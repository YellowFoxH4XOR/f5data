Description

PKCS 12 which typically uses a .p12 or .pfx file extension is a specifically formatted archive file that stores both the SSL key and certificate in a single file. The BIG-IP cannot monitor the certificate inside the PKCS 12 archive file. You must import the file into the BIG-IP certificate management configuration so it can be monitored and applied to an SSL profile.

The tmsh run sys crypto check-cert command (which runs automatically from /etc/cron.weekly/5checkcert or can be run manually) only monitors certificates that have been imported in the configuration. Additionally when you import certs and keys, they become viewable in the Configuration utility (GUI) from the SSL Certificate List page where you can monitor the dates in the Expiration column.

When you import the PKCS 12 file, the BIG-IP system extracts the certificate and key from the archive and converts them to PEM format.

Prerequisites

You must meet one of the following prerequisites to use these procedures:

  • You have access to the TMOS shell (tmsh).
  • You have access to the Configuration utility (GUI).

Procedures

Import a PKCS 12 file with the Configuration utility

Note: The PKCS 12 file will likely have a .p12 or .pfx file extension.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Navigate to System > Certificate Management > Traffic Certificate Management > SSL Certificate List in the GUI. 
  2. Select Import.
  3. Select PKCS 12 for import type.
  4. Ensure the New radio button is selected.
  5. For Certificate and Key Source select the Browse button and choose the PKCS 12 file from your workstation.
  6. Enter the password for the file.
  7. Optionally add a password to the private key that is extracted by selecting Password for Key Security and then entering Key Password.
  8. Select Import.

Import a PKCS 12 file with the TMOS shell

Note: The PKCS 12 file will likely have a .p12 or .pfx file extension.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

If you plan to import the PKCS 12 file using the TMOS shell, you must first securely copy using SCP or SFTP to transfer the file to the /shared/tmp directory. To import the PKCS 12 file, perform the following procedure:

  1. Log into the TMOS shell by typing the following command:
    tmsh
  2. Import the file using the following command syntax:
    install /sys crypto pkcs12 <use a new unique name> from-local-file </path/to/PKCS 12 file on BIG-IP> passphrase <PKCS 12 passphrase>
    For example:
    install /sys crypto pkcs12 my_certificate_2024 from-local-file /shared/tmp/pkcs12_certificate.pfx passphrase 12345
    Note: To optionally add a password to the private key that is extracted, add key-passphrase <passphrase> key-security-type password to the command
    Note: The passphrase is removed from tmsh CLI history after you end your session. If you or another user logs back in, the command will show passphrase **** or passphrase **** key-passphrase **** in the history.
  3. Save the SSL certificate and key by typing the following command:
    save /sys config
  4. Type q to exit the TMOS shell.
