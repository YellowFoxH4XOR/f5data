Description

Is it possible to modify interface speed and duplex of rSeries?
What are the effects?

Environment

  • RJ45 / Copper ports 1.0 to 4.0
  • rSeries
  • Modifying port speeds

Cause

Autonegotiation is mandatory based on IEEE standards. Refer to Autonegotiation
Note : The link above takes you to a site that is not maintained by F5. 


Only 2 modes are supported on the RJ45 ports: 1000baseT/Full or 10000baseT/Full.
 

Recommended Actions

  1. Disabling auto negotiation is not recommended. 

Additional Information

SFPs in the slots does not support auto negotiation

# ethtool sfp_5

Settings for sfp_5:

  Supported ports: [ FIBRE ]

  Supported link modes: 1000baseT/Full

                         10000baseT/Full

                         25000baseCR/Full

                         25000baseKR/Full

                         25000baseSR/Full

                         1000baseX/Full

                         10000baseSR/Full

                         10000baseLR/Full

 

  Supported pause frame use: Symmetric

  Supports auto-negotiation: No <-------------- this interface it says that auto-negotiation is not supported.

  Supported FEC modes: None

  Advertised link modes: 10000baseSR/Full <----

  Advertised pause frame use: No

  Advertised auto-negotiation: No <-------------

  Advertised FEC modes: None

  Speed: 10000Mb/s

  Duplex: Full

  Port: FIBRE
