Description

You can use the third-party tools, AWX or Ansible Automation Controller (formerly known as Ansible Tower), to manage the BIG-IP configuration and you can install F5 Modules for Ansible (FMFA) to those tools by including a requirements.yml file in a collections directory with your playbooks. AWX/Automation Controller runs the ansible-galaxy command to download the required collections when you sync your project with your source code repository.

Note: The content in this article is based on AWX, but should also apply to Ansible Automation Controller. AWX is the open source community project that serves as the upstream project for Automation Controller.

If you don't have the proper collections installed, you will see an error message in the AWX interface that appears similar to the following example:

ERROR! couldn't resolve module/action 'bigip_ucs_fetch'. This often indicates a misspelling, missing collection, or incorrect module path.

The error appears to be in '/runner/project/fetch_my_ucs.yml': line 21, column 7, but may be elsewhere in the file depending on the exact syntax problem.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You are familiar with using Ansible and AWX.
  • You have BIG-IP 13.x or later installed on the devices in the environment.
  • You have AWX installed on a control machine.
  • Playbooks in a source code repository are synchronized with your AWX project. For more information, refer to the Automation Controller User Guide.

Procedures

Create a requirements.yml file and include it in your AWX project

In the following procedure, create a file that contains one of the following YAML options depending on which type of FMFA collection you're using:

Imperative collection - f5networks.f5_modules (FMFAv1)

---
collections:
- f5networks.f5_modules

Declarative collection - f5networks.f5_bigip (FMFAv2)

---
collections:
- f5networks.f5_bigip

Note: You can include a list with both collections, as well as version, source, and other keys per the Using collections chapter in the Ansible User Guide. This previous link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Create a collections directory in your playbooks repository. This should be the repository that you use as the source control location in your AWX project.
  2. Within collections, create a requirements.yml file. The resulting relative path will be collections/requirements.yml.
  3. In the file include the YAML content from one of the options shown previously.
  4. Save the file.
  5. Commit the file to your source code repository.
  6. Log in to your AWX user interface.
  7. Go to Resources > Projects.
  8. Select your project.
  9. On the Details tab select Sync to synchronize the project with the commit from step 4.

    You are now ready to use FMFA with your AWX project.
