Description

You are trying to delete an ephemeral node and you are receiving an error similar to the following one:

0107189b:3: Cannot delete ephemeral object: /Common/_auto_203.0.113.12.

Environment

FQDN ephemeral node

Cause

By design an auto populated ephemeral node cannot be deleted if the template node exists.
No matter on which partition is the fqdn template node created, the ephemeral nodes will be created in /Common partition.

Recommended Actions

As a best practice it's better to search on all of the partitions on the respective device for the template node in question and then delete it.
Normally after deleting the template nodes the ephemeral nodes should be deleted automatically.

If not, then after deleting the template nodes and if the ephemeral nodes still exists then you can try to remove them with the following command:

tmsh delete ltm node <address>
