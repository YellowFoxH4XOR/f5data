Topic

BIG-IP APM access policies can be modified to display custom logos and banners.

The filenames of custom logos and banners must begin with logo_ or banner_ or they will not display when viewing them directly with a browser.

Description

The BIG-IP APM access policy customization code includes an allow list of file names which are permitted to be accessed directly using the following URL syntax:

https://<virtual_server_address>/public/images/customization/<partition>/<image>

For example:

https://example.apm.com/public/images/customization/Common/logo_example.gif

This protects access to information on the BIG-IP APM system and only allows direct access to the images required to customize the access policy appearance.

The allow list permits access to files with file names that begin as follows:

  • logo_
  • banner_

For example, if an access policy is configured to display a custom company logo and the logo is uploaded to the BIG-IP APM system with filename corp_logo.png, when a you view the access policy in a browser, the company logo displays but the image is not be directly accessible because the file name is not permitted by the allow list.

However, if the custom company logo is uploaded to the BIG-IP APM system with file name logo_corp.png and the access policy is customized to display this logo image, the company logo displays in the user's browser when accessing the access policy and when accessing the image directly, because the file name is permitted by the allow list.

The same is true for custom banners, but the file names of these should begin with banner_ for the allow list to permit them to be displayed and to differentiate them from the logos.
