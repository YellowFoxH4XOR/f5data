Description

After upgrade to below versions, iRule is causing reset for conneciton.
When take tcpdump you might see

Reset cause: BIG-IP: [0x2b2d3fc:2338] Route domain not reachable (strict mode)

The iRule is forwarding connection to specific node which is not in the the default route domain using node command.

  • BIG-IP
  • Upgraded to
