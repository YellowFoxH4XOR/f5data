Description
Outlook plugin fails when connecting via virtual server, but works when connecting directly to Exchange server.

This is known to occur with the KnowBe4 Phish Alert plugin.

You may observe HTTP 403 errors from the Exchange server.

Environment

  • BIG-IP configured for SSL offloading
    • SSL client-side, no SSL server-side
  • on-premise Exchange using KnowBe4 Phish Alert plugin

Cause
Undetermined. Certain Exchange functions appear to require SSL Bridging.

Recommended Actions

Configure the Exchange virtual for SSL bridging

Impact of recommended actions: you may see higher CPU use on BIG-IP and/or the Exchange servers.

  1. Ensure the Exchange servers accept HTTPS connections
  2. Change pool members to use TCP port 443
  3. Add a server-ssl profile to the virtual server
