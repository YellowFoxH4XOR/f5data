Description

The image2disk command's --format option can be used to reset the BIG-IP systems to factory defaults. However, executing the image2disk command directly against an ISO in /shared/images (e.g., image2disk --nvlicenseok --nosaveconfig --setdefault --reboot --format=volumes /shared/images/BIGIP-15.1.3.iso), may sometimes result in the device requiring a USB installation.

Environment

  • No Physical Access
  • Serial Console Access

Cause

Need to perform a Clean Install.

Recommended Actions

Create a logical volume and copy the .iso to the newly created logical volume and run image2disk against the newly created logical volume.

Note: The volume group name vg-db-sda may differ, and need to be adjusted as appropriate.
Note: Change BIG-15.1.3.iso to the ISO you want to install.
Important: Performing the following actions will completely erase all content on your BIG-IP System. This will perform a Factory Reset of your device.

  1. Create the new Logical Volume (install)
    lvcreate -L 3G -n install vg-db-sda

  2. Format the volume as EXT3
    mkfs.ext3 /dev/vg-db-sda/install

  3. Create a temporary directory
    mkdir /install

  4. Mount the new Logical Volume to the temporary directory
    mount -t ext3 /dev/vg-db-sda/install /install

  5. Copy the ISO to the new volume
    cp /shared/images/BIGIP-15.1.3.iso /install

  6. Use image2disk to perform a clean install
    image2disk --nvlicenseok --nosaveconfig --setdefault --reboot --format=volumes /install/BIGIP-15.1.3.iso

On rare occasions, the installer may fail to identify the Logical Volumes upon the initial reboot. If this occurs, perform the following:

  1. Display the Logical Volumes:

    lvscan

    Example Output:

    switch_root:/# lvscan
      inactive          '/dev/vg-db-sda/dat.boot' [448.00 MiB] inherit
      inactive          '/dev/vg-db-sda/dat.share' [40.17 GiB] inherit
      inactive          '/dev/vg-db-sda/dat.appdata' [341.44 GiB] inherit
      inactive          '/dev/vg-db-sda/dat.log' [20.09 GiB] inherit
      inactive          '/dev/vg-db-sda/dat.swapvol' [5.00 GiB] inherit
      inactive          '/dev/vg-db-sda/set.1.root' [392.00 MiB] inherit
      inactive          '/dev/vg-db-sda/set.1._usr' [3.17 GiB] inherit
      inactive          '/dev/vg-db-sda/set.1._config' [512.00 MiB] inherit
      inactive          '/dev/vg-db-sda/set.1._var' [3.00 GiB] inherit
      inactive          '/dev/vg-db-sda/install' [3.00 GiB] inherit  <<---!! inactive

  2. Activate the Logical Volumes:

    lvchange -a y vg-db-sda

  3. Proceed to copy the ISO off the disk, reinitialize the disk then run the install from MOS:

    mkdir /install
    mount /dev/vg-db-sda/install /install
    mkdir /tmpfs
    mount -t tmpfs -o size=4G blank /tmpfs/
    cp /install/BIGIP-15.1.3.iso /tmpfs/
    umount /install
    diskinit --style volumes   # Erase the hard drive.
    image2disk --nvlicenseok --nosaveconfig --format=volumes --reboot /tmpfs/BIGIP-15.1.3.iso  # Perform the install.
