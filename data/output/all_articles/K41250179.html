Known Issue

Using the Configuration utility to upload a new device certificate file may fail to update the device certificate.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to upload a new device certificate file, and use the manual method.
  • A file exists named /tmp/server.crt.

Impact

The system does not update the device certificate, and shows no error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you upload a new device certificate using the Upload File option in the Configuration utility, the device certificate remains unchanged.

Resolution

Status

F5 Product Development has assigned ID 662372 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can use the Paste Text option to import the certificate.
