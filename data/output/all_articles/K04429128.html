K04429128: Renewing NTLM Machine Account password causes Error: machine account update for '<machine_account_name>' failed: Preauthentication failed, principal name: <machine_account_name>@EXAMPLE.LOCAL. Invalid user credentials. (-1765328360)

Type
Support Solution
Published
2021-07-09
Updated
2023-10-17
Applies to
  • BIG-IP
  • BIG-IP APM: 16.X.X, 16.1.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.1, 16.0.0

Description

When admin tries to "Renew Machine Password" for newly created Machine Account the below error is thrown in GUI: 
... : ERROR: Could not connect to domain controller of realm 'EXAMPLE.LOCAL'
... : ERROR: machine account update for '<machine_account_name>' failed: Preauthentication failed, principal name: <machine_account_name>@EXAMPLE.LOCAL. Invalid user credentials. (-1765328360)
  • Machine Accountobject appears to get created fine:
    ... : machine '<machine_account_name>' has successfully joined with AD domain 'example.local' (NetBIOS domain 'EXAMPLE')


Environment

  • BIG-IP APM
  • NTLM Authentication is configured for APM

Cause

A firewall between the BIG-IP and the Domain Controller (DC) blocks traffic for udp464 and/or tcp464. During the creation of the Machine Account object the BIG-IP tries to set the password of the Machine Account, but this fails. As a result the password on the BIG-IP becomes out of sync with the password on the DC and cannot be changed anymore by the BIG-IP.

Recommended Actions

Make sure udp464 and tcp464 traffic is allowed between the BIG-IP and the DC.
Recreate NTLM machine account. Instructions can be found in K63324455.
