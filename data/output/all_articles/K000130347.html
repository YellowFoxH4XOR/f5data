Description

You are trying to set up an HTTP Explicit Proxy with client SSL and server SSL profiles to decrypt and re-encrypt traffic.

While testing you have noticed the following in the ltm log:

 01260009:4 Connection error: ssl_passthru:5855: alert(40) not SSL. 

Environment

  • BIG IP
  • Client /Server SSL profile attached to the Explicit Proxy Server attached VS.

Cause

This option can not be set since there is already an existing connection between Client and the BIG IP through HTTP Explicit Proxy.

Recommended Actions

None

Additional Information

Using ssl profile with explicit proxy cannot be done since the connection is on HTTP layer which already tunneled to the VS and expecting HTTP requests and not SSL handshake (In other words, at this stage there is a connection to the VS through HTTP).
