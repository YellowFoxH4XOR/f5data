Description

When attempting to read SNMP data objects under the IPV6-MIB subtree, the snmpwalk command will return the output below, indicating that the OID does not exist:

 # snmpwalk -v2c -c public localhost .1.3.6.1.2.1.55
IPV6-MIB::ipv6MIB = No Such Object available on this agent at this OID

Environment

  • BIG-IP v12.1.0 or later

Cause
Following the deprecation of the IPv6-specific MIBs per https://datatracker.ietf.org/doc/html/rfc8096 , in release 12.1.0, F5 disabled net-snmp support for specific MIB subtree tables including all child OIDs under MIB-2/ipv6MIB(55), ipv6IfTable.
 

Recommended Actions

Instead of accessing IPv6 address information via the IPv6 MIB, instead use the ipAddr, ipAddress, and ipAddressPrefix branches from IP-MIB, which should provide both IPv4 and IPv6 information.

IP-MIB::ipAddrTable --> .1.3.6.1.2.1.4.20

IP-MIB::ipAddressPrefixTable --> .1.3.6.1.2.1.4.32

IP-MIB::ipAddressTable --> .1.3.6.1.2.1.4.34
