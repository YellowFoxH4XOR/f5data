K13455873: Provisioned host memory for ASM may be reduced after increasing Management provisioning

Type
Support Solution
Published
2021-09-07
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K13455873

Description

Increasing management provisioning increases the amount of memory allocated to the Linux Host.
However this can decrease the amount of memory allocated to the ASM.

Environment

  • BIG-IP ASM
  • Provisioning
  • Memory

Cause

  • The ASM is a Linux kernel process 
  • When management provisioning is increased it makes more memory available to other Linux Host processes.

Recommended Actions

  1. You should consider the impact on ASM when increasing management provisioning.
  2. If your goal is to increase the provisioned host memory for ASM then you should reduce LTM provisioning level or allocate additional RAM.
