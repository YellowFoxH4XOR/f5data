Description

  • Comparing ASM policies to see the differences of what elements have been learned.
  • Possibly merging policies for a certain environment based on the application and type of traffic learned.

Environment

  • ASM
  • ASM policies
  • Seeing the difference between policies

Cause

None

Recommended Actions

How to get to the Policy Diff page on your BIG-IP ASM device GUI:

Security > Application Security > Security Policies > Policy Diff

Additional Information

Requirements:

In order to see the difference between two policies the following must be the same:

  • Application language
  • Case sensitivity
  • Differentiate between HTTP/WS and HTTPS/WSS URLs
