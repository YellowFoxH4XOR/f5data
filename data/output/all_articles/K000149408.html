K000149408: "01071c27:3: Protocol Inspection internal error: Profile doesn't exist" after upgrade

Type
Support Solution
Published
2025-02-06
Updated
2025-02-06

  • BIG-IP LTM: 16.0.0, 16.0.X, 16.0.1, 17.X.X, 16.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000149408

Description

After performing a BIG-IP software upgrade to v17.x, configuration cannot be loaded or synced through an HA group. 

  • BIG-IP devices are not able to sync, and the device that failed to load the configuration has a state of 'Awaiting Initial Sync'. 
  • The following error message is shown in the Configuration Utility under Device Management > Overview

  • The same error message is presented as a log under the /var/log/ltm file:

01071c27:3: Protocol Inspection internal error: Profile doesn't exist.

01071488:3: Remote transaction for device group /Common/sync-failover to commit id 1 7460584091945946035 /Common/<hostname> 0 failed with error 01071c27:3: Protocol Inspection internal error: Profile doesn't exist..

Environment

  • BIG-IP LTM
  • Software upgrade
  • HA pair

Cause

Bug ID 941961

Recommended Actions

  1.  Verify the output of the command:  
    tmsh load /sys config verify
  2. Using any convenient editor remove offending profiles from bigip.conf file(s) and adjust the configuration elements that use them accordingly. Follow the workaround proposed for Bug ID 941961.

Additional Information

None.
