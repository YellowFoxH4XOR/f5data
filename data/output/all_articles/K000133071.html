Source

Description

"Critical Errors found during verification" when Evaluating a deployment on BIG-IQ.

Critical Error message is "Verification error: Logging Profile <object name> contains Protocol Inspection configuration, which is not supported for device"

Environment

  • BIG-IQ
  • IPS configured on BIG-IP
  • Evaluate and Deploy failure

Cause

IPS management is not enabled on BIG-IQ

Recommended Actions

In order to manage Protocol Inspection configuration (IPS) on BIG-IQ, you must first enable it by following the procedure in the manual chapter section "Discover and import IPS services "

Additional Information

K66837555: Protocol inspection subscription license
