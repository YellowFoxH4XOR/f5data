Known Issue

In BIG-IP APM, F5 Access VPN client launches only when you run the command with sudo on MacOS Sonoma command line terminal.

This issue is observed only for the F5 Access app users running the latest Apple Sonoma OS when the OS is installed as a clean install. There are no reports of the issue happening for users who updated or upgraded from an older MacOS version to the latest MacOS Sonoma version.

This issue occurs when all of the following conditions are met:

  • You use the F5 Access VPN client to establish BIG-IP APM network access, VPN.
  • Your are using the Intel or M1 MacOS Sonoma versions.

Impact

You are unable to connect and establish network access VPN using F5 Access.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When launched from the MAC Graphical User Interface (GUI), nothing occurs and the F5 Access client does not launch.

  • When launched from the MAC command line terminal, you observe output similar to the following:

Workaround

To work around this issue, you can launch F5 Access client using the sudo command. To do so, on your MAC client terminal, enter the following command:
sudo /Applications/F5Access.app/Contents/MacOS/F5Access
