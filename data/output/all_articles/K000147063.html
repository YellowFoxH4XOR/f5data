K000147063: Why is my browser displaying a hostname in the certificate that is different from the hostname being accessed?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147063

Description

When you access a website over HTTPS, the browser checks the website's SSL/TLS certificate to verify that you connect to the correct server and that your connection is secured. In this case, it shows a different domain name.

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Answer/Recommended Actions

To solve this issue:

1. Go to the Origin Pool configuration > TLS

2. Under Origin Server Verification select Skip Verification

 

Additional Information

The browser sees the connection to F5 Distributed Cloud proxy, and that one is done with a certificate for the hostname you choose for your website.

The connection from F5XC to the origin server uses the certificate that you selected, but that will not be visible to the browser connecting to F5XC.

Skipping the TLS verification on the origin server improves: 

  • performance by reducing the overhead of SSL/TLS encryption and decryption.
  • Simplifies the configuration of the origin server, as it may not need to have an SSL/TLS certificate installed or configured.
