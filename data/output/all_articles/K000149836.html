Description

Error 50063 This dossier cannot be decrypted. The Dossier length must be evenly divisible by 512.

It occurs when copying the dossier for licensing on Activate Product .

 

 

 

Environment

Licensing

Activating Big IP

 

Cause

When additional space is added to the dossier when activating the license.

 

Answer/Recommended Actions

Copy dossier again and make sure that there is no space added.

Make sure that the dossier is copied correctly, double check the first character and last character of the dossier before copying the license.
