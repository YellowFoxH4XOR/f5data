Description
admin account for Velos Controller CLI can run only F5OS confd's command.
How to run linux command on Velos Controller/Partition CLI?
 

Environment

  • F5OS-C
  • Velos
  • CLI
  • admin
  • Linux and other commands

Cause
As design - Partition has only admin access, and linux commands are not supported. 

Recommended Actions

  • Log in to Controller CLI as root.
