Description

When class match includes "contains" operator, system shows an error as below.

Nov  2 23:35:28 big-ip err tmm[28681]: 01220001:3: TCL error: /Common/test <HTTP_REQUEST> - invalid operator contains for IP class /Common/addr_list (line 1)     invoked from within "class match [IP::client_addr] contains addr_list"

Environment

  • iRule

Cause

For IP class, contains operator is not allowed.

Recommended Actions

  1.  Please use equals operator instead.

Additional Information

Example (offending) Configuration

ltm rule /Common/test {
when HTTP_REQUEST {
    if {[class match [IP::client_addr] contains addr_list]} {
        log local0. "check1"
        pool pool_a
    } else {
        log local0. "check2"
        pool pool_b
    }
}
}
ltm data-group internal /Common/addr_list {
    records {
        10.0.40.0/24 { }
    }
    type ip
}
