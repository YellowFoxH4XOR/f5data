K51320491: Virtual Server cloning failure on BIG-IQ

Type
Support Solution
Published
2021-06-07
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K51320491

Description
When cloning a Virtual Server from BIG-IQ the following error is thrown:
"Referenced item POOL is on the wrong device"

Environment

  • BIG-IQ all versions
  • Cloning Virtual Server
  • LTM

Cause
The pool mentioned in the error message does not exist on the target device.
Currently this is BIG-IQ limitation that when cloning, it only clones VS but not its associated pools.

Recommended Actions

You will need to manually have this pool created on the target devices if you want to clone the VS.

Additional Information
None.
