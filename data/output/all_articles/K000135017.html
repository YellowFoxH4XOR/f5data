K000135017: [F5OS-A] Max limit memory

Type
Support Solution
Published
2023-06-19

  • rSeries Platforms

Source
https://my.f5.com/manage/s/article/K000135017

Description

Manual Chapter : Tenant Management says r5900 max memory size is 104GB = 106496MB

Allocated more than 104GB, then system gave the below error message on GUI.

----------------------------

/tenants/tenant{tenant1}/config: Memory is out of range. Max allowed Memory Size: 113132MB

Hide Details

  • error-type : application
  • error-tag : malformed-message
  • error-path : /f5-tenants:tenants/tenant[name='tenant1']/config

error-message : /tenants/tenant{tenant1}/config: Memory is out of range. Max allowed Memory Size: 113132MB

--------------------------


Allocate 113132MB Which is more than 104*1024MB, and get this message.

status "Tenant deployment will be processed when the platform services are running"
 

Environment

  • F5OS-A
  • rSeries
  • v1.3.x-v1.5.x
  • tenant memory allocation

Cause

  • Bug ID 1300805
  • Bug ID 1300813 

Recommended Actions

At the moment, system does not have way to calcurate how much is available, so allocate lower memory than the document.

Until above bug fix, please use the calculated value from the datasheet as the recommended maximum.
