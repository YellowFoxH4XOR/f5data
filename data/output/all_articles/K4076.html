K4076: UDP packets that lack a checksum have one inserted

Known Issue

This is the result of a known issue. In rare cases, when hardware acceleration is enabled and a UDP packet has a checksum of 0 (which means a checksum was not computed), the BIG-IP system will change the checksum when it processes the packet. This behavior can prompt the destination to reject the packet.

F5 Product Development tracked this issue as CR40815 and CR42055.

Workaround

You can work around this issue using one of the following two methods:

  • Configuring the sending device to calculate and insert checksums
  • Applying a lasthop pool to the virtual server to demote it from hardware acceleration


Configuring the sending device to calculate and insert checksums


F5 Networks recommends that you work around this issue by configuring the sending device to calculate and insert checksums by globally disabling hardware acceleration on the BIG-IP system; however, this procedure is beyond the scope of this document. For more information, refer to the documentation for the sending device.

To disable hardware acceleration globally, type the following command at the BIG-IP command line:

bigpipe global hw_acceleration none


Applying a lasthop pool to the virtual server to demote it from hardware acceleration

To apply a lasthop pool to the virtual server to demote it from hardware acceleration, perform the following two procedures:

Creating a pool containing the IP addresses of all devices from which load balanced traffic will be received

To create a pool containing the IP addresses of all devices from which load balanced traffic will be received, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Pools.
  4. Click Create.
  5. Type a name for the pool.
  6. Apply the gateway_icmp monitor by selecting it, then clicking the << button to add it to the Active list.
  7. Add the first pool member by typing the Address and Service Port in the indicated fields.
  8. Click Add.
  9. Repeat steps 7 and 8 until all pool members have been added.
  10. Click Finished.

Applying the lasthop pool to the affected virtual server

To apply the lasthop pool to the affected virtual server, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.
  3. Click Virtual Servers.
  4. Click the affected virtual server to open the configuration dialog.
  5. Select Advanced from the Configuration drop-down menu.
  6. Select the lasthop pool you just created from the Last Hop Pool drop-down menu.
  7. Click Finished.
