Description

How to determine if any of my virtual servers are using a HTTP/2 profile with a high concurrent-streams-per-connection value?

To do so, refer to the Recommended Actions section.

Environment

  • HTTP/2 profile
  • High CPU utilization

Cause

Not applicable

Recommended Actions

  1. Log in to the BIG-IP command line.
  2. Determine the concurrent-streams-per-connection value for all HTTP/2 profiles that are configured on the system by entering the following command:

    tmsh list ltm profile http2 all concurrent-streams-per-connection

    The output should list "ltm profile" followed by the HTTP/2 profile names with the concurrent-streams-per-connection value listed under each HTTP/2 profile. For example:

    ltm profile http2 http2 {
         concurrent-streams-per-connection 10
    ltm profile http2 MyCustomHttp2 {
         concurrent-streams-per-connection 100

    The above example output shows two HTTP/2 profiles on the system: the parent HTTP/2 profile (http2) with the concurrent-streams-per-connection value set to the default of 10, and a custom HTTP/2 profile (MyCustomHttp2) with the concurrent-streams-per-connection value set to 100.

  3. Determine if any virtual server references one of the HTTP/2 profiles. To do so, use the following tmsh command syntax, specifying the profile names output in step 2:

    tmsh list ltm virtual all profiles | grep -e http2 -e <HTTP/2 profile name> -e <HTTP/2 profile name>

    For example, the following tmsh command uses the profile names output in step 2 to display virtual servers that reference the parent or custom HTTP/2 profiles:

    tmsh list ltm virtual all profiles | grep -e http2 -e MyCustomHttp2

    The output should list any HTTP/2 profile name that is referenced by a virtual server and ends with a parenthesis ({). If the same profile is listed more than once, then the profile is referenced by more than one virtual server. If no output is returned, then you don't have any virtual servers that reference an HTTP/2 profile. For example,

    MyCustomHttp2 {
    http2 {
    MyCustomHttp2 {

    The above example output shows that a virtual server references the parent HTTP/2 profile (http2) and more than one virtual server references the custom HTTP/2 profile (MyCustomHttp2). In this example, since the MyCustomHttp2 profile has a high concurrent-streams-per-connection value and the profile is referenced by two virtual servers, you may want to lower the value. To lower the value, continue to the next step.

  4. If you have a virtual server referencing a HTTP/2 profile with a high concurrent-streams-per-connection value, you can lower the value back to the default by using the following syntax:

    tmsh modify ltm profile http2 <profile_name> concurrent-streams-per-connection default-value

    For example, to lower the concurrent-streams-per-connection value back to the default of 10 for the MyCustomHttp2 profile, enter the following command:

    tmsh modify ltm profile http2 MyCustomHttp2 concurrent-streams-per-connection default-value

  5. To save the configuration enter the following command:

    tmsh save /sys config
