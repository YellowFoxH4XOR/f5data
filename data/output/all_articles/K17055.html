Known Issue

BIG-IP Edge Client Datagram Transport Layer Security (DTLS) tunnels may be unexpectedly terminated.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration includes a network access profile with DTLS enabled.
  • A BIG-IP Edge Client user establishes a network access session.
  • The user's device changes the adapter interface of the DTLS tunnel to 'deprecated'.

Impact

The BIG-IP Edge Client DTLS tunnel is terminated and does not automatically recover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the user's device sets the interface that is used for the DTLS tunnel to 'deprecated,' the DTLS tunnel is terminated.
  • BIG-IP Edge Client automatically recovers the non-DTLS tunnel of the network access session.
