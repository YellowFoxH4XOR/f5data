K000137501: Velos controller is experiencing issues after an upgrade

Type
Support Solution
Published
2023-11-08
Updated
2024-02-20
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000137501

Description

Velos controller is experiencing the following errors after an upgrade:

logfile: /var/log/sw-mgmt.debug

ERROR: sw-mgmt: priority=error msgid=0x3501000000000169 msg=Failed peer (ip) connectivity checks.
CRITICAL: sw-mgmt: priority=critical msgid=0x3501000000000170 msg=Failed to receive controller services 1.6.0-18695 port assignment from active peer.
ERROR: sw-mgmt: priority=error msgid=0x3501000000000153 msg=Unexpected error importing controller services 1.6.0-18695: Failed to receive controller services 1.6.0-18695 port assignment from active peer.
DEBUG: Failed to receive controller services 1.6.0-18695 port assignment from active peer.
ERROR: sw-mgmt: priority=error msgid=0x3501000000000117 msg=Failed to import /var/export/chassis/import/iso/F5OS-C-1.6.1-19136.CONTROLLER.LTS.iso.


Environment

  • Velos
  • Controller
  • Upgrade

Cause

Unknown

Recommended Actions

  1. SSH to the active VELOS controller. Log in as 'root'.
  2. From there, SSH to the [stuck controller] using the internal 'ccpeer' link
# ssh [stuck controller IP]
  1. Stop the sw-mgmt service on [stuck controller].
# systemctl stop sw-mgmt
  1. Make a backup of /var/import/import.json
# cp /var/import/import.json ~/import.json.bak
  1. Copy the import.json file over from the [working controller].
# scp [working controller]:/var/import/import.json /var/import/import.json
  1. Start the sw-mgmt service on Controller-2.
# systemctl start sw-mgmt
  1. Wait about 5 or 10 minutes.
  2. Check if the following files contain these values: (adjust {F5OS version} accordingly) 
           /var/docker/config/controller/{F5OS_version}/env_var
           csr_port=2003

           /var/docker/config/patch/controller/{F5OS_version}/env_var.patch
           csr_patch_port=2503
  1. If you see above ports reboot [stuck controller].
# reboot
  1. Wait for it to come back up and install firmware updates
  2. Reboot again (this takes a while after the firmware update)
