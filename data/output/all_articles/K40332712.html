Known Issue

The BIG-IP system accepts an untrusted server certificate rather than dropping the connection.

This issue occurs when all of the following conditions are met:

  • You deploy the BIG-IP system as F5 Herculon SSL Orchestrator.
  • You configure the virtual server with a Server SSL profile.
  • You configure untrusted Certificate Response Control in the Server SSL profile to drop.
  • The BIG-IP system receives a certificate that it does not trust from the back-end server.

Impact

The BIG-IP system establishes a connection with the back-end server, rather than dropping the connection.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 iHealth lists Heuristic H716609 on the Diagnostics > Identified > Low page.
  • The BIG-IP system fails to drop connections to back-end servers that present untrusted certificates, even though you set Untrusted Certificate Response Control to drop.
