Known Issue

The websso process produces a core file during a shutdown event.

This issue occurs when all of the following conditions are met:

  • You license and configure the BIG-IP APM system.
  • You stop or restart the websso process.

Impact

The websso process generates a core file when shutting down.

Note: This issue does not impact processing of traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you shut down or restart the websso process, the system logs messages to the /var/log/messages file that appear similar to the following example:

    notice logger: Started writing core file: /var/core/websso.0.bld1.13.628.core.gz for PID <pid>
    notice logger: Finished writing 225456046 bytes for core file: /var/core/websso.0.bld1.13.628.core.gz for PID <pid>

  • After you restart the websso process or reboot the BIG-IP APM system, a core file for websso is located in the /shared/core file.
