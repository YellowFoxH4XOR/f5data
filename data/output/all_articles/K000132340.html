K000132340: Unable to synchronize FIPS key error on LTM pair

Type
Support Solution
Published
2023-01-31
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K000132340

Description

BIG IP with FIPS module report out of sync of certificate or keys. The sync procedure generates errors similar to:

bigipsys2 err mcpd[10105]: error: fips-codec1 Error importing private key. FIPS 0x00000081 : HSM Error: Invalid input data/params
bigipsys2 err mcpd[10105]: 01071a43:3: FIPS manager failed to synchronize FIPS key (/Common/bigipsys) from file (/config/filestore/.stage_d/1_d/Common_d/certificate_key_d/:Common:bigipsys_511718_1).
bigipsys2 err mcpd[10105]: 01070712:3: Caught configuration exception (0), unable to synchronize FIPS key (/Common/bigipsys).
bigipsys2 err mcpd[10105]: 01071488:3: Remote transaction for device group /Common/device_group to commit id 3 3232424245153619457 /Common/bigipsys1 0 failed with error 01070712:3: Caught configuration exception (0), unable to synchronize FIPS key (/Common/bigipsys)..
 

Environment

  • BIG-IP
  • FIPS
  • HA

 

Cause

Unknown
 

 Recommended Actions

Run manual sync procedure
  1. Log into the command line of the source BIG-IP system.
  2. Copy the SIM master key on the source BIG-IP system to the destination BIG-IP system by using the following command syntax, where <IP address> refers to the management IP or Self IP of the destination BIG-IP system:
  3. fipscardsync <IP address>
