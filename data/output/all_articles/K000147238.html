What Happened?

  • When in Distributed Apps > Namespace > Applications > Virtual K8s, new images for deployments using docker images are stuck in error such as "ImagePullBackOff" or "Back-off pulling image".

 

Environment

  • Docker
  • F5® Distributed Cloud console

Resolution/Answer

  • This is a common issue since the docker hub is rate-limiting the user.

  • Please subscribe to docker service https://www.docker.com/pricing/ or use another container registry.
