Description

When sorting based on "members" for any pools, will get error "General database error retrieving information."

Steps to produce the issue:

  1. Navigate Local Traffic  ››  Pools : Pool List
  2. Click on a Pool Name
  3. Click Members
  4. Click Member to sort based on members

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • BIG-IP software 14.1.4.3, 14.1.4.4, 15.1.4, 15.1.5, 16.0.1.2
  • Error "General database error retrieving information."
  • When sorting by Pool members or by Partition/Path.

Cause

Bug ID 1048141: Sorting pool members by 'Member' causes 'General database error'

Recommended Actions

Workaround when getting "General database error retrieving information." error

  1. "General database error retrieving information." error would persist even after restarting browser or logout/login the management page.
  2. Go to private mode / incognito mode of the browser.


Permanent fix for "General database error retrieving information." error

  1. Upgrade to a BIG-IP software version which is not stated in the impacted BIG-IP software version.
