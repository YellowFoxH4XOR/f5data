Security Advisory Description

Insufficient access control vulnerability in subsystem for Intel(R) CSME before version 12.0.35, Intel(R) SPS before version SPS_E3_05.00.04.027.0 may allow unauthenticated user to potentially enable escalation of privilege via physical access. (CVE-2019-0090)

Impact

Traffix SDC

An attacker with physical access to the system can exploit this vulnerability with Intel Converged Security and Management Engine (CSME) and Server Platform Services (SPS) to escalate their privileges.

BIG-IP, BIG-IQ, Enterprise Manager, and F5 iWorkflow

There is no impact; these F5 products are not affected by this vulnerability.
