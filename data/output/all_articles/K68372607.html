Description

  • Page not loading when ASM DoS profile is assigned to a virtual server.
  • Injected JavaScript with "script id="f5_cspm" blocks other scripts from the page to run

Environment

  • ASM DoS profile
  • ASM DoS JavaScript injection

Cause

  • ASM DoS profile injects a JavaScript with "script id="f5_cspm" when "collect all dos statistic" setting is enabled.
  • This feature is supported by only certain browsers/applications.

Recommended Actions

Disable "collect all dos statistic" feature.

From GUI:

  1. Go to Security ›› Reporting : Settings : Reporting Settings
  2. Locate "DoS HTTP" and uncheck "Collect All DoS Statistics"
  3. Click Save
From CLI:
  1. Run the following command to disable the feature:

    tmsh modify security analytics settings collect-all-dos-statistic disabled

  2. Save the change:

    tmsh save sys config

Additional Information

  • If an http analytics profile is assigned to a virtual server, disabling "Collect All DoS Statistics" will cause not to collect the "Page Load Time" metric
