Description

The Edge Client may fail to launch if configured for Windows Logon Integration and the Windows 'Secondary Logon' service is disabled or not running.

Environment

  • Big-IP Edge Client
  • Windows Logon Integration

Cause

When configuring the Edge Client for Windows Logon Integration, the Edge Client installation creates a local user account named "F5 Pre-Logon User".
The VPN dialer then starts the Edge Client using this local user account, using the Windows 'Secondary Logon' service.

If the 'Secondary Logon' service is disabled or not running on the client device, the "F5 Pre-Logon User" never logs in to start the Edge Client and the Edge Client  fails to launch.
 

Recommended Actions

  • Upgrade to a BIG-IP version that has the fix for ID 1350997 to support pre-logon when secondary logon service is disabled in BIG-IP Edge Client..
  • If you are unable to upgrade, or waiting to do so, when configuring the Edge Client for Windows Logon Integration, ensure the Windows 'Secondary Logon' service is enabled and running on client devices.
