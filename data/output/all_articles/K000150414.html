Description

The sshd_config file in BIG-IP cannot be edited by default and is on read-only mode. This was due to limitations in third-party software integration within F5 systems (sshd daemon)

If you are looking to modify the sshd configuration file in the BIG-IP system to modify the SSH parameters, you can achieve the same via tmsh commands.

Environment

  • BIG-IP LTM
  • sshd_config

Cause

Customers try to modify sshd_config file parameters in BIG-IP.

Recommended Actions

  ​​​​You can follow the below steps to add the desired parameter settings to the sshd_config.

  • Login to CLI and perform the following steps:

tmsh  -- to enter into the tmos

list /sys sshd all-properties -- to list all the existing properties of the ssh

edit /sys sshd all-properties -- to edit and add the required parameters in the include statement

 

Once your configurations are completed, if the configurations are still not taking effect you can run below command.

 

tmsh restart /sys service sshd

 

If you want to revert the changes you can use the below commands as well.

 

tmsh

modify /sys sshd include none

list /sys sshd all-properties

save /sys config

Additional Information

An example of how the added parameter should look inside include:

 

list sys sshd

sys sshd {

    include "LoginGraceTime 1m

    MaxAuthTries 4

    ClientAliveCountMax 3

    ClientAliveInterval 15

    X11Forwarding no

    IgnoreRhosts yes

    HostbasedAuthentication no"

}
