Issue

Error Message

011b0900:3: TMSTAT error <query>: <operation>

In this error message, note the following:

  • <query> is the statistic query that occurred.
  • <operation> is the operation being performed at the time of the failure.

For example:

011b0900:3: TMSTAT error tmstat_merge: Cannot allocate memory

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • The merged process, responsible for integrating statistical data from multiple Traffic Management Microkernel (TMM) instances, cannot query for statistics.
  • The statsd process, responsible for collecting and recording system statistics in the RRD files, cannot query for statistics. 

Impact

Statistical data may be unavailable for system utilities such as tmctl or the system performance graphs.

Recommended Actions

Errors that indicate a failed query by "tmstat_merge" may be resolved by restarting the merged process. To do so, perform the following procedure.

Impact of procedure: Performing the recommended procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Restart the statsd and merged processes by typing the following command:

    restart sys service merged
