Description

When installing a software upgrade, the install starts but does not complete, with an error similar to the following in the GUI:

Slot 0: failed (UCS application failed; unknown cause)

In /var/log/liveinstall.log, the following error messages are found:

info: /var/local/ucs/config.ucs: Not enough free disk space to install!
Terminal error: UCS application failed; unknown cause.

On other devices, you may see the following messages in /var/log/liveinstall.log:

info: Installing configuration...

info: cp: error writing '/config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1263.0.iso_67319_1': No space left on device

info: cp: failed to extend '/config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1263.0.iso_67319_1': No space left on device

info: Fatal: executing: cp -frp /var/tmp/.install_ucs/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1263.0.iso_67319_1 /config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1263.0.iso_67319_1

info: Operation aborted.

info: >----

Terminal error: UCS application failed; unknown cause.

Environment

  • BIG-IP APM
  • Installation / Upgrade
  • UCS file
  • OPSWAT EPSEC packages
     

Cause

This often happens if your UCS files are larger than 1GB.

Recommended Actions

Examine a UCS file to determine if it is excessively large. Anything above 500 MB would be considered large, depending on the size of your configuration.

If the UCS is large, check for and delete large files at the following locations:

  • /config
  • /home
  • /var

Note: Take care not to delete important files that might be needed by the system. Refer to K14403: Maintaining disk space on the BIG-IP system for guidance.

One common cause of large UCS files is an accumulation of old OPSWAT EPSEC packages, which are used by APM. These files are stored on the /config partition. A command such as the following may reveal them:

find /config -xdev -type f -exec du {} \; | sort -rn | head -30

To remove unnecessary OPSWAT EPSEC files, refer to the following article:

  • K21175584: Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system

Once the size of the UCS has been reduced, it is also recommended that you delete any unused software volumes, and attempt the upgrade again to a new volume.
