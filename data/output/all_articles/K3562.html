Known Issue

In its default configuration, BIG-IP cannot use a Microsoft Active Directory server for LDAP authentication; however, you can work around this issue by disabling LDAP case sensitivity.

To disable case sensitivity, edit the /config/bigconfig/httpd.conf file and change the following line from:

AuthLDAPCompareCase on

To:

AuthLDAPCompareCase off

If you configure BIG-IP with the correct account information, Base DN information, and LDAP server information, this change should allow authentication using Microsoft Active Directory.

For information about configuring this type of authentication, refer to K3218: Configuring remote LDAP authentication with Microsoft Active Directory.

F5 Product Development tracked this issue as CR25619.
