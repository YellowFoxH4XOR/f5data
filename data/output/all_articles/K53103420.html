Known Issue

If you set the network map as the Start screen, the Configuration utility displays a database error message.

This issue occurs when the following condition is met:

  • You set Network Map as the Configuration utility Start screen using the following menu option:

    System > Preferences > Start Screen

Impact

None. This issue is cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • At startup, the Configuration utility displays an error message that appears similar to the following example:

    General database error retrieving information.

Resolution

Status

Workaround

To work around this issue, rather than setting the network map as your Start screen, navigate manually to Local Traffic > Network Map.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
