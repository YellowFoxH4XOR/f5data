Known Issue

A user who has been assigned to a Manager role and granted access to the common partition is unable to add actions to an access policy. The user is able to create a new access policy, but when they launch the visual policy editor, the plus ( + ) icons that enable the user to add action items do not appear.

F5 Product Development tracked this issue as ID 328818 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing a hotfix, refer to K10025: Managing BIG-IP product hotfixes (10.x).
