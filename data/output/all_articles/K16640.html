Known Issue

Attempts to view the virtual server security policies page, in the BIG-IP ASM Configuration utility, may fail with an error message. The virtual server security policies page is accessible by navigating to Local Traffic > Virtual Servers > Virtual Server List > <virtual server name> > Security > Policies.

This issue occurs when the following condition is met:

  • You have assigned the following objects to a virtual server:
    • A local traffic policy that controls forwarding, with a rule that forwards traffic
    • A BIG-IP ASM security policy

Impact

You cannot use the BIG-IP ASM Configuration utility to view the affected virtual server's security policies page.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to navigate to the affected virtual server's security policies page, the BIG-IP ASM Configuration utility fails to display the security policies page and reports an error message similar to the following:

    An error has occurred while trying to process your request.
