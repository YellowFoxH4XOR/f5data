Description

You want to use iRules to select between multiple persistence profiles applied to a virtual server

Environment

  • BIG-IP LTM
  • Virtual Server
  • Multiple Persistence Profiles

Cause

Configuring a virtual server to with multiple persistence profiles is helpful in environments where you use a virtual server to process different services.

Recommended Actions

  1. Use tmsh to add the desired persistence profiles to the virtual server Note: See K39959521 in Related Content for more information
  2. Create an iRule that uses the persist command to select the different types of persistence. If your virtual server has a customized source address and cookie persistence profile, for example, your iRule should use persist source_addr and persist cookie. 
    Note: When creating the persistence profile selection iRule, ensure that the iRule persist command refers to the system parent persist profile name used by the child persistence profile of the virtual server configuration.

Additional Information

The persist iRules command does not allow you to directly reference a persistence profile, however, the command can be used to select between profiles already applied to the virtual server by type.
