K70191116: Unable load configuration on initial boot

Source

Description

BIG-IP does not load the initial configuration on new device. User receiving following error message:

01070920:3 Application error for confpp: AH00526: Syntax error on line 131 of /etc/httpd/conf.d/ssl.conf: SSL certificate: file '/etc/httpd/conf/ssl.crt/server.crt' does not exist or is empty

Environment

  • Configuration fails to load
  • Missing SSL server cert

Cause

Configuration failed to load due to missing file /etc/httpd/conf/ssl.crt/server.crt

Recommended Actions

Recreate the server.crt and reload the configuration. 

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log in to the bash shell.
  2. Regenerate the certificate and key by typing the following command:
    # openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -keyout /config/httpd/conf/ssl.key/server.key -out /config/httpd/conf/ssl.crt/server.crt
  3. Reload the configuration to load the new certificate and key by typing the following command:
    # tmsh load sys config
