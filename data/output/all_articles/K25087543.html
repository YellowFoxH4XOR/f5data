Description
You want to use FQDN nodes with an fully-qualified domain name which resolves to a CNAME (DNS Canonical Name) record.

Environment

  • FQDN nodes
  • FQDN resolves to a CNAME
  • BIG-IP configured with DNS resolver

Cause
FQDN node resolution does not does not support following CNAME records - it will not perform a second resolution. It is able to parse CNAME records and can use them if A or AAAA records are returned in the DNS response along with the CNAME.

Standard behavior for recursing/resolving DNS servers (such as ISP DNS servers, cloud providers' built-in DNS servers, or local DNS) is to resolve queries fully and return canonical records (including A or AAAA) when a request resolves to a CNAME.

Recommended Actions

Make sure that the DNS server configured for BIG-IP supports recursion and returns responses including canonical records. Normally this does not require additional configuration or customization.

Additional Information
RFC 1034 Section 4.3.2 specifies that recursing name servers should perform a full resolution, which includes CNAME resolution, to generate a response.
