Description

Traffic disrupted when using HTTP profile and compression profile with proxy-type set to reverse. 
In traffic pcap  we can notice Reset send by F5 with F5RST: Compression error.

Environment

  • HTTP profile
  • Compression profile
  • Proxy-type reverse
  • SSL Passthrough 

Cause

After the 'client hello' from the BIGIP, 'server hello' coming from the server causes an RST with F5RST: Compression error. Compression profile expects responses to be HTTP messages i.e. with a correctly formatted response, headers, and payload. Since 'server hello' does not meet that criteria, hence the compression error.

Recommended Actions

Remove the compression profile 

Additional Information

It won't be possible to compress any of the HTTP inside that SSL session, because it's going to be encrypted.
