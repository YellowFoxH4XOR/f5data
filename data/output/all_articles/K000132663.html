K000132663: Issue with initializing FIPS on the RMA device

Applies to

Source

When you try to initialise the FIPS, you get the following error message


# tmsh run util fips-util -f init

fipsutil error (line 1159): Library Initialization : 0x05 : Undefined Error Code


Check to see the Version of BIG-IP code is valid for the Hardware Platform you are running.


K9476: The F5 hardware/software compatibility matrix

For instance, if your Platform is a BIG-IP 6900F, then the latest code that you can run is 13.0.1


If you are running 13.1.0 or later, you will get the above error.
