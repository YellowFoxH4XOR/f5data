Topic

It is possible to configure the BIG-IP to use different transport protocols on the clientside and the serverside, allowing the BIG-IP system to act as a transport layer protocol translator.

The following table details the transport protocol translations that have been verified to translate successfully for some or all higher layer protocols:

Higher layer protocolClientside transport protocolSeverside transport protocol
SIPTCPUDP
AllTCPSCTP
AllSCTPTCP
RTPUDPSCTP

Note: Transport layer protocols for clientside and serverside are configured by selecting an appropriate protocol profile in the virtual server properties. To access the clientside protocol profile option, you must select Advanced in the drop-down selection box on the virtual server properties configuration screen.
