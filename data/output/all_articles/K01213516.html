Topic

You should consider using this procedure under the following condition:

  • You want to display the VNF Manager software version information.

Description

To display the VNF Manager software version, you can use the vnfm command line utility or the VNF Manager Web UI.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the VNF Manager system using the vnfm utility.
  • You have a valid user account to access the VNF Manager Web UI.

Procedures

To display the VNF Manager software version, perform one of the following procedures:

  • Displaying the software version using the VNF Manager Web UI
  • Displaying the software version using the vnfm cli utility

Displaying the software version using the VNF Manager Web UI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the VNF Manager Web UI.
  2. Navigate to Local Blueprints.
  3. Locate the last three digits of your blueprint name.

    For example, for blueprint F5-VNF-Service-Layer-GiLAN_1.0.0, your VNF Manager software version is 1.0.0

Note: Alternatively, beginning in 1.1.0, you can locate the VNF Manager version on the upper right corner of the Web UI.  

Displaying the software version using the vnfm cli utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To retrieve the software version, use the following command syntax:

    vnfm --version
