K68691386: Encryption setting for New Archive is unavailable

Type
Support Solution
Published
2021-10-21
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K68691386

Description

When create a new ucs file from GUI via System > Archives,  it is currently prompting for the "passphrase" and the "Enable" Encryption is greyed out.

Environment

  • BIG-IP

Cause

The "Enable" Encryption is greyed out when meet either of below conditions:

1. The Availability of UCS encryption is configurable using database variable security.commoncriteria  

To confirm if security.commoncriteria is configured as true, enter the following command:

tmsh list sys db security.commoncriteria

security.commoncriteria is activated if the return value is true. The output should appear similar to the following example:

sys db security.commoncriteria {
    value "true"
}

2. The database variable security.fips140.compliance could be enabled by FIPS 140-2 Compliant Mode license

To confirm if FIPS 140-2 Compliant mode is activated, enter the following command:

tmsh list sys db security.fips140.compliance

FIPS 140-2 Compliant mode is activated if the return value is true. The output should appear similar to the following example:

sys db security.fips140.compliance {
    value "true"
}

Recommended Actions

  1. Check the value of the database variable security.commoncriteria to see if it is configured to true instead of default value
  2. Check the value of the database variable security.fips140.compliance to see if it is enabled by the FIPS compliance license
