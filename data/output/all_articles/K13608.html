Known Issue

Running the EUD system memory test may cause a bridge loop.

This issue occurs when the following condition is met:

  • You run the EUD utility without disconnecting all network cables from the system.

The End-User Diagnostics (EUD) software is a set of diagnostic tests that provide reports about various components in the BIG-IP hardware unit. The EUD release notes state that before running the tests, you must disconnect all network cables from the system.

Impact

Attached network devices may experience a traffic disruption.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system broadcasts diagnostic packets on the network.
  • Attached network devices may experience a traffic disruption.

Resolution

Status

F5 Product Development has assigned ID 375510 to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you must disconnect all network cables from the system prior to running the EUD utility.

Impact of workaround: None.
