K13903: BIG-IP LTM VE includes the APM-Lite module license

Type
Knowledge
Published
2012-09-26
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 11.2.1, 10.2.1, 10.2.0, 11.2.0, 11.1.0, 10.2.2, 10.2.4, 10.2.3, 11.0.0
Source
https://my.f5.com/manage/s/article/K13903

Issue

Old Behavior

In BIG-IP LTM VE versions shipped prior to September 25, 2012, the BIG-IP LTM VE system license included an APM Base module license.

New Behavior

Beginning in BIG-IP LTM VE versions shipped on or after September 25, 2012, the system license has been corrected to include the APM-Lite module license.

Impact

None. BIG-IP LTM VE packages shipped prior to September 25, 2012 will continue to use the APM Base module license.

Recommended Actions

None
