Known Issue

Security policy event logging data does not match the referenced security policy name.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP ASM system with multiple security policies.
  • You restore a user configuration set (UCS) archive on your BIG-IP ASM system where the restored security policies are in a different order or contain a different set of security policies.
  • The BIG-IP ASM security policies process traffic, producing event log information.

Impact

The locally-logged event log data for some or all security policies is missing or does not match the referenced security policy name.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view event log data by policy name request, data does not match the policy name or event log data is missing.
  • When you compare event log data to event correlation data, the request log data does not match details listed in the event correlation data.

Workaround

To work around this issue, you can restart the asmlogd service. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure causes the BIG-IP system to temporarily stop logging while the asmlogd process restarts.

  1. Log in to the command line of the affected system with administrator privileges.
  2. To restart the asmlogd process, type the following command:

    pkill -f asmlogd
