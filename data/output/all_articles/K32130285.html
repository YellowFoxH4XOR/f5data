K32130285: LDAP Monitors created on BIG-IQ may not show in the available list

Type
Support Solution
Published
2022-05-02
Updated
2025-02-06
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K32130285

Description

BIG-IQ is not able to deploy a newly created LDAP monitor

  • Created new LDAP monitor in BIG-IQ GUI
  • When attempting to deploy the monitor, it does not show in the drop-down list.
  • No Error message

Environment

BIG-IQ Centralized Manager

  • Configuration .>> Local traffic >> Monitors 
  • Create LDAP monitor and specify username and password

Cause

After upgrading the BIG-IQ from 8.0 to 8.1 or 8.1 to 8.2, LDAP monitors created with passwords are not in the list.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Delete the affected monitor
  2. Re-create the monitor, do not input a username/password
  3. Save the monitor
  4. Edit the newly created monitor and add the username/password.
