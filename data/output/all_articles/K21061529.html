K21061529: A manual ASM LiveUpdate image file upload fails using the Configuration utility

Type
Support Solution
Published
2020-06-05
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.0, 15.0.1, 15.0.0, 15.0.X, 14.1.2
Source
https://my.f5.com/manage/s/article/K21061529

Description

Manually uploading a LiveUpdate ASM attack signature file using the Configuration utility via the System  ››  Software Management : Live Update section results in a failed signature file upload with the following error:

ASM-AttackSignatures_xxxx_xxx.im failed to upload
Unable to upload file
 

In /var/log/restjavad.0.log you see the following error:

[SEVERE][1234][05 Feb 2020 01:00:00 UTC][com.f5.rest.workers.liveupdate.LiveUpdateFileTransferWorker] null

Environment

  • BIG-IP ASM 
  • A manual Live Update signature file installation using the Configuration utility

Cause

Bug ID 911629

Recommended Actions

Install the Live Update signature file for the BIG-IP ASM system using the Advanced shell (Bash)

  1. Log in to the Advanced Shell (bash) on the BIG-IP ASM system using the root-user account.
    For example, you can use a console-access application to establish an SSH connection to the management IP address of the BIG-IP system.

  2. Place a copy of the downloaded ASM Attack Signature file (ASM-AttackSignatures_xxxxxxxx_xxxxxx.im)within the "/var/lib/hsqldb/live-update/update-files/" directory of the BIG-IP device.

  3. Adjust the signature file permissions to: -rw-r--r--
    chmod 644 /var/lib/hsqldb/live-update/update-files/ASM-AttackSignatures_20201214_154852.im

  4.  Check example signature file permission.
    ls -lh /var/lib/hsqldb/live-update/update-files/

    total 12M
    -rwxr--r--. 1 tomcat tomcat 974K Jun  5  2020 ASM-AttackSignatures_20180508_142725.im
    -rw-r--r--. 1 root   root   1.4M Dec 17 08:47 ASM-AttackSignatures_20201214_154852.im <===
    -rwxr--r--. 1 tomcat tomcat 422K Jun  5  2020 BotSignatures_20180515_150859.im
    -rwxr--r--. 1 tomcat tomcat 3.8M Jun  5  2020 BrowserChallenges_20180825_225328.im
    -rw-r--r--. 1 tomcat tomcat 3.8M Dec 17 00:42 BrowserChallenges_20201118_012927.im
    -rwxr--r--. 1 tomcat tomcat 408K Jun  5  2020 ServerTechnologies_20180214_141357.im
    -rw-r--r--. 1 tomcat tomcat 438K Dec 17 00:45 ServerTechnologies_20190828_172623.im
    drwxr-xr-x. 2 root   root   4.0K Dec 17 00:22 tmp

  5. Send a POST request specifying the signature filename in order to update the Live Update database.
    curl -sk -u admin:admin -X POST -H "Content-type: application/json" -d '{ "filename": " ASM-AttackSignatures_20201214_154852.im", "fileLocationReference": {"link": "ASM-AttackSignatures_20201214_154852.im"}}' 'https://localhost/mgmt/tm/live-update/update-files' | jq

    Note: Make note of the "selfLink" reference URL value returned similar to the highlighted example seen below.

    {
      "id": "ff808081766fdda5017671b002440008",
      "filename": "ASM-AttackSignatures_20201214_154852.im",
      "md5": "01AE67042AF360C7E8B77D8CBDE52A83",
      "fileLocationReference": {
        "link": "https://localhost/mgmt/tm/live-update/file-transfer/downloads/ASM-AttackSignatures_20201214_154852.im"
      },
      "createDateTime": "2020-12-14T15:48:52Z",
      "isFileAvailable": true,
      "isFileManuallyUploaded": true,
      "isGenesis": false,
      "kind": "tm:live-update:asm-attack-signatures:update-filesstate",
      "selfLink": "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files/ff808081766fdda5017671b002440008" <===
    }

  6. Create a POST request containing the "selfLink" URL referenced in step 4 in order to create a new installation record for the ASM signature file:
    curl -sk -u admin:admin -X POST -H "Content-type: application/json" -d '{ "updateFileReference": { "link": "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files/ff808081766fdda5017671b002440008"} }' 'https://localhost/mgmt/tm/live-update/asm-attack-signatures/installations'

  7. The ASM Signature file is now available for installation via the System  ››  Software Management : Live Update section of the Configuration utility.
