Issue

Error Message

err mcpd[<PID>]: 01070690:3: Port mirroring is not supported on this platform.

In this error message, note the following:

  • <PID> is the process ID for the tmm process.

For example:

err mcpd[7689]: 01070690:3: Port mirroring is not supported on this platform.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You configure port mirroring on a platform that does not support port mirroring.

Impact

You cannot configure port mirroring.

Recommended Actions

None
