Description

The gtmd is not able to establish a secure connection to big3d due to failure in handshake because no common ciphers were found between big3d and gtmd in FIPS mode. 
While trying to establish the iquery communication getting the below mentioned error : 
error:14077410:SSL routines:SSL23_GET_SERVER_HELLO:sslv3 alert handshake failure:s23_clnt.c:810: SSL return code: SSL_ERROR_SYSCALL

Environment

  •  BIG-IP versions 16.1.2.2 and above 
  •  FIPS 140-3 license is installed on BIG-IP or its a FullBoxFIPS device.
  •  Connections are established between big3d and gtmd in FIPS mode.

Cause

Bug ID 1120433: Removed gtmd and big3d daemon from the FIPS-compliant list

Recommended Actions

  • For 16.1.x, upgrade to 16.1.3.1 or newer
  • For 17.x, an EHF is needed from F5 Support at the time of this publication.

Additional Information

Impact 

  • SSL handshakes fail between big3d and gtmd because no common ciphers are present.
  • All the communications will be impacted as there will be no iquery communication between devices.
