K80029149: Display DNS cache records of Transparent type cache may fail to show results

Type
Support Solution
Published
2021-07-27
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP DNS: 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.X.X, 14.1.0, 14.0.1, 14.0.0, 14.1.2
Source
https://my.f5.com/manage/s/article/K80029149

Description

Display DNS cache records of a Transparent type cache may fail to show results.
If having a DNS cache configured and used on your environment, when trying to display cache entries with following command, it could show zero results:

   (tmos)# list ltm dns cache transparent <DNS-cache-name> | grep <record-to-find>

example:

   (tmos)# list ltm dns cache transparent MyCacheProfile | grep mydomainrecord.com

Environment

  • BIGIP DNS
  • DNS cache profile used and configured as a transparent type.

Cause

Unknown at the time of publication

Recommended Actions

As a workaround, try to first:

1.- Delete those specific records from the cache profile with command:

    (tmos)# delete ltm dns cache records <rrset|msg|nameserver|key> cache <DNS-cache-name>

example:

    (tmos)# delete ltm dns cache records rrset owner mydomainrecord.com cache MyCacheProfile

2.- Then, after perform more queries for same domain, search for those records with following commands:

       config # tmsh
   (tmos)# ltm dns cache records
   (tmos.ltm.dns.cache.records)# show rrset cache <DNS-cache-name> owner <record-to-find>

example:

  (tmos.ltm.dns.cache.records)# show rrset cache MyCacheProfile owner mydomainrecord.com
