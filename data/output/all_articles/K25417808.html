Known Issue

Running the load sys config merge verify command may produce an error.

This issue occurs when all of the following conditions are met:

  • You run the load sys config TMOS Shell (tmsh) command with the merge verify option to load configurations including new users.
  • You attempt to create a user with a duplicate name using the load config merge command or the Configuration utility.

Impact

It is not possible to use the verify argument when using load sys config merge with configurations containing user definitions, so the command fails and produces an error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe an error similar to the following example in tmsh:

    010719a2:3: PostgreSQL database error: ERROR:  duplicate key value violates unique constraint "auth_user_pkey" DETAIL:  Key (name)=(admin1) already exists.

Workaround

To work around this issue, you can manually remove the user data from the database. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system; however, it is always best to perform such tasks during a maintenance window.

  1. Log in to your system as the root user.
  2. At the shell prompt, type in the following command:

    psql -U postgres

  3. At the postgress=# prompt, use the following command syntax:

    \c tmdb
    DELETE FROM auth_user WHERE name='<user>';
    DROP OWNED BY <user>;
    DROP ROLE <user>;
    DROP SCHEMA <user> CASCADE;
    \q

    Note: <user> is the name of the user you want to manually remove.

  4. Press Ctrl-D to exit from the postgress=# prompt.
