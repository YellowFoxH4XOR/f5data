K000158003: BIG-IQ upgrade failed with "Invalid file content for the specified file type"

Type
Support Solution
Published
2025-11-28
Updated
2026-05-13
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000158003

Description

After upgrading the BIG-IQ system to version 8.4.0 Hotfix 1 or 8.4.0 EHF-15, users may encounter errors during files upload or installation:

  • During uploading process via the BIG-IQ Configuration Utility, you may observe the following error message:
    Error: Invalid file content for the specified file type at X.XX%
  • During BIG-IQ DCD installation, you may observe the following error message:
    Device installation failed due to Software image copy failed due to status:400, body:{\"code\":400,\"message\":\"Invalid file content for the specified file type}

These errors prevent uploading the ISO via BIG-IQ Configuration Utility and distributing it to BIG-IQ DCDs during upgrade.

Environment

  • BIG-IQ system is running on either one of the affected versions,
    • BIG-IQ 8.4.0 Hotfix 1
    • BIG-IQ 8.4.0 EHF-15 (where the build version is 8.4.0.0.15.139)
  • Uploading files to the BIG-IQ system for either one of the processes,
    • In the process of upgrading systems, uploading of an ISO file.
    • In the process of updating the GeoIP database, uploading of ZIP and/or MD5 checksum file.
  • Upgrade method attempted using the BIG-IQ Configuration Utility using either one of the menu navigations,
    • System > Software Management > Images
    • System > Software Management > Installations

Cause

ID 2140961, ID 2140945

Note: The issues are resolved from BIG-IQ 8.4.0 Hotfix 2.

Recommended Actions

To work around this issue and successfully upgrade to BIG-IQ with EHF, follow these steps on each BIG-IQ and DCD node:

  1. Copy the Hotfix ISO image manually to each device
    - Use SCP command or via winSCP :
    scp -p <local_path_to_file> <username>@<server IP/hostname>:/shared/images
  2. Install the image using tmsh
    - Run:
    tmsh install /sys software hotfix Hotfix-BIG-IQ-8.4.0-x.x.x-ENG.iso volume <volume name>
    tmsh show /sys software status
  3. Reboot into new partition
    - Copy configuration and reboot:
    cpcfg --source=HD1.1 --reboot HD1.2
  4. Post-upgrade checks for DCDs
    After reboot maybe a Data Collection Device (DCD) can display a warning message of "statistics overflow protection detected."
    K62991198: BIG-IQ DCD Warning: Statistics overflow protection detected
    When the warning appears, check to see if the ES Cluster Health status is red and multiple ES Indices are also red,

Note: MD5 checksum verification of ISO is recommended before installation.

Note: Manual upgrade does not impact database consistency if performed as described.

Note: If ES Cluster Health remains red after deleting red indices, contact F5 Support.
