Description

  • How to allow ASM GEOLOCATION not to Block Private (Internal) IP address 

Environment

  • ASM
  • geoip

Cause

  • N/A has not be included in Application Security Geolocation 

Recommended Actions

  • You have applied and allowed geiIP Enforcement from a given country/ies
  • You want to include private address from your network to make up the allowed IP address 
  • Navigate to  Security  ››  Application Security : Geolocation Enforcement,  move ' N/A'  from available section  to  Allowed Geolocations section and save

Additional Information

  • Use 'N/A' as it specifies internal IP addresses that are not mapped to a country,
  • And  use 'Other' as it specifies external IP addresses that are not mapped to a specific country.
