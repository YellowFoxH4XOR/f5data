K73474901: AS3 rpm not available after UCS restore

Type
Support Solution
Published
2022-07-27
Updated
2023-02-21
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K73474901

Description

iAppLX rpms are stored in /var/config/rest/iapps/ on the BIG-IP.
On affected versions of BIG-IP, the UCS fails to save these packages.

Before restoring the UCS :

# ls /var/config/rest/iapps/
f5-appsvcs  f5-service-discovery  RPMS


After restoring UCS with missing iApp packages:

# ls /var/config/rest/iapps/
RPMS

Note that f5-appsvcs and f5-service-discovery have disappeared.
This can result in loss of functions that depend on these iApp packages like being unable to deploy AS3 declarations.

Environment

  • BIG-IP
  • iAppLX packages such as AS3
  • UCS restore

Cause

Bug ID 1079817

Recommended Actions

The iAppLX packages must be re-installed after restoring UCS with missing iApp packages.

Additional Information

When examining the contents of the UCS archive, the rpm packages will normally be saved in the following directory:
/var/config/rest/iapps/RPMS.save/
