K19966701: Allow wildcard parameter for WebSocket URL

Description

The application is using random parameter names and WebSockets (WSS). Want to allow a wildcard parameter for a specific URL while using WSS.

  • Due to random parameter names used by the web application using WSS, it's being blocked but ASM.

Environment

  • BIG-IP ASM
  • WebSockets (WSS) are being used.
  • Random parameter names are being generated by the application

Cause

By design, parameters cannot be associated with WebSocket URLs, only with HTTP/HTTPS URLs.

Recommended Actions

To mitigate the issue follow any one step below.

  1. Modify the application so that parameter names are predictable and not random. This is the ideal solution.
    (OR)
  2. If the above can't be followed, then create a global wildcard parameter and allow it. This creates a big hole in the policy and that's why it's recommended to modify the application.
