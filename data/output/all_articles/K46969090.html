K46969090: Content length header is missing error when creating address space configuration objects

Type
Support Solution
Published
2022-09-30
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.X.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.1.X, 16.0.1, 16.0.0, 16.1.0
Source
https://my.f5.com/manage/s/article/K46969090

Description

When configuring an address space object for a network access resource you can encounter the following error:

Example: 
 
Error in getting Address Space Provider Metadata from the URI https://assets.zoom.us/docs/ipranges/Zoom.txt for the provider /Common/Zoom and error message is Content length header is missing. on 07 Jan 2022 16:48:07 UTC

Error in getting Address Space Provider Metadata from the URI https://endpoints.office.com/endpoints/worldwide?clientrequestid=277343fb-f3ac-4fea-9178-405f76537c11 for the provider /test/O365 and error message is Content length header is missing. on 07 Jan 2022 17:16:52 UTC

Environment

Relevant environmental factors specific to the topic

  • BIG-IP APM
  • Network Access 
  • Address space settings
  • Zoom or O365

Cause

Misconfigured.

Recommended Actions

It is Recommended that you use "/Common/ca-bundle.crt" bundle certificate for the "Trusted Certificate Authorities" configuration setting for Zoom or Office 356.


apm resource address-space /test/O365 {
    cfg-uri https://endpoints.office.com/endpoints/worldwide\?clientrequestid=277343fb-f3ac-4fea-9178-405f76537c11
    discovery-interval 1440
    trusted-ca-bundle /Common/default.crt                         <<< use 'ca-bundle.crt' instead
    type microsoft
}
apm resource address-space /test/Zoom {
    cfg-uri https://assets.zoom.us/docs/ipranges/Zoom.txt
    discovery-interval 1440
    trusted-ca-bundle /Common/default.crt                           <<< use 'ca-bundle.crt' instead

Additional Information
