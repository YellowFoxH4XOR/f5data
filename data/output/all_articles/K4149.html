Known Issue

This is the result of a known issue. The BIG-IP SOAP library can fail when it is performing memory intensive processes; therefore, if you use the get_all_detailed_active_connections or get_all_detailed_active_connections_ts iControl methods on a BIG-IP system that is under high traffic load, the ITCMPortal may be unable to allocate enough memory to construct the response. This causes ITCMPortal to crash and produce a core file.

F5 Networks Product Development tracked this issue as CR30493, CR37847, and CR37915.
