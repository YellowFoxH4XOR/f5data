Known Issue

The mcpd process may intermittently produce a core file and restart during configuration synchronization.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is part of the device group for configuration synchronization.
  • You initiated configuration synchronization.

This issue is sometimes known to occur after an upgrade.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H484726 on the Diagnostics > Identified > High screen.
  • The BIG-IP system generates an mcpd core file to the /shared/core directory.
  • Occasionally, you may observe an error message from mcpd in the /var/log/ltm log file that appears similar to the following example:
        
    0107072a:5: Disconnecting user svc.scmger
  • The BIG-IP system may reboot instead of restarting mcpd.
  • A failover may occur if the system is configured for high availability.
