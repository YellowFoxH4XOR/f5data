Known Issue

The configuration may fail to load the Internal Virtual Server configuration in the partition.

This issue occurs when all of the following conditions are met:

  • You start the BIG-IP system with a blank configuration.
  • You have created an external Virtual Local Area Network (VLAN) with an interface.
  • You have created a non-default route domain, and associated it with a newly created VLAN.
  • You have created a virtual server, and configured a pool in a partition other than /Common.
  • You have saved the configuration.
  • You have loaded the configuration.

    Your virtual server, pool, and route-domain configuration may appear similar to the following example:

ltm virtual ICAP_request {
destination 0.0.0.0:any
internal
ip-protocol tcp
mask any
partition part2
pool icap_pool
profiles {
/Common/tcp { }
}
source 0.0.0.0/0
translate-address disabled
translate-port disabled
vlans-enabled
vs-index 12
}
ltm pool icap_pool {
members {
10.10.10.10:webcache {
address 10.10.10.10
}
}
partition part2
}
net route-domain 2 {
id 2
vlans {
external
}
}

Impact

The BIG-IP system fails to load your configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H618246 on the Diagnostics > Identified > High screen.
  • The configuration fails to load when you use the following Traffic Management Shell (tmsh) command to load your configuration:

    load sys config partitions all verify

  • You observe an error message in the BIG-IP command line that appears similar to the following example:

    01070712:3: Values (/part2/0.0.0.0) specified for Virtual Server (/part2/ICAP_request): foreign key index (name_FK) do not point at an
    item that exists in the database.
    Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can use the common partition to complete the configuration.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
