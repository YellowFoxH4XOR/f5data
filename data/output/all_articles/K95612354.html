Environment

  • ASM Provisioned

Note: Not all customers who have run into this bug have had AFM licensed but not provisioned

Cause

This is the result of a known issue Bug ID 818309.

Recommended Actions

Upgrade, this known issue is resolved in version 15.1.0.
