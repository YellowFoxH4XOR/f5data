Description

When a vCMP guest is deployed on a blade that has recently joined a cluster provisioned for vCMP, an error similar to the following is returned and can be seen on /var/log/ltm of the vCMP host:


01510004:3: Guest (GUEST_NAME): Install to VDisk /shared/vmdisks/GUEST_NAME.img FAILED: Child exited with non-zero exit code: 255


Environment

  • BIG-IP
  • vCMP
  • VIPRION


Cause

Bug ID1408229.


Recommended Actions

Verify whether the kvm module is installed or not by running the following command on Bash CLI of the affected blade:

 

lsmod | grep kvm

 

A blade affected by ID1408229 will return an empty list.


The workaround is to reboot the newly inserted blade. Here are the steps (for example, if blade on slot 3 is affected):


1. SSH into the affected slot.


ssh slot3


2. Once you are on slot 3, reboot the blade.


reboot

3. Once the blade rejoins the cluster, verify that the previously affected blade has now kvm modules installed on the kernel by running the following command:


clsh 'lsmod | grep kvm'


The expected outcome is that all blades would now have the following kvm modules installed:


kvm_intel            179624 0

kvm                  603109 1 kvm_intel

irqbypass             13503 1 kvm
