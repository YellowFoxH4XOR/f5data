Known Issue

The NGINX Controller Agent installation process periodically prompts you to approve the installation of given packages. If you accidentally mistype the response, the package installer does not prompt you again for a confirmation.

This issue occurs when all of the following conditions are met:

  • You attempt to install NGINX Controller Agent on a Linux distribution that uses the Advanced Package Tool (APT) package manager.
  • You enter invalid input at the package installation confirmation prompt.

Impact

The issue may result in a partially installed Controller Agent.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The package installation stops after receiving invalid input, and you observe output similar to the following example:

    Do you want to continue? [Y/n] u
    Abort.

  • The Controller Agent installation continues without once again prompting you for the package install confirmation.

Resolution

Status

F5 Product Development has assigned IND-32808 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can reinstall the NGINX Controller Agent and respond affirmatively to the APT package install. To do so, refer to the Installing NGINX Controller Agent section of the NGINX Controller Admin Guide.
