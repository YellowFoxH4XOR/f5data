K20123021: LTM iRule is not removed in SSLO Interception Rule page

Type
Knowledge
Published
2023-03-31
Updated
2023-03-31
Source
https://my.f5.com/manage/s/article/K20123021

Description

iRule is created via LTM level and assigned thru the SSLO topology configuration where under Interception Rule, move the iRule from Available to Selected, deploy it. When moving the iRule from Selected to Available and deploying you may notice it is still in the Selected list.

Environment

  • SSL Orchestrator v15.1.0.7.5.2
  • iRule in Interception Rule

Cause

This issue is tracked with Bug ID 1077465
 

Recommended Actions

As a workaround, you can apply the changes in the GUI:

 Main → SSL Orchestrator → Configuration →  Interception Rule →  <sslo_example> → Resources → Move the iRule from Selected to Available →  Deploy

Additional Information

None
