K000141413: APM + Vmware View client via web browser is not allowing authentication

Type
Support Solution
Published
2025-06-04
Updated
2025-06-04
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141413

Description

Authentication fails, using browser only (Horizon View client succeeds), after upgrading your View Connection Server to 2406 (8.13) from 2309 (8.11) or an earlier version.

Environment

  • APM/VDI VMware deployment.
  • Client using internet browser to attempt to authenticate.
  • View connection server v2406

Cause

This is not an F5 issue. The issue lies with the backend Vmware server.

Prior to the Vmware server version upgrade, the server was able to have the VCS set with SAML as optional, to allow for hybrid access. This setting is now enabled by default.

Recommended Actions

Disabling SAML on the View Connection server will allow browser auth to succeed.
