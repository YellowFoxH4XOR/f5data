Known Issue

Invalid port blocks are incorrectly counted as active zombie blocks.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to process subscriber connections using a Large Scale NAT (LSN) pool.
  • The LSN pool is configured to use Port Block Allocation (PBA) mode.
  • One of the following events takes place:

    • The LSN pool configuration is modified while port blocks are active. Certain port blocks may become invalid as they no longer belong in the pool.
    • A translation request occurs during the brief period of time between port block expiration and the time the expiration is processed.

Impact

LSN pool PBA zombie statistics are invalid.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When comparing PBA statistics from the lsndb list pba and tmsh show ltm lsn-pool commands, the Traffic Management Shell (tmsh) shows a greater number of active zombie port blocks.

    Note: This is a statistic-related issue only, and system memory is not affected.

    For example, the following lsndb list pba command output shows 1 active zombie port block:

    lsndb list pba
    192.168.10.100%2                                      192.168.100.100:1234  - 6789 (z)                  

    The following tmsh show ltm lsn-pool command output shows 2000 active zombie port blocks:

    tmsh show ltm lsn-pool | grep 'Active Zombie Port Blocks'
    Active Zombie Port Blocks                        2000
