Topic

The output of the bigpipe rule show all command displays statistical information for an iRule, including the number of CPU cycles consumed by an iRule. When the number of cycles becomes large enough, a capital letter M will be appended to the output numbers to represent millions of CPU cycles used.

The following is an example of the output from the bigpipe rule show all command once the number of cycles exceeds one million:

RULE testrule+-> HTTP_REQUEST 1 total 0 fail 0 abort | Cycles (min, avg, max) = (32.46M, 32.46M, 32.46M)

Important: These counters are only populated if timing is enabled on an iRule.
