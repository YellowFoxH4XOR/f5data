K000149944: Configuration .patch files consuming /config filesystem disk space

Type
Support Solution
Published
2025-02-24
Updated
2025-02-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 17.1.2, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000149944

Description

/config filesystem is being filled with .patch files that reside in the /config/.diffVersions/config/bigip.conf directory. This is consuming all available disk space.

Directory contains 250 .patch files that are consuming a large amount of disk space, similar to the following example:

[root@bigip:Active:Standalone] config # find /config/.diffVersions/config/bigip.conf -type f | wc -l
250

[root@bigip:Active:Standalone] config # du -sh /config/.diffVersions/config/bigip.conf
2.2G   /config/.diffVersions/config/bigip.conf

[root@bigip:Active:Standalone] config # ls -lh /config/.diffVersions/config/bigip.conf
-rw-r--r-- 2 root root 4.2M Feb 11 15:41 791212.patch
-rw-r--r-- 2 root root 4.5M Feb 11 15:43 791213.patch
-rw-r--r-- 2 root root 4.8M Feb 11 15:44 791214.patch
-rw-r--r-- 2 root root 4.9M Feb 11 15:45 791215.patch
-rw-r--r-- 2 root root 4.8M Feb 11 15:47 791216.patch
-rw-r--r-- 2 root root 4.9M Feb 11 15:50 791217.patch
...

Environment

  • Configuration changes
  • Configuration patch files
  • Disk space

Cause

The configuration patch files are created by the /usr/bin/generate_config_diffs.sh shell script when the configuration is saved, as described in K53125560:

  • K53125560: Overview of BIG-IP configuration historical change tracking (config_diff)

The script is configured to keep a maximum of 250 files, as defined in the NUM_DIFFS_TO_KEEP variable.

export NUM_DIFFS_TO_KEEP=250

The accumulated patch files may consume a lot of disk space if the configuration is large.

Deleting the patch files is a temporary solution, but the problem will eventually return.

Recommended Actions

To address this problem you can reduce the value of NUM_DIFFS_TO_KEEP in generate_config_diffs.sh.

mount -o remount,rw /usr
sed -i 's/NUM_DIFFS_TO_KEEP=250/NUM_DIFFS_TO_KEEP=50/' /usr/bin/generate_config_diffs.sh
mount -o remount,ro /usr

# Optional: delete existing .patch files.
find /config/.diffVersions/config/bigip.conf -iname '*.patch' -delete

This modification must be re-applied after a software upgrade.

Additional Information

Reducing the number of patch files inhibits F5 Support's ability to troubleshoot unexpected configuration changes. However, the files may only be providing limited value if configuration changes are made very frequently.

Retaining 50 patch files is reasonable in most cases.
