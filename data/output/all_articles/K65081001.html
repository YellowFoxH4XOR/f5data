Issue

Old Behavior

In versions prior to 11.4.0, the BIG-IP system stored user password hashes using the MD5 hashing algorithm. The MD5 hash algorithm uses a 128-bit hash value.

Password hashes stored using MD5 begin with $1$ and can be viewed using the following syntax:

tmsh list auth user <username> encrypted-password

For example, to view the password for the user named example, type the following command:

tmsh list auth user example encrypted-password
auth user example {
   encrypted-password $1$0G1bvA.Q$cxe5Xfdnnw0cHZbFSwGg6.
}

New Behavior

Beginning in 11.4.0, the BIG-IP system stores user password hashes using the SHA-512 hash algorithm. The SHA-512 hash algorithm uses a 512-bit value.

Password hashes stored using SHA-512 begin with $6$ and can be viewed using the following syntax:

tmsh list auth user <username> encrypted-password

For example, to view the password for the user named example, type the following command:

tmsh list auth user example encrypted-password
auth user example {
   encrypted-password $6$u/gcPay8$acyobpJ88zHxkziwGJPcMbp9B/JukvShxg0fDJu7WuMCeB8H0XKX.90w1cAfwcXBrYCR.gjfzaolFgP2zBUua.
}

Impact

User passwords are stored in the local /etc/shadow file in a more secure manner.
