K000137060: Certificate at host f5wu2pteeihub.azure-devices.net is not trusted

Description

You may observe the BIG-IQ system reporting an error message similar to the following example:

Certificate at host f5wu2pteeihub.azure-devices.net is not trusted. Please verify the host is correct, and set up SSL Certificate Verification settings for the server certificate or one of its trust chain certificates.

Environment

  • BIG-IQ system

Cause

The certificate belongs to one of F5 sites collecting BIG-IQ usage data. For more information about BIG-IQ usage data collection, refer to K20357352: Overview of BIG-IQ usage data collection.

Recommended Actions

BIG-IQ usage data collection is enabled by default. You can disable it by logging in to the BIG-IQ user interface, navigating to the System > USAGE DATA page, and clearing the I agree to F5’s collection and use of Usage Data check box. This would stop the BIG-IQ system from sending usage data; as a result, the BIG-IQ system should not be reporting this error message.

None.
