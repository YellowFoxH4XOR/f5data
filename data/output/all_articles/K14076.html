Known Issue

The tmsh <command> /sys connection command will fail when you specify one of the following server-side client properties:

  • ss-client-addr
  • ss-client-port

Impact

You are unable to view or modify connections in tmsh specifying server-side connection properties.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to use either the tmsh <command> /sys connection ss-client-addr or tmsh <command> /sys connection ss-client-port commands, the system will display an error message that appears similar to one of the following examples:

    Syntax Error: "ss-client-addr" unknown property

    Syntax Error: "ss-client-port" unknown property

Workaround

A workaround does not exist for BIG-IP 11.x. To work around this issue for BIG-IP 10.x, you can use the bigpipe command instead of tmsh.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

You can use the following bigpipe command:

bigpipe conn ss client <IP-Address> <command>

For example:

bigpipe conn ss client 192.168.1.1 show
