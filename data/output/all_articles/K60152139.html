Topic

Link Fault Signaling (LFS) is part of the IEEE 802.3 standard that describes the ability of the PHY chip to determine remote or local link faults. Certain BIG-IP platforms support LFS to monitor and detect link status.

Description

BIG-IP platforms support LFS on 10 (or higher) gigabit interfaces. LFS is a physical layer protocol that enables communication on a link between two devices. LFS allows systems to monitor the configuration of the cables, detect link status, and report fault conditions on transmit and receive ports.

The following BIG-IP platforms support LFS for 10 gigabit or higher links:

  • BIG-IP 10000 series (D113)
  • BIG-IP 7000 series (D110)
  • BIG-IP 5000 series (C109)
  • BIG-IP i15000 series (D116)
  • VIPRION B4450 (A114)

LFS operation

LFS is enabled by default on 10 gigabit or higher links and cannot be disabled. When the system detects a local or remote link fault, the bcm56xxd process will mark the link down and log an error message to the /var/log/ltm file that appears similar to the following example:

info bcm56xxd[3124]: 012c0015:6: Link: 1.1 is DOWN
