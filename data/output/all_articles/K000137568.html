K000137568: error-message: Bad rpc, type raw-xml not supported in REST

Applies to

Source

Description

Customer fails to configure F5OS through REST api with POSTman, the failure shows in Postman as below

{

  ietf-restconf:errors: {

    error: [

      {

        error-type: application,

        error-tag: operation-failed,

        error-path: /openconfig-system:system/aaa/authentication/f5-system-aaa:users/user[username='<username>']/config/set-password/password,

        error-message: Bad rpc, type raw-xml not supported in REST

      }

    ]

  }

}

Environment

  • F5OS
  • REST Api
  • PostMan

Cause

You must also add some required headers to any API calls sent to F5OS. It is important to include the header Content-Type application/yang-data+json

Recommended Actions

Follow the guide below to set the postman properly, especially including the header Content-Type application/yang-data+json

https://clouddocs.f5.com/training/community/rseries-training/html/initial_setup_of_rseries_platform_layer.html
