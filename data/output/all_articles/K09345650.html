Description

Queries for an FQDN on your BIG-IP DNS or GTM system are not receiving load balanced responses

Environment

  • BIG-IP GTM or DNS
  • Upstream network firewall or DNS server

Cause

Query is not reaching BIG-IP. Either query is being answered by upstream DNS that is caching BIG-IP's response or upstream firewall is not passing query to BIG-IP

Recommended Actions

Take a packet capture on the BIG-IP DNS/GTM's listener to determine whether query from test client is actually reaching the BIG-IP

If it is not reaching the BIG-IP, captures on upstream devices will help you identify where the request is being blocked or responded to
