K000092669: ISO images that are uploaded may not be imported due to an incorrect destination path

Type
Support Solution
Published
2022-11-20
Updated
2022-11-20
Source
https://my.f5.com/manage/s/article/K000092669

Description


When importing an ISO file via the command line interface (via HTTP POST), although the file is uploaded successfully, it may not import into the Software Installer.
 

Environment

  • rSeries Appliance
  • F5OS

 

Cause

This is caused when an ISO file is uploaded to an incorrect destination path on the rSeries appliance.

Please note the recommended list of allowed destination directories above is incorrect. F5 is tracking this under ID1064225.
 

Recommended Action


Please ensure to only upload images to the allowed paths listed below:

    configs/
    diags/shared/
    images/import/iso/
    images/import/os/
    images/import/services/
    images/staging/

 

Additional Info

F5 is tracking this known issue via ID1064225.
