K8911: The BIG-IP ASM system logs all requests under certain conditions

Topic

The default logging profile for BIG-IP ASM security policies is Log illegal requests. The BIG-IP ASM system will ignore the default logging profile and temporarily log all requests processed by the security policy under the following conditions:

  • When running the Deployment Wizard.

    The Deployment Wizard automates several essential configuration tasks and expedites the initial configuration of a security policy. Since the Deployment Wizard initially creates a security policy with wildcard entities, and with the Perform Tightening setting enabled, the system temporarily changes the logging mechanism and logs all requests processed by the security policy. This allows the BIG-IP ASM system to discover elements in the security policy that match the wildcard entities.
  • When an attack signature in staging is triggered.

    When attack signatures detect an attack pattern during the staging period, the BIG-IP ASM system generates learning suggestions, and temporarily logs all requests processed by the security policy. This allows the user to disable the relevant attack signature without blocking on the request.
