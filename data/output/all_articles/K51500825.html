Issue

You should consider using this procedure under the following conditions:

  • You are unable to connect to BIG-APM configured VMware resources.

Symptoms

As a result of connection failure, you may encounter the following symptoms:

  • BIG-IP APM log messages show errors preventing connection.
  • A black screen occurs after successfully authenticating.
  • Packet capture shows view desktop not responding to the connection attempt.

Recommended Actions

Use the following troubleshooting steps to help determine issues connecting to BIG-IP APM configured VMWare resources:

  • Collecting troubleshooting data
  • Reviewing the BIG-IP configuration
  • Reviewing the VMWare deployment guide
  • Reviewing the BIG-IP APM client compatibility matrix
  • Reviewing BIG-IP APM logs
  • Reviewing BIG-IP APM debug VDI logs
  • Reviewing packet captures
  • Troubleshooting a black screen after authentication
  • Testing connectivity to the VMware resources

Collecting troubleshooting data

To collect the data required to troubleshoot issues with VMWare and the BIG-IP APM, refer to the following articles:

  • K000141271: Gathering data to investigate issues with VDI and BIG-IP APM
  • K71321196: Gathering data to investigate issues with VMware and BIG-IP APM (11.x - 12.x)

Reviewing the BIG-IP Configuration

Verify the following configuration items have been properly configured on the BIG-IP system:

  • Remote Desktop resource
  • Access policy
  • Client SSL profile
  • Server SSL profile
    • The SNI server name in the Server SSL profile configured to be pcoip-defult-sni.
  • HTTPS virtual server configured with the following:
    • Access policy
    • Connectivity profile
    • VDI Profile
    • Client SSL profile
    • Server SSL profile
    • HTTP profile
  • UDP port 4172 virtual server for PCoIP
    • VDI profile

Reviewing the VMWare deployment guide

F5 recommends that you check the latest VMware Horizon View deployment guide for configuration guidance, troubleshooting tips, and possible known issues.

  • F5 Deployment Guides are thoroughly tested, step-by-step configuration procedures guide you through a fast, successful deployment with your applications.

Reviewing the BIG-IP APM client compatibility matrix

To find the BIG-IP APM Client Compatibility Matrix for your specific BIG-IP version, go to the AskF5 BIG-IP APM Knowlege Center, and choose your BIG-IP APM version.

Review the BIG-IP APM Client Compatibility Matrix and verify the following:

  • Verify your version of VMware Horizon View server is listed as supported.
  • Verify your version of the VMware Horizon View client if applicable is listed as supported.
  • If you are using HTML5 (support introduced in BIG-IP 11.6.2) or Blast (support introduced in  BIG-IP 12.1), that it is supported in your version of software.

You can also determine why a session fails to get through the access profile for various reasons.

For example,

  • Failed completion of the access policy is indicated by the a message similar to the following:

    notice tmm1[5459]: 01490567:5: /Common/new_net_access:Common:b9720246: Session deleted (policy_result)

  • Exiting of the session is indicated by the a message similar to the following:

    notice tmm1[5459]: 01490567:5: /Common/new_net_access:Common:f89ba436: Session deleted (user_initiated; code - 1)

  • Denial by the access policy is indicated by the a message similar to the following:

    notice apmd[21497]: 01490102:5: /Common/new_net_access:Common:abc1234 Access policy result: Deny

Troubleshooting a black screen after authentication

If you see a black screen after successfully authenticating and selecting a pool, this may indicate an issue with PC over IP (PCoIP) traffic. When this happens verify the following:

  • The BIG-IP system has a route to the virtual desktop, and UDP/TCP port 4172 are open.
  • If you are using the BIG-IP system to natively proxy PCoIP:
    • Verify that the system is running BIG-IP 11.4 or later (with the most recently available hotfix).
    • Verify that the VMware resource Horizon View environment is using version 5.2 or later.
    • Verify that your View client is one of the listed supported clients noted in the BIG-IP APM Client Compatibility Matrix manual.

      Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  • If you are not using the BIG-IP system to proxy PCoIP traffic:
    • Verify that the client has a route to the user's Virtual Desktop.

For more information, refer to the Deploying F5 with VMware View and Horizon View deployment manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Testing connectivity to the VMware resources

You can use network layer utilities from the command line such as ping, netcat, or traceroute, to perform a simple connectivity test to confirm the VMware resource server is reachable.

Example ping command syntax: 

ping -c 4 <IP_address_of_view_desktop_server>

For example:

# ping -c 4 10.175.1.61

Output appears similar to the following:

PING 10.175.1.61 (10.175.1.61) 56(84) bytes of data.
