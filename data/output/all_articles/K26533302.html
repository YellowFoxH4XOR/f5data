Description

When you provision iRuleLX a new directory structure is created which also includes:

/opt/.sdm/var/lib/mysql/server.crt

Even though this certificate is not used by anything, it can still generate certificate expiration warnings

Environment

  • iRule Language Extensions (iRuleLX) provisioned
  • BIG-IP
  • Expired Certificate

Cause

The validity check for the certificate will take place even if the certificate is not in use

Recommended Actions

If the certificate is not in use, then it can be safely ignored.
If the certificate is in use, then it can be renewed as part of your certificate renewal process.
