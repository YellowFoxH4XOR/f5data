Topic

To display the software version and installed hotfixes on a FirePass controller, perform the following procedure:
  1. Log on to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Current Settings.

    In the FirePass Version row, the version of FirePass software is displayed.

    In the FirePass Build row, the build prefix and build number of the FirePass software is displayed.

    In the FirePass Hot-Fixes row, a list of FirePass hotfixes is displayed.

Note: The following list represents current build prefixes:

  • URM - Standard FirePass Build (English)
  • MTI - Standard FirePass Build (Japanese)
  • MTC - Standard FirePass Build (Traditional Chinese)
  • MSC - Standard FirePass Build (Simplified Chinese)
  • KOR - Standard FirePass Build (Korean)
