K45892262: BIG-IP VE configurations might be changed by cloud-init during upgrade

Type
Support Solution
Published
2025-01-09
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K45892262

Description

You may see some configurations being changed automatically during BIG-IP VE upgrade.

Environment

  • BIG-IP Virtual Edition was deployed using cloud-init customization script.
  • The script contains commands to change BIG-IP configurations.

Cause

Cloud-init saves results of execution in /var/lib/cloud/ directory. If cloud-init sees the history during boot up, it skips running customization. When BIG-IP is upgraded, the contents of the directory are not copied to the new version. As a result, from cloud-init perspective, upgrade of BIG-IP is just like the very first boot of an instance, which causes cloud-init customization.

Recommended Actions

If you do not want to run the cloud-init customization during BIG-IP upgrade, you can disable cloud-init using following command before upgrading.

  # tmsh modify sys db service.cloudinit value disable
 

You may enable it using following command.

  # tmsh modify sys db service.cloudinit value enable
