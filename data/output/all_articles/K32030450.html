Description

The dos profile configuration in bigip.conf is empty but GUI shows bados features enabled

This is how the configuration appears in the file bigip.conf:

security dos profile /Common/generic_dos_profile {
    app-service none
}

Environment

  • BADOS featured enabled
  • Dos profile can be applied to more than two Virtual Servers
  • A different BIG-IP where profile is created via GUI show a lengthy configuration in the bigip.conf

Cause

Default dos profile created via tmsh appears as shown in the 'Description' section. When the dos profile is viewed from the GUI, it appears that default features are enabled.

However, default dos profile created via tmsh does not have profile attributes enabled.

Note: Features that appear to be enabled in the GUI do not take effect.

This behaviour has been classified under Bug ID 1010717: Default DoS profile creation from tmsh is incorrectly interpreted by DoS profile GUI


Recommended Actions

Disable BADOS  or any other features that is turned on by default in the GUI after creating a DoS profile from tmsh.
