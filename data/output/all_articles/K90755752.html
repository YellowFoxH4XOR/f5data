K90755752: Localdb authentication may fail

Type
Support Solution
Published
2024-06-12
Updated
2024-06-12
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K90755752

Description

APM users authentication fail but it can be fixed by resetting all users' password. After that, the problem may occur again after around 7 days.

  • APM users  in local DB login fail
  • Error messages

LOCALDB agent: (logon attempt:1) authenticate with '<user name>' failed
notice apmd[13994]: 01490000:5: modules/LocaldbStore/LocaldbStoreAgent.cpp func: "localdblib_log_callback()" line: 12 Msg: Couldn't connect to engine!

Environment

  • APM provisioned
  • Local DB is using
  • Stand alone

Cause

VS IP address is the same with one of self-IP address.

Recommended Actions

Change VS IP address and make it different with any self-IP address.

Additional Information

None
