Known Issue

Portions of the Configuration utility may become slow and nonfunctional over time.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP modules provisioned simultaneously.
  • The Configuration utility tomcat service has been running for a period of five days, or more.

Note: This issue only affects the Configuration utility and does not affect BIG-IP traffic.

Impact

You may be unable to use all of the facilities of the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H425496 on the Diagnostics > Identified > High page.
  • You see an error message in the /var/log/tomcat/catalina.out file that appears similar to the following example:

    java.lang.OutOfMemoryError: PermGen space

  • Portions of the Configuration utility become unresponsive while other portions continue to respond normally.

Workaround

To work around this issue, you can restart the BIG-IP tomcat service. To do so, perform the following procedure:

Impact of workaround: The Configuration utility is temporarily unavailable while the tomcat service restarts.

  1. Log in to the BIG-IP command line as the root user.
  2. Restart the tomcat service by typing the following command:

    bigstart restart tomcat
