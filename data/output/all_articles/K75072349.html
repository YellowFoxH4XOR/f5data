Description

  • After adding a new ASM policy to virtual server, users are not able to access to applications 
  • ASM blocks Websocket Messages

Environment

  • BIG-IP ASM
  • Websocket traffic

Cause

The virtual server in question doesn't have a websocket profile assigned to it.

Recommended Actions

If you want the ASM system to recognize and handle WebSocket traffic, you need to associate a WebSocket profile to the virtual server in question. To do so, please follow the instruction provided on Manual Chapter : Securing Applications That Use WebSocket
