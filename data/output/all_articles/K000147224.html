K000147224: How to get fixed source NAT address

Applies to

Source

Description

Generally, the client IP is Source NATed when packets are forwarded to the origin pool but you want a fixed IP for this.

Environment

  • F5® Distributed Cloud Console

Answer/Recommended Actions

To get a fixed IP you need IP conversion of the distributed cloud:

  1. Client IP -> XC Cloud CE IP (When a packet enters the distributed cloud LB service.)
  2. Source NAT IP -> Origin Pool server IP (When a packet is forwarded to the origin server)

 Among the options above, if you choose IP address of Origin Server on given SitesorDNS Name of Origin Server on given Sitesand then select the CE, the CEs public IP will be chosen to send traffic to the origin server
