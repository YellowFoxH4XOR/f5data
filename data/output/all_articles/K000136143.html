K000136143: Enabling Envoy Metrics for HTTP Connection Manager

Type

Published
2023-09-21
Updated
2023-09-21
Applies to
  • Aspen Mesh: 1.14, 1.11
Source

Description

This article provides the information on how to enable the "HTTP Connection Manager" metrics using the Istio "Envoy Statistics" 

Environment

Aspen Mesh 1.11.x 1.14.x

Cause

The HTTP Connection Manager metrics are not enabled by default.

Recommended Actions

The "Envoy Statistics" can be used to see HTTP Connection Manager metrics.

There are two ways to enable it:

   1. The first option is to add the following information to your Aspen Mesh override values file and perform an Aspen Mesh upgrade:        

meshConfig:
    defaultConfig:
      proxyStatsMatcher:
        inclusionRegexps:
          - "http.*"

  
 2. You can also override the global stats matching configuration per proxy by using the proxy.istio.io/config annotation. You can add the annotation to a gateway proxy or a workload as follows:

metadata:
  annotations:
    proxy.istio.io/config: |-
      proxyStatsMatcher:
        inclusionRegexps:
        - "http.*"

 

Additional Information

You can also modify the inclusionRegexps prefix with the statistics you want using the envoy proxy documentation listed under "Related Content"

For more Envoy Statistics configuration you can check the documentation listed under "Related Content"
