Description

After reboot, can not log in to CLI of rSeries or VELOS as root 

login as: root
root@<appliance>'s password:
Access denied

Log in as admin to CLI or GUI and resetting root password fix the issue.
 

Environment

  • F5OS-A 1.x and F5OS-C 1.x
  • rSeries and VELOS
  • CLI login
  • root
 

Cause

Tracked as Bug ID1125349

To check appliance mode is enabled, run the command below as admin

show system appliance-mode

Output should be:

system appliance-mode state enabled

or log in to GUI and check settings at: System Settings >> General >> Appliance Mode
 

Recommended Actions

Disable appliance-mode fix this issue.

Log in to CLI as admin

config
system appliance-mode config disabled
commit and-quit

Or on GUI
System Settings >> General >> Appliance Mode : set disabled
Save
