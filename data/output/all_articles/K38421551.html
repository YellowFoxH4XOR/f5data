Issue

Error Message

notice tmm[<PID>]: 01490526:5: Initializing Access with max global concurrent connectivity session limit: <value>

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <value> is the currently licensed limit for concurrent connectivity sessions.

For example:

notice tmm[14852]: 01490526:5: Initializing Access with max global concurrent connectivity session limit: 20000

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file

Description

This message occurs when the following condition is met:

  • The BIG-IP APM module is licensed and provisioned on the BIG-IP system, and one of the following events occurs:
    • The BIG-IP APM system boots up.
    • The license for the BIG-IP APM system is reactivated.
    • An add-on license is installed on the BIG-IP APM system.
    • The standby BIG-IP APM system in a high availability (HA) configuration becomes active for the first time.

You can see the number of User Connectivity Licenses (CCUs) that are available to the BIG-IP APM system in the /config/bigip.license file:

apm_sessions :                20000

Impact

There is no impact; this is an informational message and reflects the number of licensed CCUs for the BIG-IP APM system.

Recommended Actions

None
