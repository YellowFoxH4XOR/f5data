Description

DoS Protection and Bot Defense dashboards on BIG-IP are are not displaying data. Realtime DoS data/reports are viewable.

Environment

  • AFM DoS dashboard

Cause

This is expected behaviour.
The /config/bigip.conf file shows BIG-IP unit is configured to send AVR data offbox (to DCD):

analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 10.0.0.1 10.0.0.2 }
    offbox-tcp-port 443
    source-id 62038ca1-07bd-4bb4-9e93-c697b00c37d1_10.0.0.3
    use-offbox enabled                                                   <==== Note
}

When BIG-IQ is enabled, the data is directed to the BIG-IQ system. The reports can only be viewed on the BIG-IQ DCD

Recommended Actions

As this is expected behavior, no action is needed.

Stats may also be recorded locally by enabling avrd-debug-mode:

modify analytics global-settings avrd-debug-mode enable

Important: avrd-debug-mode should only be enabled for troubleshooting purposes, and should not be left enabled.
