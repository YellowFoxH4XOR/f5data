Environment

  • Interfaces show packet drops

Cause

The counters.rx_vlan value is usually for traffic that is sent to the BIG-IP interface, for example, it receives packets with a vlan tag, but the vlan ID does not belong to any vlans that is configured on the BIG-IP interface.

Recommended Actions

Typically, this doesn’t cause any significant issues. However, it can lead to unnecessary use of switching resources and, in some cases, a capacity problem if such traffic outweighs legitimate traffic. This can be resolved by configuring the peer switch to disable unsupported automatic VLAN configuration protocols like VTP. Additionally, ensure that only the necessary VLANs are allowed on the interface connected to the BIG-IP. While this is a basic Layer 2 switching configuration when working with VLAN tags, newer network administrators may mistakenly rely on default settings and proprietary protocols like default VLANs and VTP.
