Recommended Actions

1. Copy the SELinux Policies by running the following commands from Bash:
[root@appliance-1 ~]# cp -r /usr/etc/selinux/targeted/active/modules/* /etc/selinux/targeted/active/modules/
2. Reload the SELinux modules by running the following commands from Bash:
[root@appliance-1 ~]# semodule -B
3. The following tenant status from Management CLI is seen after the semodule is reloaded:
Appliance-1# show tenants tenant <tenant name> state

...
 status        "Failed to create pod sandbox: rpc error: code = Unknown desc = failed to setup network for sandbox \"04bee1823a05ad652c85084a662eeb7c67db269af90023edc03337370ab20c83\": [default/virt-launcher-testtenant-1-pzqtn:mgmt-conf-testtenant]: error adding container to network \"mgmt-conf-testtenant\": address already in use"
...

Note - It may take some time for the tenant to reach Running status.
