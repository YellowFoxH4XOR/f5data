Known Issue

The BIG-IP system may not display interface Bidirectional Forwarding Detection (BFD) session information.

This issue occurs when the following condition is met:

  • You configure the interface BFD session between two nodes.

Impact

Your BFD session configuration is not saved in the configuration file, and you may not be able to find out if a BFD session is configured. The BFD session configuration will be lost when you restart the protocol. However, you will be able to view other BFD configuration commands.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your interface BFD session command does not appear in the zebos.conf file.

    For example, the /config/zebos/rd0/zebos.conf file does not display the following interface BFD session:

    bfd session 172.24.1.1 172.24.1.2

  • The tmsh show running-config command output does not display the interface BFD session command. However, you should be able to view the configured BFD session using the tmsh show bfd session command.
