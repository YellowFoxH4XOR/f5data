K13559: BIG-IP APM reports may erroneously display the current year

Topic

In BIG-IP APM 10.x, when you generate a report with a date range that spans a year boundary, the report will only display the current year. For example, if you run a report spanning from December 2011 to January 2012, the report will display December 2012 to January 2012. The logging daemon does not write the year as part of a log event, and as a result, BIG-IP APM uses the current year when creating the report.

Note: BIG-IP APM 11.x logs information to a database instead of a local file, and is therefore not affected by this display issue.
