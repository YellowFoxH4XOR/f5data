Description

iSeries device found to be in a shutdown/standby state.

After powering on the system, some log files contain limited entries, suggesting an orderly shutdown, for example:

(/var/log/secure)
 
Jun 18 03:15:18 i5800.bigip.corp notice systemd-logind[5320]: System is powering down.
 
(/var/log/messages)
 
Jun 18 03:15:18 i5800.bigip.corp notice syslog-ng[3792]: syslog-ng shutting down; version='3.8.1'
 
(/var/log/sel)
 
05a8 06/18/25 03:15:17 INF Host Power Cycle Event
05a9 06/18/25 03:15:21 INF Host Reset Event
 
(systemd journal)
 
Jun 18 03:15:18 i5800.bigip.corp systemd-logind[5320]: Power key pressed.
Jun 18 03:15:18 i5800.bigip.corp systemd-logind[5320]: Powering Off...
Jun 18 03:15:18 i5800.bigip.corp systemd-logind[5320]: System is powering down.

No other log messages explaining cause for shutdown.

Environment

  • iSeries

Cause

These symptoms indicate an orderly shutdown from powering off the system via AOM or LCD panel.

Recommended Actions

None
