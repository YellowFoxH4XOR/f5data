In this video, AskF5 shows you how the BIG-IP device service clustering (DSC) architecture, also known as high availability (HA), enables you to create a redundant system configuration for multiple BIG-IP devices on a network to prevent service interruptions when one device fails. To create redundancy, the system mirrors connection and persistence information to a peer device during failover. The BIG-IP system can mirror TCP, User Datagram Protocol (UDP), and SSL connections for virtual servers.

This demonstration uses BIG-IP 15.0.1.
