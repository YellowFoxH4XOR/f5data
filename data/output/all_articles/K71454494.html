Description

You want to force an active BIG-IP device to standby mode using the GUI, but you failed with the audit error log in /var/log/aduit:

notice icrd_child<[PID]>: 01420002:5: AUDIT - pid=<[PID]> user=test folder=/Common module=(tmos)# status=[Syntax Error: Must specify at least one of: "offline", "online" or "standby"] cmd_data=run sys failover

Environment

  • Multiple BIG-IPs in a device service cluster
  • Preferred device ordering is used by at least one traffic group
  • Unable to failover in GUI

Cause

The DB variable httpd.basic_auth is set to disable.

Recommended Actions

You can use the tmsh command described in K15455872 to manually force the active device to standby.

tmsh run sys failover standby

Alternatively, you can change the httpd.basic_auth to enable by the command below:

tmsh modify sys db httpd.basic_auth value enable

Note: To enable the db httpd.basic_auth may lead you to be impacted by CVE-2021-23026 on the version of below v13.1.4.1, so you may consider upgrading to v13.1.4.1 first, then changing the db key.
