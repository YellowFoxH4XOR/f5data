Known Issue

This is the result of a known issue. If the BIG-IP system forwards data to a server that is experiencing a heavy traffic load, the server sends an HTTP 100 (continue) message. This message causes the congestion control within the HTTP filter to reset. The HTTP filter is not notified when the traffic load has decreased. As a result, a portion of the data that is buffered and has not made it into the HTTP filter is not sent to the server. Communication stalls until the HTTP filter attempts to send the buffered data at once, which may result in another congestion condition.

F5 Product Development tracked this issue as CR103908 and it was fixed in 9.4.6. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.

This issue was fixed in Hotfix-BIG-IP-9.4.4-HF3, which has been issued for BIG-IP version 9.4.4, and in Hotfix-BIG-IP-9.4.5-HF2, which has been issued for BIG-IP version 9.4.5. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
