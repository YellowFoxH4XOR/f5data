Description

You are using Network Access (VPN) and want to assign a specific lease IP address to a specific device or user.

This article describes the general procedure.

Environment

Access Policy Manager (APM)

Cause

The lease IP address cannot be directly managed.

Recommended Actions

Start by creating a lease pool with just that one address.

Then edit your existing lease pool to remove that address.

 

As an example, its currently 192.168.128.5 to 192.168.128.250.

Assume you need 192.168.128.50 to be specifically assigned.

Then edit the existing lease pool to have two ranges

192.168.128.5 to 192.168.128.49

192.168.128.51 to 192.168.128.250

Create a new lease pool containing 192.168.128.50

Next step, create a new Network Access object and specify the single IP lease pool.

Finally, change the access policy.

Determine what specifically identifies that device or user.

You can use the GUI, access reports, to find a session from that device or user and look at the session variables.

If one of them will uniquely identify it, that is sufficient. If not then another method, such as Client Certificate must be used.

Then create a macro that branches on that variable and either assign the default or the specific, new, Network Access Object.

Don't assign both. Its not an error, but the outcome is unpredictable.

Additional Information

You can assign a logging option to help with testing.
