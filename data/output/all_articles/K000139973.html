K000139973: f5-fsm-tmm will report "License is missing" at startup

Type
Support Solution
Published
2024-06-11
Updated
2025-09-02
Status
Legacy Content
Applies to
  • BIG-IP Next
  • BIG-IP Next LTM: 20.2.0
Source
https://my.f5.com/manage/s/article/K000139973

Description

The f5-fsm-tmm log reports "License is missing" when the BIG-IP Next instance starts up.

2024-05-10T13:02:03.750164105Z stdout F tmm-0   <133>May 10 13:02:03 f5-fsm-tmm-7b5d4cd86c-px22c tmm[7]: 01010392:5: \"v\"=\"1.0\";\"lt\"=\"C\";\"l\"=\"notice\";\"m\"=\"License is missing\"

This appears several times.

Environment

  • BIG-IP Next
  • Reboot or restart of tmm for any other reason.

Cause

At startup, tmm is initialized with each module set to a no license state. After initialisation, tmm begins verifying the license state and for each licensed module a log message will be generated to indicate the feature is licensed.

2024-05-10T11:35:18.055037116Z stdout F tmm-2   <133>May 10 11:35:18 f5-fsm-tmm-7b5d4cd86c-px22c tmm2[7]: 01010044:5: \"v\"=\"1.0\";\"lt\"=\"U\";\"l\"=\"notice\";\"Feature\"=\"SSLO\";\"Arg2\"=\"is\";\"m\"=\"SSLO feature is licensed\"

Recommended Actions

No action is required as long as subsequent log messages indicate that required modules are licensed.

Additional Information

The f5-eesv-licensing logs provide ongoing feedback on the validity of the license.
