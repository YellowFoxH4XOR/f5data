Description

Environment

  • BIG-IP ASM
  • Disabled HTTP OPTIONS method for configuration utility 
  • Unable to modify existing bot profile

Cause

ID1128085

Recommended Actions

Re-enable HTTP OPTIONS method in the "sys httpd" base configuration.
See K74566933.
