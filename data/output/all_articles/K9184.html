Known Issue

This is the result of a known issue. The qkview script automatically calls the asmqkview script on a BIG-IP ASM standalone or if the BIG-IP ASM is running as a licensed module. However, the qkview script will abort the asmqkview script if it takes longer than 60 seconds to gather all the necessary ASM configuration and database information. As a result, no information will be gathered for the ASM portion of the system.

Note: No error message is reported if this issue is encountered.

F5 Product Development tracked this issue as CR106647 and it was fixed in BIG-IP ASM 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can gather the necessary BIG-IP ASM information by manually running the asmqkview script. To do so, type the following command:

asmqkview

Note: For more information, refer to K6824: Overview of the asmqkview script.
