Description

After upgrading to version 13.x or above, you find that iControl REST calls for BIG-IP DNS take longer to complete when using a user other than admin

Environment

  • BIG-IP DNS
  • iControl REST API
  • User other than admin

Cause

Due to Bug ID 962477, some REST API to BIG-IP DNS commands take longer to complete as the BIG-IP must internally switch between user contexts to apply the requested changes

Recommended Actions

If possible, upgrade to a version where this issue is addressed

If no fixed version is available on your software branch, there are two workaround you may consider either of the following workarounds:
  1. Modify your REST commands to use the admin user
  2. Modify your REST commands to use API Transactions Note: See Related Content for more information on using REST transactions 

Additional Information

Using transactions or the admin user will prevent the BIG-IP from having to switch between user contexts repeatedly while making the requested changes
