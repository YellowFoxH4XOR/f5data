K8114: Certain configuration settings are not restored from a backup file

Known Issue

This is the result of a known issue. If you restore your FirePass configuration from a backup file on the Device Management: Maintenance: Backup/Restore page, the system does not restore some configuration settings.

Current Issues

  • Lockout new user sessions option (CR72007)

    The Lockout new user sessions option is configured on the Device Management: Maintenance: User Session Lockout page. This setting will always be disabled after restoring from a backup file, even if the setting was enabled when the backup file was created.
  • Enable system alert E-Mails option (CR73893)

    The Enable system alert E-Mails option is configured on the Device Management: Monitoring: System Health page.
  • IPSec settings (CR73892)

    IPSec settings are configured on the Device Management: Security: IPSec Configuration page.
  • Perform failover if health monitor alarm occurs option (CR73893)

    The Perform failover if health monitor alarm occurs option is configured on the Device Management: Monitoring: System Health page.
  • Virus Database Update Automatic update settings (CR73973)

    The Virus Database Update Automatic update settings are configured on the Portal Access: Content Inspection page under the Antivirus tab in the Virus Database Update section.
  • Console Access Security settings (CR84930)

    The Console Access Security settings are configured on the Device Management: Security: Console Access Security page.

    Note: Versions prior to FirePass version 6.0.2 are not affected by this issue.

  • Check server certificate for SSL connection option (CR110040)

    The Check server certificate for SSL connection option is configured on the Device Management: Security: Back End SSL page.
  • Java Applet Tuning table (CR133952)

    The Java Applet Tuning table is located on the Portal Access: Web Applications: Content Processing page under the Global Settings tab. By default, the table is hidden. To view it, click the Show Java tuning link.

    Note: For more information about CR133952, refer to K10884: The Java Applet Tuning table is not restored from backup.

  • The key pair for an SCP log archive (CR134501)

    SCP log archives are configured in the Purge logs section of the Device Management: Maintenance: Logs page. Some earlier versions of FirePass software refer to an SCP archive as an SSH archive.

    Note: For more information about CR134501, refer to K10981: The key pair for an SCP log archive is not restored from backup.

Resolved Issues

  • SNMP settings (CR58103)

    SNMP settings are configured on the Device Management: Configuration: SNMP page.

    F5 Product Development tracked this issue as CR58103 and it was fixed in FirePass versions 6.0.1 and 6.1.0. For information about upgrading, refer to the FirePass release notes.
  • Administrator password (CR58103)

    • FirePass versions 5.4 and later

      The Administrator password is configured on the Device Management: Security: Admin Name and Password page.
    • FirePass versions 5.0 through 5.2.2

      The Administrator password is configured on the Device Management: Security: Superuser page.
    F5 Product Development tracked this issue as CR58103 and it was fixed in FirePass versions 6.0.1 and 6.1.0. For information about upgrading, refer to the FirePass release notes.
  • Enforce strong password for authentication against internal database option (CR58103)

    The Enforce strong password for authentication against internal database option is configured on the Device Management: Security: User Password page.

    F5 Product Development tracked this issue as CR58103 and it was fixed in FirePass versions 6.0.1 and 6.1.0. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by reconfiguring settings that were lost after restoring the FirePass configuration from a backup file.
