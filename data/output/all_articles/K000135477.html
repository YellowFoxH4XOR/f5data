Description

In some cases you may encounter the following error message "Request received for a non existing session" and it is common for it to coincide with a "No sid found for" error message with VDI sessions.

Environment

  • BIG-IP DNS/GTM
  • BIG-IP APM

Cause

This is generally caused by GTM directing APM requests to another global location where a session does not exist, a few items that can change client IP addresses - Hotspots, Proxies, VPNs and natting devices. 

 Recommended Actions

The GTM devices needs to be setup per the following article:

K70300789: F5 BIG-IP APM with GTM/DNS for Global Remote Access

Additional Information

In some scenarios there maybe a forwarding LTM device between the GTM and the APM devices, in this scenario the following guide should be followed as well:

K33765223: VPN for business continuity | Appendix: Load balancing BIG-IP APM Network Access VPN systems with the BIG-IP LTM system
