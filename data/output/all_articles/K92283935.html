Topic

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP system to allow ConfigSync operations only when the software versions (including hotfixes) match among device group members.

Description

BIG-IP device group members must run the same BIG-IP software version for ConfigSync operations to work between group members; this includes the major, minor, and maintenance software version numbers. By default, the point release and hotfix version numbers are not required to match among device group members when performing ConfigSync operations.

For example, by default, ConfigSync operations are permitted in the following scenarios:

  • BIG-IP-A runs 12.1.1 and BIG-IP-B runs 12.1.1
  • BIG-IP-A runs 16.0.1 and BIG-IP-B runs 16.0.1.1
  • BIG-IP-A runs 13.0.0 HF1 and BIG-IP-B runs 13.0.0 HF2

You can configure the BIG-IP systems to permit ConfigSync operations only when the major, minor, maintenance, point release and hotfix version numbers match among device group members. To do so, perform the following procedure:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have access to the TMOS Shell (tmsh).

Procedures

Configuring the BIG-IP systems to enforce point release and hotfix version matching for ConfigSync operations

To configure the BIG-IP systems to enforce point release and hotfix version matching for ConfigSync operations, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To enforce hotfix version matching, type the following command:

    modify /sys db configsync.hotfixversionmatch value enabled

  3. Repeat the previous steps for the remaining devices in the device group.

Note: To set the db key back to the default setting and disable the hotfix version matching requirement for ConfigSync operations, type the following command:

tmsh modify /sys db configsync.hotfixversionmatch value disabled
