Known Issue

Transferring a large file through the BIG-IP system may fail.

This issue occurs when all of the following conditions are met:

  • You attempt to transfer a 5 MB or larger file through your BIG-IP system.
  • The virtual server that is processing traffic is configured with an HTTP profile.
  • The HTTP profile goes into passthrough mode.

Note: Passthrough mode is an internal state where the HTTP filter does not parse data or invoke any events. This state could be the result of several factors, including the type of http-transparent profile options that are configured, how the CONNECT HTTP method is processed, or that the HTTP filter detected an unknown method or an iRule, or that the transfer took place during a protocol switch.

Impact

The BIG-IP system is unable to transfer 5 MB or larger files.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Large file transfers through your BIG-IP system intermittently hang.
  • Packets are truncated during the file transfer.
