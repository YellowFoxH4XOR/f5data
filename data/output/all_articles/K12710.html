Known Issue

This is the result of a known issue. During system startup, the BIG-IP system may log error messages similar to the following example to the /var/log/ltm file:

Could not make connection with MCP, err 16908360

You can safely ignore this error message; it indicates a temporary timing issue between the chmand and mcpd processes.

Note: For information about daemons that run on the BIG-IP system, refer to K8035: Overview of BIG-IP daemons.

F5 Product Development is tracking this issue as ID 335619 (formerly CR137868).
