Topic

This article provides information about the October 2025 F5 signing certificate and key rotation.

Description

In October 2025, F5 rotated its signing certificates and keys used to cryptographically sign F5-produced digital objects.

As a result:

  • BIG-IP, BIG-IQ TMOS and F5OS product versions released in October 2025 and later are signed with new certificates and keys
  • BIG-IP, BIG-IQ TMOS and F5OS product versions released in October 2025 and later contain new public keys used to verify certain F5-produced objects released in October 2025 and later
  • BIG-IP, BIG-IQ TMOS and F5OS product versions released in October 2025 and later may not be able to verify certain F5-produced objects released prior to October 2025
  • BIG-IP, BIG-IQ TMOS and F5OS product versions released prior to October 2025 may not be able to verify certain F5-produced objects released in October 2025 and later

These changes may affect certain use cases, including:

  • Installing BIG-IP and BIG-IQ TMOS software images while ISO image signature verification is enabled.
  • Installing BIG-IP F5OS tenant images on host systems running F5OS.
  • Installing F5OS images on VELOS or rSeries.

Installing BIG-IP and BIG-IQ TMOS software images while ISO image signature verification is enabled.

  • This feature is described in the following article:
    • K15225: Enabling signature verification for BIG-IP and BIG-IQ ISO image files
  • This feature is not enabled by default.

If ISO image signature verification is enabled:

  • BIG-IP and BIG-IQ ISOs from versions released prior to October 2025 cannot be installed on systems running a version released in October 2025 or later
  • BIG-IP and BIG-IQ ISOs from versions released in October 2025 or later cannot be installed on systems running a version released prior to October 2025

To successfully install the desired BIG-IP version in such cases:

  1. Disable ISO Signature Verification
  2. Install the desired BIG-IP version
  3. Re-enable ISO Signature Verification

It is always recommended that downloaded BIG-IP and BIG-IQ software images be manually verified before being deployed.

For more information, see:

  • K24341140: Verifying BIG-IP and BIG-IQ software images using SIG and PEM files

This article has been updated to indicate the correct public key files used to verify all released versions of BIG-IP and BIG-IQ software images.

Installing BIG-IP F5OS tenant images on host systems running F5OS.

Where possible, prefer the tar.bundle format for tenant images. This will work in all supported F5OS releases other than F5OS-A 1.5.x.

Special considerations apply to:

  • Installing a BIG-IP F5OS tenant image released in October 2025 or later on an F5OS host version released prior to October 2025
  • Installing a BIG-IP F5OS tenant image released prior to October 2025 on an F5OS host version released in October 2025 or later

In either case:

  • Installation of F5OS tenant images using the tar.bundle format will succeed. This option is only available on:
    • F5OS-A (Appliance) version 1.7.0 and later
    • F5OC-C (Chassis) all supported releases
  • Installation of F5OS tenant images using the qcow2.zip.bundle format released prior to October 2025 will fail to be verified on the following F5OS host versions released in October 2025 or later:
    • F5OS-A 1.5.4 and later in F5OS-A 1.5.x
  • Installation of F5OS tenant images using the qcow2.zip.bundle format released in October 2025 or later will fail to be verified on the following F5OS host software versions:
    • F5OS-A 1.5.3 and earlier
    • F5OS-A 1.7.0 and later (instead, use the tar.bundle format)
    • F5OS-C all supported versions (instead, use the tar.bundle format)

The qcow2.zip.bundle format for tenant disk images is deprecated. Instead, use the tar.bundle format, which is the replacement. Tenants deployed from either format operate identically.

Affected Versions

BIG-IP and BIG-IQ versions released in October 2025 and later, (signed with new certificates and keys and including new public keys for verification) include:

  • BIG-IP 17.5.1.3
  • BIG-IP 17.1.3
  • BIG-IP 16.1.6.1
  • BIG-IP 15.1.10.8
  • BIG-IQ 8.4.0 EngHF 15
  • BIG-IQ 8.3.0 EngHF 34

BIG-IP and BIG-IQ versions released prior to October 2025 (signed with old certificates and keys and including old public keys for verification) include:

  • BIG-IP 17.5.1.2 and earlier
  • BIG-IP 17.1.2.2 and earlier
  • BIG-IP 16.1.6 and earlier
  • BIG-IP 15.1.10.7 and earlier
  • BIG-IQ 8.4.0 and earlier

Installing F5OS images on VELOS or rSeries.

F5OS images are cryptographically verified when imported into the system, this process is always enforced by default and not configurable.

  • Installing an F5OS image released after October 2025 or later on an F5OS host version released prior to October 2025 will succeed.
  • Installing an F5OS image released before October 2025 on an F5OS version released after October 2025 will fail by design.
    • F5OS-A (Appliance) on versions 1.8.4 or later:
      • Versions 1.5.3, 1.7.0, 1.8.2 or earlier will fail to be installed.
    • F5OS-C (Chassis) on versions 1.8.3 or later:
      • Versions 1.6.2, 1.8.1 or earlier will fail to be installed.
  • Installing an F5OS image released after October 2025 on an F5OS version 2.0.0 or higher might fail for some versions listed below. This is also by design, as some versions released just after the certificate rotation were created with six months of validity, and the verification process is stricter from version 2.0.0 onwards.
    • F5OS 2.0.0 or later:
      • Versions F5OS-A 1.5.4 and 1.8.3 will fail to be installed.
      • Versions F5OS-C 1.6.4 and 1.8.2 will fail to be installed.

For more information, see:

  • K000162186: F5OS image signature verification process and October 2025 implications
