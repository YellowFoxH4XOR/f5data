Known Issue

BIG-IP slot status information and sensor tables are not displayed when you use the tmsh show sys hardware command.

This issue occurs when all of the following conditions are met:

  • You are running one of the following BIG-IP platforms:

    • BIG-IP 2000s/2200s
    • BIG-IP 4000s/4200v
    • BIG-IP 5000s
    • BIG-IP 7000s/7200v
    • BIG-IP 10000s/10200v
    • VIPRION B2100/B2150/B2250 blades
  • You attempt to view status information using the tmsh show sys hardware command.

Impact

None.  You can safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Slot status information is no longer displayed when you run a tmsh show sys hardware command on the primary blade.

Workaround

To work around this issue, you can obtain the missing information using alternative commands. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line as the root user.
  2. You can use the following commands to view some of the missing information:

    system_check -d

    bladectl -v
