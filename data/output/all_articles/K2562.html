K2562: Reasons why configuration synchronization may fail after an administrative password is changed

Topic

The CORBA daemon uses the administrative account password (admin user) to authenticate the BIG-IP systems. If the passwords were changed for the web user interface, you must also update the BIG-IP database.

To resolve this issue, perform the following steps to update the BIG-IP database:

  1. Initiate the First Time Boot/Setup utility, by typing the following command:

    config

  2. Press R for Redundant properties.
  3. Proceed through the redundant properties configuration until you reach the configure remote access screen.
  4. Press the Enter key to go to the next screen.

    You should see the following displayed, with the IP addresses for both the BIG-IP systems in the redundant pair:

    Specify usernames and passwords of webserver accounts on remote hosts. x 
x    These accounts will be used for authentication....
  5. Press Enter on each IP address and specify the username/password for the webserver accounts with write privileges.
  6. Finish the configuration and exit the First-Time Boot/Setup utility.
  7. Restart the CORBA, by typing the following command:

    bigstart restart
