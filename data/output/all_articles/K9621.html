K9621: The unit_id parameter is not related to the BIG-IP LTM unit ID setting

Topic

After configuring a BIG-IP redundant server on the BIG-IP GTM system, the configuration object is displayed in the wideip.conf file that appears similar to the following example:

server { // datacenter=lab, #VS=0
name "bigip01"
type bigip
box {
address 1.1.1.1
unit_id 1
}
box {
address 1.1.1.2
unit_id 2
}
}

The unit_id parameter, designated for BIG-IP redundant server objects in the wideip.conf file, indicates the order in which the gtmd process inputs the server IP addresses when the server object was created. The unit_id is not related to the high availability unit ID setting configured on redundant BIG-IP LTM devices.

Note: This article does not apply to BIG-IP GTM 11.0.0 and later. Beginning in version 11.0.0, the BIG-IP GTM configuration is in the /config/bigip_gtm.conf file. Additionally, the server configuration objects no longer use the unit_id designator.
