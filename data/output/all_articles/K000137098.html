K000137098: BIGIQ - how to review the logs from elastic search indices

Type
Support Solution
Published
2023-10-03
Updated
2023-10-03
Source
https://my.f5.com/manage/s/article/K000137098

Description

The BIGIP/BIGIQ administrator may require to review (and possibly export or copy) the raw logs from ElasticSearch indices instead of viewing the logs from BIGIQ GUI CM.

Environment

  • BIGIQ
  • ElasticSearch
  • Index

Cause

None

Recommended Actions

1) On CM (or DCD) we can check the existing indices. In lab, I'm interested in APM related 'access-active-sessions' index:

[root@bigiq-cm:Active:Standalone] config # curl -sk -u admin:admin https://localhost:9200/_cat/indices?pretty
