K000146800: F5® Distributed Cloud Services doesn't discover any AWS service

Type
Support Solution
Published
2024-11-08
Updated
2025-02-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000146800

Description

  • You deployed a node (single nic) in Amazon Web Services (AWS) in the same Amazon Virtual Private Cloud (Amazon VPC) as your Amazon Elastic Kubernetes Service (Amazon EKS)
  • Your EKS is up and running and publishing services 
  • You created a service-discovery object and imported your kubeconfig
  • Your kubeconfig works
  • F5® Distributed Cloud Services (or the node) doesn't discover any service
  • Service discovery is not working

Environment

  • F5® Distributed Cloud Node

Cause

  • You need your AWS programmatic Keys in the kubeconfig
  • For Amazon EKS you have to use token-based authentication, so you need the raw AWS credentials (not Distributed Cloud Services Cloud Credential) in the kubeconfig file

Answer/Recommended Actions

  • Add your AWS programmatic Keys (Account ID and KEY) into the kubeconfig file following the instructions here
