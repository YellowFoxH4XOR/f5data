Description

If you navigate to System  ››  Certificate Management : Traffic Certificate Management : SSL Certificate List from Configuration Utility,  iControl SOAP logs a message below in /var/log/ltm.
info soap[5108]: src=127.0.0.1, user=

Environment

  • iControl SOAP
  • Configuration Utility

Cause

This log message indicates that, iControl is called internally.

 Recommended Actions

This log message is by design, and you may safely ignore it.

Additional Information

None
