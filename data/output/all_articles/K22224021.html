Description

This article helps you determine if your Advanced WAF (AWAF) or BIG-IP ASM system is affected by CVE-2021-22991.

Environment

  • AWAF or BIG-IP ASM
  • CVE-2021-22991
Cause

If you are using AWAF or ASM and your BIG-IP software is listed in the Versions known to be vulnerable column of the table in K56715231: TMM buffer-overflow vulnerability CVE-2021-22991, your system is vulnerable if any of the following conditions are true:

  • The Risk Engine feature is enabled.
  • Note: As of March 10, 2021, when the vulnerability was disclosed, this feature is available to Early Access customers only and requires a special license.
  • A virtual server associated with an HTTP profile (K40243113: Overview of the HTTP profile) and a local traffic policy (K04597703: Overview of the Local Traffic Policies feature (12.1.0 and later)) that has a rule condition with the HTTP URI or HTTP Referer and Use normalized URI options enabled
  • A virtual server associated with an HTTP profile and an iRule using any of the following commands with the -normalized switch:
    • HTTP::uri
    • HTTP::query
    • HTTP::path

Recommended Actions

You can determine from the BIG-IP command line if the Risk Engine is enabled if all the following are true:
  • The security.tap.allow DB key is enabled. You can verify by entering the following command:
    tmsh list sys db security.tap.allow
  • There is a cloud services application with valid Cortex credentials and service class setting is tap. You can verify by entering the following command:
    tmsh list security cloud-services application access-token service-class
  • The previous cloud services application is attached to a virtual server in the app-cloud-security-services property. You can verify by entering the following syntax:
    tmsh list ltm virtual app-cloud-security-services
Note: The db variable security.tap.allow was added since BIG-IP v15.x

You can determine if virtual servers with an HTTP profile and either a local traffic policy or iRule use URI normalization by referring to the Is there a way to query my configuration to help me identify iRule or LTM Policy configurations that I should review? question in K90004114: Frequently asked questions for CVE-2021-22991

Additional Information

The AWAF/BIG-IP RIsk Engine requires a special license.
