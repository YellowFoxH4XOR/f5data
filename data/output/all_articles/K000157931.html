Description

VELOS controller upgrade failed when executing a system image set-version command.

Command appears to time out after 5-10m, returning:

Error: application timeout

Environment

  • VELOS
  • F5OS-C upgrade

Cause

A very large file exists in /var/confd/log that is causing the pre-upgrade compatibility checks to time out.

When this problem occurs, you can observe entries similar to the following at the end of /var/log_controller/cc-upgrade.dbg:

2025-11-02T23:41:06.404827+01:00 + tar -cf - lib/controller confd

2025-11-02T23:41:06.409130+01:00 + tar -xf -

The /var/log_controller/velos.log file also contains an entry similar to the following from upgrade-service:

Compatibility verification failed - data setup

Recommended Actions

Examine the contents of /var/confd/log on both system controllers for large log files.

You can truncate large logs, if found, with:

truncate -s0 <log file>

Note: The above command will delete the contents of the log file. You may wish to back it up first.

Additional Information

If there are no large log files at /var/confd/log and your upgrade is still failing with application timeout, it is likely a different issue and further investigation is required. Open a case with F5 Support.
