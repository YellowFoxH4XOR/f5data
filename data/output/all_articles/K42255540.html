Description

The Nessus application vulnerability scanner may incorrectly report that the AOM should be upgraded to Debian 9.x with messages below:

Debian 7.0 support ended on 2016-04-26 end of regular support / 2018-05-01 (end of long-term support for Wheezy-LTS).
Upgrade to Debian Linux 9.x ("Stretch").

Environment
  • Run the Nessus application vulnerability scanner

Cause

False positive being triggered based on the fact AOM firmware version is displayed as 3.2 which makes Nessus think it is Linux Kernel 3.2 which is not-supported since May 2018 hence upgrade is recommended.

Enter Command: i

Host subsystem information:
    Chassis Part Number       : 200-0393-04 REV C
    Chassis Serial Number     : f5-xxxx-xxxx
    Product Part Number       : ESS-0002-01 REV D
    Product Serial Number     : ess0002z0e37
    Power status              : on

Firmware versions
    AOM Firmware Version (1)  : 4.6.17
    AOM Firmware Version (2)  : 5.6.9 (Active)
    AOM Bootloader Version    : 3.2             <==================
    AOM Firmware Build Date   : Apr 10 2018 14:11:34 PDT
    CPLD version              : 0x26
    LCD Application Version   : 2.02.082.00.0

Recommended Actions

None

Additional Information

The AOM (Always-On Management) is a firmware OS, and is not based on Linux.  The message above returned by the Nessus scanner does not apply to the AOM.
