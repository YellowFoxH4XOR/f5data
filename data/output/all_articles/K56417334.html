Description

How to install the FAST template feature on a BIGIP running v14.0 or above

Environment

BIGIP running v14.0 or above

Recommended Actions

To install the FAST template feature on a BigIP running v14.0 or later, follow the steps below:

  1. Download the latest AS3 rpm file (f5-appsvcs-#.#.#-#.noarch.rpm) from the following GitHub link:

    https://github.com/F5Networks/f5-appsvcs-extension/releases
     
  2.  Install the file by going to the BIGIP's Web Management Interface > iApps > Package Management LX > Choose file > Select the file you just downloaded > Upload
     Note: the installation process may take a few minutes. When its done the 'f5-appsvcs' and the 'f5-appsvcs-discover' package should show up on the 'Package Management LX' page
     
  3. After you have installed BIG-IP AS3, you can test for a successful installation by sending a GET request to the /info endpoint.
    For example, from your browser, open https://(IP address of BIG-IP)/mgmt/shared/appsvcs/info After entering your credentials, you should see something like: { "version": "3.8.0", "release": "2", "schemaCurrent": "3.8.0", "schemaMinimum": "3.0.0"}
     
  4. Download the latest FAST extension RPM (f5-appsvcs-templates-#.#.#-#.noarch.rpm) from the following GitHub link:

    https://github.com/F5networks/f5-appsvcs-templates/releases
     
  5.  Install the file by going to the BIGIP's Web Management Interface > iApps > Package Management LX > Choose file > Select the file you just downloaded > Upload
     Note: the installation process may take a few minutes. When its done the 'f5-appsvcs-templates' package should show up on the 'Package Management LX' page.
     
  6. Next go to the BIGIP's Web Management Interface > iApps > Application Services > Applications LX > F5 Application Services Templates > Click the 'Deploy' tab > big-fast-templates > Click on a bigip-fast-template and configure as desired.
