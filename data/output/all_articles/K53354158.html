Description

BIG-IP devices go into a "Changes Pending" loop because the certificate from the BIG-IP is not present.

Environment

  • Data Collection Device (DCD)
  • Changes Pending loop
     

Cause

Trusted Device Certificates from the BIG-IP failed to be added to the DCD.

It will not trust as it didn't have a certificate for that BIG-IP.


Recommended Actions

  1. Export the Device Certificate from the BIG-IPs,

    See "Manual Chapter : Device Certificate Management" for your version of the BIG-IP software on https://my.f5.com/ .

  2. Import those Device Certificates into the DCDs at the SSL Certificate Verification page under the System tab.
