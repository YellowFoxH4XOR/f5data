Known Issue

This is the result of a known issue. If the arguments for the bigpipe snmpd syslocation and bigpipe snmpd syscontact commands contain white space, the command will fail with a bigpipe parsing error.

For example:

bigpipe snmpd syscontact John Doe j.doe@f5.com

The example command would cause the following bigpipe parsing error:

012e0051:3: The requested attribute (Doe j.doe@f5.com) is invalid for 'snmpd'.

For example:

bigpipe snmpd syslocation Engineering Services Lab

The example command would cause the following bigpipe parsing error:

012e0051:3: The requested attribute (Services Lab) is invalid for 'snmpd'.

F5 Product Development tracked this issue as CR106533 and and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Workaround

You can work around this issue by placing escaped double quotes ( " ) around the parameter when using the bigpipe command.

For example:

bigpipe snmpd syscontact \"John Doe j.doe@f5.com\"
bigpipe snmpd syslocation \"Engineering Services Lab\"
