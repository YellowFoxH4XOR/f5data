K000135679: When adding an ASM policy to an HTTP2/GRPC Virtual Server it stops working

Type
Support Solution
Published
2023-07-31
Updated
2026-04-17
Source
https://my.f5.com/manage/s/article/K000135679

Description

When adding and ASM policy to a Virtual Server that uses HTTP2 and GRPC traffic, it stops working.


Environment

BIG-IP ASM

HTTP2/GRPC


Cause

GRPC is not supported by ASM


Recommended Actions

Don't use GRPC


Additional Information

None
