Description

There are positional parameters in the URL list in asm policy when the policy is created with swagger file, and the * is not an indication of wildcard URL, but global positional parameter. When we put the mouse near the green box, we can see the parameter name.

Environment

  • BIG-IP ASM

  • swagger file

Cause

This is expected when the 'isinNumber' or any other positional parameter is defied in location "path" in the swagger file, which from ASM side is called "positional parameter".

Positional parameters are only global when this article is written, so location=path will be available for global parameters only.

    "/tr/assets/{isinNumber}/series": {
      "get": {
        "parameters": [
          {
            "name": "isinNumber",
            "in": "path",                            <<<<<<<<<
            "required": true,
            "type": "string",
          },

 Recommended Actions

OpenAPI 3.0 distinguishes between the following parameter types based on the parameter location. The location is determined by the parameter’s 'in' key, for example, in: query or in: path.

-path parameters
-query parameters
-header parameters
-cookie parameters

If you don't want positional parameters, please modify the swagger file to use other parameter location.
