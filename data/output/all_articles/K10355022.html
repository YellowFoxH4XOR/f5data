K10355022: Is there a limit to the number of microservices per policy in ASM/Advanced WAF?

Status

Applies to

Source

Description

Is there a limit to the number of microservices you can configure in any single policy on ASM/Advanced WAF?  Is there a cap on the total number of microservices on the entire system?

Environment

  • Running Advanced Web Application Firewall or ASM version 15 or newer

Cause

NA

Recommended Actions

None

Additional Information

There is no hard limit on the number of microservices either per Big-IP or per policy.  Memory use may become a concern as the number of objects gets very high, however.
