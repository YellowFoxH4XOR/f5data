Important:To implement this procedure, you must have a backup copy of your existing BIG-IP configuration file. (For information about restoring a BIG-IP configuration from backup, refer to K2250:

    Overview of UCS archives). If you do not have a backup file, you must configure the new system from scratch.

    To replace a failed BIG-IP system without interrupting service, perform the following steps:

    1. If the failed BIG-IP system is powered on and running, type the following command:

      halt

      If the BIG-IP system is powered on, but you cannot access the command line, turn the power off.

    2. Disconnect all the cables and set the BIG-IP aside to return to F5 Networks.
    3. Install the replacement BIG-IP system in the previous unit's place.
    4. Connect the cables to the replacement BIG-IP system in the following order:
      1. Failover cable
      2. Network cables
      3. Power cable

      Important: If you are using serial failover as the failover mechanism, you must connect the failover cable to the failover port on the replacement unit. If the failover cable is not connected properly, the replacement unit will not detect the peer BIG-IP Controller and it will attempt to become the active unit. This will disrupt traffic.

    5. Power on the replacement BIG-IP system.
    6. Log in to the replacement BIG-IP and run the config utility.
    7. Upload the backup UCS file to the replacement BIG-IP.
    8. Issue the following command to install the UCS file:

      bigpipe config install <UCS_filename>

      Note: For specific instructions, refer to K2250: Overview of UCS archives.

    The replacement BIG-IP should now have an identical configuration of the failed unit and is ready for service.
