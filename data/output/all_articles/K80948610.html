K80948610: Unable to modify or create user WEBUI account in SDC 5.x

Type
Support Solution
Published
2020-04-02
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K80948610

Description
Modification or creation of new user account via administration page is not successful.

Environment

  • SDC 5.x
  • GUI / WEBUI
  • Create or Update User Account

Cause
User account creation fails when Webui configuration file is corrupted. 

Recommended Actions

  1. Access SSH or CLI

  2. Navigate to passwordPreferences location
    #cd /data/backup/passwordPreferences/ALL

  3. Navigate to the most recent epoch folder 
    #cd 1577323939567
    Note: Linux command ls -l displays the timestamp of the folder 

  4. View the password properties by running the cat command ans ensure the listed properties are intact in the file.
    #cat password_preferences.properties

    The output of the file looks similar to: 
    #Mon Nov 26 17:13:25 SGT 2018
    minuppercarse=2
    minpasswordlength=8
    mindigits=2
    passwordexpiration=180
    autounlockaccountafter=null

    accountlockoutthreshhold=5
    minlowercase=2
    maxpasswordlength=20
    autounlockaccount=false
    warningexpiration=7
    accountlockouttime=20
    enforcehistory=7

  5. Login to WebUI

  6. Navigate to  WEBUI >> ADMINISTRATION >> USER MANAGEMENT >> PREFERENCES

  7. update preference with previous password_preference setting from step 4

  8. Submit

  9. After restoring the file, new user accounts can be added.
