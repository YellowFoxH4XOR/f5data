K05411532: The BIG-IP system fails to rewrite the SNI host name to the server name specified in the Server SSL profile

Known Issue

The BIG-IP system fails to rewrite the Server Name Indication (SNI) host name that is specified in the client request to the server name specified in the Server SSL profile.

This issue occurs when all of the following conditions are met:

  • The client sends a ClientHello message with a specific SNI host name, such as servername-1.
  • The Server SSL profile is configured with a different SNI host name than the client provided, such as servername-2.

Impact

The client is unable to establish a Secure Sockets Layer (SSL) connection.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The server-side connection does not use the SNI host name that is configured in the Server SSL profile.
