Known Issue

You may be unable to use the BIG-IP Configuration utility to import BIG-IP ISO images.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is provisioned with only the BIG-IP AFM module running on any of the affected versions.
  • The user attempts to import a BIG-IP ISO image using the Import button on the Configuration utility page System > Software Management > Image List.

Impact

You are unable to import the BIG-IP ISO image file into the system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you click the Import button on the Configuration utility, you see a blank sub-page from the import action, instead of getting the page where you can choose a file to import.

Resolution

Status

Workaround

To work around this issue, you can import the BIG-IP ISO image using an alternative method to transfer files into the BIG-IP system's /shared/images folder. For more information, refer to K175: Transferring files to or from an F5 system.
