Known Issue

Editing a portal access resource that was created using the Portal Access Setup wizard fails.

This issue occurs when the following condition is met:

  • Attempting to edit a portal access resource that was created with the Portal Access Setup wizard

Impact

You are unable to update a portal access resource.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You receive the following error message when clicking the portal access resource:

    An error has occurred while trying to process your request.

Workaround

To work around this issue, you can make a change to localization customization. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Customization.
  4. Click the Localization tab.
  5. Click the name of the portal access resource that is generating the error message.
  6. Type a description in the Description text box.
  7. Press the Enter key.
  8. Click the Save button.
