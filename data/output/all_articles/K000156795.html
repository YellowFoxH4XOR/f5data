K000156795: rSeries tenant deployment remains in pending state when allocating maximum available memory: "Insufficient memory on node, retrying tenant deployment"

Source

Description

After rebooting an rSeries appliance, a tenant that is allocated the maximum available memory is unable to deploy:

Insufficient memory on node, retrying tenant deployment

Environment

  • r10000 appliance
  • After a reboot

Cause

  • Bug ID2053301

This issue occurs rarely after appliance reboot, and prevents tenants from being deployed due to insufficient available hugepages.

Recommended Actions

You can verify if the issue is present with the following command:

lsof -p $(pidof fpgamgr) | grep 'DEL.*huge'

For example:

[root@appliance-1(R10900):Active] ~ # lsof -p $(pidof fpgamgr) | grep 'DEL.*huge'
fpgamgr 12918 root DEL REG 0,40 314814 /var/huge_pages/2048kB/l2_learn/l2_learn.seg

If the command returns nothing, the issue is not present.

To clear the issue, if present, restart the system_fpga container:

docker container restart system_fpga
