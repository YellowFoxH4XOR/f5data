Description
A connection or session mirroring does not work with BIG-IP VE running on AWS, Azure, and other cloud-based platforms.

Environment

  • You are using BIG-IP VE running on AWS, Azure, and other cloud-based platforms.
  • You configure a HA.

Cause
This is by design. The failover via API takes longer than typical TCP connection timeouts.

Recommended Actions
We don't recommend using a connection or session mirroring with BIG-IP VE running on AWS, Azure, and other cloud-based platforms.
