Description

What factors do I need to take into consideration when performing a test attack against WAAP?

Environment

  • F5® Distributed Cloud Load Balancer

Resolution/Answer

While performing a test attack, IP of the attacking machine might get denylisted if IP reputation is enabled on the Loadbalancer. Some common things to consider are:

  • Before performing a volumetric DDoS test attacks, F5 XC support needs to be informed (Limit of the attack threshold needs to be added)
  • To remove the IP of the attacking machine from getting denylisted, disable IP reputation from the loadbalancer.
  • IP reputation database is sourced from a third party vendor BrightCloud.
