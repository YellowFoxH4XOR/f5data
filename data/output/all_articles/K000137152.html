K000137152: Violation Rating Based Enforcement

Type
Support Solution
Published
2023-10-06
Updated
2023-10-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.X, 17.1.0
Source
https://my.f5.com/manage/s/article/K000137152

Description

Two new built-in violations corresponding to the existing violation rating levels have been introduced in BIG-IP ASM version 17.1.0.

These violations are Request is likely a threat and Request needs further examination.

Both violations work on the existing request violation rating levels and give an administrators a possibility to block requests with violation that have a high rating but letting low rating violations pass through.

You can find the full list of violations and detailed description of each under Security > Options > Application Security > Advanced Configuration > Violations List.

Environment

  • BIG-IP ASM or Advanced WAF running v17.1.0 and above

Cause

None

Recommended Actions

To use these violations in proper way, it is important to understand the concept of violation rating.

Each transaction with one or more violations has a violation rating associated with it. The violation rating ranks the transaction from 1 to 5, where 5 indicates the highest probability of a real attack with high severity. The system assigns the violation rating by assessing the combination of violations occurring in a transaction. The violation rating is assigned to the transaction as a whole rather than the individual violations in the request. This is because real attacks often include multiple violations within one transaction. The violation rating takes into consideration the impact of the violations on the business.

Requests with high violation ratings are likely to be real attacks, and you can review them to analyze threats to your web applications. You can filter the requests in the Requests list to focus on the high-rated illegal requests with ratings of 4 or 5.

The new violation Request is likely a threat, whenever enabled (block or alarm flag turned on under Learning and Blocking settings) will block/alarm all requests with violation rating 4 and 5, while violation Request requires further examination will block/alarm violation with rating 3.

Additional Information

Although it is possible to turn on block flag for violation Request requires further examination but turn it off for Request is likely a threat, this configuration makes no sense and should be avoided because it will block requests with violation rating 3 but not those with higher rating.
