Description

  • /var partition 100% used
  • /var filling up from ASM sync-related files
  • The following error message is logged on asm_config_server.log 
    var/log/ts/asm_config_server.log:asm_config_server.pl|ERR|May 05 03:59:30.128|14856|F5::ASMConfig::Handler::SyncHandler::sync_ucs_file_complete,,Could not load configuration while in sync recovery state: DBD::mysql::db do failed: Error dropping database (can't rmdir './DCC_ucs', errno: 39) at /usr/local/share/perl5/F5/ConfigSync.pm line 1922. var/log/ts/asm_config_server.log:asm_config_server.pl|ERR|May 05 04:00:30.191|14856|F5::ASMConfig::Handler::spawn_relay_handler,,Sync recovery state timed out. State may be inconsistent with other peers

Environment

  • HA pair
  • ASM provisioned

Cause

Seen behavior is caused by a known issue tracked with the bug ID 838269

Recommended Actions

No fix available at the time of creation of this article. As a workaround we advise to reinstall the device from scratch and load the saved configuration.
