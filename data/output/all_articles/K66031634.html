Topic

This article describes the list of BIG-IP LTM features and profiles that you can configure when you use only the BIG-IP APM license and module on your system.

Description

Appearance in the list of features in the following table is not an indication of a supported or compatible configuration. For example, a BIG-IP APM Access profile requires an HTTP profile, and the HTTP profile is mutually exclusive to the following profiles:

GTP, FTP, TFTP, RTSP, SOCKS, SMTPS, POP3, Client LDAP, Server LDAP, SMTP, IMAP, DNS, Diameter, SIP, MQTT, Radius, IPsecALG, PPTP, FIX, Netflow, Client LDAP, and Server LDAP

As a result, when you configure the HTTP profile with a DNS or FTP profile for instance, you may observe an error similar to the following:

01070734:3: Configuration error: Virtual server (/Common/example_vs): Profiles SIP/SIPSESSION/IIOP/RTSP/HTTP/MQTT/MQTTSESSION/DIAMETER/DIAMETERSESSION/RADIUS/FTP/TFTP/IPsecALG/DNS/PPTP/FIX/NETFLOW/SMTPS/CLIENTLDAP/SERVERLDAP are mutually exclusive.

For more information, refer to K93017176: Overview of the Standard virtual server.
