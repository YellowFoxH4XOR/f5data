Description

  • Does F5® Distributed Cloud Primary DNS work with ALIAS records?
  • How is F5 Distributed Cloud Primary DNS using ALIAS records?

Environment

  • F5® Distributed Cloud Primary DNS

Answer

  • An ALIAS record is a special non-RFC DNS record type used by the F5 Distributed Cloud Primary DNS service to implement a CNAME-like record at a domain's apex. 
    It is often called "CNAME flattening".
  • A common use-case is to have a website's content hosted with a third party.
  • Rather than providing an IP address, the third-party provider will provide a target domain name (e.g., sitea-axkney.thirdparty.com) for an administrator to alias in their domain. 
  • The challenge occurs when the organization wants to use the provided hostname at the root or apex of their domain (e.g., example.com).
  • The DNS specification states that CNAME records can only rewrite one name in a zone to another name.
  • In this case, using a CNAME record at the root/apex level will not function correctly because the domain's NS, SOA, and MX records will also need to exist at that same name. 
  • ALIAS records solve by implementing RFC-like CNAME compliance by resolving the defined hostname to one or more A records at resolution time.
    • For example, when using the following ALIAS record:  
           example.com. 300 IN ALIAS sitea-axkney.thirdparty.com
    • When a client sends a query to resolve example.com, the Distributed Cloud DNS service will return one or more A records values for sitea-axkney.thirdparty.com.
