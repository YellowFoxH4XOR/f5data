K000163085: Direct Tenant-to-Tenant Management Connectivity on the Same VELOS Chassis

Type
Support Solution
Published
2026-08-25
Updated
2026-08-25
Source
https://my.f5.com/manage/s/article/K000163085

Description

Direct communication between tenant out-of-band management interfaces on the same VELOS chassis is unsupported. Connectivity works only when traffic is routed through an external management gateway.

Environment

  • F5OS on a VELOS chassis
  • Multiple tenants hosted on the same chassis
  • Tenant management interfaces connected to the same management network
  • Static management routes configured through an external management gateway

Cause

F5OS isolates tenant management traffic within the VELOS chassis as a security feature. Direct communication between tenant out-of-band management interfaces on the same chassis is therefore not supported.

Resolution

  1. When management-plane connectivity is required, configure static management routes through the external management gateway.
  2. For tenant-to-tenant communication, use appropriately configured data-plane VLANs and self IP addresses instead of management interfaces.
  3. For tenant high availability or device service clustering designs, place peer tenants on separate VELOS chassis where possible.
  4. Do not attempt to enable direct same-chassis tenant management connectivity because no supported F5OS configuration is available for this purpose.

Additional Information

Routing traffic through an external management gateway is a workaround and does not indicate that direct same-chassis tenant management connectivity is supported.
