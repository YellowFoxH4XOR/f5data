Known Issue

The BIG-IP system may set the Host Name option to localhost in DHCPDISCOVER packets.

This issue occurs when all of the following conditions are met:

  • The management port is configured to automatically obtain an IP address using Dynamic Host Configuration Protocol (DHCP).
  • The system starts after a reboot.

Impact

This issue may affect DNS resolution if the DHCP server is configured to dynamically update the DNS entries based on the Host Name option in the DHCP lease.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Packet captures indicate that the Host Name option in the DHCPDISCOVER packet is set to localhost as shown in the following example:

Workaround

To work around this issue, you can remove the contents of the /var/lib/dhclient/dhclient.leases file and restart the dhclient service. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Empty the contents of the /var/lib/dhclient/dhclient.leases file by typing the following command:

    cat /dev/null > /var/lib/dhclient/dhclient.leases

  3. Restart the dhclient service by typing the following command:

    bigstart restart dhclient
