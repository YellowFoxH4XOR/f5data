Description

You have configured remote authentication (Active Directory or LDAP) for BIG-IP GUI (administrative access) and configured Remote Role Groups with correct Attribute String for the remote group.
However, the login to BIG-IP GUI fails with the remote group.

Environment

  • Configured remote authentication (AD or LDAP) under System > Users > Authentication for BIG-IP administrative access
  • Configured Remote Role Groups with Attribute String for the remote group membership that is configured as a nested group on your remote Active Directory or LDAP
    Note: A nested group is created when adding one group to a different group, and a user in the first group is not directly assigned to the new group

Cause

BIG-IP currently does not support nested groups in Remote Role Groups configuration under System > Users > Remote Groups when configuring remote authentication for BIG-IP administrative access

Note:  This is different from configuring nested groups in Access Policy in APM when configuring AAA server for authenticating users going through APM profile.  With Fetch Nested Groups setting in APM policy, nested groups is supported in APM.

Recommended Actions

Avoid using nested groups in AD/LDAP when configuring remote authentication to BIG-IP device
