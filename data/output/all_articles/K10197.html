Known Issue

This is the result of a known issue. If you install cumulative HF-603-2.1 or HF-603-3 on the FirePass controller, Passive FTP no longer works through Static Application Tunnels.

Note: For additional troubleshooting steps, refer to K193: An FTP session may fail after initial connection.

F5 Networks Product Development tracked this issue as CR122966 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-4 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
