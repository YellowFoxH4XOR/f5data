K000158172: BIG-IQ AFM Import Fails with "Missing/empty parameter: partition" When Automap Source Translation is used on a NAT Policy

Type
Support Solution
Published
2025-12-11
Updated
2025-12-11
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.4.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000158172

Description

When importing AFM (Advanced Firewall Manager) services from BIG-IP devices into BIG-IQ, the import or discovery process fails if any NAT policy rules use "automap" for source translation. The following error is observed in BIG-IQ restjavad logs:

Error while transforming NAT Policy Rule: <rule_name> in <policy_name>: java.lang.IllegalArgumentException: Missing/empty parameter: partition

This prevents successful import and management of AFM NAT policies containing automap source translation.

Environment

  • BIG-IQ versions: 8.3.0, 8.4.0
  • BIG-IP AFM module version: 16.1.x and above
  • Configuration objects:
    • NAT policies using "automap" as source translation
    • Security nat source-translation objects (for workaround)

Cause

BIG-IQ (up to v8.4.0) is yet to support the Automap FWNAT feature. This is being tracked via Bug ID 1103613.

Recommended Actions

  1. On the BIG-IP AFM device, create a "security nat source-translation" object with the required settings.
  2. Update affected NAT policy rules to reference this object instead of using "automap" for source translation.
  3. Retry discovery and import of AFM services into BIG-IQ.

Additional Information

  • This limitation is present in both BIG-IQ v8.3.x and v8.4.x.
  • Automap inf FWNAT was introduced starting BIG-IP AFM v16.1.0 but is not currently supported for AFM NAT policy import in BIG-IQ.
