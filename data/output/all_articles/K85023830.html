Known Issue

The BIG-IP Edge Client fails to notify the user that interaction is required.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a network access profile.
  • A user attempts to connect to the access profile using the BIG-IP Edge Client.
  • The BIG-IP Edge Client is in the minimized tray state.
  • The BIG-IP Edge Client encounters a session-related item that requires interaction from the user.

Impact

The Edge Client does not notify the user of the requirement.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • While the BIG-IP Edge Client is in the minimized tray state, user interaction notices, such as credential requests, do not display.

Workaround

To work around this issue, you can modify the login.inc advanced customization file of the affected access profile access policy. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Profiles/Polies > Customization > Advanced.
  3. Expand the Access Profiles section.
  4. Select the affected access profile.
  5. Expand the Access Policy section.
  6. Expand the affected access profile Logon Pages section.
  7. Expand the Logon Page section.
  8. Click logon.inc.
  9. Locate the following line of code:

    externalWebHost.webLogonNotifyUser();
     
  10. Replace the line with the following code:

    externalWebHost.WebLogonNotifyUser();

    Note: The replacement code has an uppercase W in the .WebLogonNotifyUser section instead of the lowercase w in the original section.
     
  11. In the upper-right corner of the code editor, click Save Draft.
  12. In the Do you want to save your changes? window, click Yes.
  13. In the upper-left corner of the editor, click Save.
  14. In the upper-left corner of the Configuration utility, click Apply Access Policy.
  15. Click Apply Access Policy.
