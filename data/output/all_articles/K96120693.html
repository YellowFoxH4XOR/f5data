Description

For the purposes of continuity in this documentation, Secure Web Gateway SWG should be understood as the following:

  1. SWG is licensed and provisioned. (Currently either APM or SSLO must be paired with it to create a Per-Request Policy.)
  2. Category Lookup is available for use, either with full URI lookup (in the case of APM being licensed) or hostname only lookup (in the case of SSLO being licensed).
  3. Request or Response Analytics is available for use.

    The difference between URLDB and SWG (provisioning modes) is solely in which database is downloaded from Forcepoint (previously known as Websense). With SWG, the full database will be loaded and indexed. With URLDB, only the hostname database will be loaded - this allows for a smaller memory footprint on the box, but means that lookups of full URIs will be slower. TMM interacts with the categorization databases via a linux daemon called urldb, which implements the TMM plugin interface (MPI Plugin). 

    The difference between URLF and SWG (licensing modes) is what is allowed to be looked up based on our legal restrictions with Forcepoint.


Environment

  • BIG-IP APM or SSLo
  • Secure Web Gateway


Cause

    We use session tracking to track SWG uses through APM sessions. This means two things:

    1. To use SWG, you must have an APM session.
    2. SWG sessions are tied to APM sessions - therefore an SWG session does not "expire" until the main APM session expires.

      URLF licenses do not require an APM session, but are limited in what is available for use:

      1. APM+URLF allows more privileges than SSLO+URLF.
      2. URLF licensing does NOT include content analytics.


      Recommended Actions

        When we reach the Allow Ending in the Per-Request Policy, we check to see which license was consumed. The license type is then "attached" to the APM session.
        There is currently no way to disassociate the license from that APM session, which means that the license will only be freed when the APM session is deleted or expires due to timeout
