Description

Following error message might be seen in log file /var/log/ltm when DNS cache resolver is used: 

tmm[<pid>]: DNScache: comm_point_tmm_recv_from failed: errno 103

Environment

  • BIG-IP LTM and/or BIG-IP DNS
  • Virtual server or DNS Listener
  • DNS profile
  • DNS cache resolver profile

Cause

These errors do not indicate a problem on the BIG-IP. And error code 103 means:
BIG-IP can not receive response, a connection expired, a connection aborted, or socket/data was unable to be read.

Recommended Actions

When this message occurs, you should check connectivity between the BIG-IP system and configured DNS resolvers. 
For example, by taking all DNS traffic dump on BIG-IP and stop the capture once you see the error is logged.
