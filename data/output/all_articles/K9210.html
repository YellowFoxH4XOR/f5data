Known Issue

This is the result of a known issue. A FastL4 virtual server connection may be closed by a TCP RST packet with an invalid sequence number. The BIG-IP system closes the connection when a FastL4 virtual server receives a RST packet with a sequence number outside the receive window.

RFC793 states that with the exception of the SYN-SENT state, a reset is valid if its sequence number falls within the receive window.

F5 Product Development is tracking this issue as CR102558.

This issue does not affect the 9.4.x or later software branches. For information about upgrading, refer to the BIG-IP LTM release notes.
