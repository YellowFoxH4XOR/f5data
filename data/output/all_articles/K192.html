CPU Speed and Memory

To view the CPU speed and the amount of real and available memory, type the following command:

cat /var/db/dmesg.boot

To view only the CPU speed and the amount of real memory, type the following command:

egrep 'real|CPU' /var/db/dmesg.boot

If these commands do not display the amount of available memory, type the following command:

sysctl -a | grep mem

Note: The sysctl -a | grep mem command provides only the available memory, not the CPU speed. If, at this point, you wish to view the CPU speed, you will need to reboot the system. The CPU speed is displayed upon boot up.

Available Disk Space

To view the amount of available disk space, type the following command:

df

The Avail column lists available hard-drive space in 1024 byte blocks (1KB).
