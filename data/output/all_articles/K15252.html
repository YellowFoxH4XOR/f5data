Known Issue

The BIG-IP APM system may experience Traffic Management Microkernel (TMM) memory exhaustion.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for Network Access.
  • The access policy contains an L7 ACL that is configured to reject access to an internal resource.

Impact

BIG-IP APM system memory usage increases over time, which may eventually cause a decrease in performance or a system reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425809 on the Diagnostics > Identified > Medium|High screen.
  • TMM memory utilization continually grows in performance graphs.
  • The BIG-IP APM system experiences performance degradation over time.
  • The BIG-IP APM system reboots and/or fails over to another device if configured for high availability.
  • The TMM process generates a core file in the /shared/core directory.
  • In the /var/log/ltm file, you observe error messages similar to the following example:

    011e0002:4: sweeper_update: aggressive mode activated.
