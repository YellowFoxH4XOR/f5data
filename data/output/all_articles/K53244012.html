K53244012: CPU use at 100% with high number of SSL connections impacting system

Type
Knowledge
Published
2023-03-22
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K53244012

Description

Excessive SSL connections cause an outage as CPU reaches 100%. Unusually high throughput is observed together with high SSL TPS and high connection count.

Environment

  • Standard virtual server
  • ClientSSL profile
  • Higher than usual throughput and SSL TPS

Cause

Even when hardware-accelerated, SSL handshakes (which count as transactions for the purpose of TPS) have higher CPU cost than bulk throughput. Additionally, throughput and connections per second are strong drivers of CPU use - creating a new connection is relatively expensive, and TMM uses CPU to move packets. The number of concurrent connections is not a significant driver of CPU.

Recommended Actions

  • Implement rate limits to help limit CPU use.
  • If you believe the traffic may be an attack, contact F5 Support to engage the Security Incident Response Team.
  • If you have:
    • BIG-IP Virtual Edition or a vCMP guest, consider adding more cores. This may require a license upgrade for VE.
    • A license-limited BIG-IP hardware platform, consider purchasing a performance upgrade license.
