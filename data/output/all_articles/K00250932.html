Description

Application functionality is impacted. After enabling the tm.rstcause.log database variable, you observe messages similar to the following in /var/log/ltm:

err tmm[23327]: 01230140:3: RST sent from 10.10.30.8:443 to 10.10.30.172:62905, [0x2b16dd4:1148] {peer} Internal error (ASM requested abort (payload release error))

Environment

  • Security policy
  • Data Guard enabled
  • Already have fix for bug ID 910253

Cause

Bug ID 981069: Reset cause: "Internal error (ASM requested abort (payload release error))"

Recommended Actions

You may disable Data Guard to work around the issue.

Alternatively, open a Service Request with F5 Support referencing this article, and request an Engineering Hotfix.

In the long-term, upgrade to a version where Bug ID 981069 is fixed.

Additional Information

The resets occur when the BIG-IP receives the server-side HTTP response.
