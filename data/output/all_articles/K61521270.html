Known Issue

The find-activate.pl script may enter an infinite loop when it receives an ICMP UDP port 53 unreachable message.

This issue occurs when the following condition is met:

  • The find-activate.pl script receives an ICMP UDP port 53 unreachable message when trying to resolve the root nameserver.

Impact

The BIG-IP system may eventually encounter an out-of-memory condition.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/kern.log file, you observe an error message similar to the following example:

    err kernel: Out of memory: Kill process 4444 (find-activate.pl) score 68 or sacrifice child

  • You notice that the resident memory (RSS column) for the find-activate process continues to increase over time, similar to the following example output from the ps aux | grep -e find -e USER command:

    USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
    root 4444 92.3 16.7 690204 681504 pts/0 R 13:14 4:17 /usr/bin/perl /usr/local/bin/find-activate.pl -l callhome.f5.com
    root 4444 92.4 16.8 692576 684032 pts/0 R 13:14 4:18 /usr/bin/perl /usr/local/bin/find-activate.pl -l callhome.f5.com
    root 4444 92.3 16.8 694416 685920 pts/0 R 13:14 4:19 /usr/bin/perl /usr/local/bin/find-activate.pl -l callhome.f5.com

  • Your BIG-IP system repeatedly sends queries for NS records in the root zone.
