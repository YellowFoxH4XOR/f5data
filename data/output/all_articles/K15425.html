Known Issue

The Traffic Management Microkernel (TMM) may produce a core file when the BIG-IP AAM system attempts to provide stand-in content from the cache.

This issue occurs when the following conditions are met:

  • You have configured a stand-in period for the acceleration policy.
  • You have enabled HTTP request queuing in the acceleration policy.
  • BIG-IP AAM evicts a document from the cache due to writing errors.

Impact

The TMM process may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H457547 on the Diagnostics > Identified > High screen.
  • The BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
  • The BIG-IP system temporarily fails to process traffic.

Workaround

There is no workaround for this issue. However, it is possible to mitigate this issue by disabling stand-in or HTTP request queuing for the acceleration policy.
