Description
Log messages similr to the following are logged to /var/log/apm:
01490511:5: /Common:00000000: Initializing Access profile <Access Profile Name> with max concurrent user sessions limit: 0

Environment

  • BIG-IP APM
  • BIG-IP APM license is installed, reactivated, or reloaded

Cause

The log message related number shows the Max Concurrent Users of the Access Profile.

Recommended Actions

The message is harmless. You can ignore the message safely.
