Topic

The primary ordering of FirePass resources on the webtop is by resource type. For example, Network Access resources are grouped together, Web Applications resources are grouped together, and Application Tunnels resources are grouped together. 

Note: You can only configure one Network Access resource for each resource group.
 
The secondary ordering of FirePass resources is the ordering of resources within each resource type. The order of resources within a resource type is configured in the FirePass Administrative Console. For example, navigate to the Users : Groups : Resource Groups page and click the Edit link under the Application access or Portal access column. The order of the resources displayed in the Administrative Console is the same order that is displayed on the webtop. You can change the ordering of the resources by clicking the up arrow icon or the down arrow icon to the right of the resource name.
 
If a user is assigned multiple resource groups, whether statically (for local user accounts) or dynamically through dynamic group mapping, FirePass displays the resources in the order in which they were assigned to the user. For example, if a user was assigned the Sales resource group followed by the Engineering resource group, the ordering of the resources would be as follows:
  • Sales resource group Network Access resource (if configured).
  • Engineering resource group Network Access resource (if configured).
  • Sales resource group Web Applications resources (if configured), displayed in the order they are configured in the FirePass Administrative Console.
  • Engineering resource group Web Applications resources (if configured), displayed in the order they are configured in the FirePass Administrative Console.
  • Sales resource group Application Tunnels resources (if configured), displayed in the order they are configured in the FirePass Administrative Console.
  • Engineering resource group Application Tunnels resources (if configured), displayed in the order they are configured in the FirePass Administrative Console.
 
To verify the order of the resource group assignment for a particular user, perform the following procedure:
 
  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Reports : Logons page.
  3. In the Logon column, click the logon name of the user.

    The Logon details are displayed.
  4. Next to Resource groups available for user, the order of assigned resource groups is displayed.

    For example:

    Sales_resources,Engineering_resources
 
Important: You cannot configure the order in which resource groups are assigned to a user.
