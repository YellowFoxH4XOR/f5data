Error Message

01070734:3: Configuration error: Found disallowed profile on <Virtual Server name>: Not HTTP Profile (Only on serverside)

In this error message, note the following:

  • <Virtual Server name> is the Virtual Server you are attempted to configure or update.

For example:

01070734:3 Configuration error: Found disallowed profile on /Common/test_vs:Not HTTP Profile (Only on serverside)

Message Location

You may encounter this message in the following locations:

  • The Configuration utility
  • The /var/log/tomcat/catalina.out file
  • The /var/log/webui.log file
  • The /var/log/ltm file
     
Description

This message occurs when all of the following conditions are met:

  • You attempt to configure a virtual server to use an "HTTP Profile (Server)"  that is different from the "HTTP Profile (Client)" side.
  • HTTP MRF Router is not enabled.

Impact

Fail to configure or update the virtual server.
 

Recommended Actions

You must leave the default setting "(Use Client Profile)" for the "HTTP Profile (Server)" unless you want to configure HTTP/2 full proxy by enabling HTTP MRF Router configuration under the Acceleration section.
