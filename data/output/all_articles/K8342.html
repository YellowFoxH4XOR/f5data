Known Issue

This is the result of a known issue. If a user attempts to install the FirePass SSL VPN client on a Korean Windows Mobile 5.0 device, the installation fails. This issue occurs because the SSL VPN client installer links to the English Program Files directory instead of the localized Korean directory.

F5 Networks Product Development tracked this issue as CR92013 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-2 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
