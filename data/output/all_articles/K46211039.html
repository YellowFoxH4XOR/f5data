Description

  • When trying to save your BIG-IP configuration from the Bash CLI or TMOS prompt the command never complete or errors out.
    • Example from Bash CLI:
      • [user@big-ip-A:Active:In Sync] config # tmsh save sys config
        • Nothing further appears after running the command and it's necessary to run Ctrl+C to stop the process
           
    • Example from the TMOS CLI:
      • root@(big-ip-A)(cfg-sync In Sync)(Active)(/Common)(tmos)# save sys config
      • The following error appears: 
        • Another save is in progress. You may use the option "wait"

Environment

  • Saving your BIG-IP configuration

Cause

Unknown at time of publication.

Recommended Actions

If you encounter any of the issues outline in the Details section, please follow steps to find and remove old save processes.  There are two command that need to run since there are two ways the BIG-IP software runs these save commands.

  1. Run this first command from the Bash CLI:
    1. ps auxww | grep 'save / sys config'
      • Example output:
        root 12345   6789   0.0 0.1 158.8M 75.2M ? S Jan 1   00:00:04.17 /usr/bin/tmsh -u save / sys config partitions all
         
    2. To remove this old save use the kill command on the PID of the process
      • In this example the PID is 12345
      • # kill -ABRT 12345
         
  2. Run this second command also from the Bash CLI:
    1. ps auxww | grep 'save sys'
      • Example output:
        root 23456  56789   0.0 0.1 136.1M 49.1M ? S Jan 1   00:00:00.11 /usr/bin/tmsh -f save sys config partitions all
         
    2. To remove this old save process, use the kill command on the PID of the process
      • In this example the PID is 23456
      • # kill -ABRT 23456
         
  3. Repeat steps 1 & 2 until no other save processes are present.
     
  4. Once all the save processes are removed, it's sometimes necessary to save a binary version of the configuration which is a significantly lighter-weight operation than saving the entire configuration.
    • # tmsh save sys config binary
      1. If this save without error, proceed to step 5.  
      2. However, if this fails for any reason, please review steps 1 & 2 to make sure all the errant save processes were removed.
         
  5. At this point, the configuration and processes should be ready for a new save command
    1. From bash CLI:
      1. # tmsh save sys config
    2. From tmos CLI:
      1. (tmos)# save sys config
         
  6. If these save commands continue to fail, please generate a fresh QKView and open a Support Case with F5 Network Support.
