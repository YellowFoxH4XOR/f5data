Description

Outbound NAT traffic not translated or forwarded

  • Traffic dropped if UDP
  • Resets received if traffic is TCP

Environment

  • Virtual server and NAT both matching traffic whose source is to be translated
  • NAT origins IP address is on the same vlan as the matching virtual server is listening on.
  • Sample configuration below where origins address is on vlan v-internal and  wildcard virtual also listens on vlan v-internal
ltm virtual allDestinations_vs {
    destination 0.0.0.0:any
    disabled
    mask any
    profiles {
        fastL4 { }
    }
    source 0.0.0.0/0
    source-address-translation {
        type automap
    }
    translate-address disabled
    translate-port disabled
    vlans {
        v-internal
    }
    vlans-enabled
    vs-index 3
}

ltm nat remoteOutbound_nat {
    inherited-traffic-group true
    originating-address 10.28.37.81
    traffic-group traffic-group-1
    translation-address 10.178.170.90
}

net self 10.28.37.94 {
    address 10.28.37.94/28
    traffic-group traffic-group-local-only
    vlan v-internal
}

Cause

A matching virtual server for the destination translated source traffic always takes precedence. 
This is for outbound NAT traffic.

Recommended Actions

The are two ways to resolve the issue and only one solution should be applied.

  • Configure a separate virtual server to handle traffic from the origin address for example if all traffic from the origin is to be translated
ltm virtual allNAT-dst_vs {
    destination 0.0.0.0:any
    ip-forward
    mask any
    profiles {
        fastL4 { }
    }
    source 10.28.37.81/32
    translate-address disabled
    translate-port disabled
    vlans {
        v-internal
    }
    vlans-enabled
    vs-index 20
}
  • Configure a separated specific destination if traffic is to be translated only if destined for a specific destination.
ltm virtual remoteNAT-dst_vs {
    destination 10.178.170.81:any
    ip-forward
    mask 255.255.255.255
    profiles {
        fastL4 { }
    }
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
    vlans {
        v-internal
    }
    vlans-enabled
    vs-index 21
}
