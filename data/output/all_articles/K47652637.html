Description

If you have been asked to supply historic license usage data by the Customer Success Manager (CSM) the instructions below will help you step through and collect it. 

Environment

  • FCP (flexible consumption program)
  • Need to collect historic License usage data

Cause

If you are not able to automatically share your usage data, so need to collect it manually, or if some data has been missed, this process will help ensure we have a complete set of usage data and allow us to share accurate billing reports with you.

Recommended Actions



Important: There are separate procedures below for BIG-IQ 6.x and 7.x (and later).

BIG-IQ 8.x and later

  1. From the BIG-IQ WebUI: Devices tab > License Management > Reports > Generate
  2. Choose Historic report
  3. Move the relevant licenses from Available to Selected
  4. Choose JSON as format
  5. Choose whether to obfuscate data or not
  6. Set the date range
  7. Click on Download
  8. Send the file to vesubscriptions@f5.com. Note: Don't zip or compress the file. Ensure the file is lower case "file.json" as capital "file.JSON" will not get processed.
