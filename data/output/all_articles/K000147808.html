Description

You want to know how to find correct API Groups for a specific API operation so you can use this API group to create a custom role for a user.

Environment

  • Access to F5® Distributed Cloud Console

Cause

  • None

Answer/Recommended Actions

This is an advanced topic and we assume you understand the general role-based access control (RBAC) structure for F5® Distributed Cloud Console

 

To find correct API group for specific API operation:

1. Open developer mode (Inspect) of your browser

2. Go to Network to check all API calls

3. Navigate to General -> IAM -> API Groups 

4. Click a number for Elements (any one is fine)

5. Copy the response of two API calls into json files 

  • api_groups? -> 02 api_groups.json
  • api_group_elements? -> 01 api_group_elements.json

6. Find the API calls for the operation. In this example, we are looking for how to download local-Kubeconfig

        • Here we can see the API for download local-kubeconfig is using POST and the path is
          • /api/config/namespaces/system/sites/shali-c35/local-kubeconfig

7. On the file 01 api_group_elements.json, search for the keyword and look for its element

  • For this example, we search local-kubeconfig, we can find the element name is ves-io-schema-site-configkubeconfigapi-createlocalkubeconfig-0

8. Search on the file api_groups.json for the element name from step 7

Additional Information

  • To simply describe the structure on RBAC for Distributed Cloud Console, we have
    • User <-- Role <--API Group <-- Elements
