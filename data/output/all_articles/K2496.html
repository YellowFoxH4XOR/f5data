K2496: Reasons why you may receive a ''no route to host'' error when loading a configuration from the command line

Topic

When you load a configuration using the command line, you may receive the following error:

no route to host

This error generally occurs when you attempt to load a configuration that contains nodes for which BIG-IP does not have a valid route. In versions prior to 4.0, there were a number of files in which users commonly stored static routes. Some of these files, such as /etc/rc.local, are not appropriate for loading static routes, since they are loaded after the bigip.conf file in versions 4.0 and later.

Important: When you receive this error, it also indicates that BIG-IP stopped loading the configuration when the error occurred. As a result, the BIG-IP is probably running with a partial configuration.

You must configure static routes on BIG-IP before you load the bigip.conf file. You must use a means of stopping static routes or risk encountering this problem.

Note: You can view the static routes, using netstat. Although routes added after you loaded bigip.conf file appear in the table, they will not work correctly.

For information about how to add static routes and correct this issue, refer to the following version-specific Solutions:

  • For BIG-IP versions 4.5.11 through 4.6.4, refer to K3687: Managing static routes.
  • For BIG-IP versions 4.0 through 4.5.10 and 4.6 through 4.6.2, refer to K2317: Managing static routes.
