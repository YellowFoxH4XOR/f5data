Description

Configsync fails and an error message similar to the below is logged in both the Configuration Utility and in the LTM logs:

Feb  8 13:00:12 bigip01 err mcpd[5920]: 01070712:3: Caught configuration exception (0), Values (<afm_policy>) specified for firewall global rule container (/Common/global-firewall-rules): foreign key index (fw_enforced_policy_FK) do not point at an item that exists in the database..

In this error message, note the following:

    <afm_policy> is the name of the affected AFM policy.

Environment

  • BIG-IP AFM

Cause

Bug ID 679722: Configuration sync failure involving self IP references fixed in 14.0.0, 13.1.3.2

Recommended Actions

1. upgrade to a a later version that contains the fix for the said bug.
2. if you're not able to upgrade just yet, you can workaround the issue by removing/disabling the AFM policy that is attached to the self IP/s in question. and then do a configsync
