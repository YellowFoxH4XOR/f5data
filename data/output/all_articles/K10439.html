Known Issue

This is the result of a known issue. Using an Enterprise Manager version 1.8 or 2.0 system to license an unlicensed BIG-IP 10.0.1 system fails when the unlicensed BIG-IP 10.0.1 systems returns a blank entry for the registration key.

F5 Product Development tracked this issue as CR125149 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

Workaround

If you are unable to apply the hotfix, you can avoid this issue by licensing the BIG-IP version 10.0.1 system before attempting to manage the system using Enterprise Manager version 1.8.0 or 2.0.0.
