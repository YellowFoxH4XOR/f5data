Description

Declarative Onboarding (DO) schema files are required for validating DO declarations and enabling features such as autocompletion in editors like VSCode. The GitHub repository for DO schemas is no longer updated, so the recommended and supported method to obtain the latest DO schema files is through the MyF5 Downloads portal.

Environment

  • Product: Declarative Onboarding (DO)
  • Platform: BIG-IP (all platforms supporting DO)
  • Tools: VSCode, schema validation tools
  • Source: MyF5 Downloads portal

Cause

The GitHub repository for DO schemas is no longer maintained or updated. The official and up-to-date schema files are now distributed exclusively via the MyF5 Downloads portal as part of the DO RPM package.

Answer/Recommended Actions

  1. Log in to MyF5 Downloads
    • Go to Downloads | MyF5.
    • Log in with your MyF5 credentials.
  2. Select the DO Product Family
    • On the Downloads page, select the product family: DO (Declarative Onboarding).
  3. Download the Latest DO RPM
    • Locate and download the latest available DO RPM package (e.g., f5-declarative-onboarding-1.49.0-14.noarch.rpm).
  4. Extract the Schema Files
    • After downloading, extract the RPM package.
    • The schema files are located at:
    /var/config/rest/iapps/f5-declarative-onboarding/schema/latest
    • These files are the official and up-to-date DO schemas for use in your development environment or for schema validation.

Additional Information

  • The GitHub repository for DO schemas is no longer updated. The MyF5 Downloads portal is now the authoritative source for the latest schema files.
