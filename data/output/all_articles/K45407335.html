K45407335: IP Allow List in DOS Protection Profile is still mitigated

Description

IP address in the DOS Protection profile's Allow List is still being mitigated. 

The configuration from the /config/bigip.conf appears as:

net address-list /Common/IP_Exception {
    addresses {
        10.1.1.1 { }
        }
    description 10.1.1.1
}

Environment

  • Traffic is dropped

Cause

The Compatibility level of the system is set to Level 0.

Note: To check the compatibility level of the system, browser to Advanced Menu at System > Configuration > Device > General

In the whitelist configuration, only the IP address is defined. This configuration will only apply if the Compatibility Level is 1 or 2.

Recommended Actions

For all compatibility level which includes 0, a Rich Allow List must be created where the following must be configured:
  • Name
  • Source VLAN
  • Source or Destination address
  • Port
  • Protocol
