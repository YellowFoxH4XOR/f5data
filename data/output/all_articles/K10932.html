Topic

In BIG-IP 9.x, the BIG-IP system always considers a disabled monitor instance as UP for the purposes of determining availability of the object, regardless of the reported monitor status. This behavior is intentional.

Note: When a monitor is applied to an object and the monitor instance is subsequently disabled, the monitor status reflects the last known status of the monitor instance. 

When a single monitor is applied and the monitor instance is disabled, the BIG-IP system will consider the monitor instance as UP and mark the object UP regardless of the last reported monitor status. For example, if you have a monitor applied to a pool member and disable that monitor instance, BIG-IP will load balance traffic to the pool member even if the last reported monitor status was DOWN.

When multiple monitors are applied to a pool member, and one or more monitor instances are disabled, the system does not differentiate between monitor instances that are actually UP and those that are disabled. Each disabled monitor instance is considered UP when determining whether the Availability Requirement threshold has been met for the monitored object. As a result, a monitored object may be marked UP based solely on the fact that one or more monitor instances are disabled, even if all active monitor instances report the object as DOWN.

Note: When multiple monitors are configured for an object, the Availability Requirement monitor setting is used to specify how many monitors must be UP before the object is considered UP. 

For example, if you have two monitors applied to a pool member that has its Availability Requirement setting configured to At Least 1, and you disable one of the monitors, the BIG-IP system will load balance traffic to the pool member even if the only active monitor instance reports the pool member is DOWN.

To avoid an unexpected UP status for an object with multiple monitors applied with a custom Availability Requirement setting, do not disable any monitor instances. Instead, remove the monitor that is no longer required from the configuration of the monitored object.
