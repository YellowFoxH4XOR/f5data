Description
This article describes how to run a psql command to find out the size of the bigiq_db database in postgres on a BIG-IQ.

Environment

  • BIG-IQ CLI

Cause
None

Recommended Actions

  1. Run the following command to retrieve the complete size of the database bigiq_db
    psql -U postgres -d bigiq_db -c "SELECT pg_size_pretty( pg_database_size('bigiq_db') );"
