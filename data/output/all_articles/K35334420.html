Cause

Unknown at time of publication

Recommended Actions

  1. attempt to delete the Service in question from the web GUI
     
  2. there are cases wherein even after deleting from the GUI, there are still remnants of the application service leftover in the config. In such cases, use the below tmsh command to delete the SSLo Service in question:

            # tmsh delete sys application service <application_service_name>
        
       For example, to delete an application service named "ssloS_ICAP_Symantec", run the following tmsh command:
        
            # tmsh delete sys application service ssloS_ICAP_Symantec.app/ssloS_ICAP_Symantec
     
  3. create the Service and attempt to deploy again.
