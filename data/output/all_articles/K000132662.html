Description

After authenticating with APM, the destination server page does not display until it is refreshed.

The browser network log shows the request as "Pending"



Environment


APM policy protecting a http server (APM+LTM) policy

Cause


The server is sending a 302 Redirect to http://

This port is not open.

Recommended Actions


Follow this procedure.

https://support.f5.com/csp/article/K14775

K14775: Configuring an HTTP profile to rewrite URLs so that redirects from an HTTP server specify the HTTPS protocol (10.x - 15.x)

Additional Information


The page displays on browser refresh because it will attempt to connect on https if http fails.

This behaviour varies between browsers.
