K000158832: Perform allow-move (unassign) for BIG-IQ CAT license keys

Type
Support Solution
Published
2025-12-17
Updated
2026-11-16
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
  • BIG-IP Cloud Edition
Source

Description

You need to move a CAT license key (Utility license) from one BIG-IQ to another, but this requires an "allow move" (now "unassign") to activate it on a different BIG-IQ.

Environment

  • Flexible Consumption Program (FCP)
  • Catalog (CAT) license key
  • BIG-IQ License Manager
  • Admin/Editor access to MyF5 Subscription

Cause

CAT license keys can only be assigned to one BIG-IQ at a time, therefore, the "allow move" (unassign) process is necessary to release a license from one BIG-IQ to activate it on a different BIG-IQ.

Recommended Actions

Unassign (allow move) the CAT license key from the MyF5 Customer portal. Formerly, this process required an F5 support case, but now customers can perform this request via their FCP subscription on the MyF5 Customer portal.

  1. Log onto MyF5
  2. Select Subscriptions
  3. Open the active FCP Subscription
  4. Locate the product BIG-IP VE Subscription: CAT <#> and select Edit
  5. From the slide-out drawer, click the dropdown menu and select Unassign
  6. Click Submit and confirm
  7. After 15 minutes and its status reads "ready to reassign", activate the CAT license key on the BIG-IQ. Note: Unassign releases the parent CAT license key and all of its license offerings so this request is equivalent to updating 20+ licenses and requires at least 15 minutes to process. 

Important: Prior to 15 minutes you may encounter 51092: This license has already been activated on a different unit and some license offerings may fail. Repeat the unassign and wait longer to ensure all license are released and available for reuse.

Additional Information

If unable to access the active FCP subscription via MyF5, please open a case with F5 per Create a support case using MyF5.
