K000158832: Perform allow-move for BIG-IQ CAT license keys

Description

You need to move a CAT license key (Utility license) from one BIG-IQ to another, but this requires an "allow move" to activate it on a different BIG-IQ.

Environment

  • Flexible Consumption Program (FCP)
  • Catalog (CAT) license key
  • BIG-IQ License Manager
  • Admin/Editor access to MyF5 Subscription

Cause

CAT license keys can only be assigned to one BIG-IQ at a time, therefore, the "allow move" process is necessary to unassign a license from one BIG-IQ to activate it on a different BIG-IQ.

Recommended Actions

Unassign (allow move) the CAT key from the MyF5 customer portal.

  1. Log onto MyF5
  2. Select Subscriptions
  3. Open relevant Subscription
  4. Locate BIG-IP VE Subscription: CAT <#> and select Edit
  5. From the Edit dropdown menu, select Unassign
  6. Click Submit and confirm
  7. Wait 15 minutes to activate CAT license key on new BIG-IQ

Additional Information

If unable to access this subscription via MyF5, please open a case with F5 per Create a support case using MyF5.
