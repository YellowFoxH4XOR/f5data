Description

This is for users who wish to add audit logging of SSL/certificate/key sections of the Configuration Utility (the BIG-IP GUI).

Environment
  • BIG-IP versions 14+

Cause

In certain environments customers may want to have configuration changes made in the Configuration Utility logged either locally or remotely. 

Recommended Actions

  1. Navigate to System  ››  Logs : Configuration : Options

  2. At the bottom of the page, under Audit Logging select "Enable" for GUI

Additional Information

To verify that this setting was accepted, navigate to the SSL Certificate list (System >> Certificate Management : Traffic Certificate Management : SSL Certificate List), and then check /var/log/audit for a log similar to the following:

info GUI[17621@bigip-otter]: 00000001:20000: AUDIT - user admin - RAW: GUI: host=192.0.2.1 user=admin partition=Common action=list object=[All] type=Certificate and Key result=OK
