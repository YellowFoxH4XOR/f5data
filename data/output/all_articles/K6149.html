Topic

When you perform an installation through a terminal connection, the BIG-IP system installer requires that the terminal emulation window size is a minimum of 24 rows and 80 columns. If the window size is smaller, the installation fails and the system returns an error message similar to the following example:

Can't make new window at (-1,1), size (24,75) install.info:
The installation was cancelled

Recommendation

If an installation exits with the Can't make new window error message, you should ensure that the terminal emulation window size is at least 24 rows and 80 columns, and perform the installation again.
