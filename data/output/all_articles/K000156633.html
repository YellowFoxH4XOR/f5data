K000156633: Internal Server Error when attempting to access the Network Access (VPN) section via the GUI

Type
Support Solution
Published
2025-10-01
Updated
2025-10-01
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000156633

Description

BIGIP Administrator may get Internal Server error while trying to save vpn (network-access) resource in GUI.

Environment

  • APM
  • GUI
  • VPN (network-access) resource

Cause

APM mistakenly is trying to send and resolve entries defined in 'DNS Exclude Address Space' setting (address-space-exclude-dns-name) against system DNS server. If system DNS server is not reachable (or entries can't be resolved), the GUI related daemons times out and the Internal Server Error is triggered.

Recommended Actions

Until the bug id 2064089 is fixed, make sure that system DNS is reachable and it can resolve entries from DNS Exclude Address Space. This way the GUI related daemons won't timeout and the Internal Server Error is not triggered.

Additional Information

When the bug id 2064089 is fixed, the saving of vpn resource in GUI will be independent of status/reachability of system DNS server. In another words, the reachability of system DNS server won't be mandatory for proper function of saving vpn (network-access) resource in GUI.
