Known Issue

Using the DNS::name iRule command to modify the Resource Record name of a DNS message may cause the Traffic Management Microkernel (TMM) to produce a core file and restart.

This issue occurs when one of the following conditions is met:

  • The new domain name that passes from the iRule is invalid.
  • The new domain name passes from the iRule while the BIG-IP system is processing a high volume of traffic under memory pressure.

Impact

TMM may produce a core file and temporarily fail to process traffic while restarting.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H474725 on the Diagnostics > Identified > Low|High screen.
  • TMM produces a core file and temporarily fails to process traffic while restarting.

Workaround

To work around this issue, you should verify that the iRule uses a valid domain name.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
