  • BIG-IP ASM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K86237228

Description

In /var/log/asm, the following appears several times:

[tsconfd::ASMCONFIG_CALL, update mcp device group device] Failed due to Thrift exception: connect() failed: Connection refused

Environment

  • asm daemon or all services are restarted
  • No impact on production traffic observed

Cause
These errors are a result of intentional (manual) ASM restart being issued right after making configuration changes on the device.

The logs appears whilst these changes are still ongoing.

Recommended Actions

N/A. Functioning as designed.

Additional Information
The errors reflect the failure of tsconfd component to connect to asm_config_server, because of the intentional ASM restart, while tsconfd it processing the mentioned configuration changes.
