Topic

There are several known issues that prevent full compatibility between the 3-DNS Configuration utility and the Sun Java Virtual Machine:

Status window and menu bar problems

The Sun JVM is not fully compatible with the 3-DNS Configuration utility. As a result, the status window and menu bar may not display properly when your browser is configured to use the Sun JVM.

Workaround

Install the Microsoft Java Virtual Machine for improved compatibility with the 3-DNS Configuration utility.

Network map problems

In versions prior to 4.2 PTF-09, the network map did not display correctly when used with the Sun JVM.

F5 Networks Product Development tracked this problem as CR23281 and CR23282 and it was fixed in BIG-IP version 4.2 PTF-09. For information about upgrading, refer to the 3-DNS Release Notes.

Problems managing topology records

For more information about this problem, refer to K554: Known Issue: You cannot manage topology records with a web browser that uses the Sun Java Virtual Machine (JVM).
