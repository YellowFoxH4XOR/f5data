K000138331: HA communication failed because duplicate self-ip address from the tenants in the same host

Type
Support Solution
Published
2024-04-23
Updated
2025-04-09
Applies to
  • F5OS
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000138331

Description

The tenant's configuration uses the same VLAN and Self-IP in the same host, making duplicate address self-ip address.

Dec 26 13:38:41 bigip.lab warning tmm4[14909]: 01260013:4: SSL Handshake failed for TCP 127.1.1.254:54776 -> 127.1.1.253:4353

Environment

  • LTM
  • rSeries
  • Tenant
  • HA deployment

Cause

Tenant using the same VLAN and HA self-ip address within the same host

Recommended Actions

  • Do the packet capture with the command.
    tcpdump -s0 -vi 0.0:nnn -w /var/tmp/$HOSTNAME-network.pcap port 4353
  • check the communication between port 4353 then verify the MAC address.
  • Verify whether the tenants in the same host are using the same VLAN and HA self-ip or not. If yes, change it to another ip address to avoid duplicate ip addresses.
