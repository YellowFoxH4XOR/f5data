K000137914: APM Authentication Timeout when authenticating with SAML takes longer than 60 seconds

Type
Support Solution
Published
2023-12-15
Updated
2023-12-15
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000137914

Description

When trying to access a APM VPN with a Browser, the Authentication Process times out if the SAML Authentication process takes longer than 60 seconds to complete.

Environment

  • BIG-IP APM Access Profile
  • SAML AAA Authentication Object
  • Using a Browser to access the APM Profile

Cause

If the SAML Authentication process takes longer than 60 seconds, when the SAML iDP returns the SAML Response to the Broswer, the Browser then sends the SAML Response to the APM Policy, but the Browser doesn't send the APM Session cookie (MRHSession). When APM sees the SAML Response without the MRHSession cookie, it redirects the Client to create a new APM Session. The reason the Browser does not send the MRHSession cookie, is that the MRHSession cookie does not have the SameSite attribute set.
 

Recommended Actions

If you are on v16+, then you can simply enable the SameSite cookie attribute, which is configured under the selected APM Profile -> SSO / Auth Domains section

If you are on a version that does not support the SameSite option for the APM Policy, it is recommended that you upgrade to v16+, which supports this. If this is not possible at this time, then you can try adding the following iRule:
  
when RULE_INIT {
    set static::apm_cookies { "F5_fullWT" "F5_HT_shrinked" "F5_ST" "LastMRH_Session" "MRHSequence" "MRHSession" "MRHSHint" "TIN" "F5_VdiUserClientChoicecitrix" "F5_VdiUserClientChoicevmware_view" }
}

when CLIENT_ACCEPTED {
    ACCESS::restrict_irule_events disable
}

when HTTP_RESPONSE_RELEASE {
    if { [HTTP::has_responded] } { return };    # Exit if there was a previous HTTP::(respond|redirect|retry)
    foreach apm_cookie ${static::apm_cookies} {
        if { [HTTP::cookie exists ${apm_cookie}] } {
            HTTP::cookie attribute ${apm_cookie} insert "SameSite" None
                if  { ![HTTP::cookie attribute ${apm_cookie} exists "secure"] } {
                        HTTP::cookie attribute ${apm_cookie} insert "Secure"
                }
        }
    }
}
