Known Issue

The Traffic Management Shell (tmsh) may not display iRules event statistics for virtual servers.

This issue occurs when all of the following conditions are met:

  • A BIG-IP virtual server is configured to reference an iRule.
  • You used one of the following commands to display statistical information of the virtual servers.

    tmsh show ltm virtual detail
    tmsh show ltm virtual <virtual server name> detail

Impact

The system does not display iRules event statistics for the virtual servers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the specific tmsh commands, the system does not include output with information about the virtual server-referenced iRules.

Workaround

To work around this issue, you can use an alternate tmsh command to view iRules statistics. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Viewing iRules statistics with tmsh

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To view iRules statistics for all configured iRules, type the following command:

    tmsh show ltm rule

    To view iRules statistics for an individual iRule, use the following syntax:

    tmsh show ltm rule <iRule name>

  3. To exit tmsh, type the following command:

    quit
