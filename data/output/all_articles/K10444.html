Known Issue

Under rare circumstances, the BIG-IP ASM bd process may encounter fatal errors when it is unable to connect to the MySQL database. These errors may cause the BIG-IP ASM bd process to restart and produce a core file. If the BIG-IP ASM system experiences these symptoms and produces a core file, F5 recommends opening a support case and submitting the core file to F5 Technical Support.

Note: For more information, refer to K10062: Working with BIG-IP core files.

F5 Product Development tracked this issue as ID 208754 (formerly CR122915), and it was fixed in BIG-IP ASM version 10.1.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.
