Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, the BIG-IP system's COMPAT SSL stack contains a specific list of Secure Sockets Layer (SSL) ciphers based on the OpenSSL library.

For a complete list of supported SSL ciphers in the NATIVE and COMPAT SSL stacks, refer to K13163: SSL ciphers supported on BIG-IP platforms (11.x - 13.x).

New Behavior

In BIG-IP 12.0.0 and later, the COMPAT SSL stack has been deprecated and contains no SSL ciphers by default.

F5 Product Development tracked this change as ID 484000.

Note: Beginning in BIG-IP 14.0.0, F5 removed the COMPAT SSL stack and associated SSL ciphers from TMM, and you can no longer use them in SSL profiles. For more information, refer to K56282309: The COMPAT SSL stack has been removed from TMM.

Impact

  • SSL profiles that are configured to use the deprecated COMPAT SSL stack will be reset to use the DEFAULT SSL stack during the upgrade process, and the following message will appear in the /var/log/liveinstall.log file:

    Note: Resetting COMPAT to DEFAULT only occurs when no modifier such as !, +, or - is used in the SSL Profile's Cipher option.

    info: reset to DEFAULT from COMPAT

  • Client connections that rely on ciphers found only in the COMPAT stack may fail.

Recommended Actions

F5 recommends that you use either the DEFAULT or NATIVE SSL stack. However, if you require the Export ciphers that were previously available in the COMPAT SSL stack, use the following syntax in the SSL profile:

COMPAT+EXP

The COMPAT+EXP cipher string enables the use of the following SSL ciphers:
