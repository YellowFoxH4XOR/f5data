Description

Configuration failed to load after upgrading to version 16.x or later, with an error similar to the following:

err mcpd[8070]: 01070712:3: Caught configuration exception (0), Values (/Common/Generic Policy - Enhanced) specified for WAM application /Common/http_application.app/http_application_aam): foreign key index (local_policy_FK) do not point at an item that exists in the database.

Environment

  • Upgrade to 16.x or later
  • AAM provisioned

Cause

AAM is EoSD, and no longer available in the BIG-IP software from version 16.0.0:

  • K70113407: End of Software Development for BIG-IP AAM

Any WAM application present in the configuration files will trigger this issue.

Recommended Actions

To resolve this issue after a failed upgrade, delete or comment out any WAM applications from bigip.conf, along with references to them.

For example:

#wam application /Common/http_application.app/http_application_aam {
#    app-service /Common/http_application.app/http_application
#    code 98026
#    hosts {
#        application.example.com {
#            app-service /Common/http_application.app/http_application
#            code 87150
#        }
#    }
#    perf-monitor-data-retention-period 0
#    policy "/Common/Generic Policy - Enhanced"
#}

ltm profile web-acceleration /Common/http_application.app/http_application_optimized-acceleration {
    app-service /Common/http_application.app/http_application
#   applications { /Common/http_application.app/http_application_aam }
    defaults-from /Common/optimized-acceleration
}

Note: Make sure to delete as above from all administrative partition, if applicable.

Then reload the configuration:

tmsh load sys config
 

In some cases, to prevent a cache memory limitation, it may also be necessary to change the Web Acceleration profile's defaults-from, from optimized-acceleration, to web-acceleration.

Additional Information

This issue can be avoided by removing the WAM configuration in the original boot volume, then de-provisioning AAM before upgrading.
