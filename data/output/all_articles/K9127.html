K9127: Detecting Windows XP Service Pack 3 clients in a pre-logon sequence

Topic

You may want to configure a pre-logon sequence which performs a different set of actions if the client operating system is Windows XP Service Pack 3 (SP3). For example, if your version of FirePass software does not support Windows XP SP3, you can configure a pre-logon sequence that directs Windows XP SP3 clients to the Logon Denied page. 

Note: For information about FirePass support for Windows XP SP3, refer to K9121: Support for Windows XP Service Pack 3.
 
The following procedure configures a pre-logon sequence that uses the Extended Windows and IE info inspector to gather information about Windows client systems and then directs Windows XP SP3 clients to the Logon Denied page:
 
Note: If you want to edit an existing pre-logon sequence, start the procedure at Step 7.
 
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence page.
  3. In the Create new sequence field, enter a name for the pre-logon sequence.
  4. In the Based on menu, select template: Empty.
  5. Click the Create button.

    The new pre-logon sequence appears in the Select Sequence to Use section.
  1. Click edit next to the pre-logon sequence you just created.

    The Pre-Logon Sequence Editor opens.
  2. Mouse over the Go rule.

    A plus sign (+) appears to the right of the Go rule.

    Note: If you are editing an existing pre-logon sequence, mouse over the rule in the pre-logon sequence where you would like to insert the check for Windows XP SP3. 
  3. Click the plus sign (+).

    The Change Sequence panel opens.
  4. In the Change sequence menu, select Insert action.
  5. In the Using menu, select One from the list.
  6. Click the Check OS option button.
  7. Click the Apply changes button at the bottom of the page.

    The Check OS action appears in your pre-logon sequence.
  8. Mouse over the Windows NT based rule of the Check OS action.

    A plus sign (+) appears to the right of the Windows NT based rule.
  9. Click the plus sign (+).

    The Change Sequence panel opens.
  10. In the Change sequence menu, select Insert action.
  11. In the Using menu, select One from the list.
  12. Click the Extended Windows and IE info option button.
  13. Click the Apply changes button at the bottom of the page.

    The Extended Windows and IE info action appears in your pre-logon sequence.
  14. Mouse over the fallback rule to the right of the Extended Windows and IE info box in the updated sequence.

    A plus sign (+) appears to the left of the fallback rule.
  15. Click the plus sign (+) to the left of the fallback rule.

    The Insert Rule Panel opens.
  16. Enter a name for the rule in the Name field.

    For example:

    Check XP SP3
  17. Enter the following expression in the text box:

    EXIST (session.win_info.hotfixes.hf_sp3)
  18. Click the Insert Rule button.

    The rule is added to the pre-logon sequence. The pre-logon sequence now displays the new rule leading to the Logon Denied Page action, and a fallback rule leading to the Logon Allowed Page action.

    Note: Optionally, you may want to provide text on the Logon Denied page to indicate to users that they have been denied access due to the operating system they’re using. To do so, click the Logon Denied Page box, enter the text that you want users to see, then click the Update button.
  19. Click the Back to console link at the upper right corner of the page.
  20. Click the option button next to the pre-logon sequence you just edited, under the Select Sequence to Use section.
  21. Click the Apply button to activate the pre-logon sequence.
