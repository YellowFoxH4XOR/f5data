Known Issue

An SNMP query to walk the ifTable causes the snmpd process to restart continuously.

This issue occurs when the following condition is met:

  • You perform an SNMP query to walk the ifTable on a BIG-IP system with a large number of (Virtual Local Area Networks) VLANs or VLAN groups configured, such as 4K VLANs.

Impact

The SNMP client is unable to walk the ifTable while the snmpd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your SNMP query to walk the ifTable times out.

    For example, you use the following snmpwalk command to query the ifTable on the affected system:

    snmpwalk -v2c -c public localhost ifTable

  • The snmpd process restarts continuously and produces a core file in the /shared/core directory.
