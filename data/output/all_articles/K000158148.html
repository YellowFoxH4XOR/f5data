K000158148: How to prevent data loss when copying and pasting a large amount of information.

Type
Support Solution
Published
2025-12-10
Updated
2025-12-10
Source
https://my.f5.com/manage/s/article/K000158148

Description

Users may encounter issues when copying and pasting. For example, multiple rows from Excel into a web application accessed through the load balancer. The pasted data is incomplete or missing rows when routed via F5 BIG-IP, while bypassing the load balancer results in successful paste operations.

No explicit error messages are shown.

Environment

BIG-IP LTM

Virtual server with stream profile.

Cause

Stream profile interferes with POST requests containing complex or multi-row payloads (such as those copied from Excel), resulting in incomplete data being delivered to the backend application.

Recommended Actions

          1. Remove or replace the problematic stream profile on the affected virtual server.

          2. If removing the stream profile breaks required application logic (such as URL rewrites), use an iRule to perform targeted rewrites without affecting POST payloads.

Replace the stream profile with a blank one.

Apply the iRule below (please double-check it and adjust it to fit your configuration)

when HTTP_REQUEST {
    # Always disable the stream profile at the start of each request
    STREAM::disable
    set name [HTTP::host]
}

when HTTP_RESPONSE {
    # Always disable the stream profile at the start of each response
    STREAM::disable

# Rewrite Location header on 302 redirects to HTTPS using the original host
    set location [HTTP::header Location]
    set port [URI::port $location]
    set n_path [URI::path $location]
    set n_basename [URI::basename $location]
    set n_query [URI::query $location]
if { [HTTP::is_redirect] }{
        if { $port eq VS_PORT}{
            HTTP::header replace Location "https://$name$n_path$n_basename?$n_query"
        }
    }

# Only enable stream if Content-Type contains "text"
    if { [HTTP::header value Content-Type] contains "text" }{
        # Replace all instances of http:// with https:// in textual responses
        STREAM::expression {@http://example.com:1234@https://example.com:1234@}
        STREAM::enable
    }
}

This iRule is designed to control when the stream profile (which allows search-and-replace of text in HTTP responses) is enabled on your F5 BIG-IP.

Its main purpose is to prevent the stream profile from modifying important data (like large or complex information copied and pasted from Excel), while still allowing it to make necessary changes to web pages, such as converting links from http to https.

Ensure iRule logic matches your specific port configuration and rewrite requirements.
