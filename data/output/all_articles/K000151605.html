K000151605: Global Log Receiver: Splunk - HTTP failure response: 500 Server Error - "response status: 403 forbidden"

Type
Support Solution
Published
2025-11-06
Updated
2026-06-18
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud Observability
Source
https://my.f5.com/manage/s/article/K000151605

Description

You want to configure our Global Log Receiver with Splunk as your endpoint of preference. After the configuration you do a test and you get the HTTP 500 Server error

Environment

  • Global Log Receiver

Cause

You have to refresh the token in order to make it work.

In the body of the error you can see that the response status display a "403 forbidden" status. That means that you will have to refresh the token on Splunk.

None
