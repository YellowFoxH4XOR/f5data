Description

When attempting to license a BIG-IP Virtual Edition using a Flexible Consumption Program license offering from the BIG-IQ, you may encounter the following error messages in the BIG-IP LTM logs:

err httpd[8370]: 01180010:3: [license processing][error]: custom flag validation: failed comparison err httpd[8370]: 01180016:3: [license processing][error]: custom flag comparison: failed. (null). (null) err httpd[8370]: 01180010:3: [license processing][error]: feature flag validation failed err httpd[8370]: 01180010:3: [license processing][error]: failed processing license management data

This issue results in the BIG-IP VE failing to load the configuration and not processing traffic.

Environment

  • Flexible Consumption Program (FCP)
  • BIG-IQ Centralized Management or BIG-IQ License Manager
  • BIG-IP Virtual Edition (VE)
  • Catalog (CAT) license offering

Cause

The error occurred during the manual activation of a CAT key when the incorrect license.txt was applied to the licensing offering within the Catalog license bundle. Each license offering in the bundle has a unique dossier and requires a separate license.txt. If possible, use the automatic option, rather than manual, to activate the CAT license.

Recommended Actions

To resolve this issue, unassign or request an allow-move on the CAT license key, reactivate the CAT license key on the BIG-IQ, then relicense the BIG-IP from the BIG-IQ.

  1. Release the CAT license key.
    Either unassign the CAT license key via the subscription in MyF5 or contact F5 support to perform an "allow-move". Both options prepare the license key for reactivation.
    Note: This doesn't impact the BIG-IP.
    • Unassign this CAT key from MyF5:
      1. Log onto MyF5 and select the current FCP subscription.
      2. Locate the impacted CAT key and unassign it via the edit options. This releases the license, just as an allow-move.
      3. Wait 15 minutes then proceed to step 2.
    • Contact F5 support:
      1. Request an Allow Move procedure for the CAT license key.

  2. Reactivate the CAT license bundle on the BIG-IQ
    Use the automatic option. For instructions, refer to the "Reactivate the Catalog License on the BIG-IQ" section in K84488720: Update the Service Check Date for a BIG-IP VE licensed by a BIG-IQ. 
    Note: This doesn't impact the BIG-IP.

  3. Refresh the license on the BIG-IP. 
    For instructions, refer to the "Update the license on the BIG-IP" section in K84488720: Update the Service Check Date for a BIG-IP VE licensed by a BIG-IQ.
    Important: This impacts traffic on the BIG-IP VE as its service restart to process the license update.
