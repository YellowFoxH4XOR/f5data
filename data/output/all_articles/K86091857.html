Known Issue

Citrix XenApp icons may fail to display access session webtops.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to integrate with or replace Citrix XML Brokers.
  • The Citrix XenApp is running version 6.5 and has hotfix 6 or 7 applied.

Impact

The Citrix XenApp icons no longer display in the user webtop.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Citrix application icons are not displayed on the webtop.
  • In the /var/log/apm file, you observe a log message similar to the following example when the user's webtop is rendered:

    Remote Desktop '/<partition>/<webtop name>': failed to handle '/f5vdi/citrix/icon/': Incorrect bitmap size
