K000150576: A query expression is valid but is not compatible with the Query Parameters form

Type
Support Solution
Published
2025-03-27
Updated
2025-03-27
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000150576

Description

When building a filter for BIG-IQ Web Application Security Events logs the error "A query expression is valid but is not compatible with the Query Parameters form" is thrown.

 

Environment

  • BIG-IQ
  • using filters for ASM logs

 

Cause

Not using supported keys for filtering.

 

Recommended Actions

Make sure to only use keys from the following link:

BIG-IQ: Filtering by entering query parameters
