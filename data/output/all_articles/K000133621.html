K000133621: Creating a bootable USB Flash Drive using Rufus in Windows for a clean installation of BIG-IP

Description

Creating a bootable USB Flash Drive using Rufus in Windows for a clean installation of BIG-IP
 

Environment

The Rufus software can be used under Windows only
 

Cause

None
 

Recommended Actions

1.  Download the Rufus for Windows at https://rufus.ie/en/ Note: This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

2.  Download the .iso file for the version of BIG-IP you wish to use for a clean installation at https://my.f5.com/manage/s/downloads .  For example for BIG-IP version 16.1.3 you would download the file BIGIP-16.1.3-0.0.12.iso

3.  Run the Rufus software and choose your USB device in the "Device" drop down menu

4.  Under boot selection choose the SELECT button and select the BIG-IP .iso file you downloaded in step 2

5.  You can leave the other settings on default (Partition Scheme MBR, Target system BIOS, File system Large FAT32)

6.  Click the START button near the bottom
