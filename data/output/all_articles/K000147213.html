K000147213: Why am I receiving "429 Too Many Requests" error message?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147213

Description

Error message: Http failure response: 429 Too Many Requests Object kind {...} has exhausted limits

  • Example: 429 Too Many Requests, Object kind waf has exhausted limits (0)
  • Cannot create an object

Environment

  • F5® Distributed Cloud Console UI or API

Cause

  • This functionality is not available for your user plan
  • You have reached the object limit for your plan

Answer/Recommended Actions

  • Check your current plan under General -> Billing -> Billing Settings, find more details under Compare F5® Distributed Cloud Services
  • You can switch plans by logging in as a tenant owner
  • Send a support request to query increase of quota
