K000134878: Creation of wideIP with alias may fail to add A record in the zone file

Type
Support Solution
Published
2023-06-05
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.4
Source
https://my.f5.com/manage/s/article/K000134878

Description

Created a wideip with a pool without CNAME on device A,

Results:  An A RR is created on device A and synced to other devices in the sync group.

 

Created a wideip with a pool with CNAME on device A,

Results:  A CNAME RR is created in a zone file and can be seen from GUI.

However, sometimes an A RR is missing on device A and all other devices in the sync group.

 

Environment

You must meet both conditions:
  • Creation of a wideip with an alias 
  • synchronize-zone-files is set to yes

 

Cause

BUG ID 1289313 Creation of wideip with alias would cause inconsistent zone data across GTM sync group
 

Recommended Actions

Workaround 1:
1a. Disable zone syncing by setting synchronize-zone-files to no, 
tmsh modify /gtm global-settings general synchronize-zone-files no
1b. Create the wideips (with or without aliases),
2c. Enable zone sync again 
tmsh modify /gtm global-settings general synchronize-zone-files yes



Workaround 2:
Creating the wideip without an alias, then going back in and adding the alias.

 

Additional Information


If you need an EHF, you can contact F5 support to get the EHF and follow article K13123 to install it.
