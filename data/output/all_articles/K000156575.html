Source

Description

When deploying or modifying an SSL Orchestrator [SSLo] topology, the GUI responds with the following error message:

Failed to PATCH the OB block sslo_ob_TOPOLOGY_CREATE_sslo_inbound_tcp, ID cd7cd715-2e79-4be7-90ae-296102988de5 on local device Error: java.net.ProtocolException: status:500, body:{"code":500,"message":"MCP Session terminated","errorStack":[],"apiError":32768003}

Environment

  • BIG-IP SSL Orchestrator

Cause

This is likely due to the BIG-IP primary admin user being modified.

Recommended Actions

  • do please acknowledge the error message, and do please delete the SSLo deployment you were working on;
  • do please open a terminal to the SSLo machine;
  • do please run the following commands:

# tmsh modify sys db systemauth.primaryadminuser { value "admin" }

# tmsh save sys config

  • do please restart the SSLo daemons:

# bigstart restart restjavad && sleep 30 && bigstart restart restnoded

  • do please wait something like 5/10 minutes for the restart process to settle.
