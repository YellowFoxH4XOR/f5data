Description

  • Unable to associate security policy with virtual server

Environment

  • ASM
  • FPS
  • Azure

Cause

  • ASM and FPS was not provisioned
  • ASM and FPS could not be provisioned 
  • Deployment instance like D2S was too small to accommodate the disk/memory minimum requirements  
  • To avoid capacity issues in BIG-IP 12.x and later, you should provision the BIG-IP ASM module on systems with at least 8 GB or more of memory.
    K40257355: The BIG-IP system may experience memory capacity issues when BIG-IP LTM and BIG-IP ASM are provisioned together

Recommended Actions

  • Deployment instance must reflect the required minimum resource 

Additional Information

  • For example, deployment in Azure DS2 instance, with RAM 6.8 GB and 24 G disk space running version 14.1.0.3 can be too low in resource to accomplish objectives
