Description

Unable to generate cert/key with Safenet HSM.

The following error message is logged in /var/log/cklog.log:

FINIGenerateKeyPair ***CKR_CONTAINER_OBJECT_STORAGE_FULL***(3729010ms) {Obj=0 Obj=0 }

Environment

  • BIG-IP
  • Safenet HSM

Cause

Safenet HSM Partition is full

Recommended Actions

Remove unused objects from HSM to free space.
Open ticket with HSM vendor for further investigation.

Additional Information

K05053554: Enable Network HSM Safenet Luna client debug Logging in BIG-IP
