Description

When accessing a virtual server, browser reports the following error message:

ERR_TOO_MANY_REDIRECTS

Environment

  • HTTP virtual server with SSL offload

Cause

Pool member is redirecting all HTTP requests to HTTPS in HTTP responses. The BIG-IP proxies these redirections back to the client.

This configuration results in a loop since the the client already has a HTTPS connection established, and simply sends a new request over the existing HTTPS connection each time.

Recommended Actions

There are two ways to resolve this issue, depending on your requirements.

The first solution is to reconfigure the pool member itself to accept plaintext HTTP requests, and prevent redirection to HTTPS.

The alternative solution is to add a Server SSL profile to the virtual server, which will change the configuration to perform SSL re-encryption.

  • K14806: Overview of the Server SSL profile (11.x - 17.x)

Additionally, if your pool member supports the X-Forwarded-Proto HTTP header, you can configure a custom HTTP profile to insert the X-Forwarded-Proto: https HTTP header and assign the custom HTTP profile to the affected HTTP virtual server. For information on configuring the HTTP profile to insert the header, refer to K43444200: Configuring the BIG-IP system to insert the HTTP X-Forwarded-Proto header extension.

Additional Information

SSL re-encryption may result in higher resource utilization for the pool member.
