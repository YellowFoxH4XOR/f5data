Description

  • F5 AWAF/ASM and VMware Horizon Connection Issues.

Environment

  • With web-based clients, no issue
  • Non-browser clients connections reset

Cause

AWAF/ASM supports protocols HTTP and websocket. Therefore, AWAF/ASM is able to work with web-based VMware Horizon View clients.
However, Non-browser VMware Horizon View clients use non-HTTP/websocket protocol and therefore, connections reset.

Recommended Actions

Assuming, the same Virtual Server is used for both web-based and non-browser client, an iRule ( or Local Traffic Policy ) may be used to disable ASM when non-HTTP/websocket traffic is matched. For example: 
    when HTTP_REQUEST {
        if { ([string tolower [HTTP::header value Upgrade]] equals "websocket") &&
             ([string tolower [HTTP::header value Connection]] equals "upgrade")
           } {
            ASM::disable
        }
    }

Additional Information

For web-based to work, ASM enabled Virtual Server, application of a websocket profile is required and/or a configuration that bypasses ASM for octet-streams as per the following article.

K10602137: ASM appears not to understand or blocks request with content type application/octet-stream
