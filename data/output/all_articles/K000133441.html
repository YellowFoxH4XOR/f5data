K000133441: Ansible request to f5os_device_info module results in telemetry error

Type
Support Solution
Published
2023-04-07
Updated
2023-12-01
Applies to
  • F5OS
  • VELOS Platforms
  • rSeries Platforms
Source
https://my.f5.com/manage/s/article/K000133441

Description

Ansible request to f5os_device_info module results in the following error:

AttributeError: 'NoneType' object has no attribute 'telemetry'

 

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos 
  • Journey tool

 

Cause

  • Known issue: Sending telemetry errors with f5os_device_info

 

Recommended Actions

Disable telemetry with the following playbook variable

f5_telemetry: false

 

Upgrade collection to 1.1 when it is released

 

Additional Information

  • F5OS Collection for Ansible
