Description

BIG-IQ fails to import ASM configuration with error: "Failed copying from source subcollections to target subcollections: java.lang.IllegalArgumentException: Invalid country code or country : Curacao".

 

Environment

  1. BIG-IQ 8.4.0
  2. ASM BIG-IP 17.5.1.3

 

Cause

Bugs 

 

ID2219357 [BIG-IQ]: Importing the BIG-IP device fails when the Address List includes the country code "CW" and "SX"
ID2099633 [BIG-IQ]: Importing the BIG-IP device fails when the Address List includes the country code "SS"

 

Recommended Actions

Add the following entries to geolocations.json:

"CW": {
"code": "CW",
"name": "Curacao",
"regions": []
}

"SX": {
"code": "SX",
"name": "Sint Maarten",
"regions": []
}

"SS": {
"code": "SS",
"name": "South Sudan",
"regions": []
}

Restarting restjavad.
