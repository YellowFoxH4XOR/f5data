Description

This article is in regards to the BIG-IP Advance Firewall Manager (AFM) modes.

The 2 available AFM modes are:

  • ADC mode
  • Firewall mode

Environment

  • BIG-IP AFM provisioned

Cause

By default, the Network Firewall is configured in ADC mode, a default allow configuration, in which all traffic is allowed through the firewall to virtual servers and self IP addresses on the system, and any traffic you want to block must be explicitly specified. The system is configured in this mode by default so all traffic on your system continues to pass after you provision Advanced Firewall Manager™. You should create appropriate firewall rules to allow necessary traffic to pass before you switch Advanced Firewall Manager to Firewall mode.

In Firewall mode, a default deny configuration, all traffic is blocked through the firewall, and any traffic you want to allow through the firewall must be explicitly specified.

Recommended Actions

To change the Network Firewall, perform one of the following procedures:

  • Configuring the AFM(Network Firewall) in ADC mode
  • Configuring the AFM(Network Firewall) in Firewall mode


Configuring the AFM(Network Firewall) in ADC mode

  1. Navigate to Security > Options > Network Firewall .
  2. From the Virtual Server & Self IP Contexts list, select Accept.
  3. Click Update.


Configuring the AFM(Network Firewall) in Firewall mode

  1. Navigate to Security > Options > Network Firewall .
  2. From the Virtual Server & Self IP Contexts list, select:
    Select Drop to silently drop all traffic to virtual servers and self IP addresses unless specifically allowed.
    Select Reject to drop all traffic to virtual servers and self IP addresses unless specifically allowed, and to send the appropriate reject message for the protocol.
  3. Click Update.
