Description

Unable to access the Guided configuration menu after Advanced WAF (Adv WAF) license reactivation. Following errors are noted in GUI when accessing the Guided configuration menu.

The requested url was not found on this server

Environment

  • BIG-IP ASM 
  • Licenses is upgraded to Advanced WAF (Adv WAF)
  • Guided configuration

Cause

Unknown at time of publication

Recommended Actions

Perform below workaround to resolve the issue

  1. Login into device using SSH
     
  2. Stop the restjavad and restnoded daemons with the following commands 

    #bigstart stop restjavad
    #bigstart stop restnoded
     
  3. Run the following command to clear rest storage configuration

    # clear-rest-storage

    Note: This command will remove BIG-IQ Centralized Management configuration in the BIG-IP device. It will also remove all objects in the SSL Orchestrator Guided Configuration tool
     
  4. Start the restjavad and restnoded daemons

    #bigstart start restjavad
    #bigstart start restnoded
     
  5. Then proceed to check the Guided configuration menu.
