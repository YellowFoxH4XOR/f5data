Description

You want to find SNMP OID for CPU utilization by control plane and data plane separately on the BIG-IP system.

Environment

  • SNMP
  • CPU utilization
  • BIG-IP LTM

Cause

None

Recommended Actions

You may use the OID .1.3.6.1.4.1.3375.2.1.7.5.2.1.19."x".x to retrieve the CPU utilization for every core.

The first x represents the appliance or the blade where the CPU is physically installed. The initial number in the SNMP response for the first x will always be 0 for the appliance platforms, while for multi-blade platforms, it will start from 1 and end with the total number of blades. 

The second x here represents the logical core of the CPU. The second x will start from 1 and end with the total number of logical cores on the appliance or blade.

Thus, you may use the odd-numbered index(1, 3, 5, 7) for the second x to retrieve CPU utilization for the data-planes and the even-numbered index(2, 4, 6, 8) for control planes.

Take a VIPRION system that owns 4 physical CPUs and 8 cores in each of the CPUs as an example:

snmpwalk -v2c -c public localhost .1.3.6.1.4.1.3375.2.1.7.5.2.1.19
