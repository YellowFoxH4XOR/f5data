Known Issue

SSL Forward Proxy or F5 Herculon SSL Orchestrator may sign Secure Socket Layer (SSL) certificates using the SHA1 algorithm.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to process application traffic using either SSL Forward Proxy or Herculon SSL Orchestrator.
  • An intermediate Certificate Authority (CA) certificate in the SSL certificate chain is signed using the SHA1 algorithm.

Note: This issue occurs because the BIG-IP system chooses the weakest hashing algorithm in the signing certificate chain.

Impact

Web browsers pause new connections and warn that the web site is not secure.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You receive web browser warning messages when you connect to a secure web site.
  • SSL certificates on the server side of the BIG-IP system are signed using SHA2, while SSL certificates on the client side are signed using SHA1.
