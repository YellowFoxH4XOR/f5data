Topic

F5 Advanced Web Application Firewall (AWAF) is a combination of BIG-IP ASM, L7 DDoS protection, and a selection of core BIG-IP LTM features.

Advanced WAF has the capabilities described in the following table.

Advanced WAF features 
Base ADCApplication delivery capabilities found in the BIG-IP LTM system, such as SSL offload and load balancing                                                                                       
L7 DDosComprehensive application layer DDoS mitigation capabilities found in Advanced WAF
For more information, refer to: K13410341: Overview of L7 DDoS attack protection (14.x - 17.x).
BIG-IP ASMCore Big-IP ASM capabilities
For more information, refer to: K07359270: Succeeding with application security
Attack SignaturesProtection from web exploits and application vulnerabilities (CVEs)
For more information, refer to: K8217: Managing BIG-IP ASM attack signatures
Anti-Bot DefenseProactive bot defense
For more information, refer to: K19556739: Overview of BIG-IP ASM client fingerprinting
Anti-Bot MobileProactive bot defense specific to mobile apps
Data SafeApplication Layer Encryption, which allows Advanced WAF to protect credentials and sensitive fields from compromise at the client/browser level
For more information, refer to: K02145419: Overview of the DataSafe profile
Behavioral DoS UnlimitedBehavioral DoS support across all virtual servers
For more information, refer to: K13410341: Overview of L7 DDoS attack protection (14.x - 17.x)
Credential Stuffing detectionBrute force attack prevention subscription service for Advanced WAF that leverages a threat feed of known, stolen credentials
For more information, refer to: K18650749: Configuring brute force attack protection (13.1.0 and later) or
K54335130: Configuring brute force attack protection (12.1.2 - 13.0.x)
Upstream SignalingSubscription service for an on-premise Advanced WAF solution hybrid with F5 Silverline. 
Threat CampaignSubscription service for Advanced WAF that includes unique signatures and metadata to mitigate current malicious campaigns with high accuracy
For more information, refer to: Web Threat Campaigns of the BIG-IP 14.0.0 New Features and Installation release notes
OWASP Compliance DashboardThe ability to review and update security policies to validate their OWASP top 10 compliancy (BIG-IP version 14.1.0 and later).

Description

F5 Advanced WAF is available as a standalone solution or as an add-on module for BIG-IP LTM on any supported F5 platform and on BIG-IP LTM Virtual Edition (VE). For VELOS and rSeries platforms, make sure to select a tenant image type that supports all modules. For more information, refer to K45191957: Overview of the BIG-IP tenant image types.
