K000152959: Error: Guest Operating System 'rhel9_64Guest' is not supported when deploying a CE node

Type
Support Solution
Published
2025-08-11
Updated
2026-01-14
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000152959

Description

When deploying an F5 Distributed Cloud (XC) Customer Edge (CE) node on VMware ESXi, users may encounter the following similar error during VM power-on:

Guest Operating System 'rhel9_64Guest' is not supported.

Environment

  • Customer Edge
  • VMware ESXi 6.7 or later

Cause

  • The error Guest Operating System 'rhel9_64Guest' is not supported occurs when the VM Guest OS type is incorrectly set in VMware settings.

Answer/Recommended Actions

VM Guest OS Configuration:

  1. Set the VM Guest OS to a supported Linux version in VMware settings.
    1. Go to Edit Settings > VM Options > General Options and
    2. Select "Linux" as the Guest OS type.
    3. Select "Red Hat Enterprise Linux 8 (64 bit)"
