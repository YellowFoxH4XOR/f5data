Description

You may see the error message below when trying to configure BIG-IP using AS3:
{"code":404,"message":"Public URI path not registered: /shared/appsvcs/declare","referer":"10.10.10.1","restOperationId":136926616,"kind":":resterrorresponse"}

Environment

  • AS3
  • BIG-IP

Cause

Typically this indicates that AS3 is not installed or was not installed properly. 

Recommended Actions

Refer to the Installation chapter of the AS3 User Guide for more information about how to install or re-install the AS3 package.

Additional Information

Refer to the Troubleshooting chapter of the AS3 User Guide if needed.
