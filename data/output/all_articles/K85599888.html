K85599888: Error Message: Backup failed; fail running task on restart (BIG-IQ system)

Type
Knowledge
Published
2017-01-23
Updated
2025-02-07
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 5.1.0, 5.0.0, 4.6.0
Source
https://my.f5.com/manage/s/article/K85599888

Issue

Error Message

Backup failed; fail running task on restart

For example:

Backup failed
fail running task on restart

Message Location

You may encounter this message in the following location:

  • The BIG-IQ system interface

Description

This message occurs when all of the following conditions are met:

  • You have just installed the software on the BIG-IQ system.
  • You have transferred the last known User Configurable Set (UCS) backup file into the BIG-IQ system's /var/local/ucs directory and performed a restoration using the Traffic Management Shell (tmsh) command load sys ucs <Filename>.ucs
  • The tmsh command on the UCS restoration process indicated a successful restoration.
  • You logged in to the BIG-IQ system interface and navigated to System Management > Inventory > Backup & Restore > Backup Files.

Impact

You can observe the UCS restoration process result from the tmsh command output. If the tmsh command indicates a successful restoration, then you can safely ignore the BIG-IQ system interface Backup Files menu where it indicates the status of the target UCS as Backup failed.

Recommended Actions

  • To recover from this issue, you can safely delete the failed entry from the BIG-IQ system interface Backup Files entry list. You can then restore the UCS using the recommended procedure in the following article: K45246805: Restoring the BIG-IQ system with a UCS file backup stored remotely.
  • To prevent this issue from occurring, restore the BIG-IQ system by transferring the UCS file into the /shared/ucs_backups directory instead of into the /var/local/ucs directory. For more information, refer to K45246805: Restoring the BIG-IQ system with a UCS file backup stored remotely.
