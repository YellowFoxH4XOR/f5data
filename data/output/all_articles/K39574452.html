Description

There are ASM policy differences between the HA pair.

The following log message can be found:

var/log/ts/ts_debug.log:|ZEROMQ|Feb 10 23:01:55.639|26680|10147|10147|epoll.cpp:0060|~epoll_t()|(zmq_assert) Assertion failed: load.get () == 0
 

Environment

  • BIG-IP ASM
  • ASM policy sync not working

Cause

Bug ID 912149
 

Recommended Actions

Restart asm_config_server on the units in the device group.

pkill -f asm_config_server
 

Additional Information

  • Ensure ASM sync has been enabled:K12200102: Enabling Application Security Synchronization on a device group
  • K11815612: Cannot see any requests for virtual server after applying log profile
  • K02522003: ASM policies synchronisation issue
  • K63723293: No Learning Suggestions generated for any policy in Traffic Learning

  • K38003587:  On the GUI, Cluster Synchronization Status Displays "Error" for secondary slot(s)
