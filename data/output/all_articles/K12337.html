Known Issue

This is the result of a known issue. Synchronizing the configuration from an active BIG-IP APM system to a standby BIG-IP APM system after items have been deleted from an access policy may fail. You may view the following output during the ConfigSync process:

This issue occurs because the process that retrieves access policy items retrieves all items, including the inactive items; however, the process that checks the configuration only looks for active objects. Because the process is only expecting the active items, but finds the inactive items, the validation fails and the configuration synchronization will consequently fail as well.

F5 Product Development tracked this issue as ID 336823 and was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM and Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
