Issue

Error Message

01700002:5: PPTP CALL-END id;<Call ID> reason;0 from;<Internal IP address> to;0.0.0.0 nat;<External NAT address> ext-id;<Call ID>

In this error message, note the following:

  • <Call ID> is the call identification number that represents a specific Point-to-Point Tunneling Protocol (PPTP) connection
  • <Internal IP address> is the remote PPTP client's internal IP address
  • <External NAT address> is the remote PPTP client's external network address translation (NAT) address

For example:

01700002:5: PPTP CALL-END id;12345 reason;0 from;192.168.10.1 to;0.0.0.0 nat;100.100.100.1 ext-id;12345

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • Your BIG-IP configuration includes one or more virtual servers with an associated PPTP profile and Large Scale NAT (LSN) pool.
  • There are one or more secure Virtual Private Network (VPN) tunnels forwarding PPTP control and data connections.
  • One or more of the PPTP control channels terminates.

Impact

One or more PPTP control channels terminate. This behavior occurs when the client terminates the PPTP session. If you suspect the PPTP session is terminated prematurely, refer to the Recommendations Actions section.

Recommended Actions

Timeout issues

If single PPTP control channels terminate randomly, it may be due to timeout issues. Be default, the BIG-IP system PPTP timeout value is 60 seconds. Remote clients must send a Keep-Alive packet within this period to prevent termination. To verify the current PPTP timeout value on the BIG-IP system, type the following command:

tmsh list sys db tm.pptp.timeout

Network issues

If multiple PPTP control channels terminate simultaneously, there may be issues in the network. For example, if a peer switch were to reboot, an error message logs to the /var/log/ltm file that appear similar to the following example:

01700002:5: PPTP CALL-END id;61328 reason;0 from;10.94.63.89 to;0.0.0.0 nat;120.21.92.181 ext-id;61328
01700002:5: PPTP CALL-END id;63159 reason;0 from;10.89.22.122 to;0.0.0.0 nat;120.21.11.47 ext-id;63159
