Topic

The Packet Velocity ASIC (PVA) performance graphs display performance data for fully accelerated virtual server connections. When virtual server connections are fully accelerated, all packets in the connection are processed using the PVA.

The PVA performance graphs do not show performance data for partially accelerated virtual server connections. When virtual server connections are partially accelerated, the first packet in each connection is processed in software, and each packet thereafter is processed using the PVA.

Note: For more information, refer to K4832: Overview of Packet Velocity ASIC (PVA) Acceleration features and sub features.
