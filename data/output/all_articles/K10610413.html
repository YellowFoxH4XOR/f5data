K10610413: Enabling TLS 1.3 on F5 SSL Orchestrator for outbound topology deployment

Type
Knowledge
Published
2019-07-12
Updated
2023-02-21
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 15.0.X, 15.0.0
Source
https://my.f5.com/manage/s/article/K10610413

Issue

Description

Starting in F5 SSL Orchestrator 15.0.0 - 6.0, SSL Orchestrator supports configuring TLS 1.3 for inbound topology deployment in the SSL Orchestrator configuration. The support for configuring TLS 1.3 on outbound topology deployment is currently unavailable in the SSL Orchestrator configuration. However, you can unlock (unprotect) the outbound topology deployment objects on the the SSL Configurations tab and enable TLS 1.3 for SSL profile(s) of the outbound topology deployment. After you unlock the objects, the SSL Orchestrator Configuration displays the objects in the SSL Configurations as read-only and are not be able to modify them using the SSL Orchestrator configuration. You can modify these objects at their individual profile level.  

TLS 1.3 is supported on Client SSL and Server SSL profiles. By default, it is disabled on both profiles.  

Environment

  • F5 SSL Orchestrator 15.0.0 - 6.x.
  • Outbound topology

Note: SSL Orchestrator 6.x needs BIG-IP 15.0.0 and later. It does not run in versions earlier than BIG-IP 15.0.0.

Cause

None

Recommended Actions

Depending on whether you want to turn it on for client side or server side, you can modify the respective Client SSL and/or Server SSL profile(s). To do so, perform the following procedure:

Impact of procedure: You cannot modify the unlocked objects on SSL Configurations tab in the SSL Orchestrator configuration.

  1. Log in to the Configuration utility.
  2. Navigate to SSL Orchestrator > Configuration > Configure > SSL Configurations.
  3. Click the lock icon under the Protected/Unprotected Configurations for the corresponding outbound deployment that you want to modify. For example, if you have an outbound topology deployment named sslo_ep, you click the lock icon for the corresponding SSL Configurations object ssloT_ep to unlock/unprotect it.
  4. Click OK to proceed when the SSL Orchestrator configuration prompts for a confirmation to unprotect the configuration.
  5. To see the associated Client SSL and Server SSL profiles for this deployment, on the SSL Configurations tab, under Client SSL Profile and Server SSL Profile, click Show All. In the previous example, they are as follows:
    1. /Common/ssloT_ep.app/ssloT_ep-cssl-vhf  (Client SSL Profile)
    2. /Common/ssloT_ep.app/ssloT_ep-cssl-vht  (Client SSL Profile)
    3. /Common/ssloT_ep.app/ssloT_ep-sssl-vhf  (Server SSL Profile)
    4. /Common/ssloT_ep.app/ssloT_ep-sssl-vht  (Server SSL Profile)
  6. Navigate to Local Traffic > Profiles > SSL > Client, and click the first profile listed in the previous step.
  7. For Configuration, click Advanced.
  8. For Ciphers, click Cipher Group and choose a cipher group which contains TLS 1.3 cipher suites. For example, the f5-default cipher group contains the necessary TLS 1.3 ciphers as shown in the following example:

    # tmsh show ltm cipher group f5-default | tr ':' '\n' | grep TLS13
    TLS13-AES128-GCM-SHA256/TLS1.3
    TLS13-AES256-GCM-SHA384/TLS1.3

  9. For Options List, for Enabled Options, click No TLSv1.3 and click Disable.
  10. Click Update.
  11. Repeat steps 6 through 10 for the remaining profiles from step 5. TLS 1.3 is now enabled for these SSL profiles.
