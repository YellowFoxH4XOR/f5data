Description

You observed that your rSeries platform only shows the Health option in the LCD, for example:

​You expect to see all of the four options, System, Health, Options, and Setup. For example:

Environment

  • F5OS-A 1.1.x
  • rSeries Platforms

Cause

There is only a Health option in the menu for version 1.1.x, upgrading to the latest version could bring all the options back on LCD.

Recommended Actions

Upgrade the software to the latest F5OS-A versions.
