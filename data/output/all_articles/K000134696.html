Description

This article describes an issue when response times from BIG-IP to the backend periodically slow down (For example from 100ms to 250ms+). You should also encounter a lot of messages similar to this below.
 

notice tmm[12150]: 01010045:5: Bandwidth utilization is <rate> Mbps, exceeded <percent>% of Licensed <limit> Mbps

 

You can see also in the graphs some Virtual Servers that are using periodically a huge amount of throughput, but you are not seeing ingress and egress packet drops.

 

Environment

  • BIG-IP VE
  • License with bandwidth Limits
  • Response time slowdown
 

Cause

The problem is occurring due to license limits.

 

Recommended Actions

The rate shaper drops ingress and egress packets to limit throughput to the licensed rate. However, the problem is due to bandwidth utilization, so this may appear as a slow performance. It is recommended to change the license to the one with higher throughput.
