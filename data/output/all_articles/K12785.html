Issue

When the BIG-IP ASM system fails to load an XML schema file, the Configuration utility displays an error message that appears similar to the following example:

Exception: Schema Document cannot be parsed (too big or bad syntax): read error at /usr/lib/perl5/vendor_perl/5.8.8/i386-linux-thread-multi/Parser/Expat.pm line 469. at /usr/lib/perl5/site_perl/F5/XML/Schema/Processor.pm line 4573 at /usr/lib/perl5/site_perl/F5/XML/Schema/Processor.pm line 4573

The BIG-IP ASM system uses a proprietary XML parser which may be more restrictive than third-party XML validation tools. For example, in version 10.x, the BIG-IP ASM XML schema parser does not accept the XML element <import> in a schema file without the optional supporting attribute schemaLocation.

If a third-party validation tool verifies a schema file, yet the system generates an error message similar to the one listed previously, the error may be the result of the more stringent parsing requirements of the BIG-IP ASM XML component. If you encounter this situation, contact F5 Technical Support to help you identify the specific element(s) that are generating the error, and identify any possible modifications you might make to work around the issue.

For more information about opening a case with F5 Technical Support, refer to K2633: Instructions for submitting a support case to F5 and K6825: Information required when opening a support case for BIG-IP ASM.
