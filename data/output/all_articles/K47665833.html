K47665833: After an upgrade, FTP can not work

Type
Support Solution
Published
2022-07-14
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6, 15.1.5, 15.1.4
Source
https://my.f5.com/manage/s/article/K47665833

Description

You have published your FTP business via a virtual server on BIG-IP and it runs well in version V15.1.3 or a lower verison, but after an upgrade to an higher verison of V15.x than V15.1.3, the FTP business can not run.

Environment

  • Standard Virtual Server

  • Default FTP profile

Cause

This issue is caused by BUG ID 883593. You may be confused from the description of this ID and find it relates to "PVA Offload Initial Priority" which is a parameter in FastL4 profile.

The issue here hits the ID is because:

  • For FTP business on BIG-IP with the FTP profile, only the FTP control channel acts as standard type of virtual server.

  • The FTP data channel is a separate TCP connection, it's handled in TMM level by way of an FastL4 alike mechanism.

  • The behavior of TMM on the FTP data channel hits BUG ID 883593.

Recommended Actions

To resolve this issue, you can make modifications to the FTP profile by performing one of the following procedures:

  • Set the Data Port to 0

  • Enable 'inherit-parent-profile' option in the FTP profile.

Set the Data Port to 0

Impact of action: None

  1. Go to Local Traffic Management > Profiles > Services > FTP.

  2. To create a custom FTP profile, select Create.

  3. For Name, enter a name for this new FTP profile.

  4. Under Settings, select the Custom box.

  5. For Data Port, type 0.

  6. To save the new custom FTP profile, select Finished.

  7. Associate this FTP profile with your virtual server.

Enable 'inherit-parent-profile' option in the FTP profile.

Impact of action: Enabling Inherit Parent Profile allows the FTP data channel to inherit the TCP profile used by the control channel. When the setting is disabled (default setting), the data channel uses FastL4 only. Enabling Inherit Parent Profile and consequently not using FastL4 may cause a slight performance impact.

  1. Go to Local Traffic Management > Profiles > Services > FTP.

  2. To create a custom FTP profile, select Create.

  3. For Name, enter a name for this new FTP profile.

  4. Under Settings, select the Custom box.

  5. Select the Inherit Parent Profile box.

  6. To save the new custom FTP profile, select Finished.

  7. Associate this FTP profile with your virtual server.
