Known Issue

The management port cannot be disabled on certain BIG-IP platforms.

This issue occurs when the following condition is met:

  • The platform is one of the following:

    • BIG-IP 1500 (C36)
    • BIG-IP 3400 (C62)
    • BIG-IP 6400 (D63)
    • BIG-IP 6800 (D68)
    • BIG-IP 8400 (84)
    • BIG-IP 8800 (D88)
    • BIG-IP ASM 4100 (D46)
    • BIG-IP EM 500 (C36)
    • VIPRION 4400
    • VIPRION 2400

Impact

Connections to the management interface cannot be disabled

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After setting the management interface to disabled, the tmsh show running-config /net interface mgmt command will falsely report that the interface is disabled

    For example:

    net interface mgmt {
    disabled
    mac-address 0:1:d7:65:c9:4
    media-active 100TX-FD
    }
  • After disabling the management interface, the tmsh show net interface mgmt command will report that the interface is still set to up

    For example:

    -----------------------------------------------------------
    Net::Interface
    Name Status Bits Bits Errs Errs Drops Drops Colli
    In Out In Out In Out sions
    -----------------------------------------------------------
    mgmt up 17.1G 17.1G 0 0 4.2K 0 0
  • After setting the management interface to disabled, the bigpipe interface mgmt show command will falsely report that the interface state is set to DS (disabled)

    For example:

    | DS 100 FD 2.130M 455278 1029 0 15.32G 864.0M 0
  • After setting the management interface to disabled, the bigpipe base list command will falsely report that the interface is disabled

    For example:

    interface mgmt {
    disable
    }

Workaround

To work around this issue, you can unplug the management port, or disable the port on the connected switch. To do so, perform one of the following procedures:

Unplug the management port

Impact of workaround: None.

To unplug the management port you will require physical access to the device.

Disable the port on the switch to which the management port is connected

Impact of workaround: None.

To disable the port on the switch connected to the management interface, consult the documentation for your switch.
