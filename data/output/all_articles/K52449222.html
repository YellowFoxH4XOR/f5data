K52449222: OAuth client authorization fails with error, None of the configured JWK keys match the received JWT token

Type
Support Solution
Published
2024-08-06
Updated
2024-08-07
Source
https://my.f5.com/manage/s/article/K52449222

Description

This solution will describe the possible cause(s) and resolution of the following error.

  • OAuth authorization fails.
  • You will observe the following log messages in /var/log/apm:

<bigip_hostname> notice apmd[13962]: 0149028c:5: /Common/<access_policy>:Common:<session_id>:/Common/<OAuth_client_object>_act_oauth_client_ag: OAuth Client: authorization_code is required to get access_token for server '/Common/<OAuth_server>' (client_id=9f996a8de843d703)
<bigip_hostname> notice apmd[13962]: 01490299:5: /Common/<access_policy>:Common:<session_id>:/Common/<OAuth_client_object>_act_oauth_client_ag: OAuth Client: Requesting new token for server '/Common/<OAuth_server>' using 'authorization_code' grant type (client_id=9f996a8de843d703)
<bigip_hostname> notice apmd[13962]: 014902ec:5: /Common/<access_policy>:Common:<session_id>:/Common/<OAuth_client_object>_act_oauth_client_ag: OAuth Client: Requesting ID token for server '/Common/<OAuth_server>' from 'token' endpoint
<bigip_hostname> err apmd[13962]: 01490290:3: /Common/<access_policy>:Common:<session_id>:/Common/<OAuth_client_object>_act_oauth_client_ag: OAuth Client: failed for server '/Common/<OAuth_server>' using 'authorization_code' grant type (client_id=9f996a8de843d703), error: None of the configured JWK keys match the received JWT token

Environment

  • BIG-IP Access Policy Manager (APM)
  • OAuth Server configuratioin
  • OAuth Client object
  • OAuth Scope object
  • OAuth Provider
  • Token Configurations (JWT)
  • Key Configurations (JWK)

Cause

This is caused when the JWK token key does not match the JWT token in the request.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Verfiy the Key configuration on the OAuth Server.
  2. On APM perform an auto discovery to update the JWK Key.
  3. On APM perform an manual update of the JWK Key.
