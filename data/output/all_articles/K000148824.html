Source

Description

    "System ›› Preferences" configuration changes are not saved in the Configuration utility (TMUI). The problem does not disappear after clearing the browser's cache or using Incognito Mode.

    Environment

      • BIG-IP LTM
      • TMOS Configuration utility
      • Web GUI
      • Microsoft Internet Explorer

      Cause

      Browser compatibility issues exclude using the Internet Explorer legacy browser for Configuration utility (TMUI).

      Recommended Actions

      Change the browser to one of the supported ones:

      • Mozilla Firefox 110.0, or later
      • Google Chrome 114.0.5735.90, or later
      • Microsoft Edge 109.0.1518.100, or later

      Additional Information

      None.
