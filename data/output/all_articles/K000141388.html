Description

Security scanners may flag an alert for Oracle Java JRE unsupported versions installed in your BIG-IP system.

Environment

  • Classic BIG-IP Versions
  • Classic BIG-IQ Versions
  • OpenJDK 1.7.0_181 and 1.8.0_212
  • Security Scanners

Cause

The alerts for "Oracle Java JRE Unsupported Version Detection" are due to the presence of unsupported OpenJDK versions (1.7.0_181 and 1.8.0_212) in the Classic BIG-IP/BIG-IQ versions. 

Recommended Actions

None.

Important: The presence of an unsupported version installed in the BIG-IP does not mean that the system is vulnerable to a specific CVE. The package version number alone cannot be relied upon to determine whether a specific CVE impacts the version in use within an F5 product. F5 security advisories on MyF5 are the source of truth for customers to understand their exposure based on the specific F5 use case for the third-party component in question.
