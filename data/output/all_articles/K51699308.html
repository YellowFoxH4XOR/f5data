Description

In some instances you may need to modify or delete an Application Service (iApp) after it has already been deployed. This article will walk you through the steps on how to complete either of these actions.

Environment

  • iApps
  • iApp template

Cause

None

Recommended Actions

Modifying an iApp template

When you modify an iApp template, you update the components that are exposed through the template. For example, if you want to change the virtual server IP address, you modify the IP address using the template rather than editing the virtual server directly. To modify an existing iApp template, perform the following steps:

  1. Log in to the Configuration utility.
  2. Navigate to iApps > Application Services.
  3. Click the Name of iApp.
  4. Click the Reconfigure tab.
  5. Edit any iApp template fields as needed. 
  6. Click Finished.
  7. The configuration modifications and are ready for use with the application.

Deleting an iApp

To delete an iApp and related components, perform the following steps:

Impact of procedure: Deleting an iApp deletes related components, such as virtual servers, pools, and iRules, that were created by the iApp. Components that existed prior to creating the iApp are not deleted when you delete the iApp.

  1. Log in to the Configuration utility.
  2. Navigate to iApps > Application Services.
  3. Click the name of the iApp.
  4. Click the Properties tab.
  5. Click Delete.

Additional Information

Strict Updates

When you are working in the Application Services properties screen, and select the Advanced view, the Strict Updates field is shown. The Strict Updates option is enabled by default and protects against accidental changes to an iApp's configuration, such as virtual servers, pool and iRules. F5 recommends that you leave the Strict Updates setting enabled, and make any changes to the iApp's configuration by modifying the template.

Important: If you disable Strict Updates and make customizations or modifications to the BIG-IP Configuration, you will lose these changes when redeploying or rerunning the iApp!

Even with strict updates enabled, it is possible to enable and disable some of the components within the following configuration object using the TMOS Shell (tmsh) or the Configuration utility:

  • nodes
  • pool members
  • virtual addresses
  • virtual servers
