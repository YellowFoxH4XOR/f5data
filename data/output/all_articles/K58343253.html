Description

BIG-IP configuration changes are not being recorded in the /var/log/audit file, despite Audit Logging being enabled.

Environment

  • Audit logging enabled.
  • Log filter in use, or MCP logging set higher than "notice".

Cause

  • The log filter source includes the mcpd process and the associated log publisher is not configured to send messages to the local syslog.
  • Another possibility is that the MCP log level is not set to "Notice". (This setting is found in the Configuration Utility GUI: 'System > Logs > Configuration > Options > 'Local Traffic Logging' section > MCP'). 

Recommended Actions

  • Remove the log filter, if it is not needed, or modify its settings to log messages from the mcpd process to local syslog.
  • Or set the "Local Traffic Logging > MCP" log level to "Notice", if it is currently set to a more severe level e.g. Emergency, Alert.
