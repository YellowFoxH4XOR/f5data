Security Advisory Description

A remote access vulnerability has been discovered that may allow a remote user to run shell commands on affected systems using HTTP requests to the BIG-IQ user interface. (CVE-2020-5868)

Impact

A remote attacker may be able to leverage the Grafana component to run local shell commands on the system.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column. If the table lists only an older version than what you are currently running, or does not list a non-vulnerable version, then no upgrade candidate currently exists.

Mitigation

BIG-IQ uses the Grafana component in the following pages:

Monitoring > EVENTS > DoS > DoS Summary

  • DoS Active Attacks Summary - Last 24 Hours
Monitoring > DASHBOARDS > DDoS > DNS Overview
  • DDoS DNS Summary - Last 24 Hours
  • DDoS DNS Summary - Current Attacks

By default, the Grafana process runs on the BIG-IQ system. As a result, the BIG-IQ versions listed in Versions known to be vulnerable column of the Status table in the previous section are vulnerable regardless of whether or not you use these affected DoS features.

If you are using these pages, please contact F5 Support for potential solutions.

If you are not using these pages, to mitigate this vulnerability, you can disable Grafana access by performing the following procedure:

Impact of action: Performing the following procedure disables the DoS and DDoS Monitoring pages.

  1. Use a text editor such as vi to edit the /etc/webd/webd.conf file. If using vi enter the following command:

    vi /etc/webd/webd.conf

  2. Enter i to enter insert mode.
  3. Using a # character, comment out the upstream grafana configuration block.

    For example:

    #upstream grafana {
    # server 127.0.0.1:3000;
    #}

  4. Using a # character, comment out the location /mgmt/grafana/ configuration block.

    For example:

    #location /mgmt/grafana/ {
    # proxy_pass http://grafana/;
    # proxy_set_header Host $hostname:$proxy_port;
    # proxy_set_header X-Real-IP $remote_addr;
    # proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    # proxy_connect_timeout 5s;
    # proxy_read_timeout 300s;
    # # completely disallow all access through the grafana data source proxy
    # # TODO: Move this to the /mgmt/ block after the auth proxy is in place
    # location /mgmt/grafana/api/datasources/proxy/ {
    # deny all;
    # return 404;
    # }
    #}

  5. If using vi, select ESC to exit insert mode.
  6. Save and close the file. If using vi, enter the following:

    :wq

  7. Restart the BIG-IQ webd web server by entering the following command:

    bigstart restart webd
