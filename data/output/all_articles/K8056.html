Known Issue

This is the result of a known issue. Local user accounts with console/SSH access enabled may not be properly migrated during a local upgrade from BIG-IP LTM 9.3.x to BIG-IP LTM version 9.4.1 or later.

Following the upgrade, the accounts are added to the /config/bigip.conf and /config/bigip/auth/user* files; however, the accounts are not added to the /etc/passwd and /etc/shadow files. For example, if you add a local user account called test-admin to the BIG-IP system versions 9.2.x through 9.3.x, and you save the UCS file prior to upgrading using the b config save /config.ucs command, and then perform a local upgrade to version 9.4.1 or later, the test-admin account is not migrated to the /etc/passwd and /etc/shadow files. In addition, console or SSH login attempts for the account will fail.

F5 Product Development is tracking this issue as CR85330.

Workaround

After upgrading the BIG-IP system to version 9.4.1 or later, you can work around this issue by forcing re-installation of all packages from the UCS files. To do so, type the following command:

im -force /var/local/ucs/config.ucs
