K7684: Large HTTP downloads cause Network Access to close if gzip compression and SSL Offload are enabled

Known Issue

This is the result of a known issue. Attempting a large HTTP download causes your Network Access connection to terminate. This issue occurs when the following two features are enabled:
  • SSL Offload on the FirePass Web Service
  • gzip compression on the Network Access resource

Note: This issue only occurs with HTTP downloads; it does not occur with other types of downloads, such as FTP or SAMBA.

F5 Product Development tracked this issue as CR77308 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-601-1 for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

To work around this issue, log on to the FirePass Administrative Console and clear the Use gzip compression check box on the Network Access : Resources page.
