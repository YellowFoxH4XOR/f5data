K20920315: Unable to upgrade BIG-IP VE as Service Check Date doesn't get updated (ELA)

Type
Support Solution
Published
2021-01-07
Updated
2025-02-10
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K20920315

Description

Unable to upgrade BIG-IP VE because Service Check Date has not updated.

  • The Utility license (ELA) key has expired.
  • The Utility license (ELA) key has not been reactivated from BIG-IQ.
  • BIG-IP upgrade fails with config load failure because of invalid or non-existent license.

Environment

  • BIG-IQ managed licenses
  • BIG-IP VE running a Subscription/Utility based license key (ELA).
  • License has expired or not been reactivated from BIG-IQ.

Cause

  • Expired Licenses should be renewed
  • Service Check Date should be updated prior to BIG-IP software upgrade

Recommended Actions

Check that the Utility license (ELA) key has not expired (See BIG-IQ GUI: Devices Tab -> License Management -> Licenses), then proceed with license reactivation:

  1. Select the checkbox for the Base Key
  2. Click "Reactivate" button
  3. Select the "Activation Method"
  4. Click "Reactivate"
    Note: This step will not impact BIG-IP and will simply update the license key on BIG-IQ
  5. Once all Offerings have been updated and status is "Active", the "Service Check Date" should now be up-to-date. 
    The following steps will relicense the BIG-IP:
  6. Select the "Offering Name" for the BIG-IP to be relicensed.
  7. Under "Assignments", select the checkbox for the BIG-IP Device Name.
  8. Click "Refresh"
  9. Confirm Refresh activity or enter the credentials for BIG-IP if prompted.
    Important: This final step will temporarily disrupt traffic on BIG-IP whilst the new license is installed.
If the license key has expired, please reach out to your F5 account manager to obtain a new license key.
