Known Issue

The logging profile configuration is updated excessively due to changes in the pool member state.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system has pool members configured with health monitors.
  • The pool members' availability state changes frequently over a period of time.

Impact

The logging profile configuration is updated every few seconds, causing unnecessary data plane processing.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H584730 on the Diagnostics > Identified > Low screen.
  • Messages are logged repeatedly to the /var/log/ts/dcc.log file, similar to the following example:

    [tsconfd::VirtualServerProfileMsgParser::handle_pool_member, ] ASM was notified about a change in pool: </Common/<pool_name>>[tsconfd::VirtualServerProfileMsgParser::end_transaction, ] Calling update mcp logging profile ...[PrepareFiles::prepare_core_files_update, ] executing PrepareCoreFilesUpdate...
  • Due to increased data plane processing, resource usage for the asm_config_server.pl process increases over time when observed using the top or ps utilities.
