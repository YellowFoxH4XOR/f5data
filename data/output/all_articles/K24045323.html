Description

Beginning in v12.0.0, GET requests will not be logged by restjavad by default.

Old Behavior

The restjavad dispatches iControl requests from httpd to various REST interfaces. In /var/log/restjavad.x.log logs, you will see GET request get logged:

[ChildWrapper] Timed out waiting for GET request at http://localhost:8100/tm/sys/software/status. Killing child process 21287
[ChildWrapper] Killing IcrdChild process 21287

New Behavior

Beginning in v12.0.0, GET requests are no longer logged by default.

Environment

  • BIG-IP
  • version 12.0 and above

Cause

There is no change in the default log level (INFO), but the INFO log level no longer logs GET requests.

Recommended Actions

To log GET requests, change the restjavad log level to FINE or FINEST. For more information, refer to K15436: Configuring the verbosity for restjavad logs on the BIG-IP system.

None
