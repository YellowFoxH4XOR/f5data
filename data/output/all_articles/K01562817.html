Description

  • An Error message is thrown when using the DIG command on the command line
  • No issues seen, DIG works fine, just the error
  • Error messages: 
Please disable either FIPS mode or MD5
err named[12059]: hmac_link.c:350: unexpected error:
err named[12059]: FIPS mode is 1: MD5 is only supported if the value is 0.

Environment

  • BIG-IP 
  • FIPS licence enabled
  • Running 'dig' command

Cause

The error is because named and bind-utils are compiled with support for MD5, which is not FIPS compliant. No ill effects seen or expected, its a cosmetic message

Recommended Actions

  • You may observe in certain usage, for example when entering the commands in an interactive shell, that this is a cosmetic error and you see a correct output. No action is required in such cases.
  • In some cases, for example when using the commands in a script, you observe that the final status of the command reports an error. This may affect the functionality of the script. If possible, modify the script appropriately to maintain its functionality.
