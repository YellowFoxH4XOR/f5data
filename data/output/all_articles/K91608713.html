Description

Force the BIG-IP to use the management interface to send SNMP traps.

Environment

  • SNMP traps
  • Management Interface
  • BIG-IP routing

Cause

The BIG-IP might use different outgoing interfaces to send the SNMP traps.

Recommended Actions

To configure the BIG-IP to use the management interface to send SNMP traps:

  1. Type this command from the BIG-IP command line:

    tmsh modify sys snmp trap-source <mgmt-IP>

  2. On the GUI, navigate to System  >  SNMP > Traps > Destination  > Create New Trap Record.

    The configuration option for Network, allows you to specify the network where the system will send the specified trap. Select the Management option to specify that the system sends the trap through the management interface.

    Important:  You must be able to route to the destination through that interface.

  3. Create a static route with your SNMP server as the destination host to direct SNMP traffic through the management interface.

    tmsh create /sys management-route <route_name> network <snmp_server_IP>/255.255.255.255 gateway <management gateway>

Additional Information

The configuration option Network specifies the trap network. Management: Specifies that the system sends the trap out of the management IP address (or the cluster management IP address, if this is a clustered configuration). Other: Specifies that the system sends the trap out of the interface based on the routing tables.

NOTE:  By default, the SNMP trap egresses from the TMM interface if the trap destination is accessible through Management and TMM interfaces. Also, if there is a TMM route and Management route to the same trap destination, the traps will always egress from the TMM interface and not through the Management interface. 

To look at the routing table for both Management and TMM, use the following command:

#netstat -nr
