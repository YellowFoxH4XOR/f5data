Topic

This article applies to BIG-IP 9.4.2 through 10.x. For information about other versions, refer to the following articles:

  • K13205: Configuring BIG-IP to resolve DNS hostnames  (11.x and later)

For the BIG-IP system to resolve hostnames used at the command line, you must either use the bigpipe command to add the hostnames to the BIG-IP system's /etc/hosts file, or use the bigpipe command or Configuration utility to add one or more DNS servers to the /etc/resolv.conf file, thus configuring the BIG-IP system as a DNS client.

Important: This article describes configuring the BIG-IP system as a DNS client. F5 does not recommend or support configuring BIND nameservices on the BIG-IP system for use as a resolver or forwarder by other client systems.

The BIG-IP system uses two sources of information to resolve hostnames: the hosts file and DNS. The BIG-IP system first refers to the local /etc/hosts file. If the hostname is not found in the /etc/hosts file, the BIG-IP system uses DNS, if it is  configured to do so.

Note: For information about configuring local host name resolution for BIG-IP 9.4.2 and later, refer to K8439: Configuring local hostname resolution for BIG-IP (9.4.2 to 10.x).

Note: For information about configuring DNS name resolution for BIG-IP 9.0.0 through 9.4.1, refer to K3624: Configuring BIG-IP to resolve DNS hostnames (4.5.x - 9.4.1).

You can configure DNS client name resolution from the command line or by using the Configuration utility.

Configuring the BIG-IP system as a DNS client from the command line

  1. Log in to the command line.
  2. Determine the DNS server(s) IP address(es) that you want to define on the BIG-IP system.

    Note: You can test the DNS server(s) that you want to define on the BIG-IP system by typing the following command:

    dig @<DNS_Server_IP_Address>

    If the test is successful, a list of the root name servers are displayed.

  3. Type the following command to define the DNS server(s) on the BIG-IP system.

    bigpipe dns nameservers <DNS_Server_IP_Address> add

    For example, if you want to add the DNS name servers IP addresses of 192.168.10.20 and 192.168.10.22 to the BIG-IP system, you would type the following command:

    bigpipe dns nameservers 192.168.10.20 192.168.10.22 add

  4. Save the changes by typing the following command:

    bigpipe save

The local /etc/resolv.conf file is now configured with the following entries:

nameserver      192.168.10.20
nameserver      192.168.10.22

Removing the configured nameservers from the command line

  1. Log in to the command line.
  2. Type the following command to remove DNS server(s) from the BIG-IP system configuration.

    bigpipe dns nameservers <DNS_Server_IP_Address> delete

    For example, if you want to remove the DNS name servers IP addresses of 192.168.10.20 and 192.168.10.22 from the BIG-IP configuration, type the following command:

    bigpipe dns nameservers 192.168.10.20 192.168.10.22 delete

  3. Save the changes by typing the following command:

    bigpipe save

Note: Starting in BIG-IP 9.4.2, /etc/resolv.conf is an auto-generated file and should not be manually edited.

Testing DNS name resolution

To test DNS name resolution, use the following command syntax, replacing <DNS_name> with the DNS name of a server on your network:

host <DNS_name>

For example:

host www.askf5.com

If the test is successful, you will receive a response that appears similar to the following example:

www.askf5.com has address 10.90.101.200

If the test is not successful, you will receive a response that appears similar to the following example:

Host www.askf5.com not found: 3(NXDOMAIN)

Configuring the BIG-IP system as a DNS client using the Configuration utility

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click General Properties (click Configuration in BIG-IP version 10.x).
  4. Select DNS from the Device drop-down menu.
  5. To configure a DNS Lookup Server List, enter the DNS server(s) in the Address field.
  6. Click Add.
  7. Click Update.
