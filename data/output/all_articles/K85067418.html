Known Issue

Adding servers to the BIG-IP Edge Client exclusion list may fail.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system with a connectivity profile that is set with Enable Always connected mode (locked mode).
  • You modify the exclusion list of the Windows Client Package package download.
  • You enter a DNS server name that includes the underscore ( _ ) character.

Impact

The addition of the server to the exclusion list fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to add the server to the exclusion list, you view the following error message:

    Please correct errors below

    Allowed symbols are letters, digits,:,- and dots

Workaround

To work around this issue, you can add the DNS server to the Windows registry editor (regedit) of the affected system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the affected Windows system using an account with privileges to edit the registry for the users on the system.
  2. Click the Start menu.
  3. Select Run.
  4. In the Open window, type the following:

    regedit

  5. Click OK.
  6. In the navigation pane of the Regedit program, click the plus icon ( + ) next to HKEY_LOCAL_MACHINE.
  7. Click the plus icon next to SOFTWARE.
  8. Click the plus icon next to Classes.
  9. Click the plus icon next to Wow6432Node.
  10. Click the plus icon next to F5 Networks.
  11. Click the plus icon next to RemoteAccess.
  12. Click the plus icon next to AlwaysConnected.
  13. Click the plus icon next to Exclusions.

    Note: The full Regedit path is Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Classes\Wow6432Node\F5 Networks\RemoteAccess\AlwaysConnected\Exclusions\.

  14. From Edit > New > Key, enter the fully-qualified domain name (FQDN) of the DNS server you want to exclude as the new key name.
  15. Close the Regedit program.
