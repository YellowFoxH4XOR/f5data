Known Issue

The Traffic Management Shell (tmsh) list command may not filter LTM nodes correctly.

This issue occurs when the following condition is met:

  • You attempt to filter LTM nodes using tmsh list /ltm node command

Impact

The system does not apply the filter, and returns incorrect results.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh list /ltm node command does not filter correctly.

    For example, the output of the tmsh list /ltm node 10.21.19.* one-line command displays all of the nodes when you attempt to display nodes only with 10.21.19.* prefixes:

    ltm node 1.1.1.1 { address 1.1.1.1 }
    ltm node 1.1.1.2 { address 1.1.1.2 }
    ltm node 10.21.19.93 { address 10.21.19.93 }
