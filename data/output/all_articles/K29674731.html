Issue

Error Message

01c80027: CONNECTOR: Cannot allocate memory for <service connector>

In this error message, note the following:

  • <service connector> is the name of the service connector object.

For example:

01c80027: CONNECTOR: Cannot allocate memory for L2 inline

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The Traffic Management Microkernel (TMM) is out of memory when allocating memory to the service connector.

Impact

The system behaves in a degraded condition if it is out of memory.

Recommended Actions

Look for processes consuming excessive memory and consider restarting those processes. You might need to reboot or restart the system depending on the process that is consuming the memory.

Viewing TMM memory allocation

You can view the memory allocated to each of the TMM memory subsystem objects. To do so, use one of the following methods:

  • In the TMOS Shell (tmsh), use the show sys memory command.
  • In the Configuration utility, go to Statistics > Module Statistics > Memory.

For more information about BIG-IP system memory, refer to K16419: Overview of BIG-IP memory usage.
