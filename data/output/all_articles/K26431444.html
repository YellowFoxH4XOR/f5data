K26431444: Error statsd 'unknown DS name' eisdeduinuses' during rrd_update

Applies to

  • BIG-IP LTM: 12.1.3
Source
https://my.f5.com/manage/s/article/K26431444

Description

Administrator sees repeated logging of

Error 'unknown DS name 'eisdeduinuses'' during rrd_update for rrd file '/var/rrd/endpisession'

Environment

  • Multiblade Viprion

Cause

One of the blades has a rrd/rrd.info file in /var/rrd or /shared/rrd.1.2.perm that was created when AAM was not licensed. That file kept is copied into /var/rrd on the primary blade, causing statsd to log that message about the missing data source, eisdeduinuses.

Recommended Actions

  1. bigstart stop statsd
  2. Ensure it stopped
    1.     # bigstart status statsd
  3.  Remove endpisession and endpisession.info from /var/rrd on all blades and also from /shared/rrd.1.2.perm on all blades. Then start statsd on slot 1 if it's still stopped.
    1.  rm -f /var/rrd/endpisession /var/rrd/endpisession.info
    2.  rm -f /shared/rrd.1.2.perm/endpisession /shared/rrd.1.2.perm/endpisession.info
