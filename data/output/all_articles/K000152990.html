Topic

Beginning in F5 Access for MacOS 2.1.1 Build: 401 and MacOS 15.5, you can enable DNS proxy service in split tunnel configuration in BIG-IP APM network access.

This article describes the DNS proxy service functionality of F5 Access on MacOS. For the DNS relay proxy service on Windows, refer to K72735781: DNS relay proxy service functionality on Windows.

Description

The F5 Access DNS proxy runs as a service on MacOS. It provides the following functionality:

  • It enforces DNS search order on accounts with limited privileges on the MAC system.
  • It implements DNS scope when the network access is configured with split tunneling, using the DNS address space and DNS Exclude Address Space settings.

Logging

The DNS relay proxy logs its activities in the following log file:

  • /var/root/Library/Group Containers/57P38MF5GS.group.com.f5.access.macos/DNSProxy.log

Functionality

In BIG-IP APM network access, the system can analyze DNS request resolution by determining the following criteria:

  • DNS requests are routed to the VPN tunnel or outside of the tunnel.
  • DNS requests are sent to the client's locally configured DNS server or to the DNS server configured in BIG-IP APM network access.

To determine this, the DNS relay proxy relies on the following settings that you configure in your BIG-IP APM network access:
Note: To navigate to the following settings, go to Access > Connectivity/VPN > Network Access (VPN) > Network Access Lists, select your network access object. Select Network Settings and Advanced.

  • DNS Exclude Address Space
  • Allow Local DNS Servers
  • IPv4 LAN Address Space
  • DNS Default Domain Suffix

DNS Exclude Address Space

When you configure a domain name in the DNS Exclude Address Space, the DNS proxy attempts to resolve the names you defined in the exclude address space to an IP address using the client's locally configured DNS server.

The DNS proxy adds the resolved IP addresses to the clients route table, thereby routing requests destined for the those IP addresses outside the VPN tunnel.

For example, if you add docs.example.com in the DNS Exclude Address Space configuration, the system routes the DNS request to the client's locally configured DNS server and adds the resolved IP address 192.0.2.2 to the client's route table. To display the route table, enter the netstat -rn command at the MAC command prompt.

Allow Local DNS Servers

When you enable the Allow Local DNS Servers setting, DNS proxy directs DNS requests included in the DNS Exclude Address Space to the client's local DNS server. This is achieved by adding a route in the route table of the client system. As a result, the DNS requests destined for the client's local DNS servers do not enter the VPN tunnel.

IPV4 LAN Address Space

You configure a list of internal IP addresses or internal network addresses in this setting. Any traffic destined for the address(s) in this setting does so through the VPN tunnel.

DNS Default Domain Suffix

You configure a list of DNS suffixes here to append to the name of DNS queries.

Additional Information

Current Limitations

Mac F5 Access DNS Proxy supports only the Primary DNS server in the Network Access configuration. All DNS resolution through the VPN tunnel is performed exclusively through this DNS server. To verify the primary DNS server, refer to the IPV4 Primary Name Server setting on the DNS/Hosts tab of your Network Access configuration.

Configuration requirements

To enable DNS Proxy functionality, you must activate the following system extension as follows:

  • Extension Identifier: 57P38MF5GS
  • Bundle ID: com.f5.access.macos.DNSProxy

Note: The following procedure may differ with different MacOS versions.

  1. Launch or open F5 Access 2.1.1 for the first time. On the pop-up dialog, select Open System Settings.
     
  2. Enable F5Access DNSProxy.
       
  3. Enter your credentials when authenticated to apply the change.
      
  4. Verify F5Access DNSProxy is enabled.
       

MDM Configuration

If you are using Mobile Device Management (MDM) to manage the VPN profile, you must:

  • Include the DNS Proxy system extension in the VPN profile.
  • Push the updated profile to the target macOS devices.
