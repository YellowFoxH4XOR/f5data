Known Issue

The BIG-IP system may deny console login access when a remotely authenticated user attempts to access the console.

This issue occurs when the following condition is met:

  • The system is configured to use remote authentication, and a remotely authenticated user attempts to access the console.
This issue affects only console access, but the BIG-IP system still allows a secure shell (SSH) login to the remote authenticated user.

Impact

You are unable to log in to the console.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A remotely authenticated user cannot log in to the BIG-IP system console.
