Known Issue

The database for the IP Address Intelligence Service feature cannot be updated.

The IP Intelligence Service feature introduced in BIG-IP ASM 11.2.0 allows an administrator to block requests that originate from black-listed IP addresses, which are updated by a subscription process. Due to a compatibility issue with the external supplier of the IP address information, the subscription process is unable to update the local database of IP addresses.

Impact

The IP Intelligence Service has no database of IP addresses.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • There is no F5IpRep.dat file in the /var/IpRep directory.
  • Messages that appear similar to the following log entry excerpt are written to the /var/log/iprepd/iprepd.log file:

    |7682|   Checking at 06/08/2012 14:21:09...
    |7682|   0 IPs loaded in 0.05 secs
    |7682|   No update available, managing 0 Threats
