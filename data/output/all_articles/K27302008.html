Description
When attempting to update an expired certificate, the task fails because the /shared filesystem is at 100% capacity. Several upload_xxxxxxxxxxx.dat files > 100 MB are found in the /shared/images folder.

Environment
  • BIG-IP
  • Certificate update
     
Cause
The failure cause is the /shared filesystem is at 100% capacity.

Recommended Actions
Search for and delete large .dat files using the following steps.
  1. Log on to the command line of the BIG-IP device.
  2. Change directories to the /shared directory: 
    cd /shared
     
  3. Run the following command to locate large files: 
    du -sh `ls`| sort -n | egrep '[0-9]G|[0-9]M'

    Note: Delete the large upload_<filename>.dat files listed in the command output: 
    rm -f upload_*.dat
