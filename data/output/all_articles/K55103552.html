Description
On a standby BIG-IP system, an ephemeral pool-members state remains user-down after re-enabling an FQDN node on the primary system.

Environment

  • BIGIP
  • FQDN

Cause
This is caused by a known Bug ID 714642

Recommended Actions

We recommend you upgrade to the fixed versions in 16.1.0, 16.0.1.1, 15.1.2, 14.1.4, 13.1.3.6, per the Bug Tracker article linked below.
Bug ID 714642: Ephemeral pool-member state on the standby is down

You could also consider the below,
  1. Manually disabled, and enabled all affected Nodes in pools, and kept one enabled at all times.
  2. Sync to ACTIVE.
Note: The above workaround could be work for specific case only, we highly recommend to software upgrade to fix the issue.
