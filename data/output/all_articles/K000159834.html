K000159834: BIG-IP ASM Installation of Automatically Downloaded Updates changes from Real Time to Disabled

Description

BIG-IP ASM Live Update is configured to automatically install signature updates in real-time, but the installation mode repeatedly reverts from Real Time to Disabled

  • Automatic downloads of Live update files work correctly, but installations do not occur
  • Manual installation of Live updates works as expected
  • Tomcat service shows high restart frequency
  • The following messages are observed in the /var/log/tomcat/catalina.out file
    SEVERE: The web application [/tmui] registered the JDBC driver [com.mysql.jdbc.Driver] but failed to unregister it when the web application was stopped. To prevent a memory leak, the JDBC Driver has been forcibly unregistered.

 

Environment

BIG-IP ASM
Automatic installation of Live Update files
Management provisioning (provision.extramb) set to 2048 MB
Tomcat extra memory allocation (provision.tomcat.extramb) set to 0 MB (default value)

 

Cause

Insufficient memory allocation to the tomcat process.

 

Answer/Recommended Actions

  1. Configure provision.tomcat.extramb to allocate 256 MB of additional memory
    tmsh modify /sys db provision.tomcat.extramb value 256

  2.  Restart the tomcat process
    tmsh restart sys service tomcat
