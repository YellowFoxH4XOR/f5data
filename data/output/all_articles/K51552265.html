Description

While upgrade, the BIG-IP fails to load the configuration.

The following errors appears in /var/log/ltm:

err mcpd[7482]: 01071dc9:3: BIG-IP doesn't support using a '#' in the TACACS secret.
err tmsh[11547]: 01420006:3: Loading configuration process failed.
emerg load_config_files[11544]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Loading schema version: 14.1.4
err mcpd[7482]: 01070425:3: Full configuration load failed.
  • Already followed troubleshooting steps from:
    K12304: The TACACS+ secret key with the number sign (#) cause failure for all administrative accounts (root/admin).

Environment

  • BIG-IP
  • TACACS configuration
  • Upgrade performed from versions 14.x or 15.x to  version 16.x

Cause

Unable to load the configuration with TACACS configuration. Even the TACACS+ secret key do not contain the number sign (#).

Recommended Actions

  1. Delete TACACS configuration in bigip.conf
    tmsh delete auth tacacs all
    tmsh save sys config
  2. Verify Configuration before load configuration
    tmsh load sys config verify
  3. After upgrade, recreate the TACACS configuration with following article:
    K8811: Configuring TACACS+ authentication for BIG-IP administrative users
