K08715712: Network monitoring software reports blade temperatures as out of range or critical

Type
Support Solution
Published
2019-09-24
Updated
2023-02-21
Applies to
  • VIPRION Platforms
Source
https://my.f5.com/manage/s/article/K08715712

Description

Network monitoring software reports temperatures as out of range or critical.

Environment

  • VIPRION blade
  • Network monitoring software

Cause

Network monitoring software is polling for current temperature values and alert limits are incorrectly set too low in the software.

Recommended Actions

To avoid false positive alerts, configure the alert limits to an appropriate value in the network monitoring software.

Review the output of the tmctl -w 300 blade_temperature_status_stat command to determine the hi_limit value at which the BIG-IP takes action for each temperature sensor.

Additional Information

The system uses an SNMP script, system_check to gather temperature information. This is described in further detail in the following article:

  • K4026: BIG-IP platforms support SNMP monitoring for chassis fan speed, chassis temperature, CPU temperature, and power supply status

When SNMP trap destinations are configured, the system will automatically send an SNMP trap if a temperature hi_limit is reached. This is independent of polling by network monitoring software.

To review action taken by the system when a hi_limit is reached, review the output of the tmctl -w 300 sensor_limit_table command.

For example, the following output indicates that when the bld_inlet_temp_1 sensor reaches 48c, the system will broadcast at the command line, trigger a critical alarm, log to a file, run all fans on full, and shutdown the system.
