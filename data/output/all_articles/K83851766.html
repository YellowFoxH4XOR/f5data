Description
Device is showing offline and then standby. This is as a result of partition /var being  filled up by temporary TMSH files.

Environment

  • BIG-IP
  • ASM

Cause
Bug ID 969345

Recommended Actions

  1. Per Bug ID 969345, the workaround is manually delete files in /var/system/tmp/tmsh 
  2. Depending on how fast /var is filling up by these tmp files, you may need to use a script to delete them, possibly running the script every hour from cron.

Additional Information
At the moment there is no fix to this BugID
