K94803200: Error ''cannot update (cache_path)'' when loading a SCF with tmsh merge

Type
Support Solution
Published
2022-02-04
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K94803200

Description

When creating a SCF backup there are several cache-paths that will be created as place holders in the new configuration. 
When merging one SCF configuration with another configuration that has the same existing objects - cache-paths will currently exist causing a similar error:
01070712:3: file:(/Common/full_webtop_customization:webtop_popup.css) cannot update (cache_path).
Unexpected Error: Validating configuration process failed

Environment

  • BIG-IP APM
  • SCF files
  • tmsh merge command

Cause

The reason for this error is that the items already exist as well as their cache-path.

Recommended Actions

Before merging the SCF file into your configuration, modify existing cache-path items with local-path
Note: The only items that will be changed to local-path are existing objects, new objects will need to keep the current cache-path entry in the SCF file.

  1. Open the SCF file via VI:
    vi test_scf
     
  2. Find the items that currently exist in your configuration and replace cache-path with local-path.

    For Example from this:
    apm policy customization-group /Common/apm_act_decision_box_two_ag {
        cache-path /config/filestore/files_d/Common_d/customization_group_d/:Common:apm_act_decision_box_two_ag_65586_3
        revision 3
        source /Common/modern
        templates {
            user-decision.css {
                cache-path /config/filestore/files_d/Common_d/customization_template_d/:Common:apm_act_decision_box_two_ag::user-decision.css_65600_1
                name /Common/apm_act_decision_box_two_ag:user-decision.css
                revision 1
            }
            user-decision.js {
                cache-path /config/filestore/files_d/Common_d/customization_template_d/:Common:apm_act_decision_box_two_ag::user-decision.js_65597_1
                name /Common/apm_act_decision_box_two_ag:user-decision.js
                revision 1
            }
        }
        type decision-box
    }

    To This:
    apm policy customization-group /Common/apm_act_decision_box_two_ag {
        local-path /config/filestore/files_d/Common_d/customization_group_d/:Common:apm_act_decision_box_two_ag_65586_3
        revision 3
        source /Common/modern
        templates {
            user-decision.css {
                local-path /config/filestore/files_d/Common_d/customization_template_d/:Common:apm_act_decision_box_two_ag::user-decision.css_65600_1
                name /Common/apm_act_decision_box_two_ag:user-decision.css
                revision 1
            }
            user-decision.js {
                local-path /config/filestore/files_d/Common_d/customization_template_d/:Common:apm_act_decision_box_two_ag::user-decision.js_65597_1
                name /Common/apm_act_decision_box_two_ag:user-decision.js
                revision 1
            }
        }
        type decision-box
    }
     
  3. You can test the configurations integrity before loading it to see if there will be any other objects that may need to be updated with:
    tmsh load sys config file test_scf merge verify
