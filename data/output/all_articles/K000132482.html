Your BIG-IP device is displaying console, log or Configuration utility (gui) warning messages about /var capacity similar to the following.
 

  • UCS file restore fails with "/var/local/ucs/config.ucs: Not enough free disk space to install!"
  • Console broadcast message: 011d0004:3: Disk partition /var (slot 2) has only X% free
  • err diskmonitor[15433]: 011d0004:3: Disk partition /var (slot 1) has only X% free
  • bigipDiskPartitionWarn Disk partition /var has only X% free
Note: X represents a numeric value.

Alternatively, you notice that the /var partition is highly utilized when running the following command line command:

df -h

Environment

  • BIG-IP

 

Cause
Many files are created and stored in the /var partition and the most common cause of excessive utilization is retaining many and/or large UCS and SCF archives on the BIG-IP device. A typical scenario is when UCS archives are automatically generated and not sufficiently monitored.

 

Recommended Actions
You can run the following command stanza to identify the top 25 large files stored in the /var partition.
 

find /var/ -xdev -type f -exec du {} \; | sort -rn | grep -Ev $(mount | awk '/\/var\// {print $3}' | sed -e :a -e N -e 's/\n/|/' -e ta) | head -25

Review the list of files presented from the command locating files that are in the directories /var/ucs and /var/scf. To remove all the files located in the /var/ucs and /var/scf directories use the following commands:

rm -f /var/ucs/*.ucs
rm -f /var/scf/*.scf

To remove specifically identified files, enter the following command replacing <filename> with the directory path and filename listed to the right of the file size.

rm -f /var/ucs/<filename>
rm -f /var/scf/<filename>
