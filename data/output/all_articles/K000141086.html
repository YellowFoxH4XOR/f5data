Description

Will updating ASM attack signatures have a negative impact on traffic?

Environment

  • BIG-IP ASM
  • Attack Signatures

Cause

You want to install new signatures and update existing signatures to ensure that your applications are protected against new attacks.

Recommended Actions

Review the following: When attack signatures are updated, NEW signatures are placed in staging (non-blocking) while UPDATED signatures are placed in staging if Updated Signature Enforcement is set to Retain previous rule enforcement and place updated rule in staging. You can find this setting on the Learning and Blocking Settings page.

When attack signatures are in staging, the system applies the attack signatures to application traffic, but does not block any requests that trigger those attack signatures. The staging period allows you to reduce the number of false positive violations because when signatures match attack patterns during the staging period, the system generates learning suggestions. You can view the learning suggestions, and, if you see that an attack signature violation has occurred, you can select the violation to see details about it and decide what to do. So there is no negative impact if new and updated signatures are placed in staging first.

After the staging period (Enforcement Readiness Period) the system will indicate that the signatures are ready to be enforced. If the policy is set to automatic learning mode the signatures will be automatically enforced.
