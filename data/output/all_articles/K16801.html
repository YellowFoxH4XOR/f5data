Known Issue

The BIG-IP system may fail to process highly fragmented Secure Sockets Layer (SSL) records correctly and may prematurely terminate the SSL connection.

This issue occurs when all of the following conditions are met:

  • The BIG-IP platform contains a Cavium Nitrox SSL accelerator card.

    Note: This issues does not affect the BIG-IP 1000, 2400, 51x0, 2000s, 2200s, 4000s, and 4200v platforms. All other current BIG-IP platform models are equipped with Cavium Nitrox SSL or hardware compression hardware.
  • The negotiated SSL cipher used for the connection is an AES-GCM cipher.
  • The BIG-IP system is processing SSL connections with highly fragmented SSL records.

Impact

The BIG-IP system disconnects SSL connections prematurely.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system disconnects SSL connections prematurely.
  • The SSL profile statistics show a significant number of bad records for the affected virtual server.
