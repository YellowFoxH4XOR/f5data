Known Issue

The BIG-IP APM apd process may exit and produce a core file when processing access profiles with Tool Command Language (Tcl) expressions.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured with a large number of Tcl expressions that reference session variables.
  • The BIG-IP APM system is processing the access profile while an administrator is making changes to the associated access policy.

Impact

The BIG-IP APM system temporarily fails to process traffic while it recovers from the apd process restarting.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are temporarily unable to access resources using the BIG-IP APM system.
  • An apd core file is generated to the /shared/core directory.
