Known Issue

This is the result of a known issue. The marketing name is displayed incorrectly for VIPRION platforms.

The marketing names for F5 platforms are mapped via the /etc/hal/MARKETING-NAMES file, and a Bill of Materials (BOM) number stored in EEPROM on the hardware. The mcpd process reports that the BOM number is empty for VIPRION platforms. As a result, when you execute the bigpipe platform command, the output incorrectly indicates that the marketing name for the VIPRION system is either A100 or A107 (depending on whether the command is run on a PB100 or PB200 VIPRION blade).

The command output displays similar to the following examples:

PLATFORM INFORMATION --
|     Marketing Name: A100
|     BIOS revision: LinuxBIOS 2.0.0 OBJ-0235-07 REV. A build 470
|     base MAC: 00:01:D7:81:4A:00
|     Physical memory: 8.000GB

PLATFORM INFORMATION --
|     Marketing Name: A107
|     BIOS revision: OBJ-0315-00 - Build: 90006
|     base MAC: 00:01:D7:56:16:00
|     Physical memory: 15.70GB

Note: This is a cosmetic issue and does not affect system performance.

F5 Product Development tracked this issue as ID 222740 (formerly CR123891), and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM, ASM, or PSM release notes.
