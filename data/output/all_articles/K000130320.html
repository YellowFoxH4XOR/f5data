K000130320: ASM not displaying attack signature rule in GUI

Source

Description

Whenever a high ASCII character (>127 or >7F) is used in Signature rule syntax (Advanced Mode) then the rule is no longer available when tried to modify.

Environment

  • BIG-IP ASM
  • Attack Signatures
  • Configuration Utility
  • ASCII Characters

Cause

BUG ID1210569 . json_encode() function returning the invalid value for high ASCII characters.

Recommended Actions

As a workaround whenever signature rule syntax needs to be edited, it can be done in the following way:

 

1. Check the current rule syntax in mysql, e.g. by running:

 

mysql -E -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e "select sig_id,sig_name,rule from PLC.NEGSIG_SIGNATURES where (sig_id like 300000000);"

just replace the sig_id number in above mysql query.

 

2. In GUI create new signature and in Advance Edit Mode paste a modified rule syntax.

 

3. Add a new signature to appropriate signature set.

 

4. Delete the old signature from signature set.
