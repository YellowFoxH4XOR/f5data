Issue

BIG-IP ASM may log the following error message when processing legal requests:

Complete Violation details not available - system limit exceeded

Note: The error message is logged to the Reporting screen in BIG-IP ASM 9.4.4 and later, and the Requests screen in BIG-IP ASM 9.4.2 and 9.4.3.

This issue occurs when the BIG-IP ASM security policy processes a legal request that generated a large number of tightening suggestions.

For example, if your BIG-IP ASM 9.4.4 security policy contains a wildcard parameter with tightening enabled, and the BIG-IP ASM processes a legal POST request with a large number of parameters, the error message is visible under Application Security > Reporting > Requested Object.

Note: The exact number of parameters required to trigger this behavior is dependent on the length of the parameter names and the details that must be stored in order to generate the tightening suggestions.

F5 Product Development is tracking this issue as CR112656.
