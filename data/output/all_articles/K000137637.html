Description

The BIG-IP device rebooted unexpectedly.

Environment

  • BIG-IP
  • Unexpected reboot

Cause

  • Many reasons

Recommended Actions

We recommend to check the below logs when you have unexpected reboot.

  • /var/log/ltm.* : This log shows what had happend most of the time.
  • /var/log/audit.* : This log shows user activity.
  • /var/log/sel* : This log shows hardware side matter in iSeries platform.

e.g.

/var/log/ltm: notice sod[]: 010c0044:5: Command: reboot enable all GUI. <--- This indicate user rebooted from GUI. Who actually rebooted can be checked in

/var/log/audit: syscalld[]: 01070417:6: AUDIT - user <username>- RAW: Request to run /usr/bin/cmd_sod reboot enable all GUI. <---- <username> rebooted on GUI.

If you are unable to find any relevant log messages, run an EUD test to check for hardware faults.

  • K7172: Overview of the End User Diagnostics software
  • Running the EUD Tests

After you run the EUD test, check for any failures. If yes, contact F5 Support.
