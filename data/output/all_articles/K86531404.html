Description

There is a difference when comparing these two outputs:

  • GUI: Statistics >> Module Statistics : Local Traffic. Under Statistics Type, select Pools.  Refer to the Connections >> Current column.
  • CLI:  tmsh show sys connection | grep <pool member ip and port>

Environment

  • Statistics
  • Connection table

Cause

This is expected. Using show sys connection without additional filters returns 1000 connections maximum from the entire connection table. This will likely not include all connections to the pool member(s) in question.

[root@v14:Active:Standalone] config # tmsh show sys connection

Really display 1000 connections? (y/n)

Recommended Actions

Specify additional filters when querying the connection table. For example:

tmsh show sys conn ss-server-addr <pool member ip> ss-server-port <pool member port>

For more information, refer to:

  • K53851362: Displaying and deleting BIG-IP connection table entries from the command line
