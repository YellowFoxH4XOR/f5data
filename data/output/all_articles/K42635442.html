Known Issue

The f5 Pre-Logon User temporary local user may be recreated at every execution of the CustomDialer component.

This issue occurs when the following condition is met:

  • The BIG-IP APM system is configured for Windows Logon Integration with the "Enforce access policy execution" option selected.

The f5 Pre-Logon User temporary local user is created and deleted for each use to prevent domain operations such as adding that user to a specific domain group or setting the user properties as its SSID changes every time.

Impact

Administrators cannot enforce policies for the f5 Pre-Logon User temporary local user.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Administrators cannot enforce policies for the f5 Pre-Logon User temporary local user.
