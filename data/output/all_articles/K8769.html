Known Issue

This is the result of a known issue. If a virtual server that is enabled for BIG-IP WebAccelerator is also configured to use the universal persistence (UIE) profile, the BIG-IP WebAccelerator responds to all client requests with an HTTP 503 Service Unavailable message. Each time this occurs, the following messages is logged to the /var/log/wa/pvac.log file:

WA ERROR: Circular HTTP request loop detected - check your application host mappings.

The BIG-IP WebAccelerator will continue to respond with HTTP 503 Service Unavailable messages until the BIG-IP WebAccelerator process is manually restarted. If the universal persistence profile is removed, but the process is not restarted, the problem will persist.

F5 Product Development tracked this issue as CR100374 for the version 9.x software branch. Due to a change in architecture, the 10.x branch is not affected by this issue.

Workaround

You can work around this issue by restarting the BIG-IP WebAccelerator process after first removing the universal persistence profile from the virtual server. To restart the BIG-IP WebAccelerator process, perform the following procedure:

Important: Restarting the pvac daemon will briefly disrupt connections and invalidate objects in the BIG-IP LTM RAM Cache. Restarting the pvac daemon should be scheduled accordingly.

  1. Log in to the command line.
  2. Stop the BIG-IP WebAccelerator process by typing the following command:

    bigstart stop pvac
  3. Start the BIG-IP WebAccelerator process by typing the following command:

    bigstart start pvac

Important: Restarting the BIG-IP WebAccelerator process using the bigstart restart pvac command does not restore service to the virtual server.
