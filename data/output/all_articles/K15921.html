Known Issue

Single BIG-IP GTM topology records cannot be viewed or modified using the iControl representational state transfer (REST) application programming interface (API). It is only possible to list full sets of BIG-IP GTM topology records.

Attempts to list or modify single BIG-IP GTM topology records result in the following error message:

{
"code": 403,
"errorStack": [],
"message": "Operation is not supported on component /gtm/topology."
}

Impact

Administrators are unable to remotely manage BIG-IP GTM topology records using the iControl REST API.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The iControl REST client will return a 403 error message when attempting to list or modify single BIG-IP GTM topology records.
