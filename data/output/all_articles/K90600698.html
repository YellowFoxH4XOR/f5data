Description

Unable to restore UCS on a BIG-IP system after RMA.

UCS restore failing on an old BIG-IP version:
# tmsh load sys ucs /var/local/ucs/Config_Backup.ucs no-license no-platform-check
Replace all configuration on the system? (y/n) y
Processing UCS file: /var/local/ucs/Config_Backup.ucs
grep: /var/tmp/install_all/config/ucs_version: No such file or directory
Installing full UCS () data, excluding license file.
grep: /var/tmp/install_all/config/ucs_version: No such file or directory
The hostname is set to default
Extracting manifest: /var/local/ucs/Config_Backup.ucs
Fatal: executing: /bin/sh -c tar -zxf /var/local/ucs/Config_Backup.ucs -C /var/tmp/.install_ucs 2> /dev/null
Operation aborted.

Environment

  • BIG-IP v11.5.4
  • New appliance after RMA.
  • Adding the new appliance to a device group and pushing the shared configuration to the replacement BIG-IP device does not work.

Cause

Wrong format of the UCS file.

Recommended Actions

Extract the UCS archive to a temporary folder, then repack the files into a new UCS archive.

  1. Access BIG-IP command line

  2. Create a temporary folder:
    mkdir /var/tmp/ucs

  3. Extract the UCS in that folder:
    tar -zxf <location_and_filename>.ucs -C /var/tmp/ucs

  4. Move to the temporary directory
    cd /var/tmp/ucs

  5. Repack all the files back into a UCS
    tar -czpf /var/tmp/Config_Backup_Repacked.ucs *

  6. Delete the temporary UCS folder.
    rm -rf /var/tmp/ucs

Now attempt the UCS reload again:
    tmsh load sys ucs /var/tmp/Config_Backup_Repacked.ucs no-license no-platform-check
