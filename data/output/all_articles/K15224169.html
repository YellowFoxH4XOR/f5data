Description

You need to send restnoded and restjavad-audit* logs to a remote syslog server.

Environment

  • BIG IP
  • Remote syslog logging server 

Cause

Logs from restjavad are not included with syslog by default.

Recommended Actions

Performing the following procedure will configure syslog to send restjavad, restnoded and restjavad-audit logs to a remote syslog server:

  1. Log into tmsh with the following command:
    tmsh
  2. Use the following syntax to add an include statement. Replace {<udp or tcp>(<IP address> port (<port>)); with your values:
    modify /sys syslog include "source s_restjavad {file(\"/var/log/restjavad.0.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));file(\"/var/log/restjavad-audit.0.log\"follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));file(\"/var/log/restnoded.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));};destination remote_server {<udp or tcp>(<IP address> port (<port>));};filter f_alllogs {level (debug...emerg);};log{source(local);source(s_restjavad);filter(f_alllogs);destination(remote_server);};"

    This is the multi-line view of the syslog configuration that you add with the previous tmsh command:
    include "
    source s_restjavad {
    file(\"/var/log/restjavad.0.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));
    file(\"/var/log/restjavad-audit.0.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));
    file(\"/var/log/restnoded.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));
    };

    destination remote_server {
    <UDP or TCP>(<IP> port (<port>));
    };

    filter f_alllogs {
    level (debug...emerg);
    };

    log{
    source(local);
    source(s_restjavad);
    filter(f_alllogs);
    destination(remote_server);
    };

    "
  3. Save the configuration with the following command:
    save /sys config
  4. If necessary you can restart the syslog-ng service by typing the following command:
    restart /sys service syslog-ng
    Note: Logging is disrupted when syslog-ng restarts.
