K13614065: Error Message: 010e0999:4: Duplicate oid index found: bigip_if.c:374

Description

You may get the following error message on a VIPRION platform. For example:

warning snmpd[7592]: 010e0999:4: Duplicate oid index found: bigip_if.c:374

Environment

  • VIPRION
  • SNMP

Cause

Duplicate if-index are assigned to the interfaces of non-existing blades, and these old configurations may be left in mcpd database, so snmpd process reports a warning for such duplicate OIDs.

Recommended Actions

The messages are benign and you can safely ignore them.  The duplicate if-index configuration may look like this:

net interface 3/1.1 {
    if-index 0
net interface 3/1.2 {
    if-index 0

You may summarize and sort up all the duplicate if-index. In the following example, there are 8 duplicate interfaces with if-index value of 0.

tmsh list /net interface all-properties -hidden | grep if-index | sort -n | uniq -c | sort -nr | head 

8     if-index 0               
1     if-index 98
1     if-index 97

 

To workaround the issue, you can run this command to get all the interface config to a .txt file.

tmsh list /net interface all-properties > /var/tmp/interfaces.txt 

 

Now you can open the file /var/tmp/interfaces.txt using an editor like nano or vi. Or you can copy this file out using winSCP and use notepad and search for "if-index 0"  and get the name of the interfaces.

 

Once you have the interface names, in BigIP webUI go to Network > Interfaces > Interface List and disable the interfaces that you got in the previous step.
