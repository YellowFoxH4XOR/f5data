Known Issue

When using separate RADIUS authentication and accounting servers, the RADIUS accounting stop message is not sent to the RADIUS authentication server when the user session ends.

F5 Product Development tracked this issue as ID 328274 and ID 324270 (formerly CR126855) and it has been fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, this issue has been fixed in BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP 10.1.0 and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

Workaround

You can work around this issue by configuring your F5 device to use the same server for RADIUS authentication and accounting.

Note: For more information about using and configuring RADIUS AAA servers, refer to the Configuration Guide for BIG-IP Access Policy Manager.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.
