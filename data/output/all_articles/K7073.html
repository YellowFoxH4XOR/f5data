Known Issue

This is the result of a known issue. When the BIG-IP LTM configuration contains one or more external IP data classes, a TCL memory leak can occur when the BIG-IP LTM configuration is loaded into memory.

For example, the BIG-IP LTM configuration is loaded into memory when the configsync process is run between active and standby BIG-IP systems, or when the bigpipe load command is run.

F5 Product Development tracked this issue as CR73983, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
