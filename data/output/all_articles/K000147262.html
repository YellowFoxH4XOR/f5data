K000147262: How to show real IP addresses when you integrate F5 WAAP (HTTP LB) with CDN

Description

You want to integrate the F5 WAAP with CDN but also make sure that the IPs that are accessing it are shown with their real IPs.

Environment

  • F5® Distributed Cloud HTTP Load Balancer
  • CDN

Answer/Recommended Actions

Our CDN adds client IP information with these headers when forwarding the requests to Origin Server (Upstream):

  • X-F5-True-Client-IP 
  • X-Forwarded-For

You can configure one of these headers in the HTTP Load Balancer Configuration under Other Settings via the Trusted Client IP Headers field

Additional Information

  • Trusted Client IP Headers should ONLY be enabled when a trusted proxy such as CDN sits downstream of the XC LB in the data path.
