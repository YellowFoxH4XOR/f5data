K7816: Configuring the security policy to generate input violations for negative security checks and regular expression patterns

Topic

The BIG-IP ASM logs input violations when an HTTP request includes a parameter that contains data or information that does not match the security policy.

To configure the security policy to generate input violations for negative security checks and regular expression patterns, you should enable the Malicious parameter value option located in the Input Violation section. This will ensure that the BIG-IP ASM logs an input violation for negative security checks on flow parameters or defined parameters.

To configure the security policy to generate input violations for negative security checks and regular expression patterns, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Click the appropriate Web Application.
  4. Under the Security Policies list, select the policy you want to modify.

    The Policy Properties page is displayed.

  5. Click the Edit button next to Security Level.
  6. Scroll to the Input Violations section.
  7. In the Input Violation section, scroll to the Malicious parameter value row and select the Alarm and Block check boxes.
  8. Click Save.
  9. Scroll to the top of the page and click Apply Policy.
