Topic

This article applies to BIG-IQ system. For information about configuring automatic logout for idle sessions on the BIG-IP system, refer to K9908: Configuring an automatic logout for idle sessions.

Description

You can configure automatic logout for idle/inactive sessions on the BIG-IQ system for the following interface and utilities:

  • BIG-IQ user interface

    By default, the idle timeout for BIG-IQ user interface is set to twenty (20) minutes. The idle timeout setting accepts a minimum value of five (5) minutes and a maximum value of six hundred (600) minutes. When you modify the idle timeout for the user interface, the new timeout immediately applies to all existing user interface sessions.

  • Secure shell (SSH) sessions

    By default, the inactivity timeout for SSH session is set to zero (0) seconds which indicates that inactivity timeout is disabled. When you enable the inactivity timeout for SSH session by setting the value to non-zero, the new timeout does not apply to existing SSH session; it only takes effect on SSH session established after the new timeout is applied. When you configure inactivity timeout for SSH, the timeout for SSH session does not start counting down if the user is logged in to the TMOS Shell (tmsh) session. The countdown only starts when the user exits the tmsh or the tmsh session has timed out.

  • Console sessions

    By default, the inactivity timeout for console session is set to zero (0) seconds which indicates that inactivity timeout is disabled. When you enable the inactivity timeout for console session by setting the value to non-zero, the new timeout does not apply to existing console session; it only takes effect on console session established after the new timeout is applied. When you configure inactivity timeout for console session, the timeout for console session does not start counting down if the user is logged in to the tmsh session. The countdown only starts when the user exits the tmsh or the tmsh session has timed out.

  • TMOS shell (tmsh) sessions

    By default, the idle timeout for tmsh is disabled. To enable the idle timeout for tmsh, you must set the value to non-zero. When you enable the idle timeout for tmsh, the new timeout immediately applies to all existing tmsh sessions. To disable the idle timeout for tmsh, you must set the value to zero (0).

    Important: If a system broadcast message occurs while a user is logged into a tmsh session, the tmsh idle timeout is reset. This can result in the tmsh session remaining active if the broadcast message repeats.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the BIG-IQ user interface to configure the idle timeout for the user interface.
  • You must have administrative access to tmsh to configure the idle/inactivity timeout for the SSH, console, and tmsh session.

Procedures

  • Configure automatic logout for idle BIG-IQ user interface sessions
  • Configure automatic logout for inactive SSH sessions
  • Configure automatic logout for inactive console sessions
  • Configure automatic logout for idle tmsh sessions

Configure automatic logout for idle BIG-IQ user interface sessions

To automatically log out idle BIG-IQ user interface sessions after a specific idle time, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system. 

  1. Log in to the BIG-IQ user interface as an administrative user.
  2. Go to System > User Preferences.
  3. Select Edit to modify the settings.
  4. Enter your timeout value in minutes for the Idle Timeout (minutes) setting under the Session section. The value must be between 5 and 600 inclusive.
  5. Select Save & Close to save the change. The new timeout immediately applies to all existing BIG-IQ user interface sessions.

Configure automatic logout for inactive SSH sessions

To configure automatic logout for inactive command line sessions over SSH, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system. 

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Configure an automatic logout for inactive SSH sessions by entering the following command syntax:

    modify /sys sshd inactivity-timeout <seconds>

    For example, you would enter the following command to configure automatic logout for a 10-minute inactive SSH session:

    modify /sys sshd inactivity-timeout 600

    Note: To disable the automatic logout for inactive SSH sessions, you must set the value to zero (0) by entering the following command:

    modify /sys sshd inactivity-timeout 0

  3. Save the change by entering the following command:

    save /sys config

  4. Optional: Verify the change by entering the following command:

    list /sys sshd inactivity-timeout

Configure automatic logout for inactive console sessions

To configure automatic logout for inactive command line sessions over console, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Configure an automatic logout for inactive console sessions by entering the following command syntax:

    modify /sys global-settings console-inactivity-timeout <seconds>

    For example, enter the following command to configure automatic logout for a 10-minute inactive console session:

    modify /sys global-settings console-inactivity-timeout 600

    Note: To disable the automatic logout for inactive console sessions, you must set the value to zero (0) by entering the following command:

    modify /sys global-settings console-inactivity-timeout 0

  3. Save the change by entering the following command:

    save /sys config

  4. Optional: Verify the change by entering the following command:

    list /sys global-settings console-inactivity-timeout

Configure automatic logout for idle tmsh sessions

To configure automatic logout for idle tmsh sessions, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Configure an automatic logout for idle tmsh sessions by entering the following command syntax:

    modify /cli global-settings idle-timeout <minutes>

    For example, enter the following command to configure automatic logout for a 10-minute idle tmsh session:

    modify /cli global-settings idle-timeout 10

    Note: To disable automatic logout for idle tmsh sessions, you must set the value to zero (0) by entering the following command:

    modify /cli global-settings idle-timeout 0

  3. Save the change by entering the following command:

    save /sys config

  4. Optional: Verify the change by entering the following command:

    list /cli global-settings idle-timeout
