K51626013: iRule logging output of ''LB::server pool'' keep showing value of default pool name of the Virtual Server

Type
Support Solution
Published
2021-12-17
Updated
2026-07-16
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K51626013

Description
You enable the logging output of an iRule to check the output of LB::server pool and always observe that the value of that output keep showing the value of default pool name of the Virtual Server.

Environment

  • BIGIP
  • iRule

Cause
The logging LB::server pool is set before any load balancing decision has been made by BIGIP.

Recommended Actions

Change the position of logging of LB::server pool to after the load balancing decision has been made by BIGIP.

Additional Information
None
