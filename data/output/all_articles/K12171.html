K12171: The selectiveAssembly feature does not function correctly when content in RAM Cache expires after content in Smart Cache

Known Issue

This is the result of a known issue. If you enable the BIG-IP WebAccelerator Selective Assembly feature, and content in the Smart Cache expires before the same content in the RAM Cache, the BIG-IP WebAccelerator does not enable the MultiConnect feature for that content.

The Selective Assembly feature allows MultiConnect to be selectively enabled in content-specific policy nodes instead of just the HTML pages node. You can enable this feature by setting the selectiveAssembly parameter to true in the /config/wa/pvsystem.conf file. By default, selectiveAssembly is set to false.

F5 Product Development is tracking this issue as ID 324293 (formerly CR139143).
