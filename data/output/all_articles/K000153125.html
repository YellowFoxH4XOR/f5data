Topic

Beginning in APM Client 7.2.6, F5 Access Mac is distributed as a .pkg installer. To align versioning across platforms, F5 Access Mac 7.2.6 versioning is consistent with BIG-IP Edge Client versions for Windows and macOS. For more information, refer to K000152992: F5 Access Mac 7.2.6 release major changes.

This article provides instructions for BIG-IP administrators to download the F5 Access Mac package and distribute to VPN end users running MacOS desktop.

For VPN end users, refer to your organization's documentation or contact your IT department for details about how to download the package from your organization's internal resources.

Prerequisites

To use F5 Access Mac 7.2.6 or later, you need to update your APM Clients to 7.2.6. To do so, refer to K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system.

Download the F5 Access Mac package

You can download the F5 Access Mac package from the BIG-IP Configuration utility or from the F5 downloads site. Perform one of the 2 following procedures as appropriate:

  • BIG-IP Configuration utility (This option is available beginning from BIG-IP 17.5.x)
    1. Login to the BIG-IP Configuration utility
    2. Go to Access > Connectivity/VPN > Connectivity.
    3. Select the appropriate connectivity profile.
    4. Select the Customize Package dropdown list.
    5. Select MacOS F5 Acccess.
    6. Select Download.
  • F5 downloads site
    1. Login to F5 downloads site.
    2. For Group, select BIG-IP.
    3. For Product Line, select APM Clients.
    4. For Product Versions, select 7.2.6 or later.
    5. Select F5Access.pkg.
    6. Select your download location.
    7. Select Download.

Deploy F5 Access Mac to VPN end users

After you download the package, you can deploy to endpoints using an appropriate Mobile Device Management (MDM) software or other package deployment tools. Perform one of the following procedures as appropriate:

  • Deploy with an MDM
  • Deploy manually

As part of the deployment process, you can also configure the connectivity profile. To do so perform the following:

Deploy manually

After performing the previous procedure to download F5Access.pkg perform the following:

  1. Install F5Access.pkg on your MacOS client. (using the native app installation method).
  2. Launch the application.
  3. From the system extension prompt, enable the PacketTunnel and DNSRelay proxy extensions. For macOS Tahoe 26.3, refer to Enable extensions on macOS Tahoe 26.3.
  4. Allow F5 Access security permissions.
    1. On System settings, go to Privacy * Security.
        
    2. Select Details.
    3. Enable F5 Access.
    4. Enter your credentials when prompted.

Configure connectivity profile

When you install from a package downloaded from a connectivity profile from the BIG-IP APM system, the connectivity profiles will be displayed on the client side after install.

As part of the deployment process, you can also configure the connectivity profile after installation. To do so, perform the following procedure:

  1. Launch F5 Access.
  2. When prompted with F5 Access would like to add VPN configurations, select Allow.
  3. Add the VPN name, server, and credentials and client certificate as appropriate.
    Note: The BIG-IP APM virtual server must be trusted by the MAC client and the CA certificate should reside in the system keychain. If the certificate exists in the Login Keychain, delete it and reinstall it in the system keychain only.
  4. Select Apply

Identify F5 Access Mac users in BIG-IP APM access policy

You use the Client Type check in the access policy on your BIG-IP APM system to identify users connecting with F5 Access Mac. This can be done to differentiate F5 Access Mac users from BIG-IP Edge Client users due to difference in endpoint inspection policies or as part of a process to gradually migrate users from BIG-IP Edge client on MacOS. To do so, perform the following procedure:

  1. Open the access policy on BIG-IP APM.
  2. Select + to add an item at an appropriate location in the login flow.
  3. Select Endpoint Security (Server-Side).
  4. Select Client Type.
  5. Select Add Item.
  6. Configure the rest of the policy as appropriate.

Enable extensions on macOS Tahoe 26.3

In macOS Tahoe 26.3, follow the below instructions for enabling extensions:

  1. Open System Settings.
  2. Search for Login Items & Extensions and select it.
  3. Navigate to Extensions -> By App -> F5Access.
  4. Click the information icon (i) next to F5Access.
  5. Enable DNSProxy and PacketTunnel (Note: Admin/root password will be required)
