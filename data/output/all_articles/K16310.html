Issue

Error Message

emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- 010716dd:3: Policy '<ltp policy>', rule '<ltp policy rule>'; operand 'http-basic-auth' does not support selector 'all'. Unexpected Error: Loading configuration process failed.

In this error message, note the following:

  • <ltp policy> is the affected local traffic policy
  • <ltp policy rule> is the affected rule belonging to the affected local traffic policy

For example:

emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- 010716dd:3: Policy '/Common/bug420347', rule 'bug420347-rule'; operand 'http-basic-auth' does not support selector 'all'. Unexpected Error: Loading configuration process failed.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You have configured a local traffic policy rule with the http-basic-auth operand set to the all selector on a BIG-IP system.
  • You upgraded this BIG-IP system to BIG-IP 11.5.0 or later.

Impact

After upgrading to BIG-IP 11.5.0 or later, the BIG-IP system fails to load the configuration and logs the error message.

Recommended Actions

You must reboot the BIG-IP system back to the version prior to upgrading. You must then reconfigure the http-basic-auth operand in the affected local traffic policy and set it to either the username or the password selector before attempting to perform another upgrade. To do so, perform the following procedure:

Impact of procedure: Changing the selector for an operand may change the logic flow of a local traffic policy rule. F5 recommends that you test the change in your application environment as appropriate.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Policies > Policy List.
  3. Click on the affected local traffic policy.
  4. Click on the affected rule in the Rules section.
  5. In the Rule Properties section, select the http-basic-auth row in the Conditions setting.
  6. Click Edit.

    This will remove the row from the table in the Conditions setting and place values in their respective fields for editing.
  7. Select the selector as appropriate for your application environment.
  8. To add the modification back to the Conditions setting, click Add.
  9. To save the changes, click Update Rule.

    You can now proceed to perform an upgrade to BIG-IP 11.5.0 or later.
