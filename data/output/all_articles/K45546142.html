Description

When the GSLB group synchronization is enabled (DNS > Settings > GSLB > General) you will not have control on which device will push its configuration to the BIG-IP DNS / GTM group.

This article will explain on how to control or force sync from / to a specific device.

Environment

  • BIG-IP DNS / GTM
  • Force sync DNS / GTM config from / to a specific DNS / GTM device

Cause

None.

Recommended Actions

The steps below will pull the DNS / GTM configuration from the specified DNS synchronization group member. It will also add / re-add the device which is running gtm_add to the DNS synchronization group.

Note: The BIG-IP DNS / GTM running the steps below does not be an existing member of the DNS synchronization group.

  1. Login to the Command Line.
     
  2. To pull the DNS / GTM configuration, type the following command:
    gtm_add <IP address of a member of the target DNS synchronization group>

    Note: The synchronization group name on BIG-IP DNS will be updated with the existing synchronization group name

    For example, you want to force sync BIG-IP DNS A (10.10.10.10) config to BIG-IP DNS B (10.10.10.20), you will need to login to BIG-IP DNS B and run command:
    gtm_add 10.10.10.10
     
  3. You will not need to Enable Synchronize from the GUI as gtm_add will enable it by default.
