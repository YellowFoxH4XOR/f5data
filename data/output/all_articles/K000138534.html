[F5OS-C] Adding/removing a blade in a VELOS system

Description

You want to add a new blade in a VELOS system with existing blades installed or without any existing blade.
You want to remove an existing blade from a VELOS system.
 

Environment

  • VELOS chassis.
  • Adding a new additional blade or removing an existing blade from the chassis.
  • You have physical access to the VELOS system.
  • You have administrative access to the VELOS system.
 

Recommended Actions

In order to add a new blade into the VELOS chassis follow the below process:
  • Create a partition if required.
  • Include the slot into the desired partition, existing or new one.
  • Press the blue latch release on the front of the blade to release the ejector handle. Slide the blade in until the ejector contacts the catch in the chassis. Press the ejector handle until the blade is locked in place.
  • Connect the required optical modules and cables.
  • Wait for the new blade to come up properly. After adding slots to chassis partition, the blade reboots to install the appropriate chassis partition software. When you add a blade to the chassis, an automatic PXE boot from a system controller installs the chassis partition image from that controller. This can take several minutes.

In order to remove an existing blade from the VELOS chassis follow the below process:
Impact of procedure: This procedure involves removing a blade from the chassis. Services provided by the blade will be disrupted. F5 recommends performing this during a scheduled maintenance.
  • Move the blade to the “none” partition to clear the blade data so the blade can then be moved to another chassis or chassis partition if required.
  • Disconnect all cables and remove the optical modules.
  • Press the blue latch release on the front of the blade to release the ejector handle. Grasp the ejector handle and pull towards you, ensure that you support the weight of the blade as you remove it from the chassis.

Considerations

  • The slots for all blades are automatically assigned as members of the default chassis partition.
  • If a newly installed blade is not assigned to a defined chassis partition, it is assigned automatically to the “none” partition (partition 0).
  • You can create additional chassis partitions but you need to remove the slots associated with the default chassis partition first.
  • A slot (and the blade it contains, if any) can be part of only one chassis partition.
  • If the designated slot is already allocated to a tenant adding the blade will not disturb the existing traffic for this tenant. When additional blade is inserted in the slot allocated to a tenant the VELOS system will spawn a new tenant instance of the tenant (if any already) on this new blade inserted and traffic will be balanced among the blades of the tenant as per the DAG configuration.
  • If there is a software mismatch, the system automatically upgrades the software to match the chassis partition.
