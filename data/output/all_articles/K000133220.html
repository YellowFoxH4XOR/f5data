Description

Local Application cannot download the Proxy PAC file from the APM AutoConfigURL

Environment

BIG-IP APM Edge Client with Proxy PAC

Error message from Edge Client file logterminal.txt

function findproxyforurlex(url, host)
{
if(localhosthttp/1.0 404 not found
connection: close
content-type: application/x-ns-proxy-autoconfig

Cause

If the Local Application has a Header which ends with the word Host, the APM AutoConfigURL will think that the Application has sent two Host headers, and will return a 404 response, instead of providing the Proxy PAC file.

Recommended Actions

This issue is fixed by ID 1251445 (APM Client)

This issue is not currently fixed in any Release Versions of the Edge Client, so you need to request an Engineering Hotfix from F5 Support to resolve this issue.

Additional Information

This issue was actually created by the fix for CVE-2022-23032:

K30525503: BIG-IP APM Edge Client proxy vulnerability CVE-2022-23032

This was released in APM Client 7.2.1.4 and 7.2.2.

You can workaround this issue by rolling back to APM Client 7.2.1.3 or 7.1.9
