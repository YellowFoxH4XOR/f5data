K000135684: Unable to find highest allowed version in license file

Type
Support Solution
Published
2023-08-01
Updated
2023-08-01
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K000135684

Description

Customer could not find exclusive version list in bigip.license file, customer did not reactivate license for sometime.

Another BIG-IP's license (with same SKU#) shows the exclusive version list as below:

 

Exclusive_version :               15.*.*

Exclusive_version :               16.*.*

Exclusive_version :               5.*.*

 

Environment

  • VE version plus license
  • License reactivation
  • bigip.license

 

Cause

From time to time F5 updates product functionality through the base software code (TMOS) and/or via licensing, which can impact what is displayed in the license.

 

Recommended Actions

Reactivate license to get the latest license file.

 

Additional Information

None
