K10529: The FirePass Client API OnConnected event occurs twice

Issue

Starting in FirePass 6.0.3 and FirePass 6.0.2 with cumulative hotfix HF-602-6 applied, if you configure a Network Access connection to map a drive or launch an application, the API OnConnected event occurs twice. It occurs once when the connection establishes and a second time after the FirePass client-side component performs drive mappings and launches applications. Similarly, if you configure a Static Application Tunnel (FirePass 6.x) or an Application Tunnel (FirePass 5.x) to launch an application, the API OnConnected event occurs once when the tunnel establishes and a second time after the FirePass client-side component launches the application.

Previously, the API OnConnected event was only sent once after drive mappings were performed and applications launched.

The FirePass Client API provides an Application Programming Interface (API) for use by third party applications.

Note: For more information about the Client API, refer to K7615: FirePass Client API.
