K2671: Configuring a virtual server so that it will automatically redirect HTTP requests to HTTPS

Topic

By using a rule, all users attempting to connect using HTTP will be automatically redirected to HTTPS.

In the following example, the rule redirects to https://%h/%u., where %h is expanded as the client-specified host name or IP address and %u is expanded as the client-specified URI. This ensures that the redirection is seamless for the client.

Example configuration

pool secure_pool {
member 10.10.10.125:http
member 10.10.10.124:http
}

rule redirect_rule {
redirect to "https://%h/%u"
}

virtual 192.168.71.129:http unit 1 {
use rule redirect_rule
}

virtual 127.0.0.129:http unit 1 {
use pool secure_pool
}

proxy 192.168.71.129:https unit 1 {
target virtual 127.0.0.129:http
key www.f5.com.key
cert www.f5.com.crt
}
