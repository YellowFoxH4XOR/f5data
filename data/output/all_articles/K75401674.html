Description

You may want to download the Brightcloud webroot database to perform URL categorisation using HTTP proxies reachable either over the Management or TMM interfaces

Environment

  • LTM/PEM
  • Version 13.0.0 and later
  • DNS resolver configuration to resolve service.brightcloud.com (K13205: Configuring the BIG-IP system to resolve DNS hostnames (11.x and later))
  • TMM or management route to service.brightcloud.com (K13833: Managing static routes in BIG-IP 11.x - 13.x and BIG-IQ 4.x - 6.x)

Cause

Beginning in version 13.0.0 the management-proxy-config component in tmsh allows configuration of HTTP proxy IP address and port to download webroot database

Recommended Actions

With the appropriate TMM/management route and DNS name servers configured on the BIG-IP to resolve service.brightcloud.com, create the management proxy config component in tmsh by following steps below:
  1. Login to BIG-IP command line interface (CLI) and enter the tmsh prompt:

    tmsh

  2. Run the command below to create the HTTP proxy configuration

    create sys management-proxy-config <proxy_config_name> proxy-ip-addr <proxy_IP_address> proxy-port <proxy_port_number> username <username> password <password>

    For example:

    create sys management-proxy-config test_proxy proxy-ip-addr 192.168.1.1 proxy-port 3128 username user1 password ****

  3. Save the configuration changes made:

    save sys config

  4. Restart the wr_urldbd process:

    restart sys service wr_urldbd

  5. Monitor the webroot database log file to verify webroot database download:

    tail -f /var/log/wr_urldbd.out
