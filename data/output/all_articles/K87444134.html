Topic

You should consider using this procedure under the following conditions:

  • You are using Secure Web Gateway (SWG) or SSL Orchestrator (SSLO) and URL classification.
  • You have URLs that need classification or review.
  • You have URLs reported as unclassified.

Description

SWG and SSLO both use URL classifications provided by Forcepoint. Depending on the website age or content updates on a page, these classifications may no longer match the page content. You can handle small URL updates through the CSI: ACE Insight report. The link to this report is provided in the following procedure.

Procedures

Requesting URL classification 

URL classifications are done through Forcepoint and requests are made through the Forcepoint portal. 

Note: Forcepoint limits the number of requests to five per IP address per day.

Impact of procedure: Performing the following procedure may impact the availability of blocked or allowed websites after a Forcepoint review.
