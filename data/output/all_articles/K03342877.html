K03342877: The ASM::enable iRule command value requires the partition and policy name or ASM will reset the connection with a plugin abort

Description

  • The iRule command ASM::enable requires a value in the format "/[partition]/[policyName]".
  • If only the policyName is referenced ASM will reset the connection.
  • Connection is reset
  • Error messages:
    [0x2ca021c:1148] Internal error (ASM requested abort (plugin abort error))
     

Environment

  • ASM provisioned
  • The ASM policy is configured for ASM iRule events in the policy general settings.
  • An iRule is used with the command ASM::enable

Cause

The iRule syntax check allows the ASM::enable command to have a value in the format of "[policyName]" which is invalid, since the partition isn't referenced BD isn't able to find the policy in the configuration and therefore resets the connection.

Recommended Actions

  1. Change the iRule ASM::enable command to have a value in the format /[partition]/[policyName]
