Known Issue

This is the result of a known issue. When you use a Portal Access Web Application Favorite to access a Java-based web application, a Java applet may fail to connect through the FirePass reverse proxy to the application server. Some or all of the web application functionality may fail.

If the applet is browser-based, the browser may display a Null Pointer Exception error message in the browser's Java console, if it is enabled. The error message may appear similar to the following example:

java.lang.NullPointerException

The Java console should also display the following error message:

java.net.ConnectException: Connection timed out: connect

These errors will be consistent from invocation to invocation of the applet.

F5 Product Development tracked this issue as CR80600 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Additionally, this issue was fixed in cumulative hotfix HF-601-5 issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by accessing the web application using an Application Access Favorite or a Network Access Favorite.
