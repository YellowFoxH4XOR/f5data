K7113: Limiting responses from the BIG-IP LTM system for ICMP errors and ICMP unreachable events

Topic

The TM.MaxICMPRate BigDB key can reduce the effects of a denial-of-service (DoS) attack by allowing you to limit the number of responses the BIG-IP LTM system sends for Internet Control Message Protocol (ICMP) errors and ICMP unreachable events.

The TM.MaxICMPRate db key specifies a general rate limit applied to ICMP errors coming from servers back through the BIG-IP LTM system to the clients. Each ICMP event must be associated with an established connection flow.

For example, if a virtual server connection generates ICMP unreachable response from the pool member, the BIG-IP LTM system passes the ICMP responses back to the clients until the number of ICMP messages reaches the value specified by the TM.MaxICMPRate db key. Once the number of ICMP messages reaches the value specified by the TM.MaxICMPRate db key, the BIG-IP system stops sending ICMP responses.

The default value for the TM.MaxICMPRate BigDB key is 100. The minimum value allowed is one (1) and the maximum value allowed is 1000. To configure the TM.MaxICMPRate db key, type the following command:

bigpipe db TM.MaxICMPRate <value>

Note: For more information, refer to K7301: Protecting the BIG-IP system against denial of service attacks (9.x - 11.3.x).
