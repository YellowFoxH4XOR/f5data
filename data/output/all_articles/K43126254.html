Description

This article describes the behavior and solution for an attempt to attach clientssl or serverssl profiles to a virtual server with http-transparent profile attached
When trying to attach the profile, the following error message appears:
"01070734:3: Configuration error: In Virtual Server (/Common/test1) HTTP is configured as a Transparent Proxy, and thus is incompatible with any profile other than PEM, Statistics and Request Logging"

Environment

  • http-transparent profile is attached to a virtual and you are attempting to attach clientssl or serverssl profile

Cause

This is caused due to bug ID676026:

Recommended Actions

Upgrade to version 14.1.0

None
