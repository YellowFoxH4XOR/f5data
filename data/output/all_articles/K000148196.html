Description

This article will list the steps that need to be taken to un-subscribe from the following services :

  1. F5 Distributed Cloud status updates email Notifications.

  2. Product updates, System Maintenance, Site Maintenance, and Access requests email notifications.

Environment

  • Status Notification email
  • F5® Distributed Cloud Console

Answer/Recommended Actions

1. Unsubscribe from F5 Distributed Cloud status updates Notifications.

To stop receiving status updates notification emails,  you will need to click on the unsubscribe link at the bottom of the notification email  (Figure 1).

 

Figure 1, image from MS outlook. 

 

Once you have unsubscribed, you should receive a confirmation email.

 

 

2. Turn notifications off for Product updates, System Maintenance, Site Maintenance, and Access requests.

  1. Go to Distributed Cloud Console
  2. Go to Administration -> Personal Management -> My account - Manage Notification Preferences
  3. Uncheck the type of notification that you don't want to receive a notification email from:

 

Note:  If you don't have access to the account to turn notifications off, please open a support ticket.
