K000092651: Monitor behavior when pool member or node is forced offline

Type
Support Solution
Published
2022-11-17
Updated
2022-11-17
Source
https://my.f5.com/manage/s/article/K000092651

Description

Monitor behavior when using forced offline for the pool or node behavior varies based on what exactly is forced offline.


Pool Member enabled/Node enabled

  • Node Monitor sent
  • Pool Monitor sent

Pool Member Forced Offline/ Node enabled

  • Node Monitor sent
  • Pool Monitor not sent

Pool Member enabled/Node forced offline

  • Node monitor not sent
  • Pool Monitor sent

Pool Member present in two or more pools with the same monitor, both forced offline/node enabled

  • Node monitor sent
  • Pool Monitor sent

Environment

BIG-IP

Cause

If the pool member exists in multiple pools the Big-IP will continue to send monitor traffic, even if both members are forced offline. This is due to:

Bug ID 544958: Monitors packets are sent even when pool member is 'Forced Offline'.


Recommended Actions

Upgrade to a patched version and/or assign unique monitors or pool members to each pool


Additional Information

See also: K20186005: BIG-IP keeps sending monitor packets to forced offline pool member(s)
