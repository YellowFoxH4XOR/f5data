Description

Modifying an iApps config to explicitly add a persistence profile that is already being assigned to another Virtual Server fails with the below error message. 

For example:

  • In the configuration utility, navigate to  Main >> iApps >> Application Services  
  • Select existing iApp 
  • Select the Reconfigure tab.
  • Navigate to Template Options and change to "Advanced - configure advanced options"
  • Change the profile "Which persistence profile do you want to use?"
  • Use cookie persistence (recommended) to explicit profile 
  • Select the persistence profile which is already in use
  • Click "Finished"

An error message will be displayed as below. 

err mcpd[7426]: 01070734:3: Configuration error: DB validation exception, unique constraint violation on table (virtual_server_test) object ID (<profile name>). A duplicate value was received for a non-primary key unique index field. DB exception text (Can't save/checkpoint DB object, class:virtual_server_test status:13)

 

Environment

  • IApp
  • Persistence Profile
  • Explicit profile

Cause
This behavior is by design. A persistence profile that is already in use cannot be assigned to another virtual server from an iApp application. 

Recommended Actions

Use a persistence profile that is not in use.
