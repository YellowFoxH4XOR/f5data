Known Issue

Description

The BIG-IP APM rewrite process may incorrectly handle HTML entities in HTML attributes.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • An HTML tag attribute contains HTML entities within its value.

For example, the following form action attribute contains the &#x2f HTML entity in its value:

<form action='&#x2f;somepath&#x2f;action.script'>

The BIG-IP APM system will rewrite the action path with HTML entities, causing this web application to function incorrectly.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using portal access, HTML forms are not submitted.
  • Request URLs, generated by the form action, incorrectly include the "/f5-w-" prefix.
  • Web applications malfunction or fail to render properly in browsers.
