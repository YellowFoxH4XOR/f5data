K82731981: Self IP not reachable on newly configured VLAN

Type
Support Solution
Published
2022-05-12
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K82731981

Description
Self IP not reachable from network. This occurs on a newly configured VLAN on a vCMP guest, which may be identified as Virtual Edition.

The VLAN is already configured on the switch attached to the host.

A message similar to the following is seen in /var/log/ltm:

May 12 18:23:33 bigip1.example.com warning mcpd[7523]: 01071323:4: Vlan (/Admin/VLAN1024:1024) is configured, but NOT on hypervisor allowed list.

Environment

  • new VLAN
  • VLAN configured on switch attached to BIG-IP
  • VLAN configured on vCMP guest

Cause
This error is explained in K93395707: Error message: 01071323:4: Vlan (/Common/<vlan_name>:<tag>) is configured, but NOT on hypervisor allowed list.

Recommended Actions

Configure the VLAN appropriately on the vCMP host and assign it to the guest.

Additional Information
vCMP matches host and guest VLANs using the VLAN tag.
