Known Issue

This is the result of a known issue. The SNMP object sysInterfaceStat does not include management interface statistics.

The SNMP object sysInterfaceStat is part of the F5-BIGIP-SYSTEM-MIB.text file.

F5 Networks Product Development tracked this issue as CR89587 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP ASM, GTM, LTM, Link Controller, and WebAccelerator Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.3-HF2 issued for BIG-IP version 9.4.3. You may download this hotfix or a later version of this hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about managing F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.
