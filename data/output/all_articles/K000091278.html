K000091278: NGINX Controller installation fails if there is a pre-existing Kubernetes configured

Type
Support Solution
Published
2022-02-15
Updated
2022-11-10
Source
https://my.f5.com/manage/s/article/K000091278

Description

When trying to install NGINX Controller, the installation procedure keeps failing on either "Checking Kubernetes" or "Checking resource requirements" steps.


Failing on "Checking Kubernetes" step

8. Checking Kubernetes...

kubectl version v1.23.3 satisfies 1.23.3

KUBE_VERSION=1.23.3

CLUSTER_NAME=MY-NGINX-CONTROLLER


Unfortunately, an error has occurred:

timed out waiting for the condition


This error is likely caused by:

- The kubelet is not running

- The kubelet is unhealthy due to a misconfiguration of the node in some way (required cgroups disabled)


The recommended value for "bindAddress" in "KubeProxyConfiguration" is: 0.0.0.0; the provided value is: 127.0.0.1

Failed to initialize the Kubernetes cluster



Failing on "Checking resource requirements" step


9. Checking resource requirements...

Could not determine available node resources - possible Kubernetes installation problem Please check /var/log/nginx-controller/nginx-controller-install.log for details

Could not determine available node resources - possible Kubernetes installation problem





Environment

  • NGINX Controller installation
  • Kubernetes previously configured on the host


Cause

NGINX Controller ships with a required version of Kubernetes and will install Kubernetes for you. Be sure to install NGINX Controller on a dedicated node that does not already have Kubernetes configured. NGINX Controller v3.x will install Kubernetes v1.15.5.



Recommended Actions

Make sure Kubernetes was not previously configured in the same host Controller will be installed.

During Controller installation you should see kubectl v1.15.5 is being installed.


8. Checking Kubernetes...

kubectl not found

Loading required packages: kubectl


KUBE_VERSION=1.15.5


Starting k8s installation

[init] Using Kubernetes version: v1.15.5


Your Kubernetes control-plane has initialized successfully!



If Kubernetes was configured already, before Controller installation better try on a clean host with no pre-existing Kubernetes.
