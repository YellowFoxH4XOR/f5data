Topic

In BIG-IP ASM 9.4.x and 10.x, a request that triggers a violation for an Attack Signature that is still in staging is displayed in the Configuration utility in the following two locations:

  • On the Requests page, in the Reporting menu
  • On the Traffic Learning page, in the Policy Building menu

In versions 9.4.x through 10.0.1, a request that generates an attack signature violation for an attack signature in staging is reported in the Reporting section as the request type: Illegal Request.

Beginning in BIG-IP ASM 10.1.0, a request that generates an attack signature violation for an attack signature in staging is reported as the request type: Legal Request.

Because the system considers the request legal in 10.1.0 and later, if you have set the web application logging profile to Log Illegal Requests, the system does not display the request in the Reporting screen. The request is still displayed in the Traffic Learning section as a Negative Security Violation of the type: Attack Signature Staging.
