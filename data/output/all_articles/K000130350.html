Description

  • IT Administrator want to collect the client report via cli / script.

Environment

  • BIG-IP APM
  • Edge client / Browser plugin
  • Window client

Cause

None

 Recommended Actions

Run the file f5wininfo.exe /? in the command line, it will popup a window, display the parameters for the command line.
 
For example:
f5wininfo.exe /report /html %computername%.html

Additional Information

More command to collect more data for the client system.

msinfo32.exe /nfo %computername%.nfo
systeminfo > %computername%-sysinfo.txt
wevtutil epl System %computername%-system.evtx
wevtutil epl Application %computername%-application.evtx

Please google search it to find the proper command to match the requirement.
