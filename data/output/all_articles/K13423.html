Topic

You should consider using this procedure under the following condition:

  • You need to import external file types to the BIG-IP system.

    For example:

    • External data group files
    • External monitor program files
    • Secure Socket Layer (SSL) certificate files

Description

In BIG-IP 11.x and later, F5 recommends that you use the File Management page in the Configuration utility to import certain external file types to the BIG-IP system. An external file type is a file that you need to import into the BIG-IP system and integrate as part of the local traffic configuration.

When you import a file using the File Management page, the BIG-IP system automatically places the file in the proper location on the file system. The file is then available to use when you define the associated local traffic component. For example, if you write an external monitor script that you intend to copy to the BIG-IP system and reference as an external health monitor, use the File Management page to import the script to the BIG-IP system. After importing the file, you can use the Local Traffic area of the Configuration utility to create a new external monitor based on the imported file. Alternatively, you can use the TMOS Shell (tmsh) to import the file if the file already resides on the BIG-IP system. External file types that you import into the BIG-IP system are also backed up during user configuration set (UCS) file creation. Restoring the UCS file replaces existing external file types with the archived external file types.

Note: In versions earlier than BIG-IP 11.x, you must manually copy external files to the BIG-IP system using the Secure Copy (SCP) protocol or some other means. You must then place the file in the proper location on the file system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have access to the Configuration utility or tmsh.
  • You have the external files available to you on your local workstation, on a network share, or on the BIG-IP system.

Procedures

  • Using the Configuration utility to import external files to the BIG-IP system
  • Using tmsh to import external files to the BIG-IP system

Using the Configuration utility to import external files to the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management.
  3. Click the tab for the file type that you intend to import. For example, if you want to import an external monitor script file, click External Monitor Program File List.
  4. Click Import.
  5. Browse to the location of the external file type that you want to import, and then click Open.
  6. In the Name box, type the file name or click Overwrite Existing to overwrite an existing file.
  7. Click Import.

After importing the file, you can use the Local Traffic area of the Configuration utility to create the associated new configuration element based on the imported file.

Using tmsh to import external files to the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Import the external file using one of the following command syntax options:
    • To create a new file, use the following command syntax:

      create /sys file <file_type> <new_filename> source-path file://<file_source>

      For example, to import a new external monitor script /config/monitors/mynewmon as /Common/mynewmon monitor on the BIG-IP system, type the following command:

      create /sys file external-monitor /Common/mynewmon source-path file:///config/monitors/mynewmon

    • To overwrite an existing file, use the following command syntax:

      modify /sys file <file_type> <existing_filename> source-path file://<file_source>

      For example, to import a new external monitor file named /config/monitors/mynewextmon and overwrite an existing external monitor named /Common/myextmon, type the following command:

      modify /sys file external-monitor /Common/myextmon source-path file:///config/monitors/mynewextmon

  3. Save the change by typing the following command:

    save /sys config

After importing the file, you can use the relevant modules of tmsh to create the associated new configuration element based on the imported file.

Note: For examples of importing other external file types, use the tmsh help /sys file <file type> command. For example, to view options and examples for importing external data group files, while still logged in to tmsh, type the following command: help /sys file data-group.
