K000153893: F5OS ISO image not showing in GUI > System Settings > Software Management

Type
Support Solution
Published
2025-08-29
Updated
2025-08-29
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.5.X, 1.8.0, 1.5.3, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000153893

Description

Uploaded an F5OS image to /var/import/staging on an rSeries appliance, but unable to see it in the GUI under System Settings > Software Management.

Image checksum has been verified, problem persists after system reboot.

Environment

  • F5OS
  • rSeries
  • Image upload

Cause

Image is not visible in the GUI because it hasn't been imported by the sw-mgmt service. Image has not been imported because the wrong image type has been uploaded.

For example, an R5R10 image has been uploaded to an R2R4 device.

The /var/log/sw-mgmt.debug log file contains messages similar to the following:

DEBUG: IN_CLOSE_WRITE: /var/export/chassis/import/iso/F5OS-A-1.8.0-17564.R5R10.EHF-1.iso DEBUG: queueing /var/export/chassis/import/iso/F5OS-A-1.8.0-17564.R5R10.EHF-1.iso for import
DEBUG: Generating metadata object for /var/export/chassis/import/iso/F5OS-A-1.8.0-17564.R5R10.EHF-1.iso
DEBUG: running command: ['mount', '-r', '/var/export/chassis/import/iso/F5OS-A-1.8.0-17564.R5R10.EHF-1.iso', '/tmp/tmp5vo9_dmi']
DEBUG: running command: ['umount', '-l', '/tmp/tmp5vo9_dmi']
DEBUG: VERSION info {'date': '2024-11-24', 'platform': 'R5R10', 'status': 'not_imported', 'source': '/var/export/chassis/import/iso/F5OS-A-1.8.0-17564.R5R10.EHF-1.iso', 'type': 'ehf-1'}
ERROR: sw-mgmt: priority=error msgid=0x3501000000000099 msg=Unsupported platform: R5R10

Recommended Actions

Remove the image in question and upload the correct image type for your appliance.
