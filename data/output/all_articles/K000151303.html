Description

Can Edge and Pulse IP Geolocation database be used on the BIG-IP at the same time?

Environment

F5 BIG-IP

Cause

None.

Recommended Actions

  1. BIG-IP does not support simultaneous use of Edge and Pulse geolocation databases. Only one can be active.
  2. The installed GeoIP database files serve as the single source of truth for all BIG-IP modules (ASM, AFM, APM, DNS, etc.)

Additional Information

The IP Geolocation Pulse database requires at least 900 MB of system memory. Ensure you provision sufficient system memory when updating or migrating to the GeoIP Pulse database. For more information, refer to ID 1070841.
