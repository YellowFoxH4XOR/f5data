Known Issue

This is the result of a known issue. You cannot access the Configuration utility after you run the Setup utility, because the Setup utility prompts you to change the system's self IP address. When you do this, the URL that you were originally connected to is no longer valid.

F5 Networks Product Development tracked this issue as CR19648, CR19672 and CR41810.

Workaround

To work around this issue, connect to 3-DNS using the following URL syntax, where <address> is the new self IP address that you configured for your system when you ran the Setup utility:

https://<address>/

You should now be able to access the Configuration utility.
