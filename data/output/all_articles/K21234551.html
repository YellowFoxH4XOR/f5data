Description

cannot create temp directory, no space left” in /var/log/liveinstall.log

Environment

  • BIG-IP VE
  • Trying to upgrade

Cause

Can occur after importing a large file such as an installation image.

Recommended Actions

Issue the following command to check for large files in your installation directory:
find <directory> -xdev -type f -exec du {} \; | sort -rn | head -20
Proceed with deleting the largest files that are not in use in order to free space for the new image. For more information on how to safely delete non-essential files read K14403: Maintaining disk space on the BIG-IP system
