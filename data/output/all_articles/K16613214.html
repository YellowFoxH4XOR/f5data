Description

HA pair is not able to synchronize giving this error:

01070710:3: Database error (13), Cannot update_indexes/checkpoint DB object, class:traffic_matching_criteria_port_update status:13 - EdbCfgObj.cpp, line 127.

Environment

  • Trying to synchronize within devices on the same Device Group 
  • Virtual Server using a port-list from Shared Objects

Cause

This is related to the known issue ID956109
 

Workaround

  1. Log in to the Configuration utility with administrative privileges. 
  2. Go to Local Traffic > Virtual Servers > Virtual Server List > Choose the Virtual Server that uses a port-list
  3. Within General Properties select 'Port' instead of the selected 'Port List'
  4. Click Update
  5. Once you have applied the above, sync the configuration from the device with the latest configuration 
  6. After they get sync, you can revert the changes at the Virtual Server level
