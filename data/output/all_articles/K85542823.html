Description

  • Virtual servers configured with fastL4 profiles can cache the maximum transmission unit (MTU) learned from next hop peer devices during Path MTU Discovery (PMTUD)
  • If a Low MTU value is received in ICMP type 3 code 4 (ICMP Fragmentation Needed) messages the BIG-IP system caches the MTU value in route metrics
  • A Virtual Server using a FastL4 profile advertises the cached low MTU in the egress SYN sent to the server and the egress SYN-ACK sent to the client
  • New connections using the cached MTU in route metrics may experience less than optimal performance

Note: The default value of tm.minpathmtu database variable is 296

Environment

  • BIG-IP
  • FastL4 Protocol Profile
  • Following virtual server types
    • Performance (Layer 4)
    • Forwarding (Layer 2)
    • Forwarding (IP)
    • Internal

Cause

  • If a next hop peer device responds with ICMP type 3 code 4 (ICMP Fragmentation Needed) containing a low MTU the BIG-IP caches and enforces the low Path MTU for the connection

Recommended Actions

  1. Querying the route metrics cache and packet captures of affected traffic may show the advertised MTU/MSS in the TCP connection set up
  2. To query the route metrics cache using tmsh use  
    tmsh show net cmetrics

Net::RouteMetric
	Destination IP  HWaddress         TMM  rtt  rttvar  ssthresh  bandwidth  MTU
	192.168.20.20    00:00:5E:00:53:00  0    0    0       0         0          296
	Total records returned: 1
  3. Trace the next hop peer device advertising low MTU value and update MTU on relevant interface and delete the cached route metric entry for the peer device  
    tmsh delete net cmetrics dest-addr 192.168.20.20

Additional Information

  • The following database variables control Path MTU Discovery, enforcement and caching
  • tm.pathmtudiscovery: If DF flag is set in received IP packet and packet is larger than MTU for the egress link, send ICMP fragmentation needed message
  • tm.enforcepathmtu: Use the cached MTU value and any incoming ICMP packets to set the MTU on the egress VLAN
  • tm.minpathmtu: Disregard PMTU messages below configured value
  • route.metrics.mtu: Use the cached MTU value for a new connection, if one exists (also requires tm.enforcepathmtu)
