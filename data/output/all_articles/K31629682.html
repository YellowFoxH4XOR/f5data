Description

UDP traffic to a virtual server with a UDP profile that has immediate timeout configured can collide with existing connections and result in traffic sent with UDP source port 0 Due to the source port of 0 (zero) UDP applications are showing symptoms of packet loss. When viewing network layer traffic UDP packets sent from the BIG-IP have the source port of 0 (zero).
Environment

  • BIG-IP
  • UDP virtual server
  • UDP profile with timeout set to immediate

Cause
Bug ID 745923

Recommended Actions
The issue can be mitigated by removing immediate timeout from the UDP profile.
