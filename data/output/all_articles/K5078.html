Known Issue

This is the result of a known issue. 3dpipe only allows the following characters to be used in configuration object names:

  • The letters a-z in lower case
  • The letters A-Z in upper case
  • The numerals 0-9
  • The special characters "." (period), "*" (asterisk), "?" (question mark), "-" (dash), "_" (underscore), and " " (space)

The Configuration utility will allow you to name configuration objects using special characters other than those listed; however, 3dpipe may report a parse error when other special characters are used.

F5 Networks Product Development tracked this issue as CR14955, CR14956, CR16971, CR16972, CR16973, and CR17173.
