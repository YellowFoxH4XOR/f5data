Description

When upgrading BIG-IP VE instances in AWS, you may encounter loss of the admin password on upgraded devices.

After the upgrade, login attempts using the previously set admin credentials fail, and manual password reset via AWS SSH key access is required to regain access.

Environment

  • BIG-IP Virtual Edition (AWS)
  • BIG-IP LTM
  • BIG-IP Upgrade
  • Admin and root users configured via cloud-init during initial deployment

Cause

The cloud-init service remains enabled after initial setup on BIG-IP VE in AWS environments. During an upgrade, cloud-init resets user credentials (including the admin password), overwriting any previously set values.

Recommended Actions

  • After completing initial deployment and configuration, disable the cloud-init service database key to prevent credential resets during future upgrades 
    tmsh modify sys db service.cloudinit value disable
  • If the admin password is lost after an upgrade, use AWS SSH key access to reset it manually.

Additional Information

  • F5 Cloud Docs: Disable Cloud Init on BIG-IP VE
