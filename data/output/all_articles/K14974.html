Known Issue

HTTP compression on some BIG-IP platforms may fail with large compressed streams.

This issue occurs when all of the following conditions are met:

  • You are using hardware HTTP compression on one of the following platforms:
    • 2000s/2200s
    • 4000s/4200v
  • The compressed stream exceeds 4 gigabytes in size.

Impact

Large compressed files fail to download.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H447139 on the Diagnostics > Identified > High screen.
  • In the /var/log/ltm file, you may observe an error message similar to the following example:

    01010025:2: Device error: (null) Cave Creek compression error, err = -11
    01010025:2: Device error: (null) qa_dc_ctx_done: hw_comp Error

  • The BIG-IP system closes the connection with a TCP RESET.
