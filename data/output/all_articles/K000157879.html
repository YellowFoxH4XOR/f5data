K000157879: Change in Pool Member Monitor Status Reason After Upgrading to BIG-IP 17.5.1.3 ENG-HF and 17.1.3 ENG-HF

Type
Support Solution
Published
2025-11-17
Updated
2025-11-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000157879

Description

After upgrading BIG-IP LTM systems to Hotfix-BIGIP-17.5.1.3 ENG-HF or 17.1.3 ENG-HF, administrators may notice a change in the status.status-reason field for pool members monitored by Layer 7 (L7) monitors (such as FTP, Basic Auth, etc.). Previously, when a monitor failed (for example, due to incorrect credentials), the status.reason displayed "Pool member has been marked down by a monitor." After applying these hotfixes, the status.reason now shows more specific error messages such as "No successful responses received before deadline. @2025/11/14 17:43:00. ".

Environment

  • 17.5.1.3 ENG-HF, 17.1.3 ENG-HF
  • LTM pool with Layer 7 monitor (e.g., FTP monitor)

Cause

Bug ID 1670225

 

This behavior change is intentional and results from the fix for Bug ID 1670225. The status.status-reason now reflects the actual last error reported by the monitor for improved troubleshooting visibility.

 

Recommended Actions

Note that after upgrading to BIG-IP versions containing the fix for Bug ID 1670225, the status.status-reason field will display the most recent and specific error message from the monitor instead of a generic message. No further action is required unless this change impacts operational monitoring or alerting processes

 

Additional Information

The previous behavior showed a generic message because the "last error" field was empty after certain events.
