K000153123: DNS "message-cache-size" value set to 0 does not disable caching

Type
Support Solution
Published
2025-08-21
Updated
2025-08-21
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000153123

Description

Configuring DNS cache profile parameters with zero values does not disable caching.

Environment

  • Product: BIG-IP DNS
  • Versions: All
  • Configuration:
    • DNS cache profiles with the following settings at or near minimum values:
      • msg-cache-size set to 0
      • rrset-cache-size set to 1 byte
      • nameserver-cache-count set to 0

Cause

This is by design "A value of zero will not disable caching". Instead, the system enforces internal minimums for these parameters:

  • msg-cache-size: 1024 bytes
  • rrset-cache-size: 32 bytes
  • nameserver-cache-count:  32 entries

Recommended Actions

  • It is not recommended to configure DNS cache profile parameters with zero or near-zero values
  • Use default values unless there is a specific requirement:
    Default settings:
    • key-cache-size: 1048576 bytes
    • msg-cache-size: 10485760 bytes
    • nameserver-cache-count: 16536 entries
    • rrset-cache-size: 1048576 bytes
  • Disabling caching by setting these fields to zero is not supported: 
    • The system will always enforce a minimum value internally.
    • Attempting to operate without effective caching leads to poor performance and possible service disruption.
