Description

When configuring LDAPS authentication, it fails with error:

"Remote authentication server unreachable; local authentication failed"

The Active Directory server is reachable by ping and you are able to connect to port 636 as well.
Analyzing a packet capture, it is observed the connection is being reset with "Alert (Level: Fatal, Description: Unknown CA)" cause

Environment

  • BIG-IP LTM 16.1.x using LDAPS authentication 

Cause

The configuration is not set properly to use the certificate on the LTM

Recommended Actions

  • Install a CA cert on the BIG-IP  which should be for the CA returned by the cert used by an LDAPS server 
  • Alternatively , disable ssl-check-peer on the LDAPS configuration on the BIG-IP. For example:
auth ldap /Common/system-auth {
    bind-dn binduser@f5.example.com
    bind-pw ***scrubbed***
    check-roles-group enabled
    login-attribute sAMAccountName
    port 636
    search-base-dn dc=f5,dc=example,dc=com
    servers { f5.example.com }
    ssl enabled
    ssl-check-peer enabled     >>>>>>>>>> Change it to disabled
}
