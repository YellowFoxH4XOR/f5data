Description

Illustration and confirmation of the Bandwidth Controller (BWC) solution functionality.

Environment

  • BIGIP
  • Virtual Server with Bandwidth Controller policy attached
  • Traffic capture collected using tcpdump, without any limitations
    • e.g.: tcpdump -envi 0.0:nnn -s0 -w /shared/tmp/nolimit.pcap
  • Traffic capture collected using tcpdump, while bandwidth controller policy attached
    • e.g.: tcpdump -envi 0.0:nnn -s0 -w /shared/tmp/withlimit.pcap

Cause

Once applying the Bandwidth Controller policy to a VS, the bigip will limit the incoming traffic to the value configured in the BWC policy.

Recommended Actions

  1. Using tcpdump, capture traffic while BWC policy not attached:
    • tcpdump -envi 0.0:nnn -s0 -w /shared/tmp/nolimit.pcap
  2. Attach BWC policy to the VS and capture some traffic:
    • tcpdump -envi 0.0:nnn -s0 -w /shared/tmp/withlimit.pcap
  3. Open the captures in Wireshark and filter incoming traffic only:
    • f5ethtrailer.ingress == 1
  4. Save as new file (File -> Export Specific Packets and check Displayed)
  5. Click on Statistics -> I/O Graph
  6. From the table appears below the Graph generated:
    1. Check "All Packets"
    2. Click Packets under the Y Axis column 3 times and change to Bits
    3. Change the Interval to 10ms or 100ms
    4. Change the SMA Period to 20 interval SMA
    5. Check the Time of day
  7. Repeat for both captures

 

Additional Information

  • To display BWC policy in cli, run the following tmsh command:
tmsh list net bwc policy bwc 
net bwc policy bwc {
limit max-rate 10mbps     <<< 10mbps    
}

 

  • To display BWC policy in GUI:

    Acceleration  ››  Bandwidth Controllers : Policies ›› <BWC policy name>
