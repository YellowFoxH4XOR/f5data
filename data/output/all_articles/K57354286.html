Topic

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP system to insert a custom HTTP header into an HTTP request.

Description

The primary method to insert an HTTP header into an HTTP request is to use the Request Header Insert option in the HTTP profile.

When you use the Request Header Insert option in the HTTP profile, you should consider the following:

  • You can specify only a single header string to be inserted as a header into the HTTP request.
  • If the header you want to insert already exists, the BIG-IP system does not replace it.
  • Using the HTTP profile's Request Header Insert option is the most efficient method for inserting a custom HTTP header into an HTTP request.

If you need to perform more advanced HTTP header functions, such as insert multiple headers, modify headers, or remove headers, you will need to use a BIG-IP LTM policy or an iRule. Additionally, you can apply BIG-IP LTM policy rules and iRules HTTP header functions on both the HTTP request and the HTTP response. For information about using BIG-IP LTM policies or iRules to perform HTTP header functions, refer to articles in the Supplemental Information section.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the Configuration utility or the TMOS Shell (tmsh).
  • You have an existing HTTP virtual server configured on your BIG-IP system.
  • You want to insert a custom HTTP header into incoming HTTP virtual server requests.

Procedures

Configuring the HTTP profile to insert an HTTP header into an HTTP request

To configure an HTTP profile with a header to be inserted into HTTP requests, perform the following procedure:

Note: F5 recommends that instead of modifying a default profile, you create a custom profile using the default profile as the parent profile. You can then modify some or all of the values defined in the custom profile, while leaving the parent profile settings at their default value. For more information, refer to K14488: Working with profiles.

Impact of procedure: The impact of the procedure depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Services > HTTP.
  3. Select the HTTP profile you want.
  4. For Request Header Insert, enter the HTTP header string that you want to use. For example:
    • My-Header: value
    • My-Header: value1=data; value2=data

    Note: You can use any header format that is valid within the current HTTP RFCs for each HTTP version.

  5. Select Update.
