Issue

Error Message

notice sod[<PID>]: 010c002a:5: Requesting tmm to resend gratuitous arps for traffic group <name>.

In this error message, note the following:

  • <PID> is the process ID for the sod process
  • <name> is the name of the affected traffic group

For example:

notice sod[8584]: 010c002a:5: Requesting tmm to resend gratuitous arps for traffic group /Common/traffic-group-1.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure multiple BIG-IP systems for high availability (HA).
  • A traffic group that is active on multiple BIG-IP systems in the device group transitions to active only on a single BIG-IP system.

If multiple BIG-IP systems in a sync-failover device group become active simultaneously for a traffic group, the BIG-IP systems determine which system should remain active and which system should transition to standby. When this occurs, the remaining active BIG-IP system will request the tmm process to resend gratuitous ARP messages for the traffic group.

Impact

There is no impact; this is a notification.

Recommended Actions

None
