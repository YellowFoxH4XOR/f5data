Description

JSON attack can't detect or decode without JSON profile configuration.

 

Environment

  • BIG-IP ASM version 14.1.X
  • JSON Content-Type

Cause

Missing JSON support in the configuration

Recommended Actions

Adding JSON Support to an Existing Security Policy
