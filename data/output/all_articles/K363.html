Known Issue

This is the result of a known issue. When you use the bigpipe db command to make changes to BIG-IP database keys, BIG-IP loads the changes into memory, but does not save them.

F5 Networks Product Development tracked this issue as CR27229 and CR41823.

Workaround

To work around this issue and save changes that you make to BIG-IP database keys, save the configuration by typing the following command:

bigpipe save
