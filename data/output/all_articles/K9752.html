Known Issue

When attempting to re-install a hotfix, the BIG-IP ASM system can generate an error message that appears similar to the following example:

duplicate packages exist on the system

This issue can occur when you attempt to install a hotfix when the system is not appropriately licensed, or if the BIG-IP ASM module is not activated, and then attempt to re-install the hotfix after activating the license.

For example, if a user performs the following steps when attempting to install a hotfix, the system logs the error message:

  • The user attempt to install a hotfix on a BIG-IP ASM system in which the license or the BIG-IP ASM module is not activated.
  • Error messages similar to the following are logged to the system console:

    Preparing packages for installation...
    TS-database-5.0.0-9.4.5.1086.0
    error: mcpd never came up...
    None of ASM, WA, or EM is licensed. Mysql service command ignored.
    Dec 30 11:50:42 bigip1 mcpd[315]: 01070608:0: License is not operational (expired or digital sigature does not match contents).
    error: %post(TS-database-5.0.0-9.4.5.1086.0) scriptlet failed, exit status 1
  • The user then activates the license or the BIG-IP ASM module and reboots the system.
  • The user attempts to re-install the hotfix.

F5 Product Development tracked this issue as CR112519 and it was fixed in BIG-IP ASM 9.4.7. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, Hotfix-BIGIP-9.4.6 HF-1 has been issued for BIG-IP ASM 9.4.6. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).

Workaround

If you attempted to install a hotfix on a BIG-IP ASM system in which the license or the BIG-IP ASM module is not activated, you can restore the system by performing the following procedure:

  1. Re-install the base BIG-IP ASM release.

    For example, if the base release is version 9.4.5, and you were attempting to install Hotfix-BIG-IP-9.4.5-HF2, you must re-install the base 9.4.5 release.
  2. Enable the BIG-IP ASM module by typing the following command:

    bigpipe db Module.ASM enable
  3. Reboot the system by typing the following command:

    reboot
  4. Once the system has rebooted, verify that the BIG-IP ASM module is running by typing the following command:

    bigstart status asm
  5. Install the hotfix.
