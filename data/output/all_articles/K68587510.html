Description
When viewing the BIG-IP AFM network firewall logs in the Configuration Utility on the Security  ››  Event Logs : Network : Firewall page, you do not see any firewall logs for policies and rules in some contexts.

Environment

  • BIG-IP AFM
  • Non-virtual server contexts

Cause
Network firewall rules for global, route domain, self IP, and management port contexts are associated with the default global-network logging profile. By default, the global-network logging profile is configured to perform no logging.

Recommended Action
Configure the global-network logging profile to perform network firewall event logging for these policies by setting the appropriate log publisher and the logging rules.

  1. In the Configuration Utility, go to the Security  ››  Event Logs : Logging Profiles page and click the global-network logging profile link
     
  2. In there, select the Network Firewall tab
     
  3. Select the local-db-publisher in the publisher drop down menu
     
  4. Enable the check boxes for logging all the rule matches that you wish to log such as accept, drop, and/or reject
     
  5. Click Update

Additional Information
To log network firewall events for specific virtual servers, you should attach a security logging profile to that traffic object. For more info, see K23372327: AFM not logging firewall actions
