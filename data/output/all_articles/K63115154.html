Issue

Error Message

01070313:3: Error reading key PEM file <PEM file name> for profile <profile name>: error:0D07803A:asn1 encoding routines:ASN1_ITEM_EX_D2I:nested asn1 error

In this error message, note the following:

  • <PEM file name> is the name of the key file
  • <profile name> is the name of the SSL profile from the iApp

For example:

01070313:3: Error reading key PEM file /Common/PasswordKey.key for profile /Common/HttpsPassword.app/HttpsPassword_client-ssl: error:0D07803A:asn1 encoding routines:ASN1_ITEM_EX_D2I:nested asn1 error

Message Location

You may encounter this message in the following locations:

  • The Configuration utility
  • The /var/log/tomcat/catalina.out file
  • The /var/log/webui.log file

Description

This message occurs when the following condition is met:

  • You attempt to use a password-protected key in an iApp deployment.

Impact

The error prevents you from deploying the iApp template.

Recommended Actions

To work around this issue, after you deploy the iApp, you can create a clientssl profile outside the iApp template using the appropriate password protected certificate and key. To do so, perform the following procedures:

Create a Client SSL profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Click Create.
  4. Type a name for the SSL profile.
  5. From the Parent Profile menu, select clientssl.
  6. Select the Custom check box.
  7. Select the associated certificate and key you imported.
  8. In the Passphrase box, enter the passphrase.
  9. Click Finished

Disable the Strict Updates option

Impact of procedure: Your change will be overwritten and your custom profile will be removed once you update your iApp application. You should not modify iApp deployments by way of the iApp if strict updates are disabled.

  1. Log in to the Configuration utility.
  2. Navigate to iApps > Application Services, and select the appropriate iApp template.
  3. Click the Properties tab.
  4. From the menu, select Advanced.
  5. Clear the check box next to Strict Updates.
  6. Click Update.

Apply the Client SSL profile to the virtual server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Servers List.
  3. Select the virtual server that is associated with the iApp template.
  4. From the clientssl menu, select the newly created clientssl profile.
  5. Click Update.
