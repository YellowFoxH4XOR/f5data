Known Issue

The BIG-IP APM customization template may fail to synchronize with peers.

This issue occurs when all of the following conditions are met:

  • An administrator customized the BIG-IP APM system's customization template.
  • You attempt to synchronize the configuration change to peer systems.

Impact

The customization template fails to synchronize to the peer BIG-IP APM systems in the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP APM administrators are unable to synchronize customization template changes to the BIG-IP APM systems in the device group.
  • In the /var/log/ltm file, you observe error messages similar to the following examples:

    err mcpd[6370]: 01070711:3: Caught runtime exception, Failed to collect files (get_files_to_sync:() :snapshot path () req (12158) pmgr (12158) not valid msg (modify { customization_template_file { customization_template_file_customization_group_name "/Common/<object name>"

    err mcpd[6370]: 01070712:3: Caught configuration exception (0), verify_sync_result:() :Failed to sync files. - sys/validation/FileObject.cpp, line 6196.

Workaround

To work around this issue, you can apply the Overwrite Configuration sync option and perform the synchronization operation again. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will overwrite the configuration on the target systems.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Overview.
  3. Click to highlight the device group you want to manage.
  4. Click to highlight the device you want to synchronize.
  5. Click Sync Device to Group.
  6. Select the Overwrite Configuration check box.
  7. To start the synchronization operation, click Sync.
