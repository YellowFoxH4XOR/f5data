K9503: The BIG-IP ASM No Logging profile logs violations if any learning suggestions options are enabled or alarms are triggered

Topic

The BIG-IP ASM No Logging profile logs violations if any learning suggestion options are enabled or alarms are triggered. This behavior is by design and expected. This behavior allows the system to log any violations that generate learning suggestions or trigger any alarms that are configured within a policy, which were not found or configured during the initial configuration of the web application.

If you want to disable all logging, including alarms and learning suggestions, perform the following four procedures:

  • Ensuring that only the Blocking Mask is enabled for the policy
  • Ensuring Learn and Alarm are disabled within the Attack Signature Sets Assigment settings
  • Disabling Signature Staging within the Signature Staging Configuration
  • Disabling Tightening on wildcard object types, objects, or parameters

Important: If any of the following procedures are not performed, the BIG-IP ASM will continue to log the related requests.

Ensuring that only the Blocking Mask is enabled for the policy

To ensure that only the Blocking Mask is enabled for the policy, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Web Applications.
    A  new screen will open.
  3. Click Policy.
  4. Select Settings from the Blocking menu.
  5. Clear the Learn and Alarm check boxes.
  6. Click the Save button to save the changes.

Ensuring Learn and Alarm are disabled within the Attack Signature Sets Assigment settings

To ensure Learn and Alarm are disabled within the Attach Signature Sets Assignment settings, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Web Applications.
    A new screen will open.
  3. Click Policy.
  4. Click Attack Signatures.
  5. Clear the Learn and Alarm check boxes.
  6. Click the Update button to save changes.

Disabling Signature Staging within the Signature Staging Configuration

To disable Signature Staging within the Signature Stating Configuration, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Web Applications.
    A new screen will open.
  3. Select the Signature Staging Configuration menu.
  4. Clear the Enable Signature Staging check box.
  5. Click the Save button to save the changes.

Disabling Tightening on wildcard object types, objects, or parameters

If you have any Wildcard Object Types, Objects, or Parameters configured, you must disable Tightening. For more information, refer to the  BIG-IP ASM Configuration Guide.
