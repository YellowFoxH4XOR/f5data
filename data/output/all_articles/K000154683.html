Description

When using BIG-IP SSL Orchestrator (SSLO) in an explicit proxy configuration, you may experience intermittent web browsing failures.

The following RST cause may be observed:

[F5RST(peer): service : got abort over cmp]

 

Environment

Product: BIG-IP SSL Orchestrator (SSLO)

 

Cause

This RST can occur when a client sends a subsequent request using an existing connection, but the relevant server-side connection between SSLO and the web server has been deleted for some reason.

 

Recommended Actions

Disabling the Web Cache feature on any inline HTTP proxy used within an SSLO explicit proxy service chain may resolve the issue.

We recommend opening a support case for further investigation.
