Known Issue

You cannot disable Internet Protocol version 6 (IPv6) addresses on the BIG-IP system. The BIG-IP system can send IPv6 network solicitations and advertisements even if the BIG-IP system is not configured or licensed for IPv6.

F5 Product Development tracked this issue as CR53681 and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM, or WebAccelerator release notes.

Workaround

You can perform a partial workaround for this issue by configuring an IP filter that blocks IPv6 addresses on all self IP and virtual server addresses. However, traffic traversing the management interface would not be affected by the IP filter.

After upgrading to BIG-IP 10.0.0 or later, you can prevent the BIG-IP from sending or receiving any IPv6 traffic. To do so, perform the procedure in K15056: Disabling IPv6 on a BIG-IP system.
