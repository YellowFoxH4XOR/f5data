K65838000: RFS sync failure (nCErrno(ECONNREFUSED): Connection refused)

Type
Support Solution
Published
2020-11-27
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K65838000

Description

You have a Thales (nCipher) netHSM environment and unable to synchronise to RFS resulting in a "Connection refused" error.

# /opt/nfast/bin/rfs-sync --update
Starting synchronisation, task ID 5fb8f2f5.600fcccb66666666
Unable to query generation file: RemoteServerFailed, <us> (nCErrno(ECONNREFUSED): Connection refused).

Environment

  • BIG-IP
  • Thales (nCipher) netHSM
  • RFS sync

Cause

Network connectivity issues to RFS

Recommended Actions

Troubleshoot network connectivity to RFS destination IP address and tcp port (9004 default):
  1. telnet <RFS_IP> 9004
  2. Check firewall settings (if any)
  3. Check RFS to ensure port 9004 is open.  If this is a BIG-IP, check port lockdown settings.
  4. Check RFS is installed correctly.  If installed on BIG-IP, refer to manual chapter (Setting up the RFS on the BIG-IP system) for your software version
