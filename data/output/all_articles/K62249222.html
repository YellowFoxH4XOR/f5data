Issue

Error Message

err mcpd[<PID>]: 01071246:3: Unable to reload the dns cache

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

err mcpd[4315]: 01071246:3: Unable to reload the dns cache

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The dnscached process fails to reload configuration files.

For example, this can occur when the BIG-IP system restarts and the command to reload the configuration executes before the dnscached process starts.

Impact

The dnscached process may have an invalid configuration. DNS cache functionality on the BIG-IP APM system may be impaired.

Recommended Actions

To workaround this issue when the BIG-IP system has finished restarting, you can re-enable the dnscached process and reload the configuration. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Temporarily disable the dnscached process by typing the following command:

    modify /sys db dns.cache value disable

  3. Re-enable the dnscached process by typing the following command:

    modify /sys db dns.cache value enable

  4. Verify dnscached is enabled by typing the following command:

    list /sys db dns.cache
