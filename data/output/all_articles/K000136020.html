K000136020: BIG-IP APM EPI blocks VPN connections to HTTP and untrusted HTTPS virtual servers on web browsers

Type
Support Solution
Published
2023-09-04
Updated
2024-05-03
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000136020

Description

Beginning in APM Clients 7.2.4.4, for enhanced security, when users connect to network access VPN using a web browser to HTTP and untrusted HTTPS virtual servers with endpoint inspection (EPI) configured in the BIG-IP APM access policy, the endpoint inspector blocks the connection by default.

This behavior does not apply when EPI is not configured in the access policy.

Environment

  • BIG-IP APM network access VPN
  • Web browser
  • Endpoint inspection configured in access policy
  • APM Clients 7.2.4.4

Cause

New behavior beginning from APM Clients 7.2.4.4.

Recommended Actions

F5 recommends that you configure trusted certificates on the Client SSL profiles on your BIG-IP APM network access servers so that users can continue to connect to VPN after you upgrade to APM Clients 7.2.4.4.

If you must allow network access VPN connections to untrusted virtual servers from users' web browsers, refer to the following procedures as appropriate for the client operating systems:

Prerequisite: You have administrator privileges on the client device.

  • F5 endpoint inspector on Windows
  • F5 endpoint inspector on MAC OS
  • F5 endpoint inspector on Linux

F5 endpoint inspector on Windows

Create registry keys to allow VPN connections to untrusted virtual servers. To do so, perform the following procedure:

Impact of procedure: Use caution when making changes to the Windows registry with caution. Ensure you have performed a backup of the registry. Errors while editing the Windows registry may create issues that you can solve only by reinstalling the operating system.

  1. Click the Start menu.
  2. Enter regedit.
  3. Go to the following registry key:

    Computer\HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\F5 Networks\RemoteAccess

  4. Create or edit the following DWORD32bit value pair:

    Note: By default, these registry keys do not exist. However, you may observe them already created if BIG-IP Edge Client is installed on the system beginning from APM Clients 7.2.4.2.

    AllowHTTPConnections - 1
    AskAboutUntrustedSSLCert - 1

  5. Close the regedit utility.

F5 endpoint inspector on MAC OS

Create and edit the /etc/f5/f5_epi.conf file to allow VPN connections to untrusted virtual servers. To do so, perform the following:

Important: If F5 Endpoint Inspector all-user/machine installation was previously performed, /etc/f5/f5_epi.conf already exists and you can skip step 2 below.
For per-user installation of F5 EPI, perform step 2 to create the file manually. F5 recommends all-user/machine installation for enhanced security.

  1. Open a terminal session.
  2. Enter the following commands to create the directory /etc/f5 and config file if they are not already there.

    mkdir /etc/f5
    touch /etc/f5/f5_epi.conf
    chmod 644 /etc/f5/f5_epi.conf

  3. Use your favorite editor to create and edit /etc/f5/f5_epi.conf as follows:

    ALLOW_UNTRUSTED_SERVERS=yes
    ALLOW_HTTP_SERVERS=yes

    By default, the settings are:

    ALLOW_UNTRUSTED_SERVERS=NO
    ALLOW_HTTP_SERVERS=NO

F5 endpoint inspector on Linux

Create and edit the /opt/f5/f5_epi.conf file to allow VPN connections to untrusted virtual servers. To do so, perform the following procedure:

Important: When F5 Endpoint Inspector is installed, /opt/f5/f5_epi.conf already exists and you can skip step 2 below.

  1. Open a terminal session.
  2. Enter the following commands to create the directory /opt/f5 and config file if they are not already there.

    mkdir /opt/f5
    touch /opt/f5/f5_epi.conf
    chmod 644 /opt/f5/f5_epi.conf

  3. Use your favorite editor to create and edit /opt/f5/f5_epi.conf as follows:

    ALLOW_UNTRUSTED_SERVERS=yes
    ALLOW_HTTP_SERVERS=yes

    By default, the settings are:

    ALLOW_UNTRUSTED_SERVERS=NO
    ALLOW_HTTP_SERVERS=NO
