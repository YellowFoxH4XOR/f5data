Topic

Certain settings in a DESKTOP.INI file present in a folder can change the behavior of the Windows Explorer client accessing the folder. For example, settings in the DESKTOP.INI file may cause the Security tab to be missing when the client is looking at the properties of files in that folder.

This behavior is expected. The ARX system will import the DESKTOP.INI file into the volume, and the behavior of Windows Explorer clients will be affected by it when browsing that folder in the volume.

However, the behavior may be mistaken for an issue with the ARX system, since browsing directly to an arbitrary back-end file storage device within the volume may not reproduce the behavior. The behavior only reproduces when browsing directly to the particular back-end file storage device that the DESKTOP.INI file was imported from. If you are experiencing similar behavior, check for the presence of a DESKTOP.INI file.

Workaround

You can work around this issue by renaming or deleting any DESKTOP.INI files using the ARX CIFS service.

Note: For more information about the DESKTOP.INI file and Windows Explorer, refer to your product documentation.
