Known Issue

EPSEC OPSWAT files may remain in the filestore after deletion.

This issue occurs when the following conditions are met:

  • You have multiple EPSEC OPSWAT packages installed on your BIG-IP APM or Edge Gateway system.
  • You use the Configuration utility to delete an EPSEC OPSWAT package.

Impact

The file system size does not decrease after deleting EPSEC OPSWAT packages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The EPSEC OPSWAT package does not display in the System > Software Management > Antivirus Check Updates page of the Configuration utility; however, a corresponding file exists in the /config/filestore/files_d/Common_d/epsec_package_d/ filestore.
  • The EPSEC OPSWAT package is deleted from the Configuration utility; however, the package is included in the UCS archive.

Workaround

To work around this issue, after deleting the EPSEC OPSWAT package from the Configuration utility, you can manually remove the corresponding EPSEC OPSWAT package file from the filestore.

Manually removing the EPSEC OPSWAT package file from the filestore

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM command line.
  2. Change to the EPSEC filestore directory by typing the following command:

    cd /config/filestore/files_d/Common_d/epsec_package_d/

  3. Remove the residual EPSEC package file from the filestore by typing the following command:

    rm -f <epsec_package_file_name >

    For example:

    rm -f \:Common\:epsec-1.0.0-393.0.iso_63609_1
