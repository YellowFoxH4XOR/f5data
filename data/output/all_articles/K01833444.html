Known Issue

The Traffic Management Microkernel (TMM) drops tunneled traffic when you set the connection.vlankeyed system database variable to disable.

This issue occurs when all of the following conditions are met:

  • A tunnel is configured.
  • The local address associated with the tunnel resides in a non-default route domain.
  • The BIG-IP connection.vlankeyed database variable is set to disable; the default setting is enabled.

Impact

The BIG-IP system drops tunneled traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system drops tunneled traffic even though the corresponding tunnel is created correctly.
