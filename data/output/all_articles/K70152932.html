Topic

You should consider using this procedure under the following condition:

  • You want to view the list of OPSWAT antivirus vendors supported by your BIG-IP APM version.

Description

You can generate a list of known supported OPSWAT antivirus vendors and versions used by the BIG-IP APM system from the BIG-IP APM system command line.

The following procedure demonstrates how to generate this list for Windows, Mac OS, and Linux.

Note: To view BIG-IP APM supported operating systems and versions, refer to K14047: Supported operating systems and web browsers for the BIG-IP APM system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command-line access to the BIG-IP APM system.
  • You have a general familiarity with the Linux command line.

Procedures

View the OPSWAT supported antivirus vendors and versions for your BIG-IP APM release

This procedure shows you how to derive a list of OPSWAT supported antivirus vendors and tested releases for your version of BIG-IP APM (non-VIPRION platform).

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP APM system.
  2. Change directories to the OPSWAT antivirus XML file location using the following command syntax:

    cd /var/sam/www/admin/vpe2/private/xml/opswat_v<opswat version number>

    Important: Replace <opswat version number> with the OPSWAT version number at the end of the XML file.

    For example:

    cd /var/sam/www/admin/vpe2/private/xml/opswat_v4

  3. To view supported endpoint device operating systems, enter the following command:

    ls

    Output appears similar to the following example:

    linux  mac  windows

  4. To access files based on your endpoint device operating system, change directories to the appropriate directory.

    For example, for the Linux operating system, enter the following command:

    cd linux

  5. After you have accessed the operating system directory, use one of the following command syntaxes to view the supported antivirus software and versions:
    • Linux:

      grep Signature_Name Linux_ANTIMALWARE_Support_Chart_<opswat version number>.xml | sed s'/" /"\#/'g  | cut -d\# -f 22,24,26 | sed s'/="/ /'g |sed s'/\#/,/'g | awk '$1 ~ /Signature_Name/ {$1=""; print $0}' | grep -v Signature_ID | sort

    • Mac OS:

      grep Signature_Name Mac_ANTIMALWARE_Support_Chart_<opswat version number>.xml | sed s'/" /"\#/'g | cut -d\# -f 22,24,26 | sed s'/="/ /'g |sed s'/\#/,/'g | awk '$1 ~ /Signature_Name/ {$1=""; print $0}' | grep -v Signature_ID | sort

    • Microsoft Windows:

      grep Signature_Name Windows_ANTIMALWARE_Support_Chart_<opswat version number>.xml | sed s'/" /"\#/'g  | cut -d\# -f 22,24,26 | sed s'/="/ /'g |sed s'/\#/,/'g | awk '$1 ~ /Signature_Name/ {$1=""; print $0}' | grep -v Signature_ID | sort

      VIPRION

      For VIPRION platforms licensed and provisioned with BIG-IP APM 14.1.0 and later, you can view a list of antivirus vendors and software versions using the following command stanza:

      cat <OS name>_ANTIMALWARE_Support_Chart_4.xml | sed s'/UpdateDefinitions=/\n/'g | grep Antivirus | sed s'/" /\t/'g | awk -F $'\t' '{print $27,$29,$30,$31}' | cut -c 16-900 | sort -u

      Note: Replace <OS name> with one of the following: Windows, Linux, Mac.

      For example:

      cat Windows_ANTIMALWARE_Support_Chart_4.xml | sed s'/UpdateDefinitions=/\n/'g | grep Antivirus | sed s'/" /\t/'g | awk -F $'\t' '{print $27,$29,$30,$31}' | cut -c 16-900 | sort -u

      Note: The output of these commands differs from the example output from the previous section as the XML file scheme and details are different then the ANTIMALWARE XML file scheme and details found on non-VIPRION platforms.
