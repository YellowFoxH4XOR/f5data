If a BIG-IP node's IP address changes in your environment and you need to update the associated poolmember instances with the new address, you'll need to take several actions. You need to identify all the pools that the poolmember belongs to, add the new instance of the poolmember with the new IP address, remove the old instance of the poolmember with the old IP address, and remove the associated node. If this is one or two poolmembers, it will not take much effort; however, if the node is a poolmember in multiple pools, then it can be very tedious and time consuming to repeat the previous tasks on all the pools.

For this reason the MyF5 team created a bash script to automate updating a poolmember's IP address in multiple pools. While it's possible to update IP addresses by performing a search and replace on the bigip.conf file and then attempting to verify all the replacements, and reloading the configuration, the script in this article shows you the changes that will be made prior to running all the commands and targets only the configuration objects you want to be changed; therefore, this is a safer option.

Prerequisites

  • You have administrative access to the BIG-IP Advanced Shell (bash)

Procedures

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Create a UCS backup of the configuration before running the script by typing the following command:
    tmsh save sys ucs $HOSTNAME-$(date +%H%M-%m%d%y).ucs
    For more information about backing up and restoring the configuration refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.
  3. Move a copy of the UCS to a secure location off the BIG-IP.
  4. Change directories to /var/tmp by typing the following command:
    cd /var/tmp
  5. Create a new file for the script and open it for editing with vi.
    vi myf5-pm-replace.bash
  6. Type i to enter insert mode.
  7. Copy the following contents into the file:

    #Script created by MyF5 knowledge base team for article K000137953

    #Collect new IP address, old IP address and partition name from user on CLI 
    read -p "Enter NEW IP > " newip 
    read -p "Enter OLD IP > " oldip  
    read -p "Enter Partition Name > " partitionname

    #Set partitionname to Common if no input is detected.
    if [[ -z "$partitionname" ]]; then
        partitionname="Common"
    fi

    echo "The following commands will be run:" 
    echo -e "\n"  

    #Loop through list of ltm pools that oldip belongs to 
    #Find pools with grep of oldip on one-line pool output 
    tmsh -c "cd /$partitionname; list ltm pool one-line" | grep $oldip | while read ltmpool; 
        do 
            #Create pool variable with awk that prints pool name in third column 
            #Create member variable with regex to get IP:PORT 
            pool=$(echo $ltmpool | awk '{print $3}') 
            member=$(echo $ltmpool | egrep -o $oldip:'[-_/\.\+\*a-zA-Z0-9]*')  
            
            #Remove newlines in case of multiple members 
            oldmembers=${member//[$'\n']/ }  
            
            #tmsh modify ltm pool fails if * is in port name so translate 
            #port name sql*net or any future port name with * to port number with 
            #getservbyname python function 
            for i in $oldmembers 
                do 
                    ip=$(echo $i | cut -d':' -f1) 
                    port=$(echo $i | cut -d':' -f2) 
                    if [[ $port =~ \* ]]; then 
                        portnum=$(python -c "from socket import getservbyname; import sys; \
                        print(getservbyname(sys.argv[1]))" $port) 
                        portnummem="$ip:$portnum" 
                        oldmembers=${oldmembers//"$i"/$portnummem} 
                    fi 
            done  
            
            #Create variable and replace oldip with newip in oldmembers variable 
            newmembers=${oldmembers//$oldip/$newip}  
            
            #Finally print out commands that will be run and add them to the 2nd script 
            echo "tmsh -c 'cd /$partitionname; modify ltm pool $pool members add { $newmembers }'" | tee -a tmp-K000137953 
            echo "tmsh -c 'cd /$partitionname; modify ltm pool $pool members delete { $oldmembers }'" | tee -a tmp-K000137953 
            echo -e "\n" 
    done  

    #This command may fail if the node is referenced in two or more partitions on the BIG-IP system.
    #In which case, you must first run the script for the partition the node was initially configured and then run the script for the remaining partitions.
    echo "tmsh -c 'cd /$partitionname; delete ltm node $oldip'" | tee -a tmp-K000137953 
    echo -e "\n"  

    #Ask user to confirm executing 2nd script 
    #Run 2nd script and save configuration 
    read -p "Proceed with commands? (y|n) " proceed 
    if [[ $proceed == n || $proceed == N ]]; then 
        echo "Exiting" 
    elif [[ $proceed == y || $proceed == Y ]]; then 
        bash tmp-K000137953 
        tmsh save sys config partitions all
    else 
        echo "Invalid answer" 
    fi 
    rm tmp-K000137953

  8. Review the comments in the script to understand what it's doing. Note that the script does not incorporate any error checking and assumes that the node you want to change exists only in one partition. If the node is referenced in pools which are configured in two or more partitions, then you must first run the script for the partition the node was initially configured and then run the script for the remaining partitions. For example, if nodeA was initially configured in poolX in the Common partition and then referenced in poolY in the example2 partition, you must run the script first for the Common partition to update nodeA's IP address in poolX and then subsequently run the script for the example2 partition to update nodeA's IP address in poolY.
  9. Press ESC to exit insert mode.
  10. Save and close the file by typing the following command:
    :wq
  11. Remove carriage return characters if pasting from a windows workstation using the following command:
    sed -i 's/\r$//' myf5-pm-replace.bash
  12. Execute the script with the following command:
    bash myf5-pm-replace.bash
  13. Enter the new IP address, old IP address, and the partition where the node resides in at the prompt.

    Note: If you do not enter anything for the partition prompt, the script will use the Common partition by default.

  14. The script shows you the commands that it will run. Verify that everything looks correct and hit y to proceed or n to cancel.
  15. If the BIG-IP is part of an HA pair device group, sync the changes to the peer device using the following command syntax:

    tmsh run cm config-sync to-group <device group name>

    For example:

    tmsh run cm config-sync to-group mygroup
