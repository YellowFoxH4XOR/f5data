K000136097: [F5OS] Host assigned and tenant available memory show different values

Type
Support Solution
Published
2023-09-12
Updated
2023-09-12
Source
https://my.f5.com/manage/s/article/K000136097

Description

When creating or editing tenant deployments in F5OS, the memory field for type BIG-IP does not match available memory inside the running tenant.

Environment

  • F5OS
  • BIG-IP Tenants

Cause

Tenant deployments have memory overhead associated with running tenant virtual machines. The overhead is small percentage of total memory assigned to the tenant, higher memory allocations result in less overhead. Table below is representative and environments vary;

F5OS Assigned MemoryTenant Available Memory
100009763
2000019607
3000029451
4000039295
5000049139
6000058983
7000068827
