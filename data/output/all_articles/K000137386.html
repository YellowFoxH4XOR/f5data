K000137386: iControl REST Child Daemon, Transaction time expired.

Type
Support Solution
Published
2024-11-26
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000137386

Description

customer may find the change through RestAPI failed with alert logs as below:

/var/log/icrd 

notice icrd_child[<PID>]: iControl REST Child Daemon, INFO,Transaction [<Transaction ID>] time expired.

notice icrd_child[<PID>]: iControl REST Child Daemon,WARNING,Task not found - ID: [<Transaction ID>] user: admin

/var/log/restjavad-audit

[<PID>][<Time>][ForwarderPassThroughWorker] {"user":"local/admin","method":"PATCH","uri":"http://localhost:8100/mgmt/tm/transaction/<Transaction ID>/","status":404,"from":"192.168.0.1"}

Environment

  • RESTApi
  • RestJavad
  • ICRD

Cause

There could be many reasons which trigger this error, this error does not indicate anything wrong on big-ip definitely, tcpdump on the 8100 interface would help to locate the exact root cause for the latency.

tcpdump ‐s0 ‐ni lo port 8100 ‐w /var/tmp/$HOSTNAME-restcall.pcap ‐v

Recommended Actions

Before you find the root cause of the latency, you can try edit the transaction timeout of icrd on big-ip as below

vi /etc/icrd.conf

find the line with "transactionTimeoutSeconds" as below

"transactionTimeoutSeconds" : 154,

Extend the value to larger , then save the conf

the last step is to restart restjavad to make the change above take effect

#tmsh restart sys service restjavad

Additional Information

None.
