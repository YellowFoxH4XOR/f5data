Description

Power BI Application installed on phone managed by Intune cannot authenticate using SAML

Environment

  • BIG-IP APM
  • Power BI Application
  • Intune managed device
  • 302 redirect

Cause

Power BI application on Intune-managed devices does not follow HTTP 302 redirects as required by the access policy configuration for SAML authentication. This behavior prevents proper communication between the IdP and SP, leading to failed authentication attempts.

Recommended Actions

If the application does not support following HTTP 302 redirects, contact Microsoft or your application vendor for assistance in resolving this limitation.
