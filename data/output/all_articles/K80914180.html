Description

nPath routing deployed using iApps stopped working after upgrade.

Environment

  • BIG-IP platform using RSS DAG hash (such as BIG-IP VE, 2000 or 4000 platform)
  • Upgraded from version prior to 13.1.0
  • nPath routing deployed using f5.npath iApp template

Cause

Bug ID 890229: Source port preserve setting is not honoured

Recommended Actions

Change the source port settings from "Preserve" to "Preserve-Strict".

  1. Log into GUI.
  2. In  iApps > Application Services and click the name of the Application service.
  3. Click the Properties tab.
  4. Set Configuration to Advanced.
  5. Clear the check box for Strict Updates.
  6. Click Update.
  7. Go to the affected virtual server 
  8. Select Advance.
  9. Change Source Port from "Preserve" to "Preserve Strict".
  10. Select Update.
