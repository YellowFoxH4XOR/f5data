Description

When configuring the BIG-IP as an Identity Provider IdP and a Service Provider SP send a SAML Authn Request to the BIG-IP with a RelayState, the RelayState is missing when the BIG-IP as IdP returns the SAML Assertion to the SP.

Environment

  • BIG-IP APM
  • BIG-IP as SAML IdP

Cause

This is due to manual configuration of the SP or modification of the SSO URL located on the SP.

Recommended Actions

 This SAMLRequest MUST be sent to the proper SSO URL on the BIG-IP ending in saml/idp/profile/redirectorpost/sso
        Example: https://Bigip-idp/saml/idp/profile/redirectorpost/sso

  1. It is always recommended that you configure the SP with the Metadata exported from the IdP.
    This will contain the proper SSO URL for the SP to send the SAML Authn Request to the BIG-IP as IdP

  2. If for some reason the SP cannot import the Metadata into the SP, you will need to modify the SSO URL on the SP to point to the correct URL on the BIG-IP as IdP as noted above.

Additional Information

You can match up the ID= in the SAMLRequest to the InResponseTo= in the SAMLResponse to ensure that the response is being responded to properly (the numbers will be the same).
If you do not see a InResponseTo= in the SAMLResponse, then it is a IdP initiated connection and it is not responding to a SAMLRequest and the SSO URL was most likely incorrect.
