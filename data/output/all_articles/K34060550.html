Issue

Old Behavior

In versions prior to BIG-IP ASM 11.5.0 (versions 11.3.0 through 11.4.1), when a logging profile is associated with multiple virtual servers, the BIG-IP ASM system opens a separate connection to the logging profile's defined log server for each virtual server.

New Behavior

Beginning in 11.5.0, the BIG-IP ASM system opens a single connection to each unique destination log server for all ASM logging profiles that reference the same destination log server and protocol.

F5 Product Development tracked this change as ID 423798.
