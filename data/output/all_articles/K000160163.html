K000160163: VELOS | Stale USB drive information when using show components command

Type
Support Solution
Published
2026-03-13
Updated
2026-03-13
Applies to
  • F5OS
  • F5OS-C: 1.8.X, 1.8.2, 1.8.1, 1.8.0
Source
https://my.f5.com/manage/s/article/K000160163

Description

On VELOS systems, the show components component storage state disks | tab command may display stale USB drive information due to a known bug.

Environment

  • F5 VELOS chassis
  • F5OS-C software version 1.8.2 (and possibly other versions)
  • Dual system controllers (primary and secondary)
  • Storage inventory checked using:
    • show components component storage state disks | tab
    • lsblk
    • lsusb

Cause

Bug ID 2230833: On F5OS-C systems, the show components command may display stale USB drive information after the USB drive is physically removed. The DataTraveler USB drive may have been present during factory assembly for initial software installation, but is not required or present in the field after PXE-based installations.

Recommended Actions

  • If the DataTraveler USB drive is not detected by lsblk or lsusb, and the system was installed or reimaged using PXE, this is expected and does not indicate a hardware fault.
  • The show components command may display stale information about USB drives due to Bug ID 2230833. Always verify actual hardware presence using OS-level commands (lsblk, lsusb).

  • No hardware replacement is required if the USB drive is not present and the system is functioning normally.
  • For clean installations or recovery, follow F5's documented procedures for enabling/disabling the front panel USB as needed.
  • If you require the USB drive for a specific operation (such as a USB-based clean install), ensure the front panel USB is enabled via AOM and insert the USB drive as needed.

Additional Information

  • NVMe SSD model variance (e.g., Micron vs. SVE1S3T84H1F2H21) is expected and not a fault, as long as the drive meets required capacity and performance.
  • The DataTraveler USB drive may be present in hardware inventory output from the factory process, but this does not guarantee its presence in the field.
  • The presence or absence of the DataTraveler USB drive does not impact normal operation unless a USB-based installation or recovery is required.
