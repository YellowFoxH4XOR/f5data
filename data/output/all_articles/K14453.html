Topic

For information about opening a support case for other F5 products, refer to K2633: Instructions for submitting a support case to F5.

F5 Support can help resolve issues more quickly when you provide a full description of the issue and the details of your configuration. To help you gather all the required information, use the following guidelines to prepare for opening a case:

General Information

Provide the following information when you open a case with F5 Support:

  • A full description of the issue, including the following:
    • The symptoms of the issue
    • The approximate time the issue first occurred
    • The number of times the issue has recurred
    • A network diagram indicating the traffic paths involved
    • Any error output provided by the BIG-IP AAM system
    • Steps to reproduce the issue
    • Any changes you made to the BIG-IP AAM appliance before the issue first occurred
    • Any steps you have taken in an attempt to resolve the issue
  • A description of the network link, such as the following:
    • What is the speed of the link between the two sites?
    • What is the percentage of loss between the two sites?
    • What is the Round Trip Time (RTT) between the two sites?
    • How is the speed being measured?
    • What is the throughput with BIG-IP LTM only?
  • A description of the impact that the issue is having on your system and site, using the following definitions:
    • Site Down

      Your network or application is down or critical business functions have stopped due to the issue.

    • Site at Risk

      Your network or application is severely and negatively impacted by the issue.

    • Performance Severely Degraded

      The performance of your network or application has been severely reduced due to the issue.

    • Performance Impaired

      Your network or application is suffering from reduced performance, but otherwise continues to work as expected.

    • General Assistance Required

      The subject of the case does not currently impact your network or application.

  • The hours that you are available to work on the issue with an F5 Support Representative, and any alternative individuals to contact who are aware of the issue, in the event you are unavailable.
  • Remote access information, if possible.

    Note: Remote access to your network environment is important, because it is the most effective method for collecting information and troubleshooting technical issues. If you cannot provide remote access information, F5 Support will work directly with you to resolve the issue over the phone; however, this method can often be more time consuming and may require file transfers, replication, and additional testing.

Product-specific information

Collect the following information from the affected system and provide it when you open the case. For information about sending this information to F5 Support, refer to K000090853: Exchange files with F5 Support using MyF5.

  • A QKView file

    Use the qkview utility to generate a QKView containing the configuration files that F5 Support most frequently needs when troubleshooting an issue.

    For more information about qkview, refer to K12878: Generating diagnostic data using the qkview utility.

  • Provide an explanation of the BIG-IP AAM deployment topology. A network diagram is preferable.
  • Provide any tcpdump information taken from the command line of the impaired traffic and of the normal traffic, if possible, if the issue involves network traffic. F5 also recommends similar session captures from tools like Mozilla Firefox LiveHTTPHeaders or Simtec's HTTPWatch. You can download a copy of the HTTPWatch Basic Edition for free from the HTTPWatch website.

    Note: The previous link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

    For more information about the tcpdump utility, refer to K411: Overview of packet tracing with the tcpdump utility and K6546: Recommended methods and limitations for running tcpdump on a BIG-IP system.

  • Provide an XML export of any relevant policies. You can export policies individually from the Polices page by navigating to Acceleration > Web Application > Policies.
  • Database and Performance report data files:
    • /var/lib/mysql/WA/*

    You can collect the previously listed files into a single TAR file by typing the following command:

    tar czvpf /var/tmp/aam-data.tgz /var/lib/mysql/WA/*

You can transfer files from the BIG-IP AAM system to another system using either the FTP or SCP utilities.
