K000138227: Error message: "Failure for data/openconfig-system:system/ntp API. The server or an underlying service is unreachable."

Support Solution
Published
2024-06-26
Updated

Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.1, 1.5.0
Source

Description

You may get the GUI error message when you check the NTP Time Settings:

Failure for data/openconfig-system:system/ntp API. The server or an underlying service is unreachable.

Environment

  • F5OS-A
  • NTP
  • FQDN
  • GUI
  • CLI

Cause

You have configured an FQDN in the NTP server address by following the F5 document.
Then you check the configs from the GUI, but you get the error message, and this is caused by an internal bug ID1394205.
When the article was published, the bug was not fixed, but you can work around the issue by following the Recommended Actions part.

Recommended Actions

To work around this issue, you need to change the NTP server address from an FQDN to a real NTP server IP address, for the detailed step please check the link here.

For example, if you get the GUI error message, the first step, you need to login to the CLI as the admin privilege account, and then delete the FQDN NTP server config:

# config
(config)# no system ntp servers server                                                   
(config)# commit
Commit complete.

Then the error message should disappear from the GUI, and then you can follow the further steps described in the F5 document to configure a real NTP server IP address.

Additional Information

Apart from the GUI error message, at the same time you can also get the error message "Error: application timeout" from CLI  when you run the command of #show system ntp:

# show system ntp
system ntp state enabled
system ntp state enable-ntp-auth false
Error: application timeout
