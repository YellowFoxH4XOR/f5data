Description

On BIG-IQ Data Collection Devices (DCD), the /var/log partition may become full, resulting in disk full alerts and potential system issues. The primary symptom is the /var/log partition reaching 100% utilization, with log files—particularly those generated by the appiq agent manager—consuming significant disk space. Administrators may observe messages such as "Disk partition /var/log has only 0% free" and find that the /var/log/appiq/ directory contains large or numerous log files.

Environment

  • Product: BIG-IQ
  • Version: 8.4.1
  • Role: Data Collection Device (DCD)
  • /var/log partition size: Approximately 6.8 GB (default)
  • appiq agent manager enabled and generating logs

Cause

Accumulation of old appiq agent manager log files in /var/log/appiq/ on the BIG-IQ DCD. The default /var/log partition size (~7 GB) which may be insufficient for the volume of logs generated over time, leading to the disk full condition.

Answer/Recommended Actions

  1. Immediate Remediation:
    • Manually delete old log files from /var/log/appiq/ to recover disk space.
  2. Increase /var/log Partition Size:
    • Expand the /var/log partition to at least 10–15 GB to prevent recurrence.
    • Example command to increase to 15 GB (run as root or with appropriate privileges):

    tmsh modify sys disk directory /var/log new-size 15728640

    reboot
