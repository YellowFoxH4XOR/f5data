Description

Local users (non-admin and non-root users) cannot authenticate to BIG-IP intermittently, both using Configuration Utility (GUI) or SSH.

  • Link to TACACS+ authentication server is unstable
  • Messages similar to below are logged in /var/log/secure:

err sshd[25832]: pam_tacplus: error communicating with server

notice sshd[25832]: pam_tacplus: Auth server unavailable, trying fallback

Environment

  • BIG-IP
  • TACACS+ remote authentication configured with "Fallback to Local" enabled
  • Local users (other than admin or root) without remote counterpart

Cause

By design, when using TACACS+ remote authentication with "Fallback to Local" enabled, local users without remote counterpart can login only while authentication server is unavailable. Once the authentication server becomes available, local users without remote counterpart cannot login.

Recommended Actions

  • Create a remote counterpart for the local user to be able to authenticate regardless of the authentication server availability

or

  • Change the authentication to local, if no users use remote authentication.
