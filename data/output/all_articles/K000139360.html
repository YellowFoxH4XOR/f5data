Description

After uploading qkview.tar.gz to iHealth, iHealth reports an error:

qkview.tar.gz failed processing

Environment

  • BIG-IP Next
  • Qkview taken from inside the debug sidecar using the qkview_collect command

Cause

The qkview_collect command in the debug sidecar only gathers information about the f5-fsm-tmm deployment. It is not a complete qkview file and iHealth cannot extract it.

Recommended Actions

Instead of running qkview_collect from inside the tmm debug sidecar, use Central Manager to gather the qkview instead. For more information, see How to: Use BIG-IP Next Central Manager to generate and upload to iHealth a QKView file for BIG-IP Next instances.

Important: if the API server is not responding on the BIG-IP Next instance, Central Manager will be unable to gather a qkview.
