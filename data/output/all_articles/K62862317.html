Known Issue

The BIG-IP system does not remove the Cookie Hash Persist entry after closing the corresponding connection and deleting it from the connection table.

This issue occurs when the following condition is met:

  • You have configured Cookie Hash persistence.

Impact

The persistence table grows with orphaned entries.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The persistence table grows with orphaned entries.
  • You may see a slight increase in memory usage if a large number of connections use Cookie Hash persistence.

Resolution
