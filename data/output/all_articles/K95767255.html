Description

User cannot access google.com through BIG-IP SWG after upgrade to 14.1.4.
Capture the traffic on the BIG-IP SWG, SWG receive the Server Hello from google.com, then close the connection.

Environment

  • BIG-IP SWG 14.1.4
  • Virtual Server
  • Client SSL profile and Server SSL profile
  • Per-request policy

Cause

Under investigation.

Recommended Actions

Follow K60612439, manually update the BIG-IP default certificate authority (CA) certificate bundle file (ca-bundle.crt).

None.
