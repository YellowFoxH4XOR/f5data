K000147219: How to add or see new updates on service requests?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-20
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147219

Description

  • When trying to add new messages in current requests, after clicking the Send button, you have the spinning logo appearing and the page is refreshed but the message doesn't seem to appear after that.

Environment

  • F5® Distributed Cloud Console

Answer/Recommended Actions

  • All tickets are accessible to all users with admin role in a tenant.
  • For non admin user, the user who wants to manage the support request can create new tickets with the same unresolved issues.

Cause

  • As per design, a user with admin role can access all tickets created in a tenant whereas users with non admin role can only access tickets created by themselves.
  • This behavior was introduced couple of months back to address unauthorized access to support request for non-admin users.
  • All tickets are accessible to all users with admin role in a tenant. For non admin user, the user who wants to manage the support request can create new tickets with the same unresolved issues.
