Description

After enabling HTTP/2 profile on Virtual Server, logs TCL errors similar to:

01220001:3: TCL error: <iRule_name> <HTTP_REQUEST> - ERR_ARG (line <line_number>)     invoked from within "HTTP::path"

Environment

  • BIG-IP software v14.x or v15.x
  • Enabling HTTP/2 profile on Virtual Server on client-side.

Cause
Bug ID 868889: BIG-IP may reset a stream with an empty DATA frame as END_STREAM

Recommended Actions

Fix to this issue has not yet been included in official release. Please contact F5 Support Team.

Additional Information

Error is triggered, when the client sends a request containing a payload over a stream, ending the stream with empty DATA frame. This behavior was noticed in IE 11.
