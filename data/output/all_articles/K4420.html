Topic

The UCS archive is configured in the bigdb Common.Bigip.CS.save structure. The database keys determine the files and directories in the UCS archive. There are three types of database keys:

  • Keys that specify what files to include
  • Keys that specify what directories to include
  • Keys that specify what files to exclude

Viewing the files and directories that are configured in a UCS archive

To view the files that are configured to be included in a UCS archive, type the following command:

bigpipe db get Common.Bigip.CS.save.*.file*

To view the directories that are configured to be included in a UCS archive, type the following command:

bigpipe db get Common.Bigip.CS.save.*.dir*

To view and the files that are configured to be excluded from a UCS archive, type the following command:

bigpipe db get Common.Bigip.CS.save.*.ignore*

Adding a UCS archive entry

To add an additional file to the UCS archive, perform the following steps:

  1. View the existing entries in the database, using the instructions specified in the section titled, Viewing the files and directories that are configured in a UCS archive.

    Each database key is identical, except for the fifth dot-separated field in the key name, which contains a unique number.

  2. Make a note of the highest numbered key, as you must use a unique number for the new key you want to add.
  3. Add a new key to the database, using the following command syntax:

    bigpipe db set Common.Bigip.CS.save.<number>.file = <filename>

    Where:

    • <number> is one number higher than any existing key
    • <filename> is the full path to the file that you want to include

    For example, if you want to include the /var/tmp/myfile.txt file and the highest existing key number in the database is 480, you would type the following command:

    bigpipe db set Common.Bigip.CS.save.481.file = /var/tmp/myfile.txt

  4. The file you specified will now be included each time a UCS archive is created.

Removing a UCS archive entry

Important: F5 Networks recommends that you only delete keys for files that you have created. If you delete a default key, it will result in an incomplete backup.

To remove a backup file key name from the database, perform the following steps:

  1. View the existing entries in the database, using the instructions specified in the section titled, Viewing the files and directories that are configured in a UCS archive.
  2. Make a note of the name of the key that you want to delete.
  3. Delete the key, using the following command syntax:

    bigpipe db unset <keyname>

    For example, to delete the Common.Bigip.CS.save.481.file key, type the following command:

    bigpipe db unset Common.Bigip.CS.save.481.file

  4. When prompted, confirm the database entry deletion.

Modifying a UCS archive entry

Important: F5 Networks recommends that you only modify keys for files that you have created. If you modify a default key, it will result in an incomplete backup.

To remove a backup file key name from the database, perform the following steps:

  1. View the existing entries in the database, using the instructions specified in the section titled, Viewing the files and directories that are configured in a UCS archive.
  2. Make a note of the name of the key that you want to modify.
  3. Change the value of the key, using the following command syntax:

    bigpipe db set Common.Bigip.CS.save.<number>.file = <filename>

    For example, to change the Common.Bigip.CS.save.481.file value to /var/tmp/myotherfile.txt, you would type the following command:

    bigpipe db set Common.Bigip.CS.save.481.file = /var/tmp/myotherfile.txt
