Known Issue

BIG-IP Edge Client may display sesstimeout.js errors when connecting to network access.

This issue occurs when all of the following conditions are met:

  • The BIG-IP Edge Client User-Agent string is based on Internet Explorer 11.
  • The user accesses a full webtop resource using an Internet Explorer version earlier than 11.
  • The user has enabled the Internet Explorer Display notification about all script errors setting.

Impact

There is no impact; You can safely ignore this error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When accessing a webtop resource through BIG-IP Edge Client, users receive a script error message similar to the following example:

    Error: 'Syntax Error'
    Code: 0
    String: https://<ip_virtual_server>/vdesk/sesstimeout.js

Resolution

Status

F5 Product Development has assigned ID 417819 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can configure BIG-IP Edge Client to access the resource on a network access webtop.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
