K000139822: Log rotation not working for Nginx access / error logs after RedHat OS upgrade

Type
Support Solution
Published
2024-05-29
Updated
2024-05-30
Applies to
  • NGINX Products
  • NGINX Plus: R31
Source
https://my.f5.com/manage/s/article/K000139822

Description

  • Following an OS upgrade to Redhat 9.3, the logrotate service is no longer rotating the nginx logs

Environment

  • RedHat 9.3.
  • NGINX Plus R31
  • Log rotation service

Cause

  • Following the OS upgrade the logrotate.timer service was found to be disabled. 

Recommended Actions

  • To ensure log rotation occurs as expected, the logrotate.timer service needs to be enabled and started. This was done with the following commands:
             sudo systemctl enable logrotate.timer
        
             sudo systemctl start logrotate.timer
  • Once enabled and started, the timer will be waiting for its next scheduled time to activate the associated service (logrotate.service) and perform log rotation according to the specified configuration.
