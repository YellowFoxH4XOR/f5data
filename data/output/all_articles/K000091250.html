K000091250: Applying a secure policy, it just keeps loading but not applied

Type
Support Solution
Published
2022-02-10
Updated
2022-03-02
Source
https://my.f5.com/manage/s/article/K000091250

Description

When trying to apply an ASM policy from the Configuration Utility, it seems like is loading, never stopping and either applying the policy. Next logs are present in asm_config_server logs:

 asm_config_server 2022-01-10 09:17:13.492 -06:00 Error asm_config_server.pl[16361] F5::ASMConfig::Handler::handle_error,,Code: 303, Error message = Apply Logging profile operation failed. Error:

 asm_config_server 2022-01-10 03:18:47.039 -06:00 Error asm_config_server.pl[16361] F5::ASMConfig::Handler::log_error_and_rollback,,Apply Logging profile operation failed. Error:

asm_config_server 2022-01-10 03:18:47.035 -06:00 Error asm_config_server.pl[16361] F5::ASMConfig::Handler::handle_error,,Code: 303, Error message = Apply Logging profile operation failed. Error:

 Environment

  • Applying an ASM policy

  • Configuration Utility

 Cause

Unknown

 Recommended Actions

To fix the issue, follow next steps:

1) Kill asm_config_server service with the next command:

# pkill -f asm_config_server

2) Reboot the F5

None
