Old Behavior

In versions prior to BIG-IP 11.0.0, the BIG-IP configuration files, such as the bigip.conf file and the bigip_base.conf file, reside only in the /config directory.

New Behavior

Beginning in BIG-IP 11.0.0, the BIG-IP configuration files may reside in multiple locations. BIG-IP configurations for the Common partition continue to exist in the BIG-IP configuration files that reside in the /config directory. If there are BIG-IP configurations for a partition other than the Common partition, the configurations exist in configuration files located in the /config/partitions/<partition name>/ directory.

For example, if there is a self IP configured for the ExampleA partition, the self IP is in the /config/partitions/ExampleA/bigip_base.conf file.

Impact

If you use the command line or Traffic Management Shell (tmsh) to modify a partition other than the Common partition, you must perform the configurations on the specific partition.

Recommended Actions

When using tmsh with partitions other than the Common partition, F5 recommends that you consider the following information:

Note: To run the following commands, you must be logged in to tmsh.

  • Changing partitions to the partition you want

    To change partitions, use the following command syntax:

    cd /<desired partition name>

    For example, to change the partition to the ExampleA partition, you would type the following command:

    cd /ExampleA

  • Specifying the partition name as part of the object name

    For example, to create a BIG-IP LTM pool ExamplePool with member 10.10.22.212:80 under the ExampleA partition, you would type the following command:

    create ltm pool /ExampleA/ExamplePool members add { 10.10.22.212:80 }

  • Saving the configuration changes

    When using tmsh to save configuration changes for a partition other than the Common partition, you must use the partitions option when saving the configuration. To save a configuration change, use the following command syntax:

    save /sys config partitions <part-name | all>

    For example, to save a configuration change made in the ExampleA partition, you would type the following command:

    save /sys config partitions { ExampleA }

    Alternatively, to save a configuration change for all partitions, you would type on of the following commands:

    BIG-IP 11.3.0 and later 

    save /sys config

    BIG-IP 11.0.0 through 11.2.1

    save /sys config partitions all

  • Loading configuration files

    When using tmsh to load configuration files for a partition other than the Common partition, you must use the partitions option when specifying the file to load. To load configuration files, use the following command syntax:

    load /sys config partitions <part-name | all>

    For example, to load configuration files for the ExampleA partition, you would type the following command:

    load /sys config partitions { ExampleA }

    Alternatively, to load configuration files for all partitions, you would type one of the following commands:

    BIG-IP 11.3.0 and later 

    load /sys config

    BIG-IP 11.0.0 through 11.2.1

    load /sys config partitions all
