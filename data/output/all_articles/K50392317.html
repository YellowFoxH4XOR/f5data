Description

You may wish to allow for external resources not to be masked behind your configured portal access resource.

Environment

  • BIG-IP APM
  • Portal Access Resource
  • Rewrite Profile
  • External Links embedded in the Application

Cause

The default rewrite profile rewrites all traffic that originates from the portal access application.

Recommended Actions

Configure the rewrite profile for split tunneling

  1. Login to the Configuration Utility (GUI)
  2. Navigate to Local Traffic > Profiles > Services > Rewrite
  3. Click the Create New Profile... button
  4. Fill in the required fields, then navigate to Portal (Access) on the left panel
  5. Select Yes in the Enable Split Tunneling dropdown
  6. Fill in the appropriate rewrite or bypass values in the Rewrite List and Bypass List sections from the left panel

Additional Information

Consider these factors when split tunneling is enabled:

  • Access Policy Manager matches the URI to the expressions specified on the Bypass list first. If an expression matches, then the URI is bypassed and links are not rewritten.
  • If the URI does not match the Bypass list, then it is compared to the Rewrite list. If the URI matches the expressions specified on the Rewrite list, the URI links are rewritten. If there are no matches, links are not rewritten.
  • If the URI does not match anything on the Bypass or Rewrite lists, and if the host name in the URI is a short name, not a fully qualified domain name, then links for that URI are rewritten.
