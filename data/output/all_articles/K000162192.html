Description

Clarification of versioning scheme for NGINX Plus as packaged within NGINX Ingress Controller (NIC) 5.5.1, addressing the discrepancy between the version string shown in the NIC changelog and the version reported by the installed software, and confirmation that security vulnerability fixes present in NGINX Plus R37.0.2 are included in NIC 5.5.1.

Environment

  • Product: NGINX Ingress Controller
  • NIC Version: 5.5.1

Cause

The fourth numeric component in the NGINX Plus version (e.g., the ".1" in R37.0.2.1) represents the packaging version, which includes non-code distributable components such as installation scripts, service files, and documentation. The installed software only displays the first three numeric components, which represent the core NGINX Plus code and its security content.

Answer/Recommended Actions

  • The NGINX Plus version included in NIC 5.5.1 (nginx-plus-r37.0.2) contains all security vulnerability fixes referenced in the changelog for R37.0.2.1.
  • The difference in versioning is due to the fourth numeric component being used for packaging updates, which do not affect the core NGINX Plus code or its security content.
  • Users can be assured that the installed version matches the security content described in the changelog, despite the omission of the packaging version in the software-reported string.
  • No action is required for users regarding this versioning difference.

Additional Information

  • The first three numeric components in the version string are intended for developers and represent the core code and security updates.
  • The fourth numeric component is reserved for package maintainers to denote non-code distributable updates and is not displayed by the software.
  • Documentation updates are being considered to clarify this versioning convention and reduce confusion.
