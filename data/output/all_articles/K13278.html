Known Issue

The BIG-IP system does not prevent a user from creating a stateless non-UDP virtual server.

This issue occurs when the following condition is met:

  • A user creates a Stateless virtual server type and selects a non-UPD protocol.

    For example, a user can define the following invalid virtual server configuration:

    virtual stateless_vip {
    stateless
    pool http_pool
    destination 10.24.2.68:http
    ip protocol tcp
    }

The Stateless virtual server type was added in BIG-IP version 10.2.2 to improve the performance of UDP traffic in specific scenarios.

Impact

The virtual server object does not accept or process any traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H374160 on the Diagnostics > Identified > Medium screen.
  • The virtual server drops all packets

Workaround

You can work around this issue by re-configuring the virtual server to remove one of the conflicting options. To do so, perform the following procedure that is appropriate for your traffic:

Virtual server is intended to process non-UDP traffic

Virtual server is intended to process UDP traffic

Virtual server is intended to process non-UDP traffic

If your virtual server is intended to process non-UDP traffic, you must change the virtual server Type to a value other than Stateless, by performing the following procedure:

  1. Log in to the Configuration utility.
  2. Browse to Local Traffic >> Virtual Servers >> Virtual Server List.
  3. Click the name of the affected virtual server.
  4. In the Type field drop-down menu, select Standard.
  5. Click Update to save your changes.

Virtual server is intended to process UDP traffic

If your virtual server is intended to process UDP traffic, you must change the virtual server Protocol to UDP by performing the following procedure:

  1. Log in to the Configuration utility.
  2. Browse to Local Traffic >> Virtual Servers >> Virtual Server List.
  3. Click the name of the affected virtual server.
  4. In the Protocol field drop-down menu, select UDP.
  5. Click Update to save your changes.
