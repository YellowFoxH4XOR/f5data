Known Issue

The BIG-IP system may advertise extraneous Link State Advertisements (LSAs) after deleting a summary suppression route.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is licensed with the BIG-IP Advanced Routing Module (ARM).
  • You configure route health injection (RHI) to advertise default route using Open Shortest Path First (OSPF).
  • You configure a summary route with "not-advertise" option.
  • You delete the summary route.

    For example, you delete the summary route 64.0.0.0/2 in the following configuration:

    router ospf
     redistribute static
     network 10.69.0.0/24 area 0
     summary-address 64.0.0.0/2 not-advertise
    !
    ip route 64.0.0.0/2 Null
    zebos-linux(config)#no ip route 64.0.0.0/2 Null

Impact

There is no functional or traffic impact as the extraneous LSA is immediately aged out.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing packet captures, you notice that OSPF sends LSA for summary route with age 1 and then immediately sends an update with a MAXAGE LSA of 3600.

Workaround

To work around this issue, you can use the IMI shell (imish) to configure static default route instead of RHI for the default route.

Impact of workaround:The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
