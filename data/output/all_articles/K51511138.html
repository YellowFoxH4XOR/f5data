In the /var/log/ltm logs:

Error <device name> mcpd[31376]: 01070927:3: Request failed, data provider (%mcpd-secondary [slot 1]) disconnected from mcpd.
 

Environment

  • BIG-IP LTM.
  • VIPRION.
  • Multiple Blades.

Cause

Bug ID 1305609

Recommended Actions

Force the mcpd process to reload the configuration.

Impact of procedure: BIG-IP system traffic processing is interrupted while the system restarts.

  1. Log in to the Advanced Shell (bash).

       2. To create a null file with the file name forceload in the /service/mcpd directory, enter the following command:

           touch /service/mcpd/forceload

       3. To restart the BIG-IP system, enter the following command:

           reboot
