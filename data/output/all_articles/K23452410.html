Description

You wish to identify the version of Apache installed on BIG-IP.

Environment

  • BIG-IP
  • Apache version

Cause

None

Recommended Actions

The httpd -v command can be run from bash to output the version of Apache. For example, below is an example of a system with Apache version 2.4.6 installed:

httpd -v
Server version: BIG-IP 67.el7.centos.5.0.0.2 (customized Apache/2.4.6) (CentOS)
Server built:   Jun  5 2020 07:18:19

Note: If you are at the (tmos)# prompt, you must first either exit to the Advanced Shell (bash) prompt, or use the following command instead:

run /util bash -c "httpd -v"

Additional Information

Apache version may be updated with each new release of BIG-IP software.
