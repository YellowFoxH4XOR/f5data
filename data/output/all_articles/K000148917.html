Description

While performing the Non-Interactive EUD tests from a USB flash drive, you may come across the situation where System Test results are failed while all other tests are passed. The EUD test result will be looking like shown below:

******************* TEST SUMMARY *****************
   1 System Report         FAILED
   2 Transceiver Report       PASSED
   3 Sensor Test          PASSED
   4 Memory Test          PASSED
   5 Drive Test           PASSED
   6 Packet Path Test        PASSED
   7 Power Supply Test       PASSED
   8 Fan Test            PASSED
   9 Config Module Test       PASSED
**************************************************
Total number of tests that ran:   9
Total number of tests that passed:  8
Total warnings in log:        0
Total errors in log:         1
  11 19 2024 20:12:27 ERROR: 'ascii' codec can't encode character u'\u0409' in position 0: ordinal not in range(128)
  Overall Test Result: FAILED

Environment

  • BIG IP Hardware Appliance
  • EUD Software
  • USB Drive

Cause

This kind of issue can happen due to corrupt USB drive or corrupt EUD software on USB.

Recommended Actions

  • Download the latest EUD software & upload it to the BIG IP, Perform the EUD test from the device boot menuT

       Or

  • Download the latest EUD software & Load the EUD image on a new USB drive, perform the test again from new USB stick.
