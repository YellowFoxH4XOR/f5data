Issue

An F5 product hotfix installation may fail and return the following error message if the hotfix was downloaded from downloads.f5.com using Internet Explorer:

Fullpath contains invalid data

When you use Internet Explorer to download hotfixes using either HTTP or HTTPS, Internet Explorer changes the hotfix filename. As a result, the hotfix installation fails. In most cases, Internet Explorer appends a [1] into the hotfix filename.

For example, if you use Internet Explorer to download the bind-9.3.2-1-BSD_OS-4.1.im BIND hotfix from downloads.f5.com, the hotfix downloaded to your system will have the following filename:

bind-9[1].3.2-1-BSD_OS-4.1.im

When you run the hotfix installation on the F5 device, you will receive the following error message:

Fullpath contains invalid data: /shared/tmp/bind-9[1].3.2-1-BSD_OS-4.1.im

You can work around this issue and complete the hotfix installation by removing the [1] from the filename. Alternatively, you can use a different web browser to download the hotfix, or use FTP as the transport protocol, instead of HTTP or HTTPS.
