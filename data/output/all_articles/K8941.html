Known Issue

This is the result of a known issue. If you configure a pre-logon sequence and select the Save user's session variables to Logon Reports check box on the Device Management : Maintenance : Troubleshooting Tools page, FirePass does not log the pre-logon session variables for users that are assigned to a master group by RADIUS group mapping.

Note: If you select the Save user's session variables to Logon Reports check box on the Device Management : Maintenance : Troubleshooting Tools page, you can view a user’s session variables by clicking the user’s logon name in the Logon column on the Reports : Logons page.

F5 Networks Product Development tracked this issue as CR88976 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-601-9 has been issued for FirePass version 6.0.1 and cumulative hotfix HF-602-2 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
