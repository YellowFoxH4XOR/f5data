Known Issue

This is the result of a known issue. After installing cumulative hotfix HF-603-4, Active Directory authentication and Active Directory dynamic group mapping may fail when nested groups are enabled.

Note: For more information about nested groups, refer to K9472: Change in Behavior: Active Directory authentication and dynamic group mapping now support nested groups.

For Active Directory authentication, this issue occurs when all of the following three conditions are met:

  • In the master group configuration under the Authentication tab, you entered a group name in the User must belong to Domain group (Optional) field.
  • In the master group configuration under the Authentication tab, you selected the Check nested groups check box.
  • The group configured in the User must belong to Domain group (Optional) field is a nested group for the user who is authenticating.

For Active Directory dynamic group mapping, this issue occurs when all of the following three conditions are met:

  • In the Active Directory group mapping method, you selected primaryGroupId and memberOf or memberOf only in the Mapping attribute field.
  • In the Active Directory group mapping method, you selected the Check nested groups while mapping check box.
  • The Active Directory group name configured in the master group mapping table or the resource group mapping table is a nested group for the user who is authenticating.

Important: An additional issue was introduced in cumulative hotfix HF-603-4. For more information, refer to K10314: After installing cumulative hotfix HF-603-4, Active Directory authentication and group mapping may fail when the memberOf attribute contains multiple values.

F5 Product Development has tracked this issue as ID 296501 (formerly CR125615 ) and was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in cumulative hotfix HF-603-4.2 issued for FirePass version 6.0.3.

Note: Cumulative hotfix HF-603-4.2 for FirePass version 6.0.3 was removed from the F5 Downloads site. When a later cumulative hotfix is released, you can resolve this issue by installing that hotfix. For more information about cumulative hotfix HF-603-4.2, refer to K10425: Status of cumulative hotfix HF-603-4.2.

Workaround

You can work around this issue by removing cumulative hotfix HF-603-4. For instructions about removing a hotfix, refer to K3430: Installing FirePass hotfixes.
