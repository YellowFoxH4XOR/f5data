Known Issue

Note: This article applies to the BIG-IP 3400 (C62), 6400 (D63), 6800 (D68), 8400 (D84), and 8800 (D88) platforms.

This is the result of a known issue. Under rare circumstances, the Cavium Nitrox SSL accelerator card will misidentify the number of cores available for processing SSL connections. The card should report 8 cores, and not 16 or 24. When an affected system attempts to use a nonexistent core, the SSL connection will fail.

To identify this issue, review the /var/log/tmm file after the TMM daemon starts. A message similar to the following will be logged:

cn0: Cavium NITROX (24 units); in 64 bit, 99 MHz PCI/X slot.

Note: This issue is a manufacturing defect from our supplier and not a software bug. However, F5 Product Development has provided software resolution.

F5 Product Development tracked this issue as CR69803 and it was fixed in BIG-IP LTM 9.3.1 for the 9.3 software branch, and in BIG-IP LTM 9.4.2 for the 9.4 software branch. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix HF2 issued for BIG-IP LTM 9.3. You may download this hotfix or a later version of the hotfix from the F5 Downloads site.
