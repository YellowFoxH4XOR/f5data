Note: BIG-IP LB is a limited version of BIG-IP that is equipped with a smaller set of features than the full versions. The LB feature set does not contain the Priority load balancing method.

You can achieve an effect similar to Priority load balancing by using the Ratio load balancing mode. If you specify high ratio values, it is possible to send a small amount of traffic to the primary node, thus nearly replicating Priority load balancing.

For example:

node1 ratio 1000000
node2 ratio 1

In this example, node1 will receive 1,000,000 connections for every connection that node2 receives. In the event that node1 becomes unavailable, node2 will receive all traffic.

Clearly, this is not a good solution in cases where the second node is configured with different content, such as a site down page. If this is the case, consider upgrading to a full BIG-IP feature set.
