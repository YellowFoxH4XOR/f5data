Important: BIG-IP 9.6.1 is no longer available on the F5 Downloads site. For information about upgrading or to request 9.6.1, contact F5 Support.

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.6.1. F5 recommends that all customers currently running 9.6.1 install BIGIP-9.6.1-839.0-HF3, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in BIGIP-9.6.1-839.0-HF3 for BIG-IP 9.6.1:
