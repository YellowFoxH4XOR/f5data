Topic

The DNS cache feature provides statistics on queries from the client side, cache hits and misses, nameserver traffic, and different types of errors. A definition of each statistic is described in the Viewing the statistics sub-section of this article.

Description

The DNS cache feature allows the BIG-IP system to resolve DNS requests and respond to repeated DNS queries by serving answers from the cache. For information about configuring the DNS cache feature, refer to K34350074: Overview of the DNS cache feature.

Viewing the statistics

When you have configured your DNS cache feature on your BIG-IP system, you can view the statistics of the cache in the Configuration utility or the tmsh utility. To view the statistics for a specific cache in the Configuration utility, go to DNS >  Caches > Statistics; then select View under the Details column for the cache. To view the statistics for a specific cache in the tmsh utility, enter the following command syntax:

show ltm dns cache <cache type> <cache name>

Depending on your BIG-IP versions and cache configuration, the statistics and their definitions are as follows:

Client Summary: This table provides summary statistics of all clients.

Statistics NameDescription
Total QueriesThe count of all messages received from all clients at the ingress of the cache resolver since the last time the statistics were reset.
Total ResponsesThe count of all messages sent to all clients at the egress of the cache resolver since the last time the statistics were reset.
Answered LocallyThe count of all messages sent to all clients at the egress of the cache resolver that did not send any nameserver queries since the last time the statistics were reset.
Using NameserversThe count of all messages sent to all clients at the egress of the cache resolver that sent at least one nameserver query since the last time the statistics were reset.

Client History: This table provides summary statistics for responses sent to all clients within the last second, the past five minutes, the past hour and the past day.

Statistics NameDescription
Total ResponsesLast 1 secondThe exponential moving average over time of the count of all messages sent to all clients at the egress of the cache resolver over the last second, or since the last time the stats were reset.
Last 5 minutesThe count of all messages sent to all clients at the egress of the cache resolver over the most recent 5 minutes, or since the last time the stats were reset, updated at the top of each minute.
Last 1 hourThe count of all messages sent to all clients at the egress of the cache resolver over the last 1 hour, or since the last time the stats were reset, updated at the top of each 5 minutes.
Last 1 dayThe count of all messages sent to all clients at the egress of the cache resolver over the last 24 hours, or since the last time the stats were reset, updated at the top of each hour.

Client Cache: This table provides statistics for the hits and misses of the cache.

Statistics NameDescription
HitsCountThe count of all messages sent to all clients at the egress of the cache that did not send any nameserver queries since the last time stats were reset.
RatioThe percentage of hits count relative to the sum of hits count and misses count.
Response TimeThe exponential moving average over time of the elapsed wall clock time in microseconds between the ingress of a message from a client and after sending the corresponding egress message from the cache for all messages that did not send any nameserver queries.
MissesCountThe count of all messages sent to all clients at the egress of the cache that sent at least one nameserver query since the last time stats were reset.
RatioThe percentage of misses count relative to the sum of hits count and misses count.
Response TimeThe exponential moving average over time of the elapsed wall clock time in microseconds between the ingress of a message from a client and after sending the corresponding egress message from the cache for all messages that sent at least one nameserver query.

Statistics NameDescription

Client Queries: This table provides detailed statistics for all client queries.

Statistics NameDescription
ResolvingThe count of unique, top-level resolutions currently being processed by the cache resolver that sent at least one nameserver query, but have not responded since the last time the stats were reset.
Maximum ResolvingThe maximum of the count of current messages received from all clients at the ingress of the cache resolver that sent at least one nameserver query, but have not responded since the last time the stats were reset.
OverflowedThe count of all messages received from all clients at the ingress of the cache resolver that needed to send at least one nameserver query, but failed to send the nameserver query because there was no space available to keep track of the client query since the last time stats were reset.
Timed OutWhen unique client queries are received, they are put into either the forever list or the jostle list, each of which is half the size of the Max Concurrent Queries setting (default: 1024). If there is room in the forever list, they are put there and will run to completion. If not and there is room in the jostle list, they are put there. Queries in the jostle list can be removed if they have been in the jostle list for a longer period of time than the Allowed Query Time setting (default: 200ms). Queries are removed from the jostle list as more space is required for new queries coming in.

Important: This statistic table displays only if the cache type is set to Validating Resolver.

Statistics NameDescription
