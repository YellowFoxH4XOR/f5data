Description

After upgrading to BIG-IP, tomcat is constantly restarting. As a result, you will not have access to the GUI (Configuration Terminal).

This issue only happens to one of the HA pair which has been upgraded. In other words, the peer HA pair has also been upgraded but not facing the tomcat restart issue.

The BIG-IP does not have high CPU nor high memory issue.

Increasing the management memory (provision.extramb) and tomcat memory (provision.tomcat.extramb) does not resolve the issue.

Restarting httpd, tomcat, restjavad and restnoded services also does not resolve the issue. 

Environment
  • BIG-IP
  • tomcat constantly restarting after BIG-IP upgrade
  • Upgraded HA pair (same BIG-IP software) does not have the tomcat restart issue
  • CPU utilization not high
  • Memory utilization not high
  • Increasing management and tomcat memory has no difference
  • Restarting httpd, tomcat, restjavad and restnoded services has no difference.

Cause

Unknown at the time of publication. It is suspected that the issue is related to the upgrade

Recommended Actions

You will need to reinstall this current BIG-IP software version to resolve the issue. Reload to the previous BIG-IP software (partition) to reinstall the current BIG-IP software.

  1. Login to the BIG-IP GUI.
  2. Navigate to System > Software Management > Boot Location.
  3. Click the Boot Location of the previous BIG-IP software.
  4. Click Activate. This will boot to the previous BIG-IP software.
  5. Once the BIG-IP has booted to the previous BIG-IP software, login to the BIG-IP GUI.
  6. Navigate to System > Software Management > Image List.
  7. Click any Disk object.
  8. Delete the upgraded BIG-IP software volume. Under Contained Software Volumes, select the volume of the upgraded BIG-IP software.
  9. Click Delete.
  10. Once delete, navigate to System > Software Management > Image List.
  11. Proceed to install the upgraded BIG-IP software in a new volume.
