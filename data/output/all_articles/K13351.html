Issue

Error Message

Failed to initialize VPN service.

Message Location

You may encounter this message in the following location:

  • The F5 BIG-IP Client app on the Android device

Description

This message occurs when the following condition is met:

  • The user attempts to establish a VPN session to a BIG-IP APM or FirePass system using the BIG-IP Edge Client for Android.

Some Android device manufacturers do not include the VPN TUN module in the Android 4.x version that is installed on the device. This module is similar to a device driver. Without the module installed, a VPN tunnel cannot be established from the device.

Additionally, an error message that appears similar to the following example is written to the client log files:

E/VpnJni ( 189): Cannot allocate TUN: Bad file number
E/F5EdgeClient( 1391): Failed to establish VPN
E/F5EdgeClient( 1391): java.lang.IllegalStateException: Cannot create interface

You can collect the log files by performing the following procedure:

Note: You must have an email account configured on the Android device to perform this procedure.

  1. On the Android device, open the BIG-IP Edge Client app.
  2. Select Menu.
  3. Select Settings.
  4. Select Diagnostics. Report a Problem.
  5. Tap the bug shaped icon at the top right of the screen.
  6. After the the diagnostic data has been collected, the Send Log dialog menu displays.
  7. Select your email app.

    An email window displays and attaches the EdgeClientLog.zip log file.
  • In the To box, enter the email address of where you are sending the logs.
  • If you are actively working on a related case with F5 Support, prepend the case number in the Subject field.
  • Select Send.

Impact

A user who has an affected Android 4.x device will not be able to establish a VPN connection.

Recommended Actions

F5 recommends that users who are affected by this issue contact the manufacturer of their Android device.
