Topic

The HTTP::status command returns the three-digit HTTP status code sent by the server, and you can create an iRule to test the status code and act on it. For example, the following iRule causes the BIG-IP system to send a redirect response to the client when the HTTP server responds with a 500 Internal Server Error code:

when HTTP_RESPONSE {   if { [HTTP::status] == 500 } {      HTTP::redirect "http://server2/server_error.html"   }}

When a pool member responds with an HTTP status code of 500, the BIG-IP system responds to the client with an HTTP::redirect to the URL that is specified in the iRule.

You can modify the condition included in this iRule to react to any HTTP status code, and also modify the action taken when that status is seen. Different environments may require variations on this iRule.

For specific information about configuring iRules, refer to the Writing iRules chapter of the BIG-IP LTM Configuration Guide.
