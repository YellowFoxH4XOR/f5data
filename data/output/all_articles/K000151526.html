Description

To block/allow requests based on hostnames.

Environment

  •  BIG-IP ASM

Cause

Informational

Recommended Actions

The hostnames added under the header option are the by default allowed hostnames. To add the same, follow the below steps

Go to  Security  ››  Application Security : Security Policies : Policies List  and select your policy

Go to Headers--> under Hostnames add the required hostnames. 

Enabling the illegal hostname under headers in the learning and blocking setting will block the requests coming with any host header apart from the mentioned ones in the policy 

Go to 
Security  ››  Application Security : Policy Building : Learning and Blocking Settings 

Under headers select alarm and block for 'illegal host name'

If you are looking to allow all the subdomains under a domain, add the option 'include subdomain' and anything apart from the mentioned domain will be blocked
