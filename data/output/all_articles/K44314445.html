Issue

Error Message

01070301:3: Pool (<pool_name>) is referenced by one or more virtual servers

In this error message, note the following:

  • <pool_name> is the name of the pool and the partition in which it resides.

For example:

01070301:3: Pool (/Common/pool_http) is referenced by one or more virtual servers

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure a pool and associated it with a virtual server.
  • You attempt to delete the pool from the configuration.

Impact

Users cannot delete pools that are associated with virtual servers.

Recommended Actions

You cannot remove a pool from the configuration if it is still referenced by a virtual server. To delete a pool, first remove it from any virtual server configurations. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Next to the virtual server that references the pool, click Edit.
  4. For Default Pool, remove the pool that you want to delete.
  5. Click Update.
  6. Repeat steps 2 through 5 for the other virtual servers that reference the pool.
