Known Issue

VIPRION blades may use different MAC addresses for a VLAN that spans multiple blades.

This issue occurs when the following condition is met:

  • All blades start at the same time due to either a clsh reboot or a cold start.

The VLAN MAC address assignment for a blade occurs when the blade starts up. If a MAC address has not previously been determined for the VLAN, the blade determines which MAC address to use and updates mcpd. However, when a VLAN spans multiple blades, a race condition may allow for each blade to independently determine a different MAC address for the VLAN.

Impact

You experience a partial VLAN traffic failure.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The most common initial symptom of this issue is a failure of some monitor traffic.
  • Some VLAN network traffic may fail.
  • Devices in the local network observe that the ARP address for the VIPRION tmm interfaces change.
  • You can identify the issue on a system by typing the following command:

    clsh ifconfig -a | grep HWaddr | grep -Ev '(eth|bp)'

    The command calls on each blade and displays the MAC address associated for each VLAN on the blade. The command output example appears similar to the following example, which shows that each blade is using a different MAC address for VLAN_NAME_2:

    VLAN_NAME_1 Link encap:Ethernet  HWaddr 00:01:D7:56:00:01

    VLAN_NAME_2 Link encap:Ethernet  HWaddr 00:01:D7:56:00:02

    VLAN_NAME_1 Link encap:Ethernet  HWaddr 00:01:D7:56:00:01

    VLAN_NAME_2 Link encap:Ethernet  HWaddr 00:01:D7:56:00:03

Workaround

To work around this issue, you can modify the vlan.macassignment database variable from the default value of unique to a value of global. To do so, perform the following procedure:

Impact of workaround: The VIPRION system issues a gratuitous ARP to update local network hosts.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Change the vlan.macassignment database variable from unique to global by typing the following command:

    modify sys db vlan.macassignment value global
