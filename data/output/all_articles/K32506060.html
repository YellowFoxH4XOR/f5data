Description

After applying the new license, HA devices are in Disconnected status. The /var/log/ltm log continues to log a message similar to the following.

err mcpd[<PID>]: 0107142f:3: Can't connect to CMI peer <IP address>, TMM outbound listener not yet created

Environment

  • BIG-IP 
  • Installed a new license
  • Changed module provisioing

Cause

ID 1014361

Recommended Actions

  1. Ensure configsync IP address are pingable between devices and through the correct interface.
    # ping <peer device configsync IP address>
    # ip route get<peer device configsync IP address>
  2. Ensure HA devices are properly licensed and running on same software version.

  3. Restart all services.
    Impact of workaround: Traffic handled on the device will be impacted while all services are restarted. Perform the operation starting on a Standby device. If it does not resolve the issue, perform a manual failover and run it on a new Standby.
    # bigstart restart

None
