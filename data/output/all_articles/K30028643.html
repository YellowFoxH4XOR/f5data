Topic

Third-party software and license information for NGINX Controller.

Description

You can find the list of open source packages and their licenses used by NGINX Controller in the compressed NGINX Controller installer file, downloaded from MyF5. For example, controller-installer-3.5.0.tar.gz.

Note: Access to MyF5 requires a login.

This article supplements the information that is provided in the NGINX Controller package.

  • controller-docs
