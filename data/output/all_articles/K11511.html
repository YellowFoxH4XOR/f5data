Known Issue

The BIG-IP APM Network Access client original DNS settings are not restored after changes are applied.

Note: This behavior affects Mac OS X clients only.

When Network Access is established, the BIG-IP APM updates the client's resolv.conf file with the Network Access DNS servers. However, when the client logs out of the Network Access feature, the client's resolv.conf file is not restored to its original default state and still contains the Network Access DNS server(s) even though a tunnel is no longer established.

F5 Product Development tracked this issue as CR130035 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
