Topic

Some mapping methods provide a Map verbatim option. This option uses an attribute value supplied by the mapping method, and maps the value determined by the mapping method directly to a FirePass group of the same name. If no FirePass group of the same name exists, no mapping occurs.

The following mapping methods support the Map verbatim option:

  • LDAP (user object)
  • Client Certificate
  • Session Variable

The Map verbatim option is available to master and resource groups. You can configure Master groups from the Users : Groups : Dynamic Group Mapping screen : Master group mapping table tab. You can configure resource groups with the Map verbatim option from either the Users : Groups : Dynamic Group Mapping screen, the Resource group mapping table tab or from the Users : Groups : Master Groups screen : Mapping Table tab.

Configuring the Map verbatim option

To configure the Map verbatim option, perform one of the following procedures for the mapping method you are using:

Note: These procedures assume you have already configured your group mapping sequence and methods.

Important: The attribute/session variable value must match a group name exactly including case sensitivity.

Configuring the Map verbatim option for dynamic group mapping

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Click on either the Master group mapping table tab or the Resource group mapping table tab depending on the type of group mapping you are doing.
  4. Select the mapping method from the Mapping Method drop-down menu.

    Note: Only methods configured in the Group mapping methods will be available.
  5. Click the Add button.
  6. For LDAP and Client Certificate mapping methods, select the attribute to map from the Attribute drop-down menu.
  7. For session variable mapping method, enter the session variable to use encapsulated by the percent ( % ) character into the Session Variable text box.

    %session.ad.group.name%
  8. Select the Map verbatim check box.

    The Attribute value and FirePass Group text boxes will be made unavailable.
  9. Click the Add button.

Configuring the Map verbatim option for dynamic resource group mapping to an individual master group

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Master Groups page.
  3. Click the group name of the master group to which you want to dynamically assign a resource group.
  4. Click on the Mapping Table tab.
  5. Select the mapping method from the Mapping Method drop-down menu.

    Note: Only methods configured in the mapping methods tab will be available.
  6. Click the Add button.
  7. For LDAP and Client Certificate mapping methods, select the attribute to map from the Attribute drop-down menu.
  8. For session variable mapping method, enter the session variable to use encapsulated by a percent ( % ) character into the Session Variable text box.

    %session.ad.group.name%
  9. Click the Map verbatim check box.

    The Attribute value and FirePass Group text boxes will be made unavailable.
  10. Click the Add button.

Note: For more information about configuring dynamic group mapping, refer to K9061: Overview of FirePass group mapping.
