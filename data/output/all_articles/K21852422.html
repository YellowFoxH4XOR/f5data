Description

After creating an AGC you are unable to delete or edit the configuration.
Note: During deployment, after clicking the Deploy button, the deployment may hang with a spinning circle icon on the deploy button.

Environment

  • BIG-IP APM 13.1.1.5
  • AGC (Access Guided Configuration)

Cause

During deployment, a DNS server needed to resolve a pool member by FQDN was down at the time.
 

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. tmsh modify sys application service /Common/<replace with the app-service name> description deleteme
    Note: When specifying iApp application service name, give the full path.  For example, /Common/abc123.app/abc123
  2. Go to iApps > Application Services > Applications LX.
  3. Select the affected/renamed app-service and remove it.
  4. Find all the configuration objects that have the "app-service" set to "/Common/app-service" and delete them
