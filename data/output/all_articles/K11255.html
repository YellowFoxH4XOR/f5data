K11255: Users may report a delay when connecting to a Windows File Portal Access favorite

Applies to

Topic

Users may experience a 15 second delay when attempting to open a Windows File Portal Access favorite on FirePass version 6.0.3 or later. The latency occurs if the file server is not listening for connections on port 445. FirePass attempts to establish a connection on port 445 and falls back to port 139 if the connection fails.

FirePass versions 6.0.2 and earlier only allowed connections to file servers on port 139. If you have recently upgraded to FirePass version 6.0.3 or later, users may see a delay that they had not experienced before.

To eliminate the delay, you can configure the Portal Access favorite to force traffic over port 139. To do so, perform the following procedure:

  1. Log in to the Administrative Console.
  2. Navigate to Portal Access: Windows Files: Resources.
  3. Click on the Windows Files favorite you want to force over port 139.
  4. In the Path field, add :139 after the IP address of your File Server.
    For example:
    \\10.10.1.1:139\fileshare
  5. Click the Update button.
