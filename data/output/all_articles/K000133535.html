Description

/var/log/asm is filled with logs similar to the following:

Mar 28 08:42:55 ww.test.com err perl[15837]: 01310001:3: event code C740 credential stuffing service was unreachable - there is some network configuration issue

$ tmctl asm_cloud_services_stats

service_name               latency_avg_1_min latency_avg_5_min latency_max_1_min latency_max_5_min state message      
---------------------------------------- ----------------- ----------------- ----------------- ----------------- ----- ------------------
/Common/f5-credential-stuffing-cloud-app         0         0         0         0 Red  Connection problem

When navigating to Security > Cloud Services : Cloud Security Services Applications, the status for f5-credential-stuffing-cloud-app is red.

Environment

  • BIG-IP ASM
  • Credential Stuffing

Cause

For Credential Stuffing service to work properly, a DNS resolver should be configured on BIG-IP to resolve bf.shpapi.com so that BIG-IP knows how to route; either via TMM route or mgmt route. By default, BIG-IP uses DNS server 8.8.8.8 to resolve domain bf.shpapi.com and BIG-IP will try to communicate with that resolved IP address for updates:

net dns-resolver /Common/f5-aws-dns
....
shpapi.com {
nameservers {
8.8.8.8:53 { } <<<<<<<<<<<<
}
...

When DNS resolution failed or when BIG-IP can't reach the resolved IP address successfully, this log is generated and the status is red.

Recommended Actions

If you don't use Credential Stuffing service at all, then you can safely ignore this error as it won't affect BIG-IP traffic processing. You can also disable this service with the following commands:

tmsh modify sys db asm.credential_stuffing_service value disable

tmsh save sys config

If you are using the Credential Stuffing service on your BIG-IP, you can follow the procedures described in K31539643: Managing the DNS resolver to add/remove DNS resolver and/or add/remove forward zones for a DNS resolver. If you need to troubleshoot and figure out the potential connectivity issue, please capture traffic on your BIG-IP on both mgmt interface and tmm interface to check the traffic flow. For information on how to capture traffic using tcpdump and analyze the capture, refer to K00463541: A breakdown of the tcpdump utility, recommended actions, and information to help you use and apply it to the BIG-IP.

Additional Information

Note: F5 Leaked Credential Check (Credential Stuffing) has reached End of Life (EoL) effective July 1st, 2025. For more information, refer to K000140224: End of Life announcement for F5 Leaked Credential Check.
