Description
Traffic redirection via iRule does not work with cookie persistence when the "node" command is used. Example:

ltm rule /Common/irule_redirect {
when HTTP_REQUEST {
  if { [HTTP::uri] contains "xyz" } {
    node <IP_address> <port>
  } else {
    pool <pool_name>
  }
}
}

Environment

  • BIG-IP
  • Loadbalancing to node iRule
  • Cookie Persistence

Cause
The "node" command bypasses load balancing and as a result, the persistence is not triggered. 

Recommended Actions

  1. Create pool with one dedicated node (the same as 'node' command is using)
  2. Change the iRule to use 'pool' command instead of the 'node'

None
