Description

You might have encountered an issue where the neurond process keeps restarting and logs an error message mentioning "neurond_i2c_config_steps failed." This error message appears to indicate a problem with programming the i2c bus.

Environment

  • BIG-IP i10800 [C116] running version 15.1.0.4.

Cause

The error message suggests that the problem could be with the i2c bus rather than the neurond process itself.

Recommended Actions

To resolve the issue, you can perform any of the following actions:

  1. Power cycle the system via AOM. This is the recommended option.
  2. Do a complete cable unplug cold reboot.

After performing the workaround, the neurond restarting message should disappear, and the ltm log should state that the I2C bus has been reset. Here is an example of the expected output:

neurond[7527]: neurond_i2c_config: Neuron 0 configured after 1 attempt(s)
neurond[7527]: neurond_i2c_config: Neuron 1 configured after 1 attempt(s)
info bcm56xxd[13087]: 012c0012:6: I2C mux reset completed, dev:0x2390, gpio_pin:50.
