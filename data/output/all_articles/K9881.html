Topic

Beginning in BIG-IP WebAccelerator 9.4.7, you can define how the BIG-IP WebAccelerator system manages the Via general-header field by specifying variables for the sendProxyViaHeader parameter in the /conf/wa/pvsystem.conf file.

To specify variables for the sendProxyViaHeader parameter, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd/config/wa
  3. Backup the original pvsystem.conf file by typing the following command:

    cp pvsystem.conf pvsystem.conf.sol9881
  4. Using a text editor, open the pvsystem.conf file and locate the sendProxyViaHeader line, which appears similar to the following example:

    <sendProxyViaHeader inRequest="remove" inResponse="append" hostName=""/>
  5. Modify the inRequest and inResponse variables as required, by typing one of the following three options between the quotation marks for the respective setting:
    • remove

      To remove the Via general-header field from all requests sent from the client, type remove for the inRequest variable.

      Note: This option is the default behavior for requests.

      To remove the Via general-header field from all responses sent from the origin web server, type remove for the inResponse variable.
    • preserve

      To retain any existing Via general-header field sent from the client in the request, type preserve for the inRequest variable. 

      To retain any existing Via general-header field sent from the origin web server in the response, type preserve for the inResponse variable.
    • append 

      To append the Via general-header field sent from the client in the request with a host name, type append for the inRequest variable. 

      To append the Via general-header field sent from the origin server in the response with a host name, type append for the inResponse variable.

      Note: This option is the default behavior for responses.

      If you use the append option, you can also specify a host name by typing a host name between the quotation marks for the hostName parameter. If you do not specify a host name for the hostName parameter, the BIG-IP WebAccelerator system inserts a generic host name.
  6. Save the pvsystem.conf file.
  7. Restart the WebAccelerator process by typing the following command:
     
    Important: Restarting the pvac daemon will briefly disrupt connections and invalidate objects in the BIG-IP LTM RAM Cache. Restarting the pvac daemon should be scheduled accordingly.

    bigstart restart comm_srv pvac
