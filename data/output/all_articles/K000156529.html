Description

NGINX App Protect WAF can be configured to enforce strict session cookie controls for web applications. This includes:

  • Rejecting requests that do not contain a specific application server session cookie.
  • Rejecting requests where the session cookie value does not exactly match the original value set by the application server.

Relevant violations generated by these controls are:

  • VIOL_COOKIE_MODIFIED: Triggered when an enforced cookie’s value has been altered.

Environment

  • Product: NGINX App Protect WAF
  • Configuration: Security policy with cookies defined as "enforced"

Cause

NGINX App Protect WAF enforces cookie integrity and presence using a TS (Traffic Shield) cookie mechanism:

  • The TS cookie contains encrypted CRCs (checksums) of the name and value of cookies issued by the protected service.
  • These CRCs are encrypted using app_protect_cookie_seed and signed with a digest.
  • Upon receiving a client request, NGINX App Protect checks that the CRCs in its TS cookie match those in the request; if not, or if required cookies are missing, it triggers corresponding violations.

Recommended Actions

To enable enforcement:

  • Define required session cookies as "enforced" in your security policy configuration:

{
  "cookies": [
    { "name": "session_id", "enforceIntegrity": true }
  ]
}

This will:

  • Block requests where the session cookie value has been modified (VIOL_COOKIE_MODIFIED).
  • Review official documentation for further details on supported violations and policy options.
