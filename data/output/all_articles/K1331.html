The BIG-IP system can load balance traffic from a StoneBeat firewall cluster that is using a multicast MAC address for failover. The BIG-IP system accepts traffic from any system using multicast MAC address-based software; however, you must disable auto_lasthop.

To disable auto_lasthop, type the following command:

bigpipe global auto_lasthop disable
