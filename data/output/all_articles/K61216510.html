Topic

You should consider using this procedure under the following condition:

  • You want to use the Configuration utility to update the protocol inspection signatures on your BIG-IP AFM system with subscription signatures.

Description

To detect anomalies in traffic, the BIG-IP AFM system performs protocol inspection using sets of signatures. F5 periodically updates these signatures and releases them on the MyF5 Downloads site.

F5 has an established security research team that authors and updates a more robust set of signatures. Starting with BIG-IP 14.1.0.5, you have the option to subscribe to this signature set.

In the BIG-IP AFM system, there is a new Subscription column in the Inspections List that indicates whether your BIG-IP AFM license includes a given inspection or whether you require a subscription.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have one of the following:
    • A licensed and provisioned BIG-IP AFM module that is the primary module on your BIG-IP system (BIG-IP AFM with BIG-IP LTM and other modules as add-ons)
    • A separate license key enabling the Protocol Inspection Signature Matching and Compliance Engines features
  • You have a Signature subscription.
  • You have internet access to the MyF5 Downloads site.
  • You have administrative access to the Configuration utility.

Procedures

  • Manually updating the protocol inspection signatures
  • Automatically updating the protocol inspection signatures

Manually updating the protocol inspection signatures

To manually download, install, and deploy the latest BIG-IP AFM protocol inspection signature package using the Configuration utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Security > Protocol Security > Inspection Updates.
  3. To download the latest protocol inspection signature package, click Download Latest.

    Note: You can also manually download the protocol inspection signature package from the MyF5 Downloads site to your desktop and copy the package to the /shared/protocol_inspection_updates directory on the BIG-IP AFM system. For more information about transferring files to the BIG-IP system, refer to K175: Transferring files to or from an F5 system.

    After you download the protocol inspection signature package, it appears under Available to Install.

  4. To verify and install the package, choose the package and click Install.

    The installation status displays under Status.

  5. To deploy a protocol inspection signature package, choose the package and click Deploy.

Automatically updating the protocol inspection signatures

You can configure the BIG-IP AFM system to automatically update protocol inspection signatures daily, weekly, or monthly. To configure the BIG-IP AFM system to automatically download, install, and deploy the protocol inspection signature updates, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Security > Protocol Security > Inspection Updates.
  3. Under Automatic Update Settings, for Automatic Updates, click Enabled.
  4. For Update Schedule, click Daily, Weekly, or Monthly.
  5. Click Update.
