K000133586: OSPF stuck on Exchange state

Type
Support Solution
Published
2023-05-10
Updated
2023-07-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000133586

Description

OSPF stuck on EXCH state after OSPF neighboring Firewall failover.

 

Environment

  • LTM
  • OSPF

 

Cause

OSPF is not allowed in the Port lockdown setting used for the OSPF communication.

 

Recommended Actions

To allow OSPF, from the GUI

1. Go to Network > Self IPs > select the OSPF Self-IP

2. Port lockdown > Allow Custom > Protocol : OSPF > Add > Update

 

Additional Information

None
