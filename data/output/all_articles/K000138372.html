K000138372: HTTP virtual server (without HTTP/2 profile) accepting HTTP2 connection

Type
Support Solution
Published
2024-09-05
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000138372

Description

HTTP virtual server is accepting HTTP2 protocol.

 

Environment

  • BIG-IP
  • Virtual server
  • HTTP profile only
 

Cause

Client request protocol upgrade sending

GET / HTTP/1.1
Host: <host>
User-Agent: <user_agent>
Accept: <...>
Connection: Upgrade, HTTP2-Settings
Upgrade: h2c
HTTP2-Settings: AAMAAABkAAQAoAAAAAIAAAAA

Virtual server will forward the upgrade request if you do not reject it through policy/irule to reject the upgrade protocol reuest.

If backend server is happy to upgrade, backend server will respond with

HTTP/1.1 101 Switching Protocols
Connection: Upgrade
Upgrade: h2c

And this is by design, Virtual server will forward those HTTP packets.
 

Recommended Actions

  • Set backend server not to accept upgrade to h2c.

or

  • Set policy or irule to reject upgrade.
