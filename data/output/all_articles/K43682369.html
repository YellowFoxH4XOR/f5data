K43682369: Seeing bad udp cksum when using RADIUS authentication on AWS ENI interfaces

Type
Support Solution
Published
2019-11-05
Updated
2025-02-06
Applies to

  • BIG-IP
  • BIG-IP APM: 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.1.0
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K43682369

Description

RADIUS UDP packets leaving Big IP not arriving in AWS ENI because AWS does not have hardware checksum functionality.

Environment

  • Virtual BIG-IP APM on Amazon Web Services Cloud (AWS)
  • Using AWS Elastic Network Interface (ENI)
  • RADIUS
  • UDP
  • tcpdump run on Big IP shows 'bad udp cksum' 

Cause

AWS does not perform UDP checksum validation on ENI interfaces.
Big IP Default behavior is to offload checksum validation to hardware.

Recommended Actions

To work around this issue, run the following command to configure the Big IP to perform checksum validation by software

From  Command line: 
  1. tmsh <enter>
  2. modify sys db tm.tcpudptxchecksum value Software-only
  3. save sys config
  4. quit
