Known Issue

This is the result of a known issue. There is a mismatch between the LED alert levels as defined in the alert.conf file and the alert levels as defined in the fpdd process. This can result in the BIG-IP system displaying the incorrect lcdwarn message on the LCD panel. For example, when an alert condition occurs, the LCD panel displays a critical alert level. Similarly, when a critical alert condition occurs, the LCD panel displays an alert level.

The following table shows the lcdwarn messages and alert levels defined in the alert.conf file:

lcdwarn messagesAlert level
0warning
1error
2alert
3critical
4emergency

F5 Product Development tracked this issue as ID 303490 (formerly CR84744).
