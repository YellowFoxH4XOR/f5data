K000156640: How to Block IPs/Prefixes Using FastACL's

Published

Description

  • Blocking IPs/IP Prefixes using FastACLs allows for simplified blocking of traffic at the VIP Level which allows for blocking across all Load Balancers or Subsets of Load Balancers (e.g. Multiple Load Balancers Sharing a VIP)

Environment

  • F5 Distributed Cloud (XC)

Cause

 

Answer/Recommended Actions

Create Fast ACL Policy

  • Go to Multi-Cloud Network Connect section of the XC Console
  • Expand the Manage Section
  • Under Firewall, select Fast ACLs
  • From the Fast ACLs screen, press the Add Fast ACL button in the upper left
  • Enter desired name for this Fast ACL policy
  • Under Select Site Type For ACL, choose Site Type Regional Edge (if creating a rule for a CE, choose Site Type Customer Edge)
  • Select Edit Configuration
  • Now Select the VIP(s) this policy should be applied to
    • ALL Public VIP(s) - This option applies the policy to All the VIPs (including Default Tenant VIP in your Tenant)
    • Default Tenant VIP - This option applies the policy to the Default Tenant VIP of your Tenant
    • List of Specific VIP(s) - This option lets you specify a subset of VIPs within your Tenant that the policy will apply to
  • Under Source -> Rules, select Configure
  • Select Add Item
  • Enter the desired name for this Fast ACL Policy Rule
  • Under Simple Action Select Deny
  • Under Source Drop Down, there are options for Prefix and IP Prefix Set
    • If Prefix is selected, individual IP Prefixes can be defined
      • Select Add Item
      • Enter the IP/IP Prefix to block (If a single IP make sure to enter in CIDR notation with a /32)
    • If IP Prefix Set is selected, choose your IP Prefix Set you with to reference for this Rule
  • Press Apply Button in lower right of the window until the Add Fast ACL button appears
  • Press Add Fast ACL button to create your Fast ACL Policy

Activate Your Fast ACL Policy

  • Go to Routed DDoS section of the XC Console
  • Expand the Manage Section
  • Select Fast ACLs for Internet VIPs
  • Press the Select Fast ACLs for Internet VIPs button in the upper left
  • Press the Add Item button
  • In the available drop down, select the name of the Fast ACL Policy you wish to activate
    • Repeat if multiple policies need to be activated
  • Press the Add Select Fast ACLs for Internet VIPs button in the lower right of the window
