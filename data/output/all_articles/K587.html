Topic

This article applies to F5 systems with 9-pin serial console port connections. For information about F5 systems with RJ-45 console port connections, refer to the following article:

  • K13644: Pinouts for the RJ-45-based console cable and adapter for F5 products

Connecting a device to an F5 system with a 9-pin serial port

You must use a properly-constructed null modem cable to connect the 9-pin serial port (DE-9) on F5 products to a serial console device. Pre-fabricated null modem cables with various connectors are available from many sources, but you must verify the pinouts on each end of the cable to ensure that they comply with the established standards.

Note: DE-9 refers to the standard 9 pin D-sub connector, and it is sometimes erroneously referred to as DB9.

The following F5 platforms have a 9-pin DE-9 console port:

  • BIG-IP 1500, 1600, 3400, 3600, 3900, 6400, 6800, 6900, 8900, 8950, 11000 and 11050 platforms.

Connecting from a device with a 9-pin serial port

You should use the following pinout to construct an EIA/TIA 232/574-compliant null modem cable suitable for connecting to the F5 system's serial port from a 9-pin serial port:

You should use the following pinout to construct an RS232 standard compliant null modem cable suitable for connecting to the F5 system's serial port from a 25-pin serial port:

Important: The DE9-DE9 null modem cable that is used to access the BIG-IP system command line interface over the serial console port cannot be used in place of the supplied failover cable. The failover cable uses a different custom pinout. For more information, refer to K1426: Pinouts for the failover cable used with BIG-IP platforms.

Note: ARX platforms have an RJ45F serial console port.
