Topic

You should consider using these procedures under the following conditions:

  • You want to enable or disable In-Traffic Management Microkernel (TMM) monitoring.
  • You want to configure an HTTPS monitor with a Server SSL profile.

Description

The BIG-IP system is capable of running several types of health monitors using either TMM or bigd processes. The In-TMM feature was introduced in BIG-IP 13.1.0 and offers the capability to run ICMP, TCP, HTTP, and HTTPS monitors in the TMM process, which allows monitors to consume fewer system resources and scale more efficiently. Additionally, the feature uses SSL acceleration hardware and Server SSL profiles for HTTPS monitors.

In-TMM monitoring is enabled and disabled globally using the bigd.tmm database key and is disabled by default. However, certain monitor types (including MQTT) always run in TMM. For more information, refer to K85210713: Impact of enabling In-TMM monitoring.

Note: If you configure an HTTPS monitor with a Server SSL profile when In-TMM monitoring is disabled, bigd uses the configured cipher string from the serverssl profile. In some versions, due to Bug ID 750318, a restart of bigd might be required for the changes to take effect. This is fixed in versions 13.1.1.5, 14.1.2.3, and 15.0.0.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the TMOS Shell (tmsh).

Procedures

Note: The In-TMM feature is disabled, by default. You must enable it if you want to run monitors using TMM.

  • Enable In-TMM monitoring
  • Disable In-TMM monitoring

Enable In-TMM monitoring

Impact of procedure: Performing the following procedure configures the BIG-IP system to perform monitor functions in TMM instead of the bigd process.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To enable the bigd.tmm database key, enter the following command:

    modify sys db bigd.tmm value enable

Disable In-TMM monitoring

Impact of procedure: Performing the following procedure configures the BIG-IP system to perform monitor functions using the bigd process instead of TMM.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To disable bigd.tmm database key, enter the following command:

    modify sys db bigd.tmm value disable
