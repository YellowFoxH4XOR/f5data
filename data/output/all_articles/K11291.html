Known Issue

This is the result of a known issue. Reverting to the default Front Door image does not synchronize to other members of the FirePass failover pair or cluster. However, if you upload a custom Front Door image on the active unit in a failover pair (high availability) configuration, the new image is synchronized to the standby unit. Similarly, if you upload a custom Front Door image on the primary (master) cluster unit in a cluster configuration, the new image is synchronized to the secondary cluster units.

Note: The Front Door image is configured on the Device Management: Customization page under the Global Customization tab.

F5 Product Development tracked this issue as CR138292 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Workaround

In FirePass 6.0.3 and later, you can work around this issue in a failover pair configuration by selecting the Force Full Sync link on the Failover: Settings page on the active unit.

In FirePass 6.0.3 and later, you can work around this issue in a cluster configuration by selecting the Force Full Sync link on the Clustering: Stats page on the primary cluster unit.
