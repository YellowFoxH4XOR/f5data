Description

Getting HTTP2 RST_STREAM with Error: INTERNAL_ERROR (2) when using an HTTP2 profile and an iRule that redirects the traffic to another virtual server or BIG-IP pool that is using HTTP/1.1. This error typically occurs in specific configurations involving HTTP2 profiles and internal redirections.

Environment

  • Standard Virtual Server
  • Client and Server SSL profiles
  • HTTP and HTTP2 profiles
  • iRule that redirects traffic to another virtual server or Pool 

Cause

MRF is disabled.

Recommended Actions

To resolve the issue, enable MRF in the HTTP2 profile. This will ensure that HTTP2 traffic is properly routed and processed, preventing the RST_STREAM with Error: INTERNAL_ERROR (2)
