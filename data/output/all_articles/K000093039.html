K000093039: Unable to delete SSL Orchestrator object from GUI

Type
Support Solution
Published
2022-12-08
Updated
2022-12-27
Source
https://my.f5.com/manage/s/article/K000093039

Description

Unable to delete SSL Orchestrator object from GUI. Error "Unable to delete block <block_name> with state BINDING".

 

Environment

BIG-IP SSL Orchestrator

 

Cause

This is an expected behavior.

Before a BINDING block can be deleted it must first be patched to ERROR state. All ERROR blocks should then be deleted.

 

Recommended Actions

Please follow the steps below to identify the block ID and change the state to ERROR state before deleting it.

 

1. Use this command to list all of the SSLO blocks with bad state: 
# restcurl "/mgmt/shared/iapp/blocks?\$filter=configurationProcessorReference/link%20eq%20'*f5-iappslx-ssl-orchestrator*'%20and%20state%20eq%20'BINDING'%20or%20state%20eq%20'ERROR'%20or%20state%20eq%20'BINDING'" -u admin:admin | jq ' .items[] | {id: .id, name: .name, state: .state }'

 

2. Patch BINDING block to ERROR state:
# restcurl -X PATCH -d '{"state":"ERROR"}' /mgmt/shared/iapp/blocks/ -u admin:admin
