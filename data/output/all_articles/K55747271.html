Description

By default, only user roles "Resource Administrator",  "Auditor" and  "Administrator" have the access to Log menu from Configuration Utility. The others are not allowed. There are some db keys to control this and by default those are disabled as listed below:

# tmsh list sys db ui.logaccess.* one-line
sys db ui.logaccess.accelerationpolicyeditor { value "disable" }
sys db ui.logaccess.applicationeditor { value "disable" }
sys db ui.logaccess.applicationsecurityadmin { value "disable" }
sys db ui.logaccess.applicationsecurityeditor { value "disable" }
sys db ui.logaccess.certificatemanager { value "disable" }
sys db ui.logaccess.firewallmanager { value "disable" }
sys db ui.logaccess.fraudprotectionmanager { value "disable" }
sys db ui.logaccess.guest { value "disable" }
sys db ui.logaccess.irulemanager { value "disable" }
sys db ui.logaccess.manager { value "disable" }
sys db ui.logaccess.operator { value "disable" }
sys db ui.logaccess.usermanager { value "disable" }

Environment

  • BIG-IP
  • Configuration Utility

Cause

None

Recommended Actions

If you want to give one role the access to Log from Configuration Utility, you can enabled it. For example for operator role we can use command below:

tmsh modify sys db ui.logaccess.operator value enable
