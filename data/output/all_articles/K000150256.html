Description

Only when licensing the BIG-IP or the BIG-IQ via manual licensing Method.

 

Environment

Licensing  BIG-IP / BIG-IQ.

 

Cause 

Error appear when mistakenly copied base registration key not the dossier characteristic and pasted in.

Activate F5 Product

 

Answer/Recommended Actions

When activating the license from manual method make sure to copy the right dossier characteristic not the base registration keys
