Description

SSH connections to an F5OS-A host system fail while GUI access remains functional. When attempting to establish SSH connections from external systems, the connection is immediately reset with error.

The system logs show the following fatal error messages in /var/log/messages

fatal: Missing privilege separation directory: /var/empty/sshd

 

This issue affects CLI access via SSH while the web GUI interface continues to work normally.

Environment

  • Root SSH

Cause

The required SSH privilege separation directory /var/empty/sshd is missing from the filesystem. This directory is essential for SSH daemon operation and its absence prevents the SSH service from accepting connections.

 

Answer/Recommended Actions

Console access with root privileges is required to resolve this issue:

  • Log in to the device via console access with root credentials
  • Verify if the SSH directory exists:

ls -`ld /var/empty/sshd

 

  • If the directory does not exist, create it with proper permissions:

mkdir -p /var/empty/sshd

chmod 0755

chmo /var/empty/sshd

chown root:root /var/empty/sshd

 

  • Verify the directory was created with correct permissions
  • Test SSH access from the system.
