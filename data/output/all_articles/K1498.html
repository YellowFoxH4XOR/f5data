Topic

The verbosity levels for proxyd are 1 through 9, with 9 being the most verbose. Level 9 will log several lines a second while waiting for connections to the SSL proxy. The log entries are sent to the /var/log/proxyd file as text. The higher levels are not appropriate for logging long sessions and should be used only for brief periods of time, because the /var/log/proxyd file will grow quickly.

Enabling proxyd verbose logging

To enable verbose logging for proxyd, type the following command:

proxyd -d <debug level>

The <debug level> is 0 - 9. Each level is defined as follows:

LevelDescription
0ERROR - Serious errors
1WARNING - Important information
2CONNECTION - Connections states
3TRANSFER - Data transfer information
4SPURIOUS - Displays any proxy events
5STATS - Prints statistics to a file
6CONNECTIONS - Prints connection table to a file
7(This value is not used.)
8(This value is not used.)
9PROXY STATUS - Prints detailed Proxy state

For specific information about errors reported in the proxyd log, refer to K1125: Common proxyd error messages.

Disabling proxyd verbose logging

To disable verbose proxyd logging and reset the debug level to its default of 0, type the following command:

proxyd
