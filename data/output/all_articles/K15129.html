Known Issue

The Web Image Optimization and Web Cache Invalidations dashboard windows do not appear on the BIG-IP AAM Dashboard.

This issue occurs when the following condition is met:

  • You attempt to create a custom dashboard view.

The BIG-IP AAM Dashboard for Web Acceleration has the following six dashboard windows: WMO Memory Usage, Web Optimized Transactions, Optimized Web Throughput, Web Cache Effectiveness, Web Image Optimization, and Web Cache Invalidations. When attempting to create a custom dashboard view, the Web Image Optimization and Web Cache Invalidation dashboard windows do not appear.

Impact

You may be unable to create the desired custom dashboard view.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Web Image Optimization and Web Cache Invalidation dashboard windows do not appear.
