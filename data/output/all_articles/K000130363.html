Description

Azure VMs are not aware of Public IPs. 

This prevents a simple forwarding VS with SNAT to a Public IP.

 

Environment

  • BIG-IP VE
  • Azure
  • SNAT
 

Cause

This is expected behavior.
 

Recommended Actions

The way to configure this is Forwarding VS > SNAT to Private IP > Set Azure NIC Public IP as desired source address. 
 

Additional Information

Azure NICs translate a virtual machine's private IP address to a public IP address. As a result, a virtual machine's operating system is unaware of any public IP address assigned to it, so there is no need to ever manually assign a public IP address within the operating system.
