Topic

This article lists the third-party software applicable to F5OS, F5OS-A, and F5OS-C versions.

Description

The following matrices list third-party software on F5OS:

  • F5OS third-party software installed on the Linux Operating system
  • F5OS third-party software that runs in a container

Important: F5OS releases may include upgrades and security fixes for the third-party software packages listed in the following table. As a result, when you evaluate vulnerability status for third-party software, F5 recommends that you refer to security advisory articles to determine if a F5OS release is vulnerable.

You can view third-party software version information from the F5OS command line. To do so, use the commands listed in the last column of the table.

Examples

For example, to find the Python version, perform the following procedure:

  1. Log in to the management interface as root.
  2. Enter the following command:

    Note: For F5OS-C, log in to the CLI of the chassis floating management IP address

    python -V

    You may observe an output similar to the following::

    Python 2.7.5

You can view third-party software version information after login to the container. To do so, login to the command line of the container, and use the commands listed in the last column of the table .

Examples

For example, to find the httpd version, perform the following procedure:

  1. Log in to the management interface as root.
  2. Enter the following command to view the name of the httpd container:

    Note: For F5OS-C, log in to the CLI of the chassis floating management IP address

    docker ps | grep -i http

    You may observe an output similar to the following:

    7ac8a80ebf4c        localhost:2004/http-server:1.15.13-f5os-a-1-5-0-[...]                      "/root/daemon_setu..."   2 weeks ago         Up 2 weeks     http-server

    From the output above, the name of the container is http-server.

  3. Log in to the container using the following command syntax:

    docker exec -it <container name> /bin/bash

    For example, to enter the command line of the http-server container, enter:

    docker exec -it http-server /bin/bash

  4. In the container command line, enter the command to view the version:

    httpd -v | grep version
