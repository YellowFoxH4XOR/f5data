K000138168: Unable config-sync via GUI

Type
Support Solution
Published
2024-01-09
Updated
2024-01-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000138168

Description

  • Unable to synchronize configuration between HA pair or generate a qkview from GUI.
  • On GUI "Device management > Overview" and "System > Support" got stuck on loading (Page doesn't load).
  • Message similar t the following can be seen on /var/log/restjavad.0.log:

[8100/tm/shared/bigip-failover-state BigipFailoverStateWorker] Failed to get gossip peer group members from standby: com.f5.rest.common.RestRequestSender$HttpException: java.net.ProtocolException: status:401, body:{"code":401,"message":"Authorization failed: no user authentication header or token detected.
|
[8100/shared/gossip-conflicts GossipConflictCollectionWorker] URI:http://localhost:8100/shared/gossip-conflicts/8ed67f7d-53dd-4b06-848d-11c85f95d0d5, Referrer:http://localhost:8100/shared/gossip-conflicts, Method:DELETE, Exception:java.util.concurrent.TimeoutException: remoteSender:http://localhost:8100/shared/gossip-conflicts, method:DELETE

Environment

  • BIG-IP LTM
  • HA Pair
  • BIG-IP devices are not managed by BIG-IQ

Cause

restdb discrepancies between HA pair leading to gossip failures.

Recommended Actions

To fix the issue, please perform the following steps to clear the rest framework:

1. Log in to the CLI of the BIG-IP device reporting the gossip-conflicts .
2. Restore BIG-IP REST framework with the the following command:

clear-rest-storage

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: If RCA is required, please perform the following steps before clearing the REST framework

On both devices run the following commands and save the output:

tmsh list mgmt shared resolver device-groups tm-shared-all-big-ips devices
restcurl /shared/resolver/device-groups/tm-shared-all-big-ips/devices
restcurl /shared/gossip
restcurl 'shared/gossip?$select=gossipPeerDevices'
restcurl /shared/gossip-conflicts
qkview -s0

Additional Information

You can sync the configuration via CLI using the following command: 
tmsh run cm config-sync force-full-load-push to-group <group name>
