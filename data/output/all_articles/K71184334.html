K71184334: Failover Order shows ''Undefined'' from the Traffic-Groups tab in the GUI

Description

After setting sys db key "httpd.basic_auth" value to "disable" as a mitigation step for CVE-2021-23026, and restarting httpd, restjavad and tomcat or rebooting the system, the member's hostname appears as "Undefined" in Failover Order option in Device Management >> Traffic-Group.

Similar configuration is shown after following the mitigation steps from iControl SOAP vulnerability CVE-2021-23026 :

list /sys db httpd.basic_auth all-properties
sys db httpd.basic_auth {
    default-value "enable"
    scf-config "true"
    value "disable"
    value-range "disable enable"
 }

Environment

  • BIG-IP LTM
  • Traffic-Groups
  • Failover Order
  • The sys db key "httpd.basic_auth" is disabled
  • High Availability (HA)
Cause

Unknown at the time of publication.

Recommended Actions

To workaround this issue, it is necessary to set sys db "httpd.basic_auth" value as "enable" and then restart httpd, restjavad and tomcat.

Impact of workaround: The BIG-IP Configuration utility is not accessible while services are restarting.

  1. Login to the CLI.
     
  2. Run the following command:
    #tmsh modify /sys db httpd.basic_auth value enable
     
  3. Restart httpd, restjavad and tomcat services with the following command:
    #tmsh restart /sys service httpd restjavad tomcat
