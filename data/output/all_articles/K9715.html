Known Issue

Note: The issue described in this solution does not affect BIG-IP Link Controller version 11.x due to architectural changes.

This is the result of a known issue. On rare occasions, after a fresh installation of the BIG-IP Link Controller software, the BIG-IP Link Controller system's mcpd process does not receive the gtmd configuration, although a valid wideip.conf file exists. In addition, attempts to configure a link object will fail with an error message that appears similar to the following example:

01070179:3: Link <link_name> must have an associated data center.

F5 Product Development is tracking this issue as ID 246812 and ID 246813 (formerly CR102656).

Workaround

You may be able to work around this issue by forcing the mcpd process to reload the gtmd configuration. To do so, perform the following procedure:

  1. Log in to the BIG-IP Link Controller command line.
  2. Type the following command to reload the configuration:

    gtmparse -l

You should now be able to configure the link object.

If you still cannot configure the link object, the BIG-IP Link Controller's auto-configuration process may not have correctly created the wideip.conf file, which contains the required default data center definition that references the box definition for the BIG-IP Link Controller. To ensure that the wideip.conf file contains the required entries, perform the following procedure:

  1. Log in to the BIG-IP Link Controller command line.
  2. Edit the /config/gtm/wideip.conf file in a text editor.
  3. Ensure that the configuration file contains stanzas that define the data center and the BIG-IP Link Controller object.

    For example, the following stanza defines the data center and standalone Link Controller object:

    Note: Replace LC-fqdn.domain.com with the FQDN of the BIG-IP Link Controller system, and replace 192.168.1.2 with the self IP address that was configured on the BIG-IP Link Controller system during the initial configuration.

    // *** Data Center Definitions (1) ***

    datacenter { // 1 server(s)
       name "Default DC"
       server "    LC-fqdn.domain.com"
    }

    // *** Server Definitions (1) ***

    server { // datacenter=Default DC, #VS=0
       name "LC-fqdn.domain.com"
       type bigip
       box { //gtm
          address 192.168.1.2
          unit_id 1
       }
    }

    The following stanza defines the data center and redundant HA Link Controller objects:

    Note: Replace LC-fqdn.domain.com with the FQDN of the BIG-IP Link Controller system, and replace 192.168.1.2 with the current self IP address of the local BIG-IP Link Controller system, and 192.168.1.3 with the self IP address of the peer Link Controller system.

     // *** Data Center Definitions (1) ***
     
      datacenter { // 1 server(s)
         name "Default DC"
         server "LC-fqdn.domain.com"
      }
     
    // *** Server Definitions (1) ***
      server { // datacenter=Default DC, #VS=0
         name "LC-fqdn.domain.com"
         type bigip
         box { //gtm
            address 192.168.1.2
            unit_id 1
         }
         box { //gtm
            address 192.168.1.3
            unit_id 2
         }
      }

  4. Save and close the file.
  5. Load the modified configuration by typing the following command:

    gtmload

You should now be able to configure the link object.
