Description

Single logout (SLO) is currently not support with SAML Step-up.

Environment

  • BIG-IP APM as SAML SP
  • SAML Step-up
  • Single Logout (SLO)
  • Per-Request Polices

Cause

Not all use-cases for SAML Step-up have been officially tested.

Recommended Actions

If it is a requirement to trigger SLO upon logout, then the it would be recommended that SAML be configured in a Per-Session Policy rather than a Per-Request Policy
