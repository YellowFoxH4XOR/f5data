K06512123: CPU spike on BIG-IP software 13.1.1.x

Type
Support Solution
Published
2021-05-18
Updated
2025-02-06
Status
Legacy Content
Applies to

  • BIG-IP Analytics: 13.1.1, 13.1.1
Source
https://my.f5.com/manage/s/article/K06512123

Description

BIG-IP software 13.1.1.x shows CPU spikes. The BIG-IP software impacted are:

  • 13.1.1.2
  • 13.1.1.3
  • 13.1.1.4
You have provisioned AVR on this BIG-IP.

top output from the Command Line will show various processes having CPU spikes which includes mcpd, tmm, mysqld or snmpd.

Environment

  • BIG-IP
  • BIG-IP version as mentioned in Description
  • AVR has been provisioned
  • top shows various processes having CPU spikes mentioned in Description

Cause

This issue is related to bug ID745326.

Recommended Actions

To resolve bug ID745326, you will need to upgrade to at least BIG-IP 13.1.4.

Additional Information

None.
