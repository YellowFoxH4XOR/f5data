Known Issue

The BIG-IP system may close HTTP 1.1 persistent connections without sending a Connection: close HTTP header.

This issue occurs when all of the following conditions are met:

  • You are using the HTTP profile.
  • Your HTTP client sends an Expect: 100-continue POST request.
  • Your origin web server (OWS) responds with a 401 Unauthorized response code for Basic Authentication.

Impact

Some HTTP clients may fail to authenticate.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Some clients expecting an HTTP Connection: close header on a closed HTTP 1.1 connection may continue to attempt to authenticate over the closed session.
  • Using a packet capture utility, you see the TCP connection closed with a TCP FIN.

For example, if you use the Microsoft Exchange Remote Connectivity Analyzer against an Exchange mailbox, this could be a connection affected by this issue. The connection fails with an error message similar to the following:

The test of the FolderSync command failed.
Additional Details: Exception details:
Message: The request was aborted: The request was canceled.
Type: System.Net.WebException
Stack trace:
at System.Net.HttpWebRequest.GetResponse()
at Microsoft.Exchange.Tools.ExRca.Extensions.RcaHttpRequest.GetResponse()

Workaround

To work around this issue, you can implement an iRule to insert the Connection: close in these circumstances. To do so, perform one of the following procedures:

Impact of workaround: iRules may add minor overhead to each HTTP transaction.

Note: When applying an iRule to a virtual server, the changes take effect immediately.

Adding a Connection Close header for general HTTP connections

You should use this iRule for virtual servers that process HTTP requests that are affected by this issue.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRules List.
  3. Click Create.
  4. Enter a name for the new iRule, then copy and paste the following iRule into the box:

    when HTTP_RESPONSE {
    if { [HTTP::status] == 401 and [HTTP::header exists "Content-Length"]} {
    HTTP::header insert "Connection" "Close"
    }
    }

  5. To save the iRule, click Finished.
  6. Navigate to Virtual Servers > Virtual Server List, then click the affected virtual server.
  7. Associate this iRule with your virtual server.
