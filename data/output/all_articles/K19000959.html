Description
Several partitions store files in virtual memory only. Storing files in these directories can lead to RAM exhaustion with no obvious cause.

For example, the following partitions store files in virtual memory only.
/dev/shm
/shared/rrd.1.2
/var/tmstat
/var/run
/var/prompt
/var/loipc

Environment

  • This applies to all BIG-IP systems.

Cause
BIG-IP systems mount several partitions with tmpfs file system which stores all files in virtual memory only. Upon unmount operation all files stored in those partitions are removed.  Note that some partitions will persist over reboot.  To determine which partitions exist in memory only you can run: mount | grep tmpfs

Recommended Actions

Do not store files in those partitions, even temporarily.
