Known Issue

This is the result of a known issue. The verification of the Open Shortest Path First (OSPF) packets containing an MD5 signature is incorrect for certain packet lengths. As a result, OSPF MD5 authentication fails even if the signature is valid due to the smaller incorrect packet length.

F5 Product Development tracked this issue as CR88260 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator Release Notes.

Additionally, this issue has been fixed in Hotfix-BIG-IP-9.3.1-HF2, which has been issued for BIG-IP version 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
