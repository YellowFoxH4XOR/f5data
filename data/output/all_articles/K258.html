K258: The BIG-IP system might report the CPU temperature as 255 degrees when it cannot determine the CPU temperature

Known Issue

This is the result of a known issue. In some cases, when BIG-IP cannot determine the current temperature of the CPU, it may report the temperature as 255 degrees. This will cause the system to send warning messages regarding the CPU temperature similar to the following:

Sep 14 10:10:02 bigip01 root: cpu 1 is too hot!
Sep 14 10:10:02 bigip01 root: cpu 2 is too hot!

F5 Networks Product Development tracked this issue as CR33922 and CR41793.
