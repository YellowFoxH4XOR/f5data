Issue

Old Behavior

Previously, the BIG-IP system executed the /usr/bin/qkview-lite script in the event of a TMM core.

New Behavior

Beginning in BIG-IP 10.2.2, the /usr/bin/qkview-lite script was removed from the system. When TMM cores, it no longer produces files in the /var/tmp (version 9.x) or /var/log (version 10.x) directories of the form:

<FQDN>.<DATE><TIME>.tech.out

F5 Product Development tracked this change as ID 222777.

Impact

The /usr/bin/qkview-lite script is not executed in the event of a TMM core.

Recommended Actions

None
