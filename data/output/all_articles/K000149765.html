Description

When an F5OS UCS file is generated from BIG-IQ, the timestamp of the UCS file is from a different timezone.

 

Environment

  • BIG-IQ
  • F5OS
  • UCS timestamp

 

Cause

ID1812345

 

Recommended Actions

The filename will use the local time of the F5OS device, instead of BIG-IQ.

Other than showing the incorrect backup status on BIG-IQ, the integrity of the UCS file is good.
