Description

BIG-IP GTM/DNS has marked down Server objects.

Test shows that these Server objects are actually available and reachable. The test can include icmp test and also iqdump output. 

Environment

  • BIG-IP GTM/DNS
  • Server objects are reachable/available
  • Server objects are marked down

Cause

Unknown at the time of publication. 

Recommended Actions

You will need to restart the big3d and gtmd processes on all BIG-IP GTM/DNS devices so that the Server objects would be marked correctly. 

  1. Login in to the Command Line.
  2. Run the following command to restart the big3d and gtmd processes.
    bigstart restart big3d
    bigstart restart gtmd
  3. You might need to restart the big3d and gtmd process on the Server objects (BIG-IP) if step 2 does not resolve the issue. 

Additional Information

The broadcast option for the big3d process

By default, the big3d process sends probe responses to all gtmd processes that are connected to the same self IP address that the probe request was received on. For example, if a probe request was sent to a big3d process using the iQuery link connected to the internal self IP, the resulting probe reply is sent out to all iQuery connections that are also connected to that same self IP. Because all gtmd processes in the same sync group share the same configuration, this means that all gtmd processes hear the probe reply.

However, in certain scenarios—where the iQuery mesh is partially down, and some gtmd processes have connectivity to the big3d process via a particular self IP, but others do not—this can result in only the gtmd processes that are connected to a specific interface being sent the probe response information, even though they are connected using iQuery to other self IPs on the same device.

To address this, the big3d process can be configured to send probe replies out all iQuery connections, regardless of where they are connected. This results in duplicate probe response messages arriving at the gtmd processes, which are processed in the order they are received.
