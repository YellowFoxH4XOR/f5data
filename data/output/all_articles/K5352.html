Known Issue

This is the result of a known issue. Unlike the other log files contained in the /var/log/ partition, the namesurfer.log file is not rotated. As a result, the namesurfer.log file can become quite large if you use NameSurfer frequently.

F5 Networks Product Development tracked this issue as CR27542, CR28615, and CR36844.

Workaround

To work around this issue, configure 3-DNS to rotate the namesurfer.log file, by performing the following steps:

  1. Log in to the command line.
  2. Edit the /etc/daily file.
  3. Locate the line that appears as follows:

    rotateLog 3dns

  4. Add the following new line after the line you located in step 3:

    rotatelog namesurfer.log

  5. Save the file and exit the editor.

The namesurfer.log file will now be rotated daily.
