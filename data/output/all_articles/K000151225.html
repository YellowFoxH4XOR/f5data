K000151225: Reactivating BIG-IP managed license when BIG-IQ is no longer in use

Type
Support Solution
Published
2025-05-09
Updated
2025-05-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000151225

Description

This article provides steps to activate BIG-IP managed license that was previously licensed from BIG-IQ but now BIG-IQ is no longer in use.

Environment

BIG-IP LTM

Cause

BIG-IQ is no longer in use to manage the BIG-IP license.

Recommended Actions

  1. Login to CLI
  2. Back up the existing license, enter the following command:

    eg : cp /config/bigip.license /config/bigip.license.old

  3. Truncate the existing license file, enter the following command:

    >/config/bigip.license

  4. Reboot system and it should prompt "No License"
  5. Proceed to reactivate BIG-IP license as per normal
    Follow the article K7752: Licensing the BIG-IP system

None
