Known Issue

VMware Horizon View v2.3 clients for Windows may fail to make BIG-IP APM Remote Desktop connections.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM Access Policy is configured with a VMware View Remote Desktop.
  • You use Windows 7 or Windows 8 or 8.1 systems to connect to the BIG-IP APM system.

Impact

VMware Horizon View users are unable to launch remote desktops.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H470970 on the Diagnostics > Identified > Medium screen.
  • The remote desktop connection stalls while the VMware Horizon View client displays a message similar to the following example:

    The connection server is preparing the desktop

Workaround

To work around this issue, you can use an iRule to send an HTTP/1.0 100 Continue response to the Horizon View client. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRule List.
  3. Click Create.
  4. In the Name box, type the following:

    ID450033

  5. In the Definition box, paste the following rule:

    when HTTP_REQUEST {
    if { [HTTP::path] == "/broker/xml" && [HTTP::header Expect] == "100-continue" } {
    SSL::respond "HTTP/1.0 100 Continue\r\n\r\n"
    }
    }

  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  8. Click the Edit link under Resources for the affected virtual server.
  9. In the iRules section, click Manage.
  10. Select the newly created iRule and move it to the Enabled box.
  11. Click Finished.
