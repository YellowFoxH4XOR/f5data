Known Issue

The BIG-IP ASM bd process may crash when the server defined in the remote logging profile is unavailable. This issue occurs when all of the following conditions are met:

  • A logging profile is configured to use remote storage on a remote server using the TCP-RFC3195 protocol
  • A web application is assigned the logging profile described in the first bullet
  • The BIG-IP ASM system is unable to communicate with the remote server

Impact

The BIG-IP ASM system may temporarily fail to pass traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP ASM system may temporarily fail to pass traffic
  • The BIG-IP ASM bd process dumps core, creating files in the /var/core/ directory that are named similarly to the following example:

    bd.bld473.0.core.6263.gz

  • The BIG-IP ASM system may log entries in the /var/log/asm file that appear similar to the following example:

    01310011:3: ASM configuration error: event code L2871 Failed to write to remote logger account: 5

  • The BIG-IP ASM system may log entries in the /var/log/ts/bd.log file that appear similar to the following examples:

    BD_MISC|ERR |21/09/11 08:50:04|6375|LoggingAccount.cpp:2870|remote log write FAILED res = -3 handle=0 buffer to write:
    open_remote_log: error -1 opening session with server!
    Failed to close remote log
    Failed to close remote logger lib
    BD_MISC|ERR |21/09/11 08:59:48|2077|LoggingAccount.cpp:0872|remote log open FAILED res = -4

Workaround

To work around this issue, you can configure the logging profile to use another available remote server or use another protocol, such as UDP. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Options > Logging Profiles.
  3. Click on the name of the affected logging profile.
  4. To configure the logging profile to use another available remote server, type the IP address in the Server IP box.
  5. To configure the logging profile to use another protocol, select the desired protocol, such as UDP, from the Protocol drop-down list.
  6. To save the modifications, click on the Update button.
