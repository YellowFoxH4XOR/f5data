Description
This error message appears in /var/log/apm:
null):Common:00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access.c , Function: <function's name>

For example: 
(null):Common:00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access.c, Function: hud_access_handler, Line: 3


At the very same time, another like next one is logged:
Access Profile /Common/<access policy name>: Per IP in-progress sessions limit (128) exceeded for 192.168.2.1
 

Environment

  • BIG-IP APM

Cause

This message occurs when the following condition is met:

  • The number of sessions in progress for a single client IP address exceeds the value configured for the Max In Progress Sessions Per Client IP setting in the access profile.


Recommended Actions

Follow next article to solve it: 
K38157145: Error Message: 01490547:4: Access Profile <name>: Per IP in-progress sessions limit (<#>) exceeded for <IP_address>
