Known Issue

BIG-IP APM Application Tunnels (Java & Per-App VPN) access sessions may fail to establish.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with Application Tunnels (Java & Per-App VPN) with one of the following remote desktop configuration items:
     
    • Citrix
    • Java AppTunnel
    • JavaRDP
    • Java Patcher
  • The access virtual server is configured with a non-zero Connection Rate Limit setting.

Impact

The access sessions fail to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the BIG-IP APM virtual server is configured with a Connection Rate Limit, App Tunnel access sessions are unable to establish.
  • When the BIG-IP APM virtual server is configured with a Connection Rate Limit of 0 (zero), App Tunnel access sessions are able to establish.
  • When you attempt to connect to the system using the BIG-IP Edge Client, you may observe error messages similar to the following example in the user's Edge Client log:

    f5vpn_plugin, 48, , 217, virtual void stream_pair_manager_flow::add(VPNFlowRef), Remote host:port of new flow, <fqdn of remote resource>, <port>, 0
    f5vpn_plugin, 1, , 304, event_handler, [kCFStreamEventHasBytesAvailable] Wrong second response

Workaround

To work around this issue, you can configure the virtual server to use a Connection Rate Limit setting of 0 (zero = disabled).

Impact of workaround: Connections that the virtual server handles will not be rate limited.
