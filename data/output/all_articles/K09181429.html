Description

In version 15.0.0 and newer, you may import and export the security policies with the Application Security Operations Administrator role.
Ensure the Application Security Operations Administrator role has the Common partition access. Otherwise the Application Security Operations Administrator role cannot import the security policies.

Environment

  • BIG-IP ASM / Advanced WAF

Cause

The Application Security Operations Administrator role requires the Common partition access to make the import successful.

Recommended Actions

Refer to the following manual articles to assign the Application Security Operations Administrator role with the Common partition access for the user:

K14895: Overview of BIG-IP ASM user role permissions
Manual Chapter : User Roles
