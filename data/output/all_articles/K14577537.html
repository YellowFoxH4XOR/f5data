Issue

Error Message

err snmpd[<PID>]: 010e0001:3: Cannot connect to MCPD server.

In this error message, note the following:

  • <PID> is the process ID for the snmpd process

For example:

err snmpd[7440]: 010e0001:3: Cannot connect to MCPD server.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The SNMP agent is unable to communicate with the mcpd process.

This message may be generated by a heavily loaded BIG-IP system or when the mcpd process is down. If the mcpd process is unable to respond, the snmpd process is unable to establish a communication channel and logs the error message. 

Impact

The BIG-IP system loses SNMP functionality until communication between the snmpd and mcpd processes is restored. The BIG-IP system is unable to retrieve SNMP data.

Recommended Actions

Check to ensure the mcpd process is running by typing the bigstart status mcpd command in the BIG-IP command line.  If the process in not in the run state, restart it using the bigstart restart mcpd command.  If the message persists over time it may be necessary to reboot the BIG-IP system.
