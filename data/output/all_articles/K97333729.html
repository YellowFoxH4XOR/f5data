Description

You accidentally deleted the structure in visual edit for a access profile. You have not applied the policy.
Can you revert the accidental delete?

Environment

  • APM
  • Access Policy
  • Visual Policy Editor

Cause

It is not possible to revert changes.

Recommended Actions

Before making changes you need to make a UCS backup of the entire configuration or make a copy or export the Access Policy you are modifying.

K13132 : Backing up and restoring BIG-IP configuration files with a UCS archive
Manual Chapter : Importing and Exporting Access Profiles
