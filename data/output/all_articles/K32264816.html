Description

This article describes how to customize top output and run a one-liner command to help you troubleshoot high CPU on the BIG-IP system.

Environment

  • BIG-IP
  • High CPU
  • top command

Cause
None

Recommended Actions

Follow these steps to run a one-liner script that collects the output of the top command every 10 seconds until you terminate the script.
 

  1. Enter top on the CLI.
    1. While top is running hit 1.
    2. Hit f, then scroll down using the arrow keys to PPID and P and press d to toggle them on.
    3. Go back to top using <Esc> and hit c to expand the command column.
    4. Hit H (shift+h) to enable threads view.
    5. Save the top output format with W (shift+w) and then Enter.
    6. Quit by pressing q.

      You should see the top output like below, if not, follow previous steps again.
      All CPU stats should be displayed individually:
      Cpu0  : 22.2%us,  6.3%sy,  0.0%ni, 71.5%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
      Cpu1  : 14.9%us,  4.6%sy,  0.0%ni, 79.5%id,  0.0%wa,  0.3%hi,  0.7%si,  0.0%st
      Cpu2  :  5.6%us,  5.3%sy,  1.7%ni, 87.5%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
      Cpu3  :  4.3%us,  3.6%sy,  0.0%ni, 92.1%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
      Mem:   8264900k total,  8189092k used,    75808k free,   225588k buffers
      Swap:  1048568k total,     3064k used,  1045504k free,   385452k cached

      You should see P and PPID columns (they may be on the right edge of the screen). Additionally, the full commands of each process and each thread should be displayed:
      PID USER      PR  NI  VIRT  RES  SHR S %CPU %MEM    TIME+  P COMMAND
      9833 root      RT   0 1787m  64m  63m S  6.3  0.8 166:00.42 0 tmm.0 --tmid 0 --npus 4 --platform A100 -m -s 1659
      4565 root      20   0 21468  12m 6456 S  4.6  0.2 119:41.39 2 /usr/bin/csyncd

  2. Run a while loop to collect periodic top output at a 10 second interval for up to 10 minutes. The script will create a large file the longer it runs so be careful not to fill up the /shared volume (/var/tmp is a link to /shared/tmp): 

    while :; do date >> /var/tmp/top1.out; top -cbn 1 >> /var/tmp/top1.out; tmsh show sys tmm-info >> /var/tmp/top1.out; echo "###################" >> /var/tmp/top1.out; sleep 10; done
     
  3. Stop the command string with ctrl+c.
  4. Once you have collected the data, examine it to verify which process is showing high CPU usage and verify the objects that are related to the process.
    Note: If needed, open a case with F5 support.
