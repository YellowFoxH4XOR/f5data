Issue

In the event that the BIG-IP APM system is unable to communicate with the RSA SecurID server that has been configured as an AAA server, the user may receive the following error message:

The username, password, or other logon credential is not correct.
(error: Authentication Manager is not responding)
Please try again.

In addition, the /var/log/apm file may include this corresponding error message:

SECURID module: authentication with <'username'> failed in authenticateUser(): Authentication Manager is not responding, code: -1, state: SECURID_AUTH_STATE_ACCESS_DENIED

The error message may mislead users to believe that they have submitted incorrect credentials. If your user is reporting authentication issues, ask them to submit the entire error message rather than just the first line. These error messages indicate that communication between the BIG-IP APM system and the RSA SecurID server is not working. To correct the error, confirm that the AAA server definition for the applicable RSA SecurID server is correct, confirm that the RSA SecurID device is operational, and confirm that the two devices have an open network path.

Note: This error message is similar to the error described in K12119: Error Message: SECURID_AUTH_STATE_ACCESS_DENIED. If your error message does not include the Authentication Manager is not responding error message, refer to K12119.
