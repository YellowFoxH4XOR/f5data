Topic

When you select a logging profile for BIG-IP ASM virtual servers that run on BIG-IP Virtual Edition (VE) platforms, avoid using a logging profile that logs all requests.

Description

A logging profile determines where the BIG-IP ASM system logs events, and which elements are logged. You can log events either locally on the system and view the events in the Event Logs, or log events to a remote server. In addition, the system includes two logging profiles that log data locally for Application Security: one to log all requests and another to log illegal requests.

When you select a logging profile for BIG-IP ASM virtual servers that run on BIG-IP VE platforms, you should avoid using a logging profile that logs all requests if the virtual server processes a high volume of traffic. If you use a logging profile that logs all requests, the system may experience performance issues while attempting to keep up with the logging demands. For example, as shown in the following output, the top command may indicate a high percentage for I/O wait as the system attempts to complete I/O operations:

If you have a BIG-IP ASM virtual server running on a BIG-IP VE platform, and the logging profile is configured to log all requests, you should consider changing the profile to log only illegal requests.
