Description

  • User is located in non Enterprise LAN and could surf web via IPv6
  • "Allow-Only-in-Enterprise-LAN" doesn't block IPv6 traffic

Environment

  • APM
  • NA VPN
  • Connectivity Profile with "Allow-Only-in-Enterprise-LAN" setting
  • IPv6

Cause

  • ID852837: Stonewall service does not block IPv6 traffic in Always connected Edge Client

Recommended Actions

  • There is no workaround rather than not using IPv6
