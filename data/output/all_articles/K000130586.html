Description

After making changes to the BIG-IP configuration you may notice very slow sync times between BIG-IP's in an HA group.


Environment

BIG-IP HA Pair


Cause

BIG-IP's have a large configuration, and have "Manual with Full Sync" selected as the device group's sync method.


Recommended Actions

Open the device group settings and use the "Manual with Incremental Sync" type instead of "Manual with Full Sync", and make sure that all changes combined will not exceed the "Maximum Incremental Sync Size" setting in the device group or else a full sync will still be performed even with incremental selected.


Additional Information

The "Manual with Full Sync" method will tell the BIG-IP to send its entire configuration through in the sync operation. If the configuration is too large this could cause the BIG-IP to hang while the full configuration is sent, installed and then loaded on the BIG-IP devices.


Using the "Incremental" sync type, tells the BIG-IP to only sync changes that have occurred since the last sync, greatly reducing the amount of time a sync operation needs to complete.
