Issue

If you run 3dnsmaint to install new versions of big3d, and a wide IP pool that contains no virtual servers exists on the 3-DNS, 3dnsmaint will return the following error.

Validation Warning in valPoolVSs: Wideip <name>: Pool <name> has no virtual servers

This error is a warning and does not necessarily indicate a problem.
