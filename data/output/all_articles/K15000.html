Topic

Two BIG-IP system features allow the system to check for and recommend software updates, in addition to provide F5 with high-level device use information to optimize development resources.

Description

The BIG-IP system uses the following two software features to contact F5.

FeaturePurpose
Automatic Update CheckChecks for and recommends the latest software updates for your BIG-IP system.
Automatic Phone HomeObtains product versioning, module provisioning, and hardware-related information.

For more information about these features and their connectivity requirements, refer to the following sections:

  • Automatic Update Check
  • Automatic Phone Home
  • Connectivity requirements

Automatic Update Check

BIG-IP 11.5.0 enables the system to check the F5 Downloads server for software updates for your system. By default, the system automatically checks the F5 Downloads server on a weekly basis. When there are no updates available, the system indicates that the software is up-to-date. When there are updates available, the system provides a list of available software updates with links to the software on the F5 Downloads server.

Note: The system executes /usr/bin/updatecheck once a day to determine if it needs to check the F5 Downloads server for software updates. If the system attempts to check the F5 Downloads server for software updates and fails to reach the F5 Downloads server, the system logs a message similar to the following: info updatecheck[22895]: PHONEHOME: Update Server unavailable. For more information, refer to K50510351: Error Message: info updatecheck[PID]: PHONEHOME: Update Server unavailable.

The Automatic Update Check feature checks for the following BIG-IP software update types:

  • Major, minor, and hotfix releases
  • End-User Diagnostics (EUD)
  • EPSEC/OPSWAT
  • Geolocation

The Automatic Update Check feature operates as follows:

  1. At the scheduled update check interval, the BIG-IP system checks for software update eligibility by sending its hardware manifest and current software version to the F5 license server, activate.f5.com.
  2. The BIG-IP system contacts callhome.f5.com and receives a list of the latest compatible software updates.
  3. The BIG-IP system displays the results of the update check on the Update Check page in the Configuration utility or in the TMOS Shell (tmsh).

You can disable or modify the schedule, manually check for updates, and display the results of the Automatic Update Check feature by performing the following procedures:

  • Disable the Automatic Update Check feature
  • Modify the schedule
  • Display the results
  • Manually perform an update check

Disable the Automatic Update Check feature

The Automatic Update Check feature is enabled by default. You can use either the Configuration utility or tmsh to disable the feature by performing one of the following procedures:

Impact of procedures: When you disable the Automatic Update Check feature, the system does not retrieve or display a list of software updates, even if you install new software on the BIG-IP system.

  • Use the Configuration utility to disable the Automatic Update Check feature
  • Use tmsh to disable the Automatic Update Check feature

Use the Configuration utility to disable the Automatic Update Check feature

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > Update Check.
  3. For Automatic Update Check, select Disabled.
  4. Select Apply Settings.

Use tmsh to disable the Automatic Update Check feature

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify the Automatic Update Check feature, use the following command syntax:

    modify /sys software update auto-check [disabled | enabled]

    For example, to disable the feature, enter the following command:

    modify /sys software update auto-check disabled

  3. To save the configuration, enter the following command:

    save /sys config

Modify the schedule

By default, the Automatic Update Check and Automatic Phone Home features are scheduled to check for software updates on a weekly basis. You can use either the Configuration utility or tmsh to modify the schedule for both. To do so, perform one of the following procedures:

Note: If the system does not receive a successful response from the F5 Downloads server, it attempts again, once a day, until it receives a successful response.

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

  • Use the Configuration utility to modify the Automatic Update Check schedule
  • Use tmsh to modify the Automatic Update Check schedule

Use the Configuration utility to modify the Automatic Update Check schedule

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > Update Check.
  3. For Update Check Schedule, select an appropriate value (Daily, Weekly, or Monthly).
  4. Select Apply Settings.

Use tmsh to modify the Automatic Update Check schedule

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify the Automatic Update Check schedule, use the following syntax:

    modify /sys software update frequency [daily | weekly | monthly]

    For example, to change the schedule to monthly, enter the following command:

    modify /sys software update frequency monthly

  3. To save the configuration, enter the following command:

    save /sys config

Display the results

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

  • Use the Configuration utility to display the results of an update check
  • Use tmsh to display the results of an update check

Use the Configuration utility to display the results of an update check

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > Update Check.

    The list of available software updates is displayed.

Use tmsh to display the results of an update check

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To display all update check information for the system, enter the following command:

    list /sys software update-status

    The list of available software updates is displayed.

Manually perform an update check

Manually performing an update check is useful if you need to view available software updates between scheduled checks.

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

  • Use the Configuration utility to manually run an update check
  • Use tmsh to manually run an update check

Use the Configuration utility to manually run an update check

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > Update Check.
  3. Select Check Now.

    The list of available software updates is displayed.

Use tmsh to manually run an update check

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To manually perform an update check, enter the following command:

    run /util updatecheck

  3. To display all update check information for the system, enter the following command:

    list /sys software update-status

    The list of available software updates is displayed.

Automatic Phone Home

BIG-IP 11.5.0 software enables the BIG-IP system to send non-confidential, high-level device information to F5 in order to help determine product usage to optimize product development. Some of the information received includes the following:

  • Provisioned modules
  • Platform identifier
  • Hardware version
  • Software version
  • Physical disk type
  • Cooling system
  • CPU info

You can determine the complete list of information sent to F5 by running the createmanifest -d -v command from the Advanced Shell (bash).

Note: For VIPRION systems, information is gathered for the chassis and each of the installed blades.

Automatic Phone Home operates as follows:

BIG-IP 13.x and later:

  1. At the time of license registration, the BIG-IP system creates an encrypted key and sends an SSL certificate signing request (CSR) embedded in the dossier to the F5 license server at activate.f5.com.
  2. Upon receiving a license, an SSL client certificate based on the encrypted key is installed and securely stored in the master control process daemon (MCPD) database. 
  3. The BIG-IP system sends the hardware manifest using an SSL connection to the F5 API server at api.f5.com.

    Note: Steps 1 and 2 are performed one time only, during BIG-IP license registration. Step 3 is used for remaining call home communication.

    Note: Starting in BIG-IP 14.1.2, the phone home feature is disabled for BIG-IP VE AWS China region instances.

BIG-IP 12.x and earlier:

  • At the scheduled phone home interval, the BIG-IP system encodes a dossier with the hardware manifest data and sends this information to the F5 license server at activate.f5.com.

    Note: The BIG-IP system discards the received license and does not use the license to re-license the system.

You can disable, modify the schedule, and display the results of the Automatic Phone Home feature by performing the following procedures:

  • Disable the Automatic Phone Home feature
  • Modify the schedule

The Automatic Phone Home feature is enabled by default. In BIG-IP 12.1.0 and later, you can use either the Configuration utility or tmsh to disable the feature. To do so, perform one of the following procedures:

Impact of procedure: When you disable the Automatic Phone Home feature, the system does not retrieve or display a list of software updates, even if you install new software on the BIG-IP system.

  • Use the Configuration utility to disable the Automatic Phone Home feature

Use the Configuration utility to disable the Automatic Phone Home feature

  4. Select Apply Settings.

    For example, to disable the feature, enter the following command:

    modify /sys software update auto-phonehome disabled

  3. To save the configuration, enter the following command:

    save /sys config

Connectivity requirements

Firewall

If the BIG-IP system is behind a firewall, you should allow access for the following F5 host servers, DNS servers, and ports, so that the system can complete the update tasks:

  • Host servers
    • callhome.f5.com port 443
    • activate.f5.com port 443
    • api.f5.com port 443
  • DNS servers
    • The firewall should allow port 53 UDP access for DNS resolution.
    • The BIG-IP DNS Servers List should be configured with accessible DNS name servers.

Routing and HTTP Proxy servers

To reach activate.f5.com, the BIG-IP system chooses an interface based on the current routing table. The BIG-IP system's routing table includes both the management and Traffic Management Microkernel (TMM) interfaces. For information, refer to K13284: Overview of management interface routing (11.x - 16.x). In BIG-IP 15.1.0 and later, the system supports the use of HTTP Proxy servers when configuring automatic updates. In BIG-IP versions prior to 15.1.0, the system does not support the use of HTTP Proxy servers when configuring automatic updates.
