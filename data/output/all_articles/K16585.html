Topic

Single-core Virtual Clustered Multiprocessing (vCMP) guests support only a limited number of products and product combinations.

Description

For certain platforms, the vCMP host can allocate a single core to a vCMP guest. However, because a single-core guest has relatively small amounts of CPU resources and allocated memory (shared between control and data planes within the single CPU core), F5 supports only the following products or product combinations for a single-core guest:

  • BIG-IP LTM standalone only
  • BIG-IP DNS standalone only
  • BIG-IP LTM and DNS combination only

Recommendations

When you plan vCMP configurations, you should consider the following factors:

  • The vCMP host allocates a limited amount of resources to single-core vCMP guests, which are only sufficient for the products and product combination listed in this article.
  • Generating reports is not recommended and may result in CPU peaks, impacting the vCMP guest's performance. If you need to generate reports, you should do so during a scheduled maintenance. If this is not possible, F5 recommends that you generate reports only when strictly necessary and that you closely monitor system resources during that time.
