Known Issue

The ripd process may produce a core file on the BIG-IP system.

This issue occurs when the following conditions are met:

  • You are using the Routing Information Protocol (RIP) dynamic routing protocol on your BIG-IP system.
  • You configure multiple self IP addresses belonging to different subnets on the same Virtual Local Area Network (VLAN).
  • You add one of the subnets to the router RIP stanza in the ZebOS configuration.

Impact

The ripd process core files and the configuration will not be saved.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs an error message to the /var/log/kern.log file that appears similar to the following example:

    info kernel: ripd[10029]: segfault at 24 ip 00000000080c578c sp 00000000ffd3ee40 error 4 in ripd[8048000+ac000]

  • The ripd process generates a core file, and the system logs an error message to the /var/log/messages file that appears similar to the following example:

    notice logger: Started writing core file: /var/core/ripd%0.bld1.0.1447.core.gz for PID 20429

Resolution

Status

F5 Product Development has assigned ID 614296 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can configure only one self IP address network per VLAN.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
