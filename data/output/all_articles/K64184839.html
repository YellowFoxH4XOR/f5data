K64184839: About: session.client.unique_id

Type

Source

Description

The session variable session.client.unique_id is not consistently populated when a mobile device establishes a session with an APM enabled Virtual Server.  

Environment

  • F5 Access app for Android or iOS 

  • BIG-IP APM 

Cause

session.client.unique_id may or may not be populated depending on the mobile OS being used and whether or not the device is being managed by an MDM solution. Previous use of identifiers like MAC addresses in now not supported by the OS because of privacy factors.

Recommended Actions

  • Use an MDM solution to provide the value for the attribute MdmDeviceUniqueId or UDID to the managed mobile device. These values will then be provided to APM and set as session.client.mdm_device_unique_id and/or session.client.unique_id.
  • Or use another method to identify the device, ie. device certificate.
