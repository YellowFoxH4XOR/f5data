Description

Getting these error logs on /var/log/daemon.log:

  • emerg logger: Re-starting named

Environment

  • BIG-IP DNS
  • named
  • /var/log/daemon.log

Cause

This is because there are no permissions for:var/named/config/named.conf
/var/log/daemon.log
err named[18845]: open: /config/named.conf: permission denied
crit named[18845]: loading configuration: permission denied

Answer/Recommended Actions

Change the permissions for these directories:

chown named:named /var/named/config/
chown named:named /var/named/config/namedb/*
