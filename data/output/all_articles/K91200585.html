Known Issue

The BIG-IP Edge Client may fail to connect after you upgrade the system to 13.0.0.

This issue occurs when all of the following conditions are met:

  • You have upgraded your BIG-IP APM system to 13.0.0.
  • You attempt to establish a session with an access policy that contains a logon page, or you perform another action that results in the system presenting a GUI interface.

Beginning in 13.0.0, F5 modified the BIG-IP APM JavaScript code so it better handles session timeout parameters. The issue described in this article triggers if the client system had cached the old JavaScript code.

Impact

Users are unable to establish access sessions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When users establish an access session through the BIG-IP Edge Client, they receive a script error similar to the following example:

    Error: 'APMSessionTimeout is undefined'
    Code: 0

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can locate GUI items in your access policy, such as the logon page, and add a ?13 after include for the session_check.js. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility with administrative privileges.
  2. Navigate to Access > Profiles/Policies > Customization > Advanced.
  3. Navigate to your access policy.
  4. Locate the GUI item where the issue occurs, such as a logon page.

    For a logon page, the page is "logon.inc."

  5. Locate the following line:

    <script language="JavaScript" src="/public/include/js/session_check.js" ></script>

  6. Modify the line to add ?13 after session_check.js, as follows:

    <script language="JavaScript" src="/public/include/js/session_check.js?13" ></script>

  7. Click Save Draft.
  8. Click Save.
