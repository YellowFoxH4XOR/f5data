K000149984: iRule isn't working with error: Can't call after responding - ERR_NOT_SUPPORTED (line 1) invoked from within "HTTP::host"

Published

2025-02-26
Applies to

Source

Description

After adding an additional iRule to a Virtual Server. The iRule is not working as expected with error: ERR_NOT_SUPPORTED (line 1)  invoked from within "HTTP::host" found in /var/log/ltm.

 

Environment

BIG-IP version 17.1.0 at the time of the article's creation

Attaching an additional iRule to Virtual Server.

 

Cause

The error: Can't call after responding - ERR_NOT_SUPPORTED (line 1)  invoked from within "HTTP::host" regarding the iRule is likely because it's already responded once and cannot respond again, and because of this it kills the session.

 

Recommended Actions

Add the "[HTTP::has_responded]" to the iRule like the following example:

when HTTP_REQUEST
{
if {[HTTP::has_responded]} {
    return
  } else

<the rest of iRule>
