Description

An error has occurred or the page does not load when navigating to Access -> Guided Configuration

Environment

BIG-IP APM

Cause

Unknown

Recommended Actions

1. Take a backup archive the unit and save it externall for safety - https://my.f5.com/manage/s/article/K13132

2. Download the latest version of Guided Configuration bundle

a. Browse to https://downloads.f5.com
b. For product family select "BIG-IP"
c. For product line select "Guided Configuration"
d. For prodcut version select the latest version (10.0, etc)
e. Download the .tar.gz file for example f5-iappslx-agc-usecase-pack-10.0-0.0.1636.tar.gz
f. Uncompress the tar.gz and it should create a new folder for example "f5-iappslx-agc-usecase-pack-10.0-0.0.1636" with a whole bunch of .rpms

2. Uninstall the curent version of the framework

a. In the Configuration Utility GUI of the BIG-IP navigate to iApps -> Package Management LX there is a list of installed iApps
b. Find "f5-iappslx-access-framework" checkmark it and uninstall this
c. If required, you can delete all frameworks and re-install them (note there are 2 pages of tick-boxes) in step 4

3. Restart httpd, tomcat, restjavad and restnoded with the following command from the CLI:

# tmsh restart sys service httpd tomcat restjavad restnoded

4. Install the latest version of the framework which you downloaded from step 2

a. In the Configuration Utility GUI of the BIG-IP navigate to iApps -> Package Management LX
b. Click the import button and select the .rpm you downloaded/extracted from step 2 for example "f5-iappslx-access-framework-1.8.0-0.0.1636.noarch.rpm"

Additional Information

If these steps did not resolve the issue, there is one final solution but it is destructive and will destroy the Guided Configuration part of the deployment (but the objects it created will still remain)

# bigstart stop restnoded restjavad
# clear-rest-storage
