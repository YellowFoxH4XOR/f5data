Description

When pool members' port is set 443, client connection fails.
When their port is set 80, client connection successful.
 

Environment

  • BIG-IP 
  • Any version
  • Virtual server
  • Pool member
     

Cause

Server SSL profile was not set to the virtual server.
 

Recommended Actions

Set Server SSL profile to the virtual server.
 

Additional Information

Client SSL profile is used for client side of connection, it does not used for Server side connection.

    Clients <-------> <Client ssl profile> Virtual Server 
      <server ssl profile> <-------> Pool members 443
