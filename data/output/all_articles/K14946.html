Topic

This article describes the BIG-IP Virtual Edition (VE) template types and the disk size for each of the associated OVA images provided at F5 Downloads.

Description

When downloading BIG-IP VE images from F5 Downloads, to help you select the correct version and hypervisor type, the VE image name incorporates fields for software version, software build number, and hypervisor extension.

For example:

BIG-IP-<version>.<build>-<hypervisor>

Beginning in version 11.5.0, BIG-IP VEs are available in the LTM_1SLOT, LTM, ALL, and ALL_1SLOT image template types. To differentiate between the VE image templates, an additional type field is added to the image name.

For example:

BIG-IP-<version>.<build>-<type>-<hypervisor>

The following sections describe each VE image template type and list the image disk size for each version:

  • LTM_1SLOT
  • LTM
  • ALL_1SLOT
  • ALL

Note: Upgrading to BIG-IP 11.5.0 does not affect functionality, and the disk size or disk layout remains unchanged.

Note: Versions 11.0.0 through 11.4.1 have 100 GB image sizes.

Recommendation

Disk sizing

Although these BIG-IP VE images have their default disk sizes, you can increase the disk sizes of the hosting hypervisor configuration before increasing the size of individual directories in the BIG-IP VE system. For more information, refer to K14952: Extending disk space on BIG-IP VE.

Note: Shrinking the disk size is not supported because most hypervisors do not support disk shrinking.
