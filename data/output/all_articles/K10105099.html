Known Issue

BIG-IP APM portal access may trigger a memory leak

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a portal access profile.
  • HTTP POST content is modified by the portal access rewrite process, such as XML content.

Impact

The rewrite process memory usage increases and may eventually affect other services and overall system performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing system statistics, memory utilization of the BIG-IP system continually increases.
  • When viewing the BIG-IP APM rewrite process for memory utilization, the amount of memory utilized by the processes continually increases when processing content.
  • The BIG-IP APM system stops processing content and generates a core file in the /shared/core/ directory that appears similar to the following example:

    rewrite.1.bld675.28.core.gz

  • The affected BIG-IP APM device may fail over to a peer device when configured for high availability (HA).
