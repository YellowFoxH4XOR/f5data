Topic

Some Firefox browser extensions, such as the Fasterfox and NoScript add-ons, can cause the BIG-IP system and Enterprise Manager Apache and Tomcat web servers to exceed the allowed concurrent HTTP connections (default is 10). As a result, the Configuration utility may be unable to display some pages. When this occurs, the BIG-IP or Enterprise Manager system logs one of the following error messages in the /var/log/httpd/http_errors file:

  • [error] ajp13.service() ajpGetReply recoverable error 120000
  • [error] server reached MaxClients setting

Workaround

To work around this issue, you can disable or remove the Firefox extensions that are causing the problem. Consult the Firefox and add-in documentation for information about removing or disabling extensions.

Additionally, the value of the MaxClients setting for the httpd process can safely be increased to a value of 20.

Note: For more information about increasing the MaxClients limit, refer to K9588: Error Message: httpd: [error] server reached MaxClients setting.
