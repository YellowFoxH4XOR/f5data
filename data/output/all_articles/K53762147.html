Known Issue

The BIG-IP system does not prevent you from selecting a number of CPUs that exceed the license's throughput limit.

This issue occurs when the following condition is met:

  • You configure a number of CPUs that exceeds the licensed throughput.

For example, you have a Good license option with a maximum allowed throughput of 25 Mbps, which limits the number of CPUs to two. If you erroneously configure four CPUs, the system does not warn you that you have exceeded the maximum allowed limit.

Impact

Depending on the operations you perform, the Traffic Management Microkernel (TMM) may produce a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system does not prevent or warn you from exceeding the number of CPUs for the licensed throughput.
  • You experience system instability.
