K000160019: Web browser VPN client endpoint inspection fails after upgrading to BIG-IP APM 17.5.X due to embedded 7-Zip version restriction

Type
Support Solution
Published
2026-02-16
Updated
2026-02-16
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.X, 17.5.1, 17.5.0
  • APM Clients
Source
https://my.f5.com/manage/s/article/K000160019

Description

Users experience failures with antivirus endpoint inspection when connecting via the web browser VPN client after upgrading BIG-IP APM to version 17.5.1. The antivirus check prompt appears, but no antivirus is detected and connections are denied. 

Environment

  • BIG-IP APM
  • Web browser VPN client

Cause

The web browser plugin installer uses a self-extracting file with an embedded 7-Zip version that may be blocked by security policies, preventing plugin installation and causing endpoint inspection failures.

Recommended Actions

  • Use the Edge Client for users who require endpoint checks and cannot make exceptions to the 7-Zip version policy.
  • Request a security policy exception for the required 7-Zip version in the endpoint security policy for the plugin installation path.

Additional Information

  • The Edge Client does not require the browser plugin and is not affected by the 7-Zip version restriction.
  • The issue is specific to browser-based VPN endpoint inspection and does not impact native client connections.
