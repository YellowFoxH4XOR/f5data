K000154640: Mitigating CVE-2024-3596 on BIG-IQ 8.4.1 and later versions

Type
Support Solution
Published
2025-09-08
Updated
2026-08-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.4.0
Source
https://my.f5.com/manage/s/article/K000154640

Description

BIG-IQ 8.4.1 and later versions include the fix addressing CVE-2024-3596 RADIUS authentication forgery. However, as this mitigation is not enabled by default, it must be enabled manually. 

Environment

  • BIG-IQ 8.4.1 and later versions
  • Remote RADIUS authentication
  • BIG-IQ 8.4.0 engineering hotfix (EHF)

Cause

None

Recommended Actions

To mitigate CVE-2024-3596, perform the following procedure:

Note: Before configuring these settings with true, you must ensure that your Radius server supports the message authenticator attribute, and it is enabled. Otherwise, the change may break functionality.

1. Upgrade to BIG-IQ 8.4.1 or later versions. 

   * If you use BIG-IQ 8.4.0 EHF which includes fixes for these 2 IDs, you can also configure following mitigation measures: 

    • ID1621249-9: CVE-2024-3596: Blast Radius
    • ID1678649-7: Radius client configuration option for CVE-2024-3596

2. There are two places where you must configure the enforcement:

2.1. For BIG-IQ system interface logins, you can set the radius.messageAuthenticator property to true in /var/config/rest/config/restjavad.properties.json under .platform.authn.

  Login to CLI via ssh, then use an editor (such as vi or nano) and append this property with true under .platform.authn.

 ---<snip>---
   "platform" :
   {
     "apacheAsyncClient" :
     {
     },
     "authn" :
     {
       "radius.messageAuthenticator": true
     },
     "clusterUpgrade" :
     {
     },
 ---</snip>---

 

 After added the property, the jq command output appears similar to the following example:

 # jq .platform.authn /var/config/rest/config/restjavad.properties.json

 {

  "radius.messageAuthenticator": true

 }

 

 For this change to take effect, you must restart Restjavad. To do so, enter the following command:

  Impact of procedure: The restjavad service on the BIG-IP system is briefly interrupted during the restart. F5 recommends performing this procedure during a maintenance window. 

 # tmsh restart sys service restjavad 

 

2.2. For CLI/SSH logins, enforcement is implemented by modifying DB Key: sys db radius.messageauthenticator value to true.

 # tmsh modify sys db radius.messageauthenticator value true

 # tmsh save sys config

 

 When set for the CLI, the db variable query output appears similar to the following example:

 # tmsh list sys db radius.messageauthenticator

 sys db radius.messageauthenticator {

   value "true"

 }

After these are set, the BIG-IQ system validates Message-Authenticator for the RADIUS responses when authentication is performed for remote users through RADIUS.
