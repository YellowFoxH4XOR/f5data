Source

Description

You are not able to access an application through a portal access configuration.

Environment

  • Your application(s) uses service worker or web worker
    • Or was recently upgraded to use service worker(s)
  • The application is accessed through portal access (APM)

Cause

Service worker(s) and/or web workers are not supported through portal access.

Recommended Actions

Remove service worker(s) and/or web workers from the application.
