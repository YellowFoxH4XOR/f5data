Known Issue

This is the result of a known issue. When typing the ssh-host-key rsa encrypted-hostkey ? command in config (cfg) mode, the question mark (?) should prompt the ARX CLI's help completion for the command. However, when the question mark is pressed, the cli_daemon crashes, dumps core, and terminates the SSH session. Additionally, an error message that appears similar to the following example is logged to the syslog file:

:SWITCH:1-1-ACM-0:LOG-0-ERR-FILTER:: cli_daemon[15741]: [E:1] Writing core file.
