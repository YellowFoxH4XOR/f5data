Description

You want to block access for a specific AD authenticated username.

Environment

  • BIG-IP APM
  • AD authentication 

Cause

You would like to block a user using their AD authentication username.

Recommended Actions


In the access policy you can configure a AD query object after AD auth object and configure a branch with below expression and end this branch in "Deny" 

expr { [string tolower [mcget {session.logon.last.username}]] equals "<username>" }

Note: Replace <username> with the intended AD authentication username you wish to block resource access.
