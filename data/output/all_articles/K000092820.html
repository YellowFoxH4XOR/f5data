K000092820: All vWire interfaces go down during configuration

Type
Support Solution
Published
2022-12-05
Updated
2022-12-07
Source
https://my.f5.com/manage/s/article/K000092820

Description

You are trying to set vWire with tagged VLANs, however, it fails with the following symptom:

  • All vWire interfaces are down

Environment

  • DDoS Hybrid Defender provisioned (without LTM)
  • vwire-propagate-linkstatus enabled configured on vlan group

Cause

DDoS Hybrid Defender is limited to a simple interface where many of the LTM objects are concealed, the main condition is to set the proper vWire with the same configuration on the vWire members. If a mismatch occurs and the members join the vWire, the vwire-propagate-linkstatus will mark the interface down.

 

If one interface goes down all interfaces in vWire will be marked as down.

 

 Recommended Actions

Before you will bundle interfaces into vWire, please make sure that:

  1. Interfaces are up and stable
  2. Configuration on both interfaces is the same
