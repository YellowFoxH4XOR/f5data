Known Issue

The BIG-IP system may erroneously continue to retransmit TCP data segments after receiving an Internet Control Message Protocol (ICMP) Type 3, Code 4 (fragmentation required and DF flag set) message.

This issue occurs when the following condition is met:

  • A client or router sends an ICMP fragmentation message with random Maximum Transmission Unit (MTU) values.

Impact

Too many ICMP fragmentation messages may saturate the link between the BIG-IP system and the client. In rare conditions, this may cause a minor BIG-IP system outage.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Within a packet capture, you observe that the BIG-IP system continues transmitting TCP data segments when an ICMP fragmentation message (Type 3, Code 4) with an MTU size greater than or equal to zero is received. The retransmission continues until there are no ICMP messages (Type 3, Code 4), a connection times out, or an ACK is received.
  • The client may experience a connection timeout.
