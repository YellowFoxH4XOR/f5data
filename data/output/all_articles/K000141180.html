K000141180: Reconfigure tab does not show any data on the F5 Automated backup iApp.

Type
Support Solution
Published
2024-09-25
Updated
2026-02-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000141180

Description

The F5 Automated backup iApp stopped working suddenly and the reconfigure tab does not show any data or is empty for that iApp.
Note: The f5.automated_backup iApp is not developed by F5 and is not supported by F5.  This iApp was created in the DevCentral community, and support for this iApp is only available via DevCentral. However the recommended actions detailed below can resolve this issue.

The recommended and officially supported method for automating UCS backups can be found in the following article.
    K13418: Archiving UCS files using the logrotate and crontab utilities (11.x - 17.x )

If you have encountered the issue described above after using the F5 Automated backup iApp, see below for advice on how to return the BIG-IP to regular operation 

Environment

  • BIG-IP LTM 15.1.10
  • F5 Automated Backup iApp

Cause

The scriptd daemon crashed.

Bug ID 842193 

Recommended Actions

1. Restart the scriptd daemon to recover the backup iApp functionality by running the following command from bash:

bigstart restart scriptd

 

2. Restart the httpd, tomcat, restjavad, and restnoded daemons to recover the Reconfigure tab for the iApp by running the following command from bash:

bigstart restart httpd tomcat restjavad restnoded
