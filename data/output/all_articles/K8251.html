Known Issue

This is the result of a known issue. When the autolasthop kernel module is loading during bootup, the following kernel-tainted error message is reported:

INIT: version 2.85 booting
Welcome to BIG-IP 9.4.2 Build 168.0
...................hdc.1-root: clean, 20800/386304 files, 41885/771737 blocks
........./dev/hdc1: clean, 216/1954560 files, 2096874/3907512 blocks
hdc.1-config: clean, 120/386304 files, 20638/771737 blocks
hdc.1-var: clean, 3620/2317440 files, 110466/4630424 blocks
hdc.1-usr: clean, 12507/386304 files, 115660/771737 blocks
............Using /lib/modules/2.4.21-9.4.2.166.0smp/kernel/drivers/net/lasthop.o
Warning: loading /lib/modules/2.4.21-9.4.2.166.0smp/kernel/drivers/net/lasthop.o <---
will taint the kernel: non-GPL license - Commercial <---
See http://www.tux.org/lkml/#export-tainted for information about tainted modules <---
Module lasthop loaded, with warnings <---
INIT: Entering runlevel: 3
............................................................
BIG-IP 9.4.2 Build 168.0
Kernel 2.4.21-9.4.2.166.0smp on an i686

The kernel-tainted error message is benign and will not affect operation of the system. This message indicates that any issues caused by the kernel module should be reported to the vendor rather than to the Linux kernel maintainers. For more information, refer to the Linux kernel mailing list FAQ.

Note: This message is not reported in 9.6.x or 10.x.

F5 Product Development is tracking this issue as CR82407.
