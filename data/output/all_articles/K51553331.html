Description
When the configuration is reloaded or initiate config sync, and config-sync fails with the below error message. 
Sync error on <DeviceName>: Load failed from </Common/PeerDeviceName> 01070734:3: Configuration error: Invalid create, modify, or delete for node_address objects in the root folder

You may encounter this error message under  /var/log/ltm file when running "tmsh load sys config verify" command. 

For example: Sync error on test1.lab.local: Load failed from </Common/LTM1.example.com> 01070734:3: Configuration error: Invalid create, modify, or delete for node_address objects in the root folder
In this error message, note the following:
<DeviceName> is the hostname (fqdn) of the BIG-IP device
</Common/PeerDeviceName> is the /partition/hostname(fqdn) of the peer device

Environment

  • BIG-IP
  • Config Synchronization 
  • Missing Node

Cause
This message occurs when 

  • A node was created in error and the node name is missing as a result
  • Sync between BIG-IP devices has been initiated

Recommended Actions

Update the node in question: 

  1. Deleting the incorrect node using tmsh command.
     # tmsh delete ltm node <node_name>
    Note: If that node is still needed, you can then recreate it by giving the correct node name. 

  2. Save the configutaion 
    # tmsh save sys config partitions all

  3. Reload the configuration once the node is deleted 
    # tmsh load sys config partitions all

  4. After the configuration is updated re-sync the configuration. 

Additional Information
The configuration in  /config/bigip.conf file looks as follows. 

Incorrect Syntax:

ltm node /<partition> { 
    address x.x.x.x
}
For example: 
ltm node /PartitionA {
    address 10.10.10.1
}
Correct Syntax:
ltm node /<partition>/NodeName> {
    address x.x.x.x
}
For Example: 
ltm node /PartitionA/10.10.10.1 {
    address 10.10.10.1
}
Note: <partition> - name of the partition where the node is part of <x.x.x.x> - IP address assigned to the node
