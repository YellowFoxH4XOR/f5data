Known Issue

Incremental configuration synchronization (ConfigSync) operations cause different pool member counts when comparing SNMP statistics for the ltmPoolMemberCnt object identifiers (OIDs) from various members of a device group.

The pool member count will be twice the amount for the devices that receive incremental ConfigSync updates.

Note: Incremental ConfigSync was introduced in BIG-IP 11.4.0 and is enabled by default.

This issue occurs when all of the following conditions are met:

  • You created a pool containing one or more pool members on a BIG-IP system in a device group.
  • You performed an incremental ConfigSync operation to other members in the device group.
  • The system gathered SNMP statistics for the ltmPoolMemberCnt OID.

Impact

SNMP statistics for the ltmPoolMemberCnt OIDs are inaccurate for some members of a device group.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SNMP statistics for the ltmPoolMemberCnt OIDs are inaccurate for some members of a device group.

Workaround

To work around this issue, you can either reload the configuration on the system that received an incremental ConfigSync or you can perform a full ConfigSync. To do so, perform one of the following procedures:

Performing an incremental ConfigSync and reloading the configuration

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

Note: You should perform this procedure on all BIG-IP systems that have received an updated configuration from the device group.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Reload the configuration by typing the following command:

    load sys config

Performing a full ConfigSync using the Overwrite Configuration option

Impact of workaround: The BIG-IP system may experience a performance impact when ConfigSync performs a full configuration synchronization of a large configuration.

Note: You should perform this procedure on the BIG-IP system that is syncing the updated configuration to the device group.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools.
  3. Create the new pool and add the necessary members.
  4. Navigate to Main > Device Management > Overview > Device Groups > device group name > Devices > device name (Self) > Overwrite Configuration (check).
  5. Synchronize the new pool to the device group.
