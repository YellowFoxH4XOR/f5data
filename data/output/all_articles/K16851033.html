Description

Unable to select certificate key while creating a new iApp

  • New iApp is being created.
  • The certificate and key have been imported successfully.
  • But the key doesn't show while creating the iApp.

Environment

  • BIG-IP with iApp.
  • The certificate key is password protected.

Cause

This is expected when the certificate key is password protected.

Recommended Actions

Follow either of the following steps to resolve the issue

  1. Create a new clientSSL profile with the certificate + password-protected key. Then call that profile while creating the iApp.
    (OR)
  2. Remove the password from the certificate key and re-import the key into BIG-IP. After this, the key should show up while creating the iApp.

Additional Information

Article K14912 can be referred to remove the password from the private key.
