Description

You are creating a new iRule and see logs similar to the one below in /var/log/ltm:

err tmm[<pid>]: 01220001:3: TCL error: <iRule name> <HTTP_REQUEST> - can't read "<variable>": no such variable while executing "<command>"

Environment

  • BIG-IP 
  • iRule
  • LTM logs

Cause

This error is logged whenever an iRule tries to test a variable that doesn't exist

Recommended Actions

Review iRule and modify it so that the tested variable is created before it is tested in all cases

Additional Information

None
