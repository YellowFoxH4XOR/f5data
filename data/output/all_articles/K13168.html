Topic

You should consider using this procedure under the following condition:

  • You want to disable optimization on WOM.

Description

WOM optimizes network traffic traversing the connection between two BIG-IP WOM devices. You can disable the optimization of applications or the local endpoint to aid in troubleshooting, testing of the optimization performance, or to permanently disable optimization.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • BIG-IP WOM configured with application optimizations.

Procedures

There are two methods presented below; choose the method that best fits your needs.

Disabling the Local Endpoint state

Disabling the local endpoint state is good for short term disabling of all the optimized applications of the local endpoint. You would use this for troubleshooting or testing optimization quality.

Impact of procedure: The State option does not disable the wom-tcp-lan-optimized and wom-tcp-wan-optimized profiles, causing WOM to continue to proxy all traffic passing through the system.

  1. Log in to the Configuration utility.
  2. Expand WAN Optimization.
  3. Click Local Endpoint.
  4. Clear the State Enabled checkbox.
  5. Click the Update button.

Disabling optimization by removing the optimization applications virtual servers

This procedure disables the optimized applications that are associated with the Local Endpoint. This is the preferred method of disabling optimization long term or permanently. It also allows disabling of individual application optimizations.

Impact of procedure: This procedure removes the virtual server associated with the Application optimization and will no longer optimize traffic for that application. You will have to recreate any application optimization to re-enable that optimization.

  1. Logon to the configuration utility
  2. Expand WAN Optimization
  3. Click Optimized Applications. A list of the optimization virtual servers is displayed
  4. Click the checkbox next to any optimization virtual server you wish to remove.
  5. Click the Delete button. The Confirm Delete? pane opens
  6. Click the Delete button.
