Description

If you are following the article K13309: Restricting access to the Configuration utility by source IP address and you are getting the following error from tmsh or bash:

  • When running from tmsh: modify /sys httpd allow { 10.10.10.2 }
    error: /sys: /sys:       
  • When running from bash: tmsh modify /sys httpd allow { 10.10.10.2 }
    /bin/bash: sys: No such file or directory

Environment

  • BIG-IP
  • Restricting access to the Configuration utility by source IP address

Cause

There is a 'cli alias shared /Common/modify' configuration line in the configuration file bigip_base.conf

Recommended Actions

  1. Edit the bigip_base.conf and comment out these lines:
    cli alias shared /Common/modify {
        command bash
    }
  2. Then do a tmsh load sys config and then attempt to set your lockdown.
