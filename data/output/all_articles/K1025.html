K1025: BIG-IP sends a reset when a connection limit is reached if reset on service down is enabled

Issue

In BIG-IP versions prior to 4.5.13 and 4.6.4, the BIG-IP system does not send a reset when a virtual server connection limit is reached. Beginning with BIG-IP versions 4.5.13, and 4.6.4, when the Enable Reset on Service Down setting is selected for the virtual server, the BIG-IP system sends a TCP reset when a virtual server connection limit or service connection limit is reached. If the Enable Reset on Service Down setting is not selected, the system silently discards the packet.

Note: For information about how BIG-IP version 9.x systems handle virtual server connection limits, refer to K5067: The BIG-IP sends a reset when a virtual server connection limit is reached.
