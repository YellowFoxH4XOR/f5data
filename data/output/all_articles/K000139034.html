Description

Big-IP LTM is sometimes seen to merge multiple received segments into one segment before sending it out on the wire, even on an ordinary TCP VS (which is often assumed to not change anything about a segment before forwarding it out).

 

Environment

Big-IP LTM

 

Cause

TSO/LSO (TCP Segmentation Offload/Large Send Offload, which is enabled by default on Big-IP) can merge multiple segments into one segment before sending it out on the wire by design, if the segments are received from TMM by the NIC very closely together in time.

 

Recommended Actions

None.

 

Additional Information

If this behaviour is causing a problem, then TSO/LSO can be disabled on the Big-IP by setting the value of the tm.tcpsegmentationoffload BigDB key to disable, and restarting the Traffic Management Microkernel (TMM). 

Impact: Disabling TSO will cause increased CPU usage on Big-IP, hence it is not recommended to use this configuration under normal circumstances. Additionally, restarting TMM temporarily interrupts traffic processing and devices configured as a high-availability pair may fail over.

Procedure:

  1. Log in to the BIG-IP command line.
  2. Disable TSO by typing the following command:

    tmsh modify sys db tm.tcpsegmentationoffload value disable

  3. Restart TMM by typing the following command:

    bigstart restart tmm
