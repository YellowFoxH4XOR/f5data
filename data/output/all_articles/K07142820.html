K07142820: [F5OS-C] Velos blade 1 Interface 1.1 is up but lacp status is LACP_DEFAULTED and no traffic going through

Type
Support Solution
Published
2022-09-28
Updated
2023-02-21
Applies to
  • VELOS Platforms
  • F5OS
  • F5OS-C: 1.5.X, 1.5.0
Source
https://my.f5.com/manage/s/article/K07142820

Description

After upgrading to F5OS-C 1.5.0, Blade1's interface lacp status stays LACP_DEFAULTED, even though the interface status is UP.
All egress traffic on interface 1/1.1 will be dropped by the system.

<partition># show interfaces
interfaces interface 1/1.1
 state type               ethernetCsmacd
 state mtu                9600
 state enabled            true
 state oper-status        UP
 ...
 state lacp_state         LACP_DEFAULTED

 

Environment

  • F5OS-C
  • v1.5.0
  • Velos
  • Partition with slot 1 (blade-1)
  • Interface 1.1
  • LACP
  • The port group for the interfaces in slot 1 are configured in 4 x 25GbE or 4 x 10GbE mode

Cause

  • Bug ID 1161761

Recommended Actions

  • Disable 1.1 on blade 1 and removing it from the LACP trunk.
