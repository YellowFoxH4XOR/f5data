Topic

This article provides an overview of Guided Configuration for BIG-IP APM and F5 Advanced Web Application Firewall (Advanced WAF), use cases, operational tasks, and basic troubleshooting.

Description

Beginning in BIG-IP 13.1.0.8, F5 introduced Guided Configuration in 3.0.0 to provide a way to deploy configurations for BIG-IP APM and Advanced WAF. Guided Configuration includes workflow-driven configuration templates based on iAppLX technology that you can use to deploy common use case scenarios. The following use case scenarios are available in Guided Configuration 7.0. More use cases will be added in future upgrades.

BIG-IP APM configuration templates
  • Federation: Federate user identify to enable single sign-on (SSO) to applications with BIG-IP APM as Identity Provider or Service Provider using the OAuth or SAML technologies.
  • Zero Trust: Deploy BIGP-IP APM as Identify Aware Proxy to create a policy providing secure access to public applications based on real time device posture, user identity, and step-up authentication.
  • Microsoft Integration: Integrate BIG-IP APM with Microsoft Azure AD to provide secure access to applications in the following scenarios: ADFS Proxy, Azure AD Application, and Exchange Proxy.
  • API Protection: Configure BIG-IP as an API Protection Proxy for securing API calls.
  • Credential Protection: Protect logon credentials, such as username and password, from potential man-in-the-browser attacks. To use this template you need to have a DataSafe license and FPS provisioned.

Advanced WAF configuration templates

  • Web Application Protection: Configure BIG-IP ASM in the following scenarios: Web Application Comprehensive Protection, and Traffic Security Policy.
  • API Security Protection: Configure the BIG-IP ASM security policy to protect your APIs.
  • DOS Protection: Quickly set up the BIG-IP Behavioral DoS profile to protect your application.
  • Bot Protection: Create BIG-IP Bot Protection that includes the Bot Defense profile and Bot microservices, providing verification and mitigation actions based on URL and host name for your BIG-IP virtual server.
Guided Configuration for BIG-IP APM and Advanced WAF
  • To download Guided Configuration, for BIG-IP APM and Advanced WAF, refer to K85454683: Upgrade F5 Guided Configuration on the BIG-IP system.
  • To navigate to Guided Configuration for BIG-IP APM and Advanced WAF on the Configuration utility, go to Access or Security > Configuration.

Guided Configuration for F5 SSL Orchestrator

  • Guided Configuration for SSL Orchestrator enables you to deploy configurations quickly in an array of topologies and requires you to license and provision SSL Orchestrator.
  • To download Guided Configuration for SSL Orchestrator, go to the F5 Downloads page and select Find a Download. From the Security section, select SSL Orchestrator.
  • To navigate to Guided Configuration for SSL Orchestrator, go to SSL Orchestrator > Configuration.

Troubleshooting

When troubleshooting issues with Guided Configuration, you should consider the following factors:
  • The Configuration utility provides you with a good overall view of the components created using Guided Configuration. From the Configuration utility, go to iApps > Application Services > Applications LX, and select the name of your application service. You can also identify configuration objects created using Guided Configuration in the /config/bigip.conf file. These objects contain the app-service tag. The following example details a virtual server created from a deployment named api-deployment:

ltm virtual /Common/api-deployment.app/api-deployment_vs {
    app-service /Common/api-deployment.app/api-deployment
    creation-time 2021-01-12:15:35:54
    destination /Common/10.10.10.5:443
[...]

  • By default, configuration objects created by Guided Configuration have strict updates, and the Manage Configuration setting is enabled and configured from the application management interface on the Configuration utility. When you need to disable strict updates, consider the following recommendations:
    • F5 recommends that you enable strict updates or the Manage Configuration setting.
    • Disabling Manage Configuration allows you to modify objects of the deployment outside of Guided Configuration. Go to Access or Security > Guided Configuration. Select the lock icon next to the deployment.
    • Changes that you make outside of Guided Configuration will be lost when you enable Manage Configuration for the same deployment later.
    • Display the status of strict updates for your deployment using the following command syntax:

      tmsh list sys application service <config-name>.app/<config-name> strict-updates disabled.

  • When troubleshooting, you should review the following log files:
    • /var/log/restjavad.0.log
    • /var/log/restnoded
    • /var/log/restjavad-gc.log.0.current
    • /var/log/restjavad-audit.0.log
    • /var/log/audit

  • Guided Configuration is based on iAppsLX technology and its operation is impacted by processes, such as the restjavad process. The memory required by the restjavad daemon may grow significantly in system configurations with either a high volume of device statistics collection (AVR provisioning), or with a relatively large number of BIG-IP LTM objects managed by the REST framework (SSL Orchestrator provisioning). If you experience timeout issues, the restjavad process may have CPU and memory issues, as logged in ID894593 or ID776393. You can troubleshoot by increasing the verbosity for the restjavad logs. For more information, refer to K15436: Configuring the verbosity for restjavad logs on the BIG-IP system. 

  • F5 recommends that you upgrade to the latest Guided Configuration version when it is available. However, you can only upgrade to one or two major versions later than your current version. For example, you can upgrade Guided Configuration 4.0 to 5.0 or 6.0, but you should not upgrade Guided Configuration 4.0 directly to 7.0. For more information about upgrading, refer to K85454683: Upgrade F5 Guided Configuration on the BIG-IP system.
