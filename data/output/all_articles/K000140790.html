K000140790: Disable password based authentication on F5OS system for root user

Type
Support Solution
Published
2024-08-27
Updated
2026-06-01
Source
https://my.f5.com/manage/s/article/K000140790

Description :

Disable password based authentication on F5OS system for root user.

Environment:

  • F5OS system.
  • A remote system.
  • SSH Public key authentication.
  • Password based authentication.

Cause :

You have both password and SSH public key based authentication enabled on your F5OS system. You would like to disable password based authentication and keep only SSH public key authentication for root user.

Recommended Actions:

  1. SSH to F5OS system using SSH public key authentication.
  2. On F5OS edit the “sshd_config” file using any editor of your choice and then change the configuration option as mentioned below.
    example: vi /etc/ssh/sshd_config
    PermitRootLogin prohibit-password
    PasswordAuthentication no
  3. Save and exit the file.
    example: to save the file press ‘esc’ key on your keyboard then type wq! then press ‘enter’ key.
  4. Verify, password based authentication by attempting to login to F5OS as as root, password authentication will no longer work. You should still be able to authenticate to F5OS system using SSH public key based authentication.

      note: The configuration edited sshd_config file directly will not be persisted after reboot.
