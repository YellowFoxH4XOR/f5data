Known Issue

This is the result of a known issue. The Statistics page for distributed applications only reports requests processed by one of the wide IPs within a distributed application. Statistics are not added to the total requests handled for the other wide IPs associated with the distributed application. As a result, it appears that only one wide IP processes all the requests, and the total statistics do not include the requests processed by the other wide IPs.

This issue occurs when all of the following conditions are met:

  • A distributed application is configured.
  • Multiple wide IPs are configured.
  • You are viewing distributed application statistics.

Impact

The system does not record statistics for requests to all wide IP members in the distributed application.

Note: For BIG-IP 12.0.0 and later, the system does not record statistics for requests to any wide IP members in the distributed application.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Statistics page for distributed applications reports requests processed by only one of the wide IPs within a distributed application.
  • The Statistics page for distributed applications does not report any requests processed by the wide IPs within a distributed application.
