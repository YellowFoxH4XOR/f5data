K8632: Network Access favorites do not function when using Pocket PC 2003 or earlier

Topic

The FirePass controller supports Network Access functionality for Windows PocketPC 2003 and earlier PDA-style devices through the F5 Networks SSL VPN Agent. When a PDA user logs into the FirePass controller, the user's webtop will display a link for Network Access. Clicking on the link will present a page from which the F5 Networks SSL VPN Agent can be downloaded and installed. Once installed, the F5 Networks SSL VPN Agent is configured with the IP address of the FirePass controller which will provide Network Access functionality. Additionally, the networks and resources to be tunneled over the SSL VPN are configured in the Windows PocketPC 2003 settings. Thereafter, whenever an application needs to send network traffic to a configured network or resource, the user runs the F5 Networks SSL VPN Agent to provide Network Access functionality.

Because the F5 Networks SSL VPN Agent provides the Network Access, normally a user who logs into the FirePass webtop with a PDA device will not use Network Access favorites listed under the Network Access section, even if the user's master group is configured with one or more Network Access favorites. Any Network Access favorites associated with the user's master group are for use only when the user is employing a full browser running on a non-PDA operating system. Network Access favorites do not invoke the F5 Networks SSL VPN Agent.
