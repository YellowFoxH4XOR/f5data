K67050204: Retrieve TLS Certificate Information Via iControl REST

Type
Support Solution
Published
2021-07-30
Updated
2023-02-21
Applies to
  • BIG-IP GTM
  • BIG-IP LTM: 16.X.X
Source
https://my.f5.com/manage/s/article/K67050204

Description

You need to retrieve certificate information from a traffic certificate that is not available through the certificate endpoint /mgmt/tm/sys/file/ssl-cert/<cert-name>.crt.

Environment

  • Administrative access through REST API

Cause

A limited set of properties is available through the iControl REST certificate endpoints.

Recommended Actions

Identify the cachePath of the certificate to determine where the file exists on disk then use the bash utility to cat the file.

Use the -hidden option to reveal the cachePath property of a certificate.

In this example, we will retrieve the default.crt.

  1. List the cachePath of the cert you are interested in:
    curl -sku admin:admin 'https://bigip.example.com/mgmt/tm/sys/file/ssl-cert/~Common~default.crt?options=-hidden&$select=cachePath' | jq -r .cachePath

    For Example:

    curl -sku admin:admin 'https://bigip.example.com/mgmt/tm/sys/file/ssl-cert/~Common~default.crt?options=-hidden&$select=cachePath' | jq -r .cachePath
    /config/filestore/files_d/Common_d/certificate_d/:Common:default.crt_29290_1

  2. Using the cachePath from Step 1, use the /mgmt/tm/util/bash endpoint to invoke the cat command and retrieve the certificate file:
    curl -sku admin:admin 'https://bigip.example.com/mgmt/tm/util/bash' -H "Content-Type: application/json" -X POST -d "{\"command\":\"run\",\"utilCmdArgs\":\" -c 'cat /config/filestore/files_d/Common_d/certificate_d/:Common:default.crt_29290_1'\"}" | jq -r .commandResult

    For Example:

    curl -sku admin:admin 'https://bigip.example.com/mgmt/tm/util/bash' -H "Content-Type: application/json" -X POST -d "{\"command\":\"run\",\"utilCmdArgs\":\" -c 'cat /config/filestore/files_d/Common_d/certificate_d/:Common:default.crt_29290_1'\"}" | jq -r .commandResult
