K39981662: DNS/GTM sync fails with DB validation exception

Type
Support Solution
Published
2025-10-03
Updated
2025-10-03
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.X, 17.1.2, 17.1.1, 17.1.0
  • BIG-IP GTM
Source
https://my.f5.com/manage/s/article/K39981662

Description

You are unable to load config or full sync from peer DNS/GTM.

  • Sync or config load fails with following error 
    01070734:3: Configuration error: DB validation exception, unique constraint violation on table (gtm_wideip_alias) object ID (1 /Common/www.example.com alias.example.com). A duplicate value was received for a non-primary key unique index field. DB exception text (Cannot update_indexes/checkpoint DB object, class:gtm_wideip_alias status:13)

Environment

  • The existing DNS/GTM sync group has a Wide-IP records with alias associated with it
  • The affected box has different Wide-IP but with the same alias associated with it 
    Existing DNS/GTM device
   gtm wideip a /Common/www.example.com {
     aliases {
         alias.example.com

Affected DNS box
   gtm wideip a /Common/www2.example.com {
       aliases {
         alias.example.com

Cause

The issue is causes by configuration validation failure due to a bug  ID 918693

Recommended Action

Delete conflicting Wide-IP alias on the target device
