Known Issue

This is the result of a known issue. When running the FirePass Components Troubleshooting Utility (CTU) on a Windows 7 client, the CTU may crash after selecting Network Access Diagnostics from the Tools menu. Additionally, if you select Remove Components from the Tools menu, the CTU may report an error message that appears similar to the following example:

Control is locked. Please, try to remove components after restart the system!

This error is message is erroneous and can be safely ignored.

Note: For more information about the CTU, refer to K9133: Overview of the FirePass Components Troubleshooting Utility.

F5 Product Development tracked this issue as ID 295749 (formerly CR131259) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

In addition, this issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
