K000146814: How do I skip Bot Defense and/or WAF for a trusted client?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
  • F5 Distributed Cloud Multi-Cloud App Connect
Source
https://my.f5.com/manage/s/article/K000146814

Description

  • You have F5® Distributed Cloud Bot Defense and/or a WAF implemented for your application, but you don't want those capabilities to affect your trusted clients
  • You would like to create a WAAP common allow list that bypasses these security checks

Environment

  • F5® Distributed Cloud WAF
  • F5® Distributed Cloud Load Balancer

Cause

None

Answer/Recommended Actions

To create a WAAP common allow list:

1. Open the load balancer configuration for your application.

  • In the F5® Distributed Cloud Console (Console), select the Multi-Cloud App Connect service
  • In the left navigation pane, select Manage->Load Balancers -> HTTP Load Balancers
  •  
  • From the Actions menu (... menu) for your load balancer, select Manage Configuration
  • In the upper right corner, select Edit Configuration

2. Edit the Trusted Client Rules

  • Scroll down to  the Common Security Controls section
  • In the Trusted Client Rules sub-section click Configure
  •  

3. Add a client rule that exempts your client from Bot Protection and WAF checks.

  • Click Add Item to add a client rule to the list
  •  
  • Enter a name for this rule and optionally enter a description
  • Identify the client.  There are three methods of identification:
    • IP Prefix
    •  
    • Autonomous System (AS) number
    •  
    • HTTP Headers - Identify trusted client by an HTTP header
      • Click Add Item to specify a header to match
      •  
      • Enter the header name
      • Select the method for matching the value:
        • Exact - the header value must match exactly
        • Regex - use a regular expression to specify a matching value
        • Presence - true if the header exists
      • Check NOT of match if you want to invert the selection
      • Click Add Item to save your Header to Match to your headers list
      •  
      • Use Add Item to create additional headers to match

4. Select your desired Action

  • Using the Action pull-down, select Skip WAF Processing, Skip Bot Defense Processing, or Skip Both

5. Optionally enter an Expiration Timestamp.

  • If you enter a timestamp, then this trusted client rule will expire on the specified date and time
  •   
  • The rule will continue to exist in an expired state, allowing you to return to the rule and simply update the timestamp

6. Save your changes.

  • Click the Apply at the bottom to save your Simple Client Src Rule to your list of trusted clients
  • Click Apply to save your Trusted Client Rules
  • Click Save and Exit to save the changes to your load balancer
