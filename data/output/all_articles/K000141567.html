Description

BIG-IP DNS are configured to listen to iQuery via ISP interface, and would like to restrict iQuery, SSH and Port 443 from accessed via External Public Internet access.

Environment

  • BIG-IP GTM
  • BIG-IP LTM
  • Restricting iQuery access from External Public Internet Access
  • Packet Filter
  • GUI

Cause

Guidance on how to Restrict Query access from External Public Internet access

Recommended Actions

Depending on your company security requirements, you may configure the Packet Filter "Unhandled Packet Action" to "Accept," "Discard," or "Reject" to control access to the BIG-IP TMM Interfaces.

  • Accept: Accept all traffic (Default)
  • Discard: Drop all traffic
  • Reject: Deny all traffic

After that you may configure Packet Filter Rules to control further on the received traffic on TMM interfaces. They are filter based on

  • Source IP
  • Destination IP
  • Protocol
  • Port number

Below steps is an example on enabling the Packet Filter with "Unhandled Packet Action" configure to "Accept". First browse to BIG-IP GUI >> Network >> Packet Filters >>

  1. General >> Packet Filtering: Enabled
    • Unhandled Packet Action: Accept
  2. Rules >> Create
    • Last rule to "Deny" all type of protocol from anywhere to anywhere access to BIG-IP GTM
      Notes: this rule are to be place at the bottom as a last rule and will deny access on any source IP and any protocol unless define on the rules above this last rule.

    • Followed by creating rules above the last deny rule to allow access based Source, Destination, Protocol and Port number to the BIG-IP GTM
      Notes: Allowing ICMP, iQuery port 4353, SSH port 22 to private network only and if HTTP port 80 and HTTPs port 443 for VS VIP access required for Internet public access.

    • Enabling the logging on the Packet Filter Rules when you need it for troubleshooting. The logs are store at "/var/log/pktfilter"

Notes: The way in creating the Packet Filter is entirely depending on what your environment required and the way you would like to design the Packet Filter to Accept, Deny and Discard the traffic hitting to the TMM interface.
