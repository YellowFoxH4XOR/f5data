Description

You may upload QKView, PCAP, Log files and other data to an open support case using the methods mentioned.

Environment

  • MyF5
  • Upload to Secure Files
  • iHealth
  • QKView
  • PCAP
  • Log file

Cause 

None.

Recommended Actions

  • Using MyF5 (Only for main contact of the case)

1) Sign in

2) Select "CASES" 

3) Select "CASE ID" 

4) Under "Secure Files", select "Upload to Secure Files" 

5) Select case number

6) Select "Incoming (upload to F5)"

7) Click upload button. (Green cloud icon)
 

  •  Using Secure Files
    • For main contact of the case: Sign in with MyF5 Username and Password.
    • For other contact of the case: Please refer to article K000138089: Security enhancements for F5 Secure Files
                                            
  •  Using iHealth (Only for uploading QKview)
         Please refer to the article K12878: Generating diagnostic data using the qkview utility
         Under section "Uploading a QKView file to F5 iHealth2"
         Note: Make sure to fill in the F5 Support Case Number (SR) 

Additional Information

None
