K000090477: BIG-IQ pool license Activation date not updated when reactivated

Type
Support Solution
Published
2021-10-12
Updated
2023-02-02
Status
Final
Source
https://my.f5.com/manage/s/article/K000090477

Description 

When reactivating a pool license or pool license offering managed by BIG-IQ, the Activation Date will not get updated. The Activation Date is the date the license or offering was first activated. This is the expected behavior. 

Environment 

  • BIG-IQ managing pool licenses 

Cause

None

Recommended Actions

None
