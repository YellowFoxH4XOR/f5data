Description
Getting "Bad Gateway" error while doing license reactivation when upgrading to later version.

Environment

  • License reactivation
  • Software upgrade

Cause
Internet connectivity issue.

Recommended Actions

Reactivate the license manually via the GUI by following the steps below.

      Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration.
      When licensing redundant BIG-IP systems, F5 recommends that you activate the license on  your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility.
  2. Select System > License and click Re-activate.
  3. Select Manual, then click Next.
  4. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  5. On the F5 Licensing Tools page, select Activate F5 product registration key for BIG-IP 9.x and later.
  6. Paste the dossier into the Enter Your Dossier box, and then select Next.

    The F5 Product Licensing page produces your license.

  7. Copy the license and paste it into the License box in the Configuration utility.
  8. Select Next and wait for the configuration to reload.

       Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration.

If the issue persists after doing the above steps, try to reactivate the license via CLI. Please refer to K2595: Activating and installing a license file from the command line
