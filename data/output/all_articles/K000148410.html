Description

You would like to enable the burst handling feature on BIG-IP systems installed with AS3 3.23 or later.The burst handling feature is supported beginning in AS3 3.23 and provides an alternative flow management when handling multiple AS3 declarations simultaneously. When the burst handling feature is enabled, AS3 queues the incoming requests and processes each declaration individually without rejecting subsequent requests.

Environment

  • BIG-IP
  • AS3

Cause

None

Recommended Actions

You can enable AS3 burst handling feature by sending a POST declaration to the shared/appsvcs/settings endpoint from the BIG-IP command line. To do so, perform the following procedure:

Impact of procedure: The suggested procedure alters the default AS3 declaration handling behavior. You should test any such changes in a staging environment or during a maintenance window with consideration to the possible impact on your specific environment.

Log in to the BIG-IP command line:

To verify the AS3 version, enter the following command:

curl http://localhost:8105/shared/appsvcs/info

To enable the burst handling feature, enter the following command:

curl -H "Content-Type: application/json" -X POST -d '{"burstHandlingEnabled": true}' http://localhost:8105/shared/appsvcs/settings

The output appears similar to the following example:

{"burstHandlingEnabled":true}

To verify if the burst handling feature is enabled, enter the following command:

curl http://localhost:8105/shared/appsvcs/settings

 

Alternative option using POST:

To enable burst handling, POST a simple declaration to the mgmt/shared/appsvcs/settings endpoint:

{
    "burstHandlingEnabled": true
}

BIG-IP AS3 should now be running with the burst handling feature enabled.

To check the current setting status, submit a GET request to that same endpoint.

 

Additional Information

The burst handling queue has a limit of 10. This limit is non-configurable and does not require any additional resources. GET requests are the only requests that do not go into the queue and wait to be processed; they are designed to bypass the queue. For more information, refer to F5 Application Services 3 Extension: Burst handling on Cloud Docs.
