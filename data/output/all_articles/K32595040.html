Description
You created an iRule to select pool members based on URI and used the syntax of "use pool <name>"

Environment

  •  BIG-IP LTM
  • iRule for pool member selection based on URI

Cause
Invalid iRule usage

Recommended Actions

Do not use the syntax of "use pool <name>" on version 12.x or later, instead use the correct syntax of "pool <name>"
K27803480: iRule for selecting a Pool or Pool-member based on HTTP Request URI contents.
 

  1. Create a new iRule similar to one of the two iRules below, depending on whether Pool or Pool-member selection is needed:
    Pool selection iRule example:
    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    when HTTP_REQUEST {
      if { [HTTP::uri] contains "*.css*" }{
        pool css_pool
      } elseif { [HTTP::uri] contains "*.jpg*" }{
        pool jpg_pool
      } else {
        pool html_pool
      }
    }
