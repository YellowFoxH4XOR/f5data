Issue

Error Message

Use of uninitialized value $ret_hostname in scalar chomp at /usr/local/share/perl5/F5/ServerLookup.pm line 41. No response from update server

Message Location

You may encounter this message in the following location:

  • The /var/log/webui.log file

Description

This message occurs when all of the following conditions are met:

  • You have not configured a DNS server in the BIG-IP system DNS Servers List. For more information, refer to K13205: Configuring the BIG-IP system to resolve DNS hostnames (11.x and later).
  • The BIG-IP system attempts to resolve callhome.f5.com, activate.f5.com, or api.f5.com using a local copy of the DNS root servers list (root.hint). 

Some BIG-IP features, such as software and attack signature updates, require DNS resolution for the callhome.f5.com, activiate.f5.com or api.f5.com host names. For more information, refer to K15000: Overview of the Automatic Update Check and Automatic Phone Home features and K8217: Managing BIG-IP ASM attack signatures.

Impact

The BIG-IP system may be unable to perform DNS host name lookups or recommended software updates.

Recommended Actions

To configure IP addresses instead of host names, refer to K15202: IP addresses for F5 hosted services.
