Known Issue

BIG-IP Edge Client may display text incorrectly on devices configured with a non-English language locale.

This issue occurs when the following condition is met:

  • BIG-IP Edge Client is installed on a device running the Windows operating system, and is configured with the French language locale.

Impact

BIG-IP Edge Client buttons and details may not correctly display French language text.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The displayed text for the BIG-IP Edge Client Montrer le Diagramme and Changer de Serveur buttons are not appropriately aligned within the buttons.
  • The displayed text for the BIG-IP Edge Client Connexion automatique button does not appropriately align within the button.
  • When viewing the BIG-IP Edge Client Détails de la connexion tab, the Connexion and Détails du Tunnel screens contain extraneous characters.
  • When viewing the BIG-IP Edge Client Statistiques tab, the screen contains extraneous characters.
  • When viewing the BIG-IP Edge Client Details tab, the Diagnostics section does not translate the Generate Report option to French.
