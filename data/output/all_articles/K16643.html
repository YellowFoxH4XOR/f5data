Known Issue

Installation of the Windows BIG-IP Edge Client may limit new user device access.

This issue occurs when all of the following conditions are met:

  • The BIG-IP Edge Client is installed on a device running the Windows 7 operating system.
  • A new user is created on the Windows device.
  • The new user attempts to log in to the device.

Impact

The user is unable to log in to the device.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The new user may observe error messages similar to the following example when attempting to log in to the device:

    The User Profile Service service failed the logon.

    User profile cannot be loaded.

Workaround

To work around this issue, you can remove the BIG-IP Edge Client configuration file client.f5c, allowing access for newly created users. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Windows device with administrator level privileges.
  2. Open the Windows Explorer application.
  3. Navigate to C:\Users\Default\AppData\Roaming\F5 Networks\VPN\.
  4. Locate the following file in the VPN directory.

    client.f5c

  5. Select the client.f5c file.
  6. Press Delete.
  7. To confirm deletion of the client.f5c file, click Yes.
