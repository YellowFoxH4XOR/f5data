Description
Is there a policy-template available for Outlook-2013 when creating an ASM policy.

Environment

  • BIGIP ASM
  • ASM Policy Creation 

Cause
None

Recommended Actions

Policy template is not named with the year/version for Microsoft exchange environments after Exchange-2010, however, there is an "OWA Exchange" policy template that is designed for later versions like Exchange-2013.

 

Also one of the non-application specific templates(Fundamental, comprehensive, and more) can be used with or without using the Policy Builder. Policy Builder builds the security policy when the learning mode is set to automatic and can make the changes in real time or as scheduled depends on configuration
