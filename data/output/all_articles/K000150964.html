Description

An address-list is a list of IP addresses. It can be managed via iControl REST API endpoint /mgmt/tm/net/address-list/ .

Environment

  • BIG-IP
  • iControl REST API

Cause

None

Recommended Actions

Below are some examples to manage address lists. 

Replace:

  • <username> with the appropriate administrative username
  • <password> with the appropriate administrative password
  • <big-ip address> with the BIG-IP management IP

To create an address list

# curl -sk -u <username>:<password> -X POST -H 'Content-Type: application/json' -d '{ "name":"my_list", "addresses":["10.10.10.10","10.10.10.20"] }' https://<big-ip address>/mgmt/tm/net/address-list | jq

{

 "kind": "tm:net:address-list:address-liststate",

 "name": "my_list",

 "partition": "Common",

 "fullPath": "/Common/my_list",

 "generation": 90,

 "selfLink": "https://<big-ip address>/mgmt/tm/net/address-list/~Common~my_list?ver=16.1.4",

 "addresses": [

  {

   "name": "10.10.10.10"

  },

  {

   "name": "10.10.10.20"

  }

 ]

}

To update an address list

# curl -sk -u <username>:<password> -X PATCH -H 'Content-Type: application/json' -d '{ "name":"my_list", "addresses":["10.10.10.30"] }' https://<big-ip address>/mgmt/tm/net/address-list/~Common~my_list | jq

{

 "kind": "tm:net:address-list:address-liststate",

 "name": "my_list",

 "partition": "Common",

 "fullPath": "/Common/my_list",

 "generation": 95,

 "selfLink": "https://<big-ip address>/mgmt/tm/net/address-list/~Common~my_list?ver=16.1.4",

 "addresses": [

  {

   "name": "10.10.10.30"

  }

 ]

}

To list address lists

# curl -sk -u <username>:<password> -X GET -H 'Content-Type: application/json' https://<big-ip address>/mgmt/tm/net/address-list | jq

{

 "kind": "tm:net:address-list:address-listcollectionstate",

 "selfLink": "https://<big-ip address>/mgmt/tm/net/address-list?ver=16.1.4",

 "items": [

  {

   "kind": "tm:net:address-list:address-liststate",

   "name": "my_list",

   "partition": "Common",

   "fullPath": "/Common/my_list",

   "generation": 95,

   "selfLink": "https://<big-ip address>/mgmt/tm/net/address-list/~Common~my_list?ver=16.1.4",

   "addresses": [

    {

     "name": "10.10.10.30"

    }

   ]

  }

 ]

}

To delete an address list

# curl -sk -u <username>:<password> -X DELETE -H 'Content-Type: application/json' https://<big-ip address>/mgmt/tm/net/address-list/~Common~my_list | jq

<no output>

Additional Information

"addresses" of an address list is not a subcollection and cannot be targeted directly with POST/PATCH (for adding/deleting/modifying addresses).
