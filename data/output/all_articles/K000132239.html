Description

This KB article gives an example of how to delete VPN f5cli client on debian-based linux distribution and on redhat-based linux distribution


Environment

  • APM
  • VPN Linux f5cli client
  • f5cli for debian linux_f5cli.x86_64.deb
  • f5cli for redhat linux_f5cli.x86_64.rpm


Cause

The procedure of how to delete VPN f5cli client


Recommended Actions

Redhat-based distribution procedure


1) verify the f5cli client package installed version. In the example, the version is 7221


[root@centos ~]# rpm -qa f5cli

f5cli-7221.2022.0411-1.x86_64


2) remove the f5cli package:


[root@centos ~]# rpm -e f5cli

F5 Linux CLI Edge Client Uninstalling...

Removing user configuration...

[root@centos ~]# 


3) verify that the f5cli package is removed:


[root@centos ~]# rpm -qa f5cli

[root@centos ~]# 


Debian-based distribution procedure


1) verify the f5cli client package installed version. In the example, the version is 7185


root@ubuntu:~# dpkg -l f5cli

Desired=Unknown/Install/Remove/Purge/Hold

| Status=Not/Inst/Conf-files/Unpacked/halF-conf/Half-inst/trig-aWait/Trig-pend

|/ Err?=(none)/Reinst-required (Status,Err: uppercase=bad)

||/ Name      Version     Architecture Description

+++-==============-================-============-=================================

ii f5cli     7185.2021.0108-1 amd64    Command Line VPN Client for Linux

root@ubuntu:~# 


2) remove the f5cli package:


root@ubuntu:~# dpkg -P f5cli

(Reading database ... 121256 files and directories currently installed.)

Removing f5cli (7185.2021.0108-1) ...

F5 Linux CLI Edge Client Uninstalling...

Removing user configuration...

Purging configuration files for f5cli (7185.2021.0108-1) ...

Removing user configuration...

dpkg: warning: while removing f5cli, directory '/usr/local/lib' not empty so not removed

dpkg: warning: while removing f5cli, directory '/usr/local/bin' not empty so not removed

root@ubuntu:~# 


3) verify that the f5cli package is removed:


root@ubuntu:~# dpkg -l f5cli

dpkg-query: no packages found matching f5cli

root@ubuntu:~#
