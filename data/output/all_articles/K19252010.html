Known Issue

If you restore a user configuration file (UCS) file, the system may not completely restore all object configuration details.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with any of the following objects:
    • Self IPs
    • Nodes
    • Pool Members
  • You restore a UCS file that contains some or all of the same objects, however the configured IP addresses are different from the running configuration.

Impact

The system may not overwrite the object IP address when you restore the UCS configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you restore the UCS file, when you view objects, the configured IP addresses may contain the configured pre-restoration IP addresses.
  • If you restore the UCS file a second time, the system sets the configured objects as defined in the UCS configuration.

Resolution

Status

F5 Product Development has assigned ID 556505 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can restore the UCS file a second time.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
