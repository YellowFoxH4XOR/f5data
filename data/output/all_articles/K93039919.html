K93039919: Error: coapi_query failed at /usr/local/lib/perl5/F5/COAPI.pm

Type
Support Solution
Published
2022-09-08
Updated
2022-12-28
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • VIPRION Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K93039919

Description

Unable to use switchboot command or tmsh reboot volume <location> command, an error similar to this appears
coapi_query failed at /usr/local/lib/perl5/F5/COAPI.pm line 215

Environment

  • BIG-IP
  • Multiple boot volumes

Cause

This could be due to multiple causes, some of the known issues are:

  • mcpd process is failing and TMOS commands are not working.
  • SELinux failure.
Note: The known issues need to be addressed with the F5 support team, this method must be used only to rollback to an existing and working boot location.

Recommended Actions

Note: Do not use this method unless you faced the error mentioned in this article, to set/change the default boot location follow the article K93414734: How to set the default boot volume location.
 
  1. See the current grub file and take note of the current default value (first line)
# grub_default -d
default=0 <==============!!!
  1. Confirm the current boot location name
# grub_default -c
HD1.1
  1. List the available boot locations
 # grub_default -l
HD1.1 active yes default yes title BIG-IP 16.1.2.2 Build 0.0.28
HD1.3 active no default no title BIG-IP 16.1.2.1 Build 0.0.10
  1. Change the boot location
# grub_default -b HD1.3 <=====!! Use the correct name
Note: If the system is part of a cluster you will receive a message warning and you need to synchronize grub change with the command grub_default -s
  1. Confirm grub file changed in line 1
# grub_default -d
default=1 <==============!!! This value should be different than the one listed in step 1
  1. Reboot the device
# reboot

Additional Information

None.
