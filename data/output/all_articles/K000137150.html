Description

APM reports display a blank page under : Access ›› Overview : Access Reports

Environment

  • BIG-IP APM
  • APM Report

Cause

Logging is not enabled or mysql DB has issue.

Recommended Actions

Follow the steps below to verify if the configuration for access reports are configured correctly and if the logs are stored in the mysql DB. 

  1. Check if the apm logs are generated in /var/log/apm,
    If there is none, check apm log setting attached to the access profile and verify if it's enabled true
    #tmsh list apm log-setting all-properties
    apm log-setting default-log-setting {
    access {
    general-log {
    app-service none
    enabled true <<=
    publisher sys-db-access-publisher
    type access[..]
  2. Check the publisher and verify if it's configured for local-db,
    sys log-config publisher sys-db-access-publisher {
      app-service none
      description none
      destinations {
        local-db { } <==
        local-syslog { }
      }
    }
  3. Check db keys for access and syslog and enabled,
    sys log-config publisher sys-db-access-publisher {
      app-service none
      description none
      destinations {
        local-db { } <==
        local-syslog { }
      }
    }
  4. Query log DB for sid
    eg: for sid 03750d1e

    /usr/bin/mysql --user=root --password=`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -c logdb
    MariaDB [logdb]>
    SELECT SQL_CALC_FOUND_ROWS `log_tid` `log_tid`,`log_seq` `log_seq`,`time_stamp` `time_stamp`,from_unixtime(time_stamp) `date_time`,`log_id` `log_id`,log_partition `partition`,`log_msg` `log_msg` FROM logdb.log_data FACT WHERE log_sid IN ('03750d1e') ORDER BY time_stamp ASC LIMIT 0,500;

    Or, to query last 100 entries

    SELECT SQL_CALC_FOUND_ROWS `log_tid` `log_tid`,`log_seq` `log_seq`,`time_stamp` `time_stamp`,from_unixtime(time_stamp) `date_time`,`log_id` `log_id`,log_partition `partition`,`log_msg` `log_msg` FROM logdb.log_data FACT WHERE log_sid REGEXP '[A-Fa-f0-9]{8}' AND log_sid != '00000000' ORDER BY time_stamp desc LIMIT 0,100;
