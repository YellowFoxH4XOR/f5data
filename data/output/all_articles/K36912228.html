Known Issue

Users cannot log in to the BIG-IP Configuration utility with a password that contains non-English characters.

This issue occurs when all of the following conditions are met:

  • A local or remote user account is granted access to the BIG-IP Configuration utility.
  • The user attempts to log in to the BIG-IP Configuration utility with a password that contains one or more non-English characters.

Impact

The affected user fails to log in to the BIG-IP Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The affected user fails to log in to the BIG-IP Configuration utility.
