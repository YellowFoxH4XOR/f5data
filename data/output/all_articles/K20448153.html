Topic

You should consider using these procedures under the following condition:

  • You want to view the following information about BIG-IP local traffic objects:
    • The hierarchical relationships between objects, such as virtual servers, pools, and iRules
    • The current status of objects on the system
    • Statistical information for objects on the system

Description

The Network Map page in the Configuration utility provides a hierarchical view of BIG-IP local traffic objects, such as virtual servers, pools, and iRules. It displays the status for each component and the relationships between components, and it provides additional component information on the accompanying panels.

Starting in BIG-IP 14.1.0, you can use the Network Map page for a variety or administrative tasks. You can view the status of the object, such as a pool member that may be marked offline, or view statistical information for the object, such as the current connection count for a virtual server. You can also view the relationship of one object to another, such as the parent-child relationship between a virtual server and a pool.

  • Accessing the Network Map
  • Viewing statistics for local traffic objects
  • Viewing local traffic objects by partition
  • Viewing local traffic objects by status or name
  • Viewing local traffic objects using the filter
  • Sorting local traffic objects using the advanced filter

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

Accessing the Network Map

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Network Map.
  3. Click a local traffic object, such as a virtual server, to display additional information about the object.

Viewing statistics for local traffic objects

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Network Map.
  3. Expand the local traffic object.
  4. The statistical information for the local traffic object displays.
  5. Click the Diagram tab to display a diagram for the object.

Viewing local traffic objects by partition

On the Network Map page, you can view local traffic objects for all partitions or an individual partition. When you view objects by choosing an individual partition, the objects from the Common partition also display.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Network Map.
  3. For Partition, click [All] or the name of an individual partition.

Viewing local traffic objects by status or name

When you view local traffic objects by name on the Network Map page, the objects are sorted alphabetically. When you view objects by status, the objects are sorted based on virtual server health monitor status, and objects marked down or disabled are displayed first. To view local traffic objects by name or status, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Network Map.
  3. View objects by sorting by name or status:
    • To view objects by name, for Sort by, click Name.
    • To view objects by status, for Sort by, click Status.

Viewing local traffic objects using the filter

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Network Map.
  3. For Filter, type the name or part of the name of the object.

    Sorting local traffic objects using the advanced filter

    Impact of procedure: Performing the following procedure should not have a negative impact on your system.

    1. Log in to the Configuration utility.
    2. Navigate to Local Traffic > Network Map.
    3. Click Advanced Filter.
    4. Choose filter options:
      • For Show list, click an object type to filter. For example, virtual servers.
      • Click a status. For example, offline.
      • For Search iRule definition, type part of an iRule definition. For example, HTTP_REQUEST.

        Note: To display, the iRule must be associated with a virtual server.
