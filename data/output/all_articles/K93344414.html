Topic

This article covers where to find disk error or disk failure log messages and disk status information on the BIG-IP system

Description

If you received an alert, notice a disk error or failure message in the LCD display, or suspect a disk issue on the BIG-IP system, you can investigate further by examining logs on the system and reviewing smartctl output.

Hard disk errors are logged to /var/log/kern.log similar to the following examples:

  • err kernel: ata4.00: failed command: READ DMA
  • err kernel: ata4.00: cmd c8/00:08:c7:49:a9/00:00:00:00:00/e4 tag 10 dma 4096 in
  • err kernel: res 51/40:00:c9:49:a9/00:00:04:00:00/e4 Emask 0x9 (media error)
  • err kernel: ata4.00: status: { DRDY ERR }
  • err kernel: ata4.00: error: { UNC }
  • warning kernel: Descriptor sense data with sense descriptors (in hex):
  • err kernel: end_request: I/O error, dev sda, sector 78203337

The disk monitoring process, smartd logs messages similar to the following examples to /var/log/daemon.log:

  • crit smartd[4644]: Device: /dev/sda, 25 Currently unreadable (pending) sectors
  • crit smartd[6300]: Device: /dev/sda [SAT], 3 Offline uncorrectable sectors
  • crit smartd[3474]: Device: /dev/sda, FAILED SMART self-check. BACK UP DATA NOW!

For instructions about how to review BIG-IP log files, refer to K16197: Reviewing BIG-IP log files

Displaying hard disk status information using the smartctl utility

You can use the smartctl utilty to display SMART error logs, self-test history, and disk health information.

Note: While you can use the smartctl utility to run a self test, F5 recommends that you use the End-User Diagnostics (EUD) utility to run the test. For more information, refer to the Recommended Actions section in this article.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line
  2. To display the hard disk names type the following command:

    fdisk -l

  3. Use one of the follow command syntaxes to display disk health information:

    To display all sections of the SMART output, use the following command syntax:

    smartctl -a /dev/<sda|sdb|hda|hdc>

    To display only the SMART overall health section, use the following command syntax:

    smartctl -H /dev/<sda|sdb|hda|hdc>

    To display only the SMART disk error section, use the following command syntax:

    smartctl -l error /dev/<sda|sdb|hda|hdc>

    To display only the SMART self-test log, use the following command syntax:

    smartctl -l selftest /dev/<sda|sdb|hda|hdc>

    For example, to display all sections of SMART output for the /dev/sda disk, run the following command:

    smartctl -a /dev/sda

Environment

  • Hard disk error or imminent failure warning
  • Hard disk
  • BIG-IP hardware platform

Cause

Hard disk error or failure

Recommended Actions

If you suspect a possible disk failure, you can perform the EUD SMART test to test the drive. For information about the EUD utility and links to the latest release notes, refer to K7172: Overview of the End User Diagnostics software.
