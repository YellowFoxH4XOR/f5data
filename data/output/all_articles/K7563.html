Known Issue

This is the result of a known issue. The BIG-IP ASM system may cause 20-second delays when it checks negative regular expressions for certain HTTP requests. For example, if the request is an HTTP POST with a large parameter value, the delay can be up to 20 seconds.

F5 Product Development tracked this issue as CR68392, and it was fixed in BIG-IP ASM 9.3.1 and 9.4.1. For information about upgrading, refer to the BIG-IP ASM release notes.
