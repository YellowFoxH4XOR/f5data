Known Issue

This is the result of a known issue. The BIG-IP system allows you to create a local user account with a username containing 33 characters or more. When you attempt to log in to the BIG-IP system with the username using the serial console, the system generates an error message that appears similar to the following:

Serial console

BIGpipe parsing error:
01070827:3: User login disallowed: User
(user_name_longer_than_33_characters) is not an administrator, does not have a UID of zero, and has not been assigned a role on a partition.

In addition, if the user account allows terminal access to the bigpipe shell and you attempt to log in using SSH, the system generates an error message that appears similar to the following:

SSH

BIGpipe parsing error:
012e0038:3: Mismatched remote (user_name_longer_than_33_characters)
and local user (user_name_longer_than_33_characters10.1.1.1)
Connection to 10.1.1.1 closed.


F5 Product Development tracked this issue as ID 250964 (formerly CR79938), and starting in BIG-IP version 10.1.0 the system does not permit usernames longer than 32 characters.

For information about upgrading, refer to the BIG-IP release notes.
