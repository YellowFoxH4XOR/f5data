Known Issue

The Link Traffic statistics in the BIG-IP Link Controller Configuration utility may display incorrect information.

This issue occurs when the following condition is met:

  • A Wide IP is configured.

Impact

Some Link Statistics data will be unavailable.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • On the Overview > Statistics > Link Statistics page, the Statistics Type of Wide IP Members will display erroneous information such as Virtual Server, Node, and Pool Member names in the Alternate and Preferred columns, instead of the numeric values that should be displayed in these columns.

Workaround

To work around this issue, you can view statistics using TMSH. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. You can display Wide IP statistics by using the following command syntax:

    show gtm wideip <wide IP name> all

    In the command syntax, <wide IP name> represents the name of the Wide IP you want to display.

For additional details on the TMSH wideip command, refer to the Traffic Management Shell (tmsh) Reference Guide
