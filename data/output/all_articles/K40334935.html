Description

Before an upgrade, when license re-activation is required, its noticed that even after re-activating the license service check date on license is not updated to latest date and shows old date. However 'Licensed on' date is updated successfully. 
In such scenario if upgrade was performed, it may result in configuration load failure with similar error as below:
01070582:3: Monitor rules are not licensed: /Common/tcp and /Common/http.
Unexpected Error: Validating configuration process failed.


Environment

  • License was re-activated before an upgrade 
  • Service check date fails to update
     

Cause

Issue due to incorrect base registration key of the license. 
If the service check date is missing or is earlier than the license check date, the system will fail to load the configuration when you attempt to boot into the upgraded boot location.
 

Recommended Actions

  1. Find the Base registration key from bigip.license file using below command:
    grep Reg /config/bigip.license
     
  2. Verify with F5 support if the Base registration key against the device serial number is same as the one from bigip.license file. (Contact your sales professional to get correct license details)
     
  3. If Base registration key in bigip.license file is incorrect then re-activate the license again using correct base registration key.
     
  4. Go to System > License > Re-activate > click on 'edit' option for Base Registration Key > Replace the Registration Key with correct registration key >  Select Next and follow the instructions.
