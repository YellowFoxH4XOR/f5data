Known Issue

This is the result off a known issue. Under normal conditions, the BIG-IP WebAccelerator pvac process inserts HTTP headers into a memory file, and creates a pointer to their location for later reference. However, when memory runs low, the write process may fail but report a successful write operation and return an invalid pointer. When the pvac process attempts to reference the data at the invalid pointer, pvac dumps core and restarts.

F5 Networks Product development tracked this issue as CR138911, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
