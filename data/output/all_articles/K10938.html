Known Issue

This is the result of a known issue. The DNS/WINS servers configured in Network Access will not work for users connecting with a 64-bit Windows operating system. The ipconfig /all command output will show that the PPP adapter proxy that is created after connecting to Network Access does not have the following three fields populated:

  • Connection-specific DNS Suffix
  • DNS Servers
  • Primary WINS Sserver

As a result, users are unable to connect to any resource that requires DNS resolution through a Network Access connection.

F5 Product Development tracked this issue as CR133879 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue was fixed in cumulative hotfix HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
