Topic

When making configuration changes, some changes will require a services or controller restart. Restarting the services or controller will impact active users.

For a list of frequently used configurations that require a restart, refer to the following table:

Note: When planning configuration changes, you should make these changes after peak usage hours to minimize the impact to your users.
