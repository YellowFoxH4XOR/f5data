Description

This article explains why vulnerability assessment (VA) tools may flag the PostgreSQL version bundled with BIG-IP as unsupported or vulnerable, clarifies the security implications for BIG-IP LTM systems, and outlines supported upgrade options. It also provides guidance on interpreting VA scan results and addresses common questions about direct PostgreSQL upgrades within BIG-IP.

Environment

  • Product: BIG-IP
  • Versions: 17.5.1.3 (and all 17.x, 21.x releases)
  • Bundled PostgreSQL version: 15.0
  • VA tools reporting unsupported/vulnerable PostgreSQL versions

Cause

Vulnerability scanners often report the bundled PostgreSQL version as unsupported or vulnerable based solely on its detected version, without considering F5’s restricted access model. In BIG-IP, PostgreSQL is only accessible locally by the root user and is not exposed externally, so known CVEs are not exploitable.

Recommended Actions

  • No action is required for flagged vulnerabilities in supported BIG-IP versions (17.5.1.3 and later); there is no exploitable risk due to local-only access.
  • Direct upgrades of only the PostgreSQL component on the BIG-IP are not supported; updates occur exclusively through official BIG-IP software releases.
  • If your VA scan references a path outside of BIG-IP (e.g., /opt/vmware/vpostgres/13/bin/postgres/), the findings may pertain to another product such as VMware.
  • Monitor F5 security advisories for future updates or new CVEs affecting bundled components.
  • If you have specific CVE numbers from your VA report that are not covered here, review F5 documentation or contact F5 Support for further analysis.

Additional Information

  • The bundled PostgreSQL database in BIG-IP is accessible only via localhost by root; there is no external exposure or attack vector.
  • Exploitation of known CVEs would require root privileges; exploitation tools are not used in the standard environment.
  • All component upgrades—including PostgreSQL—are handled through full BIG-IP software releases; customer-driven standalone upgrades are not supported.
  • "Unsupported version" findings from VA scans are common false positives in this context.
