Description

The following error appeared under the ltm log:

warning promptstatusd[]: 01460005:4: Failed to open /proc/<PID>/status﻿

Environment

  • BIG IP VE

Cause

File system got Read only partition.
Running mount command shows the File System got partitions in Read-Only (ro), similar to the following output:
 

/dev/mapper/vg--db--sda-set.1.root on / type ext4 (ro,noatime,seclabel,discard,data=ordered)
/dev/mapper/vg--db--sda-set.1._var on /var type ext4 (ro,noexec,noatime,seclabel,discard,data=ordered)
/dev/mapper/vg--db--sda-set.1._var on /var/named/lib type ext4 (ro,noatime,seclabel,discard,data=ordered)

 

Recommended Actions

  • Rebooting the device should fix the issue.

Note: In most cases it is recommended to add memory too

Additional Information

In cases other modules provisioned - it can shows another indication the issue is with Read-Only.
i.e.:  In case ASM provisioned, ASM log shows critical message saying it is read-only:

crit g_server_rpc_handler_async.pl[1162]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::LockFactory::Base::lock): F5::ASMConfig::Handler Line 3758: Could not open /ts/lock/asm_config_server_async_for_859.lock: Read-only file system

The above is another indication for us this is a read-only issue.
