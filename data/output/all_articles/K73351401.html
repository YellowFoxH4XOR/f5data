K73351401: BIG-IQ VE 8.1.0 Stats collection failing after BIGIQ upgrade from 7.0.0.1 to 8.1.0.1

Type
Support Solution
Published
2021-11-15
Updated
2025-02-07
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K73351401

Description
After upgrading from 7.x or 8.0.x to 8.1.0.1, statistic data is no longer being updated from the BIG-IPs. The avrd process on the BIG-IP will fail authentication to the DCD that is it sending data to. Statistics will not show for these devices in the monitoring tab. 

/var/log/avr/avrd.log on BIG-IPs will show the following message:

EXTERNAL_MESSAGES|WARNING|Nov 12 19:11:11.831|26534|lib/avrpublisher/infrastructure/avr_http_connection.cpp:0283| Bad status code : 401. Reconnecting...
 

Environment

  • BIG-IQ managing BIG-IPs with statistics collection enabled

Cause
Defect ID1040833. 
This is fixed in 8.1.0.2

Recommended Actions
Perform the following for each affected BIG-IP

  1. Re-discover the BIG-IP
  2. Re-import the services for each module on the BIG-IP
