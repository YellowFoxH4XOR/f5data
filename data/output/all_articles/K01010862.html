K01010862: Private ip is not reassigned after failover in AWS - failover initialization failed: environment information has not been provided

Type
Support Solution
Published
2021-12-13
Updated
2023-06-04
Applies to
  • Public Cloud
  • BIG-IP
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K01010862

Description

  • Public IP is not moving from primary to secondary during failover
  • In /var/log/restnoded/restnoded.log you will see the following error message:
    failover initialization failed: environment information has not been provided

Environment

  • AWS
  • BIG-IP in HA

Cause

Unknown.

Recommended Actions

1. You have to make sure that you are using the CORRECT f5cloud_failover_label on your BIG-IP. You can check your 'f5cloud_failover_label' in AWS hypervisor and then on your BIG-IP use the following curl to update failover settings:
 

curl -sk -u admin: -d '{"class":"Cloud_Failover","environment":"aws","controls":{"class":"Controls","logLevel":"silly"},"externalStorage":{"scopingTags":{"f5cloud_failover_label":"SOME_LABEL"}},"failoverAddresses"{"enabled":true,"scopingTags":{"f5_cloud_failover_label":"SOME_LABEL"},"requireScopingTags”:true},”failoverRoutes":{"enabled":false,"routeGroupDefinitions":[{"scopingName":"rtb-00000000000000000","scopingAddressRanges":[{"range":"X.X.X.X/24"}],"defaultNextHopAddresses":{"discoveryType":"static","items":["Y.Y.Y.Y”,”Z.Z.Z.Z”]}}]}}’ -H "Content-Type: application/json" -X POST http://localhost:8100/mgmt/shared/cloud-failover/declare

2. On BIG-IP run:

bigstart restart restjavad
bigstart restart restnoded
