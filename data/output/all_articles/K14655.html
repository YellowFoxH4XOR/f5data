F5 Technical Support can help resolve issues more quickly when you provide a full description of the issue and the details of your configuration. To help you gather all the required information, use the following guidelines to prepare for opening a support case:

Site Parent ID

F5 Technical Support requires that you provide the Parent ID for your site when opening a Traffix SDC support case. F5 sent a letter to Traffix SDC customers with the Parent ID information. If you do not have the Parent ID, contact F5 Technical Support for assistance.

General information

Provide the following information when you open a case with F5 Technical Support:

  • A full description of the issue, including the following:
     
    • The symptoms of the issue
    • The approximate time the issue first occurred
    • The number of times the issue has recurred
    • Any error output provided by the Traffix Signaling Delivery Controller (SDC)
    • Steps to reproduce the issue
    • Any changes you made to the Traffix SDC before the issue first occurred
    • Any steps you have taken in an attempt to resolve the issue
  • A description of the impact the issue is having on your system and site, using the following definitions:
     
    • Site Down

      All network traffic has ceased, causing a critical impact to your business.

    • Site at Risk

      Primary unit has failed, resulting in no redundancy. Site is at risk of going down.

    • Performance Severely Degraded

      Network traffic is partially functional, causing some applications to be unreachable.

    • Performance Impaired

      Your network or application is suffering from reduced performance, but otherwise continues to work as expected.

    • General Assistance Required

      You have questions regarding configurations. You need assistance troubleshooting non-critical issues, or are requesting product functionality that is not part of the current product feature set.

  • The hours that you are available to work on the issue with an F5 Technical Support Representative, and in the event you are unavailable, any alternative individuals to contact who are aware of the issue.
  • Remote access information, if possible.

    Note: Remote access to your network environment is important, because it is the most effective method for collecting information and troubleshooting technical issues. If you cannot provide remote access information, F5 Technical Support will work directly with you to resolve the issue over the phone; however, this method can often be more time consuming and may require file transfers, replication, and additional testing.

Product-specific information

When you open the case with F5 Technical Support, provide the following information (if appropriate for your issue):

  • The Traffix SDC version information

    When  F5 Technical Support receives the Traffix SDC version information, they give you the appropriate Traffix Configuration and Log Data Collection (tta_log_collector) script. You must run this script on the Traffix SDC in question, collect the configuration and the log files, and provide these items to F5 Technical Support for analysis.

  • A packet trace capturing the issue (if the issue involves the network).

For information about sending this information to F5, refer to K000090853: Exchange files with F5 Support using MyF5.
