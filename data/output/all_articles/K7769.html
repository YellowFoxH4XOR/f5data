Topic

Flow parameter names and values are defined in the BIG-IP ASM security policy and represent elements in the web application. The BIG-IP ASM searches for flow parameters in HTTP request data, or query strings. Whether a parameter is contained within the HTTP POST request body, or in the HTTP GET request query string, the BIG-IP ASM interprets the parameter structure in the same manner.

The BIG-IP ASM interprets the flow parameter structure in HTTP requests using the following logic:

  • The BIG-IP ASM interprets the flow parameter structure of GET requests starting from the first character in the query string following the question mark (?) character, and from any subsequent non-encoded and (&) character following the question mark (?) character.

  • The BIG-IP ASM interprets the flow parameter structure of POST requests starting from the first character in the POST body or from any subsequent non-encoded question mark (?) symbol.

  • Any character up to the first non-encoded equal sign (=) is the parameter name.

  • Any character from the equal sign (=) character and up to the first non-encoded and (&) character or end of line is the value.

For example, the following GET requests illustrate how the BIG-IP ASM interprets flow parameters in a request:

The following GET request contains two parameters; the a parameter has a value of 1 and the b=dc parameter has a value of 2:

GET /test.asp?a=1&b%3dc=2

The following GET request contains two parameters; the a parameter has a value of 1&2 and the b parameter has a value of 3:

GET /test.asp?a=1%262&b=3
