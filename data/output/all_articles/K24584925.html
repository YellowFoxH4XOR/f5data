Known Issue

The Virtual Clustered Multiprocessing (vCMP) host may overwrite the interface statistics table with data from vCMP guests.

This issue occurs when the following conditions are met:

  • Your BIG-IP system has the vCMP module provisioned.
  • A vCMP guest virtual server processes Secure Sockets Layer (SSL) traffic.

Impact

The merged process produces a core file and restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The merged process produces a core file and restarts.
  • The system logs an error message to the /var/log/kern.log file that appears similar to the following example:

    info kernel: [72751.993418] merged[10178]: segfault at ff52ef8c ip 0000000008073278 sp 00000000ff52ef90 error 6 in merged[8048000+5b000]
