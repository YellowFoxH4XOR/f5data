Topic

This articles applies to BIG-IP platforms i11800-DS, i11600-DS, and i11400-DS with the Cavium Nitrox V crypto hardware.

Description

On BIG-IP systems with Nitrox III crypto hardware, you can control the way the Virtual Clustered Multiprocessing (vCMP) hypervisor allocates high-performance SSL hardware resources to vCMP guests. In Dedicated mode, the system allocates a fixed amount of SSL hardware resources to a vCMP guest for full dedicated use. The rest of the resources are shared between all vCMP guests. The platforms allocate SSL resources according to the configured SSL mode settings for each vCMP guest.

In the Nitrox V crypto hardware implementation, the SSL resources are divided into two groups of shared resources. In the first group, all SSL resources are shared for all the vCMP guests that are configured in Shared mode. In the second group, a fixed number of SSL resources are allocated per vCMP guest that is configured in Dedicated mode. The platforms with Nitrox V crypto hardware provide the highest performance Elliptic Curve Cryptography (ECC) offload to the hardware. These platforms also support providing guaranteed SSL performance to a vCMP guest, with efficient SSL resource dedication between guests.

Recommendations

When you configure the SSL mode for a vCMP guest, consider the following factors:

  • F5 recommends that you configure vCMP guests in SSL Dedicated mode if you require a guaranteed level of SSL performance.
  • F5 recommends that you increase the vCPU count for the configured guest if there is a resource issue with the SSL Dedicated mode vCMP guest.
  • Configure SSL Shared mode for your vCMP guest if you have fewer vCMP guests configured, and the resources are not heavily utilized. This allows all guests to use the shared SSL resource pool, which can result in higher overall performance.
  • You can use the Configuration utility to configure SSL modes for Nitrox V-based platforms by navigating to vCMP > Guest List and clicking the name of your vCMP guest, to select the desired mode. The modes are Shared, Dedicated and None.
  • To view the list of Nitrox V devices in the BIG-IP platforms, type the following command:

    tmsh /show sys hardware

  • To view the high availability (HA) state of the Nitrox V device, type the following command:

    tmsh /show sys ha-status

    Note: The HA state of the Nitrox V device is indicated by crypto-failsafe in the TMOS Shell (tmsh) output.
