Description

BIG-IP device is self-rebooted. Following logs are noted in BIG-IP device

var/log/ltm

err logger[24122]: shutting down for system shutdown on behalf of root <<<<<<<<
err logger[20543]: shutting down for system shutdown on behalf of root <<<<<<<<

var/log/daemon

warning systemd[1]: Failed to propagate agent release message: Transport endpoint is not connected
warning systemd[1]: Failed to propagate agent release message: Transport endpoint is not connected
warning systemd[1]: Failed to propagate agent release message: Transport endpoint is not connected
notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.2 Build 0.0.249 ]===---
 

 

Environment

BIG-IP Virtual edition

Cause

BIG-IP logs indicates 'shutting down for system shutdown on behalf of root'  as shown above, it means that BIG-IP device was manually rebooted, either from the BIG-IP console or from the hypervisor.

If no reboot command issued on the BIG-IP device, this means that the device is rebooted from the hypervisor at that time,

These logs indicate there is an issue with hypervisor. Hypervisor causes the device with high I/O, prior to the reboot. Hence the BIG-IP device is self rebooted.

High memory utilization on the BIG-IP VE could also cause the BIG-IP to self reboot with the same logs displayed.

Recommended Actions

Review the hypervisor logs to see why the hypervisor initiated a shutdown of the BIG-IP VE instance.

After the first reboot, if services could not come up reboot the device device one more time.
