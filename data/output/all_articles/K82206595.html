K82206595: Error Message: AD module: change password for 'ad_user' failed: Password change rejected(4), result_string: (4)

Type
Support Solution
Published
2023-03-20
Updated
2024-09-27
Source
https://my.f5.com/manage/s/article/K82206595

Description

You are facing a problem with AD Change Password in Access Policy Logon Forms and the password change getting rejected by AD server.

Users are trying to change their password but was being rejected with the following logs visible:

err apmd[8102]: 01490107:3: /Common/example_access_policy:Common:9397e9e8: AD module: change password for 'john_smith' failed: Password change rejected(4), result_string:   (4)
debug apmd[8102]: 01490111:7: /Common/example_access_policy:Common:9397e9e8: AD module: krb5_chg_password(): Password change rejected(4), result_string:
debug apmd[8102]: 01490024:7: /Common/example_access_policy:Common:9397e9e8: AD module: LEAVE Function chgUserPassword
info apmd[8102]: 01490077:6: /Common/example_access_policy:Common:9397e9e8: AD agent: Auth (logon attempt:1): failed to change password for 'john_smith'

Environment

  • Active Directory authentication

  • GPO rules limiting password change frequency

  • Password Change via APM Access Policy

Cause

Active Directory is not allowing for the password to be changed more than once in a 24-hour period

Recommended Actions

Disabling minimum password age requirement on AD server should resolve the issue:
Windows Server 2012 (and R2) >> Minimum password age
