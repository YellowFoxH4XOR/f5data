Description

After creating additional views in Zonerunner you may experience the following error message:

01150b21:3: RCODE returned from query: 'REFUSED'." when viewing a zone

Environment

  • BIG-IP DNS
  • ZoneRunner
  • Views
  • Zones

Cause

Issue can be caused by incorrect ACL configuration. We cannot use the same ACL for multiple views:

view "external" {
    match-clients {
        "zrd-acl-000-000";      <------ same ACL
    };
    zone "a.example.com." {
        type master;
        file "db.external.a.example.com.";
        allow-update {
            localhost;
        };
    };
};
view "internal" {
    match-clients {
        "zrd-acl-000-000";      <------ same ACL
    };
    zone "b.example.com." {
        type master;
        file "db.internal.b.example.com.";
        allow-update {
            localhost;
        };
    };
};

Recommended Actions

  1. Create a new ACL under the named configuration.

    For example:

    acl "zrd-acl-000-001" {
        127.10.0.1;
    };
  2. Reconfigure one of the views to use the new ACL.

    For example:

    Reconfigure internal view, replace "zrd-acl-000-000" with "zrd-acl-000-001" under match-clients section.
