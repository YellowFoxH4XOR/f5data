Known Issue

You cannot upgrade a BIG-IP Link Controller system that contains DNS namespace iRule commands.

This issue occurs when all of the following conditions are met:

  • You attempt to upgrade a BIG-IP Link Controller system from a version prior to 11.5.x to 11.5.4 or later.
  • The BIG-IP Link Controller system contains DNS namespace iRule commands.

Impact

You cannot add DNS namespace commands to an iRule. You cannot upgrade from a pre-11.5 configuration, where the commands were working, to 11.5.4 through 12.1.2.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP Link Controller system base license improperly prevents DNS namespace iRule commands and prevents the upgrade from occurring.

Workaround

To work around this issue and enable the upgrade, remove any DNS namespace commands from the configuration before you perform the upgrade.
