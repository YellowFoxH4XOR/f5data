Known Issue

This is the result of a known issue. A multipart POST request is commonly used when a web form requires both binary and text data to be uploaded to the web server. The BIG-IP ASM may drop large HTTP POST requests containing more than 500 multipart chunks. This can occur because the BIG-IP ASM multipart parser has an array that statically holds the multipart chunk descriptors. The BIG-IP ASM process will crash when it receives more than 500 multipart chunks.

F5 Product Development tracked this issue as CR76823 and it was fixed in BIG-IP ASM 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP ASM Release Notes.
