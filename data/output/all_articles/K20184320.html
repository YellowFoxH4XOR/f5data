Description
 

Etag value is presented to the end user in HTTP response.

Environment

  • APM
  • VPN

Cause

You want to hide ETag value that is presented to the end user in HTTP response:

------
GET /abc.ico HTTP/1.1
Host: example.org
Connection: keep-alive
sec-ch-ua: "Google Chrome";v="105", "Not)A;Brand";v="8", "Chromium";v="105"
[...]
----
----
HTTP/1.1 200 OK
Server: BigIP
Last-Modified: Fri, 01 Jan 2000 00:01:02 GMT
ETag: "12a-34bcd56789e10"
Accept-Ranges: bytes
Content-Type: image/x-icon
[...]
----

Recommended Actions

The following iRule should clear the Etag: 
### START
when HTTP_REQUEST {
   set remove_etag 0
   if { [string tolower [HTTP::host]] == "example.org" } {
      set remove_etag 1
   }
}
when HTTP_RESPONSE_RELEASE {
   if { [info exists remove_etag] && $remove_etag == 1 } {
      if { [HTTP::header exists "ETag"] } {
         HTTP::header remove "ETag"
      }
   }
}
### END


Please test the iRule before using it in a production environment
