Description

You can prevent Illegal meta character false positives for XML payloads by overriding the metacharacter in an XML profile.

Example:
Violation Details
Illegal meta character in value

Context       Actual URL
/mytesturl
XML ProfileDefault
XML Element ValueR2AAXB – 802H – ME8M – 8pLd – 1A2FCM9S021
Applied Blocking SettingsBlock Alarm Learn

Environment

  • Legitimate requests trigger Illegal meta character violations for XML payloads.
  • You want to prevent false positives by allowing meta character in an XML profile.

Cause

None

Recommended Actions

You can have the system check for allowed or disallowed meta characters based on the content of a request as defined in content profiles XML. In addition, you can override the security policy settings so that the system avoids checking for metacharacters in particular content.
 
Overriding a metacharacter with an XML profile
  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Content Profiles and click a content profile type XML
  3. Select the name of the security policy you want to update in Current edited security policy.
  4. Click the Meta Characters tab
  5. Select  Check element value characters to check meta characters in XML elements, and select Check attribute value characters to check meta characters in XML attributes.
  6. In the Global Security Policy Settings list, review the meta characters that are assigned to the security policy, and which are allowed or disallowed in the content profile.
  7. From the Global Security Policy Settings list, move any meta characters that you want to override for this content profile into the Overridden Security Policy Settings list.
  8. Set the meta character to Allow or Disallow in the overridden settings list
  9. Click Update 
  10. Click Apply Policy to apply the changes
