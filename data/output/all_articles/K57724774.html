Description

You have large number of ACLs to modify and a very large number of ACEs to modify.

For example, you may want to update your ACLs ACEs if you have exhausted the lease-pool and are planning to add additional networks to the lease-pool (by extending the subnet range or changing to source network any).

Environment

  • APM with a large number of ACLs and ACEs

Cause
None
 

Recommended Actions

You can update the ACLs and ACEs using the following procedure.

Note: The following procedure uses an example of changing a 192.168.84.0/24 subnet to a new 0.0.0.0/0 (any) subnet. You will need to replace these subnet IP addresses with your desired subnet IP addresses. 
  1. Check the number of ACLs 
    # tmsh list apm acl | grep 'apm acl' | wc -l
  2. Check the number of ACE entries to be changed 
    # tmsh list apm acl | grep 'src-subnet 192.168.1.0\/24' | wc -l
  3. Capture the ACLs to a file 
    # tmsh list apm acl > /var/tmp/acls-unmodified.txt
  4. Verify the captured file 
    # grep 'apm acl' /var/tmp/acls-unmodified.txt | wc -l 
# grep 'src-subnet 192.168.1.0\/24' /var/tmp/acls-unmodified.txt | wc -l
  5. Copy the file for editing 
    # cp /var/tmp/acls-unmodified.txt /var/tmp/acls-modified.txt
  6. Stream edit the file to replace the 192.168.84.0/24 subnet with the new subnet 0.0.0.0/0 (any) 
    # sed -i 's/src-subnet 192.168.1.0\/24/src-subnet 0.0.0.0\/0/g' /var/tmp/acls-modified.txt
  7. Verify the modified file 
    # grep 'apm acl' /var/tmp/acls-modified.txt | wc -l 
# grep 'src-subnet 192.168.1.0\/24' /var/tmp/acls-modified.txt | wc -l
  8. Merge in the modified ACL entries 
    # tmsh load sys config merge file /var/tmp/acls-modified.txt
  9. verify the changes 
    # tmsh list apm acl | grep 'apm acl' | wc -l 
# tmsh list apm acl | grep 'src-subnet 192.168.1.0\/24' | wc -l
