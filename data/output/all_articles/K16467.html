Known Issue

The Configuration utility does not display DNS Express zone statistics.

This issue occurs when all of the following conditions are met:

  • You have configured a DNS Express zone on the BIG-IP system.
  • You navigate to the DNS > Zones > Zones > Statistics page in the Configuration utility.

Impact

You are unable to view statistics for DNS Express zones using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you navigate to the DNS > Zones > Zones > Statistics page in the Configuration utility, you view an error message that appears similar to the following example:

    An error has occurred while trying to process your request.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to view the statistics for DNS Express zones. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Viewing DNS Express zone statistics using the tmsh utility

  1. Log in to the tmsh utility by typing the following command:

    tmsh
  2. View the DNS Express zone statistics by using the following command syntax:

    show ltm dns <name>

    For example, to view the statistics for a DNS Express zone named dnsxzone, you would type the following command:

    show ltm dns dnsxzone
