K20132060: Threat Campaign updates fail

Type
Support Solution
Published
2022-10-31
Updated
2025-12-04
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K20132060

Description
Threat Campaigns are not updating properly.

Environment
  • Advanced WAF
  • Threat Campaigns configured

Cause
The process handling "threat campaign" exceeds max allowed memory size.

Recommended Actions

  1. Take backup of /etc/ts/tools/asm_config_server.cfg:

cp /etc/ts/tools/asm_config_server.cfg /var/tmp/asm_config_server.cfg.orig
  2. Increase allowed memory to Threat Campaign:

    In file /etc/ts/tools/asm_config_server.cfg change:
MaxMemorySize=<value>

    In this example,
MaxMemorySize=471859200
to
MaxMemorySize=1073741824
  3. Restart ASM:
    bigstart restart asm
