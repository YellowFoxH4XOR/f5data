Description

The incremental-config-sync-cache is not cleared after config sync. The cache entries are added every time there are new pending changes to sync.

Environment

BIG-IP

Cause

Expected behavior.

Recommended Actions

This is an expected behavior and not a bug.

Successful incremental sync does not empty the incremental config sync cache. Mcpd keeps track of changes based on commit ID, and it's not a problem at all when the cache is left after incremental sync.

Full config sync does flush the cache.

tmsh run cm config-sync force-full-load-push to-group <device-group>

It is possible to manually flush it. However, the next sync will fallback to full load when mcpd cannot find what it expects in the cache.

tmsh modify cm device-group <device-group> clear-incremental-config-sync-cache
