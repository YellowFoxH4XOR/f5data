Known Issue

This is the result of a known issue. Attack signatures are rules that identify attack sequences or classes of attacks on a web application and its components. When the BIG-IP ASM receives a request that triggers an attack signature, the signature appears in the Configuration utility under the Learning > Violations page. However, the Attack Signature Staging violation disappears after a few minutes, preventing a user from verifying whether the request was a false positive.

F5 Product Development tracked this issue as CR94619 and it was fixed in BIG-IP ASM 9.4.5. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, Hotfix-BIG-IP-9.4.4-HF1 has been issued for BIG-IP ASM 9.4.4. You may download this hotfix or later versions of the hotfix from the Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
