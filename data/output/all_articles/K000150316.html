Description

When using tmsh create or modify you are unable to use wilcard configuration identifiers and you receive an error "Syntax Error: the "create" command does not accept wildcard configuration identifiers"

 

First example:

# tmsh create ltm data-group internal my-internal-dg type string

# tmsh modify ltm data-group internal my-internal-dg records add { "*.example.com" { data "example" } }

Syntax Error: the "create" command does not accept wildcard configuration identifiers

Second example:

# tmsh modify sys url-db url-category Religion urls add { https://www.example.com/* }

Syntax Error: the "create" command does not accept wildcard configuration identifiers

Environment

BIG-IP LTM

BIG-IP APM

BIG-IP SSLO

 

Cause

Expected behavior

 

Recommended Actions

You need to escape the wildcard identifier and use a glob match type for example:

# tmsh create ltm data-group internal mydg type string

# tmsh modify ltm data-group internal mydg records add { "\*.example.com" { data "example" } }

# tmsh list ltm data-group internal mydg

ltm data-group internal mydg {
records {
\*.example.com {
data example
}
}
type string
}
# tmsh modify sys url-db url-category Security urls add { "https://www.example.com/\*" { type glob-match } }

# tmsh list sys url-db url-category Security

sys url-db url-category Security {
cat-id 0
cat-number 126
description "Parent category that contains categories considered to present security risks."
display-name Security
f5-id 16458
is-recategory true
urls {
https://www.example.com/\* {
type glob-match
}
}
}
