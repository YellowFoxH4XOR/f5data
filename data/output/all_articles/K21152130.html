Known Issue

Updating a user-defined violation in a security policy may fail.

This issue occurs when all of the following conditions are met:

  • You create a security policy with a user-defined violation.
  • You attempt to modify the violation title from lowercase to uppercase or the other way around, using the Configuration utility or by manually editing an exported security policy file and re-importing it.

Impact

The modification fails and the violation title remains unchanged.  Attempts to import the modified security policy fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Importing a security policy with a modified custom violation title fails with an error message similar to the following example:

    01310027:2: ASM subsystem error (asm_config_server.pl,F5::ImportExportPolicy::Base::fatal_error): User-defined violation could not be added: Failed validating value 'Custom_Violation_Title' for Title: The value 'Custom_Violation_Title' already exists, while the field is a unique field.

  • Modifying the title of a custom violation fails with an error message similar to the following example:

    Violation update failed; Error: Could not update the Violation 'violation_name'. Failed validating value 'Custom_Violation_Title' for Title: The value 'Custom_Violation_Title' already exists, while the field is a unique field.

Workaround

To work around this issue, you can modify the violation using an alternative title, then rename the violation back to the previous title using the correct capitalization. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > Violations List.
  3. Click the User-Defined Violations tab to see the list of custom violations.
  4. Click the violation to edit.
  5. In the Violation Title box, type the alternative title. For example, if the current title is violation_title and you want to change it to Violation_Title, type something like temp_title.
  6. Click Update.
  7. Click the violation again.
  8. Type the previous title using the correct capitalization in the Violation Title field.  From the previous example, you would type Violation_Title.
  9. Click Update.
