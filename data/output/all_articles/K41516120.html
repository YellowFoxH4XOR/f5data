Description

After a BIG-IP software upgrade when the configuration is loaded, a banner will appear at the top of the Configuration utility with the following error:

This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device

Environment

  • BIG-IP
  • Software upgrade
  • Modules have not been properly provisioned.
  • You need to navigate to System > Resource Provisioning to verify if all the modules are provisioned.

Cause

During the upgrade process, the device was not properly provisioned.

Recommended Actions

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window. Reprovisioning involves restarting system processes and rebooting. These actions interrupt traffic. Additionally, when the BIG-IP system is in a device group, it fails over to the next available member.

To resolve the issue, all the correct modules must be provisioned.

  1. Navigate to System > Resource Provisioning.
  2. Select all the modules which were provisioned in the previous software version.
  3. Choose the correct provision level (Dedicated, Nominal, or Minimum) from the drop down option.
  4. If the device is part of a device group, you can verify what module and level it was provisioned from a peer DSC device. 
  5. Click Submit.
