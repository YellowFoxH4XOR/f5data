K000146835: Can I extract with a regex the 2nd to the last entry on the header "x-forwarded-for"?

What Happened?

You want to extract with a regex from the 2nd to the last of the entries on the header "x-forwarded-for"

Environment

  • HTTP Load Balancer
  • Service Policies

Resolution/Answer

No, this is not supported. The regex is applied to all the entries in the XFF header, and it's treated as a string, not as an index.

Example

It's certainly possible to write a regex that happens to match the 3rd element in a specific list of IPs set in XFF. For example, if I write a rule with a regex that matches c.c.c.c, but not a.a.a.a, or b.b.b.b and if the XFF header contains a.a.a.a,b.b.b.b,c.c.c.c, we will match the 3rd element in the list.

However, if you want it to ONLY match if c.c.c.c is in the 3rd position (index), then, it should NOT match on c.c.c.c,a.a.a.a,b.b.b.b.
