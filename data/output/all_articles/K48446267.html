Description

  • GTM shows LTM errors that GTM objects can't be found (WideIP, GTM pools, etc)
  • You see the following error message within the LTM logs: 
    localhost err mcpd[7597]: 01020036:3: The requested gtm wideip (/Common/exampl.wip) was not found.

Environment

Relevant environmental factors specific to the topic

  • If the GTM is connected to Enterprise Manager (EM) and has Stats collection enabled.

Cause

If you have Enterprise Manager connected to a GTM that is running version 12.x +, and statistics collection is enabled. It must be disabled for the GTM, to stop logging the error messages.

Recommended Actions

The following workaround can be performed on the EM to disable data collection as shown below:
  1. Create custom profile for each GTM object with "Collect Data" disabled (uncheck).
    Statistics ›› Managed Devices : Global Traffic Profiles : Pool Member Profiles
    Statistics ›› Managed Devices : Global Traffic Profiles : Pool Profiles
    Statistics ›› Managed Devices : Global Traffic Profiles : Wideip Profiles
     
  2. Apply created profile from Enterprise Management ›› Devices : Device List ›› Statistics : Configure : <DEVICE NAME>
    Statistics Profile - Object Type - Global Traffic Pool Member and associate profile to all Pool Member Name
    Statistics Profile - Object Type - Global Traffic Pool and associate profile to all Pool Name
    Statistics Profile - Object Type - Global Traffic Wide IP and associate profile to all Wide IP Name
     
  3. Or you can simply remove the DNS from EM.
