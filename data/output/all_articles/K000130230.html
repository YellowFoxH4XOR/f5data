K000130230: How to check the total number of signatures that have 'block' enabled in a asm policy

Type
Support Solution
Published
2022-12-19
Updated
2022-12-30
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.1
Source
https://my.f5.com/manage/s/article/K000130230

Description


The article describes how to calculate the total number of signatures having Block enabled for specific security policy, regardless of the enforcement mode ( Transparent/Blocking ).

Environment

  • Attack Signatures

Cause

None.


Recommended Actions

In 14.x and prior versions, refer to the following method.
 

  1. Browse to Security > Application Security > Attack Signatures
  2. Click the 'show filter details
  3. Select 'Block' to yes. A list if signature with Block enabled are displayed.

Note: This method is not available for version 15.x and later.

From version 15.x, the following method is used.
 

  1. Get the ID of the policy you want to check
# curl -sku <username:password> https://<BIG-IP hostname or management IP address>/mgmt/tm/asm/policies?\$select=name,id | jq '.'

For example:
[root@www:Active:In Sync] config # curl -sku admin:admin https://localhost/mgmt/tm/asm/policies?\$select=name,id | jq '.'

  1. Once you have the policy ID, run below command to get the total number of signatures that have enabled 'block' setting.
# curl -sku admin:admin https://x.x.x.x/mgmt/tm/asm/policies/ApdguzoQ8wOrL5jDOD2GkA/signatures?$expand=signatureReference\&\$filter=inPolicy+eq+true+and+block+eq+true | jq -r '.items[].block' | wc -l
  1. If you want to see all signatures that are in blocking state, use below command:

# curl -sku admin:admin https://x.x.x.x/mgmt/tm/asm/policies/ApdguzoQ8wOrL5jDOD2GkA/signatures?$expand=signatureReference\&\$filter=inPolicy+eq+true+and+block+eq+true | jq . | more
