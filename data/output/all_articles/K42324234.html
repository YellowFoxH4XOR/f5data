K42324234: Qualys security scan threat QID 11827 detected for /my.policy and /my.logout

Applies to

Source

Description

Qualys scan is complaining that X-Frame-Options, X-XSS-Protection, and X-Content-Type-Options headers are missing from the /my.policy and /my.logout pages.

Environment

  • APM Provisioned
  • Qualys scan

Cause
/my.policy and /my.logout does not insert by default the CSP headers. If your security infrastructure requires them to be inserted, you can achieve this by using an iRule.

Recommended Actions

Deploy an iRule on to insert the required headers to the sites that you want to. For APM you can use this function in CLIENT_ACCEPTED:
https://clouddocs.f5.com/cli/tmsh-reference/v14/modules/ltm/ltm_rule_command_ACCESS_restrict_irule_events.html
