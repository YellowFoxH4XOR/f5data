Description

A custom bot signature does not trigger on the search string even though the search string appears in the "User Agent" header or URI.

Environment

The following conditions are present

  • Custom bot signature in Bot Defense profile
  • Bot defense profile is applied to a virtual server
  • Traffic with the bot search string present in either the "User Agent" header or URI

Cause

The bot defense profile has a buffer with a 255 character limit to store the "User Agent" or URI string, anything beyond 255 characters is truncated. If the search string occurs outside the limit, it will not get matched. The bot will be classified as "unknown" and the default action (block or allow) for unknown bots will be enforced.

Recommended Actions

Set the custom bot signature to search for a string that occurs within the first 255 characters.
