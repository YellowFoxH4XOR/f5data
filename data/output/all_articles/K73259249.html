Description

The BIG-IP system analyzes the mirrored traffic, drops it, and then sends the resulting analytics data and log messages to a remote analytics and logging server.

Environment

  • Passive Mode 
  • Traffic Monitoring
  • Remote analytics and Logging server

Cause

This is a new feature integrated into BIG-IP v13 and above where  interfaces can be configured to passive mode.

Recommended Actions

 To verify using CLI if passive mode is enabled.

# tmsh list net interface 1.3
net interface 1.3 {
    if-index 80
    mac-address 00:00:5E:00:53:00
    media-active 10000T-FD
    media-fixed 10000T-FD
    media-max auto
    mtu 9198
    port-fwd-mode passive <--------!!!!!!!!!
}

'port-fwd-mode' settings  are automatically propagated on vlan configuration objects associated with the passive interface.

# tmsh list net vlan
net vlan test {
    fwd-mode passive <--------!!!!!!!!!
    if-index 176
    interfaces {
        1.3 { }
    }

To verify and configure passive mode using GUI, follow the below document.

Manual Chapter : Configuring the BIG-IP System for Passive Monitoring
