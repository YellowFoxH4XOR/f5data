Topic

A static parameter is a parameter that has a final list of 20 or fewer values. Parameters that have more than 20 values should be considered dynamic or user-input parameters.

When a parameter is defined as a static content value, and the value in the request is not contained in the Parameter Static Values list, the BIG-IP ASM logs the following violation to the Reporting screen in the Configuration utility and to the /var/log/asm file:

Illegal static parameter value
