K74265345: Error Message: ''error: There were critical errors in package %post scripts Terminal error: Failed to install. *** Live install end at YYYY/MM/DD HH:MM:SS: failed (return code 255) ***'' during a BIG-IP software upgrade

Type
Support Solution
Published
2021-10-07
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 13.1.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.X.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K74265345

Description
During a BIG-IP software upgrade, installing a new software image in a new partition is failing with an error message

In /var/log/liveinstall.log, logs similar to the one below can be seen:

error: There were critical errors in package %post scripts
info: capture: status 0 returned by command: cat /mnt/tm_install/29208.lj3jNq/log.post.critical.error
info: >++++ result:
info: critical failure; f5-selinux-policy
info: >----
error: Package installation failed.
Terminal error: Failed to install.
*** Live install end at YYYY/MM/DD HH:MM:SS: failed (return code 255) ***

Environment

  • BIG-IP running 13.1.x
  • upgrading a BIG-IP device to a newer software version

Cause
Unknown at the time of publication

Recommended Actions

  1. Delete the failed partition
  2. Reboot the device
  3. Try installing the image again
