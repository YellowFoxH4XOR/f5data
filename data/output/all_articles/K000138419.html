Description

Whilst trying to license from BIG-IQ utility or pool license you get the following warning / error message
Error on server request The system returned an unexpected error (400 Bad Request). Device at X.X.X.X is not reachable. Please ensure that you've entered the correct IP address and restjavad services on the device are running

Environment

  • BIG-IQ
  • BIG-IP

Cause

The error is caused if the BIG-IQ is not able to connect to the BIG-IP on port 443 and establish communication.
You will need to do basic network checks as detailed below and possible work with the network team.

 Recommended Actions

  1. From the BIG-IQ command line, ping the IP address of the BIG-IP
  2. From the command line do a telnet on port 443 to the BIG-IP IP address
  3. Work with your network team to ensure BIG-IP is reachable
  4. iF THE big-ip is not reachable consider the solution mentioned under Additional information.
