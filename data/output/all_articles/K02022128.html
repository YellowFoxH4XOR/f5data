K02022128: PostgreSQL monitor does not support scram-sha-256 Password Authentication method

Type
Support Solution
Published
2023-06-15
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K02022128

Description

PostgreSQL monitor fails health check with the error below
[DBPinger-189] - SQL Exception:
org.postgresql.util.PSQLException: The authentication type 10 is not supported. Check that you have configured the pg_hba.conf file to include the client's IP address or subnet, and that it is using an authentication scheme supported by the driver.

Environment

  • BIG-IP LTM
  • PostgreSQL Monitor
  • Back end server uses 'SCRAM-SHA-256' Password Authentication method

Cause

  • PostgreSQL monitor on the BIG-IP uses the java library JDBC version 9.3
  • Support for SCRAM was added in version 42.2

Recommended Actions

  • Use a different monitor if the server only supports "scram-sha-256"
