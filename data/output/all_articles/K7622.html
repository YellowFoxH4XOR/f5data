K7622: Cache Cleaner closes all tabs in Microsoft Internet Explorer 7 after logging out

Topic

If the Cache Cleaner function is enabled and you access the FirePass controller with Microsoft Internet Explorer 7 (IE7), the Cache Cleaner function may attempt to close all tabs in your browser when you log out. This issue occurs when you configure your browser to open pop-up messages in a new tab. The default setting for IE7 is to open pop-up messages in a new window.

Note: The Cache Cleaner function can be enabled in the FirePass Administrative Console by selecting the Inject ActiveX/Plugin to clean-up client browser web cache check box on the Users : EndPoint Security : Post-Logon Actions page.

Note: FirePass versions 5.5.2 and 6.0.0 require a hotfix in order to support IE7. For information about FirePass support for IE7, refer to K6740: Support for Internet Explorer 7.

Workaround

You can work around this issue by configuring IE7 to open pop-up messages in a new window. For information about configuring this setting, refer to your Microsoft Internet Explorer documentation.
