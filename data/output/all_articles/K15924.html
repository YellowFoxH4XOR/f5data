Known Issue

Deletion of a network firewall rule using the BIG-IP Configuration utility may cause a change to all other rules that contain a specific port number.

Impact

The affected network firewall rules with a specific port number configuration will no longer function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 iHealth lists Heuristic H497610 on the Diagnostics > Identified > High screen.
  • All other network firewall rules that contain a specific port number will change to Any.
          
    For example:

       Source                                           Destination
       User    Address/Region    Port    VLAN/Tunnel    Address/Region    Port    Protocol    iRule    Action
    1. Any     Any               Any     Any            Any               80      6                    Accept
    2. Any     Any               Any     Any            Any               53      17                   Accept
    3. Any     Any               Any     Any            Any               Any     Any                  Reject

    If rule 3 is deleted, rules 1 and 2 change to Any for the Port setting and appear similar to following example:

       Source                                           Destination
       User    Address/Region    Port    VLAN/Tunnel    Address/Region    Port    Protocol    iRule    Action
    1. Any     Any               Any     Any            Any               Any     6                    Accept
    2. Any     Any               Any     Any            Any               Any     17                   Accept

    You can observe from the previous example that port numbers 80 and 53 changed to Any after rule 3 was deleted.

Workaround

To work around this issue, you can either use the Traffic Management Shell (tmsh), iControl, or BIG-IQ to manage firewall rules.

Alternatively, you can avoid the issue by using a port list instead of specifying a port number. A port list can include a list that contains only a single port. The port list is not affected by this issue.
