Known Issue

This is the result of a known issue. Under rare conditions, the BIG-IP ASM bd process may crash if the Attack Signature configuration is modified while the system is updating the security policy.

When the Attack Signature configuration is modified while the policy is processing traffic, the BIG-IP ASM bd process may attempt to read the changes from a location that no longer exists. If this occurs, the BIG-IP ASM process experiences a failure and exits.

F5 Product Development tracked this issue as CR99724, and it was fixed in BIG-IP ASM version 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.

In addition, this issue is fixed in hotfix BIGIP-9.4.4-94.0-HF3 issued for BIG-IP version 9.4.4, and in hotfix BIGIP-9.4.5-HF2 issued for BIG-IP version 9.4.5. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
