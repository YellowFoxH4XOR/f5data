Known Issue

During a rarely encountered client-side challenge parsing issue, the BIG-IP ASM bd process may produce a core file.

This issue occurs when all of the following conditions are met:

  • You are using the Web Scraping detection feature.
  • A challenge response is sent to the browser client.

Impact

The BIG-IP ASM bd process may produce a core file, and temporarily fail to pass traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM bd process may temporarily fail to pass traffic.
  • The BIG-IP ASM bd process produces a core file, and in the /var/core/ directory, creates files with names similar to the following example :

    bd_bld473_0_core_7328.gz
