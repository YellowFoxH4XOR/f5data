Description

When the need arises to perform a platform migration that involves SSL Orchestrator, currently, there is no established procedure to perform that action.

Environment

  • SSL Orchestrator
  • Performing Migration

    Note: This applies to all platforms; hardware, cloud, or virtual.

Cause

  • The configuration for SSLO is not created nor does it function as other F5 Modules.
  • SSLO creates a JSON file that uses REST calls to create TMM objects to perform the functions needed for SSLO to process traffic.
    • Other modules do this all within TMM.

Recommended Actions

  • A platform migration involving SSLO must be done via a fresh install.
  • We strongly suggested upgrading to the latest version at the time of migration.
