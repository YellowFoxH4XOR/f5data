Error Message

Sep 3 02:29:50 BIGIP notice logger[<PID>]: /usr/bin/syscalld  ==> /usr/bin/bigstart restart tomcat

In this error message, note the following:

    <PID> is the process ID for the logger process reporting the symptom.

Message Location

You may encounter this message in the following location:

    The /var/log/ltm file
 

Environment

    BIG-IP GUI

 
Cause

The BIG-IP GUI (running under Apache Tomcat) has a failsafe mechanism, which restarts itself when the Java VM environment servicing the BIG-IP GUI is detecting an out of memory condition.

In /var/log/tomcat/catalina.out, the following log messages may also be visible:

#
# java.lang.OutOfMemoryError: Java heap space
# -XX:OnOutOfMemoryError="/usr/bin/restart_tomcat"
#   Executing /bin/sh -c "/usr/bin/restart_tomcat"...
Sep 3 02:29:59 UTC 2020: START... [Ljava.lang.String;@3c855e
Sep 3 02:29:59 UTC 2020: Calling command 1 with args: " restart tomcat"
 
Recommended Actions

If the error messages only occur no more frequently than a few times a week, it is harmless.  If it's occurring several times a day, for further troubleshooting, please refer to the following article:

K9719: Error Message: java.lang.OutOfMemoryError
