K000141306: APM - SAML fails with error "SAML assertion is invalid, error: Audience should match entity-id of BIG-IP (as SP)"

Type
Support Solution
Published
2024-10-01
Updated
2024-10-02
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000141306

Description

  • SAML authentication failure
  • Symptoms
  • You observe the following error in /var/log/apm:

<bigip_hostname> err apmd[16313]: 0149020a:3: <access_policy_name>:<session_ID>: SAML Agent: <access_policy_name>_act_saml_auth_ag SAML assertion is invalid, error: Audience should match entity-id of BIG-IP (as SP)

 

Environment

  • APM
  • APM as SP
  • SAML

Cause

This occurs when the Entity ID in the SAML Assertion does not match the Entity ID configured in the APM SP Connector.

Recommended Actions

Modify the Entity ID in the external IdP so that it matches the APM SP Connector.

 

Additional Information

None
