Description

GTM configuration changes are not synchronized to all members in the Sync Group.

/var/log/gtm

notice gtmd[14344]: 011a001c:5: SYNC_ZONES from < IP>  skipped. Reason: sync_zones currently running from ip < IP >

The command tmsh show cm device-group indicated that one member did not have the same Commit Time and the Last Successful Sync ID.

Environment

  • BIG-IP GTM
  • BIG-IP DNS

Cause

Multiple configuration changes  made at the same time to different members of the Sync Group.

Recommended Actions

  • Make configuration changes on one BIG-IP DNS and let those changes sync to the group.
  • Verify iQuery is a full mesh state with all GTM's and BIG-IP devices
    • tmsh show gtm iquery
    • openssl s_client -connect <ip_address>:4353
    • iqdump <ip_address>
  • Verify time is in sync
    • ntpq -np
