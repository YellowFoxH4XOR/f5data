Known Issue

The SNMP sysObjectID OID for the VIPRION C2200 chassis is missing in the BIG-IP system's management information base (MIB) file.

Impact

The SNMP query to the sysObjectID may return an unknown value.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you perform an SNMP query of the VIPRION C2200 platform, the sysObjectID OID returns an unknown value.

    For example:

    snmpget -v2c -c public localhost sysObjectID.0

    SNMPv2-MIB::sysObjectID.0 = OID: F5-BIGIP-SYSTEM-MIB::unknown
