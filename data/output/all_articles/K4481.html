Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following articles:

  • K13631: Configuring the threshold values for CPU temperature and CPU fan speed (11.x - 12.x)

The threshold values for CPU temperature and CPU fan speed determine the values at which an event will be logged to the /var/log/ltm file. When the actual temperature of the CPU rises above the threshold value, a single event will be logged. When the actual speed of the CPU fan falls below the threshold value, a single event will be logged to the /var/log/ltm file.

To configure the threshold values for CPU temperature and CPU fan speed, perform the following procedure:

  1. Log in to the command line.
  2. To determine the current threshold values for CPU temperature and CPU fan speed, type the following command:

    bigpipe db | grep -i Platform.Cpu.

    The output appears similar to the following example:

    Platform.Cpu.FanSpeed.Threshold = 3000 Platform.Cpu.Temperature.Threshold = 75

  3. To configure the value for Platform.Cpu.FanSpeed.Threshold, type the following command:

    bigpipe db Platform.Cpu.FanSpeed.Threshold <value>

    Note: You can set the value for Platform.Cpu.FanSpeed.Threshold to values between 0 and 65535 RPM, inclusive. The default threshold value is 3000 RPM.

  4. To configure the value for Platform.Cpu.Temperature.Threshold, type the following command:

    bigpipe db Platform.Cpu.Temperature.Threshold <value>

    Note: You can set the value for Platform.Cpu.Temperature.Threshold to values between 0 and 65535 degrees Celsius, inclusive. The default threshold value is 75 degrees Celsius.
