Description

While monitoring fully qualified domain name (FQDN) configured nodes or pool members, the bigd process logs the monitor status  as 'was unchecked for 0hr:0min:1sec '.

    Environment

    • BIG-IP
    • Pool configured with FQDN nodes
    • Monitor is applied to the pool

    Cause

    When Pools are configured with FQDN members,  the BIG-IP sends frequent DNS queries to get the updated IP Addresses for those nodes. If the DNS responds with a new IP Address, then BIG-IP will take some time (approximately 1sec) to adjust the monitor destination IP Address and logs similar messages.

    notice mcpd[<pid>]: 01070727:5: Pool <pool name> member <member name> monitor status up. [ <monitor name>: up ] [ was unchecked for 0hr:0min:1sec ]

    Recommended Actions

    There is no real impact of this IP Address change and the message is benign.

    Additional Information
    None
