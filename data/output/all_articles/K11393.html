Known Issue

This is the result of a known issue. An index overflow in the AHA36x driver may cause compression to stall on certain BIG-IP systems. This issue occurs when a callback loop in the AHA driver code tests for a condition. When the index wraps back to zero, the loop fails and compression stalls.

Note: The following BIG-IP systems shipped with an AHA compression card:

  • BIG-IP 6400 (D63) - AHA361-PCIX card
  • BIG-IP 6800 (D68) - AHA361-PCIX card 
  • BIG-IP 8400 (D84) - AHA362-PCIX card

F5 Product Development tracked this issue as CR119065 and it was fixed in BIG-IP 10.1.0 and 9.4.8. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
