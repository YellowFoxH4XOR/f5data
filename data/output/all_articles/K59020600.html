K59020600: BIG-IP AFM Traffic is not passing through device after upgrade from to V14.1.3.1

Published

Updated

Legacy Content
Applies to

Source
https://my.f5.com/manage/s/article/K59020600

Description

Traffic is not passing through device after upgrade due to NAT translation Failures.

Environment

  • AFM
  • CGNAT

Cause

Bug ID 966681: NAT translation failures while using SP-DAG in a multi-blade chassis

We can see the counter increase on the tmctl table fw_lsn_pool_failure_stat:

tmctl -c fw_lsn_pool_failure_stat  | sed -e 's/ /_/g' | column -s, -t
name                   failure_cause            failure_count
---------------------------------------------------------------
/Common/lsn_pool_Example Port block exhaustion  10000

Recommended Actions

Change the DB key tm.lsn.retries as below:

tmsh modify sys db tm.lsn.retries value 4096

Note: After changing the DB variable you need to restart tmm.

The workaround doesn't have side-effects and works as well as the fix for ID966681.
