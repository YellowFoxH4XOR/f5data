K8110: Nightly backup FTP settings are lost after upgrading to version 6.x

Type
Known Issue
Published
2010-07-02
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.1.0, 6.0.3, 6.0.2, 7.0.0, 6.0.0, 6.0.1
Source
https://my.f5.com/manage/s/article/K8110

Known Issue

This is the result of a known issue. If the Perform nightly backups to ftp server check box is selected on the Device Management: Maintenance: Backup/Restore page, and you upgrade your FirePass controller from a 5.x version of FirePass software to a 6.x version of FirePass software, you lose all FTP settings previously configured on the Device Management: Maintenance: Backup/Restore page.

Note: This issue does not occur when you upgrade from an earlier 6.x release to a later 6.x release. For example, this issue does not occur if you upgrade from version 6.0.0 to version 6.0.2.

F5 Networks Product Development is tracking this issue as CR65029.

Workaround

You can work around this issue by re-entering your nightly backup settings on the Device Management: Maintenance: Backup/Restore page in the FirePass Administrative Console.
