Known Issue

This is the result of a known issue. iRules that contain more than 10 decode_uri functions may fill all of the buffer space available for the rule. BIG-IP can successfully detect the full buffer, but is unable to obtain more buffer space. As a result, BIG-IP cannot retain the connection and will log the following error:

kernel: Rule failure for rule <name>

F5 Networks Product Development tracked this issue as CR46975 and CR46976 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch. Monitor future Release Notes for the status of these CRs.
