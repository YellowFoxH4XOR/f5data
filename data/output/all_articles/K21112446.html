Description

Connection mirroring is not working on BIG-IP VE on ESXI hypervisor 6.7 Update 2 or later. 

Restarting tmm /var/log/tmm* will log similar to following
notice DAG hash mismatch; discarding mirrored state

 

Environment

  • One of BIG-IP VE has modified /config/tmm_init.tcl file and HA peer does not have similar modified /config/tmm_init.tcl file.
       Note: For example /config/tmm_init.tcl file modified with workaround for ID774445 on one HA peer unit but not the other

Cause

Mirroring requires all HA peer units have the same DAG hash.  Modifying /config/tmm_init.tcl file can change the DAG hash.

Recommended Actions

When changes in /config/tmm_init.tcl result in a DAG mismatch you must either remove the custom /config/tmm_init.tcl files, or make sure they are the same across all HA peer systems.

If the /config/tmm_init.tcl file was modified to work around ID774445 and you have since upgraded to a version with ID774445 fixed then remove the config/tmm_init.tcl file. 

cp /config/tmm_init.tcl /config/tmm_init.tcl.bk
rm -f /config/tmm_init.tcl
tmsh restart sys service tmm
 

If the /config/tmm_init.tcl file was modified to work around ID774445 and you have not upgraded to a version with ID774445 fixed then proceed with the ID774445 workaround on all HA peer systems, or if you modified config/tmm_init.tcl for other reasons consider applying the same changes to all HA peer systems (tmm must be restarted after making changes to /config/tmm_init.tcl).
