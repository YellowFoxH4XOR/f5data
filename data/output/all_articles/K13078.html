Known Issue

Important: Although version 10.2.1 is displayed in the Applies To box, this issue applies to only 10.2.1 HF3 for the 10.2.1 branch.

An HTTP request may increase in size beyond 10 KB after normalization.

This issue occurs when all of the following conditions are met:

  • BIG-IP ASM processes an HTTP request that is smaller than 10 KB
  • After decoding and normalizing any encoded or escaped characters, the request size exceeds 10 KB
  • Any one or more of the following Anomaly Detection features are enabled:

    • Brute Force Attack Prevention
    • Web Scraping (blocking mode only)
    • DoS Attack Prevention

Impact

The BIG-IP ASM bd process may core, and may temporarily fail to pass traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP ASM bd process may temporarily fail to pass traffic.
  • The BIG-IP ASM bd process dumps core, creating files that are named similarly to the following example in the /var/core/ directory:

    bd_bld473_0_core_7328.gz

  • The system may log entries similar to the following examples in the /var/log/ts/bd.log file:

    io_manager_init.c:0343|internal_keep_alive_thread rw_life_signs[i]=65875560 RW thread num=7 failed. current_rw_life_sign=65875560

    io_manager_init.c:0345|internal_keep_alive: BD shrinking...,going down
