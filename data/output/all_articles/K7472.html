Known Issue

This is the result of a known issue. If Deflate compression and RAM Cache are enabled within the HTTP profile, an HTTP 304 Not Modified header is sent even when an If-Modified-Since header is not received in the client request. This behavior is incorrect; if the object in the cache has expired, or an If-Modified-Since header was not received in the client request, the request should be sent back to the server and the cache content should be updated.

F5 Product Development tracked this issue as CR62309 and CR78821 and it was fixed in BIG-IP LTM 9.1.3, 9.3.1, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.0-HF3 issued for BIG-IP 9.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
