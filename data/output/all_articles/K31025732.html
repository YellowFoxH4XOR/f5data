Known Issue

The BIG-IP ASM bd process may produce a core file when the system receives a long HTTP POST.

This issue occurs when the following condition is met:

  • A long HTTP POST is terminated prematurely.
This is a rare timing issue, related to the connection clean-up process.

Impact

The BIG-IP ASM system fails to process traffic while the bd process restarts. A failover may occur if the BIG-IP ASM system is part of a high-availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Messages similar to the following example appear in the /var/log/ts/bd.log file:

    ATTACK_ENGINE|NOTICE|<DATE>|12345|dos_engine.c:6315|Slow transactions attack detected - account id: (14), number of dropped slow transactions: (3456)
  • A core file is created in the /var/core directory, similar to the following example:

    bd.bld817.0.core.1234.gz
