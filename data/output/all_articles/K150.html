Known Issue

This is the result of a known issue. If you attempt to disable a link using the link name rather than the IP address, it will not work. In addition, 3-DNS will remove the line from the wideip.conf file the next time you use the 3ndc restart or 3ndc reload command.

F5 Networks Product Development tracked this issue as CR39381.

Workaround

To work around this issue, always specify the IP address of the link when you disable it.
