Description

You are trying to use TACACS+ for management authentication, but your user cannot login to CLI when assigned the role "Resource Administrator" under Remote Role Groups. When attempting to sign in via SSH the following log messages may be printed to /var/log/secure:

May 9 12:49:45 bigip.local notice sshd[15944]: pam_tacplus: pam_tacplus: user remote_ra successfully authenticated

May 9 12:49:45 bigip.local notice sshd[15944]: pam_bigip_authz: authenticated user remote_ra with role 20 (Resource Administrator) in partition [All]

May 9 12:49:45 bigip.local notice sshd[15944]: pam_bigip_authz: No shell or bad shell for user remote_ra

May 9 12:49:45 bigip.local err sshd[15940]: error: PAM: User account has expired for remote_ra from 172.18.5.105

May 9 12:49:45 bigip.local crit sshd[15940]: fatal: monitor_read: unpermitted request 104

 

Environment

Remote TACACS+

Remote Role Groups

Resource Administrator role

ssh to the BIG-IP with remote resource admin role

 

Cause

The remote role group has not been configured to allow tmsh access for the group.

 

Recommended Actions

In order for remote Recource Administrators to have access to tmsh, the remote role group needs to be configured to allow tmsh access.

Enable tmsh access via tmsh:

tmsh modify auth remote-role role-info modify { { console tmsh } }

Enable tmsh access via Configuration Utility:

- Navigate to System --> Users --> Remote Role Groups.

- Select the group you want to allow console access to.

- Under 'Terminal Access', select tmsh. Click Update.

 

Additional Information

NOTE: Remote Resource Administrator users do not have access to bash. This is by design. If your remote user requires bash access they will need to be given the Administrator role. Please see Related Content for more information.
