Issue

Error Message

notice mcpd[<PID>]: 010713c3:5: Hypervisor updating <guest_property>. Old value: (<old_value>) New value: (<new_value>)

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <guest_property> is the property of the vCMP guest that the hypervisor is changing. The guest property can be any of the following values:
    • host name
    • management address/netmask
    • management gateway
  • <old_value> is the old value of the property of the vCMP guest.
  • <new_value> is the new value of the property of the vCMP guest.

For example:

notice mcpd[4862]: 010713c3:5: Hypervisor updating mgmt address/netmask. Old value: (192.0.2.2/255.255.255.0) New value: (192.0.2.3/255.255.0.0).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The vCMP hypervisor implements a change in the system host name, management IP address, netmask, or gateway properties of the vCMP guest.

Note: This message is a notification of a change in the property of the vCMP guest initiated from the vCMP host. This can happen during the normal system start process or when an administrator makes a change to the vCMP guest from the host.

Impact

The indicated property of the vCMP guest is updated to the new value.

Recommended Actions

You should verify that the change is intentional. In addition, verify the new value of the vCMP guest by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Verify the value of the new host name by typing the following command:

    tmsh show sys hypervisor-info
