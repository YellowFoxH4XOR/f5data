Known Issue

Some BIG-IP platforms reuse source ports too rapidly when the FastL4 virtual server is set to source-port preserve.

This issue occurs when all of the following conditions are met:

  • You are running on a BIG-IP 2000 or 4000 series hardware platform.
  • You have the FastL4 profile associated with a virtual server.
  • The virtual server is configured with source-port preserve.

Impact

Traffic throughput may be degraded.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system attempts to re-use ports while pool members remain in a TIME_WAIT state and are unable to process new connections.

Workaround

To work around this issue, you can set the source port from preserve to change . To do so, perform the following procedure:

Impact of workaround: Traffic or applications which require source port preservation may be negatively affected.

  1. Log in to the BIG-IP Configuration utility as the administrative user.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Click the virtual server you want to modify.
  4. For Configuration, click Advanced.
  5. For Source Port, click Change.
  6. Click Update.
