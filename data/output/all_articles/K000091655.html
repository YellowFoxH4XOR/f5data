jDescription

Configuring NGINX Ingress Controller to perform API key authentication.

The recommended actions below work well if you only need a few API keys configured statically. If you need more keys, or a dynamic authentication, you should consider looking into our JWT token examples which are linked below in the additional info section.

Environment

  • NGINX Ingress Controller
  • Kubernetes

Cause

You would like to configure a virtual server CRD to perform API key authentication before routing traffic to the upstream server.

Recommended Actions

The following is an example configuration which performs API key authentication.

  1. Apply http-snippets to the NGINX Ingress Controller config map. This will use the map directive to assign variables to a list of allowed apikeys. These keys are static values, and can only be changed manually. For example, refer to the following nginx-ingress configmap: 
    apiVersion: v1
kind: ConfigMap
metadata:
  name: nginx-config
  namespace: nginx-ingress
data:
  http-snippets: |
    map_hash_bucket_size 128;
    map $http_apikey $api_key_name {
    default "";

    "nny6NqCmvgVdAXKfEm2XhNhqlfhsUJKUTxwsxnKRTdAInX0TLNNKhv8HNfn0wJuv" "key_one";
    "sGemnyRwTPjP7zMav7kLjjUSW4fe6Jy24LGcgPTrueW4ME1Lg8saIVC07qzY4SBP" "key_two";
    "oCcuSIRzwQLW7bAkd74aD1OHiUwiopeahhzB6yqPxhpxE9DWQxYgPznHTwAdUQGw" "key_three";
    "A1CgrBQjTm4v5LJ4uiFM5GbzA3tlq8W7npnxFnZFfdLIZx9j6d7v4ybA2VVck5FA" "key_four";
    "b0hQZcFIxdmzvS0rfYVUKqa5kqssDZyWGFVJihLzYdLYzidUSOfUkht3gkAzjQ16" "key_five";
    }
  2. Apply the necessary server-snippets and location-snippets to the virtual server. We add the entire location block as a server-snippet to perform the apikey auth validation. And then we use the location-snippet to add the NGINX auth_request directive to any location that we want to enforce apikey validation. For example, refer to the following virtual server configuration: 
    apiVersion: k8s.nginx.org/v1
kind: VirtualServer
metadata:
  name: apikey-vs
spec:
  host: api.example.com
  server-snippets: |
    # API key validation
    location = /_validate_apikey {
        internal;

        if ($http_apikey = "") {
            return 401; # Unauthorized
        }
        if ($api_key_name = "") {
            return 403; # Forbidden
        }
        return 204; # OK (no content)
    }
  upstreams:
  - name: webapp-v1
    service: webapp1-svc
    port: 80
  routes:
  - path: /api/v1/
    location-snippets: |
      auth_request /_validate_apikey;
    action:
      pass: webapp-v1
