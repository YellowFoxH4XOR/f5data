Known Issue

The Server/Application State Protocol (SASP) monitor does not attempt to reconnect after the Group Workload Manager (GWM) server resets the TCP connection.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system uses an SASP monitor to check the availability of a GWM server.
  • The SASP monitor is configured to use Push mode.
  • The GWM server sends a TCP reset packet to the BIG-IP system.

Important: This issue only affects BIG-IP 10.2.4 HF4.

Impact

The SASP monitor stops processing any further messages, and the GWM server status remains down or offline.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The SASP monitored GWM server remains down or offline.
  • When viewing packet captures, the BIG-IP system does not attempt to connect to the GWM server.
