Description

Questions about the BIG-IP Edge Client for Windows:

  • How can you configure the BIG-IP Edge Client to automatically update required components for Windows workstations?
  • Is it possible to update the client automatically when connecting to the F5 without increasing its privileges on the computer station?

Environment

  • BIG-IP APM
  • Windows Client device
  • BIG-IP Edge Client

Cause

The purpose of the Component Installer setting is to update the BIG-IP Edge Client components.
When the Component Installer is installed with Administrator privileges, the BIG-IP Edge Client components are updated when necessary, without prompting the Windows user for administrative credentials.
To permit the Component Installer installation package to update the BIG-IP Edge Client components to automatically update components, you must set the Component Update option in the Connectivity profile configuration of the BIG-IP APM virtual server to Yes (the default setting).

Recommended Actions

To make sure you set Edge Client for automatically updated:

  1. Go to Connectivity / VPN > Connectivity > Profiles > (click the connectivity profile name).
  2. Click Edit Profile.
  3. Locate Win/Mac Edge Client.
  4. Set Component Update: Yes.
  5. Click Update.
  6. Restart Windows workstation.
  7. Using the BIG-IP Edge Client of the Windows workstation access the BIG-IP APM virtual server. 

Note: For additional information refer to: K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, Mac OS and Linux CLI

    Additional Information

    • Is it critical in terms of security if BIG-IP Edge Client components are not updated?

    Generally there is no security impact if the Edge Client components are not upgraded, but newer features may not be supported.
    Please review F5 Security Advisories regularly to ensure that any identified security issues are addressed.

    Newer versions of base BIG-IP releases, may contain bundled upgrades to APMClient versions.
