Issue

Error Message

01260025:3: Cipher <cipher> negotiated is not supported by Proxy SSL configured in virtual server <virtual_server_name>

In this error message, note the following:

  • The <cipher> is the SSL cipher in hex format.
  • The <virtual_server_name> is the name of the virtual server processing the connection.

For example:

01260025:3: Cipher c013:5 negotiated is not supported by Proxy SSL configured in virtual server /Common/example_ssl

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The Proxy SSL option is enabled in the Client and Server SSL profiles.
  • The cipher negotiated by the client and server is not supported by Proxy SSL, and one specified in each of the SSL profiles. Proxy SSL only supports RSA key exchange.

Note: For more information about Proxy SSL on BIG-IP, refer to K13385: Overview of the Proxy SSL feature.

Note: This message is introduced in BIG-IP 12.0.0. For information about a similar error message logged prior to 12.0.0, refer to K40104228: Error Message: 01260014:3: Cipher 9d:5 negotiated is not configured in profile /Common/example_ssl.

Impact

  • If the Proxy SSL Passthrough option is enabled, there is no impact.
  • If the Proxy SSL Passthrough option is not enabled, the SSL connection fails.

Recommended Actions

  • Reconfigure the back-end SSL server to negotiate only ciphers supported by Proxy SSL and by the Client and Server SSL profiles. These are ciphers that use RSA key exchange.
  • Ensure that the Client and Server SSL profiles are configured to support ciphers that use RSA key exchange.
