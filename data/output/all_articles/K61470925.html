Issue

Error Message

err mcpd[<PID>]: 01070315:3: profile <Profile Name> requires a key

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <Profile Name> is the partition location and the name of the SSL profile that is missing an SSL key.

For example:

err mcpd[5794]: 01070315:3: profile /Common/MySSL_Profile requires a key

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions are met:

  • An SSL key is missing from the Certificate Key Chain object that is associated with a Client or Server SSL profile.
  • An SSL key is missing from the Client or Server SSL profile when a certificate is present.

Impact

The mcpd process fails to validate for specific Client SSL or Server SSL profiles, resulting in failure of the mcpd operation.

Recommended Actions

Update the Client or Server SSL profile with the appropriate SSL Key.
