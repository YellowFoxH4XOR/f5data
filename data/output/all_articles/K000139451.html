Description

How to use iControl to get a specific value in Datagroup

 

Environment

-iControl

-cUrl command

-ltm data group

Cause

None

Recommended Actions

Basic command to view all:

 

[root@sample-BIG-IP:Active:Standalone] config # curl -k -u admin:admin -H "Content-Type: application/json" -X GET https://10.xx.xx.xx/mgmt/tm/ltm/data-group/internal/~Common~google_auth_keys | jq .

 

{

"kind": "tm:ltm:data-group:internal:internalstate",

"name": "google_auth_keys",

"partition": "Common",

"fullPath": "/Common/google_auth_keys",

"generation": 1437,

"selfLink": "https://localhost/mgmt/tm/ltm/data-group/internal/~Common~google_auth_keys?ver=16.1.4.1",

"type": "string",

"records": [

{

"name": "test1",

"data": "46671FHSOGKZZZZZ"

},

{

"name": "test2",

"data": "46671FHSOGKXXXXX"

},

{

"name": "test3",

"data": "46671FHSOGKKHFJM"

}

]

}

 

And you only want to check test1, test2, test3 and the corresponding value:

 

[root@sample-BIG-IP:Active:Standalone] config # curl -k -u admin:admin -H "Content-Type: application/json" -X GET https://10.xx.xx.xx/mgmt/tm/ltm/data-group/internal/~Common~google_auth_keys | jq . | egrep -i '\"name\"\:|\"data\"\:'

 

"name": "google_auth_keys",

"name": "test1",

"data": "46671FHSOGKZZZZZ"

"name": "test2",

"data": "46671FHSOGKXXXXX"

"name": "test3",

"data": "46671FHSOGKKHFJM"

 

 

In the event you want to only output test1. You can try this command.

 

[root@sample-BIG-IP:Active:Standalone] config # curl -k -u admin:admin -H "Content-Type: application/json" -X GET https://x.x.x.x/mgmt/tm/ltm/data-group/internal/~Common~google_auth_keys | jq . | egrep -i 'name|data' | awk '/test1/ {print; getline; print}'

 

"name": "test1",

"data": "46671FHSOGKZZZZZ"

 

 

Additional Information

Basically you have to play with the "grep" command to get the output you desire.
