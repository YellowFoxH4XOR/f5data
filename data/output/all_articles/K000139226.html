Description

The following error message is logged when deploying AS3 declaration with a security log profile:

 

AS3 Deployments: Declaration failed: 01070635:3: The security log profile (/Common/Shared/mylogprofile) is referenced by one or more virtual servers or Nat policy rule

 

Environment

  • BIG-IP
  • Security log profile
  • AS3 deployment

Cause

Security log profile configuration conflict

A security log profile is missing from the AS3 declaration (not necessarily the one that is identified in the error message)

Recommended Actions

Review security log profiles in use on BIG-IP

Define the all security log profiles in the AS3 declaration

Additional Information

None
