K45723242: Downgrade of MacOS Edge Client from a newer version not working

Type
Support Solution
Published
2022-05-25
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K45723242

Description

When you downgrade the MacOS Edge Client from a newer version, is does not connect as expected

  • Edge Client does not connect to the VPN
  • Error messages in edge.log: SvpnHandler::LaunchSvpn, (0xfffffffd) EXCEPTION - TunnelService, TunnelServer is not installed in location /Library/Internet Plug-Ins/F5 SSL VPN Plugin.plugin/Contents/Helpers/svpn

Environment

  • BIG-IP APM
  • MacOS
  • Edge Client

Cause

This is caused by the fact that the MacOS uninstall does not completely remove all of the Edge Client files.

Recommended Actions

K15539: Removing BIG-IP Edge Client from Mac OS X devices

Additional Information
