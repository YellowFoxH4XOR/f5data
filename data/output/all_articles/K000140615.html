Description

ASM generates the error message below which indicates an issue with the sync operation between the devices in the device group.

crit g_server.pl[16013]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::spawn_relay_handler): Sync recovery state timed out. State may be inconsistent with other peers

Environment

  • ASM sync
  • Device Group used for ASM synchronization is configured with Automatic with Incremental sync type

Cause

ID1022669

Recommended Actions

To avoid the above scenario it is recommended to follow these steps:

1.Switch to Manual Sync

2.Increase the MaxMemorySize value in /etc/ts/tools/nwd.cfg

3.Restart ASM

bigstart restart asm

4. Switch back to Automatic Sync

Additional Information

Regarding increasing the MaxMemorySize value, please refer to K01026149: Error 01310027:2: ASM subsystem error indicating Memory Size reached a threshold
