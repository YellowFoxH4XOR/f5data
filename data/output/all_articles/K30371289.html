Topic

You should consider using this procedure under the following condition:

  • You want to force an active BIG-IP system or an active traffic group to standby mode using the BIG-IP Configuration utility

Description

You can force an active BIG-IP system in a device group to standby mode using the Configuration utility. When you force a BIG-IP system to standby mode, all active traffic groups on the system fail over to another device in the device group.  You can also force a specific active traffic group on your BIG-IP system to standby mode using the Configuration utility. When you force a specific traffic group to standby mode, the traffic group fails over to a standby BIG-IP system in the device group. 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility

Procedures

Force the BIG-IP system to standby mode

To force the BIG-IP system to standby mode, perform the following procedure:

Impact of procedure: Performing the following procedure forces the BIG-IP system to fail over to another device in the device group. All active traffic groups will fail over.

  1. Log in to the Configuration utility on the active BIG-IP system.
  2. Go to Device Management > Devices. 
  3. Select the name of the local device (Self).
  4. To force the system to standby mode, select Force to Standby.

Force an active traffic group to standby mode

To force an active traffic group on your BIG-IP system to standby mode, perform the following procedure:

Impact of procedure: Performing the following procedure forces the active traffic group to fail over to another device in the device group.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Device Management > Traffic Groups. 
  3. You can view the currently active device and next active device for each traffic group.
  4. Select the name of the active traffic group.
  5. To force the traffic group to standby mode, select Force to Standby.
