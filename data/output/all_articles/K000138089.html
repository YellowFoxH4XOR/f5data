Do you have temporary users who upload or download files on your behalf using F5 Secure Files?

When F5 Support requires files to diagnose and fix technical support issues, it uses F5 Secure Files (securefiles.f5.com) to securely exchange files with you. This file transfer site complies with global data protection standards to safeguard the data you exchange.

You may have business associates who are not on your MyF5 account who assist you with uploading or downloading files for a support case using Secure Files. Before January 29, 2024, these associates were called temporary users, and they used the case ID and an automatically generated password to sign in to Secure Files. 

Starting on January 29, 2024, all users who access Secure Files must have a MyF5 account

Starting January 29, 2024, temporary users must do the following to access Secure Files:

  • Have their own or a separate MyF5 account that they use to access Secure Files.
  • Be invited to a support case folder on Secure Files by a user who:
    • Is on the MyF5 account to which the support case belongs.
    • Has access to the case.

For more information, refer to the following articles:

  • K000138087: Give or receive access to a support case folder on Secure Files
  • K000090853: Exchange files with F5 Support

Note that, on or after January 29, 2024, if temporary users try to sign in to Secure Files using the case ID and an automatically generated password, they will encounter an error. They must complete the preceding steps to secure access.

If you have any questions or concerns, contact F5 Support.
