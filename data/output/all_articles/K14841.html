Known Issue

Loading a BIG-IP APM configuration may take longer than you expect to complete.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system's access profiles include many configured agents or objects.
  • You load the affected device's configuration either manually or when the device is restarted.

Load times vary based on the available resources and the number of agents (policy checks) and objects (ACLs and links) in the BIG-IP APM configuration and platform. The BIG-IP APM configuration load time occasionally exceeds five minutes.

Impact

The BIG-IP APM resources are unavailable while the configuration loads.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP APM system experiences high CPU usage while the configuration loads.
  • Users cannot access the BIG-IP APM logon page and configured resources.
