Description

Viprion secondary blades unable to upgrade to newer version with the following error in var/log/liveinstall.log:

error: status 256 returned by command: F5_INSTALL_SESSION_TYPE=install tmsh -f save sys ucs /var/tmp/RcL7ZiBTEq.ucs
info: >++++ result:
info: Saving active configuration...
info: Thrift: Fri May 20 22:35:19 2022 TSocket::open() getaddrinfo() <Host: 127.3.0.2
info:  Port: 9090>Name or service not known
info: Error during config save.
info: Unexpected Error: UCS saving process failed.
info: >----
Terminal error: See /var/log/liveinstall.log
 

Environment

  • Viprion with two or more blades (multi-blade)
  • AVR Scheduled Reports in configuration
     

Cause

On secondary blades monpd listens on slot-specific local address 127.3.0.X, so tmsh should use this address when it establishes connection to monpd (instead of 127.0.0.1)
 

Recommended Actions

Follow the steps below to workaround on this issue.

  1. Back up your BIG-IP configuration data to a UCS configuration archive.
  2. Remove all scheduled reports from configuration.
    • On the main tab, click Local Traffic > Profiles > Analytics > Scheduled Reports.
  3. Perform upgrade.
  4. Add scheduled reports back to configuration.
