Description

You need to determine what IDs have been included in the engineering hotfix installed on your BIG-IP

Environment

  • BIG-IP
  • Engineering Hotfix

Cause

None

Recommended Actions

There are 3 ways to do so:

  1. If you still have the files included with the engineering hotfix the Readme file will list them.
  2. You can use iHealth to tell you what IDs are included on the installed Engineering Hotfix
    1. Generate a fresh qkview  Note: Refer to Related Content for steps on how to do this
    2. Upload it to iHealth
    3. Once done processing, navigate to the Commands page
    4. Scroll down to the bottom and click on Engineering Hotfix Changes.
  3. Run the following command on the CLI...tmsh show sys version  and  a list will show at the bottom of the output with the iDs included.
