K000156835: How do I know I if an iRule containing the HTTP::respond command is configured on a virtual server?

Type
Support Solution
Published
2025-10-06
Updated
2026-09-15
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000156835

Description

You want to determine whether an iRule with the HTTP::respond command is configured on a virtual server in your BIG-IP system. This can help ensure the desired traffic behavior or troubleshoot any unexpected responses.

Environment

  • BIG-IP platform
  • Version-specific configurations may apply
  • Virtual server with applied iRules

Cause

Configurations involving the HTTP::respond command may impact traffic flow, response handling, or application logic. Users may need to verify its presence for troubleshooting or auditing purposes.

Recommended Actions

Part 1: Using the BIG-IP GUI

  1. Log in to the BIG-IP Configuration Utility via your web browser.
  2. In the left menu, click Local Traffic.
  3. Click Virtual Servers to display the list of all virtual servers.
  4. Find and click the name of the virtual server you want to inspect.
  5. Scroll down to the Resources section on the virtual server’s properties page.
  6. Under iRules, review the list of iRules attached to this virtual server.
  7. For each iRule listed, click its name (the link will open the iRule details).
  8. In the iRule details page, review the iRule code displayed in the text box.
  9. Use your browser’s search function (Ctrl+F or Cmd+F) to search for HTTP::respond within the iRule code.
  10. Repeat steps 7–9 for every iRule attached to the virtual server.

Part 2: Using the BIG-IP CLI

  1. Connect to the BIG-IP device using SSH or direct console access.
  2. Run the command below to list all iRules attached to the virtual server (replace <virtual_server_name> with your server name): 
    tmsh list ltm virtual <virtual_server_name> rules
  3. Note down each iRule name listed in the output.
  4. For each iRule, run the following command to display its contents (replace <iRule_name> with each iRule name): 
    tmsh list ltm rule <iRule_name>
  5. Review each iRule’s content for any usage of HTTP::respond.
  6. (Optional) To quickly search all iRules on the system for this command, run: 
    tmsh list ltm rule | grep -i 'HTTP::respond'
  7. If using step 6, review the results and cross-reference with which iRules are attached to your target virtual server.
