Known Issue

The system may fail to load a configuration after you boot to a new software installation.

This issue occurs when all of the following conditions are met:

  • Your configuration contains network address translation (NAT) names that include a space in the name.
  • You attempt to copy the configuration from a boot location that has a BIG-IP version earlier than 11.5.0 installed, to a target location that has a version later than 11.5.0 installed.

Impact

The configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/ltm file, you observe error messages similar to the following example:

    err mcpd[<pid>]: 01070088:3: The requested object name (</path/nat name with space>) is invalid.
    err tmsh[<pid>]: 01420006:3: Loading configuration process failed.
    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- 01070088:3:
    The requested object name (</path/nat name with space>) is invalid. Unexpected Error: Loading configuration process failed.
    err mcpd[<pid>]: 01070425:3: Full configuration load failed.

Workaround

To work around this issue, using a text editor, remove any spaces from NAT names in the configuration file /config/bigip.conf of the affected volume.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
