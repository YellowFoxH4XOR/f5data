Description

BIG-IP APM  HA configuration AAA resources with Direct / Pool modes may use different source IPs.

Environment

In AAA object, there are two options determined for Server Connection

  • BIG-IP HA
  • Pool
  • Direct

Cause
Active Directory authentication is not configured to use the BIG-IP HA floating self-IP address.

 

Recommended Actions
You can connect directly to the AAA Active Directory server for standalone functionality or create pool members for High Availability. If you want to deploy Active Directory authentication for pairs of BIG-IP systems in High Availability, you must use the floating self-IP address as the source IP address by defining the AAA server connection with the use of the option Use Pool.

Direct option -  the policy agent directly connect to the server address specified for your AAA domain controller
Pool option -  APM uses an Internal L4 Virtual Server with "SNAT Automap" to reach the AAA servers, therefore the connections will follow the same rules as article K7336: The SNAT Automap and self IP address selection
