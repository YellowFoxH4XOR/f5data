Issue

If you are not licensed for advanced routing modules, you can safely ignore the following error.

S80zebos: /usr/local/sbin/zebos: not found
bigstart: zebos exited abnormally, status = 2

If you receive this error and you are licensed for advanced routing modules, contact F5 Networks Technical Support for assistance. This error may indicate that there are files missing.
