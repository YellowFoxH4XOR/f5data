Description

 

Light version option does not work with APM Exchange iApp deployment.

 

 

Environment

    • Exchange iApp template (all versions)
    • Light version and public computer option in use
    • NTLM authentication required from server side

     

    Cause

     

    In order for private/public and light version to work, OWA app on Exchange server must be configured with forms-based authentication.

     

     

    Recommended Actions

     

    Please set a forms-based authentication on the Microsoft Exchange Server.
