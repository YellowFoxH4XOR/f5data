Description

A security alert identified a malicious f5-logger package in a public NPM repository. The BIG-IQ Centralized Management f5-logger module was evaluated to determine whether it was the same package and required removal.

Environment

  • Product: BIG-IQ Centralized Management
  • Module location: /usr/lib/node_modules/f5-logger
  • Logger dependency: Winston 2.4.2
  • The f5-logger module is an internal BIG-IQ Centralized Management module and is not published in public NPM repositories.

Cause

The alert resulted from a name similarity between the internal BIG-IQ Centralized Management f5-logger module and an unrelated malicious package previously flagged in a public NPM repository.

The BIG-IQ Centralized Management module is an internal wrapper for Winston logger. File integrity verification confirmed that the files in the module directory were unaltered.

Answer/Recommended Actions

Do not remove or uninstall the BIG-IQ Centralized Management f5-logger module. Removal is not required and could affect logging functionality.

To verify file integrity:

  1. Log in to the BIG-IQ Centralized Management system with appropriate administrative privileges.
  2. Generate SHA256 hashes for all files in the module directory:
    find /usr/lib/node_modules/f5-logger -type f -exec sha256sum {} + > /var/tmp/f5-logger-hashes.txt
  3. Compare the generated hashes with hashes from a known-clean system running the same software.
  4. Contact F5 Support if any hash differs or if additional security concerns remain.

Additional Information

The BIG-IQ Centralized Management f5-logger module and the malicious public NPM package are unrelated software components. The BIG-IQ Centralized Management module is internal, is not sourced from the public NPM repository, and contains no evidence of alteration or malicious code.

The Winston logger dependency used by the module was reviewed and has no known vulnerabilities identified in the available package information.
