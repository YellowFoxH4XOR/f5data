Description

The /var/arg_ex_out file is filling the /var directory due to external monitor logging.

Error messages you may see as a result of this:

Jun 22 11:50:01 bigip-01 err diskmonitor: 011d0004:3: Disk partition /var has only 15% free
Jun 22 11:57:02 bigip-01 err diskmonitor: 011d0004:3: Disk partition /var has only 15% free
 

Environment

  • BIG-IP
  • External monitor
  • Debug or monitor logging saved to /var filesystem

Cause

External monitor script constantly writing to arg_ex_out file, fills up disk space.

This can be seen by running the following command:

# root@bigip-01:Active:In Sync] ~ # find /var -xdev -type f -exec du {} \; | sort -rn | head -30

950108 /var/arg_ex_out
267448 /var/sam/images/apmclients-7150.2017.925.1331-3979.0.iso
118236 /var/local/ucs/20180611.example.ucs
117924 /var/local/ucs/config.ucs

 

Recommended Actions

To work around or avoid this issue you may consider one of the following procedures. 

  • To use /shared instead of /var
  • To disable logging totally, enable only if needed
  • To use > instead of >>
To use /shared instead of /var
  1. Note: If you use /shared instead of /var the thing is that this file is not subjected to housekeeping. It will grow unless you manually trim down the logs inside the file or delete the file, relocate the file to local drive or create your own script to delete this file.
  2. Login to command line and edit /config/monitors/arg_example

    # vi /config/monitors/arg_example
     
  3. Then look for the following lines 

    Original

    -------
    my $outfile = "/var/arg_ex_out"; < --------

    open( OUTF, ">>$outfile" );

    -------

    Modified

    -------
    my $outfile = "/shared/arg_ex_out";

    open( OUTF, ">>$outfile" );

To disable logging totally, enable only if needed  
  1. Login to command line and edit /config/monitors/arg_example

    # vi /config/monitors/arg_example
     
  2. Then look for the following lines

    Original

    -------
    # Open the output file

    my $outfile = "/var/arg_ex_out";

    open( OUTF, ">>$outfile" );      <---------hex out the logging part
    ------

    Modified

    -------
    # Open the output file

    my $outfile = "/var/arg_ex_out";

    #open( OUTF, ">$outfile" );

To use > instead of >>
  1. Login to command line and edit /config/monitors/arg_example

    # vi /config/monitors/arg_example
     
  2. Then look for the following lines

    Original

    -------
    # Open the output file

    my $outfile = "/var/arg_ex_out";

    open( OUTF, ">>$outfile" );  <------------ 
    ------

    Modified

    -------
    # Open the output file

    my $outfile = "/var/arg_ex_out";

    #open( OUTF, ">$outfile" );
