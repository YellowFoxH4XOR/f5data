K000140791: Disable SSH public key authentication on F5OS for root user.

Type
Support Solution
Published
2024-08-27
Updated
2025-02-05
Source
https://my.f5.com/manage/s/article/K000140791

Description :

Disable SSH public key authentication on F5OS for root user.

 

Environment:

  • F5OS system
  • A remote device
  • SSH Public key authentication
  • password based authentication.
  • Root credentials

 

Cause :

You would like to disable SSH public key based authentication and enable password based authentication for root user.

 

Recommended Actions:

     

    1. SSH to F5OS using SSH public key authentication.
    2. Make sure you have root password of the F5OS system.
    3. On F5OS edit the “sshd_config” file using any editor of your choice and then change the configuration option as mentioned below.
      example: vi /etc/ssh/sshd_config
      PermitRootLogin yes
      PasswordAuthentication yes
    4. Save and exit the file
      example: to save the file press ‘esc’ key on your keyboard then type wq! then press ‘enter’ key.
    5. Keep the existing SSH session open and verify password-based authentication first, using another SSH session. Once password-based authentication is successful, move to the following steps.
      example: From remote system SSH to F5OS mgmt IP using root credentials.
      ssh root@<IP Address of F5OS system>
    6. Edit the “authorized_keys” file using any editor of your choice and remove all public keys used for remote authentication.
      example: vi /root/.ssh/authorized_keys
    7. Save and exit the file
      example: to save the file press ‘esc’ key on your keyboard then type wq! then press ‘enter’ key.
