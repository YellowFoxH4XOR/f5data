Description

This solution will describe Duo Radius authentication failures and how to troubleshoot this issue.

  • Radius authentication fails.
  • Users attempting to authenticate see a "Invalid username/password" error message.
  • In the Access Policy logs located in /var/log/apm you will see the following error:
<big-ip_hostname> err apmd[14541]: 01490108:3: /Common/<access_policy>:Common:<session_id>: RADIUS module: authentication with '<username>' failed: Access-Reject packet from host <radius_server_ip>:1812  (3)
<big-ip_hostname> debug apmd[14541]: 01490111:7: /Common/<access_policy>:Common:<session_id> RADIUS module: parseResponse(): Access-Reject packet from host <radius_server_ip>:1812 (3)
  • In a packet capture (use the tcpdump utility in the BIG-IP command line interface to capture traffic on the Radius Server IP Address) you will the following error from the Radius Server:
User Datagram Protocol, Src Port: 1812, Dst Port: 39719
RADIUS Protocol
    Code: Access-Reject (3)
    Packet identifier: 0x3b (59)
    Length: 75
    Authenticator: c91d06d8e46c71535af5a170f8cd70a6
    [This is a response to a request in frame 2]
    [Time from request: 0.219057000 seconds]
    Attribute Value Pairs
        AVP: t=Reply-Message(18) l=55 val=Failmode Secure - Denied Duo login on preauth failure
            Type: 18
            Length: 55
            Reply-Message: Failmode Secure - Denied Duo login on preauth failure

Environment

  • APM (Access Policy Manager)
  • Duo Radius Authentication
  • Duo Authentication Proxy
  • Radius Server object configuration.

Cause

The Duo Authentication Proxy (in this case Radius) can not communicate with Duo Cloud services.
