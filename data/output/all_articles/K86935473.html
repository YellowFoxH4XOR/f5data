Known Issue

After you upgrade from BIG-IP 11.6.1, you are unable to set the maxMessageBodySize option using the iControl REST API command.

This issue occurs when all of the following conditions are met:

  • You have upgraded your BIG-IP system from 11.6.1 to any of the versions listed in the Applies to (see versions) box in the upper right corner of this article.
  • During the software upgrade, you applied the user configuration set (UCS) file from BIG-IP 11.6.1.
  • After the upgrade, you attempted to run an iControl REST API command to set the maxMessageBodySize option.

    For example:

    curl -k -u admin:admin -H 'Content-Type: application/json' -H 'Connection: keep-alive' -X POST 'https://localhost/mgmt/shared/server/messaging/settings/8100' -d '{"maxMessageBodySize": "123456000"}'

Impact

The iControl REST API command fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot set the maxMessageBodySize option.
  • You receive an error message that appears similar to the following example:

    {"code":400,"message":"onPut Not implemented","originalRequestBody":"{\"maxMessageBodySize\": \"123456000\"}","referer":"127.0.0.1","restOperationId":216941,"kind":":resterrorresponse"}

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To recover from this issue, you can reset the messaging settings and perform a restart on the restjavad process. To do so, perform the following procedure:

Impact of workaround: The following procedure involves restarting the restjavad process, and this causes disruption of service that communicates with the BIG-IP system by way of iControl or REST API commands. F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the BIG-IP system command-line prompt.
  2. To reset the messaging settings, type the following REST API command:

    curl -X DELETE http://localhost:8100/shared/storage?key=shared/server/messaging/settings/8100

  3. To restart the restjavad process, type the following command:

    tmsh restart /sys service restjavad
