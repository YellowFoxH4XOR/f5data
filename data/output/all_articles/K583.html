After you edit the /etc/syslog.conf file, type the following command to load the changes into memory:

Important: The following command contains back ticks (`) around the characters that follow -HUP. Back ticks are different than apostrophes (') and are located on most keyboards, above the tilde (~) character. If you do not include these back ticks, the shell will incorrectly interpret the characters as options to the command, rather than extracting the syslog process ID.

kill -HUP `pidof syslogd`

Note: The HUP signal is commonly used to tell daemons to reread the configuration files.
