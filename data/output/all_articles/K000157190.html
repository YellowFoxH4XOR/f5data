K000157190: Origin Pools - Q&A: What happens if I set the DNS Refresh Interval to 0?

Description

You are configuring the origin server parameters as a "Public DNS Name of Origin Server" and you want to know what does it means if the Advanced field "DNS Refresh Interval" is set to 0.

Environment

  • HTTP Load Balancer - Origin Pools
  • Customer Edge

Answer

If you set the option to 0, by our internal configuration it will means 900 seconds.

Additional Information

The 900 second interval is the default override applied to any origins attached to a Regional Edge (RE).

For Customer Edge (CE) deployments, the interval can be configured at multiple levels, allowing more granular control based on the deployment architecture and operational requirements.
