Known Issue

You may be unable to search for BIG-IP DNS (formerly known as BIG-IP GTM) servers by their IP address.

This issue occurs when following condition is met:

  • You attempt to search for a BIG-IP DNS server by IP address using the BIG-IP Configuration utility.

Impact

You are unable to search for BIG-IP DNS servers by IP address.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A search for known BIG-IP DNS servers by IP address produces no results.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to search and filter by IP address. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility with a user account that has Administrator role credentials.
  2. To list all servers, type the following command:

    list gtm server addresses

  3. To filter specific addresses, use the grep filter to search for specific text.

    For example:

    list gtm server addresses | grep 192.168.1.1
