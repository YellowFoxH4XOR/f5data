K000141115: How do we specify Source IP for sFlow traffic

Description

The mgmt/eth0 port cannot be used for sending out sFlow data. It is required that the sflow receiver is reachable via a self-ip. This is a guide on how to specify the interface vlan of a self-ip you want sFlow Traffic to be directed from.
 

Environment

  • Big-IP VE / Appliance
  • sFlow

Cause

None, this is by design.

Recommended Actions

Assuming you had configured:

- an sFlow receiver 
- 2 Vlans: Internal_VLAN and External_VLAN with their associated Self-IP addresses
- default route uses External_Vlan and you want to use the Internal_VLAN instead to be the source of this sFlow traffic

To achieve this, you can:

  1. First add a more specific route ( /32 ) to the destination sFlow receiver to use the Internal_VLAN gateway
  2. Then In webUI, go to System -> sflow -> Receiver List, click on sflow receiver
  3. Change the state to disable and press update
    Note: This is to make sure previous sFlow traffic stops prior to new changes taking effect. You can check with tcpdump that traffic has stopped
  4. Change state to enable again
  5. Confirm and see that sFlow traffic has now changed to the correct source
