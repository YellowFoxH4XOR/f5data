Known Issue

Policy Builder may not receive updates for newly added attack signatures in staging.

This issue occurs when one of the following conditions is met:

  • You configure the BIG-IP ASM system to automatically update attack signatures.
  • You manually create or update user-defined attack signatures.

Impact

The BIG-IP ASM system fails to generate learning suggestions for newly updated attack signatures.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Newly updated attack signatures have no corresponding learning suggestions when triggered.

Workaround

To work around this issue, you can either restart Policy Builder or manually disable and re-enable learning for the attack signature set. To do so, perform one of the following procedures:

  • Restarting Policy Builder
  • Disabling and re-enabling learning for the attack signature set

Restarting Policy Builder

Impact of workaround: Performing the following procedure reverts all learning suggestions and tightening statistics for the previous 24 hours.

  1. Log in to the Advanced Shell (bash).
  2. Restart Policy Builder by typing the following command:

    killall -s SIGHUP pabnagd

Disabling and re-enabling learning for the attack signature set

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select Advanced.
  4. Expand Attack Signatures.
  5. Clear the Learn check box for the affected attack signature set.
  6. Click Save.
  7. Click Apply Policy.
