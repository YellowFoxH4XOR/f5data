Known Issue

The SSL::sessionid iRules command may return invalid values.

This issue occurs when one of the following conditions is met:

  • Your BIG-IP system is configured with an iRule that uses the SSL::sessionid command.
  • The virtual server is configured with an SSL persistence profile

Impact

The value returned by the SSL::sessionid iRules command does not match the Secure Sockets Layer (SSL) session ID provided by the client. Additionally, the BIG-IP system experiences high CPU usage.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When used in an iRule, the SSL::sessionid command returns a random or invalid value.
  • SSL connections that rely on the SSL session ID do not function as expected.
  • Affected SSL connections do not persist as expected.
  • CPU usage for the TMM process increases or is high.
