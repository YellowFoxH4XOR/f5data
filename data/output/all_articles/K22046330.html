Topic

You should consider using this procedure under the following condition:

  • You want to shut down and restart a Virtual Clustered Multiprocessing (vCMP) guest using the iControl representation state transfer (REST) API.

Description

You can shut down a vCMP guest by changing its state from deployed to either provisioned or configured. When a vCMP guest is shut down, the only way to start it is by changing its state to deployed. You can change the state of the vCMP guest only through the vCMP host. For more information about the different states of a vCMP guest as well as detailed steps on shutting down and restarting a vCMP guest using the Configuration utility or tmsh utility, refer to K20081511: Shutting down and restarting the vCMP guest from the vCMP host.

The REST procedure provided in this article is an example of a common BIG-IP maintenance task. You can use the iControl REST API to perform most of the BIG-IP system management and configuration tasks that you can perform using the TMOS Shell (tmsh). For example, you can generate a QKView diagnostic file for upload to F5 iHealth. For more information about the iControl REST API, refer to the iControl REST User Guide that applies to your BIG-IP version, available on F5 Cloud Docs.

curl and jq utilities

Performing the following procedure requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure from an alternate BIG-IP system; however, the jq utility is not available on systems running versions earlier than BIG-IP 12.0.0. You can still use the curl portion of commands, but the resulting output is a single string rather than formatted JSON. For more information about the jq utility, refer to https://stedolan.github.io/jq.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your vCMP host is licensed, provisioned and configured with a management IP address.
  • You have administrative access to the vCMP host Configuration utility.
  • You have command line access to a system with the curl utility and the jq utility installed. For more information, refer to curl and jq utilities in this article.

Procedures

  • Shutting down a vCMP guest
  • Starting a vCMP guest

Shutting down a vCMP guest

You can shut down a vCMP guest by changing its state to provisioned or configured through the vCMP host using the REST object name /mgmt/tm/vcmp/guest/<vCMP guest name>. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your vCMP host. The vCMP guest cannot process traffic until it is restarted.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to shut down a vCMP guest:

    curl -sku admin:<password> -H "Content-Type: application/json" -X PATCH https://<vCMP host hostname or management IP address>/mgmt/tm/vcmp/guest/<vCMP guest name> -d '{"state":"<configured or provisioned>"}' | jq -M .

    For example, you to shut down the vCMP guest named myvguest by setting its state to configured through the vCMP host management IP address 192.168.66.27, type the following command:

    curl -sku admin:admin -H "Content-Type: application/json" -X PATCH https://192.168.66.27/mgmt/tm/vcmp/guest/myvguest -d '{"state":"configured"}' | jq -M .
