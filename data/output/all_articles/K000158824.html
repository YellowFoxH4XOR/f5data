K000158824: NGINX One - errors: ConfigSync Group error "address already in use"

Description

You have configured a ConfigSync Group and you want to push a new config modifying the binding port. You get the following error: 

"address already in use"

Environment

  • F5® Distributed Cloud

  • NGINX One

Cause

This is a known limitation for NGINX running on Linux, where it will fail to reload successfully if it is already bound on a specific port. 

Answer/Recommended Actions

This can be verified locally in your data plane, by following these steps:

  1. Start off your server configuration with listen 8080; directive
  2. Verify NGINX is running as expected with that port bound.
  3. Update server configuration with what you wanted to update to, i.e. listen 127.0.0.1:8080; directive
  4. Reload NGINX with "nginx -s reload"

Checking the logs for NGINX (default location /var/log/nginx/error.log) you will notice the errors there.
