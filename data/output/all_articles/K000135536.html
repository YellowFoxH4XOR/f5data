Description

ASM is not running as the bd process is stuck in a restart loop and the below errors related to the ASM Subsystem are seen in ASM logs like the below:

Jul 12 00:50:46 ltm.example.com crit perl[11050]: 01310027:2: ASM subsystem error (asm_start,): /usr/share/ts/bin/asm_start could not obtain a lock (probably because it's already running). Exiting.

 

On checking with the below command, we see that ASM is running but faces restarts multiple times.

#tmsh show sys service asm
asm run (pid 9144) 1 seconds, 6 starts, 1116 restarts

 

Environment

  • BIG-IP ASM
  • ASM subsystem error
  • bd daemon
  • asm_start script

 

Cause

The asm_start script cannot get a lock, so ASM is failing to start smoothly. 

 

Recommended Actions

Run the below commands in BIG-IP CLI. These commands are to let ASM restart smoothly as it is unable to obtain a lock. 

Impact: The procedure needs a reboot of the machine which will cause a service impact. Perform the steps during a scheduled maintenance window.
 

1. Stop the ASM service

tmsh stop sys service asm

2. Run the below command to remove the script.

rm /ts/lock/asm_start.lock

3. Start the ASM service

tmsh start sys service asm

4. Reboot the device

reboot
