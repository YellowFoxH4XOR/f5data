Topic

You should consider using this procedure under the following condition:

  • You have web content that you want the BIG-IP APM content rewrite engine to ignore.

Description

The BIG-IP APM content rewrite engine analyzes the web content and rewrites URL information and embedded script logic to redirect requests through the BIG-IP APM system. There are occasions when you might want to block portions of the web content from the rewrite engine. For example, you may have external URL links that you do not want the BIG-IP APM system to redirect. The BIG-IP APM <apm_do_not_touch> and </apm_do_not_touch> HTML tags instruct the content rewrite engine to ignore any information located between the tags. 
 

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have configured the BIG-IP APM system with a Web Portal access policy.
  • You have access to an HTML source editor.
  • You have access to the HTML source that you want to block from the content rewrite engine.

Procedures

Inserting the <apm_do_not_touch> HTML tag

Impact of procedure: Use the <apm_do_not_touch> HTML tag carefully. Preventing the content rewrite may make resources included in the HTML source unavailable.

  1. Open the HTML source that you want to modify.
  2. Locate the start of the HTML code that you want to protect from the content rewrite engine.
  3. Insert the <apm_do_not_touch> tag.
  4. Locate the end of the HTML code that you want to protect from the content rewrite engine.
  5. Insert the </apm_do_not_touch> tag.
  6. Save the HTML source.


Note: The <apm_do_not_touch> and </apm_do_not_touch> HTML tags are not limited to BIG-IP APM configurations. BIG-IP systems that have the BIG-IP ASM module provisioned and are configured with a security policy that includes any of the following use these tags when the BIG-IP ASM unit injects JavaScript in support of these protections: 

  • Bot Defense
  • Session Tracking
  • DoS Protection
