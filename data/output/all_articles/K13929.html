Known Issue

SSL private keys that are stored in the FIPS hardware security module (HSM) are not synchronized during ConfigSync operations.

This issue occurs when the following conditions are met:

  • The BIG-IP platform supports the FIPS hardware security module.
  • The BIG-IP systems are configured in a device group.
  • One or more SSL profiles reference keys are stored in the FIPS module.
  • You performed a ConfigSync operation.

For example, if you obtain an SSL key and import the key to the FIPS module on a device group member (LTM-1) and then synchronize the configuration to the device group (LTM-2, LTM-3, LTM-4), the keys are missing from all of the receiving device group members.

Impact

SSL connections may fail after failing over to a device group member with missing SSL keys.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • SSL keys are missing from device group members.

    For example the tmsh show /sys crypto fips private-key command does not display the expected SSL private keys on some device group members.

  • SSL connections may fail after failing over to a device group member with missing SSL keys.

Workaround

To work around this issue, you can manually copy the missing SSL private keys to the receiving device group members. To do so, perform the following procedure:

Impact of workaround: The following workaround may be time consuming in the event that the device group has a high number of missing keys.

  1. Log in to the command line of the device that contains the up-to-date FIPS SSL keys.
  2. Change directories to the /config/ssl/ssl.cavfips by entering the following command:

    cd /config/ssl/ssl.cavfips

    Note: The /config/ssl/ssl.cavfips directory contains encrypted copies of the SSL private keys in the following format:

    <keyname>.exp

  3. Using the following command syntax, manually copy the <keyname>.exp file, which corresponds to each missing SSL key, to the receiving device group members.

    scp -p <missing_keyname>.exp <username>@<remote_device>:/config/ssl/ssl.cavfips/

  4. Log in to the command line of the device group members to which you copied the .exp files.
  5. For each .exp file that you copied, install the key to the FIPS hardware security module by using the following syntax:

    tmsh install /sys crypto key <filename>.key from-local-file <missing_keyname>.exp
