Known Issue

The BIG-IP system may fail to load certain Secure Sockets Layer (SSL) certificates.

This issue occurs when the following condition is met:

  • You attempt to load a certificate and key pair that uses the sha1WithRSA or dsaWIthSHA1_2 signature algorithms.

Impact

The SSL certificate fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs an error message to the /var/log/ltm file that appears similar to the following example:

    crit tmm[10208]: 01260000:2: Profile <clientssl / serverssl profile>: could not load key/certificate

    For example, the system logs the following error message for the SSL certificate named clientssl-test:

    crit tmm[10208]: 01260000:2: Profile /Common/clientssl-test: could not load key/certificate

  • The system fails to load the SSL certificate, and the virtual server does not function as expected.
