Description

chassisConfigUpgrade.pm blade migration is failing and seeing the following error messages in Step 14 of the migration process:

 

############################################

#STEP 14: taking down primary slot 2; this step may take some time.

############################################

Are you sure? (y/n) <n>

y

 

slot1/localhost load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all base " - failed. -- 01071769:3: Decryption of the field (privatekey) for object (9717) failed. Unexpected Error: Loading configuration process failed.

slot1/localhost overdog[4114]: 01140043:0: Ha feature software_update reboot requested

 

Environment

  • BIG-IP
  • VIPRION
  • blade migration upgrade
  • new blades contain config from another environment

Cause

Software image files are not available on new blade to re-create the software volumes

Recommended Actions

The blade migration guide presume that the same volumes on the Primary have already been re-created on the new blade. However this is only possible if the iso images (sig files may also be required) are located on the new blade in /shared/images. The failure is due to the new blade not being able to re-create the same software volumes as on the Primary.

 

Follow these steps to copy the image files from the original Primary blade and install the volumes, before running the migration script chassisConfigUpgrade.pm

 

Insert the new blade in slot1, whilst only the original Primary blade is in slot2.

 

1. Copy iso images and sig files from Primary to new blade:

From Primary blade: scp /shared/images/*.iso slot1:/shared/images/

From Primary blade: scp /shared/images/*.sig slot1:/shared/images/

 

2a. Check that the new volumes are being installed on new blade (tmsh show sys software does not work):

tailf /var/log/liveinstall.log

 

Move to step 3 once all volumes have been installed on new blade.

 

2b If volumes are not being installed after 10 mins, remove Primary (slot2) and reboot new blade (slot1), where volume installation will take place automatically provided that the image files are present.

tmsh show sys software

Once volume installation has completed, remove new blade (slot1) and re-insert Primary (slot2)

Once Primary is Active, insert new blade (slot1)

 

3. Proceed with migration script chassisConfigUpgrade.pm

Overview: Configuration migration from a B2100 blade to a B2150/B2250 blade

 

4. (For vCMP guests) Migrate vDisks for vCMP guests

Overview: Virtual disk migration on B2000 Series blades
