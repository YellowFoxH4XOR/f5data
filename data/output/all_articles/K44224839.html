K44224839: Bot Defense Whitelist IP address not matching

Type
Support Solution
Published
2021-06-08
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.0, 14.1.5, 14.1.4, 14.1.3, 14.1.X, 14.1.0, 14.1.2
Source
https://my.f5.com/manage/s/article/K44224839

Description

Bot Defense Whitelist IP address not working and mitigation is applied to the source traffic.


Environment

  • URL "Any"
  • Several updated made to the bot profile after adding the whitelist
  • If it is the only rule, then source traffic is whitelisted


Cause

This is due to Bug ID 783165: Bot Defense whitelists does not apply for url "Any" after modifying the Bot Defense profile


Recommended Actions

There are two methods:
  • Delete and add the whitelist after modifying the profile.
OR
  • Move the IP address to the top of the rules.


Additional Information

None.
