Description

Upgrading to Helm release version 2.0.0 (NIC version 4.0.0) or later fails. The following error or similar occurs:

Error: UPGRADE FAILED: unable to build kubernetes objects from current release manifest: resource mapping not found for name: "<nic_controller-name>" namespace: "<nic_namespace>" from "": no matches for kind "GlobalConfiguration" in version "k8s.nginx.org/v1alpha1"
ensure CRDs are installed first

Environment

NGINX Ingress Controller

Cause

This issue can occur when the NIC environment had previously been running Helm release version 1.0.2 (NIC version 3.3.2) or earlier.

Note, to confirm previous Helm release versions, run the following command:

helm history -n <release_namespace> <release_name>

Recommended Actions

Upgrade to Helm release version 1.4.2 (NIC version 3.7.2) first.

Additional Information

Documentation: https://docs.nginx.com/nginx-ingress-controller/installation/installing-nic/upgrade-to-v4
