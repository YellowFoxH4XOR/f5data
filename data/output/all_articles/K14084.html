K14084: The ARX snapshot rule no longer supports the 'error-only' reporting option

Type
Knowledge
Published
2013-01-07
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • ARX: 6.2.0
Source
https://my.f5.com/manage/s/article/K14084

Issue

Old Behavior

In versions prior to ARX 6.2.0, the ARX snapshot rule definition allowed the use of an error-only option when specifying the report type. This option would retain reports on the ARX for snapshot rules that failed.

The error-only option was used in ARX 5.0.0, where snapshot reconstruction scripts use the error-only reports to generate the commands needed to manage snapshots following an import or catastrophic failure.

New Behavior

Beginning in ARX 6.2.0, the ARX system snapshot reconstitution script no longer requires the error-only reports. As a result, the error-only option is no longer available when creating a snapshot rule.

Note: Snapshot rules that have the error-only option prior to upgrading to ARX 6.2.0 are retained and honored. However, new rule definitions cannot contain the error-only option.

Impact

You can no longer configure snapshots to create error-only reports.

Recommended Actions

To provide visibility into failed snapshots, you may create an e-mail alert specifying the group snapshot event snapshot-op-fail configuration option. This configuration option will provide an alert when the snapshot failed to be created; however, no error-only report will exist.
