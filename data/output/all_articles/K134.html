K134: Retaining the output from the bigpipe summary and bigpipe ms commands after reboot

Topic

The output provided by the bigpipe summary and the bigpipe ms commands is reset each time you reboot the BIG-IP.

You can install a script to retain this information in an archive. To save and install the script, perform the following steps:

  1. Log in to the command line.
  2. Change directories to the /sbin directory, by typing the following command:

    cd /sbin

  3. Create a file named restart, by typing the following command:

    touch restart

  4. Using a text editor, such as vi or pico, edit the restart file.
  5. Place the following script into the restart file:
    #!/bin/sh
# restart script - stick this in /sbin
bigpipe summary >/var/log/summary.`date +%d%m%y%H%M`
bigpipe ms >/var/log/ms.`date +%d%m%y%H%M`
echo ''Reboot by /sbin/restart at `date +%d%m%y%H%M`'' >/var/log/bigip
/bin/sync;/bin/sync
/sbin/reboot
  6. Save the file and exit the editor.
  7. Make the restart file executable, by typing the following command:

    chmod +x /sbin/restart

Now, instead of using the reboot command to reboot, execute the /sbin/restart command. The script contained in the restart file will run and save the bigpipe summary and bigpipe ms output to the /var/log directory and then reboot the system.
