K11903008: ''show running-config'' or ''list security'' commands freeze

Type
Support Solution
Published
2019-11-28
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.X.X, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.3
Source
https://my.f5.com/manage/s/article/K11903008

Description

The BIG-IP command line will hang with following commands

  • tmsh show running-config
  • tmsh show running-config security
  • tmsh show running-config security presentation tmui virtual-list
  • tmsh list
  • tmsh list security
  • tmsh list security presentation tmui virtual-list
     

Environment

  • BIG-IP version 15.x.
  • ASM provisioned 
  • AFM or Herculon DDoS Hybrid Defender is licensed but NOT provisioned.

Cause

ID 818309
 

Recommended Actions

  • Use more options with show running-config, list security.  
    ? after the command will show further options, for example:
    tmsh show running-config ?
    tmsh list security ?
    tmsh list ?
     
  • You can workaround this issue by provisioning AFM.

Additional Information

None
