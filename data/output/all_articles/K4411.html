To remove all configuration settings and restore factory settings, perform the following procedures:

Configuring a network boot server
Reinstalling BIG-IP system software

Configuring a network boot server

To configure a network boot server, perform the following procedure:

  1. Locate a PC to use as a network boot server. The PC must meet the criteria outlined in K3469: Hardware requirements for the BIG-IP network boot server.

  2. Connect the network boot server to the same network to which the BIG-IP's admin interface is connected.

    Important: You must use only the BIG-IP admin interface for network installation.

    Note: If you connect the network boot server directly to the BIG-IP management interface, you must use an Ethernet cross-over cable.

  3. Insert the CD into the CD-ROM drive of the network boot server.

    Note: The CD being used is the one created from the ISO image of the BIG-IP software that was downloaded. Refer to the release notes for information about downloading the ISO image. Refer to your CD application manual for information about creating a CD from an ISO image.

  4. Reboot the network boot server.

  5. Unless you know you need to use a different terminal type, enter vt100 when prompted for the terminal type.

    BIG-IP displays a menu similar to the following:

    Select installation option: Serve   Provide network installation servicesInstall   Install software onto hard diskReboot   Reboot systemExit   Exit to maintenance shell

  6. Type S to select Serve.

  7. Press Enter.

  8. If prompted, select the network interface to use for the network boot server. Choose the interface that is connected to the same network as the BIG-IP management interface.

  9. When prompted, choose your existing DHCP server or the network boot server to act as a DHCP server. For this choice, use the following guidelines:

    • If you have an existing DHCP server on the subnet that you want to use, type yes. The server configuration will complete automatically.

      Once configured, proceed to step 15.

    • If you do not have an existing DHCP server that you want to use, type no and follow the prompts to enter addresses for use with DHCP.

      Once configured, proceed to step 10.

  10. When prompted, use the following criteria to enter the IP network that you want to use with the DHCP server:
     

    • If you are connected to an existing network, choose an IP address range that is compatible.

    • If you are not connected to an existing network, use the default address range.

  11. When prompted, use the following criteria to enter the IP address that you want to use for the network boot server:

    • If you are connected to an existing network, choose a compatible IP address that is not already in use.

    • If you are not connected to an existing network, use the default IP address.

  12. When prompted, use the following criteria to enter the lowest IP address that you want available for BIG-IP to use during the installation process.

    • If you are connected to an existing network, choose a compatible IP address that is not already in use.

    • If you are not connected to an existing network, use the default IP address.

  13. When prompted, use the following criteria to enter the highest IP address that you want available for the BIG-IP system to use during the installation process.

    • If you are connected to an existing network, choose a compatible IP address that is not already in use.

    • If you are not connected to an existing network, use the default IP address.

    The BIG-IP system will display the settings that you have chosen.

  14. If the settings are correct, press Enter to continue.

    If there is an error in the settings, type no and press Enter and return to step 8.

  15. When prompted to choose the installation protocol, select HTTP.

    The configuration of the network boot server is now complete and you will be placed in a shell. The system will display the following messages:

    Server ready for installationsbash: no job control in this shell

Reinstalling BIG-IP system software

To reinstall the system software, perform the following steps:

  1. Enable network boot on the BIG-IP as described in K3525: Configuring SCCP-based BIG-IP platforms to boot from a network boot server.

  2. Reboot BIG-IP, by typing the following command:

    reboot

  3. Unless you know you need to use a different terminal type, enter vt100 when prompted for the terminal type.

    BIG-IP displays an information screen.

  4. Read the information screen and press Enter to continue.

    BIG-IP displays a copyright screen.

  5. Read the copyright screen and press Enter to continue.

    BIG-IP displays a warning page.

  6. Read the warning page. If you want to continue, type Y.

    BIG-IP displays a syslog configuration page.

  7. If you have an existing syslog server and you want to send system messages to that server during the installation process, enter the IP address of the syslog server when prompted.

    If you do not want to use a remote syslog server, press Enter to continue.

    BIG-IP displays an image selection page.

  8. When prompted to specify another installation path, type N.

    BIG-IP displays a slot configuration page.

  9. Use the S key to toggle between slots and select the slot for the disk device on which you want to install the system software.

    Note: Unless you have a specific reason to do otherwise, install the system software on the slot that is currently in use.

  10. When you have selected the desired slot, use the tab key to select OK and press Enter.

    BIG-IP displays an action selection page.

  11. When prompted, type I to proceed with installation.

  12. Use the tab key to select OK and press Enter.

    BIG-IP returns you to the slot configuration page.

  13. Type D to continue with the installation process.

  14. Use the tab key to select OK and press Enter.

    BIG-IP displays a summary of the selections that you made.

  15. Press Enter to continue.

    BIG-IP displays a final warning page.

  16. If you want to continue with the installation and erase your current configuration, type Y.

    The installation will proceed.

  17. When prompted, press Enter to reboot the system.
