Topic

Attack signatures are rules or patterns that identify attack sequences or classes of attacks on a web application and its components. F5 regularly releases new updates for attack signatures, including new attack signatures and enhancements to existing attack signatures. To ensure that you protect your applications against new attacks, F5 recommends you regularly update attack signatures.

Use the searchable table on the Attack Signatures page on F5 Cloud Docs for details about attack signatures that are used with the following products:

  • BIG-IP ASM
  • Advanced WAF
  • F5 Essential App Protect (EAP)
  • NGINX App Protect (NAP)
  • F5 Distributed Cloud

Description

How to filter your search using the table on the Attack Signatures page

F5 regularly updates the attack signatures table, which lists all available attack signatures by default. You can narrow the signatures that display using the Search table box. You can use the following types of search strings.

Search categoryExample search string
Signature IDYou can search by the attack signature ID using an exact or partial matching string. For example, you enter 200101375 for an exact match or 1375 for a partial match.
Name/at-risk systemFor example, to display all the jQuery-related entries, you enter jQuery as your search string.
Attack typeFor example, to display all the attack signatures related to cross-site scripting (XSS), you enter XSS.
Security referencesYou can search using a CVE number. For example, you enter CVE-2016-3081 to locate the CVE in the Security References column.
Announcement dateTo search for an attack signature updated within a certain period, use the <year>/<month> format in the search box. For example, you enter 2021/03.
