Topic

This article lists the common third-party software applicable to BIG-IP Next Central Manager. For information about the full list of third-party software used in the latest versions of BIG-IP Next Central Manager, refer to the following:

  • BIG-IP Next Central Manager

For information about third-party software used in BIG-IP Next, refer to the K000141141: BIG-IP Next third-party software matrix.

Description

The following matrices list the common third-party software that are installed/used in the HostOS and/or the pods/containers on the BIG-IP Next Central Manager system.

Important: F5 patch releases may include upgrades and security fixes for the third-party software packages listed in the following table. As a result, when you evaluate vulnerability status for third-party software, F5 recommends that you refer to security advisory articles to determine if a BIG-IP Next Central Manager release is vulnerable.
