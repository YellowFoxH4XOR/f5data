Known Issue

An error message occurs when activating a utility license key with the Pool License option. This message appears similar to the following example:

License activation failed: License is not a valid pool license

This issue occurs when all of the following conditions are met:

  • You attempt to install a utility license using the Licenses option in the BIG-IQ UI.
  • You select the Add New Pool License option instead of the Add New Utility License option.
  • You copy the utility license key into the Base Registration Key section and activate.

Impact

You cannot use the new utility license until you contact F5 Support.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You attempt to install a new utility license using the BIG-IQ UI and receive the following error message:

    License activation failed: License is not a valid pool license

Workaround

To work around this issue, you can contact F5 Support and request an Allow-Move procedure. Ensure that you choose the Add New Utility License option when relicensing.

For more information about managing license pools, refer to the BIG-IQ Device: Device Management guide.
