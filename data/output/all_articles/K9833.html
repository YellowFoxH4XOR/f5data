Known Issue

This is the result of a known issue. Connection table entries mirrored between an active and a standby VIPRION system may be lost if one or more blades bounce, which is the transition from an up/down to an up/down state. This behavior may result in inconsistent connection table entries between the active and the standby system.

F5 Networks Product Development tracked this issue as CR101304 and it was fixed in BIG-IP LTM version 10.0.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue has been fixed in hotfix-BIGIP-10.0.0-5460.0-HF1 issued for BIG-IP version 10.0.0, for the 10.x software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.
