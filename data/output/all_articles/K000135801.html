Description

When using the Closed Circuit Network (CCN) licensing tool to generate a license for an F5OS unit, a CCN dossier is required and that command is not included in the F5OS environment yet.

Environment

  • CCN Licensing Tool
  • F5OS

Cause

CCN Licensing requires a special kind of dossier.

 Recommended Actions

Use the below shell script to generate the required dossier.  Copy it to the F5OS system as user root, run 'chmod +x <name of script>', and invoke it, passing the base registration key as the first argument.  Copy / paste the output into the CCN licensing tool as the dossier.

#!/bin/bash


if [ $# -lt 1 ]; then
     cat >&2 <<EOF
Usage: $0 <base registration key>
EOF
     exit 1
fi

REGKEY=$1

docker exec -i system_license_service get_dossier -b "$REGKEY" -d | while IFS= read -r line; do
     [[ "$line" = *=* ]] || continue
     key=${line%=*}
     value=${line#*=}
     case "$key" in
         bios_id)
             key=F5_BIOS_ID
            ;;
         mac)
             key=F5_MAC
             ;;
         probes)
             key=F5_PROBES
             ;;
         version)
             key=F5_VERSION
              ;;
         *)
             continue
             ;;
     esac
     echo "$key=$value"
done

# Match (lower)case of what F5OS software uses when showing the UUID

UUID=$(cat /sys/class/dmi/id/product_uuid | tr A-Z a-z)
echo "F5_SYS_UUID=$UUID"
echo "F5_KEY=$REGKEY"
