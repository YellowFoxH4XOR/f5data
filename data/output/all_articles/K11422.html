Issue

In the event that the Active Directory AAA server that is configured to authenticate users is not accessible to BIG-IP APM, users may receive the following error message:

The username or password is not correct. Please try again. (error: A service is not available that is required to process the request, principal name: <username>@<domain>. Please verify Active Directory and DNS configuration.)

The first part of the error message may mislead users into thinking that they had incorrectly submitted their credentials. In fact, this error message indicates that the BIG-IP APM was unable to establish a connection with the authentication server. If users are reporting this error message, confirm that the Active Directory AAA server is accessible to the BIG-IP APM.

The system logs corresponding log message to the /var/log/apm file at the time of the event.

For example:

err apd[<pid>]: 01490107:3: <session ID>: AD module: authentication with '<username>' failed in krb5_get_init_creds_password(): A service is not available that is required to process the request, principal name: <username>@<domain>. Please verify Active Directory and DNS configuration. (-1765328355)
