Topic

The BIG-IP APM system supports the Static Hosts feature when using Windows, MacOS X, and Linux client systems for Network Access.

Description

When you configure static host entries in the Network Access configuration, the BIG-IP APM system dynamically adds the host entries to the /etc/hosts file on Linux and Mac OS X client systems and the \windows\system32\drivers\etc\hosts file on Windows client systems.

Recommendations

When configuring the Static Hosts feature, you should consider the following factors:

  • For Windows systems, if the DNS Relay Proxy component is currently installed, administrative rights are not required. If the DNS Relay Proxy component is not installed, administrative rights are required.
  • For MacOS X systems, administrative rights are required.
  • For Linux systems, root or admin user account privileges are required.
