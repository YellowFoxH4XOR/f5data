Known Issue

Modified custom provisioning ratios are not retained.

This issue occurs when all of the following conditions are met:

  • You use the Traffic Management Shell (tmsh) to configure custom resource provisioning.
  • You attempt to modify the custom provisioning values using the Configuration utility.

Impact

Modifications made using the Configuration utility are not implemented.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the Configuration utility to modify custom provisioning values, the screen refresh displays the original provisioning values after the changes are submitted.

Resolution

Status

Workaround

To work around this issue, you can use the tmsh utility to modify the custom provisioning values.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
