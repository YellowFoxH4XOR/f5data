Applies to

Source
https://my.f5.com/manage/s/article/K000133504

Description

You are receiving an error message similar to the one below when after a BIG-IQ DCD snapshot fails:
[ERROR][10 Apr 2023 00:00:00 BST][/cm/shared/esmgmt/es-snapshot-task/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/worker ESSnapshotTaskWorker] Data Collection snapshot failed to complete.

[ERROR][10 Apr 2023 00:00:00 BST][/cm/shared/esmgmt/es-snapshot-task/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/worker ESSnapshotTaskWorker] Data Collection snapshot failed to complete.

[WARN][10 Apr 2023 00:00:00 BST][/cm/shared/event/alerts AlertCollectionWorker] Data Collection device data snapshot dcd_snapshot_version#.#.#_2023-04-10t00-00-00.000z has failed because Data Collection snapshot failed to complete.

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • Versions prior to 7.1
 

Cause

Unknown

Recommended Actions

Run the following command in the bash terminal:
tmsh start sys service tokumond elasticsearch tokumx

Or upgrade to 7.1 or later.

Additional Information

None
