Description

After upgrading a BIG-IP LTM hardware device and rebooting, administrative access via SSH and GUI is lost. Access using the serial console and local admin account remains possible, but remote authentication services (such as Active Directory) are unavailable. Attempts to restart management services (sshd, httpd, tomcat, restjavad) do not restore access.

Environment

  • BIG-IP LTM
  • iSeries i2000, C117

Cause

Hardware faults related to disk or power supply issues can cause loss of administrative access after an upgrade:

  • Disk full errors during installation may indicate underlying storage problems. /var/log/liveinstall.log can write an error as below:
    error: tm_install::Process::Process_full_install -- predicted size for BIGIP1751 is 15387024 and vg has 11149312 remaining. 
    Terminal error: Disk full (volume group). See SOL#10636
  • The /var/log/kern shows possible issues with HDD:
    hostname.com warning kernel: EXT4-fs (dm-0): warning: maximal mount count reached, running e2fsck is recommended
  • The /var/log/platform_check shows possible issues with authentications:
    00e4 07/28/21 09:46:01 INF Authentication Fail Event for SSH/LAN/LAN+, User ID ZxZZ, IP Address x.x.x.x

Recommended Actions

Try to obtain a fresh QKView file via the serial console cable and provide it to the F5 support for further investigation. There may be a possible RMA procedure to be opened.

Additional Information

While this issue is in place, once you log in to the device using the serial console cable, you can run the "tailf /var/log/secure" command and force a login attempt via SSH to see if any errors or authentication failures appear. If not, most probably there can be a hardware issue in place.
