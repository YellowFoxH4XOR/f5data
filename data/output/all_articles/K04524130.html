K04524130: Cannot delete a running task

Type
Support Solution
Published
2022-09-23
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K04524130

Description

  • Delete a running task fails in BIG-IQ
  • Using 'restcurl -X DELETE <self-link>'
  • Error "code": 400, "message": "Cannot delete a running task"

Environment

  • BIG-IQ 
  • task "status": "CANCEL_REQUESTED"

Cause

Undetermined

Recommended Actions

Perform the below steps to set the task to FINISHED before deleting
  1.  use PATCH command and set the task to a failed status: 
     restcurl -X PATCH /shared/user-script-execution/<task id> -d '{"status": "FINISHED","generation": 0}'
  2.  Now try to delete the task: 
     restcurl -X DELETE /shared/user-script-execution/<task id>
  3.  If this works, repeat step 1 & 2 for the remaining tasks

Additional Information

None
