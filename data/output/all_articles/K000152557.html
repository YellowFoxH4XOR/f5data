Description

  • After you perform software upgrade you observe that the configuration is failing due to below error message.
    01020036:3: The requested parent profile (/Common/serverssl) was not found.
  • You have not made any changes to the default profile.

Environment

  • BIG-IP
  • Software upgrade

Cause

None

Recommended Actions

In the upgraded software version, copy paste definition/settings/configuration of "ltm profile server-ssl serverssl" from /defaults/profile_base.conf to /config/bigip.conf. Then load the configuration by entering below command.

tmsh load sys config

Additional Information

Below is the default profile in version 16 and 17. You can verify the same on your BIG-IP by using below command.

less /defaults/profile_base.conf | grep -w "ltm profile server-ssl serverssl " -A27

ltm profile server-ssl serverssl {
    alert-timeout indefinite
    authenticate once
    authenticate-depth 9
    authenticate-name none
    ca-file none
    cache-size 262144
    cache-timeout 3600
    c3d-cert-extension-includes { basic-constraints extended-key-usage key-usage subject-alternative-name }
    cert none
    chain none
    ciphers DEFAULT
    crl-file none
    handshake-timeout 10
    key none
    mod-ssl-methods disabled
    mode enabled
    options { dont-insert-empty-fragments no-tlsv1.3 no-dtlsv1.2 }
    passphrase none
    peer-cert-mode ignore
    renegotiate-period indefinite
    renegotiate-size indefinite
    renegotiation enabled
    secure-renegotiation require-strict
    strict-resume disabled
    unclean-shutdown enabled
    log-publisher /Common/sys-ssl-publisher
}
