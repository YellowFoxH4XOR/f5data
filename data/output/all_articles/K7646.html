Known Issue

This is the result of a known issue. The pam_ldap, which is the Pluggable Authentication Module (PAM) for LDAP authentication, does not properly handle referrals returned by the LDAP server. This issue may result in a race condition that leads to a reset of the tamd process, which controls the module.

Note: This issue only affects systems that are using LDAP for remote authentication.

F5 Product Development tracked this issue as CR67721 and CR67719 and it was fixed in BIG-IP 9.1.3, 9.3, and 9.4. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller Release Notes.
