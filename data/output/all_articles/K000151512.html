K000151512: How to reboot velos system

Published
2025-05-24
Updated

Source

Description

  • You may want to reboot Velos controller or blade in some situations.
  • You can reboot Velos controller or blade from WebGUI or CLI

 

Environment

Velos

 

Cause

  • You may want to reboot Velos controller, partition, or blade in some situations.

Recommended Actions

  • Reboot controller
    • WebGUI (Controller)
      • Login to WebGUI > System settings > General > System Controllers > Select controller as you want to reboot
    • Command line, confd (Controller)
      • system reboot controllers controller <active/standby>
  • Reboot blade
    • WebGUI (Partition)
      • Login to WebGUI > System settings > General > Slots > Select slot as you want to reboot
    • Command line, confd (Partition)
      • cluster reboot <all/node(single blade)/nodes(multiple blades)>
  • Verify after rebooting
    • Controller confd command line
      • show cluster
    • Partition confd command line
      • show system detail
