Description

Google not finding website when searching. Site not listed in search results.

Bot Defense logs occasionally show:

Search Engine Verification Failed.
The system detected a bot that presented as a known search engine. Source IP Address reverse DNS checked failed.

 

Environment

  • Bot Defense Profile

Cause

Search Engine verification failing due to incomplete DNS Resolver configuration.

Recommended Actions

Refer to the example in the following article to configure the DNS Resolver correctly and verify connectivity to the DNS resolver:

  • K31002850: ASM Bot Defense Search Engine Verification Failed

You may also check the resolver stats, using:

tmsh show net dns-resolver </Partition/dns-resolver_name>

None
