K000154620: Unable to Install ASM Attack Signature Live Update on BIG-IP v17.1.2 and later

Type
Support Solution
Published
2025-09-05
Updated
2025-09-05
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.X, 17.1.2, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000154620

Description

On BIG-IP systems running version v17.1.2 and later, administrators may encounter an issue where the ASM attack signature Live Update installation fails.


Attempts to install the update result in timeout errors (default ~1 hour) and messages such as:


- Could not look up currently installed file

- Live Update file could not be loaded

- Could not calculate staging data for installation: Live Update file could not be loaded


The problem can occur even following documented recovery steps such as rebuilding the Live Update database (per K91518607)


Environment

Versions: v17.1.2 onwards

Provisioning: ASM and FPS provisioned


Cause

This behavior is likely caused by Bug ID 1819617:


A stalled Fraud Protection Service (FPS) signature/engine update task prevents ASM from completing attack signature Live Update or Apply Policy operations.


Even if FPS is provisioned but not actively in use (no FPS profiles applied), the background FPS update task may interfere with ASM Live Update.


Recommended Actions

1. Confirm the stalled FPS update process


lsof /var/ts/lock/sigfile_update.lock


Example output:


update_fp 20259 root 3wW REG 253,12 0 188769 /var/ts/lock/sigfile_update.lock


2. Terminate the stalled process


kill <PID>


Replace <PID> with the process ID shown for update_fp.


3. Re-attempt the ASM Live Update installation.


4. Permanent workaround


If FPS functionality is not required in your environment, de-provision FPS to prevent recurrence.
