Description

Unable to block upload of executable files.

Environment

  • Added '.exe' to the Disallowed file types
  • Enforcement mode is Blocking
  • Violation 'Illegal File Type' enabled

Cause

The Disallowed filetypes is used for the when files are being downloaded. Hence, when the executable file is uploaded, ASM doesn't recognise it.

For upload, the configuration is different and requires other entities to be configured.

Recommended Actions

To disallow ASM from uploading executable, refer to article K64356849: Configuring the BIG-IP ASM system to block file uploads containing binary executable content
