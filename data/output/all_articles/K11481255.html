Known Issue

An imported access policy with a branch rule caption of none might fail.

This issue occurs when the following condition is met:

  • You import an access policy that contains a virtual policy editor (vpe) branch rule caption of none.

Impact

After the import, you cannot open or edit the access policy.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot open or edit the access policy after import.

Resolution

Status

F5 Product Development has assigned ID 438548 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

There is no work around for this issue; however, you can prevent the issue by renaming all branch rules with a caption of none before you export an access policy.
