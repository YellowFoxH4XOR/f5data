Known Issue

The BIG-IP system startup script may fail to update Certificate Revocation List (CRL) files.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to run a startup command using the /config/startup file.

    Note: For more information, refer to K11948: Configuring the BIG-IP system to run commands or scripts upon system startup.

  • The startup command attempts to update a CRL file using the following command syntax:

    tmsh modify sys file ssl-crl <name> source-path http://<url_path>

Impact

The BIG-IP system is unable to update the CRL file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system does not update the CRL file.
  • The BIG-IP system logs error messages in the /var/log/ltm file that appear similar to the following example:

    err mcpd[2345]: 01070712:3: Caught configuration exception (0), file(/var/tmp/tmsh/7QjLFt/data) expected to exist. - sys/validation/FileObject.cpp, line 3151.
    err tmsh[6789]: 01420006:3: 01070712:3: Caught configuration exception (0), file(/var/tmp/tmsh/7QjLFt/data) expected to exist. - sys/validation/FileObject.cpp, line 3151.

Workaround

To work around this issue, you can modify the command syntax and use a local file. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. From your desktop workstation, use the Secure Copy (SCP) protocol to transfer the CRL file to the /shared/tmp directory of the BIG-IP system.
  2. Log in to the Advanced Shell (bash) of the BIG-IP system.
  3. To update the current CRL file, use the following command syntax:

    tmsh -m install sys crypto crl <name> from-local-file <path>

    For example, to update a CRL file named example.crl from the updated.crl local file, type the following command:

    tmsh -m install sys crypto crl example.crl from-local-file /shared/tmp/updated.crl.

  4. To save the configuration, type the following command:

    tmsh save sys config
