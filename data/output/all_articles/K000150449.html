Description

At times you may wish to explore the inside of a running pod.

You can start a shell, but debug tools are missing.

Environment

A kubernetes cluster.

Cause

This is by design. Containers are built on minimal images.

This reduces attack surface and make them smaller and thus faster to deploy.

Recommended Actions

Kubernetes has the ability to launch an ephemeral container into an existing pod.

This can have any required debugging tools.

This example is a version of F5's NGINX Ingress Controller product.

We want to inspect it then get a tcpdump.

The pods wont share its process namespace to other containers by default. ( even with --share-processes set in the debug). This is set by an option in the deployment.

Find the deployment and patch it.

 

# kubectl get deploy -A | grep ingress-con

ingress    kic-371-nginx-ingress-controller  1/1   1      1      29m

 

Using the deployment name we patch it.

 

kubectl patch deployment kic-371-nginx-ingress-controller -n ingress --patch '
spec:
 template:
  spec:
   shareProcessNamespace: true'

This is idempotent and harmless.

 

Find the pod name. In this case we know that all these pods are labeled with app.kubernetes.io/name=nginx-ingress.

Quickly find the name and namespace.

 

# kubectl get pod -A -l app.kubernetes.io/name=nginx-ingress

NAMESPACE  NAME                        READY  STATUS  RESTARTS  AGE

ingress   kic-371-nginx-ingress-controller-6d975bbf5f-bbx4b  1/1   Running  0     15m

 

We can now attach a debug image. busybox is a minimal image. This starts a shell because we don't give an explicit command to run.

 

# kubectl debug kic-371-nginx-ingress-controller-6d975bbf5f-bbx4b -n ingress --share-processes -it --image=busybox

--profile=legacy is deprecated and will be removed in the future. It is recommended to explicitly specify a profile, for example "--profile=general".

Defaulting debug container name to debugger-9s5kf.

If you don't see a command prompt, try pressing enter.

netstat is available but tcpdump is not. For that and more complete tools, use nicolaka/netshoot

kubectl debug kic-371-nginx-ingress-controller-6d975bbf5f-bbx4b -n ingress -it --share-processes --image=nicolaka/netshoot -- tcpdump -i eth0 -w - udp

 

This runs tcpdump inside the controller pod, filtering for udp and sends the data to stdout.

So redirect to a pcap file!
