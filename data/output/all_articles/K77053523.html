K77053523: BIG-IQ VE didn’t send any audit logs to syslog server

Type
Support Solution
Published
2021-07-07
Updated
2026-11-11
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K77053523

Description

Configured Audit Log Syslog servers but failed to send audit logs to external syslog servers

Environment

  • BIG-IQ Central Management
  • BIG-IQ Data Collection Device
  • BIG-IQ Version 7.1.0
  • Audit log syslog servers

Cause

By design, it is not supported.

Recommended Actions

Important: You can only configure two remote syslog servers for a device.

  1. Sending Logs from /var/log/audit (logs whenever a user logs in or fails to login) to external syslog is not support for BIG-IQ DCD.
  2. Only audit logs showing in BIG-IQ CM GUI MONITORING Tab > AUDIT Logs can be sent to external syslog server.
