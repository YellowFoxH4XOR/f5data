Description

When configuring a BIG-IP virtual server with a fastL4 profile that has Loose Initiation enabled, a warning message similar to the following is displayed:

Warning
Loose Initiation and SYN Challenge Handling are both currently enabled.
These two features are mutually incompatible and may cause crashing.

You are concerned that disabling SYN cookie protection will impact virtual server performance

Environment

  • BIG-IP
  • fastL4 profile
 

Cause

The BIG-IP system by default is configured with SYN cookie protection enabled.

Recommended Actions

Disabling SYN cookie protection will not impact virtual server performance.
However, disabling SYN cookie protection will no longer guard the BIG-IP and virtual servers against SYN flood attacks. 
SYN cookies allow the BIG-IP system to maintain connections when the SYN queue begins to fill up during an attack.
