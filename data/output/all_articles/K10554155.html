Description

You want to use an iRule to log DNS resolution details.

Environment

  • iRule
  • BIG-IP DNS/GTM
  • Wide IP
  • Listener

Cause

None

Recommended Actions

You can attach an LTM iRule to a listener or a DNS iRule to a Wide IP using the following methods:

Impact of procedure: Enabling the following iRules will generate verbose log output to the /var/log/gtm file. You should only leave the iRules enabled while you are gathering troubleshooting data.

  • Create an LTM iRule using DNS::question, DNS::answer, IP::client_addr and DNS::origin
  • Create a DNS iRule using DNS::rrtype, DNS::rrname and IP::client_addr

Create a BIG-IP LTM iRule using DNS::question and DNS::answer, IP::client_addr and DNS::origin

Note: The DNS_RESPONSE event triggers only in the context of LTM iRules.

ltm rule ltm_log {
   when DNS_REQUEST {
      log local0. "LTM irule: DNS Requests [DNS::question name] with record type of [DNS::question type] seen from [IP::client_addr]"
   }
   when DNS_RESPONSE {
      log local0. "LTM irule: Client answer was provided by [DNS::origin], with the full response of [DNS::answer]"
   }
}

You may refer to the link DNS::question,  IP::client_addr, DNS::answer and DNS::origin on F5 Cloud Docs for more details.

Create a BIG-IP DNS iRule using DNS::rrtype, DNS::rrname and ip::client_addr

Note: DNS iRules are created under DNS >> GSLB >> iRules, and are not visible to the LTM module.

gtm rule gtm_log {
   when DNS_REQUEST {
      log local2. "GTM irule: A client [IP::client_addr] queried [DNS::rrname] with request type of [DNS::rrtype]"
   }
}

For the detailed iRules command return values,  you may refer to the link DNS::rrtype, DNS::rrname and IP::client_addr on F5 Cloud Docs.

    Additional Information

    • You may use the following command to test DNS query:

    dig <record name> @<listener_adress> <record type>

    • To monitor the /var/log/gtm log on the BIG-IP DNS command line, enter the following command:

    tail -f /var/log/gtm

    • Logs similar to the following will be recorded to /var/log/gtm: 

    info tmm[<PID>]: Rule /Common/ltm_log <DNS_REQUEST>: LTM irule: DNS Requests <Returns the resource record name requested by the client> with record type of <Returns the resource record type requested by the client> seen from <Client IP address>
    info tmm[<PID>]: Rule /Common/gtm_log <DNS_REQUEST>: GTM irule: A client <Client IP address> queried <Returns the resource record name requested by the client> with request type of <Returns the resource record type requested by the client>
