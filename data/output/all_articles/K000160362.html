Description

This page provides guidance for onboarding the NGINX One Console for the Flex Consumption Program (FCP) and subscriptions. 

Environment

  • NGINX customer
  • MyF5 Customer Portal
  • Distributed Cloud Tenant
  • Admin role in NGINX One Console

Required Prerequisites [0 day]

  1. Log into the MyF5 Customer Portal.
  2. Confirm access to the active subscription for NGINX. If the NGINX subscription is missing, email SupportOne@f5.com to request access.
  3. If you have Distributed Cloud (NGINX One Console), verify you can logon to the Distributed Cloud tenant link in the F5 Distributed Cloud Services Console Package for Deployable Products section.
    1. If you cannot find your tenant information please email support@cloud.f5.com to get your username and TENANT_NAME.  
    2. Confirm you have admin access within the NGINX One Console.
  4. Register with F5 Notifications to receive security announcements.
  5. Keep up to date with NGINX Security Advisories.

Licensing [30 day]

  1. Watch a demo of the NGINX One Console to preview how it reports data analytics. 
  2. Confirm supported Linux versions.
  3. Deploy the latest NGINX version to ensure compatibility with NGINX One Console.
  4. Enable metrics on NGINX to view from the NGINX One Console.
  5. Add NGINX instances to the NGINX One Console.
  6. Ensure NGINX Configurations are healthy and without errors.
  7. Confirm license and reporting endpoints.

Resources

Managing and Reporting [30-60 days]

  1. Verify NGINX version of the NGINX instance.
  2. Upgrade NGINX to the latest version.
  3. Stay current with NGINX Updates and Releases.
