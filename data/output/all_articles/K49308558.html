K49308558: API Authentication failure on F5 LTM returning 400 error

Type
Support Solution
Published
2022-05-11
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K49308558

Description

  • Using AppviewX to perform node enable/disable activity on F5 LTM.
  • Getting failures while processing multiple requests.
  • F5 returns HTTP response code 400

Environment

  • LTM
  • Rest API
  • AppviewX

Cause

As of 13.1 the limit (100) of the number of tokens a given user can have active at one time is enforced.  When more than the number of tokens allowed is exceeded you will see in restjavad-audit.0.log the following messages:

[I][206236][17 Apr 2022 06:27:20 UTC][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"10.0.0.1"}
[I][206238][17 Apr 2022 06:27:21 UTC][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"10.0.0.1"}
[I][206239][17 Apr 2022 06:27:23 UTC][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"10.0.0.1"}
[I][206240][17 Apr 2022 06:27:24 UTC][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"10.0.0.1"}
[I][206243][17 Apr 2022 06:27:25 UTC][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"10.0.0.1"}
[I][206245][17 Apr 2022 06:27:27 UTC][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"10.0.0.1"}

Above logs confirms that AppviewX is not doing a proper token management to keep concurrent active tokens per user under 100.

Recommended Actions

AppviewX must utilize proper token management to keep concurrent active tokens per user under 100.
