Description
Using the TMUI (GUI) and trying to add an SNMP trap destination via TMUI, you get the message "An error has occurred while trying to process your request"

Environment

  • BIG-IP
  • Adding new SNMP trap destination IP that already exists

Cause
This is a known issue.

Bug ID 696363: Unable to create SNMP trap in the GUI
 

Recommended Actions

To check for this condition: 
# cat /var/log/ltm | grep -i 01020066:3
err mcpd[7898]: 01020066:3: The requested Config Instance (/Common/snmpd /Common/<x.x.x.x> trapsess) already exists in partition Common.

To work around this issue when using the GUI, remove all traps that have the same destination address as the new one that failed. Then re-add your destination.
