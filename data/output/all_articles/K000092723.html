K000092723: Post-CER TLS over SCTP limitation

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092723

Description

  • Post Capabilities TLS is not implemented in SDC code.
  • Post TLS means that the SSL starts only after receiving CEA from the server.

Environment

  • SDC 5.1

Cause

By design.

 Recommended Actions

None.

Additional Information

Pre-CER TLS over SCTP will be fixed and supported starting CF-30.
