Known Issue

The BIG-IP system may fail to forward traffic across a Virtual eXtended LAN (VXLAN) tunnel.

This issue occurs when all of the following conditions are met:

  • The VXLAN tunnel is configured with the same local endpoint address as a previously configured VXLAN.
  • The flooding type is configured as multipoint or none.

Impact

Traffic is not forwarded across the VXLAN tunnel.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H484730 on the Diagnostics > Identified > High screen.
  • Traffic is not forwarded across the VXLAN tunnel.
  • Running tcpdump on the affected VXLAN returns an error similar to the following example:

    tcpdump: pcap_loop: Device <second VXLAN tunnel> not found

Resolution

Status

Workaround

If upgrading is not an option, you can work around this issue by using a different local endpoint address when creating multiple VXLAN tunnels.
