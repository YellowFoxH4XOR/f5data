Known Issue

The BIG-IP system incorrectly reports virtual server CPU usage statistics.

This issue occurs when one of the following conditions is met:

  • You view virtual server CPU statistics using the TMOS Shell (tmsh) show ltm virtual command.
  • You view virtual server CPU statistics using the tmctl virtual_server_cpu_stat command.
  • You view virtual server CPU statistics using the Configuration utility by navigating to Statistics › Module Statistics : Local Traffic  › Virtual Servers.

Impact

Each BIG-IP LTM virtual server may appear to be using a greater percentage of system CPU cycles than they actually use.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The average CPU usage percentage reported per BIG-IP LTM virtual server is slightly higher than the actual percentage of system CPU cycles that each virtual server uses.
  • If you want to find out the average percentage of CPU used per BIG-IP LTM virtual server, you can get the information by using the tmsh show ltm virtual and tmctl virtual_server_cpu_stat commands, and also by navigating to Statistics  ›  Module Statistics : Local Traffic  ›  Virtual Servers in the Configuration utility. The average CPU usage values reported by these commands incorrectly includes Traffic Management Microkernel (TMM) idle cycles in the calculations, which causes a slight over-reporting of the average per-virtual-server CPU usage.
