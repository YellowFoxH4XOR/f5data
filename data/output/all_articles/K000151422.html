Description

After upgrading to a new version, users may experience intermittent or persistent issues accessing both the GUI and CLI. The GUI becomes unresponsive (TCP connection is established, but the web page does not load), and SSH access to the CLI hangs after running a single command or immediately after login. File transfers using SCP/SFTP may fail, and commands in Bash or TMSH can hang or crash mid-output.

Example errors: 

From the LTM log (/var/log/ltm):

Timeout, server <hostname> not responding.

or 

File transfer stuck:

scp <hostname>:<path> <hostname>:<path>/<filename>

0%          0          0.0KB/s              --:-- ETA

Environment

  • BIG-IP LTM VE

Cause

The issue is caused by a network connectivity problem in the underlying infrastructure, specifically a reduced MTU setting below 1500 bytes. This can result in packet fragmentation or loss that disrupts SSH/CLI sessions and HTTP(S) connections to the management GUI.

Recommended Actions

Please follow these steps to troubleshoot and resolve the issue:

1. Verify MTU settings on all relevant network interfaces for affected BIG-IP VMs and ensure they are set to at least 1500 bytes.

2. Check with your cloud provider or virtualization platform for any recent changes affecting MTU size or other network parameters.

3. Investigate other potential network issues, such as duplicate MAC addresses, which can also cause similar symptoms.
