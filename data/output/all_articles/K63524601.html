K63524601: Virtual server connecting to wrong pool port

Description
The virtual server is connecting to the pool member on a port different from the port specified in the pool.

Environment

  • A Standard Virtual Server with a pool configured
  • The Virtual Server destination port and the pool member ports are different

Cause
In the Virtual Server the option "Translate Port" is disabled. This option is an Advanced option and  is enabled by default.

Recommended Actions
Set "Translate Port" to enabled.

Additional Information
When disabled, if there is a Virtual server set for TLS offload (has a Client-SSL profile and no Server SSL profile) it will attempt to connect to a pool member on port 443, even though the pool is configured for port 80. "Translate Port and Translate Address" are disabled when using a forwarding virtual server.
