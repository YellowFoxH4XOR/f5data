Summary

Common Criteria Certification for BIG-IP 17.5.0

Description

CSEC has certified the following:

  • BIG-IP LTM+AFM 17.5.0 for Common Criteria against the Network Device collaborative Protection Profile and collaborative Protection Profile Module for Stateful Traffic Filter Firewalls
  • BIG-IP LTM+APM 17.5.0 for Common Criteria against the Network Device collaborative Protection Profile
  • BIG-IP LTM+SSLO 17.5.0 for Common Criteria against the Network Device collaborative Protection Profile and PP-Module for SSL/TLS Inspection Proxy

For more information about the Security Target and related information, refer to the following CSEC and NIAP websites:

    • LTM+AFM Certificate
    • LTM+APM Certificate
    • LTM+SSLO Certificate
    • LTM+AFM NIAP PCL listing
    • LTM+APM NIAP PCL listing
    • LTM+SSLO NIAP PCL listing

Common Criteria is an international initiative to standardize security functionality and assurance measures. For more information about Common Criteria Certification, refer to the following Common Criteria website:

https://www.commoncriteriaportal.org

Note: This document, along with the Common Criteria Guidance Supplement, provides guidance on the secure installation and secure use of the Target of Evaluation (TOE) for the evaluated configuration. These documents provide clarifications and changes to the standard documentation and should be used as the guiding documents for the configuration and administration of the TOE in the Common Criteria evaluated configuration. Official product documentation should be referred to and followed only as directed within these guiding documents.

Installation

To install the BIG-IP system in accordance with the evaluation's expectations, refer to the following document:

    • BIG-IP Common Criteria Evaluation Configuration Guide

This document contains information on ensuring that you have the correct software version of the BIG-IP system as well as describing how to configure that system to be Common Criteria-compliant. This document is included in the ISO files described below.

Product Documentation

The following ISO files contain the product and guidance documentation for the 17.5.0 Common Criteria evaluation:

    • CommonCriteriaDocumentation-17.5.0.iso on F5 Downloads
    • CommonCriteriaDocumentation-17.5.0.iso.sha256 on F5 Downloads
    • CommonCriteriaDocumentationSSLO-17.5.0.iso on F5 Downloads
    • CommonCriteriaDocumentationSSLO-17.5.0.iso.sha256 on F5 Downloads

To verify the ISO file against the checksum, use the Linux sha256sum command with the --check option:

sha256sum --check CommonCriteriaDocumentation-17.5.0.iso.sha256

sha256sum --check CommonCriteriaDocumentationSSLO-17.5.0.iso.sha256
