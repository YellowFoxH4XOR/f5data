Known Issue

This is the result of a known issue. When the Microsoft Outlook Web Access S/MIME ActiveX control is loaded into Internet Explorer (IE), the reply and forward functions of OWA will fail when using a Portal Access favorite.

The Microsoft S/MIME ActiveX control allows email to be digitally signed and/or encrypted when using Outlook Web Access. The control is downloaded from the Options menu in OWA, under the E-mail Security section, and installed in IE.

If the FirePass controller's Portal Access mode is set to the most recent version of the Web Application engine (software version 6.0.2 and later), and a user with the S/MIME control loaded in IE attempts to send mail using OWA, the mail will not be sent and the following error message is reported in the email composition window:

One or more errors occurred while loading the message.
Error: (0x8000ffff): Catastrophic failure

When the FirePass controller's Portal Access mode is set to Compatibility Mode 2 (or the default Web Application engine in version 6.0.0 and 6.0.1), the composition window will either appear to do nothing indefinitely, or IE may display a script error icon. Clicking the icon will display an error message that appears similar to the following example, and the mail will not be sent:

Line: 82
Char: 116
Error: 'obj' is null or not an object

Note: The Portal Access Web Application engine's mode is configured under the Web Applications Global Settings section of the Portal Access: Web Applications: Content Processing page.

An error message will occur regardless of whether the options in the E-mail Security section of the user's OWA account are set for digital signing of the email, encryption of the email, both, or neither. Similarly, clicking off the digital signature and/or encryption buttons in the composition window will have no effect on this issue.

F5 Networks Product Development is tracking this issue as CR97313.

Workaround

Removing the Microsoft Outlook Web Access S/MIME ActiveX control from IE will enable an Microsoft Outlook Web Access user to send mail through Portal Access. The Microsoft Outlook Web Access S/MIME ActiveX control can be removed from the Windows Control Panel, using the selection to remove programs that come with the version of Microsoft Windows, such as the Add or Remove Programs option in Windows XP.

Important: Removal of the S/MIME control will prevent users from encrypting and digitally signing emails through Outlook Web Access, which may conflict with some organizations' security policies.
