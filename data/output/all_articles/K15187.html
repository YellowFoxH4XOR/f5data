Known Issue

The BIG-IP APM configuration may fail to load after you perform an upgrade.

This issue occurs when all of the following conditions are met:

  • The device is licensed as a BIG-IP APM standalone (BIG-IP APM is the only licensed module).
  • The BIG-IP APM license activation date is prior to 07/09/2013.
  • You did not re-activate the BIG-IP APM license prior to upgrading the system.
  • The BIG-IP APM license does not include the string perf_SSL_.

To determine whether the BIG-IP license is affected

  1. Log in to the command line of the BIG-IP APM device.
  2. Type the following command:

    egrep -i 'perf_SSL|Service check date' /config/bigip.license

    If the system does not return values with the perf_SSL_ syntax, or the Service check date is older than 20130709, then your license is not affected.

Impact

You are unable to load the BIG-IP APM configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you load the BIG-IP APM configuration using the Traffic Management Shell (tmsh), you may observe error messages similar to the following example.

    01070356:3: SSL feature not licensed.
    Unexpected Error: Loading configuration process failed.

Workaround

To prevent this issue, you can re-activate the license of the BIG-IP APM device before you upgrade the system.

To recover from this issue, after you upgrade, you can re-activate the license from the tmsh shell. To do so, perform the following procedure:

Impact of workaround: The BIG-IP APM license may require you to reboot the system to apply the new license. Additionally, this procedure requires that the BIG-IP APM system has outbound access to the Internet, and can perform DNS resolution. For BIG-IP APM devices that do not have Internet access, you can re-activate the license manually. For information, refer to K2595: Activating and installing a license file from the command line.

  1. Log in to the command line of the BIG-IP APM system, with administrative privileges.
  2. Type the following command to have the BIG-IP APM system access the F5 licensing server, and update the system license:

    tmsh install sys license
