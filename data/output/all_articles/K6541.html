K6541: A client may receive a message screen that reports the 'Illegal meta character in Language header' error

Topic

The BIG-IP ASM system is configured to accept a limited set of characters in HTTP headers, in order to prevent exploitation of security vulnerabilities through header manipulation. In some cases, BIG-IP ASM may block requests that contain a legitimate meta-character that is not included in the default configuration. When this occurs, you may receive the following error message:

Illegal meta character in Language header

You can configure BIG-IP ASM to accept the blocked meta-character in the future by performing the following steps:

  1. Log in to the Configuration utility.
  2. Navigate to Traffic Learning.
  3. Click Illegal meta character in header value.
  4. Select the Language header.
  5. Click Accept.

BIG-IP ASM will now allow the previously blocked meta-character in the Language header.

If you would like to allow the meta-character in all headers, you can add the meta-character to the global character set instead. Refer to the BIG-IP ASM Manual for more information.
