Known Issue

When you create a copy of a BIG-IP APM access profile, the profile may not include duplicate custom images.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration uses an access profile that includes two or more languages.
  • The same custom image is referenced by more than one of the languages configured in the access profile.
  • You create a copy of the access profile.
  • The original access profile is removed from the virtual server and replaced with the copy of the access profile.

Impact

The custom image fails to appear for all of the originally configured languages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The recently replaced access profiles fail to display custom images.

Workaround

To work around this issue, you can re-assign the custom image to the affected language of the access profile.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
