Topic

You should consider using this procedure under the following conditions:

  • Add, remove, or modify a DNS resolver object.
  • Add or remove forward zones for a DNS resolver object.
  • View the statistics for a DNS resolver object.

Description

The DNS resolver is a resolver cache that provides DNS resolver functionality for a variety of BIG-IP features and modules. For more information, refer to K12140128: Overview of the DNS resolver.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IP system.
  • For iControl REST, you should have command line access to a Linux system (or an alternate BIG-IP system) with the curl and jq (command line JSON processor) utilities installed.
  • The nameserver-ttl field was introduced in 16.1.0 and available only in tmsh. Attempts to use this field in versions prior to 16.1.0 will result in an error message in the tmsh command line. See also: https://my.f5.com/manage/s/article/K12140128

Procedures

  • Add a DNS resolver object
  • Modify the settings of a DNS resolver object
  • Remove a DNS resolver object
  • Add a forward zone to a DNS resolver object
  • Remove a forward zone from a DNS resolver object
  • View the statistics for a DNS resolver object

Add a DNS resolver object

You can use the Configuration utility, TMOS Shell (tmsh), or iControl REST to add a DNS resolver object on your BIG-IP system. To do so, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Network > DNS Resolvers > DNS Resolver List.
  3. Select Create.
  4. Enter a name for the Name setting and the desired size for the Cache Size setting; configure the remaining settings as desired. For more information about each setting, refer to K12140128: Overview of the DNS resolver.
  5. To create the DNS resolver, select Finished.

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Add an internal DNS resolver object using the following command syntax:

    create /net dns-resolver <name of internal DNS Resolver> answer-default-zones <yes|no> cache-size <max cache size> forward-zones add { <FQDN zone> { nameservers add { <nameserver1 IP:port> <nameserver2 IP:port> ...} } } nameserver-ttl <TTL> randomize-query-name-case <yes|no> route-domain <RD number> use-ipv4 <yes|no> use-ipv6 <yes|no> use-tcp <yes|no> use-udp <yes| no>

    For example, to create an internal DNS resolver my-example-resolver with a forward zone example.f5.com, and two nameservers 192.168.1.199:53 and 192.168.1.198:53, enter the following command:

    create /net dns-resolver my-example-resolver forward-zones add { example.f5.com. { nameservers add { 192.168.1.199:53 192.168.1.198:53 } } }

  3. Save the changes by entering the following command:

    save /sys config

  4. View the newly created DNS resolver object using the following command syntax:

    list /net dns-resolver <name of internal DNS Resolver> all-properties

    For example:

    list /net dns-resolver my-example-resolver all-properties

iControl REST

To add an internal DNS resolver object using iControl REST, use the following command syntax:

curl -sku <admin username>:<admin password> -X POST -H "Content-Type: application/json" https://<BIG-IP managment IP address>/mgmt/tm/net/dns-resolver -d '{"name":"<internal DNS Resolver name>","answer-default-zones":"<yes|no>","cache-size":"<max cache size>","forwardZones":[{"name":"<FQDN zone>","nameservers":[{"name":"<nameserver1 IP:port>"},{"name":"<nameserver2 IP:port>"}]}],"nameserver-ttl":"<TTL>","randomize-query-name":"<yes|no>","route-domain":"<RD number>","use-ipv4":"<yes|no>","use-ipv6":"<yes|no>","use-tcp":"<yes|no>","use-udp":"<yes|no>"}' | jq -M .

For example, to create an internal DNS resolver my-example-resolver with a forward zone example.f5.com, and two nameservers 192.168.1.199:53 and 192.168.1.198:53, enter the following command:

curl -sku admin:admin -X POST -H "Content-Type: application/json" https://localhost/mgmt/tm/net/dns-resolver -d '{"name":"my-example-resolver","forwardZones":[{"name":"example.f5.com","nameservers":[{"name":"192.168.1.199:53"},{"name":"192.168.1.198:53"}]}]}' | jq -M .

Modify the settings of a DNS resolver object

You can use the Configuration utility, tmsh, or iControl REST to modify the settings of a DNS resolver object on your BIG-IP system. To do so, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Network > DNS Resolvers > DNS Resolver List.
  3. Select the name of the DNS resolver object.
  4. Modify the settings as desired. For more information about each setting, refer to K12140128: Overview of the DNS resolver.
  5. To save the changes, select Update.

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Modify the setting of an internal DNS resolver object using the following command syntax:

    modify /net dns-resolver <name of internal DNS Resolver> answer-default-zones <yes|no> cache-size <max cache size> nameserver-ttl <TTL> randomize-query-name-case <yes|no> route-domain <RD number> use-ipv4 <yes|no> use-ipv6 <yes|no> use-tcp <yes|no> use-udp <yes| no>

    For example, to modify the value of the nameserver-ttl setting to 600 secods for the internal DNS resolver my-example-resolver, enter the following command:

    modify /net dns-resolver my-example-resolver nameserver-ttl 600

  3. Save the changes by entering the following command:

    save /sys config

  4. View the newly created DNS resolver object using the following command syntax:

    list /net dns-resolver <name of internal DNS Resolver> all-properties

    For example:

    list /net dns-resolver my-example-resolver all-properties

iControl REST

To modify the setting of an internal DNS resolver object using iControl REST, use the following command syntax:

curl -sku <admin username>:<admin password> -X PATCH -H "Content-Type: application/json" https://<BIG-IP managment IP address>/mgmt/tm/net/dns-resolver/<DNS Resolver full pathname> -d '{"answer-default-zones":"<yes|no>","cache-size":"<max cache size>","nameserver-ttl":"<TTL>","randomize-query-name":"<yes|no>","route-domain":"<RD number>","use-ipv4":"<yes|no>","use-ipv6":"<yes|no>","use-tcp":"<yes|no>","use-udp":"<yes|no>"}' | jq -M .

For example, if you want to change the default value of the nameserver-ttl setting to 600 seconds for the internal DNS resolver my-example-resolver, you would use the following command:

curl -sku admin:admin -X PATCH -H "Content-Type: application/json" https://localhost/mgmt/tm/net/dns-resolver/~Common~my-example-resolver -d '{"nameserver-ttl":"600"}' | jq -M .

The command returns output for the my-example-resolver object, and the nameserver-ttl setting indicates the new value.

Remove a DNS resolver object

You can use the Configuration utility, tmsh, or iControl REST to remove a DNS resolver object on your BIG-IP system. To do so, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Network > DNS Resolvers > DNS Resolver List.
  3. Select the check box next to the name of the DNS resolver object you want to delete.
  4. Select Delete.
  5. Select Delete again to confirm.

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Remove an internal DNS resolver object using the following command syntax:

    delete /net dns-resolver <name of internal DNS Resolver>

    For example, to delete an internal DNS resolver my-example-resolver, enter the following command:

    delete /net dns-resolver my-example-resolver

  3. To save the changes, enter the following command:

    save /sys config

iControl REST

To remove an internal DNS resolver object using iControl REST, use the following command syntax:

curl -sku <admin username>:<admin password> -X DELETE -H "Content-Type: application/json" https://<BIG-IP managment IP address>/mgmt/tm/net/dns-resolver/<DNS Resolver full pathname> | jq -M .

For example, to delete an internal DNS resolver my-example-resolver, enter the following command:

curl -sku admin:admin -X DELETE -H "Content-Type: application/json" https://localhost/mgmt/tm/net/dns-resolver/~Common~my-example-resolver | jq -M .

The command does not return output, which is expected behavior.

Add a forward zone to a DNS resolver object

You can use the Configuration utility, tmsh, or iControl REST to add a forward zone to a DNS resolver object on your BIG-IP system. To do so, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Network > DNS Resolvers > DNS Resolver List.
  3. Select the name of the DNS resolver object you want to add a forward zone.
  4. Select Forward Zones.
  5. Select Add.
  6. Type the Fully Qualified Domain Name (FQDN) of the forward zone in the Name setting.

    For example:

    example.f5.com

  7. Type the IP address of the nameserver for the forward zone in the Address setting and select the appropriate Service Port for the nameserver, then select Add.
  8. Repeat the previous step for additional nameservers.
  9. To save the change, select Finished.

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Add a forward zone to to an internal DNS resolver object using the following command syntax:

    modify /net dns-resolver <name of internal DNS Resolver> forward-zones add { <FQDN zone> { nameservers add { <nameserver1 IP:port> <nameserver2 IP:port> ... } } }

    For example:

    modify /net dns-resolver my-example-resolver forward-zones add { example2.f5.com { nameservers add { 192.168.1.197:53 192.168.1.196:53 } } }

  3. Save the changes by entering the following command:

    save /sys config

  4. View the newly created forward zone for the DNS resolver object using the following command syntax:

    list /net dns-resolver <name of internal DNS Resolver> forward-zones

    For example:

    list /net dns-resolver my-example-resolver forward-zones

iControl REST

The iControl REST does not have a command to add only a specific forward zone to an internal DNS resolver object. You must re-declare all existing forward zones in addition to the one you want to add. To do so, use the following command syntax:

curl -sku <admin username>:<admin password> -X PATCH -H "Content-Type: application/json" https://<BIG-IP managment IP address>/mgmt/tm/net/dns-resolver/<DNS Resolver full pathname> -d '{"forwardZones":[{"name":"<FQDN zone 1>", "nameservers":[{"name":"<nameserver1 IP:port>"},{"name":"<nameserver2 IP:port>"}...]},{"name":"<FQDN zone 2>", "nameservers":[{"name":"<nameserver1 IP:port>"},{"name":"<nameserver2 IP:port>"}...]}...]}' | jq -M .

For example, if the existing my-example-resolver object has a forward zone example.f5.com and you want to add a new forward zone example2.f5.com with nameservers 192.168.1.197:53 and 192.168.1.196:53, use the following command that includes the existing forward zone example.f5.com and its nameservers:

curl -sku admin:admin -X PATCH -H "Content-Type: application/json" https://localhost/mgmt/tm/net/dns-resolver/~Common~my-example-resolver -d '{"forwardZones":[{"name":"example.f5.com", "nameservers":[{"name":"192.168.1.199:53"},{"name":"192.168.1.198:53"}]},{"name":"example2.f5.com", "nameservers":[{"name":"192.168.1.197:53"},{"name":"192.168.1.196:53"}]}]}' | jq -M .

Remove forward zones from a DNS resolver object

You can use the Configuration utility, tmsh, or iControl REST to remove forward zones from a DNS resolver object on your BIG-IP system. To do so, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Network > DNS Resolvers > DNS Resolver List.
  3. Select the DNS resolver object name that you want to remove a forward zone.
  4. Select Forward Zones.
  5. Select the check box next to the forward zone you want to delete.
  6. Select Delete.
  7. To confirm, select OK.

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Remove a forward zone from an internal DNS resolver object using the following command syntax:

    modify /net dns-resolver <name of internal DNS Resolver> forward-zones delete { <FQDN zone> }

    For example:

    modify /net dns-resolver my-example-resolver forward-zones delete { example2.f5.com }

  3. Save the changes by entering the following command:

    save /sys config

iControl REST

The iControl REST does not have a command to remove a specific forward zone from an internal DNS resolver object. You must re-declare all forward zones, except for the one you want to remove. To do so, use the following command syntax:

curl -sku <admin username>:<admin password> -X PATCH -H "Content-Type: application/json" https://<BIG-IP managment IP address>/mgmt/tm/net/dns-resolver/<DNS Resolver full pathname> -d '{"forwardZones":[{"name":"<FQDN zone 1>", "nameservers":[{"name":"<nameserver1 IP:port>"},{"name":"<nameserver2 IP:port>"}...]},{"name":"<FQDN zone 2>", "nameservers":[{"name":"<nameserver1 IP:port>"},{"name":"<nameserver2 IP:port>"}...]}...]}' | jq -M .

For example, if the existing my-example-resolver object has two forward zones (example.f5.com, example2.f5.com) and you want to remove the example2.f5.com forward zone, use the following command that includes the example.f5.com but not example2.f5.com:

curl -sku admin:admin -X PATCH -H "Content-Type: application/json" https://localhost/mgmt/tm/net/dns-resolver/~Common~my-example-resolver -d '{"forwardZones":[{"name":"example.f5.com", "nameservers":[{"name":"192.168.1.199:53"},{"name":"192.168.1.198:53"}]}]}' | jq -M .

The command should return an output for the my-example-resolver object and there should only be one forward zone example.f5.com.

If you want to remove all forward zones from an internal DNS resolver object, you can re-declare an empty forward zone for the internal DNS resolver object. To do so, use the following command syntax:

View the statistics for a DNS resolver object

In BIG-IP 14.0.0 and later, you can use the Configuration utility, tmsh, or iControl REST to add a DNS resolver object on your BIG-IP system. To do so, perform one of the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Network > DNS Resolvers > DNS Resolver List.
  3. Select the name of the DNS resolver object.
  4. Select Statistics.

tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. View the statistics for a DNS resolver object using the following command syntax:

    show /net dns-resolver <name of internal DNS Resolver>

    For example:

    show /net dns-resolver my-example-resolver

iControl REST

To view the statistics of an internal DNS resolver object using iControl REST, use the following command syntax:

curl -sku <admin username>:<admin password> -X GET -H "Content-Type: application/json" https://<BIG-IP managment IP address>/mgmt/tm/net/dns-resolver/<DNS Resolver full pathname>/stats | jq -M .

For example:

curl -sku admin:admin -X GET -H "Content-Type: application/json" https://localhost/mgmt/tm/net/dns-resolver/~Common~my-example-resolver/stats | jq -M .
