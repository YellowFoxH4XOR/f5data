Description

You would like to know the CLI command to view the statistics of average dropped/allowed RPS, similar to the DoS dashboard.

GUI > Security > Reporting > DoS > Dashboard > Countries (sort Avg Dropped RPS in decending order and dashboard page auto refresh per 1 minute):

Note: Country locations are generated from dummy lab source IP addresses and do not represent any real attacks from those locations.

Environment

  • AFM
  • DOS dashboard
  • Analytics

Cause

None.

Recommended Actions

You could consider the CLI command below to view the statistics of average dropped/allowed RPS.

tmsh show analytics dos-l3 report view-by country measures { dropped-requests-per-second allowed-requests-per-second }

 

Note: Country locations are generated from dummy lab source IP addresses and do not represent any real attacks from those locations.
