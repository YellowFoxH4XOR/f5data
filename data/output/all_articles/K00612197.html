Known Issue

The BIG-IP system may send Address Resolution Protocol (ARP) replies that have an incorrect source MAC address.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a Virtual Local Area Network (VLAN) group set to Translucent mode.
  • Your BIG-IP system responds to ARP requests for a self IP or a virtual address configured on the VLAN group.

Impact

Destination lookup failures occur on the Layer 2 (L2) network.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • ARP replies have the locally administered bit set in the ARP payload, but the source MAC address of the frame has the bit unset.
  • Destination lookup failures occur on the L2 network.

Workaround

To work around this issue, you can use Transparent mode instead of Translucent mode in the VLAN group configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > VLANs > VLAN Groups.
  3. Click the affected VLAN group.
  4. In the Transparency Mode box, click Transparent.
  5. Click Finished.
