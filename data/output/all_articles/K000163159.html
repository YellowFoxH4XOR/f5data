K000163159: F5 Insight marks software image as Not Verified

Type
Support Solution
Published
2026-09-01
Updated
2026-09-21
Applies to
  • BIG-IP
  • F5 Insight: 1.2.2, 1.2.1
Source
https://my.f5.com/manage/s/article/K000163159

Description

F5 Insight may show a BIG-IP software image with a Not Verified status in the Software view when the corresponding *.sig and *.384.sig signature files and only one matching archive*.pem public key file have been uploaded.

Environment

  • F5 Insight
  • BIG-IP software Image upload and verification

Cause

Image verification does not check both *.sig and *.384.sig signature files when only one archive*.pem public-key file is uploaded.

This issue is being tracked under defect ID 2513593 and is expected to be resolved in a future software release.

Recommended Actions

  1. An easy workaround is to upload both archive*.pem files, but this may default to the older SHA-256 verification algorithm.
    To force it to use the newer and more resilient SHA-384, delete the affected software .iso image through the Insight GUI. Doing so also removes both its associated .sig and .384.sig signature files, as long as they use the same filename prefix as the .iso file.

  2. Re-upload the software image (.iso), its latest and strongest matching signature file (*.384.sig or *.sig), and the its corresponding strength public key file (archive*.pem) simultaneously.

  3. Find the public key archive*.pem file that corresponds to the BIG-IP image file you are interested in.
    Please refer to this KB Article to choose the correct .pem file: Verifying BIG-iP and BIG-IQ software images using SIG and PEM files.

  4. Upload the ISO together with only one corresponding archive-*k.pubkey.pem file and only one corresponding .sig file for the hash algorithm of your choosing.

    For example:

    When choosing BIGIP-17.5.1.9-0.0.12.iso, you will also see the following download options:

    archive-2k.pubkey.20251002.pem
    archive-3k.pubkey.20251002.pem
    BIGIP-17.5.1.9-0.0.12.iso.sig 
    BIGIP-17.5.1.9-0.0.12.iso.384.sig

    archive-2k*.pubkey.pem uses the older SHA-256 cryptographic hash and verifies *.iso.sig files.

    archive-3k*.pubkey.pem uses the newer SHA-384 cryptographic hash which is more resilient to collision attacks and verifies .iso.384.sig files.
  5. Ensure that all verification files correspond to the exact ISO image.

    For example, when choosing the preferred SHA-384, upload these 3 files only: 

    BIGIP-17.5.1.9-0.0.12.iso
    archive-3k.pubkey.20251002.pem
    BIGIP-17.5.1.9-0.0.12.iso.384.sig

    When choosing the older SHA-256, upload these 3 files only:

    BIGIP-17.5.1.9-0.0.12.iso
    archive-2k.pubkey.20251002.pem
    BIGIP-17.5.1.9-0.0.12.iso.sig 

    Do not mix or upload multiple versions of the above.

  6. After uploading, allow F5 Insight to complete image ingestion and verification.  

    If you are troubleshooting on the command line, you can see whether an image has been copied and/or verified

    $ sudo -i
    # tail -f /opt/f5insight/logs/provisioning.log

    {"level":"info","ts":"2026-09-09T21:03:37.317Z","logger":"upgrade.images.watcher","caller":"images/watcher.go:425","msg":"ingesting stable file","file":"Hotfix-BIGIP-17.5.1.6.0.67.25-ENG.iso"}

    {"level":"info","ts":"2026-09-09T21:03:37.318Z","logger":"upgrade.images.watcher","caller":"images/watcher.go:475","msg":"moved file to image store (same-fs rename)","file":"Hotfix-BIGIP-17.5.1.6.0.67.25-ENG.iso"}

    {"level":"info","ts":"2026-09-09T21:03:49.321Z","logger":"upgrade.images.watcher","caller":"images/watcher.go:787","msg":"file size stabilized at destination","file":"Hotfix-BIGIP-17.5.1.6.0.67.25-ENG.iso","size":103211008,"polls":5}


  7. Confirm that the image status reports successful authenticity and integrity verification.

    Example log:
    {"level":"info","ts":"2026-09-11T17:15:27.978Z","logger":"upgrade.images.verifier","caller":"images/verifier.go:268","msg":"authenticity/integrity verification complete","id":"7aebf126-f654-4a69-b2e9-008e959657a0","product_family":"BIG-IP","sig_verified":false,"integrity_verified":false,"security_level":"not verified"}

    Note: The .sig and .pem files are recommended for image verification but are not required to perform a BIG-IP software upgrade
