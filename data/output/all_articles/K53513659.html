K53513659: vlan if-index numbering is changed after upgraded the BIG-IP version

Type
Support Solution
Published
2022-03-26
Updated
2025-08-01
Source
https://my.f5.com/manage/s/article/K53513659

Description
You notice vlan if-index numbering has changed after an upgraded.

Note: You may see this behavior from SNMP manager.

Example prior to affected versions:

tmsh list net vlan all all-properties | egrep "(^net)|(if-index)"

net vlan VLAN781 {
    if-index 1216
net vlan VLAN782 {
    if-index 1232

Example of version v14.1.3.1 or v15.1.4 and later:

tmsh list net vlan all all-properties | egrep "(^net)|(if-index)"

net vlan VLAN781 {
    if-index 2144
net vlan VLAN782 {
    if-index 2160
 

Environment

  • BIG-IP
  • Upgrading to v14.1.3.1 or v15.1.4 and later

Cause

The VLAN if-index numbering behavior is not a bug.

Recommended Actions

None
 

Additional Information

None
