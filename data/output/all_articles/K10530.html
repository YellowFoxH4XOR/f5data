Issue

As a troubleshooting measure, you may want to decrease the load on your FirePass device. To decrease your load temporarily, you can perform the following procedures:

  • Disable gzip compression for client connections
  • Reduce the number of sed scripts
  • Disable debug logging of session variables
  • Reduce database size
  • Increase cluster sync interval

Important: If your FirePass device is being pushed to its maximum capacity on a routine basis, contact your sales representative to see if an upgrade is the long term solution.

Disable gzip compression for client connections

Much of the data accessed through Portal Access may already be compressed. Further compression can use resources while not necessarily improving the end user's experience. To disable gzip compression for client connections, perform the following procedure:

  1. Go to the Portal Access: Web Applications: Caching and Compression tab.
  2. Clear the Enable Compression option under Turn gzip Compression On or Off for Webtop and Web Applications.
  3. Click on the Service Restart link located directly above the Enable Compression option.
  4. Click on the Restart button.

Reduce the number of sed scripts

Firepass devices may have content processing substitution scripts that cause higher loads. Each time a client requested URL matches a pattern specified in a sed URL match pattern, the content is put through the sed program. You can save CPU time by making the URL match pattern to a single URL. To do so, perform the following procedure:

  1. Go to the Portal Access: Web Applications: Content Processing: Preprocessing Scripts tab.
  2. Click on the X button next to the sed script(s) you want to combine.
  3. Add a new favorite that will match a pattern to a single URL by clicking the Add New Favorite link and filling in the necessary information.
  4. Populate the information with the necessary data using your old sed scripts as a model.

    Leverage the * and ? wildcards in the URL match patterns field to encompass the URLs that your company needs.

Disable debug logging of session variables

Debug logging of session variables increases the database load when a logon occurs. If you are troubleshooting logon issues for customers, make sure to re-enable this option. To do so, perform the following procedure:

  1. Go to Device Management: Maintenance: Troubleshooting Tools
  2. Under the Session Variable Dump section, clear the Save user's session variables to Logon Reports option.

Reduce database size

Large databases can increase the time it takes for the database server to store and retrieve data. Depending on what logging options have been enabled and the number of users you support, you may want to either keep the logs for a shorter period, or set a specific maximum size for the database. To change either setting, perform the following procedure:

  1. Go to Device Management: Maintenance: Logs.
  2. Select a lower value from the Keep logs for drop-down menu.

    Note: One day or 12 hours may be good choices depending on your environment's needs.
  3. Change the value to between .5 and 1.8 GB in the field following the A purge of logs will be forced when the size of any log file exceeds this limit option.
  4. Click Update.

Increase cluster sync interval

Cluster syncing is resource intensive; it can help to increase the time between sync attempts. To increase cluster sync interval, perform the following procedure:

  1. Go to Device Management: Configuration: Clustering and failover.
  2. Under the Cluster Synchronization Time Interval section, change the value of the Synchronization Interval option.

    Note: The number you enter is in seconds. For example, to sync every 5 minutes, set the value to 300.
