Known Issue

Virtual servers are not displayed within the Configuration utility for some multi-page, multiple partition configurations.

This issue occurs when all of the following conditions are met:

  • You have two or more partitions configured.
  • The list of virtual servers in one partition spans more than one page.
  • The list of virtual servers in subsequent partitions spans only one page.
  • While viewing the second page (or any page that follows) of virtual servers in the first partition, you then switch to the second partition.

Impact

None. This is a cosmetic issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The virtual server list appears to be empty when you switch partitions.

Workaround

To work around this issue, you can switch partitions before navigating to the virtual server menu.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
