K000158162: F5 Access error: Failed to register with the provider: Couldn’t communicate with a helper application.

Type
Support Solution
Published
2025-12-11
Updated
2025-12-11
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000158162

Description

F5 Access on MacOS does not attempt to connect, with the below error:F5Access, 1, IPCCommunication_xpc.swift:91, register(withExtension:delegate:completionHandler:), Failed to register with the provider: Couldn’t communicate with a helper application.

Environment

macOS

F5 Access


Cause

This is caused by macOS privacy/security settings blocking the F5 Access network extension, preventing the app from registering the VPN provider.


Recommended Actions

Enable the F5 Access extension in macOS System Settings under Privacy & Security > VPN & Network Extensions.

none
