Topic

The Packet Velocity ASIC (PVA) can operate in three modes: full acceleration, partial acceleration, and no acceleration.

Full Acceleration (Full)

Note: Beginning in BIG-IP versions 4.5.11 and 4.6.3, the full acceleration option was removed from the BIG-IP version 4 software branch. For more information, refer to K3962: Change in behavior: The hw_acceleration global variable can no longer be set to full.

All traffic is load balanced using layer 4 features, such as virtual servers that operate only on IP addresses and ports of incoming traffic. Full acceleration is not compatible with layer 7 features, such as cookie persistence, header insertion, and rules that operate on data payload content.

Partial Acceleration (Partial)

The first packet in each connection is processed in software. All packets after the first are accelerated. This allows the software to make decisions based on layer 7 content, but accelerates the traffic once the load balancing or persistence determination has been made.

No Acceleration (None)

No traffic is accelerated.
