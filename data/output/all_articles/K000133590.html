K000133590: 422 Error when deploying HA DO via Big IQ

Type
Support Solution
Published
2023-04-20
Updated
2023-04-20
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.1.0, 8.0.X, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 7.0.0
Source
https://my.f5.com/manage/s/article/K000133590

Description

Failed to deploy DO HA configuration via BIG-IQ resulting in the following error:

 

 "id": "c7dda21a-9ff2-4d60-a8e1-17164b52ed5c",

    "selfLink": "https://localhost/mgmt/shared/declarative-onboarding/task/c7dda21a-9ff2-4d60-a8e1-17164b52ed5c",

    "code": 422,

    "status": "ERROR",

    "message": "failed",

    "errors": [

      "Failed to discover DSC group for 10.0.0.1: unable to refresh current config: java.lang.IllegalStateException: Device group could not be found (reference was http://localhost:8100/cm/system/machineid-resolver?$filter=state+eq+%27ACTIVE%27+and+product+eq+%27BIG-IP%27+and+groupName+eq+%27cm-bigip-allBigIpDevices%27)"

    ],

 

Environment

  • DO via BIG-IQ
  • Configure BIG-IP HA pair

Cause

Bug ID 984945

Recommended Actions

Workaround the "Failed to discover DSC group" error by performing a manual discover in BIG-IQ Devices > BIG-IP Clusters > DSC Groups

Additional Information

Composing a BIG-IP Declarative Onboarding declaration for a cluster of BIG-IPs
