K000137309: ECDHE Cipher Issues in iQuery Connection between big3d and gtmd.

Type
Support Solution
Published
2023-10-20
Updated
2026-06-08
Applies to
  • BIG-IP
  • BIG-IP DNS
  • BIG-IP LTM: 15.1.7
Source
https://my.f5.com/manage/s/article/K000137309

Description

This article discusses the issue related to ECDHE ciphers used for big3d, which results in an iQuery disconnection. It also provides guidance on how to verify the supported ciphers in an iQuery connection between gtmd and big3d.
You want to configure a custom cipher list for iQuery connections. Current big3d ciphers can be verified by below command

#tmsh list sys db big3d.ssl.cipherlist
Example -- Output
#list sys db big3d.ssl.cipherlist
sys db big3d.ssl.cipherlist {
  value "AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA"

Note: The ECDHE ciphers are currently not supported in the iQuery connection.

Environment

  • iQuery
  • big3d/gtmd
  • iqtest

Cause

The root cause of this issue is identified as Bug ID936417

Recommended Actions

Before making any changes, you should verify the Ciphers list on both the local and remote devices. To verify the supported ciphers in an iQuery connection, follow these steps:

  • Log in to the shell (bash).
  • To verify the supported ciphers in the iQuery connection between gtmd and big3d on your local BIG-IP DNS, use the following command syntax 
    #iqtest -cipher <cipher_string> localhost && iqtest -cipher '<your_cipher_string>' <remote big3d IP>
Example 1 >>> Failed result
#iqtest -cipher 'DEFAULT:@STRENGTH:!SHA:!RSA:!DHE:!DH'

Note: A failing connection would return an error similar to the above. This Ciphers cannot be used as can cause the iquery failure.

Example 2 >> Success result
# iqtest -cipher 'AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA' 10.10.10.1

Note: A successful connection would return similar to the following example, with sample remote big3d IP being tested is 10.10.10.1

  • After doing the testing of ciphers then proceed to do the big3d ciphers change as per the below process.
  • To configure the iQuery connection to use only specific cipher, follow all of the procedures below.

Reconfigure the big3d process to use specific cipher

      1. Log in to the tmsh utility by entering the following command.  
        #tmsh
      2. Run following command to update the db to use AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA: 
        #modify sys db big3d.ssl.cipherlist value AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA
      3. Restart big3d is required to re-establish the iQuery connection. 
        #restart sys service big3d

Note: Ciphers Not supported will give the error and can break the iquery if used in big3d ciphers configuration change.
