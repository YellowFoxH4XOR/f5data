Known Issue

This is the result of a known issue. A BIG-IP virtual server with a configured RTSP profile may incorrectly parse the CSeq field. When the BIG-IP LTM encounters a trailing space within the CSeq field following the sequence number, the BIG-IP LTM issues a reset of the connection and increments the error number in the profile counter.

The connection may be reset on the client or server side of the connection, depending on which side the request was generated from; both client and server communication must include the CSeq field and a value as per RFC2326

F5 Product Development is tracking this issue as CR125665.

Note: This issue does not affect BIG-IP 10.x.
