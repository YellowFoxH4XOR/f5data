Known Issue

This is the result of a known issue. If a BIG-IP system is configured to assign unique VLAN MAC addresses, and a 62nd VLAN is added to a configuration already containing 61 VLANs, the mcpd process fails to assign a unique MAC address to the new VLAN, and instead assigns the MAC address of 00:00:00:00:00:00 to the 62nd VLAN.

Note: By default, the BIG-IP system assigns a unique MAC address to each VLAN. You can configure the BIG-IP system to assign the same MAC address to all configured VLANs by modifying the value of the Vlan.MacAssignment db key using the command line, or by enabling the Share Single MAC Address setting on the System > Configuration > Local Traffic > General screen in the Configuration utility.

F5 Product Development tracked this issue as CR134531, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WAN Optimization, or Edge Gateway release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

Workaround

Important: This workaround is not appropriate for network configurations that rely on unique MAC address assignments per VLAN.

You may be able to work around this issue by configuring the system to use the same MAC address for all VLANs, and then rebooting the system. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To share a single MAC address among all configured VLANs, type the following command:

    bigpipe db Vlan.MacAssignment global

  3. To stop the mcpd process and free the binary mcpd database for deletion, type the following command:

    bigstart stop

  4. To remove the binary mcpd database, type the following command:

    rm /var/db/mcpdb.bin

  5. To reboot the system, type the following command:

    reboot

Once the system has rebooted, you may add the 62nd VLAN and subsequent VLANs. All BIG-IP VLANs now share the same MAC address.
