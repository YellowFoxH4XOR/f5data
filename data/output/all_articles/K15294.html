Known Issue

The BIG-IP system may fail to display correct DNS-Express zone statistics.

This issue occurs when the following condition is met:

  • The master DNS nameserver returns an Authoritative Transfer (AXFR) response to an Incremental Zone Transfer (IXFR) query.

An IXFR nameserver may periodically purge its IXFR information, for example, when the IXFR response is larger than the AXFR response. If IXFR information is not available, the entire zone is returned by way of an AXFR response.

Impact

Due to this cosmetic issue, BIG-IP statistics may misrepresent the actual data in the DNS-Express database, though actual data is consistent with the primary nameserver.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system displays inaccurate statistical information.

Workaround

To work around this issue, you can restart the zxfrd process and use the tmsh utility to display the zone statistics. To do so, perform the following procedure:

Impact of workaround: You should restart the zxfrd process during a maintenance window because the process disrupts the DNS-Express service.

  1. Log in to the BIG-IP command line.
  2. To restart the zxfrd process, type the following command:

    bigstart restart zxfrd

  3. To view the DNS-Express zone statistics using the tmsh utility, use the following command syntax:

    tmsh show ltm dns dns-express zone <Zone-Name>

    For example, to view statistics for a DNS-Express zone named example.org, type the following command:

    tmsh show ltm dns dns-express zone example.org

    Note: To avoid encountering this issue, F5 recommends that you view the statistics by each zone when you have a large number of DNS-Express zones configured (for example 1800 zones).
