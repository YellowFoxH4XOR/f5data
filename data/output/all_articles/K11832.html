Issue

When creating a forest root, if the ARX system is unable to connect to a domain controller, the forest-root command will fail with an error message that appears similar to the following example:

% ERROR: DETERMINE_REALM_IP_NOT_REACHABLE (38011023): Failed to add a new domain controller entry because the host at IP address 10.10.10.10 is not reachable or is not a domain controller. Check the IP address and retry the command.

This error message will also occur if the ARX system's in-band management IP address is not configured.

Note: For information about configuring an in-band management IP address, refer to the interface vlan command in the ARX CLI Reference Guide.
