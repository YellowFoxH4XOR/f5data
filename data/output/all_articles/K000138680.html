Description

When setting up BIG-IP Next Central Manager to use LDAP Authentication from a Windows Active Directory LDAP Server, the default values for the User Search Filter need to be configured.

Environment

  • BIG-IP Next Central Manager (CM)
  • Windows Active Directory based LDAP

Cause

Filter Default values do not match AD setting requirements.

Recommended Actions

  1. Review the documentation for setting up LDAP at How to: Configure LDAP for user authentication.
  2. Navigate to System > Users and Roles > Auth Providers
  3. Select your LDAP Configuration, and Select 'Edit'.
  4. Select "Show Advanced Settings"
  5. Fill out the settings, following the documentation until you get to the following settings: 
    1. For "User Search Filter"
      1. (&(sAmAccountName={username}))
  6. Test a valid user.
  7. Save the configuration.
