Known Issue

This is the result of a known issue. A delayed acknowledgment behavior was inadvertently activated which introduced a 0.2 second delay for some requests. This issue may result in poor NFS migration performance.

F5 Product Development tracked this issue as ID 39508 and it was fixed in ARX 5.1.7. For information about upgrading, refer to the ARX release notes.

This issue has also been fixed in V5.1.5 Hotfix 6 (build 11980) issued for ARX 5.1.5. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

Additionally, this issue has been fixed in a hotfix available for ARX 5.0.6. Customers affected by this issue should request the hotfix from F5 Technical Support, referencing this Solution number and ID 39508.
