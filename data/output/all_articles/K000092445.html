Description

You can use BIG-IP Next's REST API to generate and download qkviews.

Environment

  • BIG-IP Next Virtual Edition or VELOS edition

Procedure

Prerequisites

  • Obtain a login token using the information at How to log in to the BIG-IP Next REST API
    • That token will be stored in a variable called TOKEN in this procedure.

Procedure 1 - initiate a qkview

curl -X PUT -sk -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" https://10.10.10.10:5443/api/v1/qkview -d '{"name": "myqkview.bin"}' | jq
{
    "id": "b5127950-ce43-4374-b448-a1861988318e",
    "verb": "PUT",
    "uri": "/qkview",
    "request": "{\"name\":\"myqkview.bin\"}",
    "role": "QKVIEW",
    "status": "PENDING",
    "message": {
        "code": "",
        "title": "",
        "detail": "",
        "links": {
            "about": "",
            "resourceLink": ""
        }
    },
    "creationTime": "2022-10-12T23:59:05.914384Z",
    "updateTime": "2022-10-12T23:59:05.914384Z",
    "owner": "admin",
    "authn": "local",
    "authz": "global"
}

The ID returned is the job ID and you'll need it to detect if the qkview job is complete.

Procedure 2 - check the qkview job to see if it completed

It takes several minutes for BIG-IP Next to generate a qkview.  If the job status is "RUNNING" then the qkview is still being generated. 
curl -sk -H "Authorization: Bearer $TOKEN" https://10.10.10.10:5443/api/v1/jobs/b5127950-ce43-4374-b448-a1861988318e | jq
{
  "authn": "local",
  "authz": "global",
  "creationTime": "2022-10-12T23:59:05.914384Z",
  "id": "b5127950-ce43-4374-b448-a1861988318e",
  "owner": "admin",
  "request": "{\"name\":\"myqkview.bin\"}",
  "role": "QKVIEW",
  "status": "RUNNING",
  "updateTime": "2022-10-12T23:59:05.923436Z",
  "uri": "/qkview",
  "verb": "PUT"
}
Keep trying until the status is SUCCEEDED.  Now the response will contain a resource link.  This is the path to the qkview file that you can download. 
 curl -sk -H "Authorization: Bearer $TOKEN" https://10.10.10.10:5443/api/v1/jobs/b5127950-ce43-4374-b448-a1861988318e | jq
{
  "authn": "local",
  "authz": "global",
  "creationTime": "2022-10-12T23:59:05.914384Z",
  "id": "b5127950-ce43-4374-b448-a1861988318e",
  "message": {
    "code": "",
    "detail": "QkView created successfully. iHealth not uploaded without first setting credentials at /ihealth endpoint.",
    "links": {
      "resourceLink": "/files/01390c1d-9c99-494a-b8dc-f09a0ee4eabc"
    },
    "title": ""
  },
  "owner": "admin",
  "request": "{\"name\":\"myqkview.bin\"}",
  "role": "QKVIEW",
  "status": "SUCCEEDED",
  "updateTime": "2022-10-13T00:00:57.172874Z",
  "uri": "/qkview",
  "verb": "PUT"
}

Procedure 3 - download the qkview file

Use the resourceLink to download the file. 
curl -sk -H "Authorization: Bearer $TOKEN" -H "Accept: */*" https://10.10.10.10:5443/api/v1/files/01390c1d-9c99-494a-b8dc-f09a0ee4eabc/download -o myqkview.bin.tar.gz
With this curl command, the file is written to disk and no output is rendered to screen.

You can upload this file to https://ihealth.f5.com/ for analysis.
