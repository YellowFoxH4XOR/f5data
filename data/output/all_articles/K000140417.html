Description

Can not change the default apmclient version to older version and can not delete latest version after upgrading BIG-IP to a certain version.

 

Environment

  • BIG-IP APM
  • apmclient

 

Cause

  • by design.

Some version has limit to support older client, and also there is no backward compatibility commited.

 

Recommended Actions

If you have old client which is not supported by latest EdgeClient or some other reasons you do not want client to upgraded, before installing latest version, set all Connectivity profile: auto update == no, as it will copy over the current config to newly installed location during installation process.

Then when it is booted from the later version location, it will not force client to upgrade EdgeClient.
