Description

OAuth validation scopes request fails with error "OAuth Scope: Response is empty from server"

Environment

  • BIGIP provisioned with APM
  • APM access policy configured with an OAuth scope agent that includes "validation-scopes-request" option.

Cause

APM expects as response a 200 OK message with Content-Type: application/json, but it is receiving a response with different status code and without json data like "401 Unauthorized" or "500 Internal Server Error"



Recommended Actions


You need to capture a tcpdump to analyze all the response and maybe contacting OAuth AS support team to explain why that error happened.
