Issue

Error Message

err tmm5[<PID>]: 01340003:3: Cluster error: <Critical Message>

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <Critical Message> is the critical error message related to the MPI proxy that is used to communicate between Traffic Management Microkernel (TMM) threads.

For example:

err tmm5[20705]: 01340003:3: Cluster error: corrupted MPI header, aborting connection

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A critical error occurrs during communication between TMM threads via the MPI proxy.

Impact

The BIG-IP system may be in an unpredictable state.

Recommended Actions

Contact F5 Technical Support to open a support case to investigate the cause of the critical error message.
