Description

  • Virtual server configured with AFM DNS Protocol Security doesn't generate logs

Environment

  • AFM DNS Protocol Security
  • Security log Profile
  • DNS profile
  • DNS logging profile

Cause

Seen behavior is expected if the global-network security profile is not assigned to the virtual server in question.

Recommended Actions

Assign the global-network security profile to the virtual server in question

  1. On GUI go to Local Traffic > Virtual Servers > Virtual Server List
  2. Click on desired virtual server
  3. On upper tabs go to Security > Policies
  4. Set Log profile to Enabled
  5. Move global-network from the Available list to Selected list
  6. Click Update
