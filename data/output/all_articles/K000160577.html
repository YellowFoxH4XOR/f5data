Description

WAF events are not visible in the NGINX Instance Manager Security Dashboard, even though WAF events are present in the waf.log file on the NGINX Plus instance. The expected behavior is that WAF events should be forwarded and displayed in the NIM GUI.

Environment

  • NGINX Instance Manager (NIM) version 2.X.X
  • NGINX Plus instances with F5 WAF for NGINX enabled
  • NGINX Agent installed on monitored instances
  • WAF events confirmed in waf.log (or equivalent) via NGINX instance CLI
  • Security Dashboard in NIM GUI used for event monitoring

Cause

The NGINX Agent configuration is not properly set up to forward WAF events to NGINX Instance Manager. When the agent is not configured correctly, WAF events will not be displayed in the Security Dashboard, even if they are present in the waf.log file.

Answer/Recommended Actions

  1. Verify the NGINX Agent configuration on the NGINX Plus instance is properly configured for Security Monitoring:
    • Follow the official documentation for setting up  instances with NGINX Instance Manager
    • Pay special attention to step 3 and beyond in the agent configuration process
  2. Set the NGINX Agent log level to debug to verify event collection
  3. Check the NGINX Agent logs for messages indicating that WAF events are being collected and sent to NIM every 60 seconds. The log message should look similar to:

time="2026-03-07T01:39:09Z" level=info msg="reached a report interval of 60s, sending 60 Security Violation Events as a report"

  1. The NGINX Agent intercepts syslog server events and outputs them to stdout, then sends collected WAF events to NIM every 60 seconds
  2. Once sent, NIM will collate and display the events under the WAF : Security Dashboard page
  3. If events are still not visible after proper configuration:
    • Review agent and instance configuration settings
    • Collect agent logs and configuration details for further troubleshooting

Additional Information

  • The NGINX Agent is responsible for intercepting WAF events from the syslog server and forwarding them to NGINX Instance Manager
  • Debug log level NGINX Agent logs will display each WAF event when it happens
  • Events are sent in batches every 60 seconds to NIM for display in the Security Dashboard
