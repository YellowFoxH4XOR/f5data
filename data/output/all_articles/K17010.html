Known Issue

FastL4 forwarding virtual server connections may fail after a failover.

This issue occurs when the following condition is met:

  • You have configured the FastL4 forwarding virtual server to use the iRule nexthop command.

Following a failover, the virtual server will not use the configured nexthop address and the connection will fail.

Impact

Affected FastL4 forwarding virtual server connections fail following a high availability (HA) failover.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Affected FastL4 forwarding virtual server connections fail following an HA failover.

Resolution

Workaround

To work around this issue, you can configure the nexthop address as a member in a pool and use the iRules pool command.

Impact of workaround: Performing the recommended workaround should not have a negative impact on your system.
