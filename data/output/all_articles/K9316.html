K9316: The ARX virtual server sends empty answers to NBSTAT queries when a WINS server is not defined

Topic

In the absence of a defined WINS server, or if a WINS server is not functioning, an ARX virtual server cannot be fully functional as a WINS server. For example, without a defined working WINS server, the ARX virtual server will be able to answer to NB queries for which WINS names or aliases have been defined. However, the ARX virtual server will send empty answers to NBSTAT queries.

These empty NBSTAT answers may cause CIFS clients, particularly certain cameras and imaging equipment, to hang when attempting to connect to the ARX CIFS service.

To check for this misconfiguration, examine the settings of the virtual server being queried, and ensure that a WINS server is defined.

If a WINS server is not defined for that virtual server, correct the misconfiguration by using the wins command to define a WINS server.

Note: For more information about NetBIOS, WINS, and the wins command, refer to the ARX CLI Storage-Management Guide.
