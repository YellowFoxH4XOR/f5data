Description

When ike-daemon IPsec debug is set to level "debug2", the expected level of detail (ie: rows of hex) is not seen in /var/log/ipsec.log

Environment

  • BIG-IP configured to terminate IPsec

  • Ike-daemon logging level set to "debug2"

Cause

ID800189 

Recommended Actions

Change the ike-daemon logging publisher to something else and set it back to default. This is a one-time activity after a new build or IPsec configuration.

  tmsh modify net ipsec ike-daemon ikedaemon log-publisher sys-sslo-publisher

  tmsh modify net ipsec ike-daemon ikedaemon log-publisher default-ipsec-log-publisher

  tmsh save sys config

Additional Information

This can also be resolved by a one-off restart of tmm ("bigstart restart tmm"). This is disruptive to traffic through the BIG-IP.
