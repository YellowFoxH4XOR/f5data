Known Issue

BIG-IP GTM server objects cannot be modified when the Address List setting includes a translated address and an address that is numerically lower than the original address.

This issue occurs when all of the following conditions are met:

  • You have configured a BIG-IP GTM server IP address to use translation.

    For example, you use 192.168.10.100 as the address, which translates to 10.10.10.100.
  • You then configure the server to use a second IP address, with a numerically lower value than the first address.

    For example, using 11.11.11.100 as the second address is numerally lower than the first example address (192.168.10.100).
  • From the Configuration utility, you attempt to modify the BIG-IP GTM server object (such as attempting to change the data center).

Impact

Users cannot modify BIG-IP GTM server objects by using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • From the Configuration utility, you are unable to modify the BIG-IP GTM server object, and the system displays an error message similar to the following example:

    01020037:3: The requested GTM IP (192.168.10.100 /Common/example_server) already exists

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to modify the BIG-IP GTM server object.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
