K8182: No DNS queries for IPv6 service records during Active Directory authentication or group mapping

Issue

In FirePass software versions prior to 6.0.0, Active Directory (AD) queries for authentication or group mapping would issue DNS queries for IPv6 service records (DNS SRV records) of the AD domain controller or controllers. In version 6.0.0 and later, the IPv6 SRV queries are no longer sent. Only non-IPv6 service record queries are sent to the DNS servers configured on the DNS tab of the Device Management: Configuration: Network Configuration page.

In the majority of AD configurations, this change will have no effect on the ability of FirePass to perform AD authentication, group mapping, or other AD-based functions.  Only those AD configurations which use the IPv6 version of the DNS service record and do not use the more common IPv4 form of service record (A record) would be affected by this change. This configuration is not recommended; the preferable configuration, if IPv6 SRV records are required, is to also use the older SRv record. Normally, DNS software and application software will accommodate the use of both types of records.
