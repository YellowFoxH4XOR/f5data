Description

Attempting to configure Advanced Shell access for Resource Administrator users results in the following error:

Access denied - Administrators only: Custom shells only available to administrators, not <User Name>

Environment

  • BIG-IP upgrade to versions:
    • 15.0.0 and later
    • 14.1.0.2 and later
    • 13.1.1.5 and later
    • 12.1.4.1 and later
    • 11.6.4 and later
    • 11.5.9 and later
  • Resource Administrator role
  • Local user account

Cause

Newer versions of BIG-IP software have restricted Advanced Shell access to local users with the Administrator role. This change was made to address the issue described here: K07702240: BIG-IP Resource Administrator vulnerability CVE-2019-6618

Recommended Actions

If Advanced Shell access is required, assign the user the Administrator role.

Additional Information

Similar problems caused by permission changes in newer software versions for remotely-authenticated users can cause issues similar to those described here K33139545: After upgrade to 14.1.0.2 and later, unable to connect with sftp to the BIG-IP mgmt interface.
