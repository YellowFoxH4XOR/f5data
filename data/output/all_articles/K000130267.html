K000130267: Device "Managed By BIG-IQ" in the UI, always displays the standby unit

Type
Support Solution
Published
2023-01-17
Updated
2023-01-17
Source
https://my.f5.com/manage/s/article/K000130267

Description

  • When you hover over the "Managed By BIG-IQ" in the top left corner, it gives you the IP of the secondary BIG-IQ not the active one.

Environment

  • BIG-IP managed by BIG-IQ

Cause

Expected behavior

 Recommended Actions

None

Additional Information

If you want to verify which BIG-IQ is active, and managing the BIG-IP, run the bash command:
 

restcurl shared/resolver/device-groups/cm-bigip-allDevices/devices
