Topic

The APM Clients package version 7.1.9.9 Update 1 provides a security update to version 7.1.9.9 and does not conform to the standard versioning scheme.

Note: The APM Client 7.1.9.9 Update 1 package can be installed on BIG-IP APM 13.1.0 or later.

Description

F5 uses a three-digit numbering scheme to represent BIG-IP Edge Client major versions with a fourth digit appended for each minor update release. 7.1.9.9 Update 1 is a security update to 7.1.9.9 and does not conform to this scheme. For more information about BIG-IP Edge Client versioning, refer to K13757: BIG-IP Edge Client version matrix.

  • Locate which version of 7.1.9.9 is installed on your client systems
  • Locate which version of 7.1.9.9 is installed on your BIG-IP APM system
  • Client update behavior

Locate which version of 7.1.9.9 is installed on your client systems

For version 7.1.9.9, you must use the full version number to determine the currently installed release. The full version number is slightly different between Windows, Mac, and Linux systems. For example, the full version number for BIG-IP Edge Client 7.1.9.9 Update 1 for Windows is 7199.2021.0527.907, while for Linux and Mac the full version number is 7199.2021.0527.1.

To obtain the full version number on all desktop platforms, go to Help > About  within the Edge Client software . For a list of full version numbers and corresponding short version numbers, refer to K13757: BIG-IP Edge Client version matrix.

Locate which version of 7.1.9.9 is installed on your BIG-IP APM system

On the BIG-IP APM system, the installed APM Clients package version is reported under System > Software Management > APM Clients. The following table shows the APM Clients package ISO file names for version 7.1.9.9 and 7.1.9.9 Update 1.

VersionFile name
7.1.9.9apmclients-7199.2021.408.421-5222.0.iso
7.1.9.9 Update 1apmclients-7199.2021.527.907-5235.0.iso

Client update behavior

There is no change in this behavior. When clients connect to a BIG-IP APM system that has a newer APM Clients ISO package installed, an update automatically occurs depending on the BIG-IP APM system's Component Update setting. Clients connecting to the BIG-IP APM system will update to the new 7.1.9.9 Update 1 version as usual. For more information about BIG-IP Edge Client update behavior, refer to K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI.
