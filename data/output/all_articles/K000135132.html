K000135132: Remove stale monitor instances from mcpd using guishell

Type
Support Solution
Published
2023-07-03
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000135132

Description

Unable to delete monitor with message "In use" even though it didn't bind to any pool/node

Environment

  • BIG-IP
  • LTM Monitors

Cause

MCPD couldn't unbind the monitor instance from monitor. The cause is unknown.

 Recommended Actions

  • Find the monitor instances for that IP Address from guishell.

Note: Below guishell command will find entries for ipaddress 10.10.10.11 in table monitor_instance

guishell -c "select mon_name,addr,port,node_type,node_type,node_name,object_id from monitor_instance WHERE ADDR='10.10.10.11' "

|   MON_NAME |              ADDR | PORT | NODE_TYPE | NODE_TYPE |      NODE_NAME | OBJECT_ID |

-------------------------------------------------------------------------------------------------------------------

|  /Common/tcp |          10.10.10.11 |  80 |     2 |     2 | /Common/10.10.10.11 |  155104 |

-------------------------------------------------------------------------------------------------------------------

       (rcv: 1Kb, 0.002s, snd: 38b, 0.000s)
  • Remove the monitor instances for that IPaddress from guishell

Note: Below guishell command wil remove entries for IP Address 10.10.10.11 in table monitor_instance

guishell -c "delete from monitor_instance where ADDR='10.10.10.10'"
