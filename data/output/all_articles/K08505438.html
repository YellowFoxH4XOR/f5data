Description:

There are many ways to define the Application Path and Parameters setting in app tunnel.
Osascript is an utility installed in every Mac that executes applescript scripts.
This article will show you how to use it with APM app tunnel and make MacOS client automatically launch an SSH connection after click app tunnel resource icon.

Environment:
  • BIG-IP system with APM module
  • APP Tunnel
  • MacOS
Cause:

None

Recommended Actions:
  • You should first have basic app tunnel settings.
For more details, please refer to configuration guide: Manual Chapter : Configuring App Tunnel Access
  • For Application Path and Parameters, please use the following settings:
Launch Application --> Application Path
please use: osascript

Launch Application --> Parameters
please use: -e "tell application \"Terminal\" to do script \"ssh -p %port% %{session.logon.last.username}@%host%\""

By using these settings, if you click the app tunnel icon on the webtop, you will get a new Terminal launched with the desired ssh command. 
It will also use the username you used to log in APM portal as the login username for ssh connection.
