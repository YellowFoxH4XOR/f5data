K000163283: Modifying node IP address instead of re-creating it

Applies to

Source

Description

You want modify node IP address instead of re-creating it.

Environment

  • BIG-IP

Cause

None

Answer/Recommended Actions

BIG-IP does not support modifying IP address of node. You will have to re-create it. There is RFE (Request for Feature Enhancement) ID 2501473.

The alternative method is to use FQDN nodes. Basically you create an FQDN nodes on the BIG-IP and that way if the server IP address is changes, BIG-IP can dynamically learn and update the node IP address.
