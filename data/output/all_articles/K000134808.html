K000134808: Changing the root user's password via F5OS GUI

Type
Support Solution
Published
2024-05-23
Updated
2026-07-09
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000134808

Description

Changing root password via the F5OS GUI instead of from the CLI.

Environment

  • F5OS-A
  • rSeries

Cause

Changing password of the root user using GUI.

Recommended Actions

1.  Assign a management IP address to the device.

2.  Connect to the F5OS GUI via the management IP

3.  Change the root password via the GUI.

For pre F5OS 2.0.0:

GUI >> USER MANAGEMENT >> Users >> root >> Set Password | Confirm Password >> Save & Close

For F5OS 2.0.0:

GUI >> Users & Roles >> Select "root"  >> Set Password | Confirm Password >> Save

4.  Login and test the new root password.

Additional Information

None
