Description

APM has a method of creating a dynamic Address List that is automatically populated with a list of Server IP Addresses for a Zoom or Office365 network, and can be kept up to date automatically.
 Environment

BIG-IP APM VPN configured as follows:

  • Configure a dynamic Address list for Zoom or Office365
  • Set profile to "Frequency=Every 30 Days"
  • Start the Discovery Task

Cause

The task fails with a java stack trace when the refresh is too frequent (Integer overflow in delay counter).
Setting refresh for 30 days for Address list gives error Negative delay. at java.util.Timer.schedule

Recommended Actions

Set the profile with less than "Frequency=Every 30 Days".

None.
