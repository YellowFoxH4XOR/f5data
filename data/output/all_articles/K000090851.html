K000090851: How to determine Nginx Controller's API Key

Type
Support Solution
Published
2021-11-03
Updated
2026-07-30
Source
https://my.f5.com/manage/s/article/K000090851

Description

  • You have a need to determine the API key of your Nginx Controller 
  • API key may be required to integrate the controller with an instance
  • For example, API key is required when creating an Nginx plus image with a controller agent, as described here https://github.com/nginxinc/docker-nginx-controller#1-overview

Environment

  • Nginx Controller
  • API Key

Cause

None

Recommended Actions

To determine Nginx Controller's API key, 

  1. Access / Login to the controller User interface \[UI\]
  2. Navigate to Infrastructure  >>  Instances  >> then click create
  3. Select Add an existing instance
  4. Under the section of Instructions, check the controller's API key

Additional Information

None
