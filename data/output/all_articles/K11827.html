Known Issue

If a client request is split into multiple packets and a delay of 20 ms or more occurs between the packets, the inband health monitor fails and marks the selected pool member down.

Note: The inband health monitor was introduced in BIG-IP version 10.0.0. For more information, refer to the Configuration Guide for BIG-IP Local Traffic Manager or K10640: Pool member reselection options.

F5 Product Development is tracking this issue as ID 223667, ID 327308, and ID 328758 (formerly CR131103), and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).
