Description

After removing ASM function and deprovision ASM, BIG-IP goes offline.

Below command does not detect any error (but can have some warning for irule entry)

tmsh load sys config verify

/var/log/ltm logs

warning sod\[<PID>\]: 01140029:4: HA license_exceeded_t mcpd fails action is go offline and down links.
warning sod\[<PID>\]: 01140029:4: HA proc_running tmm fails action is go offline and down links.

Environment

  • BIG-IP
  • any version
  • Provision change
  • ASM

Cause

ASM config is left behind.

Recommended Actions

Check all config including profiles which is not assigned to any objects.

With text editor on CLI, remove security enabled/disabled line similar to below and save the config file, then run

tmsh load sys config

e.g.

ltm profile ftp /Common/ftps {
    allow-ftps enabled
    app-service none
    defaults-from /Common/ftp
    port 20
    security enabled <<<-------[!]
}

If this issue persists, please contact F5 Support.
