Description

There are a few upgrade options for VELOS (F5OS-C) and rSeries (F5OS-A) software. When is the Unbundled software upgrade recommended?

Environment

  • VELOS F5OS-C
  • rSeries F5OS-A
  • upgrade
  • unbundled

Cause

Not Applicable.

Recommended Actions

In the F5OS webUI, under SYSTEM SETTINGS > Software Management, in the Update Base OS Software section of the page, there is an option to select either Bundled or Unbundled.

F5 recommends always using Bundled installation in all situations unless F5 recommends otherwise. You should only use Unbundled, which allows you to select different software versions for base OS and service, when F5 Support instructs you to do so.

For more information about what is included in the base OS and service components of the F5OS image, refer to the following articles:

  • K07950100: Display the F5OS-A software version on the F5 rSeries system
  • K62132391: Display the F5OS-C software version on the VELOS system

Important: We do not test every single combination. You may encounter unexpected issues when you use the Unbundled installation.
