Source

Description

Customer may find this alert when checking Security >> Protocol Security : Inspection Update, as below shows.

The alert can be seen even customer licensed IPS and subscription.

Environment

  • Big-IP AFM
  • WebUI
  • License
  • Subscription

Cause

The issue is caused by BIG-IP checking the wrong license flag. There is an RFE to track this.

Bug ID 1135073 IPS Signature Update GUI message "An active subscription is required to access certain inspections" is always enabled
 

Recommended Actions

There is no impact if customer has AFM and IPS subscription license installed on BIG-IP, all the IPS signatures and compliances work normally.

None
