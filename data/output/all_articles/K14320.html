Topic

A non-flow BIG-IP iRules event is triggered outside of traffic flow activity handled by a virtual server. RULE_INIT and ACCESS_SESSION_CLOSED are both examples of non-flow events. BIG-IP iRules do not support the following Tool Command Language (Tcl) commands for non-flow events:

  • table
  • session
  • persist
  • RESOLV::lookup
  • LB::select
  • connect

You cannot save an iRule that contains an affected Tcl command for a non-flow event. If you attempt to save the iRule, you receive a validation error message that appears similar to the following example:

01070151:3: Rule [<ruleName>] error: line 2: [command is not valid in current event context (RULE_INIT)] [<offending command>]
