K000147444: Is ICMP traffic necessary for communication between the Customer Edge to the Regional Edge?

Type

Published

2024-11-08
Applies to

  • F5 Distributed Cloud
Source

Description

  • You are seeking to understand if ICMP traffic must be allowed through your firewall for successful communication between the Customer Edge (CE) and Regional Edge (RE) in your network infrastructure.
  • Is the ICMP protocol essential for communication from the CE to the RE, or can it be safely disabled?

Environment

  • F5® Distributed Cloud Regional Edge
  • F5 Distributed Cloud Customer Edge 

Resolution/Answer

  • ICMP is crucial due to the Path MTU Discovery (PMTUD) process that operates outside the tunnel. This process ensures the network can dynamically adjust the maximum transmission unit (MTU) for optimal data flow across the network.

Cause

  • pmtud process that we run outside the tunnel

Additional Information

  • At this time, it is not possible to disable ICMP traffic without potentially affecting the stability of the network tunnel.
  • If ICMP is blocked, it can disrupt the PMTUD process, leading to issues such as tunnel instability or flapping, which could degrade network performance.
