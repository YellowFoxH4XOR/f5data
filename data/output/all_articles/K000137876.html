K000137876: SSLO HA may display an error when default admin user is disabled

Description

If default admin user is disabled and configure alternate user on primary admin user, the SSL Orchestrator GUI might display the following error.

Invalid BIG-IP high availability (HA) setup. Wait 2 minutes for self-recovery. If high availability (HA) remains invalid, select HA-Status for more details to correct. Any Configuration changes are not allowed until resolved. 

While the error exists, any configuration changes are not allowed until it is fixed. 

Environment

  • SSLO HA pair

 

Cause

SSLO HA works with default admin user

 

Recommended Actions

Configure systemauth.primaryadminuser to default admin user.

# tmsh modify sys db systemauth.primaryadminuser value admin

 

Additional Information

None
