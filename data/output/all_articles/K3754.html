Topic

To assist in troubleshooting client logon failures, you can enable extended logon error codes in FirePass. When you enable extended logon error codes, FirePass reports an error code on the logon denied page when user logon fails.

Note: F5 recommends that you disable the extended logon error codes feature once troubleshooting is complete. Enabling extended logon error codes could potentially allow a remote attacker to harvest extra information about the FirePass controller configuration and valid user names.

Enabling extended logon error codes

To enable extended logon error codes, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Security.
  4. Click User Access Security.
  5. In the Failed Logon Processing section of the main screen, select the box next to Show extended logon error code on logon page.
  6. At the top of the page, click Requires services restart.
  7. To restart the FirePass services, click the Restart button.

FirePass now reports an error code on the logon denied page when user logon fails.

Viewing logon error codes reference table

You can view a reference table of the logon error codes by performing the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Error codes.
