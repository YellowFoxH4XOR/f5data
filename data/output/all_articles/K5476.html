K5476: Log messages can be reported from users other than the root user

Topic

Occasionally, log messages are reported from a user other than the root user.

For example:

Sep 7 22:40:22 bigip1 user1: Re-starting tmm
Sep 7 22:40:34 bigip1 user1: Re-starting bcm56xxd

These messages are not an indication of a security exploit or escalation of privilege attack.

These messages indicate the user user1 restarted the TMM process and bcm56xxd process, not the root user, which may be expected. The user that is logged into the console at the time of the event is the username displayed when the event is logged if that user has privileges equivalent to root privileges.
