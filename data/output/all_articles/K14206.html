Topic

This article applies to BIG-IP 11.x through 14.0.x. For information about other versions, refer to the following articles:

  • K12036: Configuring the BIG-IP system to exclude inode information from Etags (9.x - 10.x)
  • K14208: Configuring Enterprise Manager to exclude inode information from Etags

You should consider using this procedure under the following condition:

  • You want to configure your BIG-IP system to exclude inode information from Etags when connecting to the Configuration utility.

Note: In BIG-IP 14.1.0 and later, the Apache server version is 2.4.6, which defaults the FileETag Directive to FileETag MTime Size. As a result, you do not need to perform the procedures in this article for BIG-IP 14.1.0 and later. For more information, refer to the Supplemental Information section at the end of this article.

Description

When connecting to the Configuration utility, responses from the Apache server contain an Etag HTTP header that includes the file's inode information.

For example:

ETag: "8d74-ced-eeed38c0"

In this example, 8d74 is the inode of the file printed in hex.

This information is only provided while accessing the management GUI. Therefore, F5 Product Development considers the impact or risk of revealing this information as low.

Some security scanners may detect the system as vulnerable to Apache vulnerability CVE-2003-1418 because the inode information is disclosed. The Apache vulnerability was addressed with the addition of the FileETag httpd setting, which allows the Etag header to be configurable. However, the default behavior of the Apache service was not changed. The versions of Apache used by the BIG-IP system support the FileETag httpd setting required to configure the Etag header.

Note: For more information about this Apache vulnerability, refer to CVE-2003-1418. This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You can access the TMOS Shell (tmsh).

Procedures

Configuring the BIG-IP system to exclude inode information from Etags

Customers who need to comply with local security requirements can configure the BIG-IP system to exclude inode information from Etags. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To specify the format to be used for the Etag header, enter the following command:

    modify /sys httpd include "FileETag MTime Size"

  3. Save the configuration change by entering the following command:

    save /sys config

  4. To restart the httpd service, enter the following command:

    restart /sys service httpd

The Etag headers will no longer include the inode information for files. The Etag headers now appear similar to the following example:

ETag: "ced-eeed38c0"

Reverting the previous changes to the original setting

To revert the changes you made in the previous procedure back to the original setting, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To specify the format to be used for the Etag header, enter the following command:

    modify /sys httpd include none

  3. To save the configuration change, enter the following command:

    save /sys config

  4. To restart the httpd service, enter the following command:

    restart /sys service httpd
