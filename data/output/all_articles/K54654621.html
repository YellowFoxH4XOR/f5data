Environment

  • BIGIP LTM
  • Hardware C112 
  • Software version: 11.2.1

Cause

The cause is unknown, most likely a software error in the PSU polling. Software version is outdated and may miss report the hardware status. There have been many such issues in the older software versions which are out of support: K5903: BIG-IP software support policy.

Recommended Actions

Strongly advise to upgrade the the latest point release of a newer software version: K9502: BIG-IP hotfix and point release matrix.
