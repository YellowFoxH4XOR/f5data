Description

01070151:3: Rule [<irule_name>] error: Unable to find value_list (<datagroup_name>) referenced at line <#>: [<irule_command>] 
Unexpected Error: Validating configuration process failed.

In this error message, note the following:

  • <irule_name> is the iRule name.
  • <datagroup_name> is the name of the datagroup referenced by the iRule.
  • <#> is the line that references the datagroup.
  • <irule_command> is the iRules command that references the datagroup.

For example: 

01070151:3: Rule [/Common/redirect_irule] error: Unable to find value_list (redirect_irule_datagroup) referenced at line 27: [class match $combined starts_with redirect_irule_datagroup]
Unexpected Error: Validating configuration process failed.

Environment

  • An iRule that references one or more datagroups

Cause

The datagroup referenced by the iRule is not found in the configuration. It is needed to resolve iRule verification during configuration loading.

Note: Always use caution when modifying files. F5 recommends backing up each file prior to modification.

Recommended Actions

To resolve the iRule verification error during configuration loading, you can create a substitute datagroup using the name that is referenced in the iRule. To do so, perform the following procedure:

Impact of procedure: This procedure only creates a sample datagroup for the purpose of passing the iRule verification during configuration loading. It does not re-create the necessary data required for the affected iRule to function as intended.

Note: This procedure only creates one sample datagroup. You should repeat this procedure to recreate the remaining datagroups that are reported missing as needed.

  1. Log into the command line of the device.
  2. Edit the /config/bigip.conf using a text editor such as the vi editor. For example:

vi /config/bigip.conf

  1. Add the sample datagroup configuration stanza using the name that is referenced in the iRule. Using the previous example datagroup name redirect_irule_datagroup, the following is an example iRule:

    ltm data-group internal redirect_irule_datagroup {
         records {
                clientssl-noSSLv3 { }
         }
         type string
    }
  2. Save the modifications in the text editor and exit. Using the vi editor example, you can do so by typing the following key sequences: 

esc :wq!

  1. Validate the configuration by typing the following command:

tmsh load sys config verify

  1. If step 5 completes without errors, load the configuration by typing the following command: 

tmsh load sys config
