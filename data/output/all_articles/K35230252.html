Description

  • ASM reports daily subsystem errors
  • The following error message are logged on /var/log/asm

    ASM subsystem error (asm_config_server.pl,F5::Sigfile::AutoDownload::call_soap_server): SOAP request failed: 500 Connect failed: connect: No route to host; No route to host

  • The following error messages are logged on /var/log/ts/asm_config_server.log

    asm_config_server.pl|INFO|Jun 29 03:07:03.117|1508|F5::Sigfile::AutoDownload::call_soap_server,,Calling 'https://104.219.110.134/esd/services/ASMUpdate' for new Signature version.
    asm_config_server.pl|ERR|Jun 29 03:07:03.367|1508|F5::Sigfile::AutoDownload::call_soap_server,,SOAP request failed: 500 Connect failed: connect: No route to host; No route to host

Environment

  • ASM
  • Attack Signature update

Cause

Seen ASM subsystem errors correspond to the the daily Attack signatures update check and occurs when there is no route to the internet to connect to the ASM update server

Recommended Actions

If Internet access is not available, seen behavior is expected and messages can be ignored. If you want to stop the daily update check, you con perform the following steps:

  1. Connect to CLI
  2. Remove symbolic link

    rm -f /etc/cron.daily/asm_update_sigfile

  3. Restart crond

    bigstart restart crond
