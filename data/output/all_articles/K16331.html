K16331: FastL4 virtual servers may fail to pass traffic after the Idle Timeout setting is set to Immediate

Known Issue

Virtual servers that reference the FastL4 profile may fail to pass traffic. This issue occurs when the following condition is met:

  • You change the associated FastL4 profile's Idle Timeout setting, from a finite value to Immediate.

Impact

Affected virtual servers fail to pass traffic as expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The affected virtual server fails to pass traffic as expected.

Workaround

To work around this issue, you can change the Idle Timeout setting in the affected FastL4 profile, to a value other than Immediate. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility
  2. Navigate to Local Traffic > Profiles > Protocol.
  3. Click Fast L4.
  4. Select the affected FastL4 profile.
  5. For the Idle Timeout setting, select Specify and then enter the appropriate value for your application environment.
  6. Click Update.
