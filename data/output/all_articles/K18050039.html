K18050039: Enabling client certificate authentication for NGINX

Type
Support Solution
Published
2020-01-15
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus: R19, R18, R17, R16, R20, R14, R13, R15
Source
https://my.f5.com/manage/s/article/K18050039

Description

You can restrict access to your website or some parts of it by implementing client certificate validation.

Environment

  • NGINX Plus
  • NGINX SSL Termination
  • SSL client certificate

Cause

None

Recommended Actions

To enable client certificate authentication, you must make the following additions to either your http or server context.

Note: If you make these additions to the http context, all server contexts will inherit these settings.

  1. Enable client certificate validation by setting the ssl_verify_client directive to on.
  2. As a value of the ssl_client_certificate directive, specify a file with trusted CA certificates in the PEM format to verify client certificates.
  3. You can also increase the value of the ssl_verify_depth, which is 1 by default.
server {
    listen 443 ssl;
    ssl_certificate     cert.pem;
    ssl_certificate_key cert.key;
    ssl_verify_client on;
    ssl_verify_depth 3;
    ssl_client_certificate CA_cert.pem;
    #...
}
  1. Reload the nginx process by running the following command:
sudo nginx -t && sudo service nginx reload
