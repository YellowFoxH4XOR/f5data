K4888: FirePass does not modify links that contain the word ''exchange''

Topic

The Portal Access reverse-proxy engine contains several workarounds for Microsoft Outlook Web Access (OWA). These workarounds are based on keywords and disable the modifications that FirePass makes to the URLs that are used for OWA. These workarounds are necessary, because the modifications that FirePass makes to URLs are not compatible with OWA.

If you use OWA and then immediately switch to another site that uses the keyword exchange in the URL, FirePass may not translate the URL and the link will not work.

Workaround

To work around this issue, create a sed content processing script similar to the following example, that replaces one or more letters in the keyword exchange with the hexadecimal ASCII codes for those letters.

Example script

The following sed content processing script changes the letter x in "exchange" to its hexadecimal value of %78.

s/\/exchange\//\/e%78change\//g

Once this script is implemented, FirePass will modify URLs as expected and web browsers will print the characters correctly.

Note: For specific instructions about how to create a sed content processing script, refer to the FirePass Controller Administrator Guide.
