Known Issue

The BIG-IP system may reuse an ephemeral port that was recently used for a previous File Transfer Protocol (FTP) connection.

This issue occurs when the following condition is met:

  • Your configuration contains a virtual server that uses an FTP profile.

Impact

The BIG-IP system cannot pass FTP traffic, and the remote host may fail to connect or the FTP application may stop responding.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H461088 on the Diagnostics > Identified > Low screen.
  • The remote host connecting to the affected FTP virtual server experiences a connection failure and the application stops responding.
  • You review a tcpdump captured on the affected FTP virtual server and notice that the ephemeral port from a previous connection is reused.
