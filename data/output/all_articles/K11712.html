Known Issue

When you remove the Host Search Strings and Host Replace String fields in a Web application minimal patching configuration, the data reappears after you click Update.

F5 Product Development tracked this issue as ID 226715 (formerly CR142033) and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

Workaround

You can work around this issue by removing the header information from a web application patching configuration. To do so, perform the following procedure:

  1. Log in to the BIG-IP APM or Edge Gateway command line.

    Note: You will need to login using an account with sufficient permissions to delete configuration data.
  2. To remove the Host Search Strings entry, type the following command:

    bigpipe connectivity resource web application <web application name> host search strings none

    For example:

    bigpipe connectivity resource web application mywebapp host search strings none
  3. To remove the Host Replace String entry, type the following command:

    bigpipe connectivity resource web application <web application name> host replace string none

    For example:

    bigpipe connectivity resource web application mywebapp host replace string none
  4. To view the updated configuration, type the following command:

    bigpipe connectivity resource web application <web application name> list

    For example:

    bigpipe connectivity resource web application mywebapp list
  5. Examine the output to verify that the host search strings and host replace string entries were successfully removed from the configuration.

    For example:

    connectivity resource web application mywebapp {
    description "my web app"
    scheme patching enable
    item {
    host "www.example.com"
    ip 0.0.0.0
    mask 0.0.0.0
    order 1
    }
    }
