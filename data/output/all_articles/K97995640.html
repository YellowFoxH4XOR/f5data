K97995640: Trunking of interfaces on the BIG-IP Virtual Edition is not supported with the default vmxnet3 driver

Type
Support Solution
Published
2020-02-07
Updated
2025-04-02
Applies to
  • BIG-IP
  • Virtual Editions
  • Vmware ESXI and vCloud Director
Source
https://my.f5.com/manage/s/article/K97995640

Description

Trunking is supported on BIG-IP Virtual Edition (VE) from BIG-IP version 13.1.0 and later, and it is intended to be used with the Single Root I/O Virtualization (SR-IOV) interfaces but not with the default vmxnet3 driver.

Note: You can enter tmsh list net trunk to display the trunks configured on your BIG-IP system.

Trunking of the interfaces with the vmxnet3 driver may result in unstable network traffic.

Environment

  • BIG-IP Virtual Edition running in the VMWare ESXi hypervisor
  • A trunk is configured with interfaces, which use vmxnet3 driver

Cause

Trunking is not supported for the default vmxnet3 driver.

Recommended Actions

You can enable Single Root I/O Virtualization (SR-IOV). You need an SR-IOV-compatible network interface card (NIC) installed and the SR-IOV BIOS must be enabled.

An alternative approach is to configure the link aggregation at the VMWare ESXi hypervisor level. Doing so exposes the link aggregration as a single vmxnet3 interface. For more information about configuring link aggregation on the VMWare ESXi hypervisor, refer to VMWare documentation: LACP Support on a vSphere Distributed Switch.
