Topic

The FirePass system uses a standalone client or web browser plugins to provide users with VPN access to a private network through a FirePass system. The FirePass system supports the following operating systems and web browsers:

Operating systems

  • Microsoft Windows
  • Apple OS  X
  • Linux
  • Apple iOS
  • Google Android

Web browsers

  • Internet Explorer
  • Mozilla Firefox
  • Apple Safari

FirePass client compatibility

To view whether a specific version of an operating system or web browser is supported, refer to the  FirePass client compatibility matrix for your version:
