Description

  • ASM configuration not in sync even though status appears In-Sync
     

Environment

  • Sync configuration of ASM
  • HA pair
     

Cause

  • A device group for ASM is missing on: Security > Options > Application Security > Synchronization > Application Security Synchronization.
  • asm-sync is disable in the device group, 
    e.g.
    cm device-group Sync-Failover-Group {
        app-service none
        asm-sync disabled  <<<--------[!!]
        auto-sync disabled
        description none
        devices {
            bigip1.f5.com { }
            bigip2.f5.com { }
        }
        full-load-on-sync true
        hidden false
        network-failover enabled
        partition Common
        type sync-failover
    }
     

Recommended Actions

Enable asm-sync on a device group.

  1. On the Main tab, click Security > Application Security > Synchronization. The system displays a list of device groups of which this device is a member.
  2. On Device Group drop-down menu, select the device group whose members you want to synchronize.
  3. Click Save.
