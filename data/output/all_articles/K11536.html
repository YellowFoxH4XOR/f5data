Known Issue

This is the result of a known issue. When upgrading a system that contains a FIPS enabled card to BIG-IP version 10.1.0, the following error message is reported to the console:

ERROR, recvMCPreply: Got bad result: 010712d8:3: DNSSEC Key Generation 0 of key ksk6900.1 failed import.

When the configuration attempts to re-import the FIPS keys, duplicate keys are reported, and the configuration load fails.

F5 Networks Product Development tracked this issue as CR132910 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM or GTM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 Networks product hotfixes for BIG-IP version 10.x systems.
