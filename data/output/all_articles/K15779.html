Known Issue

The BIG-IP ARM show bgp neighbors command may not function.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to use BIG-IP ARM BGP routing.
  • You use the following command syntax in the BIG-IP ARM shell:

    show bgp neighbor <neighbor ip address> (advertised-routes|received prefix-filter|received-routes|routes)

    For example:

    show bgp neighbor 192.168.1.200 advertised-routes

Impact

The show bgp neighbors command produces an error message and does not display the neighbor's advertised routes.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The show bgp neighbor <neighbor ip address> advertised-routes command returns the following error message:

    % No such neighbor or address family
  • The show bgp neighbor <neighbor ip address> advertised-routes command output lists the known neighbor.

    For example:

    show bgp neighbor 192.168.1.200
    BGP neighbor is 192.168.1.200, remote AS 65010, local AS 65001, external link
    BGP version 4, remote router ID 192.168.1.200
    BGP state = Established, up for 00:05:15
    Last read 00:05:15, hold time is 90, keepalive interval is 30 seconds
    Neighbor capabilities:
    Route refresh: advertised and received (old and new)
    ...

Workaround

To work around this issue, you can retrieve the same information using alternate BIG-IP ARM command syntax. To do so, you can use any of the following command syntax examples:

Impact of workaround: The following workaround should not have a negative impact on your system.

  • show bgp (ipv4|ipv6) (unicast|multicast|) neighbors (A.B.C.D|X:X::X:X) advertised-routes
  • show ip bgp neighbors (A.B.C.D|X:X::X:X) advertised-routes
  • show ip bgp ipv4 (unicast|multicast) neighbors (A.B.C.D|X:X::X:X) advertised-routes

Command syntax parameters:

  • A.B.C.D: IPv4 neighbor IP address
  • X:X::X:X: IPv6 neighbor IP address
  • ipv4: Show IPv4 addresses
  • ipv6: Show IPv6 addresses
  • multicast: Show multicast prefixes
  • unicast: Show unicast prefixes
