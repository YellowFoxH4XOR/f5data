K35735853: Error installing: java.security.InvalidKeyException: IOException : Short read of DER length

Type
Support Solution
Published
2021-12-02
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K35735853

Description
When attempting to install a utility license to a BIG-IP from the BIG-IQ, you may encounter this error:
Error installing: java.security.InvalidKeyException: IOException : Short read of DER length

Environment

  • BIG-IQ License Manager

Cause
BIG-IQ was installed with a System Personality of "Central Manager" but the BIG-IQ license is only for BIG-IQ License Manager.

Recommended Actions

  1. Re-install BIG-IQ.
  2. At the first step of the BIG-IQ installation wizard (License) select "Skip License".
  3. Proceed through the installation steps.
  4. When reaching step 4 - System Personality - be sure to select "BIG-IQ License Manager."
  5. Complete installation.
  6. License BIG-IP device as unmanaged device.

Additional Information
None.
