K000132130: How to disable the "Display all [number] items? (y/n)." confirmation in TMSH

Type
Support Solution
Published
2023-02-28
Updated
2024-11-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000132130

Description

The BIG-IP asks for a confirmation to display all the configuration items when executing a command from an automation tool, which is unable to interact with TMSH.


Environment

  • Automation tool used to retrieve information from the BIG-IP
  • CLI preference display-threshold setting
  • TMOS


Cause

By default, the CLI preference, display-threshold is set to 100, which will trigger the question Display all [number] items? (y/n) when more than 100 items are configured.


Recommended Actions

To disable the confirmation question when displaying more than 100 items, you can set the CLI preference display-threshold value to 0 and pager to disabled as follows:

Log in to TMSH with the user account used with the automation tool. Enter the following commands:

1. modify cli preference pager disabled display-threshold 0
2. save sys config

After the configuration change, then you can execute a command to display the objects, for example, the show running-config command to verify the new behavior.

Note: This configuration will only affect the user that made this configuration change in TMSH. 
Note: You only need to make the CLI preference change, save, and ConfigSync to the device group (if applicable) once. The setting will persist across subsequent log ins and reboots.
