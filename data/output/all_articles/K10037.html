Topic

F5 recommends that when you download software, you also download the associated MD5 checksum file along with the F5 software. The MD5 file is used to test the integrity of the installation file.

Alternate md5sum checksum values for an ISO image normally indicate that the installation file is corrupted or truncated. However, results might be misleading in the following two conditions:

  • The BIG-IP system reports a different checksum value for ISO installation files than the md5sum command.

    The MD5 checksum hash value reported by the md5sum command is different from the hash value reported for the ISO file by the Configuration utility and the TMOS Shell (tmsh). The hash reported when you run the md5sum command is the checksum for the ISO file itself and is used to verify the integrity of the ISO file after downloading it from the F5 Downloads site. The hash reported by the Configuration utility and tmsh is the embedded MD5 checksum contained in the ISO file.

    Note: In BIG-IP 10.x, the MD5 checksum value is displayed in the Software Management page of the Configuration utility. In BIG-IP 11.x, you can view the MD5 checksum values using the tmsh list sys software image command.

  • A temporary ISO file is created in the image library (/shared/images) during installation.

    During installation, a smaller version of the ISO image is copied to /shared/images, but with the original name. The checksum value for the temporary file and the original image file downloaded from downloads.f5.com will be different. The checksum values also vary between systems because they are built locally.
