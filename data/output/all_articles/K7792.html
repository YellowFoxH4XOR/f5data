K7792: Network Access connections revert to default IP address pool if the selected IP address pool name contains only numeric characters

Known Issue

This is the result of a known issue. When you configure a Network Access connection and select an IP address pool whose name contains only numeric characters, users who connect to that Network Access connection will be assigned IP addresses from the Default IP address pool instead of from the IP address pool you selected.

Note: Network Access IP address pools are configured on the Network Access : Global Settings page. Network Access connections are configured on the Network Access : Resources page.

F5 Product Development tracked this issue as CR83532, and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-552-10 has been issued for FirePass version 5.5.2, and Cumulative Hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

To work around this issue, ensure that all IP address pool names contain at least one letter. For example, rename IP address pool 123 to pool123.
