K000152624: Error "Invalid keyword '<IANA Cipher Suite Name>' in ciphers list for profile" when trying to modify ciphers in ssl profile configuration

Description

Weak SSL/TLS ciphers, including CBC-mode and RSA key exchange ciphers, may be present in the assigned client SSL profile on BIG-IP LTM. Attempts to remove these ciphers can result in errors if incorrect cipher string formats are used. 

Example error message:

01070312:3: Invalid keyword 'ecdhe_rsa_with_aes_128_cbc_sha' in ciphers list for profile /Common/Custom_Ciphers

Environment

  • BIG-IP LTM
  • client-ssl or server-ssl profile

Cause

The cipher string is not formatted according to F5's requirements.

Recommended Actions

To solve the issue, use F5’s internal cipher names in the cipher string (e.g., ECDHE-RSA-AES128-CBC-SHA instead of TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA). Refer to official F5 documentation for a full list of supported cipher names.

To edit the SSL Profile: 

1. Go to Local Traffic > Profiles > SSL > Client (or Server) in the BIG-IP Configuration utility.
2. Select your target SSL profile.
3. Set configuration level to Advanced.
4. Enable the Custom option for Ciphers.
5. Add the cipher string matching your needs. 

For example, to exclude TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA from DEFAULT list use:
DEFAULT:!ECDHE-RSA-AES128-CBC-SHA

Use this command to verify which ciphers will be enabled:
tmm --clientciphers '<your_cipher_string>'
