Known Issue

Access policy client type agent may mislabel F5 Access clients.

This issue occurs when the following conditions are met:

  • You attempt to establish an access session from an Android or IOS device using the F5 Access 3.0.7 client.
  • The BIG-IP APM access policy is configured with the client type Server-Side Endpoint Security.
  • You have configured the client type access ending as Allow for the client type F5 Access, and as Deny for the client type Edge Client.

Impact

The access session fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to establish an access session to a BIG-IP APM access profile, where the configured access policy is specifically configured for the client type F5 Access and the access policy denies access from the session using the client type Edge Client, the access session is denied. 
  • When you view the access session log for the access session, you are denied access based on the client type Edge Client.
