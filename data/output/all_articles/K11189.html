Topic

In BIG-IP 9.1.1 through 10.0.1, the following files, which are related to the password change process, are present on the file system of the BIG-IP system:

FileFile typeDescription
/usr/bin/f5passwdSymbolic link to ./passwdThis is a symbolic link to the /usr/bin/passwd file.
/usr/bin/passwdBash script text executableWhen this script is executed, it performs additional tasks other than updating the user’s password in the /etc/shadow file. For example, if the user whose password is being changed is the ConfigSync user, the password is also updated in the MCP database, or if the root password is being modified, the changes are also synchronized to the SCCP or AOM subsystem.
/usr/bin/passwd.rootELF 32-bit LSB executableThis is the standard passwd utility available on most Unix operating systems; however, the file was renamed.

Beginning in BIG-IP 10.1.0, the f5passwd symbolic link is no longer present. In addition, the passwd.root file was renamed to passwd.bin.

If you have any scripts or procedures that invoke the f5passwd utility, you may safely replace the f5passwd command with the passwd command.
