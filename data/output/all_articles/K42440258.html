K42440258: Getting error '01070344:3: Cannot delete referenced virtual address /Common/x.x.x.x' after changing or syncing configuration.

Type
Support Solution
Published
2020-06-15
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 14.1.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0
Source
https://my.f5.com/manage/s/article/K42440258

Description

Unable to change the virtual server configuration. You have this error message.

01070344:3: Cannot delete referenced virtual address /Common/x.x.x.x.

Environment

  • BIG-IP LTM VE
  • Address-list configuration
  • Traffic Matching Criteria (TMC) is configured to the virtual server

Cause

ID 844085: GUI gives error when attempting to associate address list as the source address of multiple virtual servers with the same destination addres

Recommended Actions

  1. Delete the virtual server that the address list shown in the error was using.
  2. Delete the address list shown in the error.
  3. Modify the Virtual Server configuration.
  4. Re-create the address list and virtual server that was previously deleted.

Additional Information

None.
