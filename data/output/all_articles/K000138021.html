Description

Cloud load balancer is unable to detect BIG-IP offline mode when probing non-floating virtual address.

The health check is successful even when BIG-IP is "Offline"

 

Environment

  • BIG-IP HA
  • Cloud environment
  • Cloud load balancer

Cause

Misconfiguration

Additional iRule logic needed

Recommended Actions

See video in https://community.f5.com/t5/technical-articles/failing-faster-in-the-cloud/ta-p/281744

Additional Information

1. Create VIP vs_self_ip (self-ip, http profile, non-floating IP)

2. Create VIP bogus_vs (255.255.255.254, http profile, floating traffic-group)

3. Attach "monitor_respond_200" iRule to bogus_vs:

when HTTP_REQUEST {
   HTTP::respond 200 System Responding
}


4. Attach "virtual_bogus_vs" iRule to vs_self_ip:

when CLIENT_ACCEPTED {
   virtual bogus_vs
}
