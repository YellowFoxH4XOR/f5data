Topic

You can use the bigpipe display service command to control whether BIG-IP or 3-DNS systems display TCP and UDP port numbers or names at the command line.

To configure BIG-IP or 3-DNS systems to display port numbers at the command line, type the following command:

bigpipe display service numbers

After specifying port numbers to be displayed as numbers, output from the bigpipe virtual show command would appear similar to the following example:

VIRTUAL 192.168.10.1        UNIT 1
   |        (cur, max, limit, tot) = (0, 0, 0, 0)
   |        (pckts,bits) in = (0, 0), out = (0, 0)
   |        PASS ANY IP: disabled
   +---+--> SERVICE   80              ENABLED
       |        hw_acceleration none
       |        (cur, max, limit, tot) = (0, 0, 0, 0)
       |        (pckts,bits) in = (0, 0), out = (0, 0)
       +---+--> POOL test
           +--> MEMBER 10.10.10.1:80           UNCHECKED
                    (cur, max, limit, tot) = (0, 0, 0, 0)
                    (pckts,bits) in = (0, 0), out = (0, 0)

To configure BIG-IP or 3-DNS systems to display port names at the command line, type the following command:

bigpipe display service names

After specifying port numbers to be displayed as names, output from the bigpipe virtual show command would appear similar to the following example:

VIRTUAL 192.168.10.1        UNIT 1
   |        (cur, max, limit, tot) = (0, 0, 0, 0)
   |        (pckts,bits) in = (0, 0), out = (0, 0)
   |        PASS ANY IP: disabled
   +---+--> SERVICE   http            ENABLED
       |        hw_acceleration none
       |        (cur, max, limit, tot) = (0, 0, 0, 0)
       |        (pckts,bits) in = (0, 0), out = (0, 0)
       +---+--> POOL test
           +--> MEMBER 10.10.10.1:http         UNCHECKED
                    (cur, max, limit, tot) = (0, 0, 0, 0)
                    (pckts,bits) in = (0, 0), out = (0, 0)
