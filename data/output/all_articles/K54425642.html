Issue

Error Message

012a0007 BIGIP_LIBHAL_REPORT_LIBHAL_DEBUG

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • An event associated with the hardware platform monitoring code is observed.
  • The log.libhal.level database variable is set to Debug.

Impact

None. Debug-level messages are informational only.

Recommended Actions

F5 recommends resetting the log.libhal.level database variable to its default value of Notice. To do so, run the following command in command-line interface:

tmsh modify sys db log.libhal.level value Notice
