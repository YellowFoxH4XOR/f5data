Known Issue

This is the result of a known issue. Issuing a bigpipe interface show command on a BIG-IP 1000 or 2400 platform causes the command output to stall and not report all interface information. Issuing a bigpipe interface show -j command results in only the management port and 0.1 (TMM interface) to be displayed.

F5 Product Development tracked this issue as CR124714 and it was fixed in BIG-IP LTM version 9.4.8. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in BIGIP-9.4.7-326.1-HF1 issued for BIG-IP version 9.4.7. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
