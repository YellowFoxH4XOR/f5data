Topic

You should consider using this procedure under the following condition:

  • You want to import or export a security policy from a BIG-IP ASM system using the TMOS Shell (tmsh).
  • Additionally, you may want to Apply or Publish the imported policy.

Description

The BIG-IP ASM system offers various tmsh commands to manage application security policies including viewing, exporting, and importing. You can save a security policy to the selected output file format when exporting. For importing, you can create a new policy or overwrite an existing policy from the previously saved policy file on the original ASM system or on a different ASM system with the same or later BIG-IP software version installed.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the BIG-IP command line or tmsh.

Procedures

  • View configured security policies using tmsh
  • Export a security policy using tmsh
  • Import a security policy using tmsh
  • Apply imported security policy using tmsh

View configured security policies using tmsh

You can list and view all the configured security policies on the BIG-IP ASM system using tmsh commands. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To display security policies, enter the following command:

    list asm policy

Export a security policy using tmsh

The application security policy can be exported in one of three supported output file formats. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To export the security policy, use the following command syntax:

    save asm policy <policy_name> <file_format> <target_file_name>.xml

    For <file_format>, you can use one of the following supported options:

    • To save the security policy as a policy archive file (PLC file), use bin-file.
    • To save the security policy as an XML file with a reduced file size, use min-xml-file.
    • To save the security policy as an XML file, use xml-file.

    For example, to export the security policy test_policy to a policy archive file, enter the following command:

    save asm policy test_policy bin-file test_policy.plc

    Note: The command saves the security policy XML output to the /var/tmp directory.

Import a security policy using tmsh

You can import a security policy from the previously exported policy file using tmsh, and optionally, overwrite the existing policy. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To import the security policy, use the following command syntax:

    load asm policy <policy_name> overwrite file <source_policy_file>

    For example, to import the policy archive file test_policy.plc in the /var/tmp directory to the security policy named test_policy, enter the following command:

    load asm policy test_policy overwrite file /var/tmp/test_policy.plc

    Note: The command overwrites the existing policy or creates a new policy if no security policy is configured with a matching name.
     

Apply imported security policy using tmsh


You can apply the imported security policy using tmsh.  To do so, perform the following procedure:

Impact of procedure:  Performing the following procedure will apply the changes to the security policy.
  1. Log in to tmsh by entering the following command:

    tmsh

  2. To import the security policy, use the following command syntax:

    publish asm policy <policy_name> 

    For example, toapply the policy named test_policy, enter the following command:

    publish asm policy test_policy
