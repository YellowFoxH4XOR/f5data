K9538: Citrix access may fail when Citrix Client Detection is enabled when using Citrix Server version 4.6 or higher

Topic

When delivering Citrix Presentation Server through FirePass Portal Access, published applications may fail to launch and return the following error message:

An error has occurred while connecting to the requested resource

This issue may occur when the following criteria are true:

  • The Citrix Presentation Server has Citrix Client Detection enabled
  • The Citrix Presentation Server is running version 4.6 or higher

    Note: For older versions, refer to K8727: Automatic logon to a Citrix Server versions 4.0 through 4.5 web interface fails.
  • The FirePass Controller and Citrix Presentation Server are configured within the same Citrix zone
  • The Citrix Web Interface is presented to the client through FirePass Portal Access

Note: For more information about Citrix zones, refer to your Citrix documentation.

Note: For more information, refer to K8644: Overview of Citrix access through Portal Access.

When Citrix Client Detection is enabled, the content delivered to the client is dependent on whether the client is deemed to be located inside or outside the Citrix zone. The Citrix Client Detection process determines how the Citrix ICA client will be started; either an ICA file is sent to the browser (and the browser starts the ICA client), or an HTML page is sent with the ICA client embedded (the ICA client starts as embedded object).

When the client is deemed to be within the Citrix zone, as defined by the AlternateResult value stored the WINGSession cookie, which is set by the Citrix Client Detection process, the Citrix server will choose to embed the contents of the ICA configuration within the HTML response document rather than return the ICA file with the appropriate Content-Type HTTP header set to application/x-ica. When this situation occurs, the client will fail to start through FirePass Portal Access and return the example error message

Workaround

Users can work around this issue by ensuring that the FirePass is located outside of the same Citrix zone as the Citrix Presentation Server.

Alternatively, users may implement this Content Processing Script by performing the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Click Portal Access in the navigation menu.
  3. Click Content Processing.
  4. Click the Preprocessing Scripts tab.
  5. Click the add icon (i-bar) to Add new Favorite, under the Web Applications content Processing Scripts section.
  6. In the Processing script name field, enter a name for the script
    For example:
    Citrix Script
  7. In the URL match patterns field, enter the following text:
    */default.aspx*
  8. In the Content Type field, enter the following text:
    text/html
  9. Leave the Allow caching option cleared.
  10. In the Sed processing field, enter the following text:
    s@launcher.aspx@launch.ica@g
  11. In the Processing drop down menu, select Pre-process response data (before content patching).
  12. Click the Add New button.
