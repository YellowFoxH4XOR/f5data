Topic

By default, 3-DNS does not probe disabled objects. Beginning in version 4.5.12 and 4.6.3, you can configure 3-DNS to probe disabled objects. When an object is disabled, health checks are not performed and the object is marked as down. When the object is enabled, the object remains marked as down until a succesful health check is performed.

Configuring the 3-DNS to probe disabled objects allows the objects to be disabled and continue to be marked as up or down based on the health check results. If a disabled object is currently marked as up when it is re-enabled, the system can use the object without the delay of performing a new health check.

To configure the 3-DNS to probe disabled objects, type the following command from the command line:

bigpipe global probe_disabled_objects yes

To ensure the 3-DNS will continue to probe disabled objects, add the following line to the globals section of the wideip.conf file:

global probe_disabled_objects yes

To configure the 3-DNS to stop probing disabled objects, type the following command from the command line:

bigpipe global probe_disabled_objects no

To ensure the 3-DNS will not continue to probe disabled objects, remove the following line from the globals section of the wideip.conf file:

global probe_disabled_objects yes
