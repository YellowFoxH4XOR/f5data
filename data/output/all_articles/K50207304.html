K50207304: LTM remote authentication does not honour the line-order for user groups

Type
Support Solution
Published
2020-01-22
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.0.X, 15.0.1, 15.0.0, 14.1.5, 14.1.4, 14.1.X, 14.1.2, 14.1.0, 14.1.3
Source
https://my.f5.com/manage/s/article/K50207304

Description

  • LTM remote authentication does not honour the line-order for user groups.
  • Users with remote authentication belonging to more than one remote role group, might experience wrong role assigned.

Environment

  • After upgrades to v14.1.x
  • LDAP Remote authentication
  • Remote role user groups
  • Users belonging to 2 different role groups

Cause
Bug ID 762385: Wrong remote-role assigned using LDAP authentication after upgrade to 14.1.x and later

Recommended Actions

  • Upgrade to a fixed version.
  • To workaround this issue on affected versions, invert the line-order for the remote role groups, in order have the highest line-order on the role you wish to take precedence. To do this:
    1. Log into the GUI (Configuration Utility)
    2. Navigate to System >> Users >> Remote Role Groups
    3. Invert the Line-Order of all groups

Additional Information
On version 14.1.x line order has changed to work in opposite order from previous versions. Affected versions use the highest line-order instead of the lowest to select the user role for a user in more than one remote role group.
This example shows the difference on how the line-order can be seen on tmsh for affected and non-affected versions.

  • NON-affected versions: (role administrator taking precedence)
    #tmsh list auth remote-role
    auth remote-role {
        role-info {
            Group_Example1 {
                attribute "memberOF=CN=F5 Admins,CN=Users,DC=uk"
                console tmsh
                line-order 3
                role administrator
                user-partition All
            }
            Group_Example2 {
                attribute "memberOF=CN=F5 Read Only Users,CN=Users,DC=uk"
                line-order 15
                role guest
                user-partition All
            }
        }
    }
  • Affected versions: (after the workaround for role administrator to take precedence)
    #tmsh list auth remote-role
    auth remote-role {
        role-info {
            Group_Example1 {
                attribute "memberOF=CN=F5 Admins,CN=Users,DC=uk"
                console tmsh
                line-order 15
                role administrator
                user-partition All
            }
            Group_Example2 {
                attribute "memberOF=CN=F5 Read Only Users,CN=Users,DC=uk"
                line-order 3
                role guest
                user-partition All
            }
        }
    }
