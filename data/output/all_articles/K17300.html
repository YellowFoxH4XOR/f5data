Known Issue

Users may be unable to view pool objects in the Configuration utility.

This issue occurs when all of the following conditions are met:

  • In the Configuration utility, you navigate to Local Traffic > Nodes > Node List.
  • You sort the Node List page by Address.
  • You subsequently navigate to the Configuration utility Local Traffic > Pools > Pool List page.

Impact

Users cannot view pool objects by using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you navigate to the Local Traffic > Pools > Pool List page, in the Configuration utility, the system displays an error message similar to the following example:

    General database error retrieving information.

Workaround

To work around this issue, you can sort the Node List page by using a different filtering option than Address. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in the Configuration utility.
  2. Navigate to Local Traffic > Nodes > Node List.
  3. Sort the Node List page by using a filtering option other than Address.
