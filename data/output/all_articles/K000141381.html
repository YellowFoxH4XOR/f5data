Description

You want to access particular partition of BIG-IP's bash.

Doing so will make all bash commands relative to chosen partition.

Environment

  • BIG-IP

Cause

None

Recommended Actions

If you have multiple partition in your BIG-IP. You need to switch to a particular partition of bash of BIG-IP, follow the below steps:

1. Enter to TMOS shell

tmsh

2. To check what all partition you have

cd /<press_tab>

3. Change the partition

cd /partition_name

4. Exit out of TMOS. Now you will be in the bash shell of the particular partition. 

bash

Note: Though you will not see difference in the hostname or location where you are at the moment directly, you could confirm that the partitions has actually change by checking the route or interface  information by using route -n and ip a commands respectively.

Additional Information

When you exit the current bash shell you will return to TMSH.
