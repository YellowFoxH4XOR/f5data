K45343742: Modifying SSH Port Number to Non-default Number May Cause VIPRION Systems to Fail to Collect QKViews From Secondary Blades

Type
Support Solution
Published
2022-12-01
Updated
2023-02-21
Applies to
  • VIPRION Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K45343742

Description
Modifying SSH port number to a non-default port number may cause VIPRION systems to fail to collect QKViews from other blades.

Environment

  • This occurs when SSH port number has been modified.

Cause
This occurs when SSH port number has been modified from the default TCP port 22.

Recommended Actions

  1. Keep the SSH port number as its default value of TCP port 22.
  2. Only allow access from trusted network.

Additional Information
