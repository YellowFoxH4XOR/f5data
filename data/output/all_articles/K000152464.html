Description

This KB articles explains how to run the ldapsearch command against value with special character

Environment

  • APM
  • ldapsearch

Cause

None

Recommended Actions

Here is the example:

1) The group name contains the special character (#) in DN on ActiveDirectory (aka LDAP) server, the character is escaped on AD side itself by '\':

 

DistinguishedName : CN=ruslan\# test,DC=test,DC=local <==== (!)

GroupCategory   : Security

GroupScope    : Global

Name       : ruslan# test

ObjectClass    : group

ObjectGUID    : 0191e5f1-5dc3-4b3c-8f6f-2187788dcaa3

SamAccountName  : ruslan# test

SID        : S-1-5-21-3438187356-2671537110-1008693775-1114

 

2) To run ldapsearch command from BIGIP's CLI, run the command like below, replace <REPLACE> with actual values, notice that extra escape character '\' is put in front of already escaped sequence '\#' on AD:

 

[root@v13hf2:ModuleNotLicensed::Active:Standalone] config # ldapsearch -xLLL -h <REPLACE_SERVER_IP> -b "CN=ruslan\\# test,dc=test,dc=local" -D cn=a01,cn=users,dc=test,dc=local -w '<REPLACE_WITH_PASSWORD'
