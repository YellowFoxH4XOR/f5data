K000091508: Manually Configure ClickHouse to Cleanup Data With Desired Days

Type
Support Solution
Published
2022-04-20
Updated
2022-04-27
Source
https://my.f5.com/manage/s/article/K000091508

Description

You would like to configure ClickHouse to manually cleanup the data with your own desired days

 

Environment

  • NGINX Controller ADC 3.22.2
  • Clickhouse

 

Cause

None

 Recommended Actions

  • Backup ClickHouse configMap.
    • Run this command. kubectl get cm $(kubectl get cronjob db-rollup-job -ojsonpath='{.spec.jobTemplate.spec.template.spec.volumes[1].configMap.name}') -o yaml > clickhouseconfigmap.yaml
      1. Copy the backup configMap.
        • cp clickhouseconfigmap.yaml clickhouseconfigmap.yaml_backup
      2. Edit the YAML file clickhouseconfigmap.yaml
      3. In dropRules section, you can see table metrics, metrics_5mins, metrics_1hour etc).
        • Use text editor to configure the maxDays with your own desired setting.

Snippet of the YAML file below:

dropRules:

  - database: "controller"

  table: "metrics"

  maxDays: 8. <<<< edit this to your desired days

  # 12 GiB

  maxSize: 12884901888

  - database: "controller"

  table: "metrics_5min"

  maxDays: 30 <<<< edit this to your desired days

  # 4 GiB

  maxSize: 2147483648

  - database: "controller"

  table: "metrics_1hour"

  maxDays: 450 <<<< edit this to your desired days

  # 5 GiB

  maxSize: 5368709120

  - database: "controller"

  table: "metrics_1day"

  # minimum 3 years due to licensing requirements

  maxDays: 1800 <<<< edit this to your desired days

  # 3 GiB

maxSize: 3221225472

 

  • Run this command to apply the change. kubectl apply -f clickhouseconfigmap.yaml
