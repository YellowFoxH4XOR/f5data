Known Issue

This is the result of a known issue. The BIG-IP system does not support hostnames with more than 64 characters.

Note: You type the fully qualified domain name for the system in the hostname setting of the BIG-IP Configuration utility.

Starting with BIG-IP versions 9.0 through 9.4.1, it is possible to define a hostname greater than 64 characters using the BIG-IP Configuration utility. However, the UNIX hostname is not set.

For BIG-IP versions  9.4.2 and later, if you attempt to set a hostname greater than 64 characters using the BIG-IP Configuration utility, the following error message is displayed:

hostname: name too long

F5 Networks Product Development is tracking this issue as CR81922.
