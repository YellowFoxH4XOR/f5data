Known Issue

This is the result of a known issue. When you enable network boot from an external server on a BIG-IP LTM system, the SCCP attempts to obtain an IP address from a DHCP server on the local subnet. If the SCCP fails to obtain an IP address, it does not report an error message. In addition, the SCCP does not report when it successfully obtains an IP address. As a result, it may be difficult to troubleshoot issues with network boot.

F5 Product Development tracked this issue as CR41706, and it was fixed in BIG-IP LTM 9.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.
