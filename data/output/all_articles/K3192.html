K3192: Limiting the amount of information that is displayed on the 3-DNS Statistics pages

Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to

  • 3-DNS: 4.6.4
Source

Topic

By default, the 3-DNS Controller does not limit or filter the data that is displayed on the Statistics page. To reduce the amount of data, you can create and apply a filter_stats region template.

Note: You cannot make the following changes from the Configuration utility; you must make them from the command line.

filter_stats region template #1

Use the following template to modify the /config/3dns/include/region.inc file to include the region.filter.

Note: If the /config/3dns/include/region.filter file does not exist, create the file.

delete rdb user region "filter_stats"
rdb user {
region {
name "filter_stats"
[IP subnet specifications]
[region "<nested region reference>"]
}
}

Note: Issuing the delete command before declaring the region allows you to modify and reload the region.filter file. You need to drop and redefine a region in order to be able to remove items from it.

filter_stats region template #2

The following example shows an additional user-defined region nested into the filter_stats region. This filter example will refresh the LDNS, Path, or Requests Statistics pages and will display only information related to LDNS servers from F5 Networks, AOL, or the 200.0.0.0/8 network.

Use the following template to modify the /config/3dns/include/region.inc file to include the region.filter.

Note: If the /config/3dns/include/region.filter file does not exist, create the file.

rdb user {
region {
name "F5 Networks"
207.17.117.0/24
}
region {
name "AOL"
64.12.104.0/24
64.12.105.0/24
64.12.96.0/24
152.163.0.0/16
195.93.1.0/24
195.93.0.0/24
198.81.4.0/24
198.81.5.0/24
205.188.0.0/16
202.67.64.0/24
}
region {
name "filter_stats"
region "F5 Networks"
region "AOL"
200.0.0.0/8
}
}

Note: Issuing the delete command before declaring the region allows you to modify and reload the region.filter file. You need to drop and redefine a region in order to be able to remove items from it.
