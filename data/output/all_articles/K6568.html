Topic

This article applies to BIG-IP 9.x. For information about other versions, refer to the following article:

  • K15474: Determining the amount of RAM installed on the BIG-IP system (10.x - 12.x)
You can determine the amount of RAM installed on a BIG-IP switch or server appliance by using the bigpipe global or bigpipe platform command.
 
For BIG-IP versions prior to 9.4.0, you mus use the bigpipe global command. For BIG-IP versions 9.4.0 and later, the bigpipe platform command will provide the total memory amount of memory installed.

The total RAM is reported in the command output as follows:

BIG-IP 9.4.0 through 9.4.8:

The installed RAM is listed under Physical memory of the Platform Information section.

The RAM in the following example is 1.512 GB:

Note: The following output has been truncated for clarity.

# bigpipe platform

PLATFORM INFORMATION --
| Marketing Name: BIG-IP 3400
| BIOS revision: TYAN S2707 Motherboard v1.05a 0227041730 OBJ-0075-00 REV. F
| base MAC: 00:01:D7:32:07:80
| PVA Version: 2
| Physical memory: 1.512GB

BIG-IP 9.2.0 through 9.3.x:

The installed RAM is listed under Memory, host.

The RAM in the following example is 768.0 M:

# bigpipe global | grep -i memory
Memory (total, used) = TMM (380.0M, 19.57M), host (768.0M, 341.0M)

BIG-IP 9.0.0 through 9.1.3:

The installed RAM is listed under Memory (total).

The RAM in the following example is 2.000 G:

# bigpipe global | grep -i memory
Memory (total, used) = (2.000G, 207.7M)
