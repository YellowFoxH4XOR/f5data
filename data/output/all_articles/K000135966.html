K000135966: Warning "recursive-clients soft limit exceeded"

Description

The article describes the issue when a recursive-client limit, which is the option of BIND, was hit on the BIG-IP DNS.

 

In the /var/log/daemon.log there are logs similar to:

Aug 17 17:19:47 bigip.test.com warning named[20490]: 17-Aug-2023 17:19:47.368 client: warning: client @xxxxx 10.10.10.10#55880 (example.com): view external: recursive-clients soft limit exceeded (901/900/1000) aborting oldest query

 

Environment

  • BIG-IP DNS
  • DNS recursion enabled

Cause

BIG-IP uses the default limit of 1000 recursive clients.
It is not recommended to set the recursive-clients limit to a higher value, as the limit on recursive clients is important for preventing the exhaustion of server resources.

 

 Recommended Actions

None.
