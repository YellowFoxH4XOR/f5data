K11852: Pre-logon sequence antivirus checks may not work as expected if performed after entering Protected Workspace

Topic

When creating a pre-logon sequence that performs an antivirus check and creates a client Protected Workspace, if the Protected Workspace is entered before the antivirus checks are performed, the antivirus checks may fail or return unexpected results.

This behavior is expected.

Protected Workspace provides only a virtual working environment; therefore, F5 Networks does not recommend running antivirus checking inspectors whose results can be misleading, and at times certain antivirus-related functions may not work as expected. If antivirus-related functions are necessary, run them before entering Protected Workspace.

Note: For more information about creating pre-logon sequences and Protected Workspace, refer to the FirePass Controller Administrator Guide.
