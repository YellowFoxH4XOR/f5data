Description

Unable to install software image on GUI displaying "Waiting for product image" also on GUI displaying the result similar to the following.

(/Common)(tmos)# show sys software

-----------------------------------------------------------------------------------------------------------
Sys::Software Status
Volume  Slot  Product   Version   Build  Active                                     Status  Allowed Version
-----------------------------------------------------------------------------------------------------------
HD1.2      1   BIG-IP    16.1.3  0.0.12      no                                   complete              yes
HD1.2      2   BIG-IP    16.1.3  0.0.12      no                                   complete              yes
HD1.2      3     none      none    none      no  waiting for product image (BIG-IP 16.1.3)              yes   -->>!!
HD1.4      1   BIG-IP  16.1.2.2  0.0.28     yes                                   complete              yes
HD1.4      2   BIG-IP  16.1.2.2  0.0.28     yes                                   complete              yes
HD1.4      3   BIG-IP  16.1.2.2  0.0.28     yes                                   complete              yes

Environment

  • BIG-IP
  • vCMP system
  • Installing software image, preparing for upgrade
  • The reported software version is v14, v15, v16

Cause

This typically happens on multiblade systems where Primary blade is running version 14.1.0 or above and described in the following article.

Bug ID 817417: Blade software installation stalled at Waiting for product image

Recommended Actions

Manually upload the software image to the local storage (not the host itself).

  1. Importing the software image locally to the BIG-IP, this will upload the image to the Active slot.

    K34745165: Managing software images on the BIG-IP system
     
  2. Login to BIG-IP CLI to the active slot.
  3. Follow the Bug ID 817417 workaround to push the image to the issue slot which is having the issue.

    # scp /shared/images/<BIG-IP_image.iso> slot<number>:/shared/images

    For the example: 

    slot #2): scp /shared/images/BIGIP-16.1.3-0.0.12.iso slot3:/shared/images
     
  4. Check the installation status again, either on CLI or GUI.

None.
