Description

The ca-bundle.crt still shows expiration date after update it by going to: 

System  ››  Certificate Management : Traffic Certificate Management : Bundle Manager List  ››  ca-bundle

This method is also known as 'updating ca-bundle.crt using the CA Bundle Manager'.
 

Environment

BIG-IP version 13+

Cause

The BIG-IP has no internet access, so it can't reach to F5 cdn server. (url: https://cdn.f5.com)
The BIG-IP GUI does not have any indication of no internet access after you pressed the 'update' button. Therefore it caused false positive.

Recommended Actions

1. Manually update ca-bundle.crt by downloading the latest blended-bundle.crt from F5 Downloads and upload to the BIG-IP. Refer to: K60612439: Manually updating the BIG-IP default CA certificate bundle file
Note that this requires reboot.

Or

2. Configure the BIG-IP to have internet access to make sure it can reach https://cdn.f5.com/product/ca-bundle/blended-bundle.crt
Note that once BIG-IP has internet access, it should be able to download and update the ca-bundle as you press the 'update' button. It does not require a reboot.
 

Additional Information

K60612439: Manually updating the BIG-IP default CA certificate bundle file
