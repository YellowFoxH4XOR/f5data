Description

This guide provides step-by-step instructions for configuring an iRule on an F5 BIG-IP system to send logs via High-Speed Logging (HSL) whenever a client connects to a virtual server. This setup enables centralized logging for monitoring and troubleshooting by directing logs to specific syslog servers or logging platforms and can be used a template for other specific logging scenarios.

Procedures

Create HSL Pools

Before creating a pool, gather the IP addresses of the servers you want to include. Ensure that the remote log servers are configured to listen to and receive log messages from the BIG-IP system.

  1. Go to Local Traffic > Pools.
  2. The Pool List page opens. Click Create.
  3. The New Pool page opens. In the Name field, type a unique name for the pool.
  4. Using the New Members setting, add the IP address for each remote logging server:
    • Type an IP address in the Address field, or select a node address from the Node List.
    • Type a service number in the Service Port field, or select a service name from the list.
      • Note: Typical remote logging servers require port 514.
    • Click Add.
  5. Click Finished.
  6. Repeat for each additional pool.

Create log destinations

  1. Go to System > Logs > Configuration > Log Destinations.
  2. Select Create.
  3. For Name provide a unique name for the log destination.
  4. For Type select Remote High-Speed Log.
  5. For Pool Name select a pool you created previously.
  6. For Protocol select TCP or UDP depending on your log server configuration.
  7. Select Finished.
  8. Repeat for each pool you created.

Create log publisher

  1. Go to System > Logs > Configuration > Log Publishers.
  2. Select Create.
  3. For Name provide a unique name for the log publisher.
  4. For Destinations move the log destinations you created previously from the Available list to Selected.
  5. Select Finished.

Create the iRule

  1. Go to Local Traffic> iRules.
  2. Select Create.
  3. For Name provide a name for the iRule.
  4. For Definition use the example iRule in this article as a guide.
  5. Select Finished.

Use the following iRule to log client connections via HSL. Replace hsl_pools with the name of your log publisher. This iRule is designed to send logs to HSL pools:

iRule Example:

when CLIENT_ACCEPTED {
    set vs [IP::local_addr]:[TCP::local_port]

    # Open HSL connections with configured pools
    set hsl_pub [HSL::open -publisher /Common/hsl_pools] 
}

when SERVER_CONNECTED {
    set client [IP::client_addr]:[TCP::client_port]
    set srv [IP::remote_addr]:[TCP::remote_port]
    set log_message "<134>Client: $client connected to $vs and routed to server $srv at [clock format [clock seconds] -format {%Y-%m-%d %H:%M:%S}]"

    # Send logs to HSL pool
    HSL::send $hsl_pub $log_message 
}

Apply the iRule to the virtual server

  1. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  2. Select Edit in the Resources column of the target virtual server.
  3. In the iRules section select Manage.
  4. Select the iRule from the Available list and add it to the Enabled list.
  5. Select Finished.
