K1870: Reasons why the 3-DNS Configuration utility may display ''Internal Server Error''

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • 3-DNS: 4.6.4
Source

Topic

The Internal Server Error message can be caused by one of the following issues:

  • The /config/3dns/etc/wideip.conf file is missing. This will cause a parsing error.
  • The 3dnsconf.cgi is not able to read the wideip.conf file, because a link does not exist in the /config/3dns/etc/wideip.conf file. This will cause a parsing error.
  • The /config/3dns/etc/wideip.conf file contains errors.

Use the following procedures to troubleshoot these issues.

Missing /config/3dns/etc/wideip.conf file

  1. Type the following command:

    3dparse -picky

    The output should appear similar to the following:

    3dns45:~# 3dparse -picky
3dparse: Initializing ...
3dparse: Parsing /config/3dns/etc/wideip.conf
3dparse: SUCCESS
3dns45:~#

    If the /config/3dns/etc/wideip.conf file is missing, the output would appear as follows:

    3dns45:/config/3dns/etc# 3dparse -picky
3dparse: Initializing ... 
3dparse: Error - bad input filename: /config/3dns/etc/wideip.conf
3dns45:/config/3dns/etcc#
  2. If the wideip.conf file is missing, restore a backup copy of the wideip.conf file that does not have any errors.

    If you do not have a backup copy of the wideip.conf file, contact F5 Networks Technical Support for further assistance.

Missing link in the /config/3dns/etc/wideip.conf file

  1. If the wideip.conf file exists, type the following command to confirm that the link to the /config/3dns/etc/wideip.conf file exists in the /etc directory:
    dir /etc/wideip.conf

    If the link exists, the output will appear similar to the following:

    3dns45:/etc# dir /etc/wideip.conf
lrwxr-xr-x  1 root  wheel  28 Feb  4 08:52:15 2004 /etc/wideip.conf@ 
   -> /config/3dns/etc/wideip.conf
3dns45:/etc#

    If the link does not exist, the output will appear similar to the following:

    3dns45:/etc# dir /etc/wideip.conf
ls: /etc/wideip.conf: No such file or directory
3dns45:/etc#
  2. If the link is missing, type the following commands to recreate it:
    cd /etc
ln -s /config/3dns/etc/wideip.conf

Errors exist in the /config/3dns/etc/wideip.conf file

  1. If the file exists, check to see if it contains errors, by typing the following command:

    3dparse -picky

    The output should appear similar to the following:

    3dns45:~# 3dparse -picky
3dparse: Initializing ... 
3dparse: Parsing /config/3dns/etc/wideip.conf
3dparse: SUCCESS
3dns45:~#

    If the /config/3DNS/etc/wideip.conf file contains errors, the output would appear similar to the following:

    Note: The specific error you receive may vary.

    3dns45:~# 3dparse -picky
3dparse: Initializing ... 
3dparse: Parsing /config/3dns/etc/wideip.conf
/config/3dns/etc/wideip.conf:43: "parse error" at character '{' in line:
  2. If the wideip.conf file contains errors, you can restore it from a backup that does not have any errors, or, if you are comfortable editing the file manually, use a text editor such as vi or pico and correct the file.

    If you do not have a backup copy of the wideip.conf file, contact F5 Networks Technical Support for further assistance.

    Note: If you are not comfortable editing the wideip.conf file, contact F5 Networks Technical Support for assistance. Be prepared to provide access to your system or to send the wideip.conf file with the UCS file (which you can generate by running the b config save /var/tmp/3dns_ucs_file.ucs command).

  3. After you update the file, verify that it contains no errors by running the 3dparse -picky command.
  4. When no errors are reported, type the following command to instruct 3dnsd to load the modified wideip.conf file:

    3ndc restart

    You do not need to restart the web daemon, but it may be necessary to close and reopen your browser.
