K94045674: ''spanning'' property will added to virtual addresses after upgraded to version BIG-IP 12.1.0 onward

Type
Support Solution
Published
2021-12-29
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K94045674

Description

You may observe "spanning" property added to network virtual address after upgraded to version BIG-IP 12.1.0 onward.

For example :
  • Before upgrade :
ltm virtual-address 0.0.0.0 {
    address any
    arp disabled
    icmp-echo disabled
    mask any
    traffic-group traffic-group-1
}
  • After upgraded to v12.1.0 onward :

ltm virtual-address 0.0.0.0 {
    address any
    arp disabled
    icmp-echo disabled
    mask any
    spanning enabled               <---                        
    traffic-group traffic-group-1
}

Environment

  • BIG-IP
  • Upgrade to version BIG-IP 12.1.0 onward
  • Network Virtual address with arp and icmp-echo disabled (default value)

Cause

This is by design.

Recommended Actions

None
