K000160568: Admin Account Unable to Access GUI After Upgrading from 1.5.1 to 1.8.3

Type
Support Solution
Published
2026-06-24
Updated
2026-06-24
Applies to

  • F5OS-C: 1.8.0, 1.8.X, 1.8.2, 1.8.1
  • F5OS-A: 1.8.X, 1.8.4, 1.8.3, 1.8.0
Source
https://my.f5.com/manage/s/article/K000160568

Description

After upgrading F5OS from version 1.5.1 to 1.8.3, the admin account was unable to log in to the GUI, although CLI access with the same credentials was successful. Newly created user accounts could log in to the GUI without issue.

Environment

  • F5OS upgraded from version 1.5.1 to 1.8.3
  • Production environment
  • Admin account affected for GUI login; CLI login unaffected
  • Newly created user accounts function as expected in GUI

Cause

Changes in accepted special characters for passwords were introduced in F5OS version 1.8.0 and later. The admin account password contained characters no longer permitted for GUI authentication, resulting in login failure.

Answer/Recommended Actions

  1. Review the list of allowed special characters for passwords in F5OS version 1.8.0 and later (see Additional Information).
  2. Update the admin account password to use only permitted characters.
  3. Verify and update passwords for other user accounts as needed to ensure compatibility with the new restrictions.
  4. If inconsistencies persist, generate and upload a qkview, and contact F5 Support for further analysis.

Additional Information

  • Password character restrictions may differ between CLI and GUI authentication.
  • Refer to F5 article K2873 for the list of allowed special characters in passwords for F5 products.
