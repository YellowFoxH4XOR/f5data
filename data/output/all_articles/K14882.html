Known Issue

The clone pool feature and Quality of Service (QoS)/Type of Service (ToS) forwarding may not function as expected.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system uses the clone pool feature and/or QoS/ToS forwarding for a virtual server.
  • Source address translation is not defined for the virtual server.

Changes made to CGNAT (LSN address translation) have introduced issues for the clone pool feature and QoS/ToS marking. If you configure either of these features for the virtual server, and source address translation is not defined, then the features of clone pool and QoS/ToS forwarding may not function as expected.

Impact

When your system uses the clone pool feature, the affected pool members do not receive any traffic from the BIG-IP system. When you configure QoS/ToS marking, the traffic that egresses from the BIG-IP system does not receive the expected priority while traversing the network.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system does not replicate server-side traffic to a clone pool member.
  • The BIG-IP system does not propagate the configured QoS/ToS marking on the egress traffic.
