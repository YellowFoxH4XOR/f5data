Topic

A specialized qkview snapshot feature was introduced in BIG-IP 9.3.0 as CR71964, and in BIG-IP 9.4.0 as CR65640, to capture essential information in the event of a TMM core.

This specialized qkview enhancement, called qkview-lite, is immediately executed in the event TMM encounters an issue and produces a core file. The qkview-lite script is designed to execute quickly to ensure that TMM is able to restart, and to gather essential information to help determine the cause of the failure.

When a TMM core occurs, the qkview-lite script executes and writes out the information gathered to a text file named according to the following naming convention:

<FQDN>.<DATE><TIME>.tech.out

Note: The file is written to the /var/tmp directory in version 9.x, and to the /var/log directory in version 10.x.

If you experience an issue in which TMM restarts and writes a core file, the corresponding qkview file must be uploaded along with the core file to Ask F5 Technical Support for analysis.
