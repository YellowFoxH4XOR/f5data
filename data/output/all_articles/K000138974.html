K000138974: I configured an Access List and locked myself out of the GUI/SSH in F5OS/VELOS. How do I restore?

Description

When configuring an Access List for administrative access to the F5OS/VELOS environment, the behavior of the Access list becomes a Whitelist in behavior. The default behavior is All administrative ports are allowed from any IP Address, until you create an ACL for a given port, or All ports. When you configure an Access list, the behavior changes to only allow access from the Access list entry.

  • Example:
    • Add from: 198.51.100.1/32 for port 443
  • Result:
    • Administrative access to port 443 is restricted to 198.51.100.1.


Environment

F5OS-A or F5OS-C

Adding an Access List entry for Controlling Management access to the Device.


Cause

Expected behavior


Recommended Actions

To recover access to the device, You will need to access the device from the IP configured in the Access list entry, or Access the device from the Console port using command line.


Use the webUI

  1. Log in to the webUI of the F5 rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > Allow List.
  3. Select the entry you want to delete.
  4. Select Delete.

 Use the CLI from Console:

  1. Log in to the CLI of the F5 rSeries system as the admin user.
  2. Enter the following command:
    1. config
  3. Remove an existing entry in the Allow List using the following command syntax:
  4. no system allowed-ips allowed-ip <name> config <ipv4 | ipv6> address <ip_address> prefix-length <prefix> port <port>
  5. In the command syntax, note the following:
    1. <name> is the name for the Allow List entry.
    2. <ipv4 | ipv6> is the protocol, either IPv4 or IPv6.
    3. <ip_address> is the source IP address or subnet to allow.
    4. <prefix> is the prefix length.
    5. <port> is the port on the management interface.
  6. For example, the following command removes access from IPv4 address 10.10.10.50 to port 443 on the management interface:
    1. no system allowed-ips allowed-ip entry1 config ipv4 address 10.10.10.50 prefix-length 32 port 443
  7. This command can also be truncated, which will remove all available settings for entry1:  
    1. no system allowed-ips allowed-ip entry1

By removing the Access lists, you have reverted the system to allow access from any IP, and can login to the GUI and re-consider your Access list strategy.
