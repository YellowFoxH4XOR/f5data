Known Issue

The BIG-IP AAM Configuration utility fails to save some special characters when you configure an acceleration policy.

This issue occurs when all of the following conditions are met:

  • You add a Client IP type matching rule in the acceleration policy.
  • The regular expression you entered for the value contains special characters such as the following:
    • \   backslash
    • [   left square bracket
    • ]   right square bracket
    • ^  caret
    • $  dollar sign

Impact

You are unable to configure the acceleration policy with certain regular expression strings using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP AAM Configuration utility generates the following error when you attempt to save a matching rule in an acceleration policy:

    There was 1 error. The changes were not saved.
    (1) The field Value has invalid characters.

  • You are unable to save certain regular expressions in an acceleration policy using the Configuration utility.

Workaround

To work around this issue, you can configure the matching rule using the Traffic Management Shell (tmsh) by escaping the special characters. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To modify the value for the Client IP matching rule with a regular expression, use the following command syntax:

    modify wam policy Draft/<policy_name> nodes modify { <node_name> { matching modify { client-ip { values replace-all-with { <regex> } } } } }

    For example, to replace the current value for the matching rule with a regular expression containing escaped characters, type the following command:

    modify wam policy Drafts/example_policy nodes modify { example_node { matching modify { client-ip { values replace-all-with { 10.\[0-9\]$ } } } } }

  3. To publish the changes, use the following syntax:

    publish wam policy Drafts/<policy_name>

    For example, to publish the example_policy policy, type the following command:

    publish wam policy Drafts/example_policy
