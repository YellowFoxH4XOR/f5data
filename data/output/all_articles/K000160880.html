K000160880: JWT license auto-renewal may fail in NGINX Plus

Type
Knowledge
Published
2026-04-22
Updated
2026-04-22
Source
https://my.f5.com/manage/s/article/K000160880

Topic

Starting with NGINX Plus R33, NGINX Plus instances require a valid JSON Web Token (JWT) license. Beginning with NGINX Plus R35 and later, the JWT license can be renewed automatically when a term subscription is renewed, provided reporting is configured and the subscription renewal has been processed.

For more information, refer to the Update the license automatically (R35 and later) section in the NGINX Plus documentation.

Description

The automatic renewal of JWT licenses in NGINX Plus R35 and later relies on the F5 licensing endpoint (product.connect.nginx.com) to issue a renewed JWT. This process is supported exclusively for term subscription renewals only and requires that the subscription renewal is processed prior to the license expiration date.

Auto-renewal is not supported in the following scenarios:

  • Term subscription renewed to Flexible Consumption Program (FCP): The subscription type changes, causing a new subscription ID to be issued. A new JWT must be applied manually.
  • FCP renewed to FCP: FCP subscriptions do not support automatic JWT renewal. A new JWT must be applied manually.

This is expected behavior. Subscription details, including the current subscription type, can be verified on MyF5.

Symptoms

When auto-renewal fails and the license nears expiration, you may see warnings similar to the following in /var/log/nginx/error.log:

[warn] license will expire in 14 days

If not addressed, the JWT license will expire at the end of the stated timeframe.

For more information, refer to the Error log location and monitoring section in the NGINX Plus documentation.

Checking license details

The recommended way to check license status and expiration is through the NGINX Plus API. For example:

date -d @`curl -s http://127.0.0.1/api/9/license | jq '.active_till'`
Thu Apr 23 00:00:00 UTC 2026

For more information about the NGINX Plus API, including how to enable it, please see Module ngx_http_api_module.

Recommendation

When auto-renewal is not supported for your subscription type, update the JWT license manually using the following method:

  1. Download the JWT license from MyF5:
    1. Log in to MyF5.
    2. Locate your subscription
    3. Download the associated JWT license file.
  2. Follow the manual JWT license update steps in the NGINX Plus documentation.
