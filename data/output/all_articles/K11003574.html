Description

Using network access connection to the resources is slow

  • Users cannot reach resources while connecting to VPN
  • Without VPN there is no connection problem

Environment

  • Network Access resource configured in Access Policy
  • Windows 10 or Mac
  • Edge client 
  • BIG-IP 11.x-12.x (for v13.x and later, see: K80805793: VPN slowness)

Cause

Issue can be caused by multiple independent factors. In order to get deeper a deeper insight, please follow the Recommended Actions below.

Recommended Actions

Please provide a the following data from both the APM and Client with the following steps

  1. At the Bash prompt, turn up access policy logging on the BIG-IP with the following command:

    tmsh modify sys db log.accesscontrol.level value debug
     
  2. Instruct the end user to connect to VPN and notice his ip from lease pool and apm session id
  3. Start tcpdump on the BIG-IP with the following command and replace x.x.x.x with the IP which is assigned to user

    tcpdump -ni 0.0:nnn -s0 host x.x.x.x -w /var/tmp/vpnslowness.pcap
     
  4. Reproduce the slowness issue by accessing some internal resource for example. Double-check the IP of that internal resource
  5. Stop the tcpdump with ctrl+c
  6. Turn down APM logging on the BIG-IP with the following command:

    tmsh modify sys db log.accesscontrol.level value notice
     
  7. Generate a tarball of logs from BIGIP. For that please run in bash shell:

    tar -zcvf /var/tmp/$HOSTNAME-logs.tar.gz /var/log/*

    The tarball will be in /var/tmp/ folder. Download it to your PC via any tool (like WinSCP)
On the affected client machine:
  1. Run the Client Troubleshooting Utility (CTU) on the affected client machine as Administrator if possible.

    K12444: Overview of the Client Troubleshooting Utility for Windows (CTU)

    If you are using Mac OS: K12321: Enabling Network Access Debugging for Mac OS X and Linux
     
  2. Open the CTU go to Tools and check Enable Logs
  3. In the CTU go File > Generate Report and check all 4 boxes
  4. Run the report and save it as HTML
Please upload all files using:  K000090853: Exchange files with F5 Support
