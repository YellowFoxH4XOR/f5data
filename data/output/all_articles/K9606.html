Topic

As an alternative to GUI-based installation, you can install the FirePass Controller's client components for Microsoft Windows using commands in a command window, or in a scripting environment. Unlike the GUI-based installation process, the command-based installation can be performed without any input during the installation.

To perform a command-based installation, you must perform the following three procedures:

  • Downloading the GUI installer program
  • Extracting the MSI installer package and components to a local or network drive
  • Running the msiexec command from a command window or scripting environment

Important: The custom component Traffic Control Services may appear for FirePass version 7.0.0 users but will fail to install. For more information, refer to K12299: The BIG-IP Edge Client 'Traffic Control Service' component cannot be installed.

Important: The signing certificate for the F5 VPN Client expired on March 11, 2010. Using an older version of the client may fail when trying to install. For more information, refer to K11936: The digital signing certificate for the F5 VPN Client for Microsoft Windows expired March 11, 2010.

Downloading the GUI installer program

To download the f5fpcsetup.exe file, which is the Microsoft GUI installer program, perform the following procedure:

  1. Log in to the Administrative console.
  2. In the main navigation pane, select Device Management.
  3. In the main navigation pane, select Client Downloads.
  4. In the main navigation pane, select Windows (x86).
  5. Select the Customize Package tab.
  6. Select the Select all items check box.
  7. Click the Update button.

    Clicking the Update button will create an installer package with all FirePass client components. You may select the components you want to install in a later step of this procedure.

    Note: You can perform any desired customizations at this point by selecting the Customize VPN Client tab.
  8. Select the Download tab.
  9. Click the Download link.

    A Security Warning pop-up window appears with options for handling the f5fpcsetup.exe file.
  10. Click the Save button.

    A file dialog box appears.
  11. Save the f5fpcsetup.exe file.


Extracting the MSI installer package and components to a local or network drive

To extract the MSI installer package and the accompanying installation files, perform the following procedure:

  1. Open a command window.
  2. Change directories to the directory where you saved the f5fpcsetup.exe file, by typing the following command:

    cd
  3. Type the following command:

    .\f5fpcsetup.exe /x

    The Security Warning window may appear, asking whether you want to run the f5fpclients.msi software.

    Note    : To avoid any client interaction, us /q instead of /x.
  4. Click the Run button.

    The F5 Networks VPN Client for Windows Setup Wizard program appears.
  5. Click the Next button.

    A window prompts you to enter your organization name.
  6. Enter the name of your organization.
  7. Click the Next button.

    A window prompts you to enter the location where the installation files will be extracted.
  8. Enter the path to the location or browse to it with the Browse button.
  9. Click the Next button.
  10. To begin unpacking the installation files, click the Install button.
  11. To finish unpacking the installation files, click the Finish button. 

    The installation package directory should now contain the f5fpclients.msi file, and the directory F5 VPN, containing the files to be installed in the permanent location for program files.


Running the msiexec command from a command window or scripting environment

To perform a command line installation of the client, perform the following procedure:

  1. Open a command window.
  2. Change directories to the directory where you saved the f5fpcsetup.exe file by typing the following command:

    Note: You can also use an equivalent step in your scripting environment.

    cd
  3. Type the following command syntax:

    msiexec /i "f5fpclients.msi" /qn ALLUSERS=1
    ADDLOCAL=component1,component2,...,componentN

    In the command, the <component1,component2,...,componentN> section is a list of comma-separated names (case-sensitive, no embedded whitespaces between any characters in the argument list) of the components you want to install. The component names are from the MSI package, listed in the following MSI component names table:

    Note: The command will execute without need for user input, and will produce no output. Logging options and other options are available with additional command line switches. Type the msiexec command without switches or arguments for a listing of additional switches.

    Component NameDescription
    BASEBase Controls
    VPNNetwork Access
    TUNNELSERVERApplication Tunnels
    TSCLIENTTerminal Server Clients
         MSTSClient for Microsoft Terminal Services
         VNCClient for VNC Servers
         u5250Client for 5250 Servers
    InspectionHostEnd Point Security
         SANDBOXProtected Workspace
         Win32SystemCheckInspector for Win32 System Level Inspection
         OPSWATiOPSWAT Antivirus and Firewall Integration Libraries
         CLEANERCache Cleaner
         CERTCHECKMachine Certificate Checker
    InstallerServiceComponent Installer Windows Service
    CUSTOMDIALERAllows creating Network Access connection by dialing a phone book entry
    STANDALONEFirePass Client for Windows
    API PortRedirectorFirePass Client COM
    APIDNS Relay Service

    The names in this component list correspond to the Feature entries in the Features Table of the MSI database, as of the most recent version of FirePass software. Earlier versions of FirePass software may contain a subset of these components.

    Indented names are features that are packaged together under the previous non-indented name (the non-indented name above the indented names is the Feature_Parent entry in the MSI database).

    This list also mirrors the list of features available on the Customize Package tab of the Device Management >> Client Downloads >> Windows (x86) page, as of the most recent version of FirePass software. Earlier versions of FirePass software may contain a subset of these components.

    To ensure that you are using the correct Feature names, use a utility to view the MSI database, display the Feature Table, and extract the Feature names. Microsoft offers a free utility in the Windows SDK Components for Windows Installer package called Orca. Other utilities are available in the public domain.
