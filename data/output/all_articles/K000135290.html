K000135290: Install a 3rd party software on SDC system such as HP OVO agent

Support Solution
Published
2024-07-02
Updated
2024-07-02
Applies to

Source

Description

F5 does not recommend installing any 3rd party software on the SDC system due to risk functionality impacts such as load on CPU, memory resources leak, etc.

Environment

SDC

Cause

Install third-party software on the SDC system, such as HP OVO agent

Recommended Actions

F5 does not recommend installing any 3rd part software on the SDC server due to risk functionality impacts such as load on CPU, memory resources leak, etc.

Additional Information

None
