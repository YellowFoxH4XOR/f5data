Topic

This article applies to BIG-IP 10.x through 15.x. For information about other versions, refer to the following article:

  • K6568: Determining the amount of RAM installed in a BIG-IP (9.x)

You should consider using this procedure under the following condition:

  • You want to determine the amount of RAM memory installed on the BIG-IP system.

Description

You can determine the amount of memory installed on the BIG-IP system and also the amount of memory used by the system's Traffic Management Microkernel (TMM).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the BIG-IP system's Traffic Management Shell (tmsh).

Procedures

Determining the amount of RAM memory installed

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To determine the amount of RAM memory installed, type the following command:

    show /sys memory field-fmt

    In the following command output example, the total RAM installed is 3.6 GB, and the amount of memory in use is 3.5 GB:

    sys memory-host 0 {
    host-id 0
    memory-total 3.6G
    memory-used 3.5G
    }

    In the following command output example, the total RAM installed is 63 GB for each VIPRION blade (host-id1, and host-id2), and the memory used is 58.9 GB for each blade:

    sys memory-host 1 {
    host-id 1
    memory-free 4.0G
    memory-total 63.0G
    memory-used 58.9G
    other-memory-free 3.7G
    other-memory-total 62.6G
    other-memory-used 58.8G
    swap-free 5.0G
    swap-total 5.0G
    swap-used 0
    tmm-memory-free 339.6M
    tmm-memory-total 424.0M
    tmm-memory-used 84.3M
    }
    sys memory-host 2 {
    host-id 2
    memory-free 4.0G
    memory-total 63.0G
    memory-used 58.9G
    other-memory-free 3.7G
    other-memory-total 62.6G
    other-memory-used 58.8G
    swap-free 5.0G
    swap-total 5.0G
    swap-used 0
    tmm-memory-free 333.2M
    tmm-memory-total 424.0M
    tmm-memory-used 90.7M
    }
