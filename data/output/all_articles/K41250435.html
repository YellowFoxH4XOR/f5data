Description

Example regular expressions which can be used as include/exclude/pin pattern matches in a Web-acceleration Profile

  • Web-acceleration profile is being used.
  • After applying a pattern match, it gets changed to (?#glob)

Environment

  • BIG-IP LTM
  • BIG-IP WebAccelerator 
  • Virtual Servers using Web-Acceleration/Ramcache Profile

Recommended Actions

Example pattern matches are as follows :

Extension to MatchRegex query
 .png  .jpg  .jpeg  .gif files \.png    \.jpg   \.jpeg   \.gif
 htm/html files \.htm   \.html
 png images named logo logo\.png
 js files, including those with query strings appended, such as /some/thing/code.js?a=b \.js
 jquery.js with any query string parameters jquery\.js
js files, with no query strings appended, such as /some/thing/code.js\.js$



Additional Information
