Issue

This error message is benign.

This message typically appears after the bigd process is restarted through the command line.

When the bigd restarts, it attempts to kill any previous occurrences of the bigd process. It does this by opening the /var/run/bigd.pid file and issuing a kill command for the PID in that file. It then deposits the new PID for the new bigd process.

The error message indicates that when bigd attempted to kill the original PID found in the bigd.pid file, that process was no longer running.

Note: This is typical behavior for BIG-IP daemons, with the exception of the /sbin/sod daemon.
