Description

When you upgrade the BIG-IP unit with ASM enabled to any version above v14.1.x we see bot-defense-device-id-generate-before-access get enabled on the VS which has ASM profile enabled.

Environment

  • Upgrade
  • ASM profile applied
  • Bot defense and DoS not enabled 

Cause

When the unit is upgraded if one of the features is enabled this is added to VS :

  • Session Awareness with counting per Device ID
  • Brute Force protection profile with counting per Device ID
  • Session Hijacking

Recommended Actions

The profile will not have any effect as such its just for backwards compatibility.
