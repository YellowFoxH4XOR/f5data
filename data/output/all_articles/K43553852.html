K43553852: ''Waiting for device to verify installation'' on BIG-IQ

Type
Support Solution
Published
2019-11-22
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K43553852

Description

When we are trying to upgrade multi-bladed BIG-IP vCMP guest from 12.x to 13.x onward from the BIG-IQ software installations, after the installation vCMP guest will reboot to the newer version, but the state of the installation on the BIG-IQ is "Waiting for device to verify installation" forever.
Normally this state should change to "Finished" after the BIG-IP reboot.

Environment

  • BIG-IQ 6.1
  • BIG-IP 12.x
  • Upgrade to 13.x or later
  • Upgrading BIG-IP from BIG-IQ CM software installations
  • VIPRION
  • Multi-bladed vCMP guest

Cause

Part of the REST database is not properly synchronized to secondary blades. If a secondary blade is the first one to boot after the upgrade, this will generate an error and leave the upgrade task in "Waiting for device to verify installation" state forever.

This problem is covered by bug ID 843685.

Recommended Actions

1. Remove device from the BIG-IQ and add it again (rediscover the device)

Additional Information

We can avoid this situation only by disabling all the secondary blades before starting the upgrade task and re-enabling them after the upgrade is completed.
