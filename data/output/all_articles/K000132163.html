K000132163: 01480010:6: Got a message(78) for a non existent flow

2025-02-07
Applies to

Source
https://my.f5.com/manage/s/article/K000132163

Description

BIG-IP is logging the following informational messages in /var/log/ltm.

info tmm[<PID>]: 01480010:6: Got a message(78) for a non existent flow

In this error message, note the following:

  • <PID> is the process ID for the tmm process

 

Environment

  • BIG-IP ASM
  • Traffic blocked by ASM policy

Cause

The cause for this message is that in some cases the client can send additional packets even though it has received a FIN from BIG-IP. The additional packets received can not be matched to a connection/flow as the connection was closed after the FIN sequence.

Traffic Example:

 Recommended Actions

  • To determined which connection is causing this error message, collect a traffic capture while the message is being generated.
