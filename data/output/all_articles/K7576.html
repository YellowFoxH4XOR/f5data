Known Issue

This is the result of a known issue. When you configure the Topology load balancing method for a wide IP, you must configure the destination. The destination specifies the location that the BIG-IP system directs the incoming DNS request. If the destination is configured to a region that contains one or more pools, Topology load balancing fails and wide IP load balancing returns to Round Robin mode.

F5 Product Development tracked this issue as CR80154 and it was fixed in BIG-IP GTM 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM release notes.
