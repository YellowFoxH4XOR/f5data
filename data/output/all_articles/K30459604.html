Topic

You should consider using this procedure under the following condition:

  • You need the registration key for your F5 iWorkflow system.

Description

The iWorkflow system does not have a serial number format that is similar to F5 hardware platforms. You may use the Virtual Edition (VE) registration key to open a support case if you encounter any issue where you require F5 Technical Support assistance.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Traffic Management Shell (tmsh) or the iWorkflow user interface.

Procedures

  • Locating the registration key on an unlicensed system
  • Displaying the registration key in the iWorkflow user interface
  • Displaying the registration key using the tmsh utility
  • Requesting license information from F5 using the registration key

Locating the registration key on an unlicensed system

If the license has not yet been activated on your iWorkflow system, you can contact your F5 sales representative for assistance.

Displaying the registration key in the iWorkflow user interface

To display the registration key in the iWorkflow user interface, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the iWorkflow user interface using an account with the Administrator role.
  2. Navigate to System > Configuration.
  3. Under iWorkflow Cluster, double-click the localhost entry.
  4. Click Licensing.
  5. Locate the registration key in the Base Registration Key field.

Displaying the registration key using the tmsh utility

To display the registration key from the iWorkflow system using the tmsh utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Display the registration key and license information by typing the following command:

    show /sys license

    The command output appears similar to the following example:

    Sys::License
    Licensed Version 2.0.0
    Registration key ABCD-ABCD-ABCD-ABCD-ABCDEFG
    Licensed On 2016/06/15
    License Start Date 2016/06/14
    License End Date 2016/07/16
    Service Check Date 2016/06/15
    Platform ID Z100

    Active Modules
    iWorkflow, VE, Max (ABCDEFG-ABCDEFG)
    Recycle, iWorkflow, VE

Requesting license information from F5 using the registration key

To request information about the current status of an F5 registration key, such as on which system a specific registration key has been activated, or what service contracts have been assigned, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open a browser session, and connect to the following site:

    https://secure.f5.com/validate/validate.jsp

  2. In the Contact Email box, type your email address.
  3. In the F5 Licenses / Serial Numbers box, enter the base registration key.
  4. Click Submit Info Request.

    The F5 licensing server sends a license summary for the submitted registration key to the specified email address.
