Topic

This article applies to BIG-IP 13.1.0 and later. For information about other versions, refer to the following articles:

  • K16526: Configuring the SSL cipher strength for a custom HTTPS health monitor (11.0.0 - 13.0.x)

You should consider using this procedure under the following condition:

  • You want to configure a custom SSL cipher list for an HTTPS health monitor.

Description

The default HTTPS health monitor uses a default SSL cipher list that cannot be modified. However, if you need the BIG-IP system to use a specific set of SSL ciphers when monitoring the members of a resource pool, you can configure a custom HTTPS monitor to use a Server SSL profile that is configured to match the SSL ciphers.

Note: If the associated Server SSL profile is configured with the DEFAULT cipher string, the BIG-IP system applies the f5-default cipher group on the bigd process. If the associated Server SSL is configured with a cipher string other than DEFAULT, the cipher suites that the bigd process advertises are subjected to the supported OpenSSL cipher suite. For example, the cipher string in the Server SSL profile is DEFAULT:!RSA, the advertised cipher suites are determined by OpenSSL only.

Note: By default, the HTTPS health monitor uses the bigd process to monitor, but if you want to use tmm for in-band monitoring, refer to K11323537: Configuring In-TMM monitoring.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the Configuration utility.
  • You have Server SSL profile configured with the ciphers you want to use for the HTTPS monitor.

Procedures

To configure a custom HTTPS monitor to use a Server SSL profile for specified SSL ciphers, perform the following procedure:

Impact of procedure: You must verify that the list of ciphers specified in the Server SSL profile used by the custom HTTPS monitor are supported by the members of the resource pool being monitored. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

Note: You cannot specify the TLS/SSL protocol version. The HTTPS monitor will select the highest level TLS/SSL protocol based on the negotiated ciphers.

Creating a new HTTPS Monitor

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Select Create.
  4. Enter a name for the custom HTTPS monitor.
  5. For Type, select HTTPS.
  6. For Configuration, select Advanced.
  7. Complete the remaining Configuration options according to your requirements for the custom HTTPS monitor.
  8. For SSL Profile, select the Server SSL profile containing the ciphers you want.
  9. Select Finished.

You can now configure the pool to be monitored to use the new custom HTTPS monitor.
