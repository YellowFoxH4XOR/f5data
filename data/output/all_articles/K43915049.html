Description

BIQ-IQ not able to send utility report to F5
In GUI Devices > License Management > Reports you see "Report submission failed (yellow triangle)"
Click on more detail and see the full error message "Report submission failed: curl: (56) SSL read: error:00000000:lib(0):func(0):reason(0), errno 104."

Environment

  • ELA / FCP (load / cat license report)
  • BIG-IQ v7.x and 8.x
Cause

You have scheduled a utility billing report to run and get the errno 104 message on the GUI
Due to a known bug ID1087253
when you schedule a utility report to run, the actual time is set to PST and not local time as expected.
As such the majority of reports will be run on the first of each month at 00:00 PST.
The result is that the F5 API gateway gets overwhelmed and BIG-IQ clients timeout before the report is sent.

Recommended Actions

Please set your scheduled utility reports to a different day (2-5) and a different time (based off of + or - local compared to PST)

Additional Information

In the BIG-IQ GUI Devices > License Management > Reports > Schedule
Notice the day / time (and the time zone)

Day of the Month: 1  Start time: 0 hour : 0 minute (British Summer Time)


As admin user on the BIG-IQ command line run the following command:
restcurl shared/task-scheduler/scheduler/ | jq '.items[]|{name,hourToRunOn,nextRunTime}' | grep -A2 licensing

Output of restcurl:
"hourToRunOn": 0,
"nextRunTime": "2022-10-01T08:00:00.000+01:00"
Note in the example (BST) is 8 hours in front of PST, so next run time is 08:00 BST (00:00 PST)
