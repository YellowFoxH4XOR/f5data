K000091249: GUI displays an error when trying to manage GSLB pools

Type
Support Solution
Published
2022-02-10
Updated
2025-10-06
Source
https://my.f5.com/manage/s/article/K000091249

Description

While attempting to manage GSLB pools from the GUI, receive error "An error occurred while trying to process your request.

/var/log/webui.log show messages similar to the following:

2022-02-04 16:33:55,836 ERROR [ajp-bio-127.0.0.1-8009-exec-25] web.FormHandler:doAllowedCharactersCheck   - error occurred while parsing value /tmui/globallb/pool/members.jsp?name=<pool member path> for the form parameter form_page, Illegal character in query at index <index number>: /tmui/globallb/pool/members.jsp?name=<pool member path>

 Environment

  • BIG-IP DNS

 Cause

Issue is caused by Bug ID 741862. BIG-IP DNS GUI may generate errors or display names with special characters incorrectly.

 Recommended Actions

Upgrade to fixed version or contact Support for an engineering hotfix

 Additional Information

None
