Known Issue

This is the result of a known issue. The BIG-IP GTM Synchronize DNS Zone Files setting allows the BIG-IP GTM system to synchronize DNS files among the members of a BIG-IP GTM synchronization group. If Synchronize DNS Zone Files is enabled, and a user manually edits a DNS configuration file resulting in a syntax error, the DNS file will be synchronized to other members of the synchronization group, and the file will load into memory on the receiving BIG-IP GTM systems.

When this issue occurs, the following error message will be logged in the /shared/log/gtm file on the BIG-IP GTM devices receiving the named.conf file with the incorrect syntax:

zrd: 01150205:3: Unable to parse named.conf file

F5 Product Development tracked this issue as CR72907, and it was fixed in BIG-IP GTM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
