K28782240: ASM Bot Defense fails to verify GoogleBot rev DNS in 50% of cases

Type
Support Solution
Published
2020-01-30
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.X.X, 14.1.0, 14.0.1, 14.0.0, 14.1.2
Source
https://my.f5.com/manage/s/article/K28782240

Description

  • ASM Bot defense Search Engine verification fails randomly.

Environment

  • ASM Bot defense profile.
  • Search Engine.
  • DNS resolver.

Cause 

  • DNS server is case-insensitive and returns all lower-case responses.
  • The  DNS resolver is configured with Randomize Query Character Case enabled which requires the query name randomized using combination of lower and upper cases.

Recommended Actions

Disable Randomize Query Character Case in the DNS resolver:

  1. Go to Network  >  DNS Resolvers > DNS Resolver List
  2. Click on the DNS resolver name
  3. Locate and uncheck Randomize Query Character Case
  4. Click Update
