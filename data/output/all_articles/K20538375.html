Description

APM is logging messages similar to the following in /var/log/apm:

info apmd[13901]: 01490007:6: Session variable 'session.check_software.last.pm.item_1.errors' set to 'Failed to get 'missing_updates'. code: -17 method: 1013 define: 'WAAPI_ERROR_NO_CONNECTION' description: 'Defines an error where there is no connection when one is expected.'

The user session will fail the APM Windows Update check and depending on how the policy branch is configured, the access session may be denied.

Environment

  • BIG-IP APM
  • Windows Updates

Cause

The configured APM Windows Update check in the 'Patch Management' item may fail, due to a failure for the BIG-IP APM to retrieve Windows Updates from the client computer.
This can occur if the BIG-IP APM device is unable to communicate with a server handling the Windows Updates (for example Microsoft SCCM server).

Recommended Actions

  1. Ensure the BIG-IP APM device is allowed to communicate to the server handling Windows Updates in the customer environment.
    Common Windows Updates servers used are Microsoft SCCM or Microsoft Endpoint Manager.
