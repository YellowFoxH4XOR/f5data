Known Issue

Uploading an OPSWAT Endpoint Security (EPSEC) ISO file may trigger an unexpected configuration synchronization (ConfigSync) from a Standby System.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as part of a high availability (HA) device group.
  • You upload an OPSWAT EPSEC ISO file to a standby device by using the Configuration utility.
When you navigate to the System > Software Management > Antivirus Check Updates page on an Active or Standby BIG-IP APM system, the Upload Package and Install Package buttons are available (enabled).

However, performing these actions (upload package or install package), will trigger a configuration synchronization (ConfigSync) to be performed. Performing these actions on a Standby system may result in the Standby system's configuration being unintentionally synchronized to other members of the device group. 

Impact

The standby system's configuration is synchronized to other members of the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After uploading the OPSWAT EPSEC ISO update file, unsynchronized changes made to the standby device appear on the active device.
  • After uploading the OPSWAT EPSEC ISO update file, unsynchronized changes made to the active device are removed.
  • A log message similar to the following example appears in the /var/log/ltm file at the time of the EPSEC file upload:

    notice mcpd[5301]: 010714a0:5: Sync of device group /<partition>/<device-group-name> to commit id <commit id value>/<partition>/<standby device hostname> 0 from device /<partition>/<standby device hostname> complete.

Resolution

Status

F5 Product Development has assigned ID 440013 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release12.1.0*K2200: Most recent versions of F5 software
HotfixNoneNone

* Beginning in 12.1.0, the Upload Package and Install Package buttons for EPSEC updates are disabled on standby systems. For more information, refer to K03131331: The Upload Package and Install Package buttons for antivirus check EPSEC updates are disabled on standby systems.

Workaround

To work around this issue, you should perform a ConfigSync to ensure that the configurations for all members of the device group are in sync before uploading or installing an EPSEC ISO update. Alternatively, you can perform the upload/install functions from the member of the device group that has the desired configuration.
