Known Issue

This is the result of a known issue. If you have configured the BIG-IP ASM SMTP Chart Scheduler to automatically email event reports, the BIG-IP ASM system does not send the email associated with the first triggered event. However, the event is marked green, as if the email had been successfully sent. Email notification for the second and subsequent events are sent as expected, as are test notification emails, which are generated using the Send Now button.

Note: Event reporting for the Charts Scheduler is configured on the Reporting >> Charts >> Chart Scheduler screen of the Configuration utility. Before attempting to configure email event notification, you must first configure SMTP on the Options >> SMTP Configuration screen.

F5 Networks Product Development tracked this issue as CR138591 and it was fixed in version 10.2.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.
