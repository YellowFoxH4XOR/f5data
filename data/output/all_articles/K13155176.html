Known Issue

The Configuration utility may fail to activate the license when you attempt to manually license a BIG-IP Virtual Edition (VE).

This issue occurs when the following condition is met:

  • You use the Configuration utility to attempt to manually activate the BIG-IP VE license on a BIG-IP VE running 15.0.1.

    For example, an affected license SKU may appear similar to F5-BIG-LTM-VE-1G-V16-LIC-DEV.

Note: Versions prior to 15.0.1 are not affected by this issue and a fix was introduced for versions later than 15.0.1.

Impact

You are unable to activate the license for the affected BIG-IP VE.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • From the Configuration utility licensing page, after clicking Next, the page reverts to the previous unlicensed state
  • You are unable to activate the versioned BIG-IP VE license using the manual licensing process.

Workaround

To work around this issue, you can license the BIG-IP system using the automatic activation method if the system is configured to route traffic to the Internet. Alternatively, you can use the command line to manually activate the license. To do so, perform the following procedure.

Impact of workaround: Traffic processing is briefly interrupted as the BIG-IP system reloads the new license. This may result in a failover. F5 recommends that you perform this procedure on the standby device.

Note: For VIPRION systems, you should perform this procedure on a primary blade. The license registration key will be propagated to the secondary blades on the BIG-IP system once the primary blade is activated.

  1. Log in to the command line on the affected BIG-IP device.
  2. Manually create the /config/bigip.license file.
  3. Using a text editor such as the vi utility, open the /config/bigip.license file.
  4. Paste all of the new license content from the license server web page into the /config/bigip.license file.

    Note: Make sure that there are no blank lines at the top or bottom of this file.

  5. Save and close the file.
  6. To reload the license on the BIG-IP system, type the following command:

    reloadlic
