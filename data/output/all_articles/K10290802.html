Description

After upgrading to any version greater than v14.1.x, the system automatically assigns a Bot-Defense profile bot-defense-device-id-generate-before-access to one or more virtual servers.  

Environment

  • ASM security policy or DOS profile.
  • ASM is provisioned.

Cause

For each ASM policy that's attached to at least one virtual server, and has at least one feature requiring Device ID (collecting Device ID is enable); the system by default will assign the factory Bot defense profile bot-defense-device-id-generate-before-access to the virtual server.
Note. The selection of bot profile bot-defense-device-id-generate-before-access is hardcoded and cannot be changed.

Recommended Actions

  • The observed behavior is by design and since the policies were originally configured to collect the client's device ID by injecting JavaScript; this behavior shouldn't cause any outage.
  • Review the article K42323285 which covers how Bot-Denese profile work and tune recommendation to meet the protected application needs.
