Known Issue

The Configuration utility reports an error message when you attempt to view a large number of Secure Sockets Layer (SSL) certificates.

This issue occurs when the following condition is met:

  • You attempt to view 100 or more SSL certificates within the Configuration utility.

Impact

The Configuration utility reports an error message and is unable to display the certificates.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility reports an error message that appears similar to the following example:

    General database error retrieving information.

  • The BIG-IP system reports an error message in the /var/log/tomcat/catalina.out: java.sql.SQLException file that appears similar to the following example:

    java.sql.SQLException: Table not found: SSL_CERTIFICATES_0_3011215492787216 in statement [DROP TABLE ssl_certificates_0_3011215492787216]

Workaround

To work around this issue, you can refresh the screen. This allows the BIG-IP system to create a new table reference to display the SSL certificates.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
