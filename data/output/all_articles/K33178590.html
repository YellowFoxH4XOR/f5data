Known Issue

The TMOS Shell (tmsh) may erroneously log an error message when merging an iRules configuration.

This issue occurs when all of the following conditions are met:

  • You have an existing iRule configured on your BIG-IP system.
  • You attempt to update the iRule using the tmsh merge option.

    For example, to merge an updated iRule from a text file named /var/tmp/irule.txt to the existing configuration, type the following command:

    tmsh load /sys config file /var/tmp/irule.txt merge

Impact

The BIG-IP system successfully loads changes to the iRule. The error message is benign and may be safely ignored.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H612891 on the Diagnostics > Identified > Low page.
  • When you attempt to update the iRules configuration, you view an error message in the /var/log/ltm file that appears similar to the following example:

    err mcpd[6783]: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (6589).

  • After performing the merge operation, the tmsh list /ltm rule command shows the updated iRule.

Resolution

Status

F5 Product Development has assigned ID 500402 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can use the Configuration utility to update the iRule. To do so, perform the following procedure:

Impact of workaround: Ensure this modification is compatible with your environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click the name of the iRule that you want to modify.
  4. Modify the iRule.
  5. Click Update.
