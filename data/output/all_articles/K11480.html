K11480: Advanced Session Variables are not accessible in protected configurations and pre-logon sequences

Topic

The use of Advanced Session Variables (ASV) is not currently supported in FirePass protected configurations or pre-logon sequences. If a user attempts to access an ASV in a protected configuration or pre-logon sequence, the FirePass will behave as if the variable does not exist and fail comparison checks.

F5 Product Development is tracking this enhancement as ID 265675 (formerly CR140496).

Note: For more information on Advanced Session Variables, refer to K10108: Overview of Advanced Session Variables.

Note: For more information about configuring protected configurations, refer to the FirePass Controller Administrator Guide or the FirePass online help.

Workaround

You can work around this limitation in certain circumstances, such as when the ASV is using a simple value assignment, by using a custom variable in a pre-logon sequence. Unlike ASVs, user-defined variables are limited in the ways you can assign values to them.

Note: For more information about pre-logon sequence custom variables, refer to K11493: Overview of the pre-logon sequence custom variables.
