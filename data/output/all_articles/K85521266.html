K85521266: Traffic does not match a virtual server in a route domain with a source address list

Type
Support Solution
Published
2021-12-13
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K85521266

Description

When attaching the source address list to virtual server with a route domain, the traffic from the source list fails to match the virtual server.

Environment

  • BIG-IP LTM
  • Virtual Server with Route Domain and Source Address List
ltm virtual vs_test {
    ip-protocol tcp
    partition UAT
    profiles {
        /Common/http { }
        /Common/tcp { }
    }
    traffic-matching-criteria vs_test_VS_TMC_OBJ
    translate-address enabled
    translate-port enabled
    vs-index 2
    pool pool_test
}
ltm traffic-matching-criteria vs_test_VS_TMC_OBJ {
    destination-address-inline 10.10.10.1
    destination-port-inline http
    partition UAT
    protocol tcp
    source-address-inline 0.0.0.0%0
    source-address-list sample_addresslist
}

Cause

There are two BUGID which are related to this issue: ID881065 and ID898389

Recommended Actions

  1. Create traffic-matching-criteria object using TMSH command line
    root@(bigip)(cfg-sync Standalone)(Active)(/UAT)(tmos)# create ltm traffic-matching-criteria TMC-2 destination-address-inline 10.10.10.1%1 route-domain RD1 source-address-list /Common/sample_addresslist
     
  2. Create virtual server object
    root@(bigip)(cfg-sync Standalone)(Active)(/UAT)(tmos)# create ltm virtual VS-2 traffic-matching-criteria TMC-2 profiles add { tcp http }
