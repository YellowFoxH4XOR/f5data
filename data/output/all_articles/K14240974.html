Issue

Error Message

err logger: /usr/libexec/aws/aws-failover-tgactive.sh (<traffic group name>): Incorrect aws-access-key provided. Use 'tmsh sys global-settings aws-access-key' to correct it

In this error message, note the following:

  • <traffic group name> is the name of the affected traffic group.

For example:

err logger: /usr/libexec/aws/aws-failover-tgactive.sh (traffic-group-1): Incorrect aws-access-key provided. Use 'tmsh sys global-settings aws-access-key' to correct it

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP Virtual Edition (VE) system running on the Amazon Web Services (AWS) EC2 cloud service is configured with the incorrect AWS EC2 access key and secret key.

During the failover process, BIG-IP VE systems running on the AWS EC2 cloud service use the AWS API with the assigned access key and secret key to access the AWS resource through the management network. If the system is configured with the incorrect access key, the above error message will be logged during the failover process.

Impact

The BIG-IP VE system running on the AWS EC2 cloud service is unable to fail over to its peer system in a high availability (HA) configuration.

Recommended Actions

If your system does not have the appropriate access key and secret key, you must obtain the necessary access key and secret key from the AWS EC2 management console and use them to configure your system. For information about obtaining and configuring the access key and secret key, refer to K14827: Configuring failover for BIG-IP VE on Amazon EC2.
