Description

In a multiple-blade vCMP system, when migrating a vCMP guest from one slot to another, the process fails. From 'tmsh show vcmp guest' out, we can see a message like below:

VDisk migration process from slot x failed.

In the /var/log/ltm, the following error can be found:

Child exited with non-zero exit code: 2

Environment

  • Multiple-blade vCMP system
  • vCMP guest migration

Cause

The root password is expired or does not sync between the blades

Recommended Actions

  1. Login to the vCMP host CLI with root credentials.
  2. ssh to other slot(s) to verify if the root account can access other slots, for example, ssh to slot2 and it should not ask for the password again.
  3. # ssh slot2
  4. Reset/update the root password on the GUI: System - Platform, which will sync the password across the system.
  5. Try again to migrate the vCMP guest.
