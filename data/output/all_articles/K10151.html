Topic

FirePass supports the ability to define Microsoft Windows registry check pre-logon inspection agents. This agent allows you to define checks based on the content of Windows registry keys. The Windows registry supports keys of varying data formats including String (REG_SZ), Binary (REG_BINARY), DWORD (REG_DWORD), Multi-String (REG_MULTI_SZ) and Expandable Strings (REG_EXPAND_SZ). However, different types of registry data formats can hold varying types of data. For example, a registry key String value (REG_SZ) can be used to hold a numeric value.

In such cases, using FirePass logic operators (>, >=, <, <=, ==, !=) may result in a rejection even when the client should have passed the registry inspection. These logic operators should only be applied when querying numeric values such as DWORD keys. In cases where you must apply a logic operator to a string-based key, FirePass will implement the lexicographical order. For example:

  • bbb < cbb
  • bbbb < cbb
  • 120 < 900
  • 1200 < 900

Important: F5 Networks does not recommend you manually modify your Windows system registry.
