Description
Network access resource not being removed in windows "Internet Options" after disconnecting to the VPN after removing "Windows Cache and Session Control" from the Access Policy


Environment

  • Previous removal of "Windows Cache and Session Control" from the Access Policy


Cause
"Windows Cache and Session Control" used to clear that section in "Internet Options"
 

Recommended Actions

This is not an issue, as "Windows Cache and Session Control" is being deprecated, this is an expected behavior. 
 

Additional Information

About Windows Cache and Session Control
K20926295: "Loading cache cleanup control" pop up when trying to connect to VPN using browser
