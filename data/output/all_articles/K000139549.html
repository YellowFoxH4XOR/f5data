K000139549: Admin user login fail or root user take a long time to login

Type
Support Solution
Published
2024-05-08
Updated
2024-09-06
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000139549

Description

Root and admin user may login fail or take a long time.

  • Customers is using LDAP authentication. The issue may not happen immediately after adding LDAP authentication. We may observe this issue after some time.  
  • Root user login will take around 2 minutes after input correct password.
  • Admin user is unable to login. It will take around 15 seconds to error message after input correct password.
  • rSeries sends DNS query to public DNS servers 8.8.8.8 and 8.8.4.4.

Environment

  • rSeries
  • F5OS
  • LDAP
  • Docker
  • DNS

Cause

There is DNS server configured in F5OS. It is an indirect issue of K000134790

Recommended Actions

To add DNS and restart docker according to suggestion of K000134790.

Additional Information

None
