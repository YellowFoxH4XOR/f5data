Topic

Real Time Messaging Protocol (RTMP) is a proprietary protocol used by Adobe Flash to deliver real-time objects, video, and audio to clients using a binary TCP connection or a polling HTTP tunnel.

The BIG-IP LTM system processes RTMP packets the same way that it processes all IP protocols, other than TCP and UDP, based on the information contained in the IP header. The BIG-IP LTM processes RTMP packets for virtual servers when the All Protocols option is enabled, and for SNATs when the All Traffic option is enabled for SNAT packet forwarding.
