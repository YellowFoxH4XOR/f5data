Description
With a significant increase in the number of remote workers, you may see an increase in the number of connections, CPU usage as well as memory usage. This article covers techniques from the F5 Support organizations for the general guideline of BIG-IP CGNAT, PEM, and DNS performance check-list.

Environment

  • CGNAT
  • PEM
  • DNS

Cause
Significant increases in the number of remote workers resulting in higher than normal resource use.
