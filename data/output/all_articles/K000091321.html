K000091321: Default _sys_https_redirect irule mis-parses IPv6 address

Type
Support Solution
Published
2022-03-15
Updated
2022-03-15
Source
https://my.f5.com/manage/s/article/K000091321

Description

The _sys_https_redirect irule is designed to be used on an FQDN (host.com:port) and not an IP so it would be splitting on the port. If an IPv6 address is placed, it would incorrectly mistake the colon for a port separator. 

 

 Environment

  • BIG-IP LTM
  • Irule to redirect ipv6 address from HTTP to HTTPS

 

 Cause

The _sys_https_redirect irule is only applicable to ipv4 address and FQDNs. If an IPv6 address is used, it would incorrectly separate on it, hence the need to write a custom iRule to be able to handle IPv6 addresses.

 

 Recommended Actions

Configure a custom iRule to redirect to an IPv6 HTTPS virtual server

 

To use the Configuration utility to configure a custom iRule to redirect HTTP requests to an HTTPS virtual server using an IPv6 IP address and apply the custom iRule to an HTTP virtual server, perform the following procedure:

 

Impact of procedure: The following procedure contains an example iRule to have the HTTP virtual server respond with an HTTP redirect to the IPv6 IP HTTPS virtual server. The specific iRule customization may differ for your specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

 

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Local Traffic > iRules.
  3. Select Create.
  4. Enter the Name you want to use for this custom iRule. For example, redirect_IPv6.
  5. For Definition , enter the following iRule syntax:

when HTTP_REQUEST {

regsub -all {:\d*$} [HTTP::host] "" host

HTTP::redirect https://$host[HTTP::uri]

}

  1. Select Finished.
  2. Go to Local Traffic > Virtual Servers.
  3. Select the HTTP virtual server you want to redirect.
  4. Select the Resources tab.
  5. For iRules, select Manage.
  6. For Available, select the custom iRule you just configured, for example redirect_IPv6, and move it to Enabled.
  7. Select Finished.
