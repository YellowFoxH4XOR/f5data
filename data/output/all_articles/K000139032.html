Description

How to force a configuration sync on HA pair using Ansible bigip_configsync_action.py module

 

Environment

  • Ansible
  • LTM HA pair

 

Cause

N/A.

 

Recommended Actions

 

When a device group 'dg1' is in use on the HA pair the following playbook can be used to sync the configuration:

---

- name: Perform Sync
  hosts: all
  connection: local

  tasks:
    - f5networks.f5_modules.bigip_configsync_action:
        device_group: "dg1"
        sync_device_to_group: yes
        overwrite_config: yes
        provider:
          server: 192.0.2.1
          user: user
          password: password
          validate_certs: false
