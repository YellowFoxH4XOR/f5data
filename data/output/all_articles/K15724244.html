Description

QLIK web server stopped working after applying BIG-IP ASM/BIG-IP WAF policy.

Similar errors in /var/log/ts/bd.log are shown: 
IO_PLUGIN|ERR   |websocket.c:0264|101 Switching Protocols HTTP status arrived, but the websocket handshake failed.
IO_PLUGIN|ERR   |websocket.c:0265|Possible reasons are websocket profile isn't assigned on a virtual server or handshake is illegal.

Environment

  • BIG-IP ASM 

Cause

  •  The issue happens due to missing Websocket profile in the Virtual Server configuration. Due to this request after switching protocols fails to work.

Recommended Actions

  1. Add a Websocket profile to the Virtual Server

Additional Information
The behavior can also be verified using HAR or Fiddler. Verify if the page load stops before switching protocols.
