K11046517: Attempt to delete SAML resource causes error: 01070265:3: The saml_resource (/Common/SAML_Resource) cannot be deleted because it is in use by a dynamic resource specified in access profile (/Common/APM_Resource)

Type
Support Solution
Published
2021-08-03
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.3
Source
https://my.f5.com/manage/s/article/K11046517

Description
You attempt to delete SAML resource, but it fails.
An error message is visible in the /var/log/ltm file:
Error Message: 01070265:3: The saml_resource (<object_name>) cannot be deleted because it is in use by a dynamic resource specified in access profile (<object_name>)

A similar error appears in the /var/log/tomcat/catalina.out file.

Environment

  • Attempt to delete SAML resource

Cause
Not possible to delete selected configuration element as the apm policy psync-dynamic-resource" is still left behind after deleting or removing  APM object 
Object you were trying to delete might be still attached to Sync Policy,

Recommended Actions

  1. Identify affected resource by searching for "apm policy psync-dynamic-resource" under bigip.conf
  2. Check following Sync Policy
    Access ›› Profiles / Policies : Policy Sync >> Choose the IdP policy which this is tied into
  3. Click Sync Policy >> Click on 'Advanced Settings' >> Uncheck the "SAML-Resource" and click "OK:
  4. Then cancel out of the "APM Policy Sync" and you should be able to delete object
