Description
       Error message occurs when unauthorized device attempts to modify a named zone.

Environment

  • named 

Cause
        Unauthorized host trying to update a zone file

Recommended Actions
       You can either:

  1. - Ignore the error as it is just informational  (recommended)
  2. - allow updates from any device.  (not recommended -- not very secure)  or from specific devices (not normally needed)
  3. - configure the external devices to not update DNS ( this is usually impractical)

Additional Information
        This is an error message from named. In most GTM/DNS configurations the GTM/DNS servers that are in the sync group are the only devices that are allowed to modify the named zone files.
         Any updates to the zone files are handled by a different mechanism.
