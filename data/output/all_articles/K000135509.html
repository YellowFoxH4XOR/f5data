Description

When deploying DO with ldap system authentication config, it enables the parameter check-host-attr and users are unable to login.

 

Example:

list auth ldap system-auth

auth ldap system-auth {

  bind-dn searchingName

  bind-pw $M$A0$fdIWLXaP/Zqcucba4/49BQ==

  check-host-attr enabled

  check-roles-group enabled

  search-base-dn searchName

  servers { 192.168.0.1 }

  user-template uid=%s,ou=people,dc=siterequest,dc=com

  version 2

}

 

Environment

  • BIG-IP
  • Declarative Onboarding
  • LDAP system authentication
  • check-host-attr

Cause

check-host-attr is mapped to checkBindPassword in DO

Recommended Actions

Set this parameter in the DO to false:

"checkBindPassword": false

None
