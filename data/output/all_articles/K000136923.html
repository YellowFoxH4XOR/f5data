Description

Installation procedure for OpenShift and Aspen Mesh 1.11 and 1.14.
 

Environment

OpenShift, Aspen Mesh 1.11, 1.14
 

Cause

OpenShift requires Istio CNI and special permissions to run Aspen Mesh.
 

Recommended Actions

Follow the procedure listed in this link for Aspen Mesh 1.11 and this link for Aspen Mesh 1.14.
 

Additional Information

By default, OpenShift doesn’t allow containers running with user ID 1337. You must enable containers running with UID 1337 for Istio’s service accounts.
