Known Issue

TMM may produce a core file when you use the STREAM::match iRule command.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is experiencing a low memory condition.
  • An iRule is configured with the STREAM::match command, which is reporting a large number of errors.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from Traffic Management Microkernel (TMM) restarting; failover may occur if the BIG-IP system is part of a high-availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe TMM produce a core file when the system attempts to log iRule error messages that are associated with the STREAM::match command.
  • In the /shared/core directory, the BIG-IP system may generate a TMM core file that includes a time stamp that correlates to the traffic interruption.
