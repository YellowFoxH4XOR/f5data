Known Issue

This is the result of a known issue. If a client connection to a virtual server matches a secure network address translation (SNAT) listener, both client-side and server-side flows store reference counts to the SNAT listener in memory, but do not release them. As a result, if there is sufficient traffic, the listener reference count will overflow and cause the Traffic Management Microkernel (TMM) to crash.

F5 Product Development tracked this issue as CR76502, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
