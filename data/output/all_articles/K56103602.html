Known Issue

Users assigned the Manager role may be unable to create a new SWG (Secure Web Gateway) custom URL category.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP SWG is configured with a user that is assigned the Manager role.
  • Using the Configuration utility, the user attempts to create a new SWG URL Categories > Custom Category.

Impact

You are unable to create a custom category.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to create a new URL Category custom category, the Create button is deactivated and does not respond when you click it.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to create the new custom category. Once you create the category, you can use the Configuration utility to administer it. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility.
  2. To create a new custom category, use the following command syntax:

    create /sys url-db url-category /<partition>/<category name> display-name <category display name> urls add { <url> }

    For example:

    create /sys url-db url-category /Common/new-category display-name new-category urls add { https://www.example.com }

  3. Save the new category by typing the following command:

    save /sys config

  4. To exit the tmsh utility, type the following command:

    quit
