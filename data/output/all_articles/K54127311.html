Description

An Message Box added to an APM (Advanced Policy Manager) Access Policy will displaying a configured message string intended for the end-user to see and acknowledge seeing before the Access Policy will proceed with it's execution toward APM Session establishment.

These Message Boxes can be useful in present end-users with any Message that need to be communicated to the end-user before allowing them access to the resources protected by the APM Access Policy. So when the end-user initiates a new APM Session, the Message Box will be displayed to the end-user, and they will have to click the "Continue" button to proceed with the rest of the Access Policy's execution.

Additionally, Message Boxes can be useful in troubleshooting Access Policy execution issues since the Message Box acts like a PAUSE button on the Access Policy's execution, which provides the opportunity examine things like Session Variables, who's value can be changed at different points in the Access Policy.

Environment

Relevant environmental factors:

  • BIG-IP with APM provisioned and configured with Access Policies.

Cause

Need to add a Message to be displayed to end-users for their acknowledgement before allowing the Access Policy to continue it's execution toward APM Session establishment.

Recommended Actions

To add such a Message Box to an existing APM Access Policy, do the following.

  1. Navigate to and open the Visual Policy Editor for the Access Policy.
  2. Select the Branch & location on that Branch where the Message Box is to be added, and click the "+" (plus) button to insert a new object in that location.
  3. From the pop-up window, click the General Purpose tab, select the Message Box option, & click the Add Item button.
  4. In the Message Box's Properties page, add the Message syntax that's to be displayed to and acknowledge by the end-users, & click the Save button to add the Message Box to the Access Policy.
  5. Then click the Apply Access Policy link at the top of the Visual Policy Editor to put the new version of the Access Policy into use.
