K000091340: Azure AD Auth Provider - NGINX Controller returns a 401 unauthorized message

Type
Support Solution
Published
2022-03-31
Updated
2026-07-23
Source
https://my.f5.com/manage/s/article/K000091340

Description

When using Azure AD Auth Provider to login to NGINX Controller you may fail to login and receive an unauthorized message, e.g.

code 2393 message "Error logging in: the Azure AD login request failed. Check the user's group membership."

Environment

  • NGINX Controller
  • Azure AD

Cause

NGINX Controller failed to match user entity information with configured information

Recommended Actions

The returned message may help provide a clue as to why the login failure occurred. For example "Check the user's group membership" refers to a mismatch between user group information from Azure AD (if any) and Group Mappings configured in NGINX controller. Note: changes to Azure AD Group Mappings may take several minutes to take affect. For further troubleshooting review debug level logging on the NGINX Controller's platform-mgr pod when reproducing the issue.

kubectl patch cm $(kubectl get cm | grep platform-mgr | sed 's/ .*//') -p '{"data":{"LOG_LEVEL":"debug"}}' && kubectl delete pod -l app=platform-mgr && kubectl logs -l app=platform-mgr -f
