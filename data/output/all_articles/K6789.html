Known Issue

This is the result of a known issue. Under certain circumstances, BIG-IP LTM will fail to transmit the initial segment on a server-side flow, which causes a five second delay before the data is transferred to server. This behavior may occur under the following conditions:
  • The virtual server contains a TCP profile with Nagle disabled
  • The client sends data with reduced MSS
  • The server node is not directly connected
  • The HTTP request contains headers that exceed the client MSS

F5 Product Development tracked this issue as CR70394, CR70631, and CR70632 and it was fixed in BIG-IP LTM 9.1.3, 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
