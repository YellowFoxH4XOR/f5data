Description

In high volume BIG-IP APM  SSLVPN tunnel environments, it may be effective to disable compression to lower resource use on the system.

Environment

  • BIG-IP APM
    • Network Access (SSLVPN)
  • High resource use (CPU/Memory)
  • Large volume of concurrent users

Cause

Compression uses additional CPU cycles that may not be necessary in high volume user environments.

Recommended Actions

Disable GZIP Compression for the the Network Access tunnel: 

  1. Navigate to  Access >> Connectivity/VPN : Network Access (VPN): Network Access Lists >>
  2. Select your network access resource
  3. Under "Compression"  set the value to "No Compression"
  4. Select "Update"
  5. Apply Access policy to complete the changes. 
Note: The Connectivity Profile's Network Access Compression Settings are applicable only when GZIP Compression is enabled in the Network Access (VPN) settings
