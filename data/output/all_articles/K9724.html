Known Issue

This is the result of a known issue. If a user running some Windows operating systems, such as Windows Vista or Windows 7, connects to the FirePass controller using Firefox, then attempts to open a Network Access or Application Access favorite, the connection may fail to open. In addition, an error message that appears similar to the following example will display:

Error downloading required files Access is denied

This issue occurs when the F5 Networks Auto Update client control (InstallerControl.dll) is not already installed on the client system. This client control should be automatically installed when the user selects the Network Access or Application Access favorite; however, it does not install properly when running Firefox on Windows Vista or Windows 7.

F5 Product Development is tracking this issue as ID 227288 (formerly CR86665-1).

Workaround

Users can work around this issue by connecting to FirePass using Internet Explorer and launching a Network Access or Application Access favorite. This action installs the F5 Networks Auto Update client control on the client system, allowing the user to successfully connect to Network Access and Application Access favorites using Firefox.

Alternately, you can work around this issue by pre-installing the FirePass Base Controls package on Windows Vista or Windows 7 client systems. You can obtain the Base Controls package on the Device Management : Client Downloads : Windows (x86) page in the FirePass Administrative Console.
