Description

IP ranges and Domain names for auto-discovery endpoints are not getting fetched to the user without access to internet, but  connected via a proxy.

Following error may appear in the GUI and var/log/apm logs:

"Error in getting Address Space Provider Metadata from the URI https://example.com for the provider <Address Space object name> and error message is Content length header is missing. on <date> <time>"
 

 Environment

  • BIG-IP APM
  • Proxy
  • Zoom
  • Microsoft Office 365

 Cause

Dynamic Address Space discovery feature is currently not supported via proxy.

 Recommended Actions

None

None
