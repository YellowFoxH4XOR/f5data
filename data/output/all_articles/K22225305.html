Description

Question:

If we can perform backup/restore to individual partitions?

Environment

  • BIG-IP
  • Backup Partitions
  • Restore Partitions

Cause

Yes, we can backup and restore individual partitions
 

Recommended Actions

  1. Backup partition TMSH command:
    # tmsh save /sys config partitions { partition-name }

    note 1: This TMSH command will save a copy of configuration file "bigip.conf" on folder "/config/partitions/<partition_name>"
    note 2: If you perform a changes on the partition via CLI, please perform a TMSH command "save /sys config or save /sys config partitions { partition-name }" to save/replace the "bigip.conf" config file
    note 3: If you perform the changes via BIG-IP Configuration utility (GUI), it will automatically save/replace the file "bigip.conf" stored in "/config/partitions/<partition_name>"
    note 4: Please download and save a backup copy of the "bigip.conf" file that stored in "/config/partitions/<partition_name>"
     
  2. Restore partition prerequisite:
    • Same partition name must be created before restoring the partition configuration
    • Please make sure dependent configuration for any of the configuration under the partition "example: for /ltm virtual, make sure shared (/ltm /Common/node and /ltm Common/pool) are already created" 
    • If you plan to restore the partition on a different BIG-IP version, please make sure you change the entry as example below where restoring from version 15.1.5 to 16.1.2.2:
      • # vim /config/partitions/partition_name/bigip.conf
      • Change entry of #TMSH-VERSION: 15.1.5  >>> to >>> #TMSH-VERSION: 16.1.2.2
      • If the BIG-IP prompt error message: review the error message and make amendment on the "bigip.conf" file configuration (e,g, deprecated command)
         
  3. Steps to restore partition configuration with TMSH command:
    • Copy the backup file "bigip.conf" into the partition folder "/config/partitions/<partition_name>"
    • TMSH command
      # load /sys config partitions { partition-name }
       
  4. To confirm if the partition loaded with TMSH command:
    # tmsh
    # cd /partition_name

Additional Information

TMSH command "save /sys config" , it will also save a copy of the partition configuration at the same folder location.
Notes: If you are having subfolder inside the partition, you may hit the bug ID714216
