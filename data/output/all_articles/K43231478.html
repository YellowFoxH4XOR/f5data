Description

You see the BIG-IP GTM or DNS is marking a virtual server pool member down even though the virtual server is shown as available on the LTM 

Environment

  • BIG-IP GTM or DNS
  • GSLB BIG-IP Server object (LTM)
  • GSLB Pool with configured monitor

Cause

Redundant, non-functioning monitor on pool is causing BIG-IP GTM/DNS to override the monitor setting being conveyed through the bigip monitor

Recommended Actions

To determine why a DNS pool member is mark as offline you can use the following procedure.
Note: If any the DNS/GTM pool members are marked as Offline and the configured BIG-IP server shows the affected virtual server as Available there is likely an issue with the GTM pool monitor configuration.
 

  1. From the command line of the DNS/GTM system check the GTM pool status:

    tmsh /show /gtm pool <dns record type> <pool name>

    Example:
    Note: The following example command output was intentionally truncated to show only pertinent data.

    tmsh show /gtm pool a generic-http-pool

    ------------------------------
    Gtm::Pool::A generic-http-pool
    ------------------------------
    Status
      Availability : offline
      State        : enabled
      Reason       : No enabled pool members available

    Load Balancing ....

      
  2. Check the DNS/GTM pool member LTM virtual server status:

    To show all virtual servers from the BIG-IP server:
    tmsh show /gtm server <big-ip server name> virtual-servers

    To show a specific virtual server configured on the BIG-IP server:
    tmsh show /gtm server <big-ip server name> virtual-servers { <path><virtual server name> }

    Example:
    Note: The following example command output was intentionally truncated to show only pertinent data.

    tmsh show /gtm server BIG-IP virtual-servers { /Common/generic-http-vs}

    ----------------------------------------------
    Gtm::Server: BIG-IP
    ----------------------------------------------
    Status
      Availability : available
      State        : enabled
      Reason       : Available

    Global....

      ---------------------------------------
      | Gtm::Virtual Server: generic-http-vs
      ---------------------------------------
      | Status
      |   Availability : available
      |   State        : enabled
      |   Reason       :  Monitor /Common/bigip from 192.168.1.174 : UP
      |   Destination  : 192.168.1.183:80
      |   Up Time      : 1 day 2:04

      
  3. List the DNS/GTM pool configuration: 

    tmsh list /gtm pool <dns record type> <pool name>

    Note: The default server monitor (typically the bigip server monitor type) will not be listed in the output for pool level monitors.

    Example:
    tmsh list /gtm pool a generic-http-pool

    gtm pool a generic-http-pool {
        members {
            BIG-IP:/Common/generic-http-vs {
                member-order 0
            }
        }
        monitor gtp
    }

    Note: In the example the DNS/GTM pool is configured with the additional gtp monitor and this is likely the cause of the pool members being marked as offline since the LTM status shows the same virtual server as available.

Additional Information

Use the following command to see the reason why the virtual-server is marked down on BIG-IP DNS, and which device it came from for further investigation:

tmsh show /gtm server virtual-servers <name>
