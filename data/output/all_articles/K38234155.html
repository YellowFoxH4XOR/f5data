Description

Can the BIG-IP 11000 or 11050 be upgraded to a most recent software version?

Environment

  • BIG-IP 11000/11050
  • Software Upgrade
  • v13.1.3.3 and later
Cause

In order to gain protection against the May 2022 vulnerabilities (K55879220), administrators have been upgrading to software versions beyond those listed in the F5 hardware/software compatibility matrix (K9476).
This is covered by extended support (K4309) and explained in the FAQ at K95321843 (see q13, "What should I do if I am running an older platform, such as BIG-IP 6900, which is not compatible with the fixed software versions?").
In essence, the latest versions of the listed supported versions should work.

For the E101/11000 & E102/11050 the listed last supported version is 13.1.1. It was anticipated that they could run 13.1.5 to mitigate the CVEs covered by K55879220.
However, the linux Kernel upgrade from 3.10.0-514.26.2 to 3.10.0-862.14.4 which took place in the software upgrade from 13.1.3.2 to 13.1.3.3 (K3645) prevents these platforms from booting into versions 13.1.3.3 and later.

There is no workaround for this.
The E101/11000 & E102/11050 platforms are therefore limited to software version 13.1.3.2
