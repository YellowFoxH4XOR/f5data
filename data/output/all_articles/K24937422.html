Description

User-Agent (UA) of Pinterests crawler not detected by Untrusted Bot Defense signature protection.

Environment

  • BIG-IP ASM running software version 14.1.x or 15.x

  • Bot Signatures

Cause

ID749554 - [uBot] UA of Pinterest's crawler is not detecting correctly by the system

Note: Seen behavior can be expected if the unit in question is running software version 14.1.x or 15.x with older Bot signatures and does not have a Threat Campaign subscription.

Recommended Actions

  • Update to the latest Threat Campaign Bot Signatures.

  • Upgrade to a later software major release.

Workaround:

Create a Custom Pinterest Bot Signature:

  1. On the Main tab, click Security > Bot Defense > Bot Signature > Bot Signatures List.
  2. Click Create.
    The Create New Bot Signature screen opens.

  3. In the Bot Name field, type the unique name of 'Pinterest-Custom'.

  4. From the Category list, select the type of bot this signature will protect against 'Social Media Agent'.

  5. In the Rule area, set User Agent Contains 'Pinterestbot'.

  6. Click Save to create the new bot signature.

Additional Information

Bot Signatures are a class of signatures that identify legitimate or malicious web robots by looking for specific patterns in the headers of incoming HTTP requests. With the release of BIG-IP 14.1.0, this feature now requires a separate license. Bot signature updates are part of the Threat Campaigns subscription-based service license. Without a Threat Campaigns license, bot signatures cannot be updated using manual or automatic updates; however, you can still add custom bot signatures.
