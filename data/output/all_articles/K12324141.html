Description

The information stored by iRule table command called from VS-A is not available for table command called from VS-B even if called from the same iRule. I.e.

VS-A belongs to traffic group A
VS-B belongs to traffic group B

The table information is not shared between traffic groups.

Environment

  • LTM
  • iRule
  • Virtual Server
  • Traffic-group

Cause

None. This is the expected behavior.

Recommended Actions

When designing iRules, be aware that table information is not shared between traffic groups, even if the same iRule is used.

None
