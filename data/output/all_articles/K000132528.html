Description

You might observe the following warning message in /var/log/liveinstall.log during software upgrade or downgrade :

progress: 6/100
info: Creating target filesystems.
info: Installing packages.
warning: tm_install::VolumeSet::choose_filesystem_plan -- No (vadc_large) filesystem requirements found on media
 

Environment

・BIG-IP
・Appliance
・Upgrade or downgrade
 

Cause

This is expected behavior and can be safely ignored because vadc_large filesystem only applicable to Virtual Edition.
 

Recommended Actions

None
 

Additional Information

An improvement Bug ID 1813885 was raised to change the log level of this message from "warning" to "info".
