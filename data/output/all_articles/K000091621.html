K000091621: NGINX Controller custom logo reverts back to default logo daily

Type
Support Solution
Published
2023-03-20
Updated
2023-03-20
Source
https://my.f5.com/manage/s/article/K000091621

Description

A custom logo is configured for NGINX Controller, but logo is reverting back to default logo automatically. After re-configure custom logo, the revert of logo happens again and possibly daily.


 Environment

  • NGINX Controller v3.22.x
  • Use helper.sh setlogo <svg-file> to set a customized SVG image as a GUI logo.

 Cause

Bug ID NMS-34314.


 Recommended Actions

Run this command to prevent logo from reverting to default.

kubectl -n nginx-controller create configmap controller-updating --from-literal=SUSPEND_RECONCILE=true



 Additional Information

https://docs.nginx.com/nginx-controller/admin-guides/install/using-helper-script/#add-a-custom-logo
