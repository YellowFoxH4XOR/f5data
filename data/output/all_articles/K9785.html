K9785: Citrix MetaFrame Portal Terminal Server favorites are not displayed in the standalone VPN client

Topic

FirePass offers several methods for accessing a Citrix XenApp server (formerly Citrix Presentation Server and Citrix MetaFrame Server) through the FirePass controller. These methods are published in the FirePass Controller Administrator Guide and the F5 FirePass Deployment Guide for Citrix.

Of the methods available, the Citrix Metaframe Portal method enables the FirePass controller to communicate with the Citrix XML server to retrieve a list of published applications and present those applications as a list of hyperlinks on the webtop. Since the resources are presented in a web-based format and require browser-based controls, Citrix Metaframe Portal Terminal Server favorites cannot be accessed from the FirePass standalone VPN client. Therefore, when a user is running the standalone VPN client in Advanced Mode, Citrix MetaFrame Portal Terminal Server favorites are not listed under Terminal Servers in the left navigational pane.

Users who want to access Citrix Metaframe Portal Terminal Server favorites should logon to FirePass using a browser. Citrix Metaframe Terminal Server favorites and Citrix Metaframe Browser Terminal Server favorites can be accessed using the standalone VPN client in Advanced Mode.
