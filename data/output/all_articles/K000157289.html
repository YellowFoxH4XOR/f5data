Source

Description

A monitor is a BIG-IP feature that verifies connections to pool members or nodes. A health monitor is designed to report the status of a pool, pool member, or node on an ongoing basis, at a set interval.

A health monitor is maintained by bigd daemon or tmm, there are global health monitor statistics reported by bigd or tmm is avaialble such as total number of probe, number of successful probes, number of failed probes. Those statistics is accessible via tmsh or iControl REST.

Environment

  • BIG-IP LTM all version
  • health monitor is configured

Cause

This is additional feature.

Recommended Actions

To view statistics of a monitor type

Use the following command syntax.

tmsh show ltm monitor <monitor-type> stats

Output appears similar to the following example which uses http monitor type.

tmsh show ltm monitor http stats

---------------------------------------------------------------------------------------------------
Type  Name  Bigd Instance  Node Count  Pool Member Count  Probe Count  Probe Success  Probe Failure
---------------------------------------------------------------------------------------------------
http  http              0           0                  1        31327          31327              0

Coloum headings as following:

Field nameDescription
TypeThe monitor type
NameThe name of the monitor
Bigd InstanceThe process id of bigd that is responsible for creating and running the monitor
Node CountThe number of nodes associated with this monitor
Pool Member CountThe number of pool members associated with this monitor
Probe CountThe number of probes sent by this monitor to an ip-address
Probe SuccessThe number successful responses as a result of this monitor's probes
Probe FailureThe number failed responses as a result of this monitor's probes

The following restcurl operation can be used to view statistics of a monitor type
restcurl -u admin:<admin password> /mgmt/tm/ltm/monitor/<monitor-type>/stats?options=stats

To view statistics of a monitor instance in a monitor type

Use the following command syntax.

tmsh show ltm monitor <monitor-type> <monitor-instance> stats

Output appears similar to the following example which uses myhttpmon monitor instance in http monitor type.

tmsh show /ltm monitor http myhttpmon stats
------------------------------------------------------------------------------------------
Ltm::Monitor: myhttpmon

IP-Address:Port          Bigd Instance  Latency  Probe Count  Probe Success  Probe Failure
------------------------------------------------------------------------------------------
::ffff:10.1.116.193.80               0        0            3              0              0
::ffff:10.2.116.207.80               0      159            3              3              0

Coloum headings as following:

Field nameDescription
NameThe name of the monitor instance
IP-Address:PortThe ip-address:port of the node or pool-member
Bigd InstanceThe bigd process id responsible for spawning this monitor
LatencyThe RTT
Probe Count The number of probes sent to the server
Probe SuccessThe number of server responses received as a result of probes
Probe FailureThe number of probes that received no response
