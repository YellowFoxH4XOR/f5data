K000137444: SSL ERROR when accessing iControl REST endpoint by using curl on macOS

Type
Support Solution
Published
2023-11-01
Updated
2023-11-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000137444

Description

After upgrading to 17.1.0.1 or later, you get the following error when you access the BIG-IP iControl REST endpoint with curl command on macOS.

macOS:~ User $ curl -skvu admin:<admin passwd> https://<BIG-IP IP Address>/mgmt/tm/sys/software/volume
*  Trying <BIG-IP address>:443...
<snip>
* LibreSSL SSL_connect: SSL_ERROR_SYSCALL in connection to <BIG-IP IP Address>:443

 

You also see an error message like the following on /var/log/httpd/httpd_errors on the BIG-IP.

 

SSL Library Error: error:1408B10E:SSL routines:ssl3_get_client_key_exchange:Extended Master Secret must be used when FIPS 140-3 Cipher Strict Mode is enabled

 

 

Environment

  • You are using or upgraded to BIG-IP 17.1.0.1 or later.
  • FIPS 140-3 license is installed on the BIG-IP.
  • You are accessing iControl REST endpoint by using curl on macOS.

Cause

The issue occurs because of the change with ID 1252093.

Recommended Actions

  • Update your client to support Extended Master Secret (RFC 7627), or uninstall FIPS 140-3 license to disable FIPS 140-3

Additional Information

RFC 7627 Transport Layer Security (TLS) Session Hash and Extended Master Secret Extension
