Description

Since 17.1.0 release, BIG-IP now supports Elliptic Curve Cryptography (ECC) Brainpool curves in LTM/SSL for ephemeral key exchange and digital signature.
The following Brainpool curves are supported for TLS1.2 and TLS1.3:

  • For TLS1.2:
    • brainpoolP256r1
    • brainpoolP384r1
    • For TLS1.3:
      • brainpoolP256r1tls13
      • brainpoolP384r1tls13
    This article will present a way to implement Elliptic Curve Cryptography Brainpool curves.

      Environment

      • BIG-IP LTM
      • SSL profile
      • Cipher Rule/Group

      Cause

      None

      Recommended Actions

      To implement Elliptic Curve Cryptography (ECC) Brainpool curves, using Configuration Utility (GUI), please follow below steps:

      1. Log in to the Configuration utility.
      2. Navigate to Local Traffic > Ciphers > Rules.
      3. Click Create.
      4. Under General Properties , for Name, type a unique name.
      5. Under Rule Creation, for Cipher Suites, type the required cipher string value.
      6. For Signature Algorithms, type the signature algorithms, or type the special keyword DEFAULT to use the recommended algorithm set.
      7. For DH Groups, type the Elliptic Curve Diffie-Hellman (ECDH) key exchange algorithms. As desired to use Brainpool curves, type in DH Groups field:    BRAINPOOLP256R1:BRAINPOOLP384R1:BRAINPOOLP256R1TLS13:BRAINPOOLP384R1TLS13
      8. In the Rule Audit section, you can review the Cryptographic Parameters list to ensure that you get the results you expect.
      9. Click Finished.
      Such created Cipher Rule you can attach to desired Cipher Group, which will be further used in SSL profile.
      For more information, on how to implement such Rule, please follow article: K10866411: Creating a custom cipher group using the Configuration utility
