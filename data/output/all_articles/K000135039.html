K000135039: How to start Edge Client in disconnected state after installing BIG-IP Edge Client

Type
Support Solution
Published
2023-06-15
Updated
2023-06-15
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.X, 17.1.0
Source
https://my.f5.com/manage/s/article/K000135039

Description

It is possible to start Edge Client in disconnected state after installing BIG-IP Edge Client by using "Launch in Disconnected State After Windows Logon".

This is not default option, so you should check the option from downloading Customize Windows Client Package > BIGIP Edge Client.

Environment

  • BIG-IP APM v17.1.0 and later

Cause

  • This is by design

Recommended Actions

None
