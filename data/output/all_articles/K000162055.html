K000162055: APM Kerberos authentication may fail after upgrade to 17.5.1.6

Type
Support Solution
Published
2026-07-02
Updated
2026-09-09
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000162055

Description

After upgrading the BIG-IP APM to 17.5.1.6, Kerberos authentication may consistently fail for certain users.

The same APM configuration and users pass Kerberos authentication on earlier versions of BIG-IP software.

In /var/log/apm:

err apmd[14955]: 01490000:3: HTTPParser.cpp func: "parseHttpGenericHeader()" line: 608 Msg: HTTP header line too long (10289 bytes), dropping.

 

Environment

BIG-IP APM v17.5.1.6

APM access policies using Kerberos authentication

 

Cause

Bug ID 2347033

A software defect introduced in BIG-IP version 17.5.1.6 (Bug ID 2347033) caused Kerberos authentication to fail for certain users after an upgrade.

The defect resulted in the APM not properly handling Kerberos/SPNEGO tokens, leading affected clients to fall back to Basic authentication and immediate authentication failure.

 

Answer/Recommended Actions

There are no workarounds however an engineering hotfix is available.

If you are observing this issue, create a new support ticket and request an engineering hotfix for bug ID 2347033
