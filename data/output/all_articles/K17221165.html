Known Issue

The WMI GetCPUInfo command from the F5.IsHandler.dll may return an error.

This issue occurs when all of the following conditions are met:

  • You are using F5IsHandler.dll 1.0.5.0.
  • You are using the DLL on an Microsoft Internet Information Services (IIS) web server running on a Hyper-V virtual machine.
  • You are monitoring the CPU usage of IIS pool members.

Impact

You may be unable to use the WMI monitor to monitor a pool of IIS servers.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The IIS error logs display an error similar to the following example:

    [TypeInitializationException: The type initializer for 'F5.PseudoCPU' threw an exception.]

  • You are unable to monitor IIS CPU usage from an F5 host.
