Issue

When a user accesses a web page through the Portal Access reverse-proxy engine, FirePass may report an error message similar to the following example:

Parse Error: EOI in quot-quoted string

This error message occurs when the source code of the destination web page contains the string &quot; within a set of single or double quotes. For example:

<input type="submit" name="test" value="echo f5555555" onclick="window.location=&quot;echo.php?echome=f5555555&quot;" />

F5 Product Development tracked this issue as CR70737 and it was fixed in FirePass 6.0.2. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by changing each &quot; string to a double quote ( " ) character in the source code of the affected web page. Additionally, if the &quot; string is enclosed by double quote characters, you need to change the double quote characters to single quote ( ' ) characters.

For example:

<input type="submit" name="test" value="echo f5555555" onclick="window.location=&quot;echo.php?echome=f5555555&quot;" />

Replace the above example with the following:

<input type="submit" name="test" value="echo f5555555" onclick='window.location="echo.php?echome=f5555555"' />
