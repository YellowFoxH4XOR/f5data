Issue

In FirePass 6.0.0 and later, when creating local users by import or by individual entry, the Desktop Access and FirePass Webtop options no longer appear in the page on which you create users. This is due to the end-of-life of the Desktop Access feature.

The FirePass controller offers several options to create local users. From the Users > User Management page, you can select the method of creation with the Create user accounts by menu. In versions of FirePass versions prior to 6.0.0, depending on the method you selected, either check boxes or drop-down menu options appear for you to enable Desktop Access, FirePass Webtop Access, or both.

These options are no longer available in software releases where the Desktop Access feature is not present. Because Webtop Access is the only form of access to the FirePass controller, no options are offered in the process of creating a user.

Note: Licensing SSL offload to an F5 BIG-IP LTM in the FirePass 5.x maintenance release will disable the Desktop Access feature, and cause this behavior change.
