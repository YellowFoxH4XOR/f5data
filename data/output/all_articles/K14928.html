Known Issue

The BIG-IP APM apd process may core when SAML (Security Assertion Markup Language) IdP (Identity Provider) connector profiles use SLO (Single Logout Service) settings.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a SAML SP (Service Provider) profile.
  • The BIG-IP APM SAML IdP connector profile is configured with SLO.
  • The SAML IdP response contains an assertion without a SessionIndex element in the AuthnStatement.

Impact

SAML authentication fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP APM  temporarily stops processing traffic.
  • The BIG-IP APM /shared/core directory contains apd core file(s) with event centric time stamps.
  • The BIG-IP APM /var/log/apm file contains an error messages that appears similar to the following example:

    apd[23577]: 01490000:5: ** SIGSEGV **
    apd[23577]: 01490000:5: stack trace:

Workaround

To work around this issue, you can clear the URL references of the SLO configuration or reconfigure the format of the IdP server's assertions by performing the following procedure:

Impact of workaround: Users can no longer globally log out of their SAML authenticated sessions with the BIG-IP APM system.

  1. Log on to the Configuration utility.
  2. Navigate to Access Profiles > SAML > BIG-IP as SP.
  3. Click the IdP External Connectors tab.
  4. Select the check box in front of the Name of the IdP External Connector profile.
  5. Click Edit.
  6. Click SLO Service Settings in the Edit SAML IdP Connector menu.
  7. Remove the configured Single Logout Request URL.
  8. Remove the configured Single Logout Response URL.
  9. Click OK.

Alternatively, you can reconfigure the SAML IdP server to include the proper format of the IdP assertions. Refer to your IdP manufacturer's configuration guide regarding the contents of SAML assertions.
