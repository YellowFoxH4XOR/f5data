K3220: Reasons why 3-DNS may provide the IP address of a virtual server that is down or disabled

Topic

If static persistence and the global drain_requests are enabled, 3-DNS will continue to provide the IP address of a disabled virtual server until the TTL for that virtual server expires.

If your application must persist connections to the same node once a session begins, you should not change this configuration. If you use persistence only to increase the performance of your application, you can improve reliability by disabling the drain_requests global.

You can disable the drain_requests global from the Configuration utility or the command line.

Configuration utility

To disable the drain_requests global from the Configuration utility, perform the following steps:

  1. Log in to the Configuration utility.
  2. In the main navigation pane, select System.
  3. Click the General tab.
  4. Un-check the box for Drain Requests.
  5. Click the Update button.

Command line

To disable the drain_requests global from the command line, perform the following steps:

  1. Log in to the command line.
  2. Edit the /config/3dns/etc/wideip.conf file.
  3. Locate the section that begins with globals {.
  4. At the end of the globals { section, add the following line:
        drain_requests         yes
  5. Save the file and exit the editor.
  6. Apply the configuration change, by typing the following command:
        3ndc reload
