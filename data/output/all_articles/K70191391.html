  • K17850044: F5 DDoS Hybrid Defender software support policy (12.x - 13.x)

DDoS Hybrid Defender is built on the iAppLX framework and is tied to a BIG-IP release. Therefore, the DDoS Hybrid Defender support policy is based on the iAppLX version associated with that release. The combination of the BIG-IP version plus the DDoS Hybrid Defender version provides the ability for out-of-band updates (RPMs) available from the F5 Downloads site. These out-of-band releases follow the base release, unless specified otherwise.

This policy addresses the BIG-IP version and the DDoS Hybrid Defender version that ships together on-box. For example, BIG-IP 14.0.0 ships with DDoS Hybrid Defender 4.0.0, and BIG-IP 14.1.0 ships with DDoS Hybrid Defender 5.0.0. The combined versions are represented as a single string, for example 14.0.0-4.0.0 and 14.1.0-5.0.0, respectively. As a result, this policy maps to both versions and aligns with the F5 release model.

Software version support of DDoS Hybrid Defender

For Major Releases (x.0.0) up to and including BIG-IP 17.0.0, the Standard Support phase begins with the first customer ship date of the release and continues for 15 months. For Major releases (x.0.0) beyond BIG-IP 21.0.0, the Standard Support phase begins with the first customer ship date of the release and continues for 9 months. When this milestone is reached, the Major Release has reached its End of Software Development (EoSD) and End of Technical Support (EoTS) milestone.

Each x.1.0 release marks the start of the Long-Term Stability Release. The initial release (x.1.0) contains new features, stability improvements, and new hardware support. Subsequent maintenance releases (x.1.1 to x.1.n) address product defects, security fixes, diagnostic and supportability improvements, minor functional improvements, and new hardware support. Software Development support activities will occur only on the latest maintenance release of each Long-Term Stability Release (x.1.latest-latest) while the Long-Term Stability Release is within the Standard Support phase.

The Standard Support phase for the Long-Term Stability Release begins with the first customer ship date of the x.1.0 release and extends for the following duration:

  • Five years - BIG-IP versions prior to 16.1.0
  • Four years - BIG-IP version 16.1.0 and subsequent x.1.0 releases

Note: For more information about Major, Feature, and Maintenance release numbering, refer to K8986: F5 product support policies.

At the end of a release’s Standard Support phase, the release enters its EoSD and EoTS milestone. Software versions that have reached their EoSD date are no longer supported with active software development. F5 will not provide software fixes (hotfixes) or consulting services for a version that has reached the EoSD milestone.

For software releases, unless specifically declared and announced by F5, the EoTS date marks the end of the software version’s support phase.
