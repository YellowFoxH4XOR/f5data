K000150985: Traffic does not flow to Rancher Kubernetes cluster on failover of a BIG-IP in HA. The Rancher nodes do not see the GARP which announces the failover

Description

You have a BIG-IP in standard HA configuration with a Kubernetes cluster as pool members.

Traffic does not flow on BIG-IP failover.

Monitor traffic is unaffected.

Environment

You are using Rancher as the Kubernetes Cluster.

You may be deploying Container Ingress Services. (CIS)

 

Cause

On failover, the BIG-IP sends 5 GARP's for each floating object on a traffic group. This includes the Floating Self IP or SNAT pool address

These notify devices on the VLANs that the arp cache must be updated.

The Kubernetes nodes which are on the VLAN do not receive the GARP's and continue to send traffic to the old device, which is now the standby BIG-IP.

 

This is not an issue with BIG-IP or CIS but seems to be an issue with calico as used in Rancher.

See https://github.com/projectcalico/calico/pull/9582

 

Recommended Actions

Changing the failover mode to MAC masquerade may resolve this.

See https://my.f5.com/manage/s/article/K13502

 

In addition please consult with your Kubernetes supplier.

 

 

Additional Information

This is not an issue with F5's products.

As the issue is with Calico, other Kubernetes products may be affected.
