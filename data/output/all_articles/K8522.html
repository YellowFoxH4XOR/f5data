Topic

By default, the /home and /config directories are synchronized to the peer system during a configsync operation. In the event that a large file such as an ISO image or upgrade file is saved to either directory, the configuration synchronization (ConfigSync) process may fail to complete within the iControl portal timeout period of 300 seconds. When this issue occurs, error messages similar to the following example will be output to the system console:

SOAPException: 'Unexpected return Content-Type: text/html; charset=iso-8859-1'
Saving active configuration...
Transport and install failed
Error running config sync all.
BIGpipe parsing error:
01110001:3: Error running config sync all

Additionally, the BIG-IP system will not log a message similar to the following to /var/log/ltm if the configsync process failed:
bigpipe: Completed config install operation

If you have determined that the ConfigSync process is failing due to large disk usage under the /home or /config directories, contact F5 Technical Support for assistance in clearing space on the BIG-IP system.

Note: For more information, refer to K7024: Overview of the ConfigSync process (9.x - 10.x) and K4423: Overview of UCS archives.

Note: If you no longer want to include the /home directory in your UCS archives, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.
