Known Issue

The Elasticsearch process in BIG-IQ Data Collection Devices (DCD) may restart every few hours.

This issue occurs when all of the following conditions are met:

  • The amount of unique Elasticsearch documents created for a certain statistic dimension combination exceeds the 12,500 document limit.
  • The BIG-IQ system attempts to aggregate the statistics data.

Impact

The aggregated statistics data are not collected and the related module events are pending due to the failed Elasticsearch process.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log/elasticsearch/eslognode.log file on BIG-IQ DCDs, you observe messages that appear similar to the following example:

    java.lang.NoClassDefFoundError: org/elasticsearch/client/RestClient

Workaround

To work around this issue, you can upgrade F5 Elasticsearch plugins on all the BIG-IQ devices in your cluster, including the BIG-IQ Centralized Management primary, BIG-IQ Centralized Management secondary, and DCDs. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Go to the BIG-IQ Centralized Management 8.0.0 page on the F5 Downloads site, and download the following files:
    • fix_plugins.tar.gz
    • fix_plugins.tar.gz.md5
  2. Use an SCP client to copy the downloaded files to the /shared directory of the target Elasticsearch node (BIG-IQ Centralized Management or DCD).

    Note: For information about uploading files to an F5 system, refer to K175: Transferring files to or from an F5 system.

  3. Log in to the command line of the BIG-IQ device where the files are copied.
  4. To change to the /shared directory, enter the following command:

    cd /shared

  5. To verify the MD5 checksum of the TAR file, enter the following command:

    md5sum -c fix_plugins.tar.gz.md5

  6. To extract the upgrade plugin files, enter the following command:

    tar -zxvf fix_plugins.tar.gz

  7. To change to the directory where the plugin files are located, enter the following command:

    cd fix_plugins

  8. To upgrade the Elasticsearch plugins, enter the following command:

    ./reinstall_plugins.sh

  9. To verify the Elasticsearch cluster health and ensure it has a green status after the plugin upgrade, enter the following command:

    curl -k -u admin:admin https://localhost:9200/_cluster/health | jq . | grep status

  10. Repeat the upgrade procedure until the Elasticsearch plugin upgrade files are applied to all BIG-IQ Centralized Management devices and DCDs in the cluster.
