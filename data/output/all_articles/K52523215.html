K52523215: 01070668:3: The amount of cache memory assigned to Web Acceleration profiles (6144MB) exceeds the maximum amount (<>MB) defined by Ramcache.MaxMemoryPercent (50)

Type
Support Solution
Published
2022-12-27
Updated
2025-02-06
Applies to
  • Legacy Products
  • BIG-IP
  • BIG-IP WebAccelerator
Source
https://my.f5.com/manage/s/article/K52523215

Description

Configuration load fails on the BIG-IP device fails with below error :

01070668:3: The amount of cache memory assigned to Web Acceleration profiles (6144MB) exceeds the maximum amount (<>MB) defined by Ramcache.MaxMemoryPercent (50)

Environment

  • BIG-IP
  • Web Acceleration module 
  • Configuration load fails 

Cause

Default profile in /config/profile_base.conf attached to Virtual Server :

ltm profile web-acceleration optimized-acceleration {
    cache-object-max-size 67108864
    cache-object-min-size 0
    cache-size 6144                 ------------------------> size matches error
    defaults-from /Common/webacceleration
}

Recommended Actions

1.  To check if any virtual server in configuration is using this web-acceleration profile , run:

     For /Common partition :
   grep -i optimized-acceleration /config/bigip.conf

     For all other partitions:
   grep -i optimized-acceleration /config/partitions/*/bigip.conf

2. Take a UCS backup of the device 3. Backup the bigip.conf file using "cp" command

    Example:
  cp /config/bigip.conf /config/bigip.conf.backup

4. Use "vi" or any other editor to modify bigip.conf to remove optimized-acceleration web-acceleration profile from VIP

   Before :

ltm virtual /Common/Test_vs {
    destination /Common/10.10.10.10:443
    ip-protocol tcp
    mask 255.255.255.255
    pool /Common/Test_Pool
    profiles {
        /Common/clientssl {
            context clientside
        }
        /Common/http { }
        /Common/optimized-acceleration { }    ----> remove this 
        /Common/tcp { }
    }
    source 0.0.0.0/0
    source-address-translation {
        type automap
    }
    translate-address enabled
    translate-port enabled
}

  After :

ltm virtual /Common/Test_vs{
    destination /Common/10.10.10.10:443
    ip-protocol tcp
    mask 255.255.255.255
    pool /Common/Test_Pool
    profiles {
        /Common/clientssl {
            context clientside
        }
        /Common/http { }
        /Common/tcp { }
    }
    source 0.0.0.0/0
    source-address-translation {
        type automap
    }
    translate-address enabled
    translate-port enabled
}


5. Verify the configuration load works using :
    tmsh load sys config verify

6. If verify configuration load works , load the configuration using :
    tmsh load sys config
