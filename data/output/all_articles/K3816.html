K3816: Restrictions on folder names in mobile email

Topic



The FirePass Mobile Email feature uses Internet Message Access Protocol (IMAP) to communicate with the mail server. The IMAP protocol does not support forward slash characters in folder names, because IMAP uses the forward slash as a delimiter. As a result, the FirePass Mobile Email feature does not support folders with names that contain a forward slash.
