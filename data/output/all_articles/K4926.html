The BIG-IP version 4.5 software branch uses the respawn utility to monitor specific daemons and will restart the daemons in the event of a system failure. The following daemons are monitored using the respawn utility:

  • corbalocallb
  • corbamgmt
  • corbanetwork
  • corbaportal
  • corbasystem
  • sfd
  • slapd

The list of daemons monitored with the respawn utility is static and can only be modified by F5 Networks Product Development. If you need the respawn utility to monitor additional daemons, you can submit a request for enhancement (RFE) through F5 Networks Technical Support.
