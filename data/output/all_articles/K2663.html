Topic

By default, the 3-DNS Controller updates the Local Domain Name System (LDNS) file every 3600 seconds. This interval setting is located in the wideip.conf file in the global sub-statement timer_persist_cache.

Depending on your specific configuration, every 3600 seconds may be too often to update the LDNS file. This can be the case if you have several thousand LDNS or persistence records; however, to avoid performance issues, it is important not to adjust this setting too low.

If your configuration is small enough and you need to lower the timer_persist_cache setting, F5 recommends decreasing it by 300 seconds and then verifying the performance before decreasing it more.

For more information about timer values and instructions about how to change the global settings, refer to the 3-DNS Controller Reference Guide.
