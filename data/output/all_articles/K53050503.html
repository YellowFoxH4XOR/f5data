K53050503: Problem to process QKViews on iHealth

Type
Support Solution
Published
2022-10-20
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K53050503

Description

  • Unable to process qkviews on iHealth
  • An error message similar to the following can be seen on iHealth

    Qkview: 19420738 has failed initial processing and has been removed

Environment

  • Qkview
  • IHealth

Cause

None

Recommended Actions

Go to the main ihealth page and on top right corner, there is a feedback button where you can request the ihealth team to analyze the root cause of the failure.

Additional Information

None
