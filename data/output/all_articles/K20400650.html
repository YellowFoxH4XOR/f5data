K20400650: How to enable remote TACACS+ authentication on BIGIQ for SSH/TMSH access

Type
Support Solution
Published
2022-02-25
Updated
2024-12-10
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X
Source
https://my.f5.com/manage/s/article/K20400650

Description
To enable administrative bash and tmsh access for BIG-IQ using TACACS+, you must use tmsh commands.

To configure TACACS+ authentication for accessing the BIG-IQ GUI refer to K31586420: Configuring the BIG-IQ system to use TACACS+ based authentication and authorization.

Environment

  • BIG-IQ
  • tmsh

Cause
The GUI set-up for TACACS+ (USER MANAGEMENT > Auth Providers) does not apply to users accessing the command line of BIG-IQ. They're not related.

Recommended Actions

  1. Make sure an admin user is configured on your TACACS+ server with F5 attributes. For example:
    user = bigip_admin {
    name = "Admin User"
    member = "admin_group"
    }
    group = admin_group {
            service = ppp protocol = ip {
            F5-LTM-User-Info-1 = adm
            }
    }
  2. Log into the BIG-IQ using the default root user account.
  3. Create the remote role group using the following syntax:
    tmsh modify auth remote-role role-info add { <group name> { attribute <F5 vendor attribute> console enable line-order <integer> role <user role> user-partition <partition name, Common, or All> }}
    For example: 
    tmsh modify auth remote-role role-info add { adm { attribute F5-LTM-User-Info-1=adm console enable line-order 1 role administrator user-partition All }}
  4. Add the TACACS+ server using the following syntax:
    tmsh create auth tacacs system-auth protocol ip secret <tac plus secret> servers add { <ip address> } service ppp
  5. Modify the auth source to use tacacs:
    tmsh modify auth source type tacacs
  6. Save the configuration changes:
    tmsh save sys config
