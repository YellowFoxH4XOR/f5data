Description
Having imported the latest apmclients iso image, you don't see how to make it the default so that it is used instead of the original one.

Environment

  • BIG-IP APM
  • apmclients iso image

Cause
You will not be able to set the new image as the default. The wording can be a little confusing, but the default image is just implying that it was the image that was included with the version of BIG-IP that has been installed. To ensure that the new apmclients image is used follow the recommended actions.
 

Recommended Actions

  1. Import the new apmclients image as described in K52547540
     
  2. You will see that prior to installing the new apmclients image that, the original image (pictured here as 7184 for BIG-IP version 15.1.x) is shown as the default, but also it is shown as the installed image at the top of the display.
     

 

  • After you have imported the new apmclients image, the installed image shown at the top of the display is still the default image.
     

 

  • Select the check box next to the new apmclients image and click Install.
     

 

  • Confirm the installation of the image.
     

 

  • The installed image displayed at the top of the screen changes to 7185, indicating that this is the image that will be used. The original 7184 is still the system default, and being system default does not indicate that this image is the one that will be used.
