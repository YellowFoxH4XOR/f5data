Known Issue

Modifying a system-supplied (default) profile may cause configuration synchronization (ConfigSync) operations to fail.

This issue occurs when the following condition is met:

  • A default profile, which is supplied by the system (such as a Server SSL profile), was modified on the device receiving the synchronization (target device), but not modified on the device initiating the synchronization.

Impact

Administrators cannot synchronize system configurations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H509801 on the Diagnostics > Identified > Medium screen.
  • The system logs a message to the /var/log/ltm file that appears similar to the following example:

    '01020036:3: The requested parent profile (/Common/serverssl) was not found.'

Workaround

To avoid this issue, create a custom profile using the default profile as the parent, and do not modify the default profiles.

To work around this issue, you can manually undo the changes to the default profile on the target device, and then re-attempt the ConfigSync operation from the initiating device. To do so, perform the following actions:

  • On the target device, manually remove the modified profile from the /config/bigip.conf file.

    Note: Removing the modified profile from the /config/bigip.conf file will not remove the default profile.

  • Load the configuration on the target device (for example, using the tmsh load /sys config command).
  • Re-attempt the ConfigSync operation (from the initiating device) and choose the option to overwrite the configuration.
