Description

You want to maintain your F5 system's FIPS device compliance with the National Institute of Standards and Technology, (NIST) or want to ensure that the system's FIPS protected internal hardware security module (HSM) is running the latest firmware version without updating the BIG-IP software.

 

Environment

  • FIPS Upgrade
  • BIG-IP i5820
  • BIG-IP i7820
  • BIG-IP i15820
  • BIG-IP 10350V-F

Cause

None

    Recommended Actions

     

    Prerequisite 

    • Validate version compatibility on the F5 certification page https://www.f5.com/company/certifications.
    • You have command-line access to F5 system.
    • You have root access to the system.
    • You have the FIPS HSM security officer (SO) password.
    • You are running firmware version 1.0-52.

    Upgrade Procedure

    1. Verify the current FIPS firmware version.
      # fipsutil info
    2. Download the n3fips-firmware from my.f5.com > downloads > Hardware Specific > FIPS_firmware_upgrade.
      • n3fips-firmware-upgrade
      • n3fips-firmware-upgrade.md5
      • n3fipsutil
      • n3fipsutil.md5
      • Readme-f5fips-Marvell-1.1-02.txt
      • Readme-f5fips-Marvell-1.1-02.txt.md5
    3. Create a new directory called fw-upgrade in the /shared folder.
      # mkdir /shared/fw-upgrade
    4. Copy the downloaded files to the BIG-IP /shared/fw-upgrade folder.
    5. Check the md5 checksum to verify files were not corrupted in transport.
    6. Change the file permission to executable.
      # ​​​​​​​chmod +x n3fipsutil
      # chmod +x n3fips-firmware-upgrade
    7. ​​​​​​​Backup FIPS keys (Optional).
    8. Upgrade the FIPS firmware you will be required to enter the SO password.
      # ​​​​​​​./n3fips-firmware-upgrade
    9. ​​​​​​​After upgrade has been completed a reboot is required for the update to take effect.
      # ​​​​​​​reboot
    10. ​​​​​​​Verify firmware was successfully upgraded.
      # ​​​​​​​fipsutil info

    Note: Upgrading FIPS firmware will not delete the existing FIPS keys.  Best practice is to create a system backup before making any changes.
