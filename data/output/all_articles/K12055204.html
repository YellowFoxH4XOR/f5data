Known Issue

In rare circumstances, the sod process may produce a core file during a system shutdown.

This issue occurs when the following condition is met:

  • The BIG-IP system is in the process of shutting down.

Note: Because the issue rarely occurs, further conditions are unknown.

Impact

System operation is not affected since the core file is generated during system shutdown.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system generates a sod core file to the /shared/core directory before a system shutdown.
