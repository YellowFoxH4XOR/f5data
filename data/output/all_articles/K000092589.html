K000092589: How to add Post-Rtg Transformation rule or routing rule to solve SDC Error Proxy bit issue

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092589

Description

  • SDC Error Proxy bit 
  • This is fixed by adding a Post-Rtg Transformation rule

Environment

  • SDC 5.1
  • Proxy bit
  • Post-Rtg Transformation 

Cause

By design.

 Recommended Actions

Workaround :

Option 1: Modify the P bit in Routing Rule.

Option 2: Modify P bit in Out transformation Rule


Modify P bit in Out transformation Rule :

1. Goto Flows > Transformation > Post-routing

2. Locate any isRequest match false, which equivalent to matching an answer message.

3. Next, locate any message type that is expected to return a proxy flag set.

4. Append the script in the textbox of the outTR after any existing in script:

def pFlag = incomingMessage.isProxiable();
if (pFlag == false) {
  userTraceLogger.info("===outTR-number p flag before: " + pFlag);
  incomingMessage.setProxiable(true);
  userTraceLogger.info("===outTR-number p flag after set: " + incomingMessage.isProxiable());
}
return incomingMessage;
