K2692: Maximum values for service timeouts

Topic

The maximum value of a service timeout is 4,294,967,295 seconds, which is approximately 49,710 days or 136 years.

Although this value can be set very high, F5 recommends that you set it at the lowest possible value for the given application to avoid an unnecessary connection backlog, which could eventually exhaust BIG-IP resources.

The exact value depends on the requirements for the specific application. For guidance, refer to the documentation provided with the application.
