Description

When a virtual server with an HTTP profile receives unexpected HTTP data, the BIG-IP system logs an error message to the /var/log/ltm file similar to:
 
Dec 29 14:32:51 bigip1 err tmm[11306]: 011f0007:3: http_process_state_ingress_data - Invalid action:0x10b041 clientside (10.10.10.40:35340 -> 10.10.10.101:443) serverside (10.10.10.41:8443 -> 10.10.10.100:52856) (Client side: vip=/Common/<VS_name> profile=http pool=/Common<pool_name> client_ip=10.10.10.40)

As a result, BIG-IP resets connections.

Environment

  • BIG-IP
  • Virtual Server with HTTP profile

Cause

This is a known issue tracked under ID 851857: HTTP 100 Continue handling does not work when it arrives in multiple packets. This happens when a pool member server responds with a header-fragmented packet.
Example, instead of responding with one packet containing "HTTP/1.1 100 Continue\r\n\r\n" the pool member server responds with two packet containing "H" and "TTP/1.1 100 Continue\r\n\r\n"

Recommended Actions

Upgrade to a fixed version: 16.0.0, 15.1.1, 14.1.3.1, 13.1.3.

 

Additional Information

Any response that is not compliant with Internet Engineering Task Force (RFC 7230) causes this error message.
