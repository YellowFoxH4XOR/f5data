Description

When attempting to license a BIG-IP Next instance via BIG-IP Next Central Manager, activation fails and an error is returned:

LICENSING-0011-InvalidToken-TokenExpiredOrInvalid

Environment

  • BIG-IP Next, using Central Manager
  • A new BIG-IP Next instance has been added
  • A new JWT has been added to license the BIG-IP Next instance
  • <other environmental causes are still TBD>

Cause

Root cause has not yet been determined but possible causes include

  1. Central Manager is unable to reach the Internet
  2. Central Manager is configured to go through a proxy server
  3. A reused or expired BIG-IP Next Trial License JWT is being used
  4. A DNS issue may be preventing the licensing subsystem from looking up product.apis.f5.com

Recommended Actions

All known root cause(s) of this issue have not yet been determined.

From Central Manager:
  1. Ensure that it can reach product.apis.f5.com. (try pinging product.apis.f5.com)
  2. Confirm that the system does not need to go through a proxy server when it connects to the Internet
F5 Support may ask you to gather a qkview from Central Manager.   For instructions on gathering a qkview from Central Manager, see https://clouddocs.f5.com/bigip-next/latest/support/cm_qkview_script.html

It is important that the qkview be gathered right after the license event has failed, so that the relevant log messages are captured in the qkview.

F5 Support may also ask you to gather the log output of the local license manager container on Central Manager while the license event is occurring.  You may be asked to run a command similar to the following, and then copy the log output and provide it to F5 via the case. 
kubectl logs -f deploy/mbiq-llm -c mbiq-llm
