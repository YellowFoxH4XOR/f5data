Description

  • You have many APM sessions in progress (blue)
  • In the apm log you see Per IP in-progress sessions limit (xx) exceeded for :  <IP>

Environment

  • APM behind a load balancer.

Cause
The upstream load balancer is configured to perform a health check on the APM Virtual Server by initiating a  https connection. This starts an APM session.

Recommended Actions

  1. Change the load balancer configuration to use a different monitor.
  2. Mitigate by reducing the Access Policy Timeout  from the default 300 seconds. 120 seconds is a suggested start. Users must complete their login in this time.

Additional Information
Load balancing an APM Virtual Server requires special consideration.
