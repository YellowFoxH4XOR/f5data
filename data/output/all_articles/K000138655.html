K000138655: Edge Client stuck in Disconnecting while using BIG-IP as SP and Azure IdP

Type
Support Solution
Published
2024-02-19
Updated
2024-02-19
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000138655

Description

You are using BIG-IP as SP and Azure IdP. When you connect everything is fine.

If you use the disconnect button and auto-connect button it works fine.

But if you hit the max session timeout and reconnect, its after that you see the Edge Client stuck in disconnecting and unable to disconnect from the server.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client version 7.2.4.5 and earlier
  • Disconnections
  • Windows
  • Azure IdP

Cause

This is due to the bug ID 1475137 Edge client stuck in Disconnecting while using BIG-IP as SP and Azure IdP

Recommended Actions

Update BIG-IP APM Edge Client to version 7.2.4.6

Additional Information

Similar Bug ID 1041613: Edge Client stuck while disconnecting when Azure AD is configured for IdP
