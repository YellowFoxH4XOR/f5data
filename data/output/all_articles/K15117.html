Known Issue

Web applications may become unresponsive when using BIG-IP APM Portal Access.

This issue occurs when all of the following conditions are met:

  • You use a browser other than Internet Explorer to access portal resources.
  • The resource application alters the window.XMLHttpRequest JavaScript object that the BIG-IP APM system set.

In some cases, the portal resource web application logic can overwrite the XMLHttpRequest object that the BIG-IP APM system set. This occurrence can alter the functionality of the HTTP cookies that the system uses to maintain portal access. As a result, browsers become unresponsive when accessing portal resources.

Impact

The web application hangs and the portal resource becomes inaccessible.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H453733 on the Diagnostics > Identified > High screen.
  • HTTP cookies associated with BIG-IP APM Portal Access are altered or non-functional.
  • Clients using browsers other than Internet Explorer experience unresponsiveness, while Internet Explorer users are unaffected.
  • Users may view messages associated with the session in the /var/log/apm file that appear similar to the following example:

    notice tmm2[29864]: 01490502:5: 63aee19f: Session deleted due to user inactivity or errors.
