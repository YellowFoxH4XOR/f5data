Known Issue

Using the libtar utility with files larger than 2 GB creates an unusable tarball.

This issue occurs when all of the following conditions are met:

  • The file you collected using the libtar utility (for example, by qkview or another program dynamically linking with /usr/lib/libtar-1.2.11) is greater than 2 GB.
  • A 2 GB or larger file exists in a directory that the qkview utility normally collects.

The qkview utility uses the libtar utility to create the qkview output in a single, compressed tar archive (or tarball) format. In the affected BIG-IP software versions, the libtar utility cannot process files that are larger than 2 GB.

Impact

The system does not create a QKView diagnostics file. Although you can extract the QKView tarball using /usr/bin/libtar, the file is a zero-length file. You cannot submit a QKView to iHealth for analysis. Other applications using libtar produce invalid .tar files.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Programs such as QKView create a .tar file (tarball) using the libtar utility. If any of the files collected are greater than 2 GB, then /bin/tar cannot read the output .tar file.
  • The system cannot collect files larger than 2 GB in a Qkview because of a limitation of the file compression library employed by the qkview command.
  • The qkview command may generate output that iHealth cannot parse, and that the tar command cannot extract.

Workaround

To work around this issue, before you run the qkview utility, or another program that uses the libtar utility, remove the file that is larger than 2 GB from the system. If you are required to submit the QKView to F5 Support, you may work with the assigned Support Engineer to see if the files are required for troubleshooting and submit the file as instructed.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
