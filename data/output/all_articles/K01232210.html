K01232210: iRule LB::down command can cause MCPD to ignore pool monitor status

Type
Support Solution
Published
2023-12-06
Updated
2023-12-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.0, 15.1.0, 16.1.1, 14.1.4, 14.1.3, 14.1.2, 14.1.5, 14.1.0, 15.1.4, 15.1.3, 15.1.2, 15.1.1
Source
https://my.f5.com/manage/s/article/K01232210

Description

Using LB::down iRule can cause MCPD to ignore the status of pool member monitor status which lead to pool being down and reported as up. In this situation MCPD will not be able to know the status of the pool member and can cause traffic disruption.

Environment

  • BIG-IP LTM
  • One or more pool members configured
  • iRule with LB::down command which forces the pool member to go down

Cause

This issue is caused by ID910213.

Recommended Actions

Upgrade to fixed version.

Additional Information

None
