Description
Configuring a UDP virtual server with Address Translation disabled, with Source Port set to Change in conjunction with a UDP profile with Idle Timeout set to 0 (zero) causes the UDP source port to be set to 0 (zero) when processing traffic.
Note: The combination of features does not create a logical configuration for processing traffic.

Environment

  • BIG-IP LTM
  • UPD profile > Idle Timeout 0
  • Virtual sever > Address Translation > Disabled
  • Virtual server > Source Port > Change

Cause
Unknown

Recommended Actions

Change one of the following

  • Set the virtual server Source Port configuration to "preserve" or "preserve-strict".
  • Set the UDP profile Idle Timeout to value greater than 0 (zero)..
