Description

For ASM brute force protection, the system tracks the number of failed login attempts for the configured login page over a detection period. If credential stuffing attack detection is enabled, the system tracks the number of login attempts that match known leaked credentials dictionary. When the configured threshold for either or both is exceeded, the system applies the configured enforcement action until either attack stops or the maximum prevention duration has passed. You should consider the recommendation on this article to avoid ASM blocking all login attempts.

 

Environment

ASM security policy has the following settings:

  • Enforcement Mode is to Blocking.
  • Brute Force Attack Prevention is configured with a login page.
  • The block flag on the violation Brute Force: Maximum login attempts are exceeded is enabled.

 

Cause

If the login URL failed to meet ASM JavaScript qualification criteria and a distributed/Credentials brute force attack started or a user exceeds the configured failed login attempts threshold during the detection period. ASM will follow the enforcement settings for the violation Brute Force: Maximum login attempts are exceeded. in this case, since the blocking flag is enabled. ASM will block all users due to it cannot inject a JavaScript. 

 

Recommended Actions

  • To make sure that ASM doesn't block users whether they were challenged by ASM JavaScript or not, disable (uncheck) the block flag on the violation Brute Force: Maximum login attempts are exceeded. 
  • Consider the following command to manually set the login URL as a qualified URL, specify the URL(s) in global system DB key asm.cs_qualified_urls.
    For multiple URLs, separate them using a comma, for example:
    tmsh modify sys db asm.cs_qualified_urls value /my/page.html,/my/logon*

 

To reset the variable asm.cs_qualified_urls to default, refer to the following steps.

  1. Log in to the BIG-IP via CLI
  2. Run the following command from the BASH:
    tmsh modify sys db asm.cs_qualified_urls reset-to-default

 

Additional Information

  • ASM admin can see if a URL is not qualified in local and remote log if alarm is set when challenge is sent.
  • The limit of 20 URL in DOS and 10 in ASM applies only for manually configured qualified URLs.
