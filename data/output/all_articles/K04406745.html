K04406745: Managed device unavailable SNMP traps on BIG-IQ

Type
Support Solution
Published
2022-10-12
Updated
2025-01-09
Applies to
  • BIG-IQ
  • Virtual Editions
  • BIG-IQ Centralized Management: 8.0.0, 8.1.0, 8.0.X, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X
Source
https://my.f5.com/manage/s/article/K04406745

Description
You would like to find out if BIG-IQ send SNMP traps when a managed BIG-IP is unavailable or available

Environment

  • BIG-IQ 8.x
  • BIG-IP 13.x
  • SNMP traps

Cause
None

Recommended Actions

  1. Check under Monitoring > Click Settings button and scroll down below

    Condition                       SNMP Event      Enabled

    Managed Device Available    Yes        N/A
    Managed Device Unavailable    Yes        N/A
     
  2. Check command line for SNMP string name

    Example command:
    [root@CM-BIG-IQ:Active:Standalone] mibs # cat F5-BIGIQ-MIB.txt | grep -A 15 -B 10  bigiqManagedDevice

    Example output:
    bigiqManagedDeviceAvailable             NOTIFICATION-TYPE
           OBJECTS {
                    bigiqDeviceAlertObjMsg
            }
           STATUS      current
           DESCRIPTION
                  "BIG-IQ Managed Device Available"
           ::= { bigiqDeviceAlerts 4 }

    bigiqManagedDeviceUnavailable             NOTIFICATION-TYPE
           OBJECTS {
                    bigiqDeviceAlertObjMsg
            }
           STATUS      current
           DESCRIPTION
                  "BIG-IQ Managed Device Unavailable"
     
  3. Once you have the string, you can check for OID numeric value.

    Example:
    [root@CM-BIG-IQ:Active:Standalone] mibs # snmptranslate -On F5-BIGIQ-MIB::bigiqPeerDeviceUnavailable
    .1.3.6.1.4.1.3375.20.1.0.3
    [root@CM-BIG-IQ:Active:Standalone] mibs # snmptranslate -On F5-BIGIQ-MIB::bigiqPeerDeviceAvailable
    .1.3.6.1.4.1.3375.20.1.0.2
    [root@CM-BIG-IQ:Active:Standalone] mibs # snmptranslate -On F5-BIGIQ-MIB::bigiqManagedDeviceAvailable
    .1.3.6.1.4.1.3375.20.1.0.4
    [root@CM-BIG-IQ:Active:Standalone] mibs # snmptranslate -On F5-BIGIQ-MIB::bigiqManagedDeviceUnavailable
    .1.3.6.1.4.1.3375.20.1.0.5
     
  4. Create your custom SNMP Traps using K3727.
