Description

  • When navigating to Monitoring > Reports > Security > Web Application Security > Reporting in BIG-IQ the browser fails to load.
  • You are unable to run ASM reports on BIG-IQ

Environment

  • BIG-IQ v7.0 GUI

Cause
ID761873 Monitoring -> REPORTS -> Security -> Web Application Security is obsolete and should be removed

Recommended Actions

Go to: Monitoring -> DASHBOARD -> Web Application Security
