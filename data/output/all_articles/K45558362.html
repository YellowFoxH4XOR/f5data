Known Issue

The BIG-IP APM rewrite profile may incorrectly process JavaScript call() and apply() methods.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The JavaScript code in the HTML page uses the call() or apply() methods to invoke a function.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Adobe Flash web application may malfunction with Flash Patching enabled on the access policy.
  • When using portal access, requested pages that use the call() or apply() methods fail to render properly on web browsers.
