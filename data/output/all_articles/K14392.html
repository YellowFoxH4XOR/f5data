Topic

You should consider using this procedure under the following conditions:

  • You want to configure the VIPRION cluster member IP address.
  • You want to configure unicast full mesh or multicast failover on redundant VIPRION systems.

Description

Using the multicast failover or unicast full mesh failover feature on VIPRION platforms requires you to configure valid cluster member IP addresses for all slots on each redundant VIPRION system.

If you plan to configure multicast failover or unicast full mesh failover on redundant VIPRION systems, you must define a valid cluster member IP address for each slot on each of the redundant VIPRION systems.

Important: Failure to configure the cluster member IP address on all slots may result in failover daemon (sod) communication issues.

Note: The information in this article also applies to Virtual Clustered Multiprocessing (vCMP) guests which span multiple blades.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the VIPRION systems.

Procedures

To configure cluster member IP addresses on each slot on the VIPRION system, and then verify that the cluster members are marked Available - Enabled (Green), perform the following procedures:

Configuring the Cluster Member IP address using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Clusters.
  3. Click Management IP Address.
  4. In the Management IP Address section, configure the cluster's floating management IP address.
  5. In the Cluster Member IP Address section, configure the management IP address for each slot.
  6. Click Update.
  7. To verify the status of each slot, click Properties near the top of the page.
  8. Under Status, verify that each slot status is Green.

Configure the Cluster Member IP addresses using the TMOS Shell

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To configure the cluster's floating management IP address, use the following command syntax:

    modify sys cluster default address <IP address>/<Subnet mask>

    For example, to configure the cluster floating management IP address 192.168.10.1/24, type the following command:

    modify sys cluster default address 192.168.10.1/24

  3. To configure the management IP address for each slot, use the following command syntax:

    modify sys cluster default members { <slot number> { address <IP address> } }

    For example, to configure management IP addresses 192.168.10.2 and 192.168.10.3 for slots 1 and 2 respectively, type the following command:

    modify sys cluster default members { 1 { address 192.168.10.2 } 2 { address 192.168.10.3 }}

  4. To save the configuration, type the following command:

    save sys config

  5. To verify the status of each slot, type the following command:

    show sys cluster all-properties

    Ensure each slot ID status is available and enabled:
