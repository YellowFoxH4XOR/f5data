Topic

This article applies to BIG-IP 9.0.0 through 9.1.3. For information about other versions, refer to the following articles:

  • K13539: Disabling the watchdog process to perform a core dump (11.x - 12.x)
  • K9308: Disabling the watchdog process to perform a core dump (9.3.x - 10.x)

The watchdog process ensures that the BIG-IP system will reboot in the event of a system lock-up, prompting a failover. To allow a core dump to complete, you must disable the watchdog process.

Important: Always enable the watchdog feature once the core dump has completed.

Disabling watchdog

Type the following command:

bigpipe daemon overdog watchdog disable

Enabling watchdog

Type the following command:

bigpipe daemon overdog watchdog enable
