K80708148: BIG-IQ is not able to add BIG-IP devices when BIG-IP ''admin'' account is disabled

Type
Support Solution
Published
2019-10-16
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K80708148

Description

You will need to use an "admin" account with administrator role to add a BIG-IP device to a BIG-IQ.
If you use another administrator account other than "admin" to add a BIG-IP device to a BIG-IQ, you will be prompted with an "unauthorized" error.

Environment

This applies to all BIG-IQ versions and BIG-IP versions.

Cause

Not applicable.

Recommended Actions

Do not delete the "admin" account from the BIG-IP as this will impact adding the BIG-IP device to the BIG-IQ.
To help secure the "admin" account further, you can change the Terminal Access of the "admin" account to disable.

  • To do this, please navigate to System > Users > User List > admin
