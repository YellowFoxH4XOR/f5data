Description

Executing 'tmsh show sys mcp-state' shows Last Configuration Load Status as 'config-load-in-progress' though config has successfully loaded. 

You see output similar to below

-------------------------------------------------------
Sys::mcpd State:
-------------------------------------------------------
Running Phase                   running
Last Configuration Load Status  config-load-in-progress
End Platform ID Received        true
 

Environment

Before running 'tmsh show sys mcp-state' one must have executed  'tmsh load sys config verify' 

Cause

Bug ID  1352445

Recommended Actions

The MCPD state of 'Last Configuration Load Status' as 'config-load-in-progress' is cosmetic only.

To clear 'config-load-in-progress'  execute below command.

tmsh load sys config

Important : Reloading config may interrupt the traffic you may prefer to run during maintenance window
