Description

After upgrading to 17.1.0.x SSH connections to BIG-IP with Windows Putty program fail with error "Server unexpectedly closed network connection".  This could also affect any other type of SSH program that by default only uses rsa-sha.

 

Environment

BIG-IP 17.1.0.x

Putty for Windows or SSH programs using rsa-sha

Cause

This issue is caused by Bug ID 1238693: Adding SSHD support for rsa-sha2-256 and rsa-sha2-512 HostKeyAlgorithms and removing support for ed25519

Recommended Actions

You need to upgrade your version of Putty to the latest version, or configure your SSH program to use rsa-sha2 or another algorithm

Additional Information

Since we no longer support rsa-sha the BIG-IP will reset the SSH connection, here is what the behavior looks like in a packet capture:

 

using putty 0.60 -> 17.1.0

client key exchange init

server_host_key_algorithms string: ssh-rsa,ssh-dss

server key exchange init

server_host_key_algorithms string: ssh-rsa,rsa-sha2-512,rsa-sha2-256,ecdsa-sha2-nistp256,ssh-ed25519

success

--------------------------------------------------

using putty 0.60 -> 17.1.0.3

client key exchange init

server_host_key_algorithms string: ssh-rsa,ssh-dss

server key exchange init

server_host_key_algorithms string: rsa-sha2-512,rsa-sha2-256,ecdsa-sha2-nistp256,ssh-ed25519 <-----ssh-rsa is not advertised

failure, connection is reset
