K000147773: Is it possible to over-provision vk8s CPU in a Mesh Site?

What Happened?

You created a Mesh Site and saw that you still have CPU Resources available so you want to spin more containers on that Site.

Environment

  • F5® Distributed Cloud
  • Mesh Sites

Answer

It's not possible.

A Mesh site is designed for networking, not compute. It will allocate all the resources to that created site machines. Mesh sites are not meant to run large amounts of compute workloads.

If you want to run more workloads, switch to an AppStack site.
