Description:

You are attempting to use both local and remote RADIUS authentication at the same time for administrative users. However, it is not possible to use them concurrently. You need a solution that allows you to use both authentication methods and provides a backup authentication method in case the remote RADIUS authentication becomes unavailable.

 

Environment:

  • BIG-IP Configuration Utility
  • Local and remote RADIUS authentication

Cause:

It is not possible to use local and remote RADIUS authentication concurrently for administrative users.

 

Recommended Actions:

To use both local and remote RADIUS authentication simultaneously with fallback authentication, follow these steps:

 

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to 'System' > 'Users' > 'Authentication.'
  3. In the 'Authentication' tab, select 'Remote - RADIUS' as the primary authentication method.
  4. Check the box for 'Enable Fallback to Local Authentication' to enable the fallback feature.
  5. Click 'Update' to save the changes.

By following these steps, your BIG-IP system will first attempt remote RADIUS authentication for administrative users. If it fails or is unavailable, the system will then automatically attempt local authentication. This configuration ensures that you have a secure and reliable authentication system in place.
