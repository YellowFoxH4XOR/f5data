Description

If you need to deactivate a BIG-IP Next instance for any reason, you can perform this from BIG-IP Central Manager.

Environment

  • BIG-IP Next
  • The BIG-IP Next instance license was activated via Central Manager
  • You wish to deactivate the license for the BIG-IP Next instance so you do not get charged for it

Cause

Deactivation can be done via Central Manager.  This is performed automatically if the BIG-IP Next instance is deleted in Central Manager.

Recommended Actions

In Central Manager, go to the My Instances screen


Click on the name of the instance that you wish to deactivate.  A drawer will slide in from the right side of the page.  (1) Click the License and (2) click Deactivate License, and confirm when prompted.

The final state will be that the license is deactivated for that instance.

Additional Information

You can re-activate a BIG-IP Next instance that was already activated.  Follow the procedure at How to: Manage BIG-IP Next instance licenses
