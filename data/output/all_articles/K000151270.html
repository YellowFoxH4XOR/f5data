Description

The BIG-IP VE is currently operating on version 16.x.x with a V16 license. You are planning to upgrade to version 17.x.x, which necessitates a V18 license. To ensure a smooth transition, you need to be aware of any known issues with the upgrade path and any special steps required for the upgrade to version 17.x.x.

Environment

  • BIG-IP LTM VE
  • Product: BIG-IP VE SKU F5-BIG-xxx-xxx-V16
  • Upgrade BIG-IP VE from v16.x.x to v17.x.x

Cause

None

Recommended Actions

The following steps should be followed:

1- Choose a version to upgrade. F5 always suggests using the last maintenance release.

K13845: Overview of supported BIG-IP upgrade paths and an upgrade planning reference

2- Once the version is decided, check the upgrade path.

K70841910: Which version of BIG-IP should I choose for my next upgrade?​​​​​​​ 

3- Check the activation date and compare it with the content K7727; the matrix shows the date and which version is supported.

K7727: License activation may be required before a software upgrade for BIG-IP

4- Check the videos, analyze them, and perform.

K41125752: Guided video demonstrations and free training for upgrading BIG-IP software

Additional Information

If you need to upgrade the V16 license to a V18, please contact your F5 sales Account Manager.
