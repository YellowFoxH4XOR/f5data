Description

A forwarding IP VS not forwarding 3WHS (3 Ways Hand-Shake) packets to the VS, while it set with tcp forwarding profile.

The traffic flow, can be seen with a packet capture trace :

2    2021-05-21 07:55:33.587275    10.10.0.156    10.10.10.1    TCP    162    IN  s1/tmm13: [SYN]  
3    2021-05-21 07:55:33.587281    10.10.10.1    10.10.0.156    TCP    146    OUT s1/tmm13: [SYN, ACK]
4    2021-05-21 07:55:33.603827    10.10.0.156    10.10.10.1    TCP    142    IN  s1/tmm13: [ACK] 
5    2021-05-21 07:55:33.604442    10.10.0.156    10.10.10.1    TCP    172    OUT s1/tmm13: [TCP Retransmission] [SYN] /Common/vs_FW_VS    

Packet# 2-4:   3 Ways Handshake in front of the Big-IP instead of VS.
Packet#5:       The VS attached after 3WH, which is not suppose to happen.

Environment

  • VS using forwarding profile for tcp connections
  • ltm profile fastl4 is used with the following option:
    • syn-cookie-enable disable

Cause

This points to SYN Cookie being activated, but not deactivated, at that time - as it can be seen with the following command's output:

This is an expected behavior, when SYN Cookie is activated BIG-IP needs to handle TCP 3WHS in order to detect attackers.

Recommended Actions

Configuring global hardware VLAN SYN cookie protection settings.

By default, the global hardware VLAN-based SYN cookie setting is enabled on the BIG-IP system.
Important: The following actions will disable global SYN cookie protection.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

In case using supported Hardware platforms:

To make sure this setting is enabled on your BIG-IP system, perform the following procedure:

  1. Log in to the Configuration utility
  2. Navigate to System > Configuration > Local Traffic > General
  3. To enable Hardware VLAN SYN Cookie Protection settings, select the check box
  4. Click the Update
  5. tmsh modify sys db pvasyncookies.enabled value true
To disable global hardware SYN cookie protection:
  1. Log in to the Configuration utility
  2. Navigate to System > Configuration > Local Traffic > General
  3. To  disable Hardware VLAN SYN Cookie Protection settings, de-select the check box
  4. Click the Update
  5. tmsh modify sys db pvasyncookies.enabled value false
Note: changes to sys db pvasyncookies.enabled setting do not take effect until after a reboot

In case using Virtual Machine:

  • VLAN SYN Cookie is a Hardware only feature, it only works for Hardware platforms.  So, in cases it is not Hardware platform supported, to fix the issue you will need to disable HW SYN Cookie manually.

  • Use following msh command to set it to 'false':

    tmsh modify sys db pvasyncookies.enabled value false
