Known Issue

This is the result of a known issue. When a BIG-IP 1600, 3600, 3900, 6900, 8900, or VIPRION system initializes and goes active, the system sends a trap to indicate that the unit is going active. This behavior causes an informational message that appears similar to the following example to display on the LCD panel:

unit is going Active.

When this behavior occurs, the system treats the informational message as a warning and illuminates the yellow Alarm LED approximately 60 seconds after the system has completed initializing. The alarm LED remains illuminated until it is cleared.

F5 Product Development tracked this issue as CR118217 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, or WOM release notes.

Workaround

You can work around this issue and clear the LCD and the Alarm LED by entering the following command at the BIG-IP command line:

lcdwarn -c 0 0

Alternatively, you can work around this issue and clear the LCD and Alarm LED by pressing the Check key twice on the LCD panel.
