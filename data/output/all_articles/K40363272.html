Topic

You should consider using this procedure under the following conditions:

  • You want to review the reboot history of your BIG-IP system.
  • You want to understand the software volume in which the BIG-IP system was booted at a specific time.
  • You want to find out what BIG-IP software version was installed during a particular reboot.

Description

BIG-IP log files include important diagnostic information about the events that occur on the BIG-IP system. Some of these events pertain to a BIG-IP system boot.

In some of the log files you can view information such as when the BIG-IP system was rebooted, power-cycled, or booted into a different software volume.

The following table includes some relevant log files.

Log FilePurpose
/var/log/liveinstall.logHistory of the software  installation 
/var/log/mysql.outStatus of sqld start/stop 
/var/log/tmm.startHistoric record of the tmm daemon

Prerequisites

You must meet the following prerequisite before using this procedure:

  • Have access to the Advanced Shell (bash).

Procedures

Viewing the boot history of the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to bash.
  2. To view the end of the live install log file, type the following command:

    # tail /var/log/liveinstall.log

    For example: 

    [root@BIGIP1:Active:Standalone] # tail /var/log/liveinstall.log
    2017-10-10T10:16:43+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.0 Build 0.0.1434 ]===---
    2017-10-31T15:18:01+05:30 BIGIP1 notice boot_marker : ---===[ HD1.3 - BIG-IP 13.0.0 Build 0.0.1645 ]===---
    2017-10-31T15:42:13+05:30 BIGIP1 notice boot_marker : ---===[ HD1.3 - BIG-IP 13.0.0 Build 0.0.1645 ]===---
    2017-10-31T15:44:49+05:30 BIGIP1 notice boot_marker : ---===[ HD1.3 - BIG-IP 13.0.0 Build 0.0.1645 ]===---
    2017-10-31T16:05:17+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.0 Build 0.0.1434 ]===---
    2017-10-31T17:01:47+05:30 BIGIP1 notice boot_marker : ---===[ HD1.3 - BIG-IP 13.0.0 Build 0.0.1645 ]===---

  3. To view all of the BIG-IP boot markers, type the following command:

    # grep boot_marker /var/log/mysql.out 

    For example:

    [root@BIGIP1:Active:Standalone] tmp # more /var/log/mysql.out | grep boot_marker
    2016-12-10T09:59:11+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 11.6.0 Build 0.0.401 ]===---
    2016-12-10T11:44:46+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 11.6.0 Build 0.0.401 ]===---
    2016-12-10T11:48:59+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 11.6.0 Build 0.0.401 ]===---
    2016-12-10T14:16:05+05:30 localhost notice boot_marker : ---===[ HD1.3 - BIG-IP 11.6.0 Build 0.0.401 ]===---
    2016-12-13T12:05:08+05:30 localhost notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.0 Build 0.0.1434 ]===---
    2016-12-14T16:09:03+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.0 Build 0.0.1434 ]===---
    2016-12-14T16:15:11+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.0 Build 0.0.1434 ]===---
    2017-01-02T15:04:12+05:30 BIGIP1 notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.0 Build 0.0.1434 ]===---

  4. To view when the Traffic Management Microkernel (TMM) daemon started, type the following command:

    # grep boot_marker /var/log/tmm.start

    For example:

    [root@BIGIP1:Active:Standalone] tmp # more /var/log/tmm.start | grep boot
