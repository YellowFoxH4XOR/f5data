Known Issue

Under rare conditions, the system may not apply the client proxy settings in a Network Access resource.

This issue occurs when all of the following conditions are met:

  • The client proxy settings are specified in the Network Access resource.
  • The Edge Client is running on a Windows 7 system with Internet Explorer 10 installed.

Impact

The system does not apply the client proxy settings from the Network Access resource.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to connect to the BIG-IP APM system using the configured proxy address.
  • The configured proxy settings are not applied to the client system.
