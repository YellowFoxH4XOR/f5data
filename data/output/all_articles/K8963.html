K8963: SIP information within a Via header is not processed correctly when separated by a comma

Known Issue

This is the result of a known issue. SIP Information transmitted through a Via header is not parsed correctly when the information is separated by a comma.

As a result, the BIG-IP system may erroneously remove Via headers. This behavior occurs when the BIG-IP attempts to remove any SIP information it has inserted for traffic handling purposes, before sending the servers response to the client.

F5 Networks Product Development tracked this issue as CR99815 and it was fixed in BIG-IP LTM version 9.4.6. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5, for the BIG-IP 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
