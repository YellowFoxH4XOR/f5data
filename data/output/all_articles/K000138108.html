K000138108: F5OS-A software upgrade fails with "illegal reference"

Type
Support Solution
Published
2024-01-02
Updated
2024-01-02
Source
https://my.f5.com/manage/s/article/K000138108

Description

When performing a software upgrade on an F5OS appliance, the web UI reports "illegal reference" and the upgrade cannot continue.


The sw-upgrade.log logfile may contain repeating entries like this:


<timestamp> exit 1

upgrade-service killed

<timestamp> echo 'upgrade-service killed'

<timestamp> killed

<timestamp> /confd/bin/upgrade-service

<timestamp> wait

<timestamp> '[' 1 ']'

Starting upgrade-service

<timestamp> echo Starting upgrade-service

<timestamp> echo -n 1.3.0-8327

<timestamp> mkdir -p /mnt/var/confd-backup

<timestamp> ln -sf /mnt/etc/PLATFORM /etc/PLATFORM

<timestamp> ln -sf /mnt/etc/sysconfig/chassis_network_active.txt /etc/sysconfig

<timestamp> trap killed SIGTERM SIGINT

<timestamp> program=upgrade-service

Started upgrade-service ver 1.3.0-8327 container at <timestamp>

<timestamp> echo Started upgrade-service ver 1.3.0-8327 container at <timestamp>

<timestamp> date +%Y-%m-%dT%H:%M:%S.%6N%:z

<timestamp> exec


The messages logfile will contain entries like this:


Nov 29 00:00:00 appliance-1 journal: DEBUG item does not exist - /oc-sys:system/f5-system-image:image/config/install-iso-version does not exist

Nov 29 00:00:00 appliance-1 journal: DEBUG item does not exist - /oc-sys:system/f5-system-image:image/config/install-service-version does not exist

Nov 29 00:00:00 appliance-1 journal: DEBUG item does not exist - /oc-sys:system/f5-system-image:image/config/install-os-version does not exist


Environment

F5OS Appliance.


Cause

Commonly this is caused by one of the required software images being force deleted.


When upgrading, in addition to the new software image, it is necessary to also have the running software image (iso) on the system as well.



Recommended Actions

  1. Identify the missing software image by noting the cited log messages.
  2. Upload any missing software image.
  3. Attempt the install again.
