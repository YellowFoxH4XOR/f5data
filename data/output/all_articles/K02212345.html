Topic

You should consider using this procedure under the following condition:

  • You want to configure a BIG-IP ASM security policy to track user sessions.

Description

You can enable session tracking for a BIG-IP ASM security policy. You can use session tracking to track information about user sessions, device IDs, and IP addresses that attempt to access the application. To perform tracking, you enable the session awareness feature and specify how the system tracks application user names. You can also configure the system to track violations and perform actions based on the number of violations for a user, session, or IP address. When you configure violation detection actions, the system logs or blocks the activity of suspicious users, sessions, or IP addresses that caused violations.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have access to the Configuration utility.

Procedures

  • Configure user session tracking
  • View session tracking status

Configure user session tracking

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to the Session Tracking page:
    • BIG-IP 16.x and later: Go to Security > Application Security > Session Tracking
    • BIG-IP 13.x - 15.x: Go to Security > Application Security > Sessions and Logins > Session Tracking.
  3. Select the policy you want to modify:
    • BIG-IP 16.x and later: Select the policy name from the drop down menu at the top of the page
    • BIG-IP 13.x - 15.x: For Current edited security policy, select the name of the policy you want to modify.
  4. For Session Awareness, select the Enabled check box.
  5. For Application Username, select Use All Login Pages to track login sessions for all of the login pages in the security policy.
  6. For Track Violations and Perform Actions, select the Enabled check box.
  7. For Violation Detection Period, enter the number of seconds that indicates the sliding time period to count violations for violation thresholds.
  8. On the Block All, Log All Requests, and Delay Blocking tabs, configure the settings as appropriate for your policy or keep the default values.
  9. Select Save.
  10. Select Apply Policy to put the changes into effect.

View session tracking status

From the Reporting page, you can view and manage user sessions and IP addresses which the system is currently tracking. To do so, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Reporting > Application > Session Tracking Status.
  3. For Current edited security policy, select the name of the policy you want to modify.
  4. For Action, select Block all, Log All Requests, or Delay Blocking as appropriate to filter data.
  5. For Scope, select Username, Session, IP address, or Device ID as appropriate to filter data.
  6. To filter the information by value, for Value, enter the username, session identification number, IP address, device ID, or string.
  7. Select Go.
