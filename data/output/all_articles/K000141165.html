Description

You would like to determine the amount of free space available for VCMP guests on the VCMP host

Environment

BIG-IP 
VCMP
Viprion

Cause

Expected behavior

Recommended Actions

On a bladed Viprion VCMP host, VCMP guest image files are stored in /shared/vmdisks on each blade/slot.  You can use the clsh utility and the df and ls commands to view the used / available space on all slots, for example:

[root@VIP2400-R18-S10:/S1-green-P::Active:Standalone] vmdisks # clsh df -h /shared/vmdisks

On non-bladed VCMP hosts, VCMP guest images are stored in /appdata/mprov/global/vmdisks, for example:

[root@I7800-R20-S37:LICENSE EXPIRES IN 1 DAYS:Active:Standalone] config # df -h /appdata/mprov/global/vmdisks
Filesystem                           Size  Used Avail Use% Mounted on
/dev/mapper/vg--db--sda-dat.appdata  337G   39G  281G  13% /appdata

[root@I7800-R20-S37:LICENSE EXPIRES IN 1 DAYS:Active:Standalone] config # ls -halt /appdata/mprov/global/vmdisks

-rw-r--r--. 1 root root 150G Sep 24 14:41 guest01.img
-rw-r--r--. 1 root root   23 Sep  6 08:34 guest01.info

Additional Information

K24156414: Increasing the disk space for a BIG-IP vCMP guest

If you would like to increase the image size for a multi-bladed Viprion VCMP guest you can use the clsh utility for example:

[root@VIP2400-R18-S10:/S1-green-P::Active:Standalone] vmdisks # clsh qemu-img resize /shared/vmdisks/vcmpguest01.img +50G
=== slot 2 addr 127.3.0.2 color green ===

=== slot 4 addr 127.3.0.4 color green ===

=== slot 1 addr 127.3.0.1 color green ===
