K000149583: Memory leak on systemd-journald on BIG-IQ

Type
Support Solution
Published
2025-01-31
Updated
2026-08-02
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.3.0
Source
https://my.f5.com/manage/s/article/K000149583

Description

You notice that the memory usage of systemd-journald process is growing on BIG-IQ.

Environment

  • High Memory
  • Memory Leak
  • systemd-journald
  • Restart Services
  • CLI

Cause

F5 filed this issue as ID 887637-5.

Recommended Actions

  • Upgrade BIG-IQ to 8.4.1 (BIG-IQ Centralized Management 8.4.1 :: Fixes and Known Issues | BIG-IP Documentation).
  • To temporarily address the resource exhaustion issue, run below command in CLI (bash mode, not in tmos shell) or reboot the BIG-IQ:
    Important: This should not cause failover or disrupt processing traffic, however it is recommended to run in the maintenance window.
    Note: Memory leak pace will be different by each unit, so you may want to place this in scheduled job in crontab.
    # systemctl restart systemd-journald

Additional Information

None
