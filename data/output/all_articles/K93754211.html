Description
This article details how to configure an Access Policy to use a Windows Registry Check to verify a Windows PC is a domain member.

Environment

  • Windows PC.
  • Access Policy Manager (APM)
  • Access Policy
  • Virtual Policy Editor (VPE).
  • Windows Registry Check object.

Cause
You want to to use a Client Side check to determine is a Windows PC is joined to a domain.

Recommended Actions

  1.  Login to the Big-IP Configuration Utility.
  2. Navigate Access>Profiles/Policies>Access Profiles (Per-Session Policies).
  3. Click on Edit under the Per-Session Policy column for the selected Access Policy.
  4. Click on the plus sign (+) in the VPE.
  5. Select the Endpoint Security (Client-Side) tab.
  6. Select the Windows Registry object and click Add Item.
  7. In the Expression field add the following entry syntax:
    "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters"."Domain"="example.F5.com"
  8. Click Save.
