Known Issue

You may receive an error message when you use the Configuration utility to update an iRule Data Group.

This issue occurs when all of the following conditions are met:

  • The configuration contains an iRule Data Group of the String or Integer type, which has at least one record without a value.
  • You attempt to add a new record to the affected data group by using the Local Traffic > iRules > Data Group List page in the Configuration utility.

Impact

You are unable to add a new record to the affected data group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H427852 on the Diagnostics > Identified > Low screen.
  • When you attempt to add a new record to the affected data group, you receive an error message that appears similar to the following example:

    General database error

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to update the affected data group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To add a new record to the affected data group, use the following command syntax:

    modify /ltm data-group internal <Data-Group-Name> records add { <New-Record-String/Integer> { data <New-Record-Value> } }

    Note: This command syntax is applicable to a String or Integer type of data group.

    For example, to add a new String record named newString with value someData to the affected data group named mydata, type the following command:

    modify /ltm data-group internal mydata records add { newString { data someData } }

  3. To save the changes, type the following command:

    save /sys config

  4. To exit the tmsh utility, type quit and press Enter.
