Description

You may see a warning message as below when you use the match() filter in syslog-ng:

WARNING: the match()filter without the use of the value() option is deprecated and hinders performance, please use a more specific filter like message() and/or program() instead.;

Environment

  • LTM
  • syslog-ng
  • log filters

Cause

Since syslog-ng version 3.2, the behavior of match() filter has changed to use the additional value() option.

Recommended Actions

You may configure a log filter to capture log keywords prior to syslog-ng version 3.2. 

filter f_match_condition {
    match("log message keywords");
};

Since syslog-ng version 3.2 and later, you may use either one of the syntax as below:

  1. Add "value=" before the keywords in match() filter 

    filter f_match_condition {
        match(value="condition in regex");
    };

  2. Use message() filter instead of match()

    filter f_match_message_condition {
        message("condition in regex");
    };
