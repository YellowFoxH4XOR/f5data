Known Issue

This is the result of a known issue. When a client uses Microsoft Internet Explorer 8 (IE8) on a Microsoft Windows XP client system with Service Pack 2 or later installed, the pre-logon sequence IE8 browser window used to enter Protected Workspace does not close properly on the desktop. For example, if the client either exits Protected Workspace or temporarily switches out of Protect Workspace back to the desktop, the user will see that the pre-logon sequence browser window does not close.

F5 Product Development tracked this issue as CR118541 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in cumulative HF-602-10, which has been issued for FirePass version 6.0.2, and cumulative HF-603-2.1, which has been issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Once the FirePass user installs this hotfix, the following message appears in the browser window on the desktop after exiting Protected Workspace:

You have successfully switched to Protected Workspace. You can close this browser window.

Users who view this message may close the browser window without issue.

Note: Internet Explorer 8 does not offer an API method to gracefully close the browser window without generating a pop-up window. To avoid a generic pop-up window prompting the user to close the window, FirePass displays the message above.

Important: Customers who have installed cumulative HF-602-10 for FirePass version 6.0.2 or cumulative HF-603-2.1 for FirePass version 6.0.3 may notice this issue now occurs for both Internet Explorer 6 (IE6) and Internet Explorer 7 (IE7) browsers. Customers who enter Protected Workspace with either hotfix installed, in conjunction with an IE6 or IE7 browser on a Microsoft Windows XP system, will also see that the pre-logon sequence browser window does not close.

F5 Product Development is tracking this issue as CR119770.
