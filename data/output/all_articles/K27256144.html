Description

  • POST requests triggers "Illegal meta character in value" violation but the violation details are not shown
  • When opening the violation details you see: "Violation details not available"

Environment

  • ASM log events
  • Large POST requests with Content-Type: application/x-www-form-urlencoded

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 722337

Recommended Actions

As a workaround, you can set the pb_sampling_high_cpu_load to a lower value.

Impact of workaround: Performing the following procedure forces the BIG-IP system offline for a short period of time. F5 recommends that you perform this procedure during a maintenance window.
  1. Connect to to CLI
  2. Set the pb_sampling_high_cpu_load to a lower value

    /usr/share/ts/bin/add_del_internal add pb_sampling_high_cpu_load 10

  3. Restart ASM

    bigstart restart asm

None.
