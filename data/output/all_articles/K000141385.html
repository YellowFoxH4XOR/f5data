Description

You configured LDAP remote authentication, however when trying to access BIG-IP authentication fails

You also noticed following error logs in /var/log/secure for same timestamp, however the logs doesn't provide full details on exact error message or error code.

 

Sep 26 17:05:50 example.com err sshd[23799]: pam_ldap(sshd:auth): error reading from nslcd: Connection reset by peer

Sep 26 17:05:50 example.com warning sshd[23799]: pam_unix(sshd:auth): check pass; user unknown

Sep 26 17:05:50 example.com notice sshd[23799]: pam_unix(sshd:auth): authentication failure; logname= uid=0 euid=0 tty=ssh ruser= rhost=192.168.1.1

Sep 26 17:05:52 example.com err sshd[23738]: error: PAM: Authentication failure for john.smith from 192.168.1.1

Sep 26 17:05:56 example.com err sshd[23738]: error: Received disconnect from 192.168.1.1 port 59812:0: [preauth]

 

You then enabled debug for nslcd following - K15811: Troubleshooting LDAP authentication for BIG-IP administrative users  and able to see more detailed errors ( with error codes )

Sep 30 14:43:00 example.com info nslcd[16522]: nslcd: [8b4567] <authc="john.smith"> DEBUG: failed to bind to LDAP server ldap://172.16.1.1:389: Invalid credentials: 80090308: LdapErr: DSID-0C09050F, comment: AcceptSecurityContext error, data 532, v4563

Environment

  • Remote authentication
  • LDAP 

Cause

Error message - AcceptSecurityContext error, data 532, v4563 from debug output,  usually indicates issue with user account

Examples including but not limited to are

  • Account locked
  • password expired

Recommended Actions

One should reach out to LDAP server admin with the error logs to verify user account.
