Topic

Only Microsoft Windows Server platforms have the ability to permit access to a specific application. Windows workstation platforms will permit access to the full desktop and does not limit access to one application, assuming the user has the necessary permissions.

To configure FirePass to publish a single program application from Windows Terminal Server, perform the following procedure:

Note: After you select a Terminal Services favorite, users will see only the specific configured application program, not the entire Windows desktop.

  1. From the Administrative Console, click Application Access.
  2. Click Terminal Services.
  3. From the For the group menu, select the appropriate user group.
  4. Click the Add New Favorite link located in the Terminal Services favorite section.
  5. Populate the fields as follows:
    • Enter a Name for Favorites.
    • Specify a Host name or IP address for the Windows Terminal Server.
    • From the Port menu, choose Microsoft Terminal Server (port 3389).
    • In the Select a program field, specify the path for the program application.

      For example:

      notepad.exe
    • In the Working Dir field, specify the working directory.

      For example:

      C:\
    • Optional: Select the box next to Redirect local resources (drives, printers, COM ports): to access the local resources on the client workstation.
    • Leave the Encryption (Citrix-only): setting at Basic (default).
    • Optional: Select Use master group settings from the Auto-logon using FirePass user logon credentials drop-down menu if you are using the same credentials (the same username and password) to access FirePass as you are to access the Microsoft Terminal Server. This Step will allow you to log in to the Terminal Services favorite without being prompted to enter your username and password.
  6. From a client session, open Terminal Services Favorite.

    Note: If you disabled Auto-logon using FirePass user logon credentials, you will be prompted to enter your username and password.

    Once logged in, the specified program application (in the previous example, Notepad) will launch. Once you exit the application, Terminal Services will log you out.
