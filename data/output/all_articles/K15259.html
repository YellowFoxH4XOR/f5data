Known Issue

DNS Cache global settings are not synchronized during configuration synchronization (ConfigSync) operations.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP members configured in a device group.
  • You modify the DNS Cache global settings using the Traffic Management Shell (tmsh) or Configuration utility.

In BIG-IP 11.5.0 and later versions, you can access the DNS Cache global settings by navigating to DNS > Settings > Caches. In BIG-IP 11.4.1 and earlier versions, you can access the DNS Cache global settings by navigating to System > Configuration > Local Traffic > DNS. For all versions of BIG-IP 11.x, the tmsh command to modify the DNS Cache global settings is modify /ltm dns cache global-settings.

Impact

The DNS Cache global settings are not synchronized to other devices in the device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • DNS Cache global settings are not synchronized to other devices in the device group during a ConfigSync operation.
  • The ConfigSync status in the Configuration utility or the command line does not update after you change the DNS Cache global settings.

Workaround

To work around this issue, you can manually replicate the DNS cache global settings on all devices in the device group.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
