Known Issue

Description

The BIG-IP ASM system may mistakenly identify HTTP requests that are generated by users of the Ask.com browser toolbar as originating from the web crawler for the Ask.com search engine.

This issue occurs when the following condition is met:

  • The Web Scraping Detection violation is enabled with a blocking mask of Learn, Alarm, or Block
  • The BIG-IP ASM system receives an HTTP request from a web browser that is using the Ask.com search tool bar

The Web Scraping Detection feature maintains a list of allowed bots that are exempt from triggering web scraping violations. The identity of these bots is verified by a combination of their user-agent strings and DNS queries. Certain user-agent strings may cause the BIG-IP ASM system to mistakenly identify Ask.com toolbar requests as Ask.com bot requests and treat them accordingly, generating unnecessary DNS requests. For example, the following user-agent string contains the AskTbX-SD value, which causes this issue:

User-Agent: Mozilla/4.0 (compatible; MSIE 8.0; Windows NT 5.1; Trident/4.0; SearchToolbar 1.2;
GTB7.0; (R1 1.6); AskTbX-SD/5.11.3.15590; Creative AutoUpdate v1.40.01; XF_mmhpset; yie8)

Impact

The BIG-IP ASM system performs unnecessary DNS queries.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H378375 on the Diagnostics > Identified > Low screen.
  • The BIG-IP ASM system may generate excessive DNS requests.
  • If DNS is not functioning correctly, the BIG-IP ASM bd process may restart, dump core, and the system may temporarily fail to process traffic.

    For more information about this secondary symptom, refer to K12308: Web scraping detection may cause the BIG-IP ASM to dump core if DNS is not accessible.

Workaround

BIG-IP ASM 11.0.0

To work around this issue, you can manually change the bot name associated with the Ask.com search engine. To do so, perform the following procedure:

Impact of workaround: This procedure will change the criteria for activating bot detection for the Ask.com search engine to a new preferred value, which will affect all policies on the BIG-IP ASM system and may lead to a change in statistics profiles for web scraping violations.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Options > Advanced Configuration > Search Engines.
  3. In the Search Engine List, click Ask.
  4. In the Bot Name field, delete the value displayed (ask) and replace it with the following value:

    teoma
  5. Click Save.

BIG-IP ASM 10.2.0 - 10.2.2

No workaround exists for 10.2.0 through 10.2.2. F5 recommends that you upgrade to BIG-IP 10.2.3 or later.
