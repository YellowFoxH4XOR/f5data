Description

To allow TLS 1.2 and 1.3 in SSL profiles you can follow the steps provided below.

Environment

  • BIG-IP 15.x and later 
  • SSL profiles

Cause

None

Recommended Actions

Since you must configure a cipher group when using TLS1.3 anyway, one easy way to allow only TLS 1.2/1.3 is to perform one of the following procedures:

  • Allow only TLS 1.2/1.3 in an SSL profile using the Configuration utility

    To watch a video demo of this procedure, go to  Configure an SSL profile on a BIG-IP system to allow only TLS 1.2 and TLS 1.3.

  • Allow only TLS 1.2/1.3 in an SSL profile using TMSH

Allow only TLS 1.2/1.3 in an SSL profile using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client or Server.
  3. Select Create or choose an existing profile.
  4. If necessary, for Configuration, select Advanced.
  5. For Ciphers, select the Custom check box.
  6. Select Cipher Group, and then select a group such as f5-default, which is equivalent to the DEFAULT cipher string from the list.

    Note: When TLS 1.3 is enabled, you must configure a cipher group.

  7. For Options, select the Custom check box.
  8. In the Available Options list, select all off them and click 'Enable'
  9. In the Enabled Options list, select the TLS protocol that you want to enable for the SSL profile; in this case, you should select No TLSv1.3, No TLv1.2 and No TLS and then select Disable to remove them from the Enabled Options list so that the SSL profile allows these TLS protocols.
  10. Configure other properties for the SSL profile as needed.
  11. Select Finish or Update. This should allow TLS 1.2/1.3 only.

Allow only TLS 1.2/1.3 in an SSL profile using TMSH

  1. Log in to TMSH by entering the following command:
    tmsh
  2. Use the following syntax to create a client SSL profile that allows TLS 1.2 and 1.3 or skip to the next step if creating a server SSL profile:
    create ltm profile client-ssl <profile name> { cert-key-chain add { default { cert <cert file name> key <key file name> } } cipher-group f5-default ciphers none defaults-from clientssl options { dont-insert-empty-fragments no-ssl no-dtls no-session-resumption-on-renegotiation no-tlsv1.1 single-dh-use no-dtlsv1.2 tls-rollback-bug no-dtlsv1 no-sslv3 no-tlsv1 } }
  3. Use the following syntax to create a server SSL profile that allows TLS 1.2 and 1.3:
    create ltm profile server-ssl <profile name> { cipher-group f5-default ciphers none defaults-from serverssl options { dont-insert-empty-fragments passive-close no-ssl no-dtls no-tlsv1.1 single-dh-use no-dtlsv1.2 no-dtlsv1 no-sslv3 no-tlsv1 }}
  4. Save the configuration changes by entering the following command:
    save sys config
  5. Sync the changes to the device group if necessary. Refer to K14856: Performing a ConfigSync using tmsh.
  6. Exit TMSH by typing the following:
    q
