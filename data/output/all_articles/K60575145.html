Description

Error Message: Cannot delete IP <IP_address> because it would leave a pool member (pool <pool_name>) unreachable

<IP_address> is the IP address you are attempting to delete.
<pool_name> is the name of the pool that will be negatively impacted.

For example:

err mcpd[5497]: 01070605:3: Cannot delete IP 10.10.10.10 because it would leave a pool member (pool /Common/example_pool) unreachable.

Environment

  • Self IP address
  • Pool/pool member(s)

Cause

This behavior is by design and is implemented to prevent unexpected routing conditions.

Recommended Actions
You can follow either of the procedures, step1 or step2 to delete the Self IP 

  1. You will need to remove all pool members with IP addresses on the same network as the Self IP address you wish to delete. Once this has been done you can delete the Self IP address. Then add the pool members back to the pool
     
  2. Update the netmask to delete the Self IP. 
  • Navigate to  Network  ››  Self IPs  ››  <Self IP name> 
  • Change the netmask to 255.255.255.255
  • Click update.
  • Click delete. 
    Note: Updating the netmask impacts the traffic passing through the network.
