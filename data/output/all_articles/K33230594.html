Description

BIG-IP ASM is not accepting "0" (zero) as Username Parameter name when configuring Login Page.

Environment

  • Configuring Login Pages

Cause

"0" value is not allowed in this configuration object.

Recommended Actions

Use URL encoding "%30" instead of "0".
