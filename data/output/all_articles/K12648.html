Issue

Old Behavior

In versions prior to 11.2.0, F5 does not support assigning IPv6 addresses to the management interface.

Note: While it is possible to assign IPv6 addresses to the management interface, this configuration is not supported.

New Behavior

Beginning in BIG-IP 11.2.0, F5 supports assigning either IPv6 or IPv4 addresses to the management interface.

Impact

None

Recommended Actions

If upgrading to BIG-IP 11.2.0 is not an option, use switchport interfaces for management access using IPv6.
