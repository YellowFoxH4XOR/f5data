K000139299: How to log SSL Cipher Suites with NGINX Plus

Type
Support Solution
Published
2024-04-16
Updated
2024-04-16
Applies to
  • NGINX Products
  • NGINX Plus: R31, R30, R28, R29
Source
https://my.f5.com/manage/s/article/K000139299

Description

  • You have configured NGINX Plus to manage SSL Offloading 
  • You wish to determine cipher suites that accompany initial client hello during SSL handshake.  
  • You want Nginx to log these ciphers sent by the client in access loge.

Environment

  • NGINX Plus
  • SSL
  • Client Hello
  • Cipher suites
  • Log_format
  • Access Log

Cause

  • None

Recommended Actions

  • You can achieve the above objective using '$ssl_curves' parameter, which is derived from Module ngx_http_ssl_module.
  • You can also use '$ssl_cipher' to returns the name of the cipher used to establish SSL connection between NGINX and the client.

Additional Information

For example, one can append the below log_format

log format 

            log_format ssl_log  '$remote_addr - $remote_user [$time_local] "$request" $status $body_bytes_sent'
                                '"$http_referer" "$http_user_agent" "$http_x_forwarded_for" "$request_id" rt="$request_time"'
                                'alpn="$ssl_alpn_protocol" curve="$ssl_curve" curves="$ssl_curves"'
                                'cipher="$ssl_cipher" ciphers="$ssl_ciphers" sslproto="ssl_protocol" ' ;
