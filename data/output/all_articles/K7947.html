K7947: The Portal Access reverse-proxy engine does not support Adobe Flash 9 SWF files

Known Issue

This is the result of a known issue. Currently, the Adobe Flash rewrite module for the Portal Access reverse-proxy engine supports the Adobe Flash SWF file format for version 8. It does not support the Adobe Flash 9 SWF file format. As a result, users may not be able to view some SWF files through FirePass Portal Access Favorites.

F5 Product Development tracked this issue as CR85872 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by configuring minimal content rewriting. To do so, perform the following procedure:

  1. Log in to the FirePass Administrative Console.Navigate to the Portal Access: Web Applications: Master Group Setting page.
  2. Select the group you want to configure from the Master Group drop-down menu.
  3. Under the Pattern-based heading in the Minimal Content-Rewriting Bypass section, enter the patterns and target server in the Comma separated list of patterns and http[s]://<IP Address/Name>[:Port] fields, respectively.

    For example, if you want to bypass all files under <https://www.siterequest.com:8080/flash9/>, you would enter /flash9/* in the Comma separated list of patterns field and enter https://www.siterequest.com:8080 in the http[s]://<IP Address/Name>[:Port] field.

  4. Click the Add button.
  5. Repeat steps 4 and 5 until you have added all the required patterns for the Master Group.
  6. Repeat steps 3 through 6 until you have configured all the required Master Groups.

Important: Minimal content rewriting does not work in compatibility mode. To disable compatibility mode, clear the Compatibility mode check box under the Global Settings tab on the Portal Access: Web Applications: Content Processing page. This change requires you to restart the FirePass services. Compatibility mode is provided to support web applications configured using legacy versions of the Portal Access reverse-proxy engine.

If you do not want to bypass content-rewriting, or if you do not want to disable compatibility mode, you can configure Application Tunnels for the Adobe Flash 9 files instead of Portal Access Favorites. For more information about configuring Application Tunnels, refer to the FirePass Controller Administrator Guide.
