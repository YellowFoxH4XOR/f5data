Description

When attempting to enable or disable a GTM (BIG-IP DNS) pool member from the pool member property page in the GUI, the change does not take effect.

The member remains in its previous state (disabled or enabled) despite the action.

Environment

  •  BIG-IP DNS (GTM) 
  • Graphical user interface (GUI)

Cause

This issue is caused by a known  Bug ID 1014761: [DNS][GUI] Not able to enable/disable pool member from pool member property page

The change is not applied, and the member remains in its previous state.

Recommended Actions

Perform either of the following to change the members state.

1.Use TMSH (the command line interface) to enable or disable GTM pool members.

For example below is the format:

# modify gtm pool <pool type>  <pool name> { members modify { <pool member> { enabled } } }

Replace <pool_type>, <pool name>, and <pool member> with your actual configuration details.

After making changes, save your configuration:

#save sys config

2.Use the "members list" tab in the GUI (not the property page) to enable or disable pool members;
