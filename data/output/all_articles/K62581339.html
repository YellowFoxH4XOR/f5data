Known Issue

The BIG-IP system may respond with an incorrect value for the sysInterfaceMediaMaxSpeed and sysInterfaceMediaActiveSpeed SNMP management information base (MIB) objects.

This issue occurs when the following condition is met:

  • You perform an SNMP query on the sysInterfaceMediaMaxSpeed and sysInterfaceMediaActiveSpeed MIB objects related to the network interfaces of the BIG-IP system.

Impact

The system may not report the correct sysInterfaceMediaMaxSpeed and sysInterfaceMediaActiveSpeed values for the specified network interfaces.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • An SNMP query on the sysInterfaceMediaMaxSpeed MIB object returns an incorrect value similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysInterfaceMediaMaxSpeed."1.2" = Gauge32: 10

    Note: The value should match the output from the tmsh list /net interface 1.2 media-max command.

  • An SNMP query on the sysInterfaceMediaActiveSpeed MIB object returns an incorrect value similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysInterfaceMediaActiveSpeed."1.2" = Gauge32: 10

    Note: The value should match the output from the tmsh list /net interface 1.2 media-active command.

Workaround

There is no workaround for this issue. You can instead use the TMOS Shell (tmsh) to display the correct sysInterfaceMediaMaxSpeed and sysInterfaceMediaActiveSpeed values for the specified network interfaces. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To display the correct value represented by the sysInterfaceMediaMaxSpeed MIB object, use the following command syntax:

    list /net interface <interface> media-max

    The command and output for network interface 1.2 appears similar to the following example:

    list /net interface 1.2 media-max

    net interface 1.2 {

        media-max 1000T-FD

    } 

  3. To display the correct value represented by the sysInterfaceMediaActiveSpeed MIB object, use the following command syntax:

    list /net interface <interface> media-active

    The command and output for network interface 1.2 appears similar to the following example:

    list /net interface 1.2 media-active

    net interface 1.2 {

        media-active none

    }
