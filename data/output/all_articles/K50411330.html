Description

You see the following log in var/log/ltm:

012a0003:3: HAL error getting baud rate: TTYDev: I/O error  [Input/output error] at TTYConDev.cpp:60

Environment

  • BIG-IP VE

Cause

This is an expected behavior when creating new Virtual Machines. Our .ova files do not have serial ports, nor does BIG-IP need them.

Recommended Actions

This error message is benign.
