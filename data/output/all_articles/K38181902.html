Known Issue

ACL entries created with the Traffic Management Shell (tmsh) using default settings may generate an invalid configuration.

This issue occurs when the following condition is met:

  • You create an ACL using the tmsh utility where the Source IP Address or Destination IP Address is not specified (default of any).

Impact

The newly created ACL does not function as intended.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the ACL set that was created using the tmsh utility, with the default of any Source IP Address or Destination IP Address, the subnet mask is ::/128.
  • When you create the same ACL using the Configuration utility, the subnet mask is 0.0.0.0/0.

Workaround

To work around this issue, you can use the Configuration utility to create ACLs.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
