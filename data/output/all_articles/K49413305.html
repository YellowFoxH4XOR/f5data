Description
How to modify an existing port lockdown configuration on a BIG-IP self IP address from the command-line 

Environment

  • BIG-IP
  • Self IP address with port lockdown configured with a value other than 'None'

Cause
N/A

Recommended Actions
When using the modify net self command, there are several keywords that can follow allow-service:

  • all
  • none
  • default
  • add
  • replace-all-with
The add keyword will work in some cases, however it will not remove any services from an existing list if, for example, the keyword all was configured previously.  The replace-all-with keyword will replace any port lockdown configuration on the self IP with whatever services are defined in the command:
 
tmsh modify net self /Common/<self IP Name> allow-service replace-all-with { igmp:0 ospf:0 pim:0 tcp:53 tcp:4353 tcp:161 tcp:22 udp:520 udp:1026 udp:53 udp:4353 udp:161 }
tmsh save /sys config

To validate that the changes to the self IP configuration were successful, run the following command:

tmsh list net self
