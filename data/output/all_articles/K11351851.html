K11351851: TMSH command to show ramcache output and iRule ramcache adjustments

Applies to

Description

In BIG-IP versions prior to 13.1.0 the tmsh show ramcache command output does include iRule cache adjustments in account.
For example using an iRule to modify the cache control max-age (Cache-Control max-age).

Environment

  • BIG-IP
  • Web Acceleration Profile
  • iRule

Cause

Stating BIG-IP version 13.1.0 the BIG-IP will include iRule cache adjustment in tmsh show command output.

Recommended Actions

None
