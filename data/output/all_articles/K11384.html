K11384: Dynamic Application Tunnels are not supported in the Windows standalone client

  • FirePass: 6.0.3, 6.0.2, 6.1.0, 6.0.0, 6.0.1
Source

Topic

When connecting to FirePass through the Windows standalone client, Dynamic Application Tunnels do not appear in the Application Tunnels folder. This behavior is by design as the Windows standalone client does not currently support Dynamic Application Tunnels.

Note: Dynamic Application Tunnels were first introduced in FirePass 6.0.0.

Note: For more information about configuring the FirePass Application Tunnels, refer to the FirePass Controller Administrator Guide.
