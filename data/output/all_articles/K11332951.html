Known Issue

The BIG-IP APM rewrite profile may fail to patch a JavaScript-inserted cascading style sheets (CSS) style method.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access using a rewrite profile.
  • An HTML page invokes a dynamically inserted client-side JavaScript code that adds a CSS style method with syntax similar to the following:

    style.appendChild(document.createTextNode(style))

Impact

JavaScript is not patched, and web application images fail to render.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When accessing content processed by portal access, images are not displayed.
  • When accessing content processed by portal access, images are retrieved directly from the destination resource and bypass the BIG-IP APM system.

Workaround

To work around this issue, you can create and apply an iRule to rewrite the affected JavaScript content. To do so, perform the following procedure:

Impact of workaround: F5 recommends performing the following procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > Create.
  3. In the Name box, type a name for the iRule.
  4. For example:

    javascript_css_rewrite
     
  5. In the Definition box, enter the following text:

    when REWRITE_REQUEST_DONE {
        set is_253101627 0
        if { "[HTTP::path]" matches_glob "*/dashboard/js/script-built.js*" } {
            set is_253101627 1
            REWRITE::post_process 1
        }
    }
    when REWRITE_RESPONSE_DONE {
        if { $is_253101627 == 1 } {
            set loc [string first "document.createTextNode(a)" [REWRITE::payload]]
            if { $loc >= 0 }{
                REWRITE::payload replace [expr $loc + 24] 1 "F5_WrapStyleAttr(a)"
            }        
        }
    }
  6. Click Finished.
  7. Click Virtual Servers.
  8. Click the name of the BIG-IP APM virtual server that is affected by this issue.
  9. Click Resources.
  10. In the iRules section, click Manage.
  11. From the Available column, select the iRule you previously created.
  12. Click the << button. 

    The iRule moves to the Enabled column.
  13. Click Finished.
