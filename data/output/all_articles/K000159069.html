Description

BIG-IP Virtual Edition (VE) systems with V18 SKUs displayed version 21.x in the "Exclusive_version" entries of their license files after license activation.

Environment

BIG-IP Virtual Edition (VE)

Licensing

Cause

Due to an internal error the license server incorrectly displayed support for V21 for a brief period until it was discovered and corrected.

Recommended Actions

 V18 SKUs do not officially support BIG-IP version 21.x. According to K15643, V18 licenses are limited to BIG-IP TMOS versions up to 17.5.x only. The licensing server error was identified and corrected.

 

Steps to follow:

1.Reactivate the license to obtain the corrected license file. This command refreshes the license file from the licensing server with corrected version information.

2.Verify the license file after reactivation to confirm version 21.x entries have been removed.

For customers requiring BIG-IP versions beyond 17.5.x ,contact F5 Sales Representatives to purchase updated V23 license SKUs
V23 licenses support BIG-IP TMOS versions 17.1.x through 23.x
If the issue persists after reactivation, open a new support case with F5 Technical Support.
