K2094: Maximum number of rules that can be configured on BIG-IP

Topic

Rules are an optional feature that you can use if you do not want traffic to target the default pool defined for a virtual server, allowing you to more directly specify the pools to which you want traffic to be directed.

The limit for the number of rules on a BIG-IP is 1,024.
