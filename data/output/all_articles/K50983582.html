K50983582: BIG-IP DNS 01150306:3: Error connecting to named socket 'Connection refused'

Type
Support Solution
Published
2020-09-30
Updated
2023-10-16
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP DNS: 15.1.0
Source
https://my.f5.com/manage/s/article/K50983582

Description

In the GUI: DNS  ››  Zones : ZoneRunner : Zone List

Error message: 01150306:3: Error connecting to named socket 'Connection refused'

Environment

  • DNS module provisioned 

Cause

Invalid or non-used ACL defined in /var/named/config/named.conf

Example: 

options {
    listen-on port 53 {
        127.0.0.1;
        "zrd-acl-000-000"; <--- exists
        "zrd-acl-000-004"; <--- doesn't exist in /var/named/config/named.conf besides this reference
    };

Recommended Actions

  1. Check /var/named/config/named.conf in the GUI DNS  ››  Zones : ZoneRunner : named Configuration
     
  2. Make sure all ACLs are actually used, if not delete the unused ACL(s) then Update. 
     
  3. Restart zrd
    # bigstart restart zrd
