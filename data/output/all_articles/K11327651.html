Description

After upgrade to the version in the applied version list, interface 2.1 and 2.2 keep flapping, and see the LTM log below repeated:

info pfmand[PID]: 01660009:6: Link: 2.1 is UP
info pfmand[PID]: 01660009:6: Link: 2.1 is DOWN

If the interface is the member of the truck and LCAP is enabled, will see the log below repeated:

info lacpd[PID]: 01160011:6: Link 2.1 Actor Out of Sync

Environment

  • 2000 Series or 4000 Series

Cause

Bug ID 746861

Recommended Actions

Open an SR with F5 Support to request an engineering hotfix for this issue.
