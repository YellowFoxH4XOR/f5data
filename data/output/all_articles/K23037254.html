Description

Restoring device certificate on a BIG-IP system

  • Unable to access Configuration Utility (GUI) 

Environment

  • Device certificate was updated wrongly
  • BIG-IP

Cause

Device certificate was updated accidentally and you want to restore the certificate and key pairs of your BIG-IP system.

Recommended Actions

Replace the certificate and key pair located in the /config/httpd/conf/ssl.crt(key) folders with the those stored in the /var/lib/mysql/ folder.

  1. Backup existing device certificate and key pairs by running the command below:
    # cp /config/httpd/conf/ssl.crt/server.crt /config/httpd/conf/ssl.crt/server.crt.old
    # cp /config/httpd/conf/ssl.key/server.key /config/httpd/conf/ssl.key/server.key.old
     
  2. Copy the ‘server.crt’ and 'server/key' files from ‘/var/lib/mysql/’ to the /config/httpd/conf/httpd/conf/ssl.crt(key)/ folders:
    # cp /var/lib/mysql/server.crt /config/httpd/conf/ssl.crt/server.crt
    # cp /var/lib/mysql/server.key /config/httpd/conf/ssl.key/server.key
     
  3. Restart Httpd & Tomcat Process
    # tmsh restart /sys service httpd tomcat
