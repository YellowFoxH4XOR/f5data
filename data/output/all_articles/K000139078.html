Description

One of the pool member monitoring status shows "checking" and it remains forever. 

RAM and CPU cores might not be sufficient for the BIG-IP to function properly. During testing, identified the issue with the  RAM was 8 GB & CPUs were 1 Blade(s) / 2 CPU(s) / 4 Cores. Later when the RAM was increased to 16 GB & CPUs to 1 Blade(s) / 4 CPU(s) / 8 Cores the issue was resolved. 

Environment

  • BIG-IP LTM
  • Monitoring
  • Pool member
  • Virtual BIG-IP instance

Cause

The issue is due to improper resource provisioning to the Virtual machine running BIG-IP LTM. 

 Recommended Actions

It is recommended to upgrade the virtual machine resources like RAM & CPU/cores as per configuration requirements.
