Description

You get this error message when you access the folder using cd command in TMOS shell.

For example:

(Active)(/Common)(tmos)# cd /root
Data Input Error: The requested folder (/root) was not found.

Also the following message on the target device in the following location:

The /var/log/ltm file

01070734:3: Configuration error: Invalid mcpd context, folder not found (<folder>)

For example:

01070734:3: Configuration error: Invalid mcpd context, folder not found (/root)

Environment

  • BIG-IP

Cause

When you are inside TMSH shell, normal Linux directories cannot be accessed with command "cd". The "cd" command, when ran inside TMSH, points to TMSH folders, which are administrative partitions. For a more detailed information, please refer to the manual:

Manual Chapter : About Folders

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Login to BIG-IP CLI.
  2. Once you are in TMOS shell, running the following command to use bash shell:
    # bash
  3. Using cd command for accessing folder.
    # cd /<folder>

    For example:

    # cd /root
