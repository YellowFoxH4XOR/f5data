Known Issue

BIG-IP APM network access may temporarily disconnect when client device active network interfaces change.

This issue occurs when all of the following conditions are met:

  • Your network access profile has the Allow Local Subnet setting enabled.
  • You establish a network access session.
  • You connect a secondary network interface on the client device to a network.

Impact

The network access session temporarily disconnects.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Long-lived TCP connections, such as Virtual Private Network (VPN) and secure shell (SSH) connections, may terminate unexpectedly.
  • When using BIG-IP Edge Client, you observe log messages similar to the following example:

Workaround

To work around this issue, you can disable the Allow Local Subnet setting of the affected network access profile. To do so, perform the following procedure:

Impact of workaround: Local subnet access will become unavailable for access sessions using the network access profile.

  1. Log in to the Configuration utility of the affected BIG-IP APM system.
  2. Navigate to Access Policy > Network Access > Network Access List.
  3. Select the affected network access policy.
  4. Click Network Settings.
  5. In the Client Settings section, clear the Allow Local Subnet check box.
  6. Click Update.
  7. In the upper-left corner of the Configuration utility, click Apply Access Policy.
  8. Click Apply Access Policy.
