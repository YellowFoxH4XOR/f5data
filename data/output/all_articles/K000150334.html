Description

You have attached a DoS profile from within the Security section of the BIG-IP for ASM/AdvWAF and now need to setup local or remote logging. As well as needing the statics and other reports needed to track possible attacks.

Environment

  • Monitor and evaluate possible DoS traffic.
  • Logging profiles, statistics, and reports.
  • ASM/AdWAF

Cause

In the process of maintaining a proper security perimeter around and in your network there is a need to review traffic that may appear to be a DoS attack.

Recommended Actions

DoS events are not viewed in the same way others are. There are local logs and remote logging for DoS, but other things are needed to properly understand a possible DoS attack.

  1.  Configure a DoS logging profile and associate it to the virtual server with the DoS profile.
    1. Most often the default local DoS logging profile for local logging will suffice, because there is only one setting for local logging. When the DoS Security Logging Profile is created either "Local Publisher" is Enabled by checking the box or disabled by leaving it unchecked.
    2. As to setting up remote logging for DoS events refer to K29004745: Remote Logging configuration for DOS and Bot protection.
      1. These can both be part of the same DoS logging profile
    3. Add the logging profile to the virtual server Local Traffic  ››  Virtual Servers : Virtual Server List  ››  <virtual server> :: Security tab :: Log Profile and add the Dos log profile.
  2. Much of what will need to be reviewed is best covered by reviewing the manual section for your version titled Viewing DoS Reports, Statistics, and Logs (this is the one for version 17.x)
  3. Review the dosL7d logs. K45156590: Understanding DoS L7 log messages

Additional Information

If you suspect you are under a actual attack please review F5 Security Incident Response Team (F5 SIRT)  about receiving assistance from F5.
