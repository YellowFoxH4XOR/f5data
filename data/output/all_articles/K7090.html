Known Issue

This is the result of a known issue. iControl communication issues may produce an invalid dossier for licensing BIG-IP 9.x and Enterprise Manager systems. The Management::LicenseAdministration::get_system_dossier() iControl call produces an invalid dossier.

If the invalid dossier is used to generate a license from the F5 license server, the following error message will display:

Error 51090, Production Key cannot be used in the Internal Development/PD environment - Key : <Key>

F5 Product Development tracked this issue as CR73156 for the Enterprise Manager software, and it was fixed in Enterprise Manager 1.2.2. For information about upgrading, refer to the Enterprise Manager release notes.

F5 Product Development tracked this issue as CR73156 for BIG-IP software, and it was fixed in BIG-IP 9.1.3, 9.3.0, and 9.4.1. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller release notes.
