Issue

Error Message

crit tmm[<PID>]: 015e0004:2: 015e0004:2 [pg:<Processory Group> pu:<Processory Unit>] </PathTo/PacketClass>: <Error Message>

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.
  • <Processor Group> is the blade number from which the error is reported. 

    Note: If the system is an appliance, this value is always 0.

  • <Processory Unit> is the TMM instance ID that is reporting the error message (for example: 0=tmm0, 1=tmm1).
  • </PathTo/PacketClass> is the path and packet class in use.
  • <Error Message> is the error message being reported. 

For example:

crit tmm2[15146]: 015e0004:2: [pg:0 pu:2] /dev/shm/pktclass1: File stat failed.

Message Location

You may encounter this message in the following location[s]:

  • The /var/log/tmm file
  • The /var/log/ltm file

Description

This message occurs when  the following conditions is met:

  • The TMM process failed to load information from the Packet Correlation Classification Daemon (pccd) service. This can occur when there is a problem accessing one of pccd files.

Impact

None of the L2-L4 firewall policies are enforced.

Recommended Actions

Remove all packet class files. To do so, perform the following procedure:

  1. Log in to the command line.
  2. To remove the packet classes, enter the following command:

    rm -f /var/pktclass/*

  3. To restart the pccd service, enter the following command:

    tmsh restart sys service pccd
