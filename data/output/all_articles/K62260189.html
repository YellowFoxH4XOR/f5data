Description

Device is constantly re-starting mcpd, there are the next logs on /var/log/messages 

emerg logger: Re-starting mcpd

There are similar logs on /var/log/ltm

err mcpd[]: 01070047:3: DB variable ipsec.removeredundantsa's data type [ket_errors] is invalid. Valid data types are: integer, unsigned_integer, string, ipaddress, enum.
err mcpd[]: 01070734:3: Configuration error: MCPProcessor::initializeDB (2):
err mcpd[]: 01070596:3: An unexpected failure has occurred,  - sys/validation/DbVariable.cpp, line 1330, exiting...
info sod[]: 010c0012:6: Mcp start publication fails with error 0x1020003.

Environment

  • BIG-IP LTM

  • DB variable ipsec.removeredundantsa

Cause

DB variable on /config/BigDB.dat becomes corrupted, and mcpd fails to start up.

Recommended Actions

Make a backup of /config/BigDB.dat and copy the default DB.dat into /config/

  1. bigstart stop mcpd

  2. bigstart stop

  3. cp /config/BigDB.dat /config/BigDB.bak

  4. cp /usr/share/defaults/BigDB.dat /config/BigDB.dat

  5. bigstart start
