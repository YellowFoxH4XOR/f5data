Description

Serverside initiated connections inbound to APM network access tunnel lease pool addresses are failing

 

Environment

BIG-IP APM
 

Cause

Note: Virtual Server SNAT settings do not affect Network Access traffic. The server also must have a route to the BIG-IP for the leasepool subnet.

 

In order for inbound serverside connections to succeed destined to APM network access tunnel lease pool adresses, SNAT must be set to "none" on the Network Access resource.
 

Recommended Actions

In the configuration utility navigate to Access -> Connectivity / VPN -> -> Network Settings tab -> SNAT Pool set to "None"

None
