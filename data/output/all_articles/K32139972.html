Description

Updating NGINX App Protect Attack Signatures

NGINX App Protect Attack Signatures updates are released at higher frequency than NGINX App Protect, therefore they are released in their own package, separate from the App Protect package. You can update the attack signatures without updating the App Protect release, and conversely, you can update App Protect without changing the attack signature package, unless you move to a new NGINX Plus release.

Environment

NGINX App Protect installed

Cause

New NGINX App Protect Attack Signatures are available and you wish to update it

Recommended Actions

The updated package for the latest NGINX App Protect Attack Signature may be installed from the NGINX App Protect Security Updates repository using the following procedures:

Supported Operating SystemNGINX App Protect Security Updates repository Update Procedure
CentOS / RHELsudo wget -P /etc/yum.repos.d https://cs.nginx.com/static/files/app-protect-security-updates-7.repo
Debianprintf "deb https://app-protect-security-updates.nginx.com/debian/ `lsb_release -cs` nginx-plus\n" | sudo tee /etc/apt/sources.list.d/app-protect-security-updates.list
Ubuntu 18.04printf "deb https://app-protect-security-updates.nginx.com/ubuntu/ `lsb_release -cs` nginx-plus\n" | sudo tee /etc/apt/sources.list.d/app-protect-security-updates.list
Ubuntu 20.04printf "deb https://app-protect-security-updates.nginx.com/ubuntu/ `lsb_release -cs` nginx-plus\n" | sudo tee /etc/apt/sources.list.d/app-protect-security-updates.list
Alpineprintf "https://app-protect-security-updates.nginx.com/alpine/v`egrep -o '^[0-9]+\.[0-9]+' /etc/alpine-release`/main\n" | sudo tee -a /etc/apk/repositories

Information on how to update NGINX App Protect Attack Signatures can be found in the Updating App Protect Attack Signatures section of the NGINX App Protect WAF Administration Guide.

Note: After having updated the Attack Signature package you have to reload the configuration in order for the new version of the Signatures to take effect. Until then App Protect will run with the old version.

Additional Information

NGINX App Protect supported operating systems are updated periodically. Refer to the Releases page for your NGINX App Protect version for more information.
