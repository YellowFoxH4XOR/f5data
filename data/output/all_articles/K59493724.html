Description
You would like to get the details of your virtual servers in all partitions and sub-folders using TMSH.

Environment

  • BIG-IP LTM
  • Virtual Servers
  • TMSH
  • Partitions
  • Sub-folders

Cause
None

Recommended Actions

Option 1

You can use the following command to list the details of the virtual servers in all partitions and sub-folders and save the output to a text file:

  1. Login into the BIG-IP CLI
  2. Run the following command in bash:

    tmsh -c 'cd /; list ltm virtual recursive' >> /var/tmp/virtual.out

Note: The above command will save the output in a text file under the path /var/tmp.

Option 2

If you don't have access to bash, you can use the following command in TMSH to list the details of the virtual servers in all partitions and sub-folders:

  1. Login into the BIG-IP CLI and if your terminal access is TMSH, you should be logged into the tmos prompt.
  2. Run the following command:

    cd /; list ltm virtual recursive

  3. When finished enter q to exit the pager. To turn off paging, refer to K000132130: How to disable the "Display all [number] items? (y/n)." confirmation in TMSH .
