Known Issue

This is the result of a known issue. Windows clients are unable to log in to a Mac OS X client with a Terminal Service Favorite that uses a VNC protocol. After the user enters the VNC password, they are repeatedly requested to enter the password until the logon attempt fails. 

F5 Product Development is tracking this issue as ID 265607 (Formerly CR127285).

Workaround

To allow VNC access, you can configure an Application Tunnel in conjunction with a VNC view, such as RealVNC, by completing the following procedure. Users may download and install the RealVNC viewer and server application from the RealVNC site. This link takes you to a resource outside of AskF5, and it is possible that the information may be removed without our knowledge.

Note: There is a licensing fee for the RealVNC server application.

FirePass configuration steps to create a new Application Access favorite (AppTunnel)

  1. Log in to the FirePass Administrative console.
  2. Click Application Access.
  3. Click Application Tunnels.
  4. Click Resources, and select the appropriate Resource Group for the new AppTunnel.
  5. Click Add New Favorite.
  6. In the Name box, type a user-friendly name. This name is presented to clients who access the FirePass AppTunnels choices.
  7. If you want a pre-configured endpoint protection for this tunnel, select an Endpoint Protection configuration.
  8. Expand Static Tunnels.
  9. Click Add New Static Tunnel.
  10. From the New Static Tunnel box, select VNC.
  11. In the Remote Host: Port or Range box, type the IP address or hostname of the VNC server.
  12. The Port box should already be populated with the default VNC port 5900; if the VNC server is listening on an alternate port, modify this value.
  13. If required, in the Local Host: Port or Range box, change the associated port to match the port of the VNC server.
  14. In the Application box, place the full path of the application, in double quotes, as it is shown on the client systems that will use this tunnel, and then add the IP address: port, from the previous step.

    For example:

    "C:\Program Files\RealVNC\VNC-Viewer-5.0.5-Windows-64bit.exe" 127.107.34.240:5900
  15. Click Add New Static Tunnel.

To locate the full path of a client's application for Windows clients

  1. From the client's computer, right click the application icon.
  2. Select Properties, and view the contents of the Target section.

    For most Window's Start icon configurations, the contents of the Target section is already encased in double quotes, and you can highlight and copy the path into the FirePass Application box of the App Tunnel configuration.

    An example configuration:

    New Static Tunnel = VNC
    Remote Host: Port or Range = 192.168.0.20:5900
    Local Host: Port or Range = 127.107.34.240:5900
    Application = "C:\Program Files\RealVNC\VNC-Viewer-5.0.5-Windows-64bit.exe" 127.107.34.240:5900

    The VNC server is 192.168.0.20 port 5900, the automatically-generated FirePass local address is 127.107.34.240:5900.

    Note: The auto-generated local address for your configuration will most likely use a different loop back network address.

    When the client uses this favorite, and the application tunnel has been established, the program C:\Program Files\RealVNC\VNC-Viewer-5.0.5-Windows-64bit.exe is automatically initiated with the destination 127.107.34.240:5900. (The client receives a pop-up message requesting for the application to gain access). The destination address is the local loop back network address that will be tunneled by the FirePass to 192.168.0.20:5900.
