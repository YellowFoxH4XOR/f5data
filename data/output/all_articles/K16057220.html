Issue

Error Message

notice sod[<PID>]: 010c0078: Not listening for unicast failover packets on address <IP_address> port <port>

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <IP_address> is the IP address of the unicast network failover listener on the BIG-IP system.
  • <port> is the port the BIG-IP system uses to listen for network failover packets.

For example:

notice sod[5968]: 010c0078: Not listening for unicast failover packets on address 10.0.0.1 port 1026

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • While the sod process is running, you remove the specified IP address from the network failover unicast configuration.

Impact

The sod process no longer listens for network failover heartbeat packets on the noted IP address.

Recommended Actions

None
