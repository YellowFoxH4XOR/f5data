Topic

You should consider using this procedure under the following conditions:

  • Your BIG-IP system is configured with virtual servers that use a Client SSL profile.
  • You want to map SSL virtual servers to their associated Client SSL profiles and SSL certificates.

Description

A virtual server configured for SSL offload uses a Client SSL profile. The Client SSL profile is configured with an SSL PEM-formatted certificate and key.

When viewing a virtual server configuration using the TMOS Shell (tmsh), only the configured profile names are listed. To view the certificate in use by the virtual server, you will also need to view the configured Client SSL profile. Unless the profile name indicates that it is configured as a Client SSL profile, you will need to view each of the profile names configured as part of the virtual server configuration. To minimize the number of profiles to review, look for the profiles configured with context clientside.

Note: When searching for server-side configured SSL certificates, you can use context serverside and profile type server-ssl.

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP command line.

Procedures

  • Viewing specific virtual server-configured profiles using the tmsh list command
  • Viewing virtual server-configured profiles using the tmsh show command
  • Simplify mapping using a bash shell script
  • Viewing the cipher list

Using the tmsh list command to view specific virtual server configured profiles

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the BIG-IP command line.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To view a specific virtual server configuration, type the following command: 

    tmsh list /ltm virtual <virtual server name>

  4. To view each context clientside profile configuration, use the following command syntax:

    tmsh list /ltm profile client-ssl <profile name>

    In this command, replace <profile name> with the name of your profile.

    Note: If the named profile is not a Client SSL profile, the system displays the following error message syntax: 01020036:3: The requested ClientSSL Profile (/<partition>/<profile name>) was not found.

Viewing virtual server configured profiles using the tmsh show command

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the BIG-IP command line.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To view a specific virtual server configuration, type the following command:

    tmsh show /ltm virtual <virtual server name>

    In this command, replace <virtual server name> with the virtual server name.

    Note: To view information for all virtual servers, do not specify a virtual server name. However, in deployments with many virtual servers, the command output is extensive.

  4. To restrict the show command output to only the virtual server name and Client SSL profile, type the following command: 

    tmsh show /ltm virtual profiles | egrep 'Ltm::Virtual Server:| Ltm::ClientSSL Profile:'

    In this command the virtual server name is the line proceeding the line labeled Ltm::ClientSSL Profile:, and the Client SSL profile name is listed to the right of Ltm::ClientSSL Profile:.

  5. To view the Client SSL profile configuration, use the following command syntax:

    tmsh list /ltm profile client-ssl <profile name>

    To locate the certificate name, find the line that includes cert at the beginning of the line. In the following example, the configured certificate is example.crt:

    tmsh list /ltm profile client-ssl example_ssl_profile

    ltm profile client-ssl example_ssl_profile {
        app-service none
        cert example.crt
        cert-key-chain {
        ...

Simplify mapping using a bash shell script

To simplify mapping SSL certificates to configured virtual servers, you can use the following Advanced Shell (bash) script. To determine the configured profile certificate name, the script will trace each virtual server for a configured Client SSL profile, and then the Client SSL profile across all configured partitions..

Impact of procedure:  For BIG-IP systems configured with many virtual servers, F5 recommends running this script during low volume times, or on the standby BIG-IP device when applicable.

  1. Log on to the BIG-IP command line.

    Note: Command line access defaults to the bash shell.

  2. Using a text editor, create the cert-mapping file.
  3. Place the following bash script contents in the cert-mapping file:

    #!/bin/bash
    # Search /config and sub directories (partitions) for bigip.conf files
    LIST=`find /config -name bigip.conf |  xargs  awk '$2 == "virtual" {print $3}' 2> /dev/null | sort -u`
    echo "Virtual:          Profile:        Certificate:          Ciphers:"
    echo "__________________________________________________________"
    for VAL in ${LIST}
    do
    PROF=`tmsh show /ltm virtual ${VAL} profiles 2> /dev/null | grep -B 1 " Ltm::ClientSSL Profile:" | cut -d: -f4 | grep -i "[a-z]" | sed s'/ //'g| sort -u`
    test -n "${PROF}" 2>&- && {
    VIRTS=`expr $VIRTS + 1`
    for PCRT in ${PROF}
    do
    CERT=`tmsh list /ltm profile client-ssl ${PCRT} |  awk '$1 == "cert" {print $2}' 2> /dev/null | sort -u`
    test -n "${CERT}" 2>&- && {
    CIPHERS=`tmsh list /ltm profile client-ssl ${PCRT} ciphers | grep ciphers | awk '{print $2}'`
    echo "${VAL} ${PCRT} ${CERT} ${CIPHERS}"
    }
    done
    }
    done
    echo "Virtual server count: ${VIRTS}"

    Note: To alter this script to search for server-ssl profile certificates, replace client-ssl with server-ssl and Ltm::ClientSSL Profile: with Ltm::ServerSSL Profile:.

  4. Close the text editor saving the file cert-mapping that contains the bash script.
  5. To execute the script type the following command:

    bash ./cert-mapping

    Note: The script iterates through the configured virtual servers to identify virtual servers configured with a Client SSL profile. Identified Client SSL profiles are then checked for the configured SSL certificate. The execution time of the script depends on the amount of configured virtual servers and associated virtual server profiles.

    The script produces a line of output that appears similar to the following syntax:

    Virtual: <virtual name> Profile: <client-ssl profile name> Certificate: <client-ssl profile certificate name> Ciphers: <client-ssl profile ciphers>
