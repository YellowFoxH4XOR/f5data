K12508: An external-filer should be configured with a secondary IP address if the filer is multi-homed or has multiple IP addresses

Topic

When a filer is multi-homed or has multiple IP addresses, the ARX external-filer configuration must contain all IP addresses from which the filer may respond. The ARX will only allow responses from IP addresses configured within the external-filer definition. If the ARX receives a response from an address that is not configured in the external-filer definition, ARX drops the response. As a result, connections may time out and services may appear to no longer be available for the filer.

For example, when performing an NFS export probe, if the filer response to a UDP port map request is from an IP address that is not configured in the external-filer definition, the ARX will drop the response. The port map request will time out and the NFS export probe will fail with an error message that appears similar to the following example:

The filer does not support NFS or is unreachable.

Additionally, error messages similar to the following are logged to syslog:

:DNC_LIB-0-WARN-MSG4:: Failed call to null procedure: RPC_TIMEDOUT, prog:100000,vers: 2, filer: 1.1.1.2
:DNC_LIB-0-WARN-MSG4:: Failed UDP call to portmap, err: Connection timed out

Configuring an external-filer with a secondary IP address

Note: For information about the external-filer ip address command, refer to the ARX CLI Reference Guide.

  1. Log in to the ARX CLI.
  2. Enter privileged mode by typing the following command:

    enable

  3. Enable global mode by typing the following command:

    global

  4. Enter the external-filer configuration mode for the desired external-filer using the following command syntax:

    external-filer <name>

  5. Configure the secondary IP address using the following command syntax:

    ip address <nnn.nnn.nnn.nnn> secondary

    For example:

    ip address 1.1.1.2 secondary

  6. If required, repeat step 5 for each additional secondary IP address to be added.
  7. Exit the external-filer configuration mode by typing the following command:

    exit

  8. Exit the global configuration mode by typing the following command:

    global

  9. Display the external-filer configuration by typing the following command syntax:

    show global-config <filer_name>

    The command output will appear similar to the following example:

    ;============================ external-filer =============================
    external-filer testfiler
    ip address 1.1.1.1
    ip address 1.1.1.2 secondary
    exit

Note: For information about an issue removing a secondary IP address from an external-filer configuration, refer to K11526: Attempting to remove a secondary or management IP address from an external-filer configuration may result in the primary address being erroneously removed.
