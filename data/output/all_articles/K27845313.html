Known Issue

The asm control option is not available when you create or update a local traffic policy in the BIG-IP ASM system.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP system licensed and provisioned with BIG-IP ASM.
  • You use the Configuration utility to create or update a local traffic policy and attempt to select the asm control option on the policy's properties page.

Impact

You are unable to create or update a local traffic policy to use the asm control option.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you create or update a local traffic policy, asm does not appear as an option in the Available list for Controls under General Properties.
