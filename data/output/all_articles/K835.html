K835: The admin interface cannot be accelerated by the Packet Velocit ASIC (PVA)

Known Issue
Published

Status

  • BIG-IP 4.X: 4.6.4
Source

Known Issue

You cannot use the PVA to accelerate the admin interface on a BIG-IP switch appliance. If traffic to an accelerated virtual server is routed through the admin interface, corrupted packets will be sent out of the interface onto the network.

F5 Networks recommends that you use the admin interface only to manage BIG-IP. Do not use the admin interface for production traffic or include it in a VLAN that handles production traffic.

F5 Networks Product Development tracked this as CR22599.
