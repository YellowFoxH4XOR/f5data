Description

F5 Access for iOS may fail authentication when attempting to login, if the APM is configured for OAuth.
You may see the following errors in /var/log/apm during these authentication errors:
'OAuth Client: authorization_code is required to get access_token for server'

Users may also see errors similar to the following in the iOS F5 Access app:

 "403 Error The request could not be satisfied This distribution is not configured to allow the http request method that was used for this request."

Environment

  • F5 Access for iOS
  • APM OAuth

Cause

F5 Access iOS expects these OAuth request parameters: 'client_id', 'redirect_uri', 'response_type'

These parameters are required to be configured in the APM AAA OAuth-Request configuration.

If any of these parameters are missing in the configuration, the F5 Access application never sends a request to the authentication URI to obtain an authorization code and the user will get an authentication error.

Recommended Actions

Ensure the APM AAA OAuth-Request configuration contains these three parameters:  'client_id', 'redirect_uri', 'response_type'

You can verify your APM AAA OAuth-Request configuration by navigating to:

Access  ››  Federation : OAuth Client / Resource Server : Request .

Select your OAuth Request configuration and ensure 'client_id', 'redirect_uri', and 'response_type' are added under 'Request Parameters'
