K23220713: DNS pool cannot be open with ''Cannot read properties of undefined (reading 'Name')'' error

Type
Support Solution
Published
2022-06-21
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K23220713
Description

On BIG-IQ when browsing to a DNS pool list and opening a pool for editing the below error message is presented:

"Cannot read properties of undefined (reading 'Name')"

Environment

1. BIG-IQ
2. DNS configuration including DNS pools discovered.

Cause

Issue is caused by an unsupported custom monitor attached to the pool. 

To see which monitor is in use on the pool use:

# restcurl /cm/dns/working-config/pool/a/ | grep healthMonitor 

Recommended Actions

Use the below command to replace the custom monitor with a supported 'bigip' monitor:

restcurl -s -u admin:admin -X PATCH cm/dns/working-config/pool/a/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx -d '{"healthMonitors":"/Common/bigip"}'

where xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx is a DNS pool ID of the specific problematic pool.

Additional Information

Currently the only monitor types supported are ['/Common/bigip', '/Common/gateway_icmp', '/Common/gtp', '/Common/http', '/Common/http_head_f5', '/Common/https', '/Common/https_head_f5', '/Common/tcp', '/Common/tcp_half_open', '/Common/udp']

Bug ID1112869 raised to support custom monitor.
