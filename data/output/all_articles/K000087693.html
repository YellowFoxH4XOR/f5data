K000087693: Disable OAuth for certain locations

Type
Support Solution
Published
2021-03-29
Updated
2021-11-23
Source
https://my.f5.com/manage/s/article/K000087693

Description:

You need to disable OAuth for certain locations  

Environment:

  • Nginx Plus
  • OAuth

Cause:

None

Recommended Actions:

Update the location context in the configuration. For information refer to nginx documntation .

For example:

location / {
   # ....
   auth_jwt "" token=$session_jwt;
   auth_jwt_key_request /_jwks_uri; # Enable when using URL
}

You can set in that location which will disable authorization.

auth_jwt off;
