K000153196: Unable to Open Security ›› Bot Defense: Bot Defense Profiles

Type
Support Solution
Published
2025-08-28
Updated
2025-08-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000153196

Description

When there is a high number of Bot Defense profiles with numerous staged signatures configured, and a user attempts to navigate to Security ›› Bot Defense: Bot Defense Profiles, the GUI fails to load. From the browser console logs, an HTTP 500 Server Error is observed for the endpoint /mgmt/tm/security/bot-defense/profile.


Environment

ASM
GUI
BoT defense profiles


Cause

ID2034933  


Recommended Actions

At the time of the creation of this article, there is no fix available for ID2034933.

As a workaround, set all staged signatures to "None" for all Bot Defense profiles.
