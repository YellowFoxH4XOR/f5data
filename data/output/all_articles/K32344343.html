Description

iControl REST API can be used to retrieve APM OAuth access token details from non-default APM OAuth DB, however, without specifying an APM OAuth database using the "db-instance" parameter the default APM OAuth database will be queried. The following is an example iControl REST API URI that will retrieve access token details from a custom APM OAuth db.

https://bigip.example.com/mgmt/tm/apm/oauth/token-details?options="db-instance"+"/Common/custom-oauth-db"

Note: Comma separated list of parameters are allowed, e.g. https://bigip.example.com/mgmt/tm/apm/oauth/token-details?options="db-instance","/Common/custom-oauth-db"

Environment

  • APM as OAuth Server
  • iControl REST API
  • Data retrieval command such as curl or a web browser

Cause

None

Recommended Actions

This is expected behavior.

Additional Information

Additional parameters can be included in the iControl REST API URI string to narrow the search criteria. The rule-of-thumb is if the parameters successfully return desired results via a tmsh command then the corresponding iControl REST API URI may return the same results. Below are some examples of tmsh commands translated to iControl REST API URIs.

Note: F5 Support does not design iControl configuratiions.  If you are in need of comprehensive assistance configuring iControl to best work for your environment, F5 Professional Services can assist.



# Return active APM OAuth access token details
tmsh list apm oauth token-details db-instance /Common/custom-oauth-db
https://bigip.example.com/mgmt/tm/apm/oauth/token-details?options="db-instance"+"/Common/custom-oauth-db"

# Return active APM OAuth access token details issued to a client id 
tmsh list apm oauth token-details db-instance /Common/custom-oauth-db client-id f8f31c2502f8d64c84203553597b0050568644a31d063d5c
https://bigip.example.com/mgmt/tm/apm/oauth/token-details?options="db-instance","/Common/custom-oauth-db","client-id","f8f31c2502f8d64c84203553597b0050568644a31d063d5c"

# Return active APM OAuth access token details issued to a user
tmsh list apm oauth token-details db-instance /Common/custom-oauth-db user-id /Common/oauth_access_policy.user1

Note: Not all tmsh commands will translate into iControl REST API URIs. Trial and error is the only known means to discover which URI works and which does not. If one or more tmsh command[s] do not translate into valid iControl REST API URIs and you want/require them to do so then report the desired iControl REST API URI[s] to F5 Support. Include a brief description as to why the iControl REST API URIs are wanted/needed.
