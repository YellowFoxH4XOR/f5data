K000151457: Migrating BIG-IP Applience UCS file to F5OS Tenant does not remove the trunk configuration from the tenant bigip_base.conf file

Type
Support Solution
Published
2025-05-21
Updated
2025-07-21
Applies to
  • F5OS
  • BIG-IP
  • F5OS-A: 1.8.0
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000151457

Description

When migrating an appliance UCS file to an F5OS tenant using the platform-migrate option, the configuration fails to load with an similar to the following.

 

01070307:3: Invalid interface <interface number. Unexpected Error: Validating configuration process failed.

Environment

  • Platform migration
  • BIG-IP Appliance
  • F5OS tenant

Cause

The platform-migrate command doesn't fully support migration from a BIG-IP appliance to a F5OS tenant.  See K82540512 for additional details.

Recommended Actions

Manually edit the bigip_base.conf file to remove the trunk configuration.
