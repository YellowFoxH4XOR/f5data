Known Issue

The BIG-IP APM apd process may core when receiving a Security Assertion Markup Language (SAML) assertion without the NameID Format attribute.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured as a SAML Service Provider (SP)
  • A BIG-IP APM External Identity Provider (IdP) connector is configured with Single Logout (SLO)
  • The SAML assertion from the remote IdP does not include the Format attribute of the NameID element

Impact

The BIG-IP system does not accept the SAML assertion. As a result, SAML communication does not work properly.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H451460 on the Diagnostics > Identified > High screen.
  • The BIG-IP APM system generates an apd core file to the /shared/core directory.
  • The BIG-IP APM system temporarily stops processing traffic while the apd process restarts.
  • In the /var/log/apm file, you observe messages that appear similar to the following example:

    notice apd[8933]: 01490000:5: ** SIGSEGV **
    notice apd[8933]: 01490000:5: EIP=0x58B822C3

Workaround

To work around this issue, you can configure the remote IdP to include the NameID Format attribute in the SAML assertions.
