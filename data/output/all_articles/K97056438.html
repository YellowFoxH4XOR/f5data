Known Issue

BIG-IP Edge Client may fail to install on Windows 7.

This issue occurs when all of the following conditions are met:

  • You are running the Windows 7 operating system.
  • You attempt to install BIG-IP Edge Client when your device does not have access to the Internet.

Impact

BIG-IP Edge Client fails to install.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to install BIG-IP Edge Client, the installation aborts with an error message that appears similar to the following example:

    Error: BIG-IP Edge Client Setup Wizard ended prematurely. Client not installed successfully.

  • BIG-IP Edge Client installs successfully when your device has Internet access.

Resolution

Status

F5 Product Development has assigned ID 599392 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can temporarily grant your device Internet access while installing BIG-IP Edge Client.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
