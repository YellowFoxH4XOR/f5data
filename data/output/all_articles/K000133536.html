Description

You would like to know how the redirect iRule from http to https works.

Environment

  • BIG IP LTM

Cause

None

Recommended Actions

The redirect iRule which its build in as part of the built in iRules we have in the system: _sys_https_redirect iRule

How does it works?

The BIG IP LTM have separated connection between the Client's side and the Backend servers side (pool members) - like two 'legs' which each one is communicating with one side.

From client side we have the connection with HTTP (Port 80), while the response code will return 302, at this point the Client will change the port from HTTP (80) to HTTPS (443), and will continue with secured traffic.
