Known Issue

This is the result of a known issue. Uploading files to a Microsoft SharePoint server fails if the server begins transmitting the response before the request has been fully forwarded to the server. This error occurs when files are uploaded through a BIG-IP LTM virtual server to a SharePoint server. The BIG-IP LTM system passes a POST request from the client to the SharePoint server, and based on the content length header the server identifies how much data to expect. Ideally, the server waits until it receives all the data, then sends an HTTP 200 OK response. However, in some cases the SharePoint server sends the HTTP 200 OK message before the POST is complete. As a result, the BIG-IP LTM system closes the connection and logs the following error to /var/log/ltm file:

Nov 11 08:58:24 tmm tmm[1970]: 011f0005:3: http_process_state_early_
00continue - Invalid action EV_SENT during ST_HTTP_EARLY_100CONTINUE

F5 Product Development tracked this issue as CR57199 and CR57569 and it was fixed in BIG-IP LTM 9.1.2 and 9.2.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.
