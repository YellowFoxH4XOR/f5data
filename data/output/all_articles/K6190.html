Topic

The BIG-IP ASM Auto-Accept and Policy Builder features generate a detailed policy made of objects and flows, and match every object and flow with the corresponding parameters and values seen in the traffic passed through the BIG-IP ASM.

The BIG-IP ASM 9.2 through 9.3 use the Auto-Accept feature, and versions 9.4 and later use the Policy Builder feature.

Each time these features are performed in BIG-IP ASM 9.2 through 9.3, a log file is created in the /ts/log directory with a name in the following format:

pb-##-date-time.log

Each time these features are performed in BIG-IP ASM 9.4 and later, Policy Builder logging is generated to the following log files in the /ts/log/policy_builder directory:

pb-x.log
pb-negative-x.log
