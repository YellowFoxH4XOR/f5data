Topic

When you attempt to connect to the BIG-IP Configuration utility using Netscape version 4.61 or version 4.7, you may receive one of the following errors:

Netscape and this server cannot communicate securely because they have 
no common encryption algorithms.

Or:

Netscape has encountered bad data from the server

This is caused by a Netscape Navigator 4.61 and 4.7 certificate error. This error can occur if you have installed a new BIG-IP and Netscape is attempting to use a cached certificate.

If you receive this error, use the following procedure to get a new certificate:

  1. Click the Netscape Security icon.
  2. Choose Certificates.
  3. Click Web Sites.
  4. Delete the existing BIG-IP certificate.
  5. Connect to the BIG-IP Controller and accept the new certificate.
