Known Issue

Important: This issue only affects 8400 and 8800 systems built after February 2008.

This is the result of a known issue. Some 8400 and 8800 systems may not allow booting from a USB device, such as a USB-CD-ROM drive or USB memory stick. This issue only affects 8400 and 8800 systems built with motherboard part numbers MOB-0019-07, MOB-0019-08, and MOB-0019-09.

You can view the part number of the motherboard by typing the following command:

bigpipe platform show | grep MOB

Output will appear similar to the following example:

Host board serial: 05120981100028 part: MOB-0019-07 REV A

F5 Product Development tracked this issue as CR111608 and a BIOS update has been released.

Note: For more information about obtaining and installing the the BIOS update refer to K10590: BIG-IP 8400/8800 platform BIOS Update.

Workaround

You can work around this issue and allow a BIG-IP 8400 or 8800 system to boot using a USB CD-ROM or memory stick device. To do so, perform the following procedure:

  1. If the system is not operational, allow the system to fully boot.
  2. Connect the target USB boot device (CD-ROM or memory device) to the system.
  3. Connect a terminal emulator to the console port (DB-9 null modem cable) on the front of the system.
  4. Display the SCCP menu by simultaneously pressing and holding the Shift, ESC, and 9 keys.

    Note: The command being sent is: ESC (.

    You will be presented with a screen that appears similar to the following example:

    [hostconsh] Command Menu:
    1 --- Connect to Host subsystem console
    2 --- Select Host subsystem boot mode: boot from local drive
    3 --- Select Host subsystem boot mode: netboot from SCCP
    4 --- Select Host subsystem boot mode: netboot from external server
    5 --- Reboot Host subsystem (sends reboot command)
    6 --- Halt Host subsystem (sends halt command)
    7 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
    8 --- Reboot SCCP subsystem (issues hardware reset--USE WITH CARE!)
    9 --- Halt SCCP subsystem (issues hardware shutdown--USE WITH CARE!)
    Q --- Exit Host subsystem console shell
    [hostconsh] Enter command:
  5. Reboot the host and redirect the serial connection to the host, using the following options:
    • Press 7 to Reset the Host.
    • Press y when asked if you want to proceed.
    • Press 1 when the Command Menu is presented again.

    This procedure allows you to reboot or reset the host portion of the system and then connect to the host while it is in the process of booting.

  6. Press the DEL key.

    The BIOS SETUP screen will display.

    Note: Some terminal emulators do not correctly forward key-strokes over the serial connection. Correct operation has been observed using HyperTerminal.
  7. Click the left arrow button once to enter the EXIT screen.
  8. Click the arrow down button once to enter the LOAD OPTIMAL DEFAULTS screen.

    You should see a screen that appears similar to the following example:

  9. Press the Enter key to Load Optimal Defaults.
  10. When prompted with the Save configuration changes and exit setup? message, choose Ok.
