1The actual versions of EUD software installed will depend on the hardware product type the release is installed on. Additionally, after a higher version of EUD software is installed, that higher EUD version will persist even if you boot back to a slot running an earlier release.

2BIG-IP AAM has reached End of Life (EoL) and is no longer supported.

3In BIG-IP 13.0.0 and later, F5 no longer includes the EUD images in the base .iso image file. You must either install the latest EUD package from a BIG-IP-x.y.z.n.n.nnn-RECOVERY.iso image or download the EUD image of your specific hardware product from the Platform / EUD product page of the F5 Downloads site. For more information, refer to K03203114: Multiple BIG-IP .iso images are available (13.x and later).

4BIG-IP software runs as a tenant on the VELOS and rSeries hardware products. For more information about deploying the BIG-IP system as a tenant on the VELOS or rSeries hardware products, refer to the Tenant Management chapter of either the VELOS Systems: Administration and Configuration or the F5 rSeries Systems: Administration and Configuration manual. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation. Note that the AOM firmware for the VELOS and rSeries hardware products are part of F5OS-A/C software releases and not part of BIG-IP software releases. For information about the AOM firmware version, refer to K86001294: F5OS hardware/software support matrix.
