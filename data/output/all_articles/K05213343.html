Description

Upon upgrade the configuration fails to load with an error such as any of these:

  • 01020036:3: The requested profile (/Common/wam-tcp-lan-optimized) was not found.
  • 01020036:3: The requested profile (/Common/wam-tcp-wan-optimized) was not found.
  • 01020036:3: The requested parent profile (/Common/wam-tcp-lan-optimized) was not found.
  • 01020036:3: The requested parent profile (/Common/wam-tcp-wan-optimized) was not found.

Environment

  • BIG-IP 16.0.0
  • upgrading from 13.1.0 through 15.1.x to 16.0.0
  • previous version configuration utilizes the default profile wam-tcp-lan-optimized and/or wam-tcp-wan-optimized

Cause

The default profiles wam-tcp-lan-optimized and wam-tcp-wan-optimized no longer exist on the 16.0.0 system.

Bug ID 941961: Upgrading system using WAM TCP profiles may prevent the configuration from loading

Recommended Actions

Follow the 'Workaround' section provided in ID 941961.
