Description

While attempting to get information from F5 VCMP system via LLDP, MAC Address field is empty in the LLDPDU
 

Environment

  • LLDP neighbors
  • BIG-IP LTM
  • Hardware Platform

Cause

The MAC address is missing by design

Sample outbound F5 LLDPDU:

10:42:11.375967 LLDP, length 368
    Chassis ID TLV (1), length 16
      Subtype Local (7): <Serial Number redacted>
      0x0000:  0766 352d 6872 7979 2d7a 656d 7920 2020
    Port ID TLV (2), length 4
      Subtype Interface Name (5): 1.1
      0x0000:  0531 2e31
    Time to Live TLV (3), length 2: TTL 40s
      0x0000:  0028
           ...


Per the IEEE standard, the MAC address can be found in either the Chassis ID or the Port ID, however that is not a required field.  
In this case the Chassis ID is the subtype Local and the Port ID is the subtype interface name:

Chassis ID TLV (1), length 16
      Subtype Local (7): <Serial Number redacted>
      0x0000:  0766 352d 6872 7979 2d7a 656d 7920 2020
Port ID TLV (2), length 4
      Subtype Interface Name (5): 1.1 
      0x0000:  0531 2e31

 

Recommended Actions

None, the MAC address can't be acquired using LLDPDUs
