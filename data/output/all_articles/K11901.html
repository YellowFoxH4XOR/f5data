Known Issue

This is the result of a known issue. Using the Force Full Sync option from the Failover : Settings menu on the active node will fail to synchronize the changes to the standby unit.

F5 Networks Product Development is tracking this issue as ID 317787 (formerly CR142663-1) and as ID 327727 (formerly CR142663).

This issue was fixed in cumulative HF-70-1 issued for FirePass version 7.0.0 and in cumulative HF-610-3-1 issued for FirePass version 6.1.0 . You may download these hotfixes or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To work around this issue, use the Force Full Sync option from the standby node.
