Issue

Error Message

err mcpd[<PID>]: 01071c34:3: The requested member (<Interface.Number>) is already configured as a member of VLAN (/<Partition>/<VLAN Name>) with tag (<VLAN Tag Number>). A member can belong to only one VLAN for a given tag.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <Interface.Number> is the identified interface number.
  • <Partition> is the partition on which the configuration resides.
  • <VLAN Name> is the name of the VLAN to which the identified interface belongs.
  • <VLAN Tag Number> is the VLAN Tag number which is already assigned to the identified interface.

For example:

err mcpd[9430]: 01071c34:3: The requested member (1.1) is already configured as a member of VLAN (/Common/My_VLAN) with tag (4096). A member can belong to only one VLAN for a given tag.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The system attempts to assign the same virtual wire interface, either tagged or untagged, to more than one VLAN.

Impact

None

Recommended Actions

Do not attempt to add the same interface to more than one VLAN.
