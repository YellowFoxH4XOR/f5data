K000157917: Managed BIG-IPs in the standby BIG-IQ are always green

Type
Support Solution
Published
2025-11-23
Updated
2025-11-23
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000157917

Description

You notice that managed BIG-IPs in the standby BIG-IQ is always green but in the active BIG-IQ you can see some devices are red (down or unavailable) or yellow status (certificate expired or going to expire). You wonder why there is a mismatch in status.

Environment

  • BIG-IQ HA
  • Managed BIG-IPs

Cause

Expected behavior.

Recommended Actions

Standby BIG-IQ will always show managed BIG-IPs green because it is not polling or doing any data collection. Therefore it will always show green.

None
