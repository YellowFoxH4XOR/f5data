Known Issue

This is the result of a known issue. When you use the tmsh utility to create topology records, the BIG-IP GTM system displays misleading error messages when you omit a parameter value in the LDNS portion of the record. For example, if you omit the value for the parameter continent, the system presents the following error message:

root@combo54(Active)(tmos.gtm.topology)# create ldns: continent
01070242:3: Topology record contains bad server type: 15
root@combo54(Active)(tmos.gtm.topology)# create ldns: continent
01070242:3: Topology record contains bad server type: 108

F5 Product Development tracked this issue as ID 222018 (formerly CR108969), and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

To work around this issue, specify all parameters for the LDNS portion of the topology record. For information about creating topology records using the tmsh shell, type the tmsh help /gtm topology command.
