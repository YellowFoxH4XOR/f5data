Description

Error Message: Database error (13), Cannot update_indexes/checkpoint DB object class:clientssl_certkeychain status:13

Environment

  • BIG-IP
  • Upgrade from pre-v14.0.0 versions to v14.0.x
  • SSL Profiles

Cause

Bug ID 741599: After upgrade, Client SSL profile may have extra cert-key-chain structure

Recommended Actions

To work around this issue, set the 'proxy-ca-cert' and 'proxy-ca-key' attributes values back to their default values.

  1. Log into the Command Line Interface.
  2. Access the TMOS shell by typing the following command:
    tmsh
  3. delete all references to the 'CA_default' cert-key-chain by typing the following command:
    modify ltm profile client-ssl all cert-key-chain delete { CA_default }
  4. Verify that the references are gone (the command should return nothing) by typing the following command:
    list ltm profile client-ssl all cert-key-chain | grep CA_default
  5. Load the configuration by typing the following command:
    save sys config
