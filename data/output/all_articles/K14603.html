Known Issue

Using the Configuration utility to add a remote device to the device trust may fail.

This issue occurs when all of the following conditions are met:

  • The remote device certificate contains an ampersand character (&) in any of the certificate properties.
  • You attempt to add the remote device to the device trust using the Device Management > Device Trust > Peer List menu item in the Configuration utility.

Impact

You are unable to add the peer device to the device trust using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You are unable to retrieve device information from the remote device in order to complete the process of adding it to the device trust.
  • When you click Retrieve Device Information using the Configuration utility of the host, you see an error message similar to the following example:

    java.io.IOException: Could not read response from server: ParseError at [row,col]:[1,1100] Message: The entity name must immediately follow the '&' in the entity reference.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to add the remote device to the device trust. To do so, perform the following procedure:

Alternatively, you can avoid this issue by eliminating the ampersand characters in the remote device certificate's properties before adding the remote device into the device trust.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To add the desired remote peer to the trust domain configuration, use the following command syntax:

    modify /cm trust-domain <Domain-Trust-Name> [non-ca-devices|ca-devices] add { <Remote-Peer-IP> } name <Remote-Peer-Hostname> username <Remote-Peer-Administrator-Username> password <Remote-Peer-Administrator-Password>

    For example, to add a peer with the 10.10.10.101 IP address, bigip.lab1.local host name, ThePasswd user name admin password, and as an authority device to the Root domain trust name, you would type the following command:

    modify /cm trust-domain Root ca-devices add { 10.10.10.101 } name bigip.lab1.local username admin password ThePasswd

  3. Save the configuration by typing the following command:

    save /sys config

  4. To exit the tmsh utility, type the following command:

    quit
