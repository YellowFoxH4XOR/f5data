Topic

Currently, the FirePass controller does not support sending the system logs to multiple Syslog servers. The Remote host field in the System Logs section of the Device Management: Maintenance: Logs page permits only a single name or IP address.

F5 Networks Product Development is tracking an enhancement for this issue as ID 265716 (Formerly CR30202).
