Description

AS3 fails to post to Big-IP due to timeouts

 

Environment

Big-IP REST AS3

 

Cause

Timeouts causing the AS3 declaration to fail. Messages observed in the /var/log/ltm:

  • warning: [RestOperationNetworkHandler] request timed out, destroying socket...:
  • info: message=[RestOperationNetworkHandler] request timeout., stack=Error: [RestOperationNetworkHandler] request timeout.

Recommended Actions

Increase the timeout value for the following three services:

  • restnoded.timeout
  • restjavad.timeout
  • icrd.timeout

The default timeout value is set to 60 seconds for these services.

Increase the timeouts to 180 seconds to resolve the issue by doing the following.

  1. SSH to log into the Advanced Shell (bash) of the BIG-IP
  2. Run the following commands:
    1. # tmsh modify sys db icrd.timeout value 180
    2. # tmsh modify sys db restjavad.timeout value 180
    3. # tmsh modify sys db restnoded.timeout value 180
    4. # tmsh save sys config
    5. # tmsh restart sys service restjavad
    6. # tmsh restart sys service restnoded

 

Steps a-c make the changes, step d saves them, and steps e and f are required for the changes to take effect.
