Known Issue

This is the result of a known issue. When the pvad process queries for an IP address that does not exist in the Linux kernel ARP cache, the BIG-IP system may log an error message in the /var/log/ltm file that appears similar to the following example:

pvad[PID]: 01130005:3: ../Nexthop.cpp:244 - SIOCGARP error for <IP_address> No such device or address

This error message is benign, and you can safely ignore it.

F5 Product Development is tracking this issue as ID 337838.

Note: For information about platforms that contain the Packet Velocity ASIC (PVA) hardware acceleration chip, refer to K4832: Overview of PVA Acceleration.

Workaround

You can filter off this log message by performing the following procedure that applies to your version:

BIG-IP 9.4.2 - 10.2.4

  1. Log in to the BIG-IP command line.
  2. To add the filters to syslog-ng, type the following command:

    Note: You should type the following bigpipe command as a single command; it should not contain line breaks.

    bigpipe syslog include \"filter f_local0 \{ facility\(local0\) and not match\(SIOCGARP\)\; \}\; filter f_local4 \{ facility\(local0\) and not match\(SIOCGARP\)\; \}\;\"

    Important: The bigpipe syslog include command overwrites any previous syslog include entry, if configured. To add multiple elements to the syslog-ng configuration, you must construct a single include command following the above example.

  3. To save the settings, type the following command:

    bigpipe save

BIG-IP 9.0.0 through 9.4.1

  1. Log in to the BIG-IP command line.
  2. Change directories to the /etc/syslog-ng directory by typing the following command:

    cd /etc/syslog-ng

  3. To create a backup copy of the syslog-ng.conf file, type the following command:

    cp syslog-ng.conf syslog-ng.conf.original

  4. Using a text editor, edit the syslog-ng.conf file.
  5. Add the and not match(SIOCGARP) statement to the filter f_local0 and filter f_local4 stanzas.

    For example:

    # local0.* /var/log/ltm
    filter f_local0 {
    facility(local0) and level(info..emerg) and not match(SIOCGARP);
    };

    # local4.* /var/log/ltm
    filter f_local4 {
    facility(local4) and level(notice..emerg) and not match(SIOCGARP);
    };

  6. To restart the syslog-ng daemon, type the following command:

    bigstart restart syslog-ng
