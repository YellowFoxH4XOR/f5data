K63874020: Modify Traffic Matching Criteria port from 'any' to another destination-port-list can prevent a virtual server from processing traffic

Type
Support Solution
Published
2023-10-17
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K63874020

Description

After change a Traffic Matching Criteria port from 'any' to another destination-port-list, the virtual server stop to process traffic.

Environment

  • BIG-IP LTM version refer to Bug ID 997929.
  • Traffic Matching Criteria
  • Destination-port-list
  • Virtual server

Cause

This is caused by Bug ID 997929.

Recommended Actions

To solve the issue, you need contact F5 support to request Engineering Hotfix or upgrade to a fixed software version to permanently fix the issue. Or use below temporary workaround:

  1. Restart tmm daemon:

#tmsh restart sys service tmm

Note: Restart tmm will temporary make device stop process traffic. It need to be done in maintain window and when the device is on standby mode.
