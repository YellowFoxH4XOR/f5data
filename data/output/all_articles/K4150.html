Topic

The iQuery protocol is used to exchange metrics and status information between BIG-IP and 3-DNS products. iQuery communications are blowfish encrypted, but iQuery does not use an authentication mechanism. Additionally, if you do not configure keys for iQuery, the protocol will operate in an unencrypted mode.

If hostile users are able to obtain the external address of your BIG-IP system, they can connect to your BIG-IP using their own 3-DNS and auto-discover all of the virtual servers configured on your BIG-IP system. This is not considered an additional security risk if your virtual servers exist on the external network. Virtual servers that you have configured on internal networks will also be discovered, which would reveal your internal addressing.

You can minimize iQuery security risks by disabling or restricting access to big3d. If you are not using 3-DNS in your network, you can prevent all iQuery communications by disabling big3d. If you are using 3-DNS in your network, you can restrict access to big3d by editing the hosts.allow file.

Disabling big3d

To disable big3d and prevent all iQuery communications, perform the following steps:

  1. Log in to the command line.

  2. Stop big3d by typing the following command:

    bigstart stop big3d

  3. Stop big3dshim by typing the following command:

    bigstart stop big3dshim

  4. Remove big3d from the bigstart boot group by typing the following command:

    bigstart remove big3d

  5. Remove big3dshim from the bigstart boot group by typing the following command:

    bigstart remove big3dshim

  6. Remove big3d from the bigstart default group by typing the following command:

    bigstart remove --default big3d

  7. Remove big3dshim from the bigstart default group by typing the following command:

    bigstart remove --default big3dshim

The big3d and big3dshim processes are now stopped and will not start again unless you run the commands manually or reverse these steps.

Restricting access to big3d

To restrict the IP addresses that have access to big3d and big3dshim on your BIG-IP system, perform the following steps:

  1. Log in to the command line.

  2. Using a text editor, such as vi or pico, edit the /etc/hosts.allow file.

    If the following line exists in the file, remove it:

    big3d: ALL

  3. Add a line to the file to limit access to big3d using the following syntax:

    big3d: <address> <address> <address>

  4. Replace each <address> with the IP address from which you want to allow access to big3d. Separate each address with a space.

    Note: You must include the addresses for any BIG-IP GTM system that needs to communicate with the BIG-IP system.

  5. Add a line to the file to limit access to big3dshim using the following syntax:

    big3dshim: <address> <address> <address>

    Replace each <address> with the IP address from which you want to allow access to big3d. Separate each address with a space.

    Note: You must include the addresses for any BIG-IP GTM system that needs to communicate with the BIG-IP system.

  6. Save the file and exit the editor.

Access to big3d and big3dshim on your BIG-IP system is now restricted to the IP addresses that you specified.
