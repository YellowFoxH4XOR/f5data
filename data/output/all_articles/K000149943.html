K000149943: Enabling SNAT on virtual server causes connection timeout error

Type
Support Solution
Published
2025-02-24
Updated
2025-02-26
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000149943

Description

 

After enabling SNAT (Source Network Address Translation) A virtual server was not functioning as expected, resulting in a "connection timed out" error.

 

Environment

 

  • Big-IP LTM in DSC
  • SNAT enabled on virtual server

 

Cause

 

The root cause of the issue was identified as the pool member setting allow-snat being set to "no." This configuration prevented SNAT from functioning correctly for the virtual server.

 

Recommended Actions

 

Verify the current configuration of the pool members associated with the affected virtual server.

Ensure that the allow-snat setting for all relevant pool members is set to "yes."

  1. Navigate to Local Traffic > Pools> Select pool associated with virtual server
  2. Change configuration from basic to advanced
  3. Change allow SNAT to "yes"

After making this change, test connectivity to confirm that the virtual server is functioning as expected.
