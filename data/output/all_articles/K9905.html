Topic

When changes are made to the priority of a Multiple Spanning Tree Protocol (MSTP) instance other than instance 0 (zero), the BIG-IP system does not initiate a spanning tree topology update. This behavior is by design and in accordance with the IEEE 802.1Q-2003 specification. The IEEE 802.1Q-2003 specification for local and metropolitan area networks, section 12.8.1.3.4, only specifies what steps occur when changes are made to STP instance 0, and the reason changes to instance 0 initiate a topology change update.

If you want to change the priority for an MSTP instance other than instance 0, and initiate an STP topology message so that the bridge with the lowest priority will take over as the regional root bridge, you must either disable and then re-enable the link associated with the instance, or restart the stpd process. To do so, perform one of the following procedures:

  • Disabling a link
  • Restarting the stpd process 

Disabling a link

You can disable a link using either the Configuration utility or the command line. To do so, perform one of the following procedures:

Disabling a link using the Configuration utility

To disable a link using the Configuration utility, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Select Network.
  3. Select Interfaces.
  4. Select the interface or interfaces (if you are running MSTP on a trunk) by selecting the check box next to the interface(s).
  5. Click Disable.
  6. Verify that the interface(s) are disabled.
  7. Re-enable the disabled interface(s) by selecting the check box next to the interface(s).
  8. Click Enable.

Disabling a link using the command line

To disable a link using the command line, perform the following procedure:

  1. Log in to the command line.
  2. Disable the interface by typing the following command:

    bigpipe interface <interface number> disable

    For multiple interfaces, you would type the following command:

    bigpipe interface <int #1> <int #2> disable
     
  3. Verify that the selected interface is disabled by typing the following command:

    bigpipe interface <interface number> show

    For multiple interfaces, you would type the following command:

    bigpipe interface <int #1> <int #2> show
  4. Re-enable the interface by typing the following command:

    bigpipe interface <interface number> enable

    For multiple interfaces, you would type the following command:

    bigpipe interface <int #1> <int #2> enable


Restarting the stpd process

To restart the stpd process, type the following command from the command line:

bigstart restart stpd
