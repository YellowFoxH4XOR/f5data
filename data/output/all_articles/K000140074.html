Description:

After adding WAF policy to the Virtual server, application doesn't load. monitoring server was configured behind F5 VS. After adding the WAF to the virtual server, main page loads properly. However. when we click on any application icon on the page, It just shows as opening an App in new window but never loads.

Environment:

  • BIG-IP AWAF
  • ASM Policy
  • WebSocket profile
  • Application doesn't load

Cause:

Issue is due to miss configuration

Recommended Actions:

From the collected packet captures we could see web socket traffic to the Virtual server. However, there is no WebSocket profile attached. All of the WebSocket traffic was not sent to the server. 

Configuring Websocket profiles to the Virtual server on client and server side fixed the issue.
