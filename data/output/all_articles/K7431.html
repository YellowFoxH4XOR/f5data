Known Issue

This is the result of a known issue. When the Web-based Distributed Authoring and Versioning (WebDAV) functionality is configured, the WebDAV password is not synchronized across failover pairs. The FirePass controllers do synchronize the setting that turns on WebDAV, and the WebDAV content.

Note: This Solution applies to only a FirePass high availability configuration. In a FirePass cluster configuration, you should enable WebDAV on only the primary cluster node. The primary cluster node synchronizes the WebDAV sandbox content to the secondary cluster nodes. If you upload WebDAV content to a secondary cluster node, that content will not be synchronized to the other cluster nodes. For this reason, the FirePass controller does not synchronize the WebDAV password that is configured on the primary cluster node to the secondary cluster nodes.

The WebDAV customization feature is activated by selecting the Allow WebDAV sandbox customization check box on the Global Customization tab of the Device Management: Customization page. When this box is selected, a password field appears with text indicating that a WebDAV password is required. If you enter a password (8-characters, minimum) and click the Update button, the system displays additional hyperlinked text with the following message:

Your WebDAV configuration has changed. To apply the new settings click here to restart FirePass controller services.

Clicking the hyperlink will restart services and activate the WebDAV feature, but only for the FirePass controller on which this configuration was performed. The only portion of this configuration that is synchronized from the active controller to stand-by controller is the check box setting. The password will not be synchronized, and the system that is currently the standby controller will continue to display the message stating that a WebDAV password is required, until that controller is configured with a WebDAV password.

F5 Product Development tracked this issue as CR79077 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by configuring a WebDAV password separately on each FirePass controller in the failover pair. Normally, you should not make configuration changes on the stand-by unit of a failover pair. However, the WebDAV password can be safely configured on a standby unit, along with performing the Services restart.
