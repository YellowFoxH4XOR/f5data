Known Issue

The BIG-IP system drops Dynamic Host Configuration Protocol (DHCP) renew ACK messages from server when configured in forwarding mode.

This issue occurs when all of the following conditions are met:

  • The BIG IP PEM system is configured in forwarding mode.
  • DHCP clients send unicast renewal messages to the DHCP server.

Impact

Unicast DHCP renewal requests do not receive ACK messages responses. DHCP clients send broadcast renewal messages and receive ACK messages from servers.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the BIG-IP system is configured in forwarding mode, the BIG-IP system drops the renewal ACK message from the server in response to unicast renewal messages from DHCP clients.
