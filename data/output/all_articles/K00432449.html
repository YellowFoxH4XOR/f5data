Known Issue

The BIG-IP system may trigger the iRules HTML_TAG_MATCHED event for non-matching tags.

This issue occurs when one of the following conditions is met:

  • The last HTML tag in the HTTP packet data contains event handler attributes such as onClick.
  • One tag in the HTTP packet data matches both the Remove Tag and Raise Event on Tag HTML rules.

    Note: If the latter condition occurs, the system removes the tag and triggers the HTML_TAG_MATCHED event for the last tag in the same HTTP data.

Impact

The system triggers the iRules HTML_TAG_MATCHED event under the wrong conditions.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system erroneously runs iRules code.
  • A Raise Event on Tag HTML rule does not raise the HTML_TAG_MATCHED event when the BIG-IP system also removes a tag for a Remove Tag HTML rule.

Workaround

To work around this issue, you can modify the existing iRule so that the system verifies the matched tag before running the iRule. To do so, perform the following procedure:

Note: There is no workaround for the failure of a Raise Event on Tag HTML rule to raise the HTML_TAG_MATCHED event when the BIG-IP system also removes a tag for a Remove Tag HTML rule.

Impact of workaround: The impact of the suggested workaround depend on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your environment.

The following example shows a configuration with an HTML rule configured for an HTML Profile:

ltm html-rule tag-raise-event example_rule {
    match {
        attribute-name class
        attribute-value raise
        tag-name a
    }
}

Additionally, the configuration contains an iRule with an HTML_TAG_MATCHED event similar to the following example:

when HTML_TAG_MATCHED {  
    log local0. "Match Found"
}

In this situation, you can change the existing iRule to verify the matching condition in the HTML rule before running the iRule.

For example:

when HTML_TAG_MATCHED {
    if { [HTML::tag name] equals "a" && [HTML::tag attribute class] equals "raise" } {
    log local0. "Match Found"
    }
}
