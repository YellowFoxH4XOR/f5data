Important: F5 Networks recommends that you create SSL keys, X509 certificates, and signing requests using the BIG-IP Configuration utility, rather than the command line interface. For specific instructions, refer to the Proxies chapter of the BIG-IP Reference Guide.

If this is the first time you have created an SSL Key, you need to first perform the following tasks:

  • Set the local random seed.
  • Create the default openssl configuration file.

Setting the local random seed

To set the local random seed, type the following command:

cp /var/run/openssl_randfile /var/run/.sslrand

Creating the default openssl configuration file

To create the default openssl configuration file, type following command:

genconf

You will be prompted for fields necessary to create distinguished name to be included in newly created certificates.

Creating an SSL key and certificate from the command line

To create a 1024-bit RSA key and an X509-compatible self-signed certificate, type the following command:

openssl req -x509 -newkey rsa:1024 -nodes -keyout test.key -out test.crt

The un-encrypted private key is stored in the test.key file in your current working directory. The self-signed certificate is stored in the test.crt file in your working directory.

Creating a certificate signing request from the command line

Note: Public certificate authorities frequently require specific fields and options in the certificate submitted to signing. They may also request that the certificate be in a format other than PEM (for example, DER). Consult with your CA of choice for specific requirements.

To generate a certificate signing request (CSR) to be submitted to certificate authority (CA), perform the following steps:

  1. Type the following command:

    Note: This assumes that you have created the key and certificate previous procedure and have not changed your working directory.

    openssl req -key test.key -out test.csr -new

  2. Enter site-specific information (such as Country, State, City, and so forth.) as prompted.

    The certificate signing request is stored to the test.csr file in your current working directory in PEM format.

For instructions how to use openssl on other systems than BIG-IP, refer to:

http://www.openssl.org/docs/HOWTO/certificates.txt
