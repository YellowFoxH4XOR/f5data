Description
In SWG, you created a custom category to allow a certain URL

Access to this page is blocked.
Access was denied by a per-request policy.
The session reference number: f1234565
The category reference is: mycategory_A
 
For instance, example.com listed in mycategory_B, however, receives a block page for another category listed in mycategory_A.

Environment

  • BIG-IP APM
  • SWG

Cause
None.

Recommended Actions
Important: Before doing any changes back up each system and store the backup in a remote and secure location. For information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.

  1. Check the URL in question for duplicate entries in all categories by running the sample tmsh command below:

    # tmsh list sys url-db url-category default-action urls { *example.com* } | grep example.com -B4}

    sys url-db url-category mycategoryA {
        default-action block
        urls {
            \*example.com\* {
    --
    }
    sys url-db url-category mycategoryB {
        default-action allow
        urls {
            \*example.com\* {

    You will find in the example above, the URL with example.com is found both in the mycategoryA and mycategoryB categories.

    Note:
           • The category default-action of a category will be applied to the custom URL filter by default.
           • If the URL access permission conflicts between categories like the given example above, SWG will impose a block action over the allow action.
     
  2. In the custom URL filter, find the category in question and set it to Allow. 
           a. Go to "Access  ››  Secure Web Gateway : URL Filters › [Profile]"
           b. Collapse the Custom Categories item and tick the category item in question and hit the Allow button. 
           c. Verify the said categories are now in allowed-categories, e.g.

           # tmsh list apm url-filter myurl_filter allowed-categories | grep -oP "mycategory.* " mycategoryA

     Note: Only the categories which have been manually changed in the URL filter will appear in the tmsh command above.
