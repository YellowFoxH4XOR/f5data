Known Issue

The graceful restart function of the Border Gateway Protocol (BGP) daemon may cause the bgpd process to produce a core file.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP Advanced Routing Module (BIG-IP ARM) to use the BGP routing protocol.
  • The BIG-IP system is a BGP peer with a neighboring peer.
  • You have enabled BGP debug logging.
  • You perform a graceful restart of the bgpd process.

Impact

Performing graceful restart of the bgpd process takes longer than expected while the BIG-IP system creates a core file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Performing graceful restart of the bgpd process takes longer than expected and causes the BIG-IP system to save a core file to the /shared/core directory.

Workaround

To work around this issue, you can disable BGP debug logging. For information about enabling and disabling BGP debug logging, refer to K10168: Overview of BGP on the BIG-IP system.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
