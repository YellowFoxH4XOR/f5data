K000135788: How does the BIG-IP determine the MAC address of a virtual server destination IP address?

Description

You'd like to know which MAC address a virtual server uses to answer ARP requests for the destination IP address.

Environment

  • BIG-IP LTM

Cause

None, this is informational.

Recommended Actions

For a specific virtual server destination IP address (e.g. 172.16.1.55), there could be two scenarios:

  • Scenario #1 MAC masquerade is configured:
    For the Virtual Server that belongs to the traffic group, the Virtual Server will use the configured MAC masquerade address as its own MAC address to the destination IP. If you want to know more details about MAC masquerade, please refer to K13502: Configuring MAC masquerade (11.x - 17.x) .
    You can use the following command to check the MAC masquerade address for the specific traffic group:
    tmsh list cm traffic-group <name-of-the-traffic-group> all-properties
  • Scenario #2 No MAC masquerade is configured or BIG-IP is standalone: 
    The virtual server uses the MAC address associated with the VLAN where it received the ARP request if the virtual server is listening/enabled on that VLAN.
    For example: The virtual server uses the MAC address associated with the External VLAN where it receives an ARP request because the VLAN and Tunnel Traffic setting on the virtual server is configured with All VLANs and Tunnels. This means it's enabled on all VLANs. It will do this even if the virtual server address is in the same subnet as one of the self IPs on another VLAN. You can enable or disable specific VLANs by navigating to Local Traffic > Virtual Servers > Virtual Server List, selecting the virtual server, and updating the VLAN and Tunnel Traffic setting.
    You can use the following command to view the vlan setting on all virtual servers in the current partition:
    tmsh list ltm virtual vlans vlans-disabled vlans-enabled
    vlans none indicates the virtual server is enabled on all VLANs

You can display the MAC address assigned to each VLAN by entering the following command:
tmsh show net vlan
