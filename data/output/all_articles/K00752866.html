K00752866: Auto discovery is not detecting instances of other projects in Google Cloud Platform

Type
Support Solution
Published
2021-06-04
Updated
2025-02-06
Applies to
  • BIG-IP
  • Public Cloud
  • BIG-IP LTM: 16.0.1
  • Google Cloud
Source
https://my.f5.com/manage/s/article/K00752866

Description

F5 Google Deployment Manager Templates deploy and find each object in the current project with the proper tag. But it does not find other projects on Google Cloud that use the same tagging.

Environment

  • Google Cloud Platform (GCP)
  • Supported F5 Google Deployment Manager template
  • Previous deployed project using the same tagKey and tagValue
  • BIG-IP version supported by the deployment

Cause

Auto Discovery is behaving as designed.
Service delivery is currently limited to just the current project.

Recommended Actions

The Service Discovery iApp is being deprecated in favor of AS3. For more information, refer to Using Service Discovery with AS3 on F5 Cloud Docs.
