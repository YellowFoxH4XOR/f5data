Topic

Users can display information about their FirePass sessions using the View Current Sessions option from the Tools Webifyer on the webtop. FirePass administrators can display the Tools Webifyer on users' webtops by selecting the Beginner or Advanced option buttons next to View Current Sessions, from the User Experience tab of the Users: Groups: Master Groups page.

The View Current Sessions option will display a page with a table that appears similar to the following example:

The columns contain the following information:

Time to live

The Time to live column displays in units of seconds and/or minutes the amount of time until the session is expired by the applicable inactivity timeout (either a global or group-based timeout).

For the session being used to access the View Current Sessions page (the row with Yourself in the Owner column), this table cell will display the maximum number of minutes/seconds, since the activity of viewing the page will reset the session's inactivity timeout.  Occasionally, you may also see the value of one second less than the maximum; this is normal, and reflects the timing of the update to the session in the FirePass database, relative to the time taken to request and display the page.

Calling IP

The Calling IP column displays the source IP address from which the FirePass controller sees the session's packets originating. This may be the IP address of the SSL VPN client, or an intermediate device such as a proxy server or a firewall, which causes a translation of IP addresses.

Endpoint

The Endpoint column displays the client's User Agent string, which is the string sent in an HTTP header by the client's browser, which identifies the browser (user agent). This string can be used in troubleshooting when a FirePass user's webtop does not display correctly. The FirePas controller chooses what type of webtop style to display based on the User Agent string.  If the User Agent string is unknown to the FirePass controller, the webtop style chosen may not be the correct or optimal choice.

User Agent strings can be mapped to a particular browser type on the Device Management: Configuration: New Browsers page.

The value in this column should be identical to the User Agent column on the Reports: Logons page.

SSL

The SSL column displays the protocol used for the session. This value can be either HTTPS (connection between client and FirePass controller is encrypted with SSL/TLS) or HTTP if insecure access has been permitted by the Allow insecure access setting on the Device Management: Security: User Access Security page.

When the value in the Owner column is Yourself, the Time to live column will always display the time of the inactivity timeout limit, either the global limit or the group limit if the group limit is configured.  Occasionally, you may also see the value of one second less than the maximum; this is normal, and reflects the timing of the update to the session in the FirePass database, relative to the time taken to request and display the page.

Content Type

The Content Type column displays the format of web content returned to the client when the client requests FirePass-based web pages, such as the login and logout pages, and the webtop.  Different client types (full browsers, PDA's or smart phones) require the FirePass to format pages according to the ability of the device's display. The possible values are as follows:

  • HTML

    This value is used for full browsers.
  • miniHTML

    This value is used for PDA-type devices with scaled-down versions of full browsers.
  • WML

    This value is used for smart phones.

Status

The Status column displays the state of the session. Typically, the user will only see the following value:

Logged on server.

Owner

The Owner column displays either Yourself for the currently used session which is viewing the page, or Another instance, indicating that another session with the same username is present.

Delete

The Delete column provides a check box which enables a user to terminate a session other than the current session.  To terminate a session, select the Delete check box in the row of the session you want to terminate, then click the Delete selected sessions button at the bottom of the table.
