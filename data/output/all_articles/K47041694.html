Description

SSL Cavium card related issues on vCMP platforms can result in SSL connection errors on one or more vCMP guests for data-plane traffic (when SSL is offloaded on guest), configsync operation (persistent "Disconnected" status) or GTM iquery connectivity.

You may observe the following logs on vCMP guest and host.

Log messages on affected guest

/var/log/ltm
guest1 notice mcpd[4956]: 0107143c:5: Connection to CMI peer 192.1680.1 has been removed
guest1 notice mcpd[4956]: 01071432:5: CMI peer connection established to 192.1680.1 port 6699 after 0 retries
guest1 notice mcpd[4956]: 0107143c:5: Connection to CMI peer 192.1680.1 has been removed
guest1 notice mcpd[4956]: 01071432:5: CMI peer connection established to 192.1680.1 port 6699 after 0 retries
- OR -
guest1 debug mcpd[4956]: 01071ae8:7: CMI heartbeat timer: Did not receive an hb response yet from 192.0.0.1
guest1 warning tmm[17988]: 01260013:4: SSL Handshake failed for TCP 192.0.0.1:4353 -> 192.0.0.2:60414

Above shows that HA configsync is affected.

/var/log/tmm
slot1/guest1 notice cn0 (vcmp-0x6c-tmm0): wlite provider not responding - consumer cancelling pending reqs and unregistering
slot1/guest1 notice wlite NITROX (c|v): Registration tx success for vcmp-shm

Above shows Cavium Nitrox card having issues.

Log messages on the host


/var/log/tmm
slot1/host1 notice cmp state: 0x1
slot1/host1 notice wlite NITROX (p|lv): Consumer unregistered, ping == 0xffff
slot1/host1 notice wlite NITROX (p|lv): Successful registration for wlite vcmp type NITROX consumer 3 for guest: 0x1b, type: NITROX (key: 0xf7400d80)

Above shows Cavium Nitrox card having issues.

Environment

  • BIG-IP

  • vCMP host and guest

Cause

Cavium Nitrox card experiences issues.

Recommended Actions

Reboot the affected slot(s) on the vCMP host and perform End User Diagnostic test to rule out any hardware issues with SSL card.
