Known Issue

An iControl REST object member stats query produces an incorrectly nested JSON when the object is not specified with a full path.

This issue occurs when the following condition is met:

  • You query iControl for member object stats without specifying the full object path.

Impact

The response JSON contains incorrectly nested stats content.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use a non-fully-pathed name in the iControl-REST when calling for stats (for example, pool/p1/members/stats) the resulting response JSON contains incorrectly nested objects.

Resolution

Status

F5 Product Development has assigned ID 611424 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

Use the fully-qualified path, including the partition where the object resides, for example: pool/~Common~p1/members/stats.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
