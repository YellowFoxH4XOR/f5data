Description

After setting up device trust and config sync of two BIG-IP devices in HA, both devices are going into Active-Active state with below logs in /var/log/ltm logs: 

bigip notice sod[7281]: 010c006d:5: No peer active but stay put for longer.. 
bigip notice sod[7281]: 010c006d:5: Leaving Standby for Active: Next Active, peers agree on config.
bigip notice sod[7281]: 010c0053:5: Active for traffic group /Common/traffic-group-1.
bigip notice sod[7281]: 010c0019:5: Active

Environment

  • BIG-IP devices in HA
  • Split brain condition happening
     

Cause

Port lockdown on config sync self IP is set to allow none. 
 

Recommended Actions
Set port lockdown on the self IP to allow default using below instructions: 

  1. Log in to the Configuration utility.
  2. Go to Network > Self IPs.
  3. Select the relevant self IP address for HA communication.
  4. For Port Lockdown, choose the setting you want to use.
  5. Select Update.
