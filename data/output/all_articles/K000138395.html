Description

You want to configure a BIG-IP health monitor to check a pool member or node with a longer interval when it's up, but do not want to increase it's timeout. For example you want to check every 20 seconds, but do not want to set the timeout to 61 seconds.

The BIG-IP system won't let you configure a timeout shorter than the interval, but you can enable an Up Interval, which you configure in the Advanced settings of a monitor configuration.

For example, you can set the Up Interval to 20 seconds and configure the Interval to be 3 seconds and set the Timeout to 10 seconds. In this scenario while the resource remains up it's checked every 20 seconds, but if it fails to respond within 10 seconds it's marked down and then the Interval is used to check it every 3 seconds. When it responds, it's marked up and the monitor goes back to checking every 20 seconds.

Prerequisites

You have a user role on the BIG-IP that allows you to create and apply health monitors.

Procedures

To watch a video demo of this procedure, go to  K000158860: Configure a BIG-IP health monitor Up interval setting using the Configuration utility.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility (GUI).
  2. Go to Local Traffic > Monitors > Create.
  3. Enter a name for the monitor.
  4. Select a monitor type and a parent monitor.
    Note: Not all monitor types allow an Up Interval.
  5. Select Advanced for Configuration.
  6. Select Enabled for the Up Interval setting. A Seconds field appears.
  7. Enter the number of seconds for the Up Interval setting.
    Note:
    • You should typically set the Up Interval higher than the Interval.
    • Use Interval for faster detection when a resource is down and a higher Up Interval to reduce monitoring load when the resource is up.
  8. Configure the other settings as needed.
  9. Select Finished.
  10. Apply the newly created monitor in the Health Monitors setting of a pool or node.
