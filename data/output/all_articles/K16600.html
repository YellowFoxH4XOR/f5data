Known Issue

Attempts to establish FirePass access sessions may fail.

This issue occurs when all of the following conditions are met:

  • Users establish access sessions that alternate between your BIG-IP APM and FirePass systems.
  • Your BIG-IP APM and FirePass configurations use Endpoint Security (EPS) agents.
  • A user establishes an access session with the BIG-IP APM system, and the EPS inspection host plug-in installs automatically.
  • At a later time, after completing the BIG-IP APM access session, the same user (with the same browser) attempts to establish an access session with the FirePass controller.

Impact

The user is not able to establish a FirePass access session.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When users connect to the FirePass controller, after installing the updated EPS plug-in (in a previous BIG-IP APM session), the user's browser stops responding while running the EPS agent plug-in.
