Description

This message occurs when the following conditions is met:

When the virtual server's http response header has Content-Type longer than 128 characters.

The buffer size for http response header is hard coded and can not be changed in configuration.

Error Message

01240005:3: Error querying client-side Content-Type HTTP header: buffer full (Server side: vip=/<Partition_name>/<Virtual_server_name> profile=inflate pool=/<Partition_name>/<Pool_name> server_ip=<Pool_member_ip>)

In this error message, note the following:

<Partition_name> is the partition name where the object located.
<Virtual_server_name> is the virtual server which caused for this error message.
<Pool_name> is the Pool name assigned/used for the connection for this error message in server side.
<Pool_member_ip> is the backend server address which caused for this error message in server side.

For example:

01240005:3: Error querying client-side Content-Type HTTP header: buffer full (Server side: vip=/Partition1/Virtual_HTTP profile=inflate pool=/Partition1/HTTP_pool server_ip=10.1.1.50)

Message Location

You may encounter this message in the following location[s]:

/var/log/ltm*

Environment

LTM
HTTP profile attached to Virtual Server

Cause

Design

Recommended Actions

Determine why the Content-Type is over 128 characters for requests to the virtual server and fix the application not make such a request
