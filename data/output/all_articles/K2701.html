You can use iRules to persist across pools by enabling the global persist across_services variable.

When the global persist across_services variable is enabled, the BIG-IP system searches existing pools, and the values on which they are persisted, to find an exact match. If the BIG-IP system cannot find an exact match, the system load balances to the next node and adds a new persistence value to the pool. The result is similar to that of creating a single master persistence pool.

To enable the global persist across_services variable, type the following command:

b global persist across_services enable
