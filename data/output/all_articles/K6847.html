Known Issue

This is the result of a known issue. If the BIG-IP Link Controller link object is configured to use the ICMP monitor, the link object will be marked red, indicating that it is unavailable. Link objects should be monitored with the bigip_link monitor instead of the ICMP monitor.

F5 Product Development tracked this issue as CR68663 and CR60114, and it was fixed in BIG-IP 9.3.0 and 9.4.0. For information about upgrading, refer to the BIG-IP Link Controller and GTM release notes.

Workaround

To work around this issue, do not configure link objects to use the ICMP monitor. For information about monitoring link objects, refer to K6848: Monitoring link objects on a BIG-IP GTM or BIG-IP Link Controller system.
