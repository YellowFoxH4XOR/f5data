K000151211: Unable to access BIG-IQ management interface even though network firewall rules allows it

Type
Support Solution
Published
2025-05-15
Updated
2025-05-15
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000151211

Description

Unable to access BIG-IQ management interface via Configuration Utility (GUI) or CLI, even though firewall rules allows it by following K92748202: Restrict access to the BIG-IQ management interface using network firewall rules.

Environment

  • BIG-IQ

Cause

None

Recommended Actions

Allow the IP address through below settings:

  • For Configuration Utility (GUI) access: K13309: Restricting access to the Configuration utility by source IP address (11.x - 17.x) 
  • For CLI access: K5380: Specify allowable IP ranges for SSH access

Additional Information

None
