Topic

Beginning in BIG-IP 11.2.0 and Enterprise Manager 3.0.0, F5 has changed to a new vendor for the BIG-IP geolocation database.

Description

The change to the new geolocation database has been made retroactively to all applicable software versions, and the software distribution files available from the F5 Downloads site have been replaced with files that include the new database.

The following versions have been retroactively changed to include the new geolocation database:

The updated installation packages bear the same software version and build number on the Downloads site because only an external package has been changed and F5 made no underlying changes to the BIG-IP software.

As a result of these changes, the MD5 checksum value for a given F5 product download may differ from the MD5 checksum for a previously-downloaded version of the same product and version. This is expected, and does not indicate that the BIG-IP software itself has changed in any way.

Recommendations

Updating to the new geolocation database without upgrading the BIG-IP software version

Determining which installation package you have downloaded

Updating to the new geolocation database without upgrading the BIG-IP software version

If you are running an older version of BIG-IP software and wish to upgrade to the new geolocation database, you do not need to re-install or upgrade the BIG-IP software.

To upgrade the geolocation database, perform the steps detailed in K11176: Downloading and installing updates to the IP geolocation database.

Determining which installation package you have downloaded

If you need to determine whether the installation package you have downloaded contains the updated geolocation database, perform the following procedure:

Impact of procedure: None

  1. Generate an md5 checksum for the ISO image you have downloaded.

    For example, on a GNU/Linux system you would use the following command:

    md5sum BIGIP-10.0.1.283.0.iso

  2. From the F5 Downloads site, download the latest MD5 file for the ISO image you want to verify.

    For example, to verify the checksum for BIG-IP 10.1.0, you would download the following file:

    BIGIP-10.1.0.3341.0.iso.md5

  3. Examine the contents of the .md5 you downloaded in Step 2.

    For example, on a GNU/Linux system you would use a command similar to the following example:

    cat BIGIP-10.1.0.3341.0.iso.md5

  4. Compare the contents of the file from Step 3 to the value returned in Step 1. Both steps will result in a value similar to the following example:

    df5fdc1b8f336879b9cfb83585cd021c BIGIP-10.1.0.3341.0.iso.md5

    If the md5 values match exactly, the ISO you have downloaded is the latest updated version.
