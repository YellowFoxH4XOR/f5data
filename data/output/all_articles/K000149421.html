K000149421: APM: SAML SSO: SLO Response body not found in SAML message

Type
Support Solution
Published
2025-01-22
Updated
2025-01-22
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149421

Description

BIGIP APM administrator has configured SAML SP setup with Azure IDP (aka Entra ID). As part of SAML functionality, SLO is configured and administrator is observing below logs during actual logout:

Jan 13 08:52:09 apm.test err tmm[4850]: 014d1083:3: policy-test:30cd8b81:SAML SSO: SLO Request is received on SLO Response URL

Jan 13 08:52:09 apm.test err tmm[4850]: 014d1084:3: policy-test:30cd8b81:SAML SSO: SLO Response body not found in SAML message 'SAMLRequest=<omitted for brevity>'

Jan 13 08:52:09 apm.test err tmm[4850]: 014d119a:3: policy-test:30cd8b81:SAML SSO: Error (12) in reading SP info from sessionDB

Jan 13 08:52:09 apm.test err tmm[4850]: 014d1011:3: policy-test:30cd8b81:SAML SSO: Abort reason: Error in reading sp info from session db

Environment

  • APM
  • SAML
  • SLO
  • Azure (Entra ID)

Cause

The Logout URI is configured incorrectly on Azure.

Recommended Actions

1) Refer to Azure document and configure the Logout URI as described (point 9 from documentation):

Configure Microsoft Entra SSO

https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/f5-big-ip-header-advanced#configure-microsoft-entra-sso

===

Note

From Traffic Management operating system (TMOS) v16 onward, the SAML SLO endpoint changed to /saml/sp/profile/redirect/slo.

===

2) Export the metadata from Azure

3) Import the metadata to APM and bind with the corresponding saml sp service.
