Known Issue

Perl-Compatible Regular Expression (PCRE) evaluation may continue after the system has reached the maximum recursion depth for a given request.

This issue occurs when the following condition is met:

  • Attack signatures that use PCRE matching are enabled on a security policy.

When the system reaches the maximum recursion depth for a given request, PCRE evaluation should stop, and the BIG-IP ASM system should generate an informational violation that matches the following example:

The signature is not matched. The matching process exceeded the maximum number of allowed recursions.

When this issue occurs, the PCRE evaluation does not stop, and it may continue to consume available system resources, causing the BIG-IP ASM bd process to crash.

Impact

The BIG-IP ASM may temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The bd process dumps the core file, creating files in the /var/core/ directory that have names similar to the following examples:

    bd_bld473_0_core_7328.gz

  • The system may log entries that appear similar to the following examples in the /var/log/ts/bd.log file:

    io_manager_init.c:0343|internal_keep_alive_thread rw_life_signs[i]=65875560 RW thread num=7 failed. current_rw_life_sign=65875560

    io_manager_init.c:0345|internal_keep_alive: BD shrinking...,going down
