Issue

Error Message

clusterd[<PID>]: 013a0020:5: <Blade Availability Status and Condition>

In this error message, note the following:

  • <PID> is the process ID for the clusterd process.
  • <Blade Availability Status and Condition> is the blade number being reported as green and available, and the current condition of the blade.

For example:

notice clusterd[4013]: 013a0020:5: Blade 2 turned Green: Run

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A cluster member has transitioned to clusterd Availability State GREEN.

Impact

There is no impact; this is only an informational message.

Recommended Actions

None
