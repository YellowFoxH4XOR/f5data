Issue

Error Message

2311: The Citrix online plug-in received a corrupt ICA File. The name (<DOCTYPE HTML PUBLIC " -//IETF//DTD HTML//EN">) is not allowed for a section.

Message Location

You may encounter this message in the following location:

  • Internet Explorer 9 users receive the error in their browser.

Description

This message occurs when all of the following conditions are met:

  • The user connects to the FirePass controller with Internet Explorer 9.
  • The user accesses a Citrix web application.
  • The user launches an application from the Citrix desktop.

Internet Explorer 9 introduces additional security that blocks the proper operation of the Citrix XenApp client. This situation prevents the Citrix XenApp client from downloading the .ica file and properly launching an application through Citrix XenApp.

Impact

Internet Explorer 9 users are unable to launch Citrix-based applications.
