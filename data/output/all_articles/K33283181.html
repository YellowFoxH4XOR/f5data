Description

You can determine valid events for an iRule command by using the TMOS Shell(tmsh) command. 

Environment

  • TMOS Shell(tmsh).
  • IRule Command

Cause

None

Recommended Actions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line. 
  2. Log in to tmsh by typing the following command: 
  3. tmsh  
  4. To determine valid events for an iRule command, use the following command syntax:
    help /ltm rule command <iRule command>

For example, to determine valid events for TCP::idletime, type the following command:
help /ltm rule command TCP::idletime

The output contains the following:
VALID DURING
       ANY_EVENT
