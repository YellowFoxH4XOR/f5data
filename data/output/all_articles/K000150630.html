K000150630: [AS3] Escape characters are getting added to actions for LTM Policy creation

Type
Support Solution
Published
2025-04-03
Updated
2025-06-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150630

Description:

When attempting to push a configuration via AS3 (Application Services 3), you may notice that certain characters (\) are unexpectedly added to your strings. This results in modifications that were not intended. For example: 

Input String:

 "value": "tcl:[regsub -nocase {.test1.com$} [HTTP::host] {.test2.com}]"

Output (Processed String):

value "tcl:[regsub -nocase { .test1.com$ } [HTTP::host] \\{.test2.com \\}]"

This issue can cause discrepancies in your configuration and may affect functionality if the altered strings are not properly escaped or interpreted.

Environment

  • LTM
  • AS3 

Cause

ID 1780321

Recommended Actions

Upgrade to AS3.54
