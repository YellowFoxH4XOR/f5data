Issue

Error Message

info sod[<PID>]: 0114002b:6: <Process Running/Daemon Heartbeat> <Service> enabled

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <Process Running/Daemon Heartbeat> specifies whether it is a process that is running or a daemon heartbeat.
  • <Service> specifies the service name that is being enabled.

For example:

info sod[7970]: 0114002b:6: HA proc_running mcpd enabled
info sod[7970]: 0114002b:6: HA daemon_heartbeat sod enabled

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You have enabled a high availability (HA) table entry for failure monitoring.

Impact

None

Recommended Actions

None
