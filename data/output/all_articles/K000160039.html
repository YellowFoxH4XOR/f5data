Description

Is it possible to block HTTP 1.0 protocol on load balancer? 

 

Environment

  • HTTP 1.0
  • LB
  • Distributed Cloud

 

Answer/Recommended Actions

There is no way to block specified protocol on LB.

We cannot block HTTP traffic based on HTTP version.
