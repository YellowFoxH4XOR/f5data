Topic

You should consider using this procedure under the following condition:

  • You want to obtain BIG-IP inventory information using the iControl REST API.

Description

You can collect BIG-IP device inventory information using the iControl REST API. For example, if you have a large number of BIG-IP devices in your environment and need to create an application that collects and maintains device inventory information, you can use the iControl REST API to obtain BIG-IP device information as required by the application. General inventory items can be obtained by accessing the /mgmt/tm/cm/device/<hostname> iControl REST API endpoint.

BIG-IP device inventory items and corresponding iControl REST API endpoints are displayed in the following table.

  • Description

Hardware/mgmt/tm/sys/hardware
License/mgmt/tm/sys/license

curl and jq utilities

Performing the following procedure requires command-line access to a system with the curl utility and, optionally, the jq (command line JSON processor) utility installed. These utilities are commonly available on Linux systems but can also be installed on Microsoft Windows and Mac OS X systems. Additionally, you can perform this procedure on a BIG-IP system.

Fine-tuning the curl command

When defining the iControl REST command, specify the appropriate iControl REST API endpoint and, if needed, fine-tune the command to extract the individual inventory item. For example, the following command syntax specifies the iControl REST endpoint and returns the complete list of device properties:

curl -sku <username:password> -X GET https://<BIG-IP hostname or management IP address>/mgmt/tm/cm/device/<hostname>

The following command syntax adds a parameter to the /mgmt/tm/cm/device endpoint to extract the individual inventory item:

curl -sku <username:password> -X GET https://<BIG-IP hostname or management IP address>/mgmt/tm/cm/device/<hostname>?\$select=managementIp | jq

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command-line access to a Linux system with the curl utility and jq (command line JSON processor) utility installed.
  • You have reviewed the iControl REST interface documentation.

Procedures

Obtaining general inventory items from the BIG-IP using iControl Rest API

You can obtain most of the general inventory information from the BIG-IP device by accessing the /mgmt/tm/cm/device/<hostname> iControl REST API endpoint. To obtain general inventory information using the iControl Rest API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to obtain general inventory information from the BIG-IP system:

    curl -sku <username:password> -X GET https://<BIG-IP hostname or management IP address>/mgmt/tm/cm/device/<hostname> | jq

    For example, the following command obtains general inventory information for the device with a host name of BIGIP.example.com and a management IP address of 192.0.2.1:

You can obtain the self IP address by accessing the /mgmt/tm/sys/net/self iControl REST API endpoint. To view the self IP address using iControl Rest API, perform the following procedure:

Obtaining the BIG-IP software update status using iControl REST API

By default, the BIG-IP system checks the F5 Downloads server for software updates for your system and reports the update status. You can obtain the software update status by accessing the /mgmt/tm/sys/software/update-status iControl REST endpoint. To view the BIG-IP software update status using iControl Rest API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of a system with the curl and jq utilities installed.
  2. Use the following command syntax to list the software update status for the BIG-IP system:

    curl -sku <username:password> -X GET https://<BIG-IP management IP address>/mgmt/tm/sys/software/update-status | jq
