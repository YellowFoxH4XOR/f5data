Description

Files within the BIG-IP file system may get corrupted and below error messages appears in /var/log/kern.log.

ext3_lookup: deleted inode referenced: ID
ext3_lookup: deleted inode referenced: ID
 

Environment

  • BIG-IP LTM
  • BIG-IP file system errors

Cause
Files within the BIP-IP file system get corrupted due to an improper shutdown or hardware failures

Recommended Actions

In order to fix this issue the check disk utility needs to issue from from Maintenance OS by following below steps: 
  1.   Login via console and make sure you have access
  2.   Run mosreboot to reboot into MOS
  3.   Run fdisk -l | grep share  to find the correct share directory to run on step #3
  4.   Run fsck -f -y /dev/mapper/vg--db--sda-dat.share
  5.   Run reboot to reboot back into TMOS
  6.   Once the device comes up, login into the F5 and go this directory cd /var/log/kernel
  7.   Then, we have to review the /var/log/kernel.log file in order to verify that inode errors has been stopped
