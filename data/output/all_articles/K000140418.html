Description

ASM implementation of ICAP does not forward Post requests to the ICAP server for virus analysis.

Environment

  • ASM
  • ICAP

Cause

This issue can occur when the wrong configuration has been applied to the relevant Allowed URL.

For a request to be forwarded to icap there have to be two conditions in place:

  1. The request method should be "POST".
  2. The "Content-Type" should be "multipart"

In the Allowed URL configuration setting after choosing the "Advanced" option there is a tab where "Header-based Content Profiles" can be configured. In some cases, the action for "multipart" can be configured as "Do Nothing". In those cases, ASM will not forward the request to the ICAP server.

Recommended Actions

Change the action for "multipart" in the "Header-based Content Profiles" to "Form Data"

Security -> Application Security -> URLs -> Allowed URLs -> Choose the specific URL ->(Advanced) Header-Based Content Profiles
