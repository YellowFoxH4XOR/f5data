K000141085: VXLAN tunnel in multipoint mode stops sending traffic when FDB entries deleted

Type
Support Solution
Published
2024-10-21
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000141085

Description

After deleting FDB entries for VXLAN tunnel in multipoint mode, traffic no longer can be delivered.

Environment

  • VXLAN tunnel configured with flooding-type multipoint

Cause

VXLAN tunnels in multipoint mode require FDB entries.

Recommended Actions

Either configure static FDB entries or configure VXLAN in multicast mode.
