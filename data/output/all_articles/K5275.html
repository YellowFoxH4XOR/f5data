Issue

Error Message

Operation failed: Update operation refused

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file.
  • The DNS > Zones > ZoneRunner > Resource Record List > New Resource Record page of the BIG-IP DNS Configuration utility.

Description

This error message may occur for the following reasons:

  • The system does not have adequate permissions to update the associated zone file. For example, if the forward zone allows updates, but the reverse zone does not, the system generates the error message.
  • You attempt to add an MX or NS record to a zone and the specified mailserver or nameserver does not have a corresponding A record in the zone.
    Note: This issue may occur if you fail to add a trailing dot (.) to the end of the name when you create the record. For example, if you fail to add the trailing dot to mail.example.com, the name is assumed to be relative to the current zone file's $ORIGIN, and the system appends example.com to the end of the name (mail.example.com.example.com).

Impact

The system is unable to make changes to a BIND zone.

Recommended Actions

  • Make sure the system has permissions to update the associated zone file. For example, make sure the forward and reverse zones allows updates if appropriate.
  • Make sure MX or NS records are defined properly, and the specified mailserver or nameserver have a corresponding A record in the zone.
