Description

You observe continuous alerts on the console for emerg logger: Re-starting restjavad and logged in /var/log/daemon.log

You also observe that /var/log/restjavad.0.log has logged:

[LuceneStorageRequestProcessor] commit: java.io.IOException: No space left on device

Environment

  • One or more file systems on the device has no disk space available.  Check with df -h
Cause

Unexpected out of disk space condition resulting in stuck restjavad process.

Recommended Actions
Clear the disk space, for more information refer to K14403: Maintaining disk space on the BIG-IP system.

Check for duplicate restjavad processes and terminate them.  Then restart the restjavad process.

Run commands in bash CLI:

  1. Check how many restjavad processes are running: 

    ps aux | grep restjavad

    Example:  Process ID 7347 shows one instance of restjavad running
    # ps aux | grep restjavad
    root      2574  0.0  0.0   5564   792 pts/0    S+   02:05   0:00 grep restjavad
    root      7343  0.0  0.0   1880   404 ?        S    Jan27   0:00 runsv restjavad
    root      7347  0.4  1.2 492712 198280 ?       Sl   Jan27   6:11 /usr/lib/jvm/jre/bin/java -Djava.util.logging.manager=com.f5.rest.common.RestLogManager -Djava.util.logging.config.file=/etc/restjavad.log.conf -Dlog4j.defaultInitOverride=true -Dorg.quartz.properties=/etc/quartz.properties -Xss384k -XX:+PrintFlagsFinal -XX:+PrintGC -Xloggc:/var/log/restjavad-gc.log -XX:+UseGCLogFileRotation -XX:NumberOfGCLogFiles=2 -XX:GCLogFileSize=1M -XX:+PrintGCDateStamps -XX:+PrintGCTimeStamps -Xms96m -Xmx192m -XX:-UseLargePages -classpath....

    In the above example we have one instance of restjavad running which is normal.  However if you have more than one instance of restjavad running then proceed with the following steps:
     
  2. Manually stop restjavad:

    tmsh stop sys service restjavad

  3. Check how many restjavad processes are running: 

    ps aux | grep restjavad

  4. Kill unexpected restjavad process using the process ID.  Ignore process "grep restjavad" and "runsv restjavad"
    Example:  Using Process ID 7347 identified from step 1

    kill -9 7347

  5. Start the restjavad process:

    tmsh start sys service restjavad

  6. Verify only one restjavad instance is available:

    ps aux | grep restjavad

  7. Verify "Re-starting restjavad" log messages have stopped:

    tailf /var/log/daemon.log
