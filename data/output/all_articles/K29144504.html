Description

From April 1st 2024 all FCP customers using BIG-IP are required to run the FCP usage script and send the output file to customersuccess@f5.com 

The script takes a few seconds to download from F5's GIT-HUB repository and less than 10 minutes to run on a BIG-IQ with 600 managed BIG-IP devices.


Important: 

Please ensure that you have the most recent version of the script (FCP Usage Script - 20260109 ), see article K000140778 for more information.

./bigIQCollect.sh -v

example output:  FCP Usage Script - 20260109 

To accurately report on Velos and R-series devices, BIG-IQ 8.4 is required

Both host and guests (tenants / VCMP) need to be managed by BIG-IQ

If you are upgrading to BIG-IQ 8.4, and you have rSeries and Velos hosts under F5OS--- Platform / Devices, these will need to be removed and re-added (ensuring we can see the slot and blade / partition details)

Previous versions of the script had short timeouts of 30 seconds, the latest version is set to 500 seconds. using the -t switch you can control the time out ./bigIQCollect.sh -i -t 350

Environment 

  • BIG-IQ 8.3 (minimum I series / Viprion) 8.4 (recommended and include R series and Velos support)
  • Full "Classic" BIG-IQ CM / Max  (not license manager / limited version)
  • Managed BIG-IP:  VE, VCMP, R Series and Velos Tenant's , I series and Viprion
  • latest version of script: FCP Usage Script - 20260109  
    



Cause


The script allows us to collect the usage of all managed  BIG-IP devices from the BIG-IQ


Additionally we can also share asset level inventory (software versions, provisioned modules, customised CVE and Support case history)


Recommended Actions


Install and run the script and then send a copy of the output file to customer success team for processing.




  1. Log into the BIG-IQ and make a new directory

    mkdir /shared/reporting
    

  2. Change into the new directory

    cd /shared/reporting
    

  3. Download the bigIQCollect.sh script from GitHub.

    curl -k https://raw.githubusercontent.com/F5Networks/SecondSight/main/contrib/bigiq-collect/bigIQCollect.sh > bigIQCollect.sh
    

  4. Make the script executable

    chmod 777 bigIQCollect.sh
    

  5. Run the script in interactive mode

    ./bigIQCollect.sh -i  
    

  6. When prompted enter the BIG-IQ WebUI admin credentials, followed by your company name as prompted.
    Note: The output file is in /tmp directory is prefixed with your company name followed by the date, and random number and bigIQCollect.tgz
    Example: company-20250108-0517-bigIQCollect.tgz 
  7. Copy this file, from the BIG-IQ  to your desktop using your favourite tool such as scp.
  8. Email the file to customersuccess@f5.com and the customer success manager for this account. Be sure to include the relevant Company Name in the Subject Line.


Additional Information


FCP Usage Script: Inventory refresh completed [FAILED]


List of data collected by FCP usage script


FCP Usage script shows random number of BIG-IP devices each time its run.


You may need to upgrade your BIG-IQ License Manager (LM) to BIG-IQ Centralised Manager (CM) / MAX version, see How to upgrade BIG-IQ License manager to BIG-IQ VE Max


In order for the usage script to function correctly, it is necessary for all BIG-IP devices to be added into BIG-IQ as a managed device with "basic management" enabled only;


Please be careful to not Discover or Import the BIG-IP Services onto the BIG-IQ if you intend to continue managing the BIG-IP configuration directly on the BIG-IP. Please see How to add a BIG-IP device to BIG-IQ and also  Managing BIG-IP devices from BIG-IQ for instructions for device discovery and basic device management.


Please note: although these BIG-IP devices will show as managed when adding them to BIG-IQ with "basic management" only, BIG-IQ will not import or manage their services or configurations. These functions will remain performed via the BIG-IP directly.
