Description

You need clarifications on what is meant by "real-time" in security updates configured via System  ››  Software Management : Live Update.

This setting can be seen in the all types of security updates.

  • ASM Attack Signatures
  • Bot Signatures (Starting from BIG-IP v14.1, you need to have an active Threat Campaigns license for Bot Signature updates)
  • Browser Challenges
  • Server Technologies
  • Threat Campaigns (If licensed)

Environment

  • BIG-IP ASM
  • Live Updates of security signatures and features.

Cause

The "real-time" setting on this page means that once updates are downloaded, they will be installed immediately. A common misconception is that, "real-time" means, updates are downloaded as soon as they become available in the repository, which is not the case.

The Live Update feature of the BIG-IP ASM system checks for updates every 24 hours and automatically downloads them. Threat Campaign updates are checked every eight hours. The timing of these checks is based on the system startup time. These intervals are default settings configured by BIG-IP and cannot be changed. Even with "real-time" installation enabled, the system only checks for new updates at the predefined intervals. Once an update is downloaded, it is installed right away.
