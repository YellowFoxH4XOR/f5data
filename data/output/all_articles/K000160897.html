K000160897: CARP Hashing Algorithm - Include ports in hashing algorithm

Type
Support Solution
Published
2026-04-20
Updated
2026-05-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160897

Description

You want the CARP Hashing Algorithm to include ports in its hash calculations.

The default key value is "disable" for both Source Address Affinity:

list sys db persist.srcaddrcarpipport value
sys db persist.srcaddrcarpipport {
value "disable"
}

 

and for Destination Address Affinity:

list sys db persist.destaddrcarpipport value
sys db persist.destaddrcarpipport {
value "disable"
}

 

Environment

BIG-IP LTM

 

Cause

none

 

Answer/Recommended Actions

To make the BIG-IP consider ports it its hashing algorithm enable the db variables:

  1. For Source Address Affinity issue the following commands:
    1. modify sys db persist.srcaddrcarpipport value enable
    2. save sys config
  2. For Destination Address Affinity issue the following commands:
    1. modify sys db persist.destaddrcarpipport value enable
    2. save sys config
