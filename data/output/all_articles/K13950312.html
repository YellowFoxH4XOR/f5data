Known Issue

The Configuration utility may not display all configuration options when you create or modify a FastL4 profile.

This issue occurs when all of the following conditions are met:

  • You create or modify a FastL4 profile.
  • You attempt to set the TCP Window Scale Mode setting to Rewrite.

Impact

You are unable to select the Rewrite setting.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you configure the TCP Window Scale Mode setting, the system lists only the Preserve and Strip settings.
  • When you use the TMOS Shell (tmsh) to create or modify a FastL4 profile, the options for tcp-wscale-mode are Preserve, Rewrite, and Strip.

Resolution

Workaround

To work around this issue, you can use tmsh to modify the FastL4 profile to use the Rewrite setting. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the affected FastL4 profile tcp-wscale-mode setting to Rewrite, use the following command syntax:

    modify /ltm profile fastl4 <profile name> tcp-wscale-mode rewrite

    For example:

    modify /ltm profile fastl4 myfastl4 tcp-wscale-mode rewrite

  3. Save the configuration change by typing the following command:

    save /sys config

  4. Exit tmsh by typing the following command:

    quit

    Important: You need to repeat these steps every time you use the Configuration utility to modify the affected FastL4 profile.
