Known Issue

This is the result of a known issue. This issue occurs on virtual servers configured with a clientssl profile where the client's maximum segment size (MSS) is not large enough, which causes the Secure Sockets Layer (SSL) record to be fragmented over a large number of packets. If an SSL record overflows the buffer limit of 32, the request fails and the connection closes.

F5 Product Development tracked this issue as CR68194, CR64844, and CR64855, and it was fixed in BIG-IP LTM 9.1.3, 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
