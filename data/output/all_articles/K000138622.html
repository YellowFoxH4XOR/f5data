K000138622: Support for sending certain SNMP traps/alerts to a specific SNMP Manager

Source

Description

Ability to configure BIGIP to route certain SNMP alerts/traps to a specific SNMP manager instead of the one configured globally.


Environment

  • SNMP trap/alerts
  • Per alert specific SNMP Manager

Cause

None

Recommended Actions

By default, BIG-IP's built-in features allow you to configure SNMP settings globally.

However, it doesn't natively support routing certain types of alerts (traps) to different SNMP destinations than the one configured globally.

Any SNMP traps generated by the system are sent to the SNMP managers configured globally.
