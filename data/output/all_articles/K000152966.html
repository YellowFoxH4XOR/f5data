Description

After directly changing NGINX configuration on an NGINX [Plus] instance group member and restarting NGINX Agent, the NGINX configuration in the associated instance group is not updated with the changes.

Environment

NGINX Instance Manager (NIM)

Cause

NIM is functioning as expected

Recommended Actions

None

Additional Information

When an NGINX [Plus] instance is added to an instance group through NGINX Agent configuration and that instance group does not already exist then the instance group is automatically created on NIM and the NGINX configuration from that first member of the instance group will be used as the instance group's NGINX configuration. The NGINX configuration in an existing instance group is automatically applied to newly added instance group members. Direct NGINX configuration changes to an instance group member does not update the instance group's NGINX configuration.
