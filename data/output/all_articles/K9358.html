Known Issue

This is the result of a known issue. The SSL profile types are not supported on BIG-IP Link Controller systems. However, when navigating to the profiles screen on a BIG-IP Link Controller system, the option to add an SSL profile is available. If you attempt to create an SSL profile, the Configuration utility displays the following error message:

Instance not found:clientssl

In addition, attempting to create an SSL profile from the command line returns the following error message:

BIGpipe: client SSL profile operation error: 01070356:3: SSL feature not licensed.

F5 Networks Product Development is tracking this issue as CR84890.
