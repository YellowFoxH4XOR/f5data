Known Issue

Endpoint Security Client-Side agents may fail the 'Last Scan Time Not Older Than (days)' check for Windows Defender.

This issue occurs when all of the following conditions are met:

  • An access policy is configured with a client-side endpoint agent to perform the 'Last Scan Time Not Older Than (days)' check.
  • Users connect to the BIG-IP APM system from Windows 10 devices running Windows Defender 4.8.10240.16384.

Impact

Windows 10 users may be denied access to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Access policies are evaluated incorrectly for Windows 10 users.
  • Messages similar to the following example are logged to the /var/log/apm file:

    Dec 11 15:04:05 DMZGcustomsVE01 info apd[12290]: 01490007:6: 10e36d67: Session variable 'session.check_software.last.av.item_1.errors' set to 'Failed to get 'last_scan'. code: -6 (Object not found) mId: 12 iId: 9 Failed to get 'db_signature'. code: -30 (Not supported) mId: 2 iId: 9 '

Workaround

There is no workaround for this issue. However, in order for the Endpoint Security Client-Side agent to obtain the 'Last Scan Time Not Older Than (days)' value, you can provide read-only access to the C:\ProgramData\Microsoft\Windows Defender folder. This action requires an administrator to set read-only folder access for the Windows system that is being accessed.
