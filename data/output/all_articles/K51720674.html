Issue

Error Message

Error Message: notice sod[<PID>]: 010c002c:5: Traffic group /<partition>/<traffic_group_name> received a targeted failover command from cluster mate for <IP Address>.

In this error message, note the following:

  • <PID> is the process ID of the sod process.
  • <partition> is the name of the partition on which the traffic group resides.
  • <traffic_group_name> is the name of the traffic group that you attempt to force to standby.
  • <IP address> is the cluster IP address of the high availability (HA) peer cluster.

For example:

notice sod[6038]: 010c002c:5: Traffic group /Common/traffic-group-1 received a targeted failover command from cluster mate for 192.0.2.2.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following conditions is met:

  • You issue a force to standby command to a traffic group that is active on a BIG-IP cluster.

This message indicates that the administrator issued a targeted failover command to an active traffic group on the local cluster system.

Impact

The traffic group goes into a standby state on the local cluster.

Recommended Actions

Verify the failover operation succeeded by displaying the status of the specified traffic group on each HA cluster. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Display the status of the traffic group on the device by typing the following command:

    show /cm failover-status
