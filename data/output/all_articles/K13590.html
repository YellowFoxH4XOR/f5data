K13590: The BIG-IP system only allows initiation of the ConfigSync process from the device with configuration changes (11.0.0 - 11.2.0)

Topic

In BIG-IP 11.0.0, the BIG-IP system only allows initiation of the ConfigSync process from the device that has the configuration change. If multiple devices have configuration changes pending synchronization to the device group, these devices can initiate the ConfigSync operation.

In BIG-IP 11.1.0 through 11.2.0, the device group strictly enforces the initiation of the ConfigSync process only from the device with the latest change based on the timestamp recorded by the mcpd process. This behavior is intended to maintain integrity for the configuration. If an attempt is made to initiate the ConfigSync process from a device that has changes from an earlier timestamp, the BIG-IP system will not sync its change to the device group and log an error message to the /var/log/ltm file that appears similar to the following example:

0107148e:3: Sync from device group /Common/my-dg-failover failed, this device /Common/B8900-R66-S36.lab.ss.f5net.com has the highest commit id 1925714368663581705231 /Common/B8900-R66-S36.lab.ss.f5net.com

Recommended Actions

In 11.1.0 through 11.2.0, only the device that has the latest configuration change can initiate the ConfigSync process.

If you need to initiate the ConfigSync process from a device that has changes made from an earlier timestamp, you can perform one of the following actions:

  • Upgrade to BIG-IP 11.2.1 or later. In 11.2.1 the ConfigSync functionality changed so that you can initiate a sync from a device with the latest configuration, or force a synchronization from a device with an older configuration to a device or devices with a newer configuration.
  • Create a dummy object on the device from which you want to initiate the ConfigSync process. This action will update the mcpd timestamp and allow the device to initiate the ConfigSync process.
  • Force a device to initiate the ConfigSync process regardless of the change timestamp by temporarily setting the device as the sync leader in a device group. For more information, refer to K13887: Forcing a BIG-IP device group member to initiate a ConfigSync operation.
