Description

Noticed DNS zone file sync issue for the existing sync-group. DNS resolution from the client side is not working as expected during the time of issue. DNS zone files were not been properly synchronized between the sync-groups which caused the DNS lookups to fail.  

Environment

  • BIG-IP GTM

  • DNS Zone


Cause

Zone files are not Synchronized due to the default setting of Synchronize DNS Zone Files being disabled

There are two different Synchronizations available on DNS GSLB configuration.

Synchronization

Specifies whether this system is a member of a synchronization group. The default is disabled. When you enable synchronization, the system periodically queries other systems in the synchronization group to obtain and distribute configuration and metrics collection updates. The synchronization group may contain systems configured as Global Traffic Manager and Link Controller systems.

Synchronize DNS Zone Files
Specifies that the system synchronizes Domain Name System (DNS) zone files among the synchronization group members. The default setting is disabled.

Multiple BIGIP GTM/DNS devices can be in one synchronization group. We can look at the settings for the DNS group synchronization option as mentioned below,

  • DNS>> Settings>>GSLB>>General:Synchronize ==> Enabled
  • DNS >> Settings>>GSLB>>Geneal:Synchronize DNS Zone Files ==> disable

Recommended Actions

  1. Choose one DNS as "Master" DNS device

  2. All zone files are updated on the Master DNS device

  3. Enable DNS zone files under DNS  ››  Settings: GSLB: General

    Now the Master DNS zone file overwrites the rest DNSs in the same sync group because Master DNS has the latest modification time
