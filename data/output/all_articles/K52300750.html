Description

When testing a new ICAP implementation with ASM, you observe that a Client Side Integrity challenge is returned to the client when a virus is detected in an upload. Ordinarily, a blocking page should be returned.

An Enforcement action of Client Side Integrity will be shown in the ASM event logs.

Environment

  • Security policy
  • ICAP

Cause

Bug ID 862793: ASM replies with JS-Challenge instead of blocking page upon "Virus detected" violation

Recommended Actions

There is no workaround for this issue.

Upgrade to a version where this bug is fixed.

Additional Information

The virus detected violation is raised by ASM when an ICAP server detects a virus in the payload, or when connectivity fails to the configured ICAP server.

It is possible to customize the blocking page returned when the virus detected violation occurs, for example by using an iRule.
