K23937254: BIG-IP Edge Client for Windows device posture check disconnection

Type
Knowledge
Published
2019-06-26
Updated
2025-04-02
Applies to
  • BIG-IP APM: 13.X.X
Source
https://my.f5.com/manage/s/article/K23937254

Issue

Description

Users connecting to a Network Access resource are disconnected because of being out of compliance with the continuous end-point device posture checks.

Environment

  • BIG-IP APM performing device posture check
  • Browser Network Access client
  • BIG-IP Edge Client for Windows

Cause

The BIG-IP Edge Client for Windows logterminal.txt file has the following log message syntax to indicate device posture failed:

Note: Depending on the Windows version, configuration, and user permissions, log files may be located in the %userprofile%\Local Settings\Temp, %temp%, or %userprofile%\AppData\Local\Temp file.

<date>,<time>, POLICY_SERVER Policy check failed (session ID:"<sessionid>" - <OutOfComplianceErrorCode>)

The client sends the hangup code, which is then logged to /var/log/apm on the BIG-IP system, which appears in the following syntax:

<date time> <bigip hostname>  notice tmm[26052]: 01490567:5: /Common/NA_full_tunnel:Common:<sessionid>: Session deleted (out_of_compliance; code - <OutOfComplianceID>)

OutOfComplianceErrorCodeOutOfComplianceIDFailed End-Point Check
ErrFileCheck24579File check failed
ErrProcessCheck24580Process check failed
ErrOesisCheck24581Antivirus, Antispyware, firewall, P2P, Patch Management failed
ErrMachineCertCheck24582Machine certificate check failed
ErrMachineInfoCheck24583Machine information cannot be retrieved from system
ErrRegistryCheck24584Windows Registry check failed

Recommended Actions

  1. Verify the out of compliance error code and determine the end-point check that is failing.
  2. Confirm that the user workstation is meeting the compliance requirements
