K000139188: rSeries tenant goes active when appliance is rebooted, impacting connectivity

Description

BIG-IP tenant(s) running on an rSeries appliance goes active when the appliance is rebooted from F5OS, even if it recently became standby as a result of the impending reboot.

Environment

  • rSeries r5k, r10k and r12k
  • BIG-IP tenant
  • Rebooting appliance
  • Missing management IP in network failover HA configuration

Cause

ID 1399369

This issue is currently attributed to the lack of management configuration in network failover. There will be no further developments with regards to ID1399369.

Recommended Actions

Follow the recommendation of configuring management IP as part of the network failover described in  K14135: Defining network resources for BIG-IP HA features (11.x - 17.x) to avoid unexpected failover conditions.

Alternatively, the issue can be prevented by first stopping or force-offline the tenant before rebooting the appliance.
