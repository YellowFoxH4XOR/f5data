K000147487: Why can't I delete my HTTP Load Balancer resource

Type
Support Solution
Published
2024-11-08
Updated
2025-02-21
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147487

Description

  • I can't delete my HTTP Load Balancer
  • I get the error message: "HTTP failure response: 403 Forbidden - Server returned forbidden, you are probably not allowed to do this operation."
  • I am an admin, so the privileges are not the problem

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer

Resolution/Answer

  • The workload object should be deleted from the Virtual K8s (Kubernetes) page
  • You can find it under the Distributed Apps section -> Virtual K8s
  • Click the vK8s name and in the Workloads tab click on the meatball menu (...) at the end of the element to delete and click Delete 

Cause

  • Your load balancer is created as a child object of a workload object
  • Child objects cannot be deleted directly 
  • Child objects get deleted when their parent object is deleted
