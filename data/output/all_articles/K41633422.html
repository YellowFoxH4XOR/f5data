Description

  • Request that is Blocked by ASM security policy has HTTP status code 200 OK 

Environment

  • ASM
  • Blocking Response 

Cause

  • By default, ASM security response is generic and none descriptive 
  • K04550557: Overview of BIG-IP ASM blocking response

Recommended Actions

  • Should there be a need to modify the default behavior the default 200 OK response, then navigate to
    Security  ››  Application Security >>  Policy >> Response Pages
    Modify 'Response Headers' to the desired value/s
