Known Issue

This is the result of a known issue. The BIG-IP system allows you to configure the Diameter monitor for the Origin Host with an IP address. However, if you use the Configuration utility to configure the Diameter monitor with a fully qualified domain name (FQDN) for the Origin Host, the BIG-IP system displays an error message that appears similar to the following example:

Invalid IP or Hostname

Note: According to RFC3588, the Origin Host attribute-value pair (AVP) is a Diameter Identity data type that must be populated with an FQDN and must be present in all Diameter messages.

F5 Product Development tracked this issue as ID 339616, and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP release notes.

Workaround

You can modify an existing Diameter monitor to use FQDN for the Origin Host. To do so, perform the following procedure:

  1. Log in to the Traffic Management Shell (tmsh).

    Note: To access the tmsh, type tmsh at the command line.

  2. Type the following command:

    modify ltm monitor diameter <monitor name> origin-host <desired hostname>

    Replace <monitor name> with the correct monitor name and <desired hostname> with the desired FQDN for the origin-host field.

    For example:

    modify ltm monitor diameter dia-mon-no-ori-host origin-host foobar.diameter.example.com

You can create a new Diameter monitor to use FQDN for the Origin Host. To do so, perform the following procedure:

  1. Log in to the Traffic Management Shell (tmsh).

    Note: To access the tmsh, type tmsh at the command line.

  2. Type the following command:

    create ltm monitor diameter <monitor name> origin-host <desired hostname>

    Replace <monitor name> with the correct monitor name, and replace <desired hostname> with the desired FQDN for the origin-host field.

    For example:

    create ltm monitor diameter dia-mon-cli origin-host foobar.diameter.example.com
