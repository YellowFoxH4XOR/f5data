Topic

This article describes important information about the BIG-IP 17.5.1.1 release and its replacement with BIG-IP 17.5.1.2.

Description

Security scanning tools have identified an issue in the README file of a third-party package, duojs/duo, within the BIG-IP 17.5.1.1 software release. A URL included in the README file redirects to a website flagged as a phishing site. Importantly, no vulnerabilities or code issues were found within the BIG-IP software. It appears the original ownership of the domain in the URL lapsed, enabling a new owner to claim it and use it for malicious purposes. F5 has resolved this issue by removing the URL from the README file.

A new software version containing this documentation change, BIG-IP 17.5.1.2, is available on the F5 Downloads site. This new version replaces BIG-IP 17.5.1.1.

Recommendation

F5 recommends the following:

  • For customers who downloaded the BIG-IP 17.5.1.1 release, download the updated BIG-IP 17.5.1.2 release.
  • F5 encourages administrators to adhere to security best practices and remain vigilant when navigating external websites.

Additional Information

Frequently Asked Questions

Are there any risks in using the existing BIG-IP 17.5.1.1 release?

There is no risk from continuing to use the existing BIG-IP 17.5.1.1 release; the risk only comes with opening the third-party package's README file URL.

What is the difference between BIG-IP 17.5.1.1 and BIG-IP 17.5.1.2?

BIG-IP 17.5.1.2 does not involve any changes to the BIG-IP code or functionality beyond eliminating the flagged URL from the third-party package's documentation.
