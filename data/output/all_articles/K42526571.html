K42526571: BIG-IQ showing REACTIVATE LICENSE message

Type
Support Solution
Published
2021-09-13
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K42526571

Description

On the BIG-IQ Command Line, REACTIVATE LICENSE is seen.

Environment

  • BIG-IQ
  • REACTIVATE LICENSE on the Command Line

Cause

Unknown at the time of the communication.

Recommended Actions

You will need to reactivate the BIG-IQ license to resolve the issue.

  1. Login to the BIG-IQ GUI
  2. Navigate to System tab
  3. Click Licensing
  4. Click Reactivate
  5. Under Activation Method, choose Automatic
  6. Click Activate
  7. Login to the BIG-IQ Command Line and the REACTIVATE LICENSE would not appear

Additional Information

None.
