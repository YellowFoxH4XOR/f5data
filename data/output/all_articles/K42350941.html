Description

When decrypt TLS traffic from pcap file, we can follow Decrypting SSL in Wireshark . We can also inject the TLS secrets file into the pcap, then when open it with Wireshark we do not need to select PMS file anymore. Wireshark can decrypt the TLS traffic automatically.

Environment

  • Install Wireshark version above 3.0 on Linux(Not BIG-IP)
  • Pcap file with proper pms file

Cause

None

Recommended Actions

  1. Login to terminal and run command:

editcap --inject-secrets tls,<pms_file> <input_tcpdump_file> <output_tcpdump_file>

For example:

editcap --inject-secrets tls,1.pms 1.pcap out_1.pcap

  1. Then you can open output_tcpdump_file with wireshark without specify the pms file to decrypt TLS data.

None
