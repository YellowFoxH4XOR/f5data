Description

BGP 32-bit AS number (ASN) support has been included starting BIG-IP 11.0. However, this feature is disabled by default and results in an error when using 32-bit value to configure a BGP instance, or a BGP peer having a 32-bit AS number.

Here's an example of an error when creating a BGP instance with 32-bit AS number where feature is disabled:

(config)#router bgp 65538
% Extended asn capability is not enabled

Here's an example of an error when configuring a BGP peer with 32-bit ASN while feature is disabled:

(config-router)#neighbor 10.1.1.1 remote-as 65538
% Extended asn capability is not enabled

This solution article provides the procedure to enable 32-bit ASN support for BGP in both use cases.

Environment

  • ZebOS IMI Shell
  • BGP dynamic routing on BIG-IP

Cause

  • 32-bit ASN support is disabled by default.

Recommended Actions

Enable BGP 32-bit ASN support using the following procedure. After enabling 32-bit support, a BIG-IP administrator should be able to use 4-byte ASN values for BGP instance or for BGP peer remote AS values.

Impact of procedure: Changing this configuration will cause BGP neighbors to reset. Changes to a production environment should be performed during a maintenance window.

  1. Log in to the BIG-IP Bash command line.
  2. Access the Integrated Management Interface (IMI) Shell (imish) by typing the following command:

    imish

  3. Enter Enable mode by typing the following command:

    enable

  4. Enter Configuration mode by typing the following command:

    configure terminal

  5. Enable BGP 32-bit ASN support by typing the following command:

    bgp extended-asn-cap

  6. Exit Configuration mode by typing the following command:

    end

  7. Write the configuration by typing the following command:

    write
