Known Issue

The ARX system allows the creation of a / volume. However, F5 Product Development does not recommend naming a volume / because the user will encounter multiple limitations. You may encounter some of the following limitations with a / volume:

  • Creation of additional volumes under the namespace fails with an error message that appears similar to the following example:

    SupARX1k2a(gbl-ns[NS1])# volume /AnotherVolume                                 
    % ERROR: DE_ENCLOSED (41353252):
      Unable to create nested volumes. New volume would be enclosed in existing
    volume.
     
  • In order to correct inconsistencies for Lost Files (LF) or Lost Directories (LD), the / volume must be rebuilt
     
  • The sync files command results in an Internal Error: "Pathname invalid" error message that appears similar to the following example:

    show sync files
                Path: /
                Options:            recurse
                Status:             Failed
                Report Name:        sync.15._.rpt (SupARX1k2a)
                Error:              Internal Error: "Pathname invalid" (-77)
                Lost Items:         0
                Found Items:        0
                Synchronized Items: 0
                Processed Items:    0
  • The nsck command results in an Internal Error: "Pathname invalid" error message that appears similar to the following example:

    show nsck 81
                Op Type:     sync
                Op Id:       81
                Report Name: sync.15._.rpt
                Switch:      SupARX1k2a
                Namespace:   NS1
                Path:        //
                Status:      Internal Error: "Pathname invalid" (-77)

F5 Product Development tracked this issue as ID 37127 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes. 

In ARX version 5.2.0, creation of a / volume is no longer allowed. An attempt to create a volume named / will fail with an error message that appears similar to the following example:

% ERROR: VOLUME_PATH_INVALID (41353474):   The volume name '/' is invalid. The pathname must begin with a / character, and be followed by a name. The name cannot contain the characters ?, <, >, :, |, *, " and \, or invalid path components such as '..' and '.'.
