Description

This document provides the instruction on how to replace multiple slashes found in the HTTP Path to a single slash then redirect the request to the new path

For Example: 

You want to redirect http://www.site.com//app1//index.html to http://www.site.com/app1/index.html

Environment

  • BIG-IP
  • HTTP Path has multiple slashes (//)

Cause

None

Recommended Actions

Follow the steps below to apply the iRule which will modify the HTTP Path and change the multiple slashes to a single slash then redirect the request:

  1. Log in to the Configuration Utility
  2. Navigate to Local Traffic  ››  iRules
  3. Click Create
  4. Provide a name for the iRule
  5. Enter the below iRule
    when HTTP_REQUEST {
        log local0. "Initial Request: {[HTTP::uri]}"
        set path [HTTP::path]
        if {$path matches_regex {.*\//+.*}}{
            set HTTP::path [HTTP::path [regsub -all "\/+" [HTTP::path] "/"]]
            set query [HTTP::query]
            if {$query == "" }{ 
                HTTP::redirect http://[getfield [HTTP::host] ":" 1][HTTP::path]
                log local0. "Rewrite & redirect without query: {[HTTP::uri]}"
            }
            else {
                HTTP::redirect http://[getfield [HTTP::host] ":" 1][HTTP::path]?[HTTP::query]
                log local0. "Rewrite & redirect with query: {[HTTP::uri]}"
            }
        }
        else {
            log local0. "No changes: {[HTTP::uri]}"
        }
    }

    Note: To remove logging, modify the iRule stanza placing the pound sign (#) in front of the lines starting with the word "log".

  6. Click Finish
  7. Assign the created iRule to the virtual server.
Note: Please test the iRule before you implement the change in the production system. You can modify it based on your specific requirement. For complete and detailed information iRules syntax, refer to the iRules Home at F5 Cloud Docs.
