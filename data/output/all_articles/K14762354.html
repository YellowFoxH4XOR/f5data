Issue

Error Message

01670016:7: No inbound entry found for <IP address>:<service port> proto:<protocol>

In this error message, note the following:

  • <IP address> is the Large Scale NAT (LSN) external or public translation IP address.
  • <service port> is the external LSN service port.
  • <protocol> is the connection protocol, typically 17 for User Datagram Protocol (UDP) and 6 for TCP.

For example:

01670016:7: No inbound entry found for 192.168.10.100%0:22 proto:6

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Note: The LSN logging level must be set to debug to view this error message. The default level is error.

Description

This message occurs when the following condition is met:

  • A remote subscriber is attempting to connect to an external endpoint that does not exist in the LSN translation table.

Impact

There is no impact; this message is informational.

Recommended Actions

You can set the LSN logging level to debug to help troubleshoot LSN connectivity issues. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Enable LSN debug logging by typing the following command:

    modify sys db log.lsn.level value debug

  3. To disable debug logging, type the following command:

    modify sys db log.lsn.level value error
