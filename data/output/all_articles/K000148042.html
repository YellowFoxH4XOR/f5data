Description

Environment

Cause

None

Answer/Recommended Actions

In general for routed traffic, if a prefix is successfully traversing F5's network than we are ready to protect that traffic for L3/4 attacks. We will always continue to adjust alert thresholds and tune active mitigations as we learn and baseline your expected traffic over time.

 

Ensure completed the initial setup:

  1. Follow the recommend set-up guide to begin routing through F5 Distributed Cloud.
    • How to do an initial routed configuration setup
  2. Test and validate traffic is flowing without issue. Route leaks, MTU, etc.
  3. Document and inform the SOC of your Real-Time Incident Procedure for action steps in the event of an alert 
  4. Run DDoS simulation with the SOC to validate the service. (2 free test included with your service).

 

  • Route Advertisement

This feature allows for advertisements to be pushed up-stream to F5's peers via a self-service form on the console. In some situations, you might not want traffic always routing through F5 so this feature allows you to re-route traffic by providing the ability to control when F5 makes your prefix announcement up-stream. 

Additional Information: How do I advertise a Prefix?

 

  • Fast ACLs for Internet VIPs

Using the F5® Distributed Cloud Console Fast ACLs, you can block traffic from specific sources, or apply a rate limit to the traffic from a specific source. You can also enhance protection by filtering traffic based on source address, source port, destination address, destination port, and protocol.

Additional Information: Configure Fast ACLs

  • Redwolf DDoS Simulation

F5 Distributed Cloud provides the capability to generate a realistic DDoS attacks for all DDoS customers. The main goal of DDoS testing is to evaluate the resiliency of the customer's systems and processes in addition to demonstrating F5 Distributed Cloud scrubbing capabilities. Providing us with an assessment of our current security posture.
