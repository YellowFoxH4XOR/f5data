Issue

Old Behavior

In versions prior to BIG-IP 11.2.0, you can use objects defined in the IF-MIB SNMP management information base (MIB) to perform an SNMP poll on the BIG-IP system for network interface objects including statistics, such as ifHCInOctets or ifHCOutOctets.

The IF-MIB SNMP MIB defines the generic objects for network interface sub-layers.

New Behavior

Beginning in BIG-IP 11.2.0, the BIG-IP system publishes network interface data through the sysIfxStat SNMP objects defined in the F5-BIGIP-SYSTEM-MIB file instead of the IF-MIB SNMP MIB. Using the previous example, the replacement MIB for ifHCInOctets or ifHCOutOctets is sysIfxStatHcInOctets or sysIfxStatHcOutOctets, respectively.

If you attempt to perform an SNMP poll using objects defined in the IF-MIB SNMP MIB on BIG-IP 11.2.0 and later, the system returns an error message.

For example:

IF-MIB::ifHCInOctets = No Such Object available on this agent at this OID

F5 Product Development tracked this change as ID 374163.

Impact

Any SNMP Management station that continues to poll BIG-IP systems running 11.2.0 and later, using objects defined in the IF-MIB SNMP MIB, may encounter an error message stating that the object is not available.

Recommended Actions

F5 recommends that you reconfigure your SNMP Management station to use the new sysIfxStat SNMP objects from the F5-BIGIP-SYSTEM-MIB file if you want your SNMP Management station to collect data for the network interfaces on BIG-IP systems running 11.2.0 and later.

Important: Data returned by the sysIfxStatHcInOctets and sysIfxStatHcOutOctets OIDs are not synonymous with the ifHCInOctets and ifHCOutOctets OIDs. The sysIfxStatHcInOctets and sysIfxStatHcOutOctets OIDs return data associated with the BIG-IP switch interfaces, and the ifHCInOctets and ifHCOutOctets OIDs return data for Linux interfaces.
