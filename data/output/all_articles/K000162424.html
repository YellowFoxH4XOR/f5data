Description

This article explains how to disable or remove an ASM's Bot Defense profile assigned to a BIG-IP ASM virtual server and describes the expected impact. 

Environment

  • BIG-IP ASM/AWAF Module
  • Bot Defense profile assigned to a virtual server
  • LTM virtual server may also use SSL, load balancing, and ASM security policy features

Cause

No product fault was identified. This is a configuration question about disabling or removing a Bot Defense profile.

Answer/Recommended Actions

It is possible to disable or remove the Bot Defense profile for your desired Virtual Server. In this regard, you can follow the below steps on WebUI:

Important: You may consider performing the change during a planned Maintenance window to avoid any unexpected service disruption or traffic misbehavior.

 

  1. Login to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the applicable virtual server.
  4. Select the Security tab.
  5. Set the Bot Defense Profile field to None.
  6. Save the configuration.
  7. Verify application traffic after the profile is removed.

 

Important: Removing the Bot Defense profile has one direct security impact:

  • Bot Defense protection will no longer be applied to traffic passing through that virtual server.
  • Bot detection, bot classification, mitigation, browser verification, and challenge/CAPTCHA enforcement provided by the profile will stop.
  • Traffic that would previously have been identified or mitigated by Bot Defense may be forwarded to the backend application unless another security control handles it.
  • The application may become more exposed to automated attacks, web scraping, brute-force activity, and Layer 7 DoS activity that Bot Defense was intended to prevent.

Note: According to the BIG-IP documentation, Bot Defense uses browser verification, JavaScript evaluation, cookies, and bot signatures to identify and mitigate automated traffic. These controls will no longer apply after the profile is detached. [Configuring Bot Defense]
