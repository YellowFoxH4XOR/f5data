Issue

The following error message indicates that the user has supplied an incorrect password during the authentication process:

AD module: authentication with '<username>' failed in krb5_get_init_creds_password(): Preauthentication failed, principal name: <username>@<domain>. Invalid user credentials. (-1765328360)

Note: The error can also occur if the AAA server has Kerberos Preauthentication Encryption Type configured with an encryption value and the backend server doesn't support the same encryption type.

If a user reports that they are unable to authenticate, and the above error message is in your /var/log/apm file, have the user confirm they are using the correct password. If they are still unable to authenticate, instruct the user to contact their Active Directory administrator to resolve the issue.
