This article provides an overview of several large, bundled engineering hotfixes (EHF), released on top of their corresponding BIG-IP versions. For example, the EHF Hotfix-BIGIP-21.1.0.4.0.19.3-ENG is released on top of the BIG-IP version 21.1.0.4. This article covers where to find a list of fixes, installation prerequisites, and references to upgrade guidelines and documentation to assist you.

The following is a list of the bundled EHFs F5 released:

  • Hotfix-BIGIP-21.1.0.4.0.19.3-ENG
  • Hotfix-BIGIP-17.5.1.11.0.61.12-ENG
  • Hotfix-BIGIP-17.5.1.10.0.80.35-ENG
  • Hotfix-BIGIP-17.1.3.7.0.21.4-ENG
  • Hotfix-BIGIP-17.1.3.6.0.14.20-ENG
  • Hotfix-BIGIP-21.1.0.2.0.30.22-ENG (Also includes a fix for CVE-2026-94127)
  • Hotfix-BIGIP-17.5.1.9.0.160.12-ENG (Also includes a fix for CVE-2026-94127)
  • Hotfix-BIGIP-17.5.1.9.0.46.12-ENG
  • Hotfix-BIGIP 17.1.3.5.0.41.14-ENG (Also includes a fix for CVE-2026-94127)
  • Hotfix-BIGIP-17.1.3.5.0.1.14-ENG

For a list of issues that the EHFs resolve, refer to the accompanying EHF_Release_Notes PDF files for each release on the MyF5 Downloads page.

Note: When planning for an upgrade to BIG-IP version with the EHFs, consider the following factors:

  • If you are not currently running an engineering hotfix, you should review the IDs listed in the applicable EHF release notes. Once that review is done, you can then determine whether it is applicable and apply it as needed or proactively.
  • If you are currently running an engineering hotfix:
    • Review the EHF release notes to ascertain the status of the IDs in your current EHF. If you find all the IDs in your current EHF are fixed, then you can use just the base image. You should also review the release notes for the EHF on the MyF5 Downloads page and determine whether to install the EHF as needed or proactively.
    • If you find that not all IDs are fixed in the versions listed above with EHF, then review the release notes for the applicable EHF. If you find that the IDs you have are found there, then install the EHF.
    • After your review of the IDs in your current EHF, if it is shown that an ID from the current EHF is not fixed or is not listed in the release notes, open a case with F5 Support. Please provide a clear statement of what you discovered and why you are requesting an engineering hotfix for a specific BIG-IP version. Please include the IDs in question.

Description

The EHFs are delivered as part of F5's commitment to addressing critical customer needs and resolve a wide range of known issues across multiple components. The bundled EHFs are designed to build on the respective base version of the corresponding EHF. For example, Hotfix-BIGIP-21.1.0.4.0.19.3-ENG is built on the 21.1.0.4 base version.

Recommendations

You must upload the base BIG-IP version to the system before applying the corresponding EHF for each of those releases. The base image and the engineering hotfix must reside on the BIG-IP system and are stored in the default image location, /shared/images, so the BIG-IP system can automatically install the image if needed when you perform a hotfix installation. They can be seen in the GUI at System >> Software :: Image or System >> Software :: Hotfix.
