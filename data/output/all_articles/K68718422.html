Description

Monitor Logging has been turned on for all pool members, however monitors are not writing logs to /var/log/monitors.

/var/log/ltm will show logs similar to:
Couldn't open logging file /var/log/monitors/<Monitor name/ IP> log for monitor /Shared-<Monitor name/ IP>

Environment

  • Monitor logging enabled

Cause

Unknown at the time of creation of this article.

Recommended Actions

  1. Check the permissions for the /var/log/monitors directory, you can do this with:
    ls -dlZ /var/log/monitors
  2. If the permission is not correct then fix it as expected:
    chown root /var/log/monitors
