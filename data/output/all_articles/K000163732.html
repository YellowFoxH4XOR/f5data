K000163732: NGINX One Console WAF Read-Only Access Role does NOT grant Assigned User Access to WAF Security Dashboard

Type
Support Solution
Published
2026-10-15
Updated
2026-10-15
Applies to
  • NGINX Products
  • NGINX One Console
Source
https://my.f5.com/manage/s/article/K000163732

Description

In NGINX One Console, a user assigned the available monitor and read-only API groups cannot access the WAF Security Dashboard, WAF security events and analytics, or Support ID details. Assigning the broader f5xc-nginx-one-user role provides access but also grants instance-edit permissions.

Environment

  • Product: NGINX One Console
  • Feature: Role-based access control (RBAC)
  • Affected functionality:
    • WAF Security Dashboard
    • WAF security events and analytics
    • Support ID details
  • Relevant API groups:
    • f5xc-nginx-one-monitor
    • f5xc-nginx-one-standard-application-monitor
    • f5xc-nginx-one-custom-app-protect-read

Cause

The available read-only API groups do not expose all API endpoints required by the WAF Security Dashboard and Support ID details.

The missing read-only permissions include endpoints for:

  • WAF analytics
  • WAF security events
  • App Protect signatures
  • App Protect signature sets
  • Threat-campaign versions
  • App Protect versions

The f5xc-nginx-one-custom-app-protect-read API group provides read access to items such as policies, signatures, signature sets, log profiles, and settings, but it does not provide all analytics and event permissions required by the affected views.

Recommended Actions

Read-only access is supported only for the functionality exposed by the assigned API groups. Use one of the following approaches:

  1. Assign the built-in f5xc-nginx-one-monitor role when its available read-only access meets the requirement.
  2. Create a custom role containing only applicable read-only API groups, such as:
    • f5xc-nginx-one-custom-app-protect-read
    • f5xc-nginx-one-standard-application-monitor
    • Other applicable NGINX One read-only API groups
  3. Do not assign f5xc-nginx-one-user if the user must not edit instances. This role provides broader access, including instance-edit permissions.
  4. Validate the custom role by signing in as the analyst and checking access to:
    • WAF Security Dashboard
    • WAF security events and analytics
    • Support ID details
    • Instance configuration without edit controls

Additional Information

If the WAF Security Dashboard or Support ID details remain unavailable after assigning all applicable read-only and monitor API groups, the required permissions are not currently exposed through RBAC. A custom role cannot provide access to endpoints that are absent from the available API-group definitions.

A product fix is required to add the missing WAF read-only endpoints to the appropriate API groups. After the fix is available, update the custom analyst role and verify that it provides the required WAF visibility without including instance-management permissions.
