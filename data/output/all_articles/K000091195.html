Description

  • You use Nginx Controller to manage and configure your application on the Nginx Plus
  • You successfully created your API Gateways, APPs and APIs
  • Access to Application is working as intended
  • Nginx Plus is used to load balance traffic
  • However, from time to time, you observe an error message on the Nginx error logs similar to " (110: Connection timed out) while reading response header from upstream"
  • With this error, you also note application failing to load
  • You want to find and rectify the issue on the Nginx Controller

2022/02/30 11:05:17 [error] 82950#82950: *5202830 upstream timed out (110: Connection timed out) while reading response header from upstream, client: 198.51.100.1, server: 172.16.1.16, request: "POST /example/exampleParameters.do HTTP/1.1", upstream: "https://172.16.1.116:8003/example/exampleParameters.do", host: "example.nginx.com:4443", referrer: "https://example.nginx.com:4443/example/exampleParameters.do"

 Environment

  • Nginx Controller
  • Nginx Plus 
  • Components

 Cause

  • End server fails to respond to HTTP request within the default NGINX Plus timeout of 60s 

 Recommended Actions

  • The error message "upstream timed out (110: Connection timed out) while reading response header from upstream" is caused when an upstream web server takes more time to complete the request.
  • We can mitigate this timeout by increasing the value of "proxy_read_timeout" directives.
  • Proxy_read_timeout defines the timeout for receiving a response from proxied server and the default value is set to 60s.
  • However, currently we do NOT have an option on the Nginx Controller to modify Proxy_read_timeout directive to a higher value.

 Additional Information

It is possible to edit timeout for configured Components on Nginx Controller Under Service >> Apps >> Edit Component >> Workload Groups >> Additional Settings. Timeout values that can be configured on the controller are "Connect timeout" and "Send timeout". In other words, we do not have the full set of directives that can be configured on Nginx + on Nginx Controller. The two timeout values that can be set to a different values are

 

Connect timeout

Set a timeout for establishing a connection with a proxied server. It defines a timeout for establishing a connection with a proxied server. Default value is 60s

Connect timeout is equivalent to proxy_connect_timeout on Nginx Plus

this value should not exceed 75s

 

Send Timeout

Sets a timeout for transmitting a request to the proxied server. Default value is 60s

Send Timeout is equivalent to proxy_send_timeout on Nginx Plus

This directives sets a timeout for transmitting a request to the proxied server. The timeout is set only between two successive write operations, not for the transmission of the whole request. If the proxied server does not receive anything within this time, the connection is closed.
