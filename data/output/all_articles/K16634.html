Known Issue

iControl-REST queries that use headers beginning with X-F5 may return empty HTTP responses. The X-F5-REST-Coordination-Id header is not affected.

This issue occurs when all of the following conditions are met:

  • You attempt to query the configuration data of a BIG-IP system using the iControl/REST API.
  • Your query uses a header beginning with X-F5.

    For example:

    curl -k --header "X-F5-Auth-Token: 12345ABC678DEF910GHI11GHI13JKL15MNO17" "http://127.0.0.1/mgmt/tm/sys/ha-status"

Impact

The BIG-IP system responds with empty HTTP responses.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iControl-REST API queries return empty HTTP responses.
