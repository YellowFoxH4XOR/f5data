Topic

This article provides a description of the cron utility behavior on BIG-IP systems.

Note: In BIG-IP 12.0.0 and later, the BIG-IP system uses the anacron utility to manage certain scheduled jobs. For more information, refer to K70264550: The BIG-IP system uses anacron to manage scheduled jobs for daily, weekly, and monthly tasks.

Description

The BIG-IP system uses the cron utility to schedule periodically executed tasks defined in the /etc/crontab configuration file. For example, the daily log rotation on BIG-IP systems occurs every day at 04:02. The cron utility can schedule tasks for the system to execute, based on fixed times, dates, or intervals. Intervals can be based on minute, hour, day of month, month, and day of week.

On BIG-IP systems, cron uses the run-parts utility, which executes all files within a directory. This configuration makes the /etc/crontab file smaller and easier to maintain because, instead of maintaining individual configuration items in the /etc/crontab file, the BIG-IP system separates scheduled tasks into the following four directories, relatively specifying the hourly, daily, weekly, and monthly intervals. The run-parts utility executes all scripts in those directories at the scheduled intervals:

  • /etc/cron.hourly
  • /etc/cron.daily
  • /etc/cron.weekly
  • /etc/cron.monthly

The BIG-IP system /etc/crontab file appears similar to the following example:

SHELL=/bin/bash
PATH=/sbin:/bin:/usr/sbin:/usr/bin
MAILTO=""
HOME=/

# run-parts
01 * * * * root run-parts /etc/cron.hourly
02 4 * * * root run-parts /etc/cron.daily
22 4 * * 0 root run-parts /etc/cron.weekly
42 4 1 * * root run-parts /etc/cron.monthly

The cron utility uses the following schedule syntax in the /etc/crontab configuration file:

* * * * * command to be executed
- - - - -
| | | | |
| | | | +----- day of week (0 - 6) (Sunday=0)
| | | +------- month (1 - 12)
| | +--------- day of month (1 - 31)
| +----------- hour (0 - 23)
+------------- min (0 - 59)

The /etc/crontab file configuration described in the previous example run scripts in each of the directories at the following intervals:

DirectoryScheduleRun time
/etc/cron.hourly01 * * * *First minute of every hour, every day. For example, 01:01.
/etc/cron.daily02 4 * * *Only once per day, at 04:02.
/etc/cron.weekly22 4 * * 0Only once per week, at 04:22 on Sunday.
/etc/cron.monthly42 4 1 * *Only once on the first day of each month, at 04:42.

The schedule variance ensures that the BIG-IP system doesn't execute the hourly, daily, weekly, and monthly tasks at the same time. To see a list of all the scheduled tasks on the BIG-IP system, type the following command:

ls -l /etc/cron.*

For more information about the /etc/crontab configuration syntax, refer to the crontab man page by typing the following command:

man 5 crontab
