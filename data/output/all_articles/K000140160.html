Description

rSeries report PSU-x fault is detected.

/var/log/platform/pel log repeatedly logs

| AOM | 255 | Na | 4 | PSU 1 SMB alert CPLD event

 

The below command shows

show system events

66305 psu-1 psu-fault ASSERT CRITICAL "PSU fault detected" "YYYY-MM-DD HH:MM:SS.mmmmmmmmm UTC"
66305 psu-1 psu-fault EVENT NA "Deasserted: PSU x output OK" "YYYY-MM-DD HH:MM:SS.mmmmmmmmm UTC"
66305 psu-1 psu-fault EVENT NA "PSU voltage out value < lower limit, value=1.5" "YYYY-MM-DD HH:MM:SS.mmmmmmmmm UTC"   

 

Environment

  • F5OS-A
  • rSeries
  • PSU

 

Cause

  • Badly seated 
  • Faulty appliance
  • Faulty PSU

 

Recommended Actions

  • Reseat and monitor.
  • Also in maintenance window, swap the known-good PSU, and check if the "show system health" command output shows same error or not.
  • If it is the same error, possibly appliance side has issue.
  • Generate fresh qkview from F5OS before and after reseated and raise a case F5 Support.
