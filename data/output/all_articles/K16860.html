Known Issue

Attempts to modify Microsoft Outlook Web App (OWA) 2013 settings through portal access may fail.

This issue occurs when all of the following conditions are met:

  • You are using Microsoft Internet Explorer 10 or 11.
  • You have established a portal access session to an OWA 2013 application.
  • You attempt to modify an OWA setting or view OWA objects.

Impact

The OWA page does not respond.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to access OWA settings or objects, the page appears to be loading but the content never displays.
  • When attempting to modify an OWA setting, you receive a critical error message similar to the following:

    Unable to set property 'value' of undefined or null reference
