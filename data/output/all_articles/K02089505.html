K02089505: Using the '/security/strategies/balanced_default' API endpoint for the default Security Strategy

Type
Knowledge
Published
2021-07-20
Updated
2026-04-21
Status
Legacy Content
Applies to
  • NGINX Products
  • NGINX Controller: 3.18.1, 3.18.0
Source
https://my.f5.com/manage/s/article/K02089505

Topic

In NGINX Controller versions after 3.18.x, when enabling WAF on an app component, F5 recommends that you use the API endpoint /security/strategies/balanced_default instead of /services/strategies/balanced_default.

Description

In an effort to group Controller App Security API endpoints under the /security/ root, F5 plans to deprecate the /services/strategies/balanced_default endpoint in an upcoming release. Look for the deprecation notice one month before the actual deprecation.

Example:

JSON object for the security configurations on an app component

https://{{CONTROLLER_FQDN}}/api/v1/services/environments/{environmentName}/apps/{appName}/components/{componentName}

     "security": {
      "strategyRef": {
        "ref": "/security/strategies/balanced_default"
      },
      "waf": {
        "isEnabled": true,
      }
    }

NGINX Product Development tracked this change as IND-26046.

Impact

You may need to update your app components configured for WAF that previously referenced /services/strategies/balanced_default.

Note: Not specifying the ‘StrategyRef’ will imply the correct default security strategy API endpoint. If you have a configuration similar to the following, you should not be impacted by this change of behavior:

        "security": {
            "waf": {
                "isEnabled": true
            }
        }
 

Recommended Actions

Use role-based access control

When using role-based access control (RBAC), you can use the /platform/roles endpoint in the NGINX Controller REST API to configure the user with the appropriate permissions to access /security/strategies/ path.

In this example, all resources under /security/strategies/ inherit READ access:

{
 "access": "READ",
 "path": "/security/strategies/"
}
