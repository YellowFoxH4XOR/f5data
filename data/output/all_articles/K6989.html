K6989: SSLv2 is disabled in the browser and ClientSSL profile but SSLv2 Hello appears in the SSL connection

Topic

When SSLv2 is disabled in both the browser and the ClientSSL profile (default), and a tcpdump capture is taken of the connection, an SSLv2 Client Hello results.

This behavior is normal. SSLv2 Client Hello is used for compatibility reasons, as some systems did not understand the later SSL version numbers. When SSLv2 is disabled on the client side, the SSLv2 Client Hello version field number is set to 3. As a result, the server will issue an SSLv3 Server Hello response, and both client and server will then negotiate and establish an SSLv3/TLSv1 connection.

For additional information about Client SSL Connections, refer to the following Mozilla security article:

http://www.mozilla.org/projects/security/pki/nss/ssl/traces/trc-clnt-us.html
