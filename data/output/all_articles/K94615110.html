Issue

Old Behavior

In versions prior to BIG-IP 14.1.0, configuring firewall rules on the management port context requires a BIG-IP AFM license.

The BIG-IP AFM module is a separately licensed product that must be purchased and provisioned on the BIG-IP system. With BIG-IP AFM provisioned, you can configure the BIG-IP system management port using firewall rules.

New Behavior

Beginning in BIG-IP 14.1.0, you can configure the BIG-IP system management port with firewall rules without any additional license or product provisioning.  However, due to an issue in some versions, you may need to use iptables to enable logging if BIG-IP AFM isn't provisioned.  F5 Product Development is tracking this issue as ID 871457.

You can configure firewall rules for the BIG-IP system management port using the Configuration utility. By default, there are no firewall rules configured on the management port context.

F5 Product Development tracked this change as ID 248221.

Impact

None

Recommended Actions

You can view the firewall rules configured for the BIG-IP management port using the Configuration utility or the TMOS Shell (tmsh).

  • Viewing firewall rules configured on the BIG-IP management port using the Configuration utility
  • Viewing firewall rules configured on the BIG-IP management port using tmsh
  • Enabling logging for firewall rules using the Configuration utility
  • Enabling logging for firewall rules using tmsh

Viewing firewall rules configured on the BIG-IP management port using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Platform > Security.

Viewing firewall rules configured on the BIG-IP management port using tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Enter the following command:

    list /security firewall management-ip-rules

You can enable logging configured for the firewall rules for the BIG-IP management port using the Configuration utility or tmsh.

Enabling logging for firewall rules using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Log > Configuration > Log Publishers.
  3. Select default-mgmt-acl-log-publisher.
  4. To enable logging, move local-syslog to Selected Destination.
  5. If your system is impacted by ID 871457, perform one of the following sub-procedures, depending on whether your system is provisioned with BIG-IP APM:
    • If BIG-IP AFM is provisioned and your system is impacted by ID 871457:
      1. Go to Security > Event Logs > Logging Profiles.
      2. Select global-network.
      3. Select the Network Firewall tab.
      4. Select the Accept, Drop, and Reject check boxes for Log Rule Matches.
      5. Select Update.
    • If BIG-IP AFM is not provisioned and your system is impacted by ID 871457:
      • To view the counters, enter the following command:

        /sbin/iptables -vL f5acl

      • To enable logging, log in to the Advanced Shell (bash) and enter the following command:

        /sbin/iptables -I f5acl -j LOG --log-prefix "IPTables-Log: "

        Note: If you want to enable logging, you must do so after every restart.

      • To disable logging,  log in to bash and enter the following command:

        /sbin/iptables -D f5acl -j LOG --log-prefix "IPTables-Log: "

Enabling logging for firewall rules using tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Enter the following command:

    modify sys log-config publisher default-mgmt-acl-log-publisher destinations replace-all-with { local-syslog}

    Note: You can use the Configuration utility to attach the log publisher to the global-network logging profile by logging in to the Configuration utility and going to Security > Event Logs > Logging Profiles > Edit Logging Profile.

  3. Perform one of the following sub-procedures, depending on whether your system is provisioned with BIG-IP AFM:
    • If your system has BIG-IP AFM provisioned and it is impacted by ID 871457, to finish enabling logging, enter the following tmsh command:

      modify security log profile global-network { network modify { global-network { filter { log-acl-match-accept enabled log-acl-match-drop enabled log-acl-match-reject enabled }}}}

    • If your system does not have BIG-IP AFM provisioned, you can enable logging only by using the previously listed iptables examples.

For more information on configuring firewall rules on the management interface, refer to the Applying AFM Network Firewall Policies chapter in the BIG-IP AFM: Network Firewall Policies and Implementations manual.
