Description

BIG-IP may not forward the traffic to pool members, if it receives with high MSS(Maximum segment size).

Environment

  • BIG-IP LTM
  • TCP profile
  • MSS

Cause

There is an option with MSS size in tcp profile

Default value is set to maximum i.e., 1460 bytes but can be modified to any other value between 0 - 1460.

Recommended Actions

Verify if MSS value in a TCP profile assigned to Virtual server is less than the expected MSS by navigating to Local Traffic  ››  Profiles : Protocol : TCP  ››  < tcp profile name >
