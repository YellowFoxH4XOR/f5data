Description

You have an existing per-session access policy.

You would like to create different branches based on the client accessing the policy via a mobile browser and a full desktop browser.

 

Environment

An existing APM Per session policy

Desktop and Mobile client devices

Cause

none

Recommended Actions

For this use scenario, we can achieve this by using a Client Type block in the VPE.

To start, it is recommended to create a copy of your policy as a backup before proceeding.

Now open the GUI and navigate to:

Access ›› Profiles / Policies : Access Profiles (Per-Session Policies) ›› (Your policy name)


Switch to the "Access Policy" tab and click on Edit Access Policy for Profile "Your policy name" to open the VPE.

 

Now we will add a Client Type block. We can add it on the very start of the policy, after the "Start" arrow, but this is ultimately up to you. Once you decide where you want this check for branching out the policy, click the little plus and add it.

 

Once you add it, you will notice that this block has many branches. Your policy was automatically attached to the first branch, so "Edge Portal".

 

Important: Before we proceed with modifying these branches, we need to make sure we do not delete the policy by mistake. To do that, click on the arrow named "Swap items" that is located between the "Edge Portal" branch and the rest of your policy, and temporarily move it to the "fallback" branch, as we will not be modifying this one.

 

Now click the Client Type block to modify the endings. Switch to the "Branch Rules" tab. Remove all the branches you do not need - since this article describes branching out based on the client accessing the policy via a Full or Mobile browser, you can remove all branches other than "Full or Mobile Browser" and "fallback". Click Save, you will notice that the extra branches are now gone.

 

Notice that we are now left with only "Full or Mobile Browser" branch and a "fallback" branch. We still need to split Mobile from Full. Open Client Type and the "Branch Rules" tab again. Change the name of "Full or Mobile Browser" to "Full browser" or similar. Click on "change" under this entry. You will see three expressions - Full browser, Mobile browser, and Pocket PC. Delete the Mobile browser and Pocket PC and click Finished.

 

Now click on "Add a new branch rule". The rule by default will be named "Branch Rule 1". You can change the name to "Mobile browser" or similar, as this is what we will be using it for. The Expression for that branch rule is empty, so click on "change" to modify it. In the new menu that opens, click "Add expression", and from the "Context" dropdown menu choose "UI Mode". From the "UI Mode is" dropdown menu choose "Mobile Browser", and click "Add expression" to confirm. Now click "Finished" and "Save".

 

You should now have a Client Type block with three branches: Mobile browser, Full browser and fallback. Feel free to move back the rest of the policy from the fallback branch where we put it into its appropriate position (for example Full Browser branch). Remember to adjust the policy endings, as the newly created ones will end in "Deny".
