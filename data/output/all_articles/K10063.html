Known Issue

This is the result of a known issue. When you install a BIG-IP 10.0.0 hotfix, the system does not apply the configuration and license from the current installation location to the target installation location.

F5 Product Development tracked this issue as CR115938 and it was fixed in BIG-IP 10.0.1. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WAN Optimization release notes.

Workaround

To apply a configuration and license, you can install the base BIG-IP version on the target boot location prior to installing the hotfix. Installing the base BIG-IP version on the target boot location also copies the current running configuration and license from the active boot location to the target boot location.

For example, if the BIG-IP system is running version 10.0.0 on the active boot location (for example, HD1.1) and you want to install HF2, designate an inactive boot location for the installation (for example, HD1.2). Next, install the base version 10.0.0 ISO image on the inactive boot location, which copies the current configuration and license from the active boot location, and install HF2 on the inactive boot location.
