Issue

Error Message

err sod[<PID>]: 010c008a:3: Invalid go standby command. </Partition/Unit Name> is not a valid device.

In this error message, note the following:

  • <PID> is the process ID for the sod process
  • </Partition/Unit Name> is name of the partition and the unit name specified for the device

For example:

err sod[5374]: 010c008a:3: Invalid go standby command. /Common/BIGIP02 is not a valid device.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An administrator runs the cmd_sod command directly from the Linux shell and provides an invalid argument.

Impact

Failover does not occur.

Recommended Actions

To work around this issue, you can specify the correct unit name in the cmd_sod command.
