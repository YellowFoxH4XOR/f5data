Description

BIG-IP systems configured for remote high-speed DNS logging do not support configuring a Splunk type log destination. F5 is tracking this issue in ID464708.

When you configure remote high-speed DNS logging, the system allows you to select a Splunk type log destination; however, the system does not send the messages in a Splunk format and the messages do not contain the expected DNS request information. The system logs an empty message similar to the following example:

hostname=""XXXXXXXXXXXXX.XX"",errdefs_msgno=""01230140:3:"""

Recommendations

When you configure DNS logging to a remote destination, you can configure the BIG-IP system to send unformatted messages or syslog formatted messages.

To configure the BIG-IP system to send unformatted messages to a remote high-speed logging server, configure the log destination to use a remote high-speed log and to send messages to a pool of remote high-speed logging servers.

A possible workaround to send DNS request and response logs to a Splunk server is to use an iRule to format the log message in the style that Splunk expects. For an examples, refer to Prepare F5 servers to connect to the Splunk platform on the Splunk Docs site or the Workaround section in ID464708.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

If your remote logging servers support the syslog formatting standard, you can create both a remote syslog and a remote high-speed log type log destination. Configure the remote syslog log destination to specify both the syslog format you want and the remote high-speed log destination.

To configure DNS logging to send DNS request log messages, log in to the Configuration utility and perform the following procedures:

Note: The Creating a remote syslog log destination to use the remote high-speed log type log destination procedure is required only if you want to send syslog formatted messages.

  • Creating a pool of remote high-speed syslog logging servers
  • Creating a remote high-speed log type log destination to use the pool you created
  • Creating a remote syslog log destination to use the remote high-speed log type log destination
  • Creating a log publisher to use a log destination
  • Creating a custom DNS logging profile to use the log publisher
  • Assigning the custom DNS logging profile to a DNS profile

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

Creating a pool of remote high-speed syslog logging servers

Create a pool of remote log servers to which the BIG-IP system can send log messages, by performing the following procedure:

  1. Go to DNS > Delivery > Load Balancing Pools.
  2. Select Create.
  3. For Name, enter a unique name for the pool.
  4. For New Members, add the IP address for each remote logging server that you want to include in the pool:
    1. For Address, enter an IP address, or from the Node List select a node address.
    2. For Service Port, enter a service number, or select a service name from the list.

      Note: Typical remote logging servers require port 514.

    3. Select Add.
    4. Repeat the previous steps for each logging server you want to include in the pool.
  5. Select Finished.

Creating a remote high-speed log type log destination to use the pool you created

  1. Go to System > Logs > Configuration > Log Destinations.
  2. Select Create.
  3. For Name, enter a unique, identifiable name for this destination.
  4. For Type, select Remote High-Speed Log.
  5. For Pool Name, select the pool of remote log servers that you previously created.
  6. For Protocol, select the protocol used by the high-speed logging pool members.
  7. Select Finished.

Creating a remote syslog log destination to use the remote high-speed log type log destination

  1. Go to System > Logs > Configuration > Log Destinations.
  2. Select Create.
  3. For Name, enter a unique, identifiable name for this destination.
  4. For Type, select Remote Syslog.
  5. For Syslog Format, select the format you want for the logs.
  6. For Forward To, select the Remote High-Speed Log type log destination you previously created.
  7. Select Finished.

Creating a log publisher to use a log destination

  1. Go to System > Logs > Configuration > Log Publishers.
  2. Select Create.
  3. For Name, enter a unique, identifiable name for this publisher.
  4. For Destinations, select the log destination you want in the Available list, and move it the destination to the Selected list.
    • For unformatted messages, select the Remote High-Speed log destination you previously created.
    • For syslog formatted messages, select the Remote Syslog log destination you previously created.
  5. Select Finished.

Creating a custom DNS logging profile to use the log publisher

  1. Go to DNS > Delivery > Profiles > Other > DNS Logging.
  2. Select Create.
  3. For Name, enter a unique name for the profile.
  4. For Log Publisher, select the log publisher that you previously created.
  5. If you want the BIG-IP system to log all DNS queries, then for the Log Queries setting ensure that you select Enabled.
  6. If you want the BIG-IP system to include the query ID that the client in the log messages sent, then in the Include Query ID field, select Enabled.
  7. Select Finished.

Assigning the custom DNS logging profile to a DNS profile

  1. Go to DNS > Delivery > Profiles > DNS.
  2. Select the DNS profile that you want to configure.
  3. For Logging, select Enabled.
  4. For Logging Profile, select the DNS Logging profile you previously created.
  5. Select Finished.
