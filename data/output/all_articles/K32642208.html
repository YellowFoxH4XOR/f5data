Known Issue

Address list creation fails when using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has neither the BIG-IP AFM module nor the BIG-IP ASM module provisioned.
  • You navigate to Shared Objects > Address Lists in the Configuration utility and attempt to create an address list.

Impact

When you click Finish, the BIG-IP system fails to save the address list.

Symptoms

As a result of this issue, you may encounter one or more of the following symptom:

  • When attempting to create an address list using the Configuration utility, the system displays the following message:

    An error occurred:

    Public URI path not registered: /tm/security/shared-objects/address-list/

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

While there is no workaround for this issue, if you have BIG-IP AFM or BIG-IP ASM licensed, you can provision either the BIG-IP AFM module or the BIG-IP ASM module which allows you to create address lists. To do so, refer to the procedure for your version in K12111: Provisioning licensed BIG-IP modules.
