Topic

When attempting to upgrade an ARX system, if the downloaded release file was corrupted, the upgrade will fail. In addition, an error message that appears similar to the following example will display:

% ERROR: UNTAR_REL_ERROR (34340981):
  Untar to backup failed.

The release file should be downloaded again and the checksum verified using the show releases <release_filename> verbose command.

For example:

show releases V3.02.001.10856.rel verbose

If the checksum verification passes, the output will appear similar to the following example:

Version 3.02.001.10856 (Aug 26 2008 17:52:56) [nbuilds]
Checksum: Passed

If the checksum verification fails, the output will appear similar to the following example:

% ERROR: RELEASE_FILE_CHECKSUM_FAILED (40960142):
  The release file 'V3.02.001.10856.rel' checksum is failed
