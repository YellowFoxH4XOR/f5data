Description

A single DataMover CPU core (e.g., CPU12 on blade 1) in an F5OS-Appliance VELOS chassis may display continuous 100% utilization in system monitoring tools.


Environment

- Product: F5OS-A, F5OS-C

- Platform: F5-VEL-BTA-CX410-AC, F101 (VELOS chassis)

- Configuration: System with DataMover CPUs assigned to blades


Cause

This can raise concerns about potential performance impact or abnormal system behavior.


High or sustained 100% utilization on a single DataMover CPU can occur due to the way the dma-agent process handles certain traffic patterns, especially with UDP workloads. This is a known reporting artifact and does not necessarily indicate a real performance issue or data plane bottleneck. The process may intentionally busy-poll to achieve low-latency packet handling, resulting in monitoring tools reporting high CPU usage.


Recommended Actions

- Monitor application and system performance metrics (latency, throughput, error rates) to determine if there is any actual impact.

- Use the F5OS dashboard or SNMP to observe both average and per-core CPU utilization.

- If no performance degradation is observed, the high CPU usage on a single DataMover core can be considered normal and does not require action.

- If performance issues are detected, collect additional data (such as process-level CPU usage and traffic patterns) and contact F5 Support for further analysis.


Additional Information

Bug ID 1759757: UDP traffic may cause the F5OS dma-agent process to report artificially high CPU utilization.
