K000130637: APM user session not getting logged out

Type
Support Solution
Published
2023-01-18
Updated
2023-05-04
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000130637

Description

Using Microsoft Azure AD for authentication mechanism on the APM. After users log out from their session, on subsequent login attempts using the same browser session, users are not prompted to authenticate anymore, and are able to get access to the resources that have been assigned to them, straight away.


Environment

  • Azure AD
  • SAML Logout URL

Cause

Either the SAML Logout URL in Azure AD is not configured OR it is configured but there is a typo on the URL.
