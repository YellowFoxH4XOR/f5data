Topic

You should consider using this procedure under the following condition:

  • You want to dynamically display information about the traffic groups associated with devices in a device group

Description

The watch-trafficgroup-device utility displays dynamic information about the traffic groups associated with devices in a device group. You can view information such as the traffic groups associated with the device and the failover state, including any high availability (HA) failure condition.

Note: The BIG-IP system may experience a memory leak when running a centralized management infrastructure (CMI) watch script for an extended period of time. For more information, refer to K21473530: CMI watch scripts experience a memory leak.

The watch-trafficgroup-device utility displays dynamic information about the traffic group. The watch-trafficgroup-device columns are defined as follows:

  • devices

    Displays the suffix of the configuration synchronization (ConfigSync) IP address configured on the devices in the traffic group. For example, if the devices have the IP addresses 10.0.0.15 and 10.0.0.16, the IDs in the column will be 15 and 16.

  • traffic_group

    Displays the name of the traffic group associated with the device

  • device_name

    Displays the name of the device

  • failover_state

    Displays the HA state (active or standby) of the device

  • failure_condition

    Displays any detected failsafe fault conditions

  • monitor_fault

    Displays true for detected HA group fault conditions for the device

  • next_active

    Displays true for the device that becomes active if the active traffic group fails over

  • score

    Displays a system-generated HA score used to select the next active device

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have access to the TMOS Shell (tmsh).

Procedures

Displaying dynamic traffic group information

To run the watch-trafficgroup-device utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To run the watch-trafficgroup-device utility, type the following command:

    run /cm watch-trafficgroup-device

    For example, the following output indicates that devices bigip_1.local and bigip_3.local are associated with traffic group traffic-group-1, and bigip_1.local is experiencing a failsafe fault:

    Note: Type c to toggle the view from a collapsed view to a full view.

    devices  traffic_group    device_name   failover_state failure_condition  monitor_fault  next_active ha_group_name  score
    4 7      traffic-group-1  bigip_1.local HA_STANDBY     FAILSAFE_FAULT      -               -                        7694
    4 7      traffic-group-1  bigip_3.local HA_ACTIVE       -                  -               -                        7726

  3. Press Ctrl+C to exit the watch-trafficgroup-device utility.
