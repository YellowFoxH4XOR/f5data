Known Issue

The BIG-IP system incorrectly logs an Elliptic Curve Diffie-Hellman (ECDH) negotiation failure as a critical error.

This issue occurs when the following condition is met:

  • The system experiences a Secure Sockets Layer (SSL) negotiation failure involving an ECDH key agreement.

Impact

You may notice spurious critical error logs, causing unnecessary concern.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the system experiences a failure in an SSL negotiation involving an ECDH key agreement, the system logs a critical error; however, an SSL negotiation failure is not a critical issue.
