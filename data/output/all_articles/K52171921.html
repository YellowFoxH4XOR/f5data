Description

The steps to add the custom MIB entry is as follows.

The custom OID will need to be created following the steps in K3727: Configuring custom SNMP traps.

The customized MIB file will also need to be sent to the 3rd-party SNMP tool that the customer is using to process the SNMP traps from the BIG-IP.

Environment

  • BIG-IP
  • SNMP OID

Cause

None

Recommended Actions

  1. Download /usr/share/snmp/mibs/F5-BIGIP-COMMON-MIB.txt from the BIG-IP. See K175: Transferring files to or from an F5 system for details on how to download a file from a BIG-IP.

  2. Insert the following entries after the last entry under the bigipNotifications section.

    Note: This example assumes that your custom OID is '.1.3.6.1.4.1.3375.2.4.0.300' and that it is an SNMP trap for expiring SSL certificates.

    Use the following as a template, replacing <name>, <description> and <index_number> to suit your needs:

    <name>  NOTIFICATION-TYPE
        OBJECTS {
                    bigipNotifyObjMsg
        }
        STATUS      current
        DESCRIPTION
            "<description>"
        ::= { bigipNotifications <index_number> }

    For Example:

    bigipCertWillExpire  NOTIFICATION-TYPE
        OBJECTS {
                    bigipNotifyObjMsg
        }
        STATUS      current
        DESCRIPTION
            "An SSL certificate is about to expire."
        ::= { bigipNotifications 300 }

  3. Save the MIB file and provide this to the SNMP tool administrator for consumption.
