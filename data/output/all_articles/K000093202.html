Description

 

USB redirection requires secure tunnel to be enabled on the VCS.

If the environment does not have VCS and secure tunnel is disabled then USB redirection will not work.

 

Environment

 

  • BIGIP APM
  • VMware horizon agent
  • No VCS

 

Cause

 

Secure tunnel is disabled

 

Recommended Actions

 

For PCOIP, secure tunnel needs to be enabled on the VCS.

 

We support USB through Vmware virtual channel (VVC) with Blast:

 

On the VMware View Agent change the registry values:

  1.  Navigate to HKEY_LOCAL_MACHINE\SOFTWARE\VMware, Inc.\VMware UsbRedirection and set the sideChannelType key to vvc.
  2.  Navigate to HKEY_LOCAL_MACHINE\SOFTWARE\VMware, Inc.\VMware VDM\Agent\Configuration and set the UsbVirtualChannelEnabled key to true.
  3.  VCS Secure Tunnel disabled
  4.  Launch view virtual desktop via native view client from web browser APM webtop or from View client

 

With changes to registry VVC enabled on Agent:

1. USB redirection enabled in iApp and secure tunnel disable on VCS -- USB redirection works for only blast protocol
