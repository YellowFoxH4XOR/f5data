Known Issue

Lease pool statistics may display incorrect data.

This issue occurs when all of the following conditions are met:

  • You are running the BIG-IP APM system on a multiple blade chassis.
  • You attempt to view lease pool statistics using one of the following methods:
    • The Traffic Management Shell (tmsh) show command:

      tmsh /apm show resource leasepool <lease pool name or all>

    • Polling the apmLeasepoolStatCurMembers SNMP OID.

      For example:

      snmpwalk -v 2c -c <community name> <ip address> .1.3.6.1.4.1.3375.2.6.2.1.3.1.2

      or

      snmpwalk -v 2c -c <community name> <ip address> apmLeasepoolStatCurMembers

Impact

Returned statistic information is not complete.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The returned lease pool statistics are only representative of the chassis primary blade.
