Topic

You should consider using this procedure under the following conditions:

  • You use the iControl application programming interface (iControl SOAP API) to configure or manage the BIG-IP system.
  • You want to restrict access to the iControl SOAP API to a specific IP address or range of IP addresses.
  • You want to remove a specific IP address or range of IP addresses from the current list of allowed IP addresses for the iControl SOAP API.

Description

The iControl SOAP API is an XML-based messaging system that you can use to configure and manage the BIG-IP system. Depending on your organizational security requirements, one method to secure access to the iControl API is to allow only trusted IP addresses or range of IP addresses.

By default, the BIG-IP system allows any user with the Administrator role to access the iControl SOAP API, regardless of their source IP address.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to the BIG-IP system.

Procedures

  • Adding an IP address or range of IP addresses to the current allowed list
  • Replacing the current allowed list with a new list
  • Removing an IP address or range of IP addresses from the current allowed list

Note:  If you are adding an IP address or range of IP addresses for the first time, you should perform the Replacing the current allowed list with a new list procedure.
Note:  In order to configure a subnet range, you will need to specify a Perl Compatible Regular Expression to allow connections from a specific subnet. Using a CIDR notation is not supported

Adding an IP address or range of IP addresses to the current allowed list

To add an IP address or range of IP addresses to the current list of hosts that are allowed to access the iControl SOAP API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To add an IP address or range of IP addresses to the current allowed list of hosts, use the following command syntax:

    modify /sys icontrol-soap allow add { <IP address or IP address range> }

    For example, to add 172.16.1.1 and 172.16.2.1 to the current list, type the following command:

    modify /sys icontrol-soap allow add { 172.16.1.1 172.16.2.1 }

    To add the subnet 172.16.1.0/255.255.255.0 to the current list, type the following command:

    modify /sys icontrol-soap allow add { 172.16.1.* }

  3. To list the IP addresses of the current allowed hosts, type the following command:

    list /sys icontrol-soap

  4. Save the change by typing the following command:

    save /sys config

Replacing the current allowed list with a new list

To replace the current list of allowed hosts that can access the iControl SOAP API, perform the following procedure:

Important: Blocking iControl SOAP access from DSC IP addresses will prevent adding new devices to device trust; however, it doesn't interfere with ConfigSync, failover, or mirroring connectivity. For more information refer to K05914557: Adding new device to Device-Trust fails.

Impact of procedure: Access to the the iControl API is denied if the IP address or range of IP addresses is incorrect.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To replace the current list of allowed hosts with an IP address or range of IP addresses, use the following command syntax:

    modify /sys icontrol-soap allow replace-all-with { <IP address or IP address range> }

    For example, to replace the current list of allowed hosts with 172.16.1.1 and 172.16.2.1, you would type the following command:

    modify /sys icontrol-soap allow replace-all-with { 172.16.1.1 172.16.2.1 }

    To replace the current list of allowed hosts with the subnet 172.16.1.0/255.255.255.0, you would type the following command:

    modify /sys icontrol-soap allow replace-all-with { 172.16.1.* }

  3. Save the change by typing the following command:

    save /sys config

Removing an IP address or range of IP addresses from the current allowed list

To remove an IP address or range of IP addresses from the current list of hosts that are allowed to access the iControl SOAP API, perform the following procedure:

Important: Blocking iControl SOAP access from DSC IP addresses will prevent adding new devices to device trust; however, it doesn't interfere with ConfigSync, failover, or mirroring connectivity. For more information refer to K05914557: Adding new device to Device-Trust fails.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To remove an IP address or range of IP addresses from the current allowed list of hosts, use the following command syntax:

    modify /sys icontrol-soap allow delete { <IP address or IP address range> }

    For example, to remove 172.16.1.1 and 172.16.2.1 from the current list, type the following command:

    modify /sys icontrol-soap allow delete { 172.16.1.1 172.16.2.1 }

    To remove the subnet 172.16.1.0/255.255.255.0 from the current list, type the following command:

    modify /sys icontrol-soap allow delete { 172.16.1.* }

    Note: To deny access to the iControl SOAP API from any IP, you can remove all IP addresses or range of IP addresses from the list of allowed addresses by typing the following command:

    modify /sys icontrol-soap allow replace-all-with { }

  3. Save the change by typing the following command:

    save /sys config
