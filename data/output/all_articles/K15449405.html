Description

When trying to activate / reactivate license, you observed the dossier is blank on Configuration Utility, and / or the below error message is showing in CLI after running the get_dossier command per K2595: Activating and installing a license file from the command line:

<131>Mon DD HH:MM:SS bigip get_dossier[31589]: 01170003:3: halGetDossier returned error (1): Dossier generation failed.

Environment

  • License Activation
  • Re-activation
  • Configuration Utility
  • CLI
Cause

This can occur for a variety of reasons

Recommended Actions

If issue identified after an upgrade without reactivating license, roll back to previous version and reactivate the license. Attempt the upgrade again.  
K34745165: Managing software images on the BIG-IP system

If the issue on AWS instance, refer to:
K43503050: Error Message: 01170003:3: halGetDossier returned error (7): Dossier generation failed.
K000133772: AWS BIG-IQ unable to reactivate license - error when generating dossier
K55893068: AWS VE unable to reactivate license - error when generating dossier
K51550204: AWS instance INOPERATIVE after upgrade, unable to license the system
K26605521: AWS instance LTM log shows: Curl request to metadata service failed with error(22): 'HTTP response code said error'
K74004244: Unable to reactivate existing license on AWS BIGIP due to "halGetDossier returned error (1): Dossier generation failed" and K43503050 has already been applied
K83935515: Unable to use Metadata v2 with F5 deployed in AWS

If the issue is related to Bug ID 658853, refer to:
K00415052: AOM may stop responding during an upgrade on iSeries platforms

If you still need assistance, contact F5 Support:
K2633: Instructions for submitting a support case to F5
