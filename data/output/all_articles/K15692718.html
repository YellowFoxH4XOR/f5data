K15692718: Unable to select more than 1950~2000 Security Event logs in bulk amount

Description

When navigating to "Monitoring > Events > Web Application Security > Events" from the BIG-IQ, scrolling the Web Application Security Event Logs (so that the grid is populated with more than 2000 records), and checking the "Select All" checkbox located at the top left corner of the grid, only a maximum of 1950~2000 are selected at any single time. 

Environment

  • BIG-IQ Centralized Management
  • BIG-IP ASM
  • Web Application Security Event Logs from BIG-IQ
  • Selecting more than 1950 event logs

Cause

This issue is due to the limitation on the number of Security Event records that can be displayed/selected/exported from the grid. It is limited to 1950~2000 records. 

Recommended Actions

There are no options or workaround to export all of the event logs at the same time at this point. Limit the event logs to 1950 events per export.

    Additional Information

    There is also a documented limitation of the BIG-IQ's webd (nginx) process, wherein you cannot export more than 1800 event logs. If you encounter such issue, refer to K41738401: Not able to export Web Application Security Event Logs from the BIG-IQ with error message "413 Request Entity Too Large"
