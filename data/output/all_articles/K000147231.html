K000147231: How do I configure mTLS?

Description

  • I want to configure mTLS on the front or backend

Environment

  • F5® Distributed Cloud Load Balancer
  • F5® Distributed Cloud Origin Pool

Answer/Recommended Actions

To configure mTLS between client and load balancer (front end):

1. Navigate to Load Balancers -> HTTP Load Balancers (select load balancer) -> TLS Configuration

2. Click Edit Configuration

3. The Show Advanced Fields toggle is located in the upper right corner. Click the toggle

4. Under mTLS, select Enable

5. Configure the mTLS settings as applicable

To configure mTLS between load balancer and origin server (back end):

1. Navigate to Load Balancers -> Origin Pools (select origin pool) -> TLS.

2. Click Edit Configuration

3. Under mTLS with Origin Servers, select the applicable options
