Description

To generate the Certificate with key size more than 2048, CSR needs to be generated with respective Key size. But as per the standard by default key size is 2048. It cannot be altered in GUI. Another is to generate a CSR to generate CSR manually with OpenSSL.

 

Environment

  • BIG-IP All Modules
  • Version 13.x - 17.x
  • CSR with key Size more than 2048.

Cause

By default, on GUI CSR key size is 2048 and there is no option to change.

 

 Recommended Actions

 

A. CSR with OpenSSL

 

1. Login into the F5 Box via CLI. 

 

2. Run the below command in bash mode

 

openssl req -new -newkey rsa:3072 -nodes -keyout <keyname.pem> -out <CSRname.pem> 

 

For example: 

 

openssl req -new -newkey rsa:3072 -nodes -keyout mykey.pem -out myreq.pem

B. Get the Certificate Signed

 

This example only showcases a current enterprise CA (Windows Server 2012 in this example) and does not cover the steps to set up a Windows Server CA from scratch.

 

1. Go to your enterprise CA page in the browser (usually https://<CA-ip>/certsrv) and click Request a certificate.

 

 

2. Click advanced certificate request.

 

 

3. Enter the CSR you obtained from OpenSSL. In the Certificate Template drop-down list, choose Web Server.

 

4. Click the Base 64 encoded radio button.

 

 

If the downloaded certificate is of type PKCS7 (.p7b), convert it to PEM (in the next example the certificate chain was downloaded as filename "All-certs.p7b") using the command below :

 

openssl pkcs7 -print_certs -in All-certs.p7b -out All-certs.pem

 

 6. Combine the certificate chain (in this example, it is named "All-certs.pem") certificates with the private key that was generated along with the CSR (the private key of the device certificate, which is mykey.pem in this example) 

 

Enter these commands in the OpenSSL application in order to create the All-certs.pem and final.pem files:

 

openssl>pkcs12 -export -in All-certs.pem -inkey mykey.pem 

    -out All-certs.p12 -clcerts -passin pass:sampleONLY123 

    -passout pass:sampleONLY123

 

openssl>pkcs12 -in All-certs.p12 -out final.pem 

    -passin pass:check123 -passout pass:sampleONLY123

 

 

Final.pem is the file to download to the F5 certificate or can import the private key and certificate separately. 

 

Note: If the upload of the certificate to the F5 fails, verify that there is the whole chain in the pem file. If you only see one certificate in the file, then you need to manually download all the intermediate and root CA certificate files and append them (by simple copy paste) to the file to create the chain.

 

 

Additional Information

The larger the key size the more resource will be utilized.
