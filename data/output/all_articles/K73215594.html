Description

Sync fails for Device Group datasync-global-dg with error:

datasync-global-dg (Sync Failed): A validation error occurred while syncing to a remote device
          - Sync error on <BIG-IP02>: Load failed from /Common/<BIG-IP01> 00000000:0: Caught configuration exception (0), Failed to sync files..
          - Recommended action: Review the error message and determine corrective action on the device

Environment

  • Configsync performed from <BIG-IP01> to the device group

Cause

The issue appears to be on the device where the Configsync is initiated for device group datasync-global-dg

from device <BIG-IP02>, the command "ps aux | grep rsync" displayed

root        <PID>      1   0.0   0.0   10.8M  296.0K ?        S    Jul06   00:00:00.24 rsync --daemon --address=127.0.0.1 --config=/etc/rsyncd-cmi.conf

from <BIG-IP02> from where the Configsync is initiated, there is no output.
 

Recommended Actions

Restart <BIG-IP01> followed by triggering Configsync from <BIG-IP01>.

None.
