K11341: The BIG-IP WebAccelerator logs a superfluous message when it receives a request for an unmapped host

Known Issue

Note: By default, the BIG-IP WebAccelerator does not process requests for unmapped hosts. Athough this is the recommended setting, you can also customize this behavior. For more information, refer to the Configuration Guide for the BIG-IP WebAccelerator System.

This is the result of a known issue. When the BIG-IP WebAccelerator receives a request for an unmapped host, the system replies with a 403 (Forbidden) error and logs messages to the /var/log/wa/pvac.log file that appear similar to the following examples:

  • BIG-IP WebAccelerator version 10.1.0

    debug WA Debug ( 6224): [      PvSysAppManager.cxx:1167  appManagerHandleRequest ] Error [0x0] [Error text not available.]
    debug WA Debug ( 6224): [      PvSysAppManager.cxx:1193  appManagerHandleRequest ] Error [0x3c] [Access Denied by intermediary.  Domain not  recognized.] for [bogus.example.com] [/]
  • BIG-IP WebAccelerator version 10.0.x

    debug WA Debug: [      PvSysAppManager.cxx:1173  appManagerHandleRequest ] Error [0x0] [Error text not available.]
    debug WA Debug: [      PvSysAppManager.cxx:1187  appManagerHandleRequest ] Error [0x3c] [Access Denied by intermediary.  Domain not  recognized.]

In both cases, the Error [0x0] [Error text not available.] message is superfluous because it does not provide any useful information.

Note: In BIG-IP WebAccelerator version 10.0.x, these messages are also logged when a client request does not contain a Host header. For more information, refer to K11336: Change in Behavior: Client requests that do not include a Host header bypass the BIG-IP WebAccelerator.

F5 Product Development tracked this issue as CR135925, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 issued for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
