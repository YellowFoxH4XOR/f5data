Known Issue

Important: This Solution applies only if you are upgrading to BIG-IP LTM version 9.1.2 or version 9.2.2.

This is the result of a known issue. If the BIG-IP console baud rate is set to any speed other than 19200 when upgrading from BIG-IP version 9.x to version 9.1.2, a loss of console access will result. The loss is due to garbled console output after upgrading.

F5 Product Development tracked this issue as CR59156, and it was resolved in BIG-IP version 9.2.2 of the version 9.2 branch, and version 9.1.2 of the 9.1 branch.

On systems that support multiple version slots, the SCCP is common for all version slots. Therefore, you can avoid this issue for subsequent upgrades by installing BIG-IP LTM version 9.1.2 or version 9.2.2 on any slot.

Important: This issue still applies to the current upgrade to version 9.1.2 or version 9.2.2. However, the issue will not apply to subsequent upgrades. Follow the procedures in the Workaround section below to prevent this issue from affecting the current upgrade to BIG-IP LTM version 9.1.2 or 9.2.2.

Important: Upgrading to BIG-IP LTM version 9.2 will not resolve this issue.

Workaround

To work around this issue, you can prevent the loss of console access, or recover the console access after upgrading.

Preventing loss of console access after upgrading

You can prevent loss of console access by using the LCD panel to set the console baud rate to 19200 prior to upgrading. This action ensures that you are able to use a baud rate of 19200 to connect to the console after an upgrade. After upgrading, you need to set the baud rate to the desired value.

Note: For more information about changing the baud rate using the LCD panel, refer to K9156 - Setting the baud rate of the serial console port.

Recovery of console access after upgrading

If you have already performed the upgrade on a BIG-IP system on which the console baud rate has been changed, and the BIG-IP console access is no longer functional, you can perform the following procedures to set the serial console baud rate to 19200 and return the BIG-IP console access to a functional state:

  • Set the serial console baud rate in the SCCP u-boot environment variable.
  • Set the serial console baud rate using the LCD panel.
  • Set the serial console baud rate in the inittab and grub.conf files.

Note: For information about setting the serial console baud rate, refer to K5919: New baud rate scheme requires complex procedures to set serial console baud rate.
