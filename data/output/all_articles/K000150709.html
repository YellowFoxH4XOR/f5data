K000150709: Unable to create boot location, no "create" button

Type
Support Solution
Published
2025-04-08
Updated
2025-04-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150709

Description

When attempting to perform upgrade, you are unable to select/create a new boot location.


Environment

BIG-IP


Cause

You will be prompted to create a new boot location when installing the upgrade image.


Recommended Actions

-In the configuration utility, go to System > Software Management : Image List

-Click "Install" under the Available Images box, which will prompt you to name the boot location. (You must have imported a software image (.iso) to the system to install it which you can do by clicking "Import" on the same page)
