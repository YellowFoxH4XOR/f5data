Description

When configuring JSON schema validation in JSON content profile, there is no option to upload the JSON schema file.
In the JSON content profile on the Main tab in Security > Application Security > Content Profiles > JSON Profiles, the JSON Schema Files section is missing.

Environment

  • GUI
  • Big-IP ASM
  • JSON content profile

Cause

The JSON Schema Validation functionality is only available with the Advanced Web Application Firewall (AWAF) license.

Recommended Actions

Consider upgrading to the Advanced Web Application Firewall (AWAF) license to implement JSON content validation.

Additional Information

If the Advanced Web Application Firewall (AWAF) expires, the configuration will be preserved, but JSON schema validation will not work any longer.
