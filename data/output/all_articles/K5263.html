Known Issue

This is the result of a known issue. On BIG-IP and 3-DNS combination systems, 3-DNS will automatically add a router statement for the default gateway. 3-DNS routinely pings all routers to check their status for link load balancing.

If BIG-IP is not performing link load balancing, the router ping check is unnecessary.

To prevent BIG-IP from pinging the default gateway, disable automatic configuration and then remove the router statement from the wideip.conf file. When the router statement is removed, BIG-IP will no longer ping the router.

F5 Networks Product Development tracked this issue as CR29281 and CR42027.
