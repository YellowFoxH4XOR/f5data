K11152: Configuring a pre-logon sequence or a Network Access policy check to check for Windows 7 64-bit clients and hotfixes

Topic

For some client checks, FirePass uses Win7 to represent both the 32-bit and 64-bit versions of Windows 7. For other client checks, FirePass uses Win7 to represent 32-bit versions of Windows 7 and Win764 to represent 64-bit versions of Windows 7. If your organization supports 64-bit versions of Windows 7, review the following information to ensure that pre-logon sequence checks and Network Access policy checks are configured properly for Windows 7 clients.

Check OS inspector

The Check OS pre-logon inspector sets the session variable session.os.platform to Win7 for Windows 7 clients, regardless of whether the client is running a 32-bit or 64-bit version of Windows 7. The Check OS inspector does not use Win764 to represent 64-bit versions of Windows 7.

Note: If you are not currently using the Check OS inspector, refer to K10663: Detecting Microsoft Windows 7 clients in a pre-logon sequence for instructions about configuring the Check OS inspector for use with Windows 7 clients . If you configured the Check OS inspector prior to installing cumulative hotfix HF-603-4.1 or upgrading to version 6.1.0, refer to K10664: Windows 7 clients are not detected by the Check OS pre-logon inspector for instructions on updating the Check OS inspector for use with Windows 7.

Extended Windows and IE info inspector

The Extended Windows and IE info pre-logon inspector sets the session variable session.win_info.os_version to Win7 for 32-bit versions of Windows 7 and to Win764 for 64-bit versions of Windows 7. You can configure separate rules for 32-bit or 64-bit clients, or configure a single rule for both. For example:

(session.win_info.os_version == "Win7") OR (session.win_info.os_version == "Win764")

Note: For more information about configuring the Extended Windows and IE info pre-logon inspector, refer to the FirePass Controller Administrator Guide.

Network Access policy checks

The Operating system service packs field for Network Access policy checks uses Win7 for 32-bit versions of Windows 7 and Win764 for 32-bit versions of Windows 7. If you want to support 32-bit and 64-bit versions Windows 7, ensure you specify both in the policy check. For example:

(Win7 OR Win764 OR (WINVI and SP2) OR (WINXP AND SP3))

Note: Network Access policy checks are configured on the Network Access : Resources page under the Policy Checks tab. For more information about configuring policy checks, refer to the FirePass Controller Administrator Guide.
