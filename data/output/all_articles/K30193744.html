K30193744: Configuring external login page to send additional data

Type
Support Solution
Published
2021-08-04
Updated
2023-02-21
Applies to

  • VIPRION Platforms
  • BIG-IP

Source
https://my.f5.com/manage/s/article/K30193744

Description
In some deployments there may be a need to push additional information to the External Logon Page

Environment

  • BIG-IP APM
  • Access Policy with External Logon Page object

Cause
N/A

Recommended Actions

Add a query string to the URI entered in the External Logon Page to allow for passing variables to the target.  For example:
https://example.com/login?sid=%{session.logon.last.username}

This will allow for the target server to pull the appropriate 'sid' variable when it receives the request.

Note: Session variables from APM can be sensitive and should be vetted prior to being sent in a URI
