Known Issue

Malformed Flash ActionScript 2 (AS2) content that the BIG-IP APM system writes may cause portal access to fail.

This issue occurs when all of the following conditions are met:

  • A portal access is configured with a rewrite profile.
  • The portal resource response contains malformed Flash AS2 content.

When the BIG-IP APM rewrite daemon processes malformed Flash AS2 content, the malformed content can trigger a scenario where the rewrite daemon continually attempts to process the malformed content. The rewrite process CPU usage increases over time and eventually consumes all of the available CPU resources.

Impact

The BIG-IP APM system eventually stops processing all requests.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Running the command line top utility on the affected BIG-IP APM shows the rewrite daemon at very high CPU usage.
  • The rewrite process CPU usage continues to increase over time.
  • When CPU usage by the rewrite daemon reaches 99-100%, the BIG-IP APM system no longer processes requests.
