Description

F5OS management plane uses standard Linux ARP timeout procedure and configuration files. 

By default, ARP cache entries are maintained for 60 seconds before they need to be refreshed. However, by default, unless there are 128 entries in the ARP cache no garbage collection is run removing stale entries from the cache.

Default settings are as follows:

gc_interval - How frequently garbage collector should attempt to run, default 30 seconds.
gc_stale_time - Determines how long a neighbor entry is considered valid before needed to be resolved again or candidate for removal from ARP cache table, default 60 seconds.
gc_thresh1 - Minimum number of entries in ARP cache before garbage collector is allowed to run, default 128.
gc_thresh2 - Soft maximum number of entries in ARP cache. Garbage collector will this number to be exceeded for 5 seconds before collection is preformed, default 512.
gc_thresh3 - Hard limit of entries in ARP cache before garbage collection is continually run, default 1024.

Each of these is configurable by altering value of interface configuration files in /proc file system.
