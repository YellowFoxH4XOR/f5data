K000160237: Expand a BIG-IQ disk partition for a single boot location

Type
Support Solution
Published
2026-03-04
Updated
2026-03-05
Source
https://my.f5.com/manage/s/article/K000160237

Description

Expand a BIG-IQ disk partition for a single boot location without extending it across other boot locations.

Environment

  • BIG-IQ (Virtual Edition)

Cause

The resizevol tool described in K14532110 resizes the disk partition location that exists in all the software volumes regardless of whether they are active or inactive or whether the software volume is used or unused.

Answer/Recommended Actions

Expand a disk partition for a single boot location without extending it across other volumes:

  1. Display the various disk partitions and their current allocated sizes across all boot locations:
    # lvs
    LV            VG        Attr       LSize   Pool Origin Data%  Meta%  Move Log Cpy%Sync Convert
      dat.log.1     vg-db-vda -wi-ao----   6.84g
      dat.maint.1   vg-db-vda -wi-a----- 300.00m
      dat.share.1   vg-db-vda -wi-ao----  30.27g
      dat.swapvol.1 vg-db-vda -wi-ao----   1.00g
      set.1._config vg-db-vda -wi-ao---- 492.00m
      set.1._usr    vg-db-vda -wi-ao----  10.00g
      set.1._var    vg-db-vda -wi-ao----  25.00g 
      set.1.root    vg-db-vda -wi-ao---- 440.00m
      set.2._config vg-db-vda -wi-a-----   3.17g
      set.2._usr    vg-db-vda -wi-a-----  10.00g
      set.2._var    vg-db-vda -wi-a-----  75.00g 
      set.2.root    vg-db-vda -wi-a----- 440.00m

    Example:
    set.1._var refers to the /var disk partition on boot location HD1.1
    set.2._var refers to the /var disk partition on boot location HD1.2
    To display all available boot locations, run:
    # tmsh list sys software volume

  2. Expand a disk partition for a single boot location:
    Important: Increasing the disk partition size on the BIG-IQ VE system is irreversible because F5 does not support disk shrinking.

    For example, if the disk partition you want to extend is located on an inactive boot location of HD1.2, run the lvextend utility to increase the /var disk partition size by adding an additional 100 GB to it's current allocated size:
    # lvextend --size +100G /dev/vg-db-vda/set.2._var
