Description

SSO artifacts resolution fails after a BIG-IP reboot for any reason.  Users are no longer able to authenticate. You may observe the following message in the APM log.

<DATE> <HOSTNAME> err apmd[9024]: 01490000:3: modules/Authentication/Saml/SamlSPAgent.cpp func: "sendSAMLArtifactResolveRq()" line: 5575 Msg: Failed to connect to artifact resolution service. Error (56): Failure when receiving data from the peer

Environment

  • BIG-IP APM
  • Single Sign On
  • Both IdP and OAuth server are hosted on the same hostname, IP, and port combination.
  • Remove the serverssl-profile name from the SAML IdP connector.

Cause

BugID 1091509   APM as SP - ARS fails to resolve artifacts on the same ip after reboot

Recommended Actions

There are two possible workaround either one can be used
  • Change 'artifact-resolution-service-addr' to a dummy IP address, one that is not in use.
  • Disable 'serverssl-profile-name' inside the IdP connector config.
