Topic

This article applies to BIG-IP 15.x - 17.x. For information about other versions, refer to the following article:

  • K7406: Overview of the tcp-lan-optimized profile (10.x - 12.x)

The f5-tcp-lan profile is a preconfigured profile type that you can associate with a virtual server. In cases where the BIG-IP virtual server is load balancing LAN-based or interactive traffic, you can enhance the performance of your local-area TCP traffic by using the f5-tcp-lan profile.

Description

If the traffic profile is strictly LAN-based, and a standard virtual server with a TCP profile is required, you can configure your virtual server to use the f5-tcp-lan profile to enhance LAN-based traffic. By configuring your virtual server to use the f5-tcp-lan profile, you can ensure that LAN-based traffic is delivered without delay.

Settings and definitions in the f5-tcp-lan-optimized profile

The following table describes settings of the f5-tcp-lan profile that may differ from the parent default TCP profile in order to optimize LAN traffic.

Note: The default values for some settings in the default TCP profile may change between versions. These changes are inherited by the f5-tcp-lan profile. For information about the default TCP profile settings, refer to K50411377: Overview of the TCP profile (16.x and later).

SettingValueDescription
Proxy Buffer Low32768This setting specifies the proxy buffer level at which the receive window was opened. For more information, refer to K3422: Overview of content spooling.
Proxy Buffer High65535This setting specifies the proxy buffer level at which the receive window is no longer advanced. For more information, refer to K3422: Overview of content spooling.
Nagle's AlgorithmDisabled (BIG-IP 13.0.0)
Auto
(BIG-IP 13.1.0 or later)		Specifies whether the system applies Nagle's algorithm to reduce the number of short segments on the network. When selected (enabled) and the system receives packets that are less than the maximum segment size (MSS), the packets are coalesced until the peer sends the ACK packet for the previous segment. This helps to reduce congestion by creating fewer packets on the network. If you select Auto, the system determines whether to use Nagle's algorithm based on network conditions. By default, this setting is disabled. Note that enabling this setting for interactive protocols, such as telnet, rlogin, or SSH, may cause degradation on high-latency networks.
Initial Congestion Window Size16 MSS unitsSpecifies the initial congestion window size for connections to this destination. Actual window size is this value multiplied by the MSS (Maximum Segment Size) for the same connection. Valid values range from 0 to 16.
Initial Receive Window Size16 MSS unitsSpecifies the initial receive window size for connections to this destination. Actual window size is this value multiplied by the MSS (Maximum Segment Size) for the same connection. The default is 3. Valid values range from 0 to 16.
Minimum RTO200 millisecondsSpecifies the minimum length of time that the system waits for acknowledgements of data sent, before resending the data. The value must be equal to or less than 5000. If the Packet Loss Ignore Rate and Packet Loss Ignore Burst settings contain values other than 0, this value drops to 203 ms. If MPTCP is enabled, the value drops to 200 ms.

Configuring the virtual server to use the f5-tcp-lan profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers.
  3. Select the virtual server that processes the LAN-based traffic.
  4. For Configuration, select Advanced if necessary.
  5. For Protocol Profile (Client), select f5-tcp-lan.
  6. Ensure Protocol Profile (Server) has (Use Client Profile) selected.
  7. Select Update.

Recommendations

F5 recommends that, instead of modifying a default profile, you create a custom profile using the default profile as the parent profile. You can then modify some or all of the values defined in the custom profile, while leaving the parent profile settings at their default values. For information, refer to K14488: Working with profiles.
