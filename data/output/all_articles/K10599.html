Known Issue

This is the result of a known issue. Statistics that initially appear to be working and updating correctly may quickly return to a value of 0 (zero) and stop updating. This issue is known to occur when the following conditions are met:

  • The BIG-IP system is an 8900 platform running versions 9.4.7, 9.4.8, 10.0.0, or 10.0.1
  • CMP is enabled on the system and running more than four TMM instances
  • Hardware compression is enabled for at least one virtual server 

    Note: Enabling HTTP compression for any virtual server on platforms containing hardware compression cards may enable hardware compression.

This issue affects most system-wide statistics, for example interfaces, nodes, pools, and virtual servers' statistics may all return a value of zero. If the services are restarted, statistics will resume working for a short period of time; however, the issue will soon reoccur.

Important: Currently, the BIG-IP 8900 platform is the only platform affected by this issue.

Note: You can view statistics in the Configuration utility under Overview: Statistics.

Note: For more information, refer to K3393: Overview of compression settings for the HTTP profile.

F5 Product Development tracked this issue as CR129239 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue was fixed in Hotfix-BIGIP-9.4.8-385.0-HF2 issued for BIG-IP version 9.4.8, and BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
