Known Issue

This is a result of a known issue. If you change the BIG-IP sshd port setting from the default port 22, the BIG-IP sshd daemon will listen on the new port instead of the default port 22. As a result, the SCCP/AOM will continue to attempt to connect to port 22 on the BIG-IP host subsystem, and communication will fail.

Note: It is possible to modify the sshd port by manually editing the sshd stanza in the /config/bigip_sys.conf file, or by using the sshd include option within the tmsh utility, the bigpipe utility, or the bigpipe shell. However, changing the sshd port should be avoided.

For example, adding a Port 1234 statement in the sshd stanza of the /config/bigip_sys.conf file will result in the BIG-IP sshd daemon listening on only port 1234:

sshd {
include "Port 1234"
}

F5 Product Development is tracking this issue as ID 247364 (formerly CR117359).

Workaround

You can work around this issue by removing the custom port setting. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Type the following command:

    bigpipe sshd include none
  3. Save the configuration by typing the following command:

    bigpipe save all
