Topic

To reconfigure the 3-DNS Controller so that iQuery does not use the ephemeral ports for replies, change the global multiplex_iq setting, to yes. You can do this through the Configuration utility or the command line.

Important: Port 4353 is registered with IANA as the standard port for the F5 Networks iQuery protocol. If you have changed the iQuery port to 4353 and then set the global multiplex_iq setting to yes, it will cause the requests to go back and forth on port 4353.

Configuration utility

To make this change through the configuration utility, perform the following steps:

  1. From the navigation pane, click Systems.
  2. Place a check mark in the box next to Multiplex.
  3. Click the Update button.

Command line

To make this change through the command line, perform the following steps:

  1. Using a text editor, such as vi or pico, edit the wideip.conf file.

    Note: As of 3-DNS version 4.0.1, the wideip.conf file is located in the /config/3dns/etc directory. For versions prior to 4.0.1, the wideip.conf file is located in /var/3dns/etc directory.

    By default, Multiplex is enabled. If Mutliplex is disabled, you will see a line similar to the following the the globals section of the wideip.conf file.

    multiplex_iq               no                // Default=yes
  2. To enable Multiplex, remove the multiplex_iq line and save the file.
  3. After the file is saved, type the following command:

    3ndc restart

    This command will prompt the 3-DNS Controller to read the wideip.conf file and update the setting.
