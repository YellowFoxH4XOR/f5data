Issue

Description

 DUO 2Factor Authentication Remember me for 30 days option fails on Edge Client for macOS and F5 Access for iOS.

Environment

  • Duo Two-Factor Authentication (2FA) Remember me for 30 days option
  • BIG-IP Edge Client for macOS or F5 Access for iOS
Cause

macOS and iOS prevent sharing of third-party cookies. Duo's option to remember devices uses a cookie and the operating systems prevent access to the cookie.

Recommended Actions

If you experience this issue using BIG-IP Edge Client for macOS, you can upgrade to APM Clients 7.1.8.1 which contains the fix. There is currently no workaround for F5 Access for iOS.
