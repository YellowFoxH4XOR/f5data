Known Issue

This is the result of a known issue. If you open a Portal Access Web Applications Favorite from the Intranet Favorites page (as opposed to the webtop), and then resize the browser window or perform a page refresh, you will be taken back to the Intranet Favorites page, instead of viewing the refreshed page. This behavior occurs when a Web Applications Favorite is configured to display without opening a new browser window; the Open in new window check box is not selected.

F5 Product Development tracked this issue as CR60978 and it was fixed in FirePass versions 5.5.1 and 6.0.1. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in hotfix HF-61416-1 issued for FirePass version 5.5. You may download this hotfix or a later version of this hotfix from the F5 Downloads site./p>

Workaround

To work around this issue, you can open the Favorite in a new browser window. To do so, perform one of the following two procedures:

  • Opening an administrator created favorite in a new browser
  • Opening a user created favorite in a new browser

Opening an administrator created favorite in a new browser

To open an administrator created favorite in a new browser, perform the following procedure:

  1. Log in to FirePass Web Admin UI with the Administrator account, or an account with privileges to edit the Favorite.
  2. In the main menu, click Portal Access.

    The Portal Access sub-menus appear.
  3. Under Web Applications, click Resources.
  4. From the Resource Group drop-down menu, select the resource group that contains the Favorite you want to open.
  5. Click the Edit (I-beam) icon next to the Favorite to display the Favorite's settings.
  6. Select the check box next to Open in new window.
  7. Click the Update button.

Opening a user created favorite in a new browser

To open a user created favorite in a new browser, perform the following procedure:

  1. Log on to FirePass with the account of the user who created the Favorite.
  2. Click the Web Applications heading.
  3. Click the edit link.
  4. Click the Edit (I-beam) icon next to the Favorite to display the Favorite's settings.
  5. Select the check box next to Open in new window.
  6. Click the Update button.
