Description
After adding new BIG-IP DNS system to an existing DNS (previously GTM) device group, changes are not synchronized to the new system

There are logs in /var/log/gtm similar to these:
notice gtmd[12345]: 011a001c:5: SYNC bigip_gtm.conf from <DNS self IP> skipped. Reason: cannot find my box
notice gtmd[12345]: 011a001c:5: SYNC server.crt from <DNS self IP> skipped. Reason: cannot find my box

Environment

  • DNS sync group / iQuery mesh
  • Recently added a new device to the device group

Cause
No BIG-IP is configured to use a Self IP on this system in the DNS  ››  GSLB : Servers : Server List. iQuery requires communication on Self IP addresses.

K15671: The BIG-IP DNS system must use a local self IP address to define a server to represent the BIG-IP GTM system

Recommended Actions
Please refer to the Manual Chapter : Adding a new BIG-IP DNS to a BIG-IP DNS Synchronization Group for steps to add a datacenter and BIG-IP server object using a non-floating self IP to represent the new DNS system. This configuration should be created in the existing sync group prior to adding a new DNS system.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.
