Known Issue

When you modify a rate class, the statistics do not reset.

This issue occurs when the following condition is met:

  • You modify an existing rate class.

Impact

The Statistics table for the rate class displays incorrect values.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Statistics table displays the previous values for the rate class.

Workaround

To work around this issue, you can reset the statistics for the modified rate class using the TMOS Shell (tmsh) utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Reset the statistics for the modified rate class using the following command syntax:

    tmsh reset-stats net rate-shaping class <classname>

    For example:

    tmsh reset-stats net rate-shaping class Rate-Test
