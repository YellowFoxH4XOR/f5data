Topic

You can configure a pre-logon sequence in FirePass that checks for specific hotfixes and service packs on Windows client systems. This type of pre-logon check can be used to ensure that client systems meet a minimum hotfix level in order to log on, or to prevent client systems with unsupported hotfixes from logging on.

Configuring a pre-logon sequence to allow access to clients running Windows XP with Service Pack 3

To configure a pre-logon sequence that allows access to clients running Windows XP with Service Pack 3 (SP3), and denies access to all other clients, perform the following procedure:

Note: Additional configuration examples are provided in the Examples section.

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. In the Create new sequence field, enter a name for the pre-logon sequence.
  4. In the Based on menu, select template: Empty.
  5. Click the Create button.

    The new pre-logon sequence appears in the Select Sequence to Use section.
  6. Click edit next to the pre-logon sequence you just created.

    The Pre-Logon Sequence Editor opens.
  7. Mouse over the Go rule.

    A plus sign (+) appears to the right of the Go rule.
  8. Click the plus sign (+).

    The Change Sequence panel opens.
  9. In the Change sequence menu, select Insert action.
  10. In the Using menu, select One from the list.
  11. Click the Check OS option button.
  12. Click the Apply changes button at the bottom of the page.

    The Check OS action appears in your pre-logon sequence.
  13. Mouse over the Windows NT based rule of the Check OS action.

    A plus sign (+) appears to the right of the Windows NT based rule.
  14. Click the plus sign (+).

    The Change Sequence panel opens.
  15. In the Change sequence menu, select Insert action.
  16. In the Using menu, select One from the list.
  17. Click the Extended Windows and IE info option button.
  18. Click the Apply changes button at the bottom of the page.

    The Extended Windows and IE info action appears in your pre-logon sequence.
  19. Mouse over the fallback rule to the right of the Extended Windows and IE info box in the updated sequence.

    A plus sign (+) appears to the left of the fallback rule.
  20. Click the plus sign (+) to the left of the fallback rule.

    The Insert Rule Panel opens.
  21. Enter a name for the rule in the Name field.

    For example:

    Check for XP SP3
  22. Enter an expression to match for a specific hotfix.

    For example, to match for Windows XP with SP3, you would enter the following expression:

    (session.win_info.os_version == "WinXP" ) AND EXIST (session.win_info.hotfixes.hf_sp3)

    Note: Additional hotfix rule examples are provided in the Examples section.
     
  23. Click the Insert Rule button.

    The rule is added to the pre-logon sequence. The pre-logon sequence now displays the new rule leading to the Logon Denied Page action, and a fallback rule leading to the Logon Allowed Page action. If this is correct, proceed to Step 30. If you want the new rule to lead to the Logon Allowed Page action, and the fallback rule to lead to the Logon Denied Page action, proceed to the next step.
     
  24. To the right of the rule you just created, click the Logon Denied Page action.
  25. In the Type menu, select Logon Allowed Page.
  26. Click the Update button.
  27. To the right of the fallback rule, click the Logon Allowed Page action.
  28. In the Type menu, select Logon Denied Page.

    Note: Optionally, you may want to provide text on the Logon Denied page, which explains to users why access has been denied. To do so, click the Logon Denied Page action, enter the text that you want users to see, then click the Update button.
  29. Click the Update button.
  30. Click the Back to console link at the upper-right corner of the page.
  31. Click the option button next to the pre-logon sequence you just edited, under the Select Sequence to Use section.
  32. Click the Apply button to activate the pre-logon sequence.

Client systems must now run Windows XP with SP3 in order to access the FirePass logon page.

Note: For instructions about logging hotfix information to the logon log, refer to K8211: Configuring a pre-logon sequence to write the Windows and Internet Explorer client hotfix information to the logon log.

Examples

In Step 22 of the procedure, you configured a rule to check for Windows XP with SP3. For more details, refer to the following additional examples of hotfix match rules:

  • A rule that matches if the client system is Windows Vista with SP2 installed:

    (session.win_info.os_version == "WinVI") AND EXIST(session.win_info.hotfixes.hf_sp2)
  • A rule that matches if the client system is Windows XP with either SP2 or SP3 installed:

    (session.win_info.os_version == "WinXP") AND ( EXIST(session.win_info.hotfixes.hf_sp2) OR EXIST(session.win_info.hotfixes.hf_sp3) )
  • A rule that matches if Microsoft hotfix KB123456 is installed:

    EXIST(session.win_info.hotfixes.hf_kb123456)

    Note: Ensure that the letters KB in the session variable name are in lower case, as shown above.

    Note: Since no operating system is specified in the rule above, the rule matches any version of Windows with KB123456 installed.
  •  A rule that matches if Microsoft hotfixes KB123456 and KB456789 are both installed:

    EXIST(session.win_info.hotfixes.hf_kb123456) AND EXIST(session.win_info.hotfixes.hf_kb456789)
