K000139723: BIG-IP Tenants do not reflect VELOS partition Interface state change - (HA-Group)

Type
Support Solution
Published
2024-05-21
Updated
2024-06-04
Source
https://my.f5.com/manage/s/article/K000139723

Description

If an interface in a LAG enters a DOWN or DISABLED state on the VELOS partition, the HA-Group score for the Tenant BIG-IP remains unchanged, consequently preventing the HA-group anticipated failover.

Environment

  • VELOS - (F5OS-C v1.6.2)
  • Partition LAG
  • BIG-IP Tenants - (HA)
  • HA-Group

Cause

ID 1293305: LAG interface status is not updated on the BIG-IP tenant

Recommended Actions

Refer to ID 1293305 for more information about fixed versions and workarounds.

Additional Information

The HA-Group feature allows BIGIP Tenants to fail-over automatically based NOT on the health of the BIGIP Tenant itself, but on the health of external resources such as the availability of the following:

  • Pool members
  • Trunk links
  • VELOS cluster members (group of blades or nodes)
  • Combination of all three

If resource levels fall below a user-defined threshold, the system triggers a failover.
