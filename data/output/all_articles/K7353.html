K7353: Increasing the data segment size to load symbolic links for large Certificate Revocation Lists (CRLs)

Topic

The Certificate revocation section in Chapter 7 of the BIG-IP Reference Guide specifies how to create symbolic links (symlinks) to point to Certificate Revocation Lists (CRLs) for use with SSL Proxies.

If the CRLs are large or there are a large number of CRLs, the OpenSSL process can reach or exceed the default allocated data segment size of 32768 K. When a CRL exceeds the default allocated data segment size, the following error message may be reported on the command line:

1:error:07064041:memory buffer routines:BUF_MEM_grow:malloc 
failure:buffer.c:115:

1:error:0906D041:PEM routines:PEM_read_bio:malloc failure:pem_lib.c:674:

You can increase the data segment size allowed for processes by performing the following procedure:

  1. Log in to the command line as a root user.
  2. To increase the data segment size allowed from 32 MB to 128 MB, type the following command:

    ulimit -d 1024000

    Note: This change takes effect immediately.

  3. To save this change permanently for the root user, edit the /etc/login.conf file using a text editor.
  4. Locate the following entry in the login.conf file:
    daemon: :path=/bin /usr/bin /sbin /usr/sbin /usr/contrib/bin 
/usr/contrib/sbin/ usr/local/bin /usr/local/sbin /usr/libexec: 
:widepasswords: :datasize-cur=32M: :openfiles-cur=128: :auth=passwd:
  5. Locate the :datasize-cur=32M: section and replace with the following information:

    :datasize-cur=128M:

  6. Save the changes.

Once you have performed the procedure, you can follow the steps outlined in the Certificate revocation section in Chapter 7 of the BIG-IP Reference Guide without encountering an error.
