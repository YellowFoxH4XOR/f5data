K12512: The default BIG-IP WebAccelerator transaction limit for the 8900 platform is too low

Known Issue

This is the result of a known issue. The default value of the pluginTransactionLimit parameter in the /config/wa/pvsystem.conf file is not provisioned correctly on the 8900 platform. As a result, this behavior may lead to degraded performance.

F5 Product Development is tracking this issue as ID 347342; BIG-IP iHealth lists Heuristic H383268 on the Diagnostics > Identified > Medium screen.

Workaround

You can work around this issue by modifying the value of the pluginTransactionLimit parameter in the /config/wa/pvsystem.conf file. To do so, perform the following procedure:

Note: If the BIG-IP WebAccelerator system is not currently experiencing performance issues, F5 recommends performing the following procedure during a maintenance window.

  1. Log in to the BIG-IP command line.
  2. Create a backup of the /config/wa/pvsystem.conf file.

    For example:

    cp /config/wa/pvsystem.conf /config/wa/pvsystem.conf.SOL12512
  3. Open the pvsystem.conf file using a text editor.
  4. Locate the following line:

    <pluginTransactionLimit>125</pluginTransactionLimit>
  5. Change the value of pluginTransactionLimit from 125 to 300.
  6. Save and exit the file.
  7. Restart the pvac process by typing the following command:

    Important: BIG-IP WebAccelerator processing will be interrupted until the pvac process restarts.

    bigstart restart pvac
