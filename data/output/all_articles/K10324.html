Known Issue

This is the result of a known issue. When you enable the Synchronize FirePass user database with Active Directory option in the Active Directory group mapping method, FirePass may incorrectly deactivate or delete user accounts in the local user database that do not authenticate using Active Directory. For example, when FirePass synchronizes with the Active Directory server, it may delete local user accounts which authenticate using LDAP or RADIUS.

Note: Whether a user account is deactivated or deleted depends on the action you selected when configuring the Synchronize FirePass user database with Active Directory option.

In order for this issue to occur, the user account must belong to a master group that meets all of the following three conditions:

  • The master group is configured for local users.
  • The master group uses an external authentication method. For example, LDAP or RADIUS.
  • The master group has dynamic group mapping enabled.

F5 Networks Product Development tracked this issue as CR65995 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-5 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
