K000148017: Service policy or network policy not able to edit - shared namespace

Type
Support Solution
Published
2024-11-08
Updated
2025-02-25
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000148017

Description

  • I have a full access role, but some network policy or service policy is not editable
  • The action button is not showing up, for example

Environment

  • Access to F5® Distributed Cloud Console

Cause

  • Since those objects belong to the "Shared" namespace, it is not editable in the application namespace
  • Note: An object in the "Shared" namespace make it reusable in all other application namespaces

Resolution

  • Find this object in the "Shared" namespace, edit it there
    • Search "Shared configuration"
    • Go to Service Policy > Service Policies > Under "..." click Manage Configuration
