Description

You wanted to know if http port is open by default ?

you ran netstat -l command and noticed output similar to below

#netstat -l | grep -i 'http'

tcp    0   0 127.4.2.1:http     0.0.0.0:*        LISTEN
tcp    0   0 localhost.localdom:http 0.0.0.0:*        LISTEN

or

#netstat -nl | grep -i ':80'

tcp    0   0 127.4.2.1:80      0.0.0.0:*        LISTEN
tcp    0   0 127.0.0.1:80      0.0.0.0:*        LISTEN

Environment

BIG-IP 

Cause

Above listeners are loopback addresses, which are not reachable by a host outside the BIG-IP and only used for internal services.

In this instance :

  1. 127.4.2.1 is the lcd0 address (for LCD)
  2. The 127.2.0.0/24 range is AOM related (where AOM is 127.2.0.1 and .2 is the Host).

Recommended Actions

No action is needed and can be safely ignored.

Additional Information

See below rfc for additional details on loopback addresses.

https://datatracker.ietf.org/doc/html/rfc5735#section-3
