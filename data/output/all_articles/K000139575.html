K000139575: Error message - 017a0001:3: FIX: FIX license is not installed

Description

The BIG-IP system supports Financial Information eXchange (FIX) protocol connections for electronic trading between financial institutions. 
The FIX_HEADER and FIX_MESSAGE iRule events in BIG-IP allow you to manage and inspect this traffic efficiently. FIX_HEADER handles the management of headers, while FIX_MESSAGE is responsible for full message inspection and modification.
 
After configuring the virtual server with irule including the mentioned events, you may receive the following log message in /var/log/ltm:

Apr 25 09:50:35 hostname.com err tmm[22388]: 017a0001:3: FIX: FIX license is not installed

Environment

  • BIG-IP
  • BIG-IP Virtual Edition
  • iRule attached to a Virtual Server
  • FIX connections

Cause

This log message may indicate that the FIX functionality is unavailable due to the lack of a proper license or the relevant module not being provisioned.

Recommended Actions

To ensure that the FIX functionality, including FIX_HEADER and FIX_MESSAGE, can be triggered and operate correctly, the Advanced LTM® Protocols must be licensed. Once the Advanced Protocol module is licensed, the FIX messages and headers should work, and the error message should no longer appear.
