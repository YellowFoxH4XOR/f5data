Known Issue

This is the result of a known issue. If you enable the WebAccelerator module on a 6400 or 6800 platform, BIG-IP does not provision enough memory for the module. As a result, WebAccelerator performance may become degraded.

F5 Product Development is tracking this issue as ID 328326 (formerly CR141026).

This issue has been fixed, through the use of custom provisioning tables, in Hotfix-BIGIP-10.2.0-1755.1-HF1, issued for BIG-IP version 10.2.0, and in Hotfix-BIGIP-10.1.0-3402.0-HF2, issued for BIG-IP version 10.1.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

Important: In order to utilize the custom provisioning tables introduced in Hotfix-BIGIP-10.1.0-3402.0-HF2 and Hotfix-BIGIP-10.2.0-1755.1-HF1, the provisioning levels specified in SOL11982: Recommended provisioning for BIG-IP WebAccelerator version 10.x, must be applied. Failure to utilize the recommended provisioning levels will not allow the custom tables to be referenced and the BIG-IP WebAccelerator may continue to suffer from insufficient memory resources.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
