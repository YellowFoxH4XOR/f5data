Description

You have configured the setup with BIG-IQ and BIG-IP devices, but you are not able to see any of the data from BIG-IP devices in the dashboard section of the BIG-IQ.

Environment

  • BIG-IQ
  • BIG-IP

Cause

BIG-IP devices don't have AVR module provisioned

Recommended Actions

Provision AVR module on BIG-IP as it's needed to display all statistics in the dashboard section of the BIG-IQ.

None
