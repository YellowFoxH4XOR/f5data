Description

The BIG-IP Device Certificate is used for the BIG-IP management interface (httpd), EM, and iQuery connectivity between BIG-IP units.

This document attempts to list the restrictions for the certificate/key pair characteristics that can be used as the BIG-IP Device.

The following error logs may be encountered when a user attempts to import an unsupported certificate/key.

 

 

Error Logs

 

"EC keys are incompatible for Webserver/EM/iQuery."

This error appears when the user tries to apply an Elliptical Curve (EC) key pair as a BIG-IP Device Certificate/Key (BIG-IP Management Interface Certificate/Key).

The BIG-IP Device Certificate/Key does not support EC. The BIG-IP only supports RSA and DSA.

 

Note: This restriction only applies to BIG-IP Device Certificates/Keys. Traffic management keys support EC.

 

Note: If EC Certificates/Keys are required for the BIG-IP management interface, you can create a virtual server as an SSL proxy to the BIG-IP management interface and configure EC Certificates/Keys on the virtual server's clientssl profile.  See: Creating an SSL Proxy to the BIG-IP Management IP

 

 

"EC key or certificate contains unsupported curve name."

The BIG-IP supports the following EC curve names:

PRIME256V1

SECP384R1

SECP521R1

 

 

"Invalid certificate lifetime value. Maximum value cannot exceed 25 years"

The BIG-IP supports a certificate expiry that is between 1 day and 25 years.

 

 

"Unsupported key size"

The BIG-IP supports key sizes between 512 and 8192 bits.
