Topic

Note: This article only affects BIG-IP LTM, ASM, GTM, and Link Controller 9.2.x.

In accordance with the F5 Software End of Life Policy, F5 announces the End of Software Development (EoSD) for the BIG-IP 9.2.x feature release branch of software effective July 31, 2007. Repair and maintenance of confirmed software defects for the BIG-IP LTM, ASM, GTM, and Link Controller 9.2.x software will cease as of July 31, 2007. As of this date, F5 will no longer provide security updates, software fixes (hotfixes), or consulting services for version 9.2.x.

All configuration support for version 9.2.x is considered best effort support, which is limited to technical phone support and hardware support.

BIG-IP LTM, ASM, GTM, and Link Controller 9.2.x software is superseded by version 9.3.

Transition Plan

Customers currently using the 9.2.x version of software are strongly encouraged to upgrade to the currently supported 9.3.x maintenance version of software. To view the currently supported software version list, refer to K5903: BIG-IP software support policy.

For more information about this announcement, contact your local F5 Channel Sales Manager or Inside Sales Representative.
