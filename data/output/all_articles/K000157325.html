K000157325: Hyper-v bigip is offline after upgrade from 17.5.0 to 17.5.1.3 and TMM core

Support Solution
Published

Updated
2025-11-07
Applies to

  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000157325

Description

After upgrading BIG-IP Virtual Edition on Hyper-V from version 17.5.0 to 17.5.1.3, the system repeatedly went offline due to TMM process crashes. The crash was accompanied by segmentation fault errors and multiple HA process failures, resulting in the device being unable to come online.

Environment

  • BIG-IP Virtual Edition (VE) deployed on Hyper-V
  • Software version: 17.5.1.3 (Point Release 3)
  • NIC driver in use: 'xnet'

Cause

The TMM process crashes are caused by a software Bug ID2140213 affecting the 'xnet' NIC driver on BIG-IP VE running on Hyper-V with version 17.5.1.x.

Recommended Actions

  • Change the TMM NIC driver from 'xnet' to 'sock' as described in F5 article K000153024.
  • Await a permanent fix from F5 Product Development for bug ID2140213 before reverting to 'xnet' if required.
