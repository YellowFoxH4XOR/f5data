K000156666: IP address reuse within multiple SNAT pools

Type
Support Solution
Published
2025-09-30
Updated
2025-09-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000156666

Description

There is no configuration-level restriction preventing the reuse of the same IP address in multiple SNAT pools. Connection mapping is based on port numbers, not the SNAT pool itself. The only potential issue arises if the same SNAT IP is used by multiple virtual servers simultaneously and the combined connection load is high, which could lead to port exhaustion for that IP address.

 

Environment

  • BIG-IP
  • SNAT Pool

 

Cause

None

 

Recommended Actions

Be aware that if the same SNAT IP address is used by multiple virtual servers at the same time, there is a risk of port exhaustion if the total number of concurrent connections is high. Each IP address can support approximately 65,000 concurrent connections.
