What Happened?

When blindfolding the secret you receive, the following error:

    • Error during blindfolding SyntaxError: Unexpected end of JSON input
    • Error: 403 Forbidden. You do not have permission to perform this operation.

Environment

  • Distributed Cloud (SaaS)
  • F5® Distributed Cloud Service
  • TLS Blindfold

Resolution/Answer

This is a problem with the user roles.

A minimum monitor role in the Shared namespace is required

    • This is documented in the TechDocs here

It is part of the "prerequisites" of the section "blindfold your TLS certificates".
