Description

You cannot access to GUI, BIG-IP is requesting client certificate.
 

Environment

  • BIG-IP any version
  • Configulation Utility (GUI).


Cause

httpd is configured with SSL verify client as requrired.

Run following command on the CLI then you may see similar output:
tmsh list sys httpd
sys httpd {
    auth-pam-idle-timeout <value>
    ssl-ocsp-enable on        <<<-----[!]
    ssl-verify-client require <<<------[!]
}

 
Recommended Actions

Set the client to present client certificate.
Or
put it to default to running below
tmsh modify sys httpd ssl-verify-client no
tmsh modify sys httpd ssl-ocsp-enable off
tmsh save sys config 
 

    Additional Information

    ssl-verify-client Specifies if the client certificate needs to be verified for SSL session establishment. The default is none.
