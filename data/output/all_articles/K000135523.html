K000135523: F5OS-C Partition tenant Image upload does not start

Type
Support Solution
Published
2023-08-14
Updated
2023-08-14
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.1.X, 1.2.X, 1.3.X, 1.5.1, 1.1.0, 1.1.1, 1.1.2, 1.1.3, 1.1.4, 1.2.0, 1.2.1, 1.2.2, 1.3.0, 1.3.1, 1.3.2, 1.5.0
Source
https://my.f5.com/manage/s/article/K000135523

Description

When you try to upload partition tenant image, after selecting proper file, upload process does not start and there's no error presented

 

Environment

  • F5OS-C
  • Tenant image upload

Cause

Disk volume created for the partition does not have enough space left for the new image

 

Recommended Actions

Clean up files stored in .tmp folder under /var/F5/partition<ID>/IMAGES/.
In below example partition 2 has 91% disk space usage and remaining space may not be enough for the new image.


Example:

root@controller-2(velos1.local) /]# df -h 2>&1 | grep IMA

/dev/mapper/partition_image-partition1     15G  33M  15G  1% /var/F5/partition1/IMAGES

/dev/mapper/partition_image-partition2     15G  14G 1.5G 91% /var/F5/partition2/IMAGES

/dev/mapper/partition_image-partition3     15G  11G 4.7G 70% /var/F5/partition3/IMAGES

/dev/mapper/partition_image-partition4     15G  33M  15G  1% /var/F5/partition4/IMAGES

/dev/mapper/partition_image-partition6     15G 2.1G  13G 14% /var/F5/partition6/IMAGES

/dev/mapper/partition_image-partition5     15G  33M  15G  1% /var/F5/partition5/IMAGES



[root@controller-2(velos1.local) .tmp]# pwd
/var/F5/partition2/IMAGES/.tmp


[root@controller-2(velos1.local) .tmp]# ls -la
total 7934064
drwxrwxrwx. 2 root root          52 Jun 30 11:10 .
drwxrwxr-x. 4 root admin        198 Jul 18 11:05 ..
-rw-------. 1   48    48 5928976384 Jun 29 13:53 qHiTUQrz-vFdBPv
-rw-------. 1   48    48 2195503115 Jun 30 11:14 TlKE0DmX-FFx1ZT

Following command will delete files
[root@controller-2(velos1.local) .tmp]# rm qHiTUQrz-vFdBPv TlKE0DmX-FFx1ZT

 

 

Additional Information

When the upload file process fail, temporary file stored in /var/F5/partition2/IMAGES/.tmp is not automatically deleted and should be cleaned manually
