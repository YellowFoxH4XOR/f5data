Description
You may encounter this error message in /var/log/ltm file:

warning tmm2[<PID>]: 01260009:4: Connection error: ssl_hs_vfy_vfydata_cont:10848: verify failed (47)

Environment

  • BIG-IP

  • Client SSL profile

Cause
SSL handshake data verify failed. For example, other device modify the SSL data sending from client side. Below is an exmaple of capture of triggering such alerts, in which there is an addtional SSL extension inserted in the client Hello message sending to BIG-IP.
