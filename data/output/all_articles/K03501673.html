Description
The BIG-IP drops the 5th TCP SYN packet in a single connection when the Virtual Server uses a FastL4 Profile.

Environment

  • BIG-IP
  • FastL4 Profile.

Cause
The number of packets with TCP SYN allowed to forward over a single connection is limited by default.

Recommended Actions

A  the new db key, tm.dupsynenforce , was introduced in BIG-IP versions 15.0.0, 14.1.0.6, 14.0.0.5, 13.1.1.5, 12.1.4.1 and 11.6.5.1.

  1. Log on to the BIG-IP command line.
  2. Type the following TMSH command: 
    tmsh modify sys db tm.dupsynenforce value disable
    Note: Setting the db key to disable allows the BIG-IP to forward an unlimited number of SYNs.
