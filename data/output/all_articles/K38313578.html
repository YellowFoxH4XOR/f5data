Description
Configuration Utility (GUI) does not get completely populated with all menus and next error is present in the logs: 

httpd [<pid number>] [proxy:error] [pid <pid number>] (111)Connection refused: AH00957: HTTP: attempt to connect to 127.0.0.1:port
httpd[8775] [proxy:error] [pid <pid number>] AH00959: ap_proxy_connect_backend disabling worker for (localhost) for 5s

Environment

  • BIG-IP Configuration Utility 

Cause
Unknown

Recommended Actions

Reboot the BIG-IP.
  1. Logon to the Traffic Management Shell (tmsh).
  2. If the issue affects the active device of a HA (High Availability) environment failover to the peer device with the following command:
    run /sys failover
  3. Type the following command: 
    reboot
