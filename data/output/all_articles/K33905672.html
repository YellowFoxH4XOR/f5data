K33905672: Unable to login BIG-IQ GUI and got error when creating qkview

Type
Support Solution
Published
2021-08-14
Updated
2025-04-02
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K33905672

Description

You may find that several symptoms on BIG-IQ 

  • Unable to login via GUI with the error;

Authentication failed. Please have the System Administrator verify the local authentication provider's configuration.

  • Error found when creating qkview;

error: PostgreSQL is not ready to accept connections.

Failed to execute db dump. Exit code 1

 

  • Lack of disk space for /var;

/var/log/ltm

Aug 10 13:31:02 bigiq1 err diskmonitor: 011d0004:3: Disk partition /var has only 0% free

Environment

  • BIG-IQ VE

Cause

Lack of disk space for /var

Recommended Actions

  1. Follow K30902515 to resize the /var directory.
  2. Restart the services.

BIG-IQ 7.1.0 and later

# tmsh restart /sys service postgres tokumond restjavad webd guiserver

Prior to BIG-IQ 7.1.0

# tmsh restart /sys service tokumx tokumond restjavad webd guiserver

Additional Information

None.
