Known Issue

This is the result of a known issue. The PERSIST_DOWN iRule event defines the logic the iRule should evaluate when the desired persistence target is no longer available. When cookie persistence or Microsoft Remote Desktop (MSRDP) persistence is the configured persistence method, PERSIST_DOWN is not triggered on failed persistence.

F5 Product Development is tracking this issue as ID 325230 (formerly CR104960).

Workaround

You can work around this issue by choosing a different persistence method.
