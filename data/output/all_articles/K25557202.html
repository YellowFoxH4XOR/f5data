Description

  • Can't establish VDI Connections via APM Webtop when ASM policy is enabled
  • When adding AWAF/ASM security policy to an existing published desktop VDI resources, even if the policy is transparent.

Environment

  • VDI Protocol

Cause

This is due to incompatibility of protocols that are used by the VDI.

By default VDI connection established on a none 80/443 port and using a proprietary protocol while ASM is an Application layer firewall solution, which works exclusively on HTTP protocol.

Recommended Actions

  • A workaround you would need to approach this with a layered virtual setup as described in article K03113285.
  • The layered virtual solution does NOT support Citrix ICA solution.

Additional Information

VDI is a display protocol providing end users with a graphical interface to a remote desktop.

VDI components can be Windows Remote Desktop Protocol (RDP), Citrix's Independent Computing Architecture (ICA) as well as Blast Extreme and PCoIP [vmware].
