Known Issue

The BIG-IP system may prematurely reset Client SSL connections.

This issue occurs when all of the following conditions are met:

  • The affected Client SSL profile has its Alert Timeout setting set to 10 seconds.

    Note: 10 seconds is the default value for Secure Sockets Layer (SSL) profiles on BIG-IP systems running versions listed in the Applies to (see versions) box located in the upper-right corner of the page.

  • The affected client may require more than 10 seconds to respond to SSL connections.

Impact

The Client SSL connection is interrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Client SSL connection is prematurely reset by the BIG-IP system.
  • If you enable the TM.RstCause database variable during troubleshooting, you observe a log message similar to the following example in the /var/log/ltm log file:

    SSL alert timeout exceeded

    Note: For information about enabling and disabling this database variable, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.

Workaround

To work around this issue, you can increase the SSL alert timeout by modifying the Alert Timeout setting in the Client SSL profile to Indefinite. To do so, perform either of the following procedures:

Impact of workaround: Performing the following workarounds should not have a negative impact on your system.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Click the name of the affected Client SSL profile.
  4. Check the Alert Timeout setting and select Indefinite.
  5. To save the changes, click Update.

Traffic Management Shell 

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Modify the Alert Timeout setting to the value of Indefinite by using the following command syntax:

    modify ltm profile client-ssl <profile name> alert-timeout indefinite

    For example, type the following command to increase the Alert Timeout setting for the myexampleclientssl profile to indefinite:

    modify ltm profile client-ssl myexampleclientssl alert-timeout indefinite

  3. Save the changes by typing the following command:

    save /sys config
