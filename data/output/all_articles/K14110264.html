Description

F5 TMM ciphers do not use the same naming scheme as IANA or the commonly used OpenSSL naming scheme.
This document lists F5 TMM cipher-names with their IANA and OpenSSL equivalents, ordered by hex code.

Environment

  • BIG-IP LTM
  • SSL client/server profiles

Cause

None

Recommended Actions

Use the following table to convert between F5 TMM cipher names, IANA cipher names and  OpenSSL cipher names.
