Description

By default, the SNMPD log file /var/log/snmpd.log does not include timestamps for events that are logged in the file. This article describes the procedure for an administrator to enable timestamps in /var/log/snmpd.log which can be useful for correlating events.

Environment

  • snmpd logged events

Cause

None

Recommended Actions

Configure the BIG-IP to enable timestamps on /var/log/snmpd.log file using the following procedure:
  1. Log in to tmsh by typing the following command:
    tmsh
  2. Configure SNMPD to set timestamps on the logs:
    modify sys snmp include "[snmp] logTimestamp yes"
  3. Save the change by typing the following command:
    save /sys config
  4. Restart the snmpd daemon:
    restart /sys service snmpd
