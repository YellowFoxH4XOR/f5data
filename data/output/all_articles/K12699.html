Issue

Error Message

local/tmm err tmm[<pid>]: 01230113:3: Unsupported media setting 10000_T/full for interface <interface>

In this error message, note the following:

  • <interface> is the vmxnet3 interface used by the BIG-IP virtual edition.
  • <pid> is the process ID for the TMM process.

For example:

local/tmm err tmm[4651]: 01230113:3: Unsupported media setting 10000_T/full for interface 1.1

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You are running BIG-IP LTM Virtual Edition (VE) or BIG-IP APM Virtual Edition (VE).
  • A TMM process has started or has been restarted.

This error message is logged because of how the vmxnet3 driver advertises the virtual network adapters to TMM. This error message does not indicate an issue with BIG-IP LTM VE or BIG-IP APM VE.

This issue has been logged as ID 340286 and was fixed in BIG-IP 11.5.0

Note: When you deploy BIG-IP LTM VE or BIG-IP APM VE, by default, the virtual machine guest environment will include three virtual network adapters: one for the management interface and two for the TMM interfaces. If your specific needs demand more TMM interfaces, you can add more virtual network adapters to the virtual machine guest environment. For more information, refer to SOL12149, referenced in the following Supplemental Information section.

Note: On BIG-IP LTM VE and BIG-IP APM VE, a TMM interface is reported as UNINITIALIZED until it is assigned to a VLAN or trunk. For more information, refer to SOL12697 referenced in the following Supplemental Information section.

Impact

There is no impact; you may safely ignore this error message.
