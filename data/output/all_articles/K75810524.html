Description

It is not possible to load ASM updates through the proxy server. When clicking Check for Updates, the popup spins indefinitely on Checking for updates...

No outbound connections are made to the proxy server when verifying with tcpdump.

A connection to the Live Update server can be made directly via the proxy when initiating a curl manually.

Furthermore, attempting an update check using the REST API returns a 500 response similar to the following:

[root@bigip1:Active:In Sync] tmp # curl -sku admin:password "https://localhost/mgmt/tm/live-update/asm-attack-signatures/availability" | jq .
{
  "code": 500,
  "message": "complete() of GET http://localhost:8100/tm/live-update/asm-attack-signatures/availability from 127.0.0.1 127.0.0.1 called with incompatible status code 500 so redirecting to failed()",
  "originalRequestBody": "{\"kind\":\":resterrorresponse\",\"responseCode\":500}",
  "referer": "127.0.0.1",
  "restOperationId": 36480491,
  "kind": ":resterrorresponse"
}

Environment

  • Live Updates
  • Upgrade or new installation

Cause

Bug ID 951133

Recommended Actions

Restart tomcat:

tmsh restart sys service tomcat

Note: There is no impact to traffic, but the GUI will be temporarily unavailable.
