Issue

Error Message

01070967:3: The specified vlan, vlangroup or tunnel (<name>) cannot be removed from its default route domain (<rd>)

In this error message, note the following:

  • <name> is the partition and name of the Virtual Local Area Network (VLAN), VLAN group, or tunnel
  • <rd> is the partition and name of the route domain

For example:

01070967:3: The specified vlan, vlangroup or tunnel (/Common/vlan_10) cannot be removed from its default route domain (/Common/0)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • You attempt to remove a VLAN, VLAN group, or tunnel from the default route domain without specifying another route domain.

Impact

You are unable to remove the object from the default route domain. The BIG-IP system prevents the action during validation.

Recommended Actions

You should move the VLAN, VLAN group, or tunnel to the route domain you want instead of removing the object from the default route domain. Note that the VLAN, VLAN group, or tunnel must be assigned to the same partition as the route domain you want to assign to. Consider the following configuration example:

net route-domain 0 {
    id 0
    vlans {
        HA
        http-tunnel
        socks-tunnel
        external
        internal
        /partition1/partition1_VLAN
    }
}
net route-domain partition1_RD {
    id 10
    partition partition1
}

If you attempt to remove /partition1/partition1_VLAN VLAN object from the default route domain 0, the system would prevent you from removing it and reports the following error message:

# modify net route-domain 0 vlans delete { /partition1/partition1_VLAN }
01070967:3: The specified vlan, vlangroup or tunnel (/partition1/partition1_VLAN) cannot be removed from its default route domain (/Common/0).

You should assign /partition1/partition1_VLAN VLAN object to /partition1/partition1_RD route domain:

# cd /partition1/
# modify net route-domain partition1_RD vlans add { partition1_VLAN }
# list net route-domain partition1_RD
net route-domain partition1_RD {
    id 10
    partition partition1
    vlans {
        partition1_VLAN
    }
}
# cd /Common
# list net route-domain 0
net route-domain 0 {
    id 0
    vlans {
        HA
        http-tunnel
        socks-tunnel
        external
        internal
    }
}
