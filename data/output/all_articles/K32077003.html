K32077003: High memory and disk utilization reported by SNMP

Type
Support Solution
Published
2021-02-23
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K32077003
Description: 
High memory and disk utilization reported by SNMP.

Environment:
  • BIG-IP
  • SNMP

Cause:
Because of the way that the BIG-IP organizes its memory, you should not use the standard Linux OID to get memory information.
Some disk file systems are created as read-only and therefor have an intentionally low amount of free space 

Recommended Actions:
To monitor the memory of BIG-IP, it is recommended that you use the correct OID which can be obtained by installing the F5 SNMP MIB files on your monitoring system, which can be obtained via article K13322.
Only disks systems that are mounted as read-write should be monitored.


Additional Information:
None.
