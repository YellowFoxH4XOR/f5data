Known Issue

The Management Ethernet port on some BIG-IP platforms may not link with an external switch.

This issue occurs when all of the following conditions are met:

  • You are running one of the following platforms: 1600, 3600, 3900, 6900, 8900, or EM 4000.
  • You did not have the management Ethernet cable connected at boot time, and subsequently plugged it in after boot.
  • The management Ethernet port is configured for auto speed negotiation.
  • You are connecting the management Ethernet port to an external switch at a speed other than 1000baseT.

Impact

The management Ethernet port fails to operate.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The network interface fails to link to the switch, and the LEDs on the BIG-IP management Ethernet port are not illuminated.
  • The tmsh show /net interface mgmt command shows the media type as none.

Workaround

To work around this issue, you can explicitly configure the management Ethernet port to the correct speed. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Explicitly set the port Ethernet speed on the management port

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Type the following command to change the speed:

    modify /net interface mgmt media <speed>

    For example, to set 100TX Full Duplex, you would type the following command:

    modify /net interface mgmt media 100TX-FD

    Note: To view the list of interface speeds available for the management port, type the following command:

    (In the following syntax, <TAB> denotes pressing the TAB key on the keyboard.)

    modify /net interface mgmt media <TAB>

  3. Optional: Save the change by typing the following command:

    save /sys config
