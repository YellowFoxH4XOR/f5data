K000137546: Server List is deleted in the APM Edge client after upgrading the APM Client to 7.2.4.3

Type
Support Solution
Published
2024-07-11
Updated
2026-05-07
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000137546

Description

After upgrading to APM Client 7.2.4.3, the Edge Client component updates itself to the newest version. You notice that the Server List is not there anymore.

Also, the members of the Server List were never added to the Connectivity Profile in the BIG-IP APM. They were manually added to the config.f5c or automatically added when the end-users successfully connected after the first time.

 

Environment

  • Upgrade to APM Client 7.2.4.3 or later from older than 7.2.4.3
  • Server List in the Connectivity Profile does not match the contents of the config.f5c file.

 

Cause

This happened due to a new security feature added in Edge Client 7.2.4.3, which compares the client-side user-specific client.f5c with the server-side connectivity profile config, and if they do not match, it pushes the server-side config to the client-side user-specific client.f5c.

From the release notes.

1189461-6 Edge Client follows the best practices and detects the unauthorized modification of the APM Virtual Server list. This causes a behavioral change as directly modifying the Client.f5c file is not allowed. For more information, refer to the K000134716 article. In addition, this fix overwrites the APM virtual server list and other settings in the client.f5c file with the settings defined in config.f5c file. Refer to the known issue 1324053-1 for more details.

 

Recommended Actions

  • Before the upgrade, make sure that the contents of the config.f5c file matches the contents of the Server List in the connectivity profile.
