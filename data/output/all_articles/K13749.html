Known Issue

The Enterprise Manager system cannot install BIG-IP version 11.2.0, 11.2.1 and 11.3.0 on the following platforms:

  • BIG-IP 1600
  • BIG-IP 3600
  • BIG-IP 6900
  • BIG-IP 8900
  • VIPRION B4300N blade (NEBS)

This issue occurs when all of the following conditions are met:

  • The Enterprise Manager system is running version 2.3.0 or 3.1.0
  • The affected BIG-IP version's image is uploaded to the software repository on the Enterprise Manager system
  • The Enterprise Manager system has one or more of the affected platforms in its managed device list
  • You attempt to install/upgrade an affected platform to an affected BIG-IP version using the software image copy and installation task on the Enterprise Manager system

Impact

The Enterprise Manager system is unable to install/upgrade the affected BIG-IP software versions on the affected platforms

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Enterprise Manager is unable to install/upgrade the affected BIG-IP software versions on the affected platforms
  • When you attempt to perform a software image copy and installation task, the affected platform is listed as Unsupported platform under the Incompatible with Software Image device filter

Note: This issue has been confirmed to exist in Enterprise Manager 3.1.0 after it was fixed in Enterprise Manager 3.0.0.

Workaround

To work around this issue, you can temporarily disable compatibility checking on the Enterprise Manager system before proceeding to perform the desired BIG-IP software install/upgrade on the affected platform. To do so, perform the following procedure:

Impact of workaround: Disabling the compatibility checking on the Enterprise Manager system allows you to install software to incompatible target platforms, which may require a full manual installation to recover. Ensure that you re-enable compatibility checking when you complete this procedure.

  1. Log in to the command line.
  2. Disable compatibility checking by entering the following command:

    em_platform_override -d

  3. Log in to the Configuration utility.
  4. Proceed to install the desired BIG-IP software on the affected platform using the software image copy and installation task on the Enterprise Manager system.
  5. When the desired BIG-IP software install is completed on the affected platform, log in to the command line.
  6. Re-enable compatibility checking by entering the following command:

    em_platform_override -e
