K11562252: Portal Access failed to rewrite JavaScript code that contains 'let' statement

Type
Support Solution
Published
2021-12-23
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM: 14.0.X, 14.0.1, 14.0.0, 13.1.5, 13.1.4, 13.1.X, 13.1.1, 13.1.0, 13.1.3
Source
https://my.f5.com/manage/s/article/K11562252

Description

The BIG-IP APM portal access is failed to rewrite modern JavaScript that has 'let' statement in the code.
As a result of this issue, you encounter one or more of the following symptoms:

  • Web page content that depends on the BIG-IP APM rewrite of JavaScript does not function.
  • The system may not correctly display the Portal Access content. 
  • Logs similar to the below can be seen in /var/log/rewrite
<13> Jan 16 04:13:11 local-bigip1 notice rewrite - fm_patchers/jsParser.cpp:89 : jsParser::Tokenize(): There was an error: [Oops - failed to parse at line 30108, context after error: let b = a;
<13> Jan 16 04:13:11 local-bigip1 notice ...]

Environment

  • Portal Access
  • JavaScript

Cause
Bug ID 720223: Portal Access: 'let' statement is supported by server-side JavaScript parser

Recommended Actions

Please contact F5 support to get a workaround iRule. Otherwise please consider to upgrade your BIG-IP version to v14.1.0 for the fix.
