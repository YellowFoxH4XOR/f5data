Issue

Error Message

err tmm[<PID>]: 01240006:3: Error querying request URI: <Condition> (<Additional Details>)

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <Condition> is the currently reported condition of the URI being evaluated.
  • <Additional Details> is the virtual server, associated profile, assigned pool, and the client IP address that is making the request.

For example:

err tmm[16419]: 01240006:3: Error querying request URI: Not found (Client side: vip=/Common/HTTPS_VIP profile=deflate pool=/Common/HTTPS_VIP_pool_80 client_ip=192.0.2.110)

Message Location

You may encounter this message in the following location:

  • The /var/log/tmm file

Description

This message occurs when the following condition is met:

  • The inflate or deflate filter is enabled on the virtual server, and no URI is found in the request. This may happen if a client specifies either a legacy HTTP version 0.9 request without a URI or an intentionally malformed request.

Impact

The inflate or deflate filter logs the message but continues processing. This condition does not trigger a connection reset or other response.

Recommended Actions

None
