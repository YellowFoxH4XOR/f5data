K09230153: bigip_software_install is not idempotent when targeting BIG-IP appliance platform

Type
Support Solution
Published
2022-07-14
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • Public Cloud
  • Private Cloud
  • F5 Automation and Orchestration
  • F5 Modules for Ansible
Source
https://my.f5.com/manage/s/article/K09230153

Description

When running an Ansible Task with the bigip_software_install module to upgrade a BIG-IP appliance platform, the bigip_software_install module is not idempotent and will:

  • Delete the specified volume, if the volume exists, regardless of the installed image version.
  • Recreate an empty volume, prior to installation of image.
  • Installs the specified image.

Environment

  • BIG-IP appliance platform.
  • vCMP guests running on BIG-IP appliance platform.
  • BIG-IP VE in hypervisor or cloud environment.
  • F5 Modules for Ansible

Cause

Bug ID 1125013

Recommended Actions

Additional time to completion is expected for the Ansible Playbook that contains tasks that utilize the bigip_software_install module to install software images on BIG-IP appliances.
