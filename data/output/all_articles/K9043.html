K9043: The BIG-IP WebAccelerator closes the connection for HTTP HEAD requests that use NTLM authentication

Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator does not allow NTLM authentication of HTTP requests that use the HEAD method. The BIG-IP WebAccelerator will inappropriately close the server-side connection after receiving the NTMLSSP_CHALLENGE from the origin web server.

Note: Some application functionality may break when the BIG-IP WebAccelerator closes the server-side connection.For example, when an HTTP HEAD request is used to import Excel list elements into a SharePoint List, an error message will appear similar to the following example:

Cannot connect to the server at this time.  Your table cannot be published.

F5 Networks Product Development is tracking this issue as CR103739.

Workaround

To prevent the BIG-IP WebAccelerator from closing NTLM-authenticated HTTP HEAD requests, use an iRule to bypass the BIG-IP WebAccelerator for HEAD requests.

For example:

when HTTP_REQUEST {
 if { [HTTP::method] == "HEAD" } {
  HTTP::class disable
  CACHE::disable
 }
}
