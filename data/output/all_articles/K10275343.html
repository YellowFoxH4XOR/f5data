Description

When trying to load Transform Rules from SOC Dashboard to FPS Alerts Page in BIG-IQ UI, the page goes blank and does not load

Environment

  • BIG-IQ Centralized Manager (CM)
  • SOC Dashboard
  • Transform Rule Set for Fraud Protection Services

Cause

Certain network devices such as firewalls or proxy servers can set a timeout limit for API connections, and for large transform set downloads where the REST API payload can exceed this limit, the results get truncated and the CM is unable to load the GUI due to this truncation in the response

Recommended Actions

Identify the controls between the workstation and the BIG-IQ CM and adjust the thresholds accordingly

None
