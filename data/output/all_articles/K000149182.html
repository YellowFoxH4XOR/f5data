K000149182: iRule redirects may be overwritten

Type
Support Solution
Published
2025-01-29
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000149182

Description

One of the common methods to forward traffic is by using iRules, which evaluates the content of the request in order to send traffic to an specific pool, This information include considerations on iRule code that could help to identify if the forwarding action is not properly evaluated.

Environment

  • BIG-IP LTM.
  • iRule

Cause

Consider the following example to evaluate the action taken by the iRule,

An iRule has been configured to evaluate the content from the client request

3rd action which evaluates "lan.1" will be overwriting the next actions which could involve "lan.1" in this particular scenario "eraser.lan.1" being the 4th action.

ltm rule /Common/iRule_fwd {
when HTTP_REQUEST {
set hostname [string tolower [HTTP::host]]
    if { $hostname contains "book.lan.1" } { 
        pool Pool_1 
    } elseif { $hostname contains "pencil.lan.1" } { 
        pool Pool_2
    } elseif { $hostname contains "lan.1" } {       
        pool Pool_4
    } elseif { $hostname contains "eraser.lan.1" } {
         pool Pool_3
    }  
}

Since"lan.1" is included on all the possible forwarding, iRule logic is evaluate from top to the bottom, and will accept the first match on the request.

So, if client sent "eraser.lan.1" this will never get into 4th object, since this content is already included on 3rd "lan,1"

By the previous explanation we may conclude that this is an expected behavior.

Recommended Actions

Last object "eraser.lan.1" will never be evaluated, it's required to switch the order to be evaluated before "lan.1"

This example shows the correction.

ltm rule /Common/iRule_fwd {
when HTTP_REQUEST {
set hostname [string tolower [HTTP::host]]
    if { $hostname contains "book.lan.1" } { 
        pool Pool_1 
    } elseif { $hostname contains "pencil.lan.1" } { 
        pool Pool_2
    } elseif { $hostname contains "eraser.lan.1" } {
         pool Pool_3
    } elseif { $hostname contains "lan.1" } {       
        pool Pool_4
    } 
}
