Description
You have a Virtual Server (VS) defined on one HA member but it does not sync to the peer HA member.

Environment

  • BIG-IP
  • DSC (Device Service Clustering)

Cause
The Virtual server is using a Virtual IP (VIP) that is defined as traffic-group-local-only so it is not expected to sync between HA members. 

Example: 

# tmsh list /ltm virtual-address all-properties

ltm virtual-address /Common/10.0.0.1 {
    address 10.0.0.1
...snip...
    traffic-group /Common/traffic-group-local-only <----- traffic-group-local-only will not sync by design
}

Recommended Actions

Change the Virtual IP (VIP) to the sync group. 

Local Traffic  ››  Virtual Servers : Virtual Address List : <VIP>
- Traffic Group: change from "traffic-group-local-only" to "traffic-group-1"
