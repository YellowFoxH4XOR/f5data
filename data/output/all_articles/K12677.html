Known Issue

This is the result of a known issue. In the BIG-IP version 9.4.7 and later F5-BIGIP-SYSTEM-MIB file, several OIDs for reporting on memory usage have descriptions that incorrectly indicate that the values returned for those OIDs do not include memory used by TMM.

This is a cosmetic error in the OID descriptions only, and the values returned by the OIDs are otherwise correct as described in the MIB file, excluding the phrase (not including TMM).

For example the description for sysHostMemoryTotal currently reads:

The total host memory in bytes (not including TMM).

The value returned by the OID should then be interpreted as:

The total host memory in bytes.

The following six OIDs incorrectly include the description (not including TMM):

  • sysHostMemoryTotal
  • sysHostMemoryUsed
  • sysMultiHostTotal
  • sysMultiHostUsed
  • sysGlobalHostMemTotal
  • sysGlobalHostMemUsed

F5 Product Development is tracking this issue as ID 222989 (formerly CR126462).

Note: For more information about SNMP and MIB files on the BIG-IP system, refer to K503: Overview of MIB files on BIG-IP.
