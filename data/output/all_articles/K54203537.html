Description

FIPS card cannot be initialized.

tmsh run util fips-util -f init
fipsutil error (line 1159): Library Initialization : 0x05 : Undefined Error Code.

Environment

  • BIG-IPs with FIPS cards.
  • These logs are found in /var/log/ltm

    err iControlPortal.cgi[12934]: Checking for FIPS card.. FIPS open returns FIPS_ERR
    err tmsh: Checking for FIPS card.. FIPS open returns FIPS_ERR.
Cause

Defective FIPS card

Recommended Actions

  1. Follow Manual Chapter: BIG-IP FIPS Platform Setup, and try to initialize the FIPS card.


If initialization fails, Contact F5 Support as an RMA is likely necessary.

None
