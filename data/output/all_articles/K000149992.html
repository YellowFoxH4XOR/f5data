Description

Imported APM policy (originally Modern type) and made it same name as a Standard Access Policy which has been just deleted.
Advanced customization page for the imported access policy still hold Standard type of objects.

NOTE: The picture below shows the result of importing AccessPolicy_Modern (Modern type) to AccessPolicy_Originally_Standard, after removing AccessPolicy_Originally_Standard created as Standard type. 
There is no way to change customization type when importing Access Policy. Standard type Access policy is imported as Standard, and Modern type Access Policy is imported as Modern.

 

Environment

  • BIG-IP APM
  • Any version
  • APM policy Import
  • Advanced Customization page

 

Cause

  • tomcat cache

 

Recommended Actions


There are three options to see the actual contents in Advanced Customization page

  • When you import do not use same policy name.
  • Wait till the cache expires.
  • Restart tomcat on CLI
    tmsh restart sys service tomcat
    NOTE: While it is restarting there is no access to GUI, however there should not have any impact for traffic.
