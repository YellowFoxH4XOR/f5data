Description
How to change/reallocate the cores for vCMP guests, when there is not enough cores left?
 

Environment

  • BIG-IP any version
  • vCMP guests
  • CPU allocation/reallocation

Cause

n/a


Recommended Actions

When you have multiple guests, and want to change the numbers of core for some guests.
  1. set the guests Configured state, and save. 
    NOTE: when a guest is in Configured state, the vCMP HOST release those core and made them available.
     
  2. change the config for each guests.
     
  3. set the guests Provisioned state.
    NOTE: when a guest is in Provisioned state, the vCMP HOST allocate the guests for available cores, and made them unavailable. But the guest is shutdown state.
     
  4. set the guests deployed state, if there is no error returned,
    NOTE: when a guest is Deployed state, the guest is running and core reallocation is not possible.

Additional Information

  • vCMP for Appliance Models: Administration
  • vCMP for VIPRION Systems: Administration
