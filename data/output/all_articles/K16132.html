Known Issue

Retransmitted SYN packets may cause TCP three-way handshakes to fail.

This issue occurs when all of the following conditions are met:

  • You use a platform with Clustered Multiprocessing (CMP) enabled.
  • Your configuration includes an IP Forwarding virtual server.
  • A persistence profile is associated with the IP Forwarding virtual server.
  • A new connection attempt to the IP Forwarding virtual server sends multiple SYN packets before the TCP three-way handshake is complete.

Impact

Client connections fail intermittently.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client connections fail intermittently.
  • The system logs error messages similar to the following example in the /var/log/ltm file:

    err tmm[6789]: 01230140:3: RST sent from 192.168.1.1:1000 to 192.168.1.100:80, Unknown reason

Workaround

None. To avoid this issue, you can remove the persistence profile from the IP Forwarding virtual server.
