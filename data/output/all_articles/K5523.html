Note: Beginning in BIG-IP 10.0.0, logging has been enhanced to automatically include administrative activities, such as logon and logoff operations and logon failures. For more information, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

The syslog-ng utility offers flexibility, which allows for more options in filtering which messages will be sent and to which servers the messages can be sent.

The syslog-ng utility is a third party logging utility that replaces the normal syslog utility found on UNIX and Linux. The utility allows for more scalable and flexible logging.

Note: For more information about the syslog-ng utility, refer to the following location. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://www.balabit.com/products/syslog_ng/

BIG-IP 9.4.2 through 9.6.1

Starting in BIG-IP 9.4.2, you can customize the syslog-ng configuration to log informational authentication messages, such as user login attempts, by performing the following procedure:

  1. Log in to the BIG-IP command line.
  2. To replace the existing filters, type the following bigpipe syslog include command:

    bigpipe syslog include '"filter f_authpriv {
       facility(auth, authpriv) and level(info..emerg);
    };"'

    Important: The include command replaces any previously included data; only the most recently applied data set is retained. To add multiple elements to the syslog-ng configuration, you must construct a single include command following the above example.
  3. The syslog-ng service will automatically restart to initialize the new configuration.

    Note: Examine any console output for errors. A successful include operation will not produce any output to the console.
  4. Save the configuration by typing the following command:

    bigpipe save all

    Note: You can remove any includes added to the syslog-ng configuration by typing the following command:

    bigpipe syslog include none

BIG-IP 9.0.0 through 9.4.1 and BIG-IP SAM 8.0.0

To configure the BIG-IP to log informational authentication messages, such as user login attempts, perform the following procedure:

  1. Log in to the BIG-IP command line.

  2. Back up the syslog-ng.conf file by typing the following command:

    cp /etc/syslog-ng/syslog-ng.conf /etc/syslog-ng/syslog-ng.conf.orig

  3. Using a text editor, open the /etc/syslog-ng/syslog-ng.conf file and locate the following lines: 
    # authpriv.*                                    /var/log/securefilter f_authpriv {facility(auth, authpriv) and level(notice..emerg);};
  4. Change the lines shown in step 3 to the following: 
    #  authpriv.*                                    /var/log/secure# modified to log su and authentication attempts, changed level from notice to infofilter f_authpriv {facility(auth, authpriv) and level(info..emerg);};
  5. Restart syslog-ng by typing the following command:

    bigstart restart syslog-ng
