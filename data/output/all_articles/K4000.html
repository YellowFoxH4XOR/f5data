K4000: The default certificate and default key options are no longer displayed when creating an SSL proxy

  • BIG-IP 4.X: 4.6.4
Source

Topic

The default certificate and default key are used by the BIG-IP Configuration utility web server and should not be used with an SSL proxy. Starting in BIG-IP versions 4.5.11 and 4.6.3, these options are removed.
