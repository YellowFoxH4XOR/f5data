K000146866: Why is my DNS Load Balancer not distributing the load between its pool members correctly?

Type
Support Solution
Published
2024-11-08
Updated
2025-12-28
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Load Balancer
Source
https://my.f5.com/manage/s/article/K000146866

What Happened?

You added a new pool member to your DNS Load Balancer pool and it looks like the load is not getting distributed correctly.

Environment

  • F5® Distributed Cloud DNS Load Balancer 

Resolution/Answer

When configuring a DNS Load Balancer you might have enabled option "Response Cache Parameters" that is caching the response and providing the same pool member if the tests you are doing are less than the TTL configured.
