K000148611: Period '.' character is not supported in VELOS tenant names while it is a allowed character in VCMP guest names.

Type
Support Solution
Published
2024-11-19
Updated
2024-11-19
Source
https://my.f5.com/manage/s/article/K000148611

Description

Period '.' character is not supported in VELOS tenant names while it is a allowed character in VCMP guest names.

Environment

  • VELOS
  • Tenant Naming convention
  • Period character '.'

Cause

This is a restriction of K8S, and is a standard followed.

Period '.' in the tenant name would create another level of subdomain in the DNS domain name, which is why this is not feasible in VELOS tenants.

Recommended Actions

Period is not an allowed character in tenant names.

Additional Information

None
