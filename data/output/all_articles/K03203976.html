Known Issue

When you deploy BIG-IP images through the Azure Resource Manager or Marketplace Solution templates, the Azure portal may never indicate that the deployment was successful.

This issue occurs when the following condition is met:

  • You are deploying a BIG-IP image from the Azure Resource Manager or Solution Template, including the BIG-IP WAF Solution, from the Azure Security Center.

Impact

When you monitor the deployment status in the Azure portal, a successful deployment appears to have failed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system eventually times-out and indicates that the deployment has failed, even if the deployment has succeeded.
