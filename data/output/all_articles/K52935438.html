K52935438: VCMP guest fails to attach to HSB PDE

Type
Support Solution
Published
2023-04-06
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K52935438

Description

Two pool members on the standby unit are flapping after re-install. This article provides recommended actions to fix the issue.

Environment

  • iSeries device
  • v16.x
  • Problem device (Device1.example.com): 
    • sys fpga firmware-config { type l7-performance-fpga }
    • sys turboflex profile-config { type turboflex-adc }
  • Working device (Device2.example.com): 
    • sys fpga firmware-config { type standard-balanced-fpga }
    • sys turboflex profile-config { type turboflex-base }

Cause

Mismatched configuration

Recommended Actions

  1. Fix the configuration for the problem device (Device1.example.com):

    • sys fpga firmware-config { type l7-performance-fpga }
      • sys turboflex profile-config { type turboflex-adc }
        • Change to: sys turboflex profile-config { type turboflex-base }

  2. Match the working device's configuration (Device2.example.com):

    • sys fpga firmware-config { type standard-balanced-fpga }
      • sys turboflex profile-config { type turboflex-base }

  3. Reload the configuration by running:

    • tmsh load sys config

  4. Reboot the device.

Additional Information

None
