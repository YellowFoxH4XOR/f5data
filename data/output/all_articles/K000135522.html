Description

Cannot attached parent policy show none at inheritance setting

Environment

BIG-IP ASM 16.1.3

Cause

For a policy to be attached to another policy as parent, both child and parent policies would need to have the same values for the following settings:

Recommended Actions

Reconfigure the policy for HTTP/WS and HTTPS/WSS URLs" is set to Enabled/Disabled, match with parent policy

1) Application Language -- except the case when the security policy encoding is set to 'Auto Detect'

2) Policy is case sensitive

3) Differentiate between HTTP/WS and HTTPS/WSS URLs

  • Verify both policy is that " Differentiate between HTTP/WS and HTTPS/WSS URLs" is set to Enabled/Disabled same as the parent policy.
  • Once match this between the parent and child, you will be able to attach a parent policy.
