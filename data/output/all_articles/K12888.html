K12888: Users may experience latency when creating a file or directory on an ARX share which maps to a NetApp filer running ONTAP 7.3.1

Topic

A bug exists in NetApp ONTAP 7.3.1 where applications that set ACL on the file/directory during creation may get an Access Denied message or data inconsistency panics. As a result, users may experience latency when creating a file or directory on an ARX share which maps to a NetApp filer running ONTAP 7.3.1.

When this issue is encountered, the ARX will log an error message that appears similar to the following example in the syslog file:

:VCIFS-1-NOTE-UNUSUALSTS:: Operation on file '\.acopia\temp' at filer 10.10.10.20 share 'ntfs_share-1' returned STATUS_UNEXPECTED_NETWORK_ERROR.

Additionally, a packet capture will show the NT CREATE request will receive an unexpected network error response similar to the following:

49 2.721357 10.20.30.200 10.10.10.20 SMB NT Trans Request, NT CREATE
50 2.728242 10.10.10.20 10.30.40.200 SMB NT Trans Response, NT CREATE, Error: STATUS_UNEXPECTED_NETWORK_ERROR

There is no ARX workaround or resolution for this issue. To resolve the issue, the NetApp ONTAP code version must be upgraded to 7.3.1P2 or higher.
