Known Issue

The bigd process may restart and produce a core file.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running one of the following versions: 12.0.0, 11.6.0 HF6, 11.5.3 HF2, 11.4.1 HF9, or 10.2.4 HF12.
  • You have configured the BIG-IP system to use one or more custom external monitor.
  • The external monitor code causes the script to run for an extended period of time to obtain status.
  • Each external monitor instance is stopped by the next iteration of the external monitor.
  • This issue is more likely to occur when messages similar to the following appear in the /var/log/ltm file:

    info bigd[5678]: reap_child: child process PID = 6789 exited with signal = 9.

Impact

The system does not perform a health check, and available pool members may be marked as down.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The bigd process produces a core file in the /shared/core directory.
  • Log messages similar to the following example appear in the /var/log/ltm file:

    sod[5678]: 01140029:5: HA daemon_heartbeat bigd fails action is restart.
  • The system unexpectedly marks down pool members.
