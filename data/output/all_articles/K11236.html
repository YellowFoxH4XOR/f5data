Known Issue

This is the result of a known issue. On rare occasions, the BIG-IP ASM bd process writes to memory buffers without properly enforcing the buffer boundaries. This can result in memory buffer overflows, memory access errors, and possible bd crashes.

F5 Product Development tracked this issue as CR128929 and it was fixed in BIG-IP ASM 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, BIGIP-10.0.1-402.7-HF4 has been issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems with a logical volume management (LVM) disk-formatting scheme, refer to K10025: Managing BIG-IP product hotfixes (10.x). For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.
