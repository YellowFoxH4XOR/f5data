Topic

This article applies to the BIG-IP 2000, 4000, 5000, 7000, and 10000 series platforms. For information about other versions, refer to the following articles:

  • K11400446: Configuring AOM network access (i2000, i4000, i5000, i7000, and i10000 series platforms)
  • K9608: Configuring AOM network access (800, 1600, 3600, 3900, 6900, 89XX, 11000, and 11050 series platforms)

You should consider using this procedure under the following condition:

  • You want to configure Always-On-Management (AOM) so that it can be accessed over the network for one of the following platforms:
     
    • BIG-IP 2000, 4000, 5000, 7000, and 10000 series platforms

Description

The AOM system is a separate subsystem that provides lights-out management for the BIG-IP system. You can use SSH to configure AOM so that it can be accessed over the network by performing the following procedure.

Note: You can access only the command menu of the AOM on BIG-IP 2000, 4000, 5000, 7000, and 10000 series platforms. There is no shell access to the AOM subsystem itself on these platforms.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have physical serial console access to your BIG-IP system.
  • You have an available IP address that is on the same subnet as the BIG-IP management address.

Procedures

Configuring AOM network access

To configure AOM so that it can be accessed over the network, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect the serial console to the CONSOLE port.
  2. To display the AOM command menu, type the following key sequence:

    Esc (  

    Note: On US ANSI keyboards, you can select Esc+Shift+9 to display the AOM command menu.

    The AOM command menu displays as follows:

    AOM Command Menu:
    B --- Set console baud rate
    I --- Display platform information
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    N --- Configure AOM network
    S --- Configure SSH Server
    A --- Reset AOM
    E --- Error report
    Q --- Quit menu and return to console

    Note: Some menu options, such as Configure AOM network and Reset AOM, are only available using the physical serial console.

  3. To configure network access, press the N key.

    The AOM management network configurator screen appears.

  4. Complete the network configurator screens.

    Important: The AOM IP address must be different than the BIG-IP management address but on the same IP subnet.

  5. To disable the network configuration, re-run the N ---Configure AOM network option, and enter 0.0.0.0 for the IP address.
