K000157246: Do I need both the base and EHF iso images during F5OS upgrade?

Type
Support Solution
Published
2025-10-30
Updated
2025-10-30
Source
https://my.f5.com/manage/s/article/K000157246

Description

When attempting to upload an image file for the F5OS upgrade, users may be confused regarding whether both the base and EHF ISO images need to be installed.

Environment

  • F5OS
  • Image upload
  • Upgrade

Cause

The F5OS EHF is a complete image and does not require any prerequisite base image installation.

Recommended Actions

Use only the EHF (example F5OS-A-1.8.3-23493.R5R10.EHF-1.iso) for the upgrade.

Additional Information

None.
