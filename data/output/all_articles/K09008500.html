Description

In the log /var/log/ltm, find the log like below:

warning mcpd[<PID>]: 01071859:4: Warning generated : /Common/<iRule name>:<row>: warning: [possible unexpected substitution in pattern][<var expression>]

Environment

  • BIG-IP
  • iRule

Cause

Abnormal iRule command.

Recommended Actions

Refer to the row ID, find the iRule command, fix it.
For example, the following iRule will tigger this issue:

when HTTP_REQUEST {
    foreach { request_id request_time } [array get ::hit_list [HTTP::host]*] {
        if { $request_time < $window_start } {
             unset ::hit_list($request_id)
            } else {
             incr count
        }
    }
}

The ltm log:

warning mcpd[<PID>]: 01071859:4: Warning generated : /Common/<iRule name>:2: warning: [possible unexpected substitution in pattern][[HTTP::host]*]

At here, the * should not be there, remove it can fix the issue.

Additional Information

None.
