Topic

When configuring BIG-IP GTM server objects, you must use BIG-IP GTM listener IP addresses or self IP addresses, not management IP addresses, when you are defining IP addresses for the server address list.

If you configure the server objects with management IP addresses, BIG-IP GTM will not be able to monitor its objects (such as servers, virtual servers, and pool members). As a result, BIG-IP GTM will mark all objects red, indicating that they are unavailable.
