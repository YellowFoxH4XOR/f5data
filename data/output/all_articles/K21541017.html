Description

  • LTM policies configured to redirect HTTP requests may return TCL error
01220001:3: TCL error: /Common/ <iRule_name>  <HTTP_REQUEST> - Can't call after responding - ERR_NOT_SUPPORTED (line 1)     invoked from within "HTTP::method"

Environment

  • BIG-IP
  • LTM policy
  • LTM iRule

Cause

  • LTM policy action to redirect to configured URI
  • LTM iRule attempting to process HTTP context data after LTM policy has already completed URI redirect
  • Change in behavior due to enhancement ID 737252

Recommended Actions

  • Modify iRules to include return or HTTP::has_responded command
  • Currently, the iRule below allows GET and POST HTTP methods only.
  • Example syntax:
when HTTP_REQUEST {
    if {[HTTP::has_responded]} {
        return
    } elseif { ( [HTTP::method] equals "GET" ) or ( [HTTP::method] equals "POST" ) } {
        return
    } else {
        reject
    }
}

Additional Information

  • Please add any additional methods you want to allow by inserting 'or ( [HTTP::method] equals " <name of allowed http method> " )
