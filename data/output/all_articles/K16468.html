Known Issue

The BIG-IP system may generate duplicate audit log messages.

This issue occurs when all of the following conditions are met:

  • You enable audit logging for BIG-IP configuration changes.
  • You run a Traffic Management Shell (tmsh) command that results in a validation error message.

    For example, when you attempt to create an object that already exists in the configuration, you receive an error message that appears similar to the following example:

    (tmos)# create ltm pool http_pool members add { 10.1.1.1:http 10.1.1.2:http 10.1.1.3:http }
    01020066:3: The requested Pool (/Common/http_pool) already exists in partition Common.

When the aforementioned conditions are met, the validation error results in the generation of duplicate audit messages:

Apr 19 08:20:20 bigip-ha-1 notice tmsh[32477]: 01420002:5: AUDIT - pid=<PID> user=<USER> folder=/Common module=(tmos)# status=[01020066:3: The requested Pool (/Common/http_pool) already exists in partition Common.] cmd_data=create ltm pool http_pool members add { 10.1.1.1:http 10.1.1.2:http 10.1.1.3:http }

Apr 19 08:20:20 bigip-ha-1 notice tmsh[32477]: 01420002:5: AUDIT - pid=<PID> user=<USER> folder=/Common module=(tmos)# status=[01020066:3: The requested Pool (/Common/http_pool) already exists in partition Common.] cmd_data=create ltm pool http_pool members add { 10.1.1.1:http 10.1.1.2:http 10.1.1.3:http }

Impact

The BIG-IP system generates duplicate audit messages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe duplicate audit messages in the /var/log/audit file.
  • You observe duplicate audit messages sent from the BIG-IP system to a remote logging server.
