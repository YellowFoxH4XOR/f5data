Known Issue

This is the result of a known issue. For systems licensed for dynamic routing, you cannot configure the BGP neighbor password after upgrading to BIG-IP 9.4.4.

The version of ZebOS for BIG-IP 9.4.4 is missing the BGP neighbor password command.

For example:

BIG-IP 9.4.3

#show version
ZebOS 5.4 (i686-pc-linux-gnu) 06202003-Main
Copyright 2001-2003 IP Infusion Inc.
#neighbor X.X.X.X p?
passive Set neighbor to passive mode
password Set password to the neighbor
prefix-list Filter updates to/from this neighbor
...

BIG-IP 9.4.4

#show version
ZebOS version 7.5.0.e0 IPIRouter 01/30/08 11:21:16
Build # is ZebOS-7-5-0-e0-IPI on host i686-pc-linux-gnu
Copyright (C) 2001-2004 IP Infusion Inc. All rights reserved.
#neighbor X.X.X.X p?
passive Don't send open messages to this neighbor
peer-group Member of the peer-group
port Neighbor's BGP port
prefix-list Filter updates to/from this neighbor
....

F5 Product Development tracked this issue as CR95228 and it was fixed in BIG-IP 9.4.5. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator release notes.

This issue was fixed in Hotfix-BIG-IP-9.4.4-73.1-HF1, which has been issued for BIG-IP 9.4.4 for the 9.4.0 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
