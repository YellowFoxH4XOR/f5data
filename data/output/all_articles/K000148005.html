K000148005: Can I create a webhook to the F5 Statuspage?

Published
2024-11-08

Applies to

  • F5 Distributed Cloud
Source

What Happened?

  • You want to create a webhook to the F5 Statuspage to be up to date on the latest changes and incidents
  • Statuspage can send notifications to you via webhooks when we create or update an incident, or update a component status
  • Webhooks contain information about the item that changed

Environment

  • F5® Distributed Cloud Service
  • Alerts

Resolution/Answer

Yes, there is a way to create a webhook for the f5cloudstatus.com updates.

 

Additional Information

Our https://www.f5cloudstatus.com Statuspage is provided by Atlassian Statuspage, please check the following links for more details:

  • Enable webhook notifications
  • Notification event trigger shows the types of events that trigger notifications to end users
