Known Issue

The Server/Application State Protocol (SASP) monitor stops processing messages after receiving an unexpected Send Weights message from the Group Workload Manager (GWM) server.

This issue occurs when all of the following conditions are met:

  • The SASP monitor sends a Registration Request message that contains a specific Message ID to the GWM server.
  • The SASP monitor expects a Registration Reply message with the same Message ID from the GWM server.
  • The SASP monitor receives a Send Weights message with the same Message ID from the GWM server.

Impact

The SASP monitor stops processing any further messages, and the pool member status becomes offline.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The pool member status is offline.
