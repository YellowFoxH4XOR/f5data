K000160830: VPN Connection Fails due to Windows Core Isolation

Type
Support Solution
Published
2026-04-16
Updated
2026-05-22
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160830

Description

VPN Network Access connections fail on some Windows 11 clients using BIG-IP APM. Affected users receive the error messages:

  • "TUNNEL_SERVER_READY_CHECK - configuration read timed out"
  • "Failed to download configuration"

Symptoms include:

  • VPN connection attempts stall or fail during the configuration download phase.
  • The issue is observed only on certain Windows clients
  • The BIG-IP APM access policy completes successfully and ends in "Allow" for all sessions.

Environment

  • Product: BIG-IP APM
  • Client OS: Windows
  • VPN Client: F5 Edge Client and browser-based Network Access
  • Windows Security Feature: Core Isolation enabled (on affected clients)

Cause

Windows 11 "Core Isolation" security feature block the F5 VPN client from downloading configuration, resulting in connection failure.

Answer/Recommended Actions

To troubleshoot and isolate this issue, you can try:

  • Disable Core Isolation on affected Windows 11 clients:
    • Open Windows Security.
    • Go to "Device Security" > "Core Isolation".
    • Turn off "Memory Integrity" (Core Isolation).
    • Reboot the system and test the VPN connection.

Additional Information

  • The issue is not universal to all Windows 11 clients; some connect successfully under identical network conditions.
  • The presence of endpoint security software (such as Trend Micro Apex One with EDR) or Windows security features (Core Isolation) can interfere with VPN tunnel setup by blocking required system changes (e.g., routing table modifications).
  • Disabling security features may not be possible on organization-managed devices; coordinate with your IT/security team for policy adjustments or exceptions.
  • Reverting to older APM client versions is not supported if the BIG-IP default client is newer.
