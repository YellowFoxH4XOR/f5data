Known Issue

The centralized management infrastructure (CMI) watch scripts experience a memory leak.

Note: The CMI is more commonly referred to as device service clustering (DSC) technology.

This issue occurs when the following condition is met:

  • You run any of the following CMI watch scripts for an extended period (several hours):
    • tmsh run /cm watch-devicegroup-device
    • tmsh run /cm watch-trafficgroup-device
    • tmsh run /cm watch-sys-device

Impact

The BIG-IP system uses more memory over time, which may eventually cause a decrease in performance or a system reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The amount of memory resources consumed by the affected watch script process increases over time.
  • The top command indicates virtual (VIRT) and resident (RES) memory usage for the affected watch* process increases over time, similar to the following output example:

    top |grep -i watch

    PID   USER  PR  NI  VIRT  RES  SHR S %CPU %MEM   TIME+   COMMAND
    25037 root  20   0  118m  86m  41m S  1.9  0.5   0:05.35 watch_devicegro           
    ...
    25037 root  20   0  137m 105m  41m S  1.0  0.7   0:20.40 watch_devicegro   
    ...
    25037 root  20   0  153m 121m  41m S  1.0  0.8   0:35.55 watch_devicegro

    Note: In this output example, over a 30 minute period you can see the increased virtual (VIRT) and resident (RES) memory utilization for the watch_devicegroup_device process.

  • Various system processes experience restarts due to memory exhaustion.

Resolution

Status

F5 Product Development has assigned ID 385825 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you should use the affected scripts only when required and not allow them to run indefinitely. You should limit running the affected scripts to less than an hour at a time.

Impact of workaround: The suggested workaround should not have a negative impact on your system.
