Description

You may find BIG-IP willl drop SIP packet under the following condition:

  • You create a vrtual sever for SIP application, and attach UDP profile.
  • The SIP packet in a same flow and from same client ip and source port.
  • When SIP packet has high rate, the BIG-IP will drop the SIP packet.

Environment

  • SIP profile
  • UDP profile
  • High rate SIP packet

Cause

By default UDP profile not has packet buffer. If the rate of receiving traffic is high, incoming UDP packets will dropped.

Recommended Actions

You can enable Max Buffer Packets or Datagram LB option on the associated UDP profile.

Default UDP profiles have a queue limitation. all SIP messages over the same flow will be queued in a single queue, and if the queue is full, the subsequent SIP messages will be dropped. When Datagram LB option is enabled, every UDP datagram will be processed as a single flow then avoids the queue limit.
