Description

Users may experience the Big-IP Web Interface (GUI) will not fully load properly when navigating to various pages.

When this occurs, you may notice logs similar to the following in /var/log/restjavad:

[com.f5.rest.workers.asm.AsmConfigWorker] nanoTime:[1423345992591370] threadId:[23]  Exception:[org.apache.thrift.transport.TTransportException: java.net.SocketTimeoutException: Read timed out

You may also see logs similar to these in /var/log/asm:

crit perl[19403]: 01310027:2: ASM subsystem error (send_sync.pl,): $VAR1 = bless( {
crit perl[21123]: 01310027:2: ASM subsystem error (update_scanner_site_map.pl,): $VAR1 = bless( {
 

Environment

  • Big-IP ASM
  • Big-IP Web Interface (GUI)

Cause

Big-IP ASM is provisioned and the AsmConfigWorker thread is throwing a 'read timed out' exception

Recommended Actions

1. To resolve the GUI issues, restart the ASM service by running the following command on the Big-IP:

  # bigstart restart asm

2. In addition, to prevent potential GUI issues in the future, you may also want to increase the 'provisionmb' value for tomcat and restjavad with the following       commands:

- increase provision.tomcat.extramb to 100mb

# tmsh modify /sys db provision.tomcat.extramb value 100

- change restjavad.useextramb to true

# tmsh modify /sys db restjavad.useextramb value true

- save the config

# tmsh save /sys config

- restart tomcat & restjavad

# bigstart restart tomcat
# bigstart restart restjavad
