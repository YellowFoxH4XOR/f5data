Description

Users upgrading to MacOS 26 (Tahoe) are unable to connect to VPN using BIG-IP APM Edge Client

Environment

  • Product: BIG-IP APM
  • SSL VPN connection 
  • Client OS: MacOS 26 (Tahoe)
  • Component: APM Edge Client

Cause

BIG-IP APM Edge Client requires version 7.2.6 or later for compatibility with MacOS 26 (Tahoe).
Earlier versions do not support this OS and will fail to establish VPN connections.
https://techdocs.f5.com/kb/en-us/products/big-ip_apm/manuals/product/desktop-clientcompatmatrix.html will be updated soon.

F5 is tracking this issue as ID 2064457 MacOS EdgeClient fails to establish VPN on Tahoe Intel Macbooks 
https://cdn.f5.com/product/bugtracker/ID2064457.html will be updated.

Using Browser initiated VPN connections (with F5 VPN.app and optional Endpoint Inspector.app) helper apps is confirmed as working.

The new 'F5 Access for MacOS' version 7.2.6 is also confirmed as working but requires significant changes to the Access Policy to adopt.

Recommended Actions

  1. Upgrade BIG-IP APM Edge Client to version 7.2.6 or newer for proper functionality on MacOS 26 (Tahoe).
  2. Follow official upgrade instructions in K23159056: Upgrade the BIG-IP Edge Client.
  3. Download the required APM Clients 7.2.6 Build 6950.0 .iso from:
    APM Clients 7.2.6 Download

  4. If issues persist after upgrading, please complete the following steps and provide the collected data to F5 Support for further analysis:

    • Enable APM policy debugging (K45423041)

    • Record the session ID for the user (K52163551)

    • Generate a fresh QKView with full logs (K12878)

    • Gather F5 VPN client logs (K819308)
