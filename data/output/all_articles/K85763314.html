Description

Some settings in the web acceleration profiles appear to be different from the system default configuration.  This may be identified in iHealth or when importing the configuration to BIG-IQ that the default profile has been modified.

For example:

tmsh list ltm profile web-acceleration /Common/optimized-acceleration
ltm profile web-acceleration optimized-acceleration {
    app-service none
    cache-object-max-size 50000  <---------------!! Not the system default value
    cache-object-min-size 0
    cache-size 100mb
    defaults-from webacceleration
}

Environment

  • AAM is provisioned
  • Web Acceleration Profile
  • Default values not as expected

Cause

Some settings in the Web Acceleration Profiles may contain different values if AAM is provisioned.  These settings will revert back to the system default when AAM is unprovisioned.

Recommended Actions

This should not impact the normal operation of your BIG-IP, however this may be an inconvenience if you are to resolve BIG-IQ conflicts each time when importing multiple BIG-IP devices with AAM provisioned.  If the AAM module is no longer used, you should consider deprovisioning AAM on BIG-IP prior to importing its configuration to BIG-IQ.
