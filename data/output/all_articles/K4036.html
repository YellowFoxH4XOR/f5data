K4036: Overview of the ''sysctl net.inet.tcp.do_rfc1323'' system control variable

Topic

When the sysctl net.inet.tcp.do_rfc1323 system control variable is enabled, BIG-IP will use the TCP enhancements described in RFC1323. This setting is enabled by default.

RFC1323 improvements include window scaling, round trip time measurement, TCP timestamps, and protection against wrapped sequence numbers. These RFC1323 improvements are used only for SSL proxies and administrative traffic. Other BIG-IP traffic processing features are not affected by these improvements.

Disabling the sysctl net.inet.tcp.do_rfc1323 system control variable is unlikely to change the way SSL proxies or administrative VLANs handle traffic. Disabling the sysctl net.inet.tcp.do_rfc1323 system control variable will simplify tcpdump output by removing the addition TCP options information from the output.
