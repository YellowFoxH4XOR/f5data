Known Issue

A virtual server session may be reset when using the Priority Group Activation feature.

This issue occurs when all of the following conditions are met:

  • You have configured the Priority Group Activation pool setting and set the Minimum Available Members value to 1.
  • You have pool members configured with a connection limit, and the connection limit has been reached.
  • Pool members with the same or higher priority have no more capacity, but capacity exists in lower priority groups.
  • The pool member becomes unavailable, and then immediately becomes available again.

Impact

The system might reset the pool member's connection.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You encounter connection resets.
  • You encounter the following error in /var/log/ltm:

    No members available for pool <pool_name>

Workaround

To work around this issue, you can increase the Minimum Active Members value to 2 or more. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility as an administrative user.
  2. Click Local Traffic, click Pools, and then select the pool you want to modify.
  3. Click the Members tab.
  4. Under Priority Group Activation, change the Minimum Available Members value to 2, or more.
  5. To save the changes, click Update.
