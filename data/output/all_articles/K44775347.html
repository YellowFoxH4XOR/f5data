Description

1.When we try to check the HDD raid information from the device CLI issuing "tmsh show sys raid" command, the device HDD raid is not detected as shown below,

[root@bigip2:Active:In Sync]# show sys raid

-------------------------------------------------------------
Sys::Raid::Bay
Bay  Shelf  Name  Serial Number    Array Member  Array Status
-------------------------------------------------------------

1    -      -     -                -             -
2    1      HD1   WD-cc-bb-dd-ee-ff yes           ok

--------------------------------------------------------------------------------------
Sys::Raid::Disk
Name  Serial Number    Array   Array Status  Model
                       Member
---------------------------------------------------------------------
HD1   WD-cc-bb-dd-ee-ff  yes     ok            ATA     WDC WD1000CHTZ-0


2. After re-seating HDD on bay1, the status is still the same.

3. Also, On Configuration Utility, the Disk Management section shows nothing.

4. The LED status info :

  • Before replacement/re-seat HDD: bay 1 'STAT' LED is green but no LED on 'ACT'
  • After replacement HDD: bay 1 'STAT' LED is green but no LED on 'ACT'
  • Bay 2 'stat' is green and green on 'ACT'

5. Tried to run the EUD test for the appliance and it got failed.

Environment

  • BIGIP 10000 series platform
  • HDD Raid
  • LED Status

Cause
Issue is due to a hardware issue on the appliance.

Recommended Actions

Please proceed to replace the appliance.
