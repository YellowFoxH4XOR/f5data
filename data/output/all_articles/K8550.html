Known Issue

This is the result of a known issue. The Agent Start/Stop setting specifies that the BIG-IP system sends a trap whenever the SNMP agent starts running or stops running. When you disable the Agent Start/Stop setting, and then reboot the system or restart the alertd process, all SNMP traps will be disabled on the BIG-IP system.

F5 Product Development tracked this issue as CR96138 and it was fixed in version 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

This issue still exists in the BIG-IP version 9.3 and 9.4 software branches.

Workaround

You can work around this issue by enabling the Agent Start/Stop setting, and restarting the alertd process. To do so, perform the following two procedures:

Enabling the Agent Start/Stop setting

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click SNMP.
  4. From the Traps menu, select Configuration.
  5. Select the Agent Start/Stop check box.
  6. Click Update.

Restarting the alertd process

To restart the alertd process, type the following command from the command line:

bigstart restart alertd
