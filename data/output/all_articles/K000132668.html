Error Message

Feb 2 10:30:00 BIG-IP-F5-1.F5.local err httpd[24191]: [ssl:error] [pid 24191] (111)Connection refused: [client 192.168.1.254:55989] AH01974: could not connect to OCSP responder 'ocsp.apmjb5.local'

Feb 2 10:30:00 BIG-IP-F5-1.F5.local err httpd[24191]: [ssl:error] [pid 24191] [client 192.168.1.254:55989] AH02039: Certificate Verification: Error (50): application verification failure

Feb 2 10:30:00 BIG-IP-F5-1.F5.local err httpd[24191]: [ssl:error] [pid 24191] [client 192.168.1.254:55989] AH02261: Re-negotiation handshake failed, referer: https://192.168.102.208/tmui/Control/jspmap/tmui/locallb/virtual_server/list.jsp?Filter=*

Message Location

You may encounter this message in the following location:

  • The /var/log/secure file

 

Environment

BIG-IP Cert-LDAP remote auth configured for remote authentication

 

Cause

What happens, is that every time the client renegotiates an SSL session, it will query the OCSP Server, to validate the Client Certificate.

If it does not get a response from the OCSP Server, then it will prompt again for the Client Certificate.

When this happens, it indicates that the OCSP URL (in this case ocsp.apmjb5.local) is configured with multiple IP Addresses, and 1 or more of these IP Addresses is not responding. This can be either due to Firewall rules blocking the OCSP Requests, or one of the OCSP Servers simply not responding.

 

Recommended Actions

Find out all of the possible IP Addresses for the OCSP URL, and then do a tcpdump with these IP Addresses
 

C:\Users\Admin>nslookup

Default Server: AD1.APMJB5.LOCAL

Address: 10.0.0.231

> OCSP.APMJB5.LOCAL

Server: AD1.APMJB5.LOCAL

Address: 10.0.0.231

Name:   OCSP.APMJB5.LOCAL

Addresses: 10.0.0.220

          10.0.0.225

 

This returns 2 IP Addresses 10.0.0.220 and 10.0.0.225

 

# tcpdump -nvi 0.0nnn -s0 -w /shared/tmp/ocsp_001.pcap "(host 10.0.0.220 or host 10.0.0.225) and port 80"

 

If nslookup only returns 1 IP Address, but you suspect there are more than 1, you need to contact DNS Administrator to get a full list of the IP Addresses it resolves to.
