K000130318: Unexpected logs received on vCMP with message: vcpu0 ignored rdmsr: 0x1c9

Type
Support Solution
Published
2023-01-23
Updated
2023-01-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.2
Source
https://my.f5.com/manage/s/article/K000130318

Description

  • You can see unexpected number of below logs appearing in console and in /var/log/kern.log file:

[685143.617259] kvm [24641]: vcpu0 ignored rdmsr: 0x3f6
[685143.622748] kvm [24641]: vcpu0 ignored wrmsr: 0x3f6 data 11
[685143.628989] kvm [24641]: vcpu0 ignored rdmsr: 0x3f6
[685144.206946] kvm [24641]: vcpu1 ignored rdmsr: 0x34
[685219.588041] kvm [24641]: vcpu0 ignored rdmsr: 0x1c9
[685219.593523] kvm [24641]: vcpu0 ignored wrmsr: 0x1c9 data 3
[685219.599679] kvm [24641]: vcpu0 ignored rdmsr: 0x1c9

Environment

  • vCMP is licensed and provisioned
  • One or more vCMP guests are deployed

Cause

Behavior is related and documented under BUG ID 761649.

 Recommended Actions

Those error messages can be safely ignored. 
 

Additional Information

Appearing logs condition is due to vCMP Guest being deployed.

There is no workaround for this behavior, hovewer those logs are not referring to any existing/appearing problems on system, they can be safely ignored.
If you notice potential available disk space problem on /var/log, you may need to check this and remove or archive large files revealed by the following shell command:

ls -alS /var/log/kern.log*
