Description

The BIG-IP iControl REST APIs enable users to retrieve various security events, including locally logged security events, brute force attack attempts, and bot defence incidents. These APIs provide a streamlined approach for monitoring and analysing security-related activities within the BIG-IP system.

Environment

  • BIG-IP ASM
  • iControl REST APIs

Cause

None.

Recommended Actions

1.Security Event logs:

curl -sku 'admin:admin' -X GET "https://localhost/mgmt/tm/asm/events/requests" | jq .

2.Event correlation

curl -sku 'admin:admin' -X GET "https://localhost/mgmt/tm/asm/events/incidents" | jq .

3.Brute Force Application

curl -sku 'admin:admin' -X GET "https://localhost/mgmt/tm/asm/events/brute-force-attacks" | jq .

4.Bot Defense Events

curl -sku 'admin:admin' -X GET "https://localhost/mgmt/tm/asm/events/bot-incidents" | jq .

curl -sku 'admin:admin' -X GET "https://localhost/mgmt/tm/asm/events/bot-defense-events" | jq .

Notes:

  • The API endpoints provided are for guidance purposes only. Please make sure you test them before implementing them in a production environment.
  • You can modify the commands to filter the output according to your requirements. Ensure that you update the commands based on your environment by replacing:
    • admin:admin with your actual credentials
    • localhost with the IP address of the BIG-IP device
  • Additionally, we are using "jq ." to format the output in pretty JSON for better readability.
