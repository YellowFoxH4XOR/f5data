The combinations of platforms and versions of BIG-IP software that currently meet the Network Firewall requirements set by ICSA Labs are listed in the following table. If your combination of software version and platform are not listed, they have not yet been certified by ICSA Labs as a Network Firewall.

In order to meet the requirements set by ICSA, several enhancements have been made to the BIG-IP software. These enhancements include the following:

 Enhancement Description
Non-session packet loggingThe following database keys control logging of non-session packets:

icsa.forceadminpacketlogging
tmm.lognonsessionpackets
ISO 4-digit date format in log messagesDate formats in syslog are controlled via TMSH, using the iso-date option for the syslog command, in the sys module.
Handling of ICMP replay packetsThe following database key controls how BIG-IP handles ICMP replay packets:

TM.ICSAICMPReplay
Strict handling of TCP flags and RST packetsThe following database key controls how the BIG-IP handles invalid TCP flags and RST packets:

TM.ICSAStrictTcpForwarding

For detailed information about each of the above new enhancements, as well as details about configuring existing features to meet ICSA Certification requirements, refer to the BIG-IP Systems Network Firewall Guide for ICSA Certification.

F5 has tracked the enhancements made to the BIG-IP product in order to meet ICSA Network Firewall certification as ID363833.
