Description

In /var/log/ltm we see lots of logs like:
 
Error polling for AOM events

Functionality like relicensing is limited and can fail. 
"show sys hardware"  displays N/A or blank fields:  
show sys hardware

  Model       N/A
  Parameters  --                   --
              Firmware Revision    N/A
              Location             2
              Manufacturer         N/A
              Revision             N/A
              Serial number        N/A

Environment

  • BIG-IP appliance 
  • AOM

Cause

An internal reporting system is damaged. Possible hardware issue. System can't get the hardware details. 

Recommended Actions

Open support case  to investigate hardware issue:

  • K2633: Instructions for submitting a support case to F5 

Additional Information

None.
