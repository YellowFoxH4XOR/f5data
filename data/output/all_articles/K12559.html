Topic

FirePass Intranet webtops redirect users to a desired website upon successful authentication based on the Master Group assignment. The website can be public facing, such as www.f5.com, or internal facing, such as intranet.company.com. Intranet webtops are processed through the FirePass reverse proxy engine.

Configuring an Intranet webtop

  1. Log on to the FirePass Administrative Console.
  2. Navigate to Portal Access : Web Applications : Intranet Webtops.
  3. In the URL: field, enter the full URL for the website you want your users to land on.

    For example:

    https://intranet.company.com/welcome.html
  4. Check the Enabled box.
  5. Click the Update button.

Allowing access to the URL

  1. Navigate to Portal Access : Web Applications : Master Groups Settings.
  2. Change the Master Group drop-down menu to the master group you want to have access to the Intranet webtop.
  3. In the Allow list field under the Access Control Lists section, enter the URL that you configured in the Configuring an Intranet webtop procedure.

    Note: This step is not necessary if the Default action drop-down menu is set to Allow, rather than the default setting of Deny. If Allow is selected, ensure that the URL is not in the Deny list field.
  4. Click the Update button.
  5. Repeat this procedure for each master group that needs access to the Intranet webtop.
