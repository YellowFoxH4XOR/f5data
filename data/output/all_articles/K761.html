Known Issue

This is the result of a known issue. SNMP traps are stored in the Nokia NetAct alarm table until an administrator clears them. Because a number of benign conditions can trigger SNMP traps, this table can grow extremely large with SNMP traps which do not require administrator intervention.

This issue occurs only on BIG-IP and 3-DNS systems that have Nokia NetAct SNMP traps enabled. To save disk space, clear the alarm table occasionally.

F5 Networks Product Development tracked this issue as CR33815 and CR41877.
