Description

 

After changing the "apm.apd.connlwm" and "apm.apd.connhwm" db variables, the next outputs/logs are shown in the /var/log/daemon: 
 

 <date> Emergency <device name> logger[PID] Re-starting apmd
 

 

Environment

  • BIG-IP APM
  • TMSH/Bash
  • APMD daemon

 

Cause

Unknown at the time of publication 

 

 Recommended Actions

Restore the APM DB variables to their default values.

 

1 - Login TMSH:

 

    (config) # tmsh

 

2 - Restore values:

 

   # modify sys db apm.apd.connhwm value 1536

   # modify sys db apm.apd.connlwm value 1520

 

Meaning of:

 

  •  connlwm: connections low water mark
  •  connhwm: connections high water mark

 

3 - Stop and start the APMD service (manual restart):

 

     3.1. Change to bash mode:

 

    (tmos) # bash

 

     3.2. Use the following command syntax to stop and start the APMD service:

     

       # bigstart stop apmd

       # bigstart start apmd
