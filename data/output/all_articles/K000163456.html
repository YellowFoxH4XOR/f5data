K000163456: F5OS: Provide Bash and ConfD CLI Access to Remote Users and LDAP Groups

Type
Support Solution
Published
2026-09-29
Updated
2026-09-30
Source

Description

By default, only the root local account has Bash access. In F5OS-A, remote-authenticated users can obtain Bash access by assigning the superuser role as a secondary role and enabling superuser-bash-access.

The superuser role also lets the user run ConfD CLI commands from Bash using the f5sh utility.

Environment

  • F5OS
  • LDAP or Active Directory remote authentication

 

Cause

By default, only the root user is allowed Bash access K000147139.

 

Answer/Recommended Actions

F50S-A 1.8.0 introduced a new secondary role, superuser. The superuser is a new secondary role that allows existing users with access to ConfD to also get Bash access.

 

Prerequisites

Before enabling Bash access:

  1. Configure remote authentication and confirm that the F5OS-A system can authenticate the user.
  2. Assign the user an appropriate primary role, such as admin or resource-admin.
  3. Assign the superuser role as a secondary role.
  4. Ensure appliance mode is disabled. F5OS-A documentation states that appliance mode must be disabled for a superuser to obtain Bash access.
  5. Enable the superuser-bash-access setting.
  6. Ensure the user group is assigned to the admin and superuser roles on the LDAP/Active Directory server.

Configuration

Assign an LDAP group to the superuser role:

  1. config
  2. system aaa authentication roles role superuser config remote-gid 9004
  3. system aaa authentication roles role superuser config ldap-group CN=f5os_superusers
  4. commit

 

Enabled bash access for the superuser role:

  1. config
  2. system aaa authentication config superuser-bash-access true
  3. commit

Users assigned to the admin and superuser groups will log in to the bash prompt by default. To access Confd, type f5sh, and type exit to return to bash.
