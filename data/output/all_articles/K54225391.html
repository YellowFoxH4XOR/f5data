K54225391: ASM ICAP compatibility with McAfee Web Gateway

Type
Support Solution
Published
2020-06-05
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K54225391

Description

  • ASM ICAP does not work with McAfee Web Gateway
  • ASM does not block even though a virusfound response comes back from McAfee Web Gateway

Environment

  • ASM provisioned
  • ICAP configured within ASM
  • ASM + ICAP
  • Attempted workaround listed in ID695394

Cause

McAfee Web Gateway does not contain any response headers indicating a virus was found, ASM can only review headers as defined in the ASM system variables to determine if a virus was found and take action.

Recommended Actions

Customer should follow McAfee's guide here to include valid headers in the ICAP response message. Reference K70941643 below for additional details on ASM requirements.
