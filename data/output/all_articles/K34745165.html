Topic

You should consider using these procedures when you want to do one or more of the following:

  • Import a software image into the BIG-IP system
  • View a list of software images to see which is currently active
  • Install a software image, point release, or hotfix
  • Delete an imported software image
  • Boot the system to a different software image

Description

You can do one or both of the following:

  • Follow the written steps in the Procedures section, which include instructions for using the command line to complete each task.
  • Watch the following videos for a brief demonstration of each task using the Configuration utility.
    •  Booting the BIG-IP system to a different software image.
    •  Installing a software image on the BIG-IP system.
    •  Viewing software images installed on your BIG-IP system.
    •  Deleting a software image from the BIG-IP system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to the Configuration utility.
  • You have access to the BIG-IP Advanced Shell (bash) and tmsh.

Procedures

  • Importing a new software image to the BIG-IP system
  • Viewing the currently imported software images
  • Installing a software image, point release, or hotfix
  • Deleting imported software images
  • Booting the system to a different software image

Importing a new software image to the BIG-IP system

You must first import software images, point releases, and hotfixes to the BIG-IP system before you can install them on a boot location. Prior to installing any new software, you should also perform an MD5 integrity check.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Using the Configuration utility

  1. Locate the software image, point release, or hotfix and browse to the F5 Downloads site.
  2. Download the software (.iso) to your desktop computer.
  3. Download the corresponding image verification file(s)  to your desktop computer.
    • MD5 checksum file (.md5)
    • Signature (SIG) file (.sig)
    • Privacy enhanced mail (PEM) file (.pem)
  4. Log in to the Configuration utility.
  5. Go to System > Software Management.
  6. Select Import.
  7. SelectChoose File and choose the software image, point release, or hotfix, and the corresponding MD5 file to import.
  8. Select Import.
  9. Log in to bash.
  10. Change directories to the /shared/images directory by typing the following command:

    cd /shared/images

  11. Verify the software image file integrity using either the MD5 checksum, SIG, or PEM files.
    • For information about verifying the software image using the MD5 checksum, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.
    • For information about verifying the software image using the SIG or PEM files, refer to K24341140: Verifying BIG-IP software images using SIG and PEM files.

Using SCP from the command line

  1. Locate the software image, point release, or hotfix and browse to the F5 Downloads site.
  2. Download the software (.iso) and accompanying MD5 checksum file (.md5) to your desktop computer.
  3. Secure copy (SCP) the .iso file and corresponding .md5 file from your desktop computer to the /shared/images directory on the BIG-IP system.
  4. Log in to bash.
  5. Change directories to the /shared/images directory by typing the following command:

    cd /shared/images

  6. Verify the software image file integrity using either the MD5 checksum, SIG, or PEM files.
    • For information about verifying the software image using the MD5 checksum, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.
    • For information about verifying the software image using the SIG or PEM files, refer to K24341140: Verifying BIG-IP software images using SIG and PEM files.

Viewing the currently imported and installed software images

You can view the software images that you imported into the BIG-IP system, which are available for installation.

You can also view the currently installed software images using the Configuration utility or the TMOS Shell (tmsh).

For example, the tmsh show /sys software status command lists the currently installed software images and the associated volumes. When listing the installed software using the tmsh show /sys software status command, volumes are first sorted alphabetically and then numerically:

--------------------------------------------------------------------
Sys::Software Status
Volume Product Version Build Active Status Allowed Version
--------------------------------------------------------------------
HD1.1 BIG-IP 17.5.1 0.0.7 no complete yes
HD1.2 BIG-IP 17.5.1.3 0.0.19 yes complete yes

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Software Management.
  3. Available Images lists the imported software images and point releases. Installed images are listed in Installed Images. To view the list of imported software hotfixes, select the Hotfix List tab.

Using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the complete list of imported software images or hotfixes, use the following syntax:

    list /sys software <image | hotfix>

    For example, to view the list of imported software images that are available for installation, type the following command:

    list /sys software image

Installing a software image, point release, or hotfix

After the software image, point release, or hotfix is imported, you can install it on a boot location. When installing to a new boot location, the new boot location is created when performing the software installation.

Note: You can install a software image over an existing software image, provided the boot location is not active.

Before you upgrade, consider reviewing the following recommendations to prepare:

  • BIG-IP upgrade guide | Chapter 2: Choosing a BIG-IP upgrade version
  • BIG-IP upgrade guide | Chapter 3: Preparing to upgrade the BIG-IP system
  • See if there is a chapter in the BIG-IP upgrade guide dedicated to your platform, which may contain additional recommendations.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Software Management for software images and point releases, or System > Software Management > Hotfix List for hotfixes.
  3. For Available Images, select the check box next to the software you want to install.
  4. Select Install.
  5. In the Install Software Image pop-up window, for Volume set name, select a volume set or type the name of the new volume set.  For example, if you type 2 for the volume set name, the BIG-IP system creates a new volume set at boot location HD1.2.
  6. Select Install.
  7. You can monitor the installation status in the Installed Images section of the System > Software Management page or the System > Software Management > Hotfix List page.

Using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To install a software image, point release, or software hotfix, use the following command syntax:

    install /sys software <hotfix | image> <software>.iso volume <volume_number>

    For example, to install BIG-IP 17.5.1.3 to new volume HD1.2, type the following command:

    install /sys software image BIGIP-17.5.1.3-0.0.19.iso volume HD1.2 create-volume

    Note: You can use tab completion in tmsh. To see the available images for installation, press the Tab key after you type the install sys software image command.

  3. To verify the software installation progress, type the following command:

    show sys software 

    The command output appears similar to the following example:

Deleting imported software images

You delete imported software images, point releases, and hotfixes that are no longer used in order to free up disk space for future software installations.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: Deleting an imported software image does not delete any boot location volumes that the image has been installed to. For information about deleting a boot location volume that an image has already been installed to, refer to K33265170: Deleting a boot location volume to free up disk space. 

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Software Management for software image and point releases, or System > Software Management > Hotfix List for hotfixes.
  3. For Available Images, select the check box next to the software that you want to delete.
  4. Select Delete.
  5. Select Delete on the confirmation page to delete the software image.

Using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To delete a previously imported software image, point release, or hotfix, use the following command syntax:

    delete /sys software <image | hotfix> <image.iso>

    For example, to delete the BIGIP-17.1.3-0.0.11.iso software image, type the following command:

    delete /sys software image BIGIP-17.1.3-0.0.11.iso

Booting the system to a different software image

The BIG-IP system allows you to install software images on separate boot locations, also called volumes. You can then boot the BIG-IP system to a specific volume and begin processing traffic using the software version installed on that volume.

Impact of procedure: Performing the following procedure impacts traffic processing and involves rebooting the system. F5 recommends that you perform this procedure during a scheduled maintenance period.

Using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > Software Management > Boot Locations.
  3. In the Boot Location column, select the name of the target boot location, for example, HD1.3.
  4. Optional: To install the currently running configuration to the target volume, set the Install Configuration setting to Yes and select the source configuration in the Source Volume setting.
  5. Select Activate to immediately restart the system into the selected volume.

Using tmsh

Note: When using tmsh to boot to a different volume, you are unable to install the local configuration on to the target volume you are booting to.  To install a configuration on the target volume, you can first copy the desired configuration to the target volume using the cpcfg command. For information about using the cpcfg command to copy a configuration from one boot location to another boot location, refer to K14724: Using the cpcfg command to copy a configuration from one boot location to another. Alternatively, you can use the Configuration utility. 

  1. Log in to tmsh by typing the following command:

    tmsh

    1. To list the current software images, type the following command:

      list /sys software volume

  2. To boot the BIG-IP system to a particular volume, or software image, use the following command syntax:

    reboot volume <volume_name>

    For example, to boot the BIG-IP system to volume HD1.3, type the following command:

    reboot volume HD1.3
