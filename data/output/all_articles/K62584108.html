Description

What command can be used to replace RESOLV::lookup in iRule

Environment

  • LTM
  • iRule
  • Software version 15.1.x and above

Cause

None

Recommended Actions

RESOLV::lookup command has been deprecated with the release of version 15.1 in favor of the RESOLVER and DNSMSG namespaces.

RESOLVER::name_lookup attempts to send a DNS request using a specified net resolver, a domain name, and any of A, AAAA, TXT, MX, PTR, SRV, and NAPTR query types. A DNS request is sent, and response will returned in the form of an opaque dns_message structure. This structure can be used by RESOLVER::summarize and the DNSMSG iRule commands to extract the specific data in a user friendly format.

Additional Information

RESOLV::lookup command is still supported in software version 15.x and 16.x. but it is advised to move to new alternatives.
