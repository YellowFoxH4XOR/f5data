Description

  • Users getting redirect to Logout page when connecting to Virtual Server for PeopleSoft
  • Message on PeopleSoft server:
    WARNING psft.pt8.util.PSHttpUtil detectCSRF Suspected session affinity issue because a POST request arrived with an invalid ICSID

Environment

  • BIG-IP with LTM provisioned
  • Virtual Server created from iApp or manually with caching enabled

Cause

Client app cannot handle caching on Virtual Server and changes session ID as a result. The session can no longer be match with the server session and the server redirects user to logon page.

Recommended Actions

Disable caching manually on Virtual Server or in the iApp.

Additional Information

None
