Description

When you undeploy a policy created via the AdvWAF Guided Configuration Utility the policy it is not deleted from the Security  ››  Application Security : Security Policies : Policies List and is still fully functional.

Environment

  • AdvWAF Policy
  • Web Application Protection, API Security Protection, DOS Protection, Bot Protection

Cause

When a policy is created and has been added to a virtual server, as part of the virtual servers configuration, it cannot be deleted. At that point it can then be deleted.

Recommended Actions

This is by design. If you have undeployed it and need to delete the policy it will have to be removed from any and all virtual servers it has been applied to.
