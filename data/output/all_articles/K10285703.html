Description

When viewing Characters under Security  ››  Application Security : Headers : Character Set
every character above HEX 0x80 (in th GUI) is displayed as: ï¿½

 

Environment

  • ASM GUI 

Cause

ASCII is by definition a 7-bit character code, with encodings from 0 to 127 (0x7F). Anything outside that range is not ASCII.

There are a number of 8-bit and wider character codes based on ASCII.

Windows-1252 or CP-1252 (code page 1252) is a single-byte character encoding of the Latin alphabet, used by default in the legacy components of Microsoft Windows for English and many European languages including Spanish, French, and German.

So it depends on what application language settings is configured in Security  ››  Application Security : Security Policies : Policies List  ››

If it is UTF-8 then symbols above 0x7F will not be displayed.

If the 'Application Language'  changed to  'Central European (windows-1250)' then all those characters are visible.
'Application Language' is configured in the General Settings of each individual Policy.

 

Recommended Actions

None.

Additional Information

For more information about character encodings, you may want to refer to W3C article Character encodings: Essential concepts.
