Topic

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP system to rotate records when returning resource record sets (RRset) from the DNS cache.

Description

When you configure a DNS cache, the BIG-IP system is able to more quickly respond to repeated DNS queries. The DNS cache responds to requests by returning the RRset; all valid resource records for the domain.

By default, the BIG-IP system returns the RRset records from the DNS cache in the same order they were received from the upstream server. For example, when the RRset contains multiple records of the same type, the BIG-IP system returns the records from the cache in the same order they were received from the server. In some cases, this behavior may lead to uneven load distribution for the destination resource.

Starting in BIG-IP DNS 12.1.0, you can configure the BIG-IP system to rotate records when returning the RRset record from the DNS cache. When you configure RRset Rotate for the DNS cache, the system rotates record types in which the records are similar, including records in the ANSWER SECTION and the ADDITIONAL SECTION in the RRset. Configuring the DNS cache to rotate the records in the RRset response can alleviate load issues on the destination resource. The BIG-IP system uses the query ID in conjunction with the number or records in the RRset to determine which record to display first. The records are then rotated in a round robin manner for subsequent responses from the cache.

Note: RRset rotation may operate differently for BIG-IP platforms that support the hardware-accelerated cache, such as the B2250 VIPRION blade. When the client sends a query to the BIG-IP system, the system inserts the RRset response into the hardware cache before sending the response to the client. Subsequent RRset responses that are served from the hardware cache are not rotated until the system flushes the hardware cache, which occurs every second, and the hardware cache is repopulated with the next rotated RRset response.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility or TMOS Shell (tmsh).

Procedures

  • Creating the DNS cache
  • Creating the DNS profile and associating the DNS cache
  • Applying the DNS profile to the listener

Creating the DNS cache

To enable RRset rotation, you can edit an existing DNS cache, or create a new cache. To create a new DNS cache in which RRset rotation is enabled, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Caches > Cache List.
  3. Click Create.
  4. Enter a name for the DNS cache.
  5. Select the appropriate option for how you want the BIG-IP system to resolve DNS queries from the Resolver Type menu.
  6. Select query ID from the RRset Rotate menu.
  7. Complete the remaining entries.
  8. Click Finished.

Creating the DNS profile and associating the DNS cache

To create the DNS profile and associate the DNS cache, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Delivery > Profiles > DNS.
  3. Click Create.
  4. Enter a name for the DNS profile.
  5. Set DNS Cache to Enabled.
  6. Select the DNS cache that you created in the previous procedure from the DNS Cache Name menu.
  7. Complete the remaining entries.
  8. Click Finished.

Applying the DNS profile to the listener

To apply the DNS profile with associated DNS cache to a listener object, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Delivery > Listeners > Listener List.
  3. Click Create.
  4. Enter a name for the listener.
  5. Enter the IP address for the listener.
  6. Select the profile name that you created in the previous procedure from the DNS profile menu.
  7. Complete the remaining entries.
  8. Click Finished.
