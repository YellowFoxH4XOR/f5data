Known Issue

The BIG-IP Edge Client for macOS applies DNS server order incorrectly.

This issue occurs when the following condition is met:

  • You configure the network access connection with both primary and secondary DNS servers.

Impact

The secondary DNS server resolves queries over the primary DNS server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The secondary DNS server resolves queries while the primary DNS server is available.
