Description

This article describes the software lifecycle and support policy for F5 API Security Local Edition, including release support expectations, End of Software Development (EoSD), security update coverage, and End of Technical Support (EoTS).

F5 API Security Local Edition is a self-hosted F5 API security product designed for deployment in customer-controlled environments. You should run the latest available version in production to receive the latest capabilities, security updates, and critical patches.

Release and versioning model

API Security Local Edition uses a three-segment versioning model in the major.release.fix format.

  • major: represents the major product line. The current product line is version 1 and is expected to remain 1 unless a future major product-line change is introduced.
  • release: represents the planned product release number. F5 increments this value for each new planned product release.
  • fix: represents a fix or stabilization build within the same product release. F5 typically plans a .1 build for each release. If the initial build does not pass confidence checks or release validation, F5 may produce additional fix builds until a stable customer-supported release is approved.

For example, version 1.2.6 represents major product line 1, product release 2, and fix or stabilization build 6.

This model is similar in structure to semantic versioning, but for API Security Local Edition the second segment is the planned product release number, and the third segment is the fix or stabilization build number.

Software development and support policy

Each F5 API Security Local Edition release reaches EoSD on the release date of the next product release. EoSD means that no additional features or routine bug fixes are applied to that version.

F5 applies critical bug patches and security updates to the two most recent releases of F5 API Security Local Edition.

F5 strongly recommends running the latest version of F5 API Security Local Edition in production to ensure access to the latest features, security updates, and critical patches.

Licensing

F5 API Security Local Edition uses subscription-based licensing aligned with analyzed API traffic. License activation is performed offline through the user interface using a JWT issued by F5 and a signed subscription status file generated by the product.

Additional recommendations

You should plan regular upgrades to stay on a currently supported release and maintain access to security updates, critical bug patches, and product improvements. Production deployments should use the latest available F5 API Security Local Edition version unless directed otherwise by F5 Support.
