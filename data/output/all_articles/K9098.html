Topic

You can set the time zone on the BIG-IP system by using either the Configuration utility or the command line. To do so, perform one of the following two procedures:

  • Use the Configuration utility to set the time zone on the BIG-IP system 
  • Use the command line to set the time zone on the BIG-IP system 

Note: Daylight Saving Time (DST) details vary by region and occasionally change. F5 will no longer create hotfixes to patch time zone changes.

Use the Configuration utility to set the time zone on the BIG-IP system

To watch a video demo of this procedure, go to Set the Time Zone for the BIG-IP system using the Configuration utility.

  1. Log in to the Configuration utility.
  2. Go to System > Platform.
  3. For Time Zone, select the time zone you want to use.
  4. Select Update.

Use the command line to set the time zone on the BIG-IP system

  1. Log in to the BIG-IP command line.
  2. View the available time zone files by entering the following command:

    ls -laR /usr/share/zoneinfo

  3. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  4. Set the time zone using the following command syntax:

    modify /sys ntp timezone <region_dir/timezone_filename or timezone_filename>

    For example, to set the time zone to the United States Eastern time zone, enter the following command:

    modify /sys ntp timezone US/Eastern

    For example, to set the time zone to UTC, enter the following command:

    modify /sys ntp timezone UTC

  5. Save the configuration changes by entering the following command:

    save /sys config

  6. To view the currently configured time zone, enter the following command:

    list /sys ntp timezone

    The command output appears similar to the following example:

    sys ntp {
        timezone US/Eastern
    }

  7. To view the current date and time exit tmsh by typing q and enter the following command from bash:

    date
