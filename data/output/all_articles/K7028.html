K7028: Deleting a virtual server with an HTTP class profile causes TMM to stop tracking virtual server statistics

Known Issue
Published

Known Issue

This is the result of a known issue. If a virtual server with an HTTP class profile is deleted, the Traffic Management Microkernel (TMM) stops tracking virtual server statistics. Traffic flow is not interrupted. However, the statistics information in the Configuration utility and at the command line will report 0 (zero) for all virtual server traffic statistics.

F5 Product Development tracked this issue as CR69041 and CR68753, and it was fixed in BIG-IP ASM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

A reboot or restart of TMM is required for TMM to correctly track virtual statistics if the above situation is encountered.

To reboot the BIG-IP ASM, type the following command from the command line:

reboot

To restart the TMM process, type the following command from the command line:

bigstart restart tmm
