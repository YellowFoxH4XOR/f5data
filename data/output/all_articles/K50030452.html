Issue

Error Message

Error Message: 01010004:3: Memory allocation failed: <tmm memory object>

In this error message, note the following:

  • <tmm memory object> is the Traffic Management Microkernel (TMM) memory subsystem object.

For example, the following message relates to the ssl_session memory subsystem object:

01010004:3: Memory allocation failed: ssl_session

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP subsystem experiences heavy traffic processing or leaks memory.
  • A TMM memory subsystem object has reached maximum memory capacity.

Impact

BIG-IP system performance degrades over time and the BIG-IP system may eventually stop responding due to complete memory exhaustion.

Recommended Actions

Viewing TMM memory allocation

You can view the memory allocated to each of the TMM memory subsystem objects. To do so, use one of the following methods:

  • In the TMOS Shell (tmsh), use the show sys memory command.
  • In the Configuration utility, navigate to Statistics > Module Statistics > Memory.

For more information about BIG-IP system memory, refer to K16419: Overview of BIG-IP memory usage.

Responding to TMM memory allocation errors

When the BIG-IP system experiences TMM memory allocation errors, you should generate a qkview file and contact F5 Technical Support for troubleshooting assistance. To do, refer to the following articles:

  • K12878: Generating diagnostic data using the qkview utility
  • K2633: Instructions for submitting a support case to F5
