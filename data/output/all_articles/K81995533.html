Description

Unable to add DOS profile to protected objects such as the Virtual Servers.

Configuration Error seen in /var/log/audit and the /var/log/ltm logs:

Configuration error: DOS profile (/Common/<name_of_dos_profile>) with behavioral detection cannot be attached to (/Common/<name_of_virtual_server>) because the feature is limited to use on Virtual Servers. Please disable behavioral detection on one of the following virtual servers *snipped for brevity* or obtain special license to change the limit.
 

Environment

  • Adding dos profile to more than 20 virtual servers
  • Behavioral DoS (BaDOS) enabled on the DOS profile


Cause

By default there is a limit set to how many virtual servers a DOS Profile with L7 Behavioral DoS (BaDOS) enabled.

This value is 20.
 

Recommended Actions

The limit can be modified by increasing the db key adm.max.vs value using the following steps.

Impact of Procedure: There should not be negative impact on the product system.
  1. To check the current setting of db key adm.max.vs, run command:

    tmsh list sys db adm.max.vs

    output will show the default value '20'.
     
  2. Increase the value to 30 using the command:

    tmsh modify sys db adm.max.vs value 30
     
  3. Save the configuration using the command:

    tmsh save sys config
 

Additional Information

The default is set to 20 virtual servers as a safety net; the following are two reasons:

  1. It is unknown which platform is being used where this feature is turned on; it can be low end or high end appliance
  2. BaDOS uses a lot resources when applied to several ( especially busy ) virtual servers
