K23427463: Disable Netbios in Edge Client

Published
2021-05-12
Updated

Applies to

Description

You are looking to disable Netbios in Edge Client. For example, under the below conditions:

  • You are trying to get faster DNS results and avoid NETBIOS lookups. 
  • InfoSec sees it as a security risk to have NETBIOS enabled. 
     

Environment

  • BIG-IP
  • Edge Client
  • Netbios

Cause

N/A

Recommended Actions

  1. Supported starting in APM Clients build 7211.2021.408.620-5368.0
    In order to update please refer to the following article:
    K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system
  2. To disable NetBIOS, add the following entries to the Variable Assign agent in your policy:

    Custom variable:
    config.connectivity_resource_network_access./<Partition Name>/<NA_RESOURCE_NAME>.client.IPv6LAN
    <network access resource name> is the name of the network access resource.

    For example:
    config.connectivity_resource_network_access./Common/Generic_Network_Access.client.IPv6LAN

    Custom expression:
    "return {</IPv6LAN><enableNetBios0>0</enableNetBios0><IPv6LAN>}"

    Note: Though the stanza used for the custom Variable Assign specifically state IPv6LAN, NetBIOS for IPv4 will also be disabled/enabled. 

Additional Information

To enable NetBIOS, add the following entries to the Variable Assign agent in your policy:

Custom variable:
config.connectivity_resource_network_access./<Partition Name>/<NA_RESOURCE_NAME>.client.IPv6LAN
<network access resource name> is the name of the network access resource.

Custom expression:
"return {</IPv6LAN><enableNetBios0>1</enableNetBios0><IPv6LAN>}
