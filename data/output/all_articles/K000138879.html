K000138879: security-auditlog-* indexes remains on BIG-IQ

Type
Support Solution
Published
2024-03-11
Updated
2025-01-07
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0
Source
https://my.f5.com/manage/s/article/K000138879

Description

You notice that security-auditlog-* indexes have remained since the installation of BIG-IQ after navigating to System > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Cluster > SUMMARY > Indexes.

 

Environment

  • You are using BIG-IQ.

Cause

Those auditlog indexes contain the information to track access to the Elasticsearch cluster. Those are useful for compliance purposes or in the aftermath of a security breach. BIG-IQ doesn't have retention support on this to delete the old information.

 

Recommended Actions

If you want to delete security-auditlog-* indexes created in 2023, you can delete those by using the below query on any device in the BIG-IQ cluster (CM or DCD).

 

curl -s -u admin:admin -X DELETE --insecure https://localhost:9200/security-auditlog-2023.*

 

You can add month as below to delete indexes related to that month.

 

curl -s -u admin:admin -X DELETE --insecure https://localhost:9200/security-auditlog-2023.11.*
