Known Issue

When the Device Name setting is changed, the BIG-IP APM apd and apmd processes will core and restart.

Note: The device name is defined in Device Management > Devices > Device list, and can be different from the hostname.

The apd and apmd processes create configuration snapshots when they start. The configuration snapshots use a hash of the device name to create a self device ID. In the case of a device name change, the apd and apmd processes will restart automatically to re-initialize with the new device name.

Impact

New connections will not be accepted during the daemon restart which normally lasts two to five seconds.

Symptoms

  • The apd and apmd process core files exist in the /var/core file
