Known Issue

When you log in to the Configuration utility, it may return a blank page or one of the following errors:

  • Error 5 -- Reference to a null pointer.
  • Error 331776 -- Unspecified error.

This is the result of a known issue. BIG-IP's LDAP tool allows you to create user names that are over 15 characters in length; however, a number of BIG-IP internal elements do not support user names longer than 15 characters. As a result, many functions of BIG-IP may fail if you attempt to log in to the Configuration utility with a user name that contains more than 15 characters.

F5 Networks Product Development tracked this issue as CR25874 and CR41798.
