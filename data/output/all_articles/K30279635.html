Description

Swap usage is creeping up on BIG-IP system.

Environment

  • Memory

Cause

Swap usage in itself is normal and expected. The Linux kernel sometimes prefers to swap idle processes memory to disk so that more physical memory is available for more active processes, buffers, and caches.

Further investigation is needed to determine if high swap usage is due to a low memory condition.

Recommended Actions

Review the output of cat /proc/meminfo to determine the current memory available. If MemAvailable is less than 300000 kB, memory is quite low and you should consider taking steps to make more memory available to the Linux host. This may include provisioning management to large, unprovisioning modules, or making use of the provision.extramb database variable.

Additional Information

When reviewing memory graphs, you may notice swap usage goes up over time. If Other usage goes down, this is likely to be idle processes swapped to disk and not cause for concern.
