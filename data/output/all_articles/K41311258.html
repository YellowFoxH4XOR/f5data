Known Issue

Creating a user configuration set (UCS) archive file may fail.

This issue occurs when all of the following conditions are met:

  • The configuration contains a file name with the dollar sign character ( $ ).
  • You attempt to create a UCS archive file using the Traffic Management Shell (tmsh) or the Configuration utility.

Impact

You are unable to create a UCS archive file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your attempt to create a UCS archive file fails with an Unexpected Error: UCS saving process failed error message.

    For example, if you attempt to create a UCS archive on a system with an SSL certificate named te$t.crt, the action will fail with an error message that appears similar to the following example:

    Saving active configuration...
    md5sum: /var/tmp/filestore_temp/files_d/Common_d/certificate_d/:Common:te\$t.crt_174140_1: No such file or directory
    Fatal: executing: md5sum /var/tmp/filestore_temp/files_d/Common_d/certificate_d/:Common:te\$t.crt_174140_1
    Operation aborted.
    /var/tmp/configsync.spec: Error creating package

    WARNING:There are error(s) during saving.
            Not everything was saved.
            Be very careful when using this saved file!

    Error creating package
    Error during config save.
    Unexpected Error: UCS saving process failed    .

Workaround

To work around this issue, you can rename affected configuration files and ensure they do not use the dollar sign character.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
