Known Issue

Changes do not take effect when made to fallback persistence profiles attached to a virtual server.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP system with a virtual server configured with persistence and a fallback persistence profile.
  • You make changes to the fallback persistence profile.

Impact

Changes to the fallback persistence profile do not take effect with new connections until you make a change to the virtual server or you restart the Traffic Management Microkernel (TMM).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Changes do not take effect when made to fallback persistence profiles attached to a virtual server.

Workaround

To work around this issue, you can make a small change to any virtual server on which you've configured the changed fallback persistence profile. For instance, you can update the Description of the virtual server.
