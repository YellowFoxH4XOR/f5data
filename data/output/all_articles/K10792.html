Known Issue

This is the result of a known issue. When a client directs the net time command to an ARX virtual server IP address, the ARX response will set the date one day ahead of the ARX system's date.

F5 Product Development tracked this issue as ARX ID 36659 and it was fixed in ARX versions 4.1.3 and 5.1.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue is fixed in a hotfix available for ARX versions 4.1.1 and 5.0.6. Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and the associated ARX ID number, to request the hotfix.

Workaround

Clients should use NTP to ensure the date and time are set correctly.
