Known Issue

This is the result of a known issue. The following error occurs when a wide IP pool is configured with no virtual server.

ERROR: Cannot connect to any of the following selfIP(s) for a server

This is a cosmetic issue and does not affect the iQuery key synchronization.

F5 Networks Product Development tracked this issue as CR27799 and CR41830.
