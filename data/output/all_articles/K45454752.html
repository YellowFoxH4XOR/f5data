Known Issue

When you use the iRule DNS::questions and the owner name of the resource record is root, the system returns an empty string.

This issue occurs when all of the following conditions are met:

  • You have configured an iRule with the DNS::questions command to query resource record information.
  • The owner of the queried resource record is root *.*.

Impact

The system returns an empty string.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use a DNS::question name iRule to get the owner name of the question resource record, and the owner name is root, the system returns an empty string.
