Known Issue

This is the result of a known issue. The bigpipe software command allows a user to delete the active volume location on a BIG-IP system.

For example, the following bigpipe command output indicates that HD1.2 is the active volume on the system:

SOFTWARE - Volumes:
+-> SOFTWARE VOLUME HD1.1 Size: default inactive
+-> SOFTWARE VOLUME HD1.2 Size: default active

If you use the following bigpipe software command, the system deletes the HD1.2 image location, even though HD1.2 is the active volume on the system:

bigpipe software desired HD1.2 delete

When you delete the active volume, the system does not allow you to further modify any attributes of the volume. For example, if you attempt to add the volume location back using the bigpipe software desired HD1.2 add command, the system reports that it failed to create the volumeset. If you then reboot the system, it reboots to another slot.

F5 Product Development is tracking this issue as ID 291352.

Workaround

If you inadvertently deleted the active volume on the system, you must reboot to another volume and use the following command syntax to recreate the volume:

bigpipe software desired <volume > add

For example, to add the HD1.2 volume set, you would enter the following command:

bigpipe software desired HD1.2 add
