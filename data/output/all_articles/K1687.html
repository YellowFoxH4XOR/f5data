Known Issue

This is most likely the result of a known issue. When you disable an object, such as a pool or a datacenter, the 3-DNS Configuration utility prompts you to enter a value that equates to the amount of time to disable the object. Neither the Configuration utility nor the 3dpipe command restrict the value you enter. The maximum allowable Unix date is equal to a value of 2147483647. If you specify a value higher than 2147483647, 3-DNS interprets the number as a date in the past.

F5 Networks Product Development tracked this issue as CR28901 and CR41903.
