Description

This article shows how to increase the HDD storage for a CE deployed in VMware.

Environment

  • Customer Edge
  • VMware

Cause

HDD storage needs to be increased for any reason.

Recommended Actions

Increase VM HDD Size in VMware and reboot the CE.

Additional Information

A debug file can be generated to review the HDD Size. The file that contains this information is system_df.
