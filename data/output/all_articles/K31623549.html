Known Issue

The IP reputation daemon does not support Transport Layer Security (TLS) 1.2.

This issue occurs when the following condition is met:

  • You configure and use the IP reputation daemon.

Impact

Some administrators may have concern about using the IP reputation daemon because the system uses it to accept or deny connections to critical business applications. Also, some configurations may require that all transactions that exfiltrate a PCI-controlled environment use secure protocols and ciphers, and the IP reputation daemon does not meet that requirement.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The IP reputation daemon opens Secure Sockets Layer (SSL) connections to the Webroot BrightCloud server using the TLS 1.0 protocol.
