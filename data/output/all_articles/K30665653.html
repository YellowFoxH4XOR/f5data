Known Issue

You can configure a unicast IP address in a failover multicast configuration.

This issue occurs when the following condition is met:

  • You specify a unicast IP address in the Failover Multicast Configuration setting for network failover in high availability (HA) configurations.

Impact

The failover multicast configuration does not work.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The failover multicast configuration does not work when you configure it with a unicast IP address. Although this is an invalid configuration, the system does not prevent it.
