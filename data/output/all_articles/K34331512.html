Description

The /var partition had only 19% free space left. In the partition there is a file called mgmt_acld.out that keeps on growing. 

  • The mgmt_acld process maintains statistics, logging, and reporting of Management Port rules.

Environment

  • BIG-IP 
  • /var/log/mgmt_acld.out file keeps on growing

Cause

By default the mgmt_acld log level is informational, and it will grow rapidly if there is high amount of activity

Recommended Actions

The actions to reduce the log noise level is the following:

tmsh modify sys db log.mgmt_acld.level value "log level"

Example:
tmsh modify sys db log.mgmt_acld.level value Warning

Additional Information

Default setting are the following:

[log.mgmt_acld.level]
default=Informational
type=enum
realm=common
enum=|Emergency|Alert|Critical|Error|Warning|Notice|Informational|Debug|
scf_config=false
display_name=log.mgmt_acld.level


sys db log.mgmt_acld.level {
    default-value "Informational"
    scf-config "false"
    value "Informational"
    value-range "Alert Critical Debug Emergency Error Informational Notice Warning"
}
