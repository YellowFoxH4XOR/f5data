Description

From BIG-IP version 14, 'OPTIONS' and 'TRACE' methods are allowed by default in GUI.

Environment

  • With BIG-IP version 14.x or above

Cause

None

Recommended Actions

To disable these HTTP methods, please follow following guide:
Run this command in tmsh:

(tmos)# edit sys httpd

Then a editer will open (vi or nano), then modify it by adding 'include' line like this:

modify httpd {
    auth-pam-idle-timeout 120000
    redirect-http-to-https enabled
    include "
<Location />
RewriteEngine On
RewriteCond %{REQUEST_METHOD} ^(TRACE|TRACK|PUT|OPTIONS|DELETE|HEAD)
RewriteRule .*$ - [F,L]
</Location>
"
}

Then save the configuration .
