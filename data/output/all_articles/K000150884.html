Description

Uploading/downloading from backend pool members through VIP is slow.


Environment

  • BIG-IP
  • VIP handling uploads and downloads to backend pool members
  • Profile attached to VIP: tcp_timeout_1h


Cause

The f5-tcp-progressive has auto buffers enabled, which increases the buffer sizes automatically to facilitate high speed transfer; whereas the previous tcp_timeout_1h profile has fixed small buffer sizes that limited transfer speed.


Recommended Actions

Switch to Performance layer 4 VIP to streamline if no traffic inspection is needed to minimize F5 impact on the traffic. If inspection is needed, then apply f5-tcp-progressive or something with similar auto buffers enabled.
