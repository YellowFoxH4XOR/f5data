K000092629: hard-coded limit of backup task

Type
Support Solution
Published
2022-11-30
Updated
2022-11-30
Source
https://my.f5.com/manage/s/article/K000092629

Description

Once a backup is started there is a backup task job started. There is a task queue which is limited to 100 tasks so if at any point of time 100+ backups are running their 101st backup will fail.


Environment

- BIGIQ


Cause

- This is by design


Recommended Actions

- None


Additional Information

There is not a limit of backup schedules itself.
