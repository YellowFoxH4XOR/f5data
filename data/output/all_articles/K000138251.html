K000138251: [ERP] Request information about monitor interval

Type
Support Solution
Published
2024-01-16
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP Link Controller
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000138251

Description

BIG-IP GTM device is initiating gtm monitor packet to server object inconsistent interval.

Monitor to server is set every x seconds, but taking tcpdump on each device, they are sending monitor packet in consistently, and not every x seconds.

 

Environment

  • BIG-IP GTM/LC/DNS
  • any version
  • GTM monitor to server object
 

Cause

  • By design gtm monitor will be initiated by one of BIG-IP in the group, and result is shared among the group members.
     

Recommended Actions

Check "will prove" in /var/log/gtm log in all the BIG-IP GTM/DNS/LC device.
One of the BIG-IP DNS must be proving the monitor.

Also, check the tcpdump as a group it is sending monitor traffic in configured interval.
