Description

  • What is the difference between the shared, system and default namespaces?
  • What logs are associated with each namespace?

Environment

  • F5® Distributed Cloud Console

Resolution/Answer

Shared:

  • Contains shared config objects in Shared Configurations service that are available to all other services.

System:

  • Contains config objects for: Multi-Cloud Network Connect, DNS Management, Client-Side Defense, NGINX One, Routed DDoS ,  Authentication Intelligence, Application Traffic Insight, App Infrastructure Protection, Managed Service Provider, Support Operations, Audit Logs & Alerts, Billing, Administration

Default:

  • Contains config objects for: Web App & API Protection, Multi-Cloud App Connect, Distributed Apps, Bot Defense, Content Delivery Network, Observability, Account Protection
