Description

When the BIG-IP is either a Service Provider SP or Identity Provider IdP and receives SAML data that exceeds 128K, the connection will be reset.

Environment

  • BIG-IP APM
  • SAML - BIG-IP as SP or IdP

Cause

This is due to the following Bug:
Bug ID 746993: HTTPParser buffer has a limit of 128K which resets client connection if SAML responses with POST data larger then 128K.

Recommended Actions

None

Additional Information

You will see logs that resembile the following:
