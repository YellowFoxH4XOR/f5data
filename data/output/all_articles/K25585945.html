Known Issue

A Local Traffic policy with a Disable LTM policy action may cause the Traffic Managmement Microkernel (TMM) to SIGABRT and produce a core file.

This issue occurs when all of the following conditions are met:

  • You have a virtual server configured to use a Local Traffic policy.
  • The Local Traffic policy contains a rule with two or more policy actions.
  • One of the rule's policy actions is a Disable LTM policy action.
  • The Disable LTM policy action is not configured as the last policy action.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process produces a core file with a SIGABRT message.
  • A BIG-IP system in an HA configuration fails over to the peer system.
  • The BIG-IP system generates a TMM core file in the /var/core directory.
  • The system logs daemon heartbeat action error messages to the /var/log/ltm file that appear similar to the following example:

    notice sod[PID]: 01140029:4: HA daemon_heartbeat tmm fails action is go offline down links and restart.

  • The BIG-IP system logs an error message to the /var/log/tmm file that appears similar to the following example:

    notice ** SIGABRT **

Workaround

To work around this issue, you can ensure that any Local Traffic policy rules with a Disable LTM policy action are configured with the Disable LTM policy action as the last action in the list of actions. To do so, perform the following procedure:

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Policies > Policy List.
  3. From the Published Policies section, select the affected policy by clicking the policy name.
  4. Create a draft copy of the policy by clicking Create Draft.

    You will be returned to the Policy List page.

  5. From the Draft Policies section, select the newly created draft policy by clicking the policy name.
  6. Click the name of the rule with the affected Disable LTM policy action configuration.
  7. Click + (plus) on the last configured action.

    The system adds a new action field to the end of the list.

  8. Configure the desired Disable LTM policy action settings.
  9. Click - (minus) for the original Disable LTM policy action.
  10. Click Save.
  11. Click Save Draft.
  12. From the Draft Policies section, select the check box next to the newly saved draft policy.
  13. Click Publish.
