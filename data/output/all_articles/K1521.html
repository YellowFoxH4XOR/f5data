K1521: Configuring BIG-IP to use SNAT on SSL proxy connections when the SSL proxy is configured to use a target server

Topic

A SNAT is, by design, applied only to traffic passing through a virtual server. To apply SNAT to connections from the SSL proxy to an external server, you must perform the following tasks:

  1. Create a pool that contains, as its only member, the address of the external server.
  2. Create a loopback virtual server that uses the newly created pool.

    Note: The target virtual server cannot be forwarding and it cannot have the same virtual address as a node in the pool.

  3. Change the proxy configuration to use the newly created virtual server as the destination (instead of the external server).
  4. Change the destination target for the proxy to Local Virtual Server.

Refer to BIG-IP Reference Guide for specific instructions about how to create pools and virtual servers and how to modify SSL proxy configuration.
