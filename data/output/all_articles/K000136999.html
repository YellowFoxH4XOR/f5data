K000136999: Unable to create custom HTTP Analytics Profile using BIG-IQ. Parent profile is missing from drop down menu.

Support Solution
Published
2023-09-26
Updated

  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000136999

Description

The parent HTTP Analytics Profile appears to be missing from the drop down menu when trying to create a custom HTTP Analytics Profile using the BIG-IQ GUI.

 

Querying BIG-IQ REST API for any HTTP Analytics Profile returns an empty result:

 

restcurl -u admin: mgmt/cm/adc-core/working-config/ltm/profile/analytics-http
{
 "items": [],
 "generation": 1,
 "kind": "cm:adc-core:working-config:ltm:profile:analytics-http:adcprofileanalyticshttpcollectionstate",
 "lastUpdateMicros": 1694988305020620,
 "selfLink": "https://localhost/mgmt/cm/adc-core/working-config/ltm/profile/analytics-http"
}

 

 

 

Environment

  • BIG-IQ
  • HTTP Analytics Profile
  • BIG-IP AVR

Cause

AVR is not provisioned on managed BIG-IP devices.

 

Recommended Actions

 

1. Ensure that AVR is provisioned on the managed BIG-IP devices then re-discover/import the device.

 

2. From the BIG-IQ, ensure that statistics collection is enabled on the device.

 

3. Create the HTTP analytics profile according to the customer's needs and thereafter attach the profile to a virtual server which the customer wants the analytics to collect data from. Deploy the config and verify that the analytics profile has been attached to the virtual server.

 

4. Run HTTP traffic through the virtual server. Analytics data should then be visible from the monitoring dashboards after a couple of minutes.

 

Additional Information
