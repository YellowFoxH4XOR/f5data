Known Issue

This is the result of a known issue. The BIG-IP ASM bd process utilizes 100 percent of the CPU on small amounts of traffic. This behavior is due to a polling mechanism that does not immediately release the CPU after it has finished processing an event.

F5 Product Development tracked this issue as CR98979 and it was fixed in version 9.4.5 for the BIG-IP 9.4 software branch. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in hotfix BIGIP-9.4.4-94.0-HF3, issued for BIG-IP version 9.4.4. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
