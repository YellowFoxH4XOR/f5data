Description

Access session report missing path selected during policy evaluation.

  • When running access session report under Access  ››  Overview : Access Reports - You do not see the path selected during the policy evaluation.

Environment

  • Access Policy Manager
  • Session Report
  • Policy variables

Cause

what do I write here?

Recommended Actions

Toggle Policy Trace option to enable under System  ››  Logs : Configuration : Options : Access Policy Logging

Under CLI, below db variable can be modified to enable this option:

sys db tmm.access.policytrace {
    default-value "disable"
    scf-config "true"
    value "enable"
    value-range "disable enable"
}

You should see the policy trace printed in the access reports and access logs under /var/log/apm

Jan 1 09:32:20 BIGIP1 notice apmd[13829]: 014902b8:5: /Common/test_access_profile:Common:ef77df6d:  | Start (fallback) | Client OS (Windows Edge Client) | Machine Cert Auth (Found) | Check Machine Hostname (fallback) | LDAP Query (fallback) | Group Selection (fallback) | Advanced Resource Assign for test users (fallback) | Allow |  Ending is: Allow
