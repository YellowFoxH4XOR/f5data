Known Issue

TMM may produce a core file and restart when processing Network Access sessions.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a Network Access profile.
  • Your BIG-IP APM device is running multiple instances of the Traffic Management Microkernel (TMM) daemon.
  • There are active Network Access sessions connected to the BIG-IP APM system.

    This issue occurs when the BIG-IP APM system erroneously attempts to reconnect the traffic from a previous active Network Access tunnel to a TMM instance.

Impact

The system may disconnect Network Access sessions.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Network Access sessions are sporadically disconnected.
  • TMM writes a core file to /share/core correlating with the Network Access disconnect times.
  • In the /var/log/apm file, you may observe log messages similar to the following example:

    tmm2 notice tmm2[9179]: 01490505:5: 1e793ffe: PPP tunnel 0x556ac5689000 started.
    tmm notice tmm[9177]: 01490505:5: fff154a4: PPP tunnel 0x555c8d730a00 closed.
    tmm notice tmm[9177]: 01490505:5: 98979fec: PPP tunnel 0x555c8a67c900 closed.
