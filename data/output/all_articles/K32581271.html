Known Issue

Kerberos authentication may fail if the HTTP 401 RESPONSE agent is not configured at the beginning of the policy.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured for Kerberos authentication, and the HTTP 401 RESPONSE agent is not configured at the beginning of the policy.
  • The client (browser) attempts to re-authenticate with an authorization token.

Impact

Users are requested to manually re-authenticate to access content that requires Kerberos authentication.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Kerberos authentication fails, and the system, again, presents the user with login windows.
  • Users are unable to access content that requires Kerberos authentication.
