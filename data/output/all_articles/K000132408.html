K000132408: Unable to see the Round Robin load balancing method while creating a new pool

Type
Support Solution
Published
2023-02-05
Updated
2025-07-31
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000132408

Description

Unable to see the Round Robin load balancing method while creating a new pool via Configuration Utility.

But when tried to create a pool from CLI it shows the Round Robin load balancing method.

Environment

  • BIG-IP LTM 13.X and higher
  • ASM provisioned
  • GUI
  • CLI

Cause

ASM evaluation add-on license got expired.

Recommended Actions

There are 2 options: 

A) Reactivate the license with a valid ASM add-on key and the issue should auto-resolve.
Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration during license reactivation.
 

B) Remove Expired ASM Add-on License and Re-activate it.

  1. Login to your Big-IP by CLI.
  2. Run the command tmsh show /sys license detail
  3. Locate a line similar to this: timelimited_module [Advanced Web Application Firewall, r5XXX|XYZXYZX-ASDASDFI|20250509|20250509]
  4. In this case, XYZXYZX-ASDASDF is the add-on.
  5. Go to the BIG-IP license management section (System  ››  License ).
  6. Click on "Re-activate".
  7. Locate the expired ASM add-on license (XYZXYZX-ASDASDF). 
  8. Delete the entry for the expired add-on key.
  9. After removing the expired add-on, re-activate your base BIG-IP license.
  10. This will update system licensing and restore access to all standard load balancing methods.

Additional Information

If you face any issues after re-provisioning the ASM license then please contact F5 global support for further support.
