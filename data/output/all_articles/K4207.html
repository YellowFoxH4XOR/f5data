The version of mod_include used in BIG-IP and 3-DNS versions prior to 4.5.12 and 4.6.3 is vulnerable, but it is not enabled by default and is not enabled by using any BIG-IP or 3-DNS features. To enable mod_include, you must modify the httpd.conf file and then install HTML pages that use mod_include.

F5 Product Development tracked this issue as CR42429 and CR42430 and it was fixed in BIG-IP 4.5.12 and 4.6.3.
