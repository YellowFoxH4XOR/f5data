Topic

Dashboard utility alerts that are generated by the system_check utility are not cleared when the event that triggered the alert is resolved or has changed. For example, dual power supplies where one power supply is not connected will display in the Dashboard utility; however, when the power supply has been connected and the system reports the power supply as operational, the alert is not cleared from the Dashboard utility.

Note: You can safely ignore this issue; it will not affect the use of the Dashboard utility.

You can clear alerts from the Dashboard utility by restarting the logstatd process. To do so, perform the following procedure:

Impact of procedure: Restarting the logstatd process affects the logging of alerts to the Dashboard utility momentarily, but does not affect traffic processing on the BIG-IP system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the logstatd process, type the following command:

    restart /sys service logstatd

Note: If the BIG-IP system is a VIPRION platform with more than one blade, you can restart the logstatd process from the command line by typing the following command:

clsh bigstart restart logstatd
