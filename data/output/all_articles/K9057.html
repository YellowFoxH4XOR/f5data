When you configure network failover, the redundant BIG-IP systems use the network to determine the status of the peer unit. When BIG-IP redundant systems are configured to use network failover, the systems communicate over the configured failover addresses. The following table displays the transport protocol and service port used for BIG-IP network failover.

BIG-IP LTM versionProtocolService port
16.xUDP1026
15.xUDP1026
14.xUDP1026
13.xUDP1026
12.xUDP1026
11.xUDP1026
10.xUDP1026
9.6.xUDP1026
9.4.xUDP1026
9.3.xTCP1028
9.2.xSCTP1028
9.0.1 through 9.1.3TCP1028
9.0.0UDP1028

Note: Network failover does not function properly if the BIG-IP systems in a device group are configured to use different transport protocols or ports for network failover. For example, during a software upgrade if the device group members are temporarily running BIG-IP versions that use different transport protocols or ports for network failover, network failover does not function during this time.

Note: Even if the two versions use the same transport protocol and port, F5 does not support BIG-IP redundant pair configurations where each system is running a different software version, as this configuration can detrimentally affect the failover process. For more information, refer to K8665: BIG-IP redundant configuration hardware and software parity requirements.
