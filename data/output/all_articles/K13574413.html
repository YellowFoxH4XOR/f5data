Description

Unable to sync devices, Sync-failed status.

Environment

  • BIG-IP
  • Default profiles in BIG-IP

Cause

This happens when one or more default profile modification has been detected. The default profile types contain a recommended baseline from which an implementation starts. If you change the default profile values, the baseline settings may be difficult to recover.
 

Recommended Actions

  • Change default value of profile to original values as per recommendation. The default value of web acceleration is detailed in K14903.
  • Create a custom profile if the default value needed to be changed.
