Topic

When the BIG-IP system is deployed in an environment where it load-balances or forwards long-lived TCP connections, you must understand how the BIG-IP system manages long-lived TCP connections, and how you can fine-tune the TCP profile settings to optimize the TCP connection state.

Some server applications use TCP Keep-Alives to maintain long-lived TCP communication with a client, and to prevent the client from timing out or disconnecting for lack of response within a reasonable time frame. Due to the full-proxy design of the BIG-IP system, the BIG-IP system acknowledges TCP Keep-Alives from the server, but does not proxy the TCP Keep-Alive packet to the client side.

F5 recommends that you use custom TCP profiles to implement server-client TCP Keep-Alives. With the BIG-IP system, you can use separate TCP profiles for both client-side communication and server-side communication.

Configuring a custom client-side TCP profile

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol.
  3. Select TCP.
  4. Click Create.
  5. Type a name for the profile.

    For example:

    Custom_Client_TCP

  6. Select the check box next to Keep Alive Interval.
  7. Specify the amount of time, in seconds, that the BIG-IP system should send a TCP Keep-Alive packet to the client.

    Note: In most situations, F5 recommends that the value matches the server-side specified value.

    Note: You can select any other options you want to modify within the custom TCP profile.

  8. Click Finished.
  9. Apply the custom TCP profile to the virtual server that is handling the load balancing of the server application.

Note: If you do not specify a server-side TCP profile, the system, by default, uses the specified client-side profile.

Alternatively, you can configure separate client- and server-side TCP profiles using the steps in the Configuring a custom client-side TCP profile procedure for the server-side TCP profile. This allows an administrator to specify separate and independent TCP Keep-Alive intervals for client- and server-side communication.

If you specify the TCP Keep-Alive interval, the BIG-IP system can match the Keep-Alive interval of the servers. The BIG-IP system acknowledges the TCP Keep-Alives that the server sends, and the BIG-IP system issues TCP Keep-Alives at the intervals specified to the client; as a result, the BIG-IP system ensures that the client is still responding.
