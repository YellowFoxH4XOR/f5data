Description
TMM may generate core file due to software issue on Nitrox 5 compression after upgrade to v16.1.
You may observe below error from /var/log/tmm 

notice ** SIGFPE **

Furthermore prior the core file generated by tmm, you may observe below error from /var/log/ltm

Device error: n5-compress2 Zip engine ctx eviction (comp_code=4): ctx dropped.

Environment

  • BIGIP LTM
  • Nitrox 5

Cause
The exact root case is unknown at this time.
F5 document this known issue as ID1043009

Recommended Actions

  • If the issue occur after upgrade v16.1, recommend to boot back to previous software version and upgrade to other altenative software version.
  • If you would like to consider to test the Engineering Hotfix fix for ID1043009 at your testing environment then please contact F5 Support.
