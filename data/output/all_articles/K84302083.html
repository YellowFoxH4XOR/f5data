K84302083: 01420006:3: unexpected argument ''tmsh''

Type
Support Solution
Published
2022-09-28
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K84302083

Description

/var/log/ltm contains logs as below:

Sep  10 04:00 localhost err tmsh[19732]: 01420006:3: unexpected argument "tmsh"

Environment

  • BIG-IP
  • logs

Cause

Syntax error when running command with tmsh prefix in tmos shell as shown below:

root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)# tmsh
Syntax Error: unexpected argument "tmsh"
 

Recommended Actions

Do not specify tmsh prefix when running commands in (tmos) shell

Additional Information

  • To exit the (tmos) shell, enter one of the following commands:
    • q
    • run util bash
  • From the bash shell, you specify the tmsh prefix when running tmsh commands. For example,

    tmsh show sys version
