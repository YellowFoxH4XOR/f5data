Description

When renewing SSL/TLS certificates should I change the private key or retain the existing key?

Environment

  • SSL certificate
  • Private key
  • Certificate signing request (CSR)

Cause

None

Recommended Actions

When renewing SSL/TLS certificates from a Certificate Authority (CA), F5 recommends that you rekey the certificate. Rekeying the certificate involves generating a new CSR and private key during the renewal process. Although some CAs may allow you to renew SSL/TLS certificates by using the existing CSR on file, this method is less secure.

Additional Information

F5 recommends that you rekey your SSL certificates for the following reasons:

  • Gives an attacker less time to perform brute force attacks on the key.
  • Prevents attacks on a previously compromised private key; shorter validity periods reduce the amount of time that a compromised private key can be used for malicious purposes.
  • Provides an opportunity to increase the key size.
