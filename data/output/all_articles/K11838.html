Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K32641705: Determining the date, time, and software version of BIG-IP reboots (11.x - 13.x)

The BIG-IP system logs a reboot marker to the system log files following a reboot. If you are investigating a reboot issue, you can review the BIG-IP log files to determine the date, time, and frequency of reboots over the past eight days.

By default, the system keeps log files for eight days. For more information, refer to K7115: Managing log files on the BIG-IP (9.4.x - 10.x).

To determine the date, time, and frequency of BIG-IP reboots, you can use a command similar to the following:

zgrep boot_marker /var/log/ltm*

For example, the following command output indicates that the BIG-IP system has rebooted seven times over the past eight days:

/var/log/ltm:Jul 18 17:30:30 boot_marker: ---===[ HD1.1 - BIG-IP 10.0.0 Build 5401.0 ]===---
/var/log/ltm.1.gz:Jul 16 15:42:36 boot_marker: ---===[ HD1.2 - BIG-IP 10.0.0 Build 5401.0 ]===---
/var/log/ltm.1.gz:Jul 16 08:50:24 boot_marker: ---===[ HD1.2 - BIG-IP 10.0.0 Build 5401.0 ]===---
/var/log/ltm.1.gz:Jul 16 09:01:07 boot_marker: ---===[ HD1.1 - BIG-IP 10.0.0 Build 5401.0 ]===---
/var/log/ltm.5.gz:Jul 12 08:17:46 boot_marker: ---===[ HD1.1 - BIG-IP 10.1.0 Build 3341.0 ]===---
/var/log/ltm.5.gz:Jul 12 08:24:13 boot_marker: ---===[ HD1.1 - BIG-IP 10.1.0 Build 3341.0 ]===---
/var/log/ltm.5.gz:Jul 12 08:54:33 boot_marker: ---===[ HD1.1 - BIG-IP 10.1.0 Build 3341.0 ]===---

Note: If the system has rebooted multiple times over a number of days, you can use the wc command to determine the exact number of reboots. For example, the following command output indicates the system has rebooted 23 times over the past eight days:

# zgrep boot_ /var/log/ltm* |wc -l
     23
