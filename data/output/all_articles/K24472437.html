Description

JSON request with a very long base64 encoded value triggered violation for signature 200001067.
This Signature 200001067 is created to address possible XSS attack when attacker exploits old Netscape feature implemented with keyword "mocha".
It appears it allowed to perform a script associated with an IMG tag in HTML code.
Later it was replaced with "livescript" option.

Environment

  • ASM policy
  • with Attack signature 200001067 enabled
  • HTTP request with a very long request base64 parameter

Cause

This is triggered when uploading PSF file and likelihood of signature 200001067 is false positive.

Recommended Actions

Upgrade to version BIG-IP v13.1.1.5 or newest.

You can then disable the signature either:
  • In the URL /path/to/upload 
  • The parameter data by enabling the option Parse Parameters in the JSON profile

Additional Information

Alternate Workaround:  Disable the signature in the JSON profile to reduce the attack surface

Steps to disable a signature in a URL:

  1. Select the URL in Security  ››  Application Security : URLs : Allowed URLs : Allowed HTTP URLs
  2. Click Attack Signatures tab
  3. Click Click here to load Signatures List to load the attack signatures of that ASM policy
  4. Move the attack signature from right to left from box Global Security Policy Settings
  5. Set State to Disabled

Steps to disable a signature in a parameter:

  1. Select the parameter in Security  ››  Application Security : Parameters : Parameters List  ››  Parameter Properties
  2. Click Attack Signatures tab
  3. Move the attack signature from right to left from box Global Security Policy Settings
  4. Set State to Disabled
