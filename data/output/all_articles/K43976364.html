Description
No new FPS alerts on the BIG-IQ CM

Environment

  • BIG-IQ with DCDs and FPS services

Cause
DCDs are not passing traffic to CM, Cluster IDs do not match

Recommended Actions

  1. Remove both DCDs from CM. see K30423885: Removing one or more unreachable DCDs from the BIG-IQ system

  2. Run the following command on all DCDs to reset the REST databases.
    Note: ElasticSearch data is not affected, e.g. FPS alerts

    clear-rest-storage -es

  3. Access both DCDs GUI to go through the setup wizard for config initialisation.

  4. Add the DCDs to CM again,   this may require a reboot on the CM itself.

  5. Run the following command on CM:

    curl -XGET http://localhost:9200/_cluster/health?pretty

    Note: Run this command multiple times and you will see number of active_shards increasing and number of unassigned_shards decreasing. This is because ElasticSearch will restore all indices data from DCDs. Eventually the cluster status will turn to green from red. If it's not like this, then take qkviews of all BIG-IQ CM and DCDs.

  6. Activate FPS services on both DCDs
