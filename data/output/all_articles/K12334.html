K12334: Error Message: Security Exception! Access to AppTunnels Resource is not configured properly!

Issue

Application Tunnel users that attempt to connect to a backend server that has not been added to the users' Master Group access control list (ACL) may receive the following error message:

Security Exception! Access to AppTunnels Resource is not configured properly!

When the user attempts to establish a connection to the backend server, the FirePass device inspects the user's Master Group ACL. The FirePass device sees the traffic as violating security settings if the ACL does not include the backend server's IP address or the port on which the user is trying to initiate the session.

To resolve this issue, add the IP address and the port number to the Master Group's ACL.

Adding the IP address and port to the Master Group's Access Control List

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Application Access: App Tunnels: Master Group Settings.
  3. Select the user's Master Group from the Master Group drop-down menu.
  4. Under the Access Control List section, in the Allow List field, add the IP addresses and ports to which the user needs access.

    Note: For troubleshooting purposes, you can allow all IP addresses and ports by using the *:1-65535 syntax. However, F5 does not recommend that you allow all IP addresses and ports unless you are troubleshooting an issue.
  5. Click the Update button.
