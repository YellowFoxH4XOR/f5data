Known Issue

Due to a known issue, you may be unable to add a remote host to an F5 trust domain.

This issue occurs when all of the following conditions are met:

  • You are adding the device to a trust domain using the Configuration utility
  • The administrator password of the host you are adding contains non-alphanumeric characters, such as +, =, or !

Impact

You will be unable to add the host to the trust domain.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to add a trusted peer, the system will display the following error message at the top of the Configuration utility screen:

    Invalid Credentials

Workaround

To work around this issue, you can change the password of your remote host to not include non-alphanumeric characters, or you can add the host to the trust domain using the Traffic Management Shell (tmsh) interface. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not  have a negative impact on your system.

Adding a host to the trust domain using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. At the tmsh prompt, type the following command:

    modify cm trust-domain Root ca-devices add {xxx.xxx.xxx.xxx} name <host> username <user> password <password>

    In this command, note the following:

    • {xxx.xxx.xxx.xxx} is the IP address of the remote host you are going to add
    • <host> is the name of the remote host
    • <user> is the remote administrator user
    • <password> is the remote administrator

    For example:

    modify cm trust-domain Root ca-devices add {192.168.1.2} name F5-router-standby username admin password foo+bar

  3. Save the change by typing the following command:

    save /sys config
