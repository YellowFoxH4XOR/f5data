Description

When polling the BIG-IP system via SNMP, responses take a long time, which exceeds the timeout for the monitoring system.

Environment

  • SNMP polling

Cause

SNMP Client Allow List explicitly includes localhost, rather than default value of 127.0.0.0/8. snmpd then attempts to resolve localhost.localdomain via DNS, which fails and eventually times out.

Recommended Actions

  1. Remove localhost from SNMP Client Allow List
  2. Add 127.0.0.0/8 to SNMP Client Allow List

Note: SNMP slowness can be caused by various issues, for example high MCPD CPU utilization, or intensive polling patterns. If necessary open a case with F5 Support for further investigation.

Additional Information

When this issue is occurring, a packet trace on eth0 will show that the system is repeatedly attempting to resolve localhost.localdomain, similar to the following example:
