Note: This Solution does not apply to BIG-IP 9.4.2 and later. Beginning in BIG-IP 9.4.2, the client's certificate and key no longer need to be combined into a single file. Instead, you can use the Configuration utility to explicitly specify both the certificate and key. To do so, select the appropriate certificate and key in the Client Certificate and Client Key drop-down menus.

The HTTPS health monitor has a Client Certificate configuration option, which allows you to use an SSL client certificate for authentication purposes.

Client certificates are certificates that allow a client to identify itself to a server using SSL. The certificates are typically created by an administrator or network security administrator and are provided to a client to allow access to the resources on the server. In order to use client certificates with the HTTPS health monitor, the client's key and certificate must be combined within a single file.

Note: A feature is implemented in BIG-IP 9.4.2 to support specifying a key file explicitly.

Note: The following procedure does not support the use of private keys stored in a FIPS module. A feature is implemented in BIG-IP 9.4.2 to support private keys stored in a FIPS module.

Importing the key and certificate using the Configuration utility

To combine the client certificate and key file into a single file, perform the following three procedures:

  • Importing the key
  • Importing the certificate
  • Combining the key and certificate into a single file

Importing the key

  1. Log in to the Configuration utility.
  2. Select Local Traffic.
  3. Select SSL Certificates.
  4. Select Import.
  5. For Import Type, select Key.
  6. Provide a name for the key.
  7. Upload the key file or select Paste Text to paste the contents of the key file.

Importing the certificate

  1. Log in to the Configuration utility.
  2. Select Local Traffic.
  3. Select SSL Certificates.
  4. Select Import.
  5. For Import Type, select Certificate.
  6. Provide a name for the certificate.
  7. Upload the certificate file or select Paste Text to paste the contents of the key file.

After the key and certificate are imported, the two files must be combined to create a new single file that contains both the key and the certificate.

Combining the key and certificate into a single file

To combine the key and certificate into a single file, perform the following procedure:

  1. Log in to the BIG-IP LTM command line.
  2. Copy the imported certificate to a new file by entering the following command syntax:

    cat /config/ssl/ssl.crt/<name of certificate>.crt > /config/ssl/ssl.crt/<new name>.combined

    The new file appears similar to the following example:

    cat /config/ssl/ssl.crt/mycertificate.crt > /config/ssl/ssl.crt/mycertificate.combined

  3. Copy the imported key to the new file created in Step 2 by entering the following command syntax:

    cat /config/ssl/ssl.key/<name of key>.key >> /config/ssl/ssl.crt/<new name>.combined

    The new file appears similar to the following example:

    cat /config/ssl/ssl.key/mykey.key >> /config/ssl/ssl.crt/mycertificate.combined

After the client certificate and key are combined into a single file, you can add the file to the HTTPS health monitor in Client Certificate.

Note: Client Certificate is only available if you set Configuration to Advanced.

The full path of the combined file must be specified for Client Certificate. The path appears similar to the following example:

/config/ssl/ssl.crt/mycertificate.combined
