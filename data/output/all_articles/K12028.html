K12028: The BIG-IP WebAccelerator hit logs do not include requests for normalized content

Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator hit logs do not include requests for normalized content. Normalized objects match a global policy node; they do not match any of the predefined nodes in a specific policy. Since there are no log handler objects defined for the global nodes matched by normalized objects, the BIG-IP WebAccelerator is unable to log requests for those objects. 

F5 Networks Product Development is tracking this issue as ID 336692.

Workaround

You can work around this issue by disabling normalization for the global node matching the affected content type(s). To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Navigate to the Advanced Assembly box for the content node for which normalization should be disabled.

    For example, to disable normalization for PDF files, select the PDF node.
  3. Add the following content: 

    disableContentBasedIdentity=true
  4. Publish the policy.
  5. Log in to the BIG-IP WebAccelerator command line and clear the cache by typing the following command: 

    wa_clear_cache

Note: Disabling normalization causes the BIG-IP WebAccelerator to log all the 206 responses for the linearized document, which may cause a large amount of logging and may be undesirable. 

Note: F5 Networks does not recommend adding a log handler to the global node; doing so causes the BIG-IP WebAccelerator to also log all normalized traffic from all policies.
