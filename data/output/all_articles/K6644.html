Topic

Note: There is not a single object identifier (OID) that will provide transaction per second (TPS) as a time delta, which is required to determine the TPS value. The OID that is used returns only a counter value or the number of transactions the device has handled since it has been up.

You can use SNMP commands with two OIDs to gather and interpret data on Secure Sockets Layer (SSL) performance in TPS.

To gather and interpret the data for this metric, perform the following polling and calculations procedure:

Note: The polling interval you select should be in terms of seconds. If, for example, you wish to poll every two minutes, then the polling value will be 120 seconds when performing the calculation procedure below. It is best to use a smaller polling interval to keep the calculations smaller and provide more accurate results. Ten seconds should be the minimum polling interval used.

  1. Determine the time interval between polling cycles you want to poll.
  2. Perform two separate polls for each of the following OIDs located in the F5-BIGIP-SYSTEM-MIB file:

    Note: In this procedure, each OID must be polled twice during the time interval you selected in step 1. The polling results received will be used to calculate a delta value for the OID being polled. F5 recommends that you poll at the beginning of the interval and at the end of the interval.

    • sysClientsslStatTotNativeConns -

      The poll of this OID will output the total number of concurrent NATIVE connections with established SSL sessions being maintained by the filter. These are connections that are handled by the BIG-IP LTM system's NATIVE SSL stack, the DEFAULT cipher listed in the SSL Profile.

    • sysClientsslStatTotCompatConns -

      The poll of this OID will output the total number of concurrent compact connections with established SSL sessions being maintained by the filter. These are connections that are handled by the OpenSSL compatibility stack. This is used when the Ciphers option within the SSL profile is changed from the DEFAULT cipher setting.

  3. Calculate the delta of two OID polls.
  4. Once the values are collected, determine the difference between the delta from step 3.

For example, if the TPS interval is 10 seconds, the following OID polls can be used to calculate the delta:

sysClientsslStatTotNativeConns - .1.3.6.1.4.1.3375.2.1.1.2.9.6
sysClientsslStatTotCompatConns - .1.3.6.1.4.1.3375.2.1.1.2.9.9

Calculating the Delta

Note: In the example below, <sysClientsslStatTotNativeConns1> represents the data gathered at the initial poll; <sysClientsslStatTotNativeConns2> represents the data gathered at the final poll.

<sysClientsslStatTotNativeConns2> - <sysClientsslStatTotNativeConns1> = <DeltasysClientsslStatTotNativeConns>
<sysClientsslStatTotCompatConns2> - <sysClientsslStatTotCompatConns1> = <DeltasysClientsslStatTotCompatConns>

Final Calculation

( <DeltasysClientsslStatTotNativeConns> + <DeltasysClientsslStatTotCompatConns> ) / <Interval> = TPS
