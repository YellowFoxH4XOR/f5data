K60057018: AS3 deploys via BIG-IQ are not compatible with existing administrative partitions

Type
Support Solution
Published
2020-04-13
Updated
2025-02-06
Status
Legacy Content
Applies to

  • BIG-IQ
  • F5 Automation and Orchestration
  • BIG-IQ Centralized Management: 7.X.X
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K60057018

Description
Applications deployed using AS3 Templates from a BIG-IQ are not compatible with existing Administrative partitions on the managed BIG-IP. During an AS3 Application deployment, a Tenant is created and places all new objects within the Tenant on the BIG-IP.  A Tenant on the BIG-IP is an Administrative Partition.  

If a deployment uses the same name for the Tenant as an existing Partition on the BIG-IP, all objects in the pre-existing Partition will be removed and replaced with the objects from the application. 

Environment

  • BIG-IQ Applications Deployed using AS3 Templates 
  • Managed BIG-IPs with existing Administrative Partitions
Cause
Not applicable.

Recommended Actions

F5 recommends that any new application deployment Tenant name be unique from all existing Partition names on the target BIG-IP.
