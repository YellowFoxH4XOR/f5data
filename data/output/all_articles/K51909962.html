Description
Changed PortGroup settings from 40G to 100G, then the partition is not working.
 

Environment

  • F5OS-C
  • any version
  • Partition
  • PortGroup

Cause

  • Bug ID 1045177
    IMPORTANT: If you have not clean install v1.3.0, this issue may affect upper versions.

Recommended Actions

Follow Bug ID 1045177
The workaround  step 1, you may need to know below

After running below command in the partition CLI
system database config-backup name test-for-ID1045177
You will need to log in to Controller CLI.
NOTE: You can log in to Partition CLI from Controller CLI: K11206563:  F5OS-C Velos How to access Partition CLI from Controller CLI

You need to know which ID the partition has, and which controller is Active for the partition.
To check those,  run below command on CLI.
[root@controller-1 ~]# su admin
syscon-1-active# show partitions

If the partition's active controller is different from Controller's Active unit, then ssh to another controller.
For example the example case active for Controller is 1 but partition's active controllr is 2.
then
[root@controller-1 ~]# ssh controller-2
[root@controller-2 ~]# grep -A1 -F -e '<interface>' -e pgindex /var/F5/partition<ID>/configs/test-for-ID1045177
This should give the similar to the below output. Check if the all slot (blades)'s ports has "pgindex" entry.
