K000152847: New connections still using old EPSEC package despite successful new package installation

Type
Support Solution
Published
2025-08-25
Updated
2025-08-27
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.X, 17.1.X, 17.5.0, 17.1.2, 17.5.1, 17.1.1, 17.1.0, 16.1.5
Source
https://my.f5.com/manage/s/article/K000152847

Description

  • After installing a new EPSEC package 1.0.0-1892.0 on BIG-IP APM, new client connections continue to use the previous EPSEC version.
  • In the BIG-IP GUI, the new EPSEC package is shown as installed, but the "True" flag remains on the previous package. This is expected behavior, as the "True" indicator marks the default EPSEC version that comes packaged with the software version running on the BIG-IP system.

Environment

  • BIG-IP APM
  • Endpoint Inspection
  • Edge Client

Cause

APM Client (Edge Client) installed on the BIG-IP system and user devices is below the minimum required version for full compatibility with the newly installed EPSEC package.

Recommended Actions

Upgrade the APM Client on your BIG-IP system and the Edge Client on user devices to version 7248 or newer.

None
