K41085352: Application Logon Page through F5 Virtual Server with an access policy doesn't load after upgrade to v14.1.4.3

Source

Description

A virtual server with an access policy applied doesn't loads after upgrading to v14.1.4.3 but the page works on v14.1.4.2. 
The web page returns a error message:  This site can't be reached. The connection timed out.

Environment

  • Virtual server with an access policy assigned
  • The APM session completes successfully

Cause

Bug ID 1044121

Recommended Actions

Re-enable IPv6 as this now is the listener that renders logon pages. Previous to v14.1.4.3, IPv4 handled these queries.

  1. Check the current value for ipv6.enabled by running the below command: 
    tmsh list sys db ipv6.enabled value

    sys db ipv6.enabled {
        default-value "true"
        scf-config "true"
        value "false" <<<<<<<<     The default value should be true.
        value-range "false true"
    }

  2. If the value shows "false" change it to "true" by running the command:
    tmsh modify sys db ipv6.enabled value true

  3. Test the web page on v14.1.4.3.

  4. If the page loads successfully, save this configuration.
    tmsh save sys config
