K000160421: Fields Appear Editable for Guest, Auditor, and Operator Roles in BIG-IP GUI

Type
Support Solution
Published
2026-03-23
Updated
2026-03-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160421

Description

When users with Guest, Auditor, or Operator roles log in to the BIG-IP GUI and view certain objects (such as Client SSL profiles or Address Lists), many fields appear visually editable. However, these roles are intended to have read-only access, and the GUI should not display editable fields. The issue is cosmetic: while fields appear editable, the Update/Save button remains disabled, and no changes can be saved.

Environment

  • BIG-IP 15.1.10.8, 17.1.3.1, 17.5.1.4, 17.5.1.5, 21.0.0, 21.0.0.1
  • User roles: Guest, Auditor, Operator
  • Accessing objects such as Client SSL profiles and Address Lists via the GUI

Cause

Bug ID 2251549

Answer/Recommended Actions

  • No configuration changes can be saved by Guest, Auditor, or Operator roles, despite fields appearing editable.
  • There is no security risk, as backend enforcement prevents unauthorized changes.
  • If this behavior is problematic, monitor for updates or fixes from F5 addressing this cosmetic GUI issue.
  • If necessary, reference Bug ID 2251549 when contacting F5 support.
