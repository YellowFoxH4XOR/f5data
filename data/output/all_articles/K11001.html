Known Issue

This is the result of a known issue. A user account that has the Application Editor role has R/W access to the BIG-IP ASM web applications in the partitions in which the user account resides, but no access to the BIG-IP PSM system.

For example, when a user with the Application Editor role logs in to the BIG-IP ASM Configuration utility and selects a web application in a partition in which the user account resides, the ASM settings are displayed and available to edit, but only the PSM Statistics screen is displayed. The screens to change PSM settings, such as Security Profiles and Profiles Assignment, are not displayed.

F5 Product Development tracked this issue as CR128834 and it was fixed in BIG-IP ASM 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You may work around this issue by creating a user account with an alternate role, such as the Application Security Policy Editor. For more information about creating user accounts, refer to the Configuration Guide for BIG-IP Application Security Management.
