Known Issue

An administrator may erroneously configure a Secure Sockets Layer (SSL) forward proxy for client authentication on the server side.

This issue occurs when the following condition is met:

  • A Server SSL profile configured for SSL forward proxy is also configured with an SSL certificate and key.
SSL forward proxy does not support server-side client authentication. Therefore, these configurations should not be allowed.

Impact

The SSL connection fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Server SSL profile does not send the CertificateVerify message during the SSL handshake.
  • The SSL connection fails to establish.
