Issue

When starting the 3dnsd or running the 3dparse command, you may receive the following error:

Validation Warning in valVsSupportForLB: For VS <IP address> and
LBMODE qos: attempting to use both hops and rtt - ignoring hops.

On February 24, 2005, F5 Networks Product Development modified and re-released the installation and upgrade files for the following versions, now available on the Downloads page:

  • 4.5.9
  • 4.5.10
  • 4.6.2

If you upgraded or reinstalled your system software after February 24, 2005 using one of these re-released upgrade or installation packages, your 3-DNS will behave like version 4.5.11, which is described in this Solution.

Beginning in 3-DNS versions 4.5.11 and 4.6.3, 3-DNS no longer allows the use of hops and round trip time simultaneously for the QoS load balancing mode.

If you have both hops and round trip time configured for QoS, 3-DNS will ignore the hops data and you will receive an error message when you start 3dnsd or run the 3dparse command.

These changes are due to a patent finding.
