Issue

Error Message

Power Standby press Check button to command power on

Message Location

You may encounter this message in the following location:

  • The front LCD panel of a BIG-IP hardware platform

Description

This message occurs when the following condition is met:

  • You have enabled the power standby mode.

Impact

The unit cannot complete startup until you reset the power standby mode.

Recommended Actions

Forcing the BIG-IP system to restart from the front panel

To force the power standby status off, you must reset the BIG-IP system. To do so, perform the following procedure.

Note: You must have physical access to the BIG-IP system to perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. From the BIG-IP system front panel, hold the X button for four seconds to turn off the host subsystem.
  2. Hold the Check button for four seconds to turn the system on.

If the BIG-IP system does not start up after you perform this procedure, contact F5 Technical Support.
