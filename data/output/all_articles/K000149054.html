K000149054: The configured virtual server does not allow uploading files with a weight greater than 1M

Type
Support Solution
Published
2024-12-28
Updated
2024-12-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149054

Description

The system allows uploading files that are around 800kb, but when files larger than 1Mb are uploaded to applications behind a virtual server, the files no longer finish uploading.

Webacceleration and Compression profiles are enabled on the virtual server.

Environment

  • BIG-IP LTM
  • Version 17.1.1 or earlier
  • Webacceleration profile
  • Compression profile

Cause

When configuring compression and web acceleration cache, it is important to consider the maximum allowable cache size based on the system's memory allocation. If the cache size exceeds the maximum limit defined by the system, such as in the case of attempting to update the cache size beyond the specified limit, the system will fail to update the profile and report an error message indicating that the cache memory assigned exceeds the maximum amount allowed.

Recommended Actions

Remove the Compression or Webacceleration profiles from CLI

  1. View virtual server configuration:

    tmsh show ltm virtual <virtual_server_name>

  2. Remove the web acceleration or, compression profile:

    tmsh modify ltm virtual <virtual_server_name> profiles delete { web-acceleration }
    or
    tmsh modify ltm virtual <virtual_server_name> profiles delete { compression }
    Note: If you tried to remove one of the two profiles and it doesn't work, try to remove the other one.

  3. Save the configuration:

    tmsh save sys config
