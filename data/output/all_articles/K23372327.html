Description

AFM is not logging what actions are being taken by the firewall

Environment

  • BIG-IP AFM
  • Firewall Policies
  • Logging Profiles

Cause

The firewall policy is not logging because no logging profile has been attached to it

Recommended Actions

  1. Create a Security Logging profile Security > Logging Profiles > Create New Logging Profile
  2. Navigate to where your firewall rule is applied ex. the Security tab on a virtual server
  3. Select your logging profile and apply the change
Note: See the AFM Operations guide in Related Content for more information
