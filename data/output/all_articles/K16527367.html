Issue

Error Message

notice sod[<PID>]: 010c0055:5: Forced offline for traffic group <name>

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <name> is the name of the traffic group that changed to a Forced Offline state.

For example:

notice sod[9872]: 010c0055:5: Forced offline for traffic group /Common/traffic-group-2

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An administrator forces the traffic group offline.

Impact

The BIG-IP system does not process traffic for the traffic group while the traffic group is offline.

Recommended Actions

You can release the device from the Forced Offline state to allow the traffic group to process traffic.  To do so, perform one of the following procedures:

Impact of procedure: These procedures change the device to an Online state, which allows the device to accept new connections.

Releasing the Forced Offline state using the Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Device Management > Devices and click the name of your device.
  3. Click Release Offline.

Releasing the Forced Offline state using tmsh

  1. Log in to the TMOS Shell (tmsh)  by typing the following command:

    tmsh

  2. To release the Forced Offline state, type the following command:

    run /sys failover online
