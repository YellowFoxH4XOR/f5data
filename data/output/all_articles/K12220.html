The FirePass Controller supports portal access from the F5 BIG-IP Edge Portal application. The F5 BIG-IP Edge Portal application is designed to use web application portal access and does not currently support network or application access. The F5 BIG-IP Edge Portal application does not require special configuration of the web application and supports current portal configurations. To optimize the F5 BIG-IP Edge Portal application user experience, F5 recommends the following settings:

  • Disabling show administrator-defined favorites
  • Configuring Access Control Lists
  • Disabling Home/Logout tab injection

Disabling show administrator-defined favorites

Disabling the show administrator-defined favorites will allow access to all web-based resources behind your FirePass controller.

  1. Log in to the FirePass Controller.
  2. Navigate to Portal Access : Web Applications : Master Group Settings.
  3. Select the Master Group with which F5 BIG-IP Edge Portal application clients will authenticate from drop-down menu.

    Important: This will grant full resource access for your environment to all users in the selected master group.
  4. Clear the Show administrator-defined favorites only check box.

    Note: Leaving the check box selected will limit client access to only URLs defined in the web application favorites.

Configuring Access Control Lists

The Access Control Lists grant fine control of access to various resources. The Access Control Lists on your FirePass Controller should be configured to match the access requirements of your environment. 

  1. Log in to the FirePass Controller.
  2. Navigate to Portal Access : Web Applications : Master Group Settings.
  3. Select the Master Group with which F5 BIG-IP Edge Portal application clients will authenticate from drop-down menu.

    Important: This will grant full resource access for your environment to all users in the selected master group.
  4. Navigate to the Access Control Lists section.
  5. From the Default action drop-down menu, select Allow.

     Note: Selecting Allow will grant full internal access to all users in the selected master group.

Note: For more information about configuring FirePass Access Control Lists, refer to Understanding access control lists for Portal Access section in the FirePass Controller Administrator Guide.

Disabling Home/Logout tab injection

Important: The setting is global and will affect all users on the FirePass controller.

Important: Changing the Home/Logout tab will require you to restart the FirePass services and will cause a disruption for any users logged on to the FirePass controller.

The Home/Logout tab is functional on the iPhone; when pressed (if active), it will take the user to the FirePass web applications page. 

  1. Log in to the FirePass Controller.
  2. Navigate to Portal Access : Web Applications : Content Processing
  3. Click the Global settings tab.
  4. Navigate to the Home/Logout tab injection section.
  5. In the text box, type an asterisk (*).

    Note: You can enter individual URLs (wildcards are supported) to enable more granular control of the Home/Logout tab.
  6. Click the Update button.
  7. Click (Requires service restart). You are taken to the Restart services screen.
  8. Click the Restart button.
