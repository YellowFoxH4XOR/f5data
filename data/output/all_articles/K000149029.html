Description

This document describes about schema-metadata added into F5OS 1.8.0 configuration backup file.

 

Environment

F5OS 1.8.0

 

Cause

The schema-metadata is added to the F5OS 1.8.0 configuration backup file, so that detect attempts to restore incompatible(cross-version) backups.

schema-metadata component and description is following.

ComponentDescription
services-typeF5OS-A, F5OS-C partition, F5OS-C controller
services-version x.y.z-build
schema-fingerprintmd5 checksum of file /var/F5/system/schema/md5sums
fingerprint-checkencrypted fingerprint
primary-key-hashAES256 hash of primary key(s)

 

Recommended Actions

Make sure to restore the configuration backup file that is the same version of F5OS where you attempt to restore.
