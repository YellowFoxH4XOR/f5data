Known Issue

The BIG-IP ASM system may report a false positive for attack signature ID 200023003.

This issue occurs when all of the following conditions are met:

  • Attack signature ID 200023003 is enabled in the security policy.
  • The BIG-IP ASM system evaluates a request containing JSON, XML, or parameters.

Impact

The BIG-IP ASM system reports a false positive attack signature violation or blocks the request. In rare cases, when remote logging is configured and the BIG-IP ASM system is under load, this issue may cause a traffic disruption while the bd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A false positive violation is reported for attack signature ID 200023003.
  • The bd process generates a core file to the /shared/core/ directory.
  • The BIG-IP ASM system experiences a temporary traffic disruption.

Workaround

To work around this issue, you can remove the offending attack signature from the security policy. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure disables functionality for the attack signature.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Attack Signatures.
  3. In Current edited policy, click the policy to edit.
  4. For versions 11.5.0 through 11.6.x, click the Attack Signatures List tab.
  5. Click Show Filter Details.
  6. Type 200023003 in the Signature ID box and then click Go.
  7. Click the name of the filtered attack signature.
  8. Clear the check box for Enabled in the Enable setting.
  9. Click Update.
  10. Click Apply Policy.
