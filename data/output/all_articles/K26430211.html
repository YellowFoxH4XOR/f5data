Known Issue

Connections to virtual servers with an Any IP (ipother) profile may not expire.

This issue occurs when the following condition is met:

  • You have licensed and provisioned the BIG-IP PEM module on the BIG-IP system.

Impact

The connection remains in the connection table indefinitely.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing connections statistics, you observe an idle timeout value of 4294967295 seconds.
  • The number of active connections increases steadily over time.
