Known Issue

This is the result of a known issue. If you configure automatic virus database updates on the Portal Access: Content Inspection page under the Antivirus tab, and the user name you configure for the virus database updates contains a backslash ( \ ) character, virus database updates fail. This issue occurs because FirePass adds an additional backslash character for each backslash character you entered in User Name field, causing FirePass to contact the download site with an invalid user name.

F5 Product Development tracked this issue as CR98022 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-602-5 issued for FirePass 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
