K2450: Reasons why the Configuration utility may present an HTTP 500 error at login

Topic

You may receive an HTTP 500 error if the host name of the 3-DNS Controller does not match the Local Name host name in the /etc/hosts file.

Note: This issue did not occur in version 4.2, because that version of 3-DNS was not as vigilant about checking host names; therefore, the two did not have to match.

To resolve this issue, perform the following steps:

  1. From the command line, type the following command:

    config
  2. From the menu, select H for host name.

    You will be prompted for the correct host name.
  3. Type the correct host name.
  4. Reboot the 3-DNS Controller.

The Configuration utility should now appear as normal.
