K000151669: Error "Can't Find Version" When Performing UCS Backup or Software Install

Type
Support Solution
Published
2025-06-06
Updated
2025-06-06
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000151669

Description

You may encounter the following error while performing a UCS backup or attempting to install a new software image during an upgrade:

: Saving active configuration...
info: tmsh_syntax_pre: Can't find version
info: dirname: missing operand
info: Try 'dirname --help' for more information.
info: dirname: missing operand
info: Try 'dirname --help' for more information.
info: Error executing 'pre-save' configsync script /var/tmp/cs_save_pre_script.
info:  
info: WARNING:There are error(s) during saving.
info:         Not everything was saved.
info:         Be very careful when using this saved file!
info:  
info: Error creating package
info: Error during config save.
info: Unexpected Error: UCS saving process failed.

Environment

  • BIG-IP
  • Installing new software image
  • Backup UCS archive

Cause

 The issue occurs when the /var/libdata/tmsh/ directory is missing from the BIG-IP system. Instead of seeing the expected directory structure:

[root@BIGIP:Online:In Sync] config #  ls /var/libdata/
classification  dpi  ips  tmsh

You may only see the following:

[root@BIGIP:Online:In Sync] config # ls /var/libdata/
classification  dpi  ips  

Recommended Actions

Copy the /var/libdata/tmsh directory from another BIG-IP peer using WinSCP, SCP, or any FTP client of your choice.

Additional Information

This error may occur for different reasons. While the solution in this article addresses the missing /var/libdata/tmsh/ directory, other causes may require different solutions.
