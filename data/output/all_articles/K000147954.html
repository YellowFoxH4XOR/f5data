Description

  • I want to remove x-volterra-location and server response headers

Environment

  • F5® Distributed Cloud HTTP Load Balancer (LB)

Cause

  • None

Answer/Recommended Actions

  • To remove "x-volterra-location" header, you need to uncheck Add Location option under Other Settings of LB as shown in below example:

  • The "Server" response header cannot be removed but can be manipulated with dummy values. You can set a response header using the header processing options for your load balancer and manipulate it with the server header response setting. Manipulate Server Header in HTTPS Response | F5 Distributed Cloud Technical Knowledge
