Description

The BIG-IP responds with a "No server selected" or "F5RST: iRule execution error" to a connection even if pool members are available.

Environment

  • BIG-IP
  • Virtual Server with Service Profile configured.
  • Pool members available

Cause

BUG ID 1021837

 

 Recommended Actions

  • Move any redirect logic out of the inline policy which triggers the BUG ID to a new iRule.
  • In case the problem is not solved, you can try the workaround below:
    Delete the VS and re-create it without the service profile.
