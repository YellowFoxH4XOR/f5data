K000140168: Removing a F5OS platform device (VELOS / rSeries) from BIG-IQ command line interface using REST API and UUID

Description

Removing a F5OS platform device (VELOS / rSeries) from BIG-IQ command line interface using REST API and UUID

Environment

  • BIG-IQ 8.3.0
  • VELOS
  • rSeries

Cause

Unable to modify or delete an rSeries and/or VELOS device from the BIG-IQ user interface following an IP address change of the respective device(s).

Recommended Actions

Using the BIG-IQ command line interface, retrieve the UUID of the device you wish to remove using either command.

# restcurl /cm/f5os/config/ | jq '.items[]'

# curl -ks -u admin:https://bigiq_mgmt_addr/mgmt/cm/f5os/config/ | jq '.items[]'

Using the BIG-IQ command line interface, execute one of the following commands to successfully to remove the device, ensuring you specify the UUID of the device as demonstrated in the examples provided, without including the angle brackets.

# restcurl -X DELETE /cm/f5os/config/<<UUID>>

# curl -ks -u admin: -X DELETE https://bigiq_mgmt_addr/mgmt/cm/f5os/config/<<UUID>>

Additional Information

Scheduled backups for F5OS configuration has been added in BIG-IQ version 8.3. This new functionality allows for rSeries and/or VELOS devices to be added to BIG-IQ for the purpose of backing up their F5OS configurations.

Note: The configuration and monitoring of the F5OS platform layer is not managed by BIG-IQ
