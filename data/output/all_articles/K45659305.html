Topic

For some VIPRION blades, using the bladectl command with the power-on option produces unexpected results.

Description

The following VIPRION blades do not support using the bladectl command with the power-on option (-p):

  • B4100 (A100)
  • B4200 (A107)
  • B4300 (A108), B4340N (A110)
  • B4450N (A114)

For example, if you attempt to power VIPRION blade 1 ON and it is already powered ON,  using the following command:

bladectl -b 1 -p 1

the specified VIPRION blade resets and is unavailable for traffic processing while the blade restarts. Additionally, your secure shell (SSH) session to the blade is disconnected.

Note: Beginning in BIG-IP 13.1.0, the system returns the blade <#> is already powered on message when you execute this command on a VIPRION blade that is powered on.
