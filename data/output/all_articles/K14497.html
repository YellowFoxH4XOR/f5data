Known Issue

The Traffic Management Microkernel (TMM) process may core when using the Secure Sockets Layer (SSL) profile.

This issue occurs when all of the following conditions are met:

  • SSL client or server profiles are configured and associated with a virtual server.
  • The BIG-IP system is under heavy load.
  • TMM memory is exhausted.

Impact

The BIG-IP system may fail over to another host in the device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H424330 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system may fail over to a standby system or another system in the device group.
  • The TMM memory usage graph may show very high TMM memory use.
  • You view core files in the /shared/core directory.
