Known Issue

This is the result of a known issue. Users with Windows-based operating systems typically log on to the FirePass through a web browser, such as Internet Explorer or Firefox; however, users can log in to FirePass using the Windows Explorer program by typing a URL into the Windows Explorer Address Bar. Windows Explorer will then invoke Internet Explorer to process the URL and establish an HTTP session with FirePass. When the FirePass Cache Cleaner function is enabled, this logon approach does not function properly.

Under normal circumstances, if the Cache Cleaner function is enabled and logon occurs through the browser, the Cache Cleaner is loaded upon login, as indicated by a pop-up window displaying the following text:

Loading... This page loads a Cache Cleanup plugin/ActiveX control and may prompt you to install it. Please answer Yes to the installer prompt.

The pop-up window then minimizes itself, and the webtop is displayed.

When the Cache Cleaner function is enabled, but logon occurs through Windows Explorer, the Cache Cleaner function's pop-up window displays the FirePass logout page, with a message similar to the following example:

Your session is finished

Additionally, the main browser window does not display the the webtop immediately, but rather displays a message similar to the following example:

Loading Cache Cleanup control. Please wait... Click here to skip loading and continue.

Users must click the indicated link to display the webtop.

F5 Product Development is tracking this issue as ID 266571 (formerly CR64107).

Workaround

Users can work around this issue by connecting to the FirePass controller using a web browser instead of Windows Explorer.
