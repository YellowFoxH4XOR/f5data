K01584424: Configuring SNMP settings on a Secondary BIG-IQ system

Type
Support Solution
Published
2020-10-08
Updated
2025-04-02
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K01584424

Description
Certain configuration items such as SNMP and SMTP settings are not synced between Active and Standby BIG-IQ instances. They must be set up individually on each device.

Environment

  • BIG-IQ instances in HA environment

Cause
This is expected behavior. Once a BIG-IQ instance is in standby state, no changes are allowed to be made from the Configuration Utility.  Therefore, SNMP settings cannot be manually configured when the BIG-IQ is standby. The only way to make the change from Configuration Utility would be to promote the standby device to being Active, otherwise the configuration change would have to be made manually on the standby device using tmsh.

Recommended Actions

  • Modifying SNMP configuration on Standby BIG-IQ using Configuration Utility
  • Modifying SNMP configuration on Standby BIG-IQ using tmsh
 Modifying SNMP configuration on Standby BIG-IQ using Configuration Utility??????

You can promote the secondary system to primary when you are logged in to either BIG-IQ system in the pair. This task describes how to promote the secondary BIG-IQ system while logged in to the primary BIG-IQ system.
Impact of procedure: Promoting secondary BIG-IQ system to being primary will restart restjavad process so F5 recommends performing this during a maintenance window.

  1. Log in to the BIG-IQ system with your user name and password.

  2. At the top left of the screen, select System Management from the BIG-IQ menu.

  3. On the left, click BIG-IQ HA.

  4. Select the check box next to the secondary BIG-IQ system, and click the Promote to Primary button.

After secondary BIG-IQ instance has been made Primary, you can make the same modifications to the SNMP settings, so that the settings match the peer.

 Modifying SNMP configuration on Standby BIG-IQ using tmsh

  1. Log in to tmsh on the active BIG-IQ system command line using the following command:
    tmsh

  2. Gather the SNMP settings and format by running following command:
    list /sys snmp

  3. Log in to tmsh on the standby BIG-IQ system command line using the following command:
    tmsh

  4. Run load /sys config merge from-terminal from TMOS prompt. This will result in a prompt Enter configuration. Press CTRL-D to submit or CTRL-C to cancel.

  5. At this point, copy and paste your desired SNMP settings, following the same format of the settings that you gathered from the active BIG-IQ.

  6. When complete, press CTRL-D

  7. Run the following command to verify that the configuration is now in place on the standby BIG-IQ system:
    list /sys snmp

  8. Save the updated configuration changes to the disk using the following command:
    save /sys config
