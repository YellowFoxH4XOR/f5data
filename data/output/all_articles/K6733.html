Topic

You can diagnose hardware issues with the FirePass End-User Diagnostics (EUD) feature. The EUD feature is implemented as a boot option. Once booted in EUD mode, the FirePass controller provides a menu of tools for testing hardware components. All FirePass 1200 hardware platforms are currently shipped with EUD.

If you are running a 1200 platform that does not have the EUD feature installed, or if you want to upgrade to the latest version of the EUD software, you can download the latest EUD hotfix from the F5 Networks Downloads site.

Important: When downloading an EUD hotfix from the F5 Networks Downloads site, ensure that you have chosen the hotfix that is specific to your FirePass hardware platform and software version.

Note: For information about obtaining and installing the latest version of the EUD hotfix, refer to K7960: Obtaining and installing the latest version of End-User Diagnostics.

Note: The EUD hotfixes are approximately 30 megabytes in size.
