K000160379: How to automate F5OS R-series Device Backups and transfer to SFTP using Crontab

Description

You have an R-series device running F5OS-A, and you wish to back up your configuration automatically using crontab entries. 

 

Environment

  • F5OS-A
  • Usage of crontab entries

Cause

None

Answer/Recommended Actions

You can automate F5OS device backup generation and transfer to a remote SFTP server using the crontab entries outlined below.

 

Prerequisites: SSH Key Pair Configuration:

Before adding the crontab entries, you must generate an SSH key pair on the F5OS device to enable passwordless authentication.

 

SSH Key Generation Steps:

Step 1: Generate the SSH key pair on F5OS-A with the following command.

#ssh-keygen -t rsa -b 2048

  • Press Enter to accept the default file location
  • Press Enter twice to skip passphrase creation

 

Step 2: Verify SSH key file creation with the following command.

#ls -la /root/.ssh/

 

Step 3: Display the public key content with the following command.

#cat /root/.ssh/id_rsa.pub

 

Step 4: Copy the public key content to your SFTP server's authorized_keys file

 

Configuration Steps(Automate Backup and Transfer with Crontab):

 

  1. Log in to the F5OS device CLI using root credentials.

  2. Execute the command crontab -e to edit the crontab file and add the following lines:

18 20 * * * /usr/bin/f5sh 'config; system database config-backup name <backup_file_name> proceed yes'

20 20 * * * /usr/bin/sftp root@<SFTP_Server_IP>:/ <<< $'put /var/F5/system/configs/<backup_file_name>'

 

Note: Replace <backup_file_name> with your desired backup filename in both lines, add your SFTP server IP in the option SFTP_Server_IP and adjust the schedule timing as needed.

 

Example:

18 20 * * * /usr/bin/f5sh 'config; system database config-backup name new-backup.tar proceed yes'

20 20 * * * /usr/bin/sftp root@192.168.10.10:/ <<< $'put /var/F5/system/configs/new-backup.tar'

 

In this example, the backup file new-backup.tar will be created at 20:18 and transferred to the SFTP server at 20:20 daily.
