Topic

The X509::serial_number iRules command returns the serial number presented in the client certificate with any leading zeroes truncated.

For example:

00 cf cd 62 e6 28 ef 59 3b

The X509::serial_number command returns the following value:

cf:cd:62:e6:28:ef:59:3b

The leading zeroes are stripped when OpenSSL extracts the serial number from the certificate and presents it to the iRules engine as an ASN.1 integer.

As a result, when using the X509::serial_number command to compare the client certificate serial number with a known serial number, you may need to accommodate this behavior by modifying the known certificate serial number values to mirror the expected truncation.

To perform a comparison against a class, you should enter the class members with the leading zeroes truncated. 

For example:

   00 cf cd 62 e6 28 e0 59 3a
   00 ee c8 67 e7 29 30 32 3b
   42 cd cd 86 a6 2b 45 4e 3c

To use a class (Data Group List) to match on the certificate serial numbers, you would define the class members as follows:

class mySNs {
  "cf:cd:62:e6:28:e0:59:3a"
  "ee:c8:67:e7:29:30:32:3b"
  "42:cd:cd:86:a6:2b:45:4e:3c"
}

Note: For more information about the X509::serial_number iRules command, refer to the following DevCentral iRules wiki page:
