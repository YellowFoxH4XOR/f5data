Description

  • When attempting to download the JSON Web Token from MyF5, the token appears to be missing from NGINX Subscription on MyF5.
  • Starting with NGINX Plus R33, all NGINX Plus instances require a valid JSON Web Token license. NGINX Plus subscription.
  • However, you find the JSON Web Token is missing.

Environment

  • NGINX Plus subscription.
  • MyF5
  • JSON Web Token

Cause

  • Possible fulfilment issue when the subscription was being generated.

Recommended Actions

  • Log a support case or Contact support so it can be investigated further.
