Description

After installing or starting BIG-IP VE version 17.1.x, the Configuration utility (GUI) displays an error: "License invalid for 17.1.3.4".

Figure: GUI License Window

Important: The V23 license entitlement includes BIG-IP TMOS releases from 17.1.x through 23.x.

Environment

  • BIG-IP Virtual Edition
  • BIG-IP VE Version Plus V23 license
  • Licensing

 

Cause

The local BIG-IP license file may be stale, incomplete, or not synchronized with the current license-server record. As a result, the BIG-IP can report the target version as invalid even though the license server contains the correct entitlement. 

 

Recommended Actions

  1. Activate the license using the manual activation method: Manual Activation
  2. Allow a few minutes for the configuration to reload.
  3. Type the command via CLI to verify the local license file. Check the output to confirm the registration key and Service Check Date is current. 

tmsh show sys license

  1. If the issue persists, create a support case via the MyF5 Portal or contact F5 Support
