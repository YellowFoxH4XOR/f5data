Description

The following Restcurl operation can be used to obtain a SSLO setting.
 

Environment

  • BIG-IP Command line
 

Cause

You can obtain a SSLO setting via REST API.
 

Recommended Actions

The endpoint for the SSLO setting is shared/iapp/blocks/

You can access this endpoint to obtain the SSLO setting with restcurl command.

Check SSLO settings ID

restcurl "shared/iapp/blocks?\$select=name,id"|grep <SSLO Setting name> -A1 -B1
 

Example showing the Topology name as sslo_TEST. Note the "id" field

restcurl "shared/iapp/blocks?\$select=name,id"|grep sslo_TEST -A1 -B1
      "id": "6e132696-7338-4066-b68a-54325d6e88d0",
      "name": "sslo_TEST",
 

Obtain the SSLO setting

restcurl "shared/iapp/blocks/<The id identified above>"|less

 

Example showing ID ia456ad3e-84ca-456e-ac17-f372c3e040a

restcurl "shared/iapp/blocks/a456ad3e-84ca-456e-ac17-f372c3e040a0"|less

Example showing global installed packages
restcurl shared/iapp/global-installed-packages/
