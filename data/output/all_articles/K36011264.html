Description

When trying to login via rest API using radius authentication it fails, but login via ssh or gui using the same credentials it is okay.

Environment

  • BIG-IP version 15.1.4.1
  • Radius Authentication via REST API
  • Packet capture shows in Access Request that there's no Calling Station ID attribute when NAS Identifier is 'rest'
WORKING: NAS-Identifier = httpd
