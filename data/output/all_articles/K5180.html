Topic

When you use the the 3ndc querylog command, 3-DNS enables or disables query logging and provides the following output:

Query Logging Toggled

This message does not indicate whether query logging has been enabled or disabled.

To determine whether query logging is currently enabled or disabled, view the /var/log/3dns log file. When query logging is enabled, the following message is logged:

3dnsd: STATE:Query logging enabled:3dnsd.c:849

When query logging is disabled, the following message is logged:

3dnsd: STATE:Query logging disabled:3dnsd.c:851

Whichever of the two messages appears last in the /var/log/3dns file indicates the current state of query logging.
