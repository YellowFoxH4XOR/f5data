Description

Upgrading an iSeries platform from an earlier version to v15.1.0 or later caused traffic not distributed to TMMs evenly.

Environment

  • iSeries i5800, i7800, i10800, i11800 and i15800 platforms (which has high performance license - x800)

Cause

Two new TurboFlex profile options turboflex-adc and turboflex-security were added in BIG-IP v15.1.0 release, and the FPGA firmware for the TurboFlex profiles has changed to the increased L7 Bandwidth FPGA firmware as explained in ID 773793.

One of the differences the new FPGA firmware brought changed the algorithm of how TMM is chosen. For more details about the logic of the behavior, please refer to K11456586.

Recommended Actions

With the fix of ID 913829, a new db variable dagv2.pu.table.size.multiplier was introduced. Follow K11456586 to configure the db variable.
