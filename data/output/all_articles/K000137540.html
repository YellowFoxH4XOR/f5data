K000137540: How to modify default group ids for system authentication

Description

This procedure explains how to modify default group ids for system authentication so you can configure the same IDs you already use on your authentication server.


Environment

F5OS external authentication


Cause

Remote role assignment for external authentication in F5OS use default goup IDs, GID 9000 for admin role, GID 9001 for operator and GID 9100 for tenant-console. The role definitions in F5OS prior to 1.4.0 are read-only and cannot be modified so users created and managed on external authentication servers must have the same group IDs as they do on rSeries systems.


Recommended Actions

Remote roles can be matched with different GIDs in newest firmware versiones. You can do that using command line in config mode:

system aaa authentication roles role <role to change> config remote-gid <new gid to use>


Additional Information

Once the change is done you can check it at /etc/gid-map.txt file
