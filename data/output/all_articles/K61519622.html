Description
When a new route domain is created on a BIG-IP system, in the /var/run/netns/ directory of Linux file system, a file will be created as well.

Environment

  • A new route domain is created on BIG-IP systems

Cause
This is an expected behaviour. Route domain is implemented as network namespace from the perspective of Linux host.

Recommended Actions

None.

Additional Information
