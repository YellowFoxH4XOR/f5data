K000148281: Messages "info urldb[17634]: 01760024:6: 00000000: urldb_service_lookup_cb id=149 counter=0" in the APM log file.

Type
Support Solution
Published
2024-10-28
Updated
2024-10-28
Applies to
  • BIG-IP
  • BIG-IP SSL Orchestrator: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148281

Description

The /var/log/apm log files may show messages like:

info urldb[17634]: 01760024:6: 00000000: urldb_service_lookup_cb id=149 counter=0

Environment

BIG-IP SSLo

BIG-IP SWG

Cause

This message is informational, and does not mean anything is in an ERROR state. 

It pops up when a lookup to the urldb is happening ... and reveal the category of the lookup via the ID.

Recommended Actions

We can filter those messages out with updating the file /defaults/config/templates/syslog.tmpl with the following expression:

filter f_urldb {

 facility(local1) and message(": 0176[0-9a-fA-F]{4}:");

};


Here's what to do:

  • Log in a BASH session to the BIG-IP command line.
  • Mount /usr as read-write: # mount -o rw,remount /usr
  • Change directory: # cd /defaults/config/template
  • Create backup of that file: # cp syslog.tmpl /shared/tmp/
  • Edit the file syslog.tmpl to update the existing "filter f_urldb" record, following this example:

filter f_urldb {

 facility(local1) and message(": 0176[0-9a-fA-F]{4}:");

 level(warning..emerg);

};

  • Make this change in syslog configuration:

# tmsh modify sys syslog include "# test"

# tmsh modify sys syslog include none

  • Remount /usr as read-only: # mount -o ro,remount /usr
