Topic

The BIG-IP Edge Client for Windows and Mac OS maintains a local list of BIG-IP APM access profile servers. The initial server list is derived from the access profile settings of the BIG-IP APM access profile for which the distribution package was configured. When the BIG-IP Edge Client software is installed, it pre-populates a local device file with the access profile servers. The local file list is automatically updated through access of BIG-IP APM access profile servers. Updating or adding access profile servers to the local device file is dependent on several configuration factors addressed in this article.

Description

The Windows and Mac OS BIG-IP Edge Client software has the ability (when configured) to automatically retain a list of accessed BIG-IP APM access profile servers.

The BIG-IP Edge Client software installation package contents are determined by the associated access profile of BIG-IP APM when generating the BIG-IP Edge Client software installation package. Depending on the BIG-IP APM configuration, the package may contain a pre-configured list of BIG-IP APM access profile servers. You can define this list through the BIG-IP APM Configuration utility as part of the BIG-IP Edge Client application custom package distribution settings. The distribution settings also include the ability to pre-configure the BIG-IP APM Edge Client software to retain and update recently accessed BIG-IP APM access profile servers.

You can configure the initial access server list through the BIG-IP APM Configuration utility for an associated access profile. You can generate a BIG-IP Edge Client software package for distribution. To configure the BIG-IP Edge Client to save server upon exit, you can access this setting with the following Configuration utility path:

Access Policy > Secure Connectivity > Connectivity Profile <Connectivity Profile Name> Win/Mac Edge Client > Edge Client Action Settings > Save Servers Upon Exit.

When you enable this feature, accessed BIG-IP APM access profile servers will automatically save to the client.f5c local device file when exiting the BIG-IP Edge Client.

Refer to the following BIG-IP Edge Client client.f5c file path for your operating system: 

  • Windows 10 and Windows 7

    C:\Users\username\AppData\Roaming\F5 Networks\VPN\client.f5c

  • Mac OS

    ~/Library/F5Networks/client.f5c

Note: You can view the BIG-IP APM access profile servers listed in the client.f5c file under the Miscellaneous tab of the BIG-IP Edge Client.

To verify the BIG-IP Edge Client flag was set to save on exit, open the client.f5c file using a text editor. When viewing the file, look for the <SAVEONEXIT> stanza .

For example:

<STAYCONNECTED>YES</STAYCONNECTED>
<RECONNECTIONS>5</RECONNECTIONS>
<SAVEONEXIT>YES</SAVEONEXIT>
<SAVEPASSWORDS>NO</SAVEPASSWORDS>
<REUSEWINLOGONCREDS>NO</REUSEWINLOGONCREDS>
<REUSEWINLOGONSESSION>NO</REUSEWINLOGONSESSION>
<PASSWORD_POLICY>

Note: If the <SAVEONEXIT> tag value is set to NO this indicates that the BIG-IP Edge Client is not configured to automatically save access profile servers on exit.

The BIG-IP Edge Client will maintain deprecated BIG-IP APM access profile servers in the client.f5c file under the following configuration scenarios:

  • The installed BIG-IP Edge Client has save on exit enabled and the BIG-IP APM connectivity profile has save on exit enabled.
  • The installed BIG-IP Edge Client has save on exit enabled and the BIG-IP APM connectivity profile has save on exit disabled.
  • The installed BIG-IP Edge Client has save on exit disabled and the BIG-IP APM connectivity profile has save on exit enabled.

The server is removed from the local device's server list only when both the BIG-IP APM access profile and the BIG-IP Edge Client save on exit setting is disabled.

Note: When you have updated a current access server due to connectivity profile changes, it will be maintained in the list as deprecated (moved down from the top of the list). The newer access server configuration moves to the top of the list. When using a server host name that is not updated, the list is updated; however, none of the listed servers are deprecated.

Refer to the following example list with a deprecated server reference:

Address. . . . . . . . . : vpn1.example.com << Most recent access session
Alias. . . . . . . . . . :

Address. . . . . . . . . : vpn.example.com
Alias. . . . . . . . . . :

Address. . . . . . . . . : vpn.example.com
Alias. . . . . . . . . . : VPN

Address. . . . . . . . . : vpn.example.com
Alias. . . . . . . . . . : VPN_Two

Address. . . . . . . . . : vpn1.example.com
Alias. . . . . . . . . . : VPN_Three

Address. . . . . . . . . : vpn1.example.com << Most recent update based on a BIG-IP APM connectivity profile change (Hostname/Address or Alias).
Alias. . . . . . . . . . : VPN_Four

When the address of a connectivity server changes and the alias name is unchanged, the updated version is saved to the client.f5c file and replaces the previous access server configuration.

For example:

Address. . . . . . . . . : vpn1.example.com << Original client.f5c entry
Alias. . . . . . . . . . : VPN_Four

Address. . . . . . . . . : vpn2.example.com << Updated entry based on the BIG-IP APM connectivity profile server settings.
Alias. . . . . . . . . . : VPN_Four

In the previous example, the original alias VPN_Four aligns with the address vpn1.example.com when the address/hostname changes (though DNS resolves to the same IP address) BIG-IP Edge Client uses the new BIG-IP APM connectivity profile information when updating the server list.

Note: If the save on exit flag is not selected in the connectivity profile and is also set to NO in the BIG-IP Edge Client, and if your current server is one of the updated ones, a deprecated server always is listed in the server list. This is true until you restart (Manual Close/Start or computer restart).

Recommendations

There are no required actions. However, to help reduce confusion you can minimize or clean up the displayed list of access servers by removing unwanted servers from the client.f5c file using any of the following methods:

  • Using the BIG-IP Edge Client interface
  • Modifying the client.f5c file
  • Updating and redeploying the BIG-IP Edge Client software

Using the BIG-IP Edge Client interface

You can remove access server entries using the BIG-IP Edge Client interface.

Impact of recommended action: The access server will be removed from the drop-down list of available access servers.

  1. From the BIG-IP Edge Client, click Change Server.
  2. For Select Server, click the access server host name.
  3. Click the X to the right of the displayed host name.
  4. To confirm deletion, click Yes.
  5. To leave the Change Server page screen, click Cancel.

Modifying the client.f5c file

You can modify the available access servers for BIG-IP Edge Client by using a text editor and manually changing the contents of the client.f5c file.

Impact of recommended action:The access server is removed from the list of available access servers. When modifying the client.f5c file setting <SAVEONEXIT> to NO the BIG-IP Edge Client no longer automatically saves access servers and access server updates to the local access servers list.

  1. Ensure that there are no established access sessions and close the BIG-IP Edge Client.
  2. Using a non-formatting text editor (notepad) open the client.f5c file for your operating system.
  3. Locate the opening <SITEM> and closing </SITEM> stanza that contains the host name reference to the access server you want to remove.

    Example configuration for host name vpnserver.example.com:

    <SITEM>
    <ADDRESS>vpnserver.example.com</ADDRESS>
    <USER></USER>
    <ALIAS>VPN One - (vpnserver.example.com)</ALIAS>
    <ORIGIN>vpnserver.example.com</ORIGIN>
    <SSL_CERT_AUTOLOGIN>0</SSL_CERT_AUTOLOGIN>
    <SSL_CERT_LOGIN_TO_WEBTOP>0</SSL_CERT_LOGIN_TO_WEBTOP>
    <PASSWORD></PASSWORD>
    <OPTIONAL_FIELD></OPTIONAL_FIELD>
    <SAVEPASSWORDS>NO</SAVEPASSWORDS>
    </SITEM>

  4. Remove all lines starting with <SITEM> through the closing </SITEM> for the host name.

    Note: You can modify the save on exit setting to no longer save access server entries by changing YES to NO in the following stanza.

    Original SAVEONEXIT setting client.f5c:
    <SAVEONEXIT>YES</SAVEONEXIT>
    Updated SAVEONEXIT setting client.f5c:
    <SAVEONEXIT>NO</SAVEONEXIT>

  5. Save the changes to the client.f5c file.
  6. Start the BIG-IP Edge Client application.

Updating and redeploying the BIG-IP Edge Client 

For limited environments deploying a modified connectivity profile with save on exit disabled may be possible.

Impact of recommended action: All previous client-side BIG-IP Edge Client customizations are removed when deleting the current installed version of the BIG-IP Edge Client.

  1. Log on to the BIG-IP APM system with the affected access profile.
  2. Navigate to Access Policy > Secure Connectivity > Connectivity Profiles.
  3. Click the affected Connectivity Profile name and click Edit Profile.
  4. Disable the setting by clearing Win/Mac Edge Client > Edge Client Action Settings to Save Servers Upon Exit.
  5. Remove the current installation of the BIG-IP Edge Client software from affected user devices.

    • K15539: Removing the BIG-IP Edge Client from Mac OS X devices

    • K8254 Removing BIG-IP APM and FirePass client components from Windows client systems

  6. Deploy the updated BIG-IP Edge Client to the affected device user base.

Note: After the reinstalling the BIG-IP Edge Client, the save on exit setting of the client.f5c file may be set to YES. However, this setting is set to NO when establishing the initial access session to the updated access profile.
