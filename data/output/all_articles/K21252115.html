Description

Refer to the article K55131641, BIG-IP has multiple log facilities, different facility will logging to different destination files.
The following command should log into /var/log/pktfilter, but it does not.

log local5. "message to /var/log/pktfilter"

Environment

  • BIG-IP v12.1.5.2
  • Virtual server
  • iRule

Cause

Unknown.

Recommended Actions

Follow the steps below to enable packet filter under "Network ›› Packet Filters : General".

  1. Login the Configuration Utility with administrator role.
  2. Navigate to Network ›› Packet Filters : General.
  3. Change the setting "Packet Filtering" to Enabled
  4. Click Update.

Additional Information

This issue is not observed on most of the other versions.
