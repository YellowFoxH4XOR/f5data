Note: For information about the ARX Secure Agent software, refer to K10026: Overview of the ARX Secure Agent software.

When you install the ARX Secure Agent (ASA) on a Windows domain controller, the system creates an acopia-secure-agent-install-dll.log file in the logs sub-directory of the ASA install directory.

Note: The ARX Secure Agent is formerly known as the Acopia Secure Agent.

You can use this log file to verify the ASA installation date. In addition, you can use the information in this file to determine which version the Windows domain controller was running when you installed the ASA.

The ASA installation date appears similar to the following example:

************************ date: 12/31/09 *************************

To determine the Windows O/S version at the time of installation, locate the [check_os_version] section of the log file. The entries appear similar to the following example:

[check_os_version] Operating system information:
  Major Version = 5
  Minor Version = 0
  Build Number = 2195
  PlatformID = 2
  CSD Version = Service Pack 4
  ServicePackMajor = 4
  ServicePackMinor = 0

The Major Version and Minor Version entries correspond to the following Windows versions:

  • Major 5 Minor 0
    Windows 2000
  • Major 5 Minor 2
    Windows 2003
