K31751328: Error Message: 01140106:2: Overdog daemon calling bigstart restart

2017-04-18
Updated

Applies to

Issue

Error Message

crit overdog[<PID>]: 01140106:2: Overdog daemon calling bigstart restart.

In this error message, note the following:

  • <PID> is the process ID for the overdog process.

For example:

crit overdog[5442]: 01140106:2: Overdog daemon calling bigstart restart.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The BIG-IP system console

Description

This message occurs when the following condition is met:

  • A high availability (HA) table failover action that specifies 'restart-all' is triggered.

The overdog process monitors the HA table for failover actions and performs the configured action when triggered. The BIG-IP system generates this message when the 'restart-all' failover action type is triggered.

Impact

Traffic processing is interrupted while all local services restart. If configured for HA, all traffic groups fail over to the peer device.

Recommended Actions

To view the HA table, use the tmsh show /sys ha-status all-properties command. Output appears similar to the following example:
