Description

This article explains how to check the expiration dates for certificates associated with CE (Customer Edge) sites in Multi-Cloud Network Connect, specifically through the Site Management interface or tools.

 

Environment

  • Multi-Cloud Network Connect
    • Site Management

Cause

None

Answer/Recommended Actions

To check the certificate expiration date for CE sites, follow these steps:

  1. Access the CE CLI :

    • Log in to the CE Command-Line Interface (CLI) .

  2. Run the health Command :

    • Type the command health in the CLI.

  3. Scroll Through Health Information :

    • Press Enter repeatedly until you reach the Certificates Section , where you’ll find the expiration details (e.g., certificate name and expiration date).
