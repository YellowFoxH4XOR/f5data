Known Issue

The persist iRules command may produce an error message and terminate iRules execution.

This issue occurs when all of the following conditions are met:

  • You are running on a BIG-IP Clustered Multiprocessing (CMP) platform.
  • Persistence is assigned to a connection from within an iRule.
  • The iRule is associated with the virtual server or persistence profile. 
  • The persistence record is created on a Traffic Management Microkernel (TMM) other than the one handling the TCP connection request.
  • A FIN is received from the server, fully closing the server-side TCP connection before the persist command completes.

This issue occurs as a result of a race condition that allows for an iRule to attempt a persist add operation after the server-side of the connection has been closed on a separate TMM. This issue typically occurs with non-standard TCP clients, such as netcat, which may send a FIN immediately after sending a request on a TCP connection.

Impact

iRules termination may cause unexpected results on affected connections.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Execution of the iRule implementing the persistence will abruptly stop.
  • In the /var/log/ltm file, you observe error messages similar to the following example:

    local/tmm1 err tmm1[<pid>]: 01220001:3: TCL error: <irule_name> <HTTP_RESPONSE> - Prerequisite operation not in progress (line 2) invoked from within "<failed_irule_command>"

    For example:

    local/tmm1 err tmm1[5163]: 01220001:3: TCL error: irule-test <HTTP_RESPONSE> - Prerequisite operation not in progress (line 2) invoked from within "persist add uie "SomeValue" 300"

  • A TCP RESET is sent to the client.

Workaround

To work around this issue, you can use the catch iRules function in the iRule. To do so, perform the following procedure:

Impact of workaround: You may catch other runtime errors unrelated to this issue.

  1. Log in to the Configuration utility with administrative credentials.
  2. Navigate to Local Traffic > iRules.
  3. Click the iRule you want to modify.
  4. Edit your iRule to add the catch { } command around the persist statement of your iRule.

    For example:

    persist add uie "SomeValue" 300

    You change the previous example to appear as follows:

    catch { persist add uie "SomeValue" 300 }

  5. Click Update.
