Description

This guide explains on how to identify large files in UCS archive
 

Environment

  • BIG-IP 
  • UCS

Cause

Old and unused files taking up disk space
 

Recommended Actions

Run the following CLI command against the suspected UCS.  
tar -tvf [UCS_File] | awk -v size="$size" '$3 >= size {print $3" "$6}' | sort -t' ' -k1,1nr | head -30

NOTE:

  • Replace [UCS_File] with the actual value 
  • The above command will sort the files in the UCS by size.
