Published

Applies to

  • BIG-IP AFM: 15.1.6
Source

Description

Whitelist address when IP addresses are part of Route domain.


Environment

  1. DOS configured on the device and need to whitelist few IP addresses.
  2. The IP addresses are part of a route domain.


Cause

  1. The system doesnt allow the RD notation for the whitelist.


Recommended Actions

Configure IP addresses without the RD notation and the system will configure them appropriately.
