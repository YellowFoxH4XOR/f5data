K16451345: BIG-IQ failed to synchronize clustered devices; reason: Device sync failed from device

Type
Support Solution
Published
2022-03-04
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K16451345

Description

After upgrading the BIG-IQ from version 8.0.0 to 8.1.0, the reimport/rediscover action fails with error messages similar to the following are logged to /var/log/restjavad.x:

Failed to synchronize clustered devices; reason: Device sync failed from device bigip1.example.com (10.30.40.100) to device bigip2.example.com (10.30.40.101): working-config target object sender failed: Duplicate item. Key already exists: partition : Common, deviceReference : /mgmt/shared/resolver/device-groups/cm-adccore-allbigipDevices/devices/f9c47c54-a1d5-5a65-97f2-334457840585, name : HTTPServer.

Environment

  • BIG-IQ
  • Software upgrade
     

Cause

This is caused by the documented behavior under Bug ID 1034825.

Recommended Actions

Either of the following actions will resolve this issue.

  • Upgrade to BIG-IQ 8.1.0.1 (recommended)
  • Install a patched jar file: f5.rest.configmgmtbase.jar  (provided by F5 Support).
