K000135379: SMTP error 421 4.3.2 service not available

Type
Support Solution
Published
2023-07-05
Updated
2023-07-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135379

Description

Emails are not received by the SMTP server. The connection is reset by the SMTP server.

 

When doing telnet in the BIG-IP CLI specifying the SMTP server address on the corresponding port (usually 25), the connection is immediately closed by the peer indicating the following error message:

 

SMTP error 421 4.3.2 service not available.

 

Environment

  • BIG-IP LTM
  • SMTP configured

Cause

The server, firewall, or device in the middle of the network flow is not allowing connections coming from the BIG-IP floating Self-IP.

 

 Recommended Actions

Modify the server, firewall, and/or device in the middle of the network to accept the traffic coming from the BIG-IP

 

Additional Information

None.
