Known Issue

The BIG-IP system truncates the QKView tmstat snapshot file data.

This issue occurs when one of the following conditions is met:

  • The qkview utility attempts to gather a tmstat snapshot file that exceeds the default maximum file size of 5 megabytes (MB).
  • The tmstat snapshot file exceeds the specified custom maximum file size limit when you manually run the qkview utility.

Impact

The system truncates the tmstat snapshot file data.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view the tmstat snapshot file data, the file is incomplete.

Workaround

To work around this issue, you can manually run the qkview utility using the unlimited file size flag. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure can create a large QKView snapshot file, so make sure that your BIG-IP system /var partition has sufficient free storage resources.

  1. Log in to the command line of the BIG-IP system with administrative privileges.
  2. To run the qkview utility without a file size restriction, type the following command:

    qkview -s0

    Note: The system saves the QKView diagnostic information output file to /var/tmp as <hostname>.qkview.
