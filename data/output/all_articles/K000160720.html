K000160720: BigIP Edge Client-side Check failing

Description

After updating the EPSEC package on BIG-IP APM (version 16.1.6), users experienced failed BitLocker checks, repeated UAC prompts, and tunnel errors ("tunnel is not writeable"). The issue began immediately after the EPSEC update.

Cause

The root cause was a code signing certificate mismatch between the updated EPSEC package (epsec-1.0.0-1992.0.iso) and the installed APM Client version. EPSEC 1992 is only supported on specific BIG-IP versions (16.1.x with FIPS, 17.1.x, 17.5.x, 21.0.x). Installing EPSEC 1992 on unsupported versions causes client-side inspection failures (Bug ID1644325).

Solution

Confirm BIG-IP Version Compatibility

    • Run tmsh show sys version on BIG-IP.
    • If not a supported version, roll back EPSEC to the previous package (epsec-1.0.0-1915.0.iso).

Update APM Client Package (if supported)

    • Ensure the minimum required APM Client version is installed (see K25610890).
    • Download and install the correct APM Client ISO; endpoints will auto-update.

Clean Up Endpoint Components

    • Uninstall all F5/OPSWAT components (see K8253).
    • Delete all Conflict.* folders in C:\Windows\Downloaded Program Files.
    • Clean F5 registry keys, reboot, reinstall latest F5 VPN client.

If Issue Persists

    • Collect QKView, APM debug logs (/var/log/apm), session IDs, VIP and Access Policy name.

Additional Info

Rolling back to the previous EPSEC package resolved the issue across all systems. The issue was not caused by domain GPO, AV/Security software.
