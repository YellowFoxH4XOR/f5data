Topic

You should consider using this procedure under the following condition:

  • You want to determine the active version of OPSWAT running on the BIG-IP APM system.

Description

The BIG-IP APM antivirus and firewall client-side checks use software libraries from a software development kit (SDK) created by OPSWAT, Inc. The BIG-IP APM can have several OPSWAT images uploaded to the BIG-IP system. Only one version can be installed and active. The following procedures will assist in determining the active version of OPSWAT that is installed on the BIG-IP APM system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your BIG-IP system is installed with the BIG-IP APM module.

Procedures

Determining OPSWAT version from the Configuration utility (BIG-IP 11.2.1 and later)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to System > Software Management.
  3. Select Antivirus Check Updates.
  4. Select Device EPSEC Status.

    For versions prior to BIG-IP 11.4.0, select Device Status.

  5. From the local device / device group menu, select the local device or a device group for which you want to check the version.

    The installed version displays in the lower panel. For example:

    Name Installed                         Version Installed OESIS Version Last Installed version Last installed OESIS version Status
    /common/bigip1121.test.lab 1.0.0-192.0            3.6.5595.2      1.0.0-192.0                     3.6.5595.2                                    success 

Determining OPSWAT version from the Configuration utility (BIG-IP 10.2.0 - 11.2.0)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management.
  3. Select Antivirus Check Updates.

    The Installed Image section displays the F5 version, OPSWAT OESIS version, and the file date.

    For example:

    Version 1.0.0-96.0
    OESIS Version 3.4.26.1
    Date Thu Aug 25 08:46:44 PDT 2011

Determining OPSWAT version using tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh
  2. Display the version by entering the following command:

    show apm epsec software-status

    Output appears similar to the following example:

    Epsec::Software Status             Device Version    OESIS Version Previous Installed Version Previous OESIS Installed Version Status
    --------------------------------------------------------------------------------
    /Common/bigip1121.test.lab          1.0.0-160.0         3.5.2461.2      none                                        none                                                 success

Determining OPSWAT version from the command line

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Display the version by entering the following command:

    epsec version

    Output appears similar to the following example:

    Version: 1.0.0-160.0
    SDK Version: 3.5.2461.2
    Installation Date: Thu Dec 6 16:25:57 PST 2012
