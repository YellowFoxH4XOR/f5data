K000159022: VirtualServer CIS Declaration gets HTTP 422 error code

Type
Support Solution
Published
2026-01-08
Updated
2026-02-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000159022

Description

Error are observe while using CIS to create virtual server.

 

  • 2025/12/12 08:01:30 [INFO] [Request: 19][AS3][BigIP] post resulted in FAILURE
  • 2025/12/12 08:01:30 [ERROR] [Request: 19][AS3] Response from BIG-IP: code: 422 --- tenant:k8s --- message: declaration failed
  • GMT - severe: [appsvcs] {"message":"Declaration failed: 01070151:3: Rule [/Folder1/Shared/example_vs_80_http_redirect_irule_443] error: Unable to find value_list (/Folder1/Shared/example_vs_80_https_redirect_dg) referenced at line 5: [class match -value

 

Environment

  • BIG-IP
  • Container Ingress Services(CIS)
  • Products and features

Cause

This error occurs if pools's path is missing from declaration as datagroup that is needed is generated from pools path.

Recommended Actions

Make sure pool path exist in yaml file.
