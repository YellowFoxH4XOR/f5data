K000160912: Machine Tunnel VPN connection fails with Client Certificate or On-Demand Certificate Authentication in APM Clients 7.2.7.0

Machine Tunnel service fails to establish VPN connection when configured to use Client Certificate Authentication or On-Demand Certificate Authentication in APM Clients 7.2.7.0.

This issue occurs when all of the following conditions are met:

  • You are running APM Clients 7.2.7.0.
  • The Machine Tunnel service is running on client systems connecting to the BIG-IP APM system.
  • Your configuration uses Client Certificate Authentication or On-Demand Certificate Authentication.

Impact

Client systems are unable to establish a VPN connection to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Machine Tunnel VPN connection establishment fails.
  • Machine Tunnel service authentication fails.

Status

Workaround

There is currently no workaround. If you are using Client Certificate Authentication or On-Demand Certificate Authentication with the Machine Tunnel service, you should not upgrade to APM Clients 7.2.7.0 at this time. If you plan to upgrade your APM Clients version, wait to upgrade until there is a fixed APM Clients release or until there is a confirmed workaround.
