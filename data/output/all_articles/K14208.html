Topic

This article applies to Enterprise Manager. For information about other products, refer to the following articles:

  • K14206: Configuring BIG-IP to exclude inode information from Etags (11.x - 12.x)
  • K12036: Configuring BIG-IP to exclude inode information from Etags (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to configure Enterprise Manager to exclude inode information from Etags when connecting to the Configuration utility.

Description

When connecting to the Configuration utility, responses from the Apache server will contain an ETag HTTP header that includes the file's inode information.

For example:

ETag: "639e2-cfb-284e6b40"

8d74 is the inode of the file printed in hex.

This information is provided only while accessing the Configuration utility. Therefore, F5 Product Development considers the impact or risk of revealing this information as low.

However, because the inode information is disclosed, some security scanners may detect the system as vulnerable to Apache vulnerability CVE-2003-1418. The Apache vulnerability was addressed with the addition of the FileETag httpd setting, which allows the ETag header to be configurable. However, the default behavior of the Apache service was not changed. The versions of Apache used by Enterprise Manager support the FileETag httpd setting required to configure the ETag header.

Note: For more information about CVE-2003-1418, refer to the following location. This link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2003-1418

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Enterprise Manager command line.

Procedures

Configuring Enterprise Manager to exclude inode information from Etags

If you need to comply with local security requirements, you can configure Enterprise Manager to exclude inode information from ETags by performing one of the following procedures:

Impact of procedures: Performing the following procedure should not have a negative impact on your system.

Enterprise Manager 3.0.0 and later

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. Specify the format to be used for the ETag header by typing the following command:

    modify /sys httpd include \"'FileETag MTime Size'\"

  3. Save the configuration change by typing the following command:

    save /sys config

  4. Restart the httpd service by typing the following command:

    restart /sys service httpd

    The ETag headers no longer include the inode information for files. The ETag headers now appear similar to the following example:

    ETag: "cfb-284e6b40"

Enterprise Manager 1.0.0 through 2.3.0

  1. Log in to the Enterprise Manager command line.
  2. Specify the format for the ETag header by typing the following command:

    echo "FileETag MTime Size" >> /config/httpd/conf/httpd.conf

  3. Restart the httpd service by typing the following command:

    bigstart restart httpd

    The ETag headers no longer include the inode information for files. The ETag headers now appear similar to the following example:

    ETag: "cfb-284e6b40"
