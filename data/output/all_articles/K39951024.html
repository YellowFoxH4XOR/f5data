Known Issue

The TunnelServer component may log misleading error messages.

This issue occurs when the following condition is met:

  • The network access session is disconnected.

Impact

The TunnelServer component generates error messages that are uninformative and could cause confusion.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The TunnelServer component logs error messages in the f5TunnelServer.txt file, located in the %temp%, ~/Library/Logs/F5Networks and /usr/local/lib/F5Networks/SSLVPN/var/log/ folders for Windows, Mac, and Linux systems, respectively, that appear similar to the following example:

    Error <date> \UOverlappedIOSocket.cpp, UOverlappedIOSocket::isAvailable(), WSAGetOverlappedResult returned no data, 10058, A request to send or receive data was disallowed because the socket had already been shut down in that direction with a previous shutdown call.
