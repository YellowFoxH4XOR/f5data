Description
Config fails to sync or load with the following error message:

Load failed from LTM1.example.com 01070734:3:  Configuration error: The floating traffic-group: traffic-group-1 can only be set on /partition if its device-group is inherited from the root folder

Environment

  • Config Sync
  • Reloading configuration 
  • BIG-IP upgrade or system reboot

Cause

This issue can occur during any of the following circumstances:

  • The config sync was performed
  • The configuration was reloaded by running the command 'tmsh load /sys config verify'.
  • Objects in /config/bigip.conf are deleted.
  • Made modifications to an iApp deployment and a remnant iApp tunnel configuration is present in configuration files. 

Recommended Actions

To work around the issue you may consider the below procedure.
 
  1. Make a backup of the /config/bigip.conf file by typing the following command:
    cp /config/bigip.conf /config/bigip.conf.backupfile
     
  2. Search /config/bigip.conf for the configuration object in question and delete it from the configuration file.
    For example: iApp tunnel configuration and the partition /partition which are not relevant
     
  3. Verify the configuration by typing the following command:
    tmsh load sys config verify
     
  4. Load the configuration by typing the following command:
    tmsh load sys config 
     
  5. You can revert back to the original configuration file at any time by typing the following command and reload the configuration.
    cp /config/bigip.conf.backupfile /config/bigip.conf

     

Additional Information
Similar error might occur when trying to sync, for example:

Sync error on LTM1.example.com: Load failed from LTM1.example.com 01070734:3:  Configuration error: The floating traffic-group: traffic-group-1 can only be set on /LTM1.example.com if its device-group is inherited from the root folder
