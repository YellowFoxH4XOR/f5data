Known Issue

This is the result of a known issue. The Sun JVM is not fully compatible with the 3-DNS Configuration utility. As a result, you cannot modify topology records if you use a Sun JVM.

F5 Product Development is tracking this issue as CR29626, CR28627 and CR41839.

Workaround

If you want to manage topology records using the 3-DNS Configuration utility, install the Microsoft Java Virtual Machine.
