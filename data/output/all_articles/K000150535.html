Description

After upgrading to v17.1.2 or later, ZoneRunner may fail to display zone records in the GUI (DNS ›› Zones : ZoneRunner : Resource Record List) with error:

01150b21:3: RCODE returned from query: 'SERVFAIL'

 

Environment

BIG-IP DNS (formerly GTM)

Cause

This behavior is due to changes introduced in BIND version 9.20.0, which set a default limit of 100 records per type (e.g., A, AAAA) via the max-records-per-type option.

Recommended Actions

If you have more than 100 records of a single type in a zone, you must increase the max-records-per-type value.

  1. If possible, update via GUI:
    • Navigate to DNS ›› Zones : ZoneRunner : named Configuration.
    • Edit the options section to add or modify:
      options { max-records-per-type 1000; listen-on port 53 { ... }; ... }
    • If this succeeds and no errors are shown, save and apply configuration.
  2. If updating via GUI fails (for example, if you receive another SERVFAIL error after clicking update):
    1. Edit named.conf manually:
      Open a terminal on your BIG-IP system and run:
      vi /var/named/config/named.conf

      In the options section, add or adjust:
      max-records-per-type 1000;

      Example:
      { max-records-per-type 1000; listen-on port 53 { ... }; ... }
      Note: You may set the value of max-records-per-type higher than 1000 if your environment requires it (for example, for thousands of Wide IPs).

       


      Save and exit vi.

    2. Check configuration syntax:
      Run:
      named-checkconf -t /var/named
      Ensure there are no errors before proceeding.

    3. Reload BIND/named service:
      Run:
      rndc reload

    4. The ZoneRunner GUI should now display records correctly without SERVFAIL errors.
