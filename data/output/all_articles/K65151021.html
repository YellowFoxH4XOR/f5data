Known Issue

The Configuration utility setup wizard may fail when attempting to activate an SSL Orchestrator license.

This issue occurs when all of the following conditions are met:

  • You attempt to activate or reactivate an SSL Orchestrator add-on license to the BIG-IP system.
  • You attempt to run the Configuration utility setup wizard.
  • You attempt to use the Configuration utility iApps, DNS, and Acceleration menus.

The issue occurs because SSL Orchestrator is introduced as a licensed add-on in 14.0.0.

Note: SSL Orchestrator was added to BIG-IP LAB licenses in August 2018. For BIG-IP instances using LAB licenses, initial setup and license reactivation may fail.

Impact

The Configuration utility menus are not visible and you are unable to use iApps, DNS, and Acceleration features.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility iApps, DNS, and Acceleration menus are not visible.
  • You are unable to complete the Configuration utility setup wizard.
