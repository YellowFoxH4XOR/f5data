Description

When attempting to save a UCS file or generate a qkview on BIG-IP LTM, the following error may occur:

Unexpected Error: Can't create temp config file, "/var/tmp/.config.tmp/..." No space left on device Error during config save.

Unexpected Error: Ucs saving process failed.

This issue can persist even when df -h shows sufficient disk space. Running df -i reveals that the inode usage for the /shared partition is at 100%.

Environment

  • BIG-IP
  • inode

Cause

The /shared partition has run out of available inodes due to an excessive number of small files, particularly within the /shared/tmp/.config.tmp/ directory. Inode exhaustion prevents new files from being created even if there is free disk space. Temporary files generated during configuration save operations are not being deleted as expected, leading to this condition.

Recommended Actions

  1. Check inode Usage

Run df -i to confirm inode usage on the /shared partition.

  1. Identify Directories with High Inode Usage
    1. Find directories consuming the most inodes:

find /shared -xdev -type d -exec du --inode -s {} \; | sort -rn

    1. Alternatively, count files in each directory:

for i in /shared/* ; do echo $i; find $i | wc -l ; done

  1. Clean Up Temporary Files
    1. If /shared/tmp/.config.tmp/ contains a large number of files, these can be safely deleted:

cd /shared/tmp/.config.tmp/

rm -rf ./*

    1. This will free up inodes and allow UCS/qkview file creation to proceed.
  1. Handle Deleted Files Still Held Open
    1. List open deleted files:

lsof +L1

    1. If necessary, restart or kill processes holding deleted files to release inodes.
  2. Monitor Inode Usage Regularly

Use df -i periodically to monitor inode consumption and prevent recurrence.
