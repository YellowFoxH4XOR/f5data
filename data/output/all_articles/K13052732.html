Description

  • Having issues with an F5 ansible module – bigip_pool
  • Received the following error:
    {
        "msg": "Could not find imported module support code for bigip_pool.  Looked for either cmp_str_with_none.py or compare.py",
        "_ansible_no_log": false
    }
  • What python module is missing?

Environment

  • F5 Modules - Ansible 2.5.0
  • Running the module from AWX

Cause
Running an older version of Ansible. 
The compare.py addition is in the 2.8 and devel branches following fix

Recommended Actions

Upgrading to latest version of Ansible (at least 2.8.3) should correct the errors.
