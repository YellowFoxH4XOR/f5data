Description

You would like to configure an iRule which will select a specific SNAT pool for the server side connection based, on the source / destination IP on the client request.

Example requirement:

1. When client 198.51.100.1 sends a request to 203.0.113.100 select a snat pool under name SNAT_POOL_A
2. When client 198.51.100.1 sends a request to any other destination select a snat pool under name SNAT_POOL_B
3. When client 198.51.100.2 sends a request to 203.0.113.200 select a snat pool under name SNAT_POOL_C
4. When client 198.51.100.2 sends a request to any other destination select a snat pool under name SNAT_POOL_D
5. On every other scenario use automap

Environment

  • BIG-IP
  • iRules

Cause

None

Recommended Actions

To accomplish the described, you can use an iRule similar to the following example:

when CLIENT_ACCEPTED {
  switch [IP::addr [IP::remote_addr] mask 255.255.255.255] {
      "198.51.100.1" {
          if { [IP::addr [IP::client_addr] equals 198.51.100.1 ] and [IP::addr [IP::local_addr] equals 203.0.113.100] } then {
             #log local0. "Client: [IP::client_addr]:[TCP::client_port] -> VIP: [IP::local_addr]:[TCP::local_port]"
             snatpool SNAT_POOL_A
          } elseif { [IP::addr [IP::client_addr] equals 198.51.100.1 ]} {
             #log local0. "Client: [IP::client_addr]:[TCP::client_port] -> VIP: [IP::local_addr]:[TCP::local_port]"
             snatpool SNAT_POOL_B
          }
      }
      "198.51.100.2" {
          if { [IP::addr [IP::client_addr] equals 198.51.100.2 ] and [IP::addr [IP::local_addr] equals 203.0.113.200 ] } then {
             #log local0. "Client: [IP::client_addr]:[TCP::client_port] -> VIP: [IP::local_addr]:[TCP::local_port]"
             snatpool SNAT_POOL_C
          } elseif { [IP::addr [IP::client_addr] equals 198.51.100.2 ]} {
             #log local0. "Client: [IP::client_addr]:[TCP::client_port] -> VIP: [IP::local_addr]:[TCP::local_port]"
             snatpool SNAT_POOL_B
          }
      }
      default {
          #log local0. "snat for [IP::remote_addr]"
          snat automap
      }
  }
  }
}

Note: These are just example iRules and thorough tests are suggested before making use of it on a production environment.
