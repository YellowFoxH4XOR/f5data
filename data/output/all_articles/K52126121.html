Description

BIG-IP Administrators may want to create multiple users for AAA LocalDB for testing purposes.  And there is an easy way to do that.

Environment

  • APM
  • AAA LocalDB

Cause

None

Recommended Actions

  • Create the LocalDB Instance in advance or re-use the existing one. For example, in Configuration Utility 'Access >> Authentication : Local User DB : Instances', the instance '/Common/instance-article' was created.
  • In CLI, run the below command in bash shell. Make sure that the expected value for each option is specified. For example, to create 50 users for LocalDB instance '/Common/instance-article'
# for i in {1..50} ; do ldbutil --add --uname=user"$i" --instance="/Common/instance-article" --password="abc123" --user_groups="group1" --login_failures="3" --change_passwd="0" --locked_out="0" --first_name=user"$i"firstname --last_name=user"$i"lastname --email='user'"$i"'@email.com' ; done
  •  To verify the number of created users for specific LocalDB Instance, run in bash shell:
# ldbutil --list | grep '/Common/instance-article' | wc -l
50
