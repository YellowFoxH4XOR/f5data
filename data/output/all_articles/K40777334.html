Description

When attempting to update the ASM Attack Signatures or other features via Live Update, it fails, with messages similar to the following:

Check for updates failed for the following modules:
ASM Attack Signatures - Could not retrieve latest file for asm-attack-signatures
Browser Challenges - Could not retrieve latest file for browser-challenges
Server Technologies - Could not retrieve latest file for server-technologies

You also see an error similar to the following in /var/log/tomcat/liveupdate.log:

Error: Can't get hostname IP address (Timeout triggered)

Furthermore, a direct DNS lookup of callhome.f5.com using dig, nslookup or host from the command line fails.

Environment

  • Live Update

Cause

System is unable to resolve callhome.f5.com using configured DNS server.

Recommended Actions

Verify that DNS is configured and that there is connectivity to the configured DNS server.

You may wish to check if the DNS server is reachable via a TMM or management route:

ip r g <dns server ip>

You can also take a tcpdump of DNS traffic, for example:

tcpdump -s0 -vnni 0.0:nnn host <dns server ip>

tcpdump -s0 -vnni eth0 host <dns server ip>

Additional Information

Live Updates can also fail for other reasons. For more information see K82512024, or open a service request with F5 Support.
