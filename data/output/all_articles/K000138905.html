K000138905: TMUI Dashboard causes high CPU when ASM, AFM or AVR are provisioned

Type
Support Solution
Published
2024-03-13
Updated
2024-03-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000138905

Description

TMUI Dashboard causes high CPU when ASM, AFM or AVR are provisioned.

Environment

  • BIG-IP, ASM, AFM and AVR
  • Provisioning multiple modules

Cause

Functioning as Designed

This is because several of the REST calls required to provide real time data for these modules are heavy calls that require substantial CPU to run. As they are run on a ten second interval, they will drive up CPU.

Recommended Actions

No action is required.

Additional Information

Prior to 16.1.0, 15.1.4, or 14.1.4.4 high CPU will be seen regardless of provisioning, as we make these REST calls even when ASM, AFM, and AVR are not provisioned. This behavior was changed in ID956293
