Known Issue

This is the result of a known issue. Although a BIG-IP system licensed with a Load Balancer Limited (LBL) license allows an administrator to create UDP profiles and UDP virtual servers, it incorrectly disallows the administrator to use UDP monitors.

F5 Product Development tracked this issue as CR111444 and it was fixed in BIG-IP 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.
