Description

Attempting to load the configuration fails with the Error Message: The requested object name (/Common/xxxx) is invalid.
The log message does not provide enough indications as to where the badly named object is located other than the partition name.

Environment

Configuration objects.
Reserved words.

Cause

The configuration contains an object which has been named using a reserved word.
Note: The list of Reserved words that should not be used in BIG-IP configurations is available in K6869
K6869: Reserved words that should not be used in BIG-IP configurations (10.x - 16.x)

Recommended Actions

1- Search the configuration files to locate the badly named object.
2- Once found, rename the relevant object while avoiding the use of Reserved words listed in  K6869
