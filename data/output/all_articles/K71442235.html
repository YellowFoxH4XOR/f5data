K71442235: BIG-IQ upgrade of single NIC to version 8.0 results in network communication failures

Type
Support Solution
Published
2021-04-08
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K71442235

Description

Upgrading a BIG-IQ with a single NIC to version 8.0 will result in an inoperative management network interface. 

  • The management-ip may respond to ARP but not ICMP or TCP.
  • Stopping the tmm process will result in a working mgmt interface.

Important: Ensure that the BIG-IQ VE instance has at least two NICs before you upgrade from BIG-IQ versions earlier than 8.0.0. For more information, refer to K54221096: A single NIC configuration is not supported prior to BIG-IQ VE 8.0.

Environment

Prior to upgrade to version 8.0 the VM instance has exactly one interface.

  • VM instance with a single interface
  • Command tmsh list net interface lists only the mgmt interface prior to the upgrade to 8.0
  • Command tmsh list net interface lists mgmt and 1.0 interfaces after the upgrade to 8.0
This is typically seen in an environment where DHCP is not configured

Cause

K54221096: A single NIC configuration is not supported prior to BIG-IQ VE 8.0
The issue can be mitigated by following the steps in the Recommended Actions section of this article. 

Recommended Actions

Prevent the issue from occurring prior to upgrading to version 8.0

  1. Power off the BIG-IQ and add an additional interface.
  2. Perform a normal upgrade.

    Note: It is not required to configure this interface to resolve the issue.

Workaround the feature after upgrading to version 8.0

Set the SSL port to 443 using tmsh.

tmsh modify sys httpd ssl-port 443
