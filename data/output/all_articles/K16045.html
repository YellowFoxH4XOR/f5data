Known Issue

Values stored in the session table from an iRule assigned to a parent virtual server cannot be shared with an internal virtual server.

This issue occurs when all of the following conditions are met:

  • A virtual server is configured with a request-adapt or response-adapt profile.
  • An internal virtual server is referenced by the adapt profile.
  • An iRule shares data between the virtual server and the internal virtual server by way of the session table.

Impact

The system cannot use the session table to pass data between a virtual server and an internal virtual server.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The affected iRule and virtual server may not function as expected.
