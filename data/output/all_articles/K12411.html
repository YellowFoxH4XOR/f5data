Known Issue

This is the result of a known issue. An alias of a terminal server favorite will not enforce the disabled auto-logon configuration of the parent terminal server favorite. If the Auto-logon using FirePass user logon credentials: drop-down menu in the terminal server favorite is set to disabled and the Auto-logon to applicable Terminal Servers using FirePass user logon credentials check box is selected from Application Access : Terminal servers : Master Group Settings, a terminal server favorite alias will ignore the main terminal server favorite setting and attempt to auto-logon.   

F5 Product Development is tracking this issue as ID 344887.

Workaround

You can work around this issue by not using a terminal server favorite and configuring a terminal server favorite for each resource group.
