Description

You want to log the real IP address of a Virtual Server hosted on Cloudflare, as the original client IP is changed by Cloudflare to a public IP.

Environment

Client -> Cloud Flare -> BIG-IP-LTM - > Backend servers

Cause

Cloudflare client IP is stored in the header 'CF-Connecting-IP', instead of the 'X-Forwarded-For' header.

Recommended Actions

Write an iRule that uses the request header 'CF-Connecting-IP' to extract the client IP.

Additional Information

Some features of ASM may also need this Cloudflare IP configured in order to function as desired (such as K40120684: Configuring session hijacking protection)
