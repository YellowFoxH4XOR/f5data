Known Issue

The AntiVirus inspector in a pre-logon sequence fails when you use a Firefox 5 or later browser.

This issue occurs when all of the following conditions are met:

  • FirePass is configured to use the Scan active processes for viruses option in the AntiVirus inspector.
  • The user is connecting to FirePass using a Firefox version 5 or later web browser.

Impact

Users are unable to connect to FirePass using the Firefox browser.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The user's computer displays an error message that appears similar to the following example:

    F5 Networks FirePass Host plugin has crashed

  • The user's browser hangs on the Checking running processes for viruses... screen

Workaround

To work around this issue, you can disable the Scan active processes for viruses setting in the Check for AntiViruses action. To do so, perform the following procedure:

Impact of workaround: FirePass will no longer check the running processes for viruses on the client machine.

Important: Every change you make in the Pre-Logon editor will take effect immediately.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. Next to the name of the active pre-logon sequence, click the backup & edit link.

    The Pre-Logon Sequence Editor opens.

  4. Click the Check for AntiViruses action.
  5. Click All-platform antivirus checker under the Inspectors section.

    The Endpoint Inspectors Details editor opens.
  6.  Select disabled from the Perform processes scan drop-down menu. 
  7. Click the Update button.
  8. Click Close Panel.
