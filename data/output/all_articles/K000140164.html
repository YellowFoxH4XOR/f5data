K000140164: Newly received license is not working

Applies to

  • BIG-IP
Source

Description

Installed APM module license for 500 users, however it is not working as expected, still getting 10 connection max.

 

Environment

  • BIG-IP
  • license

 

Cause

  • Did not install the License on both unit.

Recommended Actions

  • License needs to be installed to each device, it is not the target for sync.
  • Check the License is valid with the F5 Sales team.

 

Additional Information

What is installed in each device, you can check in

  • /cofig/bigip.license
  • tmsh show /sys license detail
