Description

Using tmsh, You can delete a self IP without deleting static route that depends on it. This is NOT the expected result and you should encounter error mentioned on  K93641063

Environment

  • You are using route domains which is configured on routes and self IPs
  • You deleted the route domain and self IP config

Cause

This is not the expected result. This is filed under bug ID382409

Recommended Actions

Make sure to also delete all the configuration that depends on the self IP or the route domain to be deleted. If not performed, it may lead to errors in loading the configuration like below:

01070712:3: Cannot get device index for tmm in rd<id> - create socket failed: No such file or directory
