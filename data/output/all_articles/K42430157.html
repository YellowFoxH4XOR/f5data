K42430157: Authority section missing from DNS responses resolved by Wide IP

Type
Support Solution
Published
2021-12-07
Updated
2025-02-06
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP DNS: 14.1.2
Source
https://my.f5.com/manage/s/article/K42430157

Description

A wide IP maps a fully-qualified domain name (FQDN) to one or more pools of virtual servers that host the content of a domain.
When an LDNS issues a DNS name resolution for a wide IP, the configuration of the wide IP indicates which pools of virtual servers are eligible to respond to the request, and which load balancing methods BIG-IP DNS uses to select the pool.
Response provided by Wide IP does not include authority section which would be included if response was provided from ZoneRunner.

Example of the response provided by Wide IP (Authority flag is set to 0 and there's no authority section):

# dig @192.168.1.1 wideip.com

; <<>> DiG 9.11.3-1ubuntu1.15-Ubuntu <<>> @192.168.1.1 wideip.com
(...)
(...)
;; QUESTION SECTION:
;wideip.com.                    IN      A

;; ANSWER SECTION:
wideip.com.             30      IN      A       10.10.10.10

;; Query time: 2 msec
(...)


Example of the response coming from BIND (Authority flag is set and response contains authority section):

# dig @192.168.1.1 wideip.com

; <<>> DiG 9.11.3-1ubuntu1.15-Ubuntu <<>> @192.168.1.1 wideip.com
(...)
(...)
;; QUESTION SECTION:
;wideip.com.                    IN      A

;; ANSWER SECTION:
wideip.com.             0       IN      A       10.10.10.10

;; AUTHORITY SECTION:       <==============
com.                    0       IN      NS      ns1.com.

;; ADDITIONAL SECTION:
ns1.com.                0       IN      A       192.168.1.1

;; Query time: 1 msec
(...)

Environment

  • LDNS
  • Wide IP
  • Authority Section missing from DNS responses
Cause

Unknown at time of publication

Recommended Actions

Create an iRule that inserts authority and additional sections into DNS responses, then assign the iRule to the DNS Listener.

Create the iRule that inserts authority and additional sections into DNS responses:

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Delivery > iRules > iRule List.
  3. Click Create.
  4. Type in unique Name
  5. Under Definition paste the following:
    when DNS_RESPONSE {
        DNS::authority insert "com. 0 IN NS ns1.com."
        DNS::additional insert "ns1.com. 0 IN A <ip_address>"
    }
  6. Click Finished.

Assigning iRule to DNS listener

  1. Navigate to DNS > Delivery > Listeners > Listeners List.
  2. Click on Name of Listener.
  3. Change tab to iRules
  4. Click on Manage...
  5. Move previously created iRule from Available to Selected.
  6. Click Update.
