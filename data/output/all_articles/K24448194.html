Known Issue

Loaded Secure Sockets Layer (SSL) components are not shared among SSL profiles.

When SSL profiles are loaded, large Certificate Revocation Lists (CRLs) and other large components are loaded per profile, rather than being shared among profiles. When many SSL profiles are loaded, increased overall memory consumption occurs and causes low memory conditions.

Impact

The lack of available memory can cause a potential decrease in performance and may cause the Traffic Management Microkernel (TMM) to exit and restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After loading configurations with a large number of SSL profiles, available memory decreases.
  • The BIG-IP system experiences low memory conditions and instability.
  • A TMM core file is generated to the /shared/core directory.

Workaround

There is no workaround for this issue. However, you may be able to mitigate this issue by limiting the number of SSL profiles and large CRLs in your configuration.
