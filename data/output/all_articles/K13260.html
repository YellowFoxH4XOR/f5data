Known Issue

The dpid process may restart and core on system start up if BIG-IP Analytics is provisioned, even though no classification profile is associated with a virtual server.

The underlying failure only occurs at system initialization, and the dpid process correctly restarts to rectify the issue before processing traffic.

Impact

None. The dpid process restart only occurs during startup before traffic processing has commenced.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • A core file that appears similar to the following example may be written to the /var/core/ directory:

    dpid.bld1943.13.core.gz

  • Log messages that appear similar to the following example may be written to the /var/log/daemon.log file:

    emerg logger: Re-starting dpid
