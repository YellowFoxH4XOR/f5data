K55932527: Transfer none HTTP request over virtual server with HTTP profile

Support Solution
Published
2025-06-18

Applies to

  • BIG-IP LTM: 17.0.0, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X
Source

Description

Sometimes an application might send none-standard HTTP request (e.g. rstp request) to virtual server which has HTTP profile attached, then virutal server might unable to parse it and block following HTTP reqeuest in the same connection.

Environment

  • Virtual server with HTTP profile
  • Recevie a none-standard HTTP request (e.g. OPTION RTSP/1.1)

Cause

With HTTP profile enabled on one virtual server, BIG-IP will fail to parse such request and block following HTTP request in the same connection. 

Recommended Actions

We can use following irule to allow such request by disable HTTP for a single request:

when HTTP_REQUEST {
     if { [HTTP::method] equals "OPTIONS" } {
          log local0. "Disable HTTP for HTTP method ([HTTP::method]) attempted by [IP::client_addr]"
          set xx 1
     } 
}
when HTTP_RESPONSE {
     if { $xx == 1 } {
        HTTP::disable
     }
}
