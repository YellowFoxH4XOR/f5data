To add trunked ports to a VLAN or add a VLAN to a trunked port, you must complete the following tasks:

  • Create a trunked port.
  • Create a VLAN.
  • Add a trunked port to a VLAN as a tagged interface.

Note: Refer also to K3018: Connecting BIG-IP and Cisco devices with a Cisco Fast EtherChannel trunk.

Creating a trunked port

To create a trunk on BIG-IP, use the following syntax:

b trunk <primary_port> define <secondary port(s)>

For example, the following command creates a trunk with a primary port of 1.10 and a secondary port of 1.11:

b trunk 1.10 define 1.11

The following example creates a trunk with a primary of 1.10 and secondaries of 1.4, 1.6, and 1.11:

b trunk 1.10 define 1.11 1.4 1.6

Note: F5 Networks recommends that you use the exponent of 2 (2, 4, 8, 16, and so forth) for the number of interfaces in a trunk. Other numbers will work, but will not be as efficient as using an exponent of 2.

Once created, you can run the b trunk show command to display the trunk configuration. For this example, the output would appear as follows:

1.10    200     66   1.5K      0      0  45.9K   1.1M      1
1.10    400     66   1.5K      0      0  45.9K   1.1M      1

Note: The 200 and 400 in this output is the total speed of the trunk. 200MB per second for the trunk containing only two ports and 400MB per second for the trunk containing four ports.

After you create and confirm the trunk, you can control it exclusively by issuing commands to the primary of the trunk. This includes adding the trunk to a VLAN.

Creating a VLAN from the command line

To create a VLAN from the command line, use the following syntax:

Note: If you plan on having more than one VLAN per trunk, you must know the VLAN/tag number that correlates with the tag on the opposing end of the connection, such as a Cisco switch.

b vlan <vlan_name> tag <tag #>

For example:

b vlan test tag 50

VLANs are not tagged or untagged. The tag associated with a VLAN is used for identification purposes and also to show what the tag will be, when tagging is used to allow multiple VLANs on the same cable. The VLAN tag is used only externally for any interface that is added as a tagged interface.

Adding interfaces to VLANs

You can add two types of interfaces to VLANs:

  • Tagged
  • Untagged

To add a tagged interface (trunk or otherwise) to the VLAN, use the following syntax:

b vlan <vlan_name> interfaces add {tagged} <ports>

For example:

b vlan test interfaces add tagged 1.10

This command adds the 1.10 trunk to the test VLAN as a tagged interface. That means that the VLAN tag will be placed on packets passing through that trunk and the VLAN tag will be required on all packets received on that trunk.

To add an untagged interface (trunk or otherwise) from the command line, use the following syntax:

b vlan test interfaces add 1.10

Once you have added the interface, you can type the following command to view its configuration:

b vlan <vlan> show

For example:

b vlan test show

The output will appear similar to the following for a tagged interface:

VLAN test
tag                  50
port_lockdown        Disabled
failsafe             Disarmed
timeout              30
tagged interfaces 1.10

The output will appear similar to the following for an untagged interface:

VLAN test
tag                  50
port_lockdown        Disabled
failsafe             Disarmed
timeout              30
untagged interfaces  1.10
