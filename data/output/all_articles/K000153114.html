Description

You want to see the status of UCS backup of managed BIG-IP on BIG-IQ using API calls.

Environment

  • BIG-IQ
  • Managed BIG-IPs

Cause

None

Recommended Actions

Below link will show all the backup, managed BIG-IP and BIG-IQ
https://<BIG-IQ management IP>/mgmt/cm/system/backup-restore

Below link will show BIG-IQ's backup
https://<BIG-IQ management IP>/mgmt/tm/shared/sys/backup

For example to test you can run below command syntax to generate a token and save the token in TOKEN. Referring REST API call to BIG-IQ to create BIG-IP UCS Backup.
TOKEN=$(curl -ks -X POST -d "{'username':<username>, 'password':<password>, 'loginProviderName':<login provider> }" https://<BIG-IQ>/mgmt/shared/authn/login | jq .token.token)

For example:
TOKEN=$(curl -ks -X POST -d "{'username':admin, 'password':admin, 'loginProviderName':tmos}" https://<BIG-IQ>/mgmt/shared/authn/login | jq .token.token)

Then you can do curl to retrieve the backup status.
curl -ks -H "X-F5-Auth-Token: $TOKEN" 'https://<BIG-IQ management IP>/mgmt/cm/system/backup-restore' | jq
curl -ks -H "X-F5-Auth-Token: $TOKEN" -X GET https://<BIG-IQ management IP>/mgmt/tm/shared/sys/backup | jq
