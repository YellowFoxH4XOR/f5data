Description


For BIG-IP Edge Clients to automatically attempt an upgrade when connecting to a BIG-IP APM or BIG-IP Edge Gateway access profile, the BIG-IP APM or BIG-IP Edge Gateway system-side's connectivity profile Component Update setting should be set to Yes.
The setting on the APM connectivity profile takes precedence over the setting in the BIG-IP Edge Client, which makes the value in the BIG-IP Edge Client effectively redundant.

Recommended Actions

To check/change the current component update setting configured on connectivity profile :

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity > Profiles.
Note: For BIG-IP 12.x and earlier, go to Access Policy > Secure Connectivity.
  1. Select the connectivity profile that is associated to your network access virtual server.
  2. Select Edit Profile.
  3. Select Win/Mac Edge Client.
  4. Check Component Update setting or change it as per requirement.
  5. Select OK.
