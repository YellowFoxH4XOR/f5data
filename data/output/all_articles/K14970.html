Known Issue

Layered virtual servers with matching destination addresses do not process MobileSDK and JavaPatcher traffic.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with the RDP type of remote desktop application access.

    Note: This known issue does not apply to configurations that use Citrix or VMware View remote desktop selections.
  • You enable the Java Client option on the remote desktop resource configuration, or you configure the resource to use an application built using the MobileSDK.

You can configure the BIG-IP APM system to provide remote desktop application access for Citrix, RDP, or VMware View. When RDP is selected and either the Java Client option is enabled or the service is provided by a custom application using the MobileSDK, application traffic is not sent to layered virtual servers even though the destination address of the traffic matches the virtual server's configured listener.

Impact

Application traffic with a destination address that matches a layered virtual server is sent directly to the destination by the BIG-IP APM system, and the traffic bypasses layered virtual server processing.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H439224 on the Diagnostics > Identified > Medium screen.
  • iRules and other configuration elements on the matching layered virtual server are not applied to application traffic.
