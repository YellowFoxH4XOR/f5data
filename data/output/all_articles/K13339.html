Topic

You should consider using this procedure under the following condition:

  • You require the BIG-IP system to process jumbo Ethernet frames.

Description

By default, the BIG-IP system uses the standard Ethernet frame size of 1518 bytes (1522 bytes if VLAN tagging is used) with the corresponding maximum transmission unit (MTU) of 1500 bytes for a VLAN. On BIG-IP systems that support Jumbo Frames, you can configure individual VLANs to use them by changing the MTU setting of the associated VLAN.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your hardware and software combination supports Jumbo Frames. For supported combinations, refer to K6399: Support for jumbo Ethernet frames.
  • To avoid any disruption of traffic, you must ensure that the neighboring network devices support the Ethernet frame size that is configured on the BIG-IP system.

Procedures

To configure an existing VLAN on the BIG-IP system to use the supported jumbo Ethernet frame sizes, perform one of the following procedures:

Note: For vCMP systems, this procedure should  be performed on vCMP guest. For more information, refer to K15930: Overview of vCMP configuration considerations.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Configuration utility

Note: When configured, the Ethernet frame size takes effect immediately on the BIG-IP system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > VLANs.
  3. Click VLAN List.
  4. Click the name of the VLAN.
  5. In the MTU box, type the value of the frame size.
  6. Click Update.

TMOS Shell 

Note: When configured, the Ethernet frame size takes effect immediately on the BIG-IP system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To modify the MTU of a VLAN, use the following command syntax:

    modify /net vlan <vlan name> mtu <mtu size>

    For example, you would type the following command to modify the MTU of vlan1158 to 9198:

    modify /net vlan vlan1158 mtu 9198

  3. Save the change by typing the following command:

    save sys config

    Verify the Proxy-MSS and MSS settings in the TCP profile ( K50411377 ) are appropriate for your environment if you want the MSS to reflect the MTU size when using jumbo frames.
