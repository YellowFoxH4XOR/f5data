Known Issue

The chassis fan speed reported by the BIG-IP or Enterprise Manager system and by the End-User Diagnostics (EUD) utility may be inaccurate.

This issue occurs when any of the following conditions are met:

  • The BIG-IP software is running on the BIG-IP 3900 platform
  • The Enterprise Manager software is running on the EM 4000 platform

This issue has been attributed to noise on the fan tachometer line that corrupts the data supplied by the fans to the EUD and the host system.

The recommended minimum chassis fan speed for the affected platforms is 3000 RPM.

Impact

Reported chassis fan speeds that fall outside the specified range must be manually verified.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H375485 on the Diagnostics > Identified > Critical screen.
  • Fan speed is reported by the EUD as higher or lower than the actual fan speed

    For example, the EUD may report the following error message:

    ERROR: Fan4 speed is too low

    When this error is encountered, the EUD fan tests fail.

  • The following message is logged repeatedly to the kernel buffer and displayed by the dmesg command:

    emerg system_check[6462]: 010d0005:0: Chassis fan 1: status (0) is bad.

  • The bigpipe platform show command shows the following fan status:

    down! - 0rpm

  • The bigpipe platform show command may report inaccurate fan speeds which may vary widely between individual tests
  • The BIG-IP system may send SNMP traps indicating fan failure

Workaround

You can manually verify the actual fan speed by performing the following procedure.

Impact of workaround: The following procedure should not have a negative impact on your system.

  1. Access the BIG-IP Traffic Management Shell (tmsh) console.
  2. Enter the following command to display the current time:

    run /util bash -c "date"

    An output similar to the following is displayed:

    Tue Aug 16 14:50:10 PDT 2011

  3. Enter the following command to display the reported speed for all chassis fans:

    show /sys hardware | grep 'Chassis Fan Status' -A 5

    An output similar to the following is displayed:

    Chassis Fan Status
    Index Status Fan Speed(rpm)
    1 up 9642
    2 up 9642
    3 up 9121

  4. If any fan reports a speed lower than 3000 RPM, wait two minutes and run the command in step 3 again.

If any of the reported values for a given fan are above the 3000 safe minimum operating speed, the fan is operating as expected, and the errant readings are a result of this known issue.

If none of the reported values for a given fan are above the 3000 safe minimum operating speed after performing this test five times, the fan may have failed and the chassis should be replaced. Follow the instructions in K13000: Return Materials Authorization request to request a Return Materials Authorization (RMA) replacement of the chassis. Include the output from the tests above in the Diagnostic Information section.
