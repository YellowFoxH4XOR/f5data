Known Issue

The Traffic Management Microkernel (TMM) may experience false port exhaustion and produce a core file.

This issue occurs when the following condition is met:

  • The system has a connection with approximately 500 active server-side flows.

TMM uses the random port selection method, which may cause a rare condition in which TMM is unable to allocate a port for a server-side connection. When this issue occurs, TMM stops the client-side connection. While processing the stopped  connection flow, TMM may encounter a NULL conflow and produce a core file.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H446699 on the Diagnostics > Identified > Medium|High screen.
  • TMM may experience false port exhaustion and log an error message that appears similar to the following example:

    crit tmm[tmm_pid]: 01010201:2: Inet port exhaustion on 172.16.1.10 to 172.16.2.100:80 (proto 6)

  • TMM may produce a core file and temporarily fail to process traffic.
