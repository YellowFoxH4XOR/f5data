Topic

This article applies to BIG-IP APM support for elements and attributes in Security Assertion Markup Language 2.0 (SAML 2.0).

Description

The OASIS Security Assertion Markup Language (SAML) core specifications describe the structure and content of SAML assertions and protocols. Assertions are generated and sent by an Identity Provider (IdP) to make claims or assertions about a subject's authenticity and attributes for a service provider (SP) to make authorization decisions. The most important SAML protocol is the Authentication Request (AuthnRequest) protocol, which specifies how an SP sends AuthnRequests to an IdP for authentication and authorization. Assertions and AuthnRequests are made up of system entities called elements. SAML attributes are name value pairs that describe the characteristic or trait of an entity.

When you configure the BIG-IP APM as a SAML SP, BIG-IP APM can generate elements and attributes in AuthnRequests and send them to an IdP for authentication and authorization. The following table lists the supported SAML 2.0 elements and attributes in an AuthnRequest generated by BIG-IP APM.
