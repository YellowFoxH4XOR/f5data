Topic

RSA SecurID is a two-factor authentication scheme that uses a combination of a known password and a digitally generated string to grant access to the FirePass controller.

Note: For more information about RSA SecurID authentication, refer to the FirePass Controller Administrator Guide and the RSA SecurID Ready Implementation Guide.

To configure RSA SecurID authentication on a FirePass standalone controller, perform the following two procedures:

  • Configuring the Agent Host record on the RSA server
  • Configuring RSA SecurID authentication on the FirePass controller

Configuring the Agent Host record on the RSA server

Note: The following RSA configuration steps are for RSA Authentication Manager 6.1. The build version can be found from your RSA Authentication Manager GUI under Help: About Database Administration.

To configure the Agent Host record on the RSA server, perform the following procedure:

  1. Create a FirePass controller Agent Host.

    For example:

    Name: "firepass.example.com"
    Network address: <real/self or NAT translated IP address of the FirePass node>

    Important: Because the FirePass controller is a multi-homed appliance with multiple IP addresses, the Network address setting is important. If there is a NAT device between the FirePass controller and the RSA authentication server, enter the translated IP address of the FirePass controller. If there is not a NAT device between the FirePass controller and the RSA authentication server, enter the real/self IP address of the FirePass controller. If multiple interfaces are configured on the FirePass controller, enter the real/self IP address of the interface which routes to the RSA authentication server.

    Agent type: Unix Agent
    Encryption Type: DES
    Secondary Nodes: <none>
    Other settings: For the remaining Agent Host settings, configure the settings appropriate for your environment.

  2. Generate and download the configuration file for the FirePass Agent Host you created.

    Note: This configuration file is typically named sdconf.rec.

  3. Activate the FirePass Agent Host for group and/or user profiles that require access to the FirePass controller.

Configuring RSA SecurID authentication on the FirePass controller

To configure RSA SecurID authentication on the FirePass controller, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Configuration: RSA SecureID page.
  3. In the Name field, enter a name to identify your RSA server.

    Note: This name is for local use and does not need to be DNS resolvable.

    For example:

    rsasrv1

  4. In the Configuration File field, enter the full path to the Agent Host configuration file you downloaded in Step 2 of the Configuring the Agent Host record on the RSA Server procedure.

    For example:

    C:\sdconf.rec

  5. In the Source IP field, enter the IP address you configured for the Network address setting on the RSA authentication server.

    Important: RSA authentication will not work unless the IP address you enter in this field matches the IP address you entered for the Network address setting in Step 1 of the Configuring the Agent Host record on the RSA Server procedure.
  6. Click the Add button.
  7. Navigate to the Users: Groups: Master Groups page.
  8. Click the Create new group button.
  9. In the New group name field, enter the name of the new master group.
  10. In the Users in group field, select Local or External.
  11. In the Authentication Method menu, select RSA SecurID.
  12. Click the Create button.

    This step brings you to the master group configuration page.
  13. Click the Authentication tab.
  14. Under Configure RSA SecurID Server Settings, select the RSA configuration profile that you created.
  15. Click the Update button.

The FirePass controller is now configured for RSA SecurID authentication.
