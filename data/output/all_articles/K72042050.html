Known Issue

A Secure Sockets Layer (SSL) handshake may fail when the ClientHello message is sent in multiple packets.

This issue occurs when the following condition is met:

  • The BIG-IP system receives an SSL ClientHello message that is split across multiple TCP segments, and the last segment is relatively small.

Impact

SSL connections fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SSL clients experience intermittent SSL handshake failures.
  • If SSL debug logging is enabled, you observe an error message in the /var/log/ltm file similar to the following example:

    01260009:7: Connection error: ssl_hs_rxhello:6210: ClientHello contains extra data (47)
