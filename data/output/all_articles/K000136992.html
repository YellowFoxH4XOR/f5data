K000136992: Downgrade Amazon CloudHSM client version from 3.4.4. to 3.2.1

Type
Support Solution
Published
2023-09-26
Updated
2026-03-12
Applies to
  • Public Cloud
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K000136992

Description

In HSM/CloudHSM deployments F5 guides customer to follow the F5-BIGIP-HSM vendor interoperability matrix to determine which BIG-IP, vendor firmware/software and client software versions to use.

As a result of that, sometimes customer that might need to downgrade client version to align with the IOT matrix.

This article provides a guidance on how to downgrade Amazon CloudHSM client version from 3.4.4 to 3.2.1. But this is true for any Amazon CloudHSM version used.

Environment

  • Amazon CloudHSM: versions 3.4.4 and 3.2.1.

Cause

This is a "how-to" article.

Recommended Actions

Below are the required steps to perform downgrade.

1. Uninstall the 3.4.4 client form bash:

rpm -e cloudhsm-client-pkcs11-3.4.4-1.el6.x86_64

[admin@ip-XXXX:Active:Standalone] nethsm # rpm -e cloudhsm-client-3.4.4-1.el6.x86_64

warning: /opt/cloudhsm/etc/cloudhsm_mgmt_util.cfg saved as /opt/cloudhsm/etc/cloudhsm_mgmt_util.cfg.rpmsave

warning: /opt/cloudhsm/etc/cloudhsm_client.cfg saved as /opt/cloudhsm/etc/cloudhsm_client.cfg.rpmsave

userdel: user hsmuser is currently used by process 11853

groupdel: cannot remove the primary group of user 'hsmuser'

Note: These are linux errors related to user/group used by pkcs11d process. They can be ignored.

2. Confirm that client was indeed gone:

# service cloudhsm-client status

Redirecting to /bin/systemctl status cloudhsm-client.service

Failed to get properties: Access denied

Note: This is expected as the client is uninstalled.

3. Now restarting pkcs11d to make sure it will clean out any references to the previously installed client.

bigstart restart pkcs11d

4. Install the 3.2.1 client and the pkcs11 package:

rpm -ivh cloudhsm-client-3.2.1-1.el6.x86_64.rpm

Steps Summary:

1. Uninstall 3.4.4 client:

rpm -e cloudhsm-client-pkcs11-3.4.4-1.el6.x86_64

rpm -e cloudhsm-client-3.4.4-1.el6.x86_64

2. Install 3.2.1 client:

rpm -ivh cloudhsm-client-3.2.1-1.el6.x86_64.rpm

rpm -ivh cloudhsm-client-pkcs11-3.2.1-1.el6.x86_64.rpm

3. Reload daemon

systemctl daemon-reload

4. Restart pkcs service:

bigstart restart pkcs11d
