Known Issue

The Diameter monitor script does not allow custom grouped Attribute-Value-Pairs (AVPs) that contain only a single element.

This issue occurs when the following condition is met:

  • You are using a Capabilities-Exchange-Answer (CEA) diameter command with a custom grouped AVP containing a single attribute.

Impact

A monitored diameter server may incorrectly be marked down.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Affected diameter servers are marked down.

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can use multiple attributes or use a non-custom grouped-AVP.
