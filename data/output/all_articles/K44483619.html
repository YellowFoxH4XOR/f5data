Description

HTTP POST request may fail causing HTTP service errors e.g. HTTP 503. The actual error is depends on application

Environment

  • HTTP profile in use
  • Pool members replies with HTTP 100 Continue
  • HTTP 100 Continue response is split into more then one packet

Cause

The issue is caused by a Bug ID851857.

Recommended Actions

Upgrading to the version where the bug is fixed.

None
