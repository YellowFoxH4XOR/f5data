Known Issue

External monitors may appear to not synchronize to the members of a BIG-IP DNS (formerly BIG-IP GTM) synchronization group.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP DNS system is configured as part of a DNS synchronization group.
  • The synchronization group members are not configured as part of a BIG-IP LTM device group.
  • Your BIG-IP DNS configuration includes external monitors.
  • The local BIG-IP DNS configuration synchronizes to the DNS synchronization group.

Impact

Synchronization appears to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • At the time of synchronization, in the /var/log/gtm file, you observe log messages similar to the following example:

    err iqsyncer[20361]: 011ae104:3: Gtm config sync result from local mcpd: result { result_code 17237778 result_message "01070712:3: Values(/<partition>/<external monitor script name>) specified for external monitor parameter (/<partitiopn>/<monitor name> 2 RUN_I=): foreign key index (to_file) do not point at an item that exists in the database." }

  • After the failed synchronization, when you examine the receiving synchronization group members, the system synchronizes the configuration, including the external monitors.

Resolution

Status

F5 Product Development has assigned ID 511865 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Workaround

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

To work around this issue, you can create a BIG-IP LTM sync-only device group that includes the members of the DNS synchronization group. For more information, refer to K13649: Creating a device group using the Configuration utility.
