K000137809: Export ASM Policy through automation framework failed

Type
Support Solution
Published
2023-12-06
Updated
2023-12-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000137809

Description

  • Exporting of ASM policy via rest API failes with Error 500 AsyncContext timeout
  • A log message similar to the following is logged on /var/log/restjavad.log

[WARNING][825][17 Nov 2023 06:16:05 UTC][8100/mgmt ForwarderPassThroughWorker] URI:http://localhost:8100/mgmt/tm/asm/tasks/export-policy, Referrer:192.168.0.1, Method:POST, Exception:java.util.concurrent.TimeoutException: remoteSender:192.168.0.1, method:POST

Environment

  • ASM
  • Rest API
  • Timeout

Cause

Rest API request failing due to hitting the default 60-second timeout.

Recommended Actions

Please increasing the timeouts from the default 60 second values and then restart the associated services:

tmsh modify sys db icrd.timeout value 180
tmsh modify sys db restjavad.timeout value 180
tmsh modify sys db restnoded.timeout value 180

Save changes and restart related services:

tmsh save sys config
tmsh restart sys service restjavad
tmsh restart sys service restnoded

Additional Information

None
