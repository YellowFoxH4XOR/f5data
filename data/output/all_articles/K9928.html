Known Issue

This is the result of a known issue. Enabling the SSLEAY 080 CLIENT DH BUG clientssl profile option using the Configuration utility mistakenly enables many unrelated clientssl profile options, including No SSLv2, No SSLv3 and No TLSv1. Enabling these profile options together prevents further SSL connections to the virtual server.

F5 Product Development tracked this issue as CR114154 and it was fixed in BIG-IP 10.0.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You may temporarily work around this issue and enable the SSLEAY 080 CLIENT DH BUG profile option using the following bigpipe command:

bigpipe profile clientssl testDH options SSLEAY_080_CLIENT_DH_BUG

Important: If you attempt to work around this issue using the command line, and then click the Apply button for the profile using the Configuration utility, the additional unrelated clientssl options are added to the profile.
