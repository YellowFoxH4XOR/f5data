Description

When deploying F5 BIG-IP SSLO (SSL Orchestrator),  TCP connection resets (RST) may occur. Packet captures can reveal that the F5 device sends RST packets after receiving certain responses from downstream devices, such as WAFs or firewalls. TCP reset causes like "{peer} connector abort".

Environment

  • Product: F5 BIG-IP SSLO
  • Version: 17.1.1
  • Firewall in SSLO Service enable "one connect" or similar function

Cause

OneConnect mechanisms enabled on downstream firewalls or WAFs allow multiple HTTP requests from different clients to be sent over the same TCP connection. 

Recommended Actions

  • Disable OneConnect or similar features on Firewalls/WAFs so each TCP connection is used for only one session/transaction.
  • Make sure what comes in from client and what goes out to server in one TCP connection.
