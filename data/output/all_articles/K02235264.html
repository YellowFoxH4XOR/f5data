K02235264: Scripts run by BIG-IQ Script Management may be truncated

Type
Support Solution
Published
2020-11-20
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K02235264

Description
Scripts run in  BIG-IQ Script Management that result in large output are truncated due to BIG-IQ limiting script output to 24576 bytes

Environment

  • BIG-IQ
  • Script Management used to run commands on BIG-IP devices
  • BIG-IP

Cause
Known issue: ID938385 - BIG IQ: BIG-IQ limits script output to 24576 bytes
The value is hardcoded

Recommended Actions

Limit commands run via script to those with output within the limit
Run commands with larger output directly on the BIG-IP
