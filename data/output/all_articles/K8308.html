Topic

When running the Policy Wizard, you can define a Trusted IP list that specifies either a range or list of IP addresses considered by the Policy Wizard to be safe addresses.

The Policy Wizard accepts valid class IP ranges, and subnet IP ranges. For example, the following Class C IANA Reserved Private Network Range is accepted by the Policy Builder:

192.168.0.0 - 192.168.255.255

However, the following IP range is not considered to be valid, and is not supported by the Policy Wizard:

0.0.0.0 - 255.255.255.255

If the 0.0.0.0 - 255.255.255.255 IP address range is entered in the Policy Wizard Trusted IP list, no error message will display; however, the range will not appear on the Policy Configuration Summary page before the Policy Wizard completes. When running the Policy Builder, F5 Networks recommends using valid ranges when defining IP ranges for the Trusted IP list.
