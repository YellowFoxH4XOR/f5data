Known Issue

The BIG-IP system incorrectly handles HTTP2 data frames that are larger than the minimum frame size.

This issue occurs when all of the following conditions are met:

  • You configure an HTTP2 profile on a virtual server.
  • The client sends a data frame larger than 16,384 bytes, violating the Request for Comment (RFC).

    Note: The receiving maximum frame size of the BIG-IP system is permanently set at 16,384 bytes.

Impact

HTTP2 resets the stream with "FLOW_CONTROL_ERROR."

Symptoms

As a result of this issue, you may encounter one of the following symptoms:

  • The HTTP2 frame size can vary between 16 kilobytes (KB), which are included, and 16 megabytes (MB), which are not included.
    • When a client sends a data frame larger than 16,384 bytes, the BIG-IP system may incorrectly process it, rejecting the whole connection.
    • When the proxy flow control is disabled, the system creates an additional window update frame.
    • When the proxy is in flow control, the system issues a flow control error.
