Description

Events (/ui/events) and Security Monitoring Events (/ui/security/monitoring/dashboard?view=event-logs) fail to populate.

Symptoms:

  • Events and Security Monitoring Events do not populate
  • Events ui displays errors:  
    Invalid filter query parameter key.
  • Errors in /var/log/nms/nms.log:  
    [ERROR]#011clickhouse-mgr #011clickhouse/clickhouse.go:199 #011apply migrations failed: failed applying migrations: Dirty database version 41. Fix and force version.

[ERROR]#011nms-core #011errors/http.go:76 #011http failure with code '4024': Invalid filter param key: 'publication_uuid'

Environment

NMS

Cause

Clickhouse database corruption

Recommended Actions

Remove/rebuild clickhouse database schema_migrations :

  • Access clickhouse cli:  
    clickhouse-client [--password <password>]
  • Remove table schema_migrations:  
    :) drop table schema_migrations;
:) q
  • Restart clickhouse server and nms:  
    sudo systemctl restart clickhouse-server.service
sudo systemctl restart nms
