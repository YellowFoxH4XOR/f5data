K000152165: Unable to access F5 via EC2 serial console on AWS

Type
Support Solution
Published
2025-06-27
Updated
2025-06-27
Applies to

  • BIG-IP LTM: 17.1.1
Source

Description

Unable to access F5 BIG-IP LTM via the EC2 serial console on AWS. Attempts to connect using the AWS EC2 serial console fail. No specific error messages are provided, but access is not granted through the serial console.

Environment

  • F5 BIG-IP LTM
  • AWS Cloud platform

Cause

The IAM policy associated with the EC2 instance does not include the required permissions to allow access to the EC2 serial console. The existing IAM policy is missing explicit permissions for serial console actions.

Recommended Actions

Ensure that the IAM policy attached to the user or role accessing the EC2 serial console includes these permissions:

"ec2:GetSerialConsoleAccessStatus",
"ec2:EnableSerialConsoleAccess",
"ec2:DisableSerialConsoleAccess"

Follow the guidance in Configure access to the EC2 Serial Console for detailed steps and example policies.
