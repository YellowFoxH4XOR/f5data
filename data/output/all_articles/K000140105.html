Description

A false positive violation triggered for Microsoft Clarity, due to attack signature:

ID 200003141 - “Unix/Linux "fmt" execution attempt (Parameter)”

Environment

  • Attack signatures from Unix/Linux Systems applied.
  • Microsoft Clarity library for analytics.

Cause

A recent change in Microsoft Clarity modified the cookie format to include "fmt" inside pipe ("|") characters, Unix and Linux use the pipe character to pipe command output between commands and therefore the cookie appears to be an attempt to execute the fmt command.

Since 200003141 is a low accuracy signature, WAF Product Engineering has elected to recommend disabling it when Microsoft Clarity is in use.

Recommended Actions

The recommended action when getting this false positive is to disable the signature.
