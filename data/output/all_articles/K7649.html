K7649: Launching Legacy Host Favorites directly from an Intranet Webtop

Topic

A new feature was introduced in Cumulative Hotfix HF-601-5 for version 6.0.1 of FirePass software that allows you to launch Legacy Host Favorites directly from the Intranet webtop. Previously, the Intranet webtop could link to a list of Legacy Host Favorites, and you could launch the desired Legacy Host Favorite from that list.

To create a link to launch a Legacy Host Favorite from the Intranet webtop, obtain the name of the Legacy Host Favorite you want to launch and the Resource Group to which it is assigned. You can locate this information on the Application Access : Legacy Hosts : Resources page in the FirePass Administrative Console. To create a link to launch the YourServer Legacy Host Favorite from the Intranet webtop, add the following source code to your Intranet webtop web page:

<script type="text/javascript">
function createTermConnection(params)
{
var w_name = 'TERM_CONNECTION'+(Math.random()).toString().substring(2,16);
childWindow = window.open('https:/vdesk/h3270/connect.php'+params, w_name,
'name='+w_name+',resizable=1,scrollbars=0,
statusbar=0,menubar=0,width=512,height=300',
false);
}
</script>

<a href='javascript:createTermConnection
("?res_group=Default_resource&res_name=YourServer")
'>YourServer Terminal</a>

Note: Replace YourServer with the name of your Legacy Host Favorite and replace Default_resource with the name of the Resource Group to which the Legacy Host Favorite is assigned.

When users click on the YourServer Terminal link, the Legacy Host Favorite named YourServer will launch in a pop-up window.

F5 Networks Product Development tracked an enhancement for this issue as CR80242 and it was included in version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, F5 Networks Product Development introduced this feature in Cumulative Hotfix HF-601-5 for version 6.0.1 of FirePass software. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Note: Your Firepass controller must be licensed for the UNIX SYSTEM ADAPTER module. Licensed features are listed on the Device Management: Maintenance: Activate License page.
