Known Issue

The BIG-IP system repeatedly retransmits TCP segments when tm.enforcepathmtu is disabled and the system receives IPv4 ICMP Fragmentation Needed messages.

This issue occurs when all of the following conditions are met:

  • The system receives an ICMP Fragmentation Needed message.
  • The BIG-IP database variable tm.enforcepathmtu is disabled.

Impact

The system retransmits the TCP segment each time it receives an ICMP Fragmentation Needed message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the BIG-IP system receives an IPv4 ICMP Fragmentation Needed message and has tm.enforcepathmtu disabled, the system does not update the path maximum transmission unit (PMTU) for the connection. However, the TCP profile retransmits unacknowledged data at the existing PMTU size, generally resulting in further ICMP Fragmentation Needed messages and subsequent retransmissions.
  • Monitored BIG-IP interfaces report a large number of TCP profile retransmissions.

Workaround

To work around this issue, you can disable tm.enforcepathmtu. To do so, perform the following procedure.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: Disabling tm.pathmtudiscovery causes the BIG-IP system to transmit IP messages without setting the Don't Fragment option.

Disabling tm.enforcepathmtu

  1. Log in to the command line.
  2. Disable tm.enforcepathmtu using the following syntax:

    tmsh modify sys db tm.pathmtudiscovery value disable
