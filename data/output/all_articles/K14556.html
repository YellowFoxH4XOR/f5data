Known Issue

BIG-IP systems using copper 1 Gbps CuSFP modules (OPT-0015-00) configured with media other than the auto setting may not function correctly.

This issue occurs when all of the following conditions are met:

  • The interface using a 1 Gbps CuSFP module is configured for 10 Mbps or 100 Mbps (full or half duplex).
  • The platform is rebooted or services are restarted using the bigstart restart command sequence.
  • The 1 Gbps CuSFP module is installed in one of the following platforms:

    • 1600, 2000s, 2200s, 3600, 3900, 4000s, 4200v, 6900, 8900, 8950, 11000, 11050
    • VIPRION 2400 with the B2100 blade
    • VIPRION 4400 with the following blades B4100 (PB100), B4200 (PB200)

When the 1 Gbps module is initially configured for 10 Mbps or 100 Mbps (full or half duplex) the interface will work as expected. However, after you perform a reboot or the bigstart restart command, the 1 Gbps modules will not initialize.

Impact

The 1 Gbps CuSFP interfaces will not initialize and will not have network connectivity.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425804 on the Diagnostics > Identified > Medium screen.
  • After you reboot the platform, the configuration displays error messages on the console that appear similar to the following example:

    err mcpd[4754]: 01070318:3: The requested media for interface 2.1 is invalid.
    err bcm56xxd: 012c0010:3: Media setting: 0x10021 not on the option list of port:4 bs_media.c(461)
    err bcm56xxd: 012c0010:3: Trouble setting media type for 2.1 bsx.c(984)
    err mcpd[4754]: 01070318:3: The requested media for interface 2.1 is invalid.
    err mcpd[4754]: 01070318:3: The requested media for interface 2.1 is invalid.
    err mcpd[4754]: 01070318:3: The requested media for interface 2.1 is invalid.
    err mcpd[4754]: 01070318:3: The requested media for interface 2.1 is invalid.

  • After you perform the bigstart restart command, error messages display on the console that appear similar to the following example:

    The requested media for interface 2.1 is invalid. Unexpected Error: Loading configuration process failed.
    err mcpd[7663]: 01070422:3: Base configuration load failed.

  • After you perform a reboot or the bigstart restart command, network connectivity does not function for CuSFP modules that are configured with the 10 Mbps or 100 Mbps media settings.

Workaround

You can work around this issue by configuring the media speed settings to auto for all interfaces that use the 1 Gbps CuSFP module. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

Reconfiguring the CuSFP interface media settings

Important: To ensure network connectivity, you should set both the BIG-IP LTM system and the destination network device (switch) media settings to auto.

To reconfigure interfaces to use the auto speed setting, perform the following procedure:

  1. Log on to the Configuration utility.
  2. Navigate to Network > Interfaces.
  3. Select the interface that has the 1 Gbps CuSFP module.
  4. Set the Fixed Requested Media to auto.
  5. Click Update.
  6. Set the Fixed Requested Media to the desired media settings.
  7. Click Update.
