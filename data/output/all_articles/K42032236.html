F5 Application Connector components

F5 Application Connector is delivered as two components, the Application Connector service center, which is deployed onto an F5 BIG-IP system, and the Application Connector proxy, which is deployed onto a cloud.

Version schema definitions

F5 uses the following three-digit software version schema:

The definitions for the version schema are as follows:

  • Major release

    Major releases include significant changes in behavior, added functionality, significant increases in performance, new hardware support, and/or significant architectural changes.

  • Minor release

    Minor releases include added functionality, increases in performance, new hardware support, and they address product defects.

  • Maintenance release

    Maintenance releases are denoted by a value of 1 or higher in the maintenance release version element. A maintenance release contains all previous cumulative hotfixes and addresses additional product defects and security fixes. These releases may also contain new diagnostic and supportability improvements or new hardware support; however, no change in existing default behavior or new product functionality will be introduced.

F5 Application Connector service center software support policy

F5 provides six months of support for major (X.0.0) F5 Application Connector service center versions starting from the first customer ship date of a given release. Customers who require support beyond the standard six-month period should contact their F5 account manager.

F5 provides 12 months of support for minor (x.X.0) F5 Application Connector service center versions starting from the first customer ship date of a given release. Subsequent maintenance releases (x.1.1 to x.n.n) address product defects, security fixes, diagnostic and supportability improvements, and new hardware support. Software development support activities occur on only the latest maintenance release of each long-term stability release (x.latest.latest). Customers who require support beyond the standard 12-month period should contact their F5 account manager.

F5 Application Connector proxy software support policy

F5 provides 12 months of support for all F5 Application Connector proxy versions starting from the first customer ship date of a given release. F5 will provide software development support on only the latest maintenance release of each long-term stability release (x.latest.latest). Customers who require support beyond the standard 12-month period should contact their F5 account manager.

F5 Application Connector compatibility matrix

F5 provides tested, proven, support compatibility between components of F5 Application Connector.  F5 Application Connector proxies provide backwards and forwards support when connecting to the Service Center (proxy: n.x.x -> service center: n-1.x.x, n.x.x, n+1.x.x).

For each F5 Application Connector service center release, backwards compatibility is established to one major and minor F5 BIG-IP version based on the time of first customer ship, as far back as the minimal required version of 13.0.0. (Service center released with F5 BIG-IP y.x.x service center: n.x.x -> F5 BIG-IP: y-1.x.x.)
