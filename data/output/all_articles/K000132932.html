Description

BIG-IP Edge client has a compatibility issue when performing Endpoint Inspection policy checks on macOS 13.3 or later. The client will show a message indicating a browser plugin is required and none of the actions offered in the message will allow the Endpoint Inspection to continue. The message displayed will appear as shown below.

 

Environment

  • macOS 13.3 or later
  • BIG-IP Edge Client
  • Endpoint Inspection configured in the Access Policy

Cause

BIG-IP Edge Client depended on Apple's WebKit plugin technology to perform endpoint inspection. As of macOS 13.3 use of the Webkit plugin technology has been disabled by Apple.
Browser based Endpoint Inspection (Protocol Helpers) is not impacted by this issue and will continue to work as expected on MacOS 13.3 onward
This issue has no effect for Windows, Linux or Mobile OS VPN's

Recommended Actions

F5 has assigned ID 1269721 to this issue and has removed the dependency on WebKit plugin technology by re-using the Endpoint Inspection Helper Application ('F5 Endpoint Inspector.app', that was previously only used for Browser initiated connections) from within Edge Client to remove the plugin use, .When using the new Edge Client on MacOS versions before 13,3 Edge Client will continue to use a Webkit plugin.

This APM Clients side fix is now available in APMclients 7.2.4.2 from the MyF5 download site 

apmclients-7242.2023.428.523-6242.0.iso (released May 8, 2023)

Once installed, this provides a new Installer for Edge Client (mac_edgesvpn.pkg, version 7241.2023.0427.1)
And a new installer for F5 Endpoint Inspection (mac_f5epi.pkg, version 7241.2023.0427.1)
And a Windows versions (f5fpclientW.exe 7241,2023,428,523) with minimal changes

The BIG-IP APM server side software also needs to be upgraded to a fixed version to allow the new client to connect.
F5 is tracking this as ID1283645.

All these EHF can now be downloaded directly from the MyF5 download site

The recommended process to upgrade is:
  1. Upgrade BIG-IP APM servers's (install latest hotfix over matching base release on each APM)
  2. Install EHF apmclient on each APM's
  3. Depending on your policy, either push out new Edge Client  and mac_f5epi installers to your end devices and force upgrade them, or allow the devices to auto update (if you end users have not previously used Browser Initiated APM connections, then mac_f5ep.pkg may need some manual intervention. You should check that your policy settings work with this this before deployment.
  4. If you have MDM blocks for end devices upgrading to MacOS 13.3+ it is now safe to remove these.
