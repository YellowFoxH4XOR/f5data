Known Issue

This is the result of a known issue. If enabled, the browser workarounds check is skipped when the User-Agent header in a client HTTP request is larger than 128 bytes. This issue occurs if the client HTTP request is received by a virtual server with compression enabled in the HTTP profile. As a result, the Traffic Management Microkernel (TMM) does not process and determine the User-Agent, and apply the necessary browser workarounds.

When this issue occurs, the following error message is logged to the /var/log/tmm file:

tmm tmm[2143]: 01240005:3: Error querying client-side User-Agent HTTP header: buffer full

F5 Product Development tracked this issue as CR77126, and it was fixed in BIG-IP LTM 9.4.2 and 9.6.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
