Known Issue

If you use the BIG-IP APM system to copy an access profile, the process may silently fail.

This issue occurs when all of the following conditions are met:

  • You have configured the access policy of an access profile to use the Machine Cert Auth agent.

Impact

The system has not created a copy of the access profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the Configuration utility to create a copy of the access profile, the system prompts you to name the copy of the access profile. After you click Copy, the system returns you to the Access Profile List page, which does not display the intended copy of the acces profile.
  • When you view the /var/log/apm log file, you see no messages related to your attempt at copying the access profile.

Workaround

To work around this issue, you can temporarily remove the Machine Cert Auth agent from the access policy before you create a copy of the access profile, then re-add the Machine Cert Auth agent to both access policies of the access profile -- the original and the copy. To do so, perform the following procedure:

Impact of workaround: This procedure may disrupt traffic on your device. F5 recommends that you perform this procedure during a scheduled maintenance window. In the following procedure, you remove and re-add configuration information for the Machine Cert Auth agent. If you re-add the Machine Cert Auth agent configuration information incorrectly, doing so could have an adverse effect on traffic when you apply the access policy.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Access Profiles > Access Profile List.
  3. Click the Edit link to the right of the access profile you want to copy.

    A new tab for the visual policy editor opens.

  4. Locate the Machine Cert Auth box in the access policy flow.

    Important: Before proceeding, be sure to note the location of the Machine Cert Auth agent in the access policy flow and all details about the Machine Cert Auth agent configuration.

  5. To delete the agent, click the (x) in the upper right corner of the Machine Cert Auth box.
  6. Leave the Item deletion confirmation settings at their defaults and click Delete.
  7. Using the Configuration utility, navigate to Access Policy > Access Profiles > Access Profiles Lists.
  8. Click the Copy link to the right of the access profile you want to copy.

    The system creates a copy of the access profile and returns you to the Access Profile List.

  9. In the Copied Profile Name box, type a unique name for the access profile copy.
  10. Click Copy.
  11. Return to the visual policy editor tab.
  12. Locate the position in the access policy flow where the Machine Cert Auth box previously resided.
  13. To add a new agent, click the (+) to the left of the intended location.
  14. Select the Endpoint Security (Client-Side) tab.
  15. Select Machine Cert Auth.
  16. Click Add Item.
  17. Populate the Machine Cert Auth information with the information gathered in step 4.
  18. Click Save.
  19. Click Apply Access Policy in the upper left corner of the visual policy editor.
  20. Navigate to Access Policy > Access Profiles > Access Profile List.
  21. Click Edit to the right of the access profile copy created in steps 8 through 10.

    The system opens a new tab for the visual policy editor.

  22. Follow steps 12 through 19 to add the Machine Cert Auth agent to the copy of the access profile.
