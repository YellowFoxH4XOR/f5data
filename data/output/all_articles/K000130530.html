K000130530: Unable to connect to VPN using F5 Access on Macbook

Type
Support Solution
Published
2023-02-14
Updated
2023-02-14
Source
https://my.f5.com/manage/s/article/K000130530

Description

When using F5 Access on a Macbook, the user is unable to get to the portal page to enter the username and password. For this reason, the user is unable to connect to the VPN.


Environment

  • F5 Access installed on Mac
  • BIG-IP APM


Cause

TLS 1.3 being used on the Client SSL Profile. Currently, F5 Access does not work with TLSv1.3


There's an existing RFE for adding TLS1.3 support for F5 Access on Mac, however, it is still a work in progress.


Recommended Actions

Enable the No TLSv1.3 option on the Client SSL Profile


On the Configuration Utility, go to:


  1. Local Traffic
  2. Profiles
  3. SSL
  4. Client
  5. Select the clientssl profile
  6. On the Configuration section, choose Advanced
  7. On the Options List, select the No TLSv1.3 option then click Enable
  8. Once confirmed that the No TLSv1.3 is already on the Enabled Options, click Update at the bottom of the page
