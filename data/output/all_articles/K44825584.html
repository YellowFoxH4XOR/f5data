Topic

You should consider using this procedure under the following condition:

  • You want to provide a diagnostic support package to F5 Support to aid in troubleshooting an issue with an NGINX Controller system, following the instructions in K2633: Submit a support case.

Description

The helper.sh utility, using the supportpkg option, creates a compressed tarball that contains NGINX Controller configuration files, logs, and system commands. You can use this information to diagnose NGINX Controller issues and/or send the data to NGINX Support for troubleshooting assistance. SSL certificates are not included in the support package.

Note: This package is not a QKView file and cannot be used with the existing F5 iHealth service.

The support package contains the following data

Directory or fileDescription
databaseDirectory contains PostgreSQL dump files from the system and common database, and queries for specific information, such as licensing and table sizes.
k8sDirectory contains Kubernetes resource information and logs for the kube-system and nginx-controller namespaces.
logsDirectory contains NGINX Controller install and uninstall logs.
osDirectory contains Host information such as output from the top, ps, and iptables utilities, each written to a separate file.
version.txtFile contains the current running version of NGINX Controller.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to run the helper.sh utility on the NGINX Controller system.

Procedures

Running the helper.sh utility from the command line

Impact of procedure: The helper.sh utility runs several commands when collecting information. This behavior may cause an additional performance burden on systems that are already under heavy load.

  1. Log in to the command line of the NGINX Controller system.
  2. To run the helper.sh utility, enter the following command:

    /opt/nginx-controller/helper.sh supportpkg

    When the command has completed, the name of the support package will display using the following format:

    /var/tmp/supportpkg-<date and time stamp>.tar.gz

    For example:

    /var/tmp/supportpkg-20200127T063000PST.tar.gz

  3. Collect the output file from the /var/tmp directory by copying the file to an external host using a utility, such as scp.
