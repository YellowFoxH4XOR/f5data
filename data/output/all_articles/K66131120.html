Known Issue

The BIG-IP ASM system may erroneously report a Modified ASM Cookie violation.

This issue occurs when the following conditions are met:

  • Two security policies are configured for the same host.
  • A login page is configured in the security policy.
  • A user logs out of the application.

Impact

The BIG-IP ASM system reports a false Modified ASM cookie violation.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system reports a Modified ASM Cookie violation on the Reporting page, although the cookie is still valid and has not been altered.
