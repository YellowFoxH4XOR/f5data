K000151496: Deploy single tenant across 16 blades in Chiron chassis

Support Solution
Published
2025-05-23

Description

When configuring a single tenant to span across 16 blades on F5OS Chiron Chassis using the cBIGIP image, the following error may be encountered:

Aborted: 'tenants tenant <tenant_name> config': Cannot set max-nodes to 16. Cannot extract bundle version. Use 'tar.bundle' image files. Running sw version and configured bundle image version should be >= v17.5.0 and match.

This error occurs when attempting to use a classical BIGIP ".qcow2.zip.bundle" image file for the tenant.

Environment

  • Product: F5OS - Chiron Chassis
  • F5OS Version: 1.8.1 or later
  • Tenant Image: cBIGIP (BIGIP-17.5.0 or later)
  • Desired Configuration: Single tenant with max-nodes set to 16 (across 16 blades)

Cause

The deployment of a tenant across 16 blades (i.e., setting max-nodes to 16) requires the cBIGIP image in ".tar.bundle" format. The system does not support ".qcow2.zip.bundle" images for this configuration and will block the operation if an unsupported image type is used.

Recommended Actions

  • Use a ".tar.bundle" formatted cBIGIP image (e.g., BIGIP-17.5.0-0.0.15.T4-F5OS.tar.bundle) when deploying tenants with max-nodes 16.
  • Set max-nodes to 16 during tenant creation, referencing the appropriate ".tar.bundle" file.
  • ".tar.bundle" image file is supported on non-chiron chassis and Rseries.

None.
