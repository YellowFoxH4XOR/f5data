Known Issue

The Configuration utility displays a No Access error message when attempting to view an iFile object.

This issue occurs when all of the following conditions are met:

  • After importing a file to the BIG-IP system, you create an iFile.
  • You attempt to view the file from the Configuration utility Local Traffic > iRules > iFile List page.

Impact

Users cannot access iFile objects.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to view an iFile object from the Configuration utility, you receive a No Access error message.
