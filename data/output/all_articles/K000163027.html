Description

When viewing the Attack Signatures list in the BIG-IP ASM Configuration utility, the Analysis Plane may reach 100% CPU utilization on specific cores. The asm_config_server process consumes significant CPU resources while loading and processing signature data.

Environment

  • Product: BIG-IP ASM
  • BIG-IP version: 17.1.1.2
  • GUI path: Security > Options > Application Security > Attack Signatures
  • The behavior can occur when viewing an Attack Signatures set.
  • The CPU increase is more noticeable on lower-performance hardware platforms.

Cause

The GUI loads signature data through multiple requests. Each request retrieves up to 500 signatures, and the asm_config_server process processes the returned data. This temporarily consumes substantial CPU resources.

This is expected behavior by design and is not caused by custom signature sets or a hardware fault.

Answer/Recommended Actions

  • No corrective action or configuration change is required.
  • View Attack Signatures sets during off-peak business hours to minimize operational impact.
  • Allow the signature list to finish loading before performing additional management operations.
  • Increasing the resource quota for asm_config_server or increasing CPU allocation for the management plane is not available as a mitigation.
  • Higher-performance hardware may reduce the impact of the CPU increase, although a temporary increase in CPU usage may still occur.

Additional Information

  • The behavior may occur on all platforms, but its visibility depends on available hardware performance.
  • The temporary CPU increase is associated with viewing the signature list and should not be interpreted as a persistent CPU condition.
