Description

File "liveupdatedb.log" on /var/lib/hsqldb/live-update/ is consuming a lot of space (more than 100 MB) on /var partitio

Environment

  • ASM provisioned
  • Viprion platform with multiple blades

Cause

Seen behavior is expected. The "liveupdatedb.log" log file is being created each time the LiveUpdate module is starting (whether its a service restart or system restart) but if the file already exists then its just appending it records and its max size is 200Mb by default

Recommended Actions

None, but if required the log file can be safely deleted.

Additional Information

None.
