Topic

Beginning in BIG-IP 16.0.0, both the SIP and Diameter protocols support in-TMM monitoring. This feature is an extension of the in-TMM monitor delivered with BIG-IP 13.1 but applied to Diameter and SIP monitoring.

Description

Prior to version BIG-IP 16.0.0, the default SIP and Diameter monitors are based on the bigd process, which operates outside of the TMM microkernel in userland. The in-TMM monitor framework enables protocol monitors to run in the context of the TMM microkernel, allowing significantly better performance by lowering latency and removing an external process.

Configuring in-TMM SIP and Diameter monitors

Configuring an in-TMM SIP or Diameter monitor requires only one change to existing monitors:

  1. Go to Local Traffic > Monitors.
  2. Open an existing SIP or Diameter monitor or create a new one.
  3. Under Mode, enable in-TMM monitoring by selecting Message Routing.
  4. Finish configuring your SIP or Diameter monitor and select Save.

Recommendations

F5 recommends in-TMM monitoring when high performance SIP or Diameter monitoring is required.
