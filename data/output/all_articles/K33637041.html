Known Issue

The Traffic Management Microkernel (TMM) may restart when you use a SOCKS profile and an iRule.

This issue occurs when all of the following conditions are met:

  • You configure a virtual server with a SOCKS profile and an iRule that contains a SERVER_CONNECTED event.
  • The iRule uses a block call that stalls the connection while gathering data or performing another task.

Impact

TMM unexpectedly restarts and traffic may be disrupted. 

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TMM restarts when sending traffic through a SOCKS virtual server that has an attached iRule that uses certain blocking commands.

Workaround

To work around this issue, avoid adding an iRule that contains a SERVER_CONNECTED event, or avoid using certain iRules commands that do not complete immediately, such as after, table, session, and others.
