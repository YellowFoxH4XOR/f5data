Known Issue

BIG-IP AFM may not display all inline firewall rules.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is versioned for 11.5.1 HF4 or 11.5.1 HF5.
  • You configure more than 100 inline firewall rules within a single context; for example, global, management IP, or self IP.
  • You navigate to Security > Network Firewall > Active Rules page in the Configuration utility.

The Security > Network Firewall > Active Rules page lists only the first 100 inline firewall rules per context.

Impact

Users cannot view more than 100 inline firewall rules using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you navigate to the Security > Network Firewall > Active Rules page, the system displays only the first 100 inline firewall rules per any single context.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to view more than 100 inline firewall rules per any single context. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh
  2. View the properties if the active inline firewall rules by typing the following command:

    list security firewall <context>

    For example, to view the inline firewall rules within the global context, you would type the following command:

    list security firewall global-rules
