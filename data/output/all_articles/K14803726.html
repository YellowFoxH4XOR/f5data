K14803726: Citrix HTML5 may not be working with BIG-IP APM.

Type
Support Solution
Published
2022-07-15
Updated
2023-02-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K14803726

Description
With using BIG-IP APM, the clients may be using HTML5 to operate the Remote Desktop or RemoteApps connections.
Under certain conditions, upon clicking the Citrix resources icons from the Webtop, the remote connection does not open.

Environment

  • BIG-IP APM
  • Citrix with using HTML5 connections.

Cause
This may be due to some "websecurity" profiles attached to the Virtual Server, blocking the "websockets" connections to be sent to the Citrix servers.

Recommended Actions

  1. Display the properties of the Virtual Server users connect to:
    # tmsh list ltm virtual <virtualServer_name>
  2. Look at the profiles attached to it. Here is an example:
    ltm virtual <virtualServer_Name>
    description "..."
    destination 1.2.3.4:443
    profiles {
    [...]
    /Common/websecurity
    ...]
    }
  3. If any "websecurity" profile is attached to it, we may attempt to it: 
    #tmsh modify ltm virtual <virtualServer_name> profiles delete { websecurity }
