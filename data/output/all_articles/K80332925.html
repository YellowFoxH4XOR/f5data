Description

Error messages similar to the following are observed in /var/log/boot.log or printed to the command line when starting syslog-ng:

notice syslog-ng: Initiating connection failed, reconnecting; time_reopen='60'

Environment

  • Remote syslog destinations configured

Cause

This message can occur when a remote syslog destination is temporarily unavailable, and in some cases prevents syslog-ng from starting.

Recommended Actions

Verify if the remote syslog destinations are reachable and that remote logging is occurring.

If remote logging is occurring as expected, this message can be safely ignored.

To troubleshoot issues connecting to a remote syslog server, refer to the following article:

  • K86480148: Troubleshooting issues sending logs to a remote syslog server

None.
