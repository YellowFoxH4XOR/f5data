Description
This article describes details about the remote High-Speed Logging (HSL) format.

For Example: MSG Format

  • [Remote Logging] : "<$PRI> $STAMP $HOST $PRIORITY $MSG\n"
  • [type: Arcsight] : " ...  "
  • [type: IPFIX] : " ...  "
  • [type: Management Port] : " ...  "

  • [type: Remote Syslog,  Syslog Format: Syslog] : " ...  "

  • [type: Splunk] : " ...  "
