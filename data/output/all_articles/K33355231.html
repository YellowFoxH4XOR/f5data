Issue

Error Message

01010201:2: Inet port exhaustion on <ip_address> to <ip_address:port> (proto <protocol>)

In this error message, note the following:

  • The <ip_address> is the source IP address.
  • The <ip_address:port> is the destination IP address and port.
  • The <protocol> is the IP protocol number (6 = TCP, 17 = UDP).

For example:

01010201:2: Inet port exhaustion on 192.168.10.100 to 10.10.10.11:80 (proto 6)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Due to high traffic load or special client traffic patterns, the BIG-IP system exhausts the pool of available ephemeral ports.

When the BIG-IP system processes a large number of new connections, or experiences certain traffic patterns, the pool of available ports may become exhausted. For example, this issue can occur when a SNAT is configured, because the range of available ephemeral ports is limited for each SNAT address. This issue may also occur when using a UDP virtual server with the datagram-load-balancing option enabled in the UDP profile, as each incoming UDP datagram is load-balanced individually and can create a new server-side connection that needs a unique source port.  If the pool of available ports is exhausted, the BIG-IP system logs the error message and resets the connection.

Impact

The BIG-IP system resets the connection due to a lack of available ports.

Recommended Actions

For configurations that have SNAT enabled, you may be able to mitigate this issue by configuring additional SNAT addresses or by using a SNAT pool. For configurations that have datagram-load-balancing enabled, you may be able to mitigate this issue by lowering the idle timeout on the UDP profile. Please read K3605 before lowering the idle timeout to "immediate" when you have datagram-load-balancing enabled. Starting in 12.0.0, the BIG-IP system generates an ephemeral port exhaustion warning to the /var/log/ltm file when approximately 80 percent of the available ephemeral ports are in use.
