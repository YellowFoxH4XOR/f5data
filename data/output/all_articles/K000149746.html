Known Issue

After upgrading to F5 Access Android 3.1.0 or a later version, you are unable to connect to VPN.

This issue occurs when all of the following conditions are met:

  • you upgrade to F5 Access Android 3.1.0 or later
  • the client device uses a client certificate signed using SHA1.

F5 Access 3.1.0 and later uses OpenSSL 3.1.4, which has deprecated support for the SHA-1 signature algorithm starting from OpenSSL 3.x.

On F5 Access 3.1.0 and later, certificates need to be signed using a signature algorithm with SHA-256 or higher. The use of SHA-1 is not supported and should be avoided.

Impact

F5 Access for Android is unable to establish a VPN tunnel due to a TLS/SSL handshake failure

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • F5 Access for Android is unable to establish a VPN tunnel due to a TLS/SSL handshake failure
  • You may observe SSL errors in the log files similar to the following:
    (Alert (Level: Fatal, Description: Handshake Failure))

Workaround

To work around this issue, you can use client certificates that are signed using a signature algorithm with SHA-256 or higher. Do not use SHA-1 as it is not supported.
