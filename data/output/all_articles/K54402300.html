Description

JavaScript served from an ASM fictive URL (/TSPD/*) is causing an error to appear in the browser's console, similar to:

Uncaught TypeError: Cannot read property 'apply' of null
    at XMLHttpRequest.<anonymous> (https://www.example.com/TSPD/<fictive URL>)

Functionality of the webpage may also be broken.

Environment

  • Bot Defense or DoS profile in use
  • SPA enabled

Cause

Bug ID 1011049

Recommended Actions

Bug ID 1011049 is fixed via a Browser Challenges live update.

Install the latest Browser Challenges live update, then wait 48 hours to see if the problem is resolved. If the problem persists, open a service request with F5 Support for continued investigation.
