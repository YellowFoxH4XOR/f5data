K60719503: Prober pool configuration will not take effect immediately

Published

Description

After modifying the prober pool configuration in BIG-IP DNS, changes will not take effect immediately.

tmsh show gtm datacenter <data center name> detail  command will not reflect the change immediately for the prober pool configuration.

Environment

  • BIG-IP DNS
  • Prober pool configuration

Cause

BIG-IP DNS receives probe responses from big3d (this could be from any BIG-IP device including its own) which tells DNS that the pool member is healthy.
Availability of the pool member is 'available' - no change as it is already 'available' even if you have updated the prober pool configuration.

Recommended Actions

The status of  'Reason' field for the command tmsh show gtm datacenter <data center name> detail, will be updated when the pool member status change and the new prober pool configuration will be assigned to monitor pool member.
