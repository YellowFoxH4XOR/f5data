Known Issue

This is the result of a known issue. When attempting to establish a Network Access tunnel, Mac OS X users may receive the following browser message:

Connecting...

The session does not time out or achieve a successful connection. After this behavior occurs, the user is unable to successfully connect without either manually killing all processes involved or rebooting the machine. This issue is rare; it is triggered when the pppd process hangs while attempting to configure the client machine's network settings.

F5 Networks Product Development is tracking this issue as CR131269.

This issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
