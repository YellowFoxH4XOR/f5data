Issue

In BIG-IP versions prior to 9.4.7 and 10.0.0, the bigpipe memory show command output required you to add together the total memory reported for the Host and Traffic Management Microkernel (TMM) to acquire the total physical memory installed on the system.

Note: BIG-IP platforms 1600 and 3600 running version 9.4.7 or 9.4.8 with 4 GB of RAM are unable to use 760 MB of memory. For more information, refer to K10600: The BIG-IP 1600 and 3600 platforms do not use all of the RAM installed.

For example, to view the physical memory output for BIG-IP 9.4.6, you would type the following command:

# physmem

The physmem command output indicates that 1 GB of RAM is installed:

Note: The physmem command output is reported in kilobytes; therefore, 1048576 KB equal 1 GB.

1048576

To view the memory statistics, type the following command:

# bigpipe memory show

The bigpipe memory show command output displays that 1 GB of memory is split between the Host and TMM. Therefore, the Host total of 371.4 MB plus the TMM total of 632.0 MB equals the total physical memory installed of 1003.4 MB:

MEMORY STATISTICS --
| (Host) Total = 371.4MB Used = 350.1MB
| (TMM) Total = 632.0MB Used = 20.55MB

Note: Some rounding of the displayed total memory occurs, resulting in a discrepancy when the totals for TMM and the Host are added together. This behavior does not indicate an issue.

Beginning in BIG-IP 9.4.7 and 10.0.0, the Host total output from the bigpipe memory show command now displays the total physical memory installed on the system. The Host used memory includes both the memory used by the Host and TMM. In addition, the Host used memory is reported higher than in BIG-IP versions prior to 9.4.7 and 10.0.0. Subtracting the TMM total memory from the Host memory allows you to calculate the actual amount of memory used by the Host system.

For example, to view the physical memory output, type the following command:

# physmem

The following physmem command output indicates that 1 GB of RAM is installed:

1048576

Note: The physmem command output is reported in kilobytes; therefore, 1048576 KB equal 1 GB.

To view the memory statistics, type the following command:

# bigpipe memory show

The physmem command output matches the bigpipe memory show command output for the total amount of physical RAM installed on the system:

MEMORY STATISTICS --
| (Host) Total = 1000.0MB Used = 968.7MB
| (TMM) Total = 359.0MB Used = 12.40MB

Note: Some rounding of the displayed total memory occurs, resulting in a discrepancy when comparing the total memory from the bigpipe memory show command output with the physmem command output. This behavior does not indicate an issue.
