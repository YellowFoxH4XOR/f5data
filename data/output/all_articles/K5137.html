K5137: 3-DNS does not use a changed value for Check Static Dependencies until 3dnsd is restarted

Source

Known Issue

This is the result of a known issue. 3-DNS does not use the new value for Check Static Dependencies until you run the 3ndc restart command or reboot the 3-DNS system.

F5 Networks Product Development tracked this issue as CR33671 and CR41804.
