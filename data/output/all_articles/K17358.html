Known Issue

Description

The sessiondump -allkeys command may not honor the Ctrl+C key combination.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system process a high number of sessions.
  • You run the sessiondump -allkeys command from the command line.

Impact

You cannot stop the sessiondump -allkeys command using the Ctrl+C key combination. However, the operation continues to run until completion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Ctrl+C key combination has no effect on the sessiondump -allkeys operation that continues to run until completion.
  • The Ctrl+C key combination has no effect on the sessiondump -allkeys operation that may appear to stop responding.

Workaround

To work around this issue, you can open a separate command line console and manually kill the processes invoked by the sessiondump -allkeys operation.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
