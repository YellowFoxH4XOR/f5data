K000134779: API Requests Fail with '401 Authentication Needed'

Type
Support Solution
Published
2023-05-25
Updated
2023-08-04
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.10.1
Source
https://my.f5.com/manage/s/article/K000134779

Description

An API request to a basic authentication protected resource can fail with response '401 Authentication Needed'. For example: 

$ curl -kL -X GET 'https://nms.example.com/api/acm/v1/infrastructure/workspaces' --header 'Authorization: Basic ZXhhbXBsZTpleGFtcGxlCg=='
{
    "code": 401,
    "message": "Authentication Needed"
}

Environment

NMS

Cause

This issue occurs if the Authorization header value does not contain the appropriate Base64 encoded value.

Recommended Actions

  • Confirm the appropriate credentials are used in the request. For example, in the above curl example the credentials that are Base64 encoded are as follows:  
    $ echo ZXhhbXBsZTpleGFtcGxlCg== | base64 -d
example:example
  • Ensure the credentials are appropriately Base64 encoded. For example, the credentials from the above curl example should be encoded as follows (notice the difference in the two Base64 values):  
    $ echo -n example:example | base64
ZXhhbXBsZTpleGFtcGxl
  • Alternatively, use an HTTP capture tool, such as DevTools in Chrome or Web Developer Tools in Firefox, to capture the NMS UI /login request and glean the Base64 encoded credentials from the request's Authorization header
