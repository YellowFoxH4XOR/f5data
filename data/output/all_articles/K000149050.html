Description

SNMP support for SHA-2 in F5OS

Environment

SNMP

Authentication protocols

Cause

Currently only HMAC-SHA-96 is supported. For more information, refer to ID 1602245.

Recommended Actions

An RFE has been in submitted for Enhance feature to allow F5OS-A/F5OS-C to support SNMPv3 using Auth 'SHA256' and Encryption 'AES256'
