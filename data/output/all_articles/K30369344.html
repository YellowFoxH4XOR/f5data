Description
When Match Across options are enabled in persistence profiles and the persistence profiles are referenced by virtual servers, BIG-IP systems may search for any persistence record throughout persistence table, and the persistence record selected may be created by other virtual servers whose persistence profile doesn't enable any Match Across option.

Environment

  • Any Match Across option is enabled in a persistence profile

Cause
This behaviour is by design.

Recommended Actions

Administrators need to take the impact of Match Across options into consideration when configuring BIG-IP systems. If a BIG-IP system needs to keep separate persistence records for different virtual servers, administrators need to be careful to determine whether Match Across options should be enabled.
