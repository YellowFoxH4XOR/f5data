Known Issue

ICAP requests sent to an ICAP server always contain a payload, even if the HTTP request or response does not contain a payload.

This issue occurs when all of the following conditions are met:

  • You have an ICAP profile associated with a virtual server.
  • HTTP request or response does not contain a payload.

Impact

The ICAP server may parse the additional payload as a new ICAP request.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ICAP request sent to the ICAP server always contains a payload, even if the HTTP request or response does not contain a payload.
