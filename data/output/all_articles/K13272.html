Topic

This article applies to BIG-IP 9.6.x. For information about other versions, refer to the following articles:

  • K13123: Managing BIG-IP product hotfixes (11.x - 12.x)
  • K10025: Managing BIG-IP product hotfixes (10.x)
  • K6845: Managing BIG-IP product hotfixes (9.x)

You should consider using this procedure under the following condition:

  • You want to install a hotfix on a VIPRION 9.6.x system

Description

The functionality provided for managing hotfixes includes the following:

  • Hotfixes are managed using the bigpipe software command
  • Hotfixes are installed to an inactive boot location
  • Hotfixes are cumulative
  • Hotfixes have a version number
  • Hotfixes uninstall packages are no longer available

Prerequisites

You must meet the following prerequisite to use this procedure:

  • The VIPRION system must be running 9.6.x software

Backing up existing BIG-IP configuration data

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Before you install a hotfix, you should save your BIG-IP configuration data. Backing up your configuration prevents loss of data if the hotfix installation is not successful.

To collect and archive the BIG-IP configuration files, type the following command from the BIG-IP command line:

bigpipe config save /config.ucs

Determining the hotfix build to install

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To determine the appropriate hotfix to install on the system, review the latest available hotfixes in K9502: BIG-IP hotfix matrix.

Downloading the software

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

After you save the existing configuration, download the hotfix files from the F5 Downloads site to your local workstation or network share.

Note: For information about downloading files from the F5 Downloads site, refer to K167: Downloading software and firmware from F5.

Importing the hotfix to the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

If you use a method, such as SCP, to copy the hotfix files to the BIG-IP system, make sure that the files are installed to the /shared/images/ directory.

To add hotfix files to the image library, use the following command syntax:

bigpipe software image <directory><hotfix name>.im add         

For example, the following command moves the Hotfix-BIGIP-9.6.1-839.0-HF3 hotfix file from the /root/ directory to the /shared/images/ directory:

bigpipe software image /root/Hotfix-BIGIP-9.6.1-839.0-HF3.im add

Verifying the hotfix MD5 checksum

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

After the hotfix files are installed on the BIG-IP system, and before you perform the installation, F5 recommends that you test the integrity of the ISO file to ensure file quality. To run the test, use the following command syntax, where <hotfix> is the name of the upgrade file you downloaded:

md5sum <hotfix>
cat <hotfix>.md5

For example:

md5sum Hotfix-BIGIP-9.6.1-839.0-HF3.im
cat Hotfix-BIGIP-9.6.1-839.0-HF3.im.md5

The two MD5 hash values should be identical.

Installing the hotfix

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To install software on BIG-IP 9.6.x systems, you must use the following bigpipe software desired command syntax:

bigpipe software desired <install_volume> product BIG-IP version <version_number> build <build_number>

For example, if you are currently running on volume HD1.1, to install hotfix HF-3 (build 839.0) on volume HD1.2 of the cluster, you would type the following command:

bigpipe software desired HD1.2 product BIG-IP build 839.0 \ version 9.6.1

The system returns to a prompt and installs the specified software.

Verifying the hotfix installation

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To observe the progress of the software installation, type the following command:

watch bigpipe software status show

The system displays the installation progress.

Rebooting to the hotfix installation partition

Impact of procedure: Rebooting the BIG-IP system interrupts traffic management and should be performed during a maintenance window.

Once you have installed the hotfix, you must reboot the system to the target volume. To do so, use the following bigpipe software desired command syntax:

bigpipe software desired <install_volume> active enable

For example, if you are currently running on volume HD1.1, to reboot the system to volume HD1.2, you would type the following command:

bigpipe software desired HD1.2 active enable
