K000160326: Current Sessions counter higher than active connections number

Type
Support Solution
Published
2026-03-17
Updated
2026-03-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.1.2, 17.1.1, 17.5.X, 17.1.X, 17.5.1, 17.5.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000160326

Description

While reviewing statistics for one of your pool members, you can notice that number of current sessions is higher than number of current active connections.

Environment

  • BIG-IP LTM

  • Pool statistics

Cause

It can occur due to bug ID 2227209, which can cause Current session counter to not go down if connection gets ended abnormally, for example, the client connection is abruptly killed/terminated (on the client process), or the connection doesn't close gracefully.

Answer/Recommended Actions

This is only cosmetic and should not have functional impact.

Additional Information

None
