Known Issue

The RESOLV:lookup command may lead to a TMM core.

This issue occurs when all of the following conditions are met:

  • You use the RESOLV::lookup command from within an iRule.
  • The command terminates due to a connection reset or unreachable name server.

Impact

TMM may core and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
  • The BIG-IP system fails over to another device in the device group.
