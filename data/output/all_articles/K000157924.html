Description

The qcow2.zip.bundle format for tenant disk images in F5OS is deprecated. Instead, use the tar.bundle format, which is the replacement. Tenants deployed from either format operate identically.

Environment

  • Tenant disk images in F5OS

Cause

In October 2025, F5 rotated its signing certificates and keys used to cryptographically sign F5-produced digital objects.

Recommended Actions

Where possible, prefer the tar.bundle format for tenant images. This will work in all supported F5OS releases other than F5OS-A 1.5.x.

For more information on this change, refer to K000157005: F5 signing certificate and key rotation, October 2025.
