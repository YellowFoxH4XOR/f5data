Issue

Error Message

Master Keys differ between this BIG-IQ and the one you are attempting to discover.

For example:

Discovery of BIG-IQ Data Collection Device 192.168.10.100 failed with state POST_FAILED and due to error Master Keys differ between this BIG-IQ and the one you are attempting to discover. Please configure both machines to have the same Master Key.

Message Location

You may encounter this message in the following locations:

  • The BIG-IQ user interface during data collection device (DCD) discovery
  • The /var/log/restjavad.0.log file

Description

This message occurs when all of the following conditions are met:

  • You are attempting to discover a new DCD.
  • The master keys on the BIG-IQ system and the DCD do not match.

Note: You chose a specific master key passphrase during the initial set-up of your BIG-IQ system. You must use this same passphrase during the initial set-up of other BIG-IQ or DCD systems before they get discovered.

Impact

You are unable to discover the remote DCD system.

Recommended Actions

Use one of the following procedures to ensure that the master key is the same on both the BIG-IQ and DCD systems:

If the BIG-IQ master-key passphrase is known

Impact of procedure: The following procedure restores the DCD system configuration to the factory default and begin a new first-time setup procedure.

  1. Log in to the DCD system Advanced Shell (bash).
  2. To reset the DCD system configuration to default, type the following command:

    clear-rest-storage -d -l

    Note: If you receive the Member of an HA pair message, use ha_reset before trying to clear storage. Enter the following command and then repeat step 2. Ignore the Error: error doing query... message.

    ha_reset <local discovery address>

  3. Obtain the BIG-IQ system master-key passphrase for the next step.
  4. Log in to the DCD system user interface and follow the first-time set-up procedure.

    Important: During the Master Key step of the procedure, ensure that you enter the BIG-IQ system master-key passphrase.

  5. Log in to the BIG-IQ system user interface and rediscover the DCD system.

If the BIG-IQ master-key passphrase is not known

Impact of procedure: The following procedure restores the BIG-IQ and DCD system configuration to the factory default and begin new first-time setup procedures.

  1. Log in to the BIG-IQ system bash.
  2. To reset the BIG-IQ system configuration to default, enter the following command:

    clear-rest-storage -d -l

    Note: If you receive the Member of an HA pair, use ha_reset before trying to clear storage message. Enter the following command and then repeat step 2. Ignore the Error: error doing query... message.

    ha_reset <local discovery address>

  3. Log in to the BIG-IQ system user interface and follow the first-time set-up procedure.

    Important: During the Master Key step of the procedure, choose a new master-key passphrase and store it in a safe place.

  4. Log in to the DCD system bash.
  5. To reset the DCD system configuration to default, enter the following command:

    clear-rest-storage -d -l

  6. Log in to the DCD system user interface and follow the first-time set-up procedure.

    Important: During the Master Key step of the procedure, ensure that you enter the BIG-IQ system master-key passphrase.

  7. From the user interface of the BIG-IQ system, rediscover the DCD system.
