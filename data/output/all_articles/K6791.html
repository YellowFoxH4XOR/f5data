Known Issue

This is the result of a known issue. BIG-IP GTM will mark links down if the bigip_link monitor is used and Virtual Server Discovery is not enabled.

When a server object is configured on BIG-IP GTM, Virtual Server Discovery is disabled by default and must be enabled manually either during the creation of the server object, or after the server object has been created.

Once Virtual Server Discovery is enabled for the BIG-IP GTM Server entry, BIG-IP GTM will correctly monitor the link using the bigip_link monitor.

Note: This issue does not affect the BIG-IP Link Controller because Virtual Server Discovery is enabled by default.

F5 Product Development tracked this issue as CR70600 and it was fixed in BIG-IP GTM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

You can work around this issue by enabling Virtual Server Discovery when using the bigip_link monitor. To do so, perform the following procedure:

Note: In order for BIG-IP GTM to monitor links using the bigip_link monitor, the links must be directly accessible from the BIG-IP GTM.

  1. Log in to the BIG-IP GTM Configuration utility.
  2. Select Global Traffic.
  3. Under Data Centers, select Servers.
  4. Select the GTM Server entry.
  5. Select the Virtual Servers tab.
  6. Choose Enabled from the Virtual Server Discovery menu.
  7. Choose Update.
