Known Issue

A BIG-IP user session launched from an Enterprise Manager system may be granted unexpected user role permissions.

This issue occurs when all of the following conditions are met:

  • Enterprise Manager and BIG-IP systems are configured to use remote authentication.
  • A user role is changed on the remote auth server.
  • The user authenticates by logging in to the Enterprise Manager system and establishing a connection to the BIG-IP system through the Enterprise Manager system.

The system does not pass the updated user role information to the BIG-IP system in the SSO (single-sign on) token that the system uses to authenticate the user. As a result, the authenticated user continues to have the permissions on the BIG-IP system at the level that was granted to the original user role.

Impact

There is a possibility that the system will experience authorization (role) escalation issues.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Following a user role change on a remote auth server, the permissions allowed for a BIG-IP user session that is launched through an Enterprise Manager system continues to have the permission levels of the original user role.
