K5255: Reasons why older version 3-DNS Controllers may stop working when added to a synchronization group containing newer versions of 3-DNS

Topic

A 3-DNS synchronization group should never contain multiple versions of 3-DNS. Configuration statements and statistics change from version to version, and are not necessarily compatible.

The 3dns_add script will allow you to add a 3-DNS Controller that is running an older software version to a synchronization group containing 3-DNS Controllers that are running newer versions of 3-DNS. As such, you must be careful to avoid accidentally adding controllers to a sync group if they are running a different version of the 3-DNS software than the other controllers in the sync group.

If you accidentally add a 3-DNS Controller that is running an older version of the 3-DNS software to a sync group containing newer versions of 3-DNS, the controller running the older version of 3-DNS software will synchronize to the new version configuration. This may cause the older version 3-DNS to fail completely, fail partially, or to behave unpredictably.

To resolve this issue, you must remove the older version of 3-DNS from the synchronization group, and restore its configuration from backup.
