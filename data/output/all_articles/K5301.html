Known Issue

This is the result of a known issue. Return to DNS is not an available load balancing mode for Link Controller, since Link Controller does not allow the use of normal DNS zones. When you create a wide IP on Link Controller, the fallback load balancing mode defaults to Return to DNS, which is the default setting for 3-DNS. If you do not specify a fallback load balancing mode other than Return to DNS, Link Controller will not use a fallback load balancing mode.

F5 Networks Product Development tracked this issue as CR28006.
