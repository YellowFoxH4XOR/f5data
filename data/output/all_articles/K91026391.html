K91026391: BGP Down Peer reset due to nh address change

Type
Support Solution
Published
2023-11-08
Updated
2023-11-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.0.0, 14.0.1, 14.1.0, 14.1.3, 14.1.2, 15.1.0, 15.1.1, 15.1.2, 15.1.3, 15.1.4, 16.1.0, 16.1.1, 16.1.2, 15.1.5, 14.0.X, 14.1.4
Source
https://my.f5.com/manage/s/article/K91026391

Description

BGP session could hard reset the connection during a traffic group failover with the following message. /var/log/zebos/bgp.log

BGP : %BGP-5-ADJCHANGE: neighbor x.x.x.x Down Peer reset due to nh address change

Environment

  • BIG-IP LTM is configured with BGP and connected to neighbor router
  • HA Active/Standby is configured on both BIG-IP LTM units
  • Floating Self-IP is defined on a single VLAN with different traffic-groups

Cause

  • Different traffic groups on a single VLAN causes BGP session to go down during failover
  • You are running a BIG-IP LTM version affected with ID1030645

Recommended Actions

Upgrade to BIG-IP LTM version with a fix for ID1030645

Additional Information

None
