K17128: The BIG-IP AAM VE system may fail to upgrade when the datastor disk is provisioned on HD1

Type
Known Issue
Published
2015-11-04
Updated
2023-02-21
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K17128

Known Issue

The BIG-IP AAM Virtual Edition (VE) system may fail to upgrade. This issue occurs when all of the following conditions are met:

  • The BIG-IP AAM VE system was previously deployed using the BIG-IP VE ALL image template. For example, you used the BIGIP-11.5.0.0.0.221.ALL-scsi.ova image when you deployed BIG-IP VE 11.5.0 on a VMware hypervisor.
  • You did not provision the datastor disk on HD2 when you provisioned the BIG-IP AAM system.
  • You attempted to install a later version or hotfix to the next slot. For example, you attempted to install BIG-IP 12.0.0 to HD1.2.

Impact

The installation fails with an error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP AAM VE upgrade fails.
  • If you attempt to install BIG-IP 12.0.0 to HD1.2 on the BIG-IP AAM VE system, the Software Management page in the Configuration utility and the tmsh show /sys software status command both return a (Disk full (volume group). See SOL#17128) error. For example, the following output from the tmsh show /sys software status command indicates that the installation failed on HD1.2:

    -----------------------------------------------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version    Build  Active                                                      Status
    -----------------------------------------------------------------------------------------------------
    HD1.1    BIG-IP   11.5.3  0.0.163     yes                                                    complete
    HD1.2    BIG-IP   12.0.0  0.0.606      no  failed (AAM data and software on same disk. See SOL#17128)

  • If you attempt to install BIG-IP 11.5.0 through 11.6.0 including hotfixes to HD1.2 on the BIG-IP AAM VE system, both the Software Management page in the Configuration utility and the tmsh show /sys software status command return a (Disk full (volume group). See SOL#10636). For example, the following output from the tmsh show /sys software status command indicates that the installation failed on HD1.2:

    -------------------------------------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version    Build  Active                                            Status
    -------------------------------------------------------------------------------------------
    HD1.1    BIG-IP   11.5.3  0.0.163     yes                                          complete
    HD1.2    BIG-IP   11.6.0  0.0.401      no  failed (Disk full (volume group). See SOL#10636)

Workaround

To work around this issue, you can dedicate HD2 for datastor usage prior to your next upgrade attempt. To do so, perform one of the following procedures:

  • Using tmsh to dedicate HD2 for datastor usage (BIG-IP 11.6.1 HF1 and later)
  • Using the Configuration utility to dedicate HD2 for datastor usage (BIG-IP 11.4.x - 11.6.1, except 11.6.1 HF1 and later)
  • Using tmsh to dedicate HD2 for datastor usage (BIG-IP 11.4.x - 11.6.1, except 11.6.1 HF1 and later)

Impact of workaround: Traffic through the BIG-IP AAM system is temporarily disrupted during the relocation of the existing datastor to HD2, as well as the system reboot. F5 recommends that you perform these procedures during a scheduled maintenance window for the affected BIG-IP system.

Using tmsh to dedicate HD2 for datastor usage (BIG-IP 11.6.1 HF1 and later)

You must use the TMOS Shell (tmsh) for this procedure.

Note: Use the management interface or the serial console to complete these steps.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To determine if HD2 has been set to datastor mode, type the following command:

    list /sys disk logical-disk HD2

    The command should return output similar to the following example:

    sys disk logical-disk HD2 {
        size 20480
        vg-reserved 4096
    }

  3. To set HD2 to datastor mode, type the following command:

    modify /sys disk logical-disk HD2 { mode datastor }

  4. To verify HD2 is now in datastor mode, type the following command:

    list /sys disk logical-disk HD2

    The command should return output similar to the following example:

    sys disk logical-disk HD2 {
        mode datastor
        size 20480
        vg-reserved 4096
    }

  5. Save the changes by typing the following command:

    save /sys config

  6. Stop all daemons by typing the following command:

    bigstart stop

  7. To identify the datastor logical volume, type the following command:

    lvscan | grep datastor

    For example, the following output indicates that the /dev/vg-db-sda/app.datastor.dat.datastor directory is the datastor logical volume:

    ACTIVE '/dev/vg-db-sda/app.datastor.dat.datastor' [81.32 GB] inherit

  8. Remove the datastor volume by typing the following command:

    lvremove <path/to/logical/volume>

    For example, the following command removes the /dev/vg-db-sda/app.datastor.dat.datastor datastor volume:

    lvremove /dev/vg-db-sda/app.datastor.dat.datastor

  9. Reboot the system by typing the following command:

    reboot

  10. Wait for the system to come back up before upgrading the system.

Using the Configuration utility to dedicate HD2 for datastor usage (BIG-IP 11.4.x - 11.6.1, except 11.6.1 HF1 and later)

  1. Log in to the Configuration utility.
  2. Navigate to System > Disk Management.

    The Disk Management page presents a logical view of the available disks on the system and the Datastor logical volume resides on HD1.

  3. Click HD2.
  4. In the Mode box, select Datastor.
  5. To save the changes, click Update.
  6. Navigate to System > Configuration > Device.
  7. Click General.
  8. To reboot the BIG-IP AAM system, click Reboot.
  9. Wait for the system to come back up before upgrading the system.

Using tmsh to dedicate HD2 for datastor usage (BIG-IP 11.4.x - 11.6.1, except 11.6.1 HF1 and later)

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To determine if HD2 has been set to datastor mode, type the following command:

    list /sys disk logical-disk HD2

    The command should return output similar to the following example:

    sys disk logical-disk HD2 {
        size 20480
        vg-reserved 4096
    }

  3. To set HD2 to datastor mode, type the following command:

    modify /sys disk logical-disk HD2 { mode datastor }

  4. To verify HD2 is now in datastor mode, type the following command:

    list /sys disk logical-disk HD2

    The command should return output similar to the following example:

    sys disk logical-disk HD2 {
        mode datastor
        size 20480
        vg-reserved 4096
    }

  5. Save the changes by typing the following command:

    save /sys config

  6. Reboot the system by typing the following command:

    reboot

  7. Wait for the system to come back up before upgrading the system.
