Description

Multiple built-in SSL certificates (i.e. ca-bundle, default, f5-ca-bundle, f5-irule)  found in /config/filestore/files_d/Common_d/certificate_d .  For example:

Environment

  • BIG-IP
  • Built-in SSL certificates
  • Upgrade

Cause

It should be expected.  After upgrade, BIG IP will create additional symbolic links. 

Recommended Actions

There is no necessary to remove the symbolic link. 

A new symbolic link will be created after a software upgrade, unused symbolic links could be used by previous software versions. 

Additional Information

These are actually symbolic links,  just like shortcuts pointing to the same original file.
