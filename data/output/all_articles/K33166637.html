Description

This solution describes the conditions that cause the following Antivirus check error.

  • Users that attempt to connect to an Access Policy fails a Antivirus check.
  • Symptoms
  • You will observe the following error in /var/log/apm:
<bigip_hostname> info apmd[13008]: 01490006:6: /Common/<access_policy_name>:Common:<session_id>: Following rule 'fallback' from item 'Antivirus' to item 'AntiVirus Fail'
<bigip_hostname> notice apmd[13008]: 01490143:5: /Common/<access_policy_name>:Common:<session_id>: Logging Agent: Failed to detect AntiVirus software on client machine. Authorization denied.

Environment

  • APM (Access Policy Manager)
  • Antivirus check object
  • Endpoint Inspection
  • EPSEC/OPSWAT

Cause

  1. Users do not have permissions to run the check (typically administrator permission-level).
  2.  A local Security Software on the device is blocking the Antivirus check.
  3. The Endpoint Inspection components and/or OPSWAT libraries are not installed or running on the device.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Verify that users have permissions to run the Antivirus check per Solution K15302653: BIG-IP Edge Client operations guide | Chapter 6: Endpoint inspection table 6.5 "Checks that require a permission-level other than user."
  2. Ensure no other local security software is blocking the AV Check.
  3. Use the Client Troubleshooting Utility to verify that the Endpoint Inspection components and OPSWAT libraries are installed and running on the device.
