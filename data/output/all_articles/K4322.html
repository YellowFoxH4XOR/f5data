Topic

Starting in BIG-IP 4.5.12 and version 4.6.3, you can configure the amount of time that BIG-IP will wait for the configuration to finish loading. This should be necessary only if you are running very large configurations on older platforms.

To set the configuration timeout, perform the following steps:

  1. Log in to the command line.

  2. Change the value of the LoadTimeout bigdb key, using the following command syntax:

    bigpipe db set Common.Bigip.LoadTimeout = <seconds>

    Replace <seconds> with the number of seconds that you would like BIG-IP to wait to finish loading the configuration. The default value is 30 seconds.
