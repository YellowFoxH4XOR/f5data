Description

When adding SQL monitor to pool member, it fails and brings the monitor down, with the following error
/var/log/DBDaemon-0.log:

2023-09-22 07:58:18,853-0700 [id21_DBPinger-] - DB DriverManager.getConnection failed 2023-09-22 07:58:18,853-0700 [id21_DBPinger-] - SQL Exception: org.postgresql.util.PSQLException: Connection to : refused. Check that the hostname and port are correct and that the postmaster is accepting TCP/IP connections.

Environment

  • Pools with SQL servers as pool members

Cause

The error indicates that there was an error with the provided connection string, the IP address, port combination or hostname and port combination are preventing the BIG-IP from successfully connect to SQL server. Also a firewall between BIG-IP and the SQL server can result in this.

Recommended Actions

Check the configured connection string on the pool member in question, also make sure to test the reachability of the SQL server port from BIG-IP, if using hostname instead of IP address, then make sure the fqdn used is resolved properly on BIG-IP
