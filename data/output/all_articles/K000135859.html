K000135859: [F5OS-C] error message: "Unable to read optic EEPROM - device is unusable" and "Optic REMOVED."

Type
Support Solution
Published
2023-08-15
Updated
2024-11-15
Applies to
  • F5OS
  • VELOS Platforms
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0, 1.5.X, 1.5.0, 1.5.1
  • VELOS BX110 Blade
Source
https://my.f5.com/manage/s/article/K000135859

Description

Unable to read optic EEPROM - device is unusable message is logged in /var/F5/partition/log/velos.log. For example:

blade-x(px) fpgamgr[14]: priority="Err" version=1.0 msgid=0x303000000000008 msg="Unable to read optic EEPROM - device is unusable." portgroup=1.

blade-x(px) fpgamgr[14]: priority="Notice" version=1.0 msgid=0x303000000000014 msg="Optic REMOVED." Portgroup="x/x".

Note: Portgroup x/x may or may not be configured, and interfaces are disabled.

Environment

  • Velos
  • Partition
  • Portgroup
  • You may also observe error messages such as SDK error during device programming and Unexpected NACK detected during I2C transaction.

Cause

  • Bug ID1328985
  • Bug ID1345977

Recommended Actions

  • Ensure that all interfaces, used or unused, are enabled:

    interfaces interface <interface> config enabled

  • Due to bug ID1207977 it is also recommended to disable lldp for interfaces that are in a DOWN status:

    lldp interfaces interface <interface> config disabled

Additional Information

This bug may affect live portgroup as well.
