Known Issue

A SIP virtual server may drop some SIP messages under heavy load. The default SIP ingress queue length of 16 may be insufficient for processing a large volume of traffic. For example, when running a load test against a SIP virtual server, you may observe that the SIP virtual server drops a small percentage of SIP messages.

Impact

The SIP virtual server drops some SIP messages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H455107 on the Diagnostics > Identified > Low|High screen.
  • The SIP virtual server drops some SIP messages.
  • Packet captures may show SIP traffic arriving at the BIG-IP system, but not forwarded to the pool member.
