Description

You would like to know which snmp traps are used when a pool or node is changing status.

Environment

SNMP traps

Cause

None

Recommended Actions

BIG-IP stores SNMP traps in two specific files:

/etc/alertd/alert.conf
Contains default SNMP traps.

/config/user_alert.conf
Contains user-defined SNMP traps.

On the alert.conf file you will find the following OIDs which are related to status changes of pools and nodes.

alert BIGIP_MCPD_MCPDERR_POOL_MEMBER_MON_STATUS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.10"
}
alert BIGIP_MCPD_MCPDERR_POOL_MEMBER_MON_STATUS_UP {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.11"
}
alert BIGIP_MCPD_MCPDERR_NODE_ADDRESS_MON_STATUS {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.12"
}
alert BIGIP_MCPD_MCPDERR_NODE_ADDRESS_MON_STATUS_UP {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.13"
}

A description for each OID below:

bigipServiceDown (.1.3.6.1.4.1.3375.2.4.0.10)
A BIG-IP system health monitor has detected a service on a node to be stopped and thus marked the node as down.

bigipServiceUp (.1.3.6.1.4.1.3375.2.4.0.11)
A BIG-IP system health monitor has detected a service on a node to be running and has therefore marked the node as up.

bigipNodeDown (.1.3.6.1.4.1.3375.2.4.0.12)
A BIG-IP system health monitor has marked a node as down.

bigipNodeUp (.1.3.6.1.4.1.3375.2.4.0.13)
A BIG-IP system health monitor has marked a node as up.

Additional Information

The MIB file that addresses pool members and nodes availability state is F5-BIGIP-LOCAL-MIB.txt
