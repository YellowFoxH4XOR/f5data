K62110403: Insufficient disk space on /shared/vmdisks. Need 5044M additional space.

Description

vCMP Guest creation fails with an error message as shown below
err vcmpd[7368]: 01510004:3: Insufficient disk space on /shared/vmdisks. Need 5044M additional space.

Environment

  • VCMP Guests 
  • BIG-IP 
  • Low disk space

Cause

Probably hitting Bug ID 528056: VCMP: Large vdisk was unable to migrate in 15 minute timeout

Recommended Actions

  1. Increase the migrating timeout db var from 900 to 2700, to do that run the following command from the bash:   
    # tmsh modify sys db vcmp.timeout.migrating value 2700
  2. Saved the configuration
    # tmsh save sys config
  3. Deleted all of the Virtual Disks for the failed Guest 
  4. Update the failed Guest to Configured state with "none" for Virtual Disk
  5. Deploy the failed Guest
