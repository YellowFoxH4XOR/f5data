Description

This article provides guidance on how to efficiently disable or enable all Local Traffic Manager (LTM) objects—including virtual servers, pool members, and nodes—on a BIG-IP LTM system for maintenance operations. The BIG-IP GUI does not offer a single action for bulk operations, but the 'tmsh' CLI enables streamlined management of these objects. 

Environment

  • BIG-IP LTM module
  • Standard LTM configuration with multiple virtual servers, pools, and nodes

Cause

For disabling/enabling Pool Member and/or Node objects one-by-one, you can still refer to K13310. The BIG-IP GUI does not provide a single control for bulk disabling/enabling all the Virtual Server, Node, Pool Member objects. This is functioning as designed.

Answer/Recommended Actions

Note: It's always recommended to perform such activities under a planned Maintenance Window. Disabling Virtual Servers and/or Nodes, Pool Members can lead to service disruptions.

To perform bulk disabling/enabling of LTM objects like Virtual Servers, Nodes, Pool Members, use the following 'tmsh' CLI commands: 

Virtual Servers:

  • Disable all Virtual Servers:
    • tmsh modify ltm virtual all disabled
  • Re-enable all Virtual Servers:
    • tmsh modify ltm virtual all enabled

Nodes:

  • Disable all Nodes (graceful):
    • for node in $(tmsh list ltm node | grep -oP '(?<=ltm node )\S+'); do tmsh modify ltm node $node session user-disabled; done
  • Force all Nodes offline:
    • for node in $(tmsh list ltm node | grep -oP '(?<=ltm node )\S+'); do tmsh modify ltm node $node state user-down session user-disabled; done
  • Re-enable all Nodes:
    • for node in $(tmsh list ltm node | grep -oP '(?<=ltm node )\S+'); do tmsh modify ltm node $node state user-up session user-enabled; done

Save Configuration:

  • Save configuration after the changes:
    • tmsh save /sys config

 

Additional Information

  • Disabling a Node automatically propagates the disabled state to all Pool Members sharing that IP across all Pools, streamlining the process.
  • "Disabled" state allows existing persistent connections to continue, while "Forced Offline" prevents new connections and lets existing ones time out.
  • These CLI methods are efficient alternatives to manual GUI operations for bulk maintenance actions.
