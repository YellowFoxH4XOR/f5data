Known Issue

The Ask.com search engine definition may have an incorrect bot name value.

This issue occurs when the following condition is met:

  • You upgrade a BIG-IP ASM configuration from 11.0.0 to 11.1.0, or from 10.0.0 through 10.2.2

In order to more accurately identify requests from the Ask.com web crawler, the bot name for the Ask.com search engine was changed to the value teoma in BIG-IP ASM 10.2.3 and 11.1.0. The value is correctly set on a clean installation of 11.1.0. However, when upgrading from an affected version to 11.1.0, the setting is not modified to the new value during the upgrade process.

Impact

The BIG-IP ASM system performs unnecessary DNS queries.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H378375 on the Diagnostics > Identified > Low screen.
  • The BIG-IP ASM system may generate excessive DNS requests in an attempt to verify the incorrect bot name.

    Note: For more information about this symptom, refer to K13256: The Ask.com toolbar may generate excessive DNS queries.
  • Requests from the Ask.com search engine may be incorrectly identified as web-scraping violations.
  • If DNS is not functioning correctly, the BIG-IP ASM bd process may restart and dump the core file, and the system may temporarily fail to process traffic.

    Note: For more information about this symptom, refer to K12308: Web scraping detection may cause the BIG-IP ASM to dump core if DNS is not accessible.?

Workaround

To work around this issue, you can manually change the bot name associated with the Ask.com search engine. To do so, perform the following procedure:

Impact of workaround: This procedure will change the criteria for activating bot detection for the Ask.com search engine to a new preferred value, which will affect all policies on the BIG-IP ASM system and may lead to a change in statistics profiles for web scraping violations.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Click Application Security.
  3. Click Options.
  4. Click Advanced Configuration.
  5. Click Search Engines.
  6. In the Search Engine List, click Ask.
  7. In the Bot Name field, delete the value displayed (ask) and replace it with the following value:

    teoma
  8. Click Save.
