Description

- BIG-IQ is popping up HA Alert:

"Scheduled sync of files failed: /usr/bin/ha_sync_files: line 94: 12184 Terminated ( sleep "$sleep_time" & local sleep_pid="$!"; trap "kill $sleep_pid 2>/dev/null" EXIT; wait "$sleep_pid"; kill "$cmd_pid" 2> /dev/null ) "

 

- /var/log/restjavad.x.log contains errors similar to:

[WARN][16 Oct 2023 22:34:00 UTC][/shared/ha/sync-files-task/a333a7e6-f13a-46f0-a7af-28d6c647a3ff/worker SyncFilesTaskWorker] [/bin/bash, -c, /usr/bin/ha_sync_files 10.0.0.100] failed with exit code 143, stdout: Saving running configuration...

...

[WARN][14 Oct 2023 22:34:00 UTC][/shared/ha/sync-files-task/30cc6a55-e807-4844-84e8-b416dc270b70/worker SyncFilesTaskWorker] [/bin/bash, -c, /usr/bin/ha_sync_files 10.0.0.100] failed with exit code 143, stdout: Saving running configuration...

...

[WARN][11 Oct 2023 22:33:00 UTC][/shared/ha/sync-files-task/0540a061-3954-4925-8aa8-64974f4c17e0/worker SyncFilesTaskWorker] [/bin/bash, -c, /usr/bin/ha_sync_files 10.0.0.100] failed with exit code 143, stdout: Saving running configuration...

- BIG-IP backup file under /shared/ucs_backups shows file size above 600 MB usually caused by old EPSEC definitions for APM module which UCS contains

 

Environment

  • BIG-IQ CM cluster
  • Managed BIg-IPs
  • Scheduled backups
  • Huge BIG-IP UCS files
  • Cluster sync issues

Cause

Error related to file sync is caused by 60 min timeout which occurs during hile sync. This is due to size of UCS files and can be related to network throughput or config save which might take log.

Recommended Actions

Reduce size of ucs files by removing old EPSEC files by following below KB:

K21175584 : Removing unnecessary OPSWAT EPSEC packages from the BIG-IP APM system
