Known Issue

This is the result of a known issue. If a user accesses a Microsoft SharePoint 2007 server through a Portal Access Web Application, and selects Explorer View from the SharePoint View drop-down menu at the top right corner of the page, Explorer View fails to load and no files are displayed. If the user selects the default view from the View drop-down menu (for example, All Documents or All Pictures), the files are displayed.

F5 Networks Product Development tracked this issue as CR97567 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-5 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by configuring an Application Tunnel or Network Access connection for access to a SharePoint 2007 server. For more information about configuring Application Tunnels and Network Access connections, refer to the FirePass Controller Administrator Guide.
