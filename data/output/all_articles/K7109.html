Known Issue

This is the result of a known issue. The SSL key management code makes repeated calls to OpenSSL cipher resources, which can result in a memory leak in the iControlPortal.cgi process. As a result, the BIG-IP LTM system may fail due to memory exhaustion.

F5 Product Development tracked this issue as CR74629, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
