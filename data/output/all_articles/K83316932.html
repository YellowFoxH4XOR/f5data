Topic

This article provides an overview of the Manual Resume feature for BIG-IP LTM monitors.

Description

Important: If any pool members or nodes are marked down and have the Manual Resume feature enabled, they are re-enabled automatically upon reload of the BIG-IP configuration and are marked up as soon as they are available, as determined by the monitor.

When the Manual Resume feature is enabled for a BIG-IP LTM monitor, and the monitor marks a resource (pool member or node) as down, the resource becomes unavailable until resumed (enabled) manually. After enabling a resource that has been marked down, the resumed resource remains down until the monitor determines the resource is available. To perform the functions related to the Manual Resume feature, refer to the following procedures:

  • Enable the Manual Resume feature
  • Manually resume a pool member
  • Manually resume a node

To watch a video demo of these procedures, go to  Using Manual Resume for BIG-IP LTM monitors.

Enable the Manual Resume feature

To enable the Manual Resume feature for a BIG-IP LTM monitor, perform the following procedure:

Impact of procedure: Any resource marked down by the monitor remains marked down until you manually resume the affected resource using the Manually resume a pool member or Manually resume a node procedures below.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Select the monitor you want.
  4. Under Configuration, select Advanced.
  5. Under Manual Resume, select Yes.
  6. Select Update.

Manually resume a pool member

To resume a pool member that was marked down by a monitor with the Manual Resume feature enabled, perform the following procedure:

Impact of procedure: The pool member is re-enabled. The pool member is marked up as soon as the monitor determines the pool member is available.

Important: If the pool member is marked down by a monitor associated with the parent node, you must manually resume the node. To do so, perform the Manually resume a node procedure below.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools.
  3. Select the pool for the affected pool member you want to resume.
  4. Select Members.
  5. Select the check box for the pool member you wish to resume.
  6. Select Enable.

Manually resume a node

To resume a node that was marked down by a monitor with the Manual Resume feature enabled, perform the following procedure:

Impact of procedure: The node is re-enabled. All pool member resources for the affected node are re-enabled and will be marked up as soon as the monitor determines the node is available.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Nodes.
  3. Select the check box for the node you wish to resume.
  4. Select Enable.
