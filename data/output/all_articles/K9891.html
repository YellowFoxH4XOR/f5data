Topic

AVG no longer supports customers running AVG Anti-Virus Free Edition 7.x. Customers are requested to upgrade to versions 8 or later.

Note: For more information, refer to the following location:

http://freeforum.avg.com/read.php?1,155500

Note: OPSWAT has not released support for AVG Anti-Virus version 8.5 at this time. For more information about AVG Anti-Virus version 8.x, refer to K8796: Support for AVG Anti-Virus 8.x.

F5 Networks Product Development submitted a request to OPSWAT, Inc. to add support for AVG Anti-Virus version 8.5. F5 Networks Product Development is tracking this enhancement request as CR118622.
