Issue

Old Behavior

In versions prior to BIG-IP 11.6.0, the Traffic Management Shell (tmsh) net cmetrics commands display all congestion metrics across all route domains.

New Behavior

Beginning in BIG-IP 11.6.0, the tmsh utility net cmetrics commands show congestion metrics only for route domain %0.

F5 Product Development tracked this change as ID 556249.

Impact

In BIG-IP 11.6.0, you must specify the route domain to manipulate congestion metrics if the object doesn't exist within the default route domain.

Recommended Actions

To manipulate congestion metrics in a domain other than %0, you must specify the route domain.

For example, to show congestion metrics for route domain %1, you would type the following command:

tmsh show net cmetrics dest-addr 192.168.1.1%1

To delete congestion metrics for route domain %1, you would type the following command:

tmsh delete net cmetrics dest-addr 192.168.1.1%1
