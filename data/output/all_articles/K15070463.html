Issue

Error Message

warning tmm[<PID>]: 01480001:4: No held transactions to sink.

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process

For example:

warning tmm[5826]: 01480001:4: No held transactions to sink.

warning tmm[5826]: 01480001:4: Transaction is already sunk.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You provision and configure software modules on the BIG-IP system, such as ASM, APM, or WOM, that utilize the internal plugin framework to communicate with TMM.
  • The internal plugin framework encounters an error condition while processing transactions for a request.

For example, this message may be seen if the plugin signals the end of a Layer 7 (L7) request to TMM without having signaled the start of the L7 request.

Impact

The affected plugin may not function properly or disrupt the traffic flow.

Recommended Actions

  • For BIG-IP APM systems, check to see that the current sessions and current in-progress sessions do not exceed licensed and configured limits.
  • Check to see if the BIG-IP system is experiencing memory pressure or is exhausting available system resources.
  • For BIG-IP ASM systems, this message may be generated when blocking requests containing an Expect: 100-Continue HTTP header. While this message may be benign in some cases, it may also indicate a problem with the BIG-IP ASM system. If this message is logged excessively or if traffic disruptions are correlated with the messages, contact F5 Support to further diagnose the issue.
