K000149116: Prometheus shows EOF error when pulling telemetry from BIG-IP

Type
Support Solution
Published
2024-12-27
Updated
2025-03-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 17.5.X, 17.5.0, 17.1.2, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000149116

Description

When Prometheus is making HTTPS request to pull Telemetry from BIG-IP, you received an "EOF" error message.

When taking a packet capture, BIG-IP seems to FIN the connection during TLS handshake.

Environment

  • BIG-IP v17.1.0.1 or above and has FIPS Compliance enabled
  • Prometheus making HTTPS requests to pull Telemetry
  • Client (such as Prometheus) does not support TLS Extended Master Secret (EMS) extension

Cause

FIPS 140-3 now require TLS EMS to be used, while the client (Prometheus) does not support it.

Recommended Actions

You may consider one of the following workarounds:

  1. Upgrade Client side (Prometheus) to support TLS EMS, such that it uses more recent version of Golang.
  2. Use HTTP (not encrypted) to pull the required data.
  3. (More difficult) If FIPS is not required, you may activate the BIG-IP without FIPS license.

Additional Information

None.
