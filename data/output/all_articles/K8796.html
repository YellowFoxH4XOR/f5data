Topic

Support for AVG Anti-Virus 8.x was introduced in OPSWAT 2.5.7 (hotfix-99074), however the following checks were not supported:

  • Engine version
  • Database signature
  • Database age

Support for the database age check for AVG Anti-Virus 8.x was introduced in OPSWAT 2.5.10 (hotfix-104660), however the following checks are not currently supported:

  • Engine version
  • Database signature

Note: FirePass version 6.0.3 ships with OPSWAT 2.5.10. FirePass version 6.1.0 ships with OPSWAT 3.4.3.

Important: Older builds of AVG Anti-Virus 8.x (builds released prior to mid-July 2008) may not be compatible with the database age check. Performing an update or auto-update in AVG Anti-Virus 8.x does not resolve this compatibility issue. If client systems running AVG Anti-Virus 8.x fail the Windows Antivirus checker database age check, and you installed OPSWAT 2.5.10 (hotfix-104660) or a later version of the OPSWAT hotfix on the FirePass controller, obtain a newer build of AVG Anti-Virus 8.x and install it on the client systems.

If you configure the Windows antivirus checker to require a specific engine version or database signature, clients running AVG Anti-Virus 8.x will not pass the pre-logon check. If you need to support clients running AVG Anti-Virus 8.x, ensure that the Windows antivirus checker does not require a specific engine version or database signature by performing the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. Next to the pre-logon sequence you want to modify, click the edit link or the backup & edit link.
  4. Click the Check for Antiviruses action.
  5. In the Edit Action screen, click the Windows antivirus checker link.
  6. Locate the Antivirus section in which the Antivirus software menu is set to Grisoft, Inc or Any supported.
  7. Clear the Engine version field.
  8. Clear the Database signature field.
  9. Optionally, if your clients are running an older build of AVG Anti-Virus 8.x (builds released prior to mid-July 2008), clear the Database is not older than (in days) field.
  10. Click the Update button.
  11. Click the Back to console link at the top right corner of the page.

The FirePass Windows antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT, Inc. OPSWAT provides a vendor-independent framework for endpoint security management.

F5 Networks Product Development submitted a request to OPSWAT, Inc to add support for the engine version, database signature, and database age checks for AVG Anti-Virus 8.x. F5 Networks Product Development is tracking this enhancement request as CR99535.

Important: F5 Networks does not provide a schedule for incorporation of new OPSWAT SDK libraries. Typically, updates with the new libraries are periodically issued as hotfixes to supported versions of FirePass software. For more information about OPSWAT hotfixes, refer to K6664: Obtaining and installing OPSWAT hotfixes.
