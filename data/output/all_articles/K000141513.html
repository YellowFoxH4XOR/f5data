K000141513: [F5OS-A] After upgrading, only health option shows up in the LCD panel, unable to go to ConfD mode and failing to access to AOM.

Type
Support Solution
Published
2024-10-18
Updated
2024-10-18
Applies to

  • F5OS-A
Source

Description

F5OS-A Upgrade failed from old version (older than 1.2.x) to latest version.
Installation status stays "In Progress".

Only health option shows up in the LCD panel.

/var/F5/system/log/platfrom.log has the below log repeatedly

platform-hal[8]: priority="Err" msg="Action Error" index=13 message="LOPd Communication Error: LOP USB Device is not present at either: /dev/ttyAOM or /dev/ttyACM0"

 

Can not go to Confd mode with the error message

su admin

Failed to connect to server

 

Clean install was tried but it can not go to AOM mode.

 

Running the below command, get the below outputs

lsusb

Bus 002 Device 002: ID 0951:1666 Kingston Technology DataTraveler 100 G3/G4/SE9 G2
Bus 002 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
Bus 001 Device 003: ID 1d6b:0102 Linux Foundation EEM Gadget
Bus 001 Device 002: ID f5f5:df11 <<----------- not (f5f5:3800 or f5f5:3000)
Bus 001 Device 004: ID 0403:6014 Future Technology Devices International, Ltd FT232H Single HS USB-UART/FIFO IC
Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub

 

Environment

  • F5OS-A
  • rSeries
  • older than 1.4

Cause

  • Bug ID 1134613
  • Bug ID 1211025

Recommended Actions

  • Follow workaround of Bug ID 1134613

 

Additional Information

New unit or RMA unit may have unsupported version.

Once workaround is done, and have AOM access, recommend to conduct clean install following manual
