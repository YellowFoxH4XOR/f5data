K000135408: HTTP::respond is not allowed under the iRule Event "ACCESS_ACL_ALLOWED"

Type
Support Solution
Published
2023-11-24
Updated
2023-11-24
Applies to
  • BIG-IP
  • BIG-IP APM: 16.X.X, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000135408

Description

An iRule with HTTP::respond under the event "ACCESS_ACL_ALLOWED" generates the below log message under /var/log/ltm:

err tmm1[26032]: 011f0007:3: http_process_state_prepend - Invalid action:0x1070b1 clientside (10.10.10.10:49872 -> 10.11.11.40:443)serverside (10.11.12.142:443 -> 10.11.17.133:59404)(Client side: vip=/Common/vs_apm profile=http pool=/Common/server_pool client_ip=10.10.10.10)
 

Environment

  • BIG-IP APM
  • iRule with HTTP::respond under event "ACCESS_ACL_ALLOWED" 

Cause

HTT::respond is not allowed under the event "ACCESS_ACL_ALLOWED"

Recommended Actions

Use ACCESS::respond instead of HTTP::respond 

Additional Information

None
