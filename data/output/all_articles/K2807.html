Issue

The following messages display on BIG-IP switch appliances that have quiet_boot disabled.

BSP CPU...... Microcode Error

Immediately replaced with the following:

AP CPU......Microcode Error

These are benign messages and do not indicate a hardware problem.

This issue occurs because newer models of BIG-IP use 1.26GHz processors. These processors do not currently have a matching entry in the built-in BIOS table. The system BIOS prints those message because it cannot match the processor version to an entry in the BIOS table table. According to the manufacturer, this does not have any negative influence on product performance or stability.

All F5 Networks products undergo thorough manufacturing and burn-in testing before they are shipped. These tests are designed to discover a wide range of hardware and configuration problems. No problems have been detected on systems displaying these error messages.
