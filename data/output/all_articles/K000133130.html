K000133130: Importing ASM configuration to BIG-IQ fails when a created policy at panel "Guided Configuration" (cloned) is used as parent policy

Type
Support Solution
Published
2023-03-23
Updated
2023-03-23
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0
Source
https://my.f5.com/manage/s/article/K000133130

Description

Unable to import child ASM policies to BIG-IQ, this happens when a "Guided Configuration" created policy is used as parent.


Environment

  • BIG-IQ CM
  • BIG-IP ASM
  • ASM Guided Configuration Policy is used as parent.

Cause

At BIG-IP, the ASM policies created through 'Guided Configuration' are saved with an extra path name. When these policies are cloned and used as parent to other-one, the newly created child policy inherit such path name. When configuration is imported to BIG-IQ CM, the path name scheme causes incompatibility, such issue was identified internal ID 1239029 was created to track it.


 Recommended Actions

Workaround process is triggered at BIG-IP and involves to export current parent and child policies to an XML file, then complete modifications as per next steps:

 

1. Export parent policies into XML file.

2. Open the file with a text editor, and edit file by removing the highlighted texts and save it :

 

<?xml version="1.0" encoding="utf-8"?>

                 <policy integrity_check="29c13d7aaf28b4c5e31a93135efcc454" bigip_version="16.1.3" name="/Common/GuidedConfig_A.app/GuidedConfig_A_Cloned_Policy_B">

                     <type>Parent</type>

 <policy_version>

 <timestamp>2023-02-24T06:19:07Z</timestamp>

 <device_name>xxxxxxxxx</device_name>

 <policy_name>/Common/GuidedConfig_A.app/GuidedConfig_A</policy_name>

 

3. Re-import the modified file as new policy of type parent (using different name).

4. Export child policies into file.

5. Re-import child policies configuration, this time using new policies created in step 3 as parent policies.

6. Now on BIG-IQ go to devices tab and rediscover + reimport ASM service (importing without rediscover will not work).
