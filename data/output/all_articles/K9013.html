Known Issue

This is the result of a known issue. The Date HTTP header may be invalid for objects served from RAM Cache. The invalid Date HTTP header will contain the header name as part of the date, and the actual date is truncated. The invalid Date HTTP header will appear similar to the following example:

Date: Date: <truncated date>

F5 Product Development tracked this issue as CR99207 and it was fixed in BIG-IP 9.4.5. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
