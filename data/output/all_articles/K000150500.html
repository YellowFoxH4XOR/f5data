Description

  • BIG-IP fails to come up after attempting to restore configuration from UCS file.
  • System goes into a reboot loop after loading the UCS file.

 

Environment

  • Restored configuration settings from a UCS file.
  • The UCS file happened to contain encrypted passwords or passphrases using a system master key.
  • System now in a reboot loop and mcpd is crashing.
  • These errors show up in the /var/log/ltm file:
    • Master Key decrypt failure - decrypt failure - final
    • Master key OpenSSL error: <Number>:error:<Number>:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt:evp_enc.c:
    • Loading configuration process failed.
    • Symmetric Unit Key decrypt failure - decrypt failure
    • Lost connection to mcpd - reestablishing.
    • The connection to mcpd has been lost, try again.
    • Error: failed to reset strict operations; disconnecting from mcpd.

Cause

The UCS file loaded used encrypted passwords or passphrases tied to a different master key.

Recommended Actions

Follow the steps in this article to fix the master key on the BIG-IP BEFORE you load the configuration:

Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)

 

Additional Information

You may need to run this command to recover the system since it is in a reboot loop after encountering this error:

Important: This command below will reset all settings and even require re-licensing the installation!

tmsh load sys config default

You can also delete the guest and recreate it to start over if running on a hosted environment.

To stop the reboot loop temporarily:

bigstart stop mcpd
