Known Issue

BIG-IP ASM JavaScript injection for cross-site request forgery (CSRF) may cause content to not render.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured with the JavaScript injection feature for CSRF.
  • Content processed by the security policy is an HTML response page from the origin web server that contains multiple iframes with query parameters.

    For example:

    <!DOCTYPE html>
    <html>
    <head>
    <title> iframes with parameters </title>
    </head>
    <frameset cols="25%,25%">
      <frame name="frame1" src="http://10.0.0.105/iframe1.php?p=1">
      <frame name="frame2" src="http://10.0.0.105/iframe2.php">
    </frameset>
    </html>

Impact

The content injected with the CSRF JavaScript does not render correctly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Content injected with the CSRF JavaScript renders as a blank page.

Workaround

To work around this issue, you can create a custom iRule to bypass CSRF JavaScript injection for the URL. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you implement the suggested workaround during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > Create.
  3. In the Name box, type a name for the iRule.
  4. In the Definition box, enter the following text:

    when HTTP_REQUEST {
        ASM::enable
        if { $uri contains "<affected url>" } {
                    ASM::disable
         }
    }

    Important: Modify the iRule stanza by replacing <affected url> with the path and object affected by the CSRF JavaScript injection.

  5. Click Finished.
  6. Click Virtual Servers.
  7. Click the name of the virtual server that is affected by this issue.
  8. Click the Resources tab.
  9. In the iRules section, click Manage.
  10. From the Available column, select the iRule you previously created.
  11. To move the iRule to the Enabled column, click the << button.
  12. Click Finished.
