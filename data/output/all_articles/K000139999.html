K000139999: Configuring local hostname resolution for F5OS

Type
Support Solution
Published
2024-06-12
Updated
2024-06-12
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source

Description

You should consider using these procedures under the following condition:
You want to permanently add hosts to your local /etc/hosts file.

 

Environment

F5OS rSeries
Local Hostname Resolution

 

Cause

N/A.

 

Recommended Actions

Use the following command: 

system dns host-entries host-entry

Example:

appliance-1(config)# system dns host-entries host-entry www.test.com config hostname www.test.com ipv4-address 1.1.1.1
appliance-1(config-host-entry-www.test.com)# commit
Commit complete.

appliance-1# show running-config system dns
system dns host-entries host-entry www.test.com
 config hostname www.test.com
 config ipv4-address [ 1.1.1.1 ]
!
