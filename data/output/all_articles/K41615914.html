Topic

Starting with BIG-IP 14.1.0, the TMOS Shell tmsh and iControl REST interfaces have the ability to retrieve system utilization times for the available, unavailable, and in-maintenance states.

Description

Using tmsh, you can view the amount of time that a BIG-IP system has spent in the available, unavailable, and in-maintenance states.

To view these states use the following steps.

  1. Log in to tmsh.
  2. Type the following command: 

    show /sys availability

Output appears similar to the following example:

-----------------------------------------------------
Sys::Availability
Availability-State  Time
-----------------------------------------------------
available           2 days, 6 hours, 25 mins, 40 secs
unavailable         5 mins, 23 secs
maintenance         1 min, 36 secs

Note: The displayed data is generated from content stored in the binary log file /var/log/availability.0. If this file becomes corrupt or is deleted, the command does not produce any data.

Using the iControl REST interface, you can view the amount of time that a BIG-IP system has spent in the available, unavailable, and in-maintenance states. To do so, use the following command syntax:

curl -k -u <username>:<password> -H "Content-Type: application/json" -X GET  https://<big-ip ip address>/mgmt/tm/sys/availability | jq -M .

Note: The REST command can produce verbose JSON output. To format the JSON output to a more user-friendly format, use the jq command-line JSON processor command. The jq command -M flag sets the formatted JSON output to use monochrome when displaying the JSON output.  The . (period) parameter is optional in jq versions 1.5 and later.

For example:

curl -k -u admin:admin -H "Content-Type: application/json" -X GET  https://192.168.1.86>/mgmt/tm/sys/availability | jq -M .         

Note: Time in the specified state is displayed in seconds.

Output appears similar to the following example:

{
  "kind": "tm:sys:availability:availabilitystats",
  "selfLink": "https://localhost/mgmt/tm/sys/availability?ver=14.1.0.2",
  "entries": {

}
