Description

LightweightM2M protocol (LwM2M) doesn't work even over UDP stream.

Environment

  • NGINX Plus R16 or below
  • LwM2M protocol

Cause

LwM2M protocol works over UDP and requires UDP "sessions" in order to work. NGINX Plus supports UDP "sessions" beginning in the NGINX Plus R17 (1.15.7) release.

Recommended Actions

Add the udp and reuseport options to enable UDP sessions: 

  1. Upgrade NGINX Plus to the R17 version or higher.
  2. Enable UDP support for a virtual server in the stream context. 
  3. Add reuseport option to the listen directive in the stream context.

The following configuration snippet covers LwM2M protocol requirements:

stream {
    server {
        listen <port> udp reuseport;
    }
}
