Description
Beginning from 13.0.0, IF-MIB::ifLinkUpDownTrapEnable is implemented to enable/disable linkUp/linkDown traps.
Default value is enabled, so you would like to suppress ".1.3.6.1.4.1.8072.3.2.10" trap, you may need to disable IF-MIB::ifLinkUpDownTrapEnable.
 

Environment

  • BIG-IP LTM

Cause
None.

Recommended Actions

 1. Login to BIG-IP via SSH
 2. Check the current status;

    # snmpwalk -v2c -c public localhost ifName
    # snmpwalk -v2c -c public localhost ifLinkUpDownTrapEnable


Example;
 [root@test:Active:Standalone] config # snmpwalk -v2c -c public localhost ifName
 IF-MIB::ifName.32 = STRING: mgmt
 IF-MIB::ifName.176 = STRING: 1.0
 IF-MIB::ifName.192 = STRING: 1.1
 ---snip---
 [root@test:Active:Standalone] config # snmpwalk -v2c -c public localhost ifLinkUpDownTrapEnable
 IF-MIB::ifLinkUpDownTrapEnable.32 = INTEGER: enabled(1)
 IF-MIB::ifLinkUpDownTrapEnable.176 = INTEGER: enabled(1)
 IF-MIB::ifLinkUpDownTrapEnable.192 = INTEGER: enabled(1)
 ---snip---
 [root@test:Active:Standalone] config #

 3. Disable IF-MIB::ifLinkUpDownTrapEnable

    # snmpset -c public localhost IF-MIB::ifLinkUpDownTrapEnable.xxx i 2


 Example; disable the trap for interface 1.1;
 [root@test:Active:Standalone] config # snmpset -c public localhost IF-MIB::ifLinkUpDownTrapEnable.192 i 2
 IF-MIB::ifLinkUpDownTrapEnable.192 = INTEGER: disabled(2)
 [root@test:Active:Standalone] config #
