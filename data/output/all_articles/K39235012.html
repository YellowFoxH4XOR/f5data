Description

Observed Merged process is having periodic CPU spike.

  • Merged process CPU spike
  • Execessive amount of Diameter(mrf) alert display for command, tmsh show sys alert lcd
  • Execessive amount of Diameter(mrf) are found in /var/log/ltm
  • Mar 9 03:35:06 lab1.com err tmm4[11406]: 01cc0003:3: Peer (ocs.lte.lb.epc.mnc000.mcc000.3gppnetwork.org from pool /Common/pool_DTDRA at 192.168.1.1:3868) errors percentage 0 is back under the major threshold 75 percentage

Environment

  • MRF
  • Diameter peers 
  • High amount of diameter message error answer(return from pool member) in relative to diameter request send.
  • Diameter peer state flapping

Cause

Alertd is configured to pipe MRF/diameter event to LCDwarn by default.

ID1094221

Recommended Actions

Create custom alert to stop Alertd to forward MRF event to LCDwarn

Add additional alert below for MRF Diameter and comment lcdwarn as shown
Edit custom alert /config/user_alert.conf 
alert BIGIP_MRFTRAP_MRFTRAP_DIAMETER_PEER_ERRORS_HEALTH {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.206";
    #lcdwarn priority="5"
}

alert BIGIP_MRFTRAP_MRFTRAP_DIAMETER_PEER_HEALTH {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.208";
    #lcdwarn priority="5"
}
Save the above file.

Perform restart 
bigstart restart alertd

Lastly, clear all LCD alert.

Additional Information

Please refer to https://my.f5.com/manage/s/article/K11094 for procedure to clear all lcd alert.
