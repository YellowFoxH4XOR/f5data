You can determine the level of client encryption on SSL proxy connects by enabling the SSL encryption strength feature from the Configuration utility or the command line.

Note: You can use the SSL encryption strength feature in conjunction with rules to send only specific cipher strength traffic to specific pools. For more information, refer to K1724: Configuring a rule to direct clients to a pool based on SSL cipher strength.

Enabling SSL encryption strength from the Configuration utility

You can determine the level of client encryption on SSL proxy connects by enabling the SSL encryption strength feature. To do this from the Configuration utility, perform the following steps:

  1. From the Configuration menu, click Proxies.
  2. Click on the proxy for which you want to insert the cipher strength.
  3. From the proxy's properties page, click the Proxy Advanced Properties tab.
  4. Check the box next to Insert Cipher.
  5. Click the Apply button.

The inserted field should appear similar to the following:

SSLClientCipher: RC4-MD5, version=TLSv1/SSLv3, bits=128

Note: The actual field will vary depending on what ciphers are chosen.

The servers can now parse the HTTP header and make a decision based on the level of encryption.

Enabling SSL encryption strength from the command line

To enable SSL encryption strength from the command line, execute the following command where <ssl_proxy IP:Port> is the SSL Proxy and Port for your configuration:

b proxy <ssl_proxy IP:Port> cipher insert enable

For example, if the SSL Proxy is 172.23.25.163 on port 443, you would type the following command:

b proxy 172.23.25.163:443 cipher insert enable

The servers can now parse the HTTP header and make a decision based on the level of encryption.

Note: If you want to disable this feature later, set the Common.Bigip.Proxy.InsertClientCipher key to 0 and restart proxyd.
