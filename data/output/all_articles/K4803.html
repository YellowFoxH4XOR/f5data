Known Issue

This is the result of a known issue. The SNAT implementation used by the BIG-IP Local Traffic Manager (LTM) creates a TCP port 21 listener on all VLANs to which the SNAT applies. The port 21 listener is used to do FTP port translation to make active-mode FTP work through the SNAT. An open port scan will show BIG-IP listening on TCP port 21. This configuration, however, is functionally correct and does not present a vulnerability.

F5 Product Development tracked this issue as CR48055, and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
