K000159948: Deleting F5OS R-series configuration backup files via API

Description

This article describes how to delete configuration backup files from F5OS on rSeries systems using the RESTCONF API. F5OS API supports creating, downloading, and restoring backup files, as well as the deletion procedure. This article provides the API method to delete backup files from the configs/ directory to maintain a clean file system and support automated housekeeping tasks.

Environment

  • Product: F5OS-A
  • Version: 1.8.3 or later
  • Platform: rSeries (F5-BIG-BT-R5800, C129, and other rSeries models)
  • API access via port 8888 (RESTCONF)
  • Admin user credentials required
  • Configuration backup files stored in configs/ directory

Cause

Not Applicable

Answer/Recommended Actions

To delete a configuration backup file from F5OS using the RESTCONF API, use the following procedure:

  1. Prepare the API request with the following parameters:
    • Method: POST
    • URL: https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/delete
    • Headers:
      • Accept: application/yang-data+json
      • Content-Type: application/yang-data+json (required)
    • Authentication: admin user credentials
    • Body:

      {"f5-utils-file-transfer:file-name": "configs/<filename>"}

  2. Example using cURL with netrc-file for secure authentication:

    curl -X POST -sk --netrc-file <path/to/netrc-file> "https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/delete" \ -H 'Accept: application/yang-data+json' \ -H 'Content-Type: application/yang-data+json' \ -d '{"f5-utils-file-transfer:file-name": "configs/<filename>"}' -v

  3. Create a netrc file for secure credential storage (optional but recommended):

    vi /path/to/netrc-file

    Add the following content:

    machine <mgmt IP>

    login admin

    password <your-password>

    Set appropriate permissions:

    chmod 600 <path /to/netrc-file>

  4. Verify the deletion:
    • Use the F5OS CLI command: file list path configs/
    • Or use the API to list files:

      POST https://<mgmt IP>:8888/restconf/data/f5-utils-file-transfer:file/list

      Body: {"f5-utils-file-transfer:path": "configs/"}

  5. Expected API response:

    {
    "f5-utils-file-transfer:output": {
    "result": "Deleting the file"
    }
    }

Additional Information

  • The Content-Type header (application/yang-data+json) is required for the API request to succeed.
  • The Authentication header is not required when using basic authentication with username and password.
  • Avoid passing admin passwords in clear text in scripts. Use the --netrc-file option for secure automation.
  • File deletions should be performed through management interfaces (API, CLI, or webUI) rather than direct shell commands due to permission restrictions.
  • Backup files can also be deleted via the F5OS webUI by navigating to SYSTEM SETTINGS → Configuration Backup, selecting the desired file, and clicking Delete.
  • F5 Support does not provide customer-specific scripts. For comprehensive assistance with scripting and programmability functions, contact your F5 account team.
