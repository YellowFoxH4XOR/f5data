Description
The configuration utility shows incomplete list of available load balancing methods, or
vCMP Guest shows incorrect load balancing method "Observed member" via WebUI while TMSH shows the correct method "Least Connections (member)"

Environment

  • BIG-IP Platform
  • Time Limited AWAF license

Cause
A temporary and time limited AWAF license has been activated and has since expired.

Recommended Actions

Remove the expired AWAF license and reactivate the active license.
Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.
  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. Select Re-activate.
  4. For Add-On Registration Key List, select the add-on key to be removed.
  5. Select Delete.
  6. Activate the active license. Fore more information about activating the license, refer to K7752: Licensing the BIG-IP system.
