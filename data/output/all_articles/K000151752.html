Description

For some reason, you may need to verify Server Certificate and Key pairs as well as the Intermediate CA certificate also know as Chain certificate. 

ltm profile client-ssl <profile_name> {
    cert-key-chain {
        set0 {
            cert <certificate>
            key <private_key>
            chain <chain_certificate>
        }
    }
    ...
}

Environment

  • Certificates issued by 3rd party Certificate Authority
  • Server Certificate and Key Pair
  • Intermediate or Chain certificate

Cause

If the newly installed SSL certificate was signed by a different intermediate Certificate Authority (CA) than the previous certificate, the intermediate CA bundle referenced in the SSL profile did not match the issuer of the new certificate, resulting in an incomplete certificate chain being presented to clients. This caused client-side validation failures with errors such as "unable to verify the first certificate".

Recommended Actions

For simplicity, say we put the Server Certificate, Key and Chain certificate in one location, eg. /shared/tmp.

1.) Obtain the information for the Server certificate and pass it through md5.
openssl x509 -noout -modulus -in test_certificate.crt | openssl md5

Output show the md5 message digest:

MD5(stdin)= 71500b0e49e155da5cc6eee0cdb99914

2.) Obtain the information for the Key and pass it through md5.
openssl rsa -noout -modulus -in test_key.key | openssl md5

Output show the md5 message digest:

MD5(stdin)= 71500b0e49e155da5cc6eee0cdb99914

3.) Compare the md5 message digests from steps 1 and 2 to ensure that they are the same.

4.) Verify the Server Certificate against the Intermediate CA certificate. Use the following OpenSSL command.
openssl verify -CAfile <correct_chain.crt> <new_cert.crt>

For example:
openssl verify -CAfile test_chain.crt test_certificate.crt

Successful verification will display same as below:

test_certificate.crt: OK

Failed verification will display same as below:

error 20 at 0 depth lookup: unable to get local issuer certificate
error test-certificate.crt: verification failed
