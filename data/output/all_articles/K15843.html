Known Issue

Under rare circumstances, the snmpd process may produce a core file.

This issue occurs when the following condition is met:

  • An snmpd subagent, such as rmonsnmpd, fails to respond to the snmpd master agent.

Impact

The snmpd process will temporarily fail to receive or send alerts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You may view an snmpd core file in the /var/core directory.
  • You may view messages in the /var/log/daemon.log file that appear similar to the following example:

    warning rmonsnmpd[3803]: AgentX master agent failed to respond to ping. Attempting to re-register.
    err snmpd[3815]: Assertation violation: file mibgroup/agentx/master_admin.c:159, function close_agentx_session(): count < 1000
    warning rmonsnmpd[3803]: lock in _callback_lock sleeps more than 100 milliseconds in snmp_unregister_callback
    err rmonsnmpd[3803]: netsnmp_assert lock_holded < 100 failed callback.c:140 _callback_lock()
    emerg logger: Re-starting snmpd
