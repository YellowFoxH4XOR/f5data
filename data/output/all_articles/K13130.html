Known Issue

The BIG-IP WebAccelerator system logs IPv6 client IP addresses in an incorrect format.

This issue occurs when all of the following conditions are met:

  • A BIG-IP WebAccelerator system is configured with an IPv6 virtual server
  • An IPv6 client connects to the IPv6 virtual server

Impact

Client IP addresses will be incorrectly logged.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP WebAccelerator system displays IPv6 addresses in an incorrect format in the /var/log/wa/access file.

    For example, in place of the value 0.32.1.1 displayed below, the IP address should be logged as the IPv6 formatted value 2002::10:10:20:101:

    0.32.1.1 - - [15/Aug/2011:17:42:54 +0900] "GET / HTTP/1.0" 200 5 "-" "-" "JSESSIONID=10.10.10.10;" 200 - "Pages" pr 15
