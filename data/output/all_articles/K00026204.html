Known Issue

When you delete a Virtual Local Area Network (VLAN), the system removes unrelated VLAN forwarding database (FDB) entries on shared VLAN member interfaces. This issue occurs because VLAN member interface references perform FDB flushing without regard to VLAN tags.

This issue occurs when the following condition is met:

  • You issue a command to delete a VLAN that shares tagged member interfaces with other VLANs.

The following BIG-IP platforms are not affected by this issue:

  • i850, i2000/i4000 series
  • 2000s/2200s
  • 4000s/4200v

Impact

When you delete a VLAN, the system flushes unrelated FDB entries on other VLANs that share tagged VLAN member interfaces with the one you are deleting.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you delete a VLAN, the system flushes FDB entries on shared VLAN member interfaces that you are not deleting.
