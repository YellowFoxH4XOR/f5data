Known Issue

The BIG-IP system logs repeated Secure Simple Mail Transfer Protocol (SSMTP) configuration error messages to the /var/log/maillog file.

This issue occurs when the following conditions are met:

  • SSMTP is not configured on your BIG-IP system.
  • The BIG-IP system runs certain scheduled cron jobs, such as /usr/bin/diskmonitor from the crontab file.

Impact

The system logs error messages to the /var/log/maillog file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the /var/log/maillog log file, you observe error messages similar to the following examples:

    err sSMTP[<pid>]: Unable to connect to "localhost" port 25.
    err sSMTP[<pid>]: Cannot open localhost:25
    err sSMTP[<pid>]: Unable to connect to "localhost" port 25.
    err sSMTP[<pid>]: Cannot open localhost:25
    err sSMTP[<pid>]: Unable to connect to "localhost" port 25.

  • When you view the file configuration setting of the /etc/crontab file, the following stanza is not the first line of the file:

    MAILTO=""

Workaround

To work around this issue, you can use a text editor to modify the /etc/crontab file. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP device.
  2. To open the root crontab file with the vi text editor, type the following command:

    crontab -e -u root

  3. Move the following stanza to the top of the file, under # cron tab for root:

    MAILTO=""

    The root crontab file may appear similar to the following example after making the change:

    # cron tab for root
    MAILTO=""
    1-59/10 * * * * /usr/bin/diskmonitor
    0 */4 * * * /usr/bin/diskwearoutstat
    07 00 * * * /usr/bin/updatecheck -a   
    07 00 16 * * /usr/bin/phonehome_activate    
    59 * * * * /usr/bin/copy_rrd save

  4. Save the file modifications using the following vi editor command sequence:
    • Press the Esc key
    • Type :wq
    • Press the Enter key
  5. Using a text editor, open the /etc/crontab file.
  6. Modify the stanza MAILTO=root to MAILTO="".
  7. Save the file modifications.
  8. Repeat steps 6 and 7 using a text editor, to correct the /etc/cron.d/0hourly file.
  9. Ensure that the MAILTO=root stanza is not present in any of the cron-related files by typing the following command:

    grep -i mailto /etc/cron*

  10. If any of the cron files contain the MAILTO=root stanza, note the file name and repeat steps 6 and 7 using a text editor, to correct the affected files.
