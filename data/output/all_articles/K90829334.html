Description
IP Reputation is not loading after upgrade from 15.1.4 to 16.1.3.1 
/var/IpRep/F5IpRep.dat file is missing

Environment

  • iRule with IP::reputation
  • Recent license change or upgrade

Cause
License change where new license is missing the IPI feature add on

Recommended Actions

Reactivate license and include IPI add on key

Additional Information
# curl api.bcti.brightcloud.com results in 403 - Forbidden: Access is denied

Before you can enable the IP Intelligence feature, the BIG-IP system must have a valid feature license. To obtain a license for the IP Intelligence feature, contact your F5 Sales representative. To reactivate an expired license, refer to K7752: Licensing the BIG-IP system.
