Issue

Description

The Traffic Management Microkernel (TMM) may lose connection to MCPD and restart when running the following TMOS Shell (tmsh) command: tmsh show sys connection.

Note: The BIG-IP system may temporarily fail to process traffic and failover when configured as part of a high-availability (HA) pair.

Environment

  • BIG-IP
  • tmsh

Cause

Unknown at the time of publication.

Recommended Actions

When running the tmsh command tmsh show sys connection, include additional properties to narrow the scope of the search.

For example:

tmsh show sys connection cs-client-addr <ip address>

Note: Replace <ip address> with the IP address for which you want to view connection information.

Additional Information

When the BIG-IP system is processing large amount of connection, it may not be able to parse the entire connection table for display. F5 recommends adding additional properties to the command to narrow the search and present a smaller list.
