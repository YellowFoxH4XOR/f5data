K12006: Proxying multiple Microsoft Exchange ActiveSync servers will always use the first defined server

Knowledge
Published

Legacy Content
Applies to

  • FirePass: 7.0.0, 6.1.0
Source

Topic

When you use FirePass as a proxy for Microsoft Exchange ActiveSync, if you define multiple ActiveSync servers, FirePass will only use the first instance. When you define ActiveSync servers in the Minimal Content-Rewriting Bypass parameter, if you define multiple servers, FirePass will always utilize the first pattern match. This behavior is expected.

Note: For more information about configuring FirePass to proxy Microsoft Exchange ActiveSync, refer to K7812: Configuring FirePass to proxy ActiveSync. 

Workaround

You can work around this issue by utilizing a load balancing system behind the FirePass device to provide a load balanced environment.
