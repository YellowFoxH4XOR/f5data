Description

When managing the APM sessions using the iControl REST API, you get prompted with an error message when retrieving the details attached to one logged user.
Example:
"code":404,"message":"Object not found - <username>","errorStack":[],"apiError":1

Environment

  • You're using BIG-IP APM;
  • You're managing the APM sessions through the REST API.
  • You're trying to retrieve the information associated to a logged in user, by the help of the call (as copied/pasted from the official documentation):
    GET https://<mgmt_ip>/mgmt/tm/apm/access-info?ver=12.0.0&options=apm-user
Cause

This is due to incorrect examples put in the iControl REST API User Guide documentation.

Recommended Actions

We may need to use the following call, instead: https://<mgmt_ip>/mgmt/tm/apm/access-info?ver=X.Y.Z&options="logon-user","<username>".
Example:
  • if the username is "myusername",
  • then the command is: https://<mgmt_ip>/mgmt/tm/apm/access-info?ver=X.Y.Z&options="logon-user","myusername".
