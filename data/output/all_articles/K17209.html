Known Issue

The BIG-IP GTM HTTP monitor may incorrectly detect server states.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM configuration uses the HTTP monitor to detect the state of the server or virtual server object.
  • The server or virtual server object responds to the HTTP health check with a packet that is less than 64 bytes.

Impact

Monitored objects are incorrectly marked down.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP GTM system marks objects down, even if there is a legitimate HTTP response, when the total size of the response packet is less than 64 bytes.

Workaround

To work around this issue, if a custom HTTP monitor will not trigger the server or virtual server object to respond with 64 bytes or more, you can use a TCP monitor.

Impact of workaround: Monitor results will be based on the TCP port availability, and not the HTTP response.
