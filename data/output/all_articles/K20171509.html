Issue

Error Message

An error occurred while adding the BIG-IQ Device: <IP address 1> (primary) connects as <IP address 2> to <IP address 3> (secondary).

In this error message, note the following:

  • <IP address 1> is the configured discovery address of a primary BIG-IQ system.
  • <IP address 2> is the IP address used by the primary BIG-IQ system to add a new secondary BIG-IQ system.
  • <IP address 3> is the IP address of the secondary BIG-IQ system entered on the primary BIG-IQ system.

For example:

An error occurred while adding the BIG-IQ Device: 10.12.23.1 (primary) connects as 192.168.10.1 to 192.168.10.2 (secondary). Please check your discovery address and network configuration.

Message Location

You may encounter this message in the following locations:

  • The BIG-IQ user interface
  • The /var/log/restjavad.0.log file
Description

This message occurs when all of the following conditions are met:

  • You have multiple BIG-IQ systems.
  • You define the primary BIG-IQ system's discovery IP address as either the self or management IP address.
  • You define the secondary BIG-IQ system discovery IP address as the opposite of the primary BIG-IQ discovery address.
  • You attempt to add the secondary BIG-IQ system using the primary BIG-IQ system user interface.

Beginning in BIG-IQ 5.2.0, both primary and secondary BIG-IQ systems in a high availability (HA) configuration must use either a self IP address or the management IP address for communication. F5 recommends the self IP address. For more information about BIG-IQ network connectivity requirements, refer to K15612: Connectivity requirements for the BIG-IQ system.

Impact

You are unable to create a secondary or backup BIG-IQ system.

Recommended Actions

The BIG-IQ system uses the configured discovery IP address for high availability (HA) communication.  Determine if the configured discovery IP address for each system is set properly first  and then modify as needed.  If the discovery IP address for each system is correct and they belong to different subnets, you need to configure a network route to allow the addresses to communicate with each other.

Note: For more information on configuring static routes refer to K13833: Modifying Static Routes.

  • Determining the discovery IP address
  • Modifying the discovery IP address

Determining the discovery IP address

To determine if the BIG-IQ system's discovery IP address is a self IP address or the management IP address, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Select the System tab.
  3. To determine the current self IP and management IP addresses, go to the following locations:
    • THIS DEVICE > General Properties > Management Address
    • THIS DEVICE > Network Settings > Self IPs 
  4. Select BIG-IQ HA.
  5. Under Device Name, verify the hostname of the BIG-IQ system.
  6. Under IP Address, verify the discovery IP address for the BIG-IQ system.

Modifying the discovery IP address

After you determine which BIG-IQ system's discovery IP address you must change, you can change the discovery IP address by performing the following procedure: 

Impact of procedure: This procedure requires removing and rediscovering all managed devices. You should perform this procedure during a planned maintenance window.

  1. Log in to the BIG-IQ user interface on the system requiring modification of the discover IP address.
  2. To remove all discovered devices, click the Devices tab.
  3. Select the check box next to the discovered device.
  4. Select Remove All Services and then select Continue.
  5. Select Remove Device and then select Remove.
  6. Repeat steps 3 through 5 for all remaining discovered devices.
  7. In the web browser URL, after the BIG-IQ hostname or IP address /ui/setup/wizard/address, type the following content:

    For example:

    https://bigiq1.example.com/ui/setup/wizard/address

  8. For Discovery Address, modify the discovery address so that both BIG-IQ systems use either a self IP address or the management IP address. F5 recommends that you use the self IP address.
  9. Select Next.
  10. Select the System tab.
  11. Select BIG-IQ HA.
  12. Under Device Name, verify the hostname of the BIG-IQ system.
  13. Under IP Address, verify the new discovery IP address for the BIG-IQ system.
  14. To add all discovered devices, select the Devices tab.
  15. Select Add Device.
  16. Fill in the IP Address, User Name and Password of the rediscovered device.
  17. Select Add.

You should be able to successfully add the secondary BIG-IQ system from the primary system.
