Description

Using the iControl REST API to query APM access sessions and filter using Username/Client IP

Environment

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IP APM Configuration utility.

Cause

You want to use the iControl REST API to obtain Session ID of established access session and filter using Username/Client IP

Recommended Actions

From APM command line interface we can use restcurl to check of all access sessions using below command:

restcurl -s -u admin:<pwd>-i -X GET /mgmt/tm/apm/access-info/

Example:
[root@bigip1:Active:Standalone] log # restcurl -s -u admin:admin-i -X GET /mgmt/tm/apm/access-info/
{
  "kind": "tm:apm:access-info:access-infostats",
  "selfLink": "https://localhost/mgmt/tm/apm/access-info?ver\u003d14.1.2.6",             ------> selfLink 
  "entries": {
    "https://localhost/mgmt/tm/apm/access-info/d3f15292": {            ------> session id d3f15292
      "nestedStats": {
        "entries": {
          "clientIp": {
            "description": "172.18.204.167"             ----------> Client IP 
          },
          "logonUser": {
            "description": "admin"            -----------> Username 
          }
        }
      }
    }
  }
}

To check the session ID for a specific username :

restcurl -s -u admin:<pwd> -i -X GET /mgmt/tm/apm/access-info?ver\u003d14.1.2.6\&options\="logon-user","<username>"

Example:
[root@bigip1:Active:Standalone] config # restcurl -s -u admin:admin -i -X GET /mgmt/tm/apm/access-info?ver\u003d14.1.2.6\&options\="logon-user","admin"
{
  "kind": "tm:apm:access-info:access-infostats",
  "selfLink": "https://localhost/mgmt/tm/apm/access-info?options\u003dlogon-user%2Cadmin\u0026ver\u003d14.1.2.6",
  "entries": {
    "https://localhost/mgmt/tm/apm/access-info/de6f730d": {        -------> session ID de6f730d
      "nestedStats": {
        "entries": {
          "clientIp": {
            "description": "172.18.204.54"       ----------> Client IP
          }
        }
      }
    }
  }
}

To check the session ID for specific Client IP:

restcurl -s -u admin:admin -i -X GET /mgmt/tm/apm/access-info?ver\u003d14.1.2.6\&options\="Client-IP","<Client IP>"

Example:
[root@bigip1:Active:Standalone] config # restcurl -s -u admin:admin -i -X GET /mgmt/tm/apm/access-info?ver\u003d14.1.2.6\&options\="Client-IP","172.18.204.54"
{

Postman Tool 

 
To view Session ID of all the access sessions associated with their Username or Client IP  (replace IP with APM device management IP) :
 
https://<IP>/mgmt/tm/apm/access-info?$filter=partition eq Common&$select=logonUser
 
Example :

{
    "entries": { 
        "https://localhost/mgmt/tm/apm/access-info/4788b3b1": {          ------------> Session ID 4788b3b1
            "nestedStats": {
                "entries": {
                    "logonUser": {
                        "description": "bob"                    ---------> Username bob
                    }
                }
            }
        },
        "https://localhost/mgmt/tm/apm/access-info/ce43c7dc": {         ------------> Session ID ce43c7dc
            "nestedStats": {
                "entries": {
                    "logonUser": {
                        "description": "admin"                  ---------> Username admin
                    }
                }
            }
        }
    }
}
 
To view Session ID for specific username (replace IP with APM device management IP) :
 
https://<IP>/mgmt/tm/apm/access-info?$filter=partition eq Common&$select=logonUser,"<username>"


Example:
https://<IP>/mgmt/tm/apm/access-info?$filter=partition eq Common&$select=logonUser,"admin"
