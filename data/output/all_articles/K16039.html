Known Issue

Database monitors may not work as expected.

This issue occurs when all of the following conditions are met:

  • You configure a MySQL, MSSQL, Oracle or PostgreSQL database monitor.
  • You apply the database monitor to a pool member that resides in a non-default route domain.

Impact

The database monitor does not reliably monitor objects that reside in a non-default route domain.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You find that pool members in non-default route domains are incorrectly marked up or down by a database monitor.
  • You notice Java core files in the /shared/core directory.
