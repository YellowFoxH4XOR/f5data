Description

Your BIG-IP is recording warning logs in the pabnagd.log file (policy building feature) that looks like this:

entity   |WARNING|Jan 01 11:11:11.111|014950|EntityCluster.cpp:513|entity count limits have been reached: url cluster (policy ID ##) entity count limits: ### in policy, #### in memory. entity counts: ### in policy and # candidates to be added to policy, ### in memory

...

entity   |WARNING|Jan 01 11:11:11.111|014950|EntityCluster.cpp:513|Skipped # repeated messages: entity count limits have been reached: url cluster (policy ID ##) entity count limits: ### in policy, #### in memory. entity counts: ### in policy and # candidates to be added to policy, ### in memory

Environment

  • ASM provisioned
  • ASM in "Learning" mode

Cause

This error messages is just an indication that there are several learning suggestions that has not been applied.

You can verify this by going to:

"Security" menu tab > "Application Security" > "Security Policies" > "Policies Summary"

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Use a URL learning mode other than "Compact" for the affected policy
  2. Enable automatic policy builder can do a better job
  3. Add the learning suggestions manually (explicitly or using wildcards)
