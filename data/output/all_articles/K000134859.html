Description

Configuration load during upgrade to v17.x returns with the following error:

01b90053:3: Match-direction 'both' has been deprecated and renamed to 'either' since this version. Please use 'either' instead.

 

Environment

  • BIG-IP
  • AFM

Cause

Match-direction 'both' has been deprecated

Recommended Actions

  1. Backup the configuration file
cp bigip.conf bigip.conf.bak.DDMMYY
  1.  Search for the word both and replace it with either

Before changes took place:


This is how it looks after changing:

  1. Save the configuration with the following command from tmsh
save sys config
  1. load the configuration after saving - from tmsh:
load sys config
The errors you had before should not appear anymore.
Note: In case there are more from the same error appearances, please use the same as above again.
