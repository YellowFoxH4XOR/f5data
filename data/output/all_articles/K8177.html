Issue

WebAccelerator 5.2

The WebAccelerator 5.2 policies did not have a limitation on the number of characters allowed in the path field.

BIG-IP WebAccelerator 9.4.0 through 9.4.3 HF1

The BIG-IP WebAccelerator 9.4.0 through 9.4.3 HF1 have a 256 character limitation for the path field. 

If you attempt to create and publish a policy containing a node with a path in excess of 256 characters, you will receive an error message similar to the following example:

There was 1 error. Policy Not Imported.
(1) Error when attempting to import policy.

Note: It is not possible to import a policy with a path in excess of 256 characters for BIG-IP WebAccelerator versions 9.4 through 9.4.3 HF1. For more information, refer to K8176: WebAccelerator policy import fails if the policy contains a node with a path greater than 256 characters.

BIG-IP WebAccelerator 9.4.3 HF2 and later

The 256 character path length limitation was removed beginning with BIG-IP WebAccelerator 9.4.3 HF2.

F5 Product Development tracked the request to remove the 256 character limitation as CR88075 and the limitation was removed in BIG-IP WebAccelerator 9.4.3 HF2.  For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.
