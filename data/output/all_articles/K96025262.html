Description

The License Comparison functionality is added from V12.1.0 and enables you to check the difference between the existing license and the pending license. If enabled, the features of the existing license will be compared against the new license during license reactivation. A table listing the differences will be displayed and you will be prompted to proceed with the new license or keep the existing license. 

Environment

  • Licensing
  • License Comparison
  • Reactivation of License
  • Automatic License Activation Method

Cause

None

Recommended Actions

Perform the following steps to enable license comparison in the GUI:

  1. Go to System > License.
  2. Select Re-activate.
  3. Select Automatic (requires outbound connectivity) 
    Important: License comparison only works with the Automatic Reactivation method, using the Manual Activation method will activate the license with no option to cancel. 
  4. Select Enable License Comparison.
  5. Select Next. 
    A table that shows the difference between the new license and the existing license will be displayed. 
  6. Select Cancel to abort the reactivation of license.

Note: There is no impact when doing the license comparison with Automatic reactivation. However, if you proceed to activate the license, traffic processing will be briefly interrupted while the BIG-IP system reloads the configuration.
