Description

Low disk space availability is showing for /var/log
df -h

The follow error message is logged in /var/log/ltm:

alert alertd[8709]: 01100045:1: /var/log disk usage exceeds 90%. Reduce log disk space now

Environment

  • BIG-IP
  • Low disk space in /var/log

Cause

System defaults for managing log files has likely been changed.

Recommended Actions

Review section "Changing the age at which log files become eligible for removal" in K13367 and reduce as necessary to free up disk space in /var/log/
  1. List the current value of Logrotate.LogAge
    tmsh list /sys db logrotate.logage value
  2. Set new value.  In this example, the default of 8 days will be set:
    tmsh modify /sys db logrotate.logage value 8
    tmsh save /sys config

Additional Information

K13367: Managing log files on the BIG-IP system (11.x - 16.x)
