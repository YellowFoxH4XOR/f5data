Description

The following symptoms may be observed:

  • The /appdata partition is heavily utilized
  • The mysql daemon is failing to start
  • Logs similar to the following are observed in /var/log/ltm:

    Disk partition /appdata has only 0% free

Environment

  • AVR (Application Visibility and Reporting)
  • ASM (Application Security Manager)
  • APM (Access Policy Manager) 
  • AFM (Application Firewall Manager)
  • Disk Partition

Cause
mysql binary log files are consuming all available space under the /appdata partition.

Recommended Actions

Perform the following steps to help prevent the issue:

  1. Allow rotation of binary log files by modifying /var/lib/mysql/my.cnf (BIG-IP 11.x - 13.x) or /etc/my.cnf (BIG-IP 14.x and later) with a text editor and adding the following line:

    expire_logs_days=5

  2. Run the following command to determine the big files under /appdata
    find /appdata/ -xdev -type f | xargs du -ax | sort -rn | head -100

    For example:

    1049852 /appdata/mprov/local/HD1.1/mysqldb/mysqld-bin.000011
    1049832 /appdata/mprov/local/HD1.1/mysqldb/mysqld-bin.000018
    1049828 /appdata/mprov/local/HD1.1/mysqldb/mysqld-bin.000015
    1049772 /appdata/mprov/local/HD1.1/mysqldb/mysqld-bin.000006
    1049768 /appdata/mprov/local/HD1.1/mysqldb/mysqld-bin.000012

  3. Remove existing binary log files.

    rm -rf /appdata/mprov/local/HD1.1/mysqldb/mysqld-bin*

    Note: Please make sure the partition number matches your active partition or run "tmsh show sys software" to verify.

  4. Create the /var/avr/init_avrdb file necessary to reset AVR statistics.

    touch /var/avr/init_avrdb

  5. Restart mysql and monpd to complete a reset of the AVR statistics.

    tmsh restart sys service mysql

    tmsh restart sys service monpd

  6. Enter mysql shell.

    mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw`

  7. Verify expire_logs_days variable is set.

    show variables like 'expire_logs_days';

  8. Exit from mysql shell.

    exit

  9. Review BIG-IP daemon status.

    tmsh show sys service all
