Note: The High-Speed Bridge (HSB) is the interface connecting the BIG-IP switch fabric to the host subsystem. Depending on the BIG-IP platform, one or more HSBs may be present. The following platforms utilize the HSB architecture:

  • BIG-IP 3900
  • BIG-IP 6900
  • BIG-IP 8900
  • BIG-IP 8950
  • BIG-IP 11050
  • PB100 VIPRION blade
  • PB200 VIPRION blade

The high availability table includes a feature that is triggered when TMM detects a failure (receive or transmit) in an HSB attached interface. This feature is named Interface Failsafe in BIG-IP 10.x and nic failsafe in BIG-IP 9.6.x and 9.4.x. The high availability table includes an instance of this feature for each HSB present in the system.

For example:

  • If the bigpipe ha table command is executed on a BIG-IP 8900 system running 10.2.0, the command output will include the following lines:

    Feature              Key      Action          En? Act   Data
    Interface Failsafe   tmm      reboot          yes no       0
    Interface Failsafe   tmm1     reboot          yes no       0
    Interface Failsafe   tmm2     reboot          yes no       0
    Interface Failsafe   tmm3     reboot          yes no       0
    Interface Failsafe   tmm4     reboot          yes no       0
    Interface Failsafe   tmm5     reboot          yes no       0
    Interface Failsafe   tmm6     reboot          yes no       0
    Interface Failsafe   tmm7     reboot          yes no       0
     
  • If the bigpipe ha table command is executed on a BIG-IP 8900 system running 9.4.8, the command output will include the following lines:

    Feature              Key      Action          En? Act   Data
    nic failsafe         tmm0     reboot          yes no       0
    nic failsafe         tmm1     reboot          yes no       0
    nic failsafe         tmm2     reboot          yes no       0
    nic failsafe         tmm3     reboot          yes no       0
    nic failsafe         tmm4     reboot          yes no       0
    nic failsafe         tmm5     reboot          yes no       0
    nic failsafe         tmm6     reboot          yes no       0
    nic failsafe         tmm7     reboot          yes no       0

When this feature is triggered, the default action is to reboot the BIG-IP system. It is not possible to configure which action to take for this feature.

Note: For more information, type bigpipe ha table help at the command line.
