Known Issue

The Traffic Management Microkernel (TMM) might panic due to OpenSSL failure during handshake generation.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is in a low memory condition.
  • The BIG-IP system is using a software based Secure Sockets Layer (SSL) handshake generation.

Impact

The BIG-IP system is unable to process traffic while the TMM process restarts, and the system fails over if it is configured for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process restarts, and the BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
  • The system logs the stack trace to the /var/log/tmm file.
