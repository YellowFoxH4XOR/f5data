K000133442: Misleading error "Symmetric Unit Key decrypt failure" while loading UCS for rSeries and Velos

Type
Support Solution
Published
2023-04-07
Updated
2023-04-07
Applies to
  • rSeries Platforms
  • VELOS Platforms
Source
https://my.f5.com/manage/s/article/K000133442

Description

While migrating to rSeries or Velos device, customer may hit this error while loading from UCS archive:
"Symmetric Unit Key decrypt failure"

Environment

rSeries
Velos
Migration
UCS Archive

Cause

Known causes so far: 

  •  Interface mismatch between UCS configuration and Host configuration
  •  Trunk mismatch between UCS configuration and Host configuration, including Trunk name
  •  LACP cannot be active within the UCS configuration

 Recommended Actions

  1. Match the interface name in bigip_base.conf to the interfaces used in the Host configuration of the new system. Do not match to the Guest.
  2. Match the Trunk to the Trunk name and options in the Host.
  3. Comment out the LACP settings in the bigip_base.conf. LACP is pushed from the Host, so is not set in the Guest. 

Additional Information

You should see the real errors in /var/log/ltm, for MCPD errors.
You can also get rid of the false 'symmetric unit key' error by restarting services:
  # bigstart restart
Then load using: 
  # tmsh load sys config
This will now show the real error, not the symmetrical key error.
