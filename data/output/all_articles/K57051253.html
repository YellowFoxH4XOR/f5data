Description

Encounters Error 51165 during license reactivation after Subscription renewal.
Upgrade keys cannot be activated Registration Key "ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG" can only be used to upgrade an existing key

Environment

  • MyF5
  • Virtual Edition
  • Subscription
  • Renewal

Cause

You are given a new license key during renewal process. This is just a "swap key" and you are to continue using the old key for license reactivation.

Recommended Actions

  1. Renew license subscription in MyF5 portal by mapping to old subscription. K12183049: Mapping MyF5 registration keys after a subscription renewal
  2. Reactivate the old license key. K7752: Licensing the BIG-IP system
