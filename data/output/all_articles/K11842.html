Known Issue

This is the result of a known issue. The ZoneRunner utility allows users to create SRV resource record types, but the utility does not allow users to view or edit the records.

F5 Product Development is tracking this issue as ID 224850 and ID 328287 (formerly CR137850).

This issue has been fixed in BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing BIG-IP 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

Workaround

You can work around this issue by manually editing the SRV resource records. For more information, refer to K7032: Freezing zone files to allow manual update to ZoneRunner-managed zone files.
