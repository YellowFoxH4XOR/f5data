Known Issue

The oamd process may stop responding and produce a core file.

This issue occurs when all of the following conditions are met:

  • You are using Zebos for dynamic routing.
  • You stop Zebos dynamic routing by shutting down your BIG-IP system.

Impact

There should be no impact on the BIG-IP system, as this issue is triggered only during a shutdown.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe an oamd core file in the /shared/core directory.
  • In the /var/log/messages file, you observe an error message similar to the following example:

    notice logger: Started writing core file: /var/core/oamd%0.bld0.0.221.core.gz for PID <pid>

  • In the /var/log/kern file, you observe an error message similar to the following example:

    info kernel: oamd[<pid>]: segfault at 80 ip 0000000001234567 sp 0000000012345678 error 4 in oamd[8048000+ad000]
