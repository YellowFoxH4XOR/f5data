Description

Images or other web objects are not being cached on CDN (Content Delivery Network) when there is a cookie in the HTTP request, such as an ASM cookie.

Environment

  • Cookie in HTTP request
  • Content Delivery Network
Cause

Bypass Cache on Cookie feature is enabled on CDN provider.

Recommended Actions

Check the settings with your CDN provider.

Additional Information

None
