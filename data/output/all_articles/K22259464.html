Description

BIG-IP Virtual Edition may start fewer TMM instances than expected when the guest does not have sufficient memory for the assigned and licensed vCPUs.

The /var/log/ltm log may contain messages similar to:

warning sh.functions[<PID>]: Insufficient memory for <number> tmm threads; restricting to <number> tmm threads.

err sh.functions[<PID>]: TMM count must be 1, 2, or a multiple of 4, so changing it from <number> to <number>

Environment

  • BIG-IP Virtual Edition
  • BIG-IP LTM
  • vCPU license assigned and activated
  • VMware hypervisor

Cause

The guest has insufficient memory for the assigned CPU count, preventing TMM from using all available vCPUs.

Each TMM should have at least 1.5 GB of memory. Approximately 2 GB of memory per TMM is recommended, depending on the infrastructure. The guest should have a minimum of 4 GB of RAM for the first two virtual CPUs, with an additional 2 GB of RAM for each additional CPU.

To run x TMMs, BIG-IP Virtual Edition requires approximately 2x GB of memory.

For example:

24 TMMs = 48 GB RAM

The allocated memory should be reserved.

Answer/Recommended Actions

  1. Power down the BIG-IP Virtual Edition instance.
  2. Increase the guest memory allocation to support the assigned vCPUs and expected TMM count.
  3. Power on the instance.
  4. Verify the allocated cores and active TMM count: 
    tmsh show /sys cpu
    tmsh show /sys tmm-info
  5. Review the system logs after startup to confirm that no memory-related TMM restriction remains.
  6. Do not manually modify provision.tmmcountactual unless directed by F5 Support.

Additional Information

Review the BIG-IP Virtual Edition memory requirements for the applicable on-premises hypervisor:

  • VMware virtual machine memory requirements
  • KVM virtual machine memory requirements
  • XEN virtual machine memory requirements
  • Hyper-V virtual machine memory requirements
  • Citrix virtual machine memory requirements: https://clouddocs.f5.com/cloud/public/v1/citrix/citrix_setup.html#virtual-machine-memory-requirements
