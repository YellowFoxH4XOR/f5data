K10137733: Configuring Network Access Exclude Address Space by Hostname or FQDN

Type
Support Solution
Published
2020-03-18
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K10137733

Description

You want to configure Network Access DNS Exclude Address Space by Hostname or FQDN without having to also configure IPV4 Exclude Address Space.

  • Network Access DNS Exclude Address Space, but the functionality fails.

Environment

  • APM Network Access configured for DNS Exclude Address Space.
  • The APM DNS Relay Proxy Service component.
  • Windows clients.

Cause

APM Network Access is configured for DNS Exclude Address Space, but the clients do not have the DNS Relay Proxy Service installed. Without the DNS Relay Proxy installed on the client you must also configure the IPV4 Exclude Address Space in APM Network Access.

Recommended Actions

Download and install the DNS Relay Proxy on the client PC.
Note: the DNS Relay Proxy Service is a Windows only component.
Note: The BIG-IPEdgeClient executable must be installed as an Administrator.

Version 13.x and 14.x:

  1. Login to the BIG-IP Admin GUI.
  2. Navigate to Access>Connectivity/VPN>Connectivity>Profiles.
  3. Select the Connectivity Profile that is in use on the APM Virtual Server.
  4. Click on "Customize Package."
  5. Select the "DNS Relay Proxy Service" and click Download.
  6. Run the downloaded BIG-IPEdgeClient executable on the client PC.
Version 11.x and 12,x:
  1. Login to the BIG-IP Admin GUI.
  2. Navigate to Access Policy>Secure Connectivity.
  3. Select the Connectivity Profile that is in use on the APM Virtual Server.
  4. Click on "Customize Package."
  5. Select the "DNS Relay Proxy Service" and click Download.
  6. Run the downloaded BIG-IPEdgeClient executable on the client PC.
