K000132858: Failed to generate QKVIEW file on BIG-IQ

Type
Support Solution
Published
2023-04-26
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000132858

Description

Customer facing issue generating qkview file on BIG-IQ via CLI "# qkview" with error as below:

terminate called after throwing an instance of 'std::runtime_error'
 what(): error connecting to local mcp
 Aborted (core dumped)

 

Environment

BIG-IQ
QKVIEW
 

Cause

BIG-IQ Disk were corrupted and need to run fsck to fix the corrupted error, you will find similar error message as below on "/var/log/kern.log"

Recommended Actions

Login to BIG-IQ CLI and run the fsck shell command to fix the corrupted error, and then reboot the BIG-IQ.

# fsck -y /dev/mapper/vg--*
# reboot
