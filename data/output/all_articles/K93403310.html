Description

How to install and run EUD from a USB thumb drive

Environment

  • EUD IM file
  • 4GB USB thumb drive
  • BIG-IP

Cause

None

Recommended Actions

The EUD IM file first needs to be downloaded from Downloads.F5.com
Then installed onto a 4GB USB thumb drive
Then plugging it into a powered-off BIG-IP, and powering it on to boot into the EUD on the USB thumb drive

Download the EUD ISO file from Downloads.F5.com:

  1. Log on to https://my.f5.com/manage/s/downloads
  2. Click on the Resources drop-down menu
  3. Select the Downloads menu item
  4. Select Hardware-Specific from the Group  drop-down
  5. Select Platform from the Product Line drop-down
  6. Select your platform version from the Product Version drop-down
  7. In the Select a product container section click the name of the most recent release (or the one specific to your needs)
  8. Click <file_name>.im in the Select a download file section
    Note: The following procedure uses the *.im file
  9. Select a download location and click the download button.
  10. Also download the *.md5 checksum file
  11. After the downloads complete, confirm the download was successful by checking the MD5 checksum:
    K8337: Verifying the MD5 checksum for the downloaded F5 software file

Install the EUD onto a USB thumb drive:
Note: the following procedure uses a BIG-IP, but the procedure can be completed on any Linux system

  1. Upload the EUD IM file to /var/tmp/ on a BIG-IP
  2. Access the BIG-IP CLI Bash prompt
  3. Loopback mount the EUD IM file:
    mkdir /mnt/eud; mount -o ro,loop <file_name>.im /mnt/eud
  4. Plug a 4GB USB thumb drive into the BIG-IP
  5. Run mkdisk:
    cd /mnt/eud; ./mkdisk
  6. Follow the prompts to load the EUD onto the USB thumb drive
  7. Unplug the USB thumb drive when the installation completes
  8. Unmount the IM file:
    umount /mnt/eud

Running the EUD on the USB thumb drive:

  1. Connect to the serial port of the BIG-IP to be tested: K7683: Connecting a serial terminal to a BIG-IP system
  2. Make sure the BIG-IP is powered off
  3. Plug the EUD USB thumb drive into the BIG-IP
  4. Power on the BIG-IP
  5. Perform the EUD tests once the BIG-IP has booted into the EUD utility
