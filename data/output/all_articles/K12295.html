Known Issue

This is the result of a known issue. If an external monitor is configured with a user-defined variable, and if this variable contains a backslash character ( \ ), the BIG-IP system does not correctly pass this variable to the external program and the monitor fails.

For example:

The user configures the following variable in the external monitor:

data = this \"should\" work

The variable that you expect the BIG-IP system to pass to the external program is:

data = this "should" work

Due to the known issue described in this Solution, the BIG-IP system repeats and appends the last two characters of the variable:

data = this "should" workrk

F5 Product Development tracked this issue as ID 337649 and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.
