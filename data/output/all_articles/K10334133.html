Description
When creating zone in  ZoneRunner from configuration utility, 
DNS  ››  Zones : ZoneRunner : Zone List  ››  New Zone
Creation of zone fails with the error message: 

Zone <zone-name> in file <zone-file> contains errors: zone <zone-name>/IN: has 0 SOA records. zone <zone-name>/IN: not loaded due to errors.

Environment

  • ZoneRunner
  • Creating Zone
  • Invalid Email format

Cause
Under SOA records section, Email Contact contains @ sign in the address.
 

Recommended Actions

To work around the issue, replace the @ sign with '.' period. The '@' sign has a different purpose in the zone file.

While creating zones, use the autocomplete option by using the tab key, the field is completed with hostmaster.<master-server> in the correct format.

Though the format is mailbox-name.domain.com. for example, hostmaster.example.com. the e-mail is sent to hostmaster@example.com.
Most commonly ending with a '.' (dot) but if the email address lies within this domain hostmaster is sufficient.
