Description
The VPN tunnel regularly disconnects at random intervals, with the following error message:
User session was terminated due to IP address change during session. 

Environment

  • BIG-IP APM
  • Client Using Proxy
  • VPN Tunnel

Cause
If you are using a public proxy service which is load balanced, the source IP Address presented by the proxy may change if you are moved between proxy servers.
A VPN tunnel can only be established between 2 fixed IP Addresses. If either IP Address at each end of the tunnel changes, the tunnel will collapse and have to be re-established.

Recommended Actions

If using a proxy server, set an exception in your browser for the BIG-IP APM VPN virtual server.
