Description

This solution will explain to configure Portal Access object for web applications that use non-standard port configurations.

  • Portal Access configurations with web applications that use non-standard port will fail to display typically with a "page can not be displayed" error in a browser.

Environment

  • Big-IP APM
  • Portal Access configurations.
  • Web applications that use non-standard port configurations.

Cause

You must specify the non-standard port in the Portal Access configuration.

Recommended Actions

Adding the port to the Portal Access Application URI.

  1. Login to the Big-IP Admin GUI.
  2.  Navigate to Access>Connectivity/VPN>Portal Access>Portal Access Lists.
  3. Click on the Portal Access configuration name.
  4. Click on the Link Type drop-down and select Application URI.
  5. In the Application URI field enter the application uri and port, <hostname>:<port> or <ip_address><port>. For example:
https://mysitefqdn.f5.com:8000

https://10.0.0.1:8080
