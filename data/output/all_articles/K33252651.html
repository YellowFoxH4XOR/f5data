Description

When importing SAML Metadata you may encounter the following error message: 
Signature verification failed. Unable to find Signature element in metadata file

Environment

  • BIG-IP APM
  • SAML - BIG-IP as IdP or SP

Cause

When importing Metadata into the BIG-IP, there is a an option to select a Signing Certificate. A signing certificate is only needed if when the Metadata was signed by the connector peer (SP/IdP)
If you choose a signing certificate from the drop-down menu and the metadata was not signed by the connecting peer, you will receive the following error message:

Signature verification failed. Unable to find Signature element in metadata file

Recommended Actions

When importing Metadata, choose 'None' from the signing certificate list and import.

  1. Logon to the BIG-IP APM Configuration utility.
  2. Go to Access > Federation.
  3. Select SAML Service Provider or SAML Identity Provider depending on your configuration requirements.
  4. For SAML Service Provider select External IdP Connectors, or for SAML Identity Provider select SAML SP Connectors.
  5. From the Create pull-down menu select From Metadata.
  6. In the create new connector pop-up click Browse.
  7. Select the metadata file to use for the connector from your local device.
  8. In the Provider Name text box, enter a name.
  9. Set Select Signing Certificate to None.
  10. Click OK.
