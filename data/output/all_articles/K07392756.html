Description
You may encounter the following log messages on LTM log files from bcm56xxd daemon

info bcm56xxd[6751]: 012c0016:6: unit 0 WRED_AVG_QSIZE port 0 index 1 parity error
info bcm56xxd[6751]: 012c0016:6: SER_CORRECTION: reg/mem:66194 btype:9 sblk:0 at:0 stage:0 addr:0x00000000 port: 0 index: 1
info bcm56xxd[6751]: 012c0016:6: soc_reg_set: WARNING: write to 32-bit reg WRED_AVG_QSIZE with hi order data, 0x55bb2380

Environment

  • BIG-IP
  • bcm56xxd

Cause
Error message is related to soft parity error. SER (soft error recovery) is trying to clear it, but the error just comes back.

Recommended Actions

  1. Restart the bcm56xx daemon and the BIG-IP system will stop processing traffic.
    Note: This operation should be performed only during a maintenance window or when the system is in a standby state.
    # bigstart restart bcm56xxd

  2. If log messages persist even after the restart of bcm56xx daemon, please contact F5 Support.
