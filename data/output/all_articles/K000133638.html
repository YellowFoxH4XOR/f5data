Description

Does F5OS configuration backup contain Tenant's backup (UCS)?

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • Configuration backup
  • Tenant UCS

Cause

  • n/a

Recommended Actions

F5OS configuration backup does not include Tenants config/data.
Please take Tenant's backup following the solution: K13132: Backing up and restoring BIG-IP configuration files with a UCS archive

Additional Information

For Velos system, when you restore controller backup, you will need to have each partition backup and each Tenant UCS to restore.
Please refer how to take and restore backup for each product the below Related Content

  • K50135154: Back up and restore the F5OS-C configuration on a VELOS system
  • K47512994: Back up and restore the F5OS-A configuration on an rSeries system
