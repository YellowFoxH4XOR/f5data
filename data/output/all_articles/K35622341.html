K35622341: LTM doesn't reply SNMP queries from some addresses which are configured on the SNMP allowed-addresses list

Updated
2023-10-16

  • BIG-IP LTM: 15.X.X, 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0
Source
https://my.f5.com/manage/s/article/K35622341

Description

LTM snmpd doesn't respond to SNMP queries from some source IP addresses even if they are configured on the SNMP allowed-addresses list

Environment

  • LTM
  • SNMP
  • snmpd
  • SNMP allowed-addresses list

Cause

If only some source IP addresses are affected and these are properly configured on the SNMP allowed-addresses list, seen behavior is most likely the result of an inconsistent binary configuration.

Recommended Actions

Force mcpd to reload to ensure that the binary configuration is consistent with text configuration. Please follow the the procedure described in K13030
