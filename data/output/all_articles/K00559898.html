Description

The sFlow_agent daemon is down after a reboot but not affecting production traffic.

You may observe the following logs in /var/log/sflow_agent.log_truncated:

Warning: Failed to connect to the agentx master agent ([NIL]):
Warning: Failed to connect to the agentx master agent ([NIL]):
Warning: Failed to connect to the agentx master agent ([NIL]):
Warning: Failed to connect to the agentx master agent ([NIL]):

And the following logs for the snmpd daemon in /var/log/snmpd.log:

Received broken packet. Closing session.
Received broken packet. Closing session.
Received broken packet. Closing session.

Environment

  • sFlow statistics
  • SNMP

Cause

This issue could be related to: Bug ID 799001: Sflow agent does not handle disconnect from SNMPD manager correctly.

Recommended Actions

Restart services using the following commands:
tmsh restart sys service snmpd
tmsh restart sys service sflow_agent
Note: These commands will only impact SNMP and sFlow traffic, but not production traffic.

Note: If you encounter the error Service snmpd has not been added to bigstart, refer to the Adding services section in K4080: Adding and removing services included in the 'bigstart' process.
