Known Issue

The DNS Express feature is not available on BIG-IP 10.x. However, after activating or re-activating a license on a BIG-IP version 10.x system, the /config/bigip.license file may contain an entry which implies that the DNS Express feature is available as a licensable ADD-ON.

Note: The DNS Express feature is only included in BIG-IP version 11.0.0.

Impact

None; you can safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The /config/bigip.license file will contain an entry that appears similar to the following example:

    active module : Local Traffic Manager, 1600|XXXXXXX-XXXXXXX|Local Traffic Manager Module|ADD IPV6 GATEWAY|ADD RATE SHAPING|ADD RAMCACHE|50 MBPS COMPRESSION|SSL 500 TPS Per Core|ADD SSL CMP|ADD DNS EXPRESS

  • The BIG-IP Configuration utility lists the Add DNS Express option in the license summary page.
