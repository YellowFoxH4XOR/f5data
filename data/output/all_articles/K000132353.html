Description

This article describes several main benefits of using DNS express, compared with querying BIND directly.

Environment

  • BIG-IP DNS(formally known as BIG-IP GTM)

Cause

None, this is informational.

Recommended Actions

  1. DNS Express function

With DNS Express configured, the BIG-IP system can answer DNS queries for a DNS zone and respond to zone transfer requests from specified DNS nameservers (clients). Additionally, zone transfer communications can be secured with TSIG keys.

  1. Performance

DNS Express loads the whole zone files into BIGIP memory, and leverages BigIP TMOS capacity to handle client queries. Its performance is far better than a BIND server, especially for TCP-based DNS requests.

  1. Supportability

F5 provides limited support for BIND. F5 does not provide support for the actual configuration of BIND zones through the command line or troubleshooting support for zones other than those created and managed by the BIG-IP software. F5 does not provide support for BIND performance issues.
