K2650: BIG-IP compatibility with Link Aggregation Control Protocol (LACP)

Topic

At this time, BIG-IP and the BIG-IP Link Controller support only IEEE 802.3ad static link configurations and not LACP, which extends fault tolerant link aggregation by allowing autodiscovery and autogrouping of links.
