Note: In BIG-IP 10.1.0 and later, the RADIUS Accounting health monitor is available as a custom health monitor. For more information about configuring the RADIUS Accounting health monitor, refer to the Health and Performance Monitors chapter of the Configuration Guide for BIG-IP Local Traffic Manager guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

BIG-IP health monitors now include a RADIUS Accounting external health monitor.

To configure the RADIUS Accounting health monitor, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Select Local Traffic.
  3. Select Monitors.
  4. Choose Create.
  5. Type a name for the new monitor.
  6. From the Type list, select External.
  7. Enter the following string in the External Program field:

    /usr/bin/monitors/builtins/RADIUSACCT_monitor

  8. Enter the following name and value pairs for the Variables field, and choose add after each Name and Value pair is entered:

    • Name: SECRET
      Value: <your radius secret>

    • Name: USERNAME
      Value: <your username>

      Note: The Username value is optional; it allows debug to be enabled for troubleshooting.

    • Name: DEBUG
      Value: Yes (Enables Debug mode) No (Disables Debug mode if currently in use)

  9. Click Finished.
