Overview

F5 investigates and prioritizes vulnerability reports based on the potential exploitability of the system and communicates the vulnerability impact using Common Vulnerability Scoring System version 3.1 (CVSS v3.1). When F5 determines the Severity (Low, Medium, High, or Critical), the CVSS v3.1 score is used.

Starting with the August 2024 Quarterly Security Notification (QSN), F5 will also provide a CVSS v4.0 base score for first-party security issues, displayed below the CVSS v3.1 score. For example:

Frequently Asked Questions

Q: Why is F5 introducing CVSS v4.0?

A: F5 believes the enhanced metrics in CVSS v4.0 will enable more precise vulnerability assessments, allowing for more effective risk assessment and prioritization of threats. For third-party issues, F5 will continue to provide only CVSS v3.1 scores for the time being while we build experience with CVSS v4.0.

Q: Why do the scores differ between CVSS v3.1 and CVSS v4.0?

A: Due to changes in the CVSS vector and calculations, scores may differ, resulting in a different Severity. For instance, a vulnerability scored 5.9 (Medium) in CVSS v3.1 may be scored as an 8.2 (High) in CVSS v4.0. In other cases, the scores vary but the Severity remains the same, such as a vulnerability scored 7.0 (High) in CVSS v3.1 and 7.3 (High) in CVSS v4.0. For more examples, refer to the CVSS v4.0 examples document. Note: This link takes you to a resource outside of MyF5. The third party could remove the document without our knowledge.

Q: If the CVSS v3.1 and CVSS v4.0 scores differ, which score does F5 recommend?

A: You should use the vector and score that best fits your existing processes. If you are ready to begin using CVSS v4.0, then you should use CVSS v4.0. If your processes are still based on CVSS v3.1, then you can continue using CVSS v3.1.
