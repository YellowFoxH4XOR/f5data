Description

/var/log/kern.log has similar to below entry:

warning kernel: EXT2-fs warning: check time reached, running e2fsck is recommended

Does this indicate hard disk issue?
 

Environment

  • BIG-IP any version
  • kern.log
  • e2fsck (fsck)

Cause

This is just a periodic reminder, as it is good idea to run fsck periodically.
This message indicates NO hard disk issue.
 

Recommended Actions

None. However periodically running fsck is good practice.
Follow K73827442: Forcing a file system check on the next system reboot 

If you have suspect for disk issue, check the below logs and any concern, please escalate case to F5.
  • /var/log/platfrom_check 
  • /var/log/messages
  • /var/log/sel.log (for iSeriese platform)
     

Additional Information

N/A
