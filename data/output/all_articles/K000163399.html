Description

How to enable debug logging when troubleshooting layer 7 dos (dosl7d) issues

Environment

  • Layer 7 DoS profile is created and applied to a virtual server.
  • Profile exists at Security ›› DoS Protection : Protection Profiles ›› [DoS Profile Name] and has at least one mitigation method defined at Application Security ›› Behavioral & Stress-based (D)DoS Detection. 

Answer/Recommended Actions

Note: This is a GLOBAL change. It can be chatty but typically doesn't cause disruption beyond higher disk IO.

  1. Enable debug logging.
       # tmsh modify sys db dosl7.params value extra_debugging
       # tmsh modify sys db log.dosl7.all.level value Debug
       Note: Additional debugging can be enabled.
       # tmsh modify sys db dosl7.params value extra_extra_debugging
  2. Reproduce the issue.
  3. Disable the debug log and stop har, tcpdump.
       # tmsh modify sys db dosl7.params reset-to-default
       # tmsh modify sys db log.dosl7.all.level reset-to-default
  4. Fresh asmqkview and tar file of /var/log/*
       # asmqkview -s0
       # tar -czpf /var/tmp/$HOSTNAME-logs.`date "+%F"`.tar.gz /var/log/*
