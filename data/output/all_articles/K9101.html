Known Issue

This is the result of a known issue. The VIPRON system does not detect receive-side high speed bus (HSB) faults. It is possible for a VIPRION blade to lose functionality, and the related TMM instances to lose connectivity with the rest of the system without detection. As a result, multiple failures may occur, such as lost ARP and health monitor requests initiated by the downed blade. In addition, error messages that appear similar to the following examples are logged to the /var/log/tmm file:

notice MPI stream: connection to node 127.10.4.4 lost
notice MPI stream: connection to node 127.10.2.3 lost

F5 Product Development tracked this issue as CR105399 and it was fixed in BIG-IP LTM 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-v9.6.1-HF2, which has been issued for BIG-IP 9.6.1, for the BIG-IP 9.6 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
