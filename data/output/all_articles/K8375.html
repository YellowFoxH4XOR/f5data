Known Issue

This is the result of a known issue. In low temperature conditions (below 0 degrees Celsius), it is possible for the 8400 and 8800 platforms to indicate an erroneous CPU high temperature alarm. The alarm will be displayed on the LCD, console, and in the system logs with an error message that appears similar to the following example:

d84-remote system_check[3618]: 010d0001:0: Cpu 2: temperature (278) is too high

The CPU temperature is determined by an algorithm that receives an initial value from the CPU temperature sensor at system startup. An offset is then applied to calculate the CPU temperature. When the temperature is below 0 degrees Celsius, the value calculated by the CPU temperature sensor wraps around the lower temperature range and appears to be a value near the top of the temperature range. 

Important: In this situation, the alarm is not an indication of a hardware failure, and does not have an operational impact on the performance of the BIG-IP system.

F5 Networks Product Development is tracking this issue as CR87974 and it was fixed in BIG-IP version 9.4.5. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, and WebAccelerator Release Notes.
