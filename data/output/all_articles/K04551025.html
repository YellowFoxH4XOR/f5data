Known Issue

Windows devices may fail access session Endpoint Security Client-Side software checks.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP Windows device has previously established an access session to an access profile where the access policy of the access profile uses Endpoint Security agents.
  • The registry keys of the Windows device are corrupted; this is related to a previous installation of the Endpoint Security components.
  • You attempt to initiate an access session to an access profile that uses Endpoint Security agents.

Impact

The access session fails the Endpoint Security Client-Side agent checks.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to establish an access session using a browser or the BIG-IP Edge Client, the system produces an error message similar to the following example:

    Your session could not be established.

    The session reference number:  <access session id>

    Access was denied by the access policy.

    This may be due to a failure to meet access policy requirements.

  • When you attempt to establish an access session using the BIG-IP Edge Client, the Edge Client logterminal.txt file contains error messages similar to the following example:

    8768,4176,POLICY_SERVER, 1,,,, EXCEPTION - CAgentOESISCheck::CAgentOESISCheck - (CLSID_OesisInspectorCom) failed (hr:2147654730)
    8768,4176,POLICY_SERVER, 1, , 357, , EXCEPTION caught
    8768,4176,POLICY_SERVER, 1,,,, EXCEPTION - CClientSession::ExecuteCheck - Failed to create new agent (id:"/Common/MYRNA_VPN_Profile-windows_antivirus_and_firewall_act_av_check_ag_1", guid:"CLSID:2c8ffa64-e3f7-49ae-87c2-49018fde3aea", data:"type=av&collect=2&count=1&check_list_type=required&vendor_id1=0&id1=0&version1=&platform1=0&state1=1&db_version1=&db_age1=10&last_scan1=0&engine_version1=")
    8768,4176,POLICY_SERVER, 1, , 177, , EXCEPTION caught

  • Uninstalling and then re-installing the BIG-IP Edge Client allows the user to establish an access session.

Workaround

To work around this issue, you can remove the affected Windows registry keys and re-attempt to establish the access session. To do so, perform the following procedure:

Impact of workaround:   Performing the following procedure should not have a negative impact on your system.

  1. Log in to the affected Windows system using an account with privileges to edit the registry for the system users.
  2. Click the Start menu.
  3. Select Run.
  4. In the Open window, type the following:

    regedit

  5. Click OK.
  6. In the navigation pane of the Regedit program, click the plus icon ( + ) next to HKEY_CLASSES_ROOT.

    Delete the following registry keys:

    Wow6432Node\CLSID\{2C8FFA64-E3F7-49AE-87C2-49018FDE3AEA}
    Wow6432Node\Interface\{C0A8E51C-D6A5-4BF6-8926-CAF99DE30466}
    Wow6432Node\TypeLib\{1864D368-D26C-4393-A64E-C9910B7E08AE}
    CLSID\{2C8FFA64-E3F7-49AE-87C2-49018FDE3AEA}
    Interface\{C0A8E51C-D6A5-4BF6-8926-CAF99DE30466}
    TypeLib\{1864D368-D26C-4393-A64E-C9910B7E08AE}

    Important: Delete only the specific registry keys noted in this article.

  7. In the navigation pane of the Regedit program, click the plus icon ( + ) next to HKEY_LOCAL_MACHINE.

    Delete the following registry keys:

    SOFTWARE\Classes\Wow6432Node\CLSID\{2C8FFA64-E3F7-49AE-87C2-49018FDE3AEA}
    SOFTWARE\Classes\Wow6432Node\Interface\{C0A8E51C-D6A5-4BF6-8926-CAF99DE30466}
    SOFTWARE\Classes\Wow6432Node\TypeLib\{1864D368-D26C-4393-A64E-C9910B7E08AE}
    SOFTWARE\Classes\CLSID\{2C8FFA64-E3F7-49AE-87C2-49018FDE3AEA}
    SOFTWARE\Classes\Interface\{C0A8E51C-D6A5-4BF6-8926-CAF99DE30466}
    SOFTWARE\Classes\TypeLib\{1864D368-D26C-4393-A64E-C9910B7E08AE}

    Important: Delete only the specific registry keys noted in this article.

  8. In the navigation pane of the Regedit program, click the plus icon ( + ) next to HKCU.

    Delete the following registry keys:

    SOFTWARE\Classes\Wow6432Node\CLSID\{2C8FFA64-E3F7-49AE-87C2-49018FDE3AEA}
    SOFTWARE\Classes\Wow6432Node\Interface\{C0A8E51C-D6A5-4BF6-8926-CAF99DE30466}
    SOFTWARE\Classes\Wow6432Node\TypeLib\{1864D368-D26C-4393-A64E-C9910B7E08AE}
    SOFTWARE\Classes\CLSID\{2C8FFA64-E3F7-49AE-87C2-49018FDE3AEA}
    SOFTWARE\Classes\Interface\{C0A8E51C-D6A5-4BF6-8926-CAF99DE30466}
    SOFTWARE\Classes\TypeLib\{1864D368-D26C-4393-A64E-C9910B7E08AE}

    Important: Delete only the specific registry keys noted in this article.

  9. Close the Regedit program.
