Known Issue

Synchronizing a BIG-IP APM access policy may cause incremental synchronization to fail.

This issue occurs when all of the following conditions are met:

  • You have three or more BIG-IP APM systems configured in a Sync-Only device group.
  • Two of the systems are also configured in a Sync-Failover device group.
  • You synchronize a BIG-IP APM access policy from a system that is not a member of the Sync-Failover group.

Impact

The access policy fails to synchronize with the standby system in the Sync-Failover device group, causing subsequent incremental configuration synchronization (ConfigSync) attempts to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After synchronizing a BIG-IP APM access policy to a device group, incremental BIG-IP ConfigSync attempts fail.
  • The Device Management > Overview screen of the BIG-IP APM Configuration utility displays a Sync Failed error message for the device group and a Does not have the last synced configuration error message for the standby device.
  • A message appears in the /var/log/ltm file similar to the following example:

    err mcpd[7231]: 01071488:3: Remote transaction for device group /Common/<dg_name> to commit id 2 6125061889017160553 /Common/<hostname> 0 failed with error 01020036:3: The requested Access Profile (/Common/<profile_name>) was not found..

Workaround

To work around this issue, you can enable the Overwrite Configuration option and perform a ConfigSync operation. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility of the device with the access policy you want to synchronize.
  2. Navigate to Device Management > Overview.
  3. In the Device Groups section, select the name of the device group you want to manage.
  4. In the Devices section, select the name of the device you are logged in to.
  5. In the Sync Options section, select the Sync Device to Group check box.
  6. Select the Overwrite Configuration check box.
  7. Click Sync to perform the ConfigSync operation and synchronize the access policy.
