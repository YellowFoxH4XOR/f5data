Description

You should consider using this procedure under the following conditions:
  • You have configured your virtual server in the BIG-IP system to use SSL certificates inside an SSL certificate bundle.
  • You are trying to list all the expiration dates for all the certificates that are included in a bundle.
Environment

You must meet the following prerequisites to use these procedures:

  • You have access to the Bash Shell in cli.
  • You have access to the certificate bundle location.

Note: In version 11.x - 16.x, the bundle certificates are stored here /config/filestore/files_d/<partition>_d/certificate_d/<bundle_file_name>.crt

Cause

None

Recommended Actions

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.

  2. Locate the SSL certificate used by the SSL profile  in the following location
    /config/filestore/files_d/<partition>_d/certificate_d/

  3. Create a new folder where you can save your script
    mkdir /var/tmp/Script
    cd /var/tmp/Script

  4. Create a new file by using any editing tool like vi or nano.
    vi <script_file_name>

  5. Copy the following script
    cat $1 | perl -e 'for (join("",<>) =~ m/-----BEGIN(?: TRUSTED| X509)? CERTIFICATE-----.*?-----END(?: TRUSTED| X509)? CERTIFICATE-----/gs) {open OPENSSL,"|openssl x509 -subject -enddate -noout";print OPENSSL;close OPENSSL}'

  6. Save the changes you made in your text editor
    Press Esc to enter Command mode, and then type :wq to write and quit the file.

  7. Change permissions on the script file
    chmod 755 <script_file_name>

  8. Execute the script against the bundle certicate file
    ./<script_file_name> /config/filestore/files_d/<partition>_d/certificate_d/<bundle_file_name>.crt
