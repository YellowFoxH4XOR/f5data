K09827356: What is the amount of memory allocated to restjavad by default

Description

The restjavad service implements all of the iControl REST API functionalities on a BIG-IP system. This article explains how to find the default memory allocation for the restjavad process.
 

Environment

  • Running restjavad process

Cause

Informational

Recommended Actions

You can find the Xms, Xmx, and Xmn sizes using the ps command:

  • Xms Size: Initial Java heap size (Young generation + Old generation)
  • Xmx Size: Maximum Java heap size (Young generation + Old generation)
  • Xmn Size: Minimum Java heap young generation size

Example output:

You can find the default memory allocation is 96MB:

  • Xms96m
  • Xmx192m
 ps -ef | grep restjavad

root 3519 21264 0 20:52 pts/0 S+ 0:00 grep restjavad
root 8516 4186 0 14:18 ? S 0:00 runsv restjavad
root 16757 8516 0 14:22 ? Sl 1:59 /usr/lib/jvm/jre/bin/java -Djava.util.logging.manager=com.f5.rest.common.RestLogManager -Djava.util.logging.config.file=/etc/restjavad.log.conf -Dlog4j.defaultInitOverride=true -Dorg.quartz.properties=/etc/quartz.properties -Xss384k -XX:+PrintFlagsFinal -Dsun.jnu.encoding=UTF-8 -Dfile.encoding=UTF-8 -XX:+PrintGC -Xloggc:/var/log/restjavad-gc.log -XX:+UseGCLogFileRotation -XX:NumberOfGCLogFiles=2 -XX:GCLogFileSize=1M -XX:+PrintGCDateStamps -XX:+PrintGCTimeStamps -XX:MaxPermSize=72m -Xms96m -Xmx192m

By fixing Bug ID 776393: Restjavad restarts frequently due to insufficient memory with relatively large configurations, the default restjavad heap memory has been increased to 384MB.
