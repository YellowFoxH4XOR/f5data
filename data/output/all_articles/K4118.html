Issue

When a JavaScript program fails to run on a client, it provides an error message that lists the line number that contains the failing JavaScript expression. Since many expressions are often grouped together on a single line, it can be difficult to determine the specific expression that is causing the problem.

You can work around this issue by installing the following FirePass sed script:

s@\([^"'/;]*\(\("\(\\["'\\nrtv]\|[^\"]\)*"\|'\(\\["'\\nrtv]\|[^\']\)*'\|[(,=] */\(\\/\|[^/]\)*/\)[^'"/;]*\)*\);@\1;@g

This sed script will convert the JavaScript to one expression per line, making it much easier to determine the specific expression that is failing.

Installing the sed script

  1. Use HttpWatch, or a similar tool, to determine the name and content type of the failing JavaScript object.
  2. Log in to the FirePass Administration Console.
  3. Click Portal Access.
  4. Click Content Processing.
  5. In the Web Applications Content Processing Scripts section, click the Add New or Add New Favorite link, depending on the version of FirePass you are running.
  6. In the Processing script name field, enter a name for the sed script.
  7. In the URL match patterns field, enter the URL for the JavaScript object that fails.
  8. In the Content type field, enter the content type from step 1.
  9. In the Sed processing script field, paste the following sed script:

    s@\([^"'/;]*\(\("\(\\["'\\nrtv]\|[^\"]\)*"\|'\(\\["'\\nrtv]\|[^\']\)*'\|[(,=] */\(\\/\|[^/]\)*/\)[^'"/;]*\)*\);@\1;@g

  10. From the Processing menu, click Pre-process response data.
  11. Click Add New.

Now, when you run the JavaScript application, the error should reveal the specific expression that is failing.
