Known Issue

The BIG-IP APM system fails to fully load Citrix server resources.

This issue occurs when all of the following conditions are met:

  • A BIG-IP APM webtop is configured with Citrix remote access or the client is using the Citrix PNAgent.
  • You are accessing a Citrix 4.5.0 or earlier server.

The issue occurs because the Citrix server sends a response that is not Request for Comment (RFC) compliant and the BIG-IP system cannot interpret the response properly.

Impact

Users are unable to access Citrix resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Using the Citrix PNAgent, the client stops responding.
  • The BIG-IP APM webtop does not render Citrix apps published on the webtop.

Workaround

Impact of workaround: You will need to reboot the Citrix server for the changes to take effect.

To work around this issue, you can set the HKLM\SOFTWARE\Citrix\XML Service\LegacyChunkHeader registry key to 0 on the Citrix server.
