Issue

Starting in FirePass 5.5.2 with Cumulative Hotfix HF-552-12, FirePass 6.0.1 with Cumulative Hotfix HF-601-11, and FirePass 6.0.2 with Cumulative Hotfix HF-602-4, FirePass displays a new security warning on the client system before autolaunching an application for a Network Access favorite or a Static Application Tunnel. When a user launches a Network Access favorite or a Static Application Tunnel favorite, and you configured the favorite to autolaunch an application, the FirePass client-side component opens a pop-up window with a security warning that appears similar to the following example:

<FirePassHostname> has requested to execute <ApplicationName>
Do you want to allow this operation?
In the future, do no show this warning for requests from this host

Important: If you install hotfix-100479 on a FirePass controller running version 6.0.2, the above security warning does not appear in Internet Explorer (IE) if the URL of the FirePass controller is added to the IE Trusted sites zone. To obtain hotfix-100479, contact F5 Technical Support. For more information about the IE Trusted sites zone, refer to your Microsoft Internet Explorer documentation.

The security warning displays <FirePassHostname> as the host name or IP address of the FirePass controller and <ApplicationName> as the name of the application that is configured to autolaunch. Users can click the Yes button to launch the application, or the No button to prevent the application from launching. Additionally, users can configure the FirePass client-side component to prevent this message from appearing in the future by selecting the In the future, do not show this warning for requests from this host check box.

Selecting the In the future, do not show this warning for requests from this host check box modifies the HKEY_CURRENT_USER\Software\F5 Networks\TrustedHosts registry key. If the user does not have sufficient Windows permissions to modify this registry key, Windows administrators can preinstall the registry key on client systems.

For more information about distributing registry changes, refer to the following Microsoft document: 

http://msdn.microsoft.com/en-us/library/ms954395.aspx

Previously, before autolaunching an application configured for a Network Access favorite or a Static Application Tunnel, the FirePass client-side component displayed a security warning where <ApplicationName> is the name of the application that is configured to autolaunch. The security warning message appears similar to the following example:

Are you sure you want to launch <ApplicationName>?

Users could click the Yes button to launch the application, or the No button to prevent the application from launching.

Disabling the security warning for a Network Access favorite

To disable the security warning for a Network Access favorite, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to Network Access > Resources.
  3. Click the Launch Application tab.
  4. From the Resource Group menu, select the resource group you want to configure.
  5. Clear the Display message box before launching applications check box.

Disabling the security warning for a Static Application Tunnel favorite

To disable the security warning for a Static Application Tunnel favorite, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to Application Access > App Tunnels > Resources.
  3. From the Resource Group menu, select the resource group you want to configure.
  4. Select the name of the Static Application Tunnel you want to configure.
  5. Clear the Display message box before launching applications check box.
  6. Click Update.
