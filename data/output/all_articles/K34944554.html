Known Issue

The BIG-IP install mechanism does not allow you to install to an active slot, and you must install any hotfixes to an off-line slot. Once the off-line partition has the desired software, you can boot the system to the modified slot.

When installing a hotfix, if you specify the current, active slot as the destination, the hotfix fails to install.

This issue occurs when all of the following conditions are met:

  • You are installing a BIG-IP hotfix.
  • You specify a currently active volume as the destination for the hotfix.

Impact

The hotfix installation does not successfully complete.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The hotfix does not install, and it produces no error message.

Resolution

Status

F5 Product Development has assigned ID 624404 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can select another volume when installing a hotfix.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
