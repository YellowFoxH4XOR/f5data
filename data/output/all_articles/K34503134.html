Known Issue

Creating a custom report may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM device software has recently been installed or upgraded.
  • You attempt to create a custom report using the Configuration utility.

Impact

The Create the Design Custom Report webpage does not render correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you access the custom report webpage, and click Create the Design Custom Report, a pop-up window displays; however, the Available Fields folder spawns indefinitely and the Configuration utility becomes unresponsive.
  • When you run the following SQL query from the command line of the affected device, the output fails to include the log_param_metadata_ui table:

    mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e 'use apm; show tables;'

    Output may appear similar to the following example:

    +-----------------------+
    | Tables_in_apm |
    +-----------------------+
    | apm_settings |
    | log_data |
    | log_data_0 |
    | log_data_1 |
    | log_data_2 |
    | log_data_3 |
    | log_data_4 |
    | log_data_current |
    | log_metadata |
    | log_param_groups_ui |
    | log_param_metadata |
    | log_session_details |
    +-----------------------+

  • When running the SQL command, the command fails to connect to the SQL database.

Status

Workaround

There is no workaround for this issue. However, to address this issue, you can perform the following procedures:

Impact of procedures: The BIG-IP APM device will be unavailable while performing an installation of the BIG-IP system.

  • Resolving the issue after a clean installation of the BIG-IP system
  • Resolving a repeat occurrence of the issue after clearing the log_param_groups_ui apm database table

Resolving the issue after a clean installation of the BIG-IP system

If the newly installed system encounters the same issues described in this article, perform the following steps:

  1. Log in to the command line of the affected system.
  2. To enter the MySQL administrative shell, type the following command:

    mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw`

    Note: When accessing the MySQL administrative shell, the BIG-IP system displays messages similar to the following example:

    Welcome to the MySQL monitor. Commands end with ; or \g.
    Your MySQL connection id is 46
    Server version: 5.1.52-enterprise-commercial-advanced-log Source distribution

    Copyright (c) 2000, 2010, Oracle and/or its affiliates. All rights reserved.
    This is commercial software, and use of this software is governed by your applicable license agreement with MySQL

    Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

  3. To set the MySQL database to apm, type the following command:

    use apm;

    Note: When setting the MySQL database, the BIG-IP system displays messages similar to the following example:

    Reading table information for completion of table and column names
    You can turn off this feature to get a quicker startup with -A
    Database changed

  4. To display the apm database tables, type the following command:

    show tables;

    Output should appear similar to the following example:

    +---------------------+
    | Tables_in_apm |
    +---------------------+
    | apm_settings |
    | log_data |
    | log_data_0 |
    | log_data_1 |
    | log_data_2 |
    | log_data_3 |
    | log_data_4 |
    | log_data_current |
    | log_metadata |
    | log_param_groups_ui |
    | log_param_metadata |
    | log_session_details |
    +---------------------+
    12 rows in set (0.00 sec)

  5. To remove the log_param_groups_ui database table, type the following command:

    DROP TABLE IF EXISTS log_param_groups_ui;

    Note: When removing the MySQL database table, the BIG-IP system displays a message similar to the following example:

    Query OK, 0 rows affected (0.00 sec)

  6. To display the apm database tables, type the following command:

    show tables;

    Output should appear similar to the following example:

    +---------------------+
    | Tables_in_apm |
    +---------------------+
    | apm_settings |
    | log_data |
    | log_data_0 |
    | log_data_1 |
    | log_data_2 |
    | log_data_3 |
    | log_data_4 |
    | log_data_current |
    | log_metadata |
    | log_param_metadata |
    | log_session_details |
    +---------------------+
    11 rows in set (0.00 sec)

    Note: Check the output again to verify that the log_param_groups_ui database table is no longer listed.

  7. To exit the MySQL administrative shell, type the following command:

    quit

    Note: When exiting the MySQL administrative shell, the BIG-IP system displays a message similar to the following example:

    Bye

  8. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  9. To restart the logd process, type the following command:

    restart /sys service logd

  10. To restart the tomcat process, type the following command:

     

    restart /sys service tomcat

  11. To exit tmsh, type the following command:

    quit

Resolving a repeat occurrence of the issue after clearing the log_param_groups_ui apm database table

In the unlikely event that the previous procedures do not resolve the issue, you can force the BIG-IP APM system to rebuild the APM database by performing the following steps:

  1. Log in to the command line of the affected system.
  2. To enter the MySQL administrative shell, type the following command:

    mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw`

    Note: When accessing the MySQL administrative shell, the BIG-IP system displays messages similar to the following example:

    Welcome to the MySQL monitor. Commands end with ; or \g.
    Your MySQL connection id is 46
    Server version: 5.1.52-enterprise-commercial-advanced-log Source distribution

    Copyright (c) 2000, 2010, Oracle and/or its affiliates. All rights reserved.
    This is commercial software, and use of this software is governed by your applicable license agreement with MySQL

    Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

  3. To set the MySQL database to apm, type the following command:

    use apm;

    Note: When setting the MySQL database, the BIG-IP system displays messages similar to the following example:

    Reading table information for completion of table and column names
    You can turn off this feature to get a quicker startup with -A
    Database changed

  4. To completely remove the apm database, type the following command:

    DROP DATABASE IF EXISTS apm;

    Note: When removing the MySQL apm database, the BIG-IP system displays a message similar to the following example:

    Query OK, 13 rows affected (0.02 sec)

  5. Log in to the tmsh by typing the following command:

    tmsh

  6. To restart the logd process, type the following command:

    restart /sys service logd

  7. To restart the tomcat process, type the following command:

    restart /sys service tomcat

  8. To exit tmsh type the following command:

    quit
