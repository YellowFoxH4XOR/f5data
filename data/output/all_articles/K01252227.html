Issue

Description

The size of engineering hotfix ISO files can vary greatly between different builds. This can lead to confusion and concern that a small engineering hotfix file may be missing components.

Environment

  • Engineering hotfix ISO file

Cause

An engineering hotfix file is designed as an incomplete ISO image, which requires the base image to be present to install. The engineering hotfix file supplements the base image and alters the installation from the base image to include additional hotfix(es) which the engineering hotfix file contains. The engineering hotfix contains updated packages along with all dependent packages. Due to the difference in size between packages and the difference in the number of dependent packages, the resulting Engineering hotfix ISO size has the potential to vary greatly in size.

Recommended Actions

No action is needed; the potential file size difference between engineering hotfix files is functioning as designed.
