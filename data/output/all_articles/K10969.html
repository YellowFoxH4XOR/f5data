Known Issue

This is the result of a known issue. Intelligent Browser Referencing (IBR) pv tags for an object are not refreshed in the etag cache. This issue occurs when the origin web server (OWS) responds with an HTTP 304 response to a conditional GET request from the BIG-IP WebAccelerator. As a result, unexpected object cache behavior may occur.

F5 Product Development tracked this issue as CR120738 and it was fixed in BIG-IP WebAccelerator 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
