Known Issue

VIPRION systems may log extraneous userauth_hostbased mismatch messages.

This issue occurs when the following conditions are met:

  • Your BIG-IP system is a VIPRION or VIPRION-hosted Virtual Clustered Multiprocessing (vCMP) guest.
  • The 'client sends' section of the message specifies one of the following:
    • localhost
    • localhost.localdomain
    • slot1
    • slot2
    • slot3
    • slot4
    • slot5
    • slot6
    • slot7
    • slot8

      For example, the 'client sends' section of the following message specifies slot3:

      sshd[8948]: userauth_hostbased mismatch: client sends slot3, but we resolve 127.3.0.3 to 127.3.0.3

Impact

The specific error messages are benign, and should not impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system logs error messages to the /var/log/ltm file that appear similar to the following example:

    slot1/g1 info sshd[8948]: userauth_hostbased mismatch: client sends slot3, but we resolve 127.3.0.3 to 127.3.0.3
    slot1/g1 info sshd[8948]: Accepted hostbased for root from 127.3.0.3 port 35401 ssh2
