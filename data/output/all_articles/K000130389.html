K000130389: BGP not advertising some routes after graceful restart

Type
Support Solution
Published
2022-12-28
Updated
2022-12-28
Status
Final
Source
https://my.f5.com/manage/s/article/K000130389

Description


BGP not advertising some routes after graceful restart , we can still see these routes in the Zebos 

We can confirm routes are not advertised using :
imish -r<N> -e 'sh ip bgp neighbors 10.31.25.230 advertised-routes'
Note : Replace <N> with route domain number. Example for route domain 1 , use -r1.

To confirm the routes are present in Zebos, use :
imish -r<N> -e 'sh ip route'
Note : Replace <N> with route domain number. Example for route domain 1 , use -r1.
 

Environment

    • BGP
    • Graceful restart happens - example primary blade failover 
    

Cause

Bug ID 1134057
 

Recommended Actions

Contact F5 support for an EHF if this is not fixed in any of the latest versions
