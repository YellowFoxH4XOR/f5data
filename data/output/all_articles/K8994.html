Known Issue

This is the result of a known issue. The BIG-IP GTM HTTP monitor marks the virtual server down when the server response uses HTTP Keep-Alive headers. For example, if you configure an HTTP/1.1 monitor to check the status of a virtual server, and the server responds with a Connection: Keep-Alive header, the BIG-IP GTM system marks the virtual server down.

F5 Product Development tracked this issue as CR102281 and it was fixed in BIG-IP GTM 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

You can work around this issue by configuring the HTTP monitor to send a Connection: close HTTP header to the virtual server. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Global Traffic > Monitors.
  3. Click the HTTP monitor that is associated with your virtual server.
  4. Add a Connection: close header to the Send String.

    For example, the following Send String sends an HTTP/1.1 request to the virtual server:

    GET / HTTP/1.1\r\nHost: 1.1.1.1\r\n\r\n

    Change the Send String to add a Connection: close header as in the following example:

    GET / HTTP/1.1\r\nHost: 1.1.1.1\r\nConnection: close\r\n\r\n
  5. Click Update.
