Known Issue

The BIG-IP system may fail to log Deterministic NAT (DNAT) states, in a proper serialized fashion, to the /var/log/ltm file. This issue occurs when all of the following conditions are met:

  • You have made a configuration change to a Large Scale NAT (LSN) pool with deterministic NAT mode.
  • You performed the change while the BIG-IP system was processing connections.

Impact

Utilities such as dnatutil fail to properly perform reverse mapping with the interleaved DNAT state log entries.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The dnatutil utility reports inconsistent reverse mapping when it attempts to parse the DNAT state log entries in the /var/log/ltm file.
