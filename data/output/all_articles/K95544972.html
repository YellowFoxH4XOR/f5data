Description

When using BIG-IP SWG, you may be unable to browse the InterNET.
The browser may display messages such as:

  • Can’t reach this page
  • The proxy server isn’t responding

Environment

  • You're using BIG-IP SWG.
Cause

This may be due to ID813729.
Hopefully, this can be resolved by disabling the "tmm.access.policytrace" database variable.

Recommended Actions

This can be resolved by disabling the "tmm.access.policytrace' database variable:
  1. Open a CLI/SSH connection to the BIG-IP SWG
  2. Run the command: #tmsh modify sys db tmm.access.policytrace value disable
Additional Information

In case a packet trace has been recorded while the TCP Reset cause were logged, you may see the following TCP Reset cause message: "cl sm driver error (Not found)"
