Description

Upgrading BIG-IQ VE from 5.4 to 8.0 fails 

Environment

  • BIG-IQ running v5.4.0
  • Upgrade to v8.0.0

Cause

When upgrading from v5.4.0 via 6.1.0 to v8.0.0 fails. This is due to v7.0 has the last version with tokumx, it is easier for v7.0 to jump to a higher version with a different backend database (postgres)

Recommended Actions

Recommended upgrade path.

Note: Make sure to backup UCS and Generate Qkview each time they upgrade to a new version in the upgrade path

  • v5.4 -> v7.0 -> v8.0


    v5.4 -> 7.0
    BIG-IQ setups that support an upgrade process to the current version


    v7.0 -> 8.0
    Upgrading to BIG-IQ 8.0.0
