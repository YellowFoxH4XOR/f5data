K34647606: Geolocation Violation 'Access from Malicious or Disallowed Source' for Private IPs (RFC 1918)

Type
Support Solution
Published
2025-09-18
Updated
2025-09-18
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K34647606

Description
Private IPs (RFC 1918) will generate Geolocation Violation 'Access from Malicious or Disallowed Source'.

Environment

  • In Learning and Blocking setting, Alarm and/or Blocking is enabled for Violation 'Access from Malicious or Disallowed Source'
  • N/A is added to the Disallowed Geolocation configuration

Cause
N/A are IP addresses that ASM is unable to identify. These IP addresses include RFC-1918 (Private IP) addresses or unassigned global addresses. 

Recommended Actions

To avoid ASM generating the violation and/or blocking (if enabled) requests with source IP addresses that are RFC-1918, then remove N/A from the Disallowed Geolocation configuration.
  1. Browse to Security > Application Security > Geolocation Enforcement
  2. Check the Policy selected is one required for modification
  3. In the section 'Disallowed Geolocations:' search for N/A
  4. Select N/A
  5. Click on >> to move N/A to section 'Allowed Geolocations:'
  6. Click on Save 
  7. Click on Apply Changes
