Known Issue

Description

The standby BIG-IP system may continue to advertise default route link-state advertisements (LSAs).

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured to use OSPFv3.
  • The BIG-IP system is currently standby in a high-availability configuration.
  • The Open Shortest Path First (OSPFv3) protocol is configured to redistribute default route information using the default-information originate option.

The OSPF routing module is a dynamic routing protocol for internal networks, based on a link-state algorithm. The BIG-IP Advanced Routing Modules feature contains two OSPF routing modules: OSPFv2 and OSPFv3. OSPFv2 supports the IPv4 addressing format and OSPFv3 supports the IPv6 addressing format.

The default-information originate command creates a default external route into an OSPF routing domain.

To guarantee correct operation in redundant active/standby configurations, the BIG-IP system automatically changes the runtime state after failover. The purpose of a runtime state change is to modify advertised link state information in a way that makes the standby unit the least preferred next-hop router. For OSPFv3, the following two methods accomplish this goal:

  • The LSAs for all redistributed routes are aged out.
  • The OSPF interface cost is increased on all interfaces to the maximum value (65535):

    # show ipv6 ospf interface

    vlan1 is up, line protocol is up
      Interface ID 9
      IPv6 Prefixes
        fe80::250:56ff:fe92:2717/64 (Link-Local Address)
        2001:1::2/112
      OSPFv3 Process (*null*), Area 0.0.0.0, Instance ID 0
        Router ID 5.5.5.6, Network Type BROADCAST,

    Cost: 65535
            Transmit Delay is 1 sec, State Backup, Priority 1
            Designated Router (ID) 5.5.5.5
              Interface Address fe80::250:56ff:fe92:2713
            Backup Designated Router (ID) 5.5.5.6
              Interface Address fe80::250:56ff:fe92:2717
            Timer interval configured, Hello 10, Dead 40, Wait 40, Retransmit 5
              Hello due in 00:00:09
            Neighbor Count is 1, Adjacent neighbor count is 1

    However, as a result of this issue, the standby BIG-IP continues to advertise the default route LSA.

    Impact

    The standby unit will advertise a default route using OSPFv3.

    Symptoms

    As a result of this issue, you may encounter the following symptoms after failover of the active unit:

    • The standby BIG-IP system will increase the interface cost as expected.
    • The standby BIG-IP system continues to advertise its default route. For example, the following output shows the standby BIG-IP system advertising its default route LSA:

        # show ipv6 ospf database external self-originate
        
                    OSPFv3 Router with ID (5.5.5.5) (Process *null*)
        
                        AS-external-LSA
        
          LS age: 1670
          LS Type: AS-External-LSA
          Link State ID: 0.0.0.1
          Advertising Router: 5.5.5.5
          LS Seq Number: 0x80000004
          Checksum: 0xB3FB
          Length: 48
            Metric Type: 2 (Larger than any link state path)
            Metric: 20
            Prefix: ::/0
            Prefix Options: 0 (-|-|-|-)
            Forwarding Address: 2001:1::5
            External Route Tag: 0
