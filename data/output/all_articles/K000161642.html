Description

Throughput statistics become unavailable for primary Blade  on both the GUI dashboard and via CLI commands after upgrade to 17.5.1.x in Viprion Multi-Blade Cluster.

Environment

  • VIPRION chassis with multiple blades
  • Software Upgrade to 17.5.1.x
  • Active/Standby HA pair of VIPRION chassis

Cause

Unknown

Answer/Recommended Actions

No counters will be increased with time when running these CLI commands.

#  tmsh show /sys performance throughput

#  tmctl -f statsd system_traffic_stat

#  tmctl -d blade tmm_stat  -s client_side_traffic.bytes_out,client_side_traffic.bytes_in,server_side_traffic.bytes_in,server_side_traffic.bytes_out

Below  fields will also not be increasing when checking in browser developer tools for URL 'https://<management-ip>/rrdstats/rrdstats'

"totclientconns,curclientconns,ssltotcomclient,ssltotnatclient,tput_bytes_out,servicebytes,tput_bytes_in,httpcompression"

Please follow below steps to resolve this issue - 

Note: Please ensure to run this in maintenance window as it involves failover and primary blade restart. 

  1.  ​​​Save the configuration on the Active/standby.
  2.  Failover from Active to Standby and check if issue is resolved. Proceed to next step if issue does not resolve.
  3.  Ensure you are connected to the primary blade on new Standby.
  4.  Reboot the Primary Blade.
  5.  Wait for the Blade to come up.
  6.  Failover Active to Standby and check if issue is resolved in new standby or not. 
  7.  If not resolved in new Standby then please reboot primary Blade in new Standby as well.
