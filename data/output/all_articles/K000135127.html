K000135127: After loading a UCS BD fails with error "Watchdog detected failure for process. Process name: bd, Failure: Insufficient number of threads (required: 8, found: 0)."

Type
Support Solution
Published
2023-06-20
Updated
2023-06-20
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135127

Description

  • After loading a UCS BD fails with error messages
  • BD remains down and the device remains offline
  • ASM subsystem error (asm_start,F5::NwdUtils::Nwd::log_failure): Watchdog detected failure for process. Process name: bd, Failure: Insufficient number of threads (required: 8, found: 0).
  • HA proc_running bd fails action is go offline and down links.

Environment

  • ASM provisioned
  • Licensed number of cores is less than the number of physical cores

Cause

This is due to the licensed number of CPU cores being less than the physical cores assigned.

 Recommended Actions

  1. Either reduce the number of physical cores or obtain a license that includes equal to or greater than the number of physical cores.
