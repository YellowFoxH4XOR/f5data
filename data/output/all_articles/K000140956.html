K000140956: Glue records are not returned along with NS records related name queries

Type
Support Solution
Published
2024-09-05
Updated
2024-09-05
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140956

Description

Glue records are not returned along with NS records in DNS queries

Environment

  • GTM
  • Name queries for NS record

Cause

This is a change in BIND behavior.

BIND is a third-party tool and F5 has no control over it.

 

Recommended Actions

You may workaround this, revert BIND's behavior to previous versions by running following commands:

 

(a) add "glue-cache no;" statement to BIND options section (/var/named/config/named.conf) 

(b) restart named (tmsh restart sys service named)
