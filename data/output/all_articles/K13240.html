K13240: The BIG-IP WebAccelerator system fails to import a policy and reports an error message when the policy name contains spaces

Known Issue

The BIG-IP WebAccelerator system fails to import a policy and reports an error message. This issue occurs when all of the following conditions are met:

  • You attempt to import a policy that contains spaces in its name.

    For example:

    My L2 policy

Creating or copying a policy is not affected by this issue; only importing a policy is affected.

Impact

The affected policy will not be imported into the BIG-IP WebAccelerator system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility reports error messages that appear similar to the following example:

    Operation Failed
    Policy Not Imported.
    There was 1 error.
    (1) Error when attempting to import policy

Workaround

To work around this issue, you can enclose the policy name with single quotes. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the Configuration utility.
  2. Navigate to WebAccelerator >> Policies >> Policy List.
  3. Click on the Import button.
  4. Click on the Browse button and select the policy file exported in XML format.
  5. Type the name of the policy and enclose it in single quotes.

    For example:

    'My L2 policy'

  6. To import the policy, click on the Import button.
