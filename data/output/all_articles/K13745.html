Issue

Old Behavior

Prior to BIG-IP 11.1.0, the BIG-IP system had SNMP OID sysCpu objects containing information relating to the CPU status on the system.

New Behavior

Beginning in BIG-IP 11.1.0, the sysCpu objects are deprecated and replaced by sysCpuSensor objects.

F5 Product Development tracked this change as ID 368186.

Impact

The SNMP object instance relating to sysCpu is no longer valid.

Recommended Actions

An SNMP management system configured to receive the SNMP object instance relating to sysCpu must be updated to access sysCpuSensor objects.
