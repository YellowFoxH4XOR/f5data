K000149055: Wam-tcp-wan-optimized profile preventing upgrade to 17.1.1.3

Type
Support Solution
Published
2025-03-19
Updated
2025-03-19
Source
https://my.f5.com/manage/s/article/K000149055

Description

After upgrade never fully loads and can't access via SSH.

  • Upgrading from version 15 or earlier to 16 or latest.
  • Unable to access via SSH.
  • The config doesn't load.

Environment

  • BIG-IP LTM
  • Version 17.1. or earlier
  • HA

Cause

It can be caused by a Bug 941961. This is due to the WAM TCP profile is legacy profile beyond version 15.1.10.4, which is why after the upgrade device fails to load configuration.

Recommended Actions

You can follow the mitigation steps mentioned in the BUG ID page, or replace the profile it is a easier way.

 

Replace the wam-tcp-wan-optimized  for  tcp-lan-optimized.

       /Common/wam-tcp-wan-optimized {

        context clientside

Follow the steps below to replace the profile:

  1. View the current virtual server configuration:

     
    tmsh show ltm virtual <virtual_server_name>

  2. Remove the wam-tcp-wan-optimized profile:

     
    tmsh modify ltm virtual <virtual_server_name> profiles delete { wam-tcp-wan-optimized }

  3. Add the tcp-lan-optimized profile:

     
    tmsh modify ltm virtual <virtual_server_name> profiles add { tcp-lan-optimized }

  4. Save the configuration:

     
    tmsh save sys config

After the change the virtual server conf should look like this:

ltm virtual /Common/vs_test {

  destination /Common/192.168.2.5:443

  ip-protocol tcp

  mask 255.255.255.255

  pool /Common/pool_test

  profiles {

    /Common/tcp-lan-optimized { }

  }
