Known Issue

This is the result of a known issue. BIG-IP may insert an incorrect hostname when logging messages to a remote server using the syslog-ng utility.

When a BIG-IP system is configured to log to a remote syslog server, some logs generated by the system or from within an iRule may contain a hostname containing tmm, sccp, or aom instead of the actual system hostname. If multiple BIG-IP systems log to a shared remote log server, it can be difficult for administrators to track which system is reporting issues.

F5 Product Development tracked this issue as ID 349362 and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Note: For information about configuring the BIG-IP to log remotely, refer to K5527: Configuring the BIG-IP system to log to a remote syslog server.
