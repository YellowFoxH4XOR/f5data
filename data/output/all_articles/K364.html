Topic

The big3d utility is used to allow a 3-DNS Controller to poll each BIG-IP for the status of its virtual servers and active connections.

If you are not using a 3-DNS Controller in conjunction with your BIG-IP, you do not need to run the big3d utility. The method that you use to prevent the big3d utility from initializing upon startup is specific to the version of BIG-IP that you are running.

BIG-IP versions 4.0 through 4.6.4

To prevent the big3d utility from initializing upon start up for BIG-IP versions 4.0 through 4.6.1, perform the following steps.

  1. From the command line, execute the following commands:

    cd /etc/bigstart/startup
rm S15big3d
cd ../restart
rm S15big3d
cd ../stage1
rm S15big3d

    Note: The S15big3d file that you delete is only a symbolic link. If required, you can recreate this link by typing ln -s ../scripts/big3d-ctrlS15big3d from the startup, restart, or stage 1 directories.

  2. Reboot the BIG-IP or type the following command:

    bigstart shutdown big3d

BIG-IP versions 1.8.3 through 3.3.1 PTF-06

To prevent the big3d utility from initializing upon start up for BIG-IP versions 1.8.3 through 3.3.1 PTF-06, perform the following steps.

  1. Using a text editor, such as vi or pico, open the /etc/rc.local file.
  2. Locate the following three lines:
    if [ -f /usr/sbin/big3d ]; then
          echo -n 'big3d ';  /usr/sbin/big3d 2> /dev/null
fi
  3. Comment out these lines by placing a # character in front of each.

    These lines should now appear as follows:

    #if [ -f /usr/sbin/big3d ]; then
#        echo -n 'big3d ';  /usr/sbin/big3d 2> /dev/null
#fi
  4. Save the file and exit the text editor.
  5. Reboot the BIG-IP or type the following command:

    kill `ps -ax |grep big3d | awk -F " " '{ print $1 }'`

    You may receive errors similar to the following:

    kill: (214) - No such pid
kill: (216) - No such pid
kill: (218) - No such pid
kill: (219) - No such pid
kill: (220) - No such pid
kill: (221) - No such pid
kill: (222) - No such pid

    These errors are benign and simply indicate that the parent big3d process, and any child processes, were stopped.
