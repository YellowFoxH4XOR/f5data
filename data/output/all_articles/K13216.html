Known Issue

A user accessing a subdirectory of a share may not be able to view files or directories through the ARX system.

This issue occurs when all of the following conditions are met:

  • The user is using the Finder file manager.
  • The user is running Mac OS X version 10.7.
  • The user does not have permissions to view the root of a share.

Impact

Affected users may be unable to access files.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Finder file manager is unable to access files or directories in a subdirectory of a share.

    For example: A user using the Finder file manager to access the \\Users\smith directory cannot view files in the smith directory if they do not have permissions to view the root (\\Users) of the share.

Workaround

To work around this issue, affected users can access the files using an alternate method (command line or a file manager other than Finder) or you can grant the affected users permisions to the root of the share.

Impact of workaround: None
