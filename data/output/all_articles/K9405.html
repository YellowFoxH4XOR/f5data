Known Issue

This is the result of a known issue. FirePass incorrectly reads Firefox 2 and 3 browser as being Firefox rather than Mozilla. As a result, FirePass may redirect Mac users running Firefox 2 or 3 to a page asking them to manually install the InspectionHost.dmg file rather than the file auto-installing. This is the same page that Safari users would receive. Users may experience this issue when the Check Files (MacOSX) feature has been created and enabled as a prelogon check.

F5 Networks Product Development is tracking this issue as CR107490.

This issue was fixed in cumulative hotfix HF-602-8 for FirePass version 6.0.2 and in cumulative hotfix HF-603-1 for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
