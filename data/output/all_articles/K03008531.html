Issue

Error Message

01260009:4: Connection error: ssl_hs_rx_srvkeyxchg:4500: weak DHE group is used (47)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You upgrade your BIG-IP system from an earlier version to BIG-IP 11.5.4 HF3, 11.6.3.2, 12.0.0 or later.
  • You have one or more virtual servers with an associated Server SSL profile.
  • You have not patched a pool member for CVE-2015-4000. For more information, refer to K16674: TLS vulnerability CVE-2015-4000.
  • A pool member attempts to negotiate a Secure Sockets Layer (SSL) connection with the BIG-IP system using Diffie-Hellman Ephemeral (DHE) ciphers

Impact

SSL connections using DHE ciphers fail.

Recommended Actions

F5 recommends patching the affected pool member for CVE-2015-4000. However, if that is not possible, you can disable DHE ciphers in the Server SSL profile. To do so, perform the following procedure:

Disabling DHE ciphers

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Server.
  3. Under Name, click the affected profile.
  4. Set Configuration to Advanced.
  5. Add the following syntax to the current Ciphers string:

    !EXPORT:!DHE

    For example, to update the default Ciphers string DEFAULT, use the following syntax:

    DEFAULT:!EXPORT:!DHE

  6. Click Update.

Determining the affected virtual server

If you are uncertain which virtual server is affected, you can enable SSL debug logging. For more information, refer to the Enabling SSL debug logging section of K15475: Troubleshooting SSL/TLS renegotiation.
