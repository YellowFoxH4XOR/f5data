Known Issue

A virtual server that targets another virtual server may cause an Internet Control Message Protocol (ICMP) packet flood.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to send packets to a second virtual server on the same BIG-IP system.
  • The second virtual server is unable to process traffic.

Impact

The BIG-IP system sends an excessive amount of ICMP Destination Unreachable packets to clients.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clients are receiving excessive amounts of ICMP Destination Unreachable packets when connecting to the BIG-IP system.
