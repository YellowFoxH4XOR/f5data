Description

After changing Learn, Alarm or Block flags for violations in a Security Policy's Learning and Blocking settings, and applying the policy, the changes are reverted when refreshing the page.

Environment

  • Learning and Blocking Page

Cause

Changes were not saved using Save button before applying the policy.

Recommended Actions

Save the changes before applying the policy.

Additional Information

In version 15.1 and later, the Save button is only present at the bottom of the page. In earlier versions it is present at the top and bottom of the page.
