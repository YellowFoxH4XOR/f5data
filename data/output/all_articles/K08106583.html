Topic

The VELOS CX410 and CX410-N chassis platforms use different power supply units (PSUs) that should only be installed in their supported platforms.

  • CX410 chassis platform: Bel AC power supply (F5 part number PWR-0366-xx, model SPAFFIV-07).
  • CX410-N chassis platform: Bel DC power supply (F5 part number PWR-0367-xx, model SPDFFIV-08).

Description

The VELOS CX410 and CX410-N chassis platforms use different power supply units (PSUs) that should only be installed in their supported platforms.

VELOS CX410

The VELOS CX410 chassis platform uses a Bel AC power supply (F5 part number PWR-0366-xx). The Bel DC power supply is not supported on the VELOS CX410 chassis platform and cannot be swapped for the AC power supply.

You can verify the F5 part number by removing the power supply and locating the F5 PN on the exterior label, as shown in the following figure.

Figure: F5 part number location

You can visually identify the AC power supply without removing it by the alternating current symbol (~) below the indicator lights, as shown in the following figure.

Figure: Visually identifying the power supply

You can also verify the power supply using the VELOS system controller command-line interface (CLI) or webUI. In the CLI and webUI, the power supply is identified using the part-no and Part Number, respectively, rather than the F5 PN. The part-no and Part Number is equivalent to the Model on the external label. For Bel AC power supplies, this is SPAFFIV-07 .

To verify the power supply using the CLI or webUI, perform one of the following procedures:

Impact of procedure: Performing either of the following procedures should not have a negative impact on your system.

Verify the power supply using the webUI

  1. Log in to the system controller webUI as chassis administrator.
  2. Go to System Settings > System Inventory.
  3. Locate the power supply in the list. For a Bel AC power supply, the value in the Part Number column should be SPAFFIV-07.

Verify the power supply using the CLI

  1. Log in to the VELOS system controller CLI as chassis administrator using the system controller floating IP address.
  2. Identify the power supply by entering the following command where <#> is the number of the installed PSU:

    show components component psu-<#> state part-no

    The following output shows the part-no for the AC power supply:

    state part-no SPAFFIV-07

VELOS CX410-N

The VELOS CX410-N chassis platform uses a Bel DC power supply (F5 part number PWR-0367-xx). The Bel AC power supply is not supported on the VELOS CX410-N chassis platform and cannot be swapped for the DC power supply.

You can verify the F5 part number by removing the power supply and locating the F5 PN on the exterior label, as shown in the following figure.

Figure: F5 part number location

When the DC power supply is installed, you can visually identify it by the absence of an alternating current symbol (~) below the indicator lights, as shown in the following figure.

Figure: Visually identifying the power supply

You can also verify the power supply using the VELOS system controller CLI or webUI. In the CLI and webUI, the power supply is identified using the part-no and Part Number, respectively, rather than the F5 PN. The part-no and Part Number is equivalent to the Model on the external label. For Bel DC power supplies, this value is SPDFFIV-08 .

To verify the power supply using the CLI or webUI, perform one of the following procedures:

Impact of procedure: Performing either of the following procedures should not have a negative impact on your system.

Verify the power supply using the webUI

  1. Log in to the system controller webUI as chassis administrator.
  2. Go to System Settings > System Inventory.
  3. Locate the power supply in the list. For a Bel AC power supply, the value in the Part Number column should be SPDFFIV-08.

Verify the power supply using the CLI

  1. Log in to the VELOS system controller CLI as chassis administrator using the system controller floating IP address.
  2. Identify the power supply by entering the following command where <#> is the number of the installed PSU:

    show components component psu-<#> state part-no

    The following output shows the part-no for the DC power supply:

    state part-no SPDFFIV-08
