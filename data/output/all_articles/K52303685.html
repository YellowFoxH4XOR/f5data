K52303685: iHealth API for Support Case Creation and QKView Upload

Type
Support Solution
Published
2020-04-17
Updated
2026-01-28
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K52303685

Description

You may use the iHealth API to upload QKView files and associate them with your existing support case by specifying the case number in a POST call API.
However, The iHealth API does not currently provide an endpoint to create new F5 support cases.
To open a new support case, you must use standard F5 support channels such as the F5 Support Portal.

Environment

  • QKView uploaded to https://ihealth.f5.com

Cause

None

Recommended Actions

 

  1. Create a Support Case:
    Use the F5 Support Portal or contact F5 Support directly. 
  2. Review the authentication changes in F5 iHealth and generate new iHealth API credentials

    • K000132249: Authentication changes in F5 iHealth

    • K000130498: Generating new iHealth API credentials using iHealth API token service

  3. Upload a QKView:
    With your case number, use the iHealth API’s POST endpoint to upload your QKView file and associate it with your existing support case. 

    Qkviews : Operations pertaining to qkview overview

  4. Additional documentation can be found on the Devcentral iHealth Wiki

    Note: The iHealth API is not supported by the F5 support organization, but is provided as a helpful addition for you to keep your BIG-IPs running as well as possible.

Additional Information

An uploaded QKView cannot be associated to a support case after-the-fact via API
