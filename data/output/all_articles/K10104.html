Known Issue

This is the result of a known issue. When enabled, the Share Single MAC Address setting specifies that all VLANs on the BIG-IP system share a single MAC address. By default, the setting is disabled and VLANs use unique MAC addresses. If you enable the Share Single MAC Address setting, and then attempt to disable the setting using the Configuration utility, the change is not made and the Configuration utility displays the following error message:

01070050:3: Db variable vlan.macassignment's enum value [first-member] is out of enumerated (global,unique) range.

F5 Product Development tracked this issue as CR119816 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, or WebAccelerator release notes.

Workaround

If you have enabled the Share Single MAC Address setting, you can disable the setting using the command line. To do so, type the following command:

bigpipe db Vlan.MacAssignment unique
