Description

sFlow have enabled globally, no interface data pulled on network monitoring system

 

Environment

  • sFlow
  • the "Last Received NetFlow" status does not display any data (status remains "Never")
  • BIG-IP VE
  • CLI
  • GUI

 

Cause

The global default sFlow configuration does not automatically apply a polling interval and sampling rate for interfaces and VLANs. Without these parameters explicitly set, NMS cannot receive the necessary data to update the interface status.

 

 

Recommended Actions

Configure specific polling intervals and sampling rates for interfaces:

  1. In the BIG-IP GUI, navigate to:  System > sFlow > Data Sources Settings
  2. Under the Name column, select a type of data source (e.g., Interface or VLAN).
  3. Set the following parameters:
    • Polling Interval: Specify the maximum interval (in seconds) between polling by the sFlow agent.
    • Sampling Rate: Define the ratio of packets observed to samples generated (e.g., a value of 2000 means one sample is generated for every 2000 packets).
  4. Click Update to save changes.
  5. Repeat this process for other types of data sources as needed.
