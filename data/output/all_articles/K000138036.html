Topic

This article describes the procedure you can use to configure SSH access to the AOM subsystem on your F5 rSeries system.

Description

Beginning in F5OS-A 1.7.0, you can configure SSH access to the AOM subsystem of your F5 rSeries system to control the system. To do so, you need to configure the following:

Note: DO NOT configure AOM and Management with the same IP Address, as access to the Management GUI/SSH will be disrupted. For more information, refer to the article in the Related Content section at the end of this article.

  • AOM network IPv4/IPv6 configuration
  • AOM user configuration
  • SSH configuration

Prerequisites

  • You require admin access to the F5OS CLI to perform the following procedures. If you are logged in as root on bash to your rSeries, enter su - admin to switch to the F5OS CLI as admin.

Procedures

  • AOM network IPv4/IPv6 configuration
  • AOM user configuration
  • SSH configuration

AOM network IPv4/IPv6 configuration 

The F5OS system supports IPv4/IPv6 addresses, DHCP, gateway address network configuration to enable you access. Perform the following procedure to configure your AOM network:

  1. Login to the F5OS CLI as admin.
  2. To view the current AOM configuration, enter the following command:
    show system aom
  3. Enter the following command to enter configuration mode:
    config
  4. Enter the following commands as appropriate to configure your IPv4/IPv6 network configuration:
    ConfigureCommand syntaxExample
    IPv4
    IPv4 addresssystem aom config ipv4 address <IPv4>system aom config ipv4 address 192.168.3.10
    IPv4 prefix lengthsystem aom config ipv4 prefix-length <prefix>system aom config ipv4 prefix-length 24
    IPv4 gatewaysystem aom config ipv4 gateway <gateway>system aom config ipv4 gateway 192.168.3.254
    IPv4 dhcpsystem aom config ipv4 dhcp-enabled <true|false>system aom config ipv4 dhcp-enabled false
    IPv6
    IPv6 addresssystem aom config ipv6 address <IPv6>system aom config ipv6 address 2001:db8:3333:4444:5555:6666:7777:8888
    IPv6 prefix lengthsystem aom config ipv6 prefix-length <prefix>system aom config ipv6 prefix-length 64
    IPv6 gatewaysystem aom config ipv6 gateway <gateway>system aom config ipv6 gateway 2001:db8:3333:4444:cccc:dddd:eeee:ffff
  5. Enter commit to commit the changes.
  6. Enter exit.
  7. Enter the following command to display your configuration
    show system aom

AOM user configuration

To login to AOM SSH, you create a new AOM user. To do so, perform the following procedure:

  1. Login to the F5OS CLI as admin.
  2. Enter the following command to enter configuration mode:
    config
  3. To create a new user, enter the following command:
    system aom set-ssh-user-info
  4. Enter the username and password. For example, you may observe an output similar to the following:
    Value for 'username' (<string>): admin
    Value for 'password' (<string>): ********
    response AOM SSH username and password set successfully.

SSH configuration

Configure the SSH session settings using the following procedure:

  1. Login to the F5OS CLI as admin.
  2. Enter the following command to enter configuration mode:
    config
  3. Configure the SSH timeout value using the following command syntax
    system aom config ssh-session-idle-timeout <value>

    For example, enter the following command:
    system aom config ssh-session-idle-timeout 180

  4. Configure the SSH session banner using the following command syntax:
    system aom config ssh-session-banner <banner_message>

    For example,
    system aom config ssh-session-banner "Restricted system"

  5. Enter commit to commit the changes.
  6. Enter exit.
  7. Enter the following command to display your configuration
    show system aom

    You may observe an output similar to the following:
    system aom state ssh-session-idle-timeout 180
    system aom state ssh-session-banner "Restricted system

    Note:When the host system is powered off, the AOM management port will only respond to 100Mb/s connections. 

 

Additional Information

When you no longer require SSH access to AOM, perform one of the following procedures:

  • Disable IPv4/IPv6 network configuration
  • Clear the SSH and AOM configuration data. 

Disable IPv4/IPv6 network configuration

  1. Login to the F5OS CLI as admin.
  2. Enter the following command to enter configuration mode:
    config
  3. To disable IPv4 network, enter the following commands:
    system aom config ipv4 dhcp-enabled false
    system aom config ipv4 address 0.0.0.0

    To disable IPv6 network, enter the following commands:
    system aom config ipv6 address ::
    system aom config ipv6 prefix-length 128

  4. Enter commit to commit the changes.
  5. Enter exit.

Clear the SSH and AOM configuration data.

  1. Login to the F5OS CLI as admin.
  2. Enter the following command to enter configuration mode:
    config
  3. Enter the following command to clear all SSH and AOM configuration data.
    system aom clear-data
    You may observe an output similar to the following: 
    Do you really want to clear all customer data from the AOM? This includes SSH and network configuration data. [no,yes] yes
  4. Enter yes.
  5. Enter exit.

All IPv4/IPv6, AOM users and SSH configurations are cleared.
