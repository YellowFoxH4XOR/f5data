Known Issue

A DEBUG level HTTP parsing message is incorrectly written to the bd.log file.

The message listed in the Symptoms section is logged when the bd parser encounters a file type that it does not immediately recognize. This is a DEBUG level message and should be suppressed under normal ERROR level logging.

Impact

None. You can safely ignore this message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The following log message may be written to the /var/log/ts/bd.log file:

    http_request.c:0416|logical error - file_name is null
