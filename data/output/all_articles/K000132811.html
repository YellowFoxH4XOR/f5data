K000132811: Bot Defense microservice URL defined with query string will never be matched

Type
Support Solution
Published
2023-03-02
Updated
2026-08-03
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000132811

Description

GUI allows the configuration of microservice URL defined with query string in Bot Defense Profile and such URL will never be matched.

For example:

Microservice URL - /abc?p=*

The above microservice URL will never be matched as microservice URL only supports configuration of path, excluding the query string.

Environment

  • BIG-IP ASM / Advanced WAF
  • Bot Defense Profile attached to the Virtual Server
  • Microservice URL with query string defined in Bot Defense Profile under Microservice Protection.

Cause

Functioning as Designed

Recommended Actions

Define microservice URL containing only path, excluding the query string. Using the earlier example, configure microservice URL as /abc without the query string.

Additional Information

None
