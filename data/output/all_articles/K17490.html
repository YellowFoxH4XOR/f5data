Known Issue

Temporary files stored in the /var/avr/loader directory may not be deleted.

This issue occurs when any of the following conditions are met:

  • The avrd process is manually restarted while the process is editing temporary files.
  • The avrd process is restarted by the system, during some abnormal crash event.

Impact

The /var/avr/loader directory can become filled with files, causing disk space exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If the avrd process is restarted, your BIG-IP system produces an avrd core file in the /shared/core directory.
  • If the file system becomes full, your BIG-IP system produces a Traffic Management Microkernel (TMM) core file in the /shared/core directory.
  • If the TMM process creates a core file, failover occurs for systems in a high availability (HA) configuration.

Workaround

To work around this issue, you can stop the avrd and monpd processes and manually remove the temporary files in the /var/avr/loader directory. To do so, perform the following procedure:

Impact of workaround: While the avrd process is stopped, the Analytics module does not collect, aggregate, and publish application performance data. While the monpd process is stopped, no reporting charts are displayed.

  1. Log in to the BIG-IP command line.
  2. To stop the avrd and monpd processes, type the following command:

    tmsh stop /sys service avrd monpd

  3. To confirm that both services have stopped, type the following command:

    tmsh show /sys service avrd monpd

    The output appears similar to the following example:

    avrd down 9 seconds, normally up
    monpd down 10 seconds, normally up

  4. To delete the temporary files in the /var/avr/loader directory, type the following command:

    rm -rf /var/avr/loader/*

    Important: Ensure that you type the "/*" at the end of the line, so that the files in the folder are deleted, not the folder itself.

  5. To start the avrd and monpd processes, type the following command:

    tmsh start /sys service avrd monpd

  6. Confirm that both services have started, by repeating the command in step #3. The output should appear similar to the following example:

    avrd run (pid 7635) 9 seconds, 3 starts
    monpd run (pid 7637) 9 seconds, 2 starts
