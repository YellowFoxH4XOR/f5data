K000133036: restjavad-audit log shows Unknown source for bash resource

Type
Knowledge
Published
2023-03-16
Updated
2023-03-17
Source
https://my.f5.com/manage/s/article/K000133036

Description

  • The /var/log/restjavad-audit* logs may indicate an "Unknown" source posting to the http://localhost:8100/mgmt/tm/util/bash URI and receiving a 200 status in response.

Environment

  • Telemetry streaming enabled

Cause

Some entries in /var/log/restjavad-audit.0.log may indicate an "Unknown" source

[I][405][15 Mar 2023 18:35:24 UTC][ForwarderPassThroughWorker] {"user":"local/admin","method":"POST","uri":"http://localhost:8100/mgmt/tm/util/bash","status":200,"from":"Unknown"}


The log entries are from the Telemetry Streaming engine querying the bash utility URI internally in order to build the response to the requesting Pull Consumer

The restvavad-audit0.log entry will correlate with an entry in /var/log/restnoded.log that shows the Pull request and polling cycle

Wed, 15 Mar 2023 18:34:24 GMT - finest: socket 418 opened
Wed, 15 Mar 2023 18:34:24 GMT - info: [telemetry] Request received: GET /shared/telemetry/pullconsumer/My_Pull_Consumer
Wed, 15 Mar 2023 18:34:24 GMT - finest: [telemetry] 'PullConsumerEndpointHandler' request handler assigned to request: GET /shared/telemetry/pullconsumer/My_Pull_Consumer
Wed, 15 Mar 2023 18:34:24 GMT - finest: [telemetry] System poller cycle started
Wed, 15 Mar 2023 18:34:24 GMT - finest: [telemetry.f5telemetry_default::My_System::My_Poller] Starting stats collection
Wed, 15 Mar 2023 18:34:24 GMT - finest: [telemetry.f5telemetry_default::My_System::My_Poller] EndpointLoader.getData: loading data from URI = /mgmt/shared/identified-devices/config/device-info
Wed, 15 Mar 2023 18:35:24 GMT - finest: socket 418 closed

 Recommended Actions

  • The log entries are informational for troubleshooting Telemetry Streaming.
