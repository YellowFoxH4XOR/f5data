Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator may experience degraded performance or system instability as a result of a large BIG-IP WebAccelerator disk cache. 

F5 Product Development tracked this issue as CR101465 and CR102135 and it was resolved in BIG-IP WebAccelerator version 9.4.8 and version 10.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Important: This issue was resolved in BIG-IP WebAccelerator version 9.4.8 and version 10.0.0 with the introduction of the hdsPruneMaxDiskCache setting for the hds_prune process. For information about the BIG-IP WebAccelerator hds_prune process, refer to K9079: Overview of the WebAccelerator hds_prune process.

Workaround

Prior to BIG-IP WebAccelerator version 9.4.8 and version 10.0.0, if the size of the file system used for the BIG-IP WebAccelerator disk cache exceeds 5.7 GB, the default hdsPruneStartLevel and hdsPruneStopLevel settings should be modified to compensate for the additional file system capacity.

Note: For information about modifying the hdsPruneStartLevel and hdsPruneStopLevel settings, refer to the Modifying the hdsPruneStartLevel and hdsPruneStopLevel settings section of K9079: Overview of the WebAccelerator hds_prune process.
