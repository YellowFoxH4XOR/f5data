Description
In the Configuration Utility (GUI), the option to enable Web Application Firewall (WAF) is greyed out. Hence not able to activate WAF.

Environment

  • WAF
  • ASM
  • License

Cause
The ASM/ WAF license is not provisioned. 

Recommended Actions

Ensure that you have ASM/WAF license provisioned. You may do so by going to Product Information Request.
Contact F5 Sales to purchase the license if required. 

Additional Information

None.
