Known Issue

This is the result of a known issue. The BIG-IP ASM Charts Scheduler ignores the customer filter setting that allows the administrator to specify what web applications graphs they want to include in the report. As a result, the Charts Scheduler emails a PDF file that includes graphs for all web applications.

For more information regarding the BIG-IP ASM system reporting feature, refer to the Displaying Reports chapter of the Configuration Guide for BIG-IP Application Security Manager.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

F5 Product Development tracked this issue as ID 339193 and it was fixed in BIG-IP ASM 10.2.2. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
