K000137197: How to apply a HOT-FIX to BIG-IQ 8.x

Type
Support Solution
Published
2023-10-10
Updated
2023-10-11
Source
https://my.f5.com/manage/s/article/K000137197

Description

You are running BIG-IQ 8.x and want to install the latest HOT-FIX.

Environment

  • BIG-IQ 8.x
  • HOT-FIX install

Cause

From time to time you may need to install a HOT-FIX to enhance a feature set or add fixes to a known issue.

 Recommended Actions

Log into the BIG-IQ web interface (GUI) and review license / service date. If the service date is outside of the last 30 days, reactivate the license (renew service date). Download the HOT-FIX from the My F5 portal. On BIG-IQ upload the HOT-FIX image. Check to ensure you also have the BIG-IQ base image uploaded, if not this will be needed.
Important: If you used an OVA or cloud image to install your BIG-IQ, you will need to upload a copy of BIG-IQ ISO to your BIG-IQ
  1. Navigate to System, Licensing, review service check date, if needed reactivate the license to get a new service check date (current date)
  2. Navigate to System, Software Management, Images
  3. Click on "upload Image" on the next screen click on "Choose file" choose the iso image you want to upload and click "Open" on the file browser, next click on "Upload"
  4. Navigate System, Software management, Images, check you have both the base BIG-IQ iso and the new HOT-FIX iso
  5. Navigate to System, Software Management, Installations, Click on "Upgrade" button
  6. Review and select HOT-FIX file name (Software image)
  7. Target Volume, "New volume" if it does not exist use HD1.2 (create a new volume name)
  8. Leave UCS backup selected (blue tick)
  9. In the bottom right side of the browser click on "Install"
  10. Confirm install click on "Continue"
  11. After sometime, the BIG-IQ will reboot, this can take a while but IP addresses and database configuration is fully restored.
  12. once rebooted, log back into BIG-IQ GUI, review System, General Properties and note "Software edition" and "Build installed" match that of your HOT-FIX
