Note: For information about the hds_prune process, refer to K9097: Overview of the BIG-IP WebAccelerator hds_prune process.

To get basic information from the hds_prune process, you can to enable hds_prune debug logging.

Important: F5 Networks does not recommend enabling debug logging on production units. The high volume of debug logging may negatively impact the WebAccelerator system's ability to process traffic. If administrators are considering enabling debug logging so they can see the activity of the hds_prune utility, they should instead upgrade to version 10.2.0 or 10.1.0 HF1.

To enable hds_prune debug logging, perform one of the following two procedures:

BIG-IP WebAccelerator versions 9.4.5 and later

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Create the /service/hds_prune/debug file by typing the following command:

    touch /service/hds_prune/debug
  3. Change directories to the /usr/bin directory by typing the following command:

    cd /usr/bin
  4. Backup the original hds_prune file by typing the following command:

    cp hds_prune hds_prune.sol11140
  5. Use a text editor to edit the hds_prune file.
  6. Locate the following line:

    use constant DEBUG => 0;   # 1 means print debug, 0 means don't print debug
  7. Change the lines to appear as follows:

    use constant DEBUG => 1;   # 1 means print debug, 0 means don't print debug
  8. Save the changes and exit the hds_prune file.
  9. Restart the hds_prune process by typing the following command:

    bigstart restart hds_prune
  10. When the hds_prune process starts, a message similar to the following is displayed:

    Starting hds_prune in debug mode

Debug information will now be logged to the /var/tmp/hds_prune.out file.

BIG-IP WebAccelerator versions 9.4.4 and earlier

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Create the /service/hds_prune/debug file by typing the following command:

    touch /service/hds_prune/debug
  3. Restart the hds_prune process by typing the following command:

    bigstart restart hds_prune
  4. When the hds_prune process starts, a message similar to the following displays:

    Starting hds_prune in debug mode

Debug information will now be logged to the /var/tmp/hds_prune.out file.
