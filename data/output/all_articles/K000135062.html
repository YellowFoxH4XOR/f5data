Description

AS3: 207 Multi-Status Response (200 Success / 422 declaration failed) when creating a SnatPool under /Common/Shared

 

{
"code": 200,
"message": "success",
"lineCount": 27,
"host": "localhost",
"tenant": "Common",
"runTime": 3812
},
{
"code": 422,
"message": "declaration failed",
"response": "01020066:3: The requested SNAT Translation (/Common/1.1.1.0) already exists in partition Common.",
"host": "localhost",
"tenant": "Common",
"runTime": 5524
}

 

The SnatPool and the associated Snat translation addresses are successful created.

Environment

BigIP LTM

AS3

 

Cause

The AS3 declaration is being processed twice. This occurs when the SnatPool is being created under /Common/Shared.

This issue does not occur when a non-Shared Tenant is being used.

Recommended Actions

This issue is fixed in AS3 v3.46.0
