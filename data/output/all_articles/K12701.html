Known Issue

This is the result of a known issue. When URL normalization is globally disabled and the origin web server (OWS) responds with an Accept-Ranges: none header, the BIG-IP WebAccelerator removes the Accept-Ranges header before responding to the client. As a result, some browsers may not be able to load documents, such as a linearized PDF document.

F5 Product Development tracked this issue as ID 351455 and it was fixed in BIG-IP WebAccelerator version 10.2.2. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-496.0-HF2, which has been issued for BIG-IP WebAccelerator version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can work around this issue with an iRule that bypasses the BIG-IP WebAccelerator when the OWS responds with an Accept-Ranges: none header. To do so, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > iRules > iRules List.
  3. Click Create.
  4. In the Name box for the iRule, type a name for the iRule.
  5. In the Definition box for the iRule, use the following iRule syntax:

    when HTTP_RESPONSE {
        if { [HTTP::header "Accept-Ranges"] equals "none"} {
             WAM::disable
             CACHE::disable
             HTTP::close
        }
    }
  6. To save the iRule, click Finished.
  7. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  8. Under the Resources column next to the BIG-IP WebAccelerator-enabled virtual server which you would like to associate the iRule, click Edit.
  9. Click Manage for the iRule section.
  10. Highlight the iRule created in Steps 4 through 6.
  11. Click <<.
  12. To associate the iRule to the BIG-IP WebAccelerator-enabled virtual server, click Finished.
