Description

Some Wide IPs on BIG-IP DNS (GTM) remain in an offline state. The following error messages are observed in the logs:

011ae044:3: Could not find monitor object <IP>:port on server:vs <VS-name>

Environment

  • Product: BIG-IP DNS (GTM)
  • Configuration:
    • GTM servers and virtual servers defined for Wide IP pools
    • Monitors assigned to pool members (e.g., HTTPS)
    • iQuery connections between GTM units

Cause

GTM server and virtual server object names are mismatched between GTM units, causing iQuery monitor requests to fail due to name discrepancies.

Recommended Actions

Ensure Consistent Naming Across GTMs
All GTM server and virtual server object names must be identical across all GTM units for monitored Wide IPs.
If names differ (e.g., gtm_serever_test vs gtm.server.test) for same ip:port, delete and recreate the objects with matching names.
