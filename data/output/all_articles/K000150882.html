Description

I want to know if F5® Distributed Cloud provides HTTPS RFC compliance checks.

 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Cloud Load Balancer

Cause

 

Answer/Recommended Actions

We have RFC compliance check on XC, like content-legth header, but not fully RFC compliant. XC will do some RFC compliance checks automatically and will handle some of them, it can't be configured on the XC portal.
