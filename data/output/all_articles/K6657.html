K6657: The big3d process may use all available CPU resources when attempting to process certain monitor requests

Known Issue

This is the result of a known issue. The big3d XML parser cannot parse monitor requests that contain the & (ampersand) symbol. If the monitor uses an HTTP GET request that contains the & symbol, the big3d process will reset its connection to the gtmd process and the BIG-IP GTM system will drop the monitor request. This may result in the big3d process using all available CPU resources.

The following is an example of a monitor string containing the & symbol:

GET /adsvr/mko?rsi_pub=nav&rsi_ok

F5 Product Development tracked this issue as CR69128 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM release notes.
