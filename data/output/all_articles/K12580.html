Known Issue

This is the result of a known issue. Microsoft Outlook Web App (OWA) may intermittently display an incorrect number of unread messages for users accessing OWA through Portal Access. As the user reads their email, the unread message count may not decrease accordingly. However, if a user sets a read message to unread, the unread message count increases correctly.

F5 Product Development is tracking this issue as ID 344967.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
