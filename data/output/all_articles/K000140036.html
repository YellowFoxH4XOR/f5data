Description

While adding new instance on rSeries as infrastructure via WebUI BIG-IP Next CM, it might failed to create it and the following message will appear:

Alert: "Instance Creation Alert" 

Finally next instance on WebUI was not added but on rSeries Next instance was running.

 

Environment

BIG-IP Next 20.2.0

rSeries r10900 or r5900

Cause

Lack of enough resources on rSeries for BIG-IP-Next instance installed from the BIG-IP-Next CM.

Too many installed classic BIP-IP on rSeries on which BIG-IP Next instance was attempted to add.

Recommended Actions

Reinstall from the scratch BIG-IP Next from CM WebUI on clean rSeries without old classic BIG-IP.

Follow the system documentation:

How to: Install BIG-IP Next on rSeries

Summary of procedure:

  1. Make sure that rSeries is on 1.7.x software version

  1. Upload on rSeries proper software version for BIG-IP Next

  

  1. Add rSeries as a "Providers" from CM WebUI.

Note: in next step put credential for rSeries

  1. Follow the system documentation:

    Deploy a BIG-IP Next instance on an rSeries system using BIG-IP Next Central Manager
