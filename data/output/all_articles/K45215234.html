Known Issue

Under rare conditions, a virtual server using the URL categorization feature may cause the Traffic Management Microkernel (TMM) to produce a core file.

This issue occurs when the following conditions are met:

  • The URL categorization feature is licensed on the system.
  • The virtual server processes certain URL categorization input.
The URL categorization feature provides the ability to enforce policies configured as part of the subscriber profile based on the URL category type; the URL categorization is obtained by querying an internal repository.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from TMM restarting, and systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to the standby system if configured for HA.
  • The BIG-IP system generates TMM core files to the /var/core directory
