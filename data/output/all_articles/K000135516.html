K000135516: Error: SAML assertion is invalid, error: Authentication Context in Assertion does not match local configuration

Type
Support Solution
Published
2023-12-12
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.3
Source
https://my.f5.com/manage/s/article/K000135516

Description

SAML Authentication fails. You see a similar error message on /var/log/apm -- <Timestamp> <hostname> err apmd[14101]: 0149020a:3: /<Partition>/<Access_Policy_name>/:<Partition>:<Session_ID>: SAML Agent: /<Partition>/<Access_Policy_name>_act_saml_auth_ag SAML assertion is invalid, error: Authentication Context in Assertion does not match local configuration


Environment

  • BIG-IP
  • F5 as SP
  • SAML Authentication

Cause

The SAML authentication context configuration in the BIG-IP does not match the configuration in the IDP


Sample BIG-IP configuration:


apm aaa saml /Common/example.com {

  auth-context-methods { urn:oasis:names:tc:SAML:2.0:ac:classes:Password }

  entity-id https://example.com/sp

  force-authn true

  idp-connectors {

    /Common/example.com { }

  }

  is-authn-request-signed true

  name-id-policy-format urn:oasis:names:tc:SAML:1.1:nameid-format:unspecified

  sp-certificate /Common/example.crt

  sp-host example.com

  sp-signkey /Common/example.key

}



Sample IDP SAML Response:


<saml:AuthnContext><saml:AuthnContextClassRef>urn:oasis:names:tc:SAML:2.0:ac:classes:PasswordProtectedTransport</saml:AuthnContextClassRef></saml:AuthnContext>



Recommended Actions

Make sure the AuthnContext configuration on the BIG-IP and the IDP match. In the configuration above, the BIG-IP uses "Password", however the IDP uses "PasswordProtectedTransport". Depending on the requirements of your environment, make the necessary changes to make sure the BIG-IP and IDP both use the same authentication context.
