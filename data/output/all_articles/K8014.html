Issue

This error message occurs when the User-Agent string associated with an active user session changes during the user’s session. When a user logs on to the FirePass webtop, the FirePass controller records the User-Agent string reported by the user’s browser. If the reported User-Agent string changes during the user’s session, the FirePass controller detects that change as an attempt by a potential attacker to spoof the user’s session. As a result, FirePass terminates the session and logs a message similar to the following example on the Reports: System Logs page:

[jsmith@Default] Possible intrusion attempt detected against account from source IP address 192.168.0.131 for URI=[/vdesk/?S=473aa644589ee4b85b91666c158f35a7&sid=473aa644589ee4b85b91666c158f35a7&
langchar=en.iso-8859-1&ui_translation=off&gbrowsertype=](USER-AGENT changed. [Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1; SV1; YPC 3.2.0; .NET CLR 1.1.4322; yplus 5.1.04b) -> Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1; SV1; YPC 3.2.0; .NET CLR 1.1.4322)]. )

User-Agent is an HTTP header field sent by the user’s browser, which contains a text string that identifies the browser. A few examples of common User-Agent strings are as follows:

Mozilla/5.0 (Windows; U; Windows NT 5.1; en-US; rv:1.8.0.12) Gecko/20070508 Firefox/1.5.0.12
Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1; SV1; .NET CLR 1.1.4322; .NET CLR 2.0.50727; InfoPath.1)
Mozilla/5.0 (Macintosh; U; PPC Mac OS X; en) AppleWebKit/412.6.2 (KHTML, like Gecko) Safari/412.2.2 (United States)

User-Agent verification is a security feature that reduces the likelihood of session spoofing. Occasionally, this security feature is triggered when a browser changes its User-Agent string during a user’s session. This is not expected browser behavior, and is typically caused by a browser toolbar such as Yahoo! Toolbar or a customized browser supplied by your ISP. You can work around this issue by uninstalling the software that changes the browser's User-Agent string, or by using a non-customized browser when accessing the FirePass webtop.

Additionally, this security feature is frequently triggered when users run Internet Explorer 8 in Compatibility View. For more information, refer to K10189: Users may be logged out of FirePass when running Internet Explorer 8 with Compatibility View enabled.
