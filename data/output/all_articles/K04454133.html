Description
After adding destination IP addresses to be bypassed to a datagroup used by the Destination IP Bypass setting on the Client SSL profile, the new addresses are not bypassed.

This occurs with any configured Bypass or Intercept setting.

Environment

  • BIG-IP
  • SSL Forward Proxy
  • SSL Forward Proxy Bypass configured
  • Data group used for SSL Forward Proxy Bypass updated

Cause
Bug ID 434356

Recommended Actions

Do one of the following:
  • Each time the data-group is updated, remove the data-group from the Client SSL profile, then apply it again.
  • For destination IP-based bypass, configure an LTM Policy instead of using the SSL Forward Proxy Bypass feature. You can create Rules which Enable or Disable SSL Intercept.
