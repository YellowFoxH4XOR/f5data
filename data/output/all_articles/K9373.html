You can customize the appearance of the FirePass logon page and webtop on the Device Management: Customization page. Global settings are configured under the Global Customization tab, virtual host settings are configured under the Virtual Host-based Customization tab, and landing URI settings are configured under the URI-based Customization tab.

FirePass uses two default logo images on the logon page and two default logo images on the webtop. If you want to replace the default images with a customized image or banner, perform the following procedure:
 
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Customization page.
  3. If you want to replace a global image, proceed to Step 4.

    If you want to replace an image for a virtual host, click the Virtual Host-based Customization tab and select the virtual host from the Select virtual host menu. Select the Enable host-based customization check box if it is not already selected, then proceed to Step 4.

    If you want to replace an image for a landing URI, click the URI-based Customization tab and click the edit link next to the landing URI you want to customize. Select the Enable host-based customization check box if it is not already selected, then proceed to Step 4.

    Important: The settings configured under the Virtual Host-based Customization and URI-based Customization tabs override the settings configured under the Global Customization tab.
     
  4. In the Custom Images section, locate the image that you want to replace.

    Note: The Front Door logo image and Front Door banner image appear at the top of the FirePass logon page. The FirePass Webtop logo image and FirePass Webtop banner image appear at the top of the FirePass webtop.
     
  5. In the text field below the image, enter the full path to the image you’d like to upload or click the Browse button to browse for the image on your workstation.
  6. Click the Update button to replace the current image with the image you specified in Step 5.

The new image now appears on the FirePass logon page or webtop, depending on which image you replaced.
 
Note: Users may need to clear their browser cache before the new image is displayed.
 
You can additionally customize other aspects of the FirePass logon page and webtop, such as the text and background colors, on the Device Management: Customization page. Advanced customization is also available through WebDAV.

Note: For more information about FirePass customization, refer to the FirePass Controller Administrator Guide.
