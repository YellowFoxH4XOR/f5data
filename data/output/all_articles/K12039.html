Known Issue

This is the result of a known issue. When you access the FirePass controller using a multibyte character set, such as Japanese or Chinese, the log entries are stored internally to FirePass without any translation. This will cause a FirePass device that is using a multibyte language to write information to the log files with a mix of character sets. Exporting the log to an external source, such as Microsoft Excel or a syslog server, will show log information with some data correctly interpreted with other data will be in the hexadecimal value of the character encoding depending on the character set used by the viewing program.

For example:

logon=&#x3084;&#x3059

F5 Networks Product Development is tracking this issue as ID 337728.
