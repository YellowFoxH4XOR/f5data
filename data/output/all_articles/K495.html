Topic

You can use the config command to configure 3-DNS to work in one of the following modes:

  • Node
  • Bridge
  • Router

Note: For more specific instructions about configuring the 3-DNS mode, refer to the 3-DNS Administration Guide.

The dnsmode global setting contains the current operating mode for 3-DNS.

To display the current mode, type the following command:

bigpipe global dnsmode
