K000090011: Adding gateway to node failed

Type
Support Solution
Published
2021-07-27
Updated
2022-08-18
Source
https://my.f5.com/manage/s/article/K000090011

Description

  • You deploy a new instances of Nginx Controller and NginxPlus
  • You created a gateway and attempt to assign it to the Node, but fails with the below error


Error: Failed to deploy to instance (node1), Config failed nginx -t Failed testing config before applying: nginx: [emerg] dlopen() "/etc/nginx/modules/ngx_http_f5_metrics_module.so" failed (/etc/nginx/modules/ngx_http_f5_metrics_module.so: cannot open shared object file: No such file or directory) in /etc/nginx/nginx.conf:6 nginx: configuration file /etc/nginx/nginx.conf test failed



 Environment

  • Gateway
  • Nginx Controller
  • Nginx Plus

 Cause

  • None-compatibility of installed Nginx controller with that of installed Nginx-plus version

 Recommended Actions

  • Verify and confirm compatibility of controller with that of installed nginx-plus version following https://docs.nginx.com/nginx-controller/admin-guides/install/nginx-controller-tech-specs/
    • For example, nginx plus instance running 1.19.10 r24 won't be supported by nginx controller 3.16.1; however this same instance would work with 3.17.

 Additional Information

  • The actual error output indicates nginx.conf is unable to load due to "ngx_http_f5_metrics_module.so" module NOT existing on /etc/nginx/modules/.
  • It also indicates, the NONE compatibility of nginx-controller with that of nginx-plus.
