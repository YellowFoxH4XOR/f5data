Known Issue

May 2017 attack signature updates may fail.

This issue occurs when the following condition is met:

  • You attempt to install the attack signature updates on a BIG-IP ASM 11.5.4 HF2 or later hotfix.

Impact

Users are unable to install May 2017 attack signature updates.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to load the attack signature update, the system displays an error message similar to the following example:

    Failed on insert to PLC.NEGSIG_SYSTEMS (DBD::mysql::db do failed: Duplicate entry '37' for key 'PRIMARY')

Resolution

Status

F5 Product Development has assigned ID 668694 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.6.0K2200: Most recent versions of F5 software
HotfixNoneNone

Workaround

There is no work around to this issue. However, you can alternatively install the June 2017 attack signature updates.
