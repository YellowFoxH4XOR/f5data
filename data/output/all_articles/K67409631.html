Known Issue

Protected Workspace may fail to launch.

This issue occurs when all of the following conditions are met:

  • Your access profile access policy is configured with the Protected Workspace agent.
  • You attempt to establish an access session using Internet Explorer 10 or 11.
  • Any of the Internet Explorer default Compatibility View settings have been modified.

Impact

Protected Workspace fails to launch.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Protected Workspace stops launching when the Entering Protected Workspace message appears.

Resolution

Workaround

To work around this issue, you can set Internet Explorer to use the default Compatibility View settings. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Locate the Tools menu in the Internet Explorer 11 browser.
  2. From the Tools menu, select Compatibility View settings.
  3. Ensure that all of the following Compatibility View settings are enabled.

    Display intranet sites in Compatibility View

    Use Microsoft compatibility lists

    Display all websites in Compatibility View

    Note: The previously listed settings are available only on Internet Explorer 10.

  4. Click Close.
