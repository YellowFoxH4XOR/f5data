Topic

HTML syntax errors are very common in Web pages. HTML errors may be undetectable from some browsers or cause only a minor disruption in the page appearance or function; however, HTML errors can cause serious issues in less-tolerant browsers and can interfere with the FirePass content engine and content processing functions.

You can use one of the following three options to resolve HTML errors in pages accessed through FirePass:

  • Correct HTML errors in the source code

  • Use the FirePass Content Cleaning feature

  • Create a content processing script to correct specific errors

Correct HTML errors in the source code

View the HTML code immediately preceding the point where the issue occurred and fix any HTML coding errors that you encounter. The most common HTML errors consist of the following issues:

  • Missing quotes

  • Doubled (duplicate) quotes

  • Unclosed HTML tags

Use the FirePass Content Cleaning feature

You can use the FirePass Content Cleaning feature to clean errors in the source code. The Content Cleaning feature runs an open-source utility, HTML Tidy, on the pages that you specify. This utility corrects many common HTML errors.

Note: For more information about HTML Tidy, refer to the following web site: http://www.w3.org/People/Raggett/tidy/.

To enable the Content Cleaning feature on FirePass, perform the following procedure:

  1. Log in to the FirePass Administrative Console.

  2. From the navigation pane, click Portal Access.

  3. In the upper navigation pane, click Web Applications.

  4. From the menu, click Content Processing.

  5. Locate the Web Applications Content Cleaning section of the page.

  6. In the Enter a comma-separated list of patterns... field, enter the complete URL of each page on which you want to use Content Cleaning.

  7. Click the Update button.

FirePass will now correct many common HTML errors in the page(s) that you specified.

Create a content processing script to correct specific errors

You can create and apply a content processing sed script to fix the specific HTML code error dynamically.

Note: For additional information about sed scripts including uses and syntax, refer to the following web site: http://info2html.sourceforge.net/cgi-bin/info2html-demo/info2html?(sed)Introduction

To apply a sed script, perform the following procedure:

  1. Log in to the FirePass Administrative Console.

  2. Click Portal Access.

  3. Click Content Processing.

  4. Under the Web Applications Content Processing Scripts section, click the Add New Favorite link.

  5. Fill in the following fields as specified:

    • Processing script name
      The name of the script you are creating

    • URL match patterns
      The URL on which you want to run the script

    • Content type
      Additional content type to match (MIME settings)

    • sed processing script
      The sed script for processing

  6. From the Processing drop-down menu, select when you want the script to start.

  7. Click the Add New button.
