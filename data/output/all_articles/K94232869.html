Description

Users are not able to establish the APM VPN connection.

  • The following error message, in the APM logs:
    err tmm[19219]: 0149059c:3: /Common/AccessPolicy:Common:12345678: Dynamic IPv4 Addr collision: Old: tmm.uuid./Common/AccessPolicy.2895a d52b525289a80d31e033eb320a761b8f New: tmm.uuid./Common/AccessPolicy.8278 eb0081acef222f0b0134084b23ac9cdc

Environment

  • BIG-IP APM
  • Multiple Network Access objects
  • Multiple LeasePool objects
Cause

The IP ranges from the LeasePool objects, overlap each other.
Example:

apm resource leasepool LeasePool1 {
members {
10.20.30.0-10.20.30.128 { }
}
}

apm resource leasepool LeasePool2 {
members {
10.20.30.0-10.20.30.254 { }
}
}

The range 10.20.30.0 -> 10.20.30.128 is shared between both LeasePool objects (overlapping)

Recommended Actions

Re-define the configuration of all the LeasePool objects, in order to prevent any overlapping.

Additional Information

Similar error messages could be seen with our previous software version.
This was due to an bug, that is fixed in the currently available software version.
The situation was described in the following article: K16971: BIG-IP APM Network Access connections may intermittently fail to establish
