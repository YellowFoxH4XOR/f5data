Known Issue

This is the result of a known issue. When a user selects the Load into browser link for a Windows Files favorite, and the selected file name ends in .pptx, FirePass changes the .pptx file name extension to .ppsx. As a result, the file does not open and PowerPoint reports an error message in which local_path_to_file is the path to the file on the client system, typically the browser’s temporary internet files directory.

For example:

PowerPoint cannot open the file <local_path_to_file> because the file format or file extension is not valid.

Similarly, if the user right-clicks the Load into browser link and downloads the file, the file is saved with the .ppsx extension. If the user attempts to open the file, PowerPoint reports an error message in which local_path_to_file is the path to the file on the client system.

For example:

PowerPoint can't read <local_path_to_file>

The .pptx file name extension is the default extension for PowerPoint files that use the Microsoft Office Open XML File Format.

Note: For more information about the Office Open XML File Formats, refer to http://msdn.microsoft.com/en-us/library/aa338205.aspx.

Important: For FirePass version 6.0.3, this issue occurs after installing cumulative hotfix HF-603-1 or later versions of the cumulative hotfix. For earlier versions of FirePass software, a different issue occurs when accessing Microsoft Office 2007 documents through Windows File favorites. For more information, refer to K9474: Loading and downloading Microsoft Office 2007 files does not work properly through Windows Files favorites.

F5 Product Development tracked this issue as CR132780 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by selecting the Windows Files Download as Zip option to download the file locally. The .pptx file name extension is correctly preserved when the file is downloaded as part of a zip file.
