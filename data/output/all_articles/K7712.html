Known Issue

This is the result of a known issue. In previous versions, the BIG-IP system used the gettimeofday() function to calculate system timer events. However, using the gettimeofday() function makes the BIG-IP event library susceptible to system time changes.

Beginning with versions 9.2.4, 9.3.0, and 9.4.0, the BIG-IP system uses a monotonically increasing timer to calculate system timer events.

F5 Product Development tracked this issue as CR65285, CR65362, and CR68266, and it was fixed in BIG-IP versions 9.2.4, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller release notes.
