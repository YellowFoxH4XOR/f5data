Description

A BIG-IP software has been successfully installed.

When loading to the new partition (BIG-IP software), it will not boot up or it will be in a boot loop.

No error message will be seen.

When reverting back to the old BIG-IP software (previous partition), no issue will be seen.

Environment

  • BIG-IP upgrade
  • BIG-IP software installation is successful
  • New BIG-IP software (new partition) would not load or in boot loop
  • No error when loading new BIG-IP software (new partition)

Cause

The BIG-IP software installation might have a problem thus you are not able to load to it.

Recommended Actions

Follow the steps below to resolve the issue.

  1. Delete the new partition (not working).
  2. Create a new partition and install the image again.
  3. Boot to the new partition.
Refer to article K84554955 on how to navigate the BIG-IP for the above steps.
