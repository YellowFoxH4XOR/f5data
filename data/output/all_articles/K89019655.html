Description

Is there a way to extract wide-IP names from BIG-IP by means of REST API calls?

Environment

  • DNS module provisioned.
  • REST API in use.

Cause

None

Recommended Actions

Sample REST API calls are listed below where A and AAAA wide-IPs are being queried.

curl -sku admin:admin -X GET https://192.0.2.1/mgmt/tm/gtm/wideip/a | jq . | grep name
curl -sku admin:admin -X GET https://192.0.2.1/mgmt/tm/gtm/wideip/aaaa | jq . | grep name

Note: use appropriate credentials instead of "admin/admin" if required
Note: 'jq' must be installed on connecting client in order to get the output in JSON format
