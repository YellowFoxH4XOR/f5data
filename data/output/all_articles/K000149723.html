Description

Does Http LoadBalancer support VDI traffic?

 

Environment

  • Distributed Cloud (SaaS)
  • F5® Distributed Cloud Load Balancer

Cause

Since match across is required for VDI and HTTP Load Balancer doesn't support it, it is not supported.

 

Answer/Recommended Actions

No, the HTTP load balancer doesn't support VDI traffic.
