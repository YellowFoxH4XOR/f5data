Known Issue

This is the result of a known issue. If a user accesses a Microsoft Share Point 2007 server through Portal Access, and the user attempts to check in a document, the user may receive an error message that appears similar to the following example:

This document was checked out to your local drafts folder but the local copy could not be found or is on a different computer. Upload the local changes or discard your checkout to continue editing.

This issue occurs when the user selects the Use my local drafts folder check box in the check out confirmation pop-up window, when checking out the document.

Note: The Use my local drafts folder check box appears if Microsoft Office 2007 is installed on the client system.

F5 Networks Product Development tracked this issue as CR100509 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-6 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by clearing the Use my local drafts folder check box in the check out confirmation pop-up window, when checking out a document.
