Description

  • You are getting the following error message on /var/log/ltm : 
err tmm1[14822]: DNScache: tcp connect: errno 110

Environment

  • BIG-IP LTM
  • GTM/DNS module is not provisioned 
  • Var/log/ltm  shows the following message:  
    DNScache: tcp connect: errno 110

Cause

These errors do not indicate a problem on the Big-IP. They are logged when there is no response to a name query sent by the Big-IP DNS resolver, which indicates either a problem on the authoritative DNS server that was queried, or a problem reaching that authoritative name server. errno=110 messages indicate TCP connection timeouts/failures. It is usually just a sign of Unbound (DNS cache) being unable to reach the resolver.

Recommended Actions

  1. There is no reason to be concerned about these messages. they're fairly benign.

Additional Information

    Bug ID 650038: tcp connect: errno and comm_point_tmm_recv_from messages

    "Unbound" is a validating, recursive, caching DNS resolver, developed by NLnetLabs. The F5 BIG-IP's DNS Caching functionality uses this open source software.
