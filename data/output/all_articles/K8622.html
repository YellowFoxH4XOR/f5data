Known Issue

This is the result of a known issue. When Internet Explorer 6 (IE6) clients access a web page through the WebAccelerator, and the webpage contains a script that creates a file that can be downloaded, the file name may not display correctly in the File Download dialog box. This issue occurs because IE6 does not honor the Content-Disposition header when the content is compressed. Therefore, when the WebAccelerator acceleration policy is configured to perform content compression for the affected object type, the filename is displayed as the script name instead of the name indicated in the Content-Disposition header.

Note: This issues does not affect later versions of Internet Explorer or other popular web browsers.

F5 Product Development is tracking this issue as ID 248798 (formerly CR94124).

Workaround

You can disable content compression for the affected object types when the client is using IE6 by editing the WebAccelerator acceleration policy. To do so, perform the following procedure:

  1. Log in to the BIG-IP Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.
    The Policy List opens.
  4. Select the User-defined Acceleration Policy to edit.
    Note: Pre-defined Acceleration Policies can not be edited. If you are using a Pre-defined Acceleration Policy, you must copy the pre-defined policy, then edit the new User-defined Acceleration Policy.
  5. Find the node ID for the affected objects by matching the A field in the X-PvInfo header of the HTTP request affected by this issue.

    To find the node ID, hover the mouse over the nodes of the policy tree.

    Note: For information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter in the BIG-IP WebAccelerator Policy Management Guide.
  6. Select the node by clicking on the node in the Policy Tree.
  7. Click the Copy button in the menu bar at the top of the Policy Tree.
  8. Type a name in the Name field for the new node.
  9. Click the Copy button.

    The new node will appear in the Policy Tree.
  10. Select the new node in the Policy Tree.

    The Matching Rules for the node are displayed.
  11. Move the new node above the original node in the Policy Tree, by clicking the up arrow button in the menu bar at the top of the Policy Tree.
  12. Select User Agent from the Add Parameter drop-down menu.
  13. Click the Add button.
  14. Select the check box next to the Value matches: drop-down menu.
  15. Click the down arrow next to Enter a regular expression.
  16. Select Internet Explorer 6.0 from the list.
  17. Click the Save button.
  18. Select Acceleration Rules from the Matching Rules drop-down menu.
  19. Select the Assembly menu tab.
  20. Clear the Enable Content Compression check box.
  21. Click the Save button.
  22. Click the Publish button.
  23. Click the Publish Now button.

Note:  If you created a new User-defined Acceleration Policy, associate the new user defined policy with your WebAccelerator application.
