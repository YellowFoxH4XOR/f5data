Known Issue

Due to a regression introduced in ID 428163 the Traffic Management Microkernel (TMM) may create a core file when you change the DNS cache configuration.

This issue occurs when the following condition is met:

  • You delete a DNS cache from the BIG-IP configuration when the system is querying the DNS cache.

Impact

The BIG-IP system temporarily fails to process traffic and fails over if configured as part of a high availability (HA) system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system generates a TMM core file in the /shared/core directory.
  • Your BIG-IP system logs SIGFPE to the /var/log/tmm file.
  • In the /var/log/tmm file, your BIG-IP system logs an entry that appears similar to the following example:

    notice panic: ../kern/page_alloc.c:521: Assertion "vmem_hashlist_remove not found" failed.

  • Your BIG-IP system temporarily fails to process traffic and may fail over to another host in the device group.
