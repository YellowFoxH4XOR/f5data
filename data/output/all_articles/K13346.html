K13346: The BIG-IP WebAccelerator X-PvInfo header is renamed the X-WA-Info header

Issue

Old Behavior

In BIG-IP WebAccelerator 9.x and 10.x, an X-PvInfo: HTTP header is inserted into all processed HTTP traffic. The X-PvInfo header contains information, such as the method of acceleration and caching, and other debugging information useful to system administrators and F5 Technical Support.

New Behavior

Beginning in BIG-IP WebAccelerator 11.0.0 and BIG-IP AAM 11.4.0, the X-PvInfo header is renamed X-WA-Info, and the header is no longer inserted, by default, into processed traffic.

Note: BIG-IP WebAccelerator and BIG-IP WOM were combined to create BIG-IP AAM in 11.4.0.

Impact

The BIG-IP WebAccelerator or BIG-IP AAM system no longer includes diagnostic/debugging header information in the server-side request, by default.

Recommended Actions

When upgrading to BIG-IP 11.x, you should note the header name change. In addition, you must manually insert the X-WA-Info header, if required. To do so, perform one of the following procedures:

Enabling the insertion of the X-WA-info header on BIG-IP WebAccelerator hosts

  1. Log in to the BIG-IP Configuration utility.
  2. Click the Main tab.
  3. Click the WebAccelerator menu.
  4. Click Applications.
  5. Select your existing application or create a new application.
  6. In the General Options menu, select Advanced.
  7. Under Debug Options, change the X-WA-Info Header option from None to Standard.

    Note: Do not select the Debug option unless F5 Technical Support requests that you do so.

  8. Click Save.

    Changes take effect immediately.

Enabling the insertion of the X-WA-info header on BIG-IP AAM hosts

  1. Log in to the BIG-IP Configuration utility.
  2. Click the Main tab.
  3. Click the Acceleration menu.
  4. Click Web Application.
  5. Click Applications.
  6. Select your existing application or create a new application.
  7. In the General Options menu, select Advanced.
  8. Under Debug Options, change the X-WA-Info Header option from None to Standard.

    Note: Do not select the Debug option unless F5 Technical Support requests that you do so.

  9. Click Save.

    Changes take effect immediately.
