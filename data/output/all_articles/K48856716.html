Description

You should consider using this procedure under the following conditions:

  • You want to automate the license process of your BIG-IP system using the REST API (Application programming interface).

Environment

  • BIG-IP
  • Automate License
  • iControl REST API
  • License Activation

Cause

None

Recommended Actions

Use below command to automate the license from a Linux device or a device which can communicate with BIG-IP using curl utility and the BIG-IP should have internet access:

curl -sk -u username:password -H "Content-Type: application/json" -d '{"command": "install", "registrationKey": "<Base Registration key>"}' -X POST https://<BIG-IP address>/mgmt/tm/sys/license | jq .

Example:

curl -sk -u testuser:testpassword -H "Content-Type: application/json" -d '{"command": "install", "registrationKey": "12345-12345-12345-12345-1234567"}' -X POST https://192.168.1.1/mgmt/tm/sys/license | jq .

Output will look similar to the following after running above command:

{
    "kind": "tm:sys:license:installstate",
    "command": "install",
    "registrationKey": "12345-12345-12345-12345-1234567",
    "commandResult": "New license installed\n"
}
