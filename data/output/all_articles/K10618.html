Topic

Sensitive parameters will accept a wildcard character as input, but the character will be interpreted literally. For example, a sensitive parameter of aa* will mask the value of a parameter named aa* but not the value of a parameter named aab.

In the following URI example, a sensitive parameter of aa* masks the value of aa*:

/a.asp?aa*=123

In the following URI example, a sensitive parameter of aa* will not mask the value of aab:

/a.asp?aab=123

F5 Product Development is considering a request for enhancement (RFE) to allow wildcard characters for sensitive parameters. F5 Product Development is tracking this RFE as CR117180.
