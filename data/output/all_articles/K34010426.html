K34010426: Exception: ssh connection failed, exit code: 255

Type
Support Solution
Published
2021-05-07
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K34010426

Description
While running preUpgradeCheck script on BIG-IQ, you may encounter the following error:
 

Traceback (most recent call last):
  File "./preUpgradeCheck", line 1023, in <module>
    sys.exit(main())
  File "./preUpgradeCheck", line 1010, in main
    runDiskSpaceChecks(session)
  File "./preUpgradeCheck", line 892, in runDiskSpaceChecks
    with SshConnection(ip, account, 22) as conn:
  File "./preUpgradeCheck", line 109, in __init__
    self._start_master_proc()
  File "./preUpgradeCheck", line 205, in _start_master_proc
    "ssh connection failed, exit code: %d" % master_rc)
Exception: ssh connection failed, exit code: 255

Environment

  • BIG-IQ in public cloud environment, such as AWS

Cause
User name input into the preUpgradeCheck script, when prompted was not that of a user name whose account shell is bash.

Recommended Actions

  1. On each BIG-IQ in the cluster, ensure that the account username you will be using has bash shell account access. 
    modify auth user admin shell bash; save sys config

Additional Information
None.
