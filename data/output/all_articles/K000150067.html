The BIG-IP Configuration utility is the graphical user interface you use to manage the BIG-IP system. Depending on your organizational security requirements, one method to secure access to the Configuration utility is to allow only trusted IP addresses or a range of IP addresses to access the Configuration utility.

  • 00:00 Intro
  • 01:06 Add an IP address or range of IP addresses to the current allowed list
  • 02:05 Replace the current allowed list with a new list of IP addresses
  • 02:30 Remove an IP address or range of IP addresses from the current allowed list
