K000161502: f5PolicyServer.exe may be flagged as malicious by client AV software

Type
Support Solution
Published
2026-08-26
Updated
2026-08-26
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000161502

Description

Processes f5PolicyServer.exe and wa_3rd_party_host_32.exe may appear on Windows client workstations and be flagged by antivirus or endpoint protection tools as suspicious or malicious.

These are legitimate components of the BIG-IP APM Edge Client endpoint inspection framework, used for posture checks and integration with OPSWAT for endpoint security validation when connecting to BIG-IP APM environments.

Environment

  • BIG-IP APM
  • BIG-IP APM Edge Client
  • Windows client workstations connecting to BIG-IP APM
  • Endpoint inspection and OPSWAT integration enabled

Cause

None

Recommended Actions

If f5PolicyServer.exe and wa_3rd_party_host_32.exe are detected on client workstations using BIG-IP APM Edge Client components, these processes are expected and required for endpoint posture checks and security validation.

Security alerts or antivirus warnings regarding these processes can be safely ignored, provided the files originate from the official BIG-IP APM installation and are not replaced or modified by third-party sources.

Additional Information

These executables are part of the normal operation of BIG-IP APM endpoint inspection. Their presence is necessary for proper posture checking and integration with OPSWAT. If security tools flag these files, verify their source and ensure they are not replaced by unrelated or malicious software. The legitimate files are signed by F5 Networks and are distributed as part of the APM Edge Client package.
