K59210323: warning diskmonitor[1580]: 011d0002:4: Skipping /run/user/0. Stat returned message: /usr/bin/stat: cannot read file system information for /run/user/0: No such file or directory

Published
2022-06-17
Updated
2025-04-02
Applies to
  • BIG-IP
Source

Description

You may see the following log message in /var/log/ltm.

warning diskmonitor[1580]: 011d0002:4: Skipping /run/user/0. Stat returned message: /usr/bin/stat: cannot read file system information for /run/user/0: No such file or directory

Environment

  • BIG-IP LTM

Cause

If the user who has uid=0 performs login, tmpfs /run/user/0 will be mounted. Then, it's umounted due to logout, diskmonitor fails to stat it depending on the timing.
# df /run/user/0
Filesystem     1K-blocks  Used Available Use% Mounted on
tmpfs             817652     0    817652   0% /run/user/0

Recommended Actions

If you don't want these warning messages to appear,  creating a syslog-ng filter will be a workaround.

  1. Log into the TMOS shell (tmsh) by typing the following command:
    tmsh

  2. Edit syslog by typing the following command:
    edit /sys syslog

  3. When syslog configuration opens in the vi text editor, copy and paste the entire entries below:

    modify syslog {
    include "
    # Workaround to remove diskmonitor messages
    filter f_no_audit {
    not message(\"AUDIT|diskmonitor.*Skipping /run/user/0\");
    };"
    }

  4. Exit the text editor by typing the following key sequence:
    :wq!

  5. Save the configuration by typing the following command:
    save sys config

Additional Information

There is no functional impact. The message logged does not indicate functional issues, and can be safely ignored if desired.
