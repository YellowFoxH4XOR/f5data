K000161291: BIG-IP 21.1.0 upgrade changes parent clientssl profile to use clientssl-legacy

Type
Support Solution
Published
2026-05-15
Updated
2026-05-15
Applies to

  • BIG-IP LTM: 21.1.0
Source

Description

In BIG-IP 21.1.0, the default clientssl profile restricts access via TLS 1.0 and TLS 1.1 by default.

During an upgrade from earlier versions, custom clientssl profiles that previously used defaults-from clientssl are automatically updated to use defaults-from clientssl-legacy to maintain legacy TLS behavior.

A new custom clientssl profile creation In BIG-IP 21.1.0 loads the defaults-from clientssl by default. The clientssl-legacy is not automatically assigned.

The same behavior applies to serverssl profiles as well.

 

Environment

  • Client + Server SSL profiles

Cause

The default clientssl profile has been changed to restrict TLS 1.0 and TLS 1.1 access for security In BIG-IP 21.1.0.
