Known Issue

If you use modifier keys within a remote desktop, you may trigger a Java exception error message.

This issue occurs when all of the following conditions are met:

  • The local user device is running Mac OS X 10.12 (Sierra).
  • The BIG-IP APM system is configured with a Remote Desktop profile that is configured with Java Client enabled.
  • The user device has Java 8 installed.
  • The user established an access session using the Safari 10 web browser.
  • The user launches a remote desktop session.
  • The user presses a modifier key (for example: Caps Lock, Alt, Shift, etc) from within the remote desktop session.

This issue is related to Java 8 applet input handling and cannot be addressed on the BIG-IP APM system.

Refer to: JDK-8166040 : [MacOSX 10.12] Pressing a modifier key results in NullPointerException thrown by applets

Impact

Using the remote desktop session modifier key triggers a Java exception error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When users use a modifier key within the remote desktop session, the system displays a Java exception error message similar to the following example:

    An uncaught exception was raised. Choose "Continue" to continue running in an inconsistent state. Choose "Crash" to halt the application and file a bug with Crash Reporter. Choosing "Crash" will result in the loss of all unsaved data.

  • When the user selects Continue, the system immediately displays the message again (loop).  
  • When the user selects Crash, the system terminates the established remote desktop.
  • Despite the Java exception error message, the remote desktop functions as expected when the user does not use modifier keys.
  • When you use a full screen remote desktop, the system displays the Java exception error message beneath the main window of the remote desktop.

Workaround

To work around this issue, upgrade the user device to use Java 9.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
