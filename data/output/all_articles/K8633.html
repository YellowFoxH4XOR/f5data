K8633: Certificate installation fails when the intermediate certificate chain does not end with a carriage return

Known Issue

This is the result of a known issue. If you attempt to install an SSL server certificate with multiple intermediate certificates in the Optionally, put your intermediate certificate chain here (in the PEM format) field, FirePass does not display the certificate details, or give you an option to save the certificate. Additionally, FirePass reports an error message similar to the following example:

The certificate (and/or chain) you entered is invalid.

This issue occurs when you do not enter a carriage return after the final line of the last intermediate certificate.

For example, this issue would occur if the final line of the intermediate certificate chain in the following example displays with no carriage return:

-----END CERTIFICATE-----

Note: This issue only occurs when you enter multiple intermediate certificates in the Optionally, put your intermediate certificate chain here (in the PEM format) field. If you enter a single intermediate certificate, the certificate does not require a carriage return at the end.

Note: You can install an SSL server certificate by clicking the Install link in the Renew/Replace SSL Server Certificate section of the Device Management: Security: Certificates page.

F5 Networks Product Development tracked this issue as CR97331 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

This issue still exists in the FirePass version 5.x branch.

Workaround

You can work around this issue by entering a carriage return at the end of the intermediate certificate chain.
