Issue

Error Message

info bcm56xxd[<PID>]: 012c0015:6: Link <interface> is <status>

In this error message, note the following:

  • <PID> is the process ID for the bcm56xxd process.
  • <interface> is the switch interface on the BIG-IP system.
  • <status> is the link status of the interface.

For example:

info bcm56xxd[3970]: 012c0015:6: Link 1.2 is UP

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The status of a switch interface changes.

The BIG-IP system generates this message when the status of a switch interface changes.

For possible values, refer to the following table.

Interface statusDescription
UPThe interface is enabled, has a link, and is communicating.
DOWNThe interface is enabled but is not able to establish a link.
DISABLEDThe interface is administratively disabled.
UNPOPULATEDNo optic was found in the interface.
UNINITIALIZEDNo VLAN or trunk is configured.
MISSVLAN or trunk is configured but no SFP is present.

This log is only on the following hardware platforms, with broadcom switch chips:
 
 BIG-IP 6900 (D104)
 BIG-IP 8900 (D106)
 BIG-IP 8950 (D107)
 BIG-IP 11000 (E101)
 BIG-IP 11050 (E102)
 BIG-IP 5000 series (C109)
 BIG-IP 7000 series (D110)
 BIG-IP 10000s/10050s/10200v/10250v (D113)
 BIG-IP 12250v (D111)
 VIPRION blade B2100 (A109)
 VIPRION blade B2150 (A113)
 VIPRION blade B2250 (A112)
 VIPRION blade B4100 (A100)
 VIPRION blade B4200 (A107)
 VIPRION blade B4300 (A108)
 VIPRION blade B4340N (A110)

VCMP guests on these hardware platform do not have this log.

Impact

None. The message is informational.

Recommended Actions

None
