Description

How to list out traffic certificate expiration dates using SNMP

 

Environment

 

  • You wish to monitor SSL certificate expiration dates using SNMP
  • SSL Certificates configured on the BIGP-IP
  • BIG-IP LTM, APM, ASM, DNS

Cause

How-to or non-issue.

Recommended Actions

Two new OID's now exist for this task:

sysCertificateFileObjectExpirationString .1.3.6.1.4.1.3375.2.1.15.1.2.1.4

 sysCertificateFileObjectExpirationDate .1.3.6.1.4.1.3375.2.1.15.1.2.1.5

 

You can view the output as in the below sample:

 

[root@V17:Active:Disconnected] config # snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.15.1.2.1.4
