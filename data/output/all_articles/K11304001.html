Known Issue

The BIG-IP system may produce errdefsd process error messages during startup.

This issue occurs when the following condition is met:

  • You reboot your BIG-IP system.

Impact

The system generates error messages regarding errdefsd when you start the system.

Note: You can safely ignore these error messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you start the system, the system logs error messages similar to the following example to the /var/log/ltm file:

    err errdefsd[<pid>]: 0194001d:3: Errdefsd is starting. Old shared memory arena is now deprecated.
    err errdefsd[<pid>]: 01940019:3: Unable to connect to MCPD, will try again in 30 seconds.
