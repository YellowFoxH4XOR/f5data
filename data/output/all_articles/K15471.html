Known Issue

The big3d process produces invalid XML for BIG-IP GTM objects that have an ampersand (&) character in the name.

This issue occurs when the following condition is met:

  • Enterprise Manager is managing a BIG-IP GTM system that is configured with objects that have an ampersand (&) in the name.

Impact

Enterprise Manager is unable to collect statistics data from the BIG-IP GTM system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H474212 on the Diagnostics > Identified > Medium  screen.
  • In the /var/log/em file, the Enterprise Manager system logs error messages that appear similar to the following example:

    em1 err emstatsd[14343]: 040a0310:3: Could not parse xml for device 10.10.10.10 : <stats><time>1407139200</time><type>tcp</type><open>2</open><closewait>0</closewait><finwait>0</finwait><timewait>0</timewait><accept>0</accept><acceptfails>0</acceptfails><conn>2</conn><connfail>0</connfail><expires>0</expires><abandons>0</abandons><rxrst>0</rxrst><rxbadsum>0</rxbadsum><rxbadseg>0</rxbadseg><rxooseg>0</rxooseg><rxcookie>0</rxcookie><rxbadcookie>0</rxbadcookie><syncacheover>0</syncacheover><txrexmits>0</txrexmits></stats>

Workaround

To work around this issue, F5 recommends that you do not include the ampersand (&) character in BIG-IP GTM object names.
