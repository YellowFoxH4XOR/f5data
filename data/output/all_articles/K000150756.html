K000150756: After upgrading from 17.1.2 to 17.1.2.1 guided configuration page showing Not found - The requested URL was not found on this server

Description

 

After upgrading from 17.1.2 to 17.1.2.1 guided configuration and updating f5-iappslx-access-framework  guided configuration page is opening but showing:

Not found - The requested URL was not found on this server

Environment

  • BIG-IP APM
  • Upgrade
  • Guided Configuration
  • iApps LX

Cause

Guided configuration wasn't properly initialized.

Recommended Actions

  1. Navigate to System -> Preferences and set the Records Per Screen to 100
  2. Navigate to iApps -> Package Management LX, selected all the packages and selected the Uninstall button to uninstall them. Wait for that to complete
  3. Navigate to Access -> Guided Configuration and it will rebuild.
