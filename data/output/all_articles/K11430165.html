Known Issue

The Configuration utility may not display the IPv6 option in the HTTP profile.

This issue occurs when all of the following conditions are met:

  • You have created an HTTP profile with the Proxy Mode setting configured to Explicit.
  • You attempt to customize or modify the IPv6 option by selecting the Custom check box under the Explicit Proxy settings.

Impact

You are unable to customize or modify the IPv6 option in the HTTP profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility does not display the IPv6 check box or the entire IPv6 option row.

Workaround

To work around this issue, you can use the TMOS shell (tmsh) to set the IPv6 option in the HTTP profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the IPv6 option in the affected HTTP profile, use the following command syntax:

    modify /ltm profile http <profile name> explicit-proxy { ipv6 default-value|no|yes }

    For example:

    modify /ltm profile http test-http1 explicit-proxy { ipv6 yes }

  3. Save the configuration change by typing the following command:

    save /sys config

  4. Exit tmsh by typing the following command:

    quit
