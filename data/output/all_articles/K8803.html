K8803: Required NetBIOS settings for accessing Windows file shares through an Application Tunnel

Topic

If one or more users cannot access a Windows file share through a FirePass Application Tunnel, while other users are able to access the same file share through the same Application Tunnel, NetBIOS over TCP/IP (NetBT) may be disabled on the affected client systems.

Important: Some mobile data cards disable NetBT by default. For more information, refer to the vendor documentation for your mobile data card.

To access a Windows file share using an Application Tunnel, NetBT transport must be functioning properly on the client system and NetBT must be enabled on the connecting network adapter (the network adapter which connects to the FirePass controller).

To verify the status of NetBT transport on the client system, run NetDiag.exe or a similar network diagnostics tool. You can download NetDiag.exe from the Microsoft Download Center at the following location:

http://www.microsoft.com/downloads/

To determine the status of NetBT transport using NetDiag.exe, type the following command from the Windows command line:

\path\to\netdiag.exe /test:netbttransports

In the command, \path\to\netdiag.exe is the full path to NetDiag.exe on the client system. At the end of the command output, the result of the NetBT transport test is reported. For example:

NetBT transports test. . . . . . . : Passed

If the result of the NetBT transports test is reported as Passed, NetBT transport is functioning properly on the client system. If result of the NetBT transports test is reported to be another status, such as Failed or Skipped, NetBT transport is not functioning properly on the client system. For information about troubleshooting NetBT transport on the client system, refer to your Microsoft Windows documentation.

To verify whether NetBT is enabled on the connecting network adapter, type the following command on the Windows command line:

ipconfig /all

Locate the section of output corresponding to the connecting network adapter. If a line similar to the following example appears, NetBIOS over TCP/IP is disabled on the network adapter:

NetBIOS over Tcpip. . . . . . . . : Disabled

Note: The status of NetBT is only reported if NetBT is disabled. If the output for the connecting network adapter does not contain a line reporting the status of NetBT (NetBIOS over TCP/IP), NetBT is enabled for the network adapter.

If NetBT is disabled on the connecting network adapter, NetBT must be enabled before the client system can access a Windows file share through an Application Tunnel. For instructions about enabling NetBIOS over TCP/IP, refer to your Microsoft Windows documentation.
