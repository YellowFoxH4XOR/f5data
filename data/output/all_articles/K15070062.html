K15070062: guestagentd.out in /shared/tmp taking high amount of disk space

Description

On a VCMP guest the /shared partition shows high (75% plus) usage and guestagentd.out is using a large amount of space, leaving a low amount of disk space free.

Environment
  • vCMP Guests versions from 12.1.0 to 12.1.3.1

Cause

This log output file is not trimmed or rotated so will just continue growing.
This is tracked as Bug ID 624362

Recommended Actions

The file may be currently in use by the guestagentd process so it will not free up space when deleted.
The file can be cleared with the following command:
echo "" > /shared/tmp/guestagentd.out

Alternatively stop the guestagentd process to stop the logging.

bigstart stop guestagentd

Note: Stopping the guestagentd process will disable the vCMP health feature on the host
