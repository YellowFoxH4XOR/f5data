Description

Attempts to change the certificate and key used by a clientssl profile result in the following error message:

01020066:3: The requested ClientSSL CertKeyChain Entry (/Common/semicolon) already exists in partition Common.

Environment

  • BIG-IP
  • Clientssl profile
  • Certificate and Key

Cause

SSL key with passphrase containing semicolon cannot be used when creating/editing a client ssl profile via GUI. This fails as a result of a known issue ID: 477785: GUI LTM Profile ClientSSL Passphrase does not accept semicolons.

Recommended Actions

You can work around this known issue by using tmsh to edit/create the affected profile that has a passphrase that contains a semicolon.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
     
  2. Type the following command substituting the appropriate names for the clientssl profile and Certificate and Key.

    modify ltm profile client-ssl <Clientssl_profile_name> key <private_key_name.key> cert <Certificate_Name.crt> passphrase <passphrase_XXXXXXXXXXX>

    For example

    modify ltm profile client-ssl Clientssl_profile_test key test_private_key.key cert Certificate_Name.crt passphrase ABCDE;123
     
  3. Save the configuration

    save sys config
