Known Issue

This is the result of a known issue. When an attack signature is in the staging period, the signature continues to generate learning suggestions for a defined parameter even if the signature has been disabled for that specific parameter. This issue affects the signature only when it is in the staging period. Once the signature has completed the staging period, the signature no longer generates suggestions against parameters for which it has been disabled.

Additionally, while the attack signature is in staging, the BIG-IP ASM system must allocate resources to processing the signature rule. In the event of a sufficiently complex attack signature rule system performance may be become degraded, even though the attack signature is otherwise disabled.

F5 Product Development tracked this issue as ID 222898 (formerly CR125677) and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
