Description

Environment

  • CPU usage spike
  • syslog-ng
  • Unexpected reboot

Cause

Bug ID 1040277: Syslog-ng issue may cause logging to stop and possible reboot of a system

Recommended Actions

Review and implement the workaround detailed in Bug ID 1040277.
