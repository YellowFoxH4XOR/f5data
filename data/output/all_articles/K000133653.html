K000133653: Encountered error when deleting a VLAN in F5OS: illegal reference /fdb/mac-table/entries/entry

Type
Support Solution
Published
2023-04-25
Updated
2023-04-25
Source
https://my.f5.com/manage/s/article/K000133653

Description

Encountered error when deleting a VLAN in F5OS


For Example:

CLI Error: Aborted: illegal reference 'fdb mac-table entries entry XX:XX:XX:XX:XX:XX XX tag_type_vid vlan'

GUI Error: illegal reference /fdb/mac-table/entries/entry{XX:XX:XX:XX:XX:XX XX tag_type_vid}/vlan

error-type : application

error-tag : malformed-message

error-message : illegal reference /fdb/mac-table/entries/entry{XX:XX:XX:XX:XX:XX XX tag_type_vid}/vlan

 

Environment

- F5OS

- GUI / CLI (confd)

- VLAN

 

Cause

The VLAN you're trying to delete is being used by a tenant

 

Recommended Actions

Remove the affected VLAN in the tenants configuration

 

Additional Information

None
