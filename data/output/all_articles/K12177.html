Known Issue

This is the result of a known issue. When a virtual directory on a CIFS direct volume attaches to a subdirectory of a managed volume, directory listings of that virtual directory do not return snapshot directories. This issue occurs even if the snapshot directory display all-exports option is enabled on both the direct volume and the managed volume.

Note: Direct volumes are referred to as presentation volumes in the ARX GUI.

Although the snapshot directories do not appear in directory listings, they can still be accessed by name.

F5 Product Development tracked this issue as ID 340084 and it was fixed in ARX 5.1.9. For information about upgrading, refer to the ARX Release Notes.

Workaround

Users can work around this issue by accessing the snapshot directory by name. For example, users can append the snapshot directory name to the current directory name in the Windows Explorer address bar. By default, the snapshot directory is named ~snapshot and it is located under each directory in the volume. However, the snapshot directory name and accessibility options are configurable. For more information, refer to the Configuring Volume Snapshots chapter of the ARX CLI Maintenance Guide.
