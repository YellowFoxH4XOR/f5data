Description

Under specific configurations, after a reboot, "gateway failsafe" is no longer triggered.

 

You have a LTM pool with gateway failsafe configured, and the pool member is "forced offline".

# list /ltm pool dummy_pool

ltm pool dummy_pool {

  gateway-failsafe-device bigip1.local

  members {

    123.45.67.89:6789 {

      address 123.45.67.89

      session user-disabled   <=== forced offline

      state user-down

    }

  }

  min-up-members 1

  min-up-members-checking enabled

  monitor http

}

 

Pool status is "offline".

# show /ltm pool dummy_pool

-------------------------------

Ltm::Pool: dummy_pool

-------------------------------

Status

 Availability  : offline

 State         : enabled

 Reason        : The children pool member(s) are down

 

Failsafe triggered.

# show /sys ha-status

---------------------------------------------

Sys::HA Status

Feature         Key         Action       Fail

---------------------------------------------

pool-mbr-down   dummy_pool  failover      yes   <===

 

You perform a reboot.

# reboot

 

After reboot, pool status still show "offline".

# show /ltm pool dummy_pool

----------------------------

Ltm::Pool: dummy_pool

----------------------------

Status

 Availability  : offline

 State         : enabled

 Reason        : The children pool member(s) are down

 

However, failsafe is not triggered.

# show /sys ha-status

--------------------------------------------

Sys::HA Status

Feature         Key           Action    Fail

--------------------------------------------

pool-mbr-down   dummy_pool    failover    no   <===

 

Environment

  • BIG-IP
  • LTM pool configured with gateway failsafe
  • Pool member set to "forced offline" and gateway failsafe triggered
  • Perform a reboot

Cause

Changing the state of "gateway failsafe" pool member to force offline for the purpose of generating "gateway failsafe" is not supported.

Recommended Actions

To make a device "forced offline" and remain so after a reboot, use the device level "forced offline" instead.
