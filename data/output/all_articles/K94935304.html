Description
After upgrading BIG-IP code version, the 'Licensed version' and 'Licensed date' in the license file shows the original install details. The same applies to the command output from "tmsh show sys license".

Environment

  • Upgraded BIG-IP
  • Licensed version
  • Licensed date

Cause

This is by design. The licensed version and licensed date are semi-static values, these values are added when the unit is very first licensed. They will not always change after an upgrade or license reactivation. This can sometimes cause confusion, but users should not be alarmed.  The only dates that matter during re-activation and upgrade are "Service Check Date" on a Big-IP and the "License Check Date" for a specific software major revision.  More details on the interaction between these two important dates can be found here: K7727 : License activation may be required before a software upgrade for BIG-IP.


Note: After an allow move, the licensed version and licensed date may be updated upon license activation.

None
