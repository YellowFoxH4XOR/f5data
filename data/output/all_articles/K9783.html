Known Issue

This is the result of a known issue. Users may receive the following error message when accessing a Lotus Domino Web Access (DWA) server through Portal Access: 

Failed to create ur$top.cache: [object Error]
 
This error message is a debugging message and can be safely ignored.
 
F5 Networks Product Development tracked this issue as CR116852 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.
 
This issue has been fixed in cumulative hotfix HF-602-9 issued for FirePass version 6.0.2, and cumulative hotfix HF-603-2.1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For a list of current hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
