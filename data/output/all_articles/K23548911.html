Known Issue

IPv6 nodes that are monitored by the SQL database monitor may be incorrectly marked down.

This issue occurs when all of the following conditions are met:

  • Your system uses a database monitor to monitor an MSSQL, MySQL, Oracle, or PostgreSQL database.
  • The database listener is monitored by an IPv6 node on the BIG-IP system.

Impact

The BIG-IP system is unable to monitor the affected IPv6 nodes.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the monitor has debugging enabled, error messages appear in the /var/log/DBDaemon-0.log file similar to the following examples:

    MSSQL monitor error:
    jdbc:sqlserver://2002::10:10:153:3:1234;databaseName=;(Thread-381): DB DriverManager.getConnection failed: "The port number :10:10:153:3:1234 is not valid."

    MySQL monitor error:
    jdbc:mysql://2002::10:10:153:3:1237/(Thread-387): DB DriverManager.getConnection failed: "Cannot load connection class because of underlying exception: 'java.lang.NumberFormatException: For input string: ":10:10:153:3:1237"'."

    Oracle monitor error:
    jdbc:oracle:thin:@2002::10:10:153:3:1235:(Thread-393): DB DriverManager.getConnection failed: "Invalid connection string format, a valid format is: "host:port:sid" "

    Postgres monitor error:
    jdbc:postgresql://2002::10:10:153:3:1236/(Thread-397): DB DriverManager.getConnection failed: "No suitable driver found for jdbc:postgresql://2002::10:10:153:3:1236/"
