Topic

Prior to FirePass version 5.5.0, you could associate routing tables with resource groups. Beginning in version 5.5.0, routing tables are associated with master groups instead of resource groups. This change was necessary in order to support multiple routing tables for the Mobile E-mail and Windows Files features.

When you upgrade to version 5.5.0 or later, FirePass will attempt to convert your existing configuration. Any routing tables that are associated with resource groups will be modified so that they are now associated with a master group. FirePass will choose the master group that is linked to the resource group with which the routing table was originally associated.

When FirePass converts your configuration, a message similar to the following will be logged in the System Log:

<date>
<time>
maintenance
The original Resource Group to Routing Table Mapping is:
<date>
<time>
maintenance
Upgrading the policy-based routing configuration.


In some instances, FirePass may not be able to successfully convert the configuration. When this occurs, the Administration Console will display the following message when you log in:

Firepass controller has detected conflicts while upgrading the policy based routing during the last upgrade. Please go to the Master Groups configuration page and assign the proper routing tables to the following master groups: <master group names>

If no warning message is displayed when you log in, your configuration was converted successfully.

Adding new routing tables in FirePass version 5.5.0 and later

If your configuration was not converted successfully, or if you wish to add new routing tables, perform the following procedure:

  1. Log in to the FirePass Administration Console.
  2. In the main navigation pane, select Device Management.
  3. In the upper menu, select Configuration.
  4. In the sub-menu, select Network Configuration.
  5. Select the Routing tab.
  6. Click the Switch to advanced mode link.
  7. Locate the Add new routing table section of the page.
  8. Enter the details for the new routing table.
  9. Click Add New.
  10. In the main navigation pane, select Users.
  11. In the upper menu, select Groups.
  12. In the sub-menu, select Master Groups.
  13. For the Master Group you want to modify, click the link in the Routing Table column next to the Master Group.

    Note: The link will most likely be named main or default, but it could also be the name of a routing table you previously created.

  14. In the Select Routing Table drop-down menu, select the name of the routing table you just created.
  15. Click Update.

The Master Group will now use the routing table you selected.
