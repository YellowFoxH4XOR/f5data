Description

Followed DevCentral: APM Clientless Mode, the traffic works. However, when the Category lookup is enabled, it fails for the first connection and sends reset with [F5rst : cl side error], next consecutive request works.

CURL command used:

curl -H 'clientless-mode: 1' -vv --tlsv1.2 https://google.com

Following error is received:

SNI categorization input option is not supported in category lookup agent for reverse proxy configuration.

 

Environment

  • BIG-IP
  • SWG
  • curl

 

Cause

  • Curl syntax need to be modified to use forward proxy. Need to use -x option.

 

Recommended Actions

  • Please use -x option: K000149295: [APM][SWG] using cURL utility for testing
