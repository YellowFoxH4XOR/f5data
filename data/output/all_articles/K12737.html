Known Issue

This is the result of a known issue. A memory leak in the Pluggable Authentication Modules (PAM) authorization module may cause the mcpd process to restart. When this issue occurs, the BIG-IP system interrupts traffic management and logs error messages that appear similar to the following examples, to the /var/log/ltm file:

mcpd[4571]: 01070736:3: Couldn't write to the user/role/partition file, /config/bigip/auth/userrolepartitionsXYZ123 (24).
mcpd[4571]: 01071070:3: Failed to open file /config/BigDB.dat.tmp with error -167949863.
mcpd[4571]: 01070734:3: Configuration error: MCPProcessor::processRequest:
mcpd[4571]: 01070596:3: An unexpected failure has occurred, - DbVariableFile.cpp, line 806, exiting...

F5 Product Development tracked this issue as ID 350080 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, WOM, or Edge Gateway release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
