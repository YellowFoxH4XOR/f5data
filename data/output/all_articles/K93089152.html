Known Issue

BIG-IP DNS (formerly known as BIG-IP GTM) object names may not be validated for the existence of control characters.

This issue occurs when the following condition is met:

  • You create or modify a BIG-IP DNS object name in one of the following manners, and the object is referenced within the configuration:
    • Using the Configuration utility, you create or modify a BIG-IP DNS object name and include a control character in the name.
    • Using the TMOS Shell (tmsh), you create or modify a BIG-IP DNS object name and include a control character in the name.
    • You directly edit the /config/bigip_gtm.conf file by adding text that includes control characters.
  • Your BIG-IP system attempts to load the configuration.

Impact

The BIG-IP system may fail to load the configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to load the configuration using the command line, you observe an error message similar to the following example:

    Loading configuration...
         /config/bigip_gtm.conf
       Syntax Error:(at line: <line number>) "<value>" unknown property

  • When you analyze the /config/bigip_gtm.conf file, there are control characters located in the line number noted by the error.

Workaround

To work around this issue, you can ensure that control characters are not entered in to the bigip_gtm.conf file. For more information, refer to K35402294: Detecting and removing control characters from the bigip_gtm.conf configuration file.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
