K000157290: SNMP stopped to work

Support Solution

  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source

Description

After the upgrade you may encounter an issue with the SNMP, also you can notice similar logs in the /var/log/snmpd.log

Received broken packet. Closing session.
Received broken packet. Closing session.
Received broken packet. Closing session.
Received broken packet. Closing session.

Environment

  • BIG-IP
  • Viprion
  • Upgrade

Cause

The SNMP service on the affected BIG-IP guest may became unresponsive due to a post-upgrade issue with the SNMP/AgentX subsystem. The root cause is a malfunction in the SNMP/AgentX process following the upgrade.

Recommended Actions

1. Restart SNMPD and sflow_agent services.

restorecon -rF /config/snmp/snmpd.conf

tmsh restart sys service snmpd

tmsh restart sys service sflow_agent

2. If it still not working, please perform MCPD reload, this will reboot the device:

Important: BIG-IP system traffic processing is interrupted while the system restarts.

touch /service/mcpd/forceload

reboot
