Topic

When a global server is joined to an Active Directory (AD) domain, a machine account password is configured in AD for the ARX system. Current versions of the ARX system do not have the functionality to reset the machine account password. 

If the domain controller's AD security settings enforce the Domain member: Maximum machine account password age setting, and the maximum age setting expires, the virtual servers hosted on the ARX will become unusable for clients. Clients will receive access denied messages when attempting to access file resources.

Beginning in ARX 4.1.0 and 5.0.0, the cifs rekey command can be used to refresh the secret password (or key) for a CIFS service on the ARX system. For information about the cifs rekey command, refer to the ARX CLI Reference Guide.

Workaround

To ensure the ARX system machine account password does not expire, join a domain or Organizational Unit (OU) that does not enforce the Domain member: Maximum machine account password age setting.

To recover an ARX system with an expired machine account password, you must remove the ARX virtual server from the domain and then re-join the ARX virtual server to the domain. For information about joining a domain using the domain-join command, refer to the ARX CLI Reference Guide.
