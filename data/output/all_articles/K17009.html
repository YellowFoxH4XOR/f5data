Known Issue

The Description field for the BIG-IP AFM global IP Intelligence policy is missing from the BIG-IP Configuration utility.

This issue occurs when the following condition is met:

  • You are unable to view or modify the Description field in the global IP Intelligence policy screen.

Impact

There is no impact; this issue is purely cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When navigating to the Security > Network Firewall > IP Intelligence > Policies screen, the Description field under Global Policy is missing.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to configure the Description field. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

    Configuring the global policy Description field using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh
  2. Add the global policy description using the following command syntax:

    modify security ip-intelligence global-policy description <GlobalPolicyDescription>

    In this command, note the following:
    • <GlobalPolicyDescription> is the global policy description you want to use. 
    For example:

    modify security ip-intelligence global-policy description F5GlobalPolicy
