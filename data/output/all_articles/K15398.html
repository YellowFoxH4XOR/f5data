Topic

The BIG-IP system does not automatically sync the configuration between boot locations. You can accomplish this by installing a configuration when activating a boot location or using the cpcfg command to copy the configuration files between boot locations.

Description

The BIG-IP system uses the logical volume management (LVM) disk-formatting scheme to manage directories and data files, including configuration files for a boot location. For example, the /config directory for a boot location contains configuration files used by the BIG-IP system to configure VLANs, self IPs, and virtual servers while booted into that boot location. The /etc directory for a boot location contains data files including configuration files for the system processes, such as web services (http) or logging services (syslog), specific to that boot location. These directories and their files are unique to a boot location and cannot be accessed from other boot locations. Only the /shared directory that contains logs, statistics, and software images is common between boot locations and can be accessed from other boot locations.

The BIG-IP system (except for the Virtual Edition 1-slot disk images) typically allows installation of multiple versions of the BIG-IP software on different boot locations. By default, configuration of the currently active boot location is copied to the target installation boot location only during software installation. The configuration does not automatically sync between boot locations when you attempt to reboot a BIG-IP system to another boot location. If you need to sync the configuration from the currently active boot location to the desired boot location, you can use either the cpcfg utility from the BIG-IP command line or the Install Configuration option from the BIG-IP Configuration utility to copy the currently active boot location configuration to the target boot location prior to rebooting the BIG-IP system to the target boot location.

Recommendations

When you need to sync the configuration between boot locations, you should perform the procedures detailed in the following articles:

  • K14704: Installing a configuration when activating a boot location
  • K14724: Using the 'cpcfg' command to copy a configuration from one boot location to another
