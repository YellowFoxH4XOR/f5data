Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator performs URL normalization, the BIG-IP client is sent an HTTP 302 redirect response with a URI that references a temporary file on the BIG-IP WebAccelerator system. The HTTP port information is not preserved and sent with the HTTP 302 redirect response. Therefore, if the BIG-IP WebAccelerator virtual server is configured to use a non-standard HTTP port, the client request for the normalized URL will fail.

F5 Networks Product Development is tracking this issue as CR92719. 

Workaround

Prevent the URL normalization from failing, by using one of the following procedures:

  • Using an iRule to include the HTTP port information for the HTTP 302 redirect
  • Disabling URL normalization

 Using an iRule to include the HTTP port information for the HTTP 302 redirect

To include the HTTP port information when the HTTP 302 redirect response is returned to the client, you can create an iRule that adds the HTTP port information to the Location HTTP header of the HTTP 302 redirect response, and associate the iRule with the BIG-IP WebAccelerator virtual server.

For example

when HTTP_RESPONSE {
  if {[HTTP::header exists Location]} {
    set loc [HTTP::header value Location]
    clientside {
      set vport [TCP::local_port]
    }
    set uri "http://replace_with_sitename/"
    set len [expr [string length $uri] - 1]
    if {$loc starts_with $uri} {
    set loc [string replace $loc $len $len ":$vport/"]
      HTTP::header replace Location $loc
    }
  }
}

 

Disabling URL normalization

Disable URL normalization by modifying the contentBasedIdentity settings in the  /config/wa/globalfragment.xml file. 

Note: For information about modifying the contentBasedIdentity settings, refer to the Changing default values for URL normalization section of the Changing Default Settings chapter in the Administrator Guide for the BIG-IP WebAccelerator System.

Note: For information about modifying the contentBasedIdentity settings on a per node basis in the WebAccelerator acceleration policy, refer to K8379: Overview of advanced assembly features for WebAccelerator policies.
