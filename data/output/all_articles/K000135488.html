Description

How to  updateAFM address-list using PATCH command with AS3

 

Environment

AFM

DDOS : address list update using PATCH command

 

Cause

None

 

Recommended Actions

Use the below syntax

 

{

"class": "AS3",

"action": "patch",

"patchBody": [

    {

      "op": "add",

      "path": "/Sample_dos_01/DOSApp/addressList/addresses/-",

      "value":         

          "192.168.20.1"      

    }

  ]

}

 

Additional Information

 

  1. PATCH only works for AS3 version 3.44.0 and above.
