Known Issue

The Traffic Management Microkernel (TMM) may stop responding when a virtual server references a request logging profile. When the request logging profile attempts to release memory, it uses incorrect arguments. As a result, the TMM process may stop responding.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if it is configured as part of a high-availability (HA) system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process stops responding with a SIGSEGV.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system fails over to the standby system.
