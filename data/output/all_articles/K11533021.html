Known Issue

The BIG-IQ system fails to license remote BIG-IP systems when the license uses a legacy SKU number.

This issue occurs when all of the following conditions are met:

  • You are using the BIG-IQ Centralized Management or BIG-IQ License Manager systems to manage remote BIG-IP Virtual Edition (VE) systems.
  • You attempt to license a remote BIG-IP VE system using a license that does not use a VE Version Plus SKU number.

    Note: For more information about VE Version Plus SKU numbers, refer to K15643: BIG-IP VE license offerings.

Impact

The BIG-IP system fails to load the configuration and does not process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice a BIG-IP VE system has an expired license after it is licensed by the BIG-IQ system.
  • You notice a BIG-IP VE system fails to process traffic after it is licensed by the BIG-IQ system.
  • In the /var/log/ltm file, you notice error messages similar to the following example:

    err httpd[8370]: 01180010:3: [license processing][error]: invalid input for number feature flag comparison
    err httpd[8370]: 01180016:3: [license processing][error]: custom flag comparison: failed. (null). (null)
    err httpd[8370]: 01180010:3: [license processing][error]: custom flag validation: failed comparison
    err httpd[8370]: 01180010:3: [license processing][error]: feature flag validation failed
    err httpd[8370]: 01180010:3: [license processing][error]: failed processing license management data

Workaround

To work around this issue, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Contact F5 Technical Support to request an Allow Move procedure for the legacy base registration key.
  2. Manually re-license the BIG-IP system with a legacy base registration key. For more information, refer to K7752: Licensing the BIG-IP system.
  3. If you want to use BIG-IQ Centralized Management or BIG-IQ License Manager to re-license the BIG-IP system, contact your sales team and upgrade the legacy base registration key to a Version Plus license. After you obtain a Version Plus license, you can re-deploy to the BIG-IP system. For more information, refer to K77706009: Using BIG-IQ License Manager to remotely manage BIG-IP Virtual Edition licenses.
