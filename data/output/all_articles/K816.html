K816: F5 source addresses are not added to hosts.allow when the support account is enabled

Known Issue

This may be the result of a known issue. When you set up the support account at the time that you initially configure the system, BIG-IP and 3-DNS add the F5 Technical Support source addresses into the /etc/hosts.allow file.

If you configure the support account after you have configured the system, BIG-IP and 3-DNS do not add these addresses. As a result, the system will not allow connections from F5 Networks' source addresses.

F5 Networks Product Development is tracking this issue as CR25821 and CR41891. Monitor future BIG-IP and 3-DNS Release Notes for the status of these CRs.

Workaround

To work around this issue, perform the following steps:

  1. Log in to the command line.
  2. Change directories to the /etc directory, by typing the following command:

    cd /etc

  3. Using a text editor, such as vi or pico, edit the hosts.allow file.
  4. Locate the line that begins with sshd : and is followed by one or more self IP addresses.

    For example:

    sshd : 172.16.20.1

  5. At the end of the line, add the word ALL.

    For example:

    sshd : 172.16.20.1 ALL

  6. Save the file and exit the editor.

F5 Networks Technical Support should now be able to connect to your system using SSH.
