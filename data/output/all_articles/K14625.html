Known Issue

BIG-IP GTM or BIG-IP Link Controller systems may have an issue where the Configuration utility does not display the link-related weighting options for Price Prepaid Segment and Incremental Segments.

This issue occurs when one of the following conditions is met:

  • A BIG-IP GTM device is re-licensed as a BIG-IP Link Controller.
  • A new BIG-IP Link Controller module license is applied to a previously-licensed BIG-IP GTM device.
  • You attempt to configure a Link Controller link from the Configuration utility.
  • A Link Controller device is re-licensed as a BIG-IP GTM system.
  • A new BIG-IP GTM module license is applied to a previously-licensed Link Controller device.
  • You attempt to configure a BIG-IP GTM link from the Configuration utility.

Impact

You cannot use the Configuration utility to configure the Link Price weighting Prepaid Segment and Incremental Segments.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you use the Configuration utility, you are unable to locate or configure the BIG-IP GTM or BIG-IP Link Controller Link Price weighting settings.

Workaround

To work around this issue, you can use Traffic Management Shell (tmsh) to configure Price Weighting. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To create a new link, type the following command:

    create /gtm link <link name> datacenter <data center name> router-addresses add { <upstream router ip address> } cost-segments { { dollars-per-mbps <dollar value> up-to-bps <bps value> } { dollars-per-mbps <dollar value> up-to-bps <bps value> } }

    To update an existing link router reference, type the following command:

    modify /gtm link <link name> datacenter <data center name> cost-segments {{ dollars-per-mbps <dollar value> up-to-bps <bps value> } { dollars-per-mbps <dollar value> up-to-bps <bps value> } }
