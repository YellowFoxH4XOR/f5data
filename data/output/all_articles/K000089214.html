Procedures

Add MyF5 account users

You must have the Admin role to perform this procedure.

  1. In the upper right, select your profile name, and then select My Accounts.
  2. Select the account you want to add users to.
  3. In the Account Users section, select Invite new user.
  4. Enter the required information, and then select Save.

    Note: For Role, you can assign a user more than one role. For more information on roles refer to K000136095: About MyF5 account user roles and permissions.

    Invited users receive an email with registration instructions.

Change MyF5 account user roles

You must have the Admin role to perform this procedure.

  1. In the upper right, select your profile name, and then select My Accounts.
  2. Select the account that has the users whose role you want to change.
  3. Under Account Users, select the check boxes for the users you want, and then select Edit.
  4. Under Edit account users, under the name of the user whose role you want to change, in the Role list, clear the check box for each role you want to unassign and select check box for each role you want to assign.

    Note: For Role, you can assign a user more than one role. For more information on roles refer to K000136095: About MyF5 account user roles and permissions.

  5. Select Save.

Note: You cannot change or update registered e-mail address for MyF5 portal yourself at this time, but you can follow the steps outlined in the following article to get an email request change started for you: K53330134: Change or update registered e-mail address for MyF5 portal.

Remove MyF5 account users

You cannot remove users who have open support cases. After you remove a user, you can add them to the account again.

You must have the Admin role to perform this procedure.

  1. In the upper right, select your profile name, and then select My Accounts.
  2. Select the account that has the users you want to remove.
  3. Under Account Users, select the check boxes for the users you want to remove, and then select Edit.
  4. Under Edit account users, under the name of the user you want to remove, select the Remove User check box.
  5. Select Save.

Remove myself from a MyF5 account

You cannot remove yourself from an account when any of following conditions apply:

  • You are the only Admin user on the account.
  • You have an open support case on the account.
  • You are the only user on an account that has active subscriptions, product trials, or service agreements.

For information about how to make another user an Admin, refer to Change MyF5 account user roles. To close a support case or cancel active products, call F5 Support .

  1. In the upper right, select the profile icon, and then select My Accounts.
  2. Select the account you want to remove yourself from, and then select Remove.
  3. Select Remove me.
