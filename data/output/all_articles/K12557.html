Known Issue

By default, when a user connects to a Protected Workspace, they are unable to write to a USB Mass Storage device. However, when a user is connected to Protected Workspace, they are able to use Windows Explorer to save a file to a USB device that uses the Media Transfer Protocol (MTP). Most USB devices use the USB Mass Storage device class (MSC) protocol. When the user is connected to a Protected Workspace, the FirePass or BIG-IP device will block the ability to write to devices that use MSC but not devices that use MTP.

F5 Product Development tracked this issue as ID 344912 and it was fixed in FirePass HF-70-8 and BIG-IP APM 11.4.0.
