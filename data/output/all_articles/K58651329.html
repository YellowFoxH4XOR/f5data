K58651329: ''Changes Pending'' message is always showing

Type
Support Solution
Published
2021-08-10
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K58651329

Description

  • Recent Changes are from the Standby device
  • Sync is possible but inmediatly 'Changes Pending' message appears
  • An ASM policy is modified, modifications are asm_policy_transaction_id '<#>' and asm_policy_is_active_policy '<#>'   
  • Following message appears in /var/log/audit 

01070417:5: AUDIT - client Unknown, user root - transaction #<num> - object 0 - modify { asm_policy { asm_policy_name "/<Partition>/<Policy_name>" asm_policy_transaction_id <#> asm_policy_strict_app_updates 0 asm_policy_app_id "" asm_policy_folder_name "/Common" asm_policy_leaf_name "<Policy_name>" asm_policy_partition_id <Partition> asm_policy_config_source 0 asm_policy_dummy "" asm_policy_alternate_bit 0 asm_policy_avr_publisher "" asm_policy_policy_type 1 asm_policy_is_active_policy <#> asm_policy_parent_policy "none" asm_policy_policy_template <tmplate> asm_policy_encoding <encoding> asm_policy_object_<id> } } [Status=Command OK]

  • Message for DATASYNC are shown in /var/log/ltm

010718ed:5: DATASYNC: scheduling datasync_renew_conf because global device-group /Common/<Device_Group> was updated from CMI by device /Common/<Peer_Device>
010718ed:5: DATASYNC: scheduling datasync_renew_conf because global device-group /Common/<Device_Group> was updated during config load
010718ed:5: DATASYNC: renewing datasync configuration
010718ed:5: DATASYNC: Initializing datasync configuration for provisioned modules [ asm ]
010718ed:5: DATASYNC: Done initializing datasync configuration for provisioned modules [ asm ]
010718ed:5: DATASYNC: skipping force sync of device group /Common/<Data sync device group>: 0 seconds since last sync, less than 30 seconds

Environment

  • BIG-IP ASM
  • HA environment
  • Sync Type for the Device Group set up as manual

Cause
Uknown at the time of the article creation

Recommended Actions

  1. Log in to the Configuration Utility
  2. Go to Device Management  ››  <Device_Group>
  3. Change Sync Type to Automatic
  4. Go to Device Management  ››  Overview and sync the devices
  5. Change back the Sync Type to Manual
  6. The changes pending messages should no longer appear

Additional Information
 None.
