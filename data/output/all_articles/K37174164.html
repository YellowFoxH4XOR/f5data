Description

  • BIG-IP configuration is missing with visible GUI error on top of the screen:
The configuration has not yet loaded. If this message persists, it may indicate a configuration problem. is displayed after license re-activation with the automatic method.
  • Error messages in /var/log/ltm:
err mcpd[9860]: 01071772:3: Self device (<your_device_name>) specified floating config sync IP (<config_sync_IP_address>), which is not associated with non-floating traffic group (/Common/traffic-group-local-only). 
err tmsh[17082]: 01420006:3: Loading configuration process failed. 

Environment

  • BIG-IP LTM
  • Self-IP address
  • Loading the configuration
  • After upgrade or license renewal

Cause

If you have configured a config sync IP address used as a floating Self-IP, you may encounter loading config issues, eg. during software upgrades, license renewal, etc.

Recommended Actions

To avoid config loading issues F5 suggest following steps:

  1. Edit bigip_base.conf configuration file located in /config directory.
    Note: You may use any Linux text editor such like VIM, or download bigip_base.conf file directly from BIG-IP to your workstation.
     
  2. Modify related values mentioned in received error message, eg. for load config error message:
    err mcpd[9860]: 01071772:3: Self device (/Common/LTM1) specified floating config sync IP (192.0.2.3), which is not associated with non-floating traffic group (/Common/traffic-group-local-only). 

    Important: This section output contains example configuration. Setup within your environment can be different and you should stick up to yours system config.

    cm device /Common/LTM1 {
        active-modules { "..." }
        base-mac xx:xx:xx:xx:xx:xx
        ...
        chassis-id "your_serial_number"
        configsync-ip 192.0.2.3                    <<<----     Change to non-floating IP address, in presented example it will be 192.0.2.1
    ...
    }

    net self /Common/192.0.2.1 {
        address 192.0.2.1/24
        allow-service {
            default
        }
        ...
        floating disabled
        ...
        partition Common
        traffic-group /Common/traffic-group-local-only
        unit 0
        vlan /Common/Default_VLAN
    }

    net self /Common/192.0.2.3 {
        address 192.0.2.3/24
        allow-service {
            default
        }
        ...
        floating enabled
        ...
        partition Common
        traffic-group /Common/traffic-group-1
        unit 1
        vlan /Common/Default_VLAN
    }
  3. Save configuration changes in bigip_base.conf file on F5 system, and try to load modified configuration using below command:
    # tmsh load sys config

Additional Information

If problem remains after modifying config-sync according to article suggestions, please open Service Order by contacting F5 Networks Support.
