K4379: SNAT pools now use a hash function rather than an ordered list to make matches

Topic

Selective SNAT and Intelligent SNAT features, which are used with SNAT pools, utilize a selection algorithm that is poorly suited for large numbers of addresses. As a result, the Selective SNAT and Intelligent SNAT processes may be slow when used with a SNAT pool that contains a large number of addresses.

F5 Networks Product Development tracked this issue as CR41337 and this feature was optimized for improved performance in BIG-IP version 4.6.3. For information about upgrading, refer to the BIG-IP Release Notes.
