K000156773: Usage reports in NIM UI fail to send

Type
Support Solution
Published
2025-10-02
Updated
2025-10-02
Applies to
  • NGINX Products
  • NGINX Instance Manager: 2.18.0, 2.19.2, 2.19.1, 2.19.0, 2.19.X, 2.18.X, 2.20.0
Source
https://my.f5.com/manage/s/article/K000156773

Description

Attempting to send a Usage Report within the NIM UI fails. The following error may occur:

http failure with unknown error code '6017': Usage data is not available at the moment. Please try submitting usage details again later.

Environment

NGINX Instance Manager

Cause

This error is expected when NIM has no usage data to send

Recommended Actions

No action required

The error message will cease to occur when NIM has received usage data from one or more NGINX Plus nodes

Additional Information

After NIM installation, no usage report will be collected for about an hour or so because usage reporting data aggregation on NIM occurs on an hourly basis

Usage reporting occurs automatically every 24 hours
