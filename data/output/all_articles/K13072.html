Known Issue

The BIG-IP ASM Configuration utility may report an error message when you attempt to save changes on the SMTP Configuration page. This issue occurs when the following condition is met:

  • The BIG-IP ASM system was recently upgraded

On rare occasions following an upgrade, the BIG-IP ASM system is missing a record from the SMTP MySQL table. As a result, you will be unable to configure the SMTP settings using the Configuration utility.

Impact

You will be unable to configure the SMTP settings on the BIG-IP ASM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H380198 on the Diagnostics > Identified > High screen.
  • The Application Security > Options > SMTP Configuration screen in the BIG-IP ASM Configuration utility generates the following error message:

    Could not save SMTP Configuration; Error : Failed update on nonexistent record for SmtpServerSettings found -- update aborted
  • You are unable to configure the SMTP settings

Workaround

To work around this issue, you can restore the default values to the SMTP MySQL table. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP ASM command line.
  2. To access the MySQL database, enter the following command:

    mysql -u root -p$(perl -MF5::GenUtils -e "print get_mysql_password.qq{\n}") -D PLC
  3. Add the missing database entry by entering the following command:

    INSERT INTO `SMTP_SERVER_SETTINGS` VALUES (0,'example.com','admin@example .com','smtp.example.com',25,0,'',NULL,NULL);
  4. Exit the MySQL prompt by entering the following command:

    quit
