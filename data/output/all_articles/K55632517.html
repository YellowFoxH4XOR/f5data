Description

You want to delete one or more persistence entries

Environment

  • BIG-IP LTM
  • Persistence Profile
  • Persistence Records

Cause

None

Recommended Actions

Delete persistence records using the TMOS shell (tmsh).

Impact of procedure: Deleting persistence records without specifying a filter will delete all existing persistence records.

  1. SSH or Console into the BIG-IP.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. View current persistence records by typing the following command:

    show ltm persistence persist-records

    Note: This command displays all persistence records. Narrow the results by filtering for record options such as client or node IP address. Use tab-completion to view available options. For more information, use the help ltm persistence persist-records command.

  4. Use the filter you constructed in the last step to delete the desired records:

    delete ltm persistence persist-records <option>

    For example, to delete all persistence records that originate from the client IP address, 192.0.2.1, use the following command:

    delete ltm persistence persist-records client-addr 192.0.2.1
