Known Issue

Attempts to create a BIG-IP GTM pool may fail.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to create a new BIG-IP GTM pool.
  • The new pool includes a pool member that contains the question mark (?) character.

Impact

Attempts to create new pools fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to create the pool, the Configuration utility displays an error message similar to the following example:

    01070226:3: Pool Member <server name>:<virtual server name> references a nonexistent Virtual Server
  • Error messages similar to the following example appear in the /var/log/ltm file:

    err mcpd[5439]: 01070226:3: Pool Member <virtual server name> references a nonexistent Virtual Server

Workaround

To work around this issue, you can add pool virtual server members with names that contain the question mark (?) character after creation of the pool, or the pool can be created using the Traffic Management Shell (tmsh). To create a BIG-IP GTM pool by using the tmsh utility, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Create the pool by using the following command syntax:

    create /gtm pool <new pool name> fallback-mode <preferred fallback mode> load-balancing-mode <preferred load balancing algorithm> members add { /<partition>/<server name>:<1st virtual server name> /<partition>/<server name>:<2nd virtual server name> { order <numeric value>} } monitor <monitor type> ttl <numeric timeout value>

    For example:

    create /gtm pool xyz_pool fallback-mode drop-packet load-balancing-mode round-robin members add { /Common/Server1:\?Server1_vs /Common/Server2:\?Server2_vs { order 1 } } monitor tcp ttl 30

    Note: Ensure that a backslash (\) character precedes the question mark (?) character in virtual server names.
  3. To save the BIG-IP GTM configuration changes, type the following command:

    save /sys config gtm-only
