Known Issue

The BIG-IP system may not reuse HTTP OneConnect server-side connections for a wildcard non-translating virtual server.

This issue occurs when the following condition is met:

  • The affected virtual server does not use a pool.

If the server-side flow is established without use of a pool, the system disables OneConnect reuse of the server-side connection flow.

Impact

A new server-side connection flow is created for each HTTP request, which results in an increased number of server-side connections.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H502386 on the Diagnostics > Identified > Medium screen.
  • Server-side connection flows for the affected virtual server are not reused.
  • Each HTTP request results in new server-side connection.
  • Target server resources see an increased number of connections.

Workaround

To work around this issue, you can configure the virtual server to reuse connections using an iRule similar to the following:

when HTTP_REQUEST_RELEASE {
if {[HTTP::request_num] == 0} {
ONECONNECT::reuse enable
}
}

Impact of workaround: The impact of the suggested workaround will depend on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
