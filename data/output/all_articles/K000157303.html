K000157303: F5OS-C Controller HA issues due to “etcd-ha-running: false” and Controller Unhealthy Status

Type
Support Solution
Published
2025-11-06
Updated
2025-11-06
Applies to
  • F5OS
  • F5OS-C: 1.6.2
Source
https://my.f5.com/manage/s/article/K000157303

Description


This article addresses an issue observed on F5 VELOS chassis, where the cluster health status reported etcd-ha-running: false, causing HA issues, and in some cases controllers can show high memory utilization and appear unhealthy in logs.You can use the below command to verify etcd-ha state:

# show cluster

If this is our cause, it will look like this:

cluster orchestration-manager cluster-initialized true

cluster orchestration-manager cluster-ready true

cluster orchestration-manager active-node controller-1.chassis.local

cluster orchestration-manager etcd-ha-initialized true

cluster orchestration-manager etcd-ha-running false <--- (!!!)

 

Environment

Cluster orchestration-manager reporting etcd-ha-running: false


Cause

Etcd-ha not running, causing HA issues.


Recommended Actions

Reboot the affected controller (Controller-1) that is exhibiting high memory usage or appears unhealthy.

Rebuild the OpenShift cluster after rebooting the controller, per https://my.f5.com/manage/s/article/K000152701

This can take up to 90 minutes.

Only proceed with upgrades when all indicators confirm healthy cluster status.
