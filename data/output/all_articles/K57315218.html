Description
ASM detected Threat Campaigns and logs been sent to ArcSight remote logging server.
However, when checking from ArcSight remote logging server, there was no information related to what was the name of the ASM Threat Campaigns being detected.

Below is sample extracted from ASM Threat Campaigns log messages when using Arcsight remote logging,
