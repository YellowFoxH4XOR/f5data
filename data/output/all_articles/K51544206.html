Issue

Error Message

notice sod[<PID>]: 010c003e:5: Offline

In this error message, note the following:

  • <PID> is the process ID for the sod process

For example:

notice sod[2658]: 010c003e:5: Offline

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system transitions state as part of the normal boot process.
  • The sod process restarts unexpectedly.
  • An administrator forces the BIG-IP system offline.

Impact

The BIG-IP system is unable to process traffic while in the offline state.

Recommended Actions

If the offline state is unexpected, you can return to an online state using the Configuration utility by clicking Release Offline in the general properties page for the device under Device Management > Devices.

If the sod process is unable to restart properly, you can restart it using the tmsh restart /sys service sod command. If the device remains in the offline state, you may need to restart all services using the tmsh restart /sys services all command.
