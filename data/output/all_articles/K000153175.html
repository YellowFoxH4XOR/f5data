K000153175: Manually Exporting APM Resource Captions (App Tunnels, RDP Sessions, Portal Access) from Customization Groups

Type
Support Solution
Published
2025-08-27
Updated
2025-08-27
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000153175

Description

You may wish to manually export APM resources (such as RDP sessions and App Tunnels) from BIG-IP using CLI commands (e.g., tmsh list apm resource app-tunnel), instead of following the dedicated export at <a href="https://techdocs.f5.com/en-us/bigip-16-1-0/big-ip-access-policy-manager-implementations/importing-and-exporting-access-profiles.html" target="_blank">Importing and Exporting Access Profiles</a>, for documentation or other purposes. The issue is that the "Caption" field associated with each item is not included in the output. The Caption is not stored in the main configuration file (bigip.conf) under the resource object, making it difficult to migrate or merge these items to another platform without manual intervention.

Environment

APM resources with custom Captions

Export of data

Cause

The Caption for each APM resource is not stored directly in the resource definition within bigip.conf. Instead, it is located in a separate file referenced by the "customization-group" object. The customization group points to a cache path under /config/filestore/files_d/Common_d/customization_group_d/ where the Caption is stored in XML format.

Recommended Actions

To export the Caption for each APM resource item:

  1. List all APM resources: Use TMSH or parse bigip.conf to enumerate all relevant resources. example command: tmsh list apm resource portal-access Resourceame 
  2. Identify the customization-group: For each resource, note its associated customization-group from the output.
  3. Locate the cache path: In bigip.conf entry for the customization-group you found in the previous point, find the cache path for each customization group (e.g., /config/filestore/files_d/Common_d/customization_group_d/:Common:Resourcename_resource_web_app_customization_*).
  4. Extract the Caption: Read and parse the XML content of each file at its cache path; locate and extract text within <caption> tags.
  5. Automate extraction: Consider scripting this process to iterate through all resources, resolve their customization group paths, and extract Captions efficiently. This method applies to all supported resource types.

Example XML snippet from cache path file:

<customization_group name="default_resource_web_app" type="resource_web_app">

<item language="en">
<image>/public/images/full_wt/link.png</image>
<caption>TestCaption</caption>
<description></description>
</item>
</customization_group>
