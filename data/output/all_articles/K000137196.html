K000137196: Error when trying to create key with FIPS HSM: Nethsm-partition-name is valid only for NetHSM security-type

Type
Support Solution
Published
2023-10-12
Updated
2023-10-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000137196

Description

New FIPS HSM deployment key creation fails with the following messages appearing in /var/log/ltm.

ltm1.example.com err tmsh[19888]: 01420006:3: Nethsm-partition-name is valid only for NetHSM security-type.

ltm1.example.com err pkcs11d[7707]: 01680048:3: C_GenerateKeyPair for RSA PKCS: pkcs11_rv=0x000000d1, CKR_TEMPLATE_INCONSISTENT      .

ltm1.example.com err tmsh[19943]: 01960005:3: netHSM: Shared memory error [Failed to fetch result].

ltm1.example.com err tmsh[19943]: 01960023:3: fips_get_key_attr(): mod_err = 0xffffffff

ltm1.example.com err tmsh[19943]: error: fips-codec1 Failed to get length of attribute 1 for FIPS key 0. FIPS 0xffffffff : Unknown

ltm1.example.com err tmsh[19943]: 01420006:3: Key management library returned bad status: -18, A vendor error has occurred.

 

Environment

  • External HSM
  • Key creation or key import

 

Cause

The external HSM partition had incorrect security settings.

 

Recommended Actions

Review Manual Chapter: Implementing the SafeNet Luna HSM with BIG-IP Systems and the external HSM manufacturer's configuration guide.

 

Additional Information

None
