K000137898: Duplicated logs sent by BIG-IP to remote syslog server

Type
Support Solution
Published
2024-02-07
Updated
2024-02-07
Source
https://my.f5.com/manage/s/article/K000137898

Description

This article describes the issue, where you want to configure BIG-IP to send logs to remote syslog servers. The goal is to send logs via UDP to one server, and via TCP to another. However, duplicated logs are sent to one remote server using both protocols.

Environment
  • BIG-IP LTM
  • remote syslog servers


Cause

When we add a remote syslog server using the Configuration utility, BIG-IP sends logs to this server using UDP by deafult. 
The same situation is when server is added to the "remote-servers" section via tmsh.

If syslog server is specified in "remote-servers", and additionally is specified as a remote server to receive logs via TCP in "include" section, BIG-IP will send logs to this server using both protocols.
 
Example:
  
list /sys syslog all-properties
sys syslog {
    auth-priv-from notice
    auth-priv-to emerg
    console-log enabled
    cron-from warning
    cron-to emerg
    daemon-from notice
    daemon-to emerg
    description none
    include destination remote_server {tcp("10.10.10.10" port (514));};filter f_alllogs {level (debug...emerg);};log {source(s_syslog_pipe);filter(f_alllogs);destination(remote_server);};
    iso-date disabled
    kern-from debug
    kern-to emerg
    local6-from notice
    local6-to emerg
    mail-from notice
    mail-to emerg
    messages-from notice
    messages-to warning
    remote-servers {
        /Common/remotesyslog2 {
            description none
            host 10.20.20.20
            local-ip ::
            remote-port 5126
        }
        /Common/remotesyslog2 {
            description none
            host 10.10.10.10  <-----
            local-ip ::
            remote-port 514
        }
      }
    user-log-from notice
    user-log-to emerg
}
Recommended Actions
To configure BIG-IP system to send logs to particular remote syslog server using TCP protocol only, do not include the same destination IP in the "remote-servers" section of syslog-ng configuration.
