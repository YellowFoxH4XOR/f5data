Description

  Config-sync works for manually set proxy.port  F5 unable to connect to proxy using the default proxy.port db value of 8080.
   After manually set the proxy.port, BIG-IP syncs it correctly even though it is default value.

Environment

  • proxy.port DB value
  • config Sync

Cause

   Even though there is a default value of 8080 for proxy.port, the db key proxy.port must be manually set to 8080 for the port to take effect.
   Then customer concerns that default value 8080 needs to be manually set again at all HA pair units.

Recommended Actions

Config Sync will sync manually, configure the values for proxy.port, the db key proxy.port and db.
  1. Set the proxy.port to default
    # tmsh modify sys db proxy.port reset-to-default"
    synced to peer, "prox.port default" synce
  2. Set the proxy port value back to 8080
    # tmsh modify sys db prox.port value 8080"
    synced to peer, "prox.port 8080" synced.
When manually configure proxy.port value 8080, config sync will sync this data even though it is a default value.
