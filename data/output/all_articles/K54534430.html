Known Issue

The tmsh list ltm monitor command may return incorrect results.

This issue occurs when all of the following conditions are met:

  • You use the tmsh list ltm monitor command to list monitor configurations.
  • The monitor configuration does not exist; however, the name matches a valid monitor type.
In the following example, a monitor named http of the gateway-icmp type does not exist. However, the tmsh list ltm monitor gateway-icmp http command displays the standard http monitor configuration of the HTTP type.

# tmsh list ltm monitor gateway-icmp http
ltm monitor gateway-icmp http {
adaptive disabled
destination *:*
interval 5
time-until-up 0
timeout 16
user-defined IP_TOS 0
user-defined SEND "GET /\r\n"
}

Impact

The tmsh list ltm monitor command results are incorrect.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the tmsh list ltm monitor command, incorrect results are returned.
