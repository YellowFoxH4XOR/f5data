Description

Unable to log in to GUI with any user, but SSH login works.

Messages similar to the following printed in /var/log/secure or /var/log/httpd/httpd_errors:

alert httpd[12210]: PAM Couldn't open /var/log/pam/tallylog : Permission denied
alert httpd[12210]: pam_tally2(httpd:auth): Error opening /var/log/pam/tallylog for update: Permission denied
info httpd(pam_audit)[12210]: User=admin tty=(unknown) host=10.10.10.1 failed to login after 1 attempts

Environment

  • GUI
  • Authentication

Cause

/var/log/pam/tallylog inaccessible due to incorrect permissions.

Recommended Actions

Verify that permissions and ownership are correct on /var/log/pam/tallylog and parent directories.

Correct permissions, from a BIG-IP running version 16.1.0:

drwxr-xr-x. root root   /var
drwxr-xr-x. root root   /var/log
drwxrwx---. root apache /var/log/pam
-rw-rw----. root apache /var/log/pam/tallylog

Execute the following commands to return ownership and permissions to expected values:

chown root:root /var
chmod 755 /var
chown root:root /var/log
chmod 755 /var/log
chown root:apache /var/log/pam
chmod 770 /var/log/pam
chown root:apache /var/log/pam/tallylog
chmod 660 /var/log/pam/tallylog

If login still does not work, with no other symptoms, install a new boot location and boot into that.

Additional Information

GUI login issues can have numerous root causes. In some cases it's useful to gather an strace of the httpd worker processes while performing a login attempt:

ps aux | grep [/]usr/sbin/httpd | awk '{print"-p " $2}' | xargs strace -Ttv -f -s 1024 -o /var/tmp/httpd_strace.out
