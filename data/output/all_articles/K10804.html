Known Issue

This is the result of a known issue. The FTP monitor initiates a reverse DNS lookup, which must succeed in order for the monitor to succeed. If the host is not included in the BIG-IP /etc/hosts file and the DNS servers specified in the BIG-IP configuration are not available, the FTP monitor will time out and fail. As a result, the server will be marked Down.

F5 Product Development tracked this issue as CR57487 and it was fixed in BIG-IP 9.4.0. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.

Workaround

You can work around this issue by adding the host names and addresses of the monitored FTP servers to the BIG-IP system's /etc/hosts file.

Alternatively, you can apply a different monitor that does not require reverse resolution, such as the TCP monitor.
