Description
In the Configuration Utility, under the Shared Objects menu, there is an Address Lists page but there is no option for the Port Lists page.

Environment

  • BIG-IP version 14.1 or later
  • F5 DDoS Hybrid Defender or BIG-IP ASM license only
  • Configuration Utility ( GUI )

Cause
This is expected behavior. Shared Objects >> Port Lists is no longer shown in the Configuration Utility when the feature is not licensed.

Recommended Actions
None

Additional Information
Port Lists are enabled with an LTM license. On BIG-IP systems with only F5 DDoS Hybrid Defender or BIG-IP ASM license only, Port Lists are not shown on the Configuration utility.
