Known Issue

This is the result of a known issue. If a Windows Vista client enters protected workspace, client certificates installed on the Windows Vista system are not accessible after entering protected workspace. If the user’s master group requires a valid client certificate for authentication, the user cannot log on to the FirePass controller after entering protected workspace.

Note: This issue does not affect clients running other versions of Windows, such as Windows XP.

F5 Product Development tracked this issue as CR89304 and it was fixed in FirePass version 6.1.0. For information about upgrading refer to the FirePass release notes..

Additionally, this issue was fixed in cumulative hotfix HF-602-8 issued for FirePass version 6.0.2 and cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads page.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
