Known Issue

This is the result of a known issue. When the BIG-IP LTM Configuration utility uses external RADIUS authentication, it may make redundant authentication requests. As a result, if you type an incorrect password, it will be sent several times.

If the external authentication server is set to disable an account following multiple incorrect password attempts, it may disable the account.

F5 Product Development tracked this issue as CR44290, CR53955, and CR55152, and it was fixed in BIG-IP LTM 9.1.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
