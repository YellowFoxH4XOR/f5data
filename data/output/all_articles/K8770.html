Known Issue

This is the result of a known issue. Beginning in Hotfix-BIG-IP-9.4.3-HF1 issued for BIG-IP WebAccelerator version 9.4.3, URL normalization for NTLM-authenticated PDF files will fail if the file contains international characters in the filename. International characters are non-English characters, such as accent marks ( ` ).

When the client makes a request for a filename with international characters, the BIG-IP WebAccelerator will download the PDF file from the server and send an HTTP 302 redirect response to the client with the normalized URL. However, when the client sends a request for the normalized URL, the BIG-IP WebAccelerator will send a request with corrupted URL encoding to the server. The server will respond with an HTTP 400 - Bad Request error message to the client.

F5 Product Development is tracking this issue as ID 249036 (formerly CR98146).

Workaround

Disable URL Normalization for the PDF node in a specific acceleration policy

You can prevent requests for PDF files with international characters in the filename from failing by disabling URL normalization for the PDF node in the acceleration policy. To do so, perform the following procedure:

Note: Pre-defined Acceleration policies are not modifiable; this procedure must be performed on a User-defined Acceleration policy.

  1. Log in to the BIG-IP WebAccelerator Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.

    A new Policies Configuration window opens.
  4. Click on the User-defined Acceleration policy to be configured.
  5. Click the + to expand the Site nodes.
  6. Click the + to expand the Static nodes.
  7. Click the + to expand the Documents nodes.
  8. Click on the PDF node.
  9. Select Acceleration Rules from the drop-down menu.
  10. Click on the Assembly menu tab.
  11. Select Advanced from the Content Assembly Options drop-down menu.
  12. In the Advanced Assembly field type the following:

    disableContentBasedIdentity=true
  13. Click the Save button.
  14. Click the Publish button.
  15. Type a comment or note if desired in the Comment field.
  16. Click the Publish Now button.

Note: For information about modifying the contentBasedIdentity settings on a per node basis in the WebAccelerator acceleration policy, refer to K8379: Overview of advanced assembly features for WebAccelerator policies.
