K000137198: AVR Provisioning failed with error 1 - 'Disk limit exceeded. 16188 MB are required to provision these modules, but only XXXX MB are available.'

Type
Support Solution
Published
2023-12-14
Updated
2023-12-14
Source

Description

You want to provision the Application Visibility and Reporting (AVR) module, but you might encounter a similar error message when provisioning it as below:

01071008:3: Provisioning failed with error 1 - 'Disk limit exceeded. 16188 MB are required to provision these modules, but only 4958 MB are available.'


Environment

  • AVR not provisioned
  • BIG-IP VE
  • Disk space


Cause

Insufficient disk space in the /appdata directory.


Recommended Actions

1. Follow the instructions listed in the section "Extending disk space for provisioning multiple modules" of K14952: Extending disk space on BIG-IP VE. to extend the /appdata directory as needed to accommodate the module provisioning.
Note: Do not commit all of the disk resource that you have just added to the BIG-IP VE into extending the directory, as the remaining added disk resource may be required to perform the software installation into a new software slot.

2. Finally, try to provision the AVR module again.
