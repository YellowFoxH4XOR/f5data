Description

This article explains whether IPv6 traffic is allowed or denied when it does not match any configured firewall rule.

Environment

  • F5 Distributed Cloud
    • Routed DDoS
      • IPv6 firewall

Cause

I need to confirm whether IPv6 traffic that does not match any of my configured firewall rules is allowed or denied by default, as the default action is not displayed in the firewall console.

Answer/Recommended Actions

By default, the IPv6 firewall ruleset includes a final rule that allows traffic not matched by any preceding rule. Therefore, the default IPv6 firewall behavior is allow.

To implement a deny policy:

  1. Create explicit allow rules for all required IPv6 traffic.
  2. Add an IPv6 any-to-any deny rule after the required allow rules.
  3. Verify that the rules are in the intended order.

Additional Information

Firewall rules are evaluated in order. When traffic matches a rule, its action is applied, and subsequent rules are not evaluated.
