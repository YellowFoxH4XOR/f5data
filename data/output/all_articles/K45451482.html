K45451482: Unable to remove BIG-IP VE devices from BIG-IQ when BIG-IP devices were deleted

Type
Support Solution
Published
2021-06-07
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K45451482

Description

When removing services, the devices just spin and never complete the remove service task.

Environment

  • BIG-IQ
  • Imported BIG-IP devices that were deleted or otherwise no longer in communication with BIG-IQ

Cause

Unknown at time of publication.

Recommended Actions

In order to force the removal of the BIG-IPs from the BIG-IQ, please use the follow steps:

  1. Log on to the BIG-IQ command line.
  2. Display all discovered BIG-IPs associate to the BIG-IQ:
    restcurl /cm/system/machineid-resolver | jq '.items[] | {uuid,hostname,version,product,managementAddress,selfLink}'

    Example:

    "uuid": "11111111-2222-3a3b-4c4d-555555abcdef",  
    "hostname": "BIG-IP-1",  
    "version": "15.1.2.1",  
    "product": "BIG-IP",  
    "managementAddress": "10.0.0.1",  
    "selfLink": "https://localhost/mgmt/cm/system/machineid-resolver/11111111-2222-3a3b-4c4d-555555abcdef"


  3. Record the UUID of the device you need to remove.
     
  4. Run the following command with replacing <UUID> to remove that device from the BIG-IQ:

    restcurl /shared/resolver/device-groups/ |grep selfLink | grep -o "/shared/.*[[:alnum:]]" | xargs -I {} restcurl -X DELETE {}/devices/<UUID>
    Example:
    restcurl /shared/resolver/device-groups/ |grep selfLink | grep -o "/shared/.*[[:alnum:]]" | xargs -I {} restcurl -X DELETE {}/devices/11111111-2222-3a3b-4c4d-555555abcdef
    Note: Running this will display and scroll several lines to the screen. Let the command run to completion.
