Description

When using the Visual Policy Editor (VPE) in BIG-IP APM, attempting to edit an Access Profile whose name contains the substring "xsl" results in a 404 Not Found error. The URL generated for accessing the VPE is incorrect when "xsl" appears in the Access Profile name. For example, instead of generating a valid path, the system produces a broken link such as:

https://<fqdn>/tmui/Control/jspmap/sam/admin/vpe2/public/php/vpe.php?r[accessPolicyName]=/Common/approfilexslltm

This prevents access to the VPE for affected profiles.

Environment

  • BIG-IP APM
  • Visual Policy Editor (VPE)
  • AP profile with string "xsl" in name

Cause

The substring "xsl" is treated as a reserved keyword by the system's XSL transform process during URL generation for VPE links. If "xsl" is present in an Access Profile name, this process generates an invalid URL path, resulting in a 404 Not Found error when trying to access or edit that profile via VPE.

Recommended Actions

Do not use "xsl" in Access Profile names: When creating new Access Profiles on BIG-IP APM systems, avoid including the substring "xsl" anywhere in the profile name.
