K000132649: SFP Interfaces may fail to come up after software upgrade

Type
Support Solution
Published
2023-02-17
Updated
2023-02-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000132649

Description

After upgrade, you found out that SFP interfaces are down.

Below error message could shown up,


Failed to read pluggable eeprom offset=0 for vendor info (port=6): Operation timed out


Environment

  • LTM
  • SFP interface

Cause

ID1215773 Defective SFP can cause unrelated interfaces to go down

Recommended Actions

  1. Boot back to previous software version then verify which SFP interface is down.
  2. Re-seat faulty SFP and monitor using "tmsh list net interface" to make sure that SFP can be detected properly by BIG-IP.
  3. RMA SFP, if necessary.
  4. Once SFP interface can be detected properly, then attempt to upgrade again.

None
