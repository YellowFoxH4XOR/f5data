K000140240: How to output to kern.log

Type
Support Solution
Published
2024-07-03
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000140240

Description

When you use the logger utility to test SNMP traps, you can't generate a message to /var/log/kern.log.

When you try to generate a message to /var/log/kern.log like the following command, the message appears in /var/log/user.log.

# logger -p kern.warn "kern"

Environment

BIG-IP

Cause

This is by design.

Recommended Actions

If you would like to generate a message to /var/log/kern.log, you can use the following command. 

# echo "<3>TEST" > /dev/kmsg

None
