Description

When viewing Security  ››  Application Security : Policy Building : Traffic Learning in the Configuration Utility, you see learning suggestions which appear to be missing all requests from the event logs which triggered that suggestion. Other learning suggestions may have example violations as expected.

  • There are learning suggestions for categories such as Evasion Technique Detected, HTTP Protocol Compliance Failed, Request length exceeds defined buffer size, Failed to convert character
  • When viewing these suggestions on the Traffic Learning page, it indicates there are many requests that triggered this suggestion but there are no example violations
  • In BIG-IP ASM 13.0 and later, there is a lightning bolt next to the learning suggestion which shows "tightening" when you mouse over it

Environment

  • BIG-IP ASM
  • Security policy has learning enabled for these violations in Policy Building Settings
  • Normal traffic for your application does not trigger false positives for these violations

Cause

This is expected behavior. These are tightening learning suggestions which will increase the security settings as part of policy stabilization. These violations were not enabled in the blocking settings for the policy. Now, enough legitimate requests for this application have been processed that there is confidence that these settings can be enabled without causing false positives. Since legal requests triggered the learning suggestions, there are no example violations to save. 

Recommended Actions

None

Additional Information

You can configure learning for these violations in Security  ››  Application Security : Policy Building : Learning and Blocking Settings. You can configure the tightening settings on the same page by setting the General Settings dropdown menu to "Advanced". Then set the Policy Building Process dropdown menu to "Advanced" and expand the "Tighten Policy (stabilize)" options.
