K000149413: Why does BIG-IQ CM GUI show longer retention for Login logs compared to CLI logs?

Type
Support Solution
Published
2025-01-24
Updated
2025-01-24
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.2.X, 8.3.0, 8.2.0
Source
https://my.f5.com/manage/s/article/K000149413

Description

The user found that the BIG-IQ CM GUI has a longer retention period compared to the CLI logs stored under the "/var/log/" text file and would like to know why.

Environment

  • GUI
  • CLI
  • Login Logs
  • Text file
  • Database
  • Retention period

Cause

  • CLI logs are stored as text files and are subject to quicker rotation.
  • GUI logs are stored in a database, which allows for longer retention.

Recommended Actions

If a longer retention period for CLI logs is required, please consider configuring a Syslog server to which the BIG-IQ can send the logs.
