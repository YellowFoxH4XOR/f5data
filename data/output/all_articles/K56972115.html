Description

You have disabled connection mirroring for a specific virtual server, while there are still mirored connections for the virtual server in connection table.

Environment

  • Virtual Server

  • Connection mirroring

  • Connection Table

Cause

This is by design for BIG-IP LTM system, the mirrored connections will not disappear under this condition until you manually delete them.

Recommended Actions

You can execute command below to delete mirrored connection for a specific virtual server.

# tmsh delete sys connection cs-server-addr <virtual address> cs-server-port <port> type mirror

For example, if the virtual server is 192.168.1.10:80, then the command should be:

# tmsh delete sys connection cs-server-addr 192.168.1.10 cs-server-port 80 type mirror
