Description

AS3 (F5 Application Services Extension) schema supports assigning separate TCP profiles for client-side (ingress) and server-side (egress) connections using the profileTCP object in a Service_HTTPS declaration.

Users may overlook this feature if referencing the wrong schema section.

Environment

  • BIG-IP LTM
  • AS3 (F5 Application Services Extension)

 

Cause

The AS3 schema allows specifying different TCP profiles for client and server connections via the profileTCP object.

This capability may be missed if users reference only the generic TCP profile schema instead of the Service_HTTPS schema documentation.

 

 

Answer/Recommended Actions

Use the profileTCP object in your AS3 Service_HTTPS declaration to assign different TCP profiles for client-side (ingress) and server-side (egress) connections.

 

Example configuration:

 

"profileTCP": {

  "ingress": {

    "bigip": "/Common/tcp-wan-optimized"

  },

  "egress": {

    "bigip": "/Common/tcp-lan-optimized"

  }

}

 

ingress: TCP profile for client-side connections.

egress: TCP profile for server-side connections.
