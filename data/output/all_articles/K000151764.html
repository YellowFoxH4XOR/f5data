Description

In /var/log/ltm you see:

Failed to insert persistence cookie (Server side: vip=/Common/http-vip profile=http pool=/Common/http-pool server_ip=10.2.21.106)

 

The Client connection is RST.

Environment

You are using cookie persistence on a Virtual Server which has the http profile applied in reverse or transparent mode.

Cause

This triggers when the response headers (which include the Set-Cookies) get past about 3.6Kb in size..

Recommended Actions

Ensure HTTP header sizes are within size limits. See K40243113: Overview of the HTTP profile.
