Description

After you initially deploy a BIG-IP tenant from an rSeries, the tenant is unreachable from its management IP network.

Environment

  • F5OS-A

Cause

The BIG-IP tenant's management IP is in a different network than the rSeries management IP.

Recommended Actions

Deploy the BIG-IP tenant with its management IP, prefix-length and gateway in the same network as the rSeries management IP.

If the BIG-IP tenant has been deployed, you can change the following fields to match the rSeries configuration in the GUI:

  1. Go to Tenant Deployments and click on the Tenant's name.
  2. Change the management-ip so that it is on the same range as the rSeries network.
  3. Change the Prefix-length and gateway to match the rSeries configuration
  4. Save & Close the changes
