Issue

Old Behavior

In versions prior to BIG-IP APM 11.5.0, when creating a BIG-IP APM access profile, the General Properties section of the new profile contains only a Name field that the administrator must fill in.

New Behavior

Beginning in BIG-IP APM 11.5.0, when creating a BIG-IP APM access profile, the General Properties section of the new profile contains a Name field that the administrator must fill in and a new Profile Type drop-down menu. Additionally, when editing the access policy with the visual policy editor, the Profile Type selection limits the access profile's available agents and actions to those specifically related to the selected Profile Type.

The Profile Type options include the following:

  • All: For most uses
  • LTM-APM: For web access only
  • SSL-VPN: For remote access only
  • SSO: For single sign-on without an access policy
  • RDG-RAP: For gateway access to hosts for RDP clients
  • System Authentication: For administrator access to the BIG-IP system (when using APM as a pluggable authentication module)
  • SWG-Explicit: For Secure Web Gateway explicit forward proxy
  • SWG-Transparent: For Secure Web Gateway transparent forward proxy
  • Identity Service: Used internally to provide identity service for a supported integration

    Note: The All profile type encompasses SSL-VPN, LTM-APM, and SSO. However, for SSO-only configurations, F5 recommends using the SSO profile type.

F5 Product Development tracked this change as ID 450353.

Impact

When creating new BIG-IP APM profiles, administrators must now select a Profile Type to determine how the BIG-IP APM system will function for that profile.

Recommended Actions

None
