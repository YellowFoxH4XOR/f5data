Known Issue

BIG-IP APM may fail to authenticate when Kerberos AAA servers have different keytab files.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with multiple Kerberos AAA servers that are referenced by multiple access policies.
  • The Kerberos AAA servers are configured with different keytab files.
  • The keytab files are for different service accounts, but for the same realm.

Impact

Users cannot authenticate to the BIG-IP APM system by using Kerberos.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Kerberos authentication fails intermittently when the BIG-IP APM system experiences high load.
  • Messages appear in the /var/log/apm file similar to the following example:

    debug apd[14628]: 01490000:7: modules/Authentication/Kerberos/KerberosAuthModule.cpp func: "display_status_1()" line: 84 Msg: fb2944eb : GSS-API error gss_acquire_cred: d0000 : Unspecified GSS failure.  Minor code may provide more information

Workaround

To work around this issue, you can use the ktutil utility to merge the keytab files into a single, cumulative keytab file, and then configure the Kerberos AAA servers with the new file. To do so, perform the following procedure:

Impact of workaround: This procedure consolidates Kerberos AAA server keytab files into one file, which may not be suitable for all environments. Keytab file changes should be reviewed and tested thoroughly before implementation.

  1. Log in to the BIG-IP APM command line.
  2. Launch the ktutil utility by typing the following command and then pressing the Enter key:

    ktutil
  3. Load all keytab files to merge, individually, by using the following ktutil command syntax:

    rkt <keytab file name>

    For example, to load the example.keytab keytab file, type the following command and then press the Enter key:

    rkt example.keytab
  4. Repeat the previous step for all keytab files that you want to load.
  5. To list currently loaded entries, type l to select list, and then press the Enter key.
  6. After loading all required keytab files, save the consolidated keytab file by using the following command syntax:

    wkt <new keytab file name>

    For example, to save the loaded keytab files into a single file named merged.keytab, type the following command and then press the Enter key:

    wkt merged.keytab
  7. To exit the ktutil utility, type q and then press the Enter key.
  8. You can now configure the Kerberos AAA servers with the newly created keytab file.
