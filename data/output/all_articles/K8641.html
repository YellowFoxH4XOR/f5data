K8641: Configuring the 'Check Responses' setting for the wildcard object type created by the Rapid Deployment security policy template

Topic

The BIG-IP ASM system ships with security policy templates that contain pre-defined security policy configurations. You can use the templates to minimize the complexity of the initial BIG-IP ASM deployment period. When you create a policy using a security policy template, the BIG-IP ASM system automatically populates the security policy with entities that are specific to the corresponding web application.

If you select the Rapid Deployment security policy template when deploying a new security policy, the BIG-IP ASM system creates a wildcard object type entity with the Check Responses setting disabled. As a result, any attack signatures that operate on only server responses are not triggered during deployment.

If you plan to use the Rapid Deployment security policy template when deploying a new security policy, and you want to trigger attack signatures that operate on server responses, you should enable the Check Response setting for the wildcard object type. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. On the Main tab of the Application Security navigation pane, click Policies List.
  3. Click the security policy created by the Rapid Deployment policy template.
  4. Click Object Types in BIG-IP version 9.x; click File Types in BIG-IP version 10.x.
  5. Click the wildcard ( * ) Object/File Type.
  6. Select the Check Response check box.
  7. Click Update.
  8. Click Apply Policy.
