Topic

You can detect Microsoft Windows Vista clients in a pre-logon sequence, and use this information in the pre-logon sequence logic to perform Microsoft Windows Vista-specific actions.

The following procedure configures a pre-logon sequence that sends Microsoft Windows Vista users to the Logon Denied page, while displaying the standard logon page to all other users. You may customize the Logon Denied page with instructions or links for Microsoft Windows Vista users to take appropriate actions, or choose any other set of actions for Microsoft Windows Vista clients. You may also allow Microsoft Windows Vista users to log on to the FirePass controller, instead of presenting the Logon Denied page. However, F5 Networks recommends that you use session variables and Protected Configurations to limit access to resources that support Microsoft Windows Vista.

Detecting Microsoft Windows Vista clients in a pre-logon sequence

To detect Microsoft Windows Vista in a pre-logon sequence, perform the following procedure:

  1. Log in to the FirePass Administrative Console.

  2. Click Users.

  3. Click Endpoint Security.

  4. Click Pre-Logon Sequence.

  5. In the Create new sequence field, enter a name for this Pre-Logon Sequence.

    For example:

    Vista Detection

  6. From the drop-down menu for the Based on field, select template: Empty.

  7. Click the Create button.

    The Vista Detection sequence appears in the Select Sequence to Use section.

  8. Click edit next to the Pre-Logon sequence that you created.

    The Pre-Logon Sequence Editor opens.

  9. Mouse over the Go action.

    A + (plus) link appears to the right of the Go action.

  10. Click the + link.

    The Change Sequence panel opens.

  11. From the drop-down menu for Change sequence, select Insert action.

  12. From the drop-down menu for Using, select One from the list.

  13. Click the button next to Extended Windows and IE info.

  14. Click the Apply changes button at the bottom of the page.

    The Extended Windows and IE info Inspector appears in your pre-logon sequence.

  15. Mouse over the fallback rule to the right of the Extended Windows and IE info box in the updated sequence.

    A + link appears to the left of the fallback rule.

  16. Click the + link.

    The Insert Rule panel opens.

  17. Type a name In the name field.

    For example:

    check-for-vista

  18. Below the name field, type the following rule:

    session.os.platform=="WinVI"

    Note: You can create a check-for-vista rule and insert it into any existing pre-logon sequence you may have already configured.

    Note: The session.os.platform session variable may be used in a Protected Configuration to deny access to resources not appropriate for Microsoft Windows Vista users.

  19. Click the Insert Rule button at the bottom of the page.

    The check-for-vista rule appears in your pre-logon sequence. Also, the Logon Denied Page option appears directly behind the rule, and the Logon Allowed Page option is now directly behind the fallback rule.

  20. Click the Update button at the bottom of the page.

  21. Click the Back to Console link at the top right corner of the page.

    The Pre-Logon Sequence main page appears.

  22. Click the button next to the Vista Detection sequence you have just created.

  23. Click the Apply button.

Users running Windows Vista will now be directed to the Logon Denied page when they attempt to logon to the FirePass controller.
