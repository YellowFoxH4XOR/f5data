K10664: Windows 7 clients are not detected by the Check OS pre-logon inspector

Type

Published
2011-05-19
Updated
2023-02-21
Status

Applies to

  • FirePass: 7.0.0, 6.1.0, 6.0.3
Source

Topic

Support for Microsoft Windows 7 was introduced in FirePass 6.1.0 and in FirePass version 6.0.3 with cumulative hotfix HF-603-4.1. If you create a pre-logon sequence with the Check OS inspector after upgrading to version 6.1.0 or later, or after installing HF-603-4 or a later version of the cumulative hotfix on version 6.0.3, Windows 7 is correctly detected by the Check OS inspector.

Important: The Check OS inspector is automatically added to the pre-logon sequence if you selected the AV check or AV and Firewall template when creating the pre-logon sequence.

However, if the Check OS inspector was already configured prior to upgrading to version 6.1.0 or later, or prior to installing HF-603-4 or a later version of the cumulative hotfix on version 6.0.3, the Check OS inspector does not detect Windows 7 clients. Instead, the Check OS inspector directs Windows 7 clients to the fallback rule, which in a default configuration directs them to the Logon Denied page.

To add Windows 7 to the Check OS inspector, perform one of the following two procedures: 

  • If you selected the AV check or AV and Firewall template when creating the pre-logon sequence, perform the procedure Adding Windows 7 to a pre-logon sequence which uses the "AV check" or "AV and Firewall" template.
  • If you selected any other template when creating the pre-logon sequence, perform the procedure Adding Windows 7 to the Check OS inspector.

Adding Windows 7 to a pre-logon sequence that uses the AV check or AV and Firewall template

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. Next to the pre-logon sequence you want to configure, select the edit or backup & edit link.
  4. If you want to add Windows 7 to the existing Windows Vista rule, perform the following steps:
    1. To the right of the Check OS action, click Windows Vista.
      The Update Rule panel opens.
    2. In the Update Rule panel, change the Name field from:

      Windows Vista

      to:

      Windows Vista and Windows 7
    3. Change the rule expression from:

      session.os.platform == "WinVI"

      to:

      session.os.platform == "WinVI" OR session.os.platform == "Win7"
    4. Click the Update button.

      Windows 7 clients will now be directed to the actions configured for Windows Vista clients.
  5. Alternately, if you want to configure a separate rule for Windows 7, perform the following steps:
    1. To the right of the Check OS action, click the plus (+) icon.
      The Insert Rule panel opens.
    2. In the Insert Rule panel, enter Windows 7 in the Name field.
    3. In the text area below the Name field, enter the following expression:

      session.os.platform == "Win7"
    4. Click the Insert Rule button.
      The Windows 7 rule is added to the Check OS action, and the Windows 7 rule leads to the Logon Denied Page endpoint. If you want Windows 7 clients to be directed to the Logon Denied page, this procedure is complete. If you want to assign the Windows subsequence to the Windows 7 rule, proceed to the next step.
    5. To the right of the Windows 7 rule, click the plus (+) icon.
      The Change Sequence panel appears.
    6. In the Change sequence menu, select Replace action.
    7. Select the Subsequence: windows option button.
    8. Click the Apply changes button.

      Windows 7 clients will now be directed to the Windows subsequence for additional pre-logon checks.

Adding Windows 7 to the Check OS inspector

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. Next to the pre-logon sequence you want to configure, select the edit or backup & edit link.
  4. To the right of the Check OS action, click the Windows NT based rule.
    The Update Rule panel opens.
  5. In the text field in the Update Rule panel, add the expression session.os.platform == "Win7" OR (including a space after OR) to the beginning of the existing expression.

    For example:

    session.os.platform == "Win7" OR session.os.platform == "WinVI" OR session.os.platform == "WinXP" OR session.os.platform == "Win2000" OR session.os.platform == "WinNT"
     
  6. Click the Update button.
 
The Check OS inspector now applies the Windows NT based rule to Windows 7 clients.
