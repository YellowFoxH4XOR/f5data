Description

GTM auto discovery missing TCP + UDP virtual when BIG-IP DNS system's LTM server object is using virtual server discovery and discovered two of the same IP:PORT virtual servers with different protocols (TCP and UDP).
 

Environment

  • BIG-IP DNS
  • TCP and UDP
  • Multiple Virtual Servers with same IP:PORT
  • LTM 

Cause

If virtual servers using the same IP:PORT with different protocol, and were not discovered at the same time, BIG-IP DNS will only add the first virtual server.

Recommended Actions

1) Create all needed virtual servers on LTM.
2) If only one virtual server were discovered earlier, manually remove that virtual server from the list of discovered virtual server on BIG-IP DNS.
3) During next auto discovery, BIG-IP DNS should discover both the virtual servers.
