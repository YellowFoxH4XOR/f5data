Known Issue

The BIG-IP system may not honor Lightweight Directory Access Protocol (LDAP) STARTTLS on the server-side connection.

This issue occurs when all of the following conditions are met:

  • You configure the LDAP virtual server with both client and server LDAP profiles.
  • You configure LDAP profiles with the STARTTLS Activation Mode option set to Allow.
  • You configure the LDAP virtual server with a persistence profile.

Impact

Server-side LDAP traffic is not encrypted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H593228 on the Diagnostics > Identified > Medium screen.
  • Server-side LDAP traffic does not use TLS.
