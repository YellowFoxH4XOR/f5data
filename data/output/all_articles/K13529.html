Known Issue

The BIG-IP system may fail to load the configuration when a TCP profile contains a custom Maximum Segment Retransmissions or Maximum Syn Retransmissions setting.

This issue occurs when the following conditions are met:

  • The system is upgraded from a BIG-IP version 10.x system containing a TCP profile with a Maximum Segment Retransmissions or Maximum Syn Retransmissions value of more than 12.
  • A version 10.x UCS archive file containing a Maximum Segment Retransmissions or Maximum Syn Retransmissions TCP profile value of more than 12 is installed on the system.

The Maximum Segment Retransmissions setting specifies the maximum number of times that the BIG-IP system resends data segments. The Maximum Syn Retransmissions setting specifies the maximum number of times that the system resends a SYN when it does not receive a corresponding SYN-ACK. In BIG-IP version 10.x, the TCP profile supports values of more than 12 for either setting. Starting in version 11.x, the TCP profile supports values up to 12.

Impact

The BIG-IP system fails to load the configuration.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The upgrade process completes, but the BIG-IP configuration fails to load.
  • The UCS archive fails to properly install.
  • When installing a UCS archive, the system detects errors and reports an error message that appears similar to the following example:

    WARNING: There were one or more errors detected during installation.
             Check the error messages and take the proper actions if needed.
    ERROR: UCS installation failed.
    Operation aborted.
    /tmp/configsync.spec: Error installing package
    Config install aborted.
    Unexpected Error: UCS loading process failed.

  • The system generates error messages to the /var/log/ltm file that appear similar to the following example:

    err mcpd[4377]: 01070618:3: The requested max retrans (16) for TCP profile (/Common/max_seg_16) is invalid.  [0..12]
    err load_config_files: "/usr/libexec/bigpipe load" - failed. -- BIGpipe TCP profile creation error:    01070618:3: The requested max retrans (16) for TCP profile (/Common/max_seg_16) is invalid.

Workaround

If you have installed a UCS, or upgraded from a BIG-IP version 10.x system containing a TCP profile with a Maximum Segment Retransmissions or Maximum Syn Retransmissions value of more than 12, and the configuration fails to load, you can work around this issue by changing the value(s) to 12 or less on the affected system. To do so, perform the following procedure:

Note: To avoid this issue, before you upgrade, change the Maximum Segment Retransmissions or Maximum Syn Retransmissions value to 12 or less for any TCP profiles.

Impact of workaround: None

  1. Log in to the command line.
  2. Use a text editor to edit the /config/bigpipe/bigip.conf file.

    For example:

    vi /config/bigpipe/bigip.conf

  3. Change the Maximum Segment Retransmissions or Maximum Syn Retransmissions value to 12 or less for any TCP profiles.

    For example, in the below profile, change max retrans to a value of 12 or less:

    profile tcp max_seg_20 {
    defaults from tcp
    max retrans syn 3
    max retrans 20
    }

  4. Save the changes and exit the file.
  5. Load the configuration by typing the following command:

    Important: You should use the below command only when instructed to do so in an article or by F5 Technical Support.

    /usr/libexec/bigpipe daol

  6. Use tmsh to save the configuration by typing the following command:

    tmsh save /sys config partitions all

  7. Use tmsh to load the configuration by typing the following command:

    tmsh load /sys config partitions all
