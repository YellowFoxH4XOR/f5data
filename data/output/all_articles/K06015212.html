Description

You would like to know if the firewall logs (Security ›› Event Logs : Network : Firewall) can be viewed from the command line, or logged locally to a file.

Environment

  • Network firewall
  • Logging

Cause

None

Recommended Actions

You can log the firewall events locally, but with limitations.

It is possible to log the firewall logs to /var/log/ltm if you set the publisher in the respective log profile to sys-db-access-publisher.

Here is an example log:

info tmm[17924]: 23003137 "192.168.1.199","bigip1.afm","Global","/Common/global-firewall-rules","No-lookup","10.10.10.78","No-lookup","10.10.10.45","51054","80","/Common/External","TCP","0","","","","","","","","Enforced","/Common/main_policy","reject_rule","","Reject","Policy","","","0000000000000000","unknown","unknown","unknown","unknown","","","","","No-lookup","No-lookup"

Unfortunately, you can't log to both the network firewall event logs and /var/log/ltm at the same time, from the same context / object. For example you can only set a single publisher in a log profile, and you cannot apply two log profiles that publish to the two different destinations.

If the event logs are being published to local-db-publisher (and therefore visible in the GUI at Security ›› Event Logs : Network : Firewall), they are stored in the logdb MySQL database and there isn't a supported mechanism for accessing them.

Additional Information

It's recommended to send the logs to a dedicated SIEM device if possible.
