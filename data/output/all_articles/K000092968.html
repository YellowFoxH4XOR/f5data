K000092968: Determine the right parameters from Management CLI when constructing REST API calls

Type
Support Solution
Published
2022-12-05
Updated
2022-12-06
Source
https://my.f5.com/manage/s/article/K000092968

Description

You should consider using these procedures under the following condition:

  • You would like to find out what are the correct parameters to use for your REST calls when referencing the F5OS API documentation.

Environment

  • F5OS
  • Management CLI
  • RESTCONF
  • REST API calls

Cause

None

Recommended Actions

Using the following task as an example:
  • Determine the path parameters to use in the REST call that will show the status of a remote file transfer.
1. From the F5OS API documentation at the time of publication of this solution, the path parameters required are as follows:
https://clouddocs.f5.com/restconf/data/f5-utils-file-transfer:file/transfer-operations/transfer-operation={transfer-operation-local-file-path},{transfer-operation-remote-host},{transfer-operation-remote-file-path},{transfer-operation-operation},{transfer-operation-protocol}/status
Where:
transfer-operation-local-file-path refers to local file path.
transfer-operation-remote-host refers to remote host.
transfer-operation-remote-file-path refers to remote file path.
transfer-operation-operation refers to file transfer operation such as file import, file export file delete.
transfer-operation-protocol refers to file transfer protocol supported protocol such as SCP, HTTPS, SFTP.
 
2. The following procedure assumes that a remote file transfer operation is taking place or already have been completed.
Run the following command from Management CLI and use the display format restconf:
Appliance-1# show file transfer-operations | display restconf 
/restconf/f5-utils-file-transfer:file/transfer-operations/transfer-operation=images%2Ftenant%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,192.168.0.1,images%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,Import%20file,HTTPS%20%20%20/status "In Progress (76.0%)"

3. From the output shown in Step 2 the required path parameters for the REST call are:
transfer-operation-local-file-path  images%2Ftenant%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle
transfer-operation-remote-host  192.168.0.1
transfer-operation-remote-file-path   images%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle
transfer-operation-operation  Import%20file
transfer-operation-protocol   HTTPS%20%20%20

4. Using the REST API Server URL from Step 1 and the table from Step 3, construct the correct path to retrieve the status of the remote file transfer:
https://<F5OS management IP>:8888/restconf/data/f5-utils-file-transfer:file/transfer-operations/transfer-operation=images%2Ftenant%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,192.168.0.1,images%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,Import%20file,HTTPS%20%20%20/status

Additional Information

The following uses Curl as a client for sending the REST calls.
1. When the REST API call is sent without any Content-Type header, the response from F5OS REST API is in XML:
$ curl -k -u admin:admin https://<F5OS management IP>:8888/restconf/data/f5-utils-file-transfer:file/transfer-operations/transfer-operation\=images%2Ftenant%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,192.168.0.1,images%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,Import%20file,HTTPS%20%20%20/status 
<status xmlns="http://f5.com/yang/utils/file-transfer"  xmlns:f5-utils-file-transfer="http://f5.com/yang/utils/file-transfer">In Progress (4.0%)</status>

2. When the REST API call is sent with a Content-Type header with the value application/yang-data+json, the response the F5OS REST API is in JSON:
$ curl -k --header "Content-Type: application/yang-data+json" -u admin:admin https://<F5OS management IP>:8888/restconf/data/f5-utils-file-transfer:file/transfer-operations/transfer-operation\=images%2Ftenant%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,192.168.0.1,images%2FBIGIP-15.1.6.1-0.0.10.ALL-F5OS.qcow2.zip.bundle,Import%20file,HTTPS%20%20%20/status 
{
  "f5-utils-file-transfer:status": "In Progress (1.0%)"
}
