K9194: Some blocked requests are not sent to syslog-ng

Topic

By default, when BIG-IP ASM blocks a request, information about the blocked request is logged to the local MySQL database, and can be viewed on the Reporting screen of the Configuration utility.

If the Alarm check box is selected for the violation on the Blocking screen, information about the blocked request is also sent to the BIG-IP syslog-ng protocol through the local3 facility, and can be viewed in the /var/log/asm file.

Note: If BIG-IP ASM blocks a request and the Alarm check box is not selected for the violation, information about the blocked request is not logged to the /var/log/asm file. However, the request information can still be viewed on the Reporting screen.

If you want information about blocked requests to be sent to the BIG-IP local3 syslog-ng facility, ensure that the Alarm check box is selected for the specific violation.

F5 Product Development is tracking a feature enhancement as CR106646 to automatically select the Alarm check box for violations for which Block is enabled.
