You have run a security scan against your applications protected by ASM and it has reported that there is a vulnerability with an ASM cookie:

Cookie Overly Broad Path Detected

Environment

  • Security Policy
  • Cookies

Cause

This is caused by the ASM Main cookie. This cookie has an explicitly defined / path because it is used by many ASM functions. If this path was changed or removed, browsers may not send the cookie, and this would affect a lot of functionality - for instance, domain cookie validation.

Here is an example ASM main cookie returned by the BIG-IP:

Set-Cookie: TS01dae6d9=01a6908db4d44a739781eadae933221c456fa716f5c7f60d50c90ad5b881f48476c5fb550203ba42b7bb2293458f5af5778908b731104509a49dce6d7ca41011dbdfe943385a736c7aaf0456d73e5aa5b9c4e6e909c1a0d3821652fd94d33d181a3fc65103; Path=/; Domain=.example.com

Recommended Actions

None. It's not recommended to modify the path of the ASM Main cookie, as this will break ASM features that protect the application. Furthermore, ASM cookies are themselves validated by ASM, when the Modified ASM Cookie violation is enabled.
