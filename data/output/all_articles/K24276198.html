Known Issue

After you upgrade the system, the configuration load fails due to pool member validation.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP DNS system (formerly known as BIG-IP GTM) is running 11.x.
  • You configure your BIG-IP DNS system with a pool that uses the CNAME type.
  • The pool contains pool members specified with a CNAME that uses a trailing dot (Period character) in the CNAME.

    For example, the CNAME below has a trailing dot:

    a.cname-ending-with-a-dot.com.

  • You upgrade to a version that is affected with this issue.

Impact

The configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you upgrade the device, the system fails to load the configuration and displays an error message similar to the following example:

    0107019a:3: Wide IP or alias (<pool cname member>) entered is not a fully qualified domain name or contains invalid characters. Additional character support can be enabled by modifying the Domain Name Check settings.
    Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can manually modify the affected pool member configuration by removing the trailing dot, or you can change the global setting for Domain Validation to None and load the configuration. To set Domain Validation to None, perform the following procedure:

Impact of workaround: BIG-IP traffic processing is temporarily disrupted while the configuration loads.

  1. Log in to the command line of the BIG-IP DNS system.
  2. Using a text editor, open the /config/bigip_gtm.conf file.
  3. Place the following stanza lines at the very top of the configuration:

    gtm global-settings general  {
           domain-name-check none
    }

  4. Save the configuration file changes.
  5. To load the BIG-IP DNS configuration, type the following command:

    tmsh load /sys config gtm-only

    Note: For BIG-IP devices with multiple modules, use the following command to load the entire system configuration:

    tmsh load /sys config
