Known Issue

This is the result of a known issue. In versions 10.1.0 and 10.2.0, BIG-IP ASM policies created with the ActiveSync rapid deployment template may incorrectly process requests containing null bytes. As a result, the BIG-IP ASM system may drop, prematurely close, or otherwise improperly process connections.

F5 Product Development is tracked this issue as ID 338221 and it was fixed in BIG-IP versions 10.2.1 and 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue was also fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
