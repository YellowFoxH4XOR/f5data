Known Issue

This is the result of a known issue. In the FirePass Administrative console, the drop-down menu on the Reports: HTTP Logs page is not working properly.

If you select Server access log (http) from the menu, you will receive the following error message:

unable to open extra-access_log

If you select Server access log (https) from the menu, you will receive the following error message:

unable to open https.extra-access_log

F5 Product Development tracked this issue as CR73418, and it was fixed in FirePass versions 6.0.2 and 6.1.0. For information about upgrading, refer to the FirePass release notes.

Important: However, upgrading to FirePass version 6.0.2 may introduced a new issue. For more information, refer to K9562: The Administrative Console may not accurately reflect the state of the log engine.
