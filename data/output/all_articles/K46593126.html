Description

When ASM encounters a cookie name consisting of a whitespace, the Cookie not RFC-compliant violation will be raised. If a situation arises where this violation doesn't have block setting enabled, the following behavior is observed in versions prior to and after v14:

  • Prior to v14, this raw request consisting of this cookie name will be sent to the application.
  • From v14 and above releases, the cookie name consisting of the whitespace is truncated and the rest of the raw request content is not send to the application. 

Environment

  • BIG-IP ASM: 14.x - 16.x
  • The Cookie not RFC-compliant violation does not have Block setting enabled within Security  ››  Application Security : Policy Building : Learning and Blocking Settings
  • ASM receives a request consisting of a cookie name that contains a whitespace

Cause

The behavior from v14 and above releases is as a result of stricter RFC compliance checks enforced upon the requests by bd process. However, the cookie name being truncated at the whitespace and rest of raw request not sent to the application when Cookie not RFC-compliant violation doesn't have block setting enabled is due to a known issue tracked by Product Development as ID1090541.

The cookie name consisting of a whitespace is still in violation of RFC6265, so the request should not be sent to ASM with cookie consisting of a whitespace.

Recommended Actions

The recommendation is to address this issue at the application level to ensure a cookie name doesn't consist of a whitespace. If this isn't feasible, then you can modify the asm.strip_asm_cookies database variable and revert the ASM cookie behavior as prior to version 14.0.0 so the ASM cookies are left intact and passed to origin web server. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:
    tmsh

  2. To modify the system database variable and allow ASM cookies to pass to OWS, type the following command:
    modify /sys db asm.strip_asm_cookies value false

  3. To verify the modified system database variable, type the following command:
    list /sys db asm.strip_asm_cookies
