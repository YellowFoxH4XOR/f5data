Topic

The size and MD5 value of a BIG-IP system ISO image may change after you perform a clean software installation.

Description

After you complete a clean BIG-IP system software installation from an ISO image, you may notice that the installation ISO file size and MD5 digest values changed. This is because a clean installation wipes all data on the system and restores the BIG-IP system to its factory default settings, which does not occur when you upgrade boot locations using the tmsh install /sys software command or when you install software using the Configuration utility.

For example:

  1. You download the BIGIP-11.6.0.0.0.401.iso file from the F5 Downloads site and then upload the file to the /shared/images directory of the BIG-IP system. The size and MD5 value of the file display as follows:

    ls -l --block-size=MB BIGIP-11.6.0.0.0.401.iso
    -rw-r--r-- 1 root root 1956MB Dec 18 12:20 BIGIP-11.6.0.0.0.401.iso

    md5sum BIGIP-11.6.0.0.0.401.iso
    5a4fda25c0c40bd7c132b001a17e055b BIGIP-11.6.0.0.0.401.iso

  2. You perform a clean installation of BIG-IP 11.6.0 using a method such as a employing a bootable USB thumb drive or image2disk with the --format option.
  3. After the installation completes, the /shared/images directory includes a smaller version of the BIG-IP 11.6.0 ISO image, but with the same file name. The size and MD5 value of the new file displays as follows:

    ls -l --block-size=MB BIGIP-11.6.0.0.0.401.iso
    -rw-r--r-- 1 root root 1953MB Dec 18 11:35 BIGIP-11.6.0.0.0.401.iso

    md5sum BIGIP-11.6.0.0.0.401.iso
    56eaf00acc1f3e39828e2a74be45a02f BIGIP-11.6.0.0.0.401.iso

This behavior is expected. During the installation, the ISO image is unpacked and then repacked specifically for the upgraded BIG-IP system. This process can alter the installation ISO file size and MD5 digest values. Additionally, the file size and MD5 value of ISO images created during installations may also vary between systems. The repacked ISO image is valid, and you can use it for additional installations on other software slots.
