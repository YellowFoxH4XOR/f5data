Description

PEM's URL Filtering has a limited license period. If the license expires without renewal, then services can be interrupted.
This document describes the creation of a custom SNMP OID that returns the number of days validity remaining on a PEM license.
This can be used to trigger alerts from an SNMP monitoring tool when this value is close to zero.

Environment

  • BIG-IP PEM's URL Filtering license
  • SNMP OID

Cause

Need to configure alert for reaching the license's expiration date

Recommended Actions

To configure a custom SNMP OID that returns the number of days validity remaining on a Secure Web Gateway license, perform the following procedure:

  1. Log in with administrative privileges to the command line of the target device.
  2. Using a text editor, create the following file
    /config/snmp/url_days_to_expiry.sh
  3. Enter the following command syntax into the /config/snmp/url_days_to_expiry.sh file
    #!/bin/sh
    # return the number of days validity remaining on a PEM URL FILTERING
    # return 0 if the license is expired
    # return -1 if no PEM license is found

    pem=$(tmsh show sys license | grep -i "PEM URL Filtering")
    if [[ $? -eq 0 ]]
    then
      result=$(( ($( date +%s -d $( echo $pem | cut -f4 -d"|" )) - $(date +%s)) / 86400 ))
      if [[ $result -lt 0 ]]
      then
        result=0
      fi
    else
      result=-1
    fi
    echo $result
  4. Save the changes
  5. To change the file permissions, type the following command:
    chmod 755 /config/snmp/url_days_to_expiry.sh
  6. Using a text editor, create the following file:
    /config/snmp/custom_mib.tcl
  7. Enter the following command syntax in the /config/snmp/custom_mib.tcl file:
    register_mib ".1" urlpem_days_to_expiry GAUGE
        proc urlpem_days_to_expiry {} {
            set status [catch { exec /bin/bash /config/snmp/url_days_to_expiry.sh } result]
            return $result
        }
  8. Save the changes.
  9. To restart the SNMP service, type the following command:
    tmsh restart /sys service snmpd
  10. Validating the workaround is functional, type the following command from CLI:
    snmpwalk -Os -c public -v 2c localhost .1.3.6.1.4.1.3375.2.100.1
    Expected result: bigipTrafficMgmt.100.1.0 = Gauge32: 30

    From the result, we have 30 days for license expiration.
