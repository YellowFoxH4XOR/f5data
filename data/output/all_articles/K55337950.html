Description

  • While trying to reconfigure an iApp, the BIG-IP system shows an error similar to this:

notice scriptd[25171]: 014f0005:5: AUDIT - user=admin action="run template script: /Common/<iapp name> /Common/<iapp name>/<iapp name>" status="script did not successfully complete: ("<object variable>" unexpected argument

Example:
14f0005:5: AUDIT - user=admin action="run template script: /Common/example_iapp.app /Common/example_iapp.app/example_iapp.app" status="script did not successfully complete: ("cookie" unexpected argument     while executing "tmsh::create [string range $args 7 end] "

 

Environment

  • BIG-IP LTM
  • Reconfiguring iApp

Cause
The scriptd process runs application template implementation scripts when an application service is created or updated, in rare conditions scriptd is unable to parse the information generating the log error "script did not successfully complete".

Recommended Actions

  1. If the device is in HA, verify if the iApp can be reconfigured in the other peer
  2. If you identify this issue only occurs in one peer, restart scriptd. To do so, perform the following procedure
    1. Log in to the Traffic Management Shell (tmsh) as an administrative user.
      # tmsh
    2. Type the following command:
      # restart sys service scriptd
