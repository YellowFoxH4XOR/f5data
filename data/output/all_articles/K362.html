Topic

To make a 3-DNS Controller authoritative for a specific domain (that is, mydomain.com) you must add the 3-DNS Controller to the zone file for the local domain as each of the following records:

  • A (address) record
  • NS (nameserver) record

For example:

86400   IN      NS      3dns01

3dns01  86400   IN      A       10.10.20.30

The preceding zone file example shows the NS record and the A record for the server 3dns01. For specific details on how to create this zone file, please refer to your 3-DNS Controller manual.

To create a zone using NameSurfer (NameSurfer is configured during the first time boot/setup utility), perform the following steps:

  1. From the 3-DNS Configuration utility menu, click NameSurfer.
  2. Type your username and password.
  3. From the Create zone section, click Empty zone.

    Note: If the zone you are creating already exists on another name server, select Copy from other name server instead.

  4. Fill in the required fields. Refer to the online Help if you require assistance.
  5. In the Authoritative name servers (NS) field, type the name of the 3-DNS you wish to use as the host (i.e. 3dns01.mydomain.com).
  6. Select the zone you created and create the appropriate A record in the Add section by selecting Host and filling in the information for the authoritative NS you created (3dns01.mydomain.com). This will notify requesting DNS servers that the 3-DNS you specified is authoritative for the domain. Refer to the online Help if you require assistance.
  7. If necessary, register the 3-DNS as an authoritative DNS server with your domains' registrars. If this is a subdomain of a registered DNS server, you can delegate authority from one of your existing domain servers to this subdomain (for example, subdomain.mydomain.com).
