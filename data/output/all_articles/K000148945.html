K000148945: APM statistics not visible in BIG IQ Monitoring tab

Type
Support Solution
Published
2024-12-11
Updated
2026-01-14
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000148945

Description

You would like to have APM statistics visible in BIG IQ "Monitoring" tab, but nothing seems to be send from BIG IP. You may also notice similar logs on BIG IQ to:

[WARN][10 Dec 2024 14:27:59 CEST][/cm/access/oauth-profile-stats-collector OAuthProfileStatsCollectorWorker] Failed to complete stats collection for device 10.0.0.1.
[WARN][10 Dec 2024 11:12:59 CEST][/cm/access/session-stats-collector SessionStatsCollectorWorker] Failed to complete stats collection for device 10.0.0.2.

Environment

  • BIG IQ
  • BIG IP APM with AVR provisioned

Cause

BIG-IQ needs AVR to work properly and AVR is a module that requires a lot of resources (memory and CPU, so your BIG IP might be out of resources.

Recommended Actions 

Check the memory available in  BIG-IP and add more memory to management and restjavad:

tmsh modify /sys db provision.extramb value 1024
tmsh modify sys db provision.restjavad.extramb value 500
bigstart restart restjavad

Important: The BIG-IP system experiences a temporary traffic interruption as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over. F5 recommends changing the Management memory size allocation during a scheduled maintenance window.
