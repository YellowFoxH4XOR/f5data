Known Issue

This is the result of a known issue. If you create a UCS archive from the command line, you will not be able to restore or download the UCS archive from the Configuration utility.

For example:

  • You connect to the BIG-IP system command line
  • You create a UCS archive by typing the following command:

    bigpipe config save /var/local/ucs/backup.ucs
  • You connect to the BIG-IP system Configuration utility
  • You navigate to System >> Archives
  • You click on the UCS archive previously created on the command line
  • The Configuration utility displays the following error message:

    General database error retrieving information.

This issue occurs because beginning in BIG-IP version 10.2.1, the default file creation mask of the shell process was modified to allow for greater security. As an inadvertent result of this change, the Configuration utility has no access rights to UCS archives created from the command line.

Note: For more information about the aforementioned change in behavior, refer to K12606: Change in Behavior: The default file creation mask of the shell process is now 077.

F5 Product Development tracked this issue as ID 350370 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Workaround

You can work around this issue by modifying the permissions of the UCS archive before attempting to restore or download it via the Configuration utility. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Change the permissions of the UCS archive to rw-r--r-- (644) using the following command syntax:

    chmod 644 /var/local/ucs/<filename>.ucs

    For example:

    chmod 644 /var/local/ucs/backup.ucs

You can now log on to the BIG-IP system Configuration utility and proceed restoring or downloading the UCS archive.
