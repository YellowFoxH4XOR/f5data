Known Issue

This is the result of a known issue. When adding a server to a Data Center, that contains 1000 or more defined servers, you may receive the following error message:

Error 331781 -- Memory error. Could not create Data Center Server object

3-DNS and the BIG-IP Link Controller will display this error message if the Configuration utility runs low on memory while it is modifying a Data Center that contains a large number of objects.

This message does not necessarily indicate that 3-DNS or the BIG-IP Link Controller failed to add the new object.

F5 Networks Product Development tracked this issue as CR28228, CR28529, and CR41837.
