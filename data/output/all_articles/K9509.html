Issue

Configuration entries, such as SNMP administration information that contain single quote  ( ' ), double quote ( " ), and back tick ( ` ) characters cause the following error message to log to the console when the configuration is loaded:

BIGpipe unknown operation erro
 
01070920:3: Application error for confpp:
*************************************************************
localhost confpp[2564]: confpp: invalid character input found

For example, the following snmpd syslocation value will generate the confpp error message:

syslocation "AskF5 BIGIP's"

This issue may occur under the following circumstances:

  • Changing the files manually and then loading them
  • Upgrading from a version prior to version 9.4.5
  • Installing a UCS file that was created prior to version 9.4.5.

This error message occurs due to the following fix that was introduced in BIG-IP version 9.4.5:

Directory traversal vulnerability CVE-2008-0481 (CR97806)
This release fixes a directory traversal vulnerability tracked by the Common Vulnerabilities and Exposures (CVE) project, which assigned the ID CVE-2008-0481 to the problem. For more information about the vulnerability, see CVE-2008-0481.

If you receive this error message, review your configuration for any of the following characters specified at the beginning of this Solution and remove them before you reload the configuration.
