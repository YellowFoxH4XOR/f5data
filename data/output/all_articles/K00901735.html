Description
When Syncookie activation is triggered the MSS values seen on TCP connections may not be the size expected.

NOTE: This behaviour may apply to AFM TCP Half Open Vector because it also uses syn-cookies.

Environment

  • BIG-IP
  • SYN Cookie
  • AFM  TCP Half Open Vector

Cause
This is expected behavior as there are a limited number of bits for encoding MSS values supported when SYN Cookie is active. The values available depends on SYN Cookie mode:

  • When SYN Cookie runs in Software: 0, 576, 1500, 9000
  • When SYN Cookie runs in Hardware: 0, 536, 996, 1280, 1440, 1460, 2048, 8900

If the MSS does not match with one of the options above then the next higher value will be chosen. So for example, if MSS is 1600 then the chosen MSS value will be 9000 or 2048 depending on the SYN Cookie mode.  This could result in degraded performance if the MSS is ratcheted down.

Recommended Actions

  • Adjust and/or disable SYN Cookie protection
    K74451051: Configuring SYN cookie protection (13.x - 17.x)

  • K14813: Detecting and mitigating DoS/DDoS attacks (11.4.x - 16.x)
