Known Issue

When the MySQL process is suspended with a SIGSTOP signal, configured high availability (HA) actions may not occur.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured as a part of an HA group.
  • Your BIG-IP system is provisioned with modules that use the MySQL process.
  • The SIGSTOP signal has suspended the MySQL process.

Impact

Configured failover action does not occur when an affected BIG-IP system's MySQL process is not available.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If the mysqlhad.debug DB key is set to true, you review the /var/log/mysqlhad.log file and notice that the MySQL process checking for HA is suspended and has stopped checking the MySQL process. This can prevent HA failover actions on the affected BIG-IP system.
  • The affected BIG-IP system does not send failover events to other HA devices, and the expected failover does not occur.
