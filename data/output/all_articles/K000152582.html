K000152582: Unable to generate an SSL self-signed cert or a CSR

Type
Support Solution
Published
2025-07-15
Updated
2025-07-15
Source
https://my.f5.com/manage/s/article/K000152582

Description

Attempts to generate an SSL self-signed certificate or a Certificate Signing Request (CSR) on F5OS-A systems may fail with errors such as:

  • Unable to create a certificate signing request(CSR). See error log for details.
  • OpenSSL X509V3_EXT_add_nconf failed to load extension .
  • Unable to create CSR for the self-signed certificate. See error log for details.
  • These errors are observed in the system logs and during certificate operations.

Environment

  • Product: F5OS - Appliance
  • Version: 1.8.0

Cause

The issue occurs when the Subject Alternative Name (SAN) field is not formatted correctly. The SAN entries must use the correct prefixes (DNS: for domain names, IP: for IP addresses), and multiple entries must be comma-delimited. Omitting these prefixes or using an incorrect format causes OpenSSL to fail when processing the SAN extension, resulting in the errors above.


Recommended Actions

  • When specifying SANs during certificate or CSR generation, use the following format:
    • For a single DNS entry: DNS:domain.com
    • For multiple entries: DNS:domain.com,IP:X.X.X.X
  • Ensure each SAN entry is prefixed with either DNS: or IP: as appropriate.
  • Separate multiple SAN entries with commas, with no spaces.
