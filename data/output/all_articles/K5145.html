K5145: BIND does not learn zone changes from NameSurfer when 3-DNS is in receiver state

Known Issue

This is the result of a known issue. In 3-DNS versions prior to 4.6.2, NameSurfer sends a DNS NOTIFY message to BIND to indicate that changes were made to the zone. Beginning in 3-DNS version 4.6.2, when the 3-DNS system is in a receiver state, BIND does not receive notification from NameSurfer when NameSurfer receives zone changes from the principal 3-DNS.

F5 Networks Product Development tracked this issue as CR43639.
