K000139452: ConfigSync failure 01070712:3: Caught configuration exception (0), Failed to sync files

Type
Support Solution
Published
2024-09-11
Updated
2024-09-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000139452

Description

Error while performing a ConfigSync:
Load failed from /Common/HOSTNAME 01070712:3: Caught configuration exception (0), Failed to sync files.

'tmsh show /cm sync-status' shows below error: 
show /cm sync-status
--------------------------------------------------------------------------------
CM::Sync Status
--------------------------------------------------------------------------------
Color red
Status Sync Failed
Mode high-availability
Summary A validation error occurred while syncing to a remote device
Details
<LTM1.example.com>: connected
<LTM1.example.com> (Sync Failed): A validation error occurred while syncing to a remote device
- Sync error on <BIG-IP_2>: Load failed from /Common/<LTM2.example.com> 01070712:3: Caught configuration exception (0), Failed to sync files..
- Recommended action: Review the error message and determine corrective action on the device

Environment

  • BIG-IP LTMs in ConfigSync group
  • Configsync performed from <LTM2.example.com> to the device group

Cause

HA group config is inconsistent between peers, lack of Mirroring IP on Active or Standby peer.

show /cm device
------------------------------------------------------------------------------------------------
CentMgmt::Device: /Common/<LTM2.example.com>
------------------------------------------------------------------------------------------------
Hostname <HOSTNAME>
Mgmt Ip 10.1.1.1
Configsync Ip 172.16.1.1
Mirroring IP :: <===
Mirroring Secondary IP :: <===
...

show /cm device
------------------------------------------------------------------------------------------------
CentMgmt::Device: /Common/<LTM1.example.com>
------------------------------------------------------------------------------------------------
Hostname <HOSTNAME>
Mgmt Ip 10.1.1.1
Configsync Ip 172.16.1.1
Mirroring IP :: 192.168.1.1 <===
Mirroring Secondary IP :: 192.168.2.1 <===
...

Recommended Actions

Add missing mirroring IPs on active or standby HOST.

On GUI:

  • go to Device Management --> Devices --> <LTM2.example.com> --> Mirroring
  • chose proper IP from the list for 'Primary Local Mirror Address' and 'Secondary Local Mirror Address'
  • confirm by clicking 'Update'
  • perform full config sync between peers
