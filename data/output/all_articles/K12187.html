Known Issue

This is the result of a known issue. If you modify the CIFS proxy user on the ARX system, existing CIFS connections to back-end filers are not refreshed. As a result, unexpected behavior may occur if the new proxy user has different Windows privileges than the old proxy user. For example, metadata may become skewed or policies may fail unexpectedly.

Note: This issue is more likely to occur if the Microsoft Access-based Enumeration (ABE) feature is enabled on the filer.

F5 Product Development tracked this issue as ID 37768 and it was fixed in ARX 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

You can work around this issue by restarting the ARX system after modifying the CIFS proxy user. As an alternative, if you do not want to restart the system, you can contact F5 Technical Support to have the DNAS service restarted on the system.
