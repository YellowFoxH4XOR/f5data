K000158090: DoS Dashboard Missing TCP Half-Open Attack Data in BIG-IP AFM 17.5.0

Type
Support Solution
Published
2025-12-05
Updated
2025-12-05
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000158090

Description

In BIG-IP AFM version 17.5.0, users may observe that certain detected DoS attacks, specifically TCP Half-Open attack vectors, do not appear in the DoS Visibility dashboard. Although attack events are logged and assigned an attack ID, searching for these attack IDs in the DoS Visibility dashboard yields no data. Other DoS vectors display as expected.

Environment

  • Product: BIG-IP AFM
  • Product Group: BIG-IP
  • Version: 17.5.0
  • Configuration: DoS Visibility dashboard enabled; TCP Half-Open DoS vector detection active
  • Recent Actions: Attack detected and logged; attempted to view attack data in DoS Visibility dashboard

Cause

Bug ID2163033

Recommended Actions

No fix is currently available for this issue as of the time of publication. If visibility of TCP Half-Open attack data in the DoS dashboard is required, monitor F5 product updates and release notes for a future fix associated with Bug ID2163033.

For further questions or urgent requirements, contact F5 Support and reference Bug ID2163033.

Additional Information

The issue is specific to the DoS dashboard not displaying TCP Half-Open attack data; other DoS vectors are displayed as expected. The attack is detected and logged, but the dashboard does not show corresponding data for TCP Half-Open attacks.
