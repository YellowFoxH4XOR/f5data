Known Issue

iControl REST Open Data Protocol (OData) queries that use the space character may fail.

This issue occurs when all of the following conditions are met:

  • You use the iControl REST application programming interface (API) to query the BIG-IP system.
  • Your iControl REST OData query includes a space character.

    For example:

    curl -k -u admin:admin 'http://localhost:8110/tm/ltm/virtual?$filter=partition eq 'Common''

Impact

iControl REST queries fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iControl REST queries fail with an "HTTP 400 - Bad Request" error message.

Workaround

To work around this issue, you can encode the space character by using %20.

For example:

curl -k -u admin:admin 'http://localhost:8110/tm/ltm/virtual?$filter=partition%20eq%20Common'
