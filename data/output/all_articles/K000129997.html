K000129997: Can't delete user Error writing '/etc/passwd.lock': No space left on device

Type
Support Solution
Published
2022-12-22
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 12.1.5
Source
https://my.f5.com/manage/s/article/K000129997

Description

Customer facing issue where BIG-IP root "/" disk partition has 100% utilized. You will see similar error message as below:

  • Can't delete user Error writing '/etc/passwd.lock': No space left on device.
  • 011d0004:3: Disk partition / has only 0% free

Ran shell command # find / -xdev -type f -exec du {} \; | sort -rn | head -20, and you will be prompted with output of large files that can be deleted from the root drive or home folder.

Environment

  • BIG-IP
  • root "/" 100% full

Cause

Since "/home" folder is under root "/" drive partition, any large file downloaded or store under "/home" folder will cause root "/" drive partition to face disk space issue

Recommended Actions

  1. The "/home" folder is under root "/" drive partition, hence, please restrain from download files into "/home" folder.
  2. Please do change the "/home" folder to "/shared" drive instead for file upload, as this drive is one of the largest disk space in BIG-IP.
