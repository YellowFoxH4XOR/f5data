Description
Brute force attack event logs does not appear under Security > Event Logs > Application > Brute Force Attacks in configuration utility even though Brute  brute force attack protection is successfully configured.

Instead it is logged under Security ›› Event Logs : Application : Requests in Configuration Utility

Environment

  • BIG-IP ASM
  • Brute Force Attack protection
  • Event logs 
  • Configuration Utility

Cause
The is an expected behaviour.

Recommended Actions
The logs under Brute Force Attacks section of the reporting in the Configuration utility will only log for distributed events such as Distributed Attack, Credentials Stuffing or Distributed Attack + Credentials Stuffing.

If the brute force violation is a source based detection, such as,  device ID or IP address then these violations are treated as standard violations on the ASM, and hence this logs are recorded under  Security ›› Event Logs : Application : Requests.
