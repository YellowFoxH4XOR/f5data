Topic

You should consider using this procedure under the following condition:

  • You want to customize the SNMPv3 engineID format.

Description

SNMPv3 requires an SNMP agent to define a unique engineID in order to respond to SNMPv3 requests. This ID is normally determined automatically using a combination of a pseudo-random number and the current time in seconds. This generated value is then stored in the /config/net-snmp/snmpd.conf file in hexadecimal format, identified as oldEngineID. This is the recommended approach.

Alternatively, you can define the engineID using one of the methods described in the following table.

MethodDefinition
engineID <STRING>Specifies that the engineID should be built from the given <STRING>, for example, engineID f5networks
engineIDType <1, 2, 3>Specifies that the engineID should be built from the following:
  1. The IPv4 address
  2. The IPv6 address
  3. The MAC address
engineIDNic <INTERFACE>Only applied if engineIDType 3 is specified. Defines which <INTERFACE> to use when determining the MAC address. The default is eth0.

Note: For more information about engineID options, refer to SNMP documentation. For information about the formatting of the engineID hexadecimal value, refer to pages 40 through 42 in the SnmpEngineID section of Internet Engineering Task Force RFC 3411. These links take you to resources outside of AskF5. The third parties could remove the documents without our knowledge.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command-line access to the BIG-IP system.
  • You are familiar with the vi text editor.

Procedures

  • Configure the engineID to be built from a <STRING>
  • Configure the engineID to be built from a MAC address
  • Configure the engineID to be built from a MAC address other than the eth0 default

Configure the engineID to be built from a <STRING>

Impact of procedure: This procedure requires a restart of the SNMP service. SNMP functionality is momentarily interrupted during this time.

Important: Pay particular attention to syntax because the BIG-IP system does not validate the commands issued using the include parameter. You can check the /var/log/daemon.log file for validation. For example: warning snmpd[25310]: /config/snmp/snmpd.conf: line 65: Warning: Unknown token:

    engineIIID.
    1. Log in to the TMOS Shell (tmsh) by entering the following command:

      tmsh

    2. Define a string to be used for the engineID, using the following syntax:

      modify /sys snmp include "engineID <STRING>"

      Note: The STRING should be the hexadecimal format. For example, set the engineID string to f5networks, hex value 66356e6574776f726b73, by entering the following command: modify /sys snmp include "engineID 66356e6574776f726b73.

    3. Save the change by entering the following command:

      save /sys config

    4. Restart the SNMP service by entering the following command:

      restart /sys service snmpd

    Configure the engineID to be built from a MAC address

    Impact of procedure: This procedure requires a restart of the SNMP service. SNMP functionality is momentarily interrupted during this time.

    Important: Pay particular attention to syntax because the BIG-IP system does not validate the commands issued using the include parameter. You can check the /var/log/daemon.log file for validation. For example: warning snmpd[25310]: /config/snmp/snmpd.conf: line 65: Warning: Unknown token:

      engineIIID.
      1. Log in to tmsh by entering the following command:

        tmsh

      2. Define the engineID based on the engineIDType directive, using the following syntax:

        modify /sys snmp include "engineIDType <1, 2, 3>"

        For example, define the engineID based on a MAC address by entering the following command:

        modify /sys snmp include "engineIDType 3"

      3. Save the change by entering the following command:

        save /sys config

      4. Restart the SNMP service by entering the following command:

        restart /sys service snmpd

      Configure the engineID to be built from a MAC address other than the eth0 default

      Impact of procedure: This procedure requires a restart of the SNMP service. SNMP functionality is momentarily interrupted during this time.

      Important: Pay particular attention to syntax because the BIG-IP system does not validate the commands issued using the include parameter. You can check the /var/log/daemon.log file for validation. For example: warning snmpd[25310]: /config/snmp/snmpd.conf: line 65: Warning: Unknown token:

        engineIIID.

        Note: When adding more than one include statement with tmsh, each statement must be separated by a carriage return and line feed (CRLF). You must enter the tmsh command outside of the interactive shell to insert the new line.

        1. Log in to the BIG-IP system's Advanced Shell (bash).
        2. To define the engineID based on the engineIDType directive, enter the following command:

          tmsh modify sys snmp include "engineIDType 3

        3. Press the Enter key once to enter the bash secondary prompt, shown as a greater than character (>).
        4. At the bash secondary prompt, use the following syntax to define a specific interface:

          > engineIDNic <interface name>"

          For example, to use the MAC address of the internal interface, enter the following command:

          > engineIDNic internal"

        5. Press the Enter key once.
        6. Save the changes by entering the following command:

          save /sys config

        7. Restart the SNMP service by entering the following command:

          restart /sys service snmpd
