Description

How to disable HTTP/2 httprouter on a Virtual Server?

Environment

  • BIG-IP

  • Virtual Servers

Cause

Not Applicable

Recommended Actions

Impact of procedure: Depending on your virtual server configuration and application environment, there may be other configurations you may need to make, such as BIG-IP monitors, verifying your application servers support HTTP/1.1, and so on. F5 recommends performing this procedure during a scheduled maintenance after thorough testing.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers.
  3. Select the name of the virtual server.
  4. For HTTP/2 Profile (Server), select None.
  5. Clear the HTTP MRF Router check box.
  6. Select Update.
