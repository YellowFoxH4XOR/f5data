To configure a timeout for shell users, add the following line syntax to each user's .bashrc file:

export TMOUT=<seconds>

The shell session will close when the session has been idle for the specified number of seconds.

Note: For more information, refer to K9908: Configuring an automatic logout for idle sessions.
