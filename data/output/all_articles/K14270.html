Known Issue

You may be unable to modify an existing Client SSL profile.

This issue occurs when all of the following conditions are met:

  • You are using a Client SSL profile with the SSL Forward Proxy feature enabled.
  • You have a CA passphrase configured for your SSL Forward Proxy CA certificate and key.
  • You do not have a Client SSL profile key passphrase configured.

This issue is limited to the Configuration utility; it does not affect the Traffic Management Shell (tmsh).

Impact

You cannot modify the affected Client SSL profile using the Configuration utility without re-entering the SSL Forward Proxy CA passphrase.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to save changes to an affected Client SSL profile, an error message appears in the /var/log/ltm file and at the top of the screen in the Client SSL profile page of the Configuration utility.

    For example:

    01070313:3: Error reading SSL forward proxy CA key PEM file /config/filestore/files_d/Common_d/certificate_key_d/:Common:<cert>.key_1 for profile /Common/<profile>: error:0906A065:PEM routines:PEM_do_header:bad decrypt

    In this error message, note the following:
    • <cert> is the name of the certificate
    • <profile> is the name of the profile

Workaround

To work around this issue, you can use the tmsh utility to edit the affected Client SSL profile.

Alternatively, to edit the affected Client SSL profile using the Configuration utility, you can re-enter the SSL Forward Proxy CA passphrase before you save the profile.
