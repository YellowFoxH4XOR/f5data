Description

  • Config not loading due to license error
  • Unable to generate Dossier to re-activate the license
  • Getting these errors when trying to generate manually:
    • License server has returned an exception. The Dossier cannot be blank. get_dossier[28609]: 01170003:3: halGetDossier returned error (1): Dossier generation failed.

 

Environment

  • BIG-IP VE running on AWS
  • BIG-IP Version 13
  • IMDSv2 metadata set to required in AWS

Cause

Customer was running version 13 which does not support IMDSv2 metadata but the AWS instance was requiring it.

 

Recommended Actions

Switching the AWS instance to IMDSV2 optional allowed them to resolve the license issue and boot up the BIG-IP software.

 

Additional Information

Unable to reactivate existing license on AWS BIGIP due to ''halGetDossier returned error (1): Dossier generation failed'' and K43503050 has already been applied
