Description

You want to increase the size of the /var/log directory for a BIG-IP tenant, for example from 3GB to 10GB, for increased logging.

  • The /var/log partition may become 100% full affecting some administrative task due to many expected logs on the device


Environment

  • F5OS
  • BIG-IP Tenant
  • /var/log directory


Cause

You are configuring your device for verbose logs and the size (e.g. 3GB) of the /var/log directory is not enough for increased logging.


Recommended Actions

Perform the following procedure to increase size of /var/log directory.
1. Verify the system disk size assigned to the Tenant by typing this command.

tmsh list /sys disk

2. Verify the size of the logical volume of /var/log directory.

df -h
3. Extend the /var/log directories as needed.
For example, you would enter the following command to extend the /var/log directory to 10GB:
tmsh modify /sys disk directory /var/log new-size 10240000
4. Save the configuration.
tmsh save /sys config
Note: df -h output will not show changes until after a reboot of BIG-IP.
5. Reboot the BIG-IP Tenant.
reboot
6. When the BIG-IP Tenant is up, log in to bash.
7. Verify that the /var/log directory is successfully extended to the size you have specified.
df -h
