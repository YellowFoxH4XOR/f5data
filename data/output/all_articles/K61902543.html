Known Issue

The BIG-IP system may leak file descriptors when monitor logging is enabled.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a pool member or node that is set with Monitor Logging enabled.
  • The pool member or node is monitored with one of the following monitor types:
     
    • diameter
    • external
    • firepass
    • ftp
    • gateway_icmp
    • icmp
    • imap
    • ldap
    • module_score
    • mssql
    • mysql
    • nntp
    • oracle
    • pop3
    • postgresql
    • radius
    • radius_accounting
    • real_server
    • rpc
    • sasp
    • scripted
    • sip
    • smb
    • smtp
    • snmp_dca
    • snmp_dca_base
    • soap
    • virtual_location
    • wap
    • wmi
  • The health monitor is removed from the BIG-IP LTM node or pool member configuration while Monitor Logging is enabled.

Impact

Health monitors may stop functioning, erroneously marking pool members and/or nodes down. In extreme circumstances, the /var/log partition may become fully utilized, leading to a general degradation of system performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Health monitors mark known available services as down or unavailable.
  • When you access the command line of the affected system, you observe an error message in the console window similar to the following example:

    Disk partition /var/log has only 0% free

  • When you attempt to create a file in the /var/log partition, you observe an error message similar to the following example:

    write error: No space left on device

  • When listing the contents of the /var/log/monitors/ file, there are a large number of monitor files.

Workaround

To work around this issue, you can disable node logging of the node or pool member configuration prior to removing the health monitor from the LTM node, pool, or pool member configuration. To do so, perform either of the following procedures:

Impact of workaround: Performing the following procedures will disable monitor logging of the node, pool or pool member.

  • Disabling monitor logging of a node
  • Disabling monitor logging of a pool member

Disabling monitor logging of a node

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Nodes > Node List.
  3. Click name of the node.
  4. Under Monitor Logging, clear the Enable check box.
  5. Click Update.

Disabling monitor logging of a pool member

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools > Pool List.
  3. Click the pool name.
  4. Click the Members tab.
  5. Click the pool member link.
  6. Under Monitor Logging, clear the Enable check box.
  7. Click Update.
