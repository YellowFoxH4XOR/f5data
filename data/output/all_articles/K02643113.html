Description

You may see below abnormal dns log after configure BIG-IP DNS to log dns queries and responses:

Apr 28 11:54:50 bigip2 info tmm[10215]: 2021-04-28 11:54:50 bigip-dns.local  <qid>  from <client ip # port>: query: null invalid invalid + <listner ip>

A normal request log should be as below:

Mar  1 04:12:32 bigip-dns.local tmm[22169] 2019-03-01 04:12:32 bigip-dns.local from <client ip/port> view none: query: www.example.com IN A +E <listner ip>

Environment

  • DNS profile
  • Logging Publisher
  • DNS Logging profile
  • GTM/DNS listener

Cause

The empty query log is caused by configure DNS profile option "Process Recursion Desired " to disable, a DNS query with  "Recursion desired" flag set trigger can trigger this.

Recommended Actions

Modify the DNS profile option "Process Recursion Desired " to enable.
