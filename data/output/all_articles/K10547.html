Topic

When you activate a BIG-IP license, you must use the appropriate product registration key.

The format of the Base Registration Key is as follows:

AAAAA-BBBBB-CCCCC-DDDDD-EEEEEEE

The format of the Add-On Key is as follows:

AAAAAAA-BBBBBBB

 

ENVIRONMENT

Licensing

Big IP

 

Note: For more information about licensing the BIG-IP system, refer to K7752: Licensing the BIG-IP system.

If you attempt to activate a BIG-IP license using the Configuration utility, by inputting an add-on registration key in the Base Registration Key field, the Configuration utility does not produce a dossier, and displays an error message similar to the following example:

Registration key is invalid.

In BIG-IP 16.1.x and later, if you attempt to activate a BIG-IP license by inputting a base registration key in the Add-On Registration Key field, the Configuration utility does not produce a dossier, and displays an error message similar to the following example, where <Reg-Key> is the Registration Key you attempted to enter:

Invalid Key Format: <Reg-Key>

However, in BIG-IP 15.1.x and 16.1.x  if you attempt to activate a BIG-IP license by inputting a base registration key in the Add-On Registration Key field, the Configuration utility produces a dossier instead of displaying an error message. If you attempt to use that dossier to generate a license, the F5 Licensing server generates an error message that appears similar to the following example:

Unable to grant license key: Error 51076, Multiple Active Base Keys present in the Dossier - Multiple Active Base Registration Keys exist in this dossier: <registration_key>.

If you receive the previous error message when attempting to activate a license, you must attempt to re-activate the license by inputting the registration key in its appropriate field.
