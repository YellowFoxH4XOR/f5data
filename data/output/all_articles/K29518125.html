K29518125: HA Active/Active with log message ''Not receiving status updates from peer device''

Type
Support Solution
Published
2022-02-24
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K29518125

Description

You are expecting HA status to be Active/Standby.
However, they are in Active/Active status, and one of them shows a "red circle" to the other, which usually means "Disconnected".

Log messages similar to the following are logged to /var/log/ltm:
notice sod[6809]: 010c007e:5: Not receiving status updates from peer device /Common/BIGIP-F5-01 (Disconnected). warning sod[7259]: 01140029:4: HA daemon_heartbeat tmm fails action is go offline down links and restart. warning sod[7259]: 01140029:4: HA daemon_heartbeat tmm1 fails action is go offline down links and restart

Environment

  • BIG-IP HA 

Cause

This is because the heartbeat message was not successfully detected by the peer device, and may be due to networking environment. Having only one Failover Unicast Address is not sufficient in terms of minimizing the network disruption.  

Recommended Actions

To verify that the HA configuration of each device is configured with more than one IP address.
  1. Log on to the Configuration utility.
  2. Go to Device Management > Devices select the BIG-IP hostname.
 
Ensure that both BIG-IP HA devices are configured with a Failover Unicast Address using the device management IP address.
That way, if the heartbeat sent by the tmm failed, there is still management IP acts an redundant failover network.
