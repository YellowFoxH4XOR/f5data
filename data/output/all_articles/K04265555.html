K04265555: After upgrading, FQDN pools only have a single ephemeral pool member

Type
Support Solution
Published
2020-09-29
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K04265555

Description

After upgrading the BIG-IP system, FQDN pools only have one ephemeral pool member

Environment

  • BIG-IP LTM
  • LTM pool containing FQDN pool member(s).

Cause

F5 recommends reactivating the system license prior to installing the new TMOS version. Failure to do so may prevent the configuration or modules from fully loading.

If the new software requires an updated license, you may find events similar to the following examples, in your Local Traffic Log, after booting into the updated version.

Sep 29 10:49:37 bigip1 err mcpd[8568]: 01071732:3: Autopopulate not licensed. Disabling autopopulate on member ::.
Sep 29 10:49:37 bigip1 err mcpd[8568]: 01071732:3: Autopopulate not licensed. Disabling autopopulate on member ::.
Sep 29 10:49:37 bigip1 err mcpd[8568]: 01071732:3: Autopopulate not licensed. Disabling autopopulate on member ::.

Sep 29 10:49:42 bigip1 err mcpd[8568]: 01071bf3:3: /Common/tcp_half_open feature not licensed. Logged 25 times.
Sep 29 10:49:42 bigip1 err mcpd[8568]: 01070356:3: /Common/tcp_half_open_New feature not licensed.
Sep 29 10:49:42 bigip1 err mcpd[8568]: 01070356:3: L4 rule feature not licensed.
Sep 29 10:49:42 bigip1 err mcpd[8568]: 01071bf3:3: Load balancing feature not licensed. Logged 26 times.
Sep 29 10:49:42 bigip1 err mcpd[8568]: 01070356:3: Load balancing (/Common/PoolA) feature not licensed.
Sep 29 10:49:42 bigip1 err mcpd[8568]: 01070356:3: Per-invocation log rate exceeded; throttling.
Sep 29 10:49:42 bigip1 err mcpd[8568]: 01071bf3:3: Monitor /Common/tcp_half_open feature not licensed. Logged 13 times.
Sep 29 10:49:42 bigip1 err mcpd[8568]: 01071bf3:3: SNAT feature not licensed. Logged 36 times.

In addition, the FQDN pool member will show 'autopopulate' is disabled.

Recommended Actions

  1. Roll back to the previous software boot location
  2. Reactivate the license. K7727: License activation may be required before a software upgrade for the BIG-IP or Enterprise Manager system
  3. Reinstall the upgrade.
  4. Boot into the new upgraded boot location.

Note: if it is not possible to roll back, reactivate the license, then run 'tmsh load sys config'. After the configuration has loaded, go into each affected FQDN pool and delete the FQDN pool member. Add the FQDN pool member back into the pool, making sure to enable the 'autopopulate' option.
