Description

You would like to disable Alarm, but only for violations that occur at a certain URL.

You would like violations to still occur and illegal requests to be blocked, however, they should not be logged.

Environment

  • Security policy
  • Learning and Blocking

Cause

None

Recommended Actions

It is not possible to disable Alarm on a per-URL basis.

One possible solution is to use an iRule or Local Traffic Policy to select a different security policy when the URL in question is accessed.

The alternative security policy could have Alarm disabled policy-wide under each violation.

Here is an example iRule:

when HTTP_REQUEST {
    if { [string tolower [HTTP::path]] eq "/abc"} {
        ASM::enable /Common/alternative_policy
    }
}

Note: This approach does involve some administrative overhead, since there will now be two policies that need to be managed for the application.
