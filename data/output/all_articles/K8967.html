Known Issue

This is the result of a known issue. If the MCP Audit Logging option is enabled, and an SSL certificate/key pair is imported where the SSL key is encrypted, the SSL passphrase for the encrypted key will display in the Audit Log file.

Note: The MCP Audit Logging option is not enabled by default.

F5 Networks Product Development tracked this issue as CR100400 and it was fixed in BIG-IP LTM version 9.4.6. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP version 9.4.5, for the 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
