Description

You have configured DNS resolver in the BIG-IP per K31539643: Managing the DNS resolver, and notice there is(are) upper case letter(s) in the domain name of DNS query and DNS response when you look into the packet capture from the BIG-IP.

For example, below is the configuration:

net self 10.11.1.1/24 {
    address 10.11.1.1/24
    traffic-group traffic-group-local-only
    vlan External
}
net dns-resolver example_dns_resolver {
    forward-zones {
        . {
            nameservers {
                8.8.8.8:53 { }
            }
        }
    }
    route-domain 0
}

When you initiate DNS resolution to www.example.com, the packet capture shows the domain name as wwW.EXamPle.CoM in the DNS query and WwW.exAmpLe.coM in the DNS response:

src-ip      dst-ip       src-port   dest-port    protocol    info

 

10.11.1.1   8.8.8.8      12345      53           DNS         OUT s1/tmm1 : Standard query 0x4111 A wwW.EXamPle.CoM OPT
8.8.8.8     10.11.1.1    53         12345        DNS         IN  s1/tmm1 : Standard query response 0x4111 A WwW.exAmpLe.coM A 192.168.1.1 OPT

Environment

  • LTM
  • DNS Resolver
  • Randomize Query Character Case

Cause

The Randomize Query Character Case is by default enabled in DNS resolver configuration, which makes the DNS resolver randomizes the character case in domain name.

The DNS resolver uses this function to prevent against MITM (man-in-the-middle) attack via it only accepts the record matches the character case.

Recommended Actions

Consider that not all nameservers echo back the query exactly as it appears, and this may cause the BIG-IP to drop authentic responses. You can disable the Randomize Query Character Case setting if you repeatedly encounter SERVFAIL messages when the BIG-IP system drops an authentic response that did not match the character query case.

Additional Information

The DNS resolver does not have a method or utility to perform the following tasks:

  • Query an entry or entries in the cache
  • Determine the number of entries in the cache
  • Remove an individual entry from the cache

Note: All entries in the cache are removed when TMM restarts.
