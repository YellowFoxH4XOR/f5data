Topic

Network Access clients receive an IP address from the FirePass controller, which is assigned to the client's Point-to-Point (PPP) adapter. IP address ranges for clients can be configured on external devices such as a RADIUS server, which is queried when the user logs on. Alternatively, the FirePass controller can be configured with IP address assignments. Either individual users can be mapped to specific IP addresses in a table, or a pool of IP addresses can be configured and assigned to Network Access clients on a first-come, first-serve basis. Any combination of assignment methods is allowed. Users can configure IP addressing options for each resource group in the Configure IP Address Assignment section, which is located on the Network Access: Resources page.

When configuring an IP address pool for Network Access, the range of addresses in the pool must be contiguous. The IP Address field and Mask field in the Add new IP Address Pool panel create the range of addresses using a network address and a netmask, such as a Classless Internet Domain Routing (CIDR) block. Currently, users cannot specify arbitrary or non-bit boundary ranges (for example, 192.168.1.1 to 192.168.1.100) and do not have a way to specify exceptions within an IP address pool.

However, exceptions can be created within IP address pool assignment method by mapping individual users to the IP addresses which the user wants to exclude. The latter method takes precedence over the IP address pool method, when both are configured. By mapping the excluded IP addresses to non-existent usernames in the mapping table, the user can ensure that the IP addresses are not assigned to Network Access clients.

To exclude the IP address 192.168.1.1 from the IP address pool 192.168.1.0/255.255.255.0 (a range of 192.168.1.1 to 192.168.1.255), with the name Pool1, perform the following procedure:
  1. Click Network Access.
  2. Click Resources.
  3. Using the Resource Group drop-down menu, select the resource group containing the Network Access favorite that will have the exclusion.
  4. Under the Configure IP Address Assignment section, select the Use static IP address per user from mapping table (1st priority) check box.
  5. Under the Configure IP Address Assignment section, select the Assign IP address dynamically using IP address pool (lowest priority: Enabled by default) check box.
  6. Optionally, select any other methods of IP Address assignment you require.
  7. Under the Configure User to IP Address Mapping Table section, enter a name in the Logon field. Do not use the name of an existing logon in the FirePass database, or a logon name that is likely to be used by any external users. For example, use a name that describes the purpose of the entry, such as IP-Address-Exclusion-1.
  8. Under the Configure User to IP Address Mapping Table section, enter the IP address to be excluded in the IP Address field:

    For example:

    192.168.1.1
  9. Click the Add button.The logon and IP address should appear in the table below the fields.
  10. Under the Select IP Address Pool section, select MyPool1 from the drop-down menu.
  11. Click the Update button.
  12. Repeat these steps, starting from Step 3 for each resource group that requires an IP address exclusion.

The exclusion is specific to a resource group, not to the IP address pool that the resource group uses.
