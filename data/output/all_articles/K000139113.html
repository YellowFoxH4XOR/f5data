K000139113: BIG-IP DNS marks a LTM Virtual Server as Green (Available) even though its status is Blue (Unknown) on the LTM

Type
Support Solution
Published
2024-03-30
Updated
2024-03-31
Applies to
  • BIG-IP
  • BIG-IP DNS: 15.1.4
Source
https://my.f5.com/manage/s/article/K000139113

Description

You may notice that a Virtual Server on the LTM shows an Unknown blue status, while it appears as Available green status on GTM/DNS.

Environment

  • LTM
  • DNS

Cause

This behavior is expected and it is functioning as designed.

Recommended Actions

None.

Additional Information

None.
