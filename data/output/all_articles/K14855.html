Known Issue

The BIG-IP system may incorrectly respond to a recursive query with a non-recursive answer.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured as a transparent DNS cache.
  • The BIG-IP system receives and caches the DNS non-recursive query for a domain.
  • The BIG-IP system processes a subsequent DNS recursive query for the same domain.

Impact

The system does not resolve recursive DNS requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H438019 on the Diagnostics > Identified > Low screen.
  • The BIG-IP system responds to a recursive DNS query with a previously-cached non-recursive answer.
  • The DNS response for a recursive DNS query contains an empty answer section.

Workaround

If upgrading is not an option, you can mitigate this issue by disabling transparent caching on the affected virtual server or listener. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system will not cache DNS responses.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles.
  3. From the Services menu, select DNS.
  4. Click the name of the DNS profile that is associated with the affected virtual server or listener.
  5. From the DNS Cache menu, select Disabled.
  6. Click Update.
