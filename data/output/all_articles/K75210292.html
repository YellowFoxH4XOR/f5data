K75210292: BigIQ lost connectivity after upgrade to 8.1.0.2 BIG-IQ VE

Description


BIG-IQ may lose connectivity on the management IP after upgrade to version 8.x if the management IP was / is in the subnet range of 10.100.1.0/16.

Environment

  • BIG-IQ version 8.x
  • Management IP in subnet range of 10.100.1.0/16

Cause


BIG-IQ version 8 includes a docker0 interface in range of 10.100.1.0/16.  If the default gateway for management coincides with this range, default traffic heads out the docker0 interface rather than mgmt.

Recommended Actions

  1. Verify route table from a bash shell prompt:
    ip -f inet route show

    default via 10.100.0.1 dev docker0 metric 9
  2.  Using vi, edit /etc/docker/daemon.json. 
    Edit the {"base":"10.100.100.1/16","size":24} line to be a different subnet that does not conflict with your management subnet.  Save the file
  3. Restart the docker service:
    sudo systemctl restart docker
  4. Reboot the BIG-IQ and then verify the route table once again:
    ip -f inet route show

    default via 10.100.0.1 dev mgmt metric 9

None.
