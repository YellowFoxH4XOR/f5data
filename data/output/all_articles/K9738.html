Known Issue

This is the result of a known issue. If a user running Mac OS X or Linux opens a Java Static Application Tunnel, the tunnel may fail to open with an error message similar to the following example: 

Java applet cannot be started. Please make sure that a required version of Java is installed
 
Note: This issue can occur even if a supported version of Java is installed.
 
Note: The Java Static Application Tunnel was introduced in FirePass version 6.0.3.
 
F5 Product Development tracked this issue as ID 296138 (formerly CR107418) and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
