K3370: Reasons why the BIG-IP system may not detect a RealNetworks Helix server after f5realmon.dll is installed

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K3370

Topic

The Helix Admin tool does not reload .dll files when it is used to restart the rmserver.exe service. As a result, it does not use the f5realmon.dll file.

Using the Windows Services Administrative Tool, manually stop and restart the Helix rmserver.exe service. The server will load the new F5 .dll and will function as expected.
