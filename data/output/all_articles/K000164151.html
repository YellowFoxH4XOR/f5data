Description

A BIG-IP system fails to complete boot, and console login is not possible. The console may show machine check exception (MCE) hardware error lines such as CPU 0: Machine Check: 0 Bank 13 and PROCESSOR 0:80667 ... microcode 4c0000. Boot output also shows that network interfaces (for example, eth0) and SFP modules are not detected.

Not every MCE message indicates a failure. A correctable MCE is one where the UC (Uncorrected) flag, bit 61 of the MCA status register, is 0. The hardware corrected the error. However, if correctable MCE messages appear alongside missing-hardware messages, and the device still fails to boot after multiple attempts, the boot failure could still be caused by a hardware problem on the motherboard or memory and still potentially require RMA.

Environment

  • Product: BIG-IP LTM
  • Condition: System fails during boot, before it becomes operational
  • Access: Console login is not possible, so a QKView cannot be generated from the console

Cause

Hardware fault on the system board. Boot-time MCE messages and missing NIC and SFP module detection indicate a hardware problem. 

Answer/Recommended Actions

  1. Perform a cold power cycle:
    1. Power off the system completely.
    2. Disconnect the power cables.
    3. Wait at least one minute.
    4. Reconnect power and boot the system.
  2. Compare the boot output with the previous output. Capture the full boot log from NIC initialization through the point where the system stops, including any later MCE lines.
  3. Check and reseat cables and modules.
  4. If the error persists after the cold power cycle and cable checks, contact F5 Support to open an RMA for hardware replacement.
  5. Provide the boot log and any available diagnostic data to F5 Support.

Additional Information

  • Expected behavior: A correctable MCE message (UC flag = 0) that appears while the system boots normally does not require action on its own.
  • Unexpected behavior: The system does not complete boot, the console stops during boot, or NIC and SFP modules are not detected.
