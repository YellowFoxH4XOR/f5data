K000150262: ASM Signature false positives 200003534 and 200003036

Type
Support Solution
Published
2025-03-06
Updated
2025-03-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000150262

Description

A false positive violation was triggered for Microsoft Clarity, due to attack signatures:

  • ID200003534 - Windows "ftp" execution attempt (Parameter)
  • ID200003036 - Unix/Linux "ftp" execution attempt (Parameter)


Environment

  • ASM/AWAF


Cause

Some cookies (ex. _clck) of Microsoft Clarity contain "ftp" inside pipe ("|") characters.


Recommended Actions

Disable the signature.

 

Additional Information

None
