Topic

You should consider using this procedure under the following condition:

  • You want to restrict client file uploads to your web application based on the file extension.

Description

You can configure the BIG-IP ASM to restrict file uploads based on file extensions you specify in the security policy.  This allows you to prevent users from uploading potentially harmful files, such as files with double file extensions.   

You first create a parameter in the security policy based on the parameter used to upload the file in the application. Then in the parameter configuration, you specify the allowed file extensions using a regular expression. When users upload files with extensions that do not match, the system generates a violation and the files can be blocked. 

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility.

Procedures

To create a security policy parameter to restrict file uploads based on the file extension, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Security > Application Security > Parameters.
  3. In the Current edited security policy list, click the security policy that you want to edit.
  4. Click Create.
  5. Under Create New Parameter, in the Parameter Name section, in the list, click Explicit, and then in the box, type a name for the parameter.
  6. In the Parameter Level list, click Global, URL, or Flow.
  7. In the Perform Staging section, do one of the following:
    • If you want the system to evaluate traffic before enforcing this parameter, select Enabled.
    • If you want the system to enforce the parameter, clear the Enabled check box.
  8. In the Allow Empty Value section, if the parameter must always include a value, clear the Enabled check box.
  9. In the Allow Repeated Occurrences section, if users can send a request that contains multiple parameters with the same name, select Enabled.
  10. In the Sensitive Parameter section, if you do not want the data to be visible in logs or the user interface, select Enabled.
  11. In the Parameter Value Type list, click User-input value.
  12. On the Data Type tab, in the Data Type list, click Alpha-Numeric.
  13. In the Maximum Length section, if you want to limit the allowed length of the parameter value, select Value, and then in the box, type the maximum length in bytes.
  14. In the Regular Expression section, select Enable, and then in the box, type a regular expression for the allowed file extensions.

    For example, to block file uploads with double file extensions, such as the file upload.php.png, and allow only files with .pdf or .doc extensions, type the following syntax:

    (?i)^[^.]+\.(pdf|doc)$

    In the regular expression, note the following:

    • (?i) performs a case insensitive search.
    • ^ matches the start of the line.
    • [^.]+ matches any character that is not a dot (.), one or more times.
    • \.(pdf|doc) matches a single dot (.) followed by the string pdf or the string doc.
    • $ matches the end of the line.
  15. On the Value Meta Characters tab, if you want to override the global security policy meta character settings, in the Global Security Policy Settings list, click the meta character you want, and then click Move left (<<). 
  16. In the Overridden Security Policy Settings table, in the row for the meta character you just added, in the State list, click Allow or Disallow.
  17. On the Attack Signatures tab, if you want to override the global security policy attack signature settings, in the Global Security Policy Settings list, click the attack signature you want, and then click Move left (<<).
  18. In the Overridden Security Policy Settings table, in the row for the attack signature you just added, in the State list, click Allow or Disallow.
  19. Click Create.
  20. Click Apply Policy to immediately apply the changes to the security policy.

Note: In the learning and blocking section, there is a section called "Parameters". It contains a setting called, "Parameter value does not comply with regular expression".  Blocking must be checked for this setting for the procedure above to work.
