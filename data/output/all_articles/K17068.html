Known Issue

The Traffic Management Microkernel (TMM) may restart when the SSL Forward Proxy Bypass feature is enabled and the HTTP::disable iRule command is executed.

This issue occurs when all of the following conditions are met:

  • Your virtual server configuration includes the following:

    • A Secure Sockets Layer (SSL) profile with the SSL Forward Proxy Bypass feature enabled
    • An HTTP profile
    • An iRule that uses the HTTP::disable command
  • The virtual server processes a connection that matches both the SSL Forward Proxy Bypass definition and the iRule event that triggers the HTTP:disable command.

Impact

TMM restarts and temporarily fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

To work around this issue, you can disable the HTTP profile in a SERVER_CONNECTED iRule event.

For example:

when SERVER_CONNECTED {
    HTTP::disable
}

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
