Description

What does "inPriorRuleEnforced" mean when viewing signature status using iControl REST


Environment

ASM Provisioned

ASM Attack Signatures updated


Cause

When the rule of a factory signature enforced by a particular policy is updated, both the previous version of the signature rule and the new version of the signature rule will be used for this policy simultaneously. The previous version will be enforced fully, and the new version will be checked in staging.


"isPriorRuleEnforced" - returns true on a GET query if an older signature rule is enforced in policy, and new signature rule is introduced and enters staging.
