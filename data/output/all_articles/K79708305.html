Description
The inode space for the /var directory reports 100% usage.

Environment

  • BIG-IP ASM
  • BIG-IP LTM
  • inode
  • Linux filesystem directory

Cause

Undetermined.

Recommended Actions
 

  1. Run the following command to determine what are the files that are filling up the inode space:

    ls /var -AiR1U |sed -rn '/^[./]/{h;n;};G;  s/^ *([0-9][0-9]*)[^0-9][^/]*([~./].*):/\1:\2/p' |sort -t : -uk1.1,1n |cut -d: -f2 | sort -V | uniq -c |sort -rn | head -10
     
  2. Review the file list and remove each of them accordingly:

    rm /<path>/<file>
    Note: <path> is the Linux file system directory where the listed file resides, <file> is the file name of the file to delete.
