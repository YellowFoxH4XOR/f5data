Topic

This article applies to BIG-IP ASM 11.x. For information about other versions, refer to the following articles:

  • K17191923: BIG-IP ASM does not generate learning suggestions for certain security violations (BIG-IP 13.x - 17.x)
  • K7687: BIG-IP ASM does not generate learning suggestions for certain security violations (9.x - 10.x)

Summary

The Traffic Learning screen in the Configuration utility contains categories of security violations, and displays the number of actual violations for each category. The Learning Manager generates the learning suggestions based on traffic through the security policy.

Description

The Learning Manager does not currently generate learning suggestions for the following security violations in the BIG-IP ASM 11.x software branch:

Request for Comment (RFC) Violations

  • Cookie not RFC-compliant
  • Illegal HTTP format
  • Non-RFC request
  • Evasion Technique Detected

Access Violations

  • Illegal HTTP status in response
  • Illegal session ID in URL
  • Login object expired
  • Login object bypassed
  • Request length exceeds defined buffer size

Input Violations

  • Failed to convert character
  • Forbidden Null in request
  • Illegal number of mandatory parameters
  • Null in multi-part parameter value
  • SOAP method not allowed

Cookie Violations

  • Expired timestamp
  • Modified ASM cookie
  • Wrong message key

Mitigation

  • Maximum login attempts are exceeded

Recommendations

To identify one or more of the previously described security violations, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Event Logs > Application > Requests.
  3. Click Show Filter Details to display the advanced filter.
  4. From the Violation menu, select the desired violation.
  5. Click Go.

    The selected violations display.
