K000135609: Syntax error for show sys ip-address when APM resources address spaces are present.

Type
Support Solution
Published
2023-08-08
Updated
2023-08-08
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.0, 16.1.3
Source
https://my.f5.com/manage/s/article/K000135609

Description

When an address space object is added to "Access ›› Connectivity / VPN : Network Access (VPN) : Address Spaces", the cli command "show sys ip-addresses" returns a syntax error.

Environment

  • BIG-IP APM
  • APM resources address spaces
  • CLI
  • show sys ip-addresses
  • Syntax error

 

Cause

This is tracked in bug ID 1327933 'tmsh show sys ip-address' command throws 'Syntax Error: Invalid IP address' error when address space is added

Recommended Actions

There is currently no workaround for this bug

Additional Information

None
