Description

When trying to provision or deprovision AFM module via the Configuration Utility, an error is displayed that Turboflex profile is required.
However, enabling Turboflex results in the error below:

An error occurred: Cannot read properties of undefined (reading 'description')

Environment

  • BIG-IP
  • Turboflex supported platform, iSeries in particular
  • v15.1.5
  • AFM provisioning or deprovisioning
  • GUI / Configuration Utility
     

Cause

This is caused by Bug ID 1020129.
 

Recommended Actions

Use tmsh or iControl REST to manage TurboFlex profile configuration via the command line.

None
