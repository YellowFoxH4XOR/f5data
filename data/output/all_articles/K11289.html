Known Issue

This is the result of a known issue. The BIG-IP ASM Configuration utility does not show detected keywords for attack signatures in staging. If a request triggers the UNIX hidden object access attack signature, BIG-IP ASM should display the context details and the detected keywords for the violation, regardless of the configured blocking action. However, in BIG-IP ASM 10.1.0, you can review violation details for detected attack signatures only when the attack signature blocking action is set to Alarm or Block.

The violation details for detected attack signatures help you determine whether the violation is a false positive or an attack. You can display the context details and detected keywords whenever a request contains characters that are part of the signature. For example, the following details are displayed when the BIG-IP ASM system receives a request for a file located in the hidden directory /js/.askf5.com, triggering the following violation:

ContextRequest
Detected Keywords /js/.askf5.com/css/foo=%2541

F5 Product Development tracked this issue as ID 224872 (formerly CR137926) and it was fixed in BIG-IP ASM 11.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
