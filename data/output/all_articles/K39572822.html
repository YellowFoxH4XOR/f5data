Description

  1. An external SFTP monitor was configured by following the article K24595255 but the health monitor is still marking the servers as "Down". 
  2. When you run the below commands to test the expect script before you deploy it as a monitor according to the article K24595255 you are getting these errors:

Environment

  1. BIG-IP LTM v15.1.5
  2. External health monitor to validate the SFTP server's logon availability. 
  3. The SFTP script file (sftp_monitor.txt) was written on a Window system
# expect -f sftp_expect_script <sftp server ip address> <username> <user password>

OSError: [Errno 2] No such file or directory              <----- Error, No OK!!

 

Cause

  1. That python exception is coming from /usr/local/bin/test_monitor, which exists and is an app that exists on the BIG-IP. The exception is coming from python's attempt to execute "/config/filestore/files_d/Common_d/external_monitor_d/:Common:sftp_external_monitor_116723_1"  which returned ENOENT ("No such file or directory")
    • From man execve, " ENOENT The file pathname or a script or ELF interpreter does not exist."
  2. By running the below "cat" commands you can differentiate or identify what is causing the problem
# cat -A config/monitors/sftp_expect_script | head -1           -- Script file 
#!/usr/bin/expect$                                                                                 -- Expected output

# monitors # cat -A /config/filestore/files_d/Common_d/external_monitor_d/:Common:sftp_external_monitor_89635_6 | head -1
#!/bin/sh$                                                                                              -- Expected output

# monitors # cat -A /config/filestore/files_d/Common_d/external_monitor_d/:Common:sftp_external_monitor_89635_6 | head -1
# !/bin/sh^M$                                                                                          -- This is not the expected output
 
  1. The SFTP script file (sftp_monitor.txt) was written on a Window system and has a  CRLF (dos line endings). It is necessary to convert it to UNIX linde endings.


Recommended Actions

Follow either of the following two options: 
  1. Edit the "sftp_external_monitor" file from WebUI
    1. Go to System ›› File Management : External Monitor Program File List ›› sftp_external_monitor
    2. Remove the first line
      • #!/bin/sh
    3. Add it again and click the "update" button.
    4. Test and validate.
  2. Another option is creating the SFTP script file from CLI/Bash (Advanced Shell) by using the VI editor.
