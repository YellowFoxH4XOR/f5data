Description

This article outlines the steps to setup an external script to monitor an ADFS pool.

Environment

  • Consider using this procedure under the following conditions:
    You have an ADFS pool that you would like to monitor.

Cause

        None

Recommended Actions

  1. Put the following script in a text file and import it to the BIG-IP:

#!/bin/sh
# These arguments supplied automatically for all external monitors:
# $1 = IP (nnn.nnn.nnn.nnn notation)
# $2 = port (decimal, host byte order)
#
# This script expects the following Name/Value pairs:
# HOST = the host name of the SNI-enabled site
# URI  = the URI to request
# RECV = the expected response
#
# Remove IPv6/IPv4 compatibility prefix (LTM passes addresses in IPv6 format)
NODE=`echo ${1} | sed 's/::ffff://'`
if [[ $NODE =~ ^[0-9]{1,3}.[0-9]{1,3}.[0-9]{1,3}.[0-9]{1,3}$ ]]; then
NODE=${NODE}
else
NODE=[${NODE}]
fi
PORT=${2}
PIDFILE="/var/run/`basename ${0}`.sni_monitor_${HOST}_${PORT}_${NODE}.pid"
if [ -f $PIDFILE ]
then
echo "EAV exceeded runtime needed to kill ${HOST}:${PORT}:${NODE}" | logger -p local0.error
kill -9 `cat $PIDFILE` > /dev/null 2>&1
fi
echo "$$" > $PIDFILE
(echo -e "GET $URI HTTP/1.1\r\nHost: $HOST\r\nConnection: Close\r\n\r\n"; sleep 2) | openssl s_client -connect $NODE:$PORT -servername $HOST -quiet 2> /dev/null| grep -i "$RECV" 2>&1> /dev/null
#
STATUS=$?
rm -f $PIDFILE
if [ $STATUS -eq 0 ]
then
echo "UP"
fi
exit
 

            To import the file, log into the BIG-IP configuration utility and navigate to System  ››  File Management : External Monitor Program File List.
            Click "Import" on the right side, click on "Choose File", browse and select the file in the pop up window, click "Open"
            name the file and click at the "Import" button below 

       2.  Create the ADFS monitor
 
            The script requires 3 variables entered as name/value pairs. The variables are listed below.

             Variable Name           Value
             RECV                        HTTP/1.1 200
             URI                            /FederationMetadata/2007-06/FederationMetadata.xml
             HOST                        <Your ADFS host name>

            In the WebUI, navigate to Local Traffic  ››  Monitors, click "Create..." on the right side
            Name the ADFS Monitor, Choose "external" in the dropdown Type List
          
            Enter the following settings and leave others as default:
 
            External Program:  Select the file name that contains the imported script from the dropdown list
            In the Variables Section Add the 3 variables and values
