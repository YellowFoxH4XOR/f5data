Cause

csyncd/rsync may fail to sync to secondary blade under certain circumstances.

Recommended Actions

   1. Restart csyncd of slot<x>  (In case of the above scenario, it is slot3)

      # ssh slot3 "tmsh restart sys service csyncd"


If restarting csyncd does not improve the issue, follow the steps below.     

   2. Copy images/hotfixes manually.

      # scp /shared/images/* slot3:/shared/images/

   3. Register image/hotfix files to mcpd.

      # ssh slot3 "imagemgr -a /shared/images/*"

   4. List files under /shared/images.

      # ssh slot3 "ls -l /shared/images"

   5. Verify all images in /shared/images are registered.

      # ssh slot3 "tmsh list sys software image"

   6. Verify software install starts.

      # tmsh show sys software
