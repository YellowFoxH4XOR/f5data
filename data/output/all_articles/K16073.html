Known Issue

The Inherit traffic group from current partition / path traffic group setting may fail to synchronize for secure network address translation (SNAT) translation objects.

This issue occurs when the following condition is met:

  • The Automatic Sync feature is enabled in a device group.

Impact

A SNAT translation object does not have the expected traffic group setting.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Inherit traffic group from current partition / path traffic group setting for a SNAT translation object is not configured the same across device group members after synchronization.

Workaround

To work around this issue, you can configure the Full Sync setting for the device group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Device Groups.
  3. Click the name of the device group.
  4. Select the Full Sync check box.
  5. Click Update.
