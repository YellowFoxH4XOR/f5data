Known Issue

Removing a power supply unit (PSU) from BIG-IP 2000 series or 4000 series appliances may result in a recurring red alarm LED and spurious LCD error messages.

This issue occurs when the following conditions are met:

  • The device is a BIG-IP 2000s, BIG-IP 2200s, BIG-IP 4000s, or BIG-IP 4200v.
  • The system contains dual operational power supplies.
  • One of the power supplies is removed while the system is running.

Impact

The recurring red alarm LED and spurious LCD error messages may cause confusion.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H407037 on the Diagnostics > Identified > High screen.
  • Attempts to clear the alarm only work temporarily. The error messages and red alarm LED will return after about one minute after you press the CHECK button twice on the LCD panel or use the clearlcd_critical command from the command line.
  • The LCD screen display the following critical messages:

    • xxm Fan speed too low".
    • xxm hardware sensor critical alarm."
    • Power supply #2 fan-1: fan speed (0) is too low"
  • Error messages in the /var/log/ltm file appear similar to the following example:

    emerg system_check[11277]: 010d0010:0: Power supply #2 fan-1: fan speed (0) is too low.
