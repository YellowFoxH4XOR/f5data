Topic

In the Amazon Web Services (AWS) environment, AWS by default generates the BIG-IP VE host name to include the host name's private IP address for that instance.

Description

AWS generates a host name for each deployed BIG-IP VE instance and uses the private IP address of each instance as part of the host name for the instance. For example, ip-10-0-0-172.ec2.internal. If you attempt to change the host name of the BIG-IP VE instance, the BIG-IP VE instance reverts to the AWS-generated host name after you restart the system. The BIG-IP VE instance requests Dynamic Host Configuration Protocol (DHCP) information from the AWS environment during system startup and sets its host name based on the DHCP response it receives from the AWS environment.

This behavior is by design for deployed BIG-IP VE instances within the AWS environment.

Recommendations

You can configure the BIG-IP VE instance to omit the host-name option from its request for DHCP information from the AWS environment by removing the host-name option from the DHCP configuration and then configuring the host name you want for the instance. To do so, perform the following procedure:

Impact of procedure: The system temporarily stops processing traffic while the system restarts to affect the host name change. F5 recommends performing the following procedure during a scheduled maintenance window.

  1. Log in to the TMOS Shell (tmsh) on the BIG-IP VE instance by entering the following command:

    tmsh

  2. Remove the host-name option from the DHCP configuration by typing the following command:

    modify /sys management-dhcp sys-mgmt-dhcp-config request-options delete { host-name }

  3. Save the changes by entering the following command:

    save /sys config

  4. Change the host name of your BIG-IP VE instance by entering the following command syntax:

    modify /sys global-settings hostname <new_hostname>

    For example,

    modify /sys global-settings hostname abc1.ec2.internal

  5. Save the changes again by typing the following command:

    save /sys config

  6. Change the DHCP settings, and issue the following command to correct the name without losing connectivity to management:

    bash
    tmsh modify sys global-settings mgmt-dhcp disabled; tmsh modify sys global-settings mgmt-dhcp enabled

  7. Reload the configuration by entering the following command:

    tmsh load sys config

  8. Restart the system to affect the host name change by entering the following command:

    reboot
