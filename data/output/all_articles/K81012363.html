Description
Using remote logging for Security Policy, Bot Defense profile or other objects on the BIG-IP with a remote syslog server(s) setup to send log messages with UDP resulting in datagram packets being fragmented on the internal network.

Environment

  • BIG-IP with remote syslog profile
  • Network with 1500 MTU
  • IPS/IDS monitoring network traffic

Cause
UDP being a connectionless protocol, sends log messages out on the network in a single packet. If the network has an MTU that is smaller than the size of the datagram packet, those packets are fragmented so they can traverse the network. These IP fragment packets can cause issues in some network environments with an IPS/IDS monitoring network traffic.

Recommended Actions

  1.  If using UDP for remote logging causes an issue with your IPS/IDS, F5 recommends using TCP rather than UDP to send log messages to the remote syslog server.
