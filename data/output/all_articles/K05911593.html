Topic

You should consider using this procedure under the following conditions:

  • Your VMware Horizon View destination resource server is configured with a session startup script.
  • Your BIG-IP APM system is configured with an application access VMware View remote desktop profile.
  • You want the BIG-IP APM system to pass session-specific variables to the VMware Horizon View server session startup script.

Description

Beginning in BIG-IP APM 12.1.0, session startup variables can be passed to a destination VMware Horizon View server for an access session. Additionally, you can configure the BIG-IP APM access policy to enable VMware View session USB redirection.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP APM system is configured with an existing VMware View remote desktop profile, and is a resource of an access profile.
  • Your VMware Horizon View server is configured with a session startup script.
  • You understand the expected variables and syntax for the session startup script.

Procedures

Configuring your access policy to pass session variables to the VMware Horizon View session startup script

This procedure guides you through the Configuration utility steps required to send session variables to a VMware Horizon View session startup script. Configuring session startup script variables is a subsection of configuring the access policy for VMware View USB redirection.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Access Policy > Access Profiles.
  3. To the right of your access profile name, select the Edit link to open the Visual Policy Editor.
  4. Select the (+) icon anywhere in the access policy to add a new policy item.

    Note: Place the VMware View Policy policy item ahead of any logon and authentication actions for clients.

  5. Select Assignment.
  6. Select VMware View Policy, and then select Add Item.

    The VMware View Policy properties page displays.

  7. Optional: To enable USB redirection, select Enabled from the USB redirection list. Otherwise, the default setting is Disabled.

    Note: Enabling USB redirection is not a requirement to configure the VMware View Start Session Script Variables section for the access session.

    Important: Secure Tunnel must be enabled on the VMware Horizon View server for the BIG-IP APM system to support USB redirection.

    Note: When enabling Secure Tunnel on the VMWare Horizon View server set the External URL to point to the View Connection Server (VCS, typically the VMWare Horizon View server itself) and not the BIG-IP virtual server.

  8. In the VMware View Start Session Script Variables section, specify any variables that you want to pass to the VMware Horizon View server Start Session Script.
  9. Select Add new entry to add a new row in the table.
  10. For Variable Name, enter a name for the variable to be passed to the VMware Horizon View server Start Session Script. In accordance with Obtaining Input Data for a Start Session Script, start session environment variables have the prefix VDM_StartSession_. Therefore, the start session variables appear in the format: VDM_StartSession_variable_name, where variable_name is the name that you enter for Variable Name. For example, the start session environment variable that contains the client system’s IP address is VDM_StartSession_IP_Address.

    Note: The previous link takes you to resources outside of AskF5. The third party may remove these documents without our knowledge.

  11. For Value, enter a value to be associated with the variable.
  12. Select Save.
  13. In the upper-left corner of the Configuration utility, select Apply Access Policy.
