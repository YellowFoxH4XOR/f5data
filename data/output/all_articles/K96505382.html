K96505382: The BIG-IP system now pushes statistics data to BIG-IQ DCD

Type
Knowledge
Published
2019-01-30
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IQ
  • BIG-IQ Centralized Management: 6.1.X, 6.0.X
  • BIG-IP Analytics: 13.1.0
  • BIG-IP LTM: 13.1.0
Source
https://my.f5.com/manage/s/article/K96505382

Issue

Old Behavior

In versions prior to BIG-IQ 6.0.0 and BIG-IP 13.1.0.5, the BIG-IQ data collection device (DCD) initiates a connection to the managed BIG-IP device to retrieve statistical data. Additionally, the BIG-IP Application Visibility and Reporting (AVR) module is not required to be provisioned on the managed BIG-IP device.

New Behavior

Beginning in BIG-IQ 6.0.0 and BIG-IP 13.1.0.5, the managed BIG-IP device initiates a connection to the BIG-IQ DCD to send statistics data. Additionally, the BIG-IP AVR module must be provisioned on the managed BIG-IP in order to collect statistics. Finally, an Analytics profile must be attached to the virtual servers you want to collect application traffic statistics about. Although the BIG-IP system pushes the statistics data to the DCD, bi-directional connectivity using port 443 is still required. The DCD retrieves object status (online, offline, disabled, and so on) by connecting to the BIG-IP and transferring the Analytics iApp output file.

The BIG-IP device connects to the assigned BIG-IQ DCD, and streams the Analytics data that it is configured to send. If the AVR process cannot connect to the first DCD, it tries a second one, if configured, and so on. The BIG-IQ DCD still initiates a connection to the BIG-IP device to periodically retrieve event data.

The BIG-IP sends statistics data to the IP address you configured as the listener address on the BIG-IQ DCD. You configure the listener address when adding the DCD and you can choose a self IP address or the management address for this purpose. Refer to the Plan BIG-IQ Interface Requirements chapter of the Planning a Centralized Management and Visibility Deployment manual for more information.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Note: The BIG-IP Application Visibility and Reporting module enables Analytics functionality.

Impact

If the BIG-IP Application Visibility and Reporting module is not provisioned on the BIG-IP device and it is not able to initiate a connection to destination port 443 on the BIG-IQ DCD over the network, statistics collection on the BIG-IQ fails for the managed device.

Note: F5 does not recommend enabling statistics for Virtual Clustered Multiprocessing (vCMP) host systems.

Recommended Actions

If you have completed all the required configuration steps to collect statistics from managed BIG-IP devices and the BIG-IQ system is not collecting statistics, do the following:

  • Ensure that destination port 443 to the BIG-IQ DCD is open in any firewall between the BIG-IP device and the BIG-IQ DCD system to allow the traffic to flow. The avrd process on the BIG-IP device should be connected to the DCD. To verify, enter the following command:

    netstat -anpt | grep 443

  • Verify that the BIG-IQ configured the Analytics global settings properly on the BIG-IP. Enter the following command from the BIG-IP command line.

    tmsh list analytics global-settings

    Note: It may take several minutes for the settings to appear after you enable data collection.

  • On the BIG-IP device, ensure the BIG-IP AVR module is provisioned.
  • On the BIG-IP device, check /var/log/avr/avrd.log for errors.
  • On the BIG-IP device, ensure that virtual servers have Analytics profiles attached.

    For information about managing BIG-IP LTM profiles using BIG-IQ, refer to the Managing Local Traffic Profiles chapter of the BIG-IQ Centralized Management: Local Traffic and Network Implementations manual. When using BIG-IQ and F5 Application Services 3 Extension (AS3), refer to the AS3 Profiles page on F5 Cloud Docs.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  • On the BIG-IQ DCD, check that agent-manager is up. To do so, enter the following command from the BIG-IQ DCD command line:

    ps -ef | grep AgentManagerApp

  • On the BIG-IQ DCD, check /var/log/appiq/agentmanager.log for errors.
