Known Issue

VIPRION systems may erroneously log "/usr/bin/set-rsync-mgmt-fw close failed" messages in the /var/log/ltm file.

This issue occurs when the following condition is met:

  • You restart the VIPRION system.
During the VIPRION startup process, the system runs the /usr/bin/set-rsync-mgmt-fw background command, which does not apply to VIPRION systems.

Impact

None. You can safely ignore this error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the VIPRION system starts up, you notice an error message in the /var/log/ltm file that appears similar to the following example:

    01071392:3: Background command '/usr/bin/set-rsync-mgmt-fw close' failed. The command exited with status 1.
