K000139487: F5OS-A memory leak in platform-diag-agent process

Type
Support Solution
Published
2024-05-02
Updated
2025-07-02
Applies to
  • F5OS
  • F5OS-A: 1.7.0, 1.5.2, 1.5.1
Source
https://my.f5.com/manage/s/article/K000139487

Description

The platform-diag-agent process on an rSeries appliance is observed to be slowly growing in size when viewed with tools such as ps or top.

Environment

  • rSeries
  • platform-diag-agent
  • Memory

Cause

Bug ID 1575417

The memory leak is triggered by repeatedly calling show system health (including via REST).

Recommended Actions

The leak is a slow one, so in most cases there will be no impact unless show system health is called many times over a long system uptime, eventually resulting in an out of memory condition.

The memory used by platform-diag-agent can be reclaimed by periodically restarting the diag-agent docker container (for example, once a week):

docker container restart diag-agent

There should be no impact to tenant availability, but monitoring and diagnostic data will be briefly unavailable while the container restarts.

This issue has been resolved in F5OS-A .1.5.3 and 1.8.0.

Additional Information

The diag-agent service performs diagnostic activities such as Power-On Self-Test, On-Line diagnostics, Off-Line diagnostics on the system.
