Description

  • Kerberos SSO fails

Environment

  • APM
  • Kerberos SSO
  • Error message in /var/log/apm:
    014d0005:3: Kerberos: can't decrypt S4U2Self ticket for user user@domain.com - Decrypt integrity check failed (-1765328353)

Cause

This error is caused by a mismatch between the BIG-IP's crypto key and that the key distribution center (KDC) stores.

Recommended Actions

  • Clear Kerberos cache on BIG-IP by restarting websso:
    bigstart restart websso
  • Reset the Delegation Account password if any change has been made to the Account tab, such as AES supporting enabling or UPN name change. This will force to re-create the crypto key. * Do not forget to update this password on APM as well *
  • Change the service account from service.account to HOST/service.account@mydomain.com
    • Ensure to match the realm name to be uppercase or lowercase (i.e: host/service.account@mydomain.com or HOST/service.account@mydomain.com
    • This change has to be set on both F5 Kerberos SSO configuration and on Active Directory Delegation Account.
