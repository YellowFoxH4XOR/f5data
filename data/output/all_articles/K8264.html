Topic

You can configure an XML profile within the BIG-IP ASM security policy to protect XML-based web traffic. When you create the XML profile, you define the validation configuration by importing an XML-based schema file into the profile. The XML profile then protects XML applications by validating whether the incoming traffic complies to the predefined schemas or WSDL documents.

If the security policy processes a request where the XML data does not comply to the elements defined in the schema file or WSDL documents, the following violation will be logged to the /var/log/asm file, and to the Reporting screen in the Configuration utility:

XML data does not comply with schema or WSDL document

For example, if the request contains XML data that includes a tag not defined in the schema file or WSDL documents, the request will be blocked by the BIG-IP ASM security policy.
