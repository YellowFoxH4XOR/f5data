Description

The Endpoint Inspection engine used by F5 is based on the OESIS SDK inspection library from OPSWAT. It is used by both the Standalone Desktop "BIG-IP Edge Client" and the Browser Helper application of the Browser Initiated APM connections, and is now being included if the MacOS "F5 Access" client versions.

When will APM EPSEC support this new update/release AV or Malware product, so that my users can install it?
Sometimes new products are released or upgraded and no longer get recognised by the existing Malware detection capabilities in APM.

Environment

Relevant environmental factors specific to the topic

  • APM Access Policy with Endpoint Inspection 
  • Vendor AV or Malware products configured

Cause

OPSWAT OESIS EPSEC releases are regularly rebuilt and are now targeted for release early each month.
Sometimes they do not recognise new products or new versions of old products.
Some Vendors provide advance notice of significant changes in their products, and provide pre-releases to allow OPSWAT to enhance the performance in advance. Some vendors deliberately change and obfuscate the logs and provide no assistance for reverse engineering the 

Recommended Actions

With each release, your particular products may be listed in the latest release notes, always upgrade to this months version  version.

For each monthly release, there is an itemised release notes for Windows, MacOS and Linux published on MyF5.com downloads under "BIG-IP" the product "APM Epsec' and the date code.

You should consider the security policy implementations of using the VPN Access policy to deny connections when customers have just upgraded to a security product that is not being recognised. It may be more important that the customers be allowed to connect, and in this case the policy may need to be updated to bypass the security product detection and instead us a file or process check to provide that gateway check. Then when the full check is working again it can be used.

Additional Information

Updated releases from F5 are targeted for the second Tuesday of each month, generally the releases are a weeks behind those from OESIS.
An up-to-date view of the real time Opswat supported products can be browsed on the OESIS SDK sites
