K000136125: iHealth is improperly flagging some objects as orphaned

Description

iHealth is reporting some monitors as orphaned when they are actually in use.

Environment

  • qkview
  • Created using the GUI of the Big-IP
  • Uploaded to iHealth

Cause

When a qkview is generated using the GUI it omits some of a data in the mcp_module.xml file that we use for heuristics. Specifically it excludes the <monitor_instance> tags when the configuration is larger and those are used to identify if a monitor is in use. As a result iHealth will flag those objects as orphaned objects in error.

Recommended Actions

This is just a cosmetic issue. If you want iHealth to report for the orphaned objects properly then run the command qkview -s0 <filename> from the command line and upload that qkview.
