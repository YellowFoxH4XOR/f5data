K10003130: SSLO 7.5 must use BIG-IP 15.1.1 or later version

Type
Support Solution
Published
2021-01-25
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K10003130

Description

SSL Orchestrator 7.5.x does not work with BIG-IP prior to 15.1.1.  You need to use BIG-IP 15.1.1 or later with SSL Orchestrator 7.5.x. 

Note: The download link for the BIG-IP 15.1.1 RPM is under the "15.1.0 - security" page.   

Environment

  • BIG-IP 15.1.1 or later. 
  • SSL Orchestrator 7.5.x.

Cause

This is by design. 

Recommended Actions

None.

Additional Information

None.
