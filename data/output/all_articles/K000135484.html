Support Solution
Published

Updated

Applies to

  • BIG-IP ASM: 17.1.X, 17.1.0
Source

Description

You are getting error message below after upgrade.

 

DOS application (dos-hidden): Cannot edit First Response Body while its type is Default in CAPTCHA Response Settings.

 

Environment

  • ASM

 

Cause

This is documented as ID1316529.

 

Recommended Actions

  1. Edit the /config/bigip.conf, 
    vi /config/bigip.conf
  2. Search for line containing "type" below DOSL7.captcha.support_id statements
  3. If none then add "type custom" or If "type default" is found then change to "type custom"
    Your support ID is: %DOSL7.captcha.support_id%."

type custom ---->!!!!

}

first {

body "This question is for testing whether you are a human visitor and to prevent automated spam submission.

<br>

--

Your support ID is: %DOSL7.captcha.support_id%."

type custom ---->!!!!

}

}

tps-based {

mode off
  4. Save the /config/bigip.conf, 
    :wq
  5. Load the configuration, 
    tmsh load sys config
  6. Configuration should be loaded successfully.
