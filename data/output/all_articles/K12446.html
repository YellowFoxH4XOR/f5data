Known Issue

This is the result of a known issue. If the Client Certificate field for an SSL client profile is set to auto, TMM may crash.

The code that inspects the peer certificate variable expects the variable to be set to ignore, request, or require. The BIG-IP system sees the variables for ignore, request, and require as all being set to false and sends a certificate request to the client. SSLv3 clients respond with a warning alert. Earlier versions of SSL respond with an empty certificate. Since the BIG-IP is expecting a certificate, the warning alert causes issues with the SSL stack and triggers a TMM crash. The error message may appear similar to the following example:

Connection error: ssl_hs_rx_cert:1158:no certificate

Note: A similar error message may display in the Local Traffic logs if the SSL logging option is set to debug.

F5 Product Development tracked this issue as ID 340336 and it was fixed in BIG-IP 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, WebAccelerator, APM, or Edge Gateway release notes.

Additionally, this issue has been fixed in cumulative Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Workaround

You can work around this issue by changing the Client Certificate drop-down menu to ignore, request, or require. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Under Local Traffic, hover over Profiles and then SSL.
  3. Click Client.
  4. Click the profile that has the auto setting.
  5. In the Client Authentication section, select either ignore, require, or request from the Client Certificate drop-down menu.
  6. Click Update.
