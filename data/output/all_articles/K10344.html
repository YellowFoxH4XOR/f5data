Known Issue

This is the result of a known issue. Certain configurations cause the BIG-IP GTM system to log gateway error messages for a default gateway pool in another datacenter.

For example, if your BIG-IP GTM configuration contains two datacenters (one datacenter with no defined links and one datacenter with a default gateway pool and links to another subnet), the BIG-IP GTM system with no defined links might log an error message in the /var/log/gtm file that appears similar to the following example:

gtmd: 011a1002:2: Can not find GATEWAY target member <gateway_pool_member> for pool <default_gateway_pool>

F5 Product Development is tracking this issue as ID 247173 (formerly CR110976).
