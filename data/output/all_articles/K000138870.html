K000138870: BIG-IQ is not showing application stats for BIG-IP

Type
Support Solution
Published
2024-03-13
Updated
2025-06-29
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.4.0, 8.3.X, 8.3.0
Source
https://my.f5.com/manage/s/article/K000138870

Description

BIG-IQ is not showing application statistics for one BIG-IP. But, statistics is showing under BIG-IQ monitoring tab. The same application is showing statistics of other BIG-IP. 

Environment

  • GUI
  • BIG-IQ
  • Applications
  • Monitoring

Cause 

Stats sent by avrd didn't contain the correct "application" tag

Recommended Actions

1. Make sure the BIG-IP HA peer is synced. 

Figure: BIG-IP GUI showing In Sync

2. If not, sync it from BIG-IQ GUI, DSC group under Devices > BIG-IP Clusters > DSC Groups.

3. Perform a dummy change on the application service (e.g. change the description text) and save the change. This will force a new deployment of application to the managed BIG-IP.

If in case the issue still persist even after syncing managed BIG-IP configuration, then follow the Recommended Action mentioned in K000152235: Analytics/Statistics/Data missing from Application tab of BIG-IQ
