K36167027: Case sensity operand breaks the LTM policy rules

Type
Support Solution
Published
2021-12-31
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K36167027
Description

A Local Traffic Policy disrupts the traffic by applying the incorrect rule action. For example, in a URI-based pool selection policy the traffic could be sent to the wrong pool.

Environment

  • Virtual server with a Local Traffic Policy
  • The rule operands don't have the same case type, for example the http-uri value of the following rules:

rule_1 {
    actions {
        0 {
            forward
            select
            pool /Common/pool_1
        }
    }
    conditions {
        0 {
            http-host
            host
            starts-with
            values { domain1.com }
        }
        1 {
            http-uri
            path
            starts-with
            values { /MyURI }
        }
    }
}


rule_2 {
    actions {
        0 {
            forward
            select
            pool /Common/pool2
        }
    }
    conditions {
        0 {
            http-host
            host
            starts-with
            values { domain2.com }
        }
        1 {
            http-uri
            path
            starts-with
            values { /myURI}
        }
    }
}

Cause

ID1059573-3: Variation in a case insensitive value of an operand in LTM policy may fail in some rules.

Recommended Actions

Make sure that all the operands have the same case.
