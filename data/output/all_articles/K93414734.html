Description

You want to change the default boot volume location.

Note: The default behavior of the BIG-IP sets the default boot volume location when you boot into or activate a new boot volume location. Unless you specify a tmsh reboot command as listed below, a normal reboot will boot back into the current boot volume location.

Environment

  • BIG-IP
  • Multiple boot volumes

Cause

As designed

Recommended Actions

Note: If you have a VIPRION platform, please see the article K9296: Changing the default boot image location on VIPRION platforms

Note:  Changing the default boot volume will not carry over the current configuration or licensing to the new boot volume.

Perform one of the following:

  • Use the Configuration utility to select a new boot volume location
  1. Log in to the Configuration utility of the BIG-IP system.
  2. Go to System > Software Management > Boot Locations.
  3. Select the desired boot volume to be used as the new default boot location.
  4. To confirm the selection, select Activate.
  5. To confirm the action to boot into the newly selected boot location, select OK.

    Important: The BIG-IP system will reboot immediately into the selected boot volume.
  • Use tmsh to select a new boot volume location
  1. Log in to the command-line of the BIG-IP system.
  2. Determine the current active boot volume by entering the following command:
    tmsh show sys software status
    Output may appear similar to the following example:

    config # tmsh show sys software status
    --------------------------------------------------------------------
    Sys::Software Status
    Volume  Product   Version   Build  Active    Status  Allowed Version
    --------------------------------------------------------------------
    HD1.1    BIG-IP  15.1.2.1  0.0.10     yes  complete              yes
    HD1.2    BIG-IP  13.1.0.6   0.0.3      no  complete              yes

    Note: You can see that in the above example HD1.1 is currently the Active  boot volume.
     
  3. To change the default active boot volume, use the following command syntax:

    Important: The BIG-IP system immediately restarts when this command is executed.

    tmsh reboot volume <location>

    For example:

    tmsh reboot volume HD1.1

    The BIG-IP system will restart immediately.

Additional Information

Use the switchboot interactive utility to select a new boot volume location.

  1. Log in to the command line of the BIG-IP system.
  2. Enter the switchboot interactive utility by entering the following command:


    switchboot

  3. From the switchboot interactive menu, you will see the current boot volume as indicated with (default). To change the default boot volume to another location, use the up or down cursor keys to go to the desired location.
  4. To confirm the selection of the boot volume, use the left or right cursor keys to toggle and select OK.
  5. To complete the selection and request the BIG-IP system to restart into the new boot volume, press Enter.
  6.  If your BIG-IP system does not automatically reboot after performing step 5, you will want to run the reboot command:

    reboot
