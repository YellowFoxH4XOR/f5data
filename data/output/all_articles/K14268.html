Topic

Important: FirePass 7.0.0 with HF-70-8 supports Windows 8. Windows 8.1 is not supported on any released FirePass versions.

You should consider using this procedure under the following condition:

  • You need to detect Windows 8.1 or Windows 8 clients accessing the FirePass controller.

Description

FirePass supports detecting the operating system that is accessing FirePass. You can perform this action through the Check OS action of a pre-logon sequence. The Check OS action for current versions of FirePass does not detect Windows 8.1 and Windows 8 clients. However, you can modify the Windows NT Check OS action to also test for Windows 8.1 and Windows 8 by performing the following procedure.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • FirePass is configured with a pre-logon sequence that uses the Check OS action.

Procedures

Adding test for Windows 8.1 or Windows 8

The following procedure will add a condition to the Windows NT-based branch of the Check OS action to check if the client is Windows 8.1 or Windows 8.

Impact of procedure: Performing the following procedure should not have negative impact on your system.

  1. Log on to the FirePass Administrative console.
  2. Click Users.
  3. Click Endpoint Security.
  4. Click Pre-Logon Sequence.
  5. To add Windows 8 detection, click edit next to the name of the pre-logon sequence.

    Note: If the pre-logon sequence is currently active, you will need to click backup & edit.
  6. Click the Windows NT based branch of the Check OS action.

    The details for the action rule display in the UPDATE RULE text box.
  7. Add the following text to the current rule.

    OR session.os.platform == "Win8" OR session.os.platform == "Win8.1"

    Note: Windows 8.1 clients may be detected as WinNT.
  8. Click Update.

    The update is applied immediately.
