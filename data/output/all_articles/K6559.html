Topic

You can block a specific URI or portion of a URI by creating a regular expression and applying it to a policy.

Creating a regular expression

  1. In the main navigation pane, select Web Applications.
  2. In the menu, select Options.
  3. Click Create.
  4. Enter a name for the regular expression.
  5. Enter the regular expression.
  6. Click Save.

Applying the regular expression to a policy

  1. In the main navigation pane, select Web Applications.
  2. Select the web application you want to associate with the regular expression.
  3. In the Policies List section, select the policy you want to associate with the regular expression.
  4. Click the Negative RegExp tab.
  5. Click Create.
  6. Select the name of the regular expression you created in Creating the regular expression procedure and follow the prompts.
  7. Click Create.
  8. Click Set Active Policy.
