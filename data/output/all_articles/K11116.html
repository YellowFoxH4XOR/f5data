Topic

The BIG-IP nPath feature is a load balancing behavior that routes return traffic around the BIG-IP system directly to the client.

Notes: nPath routing is also known as asymmetric routing or Direct Server Return (DSR). For more information, refer to the Introducing nPath Routing section of the BIG-IP Local Traffic Manager: Implementations manual. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

When you configure nPath routing for virtual servers using Clustered Multiprocessing (CMP), client connections may fail due to the default BIG-IP source port behavior. When CMP-enabled virtual servers translate the client source port in an nPath configuration, because the BIG-IP system does not receive the return traffic to reverse the source port translation, the port on which clients receive SYN/ACK responses is different than the one from which the SYN was sent. As a result, clients cannot establish connections with the servers behind the virtual server. To prevent this port translation behavior, refer to the following configuration requirements:

  • Create a custom FastL4 profile with the Loose Close setting enabled.
  • Create a pool that contains the content servers.
  • Define a virtual server with port and address translation disabled.

    Note: Ensure that SNAT is set to None on the virtual server.

  • Assign the custom FastL4 profile to the virtual server.
  • Configure the virtual server address on each server loopback interface.
  • Set the default route on your servers to the router.
  • Enable srcport preserve strict for the virtual server.

    Note: Selecting the preserve strict option for the srcport setting forces the BIG-IP system to preserve the source port in all cases. Note the following about the srcport preserve strict option:

    • Starting in BIG-IP 11.3.0, the option is available for TCP and UDP traffic.
    • Prior to BIG-IP 11.3.0, the option is available for UDP traffic only.
    • Starting in BIG-IP 11.5.0, the option is listed in the Virtual Server Configuration section, under Advanced, and the default value is Preserve.

F5 recommends using the srcport preserve strict option only when using nPath to load balance connections and for certain other traffic profiles. Using this option for other TCP traffic may have unintended consequences.
