K5674: Failover pair enters an active-active state after an upgrade to version 5.4 or later

Topic

FirePass version 5.4 introduced a new failover subsystem that requires both units of the failover pair to use the same failover subsystem in order to communicate properly.

If the FirePass failover pair are not using the same failover subsystem, they could enter into an undesired active-active condition. In this situation, all network configuration and failover settings on the FirePass failover pair appear to be correct; however, the units will not synchronize.

Note: For more information, refer to K5611: FirePass Version 5.4 introduces a new failover subsystem.

Note: For more information, refer to K5651: Verifying which failover subsystem is being used by FirePass.
