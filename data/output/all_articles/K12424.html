Topic

The BIG-IP Edge Portal application for Apple iPhone, iPad, and iPod Touch supports the use of client certificates. In order to install the certificates for the BIG-IP Edge Portal application, you must load the required client certificates onto the iOS.

Installing a certificate from your local computer

To transfer a certificate file from your local computer to the BIG-IP Edge Portal application, perform the following procedures:

Note: The following two procedures involve a third-party product, and the instructions may change without our knowledge.

Note: This procedure requires iOS 4.0.0 or later on your iPhone, iPad, or iPod touch.

Note: The BIG-IP Edge Portal application supports only PKCS#12 (.p12) certificate files.

Transferring the certificate file to the iPhone, iPad, or iPod Touch

  1. Open iTunes.
  2. Connect your device to the computer.
  3. Click on your device in the left pane.
  4. Click the Apps tab.
  5. Below File Sharing, select the Edge Portal application.
  6. Click Add.
  7. Browse to the certificate file that you want to transfer to the device.

    Important: The certificate file must be password protected. For more information, refer to K12412: The BIG-IP Edge Portal application will not load a certificate/private key that is not password protected.

  8. Click Choose.
  9. Click Apply.

The certificate file is transferred to the device.

Importing the certificate into the BIG-IP Edge Portal application

  1. Select the BIG-IP Edge Portal App icon on your iPhone, iPad or iPod touch.
  2. Select Settings.
  3. Under the Client Certificate section, select Import. 
  4. Select Local Documents.
  5. Select the name of the certificate file you transferred in the Transferring the certificate file to the iPhone, iPad, or iPod Touch procedure.
  6. Enter the password for the certificate file.
  7. Select Import.

Importing a client certificate from a web server into the BIG-IP Edge Portal application

  1. Select the BIG-IP Edge Portal App icon on your iPhone, iPad, or iPod touch.
  2. Select Settings.
  3. Under the Client Certificate section, select Import. 
  4. Select External Server.
  5. Enter the URL for the certificate you want to import.
  6. Select Load.
  7. Enter the password for the certificate file.
  8. Select Import.
