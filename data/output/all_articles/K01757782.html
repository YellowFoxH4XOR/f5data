Description
Virtual Servers on Network map not displaying correctly and showing this error:
Error getting auth token from login provider

Environment

  • BIG-IP Configuration Utility (gui)
  • Network Map

Cause
Bug ID 717174

Recommended Actions

To work around the immediate issue, restart the following services, from the BIG-IP command line using tmsh:
tmsh restart /sys service httpd
tmsh restart /sys service restjavad
tmsh restart /sys service restnoded
