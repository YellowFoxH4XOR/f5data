Description
You can encrypt a Cookie by using an HTTP profile. However, the cookie is not encrypted when you don't enter any passphrase on Cookie Encryption Passphrase.

Environment

  • You want to encrypt a cookie by using a HTTP profile.
  • You don't entered any passphrase in Cookie Encryption Passphrase on the HTTP profile.

Cause

BIG-IP allows you to save the configuration without entering any passphrase in Cookie Encryption Passphrase even if Encrypt Cookies is specified.

Recommended Actions

  1. You need to enter a passphrase to encrypt the cookie.

    The cookie is not encrypted when there is no passphrase in Cookie Encryption Passphrase.

    root@(bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)# list ltm profile http my_http_profile
    ltm profile http my_http_encrypt {
       app-service none
       defaults-from http
       encrypt-cookie-secret none
       encrypt-cookies { test }
       proxy-type reverse
    }

    test@client:~$ curl -v http://192.168.1.10/cookie_test.php
    < Set-Cookie: test=abcde

    The cookie is encrypted when there is a passphrase in Cookie Encryption Passphrase.

    root@(bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)# list ltm profile my_http_profile
    ltm profile http my_http_encrypt {
       app-service none
       defaults-from http
       encrypt-cookie-secret $M$JK$iAPH2NbWxHRE3wZE19Wysw==
       encrypt-cookies { test }
       proxy-type reverse
    }

    test@client:~$ curl -v http://192.168.1.10/cookie_test.php
    < Set-Cookie: test=!jKbyYLrl/7kJNVzmtIuDdaSKCq8jEFwUlK1fHY9KH/xUaHiMhqYdeWcKKw==
     
  2. If you want to encrypt the cookie persistence, you can use a cookie persistence profile. You can't save the cookie persistence profile when the Cookie Encryption Use Policy is set as preferred or required and there is no Encryption Passphrase.
