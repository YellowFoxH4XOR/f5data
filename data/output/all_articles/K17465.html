Topic

You should consider using this procedure under the following condition:

  • You need to determine if a published Known Issue is already resolved for a specific BIG-IP or BIG-IP Next version to facilitate the planning for an upgrade to that specific version.

Description

F5 uses a three-digit software version schema in the format A.B.C-LTS for BIG-IP Next software, where:

  • A is the major release
  • B is the minor release
  • C is the patch release
  • -LTS is the Long Term Support (LTS) designator; without this designator, the software release is a Short Term Support (STS) release. For information about LTS and STS, refer to K000135785: BIG-IP Next software support policy.

F5 uses a four-digit software version schema in the format W.X.Y.Z for BIG-IP software, where:

  • W is the major release
  • X is the minor release
  • Y is the maintenance release
  • Z is the point release

Note: The four-digit format including point release was first introduced December 19, 2017 with the release of BIG-IP 13.1.0.1. Point release replaces the previous method of using HF to note the hotfix version. For example, a hotfix previously designated as 13.1.0 HF1, is now designated as 13.1.0.1. Known Issue status tables may include both formats, depending on the BIG-IP versions affected. For information about the definitions for major, minor, maintenance, and point and their differences, refer to K8986: F5 product support policies.

F5 maintains multiple software versions in parallel for the BIG-IP product line. This means that a lower-numbered minor version could continue to receive maintenance updates, even after higher-numbered minor versions are released. For example, the following table shows the release dates for various software versions.

Product versionRelease date

The previous table shows that both 11.5.2 and 11.5.3 were released after 11.6.0, which may cause confusion when trying to determine whether certain issues are resolved in your software version, or a version to which you plan to upgrade.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You know the version of BIG-IP or BIG-IP Next software to which you plan on upgrading.

Procedures

To determine if a particular issue is resolved or fixed in a specific release, compare the versions listed in the Applies to section of the MyF5 article, with the Fixes Introduced In column of the article status table.
