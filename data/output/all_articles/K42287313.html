K42287313: Warning Alert in BIG-IQ Application: ''Analytics Profile is missing'' even if there's an HTTP analytics profiles attached

Type
Support Solution
Published
2021-03-02
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K42287313

Description

Warning message: "Analytics Profile is missing" showing up under BIG-IQ Application Page even though there's an HTTP Analytics profile associated to the virtual server in BIG-IP LTM.

Environment

  • BIG-IQ Centralized Management 7.X
  • In BIG-IP, there's already a configured analytics profile associated to the virtual server. 
  • In, BIG-IQ application dashboard, you notice that there's a warning message indicating that "analytics profile is missing". 

Cause

Unknown at the time publication. 

Recommended Actions

To resolve the issue,  you will need to re-associate the HTTP Analytics profile from the Virtual Server in BIG-IP and rediscover the BIG-IP LTM from BIG-IQ.  

  1. Go to the target BIG-IP system where the affected Virtual Server is hosted.
  2. Disassociate the profile from the virtual server by going go to  Local Traffic  ››  Virtual Servers : Virtual Server List and click on the virtual server in question. 
  3. From the Configuration list, select Advanced.
  4. In the HTTP Analytics Profile section, select None and click Update.
  5. Re-associate the HTTP Analytics Profile by assigning it back.
  6. Login back to the BIG-IQ. 
  7. Navigate to Devices > BIG-IP DEVICES
  8. Click on the BIG-IP device. 
  9. Click SERVICES. 
  10. Under Local Traffic (LTM), click re-discover. 

Additional Information
