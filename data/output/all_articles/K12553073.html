Description
This AskF5 article explains how to configure DMARC DNS TXT Resource Records via ZoneRunner utility on BIG-IP DNS systems.

Environment

  • BIG-IP DNS
  • ZoneRunner

Cause
DMARC is the abbreviation of 'Domain-based Message Authentication, Reporting and Conformance' and an email authentication protocol. On BIG-IP DNS systems, a TXT Resource Record can be configured to implement this feature.

Recommended Actions

Adding a TXT record to the ZoneRunner utility
  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to DNS > Zones > ZoneRunner > Resource Record List.
  3. Click the appropriate View Name and Zone Name.
  4. In the Name field, type the correct name for the DMARC Resource Record, for example, _dmarc.example.com..
  5. In the TTL box, type the TTL for the resource record.
  6. In the Type box, click TXT.
  7. In the Text box, enter the DMARC Resource Data enclosed in double quotation marks, for example, "v=DMARC1;p=none;sp=quarantine;pct=100;rua=mailto:dmarcreports@example.com;".
Using dig to test the new TXT record

You may run the following command syntax to test the DMARC Resource Record created.
# dig +tcp @<name_server_address> _dmarc.<zone_name> TXT
For example,
# dig +tcp @199.43.133.53 _dmarc.example.com. TXT
