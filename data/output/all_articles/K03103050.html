Description

When retrieving ASM policies using curl with root account, the following error is logged

"parse error: Invalid numeric literal at line 1, column 10"

Environment

  • BIG-IP ASM
  • ASM policies
  • curl 

Cause

The root account is not supported to retrieve the ASM policies

Recommended Actions

Instead of root account, use the admin account or any account with Administrator rights configured in the BIG-IP device to retrieve the ASM policies using the curl

# curl -sku <user:password> https://<BIG-IP hostname or management IP address>/mgmt/tm/asm/policies?\$select=name,id | jq '.'

Note:  user:password refers to admin username and password of the device

For example,

# curl -sku admin:admin https://192.168.1.2/mgmt/tm/asm/policies?\$select=name,id |jq '.'
