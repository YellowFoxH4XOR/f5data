Known Issue

Non-administrative users may be unable to access Client SSL profiles from the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You are logged in as a non-administrative user.
  • You attempt to access a Client SSL profile using the Configuration utility.

Impact

Non-administrative users are unable to view or modify Client SSL profiles using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/ltm log file, you observe an error message similar to the following example:

    01070823:3: Read Access Denied: user (<username>) type (ClientSSL CertKeyChain Entry)

  • When you select any profile under Local Traffic > Profiles > SSL > Client in the Configuration utility, you observe the following error message:

    General Database error retrieving information

Resolution

Status

F5 Product Development has assigned ID 471070 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to modify Client SSL profiles.
