Issue

Description

You have an BIG-IP APM configuration with a Active Directory (AD) AAA pool and want to log which AAA member is chosen during load balance selection.

Environment

  • BIG-IP APM
  • AAA resource with multiple servers

Cause

There is no iRules event for the AAA load balancing decision to hook to with an iRule.

Recommended Actions

Configure the following layered virtual server to provide an event to log AD server selection. 

  1. Log in to the BIG-IP Configuration utility (GUI).
  2. Create virtual servers that can listen on a single IP address on all appropriate AD ports. For more information about creating a virtual server for application traffic, refer to Manual Chapter : Configuring a Simple Intranet:
    • A virtual server listening on all TCP ports with the DCs in a pool open for all ports.
    • A virtual server listening on all UDP ports with the DCs in a pool open for all ports.
  3. Navigate to Access > Authentication > Active Directory.
  4. Click the name of the AAA server.
  5. For Server Connection, click Direct.
  6. For Domain Controller,nbsp; enter the IP you have configured for the previous TCP and UDP virtual servers.
  7. Navigate to Local Traffic > iRules.
  8. Click Create.
  9. For the Name, enter a name for the iRule.
  10. For Definition, enter the iRule that logs on the LB_SELECTED event. For example, the iRule looks something like this:

    when LB_SELECTED {
      log local0. "Chose a pool member [LB::server]"
    }

  11. Navigate to Local Traffic > Virtual Servers.
  12. Click Edit next to the virtual server in the Resources column.
  13. Click Manage next to iRules.
  14. In the Available list, click the newly created iRule and move it to the Enabled list.
  15. Click Finished. 
  16. Repeat steps 11 through 15 for the other virtual server.

    Important:: F5 Support provides only basic support, such as syntax validation, for existing iRules.
