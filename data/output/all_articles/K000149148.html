K000149148: CLI command to find which Virtual servers with cookie persistence configured doesn't have encryption enabled

Type
Support Solution
Published
2025-01-06
Updated
2025-01-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000149148

Description

CLI command to list all the Virtual Servers using Cookie Persistence that does not have HTTP cookie encryption enabled.

Environment

  • BIG-IP LTM

Cause

Identify which virtual servers with cookie persistence are not utilizing encryption. Once identified, encryption can be enabled by following the steps outlined in the article below: 

(K14784: Configuring cookie encryption within the HTTP profile)

Recommended actions

Run the following command:

 

tmsh list ltm virtual | grep 'ltm virtual\|http {' | grep '^[[:blank:]]*http { }' -B1

 

The output lists the Virtual servers that doesn't have encryption enabled, for example: 

 

root@gallery-big-ip-17-1-1-3:TimeLimitedModules::Active:Standalone] config # tmsh list ltm virtual | grep 'ltm virtual\|http {' | grep '^[[:blank:]]*http { }' -B1
ltm virtual VIP-HTTP {
        http { }
ltm virtual VIP-HTTPS {
        http { }
