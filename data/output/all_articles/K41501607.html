Description

BIG-IP HTTPS monitors only support TLS 1.3 when utilizing In-TMM monitoring rather than the default bigd-based monitoring. 

Environment

  • BIG-IP
  • HTTPS health monitor
  • TLS1.3 enabled in server SSL profile attached to HTTPS health monitor

Cause

When BIG-IP uses traditional bigd instead of In-TMM monitoring, HTTPS monitors utilize OpenSSL to perform TLS encryption/decryption. The latest version of OpenSSL available on BIG-IP is OpenSSL 1.0.2u-fips found in 16.1.0. OpenSSL version 1.1.1 is when support for TLS 1.3 was added. Consequently BIG-IP cannot request TLS 1.3 in it's HTTPS monitor probe ClientHellos when using bigd-based monitoring.

In-TMM monitoring does not utilize OpenSSL and has had full TLS 1.3 support since version 14.1.0.1 and later. HTTPS monitoring performed when In-TMM monitoring is enabled will succeed, provided the proper configuration has been performed as described in K52220418: Creating a HTTPS monitor that utilizes TLS 1.3.

Recommended Actions

If TLS 1.3 is desired in HTTPS monitor probe ClientHellos, In-TMM monitoring must be enabled, an operation with globally affects all monitoring performed by the BIG-IP.

Additional Information

See K11323537: Configuring In-TMM monitoring for information on how to enable and disable In-TMM monitoring.
