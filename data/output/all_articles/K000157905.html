Description

Users without server name extensions are unable to access a virtual server even though a sni-default ssl profile with SNI require set to false is assigned.

Following message are seen in the LTM logs.

Connection error: ssl_hs_rxhello:11746: alert(112) Profile disabled

Environment

  • Virtual server with SNI configured
  • Default SNI client ssl profile is assigned to virtual server

Cause

The sni-default SSL profile mode is set to disabled.

Recommended Actions

Enable sni-default SSL profile mode by performing following

 

  • Navigate to Local Traffic  ››  Profiles : SSL : Client 
  • select the ssl profile
  • under configuration change from Basic to Advanced  and select the check box next to Enabled
