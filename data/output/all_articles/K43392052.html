Known Issue

The Traffic Management Microkernel (TMM) produces a core file when the following occurs:

  • TMM matches a past (saved) dynamic signature of the network or DNS family.
  • The dynamic signature is disabled for that family on the parent context.
  • The dynamic signature is still enabled for other families.

This issue occurs when all of the following conditions are met:

  • You enable network and DNS BDoS (Behavioral Denial of Service) simultaneously in the DoS device configuration.
  • You generate a dynamic signature that has both network and DNS metrics.
  • You wait for the signature to be moved to past (persist) state.
  • You disable either network or DNS BDoS but not both.
  • There is traffic that matches this signature.

Impact

TMM restarts and interrupts traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TMM produces a core file and restarts.
