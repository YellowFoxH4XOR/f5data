Description

A notification can be seen in the dashboard regarding a power supply failure even though, going through the logs and the hardware status, no issue is found with the power supplies. The notification persists even though there is no issue.

 

Environment

  • Bigip LTM
  • Dashboard notification
  • Power supplies in healthy condition
  • No error logs regarding the power supplies found
  • Power supply error message might appear on the device's lcd

 

Cause

Unknown

 

 Recommended Actions

Restarting logstatd should resolve the issue and make the notification disappear.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

tmsh

  1. To restart the logstatd process, type the following command:

restart /sys service logstatd

Note: If the BIG-IP system is a VIPRION platform with more than one blade, you can restart the logstatd process from the command line by typing the following command:

clsh bigstart restart logstatd
