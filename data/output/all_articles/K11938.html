K11938: Disabling BIG-IP WebAccelerator compression for Internet Explorer 6 (IE6) clients

Topic

The Internet Explorer 6 (IE6) browser is subject to a number of known issues regarding compressed content management. As a result, when the BIG-IP WebAccelerator acceleration policy is configured to perform content compression, IE6 browsers may not be able to interpret some of the resulting compressed objects returned by the BIG-IP WebAccelerator system. Pages affected by this issue may not display correctly and application functionality may be adversely affected, especially when embedded objects, such as JavaScript and Cascading Style Sheets (CSS), are not rendered as expected.

Note: This issue does not affect later versions of Internet Explorer or other popular web browsers.

You can identify this issue by examining packet captures or using a client-side HTTP viewer to determine whether the desired content is arriving at the client but not being rendered. If compression of specific content types is confirmed to be causing issues for IE6 browsers, you can edit the BIG-IP WebAccelerator acceleration policy to disable content compression for the affected object types when they are requested using an IE6 browser. To do so, perform the following procedure:

Editing the BIG-IP WebAccelerator acceleration policy to disable content compression

  1. Log in to the Configuration utility.
  2. Click WebAccelerator.
  3. Click Policies.

    The Policy List opens.
  4. Select the user-defined acceleration policy to edit.

    Note: You cannot edit pre-defined acceleration policies. If you are using a pre-defined acceleration policy, you must copy the pre-defined policy, then edit the new user-defined acceleration policy.

  5. Find the node ID for the affected objects by matching the A field in the X-PvInfo header of the HTTP request affected by this issue.

    To find the node ID, hover the mouse over the nodes of the policy tree. Each node displays a summary of the content types and the corresponding node ID. For example, if you are using a policy based on the Level 2 Delivery policy, and IE6 is having issues with CSS or JavaScript, the appropriate node is Site >> Static >> Components >> Includes node.

    Note: For information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter in the BIG-IP WebAccelerator Policy Management Guide.

  6. Select the node by clicking on the node in the Policy Tree.
  7. Click the Copy button in the menu bar at the top of the Policy Tree.
  8. Type a name for the new node in the Name field.
  9. Click the Copy button.

    The new node appears in the Policy Tree.
  10. Select the new node in the Policy Tree.

    The Matching Rules for the node are displayed.
  11. Move the new node above the original node in the Policy Tree by clicking the up arrow button in the menu bar at the top of the Policy Tree.
  12. Select User Agent from the Add Parameter drop-down menu.
  13. Click the Add button.
  14. Select the check box next to the Value matches: drop-down menu.
  15. Click the down arrow next to Enter a regular expression.
  16. Select Internet Explorer 6.0 from the list.
  17. Click the Save button.
  18. Select Acceleration Rules from the Matching Rules drop-down menu.
  19. Select the Assembly menu tab.
  20. Clear the Enable Content Compression check box.
  21. Click the Save button.
  22. Click the Publish button.
  23. Click the Publish Now button.

Note:  If you created a new user-defined acceleration policy, associate the new user-defined policy with your BIG-IP WebAccelerator application.
