Topic

This article describes support for compression in BIG-IP network access VPN.

Description

Beginning in APM Clients 7.2.6, BIG-IP network access VPN compression is deprecated. 

Recommendation

F5 recommends disabling network compression on the client-side and server-side as soon as it is possible. This change improves system efficiency, reduces performance bottlenecks, and mitigates potential vulnerabilities linked to compression functionalities.

To do so, disable the following:

Client-side compression

To disable client-side compression, perform the following:

  1. Log in to the Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity
  3. Select your connectivity profile.
  4. Select Edit Profile.
  5. Select Compression Settings > Network Access.
  6. For gzip Compression Level, select 0-No Compression (Disabled).
  7. Select Ok.

Server-side compression

To disable server-side compression, perform the following:

  1. Log in to the Configuration utility.
  2. Go to Access ›› Connectivity / VPN, > Network Access (VPN).
  3. Select your network access resource.
  4. Select Network settings.
  5. For Compression, select No Compression.
  6. Select Update.
