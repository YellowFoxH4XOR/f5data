Description

The variable "session.client.js" tells the APM if the client is able to execute JS script or not.

But, you might ask, how is this boolean value of "session.client.js" decided?


Environment

BIG-IP

APM


Cause

This variable is expected in various configurations.

Recommended Actions

None

Additional Information

BIG-IP APM (server side) reads the HTTP request header "User-Agent" and from an internal registry decides the properties and capabilities of the client that is being used.


The provided information can be useful when the application is sending a modified user-agent.
