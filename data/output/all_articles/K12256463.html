Description

How do you create an iQuery mesh between BIG-IP DNS/GTM and LTM devices?

Environment

  • A setup consisting of 2+ BIG-IP devices with at least one of them having DNS/GTM module provisioned

Cause

None

Recommended Action

When creating an iQuery mesh from scratch the first step is to create a data center. After that you define server objects for every device to be part of the iQuery mesh. Finally, you run the bigip_add or big3d_install scripts.
For example, in an environment with one GTM and one LTM device, you create the data center object then you must define two server objects (one for each device) and run bigip_add targeting the remote LTM device IPs (those used in server object definitions).

To do this, complete the procedures in:

  • Integrating BIG-IP DNS Into a Network with BIG-IP LTM Systems

If using route domains, complete the procedure in this guide:

  • Configuring BIG-IP DNS on a Network with One Route Domain
