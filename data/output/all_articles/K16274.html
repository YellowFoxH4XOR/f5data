Topic

When you make five unsuccessful attempts to log in to the BIG-IQ user interface within five minutes, the system locks you out for five minutes.

Upon the fifth failed attempt within five minutes, the BIG-IQ system locks the affected account and reports the following message:

Maximum number of login attempts exceeded

After five minutes, you can try again. If you fail to wait the full five minutes and re-attempt to log in, the counter resets and you have to wait another five minutes from that point.

Recommendations

If you have forgotten the Administrator account login password, you can reset the password from the BIG-IQ advance shell command line by logging in as root user.

If you forgot the root account password, you must follow the Resetting a lost or forgotten root password procedure in K16275: Changing system maintenance account passwords for the BIG-IQ system.
