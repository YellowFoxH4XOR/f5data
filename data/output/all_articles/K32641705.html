Topic

This article applies to BIG-IP 11.x through 21.x. For information about other versions, refer to the following article:

  • K11838: Determining the date, time, and frequency of BIG-IP reboots (9.x-10.x)

You should consider using this procedure under the following condition:

  • You want to check the reboot history of the device.

Description

To determine when a reboot occurred, you can use the BIG-IP system's log files. Following a reboot, the BIG-IP system will log a boot marker to the /var/log/tmm.start file that appears similar to the following example:

2017-06-14T03:42:00-07:00 bigip1 notice boot_marker : ---===[ HD1.2 - BIG-IP 13.0.0 Build 0.0.1645 ]===---

If you are investigating a reboot issue, you can review a system's boot markers to determine the date and time the reboots occurred, and which slot and version the system booted into following the reboot.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have command line access to the BIG-IP system.

Procedures

You can parse the /var/log/tmm.start file and view a list of the boot markers by performing the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. For a list of boot markers, parse the /var/log/tmm.start file by typing the following command:

    egrep "boot_marker" /var/log/tmm.start

    The command output appears similar to the following example:

    2016-05-09T23:11:50-07:00 bigip1 notice boot_marker : ---===[ HD1.2 - BIG-IP 11.6.0 Build 0.0.401 ]===---
    2016-08-16T12:12:39-07:00 bigip1 notice boot_marker : ---===[ HD1.3 - BIG-IP 12.1.0 Build 0.0.1434 ]===---
    2017-02-24T03:22:57-08:00 bigip1 notice boot_marker : ---===[ HD1.3 - BIG-IP 12.1.0 Build 1.0.1447 ]===---
    2017-03-06T02:59:48-08:00 bigip1 notice boot_marker : ---===[ HD1.1 - BIG-IP 12.1.2 Build 0.0.249 ]===---
    2017-03-17T02:15:56-07:00 bigip1 notice boot_marker : ---===[ HD1.2 - BIG-IP 13.0.0 Build 0.0.1645 ]===---
    2017-06-14T03:42:00-07:00 bigip1 notice boot_marker : ---===[ HD1.2 - BIG-IP 13.0.0 Build 0.0.1645 ]===---
