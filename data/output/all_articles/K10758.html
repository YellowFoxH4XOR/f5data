Known Issue

This is the result of a known issue. After installing OPSWAT 3.4.4 or earlier, the Windows antivirus checker no longer detects AVG 9 running on Windows Vista and Windows 7. If you use a pre-logon sequence that requires real-time protection (RTP) to be enabled, clients running AVG 9 on Windows Vista and Windows 7 will fail the inspection. This issue does not occur with other versions of Microsoft Operating Systems.

Note: RTP corresponds to the Monitor is running rule in the pre-logon sequence.

F5 Product Development tracked this issue as CR131623 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue was fixed in hotfix-137605-1 (OPSWAT 3.4.9 Update) issued for FirePass versions 6.1.0, 6.0.3, 5.5.2, 5.5.1 and 5.5. You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Downloads site.
