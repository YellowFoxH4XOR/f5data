Description

How to lock or restrict access to the LCD panel on F5 rSeries (F5OS-A) to prevent unauthorized use, such as rebooting or shutting down the device via the LCD touchscreen.

Environment

  • F5 rSeries
  • LCD touchscreen panel

Cause

By default, the LCD panel on rSeries devices allows access to various management options, including reboot and shutdown. To enhance security and prevent unauthorized physical access to these functions, the LCD panel can be set to a restricted mode.

Recommended Actions

The LCD touchscreen on F5 rSeries supports three operational modes:

  • Standard: Full access to all options.
  • Secure: Only management and setup options are accessible; reboot and shutdown are not available, and no customer data is displayed.
  • Disabled: The LCD screen does not allow access to any options; only a disabled image is shown.

To lock the LCD panel and prevent reboot or shutdown via the touchscreen, set the LCD to Secure mode. To completely disable the LCD, set it to Disabled mode.

Steps to configure LCD mode from the CLI:

1.) Log in to the CLI with an admin account.

2.) Enter configuration mode:
config

3.) Set the LCD to secure mode:
components component lcd config mode secure

To disable the LCD entirely, use:
components component lcd config mode disabled

4.) Commit the changes:
commit
