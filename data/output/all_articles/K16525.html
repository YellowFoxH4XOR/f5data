Known Issue

The Traffic Management Microkernel (TMM) process may restart and produce a core file when reloading the same external data group, which has already been loaded, in rapid succession.

For example, this issue occurs if you use Traffic Management Shell (tmsh) commands within an advanced shell (bash) script that repeatedly reloads the currently loaded data group. 

Impact

The BIG-IP system may temporarily fail to process traffic, and may fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to the standby system if configured for high availability (HA).
  • The BIG-IP system generates a TMM core file to the /shared/core directory.

Workaround

There is no workaround for this issue. However, you can prevent this issue from occurring by waiting a few seconds between each reload of the same external data group. For example, if you use a bash script to automatically perform the reload of the same external data group in rapid succession, you should introduce a delay between each reload by using the sleep <desired time in seconds> bash command.

Impact of action: Your system configuration determines the impact of the suggested action; however, introducing a delay between each reload should not have a negative impact for most systems.
