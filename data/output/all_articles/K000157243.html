K000157243: NIM can't finish to register license in Kubernetes environment

Support Solution
Published

Updated

Description

When deploying NGINX Instance Manager (NIM) in a disconnected Kubernetes environment with ClickHouse disabled, you experience an issue where license registration cannot be completed.

After uploading the license acknowledgement file via either the Web UI or REST API, the NIM dashboard becomes unresponsive and times out.

Environment

  • NGINX Instance Manager (NIM) version 2.20.0 - deployed via Helm in a Kubernetes cluster

Cause

This issue occurs due to the nms-integrations service not refreshing properly after the upload process completes.

Recommended Actions

Workaround:

  1. Delete the integrations pod in the nginx-ingress namespace:  
    kubectl delete pod integrations-c6f9bb9dc-ktp94 -n nginx-ingress
    The pod will be automatically recreated by Kubernetes.
  2. Once the new integrations pod is running, retry the license registration process using either the NIM Web UI or REST API.
  3. If issues persist after these steps, collect updated pod logs and status for further troubleshooting and contact F5 support.

Permanent Fix:

Upgrade to NGINX Instance Manager (NIM) version 2.21.0 or later.
