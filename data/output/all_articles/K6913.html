Known Issue

This is the result of a known issue. When deleting an inbound wide IP address on a BIG-IP Link Controller system from the wide IP General Properties page using the Configuration utility, all pools associated with all wide IP addresses are deleted. As a result, all wide IP addresses on the BIG-IP Link Controller system are marked gray.

F5 Product Development tracked this issue as CR72176 and CR72177, and it was fixed in BIG-IP Link Controller version 9.3 and 9.4. For information about upgrading, refer to the BIG-IP Link Controller release notes.

Workaround

To work around this issue, you can remove the inbound wide IP address from the Wide IP List page of the Configuration utility by performing the following procedure:

  1. Log in to the Configuration utility.
  2. Click Link Controller.
  3. Click Inbound Wide IPs.
  4. From the Wide IP List page, check the Wide IP to be deleted, and click the Delete button.
