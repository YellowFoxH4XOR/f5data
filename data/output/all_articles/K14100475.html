K14100475: Allocating swap volume size using the BIG-IQ updateswap utility

Topic

You should consider using this procedure under the following condition:

  • You want to modify the swap volume size of the BIG-IQ system.

Description

By default, the BIG-IQ system is assigned with 1GB swap memory during the initial deployment. Beginning in BIG-IQ 8.2.0, you can adjust the swap memory allocation by using the updateswap utility located in the /usr/bin directory.

Note: Prior to BIG-IQ 8.2.0, for procedure about allocating swap memory, refer to the Workaround section of the Bug Tracker article: Bug ID 1035485.

You should review the current allocated BIG-IQ system memory when increasing the swap size. Refer to the following table for the suggested swap size:

System memorySuggested swap size
4GB8GB
8GB8GB
16GB8GB
32GB8GB
64GB8GB
96GB12GB
128GB16GB

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the BIG-IQ system.

Procedures

Allocating swap memory of the BIG-IQ system

You can allocate swap memory using the BIG-IQ updateswap utility. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ command line.
  2. To check the current allocated swap size, enter the following command:

    grep SwapTotal /proc/meminfo

    The output appears similar to the following example:

    SwapTotal:       1048572 kB

  3. To modify the swap volume size, use the following command syntax:

    /usr/bin/updateswap <swap_size_in_GB>

    For example, to allocate 8GB of memory to the BIG-IQ system, enter the following command:

    /usr/bin/updateswap 8

  4. To verify the change, enter the following command:

    grep SwapTotal /proc/meminfo

    The output appears similar to the following example:

    SwapTotal:       8388604 kB
