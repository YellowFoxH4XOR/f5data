Description
When you are trying to delete a BIG-IP ASM security policy on the WebUI, operation fails and  the error message similar to the following:
"mcpd[6678]: 01071726:3: Cannot deactivate policy action '/<partition name>/<virtual server>'. It is in use by ltm policy '/Common/<Policy Name>'."
Note: <partition name> is the name of the BIG-IP partition where the object resides, <virtual server> is the name of the virtual server where the BIG-IP ASM policy is associated.

Environment

  • BIG-IP ASM

Cause
None

Recommended Actions
If you want to delete a security policy:

  1. Deactivate it On the Main tab, click Security > Application Security > Security Policies.
    The Active Policies screen opens.

  2. Select the security policy you want to deactivate. Click Deactivate, and then click OK when prompted to confirm your action.
    If a custom local traffic policy refers to the security policy, the security policy is not deactivated.

  3. Remove mention of the security policy in the associated local traffic policy rules.
    If a default local traffic policy is associated with the security policy, the system disassociates the local traffic policy first, then deactivates the security policy. The system moves the security policy to the Inactive Security Policies list, and permanently deletes all of the request log entries generated by the deactivated security policy.
