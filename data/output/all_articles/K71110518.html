Description
In the case you are attempting to logout from an OpenID source and need an ID Token (JWT) you may need to decrypt the id_token variable

Environment

  • BIG-IP APM
  • OpenID (eg Okta)

Cause
Full ID tokens are encrypted using the F5 Secure Vault feature.

Recommended Actions

  1. To retrieve the unencrypted token instead of using
    ACCESS::session data get session.oauth.client.last.id_token
    add the -secure flag
    ACCESS::session data get -secure session.oauth.client.last.id_token
  2. The -secure flag can also be used with the mcget command in the Access Policy
