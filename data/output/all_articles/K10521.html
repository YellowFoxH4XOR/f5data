Known Issue

This is the result of a known issue. The FTP security profile does not pass FTP traffic after upgrading BIG-IP ASM or PSM to version 9.4.6.

F5 Product Development tracked this issue as CR111334-1 and it was fixed in BIG-IP 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP ASM or PSM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIG-IP-9.4.6-425.0-HF3, which has been issued for BIG-IP 9.4.6. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Workaround

If installing Hotfix-BIG-IP-9.4.6-425.0-HF3 or later is not possible, you can work around this issue by performing the following two procedures:

  • Adding missing records to the MySQL database
  • Updating the security policy using the Configuration utility

Adding missing records to the MySQL database

To add missing records to the MySQL database, perform the following procedure:

  1. Log in to the command line.
  2. Obtain the MySQL database password by entering the following command:

    perl -I/ts/packages -MGenUtils -e 'print get_mysql_password().qq{\n}'

  3. Log in to the MySQL database using the following command where [PASSWORD] is the output from the previous command:

    mysql -p[PASSWORD]

  4. Enter the following mysql command:

    INSERT IGNORE INTO PLC.HSL_PROFILES_FTP_CONFIG (hsl_profile_id) SELECT hsl_profile_id from PLC.HSL_PROFILES WHERE hsl_profile_type_id=1;

  5. Exit the MySQL database by typing the following command:

    exit

Updating the security policy using the Configuration utility

To update the security policy using the Configuration utility, perform the following procedure:

  1. Click Web Application from the Main tab of the Application Security menu.
  2. Click the relevant web application.
  3. Click Policy.
  4. Click Apply Policy.
  5. Click Classes from the Main tab of the Application Security menu.
  6. Click the class that is associated with the security profile.
  7. In the Configuration section, select Disabled from the Application Security drop-down menu.
  8. Click Update.
  9. In the Configuration section, select Enabled from the Application Security drop-down menu.
  10. Click Update.
