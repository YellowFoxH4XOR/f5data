K274: BIG-IP does not allow a wildcard certificate that contains multiple wildcards

Known Issue

This is the result of a known issue. BIG-IP only allows you to use a wildcard certificate that is in the following form:

*.<domain name>.<category>.

For example, BIG-IP will allow:

*.askf5.com

BIG-IP will not allow:

*.*.askf5.com

F5 Networks Product Development is tracking this issue as CR17426 and CR24720. Monitor future BIG-IP Release Notes for the status of these CRs.
