Topic

This article applies to BIG-IP 12.x through 15.0.x. For information about other versions, refer to the following articles:

  • K76898322: Viewing Client SSL profile connection data (15.1.0 and later)

This article discusses viewing and understanding SSL connection data for Client SSL profiles.

Description

The BIG-IP system displays SSL connection-related data in a table format similar to the following example.

ConnectionsOpenMaximumTotal
Native12011002000
Compatibility10200400
Total14014502450

Field descriptions

  • Open represents the number of currently open SSL connections.
  • Maximum represents the highest number of SSL connections at one time.
  • Total represents the cumulative number of SSL connections after a system restart or statistics reset.
  • Native represents the number of SSL connections using the BIG-IP system's NATIVE SSL stack.
  • Compatibility represents the number of SSL connections using the BIG-IP systems COMPAT SSL stack.
  • Total represents the total number of all SSL connection attempts including unfinished and failed SSL connection attempts.

Important: The Total value may be greater than the sum of Native and Compatibility.

Viewing SSL connection statistics for a single Client SSL profile using tmsh

  1. Log in the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To view connection statistics for a Client SSL profile, use the following command syntax:

    show ltm profile client-ssl <profile_name> | grep -m 1 Connections -A 3

    For example, to view connection statistics for a Client SSL profile named example_ssl, enter the following command:

    show ltm profile client-ssl example_ssl | grep -m 1 Connections -A 3

Viewing SSL connection statistics for all Client SSL profiles using the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to Statistics > Module Statistics > Local Traffic.
  3. For Statistics Type select Profiles Summary.
  4. Under Global Profile Statistics, select View for Client SSL.
  5. Locate the Connections table.
