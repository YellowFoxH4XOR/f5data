Description

Error message:  zone <reverse-ip>.in-addr.arpa/IN: loading from master file db.<reverse-ip> failed: file not found

This error can be seen when running the named-checkconf utility and a non-existence zone file referenced in named.conf.

Example:
# named-checkconf -t /var/named -z -j /config/named.conf
zone 0.0.127.in-addr.arpa/IN: loading from master file db.127.0.0 failed: file not found

Due to this error, the zrd will not start or continuously restarts in a loop.

Environment

  • Named
  • Zonerunner

Cause

A non-existence zone file is referenced in named.conf
 

Recommended Actions

To resolve this issue, disable synchronization and remove this zone from named.conf

Disabling synchronization

  1. Log into the Configuration Utility
  2. Disable the DNS synchronization 
    1. Log in to the Configuration utility.
    2. Navigate to DNS > Settings > GSLB > General.
    3. Note the current Group Name for later and change it so that it differs from the current value.
        For example, if the group name is default, change it to default_fix.
    4. Clear the Synchronize check box.
    5. Click Update.
Removing the Zone file
  1. Log into the Command Line Interface of the BIG-IP DNS device to make changes on.
  2. Create a backup copy of /var/named/config/named.conf
    cp /var/named/config/named.conf /var/named/config/named.conf.bak
  3. Stop the zrd and named daemons by typing the following command:
    bigstart stop zrd named
  4. edit /var/named/config/named.conf using editor of your choice, remove below lines and save config:

    zone "0.0.127.in-addr.arpa" in {
            type master;
            file "db.127.0.0";
    };
     
  5. Start the zrd and named daemons with the following command:
    bigstart start zrd named

Enabling synchronization

  1. Log into the Configuration Utility Log in to the Configuration utility.
  2.  Navigate to DNS > Settings > GSLB > General.
  3.  Note the current Group Name for later and change it back to the original value.
    For example, if the group name is default_fix, change it back to default.
  4.  Enable the Synchronize check box.
  5.  Click Update.
