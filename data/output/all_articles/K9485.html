Topic

By default in BIG-IP WebAccelerator version 9.x, the Configuration utility only displays HTTP classes that are enabled for the BIG-IP WebAccelerator.

Note: By default in BIG-IP WebAccelerator version 10.x, the Configuration utility displays all HTTP classes.

To display all HTTP classes, including those that are disabled, perform the following procedure:

  1. Log in to the Configuration utility.
  2. In the main navigation pane, click WebAccelerator.
  3. For BIG-IP version 9.x, click Classes.
    For BIG-IP version 10.x, click Class Profiles.
  4. In the WebAccelerator column, click the button marked with a downward-pointing arrow.
  5. Select the Show All option.
