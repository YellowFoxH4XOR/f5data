Known Issue

Running BIG-IP ASM Chart Scheduler reports may cause the ConfigSync status to change.

This issue occurs when the following condition is met:

  • Chart Scheduler reports are run either manually or automatically.

    Note: For more information about the Charts Scheduler, refer to the Configuration Guide for BIG-IP Application Security Manager.

Impact

If Automatic Sync is enabled, this results in a ConfigSync across members of the device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After a Chart Scheduler report is run, if Automatic Sync is enabled, ConfigSync occurs automatically across members of the device group.
  • After a Chart Scheduler report is run, if Automatic Sync is disabled, the ConfigSync Status shown in the BIG-IP Configuration utility and the BIG-IP command line changes to Changes Pending. Manual ConfigSync is required at this point.
  • After automatic or manual ConfigSync occurs, a message similar to the following example will be logged in the /var/log/ltm file:

    notice mcpd[7037]: 0107168c:5: Incremental sync complete: This system is updating the configuration on device group /Common/my_failover_group device %cmi-mcpd-peer-/Common/bigip2.askf5.com from commit id { 184 6008151526735204477 /Common/bigip1.askf5.com } to commit id { 187 6008154223903397128 /Common/bigip1.askf5.com }.
