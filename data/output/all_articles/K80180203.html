Description

If there are Fortigate devices on one's network, customer may see OSPF reconvergence taking an unexpectedly long time. 

Environment

  • TMOS v. 13.1.3.5 or newer
  • Fortigate device

Cause

F5 have identified ID 1024621 for this issue. 

Fortinet has a peculiar mechanism while BFD session is down: it keeps changing udp src-port and has very high slow-timer, and this cannot be broken. 

Recommended Actions

At this time, an EHF is available. Open a service request and request the engineering hotfix to remedy this issue. 

Additional Information

None.
