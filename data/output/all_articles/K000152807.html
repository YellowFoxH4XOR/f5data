Description

This article provides information of a simple Node.js/Express API to extract and serve support lifecycle tables from F5 BIG-IP knowledge base articles as clean JSON. It uses Puppeteer to fetch and render the web pages, and Cheerio to parse and extract table data.

Environment

  • Node.js version 16 and above

  • Dependencies: express, puppeteer, cheerio
  • Internet access (for Puppeteer to fetch F5 KB articles)

Recommended Actions

For code and deployment details, go to K000152807 Github Repo.

Additional Information

The script fetches and parses tables from:

  • K5903: BIG-IP software support policy
  • K4309: F5 hardware product lifecycle support policy
