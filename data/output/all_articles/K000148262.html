Description

You configured a DNS pool with Drop Packet load balance method and there is no member configured in the pool. When a DNS query hit this pool, you found the BIG-IP doesn't drop this query.

If you enabled the debugging in wideip to log the details of load balancing decisions, you will find below message in the log.

[no pool member selected - RCODE response is enabled and no pool members exist]

Environment

  • BIG-IP DNS
  • Drop Packet Load Balance
  • Return Code On Failure

Cause

The Return Code On Failure feature is enabled in the wideip. 

Recommended Actions

One of the below two actions can solve this issue.

  1. Disable the Return Code On Failure feature in wideip.
  2. Add a dummy member in the pool.

Additional Information

The dummy member in the pool won't be selected, it's just here to make the Drop Packet effect.

Typically, a pool using the Drop Packet load balancing method but containing no members is configured as the default pool for a wide IP that is using the Topology load balancing method.
