K000162719: Automatic Attack Signature Update (ASU) Status Remains Pending After Scheduled Installation

Type
Support Solution
Published
2026-08-03
Updated
2026-08-03
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 17.5.1, 17.5.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000162719

Description

After an Automatic Attack Signature Update (ASU) completes during its scheduled window, the status of the ASU update file may still show as Pending. Reviewing /var/log/liveupdate.log reveals an initial successful installation (staging: false), followed immediately by a second installation task that places the update back into staging (staging: true).

Environment

  • BIG-IP ASM / Advanced WAF
  • Real Time or Scheduled update enabled for ASM Attack Signatures

Cause

Bug ID 2260293
