Description

This article covers how to validate a list of up to hundreds of IPs.

Environment

  • BIG-IP any version
  • IP Intelligence

Cause

Have a large list of IP addresses that you want to validate against the IPI database and do not want to validate them one at a time using the iprep_lookup tool.
 

Recommended Actions

There is not a set way to do this, so creating a script to run through the list and output to a file would be a good way.

This is the script used:

  for addr in $(cat ip.txt); do iprep_lookup $addr >> iprep.txt ; done

  1. Create a text file that will contain the list of IP addresses:
    [root@bigip08:Active:Standalone] tmp # cat ip.txt
    192.168.1.1
    192.168.1.2
    192.168.1.3
    192.168.1.4
  2. Next, run the command/script, to parse through the list and append to the contents of iprep.txt:
    [root@bigip08:Active:Standalone] tmp # for addr in $(cat ip.txt); do (iprep_lookup $addr >> iprep.txt) ; done
    iprep_lookup not found for ip = 192.168.1.1
    iprep_lookup not found for ip = 192.168.1.2
    iprep_lookup not found for ip = 192.168.1.3
    iprep_lookup not found for ip = 192.168.1.4
  3. Then, check the contents of the iprep.txt file that was created:
    [root@bigip08:Active:Standalone] tmp # cat iprep.txt
    opening database in /var/IpRep/F5IpRep.dat
    size of IP reputation database = 37193772
    opening database in /var/IpRep/F5IpRep.dat
    size of IP reputation database = 37193772
    opening database in /var/IpRep/F5IpRep.dat
    size of IP reputation database = 37193772
    opening database in /var/IpRep/F5IpRep.dat
    size of IP reputation database = 37193772
