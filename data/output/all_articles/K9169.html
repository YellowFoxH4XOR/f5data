Topic

The FirePass System Logs report displays local system logs, and you can view this report on the Reports : System Logs page. The System Logs report contains information about various system events such as boot messages, service restarts, and entering and exiting standby mode (in a high availability configuration). If you configure a remote log server in the System Logs section of the Device Management : Maintenance : Logs page, additional types of messages are logged to the remote log server, such as application events and user logon and logoff events.

Additionally, if you configure a remote log server, you can enable Extended System Logs by selecting the Enable Extended System Logs option. By default, Extended System Logs are disabled on the FirePass controller. When Extended System Logs are enabled, FirePass logs additional parameters (such as form variables) which were used to trigger application events. Extended System Logs provide a greater level of detail into user activity, and may assist in troubleshooting issues.

For example, when Extended System Logs are enabled and a FirePass administrator creates a new Portal Access Web Application favorite, the remote log server displays entries similar to the following example: 

Aug 11 16:52:18 192.168.0.31 maintenance[22636]: [] [870143] Access menu Resources
Aug 11 16:52:19 192.168.0.31 maintenance[22636]: [] [870143] param a = i
Aug 11 16:52:21 192.168.0.31 maintenance[22636]: [] [870143] param group = Default_resource
Aug 11 16:52:22 192.168.0.31 maintenance[22636]: [] [870143] param cmd = add
Aug 11 16:52:23 192.168.0.31 maintenance[22636]: [] [870143] param from = -1
Aug 11 16:52:24 192.168.0.31 maintenance[22636]: [] [870143] param fisalias = [empty]
Aug 11 16:52:25 192.168.0.31 maintenance[22636]: [] [870143] param fname = Google
Aug 11 16:52:26 192.168.0.31 maintenance[22636]: [] [870143] param furl = http://www.google.com
Aug 11 16:52:28 192.168.0.31 maintenance[22636]: [] [870143] param fvariables = [empty]
Aug 11 16:52:29 192.168.0.31 maintenance[22636]: [] [870143] param fenf = [empty]
Aug 11 16:52:30 192.168.0.31 maintenance[22636]: [] [870143] param fscope = http://www.google.com/*^M
Aug 11 16:52:31 192.168.0.31 maintenance[22636]: [] [870143] param fac_key = [empty]
Aug 11 16:52:32 192.168.0.31 maintenance[22636]: [] [870143] param submit = Add New
 
When Extended System Logs are disabled and a FirePass administrator creates a new Portal Access Web Application favorite, the remote logs server displays a single entry similar to the following example:
 
Aug 11 16:52:18 192.168.0.31 maintenance[22636]: [] [870143] Access menu Resources
 
Important: By default, the Enable Extended System Logs check box is clear. Selecting this option may significantly increase the amount of log data created and stored on the FirePass controller. Additionally, selecting this option increases the CPU and memory usage on the FirePass controller. Unless otherwise required for troubleshooting or auditing purposes, FirePass administrators should consider leaving the Enable Extended System Logs option to its default setting of disabled.
 
Note: For more information about System Logs, including configuring a remote log server, refer to the FirePass Controller Administrator Guide.
