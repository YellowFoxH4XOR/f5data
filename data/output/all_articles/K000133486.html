Support Solution

Updated
2023-04-12
Applies to

Description

Zone file is not created when adding wideip to BIG-IP DNS device


Environment

BIG-IP DNS

Zonerunner

Wideip pool

Cause

Expected behaviour. The zonerunner zone file will be created after adding a pool member to the pool.

Recommended Actions

Add pool member to the pool assigned to wide ip.
