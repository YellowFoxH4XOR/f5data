Known Issue

A Network Access session dynamically created temporary folder may not be removed when you terminate the session.

This issue occurs when all of the following conditions are met:

  • You establish a Network Access session using the BIG-IP Edge Client from a device running the Windows operating system.
  • The BIG-IP Edge Client is configured with the Windows Login Integration service.
  • You access a destination resource, such as initiate an RDP session, that automatically reuses your Windows credentials.
  • You terminate your Network Access session.

Impact

The temporary folders may accumulate and consume disk space on the client's device.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When viewing the C:\Users directory on the client device after terminating the access session, a file with the following syntax remains:

    f5 Pre-Logon User.<HOSTNAME>.<xyz>

    <HOSTNAME> = the hostname of the destination resource
    <xyz> = a numeric value.

Workaround

To work around this issue, you can manually delete the f5 Pre-Logon User.<HOSTNAME>.<xyz> files from the C:\Users directory on the client device.

Impact of workaround: Performing the mentioned workaround should not have a negative impact on your system.
