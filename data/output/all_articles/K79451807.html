Description

Failure of upgrade from version 14.1.X to version 15.1.5

  • Software upgrade status: 
    show sys software
--------------------------------------------------------
Sys::Software Status
Volume  Product  Version   Build  Active  Status
--------------------------------------------------------
HD1.1    BIG-IP   15.1.5  0.0.10      no  failed (UCS application failed; unknown cause.)
HD1.2    BIG-IP 14.1.2.8   0.0.7     yes  complete

  • The following directories sizes are too big: /var/lib/mysql/PLC and /var/lib/mysql/PRX

    # du -sh /var/lib/mysql/* | grep -E 'M|G'
<snip>
1.5M    /var/lib/mysql/mysql
887M    /var/lib/mysql/PLC <<<<
1.5G    /var/lib/mysql/PRX <<<<
4.0K    /var/lib/mysql/RPM_UPGRADE_HISTORY
<snip>
  • ltm log: 
    err logmysqld[6487]: Fatal error db.cpp:exec_query:150 SELECT COUNT(*) from log_data_current errno[2013] strerror[Lost connection to MySQL server during query]
info logmysqld[23330]: Info db.cpp:connect:195 Waiting to connect to MySQL

Environment

  • F5 ASM

Cause

The BIG-IP ASM system may experience /var/lib/mysql partition file system exhaustion.
This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with multiple security policies
  • You complete one of the following actions on the BIG-IP ASM device:
    • Load the system configuration from a user configuration set (UCS) archive.
    • Synchronize the local BIG-IP ASM device to itself.
  • Your BIG-IP ASM system is synchronized to the device group.

Recommended Actions

In order to solve the issue, please follow the suggested workaround below:
Follow K25066531 and confirm that there are policy history files for non-existent security policies under /ts/dms/policy/policy_versions directory

  1. Create backup of all the files: 
    # tar zcvf /shared/$HOSTNAME-policy_versions.tar.gz /ts/dms/policy/policy_versions/*
  2. Create clean up script called /root/clean.sh with following content (this deletes policy change history files older than 180 days): 
    #!/bin/bash
for file in /var/ts/dms/policy/policy_versions/*; do
cd /var/ts/dms/policy/policy_versions/$(basename "$file")
find ./ -type f -name "*.plc" -mtime +180 -exec rm -f {} \;
done
  3. Make script executable 
    # chmod +x /root/clean.sh
  4. Execute script 
    # /root/clean.sh
  5. Check new size of the policy versions folder 
    # du -h /var/ts/dms/policy/ --max-depth=1 | grep policy_versions
