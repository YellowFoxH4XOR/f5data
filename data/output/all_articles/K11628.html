Issue

If the time on the Active Directory server and the time on the BIG-IP APM device varies by more than five minutes, the user receives an error message similar to the following example:

The username or password is not correct. Please try again.
(error: Clock skew too great, principal name: jsmith@example.com.
Please verify current time and configuration. Time skew must be less than 5 minutes.)

While the first part of the error message may lead the user to think that the credentials they supplied are incorrect, this error message actually relates to the time difference between the time on the BIG-IP APM device and the time on the Active Directory server that was queried for authentication. This error message occurs only when the authentication method inspects the time that the Active Directory server uses. To resolve this issue, ensure that the Active Directory servers and the BIG-IP APM devices are using network time protocol (NTP) services to maintain accurate time.

Configuring NTP services on the BIG-IP APM system

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Device > NTP.
  3. In the Address box, type the IP address of the NTP server you want the BIG-IP APM system to use.
  4. Click Add.
  5. Click Update.
