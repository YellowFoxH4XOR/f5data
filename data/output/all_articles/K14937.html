Known Issue

The BIG-IP APM access policy branch rules tab may not be accessible for some BIG-IP administrative roles.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with an access profile that includes access policy branch rules.
  • A user with a read-only administrative access role attempts to view the access policy branch rules in the Configuration utility visual policy editor.

    Users with the following administrative access roles cannot access branch rules:

    Auditor
    Guest
    Operator

Note: Depending on the active modules licensed for the device, there may be additional roles with this limitation.

Impact

The administrative user is unable to view the access policy branch rules.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you select an access policy action in the Configuration utility visual policy editor, the system displays the following message in the bottom left corner of the visual policy editor.

    ( Attention! This dialogue is Read-only! )

  • When you view an access policy with the Configuration utility visual policy editor, the Branch Rule tab does not respond when you click it.
