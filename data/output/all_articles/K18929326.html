Topic

You can use this F5 supported iApp template to update or replace the default CA bundle on the BIG-IP system. The iApp also contains backup and restore functionality for the CA bundles.

For instructions about using this template, refer to the Deploying the CA Bundle iApp Deployment Guide.

To download and install the iApp template, perform the following procedures:

  • Downloading the iApp template
  • Installing the iApp template

Downloading the iApp template

Important: You must download the file; do not copy and paste the contents.

  1. Go to the F5 Downloads site.
  2. From the Downloads Overview page, click Find a Download.
  3. From the BIG-IP Product Family section, click iApp Templates.
  4. From the Select a Product Version and Container for page, click iApp-Templates.
  5. Read the End User Software License Agreement and either accept the license by clicking I Accept, or cancel the process by clicking Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, which shows a table with the file name, product description, and file size details.

    Note: After you accept the End User Software License Agreement, the system will not present the agreement again for subsequent downloads that you perform during the same browser session.

  6. From the Filename column of the table, click the file named iapps-x.x.x.x.x.zip. For example, the file for the December 2017 iApp release is named iapps-1.0.0.495.0.zip.
  7. F5 supports the FTP, HTTP, and HTTPS protocols for downloading files from F5. Select one of the three supported protocols listed by clicking the down arrow button.

    A pop-up window appears, prompting you to either open or save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  8. Select the option to save the file.

Installing the iApp template

  1. Unzip the zip file to a location that is accessible from your BIG-IP system.
  2. Log in to the Configuration utility.
  3. From the iApp tab, click Templates.
  4. Click Import.
  5. Select the Overwrite Existing Templates check box.
  6. Click Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the file named f5.ca_bundle.vx.x.x that corresponds to the iApp version you want to install. For example, the file for the December 2017 release of this iApp is named f5.ca_bundle.v1.0.1.

    Note: Refer to the previously-listed Support Matrix to select the most current, supported template for your BIG-IP software version.

  9. Click Upload.

When the upload completes, the iApp is available for use.
