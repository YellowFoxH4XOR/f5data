Source

Description

  • ASM treats json string in body as a parameter
  • ASM blocks the request with "Illegal parameter" violation.
  • Traffic Learning suggestion is to "Add Parameter"

Environment

  • ASM security policy
  • JSON content profile

Cause

Seen behavior is caused a known issue tracked with the Bug ID 1014469

Recommended Actions

As a workaround you can on Security  >  Application Security > Policy Building > Learning and Blocking Settings > Parameters > Learn New Parameters set Learn New Parameters to "Never/Compact/Selective".

This will exclude the literal strings from learning suggestions to be added as a parameter.
