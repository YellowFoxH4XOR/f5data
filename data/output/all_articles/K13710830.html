Description

Enabling specific ciphers logs an error message in the GUI: 

Certificate matching the configured cipher suites doesn't exist

Environment

  • Unable to add the cipher ECDHE-ECDSA-AES256-GCM-SHA384
  • BIG-IP version 13.x or greater , supports this cipher

Cause

ECDHE-ECDSA-AES256-GCM-SHA384 can be applied to Client-side profile if the certificate associated with the profile was signed with ECDSA key.

The error occurs if the certificate is signed with a different type of key, for e.g. RSA.

Recommended Actions

Apply appropriate cipher suite to the Client-ssl profile that match the certificate signed attributes.
