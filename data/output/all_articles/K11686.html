Issue

Note: For more information about performing a clean installation of BIG-IP 10.x, refer to K10819: Performing a clean installation of BIG-IP 10.x or Enterprise Manager 2.x.

Using a USB CD/DVD-ROM drive and using a USB thumb drive are the most common installation methods to perform a clean installation of BIG-IP 10.x. Both installation methods require downloading a BIG-IP version product ISO image file from the F5 Downloads site:

  • If using a USB CD/DVD-ROM drive, you must burn the ISO image to a CD/DVD recordable.
  • If using a USB thumb drive, you must use a utility that is provided in the ISO image to copy the installation software to the drive.

Beginning with the BIG-IP 10.2.0 ISO image, when you boot the BIG-IP system from a USB removable media, the system automatically displays a manufacturing installation dialog that appears similar to the following example:

BIG-IP 10.2.2 and later versions

info: Using repository; /cdserver
This is a default, unattended installation that will erase all
previous software and configuration from this system!
If you want to retain ANY software or application configuration
present on this system, DO NOT CONTINUE.
Use <ctrl-c> to enter a Bash shell.
Press [Enter] to begin installation.

BIG-IP 10.2.0 to 10.2.1

info: Using repository; /cdserver
info: manufacturing plan for C106:
info: --- boot volume set is HD1.1
info: --- HD1.1 => BIG-IP 10.2.0 LTM.ROS.SAM.TS.WA.WOC
info: --- HD1.2 => BIG-IP 10.2.0 LTM.ROS.SAM.TS.WA.WOC
This is the manufacturing installation!
If you want to retain ANY data present on this system, do not continue.
Use <ctrl-c> to enter a Bash shell.
Press [Enter] to begin installation.

The manufacturing installation dialog greatly simplifies performing a clean installation of the BIG-IP system, as no commands need to be entered.

Pressing Enter re-images the BIG-IP system according to the manufacturing installation plan displayed in the output; pressing Ctrl+C exits the manufacturing installation dialog and takes you to a bash shell.

From the bash shell, you can run diagnostic utilities, back up data, or perform a custom installation of the BIG-IP system using the diskinit and image2disk utilities. If you want to display the manufacturing installation dialog again, type start and then press Enter.

F5 Product Development tracked this change in behavior as ID 241718 (formerly CR131461).

Important: Due to a known issue, if you exit the manufacturing installation dialog and then attempt to install BIG-IP 10.x, the installation fails. For more information, refer to K11687: After booting the BIG-IP system from a USB removable device, exiting the manufacturing installation dialog causes any ensuing software installations to fail.

Note: In BIG-IP 10.2.2 and later versions, the manufacturing installation only installs one software volume. For more information, refer to K13603: A clean BIG-IP installation installs software to only one volume.
