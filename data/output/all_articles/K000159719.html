Description

  • Reactivating trial license for your BIG-IP VE fails. 
  • Observe banner on BIG-IP GUI with the Error Message: The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.

Environment

  • BIG-IP VE 
  • 30-days trial license

Cause

 Trial license expired. 

Answer/Recommended Actions

  ​​​​Apply for new trial license when the current trial license has expired. 

Additional Information

  • The trial license end date should be based on the license activation date, not the date the license was originally applied and approved in the portal.
  • To check if your license has expired, login to the device's CLI and run this command: 
    tmsh show sys license.
  • For example, if the trial license was initially activated on 19/12/2025 and later reactivated on 19/01/2026—after the 30-day period had elapsed—you would see the output below indicating that the trial license has expired:
       Licensed On 2025/12/19
       License Start Date 2025/12/18
       License End Date 2026/01/19
