Description

Reviewing the BIG-IQ personality type can be performed via the CLI, or remotely using the iControl REST and curl. 

Environment

  • BIG-IQ 
  • CLI or REST access 

Cause

After configuring the BIG-IQ personality type to either a CM or Logging node, the personality type is written to /config/biq_provision.cfg.  

The BIG-IQ CM personality type is listed as systemPersonality: big_iq.
Th BIG-IQ Logging node personality type is listed as systemPersonality: logging_node

Recommended Actions

To review the BIG-IQ personality type, perform the following actions

  1. View the file locally with a user that has access to bash 
    cat /config/biq_provision.cfg

generated file -- do not edit #
systemPersonality: big_iq
  2. View the file remotely with a user that has access to REST, using curl 
    curl -sk -u admin:admin GET localhost:8100/cm/system/provisioning 

{"systemPersonality":"big_iq","generation":0,"lastUpdateMicros":0}
  3. For a logging node, the output shows the following for the systemPersonality type 
    curl -sk -u admin:admin GET localhost:8100/cm/system/provisioning 

{"systemPersonality":"logging_node","generation":0,"lastUpdateMicros":0}
