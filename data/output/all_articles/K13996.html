Known Issue

When deploying an F5 Virtual Edition image (OVA file) you may observe an invalid certificate warning.

If you obtain a BIG-IP or Enterprise Manager Virtual Edition image file from the F5 Downloads site, and then deploy the file using an application such as the VMware vSphere client, you may observe an invalid certificate warning. This warning is triggered because the certificate used to sign the Virtual Edition image file has expired.

This article describes the BIG-IP and Enterprise Manager variation of the issue. For information about the BIG-IQ issue, refer to K05382384: Deploying a BIG-IQ Virtual Edition image file may result in an invalid certificate warning.

Impact

None. There is no issue with the OVA file. You can safely complete the deployment process. If you use a browser with the Flash plug-in to deploy the affected image, the deployment may be blocked, and you may be prompted to use an alternative client that supports HTML5.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using software to deploy an F5 Virtual Edition image, you may observe an invalid certificate warning message that appears similar to the following example:

    ! bigipve.f5.com (Invalid certificate)

Resolution

Status

F5 Product Development has assigned ID 723130 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
