Description

Even after upgrading to fixed version of ID 1017645, ASM is still generating the violation:

Unparsable authorization header value


Environment

  • Upgrade to 13.1.4.1, 14.1.4.3 or 16.1.2


Cause

Bug ID 1022269: False positive RFC compliant violation
 

Recommended Actions
The issue is fixed from versions 14.1.4.4, 15.1.4, 16.1.2.

To work around this issue you can turn on an internal parameter by entering the following command from the BIG-IP CLI:

Impact of workaround: Performing the following procedure forces the BIG-IP system offline for a short period of time. F5 recommends that you perform this procedure during a maintenance window, this must be done on each device in the cluster.

  1. Log in to the BIG-IP command line.
  2. Enable ignore_authorization_header_decode_failure.
    /usr/share/ts/bin/add_del_internal add ignore_authorization_header_decode_failure 1
  3. Log in to tmsh:
    tmsh
  4. Restart ASM:
    restart sys service asm
