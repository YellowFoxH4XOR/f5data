K000148161: What is the difference between an Alert and an Event?

Description

  • On my F5® Distributed Cloud (XC) console dashboard I see Alerts and Events tabs, what is the difference? 
  • I see alerts but there are no events on the dashboard, is this expected?

 

Environment

  • F5® Distributed Cloud
  • DDoS Console Dashboard

Answer/Recommended Actions

  • Alert: A volumetric threshold alert generated by mitigation hardware. Every alert that appears in your timeline is investigated by the SOC. Alerts seen here can be true or false positive. An alert followed by communication from SOC indicates the alert was determined true positive or SOC is unsure and needs feedback. An alert with no further communication from SOC should indicate the alert was determined to be a false positive. 
  • Event: An event is a mitigation start, stop, or tuning. While this often means SOC is working on mitigating an attack, sometimes SOC will create "blank" mitigation profiles during alerts in order to get a more granular view of the traffic. This means it is possible for an alert and event to generate while still being finally identified as a false positive. You will know if an alert was determined questionable or true positive if the SOC contacts you via email or phone call. 
  • It is also normal to observe alerts but no events associated to an alert. This happens when an alert is identified as a false positive and no mitigation actions are required by the SOC.
