K000154608: NGINX Instance Manager – License file upload fails during verification

Type
Support Solution
Published
2025-09-16
Updated
2025-09-16
Applies to
  • NGINX Products
  • NGINX Plus: R34
Source
https://my.f5.com/manage/s/article/K000154608

Description

Users may encounter an issue where uploading the license.jwt file to NGINX Instance Manager (NIM) fails. In the UI, the following error message is displayed:

 

License file verification failed. Please make sure you are using the correct file and try uploading again. If the problem persists, contact F5 Support.

Environment

  • Product: NGINX Instance Manager version 2.20 and above.
  • Licensing: JWT license file
  • Network: Outbound connectivity via forward proxy (e.g., http://proxy.example.com:3128)
  • Proxy: Squid or similar, with domain-based access controls

Cause

The forward proxy configuration does not allow access to the required F5 licensing endpoint - product.apis.f5.com. This results in 403 Forbidden errors and prevents successful license validation and upload.

Recommended Actions

    1. Proxy Whitelisting

      • Ensure the forward proxy allows outbound HTTPS connections to:
        • product.apis.f5.com
        • product-s.apis.f5.com
      • Alternatively, whitelist the entire .apis.f5.com domain.

    2. Configure Proxy in NIM

      • Edit /etc/nms/nms.conf for NGINX Instance Manager as described in NGINX documentation.
      • Forward Proxy configuration block: 
        proxy_config:
            proxy_enable: true
            proxy_host: <proxy-ip>
            proxy_port: <proxy-port>
            proxy_protocol: [http|https]
            proxy_auth_required: [true|false]
            proxy_ssl_verify: [true|false]

      • If the proxy requires authentication, set proxy_auth_required to true, and add the following fields:

           proxy_username: "<username>"
   proxy_password: "<password>"

    3. Restart Service

      • After updating proxy settings, restart NIM: 
        sudo systemctl restart nms

    4. Retry license upload

      • Use the NIM web console to upload the license.jwt file again. 
        • Note: The same JWT license file can be used on all NIM instances covered by your subscription. See Deploy the JWT license. 

    5. Test Connectivity

      • Use curl to verify that your proxy allows access: 
        curl -s -x http://proxy.example.com:3128 \
     --location https://product.apis.f5.com/ee/v1/entitlements/products/nim \
     -H "Authorization: Bearer $(tr -d '\n' < /etc/nginx/license.jwt)"
      • Ensure you do not receive a "403 Forbidden" response.

    6. Troubleshooting

      • Increase log level to debug in nms.conf: 
        log:
  encoding: console
  level: debug
      • Sample debug log entries for proxy issues:
    DEBUG nms-llm forward-proxy/proxy.go:38 added proxy URL: [http://proxy.example.com:3128]
    DEBUG nms-llm network/ext_http_api.go:60 failed, err: [Get "https://product.apis.f5.com/...": Forbidden]
