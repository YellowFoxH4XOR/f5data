Description

The article describes the possibility of sending email alerts for ASM Security Event Logs.

Environment

  • Email alert triggered for events such as Brute Force Attacks

Cause

Previously, the security events were written to syslog by default and were logged locally to the /var/log/asm file.

This behaviour is changed since version 11.6.0.

For further details refer to Refer K16053: BIG-IP ASM does not log security events locally by default
 

Recommended Actions

If you want to collect a log of security events, you should configure remote logging on the BIG-IP ASM system and send those events to a remote log server.

Furthermore, if you want to receive emails when BIG-IP ASM security events occur, you should configure the remote log server to trap on those events and generate emails.
