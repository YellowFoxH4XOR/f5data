Issue

Error Message

Host is unreachable

Message Location

You may encounter this message in the following location:

  • The BIG-IP serial console

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP system has no functional images installed
  • You attempt to change the serial port baud rate
  • The Always-On Management (AOM) subsystem is unable to communicate with the Host subsystem

The communication between the Host subsystem and AOM subsystem must be operational for the serial port baud rate to be set successfully. When you set the serial port baud rate, the Host subsystem sets the Host serial port baud rate before signaling to the AOM subsystem to set the AOM serial port baud rate. If the communication between the Host subsystem and AOM subsystem is not operational, the serial port baud rate will be set on only one subsystem instead of both. As a result, the serial port baud rates between the AOM subsystem and Host subsystem will be mismatched, and the serial console will display garbled output. In order to prevent the mismatch of serial port baud rate between the AOM subsystem and Host subsystem, the AOM subsystem will abort the transaction and display the error message.

Impact

The BIG-IP system cannot be administered using the serial console.

    Recommended Actions

    You can set the AOM subsystem baud rate by performing the following procedure:

    1. Connect the serial console to the CONSOLE port.
    2. Display the AOM Command Menu by typing the following key sequence:

      Esc (

      The AOM Command Menu opens as displayed below:

      AOM Command Menu

      1 --- Connect to Host subsystem console
      2 --- Reboot Host subsystem (sends reboot command)
      3 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
      4 --- Reset AOM subsystem (issues hardware reset--USE WITH CARE!)
      5 --- Power off Host subsystem (issues hardware shutdown--USE WITH CARE!)
      B --- AOM baud rate configurator
      L --- AOM subsystem login
      N --- AOM network configurator
      P --- AOM platform information
    3. To log in to the AOM subsystem, type the following:

      L
    4. Log in to the AOM subsystem as root.
    5. To set the AOM subsystem baud rate, type the following command:

      bootenv baudrate <rate>

      For example, to set the AOM subsystem baud rate to 19200, you would type the following:

      bootenv baudrate 19200
