Known Issue

The Packet Correlation Classification Daemon (PCCD) process may restart due to an out of memory state.

This issue occurs when the following condition is met:

  • The BIG-IP AFM system is configured with a large firewall rule set.

Impact

While the PCCD process is restarting, the BIG-IP AFM system is unable to detect and compile firewall configuration changes.

Note: The firewall configuration that was successfully serialized for the Traffic Management Microkernel (TMM) before PCCD restarted continues to be enforced.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H557678 on the Diagnostics > Identified > High screen.
  • Messages similar to the following example are logged to the /var/log/ltm file:

    emerg pccd[13033]: 015d0000:0: Serialization failed: out of memory
    emerg pccd[13033]: 015d0000:0: Transaction failed.
  • The PCCD process produces a core file in the /var/core directory

Resolution

Status

Workaround

To work around this issue, you can provision more memory for the PCCD process. To do so, contact F5 Technical Support for instructions about configuring and deploying a custom provisioning table to make sure the module receives adequate memory resources.

Impact of workaround: Incorrect modification to the BIG-IP provisioning tables can lead to system instability, and should be done only at the request of and under the supervision of F5 Technical Support.
