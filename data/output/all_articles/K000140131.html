Description

An iRule containing

proc {} {

This results in a message  in /var/log/ltm

can't parse TCL script beginning with\n\n \nproc

Environment

Using REST to create the iRule.

Cause

This is issue ID1600669 "Inconsistency in iRule parsing for iControl REST and tmsh/WebUI"

Recommended Actions

Add a space. It then becomes:

proc { } {

None
