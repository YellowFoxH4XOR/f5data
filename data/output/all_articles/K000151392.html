Description

After installing BIG-IP VE on KVM with a single NIC configuration, you observe that ICMP traffic is unreachable to the BIG-IP instance.

Environment

BIG-IP
KVM
Single NIC configuration

Cause

ICMP or ping is unreachable because there is no iptables rule for ICMP on the BIG-IP. F5 filed this issue as ID 1295217.

Recommended Actions

You can run the following command on the BIG-IP to add an ICMP rule.

# /sbin/iptables -t raw -I vadc_rawsock_in -p icmp -j ACCEPT
