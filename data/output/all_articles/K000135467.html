Description

SSLO audit log behavior when making configuration changes.

 

Environment

SSLO
Audit logs

Cause

Logging behavior when making configuration changes.

 

 Recommended Actions

None

Additional Information

SSLO makes all its transactions using the primaryadminuser (output from `tmsh list sys db systemauth.primaryadminuser one-line`) so MCPD (and by extension the audit log) will only show that admin user.

 

Any change from an admin that is a defined user to track configuration changes for SSLO will not show that user since SSLO uses the primary user admin to log the changes in the audit logs and this is by design.
