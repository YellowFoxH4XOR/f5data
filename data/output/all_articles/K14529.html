Known Issue

The Configuration utility may not make child Gateway ICMP monitors available when creating or modifying a BIG-IP GTM link.

This issue occurs when all of the following conditions are met:

  • You have created a child Gateway ICMP monitor with the transparent option set.
  • You are attempting to assign this child Gateway ICMP monitor to a GTM link using the Configuration utility.

Impact

You may not be able to assign a child Gateway ICMP monitor using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H425500 on the Diagnostics > Identified > Medium screen.
  • Child Gateway ICMP monitors are unavailable for selection in the Configuration utility when creating or modifying a BIG-IP GTM link.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to assign the child Gateway ICMP monitor to the BIG-IP GTM link. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the Configuration utility as the administrative user.
  2. Create the BIG-IP GTM link using the standard gateway_icmp Gateway ICMP monitor.
  3. Log in to Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  4. Modify the monitor for the existing link to use the child Gateway ICMP link using the following command syntax:

    modify /gtm link <link_name> monitor <monitor_name>

    Note the following:
    • <link_name> is the name of the existing link you want to modify.
    • <monitor_name> is the name of the child Gateway ICMP monitor you want to use.
  5. Save the change by typing the following command for your version:
    • BIG-IP 10.1.0 and later:

      save /sys config
    • BIG-IP 10.0.x:

      save config
