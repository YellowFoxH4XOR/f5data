Known Issue

Configuration synchronization (ConfigSync) may fail when you delete and recreate a pool member with a node name set.

This issue occurs when all of the following conditions are met:

  • You delete an existing pool member that has a node name set.
  • You re-create a pool member using the same node name but a different IP address.
  • You attempt to load the configuration locally using the TMOS Shell (tmsh) or synchronize the configuration to a peer device in the device group.

    Note: In BIG-IP 11.4.0 and later, this issue only occurs when a full sync is performed. Full loads may complete, even if the full-load-on-sync setting is false for the device group.

Impact

You are unable to load the configuration locally or synchronize the configuration to peer devices in a device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When loading the configuration locally using the tmsh load sys config command, or synchronizing the configuration to a peer device, you observe an error message similar to the following example:

    0107003c:3: Invalid pool member modification. An IP address change from (192.168.1.1) to (192.168.1.2) is not supported.

  • In the /var/log/ltm file, you observe an error message that appears similar to the following example:

    01070734:3: Configuration error: Invalid pool member modification. An address change from 192.168.1.1 to 192.168.1.2 is not supported.

Workaround

Important: Applying this workaround may trigger ID 638091. You should review ID 638091 and fixed versions before applying this workaround.

To work around this issue, you can synchronize the configuration just after deleting the pool member and node, before recreating the pool member. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may impact client connectivity to the node. You should perform this procedure only during a maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools and click the pool with the member you want to delete.
  3. Click the Members tab.
  4. Select the check box next to the pool member you want to delete and click Remove.
  5. Navigate to Local Traffic > Nodes.
  6. Select the check box next to the node with the same name and click Delete.
  7. Navigate to Device Management > Overview.
  8. Click the local device by hostname (self).
  9. Click Sync.
  10. If the ConfigSync was successful, you may now recreate the pool member.
