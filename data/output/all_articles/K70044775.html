K70044775: Partition choice when generating HSM key in multi-partition environment on nShield Luna HSM

Type
Support Solution
Published
2026-09-28
Updated
2026-09-28
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K70044775

Description
Two or more HSM partitions are configured on nShield Luna HSM.
HSM key was generated without specifying partition name or used partition=auto (tmsh) or Default partition (GUI).
 

Environment

  • BIG-IP LTM, version: 14.x,15.x,16.x,17.x,21.x
  • nShield Luna HSM (former Safenet Luna)

Cause
Explanation on partition choice:

Default partition (GUI) or "auto" partition (tmsh) is a special partition name that is ONLY created and exists on BIG-IP.
When we create a key using partition auto or without specifying partition at all, it will always connect to the HSM partition that is referenced as crypto slot1 on the Luna HSM. The partitions order is according to the output of "vtl listSlots" HSM utility command.
For example (depending on the nShield Luna software/firmware versions, the output in actual setup might differ):

[root@localhost:Active:Standalone] config # vtl listSlots

Number of slots: 2

The following slots were found:

Slot Description          Label                            Serial #         Status
==== ==================== ================================ ================ ============
   1  LunaNet Slot         par0                            XXXX             Present
   2 LunaNet Slot         par1                             XXXX             Present

In the case of this example, when we use Default partition or "auto" or no partition at all when generating an HSM key it will created on partition par0 on HSM.

For reference, below are HSM key generation commands examples:

tmsh create sys crypto key autohsmkey1 security-type nethsm nethsm-partition-name auto  or
tmsh create sys crypto key autohsmkey1 security-type nethsm

Or via GUI:
Browse to System  ››  Certificate Management : Traffic Certificate Management : SSL Certificate List ››  New SSL Certificate...
Choose NetHSM key and Default Partition under Key Properties section.

Recommended Actions
In multi-partition environment, it is recommended to specify the exact nethsm partition during HSM key creation to avoid confusion.
