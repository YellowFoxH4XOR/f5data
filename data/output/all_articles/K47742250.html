Description

The BIG-IP system provides the ability to monitor DDM  alerts or warning by Simple Network Management Protocol Trap.

Environment

  • BIG-IP 5000, 6900, 7000 ,8900, 10000, 11000, 12000 Series
  • VIPRION B2100, B2150, B2250, B4300, B4450

Cause

For the Digital Diagnostic Monitoring (DDM) capability available on F5 platforms, you can use the industry-standard System Management Network Protocol (SNMP) protocol to read information collected from optical transceiver modules, when available. This information is in BIG-IP Core Statistics. You can use SNMP and the F5-BIG-IP-SYSTEM-MIB file to access this information.

Recommended Actions

The following table lists the alert and warning with their official SNMP Object name, SNMP Trap OID, and description.

Object Name

OID

Description

BIGIP_BCM56XXD_BCM56XXDERR_DDM_ALARM

.1.3.6.1.4.1.3375.2.4.0.158

This is alarm when either the receive or transmit power of a particular SFP was detected to be too high or too low. The error message will contain more information, such as the interface name, whether the power was too high or too low, and a power measurement in mWatts.

BIGIP_BCM56XXD_BCM56XXDERR_DDM_ALARM_CLEAR

.1.3.6.1.4.1.3375.2.4.0.160

This is a trap to clear the previous condition on the network monitoring/management station. The error message for this trap will also contain the interface name and explain that the previous condition has cleared.

BIGIP_BCM56XXD_BCM56XXDERR_DDM_WARN

.1.3.6.1.4.1.3375.2.4.0.159

This is warning when either the receive or transmit power of a particular SFP was detected to be too high or too low. The error message will contain more information, As such, the condition (power mismatch) is less severe.

BIGIP_BCM56XXD_BCM56XXDERR_DDM_WARN_CLEAR 

.1.3.6.1.4.1.3375.2.4.0.161

This is a trap to clear previous condition on the network monitoring management station. The warning message for this trap will also contains the interface name and explain the previous condition has cleared

BIGIP_BCM56XXD_BCM56XXDERR_NON_F5_OPTICS

.1.3.6.1.4.1.3375.2.4.0.162

This is a a non-F5 SFP was found in an interface (which is not supported). As a result, a trap is sent. The error message will mention the interface name.

BIGIP_BCM56XXD_BCM56XXDERR_DISABLE_NON_F5_OPTICS

.1.3.6.1.4.1.3375.2.4.0.165

This will be triggered by 100G optics, and the the interface will also be disabled (which does not happen with NON_F5_OPTICS).
