Description
You have noticed the log messages below from /var/log/ltm 

Sep  7 23:39:06 slot2/ltm1.example.com notice logger[26468]: sshd: root@notty      ==> /bin/bigstart restart mcpd
Sep  7 23:39:09 slot1/ltm1.example.com notice logger[19361]: sshd: root@notty      ==> /bin/bigstart restart mcpd

Environment

  • BIG-IP
  • Viprion

Cause
This is caused by the clsh command clsh bigstart restart mcpd executed by user.

Recommended Actions

None

Additional Information
/var/log/audit should show the ssh login from IP 127.x.x.x during that time to execute that clsh command.

  • Sep  7 23:39:05 slot2/ltm1.example.com info sshd(pam_audit)[26398]: 01070417:6: AUDIT - user root - RAW: sshd(pam_audit): user=root(root) partition=[All] level=Administrator tty=ssh host=127.3.0.1 attempts=1 start="Wed Sep  7 23:39:05 2022".
  • Sep  7 23:39:08 slot1/ltm1.example.com info sshd(pam_audit)[19309]: 01070417:6: AUDIT - user root - RAW: sshd(pam_audit): user=root(root) partition=[All] level=Administrator tty=ssh host=127.3.0.1 attempts=1 start="Wed Sep  7 23:39:08 2022".
History file should be able to reveal that clsh command has been executed by user.
  • config # cat /root/.bash_history | grep 'clsh bigstart restart mcpd' -B1
    #1662619144
    clsh bigstart restart mcpd
    config #     date -d @1662619144
    Wed Sep  7 23:39:04 PDT 2022
