Description

After upgrading the BIG-IP APM, the client endpoint inspection is taking longer than a minute to complete

 

Environment

  • BIG-IP APM

 

Cause

APM client package and the OPSWAT Endpoint Security has not been updated after the BIG-IP APM was upgraded

 

Recommended Actions

Upgrade the BIG-IP APM Edge Client. To upgrade the BIG-IP APM Edge Client, follow K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system

Update the OPSWAT Endpoint Security package. To update the OPSWAT Endpoint Security package, follow K48955220: Installing an OPSWAT Endpoint Security update on BIG-IP APM systems (11.4.x and later)
