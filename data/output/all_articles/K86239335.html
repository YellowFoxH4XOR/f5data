K86239335: DNS configuration is missing after upgrade due to failing GTM config load

Source

Description

Configuration fails to load after an upgrade, with a message similar to the following in /var/log/ltm:

emerg load_config_files[PID]: "/usr/bin/tmsh -n -g -a load sys config partitions all gtm-only" - failed. -- Loading schema version: 13.1.1.2

Environment

  • BIG-IP GTM/DNS

  • DNS configuration existed before upgrade.

Cause

  • Bug ID 837637

Recommended Actions

This issue typically occurs when BIG-IP GTM/DNS is provisioned and DNS configuration existed, should not be deleted.

  1. Use vim or nano manually change the schema version in /config/bigip_gtm.conf:

[root@DNS1:Active:Standalone] config # vim bigip_gtm.conf

#TMSH-VERSION: 13.1.1.2           --------> Change it to version number of post-upgrade version, like change it to 13.1.3.4 if you upgrade device from v13.1.1.2 to v13.1.3.4.

  1.  Manually load verify the configuration again to see whether the error is elimilated:

tmsh load sys config verify

  1.  Load the configuration manually if no error in step 2:

tmsh load sys config gtm-only
