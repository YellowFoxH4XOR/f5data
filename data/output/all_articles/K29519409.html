Description

Error messages similar to the following are observed in /var/log/boot.log or printed to the command line when starting syslog-ng:

notice syslog-ng: Duplicate stats counter; counter='udp((null):514)'

Environment

  • BIG-IP 11.x, 12.x, 13.0.0

Cause

Unknown at time of publication.

Recommended Actions

These messages are benign and can be safely ignored.

Additional Information

This occurs with syslog-ng version 2.1.4, which is used in BIG-IP 11.x, 12.x, and 13.0.0.

BIG-IP 13.1.0 and later releases use a newer version of syslog-ng, which does not produce this message.
