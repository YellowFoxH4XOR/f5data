K85426312: Unstable behaviour after upgrade to v15.1.0

Type
Support Solution
Published
2022-02-25
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.0, 15.0.0, 14.1.2, 14.1.0, 14.0.1, 14.0.0, 15.0.1, 13.1.3, 13.1.1, 13.1.0, 13.1.4
Source
https://my.f5.com/manage/s/article/K85426312

Description

  • After upgrading to v15.1.0, you notice unstable behaviour on the BIG-IP, such as slow and intermittent failing connections to the GUI or SSH
  • Notice high CPU usage on odd cores (control plane) which might include processes such as apmd, oauth, bigd (this can variate)
  • You might find core files on the /var/core directory for different daemons, for example bidg and tmm
  • After roll back to previous version, behaviour is stable

Environment

  • After upgrade
  • High CPU odd cores
  • APM provisioned

Cause
Bug ID 706782: Inefficient APM processing in large configurations.

Recommended Actions
Upgrade to a version where this ID is fixed. Alternatively, to obtain an Engineering hotfix for this ID, open a case with F5 support.

Additional Information
None
