Description

Using 'modify auth password' without arguments doesn't trigger sync in HA pair

 

Environment

HA pair

Logged-in user is changing their password using 'modify auth password' with no arguments as below:

user@(bigip1)(cfg-sync In Sync)(Standby)(/Common)(tmos)# modify auth password
changing password for user
new password:
confirm password:

 

Password will be changed but this won't be detected by the peer in this HA setup.

 

Cause

ID385013

 

Recommended Actions

Specify the username in question as an argument:

(tmos)# modify auth password user
changing password for user
new password:
confirm password:
