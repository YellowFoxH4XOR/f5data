K000148919: BIG-IP GUI page fails to load and displays an error message

Type
Support Solution
Published
2025-02-25
Updated
2025-02-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148919

Description

The BIG-IP GUI page fails to load and displays an error message. You may notice the error message under the following conditions:

- When you access GUI pages that use REST API token-based authentication, the pages fail to load with the message "Error getting auth token from login provider".

- While viewing the /var/log/restjavad-audit.*.log when making an API call to applications hosted in virtual server behind the BIG-IP.  

 "user":"local/null","method":"GET","uri":"http://localhost:8100/mgmt/tm/ltm/pool/~Common~<<uri>>/stats","status":401,"from":"x.x.x.x"   

Note: where x.x.x.x is the ip address of the pool member/node where the application is hosted.

Environment

Accessing an application in a virtual server behind a BIG-IP loadbalancer through an API call using HTTP.

Cause

This issue has been identified in the BUG ID 1035661

Recommended Actions

For a temporary fix, Restarting the restjavad process with the command

tmsh restart /sys service restjavad

A permanent fix has been introduced in version 17.1.2

Additional Information

None
