K000151075: Forward the HTTP request to the upstream server without any changes made on headers

Description

You want to forward the exact HTTP request to the upstream server and don't want NGINX to change any headers. 

Environment

  • NGINX Plus

Cause

By default, NGINX modifies header fields in proxied requests like “Host” and “Connection”, and eliminates the header fields whose values are empty strings. “Host” is set to the value of the $proxy_host variable, and “Connection” is set to close.

This may cause some unexpected issues when the upstream server requests the exact same header values. 

Recommended Actions

You can easily define a stream server and make the NGINX to forward traffic on TCP level without touching anything on HTTP level. 

upstream backend-server {
    server backend.com:80 resolve;
}

stream {
  server {
    listen 12345 ssl;                # If the client side uses TLS connection 
    server_name example.com;

    ssl_certificate         /etc/nginx/ssl/example.crt;  # If the client side uses TLS connection
    ssl_certificate_key     /etc/nginx/ssl/example.key;  # If the client side uses TLS connection

    proxy_pass backend-server;
  }
}
