SFP

Cause

The SFP is not receiving enough power.

Recommended Actions

  1. Try to reseat the SFP or the optical cable into the interface on both sides of the connection.
  2. If that doesn't fix the issue, try to replace it with a known working SFP/cable. 
  3. Check the Transmit power on the other side of the connection.
  4. If all those fail, try to run EUD on the device
