Description

Tmm continues to advertise a static route to ZebOS dynamic routing when the next-hop is down/unavailable or the tmm interface to reach the next-hop is disabled.

Tmm shall auto withdraw static route from its route table when the gateway/pool is unavailable.

Inadvertently advertising an 'inactive' static route to ZebOS will result in LTM black-hole traffic when peers forward traffic to those prefixes.

 

Environment

  • BIG-IP LTM
  • A static route is added to the tmm route table
  • LTM redistributes kernel routes to dynamic routing

Cause

Unknown

Recommended Actions

One of two options:

  • Remove static route in tmm route table
  • Add BFD into route domain and setup BFD static route availability check in ZebOS.
