Known Issue

Secure Web Gateway (SWG) transparent forward proxy might not process Per-App Virtual Private Network (VPN) traffic.

This issue occurs when the following condition is met:

  • The SWG virtual server is listening on the connectivity profile while the Per-App VPN traffic arrives on a different Virtual Local Area Network (VLAN).

Impact

SWG transparent forward proxy does not process Per-App VPN traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SWG transparent forward proxy does not process Per-App VPN traffic.

Resolution

Status

F5 Product Development has assigned ID 458496 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can enable the SWG VIP on the same VLAN where the Per-App VPN traffic arrives.
