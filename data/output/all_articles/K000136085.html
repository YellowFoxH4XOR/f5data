Description

ASM is not detecting directory traversal attack - URI "/…/…/{file name}"
A request similar to below is getting bypassed
GET /?path=/.../.../bbb HTTP/1.1
Host: aaa
 

Environment

BIG-IP ASM

Attack Signatures

Cause

The system is not running the latest attack signature update.

directory traversal attack - URI "/…/…/{file name}" can be detected by signature 200007052 - Quick & Dirty PHPSource Directory Traversal, which was added as part of signatures update ASM-AttackSignatures_20221002_103111.

Recommended Actions

Install the signature update file ASM-AttackSignatures_20221002_103111 or a later version (Ideally the latest available for your software version).

Additional Information

Signature 200007052 is part of the signature sets below
+---------------------------+
| set_name |
+---------------------------+
| WebSphere signatures |
| Path Traversal Signatures |
| Low Accuracy Signatures |
| All Signatures |
+---------------------------+

You should ensure that the configured policies have at least one of the above signature sets enabled and ideally that both 'Alarm' and 'block' are enabled for the signature set.
