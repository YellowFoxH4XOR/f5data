K000161530: Error Message: Syntax Error: the "create" command does not accept wildcard configuration identifiers

Description

When attempting to create a BIG-IP DNS Wide IP using a wildcard in the object name (for example, to configure a catch-all response), tmsh returns a syntax error:

Syntax Error: the "create" command does not accept wildcard configuration identifiers.

For example, the following command fails:

tmsh create gtm wideip aaaa *.example.com failure-rcode-response enabled

Environment

  • BIG-IP DNS

Cause

The tmsh utility does not allow wildcard characters in the Wide IP object name (configuration identifier). Wildcards are supported only in the Wide IP aliases list.

Recommended Actions

Create the Wide IP with a standard Fully Qualified Domain Name (FQDN) and add the wildcard entry to the aliases list:

tmsh create gtm wideip aaaa example.com aliases add { *.example.com } failure-rcode noerror failure-rcode-response enabled
