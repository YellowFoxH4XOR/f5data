Known Issue

A Border Gateway Protocol (BGP) neighbor connection request may fail to establish.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with BGP dynamic routing.
  • Your BIG-IP BGP configuration is configured with no bgp default ipv4-unicast.
  • Your BIG-IP system and the BGP neighbors are configured with a peer group that is explicitly activated for IPv4.

Impact

BGP connections are unable to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing network level traffic for BGP, your BIG-IP system immediately terminates BGP connection requests.
  • Your BIG-IP system establishes BGP connections after running the clear ip bgp soft reset command on the neighbor's devices.
  • When the BGP configuration is modified, the peer group your BIG-IP system established BGP connections with neighbors is removed.

Workaround

To work around this issue, you can run the BGP clear ip bgp command on the BIG-IP BGP neighbors (see the related command syntax for your BGP device) or restart the tmrouted service on the affected BIG-IP system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will temporarily disrupt dynamic routing on the affected device.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the tmrouted service, type the following command:

    restart /sys service tmrouted

  3. To exit the tmsh utility, type the following command:

    quit
