K12063: The number of files/directories scanned by a shadow copy rule may be greater than the total number of files/directories

Topic

When a shadow copy rule encounters issues, such as locked files or files modified during processing, the rule will queue new events into the inline notification queue. The shadow copy rule will process these events and rescan the affected files/directories before the rule finishes. As a result, the shadow copy rule may rescan files and directories multiple times. When this issue occurs, the Copy Phase Information section of the show shadow command output will indicate the number of files/directories scanned is greater than the total number of files/directories.

Note: For information about the show shadow command, refer to the ARX CLI Reference Guide.

The Copy Phase Information section of the show shadow command output may appear similar to the following example:

      Copy Phase Information
      ----------------------
        Phase Started                             :   Jul 1 10:00
        Phase Completed                           :   Jul 1 10:00
        Elapsed Time                              :   00:00:14
        Average Transmission Rate                 :   25.5 Mb/s (3.1 MB/s)
        Total Files/Directories                   :   1,025,459
        Files/Directories Scanned                 :   1,375,502
        Files/Directories Skipped                 :   3,795
            Access Blocked by Client              :   2
            Modified During Processing            :   5
            Other Failure Conditions              :   3,788
        Files/Directories Processed               :   1,375,502
            Identical Files/Directories           :   1,355,626
            New Files/Directories                 :   12,171
            Updated Files/Directories             :   7,705
        Full Update Bytes Sent                    :   28,595,196,968 (26G)
        Delta Update Bytes Sent                   :   0 (0)
            Effective Data Bytes                  :   0 (0)

Note: To determine what issues the shadow copy rule may have encountered, review the shadow copy report using the show report command. For information about the show report command, refer to the ARX CLI Reference Guide.
