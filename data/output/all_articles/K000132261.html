K000132261: In the tmsh command line prompt, the BIG-IP system may display (PID-XXXX)

Type
Support Solution
Published
2023-01-26
Updated
2023-03-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000132261
DESCRIPTION
The tmsh command line prompt contains a PID value after upgrading to version 16.1.2.2 or above and could appear as such:

(EXAMPLE)(pid-27953)(cfg-sync Standalone)(Active)(/Common)(tmos)#

ENVIRONMENT
  • FIPS 140-3 is licensed
  • For physical appliances: Recently upgraded to version 16.1.2.2 or above
  • For virtual edition BIG-IP: Recently upgraded to version 16.1.3 or above and enabled FIPS 140-3
CAUSE
Starting in version 16.1.2.2 with FIPS 140-3 licensed, approved FIPS related services that use the TMSH/TMUI interface must provide an explicit service indicator in the form of logs whenever the requested service is using approved crypto algorithm. The indicator will be logged in /var/log/audit file.  
While in the tmsh command line, pid information within the prompt will uniquely identify the request originator using the approved crypto algorithm.

RECOMMENDED ACTION
None, this is expected behavior.
