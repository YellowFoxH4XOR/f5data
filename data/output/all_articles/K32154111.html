Description

When Application Visibility and Reporting (AVR) is provisioned, you can create an Analytics profile that includes traffic capturing instructions. The system can collect application traffic locally, remotely, or both. If the system is already monitoring applications, you can also update an existing Analytics profile to make it so that it captures traffic.

If logging locally, the system logs the first 1000 transactions and displays charts based on the analysis of those transactions. For VIPRION® systems, the local logging consists of the first 1000 transactions multiplied by however many blades are installed. If logging remotely, the system logs information on that system; log size is limited only by any constraints of the remote logging system. To see updated application statistics, you can clear the existing data to display the current statistics.

Environment

  • Application Visibility and Reporting (AVR) 
  • Configuration Utility

Cause

The BIG-IP system captures the application traffic described by the Analytics profile for 1000 transactions locally (or until system limits are reached).
Once the limit value is reached:

  1. The BIG-IP sets the below db value to false: # tmsh list sys db avr.trafficcapture.internal.enabled
  2. Traffic capturing stops until you clear all previously captured data records by clicking the "Clear all" button in "System ›› Logs : Captured Transactions".
  3. Error message on GUI will be logged: "Traffic Capturing is currently disabled because the log is full. Please clear the data to continue capturing."

If logging remotely, the system logs information on that system; log size is limited only by constraints of the remote logging system.

Note: System performance is affected when traffic is being captured.

Recommended Actions

On the Main tab, click System > Logs > Captured Transactions. The Captured Transactions screen opens and lists all of the captured transactions. On the Captured Transactions screen, click Clear All to clear all previously captured data records.
