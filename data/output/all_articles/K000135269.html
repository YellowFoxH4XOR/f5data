Description

Due to many reasons (e.g. iRule behavior changes between versions, unhandled exceptions in iRule), you can notice  ERR_VAL (line LINE_NUMBER) invoked from within "HTTP::path" in the /var/log/ltm logs.

ERR_VAL it's a general error for multiple issues and by default it's not pointing to the root cause directly. To identify what causes that log, you have to add the additional iRule to the virtual server which will log the error reason to the /var/log/ltm.

Environment

  • LTM
  • iRule

 Recommended Actions

1. Identify the iRule which is logging ERR_VAL. 
In the example below it is /Common/non-working-irule.

/var/log/ltm:May  5 05:57:15 LTM1.example.com err tmm4[19555]: 01220001:3: TCL error: /Common/non-working-irule <HTTP_REQUEST> - ERR_VAL (line 114)     invoked from within "HTTP::path"

2. Identify Virtual Servers with this iRule attached.
3. Create a a new datagroup named AllowedSorryPagePathList. For more information, refer to the Additional Information section of this article.
4. Create the new iRule (in the GUI navigate to: Local Traffic >> iRules >> Create) with a proper name and paste the following code: 
    when HTTP_REQUEST {
    catch {
      if { [class match [HTTP::path] equals AllowedSorryPagePathList] } {
        return
      } else {
        drop
      }
    } catch_err
    if { $catch_err ne ""} {
      log local0. "Catch_err: $catch_err"
      log local0. "HTTP Request: [HTTP::request]"
      binary scan [HTTP::request] H* request_hex
      log local0. "hex: $request_hex"
      drop
    }
    }
5. Save the iRule.

From this point on, BIG-IP starts to log the required debugging information. To identify the errors, analyze the /var/log/ltm logs.

If you won't be able to recognize the root cause of them, please raise a ticket to F5 Network Support with collected information for further troubleshooting.

Additional Information
Perform the following procedure to create a datagroup for the iRule in this article.
  1. On the Configuration utility, go to Local Traffic >> iRules >> Data Group List
  2. Select Create. 
  3. Provide a name that matches the name in your iRule.

    AllowedSorryPagePathList

  4. For Type, select String.
  5. For String Record, String, provide paths that match your environment and application. For example,.

    /example/app

  6. Select Add.

  7. Repeat step 5 as appropriate if you have more paths to add.

  8. Select Finished.
