K000140107: Retrieve ASM policy audit logs using iControl REST API

Type
Support Solution
Published
2024-06-24
Updated
2024-06-24
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000140107

Description

Retrieving ASM policy audit logs via the REST API can be resource-intensive and verbose, often resulting in errors within the restjavad log file. Follow the recommendations in this article to optimize the process.

Environment

  • ASM Security Policy
  • iControl REST API

Cause

N/A

Recommended Actions

Use iControl REST query parameters to optimize the request, this will allow the system to pull needed data without being overwhelmed, e.g.:

  •  To get the number of total audit logs:
# curl -ksu user:passwd 'https://x.x.x.x/mgmt/tm/asm/policies/EHVhd2KfO5pPg1fsdQcnsw/audit-logs/?$select=totalItems' | jq .totalItems
1149

Note: update the above command with the correct credentials and IP/hostname of the BIG-IP in question.

  • To get the first top 3 audit logs:
# curl -ksu user:passwd 'https://x.x.x.x/mgmt/tm/asm/policies/EHVhd2KfO5pPg1fsdQcnsw/audit-logs?$top=3' | jq .
