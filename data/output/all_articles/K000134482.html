Topic

You should consider using this procedure under the following condition:

  • You want to restrict access to the management interface to only trusted sources.

Description

You can use the Allowed IP Addresses feature on the F5 rSeries system to restrict access to ports on the management interface to only trusted source IP addresses. You can add entries to the Allowed IP Addresses to allow access from a specific IPv4 or IPv6 address or a range of IP addresses. The Allowed IP Addresses feature restricts access to the following ports on the F5 rSeries system's management interface: 443 (HTTPS), 80 (HTTP), 8888 (RESTCONF), 161 (SNMP), 7001 (VCONSOLE), and 22 (SSH).

By default, all ports except for 161 (SNMP) are enabled for access, meaning ports 80, 443, 8888, 7001, and 22 are allowed access. Port 80 is only open to allow a redirect to port 443 in case someone tries to access the webUI over port 80. The webUI itself is not accessible over port 80. Port 161 is typically viewed as un-secure and is therefore not accessible until an allow list entry is created for the endpoint trying to access F5OS using SNMP queries. Ideally SNMPv3 should be utilized to provide additional layers of security on an otherwise un-secure protocol. VCONSOLE access also must be explicitly configured before access to the tenants is possible over port 7001.

To further lock down access you may add an Allowed IP Addresses entry including an IP address and optional prefix for each of the protocols listed above. As an example, if you wanted to restrict API and webUI access to a particular IP address and/or subnet, you can add an Allowed IP Addresses entry for the desired IP or subnet (using the prefix length), specify port 443 and all access from other IP endpoints will be prevented.

When configuring Allowed IP Addresses, consider the following:

  • The Allowed IP Addresses feature only restricts access to the management interface and does not affect data plane traffic.
  • Access to port 161 (SNMP) is blocked by default.
  • Adding an entry for a specific port only restricts access for that port. If no other entries are configured, access to the other ports remains open.
  • Important: If you omit the port option when adding an entry, the F5 rSeries system allows access to all ports on the management interface from that IP address.
  • It is strongly recommended that you configure an Allowed IP Addresses entry for your administrative access first, before adding other Allowed IP Addresses entries.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the F5OS-A webUI, CLI, and REST API.
  • You have a system with the curl utility installed.
  • You have console access to the rSeries system for recovery.

View the Allowed IP Addresses entries on the F5 rSeries system

You can view the Allowed IP Addresses entries on the F5 rSeries system using the webUI, CLI, or REST API. To do so, perform the appropriate procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use the CLI
  • Use the REST API

Use the webUI

  1. Log in to the webUI of the F5 rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > SYSTEM SECURITY. The webUI displays the current entries under Allowed IP Addresses.

    Note: In versions prior to F5OS-A 1.7.x, go to SYSTEM SETTINGS > Allow List.

Use the CLI

  1. Log in to the CLI of the F5 rSeries system as the admin user.
  2. View the current entries in the Allowed IP Addresses using the following command:

    show running-config system allowed-ips

    The output should appear similar to the following example:

    system allowed-ips allowed-ip dev
     config ipv4 address 172.16.10.100
     config ipv4 prefix-length 32
     config ipv4 port 443
    !
    system allowed-ips allowed-ip eng
     config ipv4 address 10.18.0.0
     config ipv4 prefix-length 16
     config ipv4 port 22
    !
    system allowed-ips allowed-ip test
     config ipv4 address 10.10.10.100
     config ipv4 prefix-length 32
    !

Use the REST API

  1. Log in to a system with the curl utility installed.
  2. List the entries in the Allowed IP Addresses using the following syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<mgmt_address>/api/data/openconfig-system:system/f5-allowed-ips:allowed-ips"

    In the command syntax, note the following:

    • <mgmt_address>  is the hostname or management IP address of the F5 rSeries system.
    • <username> and <password> are a username and password combination that provides administrative access to the F5 rSeries system. If you omit <password> the system will prompt for one.

    For example, to list the entries using the admin user when the management IP address is 10.10.10.200, enter the following command:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://10.10.10.200/api/data/openconfig-system:system/f5-allowed-ips:allowed-ips"

    Output should appear similar to the following example:

Add an entry to the Allowed IP Addresses

You can add entries to the Allowed IP Addresses using the F5OS-A webUI, CLI, or REST API. To do so, perform the appropriate procedure:

Impact of procedure: Performing the following procedure restricts access to the management interface and should be performed with console access to ensure access to the system.

  • Use the webUI
  • Use the CLI
  • Use the REST API

Use the webUI

  1. Log in to the webUI of the F5 rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > SYSTEM SECURITY. 

    Note: In versions prior to F5OS-A 1.7.x, go to SYSTEM SETTINGS > Allow List.

  3. Under Allowed IP Addresses, select Add.
  4. For Name, enter a name for the entry.
  5. For IPv4/IPv6, select either IPv4 or IPv6.
  6. For Address, enter the source IP address or subnet you want to allow.
  7. For Prefix Length, enter the prefix for the IP address. For example, to allow a single IPv4 address instead of a range, enter 32.
  8. For Port, select the port on the management interface to allow.
  9. Select Save to save and apply the changes.

Use the CLI

  1. Log in to the CLI of the F5 rSeries system as the admin user.
  2. Enter the following command:

    config

  3. Add a new entry in the Allowed IP Addresses using the following command syntax:

    system allowed-ips allowed-ip <name> config <ipv4 | ipv6> address <ip_address> prefix-length <prefix> port <port>

    In the command syntax, note the following:

    • <name> is the name for the Allow List entry.
    • <ipv4 | ipv6> is the protocol, either IPv4 or IPv6.
    • <ip_address> is the source IP address or subnet to allow.
    • <prefix> is the prefix length.
    • <port> is the port on the management interface.

    For example, the following command allows access from IPv4 address 10.10.10.50 to port 443 on the management interface:

    system allowed-ips allowed-ip entry1 config ipv4 address 10.10.10.50 prefix-length 32 port 443

    To allow access to port 22 from any IPv4 address in the 172.20.10.0/24 subnet, enter the following command:

    system allowed-ips allowed-ip entry2 config ipv4 address 172.20.10.0 prefix-length 24 port 22

  4. Enter the following command to commit the change and exit config mode:

    commit and-quit

Use the REST API

  1. Log in to a system with the curl utility installed.
  2. Add an entry to the Allowed IP Addresses using the following syntax:

    curl -X POST -sku <username>:<password> -H "Content-Type: application/yang-data+json" "https://<mgmt_address/api/data/openconfig-system:system/f5-allowed-ips:allowed-ips" -d '{"f5-allowed-ips:allowed-ip": [{"f5-allowed-ips:name": "<name>", "f5-allowed-ips:config": {"f5-allowed-ips:ipv4": {"f5-allowed-ips:address":"<ip_address>","f5-allowed-ips:prefix-length": <prefix>,"f5-allowed-ips:port": <port>}}}]}'

    In the command syntax, note the following:

    • <mgmt_address>  is the hostname or management IP address of the F5 rSeries system.
    • <username> and <password> are a username and password combination that provides administrative access to the F5 rSeries system. If you omit <password> the system will prompt for one.
    • <name> is the name for the Allow List entry.
    • <ipv4 | ipv6> is the protocol, either IPv4 or IPv6.
    • <ip_address> is the source IP address or subnet to allow.
    • <prefix> is the prefix length.
    • <port> is the port on the management interface.

    For example, the following command allows access from IPv4 address 10.10.10.50 to port 22 on the management interface:

    curl -X POST -sku admin:admin -H "Content-Type: application/yang-data+json" "https://10.10.10.200/api/data/openconfig-system:system/f5-allowed-ips:allowed-ips" -d '{"f5-allowed-ips:allowed-ip": [{"f5-allowed-ips:name": "entry5", "f5-allowed-ips:config": {"f5-allowed-ips:ipv4": {"f5-allowed-ips:address":"10.10.10.50","f5-allowed-ips:prefix-length": 32,"f5-allowed-ips:port": 22}}}]}'

    You should receive a response similar to the following example if the command was successful:

    HTTP/1.1 201 Created

Delete an entry from the Allowed IP Addresses

You can delete entries in the Allowed IP Addresses using the F5OS-A webUI, CLI, or REST API. To do so, perform the appropriate procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use the CLI
  • Use the REST API

Use the webUI

  1. Log in to the webUI of the F5 rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > SYSTEM SECURITY.

    Note: In versions prior to F5OS-A 1.7.x, go to SYSTEM SETTINGS > Allow List.

  3. Under Allowed IP Addresses, select the entry you want to delete.
  4. Select Delete.
  5. Select OK to confirm the deletion.

Use the CLI

  1. Log in to the CLI of the F5 rSeries system as the admin user.
  2. Enter the following command:

    config

  3. Remove an existing entry in the Allowed IP Addresses using the following command syntax:

    no system allowed-ips allowed-ip <name> config <ipv4 | ipv6> address <ip_address> prefix-length <prefix> port <port>

    In the command syntax, note the following:

    • <name> is the name for the Allowed IP Addresses entry.
    • <ipv4 | ipv6> is the protocol, either IPv4 or IPv6.
    • <ip_address> is the source IP address or subnet to allow.
    • <prefix> is the prefix length.
    • <port> is the port on the management interface.

    For example, the following command removes access from IPv4 address 10.10.10.50 to port 443 on the management interface:

    no system allowed-ips allowed-ip entry1 config ipv4 address 10.10.10.50 prefix-length 32 port 443

    This command can also be truncated, which will remove all available settings for entry1:  

    no system allowed-ips allowed-ip entry1

  4. Enter the following command to commit the change and exit config mode:

    commit and-quit

Use the REST API

  1. Log in to a system with the curl utility installed.
  2. Delete the entry in the Allowed IP Addresses using the following syntax:

    curl -X DELETE -sku <username>:<password> -H "Content-Type: application/yang-data+json" "https://<mgmt_address>/api/data/openconfig-system:system/f5-allowed-ips:allowed-ips/f5-allowed-ips:allowed-ip=<name>"

    In the command syntax, note the following:

    • <username> and <password> are a username and password combination that provides administrative access to the F5 rSeries system. If you omit <password> the system will prompt for one.
    • <mgmt_address>  is the hostname or management IP address of the F5 rSeries system.
    • <name> is the name of the Allowed IP Addresses entry you want to delete.

    For example, to delete the entry named example when the F5 rSeries management address is 10.10.10.200, enter the following command:

    curl -X DELETE -sku admin:admin -H "Content-Type: application/yang-data+json" "https://10.10.10.200/api/data/openconfig-system:system/f5-allowed-ips:allowed-ips/f5-allowed-ips:allowed-ip=example"

    You should receive a response similar to the following example if the command was successful:

    HTTP/1.1 204 No Content
