Description

Will re-licensing a device cause a downtime?

Environment

  • Re-licensing a BIG-IP device
  • Reactivating license

Cause

None

Recommended Actions

The license reactivation process will trigger a reload of the configuration, which will temporarily interrupt all traffic processing. For information refer to K35783352: BIG-IP License Reactivation triggers the configuration to be reloaded

Additional Information

None
