Topic

F5 updated the BIG-IP Virtual Edition (VE) bring-your-own-license (BYOL) product listings on public cloud marketplaces.

Description

BYOL product listings

Previously, F5 offered the following BYOL product listings for BIG-IP VE on public cloud marketplaces:

  • F5 BIG-IP Virtual Edition – Good (BYOL)
  • F5 BIG-IP Virtual Edition – Better (BYOL)
  • F5 BIG-IP Virtual Edition – Best (BYOL)

F5 introduced new BYOL product listings to support one and two boot location BIG-IP VE images and to reduce the number of future marketplace listings. The following replacement BYOL product listings for BIG-IP VE are now available in the public cloud marketplaces:

  • F5 BIG-IP VE – ALL (BYOL, 2 Boot Locations)
  • F5 BIG-IP VE – ALL (BYOL, 1 Boot Location)
  • F5 BIG-IP VE – LTM/DNS (BYOL, 2 Boot Locations)
  • F5 BIG-IP VE – LTM/DNS (BYOL, 1 Boot Location)

When determining which BYOL product listing to use, consider the following information:

  • "F5 BIG-IP VE – ALL" versus "F5 BIG-IP VE – LTM/DNS"
  • Mapping BYOL licenses to marketplace listings
  • "1 Boot Location" versus "2 Boot Locations"

"F5 BIG-IP VE – ALL" versus "F5 BIG-IP VE – LTM/DNS"

  • The F5 BIG-IP VE – ALL product listings:
    • Support all core BIG-IP modules and standalone security products.
    • Support running standard BIG-IP VEs and per-app BIG-IP VEs.
    • Include larger disk size requirements.
    • Recommended for use with the following license types:
      • Better
      • Best
      • BIG-IP AFM, BIG-IP APM, BIG-IP ASM, or Advanced WAF
         
  • The F5 BIG-IP VE – LTM/DNS product listings:
    • Support only BIG-IP LTM and BIG-IP DNS modules.
    • Support running standard BIG-IP VEs and per-app BIG-IP VEs.
    • Include smaller disk size requirements.
    • Recommended for use with the following license types:
      • Good
      • BIG-IP LTM or BIG-IP DNS

Mapping BYOL licenses to marketplace listings

The following table lists the type of marketplace product listing you should use for your BYOL license type.

BIG-IP LTM or BIG-IP DNSF5 BIG-IP VE – LTM/DNS

"1 Boot Location" versus "2 Boot Locations"

The 1 Boot Location and 2 Boot Locations specifications within the product listing descriptions indicate whether you can upgrade the BIG-IP VE instance to a later BIG-IP version inline (2 Boot Locations), or whether you must completely replace it with a new instance to upgrade (1 Boot Location).

  • 1 Boot Location product listings support only a single boot location and cannot be upgraded to another BIG-IP version without interruption. To upgrade a 1 Boot Location BIG-IP VE instance, you must remove the original instance and replace it with a new instance of the desired version.
  • 2 Boot Locations product listings support two boot locations. You can upgrade the second boot location to another BIG-IP version without removing the instance running on the first boot location. The only interruption is the time it takes to boot from the second boot location.

The 1 Boot Location images require significantly less disk space when compared to the 2 Boot Locations images, as they do not provision the additional disk space that is required to host both the existing software version and the updated version. For information about the size requirements for the ALL, LTM/DNS, 1 Boot Location, and 2 Boot Locations product listings, refer to K14946: Overview of BIG-IP VE image sizes.
