K04554396: Swapping VLAN interfaces using a tmsh transaction

Type
Support Solution
Published
2022-08-25
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K04554396

Description
 

Environment

  • BIG-IP Virtual Edition

Cause
As a result of changes introduced in recent releases of BIG-IP (K40398645), interface ordering in VMware is expected to remain consistent when upgrading.

  • BIG-IP 17.x.x: 17.0.0
  • BIG-IP 16.1.x: 16.1.2.2
  • BIG-IP 15.1.x: 15.1.5.1
  • BIG-IP 14.1.x: 14.1.5
However, when upgrading to these versions (or later) from an earlier release, interface ordering may unexpectedly change causing connectivity issues.
To resolve these changes (as detailed in K55000339) the interfaces can be reordered from the VMware console.
If access to the VMware console is not available, the interfaces can be changed to match the required vlans from the tmsh CLI using a transaction.

Recommended Actions

tmsh batch transactions allow a number of changes to be batched and submitted in a single operation. As long as the final state of the transaction is consistent,
this avoids the problem of sequencing commands that result in an inconsistent state.
 
https://clouddocs.f5.com/cli/tmsh-reference/v14/modules/cli/cli_transaction.html

As a simple example, there is a requirement to swap the interfaces on two vlans in tmsh:
 
(tmos)# list /net vlan
net vlan External
    interfaces {
        1.3 {}
    }
    tag 4039
}
net vlan Internal
    interfaces {
        1.2 {}
    }
    tag 4039
}

If I try to modify one vlan, it will fail
 
(tmos)# modify net vlan Internal interfaces replace-all-with { 1.3 }
01070259:3: Requested member (1.3) is untagged on another VLAN

So we set up a batch transaction:
 
(tmos)# create /cli transaction
(tmos)# modify /net vlan External interfaces replace-all-with { 1.2 }
(tmos)# modify /net vlan Internal interfaces replace-all-with { 1.3 }
(tmos)# list /cli transaction
1: (tmos)# modify /net vlan External interfaces replace-all-with { 1.2 }
2: (tmos)# modify /net vlan Internal interfaces replace-all-with { 1.3 }
(tmos)# submit /cli transaction
(tmos)# list /net vlan
net vlan External
    interfaces {
        1.2 {}
    }
    tag 4039
}
net vlan Internal
    interfaces {
        1.3 {}
    }
    tag 4039
}

The transaction changes have been made without any errors.
