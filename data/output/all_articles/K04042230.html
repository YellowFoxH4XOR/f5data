Issue

Error Message

01070356:3: Snatpool <name> must reference at least one translation address

In this error message, note the following:

  • <name> is the name of the secure network address translation (SNAT) pool and the partition in which the pool resides.

For example:

01070356:3: Snatpool /Common/my_snatpool must reference at least one translation address

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • You attempt to load a BIG-IP configuration that contains a SNAT pool with no pool members.

Impact

The BIG-IP configuration fails to load, and the SNAT pool is unavailable.

Recommended Actions

You should either modify the SNAT pool by adding at least one translation address, or remove the SNAT pool from the configuration if the pool is not needed. If a pool of translation addresses in not needed, you can configure a standard SNAT or SNAT automap. For more information about SNATs, refer to K7820: Overview of SNAT features.
