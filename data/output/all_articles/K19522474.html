Known Issue

BIG-IP ASM security policies may not function after upgrading from 11.2.0.

This issue occurs when all of the following conditions are met:

  • Your configuration contains a chart schedule report with a predefined filter value of All.
  • You have upgraded from BIG-IP 11.2.0.

Impact

BIG-IP ASM securities policies are not functional after the upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After upgrading BIG-IP ASM from 11.2.0, BIG-IP ASM securities policies are no longer functional.
  • After upgrading BIG-IP ASM from 11.2.0, the BIG-IP ASM Configuration utility fails to display the Security Policies page and reports an error message that appears similar to the following example:
     You must configure the security policy before you can access it.

Workaround

To work around this issue prior to upgrading from 11.2.0, you can delete the chart schedule report with a predefined filter value of All. After the upgrade, you can recreate the chart schedule report and set the predefined filter value to Top alarmed and blocked policies instead of All.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system. However, make sure to only modify the predefined filter value when recreating the chart schedule after you upgrade.
