Topic

When troubleshooting issues on the VIPRION system, you should understand how each blade interconnects to other blades.

Description

A VIPRION system is made up of a chassis on which you can install multiple blades. The blades installed in a VIPRION chassis communicate by way of the internal interfaces on the chassis backplane while functioning as one BIG-IP cluster.

Displaying the hidden internal interfaces

You can display these hidden internal interfaces only by using special options for the bigpipe command or the TMOS Shell (tmsh), depending on your BIG-IP system version. To view these internal interfaces and the corresponding statistics, use the following command:

tmsh show /net interface -hidden
