Known Issue

The snmp_dca_base monitor erroneously sets a dynamic-ratio weight of 1.

This issue occurs when all of the following conditions are met:

  • There is a pool with dynamic ratio load balancing.
  • There is a node using the snmp_dca_base monitor.

While the snmp_dca_base monitor correctly queries the node for statistics, the monitor erroneously sets the dynamic-ratio weight for the node to 1.

Impact

Traffic is not dynamically load balanced across the pool members.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Each node in the pool has a dynamic-ratio value of 1.
  • The node weight is reported as 1 in the /var/tmp/snmpdca.log file:

    Main:Weight =1 (weight1 = 0.000000, weight2 = 0.000000)

    Note: Monitor logging for the snmp_dca and snmp_dca_base is not enabled by default. To enable monitor logging for the snmp_dca and snmp_dca_base monitors, refer to K6529: Enabling and disabling monitor logging for the snmp_dca and snmp_dca_base monitors.
