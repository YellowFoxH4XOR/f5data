K7873: The TMM processes can crash when the VLAN failsafe is enabled on a system running in CMP mode

Known Issue

This is the result of a known issue. The Clustered Multi-Processing (CMP) feature allows dual processor BIG-IP systems to run multiple TMM instances to increase traffic handling. When VLAN failsafe is enabled on a system running in CMP mode, multiple TMM processes will attempt to generate VLAN failsafe traffic when no traffic is received on the VLAN. As a result, the TMM processes may crash the system.

Note: The tmm0 process is the only process that should source VLAN failsafe traffic.

F5 Product Development is tracking this issue as CR83175, and it was fixed in BIG-IP LTM 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, Hotfix-BIGIP-9.4.1-HF1 has been issued for BIG-IP LTM version 9.4.1. You may download this hotfix from the F5 Downloads page.

Workaround

You can work around this issue by disabling the VLAN failsafe. To do so, perform the following procedure:

  1. Log in to the BIG-IP LTM Configuration utility.
  2. Click System.
  3. Click High Availability.
  4. Select VLANs from the Fail-safe drop-down menu.
  5. Select the VLAN box, then click the Remove button.
