K000092513: MCPd cored on secondary device of blade chassis or vcmp device

Type
Support Solution
Published
2022-11-08
Updated
2022-11-08
Source
https://my.f5.com/manage/s/article/K000092513

Description

Secondary blade of Viprion Chassis or VCMP device experiences a core during mcpd daemon startup.

Environment

  • Viprion or VCMP device 
  • Secondary member of cluster
  • PEM licensed and provisioned 
  • PEM traffic classifications has been updated

Cause

Installing updated traffic classification can change predefined classification objects to user defined objects causing a mismatch between binary-based configuration and text-based configuration leading to one-time mcpd core and restart using text-based configuration.  

PE is tracking as 1166329

 

Recommended Actions

None

Additional Information

MCPd should only core on secondary blades one-time and restart with text-based configuration, causing only additional time needed for device to enter operational status.
