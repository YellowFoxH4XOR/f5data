K000139116: HA pair devices may display inconsistent log messages for forced-offline pool members

Type
Support Solution
Published
2024-03-31
Updated
2024-03-31
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2, 17.5.0, 17.1.1
Source
https://my.f5.com/manage/s/article/K000139116

Description

The Active and Standby BIG-IP systems may display different log messages in their /var/log/ltm logs when a pool member is forced offline.

For example, the Standby system might show a message [ was up for 0hr:2mins:14sec ] while Active systems shows [ was forced down for 0hr:2mins:28sec ]

Environment

  • BIG-IP HA
  • Forced offline

Cause

This is tracking as ID1505081.

Recommended Actions

Currently this issue has no functional impact.

Recommend to monitor the progress of ID1505081.

Additional Information

None.
