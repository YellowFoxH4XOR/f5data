Description

When there's a need to redirect a client requesting a given HTTP URI to a different HTTP URI, and iRule can be used to perform that task.

Environment

Relevant environmental factors:

  • BIG-IP
  • Virtual Server supporting HTTP traffic

Cause

None

Recommended Actions

To redirect a client requesting a given HTTP URI to a different HTTP URI, the procedure below can be used to create an iRule that can then be assigned to the Virtual Server to provide the functionality:

  1. Login to the BIG-IP's Configuration Utility
  2. Navigate to Local Traffic  ››  iRules
  3. Click Create
  4. Provide a name for the iRule such as: httpURI_redirect
  5. Enter the below iRule logic into the iRule editor.
    Note: Modify the URI fields ("<requestURI>") below as needed to match the client's HTTP Request URI, and replace it with the Redirect URI. And the http:// can be replaced with an https:// if needed.
    when HTTP_REQUEST {
       if { ([string tolower [HTTP::uri]] eq "<requestURI>") } {
            HTTP::redirect "http://[HTTP::host]<redirectURI>"
        }
    }
  6. Click Finish
  7. Assign the newly created iRule to the Virtual Server.

    Note: Please test the iRule before you implement the change in the production system. For complete and detailed information iRules syntax, see the F5 Networks DevCentral website  https://devcentral.f5.com/.
