K000141191: VelOS Partition failed to upgrade F5OS to 1.6.x

Type
Support Solution
Published
2024-10-15
Updated
2024-10-15
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000141191

Description

VelOS Partition failed to upgrade F5OS to 1.6.x and prompted with error message as per screenshot attached.

Figure: Upgrade Error

Environment

  • VelOS
  • Controller
  • Partition
  • Upgrade Failed
  • CLI

Cause

STP configuration were enabled on LAG enabled interfaces which causes the upgrade failed on the partitions.
