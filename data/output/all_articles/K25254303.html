Description

  • CPU peak for several hours a day that does not correspond with daily load on the system
  • java process shows high CPU

Environment

  • ASM or FPS

Cause

This is caused by ASM's datasyncd process managing JavaScript for obfuscation. See the following article for more information:

  • K02827102: BIG-IP ASM and BIG-IP FPS systems experience higher CPU usage for several hours per day

Recommended Actions

No action is typically required. There is minimal chance of this affecting traffic since it's an analysis plane task.

From version 14 onwards, this task may be rescheduled to a different time of day by navigating to Security > Options > Background Tasks.
