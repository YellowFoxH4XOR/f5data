Description

The system restarts the fslogd process in loop and you can not generate the qkview or to do the configuration change from tmsh.

  • In /var/log/daemon.log:

Re-starting fslogd

  • Similar error message you can see from /var/log/ltm:

err fslogd[<PID>]: Fatal error file_writer.c:sync_mapped_memory_and_unmap:442 msync fail ed errno[30] strerror[Read-only file system]
err fslogd[<PID>]: Fatal error file_writer.c:truncate_file:342 open failed errno[30] str error[Read-only file system]
err fslogd[<PID>]: Fatal error file_writer.c:close_current_fd_and_move_file:467 ftruncat e failed errno[30] strerror[Read-only file system]

Environment

  • BIG-IP AFM
  • BIG-IP VE
  • Qkview
  • Tmsh

Cause

None

Recommended Actions

To workaround this issue, you can force a file system check on the next system reboot.

For the detailed steps, you may refer to K73827442: Forcing a file system check on the next system reboot (12.x - 14.x).
