Known Issue

The tcpdump utility fails to capture packets when using certain options.

This issue occurs when all of the following conditions are met:

  • You configure tcpdump to listen for packets on a physical interface. For example:

    -i 1.1

  • You configure tcpdump to save the packets to a file in binary format. For example:

    -w /var/tmp/example.pcap

  • You configure tcpdump to produce verbose output while capturing packets. For example:

    -v, -vv, or -vvv

Impact

The tcpdump utility does not capture packets, which may create confusion for a BIG-IP administrator who is troubleshooting the system. This issue does not affect the traffic-passing abilities of the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Although packets are flowing correctly through the BIG-IP system, the tcpdump utility fails to capture packets when you use certain command options.

Workaround

To work around this issue, you can start the tcpdump utility without the -v, -vv, or -vvv verbose output options.
