Description

SSH login directly to VelOS Partition with default local admin user "root" and being prompted error "Your account has expired"

Environment

  • F5OS-C (VelOS)
  • Local default admin user "root"
  • Your account has expired
  • Direct SSH to VelOS Partition

Cause

Bug ID 989525: Logging into a partition as root is denied with misleading message 'password expired'

Remote login to a partition as 'root' is not allowed.

Recommended Actions

SSH login directly to the VelOS Partition with other partition local users account instead of the default local admin "root" account.

None
