Description

Application that uses WebSockets does not work after applying an ASM security policy, even in transparent mode.

Environment

  • WebSocket
  • ASM policy

Cause

This is expected behaviour for ASM without a WebSocket profile applied. Messages similar to the following will also be observed in /var/log/ts/bd.log:

websocket.c:0266|101 Switching Protocols HTTP status arrived, but the websocket hanshake failed.
websocket.c:0267|Possible reasons are websocket profile isn't assigned on a virtual server or handshake is illegal.

Recommended Actions

Apply a WebSocket profile to the virtual server. The default one is usually sufficient.
