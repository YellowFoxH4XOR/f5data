Description

ASM policies are configured with 'Policy Building Learning Mode' set to Manual or Automatic.
One of the reasons of high CPU usage in Analysis Plane could be due to high number of unattended learning suggestions and also it is set to ignored.

Similar logs are noted in the /var/log/ts/pabnagd.log when pabnagd process is running hot.

|Aug 22 10:30:09.013|027815|PabNagModel.cpp:980|Resources: CPU use in last 60s: tot=81% (usr=81%, sys=0%), traffic: 4957 (82/sec), ignored learning traffic: 4908
|Aug 22 10:31:09.015|027815|PabNagModel.cpp:980|Resources: CPU use in last 60s: tot=83% (usr=81%, sys=1%), traffic: 5030 (83/sec), ignored learning traffic: 4766

Environment

  • BIG-IP ASM policy with ‘Policy Building Learning Mode’ set to manual or automatic
  • High volume of traffic learning suggestions

Cause

In this case BIG-IP  ASM device displays a high cpu usage in  analysis plane  due to a high volume of learning suggestions being processed by the pabnagd process.
After learning suggestions are addressed CPU usage in analysis plane will reduce. 

Recommended Actions

Option 1:

  • Review and accept the traffic learning suggestions, especially those with high learning scores. In addition, if any traffic learning suggestions have been ignored, accept or delete them as this will also consume Analysis Plane CPU.

Option 2:

  • Set the 'Policy Building Learning Mode' to Disable.
     
  • Note: ASM will not create any learning suggestions if 'Policy Building Learning Mode' is disabled.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
