Description

You find the AAM reply the content from the cache for one virtual server with WA profile, but no user have accessed the URL through the virtual server before.

Environment

  • BIG-IP AAM
  • Mutiple virtual server with same Web Acceleration profile

Cause

BIG-IP AAM device share the cache for different virtual server with same Web Acceleration profile.

Recommended Actions

Clone the Web Acceleration profile, make sure each virtual server get individual Web Acceleration profile..

None at this stage.
