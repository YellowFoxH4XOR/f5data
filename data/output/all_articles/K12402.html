K12402: The server-side system in a BIG-IP WOM tunnel may not apply the configured rate class

Type
Known Issue
Published
2010-11-30
Updated

  • BIG-IP Edge Gateway: 10.2.0

Source

Known Issue

If you attempt to rate limit client traffic across a BIG-IP WOM tunnel to your servers by configuring a rate class with a flow direction of Client on the server-side BIG-IP WOM system, the traffic is not rate limited.

Note: Configuring a rate class on the server-side BIG-IP WOM system with the flow direction set to Client is intended to properly rate limit each connecting client's bandwidth without throttling traffic from the BIG-IP WOM deduplication cache.

F5 Product Development is tracking this issue as ID 344145.

Workaround

You can work around this issue by using an iRule to apply the rate class to the intended traffic. To do so, perform the following procedure:

  1. Log in to the server-side BIG-IP WOM Configuration utility.
  2. Navigate to the Local Traffic > iRules screen.
  3. Click Create.
  4. In the Name field, enter a name for the iRule, such as set_rateclass.
  5. In the Definition field, enter an iRule that appears similar to the following example:

    when SERVER_CONNECTED {
    set raddr [IP::remote_addr]
    set rport [TCP::remote_port]
    set srvrs {
    {10.10.20.10 80}
    {10.10.20.11 80}
    {10.10.20.12 80}
    }

    set rclass "http_limit"

    foreach srvr $srvrs {
    set saddr [lindex $srvr 0]
    set sport [lindex $srvr 1]
    if {($rport == $sport) && ([IP::addr $raddr equals $saddr])}{
    clientside { rateclass $rclass }
    return
    }
    }
    }

    Note: Substitute the IP addresses of your servers and the name of your rate class where indicated.

  6. Navigate to Local Traffic > Virtual Servers.
  7. Select the isession-virtual listening virtual server.
  8. In the Rate Class drop-down box, select None.
  9. Click the Resources tab.
  10. In the iRules section, click Manage.
  11. In the Available list, select the iRule you created in step 4.
  12. Click << to move the iRule to the Enabled list.
  13. To save the configuration, click Finished.

    Important: If you are running a redundant server-side BIG-IP WOM system, synchronize the configuration to the peer unit.
