Issue

Old Behavior

In versions prior to BIG-IP 14.1.0, single-user mode access does not require a password by default, allowing a user with console access to a BIG-IP system to bypass standard authentication. In these versions it is possible to restrict access to single-user mode on your BIG-IP system by editing the /etc/sysconfig/init file. For more information, refer to K16122817: Configuring user authentication for single-user mode access (12.x - 13.x).

New Behavior

Beginning in BIG-IP 14.1.0, single-user mode (also known as rescue mode in CentOS 7 and later) requires a password by default.

When you attempt to boot into single-user mode, you observe the following password prompt:

Give root password for maintenance (or type Control-D to continue):

Note: In BIG-IP 14.1.0 and later (and CentOS 7 and later), many userspace services, such as sulogin (single-user mode login), are loaded at boot time by systemd, the service manager for Linux operating systems. In these versions, it is possible to recover a lost password by interrupting the boot process before control is passed to systemd. For more information, refer to the Supplemental Information section.

Impact

Single-user mode password recovery is not available.

Recommended Actions

  • F5 recommends enabling Appliance mode for devices that require strict administrative access to match that of a typical network appliance and not a multi-user UNIX device. For more information, refer to K12815: Overview of Appliance mode.
