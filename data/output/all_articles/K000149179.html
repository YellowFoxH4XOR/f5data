K000149179: F5OS Host and tenants are not accessible when Allowed IP Addresses is loopback address 127.0.0.1 and Port All is configured.

Description

F5OS Host and tenants are not accessible when Allowed IP Addresses is loopback address 127.0.0.1 and Port All is configured.

System Unreachable - The network connection for your session has been interrupted and the system is unreachable. You will be automatically logged out.

Environment

F5OS 

webUI - System Settings: System Security > Allowed IP Addresses

Pop up message: System Unreachable - The network connection for your session has been interrupted and the system is unreachable. You will be automatically logged out.

Cause

Allowed IP Addresses is 127.0.0.1 and Port ALL configured.

Recommended Actions

If there is existing SSH session, you can delete the entry by CLI. If there is no existing SSH session, you must access it from the console access to delete the entry by CLI.

 

Delete an entry from the Allowed IP Addresses 

1. Log in to the CLI of the F5 rSeries system as the admin user.

2. View the Allowed IP Addresses entries on the F5 rSeries system

show running-config system allowed-ips
system allowed-ips allowed-ip entry1
 config ipv4 address 127.0.0.1
 config ipv4 prefix-length 32

3. Enter the following command:

config

4. Remove an existing entry in the Allowed IP Addresses 127.0.0.1.
For example, the following command removes remove all available settings for entry1:

no system allowed-ips allowed-ip entry1

5. Enter the following command to commit the change and exit config mode:

commit and-quit
