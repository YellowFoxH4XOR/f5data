Description

You want to install and license NGINX Controller.

Environment

  • NGINX Controller
  • Installation and initial setup
Cause

None

Recommended Actions

Log into My F5 portal, download controller software, copy association token, copy file from desktop to Linux host, extract the file on the Linux box, change directory, run the script:

  1. Log into https://my.f5.com (My F5 portal), if you don't have access or if you don't see the NGINX Controller subscription, please follow instruction in Additional Information below.
  2. In My F5 Portal click on subscriptions or Trials, Click on View Details next to the NGINX Controller, Copy the association token. Click on the downloads link and download the controller software.
  3. Using winscp copy the controller file to the Linux host
  4. Login to the Linux host, extract the file

    tar -zxvf controller-installer-<Version>.tar.gz

  5. Change directory to controller-installer, ensure you are a non Root user

    cd controller-installer

  6. Run the install script

    ./install.sh

  7. Follow the prompts, (if you get an error see additional information section below)
  8. Log into the NGINX Controller GUI hostname or IP address in your browser noting HTTPS secure connection is needed/
  9. On the screen enter your email and password, click n sign in.
  10. "No License found" page appears, click on Paste your association token, paste in the association token, and click on save.
  11. "License has been saved successfully" at the top of the screen.
  12. Web page blanks for a few seconds and returns to "create instance" 
Additional Information

To create a My F5 portal account please see the Link to the FAQ under Related Content.
If you have an account but are not able to see the NGINX Plus subscription, please contact your Customer Success manager.
For version specific guides to installing NGINX Plus please the link to NGINX Plus Admin Guide under related content.

If the install script fails, the error message could be very cryptic and show this:
ExecStart=/usr/bin/dockerd -H fd:// (code=exited, status=1/FAILURE)

But after executing the docker binary manually you will see some errors like this
Error starting daemon: Error initializing network controller: list bridge addresses failed: no available network.

Add the following internal network IP range to work around the issue.
ip link add name docker0 type bridge
ip addr add dev docker0 172.17.0.1/16
