Description

Every ten seconds, you can see on LTM logs (/var/log/ltm) this message:

Error ''/var/rrd/throughput' is too small (should be 3686368 bytes)' during rrd_update for rrd file '/var/rrd/throughput'

Environment

  • BIG-IP LTM
  • /var/log directory is getting full

Cause

An RRD info file is not valid or has become corrupted. 

Recommended Actions

  1.  Remove the following RRD info files by running these commands:
    rm -rf /var/rrd/connections.info
    rm -rf /var/rrd/connections
    rm -rf /var/rrd/throughput.info
    rm -rf /var/rrd/throughput
    rm -rf /var/rrd/rollupcpu.info
    rm -rf /var/rrd/rollupcpu
     
  2. Restart statsd daemon by running the following command:
    tmsh restart sys service statsd

Additional Information

  • K91343855: Error Message: 011b0600:3: Error '<reason>' during rrd_update for rrd file '<filename>'
