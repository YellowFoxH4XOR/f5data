K000148921: How to create local user with limited access

Type
Support Solution
Published
2024-12-10
Updated
2024-12-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000148921

Description

You want to create a read-only access user on your F5 device, with restricted rights of only allow performing Ping and Trace Route from CLI and only can view GUI for monitoring purpose. 

 

Environment

  • User role
  • CLI access
  • CLI privilege

 

Cause

None

 

Recommended Actions

In the Terminal Access, there are 2 options for non-admin user: disabled and tmsh. 
Creating a guest user with TMSH access will have permission to use certain BIG-IP system command line utilities based on their role.  
Allowing certain set of command on CLI only such as Ping and Traceroute for local user and restrict other command is not possible.
