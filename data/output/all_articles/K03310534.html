Known Issue

BIG-IP iSeries platforms may become unresponsive following a system restart.

This issue occurs when all of the following conditions are met:

  • You are running a BIG-IP iSeries platform
  • You change the administrative password for the Configuration utility to something other than the default of admin
  • You restart the system to one of the following versions:
    • BIG-IP 16.0.1.1
    • BIG-IP 15.1.2.1 through BIG-IP 15.1.3.1
    • BIG-IP 14.1.2 through BIG-IP 14.1.4

Impact

The LCD does not respond to user input and continuously displays Secure Mode.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The LCD display does not accept input and displays Secure Mode.
  • Output of the tmsh list sys db lcd.showmenu command shows the value of the lcd.showmenu database key is set to enable even though the LCD displays Secure Mode.
  • Messages similar to the following example appear in the /var/log/touchscreen_lcd file:

    err lcdui[1236]: URL: http://<IP_address>/mgmt/tm/sys/failover, result: 'Host requires authentication' (204), HTTP method 2, status 401.
