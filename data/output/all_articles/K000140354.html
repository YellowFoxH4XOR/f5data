K000140354: Event logs display packet drops for malicious and malformed DNS queries

Type
Support Solution
Published
2024-07-17
Updated
2024-07-17
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140354

Description

When you check the event logs on Configuration Utility by navigating to Security ›› Event Logs : Protocol : DNS, you may see packet drops for malicious and malformed DNS queries.

Environment

  • BIG-IP AFM
  • DNS Profile
  • Logging Profile with Protocol Security enabled for DNS Security

Cause

The BIG-IP system uses the DNS porfile to parse the incoming DNS queries. It is expected for the system to drop the malicious and malformed DNS queries. This behavior could be observed in the event logs, if you have enabled "Protocol Security" for "DNS Security" in the logging profile.

Recommended Actions

Expected behavior, no action needed.

Additional Information

None.
