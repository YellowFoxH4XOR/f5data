Known Issue

Description

When downloading a file through Windows Files using Internet Explorer, the download fails.  

  • You are using Internet Explorer 9 or later

Impact

Users are unable to download windows files.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You receive the following error message in the browser window:

    Internet Explorer cannot download <filename> from <hostname>
    Internet Explorer was not able to open this Internet site. The requested site is either unavailable or cannot be found. Please try again later.

    In this error message, note the following:

    • <filename> is the name of the windows file being downloaded
    • <hostname> is the name of the FirePass controller

Workaround

To work around this issue, you can perform one of the following options:

  • Select the Load into browser option in Windows Files instead of selecting the Download and save locally or Download as Zip archive options
  • Use a different browser, such as Firefox
