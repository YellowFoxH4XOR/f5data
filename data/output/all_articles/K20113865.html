Description

BIG-IP is configured as an NTP server. After upgrade, it is unable to reply the NTP information to clients which are requesting.  When checking the packet capture, you can see only NTP Client request.

Environment

  • BIG-IP
  • Previous software version, 14.1.0-14.1.0.6 and 15.0.0
  • BIG-IP is configured the management interface to use NTP services.
  • Already verifying NTP peer server communications (K10240)
  • Configured BIG-IP as an NTP server (K14120)

Cause

On BIG-IP 14.1.0-14.1.0.6 and 15.0.0, under certain conditions, network protections on the management port do not follow current best practices. (CVE-2019-6664)

Recommended Actions

  1. Login to BIG-IP CLI
  2. To enable the NTP port, a management firewall entry needs to be added, refer to this command below.

    # tmsh modify security firewall management-ip-rules rules add { ntp-udp { action accept destination { ports add { 123 } } ip-protocol udp place-before first } }
     
  3. Save the configuration

    # tmsh save /sys config
