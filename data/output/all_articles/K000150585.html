Description

When attempting to upgrade the BIG-IP system, after uploading the corresponding .iso file, the "AVAILABLE" column for the imported file is set to "NO," indicating that the software is not available for operations. 

Environment

  • BIG-IP LTM VE
  • Upgrade

Cause

The platform SKU does not support the software version of the newly installed image. Attempting to use an ISO file for a version outside of its license range results in it being marked as unavailable. 

Recommended Actions

  1. Verify Supported Versions: Use your platform SKU to determine the range of supported software versions. To determine your platform's SKU please refer to K42091606: Determine your BIG-IP VE SKU and permitted software version range.

  2. Upgrade License: Contact your Account Manager to obtain a new license that supports your desired version.

  3. Re-import ISO File (Optional): If you suspect corruption during import rather than this being a licensing issue, delete the current ISO file and re-import it before proceeding with further troubleshooting.
