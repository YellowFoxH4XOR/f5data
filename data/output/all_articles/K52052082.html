K52052082: Syntax Error:(/config/bigip.conf at line: nnnn) ''user-defined'' unknown property

Description

Configuration load fails with below error :
Syntax Error:(/config/bigip.conf at line: nnnn) "user-defined" unknown property

You can run "tmsh load sys config verify" in bash to confirm this error. 

Environment

  • BIG-IP Device
  • Configuration load 

Cause

TCP monitor contains HTTP parameters.

Recommended Actions

To work around this issue and load the config :

Note : Take a UCS backup before any modifications.

1. Edit /config/bigip.conf to remove the lines with user-defined parameters. You can use a vi/vim editor to make these changes.

Note : If this error is for an object in another partition , you need to modify the respective config in /config/partitions/<partition name>/bigip.conf

Before:

ltm monitor tcp-half-open /Common/test {
    defaults-from /Common/tcp_half_open
    destination *:443
    interval 15
    time-until-up 0
    timeout 61
    user-defined RECV_I "HTTP/1.1 200"                         ----------->
    user-defined SEND "HEAD /abc/abc.html HTTP/1.0\r\n\r\n"    ----------->
}

After :
 

ltm monitor tcp-half-open /Common/test {
    defaults-from /Common/tcp_half_open
    destination *:443
    interval 15
    time-until-up 0
    timeout 61
}

2. Run "tmsh load sys config verify" to confirm the error is fixed.

3. Run  "tmsh load sys config" to load the config.
