Description

Following error message appears in the /var/log/audit approximately every one hour:
host=10.10.10.10 failed to login after 1 attempts

Environment
  • BIG-IP LTMs in High Availability
  • IP address observed in /var/log/audit is self-IP of remote peer BIG-IP in HA pair
Cause

None

Recommended Actions

As a workaround  you try to rebuild device trust: K42161405: Rebuilding device trust using the Configuration utility (11.x - 15.x)  

Additional Information:

Additionally on peer HA system you can observe following logs in /var/log/restjavad.log:

[8100/tm/shared/bigip-failover-state BigipFailoverStateWorker] Failed to discover <peer_IP_address>: java.lang.IllegalStateException: Authentication Failure to host <peer_IP-address> Please check the credentials provided.

Where <peer_ip-address> is self-ip of remote peer in HA pair.
