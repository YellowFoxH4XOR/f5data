Topic

Always-On Management (AOM) is a separate subsystem that provides lights-out management for the BIG-IP system. It is possible to configure the AOM using the AOM Command Menu and to change AOM settings, such as the network configuration.

Note: For a list of platforms that contain an AOM subsystem, refer to K9476: The F5 hardware/software compatibility matrix.

Note: For more information about AOM, refer to K9403: Overview of the AOM subsystem.

On occasion, you may want to reset the AOM configuration to factory default settings. To reset the AOM configuration to factory default settings, perform the following procedure:

Note: AOM shell access is not included on the BIG-IP 2000/4000, 5000/7000, and 10000 series platforms; all AOM management functionality is provided by the AOM menu. Therefore, the following procedure is not applicable on the aforementioned platforms.

Note: Performing this procedure will delete the secure shell (SSH) keys, which have been negotiated between the host and the AOM. The keys will be automatically regenerated after the next reboot of the host.

  1. Log in to the BIG-IP command line.
  2. SSH to the AOM by typing the following command:

    ssh aom

  3. From the AOM prompt, remove the /jffs/ directory by typing the following command:

    rm /jffs/*

  4. Open the hostconsh shell by typing the following command:

    hostconsh

  5. Display the AOM Command Menu by typing the following key sequence:

    Esc (

    The AOM Command Menu opens.

  6. To reset the AOM subsystem, select the following option:

    4 --- Reset AOM subsystem (issues hardware reset--USE WITH CARE!)
