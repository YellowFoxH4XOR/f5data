Topic

You should consider using this procedure under the following condition:

  • You want to configure your BIG-IP ASM security policy to disallow file uploads containing binary executable content.

Description

In some cases, an attacker may attempt to upload binary executable content to your web application. After executable content is successfully uploaded to the web server, the attacker can attempt to run the program to gain remote access to the server or spread malware to application users.

You can configure your BIG-IP ASM security policy to block file uploads that contain binary executable content. To do so, you configure a user-input parameter and set the parameter to disallow uploading executable files. When you configure the security policy to detect file upload content for binary executable files:

  • The system detects binary executable files compiled for many common platforms, such as Linux, Windows, and MacOS.
  • You can configure the following explicit or wildcard parameter types to detect binary executable content:
    • Global parameters
    • URL parameters
    • Flow parameters
  • The system decodes and enforces URL-encoded parameters.
  • The system detects binary executable in the following content:
    • GET and POST requests; the feature does not detect response content
    • GET requests that contain a message body
    • Multipart requests with multiple boundaries
    • 100-continue requests
    • Chunked content

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

Configuring a user-input parameter to disallow binary executable file uploads

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Parameters > Parameters List.
  3. In the security policy drop-down list, click the name of the policy you want to edit.
  4. Click Create.
  5. Type a name for the parameter.
  6. In the Parameter Level list, click the appropriate association for the parameter:
    • Global indicates that the parameter is not associated with a specific URL or flow.
    • URL indicates that the parameter occurs in the specific URL that you provide.
    • Flow indicates that the parameter occurs in the specific entry point URL or referrer URL that you provide.
  7. In the Parameter Value Type list, click User-input value.
  8. On the Data Type tab, in the Data Type list, click File Upload.
  9. For Disallow File Upload of Executables, select the Disallow check box.
  10. Click Create.
  11. Click Apply Policy.

Configuring learning and blocking settings for disallowed file upload content

The BIG-IP ASM system responds to disallowed file uploads, depending on the settings you configure for the Disallowed file upload content detected violation on the Learning and Blocking Settings page. To configure learning and blocking settings for Disallowed file upload content detected violations, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. In the security policy drop-down list, click the name of the policy you want to edit.
  4. Expand Parameters.
  5. For the Disallowed file upload content detected violation, select the Learn, Alarm, and Block check boxes, as required.
  6. Click Save.
  7. Click Apply Policy.
