K000135264: ELK command to collect elastic search data for TDR troubleshooting

Type
Support Solution
Published
2024-10-25
Updated
2024-10-25
Source

Description

  • Article is above data to collect to troubleshoot ELK for TDR on SDC
  • TDR is not generating on EMS


Environment

  • TDR is not generating on EMS(ELK)


Cause

There could different issue cause problem on elastic search.


Recommended Actions


curl -X GET "https://ip:9200/_cat/allocation?v" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cat/allocation/explain?pretty" --key instance.key -k -u elastic:traffix


curl -X GET "https://ip:9200/_cat/shards?h=index,shard,prirep,state,unassigned.reason" --key instance.key -k -u elastic:traffix

curl -X GET "https://ip:9200/_cluster/allocation/explain?pretty" --key instance.key -k -u elastic:traffix


ip: is to be replaced with EMS's node address. Please collect the follow above data from EMS, prior to opening of SR for support to investigate further.
