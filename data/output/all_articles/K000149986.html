Description

  • I want to allow file types that are by default disallowed

Environment

  • F5® Distributed Cloud Console
  • Service Policy
  • WAF exclusion rule

Cause

File Types: A File Type in App Firewall is regarded as any file extension found at the end of the URL path, such as .html, .aspx, .php, etc. The following file types are disallowed by default:

{bak, bat, bck, bin, bkp, cer, cfg, cgi, cmd, com, conf, config, crt, dat, der, dll, eml, exe, hta, htr, htw, ida, idc, idq, ini, key, log, msi, nws, old, p12, p7b, p7c, pem, pfx, pol, printer, reg, sav, save, shtm, shtml, stm, sys, temp, tmp, wmz}

 

Answer/Recommended Actions

Service policy allows you to define multiple file extensions whereas WAF exclusion rule only one by one.

A File Type in App Firewall is regarded as any file extension found at the end of the URL path, such as .html, .aspx, .php, etc.

So to allow a disallowed file type we will need to create a rule (in Service policy or WAF exclusion rule) and:

  1. Disable Illegal filetype (VIOL_FILETYPE) using the Violations menu option
  2. Add path with regex that will specify the extension
