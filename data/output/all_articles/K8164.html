Known Issue

Note: Connection mirroring is not supported for Secure Sockets Layer (SSL) connections that are terminated by BIG-IP LTM. For more information, refer to K7216: The BIG-IP LTM system does not support connection mirroring for SSL terminated traffic.

This is the result of a known issue. If connection mirroring is enabled for a virtual server, persistence mirroring for the virtual server will be disabled. Enabling connection mirroring should not affect the behavior of persistence mirroring for the virtual server.

F5 Product Development tracked this issue as CR90378 and it was fixed in BIG-IP LTM 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by ensuring connection mirroring is disabled for the virtual server. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the desired virtual server.
  4. Select Advanced from the Configuration menu.
  5. Clear the Connection Mirroring check box.
  6. Click the Update button.

Note: Repeat the procedure on the peer BIG-IP LTM system, or synchronize the configuration.
