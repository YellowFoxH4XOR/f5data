K000153003: We need to add a CNAME for a root domain which is not letting us to add, so instead can we add as an alias record?

Type
Support Solution
Published
2025-08-13
Updated
2025-08-13
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.0
Source
https://my.f5.com/manage/s/article/K000153003

Description:

 

It is not possible to create a CNAME record for a root (apex) domain, such as example.com, on BIG-IP DNS (GTM). When attempting to add a CNAME record at the root zone, the record does not appear in the Resource Records List and no error message is displayed. The "alias" record type is not available in F5 GTM, and TXT records may also disappear from ZoneRunner after creation.

 

Environment:

 

Product: BIG-IP DNS (GTM)

Version: 17.5.0

Platform: F5-BIG-DNS-I2600, C117

Configuration: Attempting to create CNAME or alias records at the root (apex) domain

Cause:

 

DNS protocol standards (RFC 1034/1035) require SOA and NS records at the root domain, which cannot coexist with a CNAME record. F5 BIG-IP DNS (GTM) does not support ALIAS or ANAME records at the root domain, and the "alias" record type is not available.

 

Recommendations:

 

Use A or AAAA records at the root domain, pointing directly to the required IP addresses.

Be aware that this approach requires manual maintenance of IP addresses if the target changes.

There is no supported method to create CNAME, ALIAS, or ANAME records at the root domain in F5 BIG-IP DNS (GTM).
