Description

How to add a new blade to an existing tenant

Environment

  • F5OS-C
  • Partition
  • Tenant

Cause

A new blade has been installed and needs to be allocated to the tenant.

Recommended Actions

1. Install the new blade to the chassis

[F5OS-C] Adding a new blade in a VELOS system

2. Login to the controller via cli. Ensure blade is added to the cluster:

show cluster nodes

3. Login to the GUI, go to Chassis Partitions > Select Blade > Click the Partition > Click Edit

In Selected Slots, the new blade is added.

Click Save 

4. Login to the Partition > Tenant Deployments > Click the tenant

In Allowed Slots, click the new blade added 

Click Save & Close

5. The system will automatically copy a tenant instance to the new blade. Wait until the whole process complete.

6. From the tenant, monitor the progress by running command below:

tmsh show sys software status

tmsh show sys cluster

Additional Information

Ensure that all ISO images of the software installed on the existing volume are present in the tenant's /shared/images directory
