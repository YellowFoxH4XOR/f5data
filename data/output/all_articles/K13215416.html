Known Issue

In rare instances, the sod or bigd processes may produce a core file when the BIG-IP system shuts down.

This issue occurs when the following condition is met:

  • The BIG-IP system is shutting down.

Impact

There is no impact. You can safely ignore the sod or bigd core file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system generates a bigd or sod core file to the /shared/core directory, which includes a time stamp that corresponds with a shutdown event.
