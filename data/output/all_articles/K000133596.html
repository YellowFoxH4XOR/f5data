Description

Using tmsh, installing Protocol Inspection update file fails.

# tmsh install security protocol-inspection updates file pi_updates_15.1.0-20230328.1944.im
01071c1e:3: Cannot perform Protocol inspection update: Malformed package

Likewise, using the Configuration utility, importing Protocol Inspection update file fails.

Error: Incompatible package due to missing 'ips_hitless_update'

/var/log/pi_hitless_upgrade may have an error message similar to below.

ERROR: IM file [/shared/protocol_inspection_updates/pi_updates_16.1.0-20230605.1111.im] is too big to install 21MB, Max allowed decompressed size is 20MB

Environment

  • Installing or importing Protocol Inspection update file newer than pi_updates_x.x.x-20230322.0546.im.

Cause

The issue is tracked as ID 1274001. Due to the fix for CVE-2022-28695 (K08510472), pi_updates IM package structure was changed in 20230328 packages. It made pi_updates IM package 20230328 and newer versions incompatible with the released BIG-IP versions.

Recommended Actions

Release note of each protocol inspection update has a note of which IM file needs to be installed. Please consult the note and determine which file to download and install. The following is the general rule for the currently supported versions as of this writing.

BIG-IP v15.x, v16.x and v17.x:

  1. Install and load IM package pi_updates_xx.x.x-20230322.0546.im first.
  2. Install and load IM package of your choice.

BIG-IP v14.1.0 - v14.1.4.5:

  1. Install and load IM package pi_updates_14.1.0-xxxxxxxx.xxxx.im.

BIG-IP v14.1.4.6:

  1. Install and load IM package pi_updates_14.1.4.6-xxxxxxxx.xxxx.im.

BIG-IP v14.1.5 - v14.1.5.x:

  1. Install and load IM package pi_updates_14.1.5-xxxxxxxx.xxxx.im.
