Topic

Configuring BIG-IP virtual servers to use iRules that contain CACHE commands.

Description

You can configure the behavior of the BIG-IP HTTP cache using the iRules CACHE commands (the HTTP cache is referred to as the RAM Cache in systems prior to BIG-IP 11.0.0). You must enable the HTTP cache on the virtual server before you assign iRules CACHE commands to it.

To enable the HTTP cache on the virtual server, do one of the following:

  • For BIG-IP 11.x and later, associate an HTTP profile and a Web Acceleration profile with the virtual server.
  • For BIG-IP 10.x, if the HTTP cache is not already enabled on the virtual server, enable the RAM Cache feature in the associated HTTP profile.

Note: For systems prior to BIG-IP 13.0.0, if you do not associate a Web Acceleration profile with your virtual server, and you use an iRules CACHE command, the Traffic Management Microkernel (TMM) resets connections to the virtual server. In BIG-IP 13.0.0 and later, TMM will not reset connections; however, without a Web Acceleration profile, objects will not be cached.
