Issue

Error Message

011b0601:3: Error '<message>' during rrd_graph for graph '<name>' 

In this error message, note the following:

  • <message> is a description of the error
  • <name> is the name of the RRD graph being created

For example:

011b0601:3: Error 'libpng error: Write Error' during rrd_graph for graph 'memory'

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The RRD graph creation fails for any reason.

Impact

The specific graph is not created and you are unable to view the performance data.

Recommended Actions

To work around this issue, you can restart the statsd process. To do so, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the statsd process, type the following command:

    restart /sys service statsd
