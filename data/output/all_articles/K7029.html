Topic

The MSSQL, MYSQL, and Oracle monitors will not verify receive strings that consist of multiple lines in a column. This is because the BIG-IP system does not support using the \r\n Carriage Return (CR) (and Line Feed (LF) control characters in send and receive strings for MSSQL, MYSQL and Oracle monitor configurations. Using Carriage Return and Line Feed control characters in send and receive strings for these monitors results in pool members being marked down.
