Description

While doing config-sync, the below error messages observed in /var/log/ltm:

Sync error on ltm1.bigip: Load failed from /Common/ltm2.bigip 01071769:3: Decryption of the field (restricted_key) for object (/Common/iappKey) failed while loading configuration that is encrypted with a different master key.

ltm1.bigip err mcpd[7598]: 0107102b:3: Master Key decrypt failure - decrypt failure - final

It also can be obersved by running the following command from CLI:

root@(ltm2)(cfg-sync Sync Failed)(Active)(/Common)(tmos)# show cm sync-status

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
CM::Sync Status
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Color red
Status Sync Failed
Mode high-availability
Summary A validation error occurred while syncing to a remote device
Details
ltm1.bigip: connected
device-group-failover (Sync Failed): A validation error occurred while syncing to a remote device
- Sync error on ltm2.bigip: Load failed from /Common/ltm1.bigip 01071769:3: Decryption of the field (passphrase) for object (/Common/f5_api_com.key) failed while loading configuration that is encrypted with a different master key.
- Recommended action: Review the error message and determine corrective action on the device
device_trust_group (Sync Failed): A validation error occurred while syncing to a remote device
- Sync error on ltm2.bigip: Load failed from /Common/ltm1.bigip 01071769:3: Decryption of the field (restricted_key) for object (/Common/iappKey) failed while loading configuration that is encrypted with a different master key.
- Recommended action: Review the error message and determine corrective action on the device

Cause

Not known at the time of publication

Recommended Actions

  1.  On Standby device (ltm2.bigip), make a copy of the /config/bigip.conf file by typing the following command from CLI:
cp /config/bigip.conf /config/bigip.conf.K000137242
  1. Use a text editor to edit the /config/bigip.conf file and remove f5_api_com.key and f5_api_com.crt.
The following will be removed from the config file i.e.:
sys file ssl-cert /Common/f5_api_com.crt {
    cache-path /config/filestore/files_d/Common_d/certificate_d/:Common:f5_api_com.crt_100287_1
    revision 1
    source-path file:///config/ssl/ssl.crt/f5_api_com.crt
}
sys file ssl-key /Common/f5_api_com.key {
    cache-path /config/filestore/files_d/Common_d/certificate_key_d/:Common:f5_api_com.key_100277_1
    passphrase ***scrubbed***
    revision 1
    source-path file:///config/ssl/ssl.key/f5_api_com.key
}
  1. Load the configuration by typing the following command from CLI:
tmsh load sys config
Note: You may use the following command to verify your configuration: tmsh load sys config verify
  1. From the Active device (ltm1.bigip) , obtain the master key by typing the following command:
f5mku -K
  1. Copy the output and save aside.
  2. On Standby device (ltm2.bigip), install the master key that you copied in step 5 using the following command syntax:
f5mku -r <key_value>
  1. Verify the master key after installed by typing the following command:
f5mku -K
  1. Verify the configuration with the following command:
tmsh load sys config verify
  1. If there are no errors, save the configuration:
tmsh save sys config
  1. Synchronize from active device (ltm1.bigip) to standby (ltm2.bigip).
