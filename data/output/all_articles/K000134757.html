K000134757: Carrier Grade Cipher Suites in Aspen Mesh

Published
2023-06-01
Updated

Applies to
  • Aspen Mesh: 1.14
Source

Description

We can enable Carrier Grade Cipher Suites in Aspen Mesh for On-mesh traffic (traffic that originates and terminates on the mesh) and Mesh-ingress traffic (traffic that originates off the mesh and terminates at an ingress gateway on the mesh).
 

Environment

Aspen Mesh 1.14.6-am4
 

Cause

Aspen Mesh can limit the amount of Cipher Suites available for security reasons.
 

Recommended Actions

Visit the Aspen Mesh Documentation to learn how to enable the Carrier Grade Cipher Suites.

 

Additional Information

Cipher suites are sets of instructions that enable secure network connections through Transport Layer Security (TLS), often still referred to as Secure Sockets Layer (SSL). Behind the scenes, these cipher suites provide a set of algorithms and protocols required to secure communications between clients and servers.

We can verify the cipher suites either by using openssl or curl 
openssl s_client -connect <host>:443 -servername <SNI> -tls1_2 -CAfile <caFile> -cipher <cipherSuite>
curl -v -HHost:example.com --cacert <cafile> "https://example.com" --tlsv1.2 --tls-max 1.2 --ciphers <cipherSuite>
