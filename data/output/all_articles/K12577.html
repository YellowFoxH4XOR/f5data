Known Issue

This is the result of a known issue. The Citrix receiver application may fail to authenticate when using the Citrix Access Gateway Enterprise Edition (AGEE) mode connecting through the BIG-IP APM. Authentication will fail if a user's name or password contains non-English characters or special characters, such as &,<,>,%, or =.

The BIG-IP APM Citrix_APM_Helper iRule does not correctly parse characters that are considered escaped. Escaped characters are characters that may have special meaning to the underlying operating system. To be literally interpreted, they are prefaced with a special character recognized by the operating system to indicate it should not perform any translation on the escaped character.

Note: For more information about configuring the BIG-IP APM for use with Citrix XenApp, refer to the Deploying BIG-IP Access Policy Manager with Citrix XenApp guide.

F5 Product Development tracked this issue as ID 343315 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
