Description

You are deploying an AS3 declaration and it fails.
If you examine the results (By using Postman or similar) you see

code": 400,
            "message": "declaration failed",
            "response": "POST http://admin:XXXXXX@localhost:8100/mgmt/tm/sys/config merge cli script response=400 body={\"code\":400,\"message\":\"incomplete command\",\"errorStack\":[],

Environment

  • Using AS3, either direct to a BIG-IP or through a BIG-IQ

Cause
The Declaration contains an invalid irule.
Consider this snippet

WWW.EXAMPLE.COM_REDIRECT": {
                    "class": "iRule",
                    "iRule": {
                        "base64": "d2hlbiBIVFRQX1JFUVVFU1QgewogIGlmIHsgW0hUVFA6OnVyaV0gPT0gIi8iIH0gewogICAgSFRUUDo6cmVkaXJlY3QgImh0dHBzOi8vd3d3LmV4YW1wbGUub3JnIgogIH0="
                    }
                },
The irule decodes to

when HTTP_REQUEST {
  if { [HTTP::uri] == "/" } {
    HTTP::redirect "https://www.example.org"
  }

This is invalid. It is missing a trailing  }

Recommended Actions

  1. Fix the syntax error.
  2. With AS3 Versions up to  3.39 (Current at time of writing) AS3 does not indicate where in the declaration  this is occurring.
