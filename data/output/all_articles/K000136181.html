K000136181: TCP health monitor shows nodes in disabled state

Type
Support Solution
Published
2023-09-13
Updated
2023-09-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.5, 17.0.0, 16.1.3, 16.1.2, 15.1.7, 15.1.6, 15.1.5, 14.1.5, 14.1.4, 15.1.8
Source
https://my.f5.com/manage/s/article/K000136181

Description

The nodes in the pools are shown as "unknown" state even if they are down. BIG-IP might send traffic to the nodes in the pool that should have been marked as down.

Environment

  • BIG-IP
  • FQDN nodes

Cause

Bug ID 1111473

Recommended Actions

The long term fix is to upgrade to the fixed version: 17.1.0, 16.1.4, 15.1.9 or later

Workaround:
Restart mcpd following workaround in Bug ID 1111473: restart mcpd with K13030: Forcing the mcpd process to reload the BIG-IP configuration

Additional Information

None
