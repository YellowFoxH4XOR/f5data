Known Issue

Java applets may fail when accessed through a Network Access profile.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with a Network Access profile that has client proxy settings enabled.
  • Users connect to the Network Access profile with the Internet Explorer browser that uses a proxy autoconfig file.
  • Users with an established session attempt to access a destination resource Java applet.

Impact

The Java applet fails to render content.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When accessing a Java applet, the following browser error message displays:

    Microsoft JScript compilation error

    Expected ';'

  • Java applet content does not render correctly.
