K000141517: Behavioral DoS blocks legitimate traffic

Type

Published
2024-10-24

Source

Description

With Standard Protection enabled for BDos, in necessary conditions, the system will limits the number of all concurrent connections based on server health

Server health can be verfiied by 

# admd -s vs./Common/VS+/Common/DOS-Profile.sig.health

replace VS with the virtual server name
replace DOS-Profile with name of the assigned profile

If the health score is > 1 it suggests the response is low.

Environment

Advanced WAF
BDoS (Behavioral DoS)
Standard Protection

 

Cause

Due to poor server health score, admd based on BDoS mitigation configuration impacts the legitimate traffic

 

Recommended Actions

General recommedation is to try below settings for "Conservative Protection mode" instead Standard protection and verify if it imporves the situation. 

If Bad Actors Behavior Detection is enabled, slows down bad identified bad actors.
If Request Signatures Detection is enabled, blocks requests that match attack signatures

Disable Use TLS patterns as part of host identification.
Disable Accelerated HTTP signatures.
Disable TLS fingerprinting signatures.
Enable Use approved signatures only.
