Note: For information about bypassing the BIG-IP WebAccelerator with an iRule in version 10.x, refer to K10127: Bypassing BIG-IP WebAccelerator with an iRule in version 10.x.

In BIG-IP WebAccelerator version 9.4.x, you can use the following iRule command to bypass the BIG-IP WebAccelerator for certain connections:

set wa_bypass 1

When using the wa_bypass command to bypass the BIG-IP WebAccelerator in an iRule, you should make sure to reset the variable to 0 (zero) for subsequent requests on the connection. Otherwise, all subsequent requests on the connection will bypass the BIG-IP WebAccelerator. For example, in the following iRule, URI requests containing Firefox in the User-Agent string will bypass the BIG-IP WebAccelerator. The wa_bypass command is then reset, allowing subsequent requests on the connection to pass through the BIG-IP WebAccelerator:

when HTTP_REQUEST {
  set wa_bypass 0
  if { [HTTP::header User-Agent] contains "Firefox" } {
    set wa_bypass 1
  }
}

It is also possible to bypass the BIG-IP WebAccelerator without using the wa_bypass variable by disabling the HTTP::class in the iRule:

when HTTP_REQUEST {
  HTTP::class enable
  if { [HTTP::uri] ends_with ".pdf"} {
    HTTP::class disable
  }
}

In versions prior to 9.4.7, if the HTTP profile selected for the virtual server has RAM Cache enabled, you should also disable caching in the iRule to prevent failed requests when the requested object matches an object in the RAM Cache from a previous request to a hostname that is enabled for BIG-IP WebAccelerator.

Note: For information about this issue, refer to K8736: Requests to unconfigured hosts fail with a 'TCL error: _sys_WA_ramchache_clientside - Illegal argument (line 13) invoked from within "CACHE::header replace "X-PvInfo" $cache_pvinfo"' error message.

The following example iRules demonstrate the required command sequences for bypassing both the cache and the BIG-IP WebAccelerator:

when HTTP_REQUEST {
  set wa_bypass 0
  CACHE::enable
  if { [HTTP::path] ends_with ".pdf" } {
    CACHE::disable
    set wa_bypass 1
  }
}

when HTTP_REQUEST {
  HTTP::class enable
  CACHE::enable
  if { [HTTP::header User-Agent] contains "Firefox"} {
    HTTP::class disable
    CACHE::disable
  }
}
