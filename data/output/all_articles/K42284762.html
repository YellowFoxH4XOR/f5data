Known Issue

BIG-IP Edge Client for Mac may terminate unexpectedly during machine certificate inspection.

This issue occurs when all of the following conditions are met:

  • The user is running macOS Sierra 10.12.6.
  • You use BIG-IP Edge Client to establish a network access session to the BIG-IP APM system.
  • The access policy is configured with a Machine Cert Auth object that has the Match Issuer field configured.
  • For BIG-IP APM 13.1.0 systems, the APM Clients 7.1.5 package is installed.

Impact

BIG-IP Edge Client fails client inspection and terminates unexpectedly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • macOS Sierra users cannot connect to the BIG-IP APM system using BIG-IP Edge Client.
  • The log entries in the edge.log file on the client for the failed connection end with a message similar to the following example:

    935, 1501,94007,edge, 48, /MachineCertChecker.cpp, 1424, DoRun, Running machine certificate check....
