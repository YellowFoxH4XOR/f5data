K77600232: BIG-IQ exceeds storage quota limits when importing a BIG-IP

Type
Support Solution
Published
2020-05-01
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K77600232

Description

When a BIG-IQ imports a new BIG-IP device, all the custom data files in the filestore are also copied to the BIG-IQ, this can fill up the volume on the BIG-IQ

Following are some examples of the error messages that may be logged in /var/log/restjavad.0.log:

Example 1:
[ERROR][<date>][/cm/access/tasks/dma/download-files/61ecd0d2-bbf9-447e-b93c-7c4ee756c412/worker DownloadFilesTaskWorker] Failed to download file (files_d/Common_d/customization_group_d/:Common:blahblahblahblah_119281_1). java.lang.RuntimeException: file files_d/Common_d/customization_group_d/:Common:blahblahblahblah_119281_1 exceeds storage quota limits

Example 2:
[ERROR][<date>][/cm/access/tasks/dma/download-files/34f06ba6-75df-4b38-a0f5-9e24de92xxxx/worker DownloadFilesTaskWorker] Failed to download one or more files.
[ERROR][<date>][/cm/access/tasks/declare-mgmt-authority/499d1be7-88f7-4bb7-8704-b81425c5xxxx/worker AccessDMATaskWorker] Failed to download one or more files.

Environment

This will be especially relevant for BIG-IP's where

  • You are using the BIG-IP to host large files like client installers
  • You have customised APM Login Configuration objects and images
  • You are managing a number of devices (BIG-IQ does not de-duplicate these files) individually

Cause

The default storage space for these shared files iin /var/config/rest/fileobject is 512 MB.
For example storing 50 MB of downloadable installers on 10 managed APM BIG-IP's will almost fill this storage space.

Recommended Actions

If you are managing a set of APM's with similar configurations, then not managing them individually, but as an Access Group allows you to push the same one file out to multiple devices

If you want to host more than 512 MB of files across all of your managed devices, you need to expand the storage space.
To see the current storage capacity, run the following command, replacing <password> with your admin password:
restcurl -u admin:<password> /mgmt/shared/file-object-configuration/storageDir

This will look something like
config # restcurl -u admin:admin /mgmt/shared/file-object-configuration/storageDir
{
  "name": "storageDir",
  "directoryPath": "/var/config/rest/fileobject",
  "maxFilespaceBytes": 524288000,
  "generation": 1,
  "lastUpdateMicros": 1555303164953727,
  "kind": "shared:file-object-configuration:fileobjectconfigurationstate",
  "selfLink": "https://localhost/mgmt/shared/file-object-configuration/storageDir"
}
This shows the directory /var/config/rest/fileobject as having a limit of 524288000 bytes (512 MB).

The following command expands the storage space when run on the BIG-IQ to 2 GB
restcurl -u admin:<password> -X PATCH /mgmt/shared/file-object-configuration/storageDir -d '{"maxFilespaceBytes":2048000000}'

The current usage of that directory on the BIG-IP can be shown with the command
du -hs /var/config/rest/fileobject/
This will show the human readable summary of the total size of the contents of that directory
