Description
   APM users get the following message when trying to access an internal resource published as Portal Access on APM Webtop.
      notice  <hostname>  tmm1[<pid>]  01490504   <session id> <hostname> can not be resolved.

Environment

  • BIG-IP APM
  • Application published as Portal Access resource using FQDN hostname.

Cause
   When more than one BIG-IP DNS (Internal & External) servers are configured on the BIG-IP, and the hostname resolution of the Portal resource is done by the BIG-IP DNS server which cannot resolve it, then the above message is logged.

Recommended Actions

  1. Make sure the BIG-IP is configured with BIG-IP DNS servers that can resolve internal hostnames.
