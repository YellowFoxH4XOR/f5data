Known Issue

This is the result of a known issue. If an XML schema contains a large pattern restriction, and the BIG-IP ASM system receives a request that contains a pattern that exceeds 512K, the BIG-IP ASM system reports a violation and blocks the request.

A 512K pattern limit size within the XML schema compiler causes this issue. The BIG-IP ASM system allows you to load a pattern restriction that exceeds 512K into the XML profile, but when the system receives a request that contains a pattern that exceeds the 512K limit, the XML profile cannot validate any information beyond the 512K mark. This results in the BIG-IP ASM system reporting a violation (a false positive when the pattern is valid) and blocking the request.

F5 Product Development tracked this issue as ID 340172 and it was fixed in BIG-IP ASM 10.2.2. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in cumulative Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
