Description

When we use F5 Configuration Utility (TMUI GUI) of SSL Orchestrator (SSLO) product, if we go to the menu SSL Orchestrator --> Configuration --> Office 365 URL updater feature, it runs a script in the background and automatically creates many BIG-IP objects. 

 

To figure out it updated successfully, we can look for the objects that it created automatically.

 

This feature, depending on configuration, create four custom URL categories:

  1. Office_365_Optimized(Managed): Contains the set of URL endpoints required for connectivity to every Office 365 service and represent over 75% of Office 365 bandwidth, connections, and volume of data. These endpoints represent Office 365 scenarios that are the most sensitive to network performance, latency, and availability. The list of URLs in this category is short, only containing the resources that are the most sensitive to latency:
    outlook.office.com
    outlook.office365.com
    *.sharepoint.com

  2. Office_365_Allow(Managed): Contains the set of URL endpoints required for connectivity to specific Office 365 services and features but are not as sensitive to network performance and latency as those in the Optimize category.
  3. Office_365_Default(Managed): Contains the set of URL endpoints that represent Office 365 services and dependencies that do not require any optimization and can be treated by customer networks as normal Internet bound traffic.
  4. Office_365_All(Managed): Contains the set of all URL endpoints

It will also optionally create two IP data groups that can be used in policy rule IP conditions:

  1. Office_365_Managed_IPv4
  2. Office_365_Managed_IPv6

Environment

  • F5 SSL Orchestrator product
  • BIG-IP 17.x and above
  • Office 365 (O365) URL updater feature

Cause

None

Recommended Actions

None
