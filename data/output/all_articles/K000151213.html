Description

CVE-2025-31324 is a security vulnerability in SAP NetWeaver that arises from insufficient authorization checks. This flaw can allow attackers with valid but unprivileged sessions to access restricted resources or URLs within the application. F5 BIG-IP ASM provides detection and mitigation for this vulnerability through attack signature ID 200020225, included in the latest attack signature sets.

Environment

  • Attack Signature Set: ASM-AttackSignatures_20250429_140907.im or later
  • Affected Application: SAP NetWeaver

Cause

The vulnerability is caused by inadequate authorization logic within the SAP NetWeaver application, which allows users with authenticated but insufficiently privileged sessions to access protected resources.

Recommended Actions

This issue can be addressed in one of two ways on the AdvWAF:

Update Attack Signatures:

  • Ensure your BIG-IP ASM system is running the latest attack signature set (ASM-AttackSignatures_20250429_140907.im or newer).
  • Verify that attack signature ID 200020225 is present and enabled, as it specifically addresses CVE-2025-31324.
    • If it is not included in one of the sets attached to the policy you can add it by adding one of these Signature Sets:
      • Websphere Signatures
      • Low Accuracy Signatures
      • Medium Accuracy Signatures
  • You can search for this signature by either its CVE number or its signature ID.
    • K45558510: Filtering the Attack Signature List by the referenced CVE

Configure Login Pages and URL Protection:

  • Define login pages and specify authenticated URLs in BIG-IP ASM to restrict access to sensitive areas of your application.
  • This configuration will require users to authenticate before accessing protected URLs.
    • Creating Login Pages for Secure Application Access
    • Note: While this measure prevents unauthenticated access, it may not block attacks from users who have valid sessions but lack proper privileges.

You can also address the CVE by using one of the above 2 options and:

Remediate at the Application Level:

  • Update SAP NetWeaver to implement robust authorization checks on all sensitive resources.
  • Apply any patches or updates provided by SAP that address CVE-2025-31324.
