Description

  • A CNAME record defines an alias for an A record

Environment

  • F5® Distributed Cloud Primary DNS 

Working with CNAME records

  • A CNAME record cannot be created for the zone apex (e.g., example.com) because this would break the zone (other services than HTTP need to query the zone apex).
  • You can however create a CNAME for a more specific domain to the zone apex.  You may for instance want to do this if you wanted all web traffic to drop the www, and just be accessible by https://example.com.
  • If the IP address of the host www.example.com changes, rather than updating two records, only the destination of the alias needs to be updated. 

When using CNAME records, ensure to take note of the following restrictions: 

  • A CNAME record name must be unique within a zone. It is not possible to use the name of 'www' with a CNAME record and another record type. 
  • A CNAME record can not point to an IP address
    • it must point to a valid domain name (e.g., www, staging, www.example.com).
