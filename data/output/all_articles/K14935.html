Known Issue

Creating, modifying, or deleting an iApp Application Service resets BIG-IP GTM global settings to default values.

This issue occurs when all of the following conditions are met:

  • The BIG-IP GTM system is a member of a sync group.
  • You have configured the BIG-IP GTM global settings with non-default values.
  • You have created, modified, or deleted an iApp Application Service.

Impact

The system resets BIG-IP GTM global settings to default values.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H442964 on the Diagnostics > Identified > Medium screen.
  • After you create, modify, or delete an iApp Application Service, the system resets to default values, any BIG-IP GTM global settings that you had configured to non-default values.

Workaround

There is no workaround for this issue. To recover from this issue, after you create, modify, or delete an iApp Application Service, you must reconfigure the affected BIG-IP GTM global settings to the values you want.
