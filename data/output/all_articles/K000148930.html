Description

When loading configuration to BIG-IP as part of a ucs installation, configuration fails to load with error "01071c51:3: TMOS Routing feature not enabled."

Environment

  • BIG-IP loading ucs file containing TMOS routing (not Zebos)  configuration.

Cause

TMOS routing configuration can only be loaded when sys db  tmrouted.tmos.routing is "enabled"

Answer/Recommended Actions

Enable sys db  tmrouted.tmos.routing before starting the ucs load.
 
tmsh modify sys db tmrouted.tmos.routing value enable
tmsh save sys config
