Known Issue

The secure network address translation (SNAT) automap source IP address translation to an origin server uses the non-floating self IP address for the BIG-IP ASM-enabled virtual server, or WebAccelerator-enabled virtual server. However, the SNAT automap source IP address translation to an origin server for a non-BIG-IP ASM-enabled virtual server or a non-WebAccelerator-enabled virtual server will use the floating self IP address.

Using different source IP addresses for BIG-IP ASM-enabled virtual servers or WebAccelerator-enabled virtual servers and, respectively, non-BIG-IP ASM and non-WebAccelerator traffic may cause some client sessions to fail, depending on the application or origin server.

F5 Product Development tracked this issue as ID244402 (formerly CR73433) and it was fixed in BIG-IP 9.3.0 and 9.4.1. For information about upgrading, refer to the BIG-IP ASM and WebAccelerator release notes.
