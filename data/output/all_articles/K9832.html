Known Issue

This is the result of a known issue. The BIG-IP may prematurely terminate the client-side connection by sending RST packets to both the client-side and server-side connections when the following sequence of events occurs:

  • A series of HTTP clients send requests that cannot have future requests.

    For example, HTTP/1.0 requests without Connection: Keep-Alive headers, or HTTP/1.1 requests with Connection: close headers cannot have future requests.
  • The requests are sent to a virtual server configured with a FastHTTP profile
  • The server sends multipacket responses
  • The server completes several requests on the same server-side connection

Likewise, the BIG-IP may prematurely terminate the server-side connection by sending RST packets to both the client-side and server-side connections when the following sequence of events occurs:

  • An HTTP/1.1 client makes a keep-alive connection to the virtual server
  • Several back-to-back requests are closed by the server

F5 Product Development tracked this issue as CR113258 and it was fixed in BIG-IP versions 9.4.8 and 10.0.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1, which has been issued for BIG-IP version 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.

Workaround

You can work around this issue by configuring a protocol profile other than FastHTTP on the virtual server.

In the case where the client is sending HTTP/1.1 requests with Connection: close headers, you can also work around this issue by performing the following procedure:

  1. Log in to the command line.
  2. To enable the http11 close workarounds profile option for the FastHTTP profile, type the following command:

    bigpipe profile fasthttp <profilename> http11 close workarounds enable
  3. To save the running configuration to disk, type the following command:

    bigpipe save all
