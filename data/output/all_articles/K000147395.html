K000147395: Does F5® Distributed Cloud DNS support ALIAS records on the Secondary DNS?

Type

Published

Updated

Applies to

  • F5 Distributed Cloud DNS Management
Source

Description

This article addresses whether ALIAS records are supported on Secondary DNS in F5 Distributed Cloud DNS.
Users may want to create ALIAS records on Secondary DNS for various DNS management scenarios and need to know if this is possible.

Environment

  • F5® Distributed Cloud DNS

Cause

ALIAS records are not standard DNS records and are not supported on Secondary DNS in F5 Distributed Cloud.

Answer/Recommended Actions

No, F5 Distributed Cloud DNS does not support ALIAS records on Secondary DNS as they are not standard DNS records.

Additional Information

If you plan to do zone transfers, you must verify if your DNS provider allows it.

  • Azure does not support zone transfers (Azure DNS FAQ)
  • AWS also does not support zone transfers (AWS Route53 zone transfers)
