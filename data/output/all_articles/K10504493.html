Known Issue

Modifying a monitor configuration stops health checks for fully-qualified domain name (FQDN) nodes.

This issue occurs when all of the following conditions are met:

  • Your system has a pool configuration that uses the FQDN nodes feature.
  • A health monitor is applied to the pool.
  • You modify the health monitor's configuration. For example, you modify the send string for an HTTP monitor.

Impact

The BIG-IP system fails to perform health checks for FQDN nodes, and connections may be sent to unavailable pool members.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you modify a health monitor, the pool member health status for FQDN nodes does not change.
  • Traffic fails intermittently.

Workaround

To work around this issue, you can restart the bigd process after modifying the health monitor's configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will interrupt health checking for all pool members. F5 recommends performing this procedure during a planned maintenance window.

  1. Log in to the command line of the BIG-IP system.
  2. To restart the bigd process, type the following command:

    bigstart restart bigd
