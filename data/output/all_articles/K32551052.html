Description

You are trying to create a virtual server and would like to use an address list instead of a singular IP address on TMSH.

If you are trying to do this with the syntax below:
# tmsh create ltm virtual <virtual> destination <addr_list> 

Following error message is shown:
Syntax Error: A port number or service name is missing for "<addr_list>". Please specify a port number or service name using the syntax "<addr_list>:<port>".

Environment

BIG-IP LTM 14.x and later

Cause

Address lists are actually linked to a Virtual Server via a 'traffic-matching-criteria' object


Recommended Actions

To create a virtual server with an address list using TMSH:

1. You have to first create an address-list
#create net address-list <address_list_name> addresses add { }

For example:
#create net address-list addr_list_test addresses add { 10.1.1.1 10.1.1.2/32 10.1.1.3/24 10.1.2.3/25 }

2. Then a traffic-matching-criteria - which creates an object of your address list
#create ltm traffic-matching-criteria <TMC_name> destination-address-list <address_list_name>

For example:
#create ltm traffic-matching-criteria traffic_matching_criteria_test destination-address-list addr_list_test

3. Then create the virtual server without a destination but instead specifying the traffic-matching-criteria
#create ltm virtual <Virtual_Server_name> traffic-matching-criteria <TMC_name>

For example:
#create ltm virtual virtual_test traffic-matching-criteria traffic_matching_criteria_test


Additional Information

This can be also done for a source address list or a port list as long as the List and the Traffic-matching-criteria is created first.
