Topic

By navigating to the Customize Package tab on the Device Management: Client Downloads: Windows (x86) page, you can create a package that gives users access to the specific FirePass controller client components that you want them to use.

For more information, refer to the following list of FirePass controller client components:

Base Controls

By selecting this component, ActiveX is downloaded automatically when required, if it is not already installed.

Network Access

The component for Network Access.

Application Tunnels

F5 Networks SSL Tunnel implementation used by VPN and Application connectors.

Terminal Clients

This component provides controls for the following clients:

  • Microsoft RDP
  • VNC servers
  • 5250 servers

Endpoint Security

F5 Networks endpoint security components.

Note: To use these controls, you must also configure an endpoint security policy on the Users: Endpoint Security page.

  • Protected Workspace
  • Win32 Inspector
  • OPSWAT Integration Libraries
  • Machine Certificate Checker
  • Cache Cleaner: Post logon actions
  • Windows Group Policy

Component Installer

After you install this package on the client, the service installs and updates FirePass controller client components on clients without requiring administrative rights.

Note: To install the Component Windows Installer service, you must have administrative rights.

Windows Logon Integration
 
This component installs and updates components for a virtual dial-up entry.

Note: For more information about the Windows Logon settings, refer to the online help.

FirePass Windows Client

This component is a Windows program that allows a user to initiate and use FirePass controller Network Access, App Tunnel, and Terminal Services sessions outside using a browser.

Note: For more information about the FirePass Windows Client component, refer to the online help.

Important: The FirePass Windows Client component must be installed with the Windows Logon Integration and DNS Replay Proxy components to successfully install on the client machine. If the other two components are not selected, the installation process will fail.

FirePass Client COM API

The COM API component is an ActiveX control providing an interface and methods for use by third-party applications.

Note: For more information about the FirePass Windows COM API component, refer to the online help.

DNS Relay Proxy
 
This component is a system service to support DNS hostname resolution for static App Tunnels and Network Access connections without use of the system hosts file. If the DNS Relay Proxy service is not installed, FirePass client components may attempt to modify the system hosts file, which requires administrative rights.
