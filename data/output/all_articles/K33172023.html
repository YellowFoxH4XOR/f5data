K33172023: Zone runner records are missing on dns express dump (dnsxdump)

Type
Support Solution
Published
2024-10-29
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K33172023

Description

Newly created zone runner records are missing on dns express dump (dnsxdump)

Environment

  • Local Bind
  • DNS Express
  • DNS express configured to pull zones from BIGIP's Local BIND

Cause

Records created under BIGIP's Local Bind using Zone Runner don't appear on DNS Express dnsxdump immediately.
Zone transfer doesn't happen between DNS Express and Local Bind right after the new records were created.

 

Recommended Actions

New entries would appear only after a successful zone transfer from the Local Bind. 

DNS Express reflects the newly created zone entries on dnsxdump immediately under the following conditions:

  1. BIG-IP's local bind is configured to allow zone transfers 
        DNS  ››  Zones : ZoneRunner: named Configuration

       allow-transfer {
        localhost;
        };

      2. BIG-IP's local bind is configured to notify the changes to DNS Express

      DNS  ››  Zones : ZoneRunner: named Configuration
  
       also-notify { 
        ::1 port 5353; 
       };

Note: If you prefer, you can configure the also-notify statement on a per-zone or per-view basis.
This can be done under DNS  ››  Zones : ZoneRunner: Zone List  ››  Properties: <zone-name>
