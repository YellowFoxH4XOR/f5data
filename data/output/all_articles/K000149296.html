Description

Unable to use iApp template to host certain applications. Error : The requested folder (/Common/test.example.com.app) already exists.

Environment

  • BIG-IP LTM
  • iApps
  • Virtual server

Cause

Some orphan folders/objects persisted in bigip_base.conf

Recommended Actions

Delete the existing folder using the below commands :

tmsh delete sys application service test.example.com.app

tmsh delete sys folder /Common/test.example.com.app recursive

Additional Information

Check in the bigip_base.conf file if the application is already present

OR run the below commands to check if the application name already exists :

  1. tmsh list ltm virtual one-line | grep test.example.com
  2. tmsh list ltm pool one-line | grep test.example.com
