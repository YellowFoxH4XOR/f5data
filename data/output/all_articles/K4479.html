Known Issue

This is the result of a known issue. The prTable values displayed after performing an SNMP query of a BIG-IP system are invalid.

The following prNames values do not indicate the full path of the process:

  • prNames.1 = STRING: bigd
  • prNames.2 = STRING: bigdbd
  • prNames.3 = STRING: chmand
  • prNames.4 = STRING: httpd
  • prNames.5 = STRING: mcpd
  • prNames.6 = STRING: sod
  • prNames.7 = STRING: tmm

The following prCount values incorrectly indicate that the processes are not running:

  • prCount.1 = INTEGER: 0
  • prCount.2 = INTEGER: 0
  • prCount.3 = INTEGER: 0
  • prCount.4 = INTEGER: 0
  • prCount.5 = INTEGER: 0
  • prCount.6 = INTEGER: 0
  • prCount.7 = INTEGER: 0

The following prErrMessage values incorrectly indicate that the processes are not running:

  • prErrMessage.1 = STRING: Too few bigd running (# = 0)
  • prErrMessage.2 = STRING: Too few bigdbd running (# = 0)
  • prErrMessage.3 = STRING: Too few chmand running (# = 0)
  • prErrMessage.4 = STRING: Too few httpd running (# = 0)
  • prErrMessage.5 = STRING: Too few mcpd running (# = 0)
  • prErrMessage.6 = STRING: Too few sod running (# = 0)
  • prErrMessage.7 = STRING: Too few tmm running (# = 0)

F5 Networks Product Development tracked this issue as CR46305, and it was fixed in BIG-IP LTM version 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If you are unable to upgrade at this time, you can work around this issue by editing the /config/snmp/snmpd.conf file from the BIG-IP command line. To do so, perform the following procedure:

  1. Backup the /config/snmp/snmpd.conf file by typing the following two commands:

    cp /config/snmp/snmpd.conf
    /config/snmp/snmpd.conf.original

  2. Using a text editor, edit the /config/snmp/snmpd.conf file, using information in the following table:

    Change these lines:

    proc    bigd       1 1proc    bigdbd     1 1proc    chmand     1 1proc    httpd      1 1proc    mcpd       1 1proc    sod        1 1proc    tmm        1 1

    To these lines:

    proc    /usr/bin/bigd     2 1proc    /usr/bin/bigdbd   2 1proc    /bin/chmand       2 1proc    /usr/sbin/httpd   infinity 1proc    /bin/mcpd         2 1proc    /usr/bin/sod      2 1proc    /bin/tmm          2 1

    The proc lines will now include the full path to the process and the proper maximum and minimum values.

  3. Save the /config/snmp/snmpd.conf file and exit the editor.
  4. Restart snmpd by typing the following command:

    bigstart restart snmpd
