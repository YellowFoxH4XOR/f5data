To mount approximately 100MB of memory, as if it were an actual disk drive, type the following command:

mount_mfs -s 200000 /mnt

The -s parameter specifies the size of the memory file system in blocks. Two blocks are equal to approximately 1K; therefore, 200,000 blocks are equal to approximately 100,000KB or 100MB.

To unmount the memory file system, type the following command:

Important: All of the information that is contained in this directory will be lost when you unmount the file system or reboot the controller.

umount /mnt
