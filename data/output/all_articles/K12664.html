Known Issue

This is the result of a known issue. The BIG-IP Edge Client for Mac and Linux users repeats the word Throughput on the Inbound and Outbound client graph labels; the word should appear only once.

The label appears as follows:

Throughput: Throughput

You can safely ignore this issue.

F5 Product Development tracked this issue as ID 348968 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in cumulative hotfix HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software from F5.
