Description

You may face the following symptom.

  • You want to use BIG-IP monitors to detect the backend server status.

  • The backend server uses NTLM authentication for users with HTTP or HTTPS protocol.

  • The LTM HTTP/HTTPS monitor is fine when using username and password authentication to detect the backend server status.

  • The DNS HTTP/HTTPS monitor fails when using username and password authentication to detect the backend server status.

Environment

  • NTLM authentication

  • HTTP/HTTPS monitor

  • DNS big3d

Cause

This is expected behavior, LTM and DNS use different processes to monitor backend server status, currently, DNS's big3d process does not support HTTP/HTTPS monitor using NTLM authentication for the backend server.

 Recommended Actions

Please avoid using DNS HTTP/HTTPS monitor with NTLM authentication, and consider using basic authentication or other types of DNS monitors.
