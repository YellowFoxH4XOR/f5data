Issue

The BIG-IP Advanced WAF / ASM system checks that the request contains a parameter whose value length (in bytes) matches the value length defined in the security policy. Attackers may exploit a parameter by sending a long parameter value which the web application was not expecting to handle. This kind of attack may result in the application experiencing various forms of buffer overflow and denial of service.

When the system processes a request for a parameter that exceeds the Maximum Length setting, the following error message will be logged to the /var/log/asm log file, and to the Reporting screen:

Illegal parameter value length

Note: BIG-IP ASM does not convert multi-bytes characters for the purpose of checking the parameter length. Therefore, selecting the Maximum Length setting for a security policy that supports a multi-byte character set may result in the error message.
