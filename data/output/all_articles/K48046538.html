Description

You may see "-nan" when you run tmsh show sys performance throughput.

For example:

# tmsh show sys performance throughput

Sys::Performance Throughput
-----------------------------------------------------------------------------
Throughput(bits)(bits/sec)     Current  Average  Max(since 01/25/21 10:54:50)
-----------------------------------------------------------------------------
Service                           -nan     -nan                          -nan
In                                -nan     -nan                          -nan
Out                               -nan     -nan                          -nan

-----------------------------------------------------------------------------
SSL Transactions               Current  Average  Max(since 01/25/21 10:54:50)
-----------------------------------------------------------------------------
SSL TPS                           -nan     -nan                          -nan

-----------------------------------------------------------------------------
Throughput(packets)(pkts/sec)  Current  Average  Max(since 01/25/21 10:54:50)
-----------------------------------------------------------------------------
Service                           -nan     -nan                          -nan
In                                -nan     -nan                          -nan
Out                               -nan     -nan                          -nan

Environment

  • BIG-IP
  • Running "tmsh show sys performance throughput"
  • Manually changing the date and time
  • /var/rrd/throughput file shows incorrect date and time
For example:
[root@test:Active:Disconnected] config # date; ls -la /var/rrd/throughput*
Thu Apr 8 09:52:38 JST 2021
-rw-r--r--. 1 root root 3686368 2035-11-28 14:05 /var/rrd/throughput <-----!!!
-rw-r--r--. 1 root root 4469 2020-02-06 16:05 /var/rrd/throughput.info
[root@test:Active:Disconnected] config #

Cause

It is due to manual time change. 
The greater the time variance change, the greater probability the rrd performance graph information accuracy is affected.

Recommended Actions

  1. Follow K11461022 to clear RRD data files
  2. Reboot the device

Additional Information

None.
