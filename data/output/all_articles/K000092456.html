K000092456: Portal access does not load all the content

Type
Support Solution
Published
2022-10-14
Updated
2022-10-28
Source
https://my.f5.com/manage/s/article/K000092456

Description

  • You have configured a portal access and when users access the portal, they do not see all of the configured portal objects.
  • In the logs, you see an error similar to the below one

01490504:5: /Common/<Policy Name>:Common:xxxxxx: <DNS hostname > can not be resolved.

Environment

  • BIG-IP APM
  • Portal Access
  • DNS

Cause

  DNS is not able to resolve one or more records involved in the portal access configuration.

 

 Recommended Actions

  Please check your DNS configuration and make sure it can resolve all the records.
