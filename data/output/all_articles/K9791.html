Known Issue

This is the result of a known issue. If you configure a master group to use Active Directory authentication and select the Warn user of password expiration check box, a user in that master group may receive a system warning on the webtop even if the Password never expires option is enabled in the user’s Active Directory account. When the user selects the system warning, a message that appears similar to the following example is displayed where X is the number of days in which the password would expire if the Password never expires option was not enabled:

Active Directory password policy

Your password will expire in <X> days.

The correct behavior is for FirePass to ignore the password expiration information received from the Active Directory server when the Password never expires option is also enabled.

Note: The password expiration warning is a new feature introduced in FirePass version 6.0.3. For more information, refer to K9790: Change in Behavior: FirePass now warns users when their Active Directory password is set to expire.

F5 Product Development is tracking this issue as ID 296273 (formerly CR115843).
