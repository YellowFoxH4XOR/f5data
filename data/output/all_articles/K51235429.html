Topic

When the BIG-IP Edge Client logs out of a session with the BIG-IP APM system, the BIG-IP APM system logs a message that provides a hang up error code, which identifies the reason for the disconnection.

Description

When a BIG-IP Edge Client session logs out, the BIG-IP Edge Client sends the BIG-IP APM system an HTTP request with a hang up error code in a query parameter. For example, when a user puts their client system to sleep after establishing a session with the BIG-IP APM system, the BIG-IP Edge Client sends the following request:

GET /vdesk/hangup.php3?hangup_error=4097 HTTP/1.1

Upon receiving the request, the BIG-IP APM system logs a message with the error code to the /var/log/apm file in the following format:

Session deleted (<category>; code - <error_code>).

In this error message, note the following:

  • <category> is the type of hang up code.
  • <error_code> is the hang up error code.
