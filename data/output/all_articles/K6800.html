Issue

F5 Product Development has never supported using the management interface for state mirroring functions. However, it is possible to configure the primary and secondary mirror addresses to use the management IP address in BIG-IP 9.1.1 and earlier, and in version 9.3.x.

In BIG-IP 9.1.2, 9.2.x, 9.4.x, and 10.x, it is no longer possible to configure the primary and secondary mirror addresses to use the management IP address.

F5 Product Development tracked this change as CR56968 and CR51503 and it was introduced in BIG-IP 9.1.1 and 9.2.0. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller release notes.

Note: For more information, refer to K7718: The BIG-IP prohibits configuring the mirroring IP address on the same network as the management port and K11736: Defining network resources for BIG-IP high availability features.
