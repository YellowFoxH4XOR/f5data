Description

Variables will not be substituted in a curly-brace delimited string in TCL.

Environment

  • BIG-IP
  • iCall script or iRule

Cause

The TCL interpreter treats the contents of a curly-brace delimited string as a literal string. This means that variable substitution (${variable}) does not occur.

So in an iCall script like

set action={down}
tmsh::modify gtm pool a testpool { members modify { genericserver0:vs0 { ${action} }}}

${action} is not substituted in the curly-brace delimited string with contents starting with members modify.

Recommended Actions

Use a double-quote delimited string where TCL variable substitution will be performed:

% set action test
test
% puts {a brace-delimited string ${action}}
a brace-delimited string ${action}

 

% puts "a double-quote-delimited string ${action}"
a double-quote-delimited string test
% puts "a double-quote-delimited { string ${action}}"
a double-quote-delimited { string test}
