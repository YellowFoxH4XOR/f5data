Known Issue

Due to a limitation of the ARX system ARP table, clients may not be able to connect to the ARX VIP.

This issue occurs when the following condition is met:

  • The platform is an ARX 1500, 2500, or Virtual Edition.

Once 1024 ARP entries have been reached, the ARX system rejects any new connections until entries have been reaped from the ARP table.   To prevent reaching 1024 ARP entries, the ARX system begins to aggressively reap ARP table entries when it exceeds 512 entries.

Impact

Clients will not be able to connect to the ARX system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Clients may not be able to connect to the ARX VIP.
  • You encounter the following error message: "localhost Neighbour table overflow " in the kernel.log.

Note: The Kernel.log log file is included in an ARX system diagnostic information file. The kernel.log log file is located in the /acopia/var/log directory of the diagnostic information file. For information about creating an ARX system diagnostic information file, refer to K8294: Providing an ARX diagnostic information file to F5 Technical Support.

  • The CLI PING command fails with the error message: "connect: No Buffer Space Available."
