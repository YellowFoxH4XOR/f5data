Gateway failsafe

The gateway failsafe feature enables BIG-IP to fail over to a redundant BIG-IP if connectivity to a specified network device (such as router) is lost. This is useful when the BIG-IPs in a redundant pair are connected to different routers, because it provides the ability to switch to a functional path if the connected router becomes unreachable.

Gateway failsafe is triggered when BIG-IP sends an Internet Control Message Protocol (ICMP) Echo Request (ping) to a specified IP address and does not receive an ICMP Echo Reply within a configured period of time (the gateway fail-safe timeout). When this occurs, BIG-IP switches to standby mode.

Note: For information about using gateway failsafe for BIG-IP version 4.x, refer to the BIG-IP Reference Guide.

Note: For more information about using gateway failsafe in BIG-IP version 9.x and higher, refer to the the BIG-IP Network and System Management Guide or K5308: Configuring gateway failsafe from the command line.

Interface/VLAN fail-safe

The interface/VLAN failsafe feature reboots BIG-IP in order to re-initialize unresponsive hardware or drivers and to signal connected LAN switches to clear L2 forwarding tables due to the loss of link signal during reboot.

Interface/VLAN failsafe feature allows BIG-IP to fail over to a redundant BIG-IP if one or more of the following situations occur:

  • BIG-IP is disconnected from the vital network link.
  • The connected network device stops transmitting data.
  • The BIG-IP network interface becomes inoperable.

Interface/VLAN failsafe is triggered when BIG-IP does not receive traffic for a configurable amount of time (half of the configured fail-safe timeout). When this occurs, BIG-IP broadcasts an Address Resolution Protocol (ARP) request for all of the addresses currently present in its ARP cache in order to solicit replies and waits to receive any traffic on the interface. If no reply is received before the failsafe timeout expires, BIG-IP switches to standby mode and reboots.

Note that failover will not occur as long as the BIG-IP is able to detect any traffic on the interface, although it may not be able to send any data itself (for example, due to a disconnected optical link transmit fiber, which is a condition that would be detected by a connected switch or router).

Note: For information about using interface/VLAN failsafe in BIG-IP version 4.x, refer to the BIG-IP Reference Guide.

Note: For information about using VLAN failsafe in BIG-IP version 9.x and higher, refer to K7066: Overview of VLAN failsafe.
