Known Issue

The BIG-IP Configuration utility may erroneously apply a search filter on the Virtual Address List page.

This issue occurs when all of the following conditions are met:

  • You specify a search criteria in the BIG-IP Configuration utility search field to look for BIG-IP objects. For example, you specify an IP address on the Local Traffic > Nodes > Node List page, to look for the corresponding node or specify an access policy name on the Access Policy > Access Profiles > Access Profile List page to look for a specific access policy profile.
  • You navigate to the Configuration utility > Virtual Servers > Virtual Address List page without clearing the search filter.
The search field that allows user input and displays the search criteria does not exist on the Virtual Address List page for the software versions listed in the Applies To box. Therefore, users may not be aware that an existing search filter from another BIG-IP object (for example, Node List) is erroneously applied to the page.

Impact

The BIG-IP Configuration utility erroneously applies the search filter on the Node List page or the Access Profile List page to the Virtual Address List. As a result, the Virtual Address List page may not display a complete list of virtual addresses.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Virtual Address List page does not have a search field. When you navigate to the Virtual Address List page, the BIG-IP Configuration utility may show only virtual addresses that match the search criteria that you specified on the Node List page or the Access Profile List page. If no match exists, the BIG-IP Configuration utility displays a message indicating that there are no records to display.

Workaround

To work around this issue, you can remove the filter on the Nodes List page or the Access Profile List page by clicking Reset Search, before navigating to the Virtual Address List page.

Impact of workaround: Performing the suggested procedure should not have a negative impact on your system.
