Description

The BIG-IP DNS, bigip health monitor is not bringing up virtual servers with a wildcard service port 'port 0' configured, and the following error message is observed.

 no reply from big3d: timed out

Environment

  • BIG-IP DNS
  • bigip health monitor
  • Virtual server with wildcard port 'port 0'

Cause

big3d sends the IP:Port specification to mcpd, and if it's a 0 port, mcpd will only match if the virtual server on the LTM has a 0 port in it's destination. If there is no 0 port in the LTM destination field, mcpd doesn't reply, big3d doesn't reply, and you get GTM virtual server down with big3d timed out.

Recommended Actions

  1. Make sure to define the correct port when creating virtual servers on BIG-IP DNS, and do not use port 0, unless the LTM virtual server is also configured with port 0.
