Topic

You should consider using this procedure when you want to do the following:

  • View a list of F5OS-C images on the VELOS system
  • Import or upload an F5OS-C image to the VELOS system
  • Remove an existing F5OS-C image from the VELOS system

Description

The F5OS-C software runs on the VELOS system and is available as separate ISO images for the system controller and chassis partition software as well as a single package that comprises both ISO images. For more information about the different F5OS software images, refer to K03278510: F5OS-A and F5OS-C software for F5 hardware platforms.

When you import or upload an image to the VELOS system, the image is stored in the built-in image server on the VELOS system controllers. This image server serves as the PXE server whenever you update or upgrade a system controller or a blade using PXE boot. The imported or uploaded images are typically stored in the following relative directories:

  • images/staging/ (actual directory on the Linux host: /var/import/staging/)
  • images/import/iso/ (actual directory on the Linux host: /var/export/chassis/import/iso/)

Prerequisites

You must meet the following prerequisites to use this procedure:

  • If you are using the webUI or REST API procedures, you have chassis administrative access to the F5OS-C webUI.
  • If you are using the command-line interface (CLI) procedures, you have chassis admin user access to the F5OS-C CLI.

Procedures

  • View the existing F5OS-C images on the VELOS system
  • Import or upload an F5OS-C image on the VELOS system
  • Remove an existing F5OS-C image from the VELOS system

View the existing F5OS-C images on the VELOS system

You can view the F5OS-C images that are imported or uploaded on the VELOS system using the webUI, the CLI, or the REST API. To do so, perform any of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use the CLI
  • Use the REST API

Use the webUI

  1. Log in to the webUI of the VELOS chassis as the chassis administrator.
  2. Select SOFTWARE MANAGEMENT. The webUI displays two sub-lists: Partition Images and Controller Images.
  3. To view the list of controller images available on the VELOS system, select Controller Images. To view the list of partition images available on the VELOS system, select Partition Images. The webUI displays the list of existing controller and partition images on the VELOS system.

Use the CLI

  1. Log in to the CLI of the VELOS chassis as the chassis admin user.
  2. Display the list of controller images available on the system by entering the following command:

    show image controller state controllers controller iso

Use the REST API

  1. Log in to a remote system with the curl utility installed.
  2. Display the list of controller and partition images available on the system using the following command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/f5-system-image:image/<controller|partition>/state/controllers/controller=<ID>/iso"

    In the previous syntax, note the following:

    • Replace <username> and <password> with the chassis administrative username and password to access the VELOS chassis.
    • If you are running the command from the chassis CLI, replace <ip address> with localhost.
    • If you are not running the command from the chassis CLI, replace <ip address> with the floating management IP address of the VELOS chassis.
    • Replace <controller|partition> with either controller or partition depending on the image type you want to view. For example, you would replace with controller if you want to view controller images only.
    • Replace <ID> with the currently active system controller ID.

    For example, enter the following command to view controller images only:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.83.35/api/data/f5-system-image:image/controller/state/controllers/controller=2/iso"

Import or upload a F5OS-C image on the VELOS system

You can either import or upload a F5OS-C image to the VELOS system.

To import, you need to first download the F5OS-C image file to a remote HTTPS server that supports PUT/POST requests with a valid CA signed SSL certificate. You then import to the VELOS system by providing the URL for the image file hosted on your remote HTTPS server to the VELOS system. For information on how to import, refer to the Download and Import Software chapter of the VELOS Systems: Software Installation and Upgrade manual.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

To upload, you need to first download the F5OS-C image file to your local workstation that has administrative access to the floating management IP address of the VELOS system. You then log in to the preferred interface (webUI, CLI) before uploading the image file to the VELOS system. To do so, perform any of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use REST API
  • Use SCP (F5OS-C 1.8.0 and later)

Using the webUI

  1. Prior to uploading, you must first download the F5OS-C image file from MyF5 Downloads page to your local workstation. You can locate the F5OS-C image files by selecting the F5OS group and then F5OS Platform Software for VELOS product line on the MyF5 Downloads page. For information about downloading software from MyF5 Downloads page, refer to K167: Downloading software and firmware from F5. Proceed to the next step after you have completed the download of the image file(s) you need.

    Note: If your VELOS system is running F5OS-C 1.1.3 or earlier, you must first upgrade to F5OS-C 1.1.4 before you can upgrade your VELOS system to F5OS-C 1.2.1 or later.

  2. Log in to the webUI of the VELOS chassis as the chassis administrator.
  3. Select SOFTWARE MANAGEMENT. The webUI displays two sub-lists items: Partition Images and Controller Images.
  4. To upload a controller image, select Controller Images followed by Upload. To upload a partition image, select Partition Images followed by Upload. The webUI then prompts you for the controller or partition image.
  5. Locate the controller or partition image you have downloaded to your local workstation and select Open. The webUI displays the status of the uploading process under the Image Transfer Status (F5OS 2.0.0 and later) or the Image Import Status (prior to F5OS 2.0.0) section on the System Controller Images page or the Chassis Partition Images page; monitor the progress of the upload till completion.

Use REST API

  1. Prior to uploading, you must first download the F5OS-C image file from MyF5 Downloads page to your local workstation. You can locate the F5OS-C image files by selecting the F5OS group and then F5OS Platform Software for VELOS product line on the MyF5 Downloads page. For information about downloading software from MyF5 Downloads page, refer to K167: Downloading software and firmware from F5. Proceed to the next step after you have completed the download of the image file(s) you need.

    Note: If your VELOS system is running F5OS-C 1.1.3 or earlier, you must first upgrade to F5OS-C 1.1.4 before you can upgrade your VELOS system to F5OS-C 1.2.1 or later.

  2. Use the curl utility from your local workstation to upload the image file to the images/staging/ directory on the VELOS chassis as the chassis admin user by performing the procedure described in K000139146: Upload a file to the VELOS or rSeries system using REST API.
  3. After the upload of the image file to the VELOS system completes, you can verify if the VELOS system accepted the image file using the previous procedure View the existing F5OS-C images on the VELOS system.

Use SCP (F5OS-C 1.8.0 and later)

  1. Prior to uploading, you must first download the F5OS-C image file from MyF5 Downloads page to your local workstation. You can locate the F5OS-C image files by selecting the F5OS group and then F5OS Platform Software for VELOS product line on the MyF5 Downloads page. For information about downloading software from MyF5 Downloads page, refer to K167: Downloading software and firmware from F5. Proceed to the next step after you have completed the download of the image file(s) you need.
  2. Beginning F5OS-C 1.8.0, you can use the secure copy (SCP) utility to upload the F5OS-C image file to the images/staging/ directory on the VELOS chassis as the chassis admin user. Locate the F5OS-C image file downloaded to your local workstation and enter the following command in the CLI of your local workstation:

    scp -O <path/to/image/file/on/local/workstation> admin@<chassis management IP address>:images/staging/

    For example,

    scp -O /var/tmp/F5OS-C-1.8.0-19782.CONTROLLER.LTS.iso admin@192.168.78.45:images/staging/

  3. After the upload of the image file to the VELOS system completes, you can verify if the VELOS system accepted the image file using the previous procedure View the existing F5OS-C images on the VELOS system.

Remove an existing F5OS-C image from the VELOS system

You can remove F5OS-C images that are no longer used to free up disk space for future software installations. To do so, perform any one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use the REST API
  • Use the CLI

Use the webUI

  1. Log in to the webUI of the VELOS chassis as the chassis administrator.
  2. Select SOFTWARE MANAGEMENT. The webUI displays two sub-list items: Partition Images and Controller Images.
  3. To remove an existing controller image from the VELOS system, select Controller Images. To remove an existing partition image from the VELOS system, select Partition Images. The webUI displays the list of existing controller and partition images on the VELOS system.
  4. Check the controller or partition image you want to remove and select Delete. Select OK to confirm the image deletion.

Use the REST API

  1. Log in to a remote system with the curl utility installed.
  2. Remove an existing controller/partition image from the VELOS system using the following command syntax:

    curl -X POST -H "Content-Type: application/yang-data+json" -sku <username>:<password> “http://<ip address>/api/data/f5-system-image:image/<controller|partition>/remove" -d '{ "f5-system-image:iso": "<image version number-build number>”}’

    In the previous syntax, note the following:

    • Replace <username> and <password> with the chassis administrative username and password to access the VELOS chassis.
    • If you are running the command from the chassis CLI, replace <ip address> with localhost. If you are not running the command from the chassis CLI, replace <ip address> with the floating management IP address of the VELOS chassis.
    • Replace <controller|partition> with either controller or partition depending on the image type you want to remove. For example, if you want to remove a controller image, replace it with controller.
    • Replace the <image version number-build number> with the one you want to remove.

    For example, if you want to remove F5OS-C 1.6.2-22734 controller image from the VELOS chassis, enter the following command:

    curl -X POST -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.83.35/api/data/f5-system-image:image/controller/remove" -d '{ "f5-system-image:iso": "1.6.2-22734"}'

    The command output appears similar to the following example if the system removes the image successfully:

    {
      "f5-system-image:output": {
        "response": "Success: Image 1.6.2-22734 is removed"
      }
    }

Use the CLI

  1. Log in to the CLI of the VELOS chassis as the chassis admin user.
  2. Enter the configuration mode terminal by entering the following command:

    config

  3. Remove an existing controller/partition image from the VELOS system using the following command syntax:

    image [controller|partition] remove iso <image name>

    For example, if you want to remove F5OS-C 1.6.2-22734 controller image from the VELOS chassis, enter the following command:

    image controller remove iso 1.6.2-22734

    The command output appears similar to the following example if the system removes the image successfully:

    Success: Image 1.6.2-22734 is removed
