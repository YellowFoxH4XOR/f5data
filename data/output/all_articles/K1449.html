K1449: Using SSL persistence with an SSL proxy

Topic

You cannot use SSL persistence on a pool that services the target VIP of an SSL Proxy, because the traffic is no longer in SSL when it reaches the pool.

SSL persistence uses the SSL session ID negotiated between the client and server to maintain persistence. When using an SSL Proxy, the traffic is decrypted (from HTTPS to HTTP); therefore, the pool that is used by the target VIP sees the traffic as HTTP, and there is no SSL session ID to persist on.

If you need to use persistence on the pool of the target VIP, use another persistence method such as cookie persistence or simple persistence.

For information about the persistence modes in BIG-IP, refer to the BIG-IP manuals.
