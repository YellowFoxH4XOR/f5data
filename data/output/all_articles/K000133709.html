Description

This article describes how to configure BIG-IP to collect full URLs (with hostnames) to AVR statistics.
 

Environment

  • BIG-IP
  • software version which includes fix for bug ID499315

Cause

There is a global setting for AVR that can be changed to collect full URLs (including the host name).

By default it is disabled.

(/Common)(tmos)# list sys db avr.includeserverinuri
sys db avr.includeserverinuri {
    value "disable"
}
 

Recommended actions

To get the full URL, you can change the value for the variable mentioned above by running the following command: 


tmsh modify sys db avr.includeserverinuri value enable

After the change, it shows:

(/Common)(tmos)# list sys db avr.includeserverinuri
sys db avr.includeserverinuri {
    value "enable"
}
