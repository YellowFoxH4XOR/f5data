Starting in versions 6.0.2 and 6.1.0 of FirePass software, you can view the maximum number of concurrent sessions on the Device Management: Monitoring: Statistics page in the Max number of concurrent sessions table row. The maximum number of concurrent sessions is the most concurrent sessions that have occurred on the FirePass controller; this number is not reset after performing a reboot.

To view the number of concurrent sessions that your FirePass license supports, navigate to the Device Management: Maintenance: Activate License page and click the Click here to view license details link. Next to Allowed Concurrent Connections is the number of connections (sessions) that your FirePass license supports.

Note: To restrict the number of concurrent sessions for a single user account, navigate to the Device Management: Security: User Access Security page, locate the Concurrent logons section, and select a session limit in the Maximum number of concurrent sessions for the same Username menu. Click the Apply button to apply the change.

Important: Any changes made to the Device Management: Security: User Access Security page will require a services restart before the changes will be active.

F5 Networks Product Development tracked this enhancement as CR67798. For information about upgrading, refer to the FirePass Release Notes.
