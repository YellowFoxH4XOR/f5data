Description

When connecting through the BIG-IP Virtual Server (VS) you get the following error:

 curl: (56) SSL read: error:00000000:lib(0):func(0):reason(0), errno 104

Environment

  • Passing traffic through an BIG-IP Virtual Server (VS)
  • Client SSL or Server SSL profile

Cause

Connection failure either to the BIG-IP Virtual Server or an issue to the pool member. This could be related to an SSL certificate issue or TCP resets although there maybe other causes.
 

Recommended Actions

  1. Troubleshoot network connectivity between the client and the pool member.
  2. Take relevant packet captures to identify the cause of the connection failure.
  3. Refer to the related content below to assist with troubleshooting.
