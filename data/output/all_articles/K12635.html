Topic

FirePass is vulnerable to a denial-of-service (DoS) attack performed by multiple simultaneous crafted HTTP requests created by Slowloris and similar tools. While any web server may be impacted by this type of DoS attack, using a tool such as Slowloris allows the DoS attack to perform with fewer attacker-side resources. Slowloris and similar tools use a technique to hold open connections for a long period of time by sending the request, followed by multiple HTTP request headers. If a Slowloris attack launches against a FirePass device, both clients and administrators may notice a significant increase in the response time from the FirePass controller, or the connection may fail.

Note: To see the current status of all F5 products in regard to Slowloris attacks, refer to K12636: Slowloris denial-of-service attack vulnerability.

F5 Product Development is tracking this issue as ID 319213 (formerly CR127049).

Workaround

You can mitigate this vulnerability by placing either a proxy server or load balancer, such as the BIG-IP LTM, that is configured to handle such attacks in front of the FirePass device. For information about configuring a BIG-IP device to mitigate this vulnerability, refer to K10260: Mitigating Slowloris denial-of-service (DoS) attacks with the BIG-IP system.
