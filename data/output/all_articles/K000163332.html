K000163332: F5OS-A 2.0.0 tenant images fail signature verification

Type
Support Solution
Published
2026-09-17
Updated
2026-09-24
Applies to
  • F5OS Products
  • F5 Distributed Cloud Services
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000163332

Description

BIG-IP tenant-image uploads complete successfully but are marked verification-failed or removed during signature validation.

For instance, the image-agent log reports:

msg="file upload status" info="Upload successful, uploadId deleted".
msg="Failed to verify image signature. Removed." IMAGE="BIGIP-17.5.1.3-0.0.19.ALL-F5OS.tar.bundle" FAILURE="signing authority".

Environment

  • F5OS-A version 2.0.0
  • Tenant image upload showed all attempted tenant images with status verification-failed
  • Image versions included BIG-IP 17.1.3, 17.5.0, 17.5.1.3 and 17.5.1.4

Cause

F5OS rejects the signing authority associated with the affected tenant-image bundle. The available image-agent logs do not identify the specific certificate or signing-chain condition.

Tenant-image signing and compatibility restrictions can also prevent older image bundles from being accepted by F5OS-A 2.0.0, even when file transfer completes successfully.

Answer/Recommended Actions

1. Use a supported BIG-IP tenant image in .tar.bundle format.

Note: zip.bundle format is not supported from version 1.8.0 onward.

2. Use a sufficiently recent, compatible tenant image for F5OS-A 2.0.0. Where applicable, use:

  • BIG-IP 17.1.3.2 or later in the 17.1.x branch
  • BIG-IP 17.5.1.5 or later in the 17.5.x branch

Note: F5 always recommends installing the latest maintenance release version, which contains the latest security patches and fixed bugs.
