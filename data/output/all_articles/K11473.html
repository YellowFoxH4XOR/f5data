Issue

The following error message indicates that the user has supplied an incorrect user name during the authentication process:

Apr 24 17:15:12 local/apm_unit warning apd[4376]: 01490106:4: 85f6d36e: AD module: authentication with '<username>' failed in krb5_get_init_creds_password(): Client not found in Kerberos database, principal name: <username>@<domain>. Please verify Active Directory and DNS configuration. (-1765328378)

If a user reports that they are unable to authenticate, and this error message is in the /var/log/apm file, the user must first confirm they are using the correct user name. If the user is still unable to authenticate, they should contact their Active Directory administrator to resolve the issue.

Possible AD items that may cause the BIG-IP APM system to report this error include the following:

  • The user name is incorrect or incorrectly entered by the user.
  • Use of constrained delegation that has been improperly configured.
  • Use of multiple delegation accounts for the same realm.
  • The AD delegation account is misconfigured.
