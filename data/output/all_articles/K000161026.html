K000161026: BIG-IP VE 17.1.3 Compatibility and Behavior with Microsoft Azure Network Adapter (MANA)

Type
Support Solution
Published

Updated
2026-04-28
Applies to

  • BIG-IP LTM: 17.1.3
Source

Description

In April 2026, Azure will be deploying the Microsoft Azure Network Adapter (MANA) for existing VM Size Families.
https://techcommunity.microsoft.com/blog/azureinfrastructureblog/announcing-microsoft-azure-network-adapter-mana-support-for-existing-vm-skus/4493279
No functional service impact is expected during this Microsoft transition. Temporary performance variability may occur if Accelerated Networking is not available, but service disruption is not expected. Azure automatically manages networking transitions, falling back to the synthetic NetVSC datapath if necessary.

Environment

  • BIG-IP LTM VE 17.1.3
  • Microsoft Azure infrastructure transitioning to MANA-enabled hosts
  • Accelerated Networking (SR-IOV) enabled on BIG-IP VE instances

Cause

There are no F5-specific compatibility issues, configuration requirements, or known defects affecting BIG-IP LTM VE 17.1.3 operation on Azure MANA-enabled infrastructure. Azure transparently manages networking transitions, and BIG-IP LTM VE continues to function as expected, with possible temporary performance variability if Accelerated Networking is not available.

Answer/Recommended Actions

No configuration changes are required for BIG-IP LTM VE 17.1.3 to operate on MANA-enabled Azure hosts.
Standard maintenance operations (reboots, stop/deallocate, redeploy) can proceed; Azure will handle networking transitions without service interruption.
Monitor for any performance variability, especially after VM redeployment, as Azure may switch between Accelerated Networking and NetVSC.

Plan to upgrade to the latest BIG-IP LTM VE release (preferably 17.5.x or newer) to align with ongoing Azure networking hardware changes and ensure continued support.
Stay updated with F5 documentation for future guidance as formal MANA qualification is completed.

Additional Information

If Accelerated Networking is not available on a MANA-enabled host, Azure will automatically fall back to the synthetic NetVSC datapath.
This transition is handled transparently and does not interrupt service, though temporary performance variability may be observed.
F5 does not recommend avoiding standard maintenance operations during the MANA rollout. There are no known functional defects or blocking issues with BIG-IP LTM VE 17.1.3 related to MANA at the time of publication.
