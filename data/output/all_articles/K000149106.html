K000149106: BIG-IP Edge client fails to render captive portal

Type
Support Solution
Published
2024-12-26
Updated
2025-01-17
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149106

Description

When trying to establish a VPN connection from a network that has captive portal (mostly public WiFi's), BIG-IP Edge Client either displays a blank page or is unable to connect to http://cdn.f5.com. 

Environment

  • BIG-IP
  • Captive Portal

Cause

Captive portal page that uses Javascript version that Edge client engine does not support.

The underlying mini browser( Trident Engine) BIG-IP edge client uses doesn’t support javascript greater than ES5, so it fails to render pages that uses Javascript ES6.

The Trident engine only supports ECMAScript version 5 and earlier.

 

Recommended Actions

Perform the following procedures:

  • Upgrade to APM Client 7.2.5
  • Perform the procedure in K000141526: BIG-IP Edge Client Windows uses default browser for authentication to configure BIG-IP Edge Client to use the default browser on Windows client for authentication.

Additional Information

We have a plan to support WebView2 and to allow customer to select an alternate browser to perform login page rendering.
