Topic

This article applies to BIG-IP 11.0.0 through 13.0.x. For information about other versions, refer to the following article:

  • K55584748: Configuring the SSL cipher strength for a custom HTTPS health monitor (13.1.x)

You should consider using this procedure under the following condition:

  • You want to configure a customized SSL cipher list for an HTTPS health monitor.

Description

The default HTTPS health monitor uses a default SSL cipher list that cannot be modified; however, you can create a custom HTTPS monitor. Creating a custom HTTPS monitor enables you to use specific SSL cipher suites to match specified SSL ciphers used by the resource pool that require health monitoring by the BIG-IP system.

The default HTTPS health monitor's Cipher List is configured as the following string:

DEFAULT:+SHA:+3DES:+kEDH

If you can access the BIG-IP command line, you can use the following command syntax to view the full list of ciphers that a cipher string represents:

openssl ciphers -v '<Cipher_String>'

For example, to view the cipher list for the default HTTPS health monitor, use the following command:

openssl ciphers -v 'DEFAULT:+SHA:+3DES:+kEDH'

Note: TLS1.2 monitor support was added in BIG-IP 11.5.0.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the Configuration utility.
  • You have the list of cipher suites that are supported by the resource pool monitored by this new custom HTTPS health monitor.

Procedures

To configure custom ciphers to be used by an HTTPS monitor, you must create a custom HTTPS health monitor. To do so, perform the following procedure:

Impact of procedure: Performing the suggested procedure should not have a negative impact on your system.

Important: You must verify that the list of ciphers you are attempting to configure to the new custom HTTPS monitor is supported by the resource pool that will be monitored. If you fail to specify a valid cipher list, the monitor will behave like a TCP monitor.

Note: You cannot modify the TLS/SSL protocol version. The HTTPS monitor chooses the highest level TLS/SSL protocol.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Monitors.

    Note: For BIG-IP DNS, navigate to DNS > GSLB > Monitors. 

  3. Click Create.
  4. For Type type, click HTTPS.
  5. Complete the remaining Configuration options according to your requirements for the custom HTTPS monitor. 
  6. For Cipher List, specify the ciphers (supported by the resource pool) that this monitor should use.

    For example, if the resource pool supports ciphers from the DEFAULT list with the exception of the RSA key exchange cipher suite, you can use the following string:

    DEFAULT:+SHA:+3DES:+kEDH:-kRSA

  7. Click Finished.
