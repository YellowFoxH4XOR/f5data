K000092717: Cannot see Edge Client menu bar icons on newer Apple Macbook with notch

Type
Support Solution
Published
2022-11-24
Updated
2023-03-16
Source
https://my.f5.com/manage/s/article/K000092717

Description

If you have a Apple Mac computer with a screen that has a camera notch, you might not be able to see the F5 access icon in the status menu (on windows devices this is known as a 'system bar').

 

Environment

You are looking for the status icon in the status menu on your Mac, but are not able to see it.

Cause

This is a known issue and is currently under investigation for remediation.

 Recommended Actions

To work around this, you can do one of the following:

  • Change resolution
  • Use an external monitor

Additional Information

None
