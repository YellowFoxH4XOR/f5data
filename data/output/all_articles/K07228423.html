Description

Not able to ping a virtual server or self IP created in a new VLAN.

tcpdump in VLAN on BIG-IP shows many ARP requests being sent out, but no response received.

Environment

  • F5 Virtual Edition (VE)
  • Virtual Server
  • VLAN

Cause

Interface assigned to VLAN in BIG-IP does not match the relevant network adapter configured for the VE on the hypervisor.

Recommended Actions

Verify that the MAC address of the interface assigned to the BIG-IP VLAN is corresponding to the expected network adapter on the hypervisor.

If there is a mismatch, re-configure the VLAN with the correct interface.
