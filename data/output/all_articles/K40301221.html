Description
How to download qkview file from rSeries?

Environment

  • F5OS-A
  • SCP

Cause

None

Recommended Actions

  1. Launch WinSCP or other file transfer utilities 
  2. Login via SCP or SFTP as the 'root' user
  3. Navigate to /var/shared/qkview/<filename>
  4. Download qkview with the transfer utilities
