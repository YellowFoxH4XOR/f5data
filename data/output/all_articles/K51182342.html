Description

ARP entries other than Route Domain 0 are not displayed in Configuration utility.
Route Domain configuration have a large number of IP addresses for which ARP is displayed. This is resource intensive.

Environment

  • BIG-IP Systems 11.x and later

Cause

This is by design change explained in K11929. 

Recommended Actions

You can use the following tmsh command to display ARP entries other than Route Domain 0.
tmsh show net arp any%<route domain id>
