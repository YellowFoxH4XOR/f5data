Source

Description

BIG-IP randomly sends challenges to API and blocks traffic.
 

Environment

  • All We Scrapping features are enabled.
    Bot Detection: Enabled
    Session Opening: Enabled
    Fingerprinting: Enabled
    Persistent Client Identification: Enabled
  • 'Web Scrapping' violations in Event Logs
  • Blocking Enabled

Cause

Due to the Bot Detection criteria and mitigation settings, BIG-IP sends challenges.
 

Recommended Actions

Review the Detection Criteria of 'Bot Detection' ( Rapid Surfing, Grace Interval, Blocking Period, Safe Interval ) and Detection and Prevention Criteria of the section 'Session Opening'.
 

Additional Information

None.
