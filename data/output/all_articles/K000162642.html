Description

BIG-IP ASM Bot Defense may block a legitimate application request when the device-identification cookie TSPD_101_DID is missing. The BIG-IP ASM sets TSPD_101 cookies for client-side challenge functionality.

The event log reports:

  • Detected Anomalies: Device ID Deletions
  • Missing cookie: TSPD_101_DID

Environment

  • BIG-IP ASM
  • Bot Defense enabled for the affected application
  • Bot Defense browser and device-identification settings enabled

Cause

The request was evaluated without the TSPD_101_DID cookie. The cookie can possibly be removed by the client, application, browser, or an intermediate network component.

Recommended Actions

  1. Verify that the application and the complete request path preserve the TSPD_101_DID cookie.
  2. Reproduce the request using a controlled client and confirm whether the cookie is created, retained, and returned to BIG-IP.
  3. If the application does not support device-identification verification, evaluate disabling the corresponding device-ID verification setting under the Bot Defense Browser settings.
  4. If only a specific request pattern should be permitted:
    • Create a narrowly scoped Bot Defense signature category.
    • Create a custom signature based on the known request characteristics.
    • Exempt only the matching traffic from the applicable mitigation.
  5. If the traffic originates from a known, trusted source that should not be evaluated by Bot Defense, consider whitelisting that source after assessing the security impact.
  6. As a broader alternative, disable the relevant violation in the Bot Defense profile mitigation settings. Use this option only after evaluating the resulting security exposure.
  7. Validate the selected change with a controlled request and confirm that access succeeds without broadly weakening Bot Defense protections.

Additional Information

  • The absence of TSPD_101_DID indicates that the device-identification cookie was not present when the request was evaluated.
  • Disabling the violation or broadly whitelisting traffic can reduce Bot Defense protection.
  • A narrowly scoped exception is preferable when only a specific application path, request pattern, or trusted source requires access.
  • Investigate the reason for the missing cookie before applying a broad mitigation change.
