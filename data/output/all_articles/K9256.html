Known Issue

This is the result of a known issue. The no metadata cache-size command should set the metadata cache-size to the default value of 512. However, the no metadata cache-size command actually sets the value to be 256.

F5 Product Development tracked this issue as ID 32013 and it was fixed in ARX 5.1.0. For information about upgrading, refer to the ARX release notes.

Important: The ARX 2.7.x, 3.x, and 4.0 CLI Reference Guides incorrectly state a default value of 256 for the metadata cache-size setting.

Workaround

You can work around this issue, and use the metadata cache-size 512 command to set the metadata cache-size to the default value of 512. For information about the metadata cache-size command, refer to the ARX CLI Reference Guide.
