Topic

Starting in FirePass version 7.0.0, the Protected Workspace (PWS) feature on clients running a 64-bit Windows operating system is supported. Earlier versions of FirePass do not support PWS for 64-bit clients; however, many other FirePass features are supported.

Note: For an overview of software compatibility, refer to the FirePass Controller Client Compatibility Matrix for your version of FirePass software.

F5 Networks tracked a request for enhancement to support Protected Workspace on 64-bit Windows clients as CR99847 and it was introduced in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.
