Description

Some BGP routes being received but are not being advertised to other neighbors. When you enable debug logging on BGP you notice the following warning.
/var/log/ltm:

BGP[24086]: BGP : -Outgoing [RIB] Announce Check: Y.Y.Y.Y/32 Route Remote Router-ID is same as Remote Router-ID

This warning indicates that the received route originator from IP address Y.Y.Y.Y is using the same router-id as the router that is supposed to receive the route from BIG-IP LTM.

Environment

  • BIG-IP LTM used to connect two or more BGP neighbors
  • Two or more neighbors are using the same BGP router-id
  • BIG-IP LTM version 14.1.4 or newer

Cause

BIG-IP default behavior is to follow strict compliance to RFC 6286, BGP identifier should be unique within the same AS.

Recommended Actions

  1. Make sure that each router (or VRF within the same router) has a unique router-id assigned.
  2. Using imish terminal, disable BGP peer router-id check feature on all the neighbors

    config terminal
    router bgp <bgp instance id>
    neighbor <neighbor ip address> disable-peerid-check
