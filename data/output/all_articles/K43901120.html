Issue

Old Behavior

In versions prior to BIG-IP 12.0.0, the BIG-IP system validates basic iRules syntax using a syntax checker during configuration load.

New Behavior

Beginning in BIG-IP 12.0.0, the BIG-IP system performs more stringent iRules syntax validation by using JET files during configuration load. iRules validations that have passed in previous software versions may fail when processed by the new JET validator engine. If validation fails with the JET validator engine, the system reverts back to the old validation method.

When the JET validator engine fails your iRules syntax validation, the BIG-IP system logs an error message in the /var/log/ltm file that appears similar to the following example:

warning mcpd[1234]: 01071859:4: Warning generated : /Common/example_irule:2: warning: [The following errors were not caught before. Please correct the script in order to avoid future disruption. "invalid argument <html><body>Results</body></html>"24 74][HTTP::respond 200 <html><body>Results</body></html> "MatchResult" "match"]

Note: JET validation for some iRule commands begins in BIG-IP 12.0.0. Validation for all remaining commands is completed in BIG-IP 12.1.0.

Impact

If your iRule fails the JET validator engine validation, a warning message is logged at the time of configuration load. Your BIG-IP system may fail to load the configuration if the syntax issue is not corrected.

Recommended Actions

To work around this issue, you must correct the syntax errors within the lines that are specified by the error message. To do so, depending on the state of your system, perform one of the following procedures:

  • BIG-IP system configuration is able to load:
    On the BIG-IP Configuration utility, go to Local Traffic > iRules > Name of your iRule, correct the iRule and select Update.

  • BIG-IP system configuration is unable to load due to error:
    From the BIG-IP command line, edit the iRule in the /config/bigip.conf file with your favorite editor. After correcting the iRule, enter the following command to reload the system configuration:.

    tmsh load sys config
