Topic

You should consider using this procedure under the following condition:

  • You want to customize the Diameter monitor to send additional Diameter commands or Attribute-Value-Pairs (AVPs), or to accept a non-default result code.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have command-line access to the BIG-IP system.
  • Have working knowledge of the Diameter protocol.

Description

You can configure the BIG-IP Diameter monitor to monitor the status of a Diameter server. You can customize most of the parameters that the Diameter monitor uses in the Configuration utility. However, if you want to customize the Diameter monitor to perform any of the following tasks, you must modify the /usr/share/monitors/diameter.cer-cea file:

  • Send additional Diameter commands.

    Note: For a list of supported Diameter commands, refer to K11681: Overview of the Diameter monitor

  • Accept a desired result code.
  • Send additional AVPs.

Procedures

To customize the Diameter monitor to perform any of the previously-listed tasks, perform the following procedures:

  • Remounting the /usr filesystem and backing up the diameter script file
  • Customizing the Diameter monitor to send additional Diameter commands
  • Customizing the Diameter monitor to accept a desired result code
  • Customizing the Diameter monitor to send additional AVPs
  • Remounting the /usr filesystem with read-only permissions

Remounting the /usr filesystem and backing up the diameter script file

Before modifying the diameter.cer-cea file, you must remount the /usr filesystem with read/write permissions and back up the diameter.cer-cea file. To do so, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Remount the /usr filesystem with read/write permissions by entering the following command:

    mount -o remount,rw /usr

  3. Make a copy of the /usr/share/monitors/diameter.cer-cea file by entering the following command:

    cp -p /usr/share/monitors/diameter.cer-cea /usr/share/monitors/diameter.cer-cea.SOL14536

  4. Perform any of the following procedures, as necessary.

Customizing the Diameter monitor to send additional Diameter commands

You can customize the Diameter monitor to send additional Diameter commands. To do so, perform the following procedure:

Impact of procedure: The Diameter monitor may fail to properly monitor a Diameter server if the diameter script file is incorrectly modified.

  1. If you have not done so, log in to the command line.
  2. Make sure that you have performed the remount and backup procedure, described previously.
  3. Edit the /usr/share/monitors/diameter.cer-cea file using a text editor of your choice.
  4. Locate the Diameter Capabilities-Exchange-Answer (CEA) command, by way of the expect line, similar to the following example:

    expectCEA', 0, AVP('result-code', 2001), inspection = True)

  5. Right after the Diameter CEA command, add the desired additional Diameter request command and corresponding Diameter answer command, using their respective send and expect lines.

    For example, you would add the following send and expect lines for the Device-Watchdog-Request (DWR) command and corresponding Device-Watchdog-Answer (DWA) command, respectively:

    send('DWR', 0, AVP('origin-host', ORIGIN_HOST),
    AVP('origin-realm', ORIGIN_REALM),
    *customavps)

    expect('DWA', 0, AVP('result-code', 2001), inspection = True)

    Note: Ensure that the mandatory AVPs are included with the Diameter request command.

  6. Save the changes and exit the text editor when you are done.

Customizing the Diameter monitor to accept a desired result code

You can customize the Diameter monitor to accept a desired result code for the Diameter monitor by performing the following procedure:

Impact of procedure: The Diameter monitor may fail to monitor a Diameter server properly if the diameter script file is incorrectly modified.

  1. If you have not done so, log in to the command line.
  2. Make sure that you have performed the remount and backup procedure described earlier.
  3. Edit the /usr/share/monitors/diameter.cer-cea file using a text editor of your choice.
  4. Locate the expect line for the desired Diameter answer command.

    For example:

    expect('CEA', 0, AVP('result-code', 2001), inspection = True)

  5. Next to the result-code AVP, replace the existing value with your desired value.

    For example, if the desired result code is 2002, you would change the line to the following:

    expect('CEA', 0, AVP('result-code', 2002), inspection = True)

    Note: Make sure that the desired result-code AVP is relevant to the Diameter command.

  6. Save the changes and exit the text editor.

Customizing the Diameter monitor to send additional AVPs

You can customize the Diameter monitor to send additional AVPs by performing the following procedure:

Impact of procedure: The Diameter monitor may fail to monitor a Diameter server properly if the diameter script file is incorrectly modified.

  1. If you have not done so, log in to the command line.
  2. Make sure that you have performed the remount and backup procedure described previously.
  3. Edit the /usr/share/monitors/diameter.cer-cea file using a text editor of your choice.
  4. Locate the customavps array, which appears similar to the following example:

    customavps = [ ]

  5. Add the AVPs to the customavps array and define a variable for each AVP.

    For example, to configure the Diameter monitor to send the origin-state-id, supported-vendor-id, and inband-security-id attributes with the values 11, 12, and 13, respectively, you would define a variable for each AVP and add these AVPs to the customavps array:

    ORIGIN_STATE_ID = 11
    SUPPORTED_VENDOR_ID = 12
    INBAND_SECURITY_ID = 13

    customavps = [ AVP('origin-state-id', ORIGIN_STATE_ID, flags='', type='Uint32'),
    AVP('supported-vendor-id', SUPPORTED_VENDOR_ID, flags='', type='Uint32'),
    AVP('inband-security-id', INBAND_SECURITY_ID, flags='', type='Uint32') ]

    Note: Make sure that the additional AVPs are relevant to the Diameter commands that use the customavps array.

  6. Save the changes and exit the text editor.

Remounting the /usr filesystem with read-only permissions

After you have modified the diameter.cer-cea file, you must remount the /usr file system with read-only permissions. To do so, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. If you have not done so, log in to the command line.
  2. Remount the /usr filesystem with read-only permissions by entering the following command:

    mount -o remount,ro /usr
