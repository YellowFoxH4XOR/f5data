Description

When a FQDN pool member with autopopulate enabled and a FQDN node with autopopulate is disabled that resolve to the same IP address(es). Some or all of the Ephemeral Pool members may not be created.


01070734:3: Configuration error: Cannot enable pool member to autopopulate: node (/Common/_auto_X.X.X.X) has autopopulate set to disabled.

Environment

  • FQDN Pool members
  • FQDN Nodes
  • Autopopulate enabled

Cause
Bug 1077405

Recommended Actions

Allow some LTM pools to use FQDN pool members with autopopulate enabled (allowing multiple ephemeral pool members to be created) while other LTM pools use FQDN pool members with autopopulate (allowing only one ephemeral pool member to be created), configure the following:

  1.  Create all FQDN Nodes with FQDN names that might resolve to a common/overlapping set of IP addresses with "autopopulate enabled".
  2.  Create FQDN Pool Members with autopopulate enabled or disabled depending on the desired membership for each pool.

Additional Information

1. Delete the FQDN template pool member and node using the following commands. Make sure to replace <affected_pool> with the actual pool name, <fqdn_pool_member_name> with affected pool member name, and <port> with actual pool member port.
 

tmsh modify ltm pool <affected_pool> members delete { <fqdn_pool_member_name>:<port> }

tmsh delete ltm node <fqdn_pool_member_name>

 

2. Verify that there are no other FQDN nodes sharing the same IP address. If there are, delete them as well and if attached to a pool use the commands in step 1 as a guide.
 

3. Recreate the FQDN template pool member using the following command, again, replace the variables with actual values:

tmsh modify ltm pool <affected_pool> members add { <fqdn_pool_member_name>:<port> { fqdn { autopopulate enabled interval ttl name <fqdn_pool_member_name> } }

This should automatically create the FQDN nodes based on records from DNS resolution response.
