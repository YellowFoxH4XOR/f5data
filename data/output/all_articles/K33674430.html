  • BIG-IP FPS: 16.1.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0

Source
https://my.f5.com/manage/s/article/K33674430

Description

Device in offline state after upgrading to 16.1.0

  • Upgrade with ASM Provisioned
  • Upgrade with AWAF Provisioned
  • Upgrade with FPS Provisioned
  • Device in Offline State due to datasyncd failsafe condition
  • Error in /var/log/datasync/datasyncd.log
    • DATASYNCD|NOTICE|Jul 19 00:00:58.861|15388|datasyncd_main.c:1575|is_generator_running: There are not enough rows (less than 2), so letting it run some more.
      java.lang.NullPointerException: NAME sjcl$exception$corrupt 38047 [length: 22] [originalname: sjcl.exception.corrupt] [source_file: /var/datasync/cs/fpm/versafe.js]

Environment

  • Post upgrade to 16.1
  • datasyncd in failsafe condition
    • tmsh show sys ha-status
  • ASM Provisioned
  • AWAF Provisioned
  • FPS / Datasafe Provisioned

Cause

BUG 1038445 On a BIG-IP system with FPS JS engine Live Update, after upgrade to 16.1.x, the old live update is not replaced by the engine in the build.

Recommended Actions

Follow workaround provided in BUG 1038445

Additional Information

None.
