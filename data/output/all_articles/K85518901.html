Issue

Error Message

Unable to locate PPTP GRE flow with <key type> key <key value> while processing connflow <ip address>:<port> -> <ip address>:<port>.

In this error message, note the following:

  • <key type> is the Generic Routing Encapsulation (GRE) flow action.
  • <key value> is the GRE flow action numeric key value.
  • <ip address> is the source or destination IP address of the GRE connection.
  • <port> is the source or destination port used for the GRE connection.

For example:

01700020:3: Unable to locate PPTP GRE flow with Translated Call ID key 10772 while processing connflow 192.168.0.100:34827 -> 172.16.0.200:34827.

Message Location

You may encounter this message in the following location[s]:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The BIG-IP system is unable to locate the call ID for the GRE connection flow, that the system expects to exist.

Note: If the  Point-to-Point Tunneling Protocol (PPTP) Application Level Gateway is functioning correctly this error can be safely ignored.

Impact

The system drops the specific packet, and the drop count increments.

Recommended Actions

If the PPTP Application Level Gateway is not functioning correctly, contact F5 Technical Support.
