Known Issue

The PB4300 blade fails to disaggregate Encapsulating Security Payload (ESP) traffic based on IP addresses in hardware.

This issue occurs when the following condition is met:

  • The PB4300 blade receives ESP traffic.

Impact

The BIG-IP system’s throughput is degraded.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The PB4300 blade attempts to disaggregate ESP traffic based on the IPsec ESP Security Parameter Index (SPI) value in hardware. However, because the blade used does not have that capability, you notice throughput degradation due to ESP traffic being sent to one High-Speed Bridge (HSB).
