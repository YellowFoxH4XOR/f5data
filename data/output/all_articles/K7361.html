Known Issue

This is the result of a known issue. Under some circumstances, the BIG-IP system creates jar_cache files that accumulate in the /var/cache/tomcat4/temp/ directory. This may be a result of the Java Virtual Machine (JVM) halting unexpectedly. Unless the files are manually deleted, they can fill up the /var partition.

F5 Networks Product Development tracked this issue as CR66759 and it was fixed in BIG-IP versions 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator Release Notes.

Workaround

To work around this issue, delete the files from the /var partition by performing the following procedure:

  1. Log in to the command line.
  2. To verify whether the system contains jar_cache files, type the following command:

    ls -las /var/cache/tomcat4/temp/jar_cache*

  3. To delete the jar_cache files from the /var/cache/tomcat4/temp/ directory, type the following command:

    rm -rf /var/cache/tomcat4/temp/jar_cache*
