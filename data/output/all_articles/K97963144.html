Known Issue

Windows 8.1 devices may fail to establish an access session.

This issue occurs when all of the following conditions are met:

  • Your device is running the Windows 8.1 operating system.
  • You install the BIG-IP Edge Client provided by BIG-IP APM 11.4.1.
  • You attempt to establish an access session by using the BIG-IP Edge Client or Internet Explorer 11 with BIG-IP APM 10.2.4.

Impact

You are unable to establish access sessions.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to establish an access session to a BIG-IP APM 10.2.4 system, you observe an error message similar to the following example:

    Network Access Connection Device not found.
  • When you attempt to establish an access session to a BIG-IP APM 11.0.0 system or later, the session is successful.
  • When you delete the BIG-IP Edge Client using the client troubleshooting utility (CTU) and install the BIG-IP Edge Client provided by BIG-IP APM 10.2.4, you are able to establish an access session when you connect to a BIG-IP APM 10.2.4 system.

Workaround

To work around this issue, you can use the CTU to remove the installed BIG-IP Edge Client and components and then install the compatible BIG-IP Edge Client version. For more information, refer to K8253: Removing BIG-IP APM and FirePass client components from Windows client systems.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
