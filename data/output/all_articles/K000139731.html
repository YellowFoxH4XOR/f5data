K000139731: How to configure security policy on BIG-IP Next WAF using BIG-IP Next Central Manager to hide Cookie value.

Description

 

BIG-IP Next WAF stores incoming requests in plain text format. Some cookies may have sensitive values, that you want to hide from system users. You can configure cookie value so that the system replaces the sensitive value, in the stored request and in logs, with asterisks (***).

 

 

Environment

 

  • BIG-IP Next WAF.
  • BIG-IP Next Central Manager.
  • Ver 20.1.1.
  • You already know the cookie name, the value of which is getting logged in plain text.
  • Cookie Name is already configured in the policy.

 

 

Cause

 

Sensitive information getting logged in logs.

 

 

Recommended Actions

 

 

  1. Login to the GUI of BIG-IP Next Central Manager
  2. Under Manage Security Policies, click on “Go to security workspace”.
  3. Select policies under WAF and select the policy for which you would like hide the cookie value.
  4. Once you select the policy, scroll down and look for “Headers” under “Application Elements”.
  5. Under “Headers” select “Cookies”
  6. Click on the Cookie Name for which, you would like to hide its value and log it as asterisks (***) instead of actual value.
  7. Look for “Mask Value in Logs” and enable it
  8. Once done, click save and then Deploy the policy.
