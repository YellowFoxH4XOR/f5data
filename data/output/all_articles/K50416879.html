Known Issue

The BIG-IP APM rewrite process may restart when rewriting URLs in POST data.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system to provide portal access to resources.
  • POST content in the request contains a URL with specific characters.

Impact

Portal access in unavailable while the rewrite process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to access resources using portal access.
  • The rewrite process generates a core file to the /shared/core/ directory.
  • Messages are logged to the /var/log/daemon.log file similar to the following:

    emerg logger: Re-starting rewrite
