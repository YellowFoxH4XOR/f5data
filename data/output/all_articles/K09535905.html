Issue

Error Message

014f0004:3: stopping worker process (<pid>) socket error

In this error message, note the following:

  • <pid> is the worker process ID.

For example:

014f0004:3: stopping worker process (1234) socket error
014f0004:3: script worker process exited, status: 139

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The scriptd process restarted one of many application template scripts it maintains. 

Impact

There is no impact; this message is informational.

Recommended Actions

None
