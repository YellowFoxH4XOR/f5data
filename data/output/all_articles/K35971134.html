K35971134: Invalid keyword 'complementofdefault' in ciphers list

Description

  • You try to configure a custom cipher list for a Client or Server SSL profile using string "complementofdefault"
  • The following error appear on GUI or CLI

    Invalid keyword 'complementofdefault' in ciphers list for profile Common/Client_SSL_Profile

Environment

  • LTM
  • Client or Server SSL profile
  • Ciphers

Cause

BIG-IP SSL profiles can use ciphers from two different SSL stacks; the NATIVE stack is built into the Traffic Management Microkernel (TMM), and the COMPAT stack is based on the OpenSSL library. The NATIVE stack is an optimized SSL stack which the BIG-IP system can use to leverage hardware acceleration.

The keyword COMPLEMENTOFDEFAULT from the COMPAT SSL stack seems to be not a valid option in the SSL profile configuration

Recommended Actions

F5 recommends that you use the NATIVE stack, as it is suitable for most SSL connections.

None.
