Description

You can configure a group of BIG-IP devices to synchronize the configuration data. The available sync types are:

  • Automatic with Incremental Sync

  • Manual with Incremental Sync

  • Manual with Full Sync

The log messages are different when using different sync types.

Environment

  • BIG-IP devices in a high availability configuration
  • Perform configuration sync operation 

Cause

None

Recommended Actions

In this example, there are two BIG-IP devices in the HA pair. BIG-IP1 syncs the configuration changes to the device group "Failover".
  • When using Automatic with Incremental Sync and Manual with Incremental Sync, you may observe the following logs in the /var/log/ltm file on the respective devices.
BIG-IP1: 
notice mcpd[5513]: 0107168c:5: Incremental sync complete: This system is updating the configuration on device group /Common/Failover device %cmi-mcpd-peer-/Common/bigip2.example from commit id { 6 6924567169420856380 /Common/bigip2.example } to commit id { 264 6924567414703140388 /Common/bigip1.example }.
