K35452421: Syslog doesn't send messages from the Local IP or to the remote port

Type
Support Solution
Published
2022-03-26
Updated
2026-05-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K35452421

Description

BIG-IP system is not sending logs to remote syslog server. You may have followed K13080 to configure remote syslog server or has made changes to local-ip or remote port configuration on BIG-IP system. Packet capture shows that the syslog traffic being sent from a different IP specified in the parameter "local-ip" or on a different port number.

Environment

  • BIG-IP
  • Remote Logging

Cause

  • Bug ID 784981
  • Bug ID 1019129

Recommended Actions

  • Restart the syslog-ng service from the command line of the BIG-IP system. 
    bigstart restart syslog-ng

Additional Information

None
