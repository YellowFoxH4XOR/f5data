Known Issue

The tmm process may terminate when BIG-IP WebAccelerator parses a blank HREF HTML attribute.

This issue occurs when the following conditions are met:

  • BIG-IP WebAccelerator parses an HREF attribute that contains only one or more spaces.

    For example:

    <A HREF="  ">TEST</A>
  • The affected BIG-IP WebAccelerator policy node has IBR enabled.

Impact

The BIG-IP host may stop temporarily processing traffic and fail over to a standby host in your device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP host may stop temporarily processing traffic and fail over to a standby host in your device group.
  • You may find a TMM core file in the /shared/core directory and errors similar to the following in the /var/log/daemon.log file:

    emerg logger: Re-starting tmm

Workaround

To work around this issue, you can use an iRule to strip out the whitespace from HREF. To do so, perform the following procedure:

Impact of workaround: iRules may increase processing overhead and require more system resources per connection.

  1. Log in to the BIG-IP Configuration Utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Click iRules List.
  5. Click Create.
  6. Enter a name for this iRule.
  7. Copy and paste the following iRule into the Definition box:

    when HTTP_REQUEST {
    # Disable the stream filter for all requests
    STREAM::disable
    }

    when HTTP_RESPONSE {

    # Disable the stream filter by default
    STREAM::disable

    # Enable the stream filter for text responses only
    if {[HTTP::header value Content-Type] contains "text/html"}{

    # Remove the spaces
    STREAM::expression {@[hH][rR][eE][fF]=" +"@href=""@}

    # Enable the stream filter for this response only
    STREAM::enable
    }
    }
  8. Click Finished.
  9. Click Local Traffic.
  10. Click Virtual Servers.
  11. Click Virtual Server List.
  12. Select the virtual server you want to modify.
  13. Under the Configuration option, select Advanced.
  14. In the Stream Profile section, select the default stream profile called stream.
  15. At the top of the screen, click the Resources tab.
  16. Associate the newly created iRule with this virtual server.
  17. Click Update.
