K45544738: UDP and TCP Port Range supported by BigIP for Virtual Server configuration

Description

BIG-IP Virtual Server Service Port field supports a range of Port numbers from 0 to 65535. 

Environment

Relevant environmental factors:

  • BIG-IP system
  • Virtual Servers configured

Cause

N/A

Recommended Actions

When configuring a Virtual Server, the Service Port number must fall between 0 and 65535.
