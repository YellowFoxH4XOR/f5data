Known Issue

The BIG-IP Diameter monitor marks a Diameter server as down when it perceives the received attribute-value pair (AVP) format or type as invalid even though the Diameter server responds with a Capabilities-Exchange-Answer (CEA) result code of 2001. The BIG-IP Diameter monitor should determine the status of the Diameter server based solely on the returned CEA result code.

Note: For more information about the Diameter monitor, refer to K11681: Overview of the Diameter monitor.

F5 Product Development tracked this issue as ID 339208, and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.
