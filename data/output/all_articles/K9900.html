Topic

This article applies to BIG-IP 9.x through 10.x. For more information about other versions, refer to the following article:

  • K17523: Modifying large external data-groups (11.x - 14.x)

Data group lists, also known as classes, provide a way to include lists of information for reference by iRules in the BIG-IP LTM configuration. Internal classes are defined in the /config/bigip.conf file along with the data they contain. External classes are also defined in the /config/bigip.conf file, but the data they contain is stored in a separate file that is referenced from the external class definition. F5 Networks recommends using external classes for maintaining large data sets, as they result in a more compact and manageable bigip.conf file.

Reloading the configuration reloads the bigip.conf file, the internal classes defined therein, and the external class files referenced in any external class definitions. If you update the contents of the external class file directly using a text editor, you must then reload the configuration using the bigpipe load command. However, reloading a configuration containing a reference to a large external class may cause CPU utilization on the BIG-IP system to increase for an extended period of time. You can avoid this temporary spike in CPU utilization by updating the class using the bigpipe class commands, and saving the changes to the configuration file using the bigpipe save command.

To update external classes perform one of the following procedures for your version:

BIG-IP 9.0 through 9.3.x

To update external classes using the bigpipe class command, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. To modify the contents of a specific class, type either the bigpipe class add or bigpipe class delete commands.

    For example, to add the entries test3,Pool1 and test4,Pool2 to the test string class, type the following command:

    bigpipe class test add { \"test3,Pool1\" \"test4,Pool2\" }

    Note: Multiple entries must be separated by whitespace for all class types. You must add double quote ( " ) characters around the string class entries, and escape the double quote characters with backslash ( \ ) characters to enter at the command line.
  3. Save the configuration to disk by typing the following command:

    bigpipe save

Important: You must run the bigpipe save command to save your changes to the external class file referenced in the configuration. Otherwise, any subsequent configuration reload will overwrite the changes made to the running configuration and they will be lost. The configuration is reloaded when the bigpipe load command is issued manually, upon failover, and upon configuration synchronization.

BIG-IP 9.4.0 through 10.0.1

To update external classes using the bigpipe class command, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Use the bigpipe class add or bigpipe class delete commands to modify the contents of a specific class.

    For example, to add the entries test3,Pool1 and test4,Pool2 to the test class, type the following command:

    bigpipe class test { \"test3,Pool1\" \"test4,Pool2\" add }

    Note: Multiple entries must be separated by whitespace for all class types. You must add double quote ( " ) characters around the string class entries, and escape the double quote characters with backslash ( \ ) characters to enter at the command line.  
  3. Save the configuration to disk by typing the following command:

    bigpipe save

Important: You must run the bigpipe save command to save your changes to the external class file referenced in the configuration. Otherwise, any subsequent configuration reload will overwrite the changes made to the running configuration and they will be lost. The configuration is reloaded when the bigpipe load command is issued manually, upon failover, and upon configuration synchronization.

BIG-IP 10.1.0 through 10.2.4

To update external classes using the tmsh data-group records command, perform the following procedure:

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Use the tmsh data-group records add or tmsh data-group records delete commands to modify the contents of a specific class.

    For example, to add the entries test3,Pool1 and test4,Pool2 to the test class, type the following command:

    modify ltm data-group test { records add { test3 { data Pool1 } test4 { data Pool2 } } }
     
  3. Save the configuration to disk by typing the following command:

    save sys config

Important: You must run the save sys config command to save your changes. Otherwise, any subsequent configuration reload will overwrite the changes made to the running configuration and they will be lost. The configuration is reloaded when the load sys config command is issued manually, upon failover, and upon configuration synchronization.
