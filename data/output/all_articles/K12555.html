Topic

FirePass allows you to customize the name of the SSL VPN connection that is displayed on the VPN client for Microsoft Windows.

By default, FirePass displays the name defined in the Network Access : Resources : Client Settings Connection Name text box, appended with - Go to  <URL of FirePass Controller>.

For example:

F5 VPN -Go to fox.f5.com

You can customize the F5 VPN portion of the name.

Specifying a custom name for the adapter that will display in the network connections

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Network Access : Resources.
  3. Click the Customization tab.
  4. In the Connection Name in Network Connections Folder text box, enter the name you want to display on the client system.

    For example:

    F5 VPN
  5. Click the Update button.

Verifying the connection name

Windows XP

  1. Establish a VPN connection to your FirePass Controller.
  2. Click Start.
  3. Click Control Panel.
  4. Click Network and Internet Connections.
  5. Click Network Connections.

    You will see the network adapter with the customized name you created earlier.

Windows Vista and Windows 7

  1. Establish a VPN connection to your FirePass Controller.
  2. Click Start.
  3. Click Control Panel.
  4. Click Network and Sharing Center.

    You will see the network adapter with the customized name you created earlier.
