Description

After connecting to portal access resource the browser becomes unresponsive and causes maximum utilization of one cpu core on the client

Environment

  • Application configured as a portal access resource
  • Browser becomes unresponsive while launching PA application
  • All browsers are affected

Cause

ID 643935: Rewriting may cause an infinite loop while processing some objects

Recommended Actions

Upgrade to non affected version: 15.0.0, 14.1.2.3, 14.0.1.1, 13.1.3.2
