Topic

This article applies to all platforms that use GRUB2, including BIG-IP and BIG-IQ virtual editions. For BIG-IP systems that use GRUB 0.97, refer to the following article: K4178: Restarting the BIG-IP system in single-user mode (GRUB 0.97).

You should consider using this procedure under the following condition:

  • You want to start your BIG-IP or BIG-IQ system in single-user mode.

Description

You may occasionally have to start the BIG-IP or BIG-IQ system in single-user mode to fix operating system issues, for example, the filesystem or root password.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command line access to your BIG-IP or BIG-IQ system.
  • You have serial console access to your BIG-IP or BIG-IQ system.
  • Your BIG-IP or BIG-IQ system is using GRUB2 bootloader.

Procedures

  • Restarting BIG-IP 14.0.0 and later or BIG-IQ 8.0.0 and later in single-user mode
  • Restarting BIG-IP 13.X and earlier or BIG-IQ 7.1.0.x and earlier in single-user mode

Restarting BIG-IP 14.0.0 and later or BIG-IQ 8.0.0 and later in single-user mode

Impact of procedure: This procedure involves restarting the BIG-IP or BIG-IQ system; thus, F5 recommends that you perform this procedure during a maintenance window. When the BIG-IP system is in single-user mode, the system does not process traffic. When the BIG-IQ system is in single-user mode, the system does not manage the BIG-IP devices.

  1. Connect a terminal to the BIG-IP or BIG-IQ serial console port.
  2. Restart the BIG-IP or BIG-IQ system.

    While starting, the BIG-IP or BIG-IQ system displays the GRUB menu and counts down before continuing the start process.

  3. Before the countdown expires, use the arrow keys to stop the countdown and select the appropriate boot image.

    Note: Alternately, select the caret (^) to move up and the V key to move down.

  4. Select the E key to edit the start options.

    A new GRUB menu displays.

  5. Select the arrow keys to select the line that begins with linux /boot/<boot location>/vmlinuz.
  6. Select the End key or use the right arrow key to go to the end of line.
  7. Enter the word rd.break at the end of the linux /boot/<boot location>/vmlinuz. line.

    Depending on the platform, the boot command may appear similar to the following example:

    linux /boot/1/vmlinuz ro root=UUID=7237fa64-e347-4bb7-a755-6e2617bd7c0e console=ttyS0 panic=1 platform=D113 rd.break

    Important: When starting BIG-IP or BIG-IQ Virtual Edition in single user mode, you should additionally delete the console=ttyS0  line, leaving only console=tty0. If you skip this, the BIG-IP or BIG-IQ VE starts and the login prompt does not display on the console.

  8. Select Ctrl-X to apply the change.
  9. After the starting sequence completes, a command-line prompt displays switch_root:/# (prompt). The system is now in single-user mode. 
    Note: Some hardware platforms will display "local login:" instead.  You can enter the username "root" here and press ENTER and then you will be dropped to "switch_root:/#" prompt.
  10. Now you can recover the root password use one of the following K Articles:
    • K23220345: How to recover the root password on RAID-capable BIG-IP platforms (BIG-IP 14.1.0 and later)
    • K35811337: Recover the root password on non-RAID BIG-IP platforms (BIG-IP 14.1.0 and later)
    • K92740423: Recover the root user password on BIG-IQ Virtual Edition

When you are finished using single-user mode and want to return the BIG-IP or BIG-IQ system to normal operating mode, enter one of the following commands:

  • exit
  • reboot

Restarting BIG-IP 13.1.0 and earlier or BIG-IQ 7.1.0.x and earlier in single-user mode

  1. Connect a terminal to the BIG-IP or BIG-IQ serial console port.
  2. Restart the BIG-IP or BIG-IQ system.

    While starting, the BIG-IP or BIG-IQ system displays the GRUB menu and counts down before continuing the start process.

  3. Before the countdown expires, use the arrow keys to stop the countdown and select the appropriate boot image.

    Note: Alternately, select the caret (^) to move up and the V key to move down.

  4. Select the E key to edit the start options.

    A new GRUB menu displays.

  5. Use the arrow keys to select the line that begins with linux /boot/<boot location>/vmlinuz.
  6. Select the End key or select the right arrow to go to the end of line.
  7. Enter the word single at the end of the linux /boot/<boot location>/vmlinuz line. 

    Depending on the platform, the boot command may appear similar to the following example:

    Note: When starting in single-user mode, the BIG-IP or BIG-IQ system may attempt to perform a file system check (fsck) and request the root password. If the root password is unknown, you can skip the file system check by appending the words single fastboot instead of single.

    For example:

    linux /boot/1/vmlinuz single fastboot

  8. Select Ctrl+X or select the F10 key to start the system using the modified options.

    After the starting sequence completes, a command-line prompt displays. You have now started the system in single-user mode.

  9. When you are finished using single-user mode and want to return the BIG-IP or BIG-IQ system to normal operating mode, enter one of the following commands:
    • exit
    • reboot
