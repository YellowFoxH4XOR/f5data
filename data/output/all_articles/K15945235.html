Description

Network Failover doesn't work properly after upgrade to version 14.x and above when Network Failover port is set to value below 1024

Error in /var/log/ltm:
010c003b:3: bind fails on recv_sock_fd addr <ip_address> port 1023

Environment

  • Recent upgrade to version 14.x or later
  • BIG-IP cluster configured
  • Network Failover Configured with custom ports
  • Customized port for Network Failover set to 1-1023 in Device Management > Devices > (device name) > Failover Network

Cause

This is expected behaviour due to security enhancements in SELinux
We have tracked this change with ID879829

Recommended Actions

Recommend to use ports above 1024 for Network Failover

Additional Information

None
