Description

After upgrading devices in the HA pair, peers mark each other Offline and consider themselves as Active for all traffic groups.

As a result, traffic-group is active on more than one device.

However, in /var/log/ltm log files you can see messages informing that failover messages were sent and received.

Example:

010c0084:4: Failover status message received after 2073.100 second gap, from device BIG-IP-01 (10.1.1.1.) (unicast: -> 10.2.2.2).

Note: The same behaviour is seen even when tmm is restarted or HA connection last for more than 30 Sec

Environment

  • BIG-IP HA pair
  • multiple traffic-groups
  • long uptime of BIG-IP devices

Cause

The issue is related to bug ID1347825.

Recommended Actions

To avoid the issue, before doing any maintenance that could disrupt the communication between two devices configured with a failover, reboot BIG-IP units or restart the sod daemon.

Important: Restarting sod process is marking the device Offline for a moment and if the device is Active, the failover happens.

1. Log in to the command line.

2. To restart the service run the following command:

bigstart restart sod
