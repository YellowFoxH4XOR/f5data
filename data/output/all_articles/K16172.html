Known Issue

The Traffic Management Shell (tmsh) fails to list NTLM profiles created in subfolders.

This issue occurs when all of the following conditions are met:

  • You have an NTLM profile configuration that was created in a subfolder.
  • You attempt to list the NTLM configuration from a base folder using tmsh.

Impact

The tmsh utility will be unable to list NTLM profiles created in a subfolder.

The Enterprise Manager system will be unable to gather NTLM profile information from managed devices.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The tmsh utility is unable to list NTLM profile configuration information from a base folder. For example, an NTLM profile named ntlm_profile1 exists in folder /Common/app1, but no configuration information is listed.

    For example:

    #(/Common)(tmos)# list ltm profile ntlm app1/ntlm_profile1
    #

  • The Enterprise Manager system is unable to list the NTLM profile using the Configuration utility and in the /var/log/em file you may observe an error message similar to the following example:

    err emdeviced[7477]: 04010568:3: Error found on device 192.168.1.100 (UID: 4): get change control info: iControl error: 'iControl::OperationFailed - primary code:2(0x2) secondary code: 0(0x0) string: Shell interface returned unexpected number of instances [1] for the following arguments [/Common] [ltm.profile.ntlm] [/Common/iapp] [list] [ltm.profile.ntlm] [/Common/app1/ntlm_profile1] [list]

Workaround

To work around this issue, you can change into the subfolder before listing the NTLM profile. To do so, perform the following procedure:

Note: There is no workaround available for the Enterprise Manager system.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To change into the subdirectory containing the NTLM profile, use the following command syntax:

    (/Common)(tmos)# cd </Base/subfolder>

    For example, to change into a subdirectory named app1 from the /Common base directory, type the following command:

    (/Common)(tmos)# cd /Common/app1

    The command prompt should reflect your current location in the directory tree, similar to the following:

    (/Common/app1)(tmos)#

  3. To list the NTLM profile, use the following command syntax:

    (/Common)(tmos)# list ltm profile ntlm <profile_name>

    For example, to list an NTLM profile named ntlm_profile1, type the following command:

    (/Common/app1)(tmos)# list ltm profile ntlm ntlm_profile1
    ltm profile ntlm /Common/app1/ntlm_profile1 {
    defaults-from none
    insert-cookie-name NTLMconn
    insert-cookie-passphrase mypassphrase
    key-by-cookie-name mycookie
    }
