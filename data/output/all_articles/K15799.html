Known Issue

Single Secure Socket Layer (SSL) transfers on some BIG-IP platforms may have lower throughput than expected.

This issue occurs when all of the following conditions are met:

  • You are using one of the following BIG-IP platforms:

    • BIG-IP 2000s/2200s (D112)
    • BIG-IP 4000s/4200v (C113)
  • You are using hardware SSL acceleration.
  • The BIG-IP system is processing a single SSL transfer through an SSL profile associated with a virtual server.

When multiple SSL transfers are processed simultaneously, performance is normal.

Impact

SSL throughput is impaired.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H487654 on the Diagnostics > Identified > Low screen.
  • SSL throughput is lower than expected.
