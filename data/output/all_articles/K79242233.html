K79242233: Config import fails when first character for policy or policy rule start with numerical

Type
Support Solution
Published
2020-12-29
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K79242233

Description

Config import of BIG-IP config to BIG-IQ fails when first character for local traffic policy or policy rule starts with a numerical character.

  • BIG-IQ will error similar to:
    Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Property 'name' value '1-example-policy-name' first character is not in the allowed set of characters 'a-zA-Z_' (white space is invalid).

Environment

  • Importing local traffic policy
  • Managing BIG-IP config with BIG-IQ

Cause

BIG-IQ config validation bug ID 818313 Import fails when first character for policy or policy rule start with numerical

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Rename all local traffic policies and policy rules so they no longer start with a numerical charecter
  2. Re-import the config to BIG-IQ
