Known Issue

BIG-IP session data may not be retained after a failback event.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP systems are configured for high availability (HA).
  • The BIG-IP systems are configured to mirror session data.
  • The active system (unit 1) fails over to the standby system (unit 2), then a failback event occurs causing unit 1 to become active again.

Impact

Missing session data from the sessiondb database following a failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Missing APM (or other modules) session data from the sessiondb database following a failover.
  • User sessions to the BIG-IP APM system are disconnected after a failover event.
  • BIG-IP Edge Client is unable to resume network access sessions after a failover event.
  • Connections may not function as expected following a failover.
