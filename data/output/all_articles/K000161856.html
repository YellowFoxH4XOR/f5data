K000161856: AS3 POST declaration with ASM throws : [fatal] Malformed XML: HASH(0x11efb760)"

Published

Applies to

Source

1. Description

When deploying an ASM (WAF) policy using F5 Application Services 3 Extension (AS3), the import may fail with errors such as "Malformed XML" or "The security policy file does not conform to the schema and cannot be imported." The error may appear in the AS3 response or BIG-IP logs, and can include messages like:

  • "Malformed XML: HASH(...)"
  • "Import policy failed. Messages: [warning] Security policy version information will be ignored, since the file has been modified since it was exported. [fatal] Malformed XML: HASH(...)"
  • HTTP 422 or 500 errors during AS3 declaration POST

These errors can occur even if the ASM policy XML file is valid and can be imported manually.


2. Environment

  • BIG-IP ASM (WAF) module
  • AS3 (Application Services 3 Extension)
  • Policy import via AS3 declaration (JSON)
  • WAF_Policy object referencing an ASM policy XML file (local or remote URL)

3. Cause

  • The WAF_Policy object name in the AS3 declaration does not exactly match the exported ASM policy name.


4. Answer/Recommended Actions

  • Ensure the WAF_Policy object name in your AS3 declaration matches the exported ASM policy name exactly. i.e. in this format : Common_test-policy__2026-5-28_14-59-32__bigip-hostname.xml.

"test-policy": { => this is what the policy would be named as on the GUI

"class": "WAF_Policy",

"file": "/var/tmp/asm_pol/Common_test-policy__2026-5-28_14-59-32__bigip-hostname.xml"

}


  • Check the total path length: The combined character length of tenant name + application name + item name (plus 3 slashes) must be less than or equal to 195 characters.
  • If the path length exceeds 195 characters, shorten the names of the tenant, application, or item in your AS3 declaration.


5. Additional Information

  • The object key name used for the WAF_Policy class in the AS3 declaration becomes the deployed policy name on BIG-IP, regardless of the exported XML filename or original policy name.
