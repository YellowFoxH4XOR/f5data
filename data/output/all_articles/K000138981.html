Description

Unable to attach an ASM Security Policy to a Virtual Server, either from the Page "Security ›› Overview : Summary", or even as a direct attachment to the Virtual Server under the Page "Local Traffic  ››  Virtual Servers : Virtual Server List  ››  VS_NAME  ›› Security ›› Policies".

 

When you try to attach the Security Policy under "Security ›› Overview : Summary", there is no same Virtual Server as desired listed here. Also, when trying to attach the Security Policy under "Local Traffic  ››  Virtual Servers : Virtual Server List  ››  VS_NAME  ›› Security ›› Policies", there is no option for "Application Security Policy" to choose the Security Policy.

 

Environment

BIG-IP ASM Module configured with Security Policy to be attached to a Virtual Server.

Cause

To attach an ASM Security Policy to a Virtual Server, you must assign an HTTP Profile to the same VS. Then, you can normally list the Virtual Server for Security Policy attachment, or directly attach the Security Policy to the same VS.

 

Recommended Actions

Follow below steps to assign an HTTP Profile to the Virtual Server:

  1.  Login to BIG-IP GUI
  2.  Navigate to Local Traffic > Virtual Server > VS_NAME > Properties > Configuration > HTTP Profile
  3.  Choose your desired HTTP Profile and click on Update
  4.  Now, you are able to either list the Virtual Server, or directly attaching the Security Policy to this VS
