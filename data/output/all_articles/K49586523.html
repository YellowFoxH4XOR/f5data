Description
You want to modify the host key algorithms used by the ssh server (sshd) on the BIG-IP. The ssh server's host key is how it identifies itself to clients. The BIG-IP has several host keys of different types. When modifying the host key algorithms ensure that you choose a key type that is included on the BIG-IP system. The host keys are stored in the /config/ssh directory.

Environment

BIG-IP versions that run OpenSSH 7.4p1, such as BIG-IP 13.1.4, 14.1.x, 15.x.x and 16.x.x
Note: For information about third-party software versions included on each BIG-IP version, refer to the BIG-IP third-party software matrix article relevant to your version in the Related Content section below.
Note: HostKeyAlgorithms were introduced in OpenSSH 7.0
Note: If you have Big-IP DNS Devices performing this can cause the bigip_add command to fail.  To keep this from happening please follow the instructions in K000137443: Modifying the host key algorithms used by the ssh client on DNS.

Cause
None

Recommended Actions
Follow the steps below to add the keyword HostKeyAlgorithms using the include statement via tmsh command (which is similar to K80425458: Modifying the list of ciphers and MAC and key exchange algorithms used by the SSH service on the BIG-IP or BIG-IQ systems for modifying ciphers, MAC and KEX algorithms)

  1.  Log into tmsh by typing the following command:

    tmsh

  2.  To modify the sshd configuration, type the following command to start the vi editor:

    edit /sys sshd all-properties

  3. To modify the list of host key algorithms, enter the keyword HostKeyAlgorithms with the include statement, and add the list of host key algorithms you want the BIG-IP ssh server to use similar to the following example:
    include "HostKeyAlgorithms ssh-rsa,rsa-sha2-512,rsa-sha2-256,ssh-ed25519"

    If your configuration already has the include statement to modify other algorithms such as Ciphers, MACs and KEX algorithms, then the include statement would look like:

    include "Ciphers aes128-gcm@openssh.com,aes256-gcm@openssh.com,aes128-ctr,aes192-ctr,aes256-ctr,chacha20-poly1305@openssh.com
    MACs hmac-sha2-256-etm@openssh.com,hmac-sha2-512-etm@openssh.com,umac-128-etm@openssh.com
    KexAlgorithms diffie-hellman-group18-sha512,diffie-hellman-group14-sha256,curve25519-sha256@libssh.org,diffie-hellman-group16-sha512
    HostKeyAlgorithms ssh-rsa,rsa-sha2-512,rsa-sha2-256,ssh-ed25519"
  4. Save the changes and exit the vi editor by typing the following:
    :wq
  5. Respond y to the prompt asking to save the changes.
  6. Save the configuration by typing the following command:

    save /sys config 

    Note: You do NOT need to restart sshd. The BIG-IP system automatically restarts it when you save the edit.
  7. Check the configuration by typing the list command:

    list /sys sshd all-properties

    For example:

    root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)# list /sys sshd all-properties
    sys sshd {
        allow { ALL }
        banner disabled
        banner-text none
        description none
        fips-cipher-version 0
        inactivity-timeout 0
        include "HostKeyAlgorithms ssh-rsa,rsa-sha2-512,rsa-sha2-256,ssh-ed25519"
        log-level info
        login enabled
        port 22
    }
