Known Issue

Enterprise Manager device discovery may fail when the system does not have access to the activate.f5.com host.

This issue occurs when the following conditions are met:

  • Enterprise Manager is configured to use DNS to resolve hostnames.
  • Enterprise Manager does not have access to the appropriate F5 service hosts through your network security infrastructure.

F5 recommends that Enterprise Manager has access to several F5 hosts to perform administrative functions such as reactivating device licenses, updating attack signatures, and providing data to F5 Technical Support. For more information, refer to K10349: Enterprise Manager may require network access to certain F5 hosts.

Impact

Enterprise Manager may be unable to discover and manage BIG-IP devices.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Enterprise Manager may be unable to discover devices.
  • Enterprise Manager logs error messages to the /var/log/em file that appear similar to the following examples:

    emdeviced[11788]: 04010568:3: Error found on device <device_name> (UID: 0): getModuleInfo: iControl error: 'iControl::char*:SOAPException: 'Error writing to secure socket  ''

    emdeviced[11788]: 04072112:3: Could not get device information for address: <device_ip> Failed to Retrieve Device Information.

Workaround

To work around this issue, you can allow Enterprise Manager to access the appropriate F5 service hosts through your network security infrastructure. If it is not possible to allow Enterprise Manager to access F5 service hosts through your network, you can remove the DNS servers from the Enterprise Manager configuration. To do so, perform the following procedure:

Removing DNS servers from the Enterprise Manager configuration

Impact of workaround: Any Enterprise Manager functionality that requires DNS resolution will fail if DNS servers are not configured.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Device.
  3. Click DNS.
  4. For DNS Lookup Server List, remove the DNS servers.
  5. Click Update.
