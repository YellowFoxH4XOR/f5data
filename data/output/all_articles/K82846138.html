Description

If an attack signature is in staging, what will happen to the attack signature after the Enforcement Readiness Period?

Note: The Enforcement Readiness Period (ERP) is 7 days by default.

Environment

  • Security Policy
  • Attack signatures

Cause

None

Recommended Actions

None

Additional Information

The state of the signature(s) after the Enforcement Readiness Period when using Signature Staging will depend on whether you are using automatic learning mode.

With learning mode disabled or manual mode:

  1. The signature starts in staging, violations may occur but requests are not blocked.
  2. If there are violations for the signature, the system may generate a learning suggestion to disable it.
  3. If no violations occur during the ERP, the signature remains in staging, but there will be an indicator that it is ready to be enforced. Violations will continue to occur but requests still won't be blocked.
  4. The signature must then be manually enforced.

With learning mode automatic:

  1. The signature starts in staging.
  2. If no violations occur during the ERP, the system will automatically enforce the signature.
  3. If there are violations, the system may not enforce the signature and may disable it, depending on how the system classified the violation.
    • The ASM system generates learning suggestions and corresponding scores for violations. The learning score measures the strength of the learning suggestion for a specific violation by showing a percentage that indicates how close the system is to recommending that you accept the suggestion. In these cases it is helpful to examine the details of the request that caused the violation so that you can determine whether it is a false positive or the violation was caused by an attack.

Both scenarios depend on the policy processing a sufficient amount of traffic / requests. If little traffic is seen, the signature may stay in staging even when using automatic learning. Conversely if a lot of traffic is seen with automatic learning mode, the policy may tighten / stabilize sooner.
