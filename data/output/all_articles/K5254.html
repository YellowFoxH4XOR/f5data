Known Issue

This is most likely the result of a known issue. The 3dnsd process will crash if you configure a BIG-IP and 3-DNS combination system as an active-active redundant pair, and then change either the BIG-IP or 3-DNS self IP address under all of the following circumstances:

  • You make the configuration changes using the Configuration utility.
  • The Unit 2 self IP address are already configured for both BIG-IP and 3-DNS.
  • The Unit 2 self IP addresses for BIG-IP and 3-DNS are different, most likely due to incorrect user input.
  • You change one of the Unit 2 self IP addresses so that the BIG-IP and 3-DNS self IP addresses match.

When all of these conditions are met, 3-DNS reports a parse error and 3dnsd crashes.

F5 Networks Product Development tracked this issue as CR23287.

Workaround

To work around this issue, use the command line to change the self IP addresses.
