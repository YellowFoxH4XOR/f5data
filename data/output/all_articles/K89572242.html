K89572242: Oldest APM logs on BIG-IQ are 90 days back

Type
Support Solution
Published
2022-08-26
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K89572242
Description

When applying a filter to display APM logs on BIG-IQ the oldest available logs are 90 days back from the current date.
Retention policy settings for APM statistics and logs set for longer than 90 days does not change the behavior.

Environment

BIG-IQ with APM device(s) discovered.

Cause 

This is working as expected.

Recommended Action

None.

Additional Information

None.
