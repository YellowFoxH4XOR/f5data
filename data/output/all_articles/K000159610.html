Description

After upgrading a BIG-IP HA cluster from version 15.1.8.2 to 15.1.10.8, the bd (Bandwidth Controller daemon) process and multiple bd_io_plug processes crashed repeatedly as traffic increased, causing continuous failovers between HA peers. The system logged "HA proc_running bd fails action is go offline and down links" errors, forcing to roll back to the previous version.

Environment

  • Using v15 release with the fix from ID1677905
  • BD process

Cause

ID2135705

Answer/Recommended Actions

Please request the Engineering Hotfix for the ID2135705.
