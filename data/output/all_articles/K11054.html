Topic

RSA SecurID is a two-factor authentication scheme that uses a combination of a known password and a digitally generated string to grant access to the FirePass controller. To configure RSA SecurID authentication on a FirePass controller using RSA Authentication Manager version 7.1, perform the following three procedures:

  • Configure the Authentication Agent on the RSA server
  • Generate and download the RSA configuration file
  • Configure RSA SecurID authentication on the FirePass controller

Configure the Authentication Agent on the RSA server

Important: These instructions are an example using RSA Authentication Manger version 7.1. Reference your vendor's documentation for instructions specific to the software you are running

  1. Log in to the RSA Security Console.
  2. Navigate to the Access tab: Authentication Agents: Add New.
  3. Under Authentication Agent Basics, enter the hostname and self-IP address of the FirePass controller.

    Note    : If you have deployed a FirePass Cluster and/or Failover configuration, be sure to enter all appropriate self-IP addresses of the FirePass nodes that will be authenticating with the RSA server in the Alternate IP Addresses field.
  4. Once you have properly configured all appropriate attributes, click Save.

Generate and download the RSA configuration file

Important: These instructions are an example using RSA Authentication Manger version 7.1. Reference your vendor's documentation for instructions specific to the software you are running

  1. Log in to the RSA Security Console.
  2. Navigate to the Access tab: Authentication Agents: Generate Configuration File.
  3. Click on the Generate Config File button.
  4. Under Download File, click on Download Now.

    Note: The configuration file will be in .zip format. You must unzip the file in order to get to the actual configuration file.

Configure RSA SecurID authentication on the FirePass controller

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Configuration: RSA SecureID page.
  3. In the Name field, enter a name to identify your RSA server.
  4. In the Configuration File field, browse to the RSA configuration file downloaded in Step 4 of the Generate and download the RSA configuration file procedure.

    Note: You must point to the actual RSA configuration file inside the .zip file.
  5. In the Source IP field, enter the IP address you configured for the Network address setting on the RSA authentication server.

    Important: RSA authentication will not work unless the IP address you enter in this field matches one of the IP address(es) configured in Step 3 of the Configure the Authentication Agent on the RSA server procedure.
  6. Click the Add button.
  7. Navigate to the Users: Groups: Master Groups page.
  8. Click the Create new group button.
  9. In the New group name field, enter the name of the new master group.
  10. In the Users in group field, select Local or External.
  11. In the Authentication Method menu, select RSA SecurID.
  12. Click the Create button.

    Note: This step brings you to the master group configuration page.
  13. Click the Authentication tab.
  14. Under Configure RSA SecurID Server Settings, select the RSA configuration profile that you created in Step 3 of this procedure.
  15. Click the Update button.

The FirePass controller is now configured for RSA SecurID authentication.
