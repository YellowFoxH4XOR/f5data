Known Issue

The Configuration utility may not display expected Virtual Local Area Network (VLAN) fail-safe actions.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured for high availability (HA).
  • You attempt to enable VLAN fail-safe for the Failover action.

Impact

The Failover action is not listed in the action menu. 

Note: This issue is cosmetic, and the common.ha.FailOver action is the Failover action.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to configure VLAN fail-safe for the Failover action, the action menu contains only the following options:

    • Reboot
    • Restart All
    • Restart TM
    • common.ha.FailOver

Resolution

Status

F5 Product Development has assigned ID 460863 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can select the common.ha.FailOver action.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
