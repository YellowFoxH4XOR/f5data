Description

Installation of BIG-IP software fails with archive read or checksum error.

show /sys software
--------------------------------------------------------
Sys::Software Status
Volume  Product  Version   Build  Active  Status
--------------------------------------------------------
HD1.1    BIG-IP   15.1.3  0.0.11     yes  complete
HD1.2      none     none    none      no  failed (archive read or checksum error)

Manual md5sum results in Input/output error:

# md5sum /shared/images/BIGIP-15.1.5.1-0.0.14.iso
md5sum: /shared/images/BIGIP-15.1.5.1-0.0.14.iso: Input/output error
 

Environment

  • BIG-IP VE
  • Upgrade
  • Unable to read image file

Cause

Either the image file is corrupt or is caused by disk errors

Recommended Actions

  1. Copy image file from known good source
  2. Check /var/log/kern.log for any sign of disk errors

Additional Information

Log messages indicating disk errors in /var/log/kern.log:

err kernel: blk_update_request: I/O error, dev sda, sector 3546048
err kernel: Buffer I/O error on dev dm-1, logical block 310549, lost async page write
