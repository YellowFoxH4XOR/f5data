Known Issue

This is the result of a known issue. If a user mounts an NFS share on a direct volume, the user may receive an input/output error when attempting to access the mounted directory. For example:

$ cd /mnt/arx/share1
-bash: cd: /mnt/arx/share1: Input/output error
 
This issue occurs when the NFSv2 UDP is disabled on the back-end filer.

Note: Direct volumes are referred to as presentation volumes in the ARX GUI.
 
F5 Networks Product Development tracked this issue as ARX ID 34771 and it was fixed in ARX versions 3.2.3, 4.1.1 and 5.0.1. For information about upgrading, refer to the ARX Release Notes.

Additionally, this issue has been fixed in a hotfix available for ARX version 3.2.2. Customers affected by this issue should request the hotfix from F5 Networks Technical Support, referencing this Solution number and ARX ID 34771.
