Known Issue

This is the result of a known issue. The BIG-IP GTM UDP monitor marks the resource down if no reply is received in response to the monitor request. For example, if the UDP monitor is configured with a 5 second interval and 15 second timeout, the resource is marked down if no reply is received within the 15 second timeout period.

The BIG-IP GTM UDP monitor is not intended to mark the resource down when no reply is received in response to the monitor request. The UDP monitor should only mark the resource down when an ICMP Destination Unreachable message, such as ICMP host unreachable or ICMP port unreachable, is received from the server.

Note: BIG-IP LTM UDP monitors also require an ICMP Destination Unreachable response before a node is marked down. For more information, refer to K6143: UDP health monitor operation.

Note: For information about a related issue regarding the BIG-IP GTM UDP monitor, refer to K9187: The BIG-IP GTM UDP monitor does not time out.

F5 Product Development tracked this issue as CR122518 and it was fixed in BIG-IP GTM 9.4.8 and 10.1.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
