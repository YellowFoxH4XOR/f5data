Known Issue

A Traffic Management Microkernel (TMM) under heavy memory pressure may send a SIGABRT signal and restart.

This issue occurs when the following condition is met:

  • Memory allocation (vmem_alloc) for a TMM, under heavy memory pressure, takes excessively long and causes a TMM heartbeat failure.

The method used to locate and allocate memory to the TMM may continue searching after a suitable block of memory has already been located. As a result, the memory allocation function may take excessively long and cause a TMM heartbeat failure.

Impact

A TMM under memory pressure may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H478801 on the Diagnostics > Identified > High screen.
  • Your BIG-IP system experiences degraded performance.
  • Repeated TMM SIGABRT cores occur during the vmem_alloc function.
  • The system temporarily fails to process traffic while TMM restarts.
