Issue

Previously, when configuring a Web Application Tunnel, you could only enter a URL starting with http:// or https://.

Starting in FirePass 6.0.3 and in FirePass 6.0.2 with Cumulative Hotfix HF-602-1, when configuring a Web Application Tunnel, you can now also enter a URL starting with ftp://. This change in behavior allows users to access FTP resources through a Web Application Tunnel.

Note: Web Application Tunnels are configured on the Application Access > App Tunnels > Resources page under the Web Application Tunnels tab.

Important: Passive mode (PASV) FTP is the default FTP mode used by most modern web browsers. To allow passive mode FTP through the Web Application Tunnel, ensure that you specify port 21 and ports 1024 through 6553 in the Allow List field when configuring the Web Application Tunnel.

For example:

ftp.siterequest.com:21,1024-65535

F5 Networks Product Development tracked this enhancement as CR89614 and it was included starting in FirePass 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-1 has been issued for FirePass 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
