Description

  • You want to know if there is a way to force NGINX Ingress Controllers to accept HTTP/1.0 request

Environment

  • NGINX Ingress Controller
  • NGINX Plus
  • HTTP

Cause

  • None

Recommended Actions

  • NGINX Ingress Controller, by default, process HTTP 1.0 request but responds with HTTP/1.1 response

Additional Information

  • The expected behavior for HTTP/1.0 requests by NGINX is to respond with HTTP/1.1
    • This is by design, which adheres to HTTP Protocol RFC 2145.
    • RFC 2145 states that, "An HTTP server MUST NOT send a version for which it is not at least conditionally compliant",
    • In other words, NGINX Plus returning HTTP/1.1 to a client sending an HTTP/1.0 request is compliant of the protocol and expected behavior.
    • This, in turn, mean that NGINX does not have a directive to affect this behavior
    • Hence, it is not possible to take any additional action to influence the default NGINX behavior.
    • Moreover, this behavior, as stated above and shown below, is part of the NGINX Plus design, which is the engine behind NGINX Ingress Controller.
    • Here you find how NGINX process version response
                                          /* "HTTP/1.x " */
                                    b->last = ngx_cpymem(b->last, "HTTP/1.1 ", sizeof("HTTP/1.x ") - 1);
