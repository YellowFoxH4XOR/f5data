K3777: Addresses used by discovery and automatic configuration

Topic

Automatic configuration will learn all configured self IP addresses for a BIG-IP, but it will only use those that are members of the same network as a default gateway on the BIG-IP. The default gateway can be an individual, static gateway, or a member of a default gateway pool.

If the BIG-IP uses multiple self IP addresses on different networks, but each address matches a gateway defined in a default gateway pool, each self IP will be configured on 3-DNS, and 3-DNS will communicate with BIG-IP using the first configured self IP address.

For example, if BIG-IP is configured with an individual default gateway of 172.16.100.10 and has self IP addresses of 172.16.100.101 on a /24 network and 172.16.102.101 on a /24 network, only the 172.16.100.101 self IP would be added to the 3-DNS configuration.

Alternatively, if BIG-IP is configured with a default gateway pool that contains default gateways of 172.16.100.10 and 172.16.102.101, both self IPs would be added to the 3-DNS configuration.
