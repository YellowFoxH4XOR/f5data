Known Issue

This is the result of a known issue. If a Web Application Webtop is directed to a website that contains JavaScript, the reverse proxy engine may fail to properly rewrite the JavaScript information, which could prevent the web page from loading completely. Additionally, the system may generate a JavaScript error that appears similar to the following example:

JS error
Line 12
Char 1 'document' null or not an object

F5 Product Development tracked this issue as ID 225668 (formerly CR139913) and it was fixed in BIG-IP 10.2.2. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
