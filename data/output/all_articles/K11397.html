Known Issue

This is the result of a known issue. The asmqkview script automatically collects configuration information from BIG-IP ASM systems and outputs a diagnostic file called asm_snapshot.<hostname>.tar.gz to the /shared/tmp directory. The asmqkview script does not collect files from the /ts/etc/* directory. As a result, the replication.ini and services.ini files are not included in the asm_snapshot file.

Note: For more information, refer to K6824: Overview of the asmqkview script.

Note: The replication.ini file contains the setting for enabling MySQL replication.

F5 Product Development tracked this issue as CR121288 and it was fixed in BIG-IP ASM 10.1.0 and 9.4.8. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
