Known Issue

The BIG-IP APM rewrite profile may process the window.onerror handler incorrectly.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The window.onerror handler is assigned a value in an empty window.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use portal access, requested pages that include the window.onerror handler fail to display.
  • The browser error console displays a message that appears similar to the following example:

    Message: Not implemented
