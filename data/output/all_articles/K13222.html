Issue

This article applies to BIG-IP versions 10.x and 11.x. For information about other versions, refer to the following article:

  • K7175: Error Message: Trunk resources exhausted

Error Message

mcpd[<pid>]: 0107071c:3: Trouble allocating mac address for trunk (<name>)

In this error message, note the following:

  • <pid> is the process ID
  • <name> is the name of the affected trunk

For example:

mcpd[5278]: 0107071c:3: Trouble allocating mac address for trunk (t24)

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Network > Trunks > Trunk List > New Trunk page in the Configuration utility
  • The Traffic Management Shell (tmsh)
  • The SSH console
  • The serial console

Description

This message occurs when all of the following conditions are met:

  • The number of trunks configured on a BIG-IP system has reached the platform's maximum configurable trunks
  • You attempt to create a new trunk on the BIG-IP system

For more information about the maximum configurable trunks for your BIG-IP system, refer to K7174: The maximum number of user configurable trunks for the BIG-IP system.

Impact

No new trunks can be created.

Recommended Actions

If you would like to replace an existing trunk configured on the affected BIG-IP system with a new trunk, you must remove the existing trunk before configuring the new trunk. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Trunks > Trunk List.
  3. Check the name of the existing trunk you would like to replace.
  4. Click Delete to remove the selected trunk.
  5. Click Delete to confirm the removal.
  6. Click Create to initiate the process of creating a new trunk.
  7. Type the name of the new trunk in the Name box.
  8. Select the appropriate interfaces and move them to the Members box by clicking <<.
  9. Configure the options, such as LACP, Link Selection Policy and Frame Distribution Hash, that are appropriate for your environment.
  10. To save the changes, click Finished.
