K26851094: Support for F5 SSL Orchestrator on the VELOS platform

Type
Support Solution
Published
2021-11-02
Updated
2024-06-04
Applies to
  • VELOS Platforms
  • F5 App Protect
  • F5 SSL Orchestrator: 17.1.0, 15.1.9, 15.1.2, 15.1.0, 15.1.X, 15.1.1
Source
https://my.f5.com/manage/s/article/K26851094

Description

The following F5 SSL Orchestrator version is supported to run on the VELOS platform as a BIG-IP tenant:

  • 17.1.0 - 11.0
  • 15.1.x-7.x

    Note: Only BIG-IP 15.1.4 and later for the BIG-IP 15.x branch is supported on the VELOS platform. Earlier versions of the BIG-IP 15.x branch is not supported on the VELOS platform. As a result, you must run your F5 SSL Orchestrator on BIG-IP 15.1.4 or later.

Environment

  • F5 SSL Orchestrator 17.1.0 - 11.0
  • F5 SSL Orchestrator 15.1.x-7.x
  • BIG-IP 15.1.4 and later
  • VELOS platform (CX410/BX110)

Cause

None.

None.
