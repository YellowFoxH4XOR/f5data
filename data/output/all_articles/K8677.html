K8677: The BIG-IP WebAccelerator 4500 platform requires BIOS update to use additional available memory

Topic

When installing a BIG-IP WebAccelerator version 9.4.x on a WebAccelerator 4500 platform, it may be necessary to upgrade the BIOS in order to use additional available memory.

The WebAccelerator 4500 platform should be using BIOS Revision WA4500 OBJ-0205-02 RevA, which allows the system to access all of the available memory. However, some older WebAccelerator 4500 platforms may be using a BIOS Revision WA4500 OBJ-0205-01 06-02-06, which will only allow the system to access 2.987 GB of memory.

Note: For information about upgrading the BIOS on the WebAccelerator 4500 platform, refer to the Downloading the firmware and software section of the Migrating from version 5.2 to version 9.4.3 on the WebAccelerator 4500 Platform guide. For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Verify the BIOS Revision and amount of memory for your WebAccelerator 4500 platform by typing the following command:
bigpipe platform
