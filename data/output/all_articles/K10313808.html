Description

You observe in the system graphs that the datasyncd obfuscator process runs for much longer than the expected 3-4 hours.

The normal operation of the process is explained in:

  • K02827102: BIG-IP ASM and BIG-IP FPS systems experience higher CPU usage for several hours per day

Environment

  • ASM or FPS provisioned

Cause

This is expected under certain conditions. The obfuscation task requires a set amount of CPU cycles. If there is contention from other CPU-intensive processes, the task can take longer.

The task can also take longer after an upgrade or reboot.

Recommended Actions

If datasyncd's obfuscation task takes an abnormally long time, and you cannot see any other processes consuming CPU time, open a service request with F5 Support for further investigation.

Additional Information

The java process spawned by datasyncd is niced so is generally expected to cause minimal impact to other processes.
