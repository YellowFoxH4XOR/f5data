K000135607: SWG URL categories failing to load after upgrade to later than 15.1.9

Type
Support Solution
Published
2023-08-29
Updated
2025-11-25
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1, 17.1.2, 17.1.3, 16.1.5, 16.1.6, 15.1.10, 15.1.6, 15.1.5, 15.1.4, 15.1.0, 15.1.9, 15.1.3, 15.1.2, 15.1.1, 15.1.8, 15.1.7
Source
https://my.f5.com/manage/s/article/K000135607

Description

You have upgraded to 17.1.1, 16.1.4.2. or 15.1.9 or newer and your config fails to load during system boot, with similar SWG URL Categories error messages such as these:

Configuration error: In url-filter (/Common/filter-name), allowed-category (/Common/Society_and_Lifestyles) does not exist. In url-filter (/Common/filter-name), allowed-category (/Common/Non-Traditional_Religions) does not exist. In url-filter (/Common/filter-name), allowed-category (/Common/Traditional_Religions) does not exist. In url-filter (/Common/filter-name), allowed-category (/Common/Gay_or_Lesbian_or_Bisexual_Interest) does not exist. In url-filter (/Common/filter-name), confirmed-category (/Common/Illegal_or_Questionable) does not exist.

 

Environment

  • BIG-IP
  • SWG Module Provisioned
  • URL Filter Category List object configured.

Cause

There have been a series of related issues, not limited to:

  • Bug ID 1398401
  • Bug ID 1566893

 Recommended Actions

  1. Boot back to the previous BIG-IP version.
  2. Delete the configured URL-Filter Category List objects.
  3. Perform the upgrade again, and the new configuration will be reloaded.

or, while in the failed version.

  1. Edit the bigip.conf file manually. This removes the invalid categories from the file.
  2. Start a cli with bash

    #  Save the config  just in case.
    cp /config/bigip.conf   /var/tmp

    sed -i 's/\/Common\/Illegal_or_Questionable//g'  /config/bigip.conf
    sed -i 's/\/Common\/Non-Traditional_Religions//g'  /config/bigip.conf
    sed -i 's/\/Common\/Society_and_Lifestyles//g'  /config/bigip.conf
    sed -i 's/\/Common\/Traditional_Religions//g'  /config/bigip.conf
    sed -i 's/\/Common\/Gay_or_Lesbian_or_Bisexual_Interest/\/Common\/LGBTQIA/g'  /config/bigip.conf
  3. tmsh load sys config

Note: As of June 2025, no fix is available.

Additional Information

  • Affected URL-Filter Category List objects include:

    /Common/Non-Traditional_Religions
    /Common/Traditional_Religions
    /Common/Society_and_Lifestyles
    /Common/Gay_or_Lesbian_or_Bisexual_Interest 
    /Common/Illegal_or_Questionable
