Description

 

The message "Vlan allowed mismatch found"  logged in tenant /var/log/ltm when the partition and tenant are configured with the different VLAN name.

 

Environment

 

  • Tenant
  • Partition and tenant configured with the difference VLAN name

 

Cause

VLAN names difference setup on velos partition versus VLAN name on tenant,  the VLAN tag ID are the same.

 For example,

VLAN name on Velos partition is V-4093 and tag 4093 

VLAN name on tenant is /Common/VLAN-4093 and tag 4093

and tenant produce the following log message :-  /var/log/ltm :
01071322:4: Vlan allowed mismatch found hypervisor (V-4093: 4093), guest (/Common/VLAN-4093: 4093).



Recommended Actions
No action is required. This log message is benign. If you want to avoid this log message:

  1. Configure tenant VLANs to match the partition VLAN name.
