K000158926: Cannot login with "admin" after tmsh load sys config default

Description

After restoring the default configuration on an Azure-deployed BIG-IP VE instance using the load sys config default command, and you are not able to log in with commonly expected default credentials (such as admin/admin or admin/default). 

 

Environment

BIG-IP LTM Virtual Edition 

 

Cause

The inability to log in was due to the absence of a default password for the admin account after restoring the default configuration on a BIG-IP VE instance. The admin password must be manually set during deployment or via CLI; default credentials are not assigned or restored by the load sys config default command.

 

Recommended Actions

Log in to the device using the root account via SSH or console access.

Run the following command to set a new password for the admin account:

tmsh modify auth user admin prompt-for-password

Save the configuration with:

tmsh save sys config

Ensure that the new admin password is securely stored for future access.
