K12088: Microsoft Windows Vista and Windows 7 will fail to launch a network access tunnel in a Protected Workspace if User Account Control is disabled and client components are not previously installed

Known Issue

The security system of Windows Vista or Windows 7 blocks the installation of the F5 client components. As a result, when you attempt to access a network access tunnel through a Protected Workspace with the Windows User Account Control (UAC) disabled, and the client components are not installed, you will receive an error message that appears similar to the following example:

Status: Network Access Connection Device was not found

F5 Product Development tracked this issue as ID 341456 for BIG-IP and was fixed in version 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

F5 Product Development is tracking this issue as ID 340680 for FirePass.

This issue has been fixed in cumulative hotfix HF-70-2, which has been issued for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about downloading software from F5, refer to SOL167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

You can work around this issue by manually installing the FirePass client component package before logging into the FirePass controller.

Note: For more information about installing the FirePass client components, refer to the FirePass Controller Administrator Guide.

Note: For an overview of the FirePass client components refer to K10407: The FirePass client components.
