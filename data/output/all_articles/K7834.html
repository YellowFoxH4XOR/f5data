K7834: PVA acceleration status will be demoted to assist for virtual servers that reference a pool with pool members that are shared across other pools

Topic

The Packet Velocity ASIC (PVA) can operate in the following three modes on BIG-IP LTM systems to accelerate load-balanced traffic:
  • Full Acceleration (Full)
  • Partial Acceleration (Assist)
  • No Acceleration (None)

If you associate your FastL4 virtual server with a pool containing pool members that are shared across other pools, or configure two or more virtual servers to reference the same pool, the PVA acceleration status for the virtual server(s) will change from full to partial acceleration. For example, if you associate the FastL4 virtual server with Pool-A, and Pool-B also exists on the system, PVA acceleration status for the FastL4 virtual server will change to partial acceleration because Pool-A and Pool-B share member 10.1.1.2:http.

For example:

pool Pool-A {
members
10.1.1.1:http
10.1.1.2:http
}

pool Pool-B {
members
10.1.1.100:http
10.1.1.2:http
}

This behavior is by design and is intended to prevent a TMM traffic flow and full PVA flow from using the same client-side ephemeral port.

Note: A pool member is defined as the combination of IP address and service port, while a node is defined as an IP address. Associating your FastL4 virtual server with a pool containing nodes that are shared across other pools does not affect PVA acceleration as long as the IP address and port are not common between pools.

You can change this behavior by performing one of the following two procedures:

Important: By changing this behavior you may experience a rare occurrence of a TMM traffic flow and full PVA flow using the same client-side ephemeral port.

Version 10.x

  1. Log in to the BIG-IP LTM command line.
  2. To change the PVA flow enforcement policy, type the following command:

    tmsh modify /sys db pva.flowkeyspace.enforce value disable

  3. To save the changes made to the bigpipe db database, type the following command:

    tmsh save /sys config

  4. To restart the pvad process, type the following command:

    bigstart restart pvad

Version 9.x

  1. Log in to the BIG-IP LTM command line.
  2. To change the PVA flow enforcement policy, type the following command:

    bigpipe db Pva.FlowkeySpace.Enforce disable

  3. To save the changes made to the bigpipe db database, type the following command:

    bigpipe save all

  4. To restart the pvad process, type the following command:

    bigstart restart pvad

Note: For more information about PVA Acceleration features, refer to K4832: Overview of Packet Velocity ASIC (PVA) Acceleration features and subfeatures.
