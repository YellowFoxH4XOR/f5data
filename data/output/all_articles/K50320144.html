K50320144: Using the BIG-IP ASM system to search request event logs by support ID may fail to locate the associated event violation

Type
Known Issue
Published

Updated

Applies to

Source

Known Issue

When you use the BIG-IP ASM system to search request event logs by support ID, your search may fail to locate the associated event violation.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to search the BIG-IP ASM application event request logs by support ID.
  • The support ID contains less than 19 digits. 

Impact

You are unable to find the associated request violation event.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you search for a request violation event using a support ID with less than 19 digits, the search does not return the event.
  • When you search the request violation event logs using the last four digits of the support ID, the search is successful.

Workaround

To work around this issue, you can search the BIG-IP ASM application event request logs using the last four digits of the support ID. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure may return multiple matching events.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Event Logs > Application > Requests.
  3. Click the Show Filter Details link.
  4. Locate the Support ID section and select Last 4 digits.
  5. Enter the last four digits of the support ID in the support ID text box.
  6. Click Go.
