Description

You want to request for Admin access for accounts that consists of Pre-Licensed images setup for hourly billing customers.

 

Environment

  • AWS - Hourly Pre-Licensed Images
  • AWS IC Marketplace
  • Azure - Hourly Pre-Licensed Images
  • Azure Marketplace
  • Google Cloud Platform
  • Google Marketplace
  • Alibaba
  • MyF5 Portal

 

Cause

All customers are only given Basic rights for Pre-Licensed Images Account as there are many customers hosted on such accounts. 

 

Recommended Actions

Admin rights can be given only for your company accounts with approval from your F5 Account team, Marketplace accounts can not be given elevated rights.
