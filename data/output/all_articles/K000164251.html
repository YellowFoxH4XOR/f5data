Description

After deploying a BIG-IP tenant on an rSeries system, the BIG-IP login page may not immediately display the password-change prompt, which can be mistaken for a tenant initialization failure.

Environment

F5OS-A rSeries BIG-IP tenant deployment. The tenant is running, and access is through the tenant’s configured management IP using HTTPS or SSH.

Cause

F5OS host authentication and BIG-IP tenant authentication are separate. The rSeries administrator account manages the F5OS appliance and tenant deployment but does not initialize the BIG-IP tenant. The password-change prompt appears after authenticating with the default BIG-IP tenant credentials.

Answer/Recommended Actions

  1. Confirm that the tenant status is Running in the F5OS-A WebUI.
  2. Connect to the tenant’s configured management IP, not the rSeries management IP.
  3. Access the tenant through HTTPS or SSH.
  4. Authenticate using the default BIG-IP tenant credentials: admin/admin.
  5. Complete the BIG-IP admin password-change prompt and initial setup wizard.

Additional Information

The absence of password fields in the F5OS tenant-deployment configuration is expected. Deleting and recreating the tenant does not resolve the separate F5OS and BIG-IP authentication processes.
