Description

You need to terminate a license key via the MyF5 Self Service for Flexible Consumption Program (FCP). This key isn't needed anymore and you need to stop its billing. 

Environment

  • New FCP Contract

  • BIG-IP Virtual Edition (VE)

  • MyF5 Customer Portal

  • Editor/Admin access to MyF5 Subscription

Cause

Starting in January 2025, new FCP customers can terminate license keys via the MyF5 Customer Portal.

Recommended Actions

This process is only if you no longer need this license key and want to end its billing. If you only need to unassign or move a license key, please reference Unassign a Self Service license in MyF5. Otherwise proceed with the following steps to terminate a license key.

Important: Terminate cannot be undone. This license key can't be reused and it no longer has support. 

  1. Logon to MyF5.
  2. Select "Registration Keys" from the "My Products & Plans" dropdown menu
  3. Choose the radio button to the left of the relevant registration key
  4. Click the "Edit Key" option
  5. From the Actions dropdown list, select Terminate.
  6. Click Submit and read the pop-up warning about terminate.
  7. If ready to proceed, select "Terminate Key".
  8. This process may take up to 15 minutes to complete and you will notice the following progress.
    • The license key status reads "processing termination". You may need to refresh the web browser. 
    • Once the status for the license key shows terminated, the "edit key" option is greyed out/no longer available when this key is selected. 
    • Eventually this license key won't be listed on the Registration Keys page, but will be visible under terminated keys.
  9. Select "Show Terminated Keys" to view terminated keys.

Important: When a key is terminated, a new license should be applied to that BIG-IP VE or that VE should be decommissioned, whether its license removed or it's deleted altogether.

Please email the F5 Customer Success Team at CustomerSuccess@f5.com for any questions related to MyF5 Self Service license keys.
