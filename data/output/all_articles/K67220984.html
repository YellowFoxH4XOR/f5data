Description

This article covers what the clear-rest-storage command does. Read all the warnings in this article prior to running the command.

Environment

  • BIG-IP
  • REST framework

Cause

BIG-IP device is not successfully in sync with REST framework.

Recommended Actions

The clear-rest-storage command completely clears the stored state for the BIG-IP REST framework. It first stops restjavad and restnoded, deletes the index and storage directories, and then restarts those services.

Note: REST storage is included in the BIG-IP UCS archive. F5 recommends that you back up your system per K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.

Important Warnings. Read the following list before proceeding:
• Do not run this command on devices that have SSLO provisioned and configured as it removes the SSLO configuration from the REST Storage and it will no longer show in the SSLO Guided Config. The MCP objects that were created would still be there, and will likely still run traffic, because they now exist outside of REST storage. Attempting to modify the configuration manually in the interim can be at best problematic and may break the configuration. Contact F5 Support for further assistance.
• This command permanently erases all Access Guided Configuration, Advanced WAF Guided Configuration, SSL Orchestrator, and iAppLX REST and FAST templates on the BIG-IP. The only way to restore the configuration is from a UCS file.
• If the BIG-IP system has any pre-existing deployed Access Guided Configuration or Advanced WAF Guided Configuration applications, it may leave orphan (not belonging to any iApp LX) MCP configuration objects on the BIG-IP system that may conflict with future applications.
• If the BIG-IP system has any pre-existing deployed SSL Orchestrator objects, it may leave dangling MCP objects that interfere with correct operation. For details and a remediation procedure, refer to K44201187: ''SSLO configurations are in an incorrect state'' error after deleting an SSLO service.
• The Access Guided Configuration and SSL Orchestrator GUI will revert to the default for the BIG-IP software version. Any desired upgrades to these systems must be repeated.
• oAuth Discovery (Use Auto JWT) is impacted.
• If proceeding with running the command on SSLO, prior to doing so create a backup adding the steps per F5 BIG-IP SSL Orchestrator considerations
• The AS3 package is removed.

When run with no switches, the command:

  • Stops restnoded and restjavad
  • Deletes all files in /var/config/rest/storage and in /var/config/rest/index
  • Deletes all files in /var/run/pamcache, except auth cookie files
  • Restarts the stopped processes

What is the impact of deleting the files stored in these locations? 
Those files store the state of the REST database - by deleting them, you force REST to rebuild those files. If anything has changed in the sources it pulls from, then those changes will now be incorporated into the REST engine's new state.

To restore or clear the BIG-IP iControl REST framework with the clear-rest-storage command, perform the procedure in K78734243: Clearing or restoring REST framework from BIG-IP after being managed by BIG-IQ.
