K56552440: vCMP Guest software installation error - lind in a restarting loop

Type
Support Solution
Published
2021-02-18
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K56552440

Description

During software installation in a vCMP guest, the process lind may fall in a restarting loop due the lack of the sym link "/dev/cdrom", as result of this issue you may find the below logs into the file /var/log/ltm

localhost err lind[4360]: 013c0004:3: unmount failed Invalid argument

localhost err lind[4360]: 013c0004:3: Fatal error: block id new probe failed - device file:/dev/cdrom

The software volume status will appear as "upgrade needed"

# show sys software

--------------------------------------------------------
Sys::Software Status
Volume  Product   Version  Build  Active          Status
--------------------------------------------------------
HD1.2      none      none   none      no  upgrade needed

Environment

  • You want to intall an ISO image in the vCMP guest which is stored in the vCMP host

Cause

In certain conditions a required sym link by the process lind is not present in the BIG-IP system.

Recommended Actions

To solve this issue perform one of the following procedures

  • Import the ISO image directly to the vCMP Guest in question.
  • Or create the missing sym link "/dev/cdrom" following next process 

On the affected devices you should get the below output when you tried to list the mentioned link,

#  ls /dev/cdrom
ls: cannot access /dev/cdrom: No such file or directory   <<<<  !

You can create the link with the below command,

# ln -sf /dev/sr0 /dev/cdrom

Then validate that the link was created,

# ls -l /dev/cdrom
lrwxrwxrwx. 1 root root 8 2020-10-21 08:23 /dev/cdrom -> /dev/sr0   <<<<<<<<<  !

After this you should be able to install the image

  •  Or force the mcpd process to reload the BIG-IP configuration

Please refer to this article for additional details about the mcpd reload process K13030: Forcing the mcpd process to reload the BIG-IP configuration
