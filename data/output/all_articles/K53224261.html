K53224261: BIG-IQ v6.0.1 /var/log directory is full due to sa6

Applies to

Source
https://my.f5.com/manage/s/article/K53224261

Description

/var/log is constantly full

Environment

  • BIG-IQ 6.0.1
  • /var/log/sa6 becomes corrupt or disk space becomes full in /var/log/sa6

Cause

Disk space is not reclaimed in /var/log/sa6. This is due to Bug ID 580500.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Check sysstat by running the command below:
    # cat /etc/logrotate.d/sysstat.txt
    Sample output:
    # rotate sysstat log file and generate sysstat xml output

    /var/log/sa6/sa {
        compress
        missingok
        notifempty
        create
        prerotate
            /usr/bin/sadf -x /var/log/sa6/sa -- -A > /var/log/sa6/saxml
        endscript
    }

    /var/log/sa6/saxml {
        compress
        missingok
        notifempty
        nocreate
        sharedscripts
        postrotate
            touch /var/log/hup_syslog
        endscript
    }
  2. Edit /etc/logrotate.d/sysstat and add this line before endscript
    # vi /etc/logrotate.d/sysstat.txt
    Example Output:
    # rotate sysstat log file and generate sysstat xml output

    /var/log/sa6/sa {
        compress
        missingok
        notifempty
        create
        prerotate
            /usr/bin/sadf -x /var/log/sa6/sa -- -A > /var/log/sa6/saxml
            # exit cleanly here in case sadf cores on corrupt files    <-----------add this line
            exit 0                                                     <-----------add this line
        endscript
    }

    /var/log/sa6/saxml {
        compress
        missingok
        notifempty
        nocreate
        sharedscripts
        postrotate
            touch /var/log/hup_syslog
        endscript
    }
  3. To save press Esc+:wq!
  4. Save config
    # tmsh save sys config
  5. Reboot Device
    # reboot
