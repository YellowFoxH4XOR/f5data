K000138675: HTTP/2 header not being passed to the client when request logging profile is being used

Type
Support Solution
Published
2024-03-24
Updated
2024-03-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000138675

Description

After configuring request logging profile for virtual server processing HTTP/2 traffic, you might notice that some headers are not being passed from BIG-IP to the client.

Environment

  • BIG-IP LTM

  • HTTP/2

  • GRPC

Cause

Unknown at the moment of publication. 

Recommended Actions

Do not use request-log profile for GRPC traffic.

Additional Information

Issue is tracked internally with Bug ID 1531729.
