Security Advisory Description

When a BIG-IP PEM classification profile is configured on a UDP virtual server, undisclosed requests can cause the Traffic Management Microkernel (TMM) to terminate. This issue affects classification engines using signatures released between 09-08-2022 and 02-16-2023. See the table below for a complete list of affected classification signature files. (CVE-2024-23982)

Impact

Traffic is disrupted while the TMM process restarts. This vulnerability allows a remote unauthenticated attacker to cause a denial-of-service (DoS) on the BIG-IP system. There is no control plane exposure; this is a data plane issue only.

Security Advisory Status

F5 Product Development has assigned ID 1223369 (BIG-IP) to this vulnerability. This issue has been classified as CWE-121: Stack-based Buffer Overflow.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by installing a version listed in the Fixes introduced in column. If the Fixes introduced in column does not list a version for your branch, then no update candidate currently exists for that branch and F5 recommends that you upgrade to a version with the fix (refer to the tables).

If the Fixes introduced in column lists a version prior to the one you are running, in the same branch, then your version should have the fix.

Mitigation

Check the current running signature version. To do so, choose one of the following procedures:

  • Use tmsh to check the signature version
  • Use the Configuration utility to check the signature version

Use tmsh to check the signature version

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

  2. Enter the following command:

    show ltm classification updates

Use the Configuration utility to check the signature version

  1. Log in to the Configuration utility.
  2. Go to Traffic Intelligence > Applications > Signature Update.
  3. For Version Details, refer to Current Deployed Version.

If you are running one of the vulnerable signatures listed in the table above, you can mitigate this vulnerability by installing the fixed traffic classification signature update.

To do so, download the fixed signature file and perform the Updating classification signatures manually procedure in K22180795: Updating the BIG-IP classification signatures and engine.

Impact of action: The signature update process reloads the system configuration and may temporarily interrupt traffic processing. F5 recommends that you perform the signature update during a maintenance window.

F5 recommends you configure the BIG-IP systems with high availability (HA) to lessen the impact of the vulnerability.

  • Configure systems with HA clustering. For more information, refer to K02234544: Manually setting up device service clustering.
  • Configure the HA table to take specific actions. For more information, refer to K9231: Overview of BIG-IP daemon heartbeat failsafe.
