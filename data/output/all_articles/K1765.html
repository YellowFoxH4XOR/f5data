K1765: BIG-IP compatibility with UDP, TCP, and other IP protocols

Topic

BIG-IP can load balance any UDP or TCP protocol through a virtual server.

Beginning in BIG-IP version 4.5, BIG-IP can also load balance any IP protocol through a virtual server when the any_ip option is enabled.

Note that, although BIG-IP can load balance any protocol, some protocols may not work properly after having been modified by a BIG-IP. For example, protocols that embed a source IP address in the packet payload, and use this address when responding, may not work properly.
