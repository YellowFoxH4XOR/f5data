Description : 

Configuring SSH public key authentication on F5OS system for root user

 

Environment:

  • F5OS system
  • A remote system
  • SSH Public key authentication
  • Root user credential

 

Cause :

You would like to enable SSH public key authentication for root user.

 

Recommended Actions:

  1. Generate ssh rsa key pair on your remote system.
    example : ssh-keygen -t rsa -b 2048
    above command may or may not work on your remote system. In case it doesn’t work, for detailed instructions on generating the key pair on your remote system, refer to the documentation from your vendor.
  2. Check the content of the newly generated public key and copy the public key.
    example (id_rsa.pub is public key file name) : cat /root/.ssh/id_rsa.pub
    ssh-rsa AAAAB3NzaC1[…..]D7Pn+op user@host
  3. SSH to F5OS system using root credentials.
  4. On F5OS edit the “authorized_keys” file using any editor of your choice, then paste the public key we have coped in step number 2 at the end of the file.
    example: vi /root/.ssh/authorized_keys
  5. Save and exit the file
    example: to save the file press ‘esc’ key on your keyboard then type wq! then press ‘enter’ key.
  6. Configure your remote system to prefer public-key authentication.
  7. Verify SSH public key authentication by running the following command. This time, authentication will be conducted using a public key; there will be no password prompt.
    ssh root@<IP Address of F5OS system>

 

Additional Information

The same can be done for other user types. Please see F5OS SSH Key-based auth for non-root accounts with superuser role
