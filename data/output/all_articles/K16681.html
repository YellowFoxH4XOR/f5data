Known Issue

In rare situations, the Traffic Management Microkernel (TMM) may fail when processing File Transfer Protocol (FTP) connections.

This issue occurs when the following conditions are met:

  • You have a virtual server configured with the FTP profile.
  • The virtual server is processing FTP data.

Impact

The BIG-IP system may temporarily fail to process traffic, and may fail over if configured as part of a high-availability system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file in the /var/core directory.
  • The BIG-IP system fails over to the peer system in a high-availability configuration.
