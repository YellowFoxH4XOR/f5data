Known Issue

Note: The EUD version M-12.0.0 is compatible with the following BIG-IP platforms: 1600 (C102), 3600 (C103), 6900 (D104).

This is the result of a known issue. By default, the EUD version M-12.0.0 logs all EUD reporting output to the /shared/log/eud.log file. On rare occasions, the EUD appears to run normally, but the eud.log file is missing from the /shared/log directory. This issue occurs when the BIG-IP system is booted in to the EUD environment, and the system detects and enumerates the hard drive with a different drive label than normal. As a result, the eud.log file is stored on a different partition than expected.

F5 Product Development tracked this issue as CR111148 and it was fixed in BIG-IP versions 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

Workaround

You can work around this issue by obtaining the eud.log file. To do so, perform the following procedure after exiting the EUD:

  1. Log in to the command line.
  2. To attach the file system on /dev/sda2 to /mnt, type the following command:

    mount /dev/sda2 /mnt
  3. Extract the eud.log file from /mnt/shared/log/eud.log.
  4. After obtaining the eud.log file, detach the file system by typing the following command:

    umount /dev/sda2 /mnt
