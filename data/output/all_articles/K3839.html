Policy Information

Product Update

F5 hereby announces the End of Life plan for the Windows 95 client support feature in FirePass. This applies to all fully-licensed FirePass products running on 1000, 4000, and 4100 hardware platforms. Microsoft announced the end of support for Windows 95 in January, 2003, which states that security patches and bug fixes will no longer be available as a part of Microsoft's standard support options.

The End of Life of the FirePass Windows 95 client support feature will allow F5 to focus on developing and supporting product capabilities on other more current and vendor-supported client Operating Systems.

Product Support

For those customers using Windows 95 Clients for remote access, F5 will continue to provide software and phone support in accordance to the customer's maintenance contracts. After the EoSD date, 3/15/2005, F5 will not be able to provide software fixes for any technical issues with Windows 95 Remote Access Clients connecting to FirePass. In addition, after the EoSD date, 3/15/2005, F5 will provide technical support for Windows 95 clients on a best-effort basis.

Questions

If you have questions about F5's decision to discontinue this feature, contact your local F5 representative or service department.
