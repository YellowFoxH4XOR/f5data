K81570145: The licensed date doesn't change after license reactivation

Type
Support Solution
Published
2022-03-05
Updated
2023-03-15
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K81570145

Description
The "Licensed on" output from CLI command "tmsh show /sys license" does not change after license reactivation. The same applies to the "Licensed date" in the /config/bigip.license file. 

Environment

  • Licensed date
  • License reactivation
  • CLI

Cause
This is by design. The "licensed on" date or "Licensed date" are mostly static values for F5's internal usage only, these values are added when the unit is very first licensed. They will not change after an upgrade or license reactivation.
Note: After an allow move, the licensed date may be updated upon license activation. 

Recommended Actions

None

Additional Information
The service check date in the BIG-IP license is updated each time the license is reactivated, if there is an active service contract for this BIG-IP system. For more information, refer to: K7727: License activation may be required before a software upgrade for BIG-IP
