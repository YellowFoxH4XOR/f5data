Issue

Error Message

err mcpd[<PID>]: 01071d92:3: Cannot assign access profile and both clientssl and serverssl profiles with ssl proxy enabled to the same virtual server (<virtual>)

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <virtual> is the partition and name of the virtual server.

For example:

err mcpd[5681]: 01071d92:3: Cannot assign access profile and both clientssl and serverssl profiles with ssl proxy enabled to the same virtual server (/Common/vs_example)

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility

Description

This message occurs when all of the following conditions are met:

  • You configure both a Client SSL profile and a Server SSL profile with the Proxy SSL feature enabled.
  • You configure a virtual server with an access profile, a Client SSL profile, and a Server SSL profile.

Impact

The BIG-IP system fails to save the configuration change and reports this error message.

Recommended Actions

When you configure a virtual server, you cannot have both the Proxy SSL feature and an access profile. The BIG-IP system prevents this configuration; it is invalid. To prevent this issue, either disable the Proxy SSL feature or remove the access profile from the virtual server.
