Description

Prior to upgrading your system, you might want to generate a report of fixed / unresolved bugs and behavior changes between BIG IP versions.

Environment

  • Current / source BIG IP version
  • Upgrade destination version
  • Additional modules

Cause

None

 Recommended Actions

  1. Browse MyF5 -> Resources -> Bug Tracker
  2. From Product Family choose current / source and destination versions
 
 
  1. Choose additional installed modules if needed
  2. Scroll down to Bug State and choose Fixed:
 
  1. You will then get a list of fixed bugs between the current and destination version
  2. In case that there was also behavior change, you will have a list of the behavior changes:
 
  1. For unresolved bugs click Unresolved

None
