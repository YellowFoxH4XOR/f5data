Topic

You can test the length of the http_uri with conditional operators. For example, you might require that all HTTP requests with a URI length greater than 200 be dropped. This rule would be written as follows:

rule ensure_len {
 if(http_uri <  201 ) {
 use pool <poolname>
 } else { 
 discard
 }
 }
