K000137717: BIG-IP Next Central Manager fails to create VMware instance with the selection of OVF/OVA templates from the VMware vSphere Content Libraries

Description

When you attempt to create a new instance on the VMware vSphere provider through the BIG-IP Next Central Manager, the instance creation fails and the BIG-IP Next Central Manager logs the following alert in the Alerts & Notifications page:

Summary - Instance Creation Alert
Description - you must use a VMware template

Environment

  • BIG-IP Next Central Manager
  • VMware vSphere provider

Cause

BIG-IP Next Central Manager does not support OVF/OVA templates however it erroneously allows you to select them from the Content Libraries of the configured VMware vSphere provider when you attempt to create a BIG-IP Next instance.

Recommended Actions

Prior to using the BIG-IP Next Central Manager to create a BIG-IP Next instance on the configured VMware vSphere provider, you must ensure that you select VM Template for the Template Type setting when you clone the BIG-IP Next OVA image to the VMware vSphere Content Library of the configured VMware vSphere provider. For instructions on creating a BIG-IP Next template on VMware, refer to Create BIG-IP Next instance template on VMware.
