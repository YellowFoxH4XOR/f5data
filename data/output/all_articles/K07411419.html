Description

Pushing BIG-IP AFM configurations from the BIG-IQ fails with the following error message:

java.lang.IllegalArgumentException: Kind Protocol Inspection Compliance is not supported by this distribute task

Environment

  • Trying to push BIG-IP AFM full or partial configuration changes
  • BIG-IQ Version 7

Cause
       JAR file code needs to be updated.
 

Recommended Actions

  1.  Request and install updated JAR file from F5 support

None
