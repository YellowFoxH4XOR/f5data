Topic

This article discusses the requirement for BIG-IP Edge Client automatic update on macOS 14.x and earlier versions when you update to APM Client 7262 on BIG-IP APM. This article applies under the following conditions:

  • you have BIG-IP Edge Client running on macOS 14.x and earlier releases.
  • you plan to update your BIG-IP system to APM Client 7262.
  • You configure BIG-IP Edge Client on macOS to automatically update.

For more information on BIG-IP Edge Client auto update, refer to K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI.

Description

You must be running APM Client 7251 or later, when you update to APM Client 7262, in order to successfully auto update BIG-IP Edge Client on macOS 14.x and earlier on the client side. Support for legacy auto update have been removed in APM Client 7262.

This also means that when you update from versions prior to APM Client 7251 to APM Client 7262, BIG-IP Edge Client auto update on macOS 14.x and earlier fails.

Recommendation

When you plan to update to APM Client 7262, update to APM Client 7251 or later first.
