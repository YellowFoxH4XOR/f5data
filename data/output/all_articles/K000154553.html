K000154553: Is NGINX Plus FIPS Compliant

Type
Support Solution
Published
2025-08-30
Updated
2025-08-30
Applies to
  • NGINX Products
  • NGINX Plus: R35, R34, R32, R31, R33
Source
https://my.f5.com/manage/s/article/K000154553

Description

  • You have installed and configured NGINX Plus
  • You want to know how to make NGINX FIPS compliant

Environment

  • NGINX Plus
  • OpenSSL
  • FIPS
  • TLS
  • cryptographic algorithms

Cause

  • None

Recommended Actions

  • NGINX Plus can be made FIPS compliant when run with FIPS-validated OpenSSL cryptographic module in FIPS mode.
  • Compliance is achieved through the underlying Operating System’s OpenSSL library.
  • When OpenSSL operates in FIPS mode with approved cryptographic algorithms and modules, the system/NGINX is said to be compliant with FIPS Standard.

Additional Information

  • NGINX Plus relies on the Operating System’s OpenSSL for encryption and decryption (SSL) operations.
  • As to NGINX Plus, there isn't FIPS dedicated image to download from my F5. However and so long the lower OpenSSL is compliant so will be the NGINX
  • The use of strict cryptographic standards increases resource usage. Subsequently, enabling FIPS mode may increase resource consumption and impact performance, especially under high traffic loads.
