K000161891: BIG-IP Tenant on F5OS Becomes Unreachable After Installing iSeries-Only Engineering Hotfix

Type
Support Solution
Published
2026-06-26
Updated
2026-08-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000161891

Description

A BIG-IP tenant running on an F5OS platform becomes unreachable after applying an Engineering Hotfix (EHF) ISO intended only for iSeries appliances. This occurs when the EHF is mistakenly installed on a non-iSeries platform, such as F5OS tenants, vCMP guests, or Virtual Editions, resulting in loss of access to the tenant. 

Environment

  • Platform: F5OS
  • Engineering Hotfix (EHF) ISO

Cause

An iSeries-only Engineering Hotfix was mistakenly installed on an F5OS tenant, causing the tenant to become unreachable due to platform incompatibility.

Recommended Actions

  1. Download the correct EHF ISO designated for non-iSeries platforms (F5OS tenants, vCMP guests, VEs, Viprion) and the BIG-IP 17.5.1.6 base ISO from MyF5 Downloads.
  2. Upload the EHF image directly to the BIG-IP tenant (not the F5OS host layer) via TMUI or using the install sys software image command.
  3. Install the EHF on top of the 17.5.1.6 base to the target boot location.
  4. Reboot into the new boot location.
  5. Verify tenant accessibility and confirm that the GUI displays configuration objects in non-Common partitions correctly.
  6. If the tenant is already unreachable, interrupt the GRUB boot process to revert to a previous working boot location:
    • Access the F5OS host as root, then switch to the admin user plane.
    • Identify the tenant name and tenant-id.
    • Use the console access command to connect to the tenant.
    • Restart the tenant and repeatedly attempt console access until successful.
    • Interrupt the GRUB process and select a previous boot location.
    • Boot from the selected location.
  7. For future upgrades, always verify that the EHF ISO matches the platform type before installation.

Additional Information

  • The iSeries-specific EHF must only be used on iSeries appliances and must not be applied to BIG-IP Virtual Editions, vCMP guests, or F5OS tenants.
  • There are separate EHF ISOs for iSeries and non-iSeries platforms. For BIG-IP 17.5.1.6, use the EHF ISO for non-iSeries platforms.
  • The fix for this issue is available in the correct EHF for non-iSeries platforms.
