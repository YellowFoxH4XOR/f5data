Topic

A NAT is based on a one-to-one mapping ratio and can handle both inbound and outbound connections. Each NAT can support 65,535 ports. A SNAT is generally a many-to-one mapping ratio used for outbound-only connections. Each SNAT can support 64,510 ports.

You can configure a SNAT automap if you need to use more than 64,510 ports for a SNAT. A SNAT automap can support up to 64,510 ports for each self IP that is enabled.

A SNAT automap will load balance port utilization in a round robin method between the self IPs enabled with SNAT automap. If the available ports have been exhausted on a self IP enabled with SNAT automap, the load balance rotation will skip that self IP. The rotation will automatically map to the next self IP enabled with SNAT automap that has available ports.

The number of self IPs is unlimited. Therefore, SNAT automap makes it possible to scale to an unlimited number of ports and clients through the SNAT.

Note: For information about configuring a SNAT automap, refer to the BIG-IP Reference Guide.
