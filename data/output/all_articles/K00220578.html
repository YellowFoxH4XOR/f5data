K00220578: BIG-IP LTM VE 12.1.1 deleted files filling disk

Type
Support Solution
Published
2021-07-13
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 12.1.1
Source
https://my.f5.com/manage/s/article/K00220578

Description
        /var/log is out of disk space

Environment

  • /var/log at 100%

Cause
       bigd is holding open 3 very large deleted files

Recommended Actions

  1.  From bash run:  losf | grep deleted
  2.  If bigd has large deleted files  run:  bigstart restart bigd

       None at this time
