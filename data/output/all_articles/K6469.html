K6469: The default BIG-IP failover tty00/01 serial port settings may cause undesired active-active status

Topic

By default, the BIG-IP failover tty00/01 serial port settings use tty01 (COM2). Some Dell and HP server appliances only have one external serial port connection that use tty00 (COM1) by default. This will cause the failover cable to be unrecognized, resulting with an undesired active-active status on the BIG-IP system.

The BIG-IP system uses the following bigdb keys to configure the tty serial port used for failover:

  • Common.Bigip.Failover.UseTty00
  • Common.Bigip.Failover.UseTty01

You can configure the BIG-IP system to use the same serial port, tty00 (COM1), as Dell and HP server appliances that have one external serial port by performing the following procedure:

  1. Log in to the BIG-IP command line.

  2. Configure the BIG-IP system to not use tty01 (COM2) for failover by typing the following command:

    bigpipe db set Common.Bigip.Failover.UseTty01 = 0

  3. Configure the BIG-IP system to use tty00 (COM1) for failover by typing the following command:

    bigpipe db set Common.Bigip.Failover.UseTty00 = 1

  4. Restart the BIG-IP services to apply the changes by typing the following command:

    bigstart restart
