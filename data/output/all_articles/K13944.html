Known Issue

When you use the BIG-IP Configuration utility to create a new virtual server, the BIG-IP system may incorrectly set the default protocol profile.

This issue occurs when all of the following conditions are met:

  • You create a custom protocol profile.
  • The name you choose for the custom protocol profile alphabetically precedes the default for the FastL4, FastHTTP, TCP, UDP, or SCTP profile types.
  • You create a new virtual server.

For example, if you create a TCP profile called aatest, this profile will automatically become the default TCP profile for all newly-created virtual servers instead of the expected default tcp profile.

Impact

Virtual servers may be inadvertently created with incorrect profiles.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Virtual servers may not behave as intended as they are using an incorrectly selected profile.

Workaround

To work around this issue, you can use the advanced option when creating a virtual server and manually select the correct profile.

Impact of workaround: None
