Description

iControl-REST API requests to modify configuration to include a feature in a module not provisioned or licensed will report an error message with status code 400 indicating the module needing to be licensed or provisioned.

  • BIG-IP responds to iControl-REST request with error message.
  • Error messages

'"code": 400, "message": "One of the following features must be licensed/provisioned for the URI < request URI> : <BIG-IP module not licensed>", "errorStack": [], "apiError": 1'

  • Example of a command to modify virtual server security NAT policy when AFM is not provisioned.

curl -sku <admin user> -H "Content-Type: application/json" -X PATCH https://<bigip management IP>/mgmt/tm/ltm/virtual/~Common~http_vs -d

 '{"securityNatPolicy":{"policy": "/<Partition>/<NAT policy>", "useDevicePolicy":"no", "useRouteDomainPolicy":"no"}}' |jq .

{

 "code": 400,

 "message": "One of the following features must be licensed/provisioned for the URI ltm/virtual/security-nat-policy/policy : afm cgnat",

 "errorStack": [],

 "apiError": 1

}

Environment

  • Any BIG-IP module.
  • Any configuration object with a sub object associated with another module.

Cause

  • Modifying configuration to including an option for a feature not licensed or provisioned.
  • Any configuration object for example trying to modify security settings on a virtual server where AFM module is not licensed.

Recommended Actions

If the change is desired ensure to provision the indicated module otherwise the error message is informational and can be ignored.
