Description

When restoring a BIG-IP configuration from an UCS file. The ca-bundle.crt is not restored/replaced with the one included in the UCS file.

Environment

  • BIG-IP
  • UCS
  • ca-bundle.crt

Cause

Seen behaviour is expected. The UCS will not update the ca-bundle file "/config/ssl/ssl.crt/ca-bundle.crt", with the ca-bundle inside the ucs if there is a ca-bundle already on the system.

Recommended Actions

If you would like the UCS to restore the ca-bundle from the UCS file, you should manually remove the file "/config/ssl/ssl.crt/ca-bundle.crt" from the BIG-IP system first, then load the UCS, then restart all services on the BIG-IP.

  1. Connect to BIG-IP CLI
  2. Delete ca-bundle.crt
    rm -rf /config/ssl/ssl.crt/ca-bundle.crt
  3. Load the UCS file
  4. To force the mcpd process to reload the configuration, enter the following command: 
    touch /service/mcpd/forceload

    On VIPRION systems, enter the following command to run this on all blades:

    clsh touch /service/mcpd/forceload
  5. To restart the BIG-IP system, enter the following command:

    Important: This command interrupts traffic while the BIP-IP system either fails over to a peer system or completes the restart process.

    reboot

    On VIPRION systems, enter the following command to run this on all blades:

    clsh reboot
