Topic

The Insert HTTP Header feature is intended for use with literal strings and cannot parse functions such as environmental variables, like client IP address or User-Agent values.

To include headers per client or per server, use the optional pool attribute, HTTP header insertion. With this feature, you can insert specific BIG-IP rule variables into the HTTP headers before the request is sent to a node member.

For specific configuration instructions, refer to the BIG-IP Reference Guide.
