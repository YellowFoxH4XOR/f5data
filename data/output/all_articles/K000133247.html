Description

When debug logging is enabled for certain processes, those verbose log details gets saved to /shared/tmp/ as opposed to /var/log/ directory. 

Environment

Debug logging enabled for some processes such as the following:

  • csyncd
  • devmgmtd
  • evrouted
  • icrd
  • lind
  • mcpd
  • mgmt_acld
  • restjavad
  • tmrouted
  • zxfrd

This is not a comprehensive list by any means, but these are some of the more commonly used processes for which you may want to leverage debug logging.

Cause

In earlier versions, only mcpd happened to write to /shared/tmp/ for it's debug logging. Since at least 12.x releases, several processes are also writing debug logs to /shared/tmp/ and this was introduced via ID496354.

Recommended Actions

This debug file stored within /shared/tmp/ doesn't get rotated out because these files aren't part of the /etc/cron.daily/ directory (which contains files such as /etc/cron.daily/logrotate that handles rotation of the files within /var/log/). Therefore, you'd have manually remove them or setup a cron task to periodically remove them if debugging is enabled often for any of these processes (which is typically not recommended unless asked to do so by F5 Support for troubleshooting purposes).
