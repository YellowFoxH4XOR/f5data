K11673: Some BIG-IP GTM versions use data other than path statistics for path-based load balancing methods when LDNS statistics are not available

Topic

When defining a path-based load balancing method (such as Round Trip Time [RTT], Hops, or Completion Rates) for a wide IP load-balancing pool, the BIG-IP GTM system gathers statistical information over time to determine how quickly traffic moves between a local DNS (LDNS) and a resource for which the BIG-IP GTM is responsible. The BIG-IP GTM stores path data in memory and uses the statistical data to select the appropriate virtual server resource for a given LDNS.

When a BIG-IP GTM 9.2.2 through 10.0.1 system processes a request from an LDNS for which path-based statistics are not yet available, the system uses data other than path statistics to select the virtual server resource. In this case, the pool statistics may indicate that the BIG-IP GTM system used the preferred load-balancing method to distribute the request even though there were no path-based statistics available at the time of the request. BIG-IP GTM 10.1.0 and later do not employ this feature.

Path-based load balancing when path statistics are available for the LDNS

When the BIG-IP GTM system processes a request from an LDNS for which path statistics are available, the system uses the statistics to select the appropriate virtual server resource for a given LDNS. For example, when Round Trip Times (RTT) is configured as the preferred load-balancing method for a wide IP pool, and virtual server resources exist in data centers DC-A and DC-B, the BIG-IP GTM system communicates with other F5 devices in the data centers to gather statistical information from the LDNS and determine the virtual server resource with the fastest measured round trip time between a data center and the LDNS. Pool statistics will indicate that the BIG-IP GTM used the preferred load-balancing method to distribute the request.

Note: Pool statistics in versions prior to 11.5.0 are located in the Configuration utility under Overview > Statistics > Global Traffic > Pools. In 11.5.0 and later, pool statistics are located in Statistics > Module Statistics > DNS > GSLB.

Path-based statistics are not available for the LDNS

BIG-IP GTM 10.1.0 and later

When the BIG-IP GTM system processes a request from an LDNS for which path-based statistics are not yet available, the system uses the alternate or fallback load-balancing methods to select the appropriate virtual server resource for a given LDNS. The BIG-IP GTM system then begins to gather path-based statistics for subsequent requests from the LDNS. Pool statistics indicate that the BIG-IP GTM used the alternate or fallback load-balancing method to distribute the request.

BIG-IP GTM 9.2.0 through 10.0.1

When the BIG-IP GTM system processes a request from an LDNS for which path-based statistics are not yet available, the system queries the netIana.inc database file for network entries that most closely match the IP address of the LDNS. The BIG-IP GTM system uses the data from the netIana.inc database file to determine the virtual server resource with the fastest measured round trip time between a data center and the LDNS. Pool statistics may indicate that the BIG-IP GTM system used the preferred load-balancing method to distribute the request even though there were no path-based statistics available at the time of the request.
