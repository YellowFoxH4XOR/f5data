Description

Windows 10 contains important security features, such as Device Guard, Credential Guard, and App Guard. These features improve security by implementing an array of hardware and operating system protections against malicious and unauthorized access. These features can also interfere with various applications and drivers, mainly those that perform system-level operations.

BIG-IP Edge Client and BIG-IP APM use cases are impacted by some of these features. All Windows 10 Guard features can be enabled and disabled by the Windows administrator.

Device Guard

The Device Guard feature affects driver operation. F5 has added support for Device Guard in the Edge Client Virtual Private Network (VPN) driver starting in BIG-IP APM 11.5.6, 11.6.3, 12.1.3.2, and 13.1.0.

Credential Guard

The Credential Guard feature attempts to minimize the amount of time that user credentials are stored in the PC's memory in a vulnerable form, to guard against memory dump and similar attacks. BIG-IP Edge Client and the associated components are not affected by this feature.

Application Guard

The Application Guard feature blocks F5 client access because it prevents helper applications from running in the browser. Many vendors use this technique to start applications that handle features because plug-ins are no longer supported. When using Microsoft Edge, this feature impacts the following use cases:

  • VMware Horizon View
  • Citrix
  • Native mode RDP (introduced in BIG-IP 13.0.0)
  • VPN
  • Endpoint Inspection

Note: Application Guard only blocks access from Microsoft Edge. Other browsers are not affected.
