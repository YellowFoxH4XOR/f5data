Issue

Error Message

err mcpd[<PID>]: 01071c34:3: The requested member (<Interface.Number>) is already configured as a member of VLAN (</Partition/VLAN Name>) with tag (<VLAN Tag>). A member can belong to only one VLAN for a given tag.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <Interface.Number> is the interface that is being reported
  • </Partition/VLAN Name> is the partition and the name of the Virtual Local Area Network (VLAN)
  • <VLAN Tag> is the VLAN tag being reported that is in conflict

For example:

err mcpd[9430]: 01071c34:3: The requested member (1.1) is already configured as a member of VLAN (/Common/My_VLAN) with tag (4096). A member can belong to only one VLAN for a given tag.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • This message is caused by an invalid configuration. A virtual-wire interface can be a member of only one VLAN. It cannot be a member of another VLAN, no matter if it is tagged or untagged.

Impact

None

Recommended Actions

To work around this issue, you can inspect the relevant object configuration in the VLAN, trunk, and interface.  Don't add a virtual-wire interface to more than one VLAN.
