Source
https://my.f5.com/manage/s/article/K000156536

Description

Failed to create the management route. CLI error:

01070712:3: unable to open file: /etc/.confpp.dat
exception: (Can't open command history file (/home/admin/.tmsh-history-admin), Read-only file system) (framework/CmdHistoryFile.cpp, line 92), exiting...

In the Configuration Utility (WebUI), an error banner is observed:

General database error retrieving information.

Environment

  • BIG-IP VE
  • Management route

Cause

A possible cause is database or MCPD corruption.

Recommended Actions

  1. Make sure you have a UCS backup file downloaded to your local computer.

    Note: You might also get an error when creating a new UCS file, it is recommended to take regular back up files of the system and have them saved externally from the BIG-IP.

  2. Perform a reboot on BIG IP system.  To do so, log in to the command line by typing the following command: 
    reboot
  3.  Forcing the mcpd process to reload the configuration. 
    1. Instructions on how to forceload the mcpd process can be found in this article: K13030: Forcing the mcpd process to reload the BIG-IP configuration

Additional Information

In case it is possible,  forcing a file system check on the next system restart: K73827442: Forcing a file system check on the next system restart (12.x - 17.x)
