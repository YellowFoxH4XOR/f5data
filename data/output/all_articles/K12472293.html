Known Issue

The Traffic Management Microkernel (TMM) may restart after performing multiple Secure Sockets Layer (SSL) profile updates or a user configuration set (UCS) installation.

This issue occurs when all of the following conditions are met:

  • You have configured multiple virtual servers with associated SSL profiles.
  • You have provisioned the BIG-IP Analytics module.
  • You perform one of the following configuration tasks:
    • Multiple SSL profile modifications in a short period of time.
    • A UCS installation.

Impact

The BIG-IP system fails to process application traffic while TMM restarts, and high availability (HA) devices may experience a failover event.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system temporarily fails to process traffic.
  • A failover event occurs.
  • In the /var/log/tmm file, you observe an error message that appears similar to the following example:

    notice ** SIGSEGV **

  • Your BIG-IP system generates a TMM core file to the /shared/core directory.
