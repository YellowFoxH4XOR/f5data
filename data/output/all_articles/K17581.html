Known Issue

BIG-IP Edge Client for Mac OS may not use updated component software.

This issue occurs when all of the following conditions are met:

  • Users establish access sessions to the BIG-IP APM system using BIG-IP Edge Client for Mac OS.
  • The BIG-IP APM system's EPSEC (OESIS libraries) software is updated.
  • Users establish or maintain their access sessions to the updated BIG-IP APM system using BIG-IP Edge Client.

Impact

The BIG-IP Edge Client EPSEC component software is updated but not used.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP Edge Client access sessions do not use the updated EPSEC component without a restart of the user's BIG-IP Edge Client system.

Workaround

To work around this issue, you can stop and restart BIG-IP Edge Client on the user device.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
