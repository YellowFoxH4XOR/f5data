Description

How to use implicit namespace labels to

  • Apply service or network policy on namespace level
  • Apply the same policy to the application (either)
    • between namespaces
    • within namespace

Environment

  • F5® Distributed Cloud Services node applications

Answer/Recommended Actions

Network policy

    1. Go to App -> {select app namespace, eg: "shali-ns1"} -> Security -> vK8s Network Policy -> Network Policies -> Add network Policy
    2. Name: allow-ns2, Policy For Endpoints -> Endpoints(s)
    3. Select Any Endpoint
    4. Connections to and From Endpoints -> Configure Ingress Rules
    5. Security -> vK8s Network Policy -> Active Network Policy -> Select above network policy and apply

Service policy

      1. App -> {select app namespace, eg: "shali-ns1"} -> Security -> Service Policy -> Service Policies -> Add service policy
      2. Add custom rule
      3. Config Rule Specification
      4. Security -> Service Policy -> Service Policies -> Active service policy

Note: To apply policy within the namespace, just select the same namespace
