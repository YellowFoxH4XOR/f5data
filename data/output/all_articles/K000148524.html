Description

After upgrading BIG-IP ASM to address bug ID1284097, violations are still occurring.

Environment

  • BIG-IP
  • ASM v17.1.1 or v16.1.5 and later
  • "Illegal cross-origin request" false positives.
  • Conditions matching the ID1284097.

Cause

These violations may still occur because the fix includes two new internal variables that are disabled by default and need to be enabled manually.

Recommended Actions

To enable these variables, refer to K000148525: How can I disable 'Illegal cross-origin' false positives occurring after the upgrade?
