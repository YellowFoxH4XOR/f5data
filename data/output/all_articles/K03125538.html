Description

A General Database Error message is shown when you click the Instances tab of a Certificate bundle / Certificate / Key, listed on the GUI under the System > Certificate Management > Traffic Certificate Management > SSL Certificate List,  Instance.

GUI shows an error similar to: 

"General database error retrieving information"

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • Viewing certificates on GUI

Cause

Bug ID 888869

Recommended Actions

ID 888869 is fixed in version 16.1.0 and 15.1.5. You can perform an upgrade to those and resolve the issue.
