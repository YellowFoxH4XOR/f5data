Issue

Old Behavior

Previously, when you assigned a MAC masquerade address in a VLAN configuration, the BIG-IP system associated the MAC masquerade address with the VLAN.

MAC masquerade address ensured that any traffic destined for a pair of redundant BIG-IP systems reached the active BIG-IP system after a failover had occurred.

New Behavior

Beginning in BIG-IP 11.0.0, the BIG-IP system associates a MAC masquerade address with a traffic group. You must now configure MAC masquerading in a traffic group instead of a VLAN. This behavior is the result of a redesign of the High Availability redundant system.

A traffic group is a collection of related configuration objects, such as self IP addresses and virtual IP addresses, that run on a BIG-IP system. The traffic group enables you to logically group configuration objects that you can fail over to another BIG-IP device in a device group if the active BIG-IP system becomes unavailable. Associating the MAC masquerade address to the traffic group (hence, the virtual IP addresses) allows the BIG-IP redundant systems to fail over without having to advertise gratuitous ARP replies each time. This helps to ensure that the system continues to process application traffic with minimal interruption in service. For more information about traffic group functionality, refer to the BIG-IP Redundant Systems Configuration Guide.

Note: The MAC masquerade address will be effective only when there is traffic hitting configuration objects (such as a virtual IP address) that are assigned to the traffic group.

F5 Product Development tracked this change as ID 338833.

Impact

If you are upgrading your BIG-IP system that has VLANs configured with MAC masquerade addresses, from BIG-IP 10.x to 11.x, the upgrade process includes only one of the MAC masquerade addresses for the default traffic group. As a result, the upgraded BIG-IP system may not have the remaining MAC masquerade addresses in its configuration.

Recommended Actions

If you are planning to upgrade, or have already upgraded your BIG-IP system from BIG-IP version 10.x to 11.x, and would like to continue to use the MAC masquerade addresses, you may have to configure your BIG-IP system to assign the MAC masquerade addresses to traffic groups, instead. To configure MAC masquerade addresses using traffic groups, perform the following procedure:

  1. Log in to the Configuration utility.
  2. For 11.3.0 and later, navigate to Device Management > Traffic Groups > Traffic Group List. For 11.0.0 through 11.2.1, navigate to Network > Traffic Groups > Traffic Group List.
  3. Click Create to create a new traffic group.
  4. Type a name for the traffic group in the Name box and click Next >>.
  5. Select the BIG-IP system from the Default Device drop-down menu for this traffic group.
  6. Type the MAC masquerade address in the MAC Masquerade Address box, and click Next >>.
  7. Select the Enable auto failback check box if you would like to have auto failback for this traffic group, and click Next >>.
  8. Click Finished to save the configuration.
  9. Repeat Steps 3 through 8 for every MAC masquerade address you would like to add to each new traffic group.
