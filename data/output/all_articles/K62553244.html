Known Issue

The BIG-IP APM rewrite profile may incorrectly handle the JavaScript flash.net.NetConnection::connect() method.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access with Flash Patching enabled on the access policy.
  • The JavaScript code in the HTML page invokes the flash.net.NetConnection::connect() method.
  • The web application requests a URI property immediately after calling the connect() method.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Adobe Flash applications malfunction with Flash Patching enabled on the access policy.
  • You are unable to access content in a different domain.
