Description

After upgrading BIG-IP APM to version 17.5.1, SAML authentication may fail with errors such as:

Jul 10 12:06:30 <node> err apmd[7348]: 01490321:3: <Resource>: TMM returned error for crypto operation 'No matching SP certificate found'
Jul 10 12:06:30 <node> err apmd[7348]: 01490203:3: <Resource>: SAML Agent: <Resource> failed to parse assertion, error: $fmt

The issue is observed when custom iRules are applied to virtual servers, particularly those that sanitize or restrict HTTP response headers (e.g., using HTTP::header sanitize or ACCESS::restrict_irule_events disable).

Environment

  • BIG-IP APM, version 17.5.1 and above
  • SAML Service Provider configuration
  • Custom iRules in use on virtual servers, especially those manipulating HTTP response headers

Cause

Starting with BIG-IP APM v17.5.1, APM relies on specific HTTP response headers for SAML cryptographic operations. If iRules sanitize or restrict HTTP response headers, required SAML headers may be removed from the response. This prevents APM from accessing necessary cryptographic information, resulting in authentication failures and errors indicating missing SP certificates or failed assertion parsing.

Recommended Actions

  • Review all iRules applied to SAML-enabled virtual servers for header manipulation commands such as HTTP::header sanitize or ACCESS::restrict_irule_events disable.
  •  Ensure the following SAML-related headers are whitelisted and not removed by iRules:
      apd_samlcryptoidpsignaturetype
      apd_samlcryptoidpsigncert
      apd_samlcryptospassertsign
      apd_samlcryptospsignkey
      apd_samlcryptospsigncert
      apd_samlcryptoaction
      apd_samlcryptospassertencrypt
      apd_samlcryptospdecryptkey
  • If using HTTP::header sanitize, extend the whitelist to include all headers above.
  • After making changes, apply the access policy and test SAML authentication.
  • For troubleshooting, review logs for errors related to missing certificates or failed assertion parsing, and verify header presence using packet capture or debug logging.
