K46504303: Change HTTP host header for an APM Application URI Portal Access Resource

Type
Support Solution
Published
2022-09-02
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP

Source
https://my.f5.com/manage/s/article/K46504303

Description

You would like to change the HTTP host header sent towards an APM Application URI Portal Access Resource

Environment

  • BIP-IP APM
  • Application URI Portal Access Resource
 

Cause

By default APM Portal Access Resource will forward the APM Virtual Server HTTP host header to APM Application URI Portal Access Resource but some applications might need a custom host header.
 

Recommended Actions

Below irule can be used to change the host header forward from the APM Virtual Server to APM Application URI Portal Access Resource

when HTTP_REQUEST_SEND {
    if { [HTTP::host] equals "Origin-HTTP-host-header"} {
        clientside {
            HTTP::header replace  "Host" "www.your-new-hostheader.com"
        }
    }
}
