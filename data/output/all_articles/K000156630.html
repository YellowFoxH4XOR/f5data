Description

When attempting to modify an iRules LX plugin using the command tmsh modify ilx plugin <plugin_name> from-workspace <workspace_name>, the following error may occur:

tar: ./extensions/NodeExtension/node_modules/.bin/semver: Cannot stat: Permission denied

tar: Exiting with failure status due to previous errors

failed to create workspace archive ... Return code {2}

This error prevents the workspace from being archived and the plugin from being updated.

Environment

  • BIG-IP LTM
  • BIG-IP iRulesLX

Cause

Sometimes a library creates hidden symlinks for binary files under the node_modules/.bin directory. The tar utility, used internally by BIG-IP to package the workspace, cannot access these symlinks due to permission issues or system security design. If tar encounters files or symlinks with problematic permissions (such as files owned by a nonexistent user or with restrictive permissions), it will fail with a "Cannot stat: Permission denied" error.

Recommended Actions

To resolve or work around this issue, consider the following options:

  1. Avoid Using .bin Symlinks
    Use binaries directly rather than through the .bin hidden path.
    Update your package.json scripts to point directly to intended files and verify their permissions.
  2. Reinstall Without Bin Links
    Remove the problematic library and reinstall it using npm’s --no-bin-links option:

    npm install <package> --no-bin-links

  3. Remove the .bin Folder
    If .bin is not required for your deployment, remove it:

    cd <your_workspace_path>

    rm -rf node_modules/.bin

    Retry running the tmsh modify ilx plugin ... command.
  4. Adjust Permissions
    If .bin is needed, ensure it and its contents have appropriate permissions:

    cd <your_workspace_path>

    chmod -R 755 node_modules

    chown -R root:root node_modules

    Ensure that your workspace is owned by a valid user (typically root:root ) for iRules LX.
  5. Install Only Production Dependencies
    If .bin is only used during development, install only production dependencies:

    npm install --production

    Review your package.json file to ensure only necessary dependencies are installed and no unnecessary symlinks are created.
