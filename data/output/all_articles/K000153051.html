Description

An NGINX [Plus] instance needs to be added or removed from a NIM instance group

Environment

NGINX Instance Manager (NIM)

Recommended Actions

From the NGINX [Plus] instance:

  • Edit file /etc/nginx-agent/agent-dynamic.conf
  • Add, comment out (to remove) or delete line instance_group: <instance_group_name> and save the file
  • Restart NGINX Agent: sudo systemctl restart nginx-agent.service
