Issue

Old behavior

In versions prior to BIG-IP 13.1.0, for the BIG-IP 13.x branch and BIG-IP 12.1.3.3 for the BIG-IP 12.x branch, FQDN ephemeral node objects are created in the same partition as the FQDN template node.

FQDN template nodes refer to nodes specified, with FQDN address type and auto-populate enabled.

FQDN ephemeral nodes refer to nodes created automatically by the BIG-IP system from resolving FQDN into IP addresses.

New behavior

Beginning in BIG-IP 13.1.0 and BIG-IP 12.1.3.3, all FQDN ephemeral node objects are created in the Common partition, even if FQDN template node resides in a partition other than the Common partition.

Impact

You may not find the FQDN ephemeral node objects in the same partition in which the FQDN template node resides.

Recommended Actions

None
