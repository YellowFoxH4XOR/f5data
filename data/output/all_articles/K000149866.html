Source
https://my.f5.com/manage/s/article/K000149866

Description

When attempting to delete a partition ISO image from the VELOS chassis, you're prompted with an error message, possibly about the OS image.

Alternatively, a deletion attempt from the chassis command line may throw an error message about the StandBy controller.

Environment

  • F5OS-C
  • VELOS

Cause

This may be due to bug ID 1497893.

Recommended Actions

Please log in to the chassis GUI and make sure all the partitions - including the "Default" one - that may be using software X.Y.Z-AAAAA are "Enabled".

Additional Information

The error message we can get from the command line:

Error: failed to remove software X.Y.Z-AAAAA, error message: standby removal failed for following reason: OS version X.Y.Z-AAAAA is used
