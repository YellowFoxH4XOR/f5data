K000160573: How to edit existing virtual site?

Source

Description

Customer wants to edit existing virtual site but the configuration is not populated in edit mode.

 

Environment

  • Virtual site

 

Cause

When customer selects 'Edit Configuration' on existing virtual site, existing Site Selector disappears. The console does not allow to do changes on existing labels, also changes in JSON are not being saved.

 

Answer/Recommended Actions

This behavior is expected and by design. It's not possible to edit existing virtual sites.

To edit virtual site, customer needs to create new virtual site and replace it on preferred object.
