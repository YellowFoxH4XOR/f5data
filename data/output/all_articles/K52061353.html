Description

You want to increase the disk space for /var, /var/log/ or /shared file system in a BIG-IP Virtual Clustered Multiprocessing (vCMP) Guest that may not have sufficient disk space for one or more of the following tasks:

  • Upgrading software or installing hotfixes
  • Provisioning multiple modules
  • Preparing for increased logging that requires additional disk space

Environment

  • VCMP environment

Cause

  • NA

Recommended Actions

Before increasing the size of the desired directories it is necessary to ensure enough space has been provided by the VCMP host to the guest(s) of interest. Refer to the instructions in K24156414 in advance.

Please note that the following steps apply to the specified directory in the current volume (the same directory in a different volume will not be resized).
 
  1. To extend the directory of interest (/var), use the following command syntax:

    Note: Do not commit all of the disk resources that you have just from the VCMP host extending the directory of interest, as the remaining added disk resource may be needed to perform different tasks such as software installation into a new software slot or storing increasing log files.

    tmsh modify /sys disk directory /var new-size <desired value in KB>

    For example, you would enter the following command to extend the /shared directory to 10 GB:

    tmsh modify /sys disk directory /var new-size 10485760

  2. Save the configuration by entering the following command:

    tmsh save /sys config

  3. Restart the BIG-IP VCMP Guest by entering the following command:

    reboot

  4. When the BIG-IP VCMP Guest is up, log in to bash.
     
  5. To verify that the /var directory is successfully extended to the size you have specified in step 1, enter the following command:

    tmsh show /sys disk directory

Additional Information

Beginning in BIG-IP 16.0.0, the logical volume size for the /var partition increased by 50%. For more information, refer to K53259232: The /var partition size is increased by 50% in BIG-IP 16.0.0 and later.
