Description

  • Consider using the procedure to replace a failed RAID disk.
  • This procedure applies to platforms with RAID for example 7000s, 10000s, i7000-D, i11000

Environment

  • BIGIP with RAID platform
  • At least one disk has failed

Cause

Procedure to replace a failed disk.

 Recommended Actions

Physically identify and remove problematic disk.

Note: Do not physically remove the bad disk from the device without following the steps below.

1. Verify the disk status.

tmsh show sys raid

Sys::Raid::Bay
Bay Shelf Name Serial Number  Array Member Array Status
-------------------------------------------------------------
1   1      HD2  WD-WX11E83L0824 yes     ok
2   1      HD1  WD-WXE1E749W87U no      failed

Output above shows the suspect disk is in bay 2.

2. To be on the safe side try and remove it from the array.

If the system throws an error ignore it.

tmsh modify sys raid array MD1 remove HD1

3) Physically identify the bad disk.

Physically identify the failing disk using flash-led option for the command "tmsh modify sys raid".
Identify the bay reported from the output of "tmsh show sys raid" in this case the failing disk is in bay 2.

tmsh modify sys raid bay 2 flash-led

LED on the given disk will start flashing and once physically identified can be removed.
Stop flashing once failing disk has been physically identified.

tmsh modify sys raid bay 2 no-flash-led

Steps to install replacement disk 

a) Physically add the new disk into bay 2.

First check to ensure the system can see the new disk.

tmsh show sys raid

Sys::Raid::Bay
Bay Shelf Name Serial Number  Array Member Array Status
-------------------------------------------------------------
1   1      HD2  WD-WX11E83L0824 yes     ok
2   1      HD1  WD-WXE1E569W38U no      undefined

b) Add the new disk to the raid array

Adding new disk to the raid array assuming we are replacing HD1 in bay 2

tmsh modify sys raid array MD1 add HD1

Give the system time to add the new disk and copy data to it.
 After at least 2 hours assuming new disk successfully replicated

tmsh show sys raid

Sys::Raid::Bay
Bay Shelf Name Serial Number  Array Member Array Status
-------------------------------------------------------------
1   1      HD2  WD-WX11E83L0824 yes     ok
2   1      HD1  WD-WXE1E569W38U yes     ok
