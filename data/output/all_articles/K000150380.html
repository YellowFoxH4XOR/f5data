K000150380: F5OS GUI logs out users every few minutes

Source

Description

F5OS automatically logs out users every few minutes when you use Cloudflare WARP

 

Environment

Cloudflare WARP is in used.

F5OS

 

Cause

The problem is that the Cloudflare and any VPN services could change the IP before accessing F5 OS appliance. Therefore the F5OS will logs out the users if the source IP has been changed. In a LTM device, the workaround is to disabled the parameter:

"Require a Consistent Inbound IP For the Entire Web Session" option, described in K41126983

 

Recommended Actions

There is no such option in F5OS. F5 has raised RFE ID1828133
