Description

SSL handshake fails with message overflow errors such as:

  • 0x1b5adb9:2003 {peer} SSL error (handshake_failure(40))
  • 0x18dda11:1656 SSL error (record_overflow(22))
  • LB02 warning tmm[20405]: 01260009:4: Connection error: ssl_hs_tx:3324: hs msg overflow (40)

Environment

  • Virtual Server
  • SSL Profile
  • Mutual SSL authentication
  • Session Ticket
  • Overly large element in handshake, such as certificate chain or cipher suite list.

Cause

Beginning in v11.4.x, a configurable default SSL handshake buffer size of 32KB was introduced. If the client SSL profile receives a client authentication certificate or the back-end server sends large SSL certificate files this may cause the entire handshake to exceed the default buffer size of 32KB.

Recommended Actions

  1. Verify the existing SSL handshake buffer size:
    tmsh list sys db tmm.ssl.maxhandshakesize
  2. The existing size is displayed 
    sys db tmm.ssl.maxhandshakesize {
        value "32768"
    }
  3. Increase the handshake buffer size, replacing <###> with the desired size in bytes:
    modify sys db tmm.ssl.maxhandshakesize value <###>
  4. Verify the increase:
    tmsh list sys db tmm.ssl.maxhandshakesize
  5. Save the change:
    save /sys config

Additional Information

To calculate the total SSL handshake size, add the total size of all handshake messages, starting at ClientHello up to the Finished message. Do not include record layer headers in this calculation. For example:

1Client Hello87228722
2Server Hello598781
3Certificate646915250
4ServerKeyExchange62115871
5CertificateRequest42816299
6ServerHelloDone416303
7Certificate (Client)827124574
8ClientKeyExchange10224676
9CertificateVerify13624812
10ChangeCipherSpecNot included in 'Finished' message verify_data calculation 
11Finished1624828
12New Session Ticket 845833286
13ChangeCipherSpecNot included in 'Finished' message verify_data calculation 
14Finished1633302

Note: When viewing in Wireshark the 'size' can be found in the Packet Information Panel for each heading. Will show as the Length:

Handshake Protocol: Client Hello
    Handshake Type: Client Hello (1)
    Length: 167

Then add 4 bytes of read-next-handshake-header (4 bytes = 1-byte type and 3-byte length). would be 33306
The minimum value of tmm.ssl.maxhandshakesize would be 33306.
