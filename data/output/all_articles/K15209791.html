Known Issue

Portal Access rewritten JavaScript content may produce an error.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a Portal Access profile.
  • JavaScript code sent by the destination resource contains a function.prototype call.

    Following is an example of the JavaScript code:

    <script>
    function genericFunction(obj, key) {
    var prototype = obj.prototype;
    var orig = prototype[key];
    delete prototype[key];
    prototype[key] = orig;
    }
    genericFunction(Function, 'call
    alert.call(this, 'Success
    </script>

Impact

The rewritten JavaScript does not function.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you access the rewritten JavaScript code, the system displays an error message similar to the following example:

    Object doesn't support property or method 'call'

  • Applications dependent on JavaScript may fail to function.
  • The system may not correctly display the Portal Access content.
