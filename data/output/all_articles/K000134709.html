Description

After following documentation on setting up OIDC auth to NMS, OIDC authentication fails or after authentication the page is blank and possibly there is a little spinner in the middle of the page.

NGINX / OpenID Connect login failure

Environment

NMS
Keycloak

Cause

Configuration

Recommended Actions

The following is supplemental information to existing documentation on how to properly implement OpenID Connect authentication into NMS

  • Following documentation Prerequisites then come back here for the next step
  • Follow documentation Configure Keycloak: 
    • When going through Configure a User under the Details tab specify an Email (can be arbitrary) and enable Email Verified 
    • After completing Configure a Client edit the client, go to Mappers tab, click Add Builtin button and add the groups mapper 
    • Note: Under Configure a Custom Role, the Keycloak Realm Role created and assigned to the Keycloak user will need to match the NMS User Groups group name created below
  • On NMS go to Settings -> Roles and create a role or roles that will be assigned, via an NMS User Groups group, to the Keycloak user 
  • On NMS go to Settings -> User Groups:
    • Create a group with a name that matches the Keycloak Realm Role that is assigned to the Keycloak user
    • Assign the desired role or roles 
    • Note: The NMS User Groups group name must match the name of the Keycloak Realm Role assigned to the Keycloak user
  • Follow documentation Enable OIDC (on NMS): 
    • When editing /etc/nms/nginx/oidc/openid_configuration.conf, at the bare minimum, be sure to do the following: 
      • Change the Keycloak endpoints in the map directives to match the host and realm of the Keycloak environment. For example, if the Keycloak host and realm is http://x.x.x.x:8080 and nginx respectively then the endpoints will be the following: 
        • default "http://x.x.x.x:8080/auth/realms/nginx/protocol/openid-connect/auth";
        • default "http://x.x.x.x:8080/auth/realms/nginx/protocol/openid-connect/token";
        • default "http://x.x.x.x:8080/auth/realms/nginx/protocol/openid-connect/certs";
      • Change the value of the oidc_client and oidc_client_secret maps to match the Keycloak client settings

Additional Information

When logging into NMS the following will occur:

  • User-agent redirected to Keycloak login page
  • After Keycloak login, NMS gets the user information from Keycloak via OAuth code exchange in an NGINX subrequest
  • NMS uses the Keycloak provided user information to do the following:
    • Create an NMS user based on the Keycloak user’s Email value
    • Assigns the NMS user the NMS Roles assigned to the NMS User Groups that match the names of the Keycloak Realm Roles assigned to the Keycloak user
