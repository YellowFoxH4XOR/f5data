K000149835: GUI error "Failure for data/openconfig-system:system/f5-mgmt-ip:mgmt-ip" after upgrade to 1.8.0

Type
Support Solution
Published
2025-02-18
Updated
2025-07-03
Applies to
  • F5OS
  • F5OS-C: 1.8.0
Source
https://my.f5.com/manage/s/article/K000149835

Description

  • After upgrade to F5OS software version 1.8.0 the GUI show the following error after login:

    Failure for data/openconfig-system:system/f5-mgmt-ip:mgmt-ip?with-defaults=report-all API. The server or an underlying service is unreachable.

  • Messages similar to the following can be seen on messages.log

    confd[657]: nodename=controller-1 - no registration found for callpoint mgmt-ip-floating/get_elem of type=external
    confd[657]: nodename=controller-1 devel-c no registration found for callpoint mgmt-ip-floating/get_elem of type=external path /oc-sys:system/f5-cmi:mgmt-ip/state/floating/ipv4-address
    confd[657]: nodename=controller-1 - no registration found for callpoint mgmt-ip-floating/get_elem of type=external
    confd[657]: nodename=controller-1 devel-c no registration found for callpoint mgmt-ip-floating/get_elem of type=external path /oc-sys:system/f5-cmi:mgmt-ip/state/floating/ipv6-address

Environment

  • Upgrade to F5OS-C 1.8.0
  • Controller
  • GUI

Cause

Floating IP callpoint failed to register on controller-1.

Recommended Actions

Reboot the affected controller

Additional Information

None
