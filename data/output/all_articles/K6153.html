Known Issue

This is the result of a known issue. Configuring an IPv6 Global Traffic server object with the gateway_icmp monitor will cause the server object to be marked down, as the gateway_icmp monitor type does not support IPv6.

F5 Product Development tracked this issue as CR59943 and it was fixed in BIG-IP GTM 9.3. For information about upgrading, refer to the BIG-IP GTM Release Notes.

Workaround

To work around this issue you can configure a monitor type of tcp, or tcp_half_open, or other non-icmp based monitor, to monitor the IPv6 objects.

For instructions about how to create a non-icmp monitor, refer to the Configuring Monitors chapter of the Configuration Guide for BIG-IP Global Traffic Management.
