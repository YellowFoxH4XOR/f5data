Description

When attempting to delete a self-IP on the BIG-IP, getting this error message:

01071413:3: Cannot delete IP (<IP_address>) because it is used by a system unicast address.

For example:

01071413:3: Cannot delete IP (172.16.70.12) because it is used by a system unicast address.

Environment

You may encounter this message in the following locations:
  • the /var/log/ltm file
  • the Configuration utility (webUI)
  • the command line interface (CLI)

Cause

The self IP address you are attempting to delete is currently in use in the Failover Network configuration on the device

Recommended Actions

Remove the self IP address from the Failover Unicast Configuration settings. To do so, perform the following procedure:

Impact of workaround: The impact of the suggested workaround depends on your specific environment. F5 recommends you perform these changes during a maintenance window and consider the possible impact on your environment.

BIG-IP 13.0.0 and later:
  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the device name.
  4. Click the Failover Network tab.
  5. In the Failover Unicast Configuration section, click the checkbox next to the IP address you would like to delete, and then click Delete.
  6. Click Update.
BIG-IP 11.x - 12.x:
  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the device name.
  4. Point to the Device Connectivity tab, and then click Failover Network.
  5. In the Failover Unicast Configuration section, click the checkbox next to the IP address you would like to delete, and then click Delete.
  6. Click Update.
You can now delete the self IP address.
