K000160358: High CPU usage spikes and pool flapping due to excessive tcp_half_open monitors on BIG-IP LTM

Type
Support Solution
Published
2026-03-21
Updated
2026-03-21
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000160358

Description

BIG-IP LTM experiences high CPU usage spikes on control-plane cores, causing pool members flapping up and down states. Health monitor failures are reported with errors such as "No successful responses received before deadline." System logs also show the bigd process load exceeding 80%.

Environment

  • BIG-IP LTM
  • tcp_half_open health monitor

Cause

The root cause is the excessive number of tcp_half_open monitor instances configured on the BIG-IP LTM. The tcp_half_open monitor type is significantly more CPU-intensive than standard TCP monitors. Bug ID 544902

Answer/Recommended Actions

To resolve high CPU usage and pool flapping caused by excessive tcp_half_open monitors, migrate them to standard TCP monitors wherever possible. This will reduce CPU usage and stabilize pool monitoring.
