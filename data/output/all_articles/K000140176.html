Description

This article describes the procedure to generate tarball files from a specific slot of VIPRION.

Environment

  •   VIPRION platform 
  •   Slots or Blades
  •   vCMP guest environments 

Cause

Support may need tarball files collected from a specific affected slot or blade running on a VIPRION platform.

Recommended Actions

You can use the following procedure to take tarball files from a specific slot of VIPRION.

For this procedure, we made the following assumptions:

  • Support asked for a tarball of the logs from slot 2
  • SSH access to cluster management IP address is available.
  1. SSH into cluster management IP address.
  2. To change into bash shell from TMSH shell, type the following command:
        run /util bash
  3. Enter Slot2 SSH:
        ssh slot2
  4. Type the following command to change into /var/tmp directory:
        cd /var/tmp
  5. To create tarball of logs on slot 2, type the following command:
        tar -czvf slot2_log.tar.gz /var/log/* (this will put a tarball of the logs in /var/tmp directory called slot2_log.tar.gz)
  6. Retrieve this file to upload to the case.
