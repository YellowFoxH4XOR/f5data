Description
Ctrl-Alt-Del might reboots BIG-IP Virtual Edition (VE)

Environment

  • BIG-IP Virtual Edition
  • Virtual Console

Cause
A device reboot occurs when pressing Ctrl-Alt-Del or sending the command to a BIG-IP Virtual Edition (VE) virtual console.

Recommended Actions

  1. To mitigate an accidental reboot run the following command from Advanced Shell (bash):

systemctl mask ctrl-alt-del.target

  1. To validate the workaround run the following command:

systemctl list-unit-files | grep ctrl-alt-del.target


The output should be similar as follows, 

ctrl-alt-del.target                        masked
