K7076: Error Message: ''Device Not Found'' in Network Access pop-up window on Windows 2000

Issue

If you use Windows 2000 to access the FirePass controller, and receive a Device Not Found error message in the Network Access pop-up window when you start a Network Access Favorite, you may be missing a necessary Windows Registry entry. The following Registry key is required for Network Acces to function:

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce

If this key does not exist, Network Access Favorites will fail.

In addition to the Device Not Found error message, you may see additional pop-ups with error messages. For example:

  • Error downloading required files
    An exception occurred in the service when handling the control request. 

  • Error downloading required files
Invalid access to memory location.

  • Error downloading required files
Access is denied

Adding the registry key

You can work around this issue by adding the registry key. To do so, perform the following procedure:

  1. Log on to the Windows 2000 system using an account with privileges to edit the registry for the users on the system.

  2. Click the Start menu.

  3. Select Run.

  4. In the Open: window, type the following:

    regedit

  5. Click the OK button.

  6. In the navigation pane of Regedit, click the plus icon ( + ) next to HKEY_LOCAL_MACHINE.

  7. Click the plus icon next to SOFTWARE.

  8. Click the plus icon next to Microsoft.

  9. Click the plus icon next to Windows.

  10. Click the plus icon next to CurrentVersion.

  11. Click the folder icon next to RunOnce.

  12. In the Edit->New->Key menu, select String Value.

  13. For the folder name, type the following:

    RunOnce

  14. Type the following:

    Enter

    The Registry key should now be added, with the following attributes:

    • Name (Default)

    • Type REG_SZ

    • Data (value not set)

  15. Close the regedit program.
