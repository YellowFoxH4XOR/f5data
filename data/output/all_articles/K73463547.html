Topic

This article applies to the BIG-IP versions in their software branches listed below:

  • BIG-IP 11.5.9 and later
  • BIG-IP 11.6.4 and later
  • BIG-IP 12.1.4.1 and later
  • BIG-IP 13.1.1.5 and later
  • BIG-IP 14.0.0.5 and later
  • BIG-IP 14.1.0.2 and later
  • BIG-IP 15.0.0 and later

Description

The scp command is used to transfer files to and from the BIG-IP system. Beginning in the previously listed BIG-IP versions, the scp blacklist and whitelist restricts how files are transferred to the BIG-IP system with the scp command if you don't have Advanced shell access. This includes if you have your Terminal Access set to either Disabled or tmsh. The locations of the scp blacklist and whitelist files are as follows:

Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

  • /config/ssh/scp.whitelist
  • /config/ssh/scp.blacklist

Note: The whitelist and blacklist apply only to copying files to the BIG-IP system. They do not apply to copying files out of the system.

The blacklist and whitelist files restrict scp transfer to the BIG-IP system in the following ways:

  • You can only transfer files using scp to directories in the system specified in the whitelist file. You are not allowed to transfer files using scp to any directories that are not specified in the whitelist.
  • If the same directory is specified both in the whitelist and the blacklist, the blacklist takes higher precedence.
  • The blacklist allows granular scp controls. While the whitelist allows you to transfer files using scp to an entire directory, you may specify specific files within that directory not to be overwritten by specifying their file names in the blacklist. For example, the /config/ssh/scp.whitelist file contains the /config directory and the /config/ssh/scp.blacklist file contains the file /config/user_alert.conf. When you attempt to copy /config/user_alert.conf to the BIG-IP system, you are denied with the following error:

    $ scp user_alert.conf john@example_bigip:/config/user_alert.conf
    Password:
    file not allowed

Recommendations

When using the scp command to copy files to the system, you can allow or disallow the target directories or files by modifying the whitelist and blacklist. To do so, perform the following procedure:

Important: Due to CVE-2019-6679, the system does not properly enforce the access controls for the scp.whitelist and scp.blacklist files when paths are symbolic links (symlinks). When configuring your BIG-IP system to use this feature, F5 recommends upgrading to a version listed in the Fixes introduced in column of the security advisory K54336216: SCP vulnerability CVE-2019-6679.

Impact of procedure: Performing the following procedures should not have a negative impact on your system.
  1. Log in to the BIG-IP command line.
  2. To allow or disallow users to copy files to a specific directory, add or remove an entry to the appropriate whitelist or blacklist files. For example:
    • to allow files to be copied to the /shared directory, add the following entry to the /config/ssh/scp.whitelist file:

      /shared

    • to disallow a specific file, /config/example to be overwritten, add the following entry to the /config/ssh/scp.blacklist file:

      /config/example

  3. Enter the following command to restart the sshd process:

    bigstart restart sshd

    Note: When you update or upgrade your system, the whitelist and blacklist files are erased.
