Known Issue

The iControl representational state transfer (REST) application programming interface (API) incorrectly omits the partition field in the device group member information.

This issue occurs when the following conditions is met:

  • The iControl REST API call collects information about device group members.
Note: If your BIG-IP system is running 11.6.0, specifically HF6 and later hotfixes are affected.

Impact

The absence of the partition field causes issues with automation scripts that rely on that data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Automation scripts fail that rely on the partition information in a separate field.
  • The iControl response format from an affected device omits the partition field and includes the partition as a prefix to the device name in the name field, similar to the following example:

    {
        "fullPath": "/Common/BIGIP-1.localdomain",
        "generation": 1,
        "kind": "tm:cm:device-group:devices:devicesstate",
        "name": "/Common/BIGIP-1.localdomain",
        "selfLink": "https://localhost/mgmt/tm/cm/device-group/~Common~device_trust_group/devices/~Common~BIGIP-1.localdomain?ver=12.0.0"
    }
            
    The correct iControl response format should include a partition field and not prefix the partition to the device name in the name field, similar to the following example:

    {
        "fullPath": "/Common/BIGIP-1.localdomain",
        "generation": 1,
        "kind": "tm:cm:device-group:devices:devicesstate",
        "name": "BIGIP-1.localdomain",
        "partition": "Common",
        "selfLink": "https://localhost/mgmt/tm/cm/device-group/~Common~device_trust_group/devices/~Common~BIGIP-1.localdomain?ver=12.1.0"
    }

Resolution

Status

F5 Product Development has assigned ID 552917 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, it may be possible to redeploy automation scripts to look for the partition in the fullPath or name fields.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your environment.
