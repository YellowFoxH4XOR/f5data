Topic

By default, the bigd health-checking daemon assumes that any stdout messages from the EAV script to the console equate to a positive response, or the node marked up. This is important to know when designing an EAV. The general guideline is that the EAV reports nothing if the node is marked down.

When a node is up, the EAV script prints data to the stdout and bigd marks and displays the node as up. When a node is down, the EAV does not print data to the stdout, as a result bigd marks and displays the node as down.

Important: Any node that fails to meet the EAV criteria should not be sent to stdout. If you create an EAV script that displays a node as up for a positive response, but also displays down for a negative response, the bigd process will interpret both responses as up.

You can view an example of a basic Health Monitor/EAV on the BIG-IP system in the following location: /usr/local/lib/pingers/sample_pinger.
