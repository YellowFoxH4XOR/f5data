Topic

Beginning with Data ONTAP 7.3, NTFS Sparse File Attribute is supported on NetApp storage systems. However, the NetApp implementation of Sparse File Attribute Support is not compatible with ARX sparse files.

If an ARX managed volume imports shares on a NetApp filer running Data ONTAP 7.3 or later, you must disable sparse files support on the managed volume using the no sparse-files command. For more information, refer to the sparse-files command in the ARX CLI Reference Guide.

If sparse files support is enabled, migration of files to or from shares on a NetApp filer running Data ONTAP 7.3 or later will fail.
