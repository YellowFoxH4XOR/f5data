Description

When trying to download document files, such as PDF or DOC, the request gets blocked by ASM.

  • The block is due to "Illegal query string length"
  • The event log shows the file extension along with the expected query string length and the query string length in that request.

Environment

  • BIG-IP ASM
  • Office document files being downloaded

Cause

This can happen if a limit in query string length is configured for various file types and if particular requests exceed that query string length.

Recommended Actions

Follow the steps below to find the which setting to modify and how much to increase.

  1. Check the event logs under Security ›› Event Logs : Application : Requests and filter for that particular ASM policy.
  2. Select Illegal query string length for the Violation filter to search for logs related to this violation. The Violation filter is under the BASIC tab for BIG-IP Advanced WAF/ASM 17.x or under the IP / Username / URL tab for BIG-IP Advanced WAF/ASM 16.x and earlier. Then inspect all the logs blocked due to Illegal query string length.
  3. Note the File Type and Detected Query String Length from violation details for a good number of requests.
  4. After you have identified the File Type and Detected Query String Length,
    • BIG-IP Advanced WAF/ASM 16.x and later

      Navigate to Security ›› Application Security : Security Policies : Policies List, select the policy name and navigate to HTTP Message Protection > File Types, select the specific extension and increase Query String Length.

    • BIG-IP Advanced WAF/ASM 15.x and earlier

      Navigate to Security ›› Application Security : File Types : Allowed File Types, under specific extension, increase Query String Length.

  5. Make sure the Query String Length slightly greater than the Detected Query String Length identified in Step 3.
    For example: If there are 10 requests that got blocked and the highest Detected Query String Length is 1800 among these requests, increase Query String Length to 2000.
