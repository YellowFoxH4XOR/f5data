K61324943: xMatters SAML requires certificate and key

Type
Support Solution
Published
2025-07-01
Updated
2025-07-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K61324943

Description

  • User gets a "404" when connecting to xMatters SP

 

Environment

  • SAML, BIG-IP as IdP
  • 404 Error message from xMatters SP

 

Cause

xMatters *REQUIRES* assertions to be signed, but they do not clearly state this on their SAML Configuration page

 

Recommended Actions

  • Configure certificate+key for external SAML SP connector on BIG-IP and import that certificate in xMatters' SAML Configuration.
