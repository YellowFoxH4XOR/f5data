Known Issue

Deleting a partition may generate a configuration warning.

This issue occurs when all of the following conditions are met:

  • You create a new partition on the BIG-IP APM device using the Traffic Management Shell (tmsh).
  • You use the Configuration utility to delete an empty partition created with the tmsh utility.

Impact

The Configuration utility displays an error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to delete the partition created with the tmsh utility, the Configuration utility displays an error message that appears similar to the following example:

    010717ac:4: Configuration Warning: Cannot remove directory with symlink to sandbox for partition (bz497676). Error: No such file or directory. If you have access to bash shell, try to run command: rmdir /var/sam/www/webtop/sandbox/files_d/<partition name>_d/

    Note: The error message is benign and may be safely ignored.

  • You cannot view the /var/sam/www/webtop/sandbox/files_d/<partition name>_d/ directory.
