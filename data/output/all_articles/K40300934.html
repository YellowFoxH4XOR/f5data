Known Issue

The HTTP Compression and Web Acceleration profiles may not perform as configured.

This issue occurs when one or more of the following conditions is met:

  • A Web Acceleration profile has been configured with glob or regular expression matching in the URI List and is applied to a virtual server handling HTTP traffic.
  • An HTTP Compression profile has been configured with a glob or regular expression matching in the URI List or Content List and is applied to a virtual server handling HTTP traffic.
The MCP process does not properly validate the configuration before providing it to the Traffic Management Microkernel (TMM) process, which leads to the issue.

Impact

HTTP content is not included or excluded for compression and caching as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H574694 on the Diagnostics > Identified > Medium screen.
  • HTTP content is not included or excluded for compression and caching as expected.
  • When you apply an affected profile to a virtual server, the system logs error messages in the /var/log/ltm file that appear similar to the following example:

    err tmm[12345]: 01010005:3: Profile /Common/example, cache_uri_excludes error - couldn't compile regular expression pattern: quantifier operand invalid
