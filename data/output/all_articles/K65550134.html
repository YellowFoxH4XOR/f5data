Description

A new vCMP guest is getting tmm restart errors and spiking CPU stats.

You may also see dev/hsb/hsb_lbb.c:760: Assertion "VLBB initialized" failed. logged repeatedly in the TMM logs.

Environment

  • BIG-IP
  • Recently deployed vCMP guest

Cause

vCMP guest is running a software version incompatible with the hypervisor version installed on the system

Recommended Actions

Deploy a new vCMP guest on an compatible software version.

None
