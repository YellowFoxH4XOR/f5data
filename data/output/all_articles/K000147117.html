K000147117: How do I create a second TCP LB listening in the same port?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147117

Description

Error occurs when creating a second TCP Load Balancer on the same port.

Environment

  • F5® Distributed Cloud (XC) console
  • F5® Distributed Cloud TCP Load Balancer

Resolution/Answer

To resolve the conflict:

  • Remove the existing LB using the desired port
  • Use a different, unused port
  • Assign a unique public IP
  • For Regional Edge deployments, use your own unique public IP if available

Cause

  • This configuration is unsupported; the error is expected.

Additional Information
