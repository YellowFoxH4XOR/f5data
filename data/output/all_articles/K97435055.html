Issue

Error Message

debug statsd[<PID>]: 011b0233:7: CACHE MISS during <event>, prev=<stat>, curr=<stat>.

In this error message, note the following:

  • <PID> is the process ID for the statsd process
  • <event> is the action performed
  • <stat> is the retrieved statistic 

For example:

debug statsd[31883]: 011b0233:7: CACHE MISS during rollup, prev=tmm_stat, curr=host_info_stat.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • The log level for the statsd process is set to debug.
  • A user makes a query for statistical information and the statsd process fails to find the requested data in its cache.

Impact

The statsd process gathers the requested statistical data. Performance may be impacted if there are a large number of cache misses.

Recommended Actions

You should use the debug log level only when troubleshooting, due to potential resource usage. Once troubleshooting is complete, restore the log level for the statsd process to the default setting. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Restore the log level for the statsd process to the default value by typing the following command:

    modify /sys db log.statsd.level value warning
