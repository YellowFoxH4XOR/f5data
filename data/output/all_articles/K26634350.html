Description:

There are many kinds of reason for vdi resource connection failure when you integrate VMware Horizon View with BIG-IP APM System.
You may get an error message : Can't resolve '<FQDN_Of_VDI_Resources>' as IPv4: Temporary failure in name resolution
Before submitting service request to F5 Support Team, we can check some basic service settings first. This article will show a scenario.

Environment:
  • BIG-IP with APM module provisioned.
  • Use VMware Horizon View as remote desktop resource.
  • VMWare Horizon View desktop/application resources are available on BIG-IP APM webtops.
  • Connection failure when launching these desktop/application resources.
Cause:

VMware connection server may return the backend remote desktop resource to BIG-IP APM in the format of <FQDN_Of_VDI_Resource>:<TCP/UDP_Port>.
If BIG-IP APM system do not have DNS server settings, it will not able to resolve the FQDN of vdi resources, which cause connection failure.

Recommended Actions:

Configure DNS server settings on BIG-IP APM System.
Refer to K13205: Configuring the BIG-IP system to resolve DNS hostnames (11.x and later)
