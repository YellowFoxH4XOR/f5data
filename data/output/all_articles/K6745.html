K6745: The BIG-IP GTM big3d process will leak memory if multiple probe protocols are configured and an LDNS path probe fails

Known Issue

This is the result of a known issue. The big3d memory leak will occur if more than one metrics collection protocol is specified in the wideip.conf file, and if the target LDNS server for a path probe cannot be reached.

The following error message may indicate a big3d memory leak, and is logged to the /var/log/gtm file:

Could not create socket: Too many open files

F5 Product Development tracked this issue as CR70156, and CR70157 and it was fixed in BIG-IP GTM 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
