K000156646: Configuration didn't load after sync due to some protocol-inspection errors

Type
Support Solution
Published
2025-09-26
Updated
2026-05-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000156646

Description

Configuration load and HA sync failures may occur on BIG-IP devices, with error messages such as:

01071c27:3: Protocol Inspection internal error: Profile doesn't exist.

01071488:3: Remote transaction for device group ... failed with error 01071c27:3: Protocol Inspection internal error: Profile doesn't exist.

These errors are seen during configuration load or device group synchronization. The configuration contains protocol-inspection objects, and warnings about deprecated compliance objects may also be present.

Environment

  • AFM was previously provisioned but is currently deprovisioned

Cause

Protocol-inspection objects associated with AFM remain in the configuration after AFM is deprovisioned. These orphaned objects (such as compliance-maps and compliance-objects) are unsupported when AFM is not provisioned, causing configuration load and HA sync failures. Deprecated compliance objects may also trigger warnings and errors.

Recommended Actions

  • Manually remove all orphaned protocol-inspection objects from the configuration files (e.g., /config/bigip.conf`).).
  • Identify and delete entries such as:

security protocol-inspection compliance-map <name> { ... }

security protocol-inspection compliance-objects <name> { ... }

Examples:

security protocol-inspection compliance-map /Common/map_10426 { ... }

security protocol-inspection compliance-objects /Common/allowed_list { ... }

security protocol-inspection compliance-objects /Common/argument_len_max { ... }

security protocol-inspection compliance-objects /Common/command_argument_len_max { ... }

  • Refer to these resources for further guidance:
    • K000149408: "01071c27:3: Protocol Inspection internal error: Profile doesn't exist" after upgrade
    • K000149104: Compliance is deprecated and removed from '/Common/protocol_inspection'](__WHITELISTED_URL_PLACEHOLDER_7__)
  • After removing orphaned configuration items, verify by running:
    tmsh load sys config verify
  • Then perform HA sync again.
  • Before upgrading to a newer BIG-IP version, ensure all deprecated or unsupported AFM configuration objects have been cleaned up.
