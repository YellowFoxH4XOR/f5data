Topic

Defining a Viewstate parameter as a BIG-IP ASM dynamic parameter may result in false positives. Alternatively, defining the .NET Viewstate parameter as an Ignore Value will reduce the likelihood of an attack signature flagging the parameter value as a false positive.

The .NET Viewstate parameter maintains form field values, for situations where the server responds with an error message. As a result, the user does not have to re-enter the information. The Viewstate parameter is a hash-signed Base 64 encoded signature value that is contained within the form field value, and is therefore not typically vulnerable to parameter tampering. Any attempts to tamper with the Viewstate value will trigger an invalid viewstate MAC error response message from the server.

Note: Due to the Base 64 encoding, the BIG-IP ASM system is unable to decode and view the Viewstate parameter value.
