K8861: The SMTP profile Sender DNS setting has a timeout of 10 seconds

Topic

You can use an SMTP security profile to control whether the BIG-IP ASM system allows email requests to be sent to a protected SMTP server. For more information about configuring an SMTP security profile, refer to the BIG-IP ASM Configuration Guide.

The Sender DNS setting allows the BIG-IP ASM system to log an alarm or block email requests when the hostname of the server sending the email cannot be resolved with a DNS query.

When the BIG-IP ASM performs a DNS query for the SMTP server hostname, the timeout is 10 seconds, and it is not configurable. If the DNS query exceeds the timeout, the SMTP firewall will block the email.

F5Product Development is tracking a feature enhancement to make the timeout configurable as CR100112. To monitor the status of this CR, refer to the BIG-IP ASM Release Notes.
