Known Issue

The BIG-IP ASM system may not ignore the NULL value for parameters defined as File Upload.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured with a Parameter Data Type defined as File Upload.
  • The BIG-IP ASM system process a multipart request with a textual (text/plain) content type.
  • The multipart request content contains a NULL value.

Impact

A NULL in the request violation is triggered.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP ASM system does not ignore the NULL value in multipart requests, and triggers a NULL in the request violation

None

Fix information

The fix for this issue introduces the ignore_null_in_multipart_text parameter. To implement this parameter on fixed versions, perform the following procedure:

Impact of fix: Restarting the asm process causes a brief traffic disruption.

  1. Log in to the command line of the BIG-IP ASM system.
  2. To enable the ignore_null_in_multipart_text parameter, enterthe following command:

    /usr/share/ts/bin/add_del_internal add ignore_null_in_multipart_text 1

  3. To restart the BIG-IP ASM service, type the following command:

    tmsh restart /sys service asm
