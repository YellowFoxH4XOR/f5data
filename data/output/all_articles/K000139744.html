K000139744: The system returned an unexpected error (400 BAD REQUEST)

Type
Support Solution
Published
2024-05-22
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000139744

Description

You are setting up the BIG-IQ for the first time and encounter "The system returned an unexpected error (400 BAD REQUEST)" after clicking next on the networking page.

Environment

  • BIG-IQ

  • Initial setup

Cause

The issue occurs if there is an underscore in the hostname (Bug ID 1584521).

Recommended Actions

Replace the underscore (_) with a hyphen (-).

Additional Information

If the underscore is required, after you complete the setup process, rename the BIG-IQ from the command line.

  • tmsh modify sys global-settings hostname <new hostname with underscore>
  • tmsh save sys config
