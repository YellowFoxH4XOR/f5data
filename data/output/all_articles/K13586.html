Known Issue

Description

When using the SNMP utility to query the active ARX system, the ARX system responds with the incorrect IP address as the source address.

This issue occurs when the following condition is met:

  • An SNMP GET request is used to query the active ARX device.

The ARX system places one of the proxy IPs instead of the queried management address IP as the source IP address for the SNMP GET response. This behavior occurs regardless of which management interface is queried.

Impact

SNMP responses may be dropped or rejected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Response returns from an ARX proxy IP versus the queried management IP.
  • Response from the ARX system is dropped or rejected.
