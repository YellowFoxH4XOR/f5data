K2126: Enabling and disabling configuration objects with the 3dpipe command

Knowledge
Published
2006-02-17
Updated

Status

Applies to

  • 3-DNS: 4.6.4
Source

Topic

You can use the 3dpipe command to enable or disable the following configuration objects:
  • Datacenters
  • Devices
  • Synchronization groups
  • Virtual servers
  • Wide IPs
  • Wide IP pools

Datacenters

To disable a datacenter, use the following command syntax:

3dpipe datacenter <datacenter> disable <time> <username>

Replace <datacenter> with the name of the datacenter.

The <time> option is not required. If you specify a number of seconds, 3-DNS will re-enable the datacenter after the specified time has elapsed.

The <username> option is not required. If you provide a username, 3-DNS will list the username in the comments of the wideip.conf file. 3-DNS will also report it to syslog for use in the 3dns log file and to SNMP traps that are triggered when the configuration is changed. The username does not have to be a 3-DNS username; you can use any short string of text.

For example, to disable the Main datacenter indefinitely type the following command:

3dpipe datacenter Main disable

To disable a datacenter for 60 seconds when the current UNIX epoch time is 1113228000 and perform the action as the username Bob type the following command:

3dpipe datacenter Main disable 1113228060 Bob

To enable a data center, use the following command syntax:

3dpipe datacenter <datacenter> enable

For example:

3dpipe datacenter Main enable

Devices

To disable a device, use the following command syntax:

3dpipe <device> <address> disable <time> <username>

Replace <device> with one of the following options:

  • 3dns
  • bigip
  • edgfx
  • router
  • host

Replace <address> with the IP address 3-DNS uses to access the device.

The <time> option is not required. If you specify a number of seconds, 3-DNS will re-enable the device after that specified time has elapsed.

The <username> option is not required. If you provide a username, 3-DNS will list the username in the comments of the wideip.conf file. 3-DNS will also report it to syslog for use in the 3dns log file and to SNMP traps that are triggered when the configuration is changed. The username does not have to be a 3-DNS username; you can use any short string of text.

For example, to disable the device accessed from 172.16.22.4 indefinitely, you would type the following command:

3dpipe bigip 172.16.22.4 disable

To disable the device accessed from 172.16.22.4 for 60 seconds, when the current UNIX epoch time is 1113228000, and perform the action as the username Bob, type the following command:

3dpipe host 172.16.24.1 disable 1113228060 Bob

To enable a device, use the following command syntax:

3dpipe <device> <address> enable

Replace <device> with with one of the following options:

  • 3dns
  • bigip
  • edgfx
  • router
  • host

Replace <address> with the IP address 3-DNS uses to access the device.

For example:

3dpipe 3dns 172.16.22.4 enable

Synchronization groups

To disable a synchronization group, use the following command syntax:

3dpipe syncgroup <syncgroup> disable <time> <username>

Replace <syncgroup> with the name of the synchronization group.

The <time> option is not required. If you specify a number of seconds, 3-DNS will re-enable the device after that specified time has elapsed.

The <username> option is not required. If you provide a username, 3-DNS will list the username in the comments of the wideip.conf file. 3-DNS will also report it to syslog for use in the 3dns log file and to SNMP traps that are triggered when the configuration is changed. The username does not have to be a 3-DNS username; you can use any short string of text.

For example, to disable the MainGroup synchronization group indefinitely, you would type the following command:

3dpipe syncgroup MainGroup disable

To disable a the MainGroup synchronization group for 60 seconds, when the current UNIX epoch time is 1113228000, and perform the action as the username Bob, type the following command:

3dpipe syncgroup MainGroup disable 1113228060 Bob

To enable a synchronization group, use the following command syntax:

3dpipe syncgroup <syncgroup> enable

For example:

3dpipe syncgroup MainGroup enable

Virtual servers

To disable any type of virtual server, use the following command syntax:

3dpipe virtual <address>:<port> disable <time> <username>

Replace <address> with the virtual server's IP address.

Replace <port> with the virtual server's service port.

The <time> option is not required. If you specify a number of seconds, 3-DNS will re-enable the virtual server after that specified time has elapsed.

The <username> option is not required. If you provide a username, 3-DNS will list the username in the comments of the wideip.conf file. 3-DNS will also report it to syslog for use in the 3dns log file and to SNMP traps that are triggered when the configuration is changed. The username does not have to be a 3-DNS username; you can use any short string of text.

For example, to disable a virtual server at 172.16.28.1 indefinitely, type the following command:

3dpipe virtual 172.16.28.1 disable

To disable a virtual server at 172.16.28 for 60 seconds, when the current UNIX epoch time is 1113228000, and perform the action as the username Bob, type the following command:

3dpipe virtual 172.16.28.1 disable 1113228060 Bob

To enable a virtual server, use the following command syntax:

3dpipe virtual <address>:<port> enable

For example:

3dpipe virtual 172.16.28.1 enable

Wide IPs

To disable a wide IP in all datacenters, use the following command syntax:

3dpipe wideip <wideip> disable <time> <username>

Replace <wideip> with the wide IP's fully qualified domain name.

The <time> option is not required. If you specify a number of seconds, 3-DNS will re-enable the wide IP after that specified time has elapsed.

The <username> option is not required. If you provide a username, 3-DNS will list the username in the comments of the wideip.conf file. 3-DNS will also report it to syslog for use in the 3dns log file and to SNMP traps that are triggered when the configuration is changed. The username does not have to be a 3-DNS username; you can use any short string of text.

For example, to disable the askwip1.askf5.com wide IP indefinitely, you would type the following command:

3dpipe wideip askwip1.askf5.com disable

To disable the askwip1.askf5.com wide IP for 60 seconds, when the current UNIX epoch time is 1113228000, and perform the action as the username Bob, type the following command:

3dpipe wideip askwip1.askf5.com disable 1113228060 Bob

To enable a wide IP in all datacenters, use the following command syntax:

3dpipe wideip <wideip> enable

For example:

3dpipe wideip askwip1.askf5.com enable

To disable a wide IP for a specific datacenter, use the following command syntax:

3dpipe wideip <wideip> datacenter <datacenter> disable <time> <username>

For example, to disable the askwip1.askf5.com wide IP in the Main datacenter indefinitely, you would type the following command:

3dpipe wideip askwip1.askf5.com datacenter Main disable

To disable the askwip1.askf5.com wide IP in the Main datacenter for 60 seconds, when the current UNIX epoch time is 1113228000, and perform the action as the username Bob, type the following command:

3dpipe wideip askwip1.askf5.com datacenter Main disable 1113228060 Bob

To disable a wide IP for a specific datacenter, use the following command syntax:

3dpipe wideip <wideip> datacenter <datacenter> enable

For example:

3dpipe wideip askwip1.askf5.com datacenter Main enable

Wide IP Pools

To disable a wide IP pool, use the following command syntax:

3dpipe wideip <wideip> pool <pool> disable <time> <username>

Replace <wideip> with the wide IP's fully qualified domain name.

Replace <pool> with the wide IP pool's name.

The <time> option is not required. If you specify a number of seconds, 3-DNS will re-enable the wide IP pool after that specified time has elapsed.

The <username> option is not required. If you provide a username, 3-DNS will list the username in the comments of the wideip.conf file. 3-DNS will also report it to syslog for use in the 3dns log file and to SNMP traps that are triggered when the configuration is changed. The username does not have to be a 3-DNS username; you can use any short string of text.

For example, to disable the askwip1.askf5.com pool MainPool wide IP pool indefinitely, you would type the following command:

3dpipe wideip askwip1.askf5.com pool MainPool disable

To disable the askwip1.askf5.com pool MainPool wide IP pool for 60 seconds, when the current UNIX epoch time is 1113228000, and perform the action as the username Bob, type the following command:

3dpipe wideip askwip1.askf5.com pool MainPool disable 1113228060 Bob

To enable a wide IP pool, use the following command syntax:

3dpipe wideip <wideip> pool <pool> enable

For example:

3dpipe wideip askwip1.askf5.com pool MainPool enable
