Description

Further information regarding the "Mask Sensitive Parameters in Logs" option in Web Application Firewall.

Environment

  • F5® Distributed Cloud

  • HTTP Load Balancer
  • Application Firewall

 

Answers/Recommended Actions

  • Q: What logging behavior applies when “Mask Sensitive Parameters in Logs” is set to Default?
    A: Default setting obfuscates parameter values from log data when:
    1. A URL query parameter named 'card', 'pass', 'pwd', or 'password' is detected
    2. Parameter value matches certain patterns likely to represent sensitive data, such as credit card and social security numbers.
  • Q: Can additional sensitive query parameters, POST parameters and cookies be configured?
    A: Yes, select Custom configuration and enter the names of parameters whose values should be masked from logs.  Sensitive data patterns will be masked regardless of parameter name.
  • Q: Are other payment card numbers (PANs) such as debit card numbers and prepaid card numbers also masked, besides credit card numbers?
    A: The pattern will be masked if it matches known algorithms for card numbers, such as Luhn's Algorithm.

 

  • Q: I would like to know the detailed patterns that XC uses to recognize as Payment card numbers (PANs)?
    A: We can't share internal implementation details about recognition patterns
