Web scraping is a data gathering technique for collecting and extracting information from websites. The BIG-IP ASM Web Scraping feature detects and mitigates web scraping activities for protected web applications.

Description

Web scraping is the process of automatically mining and using data collected from websites. Web scraping often involves using automated programs or bots to establish multiple sessions in which the bot downloads data from target websites. The data is often compiled into a database or spreadsheet and retrieved or analyzed later.

Web scraping may be used for the following purposes:

  • Data mining
  • Contact scraping
  • Online price change monitoring and price comparison
  • Product review scraping
  • Website change detection
  • Research
  • Tracking online presence and reputation

BIG-IP ASM Web Scraping feature operation

The BIG-IP ASM Web Scraping feature distinguishes bot behavior from human behavior by first verifying whether the client can process JavaScript code. The feature then monitors browsing behavior and tracks events, such as mouse movement and keyboard usage. If the BIG-IP ASM system detects web scraping behavior, it logs a warning and blocks the request, depending on the settings defined in the security policy.

To verify bot activity, the system uses the following client-side JavaScript code injection techniques:

  1. The client sends an initial request to a URL defined in the security policy.
  2. The BIG-IP ASM system issues a client-side JavaScript challenge to verify the client's ability to handle JavaScript code.
  3. The client browser processes the JavaScript code and resends the request, including ASM cookies.
  4. The BIG-IP ASM system verifies the ASM cookie values and forwards the request to the web application.
  5. The BIG-IP ASM system injects JavaScript code into the web server response to track mouse movement and keyboard usage.
    1. The system starts the Grace Interval setting, which indicates the maximum number of requests to review while trying to detect bot activity.
    2. Once the system determines that the client is valid, the system does not check the next several requests, as specified in the Safe Interval setting.
  6. If the system detects web scraping, it logs a warning and blocks the request, depending on the policy settings.
Configuring web scraping detection

To configure web scraping detection, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Anomaly Detection > Web Scraping.
  3. Select the appropriate policy from the Current edited security policy menu.
  4. Enable the following methods as needed to address web scraping attacks:
    • Bot detection: When you enable the Bot detection option, the system uses JavaScript to track events, such as mouse movement and keyboard usage, to determine whether a web client source is a bot or a human.
    • Session opening: When you enable the Session opening option, the system tracks events, such as a large amount of new sessions opened from the same IP address, and a large increase of sessions opened from a specific IP address.
    • Session transactions anomaly: When enabled, the system looks at the average amount of traffic for the web application, and detects unusually large number of transactions per session and large increases of session transactions.
    • Fingerprinting captures: When enabled, the system looks at information about browser attributes to identify a client. You can use this method when the system fails to detect web scraping anomalies by examining IP addresses, ASM cookies, or persistent device identification.
    • Suspicious clients: Used together with fingerprinting, this method specifies how the system identifies and protects against potentially malicious clients.
    • Persistent client identification: When enabled, the system prevents attackers from circumventing web scraping protection by resetting sessions and sending requests.
  5. Click Save.
  6. Click Apply Policy.

Recommendations

When using web scraping detection, you should consider the following factors:

  • Clients accessing the web application should have JavaScript enabled and support cookies.
  • Before you configure web scraping protection, you should configure the BIG-IP system to resolve DNS host names and create a DNS resolver. For more information, refer to K13205: Configuring the BIG-IP system to resolve DNS hostnames (11.x and later).
  • If your web application has its own search engine, you should configure it on the system. To do so, navigate to Options > Application Security > Advanced Configuration > Search Engines.
