Known Issue

An SSL handshake may succeed with incorrect padding.

This issue occurs when all of the following conditions are met:

  • The handshake occurs using TLS1.0 or higher with padding.
  • TLS records do not match with the expected padding.
When padding is used, if all bytes in the TLS record are not set to the length of the padding, the handshake should fail.

Impact

An SSL handshake succeeds with incorrect padding.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An SSL handshake succeeds with incorrect padding.
