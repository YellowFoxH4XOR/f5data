Description

You failed to save UCS in GUI and when save UCS via CLI, you encounter following problem:

# tmsh save sys ucs <path/to/UCS>
Saving active configuration...
readline() on closed filehandle $inf at /usr/local/share/perl5/F5/DbUtils.pm line <Number 1>.
readline() on closed filehandle $inf at /usr/local/share/perl5/F5/DbUtils.pm line <Number 1>.
readline() on closed filehandle $inf at /usr/local/share/perl5/F5/DbUtils.pm line <Number 1>.
No filehandle passed at /usr/local/share/perl5/F5/ConfigSync.pm line <Number 2>.
Error executing 'pre-save' configsync script /var/tmp/cs_save_pre_script. 

WARNING:There are error(s) during saving.
        Not everything was saved.
        Be very careful when using this saved file! 

Error creating package
Error during config save.
Unexpected Error: UCS saving process failed.
# 

Environment

  • BIG-IP ASM

  • Saving UCS via CLI

Cause

During the process of saving UCS, the perl script will load file /ts/install/dcc.sql and /ts/install/plc.sql, if any of them is missing, then this problem appears.

Recommended Actions

 If the problematic BIG-IP is:

  • A member of DSC, then copy the /ts/install/dcc.sql and /ts/install/plc.sql from a peer unit to the same directory of local box, after that try saving UCS will be successful.

  • A standalone unit, then please submit a support case by contacting F5 Support K2633: Instructions for submitting a support case to F5.

Additional Information

  • The missing of file /ts/install/dcc.sql or /ts/install/plc.sql could be caused by unintentionally deleting any of them when you encounter the disk space usage issue.

  • The missing of file /ts/install/dcc.sql or /ts/install/plc.sql can also lead to upgrade failure, because the version intallation will involve in the process of saving UCS.
