Known Issue

A Complex Programmable Logic Device (CPLD) register read may intermittently fail.

This issue occurs when the following condition is met:

  • You are using one of the following platforms:

    • VIPRION B2100 blades
    • BIG-IP 2000-series appliances
    • BIG-IP 4000-series appliances
    • BIG-IP 5000-series appliances
    • BIG-IP 7000-series appliances
    • BIG-IP 10000-series appliances

The CPLD registers are polled periodically to provide information about the internal status of BIG-IP hardware by various BIG-IP utilities. If the CPLD register read fails, but is successful during the next polling period (typically every 30 seconds), the correct information will display.

Impact

BIG-IP utilities may intermittently display incorrect or missing hardware details.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • At non-deterministic intervals, the system logs error messages in the /var/log/ltm file that appear similar to the following example:

    warning chmand[8522]: 012a0004:4: getLopCpldInfo read CPLD register 0x## error: LopDev: sendLopCmd: Lopd status: 1 packet: action=1 obj_id=e sub_obj=## slot_id=ff result=e len=0 crc=#### payload= (error code:0xe)

  • An error message that appears similar to the following example will typically follow the previous error message:

    notice chmand[8522]: 012a0005:5: reinitialize LOP CPLD sensors

Workaround

None

Note: You can safely ignore the error messages if they occur intermittently and infrequently. However, if the errors occur frequently and persistently, you should consider further hardware diagnostics.
