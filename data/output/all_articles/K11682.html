Known Issue

Mac OS X and Linux users may receive the following error message immediately after attempting to launch a network access session:

connection dropped

This issue can occur after the client workstation has been rebooted and a process identifier file exists for the network access plugin.

Note: The error message is a symptom of this issue. This error message may also occur for reasons that are unrelated to this issue.

F5 Product Development tracked this issue as CR139074 and it was fixed in BIG-IP APM 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

Workaround

You can work around this issue by manually removing the process identifier files, which are available at the following locations:

  • Mac OS X:

    /Library/Internet\ Plug-Ins/F5\ SSL\ VPN\ Plugin.plugin/var/run/svpn.pid

    Note: Older versions of the MAC client may use the /Library/Internet\ Plug-Ins/f5_sslvpn.bundle/var/run/svpn.pid directory.
  • Linux:

    /usr/local/lib/F5Networks/SSLVpn/var/run/svpn/pid
