Description

When viewing Security  ››  Event Logs : Application : Requests in the Configuration Utility, you may see that a virtual server with a security policy is not logging any requests. By default there is no security logging profile applied to a virtual server when an BIG-IP ASM security policy is applied so the log will be missing. In order to log legal or illegal requests to the BIG-IP ASM Event Logs, a local logging profile must be applied to the virtual server.

Environment

  • Virtual server
  • BIG-IP ASM security policy applied

Cause

Virtual server is not logging any BIG-IP ASM Event Logs because no logging profile is applied.

Recommended Actions
Apply a local logging profile

  1. Log into the Configuration Utility
  2. Navigate to Local Traffic  >>  Virtual Servers : Virtual Server List  >>  Virtual Server Name  >>  Security : Policies
  3. Choose Enabled... from the Log Profile dropdown menu
  4. Move the logging profile from the Available list to the Selected list.
  5. Click the Update button.
