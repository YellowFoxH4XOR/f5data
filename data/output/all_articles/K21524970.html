K21524970: When uploading images to BigIQ they are not being verified

Type
Support Solution
Published
2021-09-16
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K21524970
Problem description
After uploading an ISO file to BIG-IQ CM, if you log in to the BIG-IQ GUI and go to System > Software Management > Images, the Verification Status for the image displays as Not Verified.
 
Environment
  • BIG-IQ CM GUI System > Software Management
Cause 
None

Recommended action
  • Verify the integrity of the iso file in /shared/images on the BIG-IQ by following the article: 
        K8337: Verifying the MD5 checksum for the downloaded F5 software file
  • If the MD5 sum is incorrect delete the file and upload a file again and verify the MD5 sum
  • Make sure that the name of the file has not been altered and does not have any extra characters
  • If the above steps do not resolve the issue open a case with F5 support.
