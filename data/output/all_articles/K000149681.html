Description

Peoplesoft application is not functioning as expected with frame errors.

 

Client getting the below error when using BIG-IP APM SSO to access Peoplesoft:

 

"The page did not request an origin-keyed agent cluster, but was put in one anyway because the origin https://<domain.name> had previously been placed in an origin-keyed agent cluster. Update your headers to uniformly request origin-keying for all pages on the origin."

 

Environment

BIG-IP APM

Chrome 115 or higher

Microsoft Edge

 

Cause

Starting in Chrome 115, websites will be unable to set document.domain: Chrome will make document.domain immutable. Microsoft Edge is also planning to disable document.domain (Starting in version 118).

 

Recommended Actions

Create an iRule to insert the required header

when CLIENT_ACCEPTED {
    ACCESS::restrict_irule_events disable
}
when HTTP_RESPONSE {
    HTTP::header replace "Origin-Agent-Cluster" "?0"
}

Additional Information

Chrome disables modifying document.domain

 

https://developer.chrome.com/blog/document-domain-setter-deprecation
