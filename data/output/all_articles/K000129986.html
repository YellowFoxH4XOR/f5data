K000129986: Device not functional after upgrade from version 14.x to 16.x

Type
Support Solution
Published
2022-12-14
Updated
2022-12-14
Source
https://my.f5.com/manage/s/article/K000129986

Description

After upgrading the BIG-IP from version 14.x to version 16.x, the device is not functional and the following error messages can be seen.

err mcpd[5169]01070356:3: HTTP compression feature not licensed.

err mcpd[5169]01070356:3: HTTP header transformation feature not licensed.

err mcpd[5169]01071bf3:3: L4 rule feature not licensed. Logged 87 times.

err mcpd[5169]: 01070356:3: Monitor <path> feature not licensed.

err mcpd[5169]: 01070356:3: Monitor <path> feature not licensed.

err mcpd[5169]: 01070356:3: Monitor <path> feature not licensed.

err tmsh[11119]: 01420006:3: Loading configuration process failed.

Environment

  • BIG-IP VE
  • Upgrade from 14.x to 16.x

Cause

The cause of this behavior could be linked to using a license with SKU V13 which does not support versions higher than 15.x.

 Recommended Actions

If you need to upgrade to a version that is not supported by your current license, please contact your sales representative or account team.
