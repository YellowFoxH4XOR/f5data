Topic

F5OS 1.1.4 is a software release that contains new features and bug fixes. If you are running an F5OS software version earlier than F5OS 1.1.4, you must upgrade to F5OS 1.1.4 or later.

Description

After you upgrade your system to F5OS 1.1.4 or later, you should thoroughly test your system. When you have verified that everything is working on the new version and that you no longer require the old F5OS images, F5 recommends that you perform the following, additional steps:

  • Clean up all old F5OS images on the system, such as 1.1.0, 1.1.1, 1.1.2, and 1.1.3.
  • If you encounter Bug ID 1044257, perform the procedure in the Bug ID article's Workaround section to configure all tenants to the Provisioned state and deploy them again.

Recommendations

To upgrade to F5OS 1.1.4 or later, including the previously mentioned additional steps, perform the following procedure:

Impact of procedure: Upgrading the F5OS system disrupts traffic processing. F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Upgrade the system controller to F5OS 1.1.4 or later.

    For more information, refer to the VELOS Systems: Software Installation and Upgrade manual.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  2. Verify that the system controller upgrade is complete. To do so, perform one of the following steps:
    • Follow the /var/log/openshift.log file by entering the following command:

      tail -f /var/log/openshift.log

    • Log in to the CLI of the management address of the system controller as the chassis administrator, and enter the following command:

      show cluster

      You may observe output similar to the following example:

      cluster-status summary-status "Openshift cluster is healthy, and all controllers and blades are ready."

  3. Upgrade the chassis partitions to F5OS 1.1.4 or later.

    For more information, refer to the VELOS Systems: Software Installation and Upgrade manual.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  4. Verify that the partition upgrade is complete by entering the following command into the system controller management address CLI:

    show partitions

  5. Configure all tenants to return to the Provisioned state.

    To do so, refer to the Shut down a tenant on the VELOS system procedure in K21121803: Shut down and restart a tenant on the VELOS system

  6. Configure all tenants back to the Deployed state.

    To do so, refer to the Start up a tenant on the VELOS system procedure in K21121803: Shut down and restart a tenant on the VELOS system

  7. Thoroughly test your applications and verify that everything is working correctly.
  8. Remove the old partitions and system controller software versions.
    1. Log in to the system controller management address CLI as the chassis administrator.
    2. To display all images, enter the following command:

      show image

    3. Enter the Configuration mode terminal by entering the following command:

      config

    4. To remove a controller ISO image, use the following command syntax:

      image controller remove iso <ISO image version>

      For example:

      image controller remove iso 1.1.3-9712

    5. To remove a partition ISO image, use the following command syntax:

      image partition remove iso <ISO image version>

      For example:

      image partition remove iso 1.1.3-9712

    6. Exit the Configuration mode terminal by entering the following command:

      exit
