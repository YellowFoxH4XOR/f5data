Topic

You should consider using this procedure under the following condition:

  • You want to determine the failover status of one or more BIG-IP systems using the TMOS Shell (tmsh).

Description

You can use the tmsh show /cm failover-status command to display the failover status of the local BIG-IP device. The command also displays detailed information about the failover connections between the local BIG-IP device and the remote device group members, including the number of failover packets exchanged between device group members, the date and time of the last received packet, and the overall status of the connection. You can use information collected from the tmsh show /cm failover-status command when troubleshooting device trust, failover, and configuration synchronization (ConfigSync) issues.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP systems are configured in a sync-failover device group.
  • You must have access to tmsh.

Procedures

To determine the failover status of the BIG-IP system using tmsh, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS shell (tmsh), by entering the following command:

    tmsh

  2. Show the failover status of the BIG-IP system, by entering the following command:

    show /cm failover-status
