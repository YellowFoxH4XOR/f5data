Known Issue

This is the result of a known issue. If you have multiple non-floating self IP addresses configured on an IP subnet and you delete the primary non-floating self IP of that IP subnet, any other objects of the affected IP subnet will be removed. For example, non-floating self IP addresses or routes would be removed. This may result in routing failures.

You can determine the primary non-floating self IP by typing the ip addr show dev <vlan name> command. The primary non-floating self IP can be identified by the inet entry that does not contain the word secondary. In the following example, 172.28.21.32 is the primary non-floating self IP:

6: vlan21: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc noqueue
link/ether 00:01:d7:2f:7f:c6 brd ff:ff:ff:ff:ff:ff
inet 172.28.21.32/24 brd 172.28.21.255 scope global vlan21
inet 172.28.21.35/24 brd 172.28.21.255 scope global secondary vlan21
inet6 fe80::201:d7ff:fe2f:7fc6/64 scope link
valid_lft forever preferred_lft forever

If you attempt to recreate the default route referencing the affected IP subnet, you may receive error messages that appear similar to the following example:

01020066:3: The requested static route (0.0.0.0 0.0.0.0) already exists in partition Common.
01070712:3: Caught configuration exception (0), Netlink reply from kernel has error: -101 (for static route create: 0.0.0.0/0 gw 172.28.21.254 in vlan '') - routing.cpp, line 298.

F5 Product Development tracked this issue as ID 243704 (formerly CR137542), and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

You can avoid this issue by modifying the default behavior of the kernel. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Backup the /etc/sysctl.conf file by typing the following command:

    cp -p /etc/sysctl.conf /etc/sysctl.conf.sol11993
  3. Add the following lines to the /etc/sysctl.conf file:

    net.ipv4.conf.default.promote_secondaries = 1
    net.ipv4.conf.all.promote_secondaries = 1
  4. Save the file and exit the text editor.
  5. Reboot the system by typing the command:

    reboot
