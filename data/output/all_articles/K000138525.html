K000138525: Creating the Application Service fails with error 'Item was not found'

Type
Support Solution
Published
2024-02-08
Updated
2024-02-08
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000138525

Description

When creating an Application Service, get the following error message in the GUI and /var/log/restjavad.log

 

[ERROR]Unable to post classic-app-service : Failed to create new role for the application due to an unexpected exception. java.lang.IllegalArgumentException: Item was not found: Get document for key: cm/adc-core/working-config/ltm/pool/dd69e9fb-dc55-3884-bd61-06c409cd26f0 returned nothing.: Item was not found.

 

Environment

  • BIG-IQ
  • A pair of BIG-IPs

Cause

ID1498449

 

Recommended Actions

Re-discovery and Re-import the Standby BIG-IP into the BIG-IQ.

 

Additional Information

None.
