Description

Attempting to make a connection within Visual Studio Code, using the stated format: username@ip:port - the user is a valid and full admin account that can access via the configuration utility and works properly.  After trying to connect, next error appears:

HTTP Auth FAILURE: 401 - Cannot use 'local' auth provider name when system auth source type is not 'local'

Environment

  • Visual Studio Code
  • Authentication
  • BIG-IP LTM

Cause

Sometimes the authentication server does not recognize the user and the BIG-IP needs to use local user credentials.

Recommended Actions

To workaround this issue, please enable the "fallback to local" option.

  • Go to System >> Users >> Authentication >> enable the "Fallback to Local" checkbox.
