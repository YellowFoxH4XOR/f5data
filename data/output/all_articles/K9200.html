Issue

Previously, there was no option to import or export pre-logon sequences from a FirePass controller.

Starting in FirePass 6.0.3, you have the option to import and export pre-logon sequences on the Users > Endpoint Security > Pre-Logon Sequence page. This option allows you to efficiently configure a large number of pre-logon sequences across multiple FirePass controllers.
 
For instructions about importing or exporting pre-logon sequences, refer to K9199: Importing and exporting pre-logon sequences.
 
F5 Product Development tracked this enhancement as CR46909 and it was included starting in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.
