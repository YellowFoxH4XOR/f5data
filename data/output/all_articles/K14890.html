Known Issue

The management interface remains enabled after you attempt to disable it using the TMOS Shell (tmsh).

This issue occurs when all of the following conditions are met:

  • You disable the management network interface by using a tmsh command similar to the following example:

    tmsh modify /net interface mgmt disabled

  • You attempt to disable the management interface on one of the following BIG-IP platforms:
    • VIPRION B4100 (A100), B4200 (A107), and B4300 (A108) series blades
    • VIPRION B2100 (A109), B2150 (A113), and B2250 (A112) series blades
    • BIG-IP 2000 series (C112)
    • BIG-IP 4000 series (C113)
    • BIG-IP 5000 series (C109)
    • BIG-IP 7000 series (D110)
    • BIG-IP 10000 series (D113)

Impact

You cannot disable the management interface by using tmsh.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Checking the management interface status using tmsh indicates that the interface is disabled. Output may appear similar to the following example:

    [root@bigip:Active:Standalone] config # tmsh show /net interface mgmt

    ----------------------------------------------------------------
    Net::Interface
    Name Status Bits Bits Pkts Pkts Drops Errs Media
    In Out In Out
    ----------------------------------------------------------------
    mgmt disabled 18.2G 3.2G 2.5M 660.6K 0 0 1000T-FD

  • Sending Internet Control Message Protocol (ICMP), SSH, or HTTPS connection requests to the management interface continues to be responsive.

Workaround

To work around this issue, you can complete one of the following actions. The workaround actions are listed in the order of recommendation.

  1. Unplug the management interface
  2. Disable the port on the switch connected to the BIG-IP system management interface
  3. Disable the management interface using the ifconfig command

Unplug the management interface

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

Unplugging the management port requires physical access to the BIG-IP system.

Disable the port on the switch connected to the BIG-IP system management interface

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

To disable the port on the switch connected to the management interface, consult the documentation for your switch.

Disable the management interface using the ifconfig command

Important: Use this option only as a last resort, as disabling the MGMT interface may remove the ability for the Linux host to communicate with several of the BIG-IP subsystems. As a result of this loss of communication, certain BIG-IP features may not function as expected.

Impact of workaround: This workaround may cause unintended consequences.

  1. Log in to the BIG-IP system command prompt.
  2. Use the ifconfig command for your platform to disable the MGMT interface.
    • For BIG-IP 2000 and 4000 series platforms running BIG-IP 11.3.0 or earlier, enter the following command:

      ifconfig eth0 down

    • For all other affected versions and platforms, enter the following command:

      ifconfig mgmt down
