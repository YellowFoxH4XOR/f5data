Known Issue

The Traffic Management Microkernel (TMM) may exit and produce a core file when evaluating BIG-IP APM Secure Web Gateway (SWG) per-request policies.

This issue occurs when the following condition is met:

  • Your BIG-IP APM system is configured for per-request SWG explicit forward proxy.

Impact

The BIG-IP APM system is unable to process traffic while the TMM process is unavailable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to access your BIG-IP APM system, or you experience a traffic disruption.
  • The TMM process generates a core file to the /shared/core directory.
  • Your BIG-IP system generates a SIGSEGV fault and stack trace in the /var/log/tmm file, similar to the following example:

    notice ** SIGSEGV **
    <snip>
    RIP=0x7d02c1
