Known Issue

The BIG-IP APM rewrite profile may fail to rewrite HTML style attributes.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access configuration uses a rewrite profile.
  • The rewrite profile processes HTML content with style attributes that contain CSS styles in one of the following methods:

    • The HTML style attribute is added to a page using document.write.

      For example:

      document.write("<span style=\"color:red;\">(Style rewrite example.)<\/span>");
    • The style attribute assignment is used in an innerHTML statement.

      For example:

      <script type="text/javascript">
      function changeText3(){
      var someHTML = document.getElementById("baseinfo").innerHTML;
      var updatedHTML = "<span style='color:#FF0000'>" + someHTML + "</span>";
      document.getElementById("baseinfo").innerHTML = updatedHTML;
      }
      </script>

Impact

Style attributes are not rewritten.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Content processed by the rewrite profile contains style tags that point to the original content references.
  • Content is missing or displays incorrectly.
  • Web application functionality is impacted.

Workaround

To work around this issue, you can craft a customized iRule to rewrite the affected style attribute.

Impact of workaround: F5 recommends performing the suggested workaround during a scheduled maintenance window.
