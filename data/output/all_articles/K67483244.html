Description

  • Configure geolocation to restrict access to application/s from certain countries.
  • But want to allow access to application for a limited number of IP address from these restricted countries.

Environment

  • ASM
  • Geolocation 

Cause

  • There are no ASM features to allow a specific IP address while blocking access from a country through the use of geolocation.

Recommended Actions

  • None

Additional Information

Possible workaround, however, is to remove listed countries from the geolocation disallow list and use an iRule. The solution first determines origin country for the request, then looks for allowed IP addresses. If the IP address is not allowed/found, the request is dropped.

This uses an iRule datagroup to group together all allowed IP addresses:

  1. Create a datagroup <name of datagroup>   
    • The datagroup contains the list of IP addresses that are allowed to access application. 
  2. Associate iRule with virtual server and do not forget to remove all listed countries from disallowed geolocation under, Security > Application Security > Geolocation Enforcement.
Example when the "country code" does not equal a datagroup entry:
when CLIENT_ACCEPTED {
   if { [whereis [IP::client_addr] country] equals "<country_code>" and not [class match [IP::client_addr] equals <datagroup_name>]  } {
drop
   }
}

Example when the "country code" equals a datagroup entry:
when CLIENT_ACCEPTED {
   if { [whereis [IP::client_addr] country] equals "<country_code>" and [class match [IP::client_addr] equals <datagroup_name>] } { 
drop
   }
}
