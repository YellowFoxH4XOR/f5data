Description

Steps to add delegated external domain MX record on zonerunner

Environment

  • GTM
  • Zonerunner
  • MX record

Cause

None

Recommended Actions

The actions or steps required to address the topic covered in the description,

  1. Login to webui of GTM
  2. Click   DNS ›› Zones : ZoneRunner : Zone List
  3. Select  local Zone(example: example.com)
  4. Select "add resource record"
  5. Choose MX record type
  6. Fill up name: mx.example.com
  7. Fill up all sections 
  8. For  last section: "Mail Server"
    • 31079181.in1.example.com.office365.       <= important to have .  after their delegated domain name
    • Click finish

Note: If the above recommended action is not applied, GTM/ Zonerunner will insist for glue record. 

Additional Information

A Glue Record is the IP Address of a name server at a domain name registry. Glue records are fundamental parts of DNS records, because they help to resolve DNS servers at a core level. If you would like to change the name servers for a site, you'll have to provide the glue records for the new name serves.

Without glue records, a domain name will not work because anyone requiring the DNS information will be stuck in a loop. There is a cyclic dependency of circular referencing. Circular references exist where the name servers for a domain can't be resolved without resolving the domain they're responsible for. Glue Records are additional A records that allow the DNS client to locate name servers.

To create and view Glue record, refer K34150459: Delegating a subdomain to a remote DNS name server from the BIG-IP DNS system
