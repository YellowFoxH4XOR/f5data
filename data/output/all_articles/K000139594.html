Security Advisory Description

An issue was discovered in libxml2 before 2.10.3. Certain invalid XML entity definitions can corrupt a hash table key, potentially leading to subsequent logic errors. In one case, a double-free can be provoked. (CVE-2022-40304).

Impact

This vulnerability allows a remote (or local in the case of Traffix), unauthenticated attacker to cause memory corruption that can lead to access to restricted information, data modification, or a denial-of-service (DoS) on the affected F5 products. There is both control plane and data plane exposure.

Security Advisory Status

F5 Product Development has assigned ID 1567905 (BIG-IP), ID 1567905-4 (BIG-IQ), and SDC-2481 (Traffix) to this vulnerability.

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by installing a version listed in the Fixes introduced in column. If the Fixes introduced in column does not list a version for your branch, then no update candidate currently exists for that branch and F5 recommends that you upgrade to a version with the fix (refer to the tables).

Mitigation

BIG-IP

To mitigate this vulnerability for ASM XML profile, enable the XML data does not comply with format settings violation in the Learning and Blocking Settings > Content Profiles section of your security policy and disable the Allow DTDs setting in your XML profiles, which will disable Document Type Definition (DTD) reference declaration. Additionally, do not permit DTD declaration in monitors or iRules that contain custom XML.

Note: There is no available mitigation for the remaining affected vulnerable component or feature (XML content based routing, wap monitor, external monitor, AAM image optimization).
