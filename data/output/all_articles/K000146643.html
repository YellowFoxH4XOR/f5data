Description

  • This is the process to filter your application's traffic by Mobile or Web

Environment

  • F5® Distributed Cloud
  • Bot Defense WAAP Add-on

Answer/Recommended Actions

To filter web/mobile traffic for Bot Defense Connector for XC WAAP on my Load Balancer: 

  1. Navigate to the Load Balancers tile
  2. Go to Virtual Hosts > HTTP Load Balancers > Security Monitoring under the application you desire and click the Bot Defense tab 
  3. Click on Add filter and select Traffic Channel
  4. Select the value for the traffic you want to have filtered:
    • mobile
    • web
  5. Click Apply
