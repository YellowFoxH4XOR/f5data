Topic

To disable the sshd reverse name lookup, perform one of the following two procedures, depending on which version of BIG-IP you are running:

BIG-IP 9.4.2 and later

  1. Log in to the command line.
  2. Type the following bigpipe command:

     bigpipe sshd include '"UseDNS no"'
  3. To save the configuration, type the following command:

    bigpipe save all
  4. To restart the sshd process, type the following command:

    kill -HUP `pidof sshd`

    Note: Restarting the sshd process may disconnect your SSH session to the BIG-IP system.

BIG-IP 9.0.0 through 9.4.1

  1. Log in to the BIG-IP command line.
  2. Using a text editor, edit the /config/ssh/sshd_config file.
  3. Add the following line anywhere in the file.

    UseDNS no
  4. Save the file and exit the editor.
  5. Find the Parent Process ID for sshd, by typing the following command:

    ps |grep /usr/sbin/sshd

    You will receive output similar to the following example:

    23998 1 0 0 ?? 2 Is 0.0 0.1 540 /usr/sbin/sshd

    The first number in the output line is the Parent Process ID. In this example, the Parent Process ID is 23998.
  6. Restart sshd by typing the following command:

    kill -HUP <Parent Process ID>

    For example:

    kill -HUP 23998

    Note: Restarting sshd may terminate your SSH session. If this occurs, reconnect using SSH.

The sshd process will now operate without performing reverse name lookups.
