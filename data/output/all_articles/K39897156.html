Description

 

Uploading QKview of BIG-IP device collected by BIG-IQ to ihealth failing. 

 

Environment

  • BIG-IQ Centralized Management
  • BIG-IP
  • MyF5 portal
  • ihealth

 

Cause

 

Including the Myf5 created case number in F5 Support Case Number field (EX: 00111111) when uploading the QKview manually or automatically.

 

Recommended actions

 

Add the MyF5 ticket number in the description field.
