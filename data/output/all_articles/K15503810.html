Known Issue

The BIG-IP APM logon page might not properly display input field values.

This issue occurs when one of the following conditions is met:

  • A radio input field value in the Logon page configuration contains a space character.
  • A select input field value in the Logon page configuration contains a space character.

Impact

The Logon page presented to users does not display correct input field values.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Logon page presented to users does not display correct input field values.
