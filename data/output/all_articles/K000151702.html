K000151702: How to Add IP Address Exceptions into ASM policy by REST API Request

Type
Support Solution
Published
2025-06-05
Updated
2025-06-05
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151702

Description

Add IP Address Exception into ASM policy by REST API request

 

Environment

  • BIG-IP ASM system
  • IP Address/Mask whitelist

Cause

None

Recommended Actions

The next commands are designed to give an example on how to perform this action: 

1./ Obtain policy id

curl -ksu admin:admin https://localhost/mgmt/tm/asm/policies?\$select=name,id | jq -M . | egrep '"name":|"id":'
      "name": "test",
      "id": "MrLpFzRHNarvj_zuAOD0fw"
      "name": "Testing",
      "id": "V6FB8O_L6jj4auG8qHrMJA"

2./ Add the Whitelist IP address 

curl -sku admin:admin -X POST https://localhost/mgmt/tm/asm/policies/MrLpFzRHNarvj_zuAOD0fw/whitelist-ips -d '{"ipAddress": "1.1.1.5"}' | jq . 


3./ Save the changes and apply to the policy 

curl -ksu admin:admin -H "Content-Type: application/json" --data '{"policyReference": {"link": "https://localhost/mgmt/tm/asm/policies/MrLpFzRHNarvj_zuAOD0fw" } }' --request POST https://localhost/mgmt/tm/asm/tasks/apply-policy/ | jq .
