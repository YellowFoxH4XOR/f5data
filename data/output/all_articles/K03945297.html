Issue

Error Message

01070341:3 Virtual server <virtual_server_name> references rule <irule_name> which does not exist  

In this error message, note the following:

  • <virtual_server_name> is the name of the virtual server.
  • <irule_name> is the name of the iRule.

For example:

01070341:3: Virtual server /Common/test_vs references rule test_irule which does not exist.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • A configuration load or change contains a virtual server that references an iRule that does not exist.

Impact

The BIG-IP system does not load the configuration.

Recommended Actions

You should verify that the iRule exist on the BIG-IP system.
