Description

If you are managing BIG-IP, you may want to know who, when, and from where logged into BIG-IP. It is very useful when you want to track user activity or investigate a possible security breach.

Environment

  • Bash
  • Login History

Cause

None

Recommended Actions

You may want to displays information about the last login sessions of the system users: last <OPTIONS> <USER>
For example, to list the last two login sessions, type the following command:

# last -n 2
john_smith   pts/80       192.0.2.1        Wed Sep  8 06:49   still logged in
jane_jones   pts/79       198.51.100.1     Wed Sep  8 06:44 - 06:53  (00:09)

In this example, the user john_smith logged in via IP address 192.0.2.1, from 06:49 on 8th, Sep, and are still logged in. Another user jane_jones logged in via IP 198.51.100.1 from 06:44 to 06:53 on 8th, Sep, and stayed in the system for 9 minutes.

Additional Information

  • Each time a user logs into the system, a record for that session is written to the /var/log/wtmp file. The command last reads wtmp file and prints information about the logins and logouts of the users. Records are printed in reverse time order, starting from the most recent ones. The wtmp is a binary file maintains a history of all login and logout activities.

  • The lastb command is the same as the last command, except that, by default, it searches through the /var/log/btmp file, which contains all the bad login attempts. However, regular users don't have read permission on the /var/log/btmp file. Therefore, only the root user can get the report of bad login attempts using the lastb command.
