What Happened?

  • I need to apply rate limiting on my load balancer (LB). What do I need to do?

Environment

  • F5® Distributed Cloud (XC) Service account

Procedure

To apply custom rate limits on a load balancer

  1. From the home page of your tenant go to load balancer option
  2. Click Manage Configuration of the desired load balancer.
  3. Go to the Common Security Controls section
  4. Toggle the Show Advanced Fields button on ( this might be turned on).
  5. Click Rate Limiting
  6. Select API Rate Limiting or Custom Rate Limiting parameters
  7. Select Configure

Additional Information

  • The Number field is the amount of requests to the load balancer.
    • It can be configured for a specific domain as well
  • Burst is the number field value * burst field value
    • Example: 100 requests for a burst of 2 will allow maximum of 200 requests for that load balancer regardless of the domains it has behind itself. After 200 requests will be passed based on algorithm.
