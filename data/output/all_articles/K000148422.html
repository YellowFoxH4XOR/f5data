K000148422: The requested monitor parameter (/Common/mk-test6 2 SNI_SERVER_NAME=) was not found.

Type
Support Solution
Published
2024-11-11
Updated
2024-11-22
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148422

Description

This article is about HTTPS(DNS) monitor created via icontrol having issue modify SNI value via webui.

  • icontrol api was used to create https dns monitor without sniServerName in the declaration. 
  • The following message show up on webui, 01020036:3: The requested monitor parameter (/Common/mk1-withoutsnifield 2 SNI_SERVER_NAME=) was not found , when there is attempt to modify SNI Server field.

Environment

  • icontrol rest
  • DNS

Cause

Due to ID1701169.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  if HTTPS monitor was created without "sniServerName" declaration, delete the HTTPS monitor and re-add via icontrol rest with "sniServerName" or re-add HTTPS monitor via webui.
