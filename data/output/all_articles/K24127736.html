Description

How to clear LCD alarms remotely on iSeries platform devices

Environment

  • BIG-IP iSeries Platform
  • Alarm indicated on front panel display

Cause

None

Recommended Actions

In order to clear this LCD alert remotely, run the following command:
 
tmsh reset-stats sys alert lcd
 
Note: See Related Content for more information regarding clearing alarms on BIG-IP platforms

Additional Information

On other BIG-IP platforms you can clear LCD alarm remotely by using the lcdwarn command to remotely clear the LCD warnings, however, this command does not work on iSeries devices.
