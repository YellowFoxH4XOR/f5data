Description

This article provides detailed instructions on how to download an F5 product ISO file from MyF5 portal for the upgrade or installation purposes.

Environment

  • MyF5 portal
  • BIG-IP
  • BIG-IQ

Cause

None

Recommended Actions

  1. Please sign in or register for a MyF5 account.
  2. Visit the MyF5 portal, click the Resources menu and choose Downloads.
  3. Read the End User Software License Agreement and either accept the license by clicking the I Accept, or cancel the process by clicking Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, with a table detailing the file name, product description, and size of the file.

    Note: After you accept the End User Software License Agreement, the system does not present the agreement again for subsequent downloads that you perform during the same browser session.

  4. The Select a Product Line page displays.

    For software downloads, click the product you want to download from the Product Line column.

    For firmware downloads, click Platform/EUD in the Product Line column (next to Hardware-Specific).

    E.g BIG-IP v14.x / Virtual Edition with Traffic Management Operating System® (TMOS®)

  5. The Select a Product Version ( click on a small box e.g 14.1.3 ) and Container page displays.
  6. In the version list, click the version of the product (or platform, or firmware type) you want to download. 
  7. The version-specific software updates and releases appear.
  8. From the Name column, click the file you want to download. 
  9. From the Filename column of the table, click the name of the file you want to download.
  10. The Download Locations page appears. The locations listed are distributed mirrors of the F5 software repository, and are intended to provide a local download site for faster download for your region.
  11. Click the download location nearest to you.
  12. Select the option to save the file. Refer to your F5 product release notes to determine if you should save the file in a specific location.
