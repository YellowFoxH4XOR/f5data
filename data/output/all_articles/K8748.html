K8748: Users cannot log on after enabling the 'Accept only TLS protocol' option

Topic

If you select the Accept only TLS protocol option on the Device Management: Security: User Access Security page, users may receive an error message that appears similar to the following example when they attempt to access the FirePass logon page:

TLS browser security required. Please see your system admin.

The Accept only TLS protocol option is incompatible with some browsers. If you need to support a wide variety of clients and browsers, you may want to select one of the other two options under SSL Protocol Versions on the Device Management: Security: User Access Security page. The Accept SSLv2, SSLv3, and TLS protocols option offers greater client compatibility, while the Accept only SSLv3 and TLS protocols option offers greater security.

Note: A service restart is required after changing the SSL Protocol Versions setting.
