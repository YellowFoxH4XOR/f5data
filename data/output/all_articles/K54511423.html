Known Issue

The BIG-IP system includes insecure ciphers when a device adds another device to the device trust.

This issue occurs when the following condition is met:

  • You are configuring devices in a device cluster.

TLSv1 is the only protocol that the system supports when establishing device trust. Even though the peer device is configured to use the TLSv1.1 or TLSv1.2 protocol, the BIG-IP system will attempt to use the TLSv1 protocol to establish device trust. If the TLSv1 protocol is disabled on the peer device, the device trust will fail to establish.

Impact

You are unable to configure stronger ciphers for the device trust.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you add a device to the trust, the SSL connection can use insecure ciphers.
  • The system uses the TLSv1 protocol instead of negotiating the TLSv1.2 protocol, which is the highest and safest protocol available.
