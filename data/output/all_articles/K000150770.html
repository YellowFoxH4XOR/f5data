Description

A port on new blade we installed did not come up. Even after trying to reboot the device and re-plugging the ports, issue was not resolved.

On the switch side, the relevant ports were tested by connecting them to another blade, and it was confirmed there was no problems on the switch.

Environment

  • Installing new blade device with interfaces that supports QSFP+ breakout cables option, such as the B4450 VIPRION blade.
  • All software version.
  • Using the 40 GbE interface as four 10 GbE ports with QSFP+ breakout cables.
  • LACP is configured.
  • The interface has "bundle" option configured to "enabled". For example, when running tmsh list sys interface all-properties:
net interface 2/3.0 {
    bundle enabled <===== !!!!!!!!!!

Cause

With bundle set to enabled, the interface is configured as one 40GbE interface instead of four 10GbE links, which is not the intended configuration.

Recommended Actions

Configure the bundle option as disabled. To perform this on the Configuration Utility (GUI):

  1. On the Main tab, click Network > Interfaces.
    This displays the list of available interfaces.
  2. Click an interface name.
    The properties screen for that interface opens.
  3. From the Bundled list, select whether to enable or disable bundling.
  4. Click Update.
