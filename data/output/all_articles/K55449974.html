Description

You are following the steps in the Manual Chapter : Deploying BIG-IQ Virtual Edition guide and get the following error after running the Powershell Script:

New-AzureRmVM : Long running operation failed with status 'Failed'.
Additional Info:'OS Provisioning for VM 'BIGIQ-VM' did not finish in the allotted time. The VM may still finish provisioning successfully. Please check provisioning state later. For details on how to check current provisioning state of Windows VMs, refer to https://aka.ms/WindowsVMLifecycle and Linux VMs, refer to https://aka.ms/LinuxVMLifecycle.'
ErrorCode: OSProvisioningTimedOut
ErrorMessage: OS Provisioning for VM 'BIGIQ-VM' did not finish in the allotted time. The VM may still finish provisioning successfully. Please check provisioning state later. For details on how to check current provisioning state of Windows VMs, refer to https://aka.ms/WindowsVMLifecycle and Linux VMs, refer to https://aka.ms/LinuxVMLifecycle.
ErrorTarget: StartTime: 2020. 04. 06. 11:16:17
EndTime: 2020. 04. 01. 11:56:20 OperationID: 14e5216b-3848-4678-be96-c01144333b99
Status: Failed At line:60 char:1
+ New-AzureRmVM -VM $vm -ResourceGroupName $resourceGroup -Location $lo ...
+ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
+ CategoryInfo : CloseError: (:) [New-AzVM], ComputeCloudException
+ FullyQualifiedErrorId : Microsoft.Azure.Commands.Compute.NewAzureVMCommand
 

Environment

  • Deploying BIG-IQ VE in Azure
  • Using a custom DNS server
  • Run the Powershell script provided in the Manual Chapter

Cause

ID719241: Using custom DNS servers on the Azure VNet with the missing 168.63.129.16 causes Waagent provisioning failure.

Recommended Actions

In order to successfully deploy BIG-IQ VE in an Azure environment using the Powershell Script provided in the Manual Chapter, you will need to perform one of the following actions:
  • Remove the custom DNS Server configuration
    -- OR --
  • Replace the $nic1 variable with the following line in the Powershell Script:

    $nic1 = New-AzureRmNetworkInterface -Name $nic1Name -ResourceGroupName $resourceGroup -Location $location -SubnetId $vnet.Subnets[0].Id -PublicIpAddressId $pip.Id -DnsServer "168.63.129.16"
