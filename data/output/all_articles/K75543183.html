Description

VPN users who have both IPV4 & IPV6 addresses enabled and connecting to an IPV4 full tunnel will still be able to route traffic outside the tunnel through the IPV6 interface.

Environment

  • BIG-IP APM
  • Client machines with IPV4 & IPV6 addressing enabled
  • Connecting to IPV4 Full tunnel VPN
  • Windows Edge Client

Cause

When a client connects to a full tunnel VPN which is only configured with an IPv4 address lease pool, the Edge Client modifies only the IPv4 routes. However, if the client is enabled with both IPV4 and IPV6 addresses, the Edge Client does not update the IPv6 routes, which allows the client to send IPv6 traffic outside the VPN tunnel.

Recommended Actions

To prevent IPv6 traffic from being routed outside of the full tunnel VPN, you also need to configure an IPv6 lease pool. Configuring the network access with both IPv4 and IPv6 lease pools ensures that both the IPv4 and the IPv6 routes on the client are modified to use the tunnel, and the desired routing restrictions are enforced.

Additionally, now that the client will no longer send IPv6 traffic outside of the network access tunnel, if you want to prevent the client from sending IPv6 traffic through the tunnel, you can also create a user-defined Access Control List (ACL) to discard all traffic from the IPv6 lease pool addresses to any destination.
Note: For more information refer to the Network Access Configuring Network Access Resources chapter of the BIG-IP Access Policy Manager guide.
Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have the BIG-IP APM provisioned on your BIG-IP system.
  • Have administrative access to the BIG-IP Configuration utility.
  • Have a Full Tunnel Network Access resource configured with an existing IPv4 lease pool.
  • Have an available IPv6 address range for use.

Procedures

  • Configuring an IPv6 lease pool
  • Applying the IPV6 to the existing network access resource
  • Creating an IPV6 ACL (optional)

Configuring an IPv6 lease pool

To configure a pool of IPv6 IP addresses to be issued, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Access > Connectivity / VPN > Network Access (VPN) > IPv6 Lease Pools.
    Note: For BIG-IP 11.x and 12.x, navigate to:Access Policy > Network Access > Lease Pools > IPv6 Lease Pools.
  3. Click Create.
  4. Type a name for the lease pool.
  5. For Start IP Address and End IP Address, enter the IPv6 range you want.
  6. Click Add.
  7. Click Finished.

Applying the IPV6 to the existing network access resource

To configure your existing IPv4-only network access resource for both IPv4 and IPv6, and to use the IPv6 lease pool you just created, in addition to the existing IPv4 lease pool, perform the following procedure:

Impact of procedure: The impact of the procedure depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment. Configuring an IPv6 lease pool could potentially lead to address conflicts or routing issues depending on how your network handles IPv6. 

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate Access > Connectivity / VPN > Network Access (VPN) > Network Access Lists.
    Note:For BIG-IP 11.x and 12.x, navigate to Access Policy > Network Access > Network Access List.
  3. Click the network access item you want to update.
  4. Click the Network Settings tab.
  5. For General Settings, click Advanced.
  6. For Supported IP Version, click IPV4 & IPV6.
  7. For IPV6 Lease Pool, click the IPv6 lease pool you just created.
  8. If you want to block the local IPv6 traffic, please disable "Allow Local Subnet", and enable "Integrated IP filtering engine".
  9. Click Update.

Creating an IPV6 ACL (optional)

Now that IPv6 traffic is not sent outside of the network access tunnel, you can also configure the BIG-IP APM system with an ACL to discard any IPv6 traffic sent to the tunnel. To do so, perform the following procedure:

Impact of procedure: Any IPv6 traffic matching the defined ACL will be discarded. The exact impact of the procedure depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate Access > Access Control Lists > User-defined ACLs.
    Note:For BIG-IP 11.x and 12.x, navigate to Access Policy > ACLs > User-defined ACLs.
  3. Click Create.
  4. Type a name for the new user-defined ACL.
  5. For ACL Order, click First.
  6. Click Create.
  7. For Access Control Entries, click Add.
  8. For Type, click L4.
  9. For Source IP Address, click Network.
  10. For Address and Mask, enter the network address and subnet mask for the IPv6 subnet you used for the IPv6 lease pool.
  11. For Action, click Discard.
  12. Click Finished.
