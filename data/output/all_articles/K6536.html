Issue

Some BIG-IP system switch appliances are equipped with a separate internal processor, the Switch Card Control Processor (SCCP). The SCCP is responsible for booting the switch and performing other basic hardware management tasks.
Note: For more information about the SCCP, refer to K3454: Overview of the SCCP.

On rare occasions, the SCCP flash memory can become corrupted. This corruption prevents the BIG-IP system from booting. When this behavior occurs, you will receive the following error message on an attached terminal:

System is booting, Please wait ......Hit any key to stop autoboot:  0!!!Running Netboot Recovery Procedure!!!

Workaround

You can recover from this condition by performing one of the SCCP recovery procedures detailed in K4312: SCCP Netboot Recovery Procedures.
