Known Issue

When two non-floating self IP addresses are defined on the same VLAN, deleting one of them may fail with the following erroneous error message:

BIGpipe: self IP address deletion error: 01070393:3: Cannot delete IP 172.16.0.2 because it would leave a floating IP with no non-floating IP on this network.

F5 Networks Product Development is tracking this issue as CR109058 for the BIG-IP LTM 9.3. branch.

Workaround

You can work around this issue by removing the non-floating self IP address. First, delete the floating self IP address, then delete the non-floating self IP address and re-add the floating self IP address.

To change an existing self IP address to another, you can avoid deleting the floating self IP address by instead adding a third non-floating self IP to the VLAN, then deleting the self IP address that is no longer needed
