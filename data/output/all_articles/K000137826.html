Description

You want to configure an advance external HTTP monitor

Environment

BIG-IP

Cause

You want to configure an advance external HTTP monitor that provides more flexibility in the monitor's query

Recommended Actions

Using a text editor create a script file (shell / Perl, Python, etc.) that will perform the HTTP query e.g:

#!/bin/sh

curl -s -D - -o /dev/null http://${node_ip}/${uri} | grep ${RECV} 2>&1 > /dev/null

 

Note:

The script’s return value is 0 when the command’s response (200) is true and 1 if it is false. E.g:

# curl -s -D - -o /dev/null http://${node_ip}/${bad url}/ | grep ${RECV} 2>&1 > /dev/null

# echo $?

1

# curl -s -D - -o /dev/null http://${node_ip}/${uri} | grep ${RECV} 2>&1 > /dev/null

# echo $?

0

 

Upload the script to the ltm:

System ›› File Management : External Monitor Program File List

Click on Import and import the script file to the BIG-IP

Note:

In case that you need to modify/update the script, you should do it from the same location on the bigip

 

Associate the script with the monitor:

Created External monitor (type External)

In the External Program choose the script that you uploaded

Create Variables matching the variables that are in the script (node_ip, uri, RECV) and add values:

The rest of the settings should be configured the same way that you are configuring a monitor

Associate the monitor with a pool
