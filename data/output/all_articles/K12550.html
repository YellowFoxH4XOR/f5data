Known Issue

This is the result of a known issue. In the matching rules of the BEA Aqualogic (Plumtree without Collaboration) pre-defined acceleration policy for the BIG-IP WebAccelerator system, the Content Type for the Application Generated >> XML node is incorrectly configured as pages.json. In addition, the Content Type for the Application Generated >> JSON node is incorrectly configured as pages.xml. As a result, when this pre-defined acceleration policy is associated with an application, a mismatch of XML and JavaScript Object Notation (JSON) objects and their respective configured acceleration behavior occurs.

F5 Product Development tracked this issue as ID 348406, and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator and BIG-IP Edge Gateway release notes.

Workaround

You can work around this issue by performing the following procedure:

  1. Log in to the Configuration utility using a privileged account, such as admin.
  2. Navigate to WebAccelerator > Policies.
  3. To make a copy of the BEA Aqualogic (Plumtree without Collaboration) policy, click Copy.

    You can name the copy as BEA Aqualogic (Plumtree without Collaboration) SOL12550 or the name of your choice.
  4. Click Copy.
  5. Click the name of the Acceleration policy you created in step 4.
  6. To expand the Site nodes, click the plus sign (+).
  7. To expand the Application Generated nodes, click the plus sign (+).
  8. Click the XML node.
  9. Click Content Type.
  10. Delete the contents of the Value matches field.
  11. Type pages.xml in the Value matches field.
  12. Click Save.
  13. Click the JSON node.
  14. Click Content Type.
  15. Delete the contents of the Value matches field.
  16. Type pages.json in the Value matches field.
  17. Click Save.
  18. Click Publish.
  19. Click Publish Now.
  20. Click Exit Policy Editor.
  21. Click Applications.
  22. Click the name of the Application.
  23. Click the Policies drop-down menu.
  24. Select the policy you created in step 5.
  25. Click Save.
