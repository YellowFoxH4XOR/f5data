Description
 You are unable to establish connection on load balancer and you can see the following logs in /var/log/ltm

Mar 8 19:13:33  warning tmm[18925]: 01200017:4: Warning, pool member IP 10.10.10.10 port 8443 for pool /Common/General_URL has reached its connection limit.
Mar 8 19:14:02  warning tmm[18925]: 01200017:4: Warning, pool member IP 10.10.10.10 port 8443 for pool /Common/General_URL has reached its connection limit.
Mar 8 19:14:24  warning tmm[18925]: 01200017:4: Warning, pool member IP 10.10.10.10 port 8443 for pool /Common/General_URL has reached its connection limit.

Environment

  • BIGIP
  • Pool member 
  • New Connection 

Cause

You have limiting the number of connections to a Virtual Server

Recommended Actions

To mitigate this issue, you can increase the connection limit for the pool member to an appropriate value for your environment. To do so, perform the following procedure:

Impact of procedure: The following procedure increases the the allowed number of connections to the BIG-IP system, which may impact resources. You should perform testing in order to determine an appropriate connection limit value for your environment.
  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Pools.
  3. Select the pool for which you want to define the connection limit.
  4. Select the Members tab.
  5. Select the pool member for which you want to define the connection limit.
  6. Under Configuration, for Connection Limit, increase the limit or set to 0 for unlimited .
  7. Select Update
  8. Repeat the steps for other pool members if required.
