Description

To create the cipher string with TLS/SSL version. Sometime need to disable the specific cipher suite for the respective TLS version.

The BIG-IP system uses the cipher list format defined by OpenSSL. This format allows the selection of specific ciphers or groups of ciphers and usage of many strings defined by OpenSSL.

The cipher list consists of one or more cipher strings separated by colons. The actual cipher string can take several different forms, including:

  • A single cipher suite, such as ECDH-RSA-AES256-SHA.
  • A certain algorithm, such as AES-GCM.
  • A supported TLS version, such as TLSv1_2.
  • Certain special strings from OpenSSL, such as HIGH.
  • A string using + to combine the above strings, such as AES+SHA, which selects cipher suites that use both.

Cipher strings can be preceded by certain characters to change their meaning:

  • ! means disable the selected cipher suites.
  • - means disable the selected cipher suites unless selected again later in the string.
  • + means move the selected cipher suites to the end of the list, but only if they have already been enabled.

 Recommended Actions

  1. To create the cipher suite for the specific version, use below syntax.

ECDH-RSA-AES256-SHA+TLS version


Example

Need to disable the DHE for TLSv1.1

!DHE-RSA-AES128-SHA+TLSv1_1'


Verification Steps

In bash mode run the following command to check the Cipher supported with cipher (!DHE-RSA-AES128-SHA+TLSv1_1') string a shown below


tmm --clientciphers 'DHE-RSA-AES128-SHA+TLSv1_2'

Additional Information

Cipher Breakdown 


Let’s consider this cipher suite:

ECDHE-RSA-AES256-GCM-SHA384

Key Exchange Algorithm: ECDHE (Elliptic Curve Diffie-Hellman Ephemeral)

Authentication Algorithm: RSA

Cipher: AES256 (aka AES with a 256-bit key)

Cipher Mode: GCM (Galois/Counter Mode)

MAC: SHA384 (aka SHA-2 (Secure Hash Algorithm 2) with 384-bit hash)


Protocol Notations

TLSv1_3 – cipher suites available under TLSv1.3

TLSv1_2 – cipher suites available under TLSv1.2

TLSv1_1 – cipher suites available under TLSv1.1

TLSv1 – cipher suites available under TLSv1.0

SSLv3 – cipher suites available under SSLv3

Note the ‘Protocol’ keywords in the cipher configuration control the ciphers associated with

that protocol, and not the protocol itself!



Note that you can combine keywords using ‘+’. And multiple entries in the cipher's configuration line are separated with

tmm --clientciphers 'ECDHE+AES-GCM:ECDHE+AES‘


We can also exclude suites or keywords. There are two ways to do that: ‘!’ is a hard exclusion. Anything excluded this way cannot be implicitly or explicitly reenabled. It is disabled, period. ‘-’ is a soft exclusion. Anything excluded this way can be explicitly re-enabled later in the configuration string.
