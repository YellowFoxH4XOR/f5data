Topic

To allow non-SSL web services on the FirePass Controller, you must first confirm that traffic is not redirected to HTTPS. To do so, perform the following procedure:

Important: Before performing the following procedure, you must consult the encryption requirement policies of your organization. By performing the following procedure, you are allowing information to be sent in clear text, which may be a violation of your organization's security policies.

  1. Log in to the FirePass Controller.
  2. Navigate to the Device Management: Configuration: Network Configuration: Web Services page.
  3. If the web service you want to allow HTTP access to already exists, click Configure next to the web service and go to step 9.

    If you want to all HTTP access for a new web service, complete steps 4 through 8. 
  4. Select the IP address from the drop-down menu.
  5. In the Port field, enter 80.
  6. In the Name field, enter the fully qualified domain name (FQDN).
  7. Ensure that the SSL check box is clear.
  8. Click the Add New button.
  9. Select the Do not redirect to HTTPS check box.
  10. Select the appropriate agents that you want to access this resource.

    Note: For more information, click the read help link on the configuration page.
  11. Click the Update button.
  12. Navigating to the Device Management: Security: User Access Security page.
  13. To allow insecure access to the device, select Allow insecure Access.
  14. Navigate to the Device Management: Configuration: Network Configuration: Finalize tab.
  15. Review the settings and click Finalize Changes.
  16. Click Apply Changes.

For the services to take effect, you must restart services.
