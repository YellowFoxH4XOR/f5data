Description

I am unable to select the ''DNS Security Profile Name", within the DNS profile

  • Attempting to modify an existing or new DNS Profile (DNS > Delivery > Profiles > DNS) or (Local Traffic > Profiles > Services > DNS). Within the "DNS Traffic" area, there should be a field for "DNS Security Profile Name". 

Environment

BIG-IP AFM and BIG-IP DDoS Hybrid Defender are both licensed on the system.

Cause

The DDoS add-on license was not intended to be used with an AFM full license. When licensed with both, the DNS Security Profile Name does not appear.

Recommended Actions

If your BIG-IP system is licensed with the full AFM license, you should remove the DDoS add-on license. This will remove the restriction on the DNS Security profile in the GUI. The DDoS Hybrid Defender functionality will not be lost.
