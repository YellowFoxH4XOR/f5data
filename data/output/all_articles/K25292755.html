Description

For unknown reasons the guided configuration section of the Security section in the GUI does not appear anymore.
An error, error 404 Not found is displayed when attempt to get it 

Environment

  • BIG-IP v15 with Guided Configuration 7.0
  • ASM
  • At least one configuration deployed with the guided configuration 

Cause

Some of the templates are deleted or corrupted

Recommended Actions

First, we need to identify the missed or corrupted template, in order to do this, get a har file while accessing the Guided configuration in the GUI, the har file will indicate which is the template that is missing as follows:

 















In this example, the template that is missing is the f5-iappsxl-access-framework  as we can see in the trace the GET request for this object results in a 404 error message Not found.
We need to review the status of the iAppLX as follows:

 

there are two options:

  • The package exists but for some reason is corrupted, and can not be used when required
  • The package does not exist, as indicated in the second part of the previous image

if the package exists but can not be used, you need to select it and click on Uninstall. From there we will proceed in the same way as the package does not exist in the device. 

In order to re-install the package we need the RPM file that contains this application, the easiest way to get this file is from the Guided Configuration installation file:

  1. In the F5 Downloads webpage (https://downloads.f5.com/), click on the  Find a Download button
  2. Select Guided Configuration
  3. Select the appropriate version (for example 7.0)
  4. Click the Guided_Configuration file
  5. After accepting the End User License Agreement
  6. you will be able to download the f5-iappslx-agc-usecase-pack-7.0-0.0.1481.tar.gz package
  7. Once you have the file on your local computer, open the .tar.gz file

 







 

  1. open the .tar file inside the .tar.gz file

 



















 

  1. in the .tar file you can see the rpm file for the iApp that is needed. Extract it from the tar file and copied to a known location in the local computer. 
  2.  in the   iApps -->  Package Management LX     import the package, selecting the file you have extracted from the  tar.gz file. 

 


































 

  1. The Security Guided Configuration page should be available again, click on one of the configurations.
  2. If the information is available, review you are able to change all parameters, if everything is fine, the procedure ends here.
  3. if there was a problem visualizing or updating the configuration, go back to the --> Security -->> Guided Configuration and in the list of the configuration select the "undeploy" button, when you try to undeploy the configuration, an error should appear, indicating which other module is also corrupted for example: Config processor is not available: java.util.concurrent.TimeoutException: Unavailable: https://localhost:8100/mgmt:shared/iapp/processors/waf-app-comprehensive-protection this error indicates the package f5-iappslx-waf-app-comp-protection needs to be reinstalled, so we need to repeat steps 7- 10 of this procedure to extract, upload, and install the indicated package. The "f5-iappslx-access-framework" package is intended to set up the frameWork of Guided Configuration, other packages are required for each template/application to work. 

 


















Note: No impact on the application of the procedure is expected, and no restart is needed.
