Important: This Solution applies to FirePass version 4.0 through 6.0.1. Starting in FirePass version 6.0.2, the information in this Solution is documented in the FirePass Release Notes. If you are running FirePass version 6.0.2 or later, refer to the Certified applications for Portal Access Web Applications feature section of the FirePass Release Notes to determine which applications have been certified for your version of FirePass software.

FirePass Portal Access (known previously as MyIntranet and Reverse Proxy) provides users with access to web applications without requiring client configuration changes or software downloads. Use Portal Access when you want to allow users to access specific web application, rather than providing full network access.

F5 Networks has tested the following web applications and has determined that they work when accessed through Portal Access without requiring client configuration:

  • Microsoft Outlook Web Access
  • Microsoft SharePoint
  • IBM Lotus Domino Web Access (also known as Lotus iNotes)
  • Microsoft file servers that use the CIFS filesystem

Important: Because Portal Access provides access to web applications by proxying the content through FirePass, FirePass must change all included links to refer to the FirePass, rather than the server. In some cases, FirePass cannot change all of the links and the web application does not work correctly. For more information about issues that you may encounter with Portal Access, refer to K3084: Common problems introduced by FirePass reverse proxy features.

F5 Networks tested only those web applications specified for compatibility through Portal Access. Other web applications will work with Portal Access without requiring additional configuration, but some, particularly those that make extensive use of Javascript, Java applets, ActiveX controls, and Flash Components, may require that you use content processing scripts or other workarounds.

If a specific web application requires additional configuration to work through Portal Access, you can generally use Application Tunnels or Network Access. These access methods provide a direct connection to the internal network and do not require proxying and modification of web application content.

If you cannot use Application Tunnels or Network Access to solve access issues, you can try the Minimal Content Rewriting Bypass feature. For more information about this feature, refer to K4746: Overview of the Minimal Content Rewriting Bypass.

If none of the suggested solutions work with your web application, contact F5 Networks Technical Support and provide the following information:

  • Web application name
  • Web application version
  • Browser type used to access the web application
  • Browser version used access the web application
  • Page or component that fails
  • Steps to reproduce the problem
