Description

You are unable to attach dos profile with BADOS feature enabled on more than two Virtual Servers.

An error similar to the following is logged to /var/log/ltm:

Configuration error: DOS profile (/Common/<dos_profile>) with behavioral detection cannot be attached to (/Common/<virtual_server_3>) because the feature is limited to use on 2 Virtual Servers. Please disable behavioral detection on one of the following virtual servers (/Common/virtual_server_1, /Common/virtual_server_2, /Common/virtual_server_3) or obtain special license to change the limit.


Environment

  • BIG-IP ASM
  • BADOS

Cause

The is expected behavior.
The following statement can be found in the manual for the installed version.
"You can use a DoS profile that has Behavioral DoS enabled to protect one or, at most, two virtual servers."
Note: For more information refer to Manual Chapter : Preventing DoS Attacks on Applications for the BIG-IP software version installed.

Recommended Actions

Increase the value for the system dB variable adm.max.vs.

  1. To check the current setting of db key adm.max.vs, run the following TMSH command from the command line of the BIG-IP ASM device:

    tmsh list sys db adm.max.vs

    output will show the default value '20'.
     
  2. Increase the value to 30 using the command:

    tmsh modify sys db adm.max.vs value 30
     
  3. Save the configuration using the command:

    tmsh save sys config


Additional Information

Behavioral DoS is unlimited for Advanced WAF License.
