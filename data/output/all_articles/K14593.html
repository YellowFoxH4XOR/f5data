Topic

BIG-IQ localhost discovery is required before you can perform remote device discovery.

Description

BIG-IQ localhost discovery is the process where a BIG-IQ system selects the encryption keys that the system uses when it communicates with other BIG-IQ systems. This process happens automatically whenever a system requests that a BIG-IQ system discover another device.

If the localhost discovery process fails, you won't be able to discover remote devices that you intend to manage with the BIG-IQ system. For example, you won't be unable to declare management authority or set a peer device.

Recommendations

If you are unable to discover a remote device, perform the following procedures:

Verify that the BIG-IQ Localhost has been discovered

  1. Log in to the BIG-IQ command line.
  2. Enter the following command to get a list of all the BIG-IQ devices:

    curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

  3. In the items section, verify that an entry exists where the address field contains the BIG-IQ system's self IP address.
    • If the BIG-IQ system's self IP address is not in the list, the localhost was not discovered. To discover the BIG-IQ self IP, refer to the Adding the BIG-IQ system procedure.
  4. In the items section, verify that the state entry is Active. 
    • If the state is Post_Fail, discovery has failed. To recover from a Post_Fail state, refer to the Recovering the BIG-IQ system from a failed discovery procedure.
    • If the state is VALIDATION_FAILED, the device failed to join BIG-IQ shared group because of a validation issue.To recover from a VALIDATION_FAILED state, refer to the Recovering the BIG-IQ system from a failed discovery procedure.
    • If the BIG-IQ system is in the list and the state is Pending, wait a few minutes and verify that the state does not change, by repeating Step 2. If the state has not changed to Active, refer to the Recovering the BIG-IQ system from a failed discovery procedure.

Adding the BIG-IQ system

If the BIG-IQ system's self IP address is not in the list noted in the Verify that the BIG-IQ is discovered procedure, perform the following procedure:

  1. Log in to the BIG-IQ command line.
  2. Add the local BIG-IQ system by entering the following command:

    curl -X POST -d '{"address":"127.0.0.1", "userName":"admin", "password":"", "httpsPort":"443"}' http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | json-format

  3. Verify that the BIG-IQ system's self IP address is in the list, in an Active state, by entering the following command to get a list of all the BIG-IQ devices:

    curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

  4. After the BIG-IQ system's self IP address appears in the list, restart the restjavad service using the following command:

    bigstart restart restjavad

Recovering the BIG-IQ system from a failed discovery

If the BIG-IQ system is in the list noted in the Verify that the BIG-IQ is discovered procedure, and the state is Pending or Post_Fail, perform the following procedure:

  1. Log in to the BIG-IQ command line.
  2. Copy the value that is in the uuid field from the Verify that the BIG-IQ is discovered procedure.
  3. Remove the Pending or Post_Fail discovery by entering the following command syntax:

    curl -X DELETE http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices/[UUID] 

    For example:

    curl -X DELETE http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices/8918277c-ca79-49d8-859e-bf7b5fd7b53b

  4. Add the BIG-IQ self-IP addresses by entering the following command:

    curl -X POST -d '{"address":"127.0.0.1", "userName":"admin", "password":"", "httpsPort":"443"}' http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | json-format

  5. Verify that the BIG-IQ system's self IP address is in the list, in an Active state, by entering the following command to get a list of all the BIG-IQ devices:

    curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

  6. After the BIG-IQ system's self IP address appears in the list, restart the restjavad service using the following command:

    bigstart restart restjavad
