Description

BIG-IP LTM with two virtual servers sharing the same IP address and port marked down by BIG-IP DNS monitoring the LTM virtual servers.

 

Environment

BIG-IP LTM with two virtual servers sharing the same IP address and port.

BIG-IP DNS/GTM monitoring the LTM virtual servers


 

Cause

GTMD may fail to register each individual LTM virtual server name resulting in both virtual servers having the same LTM name.


 

Answer/Recommended Actions

Detach both virtual servers from their associated GTM pools.

Delete the affected virtual servers from the LTM configuration.

Allow GTM to rediscover the virtual servers.

Explicitly set the GTM virtual server "ltm-name" attribute to match the corresponding LTM virtual server name for each instance.

Force a reload of the mcpd process using:

bigstart stop && rm -f /var/db/mcpd* && bigstart start

Re-attach the virtual servers to their respective GTM pools.


See "Additional Information" for sample configuration and steps to resolve the issue.


 

Additional Information

Steps to resolve the issue.

---------------------------


# tmsh list gtm server


gtm server bigip-ltm1 {

addresses {

198.51.188.38 {

device-name /Common/bigip-ltm1

}

}

datacenter Test

devices {

bigip-ltm1 {

addresses {

198.51.188.38 { }

}

}

}

monitor bigip

product bigip

virtual-server-discovery enabled

virtual-servers {

https-dup_vs {

destination 198.51.188.43:https

}

https_vs {

destination 198.51.188.43:https

}

}

}


# tmsh list gtm pool


gtm pool a https_pool {

members {

bigip-ltm1:/Common/https_vs {

member-order 0

}

}

monitor https

}

gtm pool a test-https_pool {

members {

bigip-ltm1:/Common/https-dup_vs {

member-order 0

}

}

}


# tmsh modify gtm pool a https_pool members delete { bigip-ltm1:/Common/https_vs }

# tmsh modify gtm pool a test-https_pool members delete { bigip-ltm1:/Common/https-dup_vs }


# tmsh modify gtm server bigip-ltm1 virtual-servers delete { /Common/https_vs /Common/https-dup_vs }


# tmsh list gtm server virtual-servers


gtm server bigip-ltm1 {

virtual-servers {

https-dup_vs {

app-service none

description none

destination 198.51.188.43:https

enabled

explicit-link-name none

limit-max-bps 0

limit-max-bps-status disabled

limit-max-connections 0

limit-max-connections-status disabled

limit-max-pps 0

limit-max-pps-status disabled

ltm-name none <--- Set to match vip name https-dup_vs

monitor none

translation-address none

translation-port any

depends-on none

}

https_vs {

app-service none

description none

destination 198.51.188.43:https

enabled

explicit-link-name none

limit-max-bps 0

limit-max-bps-status disabled

limit-max-connections 0

limit-max-connections-status disabled

limit-max-pps 0

limit-max-pps-status disabled

ltm-name none <--- Set to match vip name https_vs

monitor none

translation-address none

translation-port any

depends-on none

}

}

}


# tmsh modify gtm server bigip-ltm1 virtual-servers modify { /Common/https_vs { ltm-name https_vs } }

# tmsh modify gtm server bigip-ltm1 virtual-servers modify { /Common/https-dup_vs { ltm-name https-dup_vs } }

# tmsh save sys config


# bigstart stop && rm -f /var/db/mcpd* && bigstart start


# tmsh modify gtm pool a https_pool members add { bigip-ltm1:/Common/https_vs }

# tmsh modify gtm pool a test-https_pool members add { bigip-ltm1:/Common/https-dup_vs }

# tmsh save sys config
