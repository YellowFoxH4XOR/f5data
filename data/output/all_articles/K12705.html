Known Issue

This is the result of a known issue. If you download executable files into a protected workspace on computers running Windows Vista or Windows 7, the files may fail to run and the following error message displays:

Windows cannot find <filename>. Make sure you typed the name correctly, and then try again.

F5 Product Development tracked this issue as ID 351044 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

For more information on the FirePass Protected Workspace feature, refer to the FirePass Controller Administrator Guide.
