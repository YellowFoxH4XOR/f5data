Known Issue

Displayed route domain configuration may be inconsistent.

This issue occurs when all of the following conditions are met:

  • You create a route domain and assign the non-default route domain as the default route domain for an administrative partition.
  • You create pool members or virtual servers in the administrative partition that reside in a route domain other than the route domain of the administrative partition.
  • You create pool members or virtual servers in the administrative partition that reside in a route domain other than the administrative partition default route domain.
  • You view the pool members or virtual servers using the Configuration utility.
  • You view the pool members or virtual servers using the Traffic Management Shell (tmsh).

Impact

You can safely ignore this issue; route domain-specific configuration information is inconsistently displayed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the virtual server destination configuration using the Configuration utility, the system does not display route domain detail for virtual servers that reside in the administrative partition.
  • When you view the virtual server destination configuration using the tmsh utility, the system displays route domain detail for virtual servers that reside in the administrative partition.
  • When you view pool member configurations using the Configuration utility or the tmsh utility, the system does not display pool members that reside in the administrative partition with the corresponding route domain detail.
