Known Issue

Attempts to install the BIG-IP 10.2.4 HF9 or HF10 cumulative hotfixes may fail.

This issue occurs when the following condition is met:

  • You attempt to install one of the following hotfixes on a system that uses the partition disk formatting scheme:

    • BIG-IP 10.2.4 HF9
    • BIG-IP 10.2.4 HF10

Impact

Attempts to install the BIG-IP 10.2.4 HF9 or HF10 cumulative hotfixes, on systems that use the partition disk formatting scheme, will fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H523108 on the Diagnostics > Identified > High screen.
  • Failed attempts to install the BIG-IP 10.2.4 HF9 or HF10 cumulative hotfixes generate error messages similar to the following example:

Resolution

Status

F5 Product Development has assigned ID 485936 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can install cumulative hotfix version BIG-IP 10.2.4 HF11 or later.

Impact of workaround: Performing the recommended workaround should not have a negative impact on your system.
