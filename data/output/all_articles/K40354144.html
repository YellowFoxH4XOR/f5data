K40354144: Software Images from vCMP Host are not listed inside vCMP Guest Image List

Description

When you go to System > Software Management > Image List in the vCMP Guest, the software images from the vCMP Host are not listed.

Environment

  • BIG-IP 14.1.2.x
  • vCMP

Cause

The issue occurs when the redirect-http-to-https setting is enabled on the vCMP Guest. This is related to BUG ID540530

Recommended Actions

You can perform this by using one of the methods below:

On vCMP Guest GUI:

  1. Go to System > Preferences
  2. On System Settings select Advanced
  3. Uncheck Redirect HTTP to HTTPS
  4. Click Update
On vCMP Guest CLI:
  1. Disable the http to https redirect by issuing the command below:
    tmsh modify sys httpd redirect-http-to-https disabled
  2. Save the config
    tmsh save sys config
