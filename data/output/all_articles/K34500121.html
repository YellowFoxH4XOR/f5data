Known Issue

The BIG-IP ASM system may incorrectly handle not trigger server-side violations.

This issue occurs when one of the following conditions is met:

  • Web scraping detection is enabled on the security profile.
  • Cross-site request forgery (CSRF) protection is enabled on the security profile.

Impact

The BIG-IP ASM system fails to detect server-side violations and may generate false positives due to missing cookies. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system fails to trigger server-side violations, such as an illegal HTTP status in responses or data guarding.
  • The BIG-IP ASM system fails to detect server-side violations and may generate false positives due to missing cookies.
