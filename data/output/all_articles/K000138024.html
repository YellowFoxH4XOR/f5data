Environment

Kubernetes
NGINX Ingress Controller Image
 

Cause

Invalid JWT file
 

Recommended Actions

Download the JWT file from MyF5 Portal and try again; if the problem persists please open a support case.
 

Additional Information

JWT file expiration date can be checked directly on the MyF5 portal.
The JWT file can also be decoded to check its validity in a site similar to https://token.dev/ or https://jwt.io/.
