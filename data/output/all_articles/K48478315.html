Description

  • After upgrading from pre-v14.1.0 versions to 15.0.x cron jobs no longer run as expected.
  • The system cron daemon not running can result in some system operations not to run.

            For example:
    • Log file rotation
    • Custom cron jobs

Environment

  • Upgrade to version 15.0.x
  • Cron jobs are not being executed
  • Log files are not being rotated as expected and may cause disk space issue

Cause

This is the result of the following known issue Bug ID 813517: The cron daemon not running after upgrade from pre-v14.1.0 versions to 15.0.x


Recommended Actions

Enable and start crond by running the following commands:

systemctl enable crond
systemctl start crond

In order to check the status of the service run the following command:

systemctl | grep -i crond
