Known Issue

Configuring a port with a copper small form-factor pluggable (SFP) interface to 100baseTX-Full does not pass traffic, despite showing the link as Up.

This issue occurs when all of the following conditions are met:

  • You have a copper SFP interface fixed to 100baseTX-Full.
  • The corresponding interface on the connected switch is fixed to 100baseTX-Full.

Impact

The affected interface does not pass traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H438050 on the Diagnostics > Identified > Medium screen.
  • The interface status shows as Up.
  • The interface does not pass traffic.
  • You observe an error message similar to the following example in the /var/log/ltm log file:

    err mcpd[5181]: 01070318:3: The requested media for interface 2.1 is invalid.

Workaround

To work around this issue, you can set the interface media type to auto. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility as the admin user.
  2. Click Network.
  3. Click Interfaces.
  4. Click Interface List.
  5. Click the affected interface.
  6. Under Fixed Requested Media, set the speed to auto.
  7. To save your changes, click Update.
