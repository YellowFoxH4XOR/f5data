Description
When attempting to apply the Cloud Failover declaration, gather declaration information, or test failover the end result is a 400 error.

Environment

  • BIG-IP Public Cloud
  • Cloud Failover Extension

Cause
BIG-IP unit cannot reach public cloud storage account.

Recommended Actions

  1. Determine why the BIG-IP unit cannot successfully connect with the public cloud storage account. For example:
    1. Firewall rule?
    2. Routing issue?
  2. If using Azure Cloud, check restnoded logs for the following: "Listing Storage Accounts" followed by "Function error, retrying: connect ECONNREFUSED <IP address>:443".
    1. Verify the IP address provided as being an Azure storage address and restore SSL connectivity to this address.
  3. If using Amazon Cloud, check restnoded logs for "Function error, retrying". 
    1. Check the region and url for AWS storage account. For example, "https://s3.us-east-1.amazonaws.com" for the US East 1 region.
    2. Verify connectivity to that url via SSH from BIG-IP and take corrective steps as needed.

Additional Information
None.
