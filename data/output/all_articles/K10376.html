K10376: The Configuration utility allows configuration of unprovisioned modules

Topic

After you have successfully licensed a BIG-IP version 10.0.x system with either the GTM or Link Controller module, the menu for the newly licensed module becomes immediately visible in the web-based Configuration utility, and it is possible to configure objects within the module. However, any GTM or Link Controller object configured before the module is provisioned will be marked Unavailable (red), and the configuration for that object is not saved in the wideip.conf file. As a result, none of the objects configured in the unprovisioned module function as expected, and these objects are removed from the running configuration if the services are restarted or the unit is rebooted.

You can avoid this situation by provisioning resources for the add-on modules before you configure them. If you have already begun configuring a module prior to provisioning it, simply provision the module before restarting services or rebooting the system. Upon provisioning the module, the configured objects are written to the wideip.conf configuration file, and their actual status is displayed.

F5 Product Development tracked an enhancement request as CR123277 to make the menus and related configuration for add-on modules visible only after the module has been provisioned, rather than when it is first licensed, and this functionality was added in BIG-IP 10.1.0.
