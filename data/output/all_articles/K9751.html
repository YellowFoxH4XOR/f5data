Known Issue

This is the result of a known issue. If object types are not defined for a security policy, the BIG-IP ASM bd process leaks memory as it processes traffic.

This behavior only occurs when an object type is not defined for the security policy. To prevent a memory leak, ensure that the security policy contains at least one defined object type; either a specific object type or a wildcard object type.

F5 Product Development tracked this issue as CR114624 and it was fixed in BIG-IP ASM 9.4.7. For information about upgrading, refer to the BIG-IP ASM release notes.
