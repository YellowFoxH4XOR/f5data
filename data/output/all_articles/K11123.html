Topic

You should consider using this procedure under the following condition:

  • You want to display user session variables without incurring the overhead of logging.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility.

Description

You can log BIG-IP APM session variables to the /var/log/apm file by setting the Access Policy log to the Informational log level. However, this configuration can add significant overhead to a production system; the setting should be enabled only temporarily for troubleshooting purposes. Another alternative is to configure the access policy to display session variables using a message box event. This configuration is especially useful when you use regular expressions within an action to manipulate session variables. In these instances, you can place a message box before and after the action to ensure that the regular expressions produce the desired effect.

Procedure

Configuring a message box action to display the sessionid variable

The sessionid is one of the session variables that can be displayed using a message box event.  To do so, perform the following procedure:

Note: This procedure assumes that you have a working access policy. For information about configuring an access policy, refer to the Configuration Guide for BIG-IP Access Policy Manager manual. To locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles:

    BIG-IP 13.x and later

    Access > Profiles / Policies

    BIG-IP 12.x and earlier

    Access Policy > Access Profiles

  3. Next to the access policy you want to configure, click Edit.
  4. At the point in the access policy where you want to insert the message box, click the plus sign (+) to add an action.
  5. Select the Message Box action.
  6. Click Add Item.
  7. In the Name box, type a name for the action.

    For example:

    Display session ID

  8. In the Language menu, select a language or leave it set to the default language.
  9. In the Message box, enter a message to display the session variables.

    For example:

    Your session ID is %{session.user.sessionid}.
    Your user name is %{session.logon.last.username}.

  10. In the Link box, type the message box link text. Users select this link to proceed to the next step of the logon sequence.

    For example:

    Click here to continue

  11. Click Save.
  12. Click Apply Access Policy.
