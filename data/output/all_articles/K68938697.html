Description

The following log messages are observed in /var/log/ltm:

warning tmm[10382]: 01200015:4: Warning, ICMP error limit reached.
warning tmm[10382]: 011e0001:4: Limiting icmp unreach response from 501 to 500 packets/sec for traffic-group /Common/traffic-group-local-only

Packet capture shows BIG-IP GTM replying with ICMP Destination unreachable (Port Unreachable) message to DNS answer.

Environment

  • BIG-IP DNS
  • DNS Cache

Cause
When there is a delay on the Internet, you will see multiple DNS queries for the same DNS record.

BIG-IP creates a connflow to handle the DNS query, therefore, for security reasons, we only keep the connflow for the latest query. (Otherwise, the BIG-IP memory will be exhausted during a DoS attack or an Internet outage)

If there is a delay, all queries will be replied by the nameserver eventually, but unless the reply comes back within the RTT of 50ms , BIG-IP will reject them by ICMP unreachable message because the connection was closed by BIG-IP.

The RTT timer is not adjustable until version 17.0.0.

BugID 969553: A DNS Cache (or Network DNS Resolver) returns SERVFAIL to some queries.

Recommended Actions
You can safely ignore these messages or upgrade to BIG-IP version 17.0.0 and adjust RTT value using the following command:

tmsh modify ltm dns cache resolver <name> nameserver-min-rtt <value>
