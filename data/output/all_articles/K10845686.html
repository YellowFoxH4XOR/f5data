Known Issue

The HTTP::path and HTTP::query iRules commands may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP virtual server is configured with a custom iRule. 
  • The custom iRule modifies the value of  HTTP::path or HTTP::query to a set string value.
  • The string value is empty.

    Example offending iRule syntax:

    when HTTP_REQUEST {
             set string_value ""
             HTTP::query $string_value
    }

Impact

The iRule fails and the connection is terminated.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to process the request, an error message logs to the /var/log/ltm file:

    err tmm[<pid>]: 01220001:3: TCL error: /<partition>/<irule name> <HTTP_REQUEST> - while executing "HTTP::path $<string name>"

  • The connection receives a TCP reset from the virtual server that terminates the connection.
  • When the string value is set to a value other than an empty value, the iRule processes the request.

Workaround

To work around this issue, you can modify the iRule to use an alternate empty string value. To do so, perform the following procedure:

Impact of workaround:  F5 recommends performing the following procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules > iRule List.
  3. Click the Name of the affected iRule.
  4. Locate the section(s) of the iRule Definition that include the HTTP::path and/or HTTP::query commands.
  5. Where the HTTP::path and/or HTTP::query commands reference the set string variable, replace the iRule syntax with the following:  
    • To set HTTP::query to an empty value, use the following syntax:

      HTTP::uri [HTTP::path]

    • To set HTTP::path to an empty value, use the following syntax:

      HTTP::uri [HTTP::query]

      For example:

      • Original iRule syntax:

        when HTTP_REQUEST {
                 set string_value ""
                 HTTP::query $string_value
        }

      • Updated iRule syntax:

        when HTTP_REQUEST {
                 HTTP::uri [HTTP::query] 
        }

  6. Click Update.
