Description

When connecting to Azure AD end failing to authenticate error message is not returned to the user.
This might happen when connecting with Edge Client, however if you try connect by the browser error should be visible.

Error example:
7572,7576,APPCTRL, 48, \UHTTP.cpp, 129, UHTTP::makeRequest(), bytes to read, 0 7572,7576,APPCTRL, 48, \UFirepass.cpp, 678, UFirepass::doGetRequestWithoutRedirect, server returned HTTP code, return code, 404, 0
7572,7576,APPCTRL, 1, \UFirepass.cpp, 689, UFirepass::doGetRequestWithoutRedirect, (0x194) EXCEPTION - wrong response HTTP code, 404, HTTP/1.0 404 NOT FOUND
7572,7576,APPCTRL, 48, \UChannelChain.cpp, 34, UChannelChain::clearChannels, destroying channel #2. Stats (0) - Recv=450 Send=194

Environment

  • Edge Client
  • Found on Apmclients-7.1.8 update2
  • Windows 

Cause

The issue is caused by Edge Client and does not render content from external idP if 4xx response code
Only 200 OK and redirects are allowed.
Any other codes are considered as errors and are by default not rendered, instead a new session is started.
