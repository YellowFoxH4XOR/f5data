Topic

The CACHE::enable iRule command forces all documents in the session to be cached by the BIG-IP LTM system. The command can also be used to cache non-GET requests. The CACHE::enable iRule command bypasses any HTTP Cache-Control response headers, including the following Cache-Response directive headers:

  • Cache-Control: private
  • Cache-Control: no-cache
  • Cache-Control: no-store
