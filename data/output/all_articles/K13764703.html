Known Issue

If you use the Traffic Management Shell (tmsh) when deleting nested objects, you may get unexpected results.

This issue occurs when the following condition is met:

  • You use the tmsh utility to delete BIG-IP configured objects using regular expression wildcard syntax.

    For example:

    tmsh modify /gtm server <gtm name> virtual-servers delete {f*}

Impact

The system deletes all objects in the category, not just objects that match the regular expression wildcard.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to use a regular expression wildcard to delete a specific group of objects, the system deletes all objects in that group.
  • When you attempt to use a regular expression wildcard to list a specific group of objects, the system lists the matching objects in that group, as expected.
