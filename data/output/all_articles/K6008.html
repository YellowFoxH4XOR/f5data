Topic

You can configure the BIG-IP system to execute system commands or scripts when a high availability (HA) failover event occurs.

Failover state goes to active state

The following file is intended for tasks, such as commands or scripts, to be executed when a standby BIG-IP system goes to an active state:

/config/failover/active

For example, if you want the BIG-IP system to add the Address Resolution Protocol (ARP) entry for an upstream device when it goes from a standby state to an active state, perform the following procedure:

  1. Log in to the command line.
  2. Using a text editor, edit the /config/failover/active file.
  3. Add one of the following commands to the bottom of the file, where 10.0.0.1 is the IP address of the upstream device, and 00:01:01:01:01:F3 is the MAC address:

    tmsh create /net arp 10.0.0.1 mac-address 00:01:01:01:01:F3

  4. Save the changes and exit the file.

The BIG-IP system will now add the ARP entry for the upstream device when it goes from a standby to an active state.

Failover state goes to standby state

The following file is intended for tasks such as commands or scripts to be executed when an active BIG-IP system goes to standby state:

/config/failover/standby

For example, if you want the BIG-IP system to delete the ARP entry for an upstream device when it goes from a standby state to an active state, perform the following procedure:

  1. Log in to the command line.
  2. Using a text editor, edit the /config/failover/standby file.
  3. Add one of the following commands to the bottom of the file, where 10.0.0.1 is the IP address of the upstream device:

    tmsh delete /net arp 10.0.0.1

  4. Save the changes and exit the file.

The BIG-IP system will now delete the ARP entry for the upstream device when it goes from active to standby state.
