K000151150: AS3 declaration response: data-group record size exceeded or Max string size exceeded

Type
Support Solution
Published
2025-05-03
Updated
2025-05-03
Applies to
  • F5 Automation and Orchestration
  • BIG-IP
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K000151150

Description

When sending an AS3 declaration, you get a response with the description "data-group record size exceeded":

 

info: [appsvcs] {"code":500,"message":"POST http://<user>:<pw>@localhost:8100/mgmt/tm/ltm/data-group/internal store a declaration response=400 body={\"code\":400,\"message\":\"01070712:3: Max string size exceeded during update of attribute:data type:class_value_item max:65520 received:65521\",\"errorStack\":[],\"apiError\":3}","host":"localhost","tenant":["<my-tenant>"],"declarationFullId":"declaration<xyz>","declarationId":"declaration<xyz>","level":"info"}

 

Audit logs on the BIG-IP show a log similar to this:

 

create ltm data-group internal /Common/____appsvcs_declaration-<xyz> command is too long

 

Environment

BIG-IP

AS3

 

Cause

An internal data group is created with meta data about the declaration in record 0 and this includes AS3 tenants on the system. Any single record cannot exceed 65520 characters. A large number AS3 tenants can cause this record size to be exceeded and you will encounter the error.

The record size limitation is described in K12112: The maximum size for a single string in a class or data group is 65,520 characters

 

Recommended Actions

 

Set encodeDeclarationMetadata to true using the Settings Endpoint in these situations per the AS3 User Guide https://clouddocs.f5.com/products/extensions/f5-appsvcs-extension/latest/userguide/best-practices.html

 

This can reduce the size of the meta data record by 50% or more in the auto-generated data group for the declaration
