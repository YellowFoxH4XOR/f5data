Description

You receive an error similar to the following when selecting a global IPI policy that resides in a non-Common partition:

01070726:3: Firewall global dynamic white/black lists rule container /Common/global-dwbl-policy in partition Common cannot reference Firewall dynamic black/white lists policy /preprod/new_policy in partition preprod.

Environment

  • IP Intelligence

Cause

This is expected. As a general rule, objects in /Common cannot reference objects in non-Common partitions.

The global IPI policy reference exists in /Common:

security ip-intelligence global-policy {  <-----
    ip-intelligence-policy /Common/new_IPI_policy
}

Recommended Actions

Create the policy in /Common.
