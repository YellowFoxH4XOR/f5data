Known Issue

This is the result of a known issue. If a Windows Mobile 5.0 client attempts an Exchange ActiveSync connection through the FirePass controller while Portal Access compression is enabled, the ActiveSync connection will fail.

For more information about Exchange ActiveSync, refer to the following website:

http://www.microsoft.com/exchange/evaluation/features/mobileaccesswp.mspx

For more information about configuring FirePass to proxy Exchange ActiveSync connections, refer to the Device Management: Customization section of the FirePass online help.

F5 Networks Product Development tracked this issue as CR86480 and it was fixed in FirePass versions 6.0.2 and 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue by disabling Portal Access compression on the FirePass controller. To do so, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. On the Portal Access: Web Applications: Caching and Compression page, clear the Enable Compression check box.
  3. Click the Requires service restart link, which is located above the Enable Compression check box.
  4. To restart FirePass services, click the Restart button.

Important: Disabling compression may increase the bandwidth consumed by the FirePass controller.
