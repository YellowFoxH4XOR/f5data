K000158946: Address List Hyperlink in Virtual Server List Opens New Address List Page Instead of Existing Object

Type
Support Solution
Published
2025-12-30
Updated
2025-12-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000158946

Description

When clicking on an Address List hyperlink in the "Destination" column of the "Local Traffic › Virtual Servers : Virtual Server List" page in the BIG-IP GUI, the system incorrectly opens the "Shared Objects › Address Lists › New Address List" creation page instead of opening the existing configured Address List object.

Environment

  • BIG-IP LTM
  • 17.1.3 and higher

Cause

This issue is associated with the following Bug ID2163321.

Recommended Actions

Monitor future BIG-IP LTM release notes for the fix associated with Bug ID2163321. As a workaround, navigate directly to the Address List object using the menu path: Shared Objects › Address Lists and locate the specific Address List manually.

None
