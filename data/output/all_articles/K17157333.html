Issue

Error Message

01070417:5: AUDIT - client <interface>, user <user name> - transaction #<ID> - object <action> <object>

In this error message, note the following:

  • <interface> is the interface used to make the configuration change. This may be the TMOS Shell (tmsh) or the Configuration utility (tmui).
  • <user name> is the name of the user changing the configuration.
  • <ID> is the transaction ID number for the configuration change.
  • <action> is the configuration action performed by the user.
  • <object> is the name of the configuration object and the object properties that were created or modified.

For example:

  • When using tmsh to create a pool, the error message appears similar to the following:

    01070417:5: AUDIT - client tmsh, user admin - transaction #1865948-1 - object 0 - obj_delete { pool_profile { pool_profile_pool_name "/Common/example" } } [Status=Command OK]

  • When using the Configuration utility to create a pool, the error message appears similar to the following:

    01070417:5: AUDIT - client tmui, user admin - transaction #1865948-2 - object 0 - obj_delete { pool_profile { pool_profile_pool_name "/Common/example" } } [Status=Command OK]

Message Location

You may encounter this message in the following location:

  • The /var/log/audit file

Description

This message occurs when all of the following conditions are met:

  • Audit logging is enabled.
  • A BIG-IP system user creates or modifies a configuration object.

Important: Beginning in BIG-IP 11.6.0, audit logging is enabled by default. For more information, refer to K16304: Audit logging for BIG-IP configuration changes is now enabled by default.

Impact

None. These messages are informational.

Recommended Actions

None
