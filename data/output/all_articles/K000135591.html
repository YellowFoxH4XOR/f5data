K000135591: EUD HSB Interface Test logging Fpga0 rescan failed

Type
Support Solution
Published
2023-08-11
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K000135591

Description

EUD test result may report HSB (High Speed Bridge) Interface Test with the following log entries:

 

 05 11 2023 15:11:26  Updating HSB:

 05 11 2023 15:12:09  Fpga0 rescan failed: rescan_dlactive_timeout

 05 11 2023 15:12:09  Failure to negotiate link.

 05 11 2023 15:12:11  HSB load attempt 1 failed, retrying...

 05 11 2023 15:12:53  Fpga0 rescan failed: rescan_dlactive_timeout

 05 11 2023 15:12:53  Failure to negotiate link.

 05 11 2023 15:12:54  HSB load attempt 2 failed, retrying...

 

This error occurs when FPGA scan timeouts whilst attempting to load HSB Firmware as part the HSB Interface Test. There will be 9 HSB load attempts before declaring the HSB load failure.

 

02 09 2017 02:02:12 HSB load attempt 9 failed, retrying...

02 09 2017 02:03:27 Fpga0 rescan failed: rescan_dlactive_timeout

02 09 2017 02:03:27 Failure to negotiate link.

02 09 2017 02:03:28 Test Complete: Cerberus HSB Update: FAILED

02 09 2017 02:03:28 ERROR: Failed to load HSB

02 09 2017 02:03:32 Did not find a current HSB firmware version for HSB#2

02 09 2017 02:03:32 Current HSB Version: Unknown

02 09 2017 02:04:31 Test Complete: HSB Interface Test: FAILED

 

Environment

  • EUD HSB Interface Test

Cause

As HSB Firmware load failed, the HSB will not be functional.

 

 Recommended Actions

If EUD HSB Interface fails, please proceed to RMA blade or platform.

 

Additional Information

None
