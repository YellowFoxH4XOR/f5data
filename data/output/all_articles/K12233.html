Known Issue

This is the result of a known issue. When a FirePass administrator navigates to the Portal Access: Mobile E-Mail page and clicks the Update button located under the Source for address list section, and the administrator does not manually re-enter the Bind password, FirePass stores random characters in the Bind password field. As a result, authentication may fail.

This issue occurs when the Portal Access Mobile E-Mail feature has been configured with the Use LDAP query for mail server, display and logon information option.

F5 Product Development is tracking this issue as ID 339702.

This issue has been fixed in cumulative hotfix HF-610-5 issued for FirePass version 6.1.0, and in cumulative hotfix HF-70-2 issued for FirePass version 7.0.0.

You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about downloading software from F5, refer to SOL167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

To prevent FirePass from storing random characters in the Bind password field, manually enter the correct password each time updates are needed on the Portal Access: Mobile E-Mail page.
