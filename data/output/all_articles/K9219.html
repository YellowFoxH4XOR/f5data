K9219: The Windows Files webifyer does not appear on the webtop for external users

Known Issue

This is the result of a known issue. If you create a master group with external users, and you clear the Limit Windows Files Access to Favorites only check box for that master group on the Portal Access: Windows Files: Master Group Settings page, the Windows Files webifyer may not appear on the FirePass webtop for users in that master group. This issue occurs when you do not configure one or more Windows Files favorites for the master group. 

Note: If you configure one or more Windows Files favorites for the master group, the Windows Files webifyer will appear on the webtop for users in the master group.
 
F5 Networks Product Development is tracking this issue as CR107546.
 
Workaround
 
You can work around this issue by configuring at least one Windows Files favorite for the master group. Configuring a Windows File favorite will cause the Windows Files webifyer to appear on the webtop.
