Known Issue

BIG-IP Configuration utility users may be unable to view system log files.

This issue occurs when all of the following conditions are met:

  • The BIG-IP is configured with a non-administrative user.
  • The BIG-IP system grants log access to the role of the non-administrative user.
  • The BIG-IP is rebooted after log access is granted.

Impact

Non-administrative role users cannot access system log files in the BIG-IP Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Non-administrative users cannot access the Configuration utility System > Logs menu
  • An administrator can view the Configuration utility Log Access settings, and see that log access is set to Deny for non-administrative users.
