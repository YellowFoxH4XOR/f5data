K000147926: How many IP Prefix Sets can I have for one Service Policy?

What Happened?

  • While adding the service policy you realized that you have lot of IP's to add and you would like to know the limit to that you can add in one service policy.

 

Environment

  • F5® Distributed Cloud Console
  • Service Policy

 

Resolution/Answer

  • You can assign maximum 4 IP Prefix Sets per service Policy. 
  • However IP Prefix Set is an object which can contain maximum up to 1024 prefixes each. So essentially it means one can include up to 4096 prefixes in total.
