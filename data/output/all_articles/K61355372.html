K61355372: Clients on specific vlan unable to reach virtual server

Type
Support Solution
Published
2020-03-17
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K61355372

Description
You see client connection from a specific vlan are unable to reach a virtual server

In packet captures, you may see that the Self-IP associated with this vlan is returning an ICMP Host Unreachable response

Environment

  • BIG-IP LTM
  • VLANs
  • Virtual Server

Cause
Your virtual server was configured for specific VLANs, but not the one the clients are trying to connect from

Recommended Actions

  1. Navigate to the virtual server
  2. Add the VAN the clients are connecting from

Additional Information
None
