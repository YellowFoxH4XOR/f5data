K46730009: Using Restcurl to obtain a list of all virtual servers managed by Big-IQ

Type
Support Solution
Published
2021-10-27
Updated
2025-04-01
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K46730009

Description

The following Restcurl operation can be used to obtain a list of all Vips stored in Big-IQ. 

Environment

Big IQ Command line

Cause

Because there is not a solid option to export all of your virtual servers managed by your Big-IQ, but You want to obtain a list of all virtual servers on your Big-IQ deployment that you want to export to a file. You can use the following commands to obtain that list and even export it to a text file which may be downloaded from the Big-IQ. 

Recommended Actions

The endpoint for the VIP locations on the Big-IQ CM is mgmt/cm/adc-core/working-config/ltm/virtual
You can initiate a Restcurl command against this endpoint to obtain  list of your virtual server. 

Example:

To specify specific information about the virtual servers in the output such as only the name, port and destination address, you can specify those endpoints to list in the restcurl command as well

Example: 
[root@bigiq1:Active:Standalone] config # restcurl -u admin:admin mgmt/cm/adc-core/working-config/ltm/virtual'?$select=name,destinationAddress,destinationPort'
{
  "items": [
    {
      "name": "exchange2016.smtp.com_smtp_vs",
      "destinationPort": "587",
      "destinationAddress": "192.168.100.53"
    },
    {
      "name": "Exchange2016_smtps",
      "destinationPort": "587",
      "destinationAddress": "192.168.100.62"
    },

To output this information to a file which can be pulled from the Big-IQ system, you would append the output operator to the command and specify the target file location. 

This is done typically using the following operator at the end of the curl operation. 

>> /path/to/target/file

Example: 
[root@bigiq1:Active:Standalone] config # restcurl -u admin:admin mgmt/cm/adc-core/working-config/ltm/virtual'?$select=name,destinationAddress,destinationPort' >> /shared/tmp/all_vips.txt

[root@bigiq1:Active:Standalone] config # ls -l /shared/tmp | grep all_vips.txt
-rw-r--r--.   1 root root          3114 2021-10-22 09:10 all_vips.txt

You may then download the output file to a local machine.
