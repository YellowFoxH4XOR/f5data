Known Issue

An error message displays in the /var/log/ltm file for some SNMP queries.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system runs on a VIPRION chassis.
  • An SNMP query is made to the F5 sysBladeVoltageNumber object ID (OID).

Impact

For bladed systems, the system fails to report blade voltage. For non-bladed systems, the error message is cosmetic and can be safely ignored.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Error messages similar to the following example are logged in the /var/log/ltm file:

    err mcpd[<pid>]: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (20594).
