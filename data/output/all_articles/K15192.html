Known Issue

BIG-IP client TCP connections may stall when you run the tcpdump command.

This issue occurs when all of the following conditions are met:

  • TCP segmentation offload (TSO) is enabled on the BIG-IP system.

    Note: TSO support was introduced in BIG-IP 11.4.0 and was initially enabled by default only for BIG-IP Virtual Edition (VE). However, beginning in BIG-IP 11.5.0, TSO is enabled for all platforms.

  • You run the tcpdump command on the BIG-IP system.

Note: This issue occurs when you run the tcpdump command on interface 0.0. For example: tcpdump -nvi 0.0.

Impact

Client TCP connections to a BIG-IP virtual server stall.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Client TCP connections to a BIG-IP virtual server stall when you run tcpdump on the BIG-IP system.

Workaround

To work around this issue, you can run the tcpdump command on an interface other than 0.0.
