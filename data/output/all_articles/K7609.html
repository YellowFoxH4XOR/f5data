Topic



You can configure a Network Access Favorite to specify a string to launch a command or application transparently. To do so, you can enter a string in the App Path field on the Launch Application tab.

You can only specify one command or application in the App Path field. For example, the following string will not start both applications:

C:\MyApps\App1 & C:\MyApps\App2

Running multiple commands or applications

To run multiple commands or applications, perform the following procedure:

  1. Enter a single command in the App Path field.

  2. Click Add.

  3. Enter a second command in App Path field.

  4. Click Add.

Repeat these steps until you have added all of the commands.

If the commands must run in a specific order, or if you need more advanced programming controls, you can create a script or batch file to run the commands. For example, you could create the following NetworkAccessCommands.cmd batch file:

iexplore http://127.10.10.80/sales/automation.pl
telnet 127.10.10.10
putty -ssh 127.10.10.10

After creating the script or batch file, you must enter the path to that file in the App Path field. For example, enter the following path:

C:\Apps\ NetworkAccessCommands.cmd

Also, you must distribute the script or batch file to everyone who will access the Network Access Favorite, and ensure the file is saved to the exact path you specified in the Network Access Favorite. Using our previous example, the batch file should be saved to the following path on the client machines:

C:\Apps\ NetworkAccessCommands.cmd
