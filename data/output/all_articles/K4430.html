Topic

BIG-IP and 3-DNS provide a number of internal variables that are used to configure experimental features and fixes. By default, these internal variables are not retained after a reboot. For more information about internal variables, refer to K920: Overview of internal variables.

To save an internal variable, perform the following steps:

Important: Be cautious when saving internal variables. Internal variables enable experimental features and fixes that may not always work as expected; therefore, saving an internal variable can cause BIG-IP or 3-DNS to enter an unusable state at boot up. In addition, some internal variables must be used only under specific conditions (such as when the unit is active) and should not be started indiscriminately when the system boots.

  1. Log in to the command line.
  2. Using a text editor, such a vi or pico, edit the /config/startup file.
  3. At the end of the file, on a new line, type the internal command for the internal variable that you want to save.
  4. Save the file and exit the editor.

The internal variable is now saved and will be set whenever the system boots.
