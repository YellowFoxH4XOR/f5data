Known Issue

This is the result of a known issue. In the Configuration utility, the Enable ARP setting is located in the configuration page for each virtual server. The location of this setting is misleading; it should be located in the virtual address settings, rather than the virtual server settings. The Enable ARP setting affects all virtual servers that use the same IP address.

For example, if you configure the virtual servers 172.16.22.1:80 and 172.16.22.1:8080 and you disable ARP for the virtual server 172.16.22.1:80, BIG-IP will also disable ARP for 172.16.22.1:8080.

F5 Networks Product Development tracked this issue as CR27518 and CR41895.
