Known Issue

The active BIG-IP system may send Open Shortest Path First (OSPF) link-state advertisements (LSAs) with an infinite metric value.

This issue occurs when the following conditions are met:

  • The BIG-IP high-availability pair is configured to use the OSPF/OSPFv3 protocol.
  • The BIG-IP high availability (HA) systems are configured to redistribute connected routes with peer router devices.

Impact

The infinity route metric gets exchanged in the other networks affecting the routing process.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The show ip ospf database external command displays the AS-external LSAs with a metric value of 16777215.
