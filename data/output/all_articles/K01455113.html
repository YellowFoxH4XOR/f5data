Issue

Error Message

010719fd:3: No IPv<version> self IP exists on VLAN (<VLAN_name>) for static route (<route_name>)

In this error message, note the following:

  • <version> is the Internet Protocol version.
  • <VLAN_name> is the name of the VLAN where the self IP address resides.
  • <route_name> is the name of the static route referencing the VLAN.

For example:

010719fd:3: No IPv4 self IP exists on VLAN (/Common/v987) for static route (/Common/route_example)

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The BIG-IP Configuration utility

Description

This message occurs when the following condition is met:

  • You attempt to delete a self IP address that belongs to a VLAN that is referenced by a static route

Impact

You are unable to delete the self IP address until the static route is removed.

Recommended Actions

None
