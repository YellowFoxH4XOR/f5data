Known Issue

This is the result of a known issue. If a Mac OS X or Linux client logs out from the FirePass webtop before terminating an active Network Access connection, the Network Access connection remains active after logout.

F5 Product Development tracked this issue as CR68662 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass version 5.x branch.

Workaround

You can work around this issue by manually closing the Network Access connection after logout. To do so, click the Terminate button in the Network Access pop-up window.
