Description

How can we access Partition CLI from Controller CLI?

Environment

  • F5OS-C
  • Velos

Cause

None

Recommended Actions

  1. Login to Controller CLI with root account.
  2. check partition ID and which controller is active for the partition with following commands

    su admin
    show partitions

                                                                          RUNNING
                     BLADE OS    SERVICE                 PARTITION        SERVICE     STATUS
    NAME         ID  VERSION     VERSION     CONTROLLER  STATUS           VERSION     AGE
    ------------------------------------------------------------------------------------------------
    partition_A  1   1.3.1-5968  1.3.1-5968  1           running-standby  1.3.1-5968  178d
                                             2           running-active   1.3.1-5968  178d
    partition_B  2   1.3.1-5968  1.3.1-5968  1           running-active   1.3.1-5968  142d
                                             2           running-standby  1.3.1-5968  142d
    none         0   -           -           1           disabled         -           -
                                             2           disabled         -           -

  3. then run the below to back to bash.

    exit

  4. if Controller's active slot is different from Partition's active slot, then run below

    ssh controller-<active_slot_number_for_partition>

    For example,

    ssh controller-2

  5. run the following command: 

    docker exec -it partition<ID>_cli su admin

    Prompt should change to:

    <partition_name>-<controller_number>#

    For example,

    docker exec -it partition1_cli su admin

    Partition_A-2#

  6. double check you are in right controller for the partition with the following command:

    show system redundancy | include current

    Example Output:

    system redundancy state current-active controller-2
