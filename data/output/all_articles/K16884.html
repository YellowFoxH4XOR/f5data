Known Issue

A network virtual server with a FastL4 profile and the PVA Acceleration option set to Guaranteed may fail to send a TCP reset (RST) packet for flows that are not eligible for embedded Packet Velocity Acceleration (ePVA).

This issue occurs when all of the following conditions are met:

  • Your configuration has a network virtual server that references a FastL4 profile.
  • The FastL4 profile's PVA Acceleration option is set to Guaranteed.
  • The network virtual server creates a TCP connection flow that is not eligable for ePVA acceleration.
  • The TCP connection experiences an issue that requires sending a TCP reset (RST) packet to the client.

Impact

The client's connection may appear to stop responding, with no diagnostic data provided by the BIG-IP system. Clients retransmit packets unnecessarily, causing additional network traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The client's connection may appear to stop responding when connecting to the BIG-IP system.
  • You may see excessive client retransmit packets when viewing packet captures.
