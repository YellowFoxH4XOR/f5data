Known Issue

This is the result of a known issue. The FirePass controller, the BIG-IP APM system, and the BIG-IP SAM system do not detect the Norton Security Suite released by Comcast. Clients running Comcast's Norton Security Suite fail the antivirus check if you use a pre-logon sequence with an antivirus check that requires that real-time protection (RTP) is enabled on a FirePass controller, or an access policy that has an Antivirus Check action on the BIG-IP APM system, SAM, or the BIG-IP Edge Gateway system.

Note: RTP corresponds to the Monitor is running rule in the pre-logon sequence.

The FirePass Windows antivirus checker and the BIG-IP APM and BIG-IP SAM Antivirus Check action use software libraries from a software development kit (SDK) created by OPSWAT. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT is aware of the issue described in this Solution and is working on a resolution. Once a resolution is available from OPSWAT, F5 will issue a hotfix to address this issue.

F5 Product Development tracked this issue as CR138640 and it was fixed starting in OPSWAT version 3.4.10. For more information, refer to K6664: Obtaining and installing OPSWAT hotfixes.
