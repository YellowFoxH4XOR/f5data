Topic

You should consider using this procedure under the following condition:

  • You want to shut down and restart a Virtual Clustered Multiprocessing (vCMP) guest from the vCMP host.

Description

You can shut down a vCMP guest by changing its state from deployed to either provisioned or configured. When a vCMP guest is shut down, the only way to start it is by changing its state to deployed. You can change the vCMP guest's state through the vCMP host using either the TMOS Shell tmsh utility or the Configuration utility. The following describes the available states of the vCMP guest:

State of the vCMP guestDescription
ConfiguredThe vCMP guest is not allocated any hardware resources. However, this does not affect the vCMP guest's existing virtual disk. Its virtual disk continues to reside on the vCMP host while it is in this state. The virtual disk would be reused by the vCMP guest when it moves out of the Configured state.
ProvisionedThe vCMP guest is allocated the necessary hardware resources such as CPU cores, virtual disk, and so on, but it is not running. Set the vCMP guest to this state if you want to shutdown a vCMP guest without deallocating its hardware resources.
DeployedThe vCMP guest is allocated the necessary hardware resources and it is running. Set the vCMP guest to this state to startup a vCMP guest that is already shut down.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the vCMP host.

Procedures

  • Shutting down a vCMP guest using the Configuration utility
  • Shutting down a vCMP guest using the tmsh utility
  • Restarting a vCMP guest using the Configuration utility
  • Restarting a vCMP guest using the tmsh utility

You can shut down a vCMP guest by changing its state to provisioned or configured through the vCMP host using either the Configuration utility or tmsh utility. To do so, perform either of the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your vCMP host. The vCMP guest cannot process traffic until it is restarted.

Shutting down a vCMP guest using the Configuration utility

  1. Log in to the Configuration utility of the vCMP host.
  2. Go to vCMP > Guest List.
  3. Select the name of the vCMP guest you want to shut down.
  4. For Requested State, select Configured or Provisioned.
  5. Select the Update button.

Shutting down a vCMP guest using the tmsh utility

  1. Log in to the tmsh utility of the vCMP host.
  2. To shut down a vCMP guest, enter the following command syntax:

    modify /vcmp guest <name of vCMP guest> state <configured or provisioned>

    For example:

    modify /vcmp guest myguest state configured

    Note: You can shut down all vCMP guests by replacing name of vCMP guest with all. For example, modify /vcmp guest all state configured.

  3. Wait for the vCMP guest to completely shut down. You can monitor the status using the show vcmp guest command.

You can start up a vCMP guest by changing its state to deployed through the vCMP host using either the Configuration utility or tmsh utility. To do so, perform either of the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Restarting a vCMP guest using the Configuration utility

  1. Log in to the Configuration utility of the vCMP host.
  2. Go to vCMP > Guest List.
  3. Select the name of the vCMP guest you want to restart.
  4. For Requested State, select Deployed.
  5. Select the Update button.

Restarting a vCMP guest using the tmsh utility

  1. Log in to the tmsh utility of the vCMP host.
  2. To start up a vCMP guest, enter the following command syntax:

    modify /vcmp guest <name of vCMP guest> state deployed

    For example:

    modify /vcmp guest myguest state deployed

    Note: You can start all vCMP guests by replacing name of vCMP guest with all. For example, modify /vcmp guest all state deployed.

  3. Wait for the vCMP guest to start up. You can monitor the status using the show vcmp guest command.
