Description

Follow the article K07608215: Configuring BIG-IP Edge Client to establish a network access session (VPN) before logging in to Windows (Windows Logon Integration) , establish the VPN, then login the windows, but cannot disconnect the VPN manually.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Network Access
  • Windows Edge client.
  • Windows Logon Integration

Cause

None

 Recommended Actions

It is by design.
The workaround is, login the Configuration Utility, navigate to Access  ››  Overview : Active Sessions, selct the sessions, kill the sessions.

Additional Information

If it is required to disconnect the VPN manually, please contact F5 support, raise the feature request.
