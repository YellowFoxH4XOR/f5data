Known Issue

This is the result of a known issue. When Microsoft Exchange Outlook Web Access (OWA) with Symantec Enterprise Vault installed is accessed through a FirePass web portal favorite, you may encounter a 403 Forbidden error when trying to empty your Deleted Items folder.

This behavior occurs because OWA is unable to run the JavaScript EVPremiumReplacement.js script.  

F5 Networks Product Development is tracking this issue as ID 317722 and CR137737.

Workaround

important:This workaround is only valid for FirePass 6.0.2 HF-602-6 and later and Portal Access : Web Applications : Content Processing is not in compatibility mode

You can work around this issue by creating a content processing script. To do so, perform the following procedure:

  1. From the FirePass Administrative Console, click Portal Access.
  2. Click Content Processing.
  3. Click Add New Favorite.
  4. Select the Processing script name text box.
  5. Enter a name for your script.

    For example:

    OWA-fix
  6. Select the URL match patterns text box.
  7. Enter the following content: 

    '*://*/enterprise%20vault/7.0.5.3001/EVPremiumReplacement.js
  8. Leave the Content Type text box blank.
  9. Select the Allow caching check box.
  10. Select the Sed processing script text box.
  11. Enter the following content: 

    s@window\.open(@F5_Invoke_open([0x6f,0x70,0x65,0x6e],window,@  

    s@g_HTTPDelItems\.open(@F5_Invoke_open([0x6f,0x70,0x65,0x6e],g_HTTPDelItems,@g
  12. Select the Post-process response data (after content patching) option from the Processing drop-down list.
  13. Click the Add New button.

Note: For more information about content processing scripts, refer to K9688: Overview of Web Application content processing scripts.
