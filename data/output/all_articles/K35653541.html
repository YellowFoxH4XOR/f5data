Description

When upgrading the BIG-IP system, the device fails to load the configuration. You may find the following message in /var/log/ltm:

01071008:3: Provisioning failed with error 1 - 'Cannot provision more than 3 modules on vCMP Guest with 8GB memory or less.'

Environment

  • vCMP guest with 8 GB RAM or less.
  • Four or more modules provisioned.
  • Software upgrade.

Cause

Behavior change introduced by Bug ID 743970. Starting from version 14.1.0, the provisioning process halts with an error if a vCMP guest has more than three modules with 8 GB or less of RAM.

Recommended Actions

vCMP guest with 8GB of memory or less will be restricted to provisioning 3 modules. In order to provision more than 3 modules you will need to allocate additional memory to the vCMP guest.
