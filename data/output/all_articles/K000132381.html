Description

This article was created to address the support of configuring Bot Defense configurations using AS3 Declarations.

Can the following options be configured via AS3?:

  • Bot Profile > Bot Mitigation Settings > DoS Attack Mitigation Mode
  • Bot Profile > Bot Mitigation Settings > API Access for Browsers and Mobile Applications
  • Bot Profile > Bot Mitigation Settings > Browser Verification
  • Bot Profile > Bot Mitigation Settings > Mitigation Settings Exceptions
  • Bot Profile > Browsers > Single Page Application
  • Enable "Signature Staging Upon Update"
  • Enable Bot Signatures
  • Apply Profile Template

Environment

  • AS3 Declarations

Cause

None

Recommended Actions

It is possible to use the following iControl REST API endpoint to configure the Bot Defense Profile:

  • /mgmt/tm/security/bot-defense/

For example, the following curl command creates a Bot Defense Profile called MyBotProfile with enforcement mode set to blocking on host bigip1.int.net:

curl -sku admin:admin -H "Content-type: application/json" -X POST https://bigip1.int.net/mgmt/tm/security/bot-defense/profile/ -d '{"name":"MyBotProfile", "enforcementMode":"blocking"}' | jq '.'

Starting from AS3 3.56.0, you can use AS3 to configure some of these Bot Defense Profile settings. Note that not all settings listed in the Description section are available in AS3 3.56.0. For information about the settings that are available in the AS3 declarations, refer to the following example declarations from F5 AS3 GitHub repo:

  • https://github.com/F5Networks/f5-appsvcs-extension/blob/main/examples/declarations/example-bot-defense-complete-profile-reference.json
