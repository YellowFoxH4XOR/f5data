Description

  • SSL handshake failing with ltm logs showing messages similar to below:
    crit tmm2[15995]: 01260010:2: FIPS acceleration device failure: fips_poll_completed_reqs: req: 134 status: 0x40000116 : ERR_HSM_ERROR
  • You observe that FIPS keys are missing on the unit.
  • Prior to the issue starting, a user tried creating a key with security-type nethsm

 

Environment

BIG-IP system using a HSM device.
Software version prior to 12.0

Cause

The issue is caused by a known ID tracked as ID856949
Note: Details related to ID856949 are not available on F5 public resources 

Recommended Actions

  • Upgrade to a recent software release.
    Refer to K5903: BIG-IP software support policy  for a list of supported software releases
  • In case an upgrade is not possible, you can workaround the issue by recreating the missing FIPS keys or syncing from another device where the keys are available.
