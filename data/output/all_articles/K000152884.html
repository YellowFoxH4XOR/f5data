K000152884: Missing APM Macro templates

Type
Support Solution
Published
2025-08-14
Updated
2025-09-08
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000152884

Description

Customer reports that some APM macro templates, specifically AD query auth OTP by email and resources, are missing in their BIG-IP APM 17.1.2 deployment.

 

Environment

  • BIG-IP APM
  • Access Policy
  • APM Macro templates missing.

Cause

Customer is using Access Profile type APM+LTM

This Access Profile type APM+LTM has limited marco options.

 

The Macro for AD query auth OTP by email and resources includes a Full Resource Assignment object which would not be compatible with this type of policy.

 

Recommended Actions

Create an Access Policy with Profile type All or SSL-VPN and you can see the full list of Macro's
