K07014156: Syntax Error:(/config/bigip_gtm.conf at line: ) '':'' unknown property

Type
Support Solution
Published
2020-06-09
Updated

Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP DNS: 12.1.2
Source
https://my.f5.com/manage/s/article/K07014156

Description
The configuration fails to load due to a stray colon-character that gets added to the prober pool stanza in the BIG-IP DNS configuration file.
The system displays an error messages similar to the following example:

Syntax Error:(/config/bigip_gtm.conf at line: ) ":" unknown property

Environment

  • Upgrade from pre-12.1.3
  • GTM Prober Pool Members 

Cause
Suspected variation of ID743082

Recommended Actions

Impact of workaround: F5 recommends that you perform the following workaround during a maintenance window.

    1. Log in to the command line of the affected BIG-IP system.
    2. To create a backup copy of the /config/bigip_gtm.conf file, type the following command:

      cp /config/bigip_gtm.conf /config/bigip_gtm.conf.K07014156

    3. Use a text editor to open the /config/bigip_gtm.conf file.

    4. Locate the affected prober pool and remove the stray colon

      gtm prober-pool /Common/prober_pool_example {
          members {
              /Common/ns.example.member.com {:   ----------------->>> !!!
                  order 0
              }
          }
      }
       
    5. Load the BIG-IP DNS configuration
    tmsh load sys config gtm-only
