Topic

Terminal Access Controller Access-Control System Plus (TACACS+) is a protocol that remotely authenticates and authorizes users. For more information about the TACACS+ protocol, refer to The TACACS+ Protocol.

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

This article covers how to configure TACACS+ authentication for accessing the BIG-IQ GUI. To configure TACACS+ authentication for the BIG-IQ command line refer to K20400650: How to enable remote TACACS+ authentication on BIGIQ for SSH/TMSH access.

Description

Starting in BIG-IQ 5.4, the BIG-IQ system uses precisely defined roles for authorization.

You can configure the BIG-IQ to authenticate and authorize users using TACACS+ for the following functions:

  • Authenticate BIG-IQ-configured users
  • Authenticate users and apply BIG-IQ user roles

    Note: TACACS+ does not directly configure individual users on the BIG-IQ.

Prerequisites

  • You have administrative access to the BIG-IQ user interface.
  • You configure the TACACS+ server with the user accounts required for BIG-IQ access.
  • You configure the BIG-IQ with DNS.
  • You have the TACACS+ server IP address, service port, shared secret, service name, and protocol name.

Procedures

  • Configuring the BIG-IQ to use a TACACS+ server
  • Adding a TACACS+ authenticated user with a predefined BIG-IQ user role
  • Creating a TACACS+ user group
  • Troubleshooting TACACS+ authentication and authorization issues

Configuring the BIG-IQ to use a TACACS+ server

You can configure the BIG-IQ system to authenticate and authorize users using TACACS+. The following procedure adds the TACACS+ provider to the BIG-IQ system.

Impact: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the system interface.
  2. Click the System tab.
  3. Navigate to USER MANAGEMENT > Auth Providers.
  4. Click Add.
  5. On Provider Type, click TACACS+.
  6. In Name, enter a name for the TACACS+ provider.
  7. Under Servers, in Host, enter a name or IP address.
  8. In Port, enter a port or keep the default, which is 49.

    Note: To add additional TACACS+ servers, click Add row (+).

  9. In Secret, enter the shared string that you configured on your TACACS+ server.
  10. In Primary Service, enter the type of authorization requests you want for this service.

    For example, enter system, connection, or PPP. The type must match your TACACS+ server settings.

  11. In Protocol, enter an optional subset of a service.

    For example: enter IP, telnet, or http. The subset must match your TACACS+ server settings.

  12. If you want to encrypt the data, for Encrypt, select Yes.

    Important: Do not select the Hide Provider check box because doing so disables the authentication provider, and the provider no longer displays as a selection on the login screen.

    Note: To verify that the BIG-IQ is communicating with the TACACS+ server, enter values in the Test User and Test Password boxes, and then click Test.

  13. Click Save.
  14. Click Close.

    Note: You can now associate TACACS+ server users with BIG-IQ users and roles.

Adding a TACACS+ authenticated user with a predefined BIG-IQ user role

You can add a user to the BIG-IQ and define their user access role(s).

Impact: Performing the following procedure should not have a negative impact on your system.

Note: You must configure the BIG-IQ Centralized Management system with the TACACS+ server settings prior to implementing the following procedure.

Important: If you do not assign a TACACS+ authenticated role to a user, their authentication fails.

  1. Log in to the BIG-IQ interface.
  2. Click the System tab.
  3. Navigate to USER MANAGEMENT > Users.
  4. Click Add.
  5. On Auth Provider, click the TACACS+ profile you created in the previous procedure.
  6. In User Name, enter the user's name. 
  7. In Full Name, type the user's full name.

    Note: The user account must be configured on the TACACS+ server. Users' full names can contain a combination of symbols, letters, numbers, and spaces.

  8. In Available, select the check box for each user role that you want to assign the user.
  9. To move the user roles(s) to the Selected list, click <.

    Important: The roles you assign a user determine whether they have access to the BIG-IQ interface.

  10. Click Save & Close.

Creating a TACACS+ user group

After you configure the BIG-IQ with a TACACS+ server profile, you can create TACACS+ authenticated user groups, which contain multiple users who are authenticated to the TACACS+ server.

Impact: Performing the following procedure should not have a negative impact on your system.

Important: If a user does not have a user account on the the provider TACACS+ server, their authentication fails when they access the BIG-IQ.

  1. Log in to the BIG-IQ interface.
  2. Click System tab.
  3. Navigate to USER MANAGEMENT > User Groups.
  4. Click Add.
  5. In Name, type a name for the user group.
  6. On Auth Provider, click TACACS+.
  7. If applicable, under Users, in the Available column, select the checkbox next to each user you want to add to the user group.
  8. If applicable, to move the users to the Selected column, click >.
  9. For Authorization Attributes, in Attribute and Value, enter the attribute and value pair that you configured on the TACACS+ server for the user group.

    Important: Do not use the equal sign (=) in the Attribute or Value boxes.

  10. In User Roles, select the check box for the role(s) you want to assign to the user group.
  11. Click Save & Close.

Troubleshooting TACACS+ authentication and authorization issues

The most effective way to troubleshoot TACACS+ authentication and group assignment issues is to view the communication stream.

Because TACACS+ network communication is encrypted, you need the TACACS+ shared secret string to view TACACS+ communication. With the shared secret string and a network capture of the TACACS+ communication, you can decrypt the capture and view the underlying communication.

Using TShark—the BIG-IQ command line utility—and the shared secret string, you can see the exchange of the four packets that are involved in TACACS+ communication:

  • Authentication request
  • Authentication reply
  • Authorization request
  • Authorization reply

Viewing the TACACS+ network communication

  1. Log in to the command line of the BIG-IQ device.
  2. Use the following TShark command syntax to decrypt and view the TACACS+ communication:

    tshark -i <vlan name> -O tacplus -Y tacplus -o tacplus.key:<shared secret> host <tacacs+ server address> and port <tacacs+ port>

    Replace:

    • <shared secret> with the shared secret string for your TACACS+ server.
    • <vlan name> with the BIG-IQ Virtual Local Area Network (VLAN) name that you use to access the TACACS+ server. Use eth0 if you access the TACACS+ server using the management interface.
    • <tacacs+ server address> with your actual server address.
    • <tacacs+ port> with the TACACS+ server port you configured.
  3. While the capture is running, send a test TACACS+ request with the Test Auth Provider Settings tool on the USER MANAGEMENT > Auth Providers page.

Note: When viewing network level communication, the last line in the TACACS+ Authorization reply typically contains the remote group assignment.
