K64320138: How to edit Chargeback Tag for FCP on BIG-IQ

Source

Description

You are using BIG-IQ Centralized Manager or BIG-IQ License Manager to manage your FCP licenses.
The Chargeback Tag is visible on the customer usage reports, and can be useful if you bill across multiple departments within the account.

Environment

  • BIG-IQ
  • FCP
  • Chargeback Tag

Cause

When you first provision a license to a BIG-IP, you have the option to add a free text entry into a field called "Chargeback Tag".

However if you missed this or want to change it afterwards, it is currently not possible to add or edit the entry via the BIG-IQ GUI.

Recommended Actions

You will need to copy the bash code from the Dev Central "Code Snippet" article and then create a simple CSV file including details of the BIG-IP IP address or BIG-IP MachineID and corresponding Chargeback Tag text you want to create or edit into the /shared directory.

You will then run this script on the BIG-IQ, which will confirm "Updating" followed by each IP address or MachineID and Chargeback Tag text.

The Charge back tag can be seen in the BIG-IQ GUI: Devices >> License Management >> Licenses >> FCP name >> Select the license type

It can also be seen in the reports created and shared each quarter by the Customer Success team.

  1. In /shared directory, create a CSV file names update.csv with the formatting of IP,chargeback text or MachineID,charge back text.
    • cd /shared
    • vi update.csv
  2. Enter details for each BIG-IP onto separate lines using the example formatting below
    • 10.31.41.22,department 42
    • or
    • xxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxx,department 42
  3. Save this file
  4. Create a file named update.sh in the same directory and copy-paste the "Code Snippet" from the Dev Central article into this file using your favourite editor. Please see "Additional Information" at the end of this article for more information about this script.
  5. Make this file executable using
    • chmod u+x update.sh
  6. Run the script using
    • ./update.sh
  7. If everything was done correctly, the script will output a similar message as below to the command line for each entry of the update.csv file:
    • Updating 10.31.41.22 to 'department 42"
