Known Issue

The Configuration utility may produce an error when selecting a device address

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with self IP addresses that reside in a route domain other than the default route domain (0).
  • You attempt to use a non-default route domain self IP address when configuring a device address (ConfigSync, Failover Network, Mirroring).

Impact

The Configuration utility displays an error message and the configuration setting fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to use a non-default route domain self IP addresses as a device address, the system displays an error message that appears similar to the following example:

    0107145a:3: CMI self-device (/<partition>/<BIG-IP fqdn>) the unicast effective address (<ip address>%<route domain>) cannot be in a route-domain.
  • Using a self IP address from the default route domain does not produce an error and the configuration change is successful.
