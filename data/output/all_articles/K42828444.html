K42828444: Loading ASM configuration using a UCS with platform-migrate option hangs

Type
Support Solution
Published
2021-09-22
Updated
2023-02-21
Applies to

  • BIG-IP ASM: 16.0.1, 14.0.X, 13.0.X, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 14.1.3, 14.1.2, 14.1.0, 15.0.X, 14.0.0, 13.1.3, 13.1.1, 13.1.0, 13.0.1, 13.0.0, 16.0.0, 14.0.1
Source

Description

Please consider the recommendation of this article if while loading a UCS with the platform-migrate option, all the configuration loads except for ASM security policies.

Environment

  • ASM is provisioned.
  • Loading a UCS with platform-migrate option.
  • Migrating the ASM configuration to a new platform.

Cause

The observed behavior is due to known ID 995629 and its sibling ID 990849.

Recommended Actions

Upgrade the new platform to a software version where both IDs are fixed [16.1.0, 16.0.1.2, 15.1.3, 14.1.4, 13.1.4.1].

Additional Information

If the platform-migrate option is not used, there is a possible workaround for ID 995629 by running 'load sys config default' to de-provision ASM. The UCS file should then load successfully.
