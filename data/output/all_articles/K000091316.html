Description

While using a Helm chart to deploy NGINX+ Ingress Controller you may encounter the following error message

  Could not get newest config version: could not get expected version: 0 after 0s

Environment

  • NGINX+ Ingress Controller
  • Helm chart deployment

Cause

The "nginxReloadTimeout" attribute in the Helm chart specifies the "Timeout in milliseconds which the Ingress Controller will wait for a successful NGINX reload after a change or at the initial start. (default is 4000. Default is 20000 instead if enable-app-protect is true)"

When this value is set to "0", the ingress controller will fail immediately instead of waiting for NGINX+ to reload the configuration.

 Recommended Actions

Implement one of following two default values for attribute "nginxReloadTimeout":

  • 4000  (when app protect is disabled)
  • 20000  (when app protect is enabled)

If these values need to be modified, please contact support for further guidance.
