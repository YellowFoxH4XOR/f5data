Known Issue

This is the result of a known issue. The bigpipe persist show all command returns the value PERSIST, and does not give persistence connection details.

F5 Networks Product Development tracked this issue as CR85914 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

You can work around this issue by using the bigpipe persist all show command.
