Security Advisory Description

The BIG-IP DNS Configuration utility may erroneously display the Transaction Signature (TSIG) key secret in plain text form.

This issue occurs when all of the following conditions are met:

  • You configure a TSIG key in the BIG-IP DNS system.
  • You use the Configuration utility to view the TSIG key configuration.

Impact

A user with Configuration utility access to the system is able to view the TSIG key secret in plain text.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you click on a TSIG key configuration on the DNS > Delivery > Keys > TSIG Key List page in the Configuration utility, you can view the TSIG key secret in plain text.
