Known Issue

BIG-IP APM session variables may not display correctly.

This issue occurs when all of the following conditions are met:

  • Your system uses a BIG-IP APM access policy configured to display session variable information in a message box or on the logon page.
  • Session variables to be displayed include arrayed session variables. For example, the message syntax may appear similar to the following:

    mac_address = %{session.machine_info.last.net_adapter.list.[0].mac_address}

Impact

The system does not convert the arrayed session variable to the associated value.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H472408 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP APM logon page or message box displays the actual arrayed session variable syntax instead of the expected value of the arrayed session variable.

    Note: An arrayed session variable is distinguished by the use of [<numeric value>] in the variable syntax. For example, the arrayed session variable may appear similar to the following:
    session.machine_info.last.net_adapter.list.[0].mac_address

Workaround

To work around this issue, you can create a custom session Variable Assign value from the arrayed session variable. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Creating and assigning a Variable Assign value

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Access Profiles > Access Profiles Lists.
  3. To open the visual policy editor, click Edit to the right of the access profile name.
  4. Click + to the left of the Logon Page or intended Message box.
  5. Click the Assignment tab.
  6. Click Variable Assign.
  7. Click Add Item.
  8. Click Variable Assign.
  9. Click the change link for rule one.
  10. Select Custom Variable.
  11. In the Custom Variable box, enter syntax similar to the following example to define the name of your new custom variable:

    session.last.usermac
  12. In the Custom Expression box, enter the arrayed session variable text, similar to the following example:

    mcget {session.machine_info.last.net_adapter.list.[0].mac_address}
  13. Click Finished.
  14. Select the affected Message Box or Logon Page box by clicking the name of the box.
  15. Locate the original user arrayed session variable, that appears similar to the following example:

    mac_address = %{session.machine_info.last.net_adapter.list.[0].mac_address}
  16. Replace the arrayed session variable with the newly created custom variable.

    For example:

    mac_address = %{session.last.usermac}
  17. Click Save.
  18. In the upper-left corner of the visual policy editor, click Apply Access Policy.
