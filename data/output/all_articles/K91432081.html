Topic

This article covers the compatibility of the F5 Anti-Fraud Security Operations Center (SOC) Dashboard with BIG-IQ Fraud Protection Service (FPS) module releases.

Description

The F5 Anti-Fraud SOC Dashboard provides a central location for receiving fraud incident alerts from BIG-IP FPS systems, while the BIG-IQ FPS module monitors these alerts on premise at customer sites.

The following table provides a general overview of the supported version and hotfix level between the F5 Anti-Fraud SOC Dashboard and the BIG-IQ FPS module:

3.9.x5.1.0
4.0.x5.2.0
5.1.0 EHF 5, 14, 16
