Known Issue

This is the result of a known issue. If you import user accounts from a text file, and the domain name of a user’s email address contains a hyphen (-) character, FirePass removes the hyphen and all characters to the right of the hyphen from the email address.

Note: You can import user accounts on the Users: User Management page in the FirePass Administrative Console.

For example:

jsmith@mail-1.siterequest.com

If you import a user account with this example email address, FirePass creates the user account email address without the -1.siterequest portion, which appears similar to the following example:

jsmith@mail.com

F5 Networks Product Development tracked this issue as CR92944 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in Hotfix-HF-602-3 issued for FirePass version 6.0.2. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by manually configuring the email addresses for affected user accounts. To configure a user’s email address, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: User Management page.
  3. Click the Edit button next to the user account you want to configure.
  4. In the Email field, enter the user’s correct email address.
  5. Click the Update user details button.
  6. Click the Back to Users: User Management page link at the top right of the page.
  7. Repeat Steps 3 through 6 until all affected user accounts are corrected.
