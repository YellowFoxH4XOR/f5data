Known Issue

The ACCESS::session iRules command may not work for Secure Web Gateway (SWG) IP-based sessions.

This issue occurs when the following condition is met:

  • Your BIG-IP APM system is configured for SWG IP-based sessions.

Impact

The ACCESS::session iRules command does not run for SWG IP-based sessions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ACCESS::session iRules command does not run for SWG IP-based sessions.
