Description

This article aims to describe how to display the RST cause of RST packets from a BIG-IP device. For example:

Frame 555: 260 bytes on wire (2080 bits), 260 bytes captured (2080 bits)
Ethernet II, Src: 00:00:5E:00:53:01 (00:00:5E:00:53:00), Dst: 00:00:5E:00:53:AA (00:00:5E:00:53:AA)
802.1Q Virtual LAN, PRI: 0, DEI: 0, ID: 0
Internet Protocol Version 4, Src: 192.168.1.1, Dst: 10.110.10.10
Transmission Control Protocol, Src Port: 443, Dst Port: 23456, Seq: 1, Ack: 29, Len: 0
F5 Ethernet Trailer Protocol
    F5 Trailer Header - Version: 1
    Low Details
    Medium Details
        F5 Trailer Header, Provider: 1, Type: 2
        Flow ID: 0x0000560e49fddb00
        Peer ID: 0x0000000000000000
        Connflow Flags High Bits: 0x00000000
        Connflow Flags: 0x84908c24
        Flow Type: 0x40
        HA Unit: 0x01

        Priority: 3

Environment

  • BIG-IP
  • tcpdump
  • Wireshark 2.6 or later

Cause

None

Recommended Actions

The following steps will display the RST cause in the packet of a pcap file from the BIG-IP.

  1. Configure the BIG-IP system to include the RST cause information in the TCP RST packet payload. For more details, refer to K13223: Configuring the BIG-IP system to log TCP RST packets.

tmsh modify /sys db tm.rstcause.pkt value enable

  1. Start to capture the packets on the BIG-IP. When capturing the packets on the BIG-IP system, the noise amplitude is nn or nnn (nnn is always recommended). For the details, please refer to K13637: Capturing internal TMM information with tcpdump.

For example:

tcpdump -s 0 -i 0.0:nnnp host <client IP> -w /var/tmp/filename.pcap

  1. From the client, generate the traffic and reproduce the issue where the BIG-IP system sends out RST packets.

  2. Stop the tcpdump command with Ctrl+C.

  3. Download the pcap file to the workstation with Wireshark, you can download the file via an SFTP application (WinSCP or similar).

  4. To display TMM information in Wireshark 2.6.0 and later, navigate to Analyze > Enabled Protocols and search for f5ethtrailer. Click the options to enable the F5 Ethernet trailer. For more details, please refer to K13637: Capturing internal TMM information with tcpdump.

  5. Open the pcap file in Wireshark, locate the RST packet, and review the Medium Details.

  • Note: The packet must be captured on the BIG-IP system, another system will not insert the noise amplitude.
  • Note: The RST cause is included in packets sent from BIG-IP to another device.
