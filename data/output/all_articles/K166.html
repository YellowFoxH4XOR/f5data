Topic

Path data will not display in the Path Statistics page if data has not been collected. This can occur under the following circumstances:

  • You are using a static load balancing method, such as Round Robin.
  • You are using a dynamic load balancing method that does not require the collection of path statistics, such as least connections.
  • Your 3-DNS has recently been restarted, and has not yet accrued statistics.

Load Balancing Method

Path metrics will only be collected and displayed if you are using a dynamic load balancing method that requires the collection of path metrics, such as Round Trip Time (RTT) or Quality of Service (QoS).

Check your configuration to verify the type of load balancing method you have specified for your pools. If you have specified a primary load balancing method that requires the collection of path metrics and the statistics are not being displayed, contact F5 Networks Support for further troubleshooting assistance.

Restarted or new 3-DNS Controller

If the 3-DNS Controller has recently been restarted, it may not display path metrics because the metrics have not been accrued. Upon restart, it takes approximately 30 minutes for statistics to populate.

If the statistics do not populate in approximately 30 minutes of restart, it may indicate that the issue is a probing failure. Troubleshoot the probing failure and, if you do not find a resolution, contact F5 Networks Technical Support for assistance.
