K72405385: Oauth Introspect service may return false responses when queried with refresh tokens.

Type
Support Solution
Published
2025-04-09
Updated
2026-01-09
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.2
Source
https://my.f5.com/manage/s/article/K72405385

Description
Within OAuth deployment, the OAuth server can provide information about tokens through the "Introspect" service.
With BIG-IP APM as the OAuth authorization server, the "Introspect" service is returning "{ "active": false }" when the query is made to a refresh token.

Environment

  • You're using BIG-IP APM;
  • BIG-IP APM is used as OAuth Authorization server and configured with an OAuth profile;
  • You're sending queries to the Introspect service "https://<BIG-IP_APM>/f5-oauth2/v1/introspect" with a refresh token.

Cause
This is due to BUG ID 1000665 - [APM][OAUTH]Introspect service replying "false" with refresh_token.

Recommended Actions

None

Additional Information
Using APM as an OAuth 2.0 Authorization Server
