Description

Following message are noted when navigating Monitoring > DDoS > DNS Overview in BIG-IQ Centralized Management GUI 

Configuration missing
Logging node is not configured for DoS.

 

Environment

  • BIG-IQ Centralized Management
  • BIG-IQ Data Collection Device is already added in the BIG-IQ 

Cause

"DoS Protection" service  is not  activated in  BIG-IQ Data Collection

 

 Recommended Actions

 Activate "DoS Protection" service in BIG-IQ Centralized Management as mentioned below 

 System >> BIG-IQ DATA COLLECTION >> BIG-IQ Data Collection Devices >> Select your DCD >> Services >> Activate DoS Protection.
