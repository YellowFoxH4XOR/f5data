If you are experiencing latency issues with a CIFS volume, you may benefit by enabling the ARX system CIFS path cache feature for affected volumes.

The CIFS path cache feature can alleviate certain latency issues, which are generally issues triggered by high volumes of CIFS protocol QUERY_PATH_INFO commands from clients. If the cache is enabled, the ARX system will cache the results from each back-end query and service repeat client queries from its own cache. Even with low volumes of queries, this behavior reduces latency.

The CIFS path cache feature is disabled by default in the ARX version 2.7.x software branch. You can enable the feature on a given CIFS volume by using the cifs path-cache command. To do so, perform the following procedure:

  1. Log in to the ARX command line.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter global mode by typing the following command:

    global
  4. Specify the namespace in which the volume in question resides by typing the following command:

    namespace ns1
  5. Specify the volume in question by typing the following command:

    volume /vol1
  6. To enable or disable the path cache feature on this volume, type one of the following commands:
    • Enable path-cache:

      cifs path-cache
    • Disable path-cache:

      no cifs path-cache

Enabling or disabling the CIFS path cache feature is non-disruptive; you can safely enable it temporarily as a test. If you must determine whether the CIFS path cache feature may benefit a CIFS latency issue in your environment prior to enabling it, contact F5 Networks Technical Support.

Note: For more information about the cifs path-cache command and related commands, refer to the CLI Reference Guide.
