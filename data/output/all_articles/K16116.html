Topic

Purpose

You should consider using this procedure under the following conditions:

  • You want to modify the maximum number of log file archives retained on the LineRate system.
  • You want to modify the file size at which log files will be rotated.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command line access to the LineRate system.
  • You have knowledge of either the vi or pico text editors.

Description

The LineRate system includes the newsyslog utility for managing log file tasks. The newsyslog utility runs once per hour, and reads the /etc/newsyslog.conf configuration file to determine conditions for managing log files.

For example:

# logfilename          [owner:group]    mode count size when  flags [/pid_file] [sig_num]
/var/log/controller.messages            640  2     10   *     JC     /var/run/syslog.pid

In the previous example, the /var/log/controller.messages log file is set to be rotated whenever it exceeds 10 kilobytes (size), saving no more than two archives (count). When the newsyslog utility runs and finds the current file to exceed the configured size, the current file will be compressed using bzip2 compression, and renamed to controller.messages.0.bz2, while the current controller.messages.0.bz2 file will be renamed to controller.messages.1.bz2 and the current controller.messages.1.bz2 file will be deleted. You can view the /var/log/ directory to confirm this behavior.

For example:

ls -lh /var/log/controller*

-rw-r-----  1 root  wheel    79B Feb 23 11:34 /var/log/controller.messages
-rw-r-----  1 root  wheel   2.9k Feb 23 11:00 /var/log/controller.messages.0.bz2
-rw-r-----  1 root  wheel   2.9k Feb 23 10:00 /var/log/controller.messages.1.bz2

When you change the number of saved archives from a higher number to a lower number, already existing archives beyond the new number of saved archives are not removed from your system. For example, if you currently have 10 saved archives for the /var/log/controller.messages file, numbered controller.messages.0.bz2 through controller.messages.9.bz2, and you change the saved number of archives from 10 to 2, then the already existing controller.messages.2.bz2 through controller.messages.9.bz2 files no longer participate in rotation, but remain on your system until you manually delete them.

Note: The default number of saved archives for the /var/log/controller.messages file is 10, and the default file size rotation is 102,400 kilobytes.

Procedures

Important: If the LineRate system requires upgrading after you perform the following procedure, you need to perform the following procedure again after the upgrade.

Adjust the rotation configuration for log files on the LineRate system

Impact of procedure: The size and count directly affect storage space. Ensure that you monitor diskspace usage after you make changes.

  1. Log in to the LineRate command line.
  2. Switch to the Bash shell, by typing the following command:

    bash

  3. Create a backup of the current /etc/newsyslog.conf file, by typing the following command:

    sudo cp /etc/newsyslog.conf /etc/newsyslog.conf-SOL16116.save

  4. Using either vi or pico, locate the line in the /etc/newsyslog.conf file that corresponds to the log file for which you wish to modify the rotation configuration.

    For example, to modify the rotation configuration for the /var/log/controller.messages file, locate the following line:

    Note: You must use the sudo command when opening your text editor, or else you will not have permissions to save your changes.

    # logfilename          [owner:group]    mode count size   when  flags [/pid_file] [sig_num]
    /var/log/controller.messages            640  10    102400 *     JC     /var/run/syslog.pid

  5. Adjust the filesize (size) and/or saved archives (count) to the desired setting.

    For example, to rotate the /var/log/controller.messages file when it exceeds 200 kilobytes, retaining only two archived copies, the line should appear similar to the following example:

    # logfilename          [owner:group]    mode count size when  flags [/pid_file] [sig_num]
    /var/log/controller.messages            640  2     200  *     JC     /var/run/syslog.pid

  6. Save your changes and exit the text editor.
  7. Optional: Force a rotation of the log files by typing the following command:

    sudo newsyslog

    Note: If you do not perform this step, the newsyslog utility will run at the next normally scheduled interval.

  8. Exit the Bash shell by typing the following command:

    exit
