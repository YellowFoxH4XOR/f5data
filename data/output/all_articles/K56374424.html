Description
Unable to modify the ASM policy on the Virtual Server due to the drop down missing with the text Manual Configuration (Advanced).

Environment

  • ASM virtual server
  • ASM Local Traffic Policy
  • ASM Policy

Cause
This condition happens when an auto generated ASM Local Traffic Policy is modified outside of the ASM Policy.

Recommended Actions
To resolve this issue the ASM Policy must be removed from the Virtual Server using TMSH.

  1. SSH to the BIG-IP
    • If at a (tmos)# prompt run the following command:
      modify ltm virtual <Virtual Server Name> policies none
    • If at a config # prompt run the following command:
      tmsh modify ltm virtual <Virtual Server Name> policies none
  2. Save the configuration:
    • (tmos)# save sys config
    • config # tmsh save sys config
  3. Log into the GUI and navigate to Local Traffic  ››  Virtual Servers : Virtual Server List  ››  Virtual Server verify the drop down is available and the text Manual Configuration (Advanced) is no longer present.
  4. Re-apply the ASM profile if necessary

Additional Information
To view Virtual Servers associated with the ASM Policy go to:

  • BIG-IP 12.x
    Security  ››  Application Security : Security Policies : Active Policies - Virtual Server Column
  • BIG-IP 13.x and later:
    Security  ››  Application Security : Security Policies : Policies List - Click desired security policy
