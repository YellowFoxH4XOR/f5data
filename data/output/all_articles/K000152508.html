Description

  • You are observing "client sent invalid header" error in NGINX Error log.

2025/07/02 06:04:44 [info] 1184148#1184148: *126719 client sent invalid header line: "MY_Example_SERVER"

Environment

  • NGINX Plus
  • "underscores_in_headers" Directive

Cause

  • By default, NGINX does not permit the presence of "underscore" like "MY_Example_SERVER" in HTTP header.

Recommended Actions

  • You can override this default behavior using directive "underscores_in_headers",
  • set directive "underscores_in_headers" in either "http or server block"

Additional Information

  • Example
            # example Server block
                      server {

                          listen       443 ssl;
                          http2 on;
                          server_name  Host $hostname;

                          underscores_in_headers on;
                          large_client_header_buffers 4 16k;


                          ssl_certificate      /etc/nginx/certs/example_ssl-bundle.crt;
                          ssl_certificate_key  /etc/nginx/certs/example_ssl-bundle.key;

                          ...
                        }
