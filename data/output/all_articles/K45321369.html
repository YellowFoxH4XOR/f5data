Topic

You should consider using these procedures under the following conditions:

  • Remote users establish a Remote Desktop Protocol (RDP) session through the BIG-IP APM system and the page is contained within a window.
  • Remote users establish an RDP session through the BIG-IP APM system and, after the user minimizes the window, the Maximize button is disabled and the window cannot be maximized.

Description

Older versions of BIG-IP software, which use ActiveX and Java for establishing RDP connections through the BIG-IP APM system, do not allow the window to be displayed full-screen, or the screen does not allow users to maximize the RDP window after it has been minimized. This article provides options for working around these limitations.

Beginning in BIG-IP APM 13.x, the system includes a full RDP proxy, which negates the conditions of this issue and provides additional support when using RDP.

Important: To open a support case with F5 Support, you must have an active support contract and you must be authorized to open support cases. If you are an end user of an F5 product or client application, such as the Edge Client for IOS, the Edge Client for Android, or the FirePass controller, and you require technical support, contact your system administrator or IT department for assistance. Only authorized contacts can open technical support cases with F5 Support.

Prerequisites

  • You have administrative access to the Configuration utility.

Procedures

When experiencing issues with maximizing the window size after establishing an RDP session, use the following procedures:

  • Using Ctrl+Alt+Break
  • Configuring the screen properties of the RDP resource
  • Modifying Custom Parameters of the RDP resource

Using Ctrl+Alt+Break

By design, the Maximize button in the browser window doesn't perform the action that is expected by most users for RDP connections. The recommended method to display a full-screen window in RDP is to select Ctrl+Alt+Break. This works even for desktops that are not initially in full-screen mode or that display a screen size smaller than the actual user's screen. The Ctrl+Alt+Break keyboard shortcut was introduced by Microsoft to move in and out of full-screen mode.

Note: If your keyboard doesn't have a Break key, there may be a function key (Fn) that gives you access to secondary key functions. For more information, refer to the manufacturer documentation.

Configuring the screen properties of the RDP resource

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access Policy > Application Access > Remote Desktops.
  3. Select the remote desktop resource.
  4. Under Screen Properties, for Window Size, select Percentage of Desktop, and for Percent, enter 100.
  5. Select Update.

Modifying Custom Parameters of the RDP resource

To add RDP custom parameters to remove the Restore Down button from the RDP session, perform the following procedure. This leaves only Minimize and Close.

Impact of procedure Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access Policy > Application Access > Remote Desktops.
  3. Select the remote desktop resource.
  4. Under General Properties, for Custom Parameters, enter the following parameters:
    • showminimizebutton:i:0
    • showrestorebutton:i:0
  5. Select Update.
