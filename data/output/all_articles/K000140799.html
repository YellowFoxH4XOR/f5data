K000140799: AS3 plugin installation fails

Type
Support Solution
Published
2024-09-30
Updated
2024-09-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000140799

Description

Installing an AS3 RPM fails and returns the following errors:

 

If installing the RPM via iApps > Package Management LX, the GUI shows:

 

Package installation failed with error: Task: /mgmt/shared/iapp/package-management-tasks/{UUID} failed to complete, with error message: [0] number of [child_process] shell access traces found in the given iApp RPM directoy

 

Restajavad log error message:

 

[WARNING][28095][25 Aug 2024 23:26:32 UTC][8100/shared/iapp/package-installer-tasks PackageInstallerTaskWorker] Failed to run security scan on /var/config/rest/downloads/f5-appsvcs-{version}.noarch.rpm: java.lang.Exception: Failed to install to /var/config/rest/iapps/f5-appsvcs. Status 1

 

Environment

BIG-IP

AS3 (f5-appsvcs)

Cause

 

Corrupted f5-appsvcs RPM file.

Recommended Actions

 

Get an intact copy from F5's GitHub repository and ensure that the checksum is accurate. Thereafter, upload the RMP into the BIG-IP and re-install the AS3 application.

Additional Information

None.
