Description
When trying to add a device to iQuery mesh using bigip_add you get the following error:
no matching cipher found: client aes128-cbc,aes256-cbc server aes128-ctr,aes192-ctr,aes256-ctr

Environment

Trying to add LTM to DNS iQuery mesh

LTM has a modified SSHD cipher list such as
sys sshd {
 Ciphers aes128-ctr,aes192-ctr,aes256-ctr
}

To see the SSHD list use the following command:
# tmsh list /sys sshd all-properties

Cause
There are no shared SSH ciphers between the DNS (formerly known as GTM) and the LTM 

Recommended Actions

You can temporarily add a shared SSH cipher such as aes128-cbc, aes256-cbc with the command below:
# tmsh modify /sys sshd include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr,aes128-cbc,aes256-cbc"

Now re-run bigip_add again:
# bigip_add <IP>

To revert the changes run the following command:
# tmsh modify /sys sshd include "Ciphers aes128-ctr,aes192-ctr,aes256-ctr"
