Description

  • Your security scanners have identified CVE-2021-41773 on your BIG-IP products.
  • You have Apache Servers running version 2.4.49 that are pool members behind Virtual Servers on your BIG-IP.

Environment

  • BIG-IP Virtual Servers with Pool Members running Apache 2.4.49
  • You have ASM either on the Virtual Server or on an Upstream BIG-IP device that services that Virtual Server.

Cause

CVE-2021-41773

Recommended Actions

  • If you run ASM, there are attack signatures in place to prevent this type of exploitation from affecting your backend Apache Servers running 2.4.49
    • ASM attack signatures to prevent this type of exploitation.
      • These signatures were added by ASM-SignatureFile_20201228_142156.
        • 200007033 Directory Traversal attempt "../" (URI) (%2e.)
        • 200007034 Directory Traversal attempt "../" (URI) (.%2e)
        • 200007035 Directory Traversal attempt "../" (URI) (%2e%2e)
           
  • If you do not run ASM inline or on the BIG-IP with the Virtual Server, it's recommended to upgrade your backend Apache Servers running 2.4.49.
