K000157996: Error 0x3000008 When Using F5 BIG-IP APM with Windows Server 2025 Remote Desktop Gateway

Type
Support Solution
Published
2025-11-27
Updated
2026-01-02
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000157996

Description

After upgrading a Remote Desktop Web (RDWeb) server farm to Windows Server 2025, users attempting to log in and launch RDP sessions through the F5 BIG-IP APM Web Portal may encounter the following error:

  • Error code: 0x3000008
  • Extended error code: 0x0

Log messages may include:

  • "An exception is thrown (TMEVT_EOF): Net:1: Connection was closed"
  • "Failed to handle request ... Bad cast: got AnyRef<N5boost6system10error_codeE> instead of AnyRef<18HttpMessageStarted>"

This issue prevents successful remote desktop connections via the APM portal.

Environment

  • BIG-IP APM, version 17.5.1
  • Remote Desktop Gateway resource configured on APM
  • RDWeb server farm running Windows Server 2025
  • SSL enabled between APM and RDWeb servers

Cause

BIG-IP APM 17.5.1 does not support or recognize RD Gateway connections to Windows Server 2025, as this platform has not been validated for compatibility.

Recommended Actions

  • Use a supported Windows Server version (such as Windows Server 2022) for RDWeb/RD Gateway integration with BIG-IP APM.
  • Monitor F5 release notes and compatibility matrices for future updates regarding Windows Server 2025 support.
  • If error code 0x3000008 occurs after upgrading to Windows Server 2025, revert to a supported Windows Server version to restore functionality.

Addition Information

  • Error code 0x3000008 (extended error code 0x0) is due to unsupported Windows Server 2025 in this configuration.
  • No internal hotfix or workaround is available.
  • Compatibility testing for Windows Server 2025 is planned for a future release.
