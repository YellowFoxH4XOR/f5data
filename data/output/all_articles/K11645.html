K11645: The BIG-IP ASM system logs violations to the /var/log/asm file only when the alarm flag is enabled for a given violation

Topic

On the Blocking Policy screen, you can enable or disable the Learn, Alarm, and Block flags (also known as blocking actions) for violations. The blocking actions determine how the system processes requests that trigger the corresponding violation.

If both the Learn and Alarm flags are disabled for a certain violation, the system does not log requests that trigger the violation to the /var/log/asm file. The system logs these requests to only the Reporting/Requests screen or, if the logging profile for the web application specifies a remote storage type, to the remote server.

This behavior is by design.

Note: If a web application is configured to log requests to a remote server, and both the Learn and Alarm flags are disabled for a certain violation, the system does not log requests that trigger that violation if the remote logging server becomes unavailable or unreachable. You should consider this scenario before disabling both the Learn and Alarm flags.
