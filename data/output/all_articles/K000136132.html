K000136132: Logs about "LOP RTC updated"

Type
Support Solution
Published
2023-09-20
Updated
2023-09-20
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000136132

Description

Customer may notice that there are logs generating with 15 minutes interval in /var/F5/system/log/platform.log
Below is an example:

platform-mgr[<PID>]: priority="Info" version=1.0 msgid=0x104000000000014 msg="LOP RTC updated." diff=28801.

Environment

  • F5OS
  • rSeries

Cause

LOP is short for Lights Out Processor,  RTC stands for "Real Time Clock". This log indicates that the "platform_mgr" component update the hardware clock following the system clock, the software clock maintains at the right time through NTP.

Recommended Actions

Those logs are benign, if customer needs cease such logs, modify the platform-mgr log level  higher than "Info" can do.
For example we can modify it to NOTICE level as below through CONFD.

#system logging sw-components sw-component platform-mgr config severity NOTICE
