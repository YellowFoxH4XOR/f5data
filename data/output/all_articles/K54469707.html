Description

You may find the log below in the log file /var/log/gtm:

err big3d[<PID>]: 012b3003:3: SSL error during shutdown: SSL SSL_ERROR_SSL
err big3d[<PID>]: 012b300e:3: SSL Error: error:1407609C:SSL routines:SSL23_GET_CLIENT_HELLO:http request on connection to ::ffff:<IP address>:<port>.
err big3d[<PID>]: 012b300e:3: SSL Error: error:140890C7:SSL routines:ssl3_get_client_certificate:peer did not return a certificate on connection to ::ffff:<IP address>:<port>.
err big3d[<PID>]: 012b300e:3: SSL Error: error:140760FC:SSL routines:SSL23_GET_CLIENT_HELLO:unknown protocol on connection to ::ffff:<IP address>:<port>.
notice big3d[<PID>]: 012b3008:5: SSL Context Cipher list set to: AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA.
notice big3d[<PID>]: 012b3007:5: SSL Context created using minimum TLS version tlsv1, SSL cipher list 'AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA'.

You may find the log below in the log file /var/log/ltm:

err tmm1[<PID>]: 01220001:3: TCL error: _cgc_pick_clientside <CLIENT_DATA> - unknown cgc sni: dns7.spdbccc.com.cn (line 49)     invoked from within "CGC::sni $tls_servername"

Environment

  • BIG-IP GTM/DNS
  • iQuery

Cause

The iQuery connection require bidirection certificate authentication when SSL handshake.
If SSL handshake / authentication failed, will cause the log like above.

Recommended Actions

When the issue happened, check the source IP address / port, it should not be the BIG-IP DNS/GTM devices.
The port 4353 is for the iQuery connection from other BIG-IP DNS/GTM device, please block the connection from other IP (not BIG-IP DNS/GTM).

  • Apply the L3/L4 firewall policy to the self IP / management IP if with AFM license.

  • Apply the filter on the network firewall.

Additional Information

None.
