Description

When generating a qkview using the BIG-IP's admin GUI, there is often a noticeable delay between when the "qkview was successfully generated" message is displayed and the activation of the "download" button (which allows an admin to download the generated qkview).
This delay becomes greater as the size of the data captured in the qkview gets bigger, eg. when using the "-s 0" option to avoid qkview data truncation.

Environment

  • QKview
  • BIG-IP

Cause

When generating a qkview using the BIG-IP's admin GUI, the "qkview was successfully generated" message is displayed immediately when the commands to capture the qkview info are successfully completed on the box, but the "download" button stays greyed out for the admin until the qkview is gzipped and ready for download (which can take a few minutes, depending on the size of the captured data and logs).

This may lead to the administrator thinking there was a problem with the GUI in the interval after the success message is generated, but before the download button is clickable, if the administrator is not already aware of this behaviour on the BIG-IP's part.
