K91675443: ASM learning is not functioning with error message ''01260025:3: Cipher c02f:5 negotiated is not supported by Proxy SSL configured in virtual server''

Type
Support Solution
Published
2020-11-18
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.2
Source
https://my.f5.com/manage/s/article/K91675443

Description
After configuring ASM policy, ASM is not learning any requests even though learning mode is enabled. There is no learning suggestions or the request logs showing up in the policy. 
When verified the in the LTM police actions successes there is zero actions in the log as shown below. 

# tmsh show ltm policy asm_auto_l7_policy__xxxxx 
------------------------------------------------------
Ltm::Policy: /Common/asm_auto_l7_policy__xxxxx
------------------------------------------------------
Virtual Server Name     N/A

Status
  Actions invoked   :             0
  Actions succeeded :             0

In addition an error message is logged in /var/log/ltm 

err tmm1[18019]: 01260025:3: Cipher c02f:5 negotiated is not supported by Proxy SSL configured in virtual server /Common/xxxxx.

Environment

  • ASM learning
  • Proxy SSL
  • LTM policy
  • SSL decryption

Cause
SSL errors causing decryption could not be executed properly and hence resulting ASM not able to learn the HTTP traffics

Recommended Actions

Disable the SSL proxy in the client and server ssl profile as shown below. 

  1. Verify if the ssl proxy is enabled on Client and Server SSL
    ltm profile client-ssl /Common/xxxxx {
    .....
    .....
    proxy-ssl enabled
    proxy-ssl-passthrough enable
    .....
    .....
    ltm profile server-ssl /Common/xxxxx {
    .....
    .....
    proxy-ssl enabled
    proxy-ssl-passthrough enabled

  2. Disable the client SSL profile
    Local Traffic  ››  Profiles : SSL : Client

  3. Disable the server SSL profile
    Local Traffic  ››  Profiles : SSL : Server

Additional Information
By default SSL proxy is disabled on client and server ssl.
