K000135056: Blank page at Statistics ›› Analytics : HTTP : Overview

Type

Published
2023-06-21
Updated
2023-06-21
Source

Description

Customer can not see any HTTP information in Statistics ›› Analytics : HTTP : Overview even though customer's HTTP web traffic is generating.


Environment

  • AVR
  • HTTP Analytics Profile
  • BIG-IQ


Cause

There is no HTTP analytics Profile configuration for a specific Virtual Server when AVR module is provisioned.
 

Recommended Actions

To configure HTTP Analytics Profile, perform the following procedure:

1. Log in to the Configuration utility.

2. On the Main tab, click Local Traffic  ››  Virtual Servers : Virtual Server List  ››  Select << virtual server name >>

3. Go to Configuration: section  > select "Advanced" from "Basic"

4. Go to HTTP Analytics Profile > select the default "analytics" from None.

Note: Changes you make might take up to 10 minutes to be reflected in the charts.

5. At the bottom of the screen, click Update.

Please wait to confirm it after 10 minutes as mentioned in Note above.
