Known Issue

This is the result of a known issue. When you attempt to run the /usr/local/wa/scripts/wam_add.pl utility to add a BIG-IP WebAccelerator to a symmetric deployment, the utility fails with error messages that appear similar to the following example:

Retrieving central configuration...
ERROR: Failed to retrieve central configuration
ERROR: Exiting

If you attempt to run the /usr/local/wa/scripts/wam_add.pl utility with the debug option (--debug), the utility fails with error messages that appear similar to the following example:

Retrieving central configuration...
DEBUG: wa_configsync_big3d.pl script failed.
ERROR: Failed to retrieve central configuration
ERROR: ---- Start of central error log [<IP address of Central WebAccelerator>] ----
ERROR:
ERROR: ---- End of central error log [<IP address of Central WebAccelerator>] ----
ERROR: Exiting

Note: Running the /usr/local/wa/scripts/wam_add.pl utility is only necessary when you need to perform a one-time manual synchronization during the initial setup for BIG-IP WebAccelerator symmetric deployment. For more information about symmetric deployment, refer to the Using a symmetric deployment section in the Configuration and Maintenance Tasks chapter of the Configuration Guide for the BIG-IP WebAccelerator System.

F5 Product Development tracked this issue as ID 209499 (formerly CR124277) and it was fixed in BIG-IP WebAccelerator version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
