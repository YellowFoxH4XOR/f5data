K10066825: BGP configuration is not loaded after unit reboot when configured from TMSH

Type
Support Solution
Published
2022-07-27
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K10066825

 

Description

BGP configuration is not loaded after unit reboot when configured from TMSH.
Even if you save the config with ‘tmsh save sys config’ bgp process will not load and neigbors will not come up.
imish -e 'show run' command will not output the bgp configuration.

Environment


- BGP is configured via TMSH
- Device comes up as standby - When bigip comes up as active (in standalone or disconnected) then bgp works fine.
- When the device becomes active after having been standby (for whatever reason,including auto-failback ) then the bgp process is re-initialised and works correctly.

 

Cause


ID959521 CIDyR: Enhance process dependencies and interactions for rtconf

 

Recommended Actions


This has not been resolved and there are no fixes/EngHF available.
Perform any re-configuration to trigger configuration update.
For instance, these two commands will trigger a config update and neighbors will come back up.
- tmsh modify net routing bgp testbgp enabled false
- tmsh modify net routing bgp testbgp enabled true

Configuring BGP through TMSH is not developed anymore, F5 recommends using IMI shell.
