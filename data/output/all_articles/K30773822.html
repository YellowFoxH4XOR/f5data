Description
When there are 2 virtual servers, one of which is with *All Ports option while the other has a specific port number, traffic may hit the All Ports virtual server incorrectly.

Environment

  • There are 2 virtual servers with the same destination address.
  • One virtual sever listens on a specific port number and the other listens on all ports.
  • Traffic is received with the destination port number as above.

Cause
This issue is caused by ID 980821.

Recommended Actions

Customers need to upgrade to fixed versions listed in the link above.
