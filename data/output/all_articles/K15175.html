Topic

F5 has recently discovered and corrected a number of issues that affect customers running BIG-IP 11.5.1. F5 recommends that all customers currently running BIG-IP 11.5.1 install the latest cumulative rollup hotfix.

The following tables list the rollup hotfixes released for BIG-IP 11.5.1. The second table lists each hotfix, along with the ID numbers of issues that the corresponding hotfix resolves, and a description of each issue. If an article exists for the issue, the ID number contains a link to a corresponding article.

Note: These rollup hotfixes are cumulative; each hotfix contains all fixes included in the previous hotfixes. For example, HF3 includes all IDs fixed in HF1 and HF2.
