Known Issue

Clients using the Firefox version 9 and later browser may fail to connect to a BIG-IP APM Network Access Webtop or a Full Webtop.

This issue occurs when all of the following conditions are met:

  • The client is using a Firefox version 9 or later browser.
  • The Webtop type is Network Access or Full.
  • The Minimize To Tray option is enabled for the Webtop.

    Note: The Minimize To Tray option is enabled by default.

Impact

Affected users are unable to establish a connection.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Firefox 9 browser stops responding.
  • After about one minute, the browser displays a message that appears similar to the following example:

    The F5 Networks Firepass Host Plugin has crashed.

    Note: The word FirePass in this situation is legacy, and used throughout the BIG-IP APM product. Do not confuse this with the actual FirePass product, which is not affected by this issue.

Workaround

To work around this issue, you can disable the Minimize To Tray option in the affected BIG-IP APM Webtop. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Click Access Policy.
  3. Click Webtops.
  4. From the Webtop List, select the affected Webtop.
  5. Clear the Enabled check box for the Minimize To Tray option.
  6. Click Update.
