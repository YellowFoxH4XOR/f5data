Topic

To allow the UIE to view User Datagram Protocol (UDP) packets the same as tcp_content, you can write a udp_content rule that contains an expression similar to the following example.
 
This rule contains an optional argument that defines the minimum size packet required before trying to match a string:

Note: Syntax such as udp_content(x) will not work.

findstr(udp_content, 'string to search for', 2)

Note: The data you search for must be contained within the first packet.

For more information refer to the iRules chapter in the BIG-IP Reference Guide.
