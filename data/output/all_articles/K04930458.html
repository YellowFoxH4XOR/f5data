Description

Error Message: crit httpd[28010]: pam_ldap(httpd:account): buffer <buffer_size> too small

In this error message, note the following:

  • <buffer_size> is the size in bytes in buffer.

Environment

  • BIG-IP system
  • LDAP authentication
  • Upgrade to BIG-IP 14.1

Cause

Bug ID 755254

Recommended Actions

Configure user accounts with attributes shorter than 255 characters.

None
