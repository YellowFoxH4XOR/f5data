K05903457: Secure mode displayed on LCD for iSeries platform

Type
Support Solution
Published
2021-05-20
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K05903457

Description

The LCD can become erroneously set to secure mode on its own, and you are unable to use the menus on the LCD.
 

Environment

  • BIG-IP
  • iSeries platform
     

Cause

Bug ID 939249
 

Recommended Actions

  1. Follow the suggestion in Bug ID 939249 and run the below commands on CLI: 
    tmsh modify sys db lcd.showmenu value disable
    tmsh modify sys db lcd.showmenu value enable
     
  2. if not resolved by step1, then run below comannd on CLI:
    ipmiutil cmd 00 20 e8 30
     
    1. If this returns 0, it means secure mode not set, then it could be something on the BMC/LCD side.

      Then rebuild mcpd running by below command:
      touch /service/mcpd/forceload; reboot

      If still the same issue, suspect hardware issue, so please run EUD.
       
    2. If this returns 1, it means secure mode still set, then we should run the set LCD secure mode by the bellow command:
      ipmiutil cmd 00 20 e8 31 00
      (secure mode disable)

      Then repeat step 1 to see if this changes anything.
      If step 1 still doesn't clear the secure mode, this also means a possible BMC/LCD issue.

      And Then rebuild mcpd running by below command:
      touch /service/mcpd/forceload; reboot

      If still the same issue, suspect hardware issue, so please run EUD.
