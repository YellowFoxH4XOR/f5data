Description

Generic host and some pool members are automatically going to disable status

Environment

  • DNS
  • GSLB Pool
  • Manual Resume


Cause

With Manual Resume enabled this is expected behavior.

Recommended Actions

Manual Resume will trigger the configuration change from enable to be disabled automatically, If the status of the pool base on the monitoring will change.



1. Go to DNS ›› GSLB : Pools : Pool List 


2. Select each pool and make sure Manual Resume box is uncheck.


3. Change state to Enabled
