Description

  • When applying an ASM Security policy  a warning message appears in the GUI:  Policy configuration applied successfully with several validation errors.
  • Additional details of the warning message can be seen in Security  ››  Application Security : Policy : Audit : Log:
2020-01-12 10:04:16 /Common/ASM-Policy bigip.local 2020-01-12 10:05:22 2020-01-12 10:05:26 admin The following parameters do not have a matching extract
 
The following extracts do not have a matching parameter
 
Global Extraction '0,0,/indexsort'
Global Extraction '1,,3/indexsort'
 

Environment

  • ASM Security policy

Cause

Seen behaviour is caused by a known issue tracked with the bug ID 456674

Recommended Actions

  1. Go to  Security ›› Application Security : Parameters : Extractions
  2. Delete all the Parameter extractions which parameter type value is now "user input alpha numeric"
