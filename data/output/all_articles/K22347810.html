Description
Logrotate not working after upgrading to version 15

Environment

  • BIG-IP
  • Recent upgrade to 15.0.x
  • Previous version was 14.0.x or older. 
     

Cause
Logrotate is not working because crond has failed to start.
Bug ID 813517: The cron daemon not running after upgrade from pre-v14.1.0 versions to 15.0.x

Recommended Actions

Start crond manually with the following commands:
  1. systemctl enable crond
  2. systemctl start crond
Alternative upgrade to a fixed version: BIG-IP V15.1.0
