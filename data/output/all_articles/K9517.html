K9517: The Encrypt Cookies list in a child HTTP profile may not be saved to disk

Source

Known Issue

This is the result of a known issue. If a custom HTTP profile is created using a parent profile that specifies a list of cookies to be encrypted, and the resulting child profile is modified to remove the Encrypt Cookies list, the configuration change is made to the running configuration but it is not saved to disk. As a result, the intended configuration change is only retained until the configuration is reloaded.

F5 Product Development tracked this issue as CR115729 and it was fixed in BIG-IP LTM version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by removing the cookie encryption passphrase when deleting the Encrypt Cookies list from either the CLI or the Configuration utility. To do so, perform one of the following two procedures:

Removing the cookie encryption passphrase when deleting the Encrypt Cookies list from the CLI

To remove the cookie encryption passphrase when deleting the Encrypt Cookies list, perform the following procedure:

  1. Log in to the CLI.
  2. To remove the cookie encryption passphrase, type the following command:

    bigpipe profile http <child_profile_name> encrypt cookies none

  3. To delete the Encrypt Cookies list, type the following command:

    bigpipe profile http <child_profile_name> cookie secret none

  4. Save the configuration by typing the following command:

    bigpipe save

  5. Load the new configuration by typing the following command:

    bigpipe load

Removing the cookie encryption passphrase when deleting the Encrypt Cookies list from the Configuration utility

To remove the cookie encryption passphrase when deleting the Encrypt Cookies list, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Browse to Local Traffic > Profiles.
  3. Click the child profile to edit it.
  4. If the Encrypt Cookies field is not already blank, select the Custom box for Encrypt Cookies, and clear the field.
  5. Select the Custom box for Cookie Encryption Passphrase.
  6. Clear the Cookie Encryption Passphrase and Confirm Cookie Encryption Passphrase text boxes.

    The new configuration is automatically loaded and saved.

Note: In some BIG-IP versions, it is not possible to create a child profile using another custom profile as the parent. For more information, refer to K8556: The Configuration utility does not allow you use a custom profile as the parent for a new custom profile.
