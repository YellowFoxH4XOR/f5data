Description

Publish NGINX configuration fails and the following error message is reported:

<instance>: failed building config payload: policy compilation failed for deployment <deployment_id> due to integration service error: compiler controller error: unexpected end of JSON input

 

The following message may be reported in NMS logs:

LibYAML.c: loadable library and perl binaries are mismatched (got handshake key 0xcd00080, needed 0xeb00080)

Environment

NIM

App Protect

Cause

When the OS that NIM is running on is upgraded, for example from Ubuntu 20.04 (Focal) to Ubuntu 22.04 (Jammy), App Protect is not upgraded to match the new OS distro. This leads to functional incompatibilities such as the LibYAML.c log message reports above. 

Recommended Actions

Upgrade/Reinstall App Protect and nms-nap-compiler
