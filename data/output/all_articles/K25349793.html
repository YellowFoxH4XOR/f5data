Description
A switch connected to BIG-IP indicates a bridge loop. The switch CAM table reports a MAC flapping between a port connected to BIG-IP and another port where the device which owns that MAC address is connected. Traffic may be lost.

A capture may show BIG-IP transmitting packets with a source MAC address of another device on connected VLANs.

Environment

  • BIG-IP LTM
  • L2 Forwarding virtual server
  • Device on local VLAN (eg router or Layer 3 switch) using a single MAC on multiple VLANs

Cause
L2 Forwarding virtual servers do not change the source MAC when forwarding traffic. In certain situations this can cause connected switches to see a MAC address appear on multiple interfaces.

Recommended Actions

Change the L2 Forwarding virtual servers to IP Forwarding.
