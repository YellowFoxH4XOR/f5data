Known Issue

BIG-IP Virtual Edition (VE) may incorrectly report the interface media duplex setting as half duplex, from the Interface Properties page in the Configuration utility.

Impact

You are unable to confirm the current duplex setting of an interface from the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The General Properties may show an Active Duplex setting of half duplex when you navigate to Network > Interfaces and click the interface.

Resolution

Status

F5 Product Development has assigned ID 368993 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

HotfixNoneNone

Workaround

To work around this issue, you can determine the interface settings by running the following command from the BIG-IP command line:

tmsh list net interface

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
