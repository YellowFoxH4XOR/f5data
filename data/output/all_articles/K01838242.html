Description
When viewing from GUI you noticed the memory usage of the BIG-IQ system is high around 85% above
 

Environment

  • BIG-IQ
  • Configuration Utility (GUI)
  • accessing System >> This Device >> Statistics >> Memory Usage
 

Cause
This is by design. This is showing the percentage of memory used by the entire system over a period of time. So values near 100% for this graph are not unusual and don't mean that the device is under memory pressure.

Below is the example of the equation on how the percentage are calculated for the BIG-IQ GUI (GUI showing 84.7%)

# free -m
              total        used        free      shared  buff/cache   available
Mem:          32176       18723        4858         985        8594       11986
total - free = current 32,176 - 4,858 = 27,318
(current / total) x 100 = usage in %

Example of calculation:
(27,318/32,176) x 100 = 84.9%

 

Recommended Actions
To view actual memory usage you can use the command line:

  1. Login to bash
  2. Run below command to show memory usage in Megabytes: 
    # free -m
    Example: 
    # free -m
              total        used        free      shared  buff/cache   available
Mem:          32176       18723        4858         985        8594       11986
Actual memory utilization:
(Used  / total) x 100 = Used in %

Example of calculation:
(18,723 / 32,176) x 100 = 58.18%



Additional Information
F5 recommends that you allocate 8 CPUs and 64 Gb of RAM to your BIG-IQ systems: Manual Chapter : Getting Started with BIG-IQ Virtual Edition
