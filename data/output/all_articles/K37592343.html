K37592343: Getting a warning message when deleting a registration key from BIG-IQ License Pool

Type
Support Solution
Published
2021-06-25
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X, 6.X.X, 5.X.X, 8.X.X
Source
https://my.f5.com/manage/s/article/K37592343

Description

Getting the following warning message when deleting a registration key from BIG-IQ License Pool:

Deleting 1 registration key will invalidate the registration key.
To reactivate the registration key, you must open a support case with F5 to reset it.
Click "OK" to proceed.

Environment

  • BIG-IQ
  • BIG-IP Virtual Edition
  • Pool License

Cause

Base Registration key has already been used and requires an Allow-Move.

Recommended Actions

Contact F5 Technical Support and request for Allow-Move.

Note: After the Allow-Move process, please wait fifteen (15) minutes before attempting to activate the license again. 
 

Additional Information
None
