K000092492: Using L7 DOS policy Switching on F5 DDoS Hybrid Defender

Type
Support Solution
Published
2022-10-22
Updated
2022-11-04
Source
https://my.f5.com/manage/s/article/K000092492

Description

Ability to configure L7 DoS policy switching on the DDoS Hybrid Defender platform

Environment

  • Hybrid Defender
  • 1 or more L7 Dos profiles
  • Virtual Server configured on system.
  • Local traffic policy to apply L7 Dos profiles based on requested URI.

Cause

By design.

Recommended Actions

Depending on how the Hybrid Defender is deployed you may be able to use a local traffic policy to deploy separate L7 DoS profiles on incoming HTTP Requests.

Additional Information

To use L7 DoS Profile switching you will have to use the advanced menu option and the virtual server needs to be configured on the device. Once the virtual server has been added to the configuration and you have created 2 or more L7 DoS profiles, you can create a local traffic profile to apply a different L7 DoS profile to specific requests based on the chosen condition, like URL.

Although it can be done using the DDoS Hybrid Defender platform, you should perform this on the BIG-IP ASM/Adv. WAF whenever possible.
