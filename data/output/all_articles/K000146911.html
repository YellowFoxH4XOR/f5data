K000146911: How to update / edit client secret or application ID Azure SSO configuration

What Happened?

  • I'm unable to edit or update Azure SSO access in the F5 XC console.

Environment

  • F5® Distributed Cloud Console
  • XC API

Resolution/Answer

  • To update or edit the configuration on the F5 Console, you can delete your SSO configuration and set up a new one. Retain the Azure App that you’ve already set up for Single Sign-On (SSO). You just need to update the Client Secret or Application ID, and it should function as expected.
  • Alternatively, you don't have to delete your SSO configuration if you utilize XC API as shown below.
    1. Obtain SSO configuration information with the following API call. Substitute your tenant name and API token value (or variable name if you've defined a variable locally). 
      • curl -X GET 'https://<tenant>.console.ves.volterra.io/api/web/custom/namespaces/system/oidc_providers/azure-oidc' -H "Authorization: APIToken $APIToken"
    2. Update SSO configuration, including client secret, with the following API call and corresponding JSON data (obtained from the response of the previous API call). Substitute your tenant name and API token value (or variable name if you've defined a variable locally). 
      • curl -v -X POST 'https://<tenant>.console.ves.volterra.io/api/web/custom/namespaces/system/oidc_providers/azure-oidc' -H "Authorization: APIToken $APIToken" -d@json_data.json
      • {
  "name": "azure-oidc",
  "namespace": "system",
  "spec": {
    "provider_type": "AZURE",
    "azure_oidc_spec_type": {
      "client_id": "<client_id>",
      "client_secret": "<client_secret>",
      "authorization_url": "<auth_url>",
      "token_url": "<token_url>",
      "logout_url": "<logout_url>",
      "user_info_url": "user_info_url",
      "issuer": "<issuer>",
      "jwks_url": "",
      "default_scopes": "",
      "prompt": "<prompt>"
    }
  }
}

Cause

  • Editing the configuration in the console is not possible. It must be done via XC API.
