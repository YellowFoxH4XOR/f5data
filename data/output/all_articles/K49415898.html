Issue

Error Message

err mcpd[<PID>]: 01070972:3: The specified route domain ID <route-domain ID> is not between 1 and 65534, inclusive.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <route-domain ID> is the unique numerical identifier for a route domain.

For example:

err mcpd[9150]: 01070972:3: The specified route domain ID (65535) is not between 1 and 65534, inclusive

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The TMOS Shell (tmsh) command line

Description

This message occurs when the following conditions is met:

  • You attempt to configure a route domain in which the route domain ID falls outside of the allowable range.

Note: The maximum number of configurable route domains is 65,534 on BIG-IP platforms. The BIG-IP system includes a default route domain with an ID of 0 (zero). If you do not explicitly create any route domains, all routes on the system pertain to route domain 0. A route domain ID must be unique on the BIG-IP system; no two route domains on the system can have the same ID.

Impact

There is no impact. This message is informational.

Recommended Actions

None
