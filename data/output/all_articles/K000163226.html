K000163226: Cannot create UDP VS via GUI

Type
Support Solution
Published
2026-10-01
Updated
2026-10-01
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163226

Description

You are able to create UDP Virtual Server (VS) via TMSH, but there is no such option available in BIG-IP GUI.

Environment

BIG-IP v17.5.1

Cause

A BIG-IP does not have LTM licensed.

Answer/Recommended Actions

Get LTM license and license the BIG-IP.
