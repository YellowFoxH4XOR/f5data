K11347034: tar xf warning message tar: var/tmp/gtm_tmp/big3d/client.crt: implausibly old time stamp

Type
Support Solution
Published
2021-06-04
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K11347034

Description

When extracting UCS file with the tar command you may observe a warning message "implausibly old time stamp"

Example:

tar -xzf my_bigip_backup.ucs
tar: var/tmp/gtm_tmp/big3d/client.crt: implausibly old time stamp 1969-12-31 16:00:00

Environment

  • Extracting UCS file.

Cause

Depending on active modules, the configuration might contain some default files that have not been used which will have an old timestamp.

Recommended Actions

No action is required, the UCS file will be extracted, and the warning message can be ignored.

Additional Information

None
