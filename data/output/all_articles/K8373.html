Known Issue

This is the result of a known issue. When the Enterprise Manager system collects configuration data from a BIG-IP LTM system enabled with FIPS, the status will be displayed as Impaired. The Enterprise Manager system's request for configuration information fails because it cannot export the FIPS keys. As a result, the Enterprise Manager will display the device as Impaired to indicate that the configuration data is not current. The Enterprise Manager will also log an error message similar to the following example:

[07f10bb0] Device uid 53 failed to update xconfig information: get change control info: iControl error: 'iControl::OperationFailed - primary code:2(0x2) secondary code: 0(0x0) string: Key management error: Cannot export FIPS-based keys'

Note: The Enterprise Manager system can still perform management tasks on the impaired device.

F5 Networks Product Development tracked this issue as CR86517 and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix HF1 issued for BIG-IP version 9.4.3. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
