K6629: Connections to a BIG-IP ASM virtual server with SNAT disabled in the pool will fail

Known Issue

This is the result of a known issue. A BIG-IP ASM virtual server using a pool with SNAT disabled will use a source address of 127.1.1.1 to make connections to the pool members. Because the loopback IP address is not routable, connections through the virtual server will fail.

F5 Product Development tracked this issue as CR69311 and it was fixed in BIG-IP ASM 9.2.4. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

If upgrading is not an immediate option, you can work around this issue by creating a separate pool with SNAT enabled for use by the BIG-IP ASM-enabled virtual server.
