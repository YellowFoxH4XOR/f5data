Known Issue

This is the result of a known issue. The entries for the ipv6-crypt or ipv6-auth protocols were inadvertently removed from the default /etc/protocols file in BIG-IP version 10.1.0. If a BIG-IP configuration contains virtual server objects that reference the ipv6-crypt or ipv6-auth protocols by name, attempts to load the configuration fail with an error message that appears similar to the following example:

BIGpipe parsing error (/config/bigip.conf Line 747):
012e0010:3: The requested value (ipv6-crypt }) is invalid (<protocol>) for 'ip protocol' in 'virtual'

By default, the BIG-IP system uses the /etc/protocols file to translate protocol numbers to their corresponding protocol names when saving virtual server definitions to the bigip.conf configuration file, and to translate the protocol names in the bigip.conf file to their corresponding protocol numbers when loading the configuration. In version 10.1.0, the /etc/protocols file was updated and the following protocols were removed:

ipv6-crypt 50 IPv6-Crypt # Encryption Header for IPv6
ipv6-auth 51 IPv6-Auth # Authentication Header for IPv6

As a result, the BIG-IP system is no longer able to load configurations that reference these protocol names.

For example, the following configuration is valid in BIG-IP version 10.0.1, but the configuration fails to load after upgrading the system to version 10.1.0:

virtual VS_default_ipsec {
mirror enable
snat automap
pool Pool_Colt_First
destination any:any
mask 0.0.0.0
ip protocol ipv6-crypt
rules iRule_SNAT_VPN
vlans VLAN_INTERNE enable
}

F5 Product Development is tracking this issue as ID 224435.

Workaround

You can work around this issue by adding the missing entries back into the /etc/protocols file. To do so, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Back up the /etc/protocols file by typing the following command:

    cp /etc/protocols /etc/protocols.SOL11296
  3. Open the /etc/protocols file in a text editor.
  4. Add the following lines to the bottom of the file:

    ipv6-crypt 50 IPv6-Crypt # Encryption Header for IPv6
    ipv6-auth 51 IPv6-Auth # Authentication Header for IPv6
  5. Save the file and exit the editor.
  6. Load the configuration by typing following command:

    bigpipe load
