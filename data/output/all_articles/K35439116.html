Known Issue

When you create a custom SNMP management information base (MIB) by using Tool Command Language (Tcl) scripts or other methods, snmpwalk fails to access the created MIB data.

This issue occurs when all of the following conditions are met:

  • You create custom SNMP MIB files.
  • The created MIB requires access to tmstat data.

Impact

The SNMP MIB does not function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are denied access to the custom MIB.
  • In the /var/log/snmp.log file, you observe an error message similar to the following example:

    /var/log/snmpd.log tcl callback tmctl_test return string: tmctl: tmstat_open_read: open: /var/tmstat/cluster/blade0-performance: Permission denied
    tmctl: tmstat_open_read: open: /var/tmstat/cluster/blade0-public: Permission denied
    tmctl: memory_usage_stat: No such table.
