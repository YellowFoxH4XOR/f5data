Known Issue

BIG-IP ASM XML content may trigger a false positive violation.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM security policy is configured to validate that the XML data complies with schema or a WSDL document.
  • The XML content processed by the security policy contains the href tag.

    Following is an example of XML content:

    <CaptureVAppParams
    name="api-vm-template-test"
    xmlns="http://www.vmware.com/vcloud/v1.5"
    xmlns:xsd="http://www.w3.org/2001/XMLSchema"
    xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
    <Description>Created by vcloud-vm-api-test</Description>
    <Source href="https://test.example.com/api/vApp/vapp-00041274-10c3-39nm-a2bc-f5"/>
    </CaptureVAppParams>

Impact

A violation is triggered.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the BIG-IP ASM system validates XML content that contains an href tag, the following violation is triggered.

    XML data does not comply with schema or WSDL document

  • When the BIG-IP ASM security policy is configured to block on the violation, the system blocks the content and displays an error message similar to the following example:

    The requested URL was rejected. Please consult with your administrator.
    Your support ID is: <numeric value>
