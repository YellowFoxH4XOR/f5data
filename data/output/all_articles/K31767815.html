Description

After upgrade to 15.1.x or higher software version, status of named service is no longer displayed in TMOS.

tmsh show /sys service | grep named
 

Environment

  • LTM
  • GTM
  • CLI
  • named

Cause

named service was moved to systemctl after 15.1.x
 

Recommended Actions

1. Current status of named service can be checked using systemctl and bigstart commands.

2. Use the following command to check if named is active and running.

# systemctl is-active named
active

# bigstart status named
named (pid  16792) is running...

3. Use the following command to check named status. 

# systemctl status named
 

Additional Information

It is impossible to stop named service during booting process. Following command will result in error message:

 # bigstart remove named
 service named does not support chkconfig
