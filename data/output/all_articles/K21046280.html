K21046280: F5 SSL Orchestrator do not support Active/Active mode in High Availability configuration

Type
Support Solution
Published
2019-09-18
Updated
2023-02-21
Applies to

  • F5 SSL Orchestrator: 15.X.X, 15.1.X, 15.0.X, 14.1.X, 14.0.X, 15.1.1, 15.1.0, 14.X.X, 14.1.4, 14.1.2, 14.1.0, 14.0.0, 15.0.0
Source
https://my.f5.com/manage/s/article/K21046280

Description

F5 SSL Orchestrator do not support Active/Active mode in High Availability (HA) configuration.

Environment

  • HA pair with Active/Active setup.

Cause

It is not supported by design.

Recommended Actions

None

Additional Information

F5 SSL Orchestrator supports only Active/Standby mode in HA configuration.
