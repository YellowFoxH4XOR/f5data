Known Issue

This is the result of a known issue. When a user launches a Citrix MetaFrame Browser favorite or a Citrix MetaFrame Portal favorite, and the Citrix server responds with UTF-16LE or UTF-16BE encoding, the favorite fails to connect to the Citrix server. Additionally, the FirePass webtop displays an error message similar to the following example, where <host> is the hostname or IP address of the Citrix server:

Can't connect to <host> (XML Parser error: Can’t read response from <host>)

Note: Citrix MetaFrame Browser favorites and Citrix MetaFrame Portal favorites are configured on the Application Access : Terminal Servers : Resources page.

Note: For FirePass version 6.0.1, this issue only occurs after installing cumulative hotfix HF-601-11. For FirePass version 6.0.2, this issue only occurs after installing cumulative hotfix HF-602-4 or a later version of the cumulative hotfix.

F5 Product Development tracked this issue as CR111487 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-601-12 has been issued for FirePass version 6.0.1 and cumulative hotfix HF-603-1 has been issued for FirePass version 6.0.3. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
