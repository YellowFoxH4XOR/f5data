Description

  • Renewing certificates is not possible due to, option not valid
  • From the Configuration utility, you navigate to System -> Certificate Management: Traffic Certificate :SSL Certificate list <CERT_NAME> 
  • Under General Properties, the Certificate Subject(s) field shows "No certificate"
  • However, the files do exist in the Big-IP filestore. Refer to the following sections for details.

Cause

While certificate and key were first created, they were set with prefix asterisk sign ('*') , in the Certificate and Key names.
Bug ID 1017909: Cannot use the GUI to view details on certificates with names containing asterisk, backslash, or square braces

Recommended Actions

As a workaround, use the CLI to re-generate the files:
  1. Locate the certificate and key file from the filestore
  2. With those create PKCS via openssl with new name (not including  '*' sign)
  3. Import it back to the unit
  4. Certificate looks OK, With Key
  5. And from it you may create a CSR.
