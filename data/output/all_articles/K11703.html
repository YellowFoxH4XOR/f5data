Beginning in ARX version 5.1.0, the ARX system was qualified to interoperate with Data Domain Storage Systems. For information about deploying the ARX with Data Domain, refer to Deploying the F5 ARX with Data Domain Storage Systems.

For the ARX system to interoperate with the Data Domain system, the following items are required on the Data Domain system:

  • Data Domain Operating System is 4.7.3.0 or newer
  • The F5 cifs option available on the Data Domain Operating System (DDOS) must be set
    • Configure required cifs options
    • Map the ARX proxy user to the required admin group for Backup-Operator privileges F5 Proxy User

Verifying whether the version of the Data Domain Operating System is 4.7.3.0 or newer

  1. Log in to the Data Domain system's command line.
  2. Type the following command:

    system show version

    The output of the command will appear similar to the following example:

    Data Domain OS 4.8.0.3-165828

Setting the F5 cifs option available on the Data Domain system

Setting the F5 cifs option on the Data Domain system will configure required cifs options and map the ARX proxy user to the required admin group for Backup-Operator privileges. To do so, perform the following procedure:

  1. Log in to the Data Domain system's command line.
  2. To set the F5 cifs option on the Data Domain system, use the following command syntax:

    cifs option set F5 <Domain>\<Proxy_User>
  3. To verify the F5 cifs option command has been run on the Data Domain system, type the following command:

    cifs option show

    The output will appear similar to the following example:

    Note: The bold entries (equivalent to lines 2, 3, 4, 5, 8, 9, and 10 out of the 12 lines in the example) are typical options when the F5 cifs options have been set:

    Currently Set Options:
            "dd admin group2" is set to "Data Domain"
            "ddkeepalivetimeout" is set to "600"
            "ddusereaddirplus" is set to "yes"
            "deadtime" is set to "5"
            "hide dot files" is set to "no"
            "idmap-type" is set to "rid"
            "loglevel" is set to "1"
            "F5 Max Snapshot Name Length" is set to "74"
            "F5 Proxy User 1" is set to "ARX\dduser01"
            "NFS_PORTMAPPER_MASK" is set to "0xD"
            "ntfs-acls" is set to "enabled"
            "allowtrusteddomains" is set to "enabled"
  4. To verify the proxy user has been mapped to the admin group with Backup-Operator privileges, use the following command syntax:

    cifs troubleshooting user <Domain>\\<Proxy_User>

    For example, if the AD domain was ARX and the proxy user was dduser01, type the following command:

    cifs troubleshooting user arx\\dduser01

    The output of the command will appear similar to the following example:

    --------------------   -----------------------------------------------
    User                   ARX\dduser01
    User ID                22221
    SID                    S-1-5-21-963282670-1504238241-3703757627-12221
    Group                  CSE-DD690\admin
    Group ID               50
    id                     uid=22221(ARX\dduser01) group=50(CSE-DD690\admin) groups=50(admin), 10513(ARX\domain users), 23363(ARX\data domain), 60001821(CSE-DD690\dd_admin_group2), 60000551(BUILTIN\Backup Operators)
    --------------------   -----------------------------------------------
  5. Verify the groups=50(admin) mapping has been set.
