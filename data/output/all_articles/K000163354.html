K000163354: Intermittent Connectivity After an F5OS Host Upgrade

Source

Description

Intermittent connections reported after an F5OS host upgrade when PVA acceleration is enabled on the associated FastL4 profile on tenant under the upgraded F5OS host.

Environment

  • F5OS-A (r5000, r10000 and r12000) and F5OS-C
  • Upgrade to F5OS v2.0.0, F5OS v2.0.0-HR1, F5OS v2.0.0-HR2
  • F5OS host with PVA-accelerated traffic
  • BIG-IP virtual server using a FastL4 profile
  • FastL4 profile configured with pva-acceleration set to full on Tenant under the upgraded F5OS host

Cause

Bug ID 2502185: Long-lived ePVA connections timeout on F5OS tenants

Answer/Recommended Actions

As a workaround, disable PVA acceleration on the affected FastL4 profile:

  • Identify the virtual server and its assigned FastL4 profile.
  • Check whether pva-acceleration is set to full, either directly or through profile inheritance.
  • Set pva-acceleration to none.
  • Apply the configuration.
  • Monitor the connections for stability.
