K000163354: Intermittent VPN Connectivity After an F5OS Host Upgrade

Type
Support Solution
Published
2026-09-21
Updated
2026-09-21
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000163354

Description

VPN and secure tunnel connections intermittently disconnect and reconnect after an F5OS host upgrade when PVA acceleration is enabled on the associated FastL4 profile.

Environment

  • F5OS host with PVA-accelerated traffic
  • BIG-IP virtual server using a FastL4 profile
  • FastL4 profile configured with pva-acceleration set to full

Cause

ID 2502185

Answer/Recommended Actions

As a workaround, disable PVA acceleration on the affected FastL4 profile:


Identify the virtual server and its assigned FastL4 profile.

Check whether pva-acceleration is set to full, either directly or through profile inheritance.

Set pva-acceleration to none.

Apply the configuration.

Monitor the VPN and secure tunnel connections for stability.


At this point, ID 2502185 is still being worked on, and no other restoration method exists.
