K000138247: Signing algorithms supported in SAML IdP connectors

Type
Support Solution
Published
2024-01-16
Updated
2024-01-24
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.X, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000138247

Description

You are setting up an IdP connector and would like to require that the SAML SP sign the assertion request before sending it to the IdP, you want to know which Signing Algorithms are supported.

 

Environment

BIG-IP as SP

IdP connector with Signing Algorithm

Cause

none

Recommended Actions

The following Signing Algorithms are supported:

  • RSA-SHA1
  • RSA-SHA256
  • RSA-SHA384
  • RSA-SHA512

Additional Information

Please note that the use of Hardware Security Modules (HSM) for signing and encryption in SAML is currently not supported. This limitation is under review for future improvements.
