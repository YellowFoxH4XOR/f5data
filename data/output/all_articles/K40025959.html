Description

The following output indicate that FIPS is not initialised on the BIG-IP platform:

# show sys crypto fips
-------------------------------------------
FIPS 140 Hardware Device
-------------------------------------------
Attempt to open FIPS 140 subsystem failed.

# create sys crypto key testkey security-type fips
Key management library returned bad status: -15, System does not support FIPS option
 

Environment

  • BIG-IP
  • FIPS Platform

Cause

These messages indicate that BIG-IP is unable to communicate with the FIPS card and requires initialisation.
This can occur if a UCS archive is loaded after FIPS initialisation had taken place.

Recommended Actions

Re-initialise FIPS as per the Manual Chapter: Hardware HSM Setup and Administration
 

Additional Information

Data is stored in the BIG-IP configuration during the initialisation process.
This is needed in order for BIG-IP to communicate with the FIPS card.
