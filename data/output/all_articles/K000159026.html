Description

To upload F5OS controller or partition images packaged in a tar file format to a VELOS chassis, you can use SCP to copy the tar file and then extract it directly on the controller.

Environment

  • Velos
  • Software Upgrade from CLI

Cause

You are having issue uploading the .iso or .tar files through GUI.

Recommended Actions

Important: F5 strongly discourages the use of the root user account to perform image uploads to the VELOS chassis. F5 strongly recommends using either the VELOS chassis webUI or the REST API to upload images to the VELOS chassis. For information about using REST API to upload images to the VELOS chassis, refer to K000139146: Upload a file to the VELOS or rSeries system using REST API.

Procedure to Upload and Extract the tar file:

  1. Use SCP to copy the tar file to /var/import/staging on the active controller:
    'scp <tar_filename> root@<Floating_IP_of_Controller>:/var/import/staging'.
  2. SSH to the active controller as root and extract the tar file:
    'tar -xf <tar_filename> --strip-components=1'.
    The --strip-components=1 option extracts the files directly into /var/import/staging without creating subdirectories.
  3. After extraction, the verification process will start automatically. The images will be available after a few minutes once verification completes. You can verify the availability of the images through GUI: Navigate to Software Management > Controller Images or Partition Images or CLI using F5OS command 'show images'.

Additional Information

  • Both controllers need to have ready status for controller/partition images before you can install them. Replication from Active Controller to Standby Controller might take time.
  • If the status is "verifying", the process is still in progress.
  • If the status is "Signature verification failed", it can be due to file name corruption or corruption of the ISO file. Please check the file integrity using MD5 or SHA512 checksums.
