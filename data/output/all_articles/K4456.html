Known Issue

Note: Only BIG-IP 3400 systems with a Revision G BIOS are affected by this issue. A list of serial numbers that were manufactured with the affected BIOS is included at the end of this article. F5 provided all affected customers with a BIOS update kit.

This is the result of a known issue. Some BIG-IP 3400 switch platforms contain a Revision G BIOS. When this BIOS is in use, the system's PCI bus may hang, which will trigger a system reboot.

Determining the BIOS version

To view the version of BIOS that is running on your BIG-IP 3400 switch, type the following command:

dd bs=65k count=10 skip=15 </dev/mem|strings|grep REV

This command should return output similar to the following example:

10+0 records in
10+0 records out
TYAN S2707 Motherboard v1.05a 0227041730 OBJ-0075-00 REV. F

In this example, the BIOS version is Revision F (REV. F), which is not affected. If your system reports REV. G, install the BIOS update kit that you received from F5.

If your system reports REV. G and the serial number is not included in the list of serial numbers below, contact F5 Technical Support to obtain the BIOS update kit.
