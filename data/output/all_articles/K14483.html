Known Issue

The ARX system will hold Windows 7 SMB2 connections to the ARX root directory open indefinitely. As a result the ARX NSM is unable to detect if Windows 7 clients are idle. The constant open connections to the windows 7 clients may lead to excessive resource consumption and exhaustion.

Impact

Excessive ARX system resources are used and may impact overall performance.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Client SMB requests are taking longer than expected.
  • The ARX system will never idle-disconnect the client, and will keep directories open indefinitely.

Workaround

To work around this issue, you can disable SMBv2 on the ARX CIFS service or on the clients. To do so, perform one of the following procedures:

Disabling SMB2 on the ARX

Impact of workaround: Features of SMB2 will not be available to all users of the VIP.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter global mode by typing the following command:

    global
  4. Enter the cifs configuration mode using the following command syntax:

    cifs [CIFS service name]
  5. Disable SMB2 for the ARX cifs service using the following command:

    no smb2-allowed

Disabling SMB2 on the Windows 7 Clients

Impact of workaround: Features of SMB2 will not be available to the disabled clients.

For more information about changing the SMB settings on Windows 7 clients, refer to the following Microsoft document. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://support.microsoft.com/kb/2696547
