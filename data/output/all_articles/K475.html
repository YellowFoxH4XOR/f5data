Topic

You can configure rules for BIG-IP to use the HTTP header information to make load balancing decisions.

For specific instructions about how to configure rules on BIG-IP, refer to the following resources:

  • For BIG-IP versions 4.5 through 4.6.4, refer to the iRules chapter of the BIG-IP Reference Guide.
  • For BIG-IP versions 3.1.1 through 4.3, refer to K770: Overview of BIG-IP rules.
