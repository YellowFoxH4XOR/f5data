Known Issue

Users authenticating with Remote Authentication Dial-in User Service (RADIUS) may be locked out of the BIG-IQ system when the RADIUS server is unavailable.

This issue occurs when all of the following conditions are met:

  • Your BIG-IQ configuration uses a remote RADIUS server to authenticate users.
  • Your BIG-IQ system cannot connect to the remote RADIUS server.
  • A user experiences five failed login attempts due to the RADIUS server being unavailable.

Impact

Affected users cannot access the BIG-IQ system for 30 minutes.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to log in, your BIG-IQ system displays a message similar to the following example:

    All radius servers are unavailable

  • After five failed login attempts, your BIG-IQ system displays a message similar to the following example:

    Maximum number of login attempts exceeded.

  • You cannot log in for 30 minutes.

Workaround

To work around this issue, you can unlock the user account by restarting the restjavad process. To do so, perform the following procedure:

Impact of procedure: Restarting the restjavad process briefly interrupts BIG-IQ services to all managed devices.

  1. Log in to the Advanced Shell (bash).
  2. Restart the restjavad process by typing the following command:

    bigstart restart restjavad
