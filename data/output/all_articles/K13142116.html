Topic

This article discusses the limitations of using Classless Inter-Domain Routing (CIDR) notation for the self IP name when creating a self IP address in the Configuration utility.

Description

CIDR notation is made up of an IP address followed by a forward slash character ( / ) and its network mask represented in decimal form.

For example 192.168.10.10/24.

When you attempt to create a self IP address using a CIDR notation as the name in the Configuration utility, such as 192.168.10.10/24, the Configuration utility does not create the self IP and reports an error message that appears similar to the following example:

01070734:3: Configuration error: Can't associate (/Common/192.168.10.10/24) with folder (/Common/192.168.10.10) folder does not exist

This behavior occurs because the Configuration utility is unable to accept self IP address names containing forward slashes. This is an expected behavior.

If you want to use the CIDR notation as the self IP address name in the Configuration utility, you can use an underscore character ( _ ) instead of a forward slash.

The Configuration utility automatically replaces the underscore with a forward slash when displaying the self IP address. Using the previous example, you can create a self IP address using 192.168.10.10_24 as the name.The Configuration utility creates and displays the self IP address as 192.168.10.10/24.

Prerequisites

You must meet the following prerequisite to using these procedures:

  • You have administrative access to the Configuration utility or the TMOS Shell (tmsh).

Procedures

  • Creating a self IP address using the Configuration utility
  • Creating a self IP address using tmsh

Creating a self IP address using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Self IPs.
  3. Click Create.
  4. For Name, type a CIDR name for the self IP address.

    For example, create the self IP 192.168.10.10/24 with the self IP name 192.168.10.10_24.

  5. For IP Address, type an address.

    Note: This IP address should represent the address space of the VLAN that you specify with the VLAN/Tunnel setting.

  6. For Netmask, type the full network mask for the specified IP address.
  7. For VLAN/Tunnel, click the VLAN to associate with this self IP address.
  8. For Port Lockdown use the appropriate settings.
  9. For Traffic Group, retain the default value or click a traffic group.
  10. Click Finished.

Creating a self IP address using tmsh

Impact of procedure: Performing the following procedure should not have a negative impact on your system..

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To create the self-ip with a CIDR name, use the following command syntax:

    create /net self < CIDR name > address < IP address/netmask>  vlan < vlan name>  allow-service <Port lock down settings>  traffic-group <traffic-group >

    For example, to create a self-IP address with the CIDR name 192.168.10.10/24:, type the following command:

    create /net self 192.168.10.10/24 address 192.168.10.10/24vlan internal allow-service default traffic-group traffic-group-local-only

  3. To save the configuration changes, type the following command:

    save /sys config partitions all

    Note: When you attempt to create a self IP address, tmsh accepts self IP names that contain either a forward (/) slash or underscore (_).
