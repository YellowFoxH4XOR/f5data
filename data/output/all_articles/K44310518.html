Description

The BIG-IP drops traffic matching a disabled Virtual Server even when a less specific Virtual Server is available to process traffic.

Environment

  • Traffic matching different virtual servers with different precedence
  • Multiple Virtual Servers configured with overlapping ranges

Cause

By default, the BIG-IP won't "continue matching" less specific Virtual Servers if the more specific one is disabled.

Recommended Actions

  • Even though F5 Support doesn't recommend this configuration, if you want to allow less specific virtual servers to process traffic when the more specific one is disabled/down, use the command below to allow that:
    • tmsh modify sys db tm.continuematching value true
  • To roll back, use the command below:
    • tmsh modify sys db tm.continuematching value false
  • To verify the current value, run the command below:
    • tmsh list sys db tm.continuematching 

Additional Information

For more information about tm.continuematching, refer to the following article:
  •  K8009: Overview of the 'tm.continuematching' database variable
