Known Issue

Synchronization may fail after you delete a rewrite profile.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as a member in a synchronization device group.
  • The device group is configured with Full Sync enabled.
  • You deleted a BIG-IP APM rewrite profile using the Configuration utility or the Traffic Management Shell (tmsh).
  • You attempt to synchronize the configuration to the device group.

Impact

The synchronization to the device group fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H518382 on the Diagnostics > Identified > Low page.
  • When you attempt to synchronize the BIG-IP APM configuration to peer members of the device group, you observe an error message similar to the following example:

    Sync error on <device group peer member name>: Load failed from <device group initiating member name>: Caught configuration exception (0), Values (<rewrite profile dependent object name>) specified for rewrite rules URI (<rewrite dependent object name> <uri name>_<numeric value>): foreign key index (<dependent object name>) do not point at an item that exists in the database.

  • When you attempt to synchronize the BIG-IP APM configuration to peer members of the device group, you observe, in the /var/log/apm file, an error message similar to the following example:

    err mcpd[6817]: 01070712:3: Caught configuration exception (0), Values (/<partition>/<rewrite profile name>) specified for rewrite rules URI (/<partition>/<rewrite profile name> <rewrite rule): foreign key index (rewrite_rules_uri_fk) do not point at an item that exists in the database.

Workaround

To work around this issue, you can manually address the configuration mismatch of the affected device before synchronizing to the device group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To save the running configuration, type the following command:

    save /sys config partitions all

  3. To load the system configuration, type the following command:

    load /sys config partitions all

  4. To mitigate this issue, you can disable Full Sync from the device group by using the following command syntax:

    modify /cm device-group <affected device group name> full-load-on-sync false

  5. To save out the device group configuration change, type the following command:

    save /sys config partitions all

  6. To exit tmsh, type the following command:

    quit
