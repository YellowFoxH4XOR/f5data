Description

Threat campaign violations are no different from any violation a security policy may raise against an HTTP request. by assigning a proper logging profile, the violation event report can be examed locally or remotely.

Environment

  • ASM is provisioned.
  • Threat Campaigns Feature is licensed.

Cause

A given Threat campaign signature is triggering false-positive block action and you wish to disable it.

Recommended Actions

Use the following steps to disable a Threat campaign signature:

  1. Navigate to Security  ››  Application Security : Security Policies : Policies List
  2. Click on the name of the security policy in question.
  3. From the side menu, select Threat Campaigns.
  4. From the filter icon, search by using the Threat Campaigns name.
  5. Disable it.
