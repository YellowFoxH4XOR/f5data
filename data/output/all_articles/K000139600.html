Description

You are not able to access BIG-IP through GUI and CLI using TACACS user. Also, following logs appear in var/log/secure 

May  3 13:15:13 example,com warning httpd[8451]: tac_connect: connection to 192.168.1.1 failed: No route to host
May  3 13:15:13 example,com err httpd[8451]: pam_tacplus: connection failed srv 0: No route to host
May  3 13:15:16 example,com warning httpd[8451]: tac_connect: connection to 192.168.1.2 failed: No route to host
May  3 13:15:16 example,com err httpd[8451]: pam_tacplus: connection failed srv 1: No route to host

Environment

  • BIG-IP
  • TACACS user
  • TACACS server

Cause

TACACS servers are not responsible

Recommended Actions

Check the connectivity from BIG-IP to the TACACS servers

Additional Information

K15596: Troubleshooting TACACS+ authentication for BIG-IP administrative users
