Description

After configuring iApp, the following behavior occurs: 
  • Users of Outlook 2016 can set up and access the server normally through the iApp.
  • Users of Outlook 2013 cannot set up completely with the below error through the iApp.
     "The action cannot be completed. The connection to Microsoft Exchange is unavailable. Outlook must be online or connected to complete this action." on the  client.
When bypassing BIG-IP, it is successfully set up.

Environment

  • Outlook 2013 and 2016
  • Configuring iApp by deploying Exchange Server 2016 template.

    Cause

    iApp setting does not configure for RPC over HTTP to support outlook 2013.
    The default configuration for Exchange Server 2013 requires RPC Encryption from the Outlook Client.

    Recommended Actions

     1. Make sure the setting for iApp is correct for outlook 2013 and 2016 users.
     2. Check the setting for Outlook Anywhere in iAPP template 
     3. Outlook Anywhere should be configured with both RPC over HTTP and MAPI over HTTP.

    None
