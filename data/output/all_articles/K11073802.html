K11073802: BIG-IQ is unable to discover DNS resolver configuration for reverse lookup zones.

Description

When importing to BIG-IQ a net dns-resolver forward-zone from BIG-IP with a reverse lookup zone format like:

# tmsh list /net dns-resolver notworking.test.com
net dns-resolver notworking.test.com {
    forward-zones {
        24.172.in-addr.arpa {
            nameservers {
                10.93.1.24:domain { }
                10.93.65.24:domain { }
                10.93.129.24:domain { }
                10.93.193.24:domain { }
            }
        }
    }
    route-domain 0
}


The following error is seen:

Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Invalid forward zone in notworking.test.com. Invalid name: 24.172.in-addr.arpa. Invalid address (24.172.in-addr.arpa). Each octet should be between 0 and 255

 

Forward lookup zones can be imported without any problem.

Environment

  • BIG-IQ Import
  • BIG-IP 
  • forward zone with in-addr.arpa domain

Cause

The "24.172.in-addr.arpa" is being validated as IP address because of the name starting with numbers and has "." as a separator.
This is a known issue tracked under ID 1108533.

Recommended Actions

As an alternative option you can name "24.172.in-addr.arpa" as "24-172.in-addr.arpa" or "24_172.in-addr.arpa". i.e. with "-" or "_" separators.
