Known Issue

Configuration synchronization (ConfigSync) may fail to save configurations on a high availability (HA) peer.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured in a device group.
  • You attempt to ConfigSync the configuration with a large number of folders or partitions (more than 56) to the device group.

Impact

The peer BIG-IP system in a device group fails to save the configuration after a ConfigSync.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The peer BIG-IP system fails to save the configuration.
  • In the /var/log/audit file, you observe an error message similar to the following example:

    AUDIT - pid=15819 user=root folder=/Common module=(tmos)# status=[Syntax Error: "}"
    is missing] cmd_data=save / sys config partitions

Workaround

To work around this issue, you can manually save the configuration on the peer system after a ConfigSync. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) of the affected device by typing the following command:

    tmsh

  2. To save the running configuration of the device, type the following command:

    save /sys config partitions all

  3. Exit tmsh by typing the following command:

    quit
