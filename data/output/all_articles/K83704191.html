K83704191: Some configurations are not synced to Standby BIG-IQ

Type
Support Solution
Published
2025-10-07
Updated
2026-01-26
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K83704191

Description

The configurations below in System >> THIS DEVICE are not synced to peer(standby) BIG-IQ.

  • SNMP
  • SMTP
  • Network config

Environment

  • BIG-IQ HA
  • Run config sync from Active to Standy BIG-IQ

Cause

It is by design. The device-specific data is not synced/copied to peer BIG-IQ.

Recommended Actions

If you would like to configure above of Standby BIG-IQ, you may need to "Promote" or "Reset to Standalone" to modify the config.

Additional Information

None.
