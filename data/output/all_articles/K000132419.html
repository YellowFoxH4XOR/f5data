Description

When the BIG-IP ASM's Live Update is used, the log file may grow larger size.

file location : /var/lib/hsqldb/live-update/liveupdatedb.log

Environment

  • ASM provisioned

Cause

This behavior is by design 

Recommended Actions

F5 recommends to keep liveupdatedb.log value to default, unless the file size grows quickly or reach the size of the partition size.


Follow the below steps to modify the default value

  1. Edit /var/lib/hsqldb/live-update/liveupdatedb.properties
    vi /var/lib/hsqldb/live-update/liveupdatedb.properties
  2. change the default value of hsqldb.log_size from 200 MB to desired value
    For example:  hsqldb.log_size= 100 
  3. Save the changes
    wq: 
  4. Restart restjavad and tomcat
    # bigstart restart restjavad tomcat 


Note : There is no hard limit of configurable value. The value should be smaller than partition size. Otherwise it has potential to cause out of disk space.
