Topic

You should consider using this procedure under the following condition:

  • You want to introduce additional security attributes to the HTTP ASM cookies as set by the BIG-IP ASM system.

Description

You can configure the BIG-IP ASM system to use the secure and HttpOnly cookie attributes to enhance the security of BIG-IP ASM cookies.

The system adds the secure attribute only when the traffic protocol is HTTPS. The secure cookie attribute directs a web browser to only use cookies on secure or encrypted sessions. The HttpOnly attribute directs browsers to use cookies by way of the HTTP and HTTPS protocols only, ensuring that the cookie is not available by other means, such as JavaScript function calls.

Note: These procedures enable the ASM cookie secure attribute. For more information about configuring BIG-IP ASM for application cookie security, refer to the Adding Cookies chapter of the BIG-IP Application Security Manager: Implementations manual. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Important: Ensure that you successfully synchronize the BIG-IP ASM configuration across all peer devices before performing the following procedure.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the BIG-IP system.

Procedures

Configuring the secure and HttpOnly attributes, perform the following procedures:

To watch a video demo of the Configuration utility procedures, go to  K000159599: Configure the "Secure" and "HttpOnly" ASM cookie attributes to strengthen cookie security.

  • Set the secure cookie attribute from the command line
  • Set the secure cookie attribute from the Configuration utility
  • Set the HttpOnly cookie attribute from the command line
  • Set the HttpOnly cookie attribute from the Configuration utility 

    Important: You must perform the configuration steps on all BIG-IP ASM devices of the device group.

    Note: The following procedures do not affect the browser verification cookies used by DoSL7 Proactive Bot Defense or Bot Defense Profile. Refer to K93240866: Configuring the Secure attribute flag for the DoSL7 Proactive Bot Defense or Bot Defense Browser Verification cookie on BIG-IP ASM systems for the procedure to set the secure attribute for cookies TSxxxxx_27 or TSxxxxx27 generated by these profiles.

Set the secure cookie attribute from the command line

Enable the secure attribute by setting the cookie_secure_attr internal BIG-IP ASM parameter.

Impact of procedure: You must restart the BIG-IP ASM service, which causes a brief traffic disruption.

  1. Log in to the Advanced Shell (bash).
  2. To enable the cookie_secure_attr parameter, enter the following command:

    /usr/share/ts/bin/add_del_internal add cookie_secure_attr 1

  3. To restart the BIG-IP ASM services, enter the following command:

    tmsh restart /sys service asm

  4. To verify the services are in the run state, enter the following command:

    tmsh show /sys service asm

    The command output appears similar to the following example:

    asm          run (pid 25144) 10 seconds, 1 start

You can disable the secure attribute by repeating the previous three steps; however, in step 2, substitute the value 0 for 1.

For example:

/usr/share/ts/bin/add_del_internal add cookie_secure_attr 0

Set the secure cookie attribute from the Configuration utility

You enable the secure attribute by setting the cookie_secure_attr internal BIG-IP ASM parameter.

Impact of procedure: You must restart the BIG-IP ASM service, which causes a brief traffic disruption.

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Select Create.
  4. For Parameter Name, enter cookie_secure_attr.
  5. For the Parameter Value, enter 1.
  6. Select Create.
  7. Log in to the command line.
  8. To restart the BIG-IP ASM services, enter the following command:

    tmsh restart /sys service asm

  9. To verify the services are in the run state, enter the following command:

    tmsh show /sys service asm

    The command output appears similar to the following example:

    asm          run (pid 25144) 10 seconds, 1 start

You can disable the secure attribute using Configuration utility by assigning value 0 to cookie_secure_attr from the System Variables list.

Set the HttpOnly cookie attribute from the command line

The HttpOnly attribute is enabled by setting the cookie_httponly_attr internal BIG-IP ASM parameter.

Impact of procedure: You must restart the BIG-IP ASM service, which causes a brief traffic disruption.

  1. Log in to bash.
  2. To enable the cookie_httponly_attr parameter, enter the following command:

    /usr/share/ts/bin/add_del_internal add cookie_httponly_attr 1

  3. To restart the BIG-IP ASM services, enter the following command:

    tmsh restart /sys service asm

  4. To verify the services are in the run state, enter the following command:

    tmsh show /sys service asm

    The command output appears similar to the following example:

    asm          run (pid 25144) 10 seconds, 2 starts

You can disable the HttpOnly attribute by repeating the previous three steps; however, in step 2, substitute the value of 0 for 1.

For example:

/usr/share/ts/bin/add_del_internal add cookie_httponly_attr 0

Set the HttpOnly cookie attribute from the Configuration utility

To enable the HttpOnly attribute, set the cookie_httponly_attr internal BIG-IP ASM parameter.

Impact of procedure: You must restart the BIG-IP ASM service, which causes a brief traffic disruption.

  1. Log in to the Configuration utility.
  2. Go to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Select the cookie_httponly_attr parameter name.

    Note: For BIG-IP 13.1.x, you must create the parameter first by selecting Create and, for Parameter Name, manually entering cookie_httponly_attr

  4. For Parameter Value, enter 1.
  5. Select Update.
  6. Log in to the command line.
  7. To restart the BIG-IP ASM services, enter the following command:

    tmsh restart /sys service asm

  8. To verify the services are in the run state, enter the following command:

    tmsh show /sys service asm

    The command output appears similar to the following example:

    asm          run (pid 25144) 10 seconds, 1 start

You can disable the HttpOnly attribute from Configuration utility by assigning value 0 to cookie_httponly_attr in the System Variables list.
