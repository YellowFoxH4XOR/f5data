Known Issue


This is the result of a known issue. BIG-IP GTM can mark the BIG-IP LTM system down after applying a hotfix on the BIG-IP LTM unit if all of the following conditions are met:
  • BIG-IP GTM is running version 9.2.x and BIG-IP LTM is running version 9.1.x
  • BIG-IP LTM is running the version 9.2.x big3d agent
  • A hotfix is installed on the BIG-IP LTM unit

If the above conditions are met, the hotfix installation on the BIG-IP LTM unit will overwrite the big3d agent with an incorrect version of big3d. As a result, BIG-IP GTM will lose its iQuery connection and mark the BIG-IP LTM unit down.

F5 Product Development tracked this issue as CR70143 and it was fixed in BIG-IP LTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

You can work around this issue by copying the correct version of the big3d agent from BIG-IP GTM to BIG-IP LTM. To do so, type the following command from the BIG-IP GTM command line:

big3d_install
