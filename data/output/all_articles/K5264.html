Known Issue

This is the result of a known issue. 3-DNS router objects are intended to be associated with links. Sometimes it is useful to create a router object to use only as the target of a health check as part of your particular configuration. When you create a router object for use with a health check, 3-DNS will still create the associated link object.

You can ignore the additional link object that was created by 3-DNS.

F5 Network Product Development tracked this issue as CR24722.
