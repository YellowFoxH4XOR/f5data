K000137813: Locate SSL Profile using particular Certificate via iControl REST

Type
Support Solution
Published
2023-12-06
Updated

Applies to

Source

Description

For a given certificate name, how do you use the iControl REST API to locate all clientssl profiles that use the certificate?

Environment

  • iControl Rest
  • BIG-IP
  • Certificates
  • SSL Profiles

Cause

You wish to look up all clientssl profiles that use a certain certificate.

Recommended Actions

Option 1 on CLI:

Create an iControl REST API request that lists you the client ssl profile for a specific certificate that you enter.

Substitute the fields written in bold below with values that are suitable for your environment.

bigip=10.0.0.1; token=$(curl -sk -X POST -H "Content-Type: application/json" -d '{"username":"admin", "password":"admin", "loginProvideName": "tmos"}' "https://${bigip}/mgmt/shared/authn/login" | jq -r '.token.token'); curl -sk -H "X-F5-Auth-Token: ${token}" "https://${bigip}/mgmt/tm/ltm/profile/client-ssl" | jq -r --arg cert "test_certificate" '.items[] | select(.certReference.link | contains($cert)) | .name'

 

Option 2 on Postman:

This example will configure Postman to print the client-ssl profile name and certificate file name to the Postman console.

First obtain an auth token to be used in subsequent commands.

  • If the BIG-IP system is using local auth, first obtain a token using the instructions available at https://community.f5.com/t5/technical-articles/icontrol-rest-authentication-token-management/ta-p/287462  
  • If the BIG-IP system is using remote auth you can follow https://clouddocs.f5.com/api/icontrol-soap/Authentication_with_the_F5_REST_API.html.

Create a GET request in Postman to the following endpoint

https://{{bigip_mgmt_ip}}/mgmt/tm/ltm/profile/client-ssl

In the Postman tests section, the following example will print the name of the clientssl profile and the name of the certificate that it is using to the console.

pm.test("Login status code is 200", function () {
  pm.response.to.have.status(200);
});
var json = pm.response.json();
for( item of json.items) {
  console.log("client-ssl profile " + item.name + " is using a certificate named " + item.cert);
}
