Topic

F5 has released the BIG-IP Edge Portal application for Android devices, which streamlines access to web applications that reside behind the BIG-IP APM system and FirePass devices.

The BIG-IP Edge Portal application for Android has the following features:

  • Username/password authentication
  • Client certificate support
  • Detection when a device is rooted
  • Saving credentials and sessions
  • Saving local bookmarks and favorites
  • Accessing bookmarks with keywords
  • An embedded web view
  • Ability to enforce device locking with PIN or password settings
  • Ability to set the minimum PIN length for the device

This application is a lightweight client for Android access to the BIG-IP APM system and FirePass controller, and supports only the web application access. You can download the F5 BIG-IP Edge Portal application from the Android marketplace at the following location:

Note: This link takes you to a resource outside of AskF5, and it is possible that the information may be removed without our knowledge.

https://market.android.com/details?id=com.f5.edge.portal

Important: The BIG-IP Edge Portal app is unable to display user log-in prompts from HTTP 401 Authorization Required responses. If single sign-on (SSO) is not configured in the Access Policy and the Web Application utilizes HTTP authentication (for example, NT LAN Manager (NTLM) or HTTP Basic), the login will likely fail. This means that the BIG-IP APM system itself must handle the 401 responses using its SSO capability. Once SSO is properly configured in the access profile, the HTTP 401 responses are handled by the BIG-IP APM system instead of the BIG-IP Edge Portal app. For instructions about configuring SSO, refer to the Configuration Guide for BIG-IP Access Policy Manager.
