K8222: Maximum size of user names

Type

Applies to

  • FirePass: 6.0.2
Source

Issue

In FirePass software versions prior to 6.0.2, the user name (Logon column in the Users > User Management page) supplied to the logon page could be arbitrarily long.

Beginning with FirePass 6.0.2, the user name is restricted to a maximum of 255 bytes. Using single-byte character sets allows for user names of up to 255 characters. Using a double-byte character set, such as Shift JIS, allows for user names of up to 127 characters.
