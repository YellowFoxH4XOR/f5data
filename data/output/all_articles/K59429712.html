Description
There is an impact on guests when the license is added or reactivated to the vCMP host.
Do not add or reactivate the license on vCMP host while guests on the host are active and processing traffic.

Environment

  • BIG-IP LTM
  • vCMP host and guest
  • Licensing
     

Cause
License activation should be performed on vCMP host and there will be a brief interruption of traffic while reactivating the license. This can impact the traffic on the guests. Hence, it is recommended to activate license in a maintenance window and on a standby unit if the guests are in HA. 

Recommended Actions
Add or reactivate the license on the host while all the guests are in Standby/Offline status in a maintenance window. To do so, perform either of the following procedure:

Shutting down a vCMP guest using the Configuration utility
Activate the license on the BIG-IP system using the manual activation method
Restarting a vCMP guest using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your vCMP host. The vCMP guest cannot process traffic until it is restarted.

Shutting down a vCMP guest using the Configuration utility

  1. Log in to the Configuration utility of the vCMP host.
  2. Go to vCMP > Guest List.
  3. Select the name of the vCMP guest you want to shut down.
  4. For Requested State, select Configured or Provisioned.
  5. Select the Update button.

Activate the license on the BIG-IP system using the manual activation method: 

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility using an account with the administrator role.
    Note: If this is a new BIG-IP system, open a web browser on a workstation attached to the network on which you configured the management port and type the following URL in the browser: https://<IP address>/. <IP_address> is the address that you configured for the management port.
  2. Select Activate.
    Note: If the BIG-IP system is already licensed, navigate to System > License and select Re-activate. Optionally on BIG-IP 12.1.0 and later, select the Enable License Comparison check box to compare a new license with the existing BIG-IP license.
  3. Select Manual.
  4. Select Next.
  5. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  6. On the F5 Licensing Tools page, select Activate F5 product registration key for BIG-IP 9.x and later.
  7. Paste the dossier into the Enter Your Dossier box, and then select Next.

    The F5 Product Licensing page produces your license.

  8. Copy the license and paste it into the License box in the Configuration utility.
  9. Select Next.
    Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. To avoid such scenarios, perform the activity in a maintenance window. 

After reactivating the license, you can start up a vCMP guest by changing its state to deployed through the vCMP host using either the Configuration utility or tmsh utility. To do so, perform either of the following procedure:

Restarting a vCMP guest using the Configuration utility

  1. Log in to the Configuration utility of the vCMP host.
  2. Go to vCMP > Guest List.
  3. Select the name of the vCMP guest you want to restart.
  4. For Requested State, select Deployed.
  5. Select the Update button.

Additional Information
Post relicensing of vCMP Host, BPDU Guard block could be triggered on the network switch linked to the BIG-IP marking the interfaces down causing a network disruption. If that happens, refer to network switch vendor on how to clear err-disabled ports.
