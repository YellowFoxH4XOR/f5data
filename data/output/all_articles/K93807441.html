Topic

You should consider using this procedure under the following condition:

  • View a list of F5OS-A images on the F5 rSeries system.
  • Import/Upload a F5OS-A image into the F5 rSeries system.
  • Remove an existing F5OS-A image from the F5 rSeries system.

Description

The F5OS-A software runs on the F5 rSeries system and is available as a single ISO which contains the base OS software and platform layer services components. For more information about the different F5OS software images, refer to K03278510: F5OS-A and F5OS-C software for F5 hardware platforms.

When you import or upload an image to the F5 rSeries system, the image is stored in the following virtual directories:

  • images/staging/ (actual directory on the Linux host: /var/import/staging/)
  • images/import/iso/ (actual directory on the Linux host: /var/export/chassis/import/iso/)

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the F5OS-A webUI if you are using the webUI or REST API procedures.
  • You have admin user access to the F5OS-A CLI if you are using the CLI procedures.

Procedures

  • View the existing F5OS-A images on the F5 rSeries system
  • Import or upload an F5OS-A image on the F5 rSeries system
  • Remove an existing F5OS-A image from the F5 rSeries system

View the existing F5OS-A images on the F5 rSeries system

You can view the F5OS-A images that are imported or uploaded on the F5 rSeries system using the webUI, the command-line interface (CLI), or the REST API. To do so, perform the appropriate procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use the CLI
  • Use the REST API

Use the webUI

  1. Log in to the webUI of the F5 rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > Software Management. The webUI displays the list of existing images on the F5 rSeries system.

Use the CLI

  1. Log in to the CLI of the F5 rSeries system as the admin user.
  2. Display the list of the ISO images available on the system by entering the following command:

    show system image state iso

    The command returns an output similar to the following example:

                                             IN            
    VERSION ISO  STATUS  DATE        SIZE    USE    TYPE   
    -------------------------------------------------------
    2.0.0-22925  ready   2026-05-20  5.76GB  true          
    1.8.4-26491  ready   2026-04-16  6.93GB  false  EHF-1  
    1.5.2-21056  ready   2024-02-29  5.85GB  false  LTS    

Use the REST API

  1. Log in to a system with the installed curl utility.
  2. Display the list of ISO images available on the system using the following command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-system:system/f5-system-image:image/f5-system-image:state/f5-system-image:iso"

    In the previous syntax, note the following:

    • Replace <username> and <password> with the username and password that has administrative access the F5 rSeries system.
    • If you are running the command from the F5 rSeries system CLI, replace <ip address> with localhost.
    • If you are not running the command from the F5 rSeries system CLI, replace <ip address> with the management IP address of the F5 rSeries system.

    For example,

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.86.35/api/data/openconfig-system:system/f5-system-image:image/f5-system-image:state/f5-system-image:iso"

Import or upload an F5OS-A image on the F5 rSeries system

You can either import or upload an F5OS-A image to the F5 rSeries system.

To import, you need to first download the F5OS-A image file to a remote HTTPS server that supports PUT/POST requests with a valid CA signed SSL certificate. You then import to the F5 rSeries system by providing the URL for the image file hosted on your remote HTTPS server to the F5 rSeries system. For information on how to import, refer to the Download and Import Software chapter of the F5 rSeries Systems: Installation and Upgrade manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

To upload, you need to first download the F5OS-A image file to your local workstation that has administrative access to the management IP address of the F5 rSeries system. You then log in to the the webUI or REST API to upload the image file to the F5 rSeries system. Starting from F5OS-A 1.8.0, you can use the admin user to secure copy (SCP) the image file to the F5 rSeries system. To upload the F5OS-A image file to the F5 rSeries system, perform any one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use SCP
  • Use REST API

Use the webUI

  1. Prior to uploading, you must first download the F5OS-A image file from the MyF5 Downloads site to your local workstation. You can find the F5OS-A image files by selecting the F5OS group and F5OS Appliance Software product line on the downloads page. For more information about downloading software, refer to K167: Downloading software and firmware from F5. Proceed to the next step after you have completed the download of the image file(s) you need.

    Note: The available ISO image files are based on the F5 rSeries Appliance. Ensure you downloaded the appropriate image file for the F5 rSeries Appliance(s) you own. For example, you should download an image file with filename ending R5R10 if you are uploading the file to a F5 rSeries 5000 or 10000 Appliance. For more information, refer to K03278510: F5OS-A and F5OS-C software for F5 hardware platforms.

  2. Log in to the webUI of the F5 rSeries system as the admin user.
  3. Go to SYSTEM SETTINGS > Software Management.
  4. To upload an ISO image file, select Upload. The webUI then prompts you for the ISO image file.
  5. Locate the ISO image file you have downloaded to your local workstation and select Open. The webUI displays the status of the uploading process under the Image Transfer Status (F5OS 2.0.0 and later) or the Image Import Status (prior to F5OS 2.0.0) section on the Software Management page; monitor the progress of the upload till completion.

Use SCP

Note: This procedure can only be used to upload an image file to a F5 rSeries system running F5OS-A 1.8.0 and later. If you attempt to upload an image file to a F5 rSeries system running F5OS-A 1.7.x or earlier, the system aborts the attempt and the scp utility reports an error similar to the following example: scp: images/staging/: Permission denied

  1. Prior to uploading, you must first download the F5OS-A image file from the MyF5 Downloads site to your local workstation. You can find the F5OS-A image files by selecting the F5OS group and F5OS Appliance Software product line on the downloads page. For more information about downloading software, refer to K167: Downloading software and firmware from F5. Proceed to the next step after you have completed the download of the image file(s) you need.

    Note: The available ISO image files are based on the F5 rSeries Appliance. Ensure you downloaded the appropriate image file for the F5 rSeries Appliance(s) you own. For example, you should download an image file with filename ending R5R10 if you are uploading the file to a F5 rSeries 5000 or 10000 Appliance. For more information, refer to K03278510: F5OS-A and F5OS-C software for F5 hardware platforms.

  2. Upload the image file to the images/staging/ directory on the F5 rSeries system as the admin user using the SCP utility from your local workstation:

    scp -O <path/to/filename/on/local/workstation> admin@<ip address>:images/staging/

    In the previous syntax, note the following:

    • Replace <path/to/filename/on/local/workstation> with the full path to the image file downloaded on your local workstation.
    • Replace <ip address> with the management IP address of the F5 rSeries system.
  3. After SCP completes the upload of the image file to the F5 rSeries system, you can verify that the F5 rSeries system accepted the image file using the previous procedure Viewing the existing F5OS-A images on the F5 rSeries system.

Use REST API

  1. Prior to uploading, you must first download the F5OS-A image file from the MyF5 Downloads site to your local workstation. You can find the F5OS-A image files by selecting the F5OS group and F5OS Appliance Software product line on the downloads page. For more information about downloading software, refer to K167: Downloading software and firmware from F5. Proceed to the next step after you have completed the download of the image file(s) you need.

    Note: The available ISO image files are based on the F5 rSeries Appliance. Ensure you downloaded the appropriate image file for the F5 rSeries Appliance(s) you own. For example, you should download an image file with filename ending R5R10 if you are uploading the file to a F5 rSeries 5000 or 10000 Appliance. For more information, refer to K03278510: F5OS-A and F5OS-C software for F5 hardware platforms.

  2. Upload the image file to the images/staging/ directory on the F5 rSeries system as the admin user using the curl utility from your local workstation by performing the procedure described in K000139146: Upload a file to the VELOS or rSeries system using REST API.
  3. After the upload of the image file to the F5 rSeries system completes, you can verify that the F5 rSeries system accepted the image file using the previous procedure Viewing the existing F5OS-A images on the F5 rSeries system.

Remove an existing F5OS-A image from the F5 rSeries system

You can remove F5OS-A images that are no longer used to free up disk space for future software installations. To do so, perform any one of the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Use the webUI
  • Use the CLI
  • Use the REST API

Use the webUI

  1. Log in to the webUI of the F5 rSeries system as the admin user.
  2. Go to SYSTEM SETTINGS > Software Management.
  3. Select the ISO image file you want to remove and select Delete. Select OK to confirm the image deletion.

Use the CLI

  1. Log in to the CLI of the F5 rSeries system as the admin user.
  2. Enter config to enter the configuration mode.
  3. Enter the following command syntax to remove the ISO image file:

    system image remove iso <ISO image file version and build>

    For example, you would enter the following command to remove F5OS-A version 1.1.1 build 9159 from the system:

    system image remove iso 1.1.1-9159

    If the image removal is successful, the system returns a message similar to the following example:

    response
           success: Image 1.1.1-9159 is removed

  4. Enter exit to exit the configuration mode.

Use the REST API

  1. Log in to to a system with the curl utility installed.
  2. Remove an existing ISO image from the F5 rSeries system using the following command syntax:

    curl -X POST -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>/api/data/openconfig-system:system/f5-system-image:image/remove" -d '{ "f5-system-image:iso": "<image version number-build number>"}'

    In the previous syntax, note the following:

    • Replace <username> and <password> with the username and password that has administrative access the F5 rSeries system.
    • If you are running the command from the system CLI, replace <ip address> with localhost.
    • If you are not running the command from the system CLI, replace <ip address> with the management IP address of the F5 rSeries system.
    • Replace the <image version number-build number> with the one you want to remove.

    For example, if you want to remove F5OS-A 1.1.1-9159 image from the F5 rSeries system, enter the following command:

    curl -X POST -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.86.35/api/data/openconfig-system:system/f5-system-image:image/remove" -d '{ "f5-system-image:iso": "1.1.1-9159"}'

    When the system removes the image successfully, the system returns an output similar to the following example:

    {
      "f5-system-image:output": {
        "response": "\n\tsuccess: Image 1.1.1-9159 is removed"
      }
    }
