Applies to

Source

Description

AFM NAT Excessive number of logs "Port Block Updated" and "LSN_PB_UPDATE"
Error Log example:
Aug  5 16:50:42 10.20.20.22 "LSN_PB_UPDATE""10.10.10.29""10.20.20.64: 1025-1275""1628178642198""unknown"

Environment

  • AFM NAT
  • Syslog
  • After Upgrade

Cause

None

Recommended Actions

There is no fix for now.
The workaround is If you deselect "Log subscriber ID" field in log profile, this message will not be written. Note that this workaround may impact other messages related to subscriber ID.
