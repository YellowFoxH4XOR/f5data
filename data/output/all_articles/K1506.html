Topic

To view the virtual connections from the command line interface, perform the following steps:

  1. Use the UNIX wc (word count) utility to check the number of connections. To do this, type the following command:

    b conn dump | wc -l

  2. Depending on the number of connections you have, run one of the the following commands:

    • 1000 or more connections

      For a thousand or more connects, use the Unix grep utility to filter the output for a single IP address (or string) by typing the following command:

      bigpipe conn dump | grep <ip>

      You should now see the connections displayed for the IP address you specified.

      Note: F5 Networks recommends that you use the IP address of a known test client to verify that the client is load balanced to the correct server and, if persistence is enabled, remains load balanced to that server.

    • Less than 1000 connections

      For fewer than a thousand connections on BIG-IP version 3.0 through 4.0, type:

      bigpipe conn dump

      For fewer than a thousand connections on BIG-IP version 1.8.3 through 3.0, type:

      bigpipe dt

      You should now see a display of a connection table similar to the following which specifies the incoming client ip:port, vip:port, and the node:port to which the client was sent.

      
           from                 vip                node           proto

     192.168.14.11:2177 -> 192.168.14.108:80 -> 192.168.104.135:80  tcp

The connection table is dynamic. If you do not see the table after typing the bigpipe conn dump command, it most likely indicates that the connections have already completed before the output could be displayed. To ensure that you are able to run the command fast enough to produce a connection table, use the following script to execute the command at selected intervals without manual execution:

while sleep 5 ; do date ; b conn dump | grep <client_ip> ; done

This script will display the date and the connection table entry for the <client_ip> every 5 seconds.

To exit the script, type the following command:

^C
