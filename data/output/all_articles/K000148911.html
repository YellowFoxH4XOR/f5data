Description

Windows Edge Client configured to use ReCAPTCHA is failing due to script error prompt

Instead of the expected behaviour, Captcha is spinning forever

 

Connection and ReCAPTHCA works fine when using a browser

 

Environment

  • An access policy is configured with ReCAPTCHA
  • A Windows Edge Client attempts to connect and ReCAPTCHA is required
  • APM login page with Google recaptcha

 

Cause

BugID 1288985
Google recaptcha does not support webview/IE anymore

 

Recommended Actions

See the BugTracker for BugID 1288985 for mitigation and/or resolution information
