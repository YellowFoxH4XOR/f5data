Topic

RSA ACE/Server software uses the remote authentication protocol, RSA SecurID. BIG-IP software does not include support for RSA SecurID authentication for BIG-IP Configuration utility access, or application traffic authentication in the PAM module.

F5 Product Development has assigned ID 248058 (formerly CR 32105) to this issue.
