K000151500: API connectivity failure when trying to access VELOS webUI: "Failure for /data/f5/cluster:cluster/nodes/node API. The server or an underlying service is unreachable."

Applies to

Source

Description

Unable to access multiple pages in VELOS partition webUI, such as:

  • Tenant Configuration
  • Network Settings -> Port Groups
  • System Settings -> Cluster Details
  • System Settings -> General
  • System Settings -> Log Settings

System returns an error message similar to the following:

Failure for /data/f5-cluster:cluster/nodes/node API. The server or an underlying service is unreachable.
original-error : Network Error

Environment

  • VELOS partition
  • webUI

Cause

Bug ID1582105

When this issue occurs, the partition's devel.log and confd.log will contain messages similar to the following:

devel-c get_elem error {external_timeout, ""} for callpoint tenant_memory_utilization path /f5-cluster:cluster/nodes/node{blade-1}/state/tenant-memory/tenant-reserved

Daemon TenantMemoryStatsOperHandler timed out
no registration found for callpoint tenant_memory_utilization/get_elem of type=external

The problem is caused by platform-stats-bridge querying blades that aren't present or part of the partition.

Recommended Actions

Bug ID1582105 is fixed in F5OS-C v1.8.1.

Workarounds from least to most impact

Restart the platform-stats-bridge container on the controller that is running-active for the partition:

docker container restart partition<n>_platform-stats-bridge

Fail the partition over to the other controller:

system redundancy go-standby

Disable and re-enable the partition

partitions partition default config disabled ; commit
# Wait ~60 seconds
partitions partition default config enabled ; commit
