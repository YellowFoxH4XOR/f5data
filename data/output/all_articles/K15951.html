Known Issue

The BIG-IP APM Machine Cert Auth access policy agent may cause the browser to stop responding.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM is configured with an access profile that uses the Machine Cert Auth access policy agent.
  • Users are connecting to the BIG-IP access profile with the Internet Explorer 11 browser.

Impact

Users are unable to access the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When users attempt to log on to the BIG-IP APM access profile using Internet Explorer 11, the browser stops responding.
  • When viewing the BIG-IP APM Session Details report for the affected user session, the machine certificate check does not occur.
  • Setting the user's browser in Compatibility mode allows the machine certificate check to occur.

Workaround

To work around this issue, you can set Internet Explorer to use Compatibility mode. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Locate the Tools menu in the Internet Explorer 11 browser.
  2. From the Tools menu, select Compatibility View Settings.
  3. To add the current website to the Compatibility View websites list, click Add.
  4. Click Close.
