K000132496: How to manually export DNS Zone files

Published
2023-02-14
Updated

Source

Description

This article provides some workarounds when you want to manually export zone files from F5 DNS for some reasons like:

  • You are trying to transfer zone files using ZoneRunner from one F5 BIG-IP DNS to another but access is restricted by firewall
  • You want to transfer Zone Files to another DNS servers and have to manually create the zones files.

 

Environment

  • BIG-IP DNS
  • DNS Zone Files
 

Cause

There's no option to export the Zone Files only.

 

Recommended Actions

All of the zone files are kept in /var/named/config/namedb folder. You could manually export those files along with your named.conf which is in /var/named/config when needed. Here's how: 

Using UCS file
  1. Create UCS backup. See K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.
  2. Download the UCS file to your local machine.
  3. Use tools like 7-zip to open the archive file and browse to /var/named/config/namedb folder.
Using QKView
  1. Generete QKView and upload it to iHealth. See K12878: Generating diagnostic data using the qkview utility.
  2. In iHealth, go to Files >> All and browse to /var/named/config/namedb folder.
