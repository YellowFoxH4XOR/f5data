Description

Even if Default Content Profiles are deleted, they will be restored when a URL is created.

Environment

  • BIG-IP ASM/AWAF
  • Delete Default Content Profiles in ASM Security Policy (e.g. Default XML Profile, Default JSON Profile)
  • Create a URL in ASM Security Policy

Cause

It is the expected behavior when you create a new url, the system will automatically create the Default Content Profiles (if they are deleted in ASM Security Policy).

Recommended Actions

None
