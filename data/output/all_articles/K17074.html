Topic

You can use the BIG-IP Deterministic NAT (DNAT) utility (dnatutil) for interpreting logs from BIG-IP 11.4.0 and later.

Description

You can use dnatutil to identify subscribers in a service provider environment. The utility calculates the reverse source address and port mapping of the DNAT pools using the subscribers to public translation addresses and ports data that are algorithmically logged by BIG-IP DNAT.

You can run dnatutil on either a BIG-IP system or supported Linux hosts, such as CentOS 64 and Ubuntu 64. The dnatutil utility is installed on a BIG-IP system by default in BIG-IP 11.4.0 and later. For supported Linux hosts, you can download the RPM or Debian package from the F5 Downloads site.

The latest dnatutil versions are capable of interpreting logs from BIG-IP 11.4.0 and later. To determine your dnatutil version, enter one of the following commands for your host type:

  • BIG-IP 11.5.0 and later

    dnatutil --version
  • BIG-IP 11.3.0 through 11.4.1

    rpm -qa | grep -i dnatutil
  • Linux host using RPM package

    For a Linux host, such as CentOS 64, that uses the RPM package, you can use either of the following commands:

    rpm -qa | grep -i dnatutil

    dnatutil --version
  • Linux host using DEB package

    For a Linux host, such as Ubuntu 64, that uses the DEB package, you can use either of the following commands:

    dpkg -l | grep -i dnatutil

    dnatutil --version

Recommendations

When using dnatutil on a Linux host, F5 recommends that you always use the latest dnatutil version for interpreting logs from BIG-IP 11.4.0 and later.
