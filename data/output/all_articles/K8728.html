Known Issue

This is the result of a known issue. TMM may crash while running tcpdump if a packet filter rejects an incoming packet.

This issue occurs when a packet filter has been configured to accept a specific protocol or type of traffic, and tcpdump is running.

F5 Networks Product Development tracked this issue as CR97531 and it was fixed in BIG-IP LTM version 9.4.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in hotfix, BIGIP-9.4.4-94.0-HF3, issued for BIG-IP version 9.4.4, and in hotfix BIGIP-9.6.1-HF2, issued for BIG-IP version 9.6.1. You may download these hotfixes or later versions of the hotfixes from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
