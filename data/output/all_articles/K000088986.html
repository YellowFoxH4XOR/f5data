K000088986: Traffic metrics may not display on NGINX Controller Dashboard for an Instance

Type
Support Solution
Published
2021-04-28
Updated
2021-07-02
Source
https://my.f5.com/manage/s/article/K000088986

Description

There are no traffic metrics showing on NGINX Controller Dashboard. It shows only the message "No Data".

 If you re-start the controller-agent with debug logs enabled, you notice a log saying AVRD is not running.



 Environment

  • NGINX Controller 3.14
  • NGINX Plus R23


 Cause 

AVRD is not running.



 Recommended Actions

Reinstall the nginx-controller agent.

  1. On the NGINX Controller UI, go to Infrastructure > Instances
  2. Click the Create + button
  3. Select the option Add an existing instance
  4. Copy the curl command and paste it on the NGINX+ instance. This action will re-install the agent.
  5. Confirm AVRD is now running with following command: ps aux | grep -i avrd
  6. Verify metrics are showing now on NGINX Controller Dashboard.


 Additional Information

None.
