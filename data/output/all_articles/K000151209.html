K000151209: Error uploading TLS key: File size exceeds 10KB limit

Description

While uploading PEM formatted key for TLS certificate, user can observe "File size exceeds 10 KB" error. 

Environment

Distributed Cloud

TLS Certificate and key upload

Cause

 "File size exceeds 10 KB" error is linked to hard limit of 10 KB file size for key.


This is expected when PEM key is generated with extensions for example using this command:

openssl rsa -in private4096.key -text > privatekey4096.pem


option -text includes extensions which are exceeding file size limit.

Answer/Recommended Actions

Edit key file and save new file that contains only this part:


-----BEGIN PRIVATE KEY-----

...cropp...

-----END PRIVATE KEY-----


Upload new file to Distributed Cloud Console. 

Additional Information

 4096 bit length keys in PEM format are well under 10KB limit for uploading.
