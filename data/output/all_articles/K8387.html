Known Issue

This is the result of a known issue. If you create an alias of a Terminal Server favorite, FirePass may report an error message similar to the following example when users attempt to access the Terminal Server alias:

Security exception: not allowed to connect to 192.168.0.130:1494

This issue occurs when the index number of the Terminal Server alias is different than the index number of the Terminal Server favorite. For example, if the Terminal Server favorite is the third item listed under Terminal Server Favorites in the FirePass Administrative Console for Resource_Group_1, and the Terminal Server alias is the fifth item listed under Terminal Server Favorites for Resource_Group_2, this issue may occur. If the Terminal Server favorite is the third item listed under Terminal Server Favorites for Resource_Group_1, and the Terminal Server alias is the third item listed under Terminal Server Favorites list for Resource_Group_2, this issue does not occur.

Note: The Terminal Server Favorites list is located on the Application Access: Terminal Servers: Resources page. Select the Resource Group name from the Resource Group menu to view the Terminal Server favorites assigned to that group.

F5 Networks Product Development tracked this issue as CR92606, and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue by configuring individual Terminal Server favorites for each Resource Group instead of configuring aliases to Terminal Server favorites. Terminal Server favorites are configured on the Application Access: Terminal Servers: Resources page in the FirePass Administrative Console.
