Description

When running bigip_add from a local BIG-IP DNS to a remote BIG-IP system, the script may fail with an error similar to the following:

ERROR: Can't parse remote /config/httpd/conf/ssl.crt/server.crt on 192.168.1.245 via ssh.
ERROR: nested "BEGIN CERT..." found in /config/big3d/client.crt at line: 67.

The big3d process on the remote BIG-IP system may be on a restart loop. When this behavior occurs, a log sequence appears in the /var/log/gtm file that appears similar to the following example:

err big3d[29455]: 012b3003:3: SSL_CTX_load_verify_locations: SSL error:0D07209B:asn1 encoding routines:ASN1_get_object:too long
err big3d[29455]: 012b3003:3: SSL_CTX_load_verify_locations: SSL error:0D068066:asn1 encoding routines:ASN1_CHECK_TLEN:bad object header
err big3d[29455]: 012b3003:3: SSL_CTX_load_verify_locations: SSL error:0D07803A:asn1 encoding routines:ASN1_ITEM_EX_D2I:nested asn1 error
err big3d[29455]: 012b3003:3: SSL_CTX_load_verify_locations: SSL error:0907400D:PEM routines:PEM_X509_INFO_read_bio:ASN1 lib
err big3d[29455]: 012b3003:3: SSL_CTX_load_verify_locations: SSL error:0B084009:x509 certificate routines:X509_load_cert_crl_file:PEM lib

Environment

  • BIG-IP DNS
  • BIG-IP LTM
  • big3d
  • bigip_add script

Cause

A certificate within /config/big3d/client.crt file in the remote BIG-IP system is corrupted.

 

Recommended Actions

  1. Login into CLI of the affected BIG-IP system (where big3d is restarting)
  2. Stop big3d process

    bigstart stop big3d

  3. Open client.crt with the editor of your preference (vi/nano)

    vi /config/big3d/client.crt

    Remove the corrupted certificate on this file. The error specifies where the corrupted certificate is, for example in line 67 of the file as below. Example: ERROR: nested "BEGIN CERT..." found in /config/big3d/client.crt at line: 67.

    vi +67 /config/big3d/client.crt

  4. Save the modification on the file
  5. Start big3d processbigstart start big3d
