Description

  • How to add/delete another tenant owner
  • How to make someone else a tenant owner
  • Note:
    • A tenant can have multiple owners
    • Once a user has upgraded to tenant owner, their namespace role configuration will be deleted since they have the highest privilege

Environment

  •  F5® Distributed Cloud 

Cause

None

Answer/Recommended Actions

Before proceeding the steps you need to access F5® Distributed Cloud Console as a tenant owner to perform this action:

  1. Administration -> IAM -> Users, choose the user, and click "...", chose either of the following
    • Click "Upgrade to Tenant Owner" 
    • Click "Downgrade Tenant Owner"  
  2. For the user been upgraded/downgraded, please log out of Distributed Cloud Console and wait for 5 mins, then login back

Note:

  • Tenant owner will be the only one who can add another users as tenant owner.
  • While creating new tenant, only one tenant owner can be created.
  • If the tenant owner is no longer part of the team/company, we recommend working with your IT team to perform a password reset to access the account and change the owner following this process. If this process can not be completed a ticket request should be raised to Support to request the tenant owner be changed.
