Known Issue

This is the result of a known issue. Running the tcpdump utility from within the Configuration utility creates an unreadable binary file.

When you run the tcpdump utility from within the Configuration utility (System > Support > TCP Dump), the command syntax listed in the Task List and the tcpdump initialization message is prepended to the binary file that is written when the tcpdump utility finishes capturing network information.

For example, running the tcpdump utility from within the Configuration utility to capture 10 packets on the internal VLAN will prepend the following text to the binary file:

tcpdump -i internal -c 10
tcpdump: listening on internal 10 packets received by filter 0 packets dropped by kernel

This prepended information causes applications that are capable of reading binary packet captures to report that the file is unreadable, or in a format the application does not understand.

F5 Product Development tracked this issue as CR124693 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1, which has been issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on a Logical Volume Management (LVM) disk-formatted system, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about installing version 10.x hotfixes on a partitioned system, refer to K9819: Installing a BIG-IP version 10.x hotfix on a partitioned system.

Workaround

If you are unable to apply the hotfix, F5 recommends that you run the tcpdump utility from the command line to prevent the tcpdump configuration syntax from being prepended to the binary file tcpdump writes.
