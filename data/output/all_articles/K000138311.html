K000138311: Unable to configure "Monitor Only" mode

Type
Support Solution
Published
2024-02-06
Updated
2026-08-12
Status
Legacy Content
Applies to
  • NGINX Products
  • NGINX Controller: 3.22.9
Source
https://my.f5.com/manage/s/article/K000138311

Description

The option "Monitor Only" can not be enabled for component on the Security page.
This option requires to Enable WAF on this page.
To Enable WAF system, it requires to configure Strategy option which should set with available default option "balanced_default".

Environment

  • Nginx Controller 3.22.9

Cause

The "balanced_default" for "Security Strategies" section was not available within: App Component -> Security.
The AppSec feature was not available on feature list.

Recommended Actions

If no "Security Strategies" section and no 'balanced_default' selection within App Component -> Security page, check if AppSec feature is available on feature list.

To do this, check if AppSec flag is enabled from helper.sh. 

These example shows that we are missing AppSec and true.

$ /opt/nginx-controller/helper.sh list-features | grep 'currentStatus' -A 25 | egrep "name|value"
"name": "ENABLE_DPM",
"value": "true"
"name": "GLOBAL_DNS",
"value": ""

To add the missing values AppSec and true use the command below:

/opt/nginx-controller/helper.sh setfeature AppSec true

Note: Applying feature flags changes will restart services. This can take up to 2 minutes.

The following will show us how the results should looks like:

$ /opt/nginx-controller/helper.sh list-features | grep 'currentStatus' -A 25 | egrep "name|value"
"name": "AppSec",
"value": "true"
"name": "ENABLE_DPM",
"value": "true"
"name": "GLOBAL_DNS",
"value": ""
