K000133604: High CPU usage on BIG-IP LTM due to excessive logging in iRules

Type
Support Solution
Published
2025-04-22
Updated
2025-05-13
Applies to
  • BIG-IP
  • BIG-IP DNS
  • BIG-IP Link Controller
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000133604

Description

BIG-IP LTM systems may experience periodic or sustained spikes in CPU usage, with utilization remaining above 80% for extended periods. These spikes can occur even when there is no significant change in traffic volume or active connections. System logs typically do not show error messages during these events.

Environment

  • High CPU Utilization
  • iRule
  • Excessive Logging

Cause

Excessive logging within custom iRules, such as frequent use of "log local[x]" or similar statements can significantly increase CPU utilization on the control plane. Each log entry requires processing and writing, which can consume substantial system resources even if network traffic is stable.

Recommended Actions

  1. Review custom iRule Logging:
    • Examine all custom iRules applied to virtual servers for unnecessary or overly verbose logging statements.
    • Identify any rules that generate large volumes of log entries during normal operation.

  2. Reduce Log Verbosity:
    • Comment out or remove non-essential log statements from custom iRules.
    • Limit logging to only critical events needed for troubleshooting or compliance.

  3. Monitor System Performance:
    • After making changes, monitor CPU usage using tools such as top, tmsh show sys cpu, or QKView/iHealth reports.
    • Confirm that CPU utilization returns to expected levels.

  4. Follow Best Practices:
    • In production environments, avoid enabling debug-level or highly verbose logging unless actively troubleshooting an issue.
    • Regularly review and optimize custom scripts and custom iRules for performance impact.

If high CPU usage persists after optimizing iRule logging, further investigation into other possible causes may be required. it is recommended to contact F5 Support for further assistance
