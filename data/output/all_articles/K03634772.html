Description
After configuring self IP's in a non default partition on BIG-IP, they are seemingly not available to use for high availability services such as config sync.

Environment

  • BIG-IP
  • High Availability
  • Self IP's configured in non default (/Common) partition.

Cause
Only self IP's in the default (/Common) partition of the BIG-IP are available to use for HA services.
Using self IP's in non default partitions for HA is not supported.

Recommended Actions

  1. Any self IP that is intended to be used for config sync or any other HA related services must be created in the default (/Common) partition of BIG-IP.
