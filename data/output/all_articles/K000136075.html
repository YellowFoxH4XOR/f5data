Description

If BIG-IPs in an HA configuration lose connection over the failover link for more than 30 seconds, and the sequence numbers are more than halfway to rolling over (on one or both boxes), when connectivity is restored, the peer unit will show offline.


sodlog will show the peer sequence number as 0, though a packet capture will show it incrementing normally (note that you may need to enable sodlog debug to see this):


Traffic Group: /Common/traffic_group_load 1 state fo_offl 

--- Start Peers & Mates ---

10.10.10.1

slot 0   seq 3191245433 no_chg_sec 0 alive no next_active false <-- The BIG-IP under review


 <log edited for clarity>


10.10.10.2

slot 0   seq 0 no_chg_sec 149126 alive no next_active true <-- The peer BIG-IP showing as offline


---- End Peers & Mates ----


If you need to enable sodlog debug see K55591231: Overview of sod debug logging


Environment

BIG-IP in HA configuration

Cause

This is ID1347825

Recommended Actions

Restart both BIG-IPs
