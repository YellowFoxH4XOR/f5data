Topic

You should consider using this procedure under the following conditions:

  • You configured your BIG-IP system with multiple traffic groups.
  • You want to identify the name of a traffic group in log messages that track traffic group state changes.

Description

When you configure the BIG-IP system with a traffic group, the system logs when the traffic group changes states.

The following example displays a typical log message:

notice tmm1[<pid>]: 01340011:5: HA unit 1 state change: from 0 to 1.

The following definitions identify the traffic group id and states in the message:

  • HA unit = The name of the traffic group is unit 1.
  • state change: from 0 to 1 = The traffic group changed to the active state on the local device.
  • state change: from 1 to 0 = The traffic group changed to the standby state on the local device.

Note: The content of log messages tracking traffic group state changes may differ in versions prior to BIG-IP 11.6.0.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the TMOS Shell (tmsh).
  • You have access to the Configuration utility or command line.

Procedures

  • Viewing log messages that track traffic group state changes
  • Identifying the traffic group that appears in log messages

Viewing log messages that track traffic group state changes

The system logs changes in the state of high availability (HA) traffic groups at the following location: /var/log/ltm. You can view BIG-IP LTM log messages using the Configuration utility or the command line.

Using the Configuration utility to view log messages

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Logs > Local Traffic.
  3. Enter the following text in the search box:

    *state change: from*

  4. Click Search.

Using the command line to view log messages

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Use the following command to search the /var/log/ltm log file for changes in the state of HA traffic groups:

    grep "state change: from" /var/log/ltm | more

Identifying the traffic group that appears in log messages

You can use tmsh to determine the name of a traffic group listed in a log message that displays its state changes.

  1. Note the HA unit listed in the state change log message.
  2. Log in to tmsh.
  3. Type the following command to list the traffic groups configured on your system:

    list /cm traffic-group

  4. Locate the unit-id that matches the HA id in the log message.
  5. Locate the line above the unit-id stanza, containing the following syntax:

    cm traffic group <traffic-group name> {

    The <traffic-group name> is the name of the traffic group for that unit-id.
