Description

In APM Visual Policy Editor (VPE), you may configure Variable Assign. The result is not expected after expr when original value started with "0" or "0x", pure number. 
For example: In the Custom Expression the setting:

expr {[string tolower [mcget {session.logon.last.username}] ]}

If the value session.logon.last.username is 0123, the result will be 83.
If the value session.logon.last.username is 0x123, the result will be 291.

Environment

  • BIG-IP APM
  • Access Profile
  • Variable Assign

Cause

A value starting with "0" or "0x" respectively denotes an OCT and HEX number.

 Recommended Actions

Replacing expr with return will fix this issue.
Example:

expr {[string tolower [mcget {session.logon.last.username}] ]}

Replace with one of them:

return [string tolower "[mcget {session.logon.last.username}]"]  
return [string tolower [mcget {session.logon.last.username}]]
