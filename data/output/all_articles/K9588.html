Issue

The BIG-IP or Enterprise Manager Configuration utility may become unresponsive when multiple instances of the Configuration utility are used simultaneously to make configuration changes. The /var/log/httpd/httpd_errors log file indicates that the httpd process has reached the MaxClients limit with an error message similar to the following example:

httpd: [error] server reached MaxClients setting, consider raising the MaxClients setting

Note: Additionally, some Firefox browser extensions may cause this error message. For more information, refer to K6416: Some Firefox browser extensions can cause Apache and Tomcat to exceed the allowed concurrent HTTP connections, preventing the Configuration utility from displaying.

To reduce the likelihood of this issue, F5 recommends that you use a single instance of the Configuration utility at a time, to administer the system.

Additionally, you can safely increase the value of the httpd process MaxClients setting to 20. To do so, perform one of the following procedures:

  • Configuring MaxClients using the Configuration utility in BIG-IP 10.x and later, and in Enterprise Manager
  • Configuring MaxClients using the command line in BIG-IP 10.x and later, and in Enterprise Manager
  • Configuring MaxClients using the command line in BIG-IP versions prior to 10.1.0

Configuring MaxClients using the Configuration utility in BIG-IP 10.x and later, and in Enterprise Manager

Note: Only perform this procedure if you can currently access the Configuration utility, and you want to proactively change the MaxClients setting.

  1. Log in to the Configuration utility.
  2. Navigate to System > Preferences.
  3. From the System Settings box, click Advanced.
  4. To allow 20 concurrent HTTP connections to the Configuration utility, in the Maximum HTTP Connections to Configuration Utility box, type 20.
  5. Click Update.

Configuring MaxClients using the command line in BIG-IP 10.x and later, and in Enterprise Manager

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Assign the value of 20 to the MaxClients setting by typing the following command:

    modify /sys httpd max-clients 20

  3. Save the configuration by typing the following command:

    save /sys config

  4. Restart the httpd service by typing the following command:

    restart /sys service httpd

Configuring MaxClients using the command line in BIG-IP versions prior to 10.1.0

  1. Log in to the command line.
  2. Assign the value of 20 to the MaxClients setting by typing the following command:

    bigpipe httpd include '"MaxClients 20"'

    Note: The MaxClients keyword/value pair is preceded by a single quotation mark, then a double quotation mark, and is followed by a double quotation mark, then a single quotation mark.

  3. Save the configuration change by typing the following command:

    bigpipe save all

  4. Restart the httpd service by typing the following command:

    bigstart restart httpd
