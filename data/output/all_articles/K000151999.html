K000151999: Configure a remote logging profile for the WAF DoS profile or BOT profile to forward logs to a remote server.

Source

Description

Configure a remote logging profile for the WAF DoS profile to forward logs to a remote server.

Environment

  • Remote logging profile
  • DoSL7 profile
  • BOT profile

Cause

None

Recommended Actions

Important: This configuration is for reference and may require adjustments to adapt to your environment. 

1)_ Verify which interface the BIG-IP system is using to reach the remote server. In this example, "Internal" refers to the Self-IP interface.

config # ip route get 1.1.1.1
1.1.1.1 dev Internal  src 1.1.1.250

2)_ Create a new pool for the destination log server

3)_ Create a new log destination. Choose the pool as destination. 

4)_ Create a new log destination and link it to the previously created log destination.

5)_ Create a new log publisher. 

6)_ Create a new DoSL7 or BOT logging profile. 

or 

7)_ Associate the new logging profile with the virtual server.
