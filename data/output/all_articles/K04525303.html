Description

You  may encounter the following symptoms after upgrade to BIG-IP 14.x:

  • Local log stops including /var/log/ltm, /var/log/tmm,etc.

  • Remote syslog stops working either if configured.

  • The syslog-ng daemon failed, check the syslog-ng daemon status with command below.

# bigstart status  syslog-ng
syslog-ng is stopped

  • Restart the syslog-ng daemon can not fix this.

# bigstart restart syslog-ng

  • Check the journal log with command below after syslog-ng restart.

# journalctl -D /var/log/journal/493e889c53404c0d8335225bb048bc3f/

systemd[1]: Starting System Logger Daemon...
syslog-ng[14716]: [2020-08-12T07:12:35.925197] Error resolving reference; content='filter', name='f_loval6_info', location='/etc/syslog-ng/syslog-ng.conf:1537:5'
syslog-ng[14716]: .
systemd[1]: syslog-ng.service: main process exited, code=exited, status=2/INVALIDARGUMENT
systemd[1]: Failed to start System Logger Daemon.
systemd[1]: Unit syslog-ng.service entered failed state.
systemd[1]: syslog-ng.service failed.
 

Environment

  • BIG-IP 14.x

  • Syslog

Cause

Typo error which triggers wrong resolving reference.

Recommended Actions

Correct the wrong resolving reference, for example,

sys syslog {
    include "destination remote_server {tcp(\"10.10.10.10\" port (514));};filter f_alllogs {level (debug...emerg);};log {source(local);filter(f_alllogs);destination(remote_server);};
    filter f_local6_info {
    not facility(local6) and level(info);
    };
    destination d_remote_loghost {
    udp(\"10.10.10.11\" port(514));
    };
    log {
    source(local);
    filter(f_loval6_info);               <<<<<<<<<<<  change f_loval6_info  to f_local6_info
    destination(d_remote_loghost);
    };
    filter f_daemon_info {
    not facility(daemon) and level(info);
    };
    destination d_remote_loghost {
    udp(\"10.10.10.12\" port(514));
    };
    log {
    source(local);
    filter(f_daemon_info);
    destination(d_remote_loghost);
    };
    "
}
