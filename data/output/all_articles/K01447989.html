Description
Configuration import of ASM module fails with erro (/var/log/restjavad.0.log):

"ASM configuration of bigip1 (Attack-type Server-Side Request Forgery (SSRF) is missing id field on BIG-IP: https://10.0.0.15:443/mgmt/tm/asm/attack-types?ver=14.1.0.3&em_server_ip=46.116.101.183&em_server_auth_token=..)"

Environment

  • BIG-IQ Centralized Management 7.x/ 6.x
  • BIG-IP  ASM 13.x,14.x, 15.x
  • Importing config ASM Configuration
  • ASM ASM-SignatureFile_20191117_112212.im  installed

Cause

ID857633

Recommended Actions

Follow workaround provided in ID857633 on affected BIG-IP ASM
  1. Install a newer ASU to reassociate the affected signatures with the correct attack type
  2. Run the following SQL on the affected BIG-IP devices: DELETE FROM PLC.NEGSIG_ATTACK_TYPES WHERE attack_type_name = "Server-Side Request Forgery (SSRF)";
    From the cli(bash) :
    mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'DELETE FROM PLC.NEGSIG_ATTACK_TYPES WHERE attack_type_name = "Server-Side Request Forgery (SSRF)"'
