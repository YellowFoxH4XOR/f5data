K08442428: AS3 Fails to send declaration

Type
Support Solution
Published
2021-07-23
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K08442428

Description

AS3 Deployment from generic client to BIG-IQ applied to a managed BIG-IP fails with the following error messages:

status: 422: /declare failed with status of 422, Failed to send declaration: /declare failed with status of 400, failure querying config for tenant prd-sftp (POST http://admin:XXXXXX@localhost:8100/mgmt/tm/util/bash execute bash command response=500 body={\"code\":500,\"message\":\"Connection refused\",\"referer\":\"Unknown\",\"restOperationId\":8810145,\"kind\":\":resterrorresponse\"}) unknown
 

Environment

  • REST client 
  • BIG-IQ
  • BIG-IP target device

Cause

Insufficient RAM provisioned on the BIG-IP for the modules in use

Recommended Actions

  1. Review the release note for the software version running on BIG-IP. Be sure there is enough RAM provisioned for the modules that have been enabled
  2. Once the RAM issue is resolved, try the AS3 deployment again

Additional Information

None
