K82222127: Console is not working, LCD screen shows ''F5 Network Incorporated''

Type
Support Solution
Published
2023-03-09
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K82222127

Description

  • The console is not working, it shows random chars, like if the baud rate were wrong. 
  • The LCD screen shows "F5 Network Incorporated".
  • Status, Alarm, and Power LED lights are on.

Environment

  • BIG-IP LTM.
  • LCD screen.
  • LED indicators.

Cause

Unknown at the time of publication.

Recommended Actions

       1. Perform a hard reboot of the device (power off the device for ~10 min and power on). To reboot, log in to the command line and enter the following command:

            # reboot

            Note: The BIG-IP restart process can take an average of four to eight minutes, depending on the BIG-IP device, resources, and configuration.

            Large configurations and configurations that include firewall rule compilation may take additional time to complete.

       2. Insert a pendrive to verify if the device is detecting it. If it was detected, run a EUD test (K7172).
       3. Try with a different console cable.
       4. Try accessing the BIG-IP device with a different computer.
       5. Confirm baud rate configuration as per F5 suggestion for the console cable (K13885).
       6. If previous steps did not resolve the SSH console access, open a ticket to request an RMA of the device.
