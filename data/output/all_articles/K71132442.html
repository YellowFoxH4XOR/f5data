Topic

You can view Virtual Clustered Multiprocessing (vCMP) guest information for high availability (HA) status, provisioned modules, and software status using the TMOS Shell (tmsh).

Description

Beginning in BIG-IP 11.6.0, you can view vCMP guest health and performance information, such as HA status, provisioned modules, and software status by running the appropriate tmsh commands on the vCMP host.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to tmsh for the vCMP host.

Procedures

  • Displaying health information for a vCMP guest
  • Displaying HA status information for a vCMP guest
  • Displaying per-slot command line prompts for a vCMP guest
  • Displaying module provisioning status information for a vCMP guest
  • Displaying software status information for a vCMP guest

Displaying health information for a vCMP guest

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh for the vCMP host by typing the following command:

    tmsh

  2. To display health information for the vCMP guest, type the following command:

    show /vcmp health

Displaying HA status information for a vCMP guest

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh for the vCMP host by typing the following command:

    tmsh

  2. To display the HA status for a vCMP guest deployed on the BIG-IP system, use the following command syntax:

    show /vcmp health ha-status <guest_name>

    For example:

    show /vcmp health ha-status MyGuest

Displaying per-slot command line prompts for a vCMP guest

You can display the per-slot command line prompts for the vCMP guests deployed on the BIG-IP system. These are the same prompts that you would see when logging into a guest using SSH. To display the per-slot command line prompt for a vCMP guest, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh for the vCMP host by typing the following command:

    tmsh

  2. To display the per-slot command line prompts for the vCMP guest, use the following command syntax:

    show vcmp health prompt <guest_name>

    For example:

    show /vcmp health prompt MyGues

Displaying module provisioning status information for a vCMP guest

You can display the module provisioning status information for the vCMP guests deployed on the BIG-IP system. This will show you which modules are provisioned for a guest and at what level. To display the module provisioning status information, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh for the vCMP host by typing the following command:

    tmsh

  2. To display the module provisioning status information for the vCMP guest, use the following command syntax:

    show vcmp health module-provision <guest_name>

    For example:

    show /vcmp health module-provision MyGues

Displaying software status information for a vCMP guest

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh for the vCMP host by typing the following command:

    tmsh

  2. To display the software status information for the vCMP guest, use the following command syntax:

    show vcmp health software <guest_name>

    For example:

    show /vcmp health software MyGues
