Description

When iprepd tries to contact BrightCloud serverm an error message logged in  /var/log/ltm file, 

err iprepd[<pid> ]: 015c0004:3: query reply parser exception: Schema item db_variable.name not found
<pid>: is the process ID of the chassis manager daemon (iprepd) process.
 

Environment

  • iprepd connecting to BrightCloud server
  • IP intelligence is not provisioned.

Cause
iprepd attempted to connect to the BrightCloud server to download the IP reputation database.

Recommended Actions
To suppress the error message, run the following commands :

  1. Stop iprep daemon
    # bigstart stop iprepd

  2. Disable iprepd
    # bigstart disable iprepd

  3. Disable db variable for iprpd from auto-update 
    # tmsh modify sys db iprep.autoupdate value disable
