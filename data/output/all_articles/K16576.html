Topic

The BIG-IP ASM system's XML processing engine is allotted 300 MB of memory by default. Processing memory-intensive XML requests can exhaust the XML processing engine's allotted memory. The following scenarios (or combinations of these scenarios) can trigger memory exhaustion:

  • The system processes a large XML schema
  • The system processes many individual XML schemata
  • The system processes a very high volume of XML requests

Description

When the XML processing engine experiences memory exhaustion, the BIG-IP ASM system loses the ability to process XML requests (requests are blocked). Common symptoms of XML processing engine memory exhaustion can include any of the following:

  • Malformed XML violations are logged to the /var/log/asm file for every request that passes through the affected profiles.
  • Malformed XML violations are continuously logged to the /var/log/asm file without additional details to identify the violation.
  • The BIG-IP ASM system logs error messages, similar to the following example, to the /var/log/asm file:

    01310003:0: ASM out of memory error: event code X89 Exceeded maximum memory assigned for XML processing
  • The BIG-IP ASM system logs an error message, similar to the following example, to the /var/log/ts/bd.log file:

    BD_XML|ERR |<date and time>|<pid>|xml_validation.cpp:0113|Cannot allocate 24064 more bytes for XML parser. current memory size 1999981913 (in bytes)

Recommendations

If you encounter the symptoms described in this article, you may need to increase the amount of memory allotted to the BIG-IP ASM XML processing engine. For more information about memory and the XML processing engine, refer to K10803: Customizing the amount of memory allocated to the BIG-IP ASM XML processing engine.

You can use the following command to view xml memory usage and the percentage of  used memory out of total available memory (the command executes every 10 seconds):

while true; do (tmctl asm_memory_util_stats -s total_xml_mem_used,total_max_mem | awk '(c!=0&&c!=1&&$2) {print $1"KB "$S2"KB "$1*100/$2"%"} {c++}') > 1; date > 2; paste -d '' 1 2 ;sleep 10;done;
