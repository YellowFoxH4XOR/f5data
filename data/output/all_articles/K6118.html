Topic

Beginning in 2006, Verisign began signing their SSL server certificates with a new certificate authority (CA). The BIG-IP versions prior to 4.6, and BIG-IP LTM versions prior to 9.2.2 do not include the CA certificate that is required to verify server certificates that are signed by the new CA.

If you use SSL server certificate verification and are planning to obtain a new certificate from Verisign after January 2006, you will need to add the new CA to the ca-bundle file on the BIG-IP system.

Note: In most cases, and unless server SSL is being used with systems outside of your control, self-signed certificates can be used with server SSL without verification. Since the servers are under your control, identifying the authenticity of the certificate to allow encryption is not required.

Updating the ca-bundle.crt file for BIG-IP version 4.5.x

To update and include the new CA certificate from Verisign in the ca-bundle.crt file, perform the following procedure:

1. Log in to the command line.

2. Change directories to the /config/bigconfig/ssl.crt/ directory.

3. Open the file ca-bundle.crt.

4. Add the new Verisign CA to the end of the ca-bundle.crt file.

5. Save the changes to the file.

6. Restart the SSL proxy process using the following command:

   proxyd

Note: This is will start a new instance of the proxyd command that will handle all new SSL connections. The previous proxyd command will continue to process existing SSL connections and close out once all the previous connections have been closed.


Updating the ca-bundle.crt file for BIG-IP version 9.x

To update the ca-bundle.crt file for BIG-IP versions previous to 9.2.2, perform the following procedure:

1. Log in to the command line.

2. Change directories to the /config/ssl/ssl.crt directory.

3. Open the file ca-bundle.crt.

4. Add the new Verisign CA to the end of the ca-bundle.crt file.

5. Save the changes to the file

The BIG-IP system will use the changes made to the file.
