Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following articles:

  • K14206: Configuring the BIG-IP system to exclude inode information from Etags (11.x - 12.x)
  • K14208: Configuring Enterprise Manager to exclude inode information from Etags

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP system to exclude inode information from Etags when connecting to the Configuration utility

Description

When connecting to the Configuration utility, responses from the Apache server will contain an Etag HTTP header that includes the file's inode information.

For example:

Etag="15b6c-ced-5b447140"

15b6c is the inode of the file printed in hex.

This information is only provided while accessing the management GUI; therefore F5 Product Development considers the impact or risk of revealing this information is low.

However, because the inode information is disclosed, some security scanners may detect the system as vulnerable to Apache vulnerability CVE-2003-1418. The Apache vulnerability was addressed with the addition of the FileETag httpd setting, which allows the Etag header to be configurable. However, the default behavior of the Apache service was not changed. The Apache versions used by BIG-IP support the FileETag httpd setting required to configure the Etag header.

Note: For more information about this Apache vulnerability, refer to CVE-2003-1418. This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the BIG-IP command line.

Procedures

Configuring BIG-IP to exclude inode information from Etags

Customers who need to comply with local security requirements can configure BIG-IP to exclude inode information from Etags by performing one of the following procedures that applies to their version:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

BIG-IP 9.4.2 through 10.2.4

  1. Log in to the command line.
  2. Specify the format for the Etag header by typing the following command:

    bigpipe httpd include \"'FileETag MTime Size'\"

  3. Save the configuration by typing the following command:

    bigpipe save

  4. Restart the httpd service by typing the following command:

    bigstart restart httpd

    The Etag headers will no longer include the inode information for files. The Etag headers will now appear similar to the following example:

    Etag="ced-5b447140"

BIG-IP 9.4.1 and earlier

  1. Log in to the command line.
  2. Specify the format for the Etag header by typing the following command:

    echo "FileETag MTime Size" >> /config/httpd/conf/httpd.conf

  3. Restart the httpd service by typing the following command:

    bigstart restart httpd

    The Etag headers will no longer include the inode information for files. The Etag headers will now appear similar to the following example:

    Etag="ced-5b447140"
