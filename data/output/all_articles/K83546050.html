K83546050: Error: The value of the property ''addToLogEnter'' is null or defined, not a Function object.

Type
Support Solution
Published
2023-03-16
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP APM: 14.1.4
Source
https://my.f5.com/manage/s/article/K83546050

Description

When the customer trying to access using the BIG-IP Edge Client, it shows the following error message:

------------------------------------------------------------------------

An error has occurred in the script on this page.

Line: <number of line>

Char: <name of character>

Error: The value of the property "addToLogEnter" is null or defined, not a Function object

Code: 0

URL: https://<VPN_URL>/my.policy

Do you want to continue running scripts on this page?

                       Yes                    No

------------------------------------------------------------------------

Environment

  • BIG-IP APM.
  • BIG-IP Edge Client.
  • Command line.
  • Windows system.

Cause

Unknown at the time of publication. 

Recommended Actions

  1. Clear all the client web browser cache, close the browser and launch it again.
  2. Log in to the command line and restart the BIG-IP using the following command:

      # reboot

            Note: The BIG-IP restart process can take an average of four to eight minutes, depending on the BIG-IP device, resources, and configuration.

            Large configurations and configurations that include firewall rule compilation may take additional time to complete.

        3. If the issue persists, uninstall and reinstall the BIG-IP Edge Client in the client workstation. Before installing, remove current components using CTU (article as a reference: K8253).

Additional Information

None
