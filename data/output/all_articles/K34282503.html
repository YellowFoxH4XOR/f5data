Description

Following Error message appears in /var/log/ltm or GUI when config-sync is failed.

mcpd[4466]: 0107004d:3: Virtual address (/Test1/10.1.1.1) encodes IP address (10.1.1.1) which differs from supplied IP address field (10.1.1.1%28).
 

Environment

  • HA Config-Sync.
  • Route Domain (RD)
  • One or more route domains configured apart from RD0.

Cause

Active unit config don't have RD added as suffix in virtual-address but standby unit config have RD added as suffix. Below is the sample config.

Active Unit.

 ltm virtual-address /Test1/10.1.1.1 {  
    address 10.1.1.1%28
    arp enabled
    mask 255.255.255.255
    traffic-group /Common/traffic-group-1
    }

Standby Unit.

 ltm virtual-address /Test1/10.1.1.1%28 {
    address 10.1.1.1%28
    arp enabled
    mask 255.255.255.255
    traffic-group /Common/traffic-group-1
    }

Recommended Actions

This can be resolved by manually adding the RD as suffix in virtual-address config by following either of the procedures. 

First Option:

  1. Edit the bigip.conf file and add RD as suffix in virtual-address name similar to Standby config.
    # vim /config/bigip.conf
    Note. You can use vim or nano or any other editor of your choice to edit the /config/bigip.conf file. It is always good to take backup of the bigip.conf file before editing.
     
  2. After the changes, run the following command to validate the configuration file.           
    # tmsh load sys config verify

      3. If no error message appears in console then you can load the config file.
         # tmsh load sys config          
          Important: It is recommended to load the config in maintenance window.

Second Option:
     
       1. Go to TMOS mode from bash
           #  tmsh

       2. Use 'mv' command to rename the object-name.
          (tmos)# mv ltm virtual-address /Test1/10.1.1.1 /Test1/10.1.1.1%28     
         Note: 'mv' command is an experimental feature and have some associated BUG ID's. Please refer K08689048 for more information. 

        3. Save the config
          (tmos)save sys config
  
        4. Sync the config now from Active to Standby.
