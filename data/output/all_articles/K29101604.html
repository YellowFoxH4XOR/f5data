K29101604: TMM may use a smaller MTU value on static and dynamic routes

Known Issue

The Traffic Management Microkernel (TMM) may use a smaller maximum transmission unit (MTU) value on static and dynamic routes.

This issue occurs when all of the following conditions are met:

  • You configure an MTU value greater than 1500 on the Virtual Local Area Network (VLAN).
  • You create a static or dynamically learned route to a destination without defining a specific MTU value.

Impact

The effective MTU value when using a static or dynamic route is limited to 1500 bytes, which includes a derived maximum segment size (MSS) in TCP connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TMM uses a smaller MTU value when you connect to a device using a configured route, regardless of the larger MTU value on the associated VLAN.

Workaround

To work around this issue, you can specify the MTU value for static routes. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line
  2. To create a static route with a specified MTU value, use the following command syntax:

    tmsh create net route network <ip address>/<network mask> gw <ip address> mtu <value>

    For example:

    tmsh create net route network 192.0.2.0/255.255.255.0 gw 203.0.113.1 mtu 9198

  3. To save the changes, type the following command:

    tmsh save sys config
