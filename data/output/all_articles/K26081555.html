Description

How to force a managed BIG-IP offline from BIG-IQ UI, when upgrading managed BIG-IPs from BIG-IQ and you would like to force the BIG-IPs offline.

Environment

  • Managed BIG-IP
  • BIG-IQ
  • Upgrade/Offline

Cause
None

Recommended Actions

You may achieve this by creating a script on BIG-IQ and applying the same to the BIG-IP in question to force it offline.

  1. Go to Device > Script Management > Script > Add
  2. Give the script a name - say "force-offline"
  3. Under Script type - "tmsh run sys failover offline"
  4. Save and close the script page.
  5. Select the script and click Run. 
  6. Move the BIG-IPs to be forced offline under the Selected side
  7. Click Run.
