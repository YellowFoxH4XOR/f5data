Description

When trying to upgrade an rSeries device tenant, the import of ISO keeps failing.

  • The import fails with error "No space left on device"
  • The import may take a long time.

Environment

  • rSeries/F5OS-A tenant
  • Tenant running BIG-IP T4 or ALL image

Cause

The /shared partition in the tenant has very less free space. This can be verified by df -h command.

Recommended Actions

Make sure the Tenant isn't T1 image. Most T1 images don't support live upgrades.

  1.  From the F5OS level, check the image name from Tenant Management > Tenant Images > Image File. The image name shouldn't have T1 in name.
  2. Then If there are any UCS files or old BIG-IP ISO files, delete them. For more details refer K14403
  3. If required the /shared partition can be increased from default allocated size. Steps below:

    1. Check the existing size for /shared.
      # tmsh show /sys disk directory

    2. Increase the /shared from 15G to say 20G.
      # tmsh modify /sys disk directory /shared new-size 20971520

    3. Check the new size for /shared has increased.
      # tmsh show /sys disk directory

    4. Reboot the tenant.
      # reboot

Note: Step 3.d restarts the tenant and will impact traffic. Follow this step after making this tenant as standby or during a maintenance window.
