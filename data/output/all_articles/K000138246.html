K000138246: F5OS-A Error message : "Node Busy."

Type
Support Solution
Published
2024-01-16
Updated
2024-03-26
Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000138246

Description

You may see numerous messages like "Node Busy." in /var/F5/system/log/platform.log 

 

Error message for example :

 

platform-hal[9]: priority="Err" msg="Action Error" index=0 message="Node Busy." interface="job-4913116" actionKey="GET:bmc/cmd" jobId=4913116

platform-hal[9]: priority="Err" msg="Action Error" index=0 message="Node Busy." interface="job-4913115" jobId=4913115 actionKey="POST:bmc/cmd/sel-time"

platform-hal[9]: priority="Err" msg="Action Error" index=0 message="Node Busy." interface="job-4913114" actionKey="POST:lop/object/rtc-date-time" jobId=4913114

platform-mgr[15]: priority="Err" version=1.0 msgid=0x102000000000001 msg="Platform-mgr HAL response error." errorcode=0 errmsg="Node Busy.".

 

 

Environment

・F5OS-A

・rSeries platform

 

Cause

The BMC (baseboard management controller) is either initializing on startup or is otherwise temporarily busy.

 

Recommended Actions

This message is not associated with any failure or disruption and can be safely ignored if is occurring infrequently.

 

Additional Information

None
