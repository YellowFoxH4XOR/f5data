K61300034: Deployment error not discovered in any device-group using Guided configuration

Type
Support Solution
Published
2021-03-04
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 15.1.2
Source
https://my.f5.com/manage/s/article/K61300034

Description

When integrate Azure AD with APM by using Guided Configuration in the GUI, there is an error stopping the deployment.

"Error
Deployment error
Error: <BIG-IP management IP Address> not discovered in any device-group."
 

 Environment

  • BIG-IP APM
  • Guided configuration in the Configuration Utility (GUI)


Cause
Unknown


Recommended Actions

Restart restjavad and restnoded with the next command:

# tmsh restart sys service restjavad restnoded


Additional Information
None
