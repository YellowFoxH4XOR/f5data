Description

When accessing https://<BIG-IP_hostname>/mgmt/tm/apm/acl, next error is thrown:

{"code":400,"message":"One of the following features must be licensed/provisioned for the URI apm : apm","errorStack":[],"apiError":1}
 

Environment

  • BIG-IP APM provisioned

  • Temporary license applied 

Cause
Unknown

Recommended Actions

Restart restjavad process with the next command: 

# bigstart restart restjavad
