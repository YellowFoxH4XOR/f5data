K000134553: Unable to access device via SSH

Type
Support Solution
Published
2023-05-11
Updated
2023-05-11
Source
https://my.f5.com/manage/s/article/K000134553

Description

  • When trying to SSH into the device, it fails with error.
  • WebUI and console works fine.
  • Error message: "Can't open command history file (/root/.tmsh-history-user), Read-only file system (framework/CmdHistoryFile.cpp, line 92) exiting..."


Environment

  • BIG-IP LTM
  • Trying to access via SSH.


Cause

This can happen if the file system is corrupted or has errors.


 Recommended Actions

Before starting the procedure, make sure you've console access to the device.


  1. Take an UCS from the device and save it somewhere safe (other than the device).
  2. Reboot the device.
  3. Interrupt the the boot selection screen, by pressing up/down arrow key.
  4. Then select the TMOS maintenance option. Screenshot attached below.
  5. Follow https://my.f5.com/manage/s/article/K14245 to list, scan and e2fsck -yf on all file systems.





Additional Information

None.
