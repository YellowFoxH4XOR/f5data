Topic

The BIG-IP ASM Data Guard feature allows you to configure response scrubbing for sensitive user information, such as credit card numbers or social security numbers. Response scrubbing prevents sensitive information from being returned in the response to the client, either by blocking the response or by scrubbing the sensitive data in the response. The BIG-IP ASM Data Guard feature supports using Perl Compatible Regular Expressions (PCRE) to match sensitive information.

Example: UK National ID Number

To create a custom pattern that would instruct Data Guard to match NINO numbers returned by the web server and then mask the data before sending it to the client, you could add the following PCRE expression in the Custom Pattern field:

\b[abceghj-prstw-z][abceghj-nprstw-z] ?\d{2} ?\d{2} ?\d{2} ?[a-dfm]?\b

Example: Danish Personal Identification Numbers

To create a custom pattern that would instruct Data Guard to match CPR numbers returned by the web server and then mask the data before sending it to the client, you could add the following PCRE expression in the Custom Pattern field:

(([0-2][1-9]|[123]0)(0[2,4,6,9]|[1]{2})|([0-2][1-9]|[123]0|31)(0[1,3,5,7,8]|1[1,2]))\d{6}
