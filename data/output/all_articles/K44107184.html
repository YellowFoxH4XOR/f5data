Description
VPN users are authenticated via Active Directory and a VPN tunnel has been established successfully; however, users do not see mapped drives which they normally see when they're on a corporate LAN and automatically mapped for them.

Note:  Mapped drives in this context is different from Drive Mappings under Network Access configuration you specify the network path with a specific network location.

Environment

  • BIG-IP APM
  • APM policy is configured with AD Auth and users are authenticated via Windows Active Directory Domain 
  • Network Access Resources is assigned

Cause
This behavior is seen if you expect that the system runs logon scripts and synchronizes mapped drives that are specified in Window's user profile without enabling "Reconnect to Domain" option in the Network Access setting.

Reconnect to Domain option synchronizes with Active Directory policies on connection establishment.  When enabled, it emulates the Windows logon process for a client on an Active Directory domain, and the following items are synchronized:

  • Logon scripts specified in the user profile
  • Mapped drives specified in the user profile
  • Group policy logon scripts specified in the user profile

Recommended Actions

  1.  Go to Network Access List under Access or Access Policy
     In v13 and higher, Access >> Connectivity / VPN : Network Access (VPN) >> Network Access Lists. 
     In v12 and older version, Access Policy >> Network Access >> Network Access List
  2.  Click the name of the Network Access you would like to modify
  3.  Click Network Settings
  4.  In the Client Settings, choose Advanced view
  5.  Find Reconnect To Domain option and put a check mark for Synchronize with Active Directory policies on connection establishment
     Optional:  You can also enable Execute logoff scripts on connection termination if you would like the system to run logoff scripts when the user disconnects  VPN.
  6.  Hit Update
  7.  Click Apply Access Policy

Additional Information
After enabling Reconnect To Domain option and when users successfully VPN, users may receive "Security Alert"  Website https://<your_VS_hostname> is attempting to run a local application"  if the logon scripts in their Window's user profile contain scripts to run some application automatically.  This security alert can be turned off by following the steps below:

  1. Go back to Network Access Lists and click your Network Access 
  2. Click Launch Applications tab
  3. Under General Properties, uncheck Display warning before launching applications
  4. Hit Update
  5. Click Apply Access Policy
