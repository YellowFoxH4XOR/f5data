Description

After updating VELOS / rSeries system password, BIG-IQ schedule backup is not functioning.

Environment

  • Password
  • BIG-IQ
  • F5OS

Cause

VELOS / rSeries device password updated.

Recommended Actions

New VELOS / rSeries credentials need to be updated on BIG-IQ. To update VELOS / rSeries system credentials on BIG-IQ GUI:

  1. Go to Devices > F5OS > Platform / Devices > Select the F5OS device > Click "Change Password". 

  2. Key in the new username / password and click "Change Now"
