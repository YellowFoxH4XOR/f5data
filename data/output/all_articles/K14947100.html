Known Issue

With a Dynamic Host Configuration Protocol (DHCP) relay virtual server, offer packets from the DHCP server intermittently fail to be forwarded to the client and are dropped on the BIG-IP system.

This issue occurs when the following condition is met:

  • A DHCP relay virtual server is in use.

Impact

Client machines joining the network do not receive DHCP offer messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Offer packets from DHCP servers are not forwarded to the client from the BIG-IP system.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to ensure that the server-side flow for the affected DHCP server is removed from the connection table. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Remove the server-side flow for the affected DHCP server from the connection table by using the following command syntax:

    delete sys connection ss-server-addr <DHCP server IP address> cs-server-port 67

    For example, to remove the server-side flow for affected DHCP server 192.168.66.222, type the following command:

    delete sys connection ss-server-addr 192.168.66.222 cs-server-port 67
