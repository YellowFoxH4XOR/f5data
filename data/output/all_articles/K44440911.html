Description

To determine what is the data transfer rate when there is a latency issues, usually measured in bytes per second, for a specific TCP stream on F5.
Use Wireshark to check data transfer rate for a TCP stream taken in the format of tcpdump on F5.

Environment

  • BIG-IP
  • Windows 10
  • Wireshark

Cause

Want to determine transfer rate for a TCP stream to troubleshoot latency issues. 

Recommended Actions

  1. Open Wireshark.

  2. Type a filter for specific TCP stream, e.g. to filter TCP stream number 12, tcp.stream.eq 12

  3. Click Statistics then click I/O Graphs.


     
     

  4. Check appropriate Display Filter then change the Y Axis value from Packets to Bytes.
     

     
     

  5. The I/O Graphs will show the Bytes per 1 second for transfer rate.
     

      

Note: The I/O Graphs showing maximum of 7x106 Bytes/s which is approximately equal to 7MB/s.

Additional Information

Wireshark can be downloadable from Wireshark website and this is a third party website.
