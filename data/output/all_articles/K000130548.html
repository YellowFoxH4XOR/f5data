K000130548: nlad schannel creation failure

Type
Support Solution
Published
2023-01-11
Updated

Applies to
  • BIG-IP

Source
https://my.f5.com/manage/s/article/K000130548

Description

Your APM device logs the following errors:

 

err nlad[17303]: 01620000:3: <0x2b9773806700> client[178]: DC[127.0.0.1]: schannel[1]: STL exception: write: Broken pipe

warning nlad[17303]: 01620000:4: <0x2b9766d4ee80> client[178]: DC[127.0.0.1]: schannel[0]: re-creating

 

Environment

BIG-IP APM
Domain Controller
NTLM Authentication

Cause

These are nlad errors and nlad is the process that establishes communication channels to the Domain Controller (DC) for NTLM authentication. A broken pipe error means that the process is trying to write or read from the pipe that has been closed. These errors can occur when required ports for communication are not allowed on the firewall for example MSRPC/TCP (tcp135)

 

Recommended Actions

Restart nlad process:

bigstart restart nlad

Allow required ports for example MSRPC/TCP (tcp135)
