K000136205: While trying to upgrade to v15.1.10, the "Install Configuration" option is either empty or incorrect

Type
Support Solution
Published
2023-09-14
Updated
2023-11-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.X, 15.1.0, 15.1.1, 15.1.2, 15.1.3, 15.1.4, 15.1.5, 15.1.6, 15.1.7, 15.1.8, 15.1.9, 15.1.10
Source
https://my.f5.com/manage/s/article/K000136205
Description
When using GUI to switch boot locations after an upgrade from v15.1.x to v15.1.10.x, the "Install Configuration" drop down may not work properly, and may either
- show a narrow blank dropdown
- show an incorrect or empty list of source boot volumes
- if the "Source Volume" field is left blank, pressing "Activate" may cause the system to report the error "null does not exist."

Environment
BIG-IP VE / Appliance
upgrading from v15.1.x to v15.1.10.x

Cause
Bug ID 1349933

Recommended Actions
Use cpcfg command in bash cli as described in https://my.f5.com/manage/s/article/K14724 to copy config to the new boot location.

Additional Information
  • If you have not made changes to the configuration since installing 15.1.10.X you may not need to install the config. See K64400324: Should I use Install Configuration when activating a new Boot Location?
  • Another option is to Reinstall the software on a target partition prior to reboot. The cpcfg process is part of the installation process which you can see in /var/log/liveinstall.log.
