Known Issue

This is the result of a known issue. Fragmented SYN/ACK packets are handled incorrectly under high memory load conditions. This behavior may result in a TMM core.

F5 Product Development tracked this issue as CR66953 and it was fixed in version 9.4.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in HOTFIX-BIG-IP-9.3.1-HF5 issued for BIG-IP version 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
