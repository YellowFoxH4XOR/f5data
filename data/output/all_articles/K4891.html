K4891: Internet Explorer may crash when using FirePass

Topic



Some older versions of Internet Explorer are prone to crash if they receive content for which gzip compression is enabled and no-cache or no-store HTTP headers are used. FirePass generates both of these type of headers by default.

If Internet Explorer crashes regularly for clients after implementing FirePass, F5 Networks recommends that you upgrade Internet Explorer to a more recent version or that you disable gzip compression on FirePass.

To disable gzip compression on FirePass, perform the following steps:

  1. Log in to the FirePass Administration Console.

  2. From the main navigation pane, click Portal Access.

  3. From the upper navigation pane, click Web Applications.

  4. From the menu, click Caching and Compression.

  5. Locate the section of the page titled Turn gzip compression On or Off for Webtop and Web Applications.

  6. Clear the Enable Compression. Saves bandwidth, at the expense of server resources. check box.

  7. Click the Update button.

Gzip compression is now disabled.
