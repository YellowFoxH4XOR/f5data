F5 Product Development tracked this issue and it was fixed in BIG-IP and 3-DNS 4.5.11 for the 4.5 software branch and in version 4.6.2 for the 4.6 software branch.

F5 Product Development tracked this issue and it was fixed in WebAccelerator 5.2 for the 5.x software branch. For information about upgrading, refer to the WebAccelerator Release Notes.

Sendmail versions prior to 8.13.6 are subject to a race condition that can be exploited, allowing an attacker to execute arbitrary code. Some versions of 3-DNS, BIG-IP, and WebAccelerator contain affected versions of Sendmail. These versions, however, are vulnerable only if you have made unsupported customizations to your configuration.

Sendmail is only vulnerable when running as a daemon. By default, no F5 products run Sendmail as a daemon.
