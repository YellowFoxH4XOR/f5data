Description


This article provides step-by-step instructions for deploying an F5 Distributed Cloud (XC) Customer Edge (CE) site on an OpenShift Kubernetes cluster.
The process involves generating a site token, preparing the deployment manifest, configuring security context constraints, deploying the site, and approving the registration.

 

Environment

 

  • OpenShift cluster
  • F5 Distributed Cloud (XC)
  • Site token and manifest required
  • Use of Security Context Constraints (SCC) in OpenShift

Cause


None

 

Answer/Recommended Actions

 

  1. Create a site token for the CE:

    • In the F5 Distributed Cloud Console, navigate to System → Manage → Site Management → Site Tokens, and add a new site token.
    • Copy the UID for use in the next step.

  2. Download the vpm manifest and update with site details:

    • Download the manifest using the provided curl command.
    • Edit the manifest to include your site-specific details.

  3. Add privileged SCC to the default ServiceAccount:

    • Run the following command in OpenShift: 
      oc adm policy add-scc-to-user privileged -z default -n ves-system
    • For more information, see Security Context Constraints.

  4. Deploy the Distributed Cloud site using Kubeconfig and the manifest file:

    • Apply the manifest: 
      oc apply -f ce_k8s.yml

  5. Approve the site registration:

    • In the Distributed Cloud Console, go to System → Manage → Site Management → Pending Registrations and approve the new site.
