Description

The iRules ILX feature was available for Early Access (EA) in BIG-IP v12.0.0.
In the EA release, without the appropriate license, although the feature was visible to the user, it would not work in the absence of a valid license.

An error message similar to is logged: 

err tmm0[<pid>]: 01220001:3: TCL error: /Common/my_irule <HTTP_REQUEST> - Could not find ILX extension my_extension in path my_plugin (line 1) invoked from within "ILX::init my_plugin my_extension"

Environment

  • iRules LX
  • NPM modules

Cause

You may encounter this error with the referring Node.js code has NPM modules referenced but not installed. 
One of the reasons you may encounter the error is by not saving the NPM module using the command: npm install <packagename> --save

Recommended Actions

To fix the issue you may follow the below procedure from the command line. 

  1. Install the NPM modules with the --save option: 
    npm install <packagename> --save

  2. Reload the affected workspace in the Configuration Utility


Additional Information 

To enable the debug logging for SDMD daemon which is responsible for ILX workspaces, follow the below procedure. 

  1. To list current SDMD log level 
    #tmsh list sys db log.sdmd.level
    #tmsh list sys db log.sdmd.stdout 

  2. To modify SDMD loglevel to debug
    #tmsh modify sys db log.sdmd.level value debug
    #tmsh modify sys db log.sdmd.stdout value enable


The sdmd.out file is located in /var/tmp/.
Debug logging can be viewed from /var/log/ltm.
