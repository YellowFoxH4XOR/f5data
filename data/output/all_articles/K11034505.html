Description

Configuration does not load, with the following error:

01070317:3: profile /Common/clientssl-insecure-compatible's key and certificate do not match Unexpected Error: Loading configuration process failed.

Environment

Upgrade or configuration load.

Cause

Certificate and key of default clientSSL profile /Common/clientssl do not match. /Common/clientssl-insecure-compatible inherits its certificate and key from this profile.

Recommended Actions

Perform the following steps to resolve this issue:

  1. Regenerate the default certificate and key:

    openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -keyout /config/ssl/ssl.key/default.key -out /config/ssl/ssl.crt/default.crt

  2. Edit the /config/bigip.conf file with a text editor, remove the entire ltm profile client-ssl /Common/clientssl stanza, then save the file.

  3. Reload the configuration:

    tmsh load sys config

Note: In some cases the GUI will continue to show a message that the config has not loaded; this is purely cosmetic and a reboot of the unit will clear this message.


Additional Information

When /Common/clientssl is removed from /config/bigip.conf, this profile will be restored to its defaults from /config/profile_base.conf, once the configuration is loaded.
