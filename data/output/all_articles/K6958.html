Known Issue

This is the result of a known issue. When running a Windows-based operating system with IPv6 installed, a Web Application Tunnel Favorite fails to display the web page for which it is configured. Instead, a blank page or error message appears, depending on your browser and configuration. Additionally, a Dynamic App Tunnel, which invokes a web browser, also fails in the same way.

Note: To determine whether IPv6 is running on your Windows system, check the Properties of your network interface for Microsoft TCP/IP version 6.

F5 Product Development tracked this issue as CR71329, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by using a Static Application Tunnel instead of a Web Application or Dynamic App Tunnel.

Alternatively, you can remove IPv6 if you do not need it. To do so, consult the documentation for your product.
