K000140869: Unable download PCAP file via rSeries GUI with "Server Error(s)" messages

Type
Support Solution
Published
2024-09-21
Updated
2024-10-01
Applies to
  • F5OS
  • F5OS-A: 1.3.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000140869

Description

Facing issue downloading PCAP via rSeries WebUI, error as per screenshot attached.

Figure: F5OS GUI PCAP Download Error

Environment

  • F5OS-A
  • rSeries
  • Configuration utility / GUI
  • File download error
  • SFTP

Cause

The file-download API is encountering a 500 internal server error via F5OS GUI are related to a known bug #1305005 as attached.

Bug ID 1305005: Error handling in F5OS file-download API

Recommended Actions

You may either perform 1 of the following options.

  1. Upgrade to the fix F5OS version "F5OS-C 1.6.1, F5OS-A 1.7.0, F5OS-A 1.5.2" as per the BUG ID
  2. SFTP with root login and download PCAP files via folder "/var/F5/system/shared/tcpdump" using SFTP client application.

Additional Information

The bug ID 1305005 tracks the fact that unhandled errors in the 'download' implementation in F5OS result in Apache error pages rather than error messages.
