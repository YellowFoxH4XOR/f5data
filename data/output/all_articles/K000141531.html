Description

You're receiving error message Import Failed: Key management library returned bad status: 400, HTML Tag-like Content in the Request URL/Body, while trying to import SSL key from Luna HSM.
During SSL certificate key import for the Key Name setting, you're using the key label from your HSM for the key you are going to import, which has "blank spaces" in name, like in example below:

My NetHSM Private Key 14

Environment

  • BIG-IP LTM
  • Luna HSM
  • SSL certificate key

Cause

Certificate Key label on your Luna HSM contains unexpected naming convention, which is rejected by BIG-IP.
This behavior is expected.

Recommended Actions

Rename SSL certificate key label stored on your Luna HSM to remove all "empty spaces" and use hyphen or underscore instead. Like in example below:

Wrong naming label: My NetHSM Private Key 14

Name label should be modified on Luna HSM to: My-NetHSM-Private-Key-14

 

To properly import SSL certificate key from NetHSM, please use steps from below article:
Managing External HSM Keys for LTM (section: Importing a key from the HSM)
