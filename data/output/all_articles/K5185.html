Known Issue

This is the result of a known issue. When you select Install and start big3d from the 3dnsmaint utility to install the big3d agent on other systems, the 3dnsmaint utility stops the big3d process on the remote system before installing the new version.

BIG-IP version 3.x did not provide the ability to stop the big3d agent using bigstart commands. As a result, the 3dnsmaint utility cannot stop big3d, and the installation of the new big3d fails. When this occurs, you will receive the following error message:

Copying proper big3d to BIG-IP <address> ...
scp: /usr/sbin/big3d: Text file busy
Sorry, copy of big3d 'big3d3*' to <address> failed

F5 Networks Product Development tracked this issue as CR27359 and CR30242.

Workaround

To work around this problem, you must log in to the affected BIG-IP, manually stop the big3d process, and manually copy the new version of big3d from the 3-DNS system. For more information about how to copy files, refer to K175: Transferring files to or from an F5 Networks system.
