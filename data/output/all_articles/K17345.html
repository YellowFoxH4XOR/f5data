Known Issue

The tmidiag utility is missing the -i option.

The tmidiag utility's -i option is typically used to ensure that all formatting has been removed from a storage device. The -i option was removed because disk initialization is now automatically performed by the system; however, the -i option was not removed from the command line help text.

Impact

The -i option is missing from the tmidiag utility and may cause confusion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Running the tmidiag utility with the -i option does not function as expected.
  • Running the tmidiag utility with the -h option displays the help text, including the following option:

    -i <disk> : initialize tmos disk
