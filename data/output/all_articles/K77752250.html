Description

ISO image upload will fail with the following error message.

  • Upload Error
  • Socket Read Failed

Environment

  • BIG-IP
  • The issue may happen during an upgrade process where you are uploading ISO images.

Cause

Unknown at time of publication.

Recommended Actions

You will need to upload the ISO image via SCP instead of the Configuration Utility (GUI)

  1. Use WinSCP to access the F5 BIG-IP.
  2. Upload the ISO image and the md5 file to the following directory. 
    • /shared/images
  3. Once the ISO image and md5 file has been uploaded to the F5 BIG-IP, you will need to verify the md5sum value of the ISO image is the same as the md5 file.
  4. Once the md5sum has been verified, proceed back to the Configuration Utility (GUI) and proceed with the upgrade process.
