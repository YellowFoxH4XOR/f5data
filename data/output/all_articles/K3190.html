K3190: Reasons why all certificates may not be displayed on the Cert Admin page

Topic

This is probably the result of a known issue. The Configuration utility runs out of memory when trying to load the Cert Admin page for systems that are configured with 150 or more proxies and 100 or more virtual servers.

F5 Networks Product Development tracked this issue as CR35695 and it was improved in BIG-IP version 4.5.11 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

Workaround

If upgrading is not an immediate option, you can work around this issue by performing the following steps:

  1. Log in to the command line.
  2. Edit the /etc/login.conf file.
  3. Locate the following line:

    :datasize-cur=32M:

  4. Change the line to appear as follows:

    :datasize-cur=64M:

  5. Save the file and exit the editor.
  6. Reboot BIG-IP.

This increases the amount of memory available to the Configuration utility, which should prevent the display issue.
