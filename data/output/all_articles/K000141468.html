Description

On the windows 10 client, install the Edge Client with Always Connected mode, when reboot the system, what time it will start to filter the traffic?

Environment

  • BIG-IP APM
  • Windows 10 with Edge Client
  • Always Connected mode

Cause

None

Recommended Actions

When install the Edge Client on Windows 10, it will install the service: F5 Networks Stonewall Service and F5 Networks Traffic Control Service, the startup type is Automatic.

If one service is startup earlier than F5 services, cause the Edge Client cannot filter the traffic which was generated by this services, you can configure the service dependency, make sure the service will startup when F5 Services are running.

For example, follow the article Automatically Starting Services, control the order of services.

You also can search / study this topic, work out the proper solution. Like run windows services in specific order.
