K35614055: Upgrade the performance capabilities of the i2600 platform via optional license module

Type
Support Solution
Published
2022-02-27
Updated
2024-06-06
Applies to
  • BIG-IP Platforms
  • BIG IP i2600
  • BIG-IP i2000 Series
Source
https://my.f5.com/manage/s/article/K35614055

Description

The i2600 platform has the ability to upgrade the performance level up to to i2800 specifications via an optional license module

i2600 Traffic Specifications:                                                     i2800 Traffic Specifications:

L7 requests per second: 350K                                                 L7 requests per second: 650K
L4 connections per second: 125K                                            L4 connections per second: 250K
L4 HTTP requests per second: 600K                                       L4 HTTP requests per second: 1M        
Maximum L4 concurrent connections: 14M                             Maximum L4 concurrent connections: 14M               
Throughput: 10 Gbps L4/L7                                                    Throughput: 10 Gbps L4/L7

Environment

  • i2600 Platform

Cause
      CPU processing increase due to increased traffic, and/or new SW modules installed (example DNS, ASM)

Recommended Actions

Obtain the license for the optional module: "Performance Upgrade, i26XX to i28XX"

Note: If converting to a Hybrid Flexible Consumption Plan that includes an iX600, no add-on key is required. It automatically converts to an iX800 after license reactivation.

Additional Information

For more information on applying an add-on upgrade license key, refer to K7752: Licensing the BIG-IP system. Note that a reboot of the BIG-IP system is required. You may observe a message in the /var/log/ltm file similar to the following:

emerg chmand[8725]: 012a0000:0: The system must be rebooted for some changes to take effect. This is an expected behavior when upgrading performance license.

F5 recommends performing this during a scheduled maintenance window.
