Known Issue

In BIG-IP 11.1.0, stateless address autoconfiguration (SLAAC) is incorrectly enabled on the management interface. This behavior causes the BIG-IP system to accept IPv6 router advertisements and configure IPv6 addresses and default routes in accordance with the router advertisement.

Impact

The BIG-IP system will accept IPv6 router advertisements from IPv6 routers on the management interface.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • IPv6 addresses and default routes may be present on the management interface.

Workaround

To work around this issue, you can manually disable SLAAC on the management interface and delete IPv6 addresses and routes configured through router advertisements. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Create a backup of the /config/startup file by typing the following command:

    cp /config/startup /config/startup-sol14299
  3. To disable SLAAC on the management interface, run the following commands in the order listed:
    1. sysctl -w net.ipv6.conf.eth0.autoconf=0
    2. sysctl -w net.ipv6.conf.eth0.router_solicitations=0
    3. sysctl -w net.ipv6.conf.eth0.accept_ra=0
  4. To delete IPv6 addresses and routes that were configured through router advertisements, run the following commands in the order listed:
    1. ip -6 addr flush dev eth0 dynamic
    2. ip -6 route flush default dev eth0
  5. Using a text editor, edit the /config/startup file.
  6. To ensure sysctl changes persist across a reboot, add the following lines at the end of the file:

    # SOL14299
    #
    sysctl -w net.ipv6.conf.eth0.autoconf=0

    sysctl -w net.ipv6.conf.eth0.router_solicitations=0

    sysctl -w net.ipv6.conf.eth0.accept_ra=0

    ip -6 addr flush dev eth0 dynamic

    ip -6 route flush default dev eth0
    #
    # SOL14299
  7. Save the /config/startup file and exit the editor.
