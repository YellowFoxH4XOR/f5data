Description

GUI issues viewing the Network Map option

  • Network Map appears garbled in the GUI (also known as the Configuration utility)
  • JavaScript variable names being shown instead of their values

Environment

  • Using Internet Explorer
  • Non-standard site security settings

Cause

Higher security settings in Internet Explorer version 11 disable the required JavaScript for the Network Map.

Recommended Actions

Microsoft announced the end of support for Internet explorer on June 22, 2022 and so support for it has also ended on BIG-IP. F5 recommends using other supported browsers to access the Configuration utility.

If you must use IE for the time being, add the affected BIG-IP IP address to Internet Explorer's "Trusted Sites" settings.

  1. Open an instance of Internet Explorer.
  2. Click the Tools icon.
  3. Select Internet Options > Security > Trusted Sites > Sites.
  4. In the Add this website to the zone: box, enter the BIG-IP IP address or host name prefixed with https://.
  5. Click Add.
  6. Click Close.
  7. Click OK.

Additional Information

JavaScript used by the Network Map is prevented from running due to Internet Explorer version 11 security settings. This JavaScript function was added in BIG-IP 13.1 to mitigate problems with the Network Map taking too long to load when processing an excessively large number of virtual servers and pools.
