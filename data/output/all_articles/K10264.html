Known Issue

This is the result of a known issue. If you configure the Windows antivirus checker in a pre-logon sequence, clients running F-Secure AntiVirus 5.44 may fail the antivirus check. This issue occurs when the pre-logon sequence requires that real-time protection (RTP) is enabled.

Note: RTP corresponds to the Monitor is running rule in the pre-logon sequence.

This issue occurs because the OPSWAT SDK library cannot currently detect whether RTP is enabled for F-Secure AntiVirus 5.44. OPSWAT, Inc. is aware of this issue and is tracking it as a bug.

F5 Product Development tracked this issue as CR117386 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.
