Description

What is the correct Committed Information Rate (CIR) rate limit unit for Rate Shaping with srTCM Policers?

 

Environment

vCMP host with more than one guest.

Per guest network throughput required using Rate Shaping with srTCM Policers.

Cause

Typographical error.

Note: All manuals currently state "Committed Information Rate (CIR)" is in bytes per second which is incorrect.
 

Committed Information Rate (CIR)

This is the rate, in bytes per second, that you want the BIG-IP® system to commit to the guest. For packets that are part of a flow consuming less than or equal to the CIR value, the system classifies the packets as green.

Recommended Actions

When configuring device know that Committed Information Rate (CIR) rate limit unit for Rate Shaping with srTCM Policers is in bits per second.

Additional Information

Important: When configuring Rate Shaping with srTCM, Committed Information Rate (CIR) rate is in bits per second.
