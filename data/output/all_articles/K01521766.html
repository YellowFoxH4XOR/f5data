Known Issue

The Configuration utility may fail to delete a Secure Sockets Layer (SSL) key or an SSL certificate that has a name beginning with 0 (zero).

This issue occurs when all of the following conditions are met:

  • You have an SSL key name or an SSL certificate that has a name starting with 0.

    For example:

    0zero.key

  • You attempt to use the Configuration utility to delete the SSL key or SSL certificate.

Impact

You cannot delete the SSL key or SSL certificate.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the Configuration utility, when you select the SSL key or SSL certificate and click Delete, the key or certificate does not appear on the deletion confirmation page and you cannot complete the deletion process.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to delete the SSL key or SSL certificate. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To delete an SSL key, type the following command syntax:

    delete /sys crypto key <Key_Name>

    For example, to delete an SSL key named 0zero.key, type the following command:

    delete /sys crypto key 0zero.key

  3. To delete an SSL certificate, type the following command syntax:

    delete /sys crypto cert <Certificate_Name>

    For example, to delete an SSL certificate named 0zero.crt, type the following command:

    delete /sys crypto cert 0zero.crt

  4. Save the changes by typing the following command:

    save /sys config
