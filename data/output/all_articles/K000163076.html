K000163076: F5 Insight LDAP Provider Is Not Displayed After Creation when the User Object Classes field contains an unsupported value

Type
Support Solution
Published
2026-08-25
Updated
2026-08-25
Applies to
  • BIG-IP
  • F5 Insight: 1.2.1
Source
https://my.f5.com/manage/s/article/K000163076

Description

An LDAP authentication provider can be created successfully and pass validation but fail to appear in the F5 Insight Identity Providers list. The issue can occur when the User Object Classes field contains an unsupported value, such as:

member={UserDN}


Environment

  • F5Insight
  • LDAP Authentication

Cause

An invalid value in User Object Classes prevents the LDAP provider from being displayed correctly after creation. Using:

UserDN

instead of:

member={UserDN}

 

Answer/Recommended Actions


  1. Open the LDAP provider configuration in F5 Insight.
  2. Review the User Object Classes field.
  3. Replace the unsupported value with the appropriate supported value, such as:
  4. UserDN
  5. Select Create to save the configuration.
  6. Confirm that the LDAP provider appears in the Identity Providers list.
  7. Select the provider's Inactive status to activate it.
