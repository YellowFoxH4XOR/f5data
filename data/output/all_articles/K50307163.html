K50307163: Error Message: ''Error: An upload with the same file name is already taking place. Simultaneous uploads of the same file name are not supported. at 0%''

Applies to

Source

Description

Facing issue uploading BIG-IP ISO image file to the BIG-IQ >> Devices >> Software Management >> Software Images >> Upload Image, and prompted with error as below.

"Error: An upload with the same file name is already taking place. Simultaneous uploads of the same file name are not supported. at 0%"

Environment

  • BIG-IQ
  • BIG-IP ISO image file
  • Upload Failed
  • CLI
  • SFTP

Cause

Bug ID 824081: Uploading a BIG-IP device software ISO image after a upload fails
If a BIG-IP device software ISO image fails, the image image is stored as incomplete in the "/shared/images/tmp" file. Until this incomplete image is deleted, you cannot upload another ISO image with the same name.

Recommended Actions

  1. If the bug ID824081 workaround doesn't resolve the issue, manually remove the incomplete ISO image file from "/shared/images/tmp/" folder.
    rm /shared/images/tmp/ISO_image_name.iso

  2. After that, upload via SFTP to folder "/shared/images/".
