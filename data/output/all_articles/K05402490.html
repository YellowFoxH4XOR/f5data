Source

Description

  • Application front page takes long time to render

Environment

  • After upgrade to software version v14.1.x
  • ASM security policy applied to virtual server in question
  • HTTP/2 profile applied to virtual server in question

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 829021

Recommended Actions

To workaround the issue you can enable OneConnect:

  1. On GUI go to Local Traffic  >  Virtual Servers  > Virtual Server List
  2. Click on affected virtual server
  3. On Acceleration locate OneConnect Profile and in the drop-down menu select oneconnect
  4. Click Update
