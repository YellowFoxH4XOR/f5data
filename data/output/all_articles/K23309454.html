Description

Attempts to deploy Yubikey FIDO2 Multifactor authentication using the built-in edge client browser fail

 
Environment
  • MacOS
  • APM v14.1.4
  • Yubikey
  • FIDO2
  • APM Edge Client

Cause

The built-in Edge Client browser view doesn't support advanced authentication methods like FIDO2

Recommended Actions

You will need to configure the Edge Client as an Oauth client in order to request an access token through the browser (Chrome, Edge, etc.) - instead of the embedded browser view.

Additional Information

VPN Access with MFA using Edge Client 7.2.1 and APM 16.0
