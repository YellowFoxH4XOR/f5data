Known Issue

When a managed device is removed as a LogIQ source device, the Enterprise Manager system may fail to remove the em-centlog-pub log publisher object from the managed device. This issue occurs when all of the following conditions are met:

  • The Enterprise Manager system has a BIG-IP managed device configured as a LogIQ source device.
  • The managed device is provisioned with any of the following modules:

    • BIG-IP AFM
    • BIG-IP ASM
    • BIG-IP PSM
  • The managed device is configured with a logging profile that points to the em-centlog-pub as a log destination.

When a managed device is added as a LogIQ source device, the Enterprise Manager system automatically creates the following objects on the managed device:

  • A pool with the name em-centlog-pool that has the Enterprise Manager system as a pool member
  • A Remote high-speed logging (HSL) log destination with the name em-centlog-pool-dest that points to the em-centlog-pool as the destination pool
  • A Remote Syslog log destination with the name em-centlog-remote-syslog-dest that points to em-centlog-pool-dest as the HSL Destination
  • A log publisher with the name em-centlog-pub that points to em-centlog-remote-syslog-dest as its log destination

When a managed device is removed as a LogIQ source device, the Enterprise Manager system automatically deletes these objects on the managed device.

Impact

The em-centlog-pub log publisher configuration is not removed from the managed device.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to remove the managed device from the LogIQ Source Devices page, the Enterprise Manager system successfully removes the managed device as a LogIQ source device but reports the following error messages in the Configuration utility and the /var/log/webui.log file:

    • Configuration utility error message:

      Remove devices had errors:<managed device name>: Some objects couldn't be removed[/Common/em-centlog-pub]
    • /var/log/webui.log file error message:

      ERROR com.f5.lunaui.em.logconfig.EmLocalApiSolrService - Remove devices had errors[400 Bad Request]: <managed device name>: Some objects couldn't be removed[/Common/em-centlog-pub]
  • The system removes em-centlog-pool, em-centlog-pool-dest, and em-centlog-remote-syslog-dest log destination configurations from the managed device, but the em-centlog-pub log publisher configuration remains on the managed device.

Workaround

To remove the em-centlog-pub log publisher configuration from the managed device, you can either remove the logging profile that is referencing the em-centlog-pub log publisher, or configure the logging profile so it logs to a destination other than the em-centlog-pub log publisher. To do so, perform either of the following procedures:

Impact of workaround: None

Configuring the logging profile to log to a different destination

  1. Log in to the Configuration utility on the managed device.
  2. Navigate to Security > Event Logs > Logging Profiles.
  3. Click the name of the logging profile that is referencing the em-centlog-pub log publisher.
  4. Change all Publisher options that are currently referencing the em-centlog-pub log publisher to a publisher other than em-centlog-pub.
  5. To save the changes, click Update.
  6. Navigate to System > Logs > Configuration > Log Publishers.
  7. Select the em-centlog-pub log publisher.
  8. To remove the selected log publisher, click Delete.
  9. To confirm the removal, click Delete again.

Removing the logging profile

  1. Log in to the Configuration utility on the managed device.
  2. Navigate to Security > Event Logs > Logging Profiles.
  3. Click the name of the logging profile that is referencing the em-centlog-pub log publisher.
  4. To remove the selected logging profile, click Delete.
  5. To confirm the selected logging profile removal, click OK.
  6. Navigate to System > Logs > Configuration > Log Publishers.
  7. Select the em-centlog-pub log publisher.
  8. To remove the selected log publisher, click Delete.
  9. To confirm the removal, click Delete again.
