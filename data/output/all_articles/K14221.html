Issue

Error Message

notice mcpd[<pid>]: 01070408:5: Deleting abandoned subscriber connection for reflector_Subscriber

In this error message, note the following:

  • <pid> is the unique process ID of the mcpd process running on your system.

For example:

notice mcpd[3312]: 01070408:5: Deleting abandoned subscriber connection for reflector_Subscriber

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The mcpd process has lost its subscriber connection to an external process.

This error message typically does not indicate an issue with the BIG-IP system; the system should recover automatically. If the error persists, it may indicate additional instances of the syslog-ng process are erroneously running. Only one instance of the process should be running. Refer to the Recommended Actions section for steps to resolve.

Impact

None

Recommended Actions

Impact of procedure: Logging is interrupted while the syslog-ng process restarts.

  1. Check if multiple instance of the syslog-ng process are running, by typing the following command:
    ps | grep syslog | grep -v grep

    The following example shows additional instances of the syslog-ng process are erroneously running:

    2337 ? Ssl 0:04 /usr/sbin/syslog-ng -F -p /var/run/syslogd.pid
    5866 ? S 0:00 supervising syslog-ng
    5867 ? Ssl 0:00 syslog-ng
    5970 ? S 0:00 supervising syslog-ng
    5972 ? Ssl 0:00 syslog-ng
    6154 ? S 0:00 supervising syslog-ng
    6155 ? Ssl 0:00 syslog-ng
    6176 ? S 0:00 supervising syslog-ng
    6177 ? Ssl 0:00 syslog-ng
  2. If only one syslog-ng process is running and the error message persists, stop the procedure and contact F5 Technical Support.
  3. If multiple syslog-ng processes are erroneously running, type the following command to terminate all instances:
    killall syslog-ng
  4. Verify that all processes have terminated using the following command:
    ps | grep syslog | grep -v grep
  5. Start one process by typing the following command:
    bigstart start syslog-ng
    Note: If you encounter a binding socket error when attempting to start syslog-ng, refer to K16505058: Error Message: Error binding socket; addr=&#39;AF_UNIX(/dev/log)&#39;, error=&#39;Address already in use (98).
