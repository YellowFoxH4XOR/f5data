Description

A web application fails to load or function correctly when accessed through BIG-IP APM Portal Access. Symptoms include incomplete page rendering, repeated or malformed URL rewrite patterns (e.g., multiple /f5-h-$$ tokens), and JavaScript errors in the browser console. Direct access to the application (bypassing APM) works as expected. Error logs and HAR or HttpWatch captures show that certain JavaScript files and resources are not loaded, and CORS errors may also be present. Attempts to resolve the issue using rewrite profiles and iRules (including those from K000130439 and K000148786) are unsuccessful.

Environment

  • BIG-IP APM 
  • APM Portal Access configured as a webtop resource
  • Rewrite profiles and iRules applied for URL and content rewriting
  • Application utilizes ES8+ JavaScript features and dynamic imports

Cause

The APM Portal Access rewrite engine currently supports up to ES7 JavaScript features. Applications using ES8+ features or dynamic imports are not supported and will fail to load properly. This has been identified by F5 Product Engineering and is tracked under Bug ID 1181933.

Answer/Recommended Actions

As a workaround, use LTM+APM (Web Access Management) mode for this application, which does not perform content rewriting and supports modern JavaScript:

  1. Create a new pool for the backend servers of the application.
  2. Create a new Access Profile (LTM-APM type) for authentication and session management.
  3. Create a new Virtual Server for the application, assign the pool and access profile, and do not attach a rewrite profile.
  4. (Optional) Add a webtop link if integration with other resources is required.
  5. Test and validate access to ensure the application loads and functions as expected.

Alternatively, modify the APM Access Policy to assign a dedicated pool for this application, bypassing Portal Access rewriting.

Monitor F5 release notes and subscribe to notifications for updates on Bug ID 1181933, which will add ES8+ support to APM Portal Access. This limitation is expected behavior for APM Portal Access when handling applications with ES8+ JavaScript features or dynamic imports. Applications using only ES7 or earlier JavaScript features are not affected.
