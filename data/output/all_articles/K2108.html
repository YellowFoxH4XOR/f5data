Known Issue

The BIG-IP system translates TPC/UDP to port 0 under the following circumstances:

  • Hardware acceleration is enabled. (Currently only an option on BIG-IP 2400.)
  • A pool is configured to use nodes with a wildcard port (0 or *).
  • Port translation is enabled on the virtual server using that pool (which is the default for non-wildcard virtual servers).

Note: Hardware acceleration is currently only available on BIG-IP 2400. If, under these same circumstances, hardware acceleration is not enabled on the BIG-IP 2400, this issue does not occur.

To resolve this issue, disable port translation on the virtual server that is using the pool with wildcard port nodes.

To disable port translation, type the following command where 192.168.1.1:0 is the virtual server using a pool with wildcard port nodes:

# bigpipe virtual 192.168.1.1:0 translate port disable

F5 Product Development tracked this issue as CR24090.
