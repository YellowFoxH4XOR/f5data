Known Issue

The Net-SNMP daemon, snmpd, experiences a memory leak when it polls interface statistics.

The memory leak is proportional to the number of interfaces you have configured and how often the system polls the interfaces. The larger the number of interfaces that the system polls, the faster the memory leak grows.

Impact

Over time, you may see the system performance degrade and the system may eventually become unresponsive due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You may see excessive swap file usage as the snmpd memory allocation grows. If you use the top utility, you can monitor swap file usage for the system as well as memory usage for the snmp daemon.
  • Due to excessive memory allocation or swap pressure, TMM may miss answering watchdog polls and cause a reboot. The system may log messages similar to the following example to the /var/log/ltm file, indicating a TMM process heartbeat timeout:

    01140029:5: HA daemon_heartbeat tmm fails action is failover and restart

  • The system may reboot or failover due to either a watchdog timeout or a memory leak impacting other system daemons.

Workaround

To work around this issue, you can restart the snmpd process at regular intervals outside of the polling intervals. To do so, perform one of the following procedures:

Impact of workaround: The BIG-IP system may not respond to snmp polls while the daemon is restarting.

You can use the following two options to restart snmpd:

  • Manually monitor snmpd memory usage and manually restart snmpd from the command line.
  • Restart snmpd at a regular interval using the crontab utility.

Manually monitor snmpd memory usage and restart snmpd from the command line

  1. Log in to the command line.
  2. To view the amount of memory snmpd is currently using, type the following command:

    top -n 1 -p `cat /var/run/snmpd.pid`

    Output will apper similar to the following example:

    Tasks: 1 total, 0 running, 1 sleeping, 0 stopped, 0 zombie
    Cpu(s): 28.7%us, 71.3%sy, 0.0%ni, 0.0%id, 0.0%wa, 0.0%hi, 0.0%si, 0.0%st
    Mem: 2071948k total, 1587264k used, 484684k free, 116648k buffers
    Swap: 1048568k total, 780k used, 1047788k free, 236496k cached

    PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
    3021 root 15 0 16672 9.8m 3796 S 0.0 0.5 4:46.72 snmpd

    If you want top to refresh and display updated snmp information, you can use the following syntax:

    top -p `cat /var/run/snmpd.pid`

  3. Press Control + C to exit when finished.

    In the previous example output, RES -Resident Size is reporting that the system is using 9.8 MB of physical memory. When you see this value reporting 30 MB or larger, a memory leak is occurring and you should restart snmpd to clear the leak.

  4. Restart snmpd using the following command:

    bigstart restart snmpd

Restart snmpd at a regular interval using crontab utility

This option allows you to use the crontab utility to restart snmpd. The benefit of using crontab is that you can restart snmpd without user intervention, during non-peak hours.

To create a custom crontab entry to specify the frequency at which you want snmpd to restart, perform the following procedure:

  1. Log in to the command line.
  2. Check the current crontab entries for root by typing the following command:

    crontab –l

  3. Edit the root crontab file by typing the following command:

    crontab -e

    Note: This command invokes the vi editor.

  4. Select one of the following entries to add the root crontab file, depending on the frequency at which you want snmpd restarted:

    * Daily restart

    The following entry will restart snmpd every day at 3 a.m.:

    00 3 * * * bigstart restart snmpd

    * Weekly restart

    The following entry will restart snmpd once a week on Sunday at 3 a.m.:

    00 3 * * 0 bigstart restart snmpd

  5. To enter insert mode, type i in the editor.
  6. On a new line in the root crontab file, type one of the options listed in Step 4.

    For example:

    # cron tab for root1-59/30 * * * * /usr/bin/diskmonitor
    00 3 * * * bigstart restart snmpd

  7. Press the ESC key to exit from insert mode.
  8. Simultaneously press the Shift and the colon ( : ) key.
  9. To save the changes and quit the editor, type the following command at the vi command prompt:

    wq
