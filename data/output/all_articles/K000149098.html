Description

By default, the HTTP profile Known Methods setting contains a list of the most common HTTP request methods, and by default the Unknown Method setting is set to Allow, which allows all methods regardless of whether they are known or not. 

You can configure a virtual server to reject HTTP requests for a particular HTTP method by modifying its associated HTTP profile and excluding it.

Environment

  •  BIG IP LTM
  •  HTTP Profile
  •  HTTP methods

Cause

Informational

 

Recommended Actions

Please follow the below steps to exclude the unwanted HTTP method from the allowed list

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Services > HTTP.
  3. Select the name of the affected HTTP profile.
  4. Select the Custom check box.
  5. Under Enforcement for Unknown Method, select Reject from dropdown.
  6. For Known Methods, select the method you want to block & then select Delete.
  7. Select Update.
