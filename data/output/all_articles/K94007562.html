Issue

Error Message

01070354:3: Self IP <self-ip> / <netmask>: This network is defined on two vlans (<VLAN1> and <VLAN2>)

In this error message, note the following:

  • <self-ip> is the self IP address being created.
  • <netmask> is netmask of the self IP being created.
  • <VLAN1> is one of the two VLANs with this self IP address.
  • <VLAN2> is one of the two VLANs with this self IP address.

For example:

01070354:3: Self IP 192.168.1.1 / 255.255.255.192: This network is defined on two vlans (/Common/vlan_1 and /Common/vlan_2)

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm log file
  • The Configuration utility
Description

This message occurs when the following condition is met:

  • The self IP being created resides on a network on a VLAN other than the VLAN specified during self IP creation.

Impact

The self IP address cannot be created.

Recommended Actions

Create the self IP in the current VLAN.
