Description
The interface shows "disabled" on the B4450 blade after upgrade to version 15.

  • The /var/log/ltm shows the error message as the below:
warning bcm56xxd[32498]: 4: f5optics does not support module in 1/8.0
err bcm56xxd[32498]: 012c0024:3: Unsupported optic in interface 1/8.0.
err bcm56xxd[32498]: 012c0025:3: Optic OPT-0043 in Interface 1/8.0: Unsupported on platform.
err bcm56xxd[32498]: 012c0010:3: Unsupported module in use on interface 1/8.0

Environment

  • Bi-Directional (BiDi) 40GBASE-SR4 QSFP+ optical transceiver module (OPT-0043).
  • B4450 blade.
  • Version 15.x.

Cause

This is by design, starting in version 15.0, the BIG-IP automatically disables the transceiver that is not supported.

Recommended Actions

Replace the unsupported transceiver with a supported one, please refer to related content for supported transceiver information.
