K40153417: OAuth Provider Discovery task fails with the error: "An error occurred: /Common/OAuth-Provider : Cannot delete a running task"

Description

You may be trying to configure OAuth Discovery and notice that when you start the discovery (after clicking on "start" under Discovery Task) it gets stuck in CANCEL_REQUESTED. You can observe the following error:

An error occurred: /Common/OAuth-Provider : Cannot delete a running task.

Environment

  • BIG-IP APM
  • OAuth Discovery.

Cause

The cause is unknown.

Recommended Actions

You can clear the REST framework database to attempt to resolve the issue. To do so, perform the following procedure:

Impact of procedure: The clear-rest-storage command permanently erases all Access Guided Configuration, Advanced WAF Guided Configuration, SSL Orchestrator configuration, and iAppLX REST and FAST templates on the BIG-IP. The only way to restore the configuration is from a UCS file. Do not run this command on BIG-IP devices that use these features. Skip to step 2 instead. Refer to K67220984: Clear-rest-storage. What does it do? for more information.

  1. Run the following command from the BIG-IP command line and check if the discovery process is working:
    clear-rest-storage
  2. Run the following commands from the BIG-IP command line and check the discovery process again:
    bigstart restart restjavad
    bigstart restart restnoded
  3. If the problem persists after performing the previous actions, please contact F5 Network Support.
