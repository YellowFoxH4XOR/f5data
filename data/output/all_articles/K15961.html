Known Issue

Local traffic policy actions may not load correctly during a configuration load.

This issue occurs when all of the following conditions are met:

  • The local traffic policy action refers to another policy object.
  • The local traffic policy is re-read due to a configuration load.

When certain policy actions, such as those that have external object references, like forward select pool <object>, are re-read due to a configuration load, they may not load properly into the configuration. As a result, the policy actions will no longer be executed, even though the Configuration utility and the tmsh utility show those actions are still present.  This can occur when using the tmsh load sys config command, during a full ConfigSync, or when reactivating a license.

Impact

The local traffic policy actions are not loaded into the configuration and the policy stops functioning properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H499656 on the Diagnostics > Identified > Medium|High screen.
  • After a configuration load, local traffic policies associated with virtual servers stop functioning properly.
  • Certain configured local traffic policy actions fail to function after loading the configuration, even though the actions still appear correctly in the Configuration utility.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) utility to first remove the affected local traffic policies from the virtual server, then re-apply the local traffic policies to the virtual server. To do so, perform the following procedure:

Note: You need to perform this procedure for each virtual server that is configured with affected local traffic policies.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Remove the affected local traffic policies from the virtual server using the following command syntax:

    modify ltm virtual <virtual server name> policies none

    Note: This command removes all associated local traffic polices from the virtual server. Be sure to make note of the currently associated local traffic policies in order to add them back.

    For example, to remove all associated local traffic policies from the virtual server vs_http, use the following command:

    modify ltm virtual vs_http policies none

  3. Add the affected local traffic policies back to the virtual server using the following syntax:

    modify ltm virtual <virtual server name> policies add { <affected policy name> }

    For example, to add the local traffic policy policy_example to the virtual server vs_http, you would type the following command:

    modify ltm virtual vs_http policies add { policy_example }

  4. Repeat step 3 for each local traffic policy previously associated with the virtual server.
