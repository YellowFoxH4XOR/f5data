K688: Known Issue: The Hops, RTT, and QoS load balancing modes return a single virtual server if probing is disabled

Known Issue

This is the result of a known issue. When 3-DNS is configured to use a preferred load balancing method that uses probing to gather virtual server information, and the system cannot gather the information that it needs, 3-DNS always returns the first virtual server in the wide IP.

Instead of returning the first virtual server, 3-DNS should use the alternate or fallback load balancing method. This issue occurs with the Quality of Service, Round Trip Time, and Hops load balancing methods.

F5 Networks Product Development tracked this issue as CR38193, CR38491, CR41856, and CR41858.

Workaround

To avoid this issue, enable probing factories when you use the Quality of Service, Round Trip Time, and Hop load balancing modes.
