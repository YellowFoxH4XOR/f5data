K5032: The Configuration utility adds a new wide IP alias, rather than changing the name of a wide IP

Known Issue

This is the result of a known issue. When you use the Configuration utility to change the name of a wide IP, 3-DNS and BIG-IP Link Controller instead add a new wide IP alias using the name you specified, and rename the wide IP with the name of an already existing alias.

F5 Networks Product Development is tracking this issue as CR23224, CR30212, and CR41816. Monitor future 3-DNS and BIG-IP Link Controller Release Notes for the status of these CRs.

Workaround

To work around this issue, you can change the name of the Wide IP at the command line, by performing the following steps:

  1. Log in to the command line.
  2. Edit the /config/3dns/etc/wideip.conf file.
  3. Locate the section of the file that begins with wideip {.
  4. Locate the address line that matches the wide IP you wish to change.
  5. Locate the name line within the wideip statement.
  6. Edit the name of the wide IP.

    Important: Do not remove the quotation marks from the line when editing the name.

  7. Save the file and exit the editor.
  8. Apply the configuration change, by typing the following command:

    3ndc restart
