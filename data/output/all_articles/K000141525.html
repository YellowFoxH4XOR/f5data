K000141525: Encrypting Cookies from back-end servers using HTTP Profile

Applies to

  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141525

Description

Need to encrypt all cookies from back-end servers using an HTTP profile.


Environment

BIG-IP

Cause

Need to encrypt large list of cookies from back-end servers.


Recommended Actions

In addition to encrypting persistence cookies generated from profiles on the BIG-IP, the BIG-IP can encrypt cookies using a list of cookie names attached to an HTTP profile. More information on that process can be found here:

Configuring cookie encryption within the HTTP profile (f5.com)


Below is an image of the field under advanced config where you will enter the names of the cookies you wish to encrypt. If the list is of considerable size, it is recommended to edit the list in a text editor, then paste it into this field. There is a 65,520 character limit that applies to this list, so if the list is longer than that either two profiles will need to be created or you can consider encrypting some or all of these cookies from the servers themselves.


NOTE: Leaving this field blank will not encrypt all cookies, and there is no option to encrypt all cookies using an HTTP profile.
