K000156619: The Requested URL was rejected. Support ID and violation logs indicate an "Illegal redirection attempt"

Type
Support Solution
Published
2025-09-24
Updated
2026-01-30
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000156619

Description

When accessing an application protected by BIG-IP ASM, users encounter the error: "The Requested URL was rejected. Please consult with your administrator." Support ID and violation logs indicate an "Illegal redirection attempt" occurs when the application tries to redirect users to an external authentication domain (e.g., screening.aetna.com).

Environment

  • Product: BIG-IP ASM (Application Security Manager)
  • Software Version: 17.1.x
  • ASM policy protecting a web application that performs redirects to external domains for authentication.

Cause

The target domain for redirection (e.g., domain.abc.com) is not included in the ASM policy's "Redirect Domains" list. As a result, legitimate redirects are blocked by the Application Security Policy as potential open redirect attempts.

Recommended Actions

  • Add all legitimate external domains used for authentication or other business purposes to the "Redirect Domains" list in your ASM security policy.
    • Navigate to Security > Application Security > URLs > Redirect Domains in the BIG-IP GUI.
    • Add each required external domain (such as domain.abc.com).
  • Review violation details and event logs to identify any additional domains that may need inclusion.
