K000161772: Configuration loading error Invalid Virtual Address, the IP address 0.0.0.0 already exists after upgrade to 17.5.1.6

Type
Support Solution
Published
2026-06-17
Updated
2026-07-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000161772

Description

After upgrading BIG-IP LTM to 17.5.1.6, configuration loading failed with the error:

"0107176c:3: Invalid Virtual Address, the IP address 0.0.0.0 already exists. 
Unexpected Error: Validating configuration process failed."

The issue was triggered when two partitions both using route domain 0, referenced the same IP address via a named virtual address object and a traffic-matching-criteria-based virtual server.

Environment

  • BIG-IP LTM, version 17.5.1.6
  • Two partitions: both configured with default route domain 0
  • Both partitions reference the same IP address (0.0.0.0) via:
  • Named virtual address object in Common
  • Traffic-matching-criteria-based virtual server

Cause

Bug ID 2313477

Answer/Recommended Actions

Upgrade to a fixed version/request EHF

Additional Information

None
