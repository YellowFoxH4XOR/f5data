Description

While trying to enable root account, or enable Bash access by running "tmsh modify /sys db systemauth.disablebash value false" command, you are unable to do that and getting following error message:

01070356:3: Root Account feature not licensed.

Environment

  • BIG-IP
  • Appliance mode enabled

Cause

Appliance mode changes behavior of the BIG-IP and disables the option to log in with root account. 

Recommended Actions

If issue is encountered on vCMP Guest, appliance mode can be disabled with GUI on vCMP Host according to the following procedure:

1. Log in to the Configuration utility of the vCMP host.
2. Go to vCMP > Guest List.
3. Select the guest you want to apply changes to.
4. For properties, select Advanced.
5. Uncheck the "Appliance mode" setting

For the BIG-IP device not being a vCMP Guest, to disable Appliance mode, you must obtain a new license from F5 and then perform a clean installation of the software.

If issue is encountered on F5OS tenant, appliance mode can be disabled from VELOS chassis partition or rSeries system according to the procedure included in K32730113: Overview of Appliance mode for F5OS on VELOS and rSeries systems
