Topic

Cumulative hotfix HF-603-4 for FirePass version 6.0.3 was removed from the F5 Download site due to issues it introduced with Active Directory authentication and Active Directory dynamic group mapping.

For more information about these issues, including resolution information, refer to the following articles:

  • K10314: After installing cumulative hotfix HF-603-4, Active Directory authentication and group mapping may fail when the memberOf attribute contains multiple values
  • K10341: After installing cumulative hotfix HF-603-4, Active Directory authentication and group mapping may fail when nested groups are enabled
