K22410024: New read-only file system for APM Clients reports 100 percent disk utilization

Type
Knowledge
Published
2018-05-01
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.1.0
  • APM Clients
Source
https://my.f5.com/manage/s/article/K22410024

Issue

Old Behavior

Prior to BIG-IP 13.1.0, BIG-IP systems provisioned with BIG-IP APM do not mount a file system dedicated for the APM Clients .iso file.

New Behavior

Beginning in BIG-IP 13.1.0, BIG-IP systems provisioned with BIG-IP APM include a new file system dedicated to BIG-IP APM clients. When the BIG-IP APM system starts, the APM Clients .iso file, for example,  /var/sam/images/apmclients-7150.2017.925.1331-3979.0.iso is mounted as a read-only file system. For example,/var/apm/mount/apmclients-7150.2017.925.1331-3979.0.iso.

Note: The specific name of the .iso file and file system mount name for subsequent versions varies to match the specific version of the APM Clients .iso file. 

Impact

As a result of being mounted as a read-only file system, the file system reports 100 percent disk utilization. This is expected behavior and is not indicative of an issue or failure.

Running the df -h command to check available disk space indicates the APM Clients file system is at 100 percent disk utilization. 

For example, on a system running 13.1.0, the df -h command outputs the APM Clients file system similarly to the following:

Filesystem            Size  Used Avail Use% Mounted on
/var/sam/images/apmclients-7150.2017.925.1331-3979.0.iso
                      261M  261M     0 100% /var/apm/mount/apmclients-7150.2017.925.1331-3979.0.iso       


However, systems configured to monitor the BIG-IP APM system, such as an SNMP management systems, may trigger a false file system capacity alarm condition when detecting the APM Clients file system being reported at 100 percent disk utilization.

Recommended Actions

If you have an SNMP management system that is triggering an alarm condition for the APM Clients file system reaching 100 percent utilization, F5 recommends configuring the SNMP management system to ignore file system capacity warnings for /var/apm/mount/* file systems.
