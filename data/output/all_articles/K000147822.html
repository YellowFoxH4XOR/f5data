K000147822: Can I overlap a domain across HTTP Load Balancers?

Description

I have 2 HTTP Load Balancers, one with a wildcard "*.example.com" and the other one with "one.example.com" and I want to know if this will cause an error.

Environment

  • F5® Distributed Cloud Console
  • HTTP Load Balancer

Answer/Recommended Actions

  • You cannot overlap a domain across HTTP Load Balancers
  • Overlapping a domain across HTTP Load Balancer will cause an error

Cause

Both these LBs are advertised on the same IP address. This will incur a HTTP 404 error.

 

Additional Information

Overlapping domains across Load Balancers will result in a config error. The best way to proceed here is to buy a separate VIP for the HTTP Load Balancer with the wildcard. 

How to contact F5® Distributed Cloud Support for more information.
