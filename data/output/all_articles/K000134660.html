Description

Some logs viewed from System >> Logs appear to be merged or mixed:

Environment

  • GUI
  • Logs

Cause

Bug ID 842669: Syslog-ng / systemd-journald cannot handle logs with embedded newlines, write trailing content to /var/log/user.log

Log entries in question have embedded carriage return (newline) characters, which are split across multiple lines.

The example in the Description of this article shows that an iRule was saved. This prints an entry to /var/log/audit containing the iRule content (including carriage returns, as the iRule is split across multiple lines).

Recommended Actions

No action is required. This is a cosmetic issue and most logs are unaffected.

ID842669 does not have a fix at the time of this article's publication.
