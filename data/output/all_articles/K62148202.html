Topic

A configuration that contains an iRule using the array command with the -exact option fails to load.

Description

When you attempt to load a configuration that contains an affected iRule, the configuration fails to load. This issue occurs when the iRule contains syntax similar to the following example:

when LB_SELECTED {
   array names myArray -exact myPattern
}

As a result of this issue, you may encounter the following symptoms:

  • The system logs messages to the console that are similar to the following:

    01070151:3: Rule [/Common/test-rule] error: /Common/test-rule:2: error: [wrong # args][array names myArray -exact myPattern

  • The system logs messages to the /var/log/ltm file that are similar to the following:

    err mcpd[<pid>]: 01070151:3: Rule [/Common/test-rule] error: /Common/test-rule:2: error: [wrong # args][array names myArray -exact myPattern]

Workaround

To work around this issue, you can modify the affected iRule to remove the -exact option from the array command and reload the configuration.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
