Issue

Error Message

01070317:3: profile /<partition>/<ssl_profile> key and certificate do not match

In this error message, note the following:

  • <partition> is the partition in which the SSL profile is located.
  • <ssl_profile> is SSL profile that contains the key and certificate that do not match.

For example:

1070317:3: profile /Common/f5_client_ssl key and certificate do not match

Message Location

You may encounter this message in the following locations:

  • The /var/log file
  • The Configuration utility
Description

This message occurs when the of the following condition is met:

  • The SSL certificate and SSL key configured in the SSL profile do not match.

When a certificate signing request (CSR) is generated, the SSL key is automatically created at the same time. After the CSR is created, you should have two files: the CSR file and the key file. The CSR is used to create an SSL certificate by either sending the CSR off to a third-party certificate authority or by signing the CSR with a local certificate authority (CA). The SSL key resides on the machine that generated the CSR and should never leave your local network. The third-party CA never has possession of the SSL key file which matches the SSL certificate.

The BIG-IP system validates the SSL certificate and key pair specified for an SSL profile. If you receive this error when you create or update an SSL profile, the SSL certificate and SSL key specified in the profile do not match each other. This commonly occurs on a BIG-IP system when you update an expiring SSL certificate and the CSR for a the new certificate is generated on a device other than the BIG-IP system. The new SSL certificate is applied to an SSL profile that is still configured to use the SSL key that matches the previously configured SSL certificate.

Impact

The certification/key validation fails and the SSL profile cannot be saved.

Recommended Actions

To resolve this issue, you need to ensure you import a matching SSL certificate and key pair to the BIG-IP system.  For information refer to K14031: Importing the SSL certificate and key using the Traffic Management Shell. 

After you import the matching SSL certificate and key pair to the BIG-IP system, you should validate the imported certificate and key pair. For information about validating a certificate and key pair, refer to K13349: Verifying SSL certificate and key pairs from the command line (11.x - 13.x).
