K43104908: Local proxy configuration from HKEY_LOCAL_MACHINE instead of HKEY_CURRENT_USER

Type
Support Solution
Published
2022-04-29
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K43104908

Description

You want to have the APM client use local proxy settings based on the machine registry keys, not the current user registry keys

Environment

  • Windows client
  • End user device is managed by an MDM
  • Proxy settings are under "HKEY_LOCAL_MACHINE" instead of the default, "HKEY_CURRENT_USER

Cause

The APM client pulls proxy configuration from [Computer\HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Internet Settings]

Recommended Actions

Modify the registry key [HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\CurrentVersion\Internet Settings::ProxySettingsPerUser] to have a value of [dword:00000000]

If the above key is set as shown, the HKLM proxy settings take precedence and HKCU is ignored.  If the value is 1 instead of 0, then current user proxy settings take precedence and HKLM is ignored.

To use the Windows Registry Editor:

  1. Log in to the affected Windows system using an account with privileges to edit the registry for the users on the system.
  2. Click Start.
  3. Select Run.
  4. In the Open box, type the following:
    regedit
  5. Click OK.
  6. Navigate to HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\CurrentVersion\Internet Settings\ folder.
  7. If there is no ProxySettingsPerUser key, then create a new key and value by right-clicking on "Internet Settings" and select "New -> DWORD (32-bit value)" and for the "Name" enter "ProxySettingsPerUser " (Case must be exact).  For the value enter 0.
    If the key already exists, simply change the value to 0.
  8. Click File and then click Exit.
