Description

Enabling the API protection feature (available with a BIG-IP APM license starting 14.1.0) on a BIG-IP "Standard" series platform results in an error message similar to the following to be displayed in /var/log/ltm:

err tmm3[PID]: 01230140:3: RST sent from 192.0.2.1:80 to 198.51.100.01:51000, [0x27d79fc:2745] API Protection feature is not licensed (Feature not licensed)
  • PID is the tmm Process ID

Environment

  • APM module is licensed and provisioned
  • API Protection enabled

Cause

This is the expected behavior.
API protection feature is currently only supported on:

  • BIG-IP iSeries platforms

  • VIPRION platforms

  • Virtual Editions

Recommended Actions

None

None
