Known Issue

This is the result of a known issue. In BIG-IP WebAccelerator 10.0.1 HF3, the /var/log/wa/pvac.log file may be flooded with large numbers of messages that include text similar to the following:

 wa_context == NULL for [TMEVT_NEW_VS_INFO]: outta here

The messages are most likely to appear during stress tests or after the pvac process restarts.

F5 Product Development is tracking this issue as CR133392.

This issue was fixed in Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems with a logical volume management (LVM) disk-formatting scheme, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Managing F5 product hotfixes for BIG-IP 10.0.x systems using the partitions disk formatting scheme.

Workaround

You can suppress the messages by typing the following command at the BIG-IP command prompt:
 
setDebugZone ZONE_PLUGIN.none

Alternatively, you can filter the log messages using the technique described in K10534: Filtering BIG-IP WebAccelerator pvac log messages.
