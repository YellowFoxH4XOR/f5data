Note: For instructions about finding the serial number or registration key for other F5 products, refer to K917: Finding the serial number or registration key of your F5 device.

The ARX serial number is located on the product information sticker. The product information sticker is stamped onto the chassis of your ARX system in the following location:

Model Location of the product information sticker
ARX6000Back of the chassis, on the lower left corner of the system
ARX4000Top of the chassis, on the front right corner of the system
ARX2500Front of the chassis, on the right side of the system
ARX2000Back of the chassis, on the left side of the system
ARX1500Front of the chassis, on the right side of the system
ARX1000Back of the chassis, on the right side of the system
ARX500Top of the chassis, on the front right corner of the system

Note: The ARX Virtual Edition (VE) systems do not have a product information sticker. You must get the serial number for an ARX VE system from the ARX CLI or ARX Manager GUI.

Display the serial number from the ARX CLI or ARX Manager GUI

Display the serial number without physical access to the ARX system, using one of the following procedures:

  • Displaying the serial number from the ARX CLI
  • Displaying the serial number from the ARX Manager GUI

Note: A small number of early ARX 500 platforms may not be able to display the ARX serial number from the ARX CLI or ARX Manager GUI. For more information, refer to K12848: ARX 500 platform may not have been programed with the chassis serial number.

Displaying the serial number from the ARX CLI

Beginning in ARX 3.x software branches, depending on the switch model, you can display the serial number from the CLI without requiring a physical inspection.

For ARX-1000 and ARX-6000 systems, the ARX system software can display the chassis serial number from the CLI beginning in the 3.x release branch.

For ARX-500 systems, the ARX system software can display the chassis serial number from the CLI beginning in the 4.x release branch.

Display the serial number from the ARX CLI by typing the following command:

show chassis chassinfo

The command output appears similar to the following example:

Note: The serial number is bold.

Identification:
 Hostname                             UUID
 ------------------------------------ --------------------------------------
 SWITCH                               cb2bec2e-bf5c-11df-b650-e1394de1c57b

 Chassis:
 Chassis Type  Model Number                          HW Ver.  Serial
 ------------  ------------------------------------  -------  -------------
 ARX-1000+     ARX1                                  B 09     03002183

 Chassis Environment:
 Base MAC Address    Power            Chassis Revision
 -----------------   --------------   ----------------
 00:0a:49:f3:33:00   Online

On an ARX VE system the show chassis chassinfo command output appears similar to the following example:

Identification:
 Hostname                             UUID
 ------------------------------------ --------------------------------------
 arx-ve1                              815f0b22-2b17-11e0-9a42-77fa59a21359

 Chassis:
 Chassis Type  Model Number                          Serial Number
 ------------  ------------------------------------  -------------
 ARX-VE        VMware                                ABCDEFG

Displaying the serial number from the ARX Manager GUI

Beginning in ARX 4.x software branches, you can display the serial number from the ARX Manager GUI without requiring a physical inspection.

The serial number is displayed on the Chassis Summary page of the ARX Manager GUI in the Serial Number field.

Important: For information about an issue where the complete serial number is not displayed in the ARX Manager GUI, refer to K10854: ARX Manager does not display the complete serial number.
