Known Issue

This is the result of a known issue. BIG-IP APM users using Firefox 3.x to access Domino Web Access (DWA) 8.5 may experience multiple issues, including but not limited to sending email, saving calendar events, setting preferences, or using the Logout button. The user may receive JavaScript error messages, which differ based on what action the user attempted.

The user might receive error messages that appear similar to the following examples:

Error: Permission denied for <https://dwa.example.com> to get property Window.name from <https://dwa.example.com>.

Error: F5_setLogoutLocation is not defined

Error: F5_Deflate_hostname is not defined
