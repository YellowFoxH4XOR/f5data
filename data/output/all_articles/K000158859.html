Description

When creating or editing a security policy, you can set a minimum accuracy level for automatically added attack signatures from factory templates in the "Learning and Blocking" settings of the security policy. This helps reduce false positives by excluding low accuracy signatures from being enabled by default.

However:

  • The minimum accuracy setting only applies to automatically added signature sets associated with factory policy templates.
  • If you manually add signature sets (e.g., Path Traversal Signatures, SQL Injection Signatures), all matching signatures—including those of lower accuracy—will be included regardless of the global minimum accuracy setting.

Environment

  • ASM attack signatures

Cause

This behavior is by design.

Recommended Actions

To disable all low Accuracy signatures you can manually enable/disable individual attack signatures within your policy:

  • Filter by "Accuracy" using the Advanced option under Attack Signatures.
  • Select all low accuracy signatures and disable them globally across the policy.
