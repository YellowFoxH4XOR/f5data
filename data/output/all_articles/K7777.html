Issue

Previously, when a Secure Sockets Layer (SSL) profile required a Client SSL certificate, and the SSL log level was set to debug, the BIG-IP system did not log a debug message when the client failed to present a certificate in the SSL handshake. However, if the client presented an invalid client certificate, the BIG-IP system would log a debug message.

Starting in BIG-IP 9.4.0, when an SSL profile requires a Client SSL certificate and the SSL log level is set to debug, the following log messages are logged to /var/log/ltm if a client fails to present a client certificate:

tmm1[5303]: 01260009:7: Connection error: ssl_hs_rx_cert:1158: no certificate (49)

F5 Product Development tracked this enhancement as CR77996.
