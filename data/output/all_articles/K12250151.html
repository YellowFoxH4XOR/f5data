Description

  • When a server with SMTP monitor is under maintenance mode won't mark the object as down, it will show it as up.
  • When monitor debug is enabled the following logs appears in /var/log/monitors/<monitor_name>
Connected to <<Server_IPaddr>> (<Server_IPaddr>) port 25 (#0)
Initial connection output "220 <node_name> <ServerType> ready at <Date>
Sending helo <domain_name>
Helo reply 250 <node_name> Hello [<Self_IP>]
Sending quit
Closing connection after quit sent
Closing connection 0
Monitor result: SUCCESS

Environment

  • BIG-IP
  • Sever under maintenance mode
  • SMTP monitor 

Cause
Under maintenance mode, the server still sends a reply with code 250 to the  SMTP monitor helo and also sends an SMTP quit command and expects the mail server to reply with code 221

Recommended Actions
Create a custom external monitor for the maintenance mode to mark the object as down
