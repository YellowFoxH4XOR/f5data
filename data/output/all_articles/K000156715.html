K000156715: After upgrade to 17.5.0 Windows users are unable to connect with Chrome or Edge Browsers

Type
Support Solution
Published
2025-09-30
Updated
2025-09-30
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000156715

Description

After upgrading BIG-IP APM from v17.1 to v17.5.1, users are unable to log in via Edge or Chrome browsers. Connections are denied at the OS check step. Only Firefox works

Environment

  • BIG-IP APM
  • Trouble to connect
  • sslvpn
  • Chrome Browser
  • Windows users

Cause

Windows 11 expression missing from Client OS check in VPE

Recommended Actions

Adjust Client OS branch rule to include Win11:

Client OS >> Windows (change link) >> From the Advanced tab make the following adjustment:

     expr {[mcget {session.client.platform}] == "Win10" || [mcget {session.client.platform}] == "Win11"}
