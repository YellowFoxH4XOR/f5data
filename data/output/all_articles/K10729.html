Known Issue

This is the result of a known issue. When migrating files between multiple filers with local CIFS group support enabled, the ARX system may experience high CPU and memory utilization, followed by multiple cores of the xsdd process. This issue occurs when the xsdd process attempts to translate a Security Identifier (SID) from the SID cache for a user account that has been deleted.

F5 Product Development tracked this issue as ARX ID 36061, and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in a hotfix available for ARX version 5.0.1. Customers affected by this issue should request the hotfix from F5 Networks Technical Support and reference this solution and ARX ID 36061.

Workaround

A temporary workaround to reduce the high CPU and memory utilization is to failover to the standby ARX system.
