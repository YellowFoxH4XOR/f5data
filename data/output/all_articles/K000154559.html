Description

DNS queries fail when all configured forwarders in the DNS Cache Profile's DNS Resolver are unreachable. The BIG-IP LTM DNS Cache Profile does not automatically fall back to recursive resolution if forwarders are down; it only attempts to use the specified forwarders for the forward zone, and if none respond, client DNS requests will fail.

Environment

  • BIG-IP DNS
  • DNS Cache Profile

Cause

The DNS Cache Profile is designed to use only the explicitly configured forwarders for a forward zone. If all forwarders are unreachable, the system does not revert to recursive resolution or perform iterative queries. This is by design.

Recommended Actions

  • Configure multiple forwarders in the forward zone's server list to ensure DNS service continuity.
  • For environments requiring automatic failover to recursive resolution, consider alternative DNS architectures or solutions outside the BIG-IP DNS Cache Profile.
  • Regularly monitor the health and availability of all configured forwarders to minimize the risk of DNS resolution failures.

Additional Information

  • There is no built-in configuration option or iRule to enable automatic fallback to recursive resolution when all forwarders are down.
