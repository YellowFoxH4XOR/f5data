Known Issue

The EUD Test 13 (Mezzanine RAM Test) may incorrectly report as FAILED on some VIPRION platforms.

This issue occurs when the following condition is met:

  • The EUD Mezzanine RAM Test is run on a VIPRION B2100 blade

Impact

None. The Mezzanine RAM Test fails, even though the memory is functioning.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The EUD Mezzanine RAM Test generates a failed message that appears similar to the following example:

    Test Complete: Mezzanine RAM Test: FAILED

  • The false test will include output that appears similar to one of the following examples:

    • ERROR: 1 core(s) failed Random Data subtest
    • ERROR: 1 core(s) failed Random XOR subtest
    • Executing Mezzanine RAM Test.............................................................................0
      child process exited abnormally
      while executing
      "exec grep -c "Random XOR: 0 0" $resultlogfile"
      (procedure "checkLog" line 12)
      invoked from within
      "checkLog $resultlogfile $cores $quickSet"
      invoked from within
      "if {$::error == 0 && $testpass3} {
      log_user 1
      prt "\n======================================================\r"
      prt "4. start hw-ddr2 memtest appl..."
      (file "/tmp/oct_memtest.exp" line 349)

      Test Begin: Mezzanine RAM Test
      This test takes up to 15 minutes to finish.
      ...............................................................................Test Complete: Mezzanine RAM Test: FAILED
  • Subsequent attempts to run EUD Mezzanine RAM Test may result in a PASSED test
