K12474: Some ARX 6000 platforms were programmed with an incorrect chassis serial number

Topic

The ARX 6000 chassis serial number is 10 digits in the following format:

mmwwyyssss

The digits are described in the following table:

DigitsDescription
mmManufacturer code. Only 02 is valid.
wwManufacturing week, represented by week 1 through 52.
yyManufacturing year.
ssssSerial number derived from the MAC address.

Note: You can use the show chassis command to view the chassis serial number.

Some ARX 6000 platforms were programmed with an incorrect manufacturing date in the chassis serial number.

Workaround

For ARX versions 4.1.3 and 5.0.5 and later, you can correct the serial number by performing the following procedure:

Note: The change-mfg-date.scr script required to correct the serial number is not included on previous ARX versions. Customers affected by this issue who are running previous ARX versions will need to contact F5 Technical Support to request assistance.

  1. Log in to the ARX CLI.
  2. Enter privileged mode by typing the following command:

    enable
  3. Program the ARX with the correct serial number by typing the following command:

    expect change-mfg-date.scr <new serial number>
  4. Verify that the Chassis section of the show chassis command displays the correct serial number by typing the following command:

    show chassis chassinfo

    The Chassis section of the command output will appear similar to the following example:

    Chassis:
    Chassis Type Model Number                         HW Ver. Serial
    ------------ ------------------------------------ ------- -------------
    ARX-6000     ARX6                                 B 20    0201311234
