Known Issue

DNS queries without the recursion desired (RD) bit set may receive responses with the RD bit set.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP DNS system (formerly known as BIG-IP GTM) is configured with a forward zone.
  • A DNS query is processed without the RD bit set.

Impact

The DNS response may have the RD bit erroneously set.

Note: This issue is cosmetic and typically does not affect acceptance of the DNS response.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When testing DNS, some DNS tools may report the DNS response as an RFC violation.
  • DNS responses to queries without the RD bit set may receive a response with the RD bit set.
