Known Issue

IP addresses associated with a BIG-IP GTM server object may not be viewable from the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to create a BIG-IP GTM server object with one or more IP addresses.
  • You then use the Configuration utility to add one or more IP addresses to a BIG-IP GTM server object.
  • You use the Traffic Management Shell (tmsh) to add one or more additional IP addresses to the BIG-IP GTM server object.
  • From the Configuration utility, you navigate to DNS > GSLB > Servers > [GTM Server Name] and then view the BIG-IP GTM server object IP addresses in the Address List box.

Impact

Only the BIG-IP GTM server object IP addresses that are added from the tmsh utility display in the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP GTM server object IP addresses appear to be missing when viewed from the Configuration utility.

Workaround

To work around this issue, you should create and add BIG-IP GTM server object IP addresses from only the Configuration utility or only the tmsh utility. If you have already used both the Configuration utility and tmsh utility, you can view the BIG-IP GTM server object IP address list by performing the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Servers.
  3. In the Name column, locate the appropriate BIG-IP GTM server name.
  4. From the same row as the server name, in the Address column, view the IP addresses.
