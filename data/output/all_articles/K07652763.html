K07652763: Local traffic policy rule names are more strictly validated

Issue

Old Behavior

Prior to version 12.0.0, a local traffic policy rule name could include the following special characters:

_ . / : % - @ ! > < *

New Behavior

Beginning in version 12.0.0, due to stricter validation, the following special characters are no longer allowed:

@ ! > < *

A local traffic policy rule name can include the following special characters:

_ . / : % -

Impact

When you upgrade to BIG-IP 12.0.0 or beyond, disallowed characters in an LTM Policy Rule name will be automatically converted to an underscore _ character.

Recommended Actions

None
