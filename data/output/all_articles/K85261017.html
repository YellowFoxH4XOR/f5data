Description

BIG-IP is intermittently creating SNMP core files.
The following log messages can be seen regularly in /var/log/ltm:

info snmpd[3883]: 0114002c:6: HA daemon_heartbeat snmpd disabled.
info snmpd[3883]: 0114002b:6: HA daemon_heartbeat snmpd enabled.

Environment

  • BIG-IP
  • DHCP enabled for management Interface
  • Snmpd cores and restarts

Cause

ID954433

Recommended Actions

Consider one of the following actions:
  1. Configure Static Management IP instead of DHCP
  2. If DHCP must be used, increase the lease time to reduce the frequency of snmpd coring.
  3. Suppress/Ignore these messages.  See K35284961

Additional Information

The DHCP lease renewal process reloads the snmpd configuration which eventually triggers ID954433.
