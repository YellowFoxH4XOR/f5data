K000137747: Regarding emails from Microsoft Azure: "Virtual machines or virtual machine scale sets are running on images that will be deprecated soon"

Description

You've received an email from Microsoft Azure, stating "Virtual machines or virtual machine scale sets are running on images that will be deprecated soon".

The email reads:

Your workloads are running on images that will be deprecated soon

You’re receiving this email because you have virtual machine and/or virtual machine scale set deployments that are running on images scheduled for deprecation./p>

One or more image versions within the plan f5-big-all-2slot-byol from the publisher, f5-networks, have been scheduled for deprecation. As of <date> you have workloads that are running on these images These workloads will continue to run and will not be impacted. However, additional instances cannot be deployed after the deprecation date, as explained below.

Impact

• Following the scheduled deprecation date, you won’t be able to deploy any additional virtual machine (VM) or virtual machine scale set (VMSS) instances using any images within these respective plans.
• Your active VM instances won’t be affected following the deprecation date.
• Your existing VMSS deployments will continue to be operational but can’t be scaled out following deprecation.

For more details on the next steps after your image is scheduled for deprecation, visit Deprecated Azure Marketplace images - Azure Virtual Machines | Microsoft Learn

Note: The version and dates included in the email may differ from the example shown above.

Environment

BIG-IP Virtual Edition running in Azure cloud.

Cause

Only the latest versions of BIG-IP Virtual Edition are available in the Azure Marketplace. 

Recommended Actions

If the Azure virtual machine installation requires an older BIG-IP TMOS version, which is no longer available through the Azure Marketplace, deploy the image from an ISO file, available from F5 Downloads page.

Note: Though the iso file may be available for download, Microsoft states that VMSS deployments can't scale out after deprecation. Refer to the links below for more information.
