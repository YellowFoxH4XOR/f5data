Known Issue

The BIG-IP system may erroneously send packets that are smaller than the specified maximum segment size (MSS) as TCP Segmentation Offload (TSO) packets and then drop them.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system has the tm.tcpsegmentationoffload database key enabled.
  • Your BIG-IP system transmits packets with a smaller value than the specified MSS.

Impact

The BIG-IP system may experience performance degradation due to dropped packets.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system drops TCP packets.

Workaround

To work around this issue, you can disable the tm.tcpsegmentationoffload database key. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure causes a temporary traffic disruption while the Traffic Management Microkernel (TMM) process restarts.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To disable the tm.tcpsegmentationoffload database key, type the following command:

    modify /sys db tm.tcpsegmentationoffload value disable

  3. To restart the TMM process, type the following command:

    restart /sys service tmm
