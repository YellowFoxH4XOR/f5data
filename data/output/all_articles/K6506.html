Issue

BIG-IP LTM attempts to mount filesystems during the boot process without specifying the filesystem type. When the mount command is run without a filesystem type, it attempts to mount filesystems using all supported filesystem types. File Allocation Table (FAT) filesystems attempt to set the codepage, and discover that the kernel is missing some modprobe modules. BIG-IP LTM will attempt to load the missing modules, and logs error messages in the /var/log/daemon.log file that appear similar to the following example:

modprobe: modprobe: Can't locate module nls_cp437
modprobe: modprobe: Can't locate module nls_iso8859-1

To avoid triggering these error messages, you can disable probing for the nls_cp437 and nls_iso8859-1 modules by performing the following procedure:

  1. Log in to the command line.
  2. Edit the /etc/modules.conf file.
  3. Add the following lines at the end of the file:

    alias nls_cp437 off
    alias nls_iso8859-1 off

  4. Save the file and exit the editor.

BIG-IP LTM will no longer attempt to load the missing modules.
