Description

BIG-IQ GUI is unavailable with the message saying: "Waiting for BIG-IQ services to become available"

When the below bash command is run the reason is shown as:

# restcurl /shared/system-started

{
  "systemStarted": false,
  "workersStarted": 2920,
  "workersAvailable": 2880,
  "reason": "System not yet started: 0 workers started in last 8 seconds, 99% of workers are available\nNo management endpoint has been set",
  "generation": 0,
  "lastUpdateMicros": 0
}

Environment

  • BIG-IQ deployed on a cloud or VM environment.

Cause

BIG-IQ is unable to obtain a management-IP and will not start until it gets one.
In the below command output it can be seen as a loopback address.

# tmsh list cm device

cm device bigiq1 {
...
    management-ip 127.0.0.1
...
}

Recommended Actions

1. Set the management IP manually via TMSH commands or using "config" utility
2. Then rerun the system setup from GUI.
