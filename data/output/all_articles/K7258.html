Known Issue

This is the result of a known issue. BIG-IP ASM does not currently support persistence for pools configured to use * All Services (service port 0). If the virtual server references a persistence profile, and the pool members are configured for service port 0, connections to the virtual server generates the following TCL error in the /var/log/ltm file:

TCL error: Prerequisite operation not in progress invoked from within
"persist add <src_ip_addr>" invoked from within "eval [subst "persist add $tmm_ts_persist_key"]"

F5 Product Development is tracking this issue as CR76474.
