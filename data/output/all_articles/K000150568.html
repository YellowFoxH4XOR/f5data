K000150568: Unable to set HA on BIG-IQ

Type
Support Solution
Published
2025-04-04
Updated
2025-04-04
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.4.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000150568

Description

When you encounter a problem while trying to put together an HA between two BIG-IQs, that can show up with these logs you should perform the recommended solution:

[WARN][20 Mar 2025 16:31:48 IST][/shared/ha/add-peer-task/xxxxxxx-xxxx-xxxx-xxxx-xxxxxxx/worker AddPeerTaskWorker] [/bin/bash, -c, /usr/bin/ha_create_pair -p 1.1.1.1 -s 1.1.1.2] failed with exit code 1, stdout: , stderr: Host key verification failed.

Environment

  • BIG-IQ
  • Discovery Addresses

Cause

Unknown at time of publication.

Recommended Actions

To solve this problem you need to follow these steps:

1.Use HA reset on both devices :

On primary device: ha_reset -f [Discovery IP Address of peer 1]
On secondary device: ha_reset -f [Discovery IP Address of peer 2]

2. Enter the following command to get uuid from the BIG-IQ:

curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

3. Log in to the BIG-IQ command line:

4. Remove the Pending or Post_Fail discovery by entering the following command syntax with uuid from step 2:

curl -X DELETE http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices/[UUID]

5. Use the following command to add BIG-IQ self-IP addresses:

curl -X POST -d '{"address":"127.0.0.1", "userName":"admin", "password":"", "httpsPort":"443"}' http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | json-format

6. Verify that the BIG-IQ system's self IP address is in the list, in an Active state, by entering the following command to get a list of all the BIG-IQ devices:

curl http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices | /usr/bin/json-format

7. After the BIG-IQ system's self IP address appears in the list, restart the restjavad service using the following command:

bigstart restart restjavad

8.Try to establish HA with Discovery Address.
