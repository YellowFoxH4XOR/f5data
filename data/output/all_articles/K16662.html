Known Issue

Datagram Transport Layer Security (DTLS) session is unexpectedly terminated when an invalid or corrupt DTLS record is received.

This issue occurs when the following condition is met:

  • The BIG-IP system receives a packet with an invalid or corrupt DTLS record.

The BIG-IP system should silently discard any packets with an invalid or corrupt DTLS record and allow the session to continue. However, a packet with an invalid or corrupt DTLS record will cause the DTLS session to be terminated.

Impact

DTLS sessions are terminated if the system receives an invalid or corrupt DTLS record.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system unexpectedly terminates DTLS sessions.
