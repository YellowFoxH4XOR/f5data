Description

How to perform a lookup of the Geolocation ISP name required for Topology Records

Environment

  • BIG-IP DNS
  • BIG-IP GTM
  • BIG-IP Geolocation IP Database

Cause

Wanting to configure ISP based load balancing using topology on BIG-IP DNS/GTM

Recommended Actions

To lookup an ISP name to use it in Topology record you will need to perform the following.

  1. Make sure you have the most up-to-date geolocation database. See K11176: Downloading and installing updates to the IP geolocation database

  2. Perform a geoip_lookup against the IPISP database file

    # geoip_lookup -f /shared/GeoIP/v2/F5GeoIPISP.dat 107.162.162.40

    Will attempt to lookup ip '107.162.162.40'
    opening database in /shared/GeoIP/v2/F5GeoIPISP.dat
    size of geoip database = 2944262, segments = 506185, version = Copyright (c) F5 Networks Inc, All Rights Reserved GEOIP2 v1, 20210628
    geoip_seek = 00000416
    geoip record ip = 107.162.162.40
    name = defense.net inc
    Scope = 16

  3. ?Note the name formatting: "defense.net inc"

  4. Create a Topology Record that references the proper name
    gtm topology ldns: geoip-isp "defense.net inc" server: datacenter /Common/external {
        order 3
        score 100
    }
