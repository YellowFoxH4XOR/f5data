Description

This article is meant to exemplify how to configure multiple ports for a single new or existing Virtual Server. It also addresses how to attach the Port List to the Virtual Server and the modifications that may need to be done to the pool members.

When setting up the BIG-IP system, you generally create a distinct virtual server for each unique combination of source or destination IP address and port number that appear in the header of incoming packets.

Essentially, this means that for every specific traffic pattern defined by these IP addresses and port combinations, there will be a corresponding virtual server to handle it. Additionally, for each virtual server, you can assign a unique collection of profiles and policies. 

Environment

This article applies to an environment that contains:

  •  Virtual Servers
  • Access to the GUI
  • Port List

Cause

None. Informational only.

Recommended Actions

Create a Port List

In order to assign a port list to a Virtual Server, it needs to be created first.

  1.  On the Main tab, click Shared Objects > Port List
  2. Click Create
  3. Choose a name for the List
  4. In the Ports field, you need to choose your selected ports and hit Add. All the ports added will be shown in the list box.
  5. Hit Update

Assign a Port List to a new or existing Virtual Server

To assign a port list that you've previously created to a new/existing virtual server on the BIG-IP, follow these steps:

  1. Log in to the BIG-IP Configuration Utility
  2. Navigate to the Virtual Servers section
  3. Create a new Virtual Server / Choose your existing Virtual Server
  4. Configure the general parameters, specify the Destination Address/Mask
  5. Scroll down to the General Properties section, in the Service Profile box, look for the Port List option, and select the port list that you previously created
  6. Continue configuring the rest of the parameters according to your needs and press Update/Finished.
  7. After saving, you should see the new virtual server listed under Local Traffic > Virtual Servers and under the Service Port column, will see the name of the Port List chosen.

Note: In the case that the pool members are listening in the same port as the Virtual Server, make sure that the pool members are configured with a port of any.

By following these steps, you can successfully assign a previously created Port List to a new/existing Virtual Server on the BIG-IP.
