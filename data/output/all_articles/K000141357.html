Security Advisory Description

An issue was discovered in libxml2 before 2.11.7 and 2.12.x before 2.12.5. When using the XML Reader interface with DTD validation and XInclude expansion enabled, processing crafted XML documents can lead to an xmlValidatePopElement use-after-free. (CVE-2024-25062)

Impact

For products with None in the Versions known to be vulnerable column, there is no impact.

BIG-IP, BIG-IP Next SPK, BIG-IP Next CNF, and Traffix SDC

This vulnerability allows a remote, authenticated attacker (unauthenticated in the case of BIG-IP Next SPK and CNF, and Traffix SDC) to cause a use-after-free issue that can lead to a denial-of-service (DoS) on the affected products.

F5 Product Development has assigned IDs 1629749, 1629753, 1629757, 1629765, and 1629773 (BIG-IP Next SPK and BIG-IP Next CNF), ID 1621205 (BIG-IP), and SDC-2563 (Traffix) to this vulnerability.

Security Advisory Recommended Actions

BIG-IP

  • To mitigate this vulnerability, you should accept or use XML files from only trusted sources. This applies to XML Content Based Routing, the wap monitor, external monitors, ASM XML profiles, and AAM image optimization.
  • Do not permit Document Type Definition (DTD) declaration in monitors or iRules that contain custom XML.
  • To mitigate this vulnerability for the ASM XML profile, enable the XML data does not comply with format settings violation in the Learning and Blocking Settings > Content Profiles section of your security policy and disable the Allow DTDs setting in your XML profiles, which will disable DTD reference declaration.
  • To learn more about the vulnerable BIG-IP components to help understand how to implement the mitigations, refer to the following:
    • K71282813: Overview of BIG-IP EAV external monitors
    • K44151603: Overview of the BIG-IP ASM XML profile
    • The Accelerating Images with Image Optimization chapter of the BIG-IP Acceleration: Implementations manual
    • The Routing Based on XML Content chapter of the BIG-IP Local Traffic Manager: Implementations manual
      Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching MyF5 and finding product documentation.
