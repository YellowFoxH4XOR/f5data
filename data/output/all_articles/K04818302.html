K04818302: Accessing network firewall policy rules that are enforced on the virtual server

Issue

Old Behavior

In versions earlier than BIG-IP 13.1.0, the network firewall rules that apply to the virtual server are displayed at the bottom of the security policy settings page, and you can configure additional rules from within this page. 

To access the network firewall rules that are configured on the target virtual server, perform the following procedure:

  1. Navigate to Local Traffic > Virtual Servers.
  2. Click the name of the virtual server.
  3. Hover over the Security tab.
  4. Click Policies.

New Behavior

Starting in BIG-IP 13.1.0, the network firewall rules are no longer managed by way of the target virtual server's Security menu option.

You can manage the network firewall policy rules by navigating to the Security module's Network Firewall Policies page. To get to this page, navigate to Security > Network Firewall > Policies.

Impact

None

Recommended Actions

You can manage the network firewall rules that are configured on the security policy by navigating to Security > Network Firewall > Policies, and clicking the name of the security policy that is enforced on the target virtual server.
