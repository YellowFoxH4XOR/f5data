Description

A Big-IP device is no longer needed in High Availability.  However when attempting to remove the device from the device-group, the following error is generated and it is not removed: 01070734:3: The floating traffic-group: /Common/<Example> can only be set on /<Test> if its device-group is inherited from the root folder.

 

Environment

BIG-IP LTMs in HA

Device group containing multiple members some of which need to be removed
 

Cause

When trying to remove BIG-IP devices that are no longer needed to be part of a device group (High Availability), the system complains with the error above and prevents the removal because of dependencies.

Recommended Actions

  1. Make sure the device is Standby or Offline
  2. Reset the device trust on the device(s) that you wish to be removed


NOTE: Resetting the device trust on a BIG-IP device will make it to be Standalone.  It will not impact the existing devices belonging to the device group or the traffic being handled by the Active device(s).
