K000152171: How to stop BIG-IP exposing its hostname via dig

Type
Support Solution
Published
2025-06-26
Updated
2025-09-30
Applies to
  • BIG-IP
  • BIG-IP DNS
  • BIG-IP GTM
Source
https://my.f5.com/manage/s/article/K000152171

Description

dig for hostname.bind against a listener IP exposes the device hostname as below:

 

$ dig @192.0.2.1 hostname.bind TXT CHAOS +short
"device.lab"

Environment

  • BIG-IP DNS formerly GTM

 

Cause

Working as intended.

Recommended Actions

The following iRule attached to the listener prevents the device to respond to this type of queries:

when DNS_REQUEST {
    if { [DNS::question class] eq "CH" } {
        drop
    }
}

 

Additional Information

None.
