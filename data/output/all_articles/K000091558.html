K000091558: NGINX Controller does not start after hostname change and reboot

Type
Support Solution
Published
2022-05-11
Updated
2022-05-11
Status
Final
Source
https://my.f5.com/manage/s/article/K000091558

Description

After an NGINX Controller node's hostname is changed and the node is rebooted NGINX Controller does not start. The NGINX Controller pods' STATUS is Pending. The following kubelet log messages, or a subset, are reported.

<date> <node_name> kubelet[868]: I0510 04:08:38.841454 868 kubelet_node_status.go:72] Attempting to register node <node_name>
<date> <node_name> kubelet[868]: E0510 04:08:38.842691 868 kubelet_node_status.go:94] Unable to register node "<node_name>" with API server: nodes "<node_name>" is forbidden: node "<previous_node_name>" is not allowed to modify node "<node_name>"
<date>  <node_name> kubelet[868]: E0510 04:08:38.875149 868 kubelet.go:2252] node "<node_name>" not found
...
<date> <node_name> kubelet[868]: E0510 04:08:39.438642 868 controller.go:125] failed to ensure node lease exists, will retry in 7s, error: leases.coordination.k8s.io "<node_name>" is forbidden: User "system:node:<previous_node_name>" cannot get resource "leases" in API group "coordination.k8s.io" in the namespace "kube-node-lease": can only access node lease with the same name as the requesting node
<date> <node_name> kubelet[868]: E0510 04:08:39.476465 868 kubelet.go:2252] node "<node_name>" not found
...
<date> <node_name> kubelet[868]: E0510 04:08:41.746021 868 eviction_manager.go:247] eviction manager: failed to get summary stats: failed to get node info: node "<node_name>" not found

 Environment

NGINX Controller

 Cause

NGINX Controller does not support node hostname change

 Recommended Actions

Change the hostname of the NGINX Controller node back to it's previous name and reboot it
