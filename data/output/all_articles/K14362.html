Issue

Error Message

% ERROR ssh command interface only works for show commands

Message Location

You may encounter this message in the following location:

  • The Linux host CLI console

Description

This message occurs when the following condition is met:

  • You attempt to use SSH to send commands that are not show-commands to an ARX system. The ARX system will return an error message that appears similar to the following example:

    root@ubuntu# ssh admin@arx1 hostname arx2
    % ERROR ssh command interface only works for show commands

Sending remote commands using SSH can be useful when attempting to manage a large network infrastructure. However, due to possible security concerns, F5 has limited the capabilities to informational commands only.

Impact

The SSH command request will fail.

Recommended Actions

If you want to administer the ARX using the command line interface, F5 recommends that you directly SSH into the ARX system before attempting to run CLI commands.
