Description

A large number of the following error messages may appear in BIG-IP ASM tmm logs: /var/log/tmm/

MAIN|EROR|dosl7_hold_message:1004|trying to hold message already held

Environment

  • BIG-IP ASM

Cause

Bug ID 1974837: This log message is related to bot defense reverse DNS (rDNS) lookups. It occurs when a client closes the connection before DNS resolution completes, resulting in a duplicate hold event being logged.

Recommended Actions

The log message is informational and does not indicate a critical failure or impact on system stability.
