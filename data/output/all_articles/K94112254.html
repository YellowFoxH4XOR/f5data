Topic

You should consider using this procedure under the following condition:

  • You have an Active Directory (AD) or Lightweight Directory Access Protocol (LDAP) pool of authentication, authorization, and accounting (AAA) servers that you would like to monitor with an LDAP monitor.

Description

AD or LDAP servers provide authentication and authorization services for BIG-IP APM users. To monitor the health of the servers, and more importantly the health of the services provided, you can configure a LDAP monitor. The BIG-IP LDAP health monitor checks the status of LDAP servers by making a directory search request and evaluating the response. For the monitor to mark the servers up, the search must return searchResDone with a resultCode of 0 (success). 

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the Configuration utility.
  • You have administrative access to the BIG-IP APM command line.
  • You already have an AD or LDAP AAA server configured that you want to monitor with an LDAP monitor.

Procedures

To configure an LDAP monitor for your AAA server, you can use the following procedures:

  • Configuring an LDAP monitor.
  • Applying the LDAP monitor to AAA server

Configuring an LDAP monitor

To configure an LDAP monitor, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility
  2. Navigate to Local Traffic > Monitors.
  3. Click Create.
  4. Enter a name for the monitor.
  5. For Type , click LDAP.
  6. For Configuration, click Advanced.
  7. Configure all settings that apply to the LDAP service you want to monitor. For example, the following list of values apply to a pool of AAA servers in the domain example.com, and user1 is any user with read permissions to AD.
    ValueExample Format
    UsernameCN=Administrator,CN=Users,DC=example,DC=com
    Password<user1_password>
    BaseCN=Users,DC=EXAMPLE,DC=COM
    Filterobjectclass=*
    Alias Service Port389 LDAP

    Note: If the monitor does not mark the pool up, you can disable Chase Referrals as a possible resolution.

  8. Click Finished.

Applying the LDAP monitor to AAA object

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility
  2. Navigate to Access > Authentication.

    Note: For BIG-IP 12.x and earlier, navigate to Access Policy > AAA Server.

  3. Click the name of the AAA server that you want to monitor with the LDAP monitor that you created earlier.
  4. For Server Connection, click the Use Pool .
  5. For Domain Controller Pool Name, enter a name if one doesn't exist.
  6. If no Domain Controllers are specified, provide the IP address and Hostname of your domain controller and click Add.
  7. For Server Pool Monitor, click LDAP monitor you created in the previous step.
  8. Click Update.
