K000137244: Big-IP AFM Cluster Sync Failed After Deleting Virtual Server

Type
Support Solution
Published
2023-10-15
Updated
2023-10-15
Applies to
  • BIG-IP
  • BIG-IP AFM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000137244

Description

You have deleted a Virtual Server and now Config Sync fails

You may see an error message similar to:

err mcpd[8787]: 01020036:3: The requested Virtual Server (/Common/ip_forward_vs) was not found

 

Environment

  • AFM Provision
  • AFM FW Rule which references a Virtual Server (Send to Virtual)

Cause

The BIG-IP Allows you to delete a Virtual Server that is referenced in an FW Rule
BZID 1367017 AFM allows to delete the virtual server which is applied in a FW rule


Workaround

If you edit the FW Rule that contains the Virtual Server, the reference will be automatically removed, so all you need to do, is open the FW Rule and Update it.

If you are not sure which FW Rule the Virtual Server was in, then run the command:

# grep <Virtual Server Name> /config/bigip_base.conf -B20

If it's a long Rule, then 20 lines before the match, may not be enough to see the name of the FW Rule, so just increase this until you find the name of the FW Rule.

If the Virtual Server was in a partition, then use:
 

for i in `find /config/ -wholename  /config/bigip_base.conf -or -path "/config/partitions/*" -name bigip_base.conf`; do grep -H <Virtual Server Name> $i -B20 ; done
