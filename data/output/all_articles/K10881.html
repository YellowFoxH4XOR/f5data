Known Issue

This is the result of a known issue. When users attempt to connect to the FirePass controller using the Windows Logon Integration (GINA) client component, the connection fails with error code 718 (PPP timeout).

Important: For FirePass version 6.0.3, this issue occurs after installing cumulative HF-603-2 or later versions of the cumulative hotfix.

Note: For information about configuring Windows Logon Integration, refer to K8092: Configuring Windows Logon Integration.

F5 Networks Product Development is tracking this issue as CR132888.

This issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
