Known Issue

The system may deselect an existing Service Provider (SP) connector when you add a new one.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as Identity Provider (IdP) with an existing SP connector.
  • Using the Configuration utility, you bind another SP connector to the IdP Service by using the Create SP Connector button.

Impact

Administrators have to manually re-select the deselected SP connector. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the Configuration utility, the system deselects an existing SP connector when you use the Create SP Connector button to bind another SP connector.

Workaround

To work around this issue, you can manually re-select the deselected SP connector. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > SAML > BIG-IP as IdP.
  3. Select the appropriate IdP service from the list.
  4. Click Bind/Unbind SP Connectors.
  5. From the list, select the appropriate SP connector.
  6. Click OK.
