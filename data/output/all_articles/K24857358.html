Description

When the RDP profile is added to the users webtop, the user cannot login to the resource page.
Logon denied due to validation error, Error Code: 3012 (Non-Network Access resource assigned)

Environment

  • RDP profile
  • Webtop
  • user cannot login

Cause

Non network access (RDP) resource for webtop type Network Access was included causing a misconfiguration.  The RDP resource requires a full webtop.

Recommended Actions

Create a full webtop. 

Additional Information

Manual Page: Configuring Webtops
