K31198402: Receiving a blank page instead of Access Policy's logon page

Type
Support Solution
Published
2020-12-28
Updated
2023-10-17
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 15.1.0
Source
https://my.f5.com/manage/s/article/K31198402

Description
When trying to hit the Access Policy's Logon Page (/my.policy), a blank page is returned instead

Environment

  • BIG-IP APM
  • Modern Logon Page

Cause
Unknown 

Recommended Actions

Clear ramcache with the next command

# tmsh delete ltm profile ramcache all


Additional Information
None
