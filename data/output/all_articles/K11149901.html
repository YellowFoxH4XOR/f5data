K11149901: F5 Access Android Compatibility

Type
Support Solution
Published
2022-09-29
Updated
2023-02-21
Applies to
  • BIG-IP
  • F5 Access
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K11149901

Description
Although there are devices running a myriad of Android versions in the market, F5 offers limited tested compatibility. This article describes the Android versions where our F5 Access App can run.

Environment

  • F5 Access App
  • Android

Cause
None. It works as designed,

Recommended Actions

F5 provides F5 App software fixes for the current major version of Android and one major version back. For older Android versions, F5 will provide configuration assistance on a case-by-case basis.
Currently, F5 Networks supports Android™ versions 11 and 12.

For software released on any vendor’s App Store, F5 provides software fixes only for the currently released version of the corresponding F5 App.
Currently: F5 Access 3.0.8

Additional Information
None.
