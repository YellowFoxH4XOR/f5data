Description

You observe messages similar to the following in /var/log/asm for various security policies:

info perl[11747]: 01310012:6: ASM bad request: event code I3984 Request has an unknown HTTP selector: /Common/sec_policy_main

You may also observe in /var/log/ts/bd.log:

did not receive account configuration after 600 seconds

Traffic for applications protected by the security policy in question is also disrupted.

Environment

  • Security policy

Cause

Bug ID 850673: BD sends bad ACKs to the bd_agent for configuration

Recommended Actions

Upgrade to a version where bug ID 850673 is fixed.

There are other conditions where Request has an unknown HTTP selector may appear. If you have ruled out bug ID 850673, open a service request with F5 Support for further investigation.

K12210419 describes another example.

Additional Information

This issue occurs when the policy configuration exists in the mysql database, but is not correctly pushed into bd for enforcement. The bd_agent daemon is responsible for this.
