Topic

Summary

BIG-IP AAM and BIG-IP WOM systems configured as tunnel endpoints should run software versions within one minor version of each other.

Description

When two BIG-IP AAM systems, or two BIG-IP WOM systems, are configured as iSession tunnel endpoints, F5 recommends that the two systems run the same software version. Deploying tunnel endpoints which run software versions more than one minor version apart is not supported, and can cause the systems to malfunction or generate core files.

For example, a BIG-IP AAM system running version 11.6.0 can be paired with another BIG-IP AAM system running 11.6.0 or 11.5.x. A BIG-IP AAM system running 11.5.0 is compatible with a system running 11.5.x or 11.4.x.

Recommendations

When configuring iSession tunnel endpoints, you should verify that the two endpoint systems are running the same version of software, or are running software versions within one minor version of each other.
