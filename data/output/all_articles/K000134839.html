K000134839: Using proxy the Update Check does not work

Type
Support Solution
Published
2023-05-30
Updated
2023-06-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.X.X, 16.1.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000134839

Description

When configuring proxy for internet access for the BIG-IP update check [System ›› Software Management : Update Check] the request is not completed when a proxy inserts a header in its response

Environment

  • Update Check
  • proxy configuration

Cause

ID1301317: Update check request is not completed with a proxy inserting header in its response

Recommended Actions

At the time of publishing this article there is no fix/workaround available for the BUG ID1301317.

If possible reconfigure the proxy to not return headers in the response packet.

Additional Information

None
