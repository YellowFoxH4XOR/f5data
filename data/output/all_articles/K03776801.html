Known Issue

IPsec log messages in the /var/log/ltm file are missing the module ID needed to reach the BIG-IQ logs.

This issue occurs when the following condition is met:

  • IPsec log messages do not include the IPsec module subset ID.

Impact

The BIG-IQ logs do not include IPsec messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Some groups of messages logged by the tmipsecd process are missing the errdefs annotation that identifies IPsec as the module. Messages reported when tunnels go up and down or issues with listeners, reach only the LTM logs, with no visibility to the BIG-IQ logs.
