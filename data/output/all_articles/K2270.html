Topic

Firewall and NAT

A typical firewall configuration uses a NAT (Network Address Translation) to allow secure access to a specific device (such as a 3-DNS Controller) located behind the firewall. The NAT at the firewall translates the inbound IP address and the outbound source address to that of the 3-DNS Controller (typically an RFC 1918 non-routable address).

The IP address of the 3-DNS Controller located behind the firewall is translated by the NAT. Therefore, the address seen by those viewing the site outside of the firewall (through the Internet) is different than the physical IP address of the 3-DNS Controller. You must configure a 3-DNS Controller using its own IP address, which is listed in the wideip.conf file.

Configuring a 3-DNS Controller behind a firewall

  1. Log in to the Configuration utility.
  2. Select Servers and then 3-DNS.
  3. From the 3-DNS list, select the 3-DNS that is behind the firewall.
  4. From the top menu bar, select Self IP List.
  5. From the top menu bar, select Add a Self IP.
  6. In the spaces provided, enter the new self IP address, as well as the routable NAT IP address for the 3-DNS that resides behind the firewall.
  7. Click Add.

The local 3-DNS Controller will now recognize itself as the actual self IP, and the it will also recognize the remote 3-DNS Controllers as the NAT IP on the firewall.

Note: Unlike previous versions of 3-DNS, no other configuration is necessary.
