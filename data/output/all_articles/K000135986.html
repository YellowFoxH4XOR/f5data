K000135986: Reject Virtual Server may not work if setting a network segment as source IP addresses

Description

A Reject virtual server specifies that the BIG-IP system rejects any traffic destined for the virtual server IP address.
The kind of virtual server is able to work with other types of virtual servers to block network access to service.

Virtual servers are usually configured to receive traffic, but sometimes it is necessary to block access to certain IP addresses. In this case, Reject Virtual Server is an option.


Symptoms

In BIG-IP 13.x, if the source address configured in the Reject Virtual Server is a network segment, for example 192.0.2.0/24, the reject virtual server will not work.
 

Environment

  • LTM
  • Reject Virtual Server
  

Condition

Reject Virtual Server with a network segment as source IP address, for example 192.0.2.0/24.

 
Workaround

The issue can be mitigated on BIG-IP 13.x by restarting TMM.
# bigstart restart tmm

Impact of workaround:Please perform these workaround in maintenance window. Restarting TMM process will interrupt traffic processing on the BIG-IP system.
 

Recommended Action

This issue was not found in the release after BIG-IP 13.x, recommend upgrade software version to at least BIG-IP 14.x.
