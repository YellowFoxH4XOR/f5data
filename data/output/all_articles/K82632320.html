Description

/var/log/ltm logs similar to below error message:

err tcl_monitor: PID: * (_check_memory_above_limit): worker exceeded memory buffer limit 10 initial memory size * current memory size *

Environment

  • BIG-IP v12.x and before
  • IMAP monitor is set
     

Cause

IMAP monitor received large data, due to it has a large Email on the backend server. IMAP uses TCL, and TCL has memory limit. Thus this error is logged, but this should not cause monitor to fail.

The initial 10 MB of memory that was assigned to the "worker" , has been reached, the monitor will be performed and the worker will be restarted right after, to release memory. That means that it should not cause the monitor to go down, and by constantly freeing up the memory we are making sure that the monitor will not overwhelm the memory.
 

Recommended Actions

You can safely ignore this message.
From v13 and over IMAP monitor will not FETCH, so this should not appear on the /var/ltm/log.
