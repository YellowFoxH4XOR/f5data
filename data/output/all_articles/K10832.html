Known Issue

This article applies to BIG-IP version 9.x and 10.x. For information about other versions, refer to the following article:

  • K13154: Windows Media extensions and mimeTypes are not included in the Audio/Video Media object type list (11.x)

This is the result of a known issue. BIG-IP WebAccelerator does not associate the Audio/Video Media object type with all of the file extensions and MIME types used by Windows Media. This behavior may cause rendering issues when the browser attempts to hand off these objects to an external application.

Windows Media uses the following extensions and MIME types:

ExtensionMIME type
.wmaaudio/x-ms-wma
.wmvaudio/x-ms-wmv
.wmaudio/x-ms-wm
.wmxaudio/x-ms-wmx
.waxaudio/x-ms-wax
.wvxaudio/x-ms-wvx
.asfaudio/x-ms-asf
.asxaudio/x-ms-asf

F5 Product Development is tracking this issue as ID 223843 and ID 223451 (formerly CR132240 and CR129834).

Workaround

You can add the appropriate extensions and MIME types to the Audio/Video Media object type by performing one of the following procedures:

Version 10.x

  1. Log in to the BIG-IP WebAccelerator Configuration utility. 
  2. Navigate to Configuration >> Policies >> Object Types.
  3. Select the Audio/Video Media predefined object type.
  4. Add wma, wmv, wm, wmx, wax, and wvx to the Extensions list.
  5. Add audio/x-ms-wma, video/x-ms-wmv, audio/x-ms-wax, and video/x-ms-wvx to the MIME-types list.
  6. To save the modified configuration, click Save.

Version 9.4.x

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa

  3. Back up the original globalfragment.xml file by typing the following command:

    cp globalfragment.xml globalfragment.xml.sol0832

  4. Open the globalfragment.xml file in a text editor.
  5. Locate the media objType entry. 
  6. Edit the ext= section of the media objType object, adding wma, wmv, wm, wmx, wax, and wvx to the list of extensions.
  7. Edit the mimeType section of the media objType object, adding audio/x-ms-wma, video/x-ms-wmv, audio/x-ms-wax, and video/x-ms-wvx to the list of mimeTypes.
  8. Save the globalfragment.xml file.
  9. Restart the pvac daemon by typing the following command:

    Important: Restarting the pvac daemon will briefly disrupt connections, and invalidate objects in the BIG-IP LTM RAM Cache. Restarting the pvac daemon should be scheduled accordingly. 

    bigstart restart pvac
