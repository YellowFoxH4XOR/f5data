Known Issue

When you create an SSL proxy, you must use individual IPv4 address. Do not use network addresses for SSL proxies.

For SSL proxy ports, use numbers in the range of 0 to 65535. Do not use any characters other than numbers.

Important: BIG-IP does not check for invalid characters, so it is important that you enter the SSL proxy information carefully. If you enter an SSL proxy with invalid characters, BIG-IP will not function properly.

F5 Networks Product Development tracked this issue as CR40861 and CR41861.
