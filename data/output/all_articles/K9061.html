Master groups and resource groups

A master group is a collection of users. A resource group is a collection of resources, access control lists, and protection criteria. Each user who connects to the FirePass controller is associated with only one master group, but you can statically assign multiple resource groups to a single master group. Additionally, if you configure dynamic resource group mapping, multiple resource groups can be dynamically assigned to a user at logon time.
 
Note: For more information about master groups and resource groups, refer to K3336: Overview of groups or to the FirePass Controller Administrator Guide.

Master group assignment

Information about static master group assignment, dynamic master group assignment, and master group assignment sequence is as follows:

Static master group assignment
In the FirePass Administrative Console, you configure master groups on the Users : Groups : Master Groups page. If you do not enable dynamic master group mapping, FirePass attempts to authenticate the user against each master group configured on the Users : Groups : Master Groups page. In this configuration, users are assigned to the first master group for which they successfully authenticate.
Dynamic master group mapping

In the FirePass Administrative Console, you configure dynamic resource group mapping on the Users : Groups : Dynamic Group Mapping page. Additionally, you must enable dynamic master group mapping in the master group configuration on the Users : Groups : Master Groups page under the General tab.

Note: For instructions about configuring dynamic master group mapping, refer to the FirePass Controller Administrator Guide.

Master group assignment sequence
If you are running FirePass version 6.x, FirePass performs the following sequence at user logon:
  • FirePass queries any external servers that are configured with dynamic mapping methods and attempts to match the user to a master group based on entries in the master group mapping table. If there is a match, the user is assigned to that master group and this sequence ends.

    Note: If a user matches more than one entry in the master group mapping table, FirePass uses the first match it encounters. You can set the order in which matching operations occur by specifying the Priority number for the group in the master group mapping table.
  • If FirePass did not assign a master group dynamically, or if dynamic group mapping was not enabled, FirePass searches its internal user database to determine the user’s master group. If FirePass finds a match, FirePass assigns the user to the master group specified in the user account configuration and this sequence ends.
  • If there is no match in the internal user database, and the Determine the user's master group by attempting to authenticate the user in each of the fallback master groups check box is selected on the Users : Groups : Dynamic Group Mapping page, FirePass attempts to authenticate the user against the master groups listed under Fallback master groups list in the order in which they appear. If there is a match, the user is assigned to that master group and this sequence ends.
  • If FirePass is unable to assign the user to a master group, authentication fails.
If you are running FirePass version 5.x, FirePass performs the following sequence at user logon:
  • FirePass queries any external servers that are configured with dynamic mapping methods and attempts to match the user to a master group based on entries in the master group mapping table. If there is a match, the user is assigned to that master group and this sequence ends.

    Note: If a user matches more than one entry in the master group mapping table, FirePass uses the first match it encounters. You can set the order in which matching operations occur by specifying the Priority number for the group in the master group mapping table.
  • If FirePass did not assign a master group dynamically, or if dynamic group mapping was not enabled, FirePass searches its internal user database to determine the user’s master group. If FirePass finds a match, FirePass assigns the user to the master group specified in the user account configuration and this sequence ends.
  • If there is no match in the internal user database, FirePass attempts to authenticate the user against each master group configured on the Users : Groups : Master Groups page. If there is a match, FirePass assigns the user to that master group.

    Note: If a user successfully authenticates against more than one master group, FirePass uses the first match it encounters.
  • If FirePass is unable to assign the user to a master group, authentication fails.

Resource group assignment

Information about static resource group assignment, dynamic resource group mapping, and resource group assignment sequence is as follows:

Static resource group assignment
In the FirePass Administrative Console, you configure resource groups on the Users : Groups: Resource Groups page. You can statically assign resources groups to a master group on the Users : Groups : Master Groups page under the Resource Groups tab. Additionally, you can statically assign resource groups to local user accounts on the Users : User Management page.
 
Note: For more information about statically assigning resource groups to master groups or local user accounts, refer to the FirePass Controller Administrator Guide.
 
Dynamic resource group mapping
In the FirePass Administrative Console, you configure dynamic resource group mapping on the Users : Groups : Dynamic Group Mapping page. Additionally, dynamic resource group mapping must be enabled in the master group configuration on the Users : Groups : Master Groups page under the General tab.

Note: For instructions about configuring dynamic resource group mapping, refer to the FirePass Controller Administrator Guide.
 
Resource group assignment sequence
FirePass performs the following sequence at user logon, after the user is assigned to a master group:
  • If dynamic resource group mapping is enabled, FirePass consults the resource group mapping table to determine which (if any) resource groups should be dynamically assigned to the user. If there are one or more matches, FirePass assigns the resources from those resource groups to the user.
  • FirePass consults the master group configuration to determine which (if any) resource groups are statically assigned to a user’s master group. If any resource groups are statically assigned to the user's master group, FirePass assigns the resources from those resource groups to the user.
  • If the user account is local (maintained in the FirePass internal user database), FirePass consults the user configuration to see which (if any) resource groups are statically assigned to the user's account. If any resource groups are statically assigned to the user's account, FirePass assigns the resources from those resource groups to the user.
  • The FirePass presents to the user all resources received from this sequence.
