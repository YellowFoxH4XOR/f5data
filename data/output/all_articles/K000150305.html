K000150305: Same MAC address is found on multiple VLANs, even though a sufficient MAC block size is configured.

Source

Description

When configuring the MAC block size to "small" or "medium" on an F5OS appliance, VLANs may appear to share the same MAC address. This behavior can occur even when a pool of unique MAC addresses is allocated. For example, running `show net vlan` may display identical MAC addresses for multiple VLANs.

Example output:  

Net::Vlan: /Common/vlan40 Mac Address (True) 0:98:76:54:32:10  

Net::Vlan: /Common/vlan50 Mac Address (True) 0:98:76:54:32:10  

Net::Vlan: /Common/vlan60 Mac Address (True) 0:98:76:54:32:10  

Environment

  • F5OS - Appliance  
  • MAC block

Cause

When a VLAN does not have an associated interface , it defaults to using a shared or inherited MAC address rather than one from the allocated pool of unique addresses defined by the configured block size. This behavior is by design and ensures that unused VLANs do not unnecessarily consume unique MAC addresses from the pool.

For VLANs applied to specific interfaces, they inherit the interface's MAC address. If no interface is assigned, the default/shared value persists.


Recommended Actions

Verify Configuration:** Ensure that each VLAN has an associated interface if unique MAC addresses are required.

Use `show sys mac` and `show net vlan` commands to verify which interfaces and components are using specific MAC addresses.
