K000138778: Downscaling NGINXaaS deployment is not possible

Type
Support Solution
Published
2024-02-29
Updated
2026-09-25
Applies to
  • NGINX Products
  • NGINX as a Service for Azure
Source
https://my.f5.com/manage/s/article/K000138778

Description

  • You encountered the following error when scaling down NGINXaaS deployment:

'/subscriptions/<Subscription>/resourceGroups/<Resource_Group>/providers/NGINX.NGINXPLUS/nginxDeployments/<Deployment>' is invalid as it is being provisioned with state: 'Accepted'.

Environment

  • NGINXaas
  • Azure
  • Deployment Scaling

Cause

  • Deployment status is stuck in 'Accepted' state on Azure side and never transitions to any other states

Recommended Actions

  • Refresh the deployment (and the browser's page) and check the deployment status
  • If the deployment status remains in 'Accepted' state, raise a ticket with F5 support

Additional Information

  • None
