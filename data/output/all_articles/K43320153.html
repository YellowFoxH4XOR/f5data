Description
You can find similar logs on /var/log/ltm:
err mcpd[7307]: 01070827:3: User login disallowed: User (%tmui) is not an administrator, does not have a UID of zero, and has not been assigned a role on a partition.

Environment

  • Logging

Cause
The error can be caused by various BUG-IDs, including:
Bug ID 566980: Periodic error "User login disallowed" messages logged referring to user "guest"

Recommended Actions
This log can be safely ignored and no further actions needs to be taken.

Additional Information
The message simply indicates that mcpd is updating the authentication cache for this user "%tmui" internally.
