K000157348: Unexpected ASM violation IDs 200012094 and 200012095

Type
Support Solution
Published
2025-11-10
Updated
2025-11-10
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 17.5.1, 17.5.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000157348

Description

When using ASM-AttackSignatures_20250828_011606.im. you encounter a great deal of hits on Attack Signature IDs:

  • 200012094 - Apache Tomcat Multipart DoS (3)
  • 200012095 - Apache Tomcat Multipart DoS (2)

Environment

  • Using ASM-AttackSignatures_20250828_011606.im.
  • Attack Signatures 200012094 and 200012095
  • ASM/AdvWAF

Cause

Both signatures were bringing about too many false positives.

Recommended Actions

Both signatures were removed in ASU ASM-AttackSignatures_20251016_175502.im due to false positives:. Upgrade to the newest Attack Signature database.
