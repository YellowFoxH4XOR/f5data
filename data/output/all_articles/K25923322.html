Description
When upgrading a multi-module network environment where BIG-IP DNS (formerly GTM) and BIG-IP LTM (and other modules) are configured as big3d clients, there is a concern about the correct order to upgrade the devices.   The quick answer, is that it depends on the timing.   The big3d environment that underlies the communication between BIG-IP DNS and it's BIG-IP LTM Clients, is only backwards compatible.

Environment

  • BIG-IP LTM, BIG-IP GTM, and other modules if present.  
  • Upgrading to a newer version

Cause
None

Recommended Actions

Note: Always check the release notes from the version you are on, and the version you are going to for any entries related to DNS or big3d before doing an upgrade.

The underlying technical need for DNS is that the big3d server must be able to receive, manage and process requests from big3d clients.  BIG-IP DNS documentation asserts that the monitored LTM devices must run the same or newer big3d version as the DNS devices that are monitoring them. For more information, refer to K13703: Overview of big3d version management.

Note: By default, the version of the big3d running on a device follows that of the TMOS version the device is running. If the monitored LTM device is running a chronologically newer version of TMOS compared to the DNS device, performing a big3d_install from the DNS device may not install a new big3d to a monitored LTM device. For more information, refer to K000137338: big3d_install may not install new big3d version.

With that being said, there are 2 preferred methods that are commonly used to upgrade environments with DNS and LTM.

If you are staggering your upgrades, where at any time the BIG-IP DNS will have a newer version of firmware than the LTM devices:

  1. Upgrade DNS devices first, immediately followed by upgrading the big3d version on all 'client' devices.
    • Upgrade BIG-IP DNS First 
    • Upgrade the big3d client on each LTM device  to bring the big3d client version up to the DNS version.

      Note: If the monitored LTM device is running a chronologically newer version of TMOS compared to the DNS device, performing a big3d_install from the DNS device may not install a new big3d to a monitored LTM device. For more information, refer to K000137338: big3d_install may not install new big3d version.

      • (see K13312: Overview of the BIG-IP DNS big3d_install, bigip_add, and gtm_add utilities (11.x - 16.x))
    • At a future time, upgrade the BIG-IP LTM devices, to the same version the BIG-IP DNS device is on.

Otherwise: 

  1. Upgrade LTM Devices first, Then upgrade the DNS devices. 
    • Upgrade all LTM devices -  the .iso includes the matching big3d client for that firmware release.
      • this ensures the big3d client is 'newer or equal to' the BIG-IP DNS device version.
    • at a future time, as required, upgrade the BIG-IP DNS device to match the BIG-IP LTM version.
