K19206967: BIG-IQ not showing the correct diskspace for a BIG-IP

Type
Support Solution
Published
2021-02-24
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.0.X
Source
https://my.f5.com/manage/s/article/K19206967

Description
The BIG-IQ GUI under System >> BIG-IQ DATA COLLECTION >> BIG-IQ Data Collection Devices, you see that the reported disk space is not all the disk space you have available in your Data Collection Device (DCD)

Example, 

shards     disk.indices disk.used disk.avail disk.total disk.percent host           ip             node
   140      359.9mb     5.8gb       68gb     73.8gb            7    <Hostname DCD1> <IP for DCD1>  <machine id for DCD1>
   140      359.5mb     5.7gb       68gb     73.8gb            7    <Hostname DCD2> <IP for DCD2>  <machine id for DCD2>

While in your DCD device, you have available 500 GBs

sys disk logical-disk HD1 {
    mode mixed
    size 512000
    vg-free 385540
    vg-in-use 124928
    vg-reserved 0
}

Environment

  • BIG-IP
  • BIG-IQ
  • Data Collection Device Disk Space

Cause
The display under System >> BIG-IQ DATA COLLECTION >> BIG-IQ Data Collection Devices looks at the usable space for the DCD under /var not the whole disk.

Recommended Actions

None. This works as designed.

Additional Information
None
