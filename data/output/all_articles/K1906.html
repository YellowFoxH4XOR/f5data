K1906: SNATs now allow ICMP responses

Published
2010-02-27

Status
Legacy Content
Applies to

  • BIG-IP 4.X: 4.6.4
Source

Issue

When two clients send an Internet Control Message Protocol (ICMP) echo through a secure network address translation (SNAT) on the BIG-IP system, the system now routes the ICMP echo replies and the ICMP time exceeded message back to the correct client.

Also, when the BIG-IP system is configured to perform ICMP monitoring, and a client sends an ICMP echo through SNAT automap on the BIG-IP system, the system now correctly routes replies to either the BIG-IP system or the client, as appropriate.

F5 Product Development tracked this enhancement as CR25315, and it was added to BIG-IP 4.6. For information about upgrading, refer to the BIG-IP Release Notes.
