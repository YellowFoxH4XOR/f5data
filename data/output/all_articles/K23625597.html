K23625597: Deleting an existing BIG-IP APM user session

Applies to

Topic

You should consider using the procedure under the following condition:

  • You want to forcefully end a BIG-IP APM user session.

Description

You may need at some point to delete a BIG-IP APM user session before it has reached its timeout or the before the user logs out.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

To delete an existing BIG-IP APM user session, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility
  2. Navigate to the Access > Overview > Active Sessions.

    Note: For BIG-IP 11.x - 12.x, navigate to Access Policy > Manage Sessions.

  3. Locate the session you want to delete. You can use the Search box to locate a session based on objects or variables related to the session, such as a username, client IP address, or virtual server.
  4. Select the check box for the session you want to delete. You may select multiple sessions if you want to delete more than one.
  5. Click Kill Selected Sessions.
  6. Review the selected Session IDs and click Delete to confirm deletion.
