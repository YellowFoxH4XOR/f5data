Known Issue

This is the result of a known issue. Provisioning BIG-IP ASM and WebAccelerator on the same system does not allocate sufficient memory for correct operation on the following platforms:

  • BIG-IP 3900 (C106)
  • BIG-IP 6900 (D104)
  • BIG-IP 8900 (D106)
  • BIG-IP 8950 (D107)

F5 Product Development tracked this issue as ID 328303 (formerly CR139736) and ID 315321 (formerly CR139410), and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP ASM and WebAccelerator release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP 10.1.0, and in Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP 10.2.0. You may download these hotfixes, or later versions of the cumulative hotfixes from the F5 Downloads site.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Note: The custom provisioning tables introduced for the BIG-IP 3900, 6900, 8900, and 8950 platforms in Hotfix-BIGIP-10.1.0-3372.0-HF1, HotFix-BIGIP-10.1.0-3402.0-HF2, and Hotfix-BIGIP-10.2.0-1755.1-HF1 set BIG-IP WebAccelerator and ASM to nominal.
