K000134967: How to Delete ASM custom signature sets using REST API

Type
Support Solution
Published
2023-06-08
Updated
2023-06-08
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.0
Source
https://my.f5.com/manage/s/article/K000134967

Description

F5 BIG-IP iControl REST API can be used to deploy, view, modify, patch .. etc configuration objects on the BIG-IP. this article will explain how to delete ASM security custom signature sets.


Environment

  • ASM
  • Custom signature sets

Cause

None


Recommended Actions

  • To get a list of ASM security custom signature sets:

curl -sk -u user:passwd 'https://x.x.x.x/mgmt/tm/asm/signature-sets?$filter=category+eq+User-defined&$select=name,id' | jq '.items[]|[.name,.id]'

Note: update the above command with the correct credentials and IP/hostname of the BIG-IP in question.


The output should be similar to the following:


[

 "Custom_sig_s1",

 "_4si74cDZqZ8mEKysJ7BCQ"

]

[

 "Custom_sig_s2",

 "Sezt0dLHIiKs7p-CB7XNlg"

]

[

 "Custom_sig_s3",

......


  • To delete a custom signature set:

curl -sk -u user:passwd -X DELETE https://x.x.x.x/mgmt/tm/asm/signature-sets/pD-I3ktwvPSMlcNInAbz7w | jq .

Note: update the above command with the correct credentials and IP/hostname of the BIG-IP in question.


The output should be similar to the following:


{

 "filter": {

  "riskFilter": "eq",

  "accuracyFilter": "eq",

  "userDefinedFilter": "yes",

  "lastUpdatedFilter": "all",

  "accuracyValue": "high",

  "riskValue": "high",

  "signatureType": "request"

 },

 "isUserDefined": true,

 "name": "Custom_sig_s1",

 "assignToPolicyByDefault": true,

 "lastUpdateMicros": 0,

 "kind": "tm:asm:signature-sets:signature-setstate",

 "selfLink": "https://localhost/mgmt/tm/asm/signature-sets/pD-I3ktwvPSMlcNInAbz7w?ver=15.1.8",

 "defaultAlarm": true,

 "systems": [],

 "id": "pD-I3ktwvPSMlcNInAbz7w",

 "type": "filter-based",

 "signatureReferences": [

  {

   "link": "https://localhost/mgmt/tm/asm/signatures/Ki44E6eG_mDUkuQVZeTuIQ?ver=15.1.8",

   "name": "sig_1",

   "signatureId": 300000000

  }

 ],

 "category": "User-defined",

 "defaultBlock": true,

 "defaultLearn": true

}


  • If a security policy had the deleted custom signature set, due to this change, it has to be applied:

curl -sk -u user:passwd 'https://x.x.x.x/mgmt/tm/asm/tasks/apply-policy -H "Content-Type: application/json" -X POST -d {\"policyReference\":{\"link\":\"https://localhost/mgmt/tm/asm/policies/2G_HvXMjZziCAWnKuWBREg\"}} | jq .

Note: update the above command with the correct credentials, IP/hostname of the BIG-IP in question, and the ID of the security policy.
