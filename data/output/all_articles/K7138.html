Known Issue

This is the result of a known issue. In low memory situations, TMM does not check for NULL values returned from xbuf headers, which may result in a TMM crash.

F5 Product Development tracked this issue as CR69420 and it was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in BIG-IP LTM 9.3.x and 9.4.x.
