Description 

This error occurs when attempting to synchronize configurations between two BIG-IP VE devices deployed as single NIC instances in different AWS Availability Zones. Unlike typical configurations, sync operations in this setup require following specific steps outlined in the AWS Single NIC Config Sync Guide. These steps include isolating static routes in a LOCAL_ONLY partition, as self-IPs across Availability Zones are not expected to be in the same subnet.

Error Message:

Sync Failed. A validation error occurred while syncing to a remote device. Sync error on <BIG-IP>: Load failed from /Common/<BIG-IP> 01070330:3: Static route gateway <Static route IP> is not directly connected via an interface

Environment 

  • BIG-IP VE
  • Single NIC setup in AWS Cloud Provider

Cause 

In a single NIC deployment, self-IPs in different Availability Zones are not in the same subnet, making default static route configurations incompatible for sync. 

Recommended Actions

To prevent conflicts during synchronization, static routes must be moved to the LOCAL_ONLY partition.

Please refer to the procedure described in the following article:

 Configure config sync between AWS Availability Zones
