Known Issue

A vCMP guest's cluster IP address may be reset to a default value after an upgrade.

This issue occurs when all of the following conditions are met:

  • The vCMP guest has no management IP address set.
  • The vCMP guest is upgraded to a newer version of BIG-IP software.

Impact

The vCMP guests in a high-availability configuration may not function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H488408 on the Diagnostics > Identified > Medium screen.
  • The vCMP guest cluster IP address will be set to the default of 192.168.1.246.

Workaround

To work around this issue, you can log in to the vCMP host and manually set the cluster IP address for the vCMP guest after the upgrade.

Alternatively, to prevent this issue from occuring, you can log in to the vCMP host and configure a unique management IP address for the guest before upgrading.

Impact of workaround: This workaround should not have a negative impact on your system.
