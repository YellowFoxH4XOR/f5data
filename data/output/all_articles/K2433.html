Topic

Beginning in version 4.5, 3-DNS no longer uses the syncd process, or its associated packaging file /config/3dns/etc/sync_list.mandatory, to perform synchronization between 3-DNS Controllers in a sync group.

Instead, the 3dnsd process now handles all synchronization tasks, and members of a sync group now exchange digest messages amongst each other through iQuery to advertise timestamps of certain files that need to be current within the sync group. If the timestamp for any of these files changes, the 3dnsd process on the local 3-DNS Controller sends a digest message with a newer timestamp, and the remote 3-DNS Controllers connect to the 3-DNS Controller with the updated files.

The 3-DNS Controller synchronizes the following files:

  • /config/3dns/etc/wideip.conf
  • /config/3dns/include/* (consisting of all the default files in the include directory)
  • /etc/named.conf
  • Associated zone files in /config/3dns/namedb

    Note: This assumes that the 3-DNS Controller is configured to synchronize named configuration files.

If you are using NameSurfer, the following directory (as well as all the files within the directory) are also synchronized:

  • /config/3dns/namesurfer/db/*

For more information about synchronization, refer to the syncd and sync_zones man pages. For information about troubleshooting 3-DNS Controller synchronization issues, refer to K2269: Overview of 3-DNS configuration synchronization.
