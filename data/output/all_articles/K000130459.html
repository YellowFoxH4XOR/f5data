Description

Configuring X-Forwarded-For in http profile in CIS in CRD Mode

 

Environment

 

  • BIG-IP Container Ingress Services in CRD mode
  • AS3 3.40
  • Custom Resource Definitions
     

Cause

None

 

Recommended Actions

This is an example for the annotation used to build your yaml code that will be executed on the K8s or Openshift


Login to the BIG-IP VE which is managed by the BigIP Controller running on K8s or Openshift

 

Create a custom http profile in the Common partition and enable the "insert-xforwarded-for" option like in the below example

 

ltm profile http custom-http {

app-service none

defaults-from http

insert-xforwarded-for enabled

proxy-type reverse

}

 

 

 

Login to the K8s Master and create a yaml code for VirtualServer and Policy

 

Below example my-policy.yaml

 

apiVersion: cis.f5.com/v1
kind: Policy
metadata:
  labels:
    f5cr: "true"
  name: sample-policy
  namespace: dev
spec:
  snat: auto
  profiles:
    tcp:
      client: /Common/f5-tcp-lan
      server: /Common/f5-tcp-wan
    udp: /Common/udp
    http: /Common/custom-http      <------!! define the name of the custom http profile here that was created on the BIG-IP in Common partition
 

Now define the policy that is created above on the below VirtualServer yaml

 

my-virtual-server.yaml

apiVersion: cis.f5.com/v1
kind: VirtualServer
metadata:
  labels:
    f5cr: "true"
  name: vs-with-policy
  namespace: dev
spec:
  host: foo.example.com
  persistenceProfile: "none"
  iRules: []
  policyName: sample-policy
  pools:
    - monitor:
        interval: 13
        recv: a
        send: /
        timeout: 10
        type: http
      path: /foo
      service: f5-demo-dev
      servicePort: 80
  snat: auto
  virtualServerAddress: 10.1.1.121
 

Once done then execute the yaml as below

 

root@control:~# kubectl create -f my-policy.yaml

policy.cis.f5.com/sample-policy created

 

root@control:~# kubectl create -f my-virtual-server.yaml

virtualserver.cis.f5.com/vs-with-policy created

 

Now you should be able to see on the BI-IP VE under the kubernetes partition the below configuration for the Virtual Server

 

ltm virtual crd_10_1_1_121_80 {

description Shared

destination /kubernetes/10.1.1.121:http

ip-protocol tcp

mask 255.255.255.255

partition kubernetes

persist {

/Common/cookie {

default yes

}

}

policies {

crd_10_1_1_121_80_foo_example_com_policy { }

}

profiles {

/Common/custom-http { } <----- custom HTTP profile

/Common/f5-tcp-lan {

context clientside

}

/Common/f5-tcp-wan {

context serverside

}

}

serverssl-use-sni disabled

source 0.0.0.0/0

source-address-translation {

type automap

}

translate-address enabled

translate-port enabled

vs-index 8

}
