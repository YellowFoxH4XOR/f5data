Topic

This Solution provides an example of how to assign a specific IP address to a client when they log on using Advanced Session Variables (ASV). In this example, the user will use client certificate authentication. The client certificate will hold information that the FirePass examines using ASV. The output from the ASV is then used in Network Access to assign the specific IP address.

Note: For more information about ASV, refer to K10108: Overview of Advanced Session Variables.

Client Certificate

Each organization that uses client certificates for authentication will have individual standards on what information is used when creating the certificate. For this approach to work correctly, one field of the certificate must be dedicated to holding information regarding which IP address that client should be assigned. If information is in the dedicated field that does not adhere to the convention used in the ASV, authentication attempts will fail.

In the following example, the OU field has the IP address to which the client machine will be assigned:

OU= myIPis192.168.10.10

Important: If multiple certificates will be used simultaneously, each client certificate will need to have a different IP address in the OU field.

Note: If you would like to use a different field, make sure that the field you want to use is reflected in your configuration.

Using a client certificate to assign an IP address

To use a client certificate to assign an IP address, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Create client certificate with the IP information that ASV will examine.

    Note: For more information, refer to the documentation provided by your Certificate Authority vendor.

  3. Install the client certificate on the client machine.

    Note

    : For more information, rever to the documentation provided by your operating system vendor.
  4. Configure FirePass to prompt for client certificate for authentication.

    Note: For detailed instructions, complete steps 1 through 14 of the procedure located in K8392: Configuring passwordless authentication using client certificates.

  5. Create an ASV.
  6. Configure Network Access to inspect the ASV output to determine the IP address.

Creating a new Advanced Session Variable

To create a new ASV, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users : Session Variables screen.
  3. Click on the Add New Session Variable link.
  4. In the Name field, enter the ASV name.
    For example:
     

    GetIPAddress

  5. In the Description field, enter a short summary of what this ASV will do.
    For example:

    Extract users' IP from their client certificate

  6. In the Expression box, enter the information needed to extract the desired field from the client certificate.
    For example:

    SUBSTR(session.ssl.cert.ou,6,16)

    Note

    : The example Expression information instructs to locate the substring in an SSL certificate's OU field, start at the sixth character, and stop after 16 characters. Since the OU field says myIPis192.168.10.10, we want to disregard the first six characters (myIPis). An IP address can not be more than 16 characters (when including the decimal used to separate the octets).
  7. Click the Save and Test button.
    If the syntax is correct, a box will appear that will allow you to test your expression.
  8. In the Enter values for session variables: box, enter the text that will be found in the client certificate field you have chosen to ensure it is working properly. 
    For example:

    myipis192.168.10.10

  9. Click the Save and Test button again.
  10. Below the Enter values for session variables: box, the Variable value results will appear. If anything other than the desired IP address is there, correct your Expression and try again.

Configuring Network Access to inspect the ASV output to determine the IP address

To configure Network Access to inspect the ASV output to determine the IP address, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2.  Navigate to Network Access: Resources.
  3. In the Configure IP address Assignment section, select the Assign IP address using session variables (third priority) check box.
  4. In the Session Variable box enter the name of the ASV you created.
    For example:
    %session.asv.GetIPAddress%
  5. Click the Update button.

Users can now authenticate using a client certificate, have the IP address that machine should be assigned passed to the FirePass using ASV, and have Network Access assigned that IP address by retrieving the IP address from the ASV.
