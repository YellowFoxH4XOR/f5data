K93250514: Secondary is not actively streaming. Postgres may be down.

Type
Support Solution
Published
2022-08-08
Updated
2025-04-02
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K93250514

Description

The "Secondary is not actively streaming. Postgres may be down." message indicates that the Primary CM is unable to communicate with Secondary CM on port 5432.

Environment

  • BIG-IQ
  • HA cluster

Cause

There can be different causes for this issue such as:

  • Network connectivity issues
  • Postgres service is not running
  • Postgres service is not working as expected

Recommended Actions

Follow troubleshooting steps:
  1. Verify Postgres service is running on both Primary and Secondary CM:
    tmsh show sys service postgres
  2. Verify Postgres service is listening on port 5432:
    netstat -pano | grep 5432
  3. Review log messages for error messages:
    /var/log/postgres/postgresql-YYYY-MM-DD.log
  4. Check status of interfaces:
    tmsh show net interface
  5. Test connectivity in both directions using Telnet:
    telnet <IP address> 5432
  6. Run simultaneous packet captures to see if traffic is sent and arrives at the destination:
    Self-IP: tcpdump -nni 0.0 port 5432
    Mgmt IP: tcpdump -nni eth0 port 5432

Additional Information

If the problem appears to be a network connectivity issue and unable to identify root cause, consider troubleshooting VM environment.
