K000153115: Getiing Error "503 Service Unavailable" while running API query

Type
Support Solution
Published
2025-08-21
Updated
2025-08-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000153115

Description

Error 503 Service Unavailable is encountered when running API queries on BIG-IP LTM. The error message may appear as:

503 Service Unavailable: Unable to process request /ltm/sys/version/. Service is unavailable.

Prior to this, a 401 Unauthorized error may also occur, which can be resolved by restarting the restjavad service.


Environment

API queries are being executed against the BIG-IP REST API.


Cause

The 503 Service Unavailable error is typically caused by the restnoded service becoming unresponsive or unavailable. This prevents the BIG-IP REST API from processing incoming API requests.


Recommended Actions

  • Restart the restnoded service to restore API functionality.
    • Impact: Restarting restnoded will interrupt API calls to the BIG-IP device. While the service is restarting (usually a few seconds to a minute), new API calls will not be processed.
    • No impact or disruption to traffic processing is expected; only API management operations are affected.
  • If a 401 Unauthorized error is encountered, restart the restjavad service.
  • Schedule service restarts during a maintenance window if possible to avoid disruption to API-based management tasks.
