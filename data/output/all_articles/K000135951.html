K000135951: How to add multiple DNS entries under DNS Exclude Address Space via CLI

Type
Support Solution
Published
2023-08-29
Updated
2023-08-30
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.5, 15.1.8
Source
https://my.f5.com/manage/s/article/K000135951

Description

You are configuring Network Access (VPN) with DNS Exclude Address Space list and you would like to append multiple DNS entries.
In GUI you can add one DNS entry at a time to DNS Exclude Address Space list. You can use this procedure to append multiple entries through CLI. 

Note:  that DNS Exclude Address Space is not supported on MacOS or mobile clients, and on Windows requires the optional "DNS Relay Proxy Service" be installed and running.

Environment

  • BIG-IP APM
  • Network Access
  • DNS Exclude Address Space
  • TMSH
  • CLI

Cause

None

Recommended Actions

  • Login via SSH to the BIG-IP
  • Copy network access configuration you want to modify to the file located in scf folder on your BIG-IP using bash command:
tmsh list apm resource network-access Network_Access_Example > /var/local/scf/na_example.txt

 

  • Edit created file na_example.txt using vi, nano or WINSCP editor, append multiple DNS entries and save the file
address-space-exclude-dns-name { google.com example.com example2.com example3.com }
  • Validate configuration with the command:
tmsh load sys config merge file na_example.txt verify
  • If there are no errors use below command to merge that file to the config
tmsh load sys config merge file na_example.txt
  • If there are errors like below first edit created file na_example.txt using vi, nano or WINSCP editor and remove line customization-group
Configuration error: Invalid primary key on customization_group object (Network_Access_Example_recource_network_access_customization) - not a full path 2
