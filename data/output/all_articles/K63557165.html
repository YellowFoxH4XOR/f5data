Topic

This article discusses how to discover a single BIG-IP device. For information about how to discover multiple BIG-IP devices, refer to the following article:

  • K31035272: Discovering multiple BIG-IP devices with your BIG-IQ system and importing the BIG-IP service configurations

You should consider using this procedure under the following condition:

  • You want to discover a BIG-IP device with your BIG-IQ system and import the BIG-IP service configuration(s).

Description

To manage a BIG-IP device from a BIG-IQ system, you must first allow BIG-IQ to discover the BIG-IP device and then select the BIG-IP device service configuration(s) you want BIG-IQ to manage.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to BIG-IQ.
  • You have administrative access to the BIG-IP system.
  • You have the BIG-IP device management IP or self IP address.

Procedures

Discovering a BIG-IP device with BIG-IQ and importing the BIG-IP service configuration(s)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Select the Devices tab.
  3. Select BIG-IP DEVICES.
  4. Under BIG-IP Devices, ensure that All BIG-IP Devices is selected, and select Add Device(s).
  5. (For BIG-IQ 6.1.x and later) For Device, select Add a single BIG-IP device.
  6. For IP Address, enter the management IP address or self IP address of the BIG-IP device you want to add. The address you choose depends on the network the BIG-IQ discovery address belongs to.
  7. For Port, the default value is 443. F5 recommends against modifying this value unless you have configured your BIG-IP device to be managed on a different port.
  8. Enter an administrative username and password for the BIG-IP device.
  9. Under Cluster Properties, for Cluster Display Name, select one of the following values:
    • None if the BIG-IP device is not a member of any existing DSC group and you do not want to create a new device service clustering (DSC) group for the BIG-IP device.
    • Create New if you want to create a new DSC group for the BIG-IP device. The BIG-IQ user interface displays a box for you to enter the cluster display name, which must be the same for each member in a DSC group for BIG-IQ to properly associate devices in the same DSC group.
    • Use Existing if the BIG-IP device belongs to an existing DSC group. The BIG-IQ user interface displays a list from which you can select the DSC group.
  10. If you choose a setting other than None for Cluster Display Name, Deployment Settings options display. Use the default recommended settings.
  11. Select Add to allow BIG-IQ to establish trust with the BIG-IP device and initiate the discovery process.
  12. After BIG-IQ establishes trust with the BIG-IP device, the BIG-IQ user interface displays a list of device service configurations and the statistics monitoring that you can import into BIG-IQ to manage. For Discover device service configuration, choose the device service configuration(s). For example, select the check boxes for Local Traffic (LTM) and Web Application Security (ASM) if the BIG-IP device has both BIG-IP LTM and BIG-IP ASM modules enabled and you want BIG-IQ to manage both these modules.
  13. Select Continue to allow BIG-IQ to discover the configuration of the modules you have selected in previous steps.
  14. When BIG-IQ completes the discovery of the configuration of the selected modules, under Services, the BIG-IQ user interface indicates Complete import tasks for the newly added BIG-IP device on the Devices > BIG-IP Devices page.
  15. Select Complete import tasks for the newly added BIG-IP device. The BIG-IQ user interface displays the list of configuration ready for import.
  16. Select Import for the configuration of the discovered module(s) to import the configuration into BIG-IQ.
  17. If there are any configuration conflicts, in Resolve Import Conflicts, the BIG-IQ user interface displays a list of configuration objects for which you can select the conflict resolution methods. Choose a method appropriate for your environment. For a description of the conflict resolution options, select the Help icon (?) or refer to the following list:
    • Select Use BIG-IQ to keep the object in BIG-IQ's working configuration. If you select this method for a shared object, the next time BIG-IQ deploys a configuration to that BIG-IP device, it updates the shared object to match the one on BIG-IQ.

      For example, if an HTTP profile called MyProfile with Insert X-Forwarded-For enabled is in the BIG-IQ working configuration and, on discovery of a service for BIGIP1, BIG-IQ encounters a profile called MyProfile with Insert X-Forwarded-For disabled, BIG-IQ keeps the MyProfile with Insert X-Forwarded-For setting enabled. The next time BIG-IQ deploys a configuration to the BIGIP1 device, it enables the Insert X-Forwarded-For setting of MyProfile.

    • Select Use BIG-IP to use the object from the BIG-IP device's current configuration to replace the object that is different in the BIG-IQ working configuration. If you select this method for a shared object, the next time it deploys a configuration,  BIG-IQ replaces the shared object for all of your managed BIG-IP devices.

      Continuing with the previous example, if you select this option, the object imports into the BIG-IQ working configuration, and, for a shared object, the next time BIG-IQ deploys a configuration to any of the managed devices that contain MyProfile, it disables the Insert X-Forwarded-For setting if it is not already disabled.

    • Select Create Version if you want BIG-IQ to create and store a copy of the BIG-IP device's BIG-IP LTM monitor or profile object(s) specific to the software version running on that BIG-IP device. If you select this method, the next time it deploys a configuration, BIG-IQ replaces that object for all the managed BIG-IP devices running that version. You can store multiple versions of BIG-IP LTM monitors or profiles. BIG-IQ deploys the appropriate stored version to your managed devices. The next time it imports services that contain BIG-IP LTM monitors or profiles, BIG-IQ automatically resolves conflicts against the appropriate version.

      For example, the values of properties or the properties themselves of profiles and monitors differ between BIG-IP versions.

  18. Select Continue to have BIG-IQ import the configuration(s).
