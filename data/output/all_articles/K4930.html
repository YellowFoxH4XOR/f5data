Topic

F5 Product Development has discovered a rare condition that exists in some of the early BIG-IP 6800 platform models that were shipped. In the affected systems, the BIG-IP 6800 may appear to be stuck at the Booting From Local Drive boot message for up to 3 minutes during the boot process.

This issue occurs because the NIC boot option is set in the BIOS and each internal NIC must time out before the boot process will continue. This BIOS setting cannot be adjusted.

This rare behavior does not impact BIG-IP system performance or functionality.
