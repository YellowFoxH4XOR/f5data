K3742: Configuring BIG-IP to reduce the time it takes to load configurations that contain a large number of SSL proxies

Topic

By default, when the configuration is loaded, BIG-IP validates all SSL certificates and keys used with SSL proxies. In configurations that have fifty or more proxies, the validation can take a considerable amount of time (30 seconds to several minutes).

Starting in versions 4.5.11 and 4.6.3, BIG-IP provides a global option, skip keycheck, that you can use with SSL proxies. When enabled, this option will skip the validation for certificates and keys when a configuration is loaded. This significantly reduces time it takes to load the configuration.

Note: When the skip keycheck option is enabled, BIG-IP will not detect SSL proxies that are configured with an invalid certificate and key pair, and connections to those undetected SSL proxies will fail.

You can enable the skip keycheck global option from the Configuration utility or from the command line.

Configuration utility

To enable the skip keycheck option from the Configuration utility, perform the following steps:

  1. From the Configuration utility, click System.
  2. Click the Advanced Properties tab.
  3. In the SSL Proxy section, check the sslproxy skip keychecks box.

Command line

To enable the skip keycheck option from the command line, type the following command:

bigpipe global sslproxy skip keycheck enable

To view the current setting, type the following command:

bigpipe global sslproxy skip keycheck show

To reenable the validation of certificates and keys, type the following command:

bigpipe global sslproxy skip keycheck disable
