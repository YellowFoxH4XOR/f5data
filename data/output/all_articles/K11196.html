Known Issue

This is the result of a known issue. In a BIG-IP high availability pair, the connection and persistence records created when the standby unit was offline are not mirrored once the standby unit is back online. The correct behavior is for the active unit to queue a list of the changes to the connection and persistence tables, and push these changes to the standby unit once the standby unit is back online.

Note: Since the iRule session command utilizes the persistence table, iRules that use the session command are also affected.

Note: For BIG-IP 9.4.5, this issue was introduced in Hotfix-BIG-IP-9.4.5-HF2.

F5 Product Development is tracking this issue as CR132507.

This issue does not affect the BIG-IP 10.x software branch.
