Description

Change the default error page for the ingress controller


 Environment

Nginx Ingress Controller 2.3.0


 Cause

The Nginx Ingress Controller deploys with a default error page which returns a generic Nginx 404 error page when traffic is received that does not match any configured Ingress resource(either Ingress or Virtualserver CRD). Customers may want to customize this response to either redirect to a more professional looking page, or configure the Ingress Controller to return a custom response.


The configmap key "default-server-return" can be used to modify the default server location block, and return a custom response.

This configmap key value is described here:

https://docs.nginx.com/nginx-ingress-controller/configuration/global-configuration/configmap-resource/#general-customization


 Recommended Actions

A simple redirect example is provided in the above link.

However you might want to configure the Ingress Controller to return a custom response.


Here are a couple configmap examples to help understand the format for the syntax:

========================================================

For simple redirect:

----------------------

kind: ConfigMap

apiVersion: v1

metadata:

name: nginx-config

namespace: nginx-ingress

data:

default-server-return: 302 https://redirect.example.com



For a custom response:

--------------------------

kind: ConfigMap

apiVersion: v1

metadata:

name: nginx-config

namespace: nginx-ingress

data:

default-server-return: 200 "Sorry\nThe resource is not here\n\n"



 Additional Information

This modification will only update the "/" location block that is under the default server block. This method cannot be used to modify any of the directives in the default server block itself.


If you need to add or remove nginx directives from the default server block, then you would need to use a custom template. This is outside the scope of this article, but more info can be found here:

https://docs.nginx.com/nginx-ingress-controller/configuration/global-configuration/custom-templates/
