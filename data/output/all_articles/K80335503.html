K80335503: Unable to establish session with ''Too many open files'' message

Type
Support Solution
Published
2021-10-26
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 13.1.5, 13.1.4, 13.1.3, 13.1.X, 13.1.0, 13.1.1
Source
https://my.f5.com/manage/s/article/K80335503

Description
All clients can not establish APM session.
There is "Too many open files" message in /var/log/apm log.

 01490000:3: ApmD.cpp func: "process_apd_request()" line: 1818 Msg: Error 3 reading/parsing response from socket 969. strerror: Too many open files, queue size 0, time since accept 0
 01490000:3: HTTPParser.cpp func: "readFromSocket()" line: 110 Msg: epoll_create() failed [Too many open files]
 

Environment

  • BIG-IP APM
  • Version 13.1.X

Cause
 This hits ID917605. This happens even when APM Logging Levels is default, Notice level.  

Recommended Actions

  1. Lower APM logging level than default likely makes it harder to run into ID917605.
  2. To recovery from this issue, restart apmd.
        bigstart restart apmd

Additional Information
Bug ID 917605: Enabling APM debug logs can lead to leakage in file descriptors
K24826763: Configuring the BIG-IP APM Logging Levels (12.x and newer)
