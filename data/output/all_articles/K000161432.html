Cannot delete custom Bot Defense signature – "in use by Bot Defense Profile Signature Staging/Override" error

Description

When attempting to delete a custom Bot Defense signature, the operation fails with an error indicating the signature is currently in use by a Bot Defense profile via Signature Staging or a Signature Override/Exception.

BIG-IP prevents deletion of any signature that is actively referenced by a Bot Defense profile — regardless of whether the reference is through automatic staging or a manually configured override/exception entry.

Symptoms

One or both of the following error messages appear when attempting to delete a custom Bot Defense signature:

Error message 1 — Signature Staging reference:

01070265:3: The Bot Defense Signature (/Common/<sig_name>) cannot be deleted
because it is in use by a Bot Defense Profile Signature Staging
(/Common/<bot_profile> /Common/<sig_name>).

Error message 2 — Signature Override/Exception reference:

01070265:3: The Bot Defense Signature (/Common/<sig_name>) cannot be deleted
because it is in use by a Bot Defense Profile Signature Override
(/Common/<bot_profile> /Common/<sig_name>).

Cause

When a custom Bot Defense signature is created, BIG-IP may automatically stage it within existing Bot Defense profiles (Signature Staging). Additionally, administrators may have manually added the signature as an exception or override within one or more Bot Defense profiles (Signature Override/Exception).

BIG-IP enforces referential integrity: a signature object cannot be deleted while it is referenced by any Bot Defense profile configuration — whether via staging or an explicit override entry. All references must be cleared before deletion is permitted.

Resolution

Important — Review impact before proceeding: Removing a signature exception from a Bot Defense profile causes that profile to revert to the default category-level mitigation action for traffic matching that signature. Confirm this behavior is acceptable in your environment before proceeding, or plan to re-create the exception after deletion is complete.
 
Step 1  –  Identify all Bot Defense profiles referencing the signature

Determine which Bot Defense profiles hold the signature in staging or as an override/exception before making any changes.

Option A – GUI

  1. Navigate to Security › Bot Defense › Bot Defense Profiles.
  2. Open each profile and review:
    • The Signature Enforcement tab (for staged signatures).
    • The Bot Mitigation Settings › Mitigation Settings Exceptions section (for override/exception entries).
  3. Note all profiles that reference the target signature.

Option B – TMSH

Note: Verify the following command syntax against your BIG-IP software version before running. Replace <sig_name> with the actual signature name.
tmsh list security bot-defense profile all-properties | grep -A5 "<sig_name>"

Review the output to identify all profiles that contain a reference to the signature.

 
Step 2A  –  Remove a Signature Staging reference

 

Perform the following steps for each Bot Defense profile where the signature appears in the Signature Enforcement (staged) state:

  1. Navigate to Security › Bot Defense › Bot Defense Profiles.
  2. Click the affected profile to open it.
  3. Select the Signature Enforcement tab.
  4. Locate the custom signature in the staged signatures list.
  5. Select the signature and click Enforce.
    This moves the signature out of the staging state.
  6. Save the profile.
  7. Repeat for all profiles where the signature is staged.
Step 2B  –  Remove a Signature Override/Exception reference

 

Perform the following steps for each Bot Defense profile where the signature appears as an override or exception entry:

  1. Navigate to Security › Bot Defense › Bot Defense Profiles.
  2. Click the affected Bot Defense profile to open it.
  3. Navigate to Bot Mitigation Settings › Mitigation Settings Exceptions.
  4. Locate the exception entry for the custom signature.
  5. Select the entry and click Remove.
  6. Save the profile.
  7. Repeat for all profiles that contain an exception entry for this signature.
Step 3  –  Delete the custom Bot Defense signature

Once all profile references have been cleared (staging enforced and/or exception entries removed), delete the signature using TMSH:

Note: Replace <sig_name> with the actual name of the custom signature.
tmsh delete security bot-defense signature /Common/<sig_name>

If the deletion succeeds without error, the signature has been fully removed. If the error persists, repeat Step 1 to confirm no additional profile references remain.
