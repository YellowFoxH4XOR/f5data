Known Issue

This is the result of a known issue. Importing a WebAccelerator policy into a BIG-IP WebAccelerator versions 9.4 through 9.4.3 HF1 system will fail if the policy contains a node with a path greater than 256 characters. BIG-IP WebAccelerator version 9.4 through 9.4.3 HF1 have a 256 character limitation for the path field. For more information refer to K8177: Change in Behavior: Path length limitation for the WebAccelerator policy.

F5 Networks Product Development tracked this issue as CR88075 and it was fixed in BIG-IP WebAccelerator version 9.4.4.  For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue was fixed in Hotfix HF2 issued for BIG-IP WebAccelerator version 9.4.3. You may download this hotfix or later versions of the Hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about how to manage F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.

Workaround

If upgrading is not an immediate option, you can work around this issue by ensuring that the path for each node in the policy is less than 256 characters. You will need to re-export the policy, and re-import the policy onto the version BIG-IP WebAccelerator that you are running.

For information about importing and exporting acceleration policies, refer to the BIG-IP WebAccelerator Policy Management Guide.
