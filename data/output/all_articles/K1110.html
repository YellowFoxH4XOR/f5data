Topic

The rlogin utility connects through a SNAT, but rsh does not. When trying to connect with rsh, you will receive the following error:

socket protocol failure in circuit setup

A SNAT (Secure Network Address Translation) translates the source port of the connection from the original port to a random high port (1024 or higher). The RSH and RCMD specification from Berkeley states that the source port for a remote command must be between 512 and 1023, or the connection is invalid.

If you need to execute RSH and RCMD commands remotely, you must use a network virtual server, or IP forwarding.
