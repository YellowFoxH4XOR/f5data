Known Issue

Access profile logon pages may not display field titles.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access policy that references a SecurID AAA profile.
  • The SecurID authentication server uses RSA 8.1.
  • Users attempt to access the access profile logon page.

Impact

The logon page does not contain titles for the authentication fields.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H520835 on the Diagnostics > Identified > Medium screen.
  • When users access the access profile logon page, they are presented with input fields with no title descriptors.
  • Users who enter invalid authentication details receive warning pages that contain no information.
