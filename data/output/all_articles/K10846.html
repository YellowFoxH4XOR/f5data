Known Issue

This is the result of a known issue. After running the gtm_add script, the gtmd process logs the following message every 10 seconds to the /var/log/gtm file:

gtmd[3938]: 011a0023:5: Setting my time ahead by 33 seconds to match GTM <Name of primary BIG-IP GTM>

This behavior occurs only when multiple BIG-IP GTM systems are configured within a sync group and the new BIG-IP GTM systems are added using the gtm_add script.

F5 Product Development tracked this issue as CR83768 and it was fixed in version 9.4.2. For information about upgrading, refer to the BIG-IP GTM release notes.

Additionally, this issue was fixed in BIGIP-9.3.1-81.1-HF8 issued for BIG-IP version 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
