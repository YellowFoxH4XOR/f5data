Issue

Old Behavior

In BIG-IP versions prior to 10.2.2, the system saves the entire syslog configuration in the /config/bigip_sys.conf file.

New Behavior

Beginning in BIG-IP version 10.2.2, the following syslog configuration options now reside in the /config/bigip_base.conf file:

  • local ip (for remote server)

    The local ip option allows you to specify an IP address the syslog-ng uses as source IP when sending log messages to the remote syslog server.

  • include

    The include option allows you to customize the syslog configuration.

This change was a result of ID 357515.

Impact

Typing the following command does not save syslog-ng configurations to the configuration files:

bigpipe save

Recommended Actions

If you have performed a modification to the described syslog-ng configurations using the bigpipe command, you must use the following command to save the modification to their respective configuration files:

bigpipe save all
