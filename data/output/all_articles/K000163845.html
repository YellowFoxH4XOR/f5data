K000163845: tmsh show /gtm iquery gives error after redeploying vcmp guest or non-vcmp.

Type

Published
2026-10-22
Updated
2026-10-22
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000163845

Description

On a BIG-IP DNS vCMP guest or just BIG-IP DNS (formally known as GTM), the command tmsh show /gtm iquery returns an error after the DNS (GTM) service is forced offline and then returned to the configured state. Restoring the configuration does not clear the error.

  • Affected command: tmsh show /gtm iquery
  • Symptom: The command fails after the DNS service is forced offline and returned to the configured state.

Environment

  • Product: BIG-IP DNS
  • Version: 17.5.1
  • Trigger: DNS service is forced offline, then returned to the configured state (vCMP) or non-vCMP.

Cause

Unknown at time of publication.

Answer/Recommended Actions

Reload mcpd and reboot the device. This procedure is recommended for this symptom.

  1. Create the forceload flag file on the affected device:
    touch /service/mcpd/forceload
  2. Reboot the device to complete the mcpd reload.
    reboot
  3. After the device comes back up, run the following command to confirm the fix:
    tmsh show /gtm iquery

Additional Information

  • The forceload procedure requires a reboot. Plan a maintenance window before applying it.
  • Review K13030: Forcing the mcpd process to reload the BIG-IP configuration before applying this procedure.
