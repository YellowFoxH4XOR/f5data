Known Issue

The Configuration utility may display an error message when accessing certain objects on the BIG-IP DNS system.

This issue occurs when the following condition is met:

  • You use the Configuration utility to create any of the following objects, with a name that contains the percent character (%):
    • Data center
    • Distributed application
    • Link
    • Pool
    • Server

Impact

Users cannot access newly created objects by using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using the Configuration utility to access an object that includes a percent character (%) in the object name, a message similar to the following example is displayed: 
    An error has occurred while trying to process your request.
  • When using the Traffic Management Shell (tmsh), you can access objects that include a percent character (%) in the object name.

Workaround

To work around this issue, you can avoid using object names that contain the percent character (%), or manage objects by using the tmsh utility.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
