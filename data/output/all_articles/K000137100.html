Description

Your internal security scanner reported weak ciphers on a virtual server and wanted to know how to remove or modify them.

Environment

BIG-IP LTM
Virtual server with SSL profile

Cause

None

Recommended Actions


Go to Local Traffic ››  Profiles : SSL : Client  ››  <ssl profile name > and verify what cipher's has been listed in 'Cipher' option under configuration section 

Copy Cipher string and run below command in CLI/BASH.
tmm --clientcipher  <Cipher string>

Where <Cipher string> is the list of cipher suites. 

Based on the output determine which one to be removed/included from the list .

Note : When you run above command in CLI, it includes all TLS versions that are available rather than TLS versions enabled on SSL profile.

For example :

If your ssl profile has cipher string - 'DEFAULT:!TLSv1:!TLSv1_1:!3DES:!RSA' and wanted to include only following list of ciphers

TLSv1.2:
  - 0xC0,0x2B ECDHE-ECDSA-AES128-GCM-SHA256
  - 0xC0,0x2F ECDHE-RSA-AES128-GCM-SHA256
  - 0xC0,0x2C ECDHE-ECDSA-AES256-GCM-SHA384
  - 0xC0,0x30 ECDHE-RSA-AES256-GCM-SHA384
  - 0x00,0x9E DHE-RSA-AES128-GCM-SHA256
  - 0x00,0x9F DHE-RSA-AES256-GCM-SHA384
 

You need to include below cipher string in your ssl profile 


ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384:!TLSv1:!TLSv1_1:!3DES:!RSA
 
Before updating ssl profile you can also verify the list of ciphers available in your cipher string by running below command.

tmm --clientcipher 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384:!TLSv1:!TLSv1_1:!3DES:!RSA'

Verify the cipher suites listed in the output are one's selected. 

Finally add cipher string to ssl profile 



Important: When a client fails to include any of the cipher suites in CLIENT HELLO, configured on client ssl profile, BIG-IP will terminate the connection.

Note : You need to repeat same procedure for serverssl profile, if you need to modify any cipher and can be verified using below command

tmm --serverciphers '<cipher string>'
