Topic

When configuring BIG-IP APM resources, such as application access or portal access, you must use either a name that exists in DNS or the IP address. The BIG-IP APM system does not read its /etc/hosts file when attempting to resolve fully-qualified domain names (FQDNs).

The BIG-IP APM system inspects its cached DNS records then makes a query to the DNS servers configured in the systems DNS configuration.

Go to System > Configuration > Device > DNS.

If the DNS record does not exist in the cache, and cannot be resolved by the BIG-IP APM system's DNS resolvers, the web resource fails to load on the user's browser.
