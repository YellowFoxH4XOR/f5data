Issue

Starting in FirePass 6.0.3 with cumulative hotfix HF-603-1, the FirePass Components Troubleshooting Utility (CTU) has a new command-line flag to exclude a specific client component or group from removal. By using the /x flag in addition to the /r flag, you can specify which components or component groups should not be removed.

For example, to remove all FirePass client components, except the Win32 Inspector component and the components listed under the Base Controls group, you would type the following command from the Windows command line:

/path/to/f5wininfo.exe /r /x “Win32 Inspector” /x "Base Controls"

Note: In the example command, /path/to/f5wininfo.exe is the full path to the f5wininfo.exe file on the client system.

Note: For more information, refer to K9534: Removing FirePass client components from the Windows command line using the Components Troubleshooting Utility and K9133: Overview of the FirePass Components Troubleshooting Utility.
