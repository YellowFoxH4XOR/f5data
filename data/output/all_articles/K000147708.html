K000147708: Why am I getting the error "NS record must not share subdomain with other types of record” when creating a subdomain in XC DNS?

Description

In DNS Management, when creating a subdomain, the below error message is displayed upon saving:

Environment

  • F5® Distributed Cloud (XC)

Cause

If a NS record is created for a DNS zone (e.g., subdomain.example.com), and a CNAME or A record is also created for subdomain.example.com, then the CNAME and A records will be ignored.

We are displaying the above error message when there are already DNS records existing for the same subdomain - to avoid those records being ignored after the NS record have been created.

 

Answer/Recommended Actions

If you want to delegate the subdomain to another DNS service (which is what you're doing by creating a NS record), then you should remove the existing DNS records (e.g. CNAME/A) and recreate them in the subdomain on the other DNS service.

Once done, this error will not be displayed when creating the NS record for this subdomain in XC DNS.
