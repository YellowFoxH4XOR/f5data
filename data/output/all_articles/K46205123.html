Known Issue

A remotely authenticated user may fail to save the configuration on a BIG-IP system.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to authenticate administrative users using a remote authentication server.
  • The affected remotely authenticated administrative user is assigned with the Administrator role.
  • The affected user performs changes to the configuration and attempts to save the changes using either the TMOS Shell (tmsh) or iControl.

Impact

The affected user is unable to save the configuration changes using either tmsh or iControl.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to save the configuration changes using the tmsh save sys config command, the system does not save the configuration and returns an error message that appears similar to the following example:

    Can't create tmsh temp directory "/config/.config.backup" Permission denied

  • When you attempt to save the configuration changes using iControl, the system does not save the configuration and returns an error message that appears similar to the following example:

    Error processing request for URI:http://localhost:8110/mgmt/tm/sys/config
    {code:400,message: Can't create tmsh temp directory \"/config/.config.backup\" Permission denied, errorStack:[]}.

Workaround

To work around this issue, the affected remotely authenticated administrative user can use the Configuration utility to modify the configuration and save the changes. Alternatively, you can use a locally authenticated administrative user with the Administrator role to perform the same task.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

Note: The workaround procedures depend largely on the configuration changes. For more information, refer to the BIG-IP manuals relevant to the desired configuration that you want to change. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.
