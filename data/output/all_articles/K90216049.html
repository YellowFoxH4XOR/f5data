Description
If you have multiple guests that are actively processing application traffic but for business needs, you need to redistribute the hypervisor cores. this article should discuss the proper ways and options to finish this task

Environment

  • BIG-IP vCMP

Cause
None

Recommended Actions

This task can be done from the Configuration utility or from tmsh:
  1. Redistribute the hypervisor cores to vCMP guests from the Configuration utility
  2. Redistribute the hypervisor cores to vCMP guests from tmsh

Redistribute the hypervisor cores to vCMP guests from the Configuration utility

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window.

Important: When you set a guest to the Configured state, the guest is removed from service until you set the guest back to the Deployed state.

  1. Log in to the BIG-IP Configuration utility on the vCMP host, using the BIG-IP system's primary management IP address.
  2. On the Main tab, click vCMP > Guest List 
  3. Left to the status column, click on the select all icon
  4. Click the Disable button.
    The guests state changes from Deployed to Configured.
    Note: It might take a few minutes for the guest state to change to Configured.
  5. Once the screen shows that the guests are now in the Configured state, you start working on modifying the guests resources.
  6. Lower/remove CPU resources from some of the existing vCMP guests, then click update.
  7. Add newly available resources to the other vCMP guests, then click update. 
  8. Deploy the guests one at a time. there is no need to reboot.

Redistribute the hypervisor cores to vCMP guests using TMSH

Download the TMSH Command Reference Guide and use index.html to navigate the document. the page for vCMP guest tmsh commands is named vcmp_guest.html.
Here's how to get to the TMSH Command Reference Guide:
  1. Go to https://downloads.f5.com
  2. Log in, and click Find a Download.
  3. In the BIG-IP section, select the version in question.
  4. In the downloads list, click TMSH_command_reference.
  5. On the Software Terms and Conditions page, review and accept the license.
  6. On the Select a Download page, click the tmsh-vX-ref.zip file. The Download Locations page opens.
  7. Select the best option relative to your current location.
  8. Select Save File. You can find the downloaded file in the Downloads folder for your browser.
  9. Optionally, repeat steps 7 through 9 to download the md5 file for this download.
  10. Once you've completed the download, unzip the reference to the location of your choice.
