Known Issue

The Configuration utility fails to create or update objects when the time zone contains invalid characters. This issue occurs when one of the following conditions is met:

  • You set the NTP.TimeZone db key with the value GMT+0 or GMT-0 using the bigpipe db command or the tmsh utility and reboot the unit
  • You set the NTP.TimeZone db key with the value GMT+0 or GMT-0 using the bigpipe db command or the tmsh utility in BIG-IP versions prior to 10.2.0 and upgrade to BIG-IP version 10.2.0

Note: The Configuration utility disallows any attempts to configure the time zone with GMT+0 or GMT-0 and reports an error message similar to the following example for all BIG-IP 10.2.x versions:

Bad Characters. Only the following special characters are allowed: period, asterisk, forward slash, dash, colon, underscore, question mark, equals, at sign, comma, ampersand and space (.*/-:_?=@,& ).

If you require the time zone to be configured with GMT+0 or GMT-0 on any BIG-IP version 10.2.x system (except version 10.2.0), you must enter the bigpipe db NTP.TimeZone <new time zone> command in the command line. For example, if you require the time zone to be configured with GMT+0, you would enter bigpipe db NTP.TimeZone GMT+0 in the command line.

Impact

You are unable to create or update any objects using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You are unable to create or update any objects using the Configuration utility
  • You observe any changes made using the Configuration utility is not saved by refreshing the page in the Configuration utility or through the bigpipe command or the tmsh utility

Workaround

To work around this issue, you can specify an alternate time zone using the command line and reboot the affected unit to effect the change. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system may temporarily fail to process traffic and failover if configured as part of a high-availability system.

  1. Log in to the command line.
  2. Configure the time zone with GMT or GMT0 instead of GMT+0 or GMT-0 by entering the following command:

    bigpipe db NTP.TimeZone <new time zone>

    For example, to change the time zone to GMT, you would type the following command:

    bigpipe db NTP.TimeZone GMT

  3. Reboot the unit to effect the change by entering the following command:

    reboot
