Known Issue

Adding or removing hypervisor network interfaces causes BIG-IP Virtual Edition (VE) interfaces to stop sending or receiving packets.

This issue occurs when all of the following conditions are met:

  • The system is running BIG-IP VE.
  • You add or remove a network interface through the hypervisor where VE is installed. Usually, the fifth network interface is the first to trigger the problem.

Impact

The system does not detect changes to the hypervisor network interfaces, even after a reboot. When this occurs, the system is not able to properly process network traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Interface numbering, as observed from the BIG-IP configuration, may no longer appear in alignment with the hypervisor.
  • Network interfaces that are no longer present on the hypervisor may continue to appear in the BIG-IP configuration.

Resolution

Status

F5 Product Development has assigned ID 366403 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Type of fixFixes introduced inRelated articles
ReleaseNoneNone
Point release/hotfixNoneNone

Note: This issue does not affect BIG-IP VE running on 15.1.0 and later.

Workaround

To work around this issue, you can recreate the Master Control Program Daemon (MCPD) database to ensure that the system properly detects the new or removed interfaces. To do so, perform the following procedure:

Impact of workaround: Rebooting the BIG-IP system disrupts traffic processing until the system is back up. F5 recommends that you perform this operation during a maintenance window.

  1. Log in to the command line.
  2. Remove the MCPD database by typing the following command:

    rm /var/db/mcpd*

  3. Restart the system by typing the following command:

    reboot

When the system is back up, you may still need to adjust the interfaces in the BIG-IP configuration to map to the correct networks. To view the interface mapping, you can compare the media access control (MAC) addresses of the interfaces, displayed in the Configuration utility, to those displayed in the hypervisor configuration.
