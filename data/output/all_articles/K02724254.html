K02724254: F5 SSL Orchestrator fails to install an RPM software package with an error of ''Invalid File''

Description

F5 SSL Orchestrator fails to install an RPM software package when upgrading from SSL Orchestrator 16.1.0-9.1.x over to 16.1.1-9.1.x+1. When one attempts to install the RPM software package, the installation fails and the Configuration utility displays an error message similar to the following example:

“Invalid File”.
“Cannot install f5-iappslx-ssl-orchestrator-16.1.1-9.1.70.noarch.rpm, package version should be 16.1.0-x.x.x and higher than 16.1.0-9.0.24”

Environment

  • You are running BIG-IP 16.1.2.0.0.18 with the built-in SSL Orchestrator 16.1.0-9.0.24.noarch package.
  • You are looking to upgrade over to an SSL Orchestrator 16.1.1-9.1.x+1 rpm package.
  • From the Configuration page of the SSL Orchestrator Configuration utility, you select the Upgrade SSL Orchestrator link to install the following F5 SSL Orchestrator RPM software package:

    16.1.1-9.1.70.noarch.rpm

Cause

The 16.1.0-9.1.x upgrade over to 16.1.1-9.1.x+1 will not be allowed because 16.1.0 and 16.1.1 are not equal. This is a known issue (ID 1020573) that has been resolved in the SSL Orchestrator 9.1 release (post-upgrade).

Note: The usage of the "Upgrade SSL Orchestrator" feature is permitted post SSL Orchestrator rpm >= 9.1.

Recommended Actions

To work around this issue, you can import the affected RPM software package using the Package Management LX page instead. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to iApps > Package Management LX.
  3. Select Import.
  4. Select Choose File and select the RPM software package.
  5. Select Upload.
