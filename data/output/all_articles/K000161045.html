K000161045: Warning: "Disk partition / has only 0% free" on F5OS tenant

Description

Disk partition / has 0% free space on BIG-IP LTM rSeries tenant after migrating configuration from iSeries. System logs show messages such as:

diskmonitor[xxxx]: 011d0004:3: Disk partition / has only 0% free

Large, obsolete EPSEC (OPSWAT Endpoint Security) package ISO files are present in temporary directories, consuming significant disk space.

Environment

  • Product: BIG-IP LTM
  • Version: 17.1.3
  • rSeries tenant migration scenario (iSeries to rSeries)
  • APM module with EPSEC (OPSWAT Endpoint Security) packages
  • Disk space issue on root (/) partition
  • Large EPSEC package ISO files found in:
    • /tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/
    • /opt/.sdm/tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/

Cause

Obsolete EPSEC (OPSWAT Endpoint Security) package ISO files accumulate in temporary directories. These files are not referenced by the current configuration and are remnants from previous UCS install or upgrade operations, causing the root partition to reach 0% free space.

Answer/Recommended Actions

To resolve the disk space issue:

  1. Identify Active EPSEC Package
    • Use qkview or configuration review to confirm which EPSEC package is currently in use.
    • Only the active package (e.g., /config/filestore/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1915.0.iso_59728_1_truncated) should be retained.
  1. Remove Obsolete EPSEC Package Files
    • Manually delete all EPSEC package ISO files in temporary directories that are not referenced by the current configuration.
    • Example commands:
  • rm -f "/tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-928.0.iso_97268_1"
  • rm -f "/opt/.sdm/tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-928.0.iso_97268_1"
  • rm -f "/tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1303.0.iso_81516_1"
  • rm -f "/opt/.sdm/tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-1303.0.iso_81516_1"
  • rm -f "/tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-696.0.iso_83883_1"
  • rm -f "/opt/.sdm/tmp/PRE/var/tmp/filestore_temp/files_d/Common_d/epsec_package_d/:Common:epsec-1.0.0-696.0.iso_83883_1"
    • Only remove files not referenced in the current configuration.
  1. Verify Disk Space
    • After cleanup, check available disk space on the root partition to confirm the issue is resolved.
  1. Reference F5 Documentation
    • For further guidance, consult the referenced F5 Knowledge Base articles.

Additional Information

  • Only one EPSEC package should be active in the configuration. All other EPSEC package files in temporary directories are safe to remove if not referenced.
  • Orphaned EPSEC package files are commonly left behind after UCS imports or upgrades and do not impact system operation once removed.
  • Always verify which files are in use before deletion to avoid removing necessary packages.
