K11967: Local users may be assigned to the incorrect Master Group if RADIUS dynamic group mapping has been configured

Known Issue

This is the result of a known issue. If a user's account that is local to the FirePass device attempts to authenticate with RADIUS dynamic group mapping configured, the user is always assigned to the Default Master Group, even if that is not the Master Group they should be assigned to. 

F5 Networks Product Development is tracking this issue as ID 336453.

This issue was fixed in cumulative hotfix HF-610-3-1 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
