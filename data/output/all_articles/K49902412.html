Security Advisory Description

nghttp2 version >= 1.10.0 and nghttp2 <= v1.31.0 contains an Improper Input Validation CWE-20 vulnerability in ALTSVC frame handling that can result in segmentation fault leading to denial of service. This attack appears to be exploitable via network client. This vulnerability appears to have been fixed in >= 1.31.1. (CVE-2018-1000168)

Impact

There is no impact; F5 products are not affected by this vulnerability.

Security Advisory Status

F5 Product Development has evaluated the currently supported releases for potential vulnerability, and no F5 products were found to be vulnerable.

Security Advisory Recommended Actions

Protecting nghttp2 servers behind the BIG-IP virtual server from CVE-2018-1000168

By default, a BIG-IP HTTP virtual server of standard type proxies HTTP/2 client traffic to the pool members using HTTP/1.1. As a result, application servers that use nghttp2 configured as pool members for a BIG-IP standard HTTP server are not vulnerable.
