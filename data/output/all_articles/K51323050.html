Description

This article explain sctp alarm

  • nmsagent log file reports:
2022-02-08 12:12:46,773 INFO [12469] **SNMP** Alarm was created: SiteIdTrapProperty = LAB-DEA 1.3.6.1.4.1.3375.3.1.4.3.6.0.10 HostNameTrapProperty = LAB-SDC-1 [SiteIdTrapProperty=BDK-DEA, HostNameTrapProperty=LAB-SDC-1, AffectedObjectTypeTrapProperty=20000, EventTypeTrapProperty=6, EventIdTrapProperty=peerSctpLink, DetectorComponentTrapProperty=LAB-SDC-1_fep-p-sctp, ManagedObjectInstanceTrapProperty=JEvMME01.epc.mnc001.mcc525.3gppnetwork.org, EventDateAndTimeTrapProperty=07:e6:02:08:0c:0c:2e:07:2b:08:00, EventDescriptionTrapProperty=Sctp Link is changed, SeverityTrapProperty=major, AdditionalTextTrapProperty=One of the links between the SDC site and one of its peers is down. The remote address is: 10.10.10.33:3868, the local address is 10.10.20.17:3868. The reason is No HB acknowledge for Non-Primary address /10.10.10.32:3868. The peer type is: Diameter. The peer name is: LABMME.epc.mnc001.mcc001.3gppnetwork.org. The association id is: 13938116., AlarmEventLogAutoClearedTrapPropert

Environment

  • SDC 5.1
  • SCTP Diameter Clients or Server

Cause

Non-Primary address did not acknowledge SCTP HB hence SDC reported the link to down.

Recommended Actions

Investigate the Diameter Peer and network for delay or missing sctp HB.
