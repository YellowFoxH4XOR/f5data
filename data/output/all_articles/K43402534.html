Description

When connecting to the GUI, objects are missing upon login, such as the sidebar.

Logs similar to the following may be found in /var/log/tomcat/catalina.out:
ERROR [ajp-bio-127.0.0.1-8009-exec-19] util.Syscall:call - Exception trying perform a system call

Similar symptoms as described in K75724931: GUI objects are missing, but there is no stalled UCS process.

Environment

  • BIG-IP GUI
  • 14.X software

Cause

Unknown at the time of publication

Recommended Actions

Rebooting the BIG-IP should return the GUI to normal operation
