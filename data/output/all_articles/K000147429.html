Description

  • How do I advertise a prefix through F5 Distributed Cloud?
  • How to route a prefix through F5 Distributed Cloud during an attack?

Environment

  • F5® Distributed Cloud (XC) Routed DDoS Service

Cause

  • None

 

Answer/Recommended Actions

Note: This route advertisement feature will typically be used by always available customer who only route traffic through F5 Distributed Cloud during the time of attack but is available to all customers.

To advertise a prefix:

  1. Sign in to your XC console account. 
  2. Select DDoS & Transit Services
  3. Select Manage > Route Advertisement
  4. Click Add Route Advertisement
  5. Enter name, prefix and select the expiration (default is never).
  6. Select Save and Exit
