Issue

Description

Commands tmsh show sys memory and free report differing amounts of free swap space. Additionally, swap space SNMP OID's equal output from command free.

Environment

  • BIG-IP

Cause

Command tmsh show sys memory calculates free swap memory by adding SwapCached and SwapFree from file /proc/meminfo. Linux command free only reports SwapFree from file /proc/meminfo.

Recommended Actions

None

Additional Information

There are times when identical memory pages exists in swap and physical memory; this is known as Linux swap cache. This happens when a page is swapped out and then recalled to physical memory. As long as the physical memory page is not modified, the page in swap memory is still valid. The physical memory page can be removed when no longer needed, without a write to swap memory. This avoids an unnecessary write, speeding up the process of swap memory.

Example:

  • Output of file /proc/meminfo appears similar to the following:

    [root@bigip1:Active:Standalone] config # cat /proc/meminfo
    SwapCached:        66512 kB
    SwapTotal:       1023996 kB
    SwapFree:         742508 kB

  • Commands free reports only SwapFree value appears similar to the following:

    [root@bigip1:Active:Standalone] config # free -k
                 total       used       free     shared    buffers     cached
    Mem:       4062984    3966660      96324      59260       1624     254928
    -/+ buffers/cache:    3710108     352876
    Swap:      1023996     281488     742508

  • Command tmsh show sys memory kil reports the addition of lines SwapFree and SwapCached similar to the following:

    [root@bigip1:Active:Standalone] config # tmsh show sys memory kil | grep -A 4 Swap\:
    Swap: 0
      Total   1023996.0
      Used     214976.0
      Free     809020.0
