Known Issue

F5 Access error messages are not displayed when you connect from a widget.

This issue occurs when all of the following conditions are met:

  • You are using the F5 Access 3.0.7 widget running on an iPadOS device.
  • You attempt to establish a VPN access session.
  • The access session fails.

Impact

The system displays no error messages.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to establish a VPN access session, if the connection fails to establish, the system displays no error message.
