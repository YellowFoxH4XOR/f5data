Known Issue

This is the result of a known issue. The MySQL administrative password is randomly chosen during the BIG-IP ASM installation process. Under rare circumstances, the BIG-IP ASM generates a MySQL password which contains a backslash ( \ ) character. A password containing a backslash character is incorrectly interpreted by the Configuration utility. When such a password is created, the BIG-IP ASM system cannot connect to the MySQL database. As a result, the Configuration utility displays the following error message when accessing the HTTP Class page:

An error has occurred while loading this page.

In addition, the BIG-IP ASM may also log error messages similar to the following to the /var/log/tomcat4/catalina.out file:

db.DBConnection:getConn - Could not init connection for a transaction: java.lang.RuntimeException: Could not find database credentials.
util.PCrypt:decrypt - Exception attempting to decrypt cipher.
java.lang.RuntimeException: Decrypt call returned non-zero value (2)..

F5 Product Development tracked this issue as ID 217013 (formerly CR106734), and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by changing the MySQL password, as documented in K6979: Managing the MySQL database password for the BIG-IP ASM.
