K01435002: Back button doesn't function via APM portal access after upgrading PeopleSoft portal application to 8.59

Type
Support Solution
Published
2024-10-29
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K01435002

Description

The back button on the target page doesn't appear to have a caption and doesn't function when accessed via APM portal access.
 

Environment

  • PeopleSoft upgraded from 8.57 to 8.59
  • Classic or Fluid Interface

Cause

Java script DoBackClassic() doesn't execute 

Recommended Actions

  1. Upgrading  to 14.X / 15.X helps bring the button's caption and make it function 

Additional Information

None
