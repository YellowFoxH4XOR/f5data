Topic

F5 has recently discovered and corrected a number of issues that affect customers running ARX 5.0.7. F5 recommends that all customers currently running version 5.0.7 install the latest cumulative rollup hotfix available.

The following table lists the rollup hotfixes available for ARX 5.0.7. Each hotfix lists the ID number and description for the issues fixed by the hotfix:

Note: These rollup hotfixes are cumulative. Therefore, each hotfix will contain the fixes included in the previous hotfixes.

ARX VersionID NumberDescription
5.0.7 HF3
(build-11795)

5.0.7 HF2
(build-11794)		336269An NSM core manifested due to a double free of a presto packet in an NFS path coupled with a network outage. This resulted in buffer corruption. The NSM can now send traffic to a file server in this situation without corrupting the buffer.
5.0.7 HF1
(build-11793)		339444Using “file history’ related commands would result in front-end NFS access issues.
343546Failing over a Netapp filer after an ARX failover would cause NFS clients connected to ARX VIPS to have mount issues.
