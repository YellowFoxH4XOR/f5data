K01730374: Factory Defaults of Protocol Inspection does not include Latest Update

Type
Support Solution
Published
2022-11-16
Updated
2024-11-22
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP AFM: 14.1.4
Source
https://my.f5.com/manage/s/article/K01730374

Description

Even if the most recent release of TMOS is installed, Protocol Inspection signatures may not be the latest.   

Environment

  • BIG-IP AFM

Cause

This is by design.

# tmsh show /security protocol-inspection update
----------------------------------------------------------------------------------------------------------
Security::Protocol Inspection::Installed Updates
Filename                                           Version  Build         Build Date  Install Date  Status
----------------------------------------------------------------------------------------------------------
FactoryDefaults                                   14.1.4.2  20.2M  04/16/21 11:36:05          None  Active 

For example, v14.1.4.2 was released on 04/27/2021(build date is usually earlier), so the Protocol Inspection Factory Defaults should have added to it and referred to the date. It does not mean the Factory Defaults includes cumulative update by the date.

Recommended Actions

After TMOS Upgrade, Updating Protocol Inspection signatures with a Latest Update will be recommended.
F5 periodically updates these signatures and releases them on the F5 Downloads site. You may see them in the container named ProtocolInspection-LatestUpdate for each versions.
