Known Issue

This is the result of a known issue. The mcpd process may crash when you are trying to process requests for HTTP statistics over a long period of time. When this issue occurs, the following error message is logged to the /var/log/ltm log file:

sccp <daemon>: Lost connection to MCP

F5 Product Development tracked this issue as CR62104 and it was fixed in BIG-IP LTM 9.3.0. For information about upgrading, refer to the BIG-IP LTM release notes.
