Description

During the ongoing maintenance of your F5 device, you may need to transfer a file to or from the device. For example, you may want to transfer the ISO to the device for installation or a PCAP file from the device to your workstation for analysis (if your workstation runs TFTP server software).

Trivial File Transfer Protocol (TFTP) can be used to transfer files to or from remote machines, including some very minimalistic, usually embedded, systems. The remote host may be specified in the command line, in which case TFTP uses the host as the default for future transfers.

TFTP does not use authentication or encryption. You should take this into consideration when using TFTP to transfer files.

Environment

  • BIG-IP devices
  • TFTP client on BIG-IP
  • TFTP server on remote system

Cause

None

Recommended Actions

To transfer files using TFTP, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. From the BIG-IP, change directories to the directory that contains the file that you want to transfer or the directory you want to add a file to. To do so, use the following command syntax:

    cd <directory>

    For example:

    cd /shared/tmp

  3. Execute TFTP by using the following command syntax:

    tftp <server>

    For example:

    tftp 10.1.1.2

  4. Transfer the file, using the following command syntax from the tftp> prompt. Use put to transfer to a remote host and get to transfer from a remote host:

    Note: To put a file, the TFTP server likely needs to be configured to receive file transfers. Typically the default behavior is to only allow the client to get files.

    • put <filename>
    • get <filename>

    For example:

    • put myfile
    • get myfile
  5. Exit TFTP by entering the following command:
    quit
