Description

This documentation describes the limitation of using High Speed Logging ( HSL ) and Log Publisher for DOS Event logs.
 

Environment

  • Logging DOS Events
  • ArcSight ( or QRadar ) Publisher used


Cause

Currently the only publisher supported for DOS events for High Speed Logging is Splunk.

Note: The limitation also applies to Bot Defense logging.


Recommended Actions

Switch the publisher to Splunk.


Additional Information

A Request for Enhancement for logs to be sent to ArcSight as remote log destination has been created; RFE ID746175.

Furthermore, the manual chapter 'Configuring Remote High-Speed Logging of DoS Protection Events' applies to AFM logging.
