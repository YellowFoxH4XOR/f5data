Description

ASM Menu missing in the ADFS iApp Configuration.

Environment

  • iApp template : f5.microsoft_adfs.v1.2.0rc9
  • ASM policy Configured
  • In the Deployment Guide, there is a section 'Application Security Manager (ASM)'

Cause

In the SSL Encryption section of the iApp configuration, 'SSL Passthrough' is selected and in this case Application Security Manager (ASM) menu is hidden.
 

Recommended Actions

Reconfigure the iApp Application, switch to 'SSL bridging' and the Application Security Manager (ASM) menu will appear.
 

Additional Information

ASM requires BIG-IP to decrypt the traffic to process the HTTP request.

When SSL Passthrough is selected, a performance layer virtual server is created.
