Description

When users are connected to Network Access VPN tunnels, it may be required to route specific traffic to a specific gateway.

Environment

  • BIG-IP APM
  • Network Access VPN
  • Routes 

Cause

By default Network Access profiles are not designed to route specific traffic to specific gateways. To accomplish this you will need to create a layered virtual server to route this traffic properly.

Recommended Actions

Create a Pool that identifies the desired gateway.
This example will route traffic from source lease pool of 192.168.1.0/24 destine for 172.16.24.0/24 to the gateway of 10.10.10.1

  1. Navigate to Local Traffic  ››  Pools : Pool List  ››  Click Create..

  2. Give the Pool an appropriate name

  3. Leave the health monitors empty

  4. In the New Members section:

    PropertyValue
    AddressDesired gateway IP address
    For example: 10.10.10.1
    Service Port0 (*All Services)

  5. Click Finished

Create the Virtual Server to forward the Network Access VPN traffic.

  1. Navigate to Local Traffic  ››  Virtual Servers : Virtual Server List  ››  Click Create...

  2. The Virtual Server an appropriate name

  3. Update the following settings:

    PropertyValue
    Source AddressDefine as the subnet of the lease pool.
    For example: 192.168.1.0/24
    Destination AddressDefine as destination subnet
    For example: 172.16.24.0/24
    Service Port0
    Protocol* All Protocols
    VLAN and Tunnel TrafficDefine as the Connectivity Profile used on the Network Access Virtual Server
    Default PoolChoose the pool created in prior step.

  4. Click Finished
