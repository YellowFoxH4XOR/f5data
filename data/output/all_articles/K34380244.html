Issue

Error Message

notice mcpd[<PID>]: 01070427:5: Initialization complete. The MCP is up and running

In this error message, note the following:

  • <PID> is the process ID for the mcpd process

For example:

notice mcpd[8502]: 01070427:5: Initialization complete. The MCP is up and running

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The mcpd process successfully completes initialization.

For example, the mcpd process generates this message during the normal boot process after the configuration loads and mcpd reaches a running phase.

Impact

There is no impact. This message is a notification that the mcpd process is up and running.

Recommended Actions

None
