Description

TACACS+ encrypts a portion of its packets using a TACACS+ Encryption Key configured on the TACACS+ server. Thus, when troubleshooting a TACACS+ Auth issue, it is sometimes necessary to decrypt that portion of the TACACS+ packets for analysis. This can be achieved by applying the TACACS+ Encryption Key from the TACACS+ server to a packet capture in Wireshark containing TACACS+ traffic. 

Environment

Relevant environmental factors:

  • BIG-IP
  • Remote Auth for BIG-IP administration using TACACS+
  • Or, an APM Access Profile supporting TACACS+ for Authentication

Cause

Need to decrypt the encrypted portion of TACACS+ traffic for analysis.

Recommended Actions

To decrypt the encrypted portion of TACACS+ traffic in Wireshark.

  1. Open the packet capture in Wireshark.
  2. Navigate to Edit > Preferences.
  3. In the pop-up window, navigate to Protocols > TACACS+.
  4. Input the TACACS+ Encryption Key retrieved from the TACACS+ server in the TACACS+ Encrypted Key field and click OK.
  5. The encrypted portion of the TACACS+ packets should now be decrypted.
