BIG-IP includes a feature is called Gateway Failsafe. This feature allows you to configure each controller in a redundant BIG-IP pair with a different default gateway route. Each route contains a failsafe monitor that verifies connections to the router.

If the failsafe mechanism on the active BIG-IP detects that its default gateway is down, it will failover to the standby BIG-IP and that controller will send traffic over its default gateway.

For more information about configuring Gateway Failsafe on BIG-IP, refer to the BIG-IP Reference Guide specific to the version you are running.
