Description
You receive an error in the Configuration Utility when trying to import a new Elliptic Curve (EC) certificate and key pair to use for the BIG-IP device in System  ››  Certificate Management : Device Certificate Management : Device Certificate  ››  server.crt.
Import Failed: Key management library returned bad status: -35, EC keys are incompatible for Webserver/EM/iQuery.

Environment

  • BIG-IP system
  • EC certificate and key pair

Cause
The trusted device certificate must be an RSA certificate

Recommended Actions
Use an RSA certificate and key pair instead

None
