K42421634: User with Web Application Security Administrator role cannot view ASM policy list - policy list is empty

Type
Support Solution
Published
2021-06-18
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K42421634

Description

After upgrade a new user created with role web-application-security-administrator is not able to view the ASM policy list on the Web GUI - policy list is empty.

Environment

  • ASM
  • User Roles
  • After upgrade

Cause

Bug ID 718796: IControl REST token issue after upgrade

Recommended Actions

To workaround the issue on affected versions, run the following commands from the command line:

restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"

bigstart restart restjavad

Note: The above command does not have any negative impact.

None
