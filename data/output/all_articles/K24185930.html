Description
This solution tell some known issues and preparation for upgrading F5OS-A to v1.2 or later

Environment

  • F5OS-A
  • rSeries
  • Upgrade to v1.2.x

Cause

  • n/a

Recommended Actions

Preparation
  • Follow below and save config backup, save it to safe/remote location and check file integrity with e.g md5sum
    K47512994:  Back up and restore the F5OS-A configuration on an rSeries system
  • Import or upload an F5OS-A image on the F5 rSeries system
    K93807441: Manage F5OS-A images on the F5 rSeries system
  • Once imported, on CLI with admin account, run the bellow command and check all columns are filled, and STATUS is ready

Installation
  1. Take all tenants' backup, save them to remote and safe location and check file integrity 
    NOTE: Before takng backup, you may want to set passphrase and password or get the Master key (especially if tenant is standalone).
    K9420: Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)
     
  2. If upgrading an r5000/r10000 seriese appliance from v1.0.x , move all tenants in Deploy state to the Provision state
    NOTE: This is due to a known issue: 
    K34815104: [F5OS-A] Upgrading r5000 and r10000 series appliancesany upgrade from 1.0.x to 1.1.0 or higher results tenants in inoperative State
     
  3. on GUI,
    SYSTEM SETTINGS >> Software Management >> Update Base OS Software: Update Software,
    keep selecting "Bundled", select ISO image: 1.2.0.
     
  4. Click Save. 
     
  5. Once system is ready, set tenants back to Deploy mode.
     

Additional Information
