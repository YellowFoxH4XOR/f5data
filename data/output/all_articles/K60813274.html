Policy Information

This article provides an overview of F5 Access for iOS and support for it.

F5 Access is a secure remote-access and VPN client app developed by F5 for Apple devices and available from iTunes. F5 Access and other networking and remote-access apps interface with an operating system framework to control networking functions on the host device. In 2015, Apple released an updated framework named Network Extension. iOS 8 through iOS 11 contained both the new and legacy frameworks, allowing apps to use either. F5 released a client named F5 Access 2018 to support the Network Extension framework. For more information, refer to the F5 Access for iOS release notes.

Note: For information about how to locate F5 product manuals, refer to K12453464: Tips for searching MyF5 and finding product documentation.

In iOS 12, Apple removed the legacy framework, causing older apps such as F5 Access 2.x to stop working. Consequently, network administrators must instead use F5 Access 2018 (3.0.0) or later versions, which support the new framework. To clarify iOS remote access apps, F5 changed the following names:

  1. F5 Access 2.x is now F5 Access Legacy.

    This client version is for enterprise customers on legacy apps, who do not intend to upgrade to iOS 12 immediately.

  2. F5 Access 2018 is now F5 Access.

    This client version is for enterprise customers who intend to use iOS 11 and later.

For updates to the latest iOS and F5 Access versions and compatibility, refer to the F5 Access and BIG-IP Edge Apps Client Compatibility Matrix manual.

  • F5 currently publishes both F5 Access and F5 Access Legacy in the Apple App Store.
  • F5 Access Legacy is no longer supported on iOS 12 and later versions.
  • With the release of iOS 12 by Apple, F5 no longer provides updates for F5 Access Legacy. Therefore, look for any bug fixes in F5 Access 2018.
  • When users use F5 Access 2.x on iOS 12, the app will not function and instead displays the following alert:

    F5 Access Needs to Be Updated. The developer of this app needs to update it to work with iOS 12.

Recommendations

F5 recommends that you upgrade your F5 Access and BIG-IP versions that include iOS support, according to the F5 Access on iOS compatibility matrix. Apple released iOS 12 on September 17, 2018. F5 customers who intend to upgrade to iOS 12 should migrate to F5 Access 3.0.1. For more information about F5 Access migration, refer to the F5 Access for iOS: Migration from 2.1.x to 3.x manual.
