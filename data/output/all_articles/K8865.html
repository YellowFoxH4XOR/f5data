The diskmonitor utility is a script that runs periodically on the BIG-IP system to monitor disk usage.

The diskmonitor utility performs the following functions:

  • Monitors BIG-IP disk usage limits and disk usage growth rates on selected volumes.
  • Sends warning and error logs to syslog when volumes are running out of space.
  • Dynamically adjusts the diskmonitor utility, which is run when disk use is approaching critical levels.

    Note: By default, 10 percent or less disk space in the /var/log volume is considered critical. When the /var/log volume is approaching critical levels, the diskmonitor error message causes alertd to run logrotate to rotate and compress the log. Due to a known issue, some BIG-IP systems do not perform this preventative measure. Refer to K31981624: The alertd process does not run the logrotate utility when the /var/log file has less than ten percent free space for more information.

Note: The nested directories and the root directory contain underscore ( _ ) characters. This formatting allows the Diskmonitor utility, which is a Perl script, to reference the directories, as the forward slash ( / ) character is reserved for use in Perl for defining regular expressions.

The diskmonitor utility also dynamically monitors and adds db variables for additional volumes you mount.

Configuration variables for the diskmonitor utility

The db variables allow customization of the diskmonitor utility on a per partition basis, as well as the option to disable the diskmonitor utility. For information about the db variables, refer to the following table.

VariableSettingsDescriptionExample
Platform.DiskMonitor.State
<value>

Enable: Enables diskmonitor (default setting).

Disable: Disables diskmonitor.

Enables or disables diskmonitor free disk space monitoring.BIG-IP 11.x and later:

tmsh modify sys db platform.diskmonitor.state value enable

BIG-IP 10.x and earlier:

bigpipe db Platform.DiskMonitor.
State=enable

Platform.DiskMonitor.Interval
<value>

min 1 - max 1440 (minutes)

BIG-IP 11.5.x and later:
The default setting is 10 minutes.

BIG-IP 11.4.x and earlier:
The default setting is 30 minutes.

Specifies the interval at which diskmonitor will run and gather disk information.

BIG-IP 11.x and later:
tmsh modify sys db platform.diskmonitor.interval value 10

BIG-IP 10.x and earlier:
bigpipe db Platform.DiskMonitor.
Interval=10

Changes diskmonitor
interval to run every 10 minutes

Platform.DiskMonitor.Monitor.
<partition> <value>

Limit: Checks the partition specified against the configured limits and sends a warning message if the disk space limit is reached.

Change: Monitors any changes and checks the changes against the limits specified.

Growth: Monitors any changes in partition growth and sends a warning message if the amount of growth exceeds the allowed growth rate.

None: Does not monitor the partition specified for any changes, growth rate, or limits. Use with caution.

Specifies how diskmonitor should monitor the configured partition.

BIG-IP 11.x and later:

tmsh modify sys db platform.diskmonitor.monitor.config value limit

BIG-IP 10.x and earlier:

bigpipe db Platform.DiskMonitor.
Monitor.config = limit

To display a list of DiskMonitors and their settings, use the following command:

BIG-IP 11.x and later:

tmsh list sys db platform.diskmonitor.monitor.*

BIG-IP 10.x and earlier:

bigpipe db show | grep Platform.DiskMonitor.Monitor
