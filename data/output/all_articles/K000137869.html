K000137869: PEM analytics may fail to display statistics for username and classifies all categories as aggregated

Type
Support Solution
Published
2023-12-11
Updated
2023-12-11
Applies to
  • BIG-IP
  • BIG-IP PEM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000137869

Description

  • When using Policy Enforcement Manager (PEM) with Analytics and Visibility Reporting (AVR), while generating analytics reports, AVR will query subscriber details from PEM but the customer is unable to view these reports by "user-name"
  • Query of the AVR analytics for a PEM subscriber displays all entries viewed by "user-name" as aggregated as shown in the output below:

root@(bigip01)(cfg-sync Disconnected)(Active)(/Common)(tmos)# show analytics pem report view-by user-name measures { total-bytes-in total-bytes-out }

--------------------------------------------------------------
Analytics query result
--------------------------------------------------------------
Time range: 10/24/2023:05:50 (EDT) ---> 10/24/2023:06:50 (EDT)
--------------------------------------------------------------
name | total-bytes-in | total-bytes-out
--------------------------------------------------------------
Aggregated | 14822 | 1477098

The following log may be observed in /var/log/avr/avrd.log:

AVRDATA_QUERY|WARNING|Nov 02 15:15:05.914|22792|lib/avrdata/query/pem_subscriber_query.c:0075| PEM Sub-prop, queue is full to deliver request to TMM. ID=172.16.1.1
 

Environment

  • BIG-IP PEM/AVR

 

Cause

  • Bug ID1394601
A leak in the asynchronous reply from the PEM/AVR internal reporting queue which results in the queue stalling

 

Recommended Actions

  • EHF is available on request.
