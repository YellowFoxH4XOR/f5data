Topic

Staging attack signatures helps reduce the number of violations triggered by false positive matches. For signatures that detect attack patterns during the staging period, the BIG-IP ASM system generates learning suggestions, which can be viewed from the Attack Signature Staging screen.

Once you evaluate the signature details, you can disable the signature if it is a false positive, or you can enable the attack signature if the detected signature match is legitimate.

Note: For more information about evaluating attack signatures, refer to the Configuration Guide for BIG-IP Application Security Management.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Additionally, you can enable the attack signatures that were not triggered during the staging process. If an attack signature is not triggered during the staging period, then no valid requests triggered the signature during the staging period. Therefore, the signature can be enabled.

Note: Enabling the attack signature removes it from the staging period, and puts the blocking policy into effect.

Enabling attack signatures that were not triggered during the staging process

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. Click the appropriate web application.
  5. Access the Traffic Learning box:
    • For versions 9.4.2 through 9.4.4, click Learning, then Violations.
    • For versions 9.4.5 and later, click Policy Building, then Manual.
  6. In the Traffic Learning box, click the Attack signature staging link.

    Note: If the Attack signature staging link does not appear, the attack staging period defined in the security policy has not ended.

  7. Enable the attack signatures that had no violations during the staging period:
    • For versions 9.4.2 through 9.4.4, click the Enable button next to the Filter drop-down menu.
    • For versions 9.4.5 and later, click the Enforce Signatures button above the Filter drop-down menu.

Note: Clicking the Enable or Enforce Signatures button removes any enabled attack signatures that had no incidents during the attack staging period.
