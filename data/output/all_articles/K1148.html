Topic

Important: The following instructions disable all inbound and outbound ICMP messages, including service checks and casual ping tests. For instructions about how to apply more specific filters, review the man pages.

To disable ICMP messages, perform the following steps:

  1. Using a text editor, such as vi or pico, edit the /config/ipfw.conf file and add the following:
    ipprotocol(1)
{
reject;
}
accept;

    Note: If there is already an accept statement at the end of the file, do not edit the file with another accept statement.

  2. Type the following commands:

    ipfwcmp -o /config/ipfw.filt /config/ipfw.conf
    ipfw pre-input -replace /config/ipfw.filt
    ipfw pre-output -replace /config/ipfw.filt
