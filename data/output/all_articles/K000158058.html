Security Advisory Description

A pre-authentication remote code execution vulnerability exists in React Server Components versions 19.0.0, 19.1.0, 19.1.1, and 19.2.0 including the following packages: react-server-dom-parcel, react-server-dom-turbopack, and react-server-dom-webpack. The vulnerable code unsafely deserializes payloads from HTTP requests to Server Function endpoints. (CVE-2025-55182)

Impact

There is no impact; F5 products are not affected by this vulnerability.

Security Advisory Status

F5 Product Development has evaluated the currently supported releases for potential vulnerability, and no F5 products were found to be vulnerable.

Note: F5 evaluates only software versions that have not yet reached the End of Technical Support (EoTS) phase of their lifecycle. For more information, refer to the Security hotfixes section of K4602: Overview of the F5 security vulnerability response policy.

Security Advisory Recommended Actions

Mitigation

BIG-IP Advanced WAF/ASM / F5 WAF for NGINX / NGINX App Protect WAF signatures

If you are using the BIG-IP Advanced Web Application Firewall (WAF) or BIG-IP ASM module or the F5 WAF for NGINX or the NGINX App Protect WAF to protect your backend pool members, you can mitigate this vulnerability for your backend pool members by using both of the following attack signatures enabled in blocking mode:

  • React Server Components RCE, ID 200204048 and ID 200204050

These attack signatures are part of the newly released attack signature update ASM-AttackSignatures_20251207_155959.im; you must perform a signature file update to ASM-AttackSignatures_20251207_155959.im or later for these signatures to be available on your system.

For information about updating attack signatures on the BIG-IP system, refer to K82512024: Managing BIG-IP ASM Live Updates. For information about assigning attack signatures to security policies on the BIG-IP system, refer to the Assigning Attack Signatures to Security Policies chapter of the BIG-IP Application Security Manager: Attack and Bot Signatures guide.

Note: After you configure these attack signatures, no further mitigation is necessary.
