K63122412: rSeries Platform may encounter kernel panic during clean installation if USB device is prematurely removed at the end of installation

Type
Support Solution
Published
2022-10-10
Updated
2023-02-21
Applies to
  • rSeries Platforms
  • F5OS
Source
https://my.f5.com/manage/s/article/K63122412

Description

A USB device is used to perform a clean installation of the rSeries Platform. The following actions may result in a kernel panic:
  1. After the USB clean installation completes the following is displayed on the serial console:
    "Installation complete.  Press return to quit"
  2. Press "return" and unplug the USB device is immediately from the rSeries platform.
  3. The following kernel panic is displayed on the serial console:

Cause

None

Recommended Actions

To avoid the kernel panic do not remove the USB device until the system boots into newly installed Host OS.
