Topic

You can use the bigstart utility to start services during startup, or to start, stop, and report service status from the command line.

  • Viewing current bigstart services
  • Adding services
  • Removing services

Viewing current bigstart services

To view the current list of services included in bigstart, type the following command:

bigstart list

The output displays three columns: Service, Boot, and Default. The Service column lists the system services. The Boot column indicates whether the service starts when the system starts. The Default column indicates the bigstart command will send signals to the services if no service specified.

You can send signals to the services that are listed under the Default column by using the following bigstart commands:

bigstart startup
bigstart reinit
bigstart restart
bigstart shutdown
bigstart kill
bigstart status
bigstart memstat

If you want a service to run when the system starts, and you want to control it using the bigstart commands, you must add the service to both Boot and Default.

Adding services

To add a service to the Boot group, type the following command:

bigstart add <service>

To add a service to the Default group, type the following command:

bigstart add --default <service>

Removing services

The service must first be stopped before it can be removed:

bigstart stop <service>

To remove a service from the Boot group, type the following command:

bigstart remove <service>

To remove a service from the Default group, type the following command:

bigstart remove --default <service>

Note: For more information about bigstart, refer to the bigstart man page.
