Description

When using gtm_add command to add a new DNS device to the sync group, an issue may be observed. The gtm_add script performs only a partial copy of the config, and the first error found following.

Nov 25 05:20:17 gtm.f5.com err sync_zones[18669]: Error from named-checkconf /config/named.conf:1: parsing failed: file not found

Environment

BIG-IP DNS all version

Cause

When you refer to a external file, such as custom rdnc key file, those file is not synchronized by gtm_add, thus named-checkconf fails to parse named.conf configuration.

For example, named.conf is following.

include "/config/myrndc.key";

Note: default rndc file is /config/rndc.key.

Recommended Actions

Before you execute gtm_add command, copy the custom file referred from named.conf to BIG-IP DNS that is newly added to sync group.

To copy, run following command

# scp user_name@<IP address of peer BIG-IP DNS>:<custom file name> /var/named/config
Following example copy the file named myrdnc.key from peer BIG-IP DNS 10.10.10.53.

# scp root@10.10.10.53:/var/named/config/myrndc.key /var/named/config
