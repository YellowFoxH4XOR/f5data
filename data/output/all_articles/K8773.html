Known Issue

This is the result of a known issue. When a UCS file is installed on the BIG-IP system, and the SSH access in the UCS file is different than on the system on which the UCS file is installed, SSH access is not changed after the UCS is loaded. This issue occurs even though the Configuration utility reflects the correct setting.

For example, if a UCS file with SSH access disabled is installed on a BIG-IP system with SSH access enabled, the Configuration utility shows that SSH access is disabled; however, SSH access remains enabled after loading the UCS file. The reverse is also true. If UCS file with SSH access enabled is installed on a BIG-IP system with SSH access disabled, the Configuration utility shows that SSH access is enabled; however, SSH access remains disabled after loading the UCS file.

F5 Product Development tracked this issue as CR99058 and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator release notes.

Workaround

To work around this issue, toggle the SSH access setting in the Configuration utility. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Platform.
  3. Click the SSH access box (to either clear or select the check box).
  4. Click Update.
  5. Click the SSH access box to set it back to the desired setting.
  6. Click Update.
