Topic

The BIG-IP APM system can gather device identifying information from Android devices running the BIG-IP Edge Client for Android and populate the information in session variables.

Description

A BIG-IP APM access policy can gather identifying information from an Android device running the BIG-IP Edge Client for Android, connecting to the BIG-IP system. This information is stored in session variables allowing the BIG-IP APM system to perform actions based on the results returned. For example, the BIG-IP APM system can perform actions such as logging clients' access to the BIG-IP APM system, customizing network access for android devices, or ensuring minimum Operating System versions. The following table lists the session variables and describes the information stored in each session variable.

Session VariableDescription
session.client.platformClient platform; always contains 'Android'
session.client.versionThe BIG-IP Edge Client version
session.client.modelThe descriptive model name of the Android device
session.client.platform_versionThe version of Android running on the device
session.client.mac_addressThe device MAC address
session.client.serial_numberThe device serial number

Note: Not all devices will send the serial number.

session.client.imeiThe device IMEI number

Note: Non phone devices may not have an IMEI number.

session.client.unique_idUnique device ID.

Note: Not available on Android 2.1 and earlier. Not all devices populate this field, and the field is easily modified on a rooted device. Therefore, it is not recommended as a reliable indicator of a unique device.
