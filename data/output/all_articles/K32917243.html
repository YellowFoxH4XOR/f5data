K32917243: Unable to generate SSHd DSA key larger than 1024 bit

Type
Support Solution
Published
2019-11-22
Updated
2025-04-02
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K32917243

Description
When trying to generate new DSA key with 2048 bits - ssh-keygen reports that DSA keys must be 1024 bits

  • Security scan discovered that there is possible to connect to F5 device (ssh) using weak DSA cipher with 1024 bits
  • Attempting to generate a 2048 bit DSA key fails with message indicating the DSA key must be 1024 bits:
    bash# ssh-keygen -q -f ssh_host_dsa_key -t dsa -b 2048 -N "" -C "$hostname"
    DSA keys must be 1024 bits
OpenSSL allows generation of DSA keys bigger than 1024 bits. However, the ssh-keygen on F5 devices (BIG-IP and BIG-IQ) only allow for 1024 bit DSA keys for SSHd.

Environment

  • BIG-IP, BIG-IQ
  • SSHd Deamon

Cause

BIG-IP and BIG-IQ devices only support 1024 bit DSA keys for SSHd. The reasoning behind the restricting DSA keys to 1024 bits in OpenSSH is a conflict between RFC recommendations and FIPS standard:

  • RFC4253 section 6.6 requires the SHA1 hash (160 bits) for ssh-dss (ie DSA) authentication: "Digital Signature Standard [FIPS-186-2] using the SHA-1 hash"

  • In FIPS 186-1 and 186-2 L could be any number between 512 and 1024 (inclusive) that was a multiple of 64. N was fixed at 160

  • FIPS 186-3 section 4.2 requires DSA keys >1024 bits to use a hash stronger than 160 bits.
    "FIPS-186-3 section 4.2 where it mandates the hash lengths for the various DSA key sizes:

    L = 1024, N = 160
    L = 2048, N = 224
    L = 2048, N = 256
    L = 3072, N = 256"


In order to comply with both RFC and FIPs, OpenSSH will only 1024 bit keys.

Recommended Actions

DSA keys for OpenSSH must be exactly 1024 bits, according to the standard. If you want larger keys, you'll need to make RSA keys instead of DSA keys and disable DSA. For information refer to K26031800: Increasing SSH keys from 1024-bit to 2048-bit keys.

Starting with the 7.0 release of OpenSSH, support for ssh-dss keys has been disabled by default at runtime due to their inherit weakness. This OpenSSH version is used in BigIP 14.x and 15.x but because of the need for backward compatibility, F5 still keeps DSA 1024 bit keys for access for SSH.
