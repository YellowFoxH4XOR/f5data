Description

Here is the output of:

# list sys service httpd
sys service httpd {
    Boot off
    Default no
}
 
How do we change 'Boot off' to 'Boot on' ?

Environment

  • Httpd

Cause

None

Recommended Actions

To enable Boot -> On for httpd, you need to run the following command at the CLI Bash prompt:
 
# systemctl enable httpd.service
 
To check this is enabled  run the following command :
 
# systemctl is-enabled httpd.service

enabled

Additional Information

K42515525: The sysvinit system has been replaced with the systemd software suite
