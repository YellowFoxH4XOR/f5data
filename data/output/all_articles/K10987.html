Note: For information about bypassing the BIG-IP PSM with an iRule in versions 9.4.5 through 9.4.8, refer to K10988: Bypassing the BIG-IP PSM module with an iRule in versions 9.4.5 through 9.4.8.

In BIG-IP PSM versions 10.0.1 and later, the following iRule commands can be used to enable or disable BIG-IP PSM processing for a particular protocol for certain requests or connections:

  • To disable or enable PSM for HTTP traffic:

    PSM::HTTP::enable
    PSM::HTTP::disable
     
  • To disable or enable PSM for FTP traffic:

    PSM::FTP::enable
    PSM::FTP::disable
     
  • To disable or enable PSM for SMTP traffic:

    PSM::SMTP::enable
    PSM::SMTP::disable

For example, to disable PSM processing for all URIs beginning with /bypass, use the following iRule:

when HTTP_REQUEST {
  PSM::HTTP::enable
  if { [HTTP::uri] starts_with "/bypass" } {
    PSM::HTTP::disable
  }
}

Note: When you use the PSM::disable command to bypass the BIG-IP PSM for one request, you should always re-enable PSM processing for subsequent connections by using the PSM::enable command at the top of the HTTP_REQUEST event. Otherwise, all subsequent requests on the connection will bypass the BIG-IP PSM module.
