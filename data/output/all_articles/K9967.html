Known Issue

This is the result of a known issue. The BIG-IP system permits users to perform a configsync operation on a non-redundant unit, potentially causing damage to the system. For example, if you attempt to run the bigpipe config sync command on a standalone system, the system will attempt to synchronize the UCS archive file to itself.

F5 Networks Product Development tracked this issue as CR112605 and it was fixed in BIG-IP version 10.0.0.  For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-9.6.1-839.0-HF3, which has been issued for BIG-IP version 9.6.1. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
