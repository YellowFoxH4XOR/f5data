Known Issue

This is the result of a known issue. Using the HTTP::header iRule command within the HTTP_REQUEST_SEND event causes the TMM to crash.

For example, the following iRule will cause the TMM to crash when traffic traverses a virtual server that references the iRule:

when HTTP_REQUEST_SEND {
  HTTP::header insert "some_header"
}

F5 Product Development tracked this issue as CR68779 and it was fixed in BIG-IP 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.
