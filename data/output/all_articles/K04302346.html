Environment

  • BIG-IQ Centralized Management
  • BIG-IP APM Discovered and Managed
  • Clienet Citrix Bundle HTML5 
  • APM Policy Deployment with connectivity profile containing Client  Citrix Bundle  

Cause

Most likely there is leftover from another HTML5 Citrix Client Bundle or Citrix Bundle with different name but the same files under (Access  ››  Connectivity / VPN : VDI / RDP : Citrix Client Bundles)  on BIG-IP APM where you would like to deploy APM Policy from BIG-IQ.
Due to the fact that when uploading Citrix html5 bundle zip  system is extracting files directly to  /config/filestore/files_d/Common_d/sandbox_file_d  and does not permit to overwrite files  (ID676169) BIG-iP can not create two separate hosted content with  the same files inside.

Recommended Actions

Verify  BIG-IP APM configuration  for Client Citrix Bundles.
 
  1. Check existing  Citrix Bundles under  Access  ››  Connectivity / VPN : VDI / RDP : Citrix Client Bundles 
    Verify if its listed in tmsh:
    tmsh list apm resource sandbox citrix
  2. If there is any exiting Not used Client Citrix Bundle remove it from BIG-IP
  3. Verify if  /config/filestore/files_d/Common_d/sandbox_file_d  contains files included into CitrixBundle zip file which was previously uploaded to the box
    ll /config/filestore/files_d/Common_d/sandbox_file_d | grep citrix-client-package
  4. Perform Deployment from BIG-IQ
