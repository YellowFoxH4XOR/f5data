Issue

Old Behavior

In versions prior to BIG-IP APM 10.2.1, session limits were based on only the concurrent user license limit.

New Behavior

Beginning in BIG-IP APM 10.2.1, the way you license sessions has changed. The BIG-IP APM system now has the following two limits:

  • Concurrent user license count
  • Application session limit

Sessions can be consumed by setting up the local application access. For each remote access connection (Network Access or portal access), the user's session will have one concurrent user license and one application session license.

Note: The number of sessions available is specific to the capabilities of the platform, and is unrelated to licensing.

The /var/log/apm file shows the number of concurrent users licensed and the maximum number of sessions available.

For example:

local/tmm notice tmm[10523]: 01490510:5: 00000000: Initializing Access with max global concurrent access session LICENSE limit: 10000

local/tmm notice tmm[10523]: 01490523:5: 00000000: Initializing Access with max global concurrent connectivity session LICENSE limit: 500

The License page indicates the number of concurrent users licensed and the number of maximum sessions allowed.

For example:

Access Policy Manager, 500CCU, 2500Access (C5211092-4187358)

F5 Product Development tracked this change as ID C815696.
