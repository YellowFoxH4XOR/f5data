K000141076: An error message 'Unsupported Media Type' is returned after executing BIG-IP Telemetry Streaming declaration

Type
Support Solution
Published
2024-09-16
Updated
2024-09-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000141076

Description

After use a curl command to declare a telemetry json file, you may get the following error message.

{

 "code": 415,

 "message": "Unsupported Media Type",

 "accept": [

  "application/json"

 ]

 

Environment

  • BIG-IP
  • Telemetry

Cause

'application/json' is not included in curl command

Recommended Actions

Need to include 'application/json' in the curl command, for example

#curl -sku admin:<your_admin_password> -X POST -H "Content-Type: application/json" -d @your.json https://<BIG-IP MGMT IP>/mgmt/shared/telemetry/declare | jq .

 

Additional Information

None.
