K000148702: BigIQ: Software installation shows "not ready" status

Type

Published
2024-11-25
Updated
2024-11-25
Source

Description

While on "Software Installations" menu, Installation properties status shows as "not ready"


  • Happens to any ISO file selected
  • ISO files have been correctly imported to BigIQ unit


Environment

BigIQ unit, when navigating to Devices > Software Management > Software Installations


  • Press "Managed device install"
  • Select any ISO file to be installed
  • Fill out all the task parameters
  • Add a BigIP unit to install ISO file to

Cause

"Not ready" status will be shown until all task parameters have been introduced and "Save/Save and close" button has been pressed.

Recommended Actions

Make sure all parameters options have been filled out and "Save/Save and close" button is pressed to save task.
