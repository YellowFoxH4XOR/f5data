K000139357: ArcSight CEF Format support for BIGIP system logs

Updated

Source

Description

ArcSight CEF Format support for BIGIP system logs and logs from other modules


Environment

  • ArcSight
  • CEF Format
  • System logs


Recommended Actions

ArcSight logging destination / ArcSight CEF format is only supported for modules AFM, ASM, and SWG components.


You could see this as a warning when you try to create a logging destination of ArcSight CEF format.


root@(bigip2ltm)(cfg-sync Standalone)(Active)(/Common)(tmos)# create sys log-config destination arcsight telemetry_formatted forward-to telemetry_hsl

There were warnings:

ArcSight destination /Common/telemetry_formatted is only supported for AFM, ASM, and SWG components.
