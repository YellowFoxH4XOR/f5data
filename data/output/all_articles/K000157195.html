K000157195: SIEM server is reporting error for syslog messages it receives from VIPRION devices

Type
Support Solution
Published
2025-11-02
Updated
2025-11-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 17.5.X, 17.5.0, 17.1.3, 17.1.1, 17.1.0, 17.1.2, 17.5.1
Source
https://my.f5.com/manage/s/article/K000157195

Description

SIEM server may not able to process syslog messages coming from VIPRION devices, as there is slot ID in front of the hostname. As a result SIEM reports error for the syslog messages it receives from VIPRION devices.

Environment

  • Syslog
  • VIPRION
  • SIEM server

Cause

None

Recommended Actions

To disable slot ID in front of the hostname run the below command.

tmsh modify sys syslog clustered-message-slot disabled

tmsh save sys config

Additional Information

None
