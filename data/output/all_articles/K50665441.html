K50665441: Getting ssl alert ''cert authority is invalid'' in browser after renewing the certificate for virtual server

Type
Support Solution
Published
2021-07-24
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K50665441

Description

SSL alert/error "certificate authority is invalid" when accessing the virtual server. 
The certificate presented by the virtual servers shows incorrect common name "localhost.localdomain" 
TCMPDUMP will show below certificate presented by BIG-IP.

* Server certificate:
* subject: C=US; ST=WA; L=Seattle; O=MyCompany; OU=IT; CN=localhost.localdomain; emailAddress=root@localhost.localdomain 
* issuer: C=US; ST=WA; L=Seattle; O=MyCompany; OU=IT; CN=localhost.localdomain; emailAddress=root@localhost.localdomain

Environment

  • Recently renewed SSL certificate and updated clientssl profile with new certificate 

Cause

Possible corruption of SSL profile. 

Recommended Actions

1. Delete the current clientssl profile causing the issue attached to virtual server in picture. 
2. Re-create the client ssl profile with same new renewed certificate.
3. Attach the newly created clientssl profile to virtual server. 

Additional Information

None.
