K000162137: ASM Signature "Install" button greyed out in the GUI

Type
Support Solution
Published
2026-07-08
Updated
2026-08-05
Applies to
  • BIG-IP
  • BIG-IP ASM: 21.0.0, 21.1.X, 21.1.0, 21.0.X, 21.X.X, 17.1.3
Source
https://my.f5.com/manage/s/article/K000162137

Description

When attempting to manually update ASM Attack Signatures on BIG-IP ASM, the "Install" button in the GUI may be greyed out, preventing installation. The GUI may display a signature entry (For example, ASM-AttackSignatures_20260603_180534.im) that does not correspond to any file present on disk. You may also see the message "installation file not available anymore" in the installation pop-up window.

Environment

  • Configuration Utility (GUI)
  • High Availability (HA) pair with ASM sync enabled

Cause

 A stale or orphaned ASM signature entry in the GUI that does not have a corresponding installation file on disk. This mismatch prevents the "Install" button from being enabled, blocking signature updates.

Recommended Actions

  1. Navigate either from CLI or GUI.
    CLI:
    List the files in the update directory:
    ls -l /var/lib/hsqldb/live-update/update-files
    GUI:
    System ›› Software Management: Live Update
  2. Under ASM Attack Signatures, delete any signature entries that do not have a matching file in the update directory (For example, orphaned entries).
  3. After cleanup, use "Check for Updates" or "Upload File" in the GUI to obtain and install the latest signature.
  4. Ensure future updates are performed from the active device, as per best practices.

Additional Information

  • If the required signature file is missing from the update directory, upload it manually before attempting installation.
  • Deleting unrelated or older signature entries will not resolve the issue; only orphaned entries (those without a corresponding file on disk) should be removed.
  • ASM signature updates should always be performed from the active device in an HA pair to ensure proper synchronization.
