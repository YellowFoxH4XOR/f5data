Known Issue

This is the result of a known issue. Audit messages are only logged when the mcpd log level is set to notice or lower (notice, debug, or info). If the mcpd log level is set to warning or higher (warning, error, critical, alert, or emergency), audit messages are not logged when auditing is enabled, regardless of the Audit Log settings.

F5 Product Development is tracking this issue as ID 284795 (formerly CR45325).

Note: By default, the mcpd process logs messages using the notice log level.

Workaround

You can work around this issue by setting the mcpd log level to notice or lower. To do so, type a command similar to the following at the command line:

bigpipe db Log.Mcpd.Level notice
