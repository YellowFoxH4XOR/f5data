K000159825: The statistic module is non functional for VS and pools

Source

Description

Virtual server and pool statistics are not displayed in the BIG-IP GUI on both nodes of a high-availability cluster running BIG-IP LTM. Traffic continues to flow normally through the BIG-IP, but statistical data for virtual servers and pools are unavailable, while AVR/Analytics data remains functional.

The issue manifests with error messages in logs:

Jan 21 15:10:55 lab.dom debug merged[11807]: 011b0999:7: tmstat_query: read_tmm_memory: no rows found
Jan 21 15:10:55 lab.dom debug merged[11807]: 011b1106:7: vscpu: no virtual_server_stat table compute_average

Environment

  • Bigip LTM

Cause

Corruption in TMM segment files (/var/tmstat/blade/tmm[x-x]) prevents the statistics subsystem from properly querying and displaying virtual server and pool statistics. The corrupted segment files cause the mcpd process to fail when attempting to retrieve statistical data, resulting in MCPE_NOT_FOUND errors.

Answer/Recommended Actions

1.Fail over traffic to the Secondary Device (standby node) and verify traffic flows properly.

2.On the Primary Device (now in standby), delete the corrupted TMM segment files:

# rm -f /var/tmstat/blade/tmm[0-3]

3.Restart TMM to regenerate the segment files:

# bigstart restart tmm

4.Verify the device returns to "Standby" status after TMM restart.

5.Fail back to the Primary Device to make it active again.

6.Allow the Primary Device to process traffic and verify virtual server statistics are now displayed correctly.

7.Repeat the process on the Secondary Device if needed.
