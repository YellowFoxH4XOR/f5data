Topic

You can configure an Application Tunnel to access the Administrative Console of a second FirePass controller. This configuration allows you to remotely administer a second FirePass controller when direct access to its Administrative Console is unavailable.

Configuring an Application Tunnel to access the Administrative Console of a second FirePass controller

You can configure an Application Tunnel by performing one of the following procedures according to your version.

FirePass version 5.x

To configure an Application Tunnel to access the Administrative Console of a second FirePass controller, perform the following procedure:

  1. On the first FirePass controller, log in to the Administrative Console.

  2. Click Application Access.

  3. Select a Resource Group for the new Application Tunnel from the Resource Group menu.

  4. Click the Add New Favorite link.

  5. Next to Name, enter the name of the Favorite.

    For example:

    Tunnel to Second FirePass

  6. From the Add new menu, select https.

  7. Next to the Add new menu, enter the IP address or fully qualified domain name (FQDN) of the second FirePass controller.

    Note: If you enter a FQDN, ensure that it is resolvable on Internet DNS servers.

  8. Click Add New.

Note: Be sure to record the information under Local Host: Port or Range. This information is required to access the second FirePass controller. For example, if the local host is 127.3.214.85 and the port is 443, you would open the Application Tunnel Favorite you just created and point the web browser to https://127.3.214.85/admin/.

FirePass version 6.x

To configure an Application Tunnel to access the Administrative Console of a second FirePass controller, perform the following procedure:

  1. On the first FirePass controller, log in to the Administrative Console.

  2. Click Application Access.

  3. Select a Resource Group for the new Application Tunnel from the Resource Group menu.

  4. Click the Web Application Tunnels tab.

  5. Click the Add New Favorite link.

  6. Enter the name of the Favorite next to Name.

    For example:

    Tunnel to Second FirePass.

  7. Enter the URL of the second FirePass controller next to URL.

    For example:

    https://192.168.15.1/admin/

    Note: You may use a fully qualified domain name (FQDN) instead of an IP address. If you enter a FQDN, ensure that it is resolvable on Internet DNS servers.

  8. Click the Add to allow list link.

  9. Click Add New.
