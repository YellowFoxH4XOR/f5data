Description

When docker is deployed in a Linux environment, it will by default modify iptables rules.
Misconfiguration of such rules can lead to problems connecting with Network Access.
Network Access may show "Connecting" but nothing is happening.

Environment

  • Linux Ubuntu OS
  • Network Access VPN using either f5fpc command or browser
  • docker is deployed

Cause

Outdated or wrong iptables rules have been enforced, causing inability to reach 1.1.1.1 or docker subnets overlapping with lease pool range(s).

Recommended Actions

Use one of these options:
  • run the following command to remove all unused networks:
docker network prune
  • reconfigure docker to stop injecting iptables rules (see links below)
