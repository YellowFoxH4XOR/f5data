K46398364: License reactivation is required for upgrading from ASM to Advanced WAF

Type
Support Solution
Published
2021-06-14
Updated
2023-02-21
Applies to
  • BIG-IP ASM: 16.X.X
Source
https://my.f5.com/manage/s/article/K46398364

Description
F5 has announced End of Sale of Application Security Manager, effective April 01, 2021. Existing ASM, or BEST bundle customers, under a valid support contract running BIG-IP version 14.1 or greater can reactivate the licenses to upgrade to Advanced WAF (Adv WAF). If you are running a BIG-IP Virtual Edition you must have VE SKU version V16 or a more recent license.

For more information on the product SKUs that this notice applies to, refer to K72212499: End of Sale announcement for BIG-IP ASM

For ELA customers, this upgrade of BIG-IP ASM licenses do not apply. For more information, refer to the ELA Customers section in K65550750: BIG-IP ASM End of Sale Migration???????

Environment

  • BIG-IP ASM
  • Appliance
  • Virtual Edition

Cause

End of Sale of Application Security Manager

Recommended Actions

If you currently own a STANDALONE or BEST Bundle ASM product and its software version meets the requirement, you can enable the Advanced WAF feature by doing a license reactivation.

After license reactivation, Advanced WAF will not show up as an "active module" under System>License, but you will have the following feature flags in the license file which will enable you to use WAF features:
    waf_gc : enabled
    mod_waf : enabled
    mod_datasafe : enabled

Verifying WAF features from cli:
 
# egrep '(waf_gc|mod_waf|mod_datasafe).+?enabled' /config/bigip.license
waf_gc :                            enabled
mod_waf :                           enabled
mod_datasafe :                      enabled

If you are not able to able to see the WAF feature flags after license reactivation, contact F5 Technical Support.
