Known Issue

An optimized Network Access profile on the BIG-IP APM system may cause browser instability.

This issue occurs when all of the following conditions are met:

  • You configured the BIG-IP APM system with an optimized Network Access profile.
  • You disabled (cleared) the Network Tunnel setting for the optimized Network Access profile.
  • The user downloaded BIG-IP Edge Client from a BIG-IP APM system that is not running a fixed software release.
  • The user attempts to establish the optimized Network Access session by clicking the Webtop Network Access link.

Impact

The Network Access session fails to initialize.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H439237 on the Diagnostics > Identified > Medium screen.
  • When you configure the optimized Network Access profile, you observe the following behavior:
    • When you click the Webtop Network Access link, a pop-up window appears and attempts to initialize the BIG-IP Edge Client connection for the session.
    • Shortly after the pop-up window appears, the browser stops responding and terminates the client's session.

Resolution

Status

Note: BIG-IP APM 11.3.0, 11.4.0, and 11.4.1 are not affected by this issue.

Workaround

To work around this issue, you can enable the Network Tunnel setting for the optimized Network Access profile. To do so, perform the following procedure:

Impact of workaround: The following procedure should not have a negative impact on your system.

Enabling the Network Tunnel setting for the Network Access profile

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Network Access.
  3. Select the name of the configured Network Access profile.
  4. Click the Network Settings tab.
  5. For Network Tunnel, select the Enable check box.
  6. Click Update.
  7. In the upper-left corner of the Configuration utility, click Apply Access Policy.
  8. Click the Apply Access Policy.
