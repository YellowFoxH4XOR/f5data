Description

NMS requires sqlite for backup and restore. NGINX documentation provides sqlite installation instructions with online package managers.

Environment

NMS

Cause

Documentation

Recommended Actions

Install sqlite offline:
Note: dependencies required such as make, C compiler, etc.
1. Download sqlite-autoconf-*.tar.gz from https://www.sqlite.org/download.html to your NMS platform
2. Run the following commands:

$ tar xvfz sqlite-autoconf-3071502.tar.gz

$ cd sqlite-autoconf-*

$ ./configure --prefix=/usr/local

$ make

$ make install
