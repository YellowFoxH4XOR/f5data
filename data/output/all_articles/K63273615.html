Description
Cannot discover DNS service for GTM in BIG-IQ
Error while transforming WideIP AAAA, exception 'NullPointerException' was returned

Environment
  • The following curl output shows an issues with 'Last resort Pool':
    restcurl -u admin:admin tm/gtm/wideip/aaaa/ 

    Example output:

    {
      "kind": "tm:gtm:wideip:aaaa:aaaastate",
      "name": "name.example.com",
     ...
      "failureRcodeTtl": 0,
      "lastResortPool": "aaaa \"\"",  <<--------------------
      "minimalResponse": "enabled",
     ...
    },
  • In GUI 'Last resort Pool' is seen as 'None' ;
  • In bigip_gtm.conf 'Last resort Pool' is not configured.
 

Cause

The REST database in the discovered BIG-IP is inconsistent due to some missing validations in certain DNS objects. Bug ID 853585

Recommended Actions

For WideIPs having the above string in the above REST response select 'None' for the 'Last resort Pool' and Update the configuration:

  1. Navigate to DNS  ››  GSLB : Wide IPs : Wide IP List
  2. Click the WideIP name
  3. Click Pools
  4. Select None for Last Resort Pool
  5. Click Update
