K000132904: Procedure for Reducing RestAPI Response of ASM/AWAF Event Log from BIG-IQ

Type
Support Solution
Published
2023-03-30
Updated
2023-03-30
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000132904

Description

This articles describes the procedure for trimming down the RestAPI responses of an ASM/AWAF event log from BIG-IQ.

Environment

  • ASM licensed on BIG-IP
  • BIG-IQ licensed
  • BIG-IQ DCD configured
  • Logging Profile configured to send logs to DCD

Cause

None.

 Recommended Actions

The following provide steps for extracting an ASM Event log using RestAPI and applying specific parameters to extracting the required information.
  1. Login to CLI
  2. To perform a Event log search with CURL, type in below command: 
    curl -u admin:admin -XPOST -H "Content-Type: application/json" -vk https://BIG-IQ CM/mgmt/cm/shared/es/logiq/asmindex/_search -d '
{                                                                                                                                                                                                                                                               "query":{
      "query_string":{
         "query":"support_id: 10961136626817826933"
      }
   },
   "from":0,
   "size":50,
   "sort":{
      "date_time":"desc"
   }
}
'
  3. Normally, a POST operation is performed in order to a search of the logs by a given support_id.

   "size":50,
   "sort":{

   }
}

  5. To trim down the response, use filter_path URL parameter.
  6. For example, to filter values of staged_sig_ids, do as the following: 
    POST https:///mgmt/cm/shared/es/logiq/asmindex/_search?filter_path=hits.hits._source
{
  "query":{
   "query_string":{
     "query":"support_id: 10961136626817826933"
   }
  },
  "_source": "ip_client",           <=====
  "from": 0,
  "size": 50,
  "sort":{
   "date_time":"desc"
  }
}
