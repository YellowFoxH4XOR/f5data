K372: Certificate licensing requirements for nodes accessed through BIG-IP

Topic

Although the certificate authority that supplies your certificates may have licensing limits on the number of nodes that may be associated with a server certificate, BIG-IP does not enforce any limits. Only one server certificate is required for each BIG-IP virtual server or SSL proxy.

Note: The host names of each node must match in order for the same certificate to be used successfully with multiple nodes.
