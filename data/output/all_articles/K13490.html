K13490: The BIG-IP GTM ZoneRunner utility fails to create DNS hint zones

Known Issue

The BIG-IP GTM ZoneRunner utility fails to create DNS hint zones. For example, if you attempt to use ZoneRunner to create a hint zone called myhint, the zone creation fails and the system generates an error message.

Impact

The hint zone is not created as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The system logs an error message to the /var/log/gtm file that appears similar to the following example:

    01150213:3: Zone 'myhint.' in file 'db.external.myhint.' contains errors: zone myhint/IN: has 0 SOA records. zone myhint/IN: has no NS records. zone myhint/IN: not loaded due to errors
  • The named-checkzone utility reports error messages that appear similar to the following examples:

    zone myhint/IN: has 0 SOA records
    zone myhint/IN: has no NS records
    zone myhint/IN: not loaded due to errors.

Workaround

To work around this issue, you can manually create the hint zone. To do so, perform the following procedure:

Impact of workaround: Incorrectly editing the DNS configuration files on a BIG-IP GTM system may cause issues, such as the ZoneRunner utility or BIND failing to start properly.

  1. Log in to the BIG-IP GTM command line.
  2. Stop the ZoneRunner process on the BIG-IP system by typing the following command:

    bigstart stop zrd
  3. Use a text editor to edit the /var/named/config/named.conf DNS configuration file and add the hint zone configuration.

    For example:

    zone "myhint." {
    type hint;
    file "db.external.myhint.";
    };
  4. Save the changes and exit the text editor.
  5. When you have completed the necessary changes to the DNS configuration files, type the following command to verify that the syntax is correct:

    named-checkconf -t /var/named -z -j /config/named.conf
  6. If no syntax errors were found, restart the named process by typing the following command:

    bigstart restart named
  7. Restart the ZoneRunner process by typing the following command:

    bigstart start zrd
