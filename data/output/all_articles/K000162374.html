K000162374: DO fails with Error initializing BigIp: Could not determine device port

Type
Support Solution
Published
2026-07-22
Updated
2026-07-22
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000162374

Description

BIG-IP failed to deploy a Declarative Onboarding declaration. DO accepted the request but failed during BIG-IP initialization with the following error messages in /var/log/restnoded/restnoded.0.log

Onboard starting for task
Platform: BIG-IP done w/ initial account setup
Error initializing BigIp: Could not determine device port
Failed to initialize BIG-IP
No device.
Onboard complete.

Environment

  • BIG-IP
  • DO

Cause

Misconfiguration of DO declaration

targetHost does not match Management IP

 

Answer/Recommended Actions

Update the DO declaration so that "targetHost" contains the correct management IP for BIG-IP.

 

Additional Information

None
