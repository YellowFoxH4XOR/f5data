Known Issue

The BIG-IP system fails to create a node IP address when you choose the Fully Qualified Domain Name (FQDN) option.

This issue occurs when all of the following conditions are met:

  • You configured the BIG-IP system to populate node IP Addresses using the Fully Qualified Domain Name (FQDN) option.
  • You have upgraded to BIG-IP 11.6.0 HF5.

Impact

The node IP address value remains empty.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Node IP address values remain empty even with successful Domain Name System (DNS) responses.
  • After upgrading the BIG-IP system to 11.6.0 HF5, nodes IP addresses are empty.
