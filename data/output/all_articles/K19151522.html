K19151522: Key management library returned bad status: -20, Domain names must be 63 characters or less

Type
Support Solution
Published
2021-09-30

2023-02-21
Applies to

  • BIG-IP DNS: 15.X.X, 15.1.0, 14.0.1, 14.0.0, 14.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.0.1, 15.0.0, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 15.0.X, 14.1.X, 15.1.X, 14.X.X
Source

Description

After upgrading to BIG-IP it is not possible to create dnssec keys with name longer than 24 characters in length.

Example:

DNS  ››  Delivery : Keys : DNSSEC Key List

Create ZSK: xxxxxxxxxx_example_com_zsk (24+ character name)

Key creation fails, yet no error message or warnings generated in GUI

/var/log/ltm:

err tmsh[21645]: 01420006:3: Key management library returned bad status: -20, Domain names must be 63 characters or less.
err mcpd[8171]: 01071746:3: Thales FIPS manager key (_Common_xxxxxxxxxx_example_com_zsk79811C34FA2F8541F40315D7ED08C82) create failed, retry attempt 1
 

Environment

  • BIG-IP DNS
  • netHSM
  • Unable to create DNSSEC key

Cause

ID1039205

Recommended Actions

Upgrade to v16.1+

Additional Information

The mechanics of nethsm key management has been redesigned in v16 for improved performance.
