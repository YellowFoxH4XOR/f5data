Description

When importing the configuration from BIG-IP cluster, "BIG-IP1" and "BIG-IP2" conflict in import occurs.
Trunk Interfaces reports configuration conflict on mac-address in Trunk Object.
Each Deployment change generates configuration-conflict.

Configuration conflict seen in GUI during process of import (Devices > BIG-IP Devices > Specific Device > Services > LTM service re-import)

Environment

  • BIG IQ 7.0 Centralized Management
  • LTM Config Imported
  • BIG-IP Cluster discovered
  • Trunk interfaces Configured On BIG-IP

Cause

Investigated in Bug ID826977, which is fixed in BIG-IQ v7.1

Recommended Actions

Upgrade BIG-IQ to 7.1 version which is not affected

Additional Information

None
