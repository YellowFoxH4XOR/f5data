Description

How to display a list of wide IPs with their corresponding pools and pool member IP addresses on BIG-IP DNS? My BIG-IP has over 100 wide IP pools and I want to view a summarized list that includes IP addresses. I need to move a site and confirm if we have any of these servers in one of our pools.

Environment

  • wide IP
  • pool member IP addresses

Cause

None

Recommended Actions

To obtain a list of wide IPs with their corresponding pools and pool member IP addresses on BIG-IP DNS, perform the following procedure:

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. Run the following command:

    show gtm wideip a all detail | grep -i -e "wideip\|Destination" -e Gtm::Pool::A -e Gtm::Pool

  3. Review the output which may appear similar to the following example:

    Gtm::WideIp::A www.mywip.int
      | Gtm::Pool::A pool1  
         | Gtm::Pool Member: pool1:A delmevip:bigip2
            |   Destination  : 172.16.0.140:80
    Gtm::WideIp::A www.myotherwip.int
      | Gtm::Pool::A pool1 
         | Gtm::Pool Member: pool1:A delmevip:bigip2
            |   Destination  : 172.16.0.140:80
      | Gtm::Pool::A pool2
         | Gtm::Pool Member: pool2:A delmevip:bigip2
            |   Destination  : 172.16.0.140:80
         | Gtm::Pool Member: pool2:A vip1:bigip2
            |   Destination  : 172.16.0.142:80
         | Gtm::Pool Member: pool2:A vip2:bigip2
            |   Destination  : 172.16.0.145:80

    For example, the above output indicates that wide IP www.mywip.int references pool1 and pool member 172.16.0.140:80.
