Description

With reference to the documentation of the iRule command "table", the session table entries will be synced to the HA peer unit.
So are the subtable entries .

Environment

  • BIG-IP
  • HA with mirror IP
  • Virtual server
  • iRule with table command

Cause

None

Recommended Actions

Refer to K15003, verify / configure the value for db key statemirror.mirrorsessions.

Additional Information

The active device will send the new table entry to the peer when the entry created, it is incremental sync.
