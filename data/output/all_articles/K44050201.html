Description

When loading a UCS archive onto a BIG-IP DNS system the (old) configuration from the UCS can overwrite the current sync group, resulting in a loss of configuration data that can be impossible to recover.

Environment

  • BIG-IP DNS Synchronization Group
  • UCS
  • RMA
  • synchronization yes in global-settings

Cause

When a UCS Archive is loaded, the Configuration Time of that BIG-IP DNS system is updated to the current time. If gtm global-settings general { synchronization } is set to yes (Synchronization Enabled) in the UCS, and the synchronization-group-name is the same as the rest of the BIG-IP DNS systems, then this device will load the (old) UCS configuration then push that configuration to the rest of the Synchronization Group Members.

Recommended Actions

Option 1

Follow the guidance of K14083: Preventing synchronization when installing a UCS archive on a BIG-IP DNS system

Option 2

Perform the following steps to update a UCS archive to set synchronization no and change the synchronization-group-name to a different value.
Note: The synchronization-group-name will be changed back to the desired value when performing gtm_add to update this devices configuration.
Note: A UCS archive is simply a GZIPed Tarball

  1. SSH to log into the Advanced Shell (bash) prompt of the desired BIG-IP DNS

  2. Copy the UCS Archive to /var/local/ucs/<name_of_ucs>
    Where <name_of_ucs> is the name of the UCS Archive you will be loading.

  3. Set UCSFILE variable to the name of the UCS Archive
    UCSFILE=<name_of_ucs>

  4. Set DIR variable to the path where the UCS archive is located:
    Note: Usually /var/local/ucs
    DIR=<path_of_ucs>
    UCSDIRFILE="${DIR}/${UCSFILE}"

  5. cd to same directory as ucs
    cd ${DIR}

  6. Rename the archive so we can decompress it.
    mv "${UCSDIRFILE}" "${UCSDIRFILE}.tar.gz"
    gzip -d "${UCSDIRFILE}.tar.gz"

  7. Extract config/bigip_gtm.conf from the tarball
    tar xf "${UCSDIRFILE}.tar" config/bigip_gtm.conf -C "${DIR}/"

  8. Disable synchronization and change the synchronization-group-name
    sed -i 's,^    synchronization yes,    synchronization no,g;s,    synchronization-group-name.*,    synchronization-group-name rma_prep,g' config/bigip_gtm.conf

  9. Remove config/bigip_gtm.conf from the archive
    tar -vf "${UCSDIRFILE}.tar" --delete config/bigip_gtm.conf

  10. Update the tarball with the updated config/bigip_gtm.conf
    tar rf "${UCSDIRFILE}.tar" config/bigip_gtm.conf

  11. gzip and rename the archive
    gzip "${UCSDIRFILE}.tar"
    mv "${UCSDIRFILE}.tar.gz" "${UCSDIRFILE}"

  12. Verify config/bigip_gtm.conf was properly updated.
    tar zxOf "${UCSDIRFILE}" config/bigip_gtm.conf | grep -A5 '^gtm global-settings'
