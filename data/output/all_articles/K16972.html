Known Issue

Access sessions may fail to initialize.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration includes an access policy that queries Active Directory user group attributes by using the member attribute.
  • Active Directory is configured with user groups that are members of other groups within the same domain. For example, if group A has group B as a member, and group B has group A as a member.

Impact

User access sessions fail to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Successfully authenticated users are unable to establish an access session.
  • When running the apd process in debug mode, while the issue occurs, repeating log messages similar to the following example are logged to the /var/log/apm file:

  • In extreme cases, all users are unable to establish access sessions until the apd process has been restarted on the affected device.
