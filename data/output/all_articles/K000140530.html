K000140530: Change license offering for BIG-IP VE from BIG-IQ

Description

Your subscription is part of a Flex Consumption Plan (FCP) and you need to relicense a BIG-IP VE that uses a catalog (CAT) license offering from the BIG-IQ.

Environment

  • BIG-IQ

  • BIG-IP VE

  • Flexible Consumption Plan (FCP)
  • Catalog (CAT) license keys 

Cause

Either the current CAT license offering is expiring or the BIG-IP VE simply requires a different license. 

Recommended Actions

If adding a new CAT key, you'll need to activate it and its license offerings, otherwise, skip directly to the Change License instructions to update the license on the BIG-IP VE. 

Activate the new CAT license keys

  1. Logon to MyF5 > Subscriptions > Subscription ID (Active) to retrieve the latest CAT license key.
  2. Follow either article to activate the CAT key and their license offerings on the BIG-IQ.
    • K52854215: Automatically install FCP licenses for BIG-IP VEs using BIG-IQ
    • K15420056: How to manually license FCP in BIG-IQ

Note: If these keys are missing from your Subscriptions, please email your Customer Success Manager at CustomerSuccess@f5.com.

Assign the new CAT license offering to the BIG-IP VE using the Change License option

The Change License option provides visibility into the current license on the BIG-IP VE and the new license about to be assigned. This process revokes the original license offering and grants the new one in a single step.

  1. On the BIG-IQ > Devices tab > License Management > Assignments
  2. Check the box to the left of the BIG-IP then click Change License above. The Current Assignment is listed above and the New Assignment is below.
  3. If your BIG-IP is unmanaged, enter the credentials for the BIG-IP, otherwise select these parameters.
    • License Type: Utility
    • Name: <New CAT key created above>
    • Offering: <lists only activated offerings>
    • Unit of Measure: Yearly
    • Chargeback Tag: <optional, but only available at activation>
  4. Assign and confirm to apply.
    Important: Applying the license on the BIG-IP is traffic impacting as its services restart while processing the new license. F5 recommends performing these changes during a maintenance window.
  5. Notice under Devices > License Management > Assignments that the status of the BIG-IP is now active and running (green)
  6. On the BIG-IP, after its services restart, verify the license via System > License. It should be provided by the BIG-IP and match the offering just assigned.

Additional Information

Prior to updating the license, confirm the health of the remote BIG-IP VE by running "tmsh load sys config verify" from its command line. Resolve any errors that are returned. Note: If you need to open a support case to address errors, use the last seven characters of the CAT license key as the serial number per K000133079: How to open a Support case for a BIG-IP VE licensed by FCP.
