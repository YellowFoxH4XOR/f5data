Description

POSTing an AS3 declaration to BIG-IP results in a 404 Error "Task Not Found".
 

Environment

  • BIG-IP
  • Large AS3 Declaration
  • Task Not Found

Cause

The restjavad process for the task timed out on BIG-IP

Recommended Actions

Verify that the <task_id> returned in the error message has indeed timed out.

grep <task_id> /var/log/restjavad.0.log

If you see a log message stating "TimeoutException", then the process has timed out:

[8100/mgmt ForwarderPassThroughWorker] URI:http://localhost:8100/mgmt/tm/task/cli/script/<task_id>, Referrer:Unknown, Method:GET, Exception:java.util.concurrent.TimeoutException: remoteSender:Unknown, method:GET

Review the AS3 best practices guide to see ways to mitigate this condition.

 

Additional Information

Use the DbVariables class to increase the timeout values on BIG-IP if using Declarative Onboarding:

DO snippet:

.....
        "class": "Tenant",
        "dbvars": {
            "class": "DbVariables",
            "icrd.timeout": 180,
            "restjavad.timeout": 180,
            "restnoded.timeout": 180
        }
.....
