Description

If client receives an HTTP 503 'Service Unavailable' error, when trying to reach a server through the BIG-IP system and when bypassing the BIG-IP system, the client encounters no such response code.

Environment

  • BIG-IP LTM or AFM
  • Pool member

Cause

  • Sender of the error may be too busy, or the service is not running.
  • Either the sender of the error itself, or a firewall in front of it may be filtering the request.
  • The sender of the error may be requiring the client to send a certain HTTP 'Host ' header.
  • When the file type or file is not allowed to access for requestor

Recommended Actions

  1. This requires further investigation to confirm which source has generated the error. This can be identified by taking tcpdump on F5 and it should cover both client and server side streams,
    # tcpdump -nn -vvv -ni 0.0:nnnp -s0 host  <IP address> -w /var/tmp/<File name>.pcap
    To capture the traffic, you may either use virtual server IP or client IP (public or private IP) which we expect to see on F5 as source, or  both IPs can be used in the packet capture shown below. 

    # tcpdump -nn -vvv -ni 0.0:nnnp -s0 host  <VS IP address> or host  < Client IP address>  -w /var/tmp/<File name>.pcap 
    For more details on tcpdump and available filters, refer K411
     
  2. If traffic is encrypted with SSL or VIP and pool members are configured to listen on 443, taking captures using above commands may not help. Below article will help to take decrypt that traffic, K12783074.
     
  3. Verify the response packet which has HTTP error code and look for "Line-based text data:" header as it give more details in any HTTP error code.
  4. Investigate the server side requirements

Additional Information

  1. Most 500-level errors do not come from the BIG-IP system and are typically not caused by a misconfiguration on the BIG-IP system. 

  2. A 503 Service Unavailable error means that the page or resource is unavailable. There are many reasons why a server might return a 503 error, but some common reasons are maintenance, a bug in the server's code, or a sudden spike in traffic that causes the server to become overwhelmed.

    The message that's sent with the 503 error can vary depending on server it's coming from, but here are some of the common ones you'll see:

  • 503 Service Unavailable
  • 503 Service Temporarily Unavailable
  • HTTP Server Error 503
  • HTTP Error 503
  • Error 503 Service Unavailable
  • The server is temporarily unable to service your request due to maintenance downtime or capacity problems. Please try again later.
