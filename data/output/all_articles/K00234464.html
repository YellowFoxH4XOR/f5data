Description

Error trying to discover a HA pair of F5's on the BIG-IQ....Error querying BIG-IP

[ERROR][21 Jul 2021 16:42:28 CDT][/cm/adc-core/tasks/discover-config/994274b2-0d19-490b-8684-031da7efd50c/worker AdcDiscoveryTaskWorker] Error querying 'Tunnel' from path '/mgmt/tm/net/tunnels/tunnel' on device TestBigIP.com (192.168.1.1), network communication failed due to protocol error : java.net.ProtocolException: status:400, body:{"code":400,"message":"01070712:3: Internal error, can't load folder or nested folder for: /internal-lb-test/iapp-pciconnect.app/iapp-pciconnect_connect","errorStack":[],"apiError":3}

Environment

  • BIG-IQ - BIG-IP discovery
  • Configuration objects in the bigip_base.conf do not match

Cause

Mismatch of configuration objects in the bigip_base.conf between the Big-IP HA pair

Recommended Actions

  1. Review the bigip_base.conf file on both members of the F5 to identify the mismatch and remove to make the bigip_base.conf the same
  2. In the example error below there is a  listed tunnel that is not present on the Standby F5 (mismatched between the two HA members.)

    [ERROR][21 Jul 2021 16:42:28 CDT][/cm/adc-core/tasks/discover-config/994274b2-0d19-490b-8684-031da7efd50c/worker AdcDiscoveryTaskWorker] Error querying 'Tunnel' from path '/mgmt/tm/net/tunnels/tunnel' on device TestBigIP.com (192.168.1.1), network communication failed due to protocol error : java.net.ProtocolException: status:400, body:{"code":400,"message":"01070712:3: Internal error, can't load folder or nested folder for: /internal-lb-test/iapp-pciconnect.app/iapp-pciconnect_connect","errorStack":[],"apiError":3}
     
  3. In the GUI on both F5 members in the HA navigate to 
    Network  ››  Tunnels : Tunnel List
     
  4. Compare the Active to the Standby tunnel list and remove the tunnel not present on the Active F5
