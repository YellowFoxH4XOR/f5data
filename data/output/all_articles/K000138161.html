K000138161: Subject Alternative Name (SAN) for GUI TLS-certificate

Type
Support Solution
Published
2024-01-11
Updated
2024-01-24
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000138161

Description

No option for Subject Alternative Name (SAN) when generating the Certificate Service Request or new self-signed certificate.

Environment

  • F5OS < 1.8.0

Cause

The function wasn't implemented in the previous versions. Since F5OS 1.8.0, the function was added via ID1496397.

Recommended Action

Upgrade F5OS to 1.8.0.

If F5OS upgrade is not an option, consider generating a key and CSR outside the system. Once CSR is signed, and a cert is issued by Certificate Authority, import the key and cert to the F5OS system.

Additional Information

F5OS-A 1.8.0 release notes: https://techdocs.f5.com/kb/en-us/products/f5os-a/releasenotes/related/relnote-supplement-f5os-a-1-8-0.html#A1496397-1
F5OS-C 1.8.0 release notes: https://techdocs.f5.com/kb/en-us/products/f5os-c/releasenotes/related/relnote-supplement-f5os-c-1-8-0.html#A1496397-2
