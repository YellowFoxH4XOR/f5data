Issue

Description

warning snmpd[<PID>]: 010e0999:4: Duplicate oid index found: bigip_gtm_server_stat2.c:143

In this error message, note the following:

  • <PID> is the process ID for the snmpd process.

For example:

warning snmpd[1234]: 010e0999:4: Duplicate oid index found: bigip_gtm_server_stat2.c:143

Environment

  • BIG-IP DNS
  • Redundant BIG-IP DNS systems configured as a GTM server

Cause

The snmpd process uses the redundant system name to create the object identifier (OID). Because there are two entries with the same name, the snmpd process reports a warning.

Recommended Actions

You should consider one of the following actions:

  • The messages are benign; you can safely ignore them.
  • Upgrade the system to BIG-IP 13.x or later. Starting in BIG-IP 13.0.0, redundant GTM server objects are defined in a different way, and the log message will not appear.
  • Filter the log message by adding the following to the include section in the syslog configuration:

    filter f_local0 { facility(local0) and not match(bigip_gtm_server_stat2); };

    To add the filter, use the following procedure:

    1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

      tmsh

    2. Add the filter by typing the following command:

      modify /sys syslog include "filter f_local0 { facility(local0) and not match(bigip_gtm_server_stat2); };"

    3. Save the changes by typing the following command:

      save /sys config
