Description

This article provides a brief explanation of the output of the following command.

Environment

  • BIG-IP LTM
  • Using CLI

Cause

None

Recommended Actions

  1. Log in to the BIG-IP command line.
  2. Run the following command:  tmsh show sys ip-stat
  3. The explanation of the outcome of the article is the following:

root@(BIG-IP)# show sys ip-stat
