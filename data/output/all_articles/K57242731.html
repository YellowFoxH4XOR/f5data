K57242731: INFO WireServer endpoint is not found. Rerun dhcp handler

Type
Support Solution
Published
2020-06-04
Updated
2025-04-02
Applies to
  • Public Cloud
  • BIG-IQ
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K57242731

Description

When deploying a BIG-IQ instance in Azure with an environment that uses Custom DNS, the BIG-IQ may not allow login and the console will display multiple errors, including 
  • INFO WireServer endpoint is not found. Rerun dhcp handler
  • WARNING No route exists to 168.63.129.16
  • WireServer is not responding. Reset endpoint

Environment

  • Azure Public Cloud
  • Custom DNS

Cause

Azure's Linux Agent needs to use 168.63.129.16 as its endpoint to install.
This is related to Bug ID719241

Recommended Actions

Complete the Recommended Actions in the following article to resolve this issue:
K55449974: BIG-IQ deployment fails in Azure with Long running operation failed with status 'Failed'
