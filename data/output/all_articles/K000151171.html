Description

When you check the "system health", you may see error similar below that says "Fan Speed Sensor Fault".

fantray-1         -     ok         error      chassis/hardware/vfc1 - vfc:health:fan:speed:sensor:fault  Fan Speed Sensor Fault  unhealthy  error      true           2025-04-30T03:39:49+08:00  
                                              chassis/hardware/vfc1 - vfc:sensor:speed:exhaustfan1       Exhaust Fan 1 (RPM)     unhealthy  error       sensor fault  2025-03-28T13:24:49+08:00

While on the "system events", "Sensor fault detected in hardware".

65577 fan-controller-1 sensor-fault ASSERT ERROR "Sensor fault detected in hardware" "2025-03-28 05:24:49.761165288 UTC"              
65798 fan-controller-1 fan-controller-fault ASSERT ERROR "Fault detected in Fan Controller health" "2025-03-28 05:39:49.148986413 UTC"

Environment

  • VELOS
  • Exhaust Fan
  • Fan Speed Sensor

Cause

The fan tray may have encountered problem with the sensor.

Recommended Actions

The fan tray is removable if it needs to be replaced but should not be removed for long periods of time, as overheating may occur.

  1. Try re-seating the fan tray and get the Fan Tray serial Number. You can refer to K000149083.
  2. If issue persist, open an F5 support. Replacement of fan tray may be needed.
