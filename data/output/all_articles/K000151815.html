Description

You take UCS backup of BIG-IP and those are stored into an external servers. You import those backup from external server to the BIG-IP via CLI. When you access backup via GUI (System > Archives > Click on the UCS backup which was imported), you get below message in the GUI.

General database error retrieving information. 

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • BIG-IP
  • UCS backup

Cause

File permission discrepancy. For example, under /var/local/ucs you see the UCS backup has no "read" permission for Group or Public:

# cd /var/local/ucs

# ll

-rw-------. 1 root webusers 101213 Jun 10 12:00 BIG-IP_backup.ucs 

Recommended Actions

Change the permissions of the UCS archive to rw-r--r-- (644) using the following command syntax:

# chmod 644 <filename>.ucs 

For example:

# chmod 644 BIG-IP_backup.ucs
