Description

Creating a regex string in Nginx which would match on multiple paths similar to the following examples:


/app1/path-a/*

/app1/path-b/sub-path/*

/app1/path-c/*


Environment

Nginx Plus


Cause


Customers might be looking to simplify their Nginx configuration by using regex to match multiple paths to a single location block.


Recommended Actions

A regex value in the location block similar to the following will match all of the above examples:


location ~* ^/app1/(path-a|path-b/sub-path|path-c)/


Breaking down the example above:

  • "~" indicates regex syntax will follow
  • "*" in this position indicates no case sensitivity
  • "^" indicates the start of the path match
  • "/app1/" will always match on this exact string
  • "(path-a|path-b/sub-path|path-c)" will match on any of the above example paths/subpaths
  • inside the parenthesis, the pipe character("|") is used as the "OR" operator between the different path values﻿
