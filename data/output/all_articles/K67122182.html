Description

When accessing APM Client Software from the GUI (Configuration utility) System  ››  Software Management : APM Clients) an error similar to the following is displayed :

General database error retrieving information.

Important: There are multiple reasons as to why you may see this database error when browsing the GUI. Unless this article fits your case exactly, it is recommended to start with General Database Error Retrieving Information in the BIG-IP Configuration Utility , which helps you discover the right article for you.

Environment

  • BIG-IP APM
  • Configuration utility (GUI)
  • APM Clients 

Cause

Unknown and may be related to a browser issue.

Recommended Actions

  • Clear the browser's cache 
  • Use a different browser 
  • Use Incognito Mode with all extensions disabled in Incognito

Additional Information

None
