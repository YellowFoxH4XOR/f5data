Removing the command line Edge Client SSL VPN components

To remove the command line Edge Client SSL VPN components from a Linux system, perform the following procedure:

  1. Log in to the Linux system command line.
  2. To uninstall the BIG-IP Edge Client components, type the following command:

    sudo /usr/local/lib/F5Networks/uninstall_F5.sh

    Note: If you are logged on to the Linux command line as root, the sudo command prefix is not required.

    The system prompts you to enter your password in order to run the command with sudo.

    The /usr/local/lib/F5Networks/uninstall_F5.sh script displays output similar to the following example:

  3. Remove /usr/local/lib/F5Networks by typing the following command:

    sudo rm -r /usr/local/lib/F5Networks

    Note: If you are logged on to the Linux command line as root, the sudo command prefix is not required.

Removing the FirePass SSL VPN components

To remove the FirePass SSL VPN components from a Linux system, perform the following procedure:

  1. Log in to the Linux system command line.
  2. Change directories to the /usr/local/lib/ directory by typing the following command:

    cd /usr/local/lib/

  3. Remove the main SSL VPN components by typing the following command:

    sudo rm -r F5Networks

    Note: If you are logged on to the Linux command line as root, the sudo command prefix is not required.
