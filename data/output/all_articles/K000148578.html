K000148578: Ephemeral pool members down

Type
Support Solution
Published
2025-02-26
Updated
2025-02-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000148578

Description

  • Ephemeral pool members are down
  • Assigned Health checks on the pool members are passing and reporting pool up.

Environment

  • BIG-IP LTM
  • Ephemeral pool
  • Default node monitoring

Cause

Ephemeral Nodes are using default node ICMP monitor. And backend servers are not entertaining the ICMP requests, thus making the ICMP monitoring failed.

Recommended Actions

  1.  Set the monitoring for the ephemeral nodes to none, the Pool members will be back online.

Additional Information

Please make sure to change the default monitoring of the ephemeral nodes in questions only.
