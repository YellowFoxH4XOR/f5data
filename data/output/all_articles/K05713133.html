Description

You should consider using this procedure under the following condition:

  • You want to configure a custom cipher list for iQuery connections for big3d
  • To configure the cipher settings for gtmd (iQuery client) follow K31434426

Default ciphers:

tmsh list sys db big3d.ssl.cipherlist all-properties

sys db big3d.ssl.cipherlist {
    default-value "AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA"
    scf-config "true"
    value "AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA"
    value-range "string"
}
 

Environment

  • BIG-IP DNS or LTM part of iQuery mesh

Cause

None

Recommended Actions

In order to configure the iQuery connection to only use specific cipher, follow all of the procedures below.

Reconfigure the big3d process to use specific cipher

  1. Log in to the tmsh utility by entering the following command:

    tmsh

  2. Run following command to update the db to use AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:

    modify sys db big3d.ssl.cipherlist value AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA

  3. Restart big3d is required to re-establish the iQuery connection. This action should not be traffic impacting.

    restart sys service big3d

Additional Information

An iQuery connection is an SSL connection on port 4353 from a gtmd process to the big3d process on a remote or local BIG-IP. When big3d starts, it listens for port 4353 on all configured self IP addresses and the management interface IP address.   By default the iQuery establishes an SSL connection to the remote big3d process using version TLS1.0 or higher.   In some situations this SSL connection needs to run at a higher TLS version
