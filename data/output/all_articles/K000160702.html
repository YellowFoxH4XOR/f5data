Description

MANA is a next-generation network interface that provides stable forward-compatible device drivers for Windows and Linux operating systems.

Environment

  • BIG-IP VE
  • Microsoft Azure
  • Microsoft Azure Network Adapter

Cause

You want to confirm whether your BIG-IP device is compatible with Microsoft Azure Network Adapter (MANA).

Answer/Recommended Actions

Gather basic information about your BIG-IP deployment like:

  • BIG-IP version
  • Family and series; i.e. Dv5

They should be obtainable from HyperVisor level.

Check compatibility here: MANA support for existing VM series

BIG‑IP VE does not directly bind to NIC hardware drivers (e.g., MANA or Mellanox). It relies on the Azure NetVSC synthetic network interface, which remains supported regardless of underlying NIC hardware.

If TMOS does not yet natively support MANA, Azure automatically provides NetVSC fallback, which Microsoft states delivers performance close to legacy SR‑IOV paths.  

No traffic outage is expected due to MANA rollout alone. No known BIG‑IP VE HA defects related to MANA deployment. MANA change does not alter IP addressing or NIC enumeration. F5 HA architecture reference: https://clouddocs.f5.com/cloud/public/v1/azure_index.html

Validation steps post-MANA rollout:

Run:

lspci | grep -i mana

to check for MANA VF presence.

Run:

ip link show

to verify network interfaces.
