Issue

Description

In the case that multiple certificates are present in the client devices local store, Machine Cert Auth can fail if the certificates have different Certificate Authorities (CAs).

Environment

  • BIG-IP APM
  • Client device with multiple certificates from differing CAs
  • Virtual server with access policy that has Machine Cert Auth configured

Cause

Certificates are processed in the order they are presented. If the first certificate presented is from a CA that doesn't match the one configured in the Machine Cert Auth object, authentication will fail.

Recommended Actions

Configure one or more of the "Match" fields in the Machine Cert Auth object to ensure the appropriate client certificate is compared. This process is detailed in K13614: Overview of the access policy Machine Cert Auth action.

In most cases, the "Match Issuer" field should provide the appropriate filter to select the proper certificate.
