K000138000: Calculating memory usage percentage on F5OS

Description

On the F5OS system memory usage can be checked with the command:


# show components component platform state memory

state memory available 9054806016

state memory free 723111936

state memory used-percent 93

state memory platform-total 16107667456

state memory platform-used 7216357376


the same values are also available using SNMP OID F5-PLATFORM-STATS-MIB:memoryStatsTable (.1.3.6.1.4.1.12276.1.2.1.4.1):

F5-PLATFORM-STATS-MIB::memAvailable."platform" = Counter64: 9054806016 bytes

F5-PLATFORM-STATS-MIB::memFree."platform" = Counter64: 723111936 bytes

F5-PLATFORM-STATS-MIB::memPercentageUsed."platform" = INTEGER: 93 percentage

F5-PLATFORM-STATS-MIB::memPlatformTotal."platform" = Counter64: 16107667456 bytes

F5-PLATFORM-STATS-MIB::memPlatformUsed."platform" = Counter64: 7216357376 bytes


However, the memory used-percent is not directly calculated from the memory platform-used and memory platform-total values.

In other words:

used-percent ≠ ( platform-used / platform-total ) *100


Using values from the example:

93 ≠ ( 7216357376 / 16107667456 ) * 100


Environment

  • F5OS
  • memory usage percentage

Cause

The platform-used and platform-total values refer to memory allocated to the Host system. These are the values that can also be seen in GUI under Dashboard -> System Summary.

In the example, the whole physical memory available is 128GB but only 15GB (platform-total 16107667456) are allocated to the Host system.


The used-percent value is calculated from the whole physical memory (memory allocated to the Host system + memory allocated to tenants). Memory allocated to tenants is technically used (even where there are not tenants deployed). The exact values can the checked under /proc/meminfo:


# cat /proc/meminfo

MemTotal:      131577312 kB

MemFree:         708064 kB

MemAvailable:   8845844 kB

[...]


From the above values:

used-percent = ( ( MemTotal - MemAvailable ) / MemTotal ) * 100


93 ≈ ( ( 131577312 - 8845844) / 131577312 ) * 100
