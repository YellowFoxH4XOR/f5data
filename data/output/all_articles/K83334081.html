Known Issue

The Configuration utility may become unresponsive.

This issue occurs when any of the following conditions are met:

  • You attempt to access the Configuration utility.
  • You attempt to create, modify, delete, or view a configuration object using the Configuration utility.

Impact

The Configuration utility connection request fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Repeating log messages similar to the following are logged to /var/log/restjavad.<numeric value>.log:

    Note: The current restjavad log name is restjavad.0.log.

    restjavad.0.log:[SEVERE][<pid>][<date and time>][ChildWrapper] Timed out waiting for <http method> request at <big-ip url> Killing child process <pid>

  • When you attempt to access the Configuration utility, the request fails with a connection timeout error.

Resolution

Workaround

To work around this issue, you can restart the restjavad service to recover the Configuration utility functionality. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the TMOS Shell (tmsh).
  2. Type the following command to restart the restjavad service:

    restart /sys service restjavad

  3. To view the restjavad service state, type the following command.

    show /sys service restjavad

  4. To exit tmsh, type the following command:

    quit
