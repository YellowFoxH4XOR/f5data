Topic

Beginning in BIG-IP 14.0.0, you can use the iControl REST API or TMOS Shell (tmsh) to run the following BIG-IP DNS configuration scripts:

  • gtm_add
  • big3d_install
  • bigip_add

This extension offers two new methods to call the BIG-IP DNS configuration scripts. For more information about these configuration scripts, refer to K13312: Overview of the BIG-IP DNS big3d_install, bigip_add, and gtm_add utilities (11.x - 15.x).

Description

The following sections provide iControl REST API and tmsh command syntax for the respective actions of the BIG-IP DNS configuration scripts as well as how to delete commands in history that contain passwords:

  • iControl REST API command syntax
  • tmsh command syntax
  • Delete passwords from command history

iControl REST API command syntax

DNS scriptCommand syntax
gtm_add

curl -sku <Username>:<Password> -X POST -H "Content-type: application/json" -d '{"command":"run",\
"options":[{"ssh-password":"<Password>","<Optional_Flags> <Username>@<Existing_GTM_IP_Address>":""}]}' \
https://<New_GTM_IP_Address>/mgmt/tm/gtm/gtm_add

big3d_installcurl -sku <Username>:<Password> -X POST -H "Content-type: application/json" -d '{"command":"run",\
"options":[{"ssh-password":"<SSH_Password>","<Optional_Flags> -use_ssh\
<Username>@<GTM/LTM_to_add_IP_Address>":""}]}' https://<Existing_GTM_IP_Address>/mgmt/tm/gtm/big3d_install
bigip_addUsing a default username for the peer system:
curl -sku username:password -X POST -H "Content-type: application/json" -d '{"command":"run",\
"options":[{"ssh-password":"<SSH_Password>","<Optional_Flags> <Default_User>@<GTM/LTM_to_add_IP_Address>":""}]}' \
https://<Existing_GTM_IP_Address>/mgmt/tm/gtm/bigip_add
Using a selected username for the peer system:
curl -sku username:password -X POST -H "Content-type: application/json" -d '{"command":"run",\
"options":[{"ssh-password":"<SSH_Password>","<Optional_Flags> <Username>@<GTM/LTM_to_add_IP_Address>":""}]}' \
https://<Existing_GTM_IP_Address>/mgmt/tm/gtm/bigip_add

tmsh command syntax

DNS scriptCommand syntax
gtm_addrun /gtm gtm_add password <SSH_Password> <Optional_Flags> <Username>@<Existing_GTM_IP_Address>
big3d_installrun /gtm big3d_install password <SSH_Password> <Optional_Flags> -use_ssh <Username>@<GTM/LTM_to_add_IP_Address>
bigip_addUsing a default username for the peer system:
run /gtm bigip_add password <SSH_Password> <Optional_Flags> <Default_Username>@ <GTM/LTM_to_add_IP_Address>
Using a selected username for the peer system:
run /gtm bigip_add password <SSH_Password> <Optional_Flags> <Username>@<GTM/LTM_to_add_IP_Address>

bigip_add-d enables debug mode.
-a enables appliance mode.

Delete passwords from command history

Since all the commands in this article require you to include the SSH password in clear text, you should remove them from your command history. To do so, perform the following procedure:

  1. Log into the BIG-IP command line where you entered the tmsh or iControl REST commands or the workstation where you entered the iControl REST commands.
  2. Enter the following command to find the line number:
    history
  3. Delete the command containing the password using the following syntax:
    history -d <line number>
  4. Repeat steps 2 and 3 for other commands containing passwords.
