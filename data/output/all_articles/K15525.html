Known Issue

You are unable to add RAID array members using the Configuration utility.

Impact

Users cannot use the Configuration utility to manage RAID array members.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility displays the following error message:

    No Access

  • In the /var/log/httpd/httpd_errors file, you may observe an error message similar to the following example:

    err httpd[3424]: [error] [client 10.0.0.1] proxy: error processing end, referer: https://10.0.0.2/tmui/Control/jspmap/tmui/system/raid_mgmt/list.jsp

Workaround

To work around this issue, you can use the command line to manage RAID array members. To do so, perform the following procedure:

Impact of workaround: Performance impact should be minimal, but if you have a concern, this procedure should be performed either on the standby BIG-IP system or during a maintenance window.

Adding a disk to the RAID array using the command line

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Confirm which drive should be added to the RAID array, by typing the following command:

    show /sys raid bay

    Assuming that HD2 is the drive that you are adding to the RAID array, the output appears similar to the following example:

    -------------------------------------------------------------
    Sys::Raid::Bay
    Bay Shelf Name Serial Number Array Member Array Status
    -------------------------------------------------------------
    1 1 HD2 WD-WCAW31499053 no undefined
    2 1 HD1 WD-WCAW31301422 yes ok

  3. Add the drive to the RAID array by using the following command syntax:

    modify /sys raid array <array name> add <drive name>

    For example, assuming that HD2 is the drive that is being added to RAID array MD1, type the following command:

    modify /sys raid array MD1 add HD2

    You will see the following output:

    info: Begin adding disk sdb to array...
    info: Addition (pending) of disk sdb to array successful.

  4. Monitor the status of the RAID replication using the command in step 2.

    During replication, output will appear similar to the following:

    -------------------------------------------------------------
    Sys::Raid::Bay
    Bay Shelf Name Serial Number Array Member Array Status
    -------------------------------------------------------------
    1 1 HD2 WD-WCAW31499053 yes replicating
    2 1 HD1 WD-WCAW31301422 yes ok

    When the operation is complete, the Array Status value will be set to ok for all drives.
