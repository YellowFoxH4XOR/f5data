Description
You have updated the Device Certificate or Key using the Command line.

tmsh modify sys httpd ssl-certfile /config/httpd/conf/ssl.crt/server.crt

An error is returned:
Useless use of AllowOverride in line 283 of /var/run/config/httpd.conf.
Useless use of AllowOverride in line 12 of /etc/httpd/conf.d/xui.conf.

Environment
  •  BIG-IP

Cause
This is a side effect of the device certificate and key not matching.

Recommended Actions

  1. Ensure that the certificate and key do match.
    openssl x509 -noout -modulus -in /etc/httpd/conf/ssl.crt/server.crt
    openssl rsa -noout -modulus -in /etc/httpd/conf/ssl.key/server.key

    The output of both must match.
     
  2. When they are correct, tell the system to update both at the same time
    tmsh modify sys httpd { ssl-certfile /config/httpd/conf/ssl.crt/server.crt ssl-certkeyfile /config/httpd/conf/ssl.key/server.key }
     
  3. Restart the http process
  • tmsh restart /sys service httpd         or
  • bigstart restart httpd
