Description

You may see the below error message when creating the client SSL Profile:
Error Message: 01070313:3: Error reading key PEM file /<partition>/<keyfile> for profile /<partition>/<profile_name>: error:0906A065:PEM routines:PEM_do_header:bad decrypt

In this error message, note the following:

  • <keyfile> is your TLS/SSL key name
  • <profile_name> is your client SSL profile name

For example:
Error Message: 01070313:3: Error reading key PEM file /Common/mykey for profile /Common/my-client-ssl: error:0906A065:PEM routines:PEM_do_header:bad decrypt

Environment

  • BIG-IP systems
  • SSL Profile
  • Certificates/Key Import

Cause

An incorrect passphrase was given, or no passphrase was given when configuring the SSL profile.

Recommended Actions

Configure the proper passphrase for your SSL profile. To do so, you may follow:

  1. Under the SSL profile creation page, click the item in the Certificate Key Chain,
  2. Click the Edit button,
  3. A pop-out window shows, put your correct passphrase in the passphrase text box,
  4. Click OK,
  5. Click Save at the bottom of the page.

If you do not know if you have the correct password for the SSL key, you can use the following openssl command to verify:

 

openssl rsa -in <your-key-file> -check

Note: You will be prompted for the passphrase.

 

Example: When an incorrect passphrase was given:

openssl rsa -in mykey.key -check
Enter pass phrase for mykey.key:
unable to load Private Key
139982414037440:error:06065064:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt:../crypto/evp/evp_enc.c:564:
139982414037440:error:0906A065:PEM routines:PEM_do_header:bad decrypt:../crypto/pem/pem_lib.c:461:

 

Example: When a correct passphrase was given: 

openssl rsa -in mykey.key -check
Enter pass phrase for mykey.key:
RSA key ok
writing RSA key
