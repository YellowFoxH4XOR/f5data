Description

Explains how to change the SSH authentication method on BIG-IP LTM systems from the default challenge-response (keyboard-interactive) authentication to password authentication.

Environment

  • BIG-IP LTM

Cause

This is a functional question.

Answer/Recommended Actions

To enable password authentication for SSH on BIG-IP:

1. Log in to the BIG-IP CLI.

2. Enter tmsh configuration mode:

tmsh

3. Edit the SSHD configuration:

edit sys sshd

4. Add the following configuration:

modify sshd {
    include "
    ChallengeResponseAuthentication no
    PasswordAuthentication yes"
    }

5. Save the system configuration:

save sys config

6. Verify the change:

show running-config sys sshd

Additional Information

UCS files includes the SSH authentication method change, and restoring the backup preserves the setting.
