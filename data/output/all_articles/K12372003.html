Known Issue

When you license a BIG-IP Virtual Edition (VE) from the BIG-IQ system, the licensing may fail.

This issue occurs when the following condition is met:

  • You use the BIG-IQ system to license a BIG-IP VE instance.

Impact

The BIG-IP VE system does not get licensed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IQ system displays the licensing operation as successful; however, the BIG-IP VE system is not licensed.
  • In the /var/log/ltm log file you observe an error message similar to the following example:

    Dossier error 16

  • In the /var/log/restjavad file, you observe a message similar to the following example:

    Dossier validation failed. error code: 5.
