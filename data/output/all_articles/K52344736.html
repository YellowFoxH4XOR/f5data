Description
Under rare circumstances, there may be lots of bcm56xxd errors generated in /var/log/ltm

Nov 27 23:47:47 localhost info bcm56xxd[7970]: 012c0016:6: REG_RESTORE: MAXBUCKETCONFIG_64[45658] blk: mmu0 index: 6 : port[0]
Nov 27 23:47:47 localhost info bcm56xxd[7970]: 012c0016:6: unit 0 MINBUCKET port 0 index 6 parity error
Nov 27 23:47:47 localhost info bcm56xxd[7970]: 012c0016:6: SER_CORRECTION: reg/mem:48209 btype:9 sblk:0 at:0 stage:0 addr:0x00000000 port: 0 index: 6
Nov 27 23:47:47 localhost info bcm56xxd[7970]: 012c0016:6: soc_reg_set: WARNING: write to 32-bit reg MINBUCKET with hi order data, 0x55bb1300
Nov 27 23:47:47 localhost info bcm56xxd[7970]: 012c0016:6: REG_CLEAR: MINBUCKET[48209] blk: mmu0 index: 6 : port[0]

This soft parity error recovery alone does not indicate a hardware failure and does not warrant an RMA. Further troubleshooting is required to determine the root cause.

Environment

  • BIG-IP
  • ??bcm56xxd errors

Cause
The errors are generated as the BIG-IP does not currently track the frequency or overall count of these error corrections. 

Recommended Actions

  1. Reboot to clear the errors.
  2. If the errors persist, run an EUD test.
  3. If there's a hardware failure found, proceed to RMA.
