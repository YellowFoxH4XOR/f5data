Description

After marking down the pool members manually, BIG-IP advanced routing protocols advertise routes such as BGP and OSPF, if virtual address route advertisement configuration options are enabled or any options except disabled.

Environment

  • Advanced Routing Protocol
  • Disable all pool members of the pool in VS.
  • Border Gateway Protocol (BGP)
  • Routing Information Protocol (RIP)
  • Intermediate System-Intermediate System (IS-IS)
  • Open Shortest Path First (OSPF)

Cause

When you disable all pool members manually in the virtual server, you can observe that the virtual server status is still available, which is by design an expected behavior, hence virtual address is still available and routes can be advertised.

Recommended Action

If you want not to advertise a route to a neighbor for virtual address or server, perform either of them below:

  • Use force offline all pool members of pool in VS instead of disabling all pool members.
    (OR)
  • Disable Virtual address  (Local Traffic ›› Virtual Servers : Virtual Address List).
