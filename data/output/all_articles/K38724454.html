Description

macOS clients with Kaspersky software installed are unable to establish VPN tunnel using the F5 Edge Client.

Environment

  • BIG-IP APM
  • F5 Edge Client versions 7180 and 7182
  • macOS
  • Kaspersky software

Cause

The Kaspersky software is causing the VPN tunnel to fail to be established.
The Kaspersky software does the following:

  • Deletes interface VPN "utun0X" which is mounted by F5 Edge Client
  • Change host file for access.destination host by 127.0.0.1 instead original destination IP

Recommended Actions

If the Kaspersky software is required to be enabled on your client system, contact Kaspersky LAB to obtain fix.

Alternatively, you can uninstall the Kaspersky software from the client system.
