K43007843: Limits on the number of ephemeral node entries for an FQDN pool

Type
Knowledge
Published
2019-12-17
Updated
2023-02-21
Applies to
  • BIG-IP LTM: 15.X.X
Source
https://my.f5.com/manage/s/article/K43007843

Topic

The maximum number of node entries for a fully qualified domain name (FQDN) pool is limited by the User Datagram Protocol (UDP) payload size for DNS messages.

Description

When you configure the BIG-IP system to auto-populate pools using FQDNs, the system queries the DNS server for FQDN information at the interval provided in the node configuration and updates the node and pool member list with the information provided in the DNS response.

The maximum number of node entries for a FQDN pool is limited by the UDP payload size for DNS messages. This is expected behavior. The payload size for UDP DNS responses is limited to 512 bytes, and the normal behavior of a DNS server needing to send a UDP response that would exceed the 512-byte limit is for the server to truncate the response so that it fits within that limit. As a result, if your FQDN references a large number of DNS records, such as over 30 A records, you may observe fewer pool members for the FQDN pool than expected.
