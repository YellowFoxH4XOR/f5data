Issue

The apmd process on BIG-IP system appears to be consuming excessive memory or may be experiencing a memory leak.

You need to collect diagnostic data to investigate the root cause.

Environment

  • Product: BIG-IP
  • Component: APM (Access Policy Manager)
  • Version: All versions
  • APM Memory leak

Cause

Memory leaks in the apmd process can occur due to various reasons including software defects, configuration issues, or specific traffic patterns.

Proper diagnostic data collection is essential for root cause analysis.

Resolution

To effectively troubleshoot apmd memory consumption issues, collect the following data in the specified order:

Step 1: Collect QkView at HIGH apmd memory usage

Generate a QkView when apmd memory consumption is elevated, before taking any corrective action:

nice -n 19 qkview -s0 -f /var/tmp/$(/bin/hostname)_$(date +"%y%m%d-%H%M%S")-apmd-before-core.qkview

Step 2: Collect process memory map (pmap)

Capture the memory mapping of the apmd process:

/bin/pmap $(pidof apmd) >/var/tmp/pmap.apmd.out

Step 3: Collect system call trace (strace)

Trace the apmd process system calls:

/bin/strace -xf -tt -p $(pidof apmd) -o /var/tmp/strace_apmd.txt

Note: Allow this command to run for several minutes to capture sufficient data, then press Ctrl+C to terminate the trace.

Step 4: Generate apmd diagnostic core

Create a diagnostic core dump of the apmd process:

kill -v -s 6 $(pidof apmd)

Note: This will cause apmd to restart automatically. The core file will be generated in /var/core/

Step 5: Collect QkView at LOW apmd memory usage

After the apmd process restarts and memory usage returns to normal levels, generate another QkView:

nice -n 19 qkview -s0 -f /var/tmp/$(/bin/hostname)_$(date +"%y%m%d-%H%M%S")-apmd-after-core.qkview

Step 6: Collect log tarball

Gather all relevant logs:

tar -czf /var/tmp/logs_apmd_$(date +%Y%m%d_%H%M%S).tar.gz /var/log/

Step 7: Upload data to F5 Support

Upload all collected files to your support case:

  • Both QkView files (high and low memory states)
  • pmap output file
  • strace output file
  • Core dump file from /var/core/
  • Log tarball
