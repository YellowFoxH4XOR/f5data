K000136151: enabling ASM internal parameter "likely_false_positive_mode" might cause bd crash

Type
Support Solution
Published
2023-09-11
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136151

Description:

enabling ASM internal parameter "likely_false_positive_mode" might cause bd failure and produced a core file.

 

Environment:

  • BIG-IP ASM or Advanced WAF.
  • ASM internal parameter "likely_false_positive_mode" enabled

 

Cause:

The related bug is ID1348945

Setting "likely_false_positive_mode" through 

/usr/share/ts/bin/add_del_internal add likely_false_positive_mode 1 

might causes bd to crash while processing a request

 

Additional Information:

None

 

Recommended Actions:

Please avoid to enabling ASM internal parameter "likely_false_positive_mode"
