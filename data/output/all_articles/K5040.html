Known Issue

Note: This issue occurs only on BIG-IP platforms equipped with a Packet Velocity ASIC (PVA).

This is the result of a known issue. If you configure two SSL proxies with the same IP address, but with different ports, the PVA daemon is not able to distinguish the proxies. When the PVA daemon encounters a duplicate IP address, it reconfigures itself and logs the following error in the /var/log/pva.log file.

bapi_db_global_::load(): key collision for SSL_PROXY IP: <address>

This issue will cause performance loss.

F5 Networks Product Development tracked this issue as CR45017 and CR48148 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch.
