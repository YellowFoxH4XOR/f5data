K000161627: F5OS host fails to authenticate with FreeRADIUS

Description

F5OS host does not authenticate with FreeRADIUS on a new configuration

Environment

  • F5OS
  • Freeradius

Cause

The FreeRADIUS dictionary file may be missing the $include directive required to load the F5-specific Vendor-Specific Attributes (VSAs), or missing the attributes themselves. Without this directive or VSAs, the FreeRADIUS server cannot parse the attributes needed for F5OS authentication, even if the client entry and dictionary file are otherwise correct.

Answer/Recommended Actions

Locate the main FreeRADIUS dictionary file (typically /etc/freeradius/dictionary), and verify that the F5 dictionary file is present on the FreeRADIUS server 

Additional Information

F5OS uses a different set of RADIUS attributes than classic BIG-IP tenants. Even if tenant RADIUS authentication is working correctly, F5OS host authentication requires its own specific VSAs to be loaded by the RADIUS server. See https://my.f5.com/manage/s/article/K000134627 for details,
