K000135949: [F5OS] Running out of disk capacity

Type
Support Solution
Published
2023-08-23
Updated
2025-02-04
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000135949

Description

F5OS Qkview can not be generated as disk is full, and "System Storage" on Dashbord also tells high usage.

Running command below on the F5OS CLI (log in as root)

df -h | grep -v lib

/dev/loop7 4.1G 4.1G 0 100% /var/images/R5R10/1.3.2-13054
...

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • Disk usage

Cause

  • /sysroot usage is 100% due to old and large core files.

Recommended Actions

For information about managing core files on the F5OS system, including how to list and delete core files, refer to the following resource:

  • K000138300: Overview of managing core files in F5OS

Additional Information

  • If the cause of the 'System Storage' message is not related to core files and you and need to gather more information such as essential log files, then run the below command (log in as root) 
qkview-collect
NOTE: The output file are not able to processed in F5 iHealth site, as this is just gather log files. Please upload to the case.
