Description

How to get the BIG-IP device state in HA pair by querying BIG-IQ.

 

Environment

BIG-IP HA pair discovered into BIG-IQ.

 

Cause

 

BIG-IP HA pair discovered into BIG-IQ.

 

Recommended Actions


When querying the below resource the device HA state will be shown at the moment the device was discovered into the BIG-IQ:

restcurl -X GET -u admin:admin /mgmt/cm/device/dsc/current/cm/device/<machine_id>
 

Once the device state actually changes in the HA (e.g. failing over to peer) the above resource will not be updated automatically.

To get the accurate device status the following two commands need to be run:

restcurl -X GET -u admin:admin /mgmt/cm/device/dsc-group/

{

 "items": [

  {

   "id": "283a1854-4671-3e7c-b375-c4b6703eb302",

...

 

Then using the "id" value from above,

 

# restcurl -X GET -u admin:admin /cm/device/dsc-group/283a1854-4671-3e7c-b375-c4b6703eb302 | jq '.devices[] | {name, trafficGroupStatus}'

{

 "name": "bigip1.device",

 "trafficGroupStatus": [

  {

   "trafficGroupName": "/Common/traffic-group-1",

   "nextActive": "true",

   "failoverState": "standby",

   "objects": []

  }

 ]

}

{

 "name": "bigip2.device",

 "trafficGroupStatus": [

  {

   "trafficGroupName": "/Common/traffic-group-1",

   "nextActive": "false",

   "failoverState": "active",

   "objects": []

  }

 ]

}
