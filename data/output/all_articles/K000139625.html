K000139625: The deploy button does not work when deploying a new BIG-IP Next instance

Type
Support Solution
Published
2024-05-15
Updated
2025-09-02
Status
Legacy Content
Applies to
  • BIG-IP Next
  • BIG-IP Next Central Manager: 20.2.X, 20.2.0
Source
https://my.f5.com/manage/s/article/K000139625

Description

After completing the setup wizard to deploy a new BIG-IP Next instance, the blue Deploy button is clickable but it does not submit anything to Central Manager.

Environment

  • BIG-IP Next Central Manager
  • Deploying a new BIG-IP Next instance using the vSphere provider deployment wizard
  • Firefox browser

Cause

The Firefox browser does not submit the form when the Deploy button is clicked. This is being tracked by ID 1585505.

Recommended Actions

Configure a new BIG-IP Next instance using Chrome or Edge.

Additional Information

None
