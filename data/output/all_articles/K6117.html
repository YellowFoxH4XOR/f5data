Known Issue

The qkview script included in BIG-IP Local Traffic Manager (LTM) versions prior to 9.1.2 does not obtain core files when the /var/core directory is a symbolic link.

F5 Networks Product Development tracked this issue as CR48884 and CR58718 and it was fixed in BIG-IP LTM versions 9.1.2 and 9.2.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

To work around this issue, download the latest version of qkview from the F5 Downloads page.
