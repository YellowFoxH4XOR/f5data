K91302639: Error Message - Trust establishment failed; reason: The device <ip address>> (null) is not a BIG-IP device

Type
Support Solution
Published
2022-02-25
Updated
2025-04-01
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K91302639

Description
When attempting to discover a BIG-IP device on a BIG-IQ, you may encounter an error stating that the BIG-IP device at <xx.xx.xx.xx> is not a BIG-IP device.

Environment

  • BIG-IQ discovering BIG-IP

Cause
Restjavad daemon not registered on BIG-IP, causing BIG-IQ's inquiries to return without expected system information.

Recommended Actions

On BIG-IP command line, type the following command:

bigstart restart restjavad

Additional Information
None.
