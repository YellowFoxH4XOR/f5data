Known Issue

The BIG-IP APM system may rewrite VBScript arguments incorrectly.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured for Portal Access.
  • Your system attempts to rewrite a response that contains VBScript.
  • A VBScript object uses the open method for an argument list.

The BIG-IP APM system VBS patcher may incorrectly rewrite arguments when using the open method in VBScript. For example, requests to open a file named xmlfile.xml may fail when using code similar to the following example:

Set xmlHttp = CreateObject("Microsoft.XMLHTTP")
Call xmlHttp.open("GET", "xmlfile.xml")
Call xmlHttp.send()
End Sub

Impact

The VBScript does not function as intended.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP APM system sends a reordered VBScript argument list to the client.
  • Clients cannot access BIG-IP APM Portal Access resources.
