Known Issue

BIG-IP managed devices may fail to establish Secure Sockets Layer (SSL) connections with the Enterprise Manager Centralized Analytics feature. This issue occurs when all of the following conditions are met:

  • The BIG-IP managed device is provisioned with the BIG-IP Analytics module.
  • The BIG-IP managed device is running an affected version listed in the Applies to (see versions) box, located in the upper-right corner of this article.

Impact

The Enterprise Manager Centralized Analytics feature is unable to generate the analytics report for the BIG-IP managed device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to use the Enterprise Manager Configuration utility to view an analytics report (for example the Transaction statistics) for an affected BIG-IP managed device, the Enterprise Manager fails to display the requested analytics report and reports an error message similar to the following example in its Configuration utility:

    The selected devices are unreachable or don't have the monpd deamon in a running state

  • At the same time, you observe an error message similar to the following example in the /var/log/avr/monpd.log file on the Enterprise Manager system:

    monpd|ERR|Mar 13 01:09:40.592|10741| [DistributedReportRunnerHandler::reduce::reduce, ] Failed to open a transport on 172.16.22.166. Reason: SSL_connect: certificate verify failed...

Resolution

Status

F5 Product Development has assigned ID 455840 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
