Summary

Depending on the BIG-IP WebAccelerator version, you may require a specific role to access the WebAccelerator section of the BIG-IP Configuration utility.

Description

BIG-IP WebAccelerator 11.x

In BIG-IP WebAccelerator 11.0.0 and later, all roles are allowed view access to the WebAccelerator section of the BIG-IP Configuration utility. The Administrator and Resource Administrator roles have the privilege to create, modify, and delete WebAccelerator policies and invalidate content in the BIG-IP Configuration utility.

In BIG-IP WebAccelerator 11.1.0 and later, the Acceleration Policy Editor role is introduced to allow the associated user account to create, modify, and delete WebAccelerator policies and invalidate content. However, the Acceleration Policy Editor role has read-only access to the Local Traffic section of the BIG-IP Configuration utility.

BIG-IP WebAccelerator 9.4.0 through 10.2.4

The Administrator role is required for users to access the WebAccelerator section of the BIG-IP Configuration utility.

The following user roles are not allowed access to the WebAccelerator section of the BIG-IP Configuration utility:

  • Guest
  • Operator
  • Application Editor
  • Manager
  • User Manager
  • Resource Administrator

Unauthorized users attempting to access the WebAccelerator section of the BIG-IP Configuration utility will receive the following error message:

You Are Not Authorised to View this Page
An authentication problem has been encountered.
Please close this window, and log in from the main BIG-IP interface.

Recommendations

When creating users on the BIG-IP WebAccelerator, you should consider the following factors:

  • In WebAccelerator 11.1.0 and later, you can assign the Acceleration Policy Editor role to the user if the user requires full access to the WebAccelerator section but read-only access to the Local Traffic section of the BIG-IP Configuration utility.
  • In WebAccelerator 11.0.0 and later, you can assign either the Administrator or Resource Administrator role to the user if the user requires full access to both the Local Traffic and WebAccelerator sections of the BIG-IP Configuration utility.
  • In WebAccelerator 9.4.0 through 10.2.4, you must assign the Administrator role to the user if the user requires full access to the WebAccelerator section of the BIG-IP Configuration utility.
