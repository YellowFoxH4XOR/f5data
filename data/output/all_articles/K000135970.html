Description

You have accessed Velos webUI with the standby controller IP address and you noticed F5OS dashboard in webUI does not display partition overview.

Environment

  • VELOS
  • System Controller
  • Partition Overview
  • WebUI

Cause

The partition overview will only be showing on the active controller.

Recommended Actions

Please use the management IP address to access on the webUI but do not use the controller ip address to access it.
By using the webUI management address you will always access the primary controller.

Note: F5 recommends you always perform config changes and commands on the primary controller or blade. This is because the standby controller or blade does not support config changes and does not support all show commands.
Messages and errors must be viewed in conjunction with other system events and not in isolation.
