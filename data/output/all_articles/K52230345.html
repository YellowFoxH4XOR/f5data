Description

A newly configured Virtual Server works for most users, but for others the BIG-IP sends a SYN, RST back to the client. For these failed client connections, nothing is forwarded to the pool members.

Environment

  • Virtual Server
  • Source Address

Cause

The source address configured for the affected Virtual Server, is wrong due to a typo, and excluding some IP ranges to be allowed to connect to the Virtual Server.

Recommended Actions

Check the Source Address configured for access to the Virtual Server and adjust if needed.

Additional Information

The Source Address on a Virtual Server specifies an IP address or network from which the virtual server accepts traffic. The virtual server accepts clients only from one of these IP addresses. The default value allowing all client IPs is 0.0.0.0/0.
