Topic

A BIG-IP DNS synchronization group (sync group) is a collection of BIG-IP DNS systems that share configuration settings and metrics information. Changes you make to any system in the sync group are automatically propagated to all other BIG-IP DNS systems in the group.

Description

BIG-IP DNS systems that are part of a sync group share and synchronize configuration settings and metrics information. You should create a synchronization group if you want BIG-IP DNS systems to work together to monitor the availability and performance of global resources and use that information to manage network traffic patterns. There is no pre-defined limit on the maximum number of BIG-IP DNS systems allowed in a sync group.

Sync group communication

BIG-IP DNS systems in a synchronization group establish an iQuery connection to each sync group member using the defined self IP address and TCP port 4353. When you make a change to the BIG-IP DNS configuration, the local mcpd process forwards the new configuration to the local gtmd process. The gtmd process updates the configuration timestamp and instructs the local big3d process to begin advertising the updated configuration to all remote gtmd processes.

Synchronization details

When you configure BIG-IP DNS synchronization, the sync group members share and synchronize BIG-IP DNS configuration objects and metrics data. The following table lists the relevant configuration objects and whether the objects are synchronized.

Synchronization group requirements

Before you configure synchronization, you should be aware of the requirements for BIG-IP DNS synchronization group members to communicate and synchronize properly. For more information, refer to K13734: BIG-IP DNS synchronization group requirements.

Configuring BIG-IP DNS synchronization

Before you configure a DNS synchronization group, make sure that you have at least one fully configured BIG-IP DNS installed on your network. When you enable synchronization, the BIG-IP DNS system that is already installed on your network shares its configuration with other BIG-IP DNS systems that you want to add to the BIG-IP DNS synchronization group.

To configure BIG-IP DNS synchronization, you perform four procedures: three on the fully-configured BIG-IP DNS system to prepare the existing system for synchronization and one on the new BIG-IP DNS system to initiate the synchronization process:

  • Enabling synchronization (existing BIG-IP DNS)
  • Creating a data center (existing BIG-IP DNS)
  • Creating a server (existing BIG-IP DNS)
  • Running the gtm_add script (new BIG-IP DNS)

Enabling synchronization (existing BIG-IP DNS)

  1. Log in to the Configuration utility.
  2. Go to DNS > Settings > GSLB > General.
  3. Under Configuration Synchronization, select the Synchronize check box.
  4. For Group Name, enter the name of the synchronization group. F5 recommends using a group name that is not 'default'
  5. For Time Tolerance, enter the maximum number of seconds that you want to allow between the time settings on this system and the other systems in the synchronization group.
  6. If you want to synchronize DNS zone files and named configuration, select the Synchronize DNS Zone Files check box.
  7. Select Update.

Creating a data center (existing BIG-IP DNS)

Create a new data center on the existing BIG-IP DNS to represent the location of the new BIG-IP DNS system.

  1. Log in to the Configuration utility.
  2. Go to DNS > GSLB > Data Centers > Data Center List.
  3. Select Create.
  4. Enter a name for the data center.
  5. For Location, enter the geographic location of the data center and new BIG-IP DNS.
  6. For Prober Preference, select the type of prober to use to monitor resources in the data center.
  7. For State, select Enabled.
  8. Select Finished.

Creating a server (existing BIG-IP DNS)

  1. Log in to the Configuration utility.
  2. Go to DNS > GSLB > Servers > Server List.
  3. Select Create.
  4. Enter a name to represent the new BIG-IP DNS system.
  5. For Product, select BIG-IP System.
  6. For Data Center, select the data center you created in the previous procedure.
  7. Under Devices, select Add.
  8. For Device Name, enter the name of the new BIG-IP DNS system.
  9. In the Add BIG-IP System Device pop-up window, for Address, enter the non-floating (self IP) internet-facing NAT address of the new BIG-IP DNS system.
  10. For Translation, enter the non-floating (self IP) private network address of the new BIG-IP DNS system.
  11. For Link, select the appropriate ink. Select Auto-Select if you are unsure which option is appropriate.
  12. Select Add.
  13. Select OK.
  14. Under Configuration, for Health Monitors, in the Available list, select the BIG-IP monitor that you want to assign to the server and move it to the Active list.
  15. Under Resources, for Virtual Server Discovery select the appropriate option.
  16. For Link Discovery, select the appropriate value. Select  Disabled if you are unsure of the appropriate value.
  17. Select Finished.

Running the gtm_add script (new BIG-IP DNS)

To initiate the synchronization process, run the gtm_add script on the new BIG-IP DNS system. The gtm_add script integrates a new BIG-IP DNS system into the existing sync group. The script uses the SSH protocol to copy the remote BIG-IP DNS system's SSL certificates to the local BIG-IP DNS system and iQuery over TCP port 4353 to synchronize the configuration.

Impact of procedure: The following procedure replaces the configuration from the BIG-IP DNS system on which it is run, with the configuration of the remote BIG-IP DNS system in the specified synchronization group.

  1. Log in from the command line of the new BIG-IP DNS system that you want to add to the existing synchronization group.
  2. To add the BIG-IP DNS system to the DNS synchronization group, use the following command syntax:

    gtm_add <IP address of a member of the target DNS synchronization group>

When the gtm_add script completes, the configuration from the existing BIG-IP DNS system is installed on the new BIG-IP DNS system.

Recommendations

  • For ease of administration, F5 recommends using BIG-IP DNS sync groups with a smaller number of devices over sync groups with a larger number of devices. However, there is no pre-defined limit on the maximum number of BIG-IP DNS systems allowed in a sync group.
  • In order to avoid the configuration being overwritten by uninitialized BIG-IP DNS systems joining the synchronization group, F5 recommends the following:
    • Set the synchronization group name to a unique value. For example, use a sync group name other than default.
    • Avoid adding any DNS or GSLB configuration elements to the new BIG-IP DNS prior to adding the system to the sync group.
  • After you have completed the synchronization group, make sure to verify that the configuration from the existing BIG-IP DNS is copied to the new BIG-IP DNS system. If the configuration is not installed on the new BIG-IP DNS, refer to the articles in the Supplemental Information section.
