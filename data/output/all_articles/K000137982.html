K000137982: Master passphrase is unknown

Type
Support Solution
Published
2023-12-20
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000137982

Description

Unable to implement high availability (HA) for a BIG-IQ or add a data collection device (DCD) to a BIG-IQ.

Environment

  • BIG-IQ 

Cause

The master key passphrase is unknown and this passphrase must be the same on all of the devices in the HA pair or DCD cluster.

During initial setup of the BIG-IQ, the passphrase is entered and is only set once. It cannot be changed unless the devices are reset to factory defaults, losing the entire configuration.

Recommended Actions

  • Build a new BIG-IQ
    • K000135410: Migrate ELA license from one BIG IQ to another without the master key
Note: During the initial configuration of the BIG-IQ, note the master passphrase then store it in a location where future teams will have access to it.
