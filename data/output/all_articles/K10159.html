Known Issue

This is the result of a known issue. When bigpipe hostname lookup is enabled on the BIG-IP system, the bigpipe utility accepts hostnames in place of IP addresses in bigpipe commands, and uses a name resolution service (such as DNS or the hosts file) to resolve the name.

When hostname lookup is enabled on the BIG-IP system, and the hostname contains four or fewer leading hexadecimal characters , the bigpipe utility removes the hexadecimal characters before performing a name lookup. This causes the hostname resolution to fail for the hostname.

Note: If the hostname contains more than four leading hexadecimal characters, the issue does not occur and no characters are removed prior to name resolution.

For example, the following hostname contains two leading hexadecimal characters (a0), and will result in the bigpipe utility removing the a0 characters prior to looking up the hostname:

a0node.example.com

The following hostname contains five leading hexadecimal characters (a01b3), and will not result in the bigpipe utility removing the hexadecimal characters prior to looking up the hostname:

a01b3node.example.com

F5 Product Development is tracking this issue as CR122213.

This issue does not affect the BIG-IP version 10.x software branch.

This issue has been fixed in Hotfix-BIGIP-9.4.8-407.0-HF4, which was issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can use the following workarounds:

  • Do not use hostnames in bigpipe commands where bigpipe is expecting an IP address.

    For example:

    Use bigpipe node <ip address> show instead of bigpipe node <hostname> show
    Use bigpipe virtual address <ip address> list instead of bigpipe virtual address <hostname> list
    Use bigpipe arp <ip address> show instead of bigpipe arp <hostname> show
  • Do not use leading hexadecimal characters in the names in your name resolution service.
  • Disable bigpipe hostname lookup.

    For example, to disable bigpipe hostname lookup, enter the following commands:

    bigpipe cli hostname lookup disable
    bigpipe save all
