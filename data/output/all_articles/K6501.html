Known Issue

This is the result of a known issue. A race condition may occur, where the BIG-IP attempts to access the tcp_state buffer of a connection after the buffer has been cleared. This will cause the BIG-IP to panic, reboot, and produce a core file.

F5 Networks Product Development tracked this issue as CR47477 and CR51898, and it was fixed in BIG-IP version 4.5.14 for the BIG-IP 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issues still exists in the BIG-IP 4.6 software branch. You can obtain a hotfix for the BIG-IP 4.6 software branch, by contacting F5 Networks Support.
