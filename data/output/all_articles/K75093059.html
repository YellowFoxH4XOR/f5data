Description

"012a0003:3: FPGA firmware file missing" can be seen after upgrade to 15.x

Environment

  • BIG-IP  15.x
  • Error can appear after upgrade on LTM logs
  • Non causing impact on current Application/Data-Plane traffic, but can be annoying to see lots of logs like that. 

Cause

Unknown.
 

Recommended Actions

After an mcpd forceload, issue should disappear: 

Note: Please refer to the linked article in 'Additional Information' to read more about this process

1.- Log in to the Advanced Shell (bash).
2.- To create a null file with the file name forceload in the /service/mcpd directory, enter the following command:
      # touch /service/mcpd/forceload
3.- To restart the BIG-IP system, enter the following command:
      # reboot


Additional Information

K13030: Forcing the mcpd process to reload the BIG-IP configuration
