Known Issue

This is the result of a known issue. The BIG-IP system allows you to delete a custom OneConnect profile that is applied to a virtual server. As a result, the BIG-IP system is unable to load the new configuration, although the system does not display an error message. The correct behavior is for the BIG-IP system to display an error message indicating that the custom OneConnect profile cannot be deleted while it is in use by a virtual server.

F5 Product Development tracked this issue as ID 323127 and CR141544, and it was fixed in BIG-IP version 9.4.0. For information about upgrading, refer to the BIG-IP LTM or ASM release notes.

Workaround

To prevent this issue from occurring, ensure that no virtual servers are using the custom OneConnect profile prior to deleting it.
