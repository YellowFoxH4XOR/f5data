K000148729: Protocol Inspection Profile does not work with TLS traffic

Type
Support Solution
Published
2024-12-04
Updated
2025-02-06
Source
https://my.f5.com/manage/s/article/K000148729

Description

Starting with the release of BIG-IP AFM 13.1.0, protocol inspection profiles are part of the configurable feature set for BIG-IP AFM when configured with an intrusion prevention system (IPS) subscription add-on license.

Protocol inspection feature supports various application services, including DNS,HTTP, SIP, and DIAMETER etc.

Protocol Inspection feature does not work for TLS traffic.

For example: 2 Virtual Servers with the same Protocol Inspection Profile : http_ips.

security protocol-inspection profile /Common/http_ips {

~

  defaults-from /Common/protocol_inspection

  description none

  services {

    /Common/http {

      compliance {

~

        /Common/http_post_with_zero_content_length {

          action reject

        }

        /Common/http_post_without_content_len_or_transfer_encoding_header {

          action reject

        }

~

 

ltm virtual http_vs {

  creation-time 2024-11-26:11:38:59

  destination 10.20.4.144:80

  ip-protocol tcp

  last-modified-time 2024-11-26:11:39:52

  mask 255.255.255.255

  profiles {

    http { }

    http_ips { }

    tcp { }

  }

  rules {

    http_sorry

  }

  serverssl-use-sni disabled

  source 0.0.0.0/0

  translate-address enabled

  translate-port enabled

  vs-index 15

}

 

ltm virtual https_vs {

  creation-time 2024-11-26:11:18:47

  destination 10.20.4.144:443

  ip-protocol tcp

  last-modified-time 2024-11-26:11:30:40

  mask 255.255.255.255

  profiles {

    clientssl {

      context clientside

    }

    http { }

    http_ips { }

    tcp { }

  }

  rules {

    http_sorry

  }

  serverssl-use-sni disabled

  source 0.0.0.0/0

  translate-address enabled

  translate-port enabled

  vs-index 14

}

The same for other application servers as SIP or Diameter.

Environment

BIGIP AFM with with an intrusion prevention system (IPS) subscription add-on license.

Cause

Protocol Inspection feature does not work for TLS traffic.

Recommended Actions

Review K000137059: Setting Protocol Inspection Profile to check HTTP traffic on port 443
