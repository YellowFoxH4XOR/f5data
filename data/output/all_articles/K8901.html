Known Issue

This is the result of a known issue. Users may receive a blank logon page if you configure FirePass with all of the following settings:

  • On the Device Management : Security : Certificates page, the Request client certificate during logon check box is selected, and the Request client certificate during logon menu is not set to Do not use certificate field for logon username.

    Additionally, if you are running version 6.0.2 of FirePass software, you selected the Request Client Certificate check box on the web service(s) to which users connect.
     
  • You enabled dynamic group mapping.
  • You configured an LDAP master group mapping method.
  • In the LDAP master group mapping configuration, you selected the Update user information from LDAP check box.
 
Note: This issue occurs in FirePass version 6.0.0 if cumulative hotfix HF-600-12 or a later cumulative hotfix is installed on the FirePass controller.
 
F5 Networks Product Development tracked this issue as CR96242 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.
 
Additionally, cumulative hotfix HF-601-11 has been issued for FirePass version 6.0.1 and cumulative hotfix HF-602-4 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
You can work around this issue by disabling the Update user information from LDAP feature in the LDAP group mapping method configuration. To do so, perform the following procedure:
 
  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Users : Groups : Dynamic Group Mapping page.
  3. Click the Group mapping methods tab.
  4. Next to the LDAP mapping method, click the Configure link.

    Note: If you have multiple LDAP mapping methods configured, for example LDAP (filter) and LDAP (user object), click the Configure link next to one of the LDAP mapping methods. It does not matter which LDAP mapping method you select, and you do not have to repeat this procedure for each LDAP mapping method.

    Clear the Update user information from LDAP check box.
  5. Click the Update button.
