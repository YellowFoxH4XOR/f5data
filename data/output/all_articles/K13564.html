Known Issue

Running the tcpdump utility from the Configuration utility may fail to capture packets.

This issue occurs when the following condition is met:

  • You use the Configuration utility's Support Snapshot menu with tcpdump selected on a VLAN.

The tcpdump utility is located in the Configuration utility under System > Support > Support Snapshot.

Impact

The tcpdump file captured through the Configuration utility contains no data.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The support snapshot archive file will contain a .dmp file that has no packet captured.
  • There are network packets captured when using the tcpdump command from BIG-IP command line at the same time frame on the same VLAN.

Resolution

Status

Workaround

To work around this issue, you can use the tcpdump command to capture network packets on a desired VLAN. To do so, refer to the tcpdump man page and K411: Overview of packet tracing with the tcpdump utility.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
