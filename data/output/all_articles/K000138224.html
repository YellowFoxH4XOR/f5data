Description

 

Reactivate the license via CLI or GUI (automatic or manual) returns error. 

Error 51088: System time differs from the F5 License Server by greater than 24 hours.

Environment

  • CLI 
  • GUI
  • F5 Appliance's System Clock
  • New License Activation (re-activation of an existing license will not trigger this error)

Cause

The timestamp of the dossier, which is based of the F5 Appliance's system clock. It should be within 24 hours of F5 License Server Time. The F5 Appliance's system clock is off by Number hours.

Even after reboot the Big-IP could still have a wrong date and you would need to change the date manually in the system.  

Recommended Actions

 

Restart the Virtual Machine using either CLI/SSH Or Web GUI. Refer to the steps given below. 

K84002132: How to reboot the BIG-IP via command line

K000139252: How to reboot the BIG-IP via Web GUI

Important: Device will be rebooted & traffic services will be interrupted. So it is suggested to do this in a maintenance window.


K3381: Setting the time and date on the BIG-IP system
