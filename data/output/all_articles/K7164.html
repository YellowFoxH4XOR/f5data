A URL that is accessible without first authenticating to the FirePass controller may be modified to inject UNIX shell commands. Under certain conditions, the commands can then be executed with user-level privileges. Any attacker with access to the FirePass logon page can theoretically launch this attack.

F5 Product Development tracked this issue as CR76003, and it has been fixed in feature release 6.0.1 of the FirePass software. For information about upgrading, refer to the FirePass Release Notes.

Additionally, hotfix HF-75705-76003-1 has been issued for supported versions of FirePass. You may download this hotfix or later versions of the hotfix from the F5 Downloads site. The fix for this issue will also be included in future versions of the cumulative hotfix for FirePass 6.0.0 and 5.5.2. Refer to the README file accompanying future cumulative hotfixes for this CR.

For instructions about how to obtain a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

The vulnerability described in this security advisory can be prevented by using any pre-logon sequence, including an empty pre-logon sequence. An empty pre-logon sequence can be configured by performing the following procedure:

  1. Log in to the FirePass Administrative console.
  2. Navigate to Users > Endpoint Security.
  3. Click Pre-Logon Sequence.
  4. Click the button next to the Empty pre-logon sequence.
  5. Click Apply.
