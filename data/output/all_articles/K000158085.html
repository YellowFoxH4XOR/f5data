Description

This article addresses an issue where F5OS devices do not send the expected disk usage metrics via OpenTelemetry (OTEL). Specifically, the system.disk.usage metric is present but always reports a value of zero, and the system.disk.utilization metric is missing from OTEL output entirely. This can impact disk space monitoring and alerting for customers relying on these metrics.

Environment

  • Product: F5OS - Chassis (BIG-IP)
  • Version: 1.x

Cause

Bug ID 2139613

The system.disk.usage metric is present but always reports zero due to a software bug. The system.disk.utilization metric is not available in OTEL output and will be removed from documentation.

Recommended Actions

  1. Use the system.disk.usage metric under Disk IO Metrics for disk space monitoring as per F5OS documentation.
  2. If system.disk.usage always reports zero, this is a known Bug ID 2139613 targeted for resolution in F5OS v2.1.0.
  3. As a temporary workaround, use the system.filesystem.usage metric if available.
  4. Ensure OTEL telemetry is enabled at both chassis and partition levels for complete data collection.
  5. Monitor F5OS release notes and upgrade to v2.1.0 or later when available to obtain the fix.

Additional Information

  • The absence of system.disk.utilization is expected; it will be removed from official documentation.
  • The correct counter for disk usage monitoring is system.disk.usage.
  • Other disk-related metrics such as system.disk.io and system.disk.operations are unaffected by this bug.
