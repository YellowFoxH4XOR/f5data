Topic

Some vulnerability scanners are reporting that FirePass potentially has a CGI script vulnerability. This is a false positive. These scanners frequently send requests for potentially vulnerable files in the /license.php3 path.

For example:

/license.php3/AT-admin.cgi

/license.php3/CSMailto.cgi

/license.php3/UltraBoard.cgi

/license.php3/UltraBoard.pl

/license.php3/YaBB.cgi

FirePass will return a 200 response code for any requests made in the example paths, regardless of whether the specific file requested exists.

To change this behavior, select the Hide License Information check box located on the Device Managment: Customization: Advanced Customization: Front Door page.

Note: For information about CGI script vulnerabilities in the /my.logon.php3 path, refer to K9306: False positive vulnerability report for /my.logon.php3.
