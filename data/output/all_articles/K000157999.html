Description

You want to know if our F5 XC platform defense features protect against the attack called: "Tabnabbing"

Environment

  • HTTP Load Balancer
  • WAF
  • Bot Defense

Answer

"Tabnabbing" is a subclass of phishing attack whereby a malicious link or impersonated website frame is loaded in an inactive tab, such that the user is transparently directed to the fraudulent location when they next interact with it.

The attack inherently relies upon the actor having a vector to deliver the malicious payload to the client browser.  As with any phishing attack, this could be via a forum post, a scam email, a watering hole, adware, a malicious plugin, XSS, or many other potential means.  A WAF can protect against this only if it inspects the vector, which is often not the case.  Furthermore, a WAF-based mitigation would involve inspection and rewrite of response-side HTML content, which is prohibitively impractical to do without breaking application logic.  For these reasons, WAF is an inapt mitigation option for 'tabnabbing' attacks.

All modern browsers have robust protection against tabnabbing attacks.  The most effective mitigation is to ensure users run updated browsers, and potentially disallow outdated browser software from accessing the application.
