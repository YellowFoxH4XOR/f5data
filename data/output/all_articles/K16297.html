Topic

This article applies to BIG-IP 10.2.x. For information about other versions, refer to the following article:

  • K16314: Configuring the BIG-IP GTM topology load-balancing behavior for pool members with a zero score (11.x)

Purpose

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP GTM topology load-balancing behavior for pool members with a zero score in BIG-IP 10.2.2 through 10.2.4.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the BIG-IP GTM command line.
  • You are using a topology load-balancing method.

Description

Starting in BIG-IP GTM 10.2.2, you can control whether topology load-balancing returns pool members with zero scores. In BIG-IP 10.2.2 through 10.2.4, the default behavior is disabled. You can enable this behavior by performing the following procedure.

Procedures

Configuring the BIG-IP GTM topology load-balancing behavior for pool members with a zero score

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Make a backup of the /config/wideip.conf file by typing the following command:

    cp /config/wideip.conf /config/wideip.conf.sol16297
  3. Edit the /config/wideip.conf file using a text editor of your choice.
  4. Locate the following global settings configuration stanza:

    globals {

       sync_group "Intranet" // Default="default"

       sync_named_conf            yes               // Default=no

    }

    Note: If the global settings configuration stanza does not exist, create an empty one similar to the following example:
     

    globals {

    }

  5. To enable whether topology load-balancing returns pool members with zero scores, add topology_allow_zero_scores yes to the global settings configuration stanza.

    For example:

    globals {

       sync_group "Intranet" // Default="default"

       sync_named_conf            yes               // Default=no

       topology_allow_zero_scores yes

    }
  6. Save the changes and exit the text editor.
  7. Reload the configuration by typing the following command:

    gtmparse -l

    For example:

    config # gtmparse -l

    gtmparse: Initializing ...

    /usr/share/monitors/gtm_base_monitors.conf: SUCCESS

    /usr/local/gtm/include/base_region.ISP: SUCCESS

    /config/gtm/wideip.conf: SUCCESS

    gtmparse: SUCCESS
