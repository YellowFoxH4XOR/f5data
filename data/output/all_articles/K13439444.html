K13439444: Traffic Learning for parameters with special characters in their name are not working as expected

Type
Support Solution
Published
2022-07-02
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K13439444

Description

Security policy with traffic learning enabled is generating learning suggestions for the default wildcard parameter unexpectedly, even after creating new parameter(s) and expecting them to match the incoming requests. 

Environment

  • BIG-IP ASM and/or Advanced WAF.
  • Security policy with traffic learning enabled.
  • Custom parameters with special character(s) in the name, like [ and ].

Cause

Traffic learning suggestions do not match the created custom parameters because of the special characters in the name need to be escaped.

Recommended Actions

Escape out the special characters using \. for example if a custom parameter name is items[*] or items[?], the [] characters need to be escaped out. The parameter name should look like items\[*\] or "items\[?\].
