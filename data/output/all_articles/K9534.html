Important: Starting in FirePass version 7.0.0 and additionally in cumulative hotfix HF-610-3-1 for FirePass version 6.1.0, running the CTU with the /r switch from a command line will run in the background and not display a GUI interface. This will allow running the CTU from a script file and not require user interaction, enabling you to remove the FirePass components from a login script or group policy transparent to the user. 

To remove all FirePass client components from the Windows command line using the FirePass Components Troubleshooting Utility (CTU), type the following command:

/path/to/f5wininfo.exe /r

Note: In the example command, /path/to/f5wininfo.exe is the full path to the f5wininfo.exe file on the client system.

Additionally, starting in FirePass version 6.1.0 and in version 6.0.3 with cumulative hotfix HF-603-1, you can pass the /x flag to the f5wininfo.exe file to exclude a specific client component or group from removal. To do so, type the following command from the Windows command line:

/path/to/f5wininfo.exe /r /x "<Component Name or Group>”

Note: In the example command, /path/to/f5wininfo.exe is the full path to the f5wininfo.exe file on the client system, and <Component Name or Group> is the name of the client component or group as listed in the left navigational pane of the FirePass CTU graphical user interface (GUI).

For example, to remove all FirePass client components except the Win32 Inspector component and the components listed under the Base Controls group, you would type the following command from the Windows command line:

/path/to/f5wininfo.exe /r /x “Win32 Inspector” /x "Base Controls"

For a complete list of client components and groups that can be removed using the FirePass CTU, launch the CTU (f5wininfo.exe) and view the component list in the left navigational pane.

Note: For more information about the FirePass CTU, refer to K9133: Overview of the FirePass Components Troubleshooting Utility.
