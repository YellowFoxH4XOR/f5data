Description

  • I need a step-by-step summary of how to create a prefix route object using the APNIC IRR. 

Environment

  • MyAPNIC

Answer/Recommended Actions

I you want to create ROAs while you create IRR objects, please see instead the Additional Information section at the bottom of page.

To create route object IRR entries using APNIC:

1. Log-in at https://www.apnic.net

 

2. Select Resource Manager > Route Management

 

3. Select Add new

 

4. Fill out the following fields:

  1. Prefix: Submit either the exact length prefix you use in Portal, or submit an encompassing prefix length if you own it. E.g. if you own a /22 but use /24s in Portal, you can create a single /22 route object to cover all /24s in Portal.
  2. Origin AS: Submit the same origin AS you use in Portal
  3. Max length: Set to match prefix length
  4. ROA: Unselect
    • Optional: Instead use the following document to create ROAs with your route objects, which will allow for RPKI usage. This is not mandatory for the scope of this project.
    • How to create an ROA using APNIC
  5. Whois: Select
  6. Leave all other options unelected and select Next
  7. Verify the details and click Submit

 

 

Additional Information

For optionally creating ROAs at the same time as route objects, please use How to create an ROA using APNIC
