Topic

Simple Network Management Protocol (SNMP) software (for example, HP OpenView and Tivoli)) uses Management Information Base (MIB) files to translate the codes reported by the BIG-IP SNMP daemon into a more user-friendly format. You will need to install or compile the MIB files on your SNMP management station and configure them in accordance with your SNMP management station software documentation. BIG-IP and 3-DNS systems contain MIB files specific to both F5 Networks system information, and non-F5 specific information.

F5 Networks specific MIB files

The following MIB files are specific to F5 Networks:

  • 3dns.my
  • LOAD-BAL-SYSTEM-MIB.txt

These F5 Networks specific MIB files contain information you can use for your remote management station to either poll the SNMP agent for BIG-IP system-specific information (Get), or receive BIG-IP system-specific notifications (Trap).

The 3dns.my file is an enterprise MIB file that contains information that an SNMP manager system can access for the purpose of managing 3-DNS objects. Examples of information in this type of MIB file include data centers, routers, hosts, links, global values, and 3dns traps.

The LOAD-BAL-SYSTEM-MIB.txt file is an enterprise MIB file that describes objects representing common BIG-IP system information. Examples of information in this type of MIB file include global statistic data, network information, and platform information, virtual servers, pools, nodes, BIG-IP traps, and health monitors.

Non-F5 specific MIB files

The following MIB files contain information for non-F5 specific system information:

    • EtherLike-MIB.txt*
    • IANAifType-MIB.txt*
    • IF-MIB.txt*
    • IP-MIB.txt*
    • NOKIA-ENHANCED-SNMP-SOLUTION-SUITE-ALARM-IRP.txt
    • NOKIA-ENHANCED-SNMP-SOLUTION-SUITE-COMMON-DEFINITION.txt
    • PLATFORM-MIB.txt*
    • RFC1155-SMI.txt*
    • RFC1213-MIB.txt*
    • RLX-MIB.txt*
    • RMON-MIB.txt*
    • SNMP-FRAMEWORK-MIB.txt*
    • SNMP-MPD-MIB.txt*
    • SNMP-USER-BASED-SM-MIB.txt*
    • SNMP-VIEW-BASED-ACM-MIB.txt*
    • SNMPv2-MIB.txt*
    • SNMPv2-SMI.txt*
    • SNMPv2-TC.txt*
    • TCP-MIB.txt*
    • UCD-SNMP-MIB.txt*
    • UDP-MIB.txt*
    • rfc1525.mib*
    • rfc1611.my*

    Viewing or Downloading BIG-IP MIB files

    The MIB files are located in the following two locations on the BIG-IP system:

    • The /usr/local/share/snmp/mibs/ directory contains all of the MIB files in text format.
    • The /usr/local/www/docs/mibs/ directory contains all of the MIB files in text format for download through the Configuration utility.

    You can view the BIG-IP MIB file by performing the following procedure:

    1. Log in to the Configuration utility.
    2. Click on the product logo on the top right corner of the browser page.

      The Configuration utility title page is displayed.

    3. Click BIG-IP MIB under the Additional Software Downloads section.

    You can download the BIG-IP MIB by performing the following procedure:

    1. Log in to the Configuration utility.
    2. Click on the product logo on the top right corner of the browser page.
    3. The Configuration Utility title page is displayed.
    4. Right-click BIG-IP MIB under the Additional Software Downloads section.
    5. Select Save Target As...
    6. Select the desired location on your local system to save the file.
    7. Click Save.

    You may now install the BIG-IP MIB file in accordance with your SNMP management station software documentation.
