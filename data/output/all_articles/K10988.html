Note: For information about bypassing the BIG-IP PSM module with an iRule in version 10.0.1 and later, refer to K10987: Bypassing the BIG-IP PSM module with an iRule in version 10.0.1 and later.

In BIG-IP PSM 9.4.5 through 9.4.8, the following iRule commands can be used to enable or disable BIG-IP PSM processing for the HTTP, FTP, and SMTP protocols for certain requests or connections:

  • PLUGIN::disable PSM
  • PLUGIN::enable PSM

For example, the following rule disables PSM processing for URIs starting with /bypass:

when HTTP_REQUEST {
  PLUGIN::enable PSM
  if { [HTTP::uri] starts_with "/bypass" } {
    PLUGIN::disable PSM
  }
}

Note: When you use the PLUGIN::disable command to bypass the BIG-IP PSM for one request, you should always re-enable PSM processing for subsequent connections by using the PLUGIN::enable command at the top of the HTTP_REQUEST event. Otherwise, all subsequent requests on the connection will bypass the BIG-IP PSM.
