Description

Some websites contain images which are hosted on the Cloud (such as Amazon S3). 

There are some cases wherein when users access these websites via APM Portal Access, the embedded images are not getting displayed.

Environment

  • BIG-IP APM Portal Access

Cause

The Cloud server where the images are hosted on require an SNI. and since by default, the built-in serverssl profile on the BIG-IP does not contain any SNI, so when the BIG-IP (acting as a client) talks to the Cloud server to fetch those images, it is rejected because the SSL connection does not contain any SNI.

Recommended Actions

To workaround this limitation, you can apply an iRule similar to the one below to the Portal Access VS in question. This iRule will add the SNI HTTP header in the server-side ClientHello

when ACCESS_ACL_ALLOWED {
   set sni_value [getfield [HTTP::host] ":" 1]
}
when SERVERSSL_CLIENTHELLO_SEND {
   SSL::extensions insert [binary format SSScSa* 0 [expr { [set sni_length [string length $sni_value]] + 5 }] [expr { $sni_length + 3 }] 0 $sni_length $sni_value]
}
