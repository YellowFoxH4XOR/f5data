Description
Lost admin password for partiion.
root is not allowed for partition, and no other user is available.

Environment

  • F5OS-C
  • Velos
  • Partition
  • Admin Password

Cause

  • n/a

Recommended Actions

  1. find partition ID 
    log in to Controller as root, and run the below commands and check ID and Partition Status to confirm which Controller for the partition is active
    su admin
    show partitions
                                                                           RUNNING
                      BLADE OS    SERVICE                 PARTITION        SERVICE     STATUS
    NAME          ID  VERSION     VERSION     CONTROLLER  STATUS           VERSION     AGE
    -----------------------------------------------------------------------------------------------
    MyPartition   2   1.5.0-8535  1.5.0-8535  1           running-active   1.5.0-8535  27d
                                              2           running-standby  1.5.0-8535  27d
    Default       1   -           -           1           disabled         -           28d
                                              2           disabled         -           28d
    none          0   -           -           1           disabled         -           -
                                              2           disabled         -           -

    In this case, for MyPartition, Active Controller is 1
    exit from confd mode 
     
  2. Check which Controller you are logged in by checking prompt.
     
  3. If you are not in Acive Controller as the partition, then
    ssh controller-<partition_active_controller-number>
     
  4. Run
    docker exec -ti partition<partition_ID>_cli su - admin
    in the above case, the partition ID is 2
       docker exec -ti partition2_cli su - admin
     
  5. You are now in Partition CLI, change config mode, and set admin password.
    # config
    Entering configuration mode terminal
    (config)# system aaa authentication users user admin config set-password
    Value for 'password' (<string>): **********
    then you can log in to GUI with admin and new password.
    No need to commit, just exit from config mode and partition.
