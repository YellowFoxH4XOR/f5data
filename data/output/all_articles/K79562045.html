Known Issue

Using the Request Header Insert option in the HTTP profile may cause a memory leak.

This issue occurs when all of the following conditions are met:

  • You configure the Request Header Insert option in a custom HTTP profile.
  • You assign the HTTP profile to a virtual server.

Impact

The BIG-IP system experiences degraded performance and may eventually reach an out-of-memory condition, causing a traffic disruption while the Traffic Management Microkernel (TMM) restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Memory usage for the tmm process slowly increases with traffic processing.
  • The allocated column of the tcl row in the output of the tmctl memory _usage_stat command is high and increasing.

Workaround

To work around this issue, you can use the HTTP::header iRules command to insert the HTTP header rather than using the HTTP profile setting. To do so, perform the following procedures:

  • Checking memory usage with the tmctl utility
  • Using an iRule to insert the header

Checking memory usage with the tmctl utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Advanced Shell (bash).
  2. Check the memory usage using the tmctl memory_usage_stat command. For example, to view memory usage for tcl, type the following command:

    tmctl memory_usage_stat |grep "name "; tmctl memory_usage_stat | grep "tcl "

    Output appears similar to the following example:

    name                            allocated   max_allocated  size  slop cur_allocs
    tcl                             15332444016  15332444948     1    0      75370

Using an iRule to insert the header

Impact of procedure: Performing the following procedure should not have a negative impact on your system; however, iRule functionality should be tested based on your environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. In the Name box, enter a name for the rule.
  5. In the Definition box, enter the code for your iRule. For example, to insert the Example-Header: true header into a request, you can use a rule similar to the following example:

    when HTTP_REQUEST {
      HTTP::header insert Example-Header true
    }

  6. Click Finished.
