Description


You want to poll the F5 using SNMP for a specific VS (Virtual Server) state.
 

Environment

  • BIG-IP
  • SNMP Server v1, v2c, v3

Recommended Actions

  1. Log in to the command line.
  2. Output all VS OIDs using snmpwalk
    Example:
        # snmpwalk -On -v2c -c public localhost .1.3.6.1.4.1.3375.2.2.10.13.2.1.2
     
        The output below shows three different VS OIDs, I’m going to use the first OID in the list which has a VS name of “VS_TEST”:
        .1.3.6.1.4.1.3375.2.2.10.13.2.1.2.19.47.67.111.109.109.111.110.47.108.116.109.51.95.83.83.76.95.86.83 = INTEGER: green(1)
        .1.3.6.1.4.1.3375.2.2.10.13.2.1.2.21.47.67.111.109.109.111.110.47.70.111.114.119.97.114.100.105.110.103.45.73.80 = INTEGER: blue(4)
        .1.3.6.1.4.1.3375.2.2.10.13.2.1.2.21.47.67.111.109.109.111.110.47.80.101.114.102.111.114.109.97.110.99.101.76.52 = INTEGER: blue(4) 
     
  3. Parse through the list of OIDs to find the VS you want to poll. To match up an OID to a specific VS name, you will need to use snmptranslate. 
    Example:
     
        # snmptranslate -Td .1.3.6.1.4.1.3375.2.2.10.13.2.1.2.19.47.67.111.109.109.111.110.47.108.116.109.51.95.83.83.76.95.86.83
       
    Output:
     
        F5-BIGIP-LOCAL-MIB::ltmVsStatusAvailState."/Common/VS_TEST"
        ltmVsStatusAvailState OBJECT-TYPE
          -- FROM       F5-BIGIP-LOCAL-MIB
          SYNTAX        INTEGER {none(0), green(1), yellow(2), red(3), blue(4), gray(5)}
          MAX-ACCESS    read-only
          STATUS        current
          DESCRIPTION   "The availability of the specified virtual server indicated in color.
                        none - error;
                        green - available in some capacity;
                        yellow - not currently available;
                        red - not available;
                        blue - availability is unknown;
                        gray - unlicensed."
     
        ::= { iso(1) org(3) dod(6) internet(1) private(4) enterprises(1) f5(3375) bigipTrafficMgmt(2) bigipLocalTM(2) ltmVirtualServers(10) ltmVirtualServStatus(13) ltmVsStatusTable(2) ltmVsStatusEntry(1) ltmVsStatusAvailState(2) 19 47 67 111 109 109 111 110 47 108 116 109 51 95 83 83 76 95 86 83 }
     
  4. Now use the specific OID to check the state of the VS

    # snmpget -v 2c -c public localhost .1.3.6.1.4.1.3375.2.2.10.13.2.1.2.19.47.67.111.109.109.111.110.47.108.116.109.51.95.83.83.76.95.86.83
    Note: The snmp line above should be run as one string.
     Output:
         
     F5-BIGIP-LOCAL-MIB::ltmVsStatusAvailState."/Common/VS_TEST" = INTEGER: green(1)


Additional Information


All VS OIDs start with .1.3.6.1.4.1.3375.2.2.10.13.2.1.2 and each VS will have a unique OID.
