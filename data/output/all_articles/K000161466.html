Description

When attempting to activate a newly generated evaluation (Strongbox/Reseller Eval) license key for a hardware device, the activation fails with the following error:

 

  • 51079 - Invalid Base Registration Key - Retired status
  • Activation attempt against Retired Keys <Registration key> (retired)

Environment

Strongbox

Licensing

Hardware device

Cause

This is expected behavior by design within the Strongbox licensing program. When a new Strongbox evaluation key is requested for a hardware device, any previously issued key associated with that same serial number is automatically retired. Only one active Strongbox key is permitted per hardware device at any given time.

Answer/Recommended Actions

  1. Identify which evaluation key was most recently generated for the device. This will be the only active (non-retired) key.
  2. Use the most recently generated Strongbox registration key to activate BIG-IP LTM.
  3. If you are unsure which key is currently active, contact F5 Licensing support and provide:
    1. The device serial number
    2. The email address used to request the evaluation key(s)
  4. To avoid this issue in the future, do not request multiple evaluation keys for the same device. If a new key is needed, be aware that requesting it will automatically retire any previously issued key for that device.
