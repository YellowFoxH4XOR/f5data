Description

This article is a guide to redirect different URLs based on the current URL.

Environment

  • BIG-IP
  • iRule
  • HTTP profile is required

Cause

None.

Recommended Actions

We will be using iRule to redirect to a specific URL based on the current URL.

The code below will redirect URL http://host1/path1 it to http://host1/path2 and when URL is http://host2/path3 it will be redirected http://host3/path4

when HTTP_REQUEST {
  if { ([string tolower [HTTP::host]] eq "host1") and ([string tolower [HTTP::uri]] eq "/path1") } {
        HTTP::redirect "http://host1/path2"
    } elseif { ([string tolower [HTTP::host]] eq "host2") and ([string tolower [HTTP::uri]] eq "/path3") } {
        HTTP::redirect "http://host3/path4"
    }
}


For example, when the browser URL is http://www.example.com/path1, it will redirect to http://www.example.com/path2 while browser URL http://secure.example.com/path3 will be redirected to http://secure2.example.com/path4.

when HTTP_REQUEST {
  if { ([string tolower [HTTP::host]] eq "www.example.com") and ([string tolower [HTTP::uri]] eq "/path1") } {
        HTTP::redirect "http://www.example.com/path2"
    } elseif { ([string tolower [HTTP::host]] eq "secure.example.com") and ([string tolower [HTTP::uri]] eq "/path3") } {
        HTTP::redirect "http://secure2.example.com/path4"
    }
}
Note: HTTP requests that do not match the specified host declaration (in the example "www.example.com") and path are not redirected and the request is processed by the virtual server that is configured with the iRule. 
Note: Be sure to use a Fully Qualified Domain Name (FQDN) in the redirect hostname.
