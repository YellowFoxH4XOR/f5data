Topic

You should consider using this procedure under the following condition:

  • You want to allow an access role other than Administrator, Resource Administrator, or Auditor to have access rights to view system logs through the Configuration utility.

Modifying any of the following system database variables to the enable state grants access to system log files through the Configuration utility. Setting these variables to disable denies access.

Description

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP system command line.

Procedures

  1. Log in to the TMOS Shell (tmsh)
  2. Use the following command syntax to modify the system database variable for the user role to enable Configuration utility log access:

    modify sys db ui.logaccess.<role_name> value enable 

    Note: Replace <role name> with the intended BIG-IP role to which you want to grant access to system logs. Refer to the previous table for the appropriate settings.

  3. To exit tmsh, type the following command:

    quit
