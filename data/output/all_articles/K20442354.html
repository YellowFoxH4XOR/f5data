Description

Unable to add a rule list to AFM policy via GUI (Option not available)

Environment

  • AFM Policy
  • Inline Rule Editor disabled

Cause

Seen behavior is expected when the BIG-IP AFM Inline Rule Editor is disabled.

Recommended Actions

Enable BIG-IP AFM Inline Rule Editor

  1. On GUI go to Security > Options : Network Firewall > Firewall Options
  2. Click the check box on Inline Rule Editor
  3. Click Update

None
