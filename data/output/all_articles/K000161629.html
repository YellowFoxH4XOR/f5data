K000161629: Migrate BIG-IP VE from Subscription license to MyF5 Self Service

Type
Support Solution
Published
2026-06-08
Updated
2026-06-08
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000161629

Description

The BIG-IP VE uses a subscription license but needs to be renewed with MyF5 Self Service license keys from the Flex Consumption Program (FCP).

Environment

  • FCP Contract after January 13th, 2025
  • BIG-IP Virtual Edition (VE)
  • VE subscription license
  • License key from MyF5 Self Service

Cause

The BIG-IP VE uses a subscription license but needs to be renewed with MyF5 Self Service license keys from the Flex Consumption Program (FCP).

Recommended Actions

  1. Generate the new license key from the MyF5 Self Service.
    • Generate Self Service license keys in MyF5
  2. Prepare the BIG-IP for the license update.
    • Best Practices when preparing to update license on BIG-IP
  3. Apply the new license key from MyF5 Self Service to the BIG-IP.
    • License the BIG-IP
  4. Update chargeback tag to track this license and BIG-IP
    • Add Chargeback tag to Self Service license keys in MyF5

Additional Information

Please email the F5 Customer Success Team at CustomerSuccess@f5.com for any questions related to MyF5 Self Service license keys.
