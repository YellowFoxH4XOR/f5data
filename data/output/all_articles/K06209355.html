K06209355: Is there a limit on the number of URLs that can be configured on the Custom URL Lists?

  • F5 SSL Orchestrator: 16.X.X, 16.0.X, 16.1.3, 16.1.2, 16.1.1, 16.1.X, 16.0.1, 16.0.0, 16.1.0
Source
https://my.f5.com/manage/s/article/K06209355

Description
As a  customer,  you have the need to configure many URLs in a Custom URL list. You are wondering if there is a limit on the number of URLs that can be configured on a Custom URL List.

Environment

  • SSL Orchestrator
  • Custom URL List.

Cause
None. It works as designed.

Recommended Actions

 The SSLOrchestrator doesn't have a programmatic limit. Yet, a huge list will hurt performance. Try to make the matching rules as simple as possible and combine URLs when possible. Keep an eye on the performance graphs, mostly focusing on memory.
