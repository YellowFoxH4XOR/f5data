Topic

You can use BIG-IP to monitor Windows Media 9 servers by connecting and searching for the client-id value, which is contained within the first 200 bytes of the first packet returned after an initial request to a Windows Media 9 server.

Note: The effect of health checks on Windows Media 9 server performance is currently unknown.

Example monitor

Following is an example BIG-IP Windows Media 9 server monitor definition:

monitor WM9_monitor {
# type http
use "http"
interval 10
timeout 30
dest *:*
send "GET / HTTP/1.0 Accept */* \n\n"
recv "client-id"
username ""
password ""
}
