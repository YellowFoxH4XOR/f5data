K00500335: AFM send statistics with negative values in the ''dos_packets_received'' metric

Type
Support Solution
Published
2020-02-04
Updated
2024-11-22
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP AFM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K00500335
Description

dos_packets_received metric contains negative numbers in Attack Sampled log messages
These messages can be seen under Security > Event Logs > DOS > Network > Events in GUI

Environment

  • AFM
  • Attack sample Log messages

Cause

This is due to the known issue tracked in ID783217

Recommended Actions

This is fixed in v15.1.0
Upgrade to v15.1.0 in order to fix the issue

Additional Information

None
