Description

This article explains how to obtain driver information. VMXNET3 will be used as an example.

Environment

  • BIG-IP VE
  • VMXNET3 driver in use for data and management interfaces 

Cause

You want to check your VE driver information.

Recommended Actions

Use following command to check which driver is in use for management interface:

# ethtool -i eth0

Example output:

[root@bigip1337:Active] # ethtool -i eth0
driver: vmxnet3
version: 1.4.7.0-k-NAPI

 

The management interface (eth0) uses a standard Linux network driver, which is directly managed by the Linux kernel and accessible via 'ethtool'. Data interfaces (eth1, eth2, eth3) are managed by the Traffic Management Microkernel (TMM) and do not use standard Linux drivers, so 'ethtool' cannot access their driver information.

Use following command to check which driver is in use for each data interface:

# tmctl -d blade tmm/device_probed

This will show the available drivers and the driver currently in use for each interface.

Example output:

pci_bdf      pseudo_name type      available_drivers     driver_in_use
------------ ----------- --------- --------------------- -------------
<mgmt_interface>F5DEV_PCI           xnet, vmxnet3, sock,

<interface>     F5DEV_PCI           xnet, vmxnet3, sock,  vmxnet3

<interface>     F5DEV_PCI           xnet, vmxnet3, sock,  vmxnet3

<interface>     F5DEV_PCI           xnet, vmxnet3, sock,  vmxnet3

We can see that vmxnet3 is in use.

For more granular data about driver in use, you can execute following commands:

# modinfo vmxnet3 | grep -i '^version'

or

# cat /sys/module/vmxnet3/version

Example output:

# modinfo vmxnet3 | grep -i '^version'
version:        1.4.7.0-k
# cat /sys/module/vmxnet3/version
1.4.7.0-k
