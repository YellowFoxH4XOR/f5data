K93521005: Not able to add a pool member (node) with error message ''cannot use the same IP Address''

Type
Support Solution
Published
2019-10-16
Updated
2023-09-01
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 11.6.2
Source
https://my.f5.com/manage/s/article/K93521005

Description

Not able to add pool member (node) to a new pool. An example of an error message is as below.

0107003a:3: Pool member node (/Common/www.example2.net-10.10.10.1) and existing node (/Common/www.example.net-10.10.10.1) cannot use the same IP Address (10.10.10.1).

Environment

  • BIG-IP

This issue occurs when all the following conditions are met.

  • Node already exist in another pool.
  • Node was added in another pool using FQDN (not IP address)
  • Using IP address when adding the node to the new pool.

Cause

Since the node was added earlier using FQDN, you will not be able to add the same node using an IP address.

Recommended Actions

When adding the node (pool member) to the new pool, instead of using the IP address, select "Use existing FQDN Node" and choose the FQDN from the other pool that shares the same node. Details are as below.

  1. Create new pool.
    • Local Traffic > Pools > Create
  2. Select "Use existing FQDN"
    • Resources > New Members > "Use existing FQDN Node"
  3. From the dropdown menu, choose the FQDN which is use by the other pool for its node.
