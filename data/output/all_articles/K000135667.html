K000135667: Unable to add Velos controller to BIG-IQ - GUI error Cannot read properties of undefined (reading 'length')

Type
Support Solution
Published
2023-08-14
Updated
2023-08-14
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0, 8.3.X
Source
https://my.f5.com/manage/s/article/K000135667

Description

BIG-IQ is not able to successfully add Velos controller under Devices -> F5OS -> Platform/Devices.
After unsuccessful attempt GUI displays error "Cannot read properties of undefined (reading 'length') every time device list page is requested

 

Environment

  • BIG-IQ
  • Velos controller with no partitions configured

 

Cause

ID1323085

Recommended Actions

As a workaround to recover GUI, perform:

1. Collect the uuid of the device to delete from the list of existing F5OS devices from any one of the below commands:

restcurl /cm/f5os/config/ | jq '.items[]'

curl -ks -u admin:<admin_password>https://bigiq_mgmt_addr/mgmt/cm/f5os/config/ | jq '.items[]'

 

2. Execute below command to delete the device successfully from any one of the below commands

restcurl -X DELETE /cm/f5os/config/<uuid>

curl -ks -u admin:<admin_password> -X DELETE https://bigiq_mgmt_addr/mgmt/cm/f5os/config/<uuid>
