Description

SSL Certificates newly imported on one device, do not sync expiry dates correctly to peer devices.

Environment

  • Config Sync
  • SSL Certificates

Cause

Bug ID 523985: Certificate bundle summary information does not propagate to device group peers

Recommended Actions

Upgrade to a version where above ID is fixed. Workaround the issue on affected versions by re-importing the Certificate Bundle on the affected peer devices.

K14620: Managing SSL certificates for BIG-IP systems using the Configuration utility

Additional Information

After applying the workaround, you might still see the wrong expiry dates on the GUI. To check the expiration status of the SSL certificates, using tmsh, enter the following command:

tmsh list sys crypto cert <certificate name>
