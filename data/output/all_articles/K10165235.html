Description:

You can observe message similar to the following in the ltm log:

info bcm56xxd: 012c0016:6: MiimTimeOut:soc_miim_write, timeout (id=0xc9 addr=0x1f data=0x0000)

The affected BIG-IP system fails to pass traffic. If configured for high availability (HA), failover occurs.

Environment:

  • VIPRION B2250 Blade (A112)
  • VIPRION B2150 Blade (A113)
  • VIPRION B4450 Blade (A114)
  • VIPRION B4300 Blade (A108)
  • BIG-IP 5250v
  • BIG-IP i5820
  • BIG-IP i7800
  • BIG-IP i10800

Cause:

ID758929: Bcm56xxd MIIM bus access failure after TMM crash
 

Recommended Actions:

Reboot the affected BIG-IP platform / VIPRION blade.

  • K7369: Shutting down and restarting the BIG-IP system
  • K11333: Using the clsh command to restart or shut down one or more blades in a VIPRION system
