K000139931: rSeries appliance shows alert: RAID STATUS:raid_failed SSD:ssd1

Source
https://my.f5.com/manage/s/article/K000139931

Description

rSeries appliance shows the following alert.

RAID STATUS:raid_failed SSD:ssd1

In F5OS-A CLI, show system raid shows output similar to below.

hostname# show system raid 
                             ARRAY   ARRAY               
NAME  BAYID  SERIAL NUMBER   MEMBER  STATUS     SIZE     
---------------------------------------------------------
ssd1  0      xxxxxxxxxxxxxx  false   undefined  652.1G
ssd2  1      xxxxxxxxxxxxxx  true    ok         652.1G

Environment

Relevant environmental factors specific to the topic

  • rSeries platforms with dual SSD disks that are RAID-1 mirrored:
    • r5920-DF
    • r10000 series
    • r12000 series
  • First boot after delivery

Cause

One of the SSDs is not seated properly like the image below.

Recommended Actions

Open the back panel and look at the drive bay. If the door is open, the drive is not seated. Power down the system and re-seat both of the drives, then power back on. Contact F5 Support if the system does not boot up, for instructions on how to boot into the good drive.
