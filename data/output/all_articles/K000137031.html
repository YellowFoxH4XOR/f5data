K000137031: BIG-IP APM Endpoint Inspection check causes an user prompt to select either "start inspection" or "skip inspection"

Type
Support Solution
Published
2023-09-29
Updated
2024-02-01
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.10, 17.1.1, 16.1.4
Source
https://my.f5.com/manage/s/article/K000137031

Description

From BIG-IP v16.1.4, when there is an Endpoint inspection check like Antivirus Check in the Visual Policy Editor, there is a browser prompt to start the check:


Environment

  • BIG-IP APM v17.1.1 or later, v16.1.4 or later, and v15.1.10 or later 
  • Endpoint inspection check (such as: Antivirus check, Checking Machine Info)

Cause

Explicit message prompt to start Endpoint Inspection check was introduced as part of the fix for the below BUG ID:
Bug ID 1039941: The webtop offers to download F5 VPN when it is already installed

Recommended Actions

Users have to click on Start inspection to start the endpoint check.

Note that such popup window is also visible with BIG-IP v17.1.0.2 and onward, but only with running Safari with Apple Mac machines.

Additional Information

This behavior change is not because of F5-oriented program but browser's behavior change in handling the custom protocol tied in with the Endpoint Inspector browser component.

When Endpoint inspection check starts, the browser needs to recognize the custom protocol (such as: f5-epi://<URL>) and run f5epi.exe, the Endpoint inspector browser component. However, the browser does not allow it without user interaction even if it has been already installed.

It is because of the security reason introduced by the browser in order to prevent the computer from running "malicious" program / application automatically. Instead, the browser asks for permission to open the program / application, and then prompts you to confirm that you want to handle the protocol and the app you’d like to use for it. If you give permission, then the selected application opens with the specified content.
