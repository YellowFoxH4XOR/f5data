K000135098: MySQL EAV monitor example with regexp

Published

Source

Description

EAV monitors give customer the flexibility of bash and regular expressions. K5917 provides information which monitor types support regular expression match in Receive String. Unfortunatelly MySQL is not on the list so one possible solution is to use EAV monitor.
 

Environment

Monitor with regular expression match in response from pool member.

Cause

Lack of support for regexp for MySQL monitor type.
 

Recommended Actions

  1. Read about EAV external monitors - K71282813
  2. Create and import bash script that will connect to MySQL server and execute commands: 
    [root@bigip:Active:Standalone] external_monitor_d # cat /config/filestore/files_d/Common_d/external_monitor_d/\:Common\:mysql_EAV_2546229_3

#!/bin/bash

NODE=`echo ${1} | sed 's/::ffff://'`

mysql --user db_user --password='secretpass' -h 1.2.3.4 db_lbmonitor -e "SHOW STATUS LIKE 'Threads_running'" | egrep 'Threads_running.*[1-2]'  > /dev/null 2>&1

STATUS=$?
if [ $STATUS -eq 0 ]
then
echo "UP"
fi
exit

    Above script will mark pool member UP if response match regexp Threads_running.*[1-2]

  3. Create a BIG-IP external monitor referencing the script 
    [root@bigip:Active:Standalone] external_monitor_d # tmsh list ltm monitor
ltm monitor external mysql_EAV {
    defaults-from external
    interval 5
    run /Common/mysql_EAV
    time-until-up 0
    timeout 16
}
