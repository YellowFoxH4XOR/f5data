Known Issue

The Traffic Management Shell (tmsh) utility fails to display the correct default boot location. This issue occurs when the following condition is met:

  • A user deployed the switchboot utility to change the default boot location.

Note: The tmsh list sys software volume active command output displays the default and current boot location as active-requested and active, respectively.

Impact

This issue is cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The tmsh list sys software volume active command output displays a default boot location that is different from the switchboot -l command.

    For example, the current default boot location is HD1.1. After a user deployed the switchboot -b HD1.3 command to change the default boot location to HD1.3 , the switchboot -l command returned the following output:

    Current boot image:
    HD1.1 - title BIG-IP 10.2.0 Build 1707.0
    Default boot image:
    HD1.3 - title BIG-IP 10.2.4 Build 577.0
    Available boot image(s):
    HD1.1 - title BIG-IP 10.2.0 Build 1707.0
    HD1.2 - title BIG-IP 11.2.0 Build 2446.0
    HD1.3 - title BIG-IP 10.2.4 Build 577.0

    However, the tmsh list sys software volume active command output indicates that HD1.1 is the default boot location:

    sys software volume HD1.1 {
    active
    active-requested
    }
    sys software volume HD1.2 { }
    sys software volume HD1.3 { }
