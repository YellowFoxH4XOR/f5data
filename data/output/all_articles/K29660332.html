Known Issue

Security Assertion Markup Language (SAML) authentication with Artifact Binding may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured as a Service Provider (SP).
  • SimpleSAMLphp is configured as Identity Provider (IdP).
  • SimpleSAMLphp Artifact response messages are signed.

Impact

SAML SSO authentication fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SAML authentication with Artifact Binding fails.
  • SAML resources are inaccessible.
  • Messages appear in the /var/log/apm file similar to the following example:

Workaround

There is no workaround for this issue. However you can alternatively configure POST binding instead of Artifact Binding.
