Description

a QKView may fail to complete for a number of reasons. Its failure needs to be analysed on a case by case basis using the following outputs

Environment

BIG-IP

Cause

More than one

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Follow K61154426: Troubleshooting QKView diagnostic utility failures
     
  2. Run the below command in the CLI, and wait till output stall for 5 min.

    qkview -v
     
  3. Stop the stuck QKView following K61154426: Troubleshooting QKView diagnostic utility failures
     
  4. Collect a complete logs tarball running the below command in bash CLI:

    tar -cvzf /var/tmp/F5SR_log.tgz /var/log
     
  5. Collect the directory structure and the open files list:

    ls -alR / > /var/tmp/F5SR_dir.log
    lsof -n > /var/tmp/F5SR_lsof.log
     
  6. Run strace and allow another 40 minutes before collecting the log:

    strace -tt -s300 -f -o /var/tmp/F5SR-strace-qkview.txt qkview -v >/var/tmp/F5SR-qkview-output-stderr.txt 2>&1
     
  7. Additionally collect the below files:

    /tmp/qkview_cmd.err
    /tmp/qkview_run.data
    /var/tmp/mcp_module.xml
     
  8. Stop the stuck QKView following K61154426: Troubleshooting QKView diagnostic utility failures
     
  9. Provide all the data gathered as well as the output of step 2 to F5 Support.

     

Additional Information

K13314650: Corrupted AVR statistics database can cause QKView generation to stall and 0KB file generated.
