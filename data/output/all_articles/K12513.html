Known Issue

This is the result of a known issue. If you install hotfixes using the image2disk utility in the Maintenance Operating System (MOS) environment, the image2disk utility will not display a status message to indicate a successful hotfix installation.

F5 Product Development tracked this issue as ID 340972, and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP release notes.

Workaround

You can verify that the hotfix installation was successful by booting into the slot where the hotfix was installed, and entering either the bigpipe version command or the tmsh show sys version command to check the build and edition.

For example, if you install the Hotfix-BIGIP-10.2.0-1755.1-HF1.iso file on a version 10.2.0 slot, you can enter the tmsh show sys version command from the command line after booting into the 10.2.0 slot. The command output will appear similar to the following example:

Note: This example command output is truncated to show only the build and edition; the hotfix list is not included.

Sys::Version
Main Package
Product BIG-IP
Version 10.2.0
Build 1755.1
Edition Hotfix HF1
Date Fri Jun 25 15:23:14 PDT 2010

Note: When possible, F5 recommends that you use the Configuration utility or the bigpipe software or tmsh install commands for a hotfix installation. For more information, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
