Known Issue

Important: This issue only affects systems that installed BIG-IP version 9.4.4 HF1 or 9.6.1 HF1 and experienced the issue detailed below. All currently released hotfixes do not experience this problem and perform a full box reboot after installation allowing the information to load properly and in the correct order.

This is the result of a known issue. Installing hotfixes may not keep changes made to the profile_base.conf file or the config_base.conf file unless you type the bigpipe load command prior to issuing a restart of the BIG-IP system. This behavior may prevent some of the changes made in a hotfix from being properly loaded and available when the BIG-IP system restarts.

F5 Networks Product Development is tracked this issue as CR101357.

This issue has been fixed in BIGIP-9.4.4-94.0-HF3 issued for BIG-IP version 9.4.4, and in Hotfix-BIGIP-9.6.1-HF2 issued for BIG-IP version 9.6.1. You may download these hotfixes or later versions of the hotfixes from the F5 Networks Downloads site.
