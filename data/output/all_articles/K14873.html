Known Issue

The remote logging filter may cause the tamd process to leak file descriptors.

This issue occurs when one of the following conditions is met:

  • A remote logging publisher uses a log filter configured with a source of tamd.
  • A remote logging publisher uses a log filter configured with a source of all.

The log filter functionality in the Traffic Management Operating System (TMOS) allows you to publish logs from a specific set of processes to various log destinations. When a log filter includes a source of tamd or all, the tamd process may start to leak descriptors.

Note: When you configure a log filter with a source of all, the tamd process is included in the log filter.

Impact

Client authentication failures may occur if the tamd process exhausts available file descriptor resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H439235 on the Diagnostics > Identified > Medium|High screen.
  • Client authentication fails when you configure virtual servers to use remote authentication.

Workaround

To work around this issue, ensure that log filters are not configured with a source of tamd or all defined.

Impact of workaround: The BIG-IP system will not send tamd log messages to the configured remote log destinations.
