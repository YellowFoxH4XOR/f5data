Known Issue

The Traffic Management Microkernel (TMM) restarts when using a custom format script for BIG-IP PEM reporting.

This issue occurs when all of the following conditions are met:

  • You use the BIG-IP PEM system to process subscriber traffic.
  • Your configuration includes a virtual server with an associated iRule.
  • Your configuration includes a custom format script for BIG-IP PEM reporting.
  • The system sends BIG-IP PEM reporting information to a remote high-speed logging (HSL) endpoint.

Impact

The BIG-IP PEM system fails to process subscriber traffic while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP PEM system fails to process traffic for a brief period of time.
  • Your BIG-IP PEM system fails over to another system in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

To avoid this issue, modify the iRule by using the set command to set a variable at the beginning of the iRule, then use the unset command on the same variable at the end of the iRule.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
