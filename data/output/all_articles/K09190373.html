Description
Dashboard alerts is not cleared and is still showing an error message although the the power supply has been connected and the system reports the power supply as operational 

Environment

  • BIG-IP running on Viprion Platforms 
  • BIG-IP Version 12.1.5

Cause
Unknown at the time of publication. 

Recommended Actions

  1. Try first the recommendations stated in K11439 to restart the logstatd process, type the following command in bash: 
    clsh bigstart restart logstatd
  2. If step 1 does not solve the issue, to issue the following command: 
    /usr/bin/logger -p local0.info -t logstatd RESET:LOGSTAT:SYSTEM_CHECK:ERROR_LEVEL

None.
