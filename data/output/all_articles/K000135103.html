K000135103: Cannot add dependency job for unit qkview.target, ignoring: Unit not found.

Description

During boot systemd tries to execute jobs for default target. However some unit files for targets are missing and you will notice below warning messages:

Oct 19 00:26:02 localhost warning systemd[1]: Cannot add dependency job for unit fips.target, ignoring: Unit not found.
Oct 19 00:26:02 localhost warning systemd[1]: Cannot add dependency job for unit qkview.target, ignoring: Unit not found.

Environment

  • Big-IP platform with systemd
     

Cause

  • Regarding fips.target error message:
systemd default target is configured to execute multi-user.target
multi-user.target requires basic.target
basic.target wants fips.service
fips.service wants fips.target
However unit file for fips.target doesn't exists: 
[root@localhost:Active:Standalone] config # systemctl status fips.target
Unit fips.target could not be found.
  • Regarding qkview.target error message:
multi-user.target wants qkview.service
qkview.service wants qkview.target
However unit file for qkview.target doesn't exists: 
[root@localhost:Active:Standalone] config # systemctl status qkview.target
Unit qkview.target could not be found.

 

Recommended Actions

Messages can be ignored. No action is required.
 

Additional Information

man systemd.unit
