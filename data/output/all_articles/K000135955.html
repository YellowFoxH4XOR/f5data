K000135955: err_str="received duplicate create for VLAN tag <vlan-id> in tree <instance-id>"

Support Solution
Published
2023-09-04
Updated

Applies to
  • F5OS
  • F5OS-A: 1.5.X, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000135955

Description

1. You configured the MSTP setting using the following commands:

docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp global config enabled-protocol MSTP;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;vlans vlan 300;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp mstp config name test revision 1;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp mstp mst-instances mst-instance range 1 config mst-id 1;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp mstp mst-instances mst-instance 1 config vlan 300;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp mstp mst-instances mst-instance 1 config bridge-priority 32768;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp interfaces interface 9.0 config edge-port EDGE_AUTO link-type P2P;commit and-quit'

2. Then you delete them using the following commands:

docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp global config enabled-protocol \[ ];commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;no stp mstp config name test;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;no vlans vlan 300;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;no stp interfaces interface 9.0;commit and-quit'
docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;show full-configuration stp'

3. When reconfiguring again use the same commands in step 1. You observed there is an error in /var/F5/system/log/platform.log after executing the following command 

docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp mstp mst-instances mst-instance 1 config vlan 300;commit and-quit'

/var/F5/system/log/platform.log

2023-08-17T01:56:37.382943+00:00 appliance-1 stpd[1]: priority="Err" version=1.0 msgid=0x6101000000000054 msg="" err_str="received duplicate create for VLAN tag 300 in tree 1".

 

Environment

MSTP

 

Cause

The reason is that mst-instance 1 wasn't deleted. So recreating on the same instance ID would report a duplicate creation. However, it can be ignored as the system is still able to recreate it without issue.

 

Recommended Actions

It's recommended to delete that mst entry before executing other delete commands if you don't wish to see the error message when configuring with the same MST instance ID as the previous one. 

 docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;no stp mstp mst-instances mst-instance 1;commit and-quit'
 docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;stp global config enabled-protocol \[ ];commit and-quit'
 docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;no stp mstp config name test;commit and-quit'
 docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;no vlans vlan 300;commit and-quit'
 docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;no stp interfaces interface 9.0;commit and-quit'
