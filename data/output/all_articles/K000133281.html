Description

After changing Internal Appliance (docker) IP range following the below instruction: 

K000132471 : [F5OS-A] Procedure for modifying rSeries Internal Appliance IP ranges 

 

still route isnot changed.

ip ro show

...

100.64.0.0/16 dev docker0 proto kernel scope link src 100.64.10.0

...

 

Environment

  • F5OS-A
  • rSeries
  • any version

Cause

  • Bug ID 1283641
     

Recommended Actions

1. first to check customer's config 

Customer can have one of them in show system network command output

R4600-R85-S11# show system network
system network state configured-network-range-type RFC1918
system network state configured-network-prefix 15
system network state configured-network-range 10.[240-255].0.0/16 <<<------[!]
system network state configured-chassis-id 1
system network state active-network-range-type RFC1918
system network state active-network-prefix 15
system network state active-network-range 10.[240-255].0.0/16     <<<------[!]

use first number in [ ... ] of above network range, so in above example, 10.240.0.0/16.

Customer config should have one of below.

2. log in to CLI as root, and modify docker file by following commands in order
mount -o remount,rw /usr
vi /usr/share/vanquish-config/docker 
NOTE: any text editor can be used.

3. Edit the yellow highlighted and bold font part, after pressing [Inset] key

From

OPTIONS=' --selinux-enabled    --log-driver=journald --log-level=error --selinux-enabled --signature-verification=false --ip=127.0.0.1 --bip=100.64.10.0/16 --host tcp://0.0.0.0:4243 --host unix:///var/run/docker.sock --signature-verification=False'
...
INSECURE_REGISTRY='--insecure-registry 100.64.10.0/16 --insecure-registry appliance-1.chassis.local:5000 --insecure-registry 10.0.0.0/8'
to
OPTIONS=' --selinux-enabled    --log-driver=journald --log-level=error --selinux-enabled --signature-verification=false --ip=127.0.0.1 --bip=10.224.0.0/16 --host tcp://0.0.0.0:4243 --host unix:///var/run/docker.sock --signature-verification=False'
...
INSECURE_REGISTRY='--insecure-registry 10.224.0.0/16 --insecure-registry appliance-1.chassis.local:5000 --insecure-registry 10.0.0.0/8'
Once you have finished, then press [Esc] key to get out from edit mode.
Then type below to save change

:qw!


4. Then copy the file to /etc/sysconfig/docker

cp /usr/share/vanquish-config/docker /etc/sysconfig/docker
5. restart docker
systemctl restart docker
6. remount /usr as read-only (or reboot will revert /usr to read only)
mount -o remount,ro /usr
NOTE: This workaround persist downgrade/upgrade, and power cycle.
