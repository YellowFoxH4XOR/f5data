K000133115: Unable to download file via WinSCP from F5

Type
Support Solution
Published
2023-06-01
Updated
2023-08-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.1.5, 17.0.0, 16.1.2, 14.1.5
Source
https://my.f5.com/manage/s/article/K000133115

Description

Copy out the file from  F5 CLI directly to Window PC machine without using WinSCP

 

Environment

  • BIG-IP 14.1.5

  • MS Windows 10

  • PowerShell

Cause

Bug ID 1097193: Unable to SCP files using WinSCP or relative path name

Recommended Actions

Use Windows PowerShell to run SCP command as alternative.

Example:

Use the following syntax to download a UCS archives backup.ucs to MS Windows user home directory.

scp root@<management IP address>:/var/local/ucs/backup.ucs /Users/<Windows User>/
