Description

When you attempting software update check, it fail with messages similar the following

 

  • No response from update server

Environment

BIG-IP

  • Ver 15.1.0 or later version
  • Configuration objects and settings
  • System ›› Software Management : Update Check
  • No DNS server configured

Cause

After 15.1.0, software update check required registration of DNS server to resolve callhome.f5.com.

 

Without DNS server setting.

GUI

  • Log in to the Configuration utility.
  • System ›› Software Management : Update Check
  • Fail with error message

    "An error has occurred while trying to process your request. -- No response from update server"

CLI

[root@gallery-big-ip-17-1-1:TimeLimitedModules::Active:Standalone] config # updatecheck
No response from update server

 Recommended Actions

In order to success software check need add DNS server as follows

  • Log in to the Configuration utility.
  • System ›› Configuration : Device : DNS
  • DNS Lookup Server List "add"
