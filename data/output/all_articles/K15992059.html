K15992059: Device stuck updating firmware during upgrade to 13.x or higher.

Type
Support Solution
Published
2021-03-09
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K15992059

Description

When upgrading BIG-IP from 11.x or 12.x to version 13.x or higher it may become stuck updating the firmware and the prompt will look similar to the following:

[root@localhost:Updating HSBE2 firmware on main ... DO NOT INTERR*:] config #

Environment

  • BIG-IP upgrade from 11.x or 12.x going to 13.x or higher

Cause
Unknown
 

Recommended Actions

  1. Connect a computer to the Console connection:  (K7683)
  2. Run a file system check.  (K73827442)
  3. Monitor the reboot process and the firmware upgrade. You should see the flash upgrade process and a percentage of completion.

    Example:

    Programming Flash...
    HSB updater: Programming flash in progress: 5% (DO NOT INTERRUPT)
    HSB updater: Programming flash in progress: 10% (DO NOT INTERRUPT)
    ...
    HSB updater: 100% complete, ETA  0:00:00 (DO NOT INTERRUPT)
    Finalize bitstream upload for HSBE2 slot 1 ...
    Bitstream upload for HSBE2 slot 1 successful
    HSBE2 firmware update: the system will automatically reboot to activate slot 1.
