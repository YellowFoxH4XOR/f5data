Topic

You should consider using this procedure under the following condition:

  • You want to update a file-based script on the LineRate system

Description

When a modified script is replaced on the LineRate system, which uses the source file directive to call that script, the script does not automatically reload into the data path. Consequently, the system continues to operate using the old version of the script. The script must also be applied to the data path through the REST API, using the curl utility.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have a LineRate system with file-based scripting enabled
  • You have a previously configured script in the data path
  • You have a replacement script with the same name as the original, which will be copied from a remote machine
  • You have a local computer with access to the curl and scp utilities

Procedures

Updating a file-based script on the LineRate system

This procedure assumes that you have previously created the following configuration on the LineRate system, and that you are modifying a file-based script named myScript.js:

    script myScript
     source file "myScript.js"
     admin-status online

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. From your local computer, use the scp utility to copy the replacement script from your local computer to the /home/linerate/data/scripting directory of the LineRate system, and include a valid user name and password.
  2. From your local computer, use the following curl command syntax to authenticate to the LineRate system and create an HTTP cookie (for use in step 3):

    curl -k -c cookie.jar -d "username=<username>&password=<password>" https://<ip address>:8443/login

    For example, to authenticate to a LineRate system with the IP address 10.11.12.254 and with the user name admin and password test, type the following command:

    curl -k -c cookie.jar -d "username=admin&password=test" https://10.11.12.254:8443/login
  3. From your local computer, use the following curl command syntax to apply the replacement script to the data path:

    curl -k -b cookie.jar --data '{ "type" : "string", "data": "<filename>", "default":false }' -H "Content-Type: application/json" -X PUT https://10.11.12.254:8443/lrs/api/v1.0/config/script/<name of script in config>/sourceFile

    For example, to apply an updated myScript.js file to the data path, use the following curl command from your local computer:

    curl -b cookie.jar --data '{ "type" : "string", "data": "myScript.js", "default":false }' -k -H "Content-Type: application/json" -X PUT https://10.11.12.254:8443/lrs/api/v1.0/config/script/myScript/sourceFile

    The output should appear similar to the following example:

    {"httpResponseCode":200,"requestPath":"/config/script/logger/sourceFile","recurse":false}
