Description
Need to generate APM Access Report for some session variables which are not included in the built in reports.

For example: 
  With SAML Authentication, you want a report to show the username/login name. However, there is no Logon Page in the APM profile.

Environment

  • BIG-IP APM
  • Custom Reports for session variables

Cause
None

Recommended Actions

To generate custom APM Access Report for a specific session variable, perform the following:

  1. Verify whether the 'Logging' agent is configured in your Access Policy (VPE). If not, add that agent after the expected session variable is available. Add new entry with the session variable name.

    For example:
      If the variable 'session.saml.last.identity' is needed. Then add the 'Logging' after the 'SAML Auth', click 'Add new entry' and paste 'session.saml.last.identity' in 'Session Variables' field.
  2. Apply the change
  3. In the custom report, select the 'Session variable value' and update its Alias with the session variable. In the above example, the 'session.saml.last.identity' should be set in the Alias.
  4. Then run the custom report, the variable will be shown up for the new sessions.
