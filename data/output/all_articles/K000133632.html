Description

ASM legitimate requests are logged even though the configured security logging profile only specifies illegal request types.

Environment

  • BIG-IP ASM

Cause

The security logging profile is configured with "Response Status Codes" including valid responses such as the 200 response code.

Recommended Actions

Remove valid response codes like 200 from the selected items' response status code in the security logging profile configuration.

Example:

security log profile "GSB_Logging_local" {
  application {
    "/Common/GSB_Logging_local" {
      filter {
        request-type {
          values { illegal } <———————!!!
        }
        response-code {
          values { 100 101 102 200 201 202 203 204 205 206 207 300 301 302 303 304 305 306 307 401 402 403 404 405 406 407 408 409 410 411 412 413 414 415 416 417 422 423 424 500 501 502 503 504 505 506 507 510 } <———————!!!
        }
      }
      format { type predefined }
      local-storage enabled
  logic-operation or
  maximum-entry-length 2048
  response-logging none
    }
  }
  description "none"
}
