Known Issue

The interfaces on a BIG-IP platform may be reported as unpopulated, or miss.

This issue occurs when one of the following conditions is met:

  • The VIPRION blade cluster status is changed to disabled.
  • The network failover feature is not appropriately configured.

This interface designation is known to occur when the sod process sets the BIG-IP system to the offline state and prevents the bcm56xxd process from configuring the interfaces. After reconfiguring network failover properly, or forcing the unit online, the system reports the interface as expected.

Impact

The interface designation may cause confusion.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system reports interfaces as follows:
    • The system reports interfaces as miss when you run the tmsh show net interface command.
    • The system reports interfaces as UNPOPULATED in the Configuration utility.
    • The system reports interfaces as MS when you run the bigpipe interface show command.
