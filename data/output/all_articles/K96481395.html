Description

Multiple Content Profiles are configured under a single URL, like the following example:

Order: 1
Request Header Name: Content-Type
Request Header Value: *xml*
Request Body Handling: XML
Profile Name: XML_1

Order: Default
Request Header Name: Any
Request Header Value: Any
Request Body Handling: XML
Profile Name: XML_2

You want to know if the request is validated against both Content Profiles.

Environment

  • Security policy
  • Content Profile

Cause

None

Recommended Actions

Requests are not validated against multiple Content Profiles. Only a single header-based Content Profile is selected for each request. This profile will be selected based on the best matching Request Header Name and Request Header Value. The order may also determine which profile is selected, for example if multiple defined profiles would match a given request, the first one will be used.

If the ultimate goal is to validate the request against multiple XML schema files, these can be defined in a single XML Content Profile.
