Known Issue

To configure Active-Active mode when Network Failover is enabled you must use the command line interface.

F5 Networks Product Development tracked this issue as CR19438.

To configure Active-Active mode from the command line, issue the following commands:

b db set Common.Bigip.Failover.ActiveMode = 1

b configsync all
