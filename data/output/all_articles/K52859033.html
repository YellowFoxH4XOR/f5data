Description

The BIG-IP system is not functional and you are not able to access the F5 BIG-IP Configuration Terminal (GUI) and command line (ssh).

You have configured accessing the BIG-IP Configuration Terminal (GUI) and command line (ssh) is via the self IP and not the management interface.

The tmsh show sys license command will display a message similar to the following example:
Can't load license, may not be operational

Environment

  • BIG-IP license is not properly loaded
  • BIG-IP system is not functional
  • Management Interface is not used for administrative access
  • Administrative access is via the BIG-IP's Self IP (including inline connectivity)

Cause

The license process has yet to be performed, the license is missing, or the license is not properly installed. This causes tmm to stop working.

Since administrative access is via the BIG-IP's Self IP (not the management interface), which will be processed by tmm thus it will also stop working.

Recommended Actions

To resolve the issue, perform one of the following procedures based on your BIG-IP device:

  • BIG-IP hardware device
  • BIG-IP virtual edition
BIG-IP hardware device
  1. Log in to the BIG-IP via serial terminal.
  2. Ensure the serial terminal tool allows copy paste feature such as Putty.
  3. Follow article K2595 to activate the license.
BIG-IP virtual edition
  1. Log in to the BIG-IP console.
  2. If the console allows copy paste, follow article K2595 to activate the license.
  3. If the console tool does not allow copy paste, you will need to access the BIG-IP VE via its management interface.
  4. From the hypervisor, ensure the network adapter bridged to the management interface is enabled. 
  5. From the console, enter the F5 Management Port Setup Utility by entering the following command:
    config
  6. To configure the management port, enter the appropriate IP address, netmask, and management route in the screens that follow.
  7. Access the BIG-IP Configuration Terminal (GUI) or command line (ssh) via the newly configured management IP address.
  8. To activate the license via Configuration Terminal (GUI) follow article K7752.
  9. To activate the license via command line (ssh) follow article K7683.
