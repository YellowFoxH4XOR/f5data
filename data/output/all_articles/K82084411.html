K82084411: Cannot import SSL profile to BIG-IQ due to 'dont-insert-empty-fragments', is not valid when Proxy SSL is enabled

Type
Support Solution
Published
2020-10-02
Updated
2023-10-16
Applies to
  • BIG-IQ Platforms
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K82084411

Description

Unable to import SSL profiles from BIG-IP in to BIG-IQ due to "don't-insert-empty-fragments" and "Proxy SSL" being both enabled in the client-ssl profile.  This is an invalid configuration that BIG-IP does not check for, but BIG-IQ does.

The following error message will appear on BIG-IQ GUI:

 Coordinator failed during working-config update, roll-back working-config started; reason: Worker http://localhost:8100/cm/adc-core/working-config/ltm/profile/client-ssl failed validation with status 500: java.lang.IllegalArgumentException: 'TM Option' value, 'dont-insert-empty-fragments', is not valid when Proxy SSL is enabled - /<partition>/<client-ssl_profile>

Environment

  • BIG-IQ
  • BIG-IP
  • Client-ssl profile with 'proxy-ssl' and option 'don't-insert-empty-fragments' enabled.  You might also see "proxy-ssl" enabled and nothing in the "options enabled" box but the clientssl profile has a parent profile.

Cause

ID886049

Recommended Actions
 

Identify the BIG-IP with the named client-ssl profile in the error message and modify the configuration:
  1. Disable the option "don't-insert-empty-fragments".  Or if there are no enabled options, check the "custom" box beside the options to select.  After you click "update" on the profile you will see the pick box change to "All Options Disabled" which removes the options that existed in the parent profile as well.
  2. Re-import the BIG-IP configuration onto BIG-IQ


Additional Information

BIG-IQ may not be able to import configuration from any BIG-IP device until this error has been resolved.  The invalid client-ssl profile may be found on a different BIG-IP device or may already be saved on the BIG-IQ if recently upgraded.
