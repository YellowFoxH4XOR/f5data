K20635225: Windows BIGIP Edge client DNS resolution issues when connected to split tunnel

Type
Support Solution
Published
2022-05-31
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K20635225

Description

Routes for the DNS servers were not added to the client's route table, though "Allow Local Subnet" and "Allow Local DNS Servers" are checked in the associated network access list.

Environment

  • BIG-IP APM
  • Network Access
  • DNS Resolution
  • DNS Relay Proxy Service

Cause

Network Access DNS servers and Client DNS servers are the same.  This is a misconfiguration.
 

Recommended Actions

Change either Client or Network access configuration DNS server assignments
 

Additional Information

None.
