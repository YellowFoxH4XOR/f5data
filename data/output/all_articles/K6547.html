Topic

You can diagnose hardware issues using the FirePass End-User Diagnostics (EUD) feature. The EUD feature is implemented as a boot option. Once booted in EUD mode, the FirePass controller provides a menu of tools for testing hardware components. All FirePass 4100 hardware platforms are currently shipped with EUD.

The EUD feature was introduced on the FirePass 4100 platform with version 5.5.0. If your FirePass 4100 platform shipped before the EUD feature was introduced, and you are running version 5.5.0 or later, a hotfix is available to install the EUD. To download the latest EUD hotfix for your FirePass version, visit the F5 Downloads site.

Important: When downloading an EUD hotfix from the F5 Downloads site, ensure that you have chosen the hotfix that is specific to your FirePass hardware platform and software version. Not all EUD hotfixes support the FirePass 4100 platform. Additionally, older platforms such as 4000, 1000, 600 do not support the EUD feature.

If you are running FirePass version 5.4.2 or earlier, you must upgrade to FirePass version 5.5.0 or later before installing the EUD hotfix.

For information about obtaining and installing EUD hotfixes, refer to K7960: Obtaining and installing the latest version of End-User Diagnostics.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Note: The EUD hotfix is approximately 30 megabytes in size.
