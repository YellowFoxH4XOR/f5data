K000133688: Unable to attach port into a new LAG interface due Server error Interface has VLAN associated with it

Support Solution
Published
2023-05-26
Updated
2023-05-26
Applies to

  • F5OS-A: 1.3.X, 1.3.2, 1.3.1, 1.3.0
Source

Description

While trying to add a new device interface into LAG port, rSeries device returned Server Error Interface has VLAN associated with it. Remove the VLANs before adding it as a LAG member.

 

Environment

rSeries

F5OS-A 1.3.1

LAG interface

 

Cause

In some rare case, rSeries allows user to remove VLAN from the device config even while it is assigned to network interface. This issue cause that the rSeries device leaves the VLAN associated to the network interface.

 

Recommended Actions

In order to workaround this issue we have to remove the VLANs from the cli by following below steps:

 

1.- Login into the rSeries by CLI using the admin user

 

2.- Then access to config mode 

 #config

 

3. Remove the vlans from the interface using below command:

 

#no interfaces interface 1.0 ethernet switched-vlan config trunk-vlans

 

4. Commit the changes 

 

#commit
