Description

After setting Port Lockdown to 'none',  still can be seen open ports for the Self-IP address, when performing a Security Scan.

Environment

  • Port Lockdown set to 'none': 
    net self /Common/Self_IP_Service_none {
    address 10.10.10.1/27
    allow-service none
    traffic-group /Common/traffic-group-local-only
    vlan /Common/external
}
  • Using same Self IP address for Virtual Servers configuration

Cause

When you create a virtual server, you specify a destination IP address (Self-IP) and service port. 
Since that, it must serve the port defined and leave it Open.

Recommended Actions

Change the destination addresses to other than the Self IP

Additional Information

You may find all 'destination address' using the same Self IP with the following tmsh command:

list ltm virtual all-properties |grep "destination 10.10.10.1:"
