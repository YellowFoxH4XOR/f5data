Description

When loading the BIG-IP configuration, you may encounter this error:

Failed: name (/Common/dtca.key) Cache path (/config/filestore/files_d/Common_d/trust_certificate_key_d/:Common:dtca.key_61484_2) does not exist and there is no copy in trash-bin to restore from.

The configuration may fail to load in the GUI. You may see only "Management" available in the System --> Resource Provisioning screen.

Environment

  • Loading new TMOS version for first time
  • Upgrading TMOS
  • The file mentioned as not existing in the location actually does exist in exactly the location where the BIG-IP system says it does not exist.

Cause

There are many different ways this failure can occur. The dtca-bundle.crt may have been modified or renamed between the time when a configuration was saved and when loaded again.  

Recommended Actions

  1. Verify that the dtca.key location listed in bigip_base.conf cache path matches the actual location  / filename in /config/filestore/files_d/Common_d/trust_certificate_key_d/
    Example:
    Listing in bigip_base.conf:
    cm key /Common/dtca.key {
        cache-path /config/filestore/files_d/Common_d/trust_certificate_key_d/:Common:dtca.key_55504_4
        checksum SHA1:(redacted)
        revision 4
    }
    Error message:
    Failed: name (/Common/dtca.key) Cache path (/config/filestore/files_d/Common_d/trust_certificate_key_d/:Common:dtca.key_55504_4) does not exist and there is no copy in trash-bin to restore from.
  2. If they do not match, correct the information in bigip_base.conf.  Save the file and run "tmsh load sys config verify" to ensure that the error is gone.
  3. If they do match, but you are still stuck with the error message, then proceed.
  4. Boot back into the last known good software volume or into the last known good .ucs archive.
  5. Do a save / load of the configuration to ensure that the configuration in both memory and disk are in sync.
    (from a tmos shell prompt)
    tmsh save /sys config
    tmsh load /sys config
  6. Reinstall the desired software version to a new software volume and re-attempt the upgrade.
