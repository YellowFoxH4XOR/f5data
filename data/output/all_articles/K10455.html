Known Issue

This is the result of a known issue. When the Maximum Age setting in the BIG-IP WebAccelerator acceleration policy is set to 0 (zero), objects matching the policy should not be eligible for Intelligent Browser Referencing (IBR). However, the IBR feature is not properly disabled for these objects.

F5 Product Development tracked this issue as CR120630 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
