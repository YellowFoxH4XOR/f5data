You can disable attack signature checks for specific entities. This functionality allows you to prevent an attack signature from triggering for a valid URI request, headers, parameters or other attributes within the HTTP request while leaving the attack signatures in place for the entire policy.

To configure an entity in the BIG-IP ASM security policy and disable attack signature checking on it, perform one or both of the following procedures, as appropriate for your software version:

  • Disable attack signatures for URLs
  • Disable attack signatures for parameters

To watch a video demo of these procedures, go to  K000152953: Disable BIG-IP ASM attack signatures for entities using the Configuration utility.

Disable attack signatures for URLs

Note: The BIG-IP ASM system does not check attack signatures against parameters in allowed URLs if a signature has been disabled on the URL.

Note: For explicit URLs, type the full resource path beginning with the forward slash (/) character.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > URLs > Allowed URLs.
  3. Verify that the policy you want to edit displays in the list below the tabs. If not, select the correct policy in the list.
  4. Select Create.
  5. Under Create New Allowed URL, for URL Example: /index.html, select Explicit or Wildcard and select the appropriate protocol HTTP or HTTPS.
  6. For URL Example: /index.html, optionally select a specific method to represent an API endpoint.
  7. Enter the URL string.
  8. Configure the remaining settings as needed.
  9. Under Attack Signatures, perform one of the following procedures:
    • To disable all attack signatures for the allowed URL, clear the check box for Check attack signatures and threat campaigns on this URL.

      Note: When this option is disabled, the BIG-IP ASM system does not check signatures on inbound or outbound transactions for this URL.

    • To disable only specific attack signatures for the allowed URL:
      1. To disable only specific attack signatures for the allowed URL, leave the check box selected and select Click here to load Signatures List to display the list of attack signatures if they are not already displayed.
      2. In the Global Security Policy Settings list, select the particular attack signature you want and move it to the Overridden Security Policy Settings list.
      3. For each signature, for State, select Disabled if necessary.

        Note: If you select Enabled for State, the BIG-IP ASM system checks the attack signature for the URL.

  10. Select Create.

    The page refreshes, and the new allowed URL appears on the Allowed URLs page.

  11. Select Apply Policy.

Disable attack signatures for parameters

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Parameters.
  3. Verify that the policy you want to edit displays in the list below the tabs. If not, select the correct policy in the list.
  4. Select Create.
  5. Under Create New Parameter, for Parameter Name select Explicit, No Name, or Wildcard and then enter the parameter name.
  6. For Parameter Level, select Global, URL, or Flow.
  7. Configure the remaining settings as needed.
  8. Select the Attack Signatures tab, and perform one of the following procedures:
    • To disable all attack signatures for the parameter, clear the Check attack signatures and threat campaigns on this parameter check box.

      Note: When this option is disabled, the BIG-IP ASM system does not check signatures on inbound or outbound transactions for with this parameter.

    • To disable only specific attack signatures for the parameter:
      1. Leave the check box selected and select Click here to load Signatures List to display the list of attack signatures if they are not already displayed.
      2. In the Global Security Policy Settings list, select the particular attack signature you want and move it to the Overridden Security Policy Settings list.
      3. For each signature, for State, select Disabled if necessary.

        Note: If you select Enabled for State, the BIG-IP ASM system checks the attack signature for the parameter.

  9. Select Create.

    The page refreshes, and the new parameter appears on the Parameters List page.

  10. Select Apply Policy.
