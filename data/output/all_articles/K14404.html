Known Issue

The BIG-IP system may reset connections for a virtual server configured with a request-adapt profile. This issue occurs when the following condition is met:

  • The virtual server is BIG-IP ASM-enabled.

The request-adapt profile allows a virtual server to forward HTTP requests to a pool of Internet Content Adaptation Protocol (ICAP) servers for content modifications before sending HTTP requests to a web server. ICAP is typically used to implement services, such as virus scanning and content filtering.

Impact

Connections to the affected BIG-IP ASM virtual server will be reset.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H417272 on the Diagnostics > Identified > Medium screen.
  • A packet capture on the affected traffic shows the system resets the connection immediately after the TCP handshake completes.
  • The BIG-IP system reports error messages in the /var/log/ltm file that appear similar to the following examples:

    01220001:3: TCL error: _plugin_rule_/Common/pluginasm <HTTP_REQUEST> - Failed on current side. invoked from within "ASM::disable"
    01220001:3: TCL error: _plugin_rule_/Common/pluginasm <HTTP_CLASS_SELECTED> - Failed on current side. invoked from within "ASM::enable"
