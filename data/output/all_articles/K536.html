Issue

This issue is most common in BIG-IP versions prior to 4.0 when filters are configured using the ipfw tool from the command line. It occurs when the Configuration utility CGI script cannot interpret the filter rule you defined, because the script does not know the meaning of specific keywords.

For example, with the ipfw tool you can use the keyword established in a filter rule so that established connections are allowed through the filter. However, early versions of the BIG-IP Configuration utility were unable to process the keyword, established, so the Configuration utility would display the following error:

Error 60 --File Parse Error

This error message can also occur if you use an asterisk (*) in a rule, to imply all.

Starting in BIG-IP 4.0, The keyword knowledgebase and syntax in the Configuration utility is more robust, so this error happens less frequently.

Important: If you choose to create filters using the command line, edit them there as well since any ipfw-specific settings will be removed if you subsequently modify the filter using the Configuration utility.

For more information about configuring IP filters from the command line, refer to the ipfw man page.
