Known Issue

The BIG-IP system may chunk Internet Content Adaption Protocol (ICAP) requests or responses with no body

This issue occurs when all of the following conditions are met:

  • You configure the virtual server with an HTTP profile and either a Request Adapt or Response Adapt profile in order to send requests or responses to an ICAP server.
  • The ICAP server modifies the request or response.
  • The modified request or response uses HTTP/1.1 and contains no body and no HTTP Content-Length header.

Impact

The BIG-IP system adds a Transfer-Encoding: chunked header to the request or response and appends a zero length chunk.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The recipient of the request or response behaves unexpectedly due to the chunking behavior.
  • Servers return an HTTP 503 Service Unavailable response when using Request Adapt or Response Adapt profiles.

Workaround

To work around this issue, you can use an iRule to insert a Content-Length header into the request or response. For example, you can filter for requests that use the GET method and contain no Content-Length header, then insert a Content-Length: 0 header. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. Type a name for the Name setting.
  5. Type the following code into the Definition setting:

    when ADAPT_REQUEST_HEADERS {
        if {([HTTP::method] eq "GET") and (not [HTTP::header exists 'Content-Length'])} {
            HTTP::header insert Content-Length 0
        }
    }

  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers.
  8. Click Edit in the Resource column for the virtual server.
  9. In the iRules section, click Manage.
  10. In the Available section, click the name of the iRule you just created then click << to move it to the Enable section.
  11. Click Finished.
