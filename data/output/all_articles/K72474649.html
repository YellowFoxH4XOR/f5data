Known Issue

The access permissions for the /var/log/ts directory and the files under /var/log/ts are set to read, write, and run for all users (chmod 777).

Impact

Authenticated users have permissions to modify BIG-IP ASM log files.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H566659 on the Diagnostics > Identified > Low page.
  • The ls command indicates that the access permissions for the /var/log/ts directory are set to read, write, and run for all users (chmod 777).

    For example:

    ls -ld /var/log/ts
    drwxrwxrwx 6 root root 4096 Aug 15 09:30 /var/log/ts

  • The ls command indicates that the access permissions for files in the /var/log/ts directory are set to read, write, and run for all users (chmod 777).

    For example:

    ls -l /var/log/ts
    total 52
    drwxrwxrwx 3 root   root   4096 Aug 15 09:04 archive
    drwxrwxrwx 2 root   root   4096 Aug 15 09:04 temp
    -rw-r--r-- 1 root   root   4961 Aug 19 15:51 ts_debug.log
    drwxrwxrwx 2 root   root   4096 Aug 15 09:04 units
    drwxrwxrwx 2 root   root   4096 Aug 15 09:04 unsent
    -rw-r--r-- 1 apache apache 1392 Aug 19 16:25 xui.log
