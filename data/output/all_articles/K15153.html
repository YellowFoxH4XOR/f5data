Known Issue

The BIG-IP APM system may incorrectly rewrite multi-byte characters.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • JavaScript Patching is enabled in the Portal Access configuration.
  • JavaScript in the server response contains multi-byte characters.

Impact

Web application functionality breaks when accessed through the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Dynamically generated requests for portal access resources fail.
  • You may view parsing errors in the /var/log/rewrite file.
  • Portal access resources fail to render properly in the browser.
