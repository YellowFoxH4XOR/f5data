Description

Key import of an existing HSM key fails with "Key management library returned bad status: -18, A vendor error has occurred" message.

Log file /var/log/ltm shows

C_SetAttributeValue: pkcs11_rv=0x00000010, CKR_ATTRIBUTE_READ_ONLY

 

Environment

  • BIG-IP configured with Luna HSM.
  • Private keys stored on HSM generated using third party utilities, for example "cmu generatekeypair"
  • Private key attribute "modifiable" set to "false"

 

Cause

During key import BIG-IP modifies "id" attribute of the imported private key. If the imported key has attribute "modifiable=false" key import fails.

 

Recommended Actions

Generate private keys stored on Luna HSM with attribute "modifiable=true"

 

Additional Information

To list private key attributes use Luna command "cmu getattribute"
