Description

If you want to view the current custom resource (CR) for VLAN configuration In BIG-IP Next CGNAT CNF.

Environment

  • Product: BIG-IP Next CGNAT CNF
  • VLAN Custom Resource (CR) objects

Cause

Viewing the current custom resource (CR) for VLAN configuration In BIG-IP Next CGNAT CNF.

Answer/Recommended Actions

  • Viewing current VLAN Custom Resource configuration:

    kubectl get f5-big-net-vlans.k8s.f5net.com -o yaml
kubectl get f5-big-net-vlans.k8s.f5net.com <vlan-name> -o yaml
