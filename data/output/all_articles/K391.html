K391: Determining node state based on the type of TCP response received from the node

Topic

When a BIG-IP health monitor checks the state of a node, it only determines if content is returned. The BIG-IP system is not able to differentiate TCP responses and, therefore, cannot detect a difference between a connection that is reset or a connection that is timed out.

It is possible to construct an EAV (Extended Application Verification) health monitor that can differentiate between TCP responses. If you would like more information about writing an EAV, contact F5 Networks Consulting for assistance.
