K41057203: Attaching a static bandwidth controller to a virtual server chain can cause tmm to crash

Type
Knowledge
Published

  • BIG-IP LTM: 13.1.0, 16.1.0, 16.1.1, 16.1.2, 16.1.3, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 16.0.1, 16.0.0, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 14.0.0, 13.1.4, 13.1.3, 13.1.1
Source

Description

Attaching a static bandwidth controller to a virtual server chain can cause tmm to crash.

A virtual server chain means that traffic is directed to the virtual server via a policy (either LTM / PEM policies) or traffic is directed to the virtual server via an irule attached to another virtual server.

                                                       + BWC static policy set on the virtual targeted virtual (aka loopback virtual)

Environment

  • Static BWC attached to a virtual server 
  • Traffic to the virtual server is directed via an LTM/PEM policy (CPM) or via irules

Cause

This is caused by Bug ID 967905.
 

Recommended Actions

The options to avoid this crash include:

  1. Do not use a policy or irule to send traffic to the virtual server with a static BWC policy
  2. Upgrade to a version not affected by this issue
  3. Attach the upload-facing static BWC policy to the front-end virtual server, and attack the downstream BWC policy to the back-end virtual server
