Policy Information

Software version support of LineRate software

The LineRate Standard Support phase begins with the First Customer Ship date (FCS) of the major or minor release of the product and ends at the End of Software Development (EoSD) date. The software version Standard Support phase is characterized by the introduction of software fixes, typically including security updates and stability improvements, delivered through maintenance and interim releases. New product features are typically not introduced to a software version after its FCS date.

After the EoSD date, the release may enter the EoSD phase. Software version branches of LineRate software that have reached their EoSD date are no longer supported with active software development or software fixes. These software versions will continue to receive reasonable effort configuration support until reaching their End of Technical Support (EoTS) date. However, F5 is no longer liable to provide software fixes or consulting services for that software version branch.

Each LineRate software version branch follows one of three release support models: Long Term Support (LTS), Short Term Support (STS), or Limited Support (LS). F5 designates the release support model for a software version branch at FCS of the release. F5 may promote a release to a longer-term support model but will not demote a release to a shorter support model.
