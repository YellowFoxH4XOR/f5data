K10598: OWA attachment download fails when Normalization is enabled

Topic

When Normalization is enabled for the Documents group, attempts to download an Outlook Web Access (OWA) email attachment through a BIG-IP WebAccelerator virtual server will fail. In addition, the BIG-IP WebAccelerator returns the following error message to the client:

Cannot retrieve normalized object

Such behavior is correct and expected, due to the way OWA sets the Expires date for email attachments. For email attachments, OWA sets the Expires date in the past to prevent the client from caching the attachment. This is a security feature designed to protect sensitive information. For more information, refer to the following Microsoft Knowledgebase article:

http://support.microsoft.com/kb/331931

When normalization is enabled, the BIG-IP WebAccelerator sends 302 redirect responses referencing the attached object. Since the content has already expired, the client receives the error when it follows the redirect.

You can avoid this error by globally or selectively disabling the BIG-IP WebAccelerator Normalization feature. When Normalization is disabled, the BIG-IP WebAccelerator acceleration policy corrects this issue by setting the Expires date in the future.

Note: For the Documents group, the default Expires value is 10 seconds in the future, allowing the client to access the content while still preventing the client from caching the content longer than necessary.

Version 10.x

To disable Normalization on the BIG-IP WebAccelerator version 10.x, perform the following procedure:

  1. Log in to the WebAccelerator Configuration utility. 
  2. Navigate to WebAccelerator > Applications > URL Normalization.
  3. To completely disable Normalization, remove documents from the Normalize these Groups-Selected section.
  4. Individual types still may be included under Normalize these Types-Selected.

Note: For more information about disabling Normalization for version 10.x, refer to the Managing URL normalization settings section of the Configuration Guide for the BIG-IP WebAccelerator System.

Version 9.4.x

To disable Normalization on the BIG-IP WebAccelerator for version 9.4.x, you must edit the globalfragments.xml file to modify the Normalization settings.

Note: For more information, refer to the Changing default values for URL normalization section of the Administrator Guide for the BIG-IP WebAccelerator System.
