K000163108: F5OS host may fail the upgrade to v2.0.0 if more than 3 DNS servers are configured

Type
Support Solution
Published
2026-08-26
Updated
2026-09-24
Applies to
  • F5OS Products
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000163108

Description

Upgrade to F5OS 2.0.0 failed during compatibility verification when more than three DNS servers are configured.

The following error is displayed on GUI:

System database upgrade compatibility check failed

The platform.log reports:

CDB: Upgrade failed: Upgrade transaction failed to validate: too many /oc-sys:system/dns/servers/server, 4 configured, at most 3 must be configured

Environment

  • F5OS
  • More than three DNS lookup servers configured on the host
  • Upgrading to v2.0.0

Cause

The upgrade validation supports a maximum of three configured DNS servers. When four DNS servers are configured, the upgrade transaction fails validation.

Answer/Recommended Actions

Reduce the configured DNS lookup servers to three or fewer before retrying the upgrade.

  1. Log in to the F5OS web user interface with administrative access.
  2. Go to System Settings > DNS.
  3. Locate the DNS Lookup Servers section.
  4. Select a DNS server to remove.
  5. Delete the selected DNS server.
  6. Select Save & Close to apply the configuration change.
  7. Confirm that no more than three DNS servers remain configured.
  8. Retry the F5OS host upgrade.

Additional Information

None.
