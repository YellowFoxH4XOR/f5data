Description

During upgrade, when booting into new software version, and configuration is loading for validation, it can fail with error messages like following:

Unexpected Error: Loading configuration process failed

The full error message contains detail of which configuration item caused it to fail. You rectify the issue but on the 2nd reload you get a new configuration error. This is because there could be more items that would not be accepted and trigger a new error that stops the config load each time you try.

Is it possible to validate all the errors that can cause the loading process fail. 

Environment

  • Upgrade and boot from new software volume
  • MCPD Validation process running 

Cause

MCPD Validation process go through configuration items in sequence and the first item it find that can not be validated, it throws error and process is stopped. 

Recommended Actions

It is not possible to validate all errors at once when loading new software version. You have to fix one error at a time and reload again to see if there are any further errors.
