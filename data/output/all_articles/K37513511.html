Known Issue

BIG-IP GTM does not recognize DNS cache resolver configuration changes until the Traffic Management Microkernel (TMM) restarts.

This issue occurs when all of the following conditions are met:

  • You change the BIG-IP GTM cache resolver configuration.
  • The cache resolver is associated with a DNS profile in a virtual server.

Impact

DNS cache resolver queries may behave unexpectedly after the configuration is changed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Changes to the DNS cache resolver are not effective.

Workaround

To work around this issue, you can restart the tmm process. To do so, perform the following procedure:

Impact of workaround: Restarting TMM interrupts all traffic processing; you should perform this procedure during a maintenance window.

  1. Log in to the BIG-IP system as the root user.
  2. Restart the tmm process by typing the following command:

    bigstart restart tmm
