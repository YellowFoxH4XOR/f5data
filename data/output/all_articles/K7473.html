This article applies to BIG-IP 9.x. For information about other versions, refer to the following article:

  • K14568: Downgrading BIG-IP software (10.x - 11.x)
Note: For information about downgrading software from 10.x to 9.x, refer to K9745: Reverting BIG-IP version 10.x LVM disk format to the partitions disk format.
Note: F5 implemented a new partitioning scheme beginning with BIG-IP 9.3.1 and later, and BIG-IP 9.4.2 and later. If you intend to downgrade BIG-IP 9.3.1 and later, or 9.4.2 and later, to versions prior to 9.3.1 or 9.4.2, you must perform a PXE installation and install the previous version on all slots on the system. For more information, refer to K7608: Choosing a partition scheme while upgrading.
Downgrading BIG-IP software for BIG-IP platforms that support multiple boot images

Important: Downgrading BIG-IP software deletes and overwrites all BIG-IP configuration and license information. No supported method exists for automatically rolling back the BIG-IP configuration when reinstalling an earlier version of the software.

Note: For information about reinstalling the same version of BIG-IP software and restoring the configuration, refer to K3621: Reinstalling BIG-IP LTM, ASM, GTM, PSM, APM, WOM, Link Controller, WebAccelerator, or Edge software.

The following BIG-IP platforms support multiple boot images:

Note: Before you downgrade the BIG-IP software, refer to the BIG-IP release notes and verify that your platform supports the software version to which you intend to downgrade.

  • BIG-IP 520 and 540 (D35)
  • BIG-IP 1500 (C36)
  • BIG-IP 1600 (C102)
  • BIG-IP 3400 (C62)
  • BIG-IP 3410 (C100)
  • BIG-IP 3600 (C103)
  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 6900 (D104)
  • BIG-IP 8400 (D84)
  • BIG-IP 8800 (D88)
  • BIG-IP 8900 (D106)

You can downgrade the BIG-IP software on BIG-IP systems that support multiple boot images by performing a clean installation over a newer version on a given partition.

For example, if BIG-IP LTM 9.2.5 is installed on slot HD1.1 of your BIG-IP system, and you want to downgrade slot HD1.1 to 9.2.3, you can a perform a clean installation over a newer version using one of the following methods:

  • Network Boot (or through a PXE Server)
  • USB CD-ROM
  • Local Installation
  • Remote Installation

Note: For more information about performing these installation methods, refer to the BIG-IP LTM release notes.

Downgrading BIG-IP software, for BIG-IP platforms that do not support multiple boot images

Note: The below platforms do not support the BIG-IP ASM or WebAccelerator modules.

The following BIG-IP platforms do not support multiple boot images:

  • BIG-IP 1000 (D39)
  • BIG-IP 2400 (D44)
  • BIG-IP 5100 and 5110 (D51)

You can downgrade the BIG-IP LTM, GTM, or Link Controller software on BIG-IP systems that do not support multiple boot images by performing a clean installation over the newer version.

You can a perform a clean installation over a newer version using one of the following methods:

  • Network Boot (or through a PXE Server)
  • USB CD-ROM
  • Local Installation
  • Remote Installation

Note: BIG-IP platforms that contain only a compact flash storage may not have sufficient disk space to use the local installation method.

Note: For more information about performing these installation methods, refer to the BIG-IP LTM release notes.
