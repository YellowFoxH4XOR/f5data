Known Issue

This is the result of a known issue. Back-end servers using Oracle Access Manager (OAM) to grant access to resources through BIG-IP APM may experience authentication and access failures. When this behavior occurs, the user receives the following error message: 

HTTP status: 401 error

This issue occurs because BIG-IP APM does not insert the SSO header reply from the OAM server into the HTTP POST request message to the back-end server. As a result, the back-end server denys the request.

F5 Product Development is tracked this issue as ID 339630 and has been fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in cumulate hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
