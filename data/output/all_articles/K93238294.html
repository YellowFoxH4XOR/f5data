Description
In some cases Security and/or Audit departments may wish to install 3rd Party monitoring software
 

Environment

  • BIG-IP
  • BIG-IQ
  • F5OS

Cause
Installation of 3rd Party software is not supported unless explicitly documented as supported.

Recommended Actions

  • Do not install 3rd Party software on F5 systems without express direction from an authorized F5 representative

Additional Information

  • The F5 SIRT has specifically noted the lack of support for 3rd party software, specifically:
    "We do not support installation of 3rd party software on BIG-IP, or other F5 products. BIG-IP is not a general purpose Linux server and it is *highly* likely tools designed to run on and scan a Linux system will get erroneous results on a BIG-IP as it is not a standard environment."
