Topic

When two BIG-IP devices are located too far apart to use a serial failover cable, you can use network failover as an alternative to using hardware failover.

Description

The BIG-IP system sends heartbeat packets over the network to communicate availability and active or standby status. The system sends the heartbeat packets at a certain rate, which differs depending on the version of BIG-IP system. The following table shows the heartbeat rate for each BIG-IP version.

(packets per second)		Details

16.x10The network failover heartbeat increased to provide the fast failover functionality.
15.x10The network failover heartbeat increased to provide the fast failover functionality.
14.x10The network failover heartbeat increased to provide the fast failover functionality.
13.x10The network failover heartbeat increased to provide the fast failover functionality.

9.3.x1 to 2The network failover heartbeat is separated from state mirroring communication.
