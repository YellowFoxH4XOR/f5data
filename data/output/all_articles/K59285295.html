K59285295: Error log; ''Could not open temporary statistics file ''pg_stat_tmp/global.tmp'': No space left on device''

Type
Support Solution
Published
2021-03-04
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP LTM: 15.0.1
Source
https://my.f5.com/manage/s/article/K59285295

Description

The GUI (Configuration Utility) is not working properly, there is no access or the system is really slow and there are some logs similar to these:
 
  • LOG: could not open temporary statistics file "filename/global.tmp": No space left on device
  • Could not open file "filename": No space left on device.

Environment

  • Var/log/ltm
  • BIG-IP LTM
  • No space left.

Cause

There were temporary files created in "/var/ts/var/tmp/" directory due to an unknown reason and those temp files were eating up the inodes in the var directory.

Recommended Actions

To work around this issue some files need to be deleted :

Delete tmp files

 
Run next command to delete some files that are consuming disk space:

           -rm -rf /var/ts/var/tmp/*.tmp.*
 

If the issue persists, please increase tomcat memory:

Reconfiguring the provision.tomcat.extramb key


Impact of workaround: There will be a brief disruption to the BIG-IP Configuration utility while the tomcat process restarts.

Increase tomcat memory with this command:

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Set the provision.tomcat.extramb database variable to the amount of additional memory that you want to be allocated, using the following command syntax:

    modify /sys db provision.tomcat.extramb value <MB>

    In this command, note the following:
    • <MB> is the number of megabytes of additional memory that you had previously configured.
    For example, if you had previously configured an additional 20 MB of additional memory, type the following command:

    modify /sys db provision.tomcat.extramb value 50
  3. Restart the tomcat process by typing the following command:

    restart /sys service tomcat
