Description

Password Caching allows automatic reconnection without the need to provide credentials again.

Edge Client Password Cache Expiration value for Android/IOS can be modified on "Save Password Method: memory", but, not on "Save Password Method: disk". The Expiration value on "Save Password Method: disk" is indefinite and can not be changed.  This is designed behavior. 

    Environment

    • APM
    • Connectivity Profile

    Cause

    Allow Password Caching checkbox is cleared by default.

    Recommended Actions

    Modify Edge Client Password Cache Expiration value via Configuration Utility

    From the Save Password Method list, select disk or memory.

    • If you select the disk, Edge Client caches the user's password (in encrypted form) securely on the disk where it is persisted even after the system is restarted or Edge Client is restarted.
    • If you select memory, Edge Client caches the user's password within the BIG-IP Edge Client application for automatic reconnection purposes.
    • If you select memory, the Password Cache Expiration (minutes) field displays with a default value of 240.

    Modify the Password caching timeout for Edge Client for Android/iOS

    Update the connectivity profile to configure Password caching for BIG-IP® Edge Client® for Android/iOS.
    1. On the Main tab, click Access Policy > Secure Connectivity .
      A list of connectivity profiles displays.
    2. Select the connectivity profile that you want to update and click Edit Profile.
      The Edit Connectivity Profile popup screen opens and displays General Settings.
    3. From the left pane of the popup screen, select Mobile Client Settings..
      Mobile Client settings for Android/iOS display in the right pane.
    4. Check Allow Password Caching.
    5. Select memory on Save Password Method.
    6. Adjust the Password Cache Expiration (minutes). The default value is 240.
