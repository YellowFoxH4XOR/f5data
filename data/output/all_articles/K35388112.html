K35388112: Is there any default settings for the HTTP request parameter ''password'' length?

Type
Support Solution
Published
2021-11-22
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.3
Source
https://my.f5.com/manage/s/article/K35388112
Description

Is there any default settings for the paramater "password" length?
-> In the first change Maximum Length was set to 15.

User get blocked when entering a password with more than the maximum length.

Environment

  • ASM Custom Parameter
  • Parameter Default (Maximum Length)
Cause

The default value on maximum length in a parameter is 10

Recommended Actions

  1. You may increase the value of your parameter (password) to a number that meets your business requirement under Security ›› Application Security : Parameters : Parameters List.
  2. Select the parameter name.
  3. In Data Type section, Change the Maximum Length value.
  4. Click Update.
