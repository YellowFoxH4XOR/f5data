Known Issue

When you try to open a remote connection to another BIG-IP using SSH, you may receive the following error message:

Host Key Not Found

This error message can occur in the following two situations:

  • When an SSH client connects to an SSH server for the first time, host keys are exchanged to establish encryption for the security of the connection. In some cases, you are prompted to accept or refuse the particular host key.

    Unless you suspect a security issue, accept the host key. If you do not accept the host key, you will receive a Host key not found error.

  • If you change the IP address of a BIG-IP, SSH assumes that the host key for that particular IP address has also changed. SSH considers this suspicious behavior from the SSH server to which you are connecting, as it may indicate a "man-in-the-middle" or "spoof" attack.

    If you know for certain that the reason you received the Host key not found error is because you changed the IP address, you can either remove the offending host key or all known host keys.

    • To change a single host key, edit the SSH client's known_hosts file and delete the line that contains the key.
    • To remove all known host keys, delete the /root/.ssh/known_hosts file.

    Note: If you are running UNIX for Windows or Mac OS, refer to the SSH client manual for specific instructions.

    After you remove the keys, you will need to reconfirm all host keys for each SSH host to which you connect.
