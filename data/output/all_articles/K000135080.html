Description

How to enforce HSTS on ASM blocking page

Environment

  • ASM
  • Security policy
  • HSTS

Cause

None

Recommended Actions

For ASM blocking page responses, you can enforce HTTP Strict Transport Security header via iRule or by creating a custom response page and adding the HSTS header to it:

Irule example:

when HTTP_RESPONSE_RELEASE {
if { !([HTTP::header exists "Strict-Transport-Security"])} {
HTTP::header insert Strict-Transport-Security "max-age=16070400; includeSubdomains"
}
}
