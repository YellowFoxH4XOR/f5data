K53046005: Cloud Failover Extension is not working properly after upgrade

Type
Support Solution
Published
2023-07-31
Updated
2025-04-01
Applies to
  • Public Cloud
  • BIG-IP
  • F5 Cloud Services
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K53046005

Description

After upgrade  a BIG-IP pair  which has been deployed in a public cloud environment using CFE (Cloud Failover Extension)  is not working  as expected after a failover event.

  • Float IP (also known as PIP) NIC is not properly updated.

  • Similar logs may appear on the BIG-IP system in the /var/log/restnoded/restnoded.log file:
Wed, 03 Feb 2021 16:17:38 GMT - severe: [RestOperationDispatcher] 'shared/cloud-failover/trigger' not found. 
Wed, 03 Feb 2021 16:17:38 GMT - severe: [ErrorHandlingModule] RestOperation failed: "/shared/cloud-failover/trigger". {"code":404,"message":"","referer":"Unknown","originalRequestBody":"{\"code\":400,\"message\":\"remoteSender:Unknown, uri:http://localhost:8105/shared/cloud-failover/trigger, method:POST referer:Unknown\",\"referer\":\"Unknown\",\"restOperationId\":5438791,\"kind\":\":resterrorresponse\"}","errorStack":[]}

Environment

  • Azure Cloud
  • AWS
  • BIG-IP VE
  • Cloud Failover Extension 

Cause

API communication cannot be completed due to mismatched version or corruption on the RPM file.

Similar logs may appear on the BIG-IP system:

Wed, 03 Feb 2021 16:17:38 GMT - severe: [RestOperationDispatcher] 'shared/cloud-failover/trigger' not found.
Wed, 03 Feb 2021 16:17:38 GMT - severe: [ErrorHandlingModule] RestOperation failed: "/shared/cloud-failover/trigger". {"code":404,"message":"","referer":"Unknown","originalRequestBody":"{\"code\":400,\"message\":\"remoteSender:Unknown, uri:http://localhost:8105/shared/cloud-failover/trigger, method:POST referer:Unknown\",\"referer\":\"Unknown\",\"restOperationId\":5438791,\"kind\":\":resterrorresponse\"}","errorStack":[]}

Recommended Actions

  1.  Verify the output of the following API calls to cloud-failover on both HA peers: 

    https://<BIG-IP-address>/mgmt/shared/cloud-failover/info
    https://<BIG-IP-address>/mgmt/shared/cloud-failover/declare
     

  2.  RPM file needs to be re-installed or updated
