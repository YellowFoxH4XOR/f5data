Known Issue

The BIG-IP system's TMM process may leak memory when handling HTTP traffic that uses Deflate content encoding.

This issue occurs when all of the following conditions are met:

  • The BIG-IP virtual server references an HTTP profile.
  • The origin server is sending HTTP traffic with the Accept-Encoding: deflate header.

Impact

Performance may degrade over time and the system may eventually become unresponsive due to memory exhaustion. This issue may lead to failover in redundant pairs.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H420212 on the Diagnostics > Identified > High screen.
  • The BIG-IP system may experience slow connections.
  • The BIG-IP system may fail over due to memory exhaustion.
  • You may view error messages in the /var/log/ltm file as the host approaches its memory limit.

    For example:

    011e0002:4: sweeper_update: aggressive mode activated. (117504/138240 pages)
