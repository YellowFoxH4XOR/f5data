Known Issue

Creating a resource record with ZoneRunner may display limited record types.

This issue occurs when the following conditions are met:

  • From the Configuration utility, you use the DNS > Zones > ZoneRunner > Resource Record List pathway to create a new resource record.
  • The resource record name contains less than five characters.

Impact

The BIG-IP system displays limited resource record types.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to create a new resource record, the menu only displays four record types (CNAME, NAPTR, NS, and PTR).
  • When attempting to create a new resource record, where the name contains more than five characters, the record type menu displays all eleven record types.

Workaround

To work around this issue, you can use the following alternate Configuration utility pathway to create the resource record. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Zones > ZoneRunner > Zone List.
  3. Click a Zone Name link.
  4. Click the Resource Records tab.
  5. Click Create.
  6. From the View Name menu, select the view name for the new resource record.
  7. From the Zone Name menu, select the zone name for the new resource record.
  8. In the Name box, type the name of the new resource record.
  9. In the TTL box, type a time to live value for the resource record.
  10. From the Type menu, select the type of resource record.
  11. Click Finished.
