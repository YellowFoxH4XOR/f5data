K55893068: AWS VE unable to reactivate license - error when generating dossier

Type
Support Solution
Published
2020-07-01
Updated
2025-02-06
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP Cloud Edition
  • Amazon Web Services
Source
https://my.f5.com/manage/s/article/K55893068

Description

BIG-IP VE deployed in AWS platform unable to proceed with license reactivation.

  • Unable to generate dossier from CLI and GUI.
  • Error message such as

    err chmand[PID]: Curl request to metadata service failed with error(28): 'Timeout was reached' err chmand[PID]: 012a0003:3: DossierReq exception: VirtDossier Service: Instance identity retrieval from the metadata failed. Check network connectivity to the instance metadata before retrying warning get_dossier[PID]: 012a0004:4: hal_request_dossier: request failed err get_dossier[PID]: 01170003:3: halGetDossier returned error (1): Dossier generation failed. err get_dossier[PID]: 01170003:3: halGetDossier returned error (1): Dossier generation failed.

Environment

  • BIG-IP VE Cloud Edition
  • AWS
  • Originally deployed using Single NIC AWS BIG-IP VE template and added additional NICs.

Cause

Unknown at the time of publishing.

Recommended Actions

  1. Deploy a multi-NIC BIG-IP VE instance.
  2. Reactivate the license.
  3. Add to existing HA cluster.
  4. Sync configuration from HA peer to newly setup BIG-IP VE.

Additional Information

None
