K000139548: [Next][CM] - Unable to recreate VELOS provider on Central Manager

Source

Description

When attempting to recreate a Next instance (that used to exist, before) through a VELOS provider, BIG-IP CM may throw some error message: SHARED-00001: Internal Server Error.

Environment

  • BIG-IP Next Central Manager
  • VELOS provider

Cause

This may be because of: (Bug alias 1584041) [Next CM] "Internal Server Error" when recreating any previously deleted Provider.

Recommended Actions

Please open command line connection to the CM;

  1. sudo kubectl get pods --> let's look at the list of pods, and let's locate the POD mbiq-proxy-service-<NUM>
  2. sudo kubectl delete pod <pod-name>  --> let's trigger a restart for this POD
  3. sudo kubectl get pods --> we'd need to wait until it's up & running (usually takes ~10-15 seconds

Additional Information
