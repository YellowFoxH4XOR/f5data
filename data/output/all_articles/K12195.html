Known Issue

This is the result of a known issue. When accessing a Microsoft Remote Desktop session through a Java-based Terminal Server favorite that is configured to use full screen screen resolution, the remote desktop session may not fill the entire screen. In addition, menu bars and other application windows on the client may obscure portions of the remote desktop session window. 

F5 Product Development is tracking this issue as ID 338380.

Workaround

You can work around this issue by defining a fixed screen size that is not the full screen setting. You can define the screen size either in the favorite settings for the individual terminal server or the terminal server Master Group settings.

Configuring a global master group setting for screen size

  1. Navigate to Application Access : Terminal Servers : Master Group Settings.
  2. Select the screen resolution you want to use from the Select initial preference for the Terminal screen resolution: drop-down menu.
  3. Optional: You can define a custom screen resolution by selecting the following options:
    • Selecting custom from the Select initial preference for the Terminal screen resolution: drop-down menu
    • Entering a width in the Width: text box
    • Entering a height in the Height: text box

Configuring screen size for a Terminal Server favorite

  1. Navigate to Application Access : Terminal Servers : Resources.
  2. Click the name of the terminal server favorite you want to edit.

    The favorite will expand to show the detail.
  3. Select the screen resolution you want to use from the Screen resolution: drop-down menu.
  4. Optional: You can define a custom screen resolution by selecting the following options:
    • Selecting custom from the Screen resolution: drop-down menu
    • Enter a width in the Width: text box
    • Enter a height in the Height: text box
  5. Click the Update button.
