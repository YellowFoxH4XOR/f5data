Issue

If a semicolon (;) character is used to end a SQL string statement in the Send String field of an Oracle monitor, an error message displays that appears similar to the following example:

SQLException ORA-00911: invalid character

The Oracle monitor does not require a semicolon at the end of the SQL statement.

The error message is only visible if the debug option is enabled within the advanced properties of the monitor. When debug is enabled, a separate log file is created in the /var/log directory that appears similar to the following example:

ORACLE_<name of monitor>.\:\:ffff\:<IP address of member being monitored>..<Port number of member>.log

Workaround

If this error occurs, edit the SQL statement within the Send String field, and remove the semicolon from the end of the statement.
