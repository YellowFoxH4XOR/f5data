Description

BIG-IP ASM triggers an illegal parameter location violation for a parameter. The parameter is already configured with 'ANY' location.

Example:

Violation Details
Illegal parameter location [2]
Detected Parameter Location  Query String
Expected Parameter Location Form Data
Parameter Level Global
Parameter Name username
Parameter Value jsmith
Applied Blocking Settings Block Alarm

Environment

  • ASM security violation
  • parameter location
  • explicit parameter
  • wildcards

Cause

The same parameter is being called multiple times in a different location like a query string or in a form-data input.
 

Recommended Actions

The concerned parameter is present in different locations, choose either of the below workarounds to resolve the issue. Based on the example in description:

Workaround 1:

Choose  location 'ANY' for an explicit parameter username.
 

Workaround 2:

  1. Create a wildcard parameter for user* and choose location as 'Formdata'
  2. Create another explicit parameter username for the other desired location 'Querystring'.
