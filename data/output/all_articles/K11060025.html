Topic

This article provides information about downloading F5 Access mobile apps. To download the BIG-IP Edge Client installer from the BIG-IP APM system as a system administrator, refer to the following article:

  • K44328534: BIG-IP administrator instructions for downloading BIG-IP Edge Client for Windows and Mac OS X, and Linux clients

Note: If you are a VPN end user and want to download the BIG-IP Edge Client desktop application (and not the F5 Access Windows Store app), you must either refer to your organization's documentation or contact your IT department for details about how to download the desktop application from your organization's internal resources.

Note: The app previously known as BIG-IP Edge Client has been renamed F5 Access as of version 3.0.0 for Android and version 2.1.0 for iOS.

Description

F5 offers the F5 Access and BIG-IP Edge Client mobile apps to support the BIG-IP APM system. To review compatibility between software and app versions, refer to F5 Apps Compatibility Matrix.
