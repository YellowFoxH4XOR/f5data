Known Issue

When you attempt to import a FIPS key using the Configuration utility, you may receive the following error:

Error 331958 -- Unable to convert key to FIPS. - nCipher KM key generation/import utility key generation/import parameter(s): protect Protected by MODULE x509dnscommon Site domain name <name> ssleayconvfile Key file to import /tmp/.f5km_nftmp/tmp.key recovery Recovery feature 1 Importing existing key ... Unable to process key data being imported /tmp/.f5km_nftmp/tmp.key: unable to find RSA PRIVATE KEY section in .pem file

This is the result of a known issue. The BIG-IP Configuration utility strips linefeed characters from the text that you enter in text boxes; however, FIPS requires a linefeed character at the end of the key.

F5 Networks Product Development tracked this issue as CR46515 and CR46516 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the 4.6 software branch.

Workaround

If upgrading is not an immediate option, you can work around this issue by importing FIPS keys using the command line.
