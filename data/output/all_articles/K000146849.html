K000146849: Error: Change of loadbalancer type from HttpsAutoCert to Https (or vice versa) is not supported

Published

Updated

Applies to

  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000146849

Description

  • You want to change the HTTP Load Balancer from HTTPs auto cert to HTTPs ( or vice versa) custom certs
  • You are unable to create the HTTP load balancer with custom certificates: 
    • Change of loadbalancer type (from HttpsAutoCert to Https) is not supported
      Show Less
      �ReplaceResource: Failed transaction handling http_loadbalancer: STM Error, PreDBUndo Error: %!s(<nil>): Applying transaction function: Change of loadbalancer type (from HttpsAutoCert to Https) is not supported< >

 

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Resolution/Answer

  • Create a new Load Balancer from scratch 
  • OR clone the existing one and change to custom cert

Cause

  • AutoCert means F5XC mints certs and the domain may be delegated
  • Trying to change that to HTTPs won't work (unless the objects are removed and new HTTPs LB with same domain name is created with custom certs).
