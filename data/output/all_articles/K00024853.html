Description
Unable to revert BIG-IP remote authentication to the local default value using the Web interface.

Environment

  • BIG-IP
  • Remote Authentication
  • Default Value

Cause
Once an external remote authentication has been set up for the F5 management interface using the Web interface, the local default value for user authentication is no longer available via the web interface.  

Recommended Actions

Login to the BIG-IP device using SSH session to revert user authentication to its default value.
  1. Login to the tmsh mode
    #tmsh
     
  2. Reconfigure user authentication to its default value
    # modify auth source type local
     
  3. Save BIG-IP configuration
    #save sys config
