Topic

You should consider using this procedure under the following condition:

  • You want to send an email notification from the BIG-IQ system when a Secure Sockets Layer (SSL) certificate is about to expire on a discovered BIG-IP system.

    Note: The SSL certificates/keys on the managed BIG-IP device are discovered by and imported into the BIG-IQ system only during the initial device discovery process. If you have made any changes and/or additions to the SSL certificates/keys on the managed BIG-IP device thereafter, you must remove the managed device and re-discover it in order for the SSL certificates/keys changes and/or additions on the managed device to show up in the BIG-IQ system.

Description

You can configure the BIG-IQ system to send an email alert when an SSL certificate is about to expire on a discovered BIG-IP system. To configure email alerts, complete the following procedures for your specific version:

  • Configuring SSL Device Certificate Expiration alerts
  • Configuring the DNS lookup server
  • Configuring the SMTP server
  • BIG-IQ 6.x and later
  • BIG-IQ 5.2.0 - 5.4.0
  • BIG-IQ 5.0.0 - 5.1.0
  • BIG-IQ 4.4.0 - 4.6.0

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the Configuration utility as the administrative user.
  • You can access an SMTP server to accept email alerts from the BIG-IQ system.
  • You can access a Domain Name System (DNS) server to resolve the host name of your SMTP server.

Procedures

Configuring SSL Device Certificate Expiration alerts (6.x and later)

The default SSL Device Certificate Expiration alert setting is 30 days. To modify this setting, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. Under BIG-IQ, click the Monitoring tab.
  3. Click ALERTS & NOTIFICATIONS.
  4. On the Alerts page, click Settings.
  5. Under the Device Alert Conditions, ensure that the Certificate expiration check box is selected and set Days to expiration to the appropriate number of days.
  6. In the lower-right corner, click Save & Close.

Configuring the DNS lookup server (6.x and later)

To configure the BIG-IQ system to resolve host names using a DNS server, perform the following procedure:

Note: If you want to use a fixed IP address instead of a resolved host name for your SMTP server, you may skip this procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. Under BIG-IQ, click the System tab.
  3. Navigate to THIS DEVICE > DNS & NTP.
  4. In the upper-right corner, click Edit.
  5. Under DNS Lookup Servers, add the DNS server IP addresses.
  6. In the lower-right corner, click Save & Close.

Configuring the SMTP server (6.x and later)

To configure the BIG-IP system to send alerts to an external SMTP server, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. Under BIG-IQ, click the System tab.
  3. Navigate to THIS DEVICE > SMTP Configuration.
  4. Click Add.
  5. Enter a name for the SMTP configuration in the Name setting.
  6. Enter the SMTP server in the SMTP Server Host setting.
  7. Enter the SMTP listening port of the SMTP server in the SMTP Server Port setting.
  8. Enter the originating email address in the From Email Address setting.
  9. If your SMTP server requires SSL/TLS encryption, select the appropriate option for the Encryption setting. Otherwise, leave the setting as No Encryption.
  10. If your SMTP server does not require authentication, select No for the Use Auth setting. If your SMTP server requires authentication, select Yes for the Use Auth setting. Then enter the appropriate username and password in the Auth Username and Auth Password settings respectively before clicking Test Connection to verify the SMTP connection.
  11. In the lower-right corner, click Save & Close.
  12. Navigate to THIS DEVICE > Email Notification Recipients.
  13. Click Create.
  14. Enter a name for the Name setting and email address for the Email Address setting for an email recipient.
  15. Ensure that System Alerts is checked.
  16. In the lower-right corner, click Save & Close.
  17. Repeat steps 13 through 16 for each email recipient you want to add.

Configuring SSL Device Certificate Expiration alerts (5.0.0 - 5.1.0)

The default SSL Device Certificate Expiration alert setting is 30 days. To modify this setting, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. In the upper-left corner, select Device Management from the BIG-IQ menu.
  3. To the right of Device Management, click Operations.
  4. Click Certificate Management.
  5. Click Alert Settings.
  6. Under the Condition column, ensure that the Device Certificate Expiration check box is selected and set Days to expiration to the appropriate number of days.
  7. In the lower-right corner, click Save.

Configuring SSL Device Certificate Expiration alerts (4.4.0 - 4.6.0)

The default SSL Device Certificate Expiration alert setting is 5 days. To modify this setting, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. On the BIG-IQ Systems panel, click the gear icon next to the group name for which you want to define the alert settings, and click Alert Conditions.
  3. Under the Condition column, ensure that the Device Certificate Expiration check box is selected and set Days to expiration to the appropriate number of days.
  4. In the upper-right corner, click Save.

Configuring the DNS lookup server (4.4.0 - 4.6.0)

To configure the BIG-IQ system to resolve host names using a DNS server, perform the following procedure:

Note: If you want to use a fixed IP address instead of a resolved host name for your SMTP server, you may skip this procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. On the BIG-IQ Systems panel, click the gear icon next to the group name for which you want to define the DNS server, and click Properties.
  3. Click Services.
  4. To resolve your SMTP server host name, add one or more DNS server IP addresses to the DNS Lookup Server list.
  5. Click Save.

Configuring the SMTP server (4.4.0 - 4.6.0)

To configure the BIG-IP system to send alerts to an external SMTP server, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the admin user.
  2. On the BIG-IQ Systems panel, click the gear icon next to the group name for which you want to define the SMTP server, and click Properties.
  3. Click SMTP Config.
  4. Under the Settings tab, enter the name and email address for the email recipients.
  5. Under the Server tab, enter the SMTP Server information appropriate for your SMTP Server configuration.
  6. To test the SMTP connection, click Test Connection.
  7. In the lower-right corner, click Save.
