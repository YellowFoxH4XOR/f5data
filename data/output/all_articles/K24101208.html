Issue

Error Message

01071a95:3: Admin IP (<AdminIP>/<AdminNetMask>): Gateway (<AdminGateway>) for management route (<Route>) is not in a connected network.

In this error message, note the following:

  • <AdminIP> is the administration port IP address.
  • <AdminNetMask> is the configured netmask for the administration port IP address.
  • <AdminGateway> is the default gateway for the administration IP address.
  • <Route> is the management route.

For example:

01071a95:3: Admin IP (192.0.2.100/255.255.255.0): Gateway (192.0.2.1) for management route (/Common/management_route) is not in a connected network.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You create a management IP address that is on a different subnet than the management route.

This validation error message helps prevent users from leaving a stray management gateway configured.

Impact

None

Recommended Actions

Delete the erroneous management route and add a new route that matches the management IP address. To do so, refer to K13284: Overview of management interface routing (11.x - 14.x).
