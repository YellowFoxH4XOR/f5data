Description

This article explains how to troubleshoot NTP issues by enabling ntp debugging?

Environment

Relevant environmental factors specific to the topic

  • BIG-IP / BIG-IQ
  • NTP

Cause

none

Recommended Actions

  1. Log in to the CLI of BIG-IP/BIG-IQ
     
  2. To enable NTP debugging, you must first stop the NTP daemon: 
    bigstart stop ntpd 
  3. Then run the following command to enable debugging output to standard out:
    ntpd -d
    If you need to direct all the output to a file:
    setsid ntpd -d > /var/tmp/ntpdebug.log 2>&1 
  4. Review debug logging for NTP troubleshooting
     
  5. To disable the NTP debugging run: 
    bigstart restart ntpd

Additional Information

Taking a packet capture while NTP is in debug mode:
Switch command -X outputs on the screen in SSH.

Management IP

tcpdump -ni mgmt -s0 -vw /var/tmp/ntp.pcap port 123 -X
tcpdump -ni mgmt host <ntp_server_IP> -X


All interfaces:

tcpdump -ni 0.0:nnn src port 123 and dst port 123 -X
tcpdump -ni 0.0:nnn host <ntp_server_IP>  -X 


NOTE: to save file, use: -w </full/path/to/the_file.pcap>
