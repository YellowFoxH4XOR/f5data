Known Issue

This is the result of a known issue. When a Windows client attempts to drag and drop a file between remote shares using the CIFS protocol, the operation may fail. When this issue occurs, the Windows client reports an error message that appears similar to the following example:

The specified network name is no longer available

The following informational messages may also be logged to the /var/log/wocplugin file on the client-side BIG-IP WOM system:

wocplugin-2[1695:f76176d0] CIFSFile.h:664 : GetFlowThread 0: 0x1e000 843776 921600
wocplugin-3[1695:f76176d0] CIFSClient.cpp:641 : \150MB.doc:0x4014 : Received response 0x68b5000 bytes 0xf000 0
wocplugin-2[1695:f76176d0] CIFSFile.h:664 : GetFlowThread 0: 0x1e000 905216 921600
wocplugin-3[1695:f76176d0] CIFSFile.cpp:201 : \150MB.doc:0x4000 : Closing...
wocplugin-2[1695:f76176d0] CIFSFile.cpp:4779 : \150MB.doc:0x4014 : Not sending pattern across m_fileHistory :(nil), m_fileHistory->patternCount 0 m_eof: 160055808
wocplugin-3[1695:f76176d0] CIFSFile.cpp:201 : \150MB.doc:0x4014 : Closing...

Note: During reproduction testing, this issue was observed to affect only approximately 25 percent of attempted drag and drop operations.

F5 Product Development is tracking this issue as ID 340635.
