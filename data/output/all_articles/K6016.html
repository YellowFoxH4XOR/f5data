K6016: The wideip.conf file does not contain the include topology.inc statement

Knowledge
Published
2006-08-04

Applies to

  • BIG-IP GTM: 9.2.5, 9.2.4, 9.2.3, 9.2.2
Source
https://my.f5.com/manage/s/article/K6016

Issue

Beginning in BIG-IP GTM 9.2.2 the /config/gtm/wideip.conf file no longer requires the include topology.inc statement to use the Topology function. If a /config/gtm/wideip.conf file exists, the gtmd process automatically includes the /config/gtm/topology.inc file.

No error occurs if you add the include topology.inc statement to the /config/gtm/wideip.conf file. However, if you update and save the /config/gtm/wideip.conf file, the system removes the statement.
