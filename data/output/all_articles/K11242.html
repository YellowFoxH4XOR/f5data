Known Issue

This is the result of a known issue. Users may report that they see the Home/Logout tab for a web application favorite even if the FirePass controller has been configured not to show that tab. This issue occurs when the following conditions are met:

  • You selected the Open in new window check box for the web application favorite
  • You selected the Proxy Basic and NTLM auth using FirePass user logon form check box and set the Preference to either Basic Authentication or NTLM Authentication on the Portal Access : Web Applications : Master Group Settings page
  • The Web Application Favorites URL is added to the Portal Access : Web Applications : Content Processing : Global Settings tab "Home/Logout" tab injection section
  • The Web Application Favorites URL uses Basic or NTLM authentication 

Note: For information about disabling the Home and Logout tabs, refer to K4880: FirePass may insert an HTML navigation script into a JavaScript source file.

F5 Product Development is tracking this issue as ID 294320 (formerly CR136527).

Workaround

You can work around this issue by clearing the Open in new window check box in the Web Application Favorites configuration. You can configure Portal Access Web Application Favorites on the Portal Access : Web Applications : Resources page.
