Description

User is using Apple iOS with F5 Access and not able to connect with the following error message:
The operation couldn’t be completed. (PacketTunnel.RemoteEventError error 1.)

Environment

  • BIG-IP APM
  • Apple iOS
  • F5 Access Client

Cause

There are multiple causes for the error; however, if the error is accompanied by User notifications are not available, the F5 Access app will not be launched if requested by PacketTunnel in the PacketTunnel.log, then notifications are not enabled for the F5 Access app on the iPhone and this is causing the failure.

Recommended Actions

F5 Access must have notifications enabled for any user prompts or weblogon interactions.

To avoid this issue, you can check and enable the iPhone settings on Notification for the F5 Access app.
