Known Issue

The Application Visibility and Reporting (AVR) Page Load Time feature may impact content formatting.

This issue occurs when all of the following conditions are met:

  • Your virtual server is configured as part of a BIG-IP Analytics profile.
  • Your BIG-IP Analytics profile is configured with the Statistics Gathering Configuration > Collected Metrics > Page Load Time feature.
  • Uncompressed HTTP content processed by the virtual server is text/html that does not include the HTML head tag.

Impact

Page Load Time JavaScript is inserted into non-HTML content.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Non-HTML content does not display correctly or returns JavaScript errors.
  • Applications dependent on the text/html content do not function correctly.

Workaround

To work around this issue, you can removed the Page Load Time feature from the BIG-IP Analytics profile. To do so, perform the following procedure:

Impact of workaround: Page load times are no longer tracked for virtual servers configured with the BIG-IP Analytics profile.

  1. Log on to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Analytics.
  3. Click on the Profile Name of the affected BIG-IP Analytics profile.
  4. Locate the Statistics Gathering Configuration section.
  5. Clear the Page Load Time check box.
  6. Click Update.
