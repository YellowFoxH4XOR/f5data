K99532234: Live Update of the Browser Challenges failed with error - ''Installation error: gpg: WARNING: unsafe ownership on homedir [...]''

Type
Support Solution
Published
2020-10-02
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K99532234

Description

During the Live Update of the Browser Challenges an Error Message similar to below appears in GUI:

Installation error:
gpg: WARNING: unsafe ownership on homedir `/usr/share/live-update/share/gpg/browser_challenges_genesis_load'
gpg: encrypted with 1024-bit ELG key, ID 7C3E3CE5, created 2007-03-20 "asm_sigfile_installer"
gpg: Signature made Thu Nov 2

Environment

  • BIG-IP ASM 15.1.x
  • Live Update of Browser Challenges

Cause

Bug ID 950953

Recommended Actions

As a workaround you can set Browser Challenges version to factory default for 15.1.0.
This should allow installation of new version.

Impact: This command will cause the system to become offline for a few minutes and then back online (causing failover).
  1. Execute below command from BIG-IP bash shell:

    Run: tmsh -q -c "cd datasync-global; delete security datasync update-file update-file-clntcap*"
     
  2. Perform another attempt of Live Update Browser Challenges installation

Additional Information

None
