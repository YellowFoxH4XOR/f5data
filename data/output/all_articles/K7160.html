Known Issue

This is the result of a known issue. The BIG-IP system implements the libuser library, which is a standard interface for manipulating system user and group accounts. A libuser memory leak causes the mcpd process to grow in size. This can result in system resource starvation and can cause TMM to crash.

F5 Product Development tracked this issue as CR72660 and CR71138, and it was fixed in BIG-IP versions 9.1.3, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller release notes.
