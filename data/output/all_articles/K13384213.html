Description

After installing a new version to a boot location, in the file /var/log/ltm, this error started coming up saying that drive /tmp/lind_util.xxxxxx (slot x) has only 0% free space.

Environment

  • Disk space

  • Software installation

  • BIG-IP

Cause

/tmp/lind_util.xxxxx is created at the time of software installation because it's required for base image installation after creating a new volume.
After finishing the upgrade, this mount point will be unmounted and all dependent directories will be deleted.

Recommended Actions

None. Work as designed. So this log '/tmp/lind_util.xxxxxx (slot x) has only 0% free' can be ignored.

Additional Information

If you run df -h you will see something like this:

Filesystem       Size    Used      Avail        Use%            Mounted on
/dev/cdrom       2.5G   2.5G      0              100%             /tmp/lind_util.xxxxxx
