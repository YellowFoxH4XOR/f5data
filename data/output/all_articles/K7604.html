K7604: Deleting the client.f5c file removes the Windows standalone VPN Client connection history

Topic



The FirePass Windows standalone VPN Client stores your connection history in the client.f5c file, which is typically located in the following location:

Note: In the following example, <logon> is your Windows logon.

C:\Documents and Settings\<logon>\Application Data
\F5 Networks\VPN\client.f5c

If you delete this file, your connection history will be lost. The next time you launch the Windows standalone VPN Client, the VPN Client will create a new client.f5c file by copying the file located in the \Program Files\F5 VPN directory to the \Documents and Settings\<logon>\Application Data\F5 Networks\VPN\ directory.

Note: If you also deleted the client.f5c file located in the \Program Files\F5 VPN directory, you will need to reinstall the Windows standalone VPN Client so that a new client.f5c file can be created.
