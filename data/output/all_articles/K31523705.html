Known Issue

ActiveX-based RDP AppTunnel sessions fail to establish on BIG-IP APM 12.1.5.2

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is running version 12.1.5.2.
  • The BIG-IP APM system is configured to provide ActiveX-based RDP access using an AppTunnel.
  • A user establishes a session to the BIG-IP APM system, downloads the client components, and attempts to establish an RDP session.

Impact

When the user attempts to establish RDP sessions, the ActiveX controls fail to download and the RDP session fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After upgrading to BIG-IP APM 12.1.5.2, when users attempt to connect to RDP resources the connection stalls and closes.
  • ActiveX-based RDP session establishment fails with the following message:

    Connecting to server. Please wait.

Workaround

You may be able to work around this issue by connecting to another BIG-IP APM system running a different version, for example BIG-IP APM 14.x, downloading and installing the client components from that system, and reconnecting to the BIG-IP APM system running BIG-IP 12.1.5.2.
