Topic

The XML profile does not support the document/literal unwrapped WSDL binding method.

Description

The document/literal unwrapped binding style has systemic limitations when mapping a WSDL to SOAP method, including:

  • The SOAP body element may have any number of children elements.
  • Operation names are not mapped from the WSDL to the SOAP message.

Due to the limitations of this binding style, methods that are defined in the WSDL for an XML profile may be allowed by the BIG-IP ASM system, even if the SOAP method is explicitly defined as not allowed in the XML profile. Methods that would otherwise generate the SOAP method not allowed violation will not be blocked.

Recommendations

To correctly block SOAP methods that are not allowed, it is recommended that the WSDL use another binding method. For more information about WSDL to SOAP binding styles, refer to the Supplemental Information section.
