K5302: The network map displays disabled virtual servers as available if the Manual Resume setting is enabled

Known Issue

This is the result of a known issue. If you have enabled the Manual Resume setting for a virtual server, the network map will display the virtual server as available, even if you have disabled the virtual server.

F5 Networks Product Development tracked this issue as CR24751 and CR24754.
