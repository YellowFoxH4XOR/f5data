K000140512: "Host inaccessible or in diagnostic mode" message on LCD panel during iSeries startup

Type
Support Solution
Published
2024-07-30
Updated
2026-05-26
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000140512

Description

"Host inaccessible or in diagnostic mode" is being displayed on LCD panel on each system startup. This happens whenever platform_check test is being triggered, and the system is going into diagnostic mode.

Environment

  • iSeries
  • "Host inaccessible or in diagnostic mode" on LCD panel

Cause

Platform Diagnostics are executed every time a system reboots. This is an expected behavior of the system. The message was introduced via ID602830 & ID563592.

Recommended Actions

If the system starts up correctly, the message should go away automatically after ~5 minutes. If the LCD is still displaying "Host inaccessible or in diagnostic mode" after this time period, reboot the BIG-IP system again. If the message remains, check if the device works correctly and contact F5 Support.

Additional Information

None.
