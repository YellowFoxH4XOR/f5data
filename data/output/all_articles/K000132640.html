Description

The num-threads value essentially provides channels for HSM communications.

When num-threads = 0, the Big-IP polls the HSM device and matches that number of open channels. If the Thales or Safenet device returns 0 then the Big-IP uses the default num-threads value of 20. When num-threads uses the default value, 20, at least 20 num-threads are used in this HSM communication. If it's set to 40, then at least 40 num-threads are used, etc. Though increasing the number of pkcs11d threads should give better performance (TPS) when using multiple HSMs, it increases the CPU utilization.

To check the # of threads:

'ps -eLf | grep "/usr/bin/pkcs11" | wc -l'

To view the current num-threads value:

tmsh list sys crypto fips external-hsm num-threads

To update the num-threads value:
Note: This needs to be performed on each Big-IP.

tmsh modify sys crypto fips external-hsm num-threads 20
tmsh save sys config

Then restart pkcs11d to implement these changes.
Note: This is traffic impacting and should be performed during a maintenance window.

tmsh restart sys service pkcs11d

Afterwards, confirm the # of threads:

'ps -eLf | grep "/usr/bin/pkcs11" | wc -l'

Monitor the CPU utilization:

tmsh show sys tmm-info

Environment

vCMP guests

Cause

Functions as designed.

Recommended Actions

Follow instructions above to check or change the num-threads value.
