Known Issue

This is the result of a known issue. The OID name loadBalTrapPortString implies that the trap provides a string; however, the checktrap.pl script pushes the trap using [OID_TYPE_INT].

The contradiction between a string and an integer has caused confusion. In BIG-IP 4.5.11 and 4.6.3, the MIB and the checktrap.pl script were changed to indicate that the OID name loadBalTrapPortString is supplied as a string. This change was not correct, because loadBalTrapPortString is actually a port number, and must be provided as an integer.

Beginning in versions 4.5.14, loadBalTrapPortString is once again reported as an integer.

F5 Product Development tracked this issue as CR29255, CR57149, and CR57150. This issue was resolved in BIG-IP 4.5.14 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.
