Description

To verify whether longest match is enabled or not for the DNS topology records. 

Environment

  • BIG-IP DNS
  • Topology Records

Cause

None

Recommended Actions

  • Login to F5 device and then navigate to DNS  ››  GSLB : Topology : Records  ››  Change Order
  • If the check box for longest match is checked then it is globally enabled.
