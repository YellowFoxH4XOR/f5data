Known Issue

This is the result of a known issue. Network Access virtual servers have a default UDP forwarding timeout of 7200 seconds. As a result, UDP traffic, such as DNS queries, directed through a Network Access tunnel virtual server can cause a large number of entries in the connection table.

F5 Product Development tracked this issue as ID 225789 (formerly CR140150) and it was fixed in BIG-IP versions 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP APM and Edge Gateway release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can work around this issue by configuring a layered virtual server for UDP traffic. To do so, perform the following procedures:

Determining the connectivity profile

  1. Log in to the BIG-IP Configuration utility.
  2. From the navigation pane, expand Local Traffic.
  3. Click Virtual Servers.
  4. Click the name of the Virtual Server created for network access.

    The Virtual Server Properties page opens.
  5. Navigate to the Access Policy section.
  6. Note the Connectivity Profile selected.

Creating the UDP layered virtual server

  1. Log in to the BIG-IP Configuration utility.
  2. From the navigation pane, click Virtual Servers.
  3. Click the Create... button.

    The New Virtual Server window opens.
  4. Navigate to the General Properties section.
  5. In the Name field type a name for the new virtual server.
  6. In the Destination section, click the Network radio button.
  7. In the Address: field type the following:

    0.0.0.0
  8. In the Mask: field type the following:

    0.0.0.0
  9. Select *All Ports from the Service Port drop-down menu.
  10. Navigate to the Configuration section.
  11. Select UDP from the Protocol drop-down menu.
  12. Select Enabled on... from the VLAN and Tunnel Traffic drop-down menu.
  13. From the Available column in the VLANs and Tunnels section, select the Connectivity Profile you noted in the Determining the connectivity profile procedure.
  14. Click the << to move the selected connectivity profile to the Selected column.

    You will see the selected profile move to the Selected column.
  15. Click Finished.

Note: The connection timeout for UDP sessions in the Network Access Tunnel will now be 30 seconds.
