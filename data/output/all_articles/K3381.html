The BIG-IP system uses the following two clocks to track time:

  • The hardware clock, which tracks time even when the system is unplugged. It initializes the operating system clock when the system is started.
  • The operating system clock, which is a software clock used when the system is running that stores time according to the local time zone that you configure when you initially set up the system.

Setting the operating system time on a BIG-IP system

Note: The Linux default security level prevents administrators from setting the time or date back from the current display. Any attempt to set the current time backward results in an Operation not permitted error message. To set the date or time backward, you must boot the system into single-user mode. For instructions, refer to K4178: Restarting the BIG-IP system in single-user mode (GRUB 0.97).

Note: If you are adjusting the date and time for the first time, make sure the appropriate time zone is selected for the BIG-IP system before continuing. If you can access the Configuration utility, navigate to System > Platform. Alternatively, to perform the same operation from the command line, refer to K13369: Performing a first-time configuration from the command line (11.x - 17.x).

  1. Log in to the BIG-IP command line.
  2. To change the operating system time, use the following command syntax:

    date <month><day><hour><minute><year>.<second>

    The specific format is as follows:

    date MMDDHHMMYYYY.SS

    For example, to set the time to 2:00pm on March 4, 2021, type the following command:

    date 030414002021.00

    Important: The greater the time variance change, the greater probability the rrd performance graph information accuracy is affected.

  3. To save the time to the hardware clock (BIOS), type the following command:

    hwclock --systohc

  4. To ensure that the BIG-IP system daemons operate, log, and maintain session state properly after you change the operating system clock, you need to restart the BIG-IP system. To restart the BIG-IP system, type the following command:

    reboot

  5. After the BIG-IP system restarts, you can verify the BIG-IP system time and the hardware clock time by typing the following command:

    date ; hwclock

    The output appears similar to the following example:

    Thu Mar  4 14:15:21 PST 2021
    Thu 04 Mar 2021 02:15:21 PM PST  -0.000184 seconds

Note: After you set the date and time to a roughly accurate value using the date command, F5 recommends that you set up the BIG-IP system to keep its clock synchronized with a network time protocol (NTP) server. For more information, refer to K3122: Using the BIG-IP Configuration utility to add an NTP server and K13380: Configuring the BIG-IP system to use an NTP server from the command line (11.x - 16.x).
