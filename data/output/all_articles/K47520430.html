K47520430: Can you downgrade the BIG-IP Edge client

Description

An APM administrator may want to downgrade the BIG-IP Edge client software their users are using.
An administrator may want to downgrade Edge Client ISO installed on the BIG-IP APM. 

Can these things be done?
 

Environment

  • BIG-IP APM 
  • BIG-IP Edge client
  • Upgrade/Downgrade of the client

Cause

In APM version 13.1.0 and later you can upgrade the Edge Client ISO Per K52547540: Updating BIG-IP Edge Client for the BIG-IP APM system.

  • When downgrading is not possible:
    • The Edge Client ISO cannot be downgraded to a version earlier than the version that came with 13.1.x
    • If the Edge client was upgraded as part of a BIG-IP OS upgrade you cannot downgrade the edge client. See K13757: BIG-IP Edge Client version matrix in order to see which version of edge client comes bundled with which version of BIG-IP OS.

Important: F5 does not support downgrading the APM Clients software to a lower version than what shipped with the BIG-IP OS. Doing so may cause the automatic Component Update to fail on client systems."   Per K23159056: BIG-IP update and upgrade guide | Chapter 22: Upgrade the BIG-IP Edge Client.

Recommended Actions

  • When downgrading is possible:
    • If you upgraded your edge client iso per K52547540 there is a possibility that your users edge client and components could possibly be automatically updated. See K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows, macOS, and Linux CLI for more details regarding this. In the event this has happened and you would like to downgrade the edge client version you are using in your environment you will have to do the following.

 1. First you must install the previously installed version of the edge client on the APM system.
     System  ››  Software Management : APM Clients > Select the previous version of the apm client and install

 2. Next you will have to completely uninstall and reinstall the edge client and all component's from any clients that were upgraded. See K8253: Removing BIG-IP APM client components from Windows client systems.
  
 3. Then you should be able to download and install the older version of the client.
      Access  ››  Connectivity / VPN : Connectivity : Profiles  > Highlight your connectivity profile > Customize package > Download
