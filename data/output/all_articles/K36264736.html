Issue

Error Message

014f0013:3: Script <name> generated this Tcl error: <message>

In this error message, note the following:

  • <name> is the name and partition of the script that generates the error message.
  • <message> is the error message reported by the script.

For example:

014f0013:3: Script (/Common/icall_script) generated this Tcl error: (script did not successfully complete: ("passphrase" can't be empty. while executing "tmsh::save /sys ucs $name passphrase " line:14))

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You implement iCall automation scripting in your BIG-IP configuration.
  • The Tool Command Language (Tcl) script used by iCall encounters an error during execution.

This error message occurs at each invocation of the script, which can be periodic or event-triggered depending on the iCall configuration. For example, error messages generates for the following reasons:

  • Syntax errors
  • Tcl initialization errors
  • iApp or iApp::legacy package dependencies are not met
  • Access to the Advanced Shell (bash) is denied
  • Unsuccessful completion of script execution

Impact

The iCall script fails to complete successfully and does not perform the intended task. The level of impact depends on the intended purpose of the script.

Recommended Actions

Review the error message reported by the script to determine the cause and details of the error.  

For example:

Syntax Error: A port number or service name is missing for "d_port"

You can correct the issue detailed in this example error message by specifying a port number or service name using the syntax d_port:<port>. If you have passwords or other strings with a dollar sign ($) character in your custom script, the Tcl interpreter may interpret the string after the dollar sign as a variable, which could trigger the error.
