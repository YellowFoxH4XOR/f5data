Description

The high temperature maybe cause the device power off silently. Before the device power off, maybe see the ltm log like below:

crit chmand[PID]: 012a0031:2: Chassis Inlet 2 temp high(crit)

Environment

  • BIG-IP

Cause

High temperature environment.

Recommended Actions

Please review the data sheet for the device, make sure the device is running in operational temperature environment.

None.
