K43203722: How to check CPU instance ID for SNMP CPU utilization alerts

Type
Support Solution
Published
2021-11-18
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K43203722

Description

You want to know which CPU core triggered the alert when you receive a CPU instance ID every time in high CPU alerts.
 

Environment

  • BIG-IP
  • VIPRION
 

Recommended Actions

1. Run below command to check the CPU instance ID:

# snmpwalk -v 2c -c public -On localhost | grep CPU

.1.3.6.1.2.1.25.3.2.1.3.196608 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz
.1.3.6.1.2.1.25.3.2.1.3.196609 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz
.1.3.6.1.2.1.25.3.2.1.3.196610 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz
.1.3.6.1.2.1.25.3.2.1.3.196611 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz
.1.3.6.1.2.1.25.3.2.1.3.196612 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz
.1.3.6.1.2.1.25.3.2.1.3.196613 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz
.1.3.6.1.2.1.25.3.2.1.3.196614 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz
.1.3.6.1.2.1.25.3.2.1.3.196615 = STRING: GenuineIntel: Intel(R) Xeon(R) CPU           X5650  @ 2.67GHz


2.  To display the percentage of cpu used on BIG-IP, type the following command:

#tmctl cpu_info_stat -s 'cpu_id,five_sec_avg.ratio'

The output of the command should appear similar to the following example:

cpu_id five_sec_avg.ratio
------ ------------------
     0                 11
     1                  1
     2                  5
     3                  1
     4                  5
     5                  1
     6                  5
     7                  0


3.  The F5-BIGIP-SYSTEM-MIB.txt file is used for general information about the System:

# cat /usr/share/snmp/mibs/F5-BIGIP-SYSTEM-MIB.txt | grep OBJECT-GROUP | grep Cpu

sysCpuGroup OBJECT-GROUP
sysHostCpuGroup OBJECT-GROUP
sysMultiHostCpuGroup OBJECT-GROUP
sysVcmpCpuCoreGroup OBJECT-GROUP
sysCpuSensorGroup OBJECT-GROUP


# cat /usr/share/snmp/mibs/F5-BIGIP-SYSTEM-MIB.txt | grep -A10 sysCpuGroup

sysCpuGroup OBJECT-GROUP
         OBJECTS {
                sysCpuNumber,
                sysCpuIndex,
                sysCpuTemperature,
                sysCpuFanSpeed,
                sysCpuName,
                sysCpuSlot
        }
        STATUS   current
        DESCRIPTION




You can use the "snmptranslate" command to translate MIB OID names between numeric and textual forms:

snmptranslate -On <MIB NAME>::<Object Name>
