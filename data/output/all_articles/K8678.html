Topic

Note: The procedure for performing a local installation changed in the BIG-IP 9.3.0 and 9.4.0 software branches. For information about removing an image using the local-install script for BIG-IP 9.1.1 through 9.2.5, refer to K6655: Using the local-install script to remove an image installed on a boot image slot.

You can use a BIG-IP 9.3.x or 9.4.x local-install script to discard the image installed on one of the boot image slots. To do so, perform the following three procedures:

  • Boot the BIG-IP system to an image that is not the image to be deleted
  • Copy the local installation package to the BIG-IP system
  • Extract the installation files and run the installation script to discard the image
Booting the BIG-IP system to an image that is not the image to be deleted

Note: If the BIG-IP system is already booted to an image that is not the image to be deleted, skip this procedure.

To boot the BIG-IP system to an image that is not the image to be deleted, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Use the switchboot utility to select the image to which you would like to boot. This image is not the image that is to be deleted.

    Note: For information about using the switchboot utility to view images installed on the boot image slots, refer to K5658: Overview of the switchboot utility.
  3. Boot the BIG-IP system to the selected image, by typing the following command:

    reboot
Copying the local installation package to the BIG-IP system

Download the local installation IM package that supports the booted version, and copy it to the BIG-IP in the /var/tmp directory, in accordance with the instructions in the Local Installation section of the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator Release Notes.

The release notes provide a link to the Local Installation document for your specific BIG-IP version.

Note: The local installation IM package installed must support an upgrade from the version that is currently booted into the system. For example, if the currently booted version is BIG-IP 9.3.1, you would not install the BIG-IP 9.2.5 local installation IM package; you would instead install the BIG-IP 9.3.1 or later local installation IM package.

Extracting the installation files and running the installation script to discard the installation

To run the local-install script and discard the image to be removed, perform the following procedure:

Note: You will not perform an upgrade during the following procedure.

  1. Log in to the BIG-IP command line.
  2. Change directories to the /var/tmp directory by typing the following command:

    cd /var/tmp
  3. Run the local-install script, by typing the following command:

    im local-install<version_number>.im
  4. From the Welcome screen, select Continue.
  5. From the Warning screen, select Yes.
  6. From the Server Summary screen, select No.
  7. From the Boot Image Configuration screen, select the image that is to be discarded, then select OK.
  8. From the Configuration screen, highlight Discard Installation and select OK.

    You will be returned to the Boot Image Configuration Screen.
  9. Review the list of boot image locations and proposed changes.

    To proceed, select Done, then select OK.
  10. From the Setup Menu screen, select Done.

    Disregard the option to set up syslog.
  11. The Install screen is the final chance to review the proposed changes. Select Back or No to abort. Select Yes to proceed

The installation script will remove the image to be discarded, and reboot the BIG-IP system.

Verify the discarded installation is no longer available by starting the local installation package again. Proceed to the Boot Image Configuration screen and inspect the Current Products Found.

After verifying the boot image location in question is empty, select Cancel to abort the script.
