Description

EDNS0 Implementation, troubleshooting recommendations and considerations

Environment

  • DNS configuration using topology load balancing method.
  • When you want to perform topology load balancing based on the actual client IP address rather than the LDNS IP address found in the IP header.

Recommended Actions

  • To mitigate the problem of DNS based geo-targetting, Google proposed a technical solution to the issue in an IETF draft Client subnet information in DNS requests. This is an experimental DNS extension that allows DNS resolvers to pass the client’s IP address (or part of) to compatible authoritative DNS servers. The F5 DNS server can then use this information to better determine where the end user is. Google DNS and OpenDNS implemented this solution as part of the Global Internet Speedup initiative in August 2011.

Implementation

Enable Globally:

1. Navigate to “DNS : Settings : GSLB : Load Balancing “

2. Click on the "Prefer Client Subnet" check box

3. Click the "Update button"

 

Enable per wideIP (impacts only the wideIP which you are modifying):

1. Navigate your browser to DNS >> GSLB : WideIP

2. Click on the WideIP in question

3. Open the "Advanced" menu

4. Click on the "Prefer Client Subnet" check box

5. Click the "Update" button

Troubleshooting

Use the following command syntax on a neighboring device to send dns requests to the BIG-IP DNS. The +subnet option is used to populate the "Client Subnet" option in the dns request, so you can test different subnets. This command will send 10 dns requests to the DNS Listener.

for i in {1..10}; do dig @<dns listener> <dns name> +subnet=<subnet-mask> +short; done

For example:

for i in {1..10}; do dig @192.18.1.2 test.example.com +subnet=192.18.1.5/24 +short; done

 

Use the following command syntax on the BIG-IP DNS to capture the relevant dns traffic and verify the dns responses are appropriate:

tshark -ni 0.0 -T pdml -Y 'dns.qry.name matches "<dns name>"' | grep 'dns.opt.client.addr4\|dns.a\|ip.src_host'

For example:

tshark -ni 0.0 -T pdml -Y 'dns.qry.name matches "test.example.com"' | grep 'dns.opt.client.addr4\|dns.a\|ip.src_host'
