K36560003: iRule to display a maintenance page using an image

Type
Support Solution
Published
2019-09-12
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K36560003

Description

You want the BIG-IP system to respond maintenance page with an image.

Environment

  • iRule

Cause

None

Recommended Actions

Use iFiles and iRule to implement your maintenance page. 

iFiles

Upload your image and HTML page as iFiles to the BIG-IP system:
  1. Login to the BIG-IP Configuration utility
  2. Go to Local Traffic > iRules > iFile List
  3. Select Create.
  4. Provide an appropriate name for your image and HTML page. You will use this name in the iRule.
  5. For File Name, select +.
  6. Select Choose File.
  7. Select the file to upload from your client system.
  8. For Name, provide an appropriate name.
  9. Select Import.
  10. Verify the name of your new iFile and it's corresponding file name and select Finished.
  11. Repeat steps 3-11 for any other files your iRule references.

iRule

Configure the following iRule according to your requirement by replacing the filenames /company_logo.png and maintanence_page.html accordingly. 

Note: The example filenames must match the name of the iFiles you used in step 4 of the earlier iFile procedure.

when HTTP_REQUEST {
    switch [HTTP::uri] {
         "/company_logo.png" { HTTP::respond 200 content [ifile get "company_logo.png"] }
        default {
            HTTP::respond 200 content [ifile get maintanence_page.html] "Content-Type" "text/html"
         }
     }
  }
