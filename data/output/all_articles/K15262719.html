Description
During installation of new software image, its not possible to chose disk for installation

tmsh list sys software image is  not showing any information about build, build-date,product , version
sys software image BIGIP-14.1.2.6-0.0.2.iso {
    build none
    build-date "none"
    checksum e870182e7eba66ed7a370fef17a399e7
    file-size "2271 MB"
    last-modified "Wed Nov 25 14:24:16 2020"
    product none
    verified yes
    version none
}


MD5sum is showing correct values as provided on downloads page

Environment

  • BIG-IP Software installation
  • MD5SUM of uploaded software image is correct
  • No information about version, and build in tmsh and GUI

Cause
Unknown.

Recommended Actions

Reboot affected device:
  1. If device is Active in active-standby cluster, Force to Standby Device ( reduce impact for production traffic)
  2. Perform reboot from CLI:
    reboot
