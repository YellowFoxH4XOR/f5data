Known Issue

The Secure Sockets Layer (SSL) handshake may fail when using ECDHE-ECDSA ciphers with a hybrid certificate.

This issue occurs when the following condition is met:

  • A BIG-IP SSL virtual server is configured to use an RSA signed Elliptic Curve Cryptography (ECC) certificate with ECDHE-ECDSA ciphers.

Impact

SSL handshake failures occur when users connect to the BIG-IP virtual server.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/ltm file, you observe messages similar to the following example:

    info tmm[12345]: 01260013:6: SSL Handshake failed for TCP 10.11.12.10:23456 -> 10.11.12.100:443

  • If SSL debug logging is enabled, messages similar to the following example are also logged to the /var/log/ltm file:

    debug tmm[12345]: 01260009:7: Connection error: ssl_select_suite:5803: no shared ciphers (40)

    Note: For more information about SSL debug logging, refer to K17045: Log messages concerning SSL handshake failures may not include enough detail.
