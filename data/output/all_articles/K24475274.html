Known Issue

The BIG-IP ASM policy merge function may fail.

This issue occurs when the following condition is met:

  • You run the BIG-IP ASM Policy Diff feature to merge security policies using the Work on copy option.

Impact

The policy merge fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When running the Policy Diff feature, the policy merge fails with error messages that appear similar to the following example:

    info perl[<pid>]: 01310053:6: ASMConfig change: Security Policy /<partition>/<merged security policy name> [add] { audit: policy = /<partition>/<merged security policy name>, username = <username>, client IP = <ip address> }
    crit g_server_rpc_handler.pl[<pid>]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback): Can't call method "populate_diff_structs" on unblessed reference at /usr/local/share/perl5/F5/ASMConfig/Entity/Base.pm line 7111.
