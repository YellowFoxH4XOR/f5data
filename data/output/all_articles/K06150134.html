Known Issue

The restjavad process may run out of memory when it processes a large amount of data.

This issue occurs when all of the following conditions are met:

  • The restjavad process receives a message that is larger than the total amount of free memory space.
  • You use the iControl REST application programming interface (API) to obtain data from the BIG-IP system.

Typically, the issue occurs when the BIG-IP system sends a broad query to the iControl Rest Daemon (icrd) that results in a large response (approx 200 MB).

Impact

The iControl REST API is not available for configuration queries or modifications.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The restjavad process stops responding to iControl Rest requests.
  • Your iControl Rest API is unable to process queries.
  • In the /var/log/restjavad.0.log file, you may observe error messages that appear similar to the following example:

    java.lang.OutOfMemoryError: Java heap space","at com.f5.rest.common.RestHelper.convertToException(RestHelper.java:3090)"

Workaround

As a temporary work around to this issue, you can restart the restjavad on the BIG-IP system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system, as the restjavad process is no longer responsive.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the restjavad process, type the following command:

    restart sys service restjavad
