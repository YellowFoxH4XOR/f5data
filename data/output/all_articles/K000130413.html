Description

You may come across a situation such as a full directory, not enough cpu/memory, or needing additional NICS. That can be done and in most cases is fairly simple.

Environment

  • BIG-IP in Azure

Cause

An issue arises that you now need to increase so aspect of your BIG-IP in Azure. Reasons to do this will vary, but may include...

  • /var or /shared at 100%
  • Out-of-memory Killer (oom-killer) being invoked due to memory issues. Not enough CPUs when ASM, APM, FIPS, or AVR are in use
  • A need arises for additional NICs for additional trunks
  • Adding disk space to install the new version for an upgrade

Recommended Actions

  1. To add disk space Increase disk space for BIG-IP VE
  2. To add NICs Create additional network interfaces
  3. To add resources may depend on you license...
    1. K72636998: Actions that require creating a new BIG-IP VE instance on public clouds
    2. In many cases you can simply change the VM instance size/type, which will change the CPU and RAM allocation based on the specs for the new instance size. When the new instance is started up it will use the new allocation.
