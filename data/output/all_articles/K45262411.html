Known Issue

The BIG-IP system does not allow address overlapping on the firewall NAT policy match side.

This issue occurs when the following condition is met:

  • You attempt to configure overlapping IP addresses in NAT policy rules.

Impact

You are unable to configure overlapping IP addresses in NAT policy rules.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to use overlapping IP addresses (addresses and address-lists) in NAT policy rules, the system displays an error message. For example, consider the following scenario:
    • You have configured two IP address lists, list1 and list2, similar to the following:

      security firewall address-list list1 {
          address-lists {
              list2 { }
          }
          addresses {
              10.0.0.1/32 { }
          }
      }
      security firewall address-list list2 {
          addresses {
              10.0.0.0-10.0.0.100 { }
          }
      }

    • You attempt to create a NAT policy rule using the two address lists by typing the following command:

      tmsh create security nat policy policy1 rules add { rule1 { source { address-lists add { list1 list2 }} place-before first }}

    • The system displays the following message:

      01071a58:3: IP Address is overlapping with another IP address located in firewall address-list '/Common/list2'

Resolution
