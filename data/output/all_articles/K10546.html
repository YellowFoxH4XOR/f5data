Known Issue

This is the result of a known issue. If a particular port is specified when configuring an SNMP server host, the ARX system's running configuration contains two entries. The first entry does not include the specified port, and the second entry contains the specified port.

The show running-config command displays the snmp-server hosts that appear similar to the following example:

  snmp-server host 5.5.5.5 public
  snmp-server host 5.5.5.5 public 555

As a result, SNMP traps will be sent to the host on the default port only, the custom port specified will not be used.

F5 Product Development tracked this issue as ID 35541 and it was fixed in ARX versions 4.1.1 and 5.1.0. For information about upgrading, refer to the ARX release notes.
