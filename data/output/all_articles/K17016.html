Known Issue

The BIG-IP system time zone does not update following a system configuration using a single configuration file (SCF).

This issue occurs when all of the following conditions are met:

  • You use an SCF file to configure a BIG-IP system.
  • The SCF file contains a time zone setting that is different than the current BIG-IP time zone.

Impact

The BIG-IP system displays incorrect time zone information.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After installing an SCF file on the BIG-IP system, the Linux date command correctly reports the time zone. However, the Traffic Management Shell (tmsh) continues to display the old time zone information.

Workaround

To work around this issue, after restoring an SCF file, you can modify the NTP time zone using tmsh. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Determine the appropriate time zone name from the /usr/share/zoneinfo directory by typing the following command:

    run util bash -c "ls -R /usr/share/zoneinfo"

    Alternatively, you can paginate the results using the less utility.

    For example:

    run util bash -c "ls -R /usr/share/zoneinfo | less"

    Note: To quit the less utility, type q.
  3. Set the desired time zone using the following command syntax:

    modify /sys ntp timezone <timezone filename>

    For example, to set the time zone to Japan (JST), type the following command:

    modify /sys ntp timezone Japan

    Note: You must first save, and then load the configuration before the change takes effect.
  4. Save the configuration change by typing the following command:

    save /sys config
  5. Load the new configuration by typing the following command:

    load /sys config
  6. Confirm you have configured the correct time zone by typing the following command:

    show /cm device | grep "Time zone"
