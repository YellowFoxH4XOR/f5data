Security Advisory Description

In FasterXML jackson-databind 2.0.0 through 2.9.10.2, due to the lack of certain xbean-reflect/JNDI blocking, as demonstrated by org.apache.xbean.propertyeditor.JndiConverter, attackers can exploit JNDI injections to remotely execute code. FasterXML Jackson is a Java-based data processing tool.(CVE-2020-8840)

Impact

This vulnerability can lead to an attacker using JNDI injection to implement remote code execution.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column. If the table lists only an older version than what you are currently running, or does not list a non-vulnerable version, then no upgrade candidate currently exists.

Mitigation

To mitigate this vulnerability, you can limit network access to the management interface to a secure, management-only network limited to specific IP addresses and only trusted users.
