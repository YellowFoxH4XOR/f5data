Description

  • GOOGLE's reCaptcha is not working in some countries
  • users connecting from some locations cannot authenticate using GOOGLE reCaptcha, getting error message:
    Data provided for authentication is not valid
  • users' browser connection to https://www.google.com/recaptcha/api.js times out

Environment

  • BIG-IP with APM or ASM provisioned
  • GOOGLE's reCaptcha is used as additional authentication method (to block bots)

Cause

By default GOOGLE's reCaptcha relies on the client connecting to https://www.google.com/recaptcha/api.js, but this FQDN is blocked in some countries (e.g. China).

Recommended Actions

Replace "www.google.com" with "www.recaptcha.net" in the BIG-IP reCaptcha configuration object.
