Topic

This article discusses BIG-IP support for Kerberos resource-based constrained delegation single sign on (SSO) in BIG-IP APM.

Description

Microsoft introduced Kerberos resource-based constrained delegation SSO in Windows Server 2012 R2 and Windows Server 2012. You can use resource-based constrained delegation to provide constrained delegation when the front-end service and the resource services are not in the same domain. Service administrators are able to configure the new delegation by specifying the domain accounts of the front-end services which can impersonate users on the account objects of the resource services. For more information, refer to Kerberos Constrained Delegation Overview.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

BIG-IP APM currently does not support Kerberos SSO resource-based constrained delegation. When you configure this, Kerberos single sign on does not work, and you may observe an error similar to the following:

Kerberos: can't get S4U2Proxy ticket for server HTTP/john.example.local@EXAMPLE.LOCAL - KDC can't fulfill requested option (-1765328371)
Kerberos: Failed to get ticket for User: 'john@EXAMPLE.LOCAL' accessing service: 'HTTP/john.example.local@EXAMPLE.LOCAL'

Recommendations

Configure Kerberos single sign on within the same domain/realm. For more information, refer to the following:

  • K43193482: Configure BIG-IP APM Kerberos SSO for multiple KDCs for highest performance
  • K43063049: Configuring BIG-IP APM Kerberos SSO constrained delegation for portal access
