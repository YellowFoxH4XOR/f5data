Topic

The following three session variables can potentially be populated with the users homedirectory information from Active Directory (AD) depending on the FirePass configuration:

  • %session.ad.auth.homedirectory%

    This session variable is populated when the user is authenticated through AD
     
  • %session.ad.groupmapping.homedirectory%

    This session variable is populated when the users AD group is dynamically mapped to a master group
     
  • %session.ad.groupresourcemapping.homedirectory%

    This session variable is populated when a users AD group is dynamically mapped to a resource group

Note: If the homedirectory attribute is not populated in AD the session variable will not be created in FirePass.

Mapping a users Active Directory home drive using session variables

Prior to starting this procedure, ensure the following:

  • You have defined a network access connection in FirePass
  • You are using AD for authentication and/or dynamic group mapping in FirePass
  • The users Home folder information in AD is populated
     
  1. Log in to the FirePass Administrative Console.
  2. Click Network Access.
  3. Click Resources.
  4. From the Resource Group: drop-down menu, select the resource group for which you want to create the drive mapping.
  5. Click the Drive Mappings tab.
  6. Type a name for this entry in the Name text box.
    For example:
    homedirectory
  7. In the Path textbox, type the session variable that contains the users homedirectory information.
    For example: 
    %session.ad.auth.homedirectory%
  8. From the Map to drop-down menu, select the drive letter to associate to this drive mapping.
  9. Click the Add button.

Note: If the drive letter is already mapped on a users system, FirePass will prompt the user for an alternate drive letter, disconnect the existing drive letter, or cancel the drive mapping.

Note: Drive mappings are not persistent. The drive will be disconnected on the users system when the network access session is terminated.

Note: For more information about configuring network access connections refer to the FirePass Controller Administrator Guide.
