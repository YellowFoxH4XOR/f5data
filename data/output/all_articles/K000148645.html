K000148645: Key exchange algorithm EECDH is supported as ECDHE

Type
Support Solution
Published
2024-11-22
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000148645

Description

In some cases, servers using TLS1, TLS1.1 or TLS1.2 may require EECDH as the Key Exchange algorithm. This is short for Ephemeral Elliptic Curve Diffie-Hellman. This name is not supported by BIG-IP; however, this algorithm is also abbreviated as ECDHE which is in fact supported.

Environment

  • BIG-IP LTM
  • TLS1, TLS1.1, TLS1.2
  • Cipher suites
  • This article applies to BIG-IP 17.x or lower

Cause

None. Informational only.

Recommended Actions

When EECDH is required, ECDHE can be used in the cipher suite instead.

For instance, use this string in the Ciphers under the SSL Profile: 

DEFAULT:ECDHE

Additional Information

To view the current cipher list that uses ECDHE for the specific version and hotfix level that your system is running, type the following command:

tmm --clientciphers ALL:EXPORT:SSLv3:NULL | grep ECDHE

Note that grep EECDH will show no output.
