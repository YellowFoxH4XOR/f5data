Issue

Error Message

named[4258]: <date> general: error: zone <DNS_zone>: zone serial unchanged. zone may fail to transfer to slaves

Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

In this error message, note the following:

  • <date> is the date when the system logged the error message
  • <DNS_zone> is the name of the locally served DNS zone

For example:

named[4258]: 10-Mar-2012 15:00:00 general: error: zone 127.IN-ADDR.ARPA/IN/view_internal_dns: zone serial unchanged. zone may fail to transfer to slaves.

Message Location

You may encounter this message in the following location:

  • The /var/log/daemon.log file

Description

This message may occur when the named service starts. RFC6303 describes locally served DNS zones as zones that all nameservers should automatically serve, unless intentionally configured otherwise. In BIND 9.6.x, the named process may generate the above error message for locally served DNS zones when the process is starting.  The message may also occur when a zone that has not had its serial number incremented is re-loaded, indicating that a zone transfer may not occur.

Impact

The error messages are benign.

Recommended Actions

None

Note: It is possible to prevent the BIND server from logging the previous messages. You can do so by adding the following directive to the options section of the /var/named/config/named.conf file:empty-zones-enable no;
