Topic

To create a new monitor, perform the following steps:

  1. Log in to the command line.
  2. View the variables for the default monitors, by typing the following command:

    bigpipe monitor list all |more

  3. Find a default monitor on which you want to base the new monitor and make a note of the settings that you want to change.

    For example, if you want to define a new monitor that is based on the default HTTP monitor, view the default HTTP monitor.

    The default HTTP monitor appears as follows:

    monitorroot http {
       defaults from
       interval 5
       timeout 16
       dest *:*
       password ""
       recv ""
       send "GET /"
       username ""
    }

    From the configuration statement of the default HTTP monitor, the following settings are available:

    SettingDefault value
    defaults fromnone
    interval5
    timeout16
    dest*.*
    password" "
    recv" "
    send"GET /"
    username" "

    Important: Note that the values for password, recv, send, and username are contained in quotes. If you want to change these values, you must place the new values in quotes.

  4. Define the new monitor, using the following command syntax:

    bigpipe monitor <name> '{ defaults from <monitor> <setting> <value>... }'

    • Replace <name> with the name you want to use for the new monitor.
    • <monitor> with the name of the default monitor on which you want to base the new monitor.
    • Replace <setting> and <value> with the name and value of each setting you want to change.

    For example, if you want create a monitor named myhttpmonitor that has an interval of 30, a timeout of 91, and a send string of "GET /test.html", you would type the following command:

    bigpipe monitor myhttpmonitor '{ defaults from http interval 30 timeout 91 send "GET /test.html" }'

    If you decide to change the timeout for the monitor to 121, you would type the following command:

    bigpipe monitor myhttpmonitor '{ interval 121 }'

  5. Save the new monitor, by typing the following command:

    bigpipe save
