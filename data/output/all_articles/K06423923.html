Known Issue

The BIG-IP APM active session count may be inaccurate.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is processing active sessions for an access policy.
  • You use the tmsh reset-stats virtual <virtual server name> command syntax to reset the statistics for the virtual server processing BIG-IP APM sessions.

Impact

The BIG-IP APM system reports a skewed active session count.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP APM dashboard active session count is higher than the number of active sessions in the BIG-IP APM Event Logs report.
  • After resetting the statistics on the virtual server, running the tmsh show apm profile access <access policy name> command syntax indicates that the number of active sessions has doubled.
