Topic

You should consider using this procedure under the following conditions:

  • You want to use Terraform and the F5 Application Services 3 extension (AS3) to configure the BIG-IP system.
  • You want to create a template file using an AS3 JSON definition of BIG-IP objects so that Terraform can pass variables to it.

Note: Terraform can also call your AS3 JSON file to apply your object definitions. However, when you create the Terraform template file, as3.tpl, Terraform can pass variables to your AS3 definitions, and you can define variables at runtime.

Description

With AS3, you can deploy an application service configuration on the BIG-IP system using a declarative representational state transfer (REST) API. To do so, you create a JSON file with a declaration and use an HTTP client to transmit it to the AS3 REST API. You can automate the task on a single or numerous BIG-IP systems using Terraform, which is an orchestration tool that automates and manages multi-machine configuration and deployment.

If you need to set up your BIG-IP system before you use AS3, you can use F5 Declarative Onboarding (DO), which uses a declarative model to perform tasks like licensing, provisioning, and initial system and network configurations. For more information about using Terraform and DO, refer to K10631470: Using Terraform and DO to configure the BIG-IP system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You read the F5 Resources for Terraform User Guide.
  • You read the F5 Application Services 3 Extension User Guide.
  • You installed the AS3 package on the target BIG-IP device.

    For more information, refer to Downloading and installing the AS3 package in the "F5 Application Services 3 Extension User Guide."

  • You installed Terraform 0.12.10 or later on your control machine.
  • You installed BIG-IP 13.1 or later on the devices in your environment.
  • You installed the uuidgen utility on the control machine.

Procedures

To configure Terraform to use AS3 to deploy objects on your BIG-IP system, you create the following three files in the same directory:

  • main.tf—A Terraform file that creates the resources, such as the as3.tpl file. You can give the file an arbitrary name, such as install_do or main, but it must have the .tf extension.
  • as3.tpl—Created from an as3.json file, the file contains AS3 JSON declarations of your BIG-IP objects.
  • terraform.tfvars—Contains all the variables you want to declare at runtime. You must use this file name and extension.

To create these files and apply them to your BIG-IP system, perform the following procedures:

Note: To apply your object definitions, instead of using an as3.tpl file, you can have Terraform call an as3.json file directly. However, using Terraform's template file, as3.tpl, enables Terraform to pass variables to your object definitions and you to define these variables at runtime.

  • Creating the JSON declaration template file
  • Creating the main.tf Terraform file
  • Creating the variable definition file
  • Running Terraform to apply the definitions
  • Destroying the AS3 definitions

Creating the JSON declaration template file

File templating is a Terraform feature, and you can create your JSON declaration file as a template to use with the bigip_appsvcs_extension module.

For example, the following procedure:

  • Describes how to include variables, using an example JSON declaration from the "F5 Application Services 3 Extension User Guide."
  • Describes how to use variables for only the label, tenant (administrative partition), id, and virtualAddresses parameters.
  • Provides an outline to help you create more advanced JSON declaration templates and use variables of your own choosing.

Notes:

  • In Terraform templates, variables are surrounded by open (${) and close (}) braces.
  • The template uses existing nodes in the Common partition.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Create a JSON declaration file using the Simple HTTP application example from the "F5 Application Services 3 Extension User Guide," and name it as3.tpl.
  2. Use a text editor to open the file for modification.
  3. For label, replace the value with the following variable: ${ TENANT }.
  4. Above the Tenant class, replace the name with the following variable: ${ TENANT }.

    This is the name of the partition where the system creates your BIG-IP objects.

  5. In the Service class, replace the value for virtualAddresses with ${ VIP_ADDRESS }.
  6. In the Pool class, replace the value for serverAddresses with nodes from your environment, new nodes, or a variable. You can include more than two, if you want.

The following example is a JSON declaration template that includes modifications made in this procedure:

{
   "class": "AS3",
   "action": "deploy",
   "persist": true,
   "declaration": {
      "class": "ADC",
      "schemaVersion": "3.0.0",
      "id": "urn:uuid:${UUID}",
      "label": "${TENANT}",
      "remark": "Simple HTTP application with RR pool",
      "${TENANT}": {
         "class": "Tenant",
         "A1": {
            "class": "Application",
            "template": "http",
            "serviceMain": {
               "class": "Service_HTTP",
               "virtualAddresses": [
                  "${VIP_ADDRESS}"
               ],
               "pool": "web_pool"
            },
            "web_pool": {
               "class": "Pool",
               "monitors": [
                  "http"
               ],
               "members": [{
                  "servicePort": 80,
                  "serverAddresses": [
                     "192.0.1.1",
                     "192.0.1.2"
                  ]
               }]
            }
         }
      }
   }
}

Creating the main.tf Terraform file

You create the Terraform file, main.tf, in the same directory as the template file from the previous procedure.

In the following example:

  • The first three objects declare the password to the BIG-IP system and variables for the AS3 template file.
  • The next objects defines the BIG-IP provider. You must include the terraform stanza, which indicates the latest version of the BIG-IP provider you want to use.
  • The template_file file object reads your AS3 definitions and passes the values of the variables to the as3.tpl file at runtime.
  • The bigip_as3 resource object calls and applies the AS3 definitions in as3.tpl.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your control machine.
  2. In the code in the following step, step 3, in the terraform -> bigip stanza, replace "1.22.2" with the latest version found in the F5Networks/terraform-provider-bigip provider in the Terraform registry.
  3. In a text editor, copy, paste, and save the following as main.tf:

variable "bigip_password" {
  type = string
}
variable "tenant" {
  type = string
}
variable "vip_address" {
  type = string
}
variable "bigip_address" {
  type = string
}
terraform {
  required_providers {
    bigip = {
      source = "F5Networks/bigip"
      version = "1.22.2" #Replace with latest version
    }
  }
}
provider "bigip" {
    address = var.bigip_address
    username = "admin"
    password = var.bigip_password
}
data "template_file" "init" {
  template = "${file("as3.tpl")}"
  vars = {
    UUID = "uuid()"
    TENANT = var.tenant
    VIP_ADDRESS = var.vip_address
  }
}
resource "bigip_as3"  "as3-example" {
     as3_json = data.template_file.init.rendered
     tenant_filter = var.tenant
}

Creating the variable definition file

There are various ways that you can define variables in Terraform. When you do not provide a default value, such as the bigip_password value in this example, the system prompts you to enter one at runtime. For other variables, you declare them in a file that you must name terraform.tfvars and locate in the same directory as your Terraform .tf file.

To create this file and define your variables, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your control machine.
  2. In a text editor, copy and paste the following code, in which tenant is the name of the partition that you will create on the BIG-IP system:

    bigip_address="10.10.10.1"
    tenant="Tenant"
    vip_address="10.10.4.1"

  3. Edit the values to make them appropriate for your environment.
  4. Save the file as terraform.tfvars.

Running Terraform to apply the definitions

To apply the AS3 definitions to your BIG-IP system, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your control machine.
  2. In the directory where you created the two files in the previous procedures, type the following command:

    terraform apply

Destroying the AS3 definitions

To remove the AS3-created configuration that you applied in the previous procedure, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your control machine.
  2. Enter the following command:

    terraform destroy -auto-approve
