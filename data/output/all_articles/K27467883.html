Known Issue

In rare circumstances, the monpd process may fail to automatically repair a table.

This issue occurs when the following condition is met:

  • A sporadic error occurs on the MySQL table and corrupts the table.
When the system detects that a table is corrupted, the monpd process is designed to automatically repair the table.

Impact

Attempts to generate some reports from the Configuration utility or the Traffic Management Shell (tmsh) may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot generate reports from the Configuration utility or the tmsh utility.
  • In the /var/log/ltm file, you observe an error message similar to the following example:

    errno[126] strerror[Incorrect key file for table './logdb/log_data_current.MYI'; try to repair it]
  • In the /var/log/avr/monpd file, you observe an error message similar to the following example:

    [DB::mysql_query_safe, query failed] Error (error number 126) executing SQL string : <...some SQL statement...> Because : Incorrect key file for table './logdb/log_data_current.MYI'; try to repair it
