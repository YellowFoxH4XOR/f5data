In this video, AskF5 shows you how to monitor the login attempts on your BIG-IP system using the Configuration utility and the command line.

This demo uses BIG-IP 16.0.x.

  • 00:00 Intro
  • 00:09 Use the Configuration utility to view login attempts from the Audit List
  • 00:26 Use the Configuration utility to view login attempts from the Logins dashboard
  • 00:49 Use the command line to review current (unarchived) log files
  • 01:13 Use the command line to review archived log files

Important: The /var/log/audit file records successful and failed login attempts for the Configuration utility and successful login attempts for the command line, but it does not record failed login attempts for the command line. You can view the /var/log/audit file from the Configuration utility using the procedure detailed in this video. The /var/log/secure file records successful and failed attempts for both the Configuration utility and for the command line. You can only view /var/log/secure and /var/log/audit files from the command line.
