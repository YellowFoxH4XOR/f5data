Topic

When a BIG-IP Edge Client user attempts to establish an access session with a BIG-IP APM virtual server, the system may prompt them to install software updates, component updates, or both.

This occurs when the user's BIG-IP Edge Client software, EPSEC antivirus check image version, or components do not match the accessed BIG-IP APM version.

Description

Access session triggers for updates message

The following events or circumstances may trigger update messages:

  • The BIG-IP APM system uses an access policy that is different from the one used in the previous access session and requires different or additional components.
  • The BIG-IP APM access policy was modified and requires components in addition to those in the previous access session.
  • The destination BIG-IP APM system is running a different version of BIG-IP APM software than the BIG-IP APM system of the previous access session.
  • The installed APM Clients image of the destination BIG-IP APM system is an upgrade or downgrade from the one on the system of the previous access session.
  • The installed OPSWAT EPSEC antivirus check software image is an upgrade or downgrade from the one on the system of the previous access session.
  • The BIG-IP APM system to which the user is initiating an access session is running a different BIG-IP APM software version than the system of the previous access session.
  • The user initiates an access session to a BIG-IP APM system running different APM Clients or EPSEC antivirus check software versions.

Important: Except when initially installing BIG-IP Edge Client, users are only prompted for software component updates when the Connectivity profile for the access session is configured with Win/Mac Edge Client > Component Update set to yes.

Users may be repeatedly prompted to install component software when connecting to the same BIG-IP APM virtual server on which the configuration has a compatibility mismatch between the BIG-IP APM version and the Edge Client, EPSEC antivirus check software, or both. This may occur when incompatible individual software images (APM Clients or EPSEC antivirus check) are manually installed on the BIG-IP APM system.

Note: Beginning in BIG-IP 14.1.0, you cannot install EPSEC packages older than the pre-installed version. For more information on BIG-IP APM compatible component software refer to: K13757: BIG-IP Edge Client version matrix

Before installing the EPSEC antivirus check software image, verify the supported minimum BIG-IP APM versions by referring to the downloadable EPSEC readme_minimum_version.txt file.

For example:

The readme_minimum_version.txt for the epsec-1.0.0-936.0 indicates the following minimum versions:

Minimum BIG-IP and APM Clients versions for epsec1.0.0 build 936.0 and above.
One of the following versions of BIG-IP are required to install this epsec binary:

BIG-IP 16.0.0 or later
BIG-IP 15.1.0.2 or later
BIG-IP 15.0.1 or later and APM Clients 7.1.8.3 or later
BIG-IP 14.1.2 or later and APM Clients 7.1.8.3 or later
BIG-IP 13.1.3 or later and APM Clients 7.1.8.3 or later
BIG-IP 12.1.5.1 or later
BIG-IP 11.6.5.2 or later

Note: The latest download of the OPSWAT EPSEC file is located in the base version for your BIG-IP APM software version directory. For example, if your BIG-IP software version is 16.0.1, the most recent version of EPSEC is located in the Downloads section for BIG-IP release 16.0.0.

Recommendations

Ensure that you review the BIG-IP Edge Client version matrix and the readme_minimum_versions.txt file for the OPSWAT EPSEC image that you plan to install for BIG-IP APM software compatibility prior to installation.
