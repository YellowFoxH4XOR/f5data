K31216330: Single ASM log message has been splited into multiple lines in remote syslog server

Type
Support Solution
Published
2022-10-16
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP ASM: 16.1.3
Source
https://my.f5.com/manage/s/article/K31216330

Description
The remote syslog showing that single ASM log message has been splited into multiple lines.
ASM remote logging profile has been configured to include violation_details in storage format.

Environment

  • ASM
  • Remote syslog

Cause
CRLF in request data sent in violation_details of asm remote logging is not subject to do format escaping.
Currently this is tracked as ID1174001.

Recommended Actions

None at this time.

Additional Information
None
