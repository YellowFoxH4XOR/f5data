Description
MRF diameter terminates peer connection if when Result-Code or Experimental-Result-Code AVP value is empty or the AVP is missing in response.

DIAMETER: serverside flow (10.247.47.38:3868 -> 10.247.47.35:63899) aborted, (Failed to get result code, cmd_code:318, hop_id:785547182, ete_id:2764428047), error: Not found

Environment

  • MRF
  • DIAMETER

Cause

  • In this example, Result-Code or Experimental-Result-Code AVP is missing in AIA message
