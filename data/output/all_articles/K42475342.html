Known Issue

The BIG-IP ASM system may fail to provide learning suggestions for certain cookies.

This issue occurs when all of the following conditions are met:

  • You use manual learning to build the security policy.
  • The web server sends explicit, unmodified cookies.

Impact

The BIG-IP ASM system fails to provide learning suggestions for adding enforced cookies to the security policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Learning suggestions are missing for traffic that should trigger such a suggestion.

Resolution

Workaround

To work around this issue, you can manually define the enforced cookies in the security policy, rather than relying on learning suggestions.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system
