K03990224: Using f5_modules Collections and Ansible Roles

Type

Published

Source

Description

When using Ansible 2.9.6 and Roles, collections must be defined in the role, not the playbook.

Environment

  • Ansible 2.9
  • Ansible Roles
  • f5_modules Collections

Cause

This is by design. If an Ansible role is in use, any collections defined in the playbook will be ignored.

Recommended Actions

Define collections: in <role>/meta/main.yml.

---
collections:
  - f5networks.f5_modules

    Additional Information

    Collections seem to be going away with Ansible version 2.10 and later.
