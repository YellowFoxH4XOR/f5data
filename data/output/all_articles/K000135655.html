K000135655: Change VLAN name F5OS-A / rSeries

Description

Changing the name of an existing VLAN in F5OS-A does not overwrite in the Tenant.

 

Environment

F5OS-A

 

Cause

If we want to rename an existing VLAN, we must first remove it from F5OS-A and Tenant. Otherwise, when we rename an existing VLAN in F5OS-A, the new VLAN name will not be overwritten in Tenant.
 

Recommended Action
 

1. Login to the F5OS webGUI, go to TENANT MANAGEMENT => TENANT DEPLOYMENT and select the appropriate "tenant".
2. In VLANs, deselect the VLAN with the incorrect name, then Save and close.
3. Go to NETWORK SETTINGS => VLANs and remove the VLAN with the incorrect name.
4. Log in to the Tenant, go to NETWORK => VLANs => VLAN List and delete the Vlan with the incorrect name.
5. Back to the F5OS webGUI, go to NETWORK SETTINGS => VLANs and add the VLAN with the corrected name.
6. Go to TENANT MANAGEMENT => => TENANT DEPLOYMENT => select the appropriate "tenant" and select the newly created Vlan (with the corrected name), then Save and close.
7. Back to Tenant (log again or refresh) and go to NETWORK => VLANs => VLAN List, the newly created Vlan with the corrected name should be visible.
