Description

When accessing F5OS appliance GUI using FQDN (hostname) in the web browser, the management IP section in GUI might show hostname instead of IP address
 

Environment

  • F5OS device (rSeries or VELOS)
  • GUI

Cause

ID 1294581

Recommended actions

Software bug ID 1294581 will be fixed in a future F5OS release.
If you encounter this problem, check release notes if ID 1294581 is fixed.
