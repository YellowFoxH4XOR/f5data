Description

FTP Monitor is not working and marks the pool members down.

Enabled monitor logging following K12531, and observed messages similar to the following in the output file under /var/log/monitors/:

08:15:14.306768:(_Tcl /Common/ftp-mon): SIZE BIG-IP-ftp.txt
08:15:14.307576:(_Tcl /Common/ftp-mon): 550 Could not get file size.

FTP connection works when connecting through the virtual server or testing using curl.

Environment

  • FTP Monitor

Cause

The most common reason for this is that the file specified in the monitor's filename setting does not exist on the FTP server.

Recommended Actions

Confirm that the filepath provided in the FTP monitor configuration is correct. Be aware that the filepath you provide here is case sensitive.
