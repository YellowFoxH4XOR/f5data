Known Issue

The Configuration utility may display an erroneous warning banner after you upgrade your BIG-IP system.

This issue occurs when all of the following conditions are met:

  • You have configured your standalone device as part of a redundant high availability (HA) pair.
  • Your BIG-IP system runs on a version prior to 11.0.0.
  • You upgrade to one of the affected versions.

Impact

The Configuration utility displays an erroneous warning banner after a device upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you upgrade the device, the Configuration utility displays the following message:

    Upgrading Device Trust Device trust is still being upgraded. Please do not make modifications to Device Management or Traffic Groups pages while this message is displayed.

    Note: You can safely ignore this warning message when the upgraded device is a standalone configuration.

Resolution

Workaround

To work around this issue, you can configure the affected device to no longer be part of a HA pair. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Set the device as standalone by typing the following command:

    modify /sys db trust.configupdatedone value true

  3. Disable the device as part of a redundant pair by typing the following command:

    modify /sys db failover.isredundant value false

  4. Log in to the Configuration utility.
  5. Navigate to Device Management > Device Trust.
  6. Click Reset Device Trust.
  7. Leave Certificate Signing Authority at the default Retain Current Authority setting.
  8. Click Update.
