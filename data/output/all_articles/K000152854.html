Description

SSL Handshake failing between client and Virtual server when SSL certificate and key are installed on the DMZ partition, While the Virtual Server is created on common partition

Envoirnment

  • BIG-IP LTM
  • SSL profiles
  • Certificates

Cause

Due to the SSL certificate and key installed under DZM partition the SSL profile will not be selectable/usable for the VIP in the Common partition.

Recommended Actions

To avoid this issue, ensure that SSL certificate/key and the Virtual Server (and all related objects) reside in the same partition, or use the Common partition for shared resources.

Steps to move an SSL certificate and key from one partition to another on BIG-IP:

Impact: Performing the suggested steps should not have a negative impact on your system.

As it is not possible to "move" them directly between partitions. Instead, you must export the certificate and key from the current partition and then import them into the desired partition (such as /Common). Refer the below steps to perform the changes using the BIG-IP Configuration utility:

Step-by-Step: Export and Import SSL Certificate and Key:

Export the Certificate and Key (Create an Archive)

    1. Log in to the BIG-IP Configuration utility.
    2. Navigate to:
    3. System > Certificate Management > Traffic Certificate Management > SSL Certificate List
    4. Select the SSL certificate and key you want to move.
    5. Click Archive.
    6. Enter a unique name for the archive file.
    7. In the Key List, select the key and move it to the Keys to Archive box.
    8. In the Certificate List, select the certificate and move it to the Certificates to Archive box.
    9. Click Generate & Download Archive to download the archive file to your local system.

Import the Certificate and Key into the Target Partition

    1. In the BIG-IP Configuration utility, switch to the target partition (e.g., /Common).
    2. Go to:
    3. System > Certificate Management > Traffic Certificate Management > SSL Certificate List
    4. Click Import.
    5. For Import Type, select Archive.
    6. Click Choose File and select the archive file you downloaded earlier.
    7. Click Load, then Import to complete the process.

After performing the above steps the certificate and key will now be available in the target partition and can be used for SSL profiles and virtual servers in that partition.

You can verify that your SSL certificate and key have been successfully imported into the desired partition on BIG-IP, by following the below steps:

  1. On Configuration Utility (GUI) navigate to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  2. Ensure you are in the correct partition (e.g., /Common).
  3. Look for your certificate and key in the list. You should see the names you specified during import.
  4. Click on the certificate name to view its details (such as subject, issuer, and expiration date) and confirm it matches your expected certificate.
  5. (Optional) Click on the key name to verify its presence.
