K000135765: When using 301 Location to redirect, must use protocol

Type
Support Solution
Published
2023-08-07
Updated
2023-08-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000135765

Description

When redirecting user traffic to another URL with a 301 response using an iRule, you should specify the protocol.

Environment

  • BIG-IP
  • Virtual Server
  • iRule with 301 Location

 

Cause

If the protocol is not specified, the HTTP::Respond function interprets this as a URI rather than a full URL and an infinite respond loop might occur.

 Recommended Actions

For example:

when HTTP_REQUEST {
  if { ([string tolower [HTTP::host]] eq "www.example.com")} {
       HTTP::respond 301 Location "secure.example2.com"
       return
   }
}

 

 

will result in www.example.com/secure.example2.com/secure.example2.com/secure.example2.com/..... ad infinitum

Instead, you must use:

 

 

when HTTP_REQUEST {
  if { ([string tolower [HTTP::host]] eq "www.example.com")} {
       HTTP::respond 301 Location "http://secure.example2.com/"
       return
   }
}
