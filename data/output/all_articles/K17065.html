K17065: Considerations for configuring vCMP guests with Isolated Management Network mode in a device group

Topic

Summary

A Virtual Clustered Multiprocessing (vCMP) guest that is configured with Isolated Management Network mode requires a unique management IP address when included in a device group configuration.

Description

The management network of a vCMP guest can be configured in either of the following modes:

  • Bridged Management Network
  • Isolated Management Network

When you configure the management network of a vCMP guest, in Bridged Management Network mode on the vCMP host, you must provide a management IP address and subnet mask. The vCMP guest can then be reachable by using this management IP address via the vCMP host management interface.

When you configure the management network of a vCMP guest, in Isolated Management Network mode on the vCMP host, no management IP address is specified for the guest during configuration. The vCMP guest in a VIPRION cluster uses the default cluster IP address/management IP address (192.168.1.246) while the vCMP guest in an appliance uses the default management IP address (127.0.0.1). Additionally, when the management network is configured in Isolated Management Network mode, the vCMP guest is not reachable on its management interface.

The device service clustering (DSC) feature provides the framework for high-availability features, and requires each device in a device group to have a unique management IP address. This requirement may conflict with vCMP guests that are configured in Isolated Management Network mode. When you attempt to add two Isolated Management Network mode vCMP guests, with default management IP addresses to a device group, the peer discovery process fails and overwrites the local host name.

Additionally, if you have configured a unique management IP address on the individual vCMP guest, and successfully added them to a device group, the configured management IP address is not carried forward when these vCMP guests are upgraded to a later BIG-IP version. As a result, the DSC feature for these vCMP guests may not function properly.

Recommendations

To properly assign a unique management IP address, for each Isolated Management Network mode vCMP guest that you want to add to a device group, F5 recommends that you use the vCMP host. You must change the management network setting for each vCMP guest to Bridged Management Network mode temporarily, then enter the unique management IP address and save the changes before changing the management network setting back to Isolated Management Network mode. The management IP address will then be properly set on the vCMP guest, for DSC use, but it will not be accessible on the management interface. Depending on whether you are creating a new vCMP guest, or modifying an existing vCMP guest, perform either one of the following procedures:

  • Assigning a management IP address for a new Isolated Management Network mode vCMP guest
  • Assigning a management IP address for an existing Isolated Management Network mode vCMP guest

Assigning a management IP address for a new Isolated Management Network mode vCMP guest

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of the vCMP host that is hosting the affected vCMP guest.
  2. Click vCMP.
  3. Click Guest List.
  4. Click Create.
  5. From the Management Network list, select Bridged.
  6. For the Management Port IP Address setting, enter a unique IP address.
  7. For the Management Port Network Mask setting, enter the subnet mask.
  8. For the Requested State setting, select Configured.
  9. Select the appropriate options for the remaining settings.
  10. To create the vCMP guest, click Finish.

    The Guest List page displays.
  11. Select the name of the newly created vCMP guest.
  12. From the Management Network list, select Isolated.
  13. For the Requested State setting, select the appropriate option.

    For example, select Deployed if you want to start up the vCMP guest.
  14. To save the changes, click Update.

    The vCMP guest now has a unique management IP address that is required for DSC but not accessible on its management interface.

Assigning a management IP address for an existing Isolated Management Network mode vCMP guest

Impact of procedure: Changing the vCMP guest's management network setting momentarily brings up its management network, and the impact of this procedure depends on your management network environment. F5 recommends that you to perform this procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility of the vCMP host that is hosting the affected vCMP guest.
  2. Click vCMP.
  3. Click Guest List.
  4. Select the name of the affected vCMP guest.
  5. From the Management Network list, select Bridged.
  6. For the Management Port IP Address setting, enter a unique IP address.
  7. For the Management Port Network Mask setting, enter a subnet mask.
  8. To save the changes, click Update.

    The Guest List page displays.
  9. Select the affected vCMP guest again.
  10. From the Management Network list, select Isolated.
  11. To save the changes, click Update.

    The vCMP guest now has a unique management IP address that is required for DSC but not accessible on its management interface.
