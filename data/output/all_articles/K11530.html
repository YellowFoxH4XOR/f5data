Topic

FirePass allows you to set up temporary access using SSH to enable F5 Technical Support engineers to access your device for troubleshooting purposes.

To allow remote access using SSH, supply the following information:

  • The IP address of the FirePass device
  • Instructions to access your network
  • The Maintenance SSH Access passphrase

The passphrase is an encrypted key that only F5 Technical Support engineers can decode to obtain the current SSH key active on your FirePass device.

Important: Ensure that that your network is configured to allow the support engineer access to the FirePass device on TCP port 22.

Important: This key is only valid for 12 to 24 hours. If that timeframe has elapsed, you will need to repeat the procedure.

To retrieve the SSH passphrase for you FirePass device, perform the following procedure:

  1. Click Device Management in the navigation pane.
  2. Expand the Security menu.
  3. Click Console Access Security.
  4. Ensure that the Disable Maintenance SSH Access check box is clear.
  5. If the Disable Maintenance SSH Access check box was clear, skip to Step 10.
  6. Expand the Maintenance menu.
  7. Click the Restart Services menu.
  8. In the right pane, click Restart Controller.
  9. Repeat this procedure from Step 1.
  10. In the Maintenance SSH Access section, copy the text under the Passphrase to the current SSH key (valid for 12-24 hours): heading, and send the text to the F5 Technical Support engineer.
