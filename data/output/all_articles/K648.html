K648: Configuring BIG-IP or 3-DNS to send mail to a specific node rather than the domain mail server

Topic

When BIG-IP sends email, like a warning from a system utility such as syslog, it typically determines the email destinations by performing a DNS lookup on the domain name of the email address. In most cases, this causes email to be sent to a company's primary email server address.

If you would rather have email sent directly to servers configured as nodes for a virtual server behind BIG-IP, modify the /etc/hosts file so that the domain mail server's name (a DNS MX record) points to the IP address of the node to which you want the email delivered.

Example configuration

You are sending mail to recipient@xyz.com and the mail server for xyz.com is a node behind BIG-IP and DNS resolves the mail server name to a virtual server address. You prefer that email from the BIG-IP is sent straight to the node instead. Change it by performing the following steps:

  1. Look for the following information in the /etc/irs.conf file to verify that BIG-IP is configured to use the /etc/hosts file before it looks to DNS for resolution.
    #hosts nis continue 
hosts local continue 
hosts dns
  2. Use nslookup to view the MX records for the desired domain.

     

    #nslookup 
>set que=mx 
>xyz.com

    The nslookup utility will return results similar to the following:

    xyz.com preference = 10, mail exchanger = mail2.xyz.com 
xyz.com preference = 9, mail exchanger = mail1.xyz.com
  3. Modify the /etc/hosts file as follows to reflect the desired node address of the mail server:
    192.168.1.10 mail1.xyz.com 
192.168.1.11 mail2.xyz.com

BIG-IP will now resolve the host names mail1.xyz.com and mail2.xyz.com to the node addresses instead of using the "real" DNS entries. BIG-IP will then send email to the server address listed in /etc/hosts, rather than the address listed as the mail exchanger in DNS.

Now, when the BIG-IP Controller sends mail to recipient@xyz.com, the mail is send it to the node address, and external users sending mail to xyz.com will still send mail to the virtual server address.
