Issue

Error Message

info <proc>[<PID>]: 0114002c:6: HA <feature> <key> disabled.

In this error message, note the following:

  • <proc> is the daemon associated with the specific high availability (HA) feature.
  • <PID> is the process ID for the daemon process.
  • <feature> is the name of the HA feature.
  • <key> is the name of the component that reports its status in the HA table.

For example:

info sod[8484]: 0114002c:6: HA daemon_heartbeat sod disabled.
info bigd[8888]: 0114002c:6: HA daemon_heartbeat bigd disabled.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The system fail-safe feature is disabled for an HA table entry as part of the daemon stop sequence.

This message most commonly occurs during a reboot of the BIG-IP system or a restart of a system daemon.

Impact

The HA status feature for the associated component is suspended.

Recommended Actions

After a system reboot or service restart, you can use the tmsh show /sys ha-status command to review and verify the current status of the HA feature.
