Issue

Error Message

notice mcpd[<PID>]: 01070727:5: Pool <pool_name> member <member_name>:<port> monitor status up.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <pool_name> is the partition and name of the pool
  • <member_name> is the partition and node name of the pool member
  • <port> is the port number used by the pool member

For example:

notice mcpd[5057]: 01070727:5: Pool /Common/pool_http member /Common/10.10.10.10:80 monitor status up.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all the following conditions are met:

  • You configure a health monitor to check the availability of a pool member.
  • The BIG-IP system detects a change in the availability status for the pool member and marks the pool member up.

Impact

This message is informational and indicates the pool member is available to receive new connections.

Recommended Actions

None
