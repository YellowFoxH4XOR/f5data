Known Issue

This is the result of a known issue. On the Application Access: Terminal Servers: Global Settings page in the FirePass Administrative Console, the default value of the URL field for the Citrix website is an obsolete link to the Citrix website.

For example:

http://download2.citrix.com/files/en/products/CPSICAClient10200/icaweb.cab

As a result, when you select the Citrix website option without modifying the associated URL, users who do not already have the Citrix ICA client installed cannot connect to Citrix Terminal Server favorites.

F5 Product Development is tracking this issue as CR133393 and it is fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by entering a valid URL for the Citrix ICA client installer in the URL field.

Note: To determine the correct URL for your environment, refer to the Citrix website.

Alternately, you can work around this issue by selecting the FirePass controller option and uploading the Citrix ICA client to the FirePass controller.

Note: For instructions about configuring these options, refer to K5891: Downloading and installing the Citrix client.
