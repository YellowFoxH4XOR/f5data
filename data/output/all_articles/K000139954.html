K000139954: Is there EUD for rSeries and VELOS platforms?

Type
Support Solution
Published
2024-06-07
Updated
2025-01-17
Source
https://my.f5.com/manage/s/article/K000139954

Description

For troubleshooting a potential hardware related problem, EUD is available to run a set of diagnostic tests on F5 physical platforms; however, there is no EUD available for the new F5OS platforms.

The new F5OS provides much better hardware diagnostics compared to the old existing platforms, and there is no more need to run EUD as all system components can be viewed from the GUI or CLI.

Environment

  • rSeries appliance platforms
  • F5 VELOS chassis platforms
     

Cause

N/A
 

Recommended Actions

Review system hardware components and its health from the GUI, CLI via F5 iHealth utility by uploading a qkview.

You can also open a support case with F5 Support for any assistance checking the system health.
