K000138211: Restjavad frequently restarts when there are many device discovery tasks

Type
Support Solution
Published
2024-01-12
Updated
2024-01-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000138211

Description

Restjavad frequently restarts, and messages similar to the following are observed in /var/log/restjavad.0.log

 

[SEVERE][1753][01 < Date > UTC][DieOnUncaughtErrorHandler] Restjavad exiting immediately due to an uncaught Error

[SEVERE][1754][01 < Date > UTC][DieOnUncaughtErrorHandler] Restjavad exiting immediately due to an uncaught Error

[SEVERE][1755][01 < Date > UTC][DieOnUncaughtErrorHandler] Uncaught Error causing restjavad to exit. Thread id 102, 'com.f5.rest.workers.storage.ThreadPoolStorageRequestProcessor_77': java.lang.OutOfMemoryError: Java heap space

 

Environment

  • BIG-IP
  • High Availability

 

Cause

Bug ID 1252389: The restjavad restarted per 30 seconds due to OOM with many device discovery tasks

 

 

Recommended Actions

1. Run the command clear-rest-storage.
2. Verify restjavad restarted bigstart status restjavad.

 

Additional Information

None
