Known Issue

This is the result of a known issue. If you configure the Windows antivirus checker in a pre-logon sequence and enable the Perform process scan option, users running Symantec AntiVirus 10.x may intermittently experience lengthy scan times even if you set Scan type to Quick. This issue occurs after installing OPSWAT SDK 2.5.2.1 or later on the FirePass controller.

F5 Networks Product Development tracked this issue as CR115678 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in hotfix-119205 OPSWAT 2.5.18. You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Networks Downloads site.

Workaround

As a temporary workaround, the user may remove the log files from the Symantec log directory.

Note: The Symantec log directory is typically located in C:\Documents And Settings\All Users\Application Dtata\Symantec\Symantec Corporate Edition\7.5\Log. However, you must reference your Symantec documentation to confirm the path for your individual clients.

Alternatively, you can remove the effected OPSWAT SDK from the FirePass controller. For instructions about removing a hotfix, refer to K3430: Installing FirePass hotfixes.

Note: Builds before 2.5.2.1 had stability issues with a user interface appearing before the scan would start, and required an additional utility be deployed.
