Known Issue

The Traffic Management Microkernel (TMM) restarts due to memory leaking while processing Secure Sockets Layer (SSL) forward proxy traffic.

This issue occurs when the following condition is met:

  • SSL forward proxy is enabled.

Impact

Traffic is disrupted or a failover event occurs while TMM restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SSL forward proxy can leak memory while forging the server certificate. TMM may eventually halt and restart when available memory is exhausted.
