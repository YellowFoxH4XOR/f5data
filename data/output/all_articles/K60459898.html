Known Issue

The BIG-IP APM system may fail to provide access to multiple domains on multiple browser tabs.

This issue occurs when all of the following conditions are met:

  • The access policy is configured for multi-domain single sign-on (SSO).
  • An unauthenticated user opens multiple web browser tabs, simultaneously, to different protected domains.

Impact

The user cannot establish a new session until the running session has expired or the web browser is restarted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users receive an error message similar to one of the following examples:

    • Your session could not be established. Invalid Session ID.
    • Your session may have expired.
    • Access policy evaluation is already in progress.
  • In the /var/log/apm file, you observe an error message similar to the following example:

    err tmm3[<PID>]: 01490514:3: 00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access.c, Function: access_multidomain_sso_decode_redirect_uri, Line: 11737
    err tmm3[<PID>]: 01490514:3: 00000000: Access encountered error: ERR_ARG. File: ../modules/hudfilter/access/access.c, Function: access_check_uri_type, Line: 10563
