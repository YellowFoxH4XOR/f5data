Known Issue

This is the result of a known issue. When you log in to the FirePass Administrative Console using Microsoft Internet Explorer 7 (IE7) and attempt to download a log file from the Reports : HTTP Logs page, IE7 reports an error message that appears similar to the following example in a pop-up window:

Internet Explorer cannot download <log file name> from
<FirePass Hostname or IP Address>.
Internet Explorer was not able to open this Internet Site.
The requested site is either unavailable or
cannot be found. Please try again later.

Note: For more information about FirePass support for IE7, refer to K6740: Support for Internet Explorer 7.

F5 FirePass Development tracked this issue as CR71465 for the FirePass 6.0.0 software branch, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-552-6 has been issued for FirePass version 5.5.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
