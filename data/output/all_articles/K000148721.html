Description

This article shows the example for assigning USER ROLE attributes on RADIUS external authentication (admin role).

Environment

  • F5OS-A (v1.5.x and later).
  • RADIUS authentication.
  • USER attributes settings on NPS (Network Policy Server).

Cause

N/A.

Recommended Actions

 1. All default settings in F5OS Users & Roles.

2. There are the settings which we put in NPS (Network Policy Server).

We mapped all fields with the following values (admin role).
    F5-F5OS-UID (21) -> 1001
    F5-F5OS-GID (22) -> 9000
    F5-F5OS-HOMEDIR (23) -> /tmp
    F5-F5OS-SHELL (24) -> /var/lib/controller/f5_confd_cli
    F5-F5OS-USERINFO (25) -> admin

For F5 VSA (Vendor-Specific Attributes), please refer to "K14324: Using F5 vendor-specific attributes with RADIUS authentication".

    VENDOR f5 3375
    BEGIN-VENDOR f5

    # F5OS vendor-specific-attributes
    ATTRIBUTE F5-F5OS-UID 21 integer
    ATTRIBUTE F5-F5OS-GID 22 integer
    ATTRIBUTE F5-F5OS-HOMEDIR 23 string
    ATTRIBUTE F5-F5OS-SHELL 24 string
    ATTRIBUTE F5-F5OS-USERINFO 25 string

    # F5OS default group IDs
    VALUE F5-F5OS-GID admin 9000
    VALUE F5-F5OS-GID operator 9001
    VALUE F5-F5OS-GID resource-admin 9003
    VALUE F5-F5OS-GID tenant-console 9100
    VALUE F5-F5OS-GID superuser 9004
    VALUE F5-F5OS-GID user 9002

3. For the connectivity setup between F5OS-A and the RADIUS Authentication server and other related settings, please refer to "Manual Chapter : User Management".
