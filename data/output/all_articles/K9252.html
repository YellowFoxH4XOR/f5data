Known Issue

This is the result of a known issue. If the Minimize window after successfully connecting Network Access client and the Use Tray icon instead of Taskbar entry when minimized check boxes are selected on the Network Access Customization page (Network Access: Resources: Customization), the Network Access pop-up window under Internet Explorer minimizes and becomes hidden in the task bar. Under Firefox, the Network Access pop-up window minimizes, but it is still visible in the task bar. This issue first appeared in cumulative hotfix HF-602-2.

F5 Product Development tracked this issue as CR101258, and it was fixed in cumulative hotfix HF-602-5 for FirePass version 6.0.2. You may download the cumulative hotfix from the F5 Downloads site.

This issue does not affect FirePass version 6.0.3.
