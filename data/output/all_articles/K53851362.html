Description

The BIG-IP connection table contains information about all the sessions that are currently established on BIG-IP system. You can display and delete the contents of the BIG-IP connection table from the command line using the tmsh connection command.

Environment

  • Connection Table 
  • Virtual server
  • Pool Member/Server  

Cause
None

Recommended Actions

To view the connection table, you may mix/match these options as necessary to isolate the connections you are interested in.
You can narrow the connection table information by specifying the filters of the endpoints listed below. 
 

FilterDescription 
cs-client-addrThe (client) source IP address on the clientside of the connection. Subnets are allowed by specifying an optional prefix length up to /24 and /56 for IPv4 and IPv6 respectively.
cs-client-portThe (client) source port on the clientside of the connection
cs-server-addr The (server) destination IP address on the clientside of the connection (i.e. the Virtual Server IP address). Subnets are allowed by specifying an optional prefix length up to /24 and /56 for IPv4 and IPv6 respectively.
cs-server-port The (server) destination port on the clientside of the connection (i.e. the Virtual Server port)
ss-client-addrThe (client) source IP address on the serverside of the connection (i.e. the SNAT address)
ss-client-portThe (client) source port on the serverside of the connection (i.e. the SNAT port)
ss-server-addrThe (server) destination IP address on the serverside of the connection (i.e., the Pool Member address)
ss-server-portThe (server) destination port on the serverside of the connection (i.e., the Pool Member port)

 

The following examples show a number of options that you can use to display or delete only those connection entries that correspond to specific IP address or port value.

Important:  On systems with a large number of connections, executing the following commands with a large output may result in excessive output causing device instability.  It is recommended you limit the output to specific IP address and/or port combination as demonstrated in the examples below.

  • Display Connection Table Entries
  • Delete Connection Table Entries


Display Connection Table Entries: 

  1. To display the BIG-IP connection table entries for a particular virtual server, use the following tmsh command syntax:

    tmsh show /sys connection cs-server-addr <vs_ip> cs-server-port <vs_port>     

    For example, to display the BIG-IP connection table entries for 10.10.2.2:443 virtual server, you would type the following command:

    tmsh show /sys connection cs-server-addr 10.10.2.2 cs-server-port 443

  2. To display the BIG-IP connection table entries for a range of virtual server addresses, use the following tmsh command syntax:

    tmsh show /sys connection cs-server-addr <vs_network_addr>/<prefix>    

    For example, to display the BIG-IP connection table entries for virtual servers in the 203.0.113.0/27 network, you would type the following command:

    tmsh show /sys connection cs-server-addr 203.0.113.0/27

  3. To display the BIG-IP connection table entries for a particular client IP address, use the following tmsh command syntax:

    tmsh show /sys connection cs-client-addr <client_ip>

    For example, to display the BIG-IP connection table entries for 10.10.20.2 client IP address, you would type the following command:

    tmsh show /sys connection cs-client-addr 10.10.20.2

  4. To display the BIG-IP connection table entries for a range of client IP address, use the following tmsh command syntax:

    tmsh show /sys connection cs-client-addr <client_network_addr>/<prefix>

    For example, to display the BIG-IP connection table entries for client IP addresses in the 203.0.113.0/27 network, you would type the following command:

    tmsh show /sys connection cs-client-addr 203.0.113.0/27 network

  5. To display the BIG-IP connection table entries for a particular pool member, use the following tmsh command syntax:

    tmsh show /sys connection ss-server-addr <pool_member_ip> ss-server-port <pool_member_port>

    For example, to display the BIG-IP connection table entries for 192.168.10.2:80 pool member, you would type the following command:

    tmsh show /sys connection ss-server-addr 192.168.10.2 ss-server-port 80

  6. To display additional information about particular connection such as Idle timeout, number of packets sent etc, use the following tmsh command syntax:

    tmsh show /sys connection cs-client-addr <client_ip> cs-client-port <client_port> cs-server-addr <vs_ip> cs-server-port <vs_port> all-properties

    For example, to display specific details of connection established between 10.10.20.2:51435 (client) and 10.10.2.2:443 (virtual server), you would type the following command:

    tmsh show /sys connection cs-client-addr 10.10.20.2 cs-client-port 51435 cs-server-addr 10.10.2.2 cs-server-port 443 all-properties


Delete the connection table entries:

  1. To delete the BIG-IP connection table entries for a particular client IP and virtual server, use the following tmsh command syntax:

    tmsh delete /sys connection cs-client-addr <client_ip> cs-server-addr <vs_ip> cs-server-port <vs_port>

    For example, to delete the BIG-IP connection table entries for 10.10.20.2 client IP address and 10.10.2.2:443 virtual server, you would type the following command:

    tmsh delete /sys connection cs-client-addr 10.10.20.2 cs-server-addr 10.10.2.2 cs-server-port 443

  2. To delete the BIG-IP connection table entries for a range of client IP addresses, use the following tmsh command syntax:

    tmsh delete /sys connection cs-client-addr <client_network_addr>/<prefix>

    For example, to delete the BIG-IP connection table entries for the 203.0.113.0/27 network, you would type the following command:

    tmsh delete /sys connection cs-client-addr 203.0.113.0/27

Additional Information

Here is an example of tmsh show sys connection output:

tmsh show sys connection cs-client-addr 10.10.10.77
Sys::Connections
10.10.10.77:55130  10.10.10.69:22  10.10.10.60:55130  10.10.10.71:22  tcp  241  (tmm: 1)  none  none
Total records returned: 1

In this example, 

10.10.10.77:55130 - client IP and source port
10.10.10.69:22 -  virtual server address and configured port
10.10.10.60:55130 - SNAT/Self IP and port used for forwarding connection to the pool member/backend server
10.10.10.71:22 - pool member IP and configured port
tcp - protocol for this connection 
241 (seconds) - has been idled since the client connection has established
(tmm: 1) - TMM 1 has processed this traffic
(the first) none - ePVA Acceleration status
(the second) none - Neuron Rules status
Note: Neuron Rules status will be only appearing on certain platforms that provide FIX protocol acceleration and anti-DDoS security feature, such as BIG-IP iSeries platform.
Idle Time - Idle time since the client connection was established.
Idle Timeout - Protocol profiles have an idle timeout setting which specifies the number of seconds that a connection is idle before it is eligible for deletion.
Lasthop - The MAC destination for packets going back to the client.
Server Nexthop - The MAC destination for packets going from the BIG-IP system to the server.
Ingress Dest - The MAC address of the destination at the client side.
Virtual Path - The virtual server IP address and port
Conn Id - The TMM ID of the connection
