Security Advisory Description

Multiple TCP/IP and ICMP implementations, when using Path MTU (PMTU) discovery (PMTUD), allow remote attackers to cause a denial of service (network throughput reduction for TCP connections) via forged ICMP ("Fragmentation Needed and Don't Fragment was Set") packets with a low next-hop MTU value, aka the "Path MTU discovery attack." (CVE-2004-1060)

Impact

The BIG-IP system may be vulnerable to denial-of-service (DoS) attacks.

Security Advisory Status

F5 Product Development has assigned ID 485917 (BIG-IP), ID 486623 (Enterprise Manager), and ID 486622 (BIG-IQ) to this vulnerability, and has evaluated the currently supported releases for potential vulnerability. Additionally, BIG-IP iHealth may list Heuristic H488350 on the Diagnostics > Identified > High screen.
