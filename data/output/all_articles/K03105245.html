Description
We would like to create a CNAME for another existing CNAME record on the F5. Is this allowed?

Environment

  • DNS

Cause
It is not a preferred configuration, but it is possible.

Recommended Actions

You can configure this under Zonerunner (DNS >> Zones >> Zonerunner in the GUI).

Example of a lookup where six CNAMEs are configured for the record: 
  # dig @172.16.125.131 A test.f5example.dom
  ...
  ;; QUESTION SECTION:
  ;test.f5example.dom.        IN    A
  ;; ANSWER SECTION:
  ;; ANSWER SECTION:
  test.f5example.dom.          99    IN    CNAME    cname.f5example.dom.
  cname.f5example.dom.         99    IN    CNAME    originalname.f5example.dom.
  originalname.f5example.dom.  99    IN    CNAME    another_cname.f5example.dom.
  another_cname.f5example.dom. 99    IN    CNAME    cname4.f5example.dom.
  cname4.f5example.dom.        99    IN    CNAME    cname5.f5example.dom.
  cname5.f5example.dom.        99    IN    CNAME    my_last_cname.f5example.dom.
  my_last_cname.f5example.dom. 99    IN    A    10.10.10.11
There does not appear to be a limitation on the number of CNAMEs that can be used. However, it should be stressed that a CNAME-to-CNAME referral is not considered best practice and should be avoided if possible.
