K000139007: Managing the SSL ciphers allowed by the VELOS or rSeries system webUI

Topic

You should consider using this procedure under the following condition:

  • You want to list the SSL ciphers allowed when accessing the VELOS or rSeries system webUI.
  • You want to change the SSL ciphers allowed when accessing the VELOS or rSeries system webUI.

Description

Starting in F5OS-C 1.6.0 and F5OS-A 1.4.0, you can display and configure the SSL ciphers used for the VELOS and rSeries system webUI respectively. This affects only the control plane traffic via the webUI interface and does not apply to data plane traffic. You can list the SSL ciphers configured and change them to meet your requirements if needed.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have administrative access to the management interface (webUI/CLI/REST API) of the VELOS or rSeries system.
  • If you intend to use the REST API procedures, you should have a workstation with curl and jq utilities installed. If you do not have one, you can login to the VELOS chassis or the rSeries command line as the root user to use the curl and jq utilities as needed.

Procedures

  • Using the webUI
  • Using the CLI
  • Using the REST API

Using the webUI

You can use the webUI to perform the following procedure to display and configure the SSL ciphers used for the VELOS chassis and partition webUI as well as the rSeries system webUI.

Impact of procedure: Performing the following procedures will result in the restart of the webUI service; as a result, the webUI and REST API will be momentarily unavailable.

  1. Log in to the webUI as the admin user.
  2. Navigate to SYSTEM SETTINGS > System Security.
  3. The list of supported cipher suites currently in used by the webUI is presented in the httpd Cipher Suites setting under Services section. Add or remove the cipher suites as needed, separating each cipher with a colon (:).
  4. Select Save to save the changes.
  5. The system then prompts you to confirm if you want to make the change. Select OK to confirm. The process will restart the webUI service and the webUI will be momentarily unavailable.

Using the CLI

You can use the CLI to perform the following procedure to display and configure the SSL ciphers used for the VELOS chassis and partition webUI as well as the rSeries system webUI.

Impact of procedure: Performing the following procedures will result in the restart of the webUI service; as a result, the webUI and REST API will be momentarily unavailable.

  1. Log in to the CLI as the admin user.
  2. To display the list of supported cipher suites currently in used by the webUI, enter the following command:

    show system security services service httpd

    The command returns an output similar to the following example:

  3. To modify the cipher suites list, you must first enter the configuration mode by entering the following command:

    config

    Then enter the following command syntax:

    system security services service httpd config ssl-ciphersuite <the replacement SSL cipher suites list>

    For example,

    system security services service httpd config ssl-ciphersuite ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256

  4. To save the change, enter the following command:

    commit and-quit

    The system then prompts you to confirm if you want to proceed with committing the change as the process will restart the webUI service and the webUI will be momentarily unavailable.

    The following warnings were generated:
      'system security services service httpd config ssl-ciphersuite': Configuring HTTP ciphersuite will restart the HTTP service.
    Proceed? [yes,no]

    To proceed, enter yes.

  5. To verify the change, enter the following command:

    show system security services service httpd

Using the REST API

You can use the REST API to perform the following procedure to display and configure the SSL ciphers used for the VELOS chassis and partition webUI as well as the rSeries system webUI.

Impact of procedure: Performing the following procedures will result in the restart of the webUI service; as a result, the webUI and REST API will be momentarily unavailable.

  1. Login to a workstation with curl and jq utilities installed. Alternatively, you can login to the VELOS chassis or the rSeries command line as the root user.
  2. To determine the list of cipher suites currently in used by the webUI, enter the following command syntax:

    curl -sku <admin user>:<admin password> -H "Content-Type: application/yang-data+json" -X GET "https://<management IP address of the VELOS chassis/partition or the rSeries system>/api/data/openconfig-system:system/f5-security-ciphers:security/services/service=httpd"

    For example,

    curl -sku admin:admin -H "Content-Type: application/yang-data+json" -X GET "https://192.168.78.7/api/data/openconfig-system:system/f5-security-ciphers:security/services/service=httpd"

Important: The default cipher suites (for non-FIPS licensed platforms) might not match your security requirements, this list should be reviewed in a per case basis and modified to match your compatibility and security requirements. IETF TLS Working Group is actively working to obsolete non-ephemeral and/or non-elliptic cipher suites. More information can be found on RFC 9325: Recommendations for Secure Use of Transport Layer Security (TLS) and Datagram Transport Layer Security (DTLS) and IETF new draft-ietf-tls-deprecate-obsolete-kex: Deprecating Obsolete Key Exchange Methods in (D)TLS 1.2 (not yet approved). When a non-ephemeral and non-elliptic cipher suites are not required for compatibility reasons, an easy and secure starting point could be to create a string list of cipher suites that only includes ECDHE-*. FIPS licensed platforms make use of ECDHE-only secure cipher suites for TLSv1.2
