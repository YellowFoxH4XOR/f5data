K62545036: Comparing BIG-IP SSH key files

Type
Support Solution
Published
2021-03-24
Updated
2025-04-01
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K62545036

Description

The procedure is useful to verify if SSH key files - private or public key - are unique between BIG-IP devices.

Environment

  • BIG-IP SSH key files
  • BIG-IP Device with SSH access enabled
  • SSH client

Cause

None. 

Recommended Actions

Compare BIG-IP SSH key files between BIG-IP devices

Impact of procedure: Secure access to SSH client and BIG-IP device while doing these procedures as SSH key file information is being reviewed.

1. Log in to BIG-IP device using SSH from a SSH client

ssh root@<Management IP of BIG-IP device>

2. Locate the SSH key file to be compared

The /root/.ssh directory under the root user account contains the SSH private key named "identity". The BIG-IP SSH private key file is in PEM format while the public key is in OpenSSH format.

The authorized_keys file is used to store SSH public keys. In the BIG-IP .ssh directory, this file is owned by the "root" user and users with Administrator role privilege.

Note: Please ensure only trusted users are provided with Administrator role (or any role) privilege for the management of the BIG-IP devices.

[root@bigip:Active:Standalone] ~ # pwd
/root

[root@bigip:Active:Standalone] ~ # ls -la .ssh/
total 10
drwxr-xr-x. 2 root root 1024 2021-01-29 11:22 .
dr-x------. 3 root root 1024 2021-03-17 00:35 ..
lrwxrwxrwx. 1 root root   29 2021-01-29 11:22 authorized_keys -> /var/ssh/root/authorized_keys
lrwxrwxrwx. 1 root root   22 2021-01-29 11:22 identity -> /var/ssh/root/identity
lrwxrwxrwx. 1 root root   26 2021-01-29 11:22 identity.pub -> /var/ssh/root/identity.pub
lrwxrwxrwx. 1 root root   25 2021-01-29 11:22 known_hosts -> /var/ssh/root/known_hosts
-rw-r--r--. 1 root root  262 2021-01-29 01:22 README

3. Run commands to verify SSH key file information

a. The ssh-keygen -l -f <BIG-IP SSH private or public key file> command can be used to verify the SSH private key information with regards to its pair public key file. the "-l" option will "Show fingerprint of specified public key file." It can also be used to verify the SSH public key file information.

If the SSH private and public key file have the same fingerprint information, these files are SSH key pairs.

Sample output of BIG-IP SSH private and public key pair

[root@bigip:Active:Standalone] ~ # ssh-keygen -l -f /var/ssh/root/identity
2048 SHA256:xdhrvNWy3OHTfXLYY5E8mI/dKZVE4OZ8LZvCiXO1fg4 Host Processor Superuser (RSA)
[root@bigip:Active:Standalone] ~ # ssh-keygen -l -f /var/ssh/root/identity.pub
2048 SHA256:xdhrvNWy3OHTfXLYY5E8mI/dKZVE4OZ8LZvCiXO1fg4 Host Processor Superuser (RSA)

b. Generate sha256sum hash of BIG-IP SSH private key.  The sha256sum will have a unique hash output for each file and can be used to verify if the contents in the SSH key file is unique.

[root@bigip:Active:Standalone] ~ # sha256sum /var/ssh/root/identity
934a18594f50d4a6e30bd173da10f37c0df0ac8e583fa441e4cd4fb523a541bf  /var/ssh/root/identity

As a quick test, here is a sha256sum command hash output comparison from 2 different BIG-IP devices

i. sha256sum output for same input - example is the text "cat"

Device A:
[root@bigip:Active:Standalone] ~ # echo "cat" | sha256sum
175cc6f362b2f75acd08a373e000144fdb8d14a833d4b70fd743f16a7039103f  -

Device B:
[root@bigip2:Active:Standalone] ~ # echo "cat" | sha256sum
175cc6f362b2f75acd08a373e000144fdb8d14a833d4b70fd743f16a7039103f  -

ii. sha256sum output for different inputs - example is the  "/var/ssh/root/identity" SSH key file.
Note: The sha256 hash output will be unique for each file

Device A:
[root@bigip:Active:Standalone] ~ # sha256sum /var/ssh/root/identity
934a18594f50d4a6e30bd173da10f37c0df0ac8e583fa441e4cd4fb523a541bf  /var/ssh/root/identity

Device B:
[root@bigip2:Active:Standalone] ~ # sha256sum /var/ssh/root/identity
58b511d1885e24af877cbcbaee5d43af33ac87f450d9bf9a332fb4dc1eeab1af  /var/ssh/root/identity

 

4. Repeat step 1 to 3 on the other BIG-IP device where SSH key file needs to be verified/compared with.

5. Compare the SSH key file information output between the  BIG-IP devices

Save the SSH key file sha256sum output from each BIG-IP device and compare them by using the "diff" command. A "diff" output showing the difference between BIG-IP SSH key file sha256sum hashes verifies each of the files have unique content and therefore different SSH key files.  

The same procedure can also be used to compare the SSH private or public key fingerprint information from different BIG-IP to verify their uniqueness. 

Sample result where 2 sha256sum hashes are not the same. The comparison result indicates that the "/var/ssh/root/identity" from sample BIG-IP device A and B are not equal.

[root@bigip2:Active:Standalone] ~ # diff DeviceA-identity-sha256hash DeviceB-identity-sha256hash
1c1
< 934a18594f50d4a6e30bd173da10f37c0df0ac8e583fa441e4cd4fb523a541bf  /var/ssh/root/identity
---
> 58b511d1885e24af877cbcbaee5d43af33ac87f450d9bf9a332fb4dc1eeab1af  /var/ssh/root/identity   

Additional Information

Please take note of ID 653418: Host Processor Superuser keys in /root/.ssh/authorized_keys no longer necessary, a change in behavior where the Host Processor Superuser keys have been removed from /root/.ssh/authorized_keys. In case you notice that the keys are missing, know that this is intentional.

https://cdn.f5.com/product/bugtracker/ID653418.html. This "Host Processor Superuser keys" entry is benign.

See also K13454: Configuring SSH public key authentication on BIG-IP systems (11.x - 15.x) Prerequisites. The "root and admin are always authenticated as local accounts, you can always use public-key authentication for these users". Also, in the Description section, "For an SSH server to accept public key authentication, the SSH server configuration must allow this authentication method globally. The SSH server must also be pre-configured with information about the remote users who are allowed to authenticate using this method by adding the remote user's public key to the local user's authorized_keys file."


Per sample output of sha256sum hashes for /var/ssh/root/identity files from different BIG-IP devices, they have different hash output and each file content is unique. sha256sum hashes comparison between 2 files will only be the same if they have the same content.
