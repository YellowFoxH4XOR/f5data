Known Issue

This is the result of a known issue. When attempting to delete a Support Snapshot file in the Configuration utility, the deletion may fail and display the following error message:

An error has occurred while trying to process your request.

When a Support Snapshot file is created in the Configuration utility, a /mnt/support memory file system is mounted to store the Support Snapshot file. However, if the BIG-IP LTM is restarted or rebooted with the Support Snapshot file still in the /mnt/support memory file system, the /mnt/support memory file system is not properly dismounted.

F5 Networks tracked this issue as CR45899 it was fixed in BIG-IP versions 9.1.2 and 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If you are unable to upgrade at this time you can work around this issue by manually removing the Support Snapshot file.

Important: You can not be in the /mnt/support directory when you attempt to remove the Support Snapshot file system.

To manually remove the Support Snapshot file and unmount the /mnt/support memory file system, perform the following steps:

  1. Log in to the BIG-IP command line.
  2. Manually remove the Support Snapshot file by typing the following command:

    rm /mnt/support/support.tar.gz

  3. Manually unmount the /mnt/support memory file system by typing the following command:

    umount /mnt/support
