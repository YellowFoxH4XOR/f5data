Description

Would like to set up a hybrid configuration, serving ECDSA certificate first, with a fallback to RSA certificate for non-supporting clients.

Environment

  • SSL Certificates
  • SSL Handshakes

Cause

None

Recommended Actions

Associate both the RSA and ECDSA cert/key pair with your SSL profile. For more information, tefer to the Configuring the SSL profile to support multiple SSL certificate/key pair types section of K15062:

  • K15062: Associating multiple SSL certificate/key pair types with an SSL profile

Once configured, the choice of certificate presented comes down to the negotiated cipher suite in the SSL handshake during the client and server hello phase.

For example:

ECDHE-RSA-AES256-GCM-SHA384
       ^____ RSA cert/key pair will be used

ECDHE-ECDSA-AES256-GCM-SHA384
       ^____ ECDSA cert/key pair will be used

A cipher string or cipher group should be configured which prefers ECDSA in the case where clients support both ECDSA and RSA.
