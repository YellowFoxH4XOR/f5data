K000163337: F5 Insight Standby Instance Displays an Expired License in a Disaster Recovery Deployment

Type
Support Solution
Published
2026-09-17
Updated
2026-09-17
Applies to
  • BIG-IP
  • F5 Insight: 1.2.2
Source
https://my.f5.com/manage/s/article/K000163337

Description

In an F5 Insight Disaster Recovery (DR) deployment, the active instance reports a valid license while the standby instance displays:

  • License Status: Expired
  • Expiration Date: December 31, 0

The DR pair remains operational.

Environment

  • Product: F5 Insight
  • Deployment: Disaster Recovery pair
  • Active instance: Licensed and operating as primary
  • Standby instance: Operating in standby/read-only mode

Cause

The standby instance operates in read-only DR mode and does not require an independent license activation. Its licensing screen displays Expired with the placeholder date December 31, 0.

This is expected presentation behavior and does not indicate that the active subscription has expired.

Recommended Actions

  1. Verify that the active primary instance reports an Active license.
  2. Confirm that the DR pair is healthy and synchronized.

Additional Information

  • The standby license display is not a reliable indication of subscription validity while the instance remains in standby/read-only mode.
  • Promoting the standby to primary confirms that the license state is associated with the instance operating as the active primary.
