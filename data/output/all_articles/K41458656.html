Topic

You should consider using these procedures under the following condition:

  • You want to revoke an existing BIG-IP Virtual Edition (VE) license and re-assign the license to a different BIG-IP VE system. 

Description

Starting in BIG-IP VE 12.1.3.3 through 12.1.6, and 13.1.0.2 and later, you can revoke the license from a BIG-IP VE system and re-use the license on a different BIG-IP VE system. You must have access to the BIG-IP VE to revoke the license. If you don't have access, for instance you deleted the virtual machine (VM), you must contact F5 support and request an "Allow Move" on the registration key to move it to a new VM.

Note: This functionality is available for only BIG-IP VE systems.
Note: Add-on keys are tied to base registration key once used/activated,  add-on keys cannot be revoked individually.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have access to the Configuration utility or the TMOS Shell (tmsh).
  • The BIG-IP device is configured for DNS and can route to the internet.

    Note: The BIG-IP system needs to be able to resolve the hostname activate.f5.com even when configured to use an outbound proxy, and must have outbound access on TCP port 443. 

Procedures

  • Using the Configuration utility to revoke and reuse a BIG-IP VE license

    To watch a video demo of this procedure, go to  K000159944: Revoke a BIG-IP VE license using the Configuration utility.

  • Using tmsh to revoke and reuse a BIG-IP VE license

Using the Configuration utility to revoke and reuse a BIG-IP VE license

Impact of procedure: Revoking the license disables traffic management features and returns the BIG-IP system to an unlicensed state.

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. On the License page, select Revoke.
  4. When prompted to remove the license, select OK.
  5. You can now install the license on the new BIG-IP VE system.
    Note: It can take 5-15 minutes for this to complete and if you get an error 51162 : "Key is being revoked none" then you will need to call F5 Support and request an "Allow Move" of the registration key.

Using tmsh to revoke and reuse a BIG-IP VE license

Impact of procedure: Revoking the license disables traffic management features and returns the BIG-IP system to an unlicensed state.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To revoke the license, enter the following command:

    revoke /sys license

  3. You can now install the license on the new BIG-IP VE system.
    Note: It can take 5-15 minutes for this to complete and if you get an error 51162 : "Key is being revoked none" then you will need to call F5 Support and request an "Allow Move" of the registration key.
