Issue

Error Message

01531003:3: Failed to sign zone transfer query for zone <zone_name> using TSIG key <key_name>

In this error message, note the following:

  • <zone_name> is the name of the zone for the transfer query
  • <key_name> is the name of the TSIG key

For example:

01531003:3: Failed to sign zone transfer query for zone example.com using TSIG key tsig_key

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The DNS Express zone transfer daemon (zxfrd) encountered an error while attempting to sign a zone transfer query for the specified zone using the specified TSIG key.

Impact

The zone transfer query will not be sent, causing the zone transfer to fail. This may cause the associated zone to be marked invalid and will not be available for DNS queries until a successful zone transfer is completed.

Recommended Actions

Verify that the associated TSIG key is correct and that the secret value entered for this key comes from the appropriate key generation utility, such as BIND's keygen utility.
