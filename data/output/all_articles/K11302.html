Issue

Old Behavior

In versions prior to BIG-IP 10.1.0, the /usr file system was mounted in read-write mode, which allowed changes to files stored on the /usr file system. For example, K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive includes procedures that involve editing the /usr/libdata/configsync/cs.dat file.

New Behavior

Beginning in BIG-IP 10.1.0, the /usr file system is mounted in read-only mode. While this change enhances overall system security, it can impact users who want to make modifications to files stored on the /usr file system.

F5 Product Development tracked this change as ID 246842 (formerly CR103438).

Impact

Modifying files stored on the /usr file system is no longer possible, because the /usr file system is mounted in read-only mode.

Recommended Actions

If you need to edit a file held on the /usr file system, you must first remount /usr in read-write mode.
