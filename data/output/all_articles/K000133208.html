Description

  • You are unable to save the configuration via the CLI with the tmsh save sys config command on a BIG-IP device

Environment

  • BIG-IP
  • CLI
  • Configuration save using tmsh

Cause

The error when saving the configuration is due to the inode or file utilization of /shared or another filesystem such as /config has reached 100%.

Note: An inode is a data structure that is allocated to a file on a UNIX-based system. If the system contains many small files, you may run out of inodes before you run out of disk space.

Recommended Actions

To fix the issue, you may move/delete any unnecessary files from the BIG-IP system.

To locate directories that have many files that would contribute to inode usage, you can use the following syntax:

find <directory> -xdev -printf '%h\n' | sort | uniq -c | sort -k 1 -nr | head -20 

For example:

find /shared/ -xdev -printf '%h\n' | sort | uniq -c | sort -k 1 -nr | head -20
find /config/ -xdev -printf '%h\n' | sort | uniq -c | sort -k 1 -nr | head -20

Use the following syntax to find large files:

find <directory> -xdev -type f -exec du -h {} \; | sort -rh | head -20

For example:

find /shared/ -xdev -type f -exec du -h {} \; | sort -rh | head -20
find /config/ -xdev -type f -exec du -h {} \; | sort -rh | head -20

The following command shows deleted files still using inodes in use by processes. Rebooting the system during a maintenance window will clear these:

lsof -ws | grep -i 'size\|deleted'
