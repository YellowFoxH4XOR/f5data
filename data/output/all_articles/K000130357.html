K000130357: FAST Template Load Balance Type can not be changed

Type
Support Solution
Published
2022-12-27
Updated
2022-12-27
Source
https://my.f5.com/manage/s/article/K000130357

Description

When trying to deploy Microsoft Exchange service using FAST template, load balancing method is not selectable in the template options.


Environment

Microsoft Exchange FAST Template

Load Balancing between servers


Cause

Missing configuration


Recommended Actions

When filling the template options. check "RPC-over-HTTP" and "IMAP4", then two sections will show up with additional 2 sections: Load Balancing Method and Slow Ramp.


Additional Information

None
