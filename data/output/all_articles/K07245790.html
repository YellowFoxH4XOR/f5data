Description

Using the option for Advertised Certificate Authorities in a client ssl profile, does not work as expected. The client is presented with all certificate options, and not only the ones issued by the advertised CA.

Environment

  • Client Authentication enabled on Client SSL profile
  • Advertised Certificate Authorities option, enabled and set
  • Using TLS1.3

Cause

Bug ID 878641: TLS1.3 certificate request message does not contain CAs

Note: This can also occur if the BIG-IP version does not support TLS 1.3 with Client Certificate Authentication.

Recommended Actions

At the time of publication of this article BUG ID 878641 is not fixed yet.

As a temporary workaround TLS1.2 can be used.

Additional Information

For information about BIG-IP versions that support TLS 1.3 with Client Certificate Authentication, refer to K10251520: BIG-IP support for TLS 1.3
