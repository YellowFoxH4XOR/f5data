Description

Sometimes, after performing an upgrade, this error appears: "Configuration not loading with banner error message. This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device.''

The command tmsh load sys config verify does not return any error.

After trying the K13223635 and K41516120, the issue still persists.

Environment

  • BIG-IP LTM
  • TMOS upgrade
  • License for the device

 

Impact

An error message appears in the GUI stating that the device is not operational. However, the device is operational.

Cause

This error happens because the license was not reactivated before the upgrade.

Recommended Actions

  1. Rollback to the previous version.
  2. Reactivate the license before the software upgrade.
    1. Log in to the Configuration utility.
    2. Go to System > License > Re-activate.
    3. Select either Automatic or Manual as the activation method.

      Note: If your system does not have Internet access to the F5 license server, you must select Manual.

    4. Select Next and follow the instructions.
    5. Verify if the service check date is updated to the new one using below command in CLI: 
      tmsh show sys license | grep "Service Check Date"
    6. If service check date got updated please continue with the step 3 if the service check date still show old date please try manual reactivation of the license.

3. Delete the existing boot location for the target version to upgrade

4. Install the iso into a new boot location

5. Boot the device into the new boot location
