Known Issue

On rare occasions, the bd process may produce a core file when the BIG-IP ASM security policy attempts to log a matched attack signature.

Impact

The BIG-IP ASM traffic processing is temporarily interrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system produces a bd core file.
  • The system sends an SIGSEGV to the bd process and logs a message to the /var/log/ts/bd.log file.

    For example

    BD_MISC|CRIT |18019|signals.c:0076|Received SIGSEGV - Core Dumping
