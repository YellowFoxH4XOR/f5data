Description

You should consider using this procedure under the following condition:

  • You want to use the Configuration utility to update the protocol inspection signatures on the BIG-IP AFM system

To detect anomalies in traffic, the BIG-IP AFM system performs protocol inspection using sets of signatures. F5 periodically updates these signatures and releases them on the MyF5 Downloads site.

You can use the Configuration utility to download, install, and deploy (load) protocol inspection signatures without interrupting traffic. You can update the protocol inspection signatures manually or you can configure the BIG-IP AFM system to perform the updates automatically on a daily, weekly, or monthly basis. When you enable the Automatic Updates feature, the BIG-IP AFM system automatically downloads, installs, and deploys the latest protocol inspection signature package.

Environment

You must meet the following prerequisite to use this procedure:

  • BIG-IP AFM
  • Internet access to the MyF5 Downloads site.
  • Administrative access to the Configuration utility.

Cause

None

 

Recommended Actions

  • Manually updating the protocol inspection signatures
  • Automatically updating the protocol inspection signatures

Manually updating the protocol inspection signatures

To download, install, and deploy the latest BIG-IP AFM protocol inspection signature package manually using the Configuration utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
Note: The Subscription column in the Inspections List indicates whether your BIG-IP AFM license includes a given inspection or whether you require a subscription. 

 

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Security > Protocol Security > Inspection Updates.
  3. To download the latest protocol inspection signature package, click Download Package From f5.com.

    Note: You can also manually download the protocol inspection signature package from the MyF5 Downloads site to your desktop and copy the package to the /shared/protocol_inspection_updates directory on the BIG-IP AFM system manually or click Download Package From File to upload it to the BIG-IP AFM system.

  4. After you download the protocol inspection signature package, it appears under Available to Install. To verify and install the package, choose the package and click Install. The installation status displays under Status.
  5. Available to Deploy lists the inactive protocol inspection signature packages installed on the BIG-IP AFM system. To deploy a protocol inspection signature package, choose the package and click Deploy.

Automatically updating the protocol inspection signatures

You can configure the BIG-IP AFM system to automatically update protocol inspection signatures daily, weekly, or monthly. To configure the BIG-IP AFM system to automatically download, install, and deploy the protocol inspection signature updates, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Security > Protocol Security > Inspection Updates.
  3. Under Automatic Update Settings, for Automatic Download and Install, click Enabled.
  4. For Update Schedule, click Daily, Weekly, or Monthly.
  5. Click Update.
