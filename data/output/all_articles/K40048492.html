Known Issue

The BIG-IP Diameter monitor may prematurely mark down the Diameter server.

This issue occurs when the following conditions is met:

  • You have a pool configured to use the Diameter monitor to monitor the Diameter server.

The Diameter monitor has a three-second timeout that overrides the interval and timeout settings configured for the monitor.

Impact

The BIG-IP system marks down the Diameter server even though the configured timeout value for the server is not reached.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system unexpectedly marks down your Diameter server.
