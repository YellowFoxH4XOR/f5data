Known Issue

The BIG-IP system does not save SSL certificates, external monitors, or data group files that contain spaces in the name in a user configuration set (UCS).

This issue occurs when all of the following conditions are met:

  • A file contains a space character in the name.
  • You performed a ConfigSync, UCS restore, or software upgrade.
  • A BIG-IP object, such as an SSL profile, iRule, or monitor, references the missing file.

Impact

  • A UCS restoration will fail.
  • A ConfigSync operation will fail.
  • The configuration will fail to load after a software upgrade or a hotfix installation.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H405958 on the Diagnostics > Identified > High screen.
  • When attempting to create a UCS file, the BIG-IP system produces an error message similar to the following example that mentions a skipped file:

    # tmsh
    # save sys ucs example
    Saving active configuration...

    /config/ssl/ssl.crt/example one.crt: Skipped, spaces not supported in filenames
    /var/tmp/cert_temp/ssl/ssl.key/example one.key: Skipped, spaces not supported in filenames
  • In 11.0.0 through 11.3.0, the configuration fails to load after an upgrade, hotfix, or UCS installation.

    The system logs the following error message to the /var/log/ltm file, which reports a file name with a space character:

    01070712:3: Caught configuration exception (0), Failed: name(/Common/example key) No copy in trash-bin
  • In 10.x, a UCS installation fails.

    The system logs the following error message to the /var/log/ltm file, which reports a file name with a space character:

    01070313:3: Error reading key PEM file /config/ssl/ssl.key/example key.key for profile
  • In 10.x, a ConfigSync operation fails.

    Note: BIG-IP 11.x does not use UCS to perform a ConfigSync.

Workaround

Depending on how this issue has impacted your BIG-IP system, you can perform one of the following workarounds:

Upgrade or hotfix installation failures

Impact of workaround: The BIG-IP system will be unavailable to process traffic during the reboot.

To work around this issue, boot back to the original boot partition and import the file using a name that does not contain spaces. Associate the new file with the BIG-IP object that references the file and proceed to upgrade or hotfix the BIG-IP system.

UCS creation failures

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

To work around this issue, import the affected file using a name that does not contain spaces and associate the new file with the BIG-IP object that references the file. Proceed with the UCS backup process.
