Description

After upgrading BIG-IP software, snmpd fails to start causing SNMP traps not to be sent.

There are errors in /var/log/snmpd.log:

/config/snmp/snmpd.conf: Permission denied
/config/snmp/snmpd.conf: Permission denied
Warning: no access control information configured.
  (Config search path: /etc/snmp:/usr/share/snmp:/usr/lib64/snmp)
  It's unlikely this agent can serve any useful purpose in this state.
  Run "snmpconf -g basic_setup" to help you configure the snmpd.conf file for this agent.
alertd pid file not found: No such file or directory

Environment

  • upgrading BIG-IP

Cause

Similar issue that may be related to SELinux problem in Bug ID 882833: SELinux issue cause zrd down
 

Recommended Actions

The following commands after upgrading have been known to fix this issue:

# restorecon -rF /config/snmp/snmpd.conf
# bigstart restart snmpd
