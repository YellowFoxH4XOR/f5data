Description

When DNS recursion is configured on the BIG-IP LTM and Address Translation is disabled, the BIG-IP will create a loop and show port exhaustion messages.
01010281:4: Inet port exhaustion threshold reached on <IP address> to <IP address>:53 (proto 17).

Environment

  • BIG-IP LTM/DNS.
  • Recursive DNS cache Virtual server.
  • Loop detected on the BIG-IP.
  • Query with opcode=1.

Cause

Disabling Address Translation on a Virtual Server may cause routing loops and port exhaustion messages.
 

  • When translate-address is disabled and a pool is not applied to a VS, the LTM will use the TMM routing table to perform a load balancing decision.

Recommended Actions

Enable Address Translation on the virtual server to avoid loops.

Similar configuration on the virtual server: 
 
ltm virtual /Common/VS_DNS {
    destination /Common/192.168.50.50:53
    ip-protocol udp
    last-modified-time 
    mask 255.255.255.255
    profiles {
        /Common/dns-recursive { }
        /Common/udp_gtm_dns { }
    }
    serverssl-use-sni disabled
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
    vlans {
        /Common/ixia-p1
    }
    vlans-enabled
}
 

Enabling Address Translation on the BIG-IP LTM virtual server:

  • Log into the GUI (Configuration Utility) and navigate to Local Traffic  ››  Virtual Servers: Virtual Server List  ››  Virtual Server
  • Select the checkbox for Address Translation.
  • Click Update.
