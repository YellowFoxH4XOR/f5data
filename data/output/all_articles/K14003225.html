Description

  • You want to configure public key authentication for a user different than root on your BIG-IP

Environment

  • BIG-IP
  • A remote device
  • Public key authentication

Cause

None, this is purely an educational article.

Recommended Actions

On the BIG-IP side:

  1. Login with the user you want to configure public key authentication for on to the CLI
  2. Create your own .ssh directory:
    mkdir -p $HOME/.ssh/
     
  3. Generate ssh keys:
    ssh-keygen -f $HOME/.ssh/id_rsa
     
  4. Copy your id_rsa file to /root/.ssh:
    cp $HOME/.ssh/id_rsa /root/.ssh/
     
  5. Use ssh-copy-id:
    ssh-copy-id some_user@<your_remote_host_ip>


On the remote device side:

You need to set up correct permissions for the following directories:
chmod go-w /home/user
chmod 700 /home/user/.ssh
chmod 600 /home/user/.ssh/authorized_keys

('user' is your username)

After that on your BIG-IP:

ssh -v user@<some_ip>
