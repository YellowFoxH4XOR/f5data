Known Issue

The BIG-IP LTM system does not update traffic statistics on a secure network address translation (SNAT) object when traffic is embedded Packet Velocity Acceleration (ePVA) accelerated.

This issue occurs when all of the following conditions are met:

  • You configure a SNAT.
  • You accelerate traffic on an ePVA-capable platform.

Impact

The BIG-IP LTM system does not update traffic-related SNAT statistics, such as pkts, bytes, in, and out.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP LTM system does not update statistics for SNAT objects that have ePVA accelerated traffic.
