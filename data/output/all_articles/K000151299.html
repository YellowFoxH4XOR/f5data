Description

Observing continually increasing memory usage on VELOS controllers, when reviewing:

  • The system dashboard
  • Output of show components component controller-* state memory

Environment

  • VELOS controllers
  • All versions of F5OS-C including v1.5.x, v1.6.x, v1.7.x and v1.8.x

Cause

There is a slow memory leak in two openshift processes:

  • openshift start master api
  • openshift start master controllers

This issue is tracked by bug ID1933877.

Recommended Actions

The leak is a slow one. Elevated memory usage may only be noticed on systems with high uptime, typically a year or more.

To review the resident size of the two openshift processes in question, use the ps command:

ps aux | grep -E '^USER| [o]penshift start master'

There is no fix for ID1933877 at the time of this article's publication. If available memory is observed to be low, a workaround is to reboot each system controller.
