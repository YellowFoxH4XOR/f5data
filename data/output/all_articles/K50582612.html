Description

Not getting real client ip into mysql backend server
Seeing only load balancer virtual IP instead of real client ip

Environment

  • BIG-IP LTM
  • MySQL application redundancy
  • Virtual Server for MySQL

Cause

Virtual server configuration "source-address-translation"  set  to Automap or SNAT pool

Recommended Actions

Change "source-address-translation" to none

Note: Source address translation set to none will change source address on server side to client IP address. Backend servers should have returning traffic send back to F5 in other case asymmetric routing will happen and traffic will not be processed correctly
