Description

You would like to add a forward slash '/' at the end of a URL with Positional Parameters.
Here is an example:

/cart/*/

When adding forward slash "/", you notice an error message: '/' and '\' are not allowed.

Environment

You are implementing URL with Positional Parameters in an ASM Policy.

Cause

none

Recommended Actions

Take /cart/*/ as an example, do the following:

  1. Navigate to Security  ››  Application Security : URLs : Allowed URLs : Allowed HTTP URLs
  2. Press Create... button 
  3. Add a segment as Text with string "cart"
  4. Add a segment as Parameter with Name as the Parameter Name and Wildcard Expression as "*"
  5. Add a segment as Text with string containing only a single space
