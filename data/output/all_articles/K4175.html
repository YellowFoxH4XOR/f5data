Issue

sfd is responsible for connection mirroring and only runs in redundant pairs. The following error will occur if your redundant pair is not configured properly.

shutdown sfd: not running

If you are not running a redundant pair, you can safely ignore this message. If you are running a redundant pair and you receive this message, contact F5 Networks Technical Support for assistance.
