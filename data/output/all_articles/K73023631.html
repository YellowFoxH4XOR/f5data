Description
The BIG-IP does not utilize the TCP timestamp options during TCP 3WHS with pool-member, even when the TCP profile settings for timestamp is enabled.

Environment

  • Server Side TCP Profile
  • TCP 3WHS Options negotiation.
  • Client Side TCP Profile
  • TCP Timestamp
  • TCP MSS 

Cause
Four settings of a TCP profile impact server side negotiation... 'proxy-options', 'proxy maximum-segment', 'Timestamps Extension for High Performance', 'Max Segment Size'
For additional information refer K61650091

Recommended Actions

  1. Verify 'Timestamps,Extension for High Performance' is enabled for the Server side as well as Client Side, and that the Client is negotiating TCP timestamp with BIG-IP.

  2. Verify clientside mss - serverside mss <= 12', proxy-mss is enabled on both sides, proxy-options is enabled on the serverside, AND timestamps are enabled on the serverside. The BIG-IP will disable timestamps on the serverside.
