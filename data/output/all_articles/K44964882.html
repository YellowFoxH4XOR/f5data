Description
When using the BIG-IP edge client on Windows the VPN user can connect successfully with no issues. However, when disconnecting the Edge Client gets stuck in the "Disconnecting from server..." state, and the connect button no longer works. The user cannot reconnect without completely exiting and relaunching Edge Client.

Environment

  • APM Policy with Azure MFA
  • Edge Client version 7.2.1.2, 7.2.1.3, 7.2.2.2, 7.2.3

Cause

  • Azure MFA has not been configured with the correct logout URL.
  • Using Edge Client v7.2.1.2 or v7.2.1.3
  • Multiple Azure accounts

Recommended Actions

  • This has typically been seen in instances with a misconfiguration on Azure MFA. 
  • The logout URL in Azure MFA should be the same URL that the Client uses to connect to. If the Client uses https://my-vpn.example.com to connect to their VPN, then this is the URL that should be configured as the Logout URL in Azure MFA.  Once this is done, the Edge Client should logout as expected.
  • If you have confirmed the logout URL, or this has worked prior to upgrading the BIG-IP Edge client to version 7.2.1.2 or v7.2.1.3. This is most likely the result of Bug ID 1041613. The fix is introduced since version 7.2.2.2 or 7.2.3

Additional Information

  • However if you are already running version 7.2.2.2 or 7.2.3 and using multiple Azure accounts you will still having the same issue and this is due to the Bug ID 1086829. Unfortunately there is no public facing documentation regarding this known issue and no known work around or fix at this time.
  • Therefore if you think are running into this issue please consider opening a support case per K23782072: Opening a support case through MyF5.
