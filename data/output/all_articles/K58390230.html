Description

You can see a large tcpdump file and after deleting it, it still shows in the file system 
Example output when running the command that shows large deleted file:  

#lsof -ws | grep -i 'size\|deleted'

COMMAND     PID   TID      USER   FD      TYPE             DEVICE        SIZE       NODE NAME
tcpdump     639            root    4w      REG             253,1 38367113216    2539525 /shared/support/tcpdump_635.dmp (deleted)

Environment

  • Running tcpdump
  • Unable to delete tcpdump file

Cause

BIG-IP TCP dump was running in the background, and it was not stopped or TCP dump is still running in background and associated to the file you are trying to delete

Recommended Actions

Find and kill the PID related to the stuck tcpdump PID by doing the following:

  1. Run 'top' or 'ps -ef | grep tcpdump' command to find the PID for tcpdump process.
     
  2. Kill the PID related to the stuck tcpdump PID.
    For example, for PID number 635, run the command, 'kill -9 635'
     
  3. Confirm that large tcp dump file no longer showing in the output of command: 
    lsof -ws | grep -i 'size\|deleted'
