Description

The TCP Fast Open option in a TCP profile (found at Local Traffic > Profiles > Protocol > TCP) reduces latency by allowing a client to include the first packet of data with the SYN. However, this works only for client-side traffic, even if the option is enabled for the server-side TCP profile.

Environment

Relevant environmental factors specific to the topic:

  • TCP profile Fast Open
  • Client and server accepting TCP Fast Open

Cause

This option is designed to work only for client-side TCP profiles. It has no effect on server-side TCP profiles, even if the server accepts TCP Fast Open.

Recommended Actions

None

Additional Information

How it works when both client and server accept Fast Open:

  • Only client-side accepts Fast Open:

    • Client <-> BIG-IP: Fast Open connection followed
    • BIG-IP <-> Server: 3-Way Handshake

  • Only server-side accepts Fast Open:

    • Client <-> BIG-IP: 3-Way Handshake
    • BIG-IP <-> Server: 3-Way Handshake

  • Both client and server accept Fast Open:

    • Client <-> BIG-IP: Fast Open connection followed
    • BIG-IP <-> Server: 3-Way Handshake
