Known Issue

This is the result of a known issue. When configuring the BIG-IP system to use RADIUS authentication and a DNS name is used for the RADIUS server value, the PAM RADIUS module does not resolve the hostname of the RADIUS server.

F5 Product Development recommends the use of IP addresses for critical hosts to prevent DNS issues from interfering with authentication to the BIG-IP system.

F5 Product Development tracked this issue as CR68847 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.
