Issue

Error Message

ata5.00: failed command: READ FPDMA QUEUED

Message Location

You may encounter this message in the following locations:

  • /var/log/kern.log file
  • End-User Diagnostics (EUD) utility

Description

This message occurs when the following conditions are met:

  • Your BIG-IP system detects a possible hardware error, such as:
    • Hard disk failure or errors
    • Power Supply Unit (PSU) failure or errors

Impact

Your BIG-IP system may fail to initialize, and devices configured as a high availability (HA) pair may fail over.

Recommended Actions

  • F5 recommends running End-User Diagnostics (EUD) tests to check for possible hardware failures, and generate a diagnostic report. For information about EUD tests, refer to K7172: Overview of the End User Diagnostics software .
