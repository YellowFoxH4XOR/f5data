K000151569: Error "Request failed with status code 401" when attempting to deploy AAD from guided configuration

Type
Support Solution
Published
2025-06-04

Status
Legacy Content
Applies to

  • BIG-IP APM: 16.1.5
Source
https://my.f5.com/manage/s/article/K000151569

Description

Attempting to deploy an Azure AD application from APM's AGC may result in a 401 unauthorized error that shows in a browser pop up. Taking a packet capture also would show that the 401 is being sent by the Azure servers back to the APM.

 

  • 401 unauthorized error in /var/log/restnoded.log
    • Tue, 08 Apr 2025 20:37:41 GMT - severe: [[azureUtils] ] getAadAccessTokenWithRetry error : Request failed with status code 401, opCode=FAILED

Environment

  • APM AGC v10
  • APM Azure AD application deployment

Cause

The information plugged into the deployment configuration for the client secret is invalid, and Azure is not accepting it.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1.  Fix the client secret to something that works.
  2. Use the "Test Connection" button before deploying.

Additional Information

Microsoft also supplies a powershell script to test your client secret:

https://learn.microsoft.com/en-us/azure/active-directory-b2c/client-credentials-grant-flow?pivots=b2c-user-flow#step-31-obtain-an-access-token-with-script
