Description

When user try to add DNS names to the tunnel using DNS Address Space, those addresses are not added to the routing table as an inclusion through the VPN tunnel.

 Environment

  • BIG-IP APM
  • VPN
  • Split tunnel

 Cause

This is expected behavior, DNS Address Space only determines whether the local DNS server or the one configured in Network Access will be used to resolve DNS names.

 Recommended Actions

User have to add all those IP addresses in IPV4 LAN Address Space in order to be routed through the VPN tunnel.
