Description

When using SPKv1.7.8 with OpenShift 4.12.53 customer will experience EDENY and how to fix for http2 vips.

Upon execution of command: 

 tmctl -d blade virtual_server_stat -s name,conf_status,destination -w 999 name conf_status destination

 

The errors will indicate the EDENY messages. 

LTM-l-spk-ingress-monitor-Monitor1-knowi-agent-8080-int-vs EDENY 00:00:00:00:00:00:00:00:00:00:00:00:5E:00:53:00:00:00:00:00

LTM-l-spk-ingress-monitor-Monitor1-mtas-gateway-8080-int-vs EDENY 00:00:00:00:00:00:00:00:00:00:00:00:5E:00:53:00:00:00:00:00

LTM-l-spk-ingress-monitor-Monitor1-mtas-gateway-8080-ext-vs OK 00:00:00:00:00:00:00:00:00:00:00:00:5E:00:53:FF:00:00:00:00

LTM-l-spk-ingress-monitor-Monitor1-scef-callback-8080-int-vs EDENY

 

Environment

  • NAME VERSION
  • aspenmesh 1.14.6-am9
  • ocp 4.12.53
  • spk v1.7.8
  • spk-operator 2.8
  • trident 23.10.0
  • webscale 1.5.10-1

Cause

If bidirectional persistence is enabled on one of the routes and, you have two http2 crs on the same port, both using bidirectional persistence, then this issue will occur. We can disable persistBidirectional and this should resolve. As of today this is a FAD on HTTP2 CRD's for F5 SPK.

 

Recommended Actions

We recommend deleting the cr (custom resource) then modify the HTTP2 ingress to make persistenceBiDirectional to "false" and re-apply.

 

  • Delete the cr

    # kubectl delete -f mycustomresourcedefinition.yaml

  • Edit the yaml file
    # vi f5-spk-ingresshttp2s.k8s.f5net.com.yaml

    Note: change the below parameter to false

staticRoutes: 
  - conditions: 
   - caseSensitive: true 
    comparisonOp: SR_COMPARE_EQUALS 
    fieldName: :u 
    values: 
    - /Portal/Login.aspx 
   customIruleProc: sister_pool_status 
   persistBidirectional: true.      <--------< by default it is set to true 
   persistField: "" 
   persistTimeout: 0 
   service: pmec-gateway-service
   snatType: SRC_TRANS_AUTOMAP

 

  • Re-apply the file recently modified.
    # kubectl apply -f f5-spk-ingresshttp2s.k8s.f5net.com.yaml

Additional Information

Presently function as designed.
