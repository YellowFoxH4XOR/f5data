K000152764: User with Resource Group Deployer does not see Deployment tab in GUI

Type
Support Solution
Published
2025-07-27
Updated
2025-07-28
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000152764

Description

You have a custom user role which has Resource Group Deployer, that user gets to deploy task but unable to see the Deployment tab in the GUI.

Environment

  • BIG-IQ

Cause

ID1989889 and ID994005 

Recommended Actions

This is known issue and tracked under ID1989889. The user with Resource Group Deployer can access the Deployment tab use the following URL.
https://<enter BIG-IQ IP address>/ui/deployment

The user will not able to see the difference in the changes made. They will just see a Deployment page just to see if the chosen configuration is deployed or not. This is also known issue and tracked under ID994005.

None
