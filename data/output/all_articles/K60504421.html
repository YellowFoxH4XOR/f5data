Issue

Error Message

notice mcpd[<PID>]: 010719e8:5: Virtual Address <name> monitor status changed from <orig_value> to <new_value>.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <name> is the partition and name of the virtual address
  • <orig_value> is the monitor status from which the virtual address changed
  • <new_value> is the monitor status to which the virtual address changed

For example:

notice mcpd[4554]: 010719e8:5: Virtual Address /Common/10.10.10.10 monitor status changed from UNCHECKED to UP.

Note: The message ID for this message may vary depending upon your BIG-IP version. The message ID in the above example is010719e8.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • Your BIG-IP system detects a monitor status change for a virtual address.

The system generates this message when the monitor status for a virtual address changes to one of the following:

  • UNCHECKED
  • CHECKING
  • INBAND
  • FORCED_UP
  • UP
  • UP_MAX
  • DOWN_MIN
  • ADDR_DOWN
  • DOWN
  • FORCE_DOWN
  • MAINT
  • IRULE_DOWN
  • INBAND_DOWN
  • DOWN_WAIT_MAN_RES

Impact

This message is informational and reports the monitor status for a virtual address. Unexpected changes to a pool member's availability state may indicate a configuration error or lack of resource availability.

Recommended Actions

If the system reports an unexpected DOWN status, verify the virtual address configuration, the configuration of associated health monitors, and the resource availability to ensure resource availability.
