K71751631: err snmpd[xxxx]: Can't find security model to free ptr: 1

Type
Support Solution
Published
2023-07-19
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K71751631

Description

SNMP error appear in daemon.log and snmpd.log after an upgrade to 15.1.x.

Environment

  • BIG-IP
  • SNMP polling

Cause

This error log appears while polling OID in SNMPv1. SNMPv2 gives No Such Instance currently exists at this OID in a response which does not trigger the SNMP error in the logs.

Recommended Actions

Verify SNMP OIDs are recognized by the BIG-IP using SNMPv1 or use SNMPv2.

Additional Information
