K06451490: Adding members with same IP and unique service port to the same pool in Application Template fails

Type
Support Solution
Published
2020-02-05
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K06451490

Description
Creating an Application Template with pool with members that share IP addresses and have different service ports will fail with an error like:

Duplicate item. Key already exists: partition : Common, deviceReference : , name : example_template_192.168.2.10

In the error above "example_template" is the name of the template and "192.168.2.10" is the IP of the pool members that attempted to share the IP address. 

Environment

  • BIG-IQ application deployment
  • Configuring pool members 

Cause
This behavior is by design.

Pool members that share IP addresses can be added during the deployment of an application.
The template cannot be configured to contain two members that have same-IP:different_port.
An additional pool member can be added that shares the IP address during the deploy of the application

Recommended Actions

To work around the issue, "Allow Multiple Instances" on the pool in the template being used
  1. Login to the GUI
  2. Navigate to  Applications>>  <Template_name> >>Pools >> <Pool_Name> 
  3. Check "Allow Multiple Instances"    
  4. Create one pool member with the IP address that you want to share in the template.
  5. The second member must be added during the application deployment from the "Add object of type: ltm pool members Pool Member"  section.
