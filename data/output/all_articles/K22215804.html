Description

LCD panel is stuck.

Rebooting did not help.

Restarting fpdd service is not possible with tmsh restart /sys service <service name> or bigstart restart <service name>.

When restarting service this message shows: "Couldn't find service: fpdd".

Environment

  • iSeries Platform
  • LCD panel

Cause

Service fpdd and lcdwarn tool are no longer used on the platform, the functionality is now built into tmsh / icontrol.

Recommended Actions

  1. Try using this command instead to clear the alerts:

    tmsh reset-stat sys alert lcd

  2. If it does not work, the AOM might have stopped responding and needs a reset. Follow the Workaround on this related article: K00415052: AOM may stop responding during an upgrade on iSeries platforms.

Additional Information

Other troubleshooting steps to check LCD screen functionality can be:

Disable LCD with this command:

# tmsh modify sys db platform.chassis.lcd value disable

Wait about 2/3 mins and re-enable it again:

# tmsh modify sys db platform.chassis.lcd value enable

Restart fpdd (front panel display daemon) with command:

# tmsh restart /sys service fpdd
