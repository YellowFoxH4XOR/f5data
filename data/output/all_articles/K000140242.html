K000140242: APM: FltRedirSrv.txt is missing in CTU report

Type
Support Solution
Published
2024-07-03
Updated
2024-07-03
Status
Final
Source
https://my.f5.com/manage/s/article/K000140242

Description

DNS Relay Proxy Service is an important component for vpn users who perform rule-based DNS resolution without the use of the host file. The component produces the FltRedirSrv.txt log file. This file may not be included into CTU report (aka f5wininfo.exe) and it makes the troubleshooting of DNS related issue more difficult for BIGIP APM administrator.

Environment

  • APM
  • VPN
  • DNS
  • FltRedirSrv.txt

Cause

The CTU report is not generated using admin rights.

Recommended Actions

Make sure that the CTU report is generated using admin rights. If the FltRedirSrv.txt log file is still not included into report, then the file can be found and copied manually from testing Windows machine in C:\Windows\Temp\
