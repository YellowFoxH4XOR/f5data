Description

On BIG-IP the LTM module runs using multiple processes:

  • TMM runs as a data plane task within the BIG-IP operating system
  • alertd, big3d, bigd, httpd,mcpd, etc. run as control plane tasks
Information about the processes is available at K48615077: BIG-IP daemons

The BIG-IP CPU utilization graph displayed in the Configuration Utility dashboard displays the highest CPU usage as a percentage of the CPU processing time available on the core. The graph does not show details of the individual processes contributing to high CPU usage for each core.

This article explains detailed information about CPU utilisation levels and contributions from individual processes running on the BIG-IP device

    Cause

    The detailed information may become required for a number of reasons including:

    • Understanding the trends in the baseline. Establishing a baseline of your configuration and network traffic is discussed in K11555: Gathering data in preparation for a traffic-impacting change to the BIG-IP system
    • Identifying the contributors causing periodic spikes of CPU utilisation
    • Understanding the contributors causing the CPU utilisation remaining high all the time

    Viewing the LTM CPU utilization in the RRD graphs

    The BIG-IP also keeps recording performance measurements originally collected every 10 s and then stored in historical RRD databases for the next 30 days with granularity decreasing with time. RRD is a platform dependent format (see RRDtool). While the files can be retrieved from the BIG-IP in raw format, the public tool may refuse to read the raw format unless the CPU architecture of the workstation matches the CPU architecture of the Big-IP which generated the database. The two popular methods are:
    • Using QKView: By default, QKView does include the RRD graphs which can be uploaded to ihealth.f5.com and explored under Graphs
       
      1. Log in to bash CLI

      2. The guidelines are available in K12878: Generating diagnostic data using the qkview utility

    • Exporting RRD records into platform independent format can be performed following K50425247 Where to find and how to read CPU utilisation stats
       

    Viewing the LTM CPU utilization using utility top

    Utility top can be used in a bash script for writing to a file detailed snapshots of CPU utilisation consumed by various processes at the moment of the snapshot.
    1. Log in to bash CLI
    2. Further details are available in K40472403: Collecting relevant data to troubleshoot high CPU utilization
    Viewing the LTM CPU utilization using utility tmctl
    Utility tmctl can be used in a bash script for writing to a file detailed snapshots of CPU utilisation consumed by various processes at the moment of the snapshot.
    The advantage of using tmctl over top is that tmctl also can include additional statistics specific to operation of BIG-IP software. The snapshots can be collected using syntax e. g.
    tmctl -a -w 10000
     
    Impact of procedure:Performing the following procedure should not have a negative impact on your system.
    1. Log in to bash CLI
    2. Further details can be found in K40472403: Collecting relevant data to troubleshoot high CPU utilization
