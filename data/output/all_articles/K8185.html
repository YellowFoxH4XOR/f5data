Known Issue

This is the result of a known issue. If you configure a URL containing a port number in the URL field under the Automatically retrieve CRLs from URLs check box, FirePass does not retrieve CRLs from the URL.

Note: The URL field does not appear unless the Automatically retrieve CRLs from URLs check box is selected on the Device Management: Security: Certificates page.

For example, FirePass would retrieve a CRL from the following example URL:

https://www.siterequest.com/crl/mycrl.crl

FirePass would not retrieve a CRL from the following example URL:

https://www.siterequest.com:80/crl/mycrl.crl

If you configure a CRL URL containing a port number and then click the Retrieve CRLs Now link on the Device Management: Security: Certificates page, FirePass reports an error message similar to the following example:

Retrieving CRL from https://www.siterequest.com:80/crl/mycrl.crl...
Error fetching URL source
Could not retrieve CRL content
Operation complete

F5 Product Development tracked this issue as CR91372 and it was fixed in FirePass version 6.1.0.  For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in Hotfix HF-603-2.1, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by configuring a CRL URL that does not contain a port number. The CRL file must be accessible on TCP port 80 if the configured URL begins with http://, or the CRL file must be accessible on TCP port 443 if the configured URL begins with https://.

You can configure the URL field under the Automatically retrieve CRLs from URLs check box on the Device Management: Security: Certificates page.
