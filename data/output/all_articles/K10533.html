Known Issue

Note: This known issue only applies to those platforms that include a Packet Velocity ASIC (PVA) chip version 1 or version 2 (PVA1, PVA2). For more information, refer to K4832: Overview of Packet Velocity ASIC (PVA) Acceleration features and sub features.

This is the result of a known issue. Beginning in BIG-IP version 9.3.0, F5 Product Development implemented a change in behavior to demote the acceleration level for virtual servers whose FastL4 profile specifies an idle timeout value greater than the PVA chips can support.

Note: For more information about this change in behavior, refer to K6792: Change in Behavior: Idle timeouts that exceed the PVA maximum value allowed result in a demotion of the PVA acceleration level.

However, the maximum idle timeout value allowed by PVA1 and PVA2 chips was calculated incorrectly. For example, PVA1 and PVA2 chips accelerate connections with an idle timeout value up to 523,280 seconds. This behavior is incorrect because the maximum idle timeout value is only 65,527 seconds. This behavior occurs because the desired timeout decimal value is converted to a binary value that does not fit in the bits reserved for it. Therefore, connections with an idle timeout value greater than 65,527 seconds will be prematurely deleted. The BIG-IP system should demote every connection with an idle timeout greater than 65,527 seconds, rather than 523,280 seconds.

F5 Product Development tracked this issue as CR125486 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Workaround

You can prevent connections from being deleted prematurely by either lowering the idle timeout to a value equal to or lower than 65,527 seconds, or by disabling PVA acceleration. Both changes require performing the following procedure to modify the FastL4 profile:

  1. Log in to the Configuration utility.
  2. Expand Local Traffic and click on Profiles.
  3. Click Fast L4 in the Protocol drop-down menu.
  4. Click on the Fast L4 profile used by the virtual server in question.
  5. Either modify the Idle Timeout setting to a value equal to or lower than 65,527 seconds, or set PVA Acceleration to None.
  6. Click Update.
