Description

Downloading via BIG-IP fails, and a packet trace shows that the BIG-IP stops retransmitting unacknowledged data.

Environment

  • Lossy network between client and BIG-IP
  • Rate class applied to virtual server

Cause

Bug ID 966785

Recommended Actions

Bug ID 966785 isn't fixed at the time of this article's publication.

A potential workaround is to remove the Rate Class, or use a Bandwidth Controller instead.

Additional Information

This issue will typically only happen if there is some kind of packet loss or congestion between the BIG-IP and client.
