Description

On the BIG-IP system, when you navigate to Statistics > Analytics and then select any category, such as HTTP or CPU, the page displays No data, but  you may observe a message similar to the following example:

There is no data to display either due to the lack of relevant traffic, or due to the settings of the filter.

Environment

  • The BIG-IP system was managed by BIG-IQ before.
  • The BIG-IQ objects are not successfully removed in the BIG-IP system.

Cause

The BIG-IP system is no longer managed by BIG-IQ, while the use-offbox in analytics global-settings setting is not deleted, so BIG-IP system will send the statistics to BIG-IQ without saving the data locally on the device.

You may run the below command to list the current analytics global-settings:

# tmsh list analytics global-settings 
analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 192.168.1.1 }
    offbox-tcp-port 443
    source-id 00000-0000-0000-0000-0000000_192.168.1.1
    use-offbox enabled
}

Recommended Actions

You may follow the tmsh command below to set the analytics global settings for BIG-IQ objects on your BIG-IP back to default:

tmsh modify analytics global-settings enable-bigiq-configuration disabled offbox-protocol none offbox-tcp-addresses none offbox-tcp-port 0 source-id none use-offbox disabled avrd-interval 300

After running the above command, you can verify the analytics global-settings again, and the example output should be like:

# tmsh list analytics global-settings 
analytics global-settings {
    avrd-interval 300
    ecm-port 443
    enable-bigiq-configuration disabled
    offbox-protocol none
    offbox-tcp-addresses none
    offbox-tcp-port 0
    source-id none
    use-offbox disabled
}

Additional Information

If your BIG-IP is manged by the BIG-IQ, then the analytics page will not display by default, for details you may check on K42361146.
