Description

HA sync breaks due to an unlicensed feature with error "01070356:3: ASM feature not licensed" and "TimeLimitedModulesExpired" status in the license details.

Figure: Reference screenshot for the error message

Environment

  • HA sync fails
  • Expired ASM add-on license
  • Expired add-on license
  • TimeLimitedModulesExpired

Cause

When the add-on license for any modules expires on the device and if any unexpected rebootes happens, then HA sync shows as failed.

Recommended Actions

  1. Verify the device has any expired add-on license by running the following command.

#tmsh show sys license 

From the output, you can verify any expired license module by refering to the "timelimited_module" line

Example:

timelimited_module [Advanced Web Application Firewall, VE-1G|NPJJYQH-PFFNOTC|20251110|20251226]

  1. Verify whether any virtual servers are using ASM policies by running the following command

#tmsh list ltm virtual | grep -i "<policy name>"

Example:

#tmsh list ltm virtual | grep -i "policies\|asm"

  1. If ASM is not required, remove the ASM configuration from the Virtual servers and then perform a manual sync.
  2. If ASM is requried, please contact F5 sales or your Account Manager to purchase the requried add-on license
  3. Verify that the HA sync completes successfully.

Note: Since the add-on license has expired,by default the related functions will be disabled, Hence removing the configuration should not give any negative impact to the system.
