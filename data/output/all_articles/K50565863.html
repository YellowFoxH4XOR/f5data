Known Issue

Trivial File Transfer Protocol (TFTP) server responses may not work when Large Scale NAT (LSN) pool inbound connections are disabled.

This issue occurs when the following condition is met:

  • The Inbound Connection setting is configured to disabled.
As a result, TFTP servers are unable to respond to clients on ephemeral ports.

Impact

The BIG-IP system drops TFTP server responses when the server utilizes an ephemeral source port to send/respond to the client.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system drops the server response, which causes the client to stop responding.

Workaround

To work around this issue, you can enable the Inbound Connections setting on the affected LSN pool. To do so, perform the following procedure:

Impact of workaround: If the LSN pool is used for other traffic in addition to TFTP, enabling Inbound Connections may create security concerns by allowing unwanted connections. If your security setup requires that you set Inbound Connections to disabled, F5 recommends that you upgrade to 12.0.0.

  1. Log in to the Configuration utility.
  2. Navigate to Carrier Grade NAT.
  3. Select LSN Pools > LSN Pool List.
  4. Select the affected LSN pool.
  5. In the Inbound Connections drop-down menu, select Automatic.
  6. Click Update.
