Known Issue

Configuration objects, such as virtual servers, pools, etc., are missing after you perform a base-only configuration load and then restart the system.

This issue occurs when the following condition is met:

  • After loading the base configuration with the tmsh load /sys config base command, you restart the system using the bigstart restart command or a system reboot.

When you load the base configuration, the mcpdb binary configuration file is saved with only the base configuration. If you subsequently restart the system before it saves a full configuration, the system restarts with only the base configuration objects.

Impact

Configuration objects may be missing after you restart the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Following a base-only configuration load, the system is missing configuration objects after you restart the system.

Workaround

To work around this issue, you can use one of the following options:

Impact of workaround: Performing either workaround should not have a negative impact on your system.

  • If possible load the full configuration using the tmsh load /sys config command without using the base option.
  • If you must load only the base configuration, ensure that you save the full configuration by running the tmsh save /sys config command before you restart the system.
