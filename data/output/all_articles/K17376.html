Known Issue

Description

The BIG-IP APM AD Query agent may fail to fetch nested groups.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM access policy for the AD Query agent.
  • You have configured the AD Query agent to fetch nested groups.
  • The AD Query agent fetches group membership for a user that belongs to a parent domain, and is also a member of a group that belongs to a sub-domain.

For example, a user belongs to the parent.com domain and is also a member of a group that belongs to the child.parent.com sub-domain.

Impact

The AD Query agent fails and the system may experience performance degradation.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The top or ps command output shows high CPU usage for the apd process.
  • The BIG-IP APM system experiences performance degradation when fetching nested groups in the AD Query agent.
