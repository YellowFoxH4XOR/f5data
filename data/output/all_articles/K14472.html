Known Issue

The BIG-IP ASM Configuration utility may incorrectly reset the policy attack signatures filter list. This issue occurs when all of the following conditions are met:

  • You initiate the attack signature enforcement configuration from the Staging-Tightening Summary page
  • You subsequently configure one or more attack signatures for enforcement from a filtered attack signature list using the Advanced Filter

The BIG-IP ASM Configuration utility allows you to initiate the attack signature enforcement configuration from the Application Security > Policy Building > Manual > Staging-Tightening Summary page by clicking on the Signatures number under the In Staging-Tightening column.

Impact

This issue is cosmetic only.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you configure the system to enforce selected signatures, the filtered attack signature list returns a list of all signatures instead of the filtered signature list.

Workaround

To work around this issue, you can initiate the attack signature enforcement configuration. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Click Application Security.
  3. Click Attack Signatures.
  4. Click Attack Signatures List.
  5. From the Current edited policy menu, select the desired security policy.
  6. From the Policy Attack Signatures menu, select Advanced Filter.
  7. Select the desired filter combination.
  8. Click Go to display the filtered attack signature list.
  9. Select the desired attack signatures to be included in the security policy for enforcement.
  10. Click Enforce.
  11. Click Apply Policy.
