Known Issue

Invalid virtual server configuration settings may cause TMM to produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • You create or already have an existing virtual server that is configured with an HTTP profile.
  • Using the Traffic Management Shell (tmsh), you modify the virtual server by adding the mblb profile.

    Note: The mblb profile is designed to be used specifically with the SIP or DIAMETER profiles.

Impact

When the virtual server processes traffic, TMM may produce a core file and restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If the TMM produces a core file, and the system is configured for high availability, the BIG-IP system fails over to the standby system.
  • The BIG-IP system generates TMM core files to the /shared/core directory that include a time stamp that correlates to the time of the traffic interruption.

Workaround

To work around this issue, you can remove the mblb profile from the virtual server configuration.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
