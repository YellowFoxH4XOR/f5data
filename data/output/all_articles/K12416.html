Known Issue

This is the result of a known issue. On rare occasions, the BIG-IP system may log an error message to the /var/log/ltm file that appears similar to the following example:

err mcpd[3259]: 010712d7:3: DNSSEC Key Generation transaction failed with exception for [Can't save/checkpoint DB object, class:gtm_dnssec_key_generation status:13] in generation_create_cb.

You can safely ignore the error message; it is likely reported when the mcpd process incorrectly detects a duplicate DNSSEC key name and ID in the database.

F5 Product Development tracked this issue as ID 223831 (formerly CR132153) and it was fixed in BIG-IP GTM 11.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.
