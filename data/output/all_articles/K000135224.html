Description

Unable to change sys db dos.scrubtime value in velos tenant.

01b9002b:3: dos.scrubtime couldn't be changed for current platform

 

Environment

Velos

Cause

DoS scrub time has global value on the slot for all tenants. In case of velos platforms, scrub time for clearing DOS vector counters on FPGA is 10ms. It is configured in to FPGA by fpgamgr.Due to this, only one value is allowed to configure and modifying the fpga value using fpgamgr for use is AFM dos.scrubtime value is not a supported technique

ID 930721

 

Recommended Actions

Expected Behavior. Value can't be changed

None
