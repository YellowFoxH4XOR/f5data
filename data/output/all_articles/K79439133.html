K79439133: APM cannot connect to Intune if using Microsoft Graph

Type
Support Solution
Published
2022-09-06
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K79439133

Description

APM cannot connect to Intune if user has migrated from Azure AD Graph to Microsoft Graph in their Intune environment
You may experience authentication errors during APM's Endpoint Management System (EMS) agent creation if using Microsoft Graph and the following logs may be observed in /var/log/apm:

err mdmsyncmgr[5348]: 019dffff:3: (null)::00000000: {} /Common/<EMS-agent-name>: Error during updating device details: Authentication error (Authentication error for query service url request)

Environment

  • Big-IP APM
  • Microsoft Intune/Microsoft Graph

Cause

This is a known limitation between APM and Microsoft Intune using the new Microsoft Graph
This is tracked via ID1034041:

Bug ID 1034041: Microsoft Intune Azure AD Graph cannot cannot migrate to Microsoft Graph.

Previously, it was required that Azure AD Graph was enabled and permissions were set on Intune servers, in order for APM's Endpoint Management System (EMS) agent creation.
Microsoft has since announced the end of support timelines for Azure AD Graph API, requiring users to migrate to Microsoft Graph instead.
After users migrate to Microsoft Graph, they can no longer apply Azure AD Graph permissions on their Intune servers, causing the APM's EMS agent creation to fail.

Recommended Actions

  1. If user has already migrated to Microsoft Graph, from Azure AD Graph, then they will need to upgrade the APM to v17.0 in order for APM to connect to Intune for APM's Endpoint Management System (EMS) agent creation.
