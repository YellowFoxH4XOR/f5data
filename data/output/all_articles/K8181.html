K8181: No DNS queries for IPv6 address records during Active Directory authentication or group mapping

Issue

In FirePass software versions prior to 6.0.2, Active Directory (AD) queries for authentication or group mapping would issue DNS queries for IPv6 address records (DNS AAAA records) of the AD domain controller or controllers. In version 6.0.2 and later, the IPv6 AAAA queries are no longer sent. Only non-IPv6 address record queries (A records) are sent to the DNS servers configured on the DNS tab of the Device Management > Configuration Network > Configuration page.

For the majority of AD configurations, this change will have no effect on the ability of FirePass to perform AD authentication, group mapping, or other AD-based functions. Only those AD configurations that use the IPv6 version of the DNS address record (AAAA record) and do not use the more common form of address record (A record) would be affected by this change. This configuration is not recommended; the preferable configuration if IPv6 AAAA records are required is to also use the older A record.  Normally, DNS software and application software will accommodate the use of both types of records.
