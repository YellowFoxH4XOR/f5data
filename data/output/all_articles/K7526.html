Known Issue

This is the result of a known issue. The Clustered Multi-Processing (CMP) feature modifies the ICMP ID field on ICMP packets. As a result, ICMP traffic is not handled correctly.

For example, the following issues indicate that ICMP traffic is not being handled correctly:

  • The client drops ICMP echo replies because the ICMP ID is incorrect.
  • The BIG-IP LTM drops ICMP errors messages, such as the following two error messages:

    ICMP time exceeded

    ICMP port unreachable

  • ICMP is not forwarded correctly through NATs.

F5 Networks Product Development tracked this issue as CR79701 and it was fixed in BIG-IP LTM version 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
