Known Issue

You may be unable to log in to the BIG-IQ user interface after an upgrade.

This issue occurs when the following condition is met:

  • You upgrade your BIG-IQ system from 6.0.1 to 6.1.0.

Impact

You are unable to log in to the BIG-IQ user interface.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IQ user interface displays the following message and does not present the login fields:

    Waiting for BIG-IQ services to become available...

  • The following error messages appear in the /var/log/restjavad.*.log log file:

    [ERROR][14 Jan 2019 21:55:52 GMT][/shared/authorization/journals JournalCollectionWorker] RBAC updates to storage failed - invalid command: update-rbacrequires an rbacUpdates list

Workaround

To work around this issue, you can run the rbac-reset script. The rbac-reset script clears the Role-based Access Control (RBAC) cache, removes the object tags, and then rebuilds both using the current configuration for the RBAC. The script ensures that all RBAC tags are in the correct and consistent state, but it does not modify the RBAC configuration of the BIG-IQ system. To run the script, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ command line.
  2. Run the script by typing the following command:

    rbac-reset

    When the script is finished you see the following message:

    restarting tokumond and restjavad
