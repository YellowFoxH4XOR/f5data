K13402: Intelligent Browser Referencing (IBR) fails when HTML statements include a tab character

Known Issue

When a tab character precedes an included filename in an HTML statement, the file referenced in that statement is not processed by Intelligent Browser Referencing (IBR).

For example, the following statement causes ibr.js to be included in the IBR content:

<SCRIPT type='text/javascript' src='ibr.js'></SCRIPT>

Where, in the following statement, TAB is a tab character, causing ibr.js to be excluded from the IBR content:

<SCRIPT type='text/javascript' TAB src='ibr.js'></SCRIPT> 

Impact

Objects will be processed outside of IBR, resulting in additional client requests for static content.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You may notice an increase in the number of HTTP conditional get requests to your origin web server.

Workaround

To work around this issue, you can remove the offending tab characters from your HTML object files.

Impact of workaround: None.
