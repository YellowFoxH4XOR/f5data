Description
F5 Automation Toolchain is a set of automation tools that makes it faster and easier to deploy and configure F5 application services via simple yet powerful declarative interfaces. This includes Declarative Onboarding, AS3 and telemetry streaming. Automation toolchain extensions, FAST and Cloud Failover Extensions will not function correctly if the admin user account is disabled on a BIG-IP
  • An alternate admin account is configured, appscvs endpoints will not function
  • GET requests to REST endpoint /shared/appsvcs/info will result in 404 responses 
  • /var/log/restnoded/restnoded.log will log an error message that contains:
    ...Failed to complete startup. Error: Unable to verify additional dependencies: Dependencies Check failed: Timed out waiting for dependencies to load...
Environment
An alternate admin account is configured 
  • To determine this setting in the GUI:
    GUI -> System -> Platform
    In Admin Account  section, Disable default admin, use alternate is checked
  • To determine in tmsh:
    The following command will show a value that is not admin:
     tmsh list sys db systemauth.primaryadminuser
Cause
This issue occurs due to ID1012493.
Recommended Actions
As a workaround, to allow the extensions to function, activate the admin account and restart restjavad
  • Using the GUI
    GUI -> System -> Platform
    In Admin Account  section, uncheck  Disable default admin, use alternate 
  • Using tmsh
    tmsh modify sys db systemauth.primaryadminuser value admin
