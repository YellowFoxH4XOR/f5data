Description

It is possible to viewing ASM per-virtual CPU usage via the CLI.

Environment

ASM (including Advanced WAF).

Cause

None.

Recommended Actions

This can be done with the following command:

tmctl -f /var/tmstat/blade/asmplugin asm_cpu_util_stats

BIG-IP Advanced WAF/ASM 15.x and later

This will show policy_name_crc and the vs_name. It is obvious what the vs_name is; the policy_name_crc is an internal ASM reference. To see what policy_name_crc maps to what policy, try a mysql query from the CLI:

mysql -B -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'SELECT account_id,policy_name_crc,policy_name from DCC.ACCOUNTS ORDER BY account_id'

BIG-IP Advanced WAF/ASM 14.x and earlier

This will show account_id and the vs_name. It is obvious what the vs_name is; the account_id is an internal ASM reference. To see what account_id maps to what policy, try a mysql query from the CLI:

mysql -B -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'SELECT account_id,policy_name from DCC.ACCOUNTS ORDER BY account_id'

Additional Information

CPU usage is reported in "ticks". See K10095 for more details.
