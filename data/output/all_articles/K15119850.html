K15119850: cookie 'grafana_sess' without secure attribute

Type
Support Solution
Published
2022-06-15
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K15119850

Description

The cookie 'grafana_sess' in HTTP response of BIG-IQ doesn't include the secure attribute.

Environment

  • BIG-IQ

Cause

Bug ID 1017981 

Recommended Actions

  1. Edit /usr/local/grafana/conf/custom.ini, and add a line [session] before cookie_secure = true
    [session]
    cookie_secure = true
  2. Restart grafana
    bigstart restart grafana

Additional Information

None.
