K000149443: Does a connection get closed when the certificates are changed or rotated?

Description

I want to know if there is a connection closed when a certificate is rotated on the F5® Distributed Cloud (XC) HTTP Load Balancer.

Environment

  • F5® Distributed Cloud HTTP Load Balancer
  • Certificates

Answer / Recommended Actions

Yes, any time a new certificate is presented to a client (i.e. even a certificate with the same CN but different serial number and expiration date), the client's browser may need to be reloaded to validate the new certificate.

However, a significant service disruption to your client base *is not expected* from changing and/or renewing the certificate on a Load Balancer, whether through automation or manual means.
