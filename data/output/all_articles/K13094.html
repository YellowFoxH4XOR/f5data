Issue

Error Message

01080038:5: Modifying variable <bigdb variable>

In this error message, note the following:

  • <bigdb variable> is the name of the affected bigdb variable

For example:

01080038:5: Modifying variable 'configsync.localconfigtime'

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The Bigdb.LogLevel bigdb variable is configured with the value of info.
  • A ConfigSync operation is performed on a BIG-IP redundant system.

During a ConfigSync operation, the bigdbd process on the BIG-IP system that receives the configuration modifies the BigDB.dat database. When the log level of the bigdbd process is set to info, it logs the described message to the /var/log/ltm file for each modified bigdb variable. The log level of the bigdbd process is configured using the Bigdb.LogLevel bigdb variable and the default value is warning.

Note: Beginning in BIG-IP 10.1.0, the bigdbd process is removed from the BIG-IP system. For more information, refer to K12584: The bigdbd process was removed from BIG-IP software.

Impact

None. The message is expected when the bigdb log level is set below the default value of warning.

Recommended Actions

You can prevent the bigdbd process from logging these messages by resetting the Bigdb.LogLevel bigdb variable to the default value. To do so, reset the Bigdb.LogLevel bigdb variable back to its default value of warning by typing the following command from the command line:

bigpipe db Bigdb.LogLevel warning
