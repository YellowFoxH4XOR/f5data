Description

Accessing iAppsLX GUI page "iApps >> Package Management LX" directs users to another page "iApps >> Application Services : Applications LX" and shows various errors.

Currently, it is known to show these three types of errors on GUI.

  • The iApp LX sub-system is currently unresponsive.
  The JavaScript sub-system is currently unavailable. Please open TMSH or ssh shell and try restarting restnoded. Also look for errors in /var/log/restnoded/restnoded.log.
  The REST sub-system is currently unavailable. Please open TMSH or ssh shell and try restarting restjavad. Also look for errors in /var/log/restjavad.log


  • remoteSender:<ip of client browser>, method:POST
  [400] remoteSender:<ip of client browser>, method:POST


  • Failure to assign ownership of item <id> for /mgmt/shared/iapp/package-management-tasks/<id> - Must provide groupName

Environment

  • User tries to access iAppsLX GUI page: iApps >> Package Management LX

Cause

The issue is known to occur when /config/f5-rest-device-id is an empty file. In very rare circumstances like an unexpected power cycling of BIG-IP without graceful shutdown, the file /config/f5-rest-device-id could be corrupted. As an indication of the issue, restjavad daemon logs a message like below when it starts up. This issue is tracked by ID 1014233.

[SEVERE][5][<date time> UTC][RestWorkerHost] Invalid machineId argument 'WAS-EMPTY':Invalid UUID string: WAS-EMPTY

Recommended Actions

  1. Review contents of /config/f5-rest-device-id file. Usually, machineID is in the format of xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.

  • Try restarting restjavad daemon with following command and check /var/log/restjavad.0.log

    # bigstart restart restjavad

  • If a message like below is shown, you need to remove the /config/f5-rest-device-id file and restart restjavad daemon to re-generate a valid machineID file. 
    [SEVERE][5][<date time> UTC][RestWorkerHost] Invalid machineId argument 'WAS-EMPTY':Invalid UUID string: WAS-EMPTY

  • Resolve the issue by running these commands.

    # rm -f /config/f5-rest-device-id
    # bigstart restart restjavad
