Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator fails to assign request objects to a leaf node when the header value is greater than 512 bytes. As a result, those request objects do not benefit from WebAccelerator features such as Intelligent Browser Referencing, MultiConnect, or Content compression.

F5 Product Development tracked this issue as CR125131 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.
