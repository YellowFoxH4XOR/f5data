Known Issue

This is the result of a known issue. If a user has the FirePass webtop open in multiple browser windows or tabs, or the user opens a Portal Access favorite launched in a separate browser window, the inactivity timeout configured on the Device Management : Security : Timeouts page may fail to terminate the user’s session after a period of inactivity.

For this issue to occur, the user must select the Click here to continue session link in the first inactivity timeout pop-up window. The pop-up window closes, and when the second inactivity timeout pop-up window opens, the timeout countdown will loop. For example, if the inactivity timeout is set to 3 minutes, the second inactivity timeout pop-up window displays a countdown starting at 2 minutes, 50 seconds. Once the countdown reaches 2 minutes, it resets to 2 minutes, 50 seconds and begins the countdown again. This loop continues until the user logs out of the FirePass controller, or clicks the Click here to continue session link in a subsequent inactivity timeout pop-up window.

Inactivity timeouts are configured on the Device Management : Security : Timeouts page. The group inactivity timeout setting overrides the global inactivity timeout setting.

Note: For more information about inactivity timeouts, refer to K3106: Configuring server-side session timeouts.

F5 Product Development is tracking this issue as ID 319129 (formerly CR106904).
