K000093009: Changing vWire members from tagged interface to untagged failed

Type
Support Solution
Published
2022-12-06
Updated
2022-12-07
Source
https://my.f5.com/manage/s/article/K000093009

Description

You are trying to replace tagged VLAN with untagged VLAN in vWire bundleand, however, it fails and the following error message can be seen:

  • java.sql.SQLException: General error: 01071c35:3: The VLAN (/Common/vWire_TP_vlan_10_2_207) has an untagged interface while the VLAN (/Common/vWire_TP_vlan_10_1_206) has a tagged interface. Interfaces of VLANs that are in the same 'virtual-wire' VLANGROUP (/Common/TP_VLAN_10) must have the same taggedness. in statement [SET TRANSACTION END] at com.f5.hsqldb.Util.createSqlException(Unknown Source)

Environment

  • DDoS Hybrid Defender provisioned (without LTM)
  • vWire configured with tagged VLANs

Cause

DDoS Hybrid Defender is limited to a simple interface where many of the LTM objects are concealed, so even if the interface was changed from tagged to untagged, not all properties of the vWire would be visible, and the configuration mismatch could cause the above error.

 

 Recommended Actions

Delete the existing vWire bundle via GUI and create a new one with untagged interfaces.

Additional Information

None.
