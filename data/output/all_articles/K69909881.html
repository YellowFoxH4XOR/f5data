Description
      Slot continuously re-starting monpd

Environment

  • Viprion
  • new blade was inserted

Cause
        BIG-IP Analytics statistics database corrupted

Recommended Actions

  1. Impact of procedure: The following procedure may remove all Application Visibility and Reporting data and reset the MySQL database.
  • Log in to the BIG-IP bash command line
  • ssh to the effected slot.
    • ssh slot<x>
  • touch /var/avr/init_avrdb
  • tmsh restart /sys service monpd
            This should create a new avr database on the effected slot.
