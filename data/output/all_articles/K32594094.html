Description

If Windows devices have Windows Applocker running, this may block the BIG-IP Edge Client from running any auto-updates.
This may prevent users from being able to connect to the Edge Client.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client

Cause

Windows AppLocker does not allow execution of software within the %TEMP% directory on the Windows device.
This prevents execution of the InstallerControl_setup.exe that is required to run for Edge Client auto-updates, as a copy of BIG-IP Edge Client runs from %TEMP% folder.

Recommended Actions

  1. You can disable the Component Update setting by setting it to 'No' in the connectivity profile on the BIG-IP. 
    • Then re-install the Edge Client on client Windows devices. 
    • Ensure that it is installed with admin privileges.
  2. Disable Windows AppLocker on the client Windows device to allow for the InstallerControl_setup.exe to run during the Edge Client auto-update

Additional Information

Delete an AppLocker rule
