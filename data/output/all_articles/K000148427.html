K000148427: Error when adding R5000 provider into Central Manager

Applies to

Source

Description

You are unable to connect to two appliances using the same wildcard certificate. This issue may manifest as connection failures or authentication errors, and you may encounter the error message: SHARED-00001: Internal server error.

Environment

  • Big-IP NEXT CM

Cause

Not supported.

Recommended Actions

  • Assign individual device certificates to each device hosting Big-IP NEXT Instances.
