Known Issue

Description

The BIG-IP APM system may not properly process JavaScript for traffic that crosses between domains or protocols.

This issue occurs when all of the following conditions are met:

  • A user generates client-side traffic by using the Google Chrome browser.
  • The web application page contains dynamic scripts.
  • The web application page is accessed from a different domain or protocol.

Note: Dynamic scripts are created as strings from the client side, and then evaluated using JavaScript functions such as eval(), Function(), or document.write(inlineScriptTag).

Impact

Dynamic scripts fail to execute for the Google Chrome browser, and cause the web application to malfunction.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Dynamic scripts fail to execute for pages that are accessed from a different domain or protocol using the Google Chrome browser.
  • An error message that appears similar to the following example is displayed in the browser error console:

    Uncaught SecurityError: Blocked a frame with origin "https://www.sitedomain1.com" from accessing a frame with origin "http://www.sitedomain2.com". The frame requesting access has a protocol of "https", the frame being accessed has a protocol of "http". Protocols must match. cache-fm.js:326

    Note: In this console error message, the domain changes from sitedomain1 to sitedomain2 and the protocol changes from https to http.
