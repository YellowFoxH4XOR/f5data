Issue

Error Message

warning tmm[<PID>]: 01230002:4: Interface <#>.<#>: link is down

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (tmm) process.
  • <#> is the interface number.

For example:

warning tmm[24378]: 01230002:4: Interface 0.4: link is down

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The tmm process on the BIG-IP system exits.

The system logs this message when internal interfaces used to communicate with F5 internal High-Speed Bridges (HSB) transition from up to down in TMM, and report to the MCP. This is not a spontaneous link failure, but a controlled action, when the tmm process exits. For example, the system generates this message when issuing the bigstart restart tmm command.

This message will appear once for every internal interface when the tmm process restarts.

Impact

There is no impact; this message is informational for an internal link status.

Recommended Actions

There is no corresponding message when the internal interface comes back up. You can check the status of the interface using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To check the interface status, use the following command syntax:

    show /net interface -hidden <interface>

    For example, to check the status of internal interface 0.1, type the following command:

    show /net interface -hidden 0.1

    The command output appears similar to the following example:

    ------------------------------------------------------------------
    Net::Interface
    Name Status Bits Bits Pkts Pkts Drops Errs Media
    In Out In Out
    ------------------------------------------------------------------
    0.1 up 3.9M 2.6M 6.2K 3.9K 6 0 10000T-FD
