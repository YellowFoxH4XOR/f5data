F5 Networks has recently imposed restrictions for distributing a third-party code library used in the BIG-IP WebAccelerator. As a result, BIG-IP WebAccelerator systems that are licensed April 13, 2009 or later will not be granted a license for BIG-IP WebAccelerator Module software versions prior to 9.4.7.

If you attempt to license a BIG-IP WebAccelerator system (including StrongBox and evaluation systems) running a software version prior to 9.4.7,  the license server will respond with an error message that appears similar to the following example:

Unable to grant license key:  Error 51131, Web Accelerator Module Incompatibility detected.  Please upgrade to BIG-IP version 9.4.7 or later.

BIG-IP WebAccelerator systems that have been successfully licensed and activated prior to April 13, 2009 will be able to re-license for any BIG-IP software version that supports the BIG-IP WebAccelerator. 

To prevent StrongBox license activations from failing, F5 Networks strongly recommends that you upgrade all StrongBox systems that are intended for use with the BIG-IP WebAccelerator to version 9.4.7 before any new StrongBox demo licenses are applied.

Important: RMA replacement systems that are replacing a system that was licensed with BIG-IP WebAccelerator prior to April 13, 2009 will be allowed to license the replacement BIG-IP WebAccelerator for any software version that supports the BIG-IP WebAccelerator.

Note: After April 13, 2009, if you have a business need to license a new BIG-IP WebAccelerator system with a software version prior to 9.4.7, contact F5 Networks Technical Support.

For information about upgrading to BIG-IP WebAccelerator version 9.4.7 or later, refer to the BIG-IP WebAccelerator Release Notes.

For information about how to download software, refer to K167: Downloading software from F5 Networks.
