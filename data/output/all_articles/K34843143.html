Topic

You should consider using this procedure under the following condition:

  • You want to enable the BIG-IQ system to support a newly published Azure BIG-IP Virtual Edition (VE) image version in the Azure cloud environment.

Description

This article explains how to modify the restjavad properties to enable BIG-IQ 7.1.0 to support the latest image version for BIG-IP VE in the Azure Marketplace.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a valid Azure cloud environment configuration on the target BIG-IQ system.
  • You are using the BIG-IQ system to deploy a new BIG-IP VE device to the Azure cloud environment.
  • You have Advanced Shell (bash) access to the BIG-IQ system with administrator credentials.

Procedures

Starting in BIG-IQ 7.1.0 by default, the restjavad properties file does not contain configuration stanzas for customizing the Azure environment on image versions. The system has a default list of the supported environment built-in and updated on each new BIG-IQ release.

To view the supported list of BIG-IP VE versions, you can use the BIG-IQ system interface and navigate to Applications > ENVIRONMENTS > Cloud Environments, and select the BIG-IP Image Name drop-down list.

Adding a new image version number

You can customize the restjavad properties file to support a new image version for Azure BIG-IP VE on the BIG-IQ system. To modify the file, perform the following procedure:

Impact of procedure: You must restart the restjavad process after you modify the property file as it will interrupt BIG-IQ services. F5 recommends performing this procedure only during a scheduled maintenance period.

  1. Log in to bash on the BIG-IQ system.
  2. Save a backup copy of the restjavad property file by entering the following command:

    cp -a /var/config/rest/config/restjavad.properties.json /shared/tmp/restjavad.properties.json.backup_K34843143

  3. Use a file editor to edit the /var/config/rest/config/restjavad.properties.json property file.
  4. Look for the azure section in the file. In BIG-IQ 7.1.0, the Azure configuration stanza appears similar to the following example: 
        "azure" :
    {
        "ssgMonitoring" :
        {
            "groomingIntervalSec": 86400,
            "monitorIntervalMS": 120000,
            "workflowTimeoutSeconds": 9000
        },
        "configsyncAddrPollIntervalMS": 60000,
        "configsyncAddrPollTries": 20,
        "dscsyncPollIntervalMS": 120000,
        "dscsyncPollTries": 15,
        "provisioningCheckPollIntervalMS": 120000,
        "checkProvisioningPollTries": 20,
        "asmCheckPollIntervalMS": 120000,
        "checkAsmPollTries": 20,
        "retryDMALimit": 50,
        "retryDMAIntervalMS": 20000
    }

  5. To add new image version, add the images configuration stanza within the Azure stanza, above the ssgMonitoring line entry.

    For example, you want to add BIG-IP 15.1.0.2 to the images configuration stanza:

            "images" :
        {
             "includeImageVersions": [ "15.1.002000" ]
        },

    Important: You must include the trailing comma ( , ) in the remaining configuration stanzas.

    After you add the images stanza, the azure section appears similar to the following example:

        "azure" :
    {
        "images" :         
        {
            "includeImageVersions": [ "15.1.002000" ]         
        },
        "ssgMonitoring" :
        {
            "groomingIntervalSec": 86400,
            "monitorIntervalMS": 120000,
            "workflowTimeoutSeconds": 9000
        },
        "configsyncAddrPollIntervalMS": 60000,
        "configsyncAddrPollTries": 20,
        "dscsyncPollIntervalMS": 120000,
        "dscsyncPollTries": 15,
        "provisioningCheckPollIntervalMS": 120000,
        "checkProvisioningPollTries": 20,
        "asmCheckPollIntervalMS": 120000,
        "checkAsmPollTries": 20,
        "retryDMALimit": 50,
        "retryDMAIntervalMS": 20000
    }
  6. After you save the changes, you must restart the restjavad service by entering the following command:

    tmsh restart /sys service restjavad

    Once the BIG-IQ system resumes service, you will be able to see the newly added Azure BIG-IP VE version when creating a new cloud environment for Azure.
