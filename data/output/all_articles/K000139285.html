K000139285: BIG-IP HTTP2 profile removes empty value headers sent by client

Type
Support Solution
Published
2024-04-15
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000139285

Description

BIG-IP removes HTTP headers with empty values when HTTP2 profile is used in full-proxy Virtual Server configuration.
When Client sends below HTTP/2 request as an example:
---------------
:method: GET
:path: /
:scheme: https
:authority: 192.0.2.14
user-agent: curl/7.81.0
accept: */*
x-example-header:                    <<--- No value 
---------------

BIG-IP will send it towards pool member without 'x-example-header' HTTP header:
---------------
:scheme: https
:authority: 192.0.2.14
:method: GET
:path: /
user-agent: curl/7.81.0
accept: */*
                                               <<--- Header removed
---------------

Environment

  • BIG-IP LTM
  • Full-proxy Virtual Server
  • HTTP2 profile

Cause

Bug ID 1567173

Recommended Actions

Remove HTTP2 profile from Virtual Server configuration.

Additional Information

Engineering Hotfix is available on request
