Description

You can install your Flexible Consumption Program (FCP) for licensing BIG-IP Virtual Editions (VEs) by activating a Catalog (CAT) key on the BIG-IQ.

To watch a video demo of this procedure, go to  Automatically Install ELA Licenses for BIG IP VEs using BIG IQ.

Environment

  • BIG-IQ License Manager or Centralized Manager
  • BIG-IP Virtual Edition (VE)
  • FCP contract
  • Catalog (CAT) key

Cause

On BIG-IQ, you need to activate the CAT key to assign its license offerings to BIG-IP VEs. The CAT key includes a bundle of license offerings for BIG-IP VE.

Recommended Actions

  1. Log in to BIG-IQ.
  2. Select Devices.
  3. Go to License Management > Licenses.
  4. Select Add License (Do not select AddRegKeyPool).

  1. In License Name, enter a name for your subscription.
  2. In Base Registration Key, paste the Catalog key that F5 emailed to you or download it from MyF5 Subscriptions.
  3. In Activation Method, select Automatic.

    Note: To automatically activate the FCP, your BIG-IQ must be configured to traffic to the internet.

  4. Select Activate.
  5. Select Accept.

    On the Licenses page, Licenses Type is Pending until the system confirms your license. After the system confirms your subscription, the License Type displays as Utility.

    Under Status, the system displays the number of offerings in your ELA subscription and the progress of downloading them.

  6. To see the list of the offerings in your subscription, select the license name.

    The system displays your offerings and the status for downloading them. The downloading process takes from 10 to 15 minutes, depending on your internet connection and the F5 license server. 

    Once the license offerings are activated on the BIG-IQ, you can assign licenses to managed or unmanaged BIG-IP VE devices. For information about license assignment, refer to K02061834: How to license BIG-IP from BIG-IQ License Manager using FCP

Additional Information

If you get the message "Error 5113, F5 registration key is not compatible with the detected platform." please see article K52740161: Activation failed: Error 51133, F5 registration key is not compatible with the detected platform
