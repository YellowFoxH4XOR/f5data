K000150932: CA Certificate Not Displayed Correctly on BIG-IQ with AS3 Declaration

Type
Support Solution
Published
2025-04-19
Updated
2025-04-19
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000150932

Description

When using an AS3 declaration to configure a certificate with the chainCA property on BIG-IQ, the CA certificate is incorrectly displayed as [object Object] in the BIG-IQ GUI.

Environment

  • AS3
  • Configure a certificate with chainCA property 

Cause

F5 tracks the issue as ID 1856421.

Recommended Actions

You can open a support case and request the fix for ID 1856421.

Additional Information

None
