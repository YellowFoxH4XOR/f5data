Known Issue

A BIG-IP configuration that contains data group objects may take longer to save than expected.

This issue occurs when the following condition is met:

  • The configuration contains a large number (more than 1,000) of data group objects.
For example, a configuration that does not contain data groups or just a few data groups may take about 5 seconds to save. However, a similar-sized configuration that contains more than 1,000 data group objects may take longer than 60 seconds to save.

Impact

Increased save times may cause some operations to time out when saving a configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Saving the configuration takes longer than expected.
  • Automatic configuration saves may encounter issues if you attempt a subsequent save before the previous save has completed.
