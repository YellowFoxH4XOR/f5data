Known Issue

Pool member connection limits do not apply when OneConnect profiles are configured with a host source mask.

This issue occurs when all of the following conditions are met:

  • Your configuration includes one or more TCP virtual servers with the following configuration:
    • An associated OneConnect profile.
    • The source address translation is set to either SNAT or Automap.
  • You have configured the OneConnect profile's Source Prefix Length setting with a value of 255.255.255.255, or host mask.
  • You have configured connection limits for pool members. 

Impact

Pool members receive a greater number of connections than the configured connection limit.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Pool members receive a number of connections greater than the configured limit.

Workaround

To work around this issue, you can configure a less strict Source Prefix Length setting, or match a greater number of source IP addresses. To do so, refer to K85357500: Managing connection reuse using OneConnect source mask (12.x - 16.x).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
