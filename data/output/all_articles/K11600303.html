Description
The getcrc utility is used to generate the ASM Main cookie name associated with a specific ASM Policy on the BIG-IP. The BIG-IP will generate a unique ASM main cookie for each domain and/or path in the traffic monitored by the ASM Policy. Depending on the software version, the getcrc utility may not recognize domain and path along with their flag, resulting in an illegally formatted ASM Main cookie name as the result.

Example:
# /usr/share/ts/bin/getcrc -td /Common/example_policy test.f5.com
16475372738770339372

Environment

  • BIG-IP with ASM provisioned
  • ASM Policy associated with Virtual Server
  • One or more domains and/or paths provided by the server in return traffic to client

Cause
The getcrc utility did not properly process domains and paths however this was corrected in ID941249. Any software version without ID941249 fixed will provide an illegal value for the ASM Main cookie name if provided with a domain and/or path and the appropriate flag.

Recommended Actions

Upgrade the BIG-IP to a software version containing the bugfix for ID941249.

Additional Information
ID946081 corrects the getcrc display version and is recommended to be included in any software version containing the fix for ID941249.
