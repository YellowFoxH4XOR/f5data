As part of its mitigation mechanism, the ASM and the Layer 7 DoS protection mechanism needs to inject javascript into client HTTP responses in order to protect an application, or identify a legitimate client from a script, a bot or a malicious user.


For this to happen, this URLs have to be detected as HTML URLs or "Qualified URLs" which means they qualify for Javascript injection.
 

Description

The following statement briefly describes the criteria for which a URL becomes qualified.
A URL becomes qualified after receiving 10 consecutive response which matches all three rules:

  • Response code is not 100 Continue
  • Must contain 'Content-Type: text/html' response header
  • Must contain the "<html" tag within the first 2KB of the body of the response.

A single response not matching all three rules will remove the URL from the qualified URLs list.

Recommendations

When configuring or implementing any feature that requires javascript injection you should consider the following factors:

  • Ensure that you have at least received 10 responses on that URL to get qualified 
  • Ensure the other 3 conditions above are in place

Once these are in place, clients will begin to receive javascript as needed for attack mitigation.
