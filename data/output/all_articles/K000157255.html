K000157255: After upgrading to v17.5.x, getting errors: async_lookupCallback:702 Error processing URL ... Status Code:S_ErrArg

Type
Support Solution
Published
2025-10-31
Updated
2025-12-16
Applies to
  • BIG-IP
  • BIG-IP PEM: 17.5.0, 17.5.1
Source
https://my.f5.com/manage/s/article/K000157255

Description

After upgrading to v17.5.x administrators may observe excessive error messages in /var/log/wr_urldbd.out even when the domain exists, and BrightCloud queries succeed.

 

root@(big-ip-v17.5)(cfg-sync Standalone)(Active)(/Common)(tmos)# show ltm urlcat-query \*.example.com

--------------------------------------------------------

URL : *.example.com

--------------------------------------------------------

URL-CATEGORIES(Combined) : Travel Business_and_Economy

URL-CATEGORIES(Webroot) : Uncategorized

URL-CATEGORIES(Custom) :

URL-CATEGORIES(Cloud) : Travel Business_and_Economy

 

/var/log/wr_urldbdownload.log

...

WR_URLDBD: Sep 04 13:32:24.341:Tid(32165):async_lookupCallback:702 Error processing URL:*.example.com and Status Code:S_ErrArg

WR_URLDBD: Sep 04 13:32:24.346:Tid(32176):async_lookupCallback:702 Error processing URL:*.example.com and Status Code:S_ErrArg

 

 

Environment

  • System upgrading to v17.5.x
  • URL category queries with * to the BrightCloud server

 

Cause

The change in logging behavior is due to the integration of the new BrightCloud SDK version 5.x in BIG-IP v17.5.x. We are tracking this issue under ID 2048325.

 

 

Recommended Actions

The behavior has changed with the new BrightCloud SDK. The extent of excessive logging depends on the customer environment. If this issue causes any service impact, please open a support ticket to request a fix.
