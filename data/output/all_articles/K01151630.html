Topic

Starting with the release of BIG-IP 12.1.0, BIG-IP APM add-on licenses for BIG-IP appliances are throughput-based and are available for multiple throughput scenarios.

Description

BIG-IP APM for appliances hardware comes with unique Base, Add-on, and Best licensing specific to the BIG-IP APM platform. You can augment the BIG-IP APM Base licensing with Add-on licenses for CCU (SSL-VPN) and Secure Web Gateway (SWG). The following table outlines appliance platform-based licensing.

Important: Application of a new license and license activation may be required to obtain the licensed features presented in this article.

The BIG-IP APM system uses different types of licenses, depending on the type of resource you access.

  • The system uses an Access Session license when you start any new session.
  • The system uses an SSL-VPN User Connectivity License (CCU) when you are assigned one or more BIG-IP APM resources with tunnel-type access.
  • The system uses an SWG license when you employ a URL filtering service or an SWG service.

Beginning in September 2019, for BIG-IP APM standalone, GBB (Best) or BIG-IP APM add-on license, after you re-activate the license on your BIG-IP system, you may observe that the value of the total access sessions and total swg limited sessions increases to a large value (10M, 20M, and so on) as displayed in the following example output:

# tmsh show apm license
--------------------------------------------
Global Access License Details:
--------------------------------------------
 total access sessions: 10.0M
 [...]
 total swg limited sessions: 10.0M

This occurs so that the number of total access sessions and total swg limited sessions are not restricted based on licensing. Note, however, that the values (10M, 20M, and so on) do not indicate your BIG-IP APM system's capacity to handle the number of sessions. You must continue performing capacity and sizing tests before you deploy your BIG-IP system in production. This licensing change does not affect the current CCU and SWG license enforcement.
