Description

Unable to configure SNMPv3 users auth and priv as sha256 or aes256 in DO declaration.

For example: sha256 and aes256 are not valid in DO schema:

....

"snmpUser1": {

"class": "SnmpUser",

"authentication": {

"protocol": "sha256",

"password": "pass1W0rd!"

},

"privacy": {

"protocol": "aes256",

"password": "P@ssW0rd"

},

.....

 

Environment

  • BIG-IP v16.x
  • DO 1.37
  • SNMPv3

Cause

Declarative Onboarding 1.37 release does not support sha256 or aes256 in the SNMPv3 declaration.

Recommended Actions

This issue is resolved in 1.38.
