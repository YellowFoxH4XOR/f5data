Issue

If a FirePass controller is configured in an active/standby configuration, otherwise known as a failover pair, and there is minimal activity on the active member, the following error message will be logged every 175 minutes:

"[Tue Sep 16 16:02:58 2008] [error] [client 192.168.1.2] handshake failure: /usr/local/uroam/firepass/my"

Note: The IP address 192.168.1.2 is the IP address of the standby (passive) member.

This log message does not indicate any configuration, stability, or security issue. This message is categorized as an error, but it can be safely ignored. This log only appears if the Device Management: Maintenance: Logs HTTP Error Log option is set to Error or below.
