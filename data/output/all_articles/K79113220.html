K79113220: How to replace GTM Server's virtual server address using tmsh

Description

You have a GTM Server (for ex. BIG-IP LTM) that has Virtual Servers inside. You wanted to change the Virtual Server's Address (not the Translation address) using tmsh. You cannot change this setting using the GUI (Configuration Utility).

Environment

  • BIG-IP GTM
  • GTM Server (Virtual Servers)
    • DNS > GSLB > Servers > Server List > (Server Object) > Virtual Servers

Cause

The GTM Server's Virtual Server address field cannot be modified using the GUI.

Recommended Actions

On the command line use the following command:

# tmsh modify gtm server <GTM Server Name> virtual-servers modify { /<Partition>/<Virtual Server Name> { destination <address>:<port> } }

Additional Information

None.
