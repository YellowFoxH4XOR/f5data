K000148032: How do I limit the roles for SSO authenticated users?

Description

You have SSO authentication enabled in F5 XC and you want to limit the roles provided in the platform.

Environment

  • F5® Distributed Cloud
  • SSO
  • Users and Roles

Resolution/Answer

if you are expecting to restrict user access to f5xc (ie, allow only few users from their org), this needs to be done at the authentication app level. For example, in Azure, The administrator can configure AD user groups with the required set of users and assign them to the auth app. We can provide more details if this is the requirement.

Additional Information

If SSO is enabled, and the user is allowed to authenticate in the configured authentication app, after the first successful login, a corresponding user entry will be created in our platform with default roles assigned. This is expected behavior.

With default roles, you will not be able to access any of the workspaces and the administrator has to explicitly assign the required roles to allow.
