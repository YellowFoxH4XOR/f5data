Description

  • The partition /appdata is filled up to 100%
  • mysql service restarts continuously
  • The following error message can be seen on var/lib/mysql/mysqld.err

    190228 8:21:17 [ERROR] mysqld: Can't open file: './AVR/AVR_STAT_FW_NAT_TRANS_DEST_H.frm' (errno: 24)
    190228 8:45:36 [ERROR] mysqld: Can't open file: './AVR/AVR_STAT_ASM_NETWORK_T.frm' (errno: 24)
    190228 9:12:22 [ERROR] mysqld: Can't open file: './AVR/AVR_STAT_ASM_NETWORK_T.frm' (errno: 24)

Environment

  • ASM

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 773925

Recommended Actions

Upgrade to a software version where the Bug ID 773925 is fixed. As an immediate workaround you can perform the following precedure

  1. Connect to CLI
  2. Delete AVR files

    rm -rf /var/lib/mysql/AVR

  3. Restart AVR database

    touch /var/avr/init_avrdb

  4. Restart monpd

    tmsh restart /sys service monpd

  5. Open /etc/my.cnf with a text editor
  6. Change the value of the 'open_files_limit' parameter from 2500 to 5000.
  7. Add the following parameter (right after 'open_files_limit'):

    table_open_cache=2000

  8. Restart MySQL

    bigstart restart mysql

    Note: This workaround does not survive upgrade. It must be reapplied after every upgrade until the upgraded version contains a fix.
