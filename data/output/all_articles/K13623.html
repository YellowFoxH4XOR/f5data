Known Issue

You cannot modify or delete a policy object type that you have created using the BIG-IP WebAccelerator Configuration utility, when the policy type identifier you have created contains a space.

Impact

You cannot delete or modify policy object types.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You see the error Deleting Object Type failed when attempting to delete one of these objects.
  • When opening an object for editing, the fields are unpopulated and you are unable to make any changes.

Workaround

To work around this issue, you can manually edit the bigip.conf configuration file to remove the offending spaces.  To do so, perform the following procedure:

Impact of workaround: Re-loading the BIG-IP configuration may affect current sessions and F5 recommends that you perform this task during a maintenance window.

  1. Log in to your BIG-IP system command line as the root user.
  2. Make a backup of your bipgip.conf file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.SOL13623

  3. Using a text editor, edit the /config/bigip.conf file.
  4. Find the entry which begins with wam object-type and contains the identifier that has a space in it.  

    For example:

    wam object-type "/Common/documents.test type" {
        code 53274
        compression disabled
        description "test type"
        extensions {
            xyz { }
        }
        mime-types {
            text/xyz { }
        }
    }

  5. Using your editor, remove the space from the wam object-type as shown in the following example:

    wam object-type "/Common/documents.testtype" {
        code 53274
        compression disabled
        description "test type"
        extensions {
            xyz { }
        }
        mime-types {
            text/xyz { }
        }
    }

  6. Save the changes.
  7. Re-load the configuration using tmsh, by typing the following command:

    tmsh load /sys config

If you encounter any errors, copy your backup file to /config/bigip.conf and start again. 

You may now edit or delete the modified object type in the Configuration utility.
