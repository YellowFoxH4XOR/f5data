K000133046: F5 DNS returns truncated answer after upgrade to 14.1.4.4 and later

Type
Support Solution
Published
2023-03-17
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP DNS: 14.1.4
Source
https://my.f5.com/manage/s/article/K000133046

Description

  • The F5 DNS gives a truncated answer (UDP) after upgrading to 14.1.4.4 and later.

Environment

  • 14.1.4.4 and later
  • BIG-IP DNS
  • BIND (zone runner)

Cause

This is caused by the EDNS buffer size change in BIND 9.11.22 (14.1.4.3) and 9.11.31 (14.1.4.4), the EDNS buffer size was 4096 (9.11.22) and changed to 1232 (9.11.31).


 Recommended Actions

  • If you have a TCP listener, no additional action is needed, when receiving a truncated DNS answer, the client should retry over TCP, as mentioned in RFC 2181.
  • If you only have a UDP listener, create a TCP listener to allow the client to retry over TCP to get the complete DNS response.
