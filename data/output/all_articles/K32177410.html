Description

When trying to remove or delete a port in self-allow list using tmsh, you are encountering the error below:
01020036:3: The requested self port default (/Common/self-allow X XXXX) was not found.

Environment

  • BIG-IP LTM
  • Deleting a port/service from self-allow list using the command:
    tmsh modify net self-allow defaults delete { <protocol>:<port> }
  • Encountered an error:
    01020036:3: The requested self port default (/Common/self-allow X XXXX) was not found.
  • The protocol and port are actually still in the self-allow list

Cause

Unknown at the time of publication

Recommended Actions

Use vi to delete/remove the port

Example (removing tcp port 8443):

# vi bigip_base.conf
...
net self-allow {
    defaults {
        igmp:0
        ospf:0
        pim:0
        tcp:161
        tcp:22
        tcp:4353
        tcp:444
        tcp:53
        tcp:8443 <---- remove this line
        udp:1026
        udp:161
        udp:4353
        udp:520
        udp:53
    }
}
...
