Known Issue

Importing local users from CSV files may stall.

This issue occurs when all of the following conditions are met:

  • You attempt to import local users by using the 'Import from CSV' option.
  • The CSV file contains a large number of user entries.

Impact

The import process takes an excessive amount of time to complete or fails to complete.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The import process is slow or never completes.
  • When importing CSV files, the Configuration utility becomes unavailable.
  • JavaScript errors appear when importing CSV files.

Resolution

Workaround

To work around this issue, you can reduce the number of users in the CSV files and attempt to restart the import process.
