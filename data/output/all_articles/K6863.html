K6863: BIG-IP GTM systems in the same data center will fail to communicate if one GTM system resides on the inside of the firewall and the other GTM system resides on the outside of the firewall

Known Issue

This is the result of a known issue. iQuery communication between BIG-IP GTM systems in the same data center will fail if one GTM system resides outside the firewall with no translated Self IP addresses specified, and the second GTM system resides inside the firewall with translated Self IP addresses specified.

F5 Product Development tracked this issue as CR70401, CR70402, and CR70580 and it was fixed in BIG-IP GTM 9.2.4 and 9.3. For information about upgrading, refer to the BIG-IP GTM Release Notes.
