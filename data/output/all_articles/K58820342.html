Issue

Error Message

010717e3:3: Client SSL profile must have RSA certificate/key pair.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You attempt to configure a Client SSL profile with a digital signature algorithm (DSA) or Elliptic Curve Cryptography (ECC)/Elliptic Curve Digital Signature Algorithm (ECDSA) certificate/key pair and no RSA certificate/key pair.

In version prior to 14.1.0, client SSL profiles cannot be configured with only DSA or ECC/ECDSA certificates. In BIG-IP version 14.1.0 and later, a client SSL profile still requires at least one certificate/key pair, but the RSA type certificate/key pair is no longer mandatory.

Impact

In version prior to 14.1.0, you must configure an RSA certificate/key pair on all Client SSL profiles.

Recommended Actions

  • For BIG-IP versions prior to 14.1.0, refer to the following actions:
    • Configure an RSA certificate/key pair in addition to the DSA or ECC/ECDSA certificate/key pair you want to use.
    • If you want to prevent use of RSA certificates, configure the cipher string or cipher group in the Client SSL profile to disable RSA authentication.
