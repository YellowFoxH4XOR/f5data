K000140640: Unable to make any configuration changes via F5OS GUI - no effect after spinning blue circle

Applies to

Source

Description

Trying to make changes to F5OS configuration via the GUI.

After hitting Save, page gets stuck on the spinning blue circle for ~30s or longer. No error occurs, but the changes do not take effect.

Environment

  • F5OS-C
  • F5OS-A

Cause

This issue might happen if there is a lock on a confd database.

In this situation, the /var/F5/system/log/devel.log (F5OS-A), /var/confd/log/devel.log (F5OS-C controller), or /var/F5/partitionX/log/devel.log (F5OS-C partition) file contains a large number of entries similar to the following:

confd HA: locking cdb_db got {error,locked}

Bug ID1388525 is one possible known root cause.

  • Bug ID 1388525: Partition configuration database locks up, preventing database changes

Recommended Actions

Look for known issues affecting your version of F5OS (for example, ID1388525) and apply documented workarounds or fixes, if available.

Open a case with F5 Support for further investigation, if required.
