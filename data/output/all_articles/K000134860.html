Description

An issue has been discovered in GitLab CE/EE affecting only version 16.0.0. An unauthenticated malicious user can use a path traversal vulnerability to read arbitrary files on the server when an attachment exists in a public project nested within at least five groups.

 

Environment

  • BIG-IP ASM
  • Gitlab

 

Cause

None.


Recommended Actions

CVE-2023-2825 can be mitigated using directory traversal violation. 

Please ensure to have "Directory traversals" violation enabled for the policy in question

 

Additional Information

Given the severity of the vulnerability, the immediate action recommended by GitLab is to upgrade GitLab installations running on version 16.0.0 to the latest release, 16.0.1. This release patches the identified vulnerability, effectively closing the avenue for a potential security breach.

It’s important to note that GitLab installations on earlier versions than 16.0.0 are not affected by this vulnerability.
