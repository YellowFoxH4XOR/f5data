Known Issue

Parsing XML content that contains Unicode Direction Formatting may trigger a false positive violation.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM security policy is configured with the content profile Malformed XML data.
  • Content processed by the security policy includes XML code that uses one of the following 3-byte character XML Directional Formatting Codes:
     

    • %E2%80%8E = 202a Left-To-Right Embedding   

    • %E2%80%8F = 202b Right-To-Left Embedding

    • %E2%80%AC = 202c POP Directional Formatting

      Following is an example of the formatting:

      data=%3Cphone%3E%3C!%5BCDATA%5B0012062726500%E2%80%AC%5D%5D%3E%3C%2Fphone%3E

Impact

This issue triggers the BIG-IP ASM violation for Malformed XML data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system presents a blocking page if you have configured blocking and enabled the Use XML Blocking Response Page setting.
  • Your BIG-IP ASM system logs a Malformed XML data violation error for the request.
