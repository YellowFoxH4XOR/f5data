Description

When attempting to add F5OS devices (VELOS controllers or rSeries systems) to BIG-IQ Centralized Management, the following error message appears:

  • "The system returned an unexpected error (400 Bad Request). Premature end of chunk coded message body: closing chunk expected"
  • This error occurs during the device addition process in the BIG-IQ GUI under Devices > F5OS > Platform / Devices. While most F5OS devices can be added successfully, certain devices consistently return this error message.

Environment

  • Product: BIG-IQ Centralized Management
  • Version: 8.4.0
  • Managed Devices: F5OS controllers (VELOS chassis partitions or rSeries systems)
  • Network: Bi-directional connectivity on port 443 between BIG-IQ and F5OS devices
  • Configuration: F5OS controllers in high availability (HA) configuration with floating and individual controller management IP addresses
  • Hostname: No underscores in hostnames


Cause

The error occurs when attempting to add an F5OS device using the standby controller's management IP address or an individual (non-floating) controller management IP address instead of the floating controller management IP address.

When BIG-IQ attempts to communicate with a standby controller directly, the connection fails because:

  • Direct access to the standby controller's API is not fully supported for device management operations
  • The standby controller cannot properly respond to device discovery and management requests from BIG-IQ
  • The communication is interrupted prematurely, resulting in the "Premature end of chunk coded message body" error


Answer/Recommended Actions

Use the Floating Controller Management IP Address

Always use the floating controller management IP address when adding F5OS devices to BIG-IQ. The floating IP automatically connects to the active controller, ensuring proper communication.

  1. Identify the floating management IP address for your F5OS controller
    • For VELOS: This is the floating IPv4 address configured for the chassis partition
    • For rSeries: This is the floating management IP address for the system
  1. In BIG-IQ, navigate to Devices > F5OS > Platform / Devices
  2. Click Add VELOS/rSeries System
  3. Enter the following information:
    • Device Name: A descriptive name for the device
    • FQDN/IP Address: Enter the floating management IP address (not individual controller IPs)
    • Username: Admin username for the F5OS controller
    • Password: Admin password for the F5OS controller
    • Click Submit & Add


Additional Information

F5OS Controller High Availability

  • F5OS controllers operate in an active-standby HA configuration
  • The floating management IP address always points to the active controller
  • Direct access to standby controller management interfaces (GUI, CLI, API) is not supported for device management operations
  • Using individual controller management IPs instead of the floating IP may result in connection failures

Best Practices

  • Always use floating management IP addresses for F5OS device management in BIG-IQ
  • Document which IP addresses are floating vs. individual controller IPs in your environment
  • Verify the active controller before troubleshooting connectivity issues
  • Collect QKView files from both BIG-IQ and F5OS controllers if issues persist
