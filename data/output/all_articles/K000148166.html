Description

  • You would like to know what means the definitions of attack types used by Web Application Firewall.
  • Your application is using custom attack types.
  • You received a violation and need to know what it means. 

Environment

  • F5® Distributed CloudLoad Balancer
  • Web Application Firewall

Cause

  • Violation names do not contain a full description

Resolution/Answer

Violation attack types on Web Application Firewall layer enabled by default are:

 

Violation Name Description
VIOL_EVASION_APACHE_WHITESPACE

Detects attempts to bypass security filters using non-standard or excessive whitespace characters often interpreted differently by Apache servers.

VIOL_HTTP_PROTOCOL_BAD_HTTP_VERSION

Indicates a request with an invalid or unsupported HTTP version.

VIOL_HTTP_PROTOCOL_BAD_HOST_HEADER_VALUE

The Host header in the HTTP request contains an invalid or malicious value.

VIOL_HTTP_PROTOCOL_BAD_MULTIPART_PARAMETERS_PARSING

Issues with parsing multipart parameters in the HTTP request indicating potential evasion or malformed data.

VIOL_EVASION_BARE_BYTE_DECODING

Detects attempts to decode bare byte values in a way that might evade standard security measures.

VIOL_HTTP_PROTOCOL_CRLF_CHARACTERS_BEFORE_REQUEST_START

Presence of CRLF (carriage return and line feed) characters before the actual start of the HTTP request which might indicate an attempt to manipulate request processing.

VIOL_EVASION_IIS_BACKSLASHES

Attempts to use backslashes in a manner specific to bypass security measures on IIS servers.

 

VIOL_EVASION_IIS_UNICODE_CODEPOINTS  Use of Unicode code points in requests to evade security filters specifically on IIS servers.
VIOL_FILETYPE  The request includes a file type that is not allowed or is potentially harmful.
VIOL_METHOD  The HTTP method used in the request is not allowed or recognized.
VIOL_JSON_MALFORMED  The JSON data in the request is malformed indicating potential attempts to break or bypass parsing logic.
VIOL_XML_MALFORMED  The XML data in the request is malformed indicating potential attempts to break or bypass parsing logic.
VIOL_MALFORMED_REQUEST  The entire HTTP request is malformed making it potentially malicious or unintended.
VIOL_MANDATORY_HEADER 
A required HTTP header is missing from the request.
VIOL_ASM_COOKIE_MODIFIED 
 		An application security management (ASM) cookie has been modified indicating potential tampering.
VIOL_HTTP_PROTOCOL_MULTIPLE_HOST_HEADERS 
 		The request contains multiple Host headers which is against HTTP protocol standards.
VIOL_EVASION_MULTIPLE_DECODING 
 		Attempts to evade security filters by encoding data multiple times.
VIOL_HTTP_PROTOCOL_NO_HOST_HEADER_IN_HTTP_1_1_REQUEST  An HTTP 1.1 request is missing the mandatory Host header.
VIOL_HTTP_PROTOCOL_NULL_IN_REQUEST 
 		Presence of null characters in the request which can be an attempt to manipulate or evade security filters.
VIOL_EVASION_PERCENT_U_DECODING 
 		Attempts to use percent-u encoding to bypass security filters.
VIOL_REQUEST_MAX_LENGTH 
 		The request exceeds the maximum allowed length.
VIOL_HTTP_PROTOCOL_SEVERAL_CONTENT_LENGTH_HEADERS 
 		Multiple Content-Length headers in the request which is against HTTP protocol standards.
VIOL_HTTP_PROTOCOL_UNPARSABLE_REQUEST_CONTENT 
 		The content of the request is unparsable indicating potential evasion or corruption.
VIOL_FILE_UPLOAD_IN_BODY 
 		The request contains a file upload in the body which is not allowed.
VIOL_FILE_UPLOAD General violation related to file uploads indicating potential issues or non-compliance.
VIOL_EVASION_DIRECTORY_TRAVERSALS 
 		Attempts to use directory traversal techniques to access restricted files or directories.
VIOL_COOKIE_MODIFIED 
 		A cookie has been modified indicating potential tampering.
VIOL_HTTP_PROTOCOL_CONTENT_LENGTH_SHOULD_BE_A_POSITIVE_NUMBER 
 		The Content-Length header should contain a positive number and the request violates this rule.
