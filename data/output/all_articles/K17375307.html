Issue

Error Message

01870011:3: 0x570000ee8700:<session id>: SWG Scheme not assigned to main access policy

In this error message, note the following:

  • <session id> is the session ID used for the request.

For example:

01870011:3: 0x570000ee8700:8039a011: SWG Scheme not assigned to main access policy

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file
Description

This message occurs when all of the following conditions are met:

  • You have created a Secure Web Gateway (SWG) Per-Request Policy access policy.
  • The main access profile's access policy, assigned to the SWG virtual server, does not have an SWG Scheme Assign agent configured.

Impact

Requests processed by the access policy cannot access the destination resource.

Recommended Actions

Configure the main access profile's access policy that is assigned to the virtual server to include the SWG Scheme Assign agent. For more information, refer to the Per-Request Policy Concepts and Examples chapter of the BIG-IP Access Policy Manager: Secure Web Gateway Implementations guide.
