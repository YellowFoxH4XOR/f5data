K000151799: Newly created local user is unable to login into BIG-IQ

Type
Support Solution
Published
2025-06-12
Updated
2026-02-18
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.3.X, 8.4.1, 8.4.0, 8.3.0
Source
https://my.f5.com/manage/s/article/K000151799

Description

  • BIG-IQ is configured with local and remote authentication.
  • You create new local user.
  • You are unable to login with with new created local user and var/log/secure shows:
    Jun 5 13:05:00 BIG-IQ.local notice pam-authenticator[27968]: pam_unix(rest:auth): authentication failure; logname= uid=0 euid=0 tty= ruser= rhost= user=new_user
    Jun 5 13:05:05 BIG-IQ.local info rest(pam_audit)[27968]: User=new_user tty=(unknown) host=(unknown) failed to login after 1 attempts (start="Wed Jun 4 13:08:27 2025" end="Thu Jun 5 13:05:05 2025").
    Jun 5 13:05:05 BIG-IQ.local info rest(pam_audit)[27968]: 01070417:6: AUDIT - user new_user - RAW: rest(pam_audit): User=new_user tty=(unknown) host=(unknown) failed to login after 1 attempts (start="Thu Jun 5 13:05:05 2025" end="Thu Jun 5 13:05:05 2025").

Environment

  • BIG-IQ CM
  • Local User Authentication
  • Remote authentication

Cause

This is because the "systemauth.source" db varialble is set to radius, tacacs, etc. instead of local.

Recommended Actions

Change db variable value to local.

tmsh modify sys db systemauth.source value local

Additional Information

To view current setting or value in "systemauth.source"

tmsh list sys db systemauth.source value
