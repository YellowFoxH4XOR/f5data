K64102400: How to clear Edge Client cache on Windows

Type
Support Solution
Published
2024-02-27
Updated
2024-02-27
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K64102400

Description

Edge Client retains session information, cookies or other history resulting in unexpected behavior such as auth loops, lack of ability to test options, or failure to allow for reconfiguration.

Environment

  • APM
  • Edge Client
  • SAML/OAuth
  • Cookies

Cause

  • Edge Client stores cookies associated with Auth source

Recommended Actions

Edge Client uses Wininet libraries you need to clear Internet Explorer cache & cookies

  • The Cache is located in C:\Users\<username>\AppData\Local\Microsoft\Windows\INetCache
    Note: INetCache is a hidden directory. You may need to type or paste the full path on Windows Explorer.
  • Alternatively, you can also go to Control Panel > Internet Options, under Browsing History, select Settings > View files.
