K000150780: SSLO Guided Configuration overwrites manual changes to SSLO objects on deployment

Description

SSLO Guided Configuration overwrites manual changes to SSLO objects on deployment


Environment

SSLO


Cause

The Guided Configuration creates a JSON file, which is used by the REST API to create all of the objects for the given topology. If changes are made outside of the Guided Configuration, it has no way to know about them and will overwrite them on next deployment.


Recommended Actions

It is not recommended that you make manual changes to SSLO objects unless it cannot be avoided. In this case you should ensure that re-adding these changes after each deployment is part of your procedures.
