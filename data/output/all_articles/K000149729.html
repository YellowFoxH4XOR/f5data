K000149729: AD Auth error "Cannot contact any KDC for realm (-1765328228)"

Type
Support Solution
Published
2025-04-16
Updated
2025-04-16
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP APM: 16.1.5
Source
https://my.f5.com/manage/s/article/K000149729

Description

 You have deployed AD Authentication on APM and users fail to be authenticated with error "Cannot contact any KDC for realm (-1765328228)"

Environment

  • APM provisioned
  • Access policy configured with an AD Auth agent
  • AD server configured with a pool.

Cause

When AD server is configured to use a pool, AS-REQ sent by APM to KDC sets source ip address with a floating ip address instead of a self ip address.

Recommended Actions

Verify no Firewall is dropping packets coming with that floating ip address and KDC includes it in its routing table.

Additional Information

None.
