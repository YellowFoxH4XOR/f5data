Known Issue

Administrative access using the Configuration utility fails to establish.

This issue occurs when all of the following conditions are met:

  • You attempt to access the Configuration utility through a reverse proxy.
  • The reverse proxy does not write the Referer header to match the destination BIG-IP host name or IP address.
  • You enter your BIG-IP administrative access credentials.

Impact

The connection to the Configuration utility fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to access the Configuration utility, you observe an error message that appears similar to the following example:

    Authentication required!

    This server could not verify that you are authorized to access the URL "/tmui/logmein.html". You either supplied the wrong credentials (e.g., bad password), or your browser doesn't understand how to supply the credentials required.

    In case you are allowed to request the document, please check your user-id and password and try again.

    Error 401

  • The system logs an error message in the /var/log/httpd/httpd_errors file similar to the following example:

    err httpd[<pid>]: [error] [client <ip address>] Login failed because of invalid referer header., referer: https://<big-ip address>:<port>/tmui/login.jsp?msgcode=2&

Resolution

Status

F5 Product Development has assigned ID 643459 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can configure the reverse proxy to write the Referer header to match the destination host name or IP address to ensure access to the Configuration utility.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
