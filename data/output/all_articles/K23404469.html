K23404469: BIG-IQ Data Collection Device is not receiving the FPS alert

Published
2021-08-11
Updated

Status

Applies to

Source
https://my.f5.com/manage/s/article/K23404469

Description

BIG-IQ Data Collection Device is not receiving  the FPS alert from BIG-IP device
Following errors are noted in /var/log/restjavad.0.log

[ERROR][30 Jun 2021 16:07:13 ][/cm/websafe/tasks/listeners/5b2610f3-dc80-43f9-baaf-87a509c0bd4e/workerHttpListenerTaskWorker] Failed POST to ES: java.net.ProtocolException: status:400, body:{"error":{"root_cause":[{"type":"illegal_argument_exception","reason":"Alias [websafe_writer] has more than one indices associated with it [[websafe_2021-06-04t00-00-00+0700, websafe_2021-06-29t00-00-00+0700]], can't execute a single index op"}],"type":"illegal_argument_exception","reason":"Alias [websafe_writer] has more than one indices associated with it [[websafe_2021-06-04t00-00-00+0700, websafe_2021-06-29t00-00-00+0700]], can't execute a single index op"},"status":400}

Environment

  • BIG-IQ Data Collection Device
  • BIG-IP is configured to send FPS alert to BIG-IQ Data Collection Device
  • BIG-IP FPS

Cause

Unknown at time of publication

Recommended Actions

  1. Login into BIG-IQ Centralized Management using root
     
  2. Enter below command as a whole. Below command will remove one of the index from websafe writer.

    #curl -XPOST 'http://localhost:9200/_aliases' -d '{ "actions" : [ { "remove" : { "index" : "websafe_2021-06-04t00-00-00+0700", "alias" : "websafe_writer" }}]}'

    Note: Replace 'websafe_2021-06-04t00-00-00+0700' with actual index name 

    For Example, for the error log mentioned below there are two indices are associated for websafe_writer. Hence remove one of the index from websafe_writer.

    [ERROR][30 Jun 2021 16:07:13 ][/cm/websafe/tasks/listeners/5b2610f3-dc80-43f9-baaf-87a509c0bd4e/workerHttpListenerTaskWorker] Failed POST to ES: java.net.ProtocolException: status:400, body:{"error":{"root_cause":[{"type":"illegal_argument_exception","reason":"Alias [websafe_writer] has more than one indices associated with it [[websafe_2021-06-04t00-00-00+0700, websafe_2021-06-29t00-00-00+0700]], can't execute a single index op"}],"type":"illegal_argument_exception","reason":"Alias [websafe_writer] has more than one indices associated with it [[websafe_2021-06-04t00-00-00+0700, websafe_2021-06-29t00-00-00+0700]], can't execute a single index op"},"status":400}

    [root@bigiqcm1.example.com:Active:Standalone] config # curl -XPOST 'http://localhost:9200/_aliases' -d '{ "actions" : [ { "remove" : { "index" : "websafe_2021-06-25t00-00-00+0800", "alias" : "websafe_writer" }}]}'

    Output will be {"acknowledged":true}
     
  3. Then proceed to check the FPS alert in BIG-IQ Centralized Management
