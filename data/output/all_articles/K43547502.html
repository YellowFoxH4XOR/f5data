K43547502: Windows client gets ''wrong value'' error when token length exceeds 160 characters

Type
Support Solution
Published
2022-10-15
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K43547502

Description

An automated script is used to generate a token for authentication. 

Environment

You may encounter the below symptoms, when the token exceeds 160 characters:

  • Windows client receive "Error: Wrong value!"
  • Windows client fail authentication
  • Linux clients still work

Cause

The BIG-IP password length cannot exceed 160 bytes (characters).

Recommended Actions

In the automated script, limit the token length to 160 characters or less.
