Source

Description

APM AAA Active Directory authentication failed with an error message under /var/log/apm as shown below: 
AD module: authentication with 'abc' failed: KDC has no support for encryption type, principal name: j.smith@example.com. Please verify Active Directory and DNS configuration.

Environment

  • APM
  • SWG
  • AAA

Cause

Kerberos keytab file is having out-of-date encryption type, It could be caused by Active Directory servers have been updated but new keytab file is not uploaded to BIG-IP system.

 Recommended Actions

  1. Create new keytab file with appropriate encryption type from AD server.
    • Creating a new keytab file with the ktpass command
  2. Upload new keytab file to BIG-IP system
    • Uploading a keytab file to a Kerberos authentication server object
