K000148978: Removed slot interfaces status showing uninitialized in the vCMP guest.

Description

Removed slot interfaces status showing uninitialized in the vCMP guest. Performing the vCMP guest reboot can't remove the uninitialized interfaces from the removed slot.

Environment

vCMP Guest

Cause

The text-based configuration (such as /config/bigip.conf) and the running configuration loaded in the mcpd process from the binary configuration image are out of synchronization.

Recommended Actions

Perform the mcpd force load on the particular vCMP guest.

K13030: Forcing the mcpd process to reload the BIG-IP configuration
