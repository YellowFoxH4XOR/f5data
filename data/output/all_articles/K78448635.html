Known Issue

The BIG-IP system unexpectedly removes or renames the high availability (HA) peer's certkeychain of the Client SSL profile after a configuration synchronization (ConfigSync).

This issue occurs when all of the following conditions are met:

  • You have configured more than one certkeychain in the Client SSL profile.
  • You have modified the certkeychain content of the Client SSL profile.
  • You have performed a ConfigSync.

Impact

If a Client SSL profile is missing the certkeychain, the profile may be unable to handle some kinds of SSL traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If a Client SSL profile is missing the certkeychain, the profile is unable to handle some kinds of SSL traffic. For example, if the Client SSL profile originally has an EC key/cert but loses it, then the profile can no longer handle an SSL connection using EC cipher suites.
