K93701708: Extra 60f characters inserted into HTTP response by CSPM injection

Support Solution
Published
2021-12-16

  • BIG-IP Analytics: 16.0.X, 15.1.9, 15.X.X, 16.0.1, 16.0.0, 15.1.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.0.X, 15.0.1, 15.0.0, 15.1.4
Source
https://my.f5.com/manage/s/article/K93701708

Description

Extra 60f  characters inserted by CSPM injection.

Environment

  • BIG-IP AVR
  • Virtual server
  • HTTP profile
  • HTTP Analytics profile with "Page Load Time" enabled
  • HTTP Compression profile

Cause

When the origin web server sends back a chunked response and the response is compressed by the BIG-IP, the javascript code inserted by the BIG-IP is not inserted properly. The chunked header for the CSPM snippet becomes part of the uncompressed response content.

Recommended Actions

Change sys db avr.cspm.inject.location to after_head.

tmsh modify sys db avr.cspm.inject.location { value after_head }
tmsh save sys config
