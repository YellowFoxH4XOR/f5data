Topic

The OneConnect feature increases network throughput by efficiently managing connections created between the BIG-IP system and pool members.

Note: For more information, refer to K7208: Overview of the OneConnect profile.

Description

Obtaining OneConnect statistics for the OneConnect profile

You can obtain OneConnect profile statistics using the Configuration utility, the Traffic Management Shell (tmsh), or through SNMP queries.

The following table provides the statistical definitions:

ConnectionsDefinition
Currently IdleThe number of currently idle connections in the connection pool. These are connections that are available for reuse.
MaximumThe maximum number of idle connections in the connection pool.
Total ReusesThe total number of times server-side connections have been reused. Typically, connections will be reused more than once, and each connection reuse will count separately toward the total.
NewThe total number of times new server-side connections have been created.

Procedures

  • Using the Configuration Utility
  • Using the Traffic Management Shell
  • Using SNMP queries

Using the Configuration utility

To view the statistics for a virtual server's associated OneConnect profile, perform the following steps:

  1. Log in to the Configuration utility.
  2. Under Main, click Local Traffic.
  3. Navigate to Virtual Servers and select the appropriate virtual server under Name.
  4. Click Statistics.
  5. In the Profiles section, use the Select Profile drop-down menu to select the OneConnect profile.

To view the aggregated OneConnect profile statistics for the BIG-IP system, perform the following steps:

  1. Log in to the Configuration utility.
  2. Under Main, click Statistics.
  3. Navigate to Module Statistics > Local Traffic.
  4. From the Statistics Type drop-down menu, select Profiles Summary.
  5. Click View next to the OneConnect profile type.

Using the Traffic Management Shell (tmsh)

To obtain a OneConnect profile's statistics, use the following tmsh command syntax:

tmsh show ltm profile one-connect <profile_name>

For example, if the profile name is one_connect_test, the command and command output appear similar to the following example:

tmsh show ltm profile one-connect one_connect_test

-----------------------------------------
Ltm::OneConnect Profile: one_connect_test
-----------------------------------------
Virtual Server Name  N/A

Connections
  Current Idle         0
  Maximum             10
  Total Reuses        25
  New                425

Using SNMP queries

To obtain OneConnect statistics using SNMP, log in to the command line and query one or more of the following object identifiers (OIDs) to obtain OneConnect statistics from the F5-BIGIP-LOCAL-MIB MIB:

SNMP OIDDescription
F5-BIGIP-LOCAL-MIB::ltmConnPoolProfileStatConnectsThe total number of times new server-side connections have been created
F5-BIGIP-LOCAL-MIB::ltmConnPoolProfileStatCurSizeThe current number of idle connections in the connection pool
F5-BIGIP-LOCAL-MIB::ltmConnPoolProfileStatMaxSizeThe maximum number of idle connections in the connection pool
F5-BIGIP-LOCAL-MIB::ltmConnPoolProfileStatReusesThe total number of times server-side connections have been reused

For example, to determine the total number of times new server-side connections have been created for virtual servers using a OneConnect profile, you can type the following command:

snmpwalk -v2c -c public localhost F5-BIGIP-LOCAL-MIB::ltmConnPoolProfileStatConnects
