Description

Unable to remove device from HA with below error : 

01071761:3: Cannot delete device (/Common/<Device Name>)  from device group (/Common/ha-group) because it is used by HA order on traffic group (/Common/traffic-group-1)

Device GUI doesn't show the option for traffic group.

Environment
  • BIG-IP devices in HA configuration 

Cause

Devices belonging to HA traffic group cannot be removed from HA configuration 
 

cm traffic-group /Common/traffic-group-1 {
    app-service none
    auto-failback-enabled true
    auto-failback-time 60
    default-device none
    description none
    ha-group none
    ha-load-factor 1
    ha-order {
        /Common/host1
        /Common/host2
    }
    is-floating true
    mac none
    partition Common
    unit-id 1
}

Recommended Actions

  1. Put the device which is to be removed and not processing traffic into force offline state.
  2. Run below command using command line interface bash mode on the active device: 
      tmsh modify cm traffic-group traffic-group-1 ha-order none
       
       3. Remove the devices from HA group if they are still present from GUI
