K08783190: Error Message: 010c0009:6: Lost connection to mcpd - reestablishing

Type
Knowledge
Published
2017-05-04
Updated
2025-04-03
Applies to
  • BIG-IP
Source

Issue

Error Message

info sod[<PID>]: 010c0009:6: Lost connection to mcpd - reestablishing.

In this error message, note the following:

  • <PID> is the process ID for the sod process

For example:

info sod[<PID>]: 010c0009:6: Lost connection to mcpd - reestablishing.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The sod process is unable to communicate with the mcpd process

Impact

Device status and configuration updates are not possible while the sod process is unable to communicate with the mcpd process.

Recommended Actions

The sod process will attempt to automatically reestablish the connection to the mcpd process. If this action fails, you may be able to alleviate the issue by restarting BIG-IP services. To do so, perform the following procedure:

Impact of procedure: The following procedure restarts all services and will disrupt traffic processing. The system may fail over to a standby system if configured for high availability (HA).

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart all services, type the following command:

    restart /sys service all
