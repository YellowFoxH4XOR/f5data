Known Issue

This is the result of a known issue. The ospfd process leaks memory equivalent to the entire OSPF LSA database for an OSPF neighbor. This issue occurs if the neighbor restarts the database exchange while the exchange is already in progress.

F5 Product Development is tracking this issue as CR139688.

This issue does not affect the BIG-IP version 9.6.x and 10.x software branches; these versions run a later version of of ZebOS.

This issue was fixed in Hotfix-BIGIP-9.4.8-407.0-HF4 issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
