K000141516: ASM blocks whitelisted URLs configured with literal characters

Type
Support Solution
Published
2024-10-24
Updated
2024-10-24
Source
https://my.f5.com/manage/s/article/K000141516

Description

If the URL is input with literal characters such as %20 and 0x20, ASM cannot match these literal characters against the allowed URLs configured in the policy. With no match in the URL list, ASM triggers the violation "illegal url"

 

Examples of literal explicit URL

"/downloads/speedpro0x20installer.exe" 
"/downloads/speedpro%20installer.exe"

 

Environment

ASM
URL Violation

 

Cause

Misconfiguration

 

Recommended Actions

Input the URL with a typed space instead of literal characters

"/downloads/speedpro installer.exe" (note the space)

Correct configuration can be confirmed on GUI with the characters outlined

 

Additional Information

None
