Known Issue

This is the result of a known issue. Beginning in BIG-IP 10.1.0, VLAN objects can reside in administrative partitions. During a single configuration file (SCF) import operation, if a VLAN has a name that is the same as another VLAN in a different administrative partition, the SCF import operation fails with an error message that appears similar to the following example:

01070726:3: VLAN vlan1 in partition partitionA cannot reference VLAN member vlan1 T0.1 in partition partitionB

F5 Product Development is tracking this issue as ID 223704 (formerly CR131332).

Workaround

You can work around this issue by first resetting your BIG-IP system to factory defaults before importing the desired SCF. To do so, type the following command that applies to your version:

  • BIG-IP 10.x:

    bigpipe import default

  • BIG-IP 11.x:

    tmsh load /sys default

Note: For more information about administrative partitions, refer to K7230: Overview of administrative partitions.

Note: For more information about configuring administrative partitions, refer to the Administrative Partitions chapter in the BIG-IP System: User Account Administration for your software version.
