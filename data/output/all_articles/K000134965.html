K000134965: Client custom certificate with intermediate certificate not working in BIG-IP DNS HTTPS health check

Type
Support Solution
Published
2023-07-06
Updated
2023-07-06
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.3
Source
https://my.f5.com/manage/s/article/K000134965

Description

HTTPS DNS monitor with custom certificate, key and intermediate certificate is not probing in rare situations.

Environment

  • BIG-IP DNS
  • HTTPS monitor with custom certificate and key
  • Intermediate certificate present

Cause

Undetermined

Recommended Actions

Use external monitor instead of DNS HTTPS monitor.

The example of script to attached to external monitor:

  • For the workaround to work, need to extract intermediate Cert and CA and put in crt for --cacert.
  • Update cert name accordingly, path 172.16.0.1:443 and needed output

curl --cacert '/config/filestore/files_d/Common_d/certificate_d/:Common:ExampleCA' --cert '/config/filestore/files_d/Common_d/certificate_d/\:Common\:Example' --cert-type PEM --key '/config/filestore/files_d/Common_d/certificate_key_d/:Common:Example' -k https://172.16.0.1:443 2>/dev/null | grep -E -i welcome

Explanation:
cacert - is point to cert which contain intermediate cert and CA
cert - is point to cert which contain the actual cert
key - is point to key

#!/bin/sh
# these arguments supplied automatically for all external pingers:
# $1 = 172.16.0.1
# $2 = 443
# $3 and higher = additional arguments
#
# In this script, $3 is the directory to GET
# $4 = Welcome
#
pidfile="/var/run/https_tls_sessionticket_workaround.$1..$2.pid"
if [ -f $pidfile ]
then
kill -9 `cat $pidfile` > /dev/null 2>&1
fi
echo "$" > $pidfile
#node_ip=`echo $1 | sed 's/::ffff://'`
curl --cacert '/config/filestore/files_d/Common_d/certificate_d/:Common:ExampleCA' --cert '/config/filestore/files_d/Common_d/certificate_d/\:Common\:Example' --cert-type PEM --key '/config/filestore/files_d/Common_d/certificate_key_d/:Common:Example' -k https://172.16.0.1:443 2>/dev/null | grep -E -i welcome > /var/tmp/logvs2
echo ${3} >> /var/tmp/logvs1
echo "nothing" >> /var/tmp/logvs1
echo ${4} >> /var/tmp/logvs1
echo ${5} >> /var/tmp/logvs1
if [ $? -eq 0 ]
then
rm -f $pidfile
echo "up"
else
rm -f $pidfile
if [ $? -eq 0 ]
then
rm -f $pidfile
echo "up"
else
rm -f $pidfile
fi
exit
