K000140175: BIGIP REST API allows re-creating UCS backup with same name

Type
Support Solution
Published
2024-06-28
Updated
2026-08-12
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000140175

Description

BIGIP issues no warning when re-creating a UCS backup with same file name via Rest API, Inadvertently replacing an existing UCS archive.


Environment

  • REST API
  • Recreating UCS archive

Cause

None


Recommended Actions

This is expected behavior, you receive a warning when replacing files on UI and CLI/TMOS but not on REST API.


Additional Information

None
