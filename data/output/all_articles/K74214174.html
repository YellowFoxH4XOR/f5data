Known Issue

You are unable to establish a VPN tunnel when using Windows Logon Integration.

This issue occurs when all of the following conditions are met:

  • The client systems connecting to the BIG-IP APM system have BIG-IP Edge Client major version 7171 installed from the APM Clients 7.1.7.1 package.
  • You use Windows Logon Integration to establish a dial-up VPN connection to the BIG-IP APM system.

Impact

BIG-IP APM end-users cannot establish a VPN tunnel using Windows Logon Integration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to establish a VPN tunnel after upgrading to APM Clients 7.1.7.1
  • Network logon fails and the Windows RAS subsystem reports a message similar to the following example:

    Connecting - Error 1471: Unable to finish the requested operation because the specified process is not a GUI process

  • Some client systems experience this issue intermittently while others can never complete network logon using Windows Logon Integration.
