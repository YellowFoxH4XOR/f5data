Question

  • Internet Routing Registry (IRR) is a database of Internet route objects.
    • What is a route: or route6: object?

Environment

  • F5 Distributed Cloud
  • Routed DDoS Protection

Answer

A route object is a Routing Policy Specification Language (RPSL) object used to describe an IPv4 prefix and the Autonomous System Number (ASN) authorized to originate it. A route6 object performs the same function for an IPv6 prefix.

  • A route: object defines an IPv4 prefix in CIDR notation.
  • A route6: object defines an IPv6 prefix in CIDR notation.
  • The origin: field identifies the originating Autonomous System, also known as the Origin AS.
  • Route and route6 objects are maintained by registered maintainers in an Internet Routing Registry, for example, MAINT-AS55002.
  • Route objects can be grouped together using route-set objects.
  • Route and route6 objects are commonly used by upstream and downstream Internet Service Providers to generate routing filters, especially in multi-homed environments where prefixes may be announced through more than one provider.
