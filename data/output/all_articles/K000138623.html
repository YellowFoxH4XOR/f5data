Description

Import of BIG-IQ is failing when Verified ID Type is different than address

Restjavad.0.log

[ERROR][31 Oct 2023 11:26:00 CET][/cm/adc-core/tasks/config-copy/e0ffecb1-2771-43fa-b07c-88dcdd828de6/worker AdcConfigCopyTaskWorker] Failed copying from source to target: java.lang.IllegalArgumentException: /Common/IKE_TEST: In main mode with preshared key authentication, id-type can only be address.

Environment

  • BIG-IQ CM
  • Importing configuration
  • IKEv2 peers config

Cause

ID1422461

Import Fails due to fact we do not support on BIG-IQ different values than address under Verified ID Type

Recommended Actions

Open support ticket to request fix for this issue.

Workaround

Reconfigure IKE pear to use address as peer  ID Type
