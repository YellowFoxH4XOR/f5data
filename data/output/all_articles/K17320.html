Known Issue

Attempts to delete virtual server objects may fail when sFlow polling is in progress.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration contains one or more sFlow receivers that are actively polled.
  • Your BIG-IP system contains a virtual server that references an HTTP profile.
  • You attempt to delete the virtual server object.

Impact

Users cannot delete virtual server objects when sFlow polling is in progress.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to delete a virtual server object, the system displays an error message similar to the following example:

    01070265:3: The Virtual Server (/Common/example_virtual) cannot be deleted because it is in use by a sflow http data source (9).

Workaround

There is no workaround for this issue. However, you can avoid this issue by removing the attached HTTP profile that has sFlow enabled before attempting to delete the affected virtual server.
