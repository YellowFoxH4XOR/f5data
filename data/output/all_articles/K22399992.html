Description

User may notice user account “svc_user” and assigned with administrator privilege. This account is not created by user.

Environment

  • BIG-IP VE 
  • Deployed in Microsoft Azure

Cause

The user account is created when instance is deployed using f5-azure-arm-templates or the instance deployed with Azure market place.

Recommended Actions

It is not recommended to delete svc_user account.

Additional Information

Github Template: https://github.com/F5Networks/f5-azure-arm-templates/blob/master/supported/failover/same-net/via-api/n-nic/existing-stack/byol/azuredeploy.json
Note:This link is valid at time of publication. Please reach out to F5 Support if requires further assistance. 

User svc_user gets created and its password is saved in the encrypted file.
CLOUD_LIB_DIR/f5-cloud-libs/scripts/createUser.sh --user svc_user --password-file /config/cloud/.passwd --password-encrypted;

User svc_user is being used for onboard.js which is first in the deployment process.
User svc_user is being used for network.js to get networking elements created.
User svc_user is being used for cluster.js to setup DSC and HA sync.
User svc_user is being used for failover script "failoverProvider.js" to move Elastic IP's during failover if Cloud Failover Extension (CFE) is not installed/configured on BIG-IP.
