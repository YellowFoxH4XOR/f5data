Known Issue

Description

Removing an interface from a trunk may fail. This issue occurs when all of the following conditions are met:

  • You attempt to modify a trunk using the Configuration utility.
  • You attempt to save a modification that includes removing and adding interfaces at the same time.

For example, while modifying a trunk configured with interfaces 1.4 and 1.5, you remove interface 1.4 and add interface 1.6. When you click the Update button, the Configuration utility returns an error message similar to the following example:

Some fields below contain errors. Correct them before continuing.

Additionally, the changes do not save.

Impact

You are unable to modify the trunk configuration.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to update a trunk configuration from the Configuration utility, a message similar to the following example appears:

    Some fields below contain errors. Correct them before continuing.
  • You are unable to save changes to a trunk configuration using the Configuration utility.

Workaround

To work around this issue, you can remove and add interfaces at separate times. First, remove the interfaces you do not want in the trunk and save the trunk configuration. Next, add the desired interfaces and save the trunk configuration.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
