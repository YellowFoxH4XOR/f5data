K05850234: EUD Test on VIPRION Chassis or Blades

Type
Support Solution
Published
2022-07-27
Updated
2025-06-19
Applies to
  • VIPRION Platforms
Source
https://my.f5.com/manage/s/article/K05850234

Description

  • All network cables and SFP modules must be removed before running these tests.
  • While it is not strictly required that you remove all other blades, F5 strongly recommends to do so.
    • If not removed; We recommend all other blades not being tested should be booted into EUD.
  • On the VIPRION platform, you must only run the EUD from the local console of the blade being tested.

Environment

  • Viprion Platforms

Cause

None

Recommended Actions

  • Running EUD on Blades:
    • If the blade that you want to test is powered on, halt it.
    • Power on the blade.
    • As the blade boots, press Esc when you see the countdown. The boot menu displays.
    • Use the arrow keys to highlight End User Diagnostics and press Enter. When the EUD starts, the EUD menu displays on the console.
    • Choose option [A] Running all blade tests. Console to other blades in turn. You can use AOM to redirect console connection from one blade to any other blade in the chassis. Select C --- Capture blade console
    • Run the option A for all blades and collect the outputB.
  • Running EUD on Chassis: Before you can run this test on the chassis:
    • At least two blades are required (the test scales up to 8 blades). Refer Additional Information section.
    • All blades installed in the chassis must be booted into EUD and sitting idle at the EUD menu.
      Note: Start the test only on one of the blades; the duration of the test is approximately two minutes per blade. Once the test has started, do not attempt to initiate tests from any other blades installed in the chassis.

Additional Information

  • To boot the other blades into EUD you need to move the USB with EUD software & console to next blade, reboot the blade and follow the process to get into EUD.
  • The same process has to be followed on all the blades.
  • Once all blades are booted into EUD then only you need to start the EUD test to complete EUD at Chassis level.
