Description

AS3 declaration fails with the following declaration failed response, while the declaration does not have any configuration that references the SNAT translation object.

        {
            "code": 422,
            "message": "declaration failed",
            "response": "01071468:3: SNAT translation address (/Common/x.x.x.x) is still referenced by SNAT (/Common/<snat_name>).",
            "host": "localhost",
            "tenant": "Common",
            "runTime": 2062
        }

Environment

  • BIG-IP
  • AS3 versions 3.46-3.50
  • SNAT object exists in /Common partition
  • AS3 declaration has a reference to any object in /Common partition

Cause

ID 1549541

Recommended Actions

Use the earlier version of AS3 for now until the issue is fixed in the upcoming AS3 release.

Additional Information

Below is an excerpt of declaration section of AS3 declaration, which may cause the issue when a SNAT object is configured in /Common. It includes a reference to an HTTP profile /Common/Shared/http_custom, which exists under /Common partition.

        "class": "ADC",
        "schemaVersion": "3.46.0",
        "id": "1549541-declaration-01",
