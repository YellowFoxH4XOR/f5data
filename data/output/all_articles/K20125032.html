Issue

Error Message

010717b3:4: Setting DHCP request-option to none can result in management-ip misconfiguration and loss of management connectivity

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP system is configured to provide Dynamic Host Configuration Protocol (DHCP) services.
  • You use the TMOS Shell (tmsh) to set the DHCP request option to none using a command similar to the following:

    tmsh modify sys management-dhcp sys-mgmt-dhcp-config request-options none

Request options specify the management options that the DHCP client on BIG-IP system requests from a DHCP server in the network. Setting request options to none could result in a the BIG-IP system not receiving configurations from the DHCP server.

Impact

The BIG-IP system experiences management IP misconfiguration and loss of management connectivity.

Recommended Actions

You can configure the DHCP server with the authoritative setting. If you do this, the server always provides a fixed set of configuration to to DHCP clients, regardless of the type of requests the server receives.
