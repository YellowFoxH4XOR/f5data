Known Issue

The IP Address Intelligence feature may fail to receive updates from the subscription service.

This issue occurs when the following condition is met:

  • Your BIG-IP ASM system is licensed for the IPI Subscription module.

The IP Address Intelligence feature allows an administrator to block requests that originate from denylisted IP addresses, which are updated by a subscription process. When you update a Secure Sockets Layer (SSL) certificate for BrightCloud, the subscription service fails for some devices.

Impact

The IP Address Intelligence feature contains outdated data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs error messages to the /var/log/ltm file that appear similar to the following example:

    err iprepd[5600]: 015c0004:3: Certificate verification error: 20
    err iprepd[5600]: 015c0004:3: nSendReceiveSsl failed SSL handshake

  • The IP Address Intelligence feature contains outdated data.

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can obtain the updated SSL certificate from BrightCloud and add it to the end of the certificate chain.
