Note: The BIG-IP LTM RAM Cache is also referred to as Hot Cache. The BIG-IP WebAccelerator cache is also referred to as disk Smart Cache and memory Smart Cache. Memory Smart Cache is also referred to as In Memory Cache (IMC).

The Maximum Age setting for the BIG-IP LTM RAM Cache (configured in the http-acceleration profile) must be shorter than the Maximum Age setting for the BIG-IP WebAccelerator cache (configured in the BIG-IP WebAccelerator acceleration policy). 

When the Maximum Age settings are configured properly, objects in the RAM Cache will be refreshed while still remaining in the Smart Cache.

Objects are promoted through the different caches in the following manner:

  • The initial request for a cacheable object received by the BIG-IP LTM is passed to the BIG-IP WebAccelerator and proxied to the origin server. The response from the origin server is served to the client and cached to the BIG-IP WebAccelerator cache, or Smart Cache disk. 
  • The next request for the object received by the BIG-IP LTM is passed to the BIG-IP WebAccelerator, the object is served from Smart Cache and promoted to memory Smart Cache, or IMC.
  • The next request for the object received by the BIG-IP LTM is passed to the BIG-IP WebAccelerator, the object is served from memory Smart Cache and promoted to the BIG-IP LTM RAM Cache. Subsequent requests for the object received by the BIG-IP LTM are served directly from the BIG-IP LTM RAM Cache and not passed to the BIG-IP WebAccelerator until the RAM Cache maximum age is reached.
  • When the RAM Cache maximum age is reached, the next request for the object will be passed to the BIG-IP WebAccelerator and served from Smart Cache, or proxied to the origin server and refreshed in the Smart Cache as appropriate.

If the Maximum Age settings are not configured properly, frequently requested objects may not remain in Smart Cache, resulting in inconsistent Intelligent Browser Referencing behavior.

Note: For information, refer to K9657: Inconsistent Intelligent Browser Referencing behavior.
