K17994145: Transfer BIG-IP ISO image files from the vCMP host to the guest using the BIG-IQ system

Type
Knowledge
Published
2021-04-02
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X, 6.X.X
Source

Topic

You should consider using this procedure under the following conditions:

  • You want to use the BIG-IQ system to upgrade the managed Virtual Clustered Multiprocessing (vCMP) guest.
  • The required ISO image file is stored in the vCMP host but not in the guest.

Description

When you use BIG-IQ Centralized Management to upgrade the managed vCMP guests, the BIG-IQ system has to transfer the required ISO image file if it is not presented in the target system. In case the available image on the vCMP guest is sourced from the host and not locally stored in the /shared/images directory, the BIG-IQ system pushes the required image file remotely to the target vCMP guest, and this may result in a slow transfer. You can resolve this issue by copying the required ISO image file from the vCMP host to the target vCMP guest using the BIG-IQ script management feature.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have administrative access to the BIG-IQ system.
  • Have administrative credentials for the managed BIG-IP vCMP system.

Procedures

Transfer BIG-IP ISO image files from the vCMP host to the guest using the BIG-IQ script management feature

You can transfer ISO image files that are located on the vCMP host to the vCMP guest by remotely running a file transfer script using the BIG-IQ script management feature. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the target BIG-IQ user interface.
  2. Go to Devices > SCRIPT MANAGEMENT > Scripts.
  3. Select Add.
  4. For Name, enter a name for the script.
  5. For Script, enter the bash script you would like to run on the target vCMP guest using the following syntax:

    #!/bin/bash

    IP=<vCMP_host>
    USERNAME=<username>
    PASSWORD=<password>
    ISO=<ISO_image_file_name>

    /usr/bin/expect <<EOF
    spawn scp -o StrictHostKeyChecking=no $USERNAME@$IP:/shared/images/$ISO /shared/images/
    expect "Password: "
    send "$PASSWORD\r"
    sleep 30
    expect eof
    EOF

    echo
    echo "transfer completed"

    ls -lrt /shared/images/

    echo
    echo "MD5 checksum:"
    md5sum /shared/images/$ISO

    echo
    echo "done"

    In the previous script, replace the following fields with the appropriate values:

    NameDescription
    <vCMP_host>The IP Address of the vCMP host
    <username>The administrative username of the vCMP host
    <password>The password of the administrative user
    <ISO_image_file_name>The name of the ISO image file stored in the vCMP host

    Note: To run the script, you must enable Advanced Shell (bash) on the target vCMP guest for the administrative user configured to communicate with the BIG-IQ system.
    Note: If your password has Linux special characters, such as $, they need to be escaped in the string such as this - 'password$123' needs to be 'password///$123'.

  6. Select Save & Close.
  7. Select the box of the newly created script.
  8. Select Run.
  9. For Name, enter a name for the script task.
  10. For Devices, select the target vCMP guest box on the Available list.
  11. To move the target device to the Selected list, select the right arrow icon.
  12. Select Run.
  13. To review the result, go to Devices > SCRIPT MANAGEMENT > Script Log.
  14. Ensure that the script status is finished and select the script name.
  15. To check the script log, select View Output.
