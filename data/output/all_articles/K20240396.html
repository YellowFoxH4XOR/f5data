K20240396: After installing icontrol, iRuleLX workspace is not accessible

Description

  • After installing icontrol, iRuleLX workspace is not accessible

Environment

  • LTM
  • iRuleLX
  • iControl
  • BIG-IP

Cause

  • Bug ID 764969
  • Change of behavior where ILX no longer supports symlinks in workspaces as of v14.1.0.

Recommended Actions

  • Determine package version
  • Remove installed npm

         # npm remove <NAME OF NODE PACKAGE>

  • Then install the same package with '--no-bin-links' option

         # npm install < NAME OF NODE PACKAGE TO INSTALL > --no-bin-links (eg. npm install ldapjs --no-bin-links)
