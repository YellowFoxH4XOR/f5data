K48923107: BIG-IQ TACACS+ SSH remote login access not working after enabling on GUI

Type
Support Solution
Published
2021-09-13
Updated
2025-06-17
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K48923107

Description

BIG-IQ TACACS+ authentication setup via GUI does not enable SSH TACACS remote authentication access.
If SSH TACACS+ remote authentication access is required, setup will need to be configured through TMSH.

Environment

  • BIG-IQ TACACS+ remote authentication
  • SSH access

Cause

This is an expected behavior.

Recommended Actions

Important: The workaround is verified as working on customer's environment. However, there is no official public facing supported documents for BIG-IQ SSH TACACS+ setup.

Follow K20400650 to setup TACACS authentication using command line.

Additional Information

None.
