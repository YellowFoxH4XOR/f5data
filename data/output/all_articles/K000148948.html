K000148948: Destination Unreachable From F5 GTM after AAAA query

Type
Support Solution
Published
2024-12-20
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000148948

Description

F5 DNS (GTM) does not have configured wideIPs for RR AAAA or any other options to resolve the AAAA query. F5 DNS is responding with ICMP Destination Unreachable (Port Unreachable) or ignoring AAAA RRs which causes a delay in resolving A RRs.

Environment

  • BIG-IP DNS
  • AAAA record
  • ICMP

Cause

According to RFC 4074 (section 3), if a client requests an AAAA record, and there are no AAAA record types for that name, the DNS server should respond with a NOERROR response code (DNS response code of 0) and an empty answer section.

Recommended Actions

Follow the workaround from the following article.

K7851: Configuring the BIG-IP DNS and BIG-IP Link Controller systems to provide NOERROR responses for IPv6 queries
