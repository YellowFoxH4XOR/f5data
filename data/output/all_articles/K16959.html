Known Issue

The leasepool high availability (HA) command may cause the tmm process to produce a core file and restart on a standby device group member.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP APM systems configured for HA.
  • The BIG-IP APM configuration includes a network access profile with an associated lease pool.
  • A standby device group member of the HA device group has just completed a reboot.
  • The active BIG-IP APM system sends a leasepool HA command to the standby member.

Impact

The tmm process on a standby device produces a core file and restarts.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The /shared/core directory contains a Traffic Management Microkernel (TMM) core file that correlates with the time of the event.
