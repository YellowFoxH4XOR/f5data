K000138972: Telemetry streaming unexpectedly stops sending logs after upgrade.

Type
Support Solution
Published
2024-03-27
Updated
2024-03-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.0.0, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.X.X, 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000138972

Description 

After upgrade BIG-IP from 16.x.x to 17.x.x  Telemetry has stops sending logs after various periods of time. You may have restarted the restnoded process to start Telemery again but it continues to fail at random times.

Environment

  • BIG-IP
  • Upgrade
  • Telemetry Steaming below 1.35 version

Cause

Memory issues

Recommended Actions

Please install the version 1.35 which contains the memory improvements: Telemetry 1.35 or later. If issue will continues to occur please contact F5 support.

For instructions of installation please take a look on following link:

Install the Telemetry Streaming iControl LX Extension
