K000146681: How to configure Content Security Policy to HTTP Response

Published

Applies to

Source

Description

  • You need a Content Security Policy Header added.
  • Headers that increase the safety of web-applications.

Environment

  • F5® Distributed Cloud WAF
  • F5 HTTP Load Balancer

Resolution/Answer

It is recommended to configure CSP from the origin server, as placing these in the HTTP Load Balancer will overwrite or may conflict with existing configurations on the backend.

To configure Content Security Policy Headers:

1. Select the Namespace.

2. Go to Load Balancers and on the right click the three [ ... ] then go to Manage Configuration.

 

3. In the top right Click Edit Configuration.

4. Go to Other Settings and at the bottom go to More Options. 

5. Go to Add Response Headers and configure as below:

  • Name of header: Content-Security-Policy
  • Value or Secret: Value
  • Example Value:  
    • default-src 'self';style-src 'self' 'unsafe-inline' https://fonts.googleapis.com https://cdnjs.cloudflare.com/;img-src 'self' data: https://*.googleapis.com https://*.gstatic.com *.google.com *.googleusercontent.com;script-src 'self' 'unsafe-inline' https://*.googleapis.com/ https://*.google.com/ https://*.gstatic.com/;frame-src 'self' *.google.com;font-src 'self' https://fonts.gstatic.com https://cdnjs.cloudflare.com/;connect-src 'self' https://*.googleapis.com *.google.com https://*.gstatic.com data: blob:;object-src 'none';

(Warning: Formatting this incorrectly will cause SSL errors.)

6. Apply.

7. Save and exit.

Additional Information

  • default-src: Only allow content to be loaded from the same origin ('self'). This prevents any content from being loaded from external sources.
  • script-src: Allow scripts to be loaded only from trusted sources. For example, you might specify 'self' to allow scripts from the same origin and specific trusted domains, such as CDNs (https://cdnjs.cloudflare.com).
  • style-src: Similarly, allow stylesheets to be loaded only from trusted sources. You can use 'self' and trusted domains like CDNs (https://fonts.googleapis.com).
  • img-src: Restrict image sources to trusted sources only. Use 'self' for images hosted on the same origin and trusted domains where images are served (https://example.com).
  • font-src: Allow fonts to be loaded from trusted sources. Use 'self' and trusted font providers (https://fonts.gstatic.com, https://cdnjs.cloudflare.com).
  • connect-src: Control which URLs the document is allowed to make requests to (XHR, Fetch). Specify 'self' and trusted domains where API requests are made (https://api.example.com).
  • frame-src: Specify the sources from which the document is allowed to embed frames. This is typically used for <iframe> elements. You might use 'self' to allow embedding frames from the same origin.
  • object-src: Control the sources that can be used as the target of <object>, <embed>, or <applet> elements. You can set it to 'none' to disallow these types of resources altogether.
  • media-src: Control the sources from which the browser can load media (audio and video) files. Use 'self' and trusted media providers (https://example.com).
