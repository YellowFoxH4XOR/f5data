Description

You have downloaded BIGIP-x.x.x.x.iso and BIGIP-x.x.x.x.html.md5 but their hash value is different.

For example, if you are downloading BIG-IP image 14.1.4.4, the downloaded file names are:

  1. BIGIP-14.1.4.4-0.0.4.iso
  2. BIGIP-14.1.4.4-0.0.4.html.md5
The following command is used to view and check the md5 hash values:
cat <md5 file> && md5sum <iso file>

For BIG-IP software 14.1.4.4 example above, the command and output is as below:
cat BIGIP-14.1.4.4-0.0.4.html.md5 && md5sum BIGIP-14.1.4.4-0.0.4.iso
ff73db0c6cd42d6c737b13f667b49589  BIGIP-14.1.4.4-0.0.4.html
500bc010e2e3cbbe41a6495375d69693  BIGIP-14.1.4.4-0.0.4.iso

Environment

  • BIG-IP ISO and md5 md5 hash has a different value
  • BIGIP-x.x.x.x.iso
  • BIGIP-x.x.x.x.html.md5

Cause

BIGIP-x.x.x.x.html.md5 is the md5 hash value for BIGIP-x.x.x.x.html and not BIGIP-x.x.x.x.iso.

Recommended Actions

You will need to download the BIGIP-x.x.x.x.iso.md5 md5 file and compare the hash values.

For example, for BIG-IP image 14.1.4.4, the command and output for BIGIP-x.x.x.x.iso.md5 and BIGIP-x.x.x.x.iso is as below:

cat BIGIP-14.1.4.4-0.0.4.iso.md5 && md5sum BIGIP-14.1.4.4-0.0.4.iso
500bc010e2e3cbbe41a6495375d69693  BIGIP-14.1.4.4-0.0.4.iso
500bc010e2e3cbbe41a6495375d69693  BIGIP-14.1.4.4-0.0.4.iso
