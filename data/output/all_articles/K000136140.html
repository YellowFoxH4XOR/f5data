K000136140: GTM pool members status availability unknown

Type
Support Solution
Published
2023-09-08
Updated
2023-09-08
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136140

Description

When the below setting is no (default value) gtm does not monitor disabled pool members.  

gtm global-settings general monitor-disabled-objects no (default value)

 

This results in the Status Availability showing the last monitor status before it was disabled.  

After reboot there is no last status and disabled gslb pool members will show:

Status Availability: Unknown.


Example:

tmsh show gtm pool a test-pool

----------------------

Gtm::Pool::A test-pool

----------------------

...
  ---------------------------------------------------------

  | Gtm::Pool Member: test-pool:A genericvs01:generichost01

  ---------------------------------------------------------

  | Status        

  |   Availability : unknown

  |   State        : disabled

  |   Reason       : Available: disabled directly

                

 

 

 

 

Environment

GTM on version 16.1.0 or higher with GLSB pool members disabled

 

Cause

This is due to ID 808829 which allows disabling the monitoring of disabled GSLB pool members.

 

Recommended Actions

Monitoring of disabled gslb pool members can be re-enabled:

gtm global-settings general monitor-disabled-objects yes
