Known Issue

This is the result of a known issue. If a user accesses a Legacy Host Favorite with a European keyboard, the Legacy Host Favorite may not accept some special characters such as a vertical bar ( | ) and a question mark (?).

F5 Product Development tracked this issue as CR48818 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Note: This issue was fixed for the VT-320 terminal type in FirePass version 6.1.0 and in cumulative hotfix HF-603-2 for FirePass version 6.0.3. This issue was fixed for the other terminal types in FirePass version 5.5.0.

Additionally, this issue was fixed in cumulative hotfix HF-603-2 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
