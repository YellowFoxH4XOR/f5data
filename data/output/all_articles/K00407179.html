Description

When selecting the Configure new virtual server... option while creating a security policy, in combination with protocol HTTP and HTTPS, to create two virtual servers, the virtual servers do not get created.

Environment

  • ASM security policies

Cause

Bug ID 937213

Recommended Actions

To workaround the issue, create the virtual servers manually.
