K000133585: ISTIO_DUAL_STACK environment variable not set in Istiod pod

Type
Support Solution
Published
2023-08-14
Updated
2023-08-14
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000133585

Description

After enabling dual-stack in the mesh, ISTIO_DUAL_STACK environment variable is not set in the Istiod pod, even though the override-values file has the following attributes:

global:
      dualStack: true
      ingressGatewayDualStack: true

No ISTIO_DUAL_STACK environment variable set in the Istiod pod:

➜  aspenmesh-carrier-grade-1.14.6-am4 ki describe pod istiod-6669547d5-46jp4 | grep -A13 "Environment"
    Environment:
      REVISION:                                     default

      POD_NAME:                                     istiod-6669547d5-46jp4 (v1:metadata.name)
      POD_NAMESPACE:                                istio-system (v1:metadata.namespace)
      SERVICE_ACCOUNT:                               (v1:spec.serviceAccountName)

      PILOT_ENABLE_ANALYSIS:                        false
      CLUSTER_ID:                                   Kubernetes

Environment

Aspen Mesh 1.14.x, Dual Stack Cluster

Cause

Repeated global configuration in the override values file.
When having a double global definition like below, this will cause only the last global section to be applied.

global:
      dualStack: true
      ingressGatewayDualStack: true
gateways:
 istio-ingressgateway:
   ports:
   - port: 15021
     targetPort: 15021
     nodePort: 32625
     name: status-port
   - port: 80
     targetPort: 8080
     nodePort: 31058
     name: http2
pilot:
          keepaliveMaxServerConnectionAge: 30m
global:
   proxy:
      logLevel: "off"

Recommended Actions

Confirm there is only one global section defined in the override values file, group all corresponding attributes under a single section:

global:
      dualStack: true
      ingressGatewayDualStack: true
      proxy:
       logLevel: "off"
gateways:
 istio-ingressgateway:
   ports:
   - port: 15021
     targetPort: 15021
     nodePort: 32625
     name: status-port
   - port: 80
     targetPort: 8080
     nodePort: 31058
     name: http2
   - port: 443
     targetPort: 8443
     nodePort: 32442
     name: https
   - port: 15443
     targetPort: 15443
     name: tls
     nodePort: 31730
pilot:
          keepaliveMaxServerConnectionAge: 30m

Additional Information

After grouping all attributes in a single section ISTIO_DUAL_STACK and upgrading the istiod chart, the environment variable should be set in the Istiod pod, as well as the other attributes.
