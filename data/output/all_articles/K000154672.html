K000154672: "show system mgmt-ip" displays all zeroes instead of actual address when mgmt interface is down

Type
Support Solution
Published
2025-09-12
Updated
2025-09-12
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000154672

Description

On F5OS Appliance platforms, when the management interface is DOWN, the output of the show system mgmt-ip command may display all zeroes or default values for the management IP address, prefix-length, and gateway. Example output:

system mgmt-ip state ipv4 system address 0.0.0.0
system mgmt-ip state ipv4 prefix-length 0
system mgmt-ip state ipv4 gateway
 0.0.0.0
system mgmt-ip state ipv6 system address ::
system mgmt-ip state ipv6 prefix-length 0
system mgmt-ip state ipv6 gateway ::

This does not reflect the actual configured management IP, which remains correctly set and visible via show running-config system mgmt-ip.

Environment

  • F5OS-A/C
  • Management interface connected to an upstream switch; interface may be administratively shut down or physically disconnected.

Cause

This is a cosmetic issue in the F5OS CLI and it is currently tracked under internal bug ID2048381 by Product Engineering for future product enhancement.

When the MGMT interface is DOWN (for example, due to the upstream switchport being shut down or disconnected), the system fails to display the actual configured management IP information in the show system mgmt-ip output and instead shows zeroes or default values. The configuration itself is not lost or changed; it remains intact and can be viewed in the running configuration.

Recommended Actions

1. To view accurate management IP configuration when the mgmt interface is DOWN, use the following command:

show running-config system mgmt-ip


2. To avoid hitting this cosmetic issue, ensure that the mgmt interface remains UP and connected to its upstream switch.

3. If this issue occurs, toggling the mgmt interface UP/DOWN or rebooting may temporarily resolve it; however, it may reoccur if the interface goes DOWN again. An upgrade or downgrade also temporarily clears the issue.

4. There is no functional impact to device management configuration—only CLI display is affected.

Additional Information

None.
