Description

When you try to create a user for BIG-IP/BIG-IQ via GUI or CLI, the below error message prompt and prevent the user creation.

1070820:3: User Modification Denied: User (user-test) is a system account and may not be modified

However, you don't find the relevant user(user-test) either in the GUI System  ››  Users : User List, or in CLI using command "tmsh list auth user | grep user-test".

While checking file /etc/passwd, you find this user is listed in here.

restnoded:x:198:198::/:/sbin/nologin

default:x:32766:100::/home/default:/bin/bash

default1:x:32767:100::/home/default1:/bin/bash

user-test:x:52561:100::/home/user-test:/bin/bash

Environment

  • BIG-IP
  • BIG-IQ
  • New user creation

Cause

This is due to this user has been already created by command useradd in the bash.

Recommended Actions

If you confirm this user is created accidentlly through bash command useradd, you may delete this user using command userdel. For example:

#userdel user-test

Additional Information

Typically, if you want to add new users for BIG-IP device, we suggest you create them via WebUI or TMSH command.
