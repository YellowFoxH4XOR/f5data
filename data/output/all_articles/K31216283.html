K31216283: Exception while checking License Info. Setup/Environment issue for Secondary BIG-IQ.

Published

Updated
2025-02-06
Applies to

Source
https://my.f5.com/manage/s/article/K31216283

Description

The preUpgradeCheck tool for BIG-IQ is a script that checks various aspects of the system such as CPU, memory, disk space, and data collection device (DCD) cluster health to ensure the BIG-IQ system and DCD cluster is ready for an upgrade.

This warning message will be displayed if the script is being ran on a secondary BIG-IQ:

Exception while checking License Info. Setup/Environment issue for Secondary BIG-IQ.
  isLicenseExpired key is not present as a part of the getresponse for the url : http://localhost:8100/shared/resolver/device-groups/cm-shared-all-big-iqs/devices for Secondary BIG-IQ
 

Environment

  • Secondary BIG-IQ configured
  • preUpgradeCheck tool

Cause

This was internally tracked as Bug ID 886937 and corrected in version 5 of the preUpgrade script.  Modern versions will complete the entire rest of the pre-upgrade check.

Recommended Actions

Verify the license of the secondary BIG-IQ CM manually.  
It is always recommended to reactivate licenses prior to upgrade.
