Description

When attempting to import the license for a product, you receive the following error: 
  • Licensing Error: Error 51136, F5 registration key is not compatible with the detected version <Version>

Environment

  • Licensing

Cause

Certain licenses are version locked in such a way that they can only be used on a specific version,  or between version X and version Y.   If you receive this error, the device is running a version that is not compatible with the license. 

Recommended Actions

  • Upgrade or downgrade the BIG-IP version to one that is supported by the license. 
  • Request a license from your F5 Sales Account Team for the version you are attempting to activate.
