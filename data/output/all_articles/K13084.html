Known Issue

The FirePass controller may incorrectly detect valid machine certificates as revoked.

This issue occurs when all of the following conditions are met:

  • The FirePass controller is using a pre-logon sequence that contains the Check Machine Certificates action
  • The FirePass controller is configured to use OCSP validation for client certificates

Impact

Users may be denied logon to the FirePass controller.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users receive the following error message on the logon screen:

    Your device does not comply to current client security policies.
    There is NO valid machine certificate installed on this machine.
  • When the Save user's session variables to Logon Reports option is enabled, the following message is logged to the logon reports; in the message, <Check ID> is the Check ID value from the Check Machine Certificates endpoint security inspector:

    %session.cert_check.<Check ID>.message% = ' The certificate has been revoked. '
  • Enabling show_client_data in the Pre-Logon sequence will display an error message that appears similar to the following example in the show client info section on the users logon screen; in the message, <Check ID> is the Check ID value from the Check Machine Certificates endpoint security inspector.
     
    [id] => <Check ID>
    [result] => 0
    [message] => The certificate has been revoked.

Workaround

To work around this issue, you can use CRL certificate validation instead of OCSP. To do so, perform the following procedures:

Impact of workaround: HTTP access to the Certificate Authority hosting the CRL information must be available to the FirePass controller.

Disabling OCSP requests

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management : Security : Certificates.
  3. Clear the Request OCSP server certificate status check box.
  4. Click the Update button.

Enabling the CRL On-Line Updates

Note: Do not configure for Client CRL On-Line Updates if you are using the FirePass controller to generate or issue client certificates to users (using either a self-signed client root CA certificate, or a client root CA certificate along with a private key). FirePass manages these CRLs internally.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management : Security : Certificates.
  3. Select the Automatically retrieve CRLs from URLs check box.  
  4. Click the Update button.
  5. In the URL text box, enter the URL for your certificate authority that the CRL information will be retrieved from.
  6. In the CRL Retrieval Frequency drop-down menu, select how often you want to retrieve CRL information.
  7. Optional: If you selected a CRL Retrieve Frequency that is once a day or greater, you can specify the time of day to retrieve CRL information by selecting the time of day from the CRL Retrieval Time drop-down menu.
  8. Click the Update button.
