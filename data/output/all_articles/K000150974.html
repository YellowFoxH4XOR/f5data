K000150974: OIDC error encountered after upgrading to NGINX Plus R30 or later

Type
Support Solution
Published
2025-04-30
Updated
2025-04-30
Applies to
  • NGINX Products
  • NGINX Plus: R30
Source
https://my.f5.com/manage/s/article/K000150974

Description

OIDC errors after the upgrade to NGINX Plus R30 and higher

 

Examples:

js: OIDC unexpected response from IdP when sending authorization code (HTTP 400). undefined

js exception: Error: unhandled promise rejection: TypeError: cannot get property "replace" of undefined while sending to client

 

Environment

NGINX Plus
NJS Module
OIDC Authentication

 

Cause

Since the NGINX R30 release, the JSON body capture reply.responseBody has been replaced with reply.responseText in the openid_connect.js file.

https://github.com/nginxinc/nginx-openid-connect/commit/8da37d2ef6761c2f16a7c6788eb387785841e93a

 

Recommended Actions

When upgrading to NGINX Plus R30 or later, please ensure that you use the latest version of the openid_connect.js file

https://github.com/nginxinc/nginx-openid-connect
