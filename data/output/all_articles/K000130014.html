Description

User unable to load the configuration on the BIG-IP device after software upgrade is performed. While we verify the configuration of the device using CLI, noticed below error from the CLI,


#tmsh load sys config verify

"Loading schema version: 16.1.2.2

01071dc9:3: BIG-IP doesn't support using a '#' in the TACACS secret.

Unexpected Error: Loading configuration process failed."


Environment

BIG-IP LTM

Software upgrade

Configuration load

TACACS


Cause

Issue is due to the value # is been used in the TCACS secret.


 Recommended Actions

Please perform the following procedure to resolve the issue


1.Edit the bigip.conf file

# vi bigip.conf


2.Search for /TACACS configuration


3.Remove # from the secret.


4.Type ESC :wq to save the modified change


5.save the device config

#tmsh save sys config


6.Load the configuration

#tmsh load sys config
