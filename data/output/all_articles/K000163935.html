Security Advisory Description

When NGINX Plus or NGINX Open Source is configured with the ngx_stream_ssl_preread_module module, a specially crafted ClientHello message from an unauthenticated attacker causes forged values of the ngx_stream_ssl_preread_module variables, affecting virtual server selection. In addition, it may also cause a disagreement with a proxied server terminating the SSL/TLS connection without Transport Layer Security (TLS) 1.3 support. (CVE-2026-123640)

Impact

This vulnerability may allow an attacker to forge values of the ngx_stream_ssl_preread_module variables and bypass the NGINX systems stream routing segmentation. As a result, the attacker may be able to route the connection to a privileged or internal backend that should be unreachable and access sensitive information.

Mitigation

Disable the ssl_preread directive in favor of SSL/TLS termination on NGINX. For more information, refer to Module ngx_stream_ssl_preread_module.

For example, the following configuration includes the ssl_preread on; directive:

stream {
    log_format sni "PREREAD_SNI=[$ssl_preread_server_name] -> [$backend]";
    access_log /var/log/nginx/stream.log sni;
    map $ssl_preread_server_name $backend {
        internal.test   127.0.0.1:9002;   # privileged backend
        default           127.0.0.1:9001;   # public backend
    }
    server {
        listen 9443;
        ssl_preread on;
        proxy_pass $backend;
    }
}

To mitigate the issue for this configuration, make the following changes:

  • Remove the ssl_preread directive.
  • Terminate TLS on NGINX by adding the following:
    • Change the listener to ssl.
    • Configure a certificate and key.
    • Replacing $ssl_preread_server_name with $ssl_server_name to use SNI-based routing.

stream {
    log_format sni "TLS_SNI=[$ssl_server_name] -> [$backend]";
    access_log /var/log/nginx/stream.log sni;
    map $ssl_server_name $backend {
        internal.test   127.0.0.1:9002;   # privileged backend
        default           127.0.0.1:9001;   # public backend
    }
    server {
        listen 9443 ssl;
        ssl_certificate     /etc/nginx/ssl/fullchain.pem;
        ssl_certificate_key /etc/nginx/ssl/privkey.pem;
        ssl_protocols       TLSv1.2 TLSv1.3;
        # ssl_preread removed; NGINX terminates client TLS.
        proxy_pass $backend;
        # Use these if the backends still expect TLS.
        proxy_ssl on;
        proxy_ssl_server_name on;
        proxy_ssl_name $ssl_server_name;
    }
}

After making the configuration changes, validate the configuration and reload, using the following commands:

nginx -t
nginx -s reload
