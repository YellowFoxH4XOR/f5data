Description

Unable to to generate a CSR from the GUI while using NetHSM

  • The CSR generation fails.
  • It gives following error in GUI "Key management library returned bad status: -18, A vendor error has occurred."
  • /var/log/ltm shows following error "The requested Certificate Signing Request File (/Common/csr-name) was not found."

Environment

  • BIG-IP v15.1.2
  • While using SafeNet Luna NetHSM for storing the keys
  • The error shows only while trying to generate from GUI.
  • Able to generate CSR successfully from CLI.

Cause

This cause appears to be an issue with daemons handling the GUI.

Recommended Actions

  1. Restart restjavad, http, tomcat, and restonded 
    # bigstart restart restjavad httpd tomcat restnoded

  2. Restart pkcs11d 
    #bigstart restart pkcs11d


Note: Running the above commands should not cause any disruption to traffic.

After running the commands above, the device should be able to generate CSR from GUI as well. If it still can't, please reach out to F5 technical support.

Additional Information

Command to create CSR from CLI can be obtained from - https://techdocs.f5.com/en-us/bigip-14-1-0/big-ip-system-and-safenet-luna-sa-hsm-implementation-14-1-0/implementing-the-safenet-luna-hsm-with-big-ip-systems.html
