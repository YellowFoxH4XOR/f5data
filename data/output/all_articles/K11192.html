Known Issue

This is the result of a known issue. BIG-IP event data handling for plug-in products may result in plug-in related crashes and core files.

For example, when a plug-in module such as BIG-IP ASM attempts to access a non-existent element in the request queue, the BIG-IP ASM bd process can crash and produce a core file. This may occur when plug-in events arrive in the request queue in the wrong order, or when the plug-in module processes certain HTTP 100-continue request messages.

F5 Product Development is tracking this issue as CR125268.

This issue does not affect the BIG-IP 10.x software branch.

BIGIP-9.4.8-396.1-HF3 has been issued for BIG-IP 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
