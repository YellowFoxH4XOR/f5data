What Happened?

  • F5® Distributed Cloud WAAP (Web App and API Protection) Services quotation/ purchase order, mentions the amount of request
  • Your purchase order mentions the amount of requests but you do not know where are those billing metrics to count or track them

Environment

  • F5® Distributed Cloud WAAP Services quotation

Resolution/Answer

  • Yes, there is a way to track http requests per namespace in Distributed Cloud Console.

To track http requests per namespace:

  1. Navigate to WAAP or Multi-Cloud app connect service
  2. Click on Performance dashboard in one of 2 places:
    1. WAAP, under Dashboard --> Performance dashboard 
    2. Multi-Cloud App Connect, its under Overview --> Performance.
  3. In the Traffic Overview widget, we show Total Requests for selected namespace
  4. To calculate "good requests", which is the billing metric for rate limiting, we need to subtract all the blocked requests from total requests. Total blocked security events can be seen in Security Analytics page. 

Additional Information

Example:

  • Distributed Cloud Mesh User Rate Limiting Good Requests (1 Million Requests, App Delivery Network, Organization Plan, Per Month) - 1Yr
  • Distributed Cloud Mesh API Protection (1 Million Requests, App Delivery Network, Organization Plan, Per Month) - 1Yr
