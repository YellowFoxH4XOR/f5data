K74439924: An error occurred while adding the BIG-IQ:Ncat:Connection timed out. Connection to port 5432 device <ip address> cannot be established.

Description
After upgrading BIG-IQ, you may experience this error when attempting to establish HA:

An error occurred while adding the BIG-IQ:Ncat:Connection timed out.  Connection to port 5432 device <ip address> cannot be established.
Where <ip address> is the discovery address of your BIG-IQ.

Environment

  • Upgrade from 7.0.x to 8.x
  • Attempting to restore HA connection

Cause
The newer versions require port 5432 for HA where 7.0.x did not.

Recommended Actions

  1. From the command line of each BIG-IQ, run these commands:
    tmsh modify net self-allow defaults add {tcp:5432}
    tmsh save sys config
  2. Then re-attempt to set up the HA configuration.
  3. You may need to set the BIG-IQ back to standalone before re-attempting the HA configuration.
