Topic

BIG-IP Edge Client support for Windows 10 is available in certain BIG-IP APM versions. For more information about supported features and versions, refer to the Client Compatibility Matrix for your version.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Description

Windows 10 support

  • BIG-IP APM supports Windows 10. This support was introduced in the following BIG-IP APM versions:
    • 12.0.0 HF1
    • 11.6.1
    • 11.6.0 HF6
    • 11.5.4
    • 11.5.3 HF2

Note: All more recent versions of BIG-IP APM support Windows 10. For up-to-date information, review the corresponding Client Compatibility Matrix for your BIG-IP version.

Note: The Windows Protected Workspace feature within BIG-IP APM Access Policy is not supported on Windows 10.

F5 Access VPN Client (formerly Inbox VPN)

  • Windows 8.1 included a built-in VPN client for the BIG-IP APM system called Inbox F5 VPN Client. Starting with Windows 10 Desktop and Mobile, the VPN client for the BIG-IP system will be available in the Windows Store. The name of the application changed to F5 Access. For more information, refer to the F5 Access for Windows 10 1.2 release notes and the Configuration Notes: F5 Access for Windows 10 and Windows 10 Mobile manual.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Recommendations

F5 recommends that you upgrade to a BIG-IP APM software version that includes Windows 10 support, according to its corresponding Client Compatibility Matrix.
