Topic

You should consider using these procedures under the following condition:

  • You want to reduce the number of false positive violations generated by attack signatures.

Description

Starting in BIG-IP ASM 15.1.0, you can enable Attack Signature False Positive Mode for your security policy. When enabled, the system finds potential false positive attack signatures by reviewing traffic patterns and identifying signatures that match benign input. Using Attack Signature False Positive Mode may reduce the amount of time the administrator spends investigating false positive violations.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the Configuration utility.

Procedures

  • Enabling Attack Signature False Positive Mode
  • Viewing Event log details for violations marked as likely false positives

Enabling Attack Signature False Positive Mode

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select Attack Signatures.
  4. For Potential False Positive Detection (this setting is known as Attack Signature False Positive Mode in BIG-IP 15.1.x), select one of the following settings:
    • Disabled: Disables Attack Signature False Positive Mode.
    • Detect: Enables Attack Signature False Positive Mode. The system identifies a potential false positive attack signature, blocks the request, and marks the request as a likely false positive violation.
    • Detect and Allow: Enables Attack Signature False Positive Mode. The system identifies a potential false positive attack signature, allows the request, and marks the request as a likely false positive violation.
  5. Select Save.
  6. Select Apply Policy.

Viewing Event log details for violations marked as likely false positives

After enabling Attack Signature False Positive Mode, you should review the Event log and determine how frequently the system identifies potential false positive violations and make sure the requests should be allowed by the policy. To view Event log details for violations marked as likely false positives, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Event Logs > Application > Requests.
  3. Select the Open Filter icon.
  4. Select the IP / Username / URL tab.
  5. Select the Potential False-Positive Attack Signature Detected (this is known as Likely False-Positive Attack Signature Detected in BIG-IP 15.1.x) check box.
  6. Select Apply Filter.
  7. Select a Request record to examine the details of the request marked as a likely false positive violation.
