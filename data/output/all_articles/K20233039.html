Source
https://my.f5.com/manage/s/article/K20233039

Description
BIG-IP DNS can't clear persistence records if disabling/enabling persistence profile too fast by following K12139717.
For example: disabling/enabling persistence profile within 2-5 seconds.
Environment

  • Wide IP

  • BIG-IP DNS/GTM

  • Persistence

Cause
Still under investigation.
Recommended Actions
After disabling persistence profile, wait 10 sec, then enable persistence profile.
