Known Issue

Outgoing connections from the switch card control processor (SCCP) cannot be established.

This issue occurs when all of the following conditions are met:

  • The BIG-IP platform contains an SCCP running version 12.0.8
    • The 1500, 3400, 3410, 4100, 6400, 6800, 8400, and 8800 platforms contain an SCCP
  • You have assigned an IP address to the SCCP so that it can be accessed over the network
    • By default, the SCCP is not assigned an IP address

This issue does not affect production traffic through the BIG-IP system.

Impact

Outgoing connections from the SCCP cannot be established.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You are able to establish incoming connections to the IP address of the SCCP. However, you are unable to establish outgoing connections from the SCCP.

Resolution

Note: SCCP version 12.0.8 was introduced in BIG-IP version 10.1.0. If you are running a BIG-IP software version prior to 10.1.0, and if you have not manually upgraded the SCCP to version 12.0.8, you are not affected by the issue described in this article.

Note: The platforms that support SCCP version 12.0.8 are not supported by BIG-IP versions 11.2.0 and later.
