Description

You face a issue with the thumbnail images for the website content shared on social media platforms, particularly on Facebook, Twitter, and others. The thumbnail images do not appear when your materials are shared. 

For example you get similar error from the Facebook debugger:

Response code reason: This response code could be due to a robots.txt block. Please allowlist facebookexternalhit on your sites robots.txt config to utilize Facebook scraping

Environment

  • BIG-IP

Cause

 The Facebook's crawler "facebookexternalhit" is being blocked by your robots.txt file.

Recommended Actions

To allow the bot to scrape your URLs, you need to modify your robots.txt file to allow Facebook's crawler by entering below anywhere in your robots.txt:

User-agent: facebookexternalhit

Allow: /
