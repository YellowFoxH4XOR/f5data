Known Issue

This is the result of a known issue. If you configure a Static Application Tunnel and select FTP (Passive) from the New Static Tunnel drop-down menu, Passive FTP sessions through that Application Tunnel will fail if one of the following cumulative hotfixes is installed:
  • HF-601-1
  • HF-601-2
  • HF-601-3
  • HF-601-4

F5 Networks Product Development tracked this issue as CR80525 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
 

Additionally, cumulative hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
