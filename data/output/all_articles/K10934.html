K10934: Dynamic App Tunnels that launch Internet Explorer 8 may fail to tunnel traffic properly

Known Issue

This is the result of a known issue. If you configure a Dynamic App Tunnel to launch Internet Explorer, and the client system has Internet Explorer 8 (IE8) installed, the Dynamic App Tunnel may fail to tunnel traffic through the FirePass controller. As a result, users cannot access internal sites using IE8.

This issue occurs when the Application field configured for the Dynamic App Tunnel contains a Windows environment variable.

For example:

"%PROGRAMFILES%\Internet Explorer\iexplore.exe"

F5 Product Development tracked this issue as CR121942 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

This issue was fixed in cumulative HF-603-5-1.1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by adding the Internet Explorer -nomerge command line switch to the command.

For example, you would change the Application field to appear as follows:

"%PROGRAMFILES%\Internet Explorer\iexplore.exe" -nomerge http://www.example.com

Note: Application Tunnels are configured on the Application Access: App Tunnels: Resources page.
