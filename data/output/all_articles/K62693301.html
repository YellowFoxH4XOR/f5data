Description

The configuration utility allows a rollback of the attack signature updates but not to the genesis signature package.

Environment

ASM is provisioned.

Cause

N/A

Recommended Actions

The best option to restore Signatures into the initial original state is by:

  1. Export all security policies in XML.
  2. Restore the BIG-IP ASM database to default or clean configuration.
  3. Once ASM starts with a clean config, import the security policies.
