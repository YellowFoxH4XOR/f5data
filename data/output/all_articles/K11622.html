Topic

F5 provides support for Oracle Access Manager (OAM) integration starting in BIG-IP APM and BIG-IP Edge Gateway 10.2.1 and in 10.2.0 if you install Hotfix-BIGIP-10.2.0-1755.1-HF1 or later. OAM is a product that combines identity management and access control, which provides centralized authentication, policy-based authorizations, and auditing.

Note: For more information about OAM, refer to Oracle's OAM documentation. This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

F5 added this feature starting in BIG-IP APM 10.2.1 and in Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for BIG-IP APM 10.2. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing a hotfix, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
