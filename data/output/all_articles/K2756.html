Important: Unless an application requires it, F5 does not recommend using global IP forwarding. Instead, use secure network address translations (SNATs) and NATs, forwarding pools, and forwarding virtual servers.

IP forwarding is a BSDi kernel function and is not tied to the active/standby functionality of the BIG-IP system. This means that both the active and the standby BIG-IP systems will forward packets when IP forwarding is enabled.

The upstream router should be configured to use only the floating shared IP address so that packets are only sent to the active BIG-IP system; however, since the network interfaces are in promiscuous mode by default, the standby BIG-IP system forwards any packets that reach the interface. This situation is most common when a hub is used instead of a switch.
