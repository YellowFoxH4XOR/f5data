Description

  • ESXi upgrade from 6.5 to 6.7

  • Applied the workaround from  K74921042.

  • The SNMP object ifSpeed on interface 1.1 and 1.2 return 0 

Environment

  • Virtual Edition - using ESXi v6.7
  • BigIP v13.x or 14.x
  • using SNMP OID - ifSpeed

Cause

Using 'unic'  for device_probed

config/tmm_init.tcl
device driver vendor_dev 15ad:07b0 unic
tmm.device_probed
driver_in_use      unic
available_drivers  sock, vmxnet3, unic,

Recommended Actions

To check the driver is currently used:

tmctl -d blade tmm/device_probed

In case using driver other then vmxnet3, use the following steps:

  1. Log in to the BIG-IP command line.
  2. (Optional) Take a backup of /config/tmm_init.tcl file:

    cp /config/tmm_init.tcl /var/tmp/

  3. Remove or delete the said file by entering following command:

    rm  /config/tmm_init.tcl

  4. Restart TMM to reload the driver by entering the following command:

    bigstart restart tmm
     

Additional Information

vmxnet3 is the default, it will be selected if you'll remove the override you have.
