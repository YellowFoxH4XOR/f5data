Topic

This article describes a configuration scenario that causes a virtual server with an IPsec ALG profile to experience intermittent traffic failures.

Description

The BIG-IP system does not support using IPsec passthrough together with IPsec ALG on the same BIG-IP appliance. If the CMP Hash setting of a VLAN is set to Default and the ipsec.lookupspi database variable is set to disable, a virtual server with an IPsec ALG profile listening on the Virtual Local Area Network (VLAN) will intermittently fail to pass traffic. This behavior does not occur on the VIPRION platform.

The ipsec.lookupspi database variable added in BIG-IP 11.2.0 gives the BIG-IP administrator the option to disable the BIG-IP system from using the SPI to identify the connection flow. Disabling the variable allows you to pass IPsec traffic through an IP forwarding or FastL4 virtual server.

Procedures

Enable SPI lookup

To avoid the behavior noted previously, enable the BIG-IP system to function as an IPsec endpoint by performing the following procedure:

Impact of procedure: The BIG-IP system cannot perform IPSec passthrough with this database key enabled.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Enable SPI lookup by typing the following command:

    modify sys db ipsec.lookupspi value enable

    Note: The ipsec.lookupspi database variable is a global setting.
