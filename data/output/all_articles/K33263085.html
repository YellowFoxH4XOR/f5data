Description

You may find the error message in /var/log/asm.

/var/log/asm
Mar  8 19:13:34 test info perl[19992]: 01310015:6: ASM application filtering applied: event code I3532
Mar  8 19:14:41 test info perl[19992]: 01310015:6: ASM application filtering applied: event code I3532

Environment

  • BIG-IP ASM

Cause

The event is triggered when there is a response side violation that leads to block the transaction.
This can happen when there is data guard in blocking, response attack signature that is found or the even more rare xml web services enforcement.

Recommended Actions

To confirm the details, we need to enable ASM debug logging.
