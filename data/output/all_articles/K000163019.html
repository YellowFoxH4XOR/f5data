K000163019: BIG-IQ DCDs No Longer Require a Separate License Starting from BIG-IQ 7.1.0

Description

BIG-IQ Data Collection Devices (DCDs) no longer require a separate license starting from BIG-IQ 7.1.0. Reinstalled or replacement DCDs running BIG-IQ 7.1.0 or later do not require the previous DCD license to be transferred or reapplied.

Environment

  • BIG-IQ 7.1.0 and later
  • BIG-IQ Data Collection Device (DCD)
  • Virtual DCD deployments

Cause

DCD licensing requirements changed in BIG-IQ 7.1.0.

Recommended Actions

For DCDs running BIG-IQ 7.1.0 or later:

  1. Deploy or reinstall the DCD using a supported BIG-IQ version.
  2. Complete the DCD initialization and configuration.
  3. Add the DCD to BIG-IQ Centralized Management as required.
  4. Do not apply or transfer a separate DCD license.

For BIG-IQ versions earlier than 7.1.0, each DCD requires an appropriate individual license.

Additional Information

The applicable upgrade path and target version depend on deployment requirements, available resources, security policies, and supported software versions. Review the release notes and supported upgrade paths before selecting a target version.
