Description

When user logs in to the GUI ( TMUI ), instead of seeing the Full menu, they see a Compact ( Basic ) one as seen in the image below which includes only Network, Visibility and System:

Environment

  • Required Modules are provisioned ( LTM + AWAF )
  • Hybrid ELA License is installed


Cause

In a Hybrid ELA License that contains DDoS Hybrid Defender, when user logs in, they will see the Compact ( Basic ) menu.

Note: DDoS Hybrid Defender does not have to be provisioned.

This behaviour is recorded in ID997881.
