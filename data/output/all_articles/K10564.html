Known Issue

This is the result of a known issue. When you run the qkview utility from the BIG-IP WebAccelerator Configuration utility, the output file does not include the BIG-IP WebAccelerator MySQL data.

F5 Product development tracked this issue as ID 222225 (formerly CR115349), and it was fixed in BIG-IP WebAccelerator 11.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

You can work around this issue by running the qkview utility from the BIG-IP WebAccelerator command line.
