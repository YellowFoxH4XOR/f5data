Description

IPsec peering lost when failover occurs with IKEv2.

Environment

  • BIG-IP configured to terminate IKEv2
  • HA mirror channel configured
  • Software version prior to version 16 in use
  • IPsec SAs are mirrored from active to standby

Cause

Software support for IPsec incomplete prior to software version 16 not up to date for IPsec & HA

Recommended Actions

Upgrade to latest version 16.1.x or 17.1.x

Additional Information

HA related logging in /var/log/ipsec.log might give the impression that IPsec HA is supported in earier versions.

There is no HA support for IKEv1.
