Description

When user tries to login via SSH, error messages such as below appears when logging into CLI of the BIG-IP:

For admin user:

    1420001:2: Can't open command history file (/root/.tmsh-history-<username>), No such file or directory


For other users:

    Can't open command history file (/home/<username>/.tmsh-history-<username>), No such file or directory
    Could not chdir to home directory /home/<username>: No such file or directory

Environment

  • BIG-IP
  • Bash
  • Advanced Shell

Cause

  • /root/ directory is missing or deleted.
  • Missing /root/.tmsh-history-<UserName> file.
  • Missing /home/.tmsh-history-<UserName> directory/file.

Recommended Actions
 

For missing /root/ directory:

  1. Login to BIG-IP CLI.
     
  2. Access the Bash shell:
    bash
     
  3. Recreate the root folder using the command:
    mkdir /root/
     
  4. Copy bash files from known-good folder (ie. from admin's home folder).
    cp /home/admin/.bash_profile /root/
    cp /home/admin/.bashrc /root/
     
  5. Logout, then try logging back in again.
    exit

 

For missing /home/ directory:

  1. Login to BIG-IP GUI
  2. Go to System >> Users and select affected user
  3. Do any modification to user configuration and then reverse change.
  4. Verify missing directory has been rebuilt



Additional Information

None.
