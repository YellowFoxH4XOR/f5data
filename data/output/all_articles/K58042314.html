Description

Round Trip Time is a load balancing method where BIG-IP DNS distributes DNS name resolution requests to the virtual server with the fastest measured round trip time between a data center and a client's LDNS.
The BIG-IP DNS system probes the LDNS server to obtain path metrics. In addition, other F5 devices that are equipped with a big3d agent and are included in the configuration may also probe the LDNS server.

If the Round Trip Time load balancing method is used as the Preferred method and BIG-IP DNS is unable to acquire the proper metrics, the BIG-IP DNS will switch to the Alternate method if set.

Environment

  • BIG-IP GTM/DNS
  • BIG-IP LC
  • WideIP load balancing method set to Round Trip Time

Cause

By default BIG-IP DNS will probe using ICMP. If ICMP is blocked on the path from BIG-IP devices to LDNS, then metrics collection will fail.

Recommended Actions

Make sure that ICMP is allowed on the network path from BIG-IP devices (that are part of iQuery mesh) toward the LDNS which sourced the request.
