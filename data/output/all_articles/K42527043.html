Description

Pools marked down on standby but online on active unit

Environment

  • BIG-IP LTM
  • High Availability Device Group
  • Local Traffic Pools, marked down on one member of device group

Cause

Monitor configuration between devices is not in sync

Recommended Actions

  • Perform a configuration sync from the device where the pool members are being marked up to the device where the pool members are marked down, even if devices are currently shown to be in sync.
    Note: You can create a test profile (for example a Client SSL profile) on the active unit before triggering a configuration sync. Remove the the test profile after resolving the issue.
  • Refer to K12531: Troubleshooting health monitors for additional troubleshooting steps.
