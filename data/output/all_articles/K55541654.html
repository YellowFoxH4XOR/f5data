Description

You need to find the serial number and part number for an SFP (small form pluggable) on the Big-IP.

Environment

Big-IQ manages the Big-IP environment.

  • The Big-IPs use SFPs to connect to the network.
  • You need to find the serial number of the SFP.
  • You need to confirm the part number of the SFP.

Cause

The part number and serial number are necessary to replace an SFP that failed or you need to inventory these parts.

Recommended Actions

Big-IQ doesn't natively collect the interface hardware information, but you can use a script on the Big-IQ to gather this data.

  1. Enable Advanced shell on the Big-IP
    • ???K12029: Accessing the TMOS Shell
  2. Create a script on the Big-IQ Central Manager (CM).
    • Script management > Scripts > Add
      • Script:
        tmsh list sys global-settings hostname
        tmsh list net interface all one-line | grep vendor-partnum
    • Save and close
  3. Run the script.
    • Check/enable the box to the left of the script
    • Select Run
    • Name the script task
    • Select the Big-IP devices
    • Run
  4. Afterwards, in Script Log, select this task & view output.
