Known Issue

This is the result of a known issue. Under certain conditions, the BIG-IP ASM enforcer is not synchronized with the correct configuration. As a result, the system stops processing requests.

When this issue occurs, the following error message is logged to the /shared/log/ts/bd.log file:

IO_PLUGIN|NOTICE|<date>|1526|io_plugin.c:477|TMEVT_REQUEST: the selector is unknown.

F5 Product Development tracked this issue as CR101980 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue has been fixed in Hotfix-BIGIP-9.4.4-94.0-HF3, which has been issued for BIG-IP 9.4.4, and in Hotfix-BIGIP-9.4.5-HF2, which has been issued for BIG-IP 9.4.5. You may download these hotfixes or later versions of these hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Workaround

You can work around this issue by restarting the BIG-IP ASM bd process. To do so, type the following command from the command line:

bigstart restart asm
