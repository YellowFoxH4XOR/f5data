Issue

Error Message

01260006:4: Peer cert verify error: <message> (depth <level>; cert <info>)

In this error message, note the following:

  • <message> is the SSL certificate verify error message. 
  • <level> is the number of SSL certificate authentication levels.
    • Level 0 certificates are also known as self-signed certificates.
    • Level 1 certificates are authenticated by a separate certificate authority (CA).
    • Levels 2 - 9 certificates are authenticated by additional CAs.
  • <info> is SSL certificate X509 information.

For example:

01260006:4: Peer cert verify error: self signed certificate (depth 0; cert /C=US/ST=WA/L=Seattle/CN=www.example.com)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions are met:

  • You have a BIG-IP systems in a high availability (HA) configuration that is unable to verify a remote BIG-IP system's device trust SSL certificate.
  • You have configured a Client SSL profile to require client certificate authentication and the BIG-IP system is unable to verify the client's SSL certificate.
  • You have configured a Server SSL profile to require Server Certificate and the BIG-IP system is unable to verify the certificate from server.

SSL certificate verification may fail for a variety of reasons. Two popular reasons include:

  • The received SSL certificate has not been signed by a recognized CA.
  • The received SSL certificate validity period has expired.

Impact

  • BIG-IP systems will be unable to perform HA actions such as configuration synchronization and fail over.
  • Client side SSL connections will fail if Client Certificate is require.
  • Server side SSL connection will fail if Untrusted Certificate Response Control or Expire Certificate Response Control is drop.

Recommended Actions

  • For HA troubleshooting information, refer to K13946: Troubleshooting ConfigSync and device service clustering issues
  • For client certificate authentication troubleshooting information, refer to K14819: Troubleshooting client certificate authentication.
