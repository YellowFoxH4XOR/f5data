Description

When uploading an ASM-specific or Standard QKview file to the F5 iHealth portal, security policies and ASM objects may not be visible. This occurs when the iHealth portal skips processing the "asm_module.xml" file due to its size exceeding 500MB, resulting in missing ASM-related data in the analysis. The skipped file can be confirmed by checking the "skipped_files" section in iHealth, where "asm_module.xml" is listed as not processed because of its large size.

Environment

  • Standard QKview / ASM-QKview files uploaded to iHealth portal 
  • ASM / AWAF 

Cause

iHealth has a known limitation where it does not process the "asm_module.xml" file if its size exceeds 500MB. This results in missing ASM objects and security policy information in the QKview analysis. This limitation is documented in Bug ID 862369.

Recommended Actions

  • If ASM objects and security policies are not visible in iHealth, check the "skipped files" section for "asm_module.xml" and its file size, reported in the root directory of the QKview data.
  • There is currently no workaround for the iHealth file size limitation. ASM objects and security policies can still be viewed directly on the BIG-IP device.
  • If you encounter this file size limitation, monitor F5 bug tracker for updates on the mentioned Bug ID "862369".
