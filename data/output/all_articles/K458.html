Topic

The performance impact of BIG-IP IP filters has not been extensively examined and predicting the impact is difficult because it is dependent on the hardware model, configuration, and traffic load. BIG-IP is not intended to be used as a firewall and the included IP filters are recommended only for short-term use in securing the device, or for troubleshooting.

On many older platforms, using a single, basic filter in conjunction with sustained 50Mbit of traffic will result in a 15-20% increase in CPU utilization. Use of additional rules may increase processor utilization as much as 2% per additional rule. Of course, the processor is intended to be used, so this only presents a problem if the rest of the configuration causes the processor to be over-utilized. The memory usage of IP filters is negligible.

F5 recommends that you test any extensive use of IP Filters thoroughly, under similar conditions to the production network, before implementing them in a production environment.

Note: This article applies only to versions of BIG-IP prior to 9.0. Version 9.0 IP filters have been redesigned and present a much less significant performance impact.
