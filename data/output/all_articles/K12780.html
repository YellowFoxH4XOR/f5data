Known Issue

Description

The hard drive firmware that F5 shipped with the BIG-IP 3900 and EM4000 platforms before September 2010 may cause the system to mark the hard drive offline, preventing certain features such as disk caching from working properly. This issue occurs when all of the following conditions are met:

  • The hard drive firmware installed on the system is version 04.04V02, 04.04V03, 04.04V04, or 04.04V05.
  • The Time Limited Error Recovery (TLER) hard drive feature reports false positives when the operating system is idling, and does not send I/O to the hard drive before the TLER feature times out.
  • Applications, such as SQL, that put heavy loads on hard drives, make the hard drive cache tables inconsistent, which causes the hard drive firmware to report errors.
  • Soft errors that occur during operating system background refresh tasks were erroneously counted into S.M.A.R.T (Self-Monitoring, Analysis and Reporting Technology) Read Error Rates (RER), which caused S.M.A.R.T to mark the hard drive offline when the RER limit was exceeded.

Impact

This issue may result in features that require write access to the disk, such as disk caching and logging, to work improperly and may cause the BIG-IP system to mark the hard drive offline.

Symptoms

As a result of this issue, the BIG-IP 3900 and EM4000 platforms may experience some of the following symptoms:

  • The LCD panel displays a Hard Drive is failing message.
  • The End-User Diagnostics (EUD) reports S.M.A.R.T failure after the S.M.A.R.T test run.
  • The BIG-IP system starts up with file system errors.
  • The smartctl command reports attribute Raw_Read_Error_Rate with RAW_VALUE 1, indicating a hard drive failure.
  • File systems mounted as read-only may result in the failure to generate a qkview file.
  • File systems mounted as read-only may result in processes such as statsd failing to write data to files and to log error messages to the /var/log/ltm file that appear similar to the following example:

    011b0600:3: Error 'opening '/var/rrd/connections': Read-only file system' during rrd_update for rrd file '/var/rrd/connections'

Status

F5 Product Development has assigned ID 354430 and ID 339225 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the top right corner of the article. F5 Product Development has released a firmware upgrade that resolves this issue. You can obtain this firmware upgrade through a new version of the EUD utility.

Note: Simply installing the new EUD does not fix this issue; refer to the Workaround section in this article for complete information about how to update the firmware and resolve this issue.

Workaround

To work around this issue, you can update the hard drive firmware of your BIG-IP 3900 or EM4000 platforms. To do so, perform the following procedures:

  • Determine the hard drive firmware version of your BIG-IP 3900 or EM4000 platform
  • Determine the EUD version and, if needed, upgrade to EUD 12.8.1, or later
  • Boot to EUD 12.8.1, or later, and update the hard drive firmware

Determine the hard drive firmware version of your BIG-IP 3900 or EM4000 platform

  1. Log in to the command line.
  2. To find the hard drive firmware version, type the following command:

    hdparm -I /dev/sda | grep Firmware

    Before you have applied the firmware update, this command produces output that appears similar to the following example, showing hard drive firmware version 04.04V02:

    Firmware Revision: 04.04V02

    After you have applied the firmware update, this command produces output that appears similar to the following example, showing hard drive firmware version 04.04V06:

    Firmware Revision: 04.04V06

Determine the EUD version and, if needed, upgrade to EUD 12.8.1, or later

  1. Log in to the command line.
  2. To determine the EUD version, type the following command:

    eud_info

  3. If the output displays a version prior to 12.8.1, restart the BIG-IP system and upgrade the EUD to version 12.8.1, or later. To perform the EUD upgrade, refer to the End User Diagnostics release notes.

Boot to EUD 12.8.1, or later, and update the hard drive firmware

  1. To boot to EUD 12.8.1, or later, refer to the End User Diagnostics release notes.
  2. To update the hard drive firmware, select the 24 Hard Drive Firmware Update option from the EUD menu.

Note: After you have applied the hard drive firmware update, the 24 Hard Drive Firmware Update option no longer appears in the EUD menu when you subsequently run EUD.
