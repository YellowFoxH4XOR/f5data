Known Issue

This is the result of a known issue. The F5 umdinstall utility is used to format and copy installation information to USB mass storage drives for upgrade or installation of F5 software. The F5 umdinstall utility may not properly format some USB devices. This can occur if the current format or file system of the drive is unknown to Microsoft Windows.

This behavior may result in an incomplete transfer of the necessary software to the USB device, and the reporting of the following error messages:

  • The error message reported during the format phase of the USB drive by the umdinstall utility appears similar to the following example:

    >>>>>>>>>>>>>>>>>>>

    <C:\Documents and Settings\user>format e: /FS:FAT32 /X /V:F5USB
    Insert new disk for drive E:
    and press ENTER when ready...
    The type of the file system is RAW.
    The new file system is FAT32.
    Verifying 0M
    Cannot determine the number of sectors on this volume.
    <<<<<<<<<<<<<<<<<<<

  • Typical error messages reported when transferring to a USB drive with an unknown or incorrect format by the umdinstall utility appear similar to the following example:

    and press ENTER when ready...

A correctly formatted USB drive with the chosen product installed will display the following menu options:

  • Serve

    Provides network installation services
  • Install

    Installs software onto hard disk
  • Configure

    Configures Network Settings
  • Reboot

    Reboots System
  • Exit

    Exits to Maintenance Shell

F5 Product Development tracked this issue as CR84514 and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM, or Link Controller Release Notes.

Workaround

You can allow the drive to be formatted correctly by performing one of the following two workarounds:

  • To ensure the operating system reads and correctly mounts the USB drive, unplug the USB device and plug it back in. If the drive is not correctly mounted and read by the operating system, it may report incorrect information.
  • If the operating system correctly reads and mounts the drive, but is unable to read the format or file system, the drive may need to be reformatted or erased with another disk utility. In this situation, you should use a disk formatting tool to erase the USB drive. This includes the Master Boot Record (MBR) and partition table information.
