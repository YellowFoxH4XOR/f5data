Known Issue

This is the result of a known issue. Starting in BIG-IP version 9.4.2, you can use the bigpipe httpd allow command to restrict access to the BIG-IP Configuration utility by source IP address. However, the bigpipe httpd allow command does not properly restrict access to the Configuration utility. For example, if you use the bigpipe httpd allow command to restrict access to the Configuration utility to a specific IP address range, IP addresses outside of that range can still access the Configuration utility.

Note: For more information, refer to K7448: Restricting access to the Configuration utility by source IP address.

F5 Product Development tracked this issue as CR95885 and CR102463, and it was fixed in BIG-IP versions 9.6.1 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator release notes.

Workaround

To restrict access to the BIG-IP Configuration utility by source IP address, perform the following procedure:

  1. Log in to the command line.
  2. Create a file called /config/httpd/conf/httpd.inc by typing the following command:

    touch /config/httpd/conf/httpd.inc
  3. Using a text editor, add the following text to the file, where <IP_address_range>/<subnet_mask> is the IP address range and subnet mask that you want to allow access to the Configuration utility:

    httpd include "
    <Location /tmui>
    Order Deny,Allow
    Allow from 127 <IP_address_range>/<subnet_mask>
    Deny from all
    </Location>"

    For example, to restrict access to the BIG-IP Configuration utility to the 10.1.1.0/24 IP address range, add the following lines to the /config/httpd/conf/httpd.inc file:

    httpd include "
    <Location /tmui>
    Order Deny,Allow
    Allow from 127 10.1.1.0/255.255.255.0
    Deny from all
    </Location>"

    Note: If the BIG-IP system is a member of a redundant pair, you should include the failover IP address of the peer system.

  4. Save the changes and exit the file.
  5. To load the configuration into memory, type the following command:

    bpsh < /config/httpd/conf/httpd.inc
  6. To save the configuration, type the following command:

    bigpipe save all

Verifying the httpd configuration

To view the included data for the httpd daemon, type either of the following commands at the BIG-IP command line:

bigpipe httpd list

or

bigpipe httpd include

Backing out the configuration change

To back out the configuration changes, type the following command at the BIG-IP command line:

bigpipe httpd include none
