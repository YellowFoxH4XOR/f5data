Known Issue

This is the result of a known issue. The iControl portal, which uses EasySoap for SOAP support, can consume excessive amounts of memory when handling large requests or responses.

F5 Networks Product Development tracked this issue as CR85134, and it was fixed in BIG-IP versions 9.3.1 and 9.4.4. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator Release Notes.

This issue still exists in the BIG-IP 9.1 software branch, and it was fixed in Hotfix-BIG-IP-9.1.3-HF1 issued for BIG-IP version 9.1.3. You may download this hotfix or later versions of this hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about managing F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.
