Known Issue

This is the result of a known issue. A BIG-IP WebAccelerator running version 10.0.1 on a 4500 platform, with 8 GB of RAM, incorrectly reports the total amount of memory when you use the bigpipe memory show command.

For example:

# bigpipe memory show   
MEMORY STATISTICS --
|    (Host) Total = 3.840GB   Used = 1.169GB
|    (TMM)  Total = 2.744GB   Used = 13.86MB

You can safely ignore this issue; it does not affect the BIG-IP WebAccelerator system's ability to access the memory.

Note: This issue affects only BIG-IP WebAccelerator version 10.0.1.

F5 Product Development is tracking this issue as CR137335.

Workaround

If you type the physmem -m command, the system correctly displays the total amount of memory.

For example:

# physmem -m
8191
