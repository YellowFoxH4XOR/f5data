K000152440: [VELOS]-upgraded to 1.8.1, root password reset to default and not able to change it

Type
Support Solution
Published
2025-07-07
Updated
2025-07-09
Applies to
  • F5OS
  • F5OS-C: 1.8.1
Source
https://my.f5.com/manage/s/article/K000152440

Description

  • After upgrading VELOS systems to F5OS version 1.8.1 changing the root password using the confd CLI may result in an "application timeout" error:

Error: application timeout

  • Unable to change root password

Environment

  • Product: F5OS - Chassis (VELOS)
  • Software Version: 1.8.1
  • Authentication Methods: Local
  • Configuration: Default and custom password policies

Cause

This issue is caused by a known issue track with the Bug ID 1962245 in F5OS version 1.8.1.

Recommended Actions

To resolve this issue and successfully change the root password:

 

  1. Connect to the controller CLI as an admin user.
  2. Enter configuration mode:
    config
  3. Set the password policy so that it applies to the root account:
    system aaa password-policy config apply-to-root true
  4. Commit your changes:
    commit and-quit
  5. Change the root password and set its last-change value:

    config
    system aaa authentication users user root config set-password
       (enter new password when prompted)
    exit
    system aaa authentication users user root config last-change 1000
    exit
    commit and-quit
