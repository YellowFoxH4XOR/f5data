Topic

Secure Web Gateway (SWG) database update process happens through the download.forcepoint.com website. The BIG-IP management address is used for the download, and must have Internet access. All SWG URL Lookups and Request/Response Analytics is provided by a technology partnership with Forcepoint (formally Websense). SWG is made up of the following databases:

  • Master database
  • Real-Time Security database
  • Advanced Classification Engine (ACE) database.

Description

Through Forcepoint's Threat Seeker Intelligence Cloud, we receive the following updates:

  • Master Database updates (MasterDB) - Database is required by Forcepoint to be updated daily, and can be manually scheduled.
  • Real-time database updates (RTU) - polled every 10 minutes
  • Real-Time Security Updates (RTSU) - polled every 10 minutes
  • ACE database updates - polled every 15 minutes

Recommendations

The following IP address ranges are generally used by Forcepoint download servers:

  • 204.15.64.0/21 - North America
  • 78.0.0.0/8 & 157.167.0.0/16 - EMEA
  • 59.151.108.0/24 APAC

While the addresses are made available for troubleshooting purposes, Forcepoint may change these addresses to respond to various events. it is recommended to not hard code these addresses for downloads or firewalls for access control. Using the DNS name download.forcepoint.com is the preferred method of accessing the database updates.
