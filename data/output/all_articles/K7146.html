Known Issue

This is the result of a known issue. If the bigip_link health monitor is removed from the configuration so that it does not check a link, the link status does not change from available (green) to unchecked (blue) after the polling cycle has completed.

The correct behavior would cause the link status to change from available (green) to unchecked (blue) to indicate that there is no health check of the link occurring.

F5 Product Development tracked this issue as CR66379 and it was fixed in BIG-IP version 9.4. For information about upgrading, refer to the BIG-IP GTM or BIG-IP Link Controller release notes.
