Known Issue

This is the result of a known issue. The mcpd process receives and processes system configuration information from other processes on the BIG-IP system. The mcpd process stores the configuration information in shared memory to be accessed by other system processes. In rare conditions, the mcpd process may consume excessive memory when a receiving process is slow to acknowledge messages from the mcpd process.

F5 Product Development tracked this issue as CR81811, and it was fixed in BIG-IP LTM version 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, Hotfix-BIGIP-9.4.1-HF1 has been issued for BIG-IP LTM version 9.4.1. You may download this hotfix or later versions of this hotfix from the F5 Downloads page.
