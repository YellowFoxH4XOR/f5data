K000138985: vCMP Host restart Guest due to heartbeat timeout

Type
Support Solution
Published
2024-03-22
Updated
2025-10-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000138985

Description

  • vCMP Host reboots Guest due to heartbeat timeout
  • On vCMP Host log messages similar to the following can be seen on /var/log/ltm:

alert vcmpd[13998]: 01510014:1: vCMP guest F501.example.com heartbeat timeout at the halfway mark.

alert vcmpd[13998]: 01510013:1: vCMP guest F501.example.com lost heartbeat.

alert vcmpd[13998]: 01510011:1: vCMP guest F501.example.com powered off.

  • Logs on the vCMP guest show that it is under memory pressure (OOM killer invoked)

grep oom-killer /var/log/kern.log | tail

warning kernel: bigd invoked oom-killer: gfp_mask=0x201da, order=0, oom_score_adj=0

warning kernel: keymgmtd invoked oom-killer: gfp_mask=0x201da, order=0, oom_score_adj=0

warning kernel: tamd invoked oom-killer: gfp_mask=0x201da, order=0, oom_score_adj=0

warning kernel: java invoked oom-killer: gfp_mask=0x201da, order=0, oom_score_adj=0

  • vCMP guest Device Management Provisioning is set to Small

Environment

  • BIG-IP
  • vCMP Host
  • vCMP Guest
  • Multiple modules provisioned on vCMP Guest
  • Software version 15.x and above

Cause

The memory allocation to BIG-IP Linux host system is not adequate, which results in memory pressure.

Recommended Actions

For devices running software version 15.x and above, and with at least two provisioned modules, the Management Provisioning should be set as Large.

Important: The BIG-IP system experiences a temporary traffic interruption as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over. F5 recommends changing the Management memory size allocation during a scheduled maintenance window.

  1. Log in to the Guest Configuration utility.
  2. Go to System > Resource Provisioning.
  3. The line for Management (MGMT) has a drop-down box for Small, Medium, or Large. Set this to Large.
  4. Click Submit.
