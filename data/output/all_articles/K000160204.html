Description

You would like to create a UCS file on a BIG-IP device with one or more iApps LX extensions installed. The methods for creating a UCS file include the GUI, tmsh, and the REST API.

Environment

You use one of these procedures:

  1. Create a UCS via GUI or TMSH
  2. Generate UCS via REST API (called through Ansible Playbook)

Cause

BIG-IP builds an RPM package per iApps LX extension while creating a UCS file. The timeout of the RPM build process is controlled by the db variable iapplxrpm.timeout (default 60 seconds), and the process is killed if it exceeds the timeout. The UCS file will be created, but the iApps LX extension RPMs that were killed due to a timeout will not be included in the UCS. Therefore, those iApps LX extensions will not be functional after the UCS is restored on a new device.

In addition, the REST API has other related timeout configurations: restjavad.timeout and icrd.timeout (both have default 60 seconds).

Answer/Recommended Actions

Check if your device is applicable:

If you see one or more directories under /var/config/rest/iapps excluding RPMS directory, the device is applicable, and those directories will be packaged as an RPM.

ls -l /var/config/rest/iapps

For example, directories like the ones below exist when AS3 and Telemetry Streaming are installed.

total 16
drwxr-xr-x. 8 restnoded restnoded 4096 Feb  3 23:12 f5-appsvcs              # AS3
drwxr-xr-x. 6 restnoded restnoded 4096 Feb  3 23:13 f5-service-discovery    # F5 Service Discovery that comes with AS3
drwxr-xr-x. 6 restnoded restnoded 4096 Mar  2 22:24 f5-telemetry            # F5 Telemetry Streaming
drwxr-xr-x. 2 root      root      4096 Feb  3 23:23 RPMS

A) When using GUI or TMSH to create a UCS file

Increase the value of the following DB variable:

  • iapplxrpm.timeout: The timeout value (default 60 seconds) for the building process of an iApps LX RPM package. The process sequenctially packages iApps LX directories one by one, and the timeout is per directory or the package. It's likely the value 120 is enough for AS3 and Telemetry Streaming. Increase the value again when rpm build fails during the process. Please refer to K04548517 for the sample errors of an rpm build failure.

tmsh modify sys db iapplxrpm.timeout value 120
tmsh restart sys service restjavad

B) When using REST API (iControl REST or Ansible Playbook)

Increase the value of the following DB variable:

  • iapplxrpm.timeout: See above for the explanation.
  • restjavad.timeout: The timeout value (default 60 seconds) for the restjavad tasks. It needs to cover the time it takes to create a UCS file, and it should be set longer on the device with larger configurations or many iApps LX extensions installed.
  • icrd.timeout: The timeout value (default 60 seconds) for the REST API timeout. For example, when querying the status of an asynchronous UCS create task against https://{{host}}/mgmt/tm/task/sys/ucs/{{taskId}}, while the task is running, the request may timeout after icrd.timeout.

tmsh modify sys db iapplxrpm.timeout value 120
tmsh modify sys db restjavad.timeout value 300
tmsh modify sys db icrd.timeout value 300
tmsh restart sys service restjavad
