Issue

Error Message

Interface <3.x> media type is incompatible with other trunk members

In this error message, note the following:

  • <3.x> is the interface port

For example:

Interface 3.1 media type is incompatible with other trunk members

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all| of the following conditions are met:

  • You attempt to configure an interface trunk consisting of member interfaces 3.1 and 3.2 on a BIG-IP 8900 or 8950 platform.
  • One or more of the following conditions exist:
    • One or both of the 3.1 and 3.2 SFP+ ports do not have an interface module plugged in.
    • One or both of the 3.1 and 3.2 SFP+ ports have an SFP interface module plugged in.
      Important: The SFP+ ports on the BIG-IP 8900 and 8950 platforms only support SFP+ modules and do not support SFP modules.

Impact

You cannot create the interface trunk.

Recommended Actions

You must perform a physical inspection of the modules installed in the SFP+ ports to ensure that the modules are present and that they are the proper module type.
