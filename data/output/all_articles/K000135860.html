Description

What does the BIG-IP do with the REPORT HTTP Request Method? 

Environment

  • HTTP Profile
  • REPORT HTTP Request Method

Cause

The BIG-IP treats the REPORT HTTP Request Method an "Unknown Method"
By default the BIG-IP will allow an unknown method.

Recommended Actions

You can configure the Unknown Method setting in the HTTP Profile to Allow, Reject, or Pass Through an unknown method.

For information about the HTTP Profile, refer to K40243113: Overview of the HTTP profile
