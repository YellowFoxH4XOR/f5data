Description

You have assigned priority group to pool members and you expect the standby pool member to process traffic when primary pool member goes down, while traffics are load balanced to all available pool members.

For example, a pool is configured as below:

ltm pool /Common/pool_test_80 {
    load-balancing-mode least-connections-member
    members {
        /Common/10.1.1.11:80 {
            address 10.1.1.11
            priority-group 10
        }
        /Common/10.1.1.12:80 {
            address 10.1.1.12
            priority-group 5
        }
    }
    monitor /Common/tcp
}

You observe that all members are processing traffic.

Environment

  • Pool Member
  • Priority Group
  • Minimum Active Members

Cause

By default, the value of minimum active members is 0 and when it's 0, the Priority Group Activation is disabled.

Recommended Actions

Set a non-zero value, less than the amount of pool member, to minimum active members to enable Priority Group Activation by any one of following ways:

  • Navigate to Local Traffic >> Pools : Pool List >> Your Pool >> Members,  select "Less than..." for Priority Group Activation and set an integer value to Available Member(s).

  • Execute commands below in the command line of BIG-IP.

# tmsh modify ltm pool [enter pool name] min-active-members [enter integer value]

# tmsh save sys config

After that, the priority group of pool member will take into effect.

Note: Do not forget to synchronize configuration if your BIG-IP runs in HA or DSC after taking the modification.

Additional Information

For this example, if value of minimum active members is set to 1, then the configuration of pool_test_80 should look like below:

ltm pool /Common/pool_test_80 {
    load-balancing-mode least-connections-member
    members {
        /Common/10.1.1.11:80 {
            address 10.1.1.11
            priority-group 10
        }
        /Common/10.1.1.12:80 {
            address 10.1.1.12
            priority-group 5
        }
    }
    min-active-members 1
    monitor /Common/tcp
}
