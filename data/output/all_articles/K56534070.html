K56534070: Error Message: Unable to grant license key: Error 51078 License error Incompatible Products and Add-on keys

Type
Support Solution
Published
2025-07-18
Updated
2025-07-18
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K56534070

Description

When you receive error message: Unable to grant license key: Error 51078, Incompatible Products and Add-ons - Keys are not valid for this EM platform : XXXXXXX-XXXXXXX, the key is causing the issue.

  • Incompatible Products and Add-ons
  • Keys are not valid for this Product Name or Platform Module

Environment

  • Unlicensed BIG-IP product
  • Attempting to add/activate an Add-on module license

Cause

The detected platform is not in the same product family as either the Base Registration Key or Add-ons found in the dossier. A BIG-IP base or add-on key can only be used on a BIG-IP platform.

Recommended Actions

  • Verify the Add-on key used is from same product family, by contacting F5 Technical Support.
  • If it is not a part of the same product family, you'll need to contact your F5 Account Manager for a compatible key.
