K000152573: Is there a limit to the number of syslog servers that can be configured in F5OS?

Description

Is there a limit to the number of syslog servers that can be configured in F5OS?

Environment

  • F5OS-A
  • F5OS-C
  • Syslog Server

Cause

There is no hard-coded limit to the number of destination syslog servers that can be configured in F5OS. However, there may be an upper limit to the number of configured syslog server that should be configured and this is dependent on the individual environment that the F5OS system is deployed in.
