Description
A BIG-IP system allowing iControl REST may generate an error message "user 21232f29-7a57-35a7-8389-4a0e4a801fc3 has reached maximum active login tokens".

Environment

  • A BIG-IP/VIPRION system is accessed via iControl REST.
  • The BIG-IP/VIPRION system is configured with remote authentication.
  • The account admin is used to access this BIG-IP/VIPRION system.

Cause
Although non-admin users have the limitation of 100 tokens, the admin user doesn't have this limitation. 

Recommended Actions

It is recommended that remote applications leveraging iControl REST be optimized to reuse available tokens.

Additional Information

For more information on iControl REST Authentication token management, refer to iControl REST Authentication Token Management on DevCentral
