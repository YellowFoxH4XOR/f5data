K33441547: SNMP traps for virtual server up/down log events are missing

Type
Support Solution
Published
2019-11-22
Updated
2025-04-03
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K33441547

Description

Some of the SNMP traps triggered based on "<VIP> has become available", "<VIP> has become unavailable" log events are not being sent to configured destination.
  • System logs VIP up/down events messages along with "Per-invocation log rate exceeded; throttling" log.
    Nov  8 09:11:05 BiGIP_C notice mcpd[8944]: 01071682:5: SNMP_TRAP: Virtual /Common/vip1 has become unavailable
    Nov  8 09:11:05 BiGIP_C notice mcpd[8944]: 01071682:5: SNMP_TRAP: Virtual /Common/VIP3 has become unavailable
    Nov  8 09:11:05 BiGIP_C notice mcpd[8944]: 01071682:5: SNMP_TRAP: Virtual /Common/VIP4 has become unavailable
    Nov  8 09:11:05 BiGIP_C notice mcpd[8944]: 01071682:5: SNMP_TRAP: Virtual /Common/VIP5 has become unavailable
    Nov  8 09:11:05 BiGIP_C notice mcpd[8944]: 01071682:5: Per-invocation log rate exceeded; throttling.

Environment

  • BIG-IP is configured to send SNMP traps.
  • Virtual Server event traps are sent (default behavior)
  • "Per-invocation log rate exceeded; throttling" error message indicating that more than five log messages with the same message ID were logged within a one-second interval.

Cause

Missing SNMP trap events are caused due to BigIP system log throttling described in the article below:
K10524: Error Message: Per-invocation log rate exceeded

Recommended Actions

In order to workaround this issue a local log-config filter can be created that matches a specific message-id and transmits it to the local-syslog log publisher. Once particular log entry is matched with explicit log-config filter it will not be throttled. 

From the CLI enter following commands:

tmsh create /sys log-config publisher local-syslog destinations add { local-syslog }
tmsh create /sys log-config filter stop_throttling_vip_down message-id 01071682 publisher local-syslog
tmsh create /sys log-config filter stop_throttling_vip_up message-id 01071681 publisher local-syslog
tmsh save /sys config
