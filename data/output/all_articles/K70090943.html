Description

After upgrading the BIG-IP software an application no longer operates as expected.  This can occur when BIG-IP is performing some logic on the SSL Certificate Subject since the order has changed in later software versions.  This may include:

  • iRule processing SSL Certificate Subject
  • APM Policy processing the SSL Certificate Subject

Environment

  • Upgrading BIG-IP software to v12.1.4.1 or above
  • BIG-IP logic processing of SSL Certificate Subject

Cause

A change in behaviour was introduced from v12.1.4.1 described in the following knowledge article:

K14204621: The X509::subject iRules command now returns the subject of the specified X509 certificate based on OpenSSL order

Recommended Actions

The BIG-IP logic for processing the SSL Certificate Subject would need to be revised to align with the new format

Additional Information

None.
