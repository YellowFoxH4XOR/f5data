K35423395: Peer Time Out of Sync

Type
Support Solution
Published
2022-05-17
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K35423395

Description

  • On GUI and Console you can see the message "Peer Time Out of Sync"
  • NTP server seems not to be reachable from ntpd -np command

    ntpq -np

    remote refid st t when poll reach delay offset jitter
    ==============================================================================
    172.28.4.133 .INIT. 16 u - 64 0 0.000 0.000 0000.00

Environment

  • LTM
  • HA Pair
  • NTP

Cause

BIG-IP devices are not getting ntp response from configured NTP serves.

Recommended Actions

Perform the procedure described in K10240 to verifying the NTP peer server communications

Additional Information

None
