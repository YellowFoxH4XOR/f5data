K000133205: How to view raw event logs and statistics directly from the DCD(s)

Type
Support Solution
Published
2023-03-27
Updated
2023-03-27
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.X, 8.1.X, 8.0.X, 8.2.0, 8.1.0, 8.0.0
Source
https://my.f5.com/manage/s/article/K000133205

Description

  • You want to view raw logs that the managed BIG-IP sending via AVR directly in the BIG-IQ DCD(s)

Environment

  • BIG-IQ DCD
  • Raw logs and statistics viewing
  • Managed BIG-IP

Cause

None

 Recommended Actions

  1. Turn on appiq-am-file-recorder on DCD to check the ingress AVR stats/events (but it doesn't diff AVR data from data on other managed devices, the results could be verbose, will need to grep the output by hostname)

To Turn on: # curl -X GET http://localhost:9081/appiq-am-file-recorder/enable; echo

To Turn off: # curl -X GET http://localhost:9081/appiq-am-file-recorder/disable; echo

 

Note: the output file is in /var/log/appiq/agentmanager-recorder*

Additional Information

Only turn on appiq-am-file-recorder for troubleshooting purposes as it may fill up /var/log disk usage
