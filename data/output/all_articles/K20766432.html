Known Issue

An Open Shortest Path First (OSPF) routing protocol with multiple processes may incorrectly redistribute routes.

This issue occurs when all of the following conditions are met:

  • You have configured OSPF routing with multiple processes.
  • Each OSPF process is configured with a different route type redistributed.

Impact

When OSPF converges, the network will contain incorrect routing information.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you configure OSPF with multiple processes that each redistributes a different type of route, the system may create link-state advertisements (LSAs) in a process for a route type that is different from the route type that is configured for redistribution into that process.

Workaround

To work around this issue, you can redistribute the leaked route type into the affected OSPF process and use a route map that filters out all routes.
