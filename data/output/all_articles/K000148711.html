K000148711: Add Chargeback tag to Self Service license keys in MyF5

Type
Support Solution
Published
2024-12-17
Updated
2025-02-10
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000148711

Description

You need to add a descriptive tag to a license key via MyF5 Self Service. This allows you to track how the Big-IP Virtual Edition (VE) is used or who owns it.

Environment

  • New FCP Contract

  • BIG-IP Virtual Edition (VE)

  • MyF5 Customer Portal

  • Editor/Admin access to MyF5 Subscription
  • Existing license keys

Cause

Starting in January 2025, new FCP customers can add and edit the chargeback tag on license keys on their MyF5 Customer Portal.

Recommended Actions

To add or edit a chargeback tag:

Important: Once a chargeback tag is added, this field must always contain characters. It can't be blank anymore.

  1. Logon to MyF5.
  2. Select "Registration Keys" from the "My Products & Plans" dropdown menu.
  3. Fill the radio button to the left of the relevant registration key.
  4. Click the "Edit Key" option.
  5. From the Actions dropdown menu, select Chargeback / Cost Centers.
  6. In the Chargeback / Cost Center text field, enter a relevant description or cost center for this key
  7. Click Submit to save.
  8. Allow up to 15 minutes to see these changes.

Important: This field is preserved when the key is terminated. No changes can be made after the key is terminated. Make sure to update this field prior to key termination if needed.
