Description

You configure new virtual servers on your BIG-IP, but find they do not respond to traffic
Packet captures show traffic reaching the BIG-IP, but the virtual server doesn't provide any type of response
Virtual server statistics indicate no traffic has been received or sent

Environment

  • BIG-IP LTM
  • Virtual Server
  • VLAN specific configuration

Cause

The VLAN and Tunnel Traffic setting on virtual servers can prevent the virtual server from sending or receiving traffic on expected vlans if misconfigured

Recommended Actions

Review the VLAN and Tunnel Traffic setting on effected virtual servers to ensure they are able to send and receive traffic from the appropriate VLANs
  1. Navigate to Local Traffic > Virtual Servers and select the virtual server in question
  2. Set Configuration to Advanced
  3. Scroll down to VLAN and Tunnel Traffic and set it to be enabled on the appropriate VLANs or All VLANs and Tunnels
