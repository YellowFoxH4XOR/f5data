Topic

You should consider using this procedure under the following condition:

  • You want to obfuscate sensitive data, such as passwords, in a QKView file.

Description

The qkview utility is a tool that allows you to automatically collect configuration and diagnostic information from BIG-IP, BIG-IQ, and F5OS systems. By default, sensitive data, such as SSL keys, are excluded from QKView files. However, in some cases you may want to include sensitive information in the QKView file and need to obfuscate it for security purposes.

On BIG-IP systems, you can specify data that you want to obfuscate in the QKView file by using regular expression matching. You can obfuscate the data by editing the /etc/qkview_obfuscate.conf file to contain a list of regular expression matching and substitution strings using JavaScript Object Notation (JSON) formatting rules.

The following example shows the syntax rules for the /etc/qkview_obfuscate.conf file:

/*
Comments section
*/
{
    "filename_regex1": {
           "search_regex11": "replace_text11",
           "search_regex12": "replace_text12",
           "search_regex13": "replace_text13"           <= No comma at the last element
       },
    "filename_regex2": {
           "search_regex21": "replace_text21",
           "search_regex22": "replace_text22",
           "search_regex23": "replace_text23"
       }                                                <= No comma at the last node
  }

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the BIG-IP Advanced Shell (bash).
  • You are familiar with regex matching and substitution strings and JSON formatting rules.

Procedures

  • Configuring the qkview_obfuscate.conf file
  • Verifying the qkview_obfuscate.conf configuration

Configuring the qkview_obfuscate.conf file

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Use a text editor such as vi to edit the /etc/qkview_obfuscate.conf file. For example:

    vi /etc/qkview_obfuscate.conf

  3. Go to the end of the comments section by pressing ESC followed by G.

    The comments section starts at the top of the page with /* and ends with */.

  4. Add the appropriate regex matching and substitution strings, using JSON formatting. For example:

    {
      "/config/abc123\\.conf": {
        "password\\s+(\\S+)": "password ####",
        "passphrase\\s+(\\S+)": "passphrase ####"
      },
      "/etc/myapp?\\w+\\.conf": {
        "bindpw\\s+(\\S+)": "bindpw dummypasswd"
      }
    }

    In the previous example, the following matching rules apply:

    • /config/abc123\\.conf matches /config/abc123.conf, and any string after the word password or passphrase is converted to ####.
    • /etc/myapp?\\w+\\.conf matches /etc/myapp*.conf, and any string after the word bindpw is converted to dummypasswd
  5. Save the changes and exit the file.

Verifying the qkview_obfuscate.conf configuration

To verify that you used the correct formatting for the qkview_obfuscate.conf file and that the sensitive data is properly obfuscated, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Type the following command from the BIG-IP command line:

    qkview

    Note: If the configuration file is syntactically incorrect, the qkview command returns an error message similar to the following example:

    Gathering System Diagnostics: Please wait ...
    Failed to parse Obfuscation config!!

  2. After you generate the QKView file, verify that sensitive data is properly obfuscated using the following tar command syntax:

    tar xfz <qkview file> <configuration file> -O

    For example, the following tar command verifies that the config/abc123.conf password used in the previous procedure is properly obfuscated:

    tar xfz /var/tmp/localhost.localdomain.qkview config/abc123.conf -O

    # this is a test
    password ####
