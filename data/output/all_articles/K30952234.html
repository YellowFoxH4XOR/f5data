K30952234: CLI prompt states 'PREFER afm PROVISION' after deprovisioning AFM

Type
Support Solution
Published
2020-08-04
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP AFM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K30952234

Description

After AFM is deprovisioned from the system, looking at the CLI prompt, it show up as:

[user@hostname:PREFER afm PROVISION:Standalone] config #

You might also see some logs similar to the one below:

01071859:4: Warning generated : Warning: please provision afm for full feature capability of the current active TurboFlex profile chosen, or use another Turboflex profile. For more information, use "help sys provision/turboflex".

Environment

  • BIG-IP that had AFM module deprovisioned
  • Turboflex profile (turboflex-security) configured

Cause

The Turboflex profile (turboflex-security) that is AFM-dependent remains intact and selected even after AFM is deprovisioned.

Recommended Actions

Update the Turboflex profile to something other than "turboflex-security".

To do so perform one of the following procedures:

From the Configuration Utility

  1. Navigate to System ›› Resource Provisioning : TurboFlex
  2. Change the profile to something other than 'turboflex-security'
  3. Click UPDATE
  4. Reboot

From the CLI

  1. tmsh modify sys turboflex profile-config type <profile>
  2. tmsh save sys config
  3. reboot
