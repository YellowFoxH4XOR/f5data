K000140390: Failover cause Access connection failure

Type
Support Solution
Published
2024-09-05
Updated
2024-09-05
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.2
Source
https://my.f5.com/manage/s/article/K000140390

Description

Without Access Policy, VIP works, and with Access policy, VIP works.

When failover, with Access policy, VIP stop working. But Without Access Policy, VIP works on the unit.

 

Environment

  • BIG-IP APM
  • HA pair
  • Failover
  • VIP with Access policy

 

Cause

One of possible reason is APM license limitation. Check /var/log/apm log.

  • K15026: Error Message: Global concurrent access session limit reached
  • K000134529: Error Message: Global concurrent url limited license limit reached. 
  • K15031: Error Message: Global concurrent connectivity session limit reached 

 

Recommended Actions

To check the license detail about APM, run the below command on CLI on both unit and check if they have same level of license.

tmsh show apm license

The best practice is HA pair has same number of access connection limit license for same unit. Please contact your usual F5 Sales team about license and order.

 

Additional Information

  • K15032: Determining license limits of the BIG-IP APM system
  • K52743138: APM CCU (VPN / Portal Access) license capacity/limit
