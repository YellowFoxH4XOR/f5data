Known Issue

The BIG-IP 4200v platform may experience a memory allocation failure when performing compression operations.

This issue occurs when the following condition is met:

  • The BIG-IP 4200v platform is configured to perform compression.

Impact

Compression operations may fail, and the system resets affected connections.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H453739 on the Diagnostics > Identified > High screen.
  • The system resets client connections to compression-enabled virtual servers.
  • Error messages similar to the following are logged to the /var/log/ltm file:

    crit tmm7[18648]: 01010025:2: Device error: (null) qa_dc_get_flat_buffer: Allocation linked list is empty
    err tmm7[18648]: 01010004:3: Memory allocation failed: qa_dc_dev_init_buffer_list: Couldn't allocate memory for buffer list.
    err tmm7[18648]: 01230140:3: RST sent from 10.1.2.201:41805 to 10.1.1.51:80, [0x171d345:974] {peer} Compression error (Out of memory)
    warning tmm7[18648]: 011e0001:4: Limiting open port RST response from 251 to 250 packets/sec
