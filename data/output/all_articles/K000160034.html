Description

After upgrading to BIG-IP ASM version 17.5.1.3, brute force protection configured for NTLM authentication stops blocking failed login attempts. The system correctly detects and logs failed authentication attempts, and brute force mitigation actions (such as "drop") are triggered in the logs when thresholds are exceeded. However, the expected blocking does not occur—users continue to receive NTLM authentication prompts instead of being denied access. This issue specifically affects NTLM authentication flows, such as those used with Outlook Web Access (OWA).

Environment

  • Virtual server configured for OWA (Outlook Web Access) using NTLM authentication
  • ASM security policy with brute force protection enabled
  • Brute force thresholds and actions configured
  • NTLM profile applied to the virtual server
  • ID1505257 is included in the Engineering Hotfix

 BUG ID2173429
