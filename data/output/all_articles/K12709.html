Known Issue

This is the result of a known issue. In BIG-IP ASM 10.2.0 and 10.2.1, if you have IP addresses configured in the Ignored IP Addresses list for the Policy Builder feature, the system does not save these values when it creates a unified computing system (UCS) archive. As a result, if you use the UCS archive to restore the configuration, the BIG-IP ASM policy does not contain the Ignored IP Addresses list and you have to manually re-enter the addresses, as needed.

Note: For more information about Ignored IP Addresses, refer to the Refining the Security Policy Using Learning section of the Configuration Guide for BIG-IP Application Security Manager.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

F5 Product Development tracked this issue as ID 353163 and it was fixed in BIG-IP ASM 10.2.2. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue and save the configured Ignored IP Addresses by modifying the /ts/install/plc.sql file. To do so, perform the following procedure:

  1. Log in to the BIG-IP ASM command line.
  2. Using the text editor of your choice, open the /ts/install/plc.sql file for editing.
  3. Locate the following line:

    --CONFIG_SYNC:PLC.LRN_BLACK_LIST_FILETYPES

  4. On the line preceding the line in step 3, type the following command:

    --CONFIG_SYNC:PLC.LRN_BLACK_LIST_SRC_IPS

  5. Save and exit the file.

Note: This workaround saves the Ignored IP Addresses values to the UCS file. However, if you upgrade or install any hotfixes to the BIG-IP ASM system after applying this workaround, you must perform this workaround again, as the /ts/install/plc.sql file reverts to its default state after you upgrade or install hotfixes.
