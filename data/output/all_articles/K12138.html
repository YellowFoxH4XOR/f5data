Topic

When a BIG-IP system is configured to display the DNS host name for system objects (such as virtual addresses, pool members, and nodes) the Configuration utility displays the DNS host name on most configuration pages. However, the Network Map and the Statistics section display only IP addresses and do not display the DNS host name of these objects. This behavior is by design.

Note: For information about configuring the BIG-IP system to display the DNS host name of system and network objects, refer to K8439: Configuring local hostname resolution for BIG-IP (9.4.2 - 10.x).

F5 Product Development is tracking the enhancement to allow the DNS host name of objects to be displayed in the Network Map and Statistics section of the Configuration utility as ID 247230 and ID 340723.
