Issue

Error Message

01140102:2: Overdog daemon requests reboot.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.
Description

This message occurs when the following condition is met:

  • The system process has requested a reboot of the BIG-IP system.

The overdog process monitors the high availability (HA) table for processes requesting a failsafe action. For more information, refer to the following articles:

  • K9231: Overview of BIG-IP daemon heartbeat failover
  • K13297: Overview of VLAN failsafe (10.x - 13.x)

Impact

No traffic processing will occur while the BIG-IP system reboots for standalone systems, and a failover event will occur if the BIG-IP system is in an HA configuration.

Recommended Actions

This error message should be preceded by a message indicating the reason for the requested reboot. In the following example, a Virtual Local Area Network (VLAN) failsafe event has occurred and is requesting a reboot:

01140029:4: HA vlan_fs /Common/VLAN1 fails action is reboot.
01140102:2: Overdog daemon requests reboot.
