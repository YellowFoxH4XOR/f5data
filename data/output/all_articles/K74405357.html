Description
Under Local Traffic ›› Pools : Pool List,   you notice a Pool member  with a Red rectangle status (marked down) 

Environment

  • BIG - IP
  • Pool Member

Cause
Incorrect IP on Self IP 

Recommended Actions

  1.  Ping the pool member from the device's own CLI
  2.  Ping Self-IP
  3.  Ping from BIG IP to any Self-IP
  4. If the pool does not respond, check within your subnet if the Self-IP has the correct IP
  5. If  IP from Self-IP is not the correct one, please follow the  following procedure to add a new Self-IP

Impact of procedure: This should not have a negative impact on your system. However, it is recommended that you create a backup and perform these actions during a maintenance window.

  1. Log in to the Configuration utility of the device that requires the Self IP address change.
  2. Click on Device Management.  
  3. Click on Devices.
  4. Select Device name (self).
  5. Select the Self IP address you are changing and click Delete.
  6. Then create a new Self-IP with the correct  IP 
  7. after following those steps  the pool shows as offline, please open a support ticket  for further troubleshooting
