Description

The customer attempted to configure two separate log rotation stanzas under sys log-rotate syslog-include:

syslog-include "/var/log/test1.log {
nocompress
missingok
notifempty
sharedscripts
postrotate
endscript
rotate 14
}"

syslog-include "/var/log/test2 {
nocompress
missingok
notifempty
sharedscripts
postrotate
endscript
rotate 7
}"

He attempted to define two separate syslog-include entries.

Environment

  • BIG-IP LTM
  • Syslog

Cause

The BIG-IP TMSH data model only supports a single string value for the syslog-include parameter. Multiple logrotate stanzas must be concatenated into one string for proper operation.

Recommended Actions

To configure log rotation for multiple custom log files with different policies:

  1. Concatenate all required logrotate stanzas into a single syslog-include string, with each file block defined sequentially.
  2. Apply the configuration using the following TMSH command (adjust file names and rotation parameters as needed): 
    tmsh modify sys log-rotate syslog-include "/var/log/test1.log {
    nocompress
    missingok
    notifempty
    sharedscripts
    postrotate
    endscript
    rotate 14
} /var/log/test2 {
    nocompress
    missingok
    notifempty
    sharedscripts
    postrotate
    endscript
    rotate 7
}"
tmsh save sys config
  3. Verify the running config after applying change: 
    tmsh list sys log-rotate syslog-include
    This will confirm the concatenated string was accepted correctly before testing rotation.
  4. (Optional) Validity test without performing actual rotation (This command does NOT perform any actual rotation and will show why postrotate script is not executed):  
    logrotate -d /etc/logrotate.conf
  5. (Optional) Force an immediate rotation to validate the configuration:  
    logrotate -f /etc/logrotate.conf
    This forces rotation of all configured log files immediately, regardless of schedule. Verify that rotated files appear (e.g., /var/log/test1.log.1, /var/log/test2.1)
  6. Validate log rotation by checking /var/lib/logrotate.status and listing rotated log files: 
    cat /var/lib/logrotate.status | grep test1
ls -lhk /var/log/test1*

cat /var/lib/logrotate.status | grep test2
ls -lhk /var/log/test2*
  7. Reapply the configuration after software upgrades, as it may not persist.
  8. Apply the same configuration on all devices in an HA pair, as this setting is not always synced.

 

Additional Information

  • The syslog-include parameter is a single string and does not support multiple discrete entries.
  • Each logrotate stanza for different log files must be included sequentially within the same syslog-include string.
  • Successful log rotation can be confirmed by checking the /var/lib/logrotate.status file and verifying the presence of rotated log files.
  • Always back up your configuration before making changes.
