K53241922: BIG-IQ taking long time to load after upgrade due to error in Launch Logs: CalledProcessError: Command '['/usr/bin/ha_generate_certs',u'<IP>''']' returned non-zero exit status 1

Type
Support Solution
Published
2021-06-01
Updated
2023-10-16
Source
https://my.f5.com/manage/s/article/K53241922

Description

  • After the initial boot and the post-boot activities occur, the bootstrap log (/var/log/bootstrap/bootstrap[date and time].out) and the GUI will show something like below:
Errors on Launch
Traceback (most recent call last):
  File "/usr/local/lib/python2.7/site-packages/bigiq_setup/configuration/bootstrap.py", line 239, in main
    _do_bootstrap(out)
  File "/usr/local/lib/python2.7/site-packages/bigiq_setup/configuration/bootstrap.py", line 211, in _do_bootstrap
    out
  File "/usr/local/lib/python2.7/site-packages/bigiq_setup/configuration/commands.py", line 416, in generate_certs
    close_fds=True
  File "/usr/local/lib/python2.7/subprocess.py", line 186, in check_call
    raise CalledProcessError(retcode, cmd)
CalledProcessError: Command '['/usr/bin/ha_generate_certs', u'192.168.1.10']' returned non-zero exit status 1
 

Environment

  • BIG-IQ upgrade to 7.1.0 or later
  • Neither management nor self address are configured to the IP address in question (in the above example, 192.168.1.10 is not a management nor a self IP)

Cause

After upgrade, the system returned a non-zero status which means that an error occurred; in this case, the bootstrap program couldn't find a matching IP address. 

Recommended Actions

Change the BIG-IQ discovery address to match either the Management IP or Self IP address based on your set-up/design (see K99418679): 

  1. Go to System > THIS DEVICE > General Properties.
  2. Select the Return to Setup button.
  3. Select Continue to enter setup mode.

    You are logged out and system services is stopped.

  4. Once the BIG-IQ user interface is available, log back in as the administrative user and you should now be redirected to the setup wizard.
  5. Select Next to advance.

    You may have to select Discard Changes to proceed.

    Once you are on the Password step, you must re-configure the Admin and Root passwords. Use the current passwords for this step.

  6. Continue selecting Next to advance to the Networking step.
  7. When on the Networking step, select a new option for Discovery Address.
  8. Select Next until you reach the final step, then select Launch.
