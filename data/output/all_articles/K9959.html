Known Issue

This is the result of a known issue. When the remove_all_region_items iControl command for the BIG-IP GTM system is used to delete all members from a specified topology region, all members in all regions are deleted, rather than just those in the specified region.

F5 Product Development tracked this issue as CR114330 and it was fixed in BIG-IP 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

You can work around this issue by using the Configuration utility to remove only the intended region members. To do so, perform the following procedure:

  1. Log in to the BIG-IP GTM Configuration utility.
  2. Click Global Traffic.
  3. Click Topology.
  4. Click Regions.
  5. Click the region whose members you want to delete.
  6. In the Member List in the Region Members section, select all existing entries.
  7. Click Remove.
  8. Click Update.
