Issue

Error Message

bcm56xxd: 012c0013:6: BCM56XXD starting.

For example:

bcm56xxd: 012c0013:6: BCM56xxd starting. debug=0, foreground=1, packet=1, bcm_debug=0x7, soc_debug=0x0

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm log file
  • The /var/log/daemon.log log file

    Note: In the /var/log/daemon.log file, the error appears similar to the following example:

    emerg logger: Re-starting bcm56xxd

Description

This message occurs when the following condition is met:

  • The bcm56xxd process starts.

This usually occurs when the BIG-IP system boots or restarts. This message is informational and indicates the bcm56xxd switch daemon has begun execution.

Impact

None. The message is informational.

Recommended Actions

None
