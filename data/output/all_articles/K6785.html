Topic

A link is a BIG-IP DNS (formerly known as BIG-IP GTM) or BIG-IP Link Controller object that defines a physical connection to the Internet. A link is associated with one or more routers on the network that provide a path to the Internet. When you add a link in the BIG-IP DNS or BIG-IP Link Controller configuration, you can assign the link an uplink address that represents the IP address of your router on the ISP side of the link.

The uplink address is used to gather SNMP metrics from the router interface. When an uplink address is configured, the BIG-IP DNS or BIG-IP Link Controller system sends SNMP requests to the IP address configured in the Router Address List of the Configuration utility's Link General Properties page. The router returns interface statistics for the interface configured as the uplink address. The uplink address helps the BIG-IP DNS or BIG-IP Link Controller system distinguish between internal-only traffic and traffic that traverses the router and is destined for the Internet.

For example, some installations have a significant amount of internal-only traffic passing through the router interface on the BIG-IP DNS or BIG-IP Link Controller side of the router. Without the uplink address configured for the link, the BIG-IP DNS or BIG-IP Link Controller system is not able to make an accurate assessment of how much traffic passes through the router to the ISP side. With the uplink address configured, the BIG-IP DNS or BIG-IP Link Controller system can gather accurate interface metrics from the router and can make load-balancing decisions based on the statistics it obtains.

You do not need to configure the uplink address on installations without a significant amount of internal-only traffic passing through the router interface on the BIG-IP DNS or BIG-IP Link Controller side of the router. If there is not a significant amount of internal-only traffic passing through the router, the BIG-IP DNS or BIG-IP Link Controller system can use the link address to gather accurate interface metrics from the router.

Defining the uplink address

  1. Log in to the Configuration utility.
  2. Perform one of the following actions:
    • In BIG-IP DNS, navigate to DNS > GSLB > Links.
    • In BIG-IP GTM, navigate to Global Traffic > Links.
    • In BIG-IP Link Controller, navigate to Link Controller > Links.
  3. In the Links list, click a link.
  4. Enter the uplink address, which is the IP address of the router on the ISP side of the link.
  5. Click Update.
