NGINX Open Source branches

NGINX has the following two branches in the NGINX Open Source code repository:

  • Mainline is the active development branch where the latest features and bug fixes are added. F5 recommends that you use the latest mainline version to get the most up-to-date features, bug fixes, and security patches. A mainline release is identified by an odd number in the second part of the version number, for example, 1.25.0.
  • The stable branch has an annual release cycle, usually in April, and inherits all the bug fixes, features, and other changes that went into the mainline branch during the previous year. Minor releases for stable versions are provided only to address security patches and/or critical bug fixes. No additional features are provided in the minor releases. A stable release is identified by an even number in the second part of the version number, for example, 1.24.0.

Mainline releases

NGINX mainline releases published within the last two years are supported. F5 commits all new features, performance improvements, and enhancements into the mainline branch and actively tests and QAs each minor release. The latest minor version is also the source of NGINX Plus builds and is completely suitable for production use.

F5 recommends that you use the latest mainline version to get the most up-to-date features, bug fixes, and security patches.

Supported modules

If NGINX Open Source is obtained from the official F5 NGINX sources, the following modules, distributed from the same repository, are supported:

  • nginx-module-geoip
  • nginx-module-image-filter
  • nginx-module-njs
  • nginx-module-perl
  • nginx-module-xslt
  • nginx-module-otel (shipped as a separate package)

Note: All other modules (except those listed in the table) are not supported.

Additionally, the following scenarios are not supported by F5 support:

  • NGINX Open Source binaries compiled by anyone other than F5 NGINX.
  • Modules developed and/or compiled by anyone other than F5 NGINX.
  • NGINX Open Source prepackaged as part of an OS distribution.
  • NGINX products and third-party modules altered or modified by anyone other than F5 NGINX.
  • NGINX products and third-party modules used on, or in conjunction with, hardware or software other than as specified in official NGINX documentation.
  • Any custom scripts written on top of modules or to extend the functionality of these modules.
  • Defects in NGINX products and third-party modules due to accident, hardware malfunction, abuse, or improper use.
  • Versions of NGINX products and third-party modules for which support services have been discontinued by F5.
  • Errors caused by third-party modules not licensed through F5.
  • Evaluation software or other software provided by F5 at no charge, unless otherwise expressly provided in the associated license agreement.
  • pen source versions of other F5 products, unless otherwise expressly provided in the associated license agreement.
  • Products sold separately by F5.
