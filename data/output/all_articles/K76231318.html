Issue

Error Message

01890008:3: Postgres stopped with a non-zero status (<code>).

In this error message, note the following:

  • <code> is the PostgreSQL exit code

For example:

01890008:3: Postgres stopped with a non-zero status (1).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The PostgreSQL server encounters an error condition and shuts down

Impact

You are unable to view or edit BIG-IP AFM firewall rules while the PostgreSQL server is down.

Recommended Actions

  • Review the /var/log/ltm file for related PostgreSQL error messages, which may help determine the cause of the issue.
  • Restarting the PostgreSQL server may alleviate the issue. To forcibly restart the pgadmind and mcpd processes, perform the following procedure:

    Impact of procedure: The system becomes temporarily unavailable and is unable to process traffic while the BIG-IP daemons restart. A failover will occur if configured for high availability (HA).

    1. Log in to the TMOS Shell (tmsh) by typing the following command:

      tmsh

    2. Restart the pgadmind and mcpd processes by typing the following command:

      restart /sys service pgadmind mcpd
