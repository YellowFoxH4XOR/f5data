K45040120: SNMP traps on management interface not answered if V2 traps are configured

Type
Support Solution
Published
2021-12-17
Updated
2022-12-27
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K45040120

Description

SNMP traps do not work on management interface while they work on Self-IP

SNMP trap for management interface fails with below error:
[root@bigip1:Active:Standalone] tmp # snmpget -v 2c -c public 10.10.10.10 .1.3.6.1.4.1.3375.2.1.1.2.1.44.0
Timeout: No Response from 10.10.10.10

SNMP trap for Self-IP works:
[root@bigip1:Active:Standalone] tmp # snmpget -v 2c -c public 10.20.20.1 .1.3.6.1.4.1.3375.2.1.1.2.1.44.0
F5-BIGIP-SYSTEM-MIB::sysStatMemoryTotal.0 = Counter64: 6245318656

Environment

  • BIG-IP
  • SNMP V2 traps are configured
Note : You can confirm V2 traps are configured on the box by running "tmsh list /sys snmp v2-traps" or checking /config/bigip_base.conf file.

Cause

Bug ID 969737

Recommended Actions

The workaround is to move all traps configured under 'v2-traps' to 'traps' in the configuration.

In order to fix this issue, you can upgrade the device to version 16.1.0 which has the fix. 

Additional Information

None.
