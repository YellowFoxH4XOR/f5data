Description

This article focuses on the additional considerations/steps for the BIG-IP APM system upgrade issue.

Environment

  • BIG-IP APM
  • BIG-IP Edge client on Windows/MAC/Linux
  • Client Inspection
  • Remote desktop
  • Advanced customization

Cause

None

Recommended Actions

  • When upgrading the BIG-IP APM, the integrated APM Client package may be upgraded, causing the BIG-IP Edge client software upgrade.

Please review the article below, understand the version of BIG-IP APM client package.

K13757:  BIG-IP Edge Client version matrix

K52547540:  Updating BIG-IP Edge Client for the BIG-IP APM system

The BIG-IP Edge client on windows and MAC can be upgraded automatically by default.

K15302: Understanding BIG-IP Edge Client Component Update behavior for Windows and Mac OS

On Windows platform, the user maybe get the permission issue when upgrading the Edge client software.

There is a component: Component Installer Package for Windows, refer to the manual like:

Manual Chapter : BIG-IP Edge Client for Windows

By default the Edge Client package includes the Component Installer Package for Windows.

If the BIG-IP Edge Client is a browser plugin, the customer will get the permission issue and they need to run the browser as Administrator mode, or install the Components Installer.

If unexpected issue when the Edge Client upgrades, remove the client and re-install it again.

K8253:  Removing BIG-IP APM client components from Windows client systems

K42051301:  Removing F5 APM plugin components in the Firefox from Linux systems

K7791: Removing Network Access client components from Linux systems

K15539:  Removing BIG-IP Edge Client from Mac OS X devices

F5 Access on different platforms will not be impacted when upgrading BIG-IP APM server.

  • When upgrading the BIG-IP APM, the integrated OPSWAT EPSEC package may be upgraded due to the BIG-IP Edge client software upgrade.
    • K48955220:  Installing an OPSWAT Endpoint Security update on BIG-IP APM systems (11.4.x and later)

Note: Beginning in BIG-IP 14.1.0, EPSEC packages older than the pre-installed version cannot be installed.

K76295094:  Why can't I install the latest OPSWAT EPSEC package on my existing BIG-IP APM?

  • When upgrading the BIG-IP APM, the RDP configuration may be impacted.
K99140252:  Remote desktop resource configurations use native RDP as the client type by default in BIG-IP APM 15.1.0
  • When upgrading the BIG-IP APM, the advanced customization configuration may be impacted.

K38601341: Considerations when upgrading BIG-IP APM advanced customizations

K93289796: APM customization is broken post v15 upgrade

  • When upgrading the BIG-IP APM, please fully understand the downtime.

K25872674: Access Policy Manager upgrade of HA pair does not support zero downtime.

Additional Information

The upgrade process will backup the configuration and copy to the new version, please make sure the free disk space is enough, before the upgrade.

K92426918: Upgrade failed with /var/local/ucs/config.ucs: Not enough free disk space to install
