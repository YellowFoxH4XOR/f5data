Description

You may observe one or more [api-status-warning] warning message in /var/log/ltm when backing up a UCS :

 

warning tmsh[20873]: 01420013:4: [api-status-warning] sys/datastor is deprecated

warning tmsh[20873]: 01420013:4: [api-status-warning] sys/ecm/cloud-provider is deprecated

warning tmsh[20873]: 01420013:4: [api-status-warning] wom/deduplication is deprecated

warning tmsh[20873]: 01420013:4: [api-status-warning] wom/endpoint-discovery is deprecated

warning tmsh[20873]: 01420013:4: [api-status-warning] wom/server-discovery is deprecated

 

Environment

  • BIG-IP
  • Backing up a UCS

Cause

This is due to the objects in question has been deprecated and the warnings message can be safely ignored.

 

 Recommended Actions

If you would like to suppress the warnings message, perform the following procedure:
 

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
 

1.Log in to tmsh by typing the following command:

  tmsh
 

2.Disable deprecated API warning messages by typing the following command:

 modify /mgmt shared settings api-status log resource-property deprecatedApiAllowed false

 modify /mgmt shared settings api-status log resource deprecatedApiAllowed false
 

3.Save the change by typing the following command:

  save /sys config
