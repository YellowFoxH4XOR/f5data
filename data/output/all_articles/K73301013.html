Description

Apple IOS clients (iPhones, iPads) unable to connect and the client displays an error. 
"An SSL error has occurred and a secure connection to the server cannot be made" 

Environment

  • APM
  • VCMP guest v14.1.0.1 or later
  • VCMP host earlier than v14.1.0.1
  • ClientSSL profile has TLSv1.3 enabled

Cause

Client lists TLSv1.3 as a supported version, BIG-IP tries to use TLSv1.3 but this does not work because VCMP host is not on the required version.

Recommended Actions

To work around the issue follow any one of the below recommendations. 

  1. Disable TLSv1.3 on BIG-IP ClientSSL profile via Options (this is the default) on the VCMP Guest

    Or

  2. Upgrade VMCP Host to BIGIP V14.1.0.1 or later  

Additional Information

Packet capture shows that BIG-IP responds with TLSv1.3 Server Hello but does not get a response from the client. The connection is eventually reset by BIG-IP with cause "SSL handshake timeout exceeded"
