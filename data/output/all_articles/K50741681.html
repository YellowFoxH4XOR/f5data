Description

  • The "Changes Pending" status may only be for "asm-sync" device group 
  • Immediately after system synchronization, most often than not, the standby device indicates a changes pending status without apparent cause

or

  • The "Changes Pending" status in sync-failover group where "asm-sync" not configured in device group 

Environment

  • ASM
  • Change-Pending
  • Device-Group (DG) 

Cause

  • Misconfiguration of asm device group
  • ASM device group set to disabled in
    • Security  ››  Options : Application Security : Synchronization : Application Security Synchronization
  • ASM device group sync-type set to manual 
    • Device Management  ››  <name of asm sync DG>

Recommended Actions

F5 Networks recommends that the "asm-sync" group set to sync-only device group with autosync enabled 
As well as, one of the "non-asm-sync" device groups be configured as the sync-failover group, preferably with incremental sync instead of full load on sync and auto-sync disabled.

  • Associate sync only DG to ASM Application Security Synchronization
  1. Navigate to  Security  ››  Options : Application Security : Synchronization : Application Security Synchronization
  2. Make sure the 'Device Group' is associated to a sync only DG
  3.  click save
  • Modify the sync type in the DG
  1. Navigate to  Device Management  ››  <name of asm sync DG>
  2. Set device group sync-type to automatic with Incremental sync
  3. Click update
  • Once configured and applied the above configuration, sync/push configuration from the device with the latest configuration
