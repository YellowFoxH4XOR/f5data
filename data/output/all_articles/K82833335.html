Description

  • In software version 12.x the local-dos logging profile was editable and you could set remote-logging and change several parameters.
  • The problem is that in the upgrade process (v12 -> v14) any custom configuration on local-dos logging profile is carried over but now you are unable to modify it
  • When trying to modify the  local-dos logging profile  the following message appears:

    System defined Application Security log profile '/Common/local-dos' cannot be modified.

Environment

  • Upgrade from software version 12.x to 14.x
  • Modified default local-dos logging profile with custom configuration

Cause

Seen behavior is expected. Starting in software version 14.x the local-dos logging profile became uneditable.

Recommended Actions

Create a new custom dos logging profile and restore the local-dos logging profile to the default values. To do so please perform the following steps

  1. Create & Export a UCS archive from the current volume
  2. Connect to CLI
  3. Edit the bigip.conf and change the name to the profile. Example:
    security log profile /Common/local-dos {                        <===== Change to new name example: security log profile /Common/mydos
        built-in enabled
        description "Default logging profile for Application DoS attacks"
        dos-application {
            local-dos {
                local-publisher /Common/local-db-publisher
                remote-publisher /Common/my_publisher_udp
            }
        }
        dos-network-publisher /Common/my_publisher_udp
        protocol-dns-dos-publisher /Common/my_publisher_udp
        protocol-sip-dos-publisher /Common/my_publisher_udp
    }
  4. Save the changes and close the file
  5. Verify the configuration

    tmsh load sys config verity

  6. If there is no errors load the configuration

    tmsh load sys config

  7. Assign new log profile to virtual servers in question
