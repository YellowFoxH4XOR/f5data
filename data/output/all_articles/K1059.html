Topic

Older server appliance platforms may suffer performance problems when running modern versions of 3-DNS under heavy load.

To decrease the number of Local DNS servers, make the following adjustments:

  • Set the Path Data Refresh and Path TTL values to 3600
  • Set the Persist Cache to 21600 (or higher)

Setting the Path Data Refresh and Path TTL

  1. From a browser, open the Configuration utility.
  2. From the navigation pane, click System.
  3. From the toolbar, click Timers and Task Intervals.
  4. In the Path TTL box, type 3600.
  5. In the Path Data Refresh box, type 600.
  6. Click Update.

Setting the Persist Cache

The persist cache sets how often it dumps data to disk. Setting the value to 21600 limits it to dumping data every 6 hours, rather than every hour.

  1. From a browser, open the Configuration utility.
  2. From the navigation pane, click System.
  3. From the toolbar, click Timers and Task Intervals.
  4. In the Persist Cache box, type 21600.
  5. Click Update.
