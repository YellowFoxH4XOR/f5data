Description

F5 Access Guard 1.1.0 (Original Release note) was an early version of a feature for performing continuous Endpoint inspection with APM.
 

Environment

  • BIG-IP APM 15.1.x or later (Manual Chapter)
  • MacOS or Windows 10
  • Chrome or Firefox browsers
 

Cause

The required features of Native messaging API and Browser Extensions are no longer working
 

Recommended Action

Deploying Access Guard is no longer supported.
 

Additional Information

End of Support, confirmed in 17.1 release note as:

"Access Policy Manager (APM) does not support F5 Access Guard for all the BIG-IP versions. Since the underlying technology for the F5 Access Guard is no longer supported by modern browsers"
