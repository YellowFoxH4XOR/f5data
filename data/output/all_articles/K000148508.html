K000148508: Edge Client v7248 maximized when it is auto launched and shows logging in process.

Type
Support Solution
Published
2024-11-12
Updated
2025-07-07
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000148508

Description

After upgrading to 7248 to 7251, Edge Client does not stay minimized when it is auto launched. It shows login process and once the login is succeeded, it goes to minimized.

However v7247, it stays minimized and complete logging in process quietly.

The 2nd symptom is, for the command f5fpc.exe, the option /t cannot work too.

Environment

  • Edge Client
  • v7248 to 7251
  • Windows

Cause

Behavior change after fixing Bug ID 1538165

now tracked this behavior change as Bug ID 1702317: From 7248 Edge client always start in maximized mode

Recommended Actions

Use v7247 where it is possible.

Additional Information

Currently (published time and day), there is no fix for this behavior on v7248-7251, the newer version may contain the fix.
