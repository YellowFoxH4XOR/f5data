K10315032: Failed to import config with error ''Invalid address (any). Address is incomplete.''

Type
Support Solution
Published
2020-04-15
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K10315032

Description

There is a failure when trying to import configuration from a BIG-IP into the BIG-IQ

  • Error reported is: 
    Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Invalid address (any). Address is incomplete.

Environment

  • BIG-IQ 7.0.0
  • BIG-IP has DNS provisioned and a DNS Listener configured a destination address of 0.0.0.0
    • The virtual address gets configured with an address set to any instead of 0.0.0.0 and a netmask of any.
ltm virtual /Common/test {
    creation-time 2020-03-10:10:25:12
    destination /Common/0.0.0.0:53
    ip-protocol udp
    last-modified-time 2020-03-10:10:25:12
    mask any
    profiles {
        /Common/dns { }
        /Common/udp_gtm_dns { }
    }
    source 0.0.0.0/0
    translate-address disabled
    translate-port disabled
}
ltm virtual-address /Common/0.0.0.0 {
    address any     <--------------------HERE
    arp disabled
    icmp-echo disabled
    inherited-traffic-group true
    mask any       <--------------------HERE
    server-scope none
    traffic-group /Common/traffic-group-1
}
  • Error happens when trying to import configuration from BIG-IP into the BIG-IQ

Cause

This is due to a known issue being tracked as ID 892953. The BIG-IQ cannot import a BIG-IP configuration containing an address or netmask set to any.

This is often seen when a DNS Listener is configured with a wildcard destination (IP address any or 0.0.0.0,  and a netmask set to any).

Recommended Actions

There is not a fix or mitigation at this time.
