Description

  • The BIG-IP GUI may return the error "General database error retrieving information" while accessing the "SSL Certificate List" if one of its certificates has "inverted validity dates" like below:

    Validity: [From: Sun Oct 21 18:04:14 GMT 2035,
    To: Sun Sep 12 11:35:58 GMT 1909]

  • If you enable TMUI debug then you may find error messages like the one below at /var/log/webui.log:

    <Date> <Time>,413 ERROR [ajp-bio-127.0.0.1-8009-exec-6] ssl_005fcertificate.list_jsp:error     - java.sql.SQLException: Wrong data type: java.lang.IllegalArgumentException in statement [INSERT INTO ssl_certificates_<config_specific_number> ( full_name, certificate_name, cert_contents, cert_cn, cert_o, cert_exp_status, cert_exp1, cert_exp2, partition_id, folder_name, cert_keytype, key_security, cert_status ) VALUES ('<offending_certificate_name>.crt', '<offending_certificate_name>', '<offending_certificate_serial>', '<offending_certificate_CN>', 'offending_certificate_Organization', '1', '586463-09-29 20:37:47.000', '9999-12-31','Common', 'Common', '1', 'Normal', '-1')]

    To enable TMUI debug please see: K10622: Configuring the BIG-IP system to log verbose messages for the Configuration utility

Environment

  • Traffic Certificate Management : SSL Certificate List
  • SSL certificates
  • default.crt

Cause
This is usually related to a malformed default.crt certificate that was carried over from previous software versions to the current releases.

Recommended Actions

  1. Check the /var/log/webui.log for error "ssl_005fcertificate.list_jsp:error" and confirm which certificate is causing the database error.
  2. When the error messages are related to the default.crt certificate, follow the instructions from article K13579 to generate a new certificate and key pair.
    Note: If the "tmsh load sys config" step from article K13579 doesn't clear the problem, you will need to do a force mcpd reload for the changes to take effect, please follow the instructions from article K13030 for that.

Additional Information

The following articles are mentioned in the Recommended Actions:

  • K13579: Generating new default certificate and key pairs for BIG-IP SSL profiles
  • K13030: Forcing the mcpd process to reload the BIG-IP configuration
