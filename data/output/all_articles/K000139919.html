Description

An HTTP health monitor configured with a '200 OK' Receive String is not marking the pool member UP.

Environment

LTM HTTP health monitor

Pool Member server returns a 3xx redirect or an HTTP meta-refresh, before the client (browser or monitor) reaches the final page.

Cause

Ensure that the pool member server is not issuing a redirect. The BIG-IP monitors will not follow a 3xx redirect or HTTP meta-refresh. This behavior is expected.

Recommended Actions

Modify the health monitor configuration, to point to a server resource that returns a non-redirect status code, such as '200 OK'.

Additional Information

BIG-IP health monitors will not follow an HTTP 3xx redirect, such as '301 Moved Permanently', '302 Found', '302 Moved temporarily', '305 Use Proxy', '307 Temporary Redirect' or '308 Permanent Redirect'.
