K5910: Disabling the Auto-Discovery setting will cause links to be marked down

Topic

The BIG-IP Link Controller requires that the Auto-Discovery setting is enabled in order for proper operation. Failure to enable the Auto-Discovery setting results in a Link Controller that will not load balance inbound traffic properly.

The Auto-Discovery setting is enabled by default.

The Auto-Disovery setting is located in the Configuration utility at System >> Global Traffic >> General.
