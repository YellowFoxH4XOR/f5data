Description

If you want to redirect the website from siteA.com to siteB.com; and when user types in a format with capitalization e.g. SiteA.com, the iRule string "string tolower"  command transforms the string to a lower case.
For example, to match the condition siteA.com, which is in lowercase sitea.com 

Environment

  • iRule
  • Virtual Server

Cause

None

Recommended Actions

If you want to redirect a url from siteA.com to siteB.com, you may configure below iRule.
  1. Login to the Configuration Utility
  2. Navigate to Local Traffic  ››  iRules
  3. Click Create
  4. Provide the name of the Irule
  5. Enter the below iRule.
    Note: Modify the name of the site according to your site name.

    when HTTP_REQUEST {
       if { ([string tolower [HTTP::host]] eq "siteA.com") and ([string tolower [HTTP::uri]] starts_with "/myuri") } {
            HTTP::redirect "http://siteB.com/index.html"
        }
    }
     
  6. Click Finish

Assign the newly created Irule to the virtual server.

Note: Please test the iRule before you implement the change in the production system. For complete and detailed information iRules syntax, see the F5 Networks DevCentral website  https://devcentral.f5.com/.
