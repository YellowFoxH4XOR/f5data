Description
When viewing the BIG-IP system's memory utilization either locally or with an external monitoring tool, you may observe higher than expected memory use by the dynconfd process.

Environment

  • The BIG-IP system has been up for a long time as show by the uptime command
  • The top utility indicates that the dynconfd process memory allocation grows over time and is larger than expected
    PID    UID    Priority    Nice    Size    Resident    Shared    State    %CPU    %MEM    Runtime    CPU #    Swap    Command line
    1234   root    20          0         1.4G    470.9M     1.4M       S         0.0          3.0          02:53:23.34    3       824.1M   /usr/bin/dynconfd -f
  • You may observe the dynconfd process resident memory size increase when a large number of pool members flap

Cause
Bug ID 724868: dynconfd memory usage increases over time

Recommended Actions

  1. As mitigation for the issue, perform the workaround in K11662998 The dynconfd process leaks memory
  2. Upgrade your BIG-IP software to a version where this ID is fixed
