Known Issue

This is the result of a known issue. FirePass 4100 hardware platforms that use Intel Xeon CPUs may incorrectly report one or both system fan speeds in the End-User Diagnostics (EUD). The fan speed reported by the Administrative console is correct. AMD-based FirePass 4100 platforms are not affected by this issue.

For example, running the EUD on an Intel-based FirePass 4100 might produce the following data:

MOBO Sensors Test started.
CPU1 fan: 5113rpm
CPU2 fan: 19014rpm
Chassis temperature: 37 degC
Battery status: Good
CPU1 temperature: 26 degC
CPU2 temperature: 26 degC

On the same system, the Administrative Console might display the following data:

CPU1 fan: 5113 RPM OK
CPU2 fan: 5150 RPM OK
CPU1 temperature: 28 C OK
CPU2 temperature: 28 C OK

You can determine whether you have an Intel-based or AMD-based FirePass 4100 by checking the Device Management: Monitoring: System Load page. For an Intel-based unit, the CPU Usage graph will have a vertical scale with a maximum of 400 percent. For an AMD-based unit, the CPU Usage graph will have a vertical scale with a maximum of 200 percent.

F5 Product Development tracked this issue as ID 335094 (formerly CR82789) and it was fixed in EUD 10.0.8, which has been released as a hotfix for FirePass 5.5.x and FirePass 6.0.2 and later.
