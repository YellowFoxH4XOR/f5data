Known Issue

This is the result of a known issue. The BIG-IP 1600 and 3600 platforms may report incorrect fan speed and fan status.

For example, typical fan speeds may appear in the range of 6k to 10k. However, when running the bigpipe platform command on the BIG-IP 1600 and 3600 platforms, fan speeds may be indicated as high as 19K RPM. For example:

+-> CHASSIS FAN
| | (1) active - 19852rpm (2) active - 19852rpm
| | (3) active
+-> POWER SUPPLY
| | (1) active (2) not present

In addition, if a fan is not operating properly, the system_check -D command reports the fan status as good. For example, the following system_check -D output was taken from a system in which fan 3 was not functioning:

Cpu 1: temperature 49
Cpu 1: fan speed 19852

Chassis fan 1: status 1 - (good)
Chassis fan 2: status 1 - (good)
Chassis fan 3: status 1 - (good)

Chassis power supply 1: status 1 - (good)
Chassis power supply 2: status 2 - (not present)

Chassis temperature 1: temperature 34

F5 Product Development tracked this issue as CR121475 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, or WOM release notes.

Workaround

To work around this issue and obtain the correct fan speed and temperature readings for 1600 and 3600 platforms, you can run the End User Diagnostics (EUD) software.

Note: For information about the EUD, refer to K7172: Overview of the End User Diagnostics (EUD) software.

Note: For information about the EUD software, such as supported platforms, downloading and running the EUD, and EUD fixes and enhancements, refer to the End User Diagnostics release notes.
