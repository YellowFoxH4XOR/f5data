Known Issue

This is the result of a known issue. The copper Gigabit Ethernet ports that are used in switch appliances are not designed to be manually configured when operating at gigabit speeds, and this configuration option should not be available to users. The media type should always be set to auto.

F5 Networks Product Development is tracking this issue as CR38086 and CR38087 and this option was removed in BIG-IP version 9.0.

This option still exists in the BIG-IP and 3-DNS version 4.5 and 4.6 branches.
