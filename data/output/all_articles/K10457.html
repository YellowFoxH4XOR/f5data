Known Issue

This is the result of a known issue. When transferring files through Network Access, Mac OS X users may experience speeds that are noticeably slower than speeds when using a Window's client. This issue only occurs when split tunneling is configured.

F5 Product Development is tracking this issue as CR121220 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-4 issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
