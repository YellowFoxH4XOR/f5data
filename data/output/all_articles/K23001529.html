Security Advisory Description

F5 SSL Intercept iApp 1.5.0 - 1.5.7 and SSL Orchestrator 2.0 is vulnerable to a Server-Side Request Forgery (SSRF) attack when deployed using the Dynamic Domain Bypass (DDB) feature feature plus SNAT Auto Map option for egress traffic. (CVE-2017-6130)

Impact

A remote attacker may be able to perform Server-Side Request Forgery (SSRF) attacks against systems.

The CVSS 3.0 metrics for CVE-2017-6130

Following are the CVSS 3.0 metrics for this vulnerability:

  • CVSS V3 score: 7.3 (base) / 6.7 (temporal) / 6.7 (environmental)
  • CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:L/E:U/RL:U/RC:C

Note: Due to details unique to CVE-2017-6130, we have included CVSS 3.0 metrics in this article. We have not included CVSS 3.0 metrics in Security Advisory articles published on AskF5 for other vulnerabilities.

1SSL Intercept iApp 1.5.0 - 1.5.7 and SSL Orchestrator 2.0 are vulnerable when deployed with the SNAT Automap feature and the Dynamic Domain Bypass (DDB) feature. The SNAT Automap feature is not configured by default and is not a recommended configuration for these deployments.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Versions known to be not vulnerable column. If the table lists only an older version than what you are currently running, or does not list a non-vulnerable version, then no upgrade candidate currently exists.

Mitigation

For information about mitigating and eliminating this vulnerability, refer to the following sections.

SSL Intercept iApp 1.5.0 - 1.5.7

You can mitigate this vulnerability for SSL Intercept iApp by disabling the SNAT Automap option or disabling the Dynamic Domain Bypass (DDB) feature. (If you choose to disable the SNAT Automap option, you can instead use the SNAT Pool option and define SNAT addresses that are appropriate for your environment).

To eliminate this vulnerability for SSL Intercept iApp, you can upgrade the SSL Intercept iApp template to SSL Intercept iApp 1.5.8. To do so, perform the following procedures:

Downloading and importing SSL Intercept iApp 1.5.8

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open a web browser and go to downloads.f5.com.
  2. Click Find a Download, and in the F5 Product Family column under the Security section, click SSL Orchestrator.
  3. Select BIG-IP version 12.1.0 from the list, and click SSL Orchestrator.
  4. Accept the End User License agreement, and download the iApp zip file to a location accessible from your BIG-IP system.
  5. Extract (unzip) the f5.ssl_intercept_svc_chain.v1.5.8 file.
  6. Log in to the BIG-IP Configuration utility.
  7. On the Main tab, expand iApp, and click Templates.
  8. Click Import.
  9. Select the Overwrite Existing Templates box.
  10. Click Browse, and browse to the location where you saved the iApp file.
  11. Click Upload.

Upgrading the Application Service to the current version of the template

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. From the Main tab of the BIG-IP Configuration utility, expand iApp and click Application Services.
  2. Click the name of your existing f5.ssl_intercept_svc_chain application service from the list.
  3. On the menu bar, click Reconfigure.
  4. At the top of the page, in the Template row, click Change to the right of the list.
  5. From the Template list, select f5.ssl_intercept_svc_chain.<latest version>.
  6. Click Finished.

Performing a ConfigSync operation (for HA device groups)

If BIG-IP systems are configured in a device group, you must perform a configuration synchronization (ConfigSync) operation to synchronize the new iApp configuration to the device group members. To do so, perform the following steps from the BIG-IP device in which you installed the SSL Intercept iApp 1.5.8.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Overview.
  3. In the Device Groups section, select the name of the device group.
  4. In the Devices section, select the BIG-IP system in which you installed the SSL Intercept iApp 1.5.8.
  5. Click Sync Device to Group.
  6. Click Sync.

SSL Orchestrator v2.0

You can mitigate this vulnerability for SSL Orchestrator by disabling the SNAT Automap option or disabling the Dynamic Domain Bypass (DDB) feature. (If you choose to disable the SNAT Automap option, you can instead use the SNAT Pool option and define SNAT addresses that are appropriate for your environment).

To eliminate this vulnerability for SSL Orchestrator 2.0, you can install SSLo RPM package f5-iappslx-ssl-orchestrator-13.0.0-2.1.22.noarch.rpm. To do so, perform the following procedures:

Downloading and importing SSL Orchestrator 2.1

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open a web browser and go to downloads.f5.com.
  2. Click Find a Download, and in the F5 Product Family column under the Security section, click SSL Orchestrator.
  3. Select BIG-IP version 13.0.0 from the list, and click SSL Orchestrator.
  4. Accept the End User License agreement, and download the f5-iappslx-ssl-orchestrator-13.0.0-2.1.22.noarch.rpm file to a location accessible from your BIG-IP system.
  5. Log in to the BIG-IP Configuration utility.
  6. On the Main tab, navigate to SSL Orchestrator > Updates.
  7. In the Install Method section, select Upload RPM.
  8. In the File Name section, click Browse, and browse to the location where you saved the RPM file.
  9. Click Open.
  10. Click Install.
