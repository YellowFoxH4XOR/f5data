Known Issue

The BIG-IP system may fail to allocate swap space on certain BIG-IP platforms after upgrading from BIG-IP 10.2.x.

This issue occurs when all of the following conditions are met:

  • You are using one of the following BIG-IP platforms:
    • BIG-IP 6900
    • BIG-IP 8900
    • BIG-IP 8950
    • BIG-IP 11050
  • You upgrade the BIG-IP system from one of the following versions to BIG-IP 11.x or 12.x:
    • 10.2.0
    • 10.2.1
    • 10.2.2
    • 10.2.3
  • The BIG-IP system uses the volume disk format in a RAID configuration. For more information, refer to K10856: Hard drive mirroring (RAID) for BIG-IP 10.1.0 through 10.2.4.

Impact

After the software upgrade, the BIG-IP system may encounter unexpected issues due to the lack of swap space.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system shows no signs of an allocated swap space in the /proc/swaps file.

    For example, if you type the cat /proc/swaps command, the command does not return any output. When the swap space is allocated, the command returns an output similar to the following example:

    Filename Type Size Used Priority
    /dev/md2 partition 3176040 816 -1

Resolution

Status

F5 Product Development has assigned ID 581865 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can perform an intermediate software upgrade from the affected 10.2.x version to BIG-IP 10.2.4, before upgrading to the desired 11.x or 12.x version.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
