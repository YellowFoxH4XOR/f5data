K34733330: BIG-IQ shows managed BIG-IP or DCD ''License is expired'' even after reactivation

Type
Support Solution
Published
2021-12-28
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K34733330

Description

After a license expires on a BIG-IP or DCD unit that is managed by BIG-IQ, the BIG-IQ CM will not clear the alert even though the target device has since reactivated its license. A yellow triangle will appear next to the BIG-IP or DCD and if you hold the cursor over the triangle it states "License is expired".

WebUI menu where the error is displayed:
  • For DCD: "System >> BIG-IQ DATA COLLECTION >> BIG-IQ Data Collection Devices"
  • For BIG-IP: "Devices >> BIG-IP DEVICES"

Environment

  • BIG-IQ Centralized Management
  • BIG-IQ DCD

Cause

  • This is a bug in the restjavad daemon process. Request for Bug ID has been submitted.

Recommended Actions
Restart the restjavad process.

  1. Login to the target BIG-IP or DCD as "root"
  2. Run the command:
    bigstart restart restjavad
"License is expired" alert should no longer appear in BIG-IQ WebUI.
