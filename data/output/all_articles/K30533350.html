Known Issue

Modifying the Lightweight Directory Access Protocol (LDAP) authentication, authorization, and accounting (AAA) configuration may trigger the apmd process to core and restart.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access profile is configured with an access policy that uses the LDAP Auth agent.
  • The BIG-IP APM is experiencing a high traffic load.
  • You modify the associated LDAP AAA server profile or modify the access policy LDAP Auth agent configuration.
  • Users attempt to authenticate to an access profile while the system is applying the configuration change.

Impact

You are unable to establish an access session while the apmd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/apm file, you observe log messages similar to the following example:

    info apmd[<pid>]: 01490004:6: /<partition>/<access name>:<partition>:b9733570: Executed agent '/<partition>/ea_windows_endpoint_verification_act_windows_info_os_ag_2_3_1_2_3_3_1_1', return value 3
    err apmd[<pid>]: 01490000:3: AccessPolicyProcessor/AccessPolicyProcessor.cpp func: "dispatchEvent()" line: 1423 Msg: EXCEPTION AccessPolicyProcessor/AgentClass.cpp line:83  function: createAgent - initInstance() failed for agent /<partition>/<auth macro name> type (11)
    err apmd[<pid>]: 01490000:3: AccessPolicyProcessor/AccessPolicyProcessor.cpp func: "dispatchEvent()" line: 1429 Msg: DispatchEvent() : Exiting due to failure in reinitializing profile<empty>
    err apmd[<pid>]: 01490000:3: modules/Authentication/Ldap/LdapCache.cpp func: "initCache()" line: 451 Msg: EXCEPTION initCache
    err apmd[<pid>]: 01490000:3: <pid> skipping recovery from signal 6 apmsig_recover_level :0
    crit apmd[<pid>]: 01490000:2: ** SIGABRT **

  • The apmd process produces a core file in the /shared/core/ directory.
  • Users are unable to authenticate while the apmd process is restarting.

Workaround

To work around this issue, you can modify the LDAP AAA server profile or access policy LDAP Auth agent configuration during expected low traffic times or during a scheduled maintenance window. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
