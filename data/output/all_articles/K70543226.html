Known Issue

The zxfrd process fails and restarts after multiple failovers between blades in a chassis.

This issue occurs when all of the following conditions are met:

  • DNS Express is configured in a multi-blade chassis.
  • A blade transitions from active to backup to active states and the DNS Express (tmmdns.bin) database is recreated while the blade is in backup status; zxfrd fails when attempting to reference old data.

Impact

The zxfrd process creates a core file and restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The zxfrd process creates a core file and restarts.
  • DNS processing halts while the zxfrd process restarts.
