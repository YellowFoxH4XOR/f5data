K000150289: F5OS LLDP neighbor details screen displays a different interface when viewing "show more" arrow

Type
Support Solution
Published
2025-03-07
Updated
2026-08-28
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000150289

Description

When using the F5OS GUI and reviewing the Network Settings >> LLDP Details >> Neighbors "Show More" drop down arrow you see an unexpected interface. 

Environment

Platform: rSeries and VELOS
Software version: F5OS 1.8.x

Cause

Bug ID 1828137: F5OS LLDP details page cannot display information about neighbors with matching port IDs

Recommended Actions

Workaround

Use the CLI or API to retrieve information about LLDP neighbors.

Log in using "root" and use command:

# f5sh 'show lldp interfaces interface 3.0 neighbors | display json' | head -30
- Replace the interface 3.0 to the specific interface you are looking for.

API example:

# curl -sku admin:admin -H'accept:application/yang-data+json' https://<IPAddress>/api/data/openconfig-lldp:lldp/
