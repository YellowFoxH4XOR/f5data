Description

TMM may core and cause a failover when the HTTP peer aborts the connection

Environment

  • HTTP and HTTP Router profiles are configured on the virtual server.
  • The HTTP peer aborts the connection unexpectedly.
Cause

Bug ID 888113

Recommended Actions

Upgrade to 15.1.2 or 16.0.0 or later
