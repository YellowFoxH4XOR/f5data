Note: For BIG-IP APM and FirePass versions 7.0.0 and later, users can reference K12321: Enabling Network Access debugging for Mac OS X and Linux.

The following two levels of debugging information are available:

Debug levelLogging
1The FirePass Network Access client component logs FirePass Network Access messages.
2The FirePass Network Access client component logs both FirePass Network Access messages and Point-to-Point Protocol (PPP) messages.

You must set these levels in the svpn.conf file on the client system.

Mac OS X

To enable debug logging on Mac OS X, perform the following procedure:

  1. From the Mac client, disconnect the FirePass Network Access connection, if connected.
  2. Open a terminal window.
  3. Start a superuser session by typing the following command:

    sudo su

  4. When prompted, enter your Mac OS X account password.
  5. To create a file named svpn.conf in the /Library/Internet Plug-Ins/f5_sslvpn.bundle/etc/ directory and enable level 2 debugging, type the following command: 
    
echo debug=2 > /Library/Internet\ Plug-Ins/f5_sslvpn.bundle/etc/svpn.conf
  6. Connect or reconnect the FirePass Network Access connection.

    Debugging information will be written to the following locations:

    
/Library/Internet Plug-Ins/f5_sslvpn.bundle/var/log/svpn.log

/Library/Internet Plug-Ins/f5_sslvpn.bundle/var/log/svpn.err

/Library/Internet Plug-Ins/f5_sslvpn.bundle/var/log/pppd.dbg

Linux

To enable debug logging on Linux, perform the following procedure:

  1. From the Linux client, disconnect the FirePass Network Access connection, if connected.
  2. Access the command line.
  3. Start a root (superuser) session by typing the following command:

    su

    Note: For some Linux distributions, you may need to type the following command to start a root session:

    sudo su
     
  4. When prompted, enter the root password.

    Note: If you entered the sudo su command in the previous step, enter your Linux account password instead of the root password.

  5. To create a file named svpn.conf in the /usr/local/lib/F5Networks/SSLVPN/etc/ directory and enable level 2 debugging, type the following command:

    echo debug=2 > /usr/local/lib/F5Networks/SSLVPN/etc/svpn.conf

  6. Connect or reconnect the FirePass Network Access connection.

    Debugging information will be written to the following locations:

    
/usr/local/lib/F5Networks/SSLVPN/var/log/svpn.dbg

/usr/local/lib/F5Networks/SSLVPN/var/log/ppp.dbg
