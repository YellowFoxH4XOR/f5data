Description

Need to know if deployed Instance is  1 slot or a 2 slot image as it affects upgrade abilities.

Environment

  • BIGIP
  • Deployed in AWS
  • Pay-as-you-go license

Cause

AWS interface lists nothing regarding 1 or 2 slots

Recommended Actions

  1. Running tmsh show sys software will show you how many software slots are currently available on your device. The example below shows two slots already in use, so this would be a two slot or more deployment:

    tmsh show /sys software

    --------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version   Build  Active  Status
    --------------------------------------------------------
    HD1.1    BIG-IP 14.1.2.6   0.0.2     yes  complete
    HD1.3    BIG-IP 14.1.2.3   0.0.5      no  complete

  2. Running tmsh show sys hardware will show you the size of the virtual disk attached to your virtual machine. The example below shows 140G disk size:

    tmsh show /sys hardware

    Sys::Hardware
    Chassis Information
      Maximum MAC Count  1
      Registration Key   none

    Hardware Version Information

      Name        HD1
      Type        physical-disk
      Model       Virtual disk
      Parameters  --                   --
                  SerialNumber         VMware-sda
                  Size                 140.00G
                  Firmware Version     2.0
                  Media Type           HDD

  3. If needed, compare size of disk with info in K14946: Overview of BIG-IP VE image sizes??????
