Description

The BIG-IP Configuration utility, often referred to as TMUI (Traffic Management User Interface), is the web-based management console for BIG-IP systems. You access this utility via a browser to configure, operate, and troubleshoot the device. It provides a simplified point-and-click interface to manage the system easily.

Environment

  • BIG-IP system
  • Configuration utility (TMUI)
  • Access via HTTPS using management IP or self IPs
  • Browser-based interface

Cause

None

Recommended Actions

  • Access the Configuration utility via https://<management IP>.
  • Log in using a BIG-IP user account with role-based access controls.
  • Use the utility to handle common tasks including:
    • Building and managing traffic objects (e.g., virtual servers, pools, nodes, monitors).
    • Configuring modules (LTM, DNS/GTM, Advanced WAF/ASM, APM, AFM).
    • Managing system/network settings (e.g., VLANs, routes, HA trust/sync, licensing).
    • Performing operations like viewing statistics, health checks, reviewing logs, and running setup wizards.
  • Prefer the management network for accessing TMUI and ensure best practices for security:
    • Restrict access to the utility. For more information refer to K13309: Restricting access to the Configuration utility by source IP address (11.x - 17.x).
    • Keep software patched and up-to-date. For more information refer to K84554955: Overview of BIG-IP system software upgrades.
    • Implement strong role-based access control (RBAC).
    • Avoid exposing TMUI to the public internet.

Additional Information

TMUI is an alternative interface to tmsh (CLI) and iControl REST API; all these modify the same running configuration. The Setup utility within TMUI is used for guided workflows during initial setup tasks such as licensing and networking configuration.
