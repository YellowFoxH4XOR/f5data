Description

When making changes to your Access Policy you may see the following URL http://localhost/livereload.js and you want to know how this is being used in the BIG-IP

Environment

  • BIG-IP APM 
  • Portal access
  • Rewrite profile

Cause

The usage must be coming directly from the user's web app.
The livelocal.js is not an F5-hosted JavaScript file.

Recommended Actions

None

Additional Information

Running the following command under the /config directory you will see it comes blank:

config # find / -name livelocal.js -print
config #
