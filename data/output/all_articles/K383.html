Topic

You can use the tcpdump utility to observe traffic between a specific client and a node, by filtering on the IP address of the client system. In this way, you can determine to which node BIG-IP is directing a particular client.

To use the tcpdump utility in this manner, type the following command:

tcpdump -ni <VLAN or Interface> host <client IP address>

For example:

tcpdump -ni exp1 host 10.90.100.1

Or:

tcpdump -ni internal host 10.90.100.1

The output will appear similar to the following:

17:48:53.407191 10.90.100.1.443 > 192.168.190.11.3114: P 1:294(293) ack 613 )
17:48:53.407244 10.90.100.1.443 > 192.168.190.11.3114: P 294:331(37) ack 613)
17:48:53.407586 10.90.100.1.443 > 192.168.190.11.3114: . 331:1791(1460) ack )
17:48:53.407604 10.90.100.1.443 > 192.168.190.11.3114: . 1791:3251(1460) ack)

From this output, you can see two IP addresses. In this example, the client address is the first address listed, but this could be reversed depending on the direction of the connection.

For additional information about the tcpdump utility, refer to the man pages by typing the following command:

man tcpdump
