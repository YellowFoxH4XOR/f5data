Description

This document explains how to use the advanced filter to manage update dates in the security policy list.

 

 

Environment

BIG-IP ASM

 

  • Attack signatures
  • ASM GUI
  • Update Date

 

Cause

 

The "Update Date" field includes three options: "All," "After," and "Before."

The date filter behavior includes the specified dates. For example:

  • Filtering "After 2019-12-11" includes items updated on or after that date.
  • Filtering "Before 2019-12-11" includes items updated on or before that date.

This is known as "before or equal" and "after or equal" filtering.

 

 

Recommended Actions

When using date filters, remember the dates specified in the filters are inclusive.

Additional Information

Location of Setting in GUI Menu

For versions 16.x and 17.x:

  • Navigate to Security > Options > Application Security > Attack Signatures > Attack Signature List
  • Click "Show Filter Details" and access the advanced filter.

For versions 13.x, 14.x, and 15.x:

  • Navigate to Security > Options > Application Security > Attack Signatures > Attack Signature List
  • Click "Show Filter Details" to access the advanced filter.
