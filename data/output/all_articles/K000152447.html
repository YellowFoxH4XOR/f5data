K000152447: DNS cache removes an "A" record in additional records part

Type
Support Solution
Published
2025-07-07
Updated
2025-07-07
Applies to
  • BIG-IP
  • BIG-IP DNS
Source
https://my.f5.com/manage/s/article/K000152447

Description

For NAPTR queries A records for a domain from the replacement field are not included in the ADDITIONAL SECTION when a DNS cache profile is attached to a listener:


# dig @192.2.0.1 domain.name NAPTR

--- snip ---

;; ADDITIONAL SECTION:

ns.domain.name 3600 IN A 1.1.1.1

--- snip ---


When no cache is in use the response is as follows:


# dig @192.2.0.1 domain.name NAPTR

--- snip ---

;; ADDITIONAL SECTION:

replacement.domain.name 300 IN A 5.5.5.5

ns.domain.name 3600 IN A 1.1.1.1

--- snip ---


DNS Cache logs will print the following:

 

Jun 24 11:34:17 hostname info tmm1[20914]: DNScache: normalize: removing irrelevant RRset: replacement.domain.name A IN


Environment

DNS Cache profile is in use on a listener.


Cause

Working as designed - all A records from ADDITIONAL section will be removed or "normalized" by the DNS Cache if they aren't provided as additional name in ANSWER and AUTHORITY section.


Recommended Actions

None.
