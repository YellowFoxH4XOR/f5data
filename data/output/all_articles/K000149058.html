K000149058: vcmp Guest INOPERATIVE state after upgrade from 15.x to 16.x or 17.x

Description

  • vcmp Guest INOPERATIVE state after upgrade from v15.x to v16.x or v17.x
  • vcmp Guest not responding by GUI, CLI or vconsole
  • high CPU usage
  • changing vcmp Guest state to Provisioned/Configured and back to Deployed state not resolving the issue

 

Environment

BIG-IP vcmp Host/Guest

 

Cause

Vcmp Guest constantly loading configuration with error: '01020036:3: The requested profile (/Common/<wam_profile_name>) was not found', because of reference to 'wam-tcp-wan-optimize' or  'wam-tcp-lan-optimized 'profiles no longer supported in v16 and v17 software.

 

Recommended Actions

Workaround:

  • restore the working vcmp Guest from UCS backup back to v15.x software

           K66401291: Recreating VCMP Guest from UCS archive

  • look for reference to 'wam' profiles on all the bigip.conf files on all partitions
  • replace the 'wam-tcp-wan-optimized' profiles with 'f5-tcp-wan' profiles
  • replace the 'wam-tcp-lan-optimize'profiles with 'f5-tcp-wan' profiles

           K31000030: 01020036:3: The requested WAM profile (/Common/<wam_profile_name>) was not found.

  • save the configuration
  • create a new UCS backup
  • upgrade again to v16.x or v17.x with installing configuration from v15.x

 

Additional Information

  • For information about using optimized TCP profiles, refer to K03553427: Using optimized TCP profiles
