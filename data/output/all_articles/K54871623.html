Environment

  • F5 automation tool like F5 DO (F5 Declarative Onboarding)
  • Desired F5 services command posted through automation tools like F5 DO require outbound connectivity through proxy server.

Cause

Proxy server settings lost or proxy server unavailable.

Recommended Actions

Ensure proxy server settings have been saved and do exist on device.

tmsh list sys db one-line |grep "db proxy."

If not set:

tmsh modify sys db proxy.host { value "<proxy IP addr>" }
tmsh modify sys db proxy.port { value "<proxy port>" }
tmsh modify sys db proxy.protocol { value "<proxy port>" }
tmsh modify sys db proxy.username { value "<proxy username>" }
tmsh modify sys db proxy.password { value "<proxy username password>" }
tmsh save sys config

Alternatively declare proxy settings along with with desired declaration, see "DB Variable class" composing-a-declaration

{
    "schemaVersion": "N.n.n",
    "class": "Device",
    "async": true,
    "label": "my BIG-IP declaration for declarative onboarding",

        "dbvars": {
            "class": "DbVariables",
            "proxy.host": "<proxy IP add>",
            "proxy.port": "<proxy port>",
            "proxy.protocol": "<proxy protocol>",
            "proxy.username": "<proxy username>",
            "proxy.password": "<proxy username passowrd>"
        }
    }
}

If settings are good then check the BIGIP can access the proxy server by taking a packet capture filtering on proxy server details.

tcpdump -ni 0.0:nnn -s0 "(host <proxy IP add> and port <proxy port>)"
