Description

You should consider using this procedure under the following condition:

  • You want to disable captive portal detection for a user attempting to establish a BIG-IP Edge Client session because the user is continually prompted to provide credentials for proxy access or captive portal network access.

When BIG-IP Edge Client is enabled and running in Connect or Auto-Connect mode, it uses captive portal detection to attempt to access F5 Internet URIs.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • BIG-IP Edge Client for Windows or Mac OS X is enabled and running in Connect or Auto-Connect mode.
  • You have sufficient administrative access to modify the client system settings.

Cause

In certain environments, captive portal detection triggers the user's configured proxy or captive portal network, which continually prompts the user for credentials to establish the outbound connection.

Disabling BIG-IP Edge Client captive portal detection eliminates repeated credential prompts for proxy or captive portal network access.

Recommended Actions

  • Disabling BIG-IP Edge Client captive portal detection in Windows
  • Disabling BIG-IP Edge Client captive portal detection in Mac OS X

Disabling BIG-IP Edge Client captive portal detection in Windows

Add the following Windows registry key so that BIG-IP Edge Client will not attempt captive portal detection during an established session.

Impact of procedure: Before BIG-IP Edge Client will establish a VPN session, it relies on the Windows operating system to prompt the user for credentials when a captive portal is detected.

  1. In Windows, from the Run command, open Registry Editor by typing the following command:

    regedit

  2. Expand the HKEY_CURRENT_USER folder.
  3. Expand the Software folder.
  4. Expand the F5 Networks folder.
  5. Expand the RemoteAccess folder.
  6. From the Edit menu, point to New, and then click DWORD (32-bit).
  7. Type DisableCaptivePortalDetection as the new DWORD name.

    Note: Registry value names are case sensitive.

  8. After the new DWORD has been created, click the DisableCaptivePortalDetection DWORD name.
  9. Right-click the DWORD name.
  10. From the pop-up menu, select Modify.
  11. Set Value data: to 1 and the default base as hexadecimal.
  12. Click OK.
  13. Close Registry Editor.

Disabling BIG-IP Edge Client captive portal detection in Mac OS X

Change the following BIG-IP Edge Client for Mac OS X key so that it will not attempt captive portal detection during an established session.

Impact of workaround: You must open a web browser and authenticate to the captive portal before attempting to establish a VPN connection.

  1. Log in to the Mac OS X system.
  2. Open a Terminal session from Applications > Utilities > Terminal.
  3. Enter the following content in the terminal window:

    defaults write com.f5networks.EdgeClient CaptiveNetworkDetection NO

  4. Close the terminal window.
  5. Restart BIG-IP Edge Client.

    Note: In some cases it may be necessary to reboot the Mac OS X system in order for the change to take effect.
