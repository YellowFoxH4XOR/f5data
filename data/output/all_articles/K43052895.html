Known Issue

BIG-IP ASM dashboard widgets may fail to display after an upgrade.

This issue occurs when the following condition is met:

  • You configure BIG-IP ASM dashboard widgets prior to an upgrade.

Impact

The BIG-IP ASM dashboard fails to display graphs and statistics.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP ASM graphs and statistics are not displayed in the dashboard; instead, the system displays an error message similar to the following example:

    Unrecoverable communications error
