Description
After upgrade the BIGIP from 13.x to ver14.1.2, there are no connections and throughput graphs showing in GUI dashboard for 3 hours, 24 Hours, Week and Month. Only could see 5 mins graph. 

Error messages from /usr/local/www/rrdstats/rrdstats

ERROR: No DS called 'httpcompression' in '/var/rrd/throughput'\n</rrd_error>

Environment

  • F5-VPR-CGN-C2200-DC
  • BIGIP 14.1.2
  • CGNAT
  • Software Upgrade
  • Dashboard
  • Graphs above 3hours and later

Cause

  • RRD does not generate http compression DS in RRD throughput table:
  • This is a known issue as ID943617.
  • After upgrading, dashboard requires compression stats, but CGNAT license does not have compression enabled. RRD can't send compression stats to dashboard caused throughput graph is empty.

Recommended Actions

Re-activate license

None.
