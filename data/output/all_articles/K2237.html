Topic

BIG-IP and 3-DNS versions 4.5 through 4.6.4 use OpenSSH. The OpenSSH configuration file defaults to using the AUTH syslog facility to log only SSH daemon errors. Following is a sample of an SSH daemon error log file, which is located in /config/ssh/sshd_config:

# Logging
SyslogFacility AUTH
LogLevel ERROR
#obsoletes QuietMode and FascistLogging

Note: F-Secure is no longer the SSH version on BIG-IP and 3-DNS.

Changing OpenSSH Default

To change the default so that OpenSSH logs each user, perform the following steps:

  1. Using a text editor, such as vi or pico, open the /config/ssh/sshd_config file.
  2. Find the file entry for ERROR and change it to LogLevel INFO.

    Note: You can change the file entry to enable other logging processes by using the following LogLevel keywords: QUIET, FATAL, ERROR, VERBOSE, DEBUG; however, it is not recommended that you use DEBUG for normal logging as it could violate user privacy.

  3. Save the file.
  4. Restart the sshd daemon by typing the following command:

    bigstart restart sshd

Changing Log Message Destination

To change the destination of log messages, such as the log file, console, email, or snmptraps, perform the following steps:

  1. Edit the /etc/syslog.conf file as in the following example, using tabs, not spaces, for the white space:

    Note: Ensure that the AUTH facility is directed to a log file such as /var/log/secure.

    auth.* /var/log/secure

  2. After you make the change, perform one of the following tasks:
    • Reboot BIG-IP or 3-DNS

      Or

    • Restart syslogd manually by finding the PID for syslogd and typing the following command:

      kill -HUP <pid # of syslogd>
