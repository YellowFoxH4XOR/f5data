Known Issue

This is the result of a known issue. When a user enters a Protected Workspace and the FirePass controller's URL has been added to the browsers Trusted Sites list, the user may still receive a pop-up message from their browser that appears similar to the following example:

The current Web page is trying to open a site in your Trusted sites list. Do you want to allow this? Yes No

This pop-up message only occurs when the user's browser is set to Prompt for the Websites in less privileged web content zone can navigate into this zone option. This message will continue to appear even after the user has selected the Add this site to your Trusted Sites list, and always allow inspection from this site option, when prompted.

Note: The user may safely select Yes when they receive this pop-up message to continue to their Protected Workspace session.

F5 Networks Product Development is tracking this issue as ID 327686 (formerly CR141380).
