K000156975: AS3 won't allow publishing HTTP/2 enabled site with TLS Offloading

Type
Support Solution
Published

Updated
2025-10-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000156975

Description

AS3 will not publish HTTP/2 site with TLS offloading and MRF Routing.

Environment

  • BIG-IP LTM Version 17.5.1
  • AS3 version 3.54.2
  • Virtual Server configured for HTTP/2, MRF Routing enabled and TLS offloading (no client SSL profile)

Cause

AS3 schema and BIG-IP validation require a client/server SSL profile when HTTP/2 and MRF Routing are enabled; configuration without SSL profile is not supported by AS3.

Recommended Actions

To publish via AS3, include a client SSL profile (TLS_Server in AS3) with renegotiation disabled.

Manual removal of the profile post-deployment is unsupported.

Setting "enforceTlsRequirements": false may help with renegotiation errors but does not remove the SSL profile requirement. No further troubleshooting is pending.
