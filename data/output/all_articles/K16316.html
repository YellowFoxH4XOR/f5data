Known Issue

The BIG-IP SASP monitor may stop processing and produce a core file. This issue occurs when all of the following conditions are met:

  • The BIG-IP SASP monitor is configured with Push for its Mode setting.
  • The BIG-IP SASP monitor subsequently receives state changes from the Group Workload Manager (GWM) server.

Impact

The SASP monitor stops processing any additional messages, and the pool member status changes to offline.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The pool member status is offline.
  • The BIG-IP SASP monitor produces a core file in the /shared/core director.
