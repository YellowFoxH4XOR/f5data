Issue

FATAL error: timer array exceeded

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The tmrouted process attempts to set a new timer, but the maximum allowed number of timers has already started.

The tmrouted process is the routing table management daemon that updates the TMM routing table based on the kernel routing table. The tmrouted process depends on the mcpd and tmm daemons, and if either of these daemons restart, tmrouted also restarts. The tmrouted process must run on the BIG-IP system for dynamic routing to function.

Impact

The timer is not set.

Recommended Actions

To work around this issue, you can restart the tmrouted process on the standby unit to reload the correct configuration. To do so, perform the following procedure:

Impact of workaround: When restarting the tmrouted process, all dynamically learned routes will be temporarily unavailable.

  1. Log in to the command line of the affected BIG-IP system.
  2. To display the status of tmrouted process, type the following tmsh command:

    tmsh show /sys service tmrouted

  3. To restart the tmrouted process, type the following command:

    bigstart restart tmrouted

Important: Manage the tmrouted daemon using only the tmsh utility. Attempting to manage tmrouted using a Linux command or with invalid parameters may cause the daemon to fail.
