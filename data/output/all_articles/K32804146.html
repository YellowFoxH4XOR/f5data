Description

Receiving learning suggestions in various ASM policies that have no traffic samples.
The following message found in /var/log/ts/asmlogd.log:

asmlogd|INFO|Jan 01 01:01:01.001|857|F5::RequestLog::delete_unused_protobuf_files,,Dropping protobuf file /var/asmdata1/request_log/0000000962

And, the UI will show the following error message under the "traffic Learning" page:

No samples found in the requests list

Environment

  • Learning suggestions
  • Events log

Cause

  • Learning suggestions sample request is stored in PRX database , If requests are missing in this database then corresponding  learning suggestions will have no sample traffic.
  • PRX database request log limit of 3M records or 5GB.  If one of the  limit is reached, BIG-IP will begin deleting logs.
    If the log rate is too high, it is possible for the BIG-IP ASM system to lose detailed information for learning suggestions  that are current for the policy.

Recommended Actions

  • Enable Remote Logging for 'All request ' local logging for 'illegal request':

             K13080: Configuring the BIG-IP system to log to a remote syslog server (11.x - 15.x)            

  • Handling the learning suggestions
