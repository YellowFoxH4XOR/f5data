Topic

This article applies to the Firepass client. For information about the BIG-IP Edge Client, refer to the following articles:

  • K14045: The BIG-IP Edge Client components for Windows
  • K14947: The BIG-IP Edge Client components for Mac OS X

The FirePass client comprises several individual components. Refer to the following sections for more information regarding each component:

Note: Some of the following components are not supported in all versions of FirePass.

Installer control / InstallerControl

This component installs a Windows service that installs F5-signed components onto the system. This component is used for cases when the superhost client component attempts a version upgrade, but the user rights assigned to the component are insufficient. This component is not required for day-to-day operations, but it does help when you encounter any of the following situations:

  • Upgrades are presented to the client and a Windows Vista or Windows 7 User Account Control (UAC) is applied.
  • The user does not have local administrator rights.
  • The web browser is running as a non-administrator.

Superhost control (urxshost)

This component creates a unified user interface for Application Tunnel and VPN webifyers. All user interfaces are made on DHTML with JavaScript. The superhost control also allows several VPN/Application Tunnel sessions in one window. This component also checks versions against the host control and checks versions to perform upgrades.

Host control (urxhost)

This component downloads, installs, and upgrades other modules, initializes and controls execution, and displays messages to the user. The host control is implemented as a self-installed browser component--Plugin for Netscape-compatible browsers, and ActiveX for Microsoft Internet Explorer (IE) (supported in IE4 and later).

TunnelServer (f5tunsrv)

This component handles the SSL connection between FirePass and the client for Application Tunnel and Network Access connections. The TunnelServer component creates a local TCP socket so that it can communicate with the VPN driver. The TunnelServer component then proxies communication back to the FirePass device. The TunnelServer component serves a similar purpose for the ActiveX Tunnel control.

ActiveX Tunnel control (urTermProxy)

This component creates the SSL connection between FirePass and the client for Application Tunnels and VPN tunnels. The user is prompted to install the ActiveX component the first time they connect to a FirePass controller with a browser. The ActiveX Tunnel control creates SSL connections between the client and the FirePass server. Optionally, the ActiveX Tunnel control can negotiate and perform gzip compression. The ActiveX Tunnel control is able to connect through a proxy server, which includes a proxy server with basic and NTLM authentication. The ActiveX Tunnel control supports IE proxy settings, including proxyautoconfiguration scripts and browser-independent settings.

Virtual Sandbox Class / PWS Control (vdeskctrl)

This component manages Protected Workspace desktop sessions on the client.

Dialer control (urxvpn)

The dialer control component creates a RAS phonebook entry for the FirePass VPN adapter, and initializes the VPN adapter using RAS32 API. The dialer control is also responsible for modifications in the local client routing table according to split tunneling settings, using either IPHLP API (WindowsNT/Windows 2000/XP), WsControl (Windows 98), or the VPN adapter (WindowsNT/Windows 2000/XP). The dialer control is responsible for policy enforcement, including checking for certain processes and monitoring routing table changes. If the dialer control encounters changes in the local routing table, it attempts to restore the routing table. If this configuration is not possible, the dialer control hangs up the session. The dialer control creates a local proxy autoconfiguration script, depending on the client's local proxy configuration. The FirePass Administrator creates the proxy configuration to be used on top of the VPN connection and DNS split settings.

Inspection Host (f5InspectionHost)

This component handles pre-logon inspection-related features, such as Windows Registry, file checks, and operating system version queries.
