Issue

Error Message

notice sod[<PID>]: 010c0056:5: Deactivating traffic group /<partition>/<name>.

In this error message, note the following:

  • <PID> is the process ID for the sod process
  • <partition> is the name of the partition where the traffic group resides
  • <name> is the name of the traffic group being deactivated

For example:

notice sod[4581]: 010c0056:5: Deactivating traffic group /Common/traffic-group-1.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The sod process deactivates a traffic group on the BIG-IP system.

The sod process reactivates traffic groups when certain configuration changes are made on the BIG-IP system. This message is generated during the deactivation phase of this process.

Impact

There is no impact; this message is a notification.

Recommended Actions

None
