K7731: WebAccelerator acknowledges the Cache-Control: max-age=0 HTTP header when it should be ignored

Known Issue

This is the result of a known issue. When the WebAccelerator is configured with the Ignore no-cache Request Headers or the Ignore no-cache Response Headers options enabled in the Lifetime section of a policy, the WebAccelerator does not ignore the Cache-Control: max-age=0 HTTP header. As a result, the request is still proxied to the origin web server (OWS).

Note: For information about the HTTP headers that are ignored when the Ignore no-cache Request Headers or the Ignore no-cache Response Headers options are enabled, refer to K7730: Certain HTTP headers are ignored when the Ignore no-cache Request Headers or the Ignore no-cache Response Headers options are enabled.

F5 Product Development tracked this issue as CR84257 and it was fixed in BIG-IP WAM version 9.4.2. For information about upgrading, refer to the WebAccelerator release notes.
