K28103688: What happens to active connections when a pool member is marked offline by a monitor?

Type
Support Solution
Published
2024-11-26
Updated
2025-11-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.1.X, 17.5.X, 21.X.X, 21.0.X, 21.0.0, 17.5.1, 17.5.0, 17.1.3, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K28103688

Description

Active connections that were going to the pool member marked offline by a monitor will be affected in the following way:

- When a pool member is marked offline by a monitor, the BIG-IP system will no longer send monitor packets to that specific pool member.
- The pool member will be considered offline for new connections, and the system will not send new connections to that pool member.
- Existing active connections that were already established with that pool member before it was marked offline will continue to function normally. The system will allow these active connections to complete their transactions or sessions without interruption.

Environment

  • Big-IP LTM
  • Health Monitors

Cause

This behaviour is by design.
