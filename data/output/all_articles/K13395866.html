Description

After installing a wildcard certificate, GSLB synchronization stopped working.

Environment

  • BIG-IP DNS

Cause

Missing intermediate certificate

Recommended Actions

When installing a third-party CA signed certificate, you must include the CA signed certificate, the root CA certificate, and all intermediate certificates in the chain in a single file to be imported as the device certificate.
