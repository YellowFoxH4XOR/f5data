Topic

You should consider using these procedures under the following condition:

  • You want to look up IP geolocation data on the BIG-IP system.

Description

The BIG-IP system uses geolocation software to identify the geographic location of a client or web application user. The default IP geolocation database provides IPv4 addresses at the continent, country, state, ISP, and organization levels, and IPv6 addresses at the continent and country levels. The database consists of the following files:

  • F5GeoIP.dat
  • F5GeoIPv6.dat
  • F5GeoIPISP.dat
  • F5GeoIPOrg.dat

IP geolocation database locations (BIG-IP 12.1.0 and later)

The IP geolocation database is stored in the following locations on the BIG-IP file system:

  • /usr/share/GeoIP/v2

    The BIG-IP system software ships with the default IP geolocation database files located in the /usr/share/GeoIP/v2 directory.

  • /shared/GeoIP/v2

    When you download and update the IP geolocation files, files are extracted to the /shared/GeoIP/v2 directory.

At startup, the BIG-IP system attempts to load the database files from the /shared/GeoIP/v2 directory. If no database files exist in the /shared/GeoIP/v2 directory, the system loads the default files from the /usr/share/GeoIP/v2 directory.

Note: If you upgraded your BIG-IP system to BIG-IP 12.1.0 or later from a version prior to BIG-IP 12.1.0 and did not update the GeoIP files after the upgrade, the GeoIP files continue to reside in the /shared/GeoIP/ directory. All subsequent updates to the GeoIP files on the upgraded BIG-IP system install the GeoIP files to the /shared/GeoIP/v2/ directory. 

IP geolocation database locations (BIG-IP 10.2.1 through 12.0.0)

The IP geolocation database is stored in the following locations on the BIG-IP file system:

  • /usr/share/GeoIP

    The BIG-IP system software ships with the default IP geolocation database files located in the /usr/share/GeoIP directory.

  • /shared/GeoIP

    When you download and update the IP geolocation files, files are extracted to the /shared/GeoIP directory.

At startup, the BIG-IP system attempts to load the database files from the /shared/GeoIP directory. If no database files exist in the /shared/GeoIP directory, the system loads the default files from the /usr/share/GeoIP/ directory.

You can query the IP geolocation database using the geoip_lookup command. To do so, perform the following procedures.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have command line access to the BIG-IP system.

Procedures

  • Querying the IP geolocation database for the location of a specific IP address
  • Querying a specific IP geolocation database file using the -f flag

Querying the IP geolocation database for the location of a specific IP address

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To query the IP geolocation database for the location of a specific IP address, use the following command syntax:

    geoip_lookup <IP_addr>

    For example, the following command queries the IP geolocation database for location of IP address 24.24.24.24:

    # geoip_lookup 24.24.24.24

    Will attempt to lookup ip '24.24.24.24'
    No database specified.
    opening database in /shared/GeoIP/F5GeoIP.dat
    size of geoip database = 67855146, segments = 12582912, version = GEO-148 20140206 Build 1 Copyright (c) F5 Networks Inc All Rights Reserved
    geoip_seek = 00c4e0e1
    geoip record ip = 24.24.24.24
    country_code = US
    country_name = United States
    region_name = New York

Querying a specific IP geolocation database file using the -f flag

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To query a specific IP geolocation database file, use the following command syntax:

    geoip_lookup -f <path/to/db/files> <IP_addr>

    For example, the following command queries the organization information for IP address 65.61.115.197:

    # geoip_lookup -f /shared/GeoIP/v2/F5GeoIPOrg.dat 65.61.115.197

    Will attempt to lookup ip '65.61.115.197'
    opening database in /shared/GeoIP/v2/F5GeoIPOrg.dat
    size of geoip database = 211202488, segments = 12356220, version = Copyright (c) F5 Networks Inc, All Rights Reserved GEOIP2 v1, 20161103
    geoip_seek = 00006e1c
    geoip record ip = 65.61.115.197
    name = f5 networks

    The following example shows the same query in BIG-IP 10.2.1 through 12.0.0:

    # geoip_lookup -f /shared/GeoIP/F5GeoIPOrg.dat 65.61.115.197

    opening database in /shared/GeoIP/F5GeoIPOrg.dat
    size of geoip database = 180356873, version = GEO-146 20120627 Build 1 Copyright (c) F5 Networks Inc All Rights Reserved
    geoip_seek = 014f0ad1
    geoip record ip = 65.61.115.197
    name = f5 networks
