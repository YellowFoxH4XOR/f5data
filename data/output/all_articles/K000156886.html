What Happened?

  • You're wondering how to enable and configure compression on server responses for your applications that are hosted in XC HTTP LBs. 
  • You're wondering how compression works in XC HTTP LBs.

Environment

  • Distributed Cloud (XC)
  • XC Console
  • F5® Distributed Cloud Load Balancer

Resolution/Answer

To enable and configure compression on your HTTP LB, click on 'more options' and then 'compression parameters' as shown in the screenshot below while you're editing your LB. You can modify compression parameters as needed. Note that only GZIP compression is supported at this time.

When the HTTP Load Balancer compresses the response, it removes the Content-Length header and adds the headers Transfer-Encoding: chunked and Content-Encoding: gzip. The LB will compress the response if the content-length is greater than or equal to the configured value.
