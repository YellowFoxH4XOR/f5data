Known Issue

Upgrading to BIG-IQ Centralized Management 5.4.0 may fail with a Waiting for BIG-IQ services to become available error message when the configuration contains a user-defined BIG-IP ASM signature set created without a filter.

This issue occurs when all of the following conditions are met:

  • You perform a software upgrade to BIG-IQ Centralized Management 5.4.0.
  • The BIG-IQ configuration has a BIG-IP ASM signature set that you have created by manually selecting individual signatures rather than using a filter.

Impact

You are unable to successfully upgrade the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When logging in to the BIG-IQ command line, you observe an error message similar to the following example:

    STORAGE_UPGRADE_FAILED

  • When logging in to the user interface, you observe an error message similar to the following example:

    Waiting for BIG-IQ services to become available...

  • The /var/log/tokuupgrade.log displays a message similar to the following example:

    TypeError: Cannot read property 'attackTypeReference' of undefined
