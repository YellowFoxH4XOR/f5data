K000140764: SSH password success & failure are logged into /var/log/secure by sshd

Description

When attempting to log in with SSH for the root user, the log entries will indicate whether the login attempts were success & failure in /var/log/secure.

 

Example:

sshd[15504]: pam_unix(sshd:auth): authentication failure; logname= uid=0 euid=0 tty=ssh ruser= rhost=10.0.0.0 user=root

sshd[15504]: pam_unix(sshd:session): session opened for user root by (uid=0)

 

Environment

・rSeries

・F5OS-A

・SSH

 

Cause

This is by design.

None
