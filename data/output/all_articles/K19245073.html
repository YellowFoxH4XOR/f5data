Known Issue

Domain Name System (DNS) address space entries may be limited for network access split-tunnel sessions.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a network access profile that uses split-tunneling.
  • The network access profile is configured with an IPv4 primary nameserver and IPv4 secondary nameserver.
  • The configured DNS address spaces of the network access profile exceed 32 entries.
  • Users establish a network access session with BIG-IP APM from a device that is running the iOS operating system.

    Note: When the network access profile is configured with only an IPv4 primary nameserver, DNS address spaces are limited to 64 entries on iOS devices.

    Important: This issue is a limitation of the iOS implementation of Virtual Private Network (VPN) and should not impact non-iOS devices.

Impact

DNS address space entries beyond the iOS limitation are not passed through the network access session.
