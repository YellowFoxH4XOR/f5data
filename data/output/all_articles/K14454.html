Known Issue

Enabling packet filtering may cause the BIG-IP system to drop ICMP echo reply packets.

This issue occurs when the following conditions are met:

  • Packet filtering is enabled
  • One or more of the following packet filtering configurations are in place:

    • The default packet filter action is set to discard or reject and no packet filter rules are in place. For example:

      tmsh list /sys db packetfilter.defaultaction

      sys db packetfilter.defaultaction {
      value "discard"

      or

      sys db packetfilter.defaultaction {
      value "reject"
    • A discard or reject packet filter rule is at the top of the filter list. For example:

      tmsh list /net packet-filter

      net packet-filter test {
      action discard
      order 10
      vlan external
      }
      net packet-filter test2 {
      action reject
      order 15
      vlan external
      }
      net packet-filter icmp_accept {
      action accept
      order 20
      rule "(icmp[icmptype]==0)"
      }
  • The ICMP echo reply packets match an established connection

Impact

The BIG-IP system may drop ICMP echo reply packets. As a result, ICMP-based monitors may fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system may drop ICMP echo reply packets, such as ICMP monitor traffic.
  • The BIG-IP system may incorrectly mark nodes that use ICMP monitors as down.

Workaround

To work around this issue, you can add an ICMP packet filter with Accept action to the top of the filter rule list. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click Packet Filters.
  4. Click Rules.
  5. Click Create.
  6. Enter a name for the new filter.
  7. From the Order menu, select First.
  8. From the Action menu, select Accept.
  9. From the Filter Expression Method menu, select Enter Expression Text.
  10. In the Filter Expression box, enter the following string:

    (icmp[icmptype]==0)
  11. Click Finished.
