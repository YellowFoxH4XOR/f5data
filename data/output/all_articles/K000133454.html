K000133454: How to modify a displayed VCMP guest name

Description

How to modify a displayed VCMP guest name.

 

Environment

  • BIG-IP VCMP
     

Cause

Currently you are unable to modify the displayed name for a VCMP guest in the configuration utility via the web interface
 

Recommended Actions

Note: This procedure will require a full configuration reload which will trigger a failover on ALL VCMP guests, we recommend to perform the procedure during a scheduled maintenance window accordingly.
 

In order to change the name displayed in the web interface you will need to modify the configuration file via command line

1. Login to the BIG-IP via ssh with the root or equivalent privileged account

2. First make a backup of the current configuration file

# cp /config/bigip.conf /config/bigip.conf_backup

3. Edit the configuration file with your favorite text editor, in this example we will use vi

# vi /config/bigip.conf

4. Locate the VCMP guest stanza you wish to change the display name for, here is an example stanza for a VCMP host named "vcmpguest001":

vcmp guest vcmpguest001 {
allowed-slots { 1 2 3 4 }
cores-per-slot 2
hostname hostname.example.com
initial-image BIGIP-15.1.0.5-0.0.8.iso
management-gw 172.30.2.1
management-ip 172.30.2.100/24
preferred-slots { 1 }
ssl-mode shared
sym-unit-key $M$4g$t7cDaDoZU7kSq/xyzIrNtNOU3OaAGuI0opRUXF9/xvL86Qv/3EEKbZ22FAsvNNDd
virtual-disk virtualdiskname.img
}

5. In this example stanza the VCMP guest named displayed in the configuration utility (gui) is vcmpguest001 so we would modify this to whatever desired for example to change the name to vcmpguest002 we would modify the stanza to this:

vcmp guest vcmpguest002 {
allowed-slots { 1 2 3 4 }
cores-per-slot 2
hostname hostname.example.com
initial-image BIGIP-15.1.0.5-0.0.8.iso
management-gw 172.30.2.1
management-ip 172.30.2.100/24
preferred-slots { 1 }
ssl-mode shared
sym-unit-key $M$4g$t7cDaDoZU7kSq/xyzIrNtNOU3OaAGuI0opRUXF9/xvL86Qv/3EEKbZ22FAsvNNDd
virtual-disk virtualdiskname.img
}

6. Save the configuration file

7. Reload the configuration on the VCMP host with the following command

# tmsh load sys config
