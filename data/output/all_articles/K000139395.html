K000139395: Unable to complete setup wizard in the BIG-IQ

Type
Support Solution
Published
2024-05-01
Updated
2024-05-08
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.3.0
Source
https://my.f5.com/manage/s/article/K000139395

Description

U are unable to complete the set-up wizard on BIG-IQ due "The system returned an unexpected error (400 BAD REQUEST)" error that appear after clicking Next in the Networking step.

Environment

  • BIG-IQ CM
  • Setup Wizard

Cause

The hostname that contains underscore and this been log as BUG ID1584521

Recommended Actions

The process will be complete if you use a hyphen instead of the underscore. If using an underscore is required, the hostname can be changed from tmsh after running through the initial setup using an accepted hostname.

You can use following command to modify hostname:

 

 tmsh modify sys global-settings hostname example_bigiq.com

None
