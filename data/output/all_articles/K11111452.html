Issue

Error Message

01070734:3: Configuration error: Invalid wildcard query, invalid or missing class ID.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • You use tab completion for some Traffic Management Shell (tmsh) commands.

The tab completion function of some tmsh command combinations will query the mcpd process with an invalid or incomplete request.

For example, from the tmsh utility, type the generate sys icall event command and then press the Tab key.

The tmsh utility will respond as if tab completion has nothing to complete. However, the error message will be logged to the /var/log/ltm file.

Impact

None. This message is innocuous and can be safely ignored.

Recommended Actions

None
