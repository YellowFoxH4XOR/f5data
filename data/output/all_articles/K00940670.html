Issue

Error Message

012a0002:2: <error>

In this error message, <error> may contain several critical variations including but not limited to the following examples:

  • critical platform initialize failure. exiting...
  • platform_detect: no recognized platform detected.
  • hal_get_dossier: space allocation error

For example:

crit chmand[12345]: 012a0002:2: critical platform initialize failure. exiting...
 

Message Location

You may encounter this message in the following location:

  • /var/log/ltm
Description

This message occurs when the following conditions is met:

  • The BIG-IP hardware abstraction layer code detects an anomaly.

Impact

The hardware abstraction layer daemon may not be able to correctly identify the platform or publish the hardware abstraction configuration at startup or has encountered a critical failure during normal operation.

Recommended Actions

The specific error output indicates if the error relates to platform-specific issues or system instability. If the issue persists across daemon and system restarts, you should file a support ticket with F5 Technical Support.
