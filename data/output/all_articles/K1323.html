K1323: Setting the color of the front panel LEDs in a BIG-IP 2000 or BIG-IP 5000 switch appliance

Topic

You can change the color of any of the front panel LEDs, except for the Power LED. Changing the LED color can aid you in the following scenarios:

  • Assist in identifying specific BIG-IP 2000 and BIG-IP 5000 switch appliances among several in a rack.
  • Accommodate an EAV/ECV or other custom script.

To change the function of the front panel LEDs, type the following command:

bigpipe led <number> <color or reset>

The variables are defined as follows:

Number
variable		LEDNote
1PowerYou cannot modify this LED.
2StatusYou can set this LED to yellow or green.
3ActivityYou can set this LED to yellow or green.
4AlarmYou can set this LED to red or yellow.

For example, to change the Alarm LED to a red LED you would type the following command:

bigpipe led 4 red

To set the alarm LED back to its default, type the following command:

bigpipe led 4 reset

Note: The LED automatically returns to the default setting after a reboot or if the BIG-IP probes/changes the LED for a particular situation (that is, if a health check fails).
