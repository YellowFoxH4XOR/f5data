Topic

FirePass offers basic IPSec functionality for the purpose of secure site-to-site communication between itself and other IPSec VPN devices. Typically, this functionality is used to protect non-secure network protocols that travel between the FirePass and a back-end server in a remote datacenter that has an IPSec gateway device. However, FirePass is an SSL VPN access device and has not been designed to operate as a router of SSL connections to VPN tunnels.

If IPSec performance is a concern, F5 Networks recommends that you use an external IPSec device. There are many IPSec products that implement IPSec exclusively, and thus are better optimized for IPSec than FirePass. FirePass is not intended to support large-scale IPSec tunnel configurations or to perform as a large-scale IPSec site-to-site VPN solution.
