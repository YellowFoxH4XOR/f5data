Description

It is common to need to choose branches based off a group that is sent in a SAML Attribute from ADFS or Azure SAML IdPs

Environment

  • BIG-IP APM
  • BIG-IP as SAML SP
  • ADFS or Azure as SAML IdP

Cause

When the SAML Groups Attribute is returned from the IdP, it is stored in the session variable 'session.saml.last.attr.name.http://schemas.xmlsoap.org/claims/Group'
This group attribute will need to be checked to choose a branch for the user to follow.

Recommended Actions

Create an Empty Box and use it to create a branches for each group to follow.

  1. After the SAML Auth Action in the VPE, add an Empty Box
  2. Name the Box Group Check
  3. Click on Branch Rules
  4. Click on Add and name the Branch, Domain Admins
  5. Click Change --> Click on Advanced
  6. Add in the following expression and modify accordingly, this example is the Domain Admins
            expr {[mcget {session.saml.last.attr.name.http://schemas.microsoft.com/ws/2008/06/identity/claims/groups}] contains "Domain Admins"}
  7. For each Group, add in an additional branch
