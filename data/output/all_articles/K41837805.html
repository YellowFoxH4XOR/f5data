Topic

You should consider using this procedure under the following conditions:

  • Your BIG-IP is licensed and provisioned with the BIG-IP APM module.
  • You want to restrict access to a virtual server using Remote Authentication Dial-In User Service (RADIUS) authentication.

Description

You can configure the BIG-IP APM system to prompt users for their RADIUS authentication credentials when accessing a virtual server.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP is configured with the virtual server to which you want to apply RADIUS authentication.
  • You have previously deployed RADIUS server(s) in your environment, and the BIG-IP system can access them.

Procedures

  • Creating a custom RADIUS monitor
  • Creating the RADIUS authentication profile
  • Creating the access profile
  • Creating the access policy
  • Applying the access profile to the virtual server

Creating a custom RADIUS monitor

The following procedure outlines the steps to create a new custom RADIUS server monitor that uses an existing user name to verify availability of the RADIUS server.

Impact of procedure: When applied to the RADIUS servers pool, an incorrectly configured custom monitor can mark the servers as unavailable.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Local Traffic > Monitors.
  3. Select Create.
  4. Enter the name of the monitor.
  5. Leave Type and Parent Monitor at the default RADIUS setting.
  6. For User Name, enter a user name that your RADIUS servers can authenticate.
  7. For Password, enter the user password.
  8. Enter the RADIUS client secret required by the RADIUS servers.
  9. Select Finished.

Creating the RADIUS authentication profile

The following procedure outlines the steps to create a new BIG-IP APM RADIUS authentication profile that references existing RADIUS servers of your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Authentication > RADIUS.

    Note: For BIG-IP 11.6.x through 12.x, go to Access Policy > AAA Servers > RADIUS.

  2. Select Create.
  3. Enter a name for the RADIUS authentication profile.
  4. For Mode, select Authentication.
  5. For Server Connection, select Use Pool.
  6. For Server Pool Name, enter a name.
  7. For Server Addresses, enter the RADIUS server IP address.
  8. Select Add.
  9. Repeat steps 7 and 8 to add additional RADIUS server pool members.
  10. For Server Pool Monitor, select the monitor you created in the previous procedure.
  11. For Service Type, select Authenticate Only.
  12. Select Finished.

Creating the access profile

The following procedure outlines the steps to create a new BIG-IP APM access profile and configure the associated access policy to present a logon page and authenticate users to existing RADIUS server or servers in your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Profiles/Policies.
  2. Select Create.
  3. Enter a name for the access profile.
  4. For Profile Type, select LTM-APM.
  5. For Profile Scope, select Virtual Server or Profile.
  6. For Customization Type, leave at the default setting of Modern.

    Important: If you are configuring an application access control scenario where you are using an HTTPS virtual server to authenticate and then sending the user to an existing HTTP virtual server to use an application, clear the check box for the SSO Across Authentication Domains > Secure setting.

  7. For Language Settings, for Factory BuiltIn Languages, select the languages you want to use and move them to Accepted Languages.
  8. Select Finished.

Creating the access policy

The following procedure outlines the steps to create a new BIG-IP APM access profile and configure the associated access policy to present a logon page and authenticate users to existing RADIUS server or servers in your environment.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Go to Access > Profiles/Policies.
  2. Next to your access profile, select Edit link to open the Virtual Policy Editor (VPE).
  3. In VPE, select the Add icon (+).
  4. Select Logon Page.
  5. Select Add Item.
  6. Modify the Form Header Text.
  7. Select Save.
  8. After the Logon Page agent, select the Add icon (+).
  9. Select the Authentication tab.
  10. Select RADIUS Auth.
  11. Select Add Item.
  12. For AAA Server, select the RADIUS server profile created in the RADIUS authentication profile procedure.
  13. Select Save.
  14. Select the Deny ending of the Successful branch.
  15. Select Allow.
  16. Select Save.
  17. Select Apply Access Policy.
  18. Select Close to exit VPE.

Applying the access profile to the virtual server

The following procedure outlines the steps to apply the newly create access profile and the associated access policy to an existing virtual server.

Impact of procedure: Performing the following procedure requires users to present their RADIUS credentials when accessing a virtual server that is configured with the BIG-IP APM access profile/policy.

  1. Go to Local Traffic > Virtual Servers > Virtual Server List.
  2. Select the name of the virtual server to which you want to apply the RADIUS authentication access profile.
  3. For Access Policy select the recently created access profile.
  4. Select Update.
