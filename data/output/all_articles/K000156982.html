K000156982: VELOS - All interfaces not coming up in partition

Type
Support Solution
Published
2025-10-10
Updated
2025-10-10
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.5.1, 1.5.0, 1.6.2, 1.6.0, 1.6.1, 1.6.X
Source
https://my.f5.com/manage/s/article/K000156982

Description

  • On F5OS-Chassis systems, all interfaces in a partition may fail to come up, with the operational status remaining blank in both the GUI and CLI. Partition logs may display errors such as:

    cdb_get failed for interface INTERFACE="1/1.1" ATTRIBUTE="slotid" ERRNOSTR="item does not exist"
    cdb_get failed for interface INTERFACE="1/1.1" ATTRIBUTE="phyport" ERRNOSTR="item does not exist"
    MAC exhaustion for interface . Exiting...
    Unexpected CONFD type for interface field INTERFACE="1/1.1" FIELD="phyport" EXPECTED=12 ACTUAL=1
  • L2 agent or partition_L2 service repeatedly restarting or unhealthy
  • Attempts to disable/enable the partition, reboot the chassis, or replace SFPs/cables do not resolve the issue.

Environment

  • Product: F5OS - Chassis (VELOS)
  • Software Version: 1.6.2 (also applicable to similar F5OS-C versions)
  • Portgroup mode: Bifurcated (e.g., 4x25G)
  • Configuration: Manual interface creation or modification via CLI

Cause

This issue is caused by the manual creation or modification of bifurcated interfaces (e.g., 1/1.1–4, 1/2.1–4) via CLI, which is not a supported workflow. This action corrupts the partition’s interface database, resulting in missing required fields (such as slotid and phyport) for the interfaces. As a result, the L2 agent fails to initialize, enters a restart loop, and all interfaces in the affected partition remain down and unmanageable.

Recommended Actions

Do not manually create or modify bifurcated interfaces via CLI. Always use supported workflows for portgroup mode changes and interface provisioning.

To recover from this state:

  1. Connect to the active controller CLI as root.
  2. Enter the partition manager container (replace partition1_manager and partition ID as appropriate): 
    docker exec -it partition1_manager bash
  3. From inside the partition run the following:

    confd_cmd -f rw -c "mdel <interface_path>"
    Example:

    confd_cmd -f rw -c "mdel /interfaces/interface{1/1.1}"
  4. Repeat for all affected interfaces.
