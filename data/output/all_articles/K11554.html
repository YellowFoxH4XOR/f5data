Known Issue

This is the result of a known issue. In rare cases, TMM may panic and restart upon failover with a failed data present assertion. When this behavior occurs, messages that appears similar to the following example are logged to /var/log/tmm file:

notice panic: ../modules/hudfilter/tcp4/tcp4.c:8400: Assertion "data present" failed.
notice cmp state: 0x0
notice ** SIGFPE **
notice fault addr: 0x50d84c
notice fault code: 0x1
notice fault time: Tue Feb 23 14:40:13 PST 2010

F5 Product Development tracked this issue as CR137528, and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, APM, WAN Optimization, or Edge Gateway release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0 and Hotfix-BIGIP-9.4.8-407.0-HF4 issued for BIG-IP version 9.4.8. You may download the hotfixes or later versions of the hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
