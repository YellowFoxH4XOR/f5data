Topic

In 2005, the maximum number of SSL transactions per second (TPS) a BIG-IP LTM system is allowed to perform was enforced, and the maximum throughput for SSL sessions was limited to 2Mbps for BIG-IP LTM systems using license option LIC-0251-00 (BIG-IP, ADD SSL TOTAL TPS).

Beginning in October of 2009, F5 has removed the 2Mbps SSL throughput limitation and allowed unlimited Mbps throughput for BIG-IP LTM systems using the LIC-0259-00 (BIG-IP, PERFORMANCE SSL [Mbps]) new license option. This change is intended to benefit environments that require a high amount of throughput for a low quantity of SSL TPS.

Note: For information about SSL session limits and how the BIG-IP LTM counts the number of SSL transactions, refer to K6475: Overview of SSL session licensing limits. If your environment requires additional SSL TPS, contact an F5 Sales Representative.

To enable the new unlimited Mbps SSL license option, you must reactivate the system's license.

Reactivating the system license

  1. Log in to the Configuration utility as the admin user.

    Note: For more information, refer to K9965: The admin user account must be used to license the system.
  2. Click System.
  3. Click License.
  4. Click Reactivate.
  5. Select either the Automatic or Manual as the activation method.

    Note: If your system does not have internet access to the F5 license server, you must select Manual.
  6. Click Next and follow the on-screen instructions.
