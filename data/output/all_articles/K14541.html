Known Issue

Configuring a trunk fails on BIG-IP 2000/4000 series platforms.

This issue occurs when the following conditions are met:

  • An SFP port is unpopulated.
  • You attempt to create a trunk with SFP interfaces using the Configuration utility or Traffic Management Shell (tmsh).

Impact

You are unable to create a trunk.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H425755 on the Diagnostics > Identified > Medium screen.
  • An error message similar to the following is returned when you create a trunk using the Configuration utility or tmsh utility:

    Interface 2.2 media type is incompatible with other trunk members

Resolution

Status

F5 Product Development has assigned ID 424322 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.5.0K2200: Most recent versions of F5 software
Hotfix11.4.1 HF9K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you must install SFP modules before you either create a trunk or load a configuration that contains trunks with SFP ports.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
