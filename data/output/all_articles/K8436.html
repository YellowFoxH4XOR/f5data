Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

  • K14272: Overview of UNIX configuration files (11.x)

Most UNIX daemons on the BIG-IP system are configurable using the Configuration utility. However, there are occasions when a BIG-IP administrator might need to add a custom UNIX configuration, or change the functionality of a UNIX daemon beyond what is possible in the Configuration utility. Starting in BIG-IP 9.4.2, you can configure many UNIX daemons on the BIG-IP system using the bigpipe command, and changes to the daemons are saved to a BIG-IP system file. In BIG-IP 9.0.0 through 9.4.1, custom UNIX configurations are performed by manually editing the specific UNIX file.

BIG-IP 9.4.2 and later

Starting in BIG-IP 9.4.2, you can perform custom UNIX configurations on the BIG-IP system using the bigpipe command, and the system saves changes to the daemons to a BIG-IP system file.

The BIG-IP 9.4.2 release includes a new feature called the single configuration file (SCF). With the addition of the SCF feature, most UNIX-based files on the BIG-IP system are considered template files, and you can no longer directly edit them. Instead, starting in BIG-IP 9.4.2, when you add custom UNIX configuration to the BIG-IP system, you must use the corresponding bigpipe command. Use the bigpipe command to add custom UNIX configurations to the BIG-IP system, and use the bigpipe save all command to save the custom UNIX configurations to the BIG-IP system file and to the UNIX-based template file.

Note: For more information, refer to K8435: Overview of the Single Configuration File (9.x - 10.x).

For example, to configure DNS nameservers on a BIG-IP 9.4.2 or later system, use the bigpipe dns nameservers command, followed by the bigpipe save all command. The nameserver configuration is saved to the /var/run/config/resolv.conf UNIX configuration file, and to the /config/bigip_sys.conf BIG-IP system file.

Note: If you edit UNIX-based files directly, the changes will be lost when the system is rebooted.

BIG-IP system file synchronization for HA pairs

Certain BIG-IP system files are considered to be common in a redundant setup and are synchronized during a ConfigSync operation, and other BIG-IP system files are considered to be local to one system in a redundant setup and are not synchronized during a ConfigSync operation.

Note: For more information, refer to K7024: Overview of the ConfigSync process (9.x - 10.x).
