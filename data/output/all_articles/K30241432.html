Known Issue

When a BIG-IP Web Accelerator or BIG-IP AAM policy node has multiple variation header rules, a memory leak occurs when each request is evaluated.

This issue occurs when the following condition is met:

  • You have a BIG-IP Web Accelerator or BIG-IP AAM policy with a node that uses multiple variation header rules.

Impact

Over time, the tmm process may exhaust memory resources until the system restarts and produces a core file. If the BIG-IP system is a member of a device group, traffic may fail over to another device group member. If the BIG-IP system is not part of a device group, traffic is interrupted until the tmm process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The amount of memory allocated for and used by the tmm process increases over time.
  • The tmm process exhausts memory resources over time. As a result, system performance may degrade, and the system may eventually become unresponsive.
  • The tmm process restarts and generates a tmm core file to the /shared/core directory.
  • Your BIG-IP system unexpectedly fails over to another system in the device group.
