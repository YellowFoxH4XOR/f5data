K17062: Logging of the BIG-IP APM session.ldap.last.errmsg session variable

Knowledge
Published
2015-08-20

Status

Applies to

Source

Issue

Old Behavior

In versions prior to BIG-IP 11.6.0 HF5, logging of the BIG-IP APM session.ldap.last.errmsg session variable contains a simple error message with extended error-related information.

New Behavior

Beginning in BIG-IP 11.6.0 HF5, when the BIG-IP APM system is not configured for debug logging, logging of the BIG-IP session.ldap.last.errmsg session variable only contains a simple error message. To log extended error-related information without enabling debug logging, you can use the session.ldap.last.errmsgext session variable.

Impact

Access policies that are configured to log the session.ldap.last.errmsg session variable will no longer include extended error-related information.

Recommended Actions

If you want your BIG-IP APM access policy to log extended error-related information, you should modify the access policy to replace logging of the session.ldap.last.errmsg session data with the session.ldap.last.errmsgext session variable.
