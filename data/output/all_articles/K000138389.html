K000138389: restnoded restarting in a loop with "initgroups extra group not found" in /var/log/restnoded/restnoded.log

Published

Description

You may notice that the REST API is unavailable, and the restnoded process is stuck in restart loop. The log file /var/log/restnoded/restnoded.log includes the message "Error: initgroups extra group not found", and that same error message can also be seen when starting restnoded manually:

[root@bigip1:Active:Standalone] ~ #  NODE_PATH=/usr/lib/node_modules /usr/bin/f5-rest-node /usr/share/rest/node/src/restnode.js -p 8105 --logLevel finest -i -s finest

/usr/share/rest/node/src/restWorkerHost.js:72
        process.initgroups(options.user, options.group);
                ^

Error: initgroups extra group not found
    at restWorkerHost (/usr/share/rest/node/src/restWorkerHost.js:72:17)
    at Object.<anonymous> (/usr/share/rest/node/src/restnode.js:53:5)
    at Object.cli.main (/usr/share/rest/node/node_modules/cli/cli.js:957:14)
    at Object.<anonymous> (/usr/share/rest/node/src/restnode.js:52:5)
    at Module._compile (module.js:652:30)
    at Object.Module._extensions..js (module.js:663:10)
    at Module.load (module.js:565:32)
    at tryModuleLoad (module.js:505:12)
    at Function.Module._load (module.js:497:3)
    at Function.Module.runMain (module.js:693:10)

Environment

  • restnoded is stuck in a restart loop
  • The REST API is unavailable

Cause

The error message indicates a failure to locate the 'restnoded' group in the /etc/group file.  This can be caused by the presense of excessively long lines (of around 4,000 characters or more, with thousands of usernames), at any point in the file prior to the line with the restnoded line.

Recommended Actions

Inspect the /etc/group file, and use a text editor to remove any unnecessary or unwanted group memberships, in order to reduce the length of any single line to below 4000 characters.

OR

If the group membership is correct, move the restnoded line to the top of the file, so it appears before any long lines, allowing the restnoded group id to be located

Restart the restnoded process after making changes to the /etc/group file.

# bigstart restart restnoded
