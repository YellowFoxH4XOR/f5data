Description

Article provides information on how to display Attack Signatures in specific Attacks Signature Set in CLI.

Environment

  • Comparing/Displaying Attacks Signatures included in Attack Signatures Sets

Cause

None

Recommended Actions

  • Display all Attack Signature Sets
mysql -uasm -p`perl -I/ts/packages -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select PLC.NEGSIG_SET_SIGNATURES.set_id, PLC.NEGSIG_SETS.set_name, PLC.NEGSIG_SET_SIGNATURES.sig_id, PLC.NEGSIG_SIGNATURES.sig_name
from PLC.NEGSIG_SET_SIGNATURES
LEFT JOIN PLC.NEGSIG_SIGNATURES
ON PLC.NEGSIG_SET_SIGNATURES.sig_id = PLC.NEGSIG_SIGNATURES.sig_id
LEFT JOIN PLC.NEGSIG_SETS
ON PLC.NEGSIG_SET_SIGNATURES.set_id = PLC.NEGSIG_SETS.set_id;"
  • Display Attack Signatures from specific Attack Signature Set
For example for set_id 299999997 which is High Accuracy Signatures:

mysql -uasm -p`perl -I/ts/packages -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select PLC.NEGSIG_SET_SIGNATURES.set_id, PLC.NEGSIG_SETS.set_name, PLC.NEGSIG_SET_SIGNATURES.sig_id, PLC.NEGSIG_SIGNATURES.sig_name
from PLC.NEGSIG_SET_SIGNATURES
LEFT JOIN PLC.NEGSIG_SIGNATURES
ON PLC.NEGSIG_SET_SIGNATURES.sig_id = PLC.NEGSIG_SIGNATURES.sig_id
LEFT JOIN PLC.NEGSIG_SETS
ON PLC.NEGSIG_SET_SIGNATURES.set_id = PLC.NEGSIG_SETS.set_id
where PLC.NEGSIG_SET_SIGNATURES.set_id = 299999997";
  • Display number of Attack Signatures in specific set
For example for set_id 299999999 which is All Signatures:

mysql -uasm -p`perl -I/ts/packages -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select count(*)
from PLC.NEGSIG_SET_SIGNATURES
LEFT JOIN PLC.NEGSIG_SIGNATURES
ON PLC.NEGSIG_SET_SIGNATURES.sig_id = PLC.NEGSIG_SIGNATURES.sig_id
LEFT JOIN PLC.NEGSIG_SETS
ON PLC.NEGSIG_SET_SIGNATURES.set_id = PLC.NEGSIG_SETS.set_id
where PLC.NEGSIG_SET_SIGNATURES.set_id = 299999999";
