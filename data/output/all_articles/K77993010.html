Known Issue

Requests that the system receives from IP addresses configured in the IP Address Exception list may trigger a memory leak.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM Security policy is configured with an IP address in the IP Address Exception list as Never log traffic from this IP Address.
  • Your BIG-IP ASM virtual server is configured with a remote logging profile with an associated Log Filter set to Source all.
  • The BIG-IP ASM virtual server receives a request from an IP address in the IP Address Exception list.

Impact

The system memory usage and swap memory usage increase over time. This may lead to the kernel running out of memory and eventually restarting the BIG-IP ASM bd process.

Note: The memory leak is 64 bytes per transaction for each request received from IP addresses configured in the IP Address Exception list.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/kern.log file, you observe an error message similar to the following examples:

    err kernel: Out of memory: Kill process <pid> (bd) score 253 or sacrifice child
    err kernel: Killed process <pid>, UID 0, (bd) total-vm:<memory size>, anon-rss:<memory size>, file-rss:<memory size>

  • The bd process exits and produces core files in the /var/core directory.
