Known Issue

The configuration may fail to load after an upgrade due to the iApp configuration.

This issue occurs when all of the following conditions are met:

  • Your configuration contains an iApp that requires the BIG-IP PSM module.
  • You upgrade from BIG-IP 11.5.0 to one of the versions listed in the Applies To box.

Impact

The configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to load the system configuration, you view an error message that appears similar to the following example:

    err mcpd[<pid>]: 0107001f:3: The system module (psm) was not found.
    err tmsh[<pid>]: 01420006:3: Loading configuration process failed.
    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- 0107001f:3: The system module (psm) was not found. Unexpected Error: Loading configuration process failed.
    err mcpd[<pid>]: 01070425:3: Full configuration load failed.

Resolution

Status

F5 Product Development has assigned ID 468559 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
ReleaseNoneNone
HotfixNoneNone

Workaround

To work around this issue, you can modify the affected iApp prior to upgrade by removing the BIG-IP PSM module requirement.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
