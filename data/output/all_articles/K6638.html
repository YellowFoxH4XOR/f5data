Known Issue

This is the result of a known issue. The alertd process does not release bytes of memory when an SNMP trap is sent.

F5 Product Development tracked this issue as CR69231 and it was fixed in BIG-IP LTM version 9.1.3. For information about upgrading, refer to the BIG-IP LTM release notes.
