Description

An iRule "event info" command can be used to log the information of the iRule event. For more detail of the event command, refer to "F5 TMSH Reference guide" .

For example, you may use an iRule to get more information as to why LB_FAILED event fires.

ltm rule catch-event-info {
   when LB_FAILED {
        log local0. "LB FAILED REASON: [event info]"
    }
}


Under specific condition, "event info" command may return empty "event info" string.

info tmm[<PID>]: Rule /Common/catch-event-info <LB_FAILED>: LB FAILED REASON:

Environment

  • An iRule "event info" command is used to log reason of load-balancing failure on LB_FAILED event.
  • Pool member silently drops initial SYN from BIG-IP. Or Pool member rejects initial SYN from BIG-IP.

Cause

Bug ID 754100

Recommended Actions

To troubleshoot reason of LB_FAILED event, take a packet capture of server side traffic between BIG-IP and pool member and make sure SYN packet from BIG-IP is accepted by pool member.
