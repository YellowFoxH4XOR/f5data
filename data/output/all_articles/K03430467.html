Description


Administrator attempt to configure split tunnel to honor DNS resolution traffic based on Include/Exclude DNS list - meaning that when traffic go through the tunnel the DNS resolution use the configured DNS server on the network access resource. When traffic going through local routes outside the tunnel, DNS resolution should use the local DNS server. For this scenario, there should be some specific configuration needs to be applied to achieve this goal.


Environment

  • VPN network access
  • BIG-IP APM is configured with Split tunneling

Cause

When not configured properly, all traffic use the network access DNS server.

Recommended Actions

1) Enable the "Enforce DNS search order" checkbox option under the DNS/Hosts tab of the related network resource
2) DNS address space include and exclude options needs to be configured.

For example, if we want domain.com to be resolved over the tunnel and that traffic to go over the tunnel, then we need to add domain.com to the DNS include address space. Then if required, everything else going outside of the tunnel, we need to configure a "*" for DNS address space exclude.
