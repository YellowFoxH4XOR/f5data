Known Issue

This is the result of a known issue. The bigpipe shell utility crashes and produces a core file when using tab completion for the ramcache option with the profile http command:

For example, hitting the tab key twice to complete the following command results in a bigpipe segmentation fault:

bp>profile http http-wan-optimized-compression-caching ramcache ent <TAB> <TAB>

F5 Networks Product Development is tracking this issue as CR133910.

Workaround

To work around this issue, manually type the full command rather than using tab completion. For example, to display RAM Cache entries for the http-wan-optimized-compression-caching profile, manually type the word entry as displayed below:

bp>profile http http-wan-optimized-compression-caching ramcache entry
