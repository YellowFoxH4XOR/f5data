Issue

When using an Active Directory AAA configuration, the BIG-IP APM system may be unable to resolve the reverse DNS PTR record for the Active Directory domain controller defined in the AAA configuration. As a result, you may receive an error message that appears similar to the following example:

Local error, SASL(-1): generic failure: GSSAPI Error: An invalid name was supplied (Cannot determine realm for numeric host address)

If you receive this error message, ensure that your DNS servers that are queried by the BIG-IP APM system are properly configured with the AAA Active Directory domain controllers reverse lookup zones and host entries.

Note: For more information about configuring and using AAA servers with the BIG-IP APM system, refer to the Configuration Guide for BIG-IP Access Policy Manager.
