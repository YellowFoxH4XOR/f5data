Description

Generated a UCS file on a VELOS or r5k/r10k rSeries tenant.

Loaded the UCS to a BIG-IP platform, such as iSeries, with the platform-migrate or no-platform-check options.

After config load, or on next TMM restart, TMM is restarting continuously.

Messages similar to the following observed in /var/log/tmm:

notice SDAG ERROR: dlopen error - /var/run/libsdag.so: cannot open shared object file: No such file or directory
notice panic: ../kern/sdag.c:695: Assertion "libsdag.so successfully loaded" failed.

Environment

  • UCS file
  • Platform migration
  • UCS load from F5OS tenant to non-F5OS system

Cause

UCS file from the tenant contains the following file:

  • /config/tmm_velocity_init.tcl

Bug ID 1311613: UCS obtained from F5OS tenant with FPGA causes continuous TMM restarts when loaded to BIG-IP

Recommended Actions

To recover from this issue, delete the file in question on the destination unit:

rm -fv /config/tmm_velocity_init.tcl

To prevent the issue occurring, remove the /config/tmm_velocity_init.tcl file from the UCS, before loading it to the destination unit.
This involves extracting the UCS, deleting the file, then re-packaging the UCS. This process can be done manually using tar commands, or automated with a script.

Example script (ucs-repackage.sh)

Note: This script was tested successfully on a handful of UCS files. You may need to test and adapt the script for your specific use case.

################

#!/usr/bin/env bash
# Workaround for Bug ID 1311613
# Repackage UCS archive to remove this file:
# /config/tmm_velocity_init.tcl

script="${0##*/}"
ucs_format='.*.ucs'

[[ -z "$1" ]] && echo "Usage: ${script%%.*} <UCS file>" && exit 1
in_file="$1"

[[ ! $in_file =~ $ucs_format ]] || [[ ! $(file "$in_file") =~ gzip ]] \
  && {
       echo "$in_file doesn't appear to be a UCS file."
       echo "(Missing .ucs suffix or non-gzip content.)"
       exit 1
     }

out_file="${in_file##*/}"
out_file="${out_file%%.ucs}-repackaged.ucs"

echo "Creating temporary directory"
mkdir ucs-tmp \
  || {
       echo 'Not proceeding as unable to create tmp directory'
       exit 1
     }

echo "Extracting UCS file: ${in_file}"
tar --gzip --extract --file "$in_file" --directory ucs-tmp 2>&1 |
  grep --invert-match --ignore-case 'time stamp'

echo "Removing config/tmm_velocity_init.tcl"
[[ -f ./ucs-tmp/config/tmm_velocity_init.tcl ]] \
  && rm -rf ./ucs-tmp/config/tmm_velocity_init.tcl

echo "Re-packaging UCS file: $out_file"
cd ucs-tmp || exit 1
tar --create --gzip --file "../${out_file}" ./*
cd ./..
echo "Removing temporary directory"
rm --recursive --force ucs-tmp
echo Done

################

chmod +x ucs-repackage.sh

./ucs-repackage.sh <ucs file>
