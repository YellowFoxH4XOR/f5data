Known Issue

The apd process may exit and produce a core file when Security Assertion Markup Language (SAML) Single Logout (SLO) is configured.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured as a SAML service provider (SP).
  • The external Identity Provider (IdP) is configured with SLO.
  • The logout request assertion received from the IdP does not contain the SessionIndex attribute.

Impact

The apd process may exit and produce a core file, and temporarily fail to process traffic while the process is restarted.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H479698 on the Diagnostics > Identified > High screen.
  • The BIG-IP APM system sends a SIGSEGV signal to the apd process, resulting in a stack trace in the /var/log/apm file and a core file generated to the /shared/core directory.
  • The BIG-IP APM system temporarily fails to process traffic.
  • If configured for high availability (HA), the BIG-IP APM system fails over to the standby system.

Workaround

While there is no work around for this issue, you can prevent this issue by deleting the SLO configuration from the external IdP connector configuration. To do so, perform the following procedure:

Impact of workaround: This procedure disables SAML SLO for the associated SAML SP.

  1. Log in to the BIG-IP command line.
  2. Change to the /config directory by typing the following command:

    cd /config

  3. Create a backup copy of the bigip.conf file by typing the following command:

    cp bigip.conf bigip.conf.sol15626

  4. Using a text editor, edit the bigip.conf file to remove the SLO configuration from the external IdP connector.

    For example, in the following configuration, delete the line beginning with single-logout-uri:

    apm aaa saml-idp-connector /Common/example.com {
    entity-id http://example.com/adfs/services/trust
    identity-location attribute
    identity-location-attribute http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress
    idp-certificate /Common/example.com_saml_idp.crt
    single-logout-uri https://example.com/adfs/ls/
    sso-binding http-redirect
    sso-uri https://example.com/adfs/ls/
    }

  5. Save and exit the file.
  6. Load the configuration by typing the following command:

    tmsh load /sys config
