Description

Warning(s): Only receiving failover updates from BIGIP_LTM-X.local on 1 connection, out of 2 total.

Environment

BIG-IP LTM

v15.x

Packet filter Rules

Cause

Configuration has tons of packet captures and one of them was wrongly created. It blocked the HA syncing between both devices.

Recommended Actions

If you see an error under "Status" for an IP, check your packet filter rules. Normally packet filter rules are not commonly configured or used, but if they are, the IPs for HA should not be included in any packet filter rules.

NOTE: If you have configured packet filter rules, check under the log file: /var/log/pktfilter for any messages that mention or list the IPs used for HA.
