Description

You see the following error in /var/log/ltm:


err mcpd[13979]: 0107071c:3: Trouble allocating mac address for vlan object /Common/<vlan object name>.


The tmsh command "show /sys mac-address" shows that the mac address is assigned for the vlan object


Example:

show /sys mac-address

------------------------------------------------------------------------------------------------------------

Sys::MAC Address

Entry           Component         Object-ID           Property

------------------------------------------------------------------------------------------------------------

[...]

 a1:b2:c3:d4:e5:b     net vlan         /Common/<vlan object name>      mac_true  <--- assigned   

[...]


 

Environment

BIG-IP LTM


Cause

ID818777, This ID does not impact the system. It is more like a cosmetic issue.

 

Recommended Actions

To work around the issue, you can consider reloading the MCPD.

For more information, see K13030
