K000156599: How to collect debug from browser developer tool

Type
Support Solution
Published
2025-09-24
Updated
2025-09-24
Applies to
  • BIG-IP
  • F5OS
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000156599

Description

When GUI management session faces problems, such as browsing delay or pause, collecting debug from browser developer tool become valueable asset for analysis. For instance, if the problem is the behavior of browser or API, it is suggested to collect debug data from browser developer tool.

Environment

Administrative client, web browser (Chrome, FireFox)

  • BIG-IP
  • BIG-IQ
  • F5OS

Cause

None

Recommended Actions

  1. Launch the application and launch browser developer tools (right click and inspect).
  2. Move to the network tab on the browser developer tool window. 
  3. Turn on record network log option is enabled (red button) - by default it is enabled. 
  4. When the problem is reproduced, click right on the API name, select copy. 
    Select 'Copy all listed as HAR' option to get HAR that includes all APIs we see in the network tab. 
    The HAR file will be saved to collect API entries.
