Known Issue

This is the result of a known issue. When memory usage and load are high, the BIG-IP WebAccelerator system logs excessive warning messages to the /var/log/pvac/log file. Messages that appear similar to the following examples may be logged:

debug WA Debug ( 8612): [       PvHttpResponse.cxx:6294     evalContentLength ] Content length of response 5760066 exceeds available length of 5413632 bytes.

debug WA Debug ( 7012): [       PvCacheManager.cxx:593           get_from_hds ] total [0x672fc3] freeMem [0xc91800]

F5 Product Development tracked this issue as CR136743 and CR136679, and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
