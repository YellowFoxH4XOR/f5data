Topic

To receive email notification for syslog messages, you can configure syslog to send messages to the local root email address and configure BIG-IP or 3-DNS to send email to remote accounts.

Note: You must first configure your system to send system email messages to a remote account before implementing this Solution. For information about configuring email delivery to remote accounts, refer to K2349: Configuring BIG-IP or 3-DNS to send mail messages to remote email accounts.

To set the level of notification that you want to receive, you must add specific lines to the /etc/syslog.conf file. These lines must include the facility and the alert level that you want to receive.

Facilities

The facilities are:

FacilityDescription
local0All BIG-IP specific messages other than bigd, sod, and proxyd messages.
local1All bigd (health check) and sod messages.
local3All proxyd (SSL proxy) messages.
local6All local LDAP messages.
local7All mrad (pvad) and MRA related messages.
cronAll messages related to the cron daemon.
daemonAll messages related to BSD daemons.
kernAll kernel messages.
mailAll mail system messages.

Alert Levels

The alert levels are:

AlertDescription
emergEmergency system panic messages.
alertSerious errors that require administrator intervention.
critCritical errors, including hardware and filesystem failures.
errNon-critical, but possibly very important, error messages.
warningWarning messages that should at least be logged for review.
noticeMessages that contain useful information, but may be ignored.
infoMessages that contain useful information, but may be ignored.
debugMessages that are only necessary for troubleshooting.

You can use wildcards for either option, which allows you to specify all facilities for a particular alert level, all alert levels for a particular facility, or any combination thereof.

For example:

local0.* will display all bigip messages, at any alert level.
*.emerg will display all emergency messages, from any facility.
*.* will show all messages at all alert levels.

Configuring email notifications for syslog

To configure email notification for syslog, perform the following steps:

  1. Log in to the command line.
  2. Back up your existing syslog.conf file, by typing the following command:

    cp /etc/syslog.conf /etc/syslog.conf.original

  3. Add a line to the file for each level of notification that you want to receive, using the following command syntax:

    Important: You must enter at least one TAB character between the <facility>.<level> specification and the |exec log2mail <mailaddress> specification.

    echo '<facility>.<level> |exec log2mail <mailaddress>' >>/etc/syslog.conf

  4. Replace:
    • <facility> with a facility described in the facility table.
    • <level> with an alert level described in the alert table.
    • <mailaddress> with the email address to which you want to send the notification.

    For example:

    echo '*.emerg |exec log2mail root' >>/etc/syslog.conf

  5. Reload the syslog configuration, by typing the following command:

    Note: The following command contains back ticks, not single quotes.

    kill -HUP `pidof syslogd`
