Known Issue

The BIG-IP system may leak memory when you modify a Layer 7 (L7) policy.

This issue occurs when the following condition is met:

  • You modify a virtual server configuration that uses L7 policies.

Impact

A slow memory leak reduces Traffic Management Microkernel (TMM) resources.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you modify a virtual server configuration that uses an L7 policy, you notice that the system leaks a small amount of memory.
