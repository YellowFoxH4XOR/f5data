Known Issue

This is most likely the result of a known issue. Although unnecessary, the BIG-IP Configuration utility is available on those systems that are licensed only for 3-DNS. If you attempt to access the BIG-IP Configuration utility on a system that is licensed only for 3-DNS, you can view all of the standard BIG-IP Configuration utility screens; however, if you try to make configuration changes, you will receive a number of errors.

The following message is the most common error message you may receive under these circumstances:

YOU HAVE ENCOUNTERED AN UNEXPECTED SYSTEM ERROR

Please take down the following information and contact customer support: 
Error 288 -- Virtual servers are not available.

F5 Networks Product Development tracked this issue as CR35655 and CR41806.
