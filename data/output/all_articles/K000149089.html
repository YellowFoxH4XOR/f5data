Description

For remote users, after upgrading to 16.1.5  the following error “Error getting auth token from login provider” appears in GUI.

As per 

  • Bug ID 717174: WebUI shows error: Error getting auth token from login provider

This occurs when the BIG-IP REST Daemon restjavad fails to start up properly, and this error most often occurs on the first or second boot after upgrade.

You've applied the below workaround to restart the BIG-IP REST daemons restjavad and restnoded by issuing the below command in TMSH, but the error still exist:

tmsh restart sys service restjavad restnoded

Environment

  • BIG IP
  • Remote Users
  • REST API

Cause

Using space in usernames.

On Linux-based systems, spaces in usernames aren't a good practice.

In version 16.1.5 and up it is not allow to use spaces in usernames.

Note: For more information, refer to the following document.

The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge

see There are a few reasons not to allow spaces in usernames as an example discussion on this matter.

Recommended Actions

There are two options we can use to overcome this:

  • Modify convention naming to include one of the mentioned characters only not containing spaces.

OR

  • Create local admin users or use the main local admin user to overcome this issue.

Additional Information

Advised to use an appropriate username (using allowed characters, without space), so the REST token can be successfully generated.

- (hyphen)
_ (underscore)
. (dot)
@ (at sign)
\\ (backslash)
