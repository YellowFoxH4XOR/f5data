Known Issue

If you configure two similar log filters with different destinations, the BIG-IP system may not define the log destinations.

This issue occurs when the following condition is met:

  • You create two or more log filters with the same log level, message ID, and source, but with different log destinations.

Impact

The BIG-IP system uses only one filter, so this could be confusing if you expect logs in one or all of the log destinations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The log destination that the BIG-IP system uses for logging is undefined.

Resolution

Workaround

To work around this issue, you can delete the duplicate filters.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
