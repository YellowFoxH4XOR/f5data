K000092539: Infinite session tracking records unexpectedly deleted from standby unit

Type
Support Solution
Published
2022-11-03
Updated
2022-12-14
Source
https://my.f5.com/manage/s/article/K000092539

Description

Session tracking records are added under "Security ›› Reporting : Application : Session Tracking Status" in  GUI. These records are synchronized to the peer unit after a configuration sync. On occasions, these manually added records that has an infinite expiration period may be unexpectedly deleted from the standby unit.

Environment

  • BIG-IP ASM / Advanced WAF

  • ASM Sync Group

  • Session tracking records are created with action set to "Block All". "Block All" records are by default created with infinite expiration period and this "Block All Period" is configurable within the security policy under "Security  ››  Application Security : Sessions and Logins : Session Tracking" page. 

Cause

Bug ID 1132981

Recommended Actions

Follow the workaround described in Bug ID 1132981

Additional Information

None
