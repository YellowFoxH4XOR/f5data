Description

seeing the following logs in urldbmgr-trace.log

2020-11-09 09:47:57; THREAD: 2F916700; ERROR; WsDownloadResponseReadBytes: Failed to read 2557723 bytes from socket. errno = 11 - Resource temporarily unavailable
2020-11-09 09:47:57; THREAD: 2F916700; ERROR; WsDownloadResponseSaveToFile: Couldn't read socket.
2020-11-09 09:47:57; THREAD: 2F916700; ERROR; DDSCommDownloadResponseReadWebsenseHeaders: DB download failure 8
2020-11-09 09:47:57; THREAD: 2F916700; ERROR; DDSCommDownloadDatabase: DDSCommDownloadResponseReadResponse failed.

Environment

  • SSLO/SWG

Cause

These logs are logged when the BIG-IP can't make a successful connection with the Websense cloud server

Recommended Actions

These logs shouldn't be of great concern as most of the time, we see there will be retries and typically the database gets downloaded successfully.

Additional Information

None
