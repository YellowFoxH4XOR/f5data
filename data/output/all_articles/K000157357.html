K000157357: Error message "Failed to update cert bundle subcollection" when Overwriting Existing Certificates & Keys

Type
Support Solution
Published
2025-11-23
Updated
2025-11-23
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.4.0
Source
https://my.f5.com/manage/s/article/K000157357

Description

  • You are trying to import certificate in BIG-IQ version 8.4.0, under LOCAL TRAFFIC > Certificate Management > Certificates & Keys. 
  • Overwriting Existing certificate fails with below error message.
    Failed to update cert bundle subcollection, see log for details
  • You do not observe any issue when you choose Create New. The issue is only observed in Overwrite Existing

Environment

  • BIG-IQ
  • 8.4.0

Cause

ID1988937

Recommended Actions

Request for EHF or JAR file by contacting the F5 Technical Support.
