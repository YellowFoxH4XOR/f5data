Known Issue

When the ARX 1500 and 2500 platform's out-of-band (OOB) management interface is configured for auto negotiation, the interface is incorrectly forced to negotiate at 1 Gb/s (1000 Mbs) Full Duplex. As a result, the interface will fail to auto negotiate the link if the device being negotiated with does not support 1 Gb/s.

Note: Auto negotiation is enabled by default for the managment interface.

This issue occurs when all of the following conditions are met:

  • The platform is an ARX 1500 or 2500
  • The OOB management interface is configured for auto negotiation
  • The device being negotiated with does not support 1 Gb/s

Impact

No connectivity for the OOB management interface.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users are unable to connect to the OOB management interface.
  • The show interface mgmt command output will indicate the link status is down. For example:

    Slot                     1
    Interface                1
    Description
    Admin Status             Enabled
    Link Status              Down
    Speed                    1  Gb/s
    Duplex                   Unknown
    Auto Negotiation         Enabled
    MAC Address              d4:a4:3c:3c:00:00
    MTU Size                 1500
    IP Address               192.168.2.104
    Subnet Mask              255.255.255.0

Workaround

To work around this issue, you can configure the OOB management interface to use a specific speed and duplex setting. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the ARX CLI via the console.
  2. Enable privileged mode by typing the following command:

    enable
  3. Enter configuration mode by typing the following command:

    config
  4. Enter the OOB management interface configuration mode by typing the following command:

    interface mgmt
  5. Configure the OOB management interface speed and duplex settings using the following command syntax:

    speed <speed-duplex>

    For example, set the OOB management interface speed and duplex settings to 100 Mbs Full Duplex by typing the following command:

    speed 100-full
  6. Enable the OOB management interface by typing the following command:

    no shutdown
  7. Exit OOB management interface configuration mode and return to privileged mode by typing the following command:

    end
