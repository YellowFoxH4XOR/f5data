What Happened?

My IP's are private, how are they still routable?

 

Environment

  • F5® Distributed Cloud Managed Services
  • F5® Distributed Cloud DDOS

 

Resolution/Answer

Private IP's are not “routable”. They are like RFC1918 IP addresses we use in our home networks or inside companies. When the request leaves the carrier network, it is NAT’d to a public IP address that is routable.

 

Additional Information

Carrier-grade Network Address Translation (CGNAT) allows service providers to conserve IPv4 addresses by sharing a single public IP address among multiple users. With CGNAT, private IP addresses are used within the provider's network, and the translation process enables communication between private IP addresses and the public Internet.

When a device with a private IP address initiates communication with an external server on the Internet, CGNAT performs a translation process. The private IP address is translated to the public IP address assigned by the service provider. The translation typically includes modifying the source IP address and port number in the outgoing packets and maintaining a translation table to track the translations.

The key aspect that makes CGNAT IP addresses routable is the translation process. The provider's CGNAT infrastructure keeps track of the translations and ensures that responses from the Internet are correctly routed back to the appropriate private IP addresses within the network. This is achieved by maintaining state information about each active translation.

When the external server receives a response packet from the private IP address, it is addressed to the public IP address assigned by the service provider. The CGNAT infrastructure then uses the translation table to identify the corresponding private IP address and forwards the response packet to the appropriate internal device.

In summary, CGNAT enables routing of traffic to and from private IP addresses by performing address translation and maintaining the necessary state information to correctly route packets between private IP addresses and the public Internet.
