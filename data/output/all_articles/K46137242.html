K46137242: Access Policy not triggering

Type
Support Solution
Published
2023-03-28
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K46137242

Description

Client is unable to start to an Access Policy session but the request is getting processed by an attached iRule

Environment

Big IP APM

Cause

When an iRule is attached to a virtual server, it may be triggered before the Access Policy is started.

Recommended Actions

Review attached and determine the correct iRules event based on the order of events.  

Additional Information
