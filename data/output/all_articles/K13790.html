Known Issue

Description

OS X data access through a network access tunnel is limited to a transfer speed of 2Mb/s.

This issue occurs when the following condition is met:

  • OS X is accessing data through a FirePass network access tunnel.

When accessing data through a FirePass network access connection, the OS X network access plugin is limiting the traffic flow.

Impact

Increased time to transfer data to or from an OS X client.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Excessive time to transfer data
  • The throughput graph in the Edge Client details screen will not go above 2Mb/s
