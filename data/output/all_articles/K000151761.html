K000151761: Support for modification backup file in Velos and rSeries devices

Published
2025-06-09

Source

Description

Does the Velos (F5OS-C) and rSeries (F5OS-A) devices support modification of backup file (which is in XML format)

  • In BIG-IP, it was possible to edit bigip.conf/bigip_base.conf and can be applied to multiple devices.
  • In BIG-IP it was also possible to copy paste sections of configurations from TMSH (via load sys config from-terminal)
  • This was used to configure common objects across several devices (like remote auth, SSH ciphers etc).

Environment

  • Velos (F5OS-C) devices
  • rSeries (F5OS-A) devices

Cause

The Velos (F5OS-C) and rSeries (F5OS-A) devices do not support modification of backup file. However, the BIG-IP tenants still support old methods.

Recommended Actions

Both Velos (F5OS-C) and rSeries (F5OS-A) devices are API first devices. For configuring common objects across several devices, any of the following alternative ways may be used to configure the common objects.

  1.  API calls
  2. Series of commands
  3. Ansible, Terraform or AS3
