K53830409: The default TCP base profile is read-only starting with BIG-IP 13.x

Published

Source

Issue

Old Behavior

In BIG-IP versions previous to 13.0.0, you can modify the default TCP base profile.

New Behavior

Beginning with BIG-IP 13.0.0, to isolate configuration changes to user profiles, the default TCP base profile is read-only. In BIG-IP 13.0.0 and later, with the new features, you can modify this profile between releases if you determine that you need to modify a setting for most general deployment cases.

Note: TCP is both the profile type and the name of the profile.

Impact

  • If you upgrade a configuration from a previous version that has a modified default TCP base profile, the system renames the profile to tcp-legacy; all child TCP profiles using the modified default TCP base profile will automatically refer to the renamed profile.
  • While you attempt to modify the default TCP base profile, the system may generate an error message similar to the following example:

    01071b49:3: Profile /Common/tcp is a read-only profile. To make changes, create a new profile that descends from /Common/tcp.

Recommended Actions

Other system base profiles might be read-only in future releases.  When possible, to minimize the impact of future behavior changes, create a custom profile based on a system base profile instead of directly modifying the system base profile.
