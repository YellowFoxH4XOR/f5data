Description

When trying to authenticate OAuth using APM, you receive an error message like the one below.

What is the meaning of the error message:

Jan 1 00:00:00 example.com err apmd[18247]: 01490000:3: ApmD.cpp func: "process_apd_request()" line: 2094 Msg: Error 3 reading/parsing response from socket 255. strerror: Success, queue size 469, time since accept 35

Environment

BIG-IP APM

Cause

This is a generic error message that simply indicate that apmd failed to reading/parsing response because the session was disconnected. The error message does not tell us what went wrong, and to troubleshoot we would need more information. 

Recommended Actions

If these logs persist, try rebooting APMD

bigstart restart apmd

Or contact the support
