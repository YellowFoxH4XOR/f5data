Issue

Error Message

notice chmand[<PID>]: 012a0021:4: Chassis power module <PSU_number> absent.

In this error message, note the following:

  • <PID> is the process ID.
  • <PSU_number> is the power supply unit slot number.

For example:

notice chmand[8484]: 012a0021:4: Chassis power module 1 absent.

Note: The error message may appear in warning level log even if the message is defined for notice level. For more information, refer to Bug ID 524277 in F5 Bug Tracker.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • A power supply module is removed from the chassis.
  • No power is applied from an installed power supply module.

Impact

The chassis may lack power redundancy when running with an absent power supply module.  

Recommended Actions

For more information on determining the power supply status, refer to K52015891: Troubleshooting BIG-IP power supply issues.
