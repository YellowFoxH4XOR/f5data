Known Issue

A BIG-IP LTM virtual server (VIP) can use an iRule to evaluate and act on the content of an HTTP stream. If a BIG-IP APM policy is attached to the VIP that also uses an iRule containing the stream command used to process HTTP events, BIG-IP APM generates an error message that appears similar to the following example in the /var/log/ltm file:

local/tmm err tmm[5477]: 01220001:3: TCL error: stream_test <HTTP_RESPONSE> - Operation not supported (line 1) invoked from within "STREAM::disable"

This issue occurs because BIG-IP APM disables the HTTP events while processing internal URIs, such as the BIG-IP APM logon or logoff pages.

F5 Product Development is tracking this issue as ID 340089.

Workaround

You can work around this issue by creating a second virtual server that handles the stream iRule events and calls the original virtual server.

Important: This procedure is only meant to demonstrate how to configure a front-end virtual server to handle streams and you may need additional configuration for your environment. This workaround will create a new virtual server with a new IP address. You may need to update DNS or other variables in your environment to direct clients to the proper virtual server.

This procedure assumes you have the following configuration:

  • An existing BIG-IP APM virtual server
  • The BIG-IP APM virtual server uses HTTPS (port 443)
  • The BIG-IP APM virtual server uses an iRule that processes stream events

Removing the Stream profile and iRule from the BIG-IP APM virtual server

  1. From the Main tab of the navigation pane, expand Local Traffic.
  2. Click Virtual Servers.

    The Virtual Servers screen displays.
  3. Click the name of your BIG-IP APM virtual server.

    The Virtual Server Details screen displays.
  4. Note the name of the Stream profile in the Stream Profile menu.
  5. From the Stream Profile menu, select None.
  6. Click the Resources tab.
  7. Click Manage... in the iRules section.
  8. Click the name of the iRule that processes the stream events in the enabled box.

    Note the name of the iRule.
  9. Click >>.
  10. Click Finished.

Editing the stream iRule to disable the stream events before passing the traffic to the BIG-IP APM virtual server

  1. From the Main tab of the navigation pane, expand Local Traffic.
  2. Click iRules.

    The iRule list screen displays.
  3. Click the name of the iRule you noted above that was removed from the BIG-IP APM virtual server.

    The iRule edit screen displays.
  4. In the iRule body, add the following content:

    Note: The following is an example of an iRule that uses the stream commands. You will need to determine the appropriate configuration for you environment.

    Add the Stream::Disable and the virtual commands to an HTTP_REQUEST event:

    when HTTP_REQUEST {

    STREAM::disable
    virtual <name of original APM virtual>
    }

    Add the STREAM::enable command to an HTTP_RESPONSE event:

    when HTTP_RESPONSE {

    if { [HTTP::header "Content-Type"] contains "text" || [HTTP::header "Content-Type"] contains "javascript" }
    { STREAM::expression {@abc@ABC@}
    STREAM::enable
    }
    }

  5. Click Update after you are finished editing the iRule.

Creating the front end new virtual server

  1. From the Main tab of the navigation pane, navigate to Local Traffic > Virtual Servers.

    The Virtual Servers screen displays.
  2. In the upper-right corner of the screen, click the Create button.

    The new Virtual Server screen displays.
  3. In the Name box, type a name for the virtual server, such as vs_stream_fe.
  4. In the Destination box, verify that Type: option Host is selected.
  5. In the Address: box, type an IP address for the virtual server.
  6. In the Service Port box, type 443, or select HTTPS from the menu.
  7. In the Configuration: menu, select Advanced.
  8. In the HTTP Profile menu, select http.
  9. In the Stream Profile menu, select the stream profile you noted above.
  10. In the SSL Profile (Client) menu, select the Client SSL profile.
  11. In the SSL Profile (Server) menu, select the Server SSL profile.
  12. Scroll to the Resources section.
  13. In the iRules Available box, click the name of your iRule you edited above.
  14. Click <<.
  15. Click Finished.
