Description

"An error has occurred while trying to process your request." error message displayed when accessing Security >> Policies tab of any virtual server in the GUI.

  • error is displayed for any user accessing GUI, either locally (e.g. admin) or remotely authenticated (e.g. TACACS user)
  • HA peer device is not affected
  • messages similar to below are logged in /var/log/restjavad.0.log file:

[8100/tm/shared/bigip-failover-state BigipFailoverStateWorker] Bad response while waiting for icrd: java.lang.Exception: Unable to process request /tm/cm/device-group. Service is unavailable.

[8100/shared/nsyncd NsyncdWorker] Bad response while waiting for icrd: java.lang.Exception: Unable to process request /tm/cm/device-group. Service is unavailable.

[8100/shared/nsyncd NsyncdWorker] Bad response while waiting for icrd: java.lang.Exception: Unable to process request /tm/sys/db/log.nsyncd.level. Service is unavailable.

Environment

  • BIG-IP vCMP Guest
  • LTM
  • AFM
  • virtual server security policy GUI tab
  • Management provisioning set to Large (500 MB)
  • sys db provision.tomcat.extramb and provision.restjavad.extramb set to default values

Cause

Restjavad process is no longer responding.

Recommended Actions

  1. restart restjavad process from bash CLI:

bigstart restart restjavad

 

Proceed with the below steps if the issue persists after restarting restjavad:

       2. Increase the Management provisioning level by following K26427018: Overview of Management provisioning

       3. After increasing Management provisioning level, increase memory for tomcat and restjavad by following K63328426: Increase memory for Tomcat and Restjavad when Out of Memory
