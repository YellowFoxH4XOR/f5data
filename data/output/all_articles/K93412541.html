Description

A Qualys scan detects that the BIG-IP is vulnerable to a TLS triple handshake vulnerability. This can be identified as QID 13607.

Environment

  • TLS
  • Virtual server
  • Qualys

Cause

On versions later than 13.0.0, this is likely a false positive.

Recommended Actions

TLS triple handshake is mitigated by enabling the extended master secret extension. Refer to the following article for more information:

  • K66202244: Support for RFC 7627 extended master secret extension

The tmm.ssl.extmsenabled database variable is enabled by default on versions later than 13.0.0.

Additional Information

There are no configuration options for this feature. You can only enable or disable this feature using a database variable.
