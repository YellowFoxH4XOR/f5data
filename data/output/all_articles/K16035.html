Known Issue

The monpd process may produce a core file when the MySQL process is down and you create many virtual servers with long names.

This issue occurs when all of the following conditions are met:

  • The MySQL process is down or otherwise unavailable.
  • You are creating more than 50 virtual servers with long (100 characters or more) names.

Impact

Users cannot view BIG-IP Analytics (AVR) report data. The monpd process will continue to restart until the MySQL process becomes available again.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs a message to the /var/log/ltm file that appears similar to the following example:

    emerg logger: Re-starting monpd
  • The monpd process restarts and produces a core file in the /shared/core directory.
