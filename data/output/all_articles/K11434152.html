Topic

You should consider using these procedures under either of the following conditions:

  • You want to increase the request size that the BIG-IP ASM security policy can process.
  • You want to optimize the amount of memory that the system allocates for long requests.

Description

By default, the BIG-IP ASM system terminates requests that exceed 10 MB. If your environment requires the BIG-IP ASM system to process requests larger than the 10 MB limit, the processing limit can be increased by modifying the long_request_buffer_size variable. For example, increasing the processing limit is helpful to accommodate large file uploads.

In addition to increasing the allowable request size, you may also want to optimize the percentage of memory that the system allocates for long requests. By default, the system allocates 10 percent of the memory available for the ASM process, bd, to process long requests. You can change the percentage of memory allocated for long requests by modifying the long_request_mem_percentage variable.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You can access the Configuration utility.
  • You can access the BIG-IP command line.

Procedures

  • Determining the frequency of long requests
  • Configuring the long request limit using the Configuration utility
  • Configuring the percentage of memory allocated for long requests using the Configuration utility
  • Configuring the long request limit using from the BIG-IP ASM command line
  • Configuring the percentage of memory allocated for long request from the BIG-IP ASM command line

    Note: In the event that the system variable is not displayed by the Configuration utility, F5 recommends using the Traffic Management Shell (tmsh) to initially configure the variable setting.

Determining the frequency of long requests

Before you modify the long request limit or the percentage of memory allocated for long requests, you may want to determine the frequency and length of long requests processed by the BIG-IP ASM system. When the system processes a high number of large requests, an error message that appears similar to the following is logged to the /var/log/ts/bd.log file:

Too many concurrent long requests allowed 16 ,current 16 needed request length: 404279

To determine the frequency of long requests processed by the BIG-IP ASM system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Switch to the /var/log/ts directory by typing the following command:

    cd /var/log/ts

  3. Use a Linux utility, such as cat or grep, to parse the bd.log file.

    For example:

    grep -i "Too many concurrent" bd.log

Configuring the long request limit using the Configuration utility

To modify the long request limit from the default value, perform the following procedure:

Impact of procedure: Restarting the BIG-IP ASM service results in a brief service interruption.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Specify the long request size, in bytes, by setting the long_request_buffer_size variable.
  4. Click Save.
  5. Log in to the command line.
  6. Restart the asm process by typing the following command:

    tmsh restart /sys service asm

    Important: This step causes a brief traffic disruption.

Configuring the percentage of memory allocated for long requests using the Configuration utility

Impact of procedure: Restarting the BIG-IP ASM service results in a brief service interruption.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Specify the percentage of memory allocated for long requests by modifying the long_request_mem_percentage variable.
  4. Click Save.
  5. Log in to the command line.
  6. Restart the asm process by typing the following command:

    tmsh restart /sys service asm

    Important: This step causes a brief traffic disruption.

Configuring the long request limit from the BIG-IP ASM command line

Impact of procedure: Restarting the BIG-IP ASM service results in a brief service interruption.

  1. Log in to the BIG-IP ASM command line.
  2. To set an internal parameter long_request_buffer_size to a longer request length value, use the following command syntax:

    /usr/share/ts/bin/add_del_internal add long_request_buffer_size <value>

  3. After you modify the parameter, restart the BIG-IP ASM service by typing the following command:

    tmsh restart /sys service asm

    Important: This step causes a brief traffic disruption.

Configuring the percentage of memory allocated for long request from the BIG-IP ASM command line

Impact of procedure: Restarting the BIG-IP ASM service results in a brief service interruption.

  1. Log in to the BIG-IP ASM command line.
  2. Specify the percentage of memory allocated for long requests by modifying the long_request_mem_percentage variable. To do so, use the following command syntax:

    /usr/share/ts/bin/add_del_internal add long_request_mem_percentage <percentage value>

  3. Restart the asm process by typing the following command:

    tmsh restart /sys service asm

    Important: This step causes a brief traffic disruption.
