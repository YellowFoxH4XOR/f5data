K000138506: Traffic continues passing through the BIG-IP even when there is no Virtual Server created on DDoS Hybrid Defender deployment.

Type
Support Solution
Published
2024-02-06
Updated
2024-02-06
Source

Description

You have a DDoS Hybrid Defender deployment. After testing, you have noticed that traffic, that any of the existing virtual servers should not process, is passing through the BIG-IP device.

 

Environment

  • DDoS Hybrid Defender
  • Virtual Wire in Layer 2
  • Normal Behavior

 

Cause

This is the expected behavior. The DDoS deployment creates a Virtual Wire in layer 2. Because the Virtual Wire exists, this is the action taken:

If there is no matching vitual server for tagged traffic, a virtual wire forwards the traffic at Layer 2, ignoring headers at Layer 3 and above. 

 

Recommended Actions

If you wish to stop the traffic from flowing through the BIG-IP.

  1.  Create a new virtual server with either a wildcard destination address, or all the specific addresses that you wish to block.
  2. Attach an iRule to it/them with this content:

when FLOW_INIT {

    drop

}
