Description

This article explains the meaning and implications of the log message "Starting initUpgrade.This is not clean Upgrade." that may appear in the /var/log/restnoded/restnoded.log file during an SSLO RPM upgrade. You perform an upgrade of the SSLO module might notice this message and seek clarification about its significance. The message is informational and does not indicate a problem with the upgrade process.

 

Environment

SSLO RPM upgrade (source version 9.0 to 9.0+ and later)

Log file location: /var/log/restnoded/restnoded.log

 

Cause

This message does not indicate a failed or incomplete upgrade.

It reflects expected behavior under certain conditions and does not require any intervention.

The SSLO module will continue upgrading normally unless other error messages appear.

The log simply shows that the upgrade is proceeding through the standard upgrade path instead of a “clean” upgrade path.

 

This can occur in scenarios such as:

- Upgrading from older SSLO versions (pre-9.0) to newer versions (9.0+), where additional cleanup is required due to changes in HA syncing mechanisms.

- A previous upgrade attempt encountered an issue, and the current upgrade is running as a retry.

 

There is no adverse impact associated with this message, and the upgrade process continues as expected.

 

Recommended Actions

No action required; this log entry is informational only.

After completing the upgrade, perform standard validation checks to ensure expected SSLO functionality.

If any actual errors are observed during or after the upgrade, review logs for specific error messages unrelated to this informational entry.
