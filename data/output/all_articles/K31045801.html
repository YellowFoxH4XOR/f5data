Known Issue

Exported Analytics TCP reports may not contain expected data.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP is licensed and provisioned with the BIG-IP Analytics module.
  • An Analytics profile has associated virtual servers that process TCP traffic assigned to it.
  • Using the Configuration utility you view the Analytics TCP report by navigating to Traffic Intelligence > Analytics > Statistics and clicking a selection in the View By list.
  • You export the report.

Impact

The exported report does not contain data based on the View By selection.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the exported Analytics TCP report, the report contains data based on the default report view and is not effected by the View By: selection.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to export the report. To do so, perform the following procedure:

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Enter the following command syntax:

    show /analytics tcp report view-by tcp-profile range now--now-3h

    For example:

    show /analytics tcp report view-by tcp-profile range now--now-3h

    For more information regarding BIG-IP Analytics and tmsh, refer to: Traffic Management Shell (tmsh) Reference Guide
