Description

When attempting to connect a mailbox using Microsoft Outlook, MAPI requests fail to follow NTLMSSP_CHALLENGE from APM. A pop up repeatedly appears when a user tries to log in
The issue only occurs if credentials are entered within the first minute of the pop up appearing and users are logged into a different domain with a different username than the one used for outlook

 

Environment

PC in a WORKGROUP
smtp domain credentials different to domain credentials
Local user account is non-Microsoft account
Exchange 2016 publication using the latest iApp f5.microsoft_exchange_2016.v1.0.2 available and using NTLM and kerberos.
Outlook client
BIG-IP APM

 

Cause

Outlook client is not sending the proper NTLM Message Type. It is reusing Message Type 1 (negotiate), causing APM to send 1 401 Unauthorized , triggering a popup on the client

 

Recommended Actions

As an alternative use user local account. While using user local account proper NLTM Message Type is sent and the issue cannot be reproduced
Respond to all prompts for user credentials
