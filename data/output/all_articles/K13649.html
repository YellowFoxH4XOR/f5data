Topic

This article applies to BIG-IP 11.x - 12.x. For information about other versions, refer to the following article:

  • K63243467: Creating a device group using the Configuration utility (13.x)
  • K13639: Configuring a device group using tmsh

You should consider using this procedure under the following conditions:

  • You want to configure a device group using the Configuration utility.
  • You want to add a BIG-IP device to an existing device group.

Description

BIG-IP 11.x software introduced the device group feature. A device group is a collection of BIG-IP devices that are configured to securely synchronize their BIG-IP configuration data, and fail over when needed. You can create the following device group types:

  • Sync-Failover

    A Sync-Failover device group contains devices that synchronize configuration data and support traffic groups for failover purposes. A Sync-Failover device group supports a maximum of eight devices.

  • Sync-Only

    A Sync-Only device group contains devices that synchronize configuration data, but do not synchronize failover objects and do not fail over to other members of the device group. A Sync-Only device group is typically used to synchronize the contents of a specific folder (partition) to the device group. For example, you can use a Sync-Only device group to synchronize a folder containing policy data that you want to share across all BIG-IP devices in a local trust domain. A Sync-Only device group supports a maximum of 32 devices.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have configured the following configuration elements on all BIG-IP devices:
     
    • Network components, such as Virtual Local Area Networks (VLAN), self IP addresses, and routes
    • Administrative components, such as network time protocol (NTP), the management IP address, and licensing

      Note: If you are adding an isolated network mode Virtual Clustered Multiprocessing (vCMP) guest to a device group, you should take note of the management IP address requirement for the vCMP guest. For more information, refer to K17065: Considerations for configuring vCMP guests with Isolated Management Network mode in a device group.

  • Each BIG-IP device that will be part of the device group has a device certificate installed on it.

Procedures

  • Configuring the ConfigSync and Failover IP addresses
  • Adding a device to the local trust domain
  • Creating a device group
  • Adding members to an existing device group (optional)

Configuring the ConfigSync and Failover IP addresses

Before creating the device group, you should configure the configuration synchronization (ConfigSync) and Failover IP addresses for each BIG-IP system in the device group. The ConfigSync address is the IP address that the system uses when synchronizing configuration with peer devices, and the Failover address is the IP address that the system uses for network failover. F5 considers it best practice to select both the management address and a Traffic Management Microkernel (TMM) network address to use for network failover. For more information, refer to K14135: Defining network resources for BIG-IP high-availability features (11.x - 12.x). To configure the ConfigSync and Failover addresses, perform the following procedure:

Note: You must enable network failover for active-active configurations (device groups with two or more active traffic groups).

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: You should perform the following procedure on each BIG-IP system that you will add to the device group.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the host name of the local device.
  4. From the Device Connectivity menu, select ConfigSync.
  5. Select the self IP address that you want to use for synchronization.
  6. Click Update.
  7. From the Device Connectivity menu, click Failover Network (click Network Failover or Failover in BIG-IP 11.5.4 and earlier). 
  8. In the Failover Unicast Configuration section, click Add. You can also optionally configure settings in the Failover Multicast Configuration section.
  9. Select the local IP address(s) you want use for failover. You can select a self IP address, the management IP address, or both for failover. F5 recommends using both a self IP address and the management IP address:
    • Select a self IP address, and then select 1026 for Port.
    • Select the management IP address, and then select 1026 for Port.
  10. Click Finished.

Adding a device to the local trust domain

Any BIG-IP devices that you intend to add to a device group must first be members of the same local trust domain. When a BIG-IP device joins the local trust domain, it establishes a trust relationship with peer BIG-IP devices that are members of the same trust domain. For example, if you are creating a device group with four members, you must log in to one of the devices and join the other devices to that system's local trust domain. The devices can then exchange their device properties and device connectivity information.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of a device that will be part of the device group.
  2. Navigate to Device Management > Device Trust > Local Domain.
  3. Click the Peer List or Subordinate List menu. (In BIG-IP 11.0.0 through 11.1.0, scroll to the Peer Authority Devices area or the Subordinate Non-Authority Devices area of the screen.)
  4. Click Add.
  5. Type the management IP address, administrator user name, and administrator password for the remote BIG-IP device, and then click Retrieve Device Information. (In BIG-IP 11.0.0 through 11.1.0, click Next.)
  6. Verify that the certificate and the remote device name are correct, and then click Finished. (In BIG-IP 11.0.0 through 11.1.0, click Next, and then advance through the remaining screens.)
  7. Repeat steps 2 through 6 for each BIG-IP system to be added to the local trust domain.

Creating a device group

After all members have been added to the same local trust domain, you can create a new device group. The device group type can be either Sync-Failover or Sync-Only. If you are creating a Sync-Failover type device group, ensure that you perform the procedure, Enabling the Force Offline option, before adding any new members.

Enabling the Force Offline option

You must enable the Offline option for the device that you will add to the Sync-Failover device group to ensure the device does not become the active unit. The Force Offline option puts the BIG-IP unit into an offline state, during which time the system will not respond to or process local traffic connections. To force the system offline, perform the following procedure:

Impact of procedure: The BIG-IP system terminates existing connections to local traffic objects, and does not allow new connections when the Force Offline option is enabled.

  1. Log in to the Configuration utility of the device you want to add to the Sync-Failover device group.
  2. Navigate to Device Management > Devices.
  3. Click the local device (Self).
  4. Click Force Offline.

Creating a Sync-Failover device group

A Sync-Failover device group contains devices that synchronize configuration data and fail over to one another when the active device becomes unavailable. To create a Sync-Failover device group, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Device Groups.
  3. Click Create.
  4. Enter the name for the device group.
  5. From the Group Type menu, choose Sync-Failover.
  6. Select all of the members that you want to add to the device group.
  7. If you want failover to occur over the network, click Network Failover.
  8. If you want the device group to automatically synchronize, click Automatic Sync.

    Note: This option is available to a Sync-Failover device group beginning with BIG-IP 11.4.0.

  9. Confirm the group settings, and then click Finished.

Creating a Sync-Only device group

Creating a Sync-Only device group typically involves associating a folder (partition) with the group; objects that reside in the folder will be synchronized to devices in the device group. To create a Sync-Only device group and associate a folder with the device group, perform the following steps:

Note: A Sync-Only device group must be associated with a folder other than the / or /Common folders.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Device Groups.
  3. Click Create.
  4. Enter the name for the device group.
  5. From the Group Type menu, choose Sync-Only.
  6. Select all of the members that you want to add to the device group.
  7. If you want the device group to automatically synchronize, click Automatic Sync.
  8. Click Finished.
  9. Navigate to System > Users.
  10. Click the Partition List menu.
  11. Click Create (or click a partition name to modify an existing partition).
  12. Enter the name for the partition.
  13. In the Redundant Device Group Configuration section, clear the Inherit device group from root folder check box, and then select the Sync-Only device group from the Device Group menu.
  14. Click Finished.

Objects created in the new partition will synchronize to members of the Sync-Only device group.

Adding members to an existing device group (optional)

You may need to add new members to an existing device group. If you are adding a member to a Sync-Failover device group, ensure that you perform the procedure Enabling the Force Offline option before adding any new members:

Enabling the Force Offline option

You must enable the Offline option for the device that you will add to the Sync-Failover device group to ensure the device does not become the active unit. The Force Offline option puts the BIG-IP unit into an offline state, during which time the system will not respond to or process local traffic connections. To force the system offline, perform the following procedure:

Impact of procedure: The BIG-IP system terminates existing connections to local traffic objects, and does not allow new connections when the Force Offline option is enabled.

  1. Log in to the Configuration utility of the device you want to add to the Sync-Failover device group.
  2. Navigate to Device Management > Devices.
  3. Click the local device (Self).
  4. Click Force Offline.

Adding a member to an existing device group

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility of a device group member.
  2. Navigate to Device Management > Device Trust > Local Domain.
  3. Click the Peer List or Subordinate List menu. (In BIG-IP 11.0.0 through 11.1.0, scroll to the Peer Authority Devices area or the Subordinate Non-Authority Devices area of the screen.)
  4. Click Add.
  5. Type the management IP address, administrator user name, and administrator password for the remote BIG-IP device, and then click Retrieve Device Information. (In BIG-IP 11.0.0 through 11.1.0, click Next.)
  6. Verify that the certificate and the remote device name are correct, and then click Finished. (In BIG-IP 11.0.0 through 11.1.0, click Next and advance through the remaining screens.)
  7. Navigate to Device Management > Device Groups.
  8. Click the device group to which you want to add the new member.
  9. In the Members section, move the new member to the Includes window. (In BIG-IP 11.0.0 through 11.1.0, click Add.)
  10. Click Update. (In BIG-IP 11.0.0 through 11.1.0, select the check box for the new member, and then click Add.)
