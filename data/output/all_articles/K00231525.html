About the SSL VPN tunnel

The BIG-IP APM Network Access client and the operating system on the client device perform multiple events to initiate and establish a BIG-IP APM Network Access tunnel.

Tunnel setup activities

  • Session management: The F5 Access plugin establishes a session with the BIG-IP APM system and handles the authentication. The system assigns the Network Access resource to the user session and sends a list of properties to the client in XML format.
  • Tunnel management: This phase includes set up and tear down. The system passes user session properties to the operating system Point-to-Point Protocol (PPP) framework to create the tunnel. The framework handles the tunnel negotiation and configuration. 
  • Tunnel framing:
    • Windows enables F5 FastPPP by default.
    • PPP for Linux, Mac OS, and Android.
    • Point-to-Point Tunneling Protocol (PPTP) for iOS.
  • DNS management: The system passes the DNS properties to the framework, and the Microsoft Name Resolution Policy Table (NRPT) manages and enforces them.
  • Proxy management: The system passes the proxy properties to the framework.

Troubleshooting

When you want to troubleshoot a BIG-IP APM Network Access tunnel issue, keep in mind that multiple factors can impact functionality, including:

  • External factors.
  • BIG-IP APM-specific factors.
  • Client device-specific factors.

Consider the following when you are trying to identify connectivity issues:

  • Client-side web proxies
  • Client-side DNS configuration
  • Client-side antivirus and firewall software
  • Firewalls, including local and remote, such as ISP firewalls
  • IP fragmentation, including mismatched maximum transmission unit (MTU) between upstream network devices and the BIG-IP APM system
  • BIG-IP APM access control lists (ACLs)
  • BIG-IP APM lease pool IP exhaustion, including IPv4 allocation failure
  • BIG-IP APM virtual server TCP profile
  • BIG-IP secure network address translation (SNAT) port exhaustion
  • BIG-IP bandwidth controller settings

Recommendations

Enable access session-level debug information

You can enable access session debug logging by doing the following:

  1. Log in to the TMOS Shell (tmsh).
  2. Enter the following command:

    modify /sys db log.accesscontrol.level value debug

    Important: Access session debug logging is verbose. Only use it for short intervals when you are logging to the local BIG-IP APM device.

Reset the access session logging level to Notice

  • Enter the following command:

    modify /sys db log.accesscontrol.level value notice

Filter access session logging for a specific BIG-IP APM virtual server

You can filter the access session information in the /var/log/apm log file for a specific BIG-IP APM virtual server.

  • To filter for a specific BIG-IP APM virtual server, enter the following command:

    grep <vpn ip address> <apm logfile> | awk '($9 = "New" && $10 = "session") { print $0 }' | cut -d: -f8 | awk '{system("grep "$1" <apm logfile>")}'

    Note: Replace <vpn ip address> with the IP address of the specific BIG-IP APM virtual server you want to filter on, and replace <apm logfile> with the uncompressed log file you wish to filter.

    For example, to see all access sessions for the BIG-IP APM VPN with the virtual address 172.16.1.63, you enter the following command:

    grep 172.16.1.63 /var/log/apm | awk '($9 = "New" && $10 = "session") { print $0 }' | cut -d: -f8 | awk '{system("grep "$1" /var/log/apm")}'

Filter based on the information you received about an access session, such as client device OS or browser

You can filter based on the information you received about an access session, such as client device OS or browser. To do so, do the following:

  • Enter the following command:

    grep <os or browser type> /var/log/apm | awk '($9 = "Received" && $10 = "User-Agent") { print $0 }' | cut -d: -f8 | awk '{system("grep "$1" /var/log/apm")}'

    Note: Replace <os or browser type> with an operating system or browser name, and replace <apm logfile> with the uncompressed log file you want to filter.

    For example, to search based on the operating system Windows, enter the following command:

    grep Windows /var/log/apm | awk '($9 = "Received" && $10 = "User-Agent") { print $0 }' | cut -d: -f8 | awk '{system("grep "$1" /var/log/apm")}'

    Alternatively, to search based on Chrome, enter the following command:

    grep Chrome /var/log/apm | awk '($9 = "Received" && $10 = "User-Agent") { print $0 }' | cut -d: -f8 | awk '{system("grep "$1" /var/log/apm")}'
