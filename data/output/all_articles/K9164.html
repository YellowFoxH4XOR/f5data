K9164: Extended Validation SSL certificates may cause error messages when accessing Network Access, Dynamic Application Tunnels, or Web Application Tunnels

Topic

The FirePass controller supports Extended Validation SSL (EV SSL) certificates for use with FirePass web services. EV SSL certificates are a special type of X.509 certificate that require more extensive investigation of the requesting entity by the Certificate Authority (CA) before issue.

For an EV SSL certificate to work properly, the CA must either add an Extended Key Usage (EKU) value of server authentication 1.3.6.1.5.5.7.3.1, or no EKU value. To confirm that your CA has added an EKU value, connect to the resource using that certificate and bring up the certificate properties details. Under the Extensions section, locate the Extended Key Usage field. The field value must include the 1.3.6.1.5.5.7.3.1 server authentication object ID (OID). If the server authentication value is set to a value other than this OID, the end user may receive one of the following SSL error messages when using Network Access, a Dynamic Application Tunnel or a Web Application Tunnel:

  • The certificate is not valid for the usage
  • Unknown Key Usage (1.3.6.1.4.1.311.10.3.3)

Note: This error message will occur any time the Key Usage attribute is not correct. While it is most often seen when using EV SSL certificates, it can be seen when using standard SSL certificates as well.

Important: All certificates in the certificate chain must include the 1.3.6.1.5.5.7.3.1 value. Each certificate is signed with the private key of the CA. If your users view an SSL error message, but the OID is correct, check the same field in the certificate used by the CA to sign the certificate that is installed on the FirePass controller. If you have questions, contact the vendor who provided the certificate.

If your CA did not include the value in the certificate, instruct your users to accept the error message and proceed to the web page. You must work with your CA to resolve the issue. FirePass, as well as any other device, is not able to correct that field value. The CA will need to issue a new certificate with the correct field value for the SSL certificate as well as all certificates used to sign or validate the SSL certificate.

Note: Prior to FirePass version 6.0.2, users may not receive the error message. However, due to a change of code beginning in FirePass version 6.0.3, users running 6.0.3 or later should always see the error message if the EKU value is incorrect.

For more information about using Extended Validation SSL Certificates, refer to K8330: Installing Extended Validation SSL certificates.
