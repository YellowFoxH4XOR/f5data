Known Issue

This is the result of a known issue. If you log on to the FirePass Administrative Console on a primary (master) cluster node and navigate to the Clustering: Slave Admin page, the following message is displayed:

Please click on a slave link, and reauthenticate to access a slave Admin Console

Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

However, in some instances, no link appears under the text. This issue occurs when the Admin Logon option is not enabled for the load-balanced web service on the cluster nodes.
 
This behavior does not indicate an issue with the FirePass cluster or configuration. For security reasons, you may prefer to configure a separate web service for administrator logon instead of permitting administrator logon on the same web service used for user logon. If you decide to configure a separate web service for administrator logon, you will need to manually log in to the Administrative Console on the secondary (slave) cluster nodes instead of using the Clustering: Slave Admin page on the primary cluster node.
 
F5 Networks Product Development is tracking this issue as CR68090.
 
Workaround
 
You can work around this issue by enabling administrator logon on the load-balanced web services. To do so, perform the following procedure:
 
Important: After performing the following procedure, you must log on to the web service configured in Step 4 on the primary cluster node in order to access the secondary cluster nodes from the Clustering: Slave Admin page. For example, if the load-balanced web service has the URL https://fp1.example.com, but an additional administrator-only web service is configured with the URL https://fp1.example.com:6000, the Administrative Console link will not appear on the Clustering: Slave Admin page if you log on to https://fp1.example.com:6000.
  1. On the primary cluster node, log in to the FirePass Administrative Console.
  2. Navigate to the Device Management: Configuration: Network Configuration page.
  3. Click the Web Services tab.
  4. Select the configure link next to a web service that is load-balanced by the primary cluster node.
  5. Select the Admin Logon check box to enable administrator logon.
  6. Click the Update button.
  7. Click the Clustering tab.
  8. In the Load Balancing section, click the Update Table button.
  9. Click the Finalize tab.
  10. Click the Finalize Changes button.
  11. Click the Apply Changes and Restart button.
  12. Click the Restart button to restart the FirePass controller.
  13. Repeat Steps 1 through 12 on each secondary cluster node.
