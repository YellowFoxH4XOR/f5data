Known Issue

The BIG-IP ASM configuration may fail to load after an upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system was previously running a version between 11.3.0 and 11.5.0.
  • You have created a scheduled report using the Top alerted URLs predefined filter.
  • You upgrade to BIG-IP 11.5.1 or later.

Impact

The BIG-IP ASM configuration fails to load after an upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to view security policies in the Configuration utility, the system displays an ASM is not ready message.
  • Attempting to load the configuration by using the tmsh load /sys config command results in messages similar to the following example:

    010715ee:3: The predefined report /Common/Top alerted URLs doesn't exist.
    Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can manually edit the bigip.conf file on the newly upgraded boot location and modify the predefined report name. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system because the configuration has already failed to load and the BIG-IP ASM system is not in a running state.

  1. Log in to the command line of the BIG-IP ASM system.
  2. Create a backup of the /config/bigip.conf file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.SOL40339022
  3. Use your preferred text editor to edit the /config/bigip.conf file.
  4. Locate the analytics application-security scheduled-report section of the configuration, and find the configuration line with the following syntax:

    predefined-report-name "/Common/Top alerted URLs"
  5. Replace the word alerted with alarmed.

    For example, the configuration line should now appear similar to the following:

    predefined-report-name "/Common/Top alarmed URLs"

    Note: If you have created more than one report using this predefined filter, repeat this for each occurrence of this configuration syntax.
  6. Load the configuration by typing the following command:

    tmsh load /sys config
  7. After successfully loading the configuration, save the loaded configuration by typing the following command:

    tmsh save /sys config
  8. Restart system services by typing the following command:

    tmsh restart /sys service all
