Topic

In FirePass versions prior to 6.0.3, FirePass offered support for all types of Application Access favorites only on the supported Windows operating systems; Windows Mobile operating systems were not included. Application Tunnels and Terminal Servers favorites are not supported on Linux or Mac OS X. Terminal Server functionality can be implemented through the Citrix Java ICA clients for Linux and Mac OS X.

For Legacy Hosts favorites, FirePass provides Java-based terminal emulation, which may function on any operating system that supports a Java Virtual Machine (JVM).

To connect to Citrix servers and published resources, use the Citrix Java ICA client, which is typically downloaded through a browser from a Citrix Portal. To use the Citrix Java client with FirePass, you can use a Portal Access favorite to connect to a Citrix web portal that serves the Citrix ICA Java applet, instead of using an Application Access favorite.

Note: For an overview of the changes made in FirePass version 6.0.3, refer to K9178: Change in Behavior: Static Application Tunnels are now supported for Linux and Mac OS X clients.
