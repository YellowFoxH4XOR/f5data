Description

Users accessing a web application, are encountering a new permission prompt in Google Chrome. The prompt states: "Look for and connect to any device on your local network" 

Environment

  • BIG-IP
  • Chrome 142 and later

Cause

This (LNA) Chrome Security feature adds a layer of Allow, or, Block before allowing a website to interact with services on your local device.

Answer/Recommended Actions

This behavior is resolved by installing the latest live update (signature). For example:

  • v17.1.3: BrowserChallenges_20260218_102345.im (or later)
  • v17.5.1: BrowserChallenges_20260210_120425.im (or later)

K82512024: Managing BIG-IP ASM Live Updates (14.1.x and later)

Note: It will take 48h after the installation of the signature before it takes effect.

Additional Information

For more information see the Google blog post about it.
