Known Issue

iControl REST may erroneously return an error message.

This issue occurs when all of the following conditions are met:

  • You use the iControl REST application programming interface (API) to perform a transaction on a BIG-IP system, such as, creating a new node.
  • Your iControl REST request contains a header name that uses non-standard letter casing, for example, the header name is sent as x-f5-rest-coordination-id instead of X-F5-REST-Coordination-Id

Impact

The error message returned does not correctly reflect the status of the transaction. As a result, you may think the transaction has failed, when it has completed successfully.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • iControl REST returns an error message similar to the following example when the transaction may have already completed successfully:

    {
    "code": 404,
    "errorStack": [],
    "message": "there is no command to commit in the transaction."
    }
