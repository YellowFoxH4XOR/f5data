K9192: The BIG-IP system boots to single user mode when connected to certain console router devices

Topic

By default, when the following prompt displays, the BIG-IP system boots to single user mode if the console detects any key input during the count-down process:

press ESC to boot now, any other key to interrupt boot sequence 4 3 2 1 0

If you boot the BIG-IP system while it is connected to a console device that sends a signal, the signal is detected as key input using the TD/RD line (Pin3 on the console router side, and Pin2 on the BIG-IP side). As a result, the BIG-IP system may attempt to boot to single user mode.

This issue occurs when the BIG-IP system is connected to certain console router devices, such as the following:

Cisco2620XM / IOS: 12.2(21b)

Note: For more information, refer to K587: Pinouts for serial terminal cables used to connect to F5 products.

Workaround

You can work around this issue by adjusting the console router settings so they do not generate the signal during the boot process.
