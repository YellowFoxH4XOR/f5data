Known Issue

The End User Diagnostics fails to install.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is installed using the partition formatting scheme rather than a volume formatting scheme.
  • You are attempting to install version 11.x or 12.x of the End User Diagnostics (EUD) software.

To determine if your BIG-IP host is using the partition or volume formatting scheme, please refer to SOL10817 referenced in the Supplemental Information section below.

Impact

You are unable to run the EUD from the BIG-IP system hard disk.

Symptoms

As a result of this issue, you may encounter the following symptom:

The EUD installation fails and may display error messages during install that appear similar to the following examples:

  • warning: Failed to find EUDs
    warning: Failed to get volume id for EUD
    warning: Insufficient free space on hda.dat.boot for EUD
    error: Insufficient space available to install new EUD.
    error: Newer EUD will not be installed.
    progress: 97/100
    info: Setting location sda.1 as default for next boot.
    progress: 98/100
    info: Installation succeeded.
    bash (try 'info') / > reboot

  • Not enough arguments for tm_install::EUD::EUD_update_system at /var/tmp/install/update line 64, near "$eud_pkg)"
    Execution of /var/tmp/install/update aborted due to compilation errors.

Resolution

Status

F5 Product Development has assigned ID 391686 to this issue, and has confirmed that this issue exists in the products listed in the Applies to (see versions) box. For information about releases or hotfixes that resolve this issue, refer to the following table:

This issue does not affect version 11.x of the BIG-IP system.

Workaround

To work around this issue, you need to run the EUD from a USB Flash Drive or connected USB CD/DVD drive. To do so, perform the following procedure:

Impact of workaround: You need to reboot the host to run the End User Diagnostics.

Booting the EUD from a USB flash drive

You can run the EUD by booting the system from a USB flash drive loaded with the EUD software. Use this procedure to load the EUD onto a USB flash drive.

Note: You must have a serial console connected to the system to run the EUD.

  1. Log in to the command line of the BIG-IP system using an account with root access.
  2. Download the EUD IM file to the /tmp/eud subdirectory of your BIG-IP host.
  3. Loopback mount the IM file using the following command syntax, where <file_name> is the name of the EUD IM file that you downloaded:

    mkdir /tmp/eud; mount -o ro,loop <file_name>.im /tmp/eud

  4. Insert a USB flash drive into the platform on which you mounted the IM file.

    Note: This USB flash drive is completely overwritten and cannot be shared with other data.

  5. To run the mkdisk utility, type the following command:

    cd /tmp/eud; ./mkdisk

    The system loads the EUD onto the USB flash drive.
  6. Power cycle the BIG-IP host with the USB flash drive attached.

When the EUD starts, the EUD menu is displayed on the serial console.

Booting the EUD from a connected USB CD/DVD device

Note: You must create a bootable CD or DVD using the EUD ISO image before you can boot the EUD from a USB CD/DVD drive. You can download the EUD ISO image from the F5 Downloads site.

Note: You must have a serial console connected to the system to run the EUD.

You can use the following method to boot the EUD from an externally-powered USB CD/DVD drive.

  1. If the system is powered on, turn it off.
  2. Plug the USB CD/DVD drive into the USB port on the BIG-IP system, and insert the EUD CD or DVD.
  3. Power on the system to boot the EUD.

When the EUD starts, the EUD menu displays on the console.
