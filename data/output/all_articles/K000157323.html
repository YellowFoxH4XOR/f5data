Description

  • You installed the NGINX App Protect
  • You have enabled the 'Time-based signature staging' feature
  • The security log output for the time-based signature staging feature shows 'isInStaging: false', despite staging functioning correctly.


Environment

NGINX App Protect


Cause

Logging for isInStaging does not accurately reflect the staging status due to a known software issue.


Recommended Actions

F5 is working on it and will fix it in future release. Version is not decided yet.


Additional Information

NGINX App Protect - Time-based signature staging
