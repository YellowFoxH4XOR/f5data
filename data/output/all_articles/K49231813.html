K49231813: APM identify user's Machine

Type
Support Solution
Published
2020-04-02
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.0
Source
https://my.f5.com/manage/s/article/K49231813

Description

Want to get some information related to users that are accessing via VPN.
Especially, machine name of user to access VPN.

Environment

  • APM VPN users
  • Machine Info agent in Access Policy
  • Reporting

Cause

Client Hostname information missing from Machine Info.

Recommended Actions

One option is to keep track of MAC address, i.e. session.machine_info.last.net_adapter.list, since users can generally not play around with the MAC address

Another option is to restrict access to the machine hostname.
To do this, make a Datalist for all the machine host names and iRule to verify with the below registry key on the unit :
Computer\HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\ComputerName\ActiveComputerName OR Computer\HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\ComputerName\ComputerName
Note:  maintaining this Datalist will be cumbersome as you will have to keep on updating it with every new user

Additional Information

More about the Machine Info Access Policy agent can be found here:  Manual Chapter : About Machine Info
