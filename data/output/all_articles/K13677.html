Known Issue

The BIG-IP system fails to save the running attribute to the configuration file. This issue occurs when all of the following conditions are met:

  • You use the tmsh modify sys daemon-ha <process name> running disabled command to set the running attributes for a process to disabled
  • You use the tmsh save sys config command to save the changes to the configuration file

By default, some processes have their running attribute enabled while others are disabled. The issue only occurs when the running attribute is manually set to disabled.

Note: For more information about configuring the daemon-ha setting, refer to the help screen available by typing the tmsh help /sys daemon-ha command.

Impact

The BIG-IP system may revert the running attribute value for a process unexpectedly after the configuration is reloaded or the system is rebooted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system reports the running attribute of a process as disabled. However, the configuration file does not indicate that it is disabled.

    For example, when you change the named running attribute from enabled to disabled, the setting is shown as disabled in the output of the tmsh list sys daemon-ha named all-properties command:

    sys daemon-ha named {
    app-service none
    description testing
    heartbeat disabled
    heartbeat-action none
    not-running-action go-offline-downlinks
    running disabled
    running-timeout 10
    }

    However, the modified setting of disabled is not displayed in the the /config/bigip.conf file, as shown in the following example:

    sys daemon-ha named {
    description testing
    heartbeat disabled
    heartbeat-action none
    }

Workaround

To work around this issue, you can manually add the running disabled setting to the daemon-ha configuration stanza for the affected process in the configuration file. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP command line.
  2. Make a backup copy of the /config/bigip.conf file by typing the following command:

    cp -p /config/bigip.conf /config/bigip.conf.sol13677

  3. Edit the /config/bigip.conf file using a text editor of your choice.
  4. Locate the daemon-ha configuration stanza of the affected process.

    For example:

    sys daemon-ha named {
    heartbeat disabled
    }

  5. Add the running disabled setting to the stanza.

    For example:

    sys daemon-ha named {
    heartbeat disabled
    running disabled
    }

  6. Save the changes and exit the text editor.
  7. Load the configuration from the modified configuration file by typing the following command:

    tmsh load sys config
