Topic

The root backing share is the share designated to hold new files created in the root of an ARX managed volume.

Description

The root backing share is, by default, responsible for accepting all new files created in a managed volume's root directory. File distribution requires the use of policies and/or share farms. However, if the root backing share is a member of a share farm, new file placement will respect the balancing rule of that share-farm with no additional policy.

The default root backing share for a managed volume is the oldest share defined in the volume.

Recommendations

You can use the show namespace command to verify which share the ARX system is using as the root backing share.

The show namespace command uses the following command syntax:

show namespace <namespace_name> volume <volume_name>

Note that you need to replace <namespace_name> with the name of the namespace, and replace <volume_name> with the name of the volume.

For example:

show namespace ns1 volume /vol1

The share designated as the root backing share will have the following entry:

 Volume Root Backing         Yes
