Description

During helm install, system reported the following error:

[admin@ocp-f5-jumphost tar]$ helm install f5ingress f5ingress-10.0.63.tgz -f f5ingress/ingress-values-slf-minimal.yaml -n <spk-namespace>

Error: INSTALLATION FAILED: execution error at (f5ingress/charts/f5-toda-logging/templates/fluentbit_cm.yaml:90:25): f5-toda-logging.fluentd.host is required

 

Environment

  • BIG-IP Next SPK 1.7.4

Cause

Wrong configuration input file during installing f5ingerss.

Recommended Actions

Follow the procedure for SPK Controller section Controller values and check point 2B.

If you did not installed Fluentd Logging, set the f5-toda-logging.enabled parameter to false:

f5-toda-logging:
  enabled: false

It is require rollback installation for f5ingerss, correct configuration input file for f5ingerss according to point 2B  and install again f5ingerss.
