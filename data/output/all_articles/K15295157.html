K15295157: MyF5 only displays maximum 1000 search results

Type
Support Solution
Published
2022-02-11
Updated
2024-01-26
Applies to
  • Support Portal
Source
https://my.f5.com/manage/s/article/K15295157

Description

When you perform search on My.F5.com, you are not able to see results that exceed 1000 items.

Environment

  • my.f5.com

Cause

This behavior is functioning as designed. The search engine used on MyF5 has a hard limit of 1000 results.
