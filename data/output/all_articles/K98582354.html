K98582354: How to force BIG-IP to use NTPv3 (NTP version 3) only

Type
Support Solution
Published
2020-11-03
Updated
2025-02-07
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K98582354

Description

By default BIG-IP will use NTPv4 to communicate with a NTP server.
This article explains how to force the BIG-IP to only use NTPv3 to communicate with the NTP server.

Environment

The following conditions must be met

  • BIG-IP
  • NTPv3

Cause

None.

Recommended Actions

Follow the steps below to force the BIG-IP ntpd daemon to communicate with the NTP server using NTPv3 protocol only.
IMPORTANT: Please follow this in maintenance window.

  1. Login to the BIG-IP command line.
     
  2. Edit the NTP configuration file with the following commands.
    tmsh
    edit /sys ntp all-properties
     
  3. Find sys ntp for the ntp configuration and add version 3 after each ntp server IP address,  also add {} to "servers none" like below
    modify sys ntp {
    description none
    include "
    server x.x.x.x version 3
    server y.y.y.y version 3
    server z.z.z.z version 3
    "
    restrict none
    servers { none }
    timezone America/Example
    }

    An example of a complete ntp configuration would be as below.
    modify sys ntp {
    description none
    include "
    server 10.1.1.1 version 3
    server 10.1.1.2 version 3
    server 10.1.1.3 version 3
    "
    restrict none
    servers { none }
    timezone America/Los_Angeles
    }
     
  4. Save and exit the file editing and for prompt, type y.
    :wq
    Save changes? (y/n/e) y
     
  5. Save config changes.
    tmsh save /sys config
     
  6. Restart ntpd
    tmsh sys service restart ntpd
