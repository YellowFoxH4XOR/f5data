K12294: The route domains feature is not compatible with IPv6 addresses

Topic

The route domains feature is compatible with only IPv4 addresses. All IPv6 addresses that you define on the BIG-IP system must reside in route domain 0 (the default route domain). This limitation is by design and is due to the current implementation of the route domains feature.

Note: For more information about route domains, refer to the following documentation:

  • BIG-IP Local Traffic Manager: Implementations
  • K10467: Userland applications on a BIG-IP system cannot connect to hosts in non-default route domains

For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

The functionality to extend the route domains feature to IPv6 addresses is added in BIG-IP 11.1.0. For more information, refer to K13388: Route domains support for IPv6.
