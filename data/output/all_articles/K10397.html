Known Issue

This is the result of a known issue. The ARX system allows the configuration of a maximum of six SNMP communities. When six SNMP communities have been configured, subsequent attempts to add another SNMP community or delete an existing SNMP community will fail with the following error message:

% ERROR: SNMP_COMMUNITY_LIMIT_EXCEEDED (34144264):
  A maximum of 6 SNMP communities can be configured.

F5 Product Development tracked this issue as ARX ID 35314 and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.

Additionally, this issue has been fixed in a hotfix available for ARX version 4.1.1. Customers affected by this issue should request the hotfix from F5 Technical Support, referencing this article number and ARX ID 35314.
