Known Issue

This is the result of a known issue. If you configure a new Administrative Realm containing one or more backslash ( \ ) characters in its name, FirePass adds three additional backslash characters after each backslash character entered.

For example:

illinois\chicago\engineering

If you enter the example text in the Create new realm field on the Device Management: Security: Administrative Realms page, FirePass will create the Administrative Realm name with three additional backslash characters, which will appear similar to the following example::

illinois\\\\chicago\\\\engineering

Note: This issue is cosmetic and does not affect the functioning of FirePass.

F5 Product Development tracked this issue as CR73298 and it was fixed in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.

This issue still exists in the FirePass 5.x branch.
