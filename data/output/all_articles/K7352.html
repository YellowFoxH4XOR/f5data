Known Issue

This is the result of a known issue. A DNS query for any request type records on the BIG-IP GTM wide IP can return a corrupted response. This results in a failed query, causing the LDNS to send another query for the information.

F5 Product Development tracked this issue as CR76811, and it was fixed in BIG-IP GTM 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP GTM Release Notes.
