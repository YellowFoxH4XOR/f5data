Description

  • Unable to configure the device management IP via CLI with the config commnad
  • The following error message appears:

    save error: 01070750:3: Route gateway address does not match destination's address type (inet vs. inet6).

Environment

  • BIG-IP device
  • New configuration

Cause

Device  was partially configured via tmsh with management ip or management route

Recommended Actions

Remove the partially configured management IP configuration:

  1. Connect to CLI
  2. Remove the management IP configuration:
    tmsh delete sys management-ip all
    tmsh delete sys management-route all
    tmsh save sys base-config
  3. Configure Management IP with 'config' command
    config

None
