K33257315: DHD compact menu is activated when DDoS module is not provisioned

Type
Support Solution
Published
2022-04-18
Updated
2023-02-21
Applies to
  • F5 App Protect
  • F5 DDoS Hybrid Defender: 16.X.X, 15.X.X, 14.X.X, 16.1.X, 16.0.X, 15.1.X, 15.0.X, 14.1.X, 14.0.X, 16.1.0, 16.0.0, 15.1.1, 15.1.0, 15.0.0, 14.1.2, 14.1.0, 14.0.0
Source
https://my.f5.com/manage/s/article/K33257315

Description

If F5 DDoS Hybrid Defender(DHD) is licensed but not provisioned, the DHD compact menu is activated. You need to click "Show Advance Menu" to see the usual BIG-IP Configuration Utility (GUI).

Environment

  • BIG-IP DDoS Hybrid Defender Version 14 onwards 
  • DDOS is licensed but not provisioned

Cause
None

Recommended Actions
Please contact F5 Support  for further assistance

Additional Information
None
