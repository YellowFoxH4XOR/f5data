Known Issue

This is the result of a known issue. On rare occasions, the BIG-IP ASM bd process crashes when a user makes configuration changes while the system is writing to the log files. This issue can occur for either local or remote logging profiles.

F5 Product Development tracked this issue as ID 242650 (formerly CR134502) and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue was also fixed in Hotfix-BIGIP-9.4.8-396.1-HF3 issued for BIG-IP version 9.4.8, and Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
