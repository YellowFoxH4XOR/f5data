K000133153: Kaspersky premium is detected as Windows Defender

Type
Support Solution
Published
2023-03-23
Updated
2023-05-23
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000133153

Description

The BIG-IP APM access policy client-side Endpoint Security (EPSEC) is failing to detect Kaspersky Premium but detecting as Windows Defender instead.


Environment

  • BIG-IP APM,
  • AV Check
  • Kaspersky Premium
  • Windows Defender
  • EPSEC version 1205

Cause

You are using outdated EPSEC version 1.0.0-1205.0 or earlier


Recommended Actions

Update to latest version of EPSEC


Additional Information

None
