Issue

Old Behavior

In versions prior to BIG-IP 15.1.0, startup services are managed by a combination of sysvinit, systemd, and the bigstart utility.

Traditionally, Linux systems have relied on sysvinit to start and manage system processes. Today, the majority of Linux distributions have adopted systemd, as it provides several advantages over the older, traditional sysvinit, as follows:

  • Services are started in parallel instead of serially, which reduces boot-up time.
  • Service configuration is easier.
  • It has more robust control and debugging.
  • It is compatible with sysvinit.

For more information about systemd, refer to systemd System and Service Manager.

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

New Behavior

Beginning in BIG-IP 15.1.0, startup services are managed by systemd and the bigstart utility.

F5 Product Development tracked this change as ID 793073.

Impact

The new systemd services that have been created will generate log files in the new log directory /var/log/f5-sysinit.d/.
