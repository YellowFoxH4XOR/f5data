Topic

BIG-IP Edge Client download components to end-user computers at initial logon and whenever a feature or favorite is started. The downloaded client components enable the various features of BIG-IP Edge Client functionality. You may remove these components from Windows systems by performing one or more of the following procedures:

To watch a video demo of the Configuration utility and Windows procedures, go to  K000157156: Remove BIG-IP client components from your Windows client system.

  • Use the CTU to remove components
  • Manually remove BIG-IP APM client components
  • Use the Windows Add/Remove feature to remove components

If you installed F5 Access and want to remove it, perform the following procedure:

  • Remove F5 Access

Use the CTU to remove components

Download the BIG-IP APM CTU

Use either the BIG-IP APM virtual server address (available to BIG-IP administrators and VPN users) or the Configuration utility (available only to BIG-IP administrators) to download the CTU.

Use the virtual server address

  1. On the Windows client system, go to the following URL where <apm_hostname> is the host name of the BIG-IP APM virtual server where you would connect to establish an access session:

    https://<apm_hostname>/public/download/f5wininfo.exe

  2. Save the f5wininfo.exe file to a folder on the client system.

Use the Configuration utility

  1. Log in to the Configuration utility.
  2. Select the F5 logo to access the Welcome page.
  3. Under Downloads, under BIG-IP Edge Client Components, select Client Troubleshooting Utility for Windows.
  4. Save the f5wininfo.exe file to a folder on the computer.

Run the CTU to remove components

The following procedure removes BIG-IP APM components from a Microsoft Windows system using the Components Troubleshooting Utility (CTU). This procedure requires administrator privileges on the Windows system.

  1. On the Windows client system, log out from any BIG-IP APM active sessions.
  2. Close all browser windows.
  3. Close BIG-IP Edge Client if it is running.
  4. Launch the CTU (f5wininfo.exe).
  5. For Tools, select Remove Components.
  6. In the pop-up window, to confirm removal, select Yes.
  7. If you downloaded the f5wininfo.exe file from a BIG-IP APM system running BIG-IP 13.1.0 or later, perform the following steps:
    1. For Tools, select Cleanup browsers custom protocol preferences.
    2. Close all browser windows.
    3. In the pop-up window, select Continue.
  8. When removal is complete, close the CTU.
  9. Optional: Delete the CTU (f5wininfo.exe).

Manually remove BIG-IP APM client components

Note: This procedure requires administrator privileges on the Windows system.

  1. On the Windows client system, log out from any BIG-IP APM active sessions.
  2. Close all browser windows.
  3. Close BIG-IP Edge Client if it is running.
  4. Open Windows command line using Run as administrator.
  5. Enter the following commands:

    sc stop "F5 Networks Component Installer"
    sc delete "F5 Networks Component Installer"
    del %WINDIR%\System32\F5InstallerService.exe
    del %WINDIR%\SysWOW64\F5InstallerService.exe

  6. Enter the following commands from the Windows command line or using a batch script:

    Note: Depending on which components you installed and which version of Windows you are running, not all of the following files and directories are present on your Windows system. When running the following commands, Windows may report that it could not find the file or directory you entered. These errors can be safely ignored.

    del "%WINDIR%\Downloaded Program Files\f5*.*"
    del "%WINDIR%\Downloaded Program Files\CacheCleaner.*"
    del "%WINDIR%\Downloaded Program Files\ur*.*"
    del "%WINDIR%\Downloaded Program Files\InstallerControl.*"
    del "%WINDIR%\Downloaded Program Files\HookDll.dll"
    del "%WINDIR%\Downloaded Program Files\*opswat*"
    del "%WINDIR%\Downloaded Program Files\set9x16.dll"
    del "%WINDIR%\Downloaded Program Files\set9x32.dll"
    del "%WINDIR%\Downloaded Program Files\setup2000.dll"
    del "%WINDIR%\Downloaded Program Files\setupdrvdll.dll"
    del "%WINDIR%\Downloaded Program Files\TunnelServer.exe"
    del "%WINDIR%\Downloaded Program Files\TunnelServerX.dll"
    del "%WINDIR%\Downloaded Program Files\utunres.dll"
    del "%WINDIR%\Downloaded Program Files\vdeskctrl.dll"
    del "%WINDIR%\Downloaded Program Files\vdeskctrl.inf"
    del "%WINDIR%\Downloaded Program Files\VNCClientX.dll"
    del "%WINDIR%\Downloaded Program Files\Win32SystemCheck.dll"

    del "%PROGRAMFILES%\Mozilla Firefox\plugins\NPuroam*"

    rmdir /S /Q "\Program Files (x86)\F5"
    rmdir /S /Q "\Program Files (x86)\F5 VPN"
    rmdir /S /Q "%USERPROFILE%\Application Data\F5 Networks"

    del %TEMP%\Low\f5*.txt
    del %TEMP%\Low\logterminal.txt
    del %TEMP%\f5*.*
    del %TEMP%\logterminal.txt
    del %WINDIR%\Temp\f5*.*
    del %WINDIR%\Temp\logterminal.txt
    del %WINDIR%\Temp\decompress_log.txt

  7. In the %WINDIR%\System32 and %WINDIR%\Downloaded Program Files directories, remove all directories starting with Conflict if they exist.
  8. Delete all BIG-IP APM Dial-up Adapters. These adapters may have been renamed on your system or may not exist. However, by default, these adapter names are:

    [Network Access Favorite Name] - Go to <BIG-IP APM hostname or IP address> instead of dialing directly

    del %PROGRAMDATA%\Microsoft\Network\Connections\Pbk\rasphone.pbk.F5VPNDialer.cfg
    del %PROGRAMDATA%\Microsoft\Network\Connections\Pbk\rasphone.pbk
    del %USERPROFILE%\AppData\Roaming\Microsoft\Network\Connections\Pbk\_hiddenPbk\rasphone.pbk

    Note: For more information about deleting Dial-Up Adapters, refer to your Windows documentation.

  9. Using the Windows Control Panel, remove (uninstall) the following programs if they are installed:

    Note: For more information about removing programs, refer to your Windows documentation.

    • F5 VPN Client for Windows
    • F5 Edge Client
    • F5 Edge Client Components
    • GPAnywhere for VPN
    • OPSWAT AntiVirus and Firewall Integration Libraries
    • Citrix Clients (if installed during access portal use)
       
  10. In the Windows Device Manager, for View, select Show hidden devices and then expand Network adapters. If the F5 VPN Adapter appears under Network adapters, right-click the F5 Networks VPN Adapter and select Uninstall.

    Note: For more information about managing devices using the Device Manager, refer to your Windows documentation.

  11. Use a registry editor tool to remove the following registry keys if they exist:

    Important: If you make an error while editing the Windows registry settings, you may create severe issues that can be solved only by reinstalling the operating system. Use the registry editor with extreme caution.

    • HKEY_CURRENT_USER\SOFTWARE\F5 Networks
    • HKEY_CURRENT_USER\ SOFTWARE \uRoam
    • HKEY_LOCAL_MACHINE\ SOFTWARE\F5 Networks
    • HKEY_LOCAL_MACHINE\ SOFTWARE\uroam
       
  12. Remove the folders created by the BIG-IP Edge Client that match the _RAS adapter name, if they exist:

    Important: If you make an error while editing the Windows registry settings, you may create severe issues that can be resolved only by reinstalling the operating system. Back up your Windows registry first and use the registry editor with extreme caution.
     
    • HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Internet Settings\Connections
    • HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\NetworkList\Profiles
    • HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\NetworkList\Signatures\Unmanaged
       
  13. Enter the following commands from the Windows command line:

    sc stop "F5FltSrv"
    sc delete "F5FltSrv"
    del %WINDIR%\System32\F5FltSrv.exe
    del %WINDIR%\SysWOW64\F5FltSrv.exe

    Note: For more information about the CTU, refer to K12444: Overview of the Client Troubleshooting Utility.

Use the Windows Add/Remove feature to remove components

You can remove BIG-IP Edge Client by using the Windows Add/Remove feature. For more information, refer to Repair or remove programs in Windows 10.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

When you use this method, BIG-IP Edge Client runs in uninstall mode and removes components, registry settings, drivers and associated Windows services. To do so perform the following procedure:

  1. On your Windows client, select Start.
  2. Go to Control Panel > Programs and Features.
  3. Select BIG-IP Edge Client.
  4. Select Uninstall.

Remove F5 Access

  1. On your Windows client, select Start.
  2. Enter Apps and Features and press Enter.
  3. Select F5 Access
  4. Select Uninstall, and then select Uninstall again.
