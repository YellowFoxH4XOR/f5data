K07425379: Unable to install attack signature if PATCH methoed blocked

Source
https://my.f5.com/manage/s/article/K07425379

Description
Attack signature fail to install

Environment

  • BIG-IP ASM
  • Install attack signature file

Cause
Typically, if the installation has not been previously created, begin with a POST to create the installation (including the installation ID returned to the browser).
POST /mgmt/tm/live-update/asm-attack-signatures/installations

Followed by a PATCH to install the installation IDs created by the POST request above.
PATCH /mgmt/tm/live-update/asm-attack-signatures/installations/ff808081826eb77d0183e91561e20018

PATCH https://172.23.133.193/mgmt/tm/live-update/asm-attack-signatures/installations/ff808081837280740183728075540001
<< Installation ID ff808081837280740183728075540001 blocked
(Access Check with a 403 Forbidden response code).

 

Recommended Actions

 If you are updating the ASU on the current proxy path, you should use this particular
/mgmt/tm/live-update/asm-attack-signatures/installations/*
endpoint (note that the installation ID will change).
