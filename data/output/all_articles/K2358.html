Topic

You cannot modify the default template for the SMTP pinger. As such, you will need to perform one of the following procedures in order to change the timeout value for the SMTP health monitor:

  • Create a new monitor with new timeout values that references the old monitor.
  • Create a new monitor that uses the HTTP default monitor and configure the HTTP port as an SMTP port.

Note: For more specific instructions about creating monitors, refer to the BIG-IP Reference Guide.

Create a new monitor that references the old monitor

Use the following example to create a new monitor, with new timeout values, referencing the SMTP pinger:

b monitor smtp_long_timeout '
{ use smtp dest *:25 interval 60 timeout 310 domain ''yoursite.com'' }'
b monitor smtp_long_timeo
t show
monitor smtp_long_timeout {
# type smtp
use ''smtp''
interval 60
timeout 310
dest *:25
domain ''yoursite.com''
}

Create a new monitor that uses the HTTP default monitor configured as an SMTP port

Use the following example to create a new monitor that uses the HTTP default monitor, and to configure the HTTP port as an SMTP port:

b monitor MySmtp '{ use http interval 30 timeout 330 dest *:25 send
 ''EHLO yoursite.com'' recv ''pleased'' username '''' password ''''
}'
b monitor MySmtp show
monitor MySmtp {
# type http
use ''http''
interval 30
timeout 330
dest *:25
send ''EHLO yoursite.com''
recv ''pleased''
username ''''
password ''''
}
