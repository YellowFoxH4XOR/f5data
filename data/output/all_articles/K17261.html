Issue

The halt command now halts and powers off the BIG-IP host subsystem for the following hardware platforms:

  • VIPRION B2250 Blades
  • BIG-IP i10000 series
  • BIG-IP i7000 series
  • BIG-IP i5000 series
  • BIG-IP i4000 series
  • BIG-IP i2000 series
  • BIG-IP 12000 series
  • BIG-IP 10000 series
  • BIG-IP 7000 series
  • BIG-IP 5000 series
  • BIG-IP 4000 series
  • BIG-IP 2000 series
  • BIG-IP 3900
  • BIG-IP 3600
  • BIG-IP 1600

Old Behavior

In versions prior to BIG-IP 12.0.0, the halt command halts the operating system of a BIG-IP host subsystem, but does not power off the host subsystem. Depending on your hardware platform, when the BIG-IP host subsystem is halted, you can reset the host subsystem by choosing one of the following options from the AOM menu to boot up the system:

  • On a VIPRION system:

    R --- Reset blade

  • On a BIG-IP 1600, 3600, or 3900 system:

    3 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)

  • On other BIG-IP systems:

    R --- Reset host subsystem

The following example shows the steps to boot up the VIPRION B2250 blade in slot1 of the VIPRION chassis, after issuing the halt command:

AOM Command Menu:
B --- Set baud rate
C --- Capture blade console
I --- Display platform information
P --- Power on/off blade
R --- Reset blade
E --- Display error report
Q --- Quit menu and return to console

Enter Command: R

Blade to reset (1-4)? 1
Are you sure you want to reset the blade in slot 1? (y/n) y

Resetting blade in slot 1...done.

New Behavior

Beginning in BIG-IP 12.0.0, the halt command halts the operating system of the BIG-IP host subsystem, and powers off the host subsystem as well. As a result, you are now required to power on the BIG-IP host subsystem by choosing one of the following options from the AOM menu to boot up the system, based on the hardware platform:

  • On a VIPRION system:

    P --- Power on/off blade

  • On a BIG-IP 1600, 3600, or 3900 system:

    5 --- Power on Host subsystem

  • On other BIG-IP systems:

    P --- Power on/off host subsystem

For example, you should connect to the AOM menu and select the P option to allow the VIPRION B2250 blade to boot up, after the halt command has been issued. The steps to power on slot1 of the VIPRION chassis may appear similar to the following example:

AOM Command Menu:
B --- Set baud rate
C --- Capture blade console
I --- Display platform information
P --- Power on/off blade
R --- Reset blade
E --- Display error report
Q --- Quit menu and return to console

Enter Command: P

Blade to turn on or off (1-4)? 1

0 -- Turn blade off
1 -- Turn blade on

Select power option: 1
Are you sure you want to power the blade in slot 1 on? (y/n) y

Powering on blade 1.... . done.

Impact

The BIG-IP host subsystem does not respond to the reset option from the AOM menu after issuing the halt command. As a result, to restore operation after halting the BIG-IP system, you must manually power on the host subsystem.

Recommended Actions

  • To restore operation, after halting the BIG-IP system, you must manually power on the BIG-IP host subsystem. To do so perform one of the following two actions:
    • Power on the host subsystem by accessing the AOM menu and selecting the Power on option.
    • On the LCD display, turn on the BIG-IP device by selecting the check mark button.
  • To achieve the results of the previous halt command behavior on a BIG-IP system, in BIG-IP 12.0.0 (to halt the operating system without powering off the host subsystem), type the following command:

    shutdown -H now

  • If you are using scripts that call the halt command, you should adjust the scripts to use the shutdown -H now command.
