Known Issue

This is the result of a known issue. When creating or editing a wide IP or link, the BIG-IP GTM Configuration utility allows adding a non-existent (blank) iRule to the wide IP configuration. For example, if you create a new wide IP and click Add in the iRule List section without selecting an iRule, the Configuration utility generates the following error message when you click Finished:

01070709:7: Wideip rule () not found

F5 Product Development is tracking this issue as CR85671.

Note: This issue does not affect the BIG-IP 10.x software branch.

Workaround

To work around this issue, click the iRule List box and then click Remove to remove the non-existent iRule from the configuration. Click Finished to complete the wide IP configuration.
