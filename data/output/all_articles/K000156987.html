Description

The SSLo GUI would allow to create Security Policies rules with Glob match expressions, especially for the options "Server Certificate (Subject DN)" or "Server Certificate (Issuer DN)". But you're prompted with an error message stating: "Must be a valid sni name".


Environment

BIG-IP SSL Orchestrator


Cause

(Bug alias 2131101) gc-ui-library's SNI validator does not support full glob features


Recommended Actions

To use the full glob feature set the security policy must be deployed than manually update the Per Request Policy.


  1. Disable strict updates for the security policy.
  2. Navigate to Access >> Profiles/Policies >> Per-request policies.
  3. Locate the policy to modify and click on “Edit”
  4. Edit the Branch Rules:
    1. Click on the agent and then go to “Branch Rules” and click on “Change”
    2. A new window will open with two tabs: Simple and Advanced.
  5. 4. Use the Advanced Tab:
    1.   Click on “Advanced” tab and modify the expression. Add the expression like:
    2.   expr {[mcget {perflow.ssl.client_hello.sni}] matches_glob "(ABC)-test.server.com"}
