Issue

Old Behavior

In versions earlier than BIG-IP 13.1.0, or BIG-IP 12.0.0 for Virtual Edition, the tm.tcplargereceiveoffload db variable is disabled by default.

For more information on Large Receive Offload (LRO), refer to K15609: Overview of TCP Segmentation Offload and Large Receive Offload.

New Behavior

Beginning in BIG-IP 13.1.0, or BIG-IP 12.0.0 for Virtual Edition, the db variable tm.tcplargereceiveoffload is enabled by default.

Impact

Generally, enabling LRO improves system performance, except for the following known configuration:

  • A FastL4 virtual server using Bandwidth Controller (BWC) policies.

    F5 Product Development has assigned ID 686190 to this issue.

Recommended Actions

F5 recommends that you monitor your CPU utilization after you upgrade to BIG-IP 13.1.0, or BIG-IP 12.0.0 for Virtual Edtion. If you observe significant performance degradation, consider disabling the tm.tcplargereceiveoffload db variable. For information about disabling the db variable, refer to K15609: Overview of TCP Segmentation Offload and Large Receive Offload.
