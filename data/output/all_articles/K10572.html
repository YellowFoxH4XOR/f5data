Known Issue

This is the result of a known issue. The Minimize window after successfully creating Static Tunnel option does not function properly in Internet Explorer 8 when both of the following conditions are met: 

  • The client system is running Windows Vista
  • The client system has User Account Control (UAC) enabled

Note: The Minimize window after successfully creating Static Tunnel setting is located on the Application Access : App Tunnels : Master Group Settings page.

F5 Product Development tracked this issue as CR116830 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-5 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by connecting to FirePass using an alternate browser, such as Firefox. For security reasons, F5 Technical Support does not recommend disabling UAC on client systems.
