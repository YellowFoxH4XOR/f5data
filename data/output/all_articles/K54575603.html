K54575603: Dataplane INOPERABLE - Expected Configuration Module bay1 is absent!

Type
Support Solution
Published
2025-03-07
Updated
2025-03-07
Applies to
  • BIG-IP
  • BIG-IP Platforms
  • BIG-IP i5000 Series
Source
https://my.f5.com/manage/s/article/K54575603

Description

From the command line, the BIG-IP broadcasts the following messages.

Dataplane INOPERABLE - Expected Configuration Module bay1 is absent!
Dataplane init error: Dataplane INOPERABLE - Expected Configuration Module bay1 is absent!
getConfigModuleBoardTypeBmcDev: getFruStorageAreaIpmiCmdDev: readFru: Unable to read FRU data for dev 1  (cc=203) Requested sensor, data, or record not present
getConfigModuleInfoCM(1) model: Unknown

Environment

  • The WebUI reports "Please wait while the configuration utility restarts"
  • The CLI repeatedly broadcasts these messages.

Cause

Possible RMA.

Recommended Actions

  1. Run an End User Diagnostic.
  2. Open a support case with F5.
  3. Upload the EUD results to the case.

Additional Information

None.
