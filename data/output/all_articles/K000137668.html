Description

BIG-IP Next SPK CWC is unable to setup channel with relevant entity  
hb.go:91] Error publishing heartbeat message. Failed to open channel
amqp.go:133] DEBUG: exchange name = CWC-SPK

 

Environment

  • BIG-IP Next SPK 1.7.X
  • BIG-IP Next SPK 1.6.X
  • BIG-IP Next SPK 1.5.X


Cause

There is a race condition between RabbitMQ and CWC


Recommended Actions

1. Scale down CWC and RABBIT
	# oc scale deployment.apps/f5-rabbit --replicas 0
	# oc scale deployment.apps/f5-spk-cwc --replicas 0

2. Scale up RABBIT first
	# oc scale deployment.apps/f5-rabbit --replicas 1

3. Once RABBIT pod is up #2 , then scale up CWC deployment
	# oc scale deployment.apps/f5-spk-cwc --replicas 1
 

Additional Information

Fixed since BIG-IP Next SPK 1.8.X
