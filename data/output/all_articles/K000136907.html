Security Advisory Description

BIG-IP APM clients may send IP traffic outside of the VPN tunnel. (CVE-2023-43124)

Impact

If a client machine connects to a malicious adjacent network device, such as a router or Wi-Fi hotspot, an attacker may be able to trick the client into sending IP traffic outside of the VPN tunnel. Any clear text traffic leaked outside the tunnel may be accessible to the attacker.

Security Advisory Status

F5 Product Development has assigned ID 1352397 (APM Clients) to this vulnerability. This issue has been classified as CWE-319: Cleartext Transmission of Sensitive Information.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by installing a version listed in the Fixes introduced in column. If the Fixes introduced in column does not list a version for your branch, then no update candidate currently exists for that branch and F5 recommends that you upgrade to a version with the fix (refer to the tables).

If the Fixes introduced in column lists a version prior to the one you are running, in the same branch, then your version should have the fix.

Mitigation

To mitigate this vulnerability for full tunnel BIG-IP Edge Clients, browser VPNs, and Android F5 Access clients, you can disable local subnet traffic in the BIG-IP APM Network Access profile. This forces all traffic, except the virtual server traffic, through the VPN tunnel. To do so, perform the following procedure:

Impact of action: Performing the following procedures should not have a negative impact on your system.

  1. Log in to the BIG-IP APM system as an administrator.
  2. Go to Access > Connectivity / VPN > Network Access (VPN) > Network Access Lists.
  3. Select the Network Access profile to configure.
  4. Select the Network Settings tab.
  5. For Client Settings, select Advanced from the list.
  6. Clear the Allow Local Subnet check box.
  7. For Traffic Options, select Force all traffic through tunnel.
  8. Select Update.

In addition, if you need to segregate some local traffic from the VPN tunnel, for example, to provide access to a printer over a local network at an employee’s home, create restrictive rules on each computer’s local firewall, if supported, to allow only certain activities from a fixed list.
