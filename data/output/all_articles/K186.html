By default, BIG-IP is configured to reject invalid segments on closed ports. It does this by sending an RST packet. To enable or disable ports, use the following version-specific commands.

Note: Starting in BIG-IP version 2.1, explicitly enabling a port is not required once you create a VIP from the Configuration utility; however, if the VIP is created through the command line interface with the bigpipe utility, you must manually enable it using the following version-specific syntax.

BIG-IP versions 4.0 through 4.6.4

To enable or disable TCP and (or) UDP for a specific port, use the following command syntax:

bigpipe service <port> ... <tcp|udp> <enable|disable>

For example:

b service 80 443 tcp enable

b service 7 53 udp enable

b service 80 443 tcp disable

b service 7 53 udp disable

BIG-IP versions 3.0 through 3.3.1 PTF-06

To enable or disable a port, use the following command syntax:

bigpipe port <port> ... <enable|disable>

For example:

bigpipe port 80 443 enable

bigpipe port 80 443 disable

BIG-IP versions 1.8.3 through 2.0

To enable or disable a port, use the following command syntax:

bigpipe port <port> ... allow

For example:

bigpipe port 80 443 allow
