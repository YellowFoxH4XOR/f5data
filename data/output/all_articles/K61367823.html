Known Issue

BIG-IP ASM remote logging may log a sub-violation attack type of N/A.

This issue occurs when all of the following conditions are met:

  • You configured your BIG-IP ASM system for remote logging using Common Event Format (ArcSight).
  • The BIG-IP ASM system detects one of the following HTTP Protocol Compliance sub-violations.
    • High ASCII characters in headers.      
    • Host header contains IP address. 
    • CRLF characters before request start.
    • Header name without header value.
    • Body in GET/HEAD requests.
  • The BIG-IP ASM system detects the following Evasion technique sub-violation. 
    • Directories traversals.

Impact

The system incorrectly logs the sub-violation attack type.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view the BIG-IP ASM remotely logged violations, you note that the sub-violation attack type is listed as N/A.
