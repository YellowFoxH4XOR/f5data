K8050: Pre-logon sequence registry checks for DWORD values need decimal conversion

Published
2007-10-29
Updated

Topic

In FirePass versions 6.0.2 and earlier, the pre-logon sequences can check Windows client systems for registry entries, using the Windows registry checker Endpoint Inspector.  When creating a pre-logon sequence that tests Windows registry key values of type DWORD, the test must be created in the Pre-logon Sequence editor using a decimal number, even if the key's value is entered as a hexadecimal number. Starting in FirePass version 6.0.3, the hexadecimal value can be used.

For example:

My Computer\HKEY_CURRENT_USER\Software\app1\testkey

If the example DWORD registry key contains a hexadecimal value of 0x000000ff, you would construct the following test for the value of the key using the decimal equivalent value (256) in the Check System registry field of the Windows registry checker Endpoint Inspector:

"My Computer\HKEY_CURRENT_USER\Software\app1"."testkey" = "256"
