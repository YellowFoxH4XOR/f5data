Topic

You should consider using these procedures under the following condition:

  • You want to modify the discovery address or the management address of the BIG-IQ system.

Description

You can modify the discovery address by accessing the BIG-IQ setup wizard. You can modify the management IP address by accessing the BIG-IQ setup wizard, or in BIG-IQ 7.1.0, the TMOS shell (tmsh). If you encounter issues updating the discovery address, review the latest restjavad log, /var/log/restjavad.0.log for details about the issue. For example you may observe a log message similar to the following:

Failed to change discovery address, reverting address to 10.1.1.1. Before changing the default self-ip, you must first delete/un-manage all devices that you have established communication with.

Note: In an IPv6 environment, you cannot use a Link Local IPv6 address as the discovery address.

Prerequisites

Read the three scenarios carefully to determine the prerequisites.

To modify the discovery address or modify the management address when it is used as the discovery address, you must meet the following prerequisites to use the procedures:

  • You must remove all managed BIG-IP systems, data collection devices (DCDs), and the HA peer.
  • You have the IP addresses of the following devices to re-manage and re-pair:
    • Managed BIG-IP devices
    • DCDs added to the BIG-IQ system
    • The BIG-IQ high availability (HA) peer
  • You create a snapshot for each DCD managed by the BIG-IQ system. To change the discovery address, you must remove each managed DCD. F5 recommends that you create an external snapshot for each DCD to avoid losing the data collected by that DCD. For more information about managing a DCD, refer to the Managing a Data Collection Device Cluster chapter in the Planning and Implementing an F5 BIG-IQ Centralized Management Deployment manual.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

  • You have administrative access credentials for the BIG-IQ system.

To modify the management address when it is not used as the discovery address, and the BIG-IQ system is in an HA pair, you must meet the following prerequisites to use the procedures:

  • You must remove the HA peer.
  • You have the IP addresses of the HA peer to re-pair.
  • You have administrative access credentials for the BIG-IQ system.

To modify the management address when it is not used as the discovery address, and the BIG-IQ system is in standalone mode, you must meet the following prerequisites to use the procedures:

  • You have administrative access credentials for the BIG-IQ system.

Procedures

  • Modifying the management address (7.1.0 and later)
  • Modifying the discovery address (7.1.0 and later)
  • Modifying the discovery address or the management address (5.3.0 - 7.0.0)
  • Configuring the management IP address of the BIG-IQ system during initial setup

Modifying the management address (7.1.0 and later)

You must use tmsh to modify the management address in BIG-IQ 7.1.0 and later. If the management address is the same as the discovery address, you must re-configure the discovery address using the BIG-IQ setup wizard.

Impact of procedure: When connected to the BIG-IQ system using the management address, changing the management address disconnects you from the BIG-IQ system. F5 recommends that you run the commands from a console connection. If the management address is used for discovery, this procedure changes the address on the BIG-IQ system that it uses to discover managed BIG-IP devices, peer BIG-IQ devices, and data collection devices.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To configure the management IP address, use the following syntax:

    Note: The TMOS Shell does not validate if you need to remove discovered devices per the prerequisites noted previously.

    create /sys management-ip [ip address/netmask]

    or

    create /sys management-ip [ip address/prefixlen]

    For example, your command looks similar to the following:

    create /sys management-ip 192.168.1.245/255.255.255.0

    or

    create /sys management-ip 192.168.1.245/24

  3. To configure a default management gateway, use the following syntax:

    create /sys management-route default gateway <gateway ip address>

    For example, your command looks similar to the following:

    create /sys management-route default gateway 192.168.1.254

    Or, to configure a default IPv6 management gateway, use the following syntax:

    create /sys management-route default-inet6 gateway <gateway ip address>

    For example, your command looks similar to the following:

    create /sys management-route default-inet6 gateway 2001:db8::1

  4. Save the changes by typing the following command:

    save /sys config

  5. If the old management address was also the discovery address, you must complete the following Modifying the discovery address (7.1.0 and later) procedure to designate the new management address as the discovery address.

Modifying the discovery address (7.1.0 and later)

To modify the discovery address, perform the following procedure:

Impact of procedure: This procedure changes the address on the BIG-IQ system that it uses to discover managed BIG-IP devices, peer BIG-IQ devices, and data collection devices. System services will restart, which causes a disruption of the BIG-IQ management traffic.

  1. Log in to the BIG-IQ system as the administrative user.
  2. Go to System > THIS DEVICE > General Properties.
  3. Select the Return to Setup button.
  4. Select Continue to enter setup mode.

    You are logged out and system services is stopped.

  5. Once the BIG-IQ user interface is available, log back in as the administrative user and you should now be redirected to the setup wizard.
  6. Select Next to advance.

    You may have to select Discard Changes to proceed.

    Once you are on the Password step, you must re-configure the Admin and Root passwords. Use the current passwords for this step.

  7. Continue selecting Next to advance to the Networking step.
  8. When on the Networking step, select a new option for Discovery Address.
  9. Select Next until you reach the final step, then select Launch.
  10. Select Restart to confirm restarting system services.

Modifying the discovery address or the management address (5.3.0 - 7.0.0)

To modify the discovery address or the management address, perform the following procedure.

Impact of procedure: When connected to the BIG-IQ system using the management address, changing the management address disconnects you from the BIG-IQ system. If the management address is used for discovery, or you modify the discovery address, this procedure changes the address on the BIG-IQ system that it uses to discover managed BIG-IP devices, peer BIG-IQ devices, and data collection devices. System services will restart, which causes a disruption of the BIG-IQ management traffic.

  1. Log in to the BIG-IQ system as the administrative user and navigate to the setup wizard using the following URL:

    https://<MGMT_IP>/ui/setup

    In this URL, note the following:

    • <MGMT_IP> refers to the management IP address of the BIG-IQ system.
  2. To advance to the Management Address step of the setup wizard process, select Next.
  3. To edit the management address, select Management Port IP address and Route.

    To modify the discovery address, choose what BIG-IQ should use for the discovery address:

    • To use the management port, select Use Management Address.
    • To use the internal self IP address, select Self IP Address and type the IP address and mask length.
  4. Select Next.

    Note: If you have not removed all the devices (DCDs, BIG-IP devices, and the HA peer) paired with this BIG-IQ system, the following error message displays:

    Before changing the default self-IP, you must first delete/un-manage all devices that you have established communication with.

    To avoid this error message, refer to the Prerequisites section of this article.

  5. If you remove all devices, the wizard moves to the Services step. To return to the Management Address step and check the newly updated IP address, select Back.

    If the new IP address is correct, you can exit the setup wizard. If the IP address is incorrect, repeat the Management Address and Services steps of the setup wizard.

  6. To exit the setup wizard and display the new discovery address or management address in the system properties page, change the URL to the following:

    https://<MGMT_IP>/ui/system/this-device/properties

    In this URL, note the following:

    • <MGMT_IP> refers to the management IP address of the BIG-IQ system. If the management address is changed, use the new IP address.

    Management Address and Discovery Address display the newly updated IP addresses.
