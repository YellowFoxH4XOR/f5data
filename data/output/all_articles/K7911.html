Known Issue

Description

When disabling the Agent Start/Stop option for SNMP traps configuration, it may cause the BIG-IP system to stop sending out pool member and node health monitor status traps.

Note: The Agent Start/Stop option, which is located under System > SNMP > Traps > Configuration, configures the system to send a trap whenever the SNMP agent starts running or stops running when this option is enabled. The default value to this option is enabled.

This issue occurs when the following condition is met:

  • Agent Start/Stop option was disabled

And, either of the following two conditions occurs:

  • The BIG-IP is rebooted.
  • Alertd is restarted.

When the issue occurs the BIG-IP will not send out any SNMP traps for pool member and node health monitor status even if the Agent Start/Stop option for SNMP traps is re-enabled.

Impact

The SNMP traps for health monitor status on pool member and node will not be sent to a configured trap destination.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system will not send out any SNMP traps for pool member and node health monitor status.

Workaround

To work around this issue, you can restart the alertd process after the Agent Start/Stop option has been re-enabled. To do so, enter following command from the command line:

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

bigstart restart alertd
