Description

When you are trying to create a DHCPv4 or DHCPv6 profile, you may see a warning message similar to this on the Configuration Utility.

Warning: Unlicensed Configuration

This page has unlicensed fields and allows configuration but does not take effect in the system.

Environment

  • You are trying to create a DHCPv4 or DHCPv6 profile.
  • The BIG-IP doesn't have the PEM license.

Cause

The warning message shows that you need a PEM license to enable Subscriber Discovery on the DHCPv4 or DHCPv6 profile.

Recommended Actions

You can safely ignore the warning message when you don't need to enable Subscriber Discovery on the DHCPv4 or DHCPv6 profile. You need a PEM license only if you need to Subscriber Discovery in the DHCPv4 or DHCPv6 profile
 

Additional Information

  • You can check the Configuration Utility to verify if you have the PEM license.
  • You can also run the following command to verify if your BIG-IP system has a license to enable Subscriber Discovery feature

    # ql subscriber_mgmt
    subscriber_mgmt:enabled

    The above result shows that the BIG-IP has the Subscriber Discovery feature flag that is required for using Subscriber Discovery.
