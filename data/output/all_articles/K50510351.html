Issue

Error Message

info updatecheck[PID]: PHONEHOME: Update Server unavailable

In this error message, note the following:

  • <PID> is the process ID for the updatecheck process.

For example:

info updatecheck[4825]: PHONEHOME: Update Server unavailable

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • Software update checking is enabled on the BIG-IP system.
  • The BIG-IP system is unable to connect to activate.f5.com through the management interface.

If the BIG-IP system is unable to connect to activate.f5.com for an extended period of time. Depending on the software versions running on the system, it logs a maximum of three error messages. After three days, the system stops logging the messages.

Note: To display the number of consecutive errors detected by update checking, run the tmsh list sys software update all-properties command.

Impact

Software update checks do not complete successfully.

Recommended Actions

When this message appears, confirm the following:

  • The BIG-IP system is able to connect to activate.f5.com.
  • DNS resolution is configured properly on the BIG-IP system.  For more information about configuring DNS on the BIG-IP system, refer to K13205: Configuring the BIG-IP system to resolve DNS hostnames (11.x and later).
