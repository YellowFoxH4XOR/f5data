Description

Applying a WAF (ASM) policy to a virtual server causes intermittent traffic interruption. The following error messages are observed in the logs:

  • ASM out of memory error: event code X264 Exceeded maximum memory assigned for XML/JSON processing
  • TMEVT_REQUEST: Request has an unknown HTTP selector: '/Common/test' (crc:12041975191127148385)
  • TMEVT_REQUEST: did not receive policy configuration after 600 seconds
  • Removing the WAF policy restores normal traffic flow. The issue is correlated with high XML/JSON processing demands on the ASM module.

Environment

  • Product: BIG-IP ASM (Application Security Manager)
  • Features: WAF (ASM) policy with XML/JSON processing enabled
  • Configuration: WAF policy attached to a virtual server
  • Observed during periods of high traffic or complex policy configurations

Cause

The issue is caused by insufficient memory allocated to the ASM XML/JSON processing engine. When the engine runs out of memory, it cannot load the policy configuration, resulting in the observed errors and traffic interruption.

Answer/Recommended Actions

1.Review the current XML/JSON memory usage and peak requirements using system logs.

2.Increase the XML/JSON engine memory allocation by adjusting the following ASM database variables as per K10803.

    • total_xml_memory
    • additional_xml_memory_in_mb These values are cumulative.

3.Restart the ASM module after making memory adjustments.

4.Perform these changes during a maintenance window to avoid service disruption.

5.Monitor system stability and adjust memory allocation further if required.

Additional Information

The variables total_xml_memory and additional_xml_memory_in_mb are cumulative. For example, setting total_xml_memory to 600 MB and additional_xml_memory_in_mb to 1024 MB results in a total of 1624 MB allocated for XML/JSON processing.
