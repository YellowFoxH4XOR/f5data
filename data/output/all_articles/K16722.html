Known Issue

FIPS exported key files are not synchronized to peers during a configuration synchronization (ConfigSync) operation.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP platforms support the FIPS hardware security module (HSM).
  • You have created FIPS exported keys in a high availability (HA) group of BIG-IP systems.
  • A ConfigSync operation is performed from a BIG-IP system where a FIPS exported key was created, to another BIG-IP system in the HA group.

When this issue occurs, FIPS .exp key files are created only in the /config/ssl/ssl.cavfips/ directory (of the unit on which the FIPS exported key is created or imported). During a ConfigSync operation, the .exp key files are not copied to HA peer devices.

Note: The BIG-IP system creates FIPS .exp key files when you convert a non-FIPS private key to FIPS.

A user configuration set (UCS) file that is created on an HA peer device, after a ConfigSync operation, does not contain the FIPS .exp key files; restoring a UCS file does not recover the FIPS keys.

Impact

If you return a BIG-IP system with FIPS hardware to F5 for a replacement system, using the Return Materials Authorization (RMA) process, recovery of FIPS keys may be difficult or impossible on the replacement system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you load a UCS file with missing FIPS exported keys, you observe error messages similar to the following example:

    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- 01070712:3: unable to import key (/Common/Cert1.key) in FIPS card Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can manually copy the FIPS .exp key files to and from each BIG-IP system in the HA group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To use the scp utility to copy all FIPS exported keys from the /config/ssl/ssl.cavfips/ directory of one HA peer to the others, use the following command syntax:

    scp /config/ssl/ssl.cavfips/*.exp root@<IP address>:/config/ssl/ssl.cavfips/

    For example, to copy the FIPS exported keys to a BIG-IP system with the IP address 10.0.0.1, type the following command:

    scp /config/ssl/ssl.cavfips/*.exp root@10.0.0.1:/config/ssl/ssl.cavfips/

  3. Repeat steps 1 and 2 for each BIG-IP system in the HA group, and ensure that all BIG-IP systems have copies of all FIPS exported key files.
