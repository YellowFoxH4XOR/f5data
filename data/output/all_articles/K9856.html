Topic

Network Time Protocol (NTP) is an Internet protocol that synchronizes computer clocks of to a known-accurate time reference. Simple Network Time Protocol (SNTP) is a simplified version of the NTP protocol, which lacks some internal algorithms that are not needed for all server types.

The BIG-IP system uses NTP to synchronize with network time servers and does not use SNTP. As a result, time synchronization fails with any time servers defined in the BIG-IP configuration that communicate using SNTP instead of NTP.

For information about verifying the NTP communications between NTP peers, refer to K10240: Verifying NTP peer server communications.
