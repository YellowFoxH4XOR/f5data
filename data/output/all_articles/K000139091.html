K000139091: iCall script to validate Virtual Server and node with same IP addresses

Type
Support Solution
Published
2024-07-30
Updated
2024-07-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.X.X, 15.0.0, 15.0.1, 15.0.X, 15.1.0, 15.1.1, 15.1.2, 15.1.3, 15.1.4, 15.1.5, 15.1.6, 15.1.7, 15.1.8, 15.1.9, 15.1.10, 15.1.X
Source
https://my.f5.com/manage/s/article/K000139091

Description

When a pool member has duplicate IP and port with an existing virtual server, health monitor will fail.

Environment

  • BIG-IP 15.x

Cause

By design

Recommended Actions

Use icall script to validate as workaround

Sample icall script output from tmsh list sys icall handler periodic Check_NodeIP

sys icall handler periodic Check_NodeIP {
    first-occurrence 2023-03-29:00:00:00
    interval 60
    script Check_NodeIP
    status inactive
}

Sample icall script output from tmsh list sys icall script Check_NodeIP

sys icall script Check_NodeIP {
    app-service none
    definition {
        set nodelist ""
        set nodecounter 0
                #tmsh::log "iCall: Starting to enumerate existing node objects..."
                foreach partition [tmsh::get_config auth partition] {
                    set partition "/[tmsh::get_name $partition]"
                            #tmsh::log "iCall: Processing Partition: $partition"
                            tmsh::cd $partition

                            set nodes [tmsh::get_config /ltm node]
                            foreach node $nodes {
                                 set nodename [tmsh::get_name $node]
                                 set nodeaddr [tmsh::get_field_value $node "address"]
                                 #tmsh::log "Processing Node : $nodename,$nodeaddr]"

                                 set vaddrs [tmsh::get_config /ltm virtual-address]
                                 foreach vaddr $vaddrs {
                                 set vs_addr [tmsh::get_field_value $vaddr "address"]
                                 #tmsh::log "Processing VS : $partition/[tmsh::get_name $vaddr], $vs_addr"
                                 if { not ($nodeaddr contains $vs_addr) } then {
                                    #tmsh::log "node address:$nodeaddr is not used: virtual address: $vs_addr"
                                       } else {
                                        tmsh::log "node address:$nodeaddr is used: virtual address: $vs_addr"
                                        }
                                  }
                  incr nodecounter
                         }
                                 #tmsh::log "Finished Partition: $partition"
                       }
    }
    description none
    events none
}
