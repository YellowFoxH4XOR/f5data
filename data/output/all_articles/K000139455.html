Description

You observe missing bigip monitor, when trying use it for GSLB pool configuration.

Environment

  • BIG-IP DNS
  • DNS pool

Cause

None, this is expected behavior.

Recommended Actions

Although BIG-IP allows to configure bigip monitor for pool using CLI command, such configuration should not be used. 
F5 Support don't recommend using such in DNS setup.
The bigip (and bigip_link) monitor types are special in that instead of actually running a monitor, they just use iquery to request the object's status from the remote mcpd.
