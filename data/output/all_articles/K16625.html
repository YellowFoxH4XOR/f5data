Known Issue

The BIG-IP system may send unexpected Open Shortest Path First (OSPF) link state update retransmissions.

This issue occurs when all of the following conditions are met:

  • Your system is licensed with the BIG-IP Advanced Routing Module (BIG-IP ARM).
  • The BIG-IP system is configured to use OSPF.
  • The BIG-IP system sends an OSPF link-state advertisement (LSA) to three or more neighbor devices.

When a single LSA update is sent, and three LSA acknowledgements are received, ospf_ls_upd_timer may incorrectly time out within one second instead of waiting the default 5 seconds. As a result, the BIG-IP system prematurely sends a link state update retransmission.

Impact

Frequent link state update retransmissions can impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system sends unexpected OSPF link state update retransmissions.
