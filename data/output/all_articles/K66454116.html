Known Issue

Under rare circumstances, the BIG-IP ASM bd process may unexpectedly produce a core file.

This issue occurs when the following conditions are met:

  • Your BIG-IP ASM system is configured with a security policy.
  • The virtual server that is configured with the security policy is also configured with a DoSL7 profile.
  • The BIG-IP ASM system processes traffic.

Impact

Traffic processing is interrupted while the bd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP ASM system temporarily fails to pass traffic.
  • Your BIG-IP ASM bd process restarts and creates a core file in the /var/core/ directory.
  • A log message similar to the following is logged to /var/log/ts/bd.log file at the time of the event:

    IO_PLUGIN|ERR   |<MMM DD HH:MM:SS.S>|<pid>|plugin_common.c:0085|plugin context doesn't match the argument which was originally set on it
