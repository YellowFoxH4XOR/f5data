Topic

In very rare instances, secure shell (SSH) keys can become corrupt and the provided configuration scripts do not resolve the issue. In these cases, the SSH keys need to be synchronized manually.

To synchronize OpenSSH keys, perform the following steps:

Note: In the following procedure, the first BIG-IP system in the pair is identified as BIG-IP1, and the second BIG-IP system in the pair is identified as BIG-IP2.

  1. On BIG-IP1, type the following command:

    ssh-keygen -t dsa

  2. When prompted for a passphrase, press Enter without specifying a passphrase.

    Important: Do not enter a passphrase, because it will cause SSH to prompt for the passphrase every time it runs.This will break configuration synchronization, as it relies on promptless, host-based authentication.

    This will produce the following two files, a private key and a public key which has a .pub file extension:

    /root/.ssh/id_dsa
    /root/.ssh/id_dsa.pub

  3. Copy the contents of the id_dsa.pub file into the /root/.ssh/authorized_keys file on BIG-IP2.

    For example, to copy the file using SSH, you would type the following command:

    cat /root/.ssh/id_dsa.pub |ssh root@bigip2 "cat >> /root/.ssh/authorized_keys"
  4. Log in to BIG-IP2.
  5. Repeat steps 1 through 3 on BIG-IP2.
  6. Copy the contents of the public key file on BIG-IP2 into the authorized_keys file on BIG-IP1, by typing the following command:

    cat /root/.ssh/id_dsa.pub |ssh root@bigip1 "cat >> /root/.ssh/authorized_keys"

  7. For the changes to take effect, you must restart sshd on each BIG-IP system. To restart sshd, type the following command:

    kill -HUP pidof sshd
