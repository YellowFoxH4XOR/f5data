Description

The BIG-IPs are unable to sync configuration after changing their ConfigSync IPs.

Environment

  • HA setup.
  • Changed the HA Self-IPs following the procedures of the article K14123529.
  • The BIG-IPs remain in a Disconnected status and cannot sync the configuration.
  • The tmsh show cm device shows that the HA peer still has the old ConfigSync IP configured, for instance:
---------------------------------------------------
CentMgmt::Device: BIG-IP-A
---------------------------------------------------
Hostname                          BIG-IP-A
Mgmt IP                           10.1.1.245
Alternate Mgmt IP                 None
Configsync IP                     10.1.20.241


------------------------------------------------------------
CentMgmt::Device: BIG-IP-B
------------------------------------------------------------
Hostname                          BIG-IP-B
Mgmt IP                           10.1.1.246
Alternate Mgmt IP                 None
Configsync IP                     192.168.4.2 <<<<< old IP

Cause

After changing the HA Self-IPs the IP of the HA peer is not updated locally.

Recommended Actions

To solve the problem, the Device Trust must be rebuilt:

K42161405: Rebuilding device trust using the Configuration utility (11.x - 15.x)
