K29241568: Allowed HTTPS URL blocked

Type
Support Solution
Published
2020-02-26
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.0, 13.0.1, 13.0.0, 12.1.3, 12.1.2, 13.0.X, 12.1.0, 12.1.1
Source
https://my.f5.com/manage/s/article/K29241568

Description

Allowed HTTPS URL blocked with violation in the Event logs: Illegal URL
 

Environment

  • Request blocked with Violation: Illegal URL
  • ASM Policy exported in XML from working environment
     

Cause

Allowed URL is blocked due to Bug ID 663396.
 

Recommended Actions

Make a spurious change to any policy and click 'Apply Policy'.

The following example may be used:
  1. Browse to Security  >  Application Security  >  URLs  >  Allowed URLs  >  Allowed HTTP URLs
  2. Click on the HTTPS / URL to go to its properties
  3. Switch to Advanced settings
  4. Click on the tab Methods Enforcement
  5. From the list, select PUT and DELETE and put them in the Override policy allowed methods
  6. Save and Apply policy
  7. Return to the same setting in step 4 and remove the two methods
  8. Save and Apply policy
