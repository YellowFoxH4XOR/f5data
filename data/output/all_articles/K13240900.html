Description

As of June 2016, F5 released the F5 iWorkflow 2.0 product as the next release in the BIG-IQ Cloud and Orchestration product line. The product has been renamed F5 iWorkflow to better reflect the product offering. F5 iWorkflow is a programmable and extensible platform, leveraging programmatic control and templating technologies such as iControl and iApps. Leveraging out of the box workflows or building new custom workflows, users can easily deploy application services. F5 encourages customers who are running BIG-IQ Cloud and Orchestration 1.0 to migrate to F5 iWorkflow 2.0.

F5 iWorkflow

F5 iWorkflow imports iApps from network-connected F5 devices, and provides centralized management of these templates. These iApps are then provisioned to the Tenant catalogues, where they are associated with users, groups, and roles, as determined by the Administrator. You can administer F5 iWorkflow using either the Configuration utility or a comprehensive set of iControl REST Application Programming Interfaces (API).

F5 iWorkflow integrates with Cisco APIC, VMWare NSX, BIG-IP hardware, or Virtual Edition (VE) platforms. F5 iWorkflow includes a REST-based API and Software Development Kit (SDK) that makes integration with third-party management and orchestration tools a core component of the product.

Customers migrating to F5 iWorkflow must perform a clean software installation, as there are no available upgrade options. The installation requires a full rediscovery of all remote devices. Upgrades from F5 iWorkflow will be supported in future releases. BIG-IQ Cloud and Orchestration 1.0 customers must obtain a new F5 iWorkflow 2.0 license. For complete F5 iWorkflow installation instructions, refer to the F5 iWorkflow release notes.

Note: For information about how to locate the release notes, refer to K12453464: Finding product documentation on AskF5.

Recommendations

  • Customers who leverage other cloud-related functionality in the BIG-IQ 4.5.x release should migrate to F5 iWorkflow 2.0 at this time.
  • Customers who run BIG-IQ Cloud and Orchestration 1.0 are encouraged to migrate to F5 iWorkflow 2.0.
