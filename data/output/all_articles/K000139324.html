Description

 

F5 VPN browser launcher support for Ubuntu 22.04 on i3 window manager

 

Environment

 

  • BIG-IP APM
  • Ubuntu Desktop 22.04
  • Linux_f5vpn.x86_64.deb package installed
  • i3 window manager

 

 Recommended Actions

 

In order to launch Linux Edge Client on Ubuntu desktop 22.04 with i3 window manager follow this steps:

 

On i3 environment, press Win+D in order to open the top menu.

On the top menu, find out the app called "firefox".

Once opened, launch the F5 VPN service by browser and it should works.

 

Additional Information

 

Chrome browser is not support at the time of this writing.
