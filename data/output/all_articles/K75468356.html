Description
In some cases OpenID endpoints may not have a mutual cipher available for TLS handshakes that will prevent functionality.

Environment

  • BIG-IP APM
  • OAuth

Cause

BIG-IP restjavad service only advertises a select number of ciphers during the TLS handshake process in the CLIENT HELLO.

For more information, refer to K00571304: BIG-IP APM deployments using OAuth/OIDC with Microsoft Azure AD may fail to authenticate.

Recommended Actions

  1. Adjust the OAuth provider to allow for TLS handshake with one of the allowed ciphers
