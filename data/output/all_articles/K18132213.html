Description

PSU Manufacturer Name String contains non ASCII characters

Environment

  • BIG-IP 5000/7000 series
  • This can be viewed with the following command:
    tmsh show sys hardware

    Sample Output:

      Name        psu2
      Type        psu
      Model       73-610-125
      Parameters  --             --
                  Location       2
                  Manufacturer   ARTESYN¦¦
                  Revision       A5
                  Serial number  XXXXXXXX

Cause

The Manufacturer Name of the PSU contains erroneous characters, which caused REST query to fail. 

Recommended Actions

  1. Verify the output of "tmsh show sys hardware" if it contains non ASCII characters
  2. To address a potential hardware issue, generate a QKView file and contact F5 Support.

Additional Information

  1. In the qkview output of the show /sys hardware PSU Manufacturer value is blank
