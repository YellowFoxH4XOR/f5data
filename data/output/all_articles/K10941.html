K10941: Network Access client IP addresses are not logged to RADIUS accounting

Topic

If you enable RADIUS accounting on the Device Management : Maintenance : Accounting page, FirePass sends an Accounting Start packet when a user logs on to the FirePass controller and an Accounting Stop packet when a user logs off from the FirePass controller.

For example:

rad_recv: Accounting-Request packet from host 172.16.100.10:32769, id=65, length=85
        User-Name = "jsmith"
        Acct-Session-Id = "1ef1522366b6b194c7227c544ab77ec2"
        Acct-Status-Type = Start
        Service-Type = Authenticate-Only
        NAS-IP-Address = 172.16.100.10
        NAS-Port = 0

rad_recv: Accounting-Request packet from host 172.16.100.10:32769, id=223, length=91
        User-Name = "jsmith"
        Acct-Session-Id = "1ef1522366b6b194c7227c544ab77ec2"
        Acct-Status-Type = Stop
        Service-Type = Authenticate-Only
        Acct-Session-Time = 244
        NAS-IP-Address = 172.16.100.10
        NAS-Port = 0

However, when a user opens or terminates a Network Access connection, no RADIUS accounting packets are sent. Therefore, it is not possible to track Network Access client IP addresses using the RADIUS accounting feature.

F5 Networks is tracking a request for enhancement to enable RADIUS accounting for the Network Access feature as CR58439.
