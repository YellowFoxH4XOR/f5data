K32548743: Locating the serial number or registration key of a managed BIG-IP device from the BIG-IQ system

Topic

You should consider using these procedures under the following conditions:

  • You want to retrieve the serial number of a managed BIG-IP device (hardware platform or VIPRION) from your BIG-IQ system.
  • You want to retrieve the registration key of a managed BIG-IP device from your BIG-IQ system.

Description

The BIG-IQ system acquires the serial number of a managed BIG-IP device (hardware platform or VIPRION) from the managed device when you export the managed device inventory using the BIG-IQ system interface.

Similarly, the registration key of a managed BIG-IP device is acquired from the managed device when you request the managed devices inventory export.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to the BIG-IQ system interface.
  • You have a utility to view an exported CSV file containing the inventory from the BIG-IQ system interface.

Procedures

  • Determining the serial number or registration key of a managed BIG-IP device
  • Determining the serial number of a blade in a VIPRION managed by BIG-IQ system

Determining the serial number or registration key of a managed BIG-IP device

To determine the serial number or registration key of a managed BIG-IP device from the BIG-IQ system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system interface.
  2. Go to Devices > BIG-IP Devices.
  3. Select Export Inventory. 

    The BIG-IQ system generates a CSV file, which you can download using your browser.

  4. Download the CSV file and note the location.
  5. Open the downloaded CSV file using a utility such as a text editor.
  6. Locate the following columns for your managed BIG-IP device to determine the appropriate option:
    • For the serial number of the managed BIG-IP hardware platform or VIPRION, refer to Chassis Serial Number.
    • For the registration key, refer to License_registrationKey.
    • For the serial number of a blade in a managed VIPRION, refer to ChassisSlotList_X_serialNumber.
      X represents the slot number of the blade.

      Note: Alternatively, you can also perform the next procedure to locate the serial number of a blade in a managed VIPRION.

Determining the serial number of a blade in a VIPRION managed by BIG-IQ system

To determine the serial number of a blade in a managed VIPRION, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ system interface.
  2. Go to Devices > BIG-IP Devices.
  3. Select the Device Name of the managed VIPRION.

    The BIG-IQ system interface displays the properties of the managed VIPRION.

  4. Locate the serial number of the blades in the managed VIPRION by referring to Serial Numbers.
