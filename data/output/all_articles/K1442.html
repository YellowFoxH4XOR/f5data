Issue

The following messages indicate that the SNAT, or SNAT automap, has run out of source ports on which to send outbound requests:

Oct 25 22:07:55 dnsbigip1 kernel: No ports available on address 191c0dce!
Oct 25 22:07:55 dnsbigip1 kernel: No ports available on address 191c0dce!

To resolve this issue, perform the following procedure:

  1. Enable SNAT automap.
  2. Add additional floating IP addresses.

Note: For specific instructions about how to enable SNAT automap and add floating IP addresses, Refer to the BIG-IP Reference Guide.

Note: Refer to the following Solutions for additional information: K2053: NAT and SNAT source port usage.
