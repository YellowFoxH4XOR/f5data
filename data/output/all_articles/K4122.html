Issue

The BIG-IP system continues to include Secure Sockets Layer (SSL) NULL cipher support, but the default behavior has changed.

Old Behavior

In versions prior to BIG-IP 10.0.0, NULL ciphers are included in the NATIVE and COMPAT SSL stacks.

New Behavior

Beginning in BIG-IP 10.0.0, NULL ciphers are removed from the NATIVE and COMPAT SSL stacks, and disabled unless explicitly included in the SSL profile. For example, adding the following string to the cipher list for an SSL profile includes the NULL-MD5 cipher in the profile:

DEFAULT:NULL-MD5

F5 Product Development tracked this change as ID 219953.

Impact

In order to utilize NULL ciphers, the desired ciphers will need to be specifically configured for an SSL profile.

Recommended Actions

None. For security reasons, F5 recommends that you do not enable NULL ciphers for SSL profiles.
