Description
Unable to downgrade iRuleLX

Environment

  • After upgrading an iRuleLX application through the Guided Configuration, you wish to downgrade it again

Cause
This is not something supported by the iRuleLX framework.

Recommended Actions

run clear-rest-storage
This will stop restnoded/restjavad and remove the storage/index files under /var/config/rest.  Then it will restart restnoded/restjavad.
Note: this may clear SSLO configuration as well.  You will also need to reconfigure the iRuleLX application via the Guided Configuration.
