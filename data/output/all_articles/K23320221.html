Known Issue

ConfigSync may fail when the BIG-IP system configuration includes both global and local Bandwidth Control (BWC) policies.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is a member of a high-availability (HA) configuration.
  • Your BIG-IP system configuration includes multiple BWC policies.
  • One or more BWC policies are global or belong to a device group that allows ConfigSync operations with other cluster members.
  • One or more BWC policies are local or do not belong to a device group that allows ConfigSync operations with other cluster members. For example, if the BWC policy resides in a folder that has no associated device group.

Impact

The affected BIG-IP system cannot perform ConfigSync operations with any of the other cluster members.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The local BIG-IP system is unable to perform ConfigSync operations with other cluster members.
  • Error messages similar to the following are logged to the /var/log/ltm file:

    err mcpd[5678]: 01070734:3: Configuration error: invalid: dist id:196609 pol name: /partition1/global_policy  old elem: /partition2/local_policy
    err mcpd[5678]: 01071488:3: Remote transaction for device group /Common/device_group1 to commit id 3 6262990150803574865 /Common/example.net 0 failed with error 01070734:3: Configuration error: invalid: dist id:196609 pol name: /partition1/global_policy  old elem: /partition2/local_policy.

Workaround

To work around this issue, you can ensure that all BWC policies are global or belong to a device group.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
