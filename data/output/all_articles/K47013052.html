Known Issue

The Traffic Management Microkernel (TMM) process may produce a core file when Behavioral Analysis is enabled.

This issue occurs when all of the following conditions are met:

  • The BIG-IP System has AFM provisioned.
  • An AFM profile is associated with a virtual server.
  • The AFM profile has the Behavioral Analysis feature enabled.
  • The virtual server is configured for state mirroring.

Impact

The BIG-IP system may temporarily fail to process traffic while TMM restarts. If configured as a high-availability pair, the device may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/tmm file, you may observe a SIGFPE panic message similar to the following example:

    panic: ./local/net/packet.h:505: Assertion "l3hdr set" failed.

  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
