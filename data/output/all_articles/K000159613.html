K000159613: F5OS-C reports inteface down and CPU events

Type
Support Solution
Published
2026-01-19
Updated
2026-02-12
Applies to
  • F5OS
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000159613

Description

Sometimes, the VELOS and rSeries devices reports interface status down and CPU events. 

/qkview/subpackages/partition_alert_service/qkview/filesystem/var/F5/partition/events$ grep "Interface down" event-log.log
XXXXX interface-3/1.0 down EVENT NA "Interface down" "YYYY-MM-DD HH:MM:SS.XXXXX UTC"

also, these symptoms are seen.

/qkview/subpackages/partition3_alert_service/qkview/filesystem/var/F5/partition/events$ more event-log.log | grep "Deasserted: CPU"
XXXXX blade-3 hardware-device-fault EVENT NA "Deasserted: CPU fatal error" "YYYY-MM-DD HH:MM:SS.XXXXX UTC"
XXXXX blade-3 hardware-device-fault EVENT NA "Deasserted: CPU machine check error" "YYYY-MM-DD HH:MM:SS.XXXXX UTC"
XXXXX blade-3 hardware-device-fault EVENT NA "Deasserted: CPU internal error" "YYYY-MM-DD HH:MM:SS.XXXXX UTC"
XXXXX blade-3 hardware-device-fault EVENT NA "Deasserted: CPU FIVR fault" "YYYY-MM-DD HH:MM:SS.XXXXX UTC"
XXXXX blade-3 hardware-device-fault EVENT NA "Deasserted: CPU thermal trip fault" "YYYY-MM-DD HH:MM:SS.XXXXX UTC"

 

Environment

  • The VELOS and rSeries platforms

 

Cause

Undetermined

Recommended Actions

When the administrator observes the log similar to above, it  is recommended to take Diagnotics log(diag) and Platform Event Log(pel), and open the support case with F5 Global Service.

  • Generate a Qkview file on the system controller and upload to iHealth. Refer to K02521182: Generating diagnostic data for the VELOS system using the qkview utility.
  • To get the platform event logs, refer to K13428255: Get VELOS and rSeries hardware diagnostics when CLI access is not available
