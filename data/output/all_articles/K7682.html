Known Issue

This is the result of a known issue. When you log in to the FirePass Administrative Console and disconnect a user?s session on the Reports : Session page, FirePass logs the session status as Logged out from server on the Reports : Sessions page under the Complete History tab. The same log message is generated when a user logs out from the FirePass controller.

F5 Product Development tracked this issue as CR76818 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix 552-7 has been issued for FirePass version 5.5.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
