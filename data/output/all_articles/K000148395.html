Description

While reviewing the logs using Configuration Utility, it shows only current log (1 day) but not from old log files.

For example, under System ›› Logs : System, it is collecting from /var/log/messages.

Environment

  • BIG-IP
  • Configuration utility

Cause

This is by design.

Recommended Actions

To review the old logs, please use tmsh or bash following by:

  • K16197: Reviewing BIG-IP log files

None.
