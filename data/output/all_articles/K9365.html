Known Issue

This is the result of a known issue. When you configure a hint zone on the BIG-IP GTM, the zrd process attempts to query the zone when a user clicks the ZoneRunner utility in the BIG-IP GTM Configuration utility. When this issue occurs, error messages that appear similar to the following example are logged in the /var/log/gtm file:

gtm zrd[18391]: 01150b21:3: RCODE returned from query: 'NOTAUTH'
gtm zrd[18391]: 0115010c:3: Unable to query zone '.'

These error messages are benign.

F5 Product Development tracked this issue as CR83505 and it was fixed in BIG-IP GTM 10.1.0 and 9.4.8. For information about upgrading, refer to the BIG-IP GTM release notes.
