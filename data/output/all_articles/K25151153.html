Description

Security nat source-translation periodic-refresh-log default value 0, sends Port Block Periodic Log logs which it should not as per design.

You might see messages similar to the following logged in /var/log/ltm or sent to remote logging destinations:

info tmm[6215]: 23003168 "Port Block Periodic Log","10.10.10.10","0","","10.10.10.10","0","1024","1031","16164968240","","unknown".

Environment

  • Port Block Allocation (PBA)

Cause

Bug ID 987345: Disabling periodic-refresh-log has no effect

Recommended Actions

There is no workaround at the time of this article's publication.

Please contact F5 support for an ENG HF.
