Description
This error indicates that a BIG-IP DNS (formerly GTM) monitor instance cannot be assigned by gtmd to a server object prober. It appears in /var/log/gtm

Environment

  • DNS / GTM sync-group

Cause
A monitor could not be assigned to any BIG-IP big3d instances

Recommended Actions
Ensure that there are available BIG-IP server objects and that all server objects have the necessary configuration to monitor all hosts. For example, server objects with only IPv4 self IP addresses will not be able to monitor IPv6 generic hosts and must have an IPv6 address to send the monitor.
