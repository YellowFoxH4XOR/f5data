Description

Apple Gatekeeper Antivirus Last Scan Time and DB Age are not supported in recent EPSEC versions ( epsec-1.0.0-928.0 and epsec-1.0.0-936.0)

Environment

  • BIG-IP APM
  • EPSEC

Cause

This is a product limitation as the Gatekeeper AV itself currently does not offer any way to add support for Last Scan Time and Definition State.

Recommended Actions

  • Gatekeeper AV only checks real-time protection state. If your security requirement involves having to check for the Last scan time and DB Age of the AV product installed on the remote endpoint clients, consider using an alternate AV solution.
