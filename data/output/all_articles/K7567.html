Known Issue

This is the result of a known issue. When a BIG-IP LTM system with connection mirroring enabled experiences failed connections to a FastL4 virtual server, the BIG-IP LTM can experience an xfrag memory leak.

You can display the xfrag memory allocation by typing the following command:

b memory show

F5 Product Development tracked this issue as CR80120, and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.
