Description
How to disable attack signature for the whole policy in version 15.1.x

Environment

  • ASM 15.1.x

Cause
Not applicable

Recommended Actions

To disable attack signature for the whole policy in version 15.1.x,  you will need to follow the below:
Please note for this example, the policy is "test".
  1. On the configuration Utility, go to Security ›› Application Security : Security Policies : Policies List ›› "test"
  2. Click on the 'Attack Signatures' tab.
  3. Search for the attack signature (use the filter symbol)
  4. Check checkbox of the attack signature
  5. Click the 'Disable' button.
