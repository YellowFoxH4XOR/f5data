K50285521: The BIG-IQ system may cause an out-of-sync condition between the managed BIG-IP HA pair

Type
Knowledge
Published
2019-07-10
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K50285521

Issue

Description

The BIG-IQ system may cause the BIG-IP systems in a high availability (HA) pair to become chronically out of synchronization after device discovery.

Environment

  • BIG-IQ 6.0.0 or later.
  • BIG-IP HA pair running BIG-IP 13.1.0 to 13.1.1 or BIG-IP 14.0.0 to 14.1.0.
  • Statistics collection is enabled for both devices in the HA pair.

Cause

When statistics collection is enabled on both BIG-IP devices in an HA pair, the BIG-IQ system attempts to install the statistic collection configuration on both units. One BIG-IP device will then synchronize the configuration to its peer, but its peer should have a different statistics configuration. As a result, the BIG-IQ system will revert it back to the correct settings. When this behavior occurs, the commit time updates so the BIG-IP device syncs its configuration to the original BIG-IP device. This issue is a symptom of Bug 753485.

The BIG-IQ system sets a unique statistics collection configuration (analytics global-settings) on each BIG-IP device. The following example illustrates how the pair of HA BIG-IP systems can be in continuous synchronization to each other. 

For example:

  1. BIG-IP A has statistics configuration A.
  2. BIG-IP A syncs its configuration A to BIG-IP B.
  3. BIG-IP B already has statistics configuration B, but is now updated to A.
  4. BIG-IQ reverts BIG-IP B back to the correct configuration B.
  5. BIG-IP B now syncs its configuration B to BIG-IP A.
  6. BIG-IP A now has configuration B.
  7. BIG-IQ reverts BIG-IP A back to the correct configuration A.
  8. BIG-IP A again syncs its configuration A to BIG-IP B.

The two sets of statistic collection configurations get passed in circles, back and forth.

If the automatic sync option is enabled, the pair shows up in sync / not in sync very rapidly and repeatedly.  If performing a manual sync, the user receives a There is a possible change conflict error and they cannot get the devices back into sync.

Recommended Actions

  1. On the BIG-IQ, disable statistics gathering for both BIG-IP systems.
    1. Go to Devices > BIG-IP DEVICES.
    2. In the device inventory list, select the Enabled link for an affected device in the HA pair.
    3. Ensure the BIG-IP HA pair belong to the same cluster, which is reported near the bottom of the page, and clear the Enabled box next to Collect Statistics Data. Because the BIG-IP systems are part of a cluster on the BIG-IQ system, statistics collection is automatically disabled for both.
  2. Perform a ConfigSync on the BIG-IP systems. For more information, refer to K13920: Performing a ConfigSync using the Configuration utility.
  3. Confirm that the BIG-IP systems are in sync. It may take a few cycles to settle down.
  4. Ensure the BIG-IP HA pair belong to the same cluster on the BIG-IQ system, then enable statistics gathering on one of the BIG-IP devices by going back to the Statistics Collection page and selecting the Enabled box next to Collect Statistics Data.
    Because the BIG-IP systems are part of a cluster on the BIG-IQ system, statistics collection is automatically enabled for both and the statistics configuration is synced down to its peer once.
  5. Check statistics for each device by going to the Monitoring tab and selecting a dashboard item.
Statistics are gathered for both BIG-IP systems, even though the statistics configuration is no longer unique on each BIG-IP device. You may see that the Stats Last Collection Date is stuck at Dec 31, 1969 or Jan 1, 1970 (depending on the time zone configured) for one of the peers, but statistics are gathered from both BIG-IP systems. This incorrect date error message can safely be ignored as long as the other peer has the current date and time.

Additional Information

The synchronization issue will occur whether you configure cluster properties on the BIG-IQ system for the BIG-IP HA pair or not.
