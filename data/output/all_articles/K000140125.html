Description

When following F5's docummentation on how to license a BIG-IP NEXT Central Manager in a Disconnected Mode, you have been able to generate the ACK file. But, when trying to upload it to the Central Manager, you get this error:


request body has an error: failed to decode request body: path fileList: unsupported content type "application/x-zip-compressed".


Environment

  • Disconnected Mode
  • BIG-IP NEXT Central Manager
  • No Internet access

Cause

Bug ID 1585329

Recommended Actions

The ACK file can be uploaded with Postman via an API call.


  1.  Use form-data as the body and leave postman to take care of the content-type.
  2. Select the form-data as the body and add a key named 'fileList'.
  3. Select 'File' from the dropdown list and select the zip file as the Value.

 You only needs to take care of the Authorization.
