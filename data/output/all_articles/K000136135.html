Description

When you attempt to remove a BIG-IP Next instance from the inventory in Central Manager, you get an error message and the device cannot be removed from inventory.

Environment

  • BIG-IP Next Central Manager
  • One or more BIG-IP Next instances are managed by Central Manager

Cause

If the BIG-IP Next instance has been powered down or removed in your VM environment, then BIG-IP Next Central Manager is unable to reach the instance, and if it cannot communicate with the BIG-IP Next instance, it cannot be removed from inventory.
 

Recommended Actions

Central Manager cannot remove BIG-IP Next instances from inventory if it cannot communicate with them.  There is no workaround.  You will be able to remove instances that are powered down or deleted in a future release.
