Description

The SIP Session Profile can be configured with Passthru Mode

Passhtru Mode (from BIG-IP Online Help )

Enables or disables passthru mode. When enabled, if the first message received in a flow is not a well formed SIP message (either non-SIP or badly formed SIP), the profile will enter passthru mode. The flow will stay in passthru mode for its lifetime. In passthru mode, all messages received are passed on without modification or validation.

Passhtru Mode is disabled (unchecked) by default in the SIP Session Profile 

Environment

BIG-IP processing SIP traffic with "not well formed" SIP messages.
SIP devices that may use custom implementations in its SIP messages.

Cause

BIG-IP processing SIP traffic with "not well formed" SIP messages

Recommended Actions

SIP Session Profile Passthru Mode is disabled by default. Only enable this configuration if you are looking to support "not well formed" SIP messages or potentially, SIP devices that may use custom implementations in its SIP messages.  
SIP Session Profile configuration is located at BIG-IP Configuration Utility, Local Traffic  ››  Profiles : Message Routing : SIP   ››  Session Profiles, then, select or create a SIP Session Profile
