K24974508: Configuring Advanced WAF DataSafe Cookie Secure Attribute

Type
Support Solution
Published
2021-05-06
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.0
Source
https://my.f5.com/manage/s/article/K24974508

Description

Configure Secure Cookie Attribute of Advanced WAF DataSafe Profile Cookies. 

Environment

  • Advanced WAF is licensed
  • Fraud Protection Service is provisioned

Cause

None

Recommended Actions

  1. Secure attribute can be configured in the Web GUI for FPS / Datasafe cookies
  2. Under Security  ››  Data Protection : BIG-IP DataSafe
  3. Create a New Profile or Configure an existing Profile » Advanced » Cookies »  Secure Attribute - enabled by default - Sets the status of the Secure Attribute on all DataSafe cookies. See online help for more information.

Additional Information
