K000150499: iRule creation through terminal

2025-03-27

Applies to

  • BIG-IP LTM: 15.1.0
Source

Description

iRule creation through CLI is required.

 

Environment

BIG-IP LTM VE

TMSH ACCESS

 

Cause

GUI inaccessible.

 

Recommended Actions

Process to create an iRule through tmsh terminal access:

 

1- Open a CLI session to the Big-IP

2- Run command:

load sys config merge from-terminal

3- Write or paste the iRule code:

ltm rule Example {

when HTTP_REQUEST { set uri [HTTP::uri] if { $uri ends_with ".gif" } { pool my_pool } elseif { $uri ends_with ".jpg" } { pool your_pool } }

}

4- Press "Enter"

5- Press Ctrl+d to submit

6- Save configuration with command:

save sys config

 

7- If required, add the iRule to the VS:

tmsh modify ltm virtual <virtual server name> rules { Example }
