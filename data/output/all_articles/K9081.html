K9081: The Windows antivirus checker process scan may cause Firefox 3 to terminate on Windows Vista clients

Known Issue

This is the result of a known issue. If you configure a pre-logon sequence with the Windows antivirus checker, and a Windows Vista client connects to FirePass using Firefox 3, Windows Vista may terminate Firefox 3.

This issue occurs when all of the following three conditions are met:

  • The CPU on the Windows Vista system supports hardware-enforced Data Execution Protection (DEP).
  • DEP is enabled on the Windows Vista system.

    Note: By default, DEP is enabled in Windows Vista.
  • The Perform processes scan menu in the Windows Antivirus checker is set to Ask User or Enabled, and the process scan attempts to run on the client system.

DEP is a security feature that is intended to prevent malicious code from executing on client systems. For more information about DEP and Windows Vista, refer to:

http://windowshelp.microsoft.com/Windows/en-US/help/186de3d0-01af-4d4c-981d-674637d2f4bf1033.mspx

F5 Networks Product Development is tracking this issue as CR102774.

Workaround

You can work around this issue by setting the Perform processes scan menu to Disabled in the Windows Antivirus checker. If you do not want to disable this setting for all clients, configure a separate sub-sequence in the pre-logon sequence for Windows Vista clients which connect with Firefox 3.0. In the separate sub-sequence, add the Windows Antivirus checker action and set the Perform processes scan menu to Disabled.

Note: For information about detecting Windows Vista clients in a pre-logon sequence, refer to K7177: Detecting Microsoft Windows Vista clients in a pre-logon sequence. For information about configuring a pre-logon action based on the browser type, refer to K9074: Configuring a pre-logon sequence action based on the client browser type.

Alternatively, users can use one of the following two workarounds:

  • Connect to the FirePass controller using an alternate browser, such as Internet Explorer.

    Note: This issue also occurs in Internet Explorer 7 (IE7) if the Enable Memory Protection to Help Mitigate Online Attacks setting is enabled in IE7. For more information, refer to K9082: The Windows antivirus checker process scan may cause Internet Explorer 7 to terminate on Windows Vista clients. By default, the Enable Memory Protection to Help Mitigate Online Attacks setting is disabled in IE7.

  • Disable DEP in Windows Vista. For information about disabling DEP, refer to your Microsoft Windows Vista documentation.

    Important: This workaround is provided for informational purposes only. F5 Networks does not recommend disabling DEP, since disabling DEP may reduce the security of the Windows Vista system.
