Known Issue

This is the result of a known issue. After a disk drive replacement on an ARX 2000 or 4000 system, the system cannot find the new drive and a RAID rebuild will fail. The Disk Details section of the show chassis diskuse command will display the disk as Not Present, similar to the following example:

Disk Details:
Disk     Size        State             Transfer Rate Model
-------- ----------- ----------------- ------------- -----------------
Bay 1    136.73G     Online            3.0Gb/sec     ST9146803SS
Bay 2                Not Present       Unknown

Additionally, the RAID rebuild will fail with an error message that appears similar to the following example:

:1-1-ACM-2573:ROOTD-0-ERR-RAID_REBUILD_DRIVE_NOT_FAILED:: The drive has to be failed to start rebuild.

F5 Product Development tracked this issue as ID 342258 and it was fixed in ARX version 6.0.0. For information about upgrading, refer to the ARX release notes.

Workaround

You can work around this issue and allow the ARX system to recognize the new disk by reloading the ARX system. To do so, type the following command:

reload

After restart, the system will recognize the new disk and the RAID rebuild may be performed.
