Description

You may have recently upgraded your BIG-IP or updated your EPSEC file to 1.0.0-1505.0. When you try to connect to the VPN via Edge Client from a Windows client. After establishing the connection, you receive the following message:

F5 Networks Client Policy Server has stopped working. A problem prevented this program from running correctly. Close the program

While troubleshooting the issue, you notice on the CTU report from the client exceptions similar to this one:

Environment

  • BIG-IP APM
  • EPSEC-1.0.0-1505.0
  • Edge Client
  • Windows 10/11
  • This may happen after an upgrade which includes the epsec file above.

Cause

This is caused by Bug ID1463105.

Recommended Actions

This issue is fixed in EPSEC 1.0.0-1602.0 and later. Install the latest EPSEC file from MyF5 Downloads.
