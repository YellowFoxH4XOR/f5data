Known Issue

This is the result of a known issue. BIG-IP ASM and PSM do not support IPv6. If a virtual server is configured for IPv6 and either BIG-IP ASM or PSM is also enabled on the virtual server, connections to the virtual server will be reset.

F5 Product Development tracked this issue as ID 240505 (formerly CR61665), and it was fixed in BIG-IP 11.1.0. For information about upgrading, refer to the BIG-IP ASM or PSM Release Notes.
