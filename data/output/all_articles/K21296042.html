Description
With Windows10 20H2, users may face difficulty using Windows Logon Integration (also known as DialUp Logon) feature.
Windows users may need to attempt to log in multiple times.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • Windows 10 20H2
  • Windows Login Integration / DialUp integration

Cause
Bug ID 1029929

Recommended Actions

Windows users should re-attempt to logon in the event of a logon failure.
