K000147977: Issue: Timeouts using kubectl

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147977

Description

  • You're using the kubectl get all command
  • The API responds slowly and you receive a timeout

Environment

  • kubectl for virtual kubernetes (vK8s)

Cause

  • The kubectl get all command will try all API GET calls to the F5® Distributed Cloud Console
  • For a vk8s site, not all k8s object is open/available for the user, that is why kubectl get all will get some timeout or 403 forbidden

Resolution

  • Avoid using kubectl get all command, please use specific get command (kubectl get pod, kubectl get deployment, etc..)

Additional Information

  • None
