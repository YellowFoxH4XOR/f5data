Known Issue

This is the result of a known issue. Clustered Multi-Processing (CMP) is a feature that allows BIG-IP platforms with multiple processors to increase traffic handling by utilizing multiple TMM instances. CMP is not compatible with certain BIG-IP configurations, such as global iRule variables.

If you add or remove an iRule with a global variable to or from a virtual server configuration using the Configuration utility, the BIG-IP system may not correctly update the CMP status for the virtual server.
For example, if you use the Configuration utility to add an iRule with a global variable to a virtual server for which CMP processing is enabled, the BIG-IP system may not change the CMP status for the virtual server to disabled.

Alternatively, if you use the Configuration utility to remove an iRule with a global variable from a virtual server for which CMP processing is disabled, the BIG-IP system may not change the CMP status for the virtual server to enabled.

F5 Product Development tracked this issue as CR93820 and it was fixed in BIG-IP 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

To work around this issue and update the CMP status for the virtual server, click the Update button on the virtual server's Properties or Resources page.
