Known Issue

Viewing learning suggestions for Web Scraping Detection violations may impair the performance of the Configuration utility.

This issue occurs when all of the following conditions are met:

  • Web Scraping Detection is enabled.
  • A Web Scraping Detected negative security violation is opened from the Manual Traffic Learning screen.

Impact

The Configuration utility may be slow to respond or may timeout.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When opening a Negative Security Violation of the type: Web Scraping Detected, the Configuration utility may be slow to respond, and may eventually time out.
  • The mysqld process may be reported as consuming a high percentage of CPU, as shown in the following excerpted output from the top command:

    PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
    12166 mysql 20 0 212m 105m 5868 S 96.3 5.2 2:35.44 mysqld
