Description


False positive violations with Cookie Hijack Reason - Mismatched message key


Environment


BIG-IP Adv. WAF

Multiple ASM devices


Cause


Multiple datacenters with ASM devices. This problem can be seen when a user reaches one ASM system and then is sent to a different datacenter with an ASM that doesn't recognize the ASM cookies set by another system.


Recommended Actions


You can sync asm encryption between data centers if they are in an ASM sync group. If ASM sync isn't possible, you can validate the desired cookie settings on the Security ›› Options : Application Security : Advanced Configuration : Cookie Protection page and then export the Cookie Protection configuration. Then import it in all other data centers. This will share the security context amongst them so the other ASM systems can recognize the same cookie message keys.


Additional Information


For more info, see "Overview: Configuring advanced cookie protection" in https://techdocs.f5.com/en-us/bigip-17-0-0/big-ip-asm-implementations/adding-entities-to-a-security-policy.html
