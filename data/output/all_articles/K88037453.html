Description

Despite the cloud environment indicating a successful deployment. A system deployed by an Azure ARM template, AWS CloudFormation template, or other cloud template may fail to configure the instance as expected, including missing VLANs, self-IP's, or other settings.

Environment

  • Big-IP Virtual Edition (VE)
  • Cloud
  • Template deployment

Cause

The system configuration is performed by F5-created scripts that run when the instance starts up. When these scripts encounter problems, they may not cause the overall deployment to fail from the cloud environment's perspective.

Recommended Actions

Information on the execution of these scripts is logged in the /var/log/cloud folder. Review these files for error messages that may provide insight into what specifically failed.

Common causes include licencing issues, lack of outbound internet connectivity, or misconfiguration within the template parameters.
