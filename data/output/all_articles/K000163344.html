K000163344: Drop-down list for client and server SSL Parent Profile names are too narrow

Type
Support Solution
Published
2026-09-21
Updated
2026-09-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000163344

Description

When creating a new SSL client or server profile in the BIG-IP Configuration utility, the Parent Profile drop-down list may render too narrow. Profile names may wrap making them difficult to read and select.

Environment

  • BIG-IP LTM running versions >=17.5.1.6 and <= 17.5.1.9.
  • SSL client and server profile creation pages in the BIG-IP GUI.
  • Drop-down fields containing multiple profiles.

Cause

This is a BIG-IP GUI regression tracked by bug ID2302209. The regression was associated with the jQuery upgrade beginning in BIG-IP 17.5.1.6.

Answer/Recommended Actions

As a temporary workaround, select a parent profile with a longer name first. This causes the drop-down list to resize so that entries are displayed without wrapping. After the list expands, select the intended parent profile.

Long-term fix is to install an EHF or a version that contains the fix for ID2302209 on versions >= 17.5.1.6 and <=17.5.1.9.
