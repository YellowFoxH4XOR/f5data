Known Issue

Updates to the SecurID configuration may not synchronize to peer devices.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured in a synchronization device group.
  • You use the Configuration utility to upload a new SecurID configuration file.
  • You attempt to synchronize the local configuration to the device group.

Impact

SecurID configuration changes are not synchronized to peer systems in the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Error messages similar to the following example are logged to the /var/log/ltm file:

    err mcpd[25015]: 01070734:3: Configuration error: Configuration from primary failed validation: 01070712:3: Caught configuration exception (0), failed in syscall link(/config/filestore/files_d/Common_d/securid_server_config_file_d/:Common:aaa_RSA::sdconf.rec_34192_9, /config/filestore/.trash_bin_d/.current_d/Common_d/securid_server_config_file_d/:Common:aaa_RSA::sdconf.rec_34192_9) errno=(No such file or directory).

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to reference the new SecurID configuration file prior to synchronizing. To do so, perform the following procedure:

Impact of workaround: The initial SecurID configuration will be replaced with the contents of the new SecurID configuration file.

  1. Use secure shell (SSH) to upload the new SecurID configuration file to the BIG-IP APM system.

    Note: This step requires administrative console access.

    For example:

    scp <securid_file> root@<apm_hostname or IP address>:/<path>

  2. Log in to tmsh by typing the following command:

    tmsh

  3. Use the following command syntax to reference the new SecurID configuration file:

    modify /apm aaa securid <securid profile name> config-files modify { sdconf.rec { local-path /<path>/sdconf.rec } }

  4. Save the configuration change by typing the following command:

    save /sys config

  5. To exit tmsh, type the following command:

    quit
