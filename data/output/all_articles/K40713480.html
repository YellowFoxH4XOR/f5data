Description

When creating a virtual server it is possible to add a dependency, so that both the virtual server and the dependent virtual must be "up" in order for the DNS pool member to be marked up. In some versions, however, it is not possible to add the dependency in the main configuration screen, and below error can be seen on GUI 

0107024f:3: VS <vip-name> does not exist

Environment

  • BIG-IP DNS
  • Virtual server
  • Dependent virtual server

Cause

This is a known issue, for more details refer to BugID 774481.
 

Recommended Actions

Create the virtual server through GUI without dependent virtual server first and then edit the virtual server to add dependency

Follow the below steps to modify the virtual server to add dependency,
  1. Open the virtual server settings
  2. From the Configuration list, select Advanced. Additional controls display on the screen.
  3. In the Dependency List area, from the Virtual Servers list, select each virtual server on which you want the virtual server to be dependent, and then click Add. The virtual servers display in the list as you add them.
  4. Click Finished.
