Known Issue

BIG-IP DNS (formerly known as BIG-IP GTM) link graphs fail to display in the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You have licensed and provisioned BIG-IP DNS.
  • You have configured BIG-IP DNS links.
  • You view the BIG-IP DNS link graphs in the Configuration utility.

Impact

You cannot view BIG-IP DNS link graphs.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you try to view the BIG-IP DNS link graphs in the Configuration utility, the system displays the following error message:

    General database error retrieving information

  • In the /var/log/ltm file, you observe an error message similar to the following example:

    statsd: err statsd[6318]: 011b030d:3: Graph '/Common/Link_AS394043' not found
