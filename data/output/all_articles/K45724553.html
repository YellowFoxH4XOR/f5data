Topic

This article applies to the BIG-IP 5250F, 7200F, 10200F, 11000F, and 11050F platforms. For all other platforms, refer to the following article:

  • K26061560: Updating the firmware for a FIPS protected internal HSM

You should consider using this procedure under the following conditions:

  • Your BIG-IP system runs on one of the following platforms:

    • 5250F, 7200F, 10200F, 11000F, or 11050F
  • You want to maintain your BIG-IP system's FIPS device compliance with the National Institute of Standards and Technology (NIST).
  • You want to ensure that the BIG-IP system's FIPS protected internal Hardware Security Module (HSM) is running the latest firmware version.

Description

NIST has required that the Random Number Generator (RNG) can no longer be included as a key generating option. F5 does not use this type of key generation, but must remove it to allow the FIPS device in the appliance to be compliant with NIST Special Publication 800-90A rev.1.

Note: The previous link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

To upgrade the firmware on the FIPS system, user intervention is required to apply the latest HSM firmware. This is due to security authorization requirements for accessing the FIPS protected HSM.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have command line access to the BIG-IP system.
  • You have the FIPS HSM security officer (SO) password.
  • You have the HSM security domain.
  • You have downloaded the current FIPS upgrade utility from the F5 Downloads site. For more information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

Procedures

Updating the FIPS HSM Firmware from the FIPS upgrade utility

Impact of procedure: Performing the following procedure requires a reboot of the system, and you should perform the procedure only during a planned maintenance period. This procedure does not affect the current HSM configuration.

Important: If you have never initialized your FIPS device, you will need to do that before running this update utility. You can change your Security password or Domain label at that time. Peer devices with this hardware need to be updated accordingly. For more information, refer to BIG-IP Platform: FIPS Administration. For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Upload the FIPSUpgrade2016 file to the following directory on the BIG-IP system:

    /var/tmp

    Note: For information about uploading files to the BIG-IP system, refer to K175: Transferring files to or from an F5 system.

  2. Log in to the command line of the BIG-IP system.
  3. Create a UCS archive and store off of the BIG-IP system
  4. Verify the current FIPS firmware, by typing the following command:

    tmsh run /util fips-util -f info

    You should observe output similar to the following example:

    Label:
    Model:              NITROX XL CN16XX-NFBE
    Serial Number:      3.0G1530-ICM502591
    …..
    Temperature:        52.7500 C
    HW version:         2.0
    Firmware version:   CN16XX-NFBE-FW-2.1-110018

  5. Change directories to /var/tmp, by typing the following command:

    cd /var/tmp

  6. Modify the permissions on the FIPSUpgrade2016 utility to include execute, by typing the following command:

    chmod 755 /var/tmp/FIPSUpgrade2016

  7. Start the FIPS upgrade utility, by typing the following command:

    ./FIPSUpgrade2016

    Follow the prompts:

    1. Security Officer credentials and reboot are required.. Continue (y/N)?:

      The system validates platform eligibility for upgrade. Type Y to continue.

      Note: Typing N terminates the utility, and no changes take place.

    2. Would you like to run this command now (y/N)?:

      The system uploads the new firmware installer package, and removes the old one. Type Y to continue.

      Note: Typing N terminates the utility, and no changes take place. Typing Y replaces the firmware installer package on the FIPS device, however the firmware itself has not yet been updated.

    3. Enter the Security Officer password:

      Type your Security Officer password at this prompt, then press ENTER.

      Note: Not entering a password, or typing the wrong password, forces the system to terminate the upgrade.

    4. Press <ENTER> to continue or Ctrl-C to cancel

      Press ENTER to upgrade the firmware.

      Note: Typing Ctrl-C terminates the installation, leaving the new firmware installer package on the FIPS device, but the system continues to use the old firmware.

  8. Reboot the system by typing the following command:

    reboot

    Important: The system will continue to use the old firmware until you have rebooted the system.

  9. After the reboot is complete, and the system has initialized, log in to the command line of the BIG-IP system.
  10. Repeat step 3 to confirm that the correct firmware version has been installed. The firmware version should match the following:

    CN16XX-NFBE-FW-2.2-130013
