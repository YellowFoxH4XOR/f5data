K000149705: high-config-load-failed. Configuration failed to load with error message "SSH Security Configuration must be specified in Ephemeral Access Configuration."

Type
Support Solution
Published
2025-02-11
Updated
2025-02-25
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2, 15.1.5
Source
https://my.f5.com/manage/s/article/K000149705

Description

  • After upgrading from 15.1.5.1 to 17.1.2, the configuration is unable to load with the error message "01b70099:3: SSH Security Configuration must be specified in Ephemeral Access Configuration."

The output of "tmsh show sys mcp-state" is as follows:

# tmsh show sys mcp-state

-------------------------------------------------------

Sys::mcpd State:

-------------------------------------------------------

Running Phase base

Last Configuration Load Status high-config-load-failed

End Platform ID Received true

Environment

  • BIG-IP LTM
  • Upgrade
  • Configuration

Cause

  • Misconfiguration
    • 01b70099:3: SSH Security Configuration must be specified in Ephemeral Access Configuration.

Recommended Actions

  1. Boot back to previous BIG-IP version
  2. Delete the object which requires the SSH Security Configuration to be specified in Ephemeral Access Configuration.
  3. Boot into the new BIG-IP version and load the configuration

Additional Information

Alternatively, you should be able to resolve the error message by specifying an SSH Security Configuration in Ephemeral Access Configuration using the F5 Tech Docs below.

  • Creating an SSH Security Configuration
  • Creating an Access Configuration for ephemeral authentication
