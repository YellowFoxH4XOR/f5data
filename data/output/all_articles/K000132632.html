Description

You want to send the TMM log(/var/log/tmm) to remote syslog server. However, the BIG-IP won't send TMM log to remote syslog server by default. You can costomize the syslog-ng setting to implement this feature.

Environment

  • BIG-IP v11.x and later
  • TMM log message
  • Remote syslog

Cause

None

 Recommended Actions

Following the below steps to configure the syslog-ng setting for sending TMM log to remote log server.

  1.  Log in tmsh by entering the following command:
tmsh
  1. To add the desired syntax that sending TMM log to the remote server, follow the below syntax;
modify /sys syslog include "source s_tmm {pipe("/var/run/tmm.pipe");};destination d_remote_loghost {udp(\"<remote_server_ip>\"port(<tcp_port>));};log {source(s_tmm);destination(d_remote_loghost);};"

For example, to send the TMM log to syslog server 10.10.10.1 with port 514 using UDP protocol, you can use the below command.

modify /sys syslog include "source s_tmm {pipe("/var/run/tmm.pipe");};destination d_remote_loghost {udp(\"10.10.10.1\" port(514));};log {source(s_tmm);destination(d_remote_loghost);};"

Important: You should use this parameter with caution. The system does not validate the configuration used with the include parameter. If you use this parameter incorrectly, the BIG-IP syslog may fail to function. F5 recommends that you test this in an appropriate environment before implementing in a production environment.

  1. Save the configuration:
save /sys config

Note: It may be necessary to restart the syslog-ng service, run the following command from bash:

bigstart restart syslog-ng
