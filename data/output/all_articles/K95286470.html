Issue

Error Message

warning chmand[<PID>]: 012a0058:4: Chassis with <blade_quantity> blades (<wattage>) may be inadequately powered - increase active number of power supplies

In this error message, note the following:

  • <PID> is the process ID for the chmand process.
  • <blade_quantity> is the total number of installed blades.
  • <wattage> is the current system power requirement.

For example:

warning chmand[18484]: 012a0058:4: Chassis with 4 blades (2200 W) may be inadequately powered - increase active number of power supplies

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The LCD panel

Description

This message occurs when the following condition is met:

  • The number of active power supplies does not meet the power requirement to support all blades.

Impact

The blade system may not function properly when running with insufficient power.

Recommended Actions

You can verify the current power supply status using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To display the current chassis power supply status, type the following command:

    show /sys hardware

    For example, the following command output indicates that the chassis has two power supplies with an up status:

    Chassis Power Supply Status
      Index  Status  Current
      1      up      AC
      2      up      AC
      3      down    AC
      4      down    AC

To determine the power requirement of your blade system, refer to the Platform Specifications chapter of your specific Platform Guide.
