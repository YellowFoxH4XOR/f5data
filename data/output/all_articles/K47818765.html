Description

Allowing APM users to change their account password more than once  per day on Windows Domain Controller.

Environment

  • BIG-IP APM is provisioned
  • Users are authenticated against Windows Active Directory
  • Users would like to change their password more than once in a day

Cause

The default AD Group Policy on a Domain Controller prevents the domain users from changing their passwords more than once in a day. If you attempt to change the password using the APM LOGON page, it works for the first time and you can see the following message in the user session logs:
    /Common/<Access-Policy-Name>:<Session-ID>: AD agent: Auth (logon attempt:0): password changed successfully for '<username>'

But if you attempt to change the password for the second time on the same day, you get the following error on the browser: 
    "The domain password change operation failed. Please try again."

And you see the following messages in the user session logs:
    /Common/<Access-Policy-Name>:Common:<Session-ID>: AD module: ENTER Function chgUserPassword
    /Common/<Access-Policy-Name>:Common:<Session-ID>: AD module: change password for '<username>' failed: Password change rejected(4), result_string: (4)
    /Common/<Access-Policy-Name>:Common:<Session-ID>: AD module: krb5_chg_password(): Password change rejected(4), result_string:
    /Common/<Access-Policy-Name>:Common:<Session-ID>: AD module: LEAVE Function chgUserPassword
    /Common/<Access-Policy-Name>:Common:<Session-ID>: AD agent: Auth (logon attempt:0): failed to change password for '<username>'

Recommended Actions

The default AD Group Policy on a Domain Controller prevents the domain users from changing their passwords more than once in a day.
This is enforced using the default Group Policy and the setting is configured on the Domain Controller under:
"Start -> Administrative Tools -> Group Policy Management -> Default Domain Policy -> Computer Configuration -> Windows Settings -> Security Settings -> Account Policies -> Password Policy".

If you look under this, the field "Minimum password age" is set to "1 day". This means that the users need to wait for at least 1 day after changing their password to change it again. 

You cannot modify the "Minimum password age" setting on the the default Group Policy on the Domain Controller. But, if you want to allow the users to change their passwords multiple times in a day, then you can create a custom Group Policy and set the "Minimum password Age" value to "0 days" and have this group Policy applied to the Domain Users.
