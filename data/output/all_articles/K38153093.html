Description

The following information provides a method to add the secure attribute onto an HTTP cookie Set-Cookie header. 

Environment

  • BIG-IP TMOS
  • Cookies being passed through an LTM virtual server.

Cause
None

Recommended Actions

Create a new iRule containing the following code:

when HTTP_RESPONSE {
    #get the names of all HTTP cookies in the HTTP Response
    set cookie_names [HTTP::cookie names]
    #check the list of cookie names for a cookie named "cookieX". If found, add the secure attribute to the Set-Cookie header
    foreach cookie $cookie_names {
        if { $cookie contains "cookieX" } {
            HTTP::cookie secure $cookie enable
        }
    }
}

 

Attach the iRule to an HTTP/HTTPS virtual server.

Note: Change the name (cookieX) shown in the example to the actual name of the cookie.
