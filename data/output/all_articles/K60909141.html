Known Issue

The /var/tmstat/blade/scripts file size increases.

This issue occurs when all of the following conditions are met:

  • You are using iRules iStats commands.
  • You are deleting configurations.
  • You are using the BIG-IP ASM module.

Impact

The virtual size of the merged process grows linearly with the /var/tmstat/blade/scripts segment; this could lead to an out of memory condition.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Over time, the size of the /var/tmstat/blade/scripts file increases. This can eventually lead to the BIG-IP system no longer providing up-to-date statistics.
