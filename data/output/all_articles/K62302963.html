Description

oom_killer is killing tmm, and other process. There is no particular consuming memory.
oom_killer is running or not, you can check in /var/log/kern.log, and see swap memory is used up like below

java invoked oom-killer
warning kernel: Free swap = 0kB
 

And also see lots of similar to below entries:

kernel: : [6641100.793123] [ 5591]     0  5591    63454    15100     100        0             0 tmsh
 

Environment

  • BIG-IP
  • v13.1.* - 15.1.0.1
     

Cause

Bug ID 742628


Recommended Actions

Follow workaround in solution: K53843889: tmsh may add resource pressure to the control plane when starting sessions

or

Kill tmsh process.
  1. Use the following command to identify the PID of the tmsh process:
    ps aux | grep tmsh

    In the following example output, the PID of the tmsh process is 2059:
    root 2059 89.1 3.7 274792 151224 pts/1 Sl 08:36 0:00 tmsh
     
  2. Kill the tmsh process with the following command syntax:
    kill -9 <tmsh pid>

    For example, the following command kills a tmsh process with a PID of 2059:
    kill -9 2059
 

Additional Information

This issue may hit hard BIG-IP with less than 8GB RAM. 
If you are using VE version, consider upgrading RAM.
