Description

  • Active alarm in Webui suggests that the peer has been disconnected.
  • The alarm looks like this "The state of the peer <Peer_Name> was changed. The previous peer state was OPEN, a new state is CLOSED. The reason for the change of the state is: Disconnected."
  • FEP logs would usually show these tyes of event logs : 

2020-12-03 12:22:01,267 WARN [10994] Peer Timeout event occurred for RemotePeer(<Peer_Name>_3871 Open_29546478215743653 None)-ProxyGroup: traffix_fep_i-tcp-( {composedState=Open_29546478215743653 None, stateAtFep=Open_29546478215743653 None, proxyPeer=ProxyInternalPeer(site_traffix_fep_i-tcp Open_40606817397005050 None), remotePeerName='<Peer_Name>_3871'} {composedState=Closed_28346678531855565 Signalling Not Available, stateAtFep=Closed_28346678531855565 Signalling Not Available, proxyPeer=ProxyInternalPeer(site_traffix_fep_i-tcp Open_40606817425318104 None), remotePeerName='<Peer_Name>_3871'}), message <***>>>>></*>. [Answer Message Executor_4_23] [PendingRequestsExpirationRunnable.doRun()]

 

Environment

  • SDC 5.1
  • FEP
  • Peer Server

 

Cause

This can be caused by various reasons. One of the reason is when the peer is disconnected or have timeouts in its connection to the FEP. 

 

 Recommended Actions

Correct the issue from the network side or the peer server side.

 

Additional Information

None.
