Topic

Note: For information about displaying the version information for the ARX Secure Agent, refer to K11713: Displaying the software version for the ARX Secure Agent.

Note: For information about displaying the version information for other F5 products, refer to K914: Displaying the software version of your F5 product.

ARX software versions are most frequently referred to in documentation as 3-digit version numbers, such as 6.2.0. However, when you view the ARX software version using the ARX Manager or command line, the version information is displayed in the following format:

Version X.YY.ZZZ.bbbbb

In the previous example, note the following:

  • X is the Major software branch version.
  • YY is the Minor version number.
  • ZZZ is the Maintenance version number.
  • bbbbb is the build number.

For example, the ARX Manager or command line would display ARX 6.2.0 as:

Version 6.02.000.14341

It is important that you ignore the leading zeros for the Minor and Maintenance version numbers, as you can easily misread the ARX version number. For example, the ARX Manager or command line displays version 5.1.0 as 5.01.000.11929, and you could easily misread that as version 5.0.1.

When using the ARX Manager or the command line to display the ARX software version information, perform one of the following procedures:

ARX Manager

To display ARX version information using the ARX Manager, perform the following procedure:

  1. Log in to the ARX Manager.
  2. Click Status.

    For ARX 5.x and later, the ARX version information is listed in the Data Management OS field.

    For ARX versions prior to 5.x, the field name was FreedomFabric NOS.

Command line

To display ARX version information using the command line, type the following command:

show version
