K000152777: Stats processing delay error may be observed for managed BIG-IP

Type
Support Solution
Published
2025-07-28
Updated
2025-07-28
Applies to
  • BIG-IQ
  • F5 Distributed Cloud Services
  • BIG-IQ Centralized Management: 8.0.0, 8.1.0, 8.0.X, 8.X.X, 8.4.X, 8.4.0, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X
Source
https://my.f5.com/manage/s/article/K000152777

Description

After adding a DCD to an existing cluster, you start receiving emails with 'Stats data from device BIG-IP.LOCAL not received for 2745242 seconds, exceeding configured threshold value of 180 seconds.

Environment

  • BIG-IQ DCD
  • Statistics Collection

Cause

There may be a situation where some of the device between the BIG-IP and BIG-IQ DCD is causing a problem with connectivity, for example MAC Spoofing. This may be a reason why BIG-IP is not able to share the statistics to BIG-IQ DCD.

Recommended Actions

Verify with the packet capture if there is a correct MAC address of BIG-IQ DCD visible for BIG-IP.
