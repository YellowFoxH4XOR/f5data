Known Issue

In rare instances, certain BIG-IP platforms may erroneously generate power supply error messages that indicate zero milli-voltage. This issue occurs when all of the following conditions are met:

  • The BIG-IP platform is using DC power supplies (Manufacturing Part Number: FND850-S101G ; F5 Part Number: PWR-0149-0x)
  • The BIG-IP platform is one of the following models:
    • 10000s, 10050s, 10055
    • 10200v, 10250v, 10255
    • 10350v
    • 12250v

Typically, the AOM subsystem queries the power supply using the I2C protocol. The I2C protocol allows for transaction errors when the AOM subsystem initiates a request. On rare occasions, the AOM subsystem receives an I2C transaction error, which is then processed and may produce the erroneous log message. Thorough investigation of this issue has proven that at no time the power supply enters a faulted state or operates with a zero millivolt output voltage.

Impact

There is no impact; these error messages are benign.

Important: Replacing the power supply or BIG-IP system will not correct this issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe the alarm LED does not illuminate. However, the system logs an error message to the /var/log/ltm file that appears similar to the following example:

    010d0017:0: Power supply #<x> meas. AC input v: milli-voltage (0) is too low.

    In this error message, note the following:
     
    • <x> is the power supply location (either 1 or 2)
