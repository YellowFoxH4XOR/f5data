Description
Windows Integrated Logon fails when a user attempts to log into a domain joined PC while not connected to the corporate network.  
User receives the error "Domain not available.  Make sure your device is connected to your organizations network and try again."

Environment

  • Domain joined PC outside the corporate network
  • Windows Integrated Logon
  • Always-connected VPN
  • APM

Cause
This is expected behavior.
Windows requires a domain user to be connected the domain if logging on to a domain joined PC for the first time

Recommended Actions

Ensure that the domain joined PC is connected to your organization's domain when your user is logging to the PC for the first time. The user needs to authenticate against the domain before they can use their domain credentials outside the corporate network.

Additional Information

When a user is authenticated to a domain, a verification hash is stored in the system registry, just in case the user has to log on outside the domain.

When a user isn't connected to the domain, windows verifies the user domain credentials against the stored hash and allows access if the user credentials can be verified.
If the users credentials cannot be verified, or there is no hash to verify against, the user will not be granted access. In the case of windows logon integration, once the credentials can be verified, the Edge client will begin to build a VPN connection, while the user is being logged in.
