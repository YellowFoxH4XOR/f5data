K24304294: ''Data Input Error: Could not locate image'' when installing software image

Type
Support Solution
Published
2022-08-26
Updated

Applies to

Source

Description

While running a version prior to 11.5.0, you could run into the following error when trying to install a software image:
Data Input Error: Could not locate image "BIGIP_ <version-build>.iso"

Environment
  • Installing a software image containing point release while currently running a version prior to 11.5.0

Cause

Pre-11.5.0 versions don't have the concept of point releases implemented, so it doesn't recognize a software image containing a 4th element in it's version. The image imported via SCP to the device's /shared/images/ location will not be recognized when viewing it within the GUI under the System > Software Management > Image List section. 

Recommended Actions

You cannot directly update from pre-11.5.0 versions (e.g., v11.4.x, v11.2.x, etc.) to any 4th element version (e.g., v12.1.3.1, v13.1.0.1, etc.). Direct upgrade to 4th element versions is supported only from v11.5.0 and later. For pre-11.5.0 versions, you must first upgrade to v11.5.0 or later. The recommended upgrade path is from v11.4.x to v12.1.3, and then to v12.1.3.1. For details about upgrading to those versions, see the release notes for the associated release.
