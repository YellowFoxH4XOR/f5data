Description

  • F5 Access for iOS and F5 Access for Android are detected as the Edge Client on BIG-IP by 'Client Type' VPE agent
  • In /var/log/apm logs the entries like below are seen
<BIG-IP hostname> notice apmd[7010]: 01490261:5: /Common/<Access Policy>:<session-id>: Updating client info - Hostname: HyperPad Type: com.f5.Edge-Client Version: 3.0.7 Platform: iOS CPU: ARM UI Mode: Standalone Javascript Support: 1 ActiveX Support: 0 Plugin Support: 0 Model: iPad Platform Version: 10.3.4 Serial Number:  IMEI:
<BIG-IP hostname> notice apmd[7010]: 01490115:5: /Common/<Access Policy>:<session-id>: Following rule 'Edge Client' from item 'Client Type' to terminalout 'Edge Client'

Environment

  • APM
  • Virtual Policy Editor(VPE)

Cause

  • By default VPE agent 'Client Type' doesn't detect F5 Access for iOS and Android
  • Session variable session.client.app_id is set to com.f5.Edge-Client for F5 Access for iOS
  • Session variable session.client.app_id is set to com.f5.edge.client_ics for F5 Access for Android
Recommended Actions

Modify 'F5 Access' branch rule of 'Client Type' agent in order to detect F5 Access for iOS and Android:

  1. In the VPE click 'Client Type'
  2. Click 'Branch Rules' tab in the new pop-up window
  3. Click 'Change' button next to 'F5 Access'
  4. Click 'Advanced' tab in the new pop-up
  5. Use the below expression instead of the default one
expr { [mcget {session.client.type}] && ( [mcget {session.client.app_id}] == "f5_access" || [mcget {session.client.app_id}] == "com.f5.Edge-Client" || [mcget {session.client.app_id}] == "com.f5.edge.client_ics" ) }
