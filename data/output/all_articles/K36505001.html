Description

The following messages are seen in the /var/log/asm:

crit g_server_rpc_handler.pl[XXXX]: XXXXXXXX:X: ASM subsystem error (asm_config_server.pl,(eval)): Couldn't pass call to async process - ignoring

Environment

  • Error messages found in /var/log/asm
  • No impact on production traffic seen
Cause

This has been matched to Bug ID 831661

Recommended Actions

The bug has been fixed in 12.1.5.1, 14.1.2.3, 15.1.0 and later. 

F5 Support recommends upgrading to the fixed version.

Additional Information

The logs are actually side effects of the async handler restarting (restart caused by the Bug ID 831661).

The impact of the bug is Control Plane instability and poor learning performance on the device.
