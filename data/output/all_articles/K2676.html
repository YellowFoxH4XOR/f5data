K2676: Configuring trunks that use ports on different network interface cards

Topic

The BIG-IP system cannot trunk ports that are located on different network interface cards.

The BIG-IP system can trunk ports that share a common back plane, such as multi-port network interface cards, or network interfaces that are built into the motherboard.
