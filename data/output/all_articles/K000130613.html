Description

Use this article to learn how to find the account Admin(s) or User Manager(s) for account related assistance, such as requesting role change or adding/removing users.

The procedure explains how to access My Accounts, select an account, and view the account users listed in the account details.

Environment

  • MyF5 Portal
  • MyF5 user accounts 

Cause

Not applicable.
 

Recommended Actions

To identify the admin(s) for MyF5 account:

  1. Sign-in to your MyF5 account.
  2. Select the profile icon in the upper right corner, and then select My Accounts.
  3. From the listed Account name, select the account for which you want to identify the Admin.
  4. Review the Account Details

Note: If you do not see the Account Users section, it means there's currently no user with an Admin role. Contact your F5 account team or F5 Support (supportone@f5.com) for assistance.
