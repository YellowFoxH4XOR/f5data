Description

On occasions, tomcat stops writing log entries into /var/log/tomcat/liveupdate.log. There are two symptoms to this issue:

  1. /var/log/ts/cron.log will show the following log message:
    asm|INFO|Dec 21 19:25:01.698|23430|,,/var/log/tomcat/liveupdate.log.1 exists without running process, joining to /var/log/tomcat/liveupdate.log
     
  2. Running lsof command shows java process continues to write to a deleted (as indicated by deleted in brackets) liveupdate.log.1 file:
    # lsof -n | grep -i liveupdate.log.1
    java      23319          tomcat   52w      REG    253,3    5965   17 /var/log/tomcat/liveupdate.log.1 (deleted)
    java      23319 23322    tomcat   52w      REG    253,3    5965   17 /var/log/tomcat/liveupdate.log.1 (deleted)
    java      23319 23323    tomcat   52w      REG    253,3    5965   17 /var/log/tomcat/liveupdate.log.1 (deleted)
    java      23319 23324    tomcat   52w      REG    253,3    5965   17 /var/log/tomcat/liveupdate.log.1 (deleted)
    java      23319 23325    tomcat   52w      REG    253,3    5965   17 /var/log/tomcat/liveupdate.log.1 (deleted)


Environment

  • BIG-IP ASM / Advanced WAF 
  • When log rotates occur for liveupdate.log
     

Cause

Bug ID 835029
 

Recommended Actions

The following is a temporary workaround to this issue.

  1. Restart tomcat and ensure that liveupdate.log.1 is created
    # bigstart restart tomcat
     
  2. Stop tomcat
    # bigstart stop tomcat
     
  3. Move and rename liveupdate.log.1 to liveupdate.log.2
    # mv /var/log/tomcat/liveupdate.log.1 /var/log/tomcat/liveupdate.log.2
     
  4. Start tomcat
    # bigstart start tomcat

Note: The issue will resurface when the next log rotation of liveupdate.log occur. You would then need to reapply the same steps above to get around the issue.

Alternatively, you may reach out to F5 Support to request for a permanent fix.
