K000163227: APM iRule TCL Error After Upgrade to 17.5.1.8

Type
Support Solution
Published
2026-09-07

Applies to

Source

Description

A BIG-IP APM iRule can generate the following TCL error when the class element command accesses index 0 in an external data group:

TCL error: Invalid index 0 in class

The affected command is:

class element -value 0 <external_data_group>

This error can prevent APM Webtop resources from being assigned to users.

Environment

  • Product: BIG-IP APM
  • An APM iRule uses class element -value 0 to retrieve the first entry from an external data group.
  • The issue affects external data-group access in an affected BIG-IP release.
  • The same iRule and data-group configuration works correctly in an unaffected release.

Cause

This issue is associated with known issue ID2397785. A regression in the internal handling of the class element command incorrectly rejects index 0 when accessing an external data group.

Index 0 is valid and represents the first data-group element. The error does not indicate invalid iRule syntax or an invalid external data-group configuration.

Recommended Actions

Upgrade BIG-IP to a release containing the fix for this issue. (for example 17.5.1.9 )

After upgrading:

  1. Test the affected APM access workflow.
  2. Confirm that the TCL error no longer appears.
  3. Verify that users receive their assigned APM Webtop resources.

If an upgrade cannot be performed immediately, use an unaffected release until the fixed release can be deployed. Changing index 0 is not recommended because it is a valid index for retrieving the first data-group element.
