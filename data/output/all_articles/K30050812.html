Description

While configuring TPS-bases DoS Detection by Source IP, you must configure the settings for "Relative Threshold TPS" and "Absolute Threshold TPS." This article provides additional information on these threshold settings.

Environment

  • ASM
  • DoS Protection Profiles

Cause

NA

Recommended Actions

To configure TPS-based DoS detection, use the following steps:
  1. Log in to the Configuration utility.
  2. Go to Security > DoS Protection > Protection Profiles.
  3. Select Create.
  4. Enter a name for the DoS profile.
  5. For Families, select the HTTP check box. 
  6. Select Commit Changes to System.
  7. In the HTTP row, select Edit.
  8. Under HTTP Properties, select Use Legacy Application DoS view.

Additional Information

By Source IP:
Specifies the criteria that determine when the system treats the IP address as an attacker. If these thresholds are reached, the system prevents further attacks by limiting the number of requests per second to the history interval. The system does not return the blocking response page. The system considers an IP as an attacking entity if either of the following conditions occur:

Relative Threshold:
TPS increased by «number»% and reached at least «number» transactions per second:
Specifies that the system considers an IP address to be an attacker if the TPS ratio (the ratio between the transaction rate detection interval and the transaction rate history interval), for one IP address, is greater than the first number, and the detected TPS for a specific IP address equals, or is greater than, the second number. If the detected TPS is lower than this number, the system does not consider this IP address to be an attacker even if the TPS increased by number was reached. The default settings are 500 percent and 40 transactions per second.

Absolute Threshold:
TPS reached <<number>> transactions per second:
Specifies that the system considers an IP address to be an attacker if the number of requests sent, per second, from an IP address is equal to or greater than this number. The default setting is 200 transactions per second.
