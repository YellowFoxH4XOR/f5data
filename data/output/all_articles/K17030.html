Known Issue

Description

The BIG-IP APM rewrite profile may not properly handle events generated by the window.postMessage method.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile is configured with a rewrite profile.
  • A user accesses a web application that returns JavaScript content.
  • The web application uses events generated by JavaScript window.postMessage method.

Impact

JavaScript events generated by window.postMessage method will not be recognized by the BIG-IP APM rewrite profile causing the web application to malfunction.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Web page content that invokes the window.postMessage method will not render properly in web browsers.
  • An error message that appears similar to the following example is displayed in the browser error console:

       I.E browser:
       Invalid operand to 'in': Object expected
       cache-fm.js, line 657 character 91

       Chrome browser:
       Uncaught TypeError: Cannot use 'in' operator to search for 'data' in Ember.TextField
