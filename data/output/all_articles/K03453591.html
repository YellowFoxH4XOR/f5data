Known Issue

Configuration synchronization may fail after deleting a network firewall policy.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured as part of a high availability (HA) group.
  • You create a child network firewall policy from a parent network firewall policy.
  • You create a child network firewall policy from the child network firewall policy.
  • You delete the first child network firewall policy.

Impact

Synchronization fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to synchronize the BIG-IP HA devices, you observe an error message similar to the following example:

    Sync error on <bigip peer device>: Load failed from <bigip local device>:3: Caught configuration exception (0), Values (<value>) specified for firewall policy (<value>): foreign key index (copy_from_FK) do not point at an item that exists in the database..

    Recommended action: Review the error message and determine corrective action on the device

Workaround

To work around this issue, you can save and synchronize the configuration using the Traffic Management Shell (tmsh). To do so, perform the following procedure:

Impact of workaround: The following procedure temporarily causes the BIG-IP device to stop processing traffic while the configuration loads.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To save the system configuration, enter the following command:

    tmsh save sys config partitions all

  3. To load the saved system configuration, enter the following command:

    tmsh load sys config partitions all

  4. To synchronize the local configuration to the HA peer device, use the following command syntax:

    run /cm config-sync <sync_direction> <sync_group>

    For example, the following command pushes the local device's configuration to the HA peer of the My_Syncfailover device group:

    run /cm config-sync to-group My_Syncfailover

  5. Exit tmsh by entering the following command:

    quit
