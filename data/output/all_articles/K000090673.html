K000090673: "neverLogRequests" does not work when "true" is set

Type
Support Solution
Published
2021-12-23
Updated
2021-12-23
Source
https://my.f5.com/manage/s/article/K000090673

Description

When using the neverLogRequests option in the Allow/Deny list of an App Protect policy you still see logs being generated despite setting the value to 'True'.

 Environment

NGINX App Protect

 Cause

The cause of this is that the functionality of that setting was not implemented until App Protect version 3.6.

 Recommended Actions

Upgrade your NGINX App Protect to version 3.6 or higher to be able to use this functionality.

 Additional Information
