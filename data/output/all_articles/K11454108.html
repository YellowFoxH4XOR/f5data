Description

During a VIPRION multiple upgrade (chassis system), one or more blades is showing waiting for product image error message.

This is an example of the error message:
show /sys software

--------------------------------------------------------
Sys::Software Status
Volume  Slot  Product  Version   Build  Active  Status
--------------------------------------------------------
HD1.2      1   BIG-IP 12.1.5.1   0.0.5      no  complete
HD1.2      2     none     none    none      no  waiting for product image (BIG-IP 12.1.5.1)
HD1.5      1   BIG-IP   12.1.4   0.0.8     yes  complete
HD1.5      2   BIG-IP   12.1.4   0.0.8     yes  complete

As per the example above, blade 2 is waiting for product image (BIG-IP 12.1.5.1).

You have copied the software image to the impacted blade as per ID817417 but issue has not been resolved.

Environment
  • BIG-IP VIPRION multiblade upgrade (chasis system)
  • One or more blade showing error waiting for product image
  • The mentioned blade already have the mentioned product image

Cause

Unknown at the time of publication.

Recommended Actions

If you have uploaded the missing image to the blade but the blade is still not able to recognize the software image, you will need to reboot the blade.

  1. Login to the Command Line of the Viprion
     
  2. To reboot a blade, use the following command syntax:
    clsh --slot=<slot number> <command>

    For example, to immediately restart only blade 2, type the following command:
    clsh --slot=2 "shutdown -r now"
     

Additional Information

To copy all the software image from one blade to another, you can use the following command where X is the slot number.
scp /shared/images/* slotX:/shared/images

For example, you have log into slot1 and you want to copy all images to slot3 the command would be:
scp /shared/images/* slot3:/shared/images

If the software is copied, but the error persists, you may need to register the software image with mcpd:

If the system still does not show the affected image from /shared/images in 'tmsh list sys software', on the target blade, run the command 'imagemgr -a /shared/images/<name of ISO>' to manually add the software image to the 'sys software' configuration.
