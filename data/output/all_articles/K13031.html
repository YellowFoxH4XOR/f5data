Known Issue

Description

An ARX 2000 or 4000 platform may experience power sensor read failures and incorrectly report both power supplies as failed or absent.

This issue occurs when the following condition is met:

  • Internal I2C communications with the power sensor have been interrupted.

    Note: This issue has been experienced by only a few customers, and F5 Product Development has not yet identified what conditions cause the interruption.

Impact

The ARX system may incorrectly report the state of the power supplies.

Note: This condition does not impact system performance.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The syslog file contains the following messages:

    :LOG-0-DBG-FILTER:: logger: ipmi.pl: both power supplies are in failed state. Retrying...
    :LOG-0-DBG-FILTER:: logger: ipmi.pl: both power supplies are in failed state. Giving up!

  • The show health command displays power fail events similar to the following example:

    System Health Information

    Date                     ID      Event                       Description
    ---------------------------------------------------------------------------------------
    Sat Jan 01 19:43:19 2011 (540) - powerFail                   Slot power 1/2 absent
    Sat Jan 01 19:43:19 2011 (540) - powerFail                   Slot power 1/1 absent

  • The show chassis chassinfo command indicates power is online but also indicates the power supplies are absent. The output of the command appears similar to the following example:

     Identification:
     Hostname                             UUID
     ------------------------------------ --------------------------------------
     ARX1                                 540c1cbc-6d01-11de-bcbe-3b33062f7c6e  

     Chassis:
     Chassis Type  Model Number                          HW Ver.  Serial    
     ------------  ------------------------------------  -------  -------------
     ARX-2000      ARX2000URLX                                    0700000112

     Chassis Environment:
     Base MAC Address    Power            Fan(setting)    Temperature
     -----------------   --------------   -------------   -------------
     00:0a:49:17:c2:00   Online           Online          Normal(<45 C)       

     Power Details:
     Supply   State
     ------   -----   
     1/1      Absent   
     1/2      Absent

  • Additionally, if configured to send SNMP traps, the ARX system sends a trap indicating both power supplies are in a failed state.

Workaround

There is no work around for this issue. However, to clear the failed or absent power supply condition, you must reboot the ARX system. To do so, perform the following procedure:

Impact of workaround: If the ARX system is a standalone unit, restarting interrupts traffic processing. If the ARX system is the active member of a redundant pair, restarting causes a failover. Traffic processing is interrupted until the failover process has completed. However, if the ARX system is the backup member of a redundant pair, there is no impact.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Reload the ARX by typing the following command:

    reload

Note: A full power cycle of the ARX system may be required if the system reboot does not clear the condition.
