Known Issue

This is the result of a known issue. Beginning in BIG-IP version 10.0.0, F5 automatically enables the IPv6 Gateway, RAM Cache, and SSL CMP modules on all BIG-IP products and platforms that support these modules. Although these modules are active, they are not listed as active modules in the BIG-IP system license file (/config/bigip.license), or in the Configuration utility under System > License.

Note: This issue affects only the BIG-IP 1500, 3400, 6400, 6800, 8400, and 8800 platforms.

Note: The SSL CMP module is only available on multi-processor BIG-IP platforms. For more information, refer to K7751: Overview of Clustered Multi-Processing.

F5 Product Development is tracking this issue as ID 291751 (formerly CR130639).

Workaround

You can verify that the modules are active using one of the following procedures:

BIG-IP 10.x

You can verify that the modules are active by inspecting the Enabled Features section in the bigpipe version command output. To do so, perform the following procedure:

  1. Log in to the BIG-IP system command line.
  2. Enter the following command:

    bigpipe version | less

  3. Using the up and down arrow keys, scroll the output of the previous command and inspect the Enabled Features section. The modules appear as follows in the command output:

    CMP SSL
    IPv6 DNS Support
    IPv6 Gateway Module
    RAM Cache

  4. To quit the less utility, press the q key.

BIG-IP 11.x

You can verify that the modules are active by inspecting the Active Features section in the tmsh license details command output. To do so, perform the following procedure:

  1. Log in to the BIG-IP system command line.
  2. Enter the following command:

    tmsh show /sys license detail | less

  3. Using the up and down arrow keys, scroll the output of the previous command and inspect the Active Features section. The modules appear as follows in the command output:

    ltm_ram_cache
    RAM Cache

    nw_dns_ipv6
    IPv6 DNS Support

    nw_ipv6
    IPv6 Gateway Module

    perf_SSL_cmp
    CMP SSL

  4. To quit the less utility, press the q key.
