Topic

To view the disk activity statistics for BIG-IP 9.0.0 through 9.4.8, type the following command:

grep disk_io /proc/stat

This command will provide output in the following format:

disk_io: (device):(totalrw,totalr,totalblocks,totalwreq,totalwritten) (device...

For example:

disk_io: (3,0):(10862,10440,272729,422,2863) (22,2):(2094,66,610,2028,27768)

In the example above, (3,0) is the primary drive, which is generally a CF card, and (22,2) is the secondary drive, which is generally a hard drive.

The primary drive (3,0) shows the following statistics:

10862 Total Read and Write Requests
10440 Total Read Requests
272729 Total Blocks Read
422 Total Write Requests
2863 Total Blocks Written

The secondary drive (22,2) shows the following statistics:

2094 Total Read and Write Requests
66 Total Read Requests
610 Total Blocks Read
2028 Total Write Requests
27768 Total Blocks Written
