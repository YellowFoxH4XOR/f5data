Description

In the GUI, allow list IP for web scraping created under:

Security  ››  Application Security : Anomaly Detection : Web Scraping : IP Address Whitelist

However, ASM blocking the request with message:  “Web scraping detected” violation

Environment

  • ASM
  • Web Scraping
Cause

Configured allow list IP is not the actual source IP in the IP header but the X-Forwarded-For IP in the HTTP header

Recommended Actions

 In order for ASM to trust the X-Forwarded-For IP address, following option must be enabled:
  1.  Go to Security >> Application Security >> Security Policies in the GUI, and then click on the policy.
  2.  Enable "Trust XFF Header" check box

None.
