K7422: A BIG-IP LTM using network failover can alternate between active and standby states when the peer system is down

Known Issue

This is the result of a known issue. If BIG-IP LTM systems in a redundant pair are using network failover with a high timeout value (such as 20 seconds), and one of the systems is temporarily offline, the remaining active system can alternate between active and standby states. When this occurs, the active system alternates between active and standby, holding each state for less than a minute. This behavior disrupts the load balanced traffic.

F5 Product Development tracked this issue as CR76108 and CR76122, and it was fixed in BIG-IP LTM 9.1.3 and 9.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.
