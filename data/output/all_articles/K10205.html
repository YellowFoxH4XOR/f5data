Known Issue

This is the result of a known issue. When accessing the BIG-IP ASM section in the Configuration utility using an account which has been assigned guest privileges, an error message that appears similar to the following is displayed:

No authorization - access denied

If you click on the link immediately below the error message, the main BIG-IP ASM configuration screen displays without any further error messages.

F5 Product Development tracked this issue as CR108159 and it was fixed in BIG-IP ASM 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.
