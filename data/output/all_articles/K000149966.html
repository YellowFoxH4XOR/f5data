K000149966: F5OS Thermal Thresholds and Actions among Different Hardware Components

Published

Applies to

  • F5OS-A: 1.7.X, 1.8.X, 1.5.2, 1.8.0, 1.7.0
  • F5OS-C: 1.6.2, 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000149966

Description

You want to know what are the threshold for the F5OS VELOS and rSeries system hardwares like INLET and OUTLET, and also check what the action the system will take if thermal exceeds threshold. For example, when the INLET tempurature exceeds 50 ℃, what will happen to the system.

Environment

  • F5OS VELOS or rSeries appliance
  • Hardware thermal threshold
  • System action when exceeding thermal threshold

Cause

None, this is informational.

Recommended Actions

The thermal threshold for different components are defined differently, so as the corresponding action it configured to take.

You can use the below command to retrieve the configured threshold and action on your VELOS or rSeries appliance:

docker exec -ti platform-hal psf run GET:lop/analog-alerts \$filter="contains(object 'Temperature')"

The output will be like:
