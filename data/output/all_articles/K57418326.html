Description

When HTTP headers are analyzed for connection from BIG-IP towards the back-end server, Server Agent Name can reveal BIG-IP device identity

Environment

  • BIG-IP AFM, APM, ASM, LTM, DNS

Cause

Unknown at the time of publication.

Recommended Actions

For security reasons, The administrator can change the Server Agent name setting in the HTTP profile from  "BigIP" to a custom value. 

Following are the steps:

1) navigate to Local Traffic >> Profiles >> Services >> HTTP

2) click the HTTP profile that you would like to modify

3) change the Server Agent name setting from "BigIP" to the desired custom value and click Update.
 

Additional Information

An administrator can use TCPDUMP, HTTP Watch, Browser Developer Tool utility to verify HTTP header information.
