Description

You want to extract the configuration for a single type of object from your BIG-IP

Environment

  • BIG-IP LTM

Cause

None

Recommended Actions

In order to retrieve just one type of configuration element from your device, you may use tmsh commands from Bash, and redirect the output to a text file. See the example below

# tmsh list ltm virtual >> /shared/tmp/my_ltm_config

# cat /shared/tmp/my_ltm_config

ltm virtual VIP-HTTP {
    destination 10.0.0.1:http
    ip-protocol tcp
    mask 255.255.255.255
    pool example_pool
    profiles {
        http { }
        tcp { }
    }
    source 0.0.0.0/0
    translate-address enabled
    translate-port enabled
    vs-index 2
}
ltm virtual VIP-HTTPS {
...

This should work for most types of elements accessible from the command line.

If you instead wish to extract the whole configuration, please refer to the links in related content for creating, exporting, and migrating SCF files
