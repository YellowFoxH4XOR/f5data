Known Issue

By default, the system only supports one outbound explicit proxy rule. You can work around this limitation by disabling strict updates and SNAT and enabling address translation on additional rules.

Impact

You are unable to create an outbound interception rule for the purpose of creating additional explicit proxy listeners. You may want to create outbound rules to create service control channels to allow internal services to interact with Internet resources or to create additional explicit proxy listeners.

Workaround

To work around this issue, you can disable strict updates and SNAT and enable address translation on additional rules.

Impact of workaround: When you change configuration of certain objects, the system re-deploys the various BIG-IP objects to match your new configuration. This re-deployment overwrites any existing BIG-IP objects without warning about existing changes. Before performing this procedure, you must first refer to the warnings and directions in the Disabling Strict Updates section of K00805840: SSL Orchestrator known issues and workarounds.

Adding the rule

  1. Navigate to SSL Orchestrator > Deployment > Interception Rules.
  2. Click Create Outbound Rule.
  3. Name the rule and for Configuration, click Advanced.
  4. For Description, add MOD:EXTRA_XP_OUT to the end of the description.

    Note: This description tells F5 Technical Support that you are using the official modification for this workaround..

  5. Under Security Policy, select the Explicit Proxy check box.
  6. Define the explicit proxy address and port to listen on.
  7. For L7 Profile Type, click HTTP.
  8. For L7 Profile click sslo_<system name>-xp.
  9. For Access Profile, click /Common/ssloP_<SSL Orchestrator per-req-policy>.app/ssloP_<sslo per-req-policy>_accessProfile.
  10. For Per Request Policy , click /Common/ssloP_<SSL Orchestrator per-req-policy>.app/ssloP_<sslo per-req-policy>_prpTcp.
  11. Under Resources, in the Available list, click sslo_<system name-xp. and move it to the Selected list.
  12. Click Finished.

Unlocking the application

  1. Navigate to SSL Orchestrator > Deployment > Deployment Settings.
  2. Under General Properties, clear the Strict Update check box.
  3. For Description, add MOD: EXTRA_XP_OUT to the end of the description.

    Note: This description tells F5 Technical Support that you are using the official modification for this workaround..

  4. Click Finished.

Modifying the virtual server

  1. Navigate to Local Traffic > Virtual Servers.
  2. Click sslo_<system name>-<rule name>.
  3. For Configuration click Advanced.
  4. For Source Address Translation, click None.
  5. For Address Translation, select the Enabled check box.
  6. Click Update.
