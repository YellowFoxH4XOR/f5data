K000138422: Installation errors: Errors during downloading metadata for repository 'nginx-plus'

Type
Support Solution
Published
2024-01-31
Updated
2024-01-31
Applies to
  • NGINX Products
  • NGINX Plus: R30
Source
https://my.f5.com/manage/s/article/K000138422

Description

Unable to install NGINX Plus in RHEL9. Error message mentions the following:

[root@server1]# dnf install ca-certificates

Extra Packages for Enterprise Linux 9 - x86_64                        489 kB/s | 20 MB   00:42
Extra Packages for Enterprise Linux 9 openh264 (From Cisco) - x86_64             2.3 kB/s | 2.5 kB   00:01
nginx-plus repo                                        0.0 B/s |  0 B   00:00

Errors during downloading metadata for repository 'nginx-plus':
 - Curl error (35): SSL connect error for https://pkgs.nginx.com/plus/centos/9/x86_64/repodata/repomd.xml [OpenSSL SSL_connect: Connection reset by peer in connection to pkgs.nginx.com:443 ]
Error: Failed to download metadata for repo 'nginx-plus': Cannot download repomd.xml: Cannot download repodata/repomd.xml: All mirrors were tried


Environment

NGINX Plus
Red Hat Enterprise Linux 9

Cause

NGINX cannot be downloaded if there's a proxy in between NGINX server and the repo server.

Recommended Actions

You could either turn off the proxy or allowlist pkgs.nginx.com in your proxy to be able to install/update NGINX.
Also, you could install NGINX offline by downloading the package from MyF5 portal.
