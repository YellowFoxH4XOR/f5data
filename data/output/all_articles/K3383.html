K3383: Creating a self-signed certificate with an expiration date that is less than or greater than the default of 30 days

Topic

If you need to create a self-signed certificate that expires in more, or less, than the default of 30 days, you must use the command line.

To create a self-signed certificate using the command line, perform the following steps:

  1. Log in to the command line.
  2. Generate the SSL private key, by typing the following command:

    genkey <Fully qualified host name>

    For example:

    genkey test.askf5.com
  3. Follow the prompts and choose all the default values.

    The key is stored in the /config/bigconfig/ssl.key/ directory.
  4. Generate the SSL certificate, by typing the following command:

    openssl req -new -key <Key path and name> -x509 -out <Cert path and name> -days <Value>

    For example, to create a certificate named test.askf5.com.crt that expires in 1000 days, you would type the following:

    openssl req -new -key /config/bigconfig/ssl.key/test.askf5.com.key -x509 -out /config/bigconfig/ssl.crt/test.askf5.com.crt -days 1000

The newly created self-signed certificate is stored in the /config/bigconfig/ssl.crt/ directory and is ready for use.
