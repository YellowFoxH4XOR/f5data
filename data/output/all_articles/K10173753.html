K10173753: Troubleshooting QKView file upload to iHealth

Type
Support Solution
Published
2022-10-26
Updated
2025-07-03
Applies to
  • F5OS
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K10173753

Description

QKView file is generated successfully, but uploading it to ihealth.f5.com either produces an error or misses some important outputs

Environment

  • iHealth
  • Qkview from BIG-IP (including Tenant) / BIG-IQ

Cause


The most common reasons for the behaviour are outlined below:
  • Unexpected characters or spaces in the name of the file.
    When downloading multiple files with the same name to the same directory of the workstation, it is common for MS Windows to rename the names by automatically appending a space character and a number in brackets.

    For example:

    support.qkview
    support.qkview (1)
    support.qkview (2)
    <…>

    Attempts to upload files containing space characters in their names will fail with an error message displayed in the browser window
  • non-ASCII characters in the QKView file
  • The file is too large for being displayed by iHealth
  • Software defect ID 704512 Automated upload of qkview to iHealth can time out resulting in error

Recommended Actions

  • For filenames containing invalid characters rename the files before uploading them to iHealth
     
  • For non-ASCII characters included in the QKView file:
    • Transfer the QKView file to a workstation and decompress. For example with file support.qkview:

      # mkdir support.qkview.tmp
      # cd support.qkview.tmp
      # tar -xvzf ../support.qkview

    • In the folder run the following to identify files with unusual characters:

      # for file in *; do xxd $file 2>/dev/null | awk '{print $2 " " $3 " " $4 " " $5 " " $6 " " $7 " " $8 " " $9}' | grep -q b8; if [ $? -eq 0 ]; then echo $file; fi; done
       
      The output will list the files containing the non-ASCII characters, which then can be edited out
       Note: SSL certificates are allowed to contain non-ASCII characters
    • Repack the QKView archive by typing, for example, the following command:

      tar czvf ../new_support.qkview *

  • Names of files present in the QKView file but too large for being displayed by iHealth are listed by iHealth in file "/skipped_files". If needed, these files can be extracted from the QKView file manually using syntax:

    tar -xvzf <QKView file> <target file>

    for example:
    tar -xvzf support.qkview asm_module.xml
