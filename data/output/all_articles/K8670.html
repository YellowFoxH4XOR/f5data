Known Issue

This is the result of a known issue. Some power supply modules on VIPRION platforms incorrectly report that a functioning power supply is not supplying power. When this issue occurs, the VIPRION LCD panel displays an alarm indicating that a power supply is not supplying power, and an error message that appears similar to the following example is logged to the /var/log/ltm file:

slot1/p4-1 emerg system_check[12005]: 010d0006:0: Chassis power supply 3 is not supplying power (status: 0): make sure it is plugged in.

F5 Product Development tracked this issue as CR98828 and it was fixed in BIG-IP LTM version 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists for VIPRION platforms that are running version 9.6.x software.

If you have a VIPRION platform that is reporting that a power supply is not supplying power, check the power supply status LED light on the front panel display. You should observe one of the following two conditions:

  • The system reports that a chassis power supply is not supplying power, and the power supply status LED light is green.
    In this case the power supply is functioning properly, and the LED alarm and error messages are false.
  • The system reports that a chassis power supply is not supplying power, and the power supply status LED light is orange.
    In this case the power supply is faulty, and should be replaced immediately.

If your VIPRION system has a power supply module that is either faulty or incorrectly reporting the power supply status, contact F5 Technical Support and request an RMA replacement for the faulty power supply.

Note: The VIPRION chassis ships with four power supplies. However, the system requires only two functioning power supplies to power four blades.
