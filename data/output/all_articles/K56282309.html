Issue

Old Behavior

In BIG-IP 12.x to 13.x, the COMPAT SSL stack is deprecated and contains no SSL ciphers by default. However, in these versions you can use ciphers that were previously available in the COMPAT SSL stack by adding the COMPAT keyword to the Ciphers field in the SSL profile. For example, the COMPAT+EXP string enables you to use export grade SSL ciphers.

New Behavior

Beginning in BIG-IP 14.0.0, F5 removed the COMPAT SSL stack and associated SSL ciphers from the Traffic Management Microkernel (TMM), and you can no longer use them in SSL profiles.

As a result of this change, the following keywords are no longer valid options in the SSL profile configuration:
COMPAT
SSLV2
RC2

Additionally, the following SSL cipher suites are removed from TMM and are no longer available for SSL connections:
EXP-EDH-RSA-DES-CBC-SHA
EXP-ADH-DES-CBC-SHA
EXP-RC2-CBC-MD5
EXP-ADH-RC4-MD5

F5 Product Development tracked this change as ID 677134.

Impact

  • SSL profiles that are configured to use ciphers from the COMPAT SSL stack are reset to use ciphers from the default SSL stack during the upgrade process, and an informational message that appears similar to the following example is logged to the /var/log/liveinstall.log file:

    info: WARNING:
    info:     ciphers in client-ssl profile /Common/<profile_name> has been
    info:     reset to DEFAULT from <compat_cipher_string>

    For example, the following message indicates that the upgrade script reset the string COMPAT+SSLV2 to DEFAULT while upgrading to BIG-IP 14.0.0:

    info: WARNING:
    info:     ciphers in client-ssl profile /Common/compat_profile1 has been
    info:     reset to DEFAULT from COMPAT+SSLV2

  • Client connections that use ciphers which were available only in the COMPAT SSL stack may fail.

Recommended Actions

Review the BIG-IP log files for error messages related to the SSL handshake, and look for messages that indicate that the cipher negotiated by the client and server is not supported in one of the SSL profiles. For information about troubleshooting SSL/TLS handshake failures, refer to K15292: Troubleshooting SSL/TLS handshake failures.
