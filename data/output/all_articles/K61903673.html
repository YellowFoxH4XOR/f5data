Topic

Old behavior

In BIG-IP APM 12.x versions, for each policy, you can configure the logging levels for each of the following access policy items:

  • Access policy
  • Per-request policy
  • Access control list (ACL)
  • Single sign-on (SSO)
  • Secure Web Gateway (SWG)
  • ECA

You can create a custom logging profile and then add the logging profile to individual access policies. This configuration method offers the advantage of keeping the quantity of log information low because you can apply verbose logging to specific policies as needed.

New behavior

Beginning in BIG-IP APM 13.0.0, you can configure logging levels for additional access policy items. The following is a complete list of the items you can configure:

  • Access policy
  • Per-request policy
  • ACL
  • SSO
  • SWG
  • ECA
  • OAuth
  • PingAccess profile
  • Virtual desktop infrastructure (VDI)
  • Endpoint management system

Impact

You can configure logging levels for these BIG-IP APM policy items using the Configuration utility rather than the TMOS Shell (tmsh).

Description

Recommended Actions

To configure logging settings for an access policy using the Configuration utility, perform the following procedures:

  • Configuring an access system logging profile
  • Applying a logging profile to an access profile
  • Removing a logging profile from an access profile

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the Configuration utility.

Procedures

Configuring an access system logging profile

Use this procedure to create a custom logging profile in which you can specify logging levels for BIG-IP APM policy items.

Impact of procedure: The Debug logging level produces large amounts of data, which may negatively impact performance. You should only select the Debug logging level on a production system when advised to do so by F5 Technical Support.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Overview > Event Logs > Settings.
  3. Click Create.
  4. Under General Information, type a name for the new profile.
  5. Select the Enable Access System Logs check box.
  6. Under Access System Logs, for Publisher, make sure the policy listed is the one you want to configure. If not, click the correct publisher in the list.
  7. Configure the logging level for each policy item. The default setting for each is Notice.

    Important: To ensure that the system populates BIG-IP APM session reports, you must configure items in the logging profile at the Notice-level or higher. For information refer to K44555523: BIG-IP APM session reports require access policy log level of Notice or higher.

  8. Click OK.

Applying a logging profile to an access profile

After you configure a custom BIG-IP APM logging profile with the logging levels you want, you apply the profile to the access profile.

Impact of procedure: Performing this procedure may increase the quantity of information recorded to the /var/log/apm file.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Profiles/Policies > Access Profiles (Per-Session Policies) or Per-Request Policies.
  3. Click the name of the profile to which you want to apply the logging profile.
  4. On the menu bar, click Logs.
  5. In the Available box, click the name of the logging profile you want to apply and move it to the Selected box.
  6. Click Update.

Removing a logging profile from an access profile

Important: To ensure that Notice-level logging data is recorded in the /var/log/apm file, you must keep the default logging profile applied to each access profile.

Impact of procedure: Performing this procedure may reduce the quantity of log data recorded in the /var/log/apm file.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Profiles/Policies > Access Profiles (Per-Session Policies) or Per-Request Policies.
  3. Click the name of the profile from which you want to remove the logging profile.
  4. On the menu bar, click Logs.
  5. In the Selected box, click the name of the logging profile you want to remove and move it to the Available box.
  6. Click Update.
