Description
F5 BIG-IP AFM Intrusion Prevention System (IPS) consists of two license parts, an IPS add-on module license, and an IPS subscription.
Protocol inspection subscription license requires the base license/add-on of Intrusion Prevention System to be fully functional. There will be no option to select Inspection Profiles once only the Subscription services license is deployed.

Environment

  • Licensing 
  • BIG-IP AFM
  • Intrusion Prevention System (IPS)

Cause
NA 

Recommended Actions

When planning to acquire IPS license/evaluation license, you should consider the following factors

The System has to be licensed with a base/add-on key for Intrusion Prevention System before IPS, 1Yr,/3 yr i2XXX / i4XXX(Subscription) becomes functional and relevant menu becomes available via the GUI eg. Security  ›› Protocol Security : Inspection Profiles
