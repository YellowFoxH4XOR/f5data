Topic

The Configuration utility provides information about hosts in two locations: the Hosts screen and the Hosts Statistics screen.

Hosts screen

The Hosts screen displays the following information:

Host Name
A descriptive name you provided when you configured the host.
Host IP address
The host's IP address.
Host Port
The host port that is probed by the 3-DNS.
Discovery
Indicates whether or not discovery and automatic configuration is enabled for the host.
Prober IP address
The IP address of the 3-DNS or BIG-IP that probes the host. When the Prober IP address is 127.0.0.1, the 3-DNS you are viewing is the prober.
Probe Protocol
The IP protocol that is used to probe the host. Available protocols are DNS_DOT, DNS_REV, ICMP, and TCP.

Hosts Statistics screen

The Hosts Statistics screen displays information in the following columns:

Server
Displays the status of the host in the form of a colored ball. A legend is provided at the top of the screen.
E/D
Indicates whether the host is enabled or disabled in the form of an arrow. An up arrow indicates the host is enabled, while a down arrow indicates that the host is disabled.
TTL
Displays the Time to Live (TTL) for the Host. The host is marked down if the TTL is 0.
Name
The descriptive name of the host.
Address
The IP address of the host.
VS Count
The number of virtual servers configured under the host.
Prober
The IP address of the 3-DNS or BIG-IP that probes the host.
Probe Protocol
The IP protocol that is used to probe the host.
Probe Port
The host port that the 3-DNS probes if the Probe Protocol is TCP or UDP.
Picks
The number of times 3-DNS has provided a DNS response containing a virtual server belonging to the host since the last reboot.
Agent
The type of SNMP service provided by the host. This setting is only used when you perform SNMP performance monitoring of non-F5 devices. This value will display n/a if SNMP monitoring is not configured.
Conn Rate
The current connection rate for non-F5 hosts that 3-DNS monitors with SNMP. This value will display n/a if SNMP monitoring is not configured.
Refreshes
The number of times the host has successfully responded to a probe.
Last Refresh
The last time 3-DNS successfully retrieved information from the host and refreshed the statistics. This value may display NULL_TIME if 3-DNS has never successfully probed the host.
