Description

Your ZoneRunner have 2 views which are:

  • view "internal"
  • view "external"
View List External is the default view.

A zone has both internal and external zone list where the Resource Record List is different. This is an expected behavior however the problem is when the Resource Record List for both internal and external zone is showing the same IP from the external zone list.

For example, you have a zone file for example.com on both view internal and external.
  • For domain test.example.com on the Internal zone has IP 10.10.10.10.
  • For domain test.example.com on the External zone has IP 192.0.0.1.
  • However when you navigate to DNS > Zones > ZoneRunner > Zone List and click example.com for either internal or external View it will show test.example.com has IP 192.0.0.1. This is not the correct behavior.
When navigating to DNS > Zones > ZoneRunner > View List, the order is seen that external view is above the internal view.

Environment

  • BIG-IP DNS/GTM ZoneRunner
  • Have both internal and external view for ZoneRunner View List
  • External view is above the internal view
  • Zone List for the same zone shows external zone list

Cause

This is the default configuration for the external view:
match-clients {
    "zrd-acl-000-000";
    any;                Note: "any" matches all source IP addresses
};

The default external view will match all IPs (match-clients any).

The internal view will match a specific subnet address such as 10.0.0.0/8.

Since the external view is above the internal view, it will match all IP address (match-clients any) thus internal and external Resource Record List will resolve the external Zone List.

Recommended Actions

To resolve this issue, you will need to move the internal view above the external view in the View List. This will ensure that IP addresses matches the internal view first before matching the external view.

  1. Login to the Configuration Terminal
  2. Navigate to DNS > Zones > ZoneRunner > View List
  3. Under View Name click external
  4. Under View Order, choose After and select internal
  5. Click Update
