Known Issue

The BIG-IP APM rewrite process may incorrectly rewrite HTML attributes.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system access profile uses a rewrite profile.
  • The BIG-IP APM system rewrites HTML content that includes HTML attributes containing the hyphen (-) character.

    For example:

    <script>
    document.write("<aa ng-style=z>");
    e = document.getElementsByTagNameaa')[0];
    alert(e.getAttributeng-style') === 'z
    </script>

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Web applications malfunction or fail to render properly in browsers.
  • Scripts on the dynamic HTML page fail to run.
