Topic

This article applies to BIG-IP systems that use GRUB 0.97. For information about other versions, refer to the following article:

  • K14663: Overview of the GRUB version 2 configuration file

This is an overview of the configuration file used by GRUB 0.97, which is implemented on BIG-IP systems.

To determine the version of the GRUB bootloader, refer to K14658: Determining the GRUB bootloader version on the BIG-IP, BIG-IQ, or Enterprise Manager system.

Description

GRUB is a boot loader that is responsible for loading and transferring control to the operating kernel software, such as Linux. The grub.conf configuration file contains a list of images and their loading parameters. GRUB reads this information to specify which image to load.

Note: Editing the grub.conf file directly can result in damage to the BIG-IP system. For information about how to edit the grub.conf file, contact F5 Technical Support.

Viewing the active grub.conf file

To view the contents of the GRUB configuration file, you can use the command grub_default. For BIG-IP 9.4.5 through 10.0.1, you can use the command grub_default_tm.

For example, to view the contents of the GRUB configuration, type the following command:

grub_default -d

Sample of the GRUB configuration content may appear similar to the following example:

default=0
timeout=5
serial --unit=0 --speed=19200
terminal serial

title BIG-IP 11.0.0 Build 8037.0 - drive sda.1
root (hd0,0)
kernel /boot/1/vmlinuz ro root=UUID=2c3f024c-ff84-499b-8466-0a189963c55d console=ttyS0 panic=1 platform=Mercury quiet
initrd /boot/1/initrd

# TIC_VS_PRODUCT: BIG-IP
# TIC_VS_VERSION: 11.0.0

For each title section, an entry on the GRUB menu will display as follows:

BIG-IP 11.0.0 Build 8037.0 - drive sda.1
BIG-IP 10.2.4 Build 577.0 - drive sda.2
End User Diagnostics
TMOS maintenance

Information contained in the grub.conf file

The information contained in the grub.conf file is specific to loading BIG-IP system images. The following table describes the components of the example output of the grub.conf file:

ComponentDescription
default=<Value>

A value of 0 in the previous example indicates the first entry of the kernel configuration, which is the title entry for BIG-IP 11.0.0 Build 8037.0 - drive sda.1. This is the default kernel for the BIG-IP system to boot up with.

The following entries indicate what image the system should load by the different default values:

  • default=1
    Second entry in the GRUB menu. In the previous example, it is BIG-IP 10.2.4 Build 577.0 - drive sda.2.
  • default=2
    Third entry in the GRUB menu. In the previous example, it is End User Diagnostics.
  • default=3
    Fourth entry in the GRUB menu. In the previous example, it is TMOS maintenance.
timeout=<Value>The timeout value specifies, in seconds, how long GRUB will wait for a user intervention before the system automatically boots the default=<Value> entry, according to the configuration in grub.conf.
serial --unit=<Value> --speed=<Value>The value for unit ranges from 0 (default value) to 3. The default value refers to COM1. Speed is the transmission speed or baud rate. The default value for speed is 19200.
terminal serialThis line specifies the terminal for user interaction. The default value is the serial port.
title <String>This line specifies a new boot entry and sets the boot entry's name. This information appears on the GRUB menu just as it appears in the title.
root (hd0,0)This line specifies the hard disk and partition location where the kernel is located. For example, root (hd0,0) refers to the first primary partition on the first hard disk.
kernel <Filename> <Parameters>

This line specifies the kernel file and the parameters to use on load, as in the following example:

kernel /boot/1/vmlinuz ro root=UUID=2c3f024c-ff84-499b-8466-0a189963c55d console=ttyS0 panic=1 platform=Mercury quiet

initrd <Filename>This line specifies the desired initial ramdisk (initrd) to use when loading the selected kernel entry. The initrd file loads an initial root file system to assist in the loading of a kernel.

Components of the kernel command entry in the GRUB configuration

The GRUB command kernel commonly contains a filename that indicates the kernel file and may contain some parameters that the system uses when loading the kernel.

For example:

kernel /boot/1/vmlinuz panic=1 quiet

The following table describes the components of the previous kernel specifications example:

Line componentSpecification
/boot/<Value>/vmlinuzSpecifies the kernel filename found on the partition. The value in this component is the boot location number. For example, the kernel file is named /boot/1/vmlinuz.
roSpecifies that the root device is mounted as read-only on boot.
root=UUID=<Value>Tells the kernel what device is to be used as the root filesystem while booting.
The UUID value depicts the unique identifier for this filesystem partition.
console=ttyS0Specifies the serial port to be used for console ttyS0=COM1.
panic=1Specifies the time, in seconds, that causes the kernel to reboot if it panics.
platform=<Value>Identifies the hardware platform identifier to the kernel.
quietDisables the log messages during the boot process.
