Topic

The upgrade instructions in the product release notes include upgrade instructions where F5 assumes an upgrade from a recent release. However, upgrading from an older, End of Life release to the latest supported software version in the 9.x branch may require a different upgrade path than that recommended in the release notes. In general, you should always upgrade to a General Availability release before upgrading to a General Sustaining release to ensure that any fixes made in the General Availability branch are incorporated in the upgrade.

The following section provides best practice guidelines for safely upgrading from an older version 9.x software release to the latest supported version 9.x releases:

Upgrading versions 9.0 through 9.0.4 to the latest 9.x General Sustaining release (9.3.x)

  1. Upgrade to version 9.1.3.
  2. Upgrade to the latest 9.x General Sustaining release (9.3.x).

Upgrading versions 9.0 through 9.0.4 to the latest 9.x General Availability release (9.4.x)

  1. Upgrade to version 9.1.3.
  2. Upgrade to the latest 9.x General Sustaining release (9.3.x).
  3. Upgrade to the latest 9.x General Availability release (9.4.x).

Upgrading versions 9.0.5 through 9.2.5 to the latest 9.x General Sustaining release (9.3.x)

F5 recommends upgrading directly to the latest 9.x General Sustaining release (9.3.x) from versions 9.0.5 through 9.2.5.

Upgrading versions 9.0.5 through 9.2.5 to the latest 9.x General Availability release (9.4.x)

  1. Upgrade to the latest 9.x General Sustaining release (v 9.3.x).
  2. Upgrade to the latest 9.x General Availability release (9.4.x). 

Upgrading version 9.3.x to the latest 9.x General Sustaining release (9.3.x)

F5 recommends upgrading directly to the latest 9.x General Sustaining release (9.3.x) from versions 9.3.x.

Upgrading version 9.3.x to the latest 9.x General Availability release (9.4.x)

F5 recommends upgrading directly to the latest 9.x General Availability release (9.4.x) from versions 9.3.x.

Important: Upgrading from 9.3.x to 9.4.x may result in disruption of traffic through high availability systems due to changes in the peer communication protocols and management interface configuration requirements. F5 recommends a local installation method for this upgrade path, and you should schedule a maintenance outage window.
