Known Issue

The diskmonitor utility may fail to monitor and provide disk warnings for the root partition.

The diskmonitor utility is a script that runs periodically on the BIG-IP system to monitor disk usage. The utility performs functions, such as monitoring disk usage growth rates on BIG-IP partitions, and sending warnings when the disk usage approaches critical levels. The default diskmonitor behavior is to scan the /etc/mtab for the appropriate file systems to monitor, and then create corresponding BigDB keys. In some cases, the diskmonitor utility fails to recognize the root partition as one that should be monitored when scanning /etc/mtab.

Impact

The BIG-IP system fails to properly monitor disk utilization for the root partition.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The tmsh command does not list a diskmonitor BigDB key for the root partition.

    For example:

    tmsh list /sys db platform.diskmonitor.monitor*

    sys db platform.diskmonitor.monitor.config {
    value "limit"
    }
    sys db platform.diskmonitor.monitor.dev_shm {
    value "limit"
    }
    sys db platform.diskmonitor.monitor.shared {
    value "limit"
    }
    sys db platform.diskmonitor.monitor.usr {
    value "growth"
    }
    sys db platform.diskmonitor.monitor.var {
    value "limit"
    }
    sys db platform.diskmonitor.monitor.var_log {
    value "limit"
    }
    sys db platform.diskmonitor.monitor.var_prompt {
    value "limit"
    }
    sys db platform.diskmonitor.monitor.var_run {
    value "limit"
    }
    sys db platform.diskmonitor.monitor.var_tmstat {
    value "limit"
    }
  • The BIG-IP system fails to generate warnings when the root partition disk usage approaches critical levels.
