Description

How to send the restjavad logs from BIG-IP or BIG-IQ to a remote logging server

Environment

  • BIG-IQ or BIG-IP
  • restjavad logs
  • syslog

Cause

When you enable remote logging on the BIG-IQ CM (under "System > Audit Log Syslog Servers"), it does not include the restjavad logs, even if all options are checked. 

Recommended Actions

You can configure the local syslog service to send these logs with the following commands:

Note: Just make sure that you modify the following syntax to replace "SERVER_IP_ADDRESS" with the actual IP address of your remote syslog server.  Also, if the syslog server is using a port other than 514, be sure to update the command with the correct port number (where "514" is currently located in the syntax).

  • If you want the logs to be sent by way of TCP:

    tmsh modify /sys syslog include "source s_restjavad {file(\"/var/log/restjavad.0.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));};destination remote_server {tcp(\"SERVER_IP_ADDRESS\" port (514));};filter f_alllogs {level (debug...emerg);};log {source(local);source(s_restjavad);filter(f_alllogs);destination(remote_server);};"

  • If you want the logs to be sent by way of UDP:

    tmsh modify /sys syslog include "source s_restjavad {file(\"/var/log/restjavad.0.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));};destination remote_server {udp(\"SERVER_IP_ADDRESS\" port (514));};filter f_alllogs {level (debug...emerg);};log {source(local);source(s_restjavad);filter(f_alllogs);destination(remote_server);};"

  • Save the change:

    tmsh save sys config

The values setting on the syslog-ng service for the parameters log-fetch-limit and log-iw-size are environment dependent. You can refer to the syslog-ng documentation for more information on the possible values for these parameters: https://www.syslog-ng.com/technical-documents/list/syslog-ng-open-source-edition/3.8

Additional Information

To return syslog configuration to the default (no configuration), issue the following command:

tmsh modify /sys syslog include none

To save the changes, once again issue:

tmsh save sys config
