K4280: Performance impacts of large configurations

Topic

BIG-IP uses high performance hash tables to match incoming traffic to configuration objects. Increasing the number of configuration objects will cause BIG-IP to consume more memory, but until you exceed 1000 configuration objects, response time should not significantly decrease.

Once you add more than 1000 configuration objects, BIG-IP response time may become slower depending on the hardware platform, the types of objects, and the amount of traffic.

If you intend to add a large number of objects to your configuration, F5 Networks recommends that you evaluate and optimize the configuration in a testing environment before using the configuration in a production environment.
