Description

You want to create and use persistent network or DNS DoS signatures on your BIG-IP AFM.

Environment

  • BIG-IP AFM
  • DoS Device Configuration or 
  • Network DoS Profile or
  • DNS DoS Profile

Cause 

After creating one or more custom network or DNS DoS signatures you will need to set the "State" and "Thresholds" in the DoS profile and/or the Device Configuration in order to use them.

Recommended Actions 

1. Navigate to DoS Signatures  
Security --> DoS Protection --> Signatures
2. Create custom persistent signature
Click "Add Signature", 
Select type from drop down(Network or DNS),
Name new signature and select the relevant "Predicates List" objects and click "Create".
3. Navigate to either Device Configuration or Network DoS profile
Device Configuration location "Security --> DoS Protection --> Device Protection” select “Network” or “DNS”
Network DoS Profile location "Security --> DoS Protection --> Protection Profiles --> select profile or click Create" 
4. Locate and select new custom DoS signature in related section
5. Click on custom DoS signature
6. Change state to desired stat, like “Mitigate” and set desired thresholds
7. Click “Commit Changes to “System”
