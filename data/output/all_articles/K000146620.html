Description

By default, when customer use Load Balancer, the request IP on the origin server will be SNAT IP of RE/CE that forwards the request.

What should I do if I want to see the client's IP on the origin server?

 

Environment

  • F5® Distributed Cloud Load Balancer
  • Distributed Cloud (SaaS)
  • SNAT

Resolution/Answer

All traffic that goes via Distributed Cloud to origin servers will use our SNAT IPs.

Client's IP address is added to request header, you can find it in HTTP header "X-Envoy-External-Address" that we add to all request originated from LB to origin server.
