Description

How to modify and update the cert and key of an existing SSL profile using Configuration Utility

Environment

  • LTM
  • Virtual Server
  • SSL profile

Cause

SSL certificate has expired, and new certificate is imported to the LTM

Recommended Actions

  1. Login to the Configuration Utility / WebUI
  2. Go to Local Traffic > Profiles > SSL > Client > click the clientssl profile
  3. Under Configuration > Certificate Key Chain > select the existing config and click Edit
  4. For the Certificate> select the new imported certificate. 
  5. Select the new Key and Chain cert from the available options if it has been added too.
