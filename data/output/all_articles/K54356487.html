Description
After applying new Device Certificate, browser continues displaying old certificate

Environment

  • BIG-IP system
  • Device certificate
  • Apache httpd process

Cause
The BIG-IP system did not automatically restart the configuration utility's Apache httpd process, therefore, it continues to use the old certificate.

Recommended Actions
Restart the httpd process.
Impact of the procedure: Restarting httpd should not have any impact to user traffic.

  1. Log in to BIG-IP command line
  2. Run the below command to restart httpd service
    #bigstart restart httpd
