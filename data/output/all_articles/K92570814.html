K92570814: Display wrong software version about peer device after software upgrade

Type
Support Solution
Published
2023-06-21
Updated
2025-04-02
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K92570814

Description

When you upgrade the HA group devices software version, you find peer device version still display old value at local device menu Device management > Devices > Devices List, but peer device has upgraded success and the synchronization status is In Sync, the software version value is correct at peer device menu Device management > Devices > Devices List. For example, when you upgrade the two device software version to 16.1. 2.2 from 16.1.2, the device version value still is 16.1.0 about peer device at local device, you also check the information at CLI.

  1. Check the sofware version information at local device ltm1.test.com
    tmsh list cm device ltm1.test.com
    cm device ltm1.test.com {
    ...
        platform-id Z100
        product BIG-IP
        self-device true
        time-zone America/Los_Angeles
        version 16.1.2.2
    } 
    tmsh list cm device ltm2.test.com
    cm device ltm2.test.com {
    ...
        platform-id Z100
        product BIG-IP
        time-zone America/Los_Angeles
    ...
        version 16.1.0                      <===wrong version
    }
  2. Check the sofware version information at peer device ltm2.test.com
    tmsh list cm device ltm1.test.com
    cm device ltm1.test.com {
    ...
        platform-id Z100
        product BIG-IP
        self-device true
        time-zone America/Los_Angeles
        version 16.1.2.2
    } 
    tmsh list cm device ltm2.test.com
    cm device ltm2.test.com {
    ...
        platform-id Z100
        product BIG-IP
        time-zone America/Los_Angeles
    ...
        version 16.1.2.2                 <===Correct version          
    }

Environment

  • Software upgrade 
  • Software version

Cause

Unknow.

Recommended Actions

This is cosmetic problem, it doesn't impact device running, and you can refer follow step solve the issue.

  1. login the peer device CLI, it has correct software version information,then perform follow command.
    tmsh run cm config-sync force-full-load-push to-group SYNC_GROUP_NAME
    Note:The command will force perform sync full configration to device group
  2. Then you can login the local device and check the peer device software version information,it should has fixed.
