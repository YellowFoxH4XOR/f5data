Topic

Beginning with BIND version 9.0, the root server list is built into the BIND executable. Therefore, BIND operates as expected without the hint zone file (root.hint file) on F5 products running BIND version 9.0 or later.

The following F5 products run BIND version 9.0 or later:

  • 3-DNS version 4.6.2 and above
  • BIG-IP version 4.6.2 and above
  • BIG-IP Link Controller versions 4.6.2, 9.2.2 and above
  • BIG-IP LTM version 9.0.0 and above
  • BIG-IP GTM version 9.2.2 and above
  • Enterprise Manager version 1.0.0 and above

Note: It is possible to configure BIND on the BIG-IP GTM system to use a custom hint zone that will override the built-in root server list. For more information, refer to K8380: Configuring a root.hint zone for use with BIG-IP GTM.
