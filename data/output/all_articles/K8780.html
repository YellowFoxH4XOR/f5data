Known Issue

This is the result of a known issue. F5 recommends that you do not modify the RAM Cache default values in the http-acceleration profile for the following settings:

  • RAM Cache
  • Minimum Object Size
  • Maximum Object Size
  • Ignore Headers

Modifying these settings may adversely affect the way the BIG-IP WebAccelerator system manages HTTP traffic.

F5 Product Development is tracking this issue as CR76031.

To view the RAM Cache settings for the http-acceleration profile, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. Click the http-acceleration profile.

The RAM Cache settings are located at the bottom of the http-acceleration profile configuration page.
