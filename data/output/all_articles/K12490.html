K12490: Diameter load balancing does not work when the virtual server is configured with the Diameter and SCTP profiles or the Diameter and SSL profiles

Known Issue

This is the result of a known issue. When you configure a virtual server to use Diameter and SCTP profiles or Diameter and SSL profiles, the BIG-IP system will create the virtual server and log error messages to the /var/log/ltm file that appear similar to the following example:

01010007:3: Config error: virtual_server_profile no suitable hudchain
01010007:3: Config error: add virtual server profile error

Although the BIG-IP system creates the Diameter virtual server successfully, the virtual server does not load-balance Diameter traffic.

The following configuration example displays that a Diameter virtual server configured with IP address 172.28.21.209 is associated with the my-diameter-proto Diameter profile and the my-sctp-proto SCTP profile:

virtual my-diameter-vs {
pool my-diameter-pool
destination 172.28.21.209:diameter
ip protocol sctp
profiles {
my-diameter-proto {}
my-sctp-proto {}
}
}

F5 Product Development tracked this issue as ID 345359 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM release notes. In addition, BIG-IP iHealth may list Heuristic H383274 on the Diagnostics > Identified > Medium screen.

Workaround

You can work around this issue in BIG-IP versions 10.1.0 and later by editing the filter constraints for Diameter. To edit the filter constraints, perform the following procedure:

  1. Log in to the command line using a privileged account, such as root.
  2. Back up a copy of /config/tmm_base.tcl by typing the following command:

    cp -p tmm_base.tcl tmm_base.tcl.sol12490
  3. Edit /config/tmm_base.tcl using a text editor.
  4. Locate the following line under the section for filter constraints:

    constrain DIAMETER require TCP4 preclude {HTTP FTP SIPP RTSP} above {TCP4 SSL HASH ISESSION}
  5. Edit the line to remove require TCP4 and insert SCTP to the final braces.

    The final result must appear as follows:

    constrain DIAMETER preclude {HTTP FTP SIPP RTSP} above {SCTP TCP4 SSL HASH ISESSION}
  6. Save the changes to the file.
  7. Restart the BIG-IP system by typing the following command:

    full_box_reboot
