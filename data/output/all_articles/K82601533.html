Known Issue

Internet Content Adaptation Protocol (ICAP) chunk parser does not perform as efficiently as possible with very large chunks. When an ICAP response contains a very large chunk, the BIG-IP system buffers the entire chunk and reevaluates the amount of data received as each new packet arrives. In extreme cases, CPU usage can reach 100 percent while the parser is handling large chunks.

This issue occurs when the following condition is met:

  • ICAP server returns a large payload entirely in a single chunk or otherwise generates very large chunks (in the megabytes to gigabytes range).

Impact

Memory exhaustion may result in degraded performance or interruptions in traffic processing.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe increased memory usage. In extreme cases, you observe high CPU usage up to 100 percent as the parser handles large incoming ICAP packets.
