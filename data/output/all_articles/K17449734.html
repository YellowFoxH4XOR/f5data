Description

Traffic is not being evenly load-balanced amongst the Wide-IP pool's members (GSLB virtual servers).

Environment

  • BIG-IP DNS
  • Wide-IP has persistnece enabled.
  • The Wide-IP's pool contains more than one member (virtual server)

Cause

Persistence is enabled on the Wide-IP.  This can give the appearance of incorrect load-balancing distribution.

Recommended Actions

Evaluate whether or not persistence should remain enabled.

Additional Information

  • Persistence is a rarely used feature but will cause uneven load balancing.  
  • BIG-IP DNS is intended to load balance LDNS requests.  The LDNS device is the client to DNS units.
