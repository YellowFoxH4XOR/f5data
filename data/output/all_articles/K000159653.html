Description

How to correctly add records bigger than 255 characters to F5 Distributed Cloud DNS Management.

Environment

  • F5 Distributed Cloud (XC)
  • DNS Management
  • TXT records (SPF, DKIM, DMARC)
  • Records exceeding 255 characters requiring splitting

Cause

F5 Distributed Cloud DNS Management automatically adds quotation marks to TXT records and escapes any quotes already present in the record data with backslashes. This behavior is related to how the system parses and processes TXT records, particularly when handling special characters and automatically splitting records exceeding 255 characters.

Recommended Actions

Enter record without any quotes and allow our DNS system to split it. 

Example Long record:

TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD 255 CHARACTERS

 

Our DNS will split it to parts after 255 characters. Response will look like this: 

  3600    IN      TXT     "TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD TEST LONG RECOORD 255" " CHARACTERS"

 

Verification Steps:

  1. After configuring the TXT record in XC DNS Management, test using dig:

dig @ns1.f5clouddns.com ~<domain> TXT

  1. Verify the response

Additional Information

  • F5 Distributed Cloud DNS Management does not currently support custom splits with double quote marks (") for TXT records exceeding 255 characters
  • Quotes already present in the record data are escaped with backslashes (\) during processing
