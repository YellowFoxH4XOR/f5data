Description

Some Request logs are missing on GUI but found fin the MySQL database.

To find request logs from the MySQL database, refer to K06821426: Viewing BIG-IP ASM request logs from MySQL database
 

Environment

  • Filtered the logs using Support ID
  • Event Logs missing logs

Cause

There is a flag known as flg_display that is set when logging requests.

When flg_display: 1 - Display on GUI ( Event Logs ) 
When flg_display: 0 - Do not display on GUI ( Event Logs )

Therefore, when Support ID is used to search for the log on the GUI, it appears it is missing.

Note: The flg_display setting cannot be changed. It is set by the ASM.
 

Recommended Actions

None.
 

Additional Information

There are certain condition under which the flg_display may set to 0

  • This was created/stored only for traffic learning
  • Automatic policy builder learnt and accepted the suggestion
  • The virtual server did not have logging profile at the time this was generated, or was in the middle of profile change
You will find many similar logs that will not be displayed on the GUI, and some of the reasons are:
  • Excessive logging
  • asmlogd/ pabnagd daemon malfunctions
  • Unexpected failures
