Description

When a HTTP Analytics profile is attached to a virtual server, the BIG-IP Analytics and Application Visibility and Reporting (AVR) module inserts a user session cookie into an HTTP response to collect user sessions as a collected metric.


Environment

  • Browser Developer tool show 'f5avraaaaaaaaaaaa'
  • User Session Setting enabled in the HTTP Analytics Profile

Cause

Functioning as Designed.
 

Recommended Actions

The name of the default AVR cookie can be changed to a preferred name using the following steps.
  1. Log in to the BIG-IP via SSH
     
  2. To list the default name of the AVR cookies, run the command:

    tmsh list sys db avr.cookieprefix

    The output should appear as:

    sys db avr.cookieprefix {
    value "f5avr"
    }
     
  3. To modify the AVR cookie name, run command:

    tmsh modify sys db avr.cookieprefix value abc 

    ( where abc is the new name )
     
  4. To verify the new AVR cookie name, run the command:

    tmsh list sys db avr.cookieprefix

    The output should appear as:

    sys db avr.cookieprefix {
    value "abc"
    }
     
  5. Save the configuration using the command:

    tmsh save sys config
