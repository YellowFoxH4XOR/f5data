K26802463: ProfileMultiplex not taking empty value

Type

Published
2021-09-29
Updated
2026-08-11
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K26802463

Description

You are attempting to remove the OneConnect profile, declared as ProfileMultiplex in the AS3 template, from a BIG-IP configuration, but are unable to submit an empty value

Environment

  • BIG-IQ GUI
  • AS3 Template

Cause

The application template has option included, so setting a value is required

Recommended Actions

Modify the application template to remove the profileMultiplex option as a required field
  1. Navigate to the Application Template and verify that the Multiplex profile is set to Editable
  2. Review the template configuration in the JSON Detail section to verify the profileMultiplex option is currently present
  3. Navigate back to the Application Template, and uncheck the Editable box for the Multiplex profile

None
