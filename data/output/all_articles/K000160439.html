Description

Occasional tmsh error logs can be seen:

Can't open command history file (/root/.tmsh-history-root), Permission denied: framework/CmdHistoryFile.cpp, line 92

Environment

  • BIG-IP AWAF
  • Threat Campaign updates licensed

Cause

These messages occur when the system updates Bot-Signatures, and does not have permission to write to the tmsh history file for the root user /root/.tmsh-history-root.

The Bot-Signatures are updated, but the updates to the configuration are not immediately saved to mcpd. If mcpd restarts before the configuration is later saved, bot signatures may be reverted to prior to the update.

Bug ID 919917: File permission errors during bot-signature installation

Answer/Recommended Actions

An Engineering Hotfix for ID919917 can be requested from F5 Support.
