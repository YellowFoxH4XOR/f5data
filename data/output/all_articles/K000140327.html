K000140327: How to Renew the BIGIP Self-Signed Device Certificate using the CLI

Description

You want to renew the BIG-IP device self-signed certificate using the CLI.Environment

  • GUI not loading
  • SSH is working
  • Device certificate/key has been updated

Recommended Actions

Use the below to generate a new self-signed device certificate and private key to gain the GUI access

# openssl req -x509 -nodes -days <number> -newkey rsa:<keysize> -sha256 -keyout /config/httpd/conf/ssl.key/server.key -out /config/httpd/conf/ssl.crt/server.crt

For example, the following command creates a self-signed certificate with 2048 key size valid for 10 years:

# openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -sha256 -keyout /config/httpd/conf/ssl.key/server.key -out /config/httpd/conf/ssl.crt/server.crt

Followed this it will ask you for few more details as shown below

Country Name (2 letter code) [XX]:
State or Province Name (full name) []:
Locality Name (eg, city) [Default City]:
Organization Name (eg, company) [Default Company Ltd]:
Organizational Unit Name (eg, section) []:
Common Name (eg, your name or your server's hostname) []:
Email Address []:

Once completed, restart the httpd service with command:

bigstart restart httpd
