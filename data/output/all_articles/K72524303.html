Description

Support for dynamic CRL checking for clientSSL profile was introduced in v15.1.0, however TLS1.3 is not working.

Environment

  • BIG-IP
  • Dynamic CRL checking for client certificate authentication
  • TLS1.3

Cause

ID944381

Recommended Actions

You may enable the use of TLS1.2 instead of TLS1.3.

None
