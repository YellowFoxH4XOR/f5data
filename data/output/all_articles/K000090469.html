Description

If an AS3 Application Service is manually removed from BIG-IP, orphaned objects related to the Application Service can be left behind.

The BIG-IQ GUI will not let these be modified or deleted and will show a banner for the object similar to the following:

"This belongs to BIG-IQ application <ASN> and cannot be changed."

Note: <ASN> is the Application Service Name.

Environment

  • BIG-IQ
  • Applications with orphaned objects

Cause

This may be caused when configuration objects are manually removed on a BIG-IP and the Application is manually removed from the BIG-IQ

Recommended Actions

The BIG-IQ rest API must be used to remove these orphaned objects associated with an ASN.

  1. Log on to the command line of the affected device.
  2. Set Application Service Name name in a variable.
  3. Set variable to hold the ASN name:

    ASN_name=<Application Service Name>
    Note: Replace <Application Service Name> with the actual ASN name.

  4. Important: Make a backup of BIG-IQ:

    tmsh save sys ucs b4_clean_ASN_${ASN_name}_objects

  5. Create a file of URIs that will be used to search for related objects:

    restcurl cm/ | grep 'working-config\/ltm' | cut -d '/' -f 5- | tr -d '"' >/var/tmp/search_uris.txt

  6. Create an empty file:

    echo -n > /var/tmp/${ASN_name}_selfLinks.txt

  7. Run the single line command below to create a file of selfLink of objects:

    while read LINE ; do restcurl ${LINE} | jq ".items[] | select(.subPath == \"${ASN_name}\")| .selfLink" | tr -d '"' ; done < /var/tmp/search_uris.txt | cut -d '/' -f5- | tee /var/tmp/${ASN_name}_selfLinks.txt
    Note: This may take several minutes.

  8. Delete the orphaned Application Service Name objects:

    while read LINE ; do restcurl ${LINE} -X DELETE ; done < /var/tmp/${ASN_name}_selfLinks.txt
    Note: This will produce some errors due to some object dependencies.

  9. Run the delete command a second time:

    while read LINE ; do restcurl ${LINE} -X DELETE ; done < /var/tmp/${ASN_name}_selfLinks.txt
    Note: There will be errors for the object that were deleted in the first run and are now missing.
