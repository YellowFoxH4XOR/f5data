K000136016: Attempting to attach new iRule, receiving an error - /Common/HSSR::http_req(rule::procedure) cannot be found.

Description

You receive an error in the configuration utility that some fields of the new iRule are incorrect. After checking the LTM logs, you see the following error message:

  • 010716ac:3: /Common/HSSR::http_req(rule::procedure) cannot be found.

Note: The HSSR iRule implements a nifty HTTP client 'http_req' using SIDEBAND. It handles challenges like redirects and cookies (lets you access APM- protected services!), IPv6, chunked transfer-coding, easy HTML forms, and Basic AuthN.

Note: For more information regarding SIDEBAND connections refer to the SIDEBAND article on F5 Cloud Docs.

Environment

  • BIG-IP LTM
  • iRule using SIDEBAND
  • iRule that attempts to create a sideband connection using http_req

Cause

Missing iRule HSSR in the configuration.

Recommended Actions

Create or copy the HSSR iRule in use on the previous device to the new device, in this way the SIDEBAND iRule will call it. 

Additional Information

HTTP Super SIDEBAND Requestor (Client) Handles Redirects, Cookies, Chunked Transfer, APM Access, etc
