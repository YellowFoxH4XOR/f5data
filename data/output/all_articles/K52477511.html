Description
This article provides the instruction on how to move or migrate a VCMP guest from one blade to another in a multi-blade Viprion. 

Environment

  • VCMP
  • Viprion
  • BIG-IP LTM

Cause
None

Recommended Actions

Important Note: 

  • F5 recommends that before making any changes to your systems, you back up each system e.g. both VCMP host and guest, and store the backup in a remote and secure location. For information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive.
  • Ensure there is enough disk free space on the /var/ and /shared/ partitions. For information, refer to K14403: Maintaining disk space on the BIG-IP system.
  • Ensure the password of the root account is not expired, see K13121: Changing system maintenance account passwords (11.x - 16.x)

Here are the steps: 

  1. In the VCMP Host Configuration Utility/GUI, under vCMP > Guest List, select the guest and change its state to Configured, see K20081511: Shutting down and restarting the vCMP guest from the vCMP host. This will automatically shut down the VCMP guest.
  2. In the VCMP Host's CLI (bash shell), monitor the VCMP guest is totally shutdown, run the command below and ensure the desired VCMP guest does not appear in list anymore: 
       watch -n1 tmsh show vcmp guest 
    To terminate this command, press CTRL+C.
  3. Go back to VCMP Host Configuration Utility/GUI, under vCMP > Guest List, select the guest and remove its current slot and add its new slot.
  4. Change the Minimum Number of Slots according to the number of slots you assigned to the VCMP guest. For more information, see Manual Chapter : Initial vCMP Configuration Tasks.
  5. Change the state of the VCMP guest to Deployed.
  6. Run the command provided in step 2 to monitor the VCMP guest; it is ready when the VCMP guest status shows running.

Note: These steps will not preserve the guest configuration. The previously saved UCS should be used to install the configuration. For more information, refer to K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
