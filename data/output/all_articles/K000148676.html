K000148676: Use REST API to query and load Advanced WAF Policy History files

Description

  • Use REST API to query and load Advanced WAF Policy History files

Environment

  • ASM provisioned
  • Want to use REST API to restore policy history

Cause

N/A

Recommended Actions

  1.  Query the list of ASM policies to get the hash for the ASM policy:
    $ curl -sku username:password  https://[bigip-mgmt-ip-or-hostname]/mgmt/tm/asm/policies?\$select=name,id | jq '.'
  2. Query the list of policy history files using the policy hash from step 1 to identify the hash for the history file you want to use:
    $ curl -u username:password -X POST -vk https://[bigip-mgmt-ip-or-hostname]/mgmt/tm/asm/policies/[policy-hash-from-step-1]/history-revisions?$orderby=activatedAtDatetime+desc&$skip=0&$top=100 | jq .
  3. Call the import-policy task with the policy hash and history hash in a json payload.
    $ curl -u username:password -X POST -vk https://[bigip-mgmt-ip-or-hostname]/mgmt/tm/asm/tasks/import-policy --data-raw '{"policyReference":{"link":"/mgmt/tm/asm/policies/[policy-hash]"},"historyRevisionReference":{"link":"/mgmt/tm/asm/policies/[policy-hash]/history-revisions/["}}' | jq .
  4. Query the link returned in the response from step 3 to observe the status of the task.
