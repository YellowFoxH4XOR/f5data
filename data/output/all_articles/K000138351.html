Description

On the event-log.log file, or on the output for show system events, you can see the below messages, what are these?

  • Firmware update is running for ...
  • Firmware update completed for ...

Environment

  • F5OS-C / F5OS-A
  • Event Logs

Cause

When the system reboots, these events are logged. For example, a blade reboot on VELOS.

Recommended Actions

The actual meaning of this log, is not "update", but "loading".
You can safely ignore these events.

Additional Information

Bug ID 1209729, this is to log Event for "reboot", and fixed in v1.6 and later

e.g
65550 blade-x firmware-update-status EVENT NA "Firmware update is running for atse 0" "day-time UTC" 65536 blade-3 hardware-device-fault EVENT NA "Deasserted: CPU machine check error" "day-time UTC"
NOTE:  Notice the "Deasserted", which means this is the intended state, so it can be safely ignored.
65550 blade-3 firmware-update-status EVENT NA "Firmware update completed for atse 0" "day-time UTC"
65550 blade-3 firmware-update-status EVENT NA "Firmware update is running for vqf 0" "day-time UTC"
