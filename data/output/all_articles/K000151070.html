K000151070: The device certificate changed automatically after an upgrade

Type
Support Solution
Published
2025-04-28
Updated
2025-04-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151070

Description

After a software upgrade, the device certificate got reverted an older certificate. Though device certificate wasn't changed recently.

Environment

  • A BIG-IP software upgrade
  • There are other .crt files present under the /config/httpd/conf/ssl.crt/ folder

Cause

After an upgrade the old .crt file from under the /config/httpd/conf/ssl.crt/ folder got installed.

Recommended Actions

  1. Re-install the new certificate. 
  2. Delete all other certificate files from /config/httpd/conf/ssl.crt/ folder leaving only the server.crt file
  3. To prevent this from happening in future, always use recommended methods to renew/import the device certificate.
Note: After deleting other .crt files, a restart of httpd may be required using "bigstart restart httpd" command from bash.
