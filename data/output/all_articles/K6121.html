Known Issue

This is the result of a known issue. If you add a new member to a SNAT pool in the BIG-IP LTM system, the timeout values that are configured for members of the SNAT pool are reset to the default timeout value.

F5 Product Development tracked this issue as CR53064 and it was fixed in BIG-IP LTM 9.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

To work around this issue, perform the following procedure:

Important: The following procedure requires you to edit configuration files manually. If you are not comfortable manually editing configuration files, contact F5 Technical Support for assistance.

  1. Log in to the command line.
  2. Using a text editor, edit the /config/bigip.conf file.
  3. Following the word member, add the new SNAT translation IP address.
  4. Save the file and exit the editor.
  5. Load the configuration by typing the following command:

    bigpipe load
