Known Issue

The Traffic Management Microkernel (TMM) process may leak memory with some Secure Sockets Layer (SSL) forward proxy configurations.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with the SSL Forward Proxy feature.
  • The virtual server is attached to an iRule that has all of the following events and actions:

    • CLIENT_ACCEPTED event that does a TCP::collect command
    • CLIENT_DATA event that does a TCP::release command
    • CLIENTSSL_CLIENTHELLO event that does an SNI lookup

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system may temporarily fail to pass traffic.
