K34358612: Access Policy agents sending more than 4096 bytes of data to Clients can result in access failure

Description
Certain Access Policy agents can be configured such that additional information is transmitted to the connecting Client. At present, the maximum amount of data APM can transmit to a Client during an Access Policy agent execution is 4096 bytes. 
If APM attempts to transmit more than 4096 bytes of data during an Access Policy agent execution, the Client's connection to the BIG-IP can timeout or be reset.

Environment

  • BIG-IP APM
  • BIG-IP V12.x and V13.x 
  • URL with request size more than 4096 bytes

Cause
Bug ID 695985: Access HUD filter has URL length limit (4096 bytes)

Recommended Actions

The best option for ensuring Clients are able to complete Access Policy evaluation is to keep the amount of data transmitted by each agent of an Access Policy to less than 4096 bytes.
