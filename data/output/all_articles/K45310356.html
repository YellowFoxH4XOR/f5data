Description

  • In certain instances attempts to delete a static subscriber created on the BIG-IP PEM fails
  • Following messages are logged
    err mcpd[4695]: 01070635:3: The static subscriber (/Common/john_smith) is referenced by one or more pem global-settings.
    err mcpd[4695]: 01070635:3: The static subscriber (/Common/jane_jones) is referenced by one or more pem global-settings.
Environment
  • BIG-IP PEM
  • Deleting static subscriber

Cause

  • PEM global settings associated with subscriber need to be removed prior to deleting subscriber

Recommended Actions

  1. List the PEM subscriber global settings
    For example subscriber(s) have the global-setting subscriber-activity-log applied to the subscribers

    user@(pem1)(cfg-sync Standalone)(Active)(/Common)(tmos)# list pem global-settings subscriber-activity-log
    pem global-settings subscriber-activity-log {
        static-subscriber-ids {
            jane_jones
            john_smith
        }
    }

  2. Disassociate relevant global settings from subscriber.  For example:

    user@(pem1)(cfg-sync Standalone)(Active)(/Common)(tmos)# modify pem global-settings subscriber-activity-log static-subscriber-ids none

  3. Delete subscriber

    user@(pem1)(cfg-sync Standalone)(Active)(/Common)(tmos)# delete pem subscriber [enter name]
