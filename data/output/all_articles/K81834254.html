Known Issue

A zone transfer interruption may cause the zxfrd process to restart and produce a core file.

This issue occurs when all of the following conditions are met:

  • An active zone transfer experiences an interruption, such as a network outage, between the BIG-IP system and the DNS server.
  • During the interruption, the DNS server is removed from the DNS zone configuration.

Impact

The BIG-IP system may temporarily fail to process DNS zone transfers, and the DNS Express features does not function as expected as it recovers from the zxfrd restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system temporarily fails to process DNS zone transfers, and the DNS Express features does not function as expected as it recovers from the zxfrd restart.
  • The BIG-IP system generates a zxfrd core file to the /shared/core directory, which includes a time stamp that correlates to the interruption.
