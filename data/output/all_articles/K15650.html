Known Issue

Attempting to update an existing SNAT pool that contains a resolved host name will result in an error.

This issue occurs when all of the following conditions are met:

  • The Display Host Names When Possible option is enabled.
  • You attempt to update an existing SNAT pool.

Impact

Users cannot update SNAT pools that a contain resolved host name as a member.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe an error message in the Configuration utility and in the /var/log/ltm file that appears similar to the following example:

    01020059:3: IP Address :: is invalid, must not be all zeros
  • The requested update to the SNAT pool will not occur.

Workaround

To work around this issue, you can temporarily disable the Display Host Names When Possible option before making a change to a SNAT pool. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility as the administrative user.
  2. Navigate to System > Preferences.
  3. Clear the check box next to the Display Host Names When Possible option.
  4. To save the changes, click Update.
  5. Make necessary changes to your SNAT pool.
  6. Repeat steps 2 through 4, and reselect the check box next to the Display Host Names When Possible option to enable the host name feature.
