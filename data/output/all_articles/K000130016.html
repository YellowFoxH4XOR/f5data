Description

The BIG-IP CLI prompt appears similar to the following:

bash-4.2#

Additionally, it is not possible to switch to tmsh:

bash-4.2# tmsh
exception: (Can't open command history file (/root/.tmsh-history-root), No such file or directory)
(framework/CmdHistoryFile.cpp, line 92), exiting...

Environment

  • CLI
  • Bash
  • tmsh

Cause

This can happen if the user's home directory or .bashrc is missing.

Recommended Actions

Confirm if the user's home directory is present (for root, that would be /root), and that the .bashrc file is present inside it.

If the directory is present, then further investigation is required.

If the directory is missing, consider if there is a possibility the system was compromised, or a user ran destructive commands. In that case, a clean install is advisable.

Alternatively, to re-create the home directory for a user, populating it with the default shell files from /etc/skel, issue the following command:

mkhomedir_helper <user>

For root, an additional step is required:

mv /home/root /root
