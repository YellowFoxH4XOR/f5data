Known Issue

A trunk port configuration may prevent the referenced interface module from being recognized.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP device uses a 40 Gigabit Ethernet (GbE) module.
  • You disable the 40 GbE interface bundle setting.

Impact

None. This cosmetic issue does not impact functionality.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the /var/log file, you observe messages that appear similar to the following example:

    info bcm56xxd[<pid>]: 012c0012:6: 4/5.1 QSFP part OPT-0025 does not support DDM.
    warning bcm56xxd[<pid>]: 4: _f5optics_validate:Port 4/5.1 not in the list of module valid ports
    warning bcm56xxd[<pid>]: 4: _f5optics_validate:f5optics does not recognaize module in 4/5.1 as F5 branded
    err bcm56xxd[<pid>]: 012c0021:3: Unsupported optic in interface:4/5.1.  See support.f5.com SOL8153 for restrictions on third-party hardware components.
    info bcm56xxd[<pid>]: 012c0015:6: Link: 4/5.1 is UP
    info bcm56xxd[<pid>]: 012c0015:6: Link: 4/5.2 is UP
    info bcm56xxd[<pid>]: 012c0015:6: Link: 4/5.3 is UP
    info bcm56xxd[<pid>]: 012c0015:6: Link: 4/5.4 is UP
