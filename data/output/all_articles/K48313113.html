Description

No Traffic or Event logs displayed in the GUI for ASM.

  • No Event logs
  • No Traffic learning suggestions

Environment

  • ASM
  • Virtual server with ASM policy
  • ASM policy in Transparent mode.
  • Local logging profile assigned to virtual server

Cause

Processes may be hung or handler is in a Start, Stop phase.

Recommended Actions

Restart these services.

pkill -f asm_config_server
pkill -f asmlogd
pkill -f pabnagd

Note: Traffic on the device is not impacted when restarting these services for ASM.

Additional Information

Check hard drive to make sure asmdata1 or appdata isn't full.
df -h
