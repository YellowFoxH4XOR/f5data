Issue

Description

Log messages indicated that syncookie protection, hardware or software, is triggered prior to configured value defined by default-vs-syn-challenge-threshold.

Environment

  • BIG-IP
  • HW Syncookie protection activated log messages
  • SW Syncookie protection activated log messages

Cause

Configuration value stored in default-vs-syn-challenge-threshold is divided by the number of tmm threads in the system, this value is used to set the syncookie cache threshold per tmm. Example, default-vs-syn-challenge-threshold=11996 and there are 4 tmm threads, 11996/4=2999. Each tmm would have a max syn cache threshold of 2999, after this value is exceeded HW or SW syncookies protection is triggered for that tmm thread.

Recommended Actions

Review requirements and set default-vs-syn-challenge-threshold to value per tmm thread.
