Description

httpd_sam[24329]: [ssl:warn] [pid 24329] AH01873: Init: Session Cache is not configured [hint: SSLSessionCache]

 

Environment

  • BIG IP
  • APM provisioned

 

Cause

The error is generated by httpd_sam, and it appears to occur when APM is provisioned. ​The httpd_sam is used to serve BIG-IP-generated user-facing HTML pages, such as Login pages, to connected users.

When the SSL session cache isn't used, the SSL handshake that must be performed to establish an SSL connection carries overhead. As such, caching the session data to avoid this initialization step for further requests can potentially avoid this penalty.

Recommended Actions

This is a warning message, not an error and there is no service impact.
