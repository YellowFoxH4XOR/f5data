Known Issue

This is the result of a known issue. At the end of March 2009, Symantec issued an update for Norton Internet Security 2009 (version 16.5.x). This update is not compatible with certain features of the Windows antivirus checker pre-logon inspector. As a result, users running the updated version of Norton Internet Security 2009 may fail the antivirus pre-logon check due to the following issues:

  • The Windows antivirus checker detects that Norton Internet Security 2009 is installed but it cannot detect whether real-time protection (RTP) is enabled.

    Note: RTP corresponds to the Monitor is running action in the pre-logon sequence.
     
  • The Windows antivirus checker cannot detect the database age of Norton Internet Security 2009.

    Note: The database age is configured in the Database is not older than (in days) field in the Windows antivirus checker configuration.

F5 Networks Product Development tracked this issue as CR118871 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in OPSWAT 2.5.18 Update (HF-119205-1). You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Networks Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
