Description

You can export all the ASM policies created on a BIG-IP at same time using an script. This article provides a way to achieve this task.

Environment

  • BIG-IP ASM
  • Security Policies

Cause

NA

Recommended Actions

1 - Move to the destination folder where you would like to store the policies ( i.e. cd /var/tmp )

 

2 - Run the following command to create a list of your policies in a text file

 

tmsh list asm policy \* one-line | cut -d " " -f 3 > policies.txt

 

3 - Run the following command to export the policies.

 

for i in $(cat policies.txt); do echo $i; tmsh save asm policy $i xml-file $i.xml; done

 

Note: You should get the XML files for all the policies once the script is completed.
