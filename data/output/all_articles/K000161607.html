K000161607: How to check the user who deleted the files from the GUI on BIG-IQ

Type
Support Solution
Published
2026-06-05
Updated
2026-06-05
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.1
Source
https://my.f5.com/manage/s/article/K000161607

Description

Unable to determine who deleted a scripts files on BIG-IQ because deletion events were not captured in CLI-accessible logs. Audit logs for script creation and deletion are stored in the internal database and are visible through the BIG-IQ GUI.

Environment

  • Product: BIG-IQ
  • Version: 8.4.1
  • Feature: Audit Logging, Script Management

Cause

Audit events for script creation and deletion are stored in the BIG-IQ database and are only visible in the GUI.

Answer/Recommended Actions

Review audit logs for script deletion events using the BIG-IQ GUI.

Additional Information

None
