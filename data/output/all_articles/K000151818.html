K000151818: Unexpected reboot/failover occurred due to FCS Errors

Type
Support Solution
Published
2025-06-12
Updated
2025-07-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151818

Description

  • BIGIP device rebooted unexpectedly, and all of these conditions are met:

boot_marker[8509]: ---===[ HD1.1 - BIG-IP 17.1.2.1 Build 0.0.2 <HD1.1> ]===---

  • NIC_FAILSAFE log:

1140029:4: HA nic_failsafe tmm0 fails action is reboot.

  • HSB log:

warning tmm[29311]: 01010031:4: Device warning: hsb hgm_fcs_errs[0] exceeds 1000

  • Flapping interface logs:

bcm56xxd[13815]: 012c0015:6: Link: 19.1 is UP

bcm56xxd[14431]: 012c0015:6: Link: 19.1 is DOWN

These symptoms highlight the presence of FCS (Frame Check Sequence) errors, which can trigger a High-Speed Bridge (HSB) reset. 

Environment

BIGIP LTM

 

Cause

BUG ID 1322517

 

Recommended Actions

To verify hardware health and pinpoint any potential issues with hardware, run an EUD
