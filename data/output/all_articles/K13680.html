Topic

This article applies to BIG-IP APM 10.x. For information about other versions, refer to the following article:

  • K15271: Removing the home tab from a portal access resource item

You should consider using this procedure under the following condition:

  • You want to remove the home tab from all pages of a portal access web application.

Description

The BIG-IP APM system allows you to remove the home tab from all web resources accessed through a portal access web application. The home tab is an overlay that displays a Logout button, Home button, and a field for the user to enter a direct URL. The Home Tab option only affects web hosts defined in the Destination field of the resource item. You can use a wild card to set the home tab option to affect all resources defined in the web application Webtop.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have a BIG-IP APM system configured with a portal access web application.
  • The web application resource is configured to use Full Patching.

Procedures

Configuring a web application resource item to remove the home tab for all web resources accessed through a portal access web application

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
  3. Click Web Applications.
  4. Click the name of the web application from which you want to remove the home tab.
  5. Click Add.
  6. In the Host Name box, enter an asterisk.

    For example:

    *

  7. In the Port box, enter zero.

    For example:

    0

  8. In the Paths box, enter an asterisk.

    For example:

    *

  9. From the Resource Item Properties menu, select Advanced.
  10. Clear the Home Tab option.
  11. Click Finished.
  12. Click Apply Access Policy.
  13. Click Apply Access Policy.
