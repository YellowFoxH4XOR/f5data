Known Issue

This is the result of a known issue. When an administrator modifies the BIG-IP host name, the BIG-IP system does not update the SNMP system name (sysName) value. As a result, administrators that are using SNMP to monitor the BIG-IP system will receive replies that return the old host name.

F5 Product Development tracked this issue as ID 247920, and it was fixed in BIG-IP 10.2.4 and 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes. In addition, BIG-IP iHealth may list Heuristic H869628 on the Diagnostics > Identified > Low screen.

Workaround

When the system's host name is modified, you must restart the snmpd process. To do so, perform one of the following procedures:

Restarting the snmpd process from the command line

  1. Log in to the command line.
  2. To restart the snmpd process, type the following command:

    bigstart restart snmpd

Restarting the snmpd process from the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to System > Services.
  3. Select the snmpd check box.
  4. Click Restart.
  5. When the Restart selected services? message displays, click OK.
