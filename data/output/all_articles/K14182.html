Known Issue

The BIG-IP system may use the incorrect linear white space (LWS) separator value.

This issue occurs when the following conditions are met:

  • You use the Configuration utility to change the LWS separator HTTP profile setting to one of the following values:
    • cr (carriage return)
    • lf (line feed)

The LWS separator setting specifies the linear white space separator that the system uses when a header exceeds the maximum width you specify in the LWS Maximum Columns setting. The default setting is \r\n. If you use the Configuration utility to change the LWS separator setting to cr, the system incorrectly saves the value as lf. Conversely, if you use the Configuration utility to change the LWS separator setting to lf, the system incorrectly saves the value as cr. The sp (space) value is not affected by this issue.

Impact

The system may send HTTP responses using an unexpected header format.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility and tmsh utility display different values for the LWS separator setting.
  • The system may send HTTP responses using an unexpected header format.

Workaround

To work around this issue, you can configure the LWS separator setting using the tmsh shell. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the tmsh shell by entering the following command:

    tmsh

  2. Use the following syntax to change the LWS separator for the desired profile:

    modify /ltm profile http <profile_name> lws-separator cr

    For example:

    create ltm profile http http_lws lws-separator cr

  3. Save the configuration by entering the following command:

    save /sys config
