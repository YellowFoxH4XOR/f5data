Issue

Error Message

Error Message: 01071a72:3: The global value tmm.ssl.maxactivehandshakes <value1> is smaller than client-ssl profile <profile> max active handshakes <value2>

In this error message, note the following:

  • <value1> is the value you set or attempt to set for the tmm.ssl.maxactivehandshakes database variable.
  • <profile> is the name of the affected Client SSL profile.
  • <value2> is the value you set or attempt to set for the Max Active Handshakes setting for the affected Client SSL profile.

For example:

01071a72:3: The global value tmm.ssl.maxactivehandshakes 10000 is smaller than client-ssl profile /Common/MyClientSSL max active handshakes 15000

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one or more of the following conditions is met:

  • You attempt to set the tmm.ssl.maxactivehandshakes database variable to a value that is smaller than the value configured for the Max Active Handshakes setting in the affected Client SSL profile.
  • You attempt to configure the Max Active Handshakes setting in the affected Client SSL profile to a value that is larger than the value set for the tmm.ssl.maxactivehandshakes database variable.

You can use the Client SSL profile Max Active Handshakes setting and the tmm.ssl.maxactivehandshakes database variable to set specific limits for the number of active SSL handshakes allowed by the BIG-IP system. The Max Active Handshakes setting applies to the specific virtual server, and the tmm.ssl.maxactivehandshakes database variable applies globally to the system.

Impact

None

Recommended Actions

Make sure to set the tmm.ssl.maxactivehandshakes database variable to a value that is larger than the value configured for the Max Active Handshakes setting in the affected Client SSL profile.
