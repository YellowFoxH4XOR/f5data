K78431520: Error when updating ASM custom response page

Type
Support Solution
Published
2022-03-05
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.X.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K78431520

Description

When updating ASM custom response page, following error messages are noted in GUI:

"Could not save changes in Response Page. Could not update the 'Deception Settings'. Invalid entity for Parent Policy."

Environment

  • BIG-IP ASM

Cause
Bug ID 778705

Recommended Actions
Upgrade to a fixed release as indicated in Bug ID 778705.

Alternatively you can use REST API to update the custom response page. Follow below steps.

  1. Use vi text editor to create a response page and save it under /shared/tmp/response_page.txt:
    For example:
    {
    "responseActionType":"custom",
    "responseContent":"<html><head><title>Request Rejected - MODIFIED</title></head><body>The requested URL was rejected. Please consult with your administrator.<br><br>Your support ID is: <%TS.request.ID()%><br><br><a href='javascript:history.back();'>[Go Back]</a></body></html>"
    }
     
  2. Use the following command syntax to determine the MD5 hash identifier for the policy name under bash shell. 

    curl -sku <username:password>  https://<BIG-IP hostname or management IP address>/mgmt/tm/asm/policies?\$select=name,id | jq '.'
