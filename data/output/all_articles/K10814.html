K10814: The BIG-IP WebAccelerator sends a Cache-Control: no-cache header for objects matching the unclassified node

Known Issue

This is the result of a known issue. Requests for unclassified object types will use the unclassified node in a BIG-IP WebAccelerator acceleration policy, and match the Always proxy option for the node's proxying configuration.

This behavior results in the BIG-IP WebAccelerator inserting a no-cache directive into the Cache-Control header. When the system responds with the Cache-Control: no-cache header, Internet Explorer 6 browser clients may be unable to display objects with an external application.

F5 Product Development tracked this issue as CR129965, and it was fixed in version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP WebAccelerator version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
