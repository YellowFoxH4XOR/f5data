Description
This document provides instructions on how to create a custom report in BIG-IP APM.

Environment

  • BIG-IP APM

Cause
None

Recommended Actions

To create a custom BIG-IP APM report follow the steps in this procedure:
  1. Go to Access > Overview > Access Reports (press the Cancel button when the Report Parameters window pop-ups).
  2. In the Reports Browser pane, click "Custom Reports".
  3. Press the Create button found at the bottom of its window space.
  4. Fill out the Report Name.
  5. In the Report Fields tab, select the fields you need to include in the report.
  6. In the Report Constraints click the Add Constraint of what desired data to show in the report

    Examples: 

    Field Name: Client IP
    Operator: begins with
    Field value: 192.168

    Field Name: Access Profile
    Operator: begins with
    Field value: /Common
     
  7. In the Sort Fields (optional), sort the fields as per your requirement.
  8. Click the Save button.
  9. Click the custom report created, and click the Run Report.
  10. In the Custom Report Parameters, select the desired time period the report will be generated for.
Note: Ensure that at least the default /Common/sys-db-access-publisher is set as the Publisher for Access System Logs and/or URL Request Logs in the Logging Profile of the Access Profile found in Access > Overview > Event Logs > Settings. The /Common/sys-db-access-publisher configuration is found in System > Logs > Configuration > Log Publishers.
