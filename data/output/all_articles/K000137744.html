K000137744: "failed in syscall mkdir... No space left on device" error when attempting to delete epsec packages via GUI/CLI

Description

When attempting to delete unused epsec packages via the GUI, getting this error:


via tmsh, getting the same error, too:

(bigip1)(cfg-sync Sync Failed (Sync Only))(Active)(/Common)(tmos)# delete /apm epsec epsec-package EPSEC/Upload/epsec-1.0.0-888.0.iso


01070712:3: failed in syscall mkdir(/config/filestore/.trash_bin_d/.current_d) errno=(No space left on device)


Environment

  • disk space is full
  • you have a lot of 'old'/unused epsec packages installed on the device


Cause

The /config directory is 100% full.

Recommended Actions

To determine what files there are in the /config directory that could be eating up disk space, run this command:

# ls -lSr /config


If you see any files (specially those that are large in size) that normally shouldn't be present in the /config directory (examples would be .txt or .pcap files), delete them.


Once the /config directory is no longer fully utilized, you should now be able to delete the unused epsec packages via the GUI/TMSH successfully.
