Known Issue

In rare conditions, the Traffic Management Microkernel (TMM) process may produce a core file when using Large Scale NAT (LSN).

This issue occurs when all of the following conditions are met:

  • Large Scale NAT (LSN) is in use.
  • The proxy connection takes extra time to complete.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high availability (HA) pair.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system produces a TMM core file in the /shared/core directory.
  • If a standby host is configured, the BIG-IP system fails over to the standby host that is configured in the device group.
  • In the /var/log/tmm log file, you may observe errors similar to the following example:

    notice panic: ../net/nexthop.c:544: Assertion "Valid nexthop type" failed.
    notice ** SIGFPE **
