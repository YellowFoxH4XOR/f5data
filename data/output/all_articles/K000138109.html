Description

In rare cases, a tmm core can result in tmm continuing to crash due to the HSB hardware being unavailable.

Environment

- iSeries i2000 or i4000 appliance

- Software version before v15.0.0.


Cause

The original cause of the crash cannot be determined without the first corefile, which is normally overwritten in this scenario. However, in software versions from 15.0.0 the fix for ID533461 "Preserve original core file on multiple TMM cores" helps troubleshoot the original crash.


Recommended Actions

Reboot appliance.
