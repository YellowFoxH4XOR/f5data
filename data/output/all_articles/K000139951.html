K000139951: Drive space fills up when using /messages as a remote-logging source for F5OS systems

Description

Using remote-logging with /messages as a source

disk space filling up nearly instantly after enabling remote-logging

 

Environment

rSeries

F5OS

 

Cause

The system generates an rsyslog config that uses /var/log/messages as a source, and since rsyslog is also a destination for log messages, this causes issues.

 

Do not add /var/log/messages as a 'file' for the the remote logging configuration; the system is already going to be forwarding things in /var/log/messages. 

Specifying files is essentially adding new _sources_ of information to rsyslog. The problem is that /var/log/messages is also rsyslog's default destination; you get an infinite loop when you ask rsyslog to both log things to /var/log/messages *and also* use it as a source.

 

This loop will fill up your disk space extremely quickly.

 

Recommended Actions

Do not add /var/log/messages as a rsyslog source
