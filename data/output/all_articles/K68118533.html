Description
After each reactivation of license, Licensed On in CLI and Licensed Date in WebGUI are updated to be the same date as Service Check Date on some of the devices.

Environment

  • BIG-IP
  • Reactivation of License
  • WebGUI
  • CLI

Cause
This is a cosmetic display and will not have impact as long as the Service Check Date is showing the date the license is reactivated if the support entitlement is active.

From time to time F5 updates product functionality through the base software code (TMOS) and/or via licensing.  We reserve the right to modify how product features are delivered without changing functionality, which can impact what is displayed in the license.

Recommended Actions

None
