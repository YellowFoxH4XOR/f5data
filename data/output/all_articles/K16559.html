Known Issue

Using empty strings for passwords may prevent re-key operations.

This issue occurs when the following conditions are met:

  • You configure a password using an empty string.

    For example, this condition applies if you configure the Lightweight Directory Access Protocol (LDAP) Bind Password setting for remote authentication by using an empty string.
  • You attempt to re-key the BIG-IP master key using the f5mku utility.

Impact

Re-key operations fail, and the system logs error messages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Re-key operations fail.
  • The BIG-IP system logs an error message similar to the following example:

    Error trying to rekey: 01071029:5: master_decrypt failed during rekey
  • Configuration synchronization (ConfigSync) operations fail.

Workaround

To work around this issue, you must change the affected password and make sure not to use passwords with empty strings in the BIG-IP configuration.
