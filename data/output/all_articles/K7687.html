Topic

This article applies to BIG-IP ASM 9.x - 10.x. For information about other versions, refer to the following articles:

  • K17191923: BIG-IP ASM does not generate learning suggestions for certain security violations (BIG-IP 13.x - 17.x)
  • K14945: BIG-IP ASM does not generate learning suggestions for certain security violations (11.x)
The Traffic Learning screen in the Configuration utility contains categories of security violations, and displays the number of actual violations for each category. The Learning Manager generates the learning suggestions based on traffic through the security policy.

The Learning Manager does not currently generate learning suggestions for the following security violations in BIG-IP ASM 9.x through 10.x:

Request for Comment (RFC) Violations

  • Cookie not RFC-compliant
  • Illegal HTTP format
  • Non-RFC request
  • Evasion Technique Detected

Access Violations

  • Illegal HTTP status in response
  • Illegal session ID in URL
  • Login object expired
  • Login object bypassed
  • Request length exceeds defined buffer size

Input Violations

  • Failed to convert character
  • Forbidden Null in request
  • Illegal dynamic parameter value
  • Illegal number of mandatory parameters
  • Malformed XML data
  • Null in multi-part parameter value
  • Parameter value does not comply with regular expression
  • SOAP method not allowed
  • XML data does not comply with schema or WSDL document

Cookie Violations

  • Expired timestamp
  • Modified ASM cookie
  • Wrong message key

Mitigation

  • Maximum login attempts are exceeded (BIG-IP 10.x and later)

To identify one or more of the previously described security violations, use the Statistics screens in the Configuration utility to search for them.
