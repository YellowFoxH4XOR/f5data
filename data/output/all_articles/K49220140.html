Known Issue

The Traffic Management Microkernel (TMM) may produce a core file when an HTTP2 or SPDY connection is terminated on both client and server sides concurrently.

This issue occurs when all of the following conditions are met:

  • The HTTP2 or SPDY profile is configured and assigned to a virtual server.
  • A client SSL profile is used on the same virtual server.
  • The HTTP2 or SPDY client interrupts a connection.
  • The server concurrently terminates the connection.

Impact

The BIG-IP system temporarily fails to process traffic while TMM restarts. If the BIG-IP system is configured for high availability (HA), the system fails over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • Your BIG-IP system logs a SIGFPE to the /var/log/tmm file at the same time TMM produces a core file and restarts.
  • In the in the /var/log/tmm log file, you observe an error message similar to the following example:

    notice panic: ../modules/hudfilter/hudfilter.c:1063: Assertion "valid node" failed.
