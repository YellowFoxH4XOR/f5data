K000152515: HTTPS traffic fails over VPN on Windows 11 after BIG-IP software upgrade

Type
Support Solution
Published
2025-07-10
Updated
2025-07-16
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.0, 17.1.2, 17.1.1, 17.5.X, 17.1.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000152515

Description

  • Following a BIG-IP software upgrade, Windows 11 clients are unable to access internal resources over HTTPS through the VPN tunnel when using Optimized Application Tunnel in the network access resource.
  • Both macOS and Linux clients can access internal resources over HTTPS through the same VPN tunnel.
  • Confirmed that these internal resources can be accessed over HTTP.
  • The Optimized Application Tunnel configuration is specifically set up for the relevant subnet and port 443.

Environment

  • BIG-IP APM
  • SSL VPN with Optimized Application Tunnel
  • Windows 11

Cause

The virtual server handling VPN has the 'translate-address' option disabled, which prevents proper routing of traffic to internal resources over the VPN tunnel when Optimized Application Tunnel is enabled for port 443.

Recommended Actions

Enable address translation (set 'translate-address' to enabled) on the affected virtual server handling VPN traffic.

Additional Information

Optimized Application Tunnels are supported only for Windows client systems.
