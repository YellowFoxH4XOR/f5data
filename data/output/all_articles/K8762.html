Known Issue

This is the result of a known issue. No entry is created in the Learning table for a NULL when the Null in request violation is enabled.

When you select the Null in request violation (default under HTTP protocol compliance) and a request contains a NULL, the violation will register in the forensics, but it will not appear in the HTTP protocol compliance page, located under Learning -> Violations in the Configuration utility.

This issue only occurs when you build the configuration manually. If you use the automatic tools (Deployment Wizard and Policy Builder) the violation is disabled, and false positives do not occur when you move the policy into blocking mode.

F5 Networks Product Development tracked this issue as CR98094 and it was fixed in BIG-IP ASM version 10.0.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.
