Issue

Error Message

err mcpd[<PID>]: 01070356:3: <feature> feature not licensed

In this error message, note the following:

  • <PID> is the process ID
  • <feature> is the BIG-IP system feature

For example:

err mcpd[4850]: 01070356:3: Load balancing feature not licensed

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The TMOS Shell (tmsh)

Description

This message occurs when the following condition is met:

  • You attempt to use a BIG-IP system feature that is not licensed.

For example, if you have a BIG-IP ASM system with a standalone license, and attempt to assign, to a virtual server, a pool that has more than one pool member, the BIG-IP system will generate this error message, because the standalone BIG-IP ASM license does not support load balancing features.

Impact

You are unable to use the feature on the BIG-IP system.

Recommended Actions

If you require use of the feature in question, you need to obtain a license. For more information, contact your F5 sales representative.
