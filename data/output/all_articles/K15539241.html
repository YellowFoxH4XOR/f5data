Issue

Error Message

011e0001:4: Limiting <reason> from <count1> to <count2> packets/sec

In this error message, note the following:

  • <reason> is the message information relating to the error reason
  • <count1> is the number of packets received by the system in a one-second period
  • <count2> is the BIG-IP system packet response rate limit

For example:

011e0001:4: Limiting open port RST response from 501 to 500 packets/sec

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one or both of the following conditions are met:

  • The BIG-IP system receives a significant number of packets that do not match existing connections to BIG-IP virtual servers, self IP addresses, or secure network address translations (SNATs).
  • The BIG-IP system experiences a denial of service (DoS) or a distributed denial of service (DDoS) attack.
  • The unmatched packet rate exceed the tm.maxrejectrate threshold value.

Note: For additional error message examples and information about the BIG-IP system packet response rate limit, refer to K13151: Configuring the rate at which the BIG-IP system issues TCP RSTs or ICMP unreachable packets (11.x - 13.x).

Impact

In many cases if you know what is causing these long entries it can be safely ignored. However, it can be indicative of other issues. Per  K9812: Overview of BIG-IP TCP RST behavior it may be indicate a possible DoS attack. System performance may be degraded if the BIG-IP system is experiencing a DoS attack.

Recommended Actions

If these error message occur frequently, refer to K14813: Detecting and mitigating DoS/DDoS attacks (11.4.x - 14.x).
