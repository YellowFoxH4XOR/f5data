Description

  • How to encrypt ASM Logging Profile Remote Storage traffic

Environment

  • ASM provisioned
  • ASM Logging Profile with Remote Storage configured

Cause

ASM Logging Profiles do not have an encryption mechanism built-in at this time, this feature is being tracked in bug ID652265. 

Recommended Actions
ASM remote storage traffic can be sent to an internal virtual server, configured on the same device that is sending the ASM logs, which then encrypts the logging traffic before sending it to a destination logging server.

  1. Create a new Standard type virtual server on the BIG-IP you want to send logs from by navigating to Local Traffic  ››  Virtual Servers. This new virtual server will be on your ASM/Adv. WAF device.
  2. The virtual server IP address assigned should be reachable via an existing TMM interface.
  3. Configure the new Virtual Server from step 1 with no client-side SSL profile and add a Server-side SSL profile.
  4. Make sure the Virtual Server from step 1 has a TCP profile, but no HTTP profile applied.
  5. Navigate to the ASM Security Logging Profile at Security  ››  Event Logs : Logging Profiles : [profile name]
    Change Storage Destination to Remote Storage
    In the Server Addresses configuration for the IP Address and Port fields enter the IP address and port of the virtual server created in step 1.
  6. Select Update
