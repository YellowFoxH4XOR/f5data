Description

You have found out there is no access to the BIG IP management IP via WebUI or SSH

Environment

  • BIG IP

Cause

AOM management IP was set with the same IP as the BIG IPs management IP.

Recommended Actions

  1. Connect console cable (K7683)
  2. Check what is the static AOM's IP set (

    K14594

    )
    •  N --- Configure AOM network 
  3. In case the same IP:
  4. Set the AOM IP with a different static IP (make sure no other use with this IP)
