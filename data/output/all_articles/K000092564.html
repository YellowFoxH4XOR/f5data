Description

What is the format of the OpenAPI swagger YAML file?

 

Environment

  • YAML openAPI file contains, "content": { "application/json" }

Cause

An OpenAPI document that conforms to the OpenAPI Specification is itself a JSON object, which may be represented either in JSON or YAML format.

 

For further information, refer to the information in the section "Format" of the manual OpenAPI Specification.
