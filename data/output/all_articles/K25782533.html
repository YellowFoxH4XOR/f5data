Description
BIG-IP APM can not identify Windows 11 on latest versions at November 2021.
This article explain how to identify Windows11 with Sec-CH-UA-Platform-Version.
 

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • Windows 11

Cause

None

Recommended Actions

Microsoft Edge and Google Chrome support Sec-CH-UA-Platform-Version header.
If client OS is Windows 11, support Sec-CH-UA-Platform-Version contains 13.0.0 and above.

Using a custom iRule you can create a session variable to detect sec-ch-ua-platform-version and use this custom session variable on VPE Branch Rule decision tree.

Example iRule stanza:

when ACCESS_SESSION_STARTED {
if { [HTTP::header sec-ch-ua-platform-version] contains "13" } {
        ACCESS::session data set session.custom.platform win11
    }
if { [HTTP::header sec-ch-ua-platform-version] contains "14" } {
        ACCESS::session data set session.custom.platform win11
    }
}

Additional Information
Microsoft Edge and Google Chrome may not grant sec-ch-ua-platform-version.

If HTTP response has accept-ch header, the browser will grant sec-ch-ua-platform-version.
In this case, you need to create an virtual server that intercepts traffic in front of the BIG-IP APM virtual server to insert the header prior to BIG-IP APM processing of the connection request.
For more information refer to: K23154551: Applying a BIG-IP LTM iRule to BIG-IP APM access session content.

<Sample>
when HTTP_RESPONSE {
HTTP::header insert "accept-ch" "Sec-CH-UA-Platform-Version"
}
