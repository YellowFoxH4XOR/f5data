Description

You create an external monitor script and it works correctly when you run it in an ssh shell session, but it fails to work when executed by the BIG-IP. Enabling monitor logging on an appropriate pool member shows the following error occurring:

EAV execve: Exec format error

Environment

  • BIG-IP
  • External Monitor

Cause

The first line of the external monitor script is not referencing the Interpreter directive (also called: 'shebang, sharp-exclamation, sha-bang, hashbang, pound-bang or hash-pling'), which is used to specify which program must to used to execute the script ( for example: #!/bin/sh or #!/bin/perl ).

Note: Do not have a comment on the first line of your script, as BIG-IP would try and use it as the interpreter.

Recommended Actions

Ensure that the first line of the external monitor script is the Interpreter directive.
