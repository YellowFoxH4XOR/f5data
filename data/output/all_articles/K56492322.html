Description

Missing Support ID's for ASM

  • No Event logs in the GUI

Environment

  • ASM policy configured 
  • Using IP address exception list
  • Never log traffic from this IP Address

Cause

Expected behavior if using this configuration to not see any traffic from the IP specified on the list.

Recommended Actions

Use this setting if you know traffic will be valid and no violation will occur for the user.
