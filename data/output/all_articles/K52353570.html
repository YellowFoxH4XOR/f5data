Description

If hostnames of backend server are used in Static AppTunnels for Linux/MacOS, this will not work. With Linux and Mac, there is no DNS Relay proxy, so application cannot be accessed through the DNS name once the tunnel is established.

When a tunnel is established, there is a binding between the hostname/ip address <-> internal loopback address. If there is no auto launch, then when you connect using the application's hostname, the DNS Relay Proxy is required to bind it to the internal loopback address of the tunnel. Since there is No DNS Relay Proxy in Linux/Mac, the users have to go find the loopback address from the client side logs to connect to when there is no auto-launch.

So it is recommended to have auto-launch to the application with %host% and %port% parameters when you have static app tunnels with linux and mac. This %host% will be populated with the loopback address assigned to the tunnel.

Environment

  • BIG-IP APM
  • Static AppTunnels for Linux/MacOS configured using hostnames

Cause

With Linux and Mac, there is no DNS Relay proxy, so application cannot be accessed through the DNS name once the tunnel is established.

Recommended Actions

Auto-launch to the application with %host% and %port% parameters when you have static app tunnels with linux and mac. This %host% will be populated with the loopback address assigned to the tunnel.

Additional Information

Please review the following example:
 

apm resource app-tunnel Linux_App_Tunnel {
    acl-order 0
    app-service none
    application-launch-warning true
    apps {
        item {
            app-service none
            compression-adaptive true
            compression-bzip2 true
            compression-deflate true
            compression-lzo true
            compression-null true
            deflate-level 1
            description connect_ssh
            host none
            ip 10.10.10.120
            local-ip any6
            local-port-range none
            log packet
            order 1
            os-type unix
            param "'/usr/bin/ssh root@%host% -p %port%'"   <==== this is the auto launch
            path "gnome-terminal -e"
            port-range 22
            protocol none
        }
    }
    customization-group Linux_App_Tunnel_resource_app_tunnel_customization
    description none
    java-tunnel false
    location-specific true
    partition Common
    type app-tunnel
}
