Known Issue

This is the result of a known issue. If you configure a Dynamic Application Tunnel and specify Microsoft Internet Explorer (IE) as the associated application, Windows Vista clients will be unable to access applications through the Dynamic Application Tunnel if Protected Mode is enabled in IE. When this issue occurs, the FirePass client-side component launches IE on the client system, but traffic from the launched browser window will route through the client’s default gateway instead of through the Dynamic Application Tunnel.

Protected Mode is a security feature that is enabled by default in Internet Explorer 7. For more information about Protected Mode, refer to the following website:

http://www.microsoft.com/windows/products/windowsvista/features/details/ie7protectedmode.mspx

F5 Networks Product Development tracked this issue as CR86595 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

This issue has been fixed in cumulative HF-603-3 issued for FirePass version 6.0.3. You may download this hotfix or a later version of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

To work around this issue, configure Web Application Tunnels for web application access instead of Dynamic Application Tunnels. You can configure Web Application Tunnels on the Application Access: App Tunnels: Resources page under the Web Application Tunnels tab. For more information about configuring Web Application Tunnels, refer to the FirePass Controller Administrator Guide.

Additionally, users may work around this issue by disabling Protected Mode in IE; however, this workaround is not recommended. Disabling Protected Mode may decrease the security of the Windows Vista system.
