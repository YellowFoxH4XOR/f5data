Known Issue

This is the result of a known issue. A boot marker log entry similar to the following example appears in certain system logs when the BIG-IP system is rebooted:

boot_marker: ---===[ HD1.1 - BIG-IP 9.4.3 Build 1.4 ]===---

Boot marker log entries are incorrectly written to the /var/log/lastlog file. As a result, output from the lastlog command is corrupted. The lastlog program formats and prints the contents of the last login to the /var/log/lastlog binary file.

F5 Product Development tracked this issue as CR93428 and it was fixed in BIG-IP LTM version 9.6.1, and version 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Note: The BIG-IP LTM version 9.6 software branch is specific to the VIPRION platform. If you are running BIG-IP software on a platform other than VIPRION, you cannot upgrade to version 9.6 software.

This issue still exists in the BIG-IP LTM 9.4 software branch.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.1-HF2 issued for BIG-IP versions 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
