What Happened?

  • F5® Distributed Cloud Console runs in a browser, but only certain browsers are supported.
  • Which browsers are supported by Distributed Cloud Console?

Environment

  • F5® Distributed Cloud Console

Resolution/Answer

Distributed Cloud Console is supported and tested on the following browsers:

  • Google Chrome
  • Firefox
  • Safari
  • Microsoft Edge

We recommend always using the latest version of your chosen browser.
