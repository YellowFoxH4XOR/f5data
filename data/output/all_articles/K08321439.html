Description

There are unsupported Apache Log4j version files found in BIG-IP which may be flagged out by your company's security team.
Example of a file: /usr/local/www/waui/WEB-INF/lib/log4j-1.2.15.jar

Environment

  • BIG-IP 
  • Apache Log4j

Cause

None

Recommended Actions

F5 does not recommend removing any log4j JAR files from the BIG-IP as it can break device monitoring and void the software support contract.

There is no currently supported method of independently updating log4j on a BIG-IP system.  Future versions of BIG-IP may include an updated version.

Refer to F5 Security Advisories for authoritative statements of vulnerability. Review the following articles covering log4j vulnerabilities:

  • K23173103: log4j vulnerability CVE-2017-5645
  • K61529042: Log4j vulnerability CVE-2019-17571
  • K15111130: log4j 1.2.x vulnerability CVE-2020-9488
  • K34002344: Overview of Log4j vulnerabilities (2021 and 2022)
  • K000133409: Log4j vulnerability CVE-2023-26464
