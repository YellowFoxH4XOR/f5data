Topic

You should consider using this procedure under the following condition:
  • You want to change the management IP address and/or management gateway route for a vCMP guest.

Description

This article provides steps for changing the management IP address and management gateway route for a vCMP guest.

When changing the management IP address or management gateway IP address, you should consider the following:

  • Routing considerations. User-defined management routes will not update if the management IP address or management gateway changes. You may also have to change user-defined routes if you change the management IP address to a new network.
  • High availability (HA) considerations. For BIG-IP 11.x, the HA configuration may include the management IP address. Therefore, if you update the management IP address on a system that specified the previous management IP address in the HA configuration, you will also have to update the HA configuration to use the new management IP address. For information about configuring HA network resources, refer to K14135: Defining network resources for BIG-IP HA features (11.x - 16.x). If you are changing the management IP address after the initial deployment of the BIG-IP system, refer to the impacts noted in the section covering this topic in K7312: Overview of the management port.

    Note: Beginning in BIG-IP 12.0.0, you are not required to manually configure the management IP address in the HA configuration, the BIG-IP system automatically specifies the management IP address.

  • You can change the management IP address or management gateway IP address when the vCMP guest is in the Configured or Provisioned state. Depending on your network environment, you may also perform the change with the guest in the Deployed state. When you do so, the vCMP host immediately propagates the changes to all of the guest VMs.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the vCMP hypervisor.

Procedures

Changing the management IP address and management gateway route

You can change the management IP address and management gateway route using either the Configuration utility or the TMOS Shell (tmsh). To do so, perform one of the following procedures:

  • Using the Configuration utility
  • Using tmsh

Impact of procedures: Changing the vCMP guest's management or gateway IP requires you to set the vCMP guest state momentarily to Configured, then back to Deployed. The vCMP guest will temporarily fail to process traffic until you return the vCMP guest state to a Deployed state. F5 recommends that you perform this procedure during a scheduled maintenance window.

Using the Configuration utility

  1. Log in to the Configuration utility of the vCMP hypervisor.
  2. Go to vCMP > Guest List.
  3. Select the name of the vCMP guest you want.
  4. For Cluster IP Address, perform the following actions:
    • Enter the management IP address in the IP Address field.
    • Enter the subnet mask address in the Network Mask field, or select the subnet mask from the list.
    • Enter the management gateway IP address in the Management Route field.
  5. Select Update.
  6. Select the check box for the vCMP guest you want.
  7. To redeploy the vCMP guest, select Deploy.

Using tmsh

  1. Log in to tmsh on the vCMP hypervisor by entering the following command:

    tmsh

  2. Change the management IP address (management-ip) and management gateway (management-gw) using the following syntax:

    modify vcmp guest <guest name> { management-ip <ip/subnet bits> management-gw <gateway ip> } 

    • <guest name> is the name of the vCMP guest you want to configure.
    • <ip/subnet bits> is the IP address and Classless Inter-Domain Routing (CIDR) subnet to use for the management IP address.
    • <gateway ip> is the IP address to use as the management gateway route.

    For example:

    modify vcmp guest guest1 { management-ip 10.10.10.10/24 management-gw 10.10.10.254 }

  3. Save the configuration by entering the following command:

    save /sys config

  4. Set the vCMP guest to a configured state using the following syntax:

    modify vcmp guest <guest name> state configured

    • <guest name> is the name of the vCMP guest you want to configure.

    For example:

    modify vcmp guest guest1 state configured

  5. Set the vCMP guest to the deployed state using the following syntax:

    modify vcmp guest <guest name> state deployed

    • <guest name> is the name of the vCMP guest you want to deploy.

    For example:

    modify vcmp guest guest1 state deployed
