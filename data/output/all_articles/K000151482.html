Description

Application Visibility and Reporting (AVR) provides advanced analytics, reporting, and visibility into application traffic passing through BIG-IP. AVR enables monitoring of latency, throughput, errors, and other key metrics for troubleshooting and optimizing application delivery.

Environment

  • BIG-IP LTM
  • AVR

Cause

None

Recommended Actions

Notes:

  • AVR data is stored locally and subject to retention policies and disk space. Ensure sufficient disk space is allocated if storing large amounts of analytics data locally.
  • For compliance or audit requirements, consider exporting or forwarding analytics data to a remote server.
  • AVR can be used for both real-time and historical analysis of application traffic.
  • Regularly review analytics data for performance baselines and anomalies.

1. Provision the AVR Module

  1. Navigate to System > Resource Provisioning in the BIG-IP Configuration utility.
  2. Set Application Visibility and Reporting (AVR) to at least “Nominal.”
  3. Click Submit to apply changes.

2. Create or Configure an Analytics Profile

  1. Go to Local Traffic > Profiles > Analytics.
  2. Click Create to make a new Analytics profile or select an existing one.
  3. Enable desired statistics collection options such as HTTP/HTTPS, TCP, latency tracking, response codes, etc.
  4. Save the profile.

3. Assign the Analytics Profile to a Virtual Server

  1. Go to Local Traffic > Virtual Servers.
  2. Select the virtual server you want to monitor.
  3. In the Analytics section, attach your Analytics profile.
  4. Click Update or Finished.

4. Access AVR Reports

  1. Navigate to Statistics > Analytics in the BIG-IP GUI.
  2. Select your virtual server or application from the available list.
  3. Review reports for:
    • Latency (client-side/server-side)
    • Throughput
    • Connection rates
    • Application response times
    • Error rates

5. Optional: Configure Remote Logging for Long-Term Retention

If you require long-term retention or centralized log analysis:

  1. Go to System > Logs > Configuration > Remote Logging.
  2. Add your remote syslog/log server details.
  3. Specify appropriate log destinations/facilities for analytics data.
  4. 6. Optional: Export Reports/Data

You can export analytics reports from within the Statistics > Analytics section for further analysis or documentation needs.
