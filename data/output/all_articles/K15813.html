Known Issue

When making a SPDY request, some HTTP response headers from the origin server may not pass to the client.

This issue occurs when the following condition is met:

  • The SPDY profile is associated with a virtual server.

Missing headers may include X-WA-Info and Content-Disposition.

Impact

Applications expecting missing headers may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A tcpdump comparison of HTTP headers between the server and client will show missing headers on the client side.
