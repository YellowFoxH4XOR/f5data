Known Issue

The BIG-IP APM MySQL database may grow to consume all available disk space. 

The BIG-IP APM system stores user session reporting data in the local MySQL database instance. When the BIG-IP APM system is experiencing high traffic volume and continuously creating a large number of sessions per hour, the session data logged to the log_session_details table may grow and eventually consume all available disk space on the filesystem.

Impact

The filesystem containing the MySQL instance may fill with data, potentially causing traffic disruptions and system instability.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP APM system becomes unresponsive or unstable.
  • Administrators are unable to access the Configuration utility.
  • Services that rely on MySQL, such as ASM, AVR, APM reporting, the Configuration utility, and the qkview utility, are degraded or they malfunction.
  • Output of the df -h command shows no available space left in the filesystem mounted on the /var/lib/mysql directory.

Workaround

To work around this issue, you can manually prune the log_session_details table from the command line.  To mitigate future occurrences of this issue, you can configure a cron job to run a pruning script hourly. To do so, perform the following procedures:

Manually pruning the log_session_details table

If your system is currently experiencing instability, you may need to manually remove unnecessary rows from the log_session_details table. 

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM command line.
  2. To prune the log_session_details table, type the following command on a single line and press Enter:

    /usr/bin/mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` --database=apm -e "delete from log_session_details where active = 'N';"

Using a cron job to run a pruning script

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM command line.
  2. To change to the /etc/cron.hourly directory, type the following command:

    cd /etc/cron.hourly

  3. Use a text editor to create a file named apm_prune_log_session_details.sh with the following content:

    #!/bin/sh

    # This script prunes the log_session_details table in MySql with unreferenced sid.

    # Mysql parameters
    MYSQL_PW=`perl -MPassCrypt -nle \
        'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw`
    SES_TABLE_NAME="log_session_details"
    COL_SID="sid"
    COL_ACTIVE="active"
    WLIST_TABLE_NAME="log_sid_wlist"
    BLIST_TABLE_NAME="log_sid_blist"
    LOG_TABLE_NAME="log_data"
    COL_LOG_SID="log_sid"

    # Resulting mysql command
    CMD_WLIST_DROP="drop table if exists $WLIST_TABLE_NAME"
    CMD_WLIST_CREATE="create table $WLIST_TABLE_NAME ($COL_LOG_SID int(10) unsigned NOT NULL, PRIMARY KEY($COL_LOG_SID)) engine=MyISAM"
    CMD_WLIST_FETCH_0="insert ignore into $WLIST_TABLE_NAME select distinct $COL_LOG_SID from ${LOG_TABLE_NAME}_0"
    CMD_WLIST_FETCH_1="insert ignore into $WLIST_TABLE_NAME select distinct $COL_LOG_SID from ${LOG_TABLE_NAME}_1"
    CMD_WLIST_FETCH_2="insert ignore into $WLIST_TABLE_NAME select distinct $COL_LOG_SID from ${LOG_TABLE_NAME}_2"
    CMD_WLIST_FETCH_3="insert ignore into $WLIST_TABLE_NAME select distinct $COL_LOG_SID from ${LOG_TABLE_NAME}_3"
    CMD_WLIST_FETCH_4="insert ignore into $WLIST_TABLE_NAME select distinct $COL_LOG_SID from ${LOG_TABLE_NAME}_4"
    CMD_WLIST_FETCH_C="insert ignore into $WLIST_TABLE_NAME select distinct $COL_LOG_SID from ${LOG_TABLE_NAME}_current"
    CMD_BLIST_DROP="drop table if exists $BLIST_TABLE_NAME"
    CMD_BLIST_CREATE="create table $BLIST_TABLE_NAME ($COL_SID int(10) unsigned NOT NULL, PRIMARY KEY($COL_SID)) engine=MyISAM"
    CMD_BLIST_FETCH="insert into $BLIST_TABLE_NAME select $SES_TABLE_NAME.$COL_SID from $SES_TABLE_NAME left join $WLIST_TABLE_NAME on $SES_TABLE_NAME.$COL_SID = $WLIST_TABLE_NAME.$COL_LOG_SID where $WLIST_TABLE_NAME.$COL_LOG_SID is NULL and $SES_TABLE_NAME.$COL_ACTIVE = 'N'"
    CMD_PRUNE="delete $SES_TABLE_NAME from $SES_TABLE_NAME join $BLIST_TABLE_NAME on $SES_TABLE_NAME.$COL_SID = $BLIST_TABLE_NAME.$COL_SID"
    CMD_OPTI="optimize table $SES_TABLE_NAME"

    echo "**** Prune $SES_TABLE_NAME's inactive rows of which $COL_SID is not refernced by $LOG_TABLE_NAME. ****"
    echo "  $CMD_WLIST_DROP;"
    echo "  $CMD_WLIST_CREATE;"
    echo "  $CMD_WLIST_FETCH_0;"
    echo "  $CMD_WLIST_FETCH_1;"
    echo "  $CMD_WLIST_FETCH_2;"
    echo "  $CMD_WLIST_FETCH_3;"
    echo "  $CMD_WLIST_FETCH_4;"
    echo "  $CMD_WLIST_FETCH_C;"
    echo "  $CMD_BLIST_DROP;"
    echo "  $CMD_BLIST_CREATE;"
    echo "  $CMD_BLIST_FETCH;"
    echo "  $CMD_PRUNE;"
    echo "  $CMD_BLIST_DROP;"
    echo "  $CMD_WLIST_DROP;"
    echo "  $CMD_OPTI;"

    CMD_WLIST_FETCH="$CMD_WLIST_FETCH_0; $CMD_WLIST_FETCH_1; $CMD_WLIST_FETCH_2; $CMD_WLIST_FETCH_3; $CMD_WLIST_FETCH_4; $CMD_WLIST_FETCH_C"
    CMD="$CMD_WLIST_DROP; $CMD_WLIST_CREATE; $CMD_WLIST_FETCH; $CMD_BLIST_DROP; $CMD_BLIST_CREATE; $CMD_BLIST_FETCH; $CMD_PRUNE; $CMD_BLIST_DROP; $CMD_WLIST_DROP; $CMD_OPTI;"

    echo "**** $CMD"

    /usr/bin/mysql -uroot -p${MYSQL_PW} --database=apm -e "$CMD"

  4. Save and exit the file.
  5. To make the file executable, type the following command:

    chmod +x /etc/cron.hourly/apm_prune_log_session_details.sh

  6. To test the script by running it, type the following command:

    /etc/cron.hourly/apm_prune_log_session_details.sh
