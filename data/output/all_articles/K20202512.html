Issue

Error Message

015c0010:5: Initial load of IP Reputation database has been completed

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following condition is met:

  • The BIG-IP system downloads the IP reputation database from the BrightCloud server for the first time.

Impact

The BIG-IP system can access the IP reputation database for IP Intelligence.

Recommended Actions

None
