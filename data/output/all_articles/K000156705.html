Description

You use a command similar to below to resize the disk space on a VELOS tenant.
tmsh modify /sys disk directory /shared new-size <new value in KB> 

The command fails with the message below:
warning: Shrinking of directories is not supported. Current size is xxxxxxxx, requested new size is yyyyyyyy. directory - internal execution error(Operation not permitted).

 

Environment

VELOS tenant

Resizing disk

 

Cause

The command used is attempting to shrink the disk space. F5 does not support disk shrinking.

 

Recommended Actions

Verify  the value specified for new-size in the command  and ensure it does not result in shrinking disk space.

 

Additional Information

None
