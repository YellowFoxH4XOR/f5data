Topic

You should consider using this procedure under the following condition:

  • You want to enable or disable the carrier-grade network address translation (CGNAT) module.

Description

The carrier-grade network address translation (CGNAT) module on the BIG-IP system supports large groups of translation addresses using Large Scale NAT (LSN) pools and groupings of address-translation-related options in an application layer gateway (ALG) profile, which can be assigned to multiple virtual servers.

By default, CGNAT is not enabled, even if you have applied a valid license to use the module.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a valid license for the CGNAT module.
  • You have administrator access to the Traffic Management Shell (tmsh) utility or the BIG-IP Configuration utility.

Procedures

Enabling or disabling CGNAT using the tmsh utility

Impact of procedure: This procedure changes the BIG-IP module and provisioning requirements, and service interruption will occur. F5 recommends that you perform this procedure only during a scheduled maintenance period.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To check the provisioning status of the CGNAT module, type the following command:

    list /sys feature-module cgnat

  3. If you want to enable the CGNAT module, type the following command:

    modify /sys feature-module cgnat enabled

    If you want to disable the CGNAT module, type the following command:

    modify /sys feature-module cgnat disabled

  4. To exit tmsh, type the following command:

    quit

Enabling or disabling CGNAT using the Configuration utility

Impact of procedure: This procedure changes the BIG-IP module and provisioning requirements, and service interruption will occur. F5 recommends that you perform this procedure only during a scheduled maintenance period.

  1. Log in to the Configuration utility.
  2. Navigate to System > Resource Provisioning.
  3. Ensure that the License Status indicates Licensed.
  4. To check the provisioning status of CGNAT, go to the entry for the Carrier Grade NAT (CGNAT) module and look at the provisioning column.
  5. If you want to enable the CGNAT module, select Enabled for provisioning.

    If you want to disable the CGNAT module, select Disabled for provisioning.

  6. Click Submit.
