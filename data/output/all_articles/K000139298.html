Description

  • Your applications In Kubernetes cluster are exposed using NGINX Plus Ingress Controller
  • You now want to add/enable HTTP Strict Transport Security (HSTS) in HTTP response, such us the one shown below 
add_header Strict-Transport-Security "max-age=21536000; includeSubDomains" always;
  • In most cases, it is possible to customize NGINX configuration using configMap key or "add_headder" directive  
  • However, you also note some exceptions with "add_headder" directive from pour published document including HST .
  • You want to know how to achieve the above objective 

Environment

  • NGINX Plus Ingress Controller
  • HTTP response Header
  • Strict Transport Security (HSTS)

Cause

  • Improving the application security posture by including HSTs header in http response

Recommended Actions

  • In order to apply hsts use http-snippets.
  • To do so, editing nginx-config configMap and append the desired conifg from within http-snippets as shown below
       apiVersion: v1
       data:
         error-log-level: info
         http-snippets: |
           add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

         server-snippets: |
           access_log /dev/stdout jweb_time;
         ssl-protocols: TLSv1 TLSv1.1 TLSv1.2
       kind: ConfigMap
       metadata:
         name: nginx-config
         namespace: nginx-ingress

Additional Information

  • Subsequently and when inspecting, NGINX Plus Ingress Controller pod reflect hsts in its configuration as shown below.
  • More importantly, since we applied hsts at http block level, all the lower blocks will inherit the settings.
        worker_processes  auto;

        daemon off;
        error_log  stderr info;
        pid        /var/lib/nginx/nginx.pid;

        load_module modules/ngx_http_js_module.so;
        events {
            worker_connections  1024;
        }

        http {
            include       /etc/nginx/mime.types;
            default_type  application/octet-stream;

            add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
