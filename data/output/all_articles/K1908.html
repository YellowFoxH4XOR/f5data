K1908: Reasons why the 3-DNS Configuration utility may display certain ports as ''null''

Topic

3-DNS refers to the /etc/services file for information about the ports and services that are defined in a wide IP pool's port list. If a port is added that is not defined in the /etc/services file, the port/service will display in the port list as null, or by the port number, rather than the name of the service.

To resolve this issue, edit the /etc/services file and add an entry for the non-standard port/service.

For example, to add the non-standard port, 8080, to the /etc/services file, you would add the following line:

port-8080 8080/tcp # will display "port-8080" in Wide-IP port list

Once the port/service is defined in the /etc/services file, it will appear in the wide IP pool port list as the specified service name.
