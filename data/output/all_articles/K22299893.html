Description

  • Occasionally, the REST API stops responding to requests.
  • Log events, similar to the following are found in /var/log/kern.log, indicating the iControl REST daemon has been killed by the Linux oom-killer:


    Mar 9 21:43:58 bigip1 err kernel: : [12654499.967491] Out of memory: Kill process 10762 (icrd_child) score 81 or sacrifice child
    Mar 9 21:43:58 bigip1 err kernel: : [12654499.967494] Killed process 10762 (icrd_child) total-vm:962488kB, anon-rss:481492kB, file-rss:17812kB, shmem-rss:8kB

Environment

  • BIG-IP REST API

Cause

Bug ID 809597: Memory leak in icrd_child observed during REST usage

Recommended Actions

Review the Bug Tracker article, to determine which TMOS versions have resolved this bug and upgrade accordingly.
