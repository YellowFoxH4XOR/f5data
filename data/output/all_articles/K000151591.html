K000151591: Communication is not happening between Virtual Server and pool

Type
Support Solution
Published
2026-03-05
Updated
2026-03-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000151591

Description

It is observed that packets into the virtual server are not forwarded out and not going to the pool members


Environment

BIG-IP LTM,

Route Domains


Cause

If the Virtual server is in a different Route Domain to the pool members, then communication will not occur. It does not matter if you have routing configured to the subnet where the pools are located, if they are not the same Route Domain.


Recommended Actions

Pools must be in the same Route domain as the virtual server, or there must be a relationship defined between the Route Domains if they are different.


Additional Information


None.
