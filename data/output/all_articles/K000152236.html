Description

You would like to download the previously uploaded OpenAPI specification file.

BIG-IP ASM/WAF security policies can be created directly from an OpenAPI specification file. When you upload the OpenAPI spec, the system parses the file and uses its contents to automatically generate the security policy, including defining API endpoints, parameters, and validation rules. This approach helps streamline policy creation by leveraging the detailed API definitions already present in the OpenAPI document.

Environment

  • BIG-IP ASM/WAF
  • Create security policies using schema

Cause

None, by design.

Recommended Actions

It is not possible to download the previously uploaded OpenAPI specification file.

In F5 BIG-IP ASM/WAF, guided configuration schema files are not stored in any directory after upload. Instead, the system parses the file and uses its contents to build the policy, but the original file itself is not saved or available for later download.
