K000161877: How to select the upstream group with ssl_preread module variables

Source

Description

The NGINX Plus stream module allows selecting the upstream group based on the SNI provided during the SSL handshake, even when NGINX Plus doesn't establish an SSL connection but only proxies TCP traffic.

Environment

  • NGINX Plus
  • The stream module is configured to proxy TCP with SSL inside.

Cause

  • none

Answer/Recommended Actions

You can enable analysis of the proxied SSL handshake to extract the SNI. To do this, you need to use the "ssl_preread" directive. After that, use the "map" directive to select the needed "upstream" group.

For example:

steram {
    ssl_preread on;

    map $ssl_preread_server_name $upstream_name {
        examle.org backend1;
        *.examle.com backend2;
        default backend3;
    }

    upstream backend1 {
        zone backend1 64k;

        server 192.168.0.1:12345;
        server 192.168.0.2:12345;
    }

    upstream backend2 {
        zone backend2 64k;

        server 192.168.0.3:12345;
        server 192.168.0.4:12345;
    }

    upstream backend3 {
        zone backend3 64k;

        server 192.168.0.5:12345;
        server 192.168.0.6:12345;
    }

    server {
        listen 443;
        proxy_pass $upstream_name;
    }
}

Additional Information

It is also possible to use the "$ssl_preread_protocol" and "$ssl_preread_alpn_protocols" variables in the same way to select the upstream group.
