Description

While creating ucs archive, it is possible to set passphrase to encrypt ucs archive. However, when specifying passphrase containing disallowed characters, an error may be thrown on GUI or TMSH.

 

root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)# save sys ucs my.ucs passphrase Abc123$Test890
Error, passphrase contains unsafe characters.
Error during config save.
Unexpected Error: UCS saving process failed.
root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)#
root@(bigip2)(cfg-sync Standalone)(Active)(/Common)(tmos)# save sys ucs my.ucs passphrase Test>
Error, invalid characters in passphrase.
Error during config save.
Unexpected Error: UCS saving process failed.
root@(bigip2)(cfg-sync Standalone)(Active)(/Common)(tmos)#

 

Environment

  • Create ucs archive with passphrase.

 

Cause

N/A

 

Answer/Recommended Actions

Here is a list of allowed characters while setting passphrase on ucs archive.

 

  • alphanumeric characters
  • ' ' (white space)
  • ! (exclamation mark)
  • @ (at sign)
  • # (hash sign)
  • % (percent)
  • ^ (hat)
  • * (asterisk)
  • ( (left parenthesis)
  • ) (right parenthesis)
  • , (comma)
  • . (dot)
  • ? (question)
  • _ (underscore)
  • - (dash)
  • + (plus)
  • = (equal)

 

Note: Double quote (") needs to be balanced, as shown below (i.e., Abc123"Test890 -> Abc123\"Test890).

root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)# save sys ucs my.ucs passphrase Abc123"Test890
Syntax Error: double quotes are not balanced
root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)# save sys ucs my.ucs passphrase Abc123\"Test890
Saving active configuration...
/var/local/ucs/my.ucs is saved.
root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)#

 

Here is a list of disallowed characters.

 

  • & (ampersand)
  • ; (semi colon)
  • ' (single quote)
  • < (less-than mark)
  • > (greater-than mark)
  • | (vertical bar)

 

Previously, following characters were allowed on older S/W versions. But starting from BIG-IP software version 17.1.3.2/17.5.1.6/21.0.0.2/21.1.0, these characters are now disallowed.

 

  • $ (dollar)
  • ` (backquote)
  • ~ (tilde)
  • [ (left square bracket)
  • ] (right square bracket)
  • { (left curly bracket)
  • } (right curly bracket)
  • : (colon)
  • " (double quote)
  • / (forwarding slash)
  • \ (back slash)
