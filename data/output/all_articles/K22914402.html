K22914402: Guided Configuration stuck in ''Initializing...'' mode

Type
Support Solution
Published
2021-03-18
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K22914402

Description


Guided Configuration page does not load properly. Message displayed - "Initializing..."
 

Environment

  • BIG-IP WAF v15.1.1
  • Guided Configuration feature
  • User is logged in as other user than default admin

Cause

ID958281 iControl REST calls failed if any user name except 'admin' used

Recommended Actions

As a workaround "admin" user can be used to make changes in the Guided Configuration.
For permanent fix upgrade to fixed version is required (15.1.2.x)

Additional Information

None
