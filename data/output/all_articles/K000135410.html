K000135410: Migrate FCP license from one BIG IQ to another without the master key

Type
Support Solution
Published
2023-07-07
Updated
2024-04-02
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0
Source
https://my.f5.com/manage/s/article/K000135410

Description

A standalone Big-IQ that hosts FCP licenses is being moved from one datacenter to another. 

Environment

  • Big-IQ Standalone
  • FCP Base Registration Keys
  • Master key is unavailable

Cause

Planned maintenance and the master key is unknown. If the master key is known then the original Big-IQ can be paired with the new Big-IQ and the licenses synced across, with no impact to the remote Big-IPs.

Recommended Actions

  1. Contact F5 support and request an allow-move for both the device license and FCP licenses
  2. Manually license the new Big-IQ
    • K29239022: Reusing a BIG-IQ license on a different BIG-IQ system
  3. Apply the FCP license to the new Big-IQ
    • K15420056: How to manually license ELA in BIG-IQ
    • Note: The FCP license can exist on both Big-IQs until it expires, but only the new Big-IQ can activate licenses.
  4. Migrate the remote Big-IPs.
    • Migrate Managed Devices
    • Migrate Unmanaged Devices

Migrate Managed Devices: 

Note: Revoking and reactivating the license causes the configuration to reload on the remote Big-IP and is traffic impacting. This work needs to be performed during a maintenance window.

Either revoke license then remove services and device or remove device which also revokes license. I recommend separating these steps to ensure they complete successfully.

  1. Remove the device from the original Big-IQ. This automatically revokes its license.
      • Devices > Big-IP Devices > Enable/Check Big-IP > Remove all services
      • Devices > Big-IP Devices > Enable/Check Big-IP > Remove
      • When prompted that "The selected device has an outstanding license assignment that will be revoked", select Remove.
      • Verify no license exists on the Big-IP
    • Add remote Big-IP to the new Big-IQ
      • Devices > Big-IP Devices > Add Device > IP, username, password, etc. > add
      • Confirm "Managed by Big-IQ" on the Big-IP
      • Confirm green status on Big-IP "This device is active and running". This may take a few minutes.
    • Relicense the Big-IP from the new Big-IQ
      • Devices Tab > License mgmt > [FCP Name] > Offering [Name] > License Devices > Unit of Measure = Yearly > Managed Devices dropdown list > Select Big-IP > Assign
      • Wait for the configuration to reload on the Remote Big-IP
      • Confirm that its license is provided by the new Big-IQ (Remote Big-IP > System > License)

    Migrate Unmanaged Big-IPs:

    Note: Revoking and reactivating the license causes the configuration to reload on the remote Big-IP and is traffic impacting. This work needs to be performed during a maintenance window.

    1. On the original Big-IQ, revoke the license for the unmanaged Big-IP.
      • License Management > Licenses > Check/Enable box left of device name > Revoke
      • Enter Username and password for this remote Big-IP
      • Select revoke
      • Wait for configuration to reload on the remote Big-IP
      • Confirm it no longer has a license
    2. On the new Big-IQ, activate the license for the unmanaged Big-IP
      • License management > [FCP Name] > Offering [name] > License Devices > Unit of Measure = Yearly > Unmanaged / IP / Username / Password > Assign
      • Wait for the configuration to reload on the remote Big-IP,
      • Confirm that its license is provided by the new Big-IQ. On the Big-IP, navigate to System > License.
