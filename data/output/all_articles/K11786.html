Known Issue

This is the result of a known issue. When the LTM module is provisioned for None (Disabled) on the BIG-IP system, the Configuration utility does not display the horizontal flyout menu for the Local Traffic log option (System >> Logs >> Local Traffic).

Note: The information on the System >> Logs >> Local Traffic screen displays information logged by the BIG-IP LTM software and correlates to the /var/log/ltm file.

For example, if you provision the WebAccelerator module to Dedicated, the LTM module is automatically provisioned for None (Disabled), although certain LTM components are still active. If you then mouse over System >> Logs, the Local Traffic horizontal flyout menu is not available.

F5 Product Development is tracking this issue as ID 225732 (Formerly CR140035).

Workaround

You can work around this issue by performing one of the following procedures:

  • Use the Configuration utility to navigate to System >> Logs, and click the Local Traffic menu instead of using the flyout menu.
  • Use the command line to display the LTM logs by entering the following command:

    cat /var/log/ltm
