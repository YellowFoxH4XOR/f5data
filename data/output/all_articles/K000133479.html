K000133479: New tenant won't boot up

Type
Support Solution
Published
2023-04-11
Updated
2023-04-11
Source
https://my.f5.com/manage/s/article/K000133479

Description

You are unable to boot up a newly deployed tenant.

The following log message appears:

err mcpd[]: 01490523:3: Tenant '' failed to boot

Environment

  • Device: BIG-IP
  • Version: F5OS
  • Location: /var/import/staging

Cause

The tenant image is stored in the incorrect directory. The image should be stored in /var/F5/system/IMAGES, but it is currently stored in /var/import/staging.

Recommended Actions

  1. Move the tenant image from /var/import/staging to /var/F5/system/IMAGES.
  2. Reboot the device.
  3. Verify that the tenant has booted successfully by checking the logs for the following message:
  4. info mcpd[]: 01490345:3: Tenant '' booted successfully

Additional Information

None
