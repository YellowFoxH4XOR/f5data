Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator hit logs are not rotated because the the /etc/logrotate.d/wa file incorrectly specified the path to the BIG-IP WebAccelerator hit logs. The correct path is /var/log/wa/access/*.log; however, the path specified is /var/log/wa/access*.log. If the BIG-IP WebAccelerator hit logs are not rotated, the files may grow until they consume all available /var partition space.

Important: The /etc/logrotate.d/wa file is an automatically generated file and cannot be edited manually.

F5 Networks Product Development tracked this issue as CR90310, and it was fixed in BIG-IP WebAccelerator 9.4.4. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

This issue was fixed in Hotfix-BIG-IP-9.4.3-HF2 issued for BIG-IP version 9.4.3. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about managing F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

For BIG-IP WebAccelerator versions 9.4.2 and later, you can work around this issue by configuring the BIG-IP WebAccelerator hit logs to be rotated. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /var/tmp directory by typing the following command:

    cd /var/tmp
  3. Create a file named wa-log-script.txt with the following contents:

    logrotate {
       wa include "/var/log/wa/access/*.log {
       compress
       size=10M
       sharedscripts
       postrotate
       /bin/kill -HUP `/sbin/pidof -s pvac 2> /dev/null` 2> /dev/null || true
       endscript
    }
    "
    }
  4. Save the wa-log-script.txt file.
  5. Load the wa-log-script.txt file by typing the following command:

    bpsh < /var/tmp/wa-log-script.txt
  6. Save the changes, by typing the following command:

    bigpipe save all

    The BIG-IP WebAccelerator hit logs will now be rotated during normal log file rotation.
  7. At this point in the procedure, you can optionally force the files to be rotated, or simulate the file rotation.

    To force the files to be rotated, type the following command:

    logrotate /etc/logrotate.d/wa

    To simulate the file rotation without actually rotating the logs, type the following command:

    logrotate -d /etc/logrotate.d/wa
