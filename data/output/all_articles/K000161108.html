Description

How can I review changes to the F5 WAF for NGINX (formerly NGINX App Protect) Attack Signature Database. 

  • For instance when doing an upgrade or updating a setting in the .conf file where you try to and an exception and you something similar to the following......Failed to insert to PLC.PL_OBJECT_NEGSIG_SIGNATURES (DBD::SQLite::st execute failed: FOREIGN KEY constraint failed)",
    "completed_successfully": false

Environment

  • F5 WAF for NGINX Attack Signatures changes, updates, adds, and deletions.

Cause

There is no README file or other published document for F5 WAF for NGINX attack signature updates.

Answer/Recommended Actions

The database used is the same as the one for BIG-IP AdvWAF. Thus there are a couple of choices... 

  1.  Review the Readme file for BIG-IP AdvWAF that can be found on the F5 Download website.
  2. There is an online tool for checking signatures (The same one is used for BIG-IP AdvWAF). There is a link on there for "Changelogs". In that change log you will find all of the attack signature new and old. For example if you look up 200001408 it will not show up in the Attack Signature Database but it will show up in the Changelogs. In the change log it will show the date of the last update for that signature. But it does not tell you why it was updated. The gist of that is if you find it there but not on the Objectives list it has been removed.
