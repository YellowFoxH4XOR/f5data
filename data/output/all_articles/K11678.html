Topic

The BIG-IP DNS system gathers path and persistence metrics information and stores the data in memory to use for load-balancing. By default, the BIG-IP system writes the data to the /config/gtm/ldns.gz file every 3600 seconds. As a result, it is possible that the path or persistence data viewed from the Statistics screen in the Configuration utility, or from the command line, does not match the path or persistence data stored in the ldns.gz file.

Changing the frequency at which the BIG-IP system writes path and persistence information

You can change the frequency at which the BIG-IP system writes path and persistence information to the ldns.gz file. To do so, perform one of the following procedures, depending on your BIG-IP version:

Note: When changing the Metrics Caching setting, you can enter a value between 0 and 604800; the default setting is 3600. Setting this value to a shorter interval may result in performance degradation. To prevent the system from writing the metrics data to the ldns.gz file, set the value to 0.

BIG-IP 11.5.0 and later

  1. Log in to the BIG-IP Configuration utility.
  2. Click DNS.
  3. Navigate to Settings > GSLB > Metrics Collection.
  4. Enter a value in the Metrics Caching field.
  5. Click Update.

BIG-IP 9.x - 11.4.1

  1. Log in to the BIG-IP Configuration utility.
  2. Click System.
  3. Click Configuration (in BIG-IP 9.4.x, click General Properties).
  4. From the Global Traffic menu, select Metrics Collection.
  5. Enter a value in the Metrics Caching field.
  6. Click Update.
