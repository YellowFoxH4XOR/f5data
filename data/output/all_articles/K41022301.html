Description

When only provisioning AFM module you do not see any option to configure ALG logging profile

Environment

  • AFM
  • CGNAT not provisioned
  • 15.x and later

Cause

CGNAT functionality is now moved under AFM, however the ALG logging profile does not appear under AFM module. Without the CGNAT module provisioning, it is not possible to configure the ALG logging profiles.

Recommended Actions

Provision CGNAT module along with AFM module to use the ALG logging profile in version 15.x and later.
This issue is tracked under the BUG ID 1097973, which will give an option to configure ALG logging profile via tmsh with only AFM module provisioned.
