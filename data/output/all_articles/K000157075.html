K000157075: Whitelisting IP range for TCP connection/rate limits

Type
Support Solution
Published
2025-11-28
Updated
2025-11-28
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.1.2, 17.1.1, 17.5.X, 17.1.X, 17.5.1, 17.5.0, 17.1.3
Source
https://my.f5.com/manage/s/article/K000157075

Description

You want to set TCP connection/rate limits, but you would like to whitelist some IP addresses.

Environment

  • BIG-IP

Cause

While applying connection/rate limits, you want it to be ignored for specific IP addresses, for example for some external scanners.

Answer/Recommended Actions

There is no built in option to whitelist range of IP addresses from TCP connection/rate limit.

In order to bypass it for some IP addresses, you can create second virtual server and specify source address so this virtual server handles traffic for hosts that you want to exclude from limits which you applied for your regular virtual servers.
