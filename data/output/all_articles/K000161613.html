K000161613: Can a virtual Base Registration Key be used in a physical device and viceversa?

Type
Support Solution
Published
2026-06-08
Updated
2026-06-11
Source
https://my.f5.com/manage/s/article/K000161613
Details

Description

Cannot re-use or apply the base registration key of a Virtual Appliance on a physical Appliance/Hardware or a base registration key of a physical Applicance/Hardware on a Virtual Appliance.

Environment

  • Appliance
  • Base Registration key
  • Reactivate License

Cause

Want to use a spare base registration key for a virtual device in a physical device or viceversa.

Recommended Actions

Base Registration Keys for virtual devices are not compatible with physical devices, also, physical Base Registration Keys are not compatible with virtual devices. It is imperative that the Base Registration Key used is being used for the kind of device it was configured for.

 

Note: While virtual Base Registration Keys can be released to used in different virtual devices, physical Base Registration Keys cannot be released unless an RMA process has been completed.
