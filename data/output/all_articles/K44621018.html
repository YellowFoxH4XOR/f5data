K44621018: Auto-indent is enabled by default on tmsh edit command

Type
Support Solution
Published
2022-01-20
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K44621018

Description

There are some configuration objects such as syslog or iRule that you can modify manually on tmsh shell using edit command. When you copy and paste some lines for adding configurations, auto-indent implicitly works and paste gets unexpected results that configuration lines are often collapsed. Paste mode is recommended to successfully paste all the lines as they are.

Environment

  • BIG-IP system

Cause

This is by design.

Recommended Actions

Input ":set paste" to get paste mode and then move into insert mode when you paste some lines that some space or # character for commented out are preceded.
