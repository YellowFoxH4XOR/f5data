Description

When restoring the F5OS-A configuration, the following error may be encountered:

APPLIANCE-1 (config)# system database config-restore name <backup file name>
A clean configuration is required before restoring to a previous configuration.
Please perform a reset-to-default operation if you have not done so already.
Proceed? [yes/no]: yes
Error: Database config-restore failed.

Environment

  • F5OS-A
  • rSeries Appliance 2x00 and 4x00
  • Restoring management CLI database backup file between 2 different rSeries Appliances
 

Cause

Bug ID 1124853

Recommended Actions

If you are restoring the configuration database from a different F5OS-A appliance, you will need to ensure that the port-profile is the same.

If you are unable to ensure that the port-profile the same, you will need to manually edit, with a text editor, the management CLI backup file and delete the <portgroup> stanza from:
        <portgroups xmlns="http://f5.com/yang/portgroup">
    to
        </portgroups>
