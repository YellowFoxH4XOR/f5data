K000151374: Available object for NetSNMP MIBs within F5OS-A 1.8.0 release

Type
Support Solution
Published
2025-05-16
Updated
2025-05-21
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000151374

Description

As of F5OS-A 1.8.0, standard NetSNMP MIBs are available.

F5 imported some SNMP definitions from those standards MIBs in the F5OS-A enterprise MIBs.

This document describes about available object for NetSNMP MIBs within rSeries F5OS-A 1.8.0 release.

Environment

  • F5OS-A 1.8.0

Cause

Not all object defined in standards NetSNMP MIBs is available, F5 imported some objects from those standards MIBs in the F5OS-A enterprise MIBs.

 

Recommended Actions

As of F5OS-A 1.8.0, the following objects for NetSNMP MIBs are available:
