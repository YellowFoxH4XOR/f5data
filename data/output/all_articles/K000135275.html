K000135275: Unable to receive email alerts from BIG-IP appliance.

Type
Support Solution
Published
2023-06-28
Updated
2023-08-02
Source
https://my.f5.com/manage/s/article/K000135275

Description

User unable to receive SNMP email alerts from the BIG-IP appliance, while checking the network connectivity & telnet the SMTP email server on port 25 is working. 

Tried generating test alerts using the below log, however, emails are not getting triggered from the BIG-IP.

logger -p local0.notice "<logged error message>"

Environment

BIG-IP LTM
SNMP
SMTP
Email alerts
alertd deamon

Cause

Issue is due to alertd process stopped working.

Recommended Actions

restart the alertd process.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To restart the alertd process, enter the following command:
tmsh restart /sys service alertd

Log in to the bash shell.
To stop the alertd process, type the following command:
tmsh stop sys service alertd

Open the user_alert.conf file for editing and compare the newly configured alerts with the examples in the previous procedures. After you fix any typographical errors, proceed to the next step.
To start the alertd process, type the following command:
tmsh start sys service alert
