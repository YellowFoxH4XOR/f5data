K05351323: BIG-IQ can't import virtual server if the virtual server name contains a colon

Type
Support Solution
Published
2020-01-15
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K05351323

Description

The BIG-IP LTM will allow for a valid IP address and port as the name of a virtual server.  Importing this configuration into BIG-IQ will fail with error message:

Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Invalid name: <IP address and port>. Invalid address (<address and port>). Contains v4 and v6 separators but doesn't match mixed notation format.
where

  • <IP address and port> is a valid IPv4 address in dotted notation and ending with a : and valid port reference
  • <address and port> is the specific virtual server name that is invalid
Example:
Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Invalid name: 10.0.0.1:80. Invalid address (10.0.0.1:80). Contains v4 and v6 separators but doesn't match mixed notation format.

Environment

  • BIG-IQ importing configuration
  • BIG-IP LTM with virtual servers named with ip address and port

Cause

The BIG-IP will treat a valid IPv4 address + ":" + valid port as a virtual server name.  The BIG-IQ will not.

Recommended Actions

Remove and re-create the virtual server on the BIG-IP with a valid alphanumeric name not including a ":" character.

Additional Information

F5 has recommended that BIG-IP object names begin with an alphabetic character and do not contain special characters.  Moving forward to IPv6 addressing will cause additional validation concerns for virtual server names including colons.
