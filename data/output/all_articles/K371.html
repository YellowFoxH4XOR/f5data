Known Issue

This is the result of a known issue. You can use the config command to create a default gateway pool; however, you cannot use the config command to modify an existing default gateway pool. Any changes that you make to an existing pool using the config command will not save to the configuration file.

F5 Networks Product Development is tracked this issue as CR27260 and CR41824.

Workaround

To work around this issue, modify existing default gateway pools using the Configuration utility or the bigpipe pool command.
