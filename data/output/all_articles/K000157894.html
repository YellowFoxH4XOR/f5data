Description

This article provides guidance on configuring the NGINX Ingress Controller (NIC) to allow users to view NIC instance details and R33+ Usage license information within the NGINX Instance Manager (NIM) user interface. It outlines the required management settings for integrating NIC with NIM, specifically for license visibility.

Environment

  • Product: NGINX Ingress Controller (NIC)
  • Management Platform: NGINX Instance Manager (NIM)
  • Configuration Method: Helm chart parameters
  • Feature: NGINX R33+ Usage license reporting
  • Agent configuration: Not required for this use case

Cause

None

Recommended Actions

To enable viewing of NIC instance and usage license information in NIM:

  1. Configure the following Helm chart parameter when deploying or updating NIC:
    - Set controller.mgmt.usageReport.endpoint to the hostname or address of your NIM instance.
  2. Deploy or update your NIC deployment using the above Helm values.
  3. Log in to the NIM UI and navigate to the "NGINX Usage" page to view license information for your NIC instance.

Note: Agent configuration is not necessary for this specific requirement.
For advanced monitoring or agent-based integration, refer to Security Monitoring documentation.

Additional Information

  • The "NGINX Usage" page in the NIM UI displays NGINX R33+ Usage license details for registered NIC instances.
  • Documentation exists for implementing agent configuration if needed for other scenarios.
