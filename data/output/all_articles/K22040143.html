Description

Where does the VELOS system store its tenant's ISO images?

Partition: IMAGES/
Controller: /var/F5/partition<partition-ID>/IMAGES/

Environment

  • F5OS-C
  • VELOS system

Cause

None.

Recommended Actions

To find the partition ID for particular partition, run the following command on Controller CLI after you login as the chassis admin:

syscon-1-active# show partitions
                                                                          RUNNING

NAME           ID  VERSION      VERSION      CONTROLLER  STATUS           VERSION      AGE
-----------------------------------------------------------------------------------------------
foo2Partition  1   1.2.1-10781  1.2.1-10781  1           running-active   1.2.1-10781  3d
                                             2           running-standby  1.2.1-10781  3d
foo1Partition  2   1.2.1-10781  1.2.1-10781  1           running-active   1.2.1-10781  3d
                                             2           running-standby  1.2.1-10781  3d

In the output of the previous example, the foo2Partition has an ID of 1 as indicated in the ID column while the foo2Partition has an ID of 2.

Additional Information
You can upload tenant image file to partition's IMAGES/ directory from your machine using scp.:

scp <path/to/tenant_image_file> admin@<partition_mgmt-ip>:IMAGES/

For example,

scp /sr/somonauk/BIGIP-15.1.8.2-0.0.17.ALL-F5OS.qcow2.zip.bundle admin@192.168.1.100:IMAGES/
