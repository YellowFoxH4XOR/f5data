Description

  • You want to know how to create a route redirection

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer

Resolution/Answer

To do an URL redirection:

1. Visit the configuration of the corresponding Load Balancer and click on Edit Configuration

2. Scroll down to Routes configuration section and click Configure

3. Select Add Item

4. Go through the following steps in the form that appears:

  • Select Redirect Route for the type of route
  • Select which HTTP Method should match this redirect
  • Set Path Match
  •  

 

4. In the Redirect Parameters set:

  • Protocol which should be use in redirect
  • Host - if you want to swap incoming host with different one. if Host is empty, we will use host header from incoming request. 
  • Redirect Path - all incoming requests will be redirected to provided path. When field is empty, route will use path provided in request.  
  • Response code which we will use in redirect response e.g. 302

 

5. Click Apply to save the redirect configuration

6. Click Apply to save the route configuration

7. Scroll down and click to Save and Exit to save the changes
