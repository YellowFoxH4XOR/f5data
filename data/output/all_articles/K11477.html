Known Issue

This is the result of a known issue. When performing a firmware upgrade on an ARX 500 platform, the Non-Volatile RAM (NVRAM) may not be saved. When the NVRAM is not saved, an error message that appears similar to the following example is logged to the syslog file:

:NVRDAEMON-0-NOTE-MSG5:: mem not saved, do BIST

As a result of the NVRAM not being saved, the ARX system must reimport any configured shares for managed volumes.

F5 Product Development tracked this issue as ID 37855 and it was fixed in ARX versions 5.0.7, 5.1.7 and 5.2.0. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in a hotfix available for ARX versions 5.0.6 and 5.1.5. To request this hotfix, contact F5 Networks Technical Support and reference this Solution and ID number.
