Topic

F5 has released HF-610-7. This hotfix corrects several issues that affect customers running FirePass version 6.1.0.

The following table lists the rollup hotfixes available for FirePass version 6.1.0. The table lists the ID number of the related bug, a link to the corresponding article (if an article exists), and a brief description of the issues that the hotfix resolves.

Note: These rollup hotfixes are cumulative; each hotfix contains all fixes included in the previous hotfixes. For example, HF-610-3 includes all IDs fixed in HF-610-1 and HF-610-2.
