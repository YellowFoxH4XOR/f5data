Description
Running "show running-config interface" command in imish will not produce any output, crash the imi daemon resulting in a core file in /shared/core/, and cause interface to flap.

Environment

  • BIG-IP.
  • Dynamic Routing enabled with only BGP enabled as a routing protocol.
  • Run the "show running-config interface" command without specifying an interface.

Cause
The issue is caused due to BUG ID977953.

Recommended Actions

There is no fix for this bug at the time of publishing this article.

There is a workaround, though, which is to simply add any other routing protocol along with BGP into the route-domain. For example, to add OSPFv2 to the list of routing-protocols running on the route-domain: 

# tmsh modify net route-domain 0 routing-protocol add { OSPFv2 }
# tmsh save sys config

This example would be for route-domain 0.

Note: You do not need to add any OSPF configuration. Simply enabling the protocol to have more than one routing daemon running will prevent the bug from triggering.

Alternatively, ensure not to run 'show running-config interface' when inside imish unless you specify an actual interface as a prefix.
