Known Issue

This is the result of a known issue. Some BIG-IP ASM Configuration utility pages may not display properly after booting to a slot containing a different version.

For example, if you are running BIG-IP ASM version 9.3.x on one slot on the system and version 9.4.6 on an alternate slot, and you boot from the older version to the new version, the BIG-IP ASM Configuration utility may incorrectly display segments from the older version. This issue occurs when objects remain in the local browser cache.

For example, after booting from version 9.3.x to version 9.4.6, the Configuration utility may display the following incorrect path for a security policy properties page:

Advanced Firewall >> [Unknown Link] >> WebAppName >> PolicyName >> Security Policy Properties

The correct path should appear as follows:

Application Security >> WebAppName >> PolicyName >> Security Policy Properties

F5 Product Development is tracking this issue as ID 222470 (formerly CR120020).

Workaround

You can work around this issue by clearing the local browser cache.
