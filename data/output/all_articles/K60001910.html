K60001910: iOS F5 Access unable to connect to VPN after upgrading to 14.1.4 with reason: HTTP internal error (bad state transition)

Type
Support Solution
Published
2021-12-14
Updated
2023-03-01
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • F5 Access
  • BIG-IP APM: 14.1.4
Source
https://my.f5.com/manage/s/article/K60001910

Description
After BIG-IP has been upgraded from 12.1.6 to 14.1.4, iOS F5 Access clients fail to establish VPN connection. With debug logging, the below error message can be found in /var/log/apm:
  server-side connection was reset, reason: HTTP internal error (bad state transition)
  
In the client log file PacketTunnel.log, below repeat error message can be found:
  Prelogon Request failed: Error Domain=NSURLErrorDomain Code=-1005 "The network connection was lost."  
 

Environment

  • BIG-IP APM
  • F5 Access 3.0.9

Cause
A OneConnect profile is applied to the virtual server 

Recommended Actions

To work around this issue, you need to remove the OneConnect profile from the virtual server. To do so, perform the following procedure:

Impact of workaround: Removing the OneConnect profile from the virtual server should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Click on the name of the affected virtual server.
  4. Set the Oneconnect profile to None.
  5. Click Update.
