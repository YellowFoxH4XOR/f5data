Description

When trying to disable a node, you get the following error: 01070029:3: The monitor rule /Common/icmp was not found.

When checking into the node's configuration, the Select Monitors field appears empty, when the node used to have the default icmp monitor configured.

You get the same error when trying to add the icmp monitor again or when trying to perform a ConfigSync on an HA pair presenting the issue.

Environment

  • Disabling a node that belongs to a pool
  • Nodes configured with default icmp monitor
  • After ConfigSync

Cause

Bug ID 717896: Monitor instances deleted in peer unit after sync

Recommended Actions

Upgrade to a version where ID 717896 is fixed. Alternatively, to workaround the issue on affected versions, you can refer to the Bug ID 717896 link or perform an mcpd reload of the affected unit: K13030: Forcing the mcpd process to reload the BIG-IP configuration.
