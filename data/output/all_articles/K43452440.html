Description

Virtual server with an iRule utilizing the command IP::reputation may produce Tcl run-time errors and abort connections if /var directory is out of disk space. A log messages similar to the following are logged to /var/log/ltm:

Jun 6 21:34:52 <Hostname> err tmm8[14142]: 01220001:3: TCL error: /Common/<iRule Name> <HTTP_REQUEST> - IP Reputation database (/var/IpRep/F5IpRep.dat) not loaded (line 3) invoked from within "IP::reputation [IP::client_addr]"

 

Environment

  • IPI
  • iRule command IP::reputation

Cause

Var directory running out of space.

Recommended Actions

  • Periodically check disk space usage and use industry best practices for keeping disk usage to a minimum.
    For more information refer to: K14403: Maintaining disk space on the BIG-IP system check.
  • Unless it's needed, enforce the IP reputation using one of the built-in features such as Local Traffic Policy, BIG-IP ASM security policy ..etc).
