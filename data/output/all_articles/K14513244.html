Description

When selecting Source IP Addresses for AFM DoS Reporting, clicking Aggregated does not show any data (IP address).

This article explains about this behavior.

An example how to view this option can be seen at (but not limited to):

  1. Login to the BIG-IP GUI.
  2. Navigate to Reporting > Dos > Network.
  3. On the Attack ID, select the following options:
      Action: Dropped
      Attack Categories: Flood
      Attack Type: ICMPv4 Flood
      VLANs: Aggregated
      VLAN Groups: N/A
  4. Under Source IP Address, Aggregated is seen.

Environment

  • BIG-IP AFM
  • DoS reporting shows Aggregated for Source IP Address

Cause

None.

Recommended Actions

The BIG-IP AFM is able to display top 1000 client IPs.

The Aggregated Client-IP, is a name given to all the client-IPs that could not be collected and did not enter the list of top IPs.

When there is a large number of different client-IPs, the BIG-IP AFM is not able to collect all of them, so it keeps the ones with top activity and aggregate the rest. Although the rest are client-IPs that have less hitcount per client-ip, together they have lot of activity, and this is the reason we see them in the top of the list.

This is an expected behavior.
