Known Issue

Copying a BIG-IP APM access profile appends "_1" to the name.

This issue occurs when the following condition is met:

  • You use the Configuration utility to copy an access profile, by clicking Copy on the Access Profile List page.

Impact

This is a cosmetic issue which does not impact system functionality.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In your configuration, copied access profiles have "_1" appended to their names.

Workaround

To work around this issue, you can manually edit the /config/bigip.conf file and reload the configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Use a text editor, such as vi or pico, to edit the /config/bigip.conf file.
  3. Locate and replace the affected access profile names, save the changes, and then exit the editor.
  4. Reload the configuration by typing the following command:

    tmsh load /sys config
