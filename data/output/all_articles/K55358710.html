Known Issue

The Traffic Management Microkernel (TMM) process may leak memory if a Stream Control Transmission Protocol (SCTP) virtual server has high availability (HA) mirroring enabled.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is in an active-standby configuration.
  • You have configured an SCTP virtual server.
  • The virtual server has mirroring enabled.

Impact

TMM may become unstable and possibly produce a core file as a result of exhausted memory.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM processes have increasingly high memory usage on the standby device.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.

Workaround

To work around this issue, you can disable mirroring on the SCTP virtual server. To do so, perform the following procedure:

Impact of workaround: You may experience data loss if a failover event occurs.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the name of the virtual server you want to modify.
  4. For Configuration, click Advanced.
  5. Clear the Connection Mirroring box.
  6. Click Update.
