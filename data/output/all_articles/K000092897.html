K000092897: Where are sys db variables stored in a UCS file?

Type
Support Solution
Published
2022-11-30
Updated
2022-11-30
Source

Description

This article covers information on where db variable configurations are stored within a UCS file.

Environment

UCS file generated and looking to see where db variable configurations are stored.

Cause

N/A

Recommended Actions

The /config/BigDB.dat file should contain the db variable configurations.

Although this isn't an officially recommended or supported approach, it is theoretically possible to extract that /config/BigDB.dat file from the UCS file, make the change to the respective db variable's value, save the changes and then gzip compress it back into the UCS file before loading that file.

The officially recommended approach is to modify the db variable prior to saving the UCS file or else modify that once the UCS file has been loaded on to the system.

None.
