Description

The following error will appear in /var/log/racoon.log when debug2 level logging is enabled:

ERROR: invalid flag 0x08

For example: # cat /var/log/racoon.log

2019-01-01 12:00:00: DEBUG: ===
2019-01-01 12:00:00: DEBUG: 248 bytes message received from <remote-ip>[500] to 127.0.0.1[500]
2019-01-01 12:00:00: DEBUG: isakmp_handler: msg buf len=248 crc=0x5701d49a
2019-01-01 12:00:00: DEBUG2: check_recvdpkt: miss crc=0xfaaad528 bucket=1320 loc=127.0.0.1[500] rem=127.0.0.1[500]
2019-01-01 12:00:00: ERROR: invalid flag 0x08.

Environment

  • Bigip configured to terminate ipsec using ikev2

Cause

The error is logged because racoon (which handles ikev1) has received an ikev2 packet,

Recommended Actions

The trigger for the issue can be that the configured traffic-selector is using the default value of ::/0.
The correct value (to have a selector that applies to the entire ipv4 address range) should be 0.0.0.0/0

This can be checked with the following command:

tmsh list net ipsec traffic-selector <name> all-properties | grep destination-address

for example:

tmsh list net ipsec traffic-selector IPSec_Traffic_Selector_example all-properties | grep destination-address

example output:

destination-address ::/0

And corrected with the following steps:
  1. Modify the IPSec Traffic Selector's destination address:

    tmsh modify net ipsec traffic-selector <name> destination-address 0.0.0.0/0

    for example:

    tmsh modify net ipsec traffic-selector IPSec_Traffic_Selector_example destination-address 0.0.0.0/0

  2. Confirm the destination address has been updated:

    tmsh list net ipsec traffic-selector <name> all-properties | grep destination-address

    for example:

    tmsh list net ipsec traffic-selector IPSec_Traffic_Selector_example all-properties | grep destination-address

    example output:

    destination-address 0.0.0.0/0

  3. Save the configuration change:

    tmsh save sys config

Additional Information

Note that their are other possible causes of ikev2 payloads being handled by racoon.
