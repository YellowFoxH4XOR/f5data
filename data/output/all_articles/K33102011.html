Description

It is not possible to view which profile attributes are inherited from a parent profile when using iControl REST.

Environment

  • iControl REST

Cause

None. This is intended behavior and there is no indicator to show if a particular value is inherited from the parent profile or not.

Recommended Actions

If you need to compare values with a parent profile, retrieve the configuration of both the given profile and the parent, then review the output.

Additional Information

It is also not possible to view profile inheritance information with tmsh output.

However you may view which parent profile a given profile defaults from, for example:

{
  "defaultsFrom": "/Common/http", <----------
  "defaultsFromReference": {
    "link": "https://localhost/mgmt/tm/ltm/profile/http/~Common~http?ver=13.1.1.5"
  }
}
