K75353708: HSTS (HTTP Profile) is not working in an iApp configuration, after upgrading the F5 to version 14.1.4.

Description

HSTS (HTTP Profile) is not working in an iApp configuration, after upgrading the BIG-IP. 

Environment

  • BIG-IP version 14.1.4
  • iApp F5 HTTP (f5.http.v1.3.0rc4)
  • HSTS is not working as expected after the upgrade. 

Cause

By default web acceleration and compression profiles can cache requests that will result in HSTS headers not immediately provided.

Recommended Actions

Remove web acceleration and compression profiles or delete the cached data on the Big IP.
Clear client browser cache and cookies, then re-test.

None
