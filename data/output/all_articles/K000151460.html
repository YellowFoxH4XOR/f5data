What Happened?

  • What Load Balancer Algorithms on XC Load Balancer and Origin Pool are compatible with each other?
  • XC Console doesn't make this clear. Some combinations will break the application/XC communication flow.

Environment

  • XC Console

Resolution/Answer

  • In general, the following is supported (anything else risks breaking):
    • If Origin Pool is configured with LB Override algorithm, then the associated Load balancer can have any desired LB algorithm.
    • If load balancer is configured with Round Robin algorithm, then the associated Origin Pool can have any desired LB algorithm.
