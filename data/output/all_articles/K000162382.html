Description

This article clarifies the Customer Edge (CE) upgrade process and includes notes and relevant information.

Environment

  •  F5® Distributed Cloud (XC) Customer Edge

Answer/Recommended Actions

Prerequisites:

  • Set a maintenance window of up to 3 hours to accommodate any unexpected issues.
  • Consider the minimum recommended resources: 8 CPUs and 32 GB RAM.
  • Ensure that the CE passes all the pre-upgrade checks, before to start the upgrade.

To complete the CE upgrade:

  1. Navigating to: Home > Multi-Cloud Network Connect > Overview > Infrastructure > Sites.
  2. On this tab, select the site you would like to upgrade.
  3. Start the upgrade on the F5 Software.
  4. Once it is complete, proceed with the upgrade of the Operating System.

Additional Information

Take into consideration:

  • It is important to know that the upgrade of the SW (software) and the OS (operating system) need to be performed separately.
  • Before starting the next upgrade, ensure that the site health is in good condition (95% - 100%).
  • The estimated time required to complete the upgrade is approximately one hour.
  • If the CE upgrade fails, please get the debug file (K000147795: How to collect debug information for cloud and on-premises Customer Edge sites) and contact to F5 Support .
    • Is important to know the CE upgrade will retry the process after fail.
