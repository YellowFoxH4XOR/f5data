Topic

This article applies to BIG-IP 10.x through 12.x. For information about other versions, refer to the following article:

  • K4443: Configuring the BIG-IP system to ensure BEA WebLogic HTTP servers respond with the HTTPS protocol (9.x)

You should consider using this procedure under the following conditions:

  • You use the BIG-IP system to terminate Secure Socket Layer (SSL) for load-balanced HTTP BEA WebLogic servers.
  • You want the BEA WebLogic servers to return URLs prefixed with HTTPS:// for the content.

Description

When you configure the BIG-IP system to terminate SSL for BEA WebLogic HTTP servers, you can ensure that the BEA WebLogic servers respond with HTTPS:// prefixed URLs. To do so, configure the BIG-IP system to insert an HTTP header named WL-Proxy-SSL: with a value of true into each request. To do so, perform one of the following procedures using either the Configuration utility or the Traffic Management Shell (tmsh).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP system.
  • You have configured the BEA WebLogic server(s) for SSL offload.
    Note: For more information regarding configuring BEA WebLogic servers for SSL offload refer to: A-Team Chronicles > Offloading SSL from WLS to the F5.

Procedures

Using the Configuration utility to create a custom HTTP profile to insert the WL-Proxy-SSL: true HTTP header

To create a custom HTTP profile that inserts an HTTP header named WL-Proxy-SSL: with a value of true into each request, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > HTTP.
  3. Click Create.
  4. In the Name box, type a name for the profile.
  5. In the Parent Profile menu, select http.
  6. For the Request Header Insert setting, select the custom check box.
  7. In the Request Header Insert box, type the following:

    WL-Proxy-SSL: true

  8. For the Redirect Rewrite setting, select the custom check box.
  9. In the Redirect Rewrite menu, select Matching.
  10. Click Finished.

Using the tmsh utility to create a custom HTTP profile to insert the WL-Proxy-SSL: true HTTP header

To create a custom HTTP profile that inserts an HTTP header named WL-Proxy-SSL: with a value of true into each request, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Create the custom HTTP profile by using the following command syntax:

    create /ltm profile http <profile_name> defaults-from http header-insert "WL-Proxy-SSL: true" redirect-rewrite matching

    In this command syntax, note the following:

    • <profile_name> is your desired profile name.
  3. Save the configuration by typing the following command:

    save /sys config
