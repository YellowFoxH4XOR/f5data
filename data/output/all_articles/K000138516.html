Description

Virtual Server configuration is using HTTP Profile and SOCKS profile is disabled.

 

Environment

BIG-IP LTM

HTTP Profile

SOCKS Profile

 

Cause

HTTP is 80/443. SOCKS is 1080. Different TCP services and different Profiles and they can not be used together.
 

Recommended Actions

Remove the HTTP profile from the VIP config and SOCKS profile will get enabled:
