K70171151: Attempt to issue utility license for disconnected BIG-IP hangs

Type
Support Solution
Published
2021-03-05
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K70171151

Description

Attempt to license the unreachable BIG-IP with a utility license hangs with no error message.

Environment

  • Existing BIG-IP VE that is unreachable by the BIG-IQ.
  • Pool of utility licenses managed by BIG-IQ.

Cause

  • The unitOfMeasure field is missing and required to assign an utility license.
  • There is no prompt for this, it must be edited in the HTTP POST command.

Recommended Actions

  • Include the UnitOfMeasure with the appropriate value in the POST.

Additional Information

None
