Topic

You can only activate an add-on license key for one device. To move an add-on license key from one device to a different device, you must contact F5 Support.

Note: This article describes the process of removing an add-on key and re-activating the license. If you are looking for instructions on how to add an add-on key, refer to the Activating an add-on module section of K7752: Licensing the BIG-IP system.

Description

After you activate an add-on license key for a device, you cannot activate the same add-on license key on another device. To move an add-on license key from one device to a different device, you must contact F5 Support to retire the existing add-on key and receive a new key.

Note:

  • F5 Support can retire Add-on keys only within two weeks of initial activation. After two weeks of activating an Add-on key, if you must move the Add-on key to another device, contact your F5 Account manager to do so. 
  • If multiple add-on keys of the same SKU (example: the duplicated add-on didn't increase the throughput/feature of the base license) have been activated, an exception will be given, and the request can still be processed.  
  • If the mis-applied add-ons are subscription add-ons, all add-on keys (with the same function) tied to the unit must be removed, not just the extra(s).

Remove an old add-on key and re-activate the license

Before contacting F5 Support, you should first remove the old add-on key and re-activate the license for the device you are removing the add-on key from. To do so, perform the following procedure:

Impact of procedure: When re-activating the license, traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the add-on module on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. Select Re-activate.
  4. For Add-On Registration Key List, select the add-on key to be removed.
  5. Select Delete.
  6. For Activation Method, select the appropriate option.
    • If you select Automatic:
    1. Optional: For Outbound Interface, select the appropriate option to contact the F5 License Server.
    2. Select Next.

      The BIG-IP system automatically connects to the F5 License Server and activates the license.

      Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the add-on module on your BIG-IP devices while they are in standby mode.

    • If you select Manual:
    1. Select Next.
    2. Copy the dossier.
    3. Go to the F5 Licensing Tools page and select Activate F5 product registration key.
    4. In the Enter your dossier box, paste the dossier, and select Next.

      The F5 Licensing Tool page produces your license.

    5. Copy the license and paste it into the License box in the Configuration utility.
    6. Select Next.

      Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the add-on module on your BIG-IP devices while they are in standby mode.

  7. Contact F5 Support to request retirement of the old add-on key and get a replacement new key.
