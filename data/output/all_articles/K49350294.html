Description

Physical network interfaces on a BIG-IP hardware show status DOWN, while they still show UP on the HA pair hardware.

On the device presenting the issue, you can find similar logs on /var/log/ltm:

info lacpd[<PID>]: 01160011:6: Link 1.1 Actor Out of Sync
info lacpd[<PID>]: 01160012:6: Link 1.1 Partner Out of Sync
info lacpd[<PID>]: 01160011:6: Link 1.2 Actor Out of Sync
info lacpd[<PID>]: 01160012:6: Link 1.2 Partner Out of Sync

Environment

When listing the interface configuration with: tmsh list net interface <interface> media-activeyou notice the media-active configuration has lost its configured value and instead it shows none, similar to the following example:

list net interface 1.1 media-active
   net interface 1.1 {
   media-active none
}

Cause

Unknown at the time of publication.

Recommended Actions

From the command line, reconfigure the media-active setting for the interfaces that are DOWN, with the following tmsh command:

modify net interface <interface> media <speed-duplex>

For example:

modify net interface 1.1 media 10000SR-FD

Note: If setting the media-active values manually does not help bring UP the interfaces, the issue could be hardware related, and further troubleshooting on the BIG-IP side and switch side, needs to be done. Follow the steps on K62013114: Troubleshooting network interface flapping to continue to determine if the issue is hardware related and could require a replacement.
