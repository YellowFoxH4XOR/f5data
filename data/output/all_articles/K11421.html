K11421: A remote desktop user's Network Access traffic may be accessible to other users

Topic

When a user connects to Network Access on FirePass, BIG-IP SAM, or BIG-IP APM, a network adapter and routing configuration is created for a network interface card (NIC), which will affect all users applying that NIC. If multiple users are logged in to the same computer using a remote connectivity solution, such as Remote Desktop, and one user establishes a Network Access connection, the other users on the machine may be able to send traffic through the Network Access tunnel. In addition, the other users may see the traffic between the authenticated Network Access user and any resources they are connected to that do not utilize encryption by running a network sniffer tool, such as tcpdump.

To prevent other users on the machine from accessing the Network Access tunnel, you can use portal access. Portal access does not create a route or network adapter on the NIC that other users can apply.

Note: For more information about creating portal access, refer to the Administrator Guide for your product.
