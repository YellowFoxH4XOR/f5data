K64309253: Automatic ASM attack signature failing

Type
Support Solution
Published
2022-03-28
Updated
2024-06-12
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.4, 15.1.2, 15.1.3
Source
https://my.f5.com/manage/s/article/K64309253

Description

ASM attack signatures not auto updating

Environment

  • BIG-IP ASM 
  • Automatic Attack Signature Enabled or Checking for Live Updates

Cause

A possible cause of this issue is due to Bug ID 951133.


Recommended Actions

  1. Verify bugID by running the below restcurl request.
# restcurl -u admin: /mgmt/tm/live-update/asm-attack-signatures/availability

The output should be something like the one below, showing a code 500

{

"code": 500,                   
"message": "complete() of GET http://localhost:8100/tm/live-update/asm-attack-signatures/availability from Unknown Unknown called with incompatible status code 500 so redirecting to failed()",
"referer": "Unknown",
"restOperationId": 15545819,
"kind": ":resterrorresponse"

}
 

2. Apply the workaround mentioned for Bug ID 951133 which is restarting tomcat service. 

# bigstart restart tomcat
