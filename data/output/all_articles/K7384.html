Known Issue

This is the result of a known issue. The BIG-IP GTM system is supposed to interpret a BIG-IP LTM virtual server with an unknown (blue) status as available (green). This status ensures that BIG-IP LTM virtual servers that reference an iRule or an unmonitored pool are not marked down by the BIG-IP GTM system. However, the BIG-IP GTM incorrectly interprets a BIG-IP LTM virtual server with an unknown (blue) status as offline (red).

F5 Product Development tracked this issue as CR77121 and it was fixed in BIG-IP GTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
