Description

The following error message is logged in /var/log/ltm after attempting to renew the license:

err mcpd[13565]: 01070596:3: An unexpected failure has occurred, can't delete file (/var/.snapshots_d/bdosd) err (Is a directory). - sys/validation/FileObject.cpp, line 599, exiting...

 

Environment

  • BIG-IP
  • re-license
  • mcpd restarting

 

Cause

Unknown

 

Recommended Actions

Manually delete directory /var/.snapshots_d/bdosd

rmdir /var/.snapshots_d/bdosd

None
