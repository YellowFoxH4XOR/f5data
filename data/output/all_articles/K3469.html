Topic

If you plan to use a PXE server to install the BIG-IP LTM system, the server must meet the following minimum system hardware requirements:

  • Intel Pentium III processor
  • 96 MB RAM
  • USB certified compliant CD-ROM drive or ATAPI CD-ROM compliant with ANSI NCITS T13 specification
  • Compatible network interface card

Note: For a complete list of supported network cards, refer to K3359: Network interfaces cards supported by the F5 PXE network boot server.
