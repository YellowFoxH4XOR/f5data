Known Issue

This is the result of a known issue. When using the ANIP kernel, the performance for virtual servers that only use L4 functions is reduced when they have not processed traffic using L7 features.

For example, if you temporarily configure an L7 rule on a virtual server, remove the rule, and then process L4 traffic, the performance of the virtual server increases as much as 10 percent.

F5 Networks Product Development tracked this issue as CR31182 and CR41766.
