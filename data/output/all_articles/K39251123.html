Description

When trying to add an NTLM Machine Account, an error shows up asking to check the logs.

  • In the GUI:
Some unexpected error has occured. Check logs for more information.
  • In the CLI:
/var/log/tomcat/catalina.out
2021-06-10 08:20:28,427 INFO  [hostname] machineaccount.MachineAccountCreateHandler:joinMachine     - Execute NTLM Domain Join for Machine Account (someaccount)
2021-06-10 08:20:28,466 ERROR [hostname] machineaccount.MachineAccountCreateHandler:trigger     - java.lang.IllegalArgumentException: Invalid parameters passed to Syscall
  
/var/log/webui.log
2021-06-10 08:20:28,427 INFO  [hostname] machineaccount.MachineAccountCreateHandler:joinMachine     - Execute NTLM Domain Join for Machine Account (tusldf5dev)
2021-06-10 08:20:28,466 ERROR [hostname] machineaccount.MachineAccountCreateHandler:trigger     - java.lang.IllegalArgumentException: Invalid parameters passed to Syscall

Environment

  • BIG-IP APM
  • NTLM Machine Account

Cause

The password that is being used contains not valid characters:

Recommended Actions

The password should not contain any of these characters.

  • (
  • )
  • ;
  • !
  • |
  • $
  • <
  • >
  • &
  • '
  • "
  • `
  • \
  • {
  • }

None.
