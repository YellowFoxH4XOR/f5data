Known Issue

The BIG-IP neurond process may continually restart after you restart the system.

This issue occurs when all of the following conditions are met:

  • You have restarted the BIG-IP system.
  • You are running on one of the following platforms:
    • VIPRION B4450 blade
    • BIG-IP i10600, i7600, i5600, i10800, i5800, i7800, i11600, i11800, i5820-DF, i7820-DF, i11800-DS, i11600-DS, i11400-DS
    • BIG-IP i15600, i15800

Impact

The BIG-IP system fails to start and is unable to process network traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system continuously logs messages similar to the following example:

    emerg logger: Re-starting neurond

  • In the /var/log/neurond log file, you observe messages similar to the following examples:

    neurond_i2c_config_steps: STEP 20 Checking for Lane Alignment
    neurond_i2c_config_steps: Timeout waiting for good rx_align for ILK1 of NSP
    neurond_i2c_config: neurond_i2c_config_steps failed

Workaround

To work around this issue, you can disable the neurond process from starting at boot. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Important: This workaround is incompatible with the FIX Low Latency option. If you are using this feature, do not perform this workaround.

Disabling the neurond service

  1. Log in to the Advanced Shell (bash) as the root user.
  2. Type the following command:

    bigstart remove neurond

  3. Restart the BIG-IP system.

Re-enabling the neurond service

  1. Log in to bash as the root user.
  2. Type the following command:

    bigstart add --default neurond
