Description

BIG-IP DNS failed to load configuration after upgrading the BIG-IP system or rebooting it (likely after force reloading configuration per K13030). Running the gtm_add command may result in the same state.

When the issue occurs, you will see an error message similar to the following.

01071b63:3: The prober fallback value for server /Common/server1 cannot be the same as the inherited prober preference value.
Unexpected Error: Validating configuration process failed.

01071b62:3: The prober preference value for server /Common/server2 cannot be the same as the inherited prober fallback value.
Unexpected Error: Validating configuration process failed.

Environment

BIG-IP DNS

Cause

Invalid configuration caused by ID 1055077.

Recommended Actions

Follow the workaround on the page below to fix the invalid configuration state.

Bug ID 1055077: Modifying the datacenter does not check gtm server configuration for prober-pool

None
