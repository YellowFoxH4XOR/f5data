Description

  • When deploying an ADFS iApp it will not save to the configuration resulting in the following error message

Can't connect to ADFS

Environment

  • BIG-IP APM
  • ADFS iApp

Cause

When configuring the ADFS iApp a default monitor is applied, if this monitor fails - the iApp will not complete.

 Recommended Actions

  1. Ensure you are using the latest iApp.
  2. Ensure the monitor for the ADFS pool is configured correctly and responding.
  3. If you are unsure if your monitor is correct - you can add a gateway_icmp monitor to bring the pool member up to complete the iApp.
  4. Once the iApp is completed, please update the ADFS pool to a monitor that acceptable to respond to ADFS services.
