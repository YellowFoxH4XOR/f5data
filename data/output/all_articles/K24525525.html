Description
This article provides the procedure for regularly checking the validity of a BIG-IP Device Trust certificate.

Environment

  • BIG-IP Device Trust Certificate
  • checkcert utility
  • Cronjob 

Cause
None

Recommended Actions

Create a cron job for to run checkcert utility command at desired intervals.

  1. As root user, open the cron editor to add a cron job using the bash command:
    crontab -e
     
  2. Set the following to run the command every Sunday:
    0 0 * * 0 cd "/config/filestore/files_d/Common_d/trust_certificate_d/" && checkcert -s -f *dtca.crt*
     
  3. Save and exit the cron editor:
    :wq
     
  4. Verify the cron using the command:
    crontab -l


Note: Custom cron jobs do not survive upgrades. See K60435335.

Sample output on /var/log/ltm would be similar to the following when certificate has less than 30 days before it expires:
Sep 20 00:12:25 bigip1 warning checkcert[2983]: 01380002:4: Certificate '4df75642-d74a-4869-948000505686e550' in file :Common:dtca.crt_36716_2 will expire on Sun Sep 21 23:15:01 2031 GMT
