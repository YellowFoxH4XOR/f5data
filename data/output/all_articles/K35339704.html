K35339704: Order of precedence for virtual server based on Protocol

Type
Support Solution
Published
2022-07-08
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K35339704

Description

Connections received on BIG-IP will be assigned to VS for processing based on the Client connection protocol and Protocol profile configured on VS.

For example -

If multiple VS is created with same source and destination with same port but with different protocol profile like 'TCP', 'UDP', 'IP other' then connection will be assigned to VS based on client connection protocol as described below.
 

  • Client sending TCP connection will be assigned to VS with 'TCP' profile applied.
  • Client sending UDP connection will be assigned to VS with 'UDP' profile applied.
  • Client sending connection with any other transport level protocol then it will be assigned to VS with 'IP Other' profile.

 


Environment

  • BIG-IP Virtual-Server
  • BIG-IP Protocol Profile

Cause

This is by Design

Recommended Actions

'IP other' Profile is not designed to handle TCP or UDP connections. It should not be used in a VS to handle  TCP or UDP connection as it can cause intermittent packet drops or unexpected results.
