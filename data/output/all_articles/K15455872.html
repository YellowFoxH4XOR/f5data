Topic

You should consider using this procedure under the following condition:

  • You want to force an active BIG-IP device to standby mode using the TMOS shell (tmsh) from the command line of the BIG-IP system.

Description

When an event occurs on the active BIG-IP device that may prevent the system from processing traffic, this triggers a failover that shifts the active status from one BIG-IP device to an available peer device in the device group so that traffic processing can continue. As a result, the previously active device goes into standby mode. As a BIG-IP administrator, you can force a failover for maintenance purposes using tmsh on the BIG-IP command line. It's useful to know how to perform a failover from the command line in the event that the Configuration utility becomes unavailable or because you prefer working with the BIG-IP system from the command line.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to tmsh.

Procedures

Forcing an active device into standby mode

You can use tmsh to force an active BIG-IP device into standby mode. If the device has more than one traffic group, all traffic groups fail over to the next available device.

Impact of procedure: Performing this procedure causes a failover of all traffic-groups to the next available device in the device group.

  1. Log in to tmsh on the command line of the active device by entering the following command:

    tmsh

  2. Force the device into standby mode by entering the following command:

    run /sys failover standby

  3. The command prompt shows the failover status; however, you can verify the status by using one or both of the following commands:
    • show /cm traffic-group
    • show /sys failover
  4. Enter q to exit tmsh.

Failing over to standby mode when you have more than one traffic group or more than two devices

You can use tmsh to force a specific active traffic group on a BIG-IP device into standby mode. You can also specify the next active device if there is more than one device to fail over to.

Impact of procedure: Performing this procedure causes a failover of one or more traffic-groups to another device in the device group.

  1. Log in to tmsh on the command line of the active device by entering the following command:

    tmsh

  2. Perform one of the following procedures, as appropriate for your situation:
    • To force a specific traffic group into standby mode on the device, enter the following command syntax:

      run /sys failover standby traffic-group <traffic group name>

      For example:

      run /sys failover standby traffic-group traffic-group-2

    • To force the device into standby mode and specify a device to take the active role, enter the following command syntax:

      run /sys failover standby device <device name>

      For example:

      run /sys failover standby device bigip3.example.com

    • You can combine the traffic-group and device options of the command to fail over a specific traffic group to a specific device.
  3. The command prompt shows the failover status; however, you can verify it by entering one or both of the following commands:
    • show /cm traffic-group
    • show /sys failover
  4. Enter q to exit tmsh.
