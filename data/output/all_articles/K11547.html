Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator cache control header parsing is not case-insensitive. As a result, the BIG-IP WebAccelerator treats HTTP cache-control headers that contain capital letters as unknown cache-control directives.

For example, the BIG-IP WebAccelerator correctly parses a Cache-Control: public header. However, the BIG-IP WebAccelerator does not correctly parse the Cache-Control: Public header, even though it is valid.

F5 Product Development tracked this issue as CR133432 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator, WAN Optimization, or Edge Gateway release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0, and Hotfix-BIGIP-9.4.8-407.0-HF4 issued for BIG-IP 9.4.8. You may download the hotfixes or later versions of the hotfixes from the F5 Downloads site.
