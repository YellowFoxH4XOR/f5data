Known Issue

The Traffic Management Microkernel (TMM) may restart when you add a DNS profile to a virtual server with an unlicensed DNS module.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server to process DNS requests.
  • The virtual server reference a DNS profile.
  • The DNS module is not licensed.
  • The virtual server references an iRule.
  • A new connection triggers an event, such as CLIENT_ACCEPTED.

Impact

TMM may restart and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
