Known Issue

Traffic Management Microkernel (TMM) may produce a core file when a document has been cached with gzip encoding and a non-deflate compression method.

This issue occurs when all of the following conditions are met:

  • The BIG-IP AAM system is enabled on a virtual server.
  • The HTTP compression profile is enabled on a virtual server.
  • The document has entered the BIG-IP AAM gzip cache.
  • An HTTP client request specifies deflate encoding.
  • The document is served from cache with gzip encoding and non-deflate compression.

Impact

The BIG-IP system fails to process traffic while the TMM process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to access the BIG-IP system, or they may experience a traffic disruption.
  • The TMM process generates a core file to the /shared/core directory.
