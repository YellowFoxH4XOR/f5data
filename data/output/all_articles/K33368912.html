Topic

When you use the BIG-IP APM system, the secure network address translation (SNAT) behavior varies, depending on the type of BIG-IP APM resource you use. The BIG-IP APM system also enables you to specify the SNAT behavior for individual users who connect through the BIG-IP system.

Description

The BIG-IP APM system provides several different methods for communicating through the BIG-IP system. For some of these communication methods, the SNAT behaves the same as when the BIG-IP system communicates through a typical virtual server. However, some BIG-IP APM resources and features provide alternate SNAT behavior.

Most BIG-IP APM system resources and features communicate with internal servers and services by way of the virtual server SNAT setting.

However, you can override this behavior by including a Route Domain and SNAT selection object in the access policy. The Route Domain and SNAT selection object enables you to specify a SNAT configuration (Auto Map, None, or a previously configured SNAT Pool) to communicate with the internal servers and services. This functionality is advantageous if you want a different SNAT behavior for specific users or groups.

Note: You cannot use the Route Domain and SNAT selection object to specify the SNAT configuration of a network access VPN tunnel.

When the BIG-IP system communicates through a network access SSL VPN tunnel, the SNAT setting of the virtual server to which the user connects to establish the VPN tunnel is not used to communicate to the internal network. You can specify the SNAT behavior in the Network Settings : General Settings setting of the Network Access resource configuration. You can configure the virtual server and network access VPN with different SNAT settings. This helps you direct the internal network to detect the source IP addresses of the VPN users (which is often required when you connect a VOIP application over the VPN tunnel), but other BIG-IP APM resources accessed through the same virtual server as that used for the VPN tunnel require the source address to be translated.

Note: The available SNAT Pool options are: Auto Map, None, or a previously configured SNAT Pool.

When you specify Auto Map in the Network Access resource Network Settings, the BIG-IP system does not use a floating IP address when relaying VPN traffic to the internal network. For additional information, refer to K13782: The BIG-IP APM network access tunnel does not use a floating IP address.
