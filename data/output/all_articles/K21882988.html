Description

At the CLI prompt localdbmgr process is showing DOWN, but when checking the service it is showing as running:

[root@localhost:localdbmgr DOWN] config# tmsh show sys service localdbmgr
localdbmgr run (pid 14457) 50 days, 1 start, 206 restarts

Environment

  • BIG-IP
  • localdbmgr process

Cause

Usually this issue is seen after a disk space issue has occurred.

This is a cosmetic issue that could be related to a large number of restarts in the past.

Recommended Actions

Manually restart the process:

tmsh restart sys service localdbmgr

If restarting the process does not bring it back up, try rebooting the device. If it still persists after rebooting the device, please open a case with F5 Support.
