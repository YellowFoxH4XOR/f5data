Known Issue

This is the result of a known issue. If you install Cumulative Hotfix HF-602-3 or Cumulative Hotfix HF-602-4 for FirePass version 6.0.2 on the FirePass controller, users cannot logon to the FirePass controller using Windows logon integration if split tunneling is enabled on the Network Access connection. When this issue occurs, the user authenticates to the FirePass controller during Windows logon, but the Network Access connection is not established.

F5 Networks Product Development tracked this issue as CR99741 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-6 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by forcing all traffic through the Network Access connection. To do so, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Network Access: Resources page.
  3. In the Resource Group menu, select the resource group you want to configure.
  4. Under the Client Settings tab, select the Force all traffic through tunnel option button.
  5. Click the Update button.

As an alternative, you can work around this issue by uninstalling Cumulative Hotfix HF-602-3 and HF-602-4 from the FirePass controller. Once the hotfix removal is complete, download the Windows Logon Integration client component from the FirePass controller and install it on the affected client systems. For more information about downloading the Windows Logon Integration client component, refer to K8092: Configuring Windows Logon Integration.
