Description

Often while troubleshooting multislot/multiblade tenants we would need the logs and data from all the slots where the tenant is placed

 

Environment

  • BIG IP tenants
  • F5OS C

Cause 
Informational


Recommended Actions 

We have two options to gather this data.

  1. Access the management IP of the tenant with SSH and then from within the tenant ssh to the slots in that particular partitions and generate a qkview via command line

              SSH to tenant management IP
              # ssh <user>@<BIG-IP IP address>

 

              To log in to a specific slot, enter the following:
              # ssh slot<number>

              For example:
              # ssh slot1

             Generate the qkview via command line
             # qkview -s0

    2. If you have individual cluster member IP address configured for each slot, then you can ssh with the specific slot ip and make use of the same qkview command.


Note:-  Make sure the SSH between the slots are enabled and working for the 1st option to be put into use. At least one Cipher, one KEX algorithm, and one MAC from the ciphers used by the ssh client must be included for blade-to-blade communication to allow SSH between slots and qkview collection.
