Known Issue

BIG-IP platforms running AMD processors may unexpectedly restart due to watchdog timeout or Southbridge system reset.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP platform uses an AMD processor. The following BIG-IP platforms use AMD processors:
    • BIG-IP 6400
    • BIG-IP 6900
    • BIG-IP 89x0
    • BIG-IP 110x0
    • VIPRION B4100
    • VIPRION B4200
  • Your BIG-IP system is running a software version that contains the fix for CVE-2017-5754 (Meltdown). For information about which software versions contain these fixes, refer to K91229003: Side-channel processor vulnerabilities CVE-2017-5715, CVE-2017-5753, and CVE-2017-5754.
  • The following BIG-IP versions are affected by this issue:
    • BIG-IP 13.1.x: 13.1.0.4 - 13.1.1.4
    • BIG-IP 13.0.x: 13.0.1 and later
    • BIG-IP 12.1.x: 12.1.3.3 and 12.1.4
    • BIG-IP 11.6.x: 11.6.3.1 and later
    • BIG-IP 11.5.x: 11.5.6 and later

Impact

The BIG-IP system restarts, causing a traffic disruption. If configured in a Sync-Failover device group, the BIG-IP system fails over to another device in the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system spontaneously restarts.
  • The BIG-IP system logs messages similar to the following examples to the /var/log/ltm file after restarting:

    notice chmand[7529]: 012a0005:5: CPLD indicates prior Host CPU subsystem reset
    notice chmand[7529]: 012a0005:5: Host CPU subsystem reset - PCI reset asserted
    notice chmand[7529]: 012a0005:5: Host CPU subsystem reset caused by a Southbridge system reset

    warning chmand[7150]: 012a0004:4: Host CPU subsystem reset caused by *** Super I/O watchdog timeout ***

Workaround

To work around this issue, you can disable kernel page-table isolation (PTI) using the kernel.pti database key. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure disables the Meltdown fix. However, BIG-IP platforms with an AMD processor are not vulnerable to Meltdown. For more information, refer to K91229003: Side-channel processor vulnerabilities CVE-2017-5715, CVE-2017-5753, and CVE-2017-5754. This workaround requires restarting the BIG-IP system, which causes a traffic disruption and should be performed during a maintenance window.

  1. Log in to the Advanced Shell (bash).
  2. Set the kernel.pti database key to disable by entering the following command:

    tmsh modify /sys db kernel.pti value disable

  3. Restart the BIG-IP system by entering the following command:

    reboot
