Known Issue

The tmsh load command may ignore the base option when merging a single configuration file (SCF).

This issue occurs when the following condition is met:

  • You perform a configuration merge using the following command syntax:

    tmsh load /sys config merge file <SCF_filename> base

Impact

The BIG-IP system ignores the base option and loads the non-base configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system ignores the base option and loads the non-base configuration.
