Topic

The iControl representational state transfer (REST) selfLink property always contain localhost in the returned URI.

Description

The iControl REST API enables remote clients to view and modify BIG-IP system resources using web service requests.

When viewing BIG-IP system resources using the iControl REST API, specific resources are further subdivided by selfLink properties. By design, the selfLink property always returns a hostname of localhost in the URI, rather than a specific device hostname or IP address.

In the following example, the selfLink property for pool objects contains the hostname localhost in the URI, when the API queries a BIG-IP system named example.bigip.com:

curl -sk -u admin:admin https://example.bigip.com/mgmt/tm/ltm/pool

"selfLink":"https://localhost/mgmt/tm/ltm/pool?ver=11.6.0"
"items":[{"kind":"tm:ltm:pool:poolstate"
"name":"pool_one"
"partition":"Common"
"fullPath":"/Common/pool_one"
"generation":760
"selfLink":"https://localhost/mgmt/tm/ltm/pool/~Common~pool_one?ver=11.6.0"

Recommendations

When using the iControl REST API to view or modify objects and selfLink properties, replace the localhost URI with a DNS resolvable host name or IP address.
