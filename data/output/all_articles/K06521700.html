Description
You want to upgrade a managed BIG-IP on your BIG-IQ Central Management

Environment

  • BIG-IQ Central Management
  • Software Upgrades for Managed BIG-IP

Cause
None

Recommended Actions

- Before you can upload a software image to BIG-IQ, you must download it from the Download site.

- You upload a software image to make it available to deploy to managed BIG-IP devices.

- To make sure the software image successfully uploads, don't log out of BIG-IQ or close the browser window until the software image name appears in the Software Image list.
Note: When BIG-IQ uploads the software, it verifies the image. This verification process can take several minutes. When BIG-IQ is finished uploading and verifying the image, the software image displays as Verified and is available for installation on a device.
  1. - At the top of the screen, click Devices.
  2. - On the left, click SOFTWARE MANAGEMENT > Software Images.
  3. - Click Upload Image button.
  4. - Click Choose File  button navigate to the downloaded image files, and click the Open
- You can deploy software images only to BIG-IP devices running version 11.5.0 or later. Refer to the Upgrading a legacy device section for specific instructions about upgrading devices running version 10.2.0 - 11.4.1

- BIG-IQ makes it easy for you to upgrade your devices. You can upgrade a single device, or upgrade several at once. 
  1. At the top of the screen, click Devices.
  2. On the left click SOFTWARE MANAGEMENT > Software Installations.
  3. Click the Managed Device Install button towards the top of the screen.
  4. From the Software Image list, select the image you want to install.
  5. In the Name field, type a name to identify this installation.
  6. For the Options setting, you can enable one or more of the following by selecting the check box next to it:
  7. If you select an option to pause at any point during before, during, or after the installation process, you'll need to click Continue to move on to the next step.
  8. Perform pre and post installation assessment and select the managed objects you want to assess the state of, before and after upgrading, so you can investigate if any difference are found.
  9. Perform backups and select the Backup Properties options for the backup.
  10. Pause after the software image is copied has been copied to devices if you want to copy the image to this device, but wait until later to install it.
  11. Pause for reboot confirmation to pause before rebooting the devices after the software is installed.
  12. Install devices one by one for DNS sync group upgrades.
  13. Because the upgrades occur sequentially when you choose this option, when the installation finishes for the last device, all of the devices in the sync group are at the same software version, and the sync group can be brought back online.
  14. Click Add/Remove Devices to select devices to install this software on.
  15. If you are upgrading devices that belong to a DNS sync group, decide how you are going to choose devices for upgrade:

    - To use the sync group name, select Group/Cluster, and then select DNS Sync Group
    - To use the host names for individual devices, select Device.
  16. From the Available list, select the device(s) you want to upgrade, move it to the Selected list, and click Apply
  17. To set the location for where BIG-IQ installs this software image:

    - Click Set Default Volume.
    - Select Volume Name.
    - In the Volume Name field, type the name of the volume on which you want to install this image.
    - Click Apply.
  18. Click Run towards the middle of the screen to put the image on the BIG-IP device(s) immediately.
    Alternatively, you can click Save & Close to save this job to deploy the software later.
  19. If you selected the option to back up the BIG-IP device(s) before installing the software, when BIG-IQ pauses, Back Up Devices.
  20. If you selected the option to run a pre-installation assessment, when BIG-IQ pauses:
    - Click Run Pre-assessment.
    - Select the configurations that you want BIG-IQ to review before upgrading and click OK.
    - When the assessment is complete, click Continue to start the installation
  21. If you selected the option to back up the BIG-IP device(s) after installing the software, click Back Up Devices.
  22. If you selected the option to pause before rebooting the BIG-IP device after the software is installed, click Continue to reboot.
  23. To run a post-installation assessment, click Run Post-assessment
  24. To compare the pre-upgrade assessment and the post-upgrade assessment, click Compare Assessments towards the bottom of the screen, and click Mark Finished when it's done.
