Description

QKVIEW upload to ihealth fails with timeout  when  its send from BIG-IQ to ihealth.
Task for qkview creation works fine, file transfer fails. Proxy server is virtual server on BIG-IP with not configured persistence

Environment

  • BIG-IQ Centralized Management
  • Sending QKVIEWS from BIG-IQ to Ihealth Via proxy
  • Proxy Server is VirtualServer on BIG-IP without Persistence setup

Cause

It seems another http request from BIG-IQ goes to different proxy server and times out 

Recommended Actions

  1. Set persistence in Virtual server to send both http request from BIG-IQ to the same

Additional Information

None.
