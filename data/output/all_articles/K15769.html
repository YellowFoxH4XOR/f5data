Known Issue

BIG-IP APM access profile authentication with Oracle Access Manager (OAM) may be slow to respond.

This issue occurs when all of the following conditions are met:

  • The OAM AAA profile is configured with Transport Security Mode set to simple.

Impact

Access profile authentication is slow to respond.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Users experience authentication delays of up to 3 minutes when attempting to authenticate with the access profile that is configured with OAM AAA.

Workaround

To work around this issue, you can limit the number of retry attempts sent to the OAM. To do so, perform the following procedure:

Impact of workaround: There will be a temporary disruption in processing OAM authentication.

  1. Log in to the command line of the affected BIG-IP APM systems.
  2. Using a text editor, open the file /etc/bigstart/scripts/eam for editing.
  3. Locate the line "export OAM_WEBGATE_INIT_RETRY_COUNT=8" (approximate line number 47).
  4. Change the retry count value from 8 to 4.
  5. Save the modification and close the file.
  6. To manually restart the eam service from the command line, type the following command:

    bigstart restart eam

    Important: Restarting the eam service temporarily stops processing of access profile authentication for 3rd party identity integration such as OAM.
