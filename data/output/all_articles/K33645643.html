Known Issue

File Transfer Protocol (FTP) control channel connections (port 21) fail to establish through a secure network address translation (SNAT) object.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to process FTP control channel connections using only a SNAT object.

    Note: This issue does not affect FTP control channel connections through virtual servers configured to use SNAT.

  • A remote client attempts to initiate an FTP connection through the BIG-IP system.

Impact

FTP control channel connections (port 21) fail to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Remote clients are unable to establish FTP control channel connections through the BIG-IP system.
  • After upgrading the BIG-IP system, you notice remote clients are unable to establish FTP control channel connections.
  • Under rare conditions, the BIG-IP system generates a Traffic Management Microkernel (TMM) core file to the /shared/core directory.
  • Under rare conditions, the BIG-IP system temporarily fails to process traffic while TMM restarts.
  • Under rare conditions, the BIG-IP system fails over to another host in the device group.
