K3980: Configuring 3-DNS to failover if the 3dnsd process fails

Topic

Only units in a redundant pair that are in an active state may become principle 3-DNS units. If 3dnsd crashes or is stopped on an active 3-DNS, the standby system will not become principle by default.

You can change the default behavior so that 3-DNS will fail over whenever 3dnsd is stopped. To implement this change, type the following command.

bigpipe db set Common.Bigip.Failover.On3dnsfail = 1
