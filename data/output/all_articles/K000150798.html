K000150798: Nginx-plus not showing on NIM dashboard

Type
Support Solution
Published
2025-04-10
Updated
2025-04-10
Applies to
  • NGINX Products
  • NGINX Plus: R33
Source
https://my.f5.com/manage/s/article/K000150798

Description

  • You configured NGINX Instance Manager to manage NGINX Plus instances 
  • You deployed an NGINX Plus instance 
  • To manage this freshly created NGINX, you also installed NGINX Agent as per provided guide
  • However, you are unable to discover and view NGINX Instance on NGINX Instance manager

Environment

  • NGINX Plus
  • NGINX Instance Manager
  • NGINX Agent

Cause

  • Even if NGINX Agent service is in a running state, the Agent won't be able to send any kind of NGINX Plus status if Nginx's service is down.
  • Hence, initial instance discovery will fail and the Nginx will NOT show up on the Instance Manager; as the Agent is unable to find and interact with a healthy and working NGINX Instance.

Recommended Actions

  • verify NGINX Agent service status
                sudo systemctl status nginx-agent
  • verify NGINX Plus service status
                sudo systemctl status nginx
  • If NGINX service is down, determine cause by investigating error log at /var/log/nginx/error.log
  • Address the issue per log and restart service following
                sudo systemctl restart nginx
