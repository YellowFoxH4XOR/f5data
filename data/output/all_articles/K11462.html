Topic

The BIG-IP system does not allow you to delete a self IP when a route references that self IP address or subnet.

This behavior is by design, and is implemented to prevent unexpected routing conditions.

For example, if you attempt to delete a self IP that is referenced by a route, you will receive an error message that appears similar to the following example:

01070604:3: Cannot delete IP 10.1.0.150 because it would leave a route unreachable.

If you receive an error message that appears similar to the above example, update or delete the route object that references the self IP address or its subnet, and then delete the self IP.

Note: F5 recommends scheduling a maintenance window prior to updating or deleting a route.
