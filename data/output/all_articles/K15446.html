Known Issue

The BIG-IP Traffic Management Microkernel (TMM) may stop responding when you create a virtual server assigned to an invalid profile.

This issue occurs when all of the following conditions are met:

  • You create a profile with invalid values or a non-existent referred object.
  • You create a virtual server and assign it to the invalid profile.

Impact

The BIG-IP system may temporarily fail to process traffic, and may fail over if configured as part of a high-availability pair.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM stops responding and produces a core file in the /var/core directory.
  • An error similar to the following example appears in the /var/log/ltm file:

    01010025:2: Device error: mpi failed to allocate shared memory
