Command Line Accounts

Setting a new password for the root account when the previous password was lost or forgotten

To reset a forgotten or unknown password on the BIG-IP or 3-DNS Controller, you must:

  • Boot to single-user mode
  • Reset the root password
  • Reboot the controller

Boot to single-user mode

Note: You must have local access to the BIG-IP or 3-DNS Controller with a console (keyboard and video) connection. If you have a redundant pair of controllers, you can minimize site down time by using the standby system for this procedure.

To boot the controller to single-user mode, perform the following steps:

  1. If the controller is powered on, but you are not able to log in, hard reset the controller using the reset switch on the front panel.

  2. After the CMOS check, and during the boot sequence 4-second countdown, press the space bar to interrupt the boot process.

  3. At the boot prompt, type the following command:

    bsd

  4. At the Root device prompt, type the following command:

    wd0

    Note: This command only applies to F5 manufactured hardware. Other hardware, such as blades, Dell OEM, Nokia, and so on, have other root devices. Refer to the Platform Guide for specific instructions.

  5. At the shell prompt, type the following command:

    /bin/bash

  6. Mount the file system, by typing the following command:

    /sbin/mount -auw

    Note: Beginning in version 4.0, BIG-IP and 3-DNS Controllers have a protected file system.

Reset the root password

To reset the root password, perform the following steps:

  1. From the command line, type the following command:

    /usr/bin/passwd root

  2. When prompted, type the new password and press Enter.

  3. When prompted, retype the password and press Enter.

  4. Reboot the controller, by typing the following command:

    /sbin/reboot

  5. Once the controller finishes the boot cycle, log in using the new root password.

Changing the password for a command line account

You can change the root and support passwords from the command prompt by typing the following command variable:

passwd <account>

Replace <account> with either root or support. You will be prompted for the new password and a confirmation.

Adding, removing, or changing command line accounts from the command line

BIG-IP organizes users by roles. Roles determine what a particular user is permitted to do. The most commonly used roles are as follows:

Note: The roles listed are also the default role settings.




Administrator

This role is allowed to run administrative commands that deal primarily with communication between F5 devices. This role is used infrequently.
bigiprole1
This is equivalent to a junior administrator role. The user, to which this and no other role is assigned, can log in to the Configuration utility and view statistics and logs, and reboot/shutdown BIG-IP.
bigiprole2
This is the primary BIG-IP administrator role. A user with this role can do virtually any action with the BIG-IP, including modifying its configuration.
remoteuser
This role can log in to the command line using the password configured from the Configuration utility. Once logged into the command line, this role has BIG-IP root privileges.

The ldap utility

Beginning with BIG-IP version 4.5, all web administration user authentication is performed through a Lightweight Directory Access Protocol (LDAP) server that runs on BIG-IP. F5 Networks has created the ldap utility to assist you in modifying the LDAP database from the command line.

Using the ldap utility you can view, add, and remove users, change passwords, and add/remove roles from a user. You can view the basic syntax by typing the following command:

ldap -h

The output displays as follows:

Usage: [switch] [arguments]
Shows or modifies contents of local LDAP user database
ldap +u key commonName password role1 [role2...]
Adds new user.
ldap -u key
Removes user.
ldap +r key role
Adds role to user.
ldap -r key role
Removes role from user.
ldap -p key password
Changes password for user.
ldap -U
Shows current valid users.
ldap -R
Shows current valid roles.
ldap     Shows current valid users and roles.

Adding a user

To add a Configuration utility user with full Read/Write permissions from the command line, type the following command variable:

ldap +u user commonName password role1 <additional optional roles>

For example, to add the username jesse as bigiprole2, you would type the following command:

ldap +u jesse jesse MyPasswwd bigiprole2

Removing a user

To remove a user, type the following command variable:

ldap -u <user>

For example, to remove the user jesse, you would type the following command:

ldap -u jesse

Change the access level for a user

To change the access level for a Configuration utility user account from the command line, perform the following steps:

  1. Log in to the command line.

  2. Display the current users, by typing the following command:

    ldap -U

    Each user account will display with their assigned roles.

  3. To remove a role from a user account, use the following command variable:

    ldap -r <username> <role>

    For example:

    ldap -r askf5 bigiprole0

  4. To add a role to a user account, use the following command variable:

    ldap +r <username> <role>

    For example:

    ldap +r askf5 bigiprole2

  5. You can add multiple roles to a user account. For example, to provide both command line and full Configuration utility access to the user askf5, you would type the following commands:

    ldap +r askf5 remoteuser

    ldap +r askf5 bigiprole2

The access level for the user has been changed. These changes will take affect immediately.

Adding, removing, or changing command line accounts from the Configuration utility

The versions of BIG-IP and 3-DNS covered by this Solution do not allow you to make changes to command line accounts using the Configuration utility.

Configuration Utility Accounts

Setting a new password for the Admin account when the previous password was lost or forgotten

The web administrative account that you create using the First Time Boot/Setup Utility is the primary administrative account. Information about this account is contained within the BIG/db Configuration database.

Important: Do not use the htpasswd command to change the password for the primary administrative account. If you use the htpasswd command to change the primary administrative account password, the configuration synchronization with the peer unit will fail.

  1. Verify the name of the primary administrative account by typing the following command, where <file_name> is the name of a text file that is created by extracting information from the BIG/db Configuration database:

    bigpipe db dump <file_name>

    For example:

    bigpipe db dump dbdump.txt

    You will receive the following output:

    Dumping database "/config/user.db"
      to file "dbdump.txt"...
    Dumped 223 records

  2. Using the more utility, view the newly created file.

    For this example, you would type the following command:

    more dbdump.txt

  3. Look in the text file for the primary administrative account information. This account information appears after the phrase, Common.Bigip.CORBA.Users.

    You can use the / command to search for this information within the more utility. For example, typing /CORBA.Users and pressing enter will prompt the more utility to navigate directly to the relevant line.

    The output would appear similar to the following:

    Common.Bigip.CORBA.Users.root.172.16.100.54 = "=>KC5Udk29g;N^3<aFaUGjaQu(=e:cMdRjBMSfEc^Q7i`[" Common.Bigip.CORBA.Users.root.172.16.100.55 = "=>KC5Udk29g;N^3<aFaUGjaQu(=e:cMdRjBMSfEc^Q7i`["

In this example, the BIG-IP pair (172.16.100.54 and 172.16.100.55) are both using root as the name of the primary administrative account.

  • To change the primary administrative account password, type the following command:

    Note: This is the best way to change the password for the primary administrative account; however, this method does require navigating through a number of unrelated configuration screens.

    config redundant

  • From the list, select R.

  • Follow the prompts.

    • Changing all Other Web Administrative Account Passwords

    Passwords for all other web administrative accounts used in the web interface are stored in the /config/bigconfig/users file. To change these passwords, perform the following steps:

    1. Type the following command variable, where <account> is the username for which you would like to change the password, and <new password> is the new password for the account:

      ldap -p <user> <new password>

      For example:

      ldap -p TestUser1 MyNewPassword

    2. Follow the prompts.

    Changing the password for a Configuration utility account

    To change a Configuration utility password, type the following command variable:

    ldap -p user password

    For example, to change the Configuration utility password for the user jesse, you would type the following command:

    ldap -p jesse MyNewPassword

Adding, removing, or changing Configuration utility accounts from the Configuration utility

To add an Administrative user, perform the following steps:

  1. From the left navigation menu on the Configuration utility screen, click System Admin.

  2. Click the User Administration tab.

  3. Click the ADD (+) icon.

  4. Populate the following fields in the Add User box:

    • User ID
    • Password
    • Retype Password

  5. Choose one of the following Access Levels from the drop down menu:

    • Web Read Only
    • Partial Web Read/Write
    • Full Web Read/Write
    • CLI
    • CLI+Full Web Read/Write
    • None

    Note: Setting the user access level to None explicitly prevents that user from any BIG-IP administrative functions. For detailed information on the other access levels, click the Help button at the top of the Add User screen.

  6. Click the Done button.

Editing an Administrative user

To edit an Administrative user, perform the following steps:

  1. From the left navigation menu on the Configuration utility screen, click System Admin.

  2. Click the User Administration tab.

  3. Click the name of the user you want to edit.

  4. Modify the password and/or user access level.

  5. Click the Apply button.

Removing an Administrative user

To remove an Administrative user, perform the following steps:

  1. From the left navigation menu on the Configuration utility screen, click System Admin.

  2. Click the User Administration tab.

  3. Click the name of the user you would like to remove.

  4. Click the Trash Can icon adjacent to that user.

NameSurfer Accounts

Setting a new password for a NameSurfer account when the previous password was lost or forgotten

NameSurfer stores usernames and passwords as if they were zone files, identifying them with an NSURF class and an 8053 record type. These usernames and passwords are stored in the /config/3dns/namesurfer/db/db.nsurf.users file.

Important: Use this process to reset a password or username that is unknown, or not working, only when you cannot access the Configuration utility.

If you do not have access to the Configuration utility, you can change the NameSurfer username and password from the command line by performing the following steps:

Note: To change only the password for an existing account, skip to step 6.

  1. Log in to the command line.

  2. View the file /config/3dns/namesurfer/db/db.nsurf.users file, by typing the following command:

    strings /config/3dns/namesurfer/db/db.nsurf.users

    This will list the following records:

    <user name>
    users
    <password>

    For example:

    AskF5:/# strings /config/3dns/namesurfer/db/db.nsurf.users
    users
    askf5
    users
    bcgDpee/2cTYU
    root
    users
    JEm3EfpZnCcTs
    askf5
    users
    root
    users
    users

  3. Locate the encrypted password that is associated with the NameSurfer account that you would like to change.

    In the previous example, the Namesurfer user root is using the following password (displayed in encrypted form):

    JEm3EfpZnCcTs

    The user askf5 is using the following password (displayed in encrypted form):

    bcgDpee/2cTYU

  4. Remove the username and associated password, by typing the following command:

    /usr/local/namesurfer/bin/nsctl update --class NSURF --zone users. --delete <username> password <password>

    For example:

    /usr/local/namesurfer/bin/nsctl update --class NSURF --zone users. --delete root password JEm3EfpZnCcTs

  5. Restart NameSurfer, by typing the following command:

    bigstart restart namesurfer

  6. Change to the /usr/local/namesurfer/ directory, by typing the following command:

    cd /usr/local/namesurfer/

  7. Add the user back with the desired username, by typing the following command:

    bin/ns --recoverpw --user <username>

  8. When prompted, enter the new password.

    For example:

    /usr/local/namesurfer/bin/ns --recoverpw --user admin

  9. Restart NameSurfer, by typing the following command:

    bigstart restart namesurfer

The account should now work with the new password.

Changing the password for a NameSurfer account

  1. From the navigation pane in the WebUI, click NameSurfer.

  2. Click User Accounts.

  3. Click on the account you want to change.

  4. Type the new password in the password field at the top of the screen.

  5. Click OK at the bottom of the screen.

Adding, removing, or changing NameSurfer accounts

Adding a NameSurfer account

  1. From the navigation pane in the WebUI, click NameSurfer.

  2. Click User Accounts.

  3. Click Add to add a new account.

Deleting a NameSurfer account

  1. From the navigation pane in the WebUI, click NameSurfer.

  2. Click User Accounts.

  3. Click on the name of the account you would like to delete.
