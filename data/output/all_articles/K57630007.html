Description

VPN Client to Client communication intermittently failing on Route Domain 0


Environment

  • APM Network Access
  • BIG-IP APM VE v16.1.0
  • CMP enabled (default)


Cause

Bug ID 1047213: Client to Client communication on default route domain is failing when CMP is enabled


Recommended Actions

Demote the virtual server from CMP processing.

# tmsh modify ltm virtual <virtual> cmp-enabled no


Additional Information

None
