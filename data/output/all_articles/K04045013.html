Description

- trying to install a new image but received the error message "failed (Disk full (volume group). See SOL#10636)"

Environment

  • vCMP system

  • performing an upgrade

Cause

- the disk does not have enough volume group space available to create a new volume for installation

Recommended Actions

Performing either of the following options will free up disk space:

- free up volume by deleting unused boot locations
- extend the free space using lvreduce to reallocate some space from the appdata volume

None
