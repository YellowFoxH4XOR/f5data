Description

You are looking to log client connections for a virtual servers.  As it may not be ideal to keep logging locally on BIG-IP depending on the amount of traffic the unit receives every day, there are some options.

Environment

  • BIG-IP LTM
  • At least one Virtual Server configured

Cause

By default, client's connection details are not logged anywhere on the BIG-IP.

However be aware that you can use 'tmsh show sys connection' command to display the contents of the BIG-IP connection table.
K53851362: Displaying and deleting BIG-IP connection table entries from the command line
K40033505: Explaining the output of tmsh show sys connection

Recommended Actions

1. If device has high amount of traffic, using an iRule with a remote log server and HSL (High Speed Logging) would be ideal.
While F5 support does not create custom iRules, our user forum http://devcentral.f5.com is a great resource.

Log client to vip connections
Irule to log specific client IP to a syslog server


2. However, if having an iRule is not feasible, then Analytics (AVR) could be an option.
Note: It's necessary to provision AVR first in order to use it.

Manual Chapter : Setting Up Application Statistics Collection
 

Additional Information

For more information on High-Speed logging please refer to:
K50040950: Configuring the BIG-IP system to send high-speed logs through the management interface
K14459: The BIG-IP system sends high-speed logs through TMM interfaces only
