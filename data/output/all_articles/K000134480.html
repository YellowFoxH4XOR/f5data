Description

This guide will show you how to sort Webtop Applications received from Citrix by Name instead of UID
 

Environment

BIG-IP, APM
Citrix v7.x


Cause

XML from Citrix broker itself is returning the apps sorted in v6.x and not sorted in v7
[RFE: 438370] APM Webtop should merge and sort Citrix published apps
 

Recommended Actions

First, contact Citrix and check whether there are any hidden settings to force the XML broker to return the list of apps sorted as it was in v6.x. If there are no such settings available, you can implement the following workaround on the BIG-IP side:

This is example when webtop shortcuts received from Citrix broker are sorted by UID:

 

To sort applications by names you need to modify :

/var/sam/www/php_include/webtop/renderer/webtop_full/full/common/webtop_common.inc



add below code after first open brace {

ccl.renderReceivedFavorites = function(res, apps) 
{
  apps.sort((a,b) => (a.caption.toLowerCase() > b.caption.toLowerCase()) ? 1 : ((b.caption.toLowerCase() > a.caption.toLowerCase()) ? -1 : 0));

+ [rest of the old code]...



Save changes
Next, restart your big-ip and clear all cache and cookies before accessing APM again.

Result:

Additional Information

The above code example uses the JavaScript array sort() method, performing the sort using an arrow function for comparisons.


Important:

The modification will not survive an upgrade, so it must be re-implemented after upgrading BIG-IP to different version
