K000163077: F5 Insight Application Telemetry Port Cannot Be Changed

Type
Support Solution
Published
2026-08-25
Updated
2026-08-25
Applies to
  • BIG-IP
  • F5 Insight: 1.2.1
Source

Description

F5 Insight Application Telemetry uses UDP port 30514. Customers may request to change this port to meet network or security requirements.


Environment

  • F5 Insight
  • Application Telemetry
  • Protocol: UDP
  • Default and required port: 30514


 

Cause

Changing the F5 Insight Application Telemetry port is not supported.


Answer/Recommended Actions

The port is fixed in the product at 30514/UDP and cannot be changed through a supported BIG-IP or F5 Insight configuration.


Do not attempt to override the port by modifying underlying platform components or using unsupported methods such as kubectl. Such changes are not supported and may be overwritten or cause unexpected behavior.


The network path to the F5 Insight endpoint must therefore allow UDP/30514.


If the customer has a technical requirement to use another port, the requirement should be submitted as a product enhancement request. It should not be treated as a product defect unless separate evidence demonstrates that the documented port behavior is not functioning as designed.
