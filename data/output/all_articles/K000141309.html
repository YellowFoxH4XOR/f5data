Description

There can be restrictions when upgrading to a new software release often times due to expanded memory use.

Information about which software version is supported on a specific F5 hardware platform can be found here:

K9476: The F5 hardware/software compatibility matrix

https://my.f5.com/manage/s/article/K9476

 

Here are the most common reason why new releases uses more memory and is the cause why older BigIP hardware can't upgrade to that version.

The technical term used when talking about RAM memory use is "memory footprint"

That will always be higher from version to version as customers upgrade and an important reason why F5 hardware gets obsoleted over time.

 

Environment

All software environments

 

Cause

Following are 4 general reasons why a newer software versions, commonly also known as a releases, use more memory

  1. Newer software versions include new and improved features consuming more memory. For example, in BigIP ASM, the java based "Guided Configuration" feature has been added.
  2. Newer software versions include many bugfixes which generally use more memory.
  3. Number of ASM Attack signatures and LiveUpdates in general is ever increasing. While verifying more security risks, the memory use of BD (the traffic enforcer) is increasing.
  4. Memory can be used to speed-up certain tasks which is a common use in updated software versions. The amount of memory a program or process uses while running will be higher in later versions because the memory used by binaries and dynamic-link libraries (DLLs) are higher, which is mainly done to improve performance.

 

Recommended Action

When acquiring a new hardware platform to run software which is frequently updated, It may be a good idea to confirm that the hardware contains enough memory to support upcoming software releases.
