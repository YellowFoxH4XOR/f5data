Description

The following error is observed when using the get_dossier command to update the BIG-IP license.

get_dossier[3007]: 01170015:3: Hal open call failed 5 times.

Environment

  • Modified Iptables configuration file.

Cause

 The following three lines in the iptables configuration are missing or have been modified which prevents AOM communication:

-A INPUT -s 127.2.0.1/32 -d 127.2.0.2/32 -j ACCEPT
-A INPUT -s 127.2.0.2/32 -d 127.2.0.2/32 -j ACCEPT
-A INPUT -d 127.2.0.2/32 -j DROP

Recommended Actions

  1. Restore the above lines to /etc/sysconfig/iptables
  2. Reload iptables with command iptables-restore <filepath>

Additional Information

If the restoration iptables configuration fails please run a EUD and contact F5 Technical Support
