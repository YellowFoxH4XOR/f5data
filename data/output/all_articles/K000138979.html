K000138979: Monpd constantly restarting

Type
Support Solution
Published
2024-03-21
Updated
2024-03-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000138979

Description

monpd service is constantly restarting.

Environment

Big-IP LTM

AVR Provisioned

Seeing errors in /var/log/avr/monpd.log

    DB|ERROR|{Date}|[PID]|../src/db/MonpdDbAPI.cpp:initMysqlConn:0112| Failed to connect to database: Unknown database 'AVR'

    DB|ERROR|{Date}|[PID]|../src/db/MonpdDbAPI.cpp:init:0049| Connect to MySQL failed

Also have errors in /var/log/avr/monpd.mysql.issues

  {Date} [avr_srv_code.sql]: ERROR 1049 (42000): Unknown database 'AVR'

Cause

Monpd is unable to communicate with the SQL database properly.

Recommended Actions

Run the following commands in the CLI:

bigstart stop monpd

touch /var/avr/init_avrdb

bigstart start monpd

Additional Information

None
