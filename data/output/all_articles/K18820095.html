Topic

In the Configuration Utility, the system reports profile statistics for one virtual server per Web Acceleration profile.

Description

If you have a single Web Acceleration profile associated with multiple virtual servers, the profile statistics only reflect information for one of the virtual servers.

For example, if virtual servers VS1 and VS2 both use the same Web Acceleration profile, the RAM cache statistics for the profile only reflect information for one of the virtual servers.

Note: In most cases, profile statistics report information for the first virtual server to be associated with the profile. If the configuration is modified or reloaded, behavior may differ.

Recommendations

If you want individual RAM cache statistics for each virtual server, you should create a copy of the Web Acceleration profile for each virtual server.
