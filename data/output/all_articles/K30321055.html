Description

  • BIG-IP units cannot be synced and the following error message appears:

    01070265:3: The Protocol Inspection Compliance (/Common/gtp_disallowed_message_types_National_network) cannot be deleted because it is in use by a Protocol Inspection Compliance Allowed Object Field Names (/Common/National_mobile_network_list 10234)

Environment

  • High Availability environment
  • Performed: Full sync OR full configuration reload
  • BIG-IP AFM
    • License with Protocol Inspection Compliance 

Cause

Mismatch between the PI (Protocol Inspection) versions/dates.
# tmsh show /security protocol-inspection update

Recommended Actions

This is expected behavior.
Always ensure the same PI version update is loaded on both members of the device group

Use one of the options, to make sure both units will be updated and get the same version for the Protocol Inspection (TMSH or GUI options):

  1. K02466443: Updating the BIG-IP AFM protocol inspection signatures using tmsh
  2. K17341610: Updating the BIG-IP AFM protocol inspection signatures using the Configuration utility
