K17333644: Newly created monitors in BIG-IQ may not show in the drop-down list for pool assignment

Type
Support Solution
Published
2022-04-12
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K17333644

Description

When assigning a new monitor to a pool, it is not listed in the drop-down.

  • New monitor is created in BIG-IQ
  • The new monitor does not show in the list when trying to assign it to the pool
  • No error messages

Environment

Relevant environmental factors specific to the topic

  • Monitor assignment to a pool in BIG-IQ GUI
  • Configuration >> Local Traffic >> Pools >> Health Monitors
  • BIG-IQ CM

Cause

The health monitor list may only show a subset of all available monitors.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. In the Health Monitor section
  2. Click the down arrow to expand the subset list
  3. in the "Filter" box, type in the name of the new monitor in question
  4. The new monitor will show and then it can be assigned
