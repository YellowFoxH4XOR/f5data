K000133664: After changing hostname, it is not reflected in Device Management/Sync configuration

Type
Support Solution
Published
2024-05-23
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000133664

Description

After changing hostname, it is not reflected in Device Management HA configuration.

Environment

  • LTM
  • DSC

Cause

Device identity certificate is associated with the old hostname

Recommended Actions

In the device with changed hostname, put it on Standby and Forced Offline

1. Reset Device Trust

Device Management ›› Device Trust : Local Domain

2. Change Device Name

Device Management ›› Devices ›› device (Self) : Change Device Name

3. Add Device Trust Members

Device Management ›› Device Trust : Device Trust Members

4. Update Device Group Members

Device Management ›› Device Groups : Device Group 

5. Sync

Device Management ›› Overview

 

Additional Information

None
