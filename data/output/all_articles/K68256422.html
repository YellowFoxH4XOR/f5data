Topic

You should consider using this procedure under the following condition:

  • You want to use the Traffic Management Shell (tmsh) to enable a secure network address translation (SNAT) or network address translation (NAT) object on all Virtual Local Area Networks (VLANs) or tunnels on the system.

Description

When you create a SNAT or NAT object using the Configuration utility, the default value for the VLAN / Tunnel Traffic setting is '* All' which specifies that the SNAT or NAT is enabled on all VLANs or tunnels on the system.

When you create a SNAT or NAT object using the tmsh utility, you must specify the vlans-disabled option and set the vlans option to none to enable the SNAT or NAT object on all VLANs or tunnels on the system. To do so, perform one of the following procedures:

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You must have administrative access to the tmsh utility.
  • You have an existing SNAT or NAT object that you want to enable on all VLANs or tunnels on the system.

Procedures

Enabling a SNAT on all VLANs or tunnels using the tmsh utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Use the following syntax to enable a SNAT object on all VLANs or tunnels:

    modify /ltm snat <SNAT_name> vlans-disabled vlans none

    For example:

    modify /ltm snat MySnat vlans-disabled vlans none

  3. Save the configuration by typing the following command:

    save /sys config

Enabling a NAT on all VLANs or tunnels using the tmsh utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Use the following syntax to enable a NAT object on all VLANs or tunnels:

    modify /ltm nat <NAT_name> vlans-disabled vlans none

    For example:

    modify /ltm nat MyNat vlans-disabled vlans none

  3. Save the configuration by typing the following command:

    save /sys config
