Issue

Error Message

err websso.1[<pid>]: 014d0019:3: <session id>: Kerberos: Failed to resolve IP address: <ip address>

In this error message, note the following:

  • <pid> is the process ID for the websso process.
  • <session_id> is the BIG-IP APM session ID assigned to the session.
  • <ip_address> is the IP address of the destination Kerberos authentication server.

For example:

err websso.1[20226]: 014d0019:3: 37b68e75: Kerberos: Failed to resolve IP address: ::ffff:10.0.0.4

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file
Description

This message occurs when one of the following conditions is met:

  • The BIG-IP APM system cannot resolve the destination Kerberos authentication server IP address to a DNS PTR record.
  • The BIG-IP APM system cannot resolve the destination Kerberos authentication server IP address to a DNS A or AAAA record.

Impact

Kerberos authentication fails.

Recommended Actions

  • Ensuring that the BIG-IP APM device is configured for DNS
  • Verifying the PTR record configuration
  • Verifying the A or AAAA record configuration

Ensuring that the BIG-IP APM device is configured for DNS

To view or configure the BIG-IP APM device DNS configuration settings, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Device > DNS.

Verifying the PTR record configuration

Verify that the BIG-IP APM device’s referenced DNS servers are properly configured PTR records for all configured Kerberos authentication servers used by the BIG-IP APM configuration. To do so, perform the following procedure:

  1. Log in to the BIG-IP APM command line shell.
  2. Verify the Kerberos server PTR record using the following command syntax:

    dig ptr <reverse server dotted-decimal ip address>.in-addr.arpa.

    For example:

    dig  ptr 5.1.10.10.in-addr.arpa.

    Note: The in-addr.arpa text is followed by a trailing period (.) character.

Verifying the A or AAAA record configuration

Verify that the BIG-IP APM device’s referenced DNS servers are properly configured for A or AAAA records for all configured Kerberos authentication servers used by the BIG-IP APM configuration. To do so, perform the following procedure:

  1. Log in to the BIG-IP APM command line shell.
  2. Verify the Kerberos server A or AAAA record using the following command syntax:

    dig <Kerberos_server_host_name>. ANY @<device_configured_dns_server_ip_address>

    For example:

    dig auth1.test.local. ANY @10.10.1.53

    Note: The Kerberos server host name is followed by a trailing period (.) character.
