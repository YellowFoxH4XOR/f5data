Known Issue

The BIG-IP APM wizard may fail to assign single sign-on (SSO) objects to the access policy.

This issue occurs when the following condition is met:

  • You use the Web Application Access Management for Local Traffic Virtual Servers wizard to create an access policy with an SSO object.

Impact

You cannot configure SSO objects while using the wizard.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP APM wizard does not assign SSO objects to the access policy that you select using the wizard.

Resolution

Status

F5 Product Development has assigned ID 596336 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release13.0.0K2200: Most recent versions of F5 software
HotfixNoneNone

Workaround

To work around this issue, you can manually assign SSO objects to the access policy using the Configuration utility or the Traffic Management Shell (tmsh).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
