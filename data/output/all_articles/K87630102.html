Description

Trying to configure E-mail alerts with outbound-smtp mailhub and TLS authentication, based on K13180: Configuring the BIG-IP system to deliver locally generated email messages (11.x - 15.x), however this option only shows available for version 11.0.0 to 11.4.1.

When testing this configuration without the authentication options, you get similar errors:

554 5.7.1 Authentication required
530 5.7.1 Client was not authenticated

Environment

  • Outbound-smtp mailhub configured
  • Versions newer than 11.4.1

Cause

An RFE has been opened to add the options for configuring the outbound-smtp mailhub with TLS authentiation via tmsh commands. This is expected to be introduced in future releases only. No further information from PD is available at the moment of publication of this article.

RFE is tracked with ID 657923: Allow configuration of SMTPS fields via tmsh.

Recommended Actions

The configuration for TLS authentiation can still be done with procedure indicated on K13180, however, the configuration added on /etc/ssmtp/ssmtp.conf will disappear after a reboot.

You can track the RFE ID mentioned above for updates, by contacting your F5 Account Manager.
