K34744044: ''Report submission failed: Please provide a valid certificate'' when ELA license has expired

Type
Support Solution
Published
2021-07-19
Updated
2025-04-01
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K34744044

Description

Your BIG-IQ is showing the following error message:

Report submission failed: Please provide a valid certificate

When viewing /var/log/restjavad.*.log, you will see the following log message examples:

[ERROR][BillingReportTask] Report generated but submission failed for AAAAA-BBBBB-CCCCC-DDDDD-EEEEEEE (task aaaaaaaa-1111-aaaa-1111-aaaaaaaaaaaa): Report submission failed: Please provide a valid certificate
 : com.f5.rest.workers.device.license.utility.billing.CurlReportSender$ReportSubmissionException: Report submission failed: Please provide a valid certificate

Environment

  • BIG-IQ 7 or 8
  • Error message: Report submission failed: Please provide a valid certificate

Cause

One of your BIG-IQ certificates has expired and needs to be updated. 

Recommended Actions

Refer to article K81246843 to resolve the issue.

If the Reactivate button is greyed out, refer to article K30249546.

None
