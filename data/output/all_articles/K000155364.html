Description

After applying Custom Resources, such as a VS/VSR, Ingress, Service, etc., the NGINX [Plus] configuration does not update nor change as expected.

Environment

NGINX Ingress Controller

Cause

This behavior can occur when NIC is in batch reload mode

Batch reload mode occurs when NIC encounters a number of concurrent configuration update requests

When NIC is in batch reload mode, reload of NGINX [Plus] will not occur

Once the number of queued configuration requests reaches zero then NIC will reload NGINX [PLus]

Recommended Actions

Be patient and allow NIC to process configuration updates
