K000136003: iControl REST Asynchronous task request returns "Error 500 AsyncContext timeout"

Type
Support Solution
Published
2023-08-29
Updated
2023-08-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136003

Description

You are using iControl REST asynchronous task API endpoint, /mgmt/tm/task/sys/ucs, to create UCS of a BIG-IP device.
When attempting to check the completion state of the UCS task, the BIG-IP is returning Error 500 AsyncContext timeout to the client.


Additionally, BIG-IP restjavad log file will print warning message:

mgmt/tm/task/sys/ucs/<task id>, Referrer:127.0.0.1, Method:GET, Exception:java.util.concurrent.TimeoutException

BIG-IP is also installed with one or more iControl LX extensions such as AS3 or Telemetry.

Environment

  • iControl REST asynchronous task URI
  • iControl LX extensions (e.g., AS3, Telemetry) are installed on the BIG-IP

Cause

The issue is due to Bug ID 538283​​​​.
BIG-IP that is installed with iControl LX packages observed this issue frequently as UCS needs longer saving time caused by Bug ID 985329. 

 Recommended Actions

As Bug ID 538283 neither has a fix nor workaround yet, it may be preferable to use equivalent iControl REST synchronous URI with increase the timeout value of db key icrd.timeout, restjavad.timeout, and restnoded.timeout to run such task instead.
