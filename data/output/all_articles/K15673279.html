Description
Persistence cookies sent encrypted by the client are transmitted decrypted on the server side.

When the cookie persistence profile is configured for encryption, and the client returns an encrypted persistence cookie, the BIG-IP sends a decrypted version of the cookie to the server.

Environment

  • BIG-IP
  • Cookie persistence profile with encryption enabled

Cause
Cookie encryption is intended to prevent tampering on the client side and exposing server addresses. There is no reason to conceal the contents of the cookie from the server.

Recommended Actions
None.
