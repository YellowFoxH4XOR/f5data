Description

Oracle database health monitors configured on BIG-IP LTM may fail to mark pool members as up. Monitor debug logs display connection failures with the error:

SQL Exception: java.sql.SQLRecoverableException: IO Error: Invalid number format for port number

The connection string in use is shown as:

connect str = jdbc:oracle:thin:@jdbc:oracle:thin:@db01.dbserver.internal:1551/DBINSTANCE

This leads to Oracle driver connection failure, resulting in pool members remaining down.

Environment

  • Product: BIG-IP LTM
  • Oracle health monitor type: ltm monitor oracle

Cause

The "database" field in the Oracle monitor configuration incorrectly contains the full JDBC prefix (jdbc:oracle:thin:@). BIG-IP automatically prepends this prefix internally, causing a duplicated string (jdbc:oracle:thin:@jdbc:oracle:thin:@...). This results in an invalid connection string and triggers the "Invalid number format for port number" error from the Oracle JDBC driver.

Recommended Actions

  • Remove the jdbc:oracle:thin:@ prefix from the "database" field in all affected Oracle monitor configurations.
  • Specify only host, port, and service name. For example:

    database db01.dbserver.internal:1551/DBINSTANCE

  • Apply this correction to each relevant Oracle monitor.
  • Check for extra spaces, carriage returns, or formatting issues within the monitor configuration.
  • After making these changes, verify that pool members are correctly marked as up by the health monitor.
