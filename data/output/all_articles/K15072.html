Known Issue

The BIG-IP GTM Cache Local DNS Servers global variable (cache-ldns-servers) can be erroneously disabled when persistence is enabled for a wide IP.

The Cache Local DNS Servers variable specifies whether or not the BIG-IP GTM system retains all local DNS (LDNS) servers, that make requests, in memory. This setting is enabled by default. This variable must be enabled if you want the system to store and use LDNS persistence information; however, the system allows an administrator to disable the variable when persistence is configured for a wide IP.

Impact

Persistence does not function correctly if the Cache Local DNS Servers global variable is disabled.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Wide IP persistence does not function as expected.

Workaround

To work around this issue, you can enable the Cache Local DNS Servers global variable. To do so, perform one of the following procedures:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Using the Configuration utility to enable the 'Cache Local DNS Servers' global variable

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Global Traffic > General.
  3. Select the Cache Local DNS Servers check box.
  4. Click Update.

Using the Traffic Management Shell (tmsh) to enable the 'Cache Local DNS Servers' global variable

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Enable the cache-ldns-servers global variable by typing the following command:

    modify /gtm global-settings general cache-ldns-servers yes
  3. Save the configuration by typing the following command:

    save /sys config gtm-only
