K04270215: Attaching a mobile phone to PC with Edge Client installed via USB disconnects the VPN

Source

Description

When connecting an Android mobile phone to a PC with Edge Client installed using USB cable to charge or transfer data, the VPN gets disconnected.

Environment

  • Android Mobile Phone
  • Windows 10
  • Connecting the phone to PC with Edge Client installed

Cause

When plug in the phone, it's also adding the SAMSUNG Mobile USB Modem which seems to interfere with the VPN default behavior

Recommended Actions

To resolve this issue we need to disable Mobile USB Modem.

Under "Device Manager" we can see the following:

-> Modems" | -> "SAMSUNG Mobile USB Modem"

If we simply right click on this and select 'Disable device' then we are no longer able to reproduce the issue.
