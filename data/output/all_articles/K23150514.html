Known Issue

An incremental configuration synchronization (ConfigSync) operation may fail when the BIG-IP system is configured with a Security Assertion Markup Language (SAML) Identity Provider (IdP) connector with an embedded certificate.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a SAML IdP connector.
  • The SAML IdP connector contains an embedded certificate.

Impact

The incremental ConfigSync operation fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You navigate to Device Management > Overview in the Configuration utility and notice that the device group sync status is Sync Failed and the system displays an error which appears similar to the following:

    -------------------------------------------------------------------
    CM::Sync Status
    -------------------------------------------------------------------
    Status Sync Failed
    Mode high-availability
    Summary A validation error occurred while syncing to a remote device
    Details
    <DeviceName>: connected
    <Device Group Name> (Sync Failed): A validation error occurred while syncing to a remote device
    - Sync error on <DeviceName>: Load failed from /Common/<PeerDeviceName> 01070734:3: Configuration error: /Common/<Name of certificate>.crt certificate not found.
    - Recommended action: Review the error message and determine corrective action on the device

Workaround

To work around this issue, you can manually perform a full ConfigSync. To do so, perform the following procedure:

Manually performing a full ConfigSync

Impact of workaround: Performing the following procedure should not have a negative impact on the system that initiates the ConfigSync; however, the full ConfigSync causes the configuration to reload on the systems receiving the ConfigSync, which may temporarily disrupt traffic.

  1. Log in to the Configuration utility on the BIG-IP system from which you want to initiate the ConfigSync.
  2. Navigate to Device Management > Device Groups.
  3. Click the device group you plan to sync.
  4. Under Configuration, note the current setting in the Sync Type list and click Manual with Full Sync.

    Note: You will return the system to its original Sync Type setting after performing the manual ConfigSync.

  5. Click Update.
  6. Navigate to Device Management > Overview.
  7. Click the device group you plan to sync.
  8. Click the self device.
  9. Under Sync Option, click Push the selected device configuration to the group.
  10. Click Sync.
  11. To return your system to its original sync settings, repeat steps 2 through 5, but for step 4, for Sync Type, click the original setting you noted earlier.
