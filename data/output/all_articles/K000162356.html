K000162356: Loop IP (127.0.0.1) trying to login the BIG-IQ after upgrading to 8.4.1

Type
Support Solution
Published
2026-07-27
Updated
2026-07-29
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.1
Source
https://my.f5.com/manage/s/article/K000162356

Description

In BIG-IQ audit logs you see login attempts from loopback interface IP address 127.0.0.1 every 10 minutes after upgrading BIG-IQ to software version 8.4.1 

Environment

  • BIG-IQ
  • 8.4.1

Cause

ID2365397

Answer/Recommended Actions

bwafconfd daemon can be safely disabled on BIG-IQ systems. Run below command on all BIG-IQ devices:

bigstart stop bwafconfd
bigstart disable bwafconfd

Additional Information

None
