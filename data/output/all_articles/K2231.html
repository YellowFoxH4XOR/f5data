Topic

By default, BIG-IP processes traffic regardless of whether it contains a valid checksum.

When the l7_validate_checksums global is enabled, BIG-IP checks the appropriate checksums for any traffic that traverses a delayed binding virtual server. If the checksum is not valid, BIG-IP will drop the packet.

This setting is optional because it imposes a significant performance burden on BIG-IP.
