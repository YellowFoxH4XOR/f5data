Topic

This article applies to ASM Proactive Bot Defense cookies with the TSPD prefix. To modify ASM cookies with the TS prefix, refer to the following article:

  • K54501322: Modifying ASM cookie names

You should consider using this procedure under the following condition:

  • You want to modify the prefix of the ASM Proactive Bot Defense cookie name.

Description

The BIG-IP ASM system validates real browser actions by using a series of JavaScript challenges and sets the Proactive Bot Defense cookie to enforce the Layer 7 (L7) denial-of-service (DoS) policy. Users may notice one or both of the following Proactive Bot Defense cookies are set by the L7 DoS policy:

  • Proactive Bot Defense cookies with the default TSPD_101 prefix are related to client-side challenges.
  • Proactive Bot Defense cookies with the default TSPD prefix are related to cross-domain flow.
Note: Some ASM policy features, such as Session Tracking, also use TSPD_101 cookies for fingerprinting. 

You can customize the prefix of the Proactive Bot Defense cookie name for security purposes or to meet cookie naming requirements.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Traffic Management Shell (tmsh).

Procedures

Modifying the prefix of the TSPD_101 Proactive Bot Defense cookie name

To modify the prefix, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the prefix, use the following command syntax:

    modify /sys db dosl7.proactive_defense_cookie_name <new_prefix>

    For example, to use EXPL_101 as the prefix, type the following command:

    modify sys db dosl7.proactive_defense_cookie_name value EXPL_101

  3. To verify the modified prefix, type the following command:

    list /sys db dosl7.proactive_defense_cookie_name

Modifying the prefix of the TSPD Proactive Bot Defense cookie name

To modify the prefix, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify the prefix, use the following command syntax:

    modify /sys db dosl7.proactive_defense_prefix <new_prefix>

    For example, to use EXPL as the prefix, type the following command:

    modify sys db dosl7.proactive_defense_prefix value EXPL

  3. To verify the modified prefix, type the following command:

    list /sys db dosl7.proactive_defense_prefix
