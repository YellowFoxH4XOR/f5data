K000147960: Can I check the logs across multiple namespace in one single view?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147960

Description

  • I would like to view all the logs of my namespaces
  • Is there a single place where I can see all the logs for all of my namespaces?

Environment

  • F5 Distributed Cloud Console

Answer

  • There is currently no way to see all the logs of multiple namespace in one single place.
  • We do not have the functionality where you can view all logs across all namespaces in one single view or location.
