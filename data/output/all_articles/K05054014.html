Known Issue

Performing an iControl GET request on a BIG-IP system with a large number of virtual servers may result in slow performance and timeout errors.

This issue occurs when all of the following conditions are met:

  • You are performing iControl GET requests on a BIG-IP system.
  • You have configured a large number of virtual servers.
  • The virtual servers reference persistence profiles.

Impact

You are unable to reliably perform iControl GET queries on the affected BIG-IP systems.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You may experience slow performance and timeouts.
  • The iControl REST API is briefly unavailable.
  • Queries may unexpectedly fail.
