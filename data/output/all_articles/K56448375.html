Description

  • Big-IQ Configuration Utility (WebUI) randomly logs active user out of session.
  • When logged into the BIG-IQ Configuration Utility, the user is auto-logged out while navigating with next error message: 
    Your user session has been terminated.

Environment

  • You are running BIG-IQ version 6.1
  • You are using HTTP/2 enabled browser
  • You are using Configuration Utility

Cause

The issue is caused by Bug ID764745.

Recommended Actions

Upgrade to BIG-IQ version 7.0.0 or higher where ??? bug is fixed.

Additional Information

BIG-IQ 6.1 ships with HTTP/2 enabled that cause issues with browsers

As a workaround this issue, you can edit the /etc/webd/webd.conf to remove the http2 reference
  1. Log into the Command Line Interface.
  2. Using your favorite editor open the file

    /etc/webd/webd.conf

  3. Locate the following two lines:

    listen [::]:443 ipv6only=on ssl http2;
    listen *:443 ssl http2;

  4. Remove the http2 reference from both lines so they now look like the following:

    listen [::]:443 ipv6only=on ssl;
    listen *:443 ssl;

  5. Save and exit the file by typing the following command:
  6. Restart the webd daemon by typing the following:
    bigstart restart webd
