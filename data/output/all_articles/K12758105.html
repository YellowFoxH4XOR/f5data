Description

Environment

  • TAM (Traffic Acceleration Manager) provisioned
  • Turboflex profile defined
  • Traffic Acceleration Manager
  • You are using one of the following hardware platforms:
    • BIG-IP i5000 Series
    • BIG-IP i7000 Series
    • BIG-IP i10000 Series
    • VIPRION B4450 blade

Cause

A turboflex profile other than turboflex-ultrafast-layer4 is in use while TAM is provisioned.
TAM (Traffic Acceleration Manager) requires the turboflex profile turboflex-ultrafast-layer4 be enabled.
If you have a standard ix600 license such as i7600 you can provision TAM when this should not be allowed, this is due to Bug ID 690934

Recommended Action

Impact: Modifying the turboflex profile will cause a brief interruption to traffic as services restart.
Note: If the TAM module is not needed or not in use it may be de-provisioned at System >> Resource Provisioning which will also prevent the issue.
Note: If you are using the standard ix600 license you cannot use TAM, please de-provision and contact sales to upgrade to the performance ix800 license.

  1. Go to System > Resource Provisioning > TurboFlex in the Configuration utility to view the active TurboFlex profile.
  2. Select Enable Profile for the profile turboflex-ultrafast-layer4
  3. A reboot may be required.
