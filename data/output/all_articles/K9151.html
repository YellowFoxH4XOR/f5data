Topic

The BIG-IP ASM Requests List screen displays a complete list of objects requested by users of the web application. By clicking on an object on the Requests List screen, you can view specific information about the request, such as the time and type of request, the request ID, and whether the request generated a violation. You can also accept the explicit object and add it to the security policy by clicking the Accept button.

When you view specific information about the request, you can determine whether the request was legitimate and should be allowed by the security policy, or whether the security policy should continue to block the request. If you decide that the request was legitimate and should be allowed by the security policy, you can click the Accept button at the top right corner of the View Full Request Information pop-up page.

Clicking the Accept button adjusts the current policy by running the Policy Builder against the single request shown in the Request window. The Policy Builder then makes a granular set of policy changes to fit the request shown, and the security policy then accepts future requests for the same object as legitimate.

For example, if a request containing a parameter triggers an attack signature, the BIG-IP ASM security policy blocks the request, and logs a violation on the Requests List screen. You can then view specific information about the request and the parameter by navigating to the Requests List screen, and clicking on the object. If you decide to allow the request and click the Accept button, the Policy Builder runs and creates an object-level parameter containing specific attributes that prevent the parameter contents from triggering another violation.

Note: The Accept button only works for violations on which the Policy Builder supports. For more information about the Policy Builder, refer to the Configuration Guide for your version of BIG-IP ASM.

Using the Accept button to add an object to the security policy

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

To add an object to the security policy by using the Accept button, perform the following procedure:

  1. On the Main tab of the Application Security navigation pane, click Reporting.
  2. Click the Requests menu.
  3. Click the request violation that you want to add to the security policy.
  4. The View Full Request Information pop-up page displays.
  5. Click the Accept button.
  6. Once the Policy Builder has added the request to the policy, click Policy.
  7. Click the Apply Policy button.
