Description

You want to set up the BIG-IP system to forward or load balance passive mode FTP traffic. 

Environment

  • You have a BIG-IP in-front of an FTP server
  • Your server is configured as a Passive FTP server
  • There is a specified random port range for data channel on the FTP server

Cause

None

Recommended Actions

Follow the Implementation Guide 'Load Balancing Passive Mode FTP Traffic'

  1. Create a custom FTP monitor
  2. Create a pool to manage FTP traffic
  3. Create a virtual server for FTP traffic
Note: You only need to create a single virtual server with destination port 21. This virtual server will be used to process traffic for both the control and data channel ports.

Additional Information

A BIG-IP system with this configuration can process FTP traffic in passive mode, in a way that optimizes the traffic on both the control channel and the data channel.
