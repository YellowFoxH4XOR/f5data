Known Issue

Description

BIG-IP APM customizations configured on the standby unit will not properly update the cache on the active unit. 

This issue occurs when the following condition is met:

  • A BIG-IP APM customization has been created or updated on the standby unit and synchronized to the active unit.

Impact

 

Users will not receive updated customizations from the BIG-IP cache.  

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Customization changes will not be displayed by the client.
  • Viewing the customizations on the active unit will show the changes were successfully synchronized.

Workaround

To work around this issue, perform the following procedure:

  1. Log in to the active unit on the BIG-IP Configuration utility.
  2. Navigate to the customizations that were created on the standby unit.
  3. Click Save.

    Creating future customizations on the active unit will properly update the standby unit.
