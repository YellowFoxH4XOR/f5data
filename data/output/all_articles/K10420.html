Known Issue

This is the result of a known issue. After using the shutdown command to disable the out-of-band (OOB) management interface on an ARX 1000 system. The no shutdown command fails to re-enable the interface.

The show interface fastethernet 1/1 command output will indicate that the Admin Status is enabled; however, the Link Status remains down for the management interface.

Slot                     1
Interface                1
Description
Admin Status             Enabled
Link Status              Down
Speed                    0 Mb/s
Duplex                   Full
Auto Negotiation         On
MAC Address              00:0a:49:0b:f3:03
MTU Size                 1500

F5 Product Development tracked this issue as ARX ID 35737 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.

Workaround

To restore service for the OOB management interface, you must reboot the ARX system using the reload command.
