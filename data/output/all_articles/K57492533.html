Description
Currently, there is no simple way to bulk import TLS Certificates and Keys using the Advanced Shell (bash) or Traffic Management Operating System (tmos). This article provides a solution using a bash script and tmsh transactions to bulk import multiple certs/keys in a single transaction.

Environment

  • BIG-IP
  • TLS/SSL Certificates

Cause
Import Archive feature not currently available.

Recommended Actions

  1. Copy all desired certificates/keys into /var/tmp/certs/
    Note: Make sure the directory exists
    Note: See K175: Transferring files to or from an F5 system for details on copying files to a BIG-IP system.

    mkdir /var/tmp/certs/

  2. With the following assumptions, create a cli transaction to import all certs and keys:
    Note: Assumption #1: All keys end with a .key extension
    Note: Assumption #2: All certificates end with a .crt extension

    vim /var/tmp/bulk_import_certs_keys.sh
    :set paste

    ### COPY / PASTE the following ###

    #!/bin/bash

    (
    echo create cli transaction

    for certkey in /var/tmp/certs/*
    do
      if [[ "$certkey" == *.key ]]
      then
        object="key"
        echo "install sys crypto ${object} $(basename "$certkey" .key) from-local-file ${certkey}"
      elif [[ "$certkey" == *.crt ]]
      then
        object="cert"
        echo "install sys crypto ${object} $(basename "$certkey" .crt) from-local-file ${certkey}"
      fi
    done

    echo submit cli transaction
    ) | /usr/bin/tmsh
    ######## END COPY/PASTE ##########

    :wq

  3. Run the script:

    bash /var/tmp/bulk_import_certs_keys.sh

  4. Output will look similar to the following:

    tmsh list sys crypto key one-line
