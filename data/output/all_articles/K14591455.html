Known Issue

The BIG-IP ASM request log may fail to load in the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You are using a VIPRON chassis system.
  • You have the BIG-IP ASM module licensed and provisioned.
  • You are running one of the following BIG-IP system point releases:
    • 13.1.0.4
    • 13.1.0.5
    • 13.1.0.6
    • 13.1.0.7
  • You navigate to Security > Event Logs > Application > Requests in the Configuration utility.

Impact

You are unable to view BIG-IP ASM request log entries using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The requests log fails to load and you notice the following message in the Configuration utility:

    Loading Requests Log...
