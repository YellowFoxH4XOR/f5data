Description

After the software upgrade the HA cluster goes out of sync every day at the update attempt of the DPI Signatures.

  • There are similar messages logged in /var/log/hitless_upgrade.log when the sync status changes:

update_dpi_sigfile.pl`INFO`Dec 29 03:23:04.409`3698`F5::Sigfile::Update::update,,The most recent DPI Signatures file is already installed.

Environment

  • PEM is not provisioned
  • The automatic sync is not enabled on the device group.
Cause

The DPI Signatures would be update every day. The DPI signatures are only required for the PEM module, that is not provisioned.

Recommended Actions

Disable DPI Signature updates. Run these commands in tmsh:

modify ltm classification signature-update-schedule auto-update-disabled
save sys config

Running the above commands do not affect the traffic processing, they can safely be run them on the active device.
