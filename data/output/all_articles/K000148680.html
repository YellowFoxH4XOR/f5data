K000148680: How to display information about scripts in BIG-IQ via the command line

Type
Support Solution
Published
2024-11-25
Updated
2024-11-25
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.2.X, 8.3.0, 8.2.0
Source
https://my.f5.com/manage/s/article/K000148680

Description

You would like to know if you can display more information via command line about the scripts that was run in "Script Management" in the GUI on the BIG-IQ.

Environment

  • BIG-IQ
  • Script Management

Cause

None

Recommended Actions

You can use following command to display all scripts that was run as well related data like output, error or if it was success or failed and other:

Note: Command have to be run in bash mode

restcurl -u admin:a /mgmt/shared/user-script-execution
