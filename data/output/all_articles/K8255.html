Known Issue

This is the result of a known issue. The Policy Builder may not become active after the BIG-IP ASM is restarted from the command line using the bigstart restart asm command. When this behavior occurs the BIG-IP ASM Policy Builder will report a status of Inactive within the Configuration utility.

Note: For information about viewing the Policy builder status, refer to the Building a Security Policy Automatically with the Policy Builder chapter of the Configuration Guide for BIG-IP Application Security Management.

F5 Product Development is tracking this issue as CR92087.

Workaround

You can work around this issue by restarting the Policy Builder from the Configuration utility. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Select the Web Application for which you want to check the status.
  4. Select Policy.
  5. Select the Status option from the Policy Builder menu to verify the status of the Policy Builder.

    If the status reports Inactive, proceed to the next step.
  6. Click Apply Policy Button to restart the Policy Builder.
