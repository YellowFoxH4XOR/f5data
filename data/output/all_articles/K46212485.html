Known Issue

The BIG-IP ASM bd process may produce a core file when processing many false-positive attack signatures.

This issue occurs when all of the following conditions are met:

  • Your security policy configuration has the Parameters violation option set to Parameter value does not comply with regular expression.
  • The security policy processes content that does not match the policy’s configured content type, causing the Request Body Handling parser to trigger many false-positive attack signature matches. For example, this happens when a security policy configured to process HTML content receives XML or JSON content.

Impact

The BIG-IP ASM system temporarily fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system generates a bd core file to the /shared/core directory.
  • The BIG-IP ASM system sends a SIGSEGV to the BIG-IP ASM bd process and logs a message to the /var/log/ts/bd.log file similar to the following example:

    BD_MISC|CRIT  |<date and time>|<pid>|signals.c:0076|Received SIGSEGV - Core Dumping

Workaround

To work around this issue, you can configure the Header-Based Content Profiles setting on specific URLs where the content of the URL varies from the default content type of the security policy. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > URLs > Allowed URLs.
  3. In the Current edited security policy list, click the affected security policy.
  4. Click the affected URL.
  5. Click the Header-Based-Content-Profiles tab.
  6. Enter the Request Header Name and Request Header Value information.
  7. For the Request Body Handling setting, click the appropriate form data type.
  8. Use the existing data type profile or click Create to create a new profile.
  9. Click Add.
  10. Click Update.
  11. Click Apply Policy.

Note: For more information about configuring JSON specific header-based content profiles, refer to the Adding JSON Support to an Existing Security Policy chapter of the BIG-IP Application Security Manager: Implementations manual.
