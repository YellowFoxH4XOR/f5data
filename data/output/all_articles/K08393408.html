K08393408: TMM may send IP fragments which can cause SSL handshake failures

Type
Support Solution
Published
2020-01-10
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K08393408

Description
Under certain conditions TMM may send IP fragments. As a result you may observe the following behavior:

  • Intermittently failing SSL handshakes
  • Fragmented SSL Server Hello and Certificate messages

Environment

  • 13.1.1.5
  • BIG-IP
  • SSL profile
  • Hardware Syncookies (enabled by default)

Cause
ID802493 – HW Syncookie may retrieve incorrect MSS
https://cdn.f5.com/product/bugtracker/ID802493.html

ID803237 – PVA does not validate interface MTU when setting MSS
https://cdn.f5.com/product/bugtracker/ID803237.html

Recommended Actions
None

Additional Information
None
