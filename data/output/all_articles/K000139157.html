Description

When BIG-IP contain the switch chipset, in the VLAN, all external interface is down, and self IP is configured, BIG-IP need to send out the frame on this VLAN, but the frame cannot send to the network, the internal interface "Drops In" statistics may grow.

When the interface is up, but change the trunk configuration, like add interface to the trunk or remove the interface from trunk, it may cause "Drops In" statistics increase at that moment.

For example:

tmsh show net interface -hidden 9.1 10.1 all-properties raw

9.1      up              none 9398 526.2K 112.7K  779  133   133   133   646     0    0    0     0         0         0   42000-FD    rx      none detached hsb0.1

10.1     up              none 9398 410.8K 112.7K  642  133     0   133   507     0    0    0     0         0         0   42000-FD    rx      none detached hsb1.1

In the example above, the "Drops In" account is 646 and 507.

Environment

  • BIG-IP with internal switch chipset
  • VLAN

Cause

It is expected result

Recommended Actions

If the "Drops In" count is growing, please check the VLAN configuration, make sure the BIG-IP was able to send the frame to network.

If the "Drops In" count is not growing, then the count should be generated earlier, when no interface is up in the VLAN.
