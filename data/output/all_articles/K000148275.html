K000148275: Option to configure Floating IP for BIGIP Management Interface

Type
Support Solution
Published
2024-10-27
Updated
2024-10-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148275

Description

Option to configure a floating IP for BIGIP Management interface


Environment

  • Management Interface
  • Floating Management IP address

Cause

BIGIP does not support configuring floating IP address for management interface.


Recommended Actions

TMM interfaces support configuring floating IP.

Configure TMM interface on BIGIP to manage using floating IP address.


Additional Information

None
