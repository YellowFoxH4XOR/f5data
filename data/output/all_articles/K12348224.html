K12348224: APM may break Citrix Server Host to Client URL Content Redirection and Validation

Type
Support Solution
Published
2023-04-28
Updated
2023-04-28
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP APM: 15.1.2
  • Citrix Xenserver
Source
https://my.f5.com/manage/s/article/K12348224

Description
Citrix URL redirection and validation makes an initial HEAD request to the root URI. On some Big-IP versions, this request fails when APM is front-ending the Citrix infrastructure, since APM doesn't accept HEAD requests. Normally under these circumstances the APM should return an HTTP 404 response, but in some software versions the APM will close the TCP connection completely instead. We can mitigate this by adding an iRule that responds to these HEAD requests with a simple blank HTTP response.

Environment

  • APM v15.1
  • Citrix Receiver
    • URL Redirection and Validation enabled

Cause
The URL Redirection and Validation feature of the Citrix client makes a "HEAD /" request after starting the user's session. Because APM does not support the HEAD HTTP method, we do not send a 200 OK response. Under normal circumstances we should send a 404 response, which the client will accept. On some software versions starting at 15.1.2, the APM instead resets the connection completely. Because of this failure, the citrix client will hang and retry creating a new session, leading to effectively an infinite loop that never actually logs in.

Recommended Actions

  1. The citrix client is just looking for any valid HTTP response and doesn't appear to inspect the content of that response at all. Therefore if this feature cannot be disabled in your environment we can use a simple iRule to allow these sessions to proceed:
when HTTP_REQUEST {
     if {[[HTTP::url] eq "/"] && [[HTTP::method] eq "HEAD"]}{
         HTTP::respond 404
     }
}

Note: This workaround has not been validated with Citrix support or development. It has been effective in basic testing, but should be thoroughly vetted for unexpected behaviors before deploying to production.
