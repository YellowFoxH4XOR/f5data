Known Issue

This is the result of a known issue. The Configuration utility in BIG-IP versions 4.5.12 through 4.6.4 and BIG-IP LTM versions 9.0 5 through 9.1.2 may display random, incorrect characters after the Common Name of the certificate.

F5 Networks Product Development tracked this issue as CR47752 and CR47753 and it was fixed in BIG-IP versions 4.5.13 and 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

This issue still exists in the BIG-IP version 4.6 software branch and the BIG-IP LTM version 9.1 software branch.
