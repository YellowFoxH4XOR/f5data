To set up the keyboard type for a BIG-IP system, copy the appropriate keyboard.map file from the /usr/libdata/keyboard directory to the /etc/keyboard.map file.

For example, to use the UK keyboard type, type the following command at the command prompt:

cp /usr/libdata/keyboard/UK /etc/keyboard.map

To make the new keyboard map take effect, reboot the BIG-IP by typing the following command:

/sbin/shutdown -r now
