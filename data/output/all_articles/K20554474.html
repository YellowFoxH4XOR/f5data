K20554474: Enterprise Manager will fail to upload qkview files after February 28, 2016 when running software versions 3.0.0 through 3.1.1 HF4

Topic

F5 is renewing the Secure Sockets Layer (SSL) certificate of the central login service on February 29, 2016. As a result, Enterprise Manager will fail to upload qkview files when running software versions 3.0.0 through 3.1.1 HF4.

Description

To proactively identify issues that remotely managed BIG-IP systems may experience, Enterprise Manager uses the Gather iHealth Diagnostics task to obtain qkview files from remote systems and upload them to BIG-IP iHealth. If your Enterprise Manager system is running software versions 3.0.0 through 3.1.1 HF4, the Gather iHealth Diagnostics task will fail after February 28, 2016.

If you are running the task for the first time, from the Configuration utility, the system will display an error message similar to the following example:

  • iHealth login failed: Peer certificate cannot be authenticated with known CA certificates

Previously scheduled tasks will fail, and an error message similar to the following example will be logged to the /var/log/em file:

  • err emdeviced[6789]: 04072927:3: Login to iHealth service failed, for job with uid 123: 'Peer certificate cannot be authenticated with known CA certificates'.

Recommendations

F5 recommends that Enterprise Manager systems configured to run the Gather iHealth Diagnostics task be upgraded to 3.1.1 HF5 or later.
