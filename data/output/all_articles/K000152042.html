Description

  • Unable to access vCMP guest via GUI and CLI.
  • When you use console (vconsole) to access the vCMP guest, you observe high memory utilization (top, cat proc/meminfo)

Environment

  • BIG-IP vCMP Guest

Cause

Management IP went back to default 192.168.1.246. Hence the guest is unreachable using original IP address or FQDN. In bigip.conf shows the correct IP address but it is missing from Linux bash.

Recommended Actions

First check if the management IP is configured. When you console into the vCMP guest you may see high memory utilization which gives a false indication that guest is inaccessible because of memory issue. In reality memory was not he issue but instead either management IP is completely missing or went to default value.

Check if management IP exist in the Linux. Run the below command in bash.

# ifconfig

If the it is missing from Linux bash, then configure management IP using below command.

# config

Additional Information

Once the management IP is configured see if guest is reachable. If yes, monitor the guest for some while and see if memory utilization is coming down. If not, then proceed with troubleshooting memory issue.

Kindly note that in vCMP guest, even if you configure management IP, you will not see any output when running "tmsh list sys management-ip all-properties". This is an expected behavior in vCMP guest.
