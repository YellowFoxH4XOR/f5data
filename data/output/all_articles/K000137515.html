Description

The below warning message occurs when you save ucs via GUI or CLI.

Saving active configuration...

ERROR 2002 (HY000): Can't connect to local MySQL server through socket '/var/lib/mysql/mysql.sock' (2)

/var/local/ucs/1.ucs is saved.

 

Environment

  • BIG-IP LTM
  • UCS
  • MySQL

Cause

Bug ID 760740: Mysql error is displayed when saving UCS configuration on BIG-IP system when MySQL is not running.

Recommended Actions

Typically, the issue happens when the device once enabled the modules that needed the MySQL service, such as AFM, ASM, APM, etc, and now was removed. The error message is cosmetic and has no impact on the UCS save process. You can safely ignore this warning message.
