Description

Configuration failed to load after reboot, with an error similar to the following:

Syntax Error:(/config/bigip_base.conf at line: 541) "log-level" invalid value "}", expected one of the following: "critical" "debug" "error" "informational" "notice" "warning"

Environment

  • After reboot
  • Configuration load

Cause

csyncd log level is set to an invalid or missing value in /config/bigip_base.conf:

sys daemon-log-settings csyncd {
    log-level
}

This happens if the csyncd log level was set to Alert, Emergency, or Verbose via tmui or tmsh.

ID1142065 tracks this issue.

Recommended Actions

Remove the invalid configuration stanza from /config/bigip_base.conf, then reload the configuration:

sed -i '/sys daemon-log-settings csyncd {/,/^}/d' /config/bigip_base.conf && tmsh load sys conf

Avoid setting the csyncd log level to Alert, Emergency, or Verbose.
The default value is Notice.
Use Debug for troubleshooting csyncd issues, if necessary.
