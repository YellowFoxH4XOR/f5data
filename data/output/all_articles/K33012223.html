Description

For iSeries and rSeries platforms, SDN Services license is included in the base license. SDN services are governed by the ltm_network_virtualization feature flag in the license file, as below:  
ltm_network_virtualization :  enabled

There is no need to obtain extra SDN Services add-on key. If customer attempts to activate a new SDN Services add-on key on iSeries platform,  the following licensing error is expected:
Error 51086:  Add-on Module Key is not a valid option for the Base Registration Key Product BIG-LTM-IXXXX does not allow the Add-On module to be included: ABCDEFG-ABCDEFG (LIC-PKG-BIG-ADD-SDN)

Environment

  • iSeries and rSeries
  • SDN Service
  • ltm_network_virtualization feature

Cause

Add-on key is not compatible with the product.

Recommended Actions

None

Additional Information

Verify if the ltm_network_virtualization feature is enabled by running the command below:

iSeries

grep ltm_network_virtualization /config/bigip.license

rSeries

show system licensing full | include ltm_network_virtualization
