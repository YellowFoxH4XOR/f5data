K000092998: The Support menu option is not displayed on the F5 Access for iOS application for iPads

Type
Support Solution
Published
2023-03-07
Updated
2023-03-07
Source
https://my.f5.com/manage/s/article/K000092998

Description

The "Support" tab and all the items such as Manage Certificates, Diagnostics, Email Logs are not being displayed in the F5 Access for iOS application when using it on an iPad. They are displayed properly on an iPhone.


Environment

BIG-IP APM, F5 Access for iOS

Cause

When using the F5 Access for iOS client on an iPad in Portrait orientation the menu item "Support" is not displayed, only the Configurations tab is displayed.


When you switch to Landscape orientation then the Support tab is listed and you can select it and all sub items such as Manage Certificates, Diagnostics, Email Logs.

Recommended Actions

Switch to Landscape orientation and the tab is displayed properly. If you select the Support tab you can then move back to Portrait orientation if desired.
