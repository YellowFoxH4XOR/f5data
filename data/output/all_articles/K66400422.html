Description:


Clients experience slow performance while browsing internet.
Speedtests results are worse than expected.
 

Environment:

  • BIG-IP LTM
  • Standard virtual server type Pool of HTTP proxies

Cause:


None.
 

Recommended Actions:


In order to achieve best performance in simple L4 traffic processing it's recommended to use Performance  (Layer 4).
This virtual server type takes advantage of  FastL4 profile that increase performance and throughput for supported platforms by using the embedded Packet Velocity Acceleration (ePVA) chip to accelerate traffic.
