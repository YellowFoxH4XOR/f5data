Issue

Error Message

err mcpd[<PID>]: 010712a5:3: Ha_group <ha group name> unknown <object type> <object name>

In this error message, note the following:

  • <PID> is the process ID for mcpd.
  • <ha group name> is the high availability (HA) group name.
  • <object type> is the object type that you are attempting to add to the HA group such as pool, trunk, or cluster.
  • <object name> is the name of the pool, trunk, or cluster.

For example:

err mcpd[<PID>]: 010712a5:3: Ha_group my_group unknown pool my_pool

Message Location

You may encounter this message in the following location[s]:

  • /var/log/ltm
  • TMOS shell (tmsh)
Description

This message occurs when the following condition is met:

  • You attempt to add a non-existent pool, trunk, or cluster object to an HA group.

Impact

The HA group configuration is not modified.

Recommended Actions

Use tab completion in tmsh or use the BIG-IP Configuration utility to ensure that you are adding an existing pool, trunk, or cluster to the HA group.
