Description

This article describes troubleshooting steps required to determinate if SNMP v3 works properly on the BIG-IP. Below steps should be performed when the SNMP is already configured. For more information please refer to related content.

 Environment

  • BIG-IP
  • SNMPv3

Recommended Actions

1. Take a packet capture from CLI level on BIG-IP. Please use TCPDUMP utility with the syntax below:

 

tcpdump -nni mgmt -A -vv host <SNMP agent IP address> and port 161 or icmp -w /var/tmp/SNMPv3.pcap

 

Note: In the example above <SNMP agent IP address> is the IP address of SNMP agent which is polling BIG-IP. Please set a proper IP address here.

 

While TCP dump is running, please generate a poll from agent to BIG-IP.

Once that is done, press CTRL + C to stop TCPDUMP.

 

This will create a SNMPv3.pcap file in /var/tmp/ directory of F5 device. Please move this file to your local workstation using SFTP or SCP client.

Impact of this procedure: It should not have any negative impact for traffic processing and configuration. 

 

2. Currently, SNMPv3.pcap file is encrypted and you can see only: encryptedPDU: privkey Unknown. Decrypt obtained pcap file using WireShark (Third Party Tool), by providing authorization credentials:

  • Navigate to: Edit > Preferences > Protocols
  • Select SNMP from the protocol list
  • Click on Edit button next to Users Table

 

  • Click on the Add button and enter the required details:

 

    Engine ID
    SNMPv3 username
    Choose the authentication model
    Enter the password for the authentication model
    Select the privacy protocol
    Enter the privacy password
