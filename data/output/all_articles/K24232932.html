Description

Higher CPU in management / control plane observed after upgrade to 15.1.0 or later, from an earlier branch. This does not reduce to pre-upgrade levels, even after waiting several days.

No obvious culprit visible when using standard tools such as top or ps.

Environment

  • CPU utilization
  • After upgrade

Cause

Bug ID 948717: F5-pf_daemon_cond_restart uses excessive CPU

Recommended Actions

The amount of extra CPU utilization may be fairly low, around ~15% of odd cores. It is advisable to plan an upgrade to a fixed version, but there shouldn't be any immediate risk, unless the system is already over-utilized.

Additional Information

The extra CPU utilization is from children of the F5-pf_daemon_cond_restart process, so it is not obvious to spot using standard tools for troubleshooting high CPU.
