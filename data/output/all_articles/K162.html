F5 Networks has registered port 4353 with the Internet Assigned Numbers Authority (IANA) for communication using the iQuery protocol. The default port for the iQuery protocol is port 245; however, this port is not registered to F5 Networks.

To send iQuery traffic to port 4353, change the value of the wideip.conf global variable, use_alternate_iq_port, to yes, by performing the following steps:

  1. From the Configuration utility, click System.

    The System - General properties page is displayed.

  2. Check the Use Alternate Port (port 4353) checkbox.
  3. Click Update.
