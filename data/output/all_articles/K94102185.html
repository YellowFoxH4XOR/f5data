K94102185: Ping -I will not work if lack of explicit route

Source

Description
Ping -I will not work if lack of explicit route

# ping -I external 1.1.1.1
PING 1.1.1.1 (1.1.1.1) from 172.28.4.13 external: 56(84) bytes of data.
From 172.28.4.13 icmp_seq=2 Destination Host Unreachable
From 172.28.4.13 icmp_seq=3 Destination Host Unreachable
From 172.28.4.13 icmp_seq=4 Destination Host Unreachable

Environment

  • BIG-IP

Cause
Lack of explicit route toward destination IP.

Recommended Actions

Add explicit route toward destination IP.
# tmsh create /net route 1.1.1.1/32 gw 172.28.4.32
# ping -I external 1.1.1.1
PING 1.1.1.1 (1.1.1.1) from 172.28.4.13 external: 56(84) bytes of data.
64 bytes from 1.1.1.1: icmp_seq=1 ttl=255 time=0.641 ms
