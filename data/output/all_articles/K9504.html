Known Issue

This is the result of a known issue. The Java version of the Microsoft Terminal Services (Remote Desktop) client does not auto-launch the program you configured in the Select a program field in the Terminal Servers favorite configuration.

Note: The Microsoft Terminal Services Java client was introduced in FirePass version 6.0.3. You enable the Java client by selecting the Java client check box in the Terminal Servers favorite configuration.

The ActiveX version of the Microsoft Terminal Services client does auto-launch the program configured in the Select a program field. However, the ActiveX client only supports Microsoft Window systems.

F5 Product Development tracked this issue as CR112541 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

This issue was fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

If you do not need to support Linux and Mac OS X clients, you can work around this issue by configuring the ActiveX version of the Microsoft Terminal Services client. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Application Access: Terminal Servers: Resources page.
  3. Select the name of the Terminal Servers favorite you want to configure.
  4. Clear the Java client check box.
  5. Click Update.

When users launch the Terminal Servers favorite, the client system will now use the ActiveX version of the Microsoft Terminal Services client and launch the program you configured in the Select a program field.
