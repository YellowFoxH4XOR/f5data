K30114265: Configuring HTTP 301 redirect to include HSTS headers

Topic

You should consider using this procedure under the following conditions:

  • You have a BIG-IP virtual server that is redirecting to another location.
  • You have a requirement for HTTP Strict Transport Security (HSTS) on all requests.

Description

The BIG-IP system's native iRule, _sys_https_redirect, uses a 302 response to redirect traffic from the HTTP virtual server to HTTPS. This default 302 response comes from the BIG-IP and will not contain an HSTS header. 
However, you can create custom iRule that includes an HSTS header in the redirect response.
 

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the Configuration utility or TMOS Shell (tmsh).
  • You have existing HTTP and HTTPS virtual servers using the same virtual address on your BIG-IP system.

Procedures

Creating a custom iRule to redirect HTTP to HTTPS with 301 response

To use the Configuration utility to configure a custom iRule to redirect HTTP requests to HTTPS with a 301 redirect and apply the custom iRule to an HTTP virtual server, perform the following procedure:

Impact of procedure: The specific customization of this iRule may differ for your specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log into the BIG-IP Configuration Utility
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. Type the Name you want for this custom iRule. For example: hsts_redirect.
  5. In the Definition box, use the following iRules syntax, modifying the values for <hostname> and <destination> to match your needs:

    when HTTP_REQUEST {
        switch -glob -- [string tolower [HTTP::uri]] {
            "/" {
                HTTP::respond 301 Location "https://<hostname>/destination/" Strict-Transport-Security "max-age=31536000"
                 }
        }
    }

    For example:

    when HTTP_REQUEST {
        switch -glob -- [string tolower [HTTP::uri]] {
            "/" {
                HTTP::respond 301 Location "https://f5.com/example/" Strict-Transport-Security "max-age=31536000"
                 }
        }
    }

  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers.
  8. Click the HTTP virtual server you want to redirect.
  9. Click the Resources tab.
  10. Under iRules, click Manage.
  11. In the Available box, click the custom iRule you just configured. For example: hsts_redirect.
  12. Click the Move button to move the custom iRule to the Enabled box.
  13. Click Finished.
