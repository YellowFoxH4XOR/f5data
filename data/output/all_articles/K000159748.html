Description

When attempting to login via helm to repo.f5.com, an error occurs:

cat cne_pull_64.json | helm registry login -u _json_key_base64 --password-stdin https://repo.f5.com

Error: authenticating to "repo.f5.com": GET "https://repo.f5.com/v2/": GET "https://repo.f5.com/_token": response status code 401: unauthorized: authentication failed

Environment

  • BIG-IP Next BNK, SPK, or CNF

  • Authenticating helm to repo.f5.com as part of the installation process

Cause

The content in cne_pull_64.json is invalid. This can occur if you printed the contents to screen on one system and copy/paste into a terminal of the destination system.

Answer/Recommended Actions

  1. Upload the f5-far-auth-key.tgz file to the system where you will perform the helm login
  2. Extract the tarball file
  3. Attempt to execute the helm login again. The command should return "Login Succeeded".
