Description
Pool member / Node is marked down by health monitor. 
Took tcpdump between self IP and the node/pool member IP address, and it shows monitor is working. 
debug monitor log also shows it is working.
 

Environment

  • BIG-IP
  • health monitor
  • bigd
  • mcpd
     

Cause
Bug ID722657

Recommended Actions

to workaround,
remove the monitor and save the change, then add the monitor and save again. (if it did not work, please restart bigd)
   or 
restart bigd with the following command
tmsh restart sys service bigd
 

Additional Information

  • K12531:  Troubleshooting health monitors
  • K16008: Overview of BIG-IP pool status (11.x - 16.x)
