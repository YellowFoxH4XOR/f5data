Description

After they upgrades to v15.1.8.1 in vCMP guest, customer will get the error message in ltm log.

warning chmand[4101]: 012a0004:4: VcmpShmIntf::querySeg: err code -34

Environment

BIG-IP vCMP guest

Cause

ID1228465

Recommended Actions

tmsh modify sys syslog { include "filter f_local0 { (facility(local0) and not match (getHostVWireNtiObjectConfigs) and not match (getHostVWireObjectConfigs) and not match (VcmpShmIntf));};" }
