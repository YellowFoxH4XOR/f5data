Known Issue

This is the result of a known issue. If you attempt to save or update an iRule in the BIG-IP GTM Configuration utility which contains the == (numerically equal) or >= (numerically greater than or equal to) comparison operator, the Configuration utility may stop responding, or display an error message that appears similar to the following example:

01070151:3: Rule [test] error:
line 1: [undefined procedure: ] [{}]

F5 Product Development is tracking this issue as ID 221912 (formerly CR100063).

Workaround

You can work around this issue in either of two ways:

  • Using an alternate comparison operator (9.x - 11.x)
  • Editing the configuration file directly (9.x - 10.x only)

Using an alternate comparison operator (9.x - 11.x)

Instead of using the numeric equality operator (==), you may be able to use the equals or eq string comparison operator.

For example:

$x == 1

If your original iRule contained the example comparison, you may be able to replace it with the following equivalent comparison:

$x equals 1

However, since equals and eq are string comparison operators, numeric comparisons may not resolve as expected.

Instead of using the greater than or equal to comparison operator (>=), you may be able to use an alternate numeric comparison.

For example:

$x >= 1

If your original iRule contained the example comparison, you could replace it with the following equivalent comparison:

$x > 0

Editing the configuration file directly (9.x - 10.x only)

Since this issue affects only the configuration of iRules in the Configuration utility, you may edit the iRule directly in the wideip.conf configuration file, then load the modified configuration. To do so, perform the following procedure:

  1. Log in to the BIG-IP GTM command line.
  2. Open the /config/gtm/wideip.conf file for editing.
  3. Locate the // *** Rule Definitions (1) *** section.
  4. Insert your iRule immediately following the *** Rule Definitions (1) *** line.

    Important: You must include the first line which defines and names the rule object, and the last line which contains only the closing curly brace. For example, the following code block defines the iRule named LogRequests:

    rule "LogRequests" partition "Common" {
    when DNS_REQUEST {
    if { [active_members gtm_pool] == 1 } {
    log "load balancing request..."
    }
    }
    }
  5. Close and save the modified configuration file.
  6. Load the modified configuration file by typing the following command:

    gtmparse -l
