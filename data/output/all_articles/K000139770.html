K000139770: tmsh core after running tmsh command

Type
Support Solution
Published
2024-05-24
Updated
2024-05-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000139770

Description

  • tmsh process crashes after running tmsh command and a tmsh core file is generated
  • An output similar to the following can be seen on CLI

    terminate called after throwing an instance of 'CLI::SyntaxError'
    what(): single quotes are not balanced
    Aborted (core dumped)

Environment

  • BIG-IP
  • tmsh
  • CLI

Cause

tmsh is aborted due to a syntax error, the quotes on the tmsh command are not balanced

For additional information, please refer to Bug ID 1330213

Recommended Actions

Make sure that quotes are balanced on the tmsh command before execution

Additional Information

None
