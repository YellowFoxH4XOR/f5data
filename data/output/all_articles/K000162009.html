K000162009: Remote authenticated users may receive "Error getting auth token from login provider" error on GUI.

Type
Support Solution
Published
2026-07-01
Updated
2026-07-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 21.0.0, 21.1.0, 17.5.1
Source
https://my.f5.com/manage/s/article/K000162009

Description

After logging into the BIG-IP Configuration Utility (GUI), remotely authenticated users cannot access certain BIG-IP GUI pages for example "Device Management → Overview, Application Security, and System → Support" in the BIG-IP GUI. The GUI displays “Error getting auth token from login provider,” while the related requests returned HTTP 400 errors.

 

Figure: GUI error on "[Device Management]=>[Overview]" for user "_admingroup_user1"

 

Restjavad may record error messages similar to followings.

 

  • /var/log/restjavad.0.log

[WARNING][187][18 Jun 2026 11:09:07 JST][RestOperationIdentifier] Failed to validate Authentication failed.

 

  • /var/log/restjavad-audit.0.log

[I][204][18 Jun 2026 11:09:52 JST][ForwarderPassThroughWorker] {"user":"local/null","method":"POST","uri":"http://localhost:8100/mgmt/shared/authn/login","status":400,"from":"$(GUI client address)"}

 

Some parts of the GUI pages are known to be affected. For example, "Device Management >> Overview", "Device Management >> Traffic Groups : [traffic-group-object]", "Shared Objects", "iApps >> Application Services : Applications LX".

 

Environment

  • Remote authentication is configured to access to GUI (e.g., LDAP, Radius, TACACS+...etc).
  • Remotely authenticated username starts with underscore '_' or '\' or '@' characters.
  • BIG-IP v17.x, v17.5.x, v21.0.x, v21.1.x (at the time of article publication)

 

Cause

Bug ID2295233 for '_' and Bug ID2304105 for '\' or '@'.

 

Answer/Recommended Actions

A fix is in progress and will be included in a future maintenance releases. Upgrade to a release where both ID2295233 and ID2304105 are resolved or request for an EHF with fix for both ID2295233 and ID2304105.
