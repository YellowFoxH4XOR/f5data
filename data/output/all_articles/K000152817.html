K000152817: BIG-IP Azure VM without Accelerated Networking frequent tcp retransmissions after upgrade to 17.5.x

Source

Description

BIG-IP Azure VM without Accelerated Networking frequent tcp retransmissions after upgrade to 17.5.x  

 

Environment

  • BIG-IP Azure VE
  • Upgrade to 17.5.x
  • DPDK driver
  • SOCK driver

Cause

Azure VM without Accelerated Networking using DPDK driver.

Recommended Actions

Apply the workaround to change the driver from 'DPDK' to 'sock'. 

Note:  Perform below steps involves tmm restart which is disruptive to traffic. Recommended to perform this in maintenance window.

(a)  Check the loaded driver.

# tmctl -d blade tmm/device_probed

pci_bdf   pseudo_name type   available_drivers driver_in_use

------------ ----------- --------- ----------------- -------------

0000:00:e0.0          F5DEV_PCI xnet, sock,

0000:00:e1.0 1.1       F5DEV_PCI xnet, sock,      xnet

0000:00:e2.0 1.2     F5DEV_PCI xnet, sock,      xnet

0000:00:e3.0 1.3     F5DEV_PCI xnet, sock,      xnet

(b)  Since, Azure VM without accelerated networking use Host Bridge and does not list Ethernet Controller in 'lspci' output. Driver can be changed using following method.

 

  •  Check the PCI ID for the interface.

# tmctl -d blade tmm/ndal_dev_status -s iface,pci

             

  • Add entry in tmm_init.tcl

# cd /config

# echo "device driver pci 00:e3.0 sock" >> tmm_init.tcl

(c) Now, tmm need to be restarted.   Restarting TMM will cause traffic to be disrupted. 

   # bigstart restart tmm

(d) Now, check the interface and its associated driver status.

# tmctl -d blade tmm/device_probed
