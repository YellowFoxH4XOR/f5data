Description

(Legend: t = total, s = synchronized, r = replicating)

Environment

This has only been observed on 14.0.x, 14.1.x, 15.0.x, and 15.1.x, on BIG-IP hardware platforms which contain a raid array, such as but not limited to 7200v.

Cause

BUG ID748044 

Recommended Actions

You can correct the stale 'show sys raid' information, by performing the procedure below.
Note: this procedure requires the system be rebooted. The system will not be able to process traffic, while it is rebooting.

  1. touch /service/mcpd/forceload
  2. reboot
Note: For more information regarding the mcpd force load process refer to K13030 in Related Content
