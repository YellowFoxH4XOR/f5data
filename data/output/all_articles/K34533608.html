DescriptionHA is not forming and status is showing as disconnected, while the HA interfaces can ping from each other and HA VLAN is configured as tagged Interface

Environment

  • High Availability 
  • VLAN Tagging

Cause

If there is a switch between two BIG-IP devices and HA VLAN is configured as tagged interfaces, switch might drop the packets. This happens if switch is not configured to pass tagged packets. 

Recommended Actions

To fix the issue you may either configure the HA VLAN interface as untagged or configure switch to allow tagged packets.
To update the HA VLAN configuration on BIG-IP
  1. Navigate to VLAN configuration
    On the Main tab, click Network > VLANs 
  2. Select the VLAN to modify
  3. From the Interface list, select an interface number
  4. From the Tagging list, select Untagged.
  5. Click update

Additional Information

In case of VMware Environment refer the  article for VLAN configuration on virtual switches
