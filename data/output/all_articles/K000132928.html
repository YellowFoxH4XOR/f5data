Description

You're trying to upgrade or apply a BIG-IP Engineering Hotfix on a F5OS Tenant.

Environment

  • F5OS Platform (F5OS-A and F5OS-C)
  • BIG-IP Tenant
  • Engineering Hotfix

Cause

None

Recommended Actions

For upgrading and applying an Engineering Hotfix on a F5OS Tenant (BIG-IP), we still follow the normal upgrade procedure of BIG-IP TMOS. Unlike vCMP with F5OS the image is not imported to the host but directly to each tenant.

Articles related below:

  • K84554955: Overview of BIG-IP system software upgrades
  • K13123: Managing BIG-IP product hotfixes (11.x - 17.x) 
  • K55025573: BIG-IP engineering hotfix installation overview

Along with the EHF the ISO base image file is also needed upgrading/applying hotfix.

If the base image is not already on the tenant login to the F5 Download site and download the applicable iso and import it to the BIG-IP along with the EHF.

For example:

Select a product family: BIG-IP
Tell us more about your product: BIG-IP v17.x 
Select a product container: 17.1.x or 17.5.x
Select a download file: Example only: BIGIP-17.1.3-0.0.7.iso (Use for upgrades. Does not include EUD.)

Once you have both images on the tenant you can install. 

Please review the aforementioned articles prior to installing the new EHF.
