Description

SNMP polling of BIG-IP sometimes reporting partialSync as sync status while querying sysCmSyncStatusId

  • SNMP is polling OID .1.3.6.1.4.1.3375.2.1.14.1.1 (sysCmSyncStatusId)
  • In the response, sometimes partialSync (9) is returned as status

Environment

  • BIG-IP (Cloud or hardware based)
  • SNMP tool monitoring BIG-IP
  • Auto-sync is configured in HA.

Cause

If the partialSync is followed by inSync, then it's working as expected and not a cause for concern. However this can be reduced by following the steps in Recommended Actions section.

Recommended Actions

  1. Reduce the frequency at which this OID is being polled.
