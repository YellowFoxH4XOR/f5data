K000150788: ASM support for Webdav

Description

The WebDAV protocol provides a framework for users to create, change and move documents on a server.  ASM supports this protocol as it is an extension of HTTP.

By defaults the methods used by WebDAV are disabled in the security policy and should be enabled for the relevant Allowed URLs in Method Enforcement.

In cases were files are created with PUT method, the content-type in the requests can be misrepresented based on the actual payload. This can lead to false positives and blocked requests.

Environment

  • ASM
  • WebDAV
  • Allowed URLs
  • Allowed methods

Cause

None.

Recommended Actions

After allowing the relevant methods for incoming requests in the Allowed URL and in the scenario where requests are blocked due to their content being parsed by the xml profile, a Header-Based content profile with action "Do nothing" should be configured for xml as the application is sending binary data and not actual xml.
