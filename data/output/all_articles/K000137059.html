K000137059: Setting Protocol Inspection Profile to check HTTP traffic on port 443

Type
Support Solution
Published
2023-09-29
Updated
2025-02-06
Source
https://my.f5.com/manage/s/article/K000137059

Description

When adding a Protocol Inspection profile to an HTTPS virtual server and you want it to do HTTP protocol inspection you need to add port 443 to the HTTP section.

Environment

BigIP AFM with Intrustion Prevention added.

Cause

 HTTP checks will not be done by default due to the HTTP protocol only checking ports 80 and 8080.

Recommended Actions

In the Protocol Inspection Profile go to the HTTP section and click the pencil icon to the far right.
This will open up a side panel that allows you to modify the ports.
Here you can add port 443 if needed.
