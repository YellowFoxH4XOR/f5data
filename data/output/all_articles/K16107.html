Known Issue

The /etc/monitors/monitors_logrotate.conf file contains a syntax error.

You can find the size=5MB error on line 6. The correct syntax should be size=5M.

Impact

Log files in the /var/log/monitors directory are not rotated based on size, and the /var/log directory can become full.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H499707 on the Diagnostics > Identified > Medium screen.
  • The diskmonitor utility reports a message similar to the following example in the /var/log/ltm file:

    diskmonitor: 011d005: Disk partition var has less than 30% free

  • The BIG-IP system sends email alerts every thirty minutes regarding the following syntax error:

    error: /etc/monitors/monitors_logrotate.conf:6 unknown unit 'B'
    error: found error in /var/log/monitors/*.log , skipping

Workaround

To work around this issue, you can modify the /etc/monitors/monitors_logrotate.conf file using a text editor or the sed command. To use the sed command, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Modify the /etc/monitors/monitors_logrotate.conf file by using the following sed command syntax:

    sed -i 's/size=5MB/size=5M/g' /etc/monitors/monitors_logrotate.conf
