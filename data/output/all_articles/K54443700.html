Known Issue

HTTP/2 requests receive an HTTP/2 RST_STREAM protocol error response.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP virtual server with an HTTP/2 profile.
  • The virtual server processes a fragmented HTTP/2 frame header (due to TCP segmentation).

Impact

The HTTP/2 connection fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP virtual server intermittently sends the HTTP/2 connection requests an HTTP/2 RST_STREAM protocol error response.
