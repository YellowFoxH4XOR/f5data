Known Issue

The Traffic Management Microkernel (TMM) may exit and restart when you associate an acceleration profile with a virtual server in BIG-IP 11.x.

This issue occurs when all of the following conditions are met:

  • You configure a BIG-IP WebAccelerator 10.x acceleration policy with a large number of wildcard characters in matching rules.
  • You perform one of the following actions:
    • You upgrade from BIG-IP WebAccelerator 10.x to 11.x.
    • You configure a virtual server on a BIG-IP 11.x system with the 10.x acceleration policy.

Note: BIG-IP WebAccelerator and BIG-IP WOM were combined to create BIG-IP AAM in 11.4.0.

When you enable WebAccelerator or BIG-IP AAM in a Web Acceleration profile, and associate the profile with a virtual server in BIG-IP 11.x, the associated acceleration policy is compiled in to binary form for efficiency. During compilation, a large number of wildcards in matching rules, such as path segment matching rules, may cause the tmm process to enter a loop and fail to respond to heartbeat messages, which causes TMM to exit and restart.

Impact

The BIG-IP system may temporarily fail to process traffic while the TMM process restarts, and the system fails over if it is configured for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system generates a TMM core file to the /shared/core/ directory.
  • Your BIG-IP system fails over to another host in the device group.

Workaround

You can prevent an AAM policy compilation from taking too long by turning the regular expression into plain matches using the backslash character to escape those symbols that turn a string into a regular expression. For example, previously, favicon.ico was treated as a regular expression because the period character (.) means any character. Now you can specify favicon\\.ico, which causes the (.) to mean the period character, thus avoiding the unintended regular expression.

Note: This workaround will only function when the fixes listed in the in the Fixes Introduced In section have been installed.
