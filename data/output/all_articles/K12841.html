K12841: ARX uses multiple TCP connections as needed to support a greater number of tree connections

Type

Published
2011-06-30

Applies to

  • ARX: 5.2.2, 5.3.1
Source

Issue

Note: Some file servers cannot tolerate more than 2,048 simultaneous tree connections in a single TCP connection. New connections will fail during a tree connect once the available Tree Connect IDs (TIDs) have been exhausted.

ARX versions prior to 5.2.2 use a single TCP connection and do not limit the number of CIFS Tree Connect IDs (TIDs) passed to a file server in that single TCP connection. As a result, if all available TIDs for the TCP connection are exhausted, the Windows server will respond with STATUS_INSUFFICIENT_SERVER_RESOURCES and new connections will fail until TIDs become available.

Beginning in ARX 5.2.2, the ARX system will use multiple TCP connections as needed to support a greater number of tree connections. When the number of TIDs used exceeds 2,000 per TCP connection, an additional TCP connection is used.

Note: The new behavior was also ported back to ARX 5.1.9 HF4 (build 12110).

F5 tracked this change in behavior as ID 343244. For information about upgrading, refer to the ARX release notes.
