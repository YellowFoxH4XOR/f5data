Known Issue

The configuration may fail to load if a link-local address is configured as a default gateway.

This issue occurs when all of the following conditions are met:

  • You have set the config.allow.rfc3927 database key to enable to allow the system to use IPv4 link-local addresses.
  • You configure a link-local address as a default gateway. For example, the following TMOS Shell (tmsh) command configures the link-local address gateway with an interface value of Ext:

    create net route External_defaul_GW gw 169.254.200.1 interface Ext

  • Your bigip.conf configuration file contains an interface without an interface value under the link-local address configuration.

    For example, an interface value Ext is missing from the following configuration:

    net route /Common/External_default_GW {
        gw 169.254.200.1
        interface                      
        network default
      }

Impact

The configuration fails to load. However, your configured default gateway works as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If you attempt to load the configuration by using the tmsh load /sys config command, the system displays an error messages similar to the following example:

    Syntax Error:(/config/bigip.conf at line: 1017) "default" unknown property.

  • Your configured interface value is not saved to the bigip.conf file.

Workaround

To work around this issue, you can manually modify the /config/bigip.conf configuration file and edit the affected interface. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform the following workaround during a maintenance window.

  1. Log in to the command line of the affected BIG-IP system.
  2. To create a backup copy of the /config/bigip.conf file, type the following command:

    cp /config/bigip.conf /config/bigip.conf.673316

  3. Use a text editor to open the /config/bigip.conf file.

  4. Locate the affected interface and add the correct interface value (interface Ext).

    For example:

    net route /Common/External_default_GW {
        gw 169.254.200.1
        interface Ext                    
        network default
      }

  5. Save the changes to the /config/bigip.conf file.
  6. To load the updated configuration, type the following command:

    tmsh load /sys config
