Description

Web application is unresponsive when clients try to open it via virtual server IP address.

Environment

  • Virtual server

Cause

Server-side connection cannot be established, as firewall is blocking SYN from BIG-IP to pool member.

Recommended Actions

  1. Take a packet capture of the affected traffic

    tcpdump -s0 -vnni 0.0:nnnp host a.b.c.d -w /var/tmp/vs_troubleshooting.pcap

    Note: Replace a.b.c.d with the IP of the client accessing the virtual server

  2. Review the packet capture with Wireshark or tshark to determine why the connection is failing

    When this issue occurs, a SYN will be retransmitted several times server-side. A reset will then be issued, similar to the following example:

    10.10.10.100 → 10.10.10.75 TCP OUT s1/tmm1 : 1900 → 80 [SYN]
    10.10.10.100 → 10.10.10.75 TCP OUT s1/tmm1 : [TCP Retransmission] 1900 → 80 [SYN]
    10.10.10.100 → 10.10.10.75 TCP OUT s1/tmm1 : [TCP Retransmission] 1900 → 80 [SYN]
    10.10.10.100 → 10.10.10.75 TCP OUT s1/tmm1 : [TCP Retransmission] 1900 → 80 [SYN]
    10.10.10.100 → 10.10.10.75 TCP OUT s1/tmm1 : 1900 → 80 [RST, ACK] Seq=1 Ack=1 Win=0 Len=0 [F5RST: TCP retransmit timeout]

Additional Information
