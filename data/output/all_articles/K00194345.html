Description

After install the BIG-IP Edge Client software, and the client is connect to remote network, Always Connected mode setting is Allow-Only-in-Enterprise LAN, the Windows system boot up become slower, like 1-3 munites slower than before.

Environment

  • Big-IP Edge Client on Windows
  • Always Connected mode setting is Allow-Only-in-Enterprise LAN
  • Client connect to remote network

Cause

The BIG-IP Edge Client block some connection when the system boot up, cause the system boot up slow.

Recommended Actions

The following steps can address the blocked connections, you can evaluate the connection, add them into the exclusion list if allowed.

  1. Remove the BIG-IP Edge Client software from the client, power off it.
  2. Setup the network connection, capture the traffic when the client boot up.
  3. Power on the client.
  4. Analysis the connection from the client, list the domain name.
  5. Rebuild the BIG-IP Edge Client package, add the domains to the exclusion list.
Please perform the steps 1-4 multiple times, capture the traffic from different client, to make sure you get all the domains.
