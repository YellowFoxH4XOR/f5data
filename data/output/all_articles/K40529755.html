Environment

  • Citrix VDI infrastructure
  • Network access tunnel using EdgeClient

Cause

It seems issue was caused by insufficient permission as EdgeClient was installed without admin rights.

Recommended Actions

Uninstall EdgeClient from the affected Windows client using the Client Troubleshooting Utility (CTU) tool and reinstall it using an account with admin privileges.
To use CTU tool to uninstall EdgeClient please refer  K8253: Removing BIG-IP APM client components from Windows client systems
