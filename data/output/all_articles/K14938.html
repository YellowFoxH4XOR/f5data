Topic

This article applies to BIG-IP GTM 11.5.0 and later. For information about other versions, refer to the following articles:

  • K13404: Overview of BIG-IP GTM global variables (11.0.0 - 11.4.1)
  • K9629: Overview of BIG-IP GTM global variables

Summary

BIG-IP GTM global variables are system-wide settings, including load-balancing, metrics collection, and general configuration parameters.

Description

BIG-IP GTM global variables are configured in the Configuration utility on the DNS > Settings > GSLB > General page.

Configured global variables can also be viewed using the tmsh list /gtm global-settings all-properties command.

The following tables list the global variables as they appear in the Configuration utility.
