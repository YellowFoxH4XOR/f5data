K12345: ARX 5.2.0 has been removed from the F5 Downloads site

Topic

F5 has identified an issue with ARX 5.2.0 relating to how the upgrade process handles multiple share farms in the configuration. As a result, ARX 5.2.0 has been removed from the F5 Downloads and FTP sites. You should not upgrade to ARX 5.2.0 (build 12637) if your current configuration contains two or more share farms. For more information about the potential issue, refer to K12344: Upgrading to ARX version 5.2.0 may cause multiple core files and reloads.

If you already upgraded to ARX 5.2.0, and you did not encounter any issues following the upgrade, you may continue to run version 5.2.0. The issue relating to multiple share farms only occurs during the upgrade process.
