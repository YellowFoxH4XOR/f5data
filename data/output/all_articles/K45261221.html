Environment

  • BIG-IP Viprions with multiple blades configured in an HA pair
  • TMOS 13.1.1
  • Crash and Core dump
  • TMMs constantly restarting on one or more blades

Cause
Potentially due to a hardware issue with the blade.

Recommended Actions
Restore the blade(s) to a functional status by rebooting the blade(s).  Additionally, open a support case on support.f5.com, upload any core files that may have been generated and run EUD against the blade(s) to determine, if there are any potential hardware issues.
