Description

HTTP Header "X-Client-Cert: \r\n" is empty.


Environment

* BIGIP

* VIP

* Client-ssl

* iRule

Cause

When the client-ssl profile uses "retain-certificate" with value "false", the iRule doesn't work. The HTTP Header "X-Client-Cert: \r\n" is empty.


Example: client-ssl used by a VIP:


ltm profile client-ssl /Common/profile_clientssl_example {

<...>

retain-certificate false <-----This is disabled

<...>

}


ltm rule /Common/add_client-certificate {

when HTTP_REQUEST {

HTTP::header insert X-Client-Cert [b64encode [SSL::cert 0]]

}

}


NOTE: This iRule should insert a client certificate.

Recommended Actions

Enable "retain-certificate" on client-ssl profile

Additional Information

Example of http header in packet capture.


Working:


GET /example HTTP/1.1

Host: example.com

User-Agent:

X-Client-Cert:

Accept:


NOTE: When this works fine, X-Client-Cert header has a value.


Not-working:


GET /example HTTP/1.1

Host: example.com

User-Agent:

X-Client-Cert: <----- There is no value. It is empty.

Accept:


NOTE: When this doesn't work fine, X-Client-Cert header has no value.
