Can you give an example of the 'crafted URL' required to exploit this vulnerability?

In accordance with our policies outlined in K4602: Overview of the F5 security vulnerability response policy, F5 will not disclose the specifics required to trigger this vulnerability.

Can I mitigate this vulnerability by restricting access to the iControl REST interface?

Attackers can exploit this vulnerability by sending a crafted link or otherwise tricking a legitimate administrator into executing the payload; therefore, restricting access is not a valid mitigation.

You can mitigate the risk of legitimate administrators being tricked into executing a malicious payload by ensuring that an isolated, specific management browser is used to administer the BIG-IP system or that all management is done through a jump host or other isolated environment, such as a virtual machine on which untrusted links or scripts will not execute.

Why was the fix for CVE-2020-5948 incomplete?

F5 will not disclose the specifics required to exploit CVE-2021-22994 or CVE-2020-5948. F5 has implemented additional test procedures and updated internal training to minimize the possibility of future similar oversights.

I already installed a version in which CVE-2020-5948 is resolved. Do I have to install another fixed version?

Yes. Since the fix for CVE-2020-5948 was incomplete, you should install BIG-IP 11.6.5.3, 12.1.5.3, 13.1.3.6, 14.1.4, 15.1.2.1, or 16.0.1.1, depending on your preference.
