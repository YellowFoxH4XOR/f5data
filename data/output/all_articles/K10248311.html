Security Advisory Description

This issue occurs when all of the following conditions are met:

  • You have licensed and provisioned the BIG-IP APM module.
  • You have configured the apmd process to log at the debug level.
  • You have configured the BIG-IP APM virtual server to run an access policy using an iRule that contains the command ACCESS::policy evaluate.
  • A client supplied a clear text password while authenticating with the BIG-IP APM virtual server.

The following configuration shows an access policy run using an iRule with the ACCESS::policy evaluate command.

ACCESS::policy evaluate -sid $flow_sid -profile /Common/example_access_profile session.logon.last.username <username> session.logon.last.password <clear_password>

Note: For more information on ACCESS::policy evaluate, refer to ACCESS::policy on F5 Cloud Docs.

Impact

In the /var/log/apm file, the apmd process logs the clear-text password from a user session.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe the password of a user's BIG-IP APM session logged in the /var/log/apm file.
