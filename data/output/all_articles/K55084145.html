Description
Export an SSL certificate and key to another BIG-IP.

Environment

  • BIG-IP version 13.1.3.6
  • Client SSL certificate and key.
  • Need to export the certificate and key to another BIG-IP.

Cause
None

Recommended Actions

You can manually create an "archive" file including the certificate and/or key and then import it to another BIG-IP. To do so, follow these steps:

Creating the archive file with the SSL Certificate and key from the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 13.0.0 and later

  1. Log in to the Configuration utility.
  2. Navigate to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  3. Select the SSL Certificate and/or the Key to be exported. 
  4. Click Archive
  5. In the Archive File Name box, type a unique name. 
  6. In the Key List select the desire key name and move it to the Keys to Archive box.
  7. In the Certificate List select the desire Certificate name and move it to the Certificates to Archive box.
  8. Click Generate & Download Archive

BIG-IP 11.0.0 - 12.1.x

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management > SSL Certificate List.
  3. Select the SSL Certificate and/or the Key to be exported. 
  4. Click Archive
  5. In the Archive File Name box, type a unique name. 
  6. In the Key List select the desire key and move it to the Keys to Archive box.
  7. In the Certificate List select the desire Certificate and move it to the Certificates to Archive box.
  8. Click Generate & Download Archive

Importing the archive file to the BIG-IP system

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

BIG-IP 13.0.0 and later

  1. Log in to the Configuration utility.
  2. Navigate to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  3. Click Import
  4. In the Import Type box, click Archive.
  5. Click Choose File and then browse to the location of the archive file (certificate and/or key bundle).
  6. To import the archive file (certificate and/or key bundle) to the BIG-IP system, click Load.
  7. Click Import

BIG-IP 11.0.0 - 12.1.x

  1. Log in to the Configuration utility.
  2. Navigate to System > File Management > SSL Certificate List.
  3. Click Import
  4. In the Import Type box, click Archive.
  5. Click Choose File and then browse to the location of the archive file (certificate and/or key bundle).
  6. To import the archive file (certificate and/or key bundle) to the BIG-IP system, click Load.
  7. Click Import
