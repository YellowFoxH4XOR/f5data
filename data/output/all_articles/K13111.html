Known Issue

The syslog include configuration does not synchronize in an HA redundant pair after you perform a ConfigSync operation. This issue occurs when all of the following conditions are met:

  • The BIG-IP system contains syslog include configuration.
  • You perform a ConfigSync operation from the BIG-IP system that has the syslog include configuration.

Impact

The syslog-ng configuration is not consistent across redundant pair members.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The syslog include configuration on a BIG-IP system does not get synced over to its HA peer. For example, if you run the bigpipe syslog include show command on both members of the redundant pair, the output will be different if they are affected.
  • The syslog-ng utility may not be logging as expected on the HA peer.

This issue does not affect BIG-IP 11.x.

Workaround

There is no workaround for this issue. You have to re-add the syslog include configuration on the HA peer using the bigpipe command or tmsh utility. To do so, perform one the following procedures:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.

  2. Re-add the syslog include configuration by entering the following command:

    modify /sys syslog include <syslog include configuration>

    In the previous command, note the following:

    <syslog include configuration> is the previously configured syslog include configuration.
  3. Save the change by typing the following command:

    save sys config

bigpipe utility

  1. Log in to the command line.
  2. Re-add the syslog include configuration by typing the following command:

    bigpipe syslog include <syslog include configuration>

    In the previous command, note the following:

    <syslog include configuration> is the previously configured syslog include configuration.
  3. Save the changes by typing the following command:

    bigpipe save all
