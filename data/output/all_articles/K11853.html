Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 10.2.0. F5 recommends that all customers currently running 10.2.0 install Hotfix-BIGIP-10.2.0-1755.1-HF1, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1 for BIG-IP 10.2.0:
