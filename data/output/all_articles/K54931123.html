Known Issue

BIG-IP Analytics may report virtual server statistics incorrectly. For example, BIG-IP Analytics reporting may show connections for the wrong virtual server.

This issue occurs when either of the following conditions is met:

  • Two virtual servers are configured with the same IP address or port combinations but different protocols (such as TCP for one and User Datagram Protocol (UDP) for the other).
  • A virtual server is defined using Classless Inter-Domain Routing (CIDR) notation rather than an explicit IP address (for example, 10.10.10.0/24).

Impact

BIG-IP Analytics reporting shows virtual server statistics incorrectly.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP Analytics reports virtual server statistics incorrectly. For example, the statistics may report connections for the incorrect virtual server.
