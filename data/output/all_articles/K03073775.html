Description

The BIG-IP APM On-Demand Certificate Authentication feature does not work with TLS 1.3.

Environment

  • BIG-IP APM
  • On-Demand Certificate Authentication feature
  • TLS 1.3

Cause

The BIG-IP APM On-Demand Certificate Authentication feature relies on the TLS renegotiation feature which has been removed in TLS 1.3.

Recommended Actions

Use one of the following as appropriate for your environment:

  • If you want to use the BIG-IP APM On-Demand Certificate Authentication feature, you must disable TLS 1.3 for the associated SSL profiles.
  • Use Client Certificate Inspection instead of On-Demand Certificate Authentication. For more information, refer to the Client Certificate Inspection chapter of the BIG-IP Access Policy Manager: Authentication Methods manual
    • BIG-IP 17.1
    • BIG-IP 16.1

Additional Information

The TLS renegotiation feature has been removed and replaced with a new TLS extension Post-Handshake Client Authentication in TLS 1.3 (per RFC 8446).
