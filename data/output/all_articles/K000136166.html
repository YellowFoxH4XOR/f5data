K000136166: BIG-IP not visible on BIG-IQ after it is imported

Type
Support Solution
Published
2023-09-12
Updated
2023-09-12
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IQ Centralized Management: 8.0.0, 8.1.X, 8.1.0, 8.0.X, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000136166

Description

  • After importing a BIG-IP device to BIG-IQ, the BIG-IP device states that is managed by BIG-IQ, but it does not appear in the BIG-IQ managed devices list.
  • BIG-IP is not showing on BIG-IQ GUI but is can be seen on BIG-IQ database via iControl REST output (K54392016).

Environment

  • BIG-IQ CM
  • BIG-IP
  • BIG-IP configured with remote authentication.

Cause

BIG-IQ is unable to authenticate with the BIG-IP device.

Recommended Actions

1. On the BIG-IP switch remote authentication to local. This configuration change can be made in the GUI under System : Users : Authentication and change the directory to Local.

2. Then from BIG-IQ re-import the BIG-IP device using local credentials.

3. Then on BIG-IP switch back to remote authentication.
