Description

BIG-IP ping result showing 'connect: Invalid argument'

[root@bigip.example.com] config # ping 10.10.10.100
connect: Invalid argument

Environment

  • BIG-IP LTM
  • Network route with type blackhole

Cause

Pinging to an IP address that uses the network route of type blackhole.

To check network route.

[root@bigip.example.com] config # tmsh show net route
-----------------------------------------------------------------------------------
Net::Routes       
Name                Destination         Type       NextHop                Origin
-----------------------------------------------------------------------------------
10.10.10.0/24       10.10.10.0/24       blackhole                         dynamic


Recommended Actions

This is an expected behaviour of the blackhole (aka 'reject') route.

Additional Information

For more information about route type blackhole, refer to https://en.wikipedia.org/wiki/Black_hole_(networking).
