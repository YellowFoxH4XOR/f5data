Description

Mitigate CVE-2022-42889 vulnerability with the ASM signatures.

Note: For information about F5's response to CVE-2022-42889, refer to K24823443: Apache Commons Text vulnerability CVE-2022-42889.

Environment

  • ASM signatures

Cause

None.

Recommended Actions

In order to protect your web application against the vulnerability CVE-2022-42889, it is recommended to enforce the following signature IDs:

200104807 - exists as of 13th July, 2022
200104808 - exists as of 13th July, 2022
200104809 - exists as of 13th July, 2022

Ensure you have downloaded and applied the latest available Advanced WAF Signature Update to receive signatures 200104807, 200104808 & 200104809 - at least ASM-SignatureFile_20220712_133421 or newer.

Additional Information

The configured policies may not have signature set that consists of the signatures IDs, therefore, you can do either of the following:
 

  • Add any of the signatures sets; these sets contain all three signature IDs;
WebSphere signatures
Server Side Code Injection Signatures
Low Accuracy Signatures
Medium Accuracy Signatures
All Signatures
 
  • Or create custom signature set and add only the three required signatures.
Followed by adding the custom signature set to the policy.
 
For more information to creating custom sets, refer to Manual Chapter : Assigning Attack Signatures to Security Policies
