Description
QKView failed processing on iHealth. When attempting to view the QKView with URL link, the following error is displayed: 

Processing Failure:
Unable to process unified QKView data output.

Environment

  • QKView
  • iHealth
  • CLI

Cause

The issue is caused by the use of long object name.

Recommended Actions

  1. Log in to the CLI and ensure that you are in bash mode.
  2. Run the below commands
    cd /var/tmp/ && mkdir qkview && cd qkview
    tar -xaf /var/tmp/<qkview_file_name>
    sed 's/~/./g' proc_module.xml
    tar -cpzf <new_qkview_file_name>
  3. Upload the fixed version of the QKView file to iHealth.
