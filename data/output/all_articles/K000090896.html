K000090896: Warning AddedOrUpdatedWithError : nginx reload failed: too long parameter

Description

NGINX fails to load when applying changes to configuration. You observe error message that appear similar to the following example:
 

stderr: "2020/24/09 11:52:39 [emerg] 11111#11111: too long parameter \"$vs_nginx_...\" started in /etc/nginx/conf.d/vs_nginx.conf:1234\nnginx: [emerg] too long parameter \"$vs_nginx_...\" started in /etc/nginx/conf.d/vs_nginx.conf:1234\n"
finished with error: exit status 1
 

 Environment

NGINX Ingress Controller

NGINX+

 

 Cause

There is a known issue when there are a large number of match conditions defined in NGINX Ingress Controller configuration YAML, when applied NGINX Ingress Controller may generate a map parameter that is longer than is supported by NGINX+ (4096), the config will fail to load.

 

 Recommended Actions

To workaround this issue, find ways of reducing the number of conditions. Consider using regex as described in NGINX Ingress Controller - Configuration - VirtualServer and VirtualServerRoute Resources.
