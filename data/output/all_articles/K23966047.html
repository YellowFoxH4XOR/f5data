Description
  • Security group entries are not created when deploying BIG-IP using AWS CloudFormation templates
  • When specifying "restrictedSrcAddress" with a netmask /23, no security group entries get created
  • When trying to create the security group entries manually using a /23 netmask, they show up for a few seconds and then they get removed automatically
  • When specifying a netmask of /24 while/after creating the stack, the entry remains persistent in the security group
Environment
  • LTM VE on AWS
Cause

The AWS account used does not have sufficient permissions to create/modify security group objects

Recommended Actions

None

None
