K000141025: Block or Allow HTTP Methods on a specific URL

Published
2024-09-11

Source

Description

An Allowed URL can be configured to either permit or restrict specific HTTP methods.

For example, you may want to block GET requests to a particular URL without affecting any other traffic.

Environment

  • ASM is provisioned
  • Security Policy is created and applied
  • Allowed URL is created and enforced

Cause

None

Recommended Action

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > URLs > Allowed URLs.
  3. Select the name of the desired URL.
  4. Next to Allowed URL Properties change the dropdown from Basic to Advanced.
  5. Select the Methods Enforcement tab which is in the row of tabs below the Allowed URL Properties section.
  6. Check the box next to Override policy allowed methods. In earlier versions this is called Override Security Policy Settings.
  7. Select the desired method under Global Security Policy Settings.
  8. Click the << button to move the method to the Overridden Security Policy Settings pane.
  9. Select Allow or Disallow from the State column.
  10. Click Update.

Additional Information

  • You must have an Allowed URL configured in order to perform this procedure. Refer to K29418033: Configure allowed or disallowed URL lists
