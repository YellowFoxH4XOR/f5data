K000151231: Unable to login after reboot

Type
Support Solution
Published
2025-05-08
Updated
2025-05-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151231

Description

Unable to log into device with remote credentials after rebooting.

Able to log in with Admin or Root accounts, but config objects appear to be missing.

Device is showing not in sync.

Running tmsh load sys config verify reports a problem loading an SSL profile due to being unable to read default.key


Environment

Rebooted system after following procedure to forceload mcpd.


Cause

SSL default cert/key pair corrupted.


Recommended Actions

Re-create default SSL certificate/key pair.

openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -keyout /config/ssl/ssl.key/default.key -out /config/ssl/ssl.crt/default.crt


Additional Information

None
