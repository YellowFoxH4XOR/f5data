Known Issue

Changing the order of the active access sessions list may produce a database error message.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system processes traffic for access sessions.
  • Using the Configuration utility, you view the current access sessions. In BIG-IP APM 13.0.0, navigate to Access > Overview > Active Sessions. In BIG-IP APM versions prior to 13.0.0, navigate to Access Policy > Manage Sessions.
  • You attempt to change the order of the active access sessions list using the Validation Timeout or Idle Timeout tabs.

Impact

Your changes fail to render and the Configuration utility displays an error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to sort the active access sessions list using the Validation Timeout or Idle Timeout  tabs, the Configuration utility displays an error message that appears similar to the following example:

    General database error retrieving information.

  • Subsequent attempts to access the Configuration utility web page display the same error message.

Workaround

To recover from this issue, you can log out of the Configuration utility, clear your browser cache, and log back in to the Configuration utility. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
