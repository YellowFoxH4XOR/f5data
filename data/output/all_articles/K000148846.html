Description

Due to security restrictions, using a wildcard (*) in the allowed URL list under the ASM security policy is not permitted. In such scenarios, you can utilize an LTM traffic policy to achieve the required functionality. An example scenario could involve whitelisting URLs in the format /special-URL/{id}, where {id} represents any integer. Creating explicit entries for each possible value of {id} is not practical.

Environment

  • BIG-IP ASM
  • Wildcard (*) in allowed URL list is not permitted due to security limitations. 

Cause

Not allowed to use wildcard (*) URLs in the security policy. 

Recommended Actions

  1. Create an LTM traffic policy with below characteristics.
    • Condition: HTTP URI path contains '/special-URL/' at request time.
    • Actions: Disable asm at request time.

Important: It is essential to adjust the values according to your specific requirements and thoroughly test in a staging environment before implementing in production. The provided examples are for guidance only. If you need F5 to create a traffic policy for you, please contact F5 Professional Services.
