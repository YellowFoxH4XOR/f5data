K000134520: Unable to add BIG-IP device into the BIG-IQ management centre

Type
Support Solution
Published
2023-05-10
Updated
2023-08-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8, 14.X.X, 14.0.0, 14.0.1, 14.0.X, 14.1.0, 14.1.2, 14.1.3, 14.1.4, 14.1.5, 14.1.X, 15.0.0, 15.0.1, 15.0.X, 15.1.0, 15.1.1, 15.1.2, 15.1.3, 15.1.4, 15.1.5, 15.1.6, 15.1.7, 15.1.8, 15.1.X, 15.X.X
Source
https://my.f5.com/manage/s/article/K000134520

Description

You are not able to add BIG-IP to the BIG-IQ management center. The similar errors are displayed while you try to add LTM to the BIG-IQ:

Unauthorized 401

An error occurred while adding the BIG-IQ: Could not connect to host Please ensure there are no licensing, firewall, port lockdown or network connectivity issues.

Environment

  • BIG-IP
  • BIG-IQ CM

Cause

Bug ID 1146373: Basic authentication for REST admin account failing

Recommended Actions

Configuring the device to resolve to localhost may workaround this issue in some cases.  If it does not fix the problem contact F5 Support:

tmsh mod sys global-settings remote-host add { null { hostname null addr 127.0.0.1 } }

tmsh save sys config

None
