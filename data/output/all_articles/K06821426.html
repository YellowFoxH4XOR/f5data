Issue

Description

Request data can be viewed in the BIG-IP ASM event logs using the GUI (Configuration utility). When viewing event logs using the Configuration utility, some requests may be missing under the following conditions:

  • The BIG-IP ASM system is processing a large number of learning suggestions.
  • Due to high load, the BIG-IP ASM system frequently prunes binary request logs.
  • The bd and pabnagd processes are experiencing high CPU utilization.

Environment

  • BIG-IP system with the BIG-IP ASM module provisioned
  • One or more virtual servers with an associated application security policy
  • Missing requests in the event logs

Cause

When experiencing high utilization, the BIG-IP ASM system may not be able to log all requests to event logs.

Recommended Actions

You can view request logs by directly querying the MySQL databases when logged into the Advanced Shell (bash). The application event logs are stored in the REQUEST_LOG table (BIG-IP 11.6.x and later) and the PROXY_LOG table (BIG-IP 11.5.x and earlier) within the PRX database.

Viewing the number of requests that exist within MySQL database

BIG-IP 11.6.0 and later

Type the following command:

mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select COUNT(*) from PRX.REQUEST_LOG"

BIG-IP 11.4.0 - 11.5.x

Type the following command:

mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select COUNT(*) from PRX.PROXY_LOG"

Output appears similar to the following:

+----------+
| COUNT(*) |
+----------+
|   355687 |
+----------+

Viewing the support IDs for the request data in the database

BIG-IP 11.6.0 and later

Type the following command:

mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select support_id from PRX.REQUEST_LOG"

BIG-IP 11.4.0 - 11.5.x

mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select support_id from PRX.PROXY_LOG"

Viewing the request data for a specific support ID

BIG-IP 11.6.0 and later 

Enter the following command syntax:

mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select * from PRX.REQUEST_LOG where support_id = <support_ID>\G"

BIG-IP 11.4.0 - 11.5.x

Enter the following command syntax:

mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "select * from PRX.PROXY_LOG where support_id = <support_ID>\G"
