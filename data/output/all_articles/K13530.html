Known Issue

The standby BIG-IP system in a redundant pair may dump core when connection mirroring is enabled. This occurs when the standby system processes connection mirroring packets out of sequence.

Impact

TMM crashes and the standby unit is temporarily unavailable and fails to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system sends a SIGFPE signal to TMM, resulting in a stack trace and core file
  • The BIG-IP system generates an assertion failure panic string in the /var/log/tmm file that appears similar to the following example:

    panic: Request for segment from middle of queue
