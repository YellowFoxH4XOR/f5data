Description

If the BIG-IP DNS system is configured with a large number of zone files, or very large zone files, the zone files may fail to synchronize to other BIG-IP DNS peers.

The BIG-IP Configuration Utility of the BIG-IP DNS system may display a generic error: "The configuration has not yet loaded. If this message persists, it may indicate a configuration problem."

Log events similar to the following may be found in the /var/log/gtm log file:

Jan 01 12:33:28 bigiphostname err gtmd[6065]: 011a0030:3: SYNC Zones timed out from ip <peer IP>

Jan 01 12:33:29 bigiphostname err zrd[18432]: 01150a31:3: Sync Zones timeout, killing <pid>

Environment

BIND DNS zones

Cause

Several zone files failed to sync over.

Recommended Actions

Increasing the synchronization timeout should resolve this problem. Run the following command on both BIG-IP peers

 tmsh modify gtm global-settings general synchronize-zone-files-timeout 600
