K42063531: BIG-IP APM as SAML SP or IdP and Error Message ''SAML SSO: Error failed to base64 decode message:''

Type
Support Solution
Published
2020-04-03
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K42063531

Description

BIG-IP APM as SAML SP or IdP URL decodes POST binding SAML messages and then base64 decodes them. If the BIG-IP APM as SAML SP or IdP receives a SAML message that is not URL encoded then it will still URL decode the message and attempt to base64 decode which may lead to failure to process the SAML message and the following error message may be found in /var/log/apm

SAML SSO: Error failed to base64 decode message:

Environment

  • BIG-IP APM as SAML SP or IdP
  • POST binding SAML messages that are not URL encoded

Cause

This is expected behavior.

Recommended Actions

None.

Additional Information

User-agent needs to send POST binding SAML requests with URL encoded SAML messages

SAML messages can be found on the BIG-IP APM within apm logs and session variables. A good base64 SAML message contains a large block of ascii characters. If this SAML message contains a space then this indicates the SAML request message was not URL encoded.
