K000152757: Viewing BIG-IP ASM Bot logs from MySQL database

Type
Support Solution
Published
2025-09-29
Updated
2025-09-29
Source

Description

The bot event log data can be viewed in the BIG-IP ASM event logs using the GUI (Configuration utility). However, when viewing event logs using the Configuration utility, some requests may be missing under the following condition:

 

Bot-defense Logging Limits:
For bot defense, logs are only limited by the number of rows in the database. This is controlled by the following parameter (F5 does not recommend changing the defaults).

 

PRX.BOT_DEFENSE_EVENT_LOG:
   row_limit: 100000 

 

Environment

  • BIG-IP system with the BIG-IP ASM module provisioned
  • One or more virtual servers with an associated bot security policy
  • Missing requests in the event logs
     

Cause

When the rate of logging is very high, the BIG-IP ASM system may not be able to log all requests to event logs. This can result in some bot event logs not appearing in the GUI.
 

Recommended Actions

You can view the bot log by directly querying the MySQL databases when logged into the Advanced Shell (bash). The bot event logs are stored in the BOT_DEFENSE_EVENT_LOG table.

 

Command:
#mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "SELECT * FROM PRX.BOT_DEFENSE_EVENT_LOG where support_id = '<support_id>'\G"

 

Example:
mysql -uasm -p`perl -MF5::Cfg -e 'print F5::Cfg::get_mysql_password()'` -e "SELECT * FROM PRX.BOT_DEFENSE_EVENT_LOG where support_id = '4607863381569830969'\G"
