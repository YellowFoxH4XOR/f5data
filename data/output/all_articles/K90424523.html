K90424523: APM discovery is failing. Rootnode refers to nonexistent object

Type
Support Solution
Published
2021-03-01
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K90424523

Description

During the APM modul discovery on BIG-IQ CM you are observing an error similar to below: 

Coordinator failed during working-config update, roll-back working-config started; reason: Worker http://localhost:8100/cm/adc-core/working-config/root-node failed validation with status 500: java.lang.IllegalStateException: /Common/RootNode refers to nonexistent object (https://localhost/mgmt/cm/adc-core/working-config/sys/file/ssl-cert/44b96d5d-d61c-3af1-920d-dcfcef22ba75)

Environment

  • BIG-IQ CM 7.1
  • APM Device discovery

Cause

One of the workers has incorrect data and it's pointing to a non-existent object. Config validation is failing.

Recommended Actions

Impact of workaround: Performing the following procedure should not have a negative impact on your system. During the restart, BIG-IQ GUI will be unavailable for a few minutes.  

  1. Restart restjavad process on BIG-IQ CM and failing BIG-IP:
    bigstart restart restjavad
  2. Rediscover and reimport LTM module
  3. Rediscover and reimport APM module
