Known Issue

When you modify an existing Gateway Failsafe pool, the Device setting shows "Device" instead of the currently selected device.

This issue occurs when all of the following conditions are met:

  • You attempt to modify a Gateway Failsafe pool using the System > High Availability > Failsafe > Gateway page of the Configuration Utility.
  • You are using the Microsoft Internet Explorer browser to access the Configuration utility.

Impact

If the appropriate device is not re-selected, the system cannot save changes made to other settings.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility displays an error similar to the following example:

    Some fields below contain errors. Correct them before continuing.

Resolution

Workaround

To work around this issue, you can manually re-select the appropriate device before saving, or use an alternative browser such as Firefox or Chrome.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
