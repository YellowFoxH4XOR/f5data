Note: For more information, refer to K4423: Overview of UCS archives and K8465: Viewing and extracting the contents of an encrypted UCS archive file.

The encryption implementation used to create user configuration set (UCS) files is based on the GNU Privacy Guard (GnuPG). Information about GnuPG is available at the following location:

www.gnupg.org

The BIG-IP system uses a 128-bit AES cipher for UCS file encryption.

UCS files are encrypted using a symmetric cipher as the encryption key. The symmetric cipher allows the UCS file to be decrypted locally or remotely using a passphrase. When archive encryption is enabled, fields for the passphrase are exposed in the Configuration utility. The passphrase used when creating the UCS file is also required when decrypting or installing the UCS file.
