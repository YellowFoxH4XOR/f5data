K184: Known Issue: The Configuration utility does not create an ECV monitor that includes an Authorization header

Known Issue

This is the result of a known issue. You cannot use the Configuration utility to configure an HTTP ECV health monitor that includes an Authorization: Basic header. If you attempt to do so, the Configuration utility will ignore it and will not include any of the information that you specify in the GET request after the Authorization: Basic header.

F5 Networks Product Development tracked this issue as CR28333 and CR41763.

Workaround

To work around this issue, use the command line to create HTTP ECV health monitors that require an Authorization: Basic header.
