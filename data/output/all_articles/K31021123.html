Known Issue

Running a packet capture from the BIG-IP Configuration utility may fail for certain Virtual Local Area Network (VLAN) names.

This issue occurs when all of the following conditions are met:

  • You have configured VLAN names with 16 or more characters.
  • You are trying to run a packet capture (TCP dump) on the affected VLAN from the BIG-IP Configuration Utility > System > Support screen.

Impact

The packet capture operation will fail to capture network traffic for the affected VLANs.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The packet capture does not contain network traffic data for the affected VLANs.

Workaround

To work around this issue, you can run packet capture from the command line. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To run the packet capture, use the following command syntax: tcpdump -ni <VLAN_Name>
  3. For example, to perform a packet capture on VLAN16CHARACTERS, type the following command:

    tcpdump -ni VLAN16CHARACTERS
