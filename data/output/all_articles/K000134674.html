Description

You are encountering an error message "ERROR: IM package is too big to install and allowed max size is 20MB" when attempting to update Protocol Inspection.

/var/log/pi_hitless_upgrade has an error message similar to below.

ERROR: IM file [/shared/protocol_inspection_updates/pi_updates_16.1.0-20230605.1111.im] is too big to install 21MB, Max allowed decompressed size is 20MB

Environment

  • BIG-IP AFM
  • TMOS 16.x versions before 16.1.2.2
  • TMOS 15.x versions before 15.1.5.1
  • TMOS 14.x versions before 14.1.4.6
  • Installing or importing Protocol Inspection update file pi_updates_x.x.x-20230328.1944.im or newer

Cause

The error occurs due to ID 1274001. For more information, please refer to K000133596: Protocol Inspection updates cannot be installed or imported.

Recommended Actions

  1. Install the March 22nd IM version (pi_updates_x.x.x-20230322.0546.im), which includes a fix to handle larger IM files.
  2. After installing the March 22nd IM, attempt to update Protocol Inspection again using the desired IM file.

Additional Information

See Protocol Inspection release notes.
