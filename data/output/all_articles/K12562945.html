Known Issue

The gtmd process may enter a restart loop.

This issue occurs when all of the following conditions are met:

  • You configure a Device Management device with a description field that is longer than 65,432 characters for any of the following items:

    • Description
    • Location
    • Contact
    • Comment

Impact

The BIG-IP GTM system stops processing the request.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the status of the gtmd process the restart count continually increases.
  • The BIG-IP GTM system logs repeating messages to the /var/log/daemon.log file:
emerg logger: Re-starting gtmd
  • The BIG-IP GTM system is unable to process the request.
  • The BIG-IP GTM system appears offline to other BIG-IP GTM members of the configuration synchronization group.
  • Modifying the offending device description field to less than 65,432 characters allows the gtmd process to function normally.

Workaround

To work around this issue, you can limit the description fields to less than 65,432 characters.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
