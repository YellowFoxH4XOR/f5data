Description

When using the F5 REST API to automate the deployment of the mitigation.sh script from K000137353 will cause the HTTPD process to not restart due to a known issue relating to Bug ID775845 . 

  • Management UI is unavailable after restarting HTTPD with the REST API
  • Similar log message to "commandResult": "Stopping httpd: [  OK  ]\r\nStarting httpd: [FAILED]\r\n(98)Address already in use: AH00072: make_sock: could not bind to address 127.0.0.1:80\nno listening sockets available, shutting down\nAH00015: Unable to open logs\n"

Environment

  • BIG-IP devices affected by CVE-2023-46747
  • Ansible user with root/administrator permissions
  • Advanced Shell for non-root administrators
  • SSH Access to the BIG-IP
  • Ansible Client Machine (tested on Core 2.14.3)
  • SSH Pass installed on the Ansible client machine

Cause

The last few lines of the mitigation.sh script contains the command to restart the HTTPD service. When the HTTPD service is restarted during an active REST API transaction the HTTPD service is not able to completely restart requiring manual intervention. 
 

echo "Restarting httpd..."
bigstart restart httpd

 

Recommended Actions

Use an automation tool that has the ability to utilize SSH instead of the F5 REST API like Ansible.

A example of using Ansible to apply the mitigation script using SSH is below.

The mitigation.sh script can be downloaded from K000137353  under the Security Advisory Recommended Actions section. 

Sample inventory file 
Note: Ansible Vault or the --ask-pass flag can be used instead of adding the password to the inventory file
[all:vars]
ansible_connection=ssh
ansible_user=root
ansible_ssh_pass=password

[all]
1.2.3.4
 

Sample Ansible playbook

- name: K000137353 Script Mitigation Playbook
  hosts: all
  connection: local

  tasks:

    - name: Copy the mitigation script from local directory to BIG-IP
      ansible.builtin.copy:
        src: mitigation.sh
        dest: /var/tmp/mitigation.sh
        owner: root
        group: root
        mode: '0766'

    - name: Run the mitigation script
      shell: /var/tmp/mitigation.sh

    - name: Verify that the proxy_ajp.conf, proxy_ajp.conf.bak, proxy_ajp.conf.f5orig files are present
      shell: ls -1 /config/httpd/conf.d/proxy*

    - name: Verify that httpd restarted successfully (optional)
      shell: curl -sku admin:admin https://localhost/mgmt/tm/sys/service/httpd
