Known Issue

The Configuration utility may display an incorrect 'Next Active Device' status.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured as part of a high-availability pair, with a peer unit using the hardwired serial failover cable only.
  • The configurations of the high-availability devices are already synchronized.

When only the hardwired serial failover cable is used in a BIG-IP high availability (HA) configuration, and the high-availability pair is synchronized, the Configuration utility should display 'Not Watched' for the traffic group's 'Next Active Device' status.

Impact

There is no impact. This issue should not affect BIG-IP system operations.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility shows the traffic group's status as 'Initializing / Not Synced' in the Next Active Device column; however, the devices are synchronized and are not in the initialization state.
