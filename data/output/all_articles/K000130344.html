K000130344: AFM IP Intelligence enforcement affects other BIG-IP tenants on same VELOS blade

Type
Support Solution
Published
2022-12-23
Updated
2022-12-23
Applies to
  • F5OS
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000130344

Description

IP intelligence enforcement affects other tenants running on the same blade on VELOS systems, even if those tenants do not have AFM/IPI configured.

Environment

  • VELOS
  • AFM
  • IPI

Cause

Bug ID 1211853.

This problem only happens if the drops are done in hardware.

If drops are moved to software (e.g. by enabling "log category matches" in the IPI policy), the problem does not happen.

Recommended Actions

None

Additional Information

None
