Description:

You are experiencing a validation error during the synchronization process with a remote device. The specific error message is as follows:

 

Sync error on <devcie-name>: Load failed from /Common/group-name:3: External datagroup file (/partition-1/datagroup_external_object_name): Changing the datagroup file object is not allowed.

 

Environment:

BIG-IP 15.1.10.x

 

Cause:

The error is triggered by an attempt to change the datagroup file object (/partition-1/datagroup_ecternal_object_name), which is not allowed during the synchronization process.

 

Recommended Actions:

 

1. On the Standby device via GUI, navigate to Local Traffic > iRules > Datagroup List.

2. Delete the "group-name" datagroup.

3. Trigger a Config-Sync from the active device, ensuring to overwrite the config on the Standby.
