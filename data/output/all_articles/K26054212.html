Known Issue

The Network Access VPN driver installation may fail on Windows client machines.

This issue occurs when all of the following conditions are met:

  • The client machine does not have the VPN driver installed.
  • You attempt to establish a network access session with the BIG-IP APM system using a browser.

Impact

You are unable to successfully establish network access sessions with the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to establish a VPN session.
  • Users see a Network Access Device Not Found error message when connecting to network access.
