Environment

  • f5.ldap 1.0.0 template
  • Double quote in monitor / health check password field

Cause
The iApp does not handle the double quote in the password field properly

Recommended Actions

Remove any double quote '"' characters from password

Additional Information
Certain other special characters, such as a dollar sign '$', may also cause errors if included in the password. Bug ID 747952: iApp: f5.ldap fails when monitor pw contains '$'
