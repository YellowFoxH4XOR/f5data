Description

Users from groups different of the main group are not getting authenticated even though Fetch Nested Group is enabled

Environment

  •  BIG-IP APM
  •  AD Authentication 
  •  Fetch Nested Group enabled

Cause

APM is not searching recursively in all the groups because groups are in cache and they are different that the ones on the Active Directory

Recommended Actions

Clearing cache on the BIG-IP to get the Updated from Active Directory

  1.  Go to access >> authentication >> Active Directory >> Click on the server involved on this issue
  2.  Click on "clear cache" on Group Cache Lifetime row
