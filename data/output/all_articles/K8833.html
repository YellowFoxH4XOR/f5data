Known Issue

This is the result of a known issue. The TM.PreserveClientPort BigDB variable determines whether the BIG-IP system preserves the client's ephemeral port when connecting to the server. By default the TM.PreserveClientPort variable is set to enabled, and the BIG-IP LTM system attempts to preserve the client's source port. When TM.PreserveClientPort is disabled, the BIG-IP LTM system selects ephemeral ports based on an incrementing algorithm rather than preserving the original source port.

When the TM.PreserveClientPort BigDB variable is set to disable, the BIG-IP LTM overrides port selection for the SNAT iRule command, and selects ephemeral ports based on an incrementing algorithm.

F5 Product Development tracked this issue as CR95338, and it was fixed in BIG-IP versions 9.6.1 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.1-HF3 issued for BIG-IP version 9.3.1, for the BIG-IP 9.3.0 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
