Topic

You should consider using these procedures under any of the following conditions:

  • You have a Secure Sockets Layer (SSL) virtual server using a Client SSL profile and either of the following statements is true:
    • The virtual server is not configured with an APM access profile.
    • The virtual server is not configured to use an iRule that relies on the client certificate.
  • You have an SSL virtual server using a Server SSL profile and either of the following statements is true:
    • The virtual server is not configured with an APM access profile.
    • The virtual server is not configured to use an iRule that relies on the server certificate.

Description

The Retain Certificate option in the Client SSL and Server SSL profiles directs the Traffic Management Microkernel (TMM) to store the client/server certificate in memory for each SSL session. Under certain circumstances, particularly on the server-side context as every proxy SSL connection results in a stored certificate, a large amount of memory is consumed for unnecessary certificate storage. In deployments with many concurrent SSL connections, it is possible to exhaust memory resources and negatively impact system performance.

However, storing the client or server certificate in an SSL session is typically only required in BIG-IP APM deployments or when an iRule relies on certificate information.

If your virtual configuration does not use APM or an iRule that relies on the client or server certificate, F5 recommends disabling the Retain Certificate option in SSL profiles to reduce memory pressure.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You can access the Configuration utility or Traffic Management Shell (tmsh).

Procedures

Disabling the Retain Certificate option in a Client SSL profile

To disable the Retain Certificate option in a Client SSL profile using the Configuration utility or the tmsh utility, perform one of the following procedures:

Impact of procedures: The client certificate will not be stored in memory during an SSL session and will be unavailable for use in APM or iRules functions.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Select a Client SSL profile.
  4. From the Configuration menu, select Advanced.
  5. In the Client Authentication section, next to the Retain Certificate option, clear the Enabled check box.
  6. Click Update.

tmsh utility

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Disable the Retain Certificate option in a Client SSL profile using the following command syntax:

    modify /ltm profile client-ssl <profile_name> retain-certificate false

    For example, to disable the Retain Certificate option in a Client SSL profile named myclientssl, type the following command:

    modify /ltm profile client-ssl myclientssl retain-certificate false

    Note: To revert to the default value, use the modify /ltm profile client-ssl myclientssl retain-certificate default-value command.

  3. Save the configuration by typing the following command:

    save /sys config

Disabling the Retain Certificate option in a Server SSL profile

To disable the Retain Certificate option in a Server SSL profile using the Configuration utility or the tmsh utility, perform one of the following procedures:

Impact of procedures: The server certificate will not be stored in memory during an SSL session and will be unavailable for use in APM or iRules functions.

Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Server.
  3. Select a Server SSL profile.
  4. From the Configuration menu, select Advanced.
  5. In the Server Authentication section, next to the Retain Certificate option, clear the Enabled check box.
  6. Click Update.

tmsh utility

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Disable the Retain Certificate option in a Server SSL profile using the following command syntax:

    modify /ltm profile server-ssl <profile_name> retain-certificate false

    For example, to disable the Retain Certificate option in a Server SSL profile named myserverssl, type the following command:

    modify /ltm profile server-ssl myserverssl retain-certificate false

    Note: To revert to the default value, use the modify /ltm profile server-ssl myserverssl retain-certificate default-value command.

  3. Save the configuration by typing the following command:

    save /sys config
