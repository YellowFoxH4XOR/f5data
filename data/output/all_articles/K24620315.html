Description

From October 2021 onwards, only those platforms that trust ISRG Root X1 will validate Let’s Encrypt certificates. The ca-bundle.crt certificate bundle file in the BIG-IP SSL Certificate list includes the ISRG Root X1 certificate. Previously, the DST Root CA X3 which has now expired, was used by client devices and web browsers to verify the chain of trust for Let’s Encrypt certificates.

Environment

  • ca-bundle.crt is used in BIG-IP LTM and APM configurations
  • Let’s Encrypt certificates used in BIG-IP LTM and APM configurations
Cause

DST Root CA X3 certificate has expired. 

Recommended Actions

To verify that the ISRG Root X1 certificate is included in the ca-bundle.crt file, run the command either one of the following commands:

  • BIG-IP command line: tmsh list sys file ssl-cert ca-bundle.crt bundle-certificates | grep -i isrg
  • TMOS shell (tmsh): list sys file ssl-cert ca-bundle.crt bundle-certificates | grep -i isrg
The following examples lists the output you may observe for different BIG-IP versions:
