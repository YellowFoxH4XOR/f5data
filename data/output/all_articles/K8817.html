Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13674: Preventing a standby member of a sync-failover group from rebooting when a VLAN failsafe event is triggered

The Failover.VlanFailsafe.StandbyNoAction bigpipe database variable was introduced in BIG-IP 9.2.0. This bigpipe database variable allows an administrator to prevent a standby unit with Virtual Local Area Network (VLAN) failsafe enabled from constantly rebooting when network traffic is not detected on the enabled VLANs.

This behavior is common in redundant firewall and switch configurations that remain in standby or ready mode and do not allow traffic to pass until they become the active unit.

When the bigpipe database variable is enabled on the standby unit, the standby unit will not perform the selected high availability action for VLAN failsafe if the VLAN failsafe timeout expires.

Note: The default high availability action for VLAN failsafe is to reboot the BIG-IP system.

To enable the bigpipe dbatabase variable, type the following command from the command line:

bigpipe db Failover.VlanFailsafe.StandbyNoAction enable

To disable the bigpipe database variable, type the following command from the command line:

bigpipe db Failover.VlanFailsafe.StandbyNoAction disable

Note: This setting should be replicated on the active unit as well.

Note: When the Failover.VlanFailsafe.StandbyNoAction bigpipe database variable is enabled, the high availability table on the standby unit will display an inaccurate VLAN failsafe status.
