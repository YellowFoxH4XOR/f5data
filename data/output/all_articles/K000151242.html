QUESTIONANSWER
Could we leverage the same mobile SDK for both Bot Defense and Mobile Shield? Yes, F5 Mobile SDK which is injected during Shield integration can be used for Bot Defense and Shield.
Can Mobile App Shield protect Cordova applications?

Cordova apps leverage web technologies, which Mobile App Shield is mostly designed to protect native apps. If the app is 100% webview app, Shield provides only a limited value (i.e. it can be configured to close the app on rooted/jailbroken devices, or if debugger is detected). However, its JS obfuscation capabilities are limited, and the JS code can be extracted and repackaged.

However, if the app is mix of Webview and Native technologies, Shield will prevent reverse engineering of and tampering with the Native code, and if JS code is dependent on Native, it will prevent app repackaging.

Does Shield obfuscate iOS code?Yes, starting Mobile App Shield v1.3, the code obfuscation is part of Shield. Shield obfuscates Android Dex code, as well as, iOS and Android binary code.
If my Android phone has USB Debugging enabled, does Shielded app work on this phone? By default, Shield blocks apps from working on phones which have USB Debugging enabled, even if the USB port is not being used. 
Does Mobile App Shield support apps developed in .NET MAUI framework?Yes, Mobile App Shield supports MAUI. However, not the SDK Integrator part (customer would need to integrate F5 Mobile SDK manually, if they need it). Also, Binary Obfuscation feature is not supported.
