Description

You're configuring LDAP/Active Directory authentication in F5OS using the Web UI and want more information about the timeout values.

Environment

  • F5OS
  • LDAP/Active Directory authentication.

Cause

ID1712249

Recommended Actions

There are three timeout options available in the F5OS WebUI and CLI:

  • Connect Timeout: The number of seconds that the system waits before timing out when trying to reach the LDAP server.
  • Read Timeout: The number of seconds that the system waits to receive an LDAP response before aborting the read attempt.
  • Idle Timeout: The number of seconds that an LDAP connection can be inactive before the connection is closed.

Because of the issue in F5OS versions listed in this knowledge article, the Connect and Read timeout values are reversed. Updating the value of Read Timeout will set the number of seconds the system waits while trying to connect to the LDAP server while updating the value of Conenct Timeout will set the number of seconds the system waits to receive an LDAP response from the server.

This issue does not affect the CLI:

R2600-R84-S8(config)# system aaa authentication ldap ?
