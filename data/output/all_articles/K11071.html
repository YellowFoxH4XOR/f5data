Topic

The snap-recon.pl script is used to generate ARX CLI commands that reconstitute an ARX snapshot from the snapshot reports. This script has a flag to specify the target name space (-target-ns) and a flag to specify the target volume (-target-vol), but there is no flag to specify the target share. As a result, the generated CLI commands will fail if the share name listed in the snapshot report does not exist on the target volume.

Note: For detailed instructions on using the snap-recon.pl script, refer to the ARX CLI Maintenance Guide.

F5 Product Development is tracking a request for enhancement (RFE) as ARX ID 34553 to add a flag for the target share name.
