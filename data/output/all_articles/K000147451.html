What Happened?

You are upgrading your AWS CE site and you get stuck in "State Admin State: Upgrading" with the error 

Deployment ves-system/ebs-csi-controller has not matched the expected number of replicas for longer than an hour.

Environment

  • F5® Distributed Cloud
  • Create AWS Site

Resolution/Answer

In order to unstick the AWS site you have to follow the following steps:

  1. Configure Kubernetes: CloudProvider: disabled and restart vpm
    1. You can find the file in /etc/vpm/config.yaml and change the following line. You have to have root access(This may can't be done by the customer, we need the customer to grant the permission to SRE team to implement this.)
execcli files vim /etc/vpm/config.yaml
------
Kubernetes:
  CloudProvider: disabled

          2. Restart VPM

systemctl restart vpm

    3. When vpm finishes till Stage: ver ongoing, update csimigration file in vpm etcd

vpmetcdctl get '/_vpm/example_node/csimigration.yml' > csimigration.yml # example_node is node name, so this one needs to be changed per node

then

vi csimigration.yml

``
CSIControllerMigrated: true <-- change from `false`
CSIMigrated: true <-- change from `false`
LastChange: "2024-03-19T17:23:13.055536393Z"
SavedAt: "2024-03-19T17:23:13.055536793Z"
``

then

vpmetcdctl put '/_vpm/example_node/csimigration.yml' < csimigration.yml

    4. Restart vpm

systemctl restart vpm

 

Once done the Site Admin State should become Online and SW version to In progress.
After around 30 min, status of SW Version should be updated to Successful automatically.

Additional Information

Q.: about the option in /etc/vpm/config.yaml. How do you edit that file when you are not super user or veops with SSH public key?
A.: this one is only configurable with ssh with vesop
