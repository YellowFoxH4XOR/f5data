K15053316: Advanced Resource Assign isn't available in the VPE agent

Description

The assignment tab in the APM VPE agent doesn't include "Advanced Resource Assign".
When adding an agent to an APM VPE, the "Advanced Resource Assign" option is unavailable.

Environment

Attempt to add "Advanced Resource Assign" to the APM VPE.
  • Select + to add an agent
  • Navigate to the Assignment tab
  • "Advanced Resource Assign" is not an option

Cause

The access policy profile type isn't Full or SSL-VPN.

Recommended Actions

Create a new access policy and select Full or SSL-VPN as its profile type.

Additional Information

The essential difference between policy types, LTM+APM and Full, is specific to the availability of tunnel resources. After authentication, LTM+APM typically offers access to web applications (pool members), whereas, "Full" offers access to all VPE options (network access, portal access, dynamic resource assignment, etc) and includes concurrent user content.

In addition, profile type, SSL-VPN, also offers "advanced resource assign" as it is a tunneling resource.
