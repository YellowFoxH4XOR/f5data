K41481489: Error Message: [ERROR] [CORE] Error getting service list. etcdserver: xxxxxx

Description

You may find an error message like this in your Container Ingress Service pod:
<Date> <time> [CORE] Error getting service list. etcdserver: <xxxx>
In this error message, notice:

  • xxxx represents the etcd error message from the apiserver.
For example, 
2022/10/01 00:00:00 [ERROR] [CORE] Error getting service list. etcdserver: leader changed
2022/10/01 00:00:00 [ERROR] [CORE] Error getting service list. etcdserver: request timed out

This error message indicates your Kubernetes cluster is unstable, this might cause the Container Ingress Service to delete all resources that were pushed to the BIG-IP you managed.

Environment

  • F5 Container Ingress Service with version 2.x.

Cause

The Container Ingress Service can not get the required information from the ApiServer.

Recommended Actions

You should check your Kubernetes cluster health status and make sure your Kubernetes has a good condition while using the Container Ingress Service. For how to check your Kubernetes health status, please refer to Kubernetes Docs.
