Known Issue

When repeating a Coordinated Universal Time (UTC) value during a leap second, the International Atomic Time (TAI) timescale should not stop. However, the kernel increments the TAI offset one second too late.

This issue occurs when the following conditions is met:

  • There is a network time protocol (NTP) leap second event. For example, an event occurs on December 31, 2016, at 23:59:60 UTC.

Impact

Impact to applications are unknown. The system will stay stable and a timer may fire off later than expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • There is an unknown impact to applications that rely on strict adherence to UTC time.
