K764: Wide IPs created in the Link Controller Configuration utility are not included in NameSurfer

Known Issue

This is the result of a known issue. If you create a wide IP from the BIG-IP Link Controller Configuration utility on systems that are licensed for both BIG-IP Link Controller and NameSurfer functionality (such as BIG-IP/3-DNS combination systems), they are not added in NameSurfer.

F5 Networks Product Development tracked this issue as CR36729 and CR41882.

Workaround

To work around this issue, create the wide IP using the 3-DNS Configuration utility rather than the BIG-IP Link Controller Configuration utility.
