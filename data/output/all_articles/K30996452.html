Description

You want to check if the SUDO command is enabled on the BIG-IP.

Environment

  • BIG-IP
  • SUDO command

Cause

None.

Recommended Actions

  • Run the command below:
    # rpm -qa | grep sudo

    Note: 

    If it will just go to the next line without displaying anything it means there is no SUDO installed

    [root@HARDWARE-BIG-IP:Active:Standalone] config # rpm -qa | grep sudo
    [root@HARDWARE-BIG-IP:Active:Standalone] config #


    And if running the command on VE output will be like the below:

    [root@BIG-IP-VE:Active:Standalone] ucs # rpm -qa | grep sudo
    sudo-1.8.6p7-23.el7_3.0.0.11.x86_64
    [root@BIG-IP-VE:Active:Standalone] ucs #

Additional Information

None.
