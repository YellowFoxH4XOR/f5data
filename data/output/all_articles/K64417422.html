K64417422: ASM Live Update files not synced in cluster

Type
Support Solution
Published
2020-11-05
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.8, 15.1.1, 15.1.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K64417422

Description

ASM Live Update files are not synced or displayed on other members of a device group, even after installation.

This is determined by reviewing the Live Update page at System >> Software Management : Live Update.

Furthermore, there are no recent entries found in /var/log/nsyncd.log, but the nsyncd daemon is running.

Environment

  • Live Update

Cause

Undetermined at time of publication. Suspect a problematic state with the nsyncd process.

Recommended Actions

On all units involved, delete the nsyncd manifest file, restart nsyncd and perform a full sync:

  1. tmsh stop sys service nsyncd
  2. rm -f /var/nsyncd/manifest
  3. tmsh start sys service nsyncd
  4. tmsh run cm config-sync to-group <device-group> force-full-load-push

Note: If you require an exact root cause analysis, please open a service request with F5 Support, referencing this article.

Additional Information

The nsyncd process is responsible for synchronizing Live Update files in a device group.
