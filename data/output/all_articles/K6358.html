Topic

When a user's client system fails one or more pre-logon sequence checks, FirePass displays a message that appears similar to the following example on the Logon Denied page:

Logon denied
Your device does not comply to current client security policies.

The reasons for failing the checks may not be apparent. If an administrator needs to determine why a client system is failing, FirePass can be configured to provide a link on the Logon Denied page, which will display the client information that has been collected during the pre-logon sequence.

Configuring FirePass to display client information

You can configure FirePass to display client information on the Logon Denied page when a client system fails one ore more pre-logon checks. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Endpoint Security: Pre-Logon Sequence page.
  3. Next to the name of the active pre-logon sequence, click the backup & edit link.

    The Pre-Logon Sequence Editor opens.

  4. Mouse over the line next to Sequence Start.

    A plus sign ( + ) character appears on the line.

  5. Click the plus sign character.

    The Change Sequence panel appears.

  6. Select the Write to Logon log option button.
  7. Click the Apply Changes button.

    The Edit Action panel appears.

  8. Click the logger link.

    The Endpoint Inspector Details panel appears.

  9. Enter show_client_data in the Expression field.
  10. Click the Update button.
  11. Click the Back to console link in the top right corner.

Important: The show client_info link only appears on the Logon Denied page. If a client system passes all pre-logon checks, the user is directed to the Logon Allowed page. If you want to view the client information for a client system that passes all pre-logon checks, you can temporarily change the end page in the pre-logon sequence from Logon Allowed page to Logon Denied page. Once you have viewed the client data, change the end page back to the Logon Allowed page. Changing the end page to the Logon Denied page will prevent other users from logging on to the FirePass controller.

When the Logon Denied page appears, it will display a show client_info link at the bottom of the page. Clicking on this link opens a new browser window that displays a set of nested arrays containing all the information collected by FirePass during the pre-logon sequence. The terminal arrays consist of values which are keyword-indexed in the array.

This sample dataset contains a top-level array called session, which contains the following arrays:

  • av
  • fw
  • tmp
  • datetime
  • os
  • browser
  • ui_mode
  • ssl
  • network
  • detected_av

If you examine the av array, you will notice that it contains two arrays:

  • list
  • McAfeeAV

The list array contains one array for every instance of antivirus software found. In this example, one antivirus software package was found, and the details of this antivirus software are displayed in the keyword-indexed entries of array 0 (zero-indexed array).

For example, the name of the antivirus software is McAfeeAV and the engine_version is 4400. The information is duplicated in an array named McAfeeAV.

The information from this page may be used by an administrator to troubleshoot pre-logon sequence issues, or it may be submitted to F5 as part of a support case.
