Known Issue

BIG-IP 10.2.1 hotfix 3 may cause the next installation of BIG-IP to continuously restart the tomcat service.

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP 10.2.1 build 511.0 (hotfix 3).
  • You attempt to install or upgrade another software slot with BIG-IP 10.2.1 Final Edition or BIG-IP 10.2.1 hotfix with a build number that is lower than hotfix 3.

BIG-IP 10.2.1 hotfix 3 modifies the tomcat shell access setting to be incompatible with other 10.2.1 builds prior to 511.0. As a result, if you attempt to install or upgrade another software slot with version 10.2.1 and builds that are prior to 511.0, the system will experience continuous restarts of tomcat service.

Impact

You cannot access the BIG-IP Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you reboot into the newly upgraded or installed software slot, you may notice the tomcat service restart continuously. In addition, you may see an error message that appears similar to the following example:

    emerg logger: Re-starting tomcat

Workaround

To work around this issue, you can modify the tomcat service file. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To stop the tomcat service, type the following command:

    bigstart stop tomcat
  3. To save a backup copy of the /service/tomcat/run file, type the following command:

    cp -a /service/tomcat/run /<Backup_File_Path>/<Backup_File_Name>

    For example:

    cp -a /service/tomcat/run /tmp/SOL14026_service_tomcat_run
  4. Use a text editor to open the /service/tomcat/run file.
  5. Locate the following line:

    exec su - $TOMCAT_USER -c "export JAVA_OPTS='-Dpython.cachedir=/var/tmp -Djava.library.path=/usr/lib -Xmx${xmx_mb}m ${addl_permgen}'; exec $TOMCAT_SCRIPT run >> ${logfile} 2>&1;"

    Modify the line by replacing su - with su -s /bin/bash. For example:

    exec su -s /bin/bash $TOMCAT_USER -c "export JAVA_OPTS='-Dpython.cachedir=/var/tmp -Djava.library.path=/usr/lib -Xmx${xmx_mb}m ${addl_permgen}'; exec $TOMCAT_SCRIPT run >> ${logfile} 2>&1;"

    Note: This line should not have a line break when modifying with a text editor.
  6. Save the changes and exit the text editor.
  7. To start the tomcat service, type the following command:

    bigstart start tomcat
  8. To verify tomcat service is working correctly, access the BIG-IP Configuration utility.
