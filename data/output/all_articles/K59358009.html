Description

Pool member returns a response similar to the following when connecting through the BIG-IP:

10.10.10.65 → 10.10.10.100 93 6446 55575 MySQL IN s1/tmm1 : Server Greeting Error 1129

MySQL Protocol
    Packet Length: 49
    Packet Number: 0
    Error Code: 1129
    Error message: Too many connection errors from 10.10.10.100

Environment

  • Load balancing MySQL

Cause

This response indicates that all available connections are in use on the MySQL server, as determined by the MySQL max_connections system variable.

Recommended Actions

If the MySQL server has reached the max_connections limit, consider increasing the value of this variable to support more connections: MySQL 5.5 Reference Manual / Too many connections

Additional Information

To verify if a packet capture contains MySQL error messages, a tshark command similar to the following example may be used:

tshark -r <pcap file> -Y "mysql.error.message" -VP -O mysql

Note: if a non-standard port is used, decode this as MySQL by appending -d tcp.port==xxxx,mysql to the tshark command, where xxxx is the port used.

Alternatively, use the following display filter in Wireshark:

mysql.error.message

Decode non-standard ports as MySQL in Wireshark by right clicking on a frame and selecting Decode As... from the menu.
