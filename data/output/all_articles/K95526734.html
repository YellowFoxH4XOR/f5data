Description

The BIG-IP system may report below snmpd process error log in /var/log/daemon.log:

err snmpd[<PID>]: unsupported address type

The BIG-IP system may also record the below error log in /var/log/snmpd.log:

unsupported address type

Environment

  • BIG-IP system version 11
  • SNMP query
  • MIB IP-MIB::ipNetToPhysicalPhysAddres

Cause

Version 11 does not support implementing custom ipNetToPhysicalTable. It is only implemented on version 12.1.0 and later, and it cannot be back ported to version 11.

Recommended Actions

This is a cosmetic issue without traffic impact.  No action is needed, and the error log could be safely ignored.
