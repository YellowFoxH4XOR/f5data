K000092332: Installation of Nginx Controller fails on a VirtualBox VM

Type
Support Solution
Published
2022-08-16
Updated
2022-08-16
Source
https://my.f5.com/manage/s/article/K000092332

Description

Installing NGINX Controller on a VirtualBox VM fails with install error "Job k8s-ctrl-init failed to complete" or other reason

 Environment

VirtualBox VM

NGINX Controller

 Cause

F5 has not tested nor verified installing NGINX Controller on a VirtualBox VM

 Recommended Actions

Install and run NGINX Controller on a virtual machine hosted on an enterprise level virtualization platform such as VMWAre, AWS, Azure, GWS, etc.

 Additional Information

None
