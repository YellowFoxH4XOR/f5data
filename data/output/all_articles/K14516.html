Known Issue

The BIG-IP system may not generate link state log messages for interface transitions.

This issue occurs when all of the following conditions are met:

  • A status change (Up/Down/Disabled) occurs for one or more of the interfaces.
  • The BIG-IP platform is one of the following:

    • BIG-IP 2000 series (2000s, 2200s)
    • BIG-IP 4000 series (4000s, 4200v)

The pfmand process does not send the required Up/Down/Disabled interface transition information to syslog. The system should log messages that appear similar to the following examples, to indicate a link state transition:

info pfmand[1234]: 01660009:6: Link: 1.1 is UP
info pfmand[1234]: 01660009:6: Link: 1.1 is DOWN
info pfmand[1234]: 01660009:6: Link: 1.1 is DISABLED

Impact

A link state transition may go unnoticed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system fails to log a message when a status change (Up/Down/Disabled) occurs for one or more of the interfaces.
