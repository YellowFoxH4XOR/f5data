Description

DNS lookups with search domains failing for BIG-IP system.

  • Non-FQDN lookups fail
    • nslookup lookup may return SERVFAIL
    • Search domain name not appended to lookup
  • FQDN Lookup Succeed

Environment

  • Workaround implemented from K39744305 Attempting to modify the DNS options ndots:0 value results in duplicate entries in the /etc/resolv.conf file
  • bigip_base.conf may contain:
         include "options ndots:1"

  • /defaults/config/templates/dns.tmpl maybe modified to use options ndots:1 instead of default value of options ndots:0

Cause

Duplicate option ndots entries in /etc/resolv.conf
Example:
#
# THIS IS AN AUTO-GENERATED FILE -- DO NOT EDIT!!!
#
# Use the bigpipe shell utility to make changes to the system configuration.
# For more information, see bigpipe dns help.
#
options ndots:0
options ndots:1

Recommended Actions

  1.   Remove workarounds from K39744305 Attempting to modify the DNS options ndots:0 value results in duplicate entries in the /etc/resolv.conf file
    1. tmsh modify sys dns include none Note: you will need to re-add any additional include statements after issuing none
    2. edit /defaults/config/templates/dns.tmpl back to default values ( options ndots:0 )
  2.   Configure required ndots via tmsh
    1. tmsh modify sys dns number-of-dots 1
    2. tmsh save sys config

Additional Information

Release Notes : BIG-IP 12.1.0 New and Installation

  • ID 227069 - There is now a number-of-dots field for the dns commands to allow changes to ndots in /etc/resolv.conf, so DNS search domain list are honored as expected.
