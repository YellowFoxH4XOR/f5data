Description

SSH Proxy is not available under Security >> Protocol Security >> Security Profiles.
 

Environment

  • SSH Proxy
  • GUI

Cause

AFM is not provisioned

Recommended Actions

The SSH Proxy profile requires AFM to be licensed and provisioned.

Provision AFM via the GUI or tmsh.

GUI: System >> Resource Provisioning

tmsh: tmsh modify sys provision afm level nominal

Note: This is traffic disrupting.

Note: Ensure your system has sufficient resources to provision an additional module.
