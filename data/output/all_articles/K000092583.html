K000092583: Audit logs missing host value - host=(unknown) failed to login

Type
Support Solution
Published
2022-11-09
Updated
2022-11-09
Source
https://my.f5.com/manage/s/article/K000092583

Description

Audit logs not providing host value for login attempts:

Oct 25 22:48:09 ltm1.example info rest(pam_audit)[21584]: 01070417:6: AUDIT - user admin - RAW: rest(pam_audit): User=admin tty=(unknown) host=(unknown) failed to login after 1 attempts (start="Tue Oct 25 22:48:07 2022" end="Tue Oct 25 22:48:09 2022").

Note host=(unknown).

Environment

  • Login attempts
  • Audit logs

Cause

Login attempts are made via REST, and missing hostname/IP is due to bug ID862693 .

Recommended Actions

Upgrade to a version where ID862693 is fixed.

Example logs from a fixed version:

Nov 1 02:18:26 ltm2.example info httpd(pam_audit)[29889]: 01070417:6: AUDIT - user admin - RAW: httpd(pam_audit): User=admin tty=(unknown) host=10.10.10.5 failed to login after 1 attempts (start="Tue Nov 1 02:18:24 2022" end="Tue Nov 1 02:18:26 2022").
