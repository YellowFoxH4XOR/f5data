K51420194: BIG-IQ DO licensing fails to remove from old SKU

Type
Support Solution
Published
2022-07-14
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K51420194

Description

After using DO via BIG-IP to change the license on BIG-IP there are duplicate entries for the BIG-IP under License Management -> Assignments.
The BIG-IP Device name is associated with the old and new license.

Environment

  • BIG-IQ Utility License
  • License change

Cause

The machineId on BIG-IP had changed since it was last licensed.
 

Recommended Actions

The issue is cosmetic, however the duplicate entries may cause confusion.  Follow these steps to correct the issue:
  1. Revoke both duplicate device entries.
    Important: This will remove the existing license from BIG-IP and is traffic impacting.
    Devices tab -> License Management -> Assignments
    Select the duplicate device entries
    Click Revoke
  2. Re-allocate new license to Device
    Devices tab -> License Management -> Licenses
    Select License Name -> Offering
    Click License Devices

     

Additional Information

The machineId on BIG-IP can be found in /config/f5-rest-device-id

List all license assignments matching <BIG-IP IPaddress> from BIG-IQ. Replace with actual IP address of BIG-IP:
restcurl /cm/device/licensing/assignments | jq -r '.items[] | select(.deviceAddress=="<BIG-IP IPaddress>")'

The entry with the incorrect machineId is now redundant and should be removed from BIG-IQ (revoked).
Important: This will remove the existing license from BIG-IP and is traffic impacting.
