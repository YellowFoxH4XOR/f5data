Known Issue

Enabling or disabling the BIG-IP ASM system using an iRule produces an error.

This issue occurs when the following condition is met:

  • You enable or disable BIG-IP ASM using an iRule similar to the following example:

    when HTTP_REQUEST {
               ASM::disable
               if { ([IP::local_addr] equals "1.1.1.1") } {

                         ASM::enable /Common/http_asm_policy
                         log local0. "1 access"

               }
               elseif { ([IP::local_addr] equals "1.1.1.2") } {

                         ASM::enable /Common/http_asm_policy_2
                         log local0. "2 access"

               }
    }

Impact

The iRule fails to run successfully and BIG-IP ASM is not enabled or disabled as requested.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system logs errors in the /var/log/ltm file that appear similar to the following example: 
    err tmm3[26234]: 01220001:3: TCL error: /Common/irule_switch <HTTP_REQUEST> - while executing "ASM::disable".

    err tmm2[27595]: 01220001:3: TCL error: /Common/irule_switch <HTTP_REQUEST> -      while executing "ASM::enable /Common/http_asm_policy_2"
err tmm2[27595]: 01220001:3: TCL error: /Common/irule_switch <HTTP_REQUEST> -      while executing "ASM::enable /Common/http_asm_policy"
