K000153050: Database error while accessing GUI components due to diskspace issue

Support Solution
Published
2025-09-15

Applies to

  • BIG-IP ASM: 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000153050

Description

  • Getting a below DB error while accessing certain functions in the GUI like event logs, license etc :

    There seems to have been a slight problem with the BIG-IP@ Application Security Manager database.

    Please try again by pressing the refresh button in your browser.
    We apologize for any inconvenience.

  • Logging into the CLI shows the prompt as inoperative.

Environment

  • BIG-IP ASM

Cause

 Root directory(/) was 100% occupied on the disk. 

Recommended Actions

Impact of workaround: Stopping or restarting core services will interrupt the system's operations, so it should be done with caution

Free up disk space by removing any unnecessary files. Additionally, avoid storing any files in the Root (/) directory than the default ones. 

Perform a restart on the system after freeing up the space, so that any process that might have got interrupted due to lack of diskspace would be re-initiated to run.

#bigstart restart

You should be able to see the GUI options working as expected.

You can verify if the services are running from the CLI:

#tmsh show sys service

Additional Information

Make sure the diskspace utilization is within limits before you perform the restart. 

The services may not be able to restart, and the device might get marked offline without enough diskspace under the root(/) folder
