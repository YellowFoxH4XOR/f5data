Known Issue

Auto installation of Network Access and Endpoint Security agent plugins may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured with a Network Access (NA) resource or Endpoint Security (EPS) agent.
  • Users attempting to establish a session with the BIG-IP APM system are running the Mac OS X operating system.
  • The version of Java installed on the user's device is Java version 7 update 51.

Impact

Plugin installation does not complete.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When users attempt to establish the access profile session, the installation of required plugins stops, and the system displays the following message:

    "Installing browser plugin..."

  • When users attempt to launch a Java App Tunnel, the tunnel initialization stays in the queued state.
