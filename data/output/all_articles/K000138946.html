Topic

You should consider using these procedures under the following condition:

  • You want to install an optics-mgr-package onto a F5 VELOS or rSeries system.

Description

For your F5 VELOS or rSeries hardware product to support newer optical transceiver modules, you must be running the latest version of the optics manager package for that hardware product. Before you use the newly supported optical transceiver modules with your F5 VELOS or rSeries hardware products, you must update the system to the latest version of the optics manager package provided by F5. New optical transceiver modules that are released after an F5OS-C/A software release might be unrecognized or improperly tuned. When you run an optics manager package installation process, traffic on the system being updated is disrupted. During the installation process, you are prompted to confirm that you are aware of this action before the installation can proceed. When you install the optics manager package on a VELOS system, all partitions on the VELOS system will be affected. This is because the optics-mgr container runs on the chassis controllers and not the blade. Note that you do not need to restart blades or partitions after installation as the new package will be applied immediately to all partitions on the VELOS system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • Your VELOS and rSeries systems must be using an F5-branded optical transceiver module currently supported by the hardware product. For information about the F5-branded optical transceiver module supported by the hardware product, refer to the Transceiver Modules chapter of the F5 Platforms: Accessories guide. Alternatively, you can refer to the Readme file when you download the optics-mgr-package file from MyF5 Downloads page.

    Important: Using this package with a third-party transceiver module installed in your system is not supported and may invalidate your warranty. For more information, refer to K8153: F5 support of third-party hardware components.

  • Your VELOS and rSeries systems must be running F5OS-C 1.6.0 and later and F5OS-A 1.4.0 and later respectively.
    Note that beginning in F5OS-A 1.8.x, the optics-mgr package is installed by default. For more information, refer to K000162637: Unable to install optics-mgr package F5OS-A 1.8.x.
  • You have access to MyF5 Downloads page to download the optics-mgr-package file.
  • To import or upload the optics-mgr-package file to the VELOS or rSeries system and install it, you must have the admin user access to the F5OS-C/A webUI/CLI/API management interface.

    Note: For the VELOS system, the admin user is the chassis admin user, not the partition admin user.

  • To remove the optics-mgr-package from the VELOS system, you must have the chassis root user access to the F5OS-C CLI to uninstall and remove the optics-mgr-package from the system.

Procedures

Depending on the system, you should perform either of the following procedure:

  • Uploading and installing the optics-mgr-package on a VELOS system
  • Uploading and installing the optics-mgr-package on a rSeries system

Uploading and installing the optics-mgr-package on a VELOS system

  • Import or upload the optics-mgr-package to the VELOS system
  • Install the optics-mgr-package on the VELOS system
  • Remove the optics-mgr-package on the VELOS system

Import or upload the optics-mgr-package to the VELOS system

You can either import or upload the optics-mgr-package file to the VELOS system. 

Prior to importing or uploading, you must first download the optics-mgr-package file from MyF5 Downloads page to either your remote HTTPS server that supports PUT/POST requests with a valid CA signed SSL certificate (if you are importing to the VELOS system) or your local workstation (if you are uploading to the VELOS system). You can locate the optics-mgr-package files by selecting F5OS for Group under Select a product family, followed by Components for Product Line and then optics-mgr for Product Version under Tell us more about the product you want on the MyF5 Downloads page. Select the file that has the format optics-mgr-package-<version>.controller.img. For information about downloading software from MyF5 Downloads page, refer to K000090258: Download F5 products from MyF5. After you have downloaded the file to your local workstation, you should verify the MD5 checksum of the file you have downloaded. For information about verifying MD5 checksum on the downloaded file, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file. Proceed to either the Importing the file or Uploading the file procedure after you have completed the download of the optics-mgr-package file(s) you need.

Impact of procedure: Performing the following procedures should not have a negative impact on your system.

  • Importing the file

    To import the downloaded optics-mgr-package file from your remote HTTPS server to the images/staging/ directory on the VELOS system, you can use either the webUI or the CLI. Perform either of the following procedures:

    • Using the webUI
    • Using the CLI

    Using the webUI

    1. Log in to the webUI of the VELOS chassis as the chassis admin user.
    2. Navigate to SYSTEM SETTINGS > File Utilities.
    3. Under the File Transfer Operations section, select images/staging for the Base Directory setting.
    4. Select Import; the webUI displays the File Import popup.
    5. Enter the URL for the image file hosted on your remote HTTPS server in the URL setting. If required, enter the username and password of an account on the remote HTTPS server in the Username and Password settings respectively. Select Ignore Certificate Warnings to skip certificate check as needed. The file is then imported to the VELOS chassis; you can observe the status in the File Transfer Status section. When the file is imported successfully to the VELOS chassis, you should be able to observe the imported file listed in the images/staging directory.

    Using the CLI

    1. SSH to the floating management IP address of the VELOS chassis as the chassis admin user.
    2. Import the file to the images/staging/ directory on the VELOS chassis by entering the following command syntax:

      file import remote-url <URL> local-file images/staging/ insecure username <admin username> password

      For example,

      file import remote-url https://example.myfileserver.com/files/optics-mgr-package-3.11.33.controller.img local-file images/staging/ insecure username admin password

      Note: The command should prompt you for the admin user's password before initiating the file import.

    3. Monitor the status of the import by entering the following command:

      file transfer-status

    4. When the file import is completed, you can list the file on the VELOS chassis by entering the following command syntax:

      file list path images/staging/<uploaded filename>

      For example,

      file list path images/staging/optics-mgr-package-3.11.33.controller.img

      The command returns an output similar to the following example:

      entries {
          name optics-mgr-package-3.11.33.controller.img
          date Tue Apr  2 02:25:04 UTC 2024
          size 733KB
      }

  • Uploading the file

    To upload the optics-mgr-package file from your local workstation to the images/staging/ directory on the VELOS chassis, you can use either the webUI or the REST API. Perform either of the following procedures:

    • Using the webUI
    • Using the REST API

    Using the webUI

    1. Log in to the webUI of the VELOS chassis as the chassis admin user.
    2. Navigate to SYSTEM SETTINGS > File Utilities.
    3. Under the File Transfer Operations section, select images/staging for the Base Directory setting.
    4. Select Upload.
    5. Locate the downloaded optics-mgr-package file on your local workstation and select Open. The file is then uploaded to the VELOS chassis; you can observe the status in the File Transfer Status section. When the file is uploaded successfully to the VELOS chassis, you should be able to observe the uploaded file listed in the images/staging directory.

    Using the REST API

    To upload the optics-mgr-package file to the images/staging/ directory on the VELOS chassis using the REST API, perform the procedure described in K000139146: Upload a file to the VELOS or rSeries system using REST API.

Install the optics-mgr-package on the VELOS system

To install the optics-mgr-package on the VELOS system, perform the following procedure:

Impact of procedure: During the installation process, traffic on the VELOS system will be disrupted. F5 recommends performing this procedure during an appropriate maintenance window.

  1. Login to the CLI of the floating management IP address of the VELOS chassis as the chassis admin user.
  2. Verify the optics-mgr-package file has been imported or uploaded successfully to the VELOS system by entering the following command:

    show system packages

    You should observe an output similar to the following example:

                                PACKAGE    INSTALL                                         IN     
    PACKAGE NAME        NUMBER  INSTALLED  STATUS   VERSION  STATUS  DATE        SIZE      USE
    ----------------------------------------------------------------------------------------------
    optics-mgr-package  1       3.11.30    success  3.11.30  ready   2023-10-20  732.50KB  true
                                                    3.11.33  ready   2023-12-28  732.50KB  false
                        2       3.11.30    success  3.11.30  ready   2023-10-20  732.50KB  true
                                                    3.11.33  ready   2023-12-28  732.50KB  false

    The previous example indicates that the optics-mgr-package in used on the VELOS system is version 3.11.30 and the newly imported optics-mgr-package is version 3.11.33.

  3. To install the optics-mgr-package file on the VELOS system, you must first go into the configuration mode by entering the following command:

    config

    When you are in the configuration mode, enter the following command syntax to initiate the install of the optics-mgr-package:

    system packages package optics-mgr-package set-version version <version>

    Using the previous example, you would enter the following command to initiate the install of the optics-mgr-package version 3.11.33:

    system packages package optics-mgr-package set-version version 3.11.33

    The system would then prompt you the following:

    Changing Package version will trigger service restart. Proceed? [yes/no]:

    To proceed with the install, enter yes.

    When the installation is completed, you should observe an output similar to the following example:

    response optics-mgr-package :version has been set

  4. Exit the configuration mode by entering the following command:

    exit

  5. At this point, the optics-mgr container should have been restarted on the chassis controllers. You can verify the optics-mgr container is running using the new package by entering the following command:

    show system packages

    You should observe an output similar to the following example:

                                PACKAGE    INSTALL                                         IN     
    PACKAGE NAME        NUMBER  INSTALLED  STATUS   VERSION  STATUS  DATE        SIZE      USE    
    ----------------------------------------------------------------------------------------------
    optics-mgr-package  1       3.11.33    success  3.11.30  ready   2023-10-20  732.50KB  false  
                                                    3.11.33  ready   2023-12-28  732.50KB  true   
                        2       3.11.33    success  3.11.30  ready   2023-10-20  732.50KB  false  
                                                    3.11.33  ready   2023-12-28  732.50KB  true 

    The previous output shows that the VELOS system is now using optics-mgr-package version 3.11.33.

    Alternatively, you can verify the optics-mgr-package version in used by the VELOS partition by entering the following command as the partition admin:

    file show log/velos.log | include optics-mgr | include starting

    You should observe an output similar to the following example:

    2023-12-29T00:32:29.394600+00:00 controller-1(p1) optics-mgr[42]: priority="Notice" version=1.0 msgid=0x4801000000000001 msg="optics-mgr starting" version="3.11.33" date="Thu Nov 30 20:26:44 2023" partition="1".

Remove the optics-mgr-package on the VELOS system

To remove the optics-mgr-package that is in used on the VELOS system, perform the following procedure:

Impact of procedure: During the removal process, traffic on the VELOS system will be disrupted. F5 recommends performing this procedure during an appropriate maintenance window.

  1. SSH to the management IP address of the active VELOS system controller as the chassis root user.
  2. To remove the currently-in-use optics-mgr-package from the VELOS system, enter the following command once on each system controller:

    echo "switch controller_rpms optics-mgr-package none" | nc -U /var/sw-mgmt.unix

    The command should return an output of 0.

    After you have entered the command on the active system controller, you must now log in to the standby system controller to enter the same command. To log in to the standby system controller, enter the following command syntax:

    ssh controller-<ID>

    For example, if you were originally logged into controller-2, then you should now log in to controller-1:

    ssh controller-1

    Then enter the same command on the standby controller:

    echo "switch controller_rpms optics-mgr-package none" | nc -U /var/sw-mgmt.unix

    When you have entered the command on the standby system controller, enter exit to log out of the standby system controller.

  3. You must now log in to the CLI of the floating management IP address of the VELOS chassis as the chassis admin user. You can do so by entering the following command:

    su - admin

  4. To remove the optics-mgr-package file from the VELOS system completely, you must first go into the configuration mode by entering the following command:

    config

    When you are in the configuration mode, enter the following command syntax to initiate the complete removal of the optics-mgr-package file:

    system packages package optics-mgr-package remove version <version>

    Using the previous example, you would enter the following command to initiate the complete removal of the optics-mgr-package file version 3.11.33:

    system packages package optics-mgr-package remove version 3.11.33

    The command should return an output similar to the following example:

    response Successfully removed specified package optics-mgr-package: 3.11.33

  5. Exit the configuration mode by entering the following command:

    exit

  6. At this point, you can verify that the optics-mgr-package has been completely removed from the VELOS system by entering the following command:

    show system packages

Install the optics-mgr-package on the rSeries system

To install the optics-mgr-package on the rSeries system, perform the following procedure:

Impact of procedure: During the installation process, traffic on the rSeries system will be disrupted. F5 recommends performing this procedure during an appropriate maintenance window.

  1. Login to the CLI of the management IP address of the rSeries system as the admin user.
  2. Verify the optics-mgr-package file has been imported or uploaded successfully to the rSeries system by entering the following command:

    show system packages

    You should observe an output similar to the following example:

                        PACKAGE    INSTALL                                         IN     
    PACKAGE NAME        INSTALLED  STATUS   VERSION  STATUS  DATE        SIZE      USE    
    --------------------------------------------------------------------------------------
    optics-mgr-package  -          none     3.11.24  ready   2023-08-22  732.50KB  false  

    The previous example indicates that the optics-mgr-package in used on the rSeries system is the default version from the F5OS-A version and the newly imported optics-mgr-package is version 3.11.24.

  3. To install the optics-mgr-package file on the rSeries system, you must first go into the configuration mode by entering the following command:

    config

    When you are in the configuration mode, enter the following command syntax to initiate the install of the optics-mgr-package:

    system packages package optics-mgr-package set-version version <version>

    Using the previous example, you would enter the following command to initiate the install of the optics-mgr-package version 3.11.24:

    system packages package optics-mgr-package set-version version 3.11.24

    The system would then prompt you the following:

    Changing Package version will trigger system reboot and interrupt tenant operation. Proceed? [yes/no]:

    To proceed with the install, enter yes.

    When the installation is completed, you should observe an output similar to the following example:

    response optics-mgr-package :version has been set

  4. Exit the configuration mode by entering the following command:

  5. At this point, the optics-mgr container should have been restarted on the system. You can verify the optics-mgr container is running using the new package by entering the following command:

    show system packages

    You should observe an output similar to the following example:

                        PACKAGE    INSTALL                                         IN
    PACKAGE NAME        INSTALLED  STATUS   VERSION  STATUS  DATE        SIZE      USE
    -------------------------------------------------------------------------------------
    optics-mgr-package  3.11.24    success  3.11.24  ready   2023-08-22  732.50KB  true

    The previous output shows that the rSeries system is now using optics-mgr-package version 3.11.24.

    Alternatively, you can verify the optics-mgr-package version in used by the rSeries system by entering the following command:

    file show log/system/platform.log | include optics-mgr | include starting

Remove the optics-mgr-package on the rSeries system

  2. To remove the optics-mgr-package file from the rSeries system completely, you must first go into the configuration mode by entering the following command:
