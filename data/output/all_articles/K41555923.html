Description
When you run the full sync, you may see that the virtual server which doesn't have a default pool is flapping (becomes UNCHECKED then UP).
When you run the incremental sync, this flapping won't occur.

Environment

  • Virtual Server without a default pool
  • Run full config sync

Cause
It is by design.

Recommended Actions

If you would like to avoid this flapping, the solution is to assign a default pool.

Note: "UNCHECKED" status is not "DOWN", so it will not block the traffic.

Additional Information

Here are the sample config and log messages.

ltm virtual vs-1 {
    destination 192.0.2.100:http
    ip-protocol tcp
    mask 255.255.255.255
    pool none
    profiles {
        http { }
        tcp { }
    }
    rules {
        test-rule-1
    }
    source 0.0.0.0/0
    source-address-translation {
        type automap
    }
    translate-address enabled
    translate-port enabled
    vs-index 2
}

ltm rule test-rule-1 {
when HTTP_REQUEST {
    pool pool-1
}
}
