K000136154: No GUI or CLI access to the BIG-IP (Google Cloud Platform)

Type
Support Solution
Published
2023-09-11
Updated

Status
Legacy Content
Applies to

  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000136154

Description

  • No response from the management IP of a BIG-IP running in Google Cloud Platform.
  • Console access only.
  • Packet captures in the BIG-IP show the TCP requests are coming in.

Environment

  • BIG-IP
  • Virtual Machine running in Google Cloud Platform

Cause

The management IP is configured with a /32 subnet mask, there is no access to the default gateway, for example:
 

tmsh list sys management-ip
sys management-ip 10.155.226.1/32 {
    description configured-statically
}

 

Recommended Actions

Change the subnet mask to a value that allows the BIG-IP to access the default gateway configured for the management IP.

Remove the current configuration: 
tmsh delete /sys management-ip <address>/<netmask>
For example: 
tmsh delete /sys management-ip 10.155.226.1/32

Configure again the management-ip with a different subnet: 
tmsh create /sys management-ip <address>/<netmask>
For example, /16: 
tmsh create /sys management-ip 10.155.226.1/16

Confirm the new setting: 
tmsh list /sys management-ip
