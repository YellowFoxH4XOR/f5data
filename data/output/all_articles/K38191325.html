K38191325: Dynamic routes may drop from the routing table unexpectedly

Published

Applies to

Source

Description

When the BIG-IP is configured for dynamic routing. some traffic may not work as expected.

  • BIG-IP using dynamic routes for traffic
  • Routes learned through dynamic advertisements disappear from the routing table
  • No error message

Environment

Relevant environmental factors specific to the topic

  • During a route advertisement
  • Advanced Routing configured
  • Dynamic routing enabled

Cause

The ZebOS routing daemon is missing kernel routes and not advertising some virtual addresses.

Recommended Actions

Choose one of the following workarounds for this issue:

  1. Restart the tmrouted daemon by typing the following command:
    bigstart restart tmrouted

  2. Re-create the affected virtual address.
    You must first delete the associated virtual server(s). This should automatically delete the virtual address. You can check in the GUI by navigating to Local Traffic > Virtual Servers > Virtual Address List. Then re-create the virtual server(s) which will also automatically re-create the virtual address. Copy the settings from the virtual server in order re-create it. This work should be performed during a maintenance window.
