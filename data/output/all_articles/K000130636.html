K000130636: Retransmitted SYN/ACK delayed by 3 seconds

Type
Support Solution
Published
2023-01-17
Updated
2023-01-19
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000130636

Description

Do to network congestion, network issues, or other issues outside client device or BigIP control, SYN/ACK from BIGIP back to client devices could be dropped. If the BIG-IP receives a re-transmitted SYN packet from the client the BigIP will take 3 seconds before responding with another SYN/ACK to the client.

 

Environment

BIGIP

 

Cause

Functions as designed

Recommended Actions

Alter the syn-rto-base setting in tcp profile attached to the virtual server to something that works in customer environment. In TMUI this setting is called "Initial Retransmission Timeout Base Multiplier for SYN Retransmission" in tcp profile.
