Known Issue

This is the result of a known issue. The TM.MaxRejectRate db key regulates the number of TCP RSTs or ICMP unreachable packets that the BIG-IP system sends in response to incoming connections that cannot be matched with virtual server connections. The default value for the TM.MaxRejectRate db key is 250 TCP RSTs or ICMP unreachable packets per second.

Note: For more information, refer to K9259: Limiting the rate at which the BIG-IP system issues TCP RSTs or ICMP unreachable packets.

The limiting ICMP ping response error message does not honor the 1-second limit. For example, if the last ICMP message arrives many seconds after the first ICMP message, the BIG-IP system will still log the limiting ICMP ping response error message.

F5 Product Development is tracking this issue as ID 223784 (formerly CR131874).

Note: The TM.MaxRejectRate bigdb variable message counting is off by one. For more information, refer to K10707: The TM.MaxRejectRate bigdb variable message counting is off by one.
