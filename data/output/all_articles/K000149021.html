Description

Strongbox is a program designed for Partners or Value Added Resellers (VAR) to provide appliances to potential customers. Unit is defined as a "Strongbox" when a specific Sales "demo" license is applied and is visible in the license file. 

Environment

  • iSeries
  • Viprion series
  • Z100 VE platform

Cause

Partner needs a "low cost" reusable platform that can be customized for a specific "demo" scenario.

"Strongbox" unit is partner's property, but it can be reused and customized as many times as needed, in as many demo scenarios for as many customers.

"Strongboxes" cannot be sold to customer. An "F5 solution" full box or virtual unit shall be sold to end customer instead.

Recommended Actions

Verify the license type by running the following command on the BIG-IP:

tmsh show sys license

Look for the Strongbox line in the output. If present, the unit is operating under a Strongbox Sales demo license.
