Description

Error Message

Error 51086, Add-on Module Key is not a valid option for the Base Registration Key - Product <Base Registration Key> does not allow the Add-On module to be included: <Add-on Module Key and SKU>

In this error message, note the following:

  • <Base Registration Key> is the base registration key of the product you are attempting to add the new add-on key
  • <Add-on Module Key and SKU> is the add-on key you are attempting to add

For example:

Error 51086, Add-on Module Key is not a valid option for the Base Registration Key - Product BIG-VE-LAB-LIC-DEV does not allow the Add-On module to be included: A304747-8367043 (LIC-PKG-BIQ-ADD-DVC-VE-20)

Message Location

You may encounter this message in the following locations:

  • In the Configuration utility, if you attempt to activate the add-on key using the Configuration utility
  • In the command line or TMOS Shell (tmsh), if you attempt to activate the add-on key using the tmsh install sys license add-on-keys command

This message occurs when all of the following conditions are met:

  • You attempt to apply a new add-on key to an existing product base registration key (which may have been upgraded to a higher throughput)
  • The add-on key is not valid for the existing product base registration key.

Environment

License Activation

BIG-IP

BIG-IQ

 

Cause

The Add-on key is not compatible with the Base Registration Key

 

Answer/Recommended Actions

Contact your F5 sales representative to ensure the add-on key is valid for the product base registration key.  Alternatively, to investigate the cause of the mismatched key requirements, you can contact F5 Technical Support by referring to K2633: Instructions for submitting a support case to F5.
