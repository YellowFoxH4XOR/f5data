Description

You want to obfuscate the X-Forwarded-For header received on the HTTP request before it is sent to the back end pool member. Is it possible?

Environment

  • X-Forwarded-For header
  • HTTP

Cause

None

Recommended Actions

You may insert or strip the X-Forwarded-For header from the HTTP request. However, it is not possible to obfuscate it.

None
