Known Issue

This is the result of a known issue. If a user has multiple simultaneous connections to the same server with either Static or Dynamic Tunnels, the tunnel may drop connections to the server. This issue may occur when either the FirePass or the back-end server is slow to respond. The connection will appear to be dropped from the client side. If the entire session is not dropped, the customer may notice that different portions of the HTML code do not load.

F5 Product Development tracked this issue as CR128547 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.
