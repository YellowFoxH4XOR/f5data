K15385335: ONBOARDING CLUSTER fails ''No local config sync IP''

Type
Support Solution
Published
2021-07-14
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K15385335

Description
When using the BIG-IQ GUI to onboard a cluster of BIG-IPs the Class Config Sync is not automatically included or shown as a required field. This allows the onboarding to be submitted and will fail after about five minutes with an error like the following example:

/var/log/restnoded/restnoded.log
Tue, 13 Jul 2021 17:41:11 GMT - info: [f5-declarative-onboarding: restWorker.js] join cluster failed: tryUntil: max tries reached: No local config sync IP. 

 

Environment

  • BIG-IQ using Declarative Onboarding to onboard a cluster of BIG-IPs

Cause
The config sync IP is needed to configure a cluster of BIG-IPs. 

Recommended Actions

Enable the Config Sync Class when using the GUI to onboard a cluster of BIG-IPs

Additional Information
None
