K000157270: SPK fails to egress traffic after upgrade in OCP 4.12 cluster

Description

Traffic fails to pass through egress CR following an SPK upgrade or pod restart in OCP 4.12 cluster.

Environment

  • SPK
  • Dual-stack cluster
  • OCP 4.12

Cause

There are known issues in OCP 4.12 that can cause these symptoms:

  • https://issues.redhat.com/browse/OCPBUGS-11710
  • https://access.redhat.com/solutions/7037795

When OVN sends traffic to a stale destination MAC address (for example to an older address after an SPK restart), the packet is not picked up by SPK for egress forwarding.

Recommended Actions

This is an OCP issue that occurs prior to SPK receiving any traffic. The recommendation is to engage RedHat in these scenarios to dig into why OVN is sending egress traffic to the incorrect MAC address.
