Description

BIG-IQ GUI Connection and Read Timeout values do not update in Active Directory Auth Provider Configuration

  • During configuration of Active Directory Authentication in BIG-IQ
  • Update Connection and/or Read timeout values
  • When the "test' button is used the new values are not used.

Environment

Relevant environmental factors specific to the topic

  • BIG-IQ Configuration Utility, configuring authentication
  • In the GUI, System>>User Management>> Auth Providers>> New Auth Provider 
  • BIGIQ 7.0, 7.1, 8.0

Cause

This is a result of a known issue in the GUI of BIGIQ.

Recommended Actions

Use this workaround:

  1. Using the Rest API, the values can be modified.

    Identify the unique identifier for the Active Directory Provider:

    restcurl cm/system/authn/providers/ldap?\$select=name,id,providerType

    The output will look something like this:

    {
      "items": [
        {
          "id": "2b0fa5cd-c428-4555-acbf-307b56b1e649",
          "name": "my.ldapserver",
          "providerType": "LDAP"
        },
        {
          "id": "983615c9-d53d-444e-985f-20b845a98f9d",
          "name": "my.adserver",
          "providerType": "Active Directory"
        }
      ],
      "generation": 14,
      "kind": "cm:system:authn:providers:ldap:ldapprovidercollectionstate",
      "lastUpdateMicros": 1617129152260618,
      "selfLink": "https://localhost/mgmt/cm/system/authn/providers/ldap"
    }

    Using the ID for my.adserver (983615c9-d53d-444e-985f-20b845a98f9d), update the values to the desired value in milliseconds.  This example sets the connection timeout to 90 seconds and the read timeout to 120 seconds:
