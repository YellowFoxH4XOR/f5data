Issue

Prior to BIG-IP 10.1.0, you can enter a question mark (?) as a literal character in tmsh command arguments. Beginning in BIG-IP 10.1.0, you must precede the question mark with a backslash (\) escape character for the system to interpret the question mark character as a literal character in an argument. In BIG-IP 10.1.0 and later, if you enter a question mark character without a preceding backslash, the system enables the tmsh Context-Sensitive Help feature. At any time, you can type a question mark on the command line, and tmsh returns information to assist you in completing the command.

For example, in BIG-IP 10.0.0, to create an HTTP monitor that includes a query string in the Send value, you would type the following command:

create http my_monitor defaults-from http recv "UP" send "GET /path/?value=true\r\n" interval 5 timeout 16

In version 10.1.0 or later, to create the same monitor, you must escape the question mark character, as shown in the following example:

create http my_monitor defaults-from http recv "UP" send "GET /path/\?value=true\r\n" interval 5 timeout 16
