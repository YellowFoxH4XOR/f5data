Description

An administrative partition is a logical container that you create, containing a defined set of BIG-IP system objects. You can create administrative partitions to control other users’ access to BIG-IP objects.

Environment

  • All BIG-IP products


Cause

None


Recommended Actions

  • Creating an administrative partition via Configuration Utility
  • Creating an administrative partition using tmsh Utility
  • Delete the partition from Configuration Utility
  • Delete the partition from tmsh utility
Note: You must have administrative or user manager a user role assigned to use this procedure

Creating an administrative partition via Configuration Utility
  1. Navigate to System > Users > Partition List

  2. Click Create

  3. Enter a unique Partition Name

  4. Optional: Type a description of the partition.

  5. For the Device Group setting, choose an action:

    • [Default] Inherit device group from root folder
      Note: Choose this option if you want the folder corresponding to this partition to inherit the value of the Device Group attribute from folder root

    • Clear the check box and select the name of a Device Group
      Note: Choose this option if you do not want the folder corresponding to this partition to inherit the value of the Device Group attribute from folder root

  6. For the Traffic Group setting, choose an action:

    • Retain the default value
      Note: Choose this option if you want the folder corresponding to this partition to inherit the value of the Traffic Group attribute from folder root

    • Clear the check box and select the name of a Traffic Group
      Note: Choose this option if you do not want the folder corresponding to this partition to inherit the value of the Traffic Group attribute from folder root

  7. Click Finished. The new partition appears in the partition list.

Creating an administrative partition using tmsh Utility

  1. Create a partition using tmsh:

    tmsh create auth partition <partition_name> default-route-domain [value]

    For Example:

    tmsh create auth partition my_partition default-route-domain 0
     
  2. List the available partitions on the system:

    tmsh list auth partition all-properties
     
  3. Save the configuration:

    tmsh save sys config partitions all
Deleting an administrative partition
Important: Before deleting the administration partition, you must delete all the objects created in the partition.
Important: No user can delete partition Common

Delete the partition from configuration utility
  1. Navigate to System > Users > Partition List
  2. Select the checkbox next to the partition you want to delete.
  3. Click Delete...
  4. Click Delete to confirm deletion of partition
 
Delete the partition from tmsh utility
 
  1. Delete a partition using tmsh:

    tmsh delete auth partition <partition_name>

    For Example:

    tmsh delete auth partition my_partition
     
  2. List the available partitions on the system:

    tmsh list auth partition all-properties
     
  3. To save the configuration:

    tmsh save sys config partitions all
