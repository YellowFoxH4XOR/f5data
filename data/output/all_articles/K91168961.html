Known Issue

The Configuration utility may become unresponsive during Policy Sync operations.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for Policy Sync.
  • You perform Policy Sync operations such as synchronizing access policies or resolving location-specific objects (LSO).

Impact

The Configuration utility becomes unresponsive and you must manually restart it.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility becomes unavailable during access policy synchronization.
  • The system generates messages to the /var/log/webui.log file that appear similar to the following example:

    ERROR [TP-Processor3] ajax.facade_jsp:_jspService - Error processing request :Java heap space

Workaround

To work around this issue, you can log in to the command line and restart the tomcat process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP APM command line.
  2. To restart the tomcat process, type the following command:

    tmsh restart /sys service tomcat

  3. Log back in to the Configuration utility once the tomcat process has restarted.
