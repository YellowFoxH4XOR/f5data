Known Issue

The Server/Application State Protocol (SASP) monitor attempts to open a new connection to the Group Workload Manager (GWM) server.

This issue occurs when all of the following conditions are met:

  • The BIG-IP configuration contains a resource that uses the SASP monitor.
  • The SASP monitor receives a Send Weights message from a pool member before registration of all pool members is complete.

When the SASP monitor starts up, it may attempt to open a new TCP connection to the GWM server when a connection already exists.

Impact

The SASP monitor sends a TCP FIN flag, closing the existing TCP connection to the GWM server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe multiple TCP connections to the GWM server.
