Description

 This article explains how to retrieve the BIG-IP system software version using SNMP and clarifies the limitations regarding EPSEC (Endpoint Security) software version and update status retrieval. It also provides alternative methods to obtain EPSEC version information using CLI commands.

Environment

  • BIG-IP APM
  • SNMP enabled and configured
  • EPSEC (APM Endpoint Security) module present
  • F5-BIGIP-SYSTEM-MIB loaded on SNMP manager

Cause

F5 SNMP MIBs do not provide OIDs for EPSEC version or software update status. Only system version and statistical data are available via SNMP.

Answer/Recommended Actions

 To retrieve the BIG-IP system version via SNMP:

  1. Use the following OID (sysProductVersion): 
    snmpget -v 2c -c <community> <BIG-IP-IP> F5-BIGIP-SYSTEM-MIB::sysProductVersion.0
  2. Example output:

F5-BIGIP-SYSTEM-MIB::sysProductVersion.0 = STRING: 17.5.1

To retrieve EPSEC version and update status:

  1. Use the following CLI commands on the BIG-IP system: 
    # tmsh show apm epsec software-status
# tmsh show sys software update-status
