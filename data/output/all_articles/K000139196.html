K000139196: Error: 404 - data/openconfig-platform:components/component=platform/state not found

Type
Support Solution
Published
2024-04-05
Updated
2024-04-05
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000139196

Description

Upon initiating a new deployment/setup and accessing the GUI, the following error is encountered.

"Error 404 - /data/openconfig-platform:components/component=platform/state not found"

Environment

  • F5OS Appliance / rSeries
  • F5OS 1.5.0

Cause

Software Corruption

Recommended Actions

Upgrade to a later F5OS build.

Additional Information

If the problem continues following the upgrade, it is advised to proceed with a fresh installation. For more information, refer to: Manual: F5 rSeries Systems: Installation and Upgrade
