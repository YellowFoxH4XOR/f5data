K000134971: Output of GET /mgmt/shared/appsvcs/declare has unexpected results

Type
Support Solution
Published
2023-06-08
Updated
2023-06-08
Source
https://my.f5.com/manage/s/article/K000134971

Description:

When performing a "GET /mgmt/shared/appsvcs/declare" some AS3 Applications returned do not show up as having been deployed to all devices of a cluster.

 

Environment:

Big-IQ used as a AS3 Proxy

Ignore BIG-IP DSC sync when deploying configuration changes selected in Cluster Properties

 

Cause:

On the Cluster Properties screen For Deployment Settings If Ignore BIG-IP DSC sync when deploying configuration changes is selected then Tenants of AS3 deployments will be saved to their respective target address not to all devices in the DSC as is normal

 

If selected, Initiate BIG-IP DSC sync when deploying configuration changes (Recommended) then the Tenants of AS3 deployments will be saved to all nodes of the DSC that the target address is a member of.

 

Recommended Action:

On the Cluster Properties screen For Deployment Settings select Initiate BIG-IP DSC sync when deploying configuration changes (Recommended)
