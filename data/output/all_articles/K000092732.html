K000092732: F5OS API access and GUI login fails if password contains a semicolon ';'

Type
Support Solution
Published
2022-11-28
Updated
2022-11-28
Source
https://my.f5.com/manage/s/article/K000092732

Description


GUI and API access will not work if a user's password contains a semicolon ';'

The error messages for the failure are similar to one using an incorrect password: 
confd[118]: audit user: admin/0 external authentication failed via rest from 172.18.0.20:0 with http:
confd[118]: audit user: admin/0 login failed via rest from 172.18.0.20:0 with http: noauth

The error messages can be found in the following log files:
  • rSeries: /var/F5/system/log/audit.log
  • Chassis controllers (F5OS-C): /var/log/message
  • Partitions (F5OS-C): /var/F5/{partition name}/log/audit/log
 

Environment

  • F5OS
 

Cause

F5 is tracking this known issue via ID 1185741.
 

Recommended Action


Avoid using semicolons ';' in a password.

You may be able to change the password via ssh into the affected controller, or partition,

Controller: 
[root@controller-1 ~]# passwd admin
Changing password for user admin.
New password:          (new password without a semicolon)
Retype new password:


Partition: 
# system aaa authentication users user admin config change-password old-password
Value for 'old-password' (<string>): *****      (current password with a semicolon)
Value for 'new-password' (<string>): *******    (new password without a semicolon)
Value for 'confirm-password' (<string>): *******
 

Additional Info


An example failed REST API call with a colon in the password: 
# curl -sku 'admin:test;42' -H "Content-Type: application/yang-data+json" https://10.154.81.13:8888/restconf/
{
  "ietf-restconf:errors": {
    "error": [
      {
        "error-type": "protocol",
        "error-tag": "access-denied"
      }
    ]
  }
}

An example of a successful REST API call without a colon in the password: 
# curl -sku 'admin:admin' -H "Content-Type: application/yang-data+json" https://10.154.81.13:8888/restconf/ | jq
{
  "ietf-restconf:restconf": {
    "data": {},
    "operations": {},
    "yang-library-version": "2019-01-04"
  }
}
