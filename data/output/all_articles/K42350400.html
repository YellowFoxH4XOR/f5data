K42350400: Renewing NTLM Machine Account password causes Error Message: machine account update for '<machine_account_name>' failed: Preauthentication failed, principal name: <machine_account_name>@EXAMPLE.LOCAL. Invalid user credentials. (-1765328360)

Type
Support Solution
Published
2020-01-21
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K42350400

Description

  • NTLM authentication is configured on APM for Outlook Anywhere
  • errors in APM logs:
    err nlad[6303]: 01620000:3: <0x2b8de2040700> nlclnt[4c4a201710a] init: Error [0xc000006d,NT_STATUS_LOGON_FAILURE] connecting to DC 192.168.1.1
    err nlad[6303]: 01620000:3: <0x2b8de1e3e700> nlclnt[4c4a201710a] init: Error [0xc000006d,NT_STATUS_LOGON_FAILURE] connecting to DC 192.168.1.2
    err nlad[6303]: 01620000:3: <0x2b8dded7f700> nlclnt[4c4a101710a] init: Error [0xc000006d,NT_STATUS_LOGON_FAILURE] connecting to DC 192.168.1.1
    err nlad[6303]: 01620000:3: <0x2b8de1f3f700> nlclnt[4c4a201710a] init: Error [0xc000006d,NT_STATUS_LOGON_FAILURE] connecting to DC 192.168.1.2
  • when admin tries to "Renew Machine Password" for existing NTLM Machine account the below error is thrown in GUI
    Could not connect to domain controller of realm 'EXAMPLE.LOCAL'
    machine account update for '<machine_account_name>' failed: Preauthentication failed, principal name: <machine_account_name>@EXAMPLE.LOCAL. Invalid user credentials. (-1765328360)

Environment

  • APM
  • NTLM
  • Microsoft Outlook

Cause

The Machine Account Password might have been reset by one of the AD server.

Recommended Actions

Recreate NTLM machine account.  The following article contains instructions:  K63324455: APM: NTLM Authentication fails with the error message: Fail (STATUS_NO_LOGON_SERVERS)

Additional Information

None
