K84120003: Remove license from BIG-IQ using restcurl

Published
2022-04-19
Updated
2025-02-07
Applies to
  • BIG-IQ
Source

Description

This article describes the steps on how to remove a license on BIG-IQ that has been assigned to BIG-IP, using restcurl commands on BIG-IQ.

Environment

  • BIG-IQ
  • Remove license using restcurl

Cause

None

Recommended Actions

  1. Review licensing audit and identify the BIG-IP "machineId" for manual license deletion
    restcurl /cm/device/licensing/audit/ | jq .
  2. Find the license assignment using the "machineId" in previous step and search for "deviceMachineId".  8e309f83-7afa-4e38-929b-0b32000f93c1 is used in the following example:
    restcurl /cm/device/licensing/assignments | jq -r '.items[] | select(.deviceMachineId=="8e309f83-7afa-4e38-929b-0b32000f93c1")'
    Verify other details to ensure the correct device has been selected before proceeding with deletion of its license in step 4.
  3. Get selfLink for next step:
    restcurl /cm/device/licensing/assignments | jq -r '.items[] | select(.deviceMachineId=="8e309f83-7afa-4e38-929b-0b32000f93c1")| .selfLink' | sed 's/^.*\/cm/\/cm/'
    Example output:
    /cm/device/licensing/pool/utility/licenses/L8471-22580-09186-08717-5656797/offerings/1404a598-ba4e-4d68-bcee-f6cf419753d3/members/1b366659-9065-4042-abee-dc08c7fbe359
    Take note of the member ID for next step: "id":"1b366659-9065-4042-abee-dc08c7fbe359"
  4. Delete the license assignment and revoke license on BIG-IP by manually deleting the "id" using selfLink from previous step:
    restcurl /cm/device/licensing/pool/utility/licenses/L8471-22580-09186-08717-5656797/offerings/1404a598-ba4e-4d68-bcee-f6cf419753d3/members/1b366659-9065-4042-abee-dc08c7fbe359 -X DELETE -d '{"username":"admin","password":"adminpassword","id":"1b366659-9065-4042-abee-dc08c7fbe359"}'
    Note: Replace admin/adminpassword with your actual admin credentials for BIG-IP.
    Important: Removal of the license from BIG-IP will cause impact to traffic.

Additional Information

To list all license assignments matching <BIG-IP IPaddress>. Replace with actual IP address of BIG-IP.

 restcurl /cm/device/licensing/assignments | jq -r '.items[] | select(.deviceAddress=="<BIG-IP IPaddress>")'

Always revoke license from BIG-IQ before deleting the BIG-IP instance.
