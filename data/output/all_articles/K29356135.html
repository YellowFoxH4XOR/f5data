Known Issue

The BIG-IP logging system occasionally writes a blank message.

This issue occurs when the following condition is met:

  • An exception handler issue occurs in the Master Control Program Daemon (MCPD) File Object validator.

Damaged logs can exist anywhere in the mcpd process, but appear only after a File Object configuration change fails validation. The issue occurs only once per validation error. When the system rewrites the log, the damage caused by the exception handler is automatically corrected.

Impact

BIG-IP system behavior is unaffected; however, log text may be incomplete.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Occasionally, the logging system writes a blank message that appears similar to the following example:

    -- err mcpd[19114]: 01070711:3:

    For this log statement, the system should log the text associated with the corresponding error from the following entry in the /etc/alertd/bigip_mcpd_error_maps.h file:

    0 LOG_ERR 01070711 BIGIP_MCPD_MCPDERR_GENERIC_EXCEPTION "Caught runtime exception, %s."
