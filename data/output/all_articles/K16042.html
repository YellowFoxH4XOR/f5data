Known Issue

Users with established access profile sessions may receive HTTP 500 errors.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration uses an access profile for access to VMware Horizon View.
  • A user with an established access session connects to their VMware Horizon View desktop, and then subsequently disconnects from the desktop.
  • The user attempts to reconnect to their VMware Horizon View desktop.

Impact

Users cannot access VMware Horizon View desktops.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to reconnect to a VMware Horizon View desktop, during an established access session, the user receives an HTTP 500 error from the BIG-IP APM system.
  • After receiving an HTTP 500 error from the BIG-IP APM system, if the user logs off of the access profile session and initiates a new access profile session, they are able to access their VMware Horizon View desktop.
