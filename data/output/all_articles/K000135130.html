Applies to

Source

Description

  • You want to know a pool member's last marked-up timestamp from GUI by F5 BIG-IP. 

Environment

  • GUI
  • Pool member status

Cause

Behavior.

Recommended Actions

For example, in the F5 BIG-IP GUI, the green timestamp shows when a pool member was last marked as "up" on 23:23:38 20th, 2023.

This value will remain unchanged until the pool member is marked as "up" again.
