Known Issue

This is the result of a known issue. BIG-IP GTM daemons that collect metric data will mark down other F5 devices configured with multiple non-floating self IP addresses configured on a single VLAN.

F5 Product Development tracked this issue as CR69229, CR69230, and CR69320, and it was fixed in BIG-IP versions 9.2.4, 9.3.0, and 9.4.0. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller release notes.

Note: If you have upgraded to BIG-IP versions 9.3.0 or later and want the big3d process to listen on multiple non-floating self IP addresses on a single VLAN, it is necessary to manually adjust the big3d startup script. For more information, refer to K10331: Configuring the big3d agent to listen on all self IP addresses.
