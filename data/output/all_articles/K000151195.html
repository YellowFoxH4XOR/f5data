Description

When attempting user authentication via RADIUS on BIG-IP APM, all users fail to authenticate after a new access policy is applied. The following error appears in the logs:

RADIUS module: authentication with '<username>' failed: packet verification failed, most likely the shared secret is not correct  (-1)

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • AAA RADIUS authentication

Cause

RADIUS authentication fails due to a mismatch or incorrect configuration of the shared secret between the BIG-IP APM RADIUS AAA server object and the backend RADIUS server.

Recommended Actions

Check the shared secret configured in the BIG-IP APM RADIUS AAA server object used by the affected access policy.
Ensure it matches exactly with the shared secret configured on the backend RADIUS server (case-sensitive, no extra spaces).

None.
