Description

Usage of explicit -sid parameter in ACCESS::session data get/set [-sid <sid>]

Environment

  • BIG-IP APM
  • iRule containing HTTP_REQUEST event
  • Retrieve/set a value from/to a session variable using "ACCESS::session data get/set"

Cause

Explicitly setting the -sid parameter in "ACCESS::session data get/set" will ensure that the session variable value for that particular APM session is being retrieved/set

Recommended Actions

Get the APM session cookie using [HTTP::cookie value MRHSession] and use that value with the -sid parameter in ACCESS::session data get/set [-sid <sid>]

For example:

when HTTP_REQUEST {
  log local0. "HTTP URI: [HTTP::uri]"
  # getting the MRHSession from the http cookie
  set apm_cookie [HTTP::cookie value MRHSession]
  if { $apm_cookie != "" &&  [ACCESS::session exists $apm_cookie] } {
    # using  to get that specific variable value
    set customvar [ACCESS::session data get -sid $apm_cookie "session.logon.custom.var"]
    # using MRHSession to set that specific variable value  
    set userid [ACCESS::session data get -sid $apm_cookie "session.logon.last.username"]
  }
}
