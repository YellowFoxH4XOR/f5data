K000161579: F5OS FEC status inconsistency between GUI and CLI

Description

On F5OS the Forward Error Correction (FEC) status for 40G may appear as "auto" in the GUI, while the CLI displays the operational state as "disabled". 

Environment

  • F5OS
  • 40G interfaces (e.g., OPT-0043, OPT-0060)

Cause

This is expected behavior by design. The GUI displays the FEC value from the running-config (default "auto"), while the CLI state reflects the real operational FEC state. 

Answer/Recommended Actions

  • No configuration changes are required.
  • FEC configuration changes (enabled/disabled) are not permitted on interfaces that do not support FEC. Only "auto" is accepted as a config value, and it has no operational effect on unsupported interfaces.
  • Use the CLI to verify the actual FEC operational state.
