Description

F5OS software status shows Signature Verification Failure
 

Environment

  • Velos / rSeries
  • F5OS-C / F5OS-A
  • Software upload

 

Cause

  • not known, however hardware clock is significantly different this may be the cause: K000140167: [F5OS-A] "Signature Verification Failed" after uploading image to the F5OS appliance

 

Recommended Actions

If this is already the status for the new/RMAed unit, best to clean install following manual:

  • F5OS-C: Manual : VELOS Systems: Clean installation
  • F5OS-A: Manual : F5 rSeries Systems: Clean installation

Another way to recover from the status

  1. Log in to appliance / controller both active and standby (ssh controller-*), the all the iso version run below: 
    mount | grep 1.x.
    mount | grep 1.x. | grep PARTITION (if it is partition iso)
  2. If anything mounted, then run: 
    umount <mount location in above command>
  3. Check md5sum of /var/import/staging/*.iso files if they are correct, then move to /tmp (for F5OS-C Standby simply delete)
    mv /var/import/staging/<*>.iso /tmp/
  4. Run below commands on both Controller 1 and 2 to
    ls -al /var/import
    cp /var/import/import.json /tmp/ (taking backup)
    rm /var/import/.<versions having issue>
    rm /var/import/staging/
  5. then delete all close ({}) for the iso version and files got Signature Verification failure from import.json and save
  6. move back valid iso files to /var/import/staging
    mv /tmp/<*>.iso /var/import/staging/
  7. and then make sure the copying and verifying process is running and succeed.
