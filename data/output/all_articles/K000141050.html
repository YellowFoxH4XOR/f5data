K000141050: rSeries: Some log files may show suspicious messages about fault status/addr with the Linux kernel DMAR

Type
Support Solution
Published
2024-09-12
Updated
2024-09-12
Applies to
  • F5OS
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000141050

Description

The /var/log/messagesXXX log file(s) may show records like those:

Jan 01 07:11:00 appliance-1 kernel: DMAR: DRHD: handling fault status reg 2

Jan 01 07:11:00 appliance-1 kernel: DMAR: [DMA Read] Request device [ec:09.3] fault addr 3b12d8000 [fault reason 06] PTE Read access is not set


Environment

F5OS-A

rSeries

Cause

This is likely due to the IOMMU unable to read from the memory which the PTE [page table entry] did not grant the memory access as it does not have read access to the memory.

Recommended Actions

None, those messages are unlikely to be a consequence of a fault with the F5 device itself.

Additional Information

It has been reported that a VLAN misconfiguration of the switch the F5 device is connected to may induce Linux machine - not simply F5OS but many Linux flavours - to dump similar messages to the logs.
