Known Issue

SSL certificate Subject Alternative Name presents an error message when the password begins with an exclamation point ( ! ).

This issue occurs when the following condition is met:

  • You enter a Subject Alternative Name password that begins with an exclamation point.

Impact

You are unable to set the Subject Alternative Name password.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP Configuration utility presents an error message similar to the following example:

    Error: Failure to create certificate request passphrase with error: Syntax Error: command history is only available in shell mode

Resolution

Status

F5 Product Development has assigned ID 487581 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can avoid using an exclamation mark in either the Subject Alternative Name or the Password.
