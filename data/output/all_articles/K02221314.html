Description
Effects for rollback to older version / boot slot is unexpected.
You will lose all config you created for new boot location, and the old boot location will retain old config.
 

Environment

  • BIG-IP
     

Cause

N/A
 

Recommended Actions

We do not support downgrading config to older version. 
Recommend to take back up for current config and make sure what config you will need to configure on older boot location.
 

Additional Information

If the other boot location has same version or later version, you can copy config from current boot location, please read further detail: K14724: Using the cpcfg command to copy a configuration from one boot location to another
Or you can use GUI, "install config".
