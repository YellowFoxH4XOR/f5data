K000151997: Distribution-hash configuration discrepancy on rseries platforms

Description

A configuration discrepancy may be observed between F5OS (on rSeries platforms) and BIG-IP tenants regarding the distribution-hash setting for trunk interfaces. Specifically, F5OS may display the distribution-hash as src-dst-ipport, while the tenant (e.g., running TMOS 17.5.0) displays it as src-dst-mac. This mismatch can cause confusion about which setting is authoritative and which value is actually used for traffic distribution.

Environment

  • Product: F5OS - Appliance.
  • Platforms:
    • F5-BIG-R5600-RE, F5-BIG-R10000 (r5k/r10k).
    • F5-BIG-R2000, F5-BIG-R4000 (r2k/r4k).
  • Tenant Versions: 17.5.0 (and other TMOS versions).
  • Configuration: Trunk interfaces with distribution-hash setting.

Cause

The observed discrepancy is due to architectural differences between (r5k/r10k) and (r2k/r4k) platforms:

For (r5k/r10k):

The distribution-hash setting configured on the F5OS platform is authoritative. The value shown in the tenant can be ignored, as the platform setting is used for actual traffic distribution. This is expected behavior and not a bug.

For (r2k/r4k):

There was a historical issue (Bug ID 1133869) where the distribution-hash setting was not synchronized between the platform and the tenant. This has been addressed in TMOS versions 15.1.9, 17.1.0, and 17.5.0, where the platform setting is now synchronized to the tenant.

Recommended Actions

For (r5k/r10k) platforms:

  • Rely on the distribution-hash value configured in F5OS; this value determines actual traffic distribution.
  • The value displayed within tenants can be disregarded as it does not affect functionality.
  • The default on F5OS is typically src-dst-ipport, but tenants may show src-dst-mac; this difference is cosmetic.

For (r2k/r4k) platforms:

  • Ensure tenants are running a version with Bug ID 1133869 resolved (15.1.9, 17.1.0, or later).
  • With these versions or newer, the platform’s distribution-hash will synchronize automatically to tenants.
