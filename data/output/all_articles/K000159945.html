K000159945: Multi-Factor Authentication for the F5OS Admin GUI.

Type

Published

  • F5OS-C
Source

Description

You are looking to use Multi-Factor Authentication (MFA) for the F5OS admin login.

Environment

  • F5OS admin login
  • rSeries and VELOS
  • Multi-Factor Authentication

Cause

F5OS does not currently have the ability to use MFS for the admin login.

Answer/Recommended Actions

If you have any questions about this please open a case with F5 Support. Reference enhancement ID1341169 "Multi-factor authentication to be made available for F5OS admin login".
