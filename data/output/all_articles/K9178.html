Issue

Previously, FirePass did not support Static Application Tunnels for Linux or Mac OS X client systems.

Starting in FirePass 6.0.3, FirePass supports Static Java Application Tunnels for Linux and Mac OS X client systems. You can configure an Application Tunnel on the Application Access: Resources page. When configuring an Application Tunnel, select the Java based tunnel check box to configure a Static Java Application Tunnel.

Note: FirePass does not support Dynamic Application Tunnels or Web Application Tunnels for Linux or Mac OS X client systems.
Note: You can configure Static Java Application Tunnels in addition to Static Application Tunnels for Windows clients.

For information about which versions of Linux and Mac OS X are supported for Static Java Application Tunnels, refer to the FirePass Controller Client Compatibility Matrix for your version of FirePass software.

F5 Product Development tracked this enhancement as CR62084 and it was included in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.
