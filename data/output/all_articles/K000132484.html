Description

When having SSL handshake issues for a virtual server, after taking a packet capture you may notice the pool member is not responding to a Client Hello, and the BIG-IP finishes the connection with a failure after the SSL handshake timeout expires. In normal behavior, the server should respond with a Server Hello to complete the SSL negotiation.

 

Environment

  • BIG-IP LTM
  • SSL Server profile attached to Virtual Server
  • Pool member not processing TLS.

Cause

The pool member is not processing encrypted traffic, therefore will not negotiate TLS.

 

Recommended Actions

Remove the Server SSL profile from the virtual server.
