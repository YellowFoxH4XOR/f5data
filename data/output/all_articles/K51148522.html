Known Issue

The BIG-IP system may truncate server-side responses.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a server Secure Sockets Layer (SSL) profile.
  • Your BIG-IP system is configured with an iRule that invokes the HTTP::collect command on server-side responses.

Impact

The BIG-IP system truncates responses from the server.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Responses from the server are truncated when the Server SSL profile is combined with the use of the HTTP::collect iRule command.
  • Your BIG-IP system does not send the server response to the client and closes the client-side connection.
