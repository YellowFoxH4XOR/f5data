Issue

Error Message

notice clusterd[<PID>]: 013a0024:5: <Information regarding which blade is assuming primary status>

In this error message, note the following:

  • <PID> is the process ID for the clusterd process.
  • <Information regarding which blade is assuming primary status> indicates which blade is assuming primary status and the former primary blade from which it is taking the status from.

For example:

notice clusterd[7154]: 013a0024:5: Blade 2: Changing primary from 1 to 2 (self)

Message Location

You may encounter this message in the following location:

  • /var/log/ltm
Description

This message occurs when the following condition is met:

  • The cluster selects a new cluster member to take on the role of the primary cluster member.

Impact

There is no impact. This message is a notification of primary blade status change.

Recommended Actions

None
