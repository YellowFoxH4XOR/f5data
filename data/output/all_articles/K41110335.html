Description

Virtual-Server associated with HTTP and FastL4 profiles does not allow manipulation of HTTP traffic.

Environment

  • BIG-IP LTM
  • Virtual-Server associated with HTTP and FastL4 profiles

Cause

It's expected behaviour. When both HTTP and FastL4 profiles are associated with Virtual-Server, HTTP profile is used only for "read-only" activities like gathering statistics.
You cannot manipulate HTTP Header fields via features like:

  • HTTP profile options like Redirect Rewrite
  • iRules
  • LTM Policies

Recommended Actions

To allow HTTP traffic manipulation you can associate Virtual-Server with Standard profile.
