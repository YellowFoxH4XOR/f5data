K17205: Users may not be able to set the security policy name when importing or creating policies from templates

Known Issue

You may not be able to configure a custom name for the BIG-IP ASM security policy.

This issue occurs when the following conditions are met:

  • You use the Deployment wizard to import or create a policy by using a template.
  • When creating the policy, you choose either of the following options:
    • Existing Virtual Server
    • New Virtual Server

Impact

You cannot configure a custom name for the security policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You cannot configure a custom name for the security policy.

Workaround

To work around this issue, you can manually configure the policy (without using the Deployment wizard).
