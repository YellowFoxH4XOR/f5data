Description
BIG-IP device has Advanced Web Application Firewall(AWAF) add-on module activated, when ASM module is provisioned, under /var/log/ltm log, the below messages are observed :
BIG-IP-LTM notice tmm[11142]: 01010044:5: ASM feature is licensed
BIG-IP-LTM notice tmm[11142]: 01010044:5: ASM feature not licensed

Environment

  • Advanced WAF is licensed
  • ASM is provisioned

Cause
This is a cosmetic issue.   

Recommended Actions

None, as there is no impact.

None
