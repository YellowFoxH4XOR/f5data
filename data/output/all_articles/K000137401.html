K000137401: Unable to backup UCS file with error "Can't find version"

Type
Support Solution
Published
2023-12-09
Updated
2023-12-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.X.X, 16.0.0, 16.0.1, 16.0.X, 16.1.0, 16.1.1, 16.1.2, 16.1.3, 16.1.4, 16.1.X
Source
https://my.f5.com/manage/s/article/K000137401

Description

You may encounter an error while doing the ucs backup or installing the new software.

root@(BIGIP)(cfg-sync In Sync)(Online)(/Common)(tmos)# save sys ucs test
Saving active configuration...
ASM configuration could not be saved, mysql is unavailable
tmsh_syntax_pre: Can't find version
Error executing 'pre-save' configsync script /var/tmp/cs_save_pre_script.

WARNING:There are error(s) during saving.
        Not everything was saved.
        Be very careful when using this saved file!

Error creating package
Error during config save.
Unexpected Error: UCS saving process failed.

Environment

  • LTM
  • Backup UCS file
  • Installing the new software


Cause

  • The "/VERSION" file is NULL

For example
[root@BIGIP:Online:In Sync] / # cat /VERSION
[root@BIGIP:Online:In Sync] / #
 

  • Usually, the "/VERSION" file should contain the software version information

For example
[root@BIGIP:Online:In Sync] / # cat VERSION 
Product: BIG-IP
Version: 16.1.3.1
Build: 0.0.11
Sequence: 16.1.3.1-0.0.11.0
BaseBuild: 0.0.11
Edition: Point Release 1
Date: Thu Jul 21 02:50:44 PDT 2022
Built: 220721025044
Changelist: 3617116
JobID: 1372898


Recommended Actions

  • You can copy the "/VERSION" file from another big-ip peer
  • Another way is to copy from the big-ip image file
    • Create tmp folder
      • # mkdir /shared/tmp/iso
    • Mount the ISO file
      • # mount -o loop BIGIP<same_version>.iso /shared/tmp/iso
    • then move to BIGIPxxx dir,
      • # cd /shared/tmp/iso/BIGIPxxx
    • Copy the /VERSION file.
      • # cp VERSION > /VERSION
