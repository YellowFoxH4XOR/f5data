K000150106: WAF remote logging truncates "vs_name" field to 64 characters

Type
Support Solution
Published
2025-02-27
Updated
2025-02-27
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.0, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000150106

Description

Virtual server name truncated at 64 bytes with remote logging handled by BD.

Environment

  • BIG-IP ASM/Advanced WAF provisioned and running 17.1.1 or later release
  • Virtual Server name (/<partition-name>/<vs-name>) exceeds 64 characters
  • Logging profile configured with Remote Storage and applied to the virtual server
  • The vs_name field is specified within the remote logging profile

Cause

This is tracked as a known bug ID1825057 wherein the virtual server name gets truncated at 64 characters within remote logging's vs_name field.

Recommended Actions

There is no workaround at this time besides ensuring virtual server name (/<partition-name>/<vs-name>) doesn't exceed 64 characters. 

The alternative option is to leverage destination address and/or port to uniquely identify the virtual server.

Additional Information

None.
