K10994: Persistence cookies are not inserted into responses served from the BIG-IP cache

Topic

If a virtual server is configured to use a cookie persistence profile and perform HTTP caching, then persistence cookies will not be inserted into responses served from the cache. This behavior is by design. Persistence cookies contain information that is private to an individual session and is not appropriate to be served from a shared cache.

If you want persistence cookies to be inserted for a specific object, you may perform either of the following tasks:

  • Configure the HTTP profile (9.x - 10.x) or Web Acceleration profile (11.x) to exclude the object from caching
  • Set a Cache-Control: private header for the object on the origin web server (OWS)
