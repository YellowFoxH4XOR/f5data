Known Issue

When you upgrade from BIG-IP 10.2.4 to 11.5.x or 11.6.x, with Fallback set to null in a wide IP pool, the new pool has fallback-ipv4 set to any6.

This issue occurs when all of the following conditions are met:

  • You upgrade from BIG-IP 10.2.4 to 11.5.x or 11.6.x.
  • You have set the Fallback to null in a wide IP pool.

Impact

The system incorrectly sets the fallback-ipv4 to an IPv6 address instead of an IPv4 address.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you upgrade from BIG-IP 10.2.4 to 11.5.x or 11.6.x, with Fallback set to null in a wide IP pool, the new pool has fallback-ipv4 set to any6.

Workaround

To work around this issue, you can set the wide IP pool Fallback option to a different value before you upgrade the system, and then set the option back after you complete the upgrade.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
