K000134898: LACP is down even the interfaces assigned are up.

Type
Support Solution
Published
2023-06-02
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 12.1.2
Source
https://my.f5.com/manage/s/article/K000134898

Description

  • LACP is down even the interfaces assigned are up.
  • Link Aggregation allows multiple physical links to be treated as one logical link on a BIG-IP system and provides redundancy in the event of a physical link failure. For more information about LACP trunks, refer to the Trunks chapter in the BIG-IP TMOS: Routing Administration manual.

Environment

  • BIGIP
  • LACP trunk configured.

Cause

Below error messages in debug logs

May 27 23:53:13 NUF5SHP3SYS02 info lacpd[7160]: 01160016:6: Switchboard Failsafe enabled
May 27 23:53:13 NUF5SHP3SYS02 info lacpd[7160]: 01160016:6: LACP has no switch, switchboard.failsafe disabled

This is due to LACP Timeout Value mismatch.

 

 Recommended Actions

  • Check the Values for LACP timeout on both the end devices. For F5 you can check as per below

Example

net trunk pacsTrunk {

  interfaces {

    2.1

    2.2

  }

  lacp enabled

  lacp-timeout short - This value should be same on both the devices.

 

 

  • Change the value on the other device accordingly.
