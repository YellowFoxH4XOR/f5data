K000152897: Failure when changing admin or root password on velos controller

Type
Support Solution
Published
2025-09-03
Updated
2025-09-03
Applies to
  • F5OS
  • F5OS-C: 1.5.X, 1.6.X, 1.8.X, 1.8.1, 1.8.0, 1.6.2, 1.6.1, 1.6.0, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000152897

Description

Password change from confD (logged in as admin) is not possible:

syscon-2-active# system aaa authentication users user admin config set-password
Value for 'password' (<string>): **********
Error: application communication failure
syscon-2-active# system aaa authentication users user root config set-password
Value for 'password' (<string>): **********
Error: application timeout

While it is possible to change the root password using 'passwd' command in Linux bash.

Environment

  • VELOS controller
  • password change

Cause

Bug ID 1359277: ConfD CLI timed out and subsequently sees Error: application communication failure

Recommended Actions

  1. Log in as root and restart the 'controller-userman' container, which is responsible for managing the passwords: docker restart controller-userman
  2. Reset the password again

Additional Information

None.
