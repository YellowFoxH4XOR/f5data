Description

After the TMOS upgrade, navigate to GUI menu Security ›› Protocol Security : Inspection Dashboard and select time frame in drop down list, then Inspection Events may show unknown inspection event ID 1 with empty description.


Environment

BIG-IP AFM

TMOS upgrade

Cause

"ID 1" is aggregated value created in the DB loading which was run in the TMOS upgrade process as designed.

But, there is no description assigned to "ID 1" yet.

Recommended Actions

Consider "ID 1" in "Inspection Events" as "Aggregated" value.

Additional Information

None
