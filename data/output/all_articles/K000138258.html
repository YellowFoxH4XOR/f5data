K000138258: Downloading BIG-IP ISO files from MyF5 portal using Command Line Interface

Description

Sometimes, you may need or prefer to download ISO files directly from MyF5 portal using a command line tool, such as wget or curl. This can be useful if you have limited bandwidth, want to automate the download process, or encounter issues with the web browser. In this article, we will show you how to download ISO files from my.f5.com using the command line interface (CLI) on BIG-IP using the curl command.

Environment

  • You have access to the software downloads on MyF5 portal.
  • You have command line access to your BIG-IP system
  • You have sufficient disk space on your BIG-IP system to store the downloaded ISO file

Cause

N/A

Recommended Actions

  1. Log in to your F5 account on MyF5 portal and navigate to the software downloads page.
  2. Select the product, version, image type and location that you want to download.
  3. Select "Copy Download Link". The copied link will include authentication token that will be valid for a limited time.
  4. Login to the CLI on your BIG-IP system.
  5. Change to the directory where you want to save the ISO file. For example, cd /shared/images.
  6. Type the following command syntax to download the ISO file using the curl command:

    curl -O -L -J --url "Copied HTTPS link"

    Note: If the terminal is unstable, you may want to start the curl command using nohup; curl will continue downloading even after the terminal disconnects. For example, nohup curl -O -L -J --url "Copied HTTPS link" -s &

    Note: Replace the Copied HTTPS link with the copied url from step 3 and enclosed it in double quotes.

  7. Verify that the downloaded ISO file is not corrupted by comparing its checksum with the one provided on MyF5 portal. You can use the following command syntax to generate the checksum of the ISO file: sha384sum <filename> where <filename> is the name of the downloaded file. For example, sha384sum bigip-16.0.1.1-0.0.6.iso
  8. If the checksum matches, you have successfully downloaded the ISO file from MyF5 portal using the command line interface. You can now use the ISO file to install or upgrade your F5 product.
  9. Use TMSH or TMUI to install the Image or Hotfix using normal install methods.
