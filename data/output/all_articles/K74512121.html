Issue

Error Message

warning tmm[<PID>]: 01200014:4: Warning, connections equals limit <RD IP Address Source:Port> -> <RD IP Address Destination: Port>, proto TCP, RD <Route Domains Profile>: Connection limit reached.

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (tmm) process.
  • <RD IP Address Source:Port> is the route domain source IP address and port.
  • <RD IP Address Destination:Port> is the route domain destination IP address and port. 
  • <Route Domains Profile> is the route domain profile in use. 

For example:

warning tmm[10866]: 01200014:4: Warning, connections equals limit 192.168.1.10%1:4238 -> 172.16.5.23%1:445, proto TCP, RD /Common/My_RouteDomains: Connection limit reached.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system reaches the maximum number of connections for the given protocol on the given route domain.

Impact

The new connection is not made.

Recommended Actions

None
