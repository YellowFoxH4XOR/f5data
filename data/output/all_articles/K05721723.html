Source

Description.

While trying to modify a BIG-IP ASM security policy, you get the error "Set active failed" when applying the security policy.

Environment.

  • BIG-IP ASM
  • Security Policy

Cause.

The problem is related to the database table PL_SUGGESTION_SUPPORT_IDS being full, you can view this in the log file /var/log/ts/asm_config_server.log:

Recommended Actions.

Select one of the following to work around this issue.

  • Accept/Delete/Ignore the associated learning suggestions
  • Truncate the BIG-IP ASM MySQL table with the following command:
    mysql -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'TRUNCATE TABLE PLC.PL_CONFIG_LOG;'
