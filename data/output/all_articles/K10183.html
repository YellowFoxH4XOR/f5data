Known Issue

This is the result of a known issue. When opening a Network Access, AppTunnel, or Terminal Server resource for the first time, users may receive the following error message:

Couldn't open proxy server

This issue typically occurs when anti-spyware, anti-virus or other protection software is installed. The failure occurs because the protection software checks the process used to create a new SSL tunnel. By default, that process will time out after 11 seconds. Because the protection software may take more than 11 seconds, the process times out and sends the user the error message.

F5 Product Development tracked this issue as CR119897 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-3 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
