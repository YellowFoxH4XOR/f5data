Known Issue

The BIG-IP WebAccelerator dumps core and restarts the pvac process and comm_srv process when the operating system clock is adjusted to an earlier time. This issue occurs when any of the following conditions are met:

  • The operating system clock is set backwards using the date command.
  • The operating system clock is set backwards by the Network Time Daemon (ntpd).

When the system clock is adjusted backwards, the pvac process and the comm_srv process fail to send out their respective heartbeats. As a result, the sod process kills these two processes and restarts them.

Impact

The BIG-IP WebAccelerator fails to process traffic during the restart of the processes.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP WebAccelerator logs a message that appears similar to the following to the /var/log/ltm file after the system clock is adjusted:

    01140029:5: HA daemon_heartbeat pvac fails action is restart.

  • The BIG-IP WebAccelerator logs messages that appear similar to the following to the command line, as well as the /var/log/ltm file, after the system clock is adjusted:

    emerg logger: Re-starting comm_srv
    emerg logger: Re-starting pvac

  • The BIG-IP WebAccelerator dumps cores to the /var/core directory with files that appear similar to the following:

    comm_srv.bld763.3.core.7314.gz
    pvac.bld763.3.core.7103.gz
