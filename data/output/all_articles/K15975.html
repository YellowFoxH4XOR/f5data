Known Issue

Automatic update settings may be reset to the default values following a ConfigSync operation.

This issue occurs when the following conditions are met:

  • The BIG-IP systems in the device group have different automatic update settings.
  • You perform a ConfigSync operation for the device group.

Impact

The automatic update settings may unexpectedly change for one or more devices in the device group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The automatic update settings change following a ConfigSync operation.
  • The BIG-IP system performs software update checks at unexpected intervals.

Workaround

To work around this issue, you can set the automatic update settings back to the desired values following the ConfigSync operation. For information about configuring automatic updates, refer to K15000: Using the Automatic Update Check feature.
