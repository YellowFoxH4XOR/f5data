Known Issue

The serial console for the BIG-IP 1600, 3600, 3900, 6900, 8900, and 8950 platforms persistently displays garbled output when all of the following conditions occur:

  • The baud rate of the BIG-IP system has been changed to a lower baud rate.
  • The baud rate of the client system is set to a different value than that of the BIG-IP system.
  • The Enter key is pressed on the client serial device.

When this occurs, access to the BIG-IP system using either the Configuration utility or SSH is unaffected.

For example, the BIG-IP serial console will display garbled output if the baud rate of the client serial device is set to 19200, and you use the BIG-IP LCD control panel to change the baud rate of the BIG-IP system from 19200 to 9600, and you then press the Enter key on the client serial device. If you then change the baud rate of the client serial device to 9600, the BIG-IP serial console continues to display garbled output.

Impact

You may not have access to the BIG-IP serial console as a result of the persistent garbled output.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The serial console output appears as garbled.

Workaround

To work around this issue, you can choose from one of the following options:

  • Setting the serial console baud rate using the command line
  • Setting the serial console baud rate using the LCD panel

Setting the serial console baud rate using the command line

If console output is garbled after changing the baud rate of the AOM or SCCP, you can reset the baud rate from the command line of the BIG-IP by using SSH. To do so, perform the following steps:

Note: By default, the root user is allowed SSH access. If a firewall or other security device is preventing SSH access, you need to contact your security administrator to allow SSH access to the BIG-IP system.

Impact of Workaround: Under certain conditions, a reboot may be necessary. Therefore, if the BIG-IP system is the active member of a redundant pair, rebooting will cause a failover. If the system is a standalone unit, rebooting will interrupt traffic processing.

  1. Log in to the BIG-IP command line.
  2. Log in to the Traffic Management Shell (tmsh) by entering the following command:

    tmsh

    Note: If you are currently logged in to the tmsh shell, you can skip this step.
  3. To view the current baud-rate value, type the following command:

    show /sys console

    The output of the command appears similar to the following example:

    Sys::Console
    ----------------
    Baud Rate 19200
  4. Type the following command syntax to change the baud rate:

    modify /sys console baud-rate <value>

    In the previous command syntax, <value> is one of the following options:

    9600
    19200 (Default)
    57600
    115200
  5. Save the change by typing the following command:

    BIG-IP 10.1.0 and later:

    save /sys config

    BIG-IP 10.0.x:

    save config
  6. If after changing the baud rate to match the baud rate of the serial terminal you still see garbled output on the serial terminal console, reboot the BIG-IP system by typing the following command:

    reboot

Setting the serial console baud rate using the LCD panel

If SSH access is not an option, you can reset the console baud rate from the BIG-IP LCD control panel. To do so, perform the following steps:

Impact of Workaround: Under certain conditions, a reboot may be necessary. Therefore, if the BIG-IP system is the active member of a redundant pair, rebooting will cause a failover. If the system is a standalone unit, rebooting will interrupt traffic processing.

  1. Press the X button, then use the arrow keys to navigate to the System menu.
  2. Press Check.
  3. Navigate to the Serial Speed menu.
  4. Press Check.
  5. Select the desired console baud rate.
  6. Press Check.
  7. To exit, press the X button twice.
  8. If after changing the baud rate to match the baud rate of the serial terminal you still see garbled output on the serial terminal console, proceed to the following steps to reboot the BIG-IP system:
  9. Press the X button, then use the arrow keys to navigate to the System menu.
  10. Press Check.
  11. Navigate to the Halt menu.
  12. Press Check.
  13. Press Check again at the confirmation screen.
  14. Wait 30 seconds before powering the machine off or rebooting it.
  15. Hold the Check button for four seconds to reset the unit. You should use this option only after you halt the unit.
