Known Issue

Certain virtual server configurations may cause the Traffic Management Microkernel (TMM) to produce a core file when processing traffic. This issue occurs when all of the following conditions are met:

  • A virtual server has the following configuration:

    • Is associated with a OneConnect profile
    • Uses an NTLM profile or uses an iRule using the ONECONNECT::select persist command
    • Uses one of the following persistence methods: cookie hash, msrdp, uie, sip, ssl_sid
    • Is associated with a WebAccelerator profile or is associated with a Request Logging profile
  • The virtual server receives a client request

Impact

If the BIG-IP system is a member in a redundant configuration, traffic will fail over to the standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic will be interrupted until TMM restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system fails over to the standby system
  • The BIG-IP system generates a TMM core file to the /shared/core directory
