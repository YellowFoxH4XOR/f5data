Topic

Beginning in BIG-IP 9.0.0, the BIG-IP SSH daemon only allows connections from SSH clients that support the keyboard-interactive option.

As a result, many SSH clients that worked with previous BIG-IP versions do not work with BIG-IP 9.0.0 and later. Most notably, the F-Secure SSH that was previously provided with the BIG-IP system does not support the keyboard-interactive option.

You cannot disable the keyboard-interactive option on the BIG-IP system; you must update your SSH client if the keyboard-interactive option is not supported by your SSH client.

For a list of common SSH clients that support the keyboard-interactive option, refer to the following table.

Operating systemSSH client
WindowsPuTTY
OpenSSH
UnixOpenSSH
MacOpenSSH

Note: Mac OS X versions 10.2 and later are already updated with the required version of OpenSSH.
