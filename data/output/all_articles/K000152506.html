K000152506: How to determine NGINX Plus license expiry date from JSON Web Token (JWT)

Type
Support Solution
Published
2025-07-10
Updated
2026-08-12
Applies to
  • NGINX Products
  • NGINX Ingress Controller: 4.0.0, 5.0.X, 5.0.0, 4.0.X, 5.X.X, 4.X.X, 5.1.X, 5.1.0
  • NGINX Instance Manager
  • NGINX Plus: R33, R34
Source
https://my.f5.com/manage/s/article/K000152506

Description

  • You are using one of NGINX products 
  • You wish to determine license expiry date using jwt token. 

Environment

  • NGINX Plus
  • NGINX Plus Ingress Controller
  • NGINX Instance Manager
  • JSON Web Token (JWT)

Cause

  • None

Recommended Actions

  • You can determine expiry date from command line following the below command and steps.
  • For easy of use, prerequisites require you to have JQ installed
    • SSH into your Linux Host where NGINX installed
    • Run the below command
      • "jq -R 'split(".") | .[1] | @base64d | fromjson' <<< cat <path/to/file/license.jwt>"
                          jq -R 'split(".") | .[1] | @base64d | fromjson' <<< cat license.jwt
                                      {
                                       "sub": "FNI-97xxxde-b93a-4465-b07b-514a0xxxx058",
                                       "iat": 1726784928,
                                       "iss": "F5 Inc.",
                                       "aud": "urn: f5:teem",
                                       "jti": "8axxxx270-76d6-11ef-9d89-e959a8xxxx65",
                                       "f5_order_type": "paid",
                                       "f5_sat": 1783900800       ~ < ---  date
                                      }
    • You can then validate date as shown below 
                                      date -d @1783900800
                                      Mon 13 Jul 2026 01:00:00 AM BST

Additional Information

  • Unwanted carriage returns or new line characters added to the JWT token file can prevent the license file from being processed correctly.
  • This example shows jq returning a parsing error when encountering a carriage return / line feed sequence at the beginning of the file:
                            jq -R 'split(".") | .[1] | @base64d | fromjson' <<< cat license.jwt
