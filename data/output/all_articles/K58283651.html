Description
When upgrading to Windows 10, Version 2004 and trying to connect to the APM RDP resource next message is shown: 

 "We couldn't connect to the gateway because of an error. If this keeps happening, ask your admin or tech support for help."

 

Environment

  • BIG-IP APM 
  • Upgrade to Windows 10, Version 2004
  • Now using "Microsoft Remote Desktop" instead of "Microsoft Remote Desktop Connection" app

Cause
BIG-IP APM does not support RDG-HTTP transport nor PAA (Pluggable Authentication and Authorization)

Recommended Actions

Not to use the Store App

None
