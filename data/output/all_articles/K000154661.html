Security Advisory Description

When a highly-privileged, authenticated attacker attempts to initialize the rSeries FIPS module using a password with special shell metacharacters, arbitrary system commands may be executed, and the FIPS hardware security module (HSM) may fail to initialize. A successful exploit can allow the attacker to cross a security boundary. (CVE-2025-60013)

Impact

This vulnerability may allow an authenticated attacker with the Admin or Resource Admin role to execute arbitrary system commands when initializing the FIPS HSM. This may allow an attacker to create or delete files, disable services, or bypass Appliance Mode. The limited additional privileges obtained by the already highly-privileged roles limits the impact to Confidentiality and Integrity. There is no Availability impact beyond existing user capabilities. There is no data plane exposure; this is a control plane issue only.

This vulnerability affects only rSeries hardware with a FIPS HSM. The following hardware products are affected:

  • r5920-DF
  • r10920-DF
