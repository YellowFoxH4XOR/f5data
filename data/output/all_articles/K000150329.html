K000150329: Protect VIP with Whitelist of Acceptable Public IPs

Type
Support Solution
Published
2025-03-11
Updated
2025-12-02
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000150329

Description:

Enhance security by implementing a whitelist of acceptable public IPs that can access a Virtual Server (VIP) on the BIG-IP system. This configuration ensures that only specific, pre-approved IP addresses are allowed to connect to the VIP.

Environment:

  • BIG-IP LTM

Cause:

The need for enhanced security measures to restrict access to a VIP by allowing only specific public IP addresses.

Recommended Actions:

To implement a whitelist of acceptable public IPs for a VIP, use an address list as the source address in your virtual server configuration. Follow these steps:

Step 1: Create an IP Address List

An address list allows you to specify multiple source or destination IP addresses for a virtual server. The list can include single non-contiguous IP addresses, ranges of contiguous IP addresses, or both.

  1. Navigate to the Shared Objects section in the BIG-IP Configuration utility.

  2. Click on Address List and then click Create.

  3. Provide a descriptive name for the address list in the Name field.

  4. In the Addresses field:

    • Enter an individual IP address and click Add, or

    • Specify a range of contiguous IP addresses and click Add.

  5. Repeat step 4 for each additional address or range you want to include in the list.

  6. Click Update to save your changes.

After completing this step, you will have created an address list that can be used as part of your virtual server configuration.

Step 2: Apply the Address List to Your Virtual Server

Once you've created an address list, configure your virtual server to use it as its source address filter.

  1. Navigate to Local Traffic > Virtual Servers in the BIG-IP Configuration utility.

  2. Click on the Virtual Server you want to apply the whitelist to.

  3. Scroll down to the Source Address field.

  4. Enter the name of the address list created in Step 1.

  5. Click Update to apply the configuration.

This configuration ensures that only the IPs defined in the address list can access the VIP.

Optional: Create a Service Port List (if needed)

If you also need to define multiple service ports for your virtual server:

  1. Navigate to the Shared Objects > Port List section.

  2. Click on Create.

  3. Provide a descriptive name for the port list in the Name field.

  4. In the Ports field:

    • Enter individual service ports and click Add, or

    • Specify ranges of ports if applicable and click Add.

  5. Repeat step 4 for each additional port or range you want included in the list.

  6. Click Update to save your changes.

This optional step is useful if you need granular control over which service ports are allowed alongside specific source/destination addresses.
