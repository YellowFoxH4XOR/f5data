Description

The BIG-IP Configuration fails to load with error message that appears similar to the following:

Syntax Error:(/config/bigip.conf at line: 2252) "access" unknown property

Note: In the error message the word "access" can be any string wrapped with quotes. 

Environment

  • BIG-IP LTM
  • Loading configuration

Cause

Quotes were added to text in the Configuration Utility for a monitor's Description field. In the /config/bigip.conf file it looks like this:

ltm monitor https /Common/monitor_example {
    adaptive disabled
    defaults-from /Common/https
    description "Looking for "No access""    <------

Note: Configuration Utility doesn't show the extra quotes but in the /config/bigip.conf file it shows four quotes.
 

Recommended Actions

Option 1: GUI

    1. Log in to the affected BIG-IP system.
    2. Locate the BIG-IP object in question.
    3. Delete/Remove the quotes.
    4. Save the change.
    Option 2: CLI
    1. Log in to the command line of the affected BIG-IP system.
    2. Create a backup of the /config/bigip.conf file, type the following command:
       cp /config/bigip.conf /config/bigip.conf.original
    3. Use a text editor of your choice (e.g. vi, nano) to open the /config/bigip.conf file.
    4. Go to the object in question. The error tells you what number line contains the problem. 
    5. Delete/Remove the quotes.
    6. Save the change you performed with your text editor.
    7. Save the bigip.conf file: tmsh save sys config
