Description

After failover in HA architecture VSs are not reachable despite appears as available

Environment

  • BIG IP in HA architecture
  • Traffic groups configured

Cause

This usually happens when MAC Masquerade is not configured in your BIG IP system and as results, switches connected to the system are not aware that traffic should be route to the new active device

 Recommended Actions

  1. Configure your BIG IP system to use MAC Masquerade which is actually a floating / virtual MAC address of the system
  2. Make sure that the MAC address to be use is unique in your network
