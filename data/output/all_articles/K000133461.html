Description

F5OS Upgrading step to v1.3.2 including the firmware and K3s upgrade.

 

Environment

  • F5OS
  • All rSeries platform
  • Upgrade to v1.3.2

 

Cause

N/A

 

 Recommended Actions

Follow step by step procedure below:

 

1. Initial Configs

 

1.1 Perform config backup and store in a secured location. All the system config will be stored under /var/F5/system/configs/.


appliance-1(config)# system database config-backup name config_1_3_2 proceed yes

result Database backup successful.

 

[root@appliance-1 configs]# cd /var/F5/system/configs/

[root@appliance-1 configs]# ls

config_1_3_2


[root@appliance-1 configs]# scp config_1_3_2 test@10.0.0.1:/home/test/

test@10.0.0.1's password:

config_1_3_2                                  100%  59KB  16.1MB/s   00:00  

 

1.2 Capture Qkview on the initial version.  


appliance-1# system diagnostics qkview capture filename capture-qkview.qkview

result Warning: Qkview may contain sensitive data such as secrets, passwords and core files. Handle with care. Please send this file to F5 support.

Qkview file capture-qkview.qkview is being collected.

return code 200

[root@appliance-1 qkview]#

 

1.3 Validate that the newly released version is imported and also capture tenants, interface, and initial version info. How to import can be found at F5 Image Import

 

2. Image Upgrade

Execute the image set command to upgrade the system to a new iso. At this point system reboots and boots on the latest iso. The system might take approximately 4 minutes to boot on the new version.

Note: Validate if there is a need to move the tenants to provisioned state before the Upgrade. Some versions might require tenants to be in the provisioned state before upgrading.

 

appliance-1(config)# system image set-version iso-version 1.3.2-13054 proceed yes

response System iso version has been set

appliance-1(config)# exit

 

Once the system is up, System will take about 2 min for starting all the containers. At this point, confd will be reachable. One should wait for all the Firmware upgrades and k3s upgrades to complete before deploying any new tenant.

 

3. Firmware Upgrade

3.1 AFU will trigger FW upgrades immediately after confd up. Confd/console will repeatedly print firmware upgrade messages. BIOS upgrade will trigger a system reboot and that is expected. This may take about 18min to complete
