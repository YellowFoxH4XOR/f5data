K000161412: Calculate the throughput - "IN" and "OUT" by using the TMCTL table

Description

When using the TMCTL table counter to calculate the device throughput, the direction could be different than using SNMP or GUI.

  • You may see a different value in the server-out in the TMCTL output

 

Environment

BIG-IP NEXT CGNAT CNF

  • Using TMCTL counters - Clientside.bytes_in, Clientside.bytes_out, Serverside.bytes_in, Serverside.bytes_out

Cause

The TMCTL counter for the Clientside.bytes_in/out and SErverside.bytes_in/out, the "flow direction" is NOT the same as described in article K9077: Overview of BIG-IP traffic flow

Answer/Recommended Actions

To use the TMCTL to calculate the IN and OUT throughput, the formula should be:

IN = ( <Delta of Clientside.bytes_in> + <Delta of Serverside.bytes_in> ) *8 / <interval>

OUT = ( <Delta of Serverside.bytes_out> + <Delta of Clientside.bytes_out> ) *8 / <interval>

 

Note: The TMCTL table output is showing "bytes", hence you need to times 8 to make it bits per second.

 

Additional Information

Example output:

# date; k exec f5-tmm-6bbc664ff8-bbmh5 -c debug -- tmctl -d blade virtual_server_stat -w 300 -s name,clientside.bytes_in,clientside.bytes_out,serverside.bytes_in,serverside.bytes_out
Sun May 17 14:06:11 UTC 2026
name                             clientside.bytes_in clientside.bytes_out serverside.bytes_in serverside.bytes_out
-------------------------------- ------------------- -------------------- ------------------- --------------------
default-virtual-SecureContext_vs            12600073                12733               12733             12600073 

By applying the formula, the throughput "IN" will be 12600073 + 12733, as well as the "OUT" will be the same.
