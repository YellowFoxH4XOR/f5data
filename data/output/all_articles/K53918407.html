Description

When you make changes to SSL Cipher rules, it doesn't reflect the change if the SSL profile name is more than 25 characters

  • When verifying the changes (ex. Cipher Strings) using OpenSSL, SSLScan, etc., it will not reflect the changes in the cipher.
  • No Error Message will be encountered on BIG-IP GUI or CLI.

Environment

Relevant environmental factors specific to the topic

  • You have a custom Client SSL profile applied in your Virtual Server with a  profile name of 25 characters or more
  • You applied a custom Cipher Group inside the custom Client SSL profile
  • You are running BIG-IP version 13.x or 14.x

Cause

Unknown at the time of publication

Recommended Actions

For Workaround:

  1. On the Client SSL Profile (with a profile name of 25 characters) attached to the virtual server, set the cipher-group from custom to default, then update.
  2. Make changes to the cipher strings in the custom cipher group, then update.
  3. On the Client SSL Profile attached to the VS, set again the cipher-group back to the custom cipher group, then update/save changes.
For Permanent Fix:
  • You can upgrade to version 15.x onwards
