K000160330: Licensing F5OS rSeries Devices in Classified (No access to internet) Environments

Type
Support Solution
Published
2026-03-12
Updated
2026-03-12
Source
https://my.f5.com/manage/s/article/K000160330

Description

License activation or reactivation failure on F5OS rSeries devices deployed on classified environments where devices lack internet access and security restrictions prevent exporting dossier files for manual activation.

Environment

  • F5OS rSeries
  • Software version: 1.5.1

Cause

Devices on classified environments cannot connect to the internet for license activation, and security restrictions may prevent exporting the dossier file required for manual activation.

Answer/Recommended Actions

  1. Attempt to generate and export the dossier file from the F5OS device.
  2. If unable to export the dossier due to security restrictions:
    • Open a support case with F5 and provide:
      • Device serial number(s)
      • Base registration key(s)
      • Description of the classified environment and inability to export the dossier
  3. F5 Support may be able to locate a previous dossier associated with your registration key using internal systems.
  4. If a previous dossier is available, F5 Support can use it to generate a license file and provide it to you for local application.
  5. Apply the provided license file to your F5OS device using the GUI or CLI.

Additional Information

  • This process is only possible if a previous dossier exists in F5's internal systems. If no dossier is available, you may need to coordinate with your security team to temporarily allow dossier export.
  • F5 Support does not access your device directly; all actions are performed using internal records and tools.
  • This process is intended for exceptional cases in classified or highly restricted environments for F5OS rSeries.
