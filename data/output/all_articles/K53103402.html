Description

In certain scenarios, The config fails to load or iApp fails to be reconfigured with following error message.

010716d9:3: Virtual server /Common/Exchange_2013_Ext.app/example_virtual_https requires a profile of type websecurity for ltm policy /Common/Exchange_2013_Ext.app/asm_auto_l7_policy__virtual_https.

Environment

  • BIG-IP iApps
  • BIG-IP ASM
  • LTM Policy

Cause

  • If a virtual server is configured with LTM policy and the LTM policy referenced in the error message is enabled with ASM.
  • If a websecurity profile is not configured in the virtual server.

Recommended Actions

To work around the issue, you may follow either of the below procedures.

Assign a websecurity profile to Virtual server via the command line:.
  1. Log in to the TMOS
    # tmsh
     
  2. Modify the Virtual Server configuration to add websecurity profile: (Example: virtual_https)
    modify ltm virtual virtual_https profiles add { websecurity }
     
  3. View the changed virtual server configuration:
    list ltm virtual virtual_https
     
  4. Verify the configuration 
    load sys config verify 
     
  5. Load the configuration 
    load sys config

Remove ASM from the HTTP Virtual Service in questions via the Configuration utility.

  1. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
     
  2. Click on the name of the virtual server configured with the application security policy.
     
  3. Hover on the Security tab and click Policies.
     
  4. Set Application Security Policy to Disabled.
     
  5. Click Update.
     
  6. Repeat steps 3 - 5 for each virtual server that is configured with an application security policy.
