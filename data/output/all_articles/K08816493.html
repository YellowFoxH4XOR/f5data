Description

How to enable sFlow for interface, system, and VLAN, but not for HTTP data

sFlow is an industry-standard technology for monitoring high-speed switched networks. You can configure the BIG-IP® system to monitor interface, system and VLAN data, but you may not want to include HTTP Data in that monitor stream due to volume

Environment

  • BIG-IP
  • sFlow monitoring

 

Recommended Actions

The effect of setting the HTTP sample and interval to zero is to disable sflow for HTTP.

Use the Configuration utility

  1. In the GUI select System from the left hand menu.
  2.  Select sFlow, then Global Settings.
  3.  Click http
  4.  Change Polling Interval and Sample Rate to zero.
  5.  Click Update

Use the TMOS Shell (tmsh)

  1. Log in to tmsh by typing the following command:
    tmsh
  2. Change Polling Interval and Sample Rate to zero.
    modify sys sflow global-settings http poll-interval 0 sampling-rate 0
  3. Save the configuration to memory by entering the following command:
    save sys config
