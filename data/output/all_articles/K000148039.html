K000148039: Will source IP Stickiness work with multiple Origin Pools?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-22
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000148039

Description

I want to use multiple Origin Pools with Source IP Stickiness.

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer

Cause

  • It is only expected to work for multiple endpoints within one origin pool mapped to a route and not across multiple origin pools mapped to a route.

Answer/Recommended Actions

No, source IP stickiness does not work across multiple origin pools. It only works if the endpoints are part of the same origin pool.

Additional Information

  • The information above can also be referring to "routes" in HTTP Load Balancer.
    • For example: Having multiple Origin Pools mapped to a single route is not going to work. You have to have all the endpoints in one Origin Pool.
