Known Issue

This is the result of a known issue. You can use the production rule wizard to configure any setting when you are a creating a new production rule; however, you cannot use the production rule wizard to change the QoS settings for a production rule that already exists.

F5 Networks Product Development tracked this issue as CR16629 and CR41808. 

Workaround

To work around this issue, you can edit the production rule in the wideip.conf file or delete the production rule and use the production rule wizard to recreate a new production rule with the desired QoS settings.
