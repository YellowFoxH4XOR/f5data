K000149733: BIG-IP send SYN and server replies with ACK instead of SYN-ACK

Source

Description

Connection timeout while accessing a VS but when you access the backend server directly, there is no connection timeout. Comparing the pcap from BIG-IP and backend server, you see BIG-IP send SYN but the server replies with ACK instead of SYN-ACK.

Environment

  • LTM
  • FastL4

Cause

Not BIG-IP issue. BIG-IP is sending SYN packets to the backend server and server replies with ACK instead of SYN-ACK. Which causes 3WHS to not complete and client ends up seeing connection timeout.

Recommended Actions

Check with backend server team why certain connection the server replies with a ACK instead of SYN-ACK.

None
