K51458353: Configuring the BIG-IQ system to use RADIUS authentication

Applies to

Topic

You should consider using these procedures under the following condition:

  • You want to configure the BIG-IQ system to use Remote Authentication Dial-in User Service (RADIUS) authentication.

Description

You can configure the BIG-IQ system to use RADIUS authentication for the user interface. Prior to configuring RADIUS authentication, ensure you understand how user roles apply to locally and remotely configured user accounts:

User roles

User roles are applied once the the remote RADIUS authentication server authenticates the user. If the user account is locally defined on the BIG-IQ system, the roles defined in the local user account's Roles option are applied. If the user account is not defined locally on the BIG-IQ system, but rather on a remote RADIUS authentication server, you must define the user roles with a user group.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to the BIG-IQ user interface.
  • You have user accounts configured on the BIG-IQ system and RADIUS server.
  • You have the RADIUS server's shared secret, IP address, and service port number.

Procedures

  • Creating the RADIUS authentication provider
  • Creating the user group

To configure RADIUS authentication for locally maintained user accounts, you only need to create the RADIUS authentication provider object. To configure RADIUS authentication for remotely maintained user accounts, you must create both the RADIUS authentication provider (server) object and one or more user groups. To configure the BIG-IQ system to user RADIUS authentication, perform the following procedures:

Creating the RADIUS authentication provider

Impact of procedure: Performing the recommended workaround should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Select System at the top of the page.
  3. In the left column, navigate to USER MANAGEMENT > Auth Providers.
  4. Click Add.
  5. From the Provider Type drop-down, select RADIUS.
  6. Enter a unique Name for the RADIUS server.
  7. Enter the RADIUS server connectivity information:
    • BIG-IQ 5.3.0 and later:
      In the Servers section, enter the server IP address or domain name in the Host field and the service port number in the Port field.
      In the Secret section, enter the passphrase used to validate RADIUS requests.
    • BIG-IQ 5.2.0:
      Under RADIUS Servers, enter the server IP address or domain name in the Host field, the service port number in the Port field and the passphrase used to validate requests in the Secret field.
  8. Optional: Under Test Connection, enter a valid username in the Test User field and the user password in the Test Password field.
  9. Optional: Click Test to verify RADIUS functionality. You will see a green check mark if the test is successful.
  10. Click Save & Close at the bottom of the page.

Creating the user group

When the BIG-IQ system requests authorization for remotely maintained users, the RADIUS server authenticates the user and responds with a custom RADIUS authorization attribute that is shared by both the BIG-IQ system and the remote RADIUS server. The BIG-IQ system uses the RADIUS authorization attribute to find the correct user group and apply the appropriate user roles. 

The following RADIUS server configuration example uses the F5-LTM-User-Info-1 authentication attribute with a custom value of exampleDNSview for the user account john:

john Cleartext-Password :="password"
     F5-LTM-User-Info-1 = exampleDNSviewer,

The following BIG-IQ system configuration example uses the F5-LTM-User-Info-1 authentication attribute with the same custom value exampleDNSviewer to set the user role as DNS Viewer.

DNS Viewer

Impact of procedure: All user accounts other than the default admin and root user accounts will authenticate using RADIUS. F5 recommends performing this procedure during a scheduled maintenance period.

  1. Log in to the BIG-IQ user interface.
  2. Select System at the top of the page.
  3. In the left column, navigate to USER MANAGEMENT > User Groups.
  4. Click Add near the top of the page.
  5. From the Auth Provider drop-down, select the RADIUS authentication provider created in the previous procedure.
  6. Define the user group attribute sent to the remote RADIUS authentication provider.
  7. In the Authorization Attributes section, enter the following information:
    • BIG-IQ 5.3.0 and later:
      In the Authorization Attributes section, enter the following information:
      In the Attribute field, enter F5-LTM-User-Info-1.
      In the Value field, enter a unique string that will identify the user group attribute define on the remote RADIUS server.
    • BIG-IQ 5.2.0:
      In the Connect Properties section, enter the following information:
      In the Key field, enter F5-LTM-User-Info-1.
      In the Value field, enter a unique string that will identify the user group attribute defined on the remote RADIUS server.
  8. In the Roles section, select the appropriate user roles for the user group.
  9. Click Save & Close at the bottom of the page.
