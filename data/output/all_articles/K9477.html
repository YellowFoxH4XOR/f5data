Known Issue

This is the result of a known issue. After enabling BIG-IP WebAccelerator, client requests may fail with an error message that appears similar to the following example:

Request header length exceeds permitted size.

The default HTTP profile is configured to accept requests with a maximum HTTP request header size of 32768 bytes. However, by default, the maximum size of an HTTP request header accepted by BIG-IP WebAccelerator is only 16384 bytes. Before enabling BIG-IP WebAccelerator, requests with an HTTP header size up to 32768 bytes were allowed. However, after enabling BIG-IP WebAccelerator for the virtual server, requests with an HTTP header size larger than 16384 bytes begin to fail.

Note: If the HTTP request header exceeds the maximum size configured in the HTTP profile, an error message that appears similar to the following example is logged to the /var/log/ltm file: 

HTTP header (33760) exceeded maximum allowed size of 32768

F5 Networks Product Development is tracking this issue as CR114627.

Workaround

You can work around this issue by configuring the maximum size of an HTTP request header accepted by BIG-IP WebAccelerator to match the size configured in the HTTP profile used by the virtual server. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Back up the original pvsystem.conf file by typing the following command:

    cp pvsystem.conf pvsystem.conf.sol9477
  4. Open the pvsystem.conf file in a text editor.
  5. Locate the following httpRequestHeaderSize entry:

    <httpRequestHeaderSize>16384</httpRequestHeaderSize>
  6. Edit the httpRequestHeaderSize entry to match the value configured in the profile used by the BIG-IP WebAccelerator enabled virtual server.

    For example:

    <httpRequestHeaderSize>32768</httpRequestHeaderSize>
  7. Save the pvsystem.conf file.
  8. Stop the BIG-IP WebAccelerator process by typing the following command:

    bigstart stop pvac
  9. Start the BIG-IP WebAccelerator process by typing the following command:

    bigstart start pvac
