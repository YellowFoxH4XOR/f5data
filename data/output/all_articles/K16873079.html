Known Issue

The BIG-IP system may fail to bring a pool member offline.

This issue occurs when the following condition is met:

  • You attempt to set the state of a pool member to user-down using the following Traffic Management Shell (tmsh) command syntax:

    tmsh modify /ltm node <node IP address> state user-down

    For example, to set the state of pool member 192.168.10.10 to user-down you would type the following command:

    tmsh modify /ltm node 192.168.10.10 state user-down

Impact

The BIG-IP system cannot update the session status of the affected pool member.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H585314 on the Diagnostics > Identified > Medium screen.
  • You observe that the state of the affected pool member is available (green).
  • In the /var/log/ltm file, you observe an error message similar to the following example:

    01070712:3: Caught configuration exception (0), Invalid monitor rule instance identifier: 1137
