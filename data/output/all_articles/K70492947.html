Issue

Error Message

warning tmm[<PID>]: 01260026:4: No shared ciphers between SSL peers <client_IP>:<server_IP>.

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <client_ip> is the IP address and port of the Secure Sockets Layer (SSL) client
  • <server_IP> is the IP address and port of the virtual server on the BIG-IP system

For example:

warning tmm[7887]: 01260026:4: No shared ciphers between SSL peers 10.10.10.10.34492:10.20.20.20.443.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • A virtual server is configured with a Client SSL profile.
  • An SSL client attempts to connect to the virtual server.
  • None of the ciphers sent by the client match the configured ciphers in the Client SSL profile.

This issue generally occurs when an older SSL client attempts to connect to the BIG-IP system using a less secure cipher. 

Impact

The SSL client is unable to connect to the virtual server.

Recommended Actions

Review a tcp capture (tcpdump) of the SSL handshake between the client and virtual server to determine what ciphers the client is presenting in client hello.  Then review the list of cipher strings configured for client SSL profile attached to the virtual server. 

The view the list of ciphers available for the BIG-IP system to use for an SSL client are configured using the Ciphers setting in the Client SSL profile. After you determine the ciphers presented by the client, you can view the list of ciphers available to the Client SSL profile and compare them against the ciphers sent by the client.

To list the ciphers available to the Client SSL profile, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Select the name of the Client SSL profile.
  4. Select Advanced in the Configuration section.
  5. Note the cipher string configured in the Ciphers setting.
  6. Log in to the Advanced Shell (bash).
  7. Using the cipher string from the Client SSL profile, list the available ciphers using the following syntax:

    tmm --clientciphers '<cipher_string>'

    For example:

    tmm --clientciphers 'ecdhe:rsa:!sslv3:!rc4:!exp:!des'

    Note: The default cipher list is DEFAULT.
