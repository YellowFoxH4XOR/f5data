Known Issue

This is the result of a known issue. You will receive the following error if you enter an invalid date range for NameSurfer and NameSurfer will not allow you to go back to its main page.

Cannot Understand Date

F5 Networks Product Development is tracking this issue as CR38569.

Workaround

To work around this problem, use the Return to index page link to return to the main NameSurfer page.
