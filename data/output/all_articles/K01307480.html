Description
When you use iRule HTTP2::disable serverside command, the BIG-IP still specifies h2 (HTTP/2) on the Application-Layer Protocol Negotiation (ALPN) on the Transport Layer Security (TLS) level of communication.

TLSv1.2 Record Layer: Handshake Protocol: Client Hello
<snip>
    Extension: application_layer_protocol_negotiation (len=14)
        Type: application_layer_protocol_negotiation (16)
        Length: 14
        ALPN Extension Length: 12
        ALPN Protocol
            ALPN string length: 2
            ALPN Next Protocol: h2
            ALPN string length: 8
            ALPN Next Protocol: http/1.1

Environment

  • The virtual server has an HTTP/2 profile on the server-side.
  • The iRule applied to the virtual server uses HTTP2::disable serverside command.

Cause
F5 tracks the issue as ID 869565.

Recommended Actions

You can fix the issue by installing a version listed in the "Fixed In" on the Bug Tracker.
