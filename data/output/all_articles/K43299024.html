Issue

Error Message

notice bigd[<PID>]: 01060002:5: Node address detected <status> for <address> monitor <name>.

In this error message, note the following:

  • <PID> is the process ID for the bigd process
  • <status> is the monitor status for the node
  • <address> is the IP address for the node

For example:

notice bigd[5454]: 01060002:5: Node address detected UP for ::fff:10.10.10.10 monitor /Common/mon_icmp.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The BIG-IP system detects a change in the monitor status of a node.

The BIG-IP system generates this message when the monitor status for a node changes to UP, DOWN, ENABLED, or DISABLED.

Impact

There is no impact; this is a notification of monitor status for a node.

Recommended Actions

None
