Issue

This article applies to Client SSL certificate support of the SHA-2 hashing algorithm. For information about Server SSL certificate support, refer to the following article:

  • K12139: BIG-IP Client SSL profile support for Server SSL certificates signed using the SHA-2 hashing algorithm

Old Behavior

In versions prior to BIG-IP 11.1.0 HF3 and 11.2.0, the Client SSL profile does not support Client SSL certificates signed using the SHA-2 hashing algorithm.

New Behavior

Beginning in BIG-IP 11.1.0 HF3 and 11.2.0, the Client SSL profile now accepts Client SSL certificates signed using the SHA-2 hashing algorithm.

F5 Product Development tracked this change as ID 374685.

Impact

The BIG-IP Client SSL profile can support a wider range of Client SSL certificates by including the SHA-2 hashing algorithm.

Recommended Actions

None
