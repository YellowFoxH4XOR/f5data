Source

Description

The following error message can be triggered by several environmentally based factors. Dependent on the environment, the error message can be logged to the console and /var/log/ltm (BIG-IP and BIG-IP APM) or /var/log/scriptd.out (iWorkflow). 

Error Message: 01070734:3: Configuration error: Invalid mcpd context, folder not found <folder>

Note: <folder> indicates a specific folder path and name.

 

 

 

Environment

• BIG-IP

• iWorkflow

• BIG-IP APM

Note: Each environment bullet refers to a specific environment and does not require all environmental items to encounter the error message.

Cause

Multiple - environmental dependence.

Recommended Actions

• K61214360: Error Message: 01070734:3: Configuration error: Invalid mcpd context, folder not found (/Common/EPSEC/Images)

Error message is logged to /var/log/ltm when attempting to install a BIG-IP APM EPSEC package and is a known issue Bug ID 739570.

 

• K42390368: Error Message: 01070734:3: Configuration error: Invalid mcpd context, folder not found (<folder>)

Error is logged to /var/log/scriptd.out when attempting to deploy a version of the Application Services Integration (iApp) for iWorkflow.
 

• K31114151: Error Message: 01070734:3: Configuration error: Invalid mcpd context, folder not found (<folder>)

Error message is logged to the console and /var/log/ltm when attempting to execute a Linux command line command when within the TMSH shell.
