Description
You receive an error similar to the following:

01220001:3: TCL error: /Common/iRule-example <CLIENT_ACCEPTED> - Error: iStat for table 'ltm_rule' column 'col' cannot be added as row size '4348' is too long (line 1) invoked from within "ISTATS::set "ltm.rule iRule-example string col" "foo""

Environment

  • BIG-IP
  • iRule using iStats commands

Cause
The number of iStats entries (by "measure name") for a given object type is limited by the storage space available for iStats and the type of entries created. The space available is approximately 4000 bytes.

Recommended Actions
Avoid the use of string measures in iStats where possible.
