Issue

Description

Network Access creates a series of internal virtual servers (listeners) that can process traffic before the packet egresses. The role of these listeners is to:

  • provide an additional enforcement point for BIG-IP APM access control lists (ACLs) if configured.
  • forward IP addresses (and translate if needed) to the destination IP address rather than load balancing the traffic to a pool.

Environment

  • Network Access
  • Connectivity profile
  • Internal virtual servers 

Cause

None

Recommended Actions

None

Additional Information

BIG-IP APM Network Access uses the connectivity profile attached to the ingress virtual server along with the internal VPN/PPP proxy and lease pool in order to remove the PPP encapsulation from the client and forward it on to the LAN. There are a series of internal virtual servers and administrator-defined, layered virtual servers that can process the traffic before the packet egresses to the LAN. Returning traffic and traffic initiated from the back-end is processes by a special listener called an ephemeral listener, which forwards traffic to a client side tunnel.
