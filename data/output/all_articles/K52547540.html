Topic

This article applies to BIG-IP APM 13.1.0 and later. Beginning in BIG-IP 13.1.0, APM Clients lets BIG-IP APM administrators update the Edge Client version on the BIG-IP system without needing to upgrade the entire BIG-IP system. 

You should consider using these procedures under the following conditions:

  • You are a BIG-IP APM administrator.
  • You want to update the Edge Client VPN software on the BIG-IP system.

After updating the APM Client VPN software on the BIG-IP system, you should perform one of the following tasks to update the VPN software on your users' clients as well:

  • Set the Component Update value to Yes (default value: Yes) in the affected connectivity profile to automatically update connecting client systems.
  • Refer to K44328534: BIG-IP administrator instructions for downloading BIG-IP Edge Client for Windows and Mac OS X, and Linux clients to download the updated BIG-IP Edge Client package. With the updated BIG-IP Edge Client package, you can distribute it to your end users by performing the procedure in K05816648: Enabling end user access to download the BIG-IP Edge Client for BIG-IP APM.

Note: After updating the APM Clients software on the system, you can remove the ISO file from the system.

Note: The BIG-IP Edge Client for Linux (f5fpc) is a command line utility, and it does not include the same feature set of the Windows and Mac OS X clients. For more information, refer to K23653432: BIG-IP APM client feature matrix.

Description

Prerequisites

You must meet the following prerequisites to use these procedures:

  • Your BIG-IP system is running BIG-IP APM 13.1.0 or later.
  • You have credentials to log in to the F5 website.

Procedures

  • Download BIG-IP APM Clients from F5.com
  • Upload and install the ISO image file to the BIG-IP system
  • Set the Component Update to Yes in the connectivity profile

Note: When upgrading the BIG-IP system, the version of the APM Clients ISO file that is shipped with the BIG-IP software ISO file automatically becomes the active APM Clients version. For example, when you upgrade a system running BIG-IP 15.1.1 with APM Clients version 7.2.1 active to BIG-IP 15.1.2, the active APM Clients version after the upgrade automatically becomes 7.1.8.4, the version that is shipped with BIG-IP 15.1.2. You should verify the active APM Clients version after a BIG-IP software upgrade and update your APM Clients version as appropriate. For more information on BIG-IP and APM Clients version, refer to K13757: BIG-IP Edge Client version matrix.

Download BIG-IP APM Clients from F5.com

Impact of procedure: Downloading BIG-IP APM Clients consumes approximately 300 megabytes (MB) of bandwidth and disk space.

  1. Go to https://my.f5.com/manage/s/downloads

    When the F5 Login page displays, log in.

  2. On the Select a product family option select BIG-IP.
  3. On the Product Line option select APM Clients.
  4. On the Product Version option select your version.
  5. In Software Terms and Conditions click the I Accept button.
  6. On the Select a Download page, select the ISO file, select your region, and then complete the steps to download the file.

    Note: You have the option to use the included MD5 utility to validate the checksum. For more information, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.

    Note: If you have enabled automatic image verification on the BIG-IP system, you also need to download the associated SIG file for the APM Clients ISO file that you are downloading. For information, refer to K24341140: Verifying BIG-IP software images using .sig and .pem files and K15225: Enabling signature verification for BIG-IP ISO image files.

Upload and install the ISO file to the BIG-IP system

Impact of procedure: This procedure consumes approximately 300 MB on your BIG-IP system.

  1. Log in to the BIG-IP system.
  2. Go to System > Software Management > APM Clients > Import.
  3. On the New Image page, browse to the ISO file you downloaded, and then select Import.
  4. After The upload of image has completed message displays, select OK.
  5. On the next page, in the list of client images uploaded to the system, select the check box for the APM Clients image you just uploaded, and then select Install.
  6. On the Software Image page, select Install.
  7. The Installed Image area at the top of page indicates the currently active image that will be delivered to users.

Notes:

  • The System Default on the available images page indicates the version included with your version of the BIG-IP system, not the currently active version.
  • You may upload images older than the System Default, but you cannot install them.
  • When clients connect to the BIG-IP system, they are updated with the new components.
  • Any new client packages that you generate from the BIG-IP administrator page contain the new client version.
  • In a high availability (HA) environment, you must update each BIG-IP system with the new client version.
  • In a multi-blade cluster environment on a chassis system, the system automatically replicates the client to the peers.

Use command line installation

Alternatively, after uploading the ISO file, you can use the TMOS Shell (tmsh) to install and obtain the status of the BIG-IP APM Clients image from the command line interface. The following commands below are now available for these purposes.

  1. The following command lists the client images available on the system:

    tmsh list /apm client image

  2. Upload the BIG-IP APM Clients image to the BIG-IP APM  /shared/apm/images directory.
  3. Enter the following command syntax to install a new BIG-IP APM Clients image on the system:

    tmsh install /apm client image <apmclients-version.iso>

    Note: Replace <apmclients-version.iso> with the APM Clients ISO image name.

  4. Enter the following command to list the currently active BIG-IP APM Clients image on the system:

    tmsh list sys db apm.client.version

For more information, refer to the Traffic Management Shell (tmsh) Reference Guide.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Set the Component Update to Yes in the connectivity profile

Impact of procedure: This updates the Edge Client VPN software version on your users' client devices to match the APM Clients version on the BIG-IP APM system.

  1. Log in to the BIG-IP system.
  2. Go to Access > Connectivity / VPN > Profiles.
  3. Select the name of the connectivity profile associated with your network access virtual server.
  4. Select Edit Profile.
  5. Select Win/Mac Edge Client.
  6. For Component Update, select yes.
