Description

The /var/log partition is growing, with files in /var/log/ts and /var/log/avr failing to rotate.

The following message is observed frequently in /var/log/messages:

notice logrotate[46190]: ALERT exited abnormally with [1]

Messages similar to the following may also be observed in /var/log/ts/cron.log:

error: error creating output file /ts/log//asm_config_server.log.1: File exists

Environment

  • Logging
  • ASM & AVR logrotate
  • Disk space

Cause

  • ID799749, ID908065

The presence of log files ending in .1 causes this issue. This may be because an archived log file was unzipped, for example, with:

Important: This command is an example of something that causes the issue. It does not fix the issue.

gunzip /var/log/avr/monpd.log.1.gz

Recommended Actions

To work around the issue, delete the files ending in .1 from /var/log/ts and /var/log/avr.

Note: To avoid loss of information concerning historical system events, it's recommended to back up the log files first.

rm -rf /var/log/ts/*.1

rm -rf /var/log/avr/*.1

If the issue returns or happens frequently, open a Service Request with F5 Support and request an Engineering Hotfix.
