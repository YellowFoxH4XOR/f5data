Description

After Microsoft April patches our clients can't connect. Access profile is using certificates for machine and user auth. Edge Clients' versions are 7245 or 7246.

EdgeClient log says

Environment

  • BIG-IP APM 16.1.4.1
  • Machine Cert Auth
  • 2024 Microsoft April patch
  • Edgeclient
  • VPN

 

Cause

  • Machine cert on client need to be renewed with the same key.

 

Recommended Actions

  • Renew the machine cert on client with the same key.
