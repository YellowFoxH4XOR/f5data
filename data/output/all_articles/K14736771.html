Recommended Actions

  1. Log in to bash.
  2. # tmsh create /net vlan <vlan name> interfaces add <interface number>
  3. # tmsh create /net self <self IP name> address <IP address> vlan <vlan name>
  4. # tmsh delete /net self <self IP name>
  5. # tmsh delete /net vlan <vlan name>
