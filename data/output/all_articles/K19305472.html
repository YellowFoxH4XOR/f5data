Description

This describes how to view CPU usage statistics on the BIG-IP as broken down into the Data Plane, Control Plane and Analysis Plane categories via the Configuration Utility (GUI).

Environment
Per-plane CPU usage statistics are only available for BIG-IP physical devices (including vCMP guests). vCMP hosts do not have per-plane CPU statistics as their resources are provided to vCMP guests. Virtual Edition BIG-IPs do not currently have per-plane CPU statistics.

Cause
N/A

Recommended Actions

Displaying per-plane CPU statistics via GUI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Configuration Utility
  2. Navigate to Statistics -> Performance Reports -> Performance Reports
  3. Go to the System CPU Usage graph
  4. Click the hyperlink for View Detailed Graph
  5. Per-plane CPU usage is provided in the Plane CPU Usage graph
