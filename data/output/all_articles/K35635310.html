Description

List of SMTP authentication methods supported in SMTP profile when protocol security is enabled.

Environment

  • SMTP protocol profile with Protocol Security enabled 

Cause

None

Recommended Actions

The BIG-IP ASM  supports only single-line SMTP authentication methods such as "AUTH PLAIN".

SMTP authentication methods which are not supported are "AUTH LOGIN", "AUTH CRAM-MD5" .
Hence If a non-supported authentication method is used in SMTP server, there may be connectivity issue noted when traffic goes through virtual server.
