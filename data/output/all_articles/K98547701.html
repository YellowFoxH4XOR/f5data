Known Issue

Source address affinity persistence may fail when used in conjunction with the Match Across Virtual Servers setting.

This issue occurs when all of the following conditions are met:

  • A source address affinity persistence profile is configured with the Match Across Virtual Servers setting.
  • The persistence profile is associated with multiple virtual servers that are configured to reference different destination pools.
  • Persistence entries for a user's IP address point to pool members that do not exist in the configured virtual server pool.

Impact

Source address persistence fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system incorrectly routes the return connection to an incorrect pool member.
  • User connections do not persist to the same pool member as expected.
  • Application content dependent on persistence does not render correctly or produces an error.
