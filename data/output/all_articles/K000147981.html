Description

According to VMware Images | F5 Distributed Cloud Technical Knowledge, CentOS for VMware has been deprecated, this article will tell you what you should do if you used CentOS and want to migrate to Red Hat Enterprise Linux for the VMware CE site.

Environment

  • F5® Distributed Cloud (XC)
  • Customer Edge

Answer/Recommended Actions

We don't support CE migration, for now so you need to create a new site with RHEL9 but in upcoming releases, F5 XC will allow customers to automatically upgrade the OS from CentOS to RHEL as part of the ‘OS upgrade’ workflow with the objective of providing a seamless upgrade experience. For the seamless auto-upgrade to RHEL; however, customer CE sites will need to meet specific prerequisites and pre-upgrade RHEL upgrade workflow. 
 
Once verified it is working then you can switch the workload or LB traffic to the new site.
