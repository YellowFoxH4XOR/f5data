Known Issue

This is the result of a known issue. When an NTLM profile is applied to a BIG-IP WebAccelerator-enabled virtual server, the BIG-IP WebAccelerator does not perform the expected ESI fragment assembly for responses. As a result, the web pages served by the virtual server render without the expected ESI fragments.

F5 Product Development tracked this issue as CR137673 and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
