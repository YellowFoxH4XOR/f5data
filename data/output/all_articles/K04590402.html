Description

Additionaly /var/log/ltm reports error simiar to:

The Bot Defense Signature (/Common/TBI project (1)) cannot be deleted because it is in use by a Bot Defense Profile Signature Staging (/TestENV_Prt/Bot_TestENV /Common/TBI project (1)).

Environment

  • BIG-IP ASM 15.1.x 

Cause

ID883853: Bot Defense Profile with staged signatures prevents signature update

Recommended Actions


As a resolution you can enforce staged signature, in this example: "/Common/TBI project (1)"
