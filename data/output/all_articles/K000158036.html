Topic

Versions from 7.2.7.1 have changed binary names and may need their dependenceies rechecking.  

Following the upgrade of Qt framework from version 5.5.1 to version 6.10, the F5VPN and F5 Endpoint Inspector applications require additional system libraries to launch successfully. These dependencies may already be present on some Linux desktop distributions but absent on others. The applications rely on these libraries for proper operation. This requirement applies to the following versions:

  • BIG-IP Edge Client for Linux version 7.2.6.2 and later.

Impact

If the required system libraries are not installed, the F5VPN and F5 Endpoint Inspector applications will fail to launch.

Workaround

Install the necessary system libraries on the Linux operating system before launching F5VPN or F5 Endpoint Inspector.
This is a standard system dependency requirement for the new upgraded client. Ensure all prerequisites listed in the installation documentation are met before deploying the APM Linux Client.

How to identify missing packages for deb file

If the APM Linux Client fails to launch, it is likely due to some missing system packages. On Ubuntu, the presence of required packages can be verified, and any missing ones can be installed with the following commands. These commands should be executed after completing the installation of F5VPN or F5 Endpoint Inspector using the dpkg command.

Incase of F5VPN deb file

  1. Traverse to the F5VPN application directory
    cd /opt/f5/vpn/
  2. Check for missing libraries for the f5vpn binary
    ldd f5vpn | grep not
  3. Install the missing libraries
    sudo apt install <missing lib1> <missing lib2> ... 
  4. Check for missing libraries in the lib folder of the F5VPN application directory
    ldd lib/libQt* | grep not
  5. Install the missing libraries
    sudo apt install <missing lib1> <missing lib2> ...  
  6. Check for missing libraries in the plugins directory of the F5VPN application directory
    ldd plugins/xcbglintegrations/lib* | grep not 
  7. Install the missing libraries
    sudo apt install <missing lib1> <missing lib2> ...
  8. Check for missing libraries in the platforms directory of the F5VPN application directory
    ldd platforms/lib* | grep not
  9. Install the missing libraries
    sudo apt install <missing lib1> <missing lib2> ...
  10. Cross check for the missing libraries by running steps 2,4,6,8 to ensure that all the libraries are properly installed.

Note : To simplify the process, all missing packages can be installed together in one step by identifying the required dependencies using steps 2,4,6,8 and running a single installation command.
            sudo apt install <missing lib1> <missing lib2> ... 
                        OR

                <missing lib1> \
                <missing lib2> \
                <missing lib3> \
                ...
                <missing libn>

How to identify missing packages for rpm file

When installing an RPM package (unlike a DEB package), the installer automatically identifies and reports any missing dependencies during the installation process. These commands should be executed during the installation of the F5VPN or F5 Endpoint Inspector application. Using the dnf command ensures that the application is installed along with any required dependencies. 

Incase of F5VPN rpm file

  1. The dependencies required by the F5VPN may only be available in the EPEL (Extra Packages for Enterprise Linux)
    sudo dnf install -y epel-release
  2. Enable CRB repository to provide access to development libraries required for compiling dependencies
    sudo dnf config-manager --set-enabled crb
  3. Traverse to the Downloads directory for the installation of F5VPN (This might differ based on the current folder from which you are running the command)
    cd Downloads
  4. To identify the missing packages during the installation itself
    sudo rpm -ivh linux_f5vpn.x86_64.rpm
  5. To install the missing packages along with the F5VPN installation
    sudo dnf install linux_f5vpn.x86_64.rpm 
  6. Cross check for any missing packages. The following command should return an empty response.
    ldd /opt/f5/vpn/f5vpn | grep no

Incase of F5 Endpoint Inspector rpm file

  1. The dependencies required by the F5 Endpoint Inspector may only be available in the EPEL (Extra Packages for Enterprise Linux)
    sudo dnf install -y epel-release
  2. Enable CRB repository to provide access to development libraries required for compiling dependencies
    sudo dnf config-manager --set-enabled crb
  3. Traverse to the Downloads directory for the installation of F5 Endpoint Inspector (This might differ based on the current folder from which you are running the command)
    cd Downloads
  4. To identify the missing packages during the installation itself
    sudo rpm -ivh linux_f5epi.x86_64.rpm
  5. To install the missing packages along with the F5 Endpoint Inspector installation
    sudo dnf install linux_f5epi.x86_64.rpm
  6. Cross check for any missing packages. The following command should return an empty response.
    ldd /opt/f5/vpn/f5epi | grep not
