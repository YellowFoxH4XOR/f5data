Known Issue

This is the result of a known issue. When a pre-logon sequence is enabled on the FirePass controller, FirePass does not provide the appropriate error message when the master group concurrent session limit has been exceeded. Alternatively, after a user attempts to log on, the following message briefly appears on the screen before the user is redirected to the pre-logon sequence:

Rejecting...

When no pre-logon sequence is enabled, FirePass correctly displays the following message when the master group session limit is exceeded:

The number of concurrent sessions exceeds the limit for this group!

Note: Master group concurrent session limits are enabled by selecting the Limit the number of concurrent sessions for this group check box on the Users > Groups > Master Groups page under the General tab.

F5 Product Development tracked this issue as CR135569 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-2 issued for FirePass 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
