Known Issue

The BIG-IP system may respond to some Secure Sockets Layer (SSL) connection requests with an SSL handshake failed message, and then close the connection. This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with a virtual server that has a Client SSL profile associated.
  • The BIG-IP system receives an SSL handshake ClientHello request from a client that has the Protocol Version set to 3.2 (TLSv1.1) or 3.3 (TLSv1.2).

The expected behavior is for the BIG-IP system to respond with a ServerHello message using the Transport Layer Security (TLS) version 1.0, since BIG-IP SSL profiles do not currently support TLS version 1.1 and 1.2 in the native SSL stack.

Impact

The BIG-IP system will prematurely close affected SSL connections.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H380456 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system logs an entry to the /var/log/ltm file. The entry appears similar to the following example:

    01260013:6: SSL Handshake failed for TCP from <virtual server> to <client>

    In this log entry, note the following:

    • <virtual server> is the virtual server that has a Client SSL profile associated and is processing the client request; it is in the following format:

      IP address:port
    • <client> is the client that sends TLS version 1.1 or 1.2 ClientHello request; it is in the following format:

      IP address:port
  • The BIG-IP system closes the client connection. For example, if you capture a tcpdump on the client-side, the tcpdump capture will show the BIG-IP system responding to the ClientHello request with a handshake failed message, followed by the TCP connection closing sequence.
