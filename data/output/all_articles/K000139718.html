Description

You are unable to load a UCS file on the device with the following error:

Saving active configuration...
Current configuration backed up to /var/local/ucs/cs_backup.ucs.
/var/tmp/configsync.spec: Error installing package
Config install aborted.
Unexpected Error: UCS loading process failed.

 

Environment

  • BIG-IP
  • UCS file

Cause

The UCS file is corrupted.

 

Recommended Actions

There are two option to resolve that problem

1) Load some other UCS known to be working.

2) Create base config on the BIG-IP (self-IP's, any partitions, route-domains, HA config) and then sync config from another peer of the HA group.
