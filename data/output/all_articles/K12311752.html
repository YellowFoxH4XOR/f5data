Description

Before disposing of a unit for redeployment you can wipe the drives to reduce the likelihood of any data being recovered

Environment
Any BIG-IP appliance.

Cause

To more securely erase the hard drives than just a clean software install you can use TMOS maintenance and the shred command

Recommended Actions

  1. Connect via the serial console.
  2. Reboot the BIG-IP.
  3. While the BIG-IP is restarting, you must press a keyboard key to interrupt auto-boot. After the GNU GRUB menu appears, immediately press the down arrow key and select TMOS maintenance.
  4. Once BIG-IP is fully booted up, login as the root user and run the command:

    shred -vfz /dev/sda

    Note: If you boot the BIG-IP into single user mode, you may not be able to run this command.

  5. If the unit has RAID array, then repeat on other drives.

    For instance,

    shred -vfz /dev/sdb

    Important: The unit will no longer boot once this is complete and needs to be clean installed via USB key or DVD drive.

Additional Information

The shred command will write 3 passes of random data and then overwrite with 0s if the z option is given. You can specify more passes with the -n option.

According to NIST SP 800-88r1 this shred command is sufficient to be used as a purge on ATA style disks.  For SSD disks it only serves as a clear.
