Issue

Error Message

012a0004:4: getRegKey error: VictoriaSeepromDev: Object 0x6a is not programmed in SEEPROM

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You attempt to join a new or replacement blade to an existing VIPRION cluster.
  • The VIPRION system encounters a licensing failure and is unable to read the chassis registration key Serial EEPROM (SEEPROM) value.

    Additionally, the tmsh show sys hardware command output displays a 0xFFFF chassis registration key value that indicates an invalid license. The Chassis Information section of the command output appears similar to the following example:

    Chassis Information
    Maximum MAC Count 2
    Registration Key    FFFFF-FFFFF-FFFFF-FFFFF-FFFF

Impact

The VIPRION system will not allow a new or replacement blade to join the cluster.

Recommended Actions

To recover from this issue, relicense the VIPRION system to restore the correct registration key SEEPROM value. Once the system updates the license and the SEEPROM, the new blade will be allowed to join the cluster.
