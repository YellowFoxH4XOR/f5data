Topic

The Autolaunch based on endpoint protection feature automatically opens a Network Access connection after a user logs on to the FirePass controller webtop, providing that the user passes any endpoint security requirements. This feature does not automatically open a Network Access connection if a user logs on to the FirePass controller using the standalone VPN client.

When a user logs on to the FirePass controller using the standalone VPN client in Simple Mode, the VPN client automatically opens the first available Network Access connection. When a user logs on to the FirePass controller using the standalone VPN client in Advanced Mode, the VPN client does not automatically open a Network Access connection. In Advanced Mode, the VPN client displays a list of available Network Access connections in the left navigational panel located below Favorites: Network Access Connections. The user can then select a connection from the list to open the desired Network Access connection.

Creating icons to connect to specific FirePass controllers with the standalone VPN Client

To create an icon to connect to a specific FirePass controller with the standalone VPN client, perform the following procedure:

  1. Open the standalone VPN client.

  2. Log on to the desired FirePass controller.

  3. In the VPN client toolbar, select Session -> Save Session.

  4. Select a location to save the icon.

  5. Click the Save button.

When you double-click the icon you just created, the standalone VPN client will launch and connect to the FirePass controller you specified in step 2.

Creating icons to open specific Network Access connections with the standalone VPN Client

To create an icon to open a specific Network Access connection with the standalone VPN Client, perform the following procedure:

  1. Open the standalone VPN client.

  2. Log on to the desired FirePass controller.

  3. In the VPN client toolbar, select View -> Switch to Advanced Mode.

  4. Locate the desired connection under Favorites : Network Access Connections in the left navigational panel.

  5. Drag and drop the connection you located in Step 4 to the desired location on your machine.

When you double-click the icon you just created, the standalone VPN client will launch and connect to the Network Access connection you selected in step 5.
