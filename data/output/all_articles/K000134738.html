K000134738: HTTP::payload command is not collecting data

Type
Support Solution
Published
2023-05-23
Updated
2023-05-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000134738

Description

When you use the HTTP::payload command without collecting the data with HTTP::collect before, the HTTP::payload returns only the HTTP body that's present in the first packet of the HTTP request.

In consequence, if there's no HTTP body in the first packet (i.e. there are only HTTP headers) HTTP::payload will return an empty string.


Environment

- LTM

- iRule

- HTTP::payload command


Cause

n/a


Recommended Actions

As per the documentation, the intended usage is to first use HTTP::collect and then access the data with HTTP::payload.

These commands should be used together for expected results.

For example:

-----

when HTTP_REQUEST {

HTTP::collect 1500

}


when HTTP_REQUEST_DATA {

log local0. "Payload: [HTTP::payload]"

}
