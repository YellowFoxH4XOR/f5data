Description
As IPv6 packets rely on Next Header field to indicate the upper layer type, it is possible that between the IPv6 header and the ICMPv6 header, there are other extension headers. To capture ICMPv6 traffic, the filter used in the tcpdump command needs to take this into account.

Environment
This article applies when ICMPv6 traffic needs to be captured.

Cause
As IPv6 header may specify an extension header which then references ICMPv6 header instead of specifying ICMPv6 header directly, the 'icmp6' filter may not capture all relevant traffic.

Recommended Actions
To capture ICMPv6 traffic on TMM interfaces, run the following command:

# tcpdump -i 0.0:nnn "ip6 protochain 58" -s 0 -w /var/tmp/K11308743.pcap
