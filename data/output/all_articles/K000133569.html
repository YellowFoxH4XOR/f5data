K000133569: "limit_rate" directive does not work with "proxy_buffering off"

Support Solution
Published

Updated
2023-04-19

  • NGINX Plus: R28, R27, R26, R25, R24, R23, R22, R21, R20, R19, R18, R17, R16, R15, R14, R13

Description

"limit_rate" does not work when "proxy_buffering off" is configured on NGINX Plus.

Environment

- NGINX Plus

- Both "limit_rate" and "proxy_buffering off" are configured

Cause

This is by design.

Recommended Actions

None
