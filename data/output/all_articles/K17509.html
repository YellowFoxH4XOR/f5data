Known Issue

The mcpd process may restart when loading a configuration.

This issue occurs when the following condition is met:

  • You attempt to load a configuration that takes a long time to complete the validation stages.

When loading a configuration, the system goes through several stages of validation before actually loading the configuration. The mcpd process updates the high availability (HA) heartbeat monitor after each stage validation. However, each stage of the validation is recursive and, therefore, takes longer to complete and may exceed the mcpd heartbeat timeout. For example, when validating a large configuration with iRules, the validation may take longer to complete than what is allotted for the mcpd heartbeat timeout. As a result, the sod process will restart the mcpd process.

Note: For multi-blade VIPRION systems, the validation occurs on both the primary blade and any secondary blades.

Impact

Attempts to load the configuration fail. The BIG-IP system temporarily stops processing traffic, and may fail over if paired with other BIG-IP systems.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to load the configuration, the mcpd service times out.
  • The configuration fails to load, the mcpd service restarts and produces a core file in the /var/core directory.

Workaround

To work around this issue, you can first try reloading the configuration. If the configuration continues to fail to load, you can temporarily disable heartbeat monitoring for the mcpd process, load the configuration, then re-enable heartbeat monitoring. To do so, perform the following procedure:

Impact of workaround: While heartbeat monitoring is disabled for the mcpd process, the system will not take a failover action in the event of an actual mcpd failure.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Disable the mcpd heartbeat by typing the following command:

    mod sys daemon-ha mcpd heartbeat disabled

  3. Load the configuration by typing the following command:

    load /sys config partitions all

  4. Re-enable the mcpd heartbeat by typing the following command:

    mod sys daemon-ha mcpd heartbeat enabled

    Note: For more information about configuring the daemon-ha setting, refer to the help screen available by typing the tmsh help /sys daemon-ha command.
