Known Issue

This is the result of a known issue. When installing a version 10.x hotfix on a BIG-IP system, both the hotfix ISO image and base software ISO image must be present in the /shared/images directory for the installation to proceed. This behavior is by design.

If you attempt to install a version 10.x hotfix and the base software ISO image is not present in the /shared/images directory, the hotfix installation process does not proceed, and the Configuration utility and bigpipe software command output reports a misleading message that appears similar to the following example:

waiting for image (BIG-IP 10.1.0 3402.0)

Note: The example message is misleading because it reports that the system is waiting for the hotfix build number, when it should report that the system is waiting for the base software ISO image.

For example, if you attempt to install the version 10.1.0 HF-2 hotfix image on a BIG-IP version 10.1.0 partition, the following files must be present in the /shared/images directory:

  • The version 10.1.0 base software ISO image.

    For example:

    BIGIP-10.1.0.3341.0.iso
  • The version 10.1.0 HF-2 hotfix image.

    For example:

    Hotfix-BIGIP-10.1.0-3402.0-HF2.iso

F5 Product Development is tracking this issue as ID 225815.

Workaround

You can work around this issue by copying the base ISO image to the /shared/images directory and attempting to install the hotfix again.

For more information about managing hotfixes for BIG-IP version 10.x, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
