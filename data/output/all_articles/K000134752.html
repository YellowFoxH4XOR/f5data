K000134752: Error messages when uploading QKview from BIG-IQ

Issue

Error Message

404 – Doesn’t Exist

Environment

BIG-IQ version 8.2.0 and earlier

Note: A fix has been introduced in BIG-IQ version 8.3 with the new iHealth API Token Service.

Message Location

You may encounter this message in the following BIG-IQ User Interface locations:

  • System > This Device > Big-IQ iHealth > Tasks > Select "QKView Upload"
  • Monitoring > Reports > Device > iHealth > Tasks >  Select "QKView Upload"
  • Monitoring > Reports > Device > iHealth > Tasks > Select a failed task

Description

This message could appear under the following conditions:

  • You attempt to upload QKview files from a BIG-IQ version that does not have the new iHealth API Token Service implemented.

Impact

The QKView file is failed to be uploaded to iHealth from the BIG-IQ device with a 404 error message. 

Recommended Actions

  • Download and install the latest BIG-IQ update that includes the new iHealth API Token Service (BIG-IQ 8.3 and later).
  • You can download the QKView file to a local machine and manually upload the QKView file to iHealth, To do so, perform the following procedure:
    1. Generate the QKView from BIG-IQ 
      • Log in to the BIG-IQ command line.
      • To run the qkview utility, enter the following command:

        qkview

      • The output file name displays after the command has completed.
    2. Download the last generated QKView from the filesystem in BIG-IQ to a local machine
      • Collect the output file from the /var/tmp directory by copying the file to an external host using a utility such as ftp or scp
    3. Login to iHealth2.f5.com, select Upload in the banner, and upload the QKView to iHealth.
