Description
BIG-IP can close connection using FIN,ACK when receives TLS Client Hello from client.

No logs are generated.

Packet capture can show similar behavior to the one below:

6    10.101.1.101    10.127.84.141    1571    0    TLSv1    736        IN  s1/tmm0 : Client Hello    18955    443    65535    65535
7    10.127.84.141    10.101.1.101    1571    0    TCP    219        OUT s1/tmm0 : [TCP Out-Of-Order] 443 → 18955 [FIN, ACK] Seq=1 Ack=...

Environment

  • BIG-IP SSL profile with CRL check (local)

Cause

Bug ID 964673: CRL with duplicate entries is allowed to be uploaded, but later unable to pass traffic due to 'invalid profile'
CRL file is containing duplicate entries.

Recommended Actions

Inspect CRL file and remove duplicates or recreate CRL bundle.

Additional Information

None.
