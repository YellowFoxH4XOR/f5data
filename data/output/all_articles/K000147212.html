K000147212: How do I migrate my Delegated Domains to Primary DNS?

Type
Support Solution
Published
2024-11-08
Updated
2025-10-28
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147212

Description

  • You have a domain delegated in Distributed Cloud (XC)
  • Domain delegation has been deprecated
  • Existing delegated domains will need to be migrated to XC Primary DNS

Environment

  • Distributed Cloud
  • Domain Delegation
  • Primary DNS

Resolution/Answer

Note: During the migration process, you should NOT make any changes to the Load Balancers

To get the F5 team to help you migrate your delegated domains:

  1. Open a ticket through the XC Console to Support asking them to migrate your delegated domains - How to contact F5® Distributed Cloud Support
    • If you're using DNSSEC, you will have to disable it before performing the migration:
      this is done by removing the 'DS' record in the parent zone (usually through your registrar portal).
  2. Wait for the Support team to confirm that they have cloned the DNS zones from the Delegated Domains to XC Primary DNS and that they have migrated the TCP/HTTP Load Balancers to use XC DNS
  3. Update your registrar (or parent zones) by changing the NS records with your DNS provider to:
    1. Remove ns1.volterradns.io, ns2.volterradns.io, ns3.volterradns.io, and ns4.volterradns.io 
    2. Add ns1.f5clouddns.com and ns2.f5clouddns.com 

      Note: this change may take a few days to be completed.

  4. Validate that the domains are working correctly by running the below commands for each of the domains replacing the <domain> value: 
    • dig <domain> NS +short
    • This should give you the aforementioned ns1/ns2.f5clouddns.com Distributed Cloud DNS name servers
  5. You will need to disable the zone in Delegated Domains once they validate that the parent zones contain the ns1/ns2.f5clouddns.com records
  6. (Optional) Re-enable DNSSEC in XC Primary DNS once the migration is over - if you had disabled it as part of step 1.

Cause

  • Delegated Domains is a feature in XC which allows automatically creating DNS records when creating a HTTP Load Balancer

  • This feature was limited to just that: you could not manage the delegated DNS zone, nor see its content

  • With the ability of Primary DNS in XC you can keep the automatic creation of DNS records when adding an HTTP LB, while:

    • also fully managing the DNS zone content – add/modify/delete records, and also seeing records created from the HTTP LB

    • having access to DNS Requests Logs, and to XC DNS Dashboards - thus giving a lot more insight into your DNS usage

Additional Information

  • The Delegated Domains feature was disabled in October 2023
  • During the migration there won't be any disruption in traffic or to the load balancer
  • We recommend performing the migration during non-working hours (or low-volume period) to minimize risks
  • F5 will support the migration efforts until the end of April 2026
