Description

Increasing the MTU size from 1500 to 9000 bytes (enabling jumbo frames) on VLANs configured on BIG-IP LTM can result in authentication failures for services such as RADIUS load balancing to Cisco ISE servers. Symptoms include wireless users being unable to connect or authenticate through the affected service. The issue is resolved by reverting the MTU back to 1500 bytes. Authentication failures may occur without specific error messages, but widespread connectivity issues are observed.

Environment

  • Product: BIG-IP LTM
  • Configuration: VLAN MTU increased from 1500 to 9000 bytes (jumbo frames enabled)
  • Services: RADIUS load balancing to Cisco ISE servers; wireless controllers as clients

Cause

An MTU mismatch exists somewhere along the network path between the wireless controllers, BIG-IP, and ISE servers. If any device in this path does not support or is not configured for jumbo frames (MTU 9000), packets may be dropped or fragmented incorrectly. Since RADIUS uses UDP, it is particularly sensitive to packet loss or improper fragmentation, resulting in authentication failures.

Recommended Actions

  • Before increasing VLAN MTU, verify that all devices (switches, routers, firewalls, servers) between clients, BIG-IP, and backend servers support and are configured for the same MTU.
  • Use packet captures on BIG-IP and other network devices to check if RADIUS packets are being dropped or fragmented.
  • Test end-to-end jumbo frame support using ping with large payloads and "do not fragment" set.
  • Incrementally increase MTU size and test at each step if jumbo frames are required.
  • Ensure ICMP "Fragmentation Needed" messages are allowed through the network for proper Path MTU Discovery.
  • Validate interface and VLAN configuration on BIG-IP using tmsh show net vlan and tmsh show net interface.
  • Confirm that ISE servers and all intermediate network devices are configured for MTU 9000.
  • If issues persist after verifying all configurations, revert the MTU setting to 1500 bytes while investigating further.
