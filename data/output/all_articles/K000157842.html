K000157842: Failure for data/openconfig-system:system/f5-mgmt-ip:mgmt-ip

Type
Support Solution
Published
2025-11-13
Updated
2026-08-25
Applies to
  • F5OS Products
  • F5OS-C: 1.8.2, 1.8.1
Source
https://my.f5.com/manage/s/article/K000157842

Description

The system controllers act as an active-standby pair for system management. When the standby controller is accessed directly using its uniquely assigned IP address, an error similar to the one shown below appears on the Dashboard:

Server Error(s)

---------------------------------------------------------------------------------------------------------------------------------------------

Failure for data/openconfig-system:system/f5-mgmt-ip:mgmt-ip?with-defaults=report-all API. The server or an underlying service is unreachable.

Failure for data/f5-system-partition:partitions?with-defaults=report-all API. The server or an underlying service is unreachable.

error-message : Failure for data/f5-system-partition:partitions?with-defaults=report-all API. The server or an underlying service is unreachable.
original-error : Network Error

Environment

  • F5OS-C (VELOS) 1.8.1 , 1.8.2
  • System controller high availability
  • System Controller Management

Cause

Direct access to the standby controller’s GUI, CLI, or API is not supported.

Recommended Actions

The system controller floating management IP address should always be used, as it connects to the active controller.

Additional Information

Enhancement requests (IDs 1572133 and 1933761) have been opened to support planned improvements for clearer messaging or potential behavioral change in a future release.
