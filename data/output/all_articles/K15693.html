Issue

Old Behavior

In versions prior to BIG-IP 11.5.0, when the bigd TCP handshake timeout period of 20 seconds expires, a new TCP connection is created without sending a TCP Reset (RST) packet to the monitored pool member.

In the following example, packet 4 shows a new TCP connection being created without a TCP Reset (RST) packet being sent:

1 0.000000    10.12.23.120          10.12.23.29           TCP      85     36995 > http [SYN] Seq=3013869846
2 2.999774    10.12.23.120          10.12.23.29           TCP      85     36995 > http [SYN] Seq=3013869846
3 8.999702    10.12.23.120          10.12.23.29           TCP      85     36995 > http [SYN] Seq=3013869846
4 20.999661   10.12.23.120          10.12.23.29           TCP      85     36995 > http [SYN] Seq=3057904749
5 44.999597   10.12.23.120          10.12.23.29           TCP      85     36995 > http [SYN] Seq=3108232749

New Behavior

Beginning in BIG-IP 11.5.0, when the bigd TCP handshake timeout period of 20 seconds expires, a TCP Reset (RST) packet is sent to the monitored pool member prior to creating a new TCP connection.

In the following example, packet 6 shows a TCP Reset (RST) packet being sent, and packet 7 shows a new TCP connection being created:

1 0.000000    10.12.23.120          10.12.23.29           TCP      81     60746 > http [SYN] Seq=2995623477
2 1.000592    10.12.23.120          10.12.23.29           TCP      81     60746 > http [SYN] Seq=2995623477
3 2.999963    10.12.23.120          10.12.23.29           TCP      81     60746 > http [SYN] Seq=2995623477  
4 7.000307    10.12.23.120          10.12.23.29           TCP      81     60746 > http [SYN] Seq=2995623477
5 14.998997   10.12.23.120          10.12.23.29           TCP      81     60746 > http [SYN] Seq=2995623477  
6 23.382215   10.12.23.120          10.12.23.29           TCP      61     60746 > http [RST, ACK] Seq=2995623477  
7 24.938799   10.12.23.120          10.12.23.29           TCP      81     60762 > http [SYN] Seq=3506546766

F5 Product Development tracked this change as ID 434941.

Impact

Both the BIG-IP and remote servers being monitored will remove connection table entries in a timelier manner, offering a slight improvement to memory management.

Recommended Actions

None
