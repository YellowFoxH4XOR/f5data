Known Issue

The Traffic Management Microkernel (TMM) may produce a core file when you configure BIG-IP APM for Security Assertion Markup Language (SAML) on BIG-IP 2000 or 4000 series platforms.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system as a SAML service provider (SP).
  • You enable SAML signature verification in the BIG-IP APM system.

BIG-IP 2000 and 4000 series platforms use hardware acceleration to increase performance. When these platforms use the BIG-IP APM system as a SAML SP, the hardware may accelerate synchronous RSA operations for signature verification, which causes the TMM process to exit and produce a core file.

Impact

The BIG-IP APM system may temporarily fail to process traffic while it recovers from TMM restarting. If you configure the device for high availability (HA), the system may fail over.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H440736 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP APM system stops processing traffic and potentially fails over to a standby system.
  • The BIG-IP APM system sends a SIGSEGV signal to TMM, which produces a core file in the /shared/core directory.
  • Stack trace messages appear in the /var/log/ltm file.

Workaround

To work around this issue, you can disable hardware acceleration for the affected platform. To do so, perform the following procedure:

Impact of workaround: This procedure involves restarting the TMM process, which causes a brief traffic disruption. Additionally, disabling hardware acceleration may have a negative impact on performance.

Disabling hardware acceleration on a BIG-IP 2000 or 4000 series platform

  1. Log in to the BIG-IP system as the root user.
  2. Type the following command:

    echo "device exclude 07:00.0;device exclude 08:00.0" >> /config/tmm_init.tcl

  3. Restart the TMM process by typing the following command:

    bigstart restart tmm

Re-enabling hardware acceleration on a BIG-IP 2000 or 4000 series platform

  1. Log in to the BIG-IP system as the root user.
  2. Delete the /config/tmm_init.tcl file by typing the following command:

    rm -f /config/tmm_init.tcl

  3. Restart the TMM process by typing the following command:

    bigstart restart tmm
