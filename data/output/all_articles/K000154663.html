Description

Configuring engine-ID for SNMPv3 traps on F5 rSeries Appliances.

Environment

F5OS - rSeries Appliance

Cause

On F5OS, the SNMPv3 engineID is auto-generated and not configurable via GUI (unlike TMOS), but can be set manually using CLI command as shared below:

system snmp engine-id config value <string, min: 5 chars, max: 27 chars> ipv4 ipv6 mac

It is a unique hexadecimal string that identifies the SNMP agent, which is normally determined by a combination of a pseudo-random number and chosen method. You can find the engine-ID by inspecting the traffic with a tool like Wireshark or command shared below

show system snmp engine-id

Note: By default it uses management interface mac-address to calculate the engine-id.
