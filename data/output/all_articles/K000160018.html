K000160018: MacOS VPN Connection Failure Due to SSL Certificate Chain Path Length Constraints on BIG-IP APM

Type
Support Solution
Published
2026-02-16
Updated
2026-02-16
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1, 17.5.0, 17.1.1
Source
https://my.f5.com/manage/s/article/K000160018

Description

MacOS users are unable to connect to VPN via BIG-IP APM, remaining stuck on the "waiting for endpoint inspection" status screen. Logs on the Mac client show SSL handshake failures, including "Unhandled ssl error: The basicConstraints path length parameter has been exceeded" and "SSL handshake failed." This is due to macOS enforcing strict basicConstraints pathlen validation in certificate chains, rejecting those that exceed the allowed path length.

Environment

  • BIG-IP APM
  • SSL profiles configured with a CA bundle containing multiple root and intermediate certificates
  • MacOS VPN clients

Cause

MacOS enforces strict validation of the basicConstraints pathlen parameter in SSL certificate chains. When the CA bundle assigned to the SSL profile contains multiple CAs and the chain exceeds the allowed path length, macOS rejects the chain during SSL handshake, resulting in connection failures for Mac clients.

Recommended Actions

  • Switch the SSL profile from using a full CA bundle to a single required CA, which resolves the issue for macOS users.
  • Limit CA bundles in SSL profiles to only include the necessary root and intermediate certificates, avoiding large bundles with multiple CAs unless required.
  • Use tools like OpenSSL or Keychain Access on macOS to inspect certificates for basicConstraints and pathlen values:
    Command: openssl x509 -in <certificate_file>.crt -text -noout
  • Check the X509v3 Basic Constraints section for pathlen.

Additional Information

MacOS is more strict than Windows regarding certificate chain validation, particularly with the basicConstraints pathlen parameter. Limiting the CA bundle to only required certificates and validating chain length constraints is critical for cross-platform compatibility.
