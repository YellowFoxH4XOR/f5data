Description

When migrating BIG-IP ASM configurations from iSeries to rSeries platforms using an SCF (Single Configuration File), the following error may occur during configuration load:

Data Input Error: Can't create "dynamic" type DoS signature.

This error is caused by the presence of "dynamic" type DoS signature configuration blocks in the SCF file, which are not supported for import on rSeries platforms. Only persistent DoS signatures can be imported.

Environment

  • Source: BIG-IP ASM, version 17.1.3, iSeries platform
  • Target: BIG-IP ASM, version 17.1.3, rSeries platform
  • Migration method: SCF file export/import
  • Configuration includes both persistent and dynamic DoS signatures

Cause

The error occurs because "dynamic" type DoS signature configuration blocks are present in the SCF file. Dynamic DoS signatures are system-generated and not intended for manual export/import; rSeries platforms only support persistent signatures for import. Attempting to import dynamic signatures results in a configuration load error.

Answer/Recommended Actions

To resolve the issue and successfully migrate your configuration:

  1. Manually edit the SCF file to remove all configuration blocks defining type dynamic under security dos dos-signature.
  2. Only retain persistent signature blocks (type persistent) for import.
  3. Optionally, convert dynamic signatures to persistent on the source system before export:
    • In the GUI: Security > DoS Protection > Signatures > Dynamic tab > Make Persistent.
  4. After editing, verify the SCF file syntax using:
    tmsh load sys config file <filename> merge verify
    on a test system.
  5. For future migrations, consider using the BIG-IP Journeys app to identify unsupported features and configuration parity gaps.
  6. Always take UCS and QKview backups of the source system before migration.

Step-by-Step Instructions for Editing SCF File:

  • Open the SCF file in a text editor (e.g., vim, nano, Notepad++).
  • Search for stanzas starting with: security dos dos-signature.
  • Within each stanza, look for: type dynamic.
  • Delete the entire block (from security dos dos-signature ... { to the closing }) if it contains type dynamic.
  • Save your changes and keep a backup of the original file.
  • Verify the edited file before importing.

There is no built-in SCF export option to automatically exclude dynamic signatures; manual conversion or removal is required.

Additional Information

  • Dynamic DoS signatures are system-generated and not intended for manual migration.
  • Only persistent signatures are supported for import on rSeries platforms.
  • Attempting to import dynamic signatures will result in configuration errors.
  • For further details on DoS signature configuration, refer to: security dos dos-signature.
