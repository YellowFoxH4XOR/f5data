Description

The following logs appear in /var/log/ltm during the boot-up.

err chmand[<pid>]: 012a0003:3: Setting /sys/kernel/debug/x86/ibpb_enabled failed. Request ibpb=1 ignored

Environment

  • You are using v13.x.x or v14.x.x.
  • You are booting the BIG-IP.

Cause

The correct log level of the message is notice. F5 tracks the issue as ID 751072. The is fixed in v15.0.0.

ID 751072 Error message in /var/log/ltm Setting /sys/kernel/debug/x86/ibpb_enabled failed. Request ibpb=0 ignored

Recommended Actions
You can ignore the log safely.

Additional Information
On v15.0.0 and later, the log appear in /var/log/ltm as notice level.
notice chmand[<pid>]: 012a0005:5: Setting /sys/kernel/debug/x86/ibpb_enabled ignored. Current value in kernel is 1 and in config setting is 0.
