K000139737: Accessing the internal MariaDB database for APM and Other Logs

Type
Support Solution
Published
2024-05-22
Updated
2025-12-10
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000139737

Description

This article provides a detailed guide on how to access and interact with the internal MySQL database on an F5 system to browse APM and other logs. The steps include decrypting the MySQL password, accessing the database, and viewing the necessary tables and logs.

Environment

APM provisioned

Cause

Accessing the internal MySQL database is necessary for troubleshooting and obtaining detailed log information using SQL queries

Recommended Actions

Getting the Password:

To access the MySQL database, you first need to retrieve the password. Use the following command in bash to decrypt the stored password:

# perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw

 

Accessing the Database:

Once you obtained the password, log into the MySQL database using the command below.

# mysql -u root -p

 

Viewing Databases:

After logging in, list the available databases to identify where the needed information is stored:

MariaDB [(none)]> SHOW DATABASES;

Using the logdb Database:

The APM details are stored in the logdb database. Switch to this database with the following command:

MariaDB [(none)]> USE logdb;

Reading table information for completion of table and column names

You can turn off this feature to get a quicker startup with -A

 

Database changed

MariaDB [logdb]>

Viewing Tables:

Within the logdb database, view the available tables to identify where the logs are kept:

MariaDB [logdb]> SHOW tables;

Querying Log Data:

You can now query the tables to retrieve log data. For example, to view entries in the log_data table:

MariaDB [logdb]> SELECT * FROM log_data LIMIT 10;
