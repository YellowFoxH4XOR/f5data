Description

Active Directory integration error: could not get filtered groups for domain.com: LDAP Result Code 4 "Size Limit Exceeded"

 

Environment

Nginx Controller

Microsoft Active Directory (AD) Authentication Integration

 

Cause

Microsoft AD has a limit of returning 1000 Objects in one query by default.

 

Recommended Actions

Modify the AD query to return results less than 1000 Objects at once, Narrow the search parameter under the query.

OR

Modify the limit of MaxPageSize on Microsoft AD Server

Important: Please try the below instructions at your own risk. Depending on your setup there may be a negative impact as increasing the returned results can consume more memory/resources on the receiving end.
