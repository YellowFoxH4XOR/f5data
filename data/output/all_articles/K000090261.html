Description

You can view a list of your NGINX Controllers and track usage data for each one on MyF5.

About subscriptions and your NGINX Controller usage

Your NGINX Controller subscriptions set the maximum usage limit for each feature you purchased in your subscription. Available features include app delivery, app security, API management, and API management security. NGINX does not currently enforce maximum usage limits; however, you can track your usage of each feature on MyF5.

Types of subscriptions

There are two types of subscriptions:

  • Annual—Annual subscription for an NGINX Controller.
  • Flexible Consumption Program (FCP)—Enterprise agreement, formerly known as an Enterprise License Agreement (ELA).

You may also have multiple products within one subscription. Each product corresponds to a different level—or type—of support, such as premium, standard, or self-serve. Each product defines the maximum usage limit you have for that type of support.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have one of the following NGINX Controller products:
    • A subscription
    • An FCP
    • A trial

Procedures

View a list of your NGINX Controllers

You may see multiple NGINX Controllers for the same subscription ID. Each one is a different product, because it has a different level of support. You can identify the level of support in the Support column.

  • Go to My Products and Plans > NGINX Controller.

View your NGINX Controller usage—subscription or FCP

When you have an NGINX Controller subscription or FCP, use this procedure.

  1. Go to My Products and Plans > NGINX Controller.
  2. Select the NGINX Controller you want.

View your NGINX Controller usage—trial

When you have an NGINX Controller trial, use this procedure.

A free trial is a 30-day trial with unlimited usage. A freemium trial has no expiration date and limited maximum usage.

  1. Go to My Products and Plans > Trials.
  2. Under My Trials, select the NGINX Controller trial you want.

About the NGINX Controller usage page

The following table describes the product information on the page.

SectionDescription
TopDescription of your subscription entitlements, including the following:
  • Your subscription ID
  • Your maximum usage limit for each feature you purchased: app delivery, app security, API management, and/or API management security
  • Your type of support
  • The expiration date for your subscription
Instances and usageAggregate usage of each service you purchased by all of your NGINX Controller instances and the amount of usage you have left for each feature.* Your aggregate usage should not surpass your entitled usage, which is displayed at the top of the page.
InstancesUsage of each service you purchased by each of your NGINX Controller instances that reported data to F5.†‡ Additional information includes:
  • The last time each instance reported back to F5
  • The current reporting status of each instance that reported back
Note: In this section, you can also initiate a new instance of NGINX controller by selecting Instance. For more information, refer to K000090854: Download and license NGINX Controller using MyF5.

*F5 measures API management and API management security in millions (M).

†The system reports only successful API calls.

‡The system reports only NGINX Controllers that connect to F5 licensing servers and have a connected license.
