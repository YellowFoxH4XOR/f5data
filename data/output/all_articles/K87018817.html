Cause

This can sometimes be caused by installing APM guided configuration previously (and not using it for several upgrades)

"/var/config/rest/iapps/f5-iappslx-access-saml-idp/nodejs/blockUtil.js" does not exist.

Recommended Actions

Delete the related RPM and reinstall if needed. To do so, perform the following procedure:

  1. Go to iApps >> Package Management LX 
  2. Select the RPMs used by Access Guided Configuration, f5-iappslx-access* 
  3. Select Uninstall to uninstall all of the rpms. 
  4. Return to AGC so that all the rpms will be reinstalled (with the default AGC version of the BIG-IP version the system is running). 
  5. Verify that the error and issue are resolved and deployments are visible.
