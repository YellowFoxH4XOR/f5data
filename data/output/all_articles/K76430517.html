K76430517: When importing ISO image via gui - ''error occured while trying to process your request''

Type
Support Solution
Published
2021-10-18
Updated
2023-02-21
Applies to
  • BIG-IP
  • Virtual Editions
  • Vmware ESXI and vCloud Director
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K76430517

Description

While importing an .iso file via GUI, you get prompted with: "an error occurred while trying to process your request"

Environment

  • Error on the GUI page
  • Uploading the .iso file via GUI

Cause

Undetermined

Recommended Actions

  1. Validate whether you have enough disk space to upload the .iso file,
  2. Transfer the .iso file to /shared/images (using WinSCP for example).
After uploading the file via CLI, it should be visible in the GUI after a few minutes.

Additional Information

None.
