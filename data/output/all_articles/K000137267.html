Description

Customer may only want to connect to VPN but do not want to login to Windows via "Windows Logon Integration" feature.

Environment

  • BIG-IP
  • APM
  • Edge Client
  • Windows

Cause

None.

 Recommended Actions

 "Windows Logon Integration" feature supports VPN setup before Windows logon

However, the Windows logon can not be done manually.
Customer may consider the machine tunnel feature.

Additional Information

None.
