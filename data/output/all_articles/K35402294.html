Topic

You should consider using this procedure under the following conditions:

  • You use the Configuration utility to create or modify DNS configuration object names.
  • You manually edit the BIG-IP DNS configuration file /config/bigip_gtm.conf.

Description

When setting BIG-IP DNS configuration object names using the Configuration utility, you could inadvertently introduce unseen control characters by cutting and pasting into the configuration object name fields. Additionally, using an external editor or cutting and pasting while directly modifying the bigip_gtm.conf file may introduce unintended control characters to the configuration file.

When you load the bigip_gtm.conf configuration file onto the running configuration, the system first sends the file through a syntax check parser. Control characters located in the configuration file may cause the parser to produce an error and the configuration load to fail. F5 anticipates that future versions of the configuration parser will be less tolerant of errant control characters within the configuration file. So, to avoid possible configuration incompatibility issues during an upgrade, F5 encourages you to review the system file bigip_gtm.conf to avoid unintended control characters in the file stanza.

The following procedures outline how to detect the location of control characters in the /config/bigip_gtm.conf file and provide steps on how to remove control characters from the file.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have administrative access to the command line of the BIG-IP system.
  • Are comfortable using the vi or vim editors.
  • Have a scheduled maintenance window set up in which to perform the procedures.

Procedures

  • Detecting hidden control characters
  • Removing a limited number of control characters
  • Removing all control characters
  • Rolling back to the original configuration

Detecting hidden control characters

When you view the /config/bigip_gtm.conf system configuration file, you may find it difficult to see unintended control characters within the file.

The following procedure enables the system to display all control characters in the /config/bigip_gtm.conf file.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP device.
  2. To view control characters in the /config/bigip_gtm.conf file, type the following command:

    cat -A /config/bigip_gtm.conf

    Note: The output from this command shows each line of the file ending with the dollar sign ($); this is normal and expected behavior. However, other non-alphanumeric characters starting with the caret symbol (^) are likely unwanted control characters.

Following is an example configuration section of a bigip_gtm.conf file that contains a control character:

gtm datacenter /Common/DataCenter-A
gtm server /Common/ServerOne {
    datacenter /Common/DataCenter-A
    devices {
        1310.bigip.local {
            addresses {
                10.0.13.83 { }
            }
        }
    }

Following is the same bigip_gtm.conf configuration section using the cat -A command:

$
gtm datacenter /Common/DataCenter-A^@ { }$
gtm server /Common/ServerOne {$
    datacenter /Common/DataCenter-A$
    devices {$
        1310.bigip.local {$
            addresses {$
                10.0.13.83 { }$
            }$
        }$
    }$

Note: In the second line of this example there is a control character ^@ at the specified name for the following datacenter:

 gtm datacenter /Common/DataCenter-A^@ { }$

When you view the bigip_gtm.conf file, be sure to note the location of any identified control characters you find in the file.

Removing a limited number of control characters

When a limited number of control characters are identified from the previous procedure, you can use a command line editor such as vi or vim to remove the control characters. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure may fail to load the configuration when control characters remain in the configuration file or the editing process alters the configuration stanza.

  1. Create a copy of the affected bigip_gtm.conf file by typing the following command:

    cp /config/bigip_gtm.conf /config/fixed_bigip_gtm.conf

  2. Use the vi or vim editor to open the fixed_bigip_gtm.config file by typing the following command:

    vi /config/fixed_bigip_gtm.conf

  3. From within the vi or vim editor, after you press Esc, type the following command:

    :set list

    Note: The content of the vi or vim editor now appears the same as the file content that the previous cat -A command displays.

  4. Locate the control characters.
  5. Place the cursor in front of the first character of the first control character and type the following vi command to remove the control character:

    dw

  6. Press Esc.
  7. Repeat step 5 and 6 on each of the remaining control characters identified in the file.
  8. Save the file modifications to /config/fixed_bigip_gtm.conf file by typing the following command:

    :wq

  9. Copy the /config/fixed_bigip_gtm.conf file and replace the existing /config/bigip_gtm.conf file by typing the following command:

    cp -f /config/fixed_bigip_gtm.conf /config/bigip_gtm.conf

  10. Verify the modified configuration by typing the following TMOS Shell (tmsh) command:

    tmsh load /sys config gtm-only verify

    Note: If the verification step produces an error, note the line number of the error and repeat steps 2 through 10, using the line number for guidance.

  11. To load the updated configuration onto the running configuration, type the following command: 

    tmsh load /sys config gtm-only

  12. To save the loaded system configuration, type the following command:

    tmsh  save /sys config partitions all

Removing all control characters

When you identify a large number of control characters in the bigip_gtm.conf file, use the following procedure to remove the control characters:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Create a copy of the affected bigip_gtm.conf file by typing the following command:

    cp /config/bigip_gtm.conf /config/bigip_gtm.conf.backup

  2. To remove all control characters, type the following command:

    cat /config/bigip_gtm.conf | tr -cd '[:print:]\n' > /config/fixed_bigip_gtm.conf

  3. To copy the /config/fixed_bigip_gtm.conf file, and replace the existing /config/bigip_gtm.conf file, type the following command:

    cp -f /config/fixed_bigip_gtm.conf /config/bigip_gtm.conf

  4. To load the modified configuration, type the following tmsh command:

    tmsh load /sys config gtm-only verify

    Note: If the verification step produces an error, note the line number of the error and repeat steps 2 through 10 of the previous procedure, using the error line number as guidance to locate the offending character.

  5. To load the modified configuration into the running configuration, type the following command:

    tmsh load /sys config gtm-only

  6. To save the running system configuration, type the following command:

    tmsh save /sys config partitions all

Rolling back to the original configuration

If the previous procedures do not create a verifiable configuration or the configuration file changes produce an unwanted result, you can restore the original bigip_gtm.conf file. To do so, perform the following procedure:

  1. Replace the current /config/bigip_gtm.conf file with the backup copy bigip_gtm.conf file created in step 1 of the previous procedures, using the following command syntax:

    cp -f /config/<backup file name> /config/bigip_gtm.conf

  2. To load the original configuration onto the running configuration, type the following command:

    tmsh load /sys config gtm-only

  3. Save the running system configuration by typing the following command:

    tmsh save /sys config partitions all
