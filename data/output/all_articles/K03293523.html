Known Issue

Disabling the Require A Consistent Inbound IP For the Entire Web Session setting does not apply to some locations in the Configuration utility.

This issue occurs when one of the following conditions is met:

  • You disable the Require A Consistent Inbound IP For the Entire Web Session setting using the Configuration utility.
  • You disable the auth-pam-validate-ip setting using the TMOS Shell (tmsh).

By default, the Configuration utility restricts client sessions to a single source IP address and terminates the session if the source IP address changes during the session. For example, this issue occurs when accessing the BIG-IP system from behind a proxy.

When you disable this functionality and the source IP address connecting to the BIG-IP system changes during a session, the client remains connected. However, some menus in the Configuration utility, such as those related to BIG-IP ASM, BIG-IP Analytics, and BIG-IP APM, do not honor this setting. The BIG-IP system logs out the client when the source IP address changes during a session.

Impact

When the client source IP address changes while attempting to access affected areas of the Configuration utility, the system logs out administrators and redirects them to the login page.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Administrators are unable to log in to the Configuration utility, but are able to maintain secure shell (SSH) sessions.
  • The system periodically logs out administrators when they access Configuration utility menus for BIG-IP ASM, BIG-IP Analytics, or BIG-IP APM.

Workaround

To work around this issue, ensure the source IP address that the client uses to connect to the Configuration utility does not change during the session. To restrict access to the Configuration utility to only a single source IP address per session (default), perform one of the following procedures:

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Enabling the 'Require A Consistent Inbound IP For The Entire Web Session' setting using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to System > Preferences.
  3. In Security Settings, click Advanced.
  4. Select the Require A Consistent Inbound IP For the Entire Web Session check box.
  5. Click Update.

Enabling the 'auth-pam-validate-ip' setting using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Enable the auth-pam-validate-ip setting by typing the following command:

    modify /sys http auth-pam-validate-ip on

  3. Save the change by typing the following command:

    save /sys config
