Issue

Note: For information about changing the baud of the serial console on a VIPRION system, refer to K10621: Setting the serial console baud rate on a VIPRION system (9.6.x - 10.x).

Starting in BIG-IP 9.4.0, the bigpipe hardware baud rate command replaces the previous bigpipe baud rate command used to change the serial console baud. To change the baud for the serial console, type one of the following two commands for the version you are running:

  • Versions prior to BIG-IP 9.4

    bigpipe baud rate show | <value>
  • BIG-IP 9.4 and later versions

    bigpipe hardware baud rate show | <value>

Note: For more information about this command, refer to K9156: Setting the baud rate of the serial console port (9.x - 10.x).

F5 Product Development tracked this enhancement as CR58285, and it was added to BIG-IP 9.4.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.
