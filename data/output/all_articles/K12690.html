K12690: Mac and Linux users are unable to automatically launch the Citrix client through a reverse proxy

Topic

Mac and Linux users are unable to automatically launch a Java Independent Computing Architecture (ICA) client in a Static Application Tunnel when the user clicks on Citrix Web Interface published applications. The Static Application Tunnel is created automatically, without user intervention.

When a Windows user connects to a Citrix deployment through a Portal Access configuration, a modified Citrix ICA configuration file is sent to the user's browser. The file contains information to establish an ICA connection to the Citrix server hosting the resource, including an IP address or computer name (typically a Fully Qualified Domain Name (FQDN)) and a TCP port number. The browser then launches an ICA client; either a webified ICA client, such as the ActiveX client or the Java ICA client. Alternatively, the browser can launch a fat client, such as the Citrix Program Neighborhood. The choice of Citrix client is governed by the program associated with the .ica file type in the browser's configuration.

F5 Product Development is tracking a Request for Enhancement (RFE) as ID 238562 to enable Mac and Linux users to automatically launch a Java ICA client in the same manner as Windows users.

This enhancement was added in hotfix HF-610-6.1 for Firepass 6.1.0 and hotfix HF-70-4.1 for FirePass 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
