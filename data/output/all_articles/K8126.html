Issue

For FirePass 6.0.0 and earlier, the Network Access-only webtop configuration is accessed on the User Experience tab within each master group on the Users: Groups: Master Groups page. To activate the Network Access-only webtop, select the Use Network Access Only Webtop check box.

For FirePass 6.0.1 and later, the Network Access-only webtop configuration is accessed within each resource group on the Network Access: Resources page. To activate the Network Access-only webtop, select the Autolaunch based on endpoint protection check box, and then select the Use Alternate Webtop check box.

Configuring the Network Access-only webtop on a per-resource group basis provides more granular control over which Network Access Favorites can be presented with or without webtop, and which users can be allowed access to either configuration.
