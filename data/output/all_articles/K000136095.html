Each MyF5 user role corresponds to a set of actions that users with that role can take on a MyF5 account. MyF5 uses Role-Based Access Control (RBAC) across two levels:

  • Account user roles: Define permissions that apply across the MyF5 account
  • Subscription user roles: Define permissions for managing and viewing specific subscriptions, registration keys, and associated teams.

Only the Admin role (or Team Manager / Team Owner within their designated scope) has permissions to manage or assign roles for others.

Account user roles and permissions

There are currently six MyF5 user roles. Only the Admin role has permissions to assign roles to others. The role privileges apply to all accounts for which they have access.

Important: If your account does not have one Admin user yet, contact your F5 account team to assign an account user the Admin role. 

Important: Elevation to any role other than Basic or Viewer requires approval from the F5 Accounts Team. Please contact your F5 Accounts Team for approval before requesting Support to elevate the user’s role. Support can apply the role change only after the required approval has been obtained. This includes the Case Manager, User Manager, Editor, and Admin roles.

Note: You must log in to MyF5 to use chat.

About MyF5 account user statuses

There are two user statuses:

  • Active—User has access to a MyF5 account.
  • Pending—User is invited to and has completed registration on MyF5 but still approval needs to be procured from F5 Account Manager or Customer Success Manager.
