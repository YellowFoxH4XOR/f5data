Known Issue

This is the result of a known issue. If you configure an Active Directory dynamic group mapping method with the Forest mode option enabled, master groups using Active Directory authentication with the Forest mode option disabled may continue to use the Forest mode option to query the Active Directory server, even after one or both of the following conditions are met:

  • You delete the Active Directory group mapping method.

    Note: The Active Directory group mapping method is configured on the Users: Groups: Dynamic Group Mapping page under the Group mapping methods tab.

  • You disable dynamic master group mapping.

    Note: If the Determine the user's master group dynamically using the master group mapping table check box is cleared under the Group mapping sequence tab of the Users: Groups: Dynamic Group Mapping page, the dynamic master group mapping is disabled.

The Forest mode option was introduced in FirePass version 6.0.2, and it allows you to authenticate users against Active Directory using their user principal names (UPN). In some Active Directory configurations, enabling forest mode on the FirePass controller causes Active Directory authentication to time out or fail.

F5 Networks Product Development tracked this issue as CR96736, and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-602-4 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by disabling the Forest mode option in the Active Directory group mapping method. To disable the Forest mode option in the Active Directory group mapping method, perform one of the following two procedures:

Disabling Forest mode when the Active Directory group mapping method is configured

To disable the Forest mode option in the Active Directory, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Click the Group mapping methods tab.
  4. Next to Active Directory, click the Configure link.
  5. Clear the Forest mode check box.
  6. Click the Update button.

Disabling Forest mode when the Active Directory group mapping method was deleted

To disable the Forest mode option in the Active Directory, perform the following procedure:

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Click the Group mapping methods tab.
  4. In the Mapping methods menu, select Active Directory.
  5. Click the Add mapping method button.
  6. Next to Active Directory, click the Configure link.
  7. Clear the Forest mode check box.
  8. Click the Update button.
  9. Click the Group mapping methods tab.
  10. Next to Active Directory, click the Delete link.
