Description

systemd-journald leaks memory, and cause memory pressure and cause oom-killer run and random process may be killed, or some process crash and produce core file.
 

Environment

  • BIG-IP (excluded cloud edition)
  • v14.1.2.1-14.1.2.3 and v15.1.0.*
     

Cause

K22040951: systemd-journald vulnerability CVE-2019-3815
 

Recommended Actions

To resolve this resource issue, upgrade to a BIG-IP version listed as "Fixed" in K22040951: systemd-journald vulnerability CVE-2019-3815.
 
To temporarily address the resource exhaustion issue, run below command in CLI (bash mode, not in tmos shell):

Important: This should not cause failover or disrupt processing traffic, however it is recommended to run in maintenance window.

systemctl restart systemd-journald

Note: Memory leak pace will be different by each unit, so you may want to place this in scheduled job in crontab.
