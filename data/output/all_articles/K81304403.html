Description
How to provision original or additional modules (like AVR) via command line (CLI/TMSH)

Environment

  • You have Licensed for other modules like AVR, APM but it is not yet provisioned
  • You want to provision modules via Command line (CLI/TMSH)
  • You need to recover original modules provisioning for configuration to load correctly.
  • No GUI access, only SSH/serial console.

Cause

Some modules might have been incorrectly unprovisioned

Recommended Actions

Impact of procedure: F5 recommends that you perform this procedure during a maintenance window. Reprovisioning involves restarting system processes and rebooting. These actions interrupt traffic. Additionally, when the BIG-IP system is in a device group, it fails over to the next available member.

  1. Verify correct SW module provisioning from a reliable source       0.

i.e.     HA peer or exact same provisioned unit.

  1. Login to TMSH from command line

    # tmsh
     
  2. Check for AVR properties first

    # list sys provision avr all-properties

    Sample Output:

    sys provision avr {
        cpu-ratio 0
        description none
        disk-ratio 0
        level none       <------- in this example, AVR is not provision
        memory-ratio 0
    }
  3. To provision AVR, or any other module, you can use the command below:

    NOTE:

    i        Custom
             F5 Networks does not recommend that you specify this level.

    ii        Dedicated
             Specifies that all resources are dedicated to the module you
             are provisioning. For all other modules, the level option
             must be set to none.

    iii        Minimum
             Specifies that you want to provision the minimum amount of
             resources for the module you are provisioning.

    iv        Nominal
             Specifies that you want to share all of the available
             resources equally among all of the modules that are licensed
             on the unit.

    v        None Specifies that you do not want to provision any resources for
             this module.

    Command:   
    modify sys provision avr level nominal
    # modify sys provision <module> level <value>          <module> = AVR  <value> = nominal
     
  4.  Save the changes to the stored configuration.

    # save sys config

Additional Information

Run the command for as many combinations of modules and levels you have. Leave Management the way it is.
