K000137787: Error: Unable to get license for RegKey when attempting to create dossier

Type
Support Solution
Published
2023-12-06
Updated
2023-12-06
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.0
Source
https://my.f5.com/manage/s/article/K000137787

Description

While attempting to generate a dossier for a BIG-IQ, the following error occurs. Manual activation also returns this error.

Error on server request: 1. Error: Unable to get license for RegKey: <customer base registration key here>, try manual activation. Detail: Command failed /usr/bin/get_dossier -b <customer base registration key here> Exit Code: 1 Stderr:

Where <customer base registration key here> refers to the five blocks of characters, XXXXX-XXXXXX-XXX-XXXXXXX-XXXXXXX, associated with the base registration key.

Additionally the LTM logs report "err get_dossier[27091]: 01170005:3: /VERSION stat fails: No such file or directory".

Environment

  • BIG-IQ License Manager
  • Device or LOAD/CAT license
  • License activation

Cause

The /VERSION.LTM file is missing. 

Recommended Actions

Restore this missing file.

  1. Log onto the command line for the BIG-IQ
  2. Check for the file: ls -lh /VERSION.LTM
  3. Confirm the active version of the BIG-IQ: tmsh show sys software
  4. Create the file: touch /VERSION.LTM
  5. Copy the contents from another BIG-IQ on the same version.

Additional Information

To search the LTM logs for errors associated with get_dossier, from the command line via an SSH connection, run the following command:
  • grep -i get_dossier /var/log/ltm
To search the compressed logs that are older than 24 hours, run this command:
  • zgrep -i get_dossier /var/log/ltm*
