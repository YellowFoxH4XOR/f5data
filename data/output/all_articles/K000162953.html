K000162953: BIG-IQ Statistics Unavailable When BIG-IP Uses a Non-Default Primary Administrative User

Type
Support Solution
Published
2026-08-17
Updated
2026-08-17
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000162953

Description

BIG-IQ Centralized Management does not display AVR statistics from a BIG-IP system. BIG-IP avrd.log reports HTTP 401


Bad status code : 401. Reconnecting...

 

Environment

  • BIG-IQ Centralized Management
  • BIG-IP with AVR provisioned
  • BIG-IQ statistics collection enabled
  • BIG-IP configured with a non-default value for systemauth.primaryadminuser


Cause

An authentication and authorization mismatch occurs when systemauth.primaryadminuser is configured with a non-default administrative user instead of admin.

The HTTP 401 response from BIG-IP avrd indicates that the statistics connection is unauthorized.


Answer/Recommended Actions

Recommended the customer change the admin account back to default and restart the system to resolve this issue.


  1. Check the current primary administrative user:
    1. tmsh list sys db systemauth.primaryadminuser
  2. Restore the default value:
    1. tmsh modify sys db systemauth.primaryadminuser value admin
    2. tmsh save sys config
  3. Reboot the BIG-IP system.


If the customer does not wish to change this back to admin, all eligible DCDs need to have the same user defined as admin. The user does not need a password or access to either the shell or UI.
