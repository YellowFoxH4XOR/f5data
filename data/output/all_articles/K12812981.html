Description

You may observe value of throughput-capacity for route-domain in /config/bigip_base.conf is changed from 0 to infinite after the upgrade.

Before upgrade :

net route-domain 0 {
<snip>
    throughput-capacity 0
}

After upgrade :

net route-domain 0 {
<snip>
    throughput-capacity infinite
}

Environment

  • BIG-IP
  • Upgrade from version prior to 14.0.0

Cause

This is by design and will not affect the behavior

Recommended Actions

None

Additional Information

None
