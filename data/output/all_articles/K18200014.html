Description
When you clear all "Learn" settings of Attack siganture and change "Learn New Parameters" setting then Save & Apply Policy,
"Check attack signature on this parameter" of wildcard parameter is disabled automatically.

Environment

  • BIG-IP ASM
  • "Check attack signature on this parameter" of wildcard(*) parameter is enabled in Security >> Application Security >> Parameters >> Parameter List >> Prameter Properties
  • Disable all "Learn" for Attack signature in Security >> Application Security >> Policy Building >> Leaning and Blocking Settings
  • Change "Learn New Parameters" from Always to Compact/Selective/Never in Security >> Application Security >> Policy Building >> Leaning and Blocking Settings

Cause
It is by our design.

Recommended Actions

You can re-enable "Check attack signature on this parameter" of wildcard parameter.
Please note, when turning on "Check attack signature on this parameter" with signatures learning disabled, the signatures will be enforced without prior learning.
