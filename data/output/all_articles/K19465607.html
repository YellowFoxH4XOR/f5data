Known Issue

After you upgrade to BIG-IP 14.1.2.8 or 15.1.1, you can no longer install or upgrade DDoS Hybrid Defender to a newer version.

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP 14.1.2.8 or 15.1.1.
  • You perform one of the following actions:
    • In the BIG-IP Configuration utility, you navigate to one of the following pages:
      • DoS Setup > Silverline
      • DoS Setup > Global
      • Network > High Availability

      Note: When navigating to these pages, DDoS Hybrid Defender automatically attempts to install the latest version.

    • You attempt to manually update the DDoS Hybrid Defender version from the System > About page in the Configuration utility.

Impact

You cannot install or upgrade DDoS Hybrid Defender.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility displays a message similar to the following example:

    Package installation failed with error: Failed to load IApp artifacts from f5-ddos-hybrid-defender: java.lang.IllegalStateException: Failed to post templates to block collection.

Workaround

F5 recommends that you do not upgrade DDoS Hybrid Defender systems to BIG-IP 14.1.2.8 or 15.1.1. To work around this issue, if you already installed BIG-IP 14.1.2.8 or 15.1.1, you can delete the iApp and associated RPM package, then manually install the latest RPM package. To do so, perform the following procedure:

Note: Alternatively, you can reboot the BIG-IP system to the previous boot location.

Impact of workaround: This procedure requires you to delete any pre-existing DDoS Hybrid Defender iApp configuration. You must manually reconfigure this configuration.

  1. Download the latest DDoS Hybrid Defender RPM package from F5 Downloads (https://downloads.f5.com). For specific instructions, refer to K167: Downloading software and firmware from F5.
  2. Log in to the Configuration utility.
  3. In the lower left, select Show Advanced Menu.
  4. Go to iApps > Application Services > Applications LX.
  5. Select all iApps with the prefix purposeBuilt_pbdos, and then select Undeploy.
  6. Select all iApps with the prefix purposeBuilt_pbdos, and then select Delete.
  7. Select Yes.
  8. Go to iApps > Templates > Templates LX.
  9. Select all templates with the prefix pbdos, and then select Delete.
  10. Select Yes.
  11. Navigate to iApps > Package Management LX.
  12. Select the f5-ddos-hybrid-defender RPM package, and then select Uninstall.
  13. Select Import, and then browse to the latest DDoS Hybrid Defender RPM package that you downloaded.
