Known Issue

This is the result of a known issue. You can use the bigpipe persist show command to display persistence table entries on the BIG-IP system. The BIG-IP LTM system is unable to display the persistence table when more than 10,800 persistence records exist in the table.

When the persistence table contains more than 10,800 persistence records, and you attempt to display the persistence entries using the bigpipe persist show command, the following error message outputs to the console:

BIGpipe: Unable to complete request

In addition, an error message may be logged to the /var/log/tmm file that appears similar to the following example :

mcp error: 0x1020004 at ../mcp/db_persist.c:287

Note: The mcp error message usually indicates that the persistence table is too large to be displayed using the bigpipe command; it does not indicate an issue with the actual persistence table in production.

F5 Product Development tracked this issue as CR49412 and it was fixed in BIG-IP LTM version 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP LTM 9.1.x and 9.3.x software branches.

Note: The BIG-IP Configuration utility does not display more than 10,800 persistence entries. For more information, refer to K8568: The BIG-IP Configuration utility cannot display persistence records when persistence table contains more than 10800 entries.
