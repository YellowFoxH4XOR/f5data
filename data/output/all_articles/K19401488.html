Known Issue

Modifications to the topology records order may not be applied to the running configuration.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP DNS (formerly known as BIG-IP GTM) system is configured with topology records.
  • On the Change Order page in the Configuration utility, the Longest Match check box is cleared (disabled).
  • You modify the order of the topology records.
  • You do not add or delete a topology record.

Impact

The topology record order change is not reflected in the running configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you modify the topology records order, topology load-balancing decisions continue to use the previously configured records order.

Workaround

To work around this issue, after you modify the topology records order, you can reload the BIG-IP DNS configuration. To do so, perform the following procedure:

Impact of workaround: This procedure temporarily interrupts processing by the BIG-IP DNS system while the configuration is loading.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Type the following command to load the BIG-IP DNS configuration:

    load /sys config gtm-only

  3. To exit tmsh type the following command:

    quit
