K9789: The advanced routing module now advertises routes for virtual addresses with an unknown status

Issue

You can configure BIG-IP systems licensed for the advanced routing module to selectively advertise routes for a specific virtual address based on the status of that address by enabling the Route Advertisement setting in the virtual address configuration.

In BIG-IP versions prior to 9.4.4, the advanced routing module did not advertise dynamic routes for virtual addresses with Route Advertisement enabled and an unknown status (blue square). Beginning in BIG-IP 9.4.4, the advanced routing module advertises dynamic routes for virtual addresses with an unknown status (blue square). This change in behavior was intentional.

The virtual address status is derived from the status of the virtual servers using the virtual address. In most cases the status derived for virtual servers and virtual addresses is intuitively obvious. However, some anomalies are detailed in K6514: BIG-IP may not accurately detect the status of virtual servers using iRules or HTTP classes to select a pool and K9700: Counterintuitive virtual address status may adversely affect route advertisement.
