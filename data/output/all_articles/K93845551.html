Description

You want to add condition when a certain header exist, do nothing in LTM policy on BIG-IP v14.x and before.
 

Environment

  • BIG-IP
  • v14.x and before
  • LTM policy
  • exist / does not exist

Cause

N/A
 

Recommended Actions

There is NO "exist/does not exit" option in v14.x and before. Need to use iRule for this type of condition.
From v15.x and later, "exist/does not exist" option is implemented.
 
if { [HTTP::header exists "<header_name>"] } { 
   <do something when the header exist: if no action required, leave empty here>
} else {
   <do something when the header doesn't exit: if no action required, leave empty here>
}

NOTE: There are more variations, so please check our Devcentral or Cloud documents for iRule.
