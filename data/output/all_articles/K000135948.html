K000135948: There is only one file in one or more snapshots folders (/shared/tmstat)

Type
Support Solution
Published
2023-08-24
Updated
2023-08-28
Status
Final
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.6
Source
https://my.f5.com/manage/s/article/K000135948

Description

  • There is only one file in one or more snapshots folder (/shared/tmstat)
# ls -lh /shared/tmstat/snapshots/blade0/performance/600

total 136K

-rw-r--r--. 2 root root 132K Aug 23 15:30 blade0-performance-600-2023-08-23T15:30:00

Environment

  • BIG-IP

Cause

This is caused due to manual deletion of all files under snapshots subfolder

 Recommended Actions

  1. Restart the bigstart

# bigstart restart

# ls -lh /shared/tmstat/snapshots/blade0/performance/600

total 544K

-rw-r--r--. 1 root root 132K Aug 23 15:30 blade0-performance-600-2023-08-23T15:30:00

-rw-r--r--. 1 root root 132K Aug 23 15:40 blade0-performance-600-2023-08-23T15:40:00

-rw-r--r--. 1 root root 132K Aug 23 15:50 blade0-performance-600-2023-08-23T15:50:00

-rw-r--r--. 2 root root 132K Aug 23 16:00 blade0-performance-600-2023-08-23T16:00:00

 

  • Note:

This is a service affecting command and should be perform on maintenance time window
