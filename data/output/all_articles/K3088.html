Topic

This Solution describes factors to consider when choosing whether to configure an Application Tunnel or a Network Access connection for a particular master group. For some master groups, you may want to configure both features.

Applications Tunnels

Application Tunnels are best suited for business partners with a specific business requirement, such as accessing particular database programs or uploading files to specific servers. Application Tunnels are the optimum choice for groups of users requiring access to TCP-based client-server applications. Application Tunnels are configured on a per-application basis.

The Static Application Tunnels feature supports access to TCP-based client-server applications which use static IP addresses and ports. Prior to FirePass version 6.0.3, FirePass supported the Static Application Tunnel feature for Windows clients only. The Java Static Application Tunnel feature was introduced in FirePass version 6.0.3, which supports Windows, Mac OS X, and Linux clients.

The Dynamic Application Tunnels feature was introduced in FirePass version 6.0.0, which supports access from Windows clients to TCP-based applications requiring dynamic ports and/or IP addresses. If you are running version 5.x of FirePass software, or if you need to support non-Windows clients, you must configure a Network Access connection for access to applications which require dynamic ports and/or IP addresses.

Network Access

The FirePass Network Access (SSL VPN) feature is an optimal choice for groups of users which have the following requirements:

  • Access to a several (five or more) applications.

    Important: For increased security, you can configure the packet filters feature to control which network resources are available through Network Access connections. For information about enabling and configuring packet filters, refer to the FirePass Controller Administrator Guide.
  • Access to UDP-based applications or other non-TCP-based applications.
  • For FirePass version 5.5.2 and earlier, access to TCP applications requiring dynamic ports and/or IP addresses.

    Note: The Dynamic Application Tunnel feature was introduced in FirePass version 6.0.0 to support applications requiring dynamic ports and/or IP addresses.
  • For FirePass version 6.0.2 and earlier, access to an application from a non-Windows client (for example: Linux and Mac OS X systems).

    Note: The Java Static Application Tunnels was introduced in FirePass version 6.0.3 to support the Static Application Tunnels feature for Linux and Mac OS X clients.
  • Full network access (for example: systems administrators).
  • Changing needs that you cannot easily forecast.
