Known Issue

The BIG-IP system may fail to create an iApp application service.

This issue occurs when the following condition is met:

  • You attempt to create an iApp application service using the Configuration utility with a non-administrative user account. For example, you log in as an Application Editor user.

Impact

You are unable to create an iApp application service.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to create an iApp application service, the Configuration utility displays an error message similar to the following example:

    Error parsing template:Tcl_Init failed: (invalid command name "file" while executing "file join $i init.tcl" (procedure "tclInit" line 21) invoked from within "tclInit" line:46)

  • In the /var/log/audit file, you observe an error message similar to the following example:

    014f0005:5: AUDIT - user=mgr action="run stand-alone script: Script" status="Tcl_Init failed: (invalid command name "file"     while executing "file join $i init.tcl"     (procedure "tclInit" line 21)     invoked from within "tclInit" line:46)"

Workaround

There is no workaround for this issue. However, you can prevent this issue from occurring by using an administrator account to create the iApp application service.
