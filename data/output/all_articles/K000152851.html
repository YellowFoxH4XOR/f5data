K000152851: Unable to login to terraform deployed BIGIQ cloud instance

Type
Support Solution
Published
2025-08-01
Updated
2025-08-01
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000152851

Description

Unable to login to terraform deployed BIGIQ cloud instance with the default or defined credentials in declaration


Environment

  • Azure cloud
  • Google cloud
  • Amazon cloud
  • Terraform & BIGIQ

Cause

No F5-supported Terraform module available for BIG-IQ at the time of writing.

The inability to log in is primarily due to the use of an unsupported deployment method. F5 does not provide or support a Terraform module for BIG-IQ deployments in Aws/Azure. Using Aws/Azure-provided modules may result in unpredictable behavior, including failed authentication with default or specified credentials.


Recommended Actions

If you have already deployed BIG-IQ using Terraform module provided by Azure/Aws/Gcp and cannot log in, redeploy the instance manually instead of using terraform. We support only F5 provided Terraform modules.
