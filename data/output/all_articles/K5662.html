Topic

This article applies to BIG-IP GTM 9.x - 10.x. For information about other versions, refer to the following article:

K14799: Reconciling changes between the BIG-IP DNS Configuration utility and the bigip_gtm.conf file (11.x - 13.x)

You should consider using this procedure under the following conditions:

  • The BIG-IP GTM configuration in the Configuration utility does not accurately reflect the /config/gtm/wideip.conf configuration file.
  • The BIG-IP GTM configuration in the wideip.conf file is the desired configuration.

Description

The BIG-IP GTM configuration in the Configuration utility represents the configuration communicated to the master configuration process service (mcpd). The Configuration utility should reflect the global traffic manager daemon's (gtmd) current configuration. The mcpd process communicates all BIG-IP GTM configuration changes from the Configuration utility, and then gtmd updates the /config/gtm/wideip.conf file.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Command-line administrative access

Procedures

Reloading the wideip configuration to rectify the configuration discrepancies

If the configuration in the Configuration utility does not match the configuration in the /config/gtm/wideip.conf file, you can reconcile the changes by performing the following procedure.

Impact of procedure: The BIG-IP GTM system cannot respond to any wide IP queries until the gtmd process is started. For BIG-IP GTM synchronization group configurations the configuration update is propagated across all of the devices in the configured synchronization group.

  1. On the affected BIG-IP GTM system, log in to the command line.
  2. Load the /config/gtm/wideip.conf configuration by typing the following command:

    gtmload

  3. Restart the BIG-IP GTM daemon by typing the following command:

    bigstart restart gtmd
