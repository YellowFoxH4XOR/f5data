Description
The following error message is detected when running tmsh load sys config verify after upgrading from 14.1.4 to 16.1.2.2:

01b7003d:3: Per-request access policy <PARTITION/POLICY_NAME> is not referenced by any existing customization group set
Unexpected Error: Loading configuration process failed.

Environment

  • BIG-IP APM
  • Per Request Policy

Cause
On v14.x, there was no configuration for "customization-group-set" related to the Per-Request Policy (PRP).
v16.1.2.2 is now detecting the lack of this configuration.
F5 Product Development has assigned BUG ID 1135377 to this issue.

Recommended Actions
This message can be removed by manually adding the missing configuration into the bigip.conf file.

# Showing additional lines to highlight the section to add this configuration.
...
apm policy customization-group-set /Common/Non_related_policy {
    <output omitted>
}
### Adding next 3 lines to remove the error message:
apm policy customization-group-set /Common/POLICY_NAME {
    access-policy /Common/POLICY_NAME
}
###
apm policy customization-source /Common/modern { }
apm policy customization-source /Common/standard { }
...

Additional Information
This message should be categorized as warning instead of error. This is not causing the upgrade process to fail or stopping configuration to load.
However, it may be misleading when troubleshooting a different issue after an upgrade.
