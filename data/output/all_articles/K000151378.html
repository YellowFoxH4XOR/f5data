K000151378: Some New Dos Vectors were added with non-default configured value by an upgrade

Type
Support Solution
Published
2025-05-16
Updated
2025-05-16
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 17.5.0
Source
https://my.f5.com/manage/s/article/K000151378

Description

You may notice new attack vectors have been added with non-default configured values by an upgrade to 17.1.0 or later.

For example, TCP ACK (TS) or TCP Flags Uncommon vector is Disabled even though those default State value is Mitigate.

Environment

  • BIG-IP AFM
  • TCP BADACK Flood or TCP PUSH Flood vector had custom configured values before upgrade
  • Upgrade to 17.1.0 or later

Cause

This is by design.

TCP ACK (TS) vector:

The configured values from TCP BADACK Flood (tcp-ack-flood) vector in earlier releases will be applied to this vector.

TCP Flags Uncommon vector:

The configured values from TCP PUSH Flood (tcp-psh-flood) vector in earlier releases will be applied to this vector. 

Recommended Actions

None
