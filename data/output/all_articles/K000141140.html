Description

Duplicate X-Forwarded-For HTTP headers sent to pool member by profile setting and irule cause issue with backend application.

Environment

  • BIG-IP
  • The HTTP profile attached to the virtual server has been configured to send the X-Forwarded-For HTTP header.
  • An iRule  attached to the virtual server is also configured to send the X-Forwarded-For HTTP header

Cause

You are using multiple methods to send the same header.

Sending duplicate HTTP headers violates the HTTP standard and can cause issues for any applications and network infrastructure processing these headers. 

Recommended Actions

Choose one method to send the X-Forwarded-For HTTP Header once, do not send it using multiple methods.
