K000141422: Importing QualysGuard WAS beyond version 4.x xml export into ASM

Type
Support Solution
Published
2024-10-11
Updated
2024-10-11
Status
Final
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141422

Description

You are trying to import a Qualys Web Application Scanning (WAS) XML export into ASM but encounter an import error. The error message is similar to "Vulnerabilities file doesn't contain Vulnerabilities Found and Verified by Qualys."

Environment

  • QualysGuard WAS v9.7.69
  • ASM 17.x
  • Vulnerability assessment template for ASM

Cause

None

Recommended Actions

Please follow these steps.

  1. On Qualys UI, follow the steps below to download the XML report.
  2. Go to the Application Tab, hover the mouse cursor over the application row then you will see the chevron icon.
  3. Click the chevron icon to open a dropdown menu, select "View Report".
  4. You are now on the "Web Application Report" screen.
  5. Click the download icon in the upper right corner.
  6. The downloaded XML report should start with "WAS_WEBAPP_REPORT" and have no issues when importing to ASM.
        <?xml version='1.0' encoding='UTF-8'?>
        <WAS_WEBAPP_REPORT>
            <HEADER>
                <NAME>Web Application Report</NAME>
                <DESCRIPTION>Each targeted web application is listed with the total number of detected vulnerabilities and sensitive content.</DESCRIPTION>
                <GENERATION_DATETIME>09 Oct 2024 03:13PM GMT+0900</GENERATION_DATETIME>
                <COMPANY_INFO>
                    <NAME>DummyCompany</NAME>
                    <ADDRESS></ADDRESS>
                    <CITY>DummyCity</CITY>
                </COMPANY_INFO>
            </HEADER>
        </WAS_WEBAPP_REPORT>
