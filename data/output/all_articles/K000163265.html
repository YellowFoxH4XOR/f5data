Description

During F5OS-A system boot, after the BIOS screen, the system will show the GRUB menu such as the one below:

=====

CentOS Linux 7 (Core) (ostree:0)
CentOS Linux 7 (Core) (ostree:1)

 

Use the ^ and v keys to change the selection.
Press 'e' to edit the selected item, or 'c' for a command prompt.
The selected entry will be started automatically in 5s.

=====

A 5 seconds countdown timer is started before it automatically boots the default OS.

Environment

  • F5OS-A (rSeries)

Cause

  • System boot/reboot
  • F5OS-A upgrade

Recommended Actions

Do not press any key to interrupt the GRUB selection, so that system boots the default OS.

If you have pressed any key to interrupt or change the GRUB selection, it is not possible to determine which OS is the default from the GRUB menu. The safest recovery method, is to use AOM to reboot the appliance, by pressing Esc + ( or Alt + ( via serial console. During the next system boot, do not press any key at the GRUB screen and let the system boot the default OS. 

Additional Information

OSTree is a system for versioning updates of Linux-based operating systems. It can be considered as "Git for operating system binaries". F5OS uses OStree to manage different versions and when upgrading/downgrading F5OS, the installation process will pull the version objects from the relevant repository/registry. This is different from how the BIG-IP software volumes work. It is not possible to select the new version or rollback to the previous version of F5OS-A by selecting an item from the GRUB menu like how BIG-IP works.

If you boot a non-default OS from the GRUB menu, the system will be inoperative due to a mismatch of OS and SERVICE versions. The cluster will not be ready and tenants cannot be deployed. If this occurs during an upgrade, it may give the appearance of a failed or incomplete upgrade.
