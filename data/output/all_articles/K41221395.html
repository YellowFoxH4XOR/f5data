Issue

Error Message

01420006:3: File operation failed on "/var/apm/images/apmclients-7160.2018.417.2013-4204.0.iso"

In this error message, note the following:

  • <apmclients.xxxx.xxxx.xxx.xxx-xxx.x.iso> is the version of the APM client you are attempting to install.

For example, the following error message may appear in the /var/log/ltm file:

err tmsh[18438]: 01420006:3: File operation failed on "/var/apm/images/apmclients-7160.2018.417.2013-4204.0.iso".

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The TMOS Shell (tmsh)
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • You attempt to install an APM Clients .iso file and there is not enough space available in the /var directory.

You may also observe an error message similar to the following example at the same time in the Configuration utility:

Image File Error: call tmsh to install image failed

Impact

You are unable to install the APM Clients package.

Recommended Actions

To work around this issue, you can first try to remove large files in the /var directory. Common files that occupy disk space include user configuration set (UCS) files, which can be found in the /var/local/ucs directory. You can also increase the size of the /var directory before installing the APM client. From the command line of a BIG-IP system, the /var directory can be expanded by 1 GB. To do so, perform the following procedure:

Note: This workaround only applies to a single device, and will not persist across upgrades.

Impact of workaround: This procedure requires a reboot of the system. F5 recommends performing this procedure during a scheduled maintenance window.

  1. Log in to the Advanced Shell (bash).
  2. To increase the size of the /var directory by 1 GB, type the following command:

    NEW_SIZE=$(($(df -P /var | tail -1 | awk '{print $2}') + 1*1024*1024)); echo "Resizing /var to $NEW_SIZE (unit: 1K blocks); changes should take effect after a reboot"; tmsh modify sys disk directory /var new-size $NEW_SIZE; tmsh save sys config

  3. To reboot the device, type the following command:

    reboot
