Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K13309: Restricting access to the Configuration utility by source IP address (11.x - 12.x)

You can restrict access to the Configuration utility by the source IP address. To do so, perform one of the following two procedures for the version of the BIG-IP system that you are running:

BIG-IP 9.4.2 and later

Important: In some versions, the bigpipe httpd allow command does not properly restrict access to the Configuration utility. For more information, refer to K8518: The bigpipe httpd allow command does not restrict access to the Configuration utility. 

Adding to the existing list of hosts in the httpd allow list

To add an entry to the existing list of hosts that can connect to the Configuration utility in BIG-IP 9.4.2 and later, perform the following procedure:

  1. Log in to the command line.
  2. To add an entry to the existing list of hosts that can connect to the Configuration utility, use the following bigpipe command syntax:

    bigpipe httpd allow <IP_address / IP_address_range> add

    For example, to add the specific host address of 172.27.1.1 to the list of hosts that can currently connect to the Configuration utility, type the following command:

    bigpipe httpd allow 172.27.1.1 add

  3. To save the configuration, type the following command:

    bigpipe save

Replacing the existing list of hosts in the httpd allow list

To replace the existing list of hosts that can connect to the Configuration utility in BIG-IP 9.4.2 and later, perform the following procedure:

  1. Log in to the command line.
  2. To replace the existing list of hosts that can connect to the Configuration utility, use the following bigpipe command syntax:

    bigpipe httpd allow <IP_address / IP_address_range>

    For example, to replace the existing list of hosts that can connect to the Configuration utility with the hosts in the 172.27.0.0/255.255.0.0 network, type the following command:

    bigpipe httpd allow 172.27.0.0/255.255.0.0

  3. To save the configuration, type the following command:

    bigpipe save

Removing an IP address from the httpd allow list

To remove an IP address from the httpd allow list for BIG-IP 9.4.2 and later, perform the following procedure:

  1. Log in to the command line.
  2. Use the following bigpipe command syntax:

    bigpipe httpd allow <IP_address / IP_address_range> delete

    For example:
    • To remove the the hosts in the range, 172.27.0.0/255.255.0.0 from the existing list of hosts that can connect to the Configuration utility, type the following command:

      bigpipe httpd allow 172.27.0.0/255.255.0.0 delete

    • To remove the specific host address of 172.27.1.1 from the existing list of hosts that can connect to the Configuration utility, type the following command:

      bigpipe httpd allow 172.27.1.1 delete

  3. To save the configuration, type the following command:

    bigpipe save

BIG-IP 9.0.0 through 9.4.1

To restrict access to the Configuration utility by the source IP address for BIG-IP versions 9.0.0 through 9.4.1, perform the following procedure:

Note: The following changes are not carried over if the system is upgraded or if a hotfix is applied that modifies the httpd.conf file. Additionally, the changes are not synchronized and must be performed on each system in a redundant pair.

  1. Edit the httpd.conf file located in the /config/httpd/conf/ directory.
  2. Locate the following entry in the httpd.conf file:
      
    <Location /tmui>    Order Allow,Deny    Allow from all    AuthType Basic    AuthName "BIG-IP"    AuthPAM_Enabled on    AuthPAM_CacheTimeout 86400    require valid-user</Location>
  3. Comment out the Allow from all line. The line should appear similar to the following example:

    <!-- Allow from all -->

  4. Add the appropriate Allow statement for the source IP addresses that are allowed access, by following one of the examples below:

    Note: In addition to the examples provided, you can use a combination of partial and single addresses.

    • To specify a single IP address, add the following line:

      Allow from x.x.x.x

      For example:

      Allow from 10.10.1.20

    • To specify multiple single IP addresses, add the following line:

      Allow from x.x.x.x y.y.y.y z.z.z.z

      For example:

      Allow from 10.10.1.20 20.20.1.20 30.30.1.30

    • To specify a partial IP address, add the following line:

      Allow from x

      For example:

      Allow from 10

      Note: The format for partial IP addresses is treated the same as a network netmask pair for subnet restriction. The applied subnet mask is assumed to be 255 for each byte of the address specified.

    • To specify a network/netmask pair, add the following line:

      Allow from a.b.c.d/x.x.x.x

      For example:

      Allow from 10.10.1.20/255.255.255.0

  5. Once you have made the changes, save the changes to the http.conf file.

  6. Restart the httpd daemon to read the changes you have made, by typing the following command:

    bigstart restart httpd
