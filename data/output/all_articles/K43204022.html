Description

Configured a parameter's Data Type as File Upload with Maximum Length set to Any, but a large POST request is still blocked with the following violations:

Illegal POST data length
Illegal request length

Is this expected?

Environment

  • File upload
  • ASM violations

Cause

This is expected behaviour. The Maximum Length defined in the parameter applies to only the parameter value. It is completely separate from the the POST data length, which applies to the entire payload of the POST, and the Request Length, which applies to the entire request.

Recommended Actions

To allow larger requests and POST payloads, increase the values under the Allowed File Types - they are enforced separately from the Illegal parameter value length violation.

To navigate to Allowed File Types on the BIG-IP configuration utility, refer to the following:
  • BIG-IP 16.1.0 and later: Navigate to Security > Application Security > Security Policies > Select the name of your policy > HTTP Message Protection > File Types.
  • BIG-IP 13.1.x - 15.1.x: Navigate to Security > Application Security > File Types > Allowed File Types > Select the name of your policy. 

Additional Information

You will typically observe that the length reported in the Illegal request length violation is slightly higher than the one reported in the Illegal POST data length violation.
