Issue

Error Message

notice tmm[<PID>]: 01700000:5: PPTP CALL-REQUEST id;<ID Number> from;<Source IP Address> to;<Destination IP Address> nat;<NAT IP Address> ext-id;<ID Number>

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process
  • <ID Number> is the unique call ID assigned to the initiating caller
  • <Source IP Address> is the source IP address of the initiating caller
  • <Destination IP Address> is the destination IP address of the remote contact
  • <NAT IP Address> is the IP address of the NAT being used
  • <ID Number> is the unique call ID assigned to the remote contact

For example:

notice tmm4[16974]: 01700000:5: PPTP CALL-REQUEST id;39782 from;192.0.2.10 to;203.0.113.10 nat;198.51.100.15 ext-id;65422

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The client has sent an outgoing call request.

Impact

There is no impact. This is an informational message only.

Recommended Actions

None
