Description

F5OS physical interfaces are up but when configured them as LAG, it is not coming up and showing LACP_DEFAULTED

  • F5OS-A 1.1.1
  • rSeries

 

Cause

Software Bug on F5OS-A 1.1.1 which is unknown as of this writing. F5OS-A 1.1.1 is also End of Technical Support since Dec. 6, 2022

Recommended Actions

Upgrade to Supported version. Please refer K21501912: Software lifecycle policy for F5OS.
