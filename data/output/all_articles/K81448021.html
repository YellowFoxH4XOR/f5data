Known Issue

The BIG-IP ASM bd service may produce a core file and restart under certain conditions.

This issue occurs when all of the following conditions are met:

  • You deploy the iApp OWA Exchange 2010 application ready policy template for HTTP or HTTPS.
  • The security policy processes a large request for the /microsoft-server-activesync URL.

Impact

The BIG-IP ASM system stops processing traffic, and may fail over to a peer device when configured for high availability (HA).

Workaround

To work around this issue, you can modify the affected Request Body Handling security policy setting for the /microsoft-server-activesync URL to Do nothing. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs.
  3. Click the /microsoft-server-activesync URL link.
  4. Click Header-Based Content Profiles.
  5. Set Request Body Handling to Do nothing from the menu.
