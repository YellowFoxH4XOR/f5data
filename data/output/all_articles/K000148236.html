K000148236: DNS Resolution fails while connecting to VPN with Zscaler Private Access running on Windows

Type
Support Solution
Published
2024-10-23
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000148236

Description

Users with Zscaler Private Access installed on Windows experience DNS resolution issues while connecting to VPN.

 

Environment

  • BIG-IP APM Edge Client
  • Zscaler Private Access installed on Windows

 

Cause

Zscaler Private Access interacts with F5 DNS Replay Proxy Service (F5FltSrv.exe) causing DNS resolution issues

 

Recommended Actions

  1. Exclude DNS Relay Proxy Service (F5FltSrv.exe) from Zscaler policy
  2. If that's not possible, create a new APM client package without DNS Relay Proxy Service, then re-install this new client package:

------------

1. Go to Access > Connectivity/VPN, click on the connectivity profile attached to the VPN Virtual Server

2. Click on Customize Package at the bottom and choose Windows.

3. In the 'Customize Windows Client Package" and 'Available Components', uncheck "DNS Relay Proxy Service"

4. Hit Download

 

Then install this client package on the affected user's machines and verify F5 VPN client still works without DNS Relay Proxy Service.

------------
