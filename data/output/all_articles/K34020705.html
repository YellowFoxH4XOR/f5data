Description

Configuration cannot be loaded on post-14.x version if the "ne" operator was used alongside "class" command in iRule on the previous SW version.
As a side effect GUI won't be accessible.

Environment
  • Upgrade between pre-14.x and post-14.x versions of SW
  • Rule similar to:
    when CLIENT_ACCEPTED {
        if { [whereis [IP::client_addr] country] equals "BD" and [class match [IP::client_addr] ne CLASS]  } {
            drop
        }
    }

Cause

'class match' iRule statement can only be used alongside '

  • contains
  • ends_with
  • equals
  • starts_with.

Recommended Actions

Rewrite the effected iRule(s) to only use 'contains' or 'ends_with' or 'equals' or 'starts_with' statements:

  1. At the CLI Bash prompt, create a backup copy of the "bigip.conf" file:
    cp /config/bigip.conf /config/bigip.backup.K34020705
  2. Open /config/bigip.conf for editing using a preferred text editor (vi or nano)
  3. Rewrite the iRule(s) to only use 'contains' or 'ends_with' or 'equals' or 'starts_with' statements.
  4. Load the configuration to the running memory using 'tmsh load sys config'
