Topic

This article applies to F5 AI Gateway. For information about other products, refer to the following article:

  • K914: Displaying the software version of your F5 product

You should consider using this procedure under the following condition:

  • You want to determine the AI Gateway software version.

Description

You can use the helm list command to determine the AI Gateway software version.

Note: In most cases, the helm ls output is sufficient to determine the AI Gateway version installed. However, if you manually selected an older software version than the default when using the --set aigw.image.tag parameter with the helm install command, you will need to use kubectl commands to view the deployment, in order to observe the installed software version.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have a valid user account on the Kubernetes system where AI Gateway is installed.

Procedures

  • Using the helm ls command
  • Using the kubectl command

Using the helm ls command

Using the helm ls command is a fast way to determine the installed software version, if the default installation was performed.

  1. Log in to the system where AI Gateway is installed.
  2. List the installed helm charts using the helm ls -A command, taking note of the version listed under APP VERSION.
    For example:

    helm ls -A

    The output appears similar to the following example:

    NAME    NAMESPACE       REVISION        UPDATED                                 STATUS          CHART           APP VERSION
    aigw    ai-gateway      1               2025-02-26 15:52:57.995000279 -0800 PST deployed        aigw-0.1.0      v1.0.0

    Note: The -A flag used with this helm command lists releases across all namespaces. For additional filtering options, refer to the Helm List documentation page. This link takes you to a resource outside of MyF5. The third party could remove the document without our knowledge.

Using the kubectl command

If a non-default software version was selected during installation, using the --set aigw.image.tag helm install parameter, the helm ls output will still show the default software version for the chart that was used to perform the installation instead of the actual installed software version. You can use the kubectl describe command to determine the software version from the deployment, or you can use the following go-template filter with the kubectl get deployments command to determine the software version.

  1. Log in to the system where AI Gateway is installed.
  2. List the installed version of AI Gateway, AI Gateway Processors, and the version of Helm chart used to install, using the following command:

    kubectl -n ai-gateway get deployments -o go-template='{{range .items}}{{"\n"}}{{.metadata.name}}{{"\n"}}app.kubernetes.io/version={{index .metadata.labels "app.kubernetes.io/version"}}{{"\n"}}helm.sh/chart={{index .metadata.labels "helm.sh/chart"}}{{"\n--\n"}}{{end}}'

    The output appears similar to the following example:

    aigw
    app.kubernetes.io/version=v1.0.2
    helm.sh/chart=aigw-0.2.3
    --

    aigw-processors-f5
    app.kubernetes.io/version=v1.0.1
    helm.sh/chart=aigw-0.2.3
    --
