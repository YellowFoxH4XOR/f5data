K000135364: After rSeries F5OS-A upgrade to 1.5.0 interfaces are greyed out in the network dashboard on the GUI

Type
Support Solution
Published
2023-07-04
Updated
2023-09-04
Applies to
  • F5OS
  • F5OS-A: 1.5.0
Source
https://my.f5.com/manage/s/article/K000135364

Description

After the rSeries F5OS-A upgrade to 1.5.0, interfaces are greyed out in the network dashboard on the GUI. For example:

 

Environment

  • F5OS-A 1.5.0
  • rSeries
  • Interface with 1GB speed
  • Dashboard

 

Cause

Bug ID 1311049: For a system that has interfaces with 1GB speed, the network tab on the webUI dashboard is not showing all information

Recommended Actions

As a workaround, you can check interface status and speed from CLI (SSH) by using the command show interfaces summary

 

Additional Information

None
