Known Issue

This is the result of a known issue. 3-DNS Controllers that are licensed as 3-DNS stand-alone systems contain a licensing error that prevents you from creating a default gateway pool using the bigpipe command. This does not affect normal, static default gateways.

You may receive the following error message when attempting to create a default gateway pool on the 3-DNS Controller:

bigpipe:  Load balancing is not available
bigpipe:  The requested pool was not found
Error setting default_gateway to default_gateway_pool

Note: The licensing issue also prevents configuration of a default gateway pool using the First Time Boot Utility (FTBU).

F5 Networks Product Development tracked this issue as CR31928 and CR41911.

Workaround

You can work around this issue by entering a single default gateway when you run through the First-Time Boot utility, then configuring the gateway pool using the Configuration utility.
