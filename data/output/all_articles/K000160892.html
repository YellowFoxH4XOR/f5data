Description

This article addresses the recommended approach for handling SSL/TLS traffic between layered virtual servers in a BIG-IP Advanced WAF and BIG-IP APM deployment. Disabling SSL profiles on either the BIG-IP Advanced WAF (outer) or BIG-IP APM (inner) virtual servers can cause session timeouts, failed logins, and potential exposure of sensitive data if SSL is not enabled.

Environment

  • BIG-IP Advanced WAF
  • BIG-IP APM
  • Layered virtual server configuration: BIG-IP Advanced WAF in front, BIG-IP APM behind
  • Client-side and server-side SSL profiles
  • Session cookies (e.g., MRHSession) with "Secure" attribute
  • Compliance requirements (PCI DSS, HIPAA, etc.)

Cause

Disabling SSL/TLS on either the BIG-IP Advanced WAF server-side or BIG-IP APM client-side virtual server results in unencrypted traffic. Browsers will not send session cookies with the "Secure" attribute, leading to session management failures and exposing sensitive data to interception.

Answer/Recommended Actions

  1. Always enable SSL/TLS profiles on both the client-side and server-side virtual servers in a layered BIG-IP Advanced WAF + BIG-IP APM deployment.
    • Assign a Client-SSL profile to the BIG-IP APM virtual server (port 443).
    • Assign a Server-SSL profile to the BIG-IP Advanced WAF virtual server if traffic is passed to BIG-IP APM.
  2. Ensure session cookies with the "Secure" attribute are transmitted over encrypted channels to maintain proper session management and authentication.
  3. Avoid disabling SSL unless the internal network between BIG-IP Advanced WAF and BIG-IP APM is fully trusted, isolated, and there are no compliance requirements for encryption.
  4. Disabling client-side SSL on BIG-IP APM is not supported and will break session handling.
  5. Review and follow compliance requirements for secure transmission of sensitive data.

Additional Information

  • Session cookies with the "Secure" attribute will not be sent over HTTP, resulting in immediate session timeouts or failed logins.
  • Security standards require encrypted channels for sensitive data and session cookies.
  • Layered virtual server architecture is recommended for combining BIG-IP Advanced WAF and BIG-IP APM, but both must use SSL profiles for secure and functional operation.
