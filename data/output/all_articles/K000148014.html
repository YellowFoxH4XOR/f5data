Description

  • How can I investigate an attack from the Distributed Cloud Console dashboard? 

 

Environment

  • F5® Distribution Cloud Console

   

 

Answer/Recommended Actions

How to identify the Load Balancers that are under attack:

 

Access to Web App & API Protection


 1. Select from the left menu the Dashboard option, and you can check all the Load Balancers that belong to the tenant. 

 2. Organize by Security events, so you can identify which LB is under attack, and select the Load Balancer in question.
 

3. Once you select the Load balancer, you will get all the information of the security events, or top signatures hit Top Attack Types, etc., over the Dashboard tab.
 

Filter by the Security


1. You can navigate also to the Security Events tab and filter by different types of events.
 

2. The request tab option, will show the different types of client IP, Origin Server with more traffic or request, along with the date/time.

 

Please keep in mind that some features will be activated in the console to get logs if the services are contracted, for instance the DDoS services.
