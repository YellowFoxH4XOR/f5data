Description

You are seeing unexpected connection entries in the BIG-IP LTM connection table. These connections are not related to any virtual servers and are instead related to monitoring traffic between BIG-IP and pool members. The issue is causing concern as you are not expecting these connections to be present.

Environment

  • BIG-IP LTM version 14.1.2, but this issue may occur in all versions.
  • http monitor is configured.
  • No HTTP response from the pool member.

Cause

In some cases, monitoring traffic between BIG-IP and pool members may remain in the connection table for up to 15 minutes when the pool member is unresponsive to GET requests. This is expected behavior and is due to the system attempting to contact the pool member with increasing intervals. The monitoring connections are tracked in the connection table as they pass through TMM.

Recommended Actions

None, as this behavior is by design and expected for monitoring traffic. No further action is required.
