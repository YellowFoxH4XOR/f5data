K9669: The WhiteHat Sentinel GUI returns an error message when accessing the BIG-IP ASM

Topic

Beginning in BIG-IP ASM version 9.4.5, you can integrate the WhiteHat Sentinel Scanner with BIG-IP ASM.

Note: For more information, refer to K9254: Integrating the WhiteHat Sentinel Scanner with BIG-IP ASM.

When you perform the procedures in SOL9254, you must import the security policy and attack signatures to the BIG-IP ASM before connecting to the WhiteHat Sentinel portal.

If you connect to the WhiteHat Sentinel portal before importing the security policy and attack signatures to the BIG-IP ASM, you may receive the following error message in the WhiteHat GUI:

Failed to contact WAF: Security error accessing url

This issue occurs because the WhiteHat flash component is attempting to access the BIG-IP ASM system and retrieve the /crossdomain.xml file using a client browser framework, but it is unable to complete the SSL handshake with the BIG-IP ASM GUI due to an SSL certificate error.

Workaround

To work around this issue, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Using the same browser window, type the IP address configured for the WhiteHat Sentinel GUI.
  3. Accept the SSL certificate.

After you complete this procedure, you can connect from WhiteHat Sentinel GUI to BIG-IP ASM GUI.

Note: You should perform this procedure each time you connect to the BIG-IP ASM from the WhiteHat Sentinel portal.
