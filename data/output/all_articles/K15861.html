Description

The following matrix lists third-party software that runs on the Linux host operating system on BIG-IQ systems.

Important: F5 hotfix and point releases may include upgrades and security fixes for the following third-party software packages. As a result, when evaluating vulnerability status for third-party software, F5 recommends that you refer to Security Advisory articles to determine if a BIG-IQ release is vulnerable.

Java OpenJDKFor BIG-IQ Centralized Management, use the following commands:

Query for the full path of the java binary used by the system, using the following command:

ps ef | grep openjdk.*java | sed /grep/d | awk {'print $7;'}

With the full path of the java binary, you can query the exact version and update numbers of the java binary. Use the following command syntax where X.Y.Z denotes to the representation of the binary version number:

/usr/lib/jvm/jre-X.Y.Z-openjdk.x86_64/bin/java -version

For example, for the system with the version 1.8.0 java binary, use the following command:

/usr/lib/jvm/jre-1.8.0-openjdk.x86_64/bin/java -version

Example 1: To determine the ZebOS version by using the rpm command, enter the following command:

rpm -qa | grep -i zebos

The output from a BIG-IQ system running 8.2.0 may appear similar to the following example:

ZebOS-7.10.6-0.0.310.i686

The numeric value after the first dash (-) indicates the ZebOS software version, which is 7.10.6.

Example 2: To determine the Java OpenJDK version, use the following commands:

  1. Query the java processes using the following command:

    ps ef | grep openjdk.*java | sed /grep/d | awk {'print $7;'}

  2. For example, on the BIG-IQ 8.2.0 system, use the 1.8.0 binary to query for the version and update numbers using the following command:

    /usr/lib/jvm/jre-1.8.0-openjdk.x86_64/bin/java -version

    The output of the command may appear similar to the following example:

    openjdk version "1.8.0_212"
    OpenJDK Runtime Environment (build 1.8.0_212-b04)
    OpenJDK 64-Bit Server VM (build 25.212-b04, mixed mode)

    The Java OpenJDK version is 1.8.0_212, which refers to Java 8 update 212.
