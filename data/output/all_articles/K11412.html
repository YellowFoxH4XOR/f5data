Known Issue

This is the result of a known issue. Writes to a CIFS global server VIP will fail if the Server Message Block (SMB) Query Path Info (QPI) request is split over multiple TCP segments. When this issue occurs, the client will receive the following error message:

The specified network name is no longer available

In addition, the following message will be logged to the fastpath log on ARX:

: cifs_qpi_dnas_path_relookup -  re-run qpi request

F5 Networks Product Development tracked this issue as ARX ID 37868 and it was fixed in ARX version 5.1.5. For information about upgrading, refer to the ARX Release Notes.

This issue was fixed in a hotfix available for ARX version 5.1.0. Customers affected by this issue should request the hotfix from F5 Networks Technical Support, referencing this Solution number and ARX ID 37868.
