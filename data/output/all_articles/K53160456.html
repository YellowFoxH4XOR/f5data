Known Issue

You are unable to generate new Secure Sockets Layer (SSL) keys after restarting a SafeNet external hardware security module (HSM) device.

This issue occurs when all of the following conditions are met:

  • You have configured your BIG-IP system to use a SafeNet Luna SA HSM device.
  • You restart the SafeNet network HSM device.

After you restart a SafeNet HSM device, the Luna SA client is unable to authenticate with the SafeNet HSM device.

Impact

You are unable to generate SSL keys after you restart the SafeNet HSM device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After restarting the SafeNet Luna HSM device, you are unable to generate new SSL keys.
  • Commands to generate new keys fail with error messages that appear similar to one of the following examples:

    • Key management library returned bad status: -37, Nethsm fails to complete the task

    • Error: The user is not logged in to the selected slot (1).
      Key creation failed. Key not found
      Safenet: Generate key failure.
      Safenet HSM command execution failed

Workaround

To work around this issue, you can force the client to reauthenticate with the SafeNet HSM device by closing and reopening the SafeNet Luna SA client connection. To do so, perform the following procedure:

Impact of workaround: The BIG-IP system is unable to use the SafeNet HSM device while you restart the connection. The impact of the suggested workaround will depend on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the command line.
  2. Close the existing client connection to the SafeNet HSM device by typing the following command:

    /shared/safenet/toolkit/sautil -v -s 1 -i 10:11 -c

  3. Open a new client connection to the SafeNet HSM device using the following command syntax:

    /shared/safenet/toolkit/sautil -v -s 1 -i 10:11 -o -p <hsm_partition_password>

Alternatively, you can reinstall the SafeNet Luna SA client. For information about installing the SafeNet Luna SA client, refer to the Manually Setting Up the SafeNet Luna HSM with BIG-IP Systems chapter of the BIG-IP System and SafeNet Luna SA HSM: Implementation guide.
