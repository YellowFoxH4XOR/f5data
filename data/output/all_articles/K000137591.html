K000137591: CRDs are not removed after Aspen Mesh is uninstalled using helm

Type
Support Solution
Published
2023-11-15
Updated
2023-11-22
Applies to
  • Aspen Mesh
Source
https://my.f5.com/manage/s/article/K000137591

Description

When deleting Aspen Mesh using helm uninstall, Aspen Mesh and Istio crds are not removed.

Environment

- Aspen Mesh CRDs
- Helm

Cause

None, it's expected behaviour.

Recommended Actions

MATCH_STRING="istio.io"
kubectl get crds -oname | grep "$MATCH_STRING" | xargs kubectl delete

or

kubectl get crds | grep -e istio.io -e aspenmesh.io |
while read -r crd _; do
kubectl delete crd "$crd"
done || true

Additional Information

As per: https://istio.io/latest/docs/setup/install/helm/#uninstall

"By design, deleting a chart via Helm doesn’t delete the installed Custom Resource Definitions (CRDs) installed via the chart."
