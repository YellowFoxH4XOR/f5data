Known Issue

Once you set a netmask for a virtual server through the Configuration utility, you cannot delete it.

Note: It is possible to inadvertently set a netmask on a non-network virtual server from the Virtual Address Properties tab of the Configuration utility. A non-network virtual server that has a netmask will not function.

F5 Product Development tracked this issue as CR4056.

Workaround

You can work around this issue using one of the following methods:

  • Using the Configuration utility, remove the virtual server and add it back.
  • Using the command line interface, edit the virtual server definition in the /config/bigip.conf file and issue the b load command to save the changes.
