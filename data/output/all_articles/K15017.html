Known Issue

Under rare conditions the BIG-IP APM apd process may exit and core.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is licensed and provisioned on chassis platforms configured for high availability.
  • The access policy is configured with a Deny ending.
  • The BIG-IP APM system experiences a failover.

When the BIG-IP APM system experiences a failover event on a chassis platform configured for high availability, it is possible for session variables to become inaccessible. When this issue occurs, the apd process may produce a core file while attempting to read variables for current sessions.

Impact

Users are unable to connect to application resources while the apd process restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425808 on the Diagnostics > Identified > Low screen.
  • The BIG-IP APM system stops accepting connections.
  • The apd process produces a core file in the /shared/core directory.
  • Messages appear in the /var/log/apm file that appear similar to the following example:

    notice apd[22047]: 01490000:5: ** SIGSEGV **
    notice apd[22047]: 01490000:5: fault addr: 0x0
    notice apd[22047]: 01490000:5: fault code: 0x1
    notice apd[22047]: 01490000:5: fault time: Thu Jun 27 13:33:29 2013
    notice apd[22047]: 01490000:5: EAX=0x0 EBX=0x0 ECX=0x0 EDX=0x0
    notice apd[22047]: 01490000:5: ESI=0xA8E3020 EDI=0xA8C2AD8 EBP=0x5973D7A8, ESP=0x5973D6DC
    notice apd[22047]: 01490000:5: EIP=0x57A3CCC3
