Description

Observed a message similar to the following in /var/log/ltm:

info systemd-journal[11641]: Permanent journal is using 24.0M (max allowed 20.0M, trying to leave 3.1G free of 19.1G available → current limit 24.0M).

What does this message mean?

Environment

  • Logging

Cause

This is an informational message sourced from systemd-journald when it starts. Typically this message will be seen on boot, or after a restart of systemd-journald.

Recommended Actions

No action is required as this is an informational message.

Additional Information

The content of the message can be understood as follows:

  • The systemd journal is configured to store the journal persistently at /var/log/journal. Those "permanent" journal files are using ~24MB.
  • The journal is configured to use ~20MB of disk space, based on the SystemMaxUse parameter.
  • The journal is configured to leave 15% of the available disk space on the filesystem where the files reside (/var/log), based on the SystemKeepFree parameter, and is attempting to honour that by leaving ~3.1GB free of ~21GB.
  • Currently enforced limit is ~24MB, based on the smaller of the two parameters above.

The systemd documentation contains more information about the parameters that control journald behaviour:

  • journald.conf
