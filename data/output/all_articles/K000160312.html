K000160312: F5OS-A Host triggers the APIGW messages to update the Vlan Tagging configuration in tenant after timezone update in F5OS

Type
Support Solution
Published
2026-03-12
Updated
2026-03-12
Source

Description

Tenant Vlan tag re-configuration triggered from F5OS-A Host during timezone update in F5OS.

Environment

  • F5OS-A
  • Tenant
  • VLAN Tag

Cause

Behavior as Designed.

Answer/Recommended Actions

Even though, Tenant vlan tagging configuration can be changed from Tenant but it is not a recommended practice to do so.

In case, Tenant vlan tagging configuration does not match the F5OS Host vlan tagging configuration then F5OS will trigger update using APIGW messages to overwrite the tenant VLAN tagging current configuration.

There can be different events when F5OS may trigger the update to Tenant VLAN tag configuration like F5OS reboot, F5OS interface or vlan related changes, F5OS timezone updates etc.

In this Example, Tenant is configured with no vlan tag and F5OS Host is configured with vlan tag. F5OS updates the timezone which triggered the APIGW messages to update the vlan tag in Tenant which caused the Tenant tagging configuration changed from untagged to tagged which caused tenant to be unreachable on the network.
