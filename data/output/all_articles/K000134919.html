Description

You may encounter a 404 - Doesn't Exist error when you attempt to upload a QKView to F5 iHealth portal from the following location on a BIG-IP system:

  • From the System >> Support page in the BIG-IP Configuration utility
    • Select New Support Snapshot.

    • Select Generate and Upload QKView to iHealth.

    • Select Start to initiate the process to generate a QKView and upload to iHealth.

Environment

  • BIG-IP devices running BIG-IP 17.1.0 and earlier.

Cause

You attempt to upload QKView files from a BIG-IP version that does not have the new F5 iHealth API Token Service implemented. As a result, you will not be able to uoload a QKView to F5 iHealth from the BIG-IP system but will instead receive a 404 - Doesn't Exist message.

Recommended Actions

You have to download the QKView locally and manually upload the QKView to F5 iHealth:

Generate the QKView from BIG-IP

From the Configuration utility
  1. Log in to the Configuration utility.
  2. Go to System > Support.
  3. Select New Support Snapshot.
  4. For Health Utility, select Generate QKView.

  5. Select Start.
From the Command Line
  1. Log in to the command line.
  2. To run the qkview utility, enter the following command:

    qkview

  3. The output file name displays after the command has completed.

Download the last generated QKView from the filesystem in BIG-IP to a local machine

From the Configuration utility
  1. Log in to the Configuration utility.
  2. Go to System > Support.
  3. You should see the QKView file that was generated from the previous procedure in the Last Generated Snapshot section.
  4. Select Download to download the QKView file to the local machine.

From the Command Line

Collect the output file from the /var/tmp/ directory by copying the file to an external host using a utility such as ftp or scp. For more information, refer to K175: Transferring files to or from an F5 system.

Upload the QKView file to F5 iHealth portal

  1. Login to iHealth.f5.com
  2. Select Upload in the banner.
  3. Select Choose and navigate to the QKView file you have downloaded to the local machine.
  4. Select Upload QKView(s) to initiate the upload of the QKView file to iHealth.

Additional Information

For some newer versions such as 16.X or 17.X there may be an Engineering Hotfix available from F5 support.  If you need one then please open a case until which time ID1225789 is released in a readily available fixed version.
