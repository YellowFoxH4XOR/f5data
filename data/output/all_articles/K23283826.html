Description

How to Remove F5 logo on the Webtop landing page

Environment

Relevant environmental factors specific to the topic

  • Customize/ remove F5 logo
  • Customization

Cause

None

Recommended Actions

Normally, removing logo can be done under Access  ››  Profiles / Policies : Customization : Advanced, then select the profile in question and click "header.inc" and remove header_logo section entirely

You can also replace logo

  1. Edit the VPE item "Logon Page" and then click "[Revert to Default]" next to "Front Image"
  2. Go to Access  ››  Profiles / Policies : Customization : Quick Start/Basic
  3. Select Access Profile
  4. Select Language "All Languages"
  5. Click on "Upload new Image", select your logo image
  6. Click "Save" button (at the bottom of the page)
  7. Apply Access Policy

So in the VPE in the Login you can change the image displayed on the right. If you want to change other images on the page you need to go to Access Policy>Customization>branding, expand access profile, expand profile>Common>Page header settings>image browser>header left image
