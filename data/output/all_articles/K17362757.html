Issue

Error Message

warning sod[<PID>]: 010c0083:4: No failover status messages received for <timeout> seconds, from device <device> (<IP_address>).

In this error message, note the following:

  • <PID> is the process ID for the sod process.
  • <timeout> is the timeout interval for failover packets.
  • <device> is the peer device's domain name and management IP address.
  • <IP_address> is the peer device failover IP address.

For example:

warning sod[7656]: 010c0083:4: No failover status messages received for 3.100 seconds, from device /Common/bigip01.com (192.168.5.10) (unicast: -> 10.10.5.11).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions is met:

  • The sod (failover daemon) process has not received a failover heartbeat packet from a peer connection during the configured timeout interval.

The log indicates that sod is no longer receiving failover updates from a peer. Possible root causes are a busy or offline system, or connectivity issue caused by external network failure.

Impact

A failover may happen if sod failed to receive failover packet during the timeout on all failover addresses.

Recommended Actions

To further determine the peer connection status, refer to K95002127: Troubleshooting BIG-IP failover events
