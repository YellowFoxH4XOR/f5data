Security Advisory Description

The NGINX Controller Administrator password may be exposed in the systemd.txt file that is included in the NGINX support package. (CVE-2021-23019)

Impact

The Administrator password is exposed in the NGINX support package. This password leak occurs only when you enabled sudo auditing.

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by installing a version listed in the Fixes introduced in column. If the Fixes introduced in column does not list a version for your branch, then no update candidate currently exists for that branch and F5 recommends upgrading to a version with the fix (refer to the table).

Mitigation

To mitigate this vulnerability, you can disable sudo auditing. This vulnerability occurs only when you enabled sudo auditing on the system. Disabling sudo auditing depends on the specific operating system NGINX Controller is running on. Additionally, if you suspect that you exposed the Administrator credentials, reset the password immediately. To do so, perform the following procedures:

  • Disable sudo auditing
  • Reset Administrator account password

Disable sudo auditing

Impact of action: Performing the procedure should not have a negative impact on your system.

Note: You can implement Sudo auditing using the following packages: RHEL/Centos, audit and Ubuntu, auditd.

For more information, refer to the following articles:

  • Defining audit rules in Redhat documentation.
  • How do I configure Linux audit rules to track user activity? in Amazon Web Services (AWS) documentation.
