Description
When configuring OWA for portal access you will need to create a manual Client-Initiated forms SSO object to properly pass the user credentials from APM login page to OWA

Environment

  • BIG-IP APM with Portal Access to OWA 2016
  • SSO Credential Mapping in VPE

Cause
Expected Behavior

Recommended Actions
Configure Client-Initiated Forms SSO and apply the object to OWA Portal Resource URL

Configure Client-Initiated Forms SSO

  1. Log in to the Configuration Utility
    Access  ››  Single Sign-On : Forms - Client Initiated ›› Click Create...

  2. Name the SSO Configuration, for example: owa_sso_client_init

  3. Click on Form Settings ›› Click Create...

  4. Name the Form, for example: owa_form

  5. Click on Request Detection
    Detect request for form by: URI
    Request URI: /owa/auth/logon.aspx
    Form Identification: Form Parameters

  6. Click on Form Parameters below Form Identification ›› Click Create...

    Form Parameter NameForm Parameter ValueSecure
    usernameSelect: %{session.sso.token.last.username} 
    passwordSelect: %{session.sso.token.last.password}true


    Note: If you are using OWA logon options, click Create again in the Forms Parameters box and add the following parameter. If you add these parameters and you are not configured to use them, SSO will fail.

    Form Parameter NameForm Parameter Value
    flagsType: %{session.custom.owa.flags}
    trustedType: %{session.custom.owa.trusted}

  7. Click on Logon Detection
    Detect Login by: Presence of Cookie
    Cookie Name: cadata

  8. Click on Javascript Injection below Advances Settings
    Injection Method:     extra
    Extra Javascript: clkLgn()

  9. Click OK to save Form Click OK to save SSO Configuration

Apply SSO Configuration to OWA Portal Access

  1. Log in to the Configuration Utility
    Access  ››  Connectivity / VPN : Portal Access : Portal Access Lists

  2. Click on OWA Portal Resource name

  3. Click on the Resource Item with the Paths for /*
    SSO Configuration: owa_sso_client_init

  4. Click Update
