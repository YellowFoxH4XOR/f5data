Description

You may be able to provision and configure features for modules that are listed in the Optional Modules section of the BIG-IP license. However, functionality for these features is inactive unless the license includes support for the module.

BIG-IP licenses indicate the active modules and optional modules which are available on the system.

Active modules

The features for modules listed in the Active Modules section are fully licensed and available for provisioning, configuration, and use.

Optional modules

The features for modules listed in the Optional Modules section (sometimes referred to as unlicensed modules) are available for licensing. The BIG-IP system may allow you to provision and configure objects for an optional (unlicensed) module feature; however, functionality for the optional module feature is inactive until the BIG-IP system is licensed for the module feature.

For example, on a system that lists DNSSEC in the Optional Modules section, you may be able to configure features such as Domain Name System Security Extensions (DNSSEC). However, unless you contact your F5 Sales representative and purchase the add-on license for the DNSSEC module, functionality remains inactive.

Cause

 None

Recommended Actions

To view the Active Modules and Optional Modules sections for your BIG-IP system, perform either of the following actions:

  • In the Configuration utility, navigate to System > License.
  • From the command line, use the tmsh show /sys license detail command.

For information about provisioning and using one or more of the modules listed as optional on your BIG-IP system, contact your F5 Sales representative.
