Description

GUI getting stuck on 'processing request' when trying to export reports under security > overview > Analytics or application traffic. 
No issues found when exporting reports under Statistics > Analytics
 

Environment

  • ASM provisioned 
  • Trying to export report under security > overview > Analytics or application traffic.
  • No CPU/Memory/Disk utilization found 
     

Cause

Bug ID 1009093: GUI widgets pages are not functioning correctly
 

Recommended Actions

  1. Log out from GUI. 
  2. Back up the file /var/ts/dms/amm/templates/overview.tpl using below command:
    cp /var/ts/dms/amm/templates/overview.tpl  /var/ts/dms/amm/templates/overview.tpl.bk
     
  3. Edit the file in vi editor and remove following line:
    <script type="text/javascript" src="script/analytics_stats.js{{BIGIP_BUILD_VERSION_JS}}"></script>
     
  4. Add the following lines after the 'var _default_smtp = '{{smtp_mailer}}';' line:
    $(document).ready(function() {
            if(!window.AVR_LOCALIZATION) return;
            $('.need-localization-avr').each(function() {
                var item = $(this);
                if (item.is("input")) {
                    var key = "avr." + item.val().replace(/\s/g, '');
                    item.val(window.AVR_LOCALIZATION[key] || item.val());
                } else {
                     var key = "avr." + item.text().replace(/\s/g, '');
                     item.text(window.AVR_LOCALIZATION[key] || item.text());
                }
             }).removeClass('need-localization-avr');
    });
     
  5. Save and exit. 
  6. Log back in to GUI.
