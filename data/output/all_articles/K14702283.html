Description
When trying to add disallowed method or disallowed response codes to a Constrained Application Protocol (CoAP) Protocol Inspection profile you may see an error that looks similar to these:

01071c1f:3: Protocol Inspection compliance inspection /Common/coap_disallowed_methods requires valid value: 0.01
01071c1f:3: Protocol Inspection compliance inspection /Common/coap_disallowed_response_codes requires valid value: 2.01

Environment

  • BIG-IP AFM
  • IPS License

Cause
The reason for this happening is that the profile will only accept positive integer values for these codes.
The codes that it is looking for are actually outlined in the original IETF draft for this protocol and are not listed in the RFC 7252.
