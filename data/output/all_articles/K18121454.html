Description

  • You get a warning log similar to the following, indicating that a certificate on the default BIG-IP CA-bundle has expired or is about to expire:

    warning tmsh[<PID>]: 01420008:4: Certificate 'CN=<CertificateName> CA,O=<CertIssuer>, Inc.,C=US' in file /Common/ca-bundle.crt will expire on <Month> <Day> <HH:MM:SS> <YEAR> <TIME ZONE>

  • You want to update or remove the expiring certificate from the bundle ca-bundle.crt

Environment

  • CA Bundle Certificates
  • SSL Profiles

Cause

The default CA certificate bundle file used by the system contains some older certificates, expired or soon-to-be expired.

Recommended Actions

You can either remove the expiring certificate from the CA Bundle or update the CA Bundle. In either case, verify if the ca-bundle.crt is being used by any SSL Profiles before making any changes.

Removing the expiring certificate from the CA Bundle

  • Follow the steps described in K74439849: How to remove expired certificates from CA-bundle.crt

Updating the CA Bundle

  • Follow the steps described in K60612439: Manually updating the BIG-IP default CA certificate bundle file
