K3376: How disabling web aggregation (OneConnect) affects SSL proxies

Topic

If you disable OneConnect on BIG-IP, clients will still be able to negotiate HTTP version 1.1 sessions that use keep-alives successfully. Disabling OneConnect only changes the behavior of requests that are sent over the keep-alive session after the initial request.

If OneConnect is disabled and a client creates a connection that uses keep-alives, the connection will use keep-alives as normal, assuming the servers in the pool that are being load balanced accept keep-alive requests. Delayed binding features will be applied only to the first request in the keep-alive session. All subsequent requests over the keep-alive session will be load balanced to the node that was selected during the client's first request.
