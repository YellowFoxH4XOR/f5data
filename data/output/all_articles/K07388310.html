Known Issue

When you perform some configuration operations, such as Configuration Syncronization (ConfigSync), they fail with user restriction errors.

This issue occurs when all of the following conditions are met:

  • You configure multiple devices in a device group for remote authentication.
  • A user has different access permission on the devices in the device group, such as the following example:
    • On device 1, user A has role permissions to all partitions.
    • On device 2, user A has role permissions restricted to a single partition.
  • The user performs an operation that involves accessing partitions on each device, such as the following example:

    The BIG-IP system attempts a ConfigSync operation in which one device tries to sync an [all] partition to a peer that has a configuration for a user that is not an [all] partition.

Impact

Your configuration operations fail with User Restriction errors.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Some operations that access partitions on multiple devices, such as ConfigSync, fail with User Restriction errors.

    For example, when the BIG-IP system performs the ConfigSync operation, it produces an error message similar to the following example:

    error 01070821:3: User Restriction Error: Once configured for specific partition(s), user cannot have [all]

Workaround

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends that you test any such changes during a maintenance window with consideration to the possible impact on your specific environment.

To work around this issue, use local authentication or ensure the remote authenticated account has the same access permissions on each device.
