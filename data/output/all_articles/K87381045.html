Known Issue

The BIG-IP Virtual Edition (VE) may produce a kernel panic during startup.

This issue occurs when all of the following conditions are met:

  • You are running BIG-IP VE in a Microsoft Hyper-V virtual machine.
  • The VE RAM is configured so it spans multiple NUMA nodes.

Impact

The BIG-IP VE instance may fail to start.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the Microsoft Hyper-V boot diagnostics, you may see an error message similar to the following example:

    PANIC: early exception 06 rip 10:ffffffff816d8936 error 0 cr2 0

  • The BIG-IP VE system fails to start.
