K000162122: VELOS blade dma-agent incorrectly reported not ready in 'show system health'

Source

Description

The show system health output in a VELOS partition indicates that the dma-agent service is not healthy on one of the blades, similar to the following example:

COMPONENT           COMPONENT  COMPONENT                                            ATTRIBUTE             ATTRIBUTE  ATTRIBUTE  ATTRIBUTE
NAME          NAME  HEALTH     SEVERITY   ATTRIBUTE NAME                                DESCRIPTION           HEALTH     SEVERITY   VALUE      UPDATED AT
----------------------------------------------------------------------------------------------------------------------------------------------------------------------
blade-1       -     ok         notice
blade-3       -     ok         warning    blade/services/dma-agent - service:ready  Service ready status  ok         warning    false      2026-06-23T11:00:56-07:00
controller-1  -     ok         notice
controller-2  -     ok         notice

However, the service is running according to the dma-agent.health file, and there is no issue with running tenants or passing traffic.

[root@controller-1(VEL1610):Active ~]# ssh blade-3 docker exec platform-monitor cat /var/diagnostics/services/dma-agent.health
STATE: running
STATUS: ok
SEVERITY: info
VERSION: 11.5.0~f5os_c_1_8_1_
STARTED-AT: 1782237655100877946

Environment

  • VELOS blade
  • dma-agent

Cause

  • Bug ID 1612557: Dma-agent service health warnings appears in show system summary

This is a false positive that can occur during blade startup, when dma-agent is starting up for the first time.

Recommended Actions

Restarting the platform-monitor container on the blade in question should clear this issue.

For example:

ssh blade-3 'docker container restart platform-monitor'
