K000161357: BIG-IP Edge Client on Windows auto upgrade to 7270 fails

Description

When attempting to auto-upgrade BIG-IP Edge Client for Windows from any version prior to 7270 to version 7270, the upgrade fails to update the Component Installer module due to a change in the code signing certificate.

When this happens, the component Installer remains at the older version. There is no immediate service impact (VPN and Endpoint inspection functions continue), but future auto-upgrades fails.

Environment

  • BIG-IP Edge Client for Windows
  • Auto upgrade from any version to 7270

Cause

BIG-IP Edge Client 7270 introduces a new code signing certificate authority (CA), changing from Entrust (older versions) to Sectigo. The Component Installer Service in older Edge Client versions contains hardcoded logic to validate only the Sectigo-signed certificate. When auto-upgrade is attempted, the existing Component Installer cannot validate the new Sectigo-signed CAB files, causing the upgrade to fail. Because the Component Installer is responsible for upgrading itself, it cannot self-upgrade under these conditions, blocking all future auto-upgrades.

Recommended Actions

You can manually deploy the Component Installer MSI for BIG-IP Edge Client 7270. To do so, perform the following procedure:

  1. Obtain the Component Installer MSI for Edge Client 7270 by following the procedure in the Additional Information section.
  2. Deploy and install the Component Installer MSI to your target Windows machines.
  3. On the Windows machines, restart BIG-IP Edge Client by exiting and relaunching it.
  4. Connect to VPN with BIG-IP Edge Client. The auto-upgrade will now complete successfully for all components, including the Component Installer.

Alternatively, you can also uninstall any older versions of BIG-IP Edge Client on Windows systems and perform a fresh installation of BIG-IP Edge Client 7270.

Additional Information

Procedure to download the Component Installer Service component from the BIG-IP system running APM Client 7.2.7.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Go to Access > Connectivity / VPN > Connectivity.
  3. Select the connectivity profile you are going to use for your client.
  4. Select Customize Package.
    Note: Selecting Customize Package defaults to downloading the Windows client.
  5. Select Available components; it will list all the available components.
  6. Select Component Installer Service alone by marking the tick.
  7. Select Download.
