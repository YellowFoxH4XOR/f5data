Known Issue

This is the result of a known issue. If the connection is lost between two big3d daemons, a small memory leak occurs each time the connection is reestablished.

F5 Product Development tracked this issue as CR89582 and it was fixed in BIG-IP GTM 9.4.4. For information about upgrading, refer to the BIG-IP GTM release notes.

Additionally, this issue has been fixed in Hotfix-BIG-IP-9.3.1-HF2 issued for BIG-IP 9.3.1, and Hotfix-BIG-IP-9.4.3-HF2 issued for BIG-IP 9.4.3. You may download these hotfixes or later versions of these hotfixes from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
