Topic

You should consider using this procedure under the following condition:

  • You want to erase a solid-state drive (SSD) or hard disk drive (HDD) using the Security Erase Unit Advanced Technology Attachment (ATA) command.

Description

There may be instances when you want to fully erase the internal BIG-IP system HDD or SSD for administrative or security purposes. For example, you may want to erase the internal drive when returning a unit for Return Materials Authorization (RMA) replacement. In BIG-IP 11.6.0 and later, an addition to the BIOS of some BIG-IP platforms allows you to perform a single-pass, zero-write disk erase operation, in accordance with ATA specifications.

Note: The Security Erase Unit BIOS feature was introduced in BIG-IP 11.6.0 through an upgrade of the device BIOS. Devices that have been upgraded to 11.6.0 and are subsequently downgraded to an earlier release will retain the Security Erase Unit BIOS feature.

Note:  The bios disk erase is a Security Erase Unit command defined in the Security Feature Set section of the ATA8 Command Specification. This performs a single pass, zero write operation from the drive firmware. In contrast to a typical OS zero-write, only a single command is issued to the drive. NIST defines this as a Clear and not a Purge.

  • You are running one of the following BIG-IP platforms:

Procedures

Erasing a disk

To erase an HDD or SSD, perform the following procedure:

Impact of procedure: This procedure erases all data on your disks and is irreversible.

  1. Connect to the BIG-IP serial console using the serial cable or Always-On Management (AOM).
  2. Log in as the root user.
  3. Restart the system by typing the reboot command.
  4. During restart, type e when the system displays a message similar to the following example:

    Press <c> to enter setup.
    Press <e> to launch F5 Disk Erase Utility

    The system displays a warning message similar to the following example:

    This utility is capable of performing a single-pass zero write, causing PERMANENT DATA LOSS on selected storage devices.

  5. Select Continue.

    The system displays a message similar to the following example:

    The system must reset to prepare devices.
    Press any key to reset.

  6. Press any key.

    The F5 Disk Erase Utility menu displays.

    The menu appears similar to the following example:

                  /--------------------------------------------------\
                  |              F5 DISK ERASE UTILITY               |
                  |--------------------------------------------------|
                  | Drive in Bay 1, Shelf A                          |
                  | Exit                                             |
                  |--------------------------------------------------|
                  |   All data on selected devices will be erased.   |
                  |            ^ and v to move selection             |
                  |                 ENTER to select                  |
                  \--------------------------------------------------/

  7. Select the drive you want to erase.

    Note: If you want to exit the utility, select Exit.

  8. On the confirmation menu, select Erase-All-Data to erase the drive or Cancel to return to the menu.
  9. When drive erasure is complete, you may choose to erase another drive or select Exit to restart the system.
