Description

You are seeing following entries in var/log/ltm at your BIG-IP:
<time stamp> <host name> <log level> <tmm[pid]> 01260009:4: Connection error: ssl_passthru:<number>: not SSL (40)


For example:

Feb  5 04:41:14 big-ip-1.com warning tmm1[24114]: 01260009:4: Connection error: ssl_passthru:5335: not SSL (40)

Environment

  • BIG-IP LTM

Cause

The client connection attempt to the virtual server will be unsuccessful and will not pass data, requiring either client parameters or virtual server to be changed.

Warning means that someone is sending something that is not a client ssl handshake such as sending an HTTP request before client hello.
Simply that non SSL/TLS traffic is received by a Virtual Server configured with a ClientSSL profile.

Recommended Actions

Verify if a client is sending non-SSL traffic to SSL-enabled Virtual Server.
