K000163249: ACME Provider Remains in Updating or Pending State After Account Update

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 21.1.0
Source
https://my.f5.com/manage/s/article/K000163249

Description

When updating an ACME account from the BIG-IP Configuration utility, the ACME provider may remain in an Updating or Pending state.

Environment

  • BIG-IP 21.1.0
  • ACME provider
  • Let’s Encrypt or another ACME-compatible certificate authority
  • ACME account update initiated from the GUI

Cause

After an ACME account update, the account-action value may remain set to update even though the account status is valid. This leaves the provider in an Updating or Pending state and may prevent additional account changes, certificate operations, or provider deletion.
Bug ID2471597: ACME: Account Status remains Updating after updating account for ACME Provider

Answer/Recommended Actions

  1. Log in to the BIG-IP command-line interface.
  2. Display the ACME provider configuration:
    tmsh list sys crypto acme-provider <provider_name>
  3. Confirm that the output contains both of the following values:
    account-action update
    account-status valid
  4. Clear the pending account action:
    tmsh modify sys crypto acme-provider <provider_name> account-action none
  5. Save the configuration:
    tmsh save sys config
  6. Verify the provider configuration again:
    tmsh list sys crypto acme-provider <provider_name>
    The account-action update line should no longer be present.
  7. Confirm that the provider is no longer displayed as Updating or Pending in the GUI, then test certificate renewal. 

Before clearing the pending action:

sys crypto acme-provider <provider_name> {
    account-action update
    account-status valid
}

After clearing the pending action:

sys crypto acme-provider <provider_name> {
    account-status valid
}

    Additional Information

    If the provider remains stuck, certificate renewal fails, or the account-action value returns to update, collect the ACME provider configuration and relevant log messages and contact F5 Support. Do not delete the provider while an account update is reported as in progress.
