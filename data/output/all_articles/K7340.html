Known Issue

This is the result of a known issue. Perl Compatible Regular Expressions (PCRE) implementation for BIG-IP ASM does not support asterisks (*). This limitation affects how patterns can be written to filter dynamic sessions used in a web application's Use Dynamic Sessions In URL option.

F5 Product Development tracked this issue as CR56984 and CR67388, and it was fixed in BIG-IP ASM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

To workaround this issue, you can replace asterisks (*) with plus signs (+) in the syntax.

For example, the following syntax is not supported:

(?<=sell.php).*(?=END)

However, if you replace the asterisk with a plus sign, the following syntax is supported:

(?<=sell.php).+(?=END)

For example, the following example pattern syntax will retrieve the any_text information found between sell.php and END:

http://auction.f5demo.com/sell.php/any_text/END?param1=value1
