Topic

Local traffic policy event evaluation occurs before iRules evaluation for Layer-7 events.

Description

Local traffic policies are available in BIG-IP 11.4.0 and later.  A virtual server can have an associated local traffic policy and an iRule at the same time. For supported events, such as HTTP_REQUEST or HTTP_RESPONSE, local traffic policy evaluation occurs before iRules evaluation.

For example, if you have a local traffic policy that modifies the HTTP User-Agent header value and an HTTP_REQUEST iRule event that reads the User-Agent header value, the iRule reads the modified value.
