Description
While the vast majority of users can work without any noticeable difficulty, a few of them are experiencing many disconnect events per day.
While the issue can affect anyone, it's more prevalent with home workers.

Environment

  • BIG-IP APM
  • APM VPN (browser based or with using EdgeClient).

Cause
This may be due to some short lived DHCP leases from the DHCP server.
While the client machine interface is renewing the lease, the connection to the APM Virtual Server can get interrupted, the tunnelServer process can get disconnected and the routing table can get modified, unexpectedly.

Recommended Actions

Please review the configuration of the DHCP server and ensure the IP addresses as assigned to the client machine interface lasts long enough, to prevent any DHCP renew operation while the VPN is operating.
