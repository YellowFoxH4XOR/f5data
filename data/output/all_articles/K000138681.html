K000138681: NGINX Instance Manager "Generic Error" after login

Type
Support Solution
Published
2024-02-21
Updated
2025-02-07
Applies to
  • NGINX Products
  • NGINX Instance Manager
  • NGINX Management Suite Security Monitoring
Source
https://my.f5.com/manage/s/article/K000138681

Description.

  •     After installing a new copy of NGINX Instance Manager (NIM, NMS) on a new host.
  •     The Web Gui displays "Generic Error" after authentication.
  •     Nothing is logged.

Cause.

sqlite3 is not installed.
This was omitted from the prerequisites.

Resolution.

Install sqlite3 using the appropriate method for your host.

Additional Information.

The script /etc/nms/scripts/support-package.sh  will also fail without sqlite3.
