K3775: The SNMP PoolMemberEntry table is not populated when a forwarding virtual server exists

Known Issue

This is the result of a known issue. If you configure a forwarding virtual server, BIG-IP will no longer populate the PoolMemberEntry OID table with data.

F5 Networks Product Development tracked this issue as CR35527 and CR41921.
