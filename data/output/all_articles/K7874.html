Known Issue

This is the result of a known issue. The SSL::handshake iRule command can be used to halt SSL activity upon authentication, and then it resumes any previously halted SSL activity. Due to a missing patch in the BIG-IP LTM native SSL stack, the BIG-IP LTM does not support the SSL::handshake iRule command in certain versions.

F5 Product Development tracked this issue as CR82672, and it was fixed in BIG-IP LTM versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.
