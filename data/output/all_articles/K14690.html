Known Issue

Using the Traffic Management Shell (tmsh) one-line option may introduce an unexpected new line in the output.

This issue occurs when all of the following conditions are met:

  • You perform a tmsh list operation on an object with an associated list.

    For example:
    • A virtual server with an associated iRule:

      list ltm virtual <virtual server> one-line

    • An HTML rule profile with an associated rule:

      list ltm profile html one-line

Impact

User-written scripts that rely on one-line output from the tmsh utility may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the tmsh one-line option, output may appear on two or more lines.

Workaround

To work around this issue, you can modify your scripts to filter out or ignore new lines in tmsh output.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To remove new lines from tmsh output, type one of the following commands:

    tmsh list ltm virtual test-vip one-line | tr -d '\n'

    tmsh list ltm virtual test-vip one-line | sed '{:q;N;s/\n//g;t q}'
