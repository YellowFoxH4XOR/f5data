K41400203: How to concatenate session variables in the same log line with BIG-IP APM

Type
Support Solution
Published
2020-12-03
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP APM: 15.1.0
Source
https://my.f5.com/manage/s/article/K41400203

Description
Sometimes, there is a need to make to variables, normally in different log lines, to be in the same one.

Environment

  • BIG-IP APM

Cause
None

Recommended Actions

Use a Logging Agent in the VPE of the policy to add a new log: 

1. Go to Access  ››  Profiles / Policies : Access Profiles (Per-Session Policies)
2. Click "edit" in the policy
3. Click the plus sign to add an agent where the log needs to be added in the policy sequence
4. Type "logging" in the search field
5. Add an item according to the item that needs to be log
 

Additional Information

None
