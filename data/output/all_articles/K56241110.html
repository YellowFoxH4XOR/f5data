Description
When a non-floating self IP address is created on a BIG-IP system, on Linux kernel, besides a new interface IP address, a corresponding link scope route will be created. For example, a new interface address is created.
7: sampleVLAN: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc noqueue state UNKNOWN
    link/ether 00:23:e9:00:00:01 brd ff:ff:ff:ff:ff:ff
    inet 10.0.0.1/24 brd 10.0.0.255 scope global sampleVLAN
    inet6 fe80::223:e9ff:fe00:1/64 scope link
       valid_lft forever preferred_lft forever

A corresponding link scope route will be created as a result.
10.0.0.0/24 dev sampleVLAN  proto kernel  scope link  src 10.0.0.1

If the link scope route is missing for some reason, some functions on BIG-IP system will fail, for example, transparent monitors.
 

Environment

  • BIG-IP LTM
  • Transparent monitors are applied.

Cause
Without the link scope route, the Linux system will forward traffic whose destination is on the same subnet as the self IP address to another route, for example, default route on the BIG-IP system. Besides, the BIG-IP system is unable to learn ARP entries because it considers that address needs to be routed via a gateway. Those features involving MAC address manipulation will fail, such as transparent monitors.

Recommended Actions

Customers may check link scope routes and make sure for each self IP address, a corresponding link scope route is available.
# ip route show
