Topic

This article applies to BIG-IP 11.x through 15.x. For information about other versions, refer to the following article:

  • K8849: Configuring a virtual server to use the same IP address as a self IP (9.x - 10.x)

You should consider using these procedures under the following condition:

  • You need to configure a virtual server to use the same IP address as a self IP.

Description

It is possible to configure a virtual server destination IP address to use the same IP address as a self IP address. The requirements for configuring a virtual server to use the same IP address as a self IP are different depending on whether the BIG-IP system is a standalone unit or a member of a sync-failover device group.

These requirements are as follows:

  • If the BIG-IP system is a standalone system, you can configure the virtual server to use the same IP address as any non-floating self IP.
  • If the BIG-IP system is a member of a sync-failover device group, you must configure the virtual server to use the same IP address as a floating self IP. If you create a virtual server on a non-floating self IP, the virtual address can only be in the local traffic group and the virtual server will not fail over to the peer in the sync-failover device group.

Important: If you configure the Configuration utility and a virtual server with /32 mask,  to use the same self IP address and port, the virtual server takes precedence and processes connections to the address. Otherwise the subnet mask length of the VS will decide on the precedence , for example Wildcard VS and Self-IP ( /32 mask ) , the traffic will be processed by the Self-IP and not the VS.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • None

Procedures

To configure a virtual server destination IP address to use the same IP address as a self IP address, perform one of the following procedures:

  • Configuring a virtual server to use the same IP address as a self IP on a standalone system
  • Configuring a virtual server to use the same IP address as a self IP on a member of a sync-failover device group

Configuring a virtual server to use the same IP address as a self IP on a standalone system

You can only configure standalone BIG-IP systems with non-floating self IP addresses that are assigned to the local traffic group. To configure a virtual server destination IP address to use the same IP address as a self IP address on a standalone system, you must display the available non-floating self IP address on the system, and then configure the virtual server destination address to use the same IP address. To do so, perform the following procedures:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Display the available non-floating self IP addresses using one of the two following methods:
    • TMOS Shell (tmsh)

      To display the available non-floating self IP addresses using tmsh, type the following command:

      tmsh list /net self all-properties

      For example, the following self IP address has the floating option disabled and is assigned to the local traffic group:

      net self non-floating-self {
      address 10.12.10.22/16
      allow-service none
      app-service none
      description none
      floating disabled
      inherited-traffic-group false
      partition Common
      traffic-group traffic-group-local-only

    • Configuration utility

      To display the available non-floating self IP addresses using the Configuration utility, navigate to Network > Self IPs.

      The self IP addresses on a standalone system is assigned to the local traffic group.

      For example:

      traffic-group-local-only

  • Configure the virtual server using one of the two following methods:
    • tmsh

      You can configure the virtual server destination IP address to use a non-floating self IP address by using the following tmsh command syntax:

      tmsh create /ltm virtual <virtual_name> { destination <non-floating_selfIP>:<port> } pool <pool_name> }

    • Configuration utility

      You can configure the virtual server destination IP address to use a non-floating self IP address from the Configuration utility by navigating to Local Traffic > Virtual Servers.

Configuring a virtual server to use the same IP address as a self IP on a member of a sync-failover device group

To configure a virtual server destination IP address to use the same IP address as a self IP address on a member of a sync-failover device group, you must select an eligible floating self IP address on the system and then configure the virtual server destination address to use the same IP address. To do so, perform the following tasks:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Display the available floating self IP address using one of the two following methods:
    • tmsh

      To display the available floating self IP addresses using the tmsh utility, type the following command:

      tmsh list /net self all-properties

      For example, the following self IP address has the floating option enabled and is assigned to a non-local traffic group:

      net self float_self {
      address 10.11.16.214/16
      allow-service none
      app-service none
      description none
      floating enabled
      inherited-traffic-group false
      partition Common
      traffic-group traffic-group-1
      unit 1
      vlan external

    • Configuration utility

      To display the available floating self IP addresses using the Configuration utility, navigate Network > Self IPs.

      The appropriate self IP addresses on a member of a sync-failover device group is assigned to the non-local traffic group.

      For example:

      traffic-group-1

  • Configure the virtual server using one of the two following methods:
    • tmsh

      You can configure the virtual server destination IP address to use a floating self IP address by using the following tmsh command syntax:

      tmsh create /ltm virtual <virtual_name> { destination <floating_selfIP>:<port> } pool <pool_name> }

    • Configuration utility

      You can configure the virtual server destination IP address to use a floating self IP address from the Configuration utility by navigating to Local Traffic > Virtual Servers
