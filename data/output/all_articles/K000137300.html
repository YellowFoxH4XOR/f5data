Description

SSL virtual server not working after certificate update on Client and server SSL profiles

Below error message can be seen under /var/log/ltm
Connection error: hud_ssl_handler:1305: alert(40) invalid profile

Also below error can be seen under ltm log:
f5 err tmm1[22621]: 01010004:3: Memory allocation failed: can't allocate memory to extend db size
 

Environment

    • SSL Handshake Failure
    • Client and server SSL profiles
    • TMM
 

Cause

Encountered Bug ID655383 .

TMM's memory is fragmented, which means it's in a state where it's unable to accept some/many configuration updates from MCPD. TMM was unable to process the configuration updates related to the new certificates, which meant that the client SSL profile was missing a certificate when it was assigned to the virtual server.
 

Recommended Actions

To resolve this issue TMM restart is required.
Impact of workaround: Restarting the affected TMM process will interrupt traffic processing on the BIG-IP system.
  1.  Login to BIG-IP CLI.
  2. Run the below command to restart TMM
           bigstart restart tmm


Additional Information

A reboot would also work however simply restarting the TMM will be faster, and should resolve the issue.
