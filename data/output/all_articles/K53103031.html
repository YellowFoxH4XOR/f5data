Description
A Virtual Server working fine before Version 15 now closes the client connection with RST. No Reason code is given.

Environment

  • Virtual Server with HTTP profile with Insert X-Forward-For  enabled

Cause

  • The Client is sending an X-Forwarded-For header with no value

Recommended Actions

  1. Use an  irule replace the existing header with correct header.
  2. Upgrade to version with fix for   Bug ID 985433: Insertion of the X-Forwarded-For HTTP header can fail, causing the client's connection to be reset

     

Additional Information
Prior to V15, the HTTP profile returned the empty header followed by the correct header. Servers looking for the X-Forward-For header would see the last header and operate correctly.
