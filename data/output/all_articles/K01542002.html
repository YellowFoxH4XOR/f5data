Description


Whenever you press enter on the BIG-IP command line, a service restart message is displayed indicating the statsd service is restarting.

  • The statsd process continuously restarts


When statsd starts, it parses /config/statsd.conf and breaks it down into individual components as *.info files in /var/rrd/. Each of these .info files is a text file with a CRC at the end.
If a file in /var/rrd/*.info is corrupt, it will cause statsd to continuously restart.

Environment

  • statsd daemon

Cause

This is due to the following Bug 
Bug ID 879413 statsd fails to start if one or more of its *.info files becomes corrupted

Recommended Actions

1. Identify the affected file(s)

1.1. Log in to the BIG-IP command line

1.2. Check for corrupted files by typing the following command:
  
file /var/rrd/*.info

The file format is expected to be ASCII text

2. Allow the software to re-create the affected file(s) in the expected format

Delete the affected file(s) and wait till the software re-creates them. Multiple iterations may be required before each of the affected file(s) is re-created in the expected format.

Illustrated below are two of the possible approaches

2.A. One file at a time approach

2.A.1. Go to directory /var/rrd/ by typing the following command:
  
cd /var/rrd/

2.A.2. Let the script run until the affected .info file is re-created. Replace the three strings "<filename>" with the actual name of the affected file
  
found=0;while [ $found != 1 ]; do filetype=`file <filename> | cut -d " "  -f2`;if [[ $filetype != "ASCII" ]]; then rm -f <filename>; else grep CRC <filename>;found=1;fi; done

For example, with file rollupcpu.info:

# cd /var/rrd/
# found=0;while [ $found != 1 ]; do filetype=`file rollupcpu.info | cut -d " "  -f2`;if [[ $filetype != "ASCII" ]]; then rm -f rollupcpu.info; else grep CRC rollupcpu.info;found=1;fi; done

 

2.B. All the files in a single pass approach

Run in bash CLI the following script. The script reports its current status every 10 s.
 

gawk 'BEGIN {
  fnam = "/var/tmp/F5-PID'$$'-epoch'$(date +%s)'-sel'$RANDOM'";
  print("Creating", fnam, "...");
  i = cheklist(0);
  for(j in flist) {
    print(j, ":", flist[j]);
  }
  while(i > 0) {
    print("Waiting tor statsd to re-create", i, "file(s), Ctrl+c to exit");
    j = systime();
    system("sleep 10");
    if((systime() - j) < 8) {
      print("Ctrl+c received, exiting");
      exit(130);
    }
    i = cheklist(1);
    for(j in flist) {
      if (flist[j] == 0) {
        print("File", j, "not re-created after it was removed");
        i++;
      }
    }
  }
  print("Deleting", fnam);
  system("rm " fnam);
}

func cheklist(cheklist_i) {
  system("file /var/rrd/*.info > " fnam);
  for(cheklist_j in flist) {
    flist[cheklist_j] = 0
  }
  cheklist_j = 0;
  system("date");
  while((getline < fnam) > 0) {
    if(NF > 1) {
      if($0 ~ / ASCII text/) {
        if(cheklist_i == 0) {
          print($0, "<-", "OK")
        }
        else {
          delete flist[$1];
        }
      }
      else if($0 ~ / empty/) {
        print($0, "<- Warning")
        if(cheklist_i > 0) {
          if(flist[$1] != "") {
            print($1, "Now fixed")
          }
          delete flist[$1];
        }
      }
      else {
        print($0, "<- Removing");
        cheklist_j++;
        flist[$1] = cheklist_j;
        sub(":$", "", $1);
        system("rm " $1);
      }
    }
  }
  close(fnam);
  return(cheklist_j);
}'
