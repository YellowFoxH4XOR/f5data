Known Issue

This is the result of a known issue. Performing a configsync using the bigpipe shell utility may report the following error message:

Synchronizing Master Keys...Cannot fetch unit certificate from peer

This error message is cosmetic only; data synchronization still occurs. This issue occurs when the configsync all command attempts to request the peer's device certificate using an incorrect option flag.

F5 Product Development tracked this issue as CR103322 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, Link Controller, or WebAccelerator release notes.

This issue still exists in the BIG-IP 9.4.x software branch.
