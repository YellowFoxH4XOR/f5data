Known Issue

Remote audit logging messages contain an incorrect nas-ip-address attribute on hardware-based BIG-IP platforms.

This issue occurs when all of the following conditions are met:

  • You have a hardware-based BIG-IP system. This issue does not affect virtual BIG-IP systems.
  • You have enabled remote audit logging on the BIG-IP system.

Impact

Audit logging message accounting is inaccurate.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When viewing audit log messages remotely, the nas-ip-address attribute does not match the IP address of the sending BIG-IP system.
