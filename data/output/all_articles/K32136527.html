Issue

Error Message

alert <Administrator>[<PID>]: 01100055:1: <Alert level message>

In this error message, note the following:

  • <Administrator> is the name of the administrator account that issued the message
  • <PID> is the process ID
  • <Alert level message> is the message the administrator wishes to convey to the LCD screen

For example:

alert admin: 01100055:1: This is a test alert message

Message Location

You may encounter this message in the following locations:

  • The console display
  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • An administrator uses the lcdwarn command to log a message with a log level of alert.

    For example, using the lcdward -p alert "Test Alert Message" command will result in the following:

    • The Alert LED on the front panel of the BIG-IP system will be solid red.
    • The LCD displays Test Alert Message on the LCD panel under priority > alert.
    • The console display and the /var/log/ltm file display the following message:

      01100055:1: Test Alert Message

Impact

The LCD panel displays the desired message, and the alert LED on the front panel of the BIG-IP system is solid red, unless a higher priority message is also being displayed.

Recommended Actions

To clear all alert level messages from the LCD panel, type the following command in the Advanced Shell (bash):

lcdwarn -c alert
