Topic

You should consider using this procedure under the following condition:

  • You want to change the F5 SSL Orchestrator service monitor to another health monitor other than the default assigned health monitor.

Description

Starting in F5 SSL Orchestrator 15.0.0-6.0, you can modify the health monitor for a service through the SSL Orchestrator Guided Configuration. This applies to all services except the Terminal Access Point (TAP) service. The default health monitor assigned to these services is the gateway_icmp health monitor; the only exception is Internet Content Adaptation Protocol (ICAP) service, where the default health monitor is the tcp health monitor.

In versions before F5 SSL Orchestrator 15.0.0-6.0, you must disable the strictness for the service before manually adding a health monitor to the service pool.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the SSL Orchestrator Guided Configuration.

Procedures

To change the health monitor for a service, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in the SSL Orchestrator Configuration utility.
  2. Go to SSL Orchestrator > Configuration > Services.
  3. Select the Service you want to modify.
  4. For Service, select the edit (pencil) icon.
  5. For Device Monitor, select your preferred health monitor.
  6. Select Save & Next.
  7. If the service is associated with a service chain, the system prompts you that editing the setting may affect the associated service chain. Select OK to continue.
  8. Review the service chain and edit as needed, then select Save & Next.
  9. Select Deploy.
