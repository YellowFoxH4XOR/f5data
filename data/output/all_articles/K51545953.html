Description

Unable to recover root user password using single-user mode in Grub version 0.97, if TACACS is in use.

  • Using the following articles root user password cannot be recovered:
    https://my.f5.com/manage/s/article/K4178
    https://my.f5.com/manage/s/article/K73551536 

Environment

  • BIG-IP
  • Grub version 0.97
  • Root Password Recovery.
  • TACACS authentication in use.

Cause

TACACS can break root user password recovery. 

Recommended Actions

First, confirm if previous solutions do not work for you:

  1. Please make sure, the baud rate is set to the proper value while using console connection:
    K7683: Connecting a serial terminal to a BIG-IP system
  2. Follow the steps to log in via single-user mode on grub menu 0.97:
    K4178: Restarting the BIG-IP system in single-user mode (GRUB 0.97)
  3. Follow the steps to recover the root user password
    K73551536: How to recover the root password on BIG-IP platforms (BIG-IP 11.x - 14.0)
  4. If the change seems successful but the password of root, when prompted to the user login, still does not work, there is another behavior that will break root access login and this is TACACS access.
  5. When running into step 4, please follow the next steps to:
    a.- The system is using TACACS for authentication.
    b.- If this is confirmed, then you need to modify access to local instead of TACACS on the bigip.conf file.
    c.- Perform the troubleshooting steps mentioned on "Reverting to local authentication by booting into single-user mode" https://my.f5.com/manage/s/article/K12304.
