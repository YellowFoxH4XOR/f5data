K4749: The configsync process fails if the admin password contains special characters

Known Issue

This is the result of a known issue. If your admin password contains the at (@) symbol, the forward-slash (/) symbol, or the dollar sign ($) the configuration synchronization process misinterprets that character as a break in the password. This will result in the following error messages:

SOAPException: 'Error calling getaddrinfo for <text>@<address>

(Temporary failure in name resolution)'

SOAPException: 'Error calling getaddrinfo for (Name or service not known)'

F5 Product Development tracked the issue with the at (@) symbol and the dollar sign ($) as CR46841 and CR47750, and it was fixed in BIG-IP 9.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

F5 Product Development tracked the forward-slash (/) issue as CR48787. This problem was fixed in BIG-IP 9.1.1 and 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
