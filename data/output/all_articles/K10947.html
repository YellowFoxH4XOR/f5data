Known Issue

This is the result of a known issue. The follow error message is a false positive and can be safely ignored:

security[8397]: [-] Virus detected in upload, Empty file

ClamAV, which is the antivirus software FirePass uses to scan files, generates this error message. When ClamAV scans an empty file, it logs the message. This log is erroneous because a virus has not been detected.

F5 Networks Product Development is tracking this issue as CR129542.
