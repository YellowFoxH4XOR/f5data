Description

The support ID displayed in the response blocking page is not found at: Security > Event Logs > Application > Requests

Environment

  • Requests are blocking
  • Logging profile is applied

Cause

The support ID displayed is associated with the Bot protection profile applied to the virtual server.

There are two types of Request logs that can be found: ASM request and Bot Request logs, each starting with a different digit and both can be up to 20 Digits.

Recommended Actions

Search for the Support ID at: Security > Event Logs > Bot Defense > Bot Requests

Additional Information

If the support ID is still not found, then it's possible that the appropriate logging profile is not associated with the virtual server, or the logs may have rotated. Please refer to K45320421: ASM event logs are deleted or rotated out very quickly

Note: K45320421 also applies to Bot Request logs as they share the same database table.
