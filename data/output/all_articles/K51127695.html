Description

Changing a Virtual Server's destination IP from static to shared gives you the below error in GUI.

"Some fields below contain errors. Correct them before continuing."

It is also unclear which fields are problematic and have to be corrected.
 

Environment

  • BIG-IP LTM running supported iApp template.
  • Virtual Server created via iApp.
  • Change destination IP from static IP to a shared IP.
 

Cause

Shared objects cannot be used on iApp Virtual Servers since this feature is not integrated into the iApp template.
 

Recommended Actions

None.
 

Additional Information

iApp template is designed to use "create virtual" command while shared objects are created by "create traffic-matching-criteria". This is the reason for GUI error.
