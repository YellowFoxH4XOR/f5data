Overview

The qkview utility is a script that automatically collects configuration and diagnostic information from BIG-IP and Enterprise Manager systems. The information is gathered into a single file, which can then be provided to F5 Technical Support to aid in troubleshooting. F5 Technical Support requires qkview output in all cases where remote access to the product is not available.

Obtaining the latest version of qkview

The qkview utility is periodically updated for BIG-IP 9.x. You should make certain that you are running the latest version before you provide qkview output to F5 Technical Support. To determine the version of qkview installed on your system, run the command qkview -v from the BIG-IP command line. In the example below, the version of qkview is 6.2.7:

# qkview -v
Thu Jun 10 11:02:51 PDT 2010
Qkview v6.2.7 UPTIME: 11:02:51 up 54 min, 1 user, load average: 0.29, 0.26, 0.22
#

If the version of qkview installed on your system is older than the version available on the F5 Downloads site, you should update the qkview utility as described below.

Note: To locate the latest version 9.x qkview script on the Downloads site, navigate to Overview > Find a Download > BIG-IP v9.x and select 9.x from the drop-down menu.

Note: The version 9.x qkview script is also used for Enterprise Manager 1.x systems and BIG-IP SAM systems.

Installing qkview on BIG-IP or Enterprise Manager

  1. Log in to the command line.
  2. Change to the /usr/bin directory by typing the following command:

    cd /usr/bin

  3. Back up your existing version of qkview by typing the following command:

    mv qkview qkview.old

  4. Download the most recent version of qkview and copy it to the /usr/bin directory.
  5. Decompress the qkview.gz file by typing the following command:

    gunzip qkview.gz

    Note: If you receive the not in gzip format error message, your web browser may have automatically decompressed the file when it was downloaded. If the file has already been decompressed, rename it by typing the following command: mv qkview.gz qkview

  6. Set permissions for qkview by typing the following command:

    chmod 700 qkview

  7. Test qkview by typing the following command:

    qkview -v

The version of qkview should be reported. If qkview does not report its version, or if you receive a Permission denied error message, the file may have been corrupted during the download process. If this is the case, repeat Steps 1 through 7 to re-install it.

Running qkview from the Configuration utility

Important: The qkview script runs a large number of commands when collecting information. This behavior may cause an additional performance burden on systems that are already heavily loaded. If this is a concern for your system, run qkview from the command line and refer to the Command line options (BIG-IP 9.x) section for information about reducing the performance impact of qkview.

  1. Log in to the Configuration utility.
  2. Navigate to System > Support.

    The QKView option is already selected.
  3. Click Start button.
  4. When prompted, click Download Snapshot Filebutton to download the output file.

Note: When qkview is run from the Configuration utility, a file is created on the memory file system for the user to download. This file should be automatically removed after 30 minutes. However, due to a known issue, the removal process may fail. For more information, refer to K12209: A qkview or tcpdump output file created using the Configuration utility is not automatically removed.

Running qkview from the command line

Note: When the qkview script is run from the command line on a BIG-IP ASM system, it automatically calls and runs the asmqkview script. For information about the asmqkview script, refer to K6824: Overview of the asmqkview script.

  1. Log in to the command line.
  2. Run qkview by typing the following command:

    Important: The qkview script runs a large number of commands when collecting information. This behavior may cause an additional performance burden on systems that are already heavily loaded. If this is a concern for your system, refer to the Command line options (BIG-IP 9.x) section for information about reducing the performance impact of qkview.

    qkview

    Note: If the system is configured to use Sendmail, qkview will prompt you to email the qkview output to F5 Support. If you choose to use this option, include your case number as the subject for the email.

  3. Collect the output file from the /var/tmp/ directory.

    The output file name is <hostname>-tech.out, where <hostname> is the host name of the device on which you are running qkview.

Command line options

For BIG-IP 9.x, you can provide two command line arguments to change the qkview utility's default behavior, using the following syntax:

qkview <file> <verbosity>

To save the output file to a directory or filename other than /var/tmp/<hostname>-tech.out, replace <file> with the full path and filename of the file you want to use for the output.

To specify the number of lines qkview will collect from the log file, replace <verbosity> with a number value. By default, qkview collects the last 175 lines from each log file.

To reduce the performance burden of qkview, you can run qkview at the lowest possible priority by typing the following command:

nice -n 19 qkview

Note: On heavily loaded systems, qkview may take a long time to finish running when using nice -n 19.

Sending data to F5

If your system was not configured to use Sendmail, download the qkview output file and transfer the file to F5 Technical Support using dropbox.f5.com. Include your case number in the subject of the email.

Note: For more information about sending files using dropbox.f5.com, refer to K2486: Providing files to F5 Technical Support.
