Known Issue

This is the result of a known issue. When viewing audit request log information within the Configuration utility, the BIG-IP LTM system may hang, causing excessive use of the CPU.

This issue occurs when the following conditions are met:

  • Auditing is enabled
  • The ltm log file located in /var/log/ltm is 60 MB or larger
  • An administrator attempts to view or request audit information using the Configuration utility

When this issue occurs, the Configuration utility stalls and prevents users from logging in to the command line or the Configuration utility. This issue may also prevent monitor information from being correctly updated, which may cause the BIG-IP LTM to send traffic to a down or unavailable server node.

F5 Product Development tracked this issue as CR99853 and it was fixed in BIG-IP 9.4.6. For information about upgrading, refer to the BIG-IP LTM release notes.
