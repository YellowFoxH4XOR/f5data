Issue

Starting in FirePass 6.0.2 with cumulative hotfix HF-602-3, the Remove Components tool in the FirePass Components Troubleshooting Utility (f5wininfo.exe) now supports Windows Vista systems. Previously, the Remove Components tool only supported Windows XP systems.

You can download the Components Troubleshooting Utility on the Device Management: Client Downloads: Windows (x86) page under the Downloads tab in the FirePass Administrative Console.

Note: For information about removing FirePass components using the Components Troubleshooting Utility, refer to K8253: Removing FirePass client components from Windows 2000, 2003, XP, and Vista systems.

F5 Product Development tracked this enhancement as ID 269390 (Formerly CR92271) and has been added starting in FirePass 6.0.3.

Additionally, cumulative Hotfix HF-602-9 has been issued for FirePass 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
