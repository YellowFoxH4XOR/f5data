Known Issue

Deleting a file from the root directory of a Distributed File System (DFS) file share fails.

This issue occurs when the following condition is met:

  • Deleting a file from the root directory of a DFS file share through FirePass

Impact

Users cannot delete files from the root directory of the DFS share.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Users receive the following error message:

    Failed to delete \\<ad domain>\<share>\<filename>

    In the following error message, note the following:

    • <AD domain> is the name of the AD domain that hosts the DFS share
    • <share> is the name of the DFS file share
    • <filename> is the name of the file being deleted

    For example:

    Failed to delete \\ad.example.com\dfs\example.doc
