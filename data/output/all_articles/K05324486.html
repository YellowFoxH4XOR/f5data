Description

If the Device-Watchdog-Answer (DWA) misses twice to respond, SDC will close the connection to the diameter server by sending Disconnect-Peer-Request before initiating another connection.

Environment

  • Diameter
  • AAA Protocol
  • TCP and SCTP

Cause

To detect failures faster, the AAA protocol supports an application layer watchdog messages. According to RFC-3539, the client must not close the primary connection until the primary watchdog timer lapsed for at least twice without a response. 

This behavior is by design. No action required.

Recommended Actions

Not Applicable

Additional Information

Diameter is an AAA protocol, defines the application layer acknowledgments and failover methods.
Device-watchdog-request (DWR) is sent according to a single-timer (TW) configuration in the Diameter profile.
