Known Issue

This is the result of a known issue. Ubuntu 9.10 users may be continually prompted to install the VPN components when trying to connect to Network Access with Firefox version 3.5.x.

This issue occurs when the user launches the browser they use to connect to the FirePass controller with sudo privileges rather than root privileges. When the user clicks on a Network Access favorite, they will be prompted to install a plugin and restart Firefox. After restarting FirePass, logging in again, and reselecting the Network Access favorite, the user will receive the following error message:

Installation fails

In addition, the user is unable to connect to the Network Access favorite and is prompted to install the plugin again.

F5 Product Development tracked this issue as ID 317694 (formerly CR134676) and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-2, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Workaround

Users who have access to the root password can successfully install the components by selecting root when prompted and entering the root password.
