Known Issue

Simple Object Access Protocol (SOAP) calls using the System::SystemInfo::get_product_information iControl method may return an error.

This issue occurs when the following condition is met:

  • You use the SOAP call to request product information from a system running one of the following hotfix versions:
    • 12.1.1 HF2
    • 11.3.0 HF1 through HF4
    • 11.2.1 HF2 through HF3

The iControl call encounters an unrecognized feature flag that was added to the hotfix build but not included in the hotfix iso. 

Impact

SOAP calls requesting product information from systems running the affected hotfix versions return a get_ff_present feature flag out of range error.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SOAP calls using the System::SystemInfo::get_product_information iControl method return an error.
  • In the /var/log/ltm file, the BIG-IP system logs an error message similar to the following example:

    err iControlPortal.cgi[3811]: 01180009:3: get_ff_present feature flag <###> out of range

Resolution

Status

F5 Product Development has assigned ID 418296 and ID 410001 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
