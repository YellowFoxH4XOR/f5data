Description

Use the command in this article to find the expiration date of the DSC device management/device trust certificate on the CLI.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP LTM
  • DSC Device Trust Certificates

Cause

None. Informational only.

Recommended Actions

Check the device specifications and look for the certificate using the following command:

  • tmsh list cm device

Once the name is located, use the openssl command syntax below to determine the date:

  • openssl x509 -noout -enddate -in /config/ssl/ssl.crt/<certificate_name>.crt

For example:

# openssl x509 -noout -enddate -in /config/ssl/ssl.crt/dtdi.crt
notAfter=Dec 8 20:58:29 2034 GMT

The certificate default path is /config/ssl/ssl.crt/. Additionally the system keeps identical copies of dtdi.crt in /config/ssl/ssl.crt/ and /config/filestore/files_d/Common_d/trust_certificate_d/
