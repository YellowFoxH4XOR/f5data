Description

NIM may produce excessive log messages that are generated from ClickHouse server.

Environment

NGINX Instance Manager

Cause

ClickHouse server on NIM has trace level logging enabled by default.

Recommended Actions

Reduce ClickHouse log level.

  • Edit the ClickHouse configuration:
sudo vi /etc/clickhouse-server/config.xml
  • Change the clickhouse.logger.level value from trace to warning
<logger>
    <level>warning</level>
</logger>
  • Restart ClickHouse server
sudo systemctl restart clickhouse-server
