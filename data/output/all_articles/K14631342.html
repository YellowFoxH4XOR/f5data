Description
Can no longer access the "Security" tab of a virtual server. The following error message appears in the GUI

"An error has occurred while trying to process your request."

The following error message appears in the audit logs of  /var/log/restjavad:

[I][2429][05 Nov 2020 15:02:04 UTC][ForwarderPassThroughWorker] {"user":"local/<user_name>","method":"GET","uri":"http://localhost:8100/mgmt/tm/security/presentation/tmui/virtual-list/~example.com_combined_https","status":401,"from":"Unknown"}
 

Environment

  • ASM GUI

Cause

This issue is due to the BUG tracked in ID957337

Recommended Actions

Upgrade to 15.1.2
Please see the release note for detail information 

Additional Information

None.
