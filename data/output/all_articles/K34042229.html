Known Issue

When you use the TMOS Shell (tmsh) list ltm node command to attempt to list a node, and the node does not exist, the system fails to return an error message.

This issue occurs when all of the following conditions are met:

  • You used a tmsh command similar to the following example to list node information.

    tmsh list ltm node <node_name1> <node_name2> <node_nameN>

  • The name of the node you specified does not exist.

When you run a specific tmsh command to list a node, and the node does not exist, the system should return an error message similar to the following example:

# tmsh list ltm node <node_name>
01020036:3: The requested Node (/Common/<node_name>) was not found.

Impact

When you run a tmsh command to list a BIG-IP LTM node, and the node does not exist, the system displays no output or error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the specific tmsh command, you observe output similar to the following example:

    # tmsh list ltm node <node_name>

    #
