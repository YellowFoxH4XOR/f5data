K000132659: Using special characters in restcurl commands

Description

restcurl commands typically include data enclosed in double quotes, for example:

restcurl -X POST /cm/global/tasks/device-trust -d '{"address":"10.155.226.1","httpsPort":443,"userName":"admin","password":"admin","clusterName":"Test","useBigiqSync":false,"deployWhenDscChangesPending":false,"name":"Test"}


But special characters may be part of the data, for example, the password below contains a single quote:

p@ss'w0rd


The bash shell will output a ">" (waiting for input) when trying to run a command such as:
 

restcurl -X POST /cm/global/tasks/device-trust -d '{"address":"10.155.226.1","httpsPort":443,"userName":"admin","password":"p@ss'w0rd","clusterName":"Test","useBigiqSync":false,"deployWhenDscChangesPending":false,"name":"Test"}'


Even if the single quote is escaped:
 

restcurl -X POST /cm/global/tasks/device-trust -d '{"address":"10.155.226.1","httpsPort":443,"userName":"admin","password":"p@ss\'w0rd","clusterName":"Test","useBigiqSync":false,"deployWhenDscChangesPending":false,"name":"Test"}'

 

Environment

  • Linux bash
  • restcurl tool

 

Cause

Single quotes are not escaped within double quotes, so escaping the single quote as below won't work:

"p@ss\'w0rd"

 

Recommended Actions

Use single quotes and then escape the single quote with \, ie:

'p@ss\'w0rd'

The following command syntax is accepted by the bash shell, the command will be properly executed:
 

restcurl -X POST /cm/global/tasks/device-trust -d '{"address":"10.155.226.1","httpsPort":443,"userName":"admin","password":'p@ss\'w0rd',"clusterName":"Test","useBigiqSync":false,"deployWhenDscChangesPending":false,"name":"Test"}'
