Issue

Error Message

01071451:5: Received CMI hello from /<partition>/<host name>

In this error message, note the following:

  • <partition> is the administrative partition for the centralized management infrastructure (CMI) peer device object.
  • <host name> is the host name of the remote CMI peer device.

For example:

01071451:5: Received CMI hello from /Common/peer.example.com

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A remote BIG-IP system has established a CMI connection to the local BIG-IP system.

Note: CMI is also referred to as device service clustering (DSC).

Impact

None. The message is informational.

Recommended Actions

For more information about DSC technology, refer to K13946: Troubleshooting ConfigSync and device service clustering issues (11.x - 12.x).
