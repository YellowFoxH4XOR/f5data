Known Issue

A Client SSL parent profile may unexpectedly override certificate, key, and chain certificate configurations in its child profile.

This issue occurs when all of the following conditions are met:

  • Create a custom client SSL profile "A", using the default clientssl parent profile.
  • Create a custom client SSL profile "B", using the newly created "A" as a parent profile.
  • In the custom client SSL profile "B", select a custom certificate, key, or chain certificate.
  • Modify any part of the custom client SSL profile "A". For example, change Ciphers to DEFAULT:@STRENGTH.
  • Navigate to client SSL profile "B", and observe that none of the custom check boxes are selected.
Note: Even though the Configuration utility does not appear to be preserving the configuration of the child SSL profile "B", the configuration is still intact when viewed from the Traffic Management Shell (tmsh) or from within the /config/bigip.conf file.

Important: If you select Update while viewing the child SSL profile, the changes will be written to the running configuration and will become permanent.

Impact

This is only a cosmetic issue, as long as changes are not saved to the child SSL profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After making a change to the custom parent client SSL profile, you observe the following:
    • The custom child client SSL profile has reverted to the inherited settings of the parent profile, when viewed in the Configuration utility.
    • The custom child client SSL profile has not been affected, when viewed from either tmsh or within the /config/bigip.conf file.
