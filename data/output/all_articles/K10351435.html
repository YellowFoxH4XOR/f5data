Description

  • Could not locate/select image file on GUI or CLI for code upgrade
  • Software image file is present on /shared/images/

Environment

  • BIG-IP device running software version prior to 11.5.x
  • Trying to install/upgrade to a four digit software version (Ex: 12.1.4.1)

Cause

The four-digit software version schema is supported from 11.5.0 and above

Recommended Actions

Upgrade to 11.5.X or to a maintenance release.

None
