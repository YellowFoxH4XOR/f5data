K000146401: ASM blocks staged signatures

Type
Support Solution
Published
2024-10-24
Updated
2024-10-24
Source
https://my.f5.com/manage/s/article/K000146401

Description

When ASM policy is configured with "Retain previous rule enforcement and place updated rule in staging" setting, then newly updated ASM signatures are moved to staging and ASM will still enforce the older version of the signature until updated signatures are enforced

 

Environment

BIG-IP ASM 
Attack Signature live updates

 

Cause

Functioning as designed

 

Recommended Actions

Review the updated signatures and choose to enforce for proper ASM action. Details of last update of Signature can be verified on GUI Security >> Options : Application Security : Attack Signatures : Attack Signatures List
