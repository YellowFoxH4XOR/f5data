K25244654: IsGrdLookup XML Element appears in flowManager.xml after CM process restarts

Description

You notice the flowManager.xml contains additional XML element called IsGrdLookup after restarting Configuration Manager (CM) process.

    <SessionBindingDecision>
        <SessionBindingTypeConfiguration>NO_BINDING</SessionBindingTypeConfiguration>
        <IsGrdLookup>false</IsGrdLookup>
    </SessionBindingDecision>

IsGrdLookup is part of the Subscriber Location Function (SLF), which is deprecated in SDC 5.

Environment

  • IsGrdLookup XML element in flowManager.xml
  • Session Management

Cause

IsGrdLookup is part of the Subscriber Location Function (SLF), which is deprecated in SDC 5. There is no impact since this function is not used and is set to false by default. At the creation/submit on new/existing Session Binding rule, it is reset to null and therefore it does not appear at the flowManager.xml. Upon each CM process restarts the line will appear while creation/submit will remove it.

Recommended Actions

No action is needed when IsGrdLookup XML element appears in flowManager.xml.
