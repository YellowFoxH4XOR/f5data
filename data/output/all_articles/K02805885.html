Description
The SSH host key is used to uniquely identify a given device when an SSH connection is established to that device.

Environment

  • BIGIP
  • SSH

Cause
None

Recommended Actions

  1. When SSH client trying to access SSH server for the first time, you would see the below messages,
    • ~$ ssh -V;ssh root@10.201.31.172
      OpenSSH_8.4p1 Debian-6, OpenSSL 1.1.1l  24 Aug 2021
      The authenticity of host '10.201.31.172 (10.201.31.172)' can't be established.
      ECDSA key fingerprint is SHA256:mUKaqqQaArGj/PNMtpkfehzQ4YkBzmhBPZrsqyZAUt4.
      Are you sure you want to continue connecting (yes/no/[fingerprint])?
  2. The fingerprint of remote SSH server is mUKaqqQaArGj/PNMtpkfehzQ4YkBzmhBPZrsqyZAUt4 as displayed on the output.
  3. Login into BIGIP command prompt and look for ECDSA key,
    • config # ll /var/ssh/ssh_host_ecdsa_key
      -rw-------. 1 root root 227 Oct 30  2020 /var/ssh/ssh_host_ecdsa_key
  4. Use the command below on BIGIP to verify the ECDSA key fingerprint,
    • config # ssh-keygen -l -f /var/ssh/ssh_host_ecdsa_key
      256 SHA256:mUKaqqQaArGj/PNMtpkfehzQ4YkBzmhBPZrsqyZAUt4 test.example.net (ECDSA)
  5. Fingerprint is matching.
