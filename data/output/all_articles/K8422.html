Known Issue

This is the result of a known issue. When a user exits protected workspace, the FirePass client-side component fails to clear the list of files from the Microsoft Office most recently used (MRU) registry key. The purpose of the MRU feature is to provide quick access to recently accessed files, but for security reasons many administrators prefer not to have these files listed.

The default location for the Microsoft Office MRU registry key is as follows:

HKEY_CURRENT_USER\Software\Microsoft\Office\<version>\Common\General\RecentFiles

For more information about clearing the Microsoft Office MRU list, refer to the following website:

http://support.microsoft.com/kb/826208

F5 Networks Product Development is tracking this issue as ID 266963 (formerly CR93837).

Workaround

You can work around this issue by modifying the Microsoft Office MRU registry key. For more information, refer to the following website:

http://support.microsoft.com/kb/826208
