Description

The BIG-IP SSL profiles support Elliptic Curve Cryptography (ECC) curves (also referred to as DH Groups) for use in the key exchange process within the SSL/TLS handshake. DH groups are a specific type of algorithm that leverage ECC to establish a temporary, secret key used to encrypt the rest of the TLS communication, enhancing forward secrecy. You might want to change the ECC curve order of preference or disallow one or more ECC curves for Client SSL connections.

Environment

  • Client SSL profile
  • DH group
  • Cipher Group
  • Cipher Rule 

Cause

None

Recommended Actions

By default, the Client SSL profile provides ECC curves in the following order of preference for TLS connections:

  • P256
  • X25519
  • P384

To change the default order of preference, or to prevent the system from offering one or more ECC curves, refer to the following procedures:

Change the order of preference of ECC curves

To change the order of preference of ECC curves for TLS connections, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Local Traffic > Ciphers > Groups.
  3. Select Create.
  4. Type a name for the cipher group.
  5. Under Group Creation, select a rule from Available Rules, such as f5-default, and move it to Allow the following.
  6. For Order, select the desired order for the cipher suites, DH Groups and signature algorithms. For example, to order the algorithms from fastest to slowest, select Speed.
  7. Select Finished.
  8. Associate the cipher group with the virtual server's client SSL profile.

Prevent the system from offering one or more ECC curves

To prevent the system from offering one or more ECC curves, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Local Traffic > Ciphers > Rules.
  3. Select Create.
  4. Type a name for the cipher rule.
  5. Under Rule Creation, complete the following:
    • Cipher Suites
      Enter the cipher suites that you want to include in the rule. For example, enter DEFAULT, to use the default cipher suites.
    • DH Groups
      Enter the ECC curves that you want to include in the rule, For example, to allow only curves P256 and X25519, enter P256:X25519.
    • Signature Algorithms
      Enter the signature algorithms that you want to include in the rule. Enter DEFAULT, to use the default signature algorithms.
  6. Select Finished.
  7. Go to Local Traffic > Ciphers > Groups.
  8. Select Create.
  9. Type a name for the cipher group.
  10. Under Group Creation, select the cipher rule you created in the previous steps from Available Rules and move it to Allow the following.
  11. Select Finished.
  12. Associate the cipher group with the virtual server's client SSL profile.

Additional Information

The ECC curve selection process differs depending on the TLS version. In TLS 1.2 handshakes, the curve is selected by the server, while in TLS 1.3 handshakes the client sends its preferred curves in the initial ClientHello. If the the curve selected by the client is not acceptable to the server, then the server will respond with a HelloRetryRequest, adding an additional round-trip to the TLS 1.3 handshake.
