Known Issue

Domain Name System Security Extensions (DNSSEC) key creation may not appear to synchronize to synchronization group members.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is configured as a member of a synchronization group.
  • A DNSSEC key is created by any member of the system's synchronization group.

Impact

Configuration information specific to the key generation is not synchronized to other members of the synchronization group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you create a zone-signing key, the key creation configuration information is not synchronized to synchronization group members.
  • When you create a key-signing key, the key creation configuration information is not synchronized to synchronization group members.
  • When you view the Configuration utility DNSSEC Key List screen for synchronization group members, the list contains the newly created key.

Workaround

To work around this issue, you can trigger a synchronization of the DNSSEC configuration by modifying another parameter on the BIG-IP GTM system after generating a DNSSEC key.

Impact of workaround: This action triggers a synchronization of the local device DNS configuration to all synchronization group members.
