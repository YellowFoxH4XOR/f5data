Description

After adding a new VLAN ID #0 to the GTM interface, intermittent ICMP Ping issues with the gateway ICMP monitoring profile were observed.

Environment

  • BIG-IP DNS
  • Intermittent ICMP
  • Network Flaps

Cause

The VLAN interface experiencing intermittent ICMP flaps was blocked by a Packet Filter rule, preventing ICMP traffic.

Recommended Actions

May either implement one of the option listed below.

  1. Create a new Packet Filter rule to allow ICMP traffic on the VLAN interface that requires ICMP monitoring, such as for gateway ICMP monitor profiles.
  2. Alternatively, may allow ICMP traffic on all VLAN.
