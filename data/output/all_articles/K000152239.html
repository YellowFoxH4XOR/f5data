K000152239: ASM logging events neither locally nor remotely

Type
Support Solution
Published
2025-06-29
Updated
2025-09-30
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000152239

Description

ASM event logging is not working, with no associated messages being sent to remote logging servers and no events logged to the local event log.

Environment

One of the following modules is provisioned:

  • ASM
  • Advanced WAF

Cause

bd's communication pipes did not finish setting up properly.  This is most likely to happen after an upgrade, but can also happen after a relicensing event.

 

You can tell when a bd process is in such a degraded state when all the counters from this CLI command are 0: tmctl -if /var/tmstat/blade/asm_bd asm/bd_remote_log_pipe

 

# tmctl -if /var/tmstat/blade/asm_bd asm/bd_remote_log_pipe
name           internal_drop external_drop successful
-------------- ------------- ------------- ----------
sampling                   0             0          0
tightening                 0             0          0
violation                  0             0          0
statistic_msgs             0             0          0
request_log                0             0          0
remote_logger              0             0          0

Recommended Actions

  • Restart ASM: bigstart restart asm

Note: This is disruptive to traffic passing through the unit and will result in a failover in HA environment.
