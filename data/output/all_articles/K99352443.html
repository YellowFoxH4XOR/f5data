Description

There are 3 ways of using MacOS as a VPN Client system, there is an Edge Client App that can be distributed from an APM, There is s dedicated AppleStore F5 Access client, and there is a Browser based extension that can be installed as a "Helper Application" .

 The MacOS components for SSL VPN with "BIG-IP Edge Client" are distributed as an "Apple installer" package named
    mac_edgesvpn.pkg
This is downloaded from the APM with an initial configuration cleartext file (config_tmp.f5c) as a zip bundle by an Administrator and is usually deployed manually or using a MDM platform or it can be distributed by a variety of methods for manual install.

Environment

  • APM SSL VPN deployments 

Cause

The installer application for MacOS was changed to become compatible with MacOS 15.0 in APMClient 7.2.5.1
This is tracked as ID1644477
https://cdn.f5.com/product/bugtracker/ID1644477.html

The standard Apple installer copies the applications to the /Application directory by default and then runs a postinstall script that may move or change some of the components individually. This postinstall script needs administrator privilege and will prompt for a suitable account during install. If this is not granted then the Edge Client will not be correctly installed (specifically the PolicyServer component) and may not work as expected. 

Recommended Actions

The Applications can be checked for valid Notarization as per K94015957 and for specific file type with the file terminal command
For example

BIG-IP Edge Client
This is the full GUI application for Edge Client on MacOS.
Recent versions log to ~/Library/Logs/F5Networks/edge.log

InstallerHelper
This helper supports the installation and upgrade of privileged Edge Client and Inspection components
Recent versions log to ~/Library/Logs/F5Networks/install.log

PolicyServer
This helper performs the Endpoint Inspection tasks and can call the OPSWAT OESIS library components with administrator privilege if required.
Recent versions log to /Library/Logs/F5Networks/policyserver.log

RSASoftTokenEdgeHelper
This helper supports the certificate validation

f5fwctl
This helper is used to control the MacOS firewall, and is only used when "Always connected mode" is configured
Recent versions log to /Library/Logs/F5Networks/f5fwctl.log

f5fpc
Is the legacy command line interface, this have limited capabilities and its use is deprecated.

svpn
This background daemon runs the PPP over TLS/DTLS that is used for the SSL VPN Tunnel
Recent versions log to /Library/Logs/F5Networks/svpn.log
