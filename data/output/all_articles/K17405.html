Issue

Error Message

Disk full (volume group). See SOL#10636

Note: This error message is described in the context relevant to only BIG-IQ systems. For other products and versions that reference the SOL#10636 error message, refer to K10636: Issues related to a disk full error with recommendation to See SOL#10636.

Message Location

You may encounter this message in the following locations:

  • The status of the Traffic Management Shell (tmsh) command, tmsh show sys software

    For example:

    --------------------------------------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version     Build  Active                                            Status
    --------------------------------------------------------------------------------------------
    HD1.1    BIG-IQ    4.5.0  0.0.7028     yes                                          complete
    HD1.2    BIG-IQ    5.1.0   0.0.631      no                                          complete
    HD1.3    BIG-IQ    5.3.0  0.0.1119      no  failed (Disk full (volume group). See SOL#10636)

  • The /var/log/liveinstall.log file:

    For example, the installation of 5.3.0 on the third slot may appear similar to the following error messages:

    error: tm_install::Process::Process_full_install -- predicted size for BIGIQ530 is 14885760 and vg has 8851456 remaining.
    Terminal error: Disk full (volume group). See SOL#10636
    *** Live install end at 2017/08/10 01:08:10: failed (return code 9) ***
     

Description

This message occurs when all of the following conditions are met:

  • The BIG-IQ virtual machine is originally deployed by way of the standard OVA for BIG-IQ 4.5.0, with the thick provisioning size of 55 GB on the VMware ESXi.

    Note: The original HD1.1 instance may have already been replaced by a later BIG-IQ version (5.3.0). However, the BIG-IQ system's disk structure that was deployed based on the 4.5.0 OVA remains unchanged.

  • The BIG-IQ virtual machine has two software volumes that are already installed with BIG-IQ software.
  • Your attempt to create a new software volume (for example, the third volume), to install a hotfix or image fails and results in this error message.

    Note: This issue will continue to exist on the BIG-IQ system, even if newer BIG-IQ versions (5.x or later) are installed, because the original disk structure set up from the 4.5.0 OVA remains unchanged.

The BIG-IQ virtual machine that is deployed using the standard OVA for BIG-IQ 4.5.0, with a thick provisioning size of 55 GB, can only support up to two software volumes.

To understand more about using the available tools on the BIG-IQ system to provide an installation or upgrade guidance, you can refer to K17406: Using the tmsh utility to create a new software volume for installing a new image or hotfix on the BIG-IQ system.

In addition, when this error message occurs, you can observe the following symptom using the vgdisplay command:

The amount of free space in the volume group is indicated on Free PE / Size, which has less than 10 GB. This amount of space is not sufficient to install any software image or hotifx on the third software slot.

Impact

Installation of the new software image or hotfix to the third slot will fail.

Recommended Actions

There are two recommended actions for this issue:

  • Deploying a new instance of virtual machine using the OVA from the latest BIG-IQ version
  • Deleting the failed installation and re-install to an existing partition
     

Deploying a new instance of virtual machine using the OVA from the latest BIG-IQ version

For a permanent resolution to this issue, F5 recommends that you create a new instance of the virtual machine using the OVA from the latest BIG-IQ version. The latest version OVA will create the new disk system structure that will meet the demands from the newer version of the BIG-IQ software.

Impact of recommended actions: For more information about the upgrade path, refer to the release notes of the newer BIG-IQ version. For more information about locating the desired documentation, refer to K12453464: Finding product documentation on AskF5.

Deleting the failed installation and re-install to an existing partition

You can delete the failed installation slot, which is the third software volume, and identify one of the two used slots as the target destination of the new installation. However, this issue will resurface whenever there is an attempt to install a new software on the third slot (HD1.3) because this workaround continues to use the disk system structure that was originated from the BIG-IQ 4.5.0 OVA.

Impact of recommended actions: F5 recommends that you have the latest configuration backup from the target destination, as the recommended action deletes the existing configuration on the target software volume. The target slot must not be an active boot volume.

  1. Log in to the advanced shell of the BIG-IQ system as administrator.
  2. Delete the failed installation slot on the third installation software volume using the following command syntax:

    tmsh delete /sys software volume <HDx.y>

    For example, to delete the software slot HD1.3, type the following command:

    tmsh delete /sys software volume HD1.3

  3. Choose one of the two used software volumes as the target destination software slot.

    Important: Ensure that you have the latest configuration backup from the target destination copied to a remote system, as the configuration on this software slot will be erased in the next step. To perform this installation, make sure that the chosen target destination slot is not active.

  4. Install the new software image or hotfix on a selected target software volume using the following command syntax:

    tmsh install /sys software <hotfix|image> <ISO> volume <HDx.y>

    For example, to install the new software Hotfix 3 for BIG-IQ 4.5.0 to HD1.2, where HD1.2 is not the active software volume, type the following command:

    tmsh install /sys software hotfix Hotfix-BIG-IQ-4.5.0-3.0.7310-HF3.iso volume HD1.2

  5. Review the installation status by typing the following command:

    tmsh show /sys software

  6. Optional: Once the software installation completes, you can switch the active boot location of the newly installed software using the following command syntax:

    tmsh reboot volume <HDx.y>

    For example, to switch to software volume HD1.2, type the following command:

    tmsh reboot volume HD1.2
