K3064: Configuring BIG-IP with a default SNAT in an active-active configuration

Topic

You cannot configure BIG-IP with a default SNAT in active-active configurations. Instead, you must configure SNAT automap on each unit.

In a typical active-standby configuration using a default SNAT, the systems might have only two VLANs: External and Internal. The active and standby systems share these VLANs, so only two VLANs are necessary. However, in an active-active configuration using SNAT automap, each system must have an Internal VLAN configured. Therefore, you must configure three VLANs:

  • The External VLAN. Configure this as normal and share it between the units.
  • An Internal VLAN for Unit 1 (for example, Internal_U1).
  • An Internal VLAN for Unit 2 (for example, Internal_U2).

You can also enable SNAT automap on the unique internal VLANs for each system.

Example configuration

askf51:/# bigpipe vlan Internal_U1 snat automap enable
askf51:/# bigpipe self <External_Shared_Self_IP_Address> snat automap enable

askf52:/# bigpipe vlan Internal_U2 snat automap enable
askf52:/# bigpipe self <External_Shared_Self_IP_Address> snat automap enable

This will result in SNAT automap for connections through either BIG-IP.
