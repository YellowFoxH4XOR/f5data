Topic

Beginning with BIG-IP LTM 10.1.0, inserting the SSL client certificate information with an iRule can be done directly using the SSL::cert command within the HTTP_REQUEST event. Versions prior to 10.1.0 required extracting the SSL client certificate information from the SSL session, and then creating a custom HTTP header to encode and insert the certificate information.

The following SSL and X509 iRule commands are available:

Important: To use these iRule commands in an iRule, the virtual server must also use a client or server SSL profile, and an HTTP or FastHTTP profile.

SSL

  • SSL::mode
  • SSL::cert <index>
  • SSL::cert issuer <index>
  • SSL::cert count
  • SSL::verify_result
  • SSL::cipher name
  • SSL::cipher version
  • SSL::cipher bits
  • SSL::current_sessionid
  • SSL::modssl_sessionid_headers [<option>+]

X509

  • X509::version <X509 certificate>
  • X509::serial_number <X509 certificate>
  • X509::signature_algorithm <X509 certificate>
  • X509::issuer <X509 certificate>
  • X509::not_valid_before <X509 certificate>
  • X509::not_valid_after <X509 certificate>
  • X509::subject <X509 certificate>
  • X509::subject_public_key_type <X509 certificate>
  • X509::subject_public_key <X509 certificate>
  • X509::subject_public_key_RSA_bits <X509 certificate>
  • X509::extensions <X509 certificate>
  • X509::whole <X509 certificate>
  • X509::hash <X509 certificate>
  • X509::verify_cert_error_string <X509 verify error code>
  • X509::cert_fields <X509 certificate> <verify error code>
