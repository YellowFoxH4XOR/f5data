Known Issue

The BIG-IP Configuration utility may not display the Save on Automatic Sync option.

This issue occurs when all of the following conditions are met:

  • You have multiple devices configured in a device service clustering (DSC) configuration.
  • You have Automatic Sync with either the Full or Incremental option enabled on a device group (DG).
  • You attempt to configure the Save on Automatic Sync option on the DG using the Configuration utility.

In BIG-IP 11.5.0 and later, you can configure designated DGs to instruct the BIG-IP peer devices to save their configuration to file after the system performs an automatic configuration synchronization (ConfigSync). To do so, enable the save-on-auto-sync option using the Traffic Management Shell (tmsh). Note that this option (otherwise known as Save on Automatic Sync) is not available in the Configuration utility on the software versions listed in the Applies to (see versions) box in the upper-right corner of this article.

Impact

You must use the tmsh utility on the BIG-IP system to configure the Save on Automatic Sync option.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You do not see a Save on Automatic Sync option in the BIG-IP Configuration utility when you navigate to Device Management > Device Groups > <DG_Name>.

Resolution

Status

F5 Product Development has assigned ID 591733 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can configure the Save on Automatic Sync option using the tmsh utility. To do so, refer to K14624: Configuring the Automatic Sync feature to save the configuration on the remote devices.

Impact of workaround: Performing the suggested procedure should not have a negative impact on your system.
