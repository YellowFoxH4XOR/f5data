Description

 

After an upgrade, FAST templates configuration does not load and "error 404" displays instead of templates listing after clicking on "F5 Application Services Templates" link.

 

 

Environment

 

BIG-IP

FAST templates

 

 

Cause

 

Unit has been upgraded from a version affected by ID1079817:

 

Bug ID 1079817: Java null pointer exception when saving UCS with iAppsLX installed

 

FAST templates have been reimported following procedure described in article:

 

K56417334: How To Install FAST Templates

Recommended Actions

 

To recover from this issue, you can forceload mcpd bin db, following the described procedure in article:

 

K13030: Forcing the mcpd process to reload the BIG-IP configuration

 

 

Procedure

 

Impact of workaround: Performing the recommended procedure will cause a down time to your system.

 

  1. Log in to the bash shell
  2. Run command tmsh save sys config
  3. Run command touch /service/mcpd/forceload       
  4. Run command reboot  
  5. Sync configurations (when in HA scenario) after procedure has been run to both units.

 

Note: forcing the configuration to be loaded will refresh mcpd bin db, permitting system to run exactly as configured in configuration text files.

 

 

Additional Information

 

To prevent issue, try to upgrade your unit to a non affected OS version, as described in document:

 

Bug ID 1079817: Java null pointer exception when saving UCS with iAppsLX installed
