Known Issue

Secure Web Gateway (SWG) transparent forward proxy configurations may introduce memory leaks.

This issue occurs when one of the following conditions is met:

  • The access policy is configured with a Logon Page agent, an External Logon Page agent, or an HTTP 401 Response agent.
  • An access policy evaluation is triggered when another evaluation is already in progress, or when you access a page where the system requires an established session.

Impact

The BIG-IP system may experience resource exhaustion and possible failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The show sys memory command may indicate that the memory that the Traffic Management Microkernel (TMM) used is close to the amount of allocated TMM memory.
  • Your BIG-IP APM system fails to process traffic for a brief period of time.
  • Unexpected TMM restarts or high availability (HA) failover events occur.
