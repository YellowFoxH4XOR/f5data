Known Issue

This is the result of a known issue. You can display attack signatures in the BIG-IP ASM Configuration utility that match specific filter options by defining a custom search filter. The Containing String filter allows you to search for signature names that contain a specific string.

When searching for an Attack Signature using a Containing String criteria which contains the space character, the first page of results are displayed. When you attempt to select another page result by clicking the Next Page button or by using the Total Entries drop-down menu, no records are displayed. This occurs because the space character is erroneously stripped from the search criteria URI on subsequent page searches.

For example, if you specify the Containing String filter, and search for attack signature names that contain the string execution attempt, the first page of results are displayed. However, when you attempt to select another page result, no additional records are displayed.

F5 Networks Product Development tracked this issue as CR108060 and it was fixed in BIG-IP ASM version 10.0.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Workaround

You can work around this issue by manually editing the URI in your browser window and inserting the space character as a URL-encoded space where necessary. For example, if you are searching for execution attempt, you would locate the following section of the URI:

filter_string=executionattempt

You would then replace the example section with the following:

filter_string=execution%20attempt
