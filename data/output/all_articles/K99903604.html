Issue

Error Message

tmm[<PID>]: 01220002:6: Rule <iRule name and iRules command>: <Action>

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <iRule name and iRules command> is the name of the iRule and the iRules command being executed.
  • <Action> is the action the iRule attempted when the error occurred.

For example:

tmm[1854]: 01220002:6: Rule HTTPS_TEST_iRule <HTTP_REQUEST>: sending to HTTP_POOL_TEST 0

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The iRule code includes a log statement which does not use any of the component, facility, or priority options.

    For example, the statement appears similar to the following:

    <some code>
    ...
    log "this is a log message without facility and priority"

  • An error occurs during Tcl compilation of the script.

    In this case, the message includes details of the error generated by the compiler and appears in the form Rule <rule name> compilation failed: <compiler error here>"

Impact

  • For the first condition, normal log messages appear in the log with this code.
  • For the second condition, the iRule needs to be modified to correct the error.

Recommended Actions

  • For the first condition, F5 recommends that you change the usage of the log command to include facility and priority. For example, change the following statement:

    log "this is a log message without facility and priority"

    to the following statement:

    log local0.info "this is an info level log message"

  • For the second condition, the resolution is highly dependent on the error generated, but it most likely requires you to modify the iRule source.
