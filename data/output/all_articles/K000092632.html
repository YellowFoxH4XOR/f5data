K000092632: 011c0003:3: Rule checker ::tclCheck::checkScript did not complete: save_profile_dep: invalid profile type --- after upgrade

Type
Support Solution
Published
2022-11-16
Updated
2022-12-06
Source
https://my.f5.com/manage/s/article/K000092632

Description

Config not loading after upgrade with following error:

011c0003:3: Rule checker ::tclCheck::checkScript did not complete: save_profile_dep: invalid profile type

 

Environment

- upgrade from version <14.1 to any version >=14.1

- iRule with any SPDY:: command

- Config does not load with error

 

Cause

SPDY:: iRule commands were intentionally removed (i.e. are no longer valid commands, hence the error) since 14.1 because the SPDY profile was deprecated

Recommended Actions

- remove any SPDY:: commands from the iRule to allow successful config load

Additional Information

None
