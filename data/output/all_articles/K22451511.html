Source
https://my.f5.com/manage/s/article/K22451511

Description
Using Ansible with the collection version before or 1.10.0 to deploy the SSL Orchestrator topology, got an error when deploying

TASK [Create SSLO Topology] *************************************************************
fatal: [10.10.100.1]: FAILED! => {"changed": false, "msg": "CREATE operation error: 493cb833-aaaa-bbbb-cccc-08662440f284 : [OrchestratorConfigProcessor] Deployment failed for Error: [BaseHAConfigProcessor (TopologyBaseHAConfigProcessor)] Error: Failed to resolve reference property appId = f5-ssl-orchestrator-tls, propertyValue: s"}

Environment

  • BIG-IP Ansible collection version <= 1.10.0
  • SSL Orchestrator version 9.x

Cause
Newer SSL Orchestrator version 9.x is not compatible with any BIG-IP Ansible collection version before or 1.10.0. 

Recommended Actions

Please install F5 BIG-IP Ansible collection 1.11.0

None
