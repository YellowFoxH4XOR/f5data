Description

When trying to add a DCD to BIG-IQ CM (Centralized Manager) you receive the following error message: 
    Discovery of BIG-IQ Data Collection Device 10.0.0.10 failed due to 'Failed to get device information from REST server on 10.0.0.10.'
 

Environment

  • BIG-IQ
  • Adding a DCD


Cause

The restjavad daemon is not running on the DCD. 
 

Recommended Actions

  1. Check the status of restjavad on the DCD with bigstart status restjavad
bigstart status restjavad
restjavad    down, waiting for setupd configuration to complete
Note the message waiting for setupd configuration to complete. If you get this status, log into the DCD WebUI and complete the setup wizard so restjavad can start properly. 
  1. After completing the wizard verify if restjavad is running properly
bigstart status restjavad
restjavad    run (pid 4642) 15 minutes
  1. When the message reports restjavad is running, re-add the DCD


Additional Information

If you added the DCD initially with the incorrect CM Master Key (also known as the Passphrase) you will need to reset the DCD back to factory settings using the following 

clear-rest-storage -d


K15886: Restoring the BIG-IQ system to factory default settings

Now complete the setup wizard on the DCD with the correct CM Master Key (also known as the Passphrase).
