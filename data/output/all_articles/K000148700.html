Description

Vulnerability assessment services identify, classify, and report potential security holes or weaknesses in the code of your web site. The BIG-IP Web Application Firewall (ASM/WAF) can integrate with the Qualys Vulnerability Assessment (VA) tool to create a security policy that addresses the vulnerabilities identified during scans. You import the vulnerabilities detected by the scanner, and choose whether or not to update the security policy for each problem found.

Environment

  • BIG-IP
  • ASM
  • Qualys Vulnerability Assessment (VA) tool

Cause

None

Recommended Actions

Refer the steps from Using Vulnerability Assessment Tools with a Security Policy 

Note: We recommend you to integrate Vulnerability Assessment tools with newly created security policies with Vulnerability Assessment Baseline template.
