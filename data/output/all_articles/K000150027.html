Description

OCSP shows "F5RST: HTTP internal error (bad state transition)"or "ocsp:response:status {Error (Initialization error)}"

 

Similar logs are found after enabling tam debug logs:

 

#tmsh modify sys db log.tamd.level value Debug

debug tamd[6712]: 010b0888:7: pam_tmm_ocsp.c#54 -url

debug tamd[6712]: 010b0888:7: pam_tmm_ocsp.c#54 My_default_test_responder

debug tamd[6712]: 010b0888:7: pam_tmm_ocsp_client.c#205 Error parsing URL

 

ltm auth ocsp-responder /Common/My_default_test_responder {

 ca-file /Common/my-test-ca-bundle.crt

 url My_default_test_responder <------------ not a URL

 verify disabled

 verify-cert disabled

}

 

Environment

BIGIP LTM

OCSP

 

Cause

The ocsp-responder url field should be a URL as to where to reach the external OCSP responder.

 

Recommended Actions

Include the URL to contact the OCSP service on the responder.
