Known Issue

The EUD Transceiver Report fails to list ports 7.0 and 8.0 on the Herculon i10800 platform.

This issue occurs when the following conditions are met:

  • You have the Herculon i10800 platform.
  • You run the Transceiver Report on EUD 3.2 or earlier.

Impact

The EUD Transceiver Report test results may cause confusion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The EUD Transceiver Report fails to list ports 7.0 and 8.0 on the Herculon i10800 platform, similar to the following example:

    Test Begin: Transceiver Report
    Port 1.1 Transceiver: Not Found
    Port 1.2 Transceiver: Not Found
    Port 1.3 Transceiver: Not Found
    Port 1.4 Transceiver: Not Found
    Port 2.1 Transceiver: Not Found
    Port 2.2 Transceiver: Not Found
    Port 2.3 Transceiver: Not Found
    Port 2.4 Transceiver: Not Found
    Port 3.0 Transceiver: Not Found
    Port 4.0 Transceiver: Not Found
    Port 5.0 Transceiver: Not Found
    Port 6.0 Transceiver: Not Found
    Test Complete: Transceiver Report: PASSED
