K55104539: BIG-IQ is unable to import DNS config when synchronization Group Name contains spaces

Type
Support Solution
Published
2021-01-26
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K55104539

Description

  • Discovering and importing a BIG-IP device with a DNS configuration fails in BIG-IQ Centralized Management
  • Error Message: "failed to add device group. Reason: groupName may only contain underscores, dashes, alpha-numeric characters, and periods."

Environment

  • BIG-IQ 7.X
  • BIG-IP DNS
  • Trying to discover and import a BIG-IP device with a DNS configuration that has a group name with a space in it.

Cause

This is caused by ID745754


Recommended Actions

  1. Go to GUI of the BIG-IP DNS under DNS -> Settings -> GSLB -> General.
  2. At the top of that page in the Group Name box, remove the space from the BIG-IP Synchronization group by renaming it: 
    For example:
    "DNSSync Group" to "DNSSync_Group"
  3. Click Update at the bottom of the page. 
  4. Go back to your BIG-IQ and rediscover the BIG-IP DNS and do the Import tasks, and check if it is successful this time.
     

Additional Information

None.
