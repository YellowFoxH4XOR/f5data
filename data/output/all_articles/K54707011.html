Description

This article will describe how to configure Remote Desktop Native to automatically launch applications once the Remote Desktop session is connected.

  • Previously with Remote Desktop configured in ActiveX mode you could use the "Launch Applications"  feature to automatically launch an application in the Remote Desktop session once it was connected. This feature is not available in Remote Desktop Native mode.
  • In Remote Desktop Native mode you can use the "Custom Parameters" feature to enable the same functionality as "Launch Applications."

Environment

  • Big-IP APM
  • Remote Desktop Native configuration.
  • Microsoft Remote Desktop client.

Cause

Remote Desktop native does not support the "Launch Applications" feature. In addition, starting in Big-IP version 15.1, Active X is not long supported for RDP.

Recommended Actions

Configure custom parameters in the Remote Desktop configuration:

  1. Login to the Admin GUI.
  2. Navigate to Access>Connectivity / VPN>VDI / RDP>Remote Desktops.
  3. Click on the Remote Desktop configuration.
  4. In the "Custom Parameters" field enter "alternate shell:s:value" where "value" is the full path to the application. In the following example in this configuration will launch the MS Word application:
alternate shell:s:C:\ProgramFiles\Office\word.exe

Additional Information

Per Microsoft documentation alternate shell:s:value, "Specifies a program to be started automatically in the remote session as the shell instead of explorer."
