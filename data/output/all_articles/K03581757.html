Topic

You should consider using this procedure under the following condition:

  • Your BIG-IP APM system Security Assertion Markup Language (SAML) single sign-on (SSO) profile is configured with single logout (SLO) and you want to disable the SLO feature.
  • F5 Support recommends that you disable SLO for you BIG-IP APM SSO profile.

Description

Depending on the complexity of the BIG-IP SSO profile and the SAML environment, the SLO feature may not perform in the manner you want. As a workaround, you can modify the SSO profile and disable the SLO feature described in the following procedure.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility.

Procedures

Disabling the SLO feature of a SSO profile

Impact of procedure: Performing the following procedure disables SLO for the modified SSO profile.

  1. Log in to the Configuration utility.
  2. Go to Access > SAML > BIG-IP as SP.

    Note: For versions prior to BIG-IP 13.x, go to Access Policy > SAML > BIG-IP as SP.

  3. Select the External IdP Connectors tab.
  4. Select the check box in front of the Name of the IdP External Connector profile.
  5. Select Edit.
  6. For Edit SAML IdP, select SLO Service Settings.
  7. Remove the configured Single Logout Request URL.
  8. Remove the configured Single Logout Response URL.
  9. Select OK.
