Known Issue

BIG-IP APM password complexity check may trigger a memory leak.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured for Active Directory authentication.
  • The access policy incorporates the Complexity check for Password Reset option.
  • The authenticating user's domain displayName contains any of the following special characters.

    Period .
    Left bracket [
    Open brace {
    Open Parenthesis (
    Close Parenthesis )
    Backslash \
    Asterisk *
    Plus sign +
    Question mark ?
    Pipe symbol |
    Circumflex ^
    Dollar sign $

Impact

When memory utilization of the apd service reaches a maximum, the BIG-IP APM Active Directory authentication may temporarily stop functioning while the apd service restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The apd service memory utilization grows over time.

    For example when you view virtual memory utilization of the apd service using the following command, the amount of utilized virtual memory steadily increments over time.

    top -p `pidof apd`

    Example output from the top -p `pidof apd` command follows. Note the value under the header VIRT:

    PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
    5733 root 20 0 135m 52m 29m S 0.0 1.3 0:00.27 apd

  • The system may temporarily stop processing access policy Active Directory authentication requests.
  • After the system has resumed connectivity to the Active Directory server, the command bigstart status apd shows that the apd daemon has been restarted.
  • When you set logging for the apd service to debug logging, the system logs error messages similar to the following in /var/log/apm:

Workaround

To work around this issue, you can disable Complexity check for Password Reset of the affected access policy. To do so, perform the following procedure:

Impact of workaround: User passwords are no longer checked for complexity.

Disabling AD/LDAP password complexity checks

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Access Profiles > Access Profiles List.
  3. To the right of the affected access policy name, click Edit to open the VPE editor.
  4. Locate the AD Auth box of the access policy (should be located to the right of the Logon page box).
  5. Click the name of the AD Auth box.
  6. Under the Active Directory configuration options, change the Complexity check for Password Reset setting to Disabled.
  7. Click Save.
  8. To apply the configuration change, click Apply Access Policy in the upper left corner of the VPE editor.
