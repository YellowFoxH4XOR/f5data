Description

On Demand Certification Authentication will only check the first certificate listed in the Local Machine certificate store on the client device, when the user is connected to an APM machine tunnel.
This can cause unwanted certificate authentication failures if there are other certificates listed above the authentication certificate in the Local Machine certificate store

Environment

  • BIP-IP APM
  • On Demand Certificate Authentication

Cause
When the user is connected to an APM machine tunnel, there is no prompt for a user to select a certificate to present for authentication if using On Demand Certificate authentication in the APM access policy.
Instead, the On Demand Cert Authentication  will detect the first certificate presented. If the certificate presented is not a valid certificate for authentication, then the user will fail the On Demand Cert Authentication check and be denied by the access policy.

Recommended Actions
Configure F5 Machine Tunnel service to select client certificate. This task requires that the F5 Machine Tunnel service is installed on the client system on which you are configuring certificates. You can configure the F5 Machine Tunnel service to select a client certificate from the local computer store or service store.

Using the Windows Registry:
  1. Start the registry editor Start > regedit.
  2. Navigate to HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\F5MachineTunnelService\Parameters.
  3. Set string ClientCertStoreLocation to system or service.
    Note: system - for selecting client certificate from the Local Machine store and service for selecting client certificate from the F5 Machine Tunnel service store.
     
  4. Set string ClientCertStoreName to the store name. The default store name is MY and can be changed to a custom store.
    Note: When no registry setting is specified, then the machine tunnels service will pick the client certificate from the service store.
     
  5. Using the F5MachineTunnelInfo utility: From the command prompt that is run as an administrator.
     
    • Type: F5MachineTunnelInfo.exe --set_client_certstore system <store name> to set the client certificate store location as the Local Machine store.
    • Type: F5MachineTunnelInfo.exe --set_client_certstore service <store name> to set the client certificate store location as the F5MachineTunnelService store.
    • Type: F5MachineTunnelInfo.exe --remove_client_certstore to remove the client certificate store location and name configuration.
       
    Note: You have now configured the F5 Machine Tunnel service to select a client certificate from the local computer store or service store.
 However, there is no supported method for the On Demand Cert Auth to choose which specific certificate out of this store. It will detect the first certificate presented.
The workaround would be to either load the file into the F5 Machine Tunnel Service store and ensure the F5 Machine Tunnel Service is configured to utilize this store for the On Demand Cert check.
Otherwise, if you need to utilize the Local Machine store location, you will need to ensure the required certificate is listed first.

Another option could be to create a custom certificate  store name, other than MY, that contains just the required certificiate.
Then change the ClientCertStoreName to point to this custom store, per the above steps.
