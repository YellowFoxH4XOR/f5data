Known Issue

After changing the Internet Key Exchange (IKE) protocol ike-peer from IKEv2 to IKEv1, the system does not update the racoon daemon.

This issue occurs when the following condition is met:

  • You change the IKE peer key exchange from IKEv2 to IKEv1.

Impact

You are unable to initiate the IPsec tunnel.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system does not update the racoon daemon with the change.
  • You are unable to initiate the IPsec tunnel.

Workaround

To work around this issue, you can restart the tmipsecd service. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the tmipsecd service, type the following command:

    restart /sys service tmipsecd

  3. To exit tmsh, type the following command:

    quit
