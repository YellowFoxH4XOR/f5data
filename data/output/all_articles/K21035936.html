Known Issue

The ospf6d process may leak memory when configured to use a distribute-list filter.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration uses the Open Shortest Path First (OSPF) dynamic routing protocol.
  • Your OSPFv3 configuration includes a distribute-list filter.
  • The routing database contains IP address prefixes that are filtered by the distribute-list filter when a link-state advertisement (LSA) occurs.

Impact

OSPFv3 dynamic routing is interrupted while the ospf6d process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The ospf6d process size continues to increase in memory.
  • The ospf6d process produces a core file in the /var/core directory.

Workaround

To work around this issue, you can place the BIG-IP system in the network so that LSAs do not need to be filtered using a distribute-list filter (for example, in a stub area).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
