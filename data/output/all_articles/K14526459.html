Known Issue

The TMOS Shell (tmsh) may erroneously generate [api-status-warning] messages on objects that are not configured on the BIG-IP system.

This issue occurs when all of the following conditions are met:

  • You perform an upgrade to the affected software version listed in the Applies to (see versions) box, located in the upper-right corner of this article.
  • You run the tmsh save /sys config command on the BIG-IP system.

When it detects a potential misconfiguration (due to, for example, a deprecated component), tmsh generates warning messages on the configured BIG-IP objects. In this case, tmsh erroneously generates warning messages on objects that do not correspond to any of the configured settings.

Impact

There is no impact. The save operation completes successfully, but the system logs additional warning messages on objects that are not part of the BIG-IP configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the tmsh save /sys config command, you may notice warning messages that appear similar to the following example:

    warning tmsh[<PID>]: 01420013:4: [api-status-warning] ltm/classification/url-cat-policy is deprecated.
    warning tmsh[<PID>]: 01420013:4: [api-status-warning] sys/crypto/ca-bundle-manager is early_access.

Resolution

Status

F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
