K000135295: authz_core:error - client denied by server configuration

Type
Support Solution
Published

Applies to

Source

Description

This article explains about the log messages similar to the samples below that can be seen in multiple locations:
  • Error messages seen from /var/log/httpd/httpd_errors
    Jun 11 19:00:12 bigip1.example.com err httpd[12947]: [authz_core:error] [pid 12947] [client 2001:DB8::abcd] AH01630: client denied by server configuration: /usr/local/www/
  • Error messages seen from /var/log/secure
    Jun 11 19:00:11 bigip1.example.com err httpd[22760]: [authz_core:error] [pid 22760] [client 2001:DB8::abcd] AH01630: client denied by server configuration: /usr/local/www/
 

Environment

  • BIG-IP
  • httpd log
  • secure log
 

Cause

The client with the IP address seen in the logs has been restricted to access to the BIG-IP Configuration Utility. This indicates that the server is denying access to a client due to configuration settings related to authorization. Most of the time, this is due to the effect of the httpd allow list allowing to certain IP addresses/IP ranges only.

Jun 11 19:00:11 bigip1.example.com err httpd[22760]: [authz_core:error] [pid 22760] [client 2001:DB8::abcd] AH01630: client denied by server configuration: /usr/local/www/
 

Recommended Actions

To view the list of allowed IP addresses, use the command: 
tmsh list sys httpd allow

sys httpd {
    allow { 10.0.0.1 172.16.0.2 192.168.0.0 2001:DB8::dcba }
}

 

Additional Information

httpd logs - The httpd messages contain the Apache Web server error log.
    Log file: /var/log/httpd/httpd_errors

security logs - The secure log messages contain information related to authentication and authorization privileges.
    Log file: /var/log/secure
