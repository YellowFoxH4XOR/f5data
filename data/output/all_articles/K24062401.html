Topic

You should consider using this procedure under the following condition:

  • Internet Control Message Protocol (ICMP) health monitors are marking nodes down due to network congestion and you want to increase the priority level of ICMP health monitor traffic.

Description

Starting in BIG-IP 15.0.0, you can configure the BIG-IP system to prioritize ICMP health monitor traffic over other types of traffic. ICMP monitor prioritization is effective whether the network congestion occurs at the BIG-IP switch, at the high-speed bridge (HSB), or on a Traffic Management Microkernel (TMM) instance.

When you configure ICMP monitor prioritization, the system raises the priority of all ICMP requests and replies for a self IP address, not just monitor traffic. As a result, the ICMP traffic will be dropped less frequently in high congestion situations.

Refer to the following information before you enable ICMP health monitor prioritization:

  • The following platforms support this feature as of BIG-IP 15.x:
    • B4450 blades
    • i15000 series
  • The Virtual Clustered Multiprocessing (vCMP) feature does not currently support ICMP health monitor prioritization.
  • ICMP health monitor prioritization supports a maximum of 64 self IP addresses.
  • The feature applies to both ICMPv4 and ICMPv6 traffic.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have access to the Configuration utility.
  • Have one of the supported hardware platforms.

Procedures

Setting the ICMP health monitor prioritization value

To set the ICMP health monitor prioritization value, perform the following procedures:

Impact of procedure: Enabling ICMP health monitor prioritization raises the priority of all ICMP traffic that originates from the self IP address, including responses to ICMP traffic, such as ping requests. For security purposes, you should ensure that external users cannot directly ping the self IP address before you enable this feature.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To change the ICMP health monitor prioritization value, use the following syntax:

    modify /net dag-globals icmp-monitor-priority <value>

    For example, to raise the ICMP health monitor prioritization value, enter the following command:

    modify /net dag-globals icmp-monitor-priority high

    To restore ICMP health monitor prioritization to the default value, type the following command:

    modify /net dag-globals icmp-monitor-priority normal

  3. To save the configuration, type the following command:

    save /sys config
