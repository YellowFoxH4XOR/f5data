Known Issue

The BIG-IP GTM and Link Controller systems may not correctly display virtual server link references.

This issue occurs when all of the following conditions are met:

  • Your system is licensed and configured with both the BIG-IP LTM and GTM modules, or as a Link Controller.
  • The BIG-IP GTM or BIG-IP Link Controller virtual server targets a BIG-IP LTM virtual server that also exists on the local system.
  • You use the Traffic Management Shell (tmsh) to load the system configuration.

Impact

The affected virtual server link reference does not display correctly. However, this issue is only cosmetic and does not affect the functionality of the configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H439238 on the Diagnostics > Identified > Low screen.
  • After you use the tmsh utility to load the system configuration, previously configured virtual server link references display "None".

Workaround

To work around this issue, you can restart the gtmd process. To do so, perform the following procedure:

Impact of workaround: The BIG-IP GTM and Link Controller systems cannot respond to any wide IP queries until the gtmd process starts.

Using the Configuration utility to restart the BIG-IP GTM process

  1. Using administrator privileges, log in to the Configuration utility of the affected BIG-IP GTM system.
  2. Navigate to System > Services.
  3. Select the gtmd service check box.
  4. Click Restart.

Using the tmsh utility to restart the BIG-IP GTM process

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Type the following command:

    restart /sys service gtmd
