Known Issue

After upgrading to ARX 6.4.0, build 15219, users on Windows clients may not be able to drag-and-drop files to the ARX managed volumes.

Impact

Clients are unable to use ARX managed services as expected

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clients receive an error message that appears similar to the following example:

    "No more connections can be made to this remote computer at this time"

Resolution

Status

F5 Product Development has assigned ID 424453 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the top right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of Fix
Versions Fixed
Related Articles

HotfixARX 6.4.0 HFRU1
K12766: ARX hotfix matrix

Workaround

If you are unable to apply ARX 6.4.0 HFRU1, please downgrade the ARX system to either the previous running release or to ARX 6.3.0 HFRU3.

Important: You should downgrade only under the guidance of F5 Technical Support. Downgrading deletes all configuration parameters, both the running-config and the global-config; F5 recommends that you save both configuration files from the ARX system before performing a downgrade.
