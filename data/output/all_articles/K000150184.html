Description

Procedure to manually perform Attack Signature Update in v14.1.0 and later releases via iControl REST API.

Environment

  • BIG-IP ASM / Advanced WAF provisioned and running a 14.1 or later release
  • Performing Attack Signature Update manually via REST API

Cause

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the BIG-IP ASM Configuration utility.

Recommended Actions

The following steps can be used to upload the Attack Signature Update (ASU) .im file, inserting the file into the LiveUpdate database and then installing it:

(1) Upload the file to LiveUpdate files directory on the device via SCP/SFTP:

# scp ASM-AttackSignatures_20250213_075339.im root@<BIG-IP_HOSTNAME>:/var/lib/hsqldb/live-update/update-files/
Password:
ASM-AttackSignatures_20250213_075339.im 100% 1714KB 16.6MB/s 00:00

 

(2) Generate a POST request with the ASU filename in order to insert the file to the LiveUpdate database:

* HTTP Method: POST
* URL: /mgmt/tm/live-update/asm-attack-signatures/update-files
* Payload: '{"filename": "<FILENAME>.im", "fileLocationReference": {"link": "<FILENAME>.im"}}'

For example:

# curl -u admin:admin -kv -H "Content-Type: application/json" "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files" -X POST -d '{"filename": "ASM-AttackSignatures_20250213_075339.im", "fileLocationReference": {"link": "ASM-AttackSignatures_20250213_075339.im"}}' 2> /dev/null | jq .
{

  "md5": "324C3FFA4DBD2D90A5B3108E1388DA52",

Note: Substitute the hostname and relevant device credentials accordingly in this step as well as in the next few steps.

(3) Obtain the link reference for this ASU file present within LiveUpdate database:

* HTTP Method: GET
* URL: /mgmt/tm/live-update/asm-attack-signatures/update-files/?\$filter=filename+eq+'<FILENAME>.im'"

For example:

# curl -u admin:admin -kv -H "Content-Type: application/json" "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files/?\$filter=filename+eq+'ASM-AttackSignatures_20250213_075339.im'" 2> /dev/null | jq .

Make note of the unique Update Files ID from this output within the id and selfLink of this output, as that is used in the next step.

 

(4) Create a POST request with the value above for creating a new installation record:

* HTTP Method: POST
* URL: /mgmt/tm/live-update/asm-attack-signatures/installations
* Payload: '{"updateFileReference": { "link": "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files/<update-file-id>"}}'

For example:

# curl -u admin:admin -kv -H "Content-Type: application/json" "https://localhost/mgmt/tm/live-update/asm-attack-signatures/installations" -X POST -d '{"updateFileReference": { "link": "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files/ff808081954c9f1901954d887c490008"}}' 2> /dev/null | jq .
{
  "id": "ff808081954c9f1901954d90e5060009",
  "lastUpdateMicros": 1740763096317000,
  "updateFileReference": {
    "link": "https://localhost/mgmt/tm/live-update/asm-attack-signatures/update-files/ff808081954c9f1901954d887c490008"
  },
  "status": "new",
  "kind": "tm:live-update:asm-attack-signatures:installationsstate",
  "selfLink": "https://localhost/mgmt/tm/live-update/asm-attack-signatures/installations/ff808081954c9f1901954d90e5060009"
}

 

The ASU .im file should now be visible under 'System ›› Software Management : Live Update' section within Configuration Utility after this step.

Additionally, make note of the Installation ID within the id and selfLink of this output, as that's used in the next step.

 

(5) Now, we can install the ASU file via this Installation ID with a PATCH request containing a payload action to install it, and a command such as the following should work:

* HTTP Method: PATCH
* URL: /mgmt/tm/live-update/asm-attack-signatures/installations/<INSTALLATION-ID>
* Payload: '{"status" : "install"}'

For example:

# curl -u admin:admin -kv -H "Content-Type: application/json" "https://localhost/mgmt/tm/live-update/asm-attack-signatures/installations/ff808081954c9f1901954d90e5060009" -X PATCH -d '{"status" : "install"}' 2> /dev/null | jq .
{

  "lastUpdateMicros": 1740763251422000,
  "updateFileReference": {

}
