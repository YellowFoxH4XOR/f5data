Known Issue

You are unable to remove a self IP address when an unrelated static Address Resolution Protocol (ARP) entry exists.

This issue occurs when all of the following conditions are met:

  • A static ARP entry exists.
  • The static ARP entry is not associated with any of the self IP address subnets.

Impact

You are unable to delete a self IP address until the static ARP entries are deleted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system produces an error similar to the following example:

    err mcpd[6743]: 01071907:3: Cannot delete IP <addr> because it would leave a static neighbor (ARP/NDP) entry unreachable
