Description

Applications like API sometimes have backend servers which need client certificate authentication for some API requests. 
When virtual server on BIG-IP is configured with SSL bridging, some API requests can fail with error on client side : 

"error" :"invalid request"
"error description" : "SSL with client authentication is required"

Environment

  • Standard virtual server with client and server ssl profiles 
  • Backend servers expecting client cert authentication 

Cause

This is server side requirement.
The serverssl profile will handle SSL on serverside of the proxied session, by default serverssl does not provide a client cert to server while performing SSL handshake. 

Recommended Actions

Configuring Client Certificate Constrained Delegation (C3D) feature was introduce to resolve the issue of client certificate authentication requirements from backend server when serverside SSL is configured on the BIG-IP virtual server. For more information refer to the following: 
  • K14065425: Configuring Client Certificate Constrained Delegation (C3D)
  • K72668381: Overview of the SSL Client Certificate Constrained Delegation feature

Note: If the BIG-IP is running version is 12.x and below, the Client Certificate Constrained Delegation is not available. You work around this you can configure the virtual server to performance layer 4 or TCP  allowing the backend server to process the SSL transaction for the request.
