Description

Unable to ConfigSync with errors given such as:

Load failed from /Common/example.com 01070712:3: Caught configuration exception (0), Invalid monitor rule instance identifier: XXXX.

where XXXX is an integer.

Environment

  • BIG-IP 16.0.1
  • HA with 2 or more devices
  • Incongruent monitor instances

Cause

Monitor instance on receiving device exists that is inconsistent with monitor instance that needs to be created based on configuration from the sending device.

Recommended Actions

  1. If detected which monitor instance is causing failure on the receiving device, simply remove either the monitor instance from the target device or the monitor configuration on the sending device
  2. Perform ConfigSync again.
  3. Do 1 and 2 above until all instances are cleared and configuration successfully syncs.
Or perform the following procedure in the Configuration Utility on the target device:
  1. Delete all virtual servers
  2. Delete all pools
  3. Delete all monitors
  4. Check that the monitors have NO instances
  5. Attempt ConfigSync with Overwrite from the device with the correct configuration to the device where just deleted all the virtuals, pools and monitors.
