Description

Live Update installation of attack signatures fails and may cause to run update for several hours. You are unable to upload latest Attack Signature file successfully. Attempt to install and the process hangs "installing..." . This doesn't appear to affect the BIG-IP operation, but signature may not be providing the intended protection.

Environment

ASM Attack Signature update hangs

Cause

Unknown

Recommended Actions

You can use the following procedure to resolve this issue:

From bash delete all the non-genesis update files, re-downloaded the signature updates from F5, and re-apply the updates from the GUI.

Note: Stopping the tomcat service should not affect production traffic. This is safe to run on a production system.

Here are the command line steps that should be taken:

  1. Stop the tomcat server:
    bigstart stop tomcat
  2. Clean the live update db
    cd /var/lib/hsqldb/live-update
    rm -f liveupdatedb.*
  3. Get the list of genesis files (factory-default files)
    less /etc/live-update-genesis.yaml | grep genes | cut -d":" -f2
  4. Go to the update file directory and list the files:
    cd /var/lib/hsqldb/live-update/update-files
    ls -l
  5. Manually remove  *.im files that are not the genesis files. Refer step no 3 for list of genesis file
    rm –f <filename>
  6. Restart the tomcat server:
    bigstart start tomcat


Additional information

The following errors may be found in /var/log/tomcat/liveupdate.log

ERROR Update:236 - Could not look up currently installed file
ERROR Update:256 - Could not calculate readme

Additionally, it is possible that you may observe the BIG-IP Configuration utility repeatedly restarts while the java process consumes a large amount of CPU resources. You may also observe the following log messages repeating in the /var/log/tomcat/liveupdate.log file:

INFO StartStopListener:90 - Live Update Servlet has been started
INFO StartStopListener:50 - Initializing DB

You may also observe signature update timeout with similar logs found in /var/log/tomcat/live_update_upload.log.

apply_asm_attack_signatures|INFO|F5::LiveUpdate::PayloadHandler::upload,,Start Negative Signatures
apply_asm_attack_signatures|ERR|F5::LiveUpdate::PayloadHandler::clean_fail,,Fail load update files: Time exceeded
