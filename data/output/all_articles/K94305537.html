Description

  • GUI and CLI shows a FailsafeFault message
  • An output similar to the following can be seen by running show /sys ha-status all-properties

    --------------------------------------------------------------------------------
    Sys::HA Status
    Feature               Key              Action                        Fail  Feature  Take  Client  Proc          Timeout
                                                                               Enabled  Act   Data                  (sec)

    --------------------------------------------------------------------------------
    vlan-failsafe         /Common/Internal  failover                      yes   yes      yes   0       tmm           90                       <==== Note
    vlan-failsafe         /Common/Internal  failover                      yes   yes      yes   0       tmm1          90                       <==== Note
     

  • CLI prompt example:

    root@(big-ip)(cfg-sync In Sync)(FailsafeFault)(/Common)(tmos)

Environment

  • BIG-IP
  • HA pair
  • VLAN Failsafe

Cause

The FailsafeFault message indicates that VLAN failsafe is triggered and the condition was not cleared as there is still no traffic in the affected VLANs.

Recommended Actions

Please perform the procedure described in the following article to check the physical layer

K62013114: Troubleshooting network interface flapping
