Description

When there are multiple SSL / TLS profiles assigned on a virtual server the [PROFILE::clientssl name] command does not return the currently selected client SSL / TLS profile but in contrast it returns the first client SSL / TLS profile which is assigned on the virtual server in question. 

Environment

  • iRules

Cause

None

Recommended Actions

This behavior is by design as the [PROFILE::clientssl name] command searches the assigned SSL / TLS profiles of a virtual server and returns the first one according to the client SSL / TLS order of the virtual server configuration.

It does not return the client SSl / TLS profile which currently used for a specific client side connection.

Note: [PROFILE::clientssl name] is effectively an internal command and currently there is no priority to enhace it.
