Topic

Issues with encrypted iQuery communications can be caused by the following:

  • The encryption globals statement does not exist, or is not properly configured in the wideip.conf file on the 3-DNS Controller.
  • The F5Key.dat files are corrupted.

Verifying and configuring the globals settings

For encryption, the wideip.conf file must contain the globals statement with the name and the location for the iQuery key file defined.

To confirm the existence and contents of the globals statement, perform the following steps:

  1. View the wideip.conf file, by typing the following command:

    more /etc/wideip.conf

    The globals encryption statement (located at the top of the file) should appear similar to the following:

    globals {
encryption yes
encryption_key_file '/etc/F5key.dat'
}
  2. If a globals statement does not exist, add it to the /etc/wideip.conf file.

Fixing corrupted F5key.date files

If the globals statement exists and is properly configured, the issue could be corrupt F5Key.dat files.

To generate new F5Key.dat files, perform the following steps:

  1. Delete the /etc/F5Key.dat files from both the BIG-IP and the 3-DNS Controller.
  2. Edit the /etc/wideip.conf file globals statement to read encryption no.
  3. Remove the /etc/F5key.dat file from the globals statement, by typing the following command:

    rm /etc/F5Key.dat

  4. Restart BIND, by typing the following command:

    3ndc restart

  5. From the navigation pane in the Configuration utility, click Servers.
  6. Choose BIG-IP Controllers.
  7. Click each BIG-IP entry and confirm an external address is listed (rather than an internal address).
  8. From the 3-DNS Maintenance menu, choose Generate and Copy iQuery Encryption Key. This will generate a new iQuery encryption key (F5Key.dat), and copy it to all of the 3-DNS and BIG-IP Controllers, overwriting all previous F5Key.dat files.
  9. Once the F5key.dat files are copied, select Install and Start big3d from the 3-DNS Maintenance menu.
  10. Edit the /etc/wideip.conf file globals statement to reflect the following:
    globals {
encryption yes
encryption_key_file '/etc/F5key.dat'
}
  11. Restart BIND, by typing the following command:

    3ndc restart

  12. After BIND restarts, type the following command:

    check big3d

    This command will connect the 3-DNS Controller to all the 3-DNS and BIG-IP Controllers and verify the version of the big3d agent.

Encrypted iQuery communication should now work. If it does not, contact F5 Networks Support for further assistance.
