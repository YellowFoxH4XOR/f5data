Known Issue

This is the result of a known issue. Installing an older UCS on BIG-IP ASM 9.4.5 results in the loss of user-defined and system-defined Attack Signatures. This issue occurs if you install a UCS, which was created on a version previous to BIG-IP ASM 9.4.5, onto a BIG-IP ASM system running 9.4.5.

Note: This issue does not occur when upgrading from a previous version to BIG-IP ASM 9.4.5.

When this issue occurs, system-defined Attack Signatures, attack type lists, and user-defined Attack Signatures will appear empty in the Attack Signatures section within the Configuration utility.

F5 Product Development tracked this issue as CR108866 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.
