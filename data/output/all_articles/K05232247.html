Known Issue

If you create a fully-qualified domain name (FQDN) pool with an existing FQDN node, the system reports the pool as having a red status.

This issue occurs when all of the following conditions are met:

  • An FQDN node currently exists.
  • You create a pool with an existing FQDN node as a member.

Impact

The system will not pass traffic for the configured pool.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you create an FQDN pool using an existing FQDN node, the system reports the pool as having a red status.

Workaround

To work around this issue, use the following procedure to delete and re-create the pool to allow it to pass traffic. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. From the Configuration utility, navigate to Local Traffic > Pools > Pool List.
  2. Delete the affected FQDN pool by clicking the check mark next to the pool and clicking the Delete button.
  3. Navigate to Local Traffic > Nodes > Node List.
  4. Delete the existing FQDN node by clicking the check box next to the node and clicking the Delete button.
  5. Re-create the FQDN node.
  6. Navigate to Local Traffic > Pools > Pool List.
  7. Re-create the FQDN pool and add the re-created FQDN node.
