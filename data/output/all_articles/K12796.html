Known Issue

Description

The ARX hostname is displayed as localhost for messages logged to a remote syslog server. As a result, ARX messages logged to a remote syslog server may appear similar to the following example:

172.28.73.28 localhost 2011-03-09T03:02:36.210+0000:ARX500-R73-28:1-1-ACM-3192:DNAS_PGRP-1-NOTE-MSG5:: Volume /volume1 (2:4:) space query failed [-209]: "Device offline"
172.28.73.28 localhost 2011-03-09T03:02:36.317+0000:ARX500-R73-28:1-1-ACM-3192:DNAS_PGRP-1-NOTE-MSG5:: Volume /sharefarm (1:1:) has 9863MB free for metadata

Impact

This issue is cosmetic only. However, it may be harder to determine which ARX system logged the message.

Symptoms

ARX will log the aforementioned error messages.

Status

F5 has confirmed that this issue exists in the products listed in the Applies To box. ID 353418 has been assigned to this issue.
