Topic

F5 has created more descriptive error messages associated with issues that may occur when configuring Single Sign-On credential mapping in an access profile.

For example, an old error message appeared similar to the following:

local/dfedge01 err websso[3912]: 01490000:3: Modules/HttpHeaderBased/HttpHeaderBased.cpp:117 Master Decyrpt failed

This error message has been improved to appear similar to the following example:

local/bigip6401mgmt err websso[9785]: 01490000:3: ff8bc670: Could not find SSO username, check SSO credential mapping agent setting
local/bigip6401mgmt err websso[9785]: 01490000:3: ff8bc670: Could not find SSO password, check SSO credential mapping agent setting

F5 Product Development tracked this feature enhancement as ID 242993 (formerly CR135409), and it was included in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
