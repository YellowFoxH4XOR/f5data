Known Issue

This is the result of a known issue. After launching a Network Access favorite, FirePass may not display certain icons in the Network Access pop-up window. A missing icon may be indicated with a red x in a white square or by an empty space where the icon would normally appear.

Failed HTTP requests to retrieve icons appear when selecting the Server access log (https) view in the pull-down menu on the Reports: HTTP Logs page. The failures will appear in the Text column as HTTP 404 status codes.

For example:


"GET /vdesk/terminal/nogzip/my.get.geek.image.php3/nowhere.gif HTTP/1.1" 404 5 -

"GET /vdesk/terminal/nogzip/my.get.geek.image.php3/both.gif HTTP/1.1" 404 5 -

"GET /vdesk/terminal/nogzip/my.get.geek.image.php3/left.gif HTTP/1.1" 404 -

"GET /vdesk/terminal/nogzip/my.get.geek.image.php3/right.gif HTTP/1.1" 404 5 -

Additionally, the FirePass may experience poor system performance when the Network Access Favorite is launched. Poor system performance may be indicated by elevated levels of the Process Creation Rate graph on the Device Management: Monitoring: System Load page. CPU Usage and Load Average graphs may display elevated levels as well.

The following conditions may trigger poor system performance and missing icons in the Network Access pop-up window:

  • The FirePass is not licensed for Terminal Servers Favorites

    A FirePass that is licensed for Terminal Servers will display the line FP Terminal Server Adapter in the Active Modules section on the Device Management: Maintenance: Activate License page.

  • Terminal Services are not displayed on the user's Webtop

    The Terminal Services type of Favorite can be hidden from users in a master group. Terminal Services are hidden if the option for Terminal Servers is set to Don't Use for the user's master group, under the User Experience tab of the Users: Groups: Master Groups page.

F5 Networks Product Development tracked this issue as CR65258 and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-600-1, which has been issued for FirePass version 6.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue if it is the result of hidden Terminal Services Favorites. To display the Terminal Services Favorites and prevent the issue, set the option to Beginner or Advanced under the User Experience tab of the Users: Groups: Master Groups page, for all master groups that use Network Access.

If your FirePass is not licensed for Terminal Services, you must obtain the hotfix.
