Known Issue

This is the result of a known issue. Under rare conditions, the BIG-IP LTM may drop a TCP FIN packet that contains the same sequence number and receive window size as a prior ACK packet. This behavior may cause the peer system in the TCP connection to retransmit the FIN segment.

F5 Product Development is tracking this issue as CR70248 and CR68618 for the BIG-IP 9.3.0 and 9.4.0 software branches. This issue was also tracked as CR107859 for the BIG-IP 10.x branch, and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, Hotfix-BIGIP-9.4.8-407.0-HF4 has been issued for BIG-IP 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
