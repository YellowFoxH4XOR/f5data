K50242325: BIG-IQ HA error ''Secondary TokuMX (<IP_of_HA_peer>) reporting as primary''

Type
Support Solution
Published
2021-04-30
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X, 6.X.X
Source
https://my.f5.com/manage/s/article/K50242325

Description

BIG-IQ HA broken, Secondary TokuMX reporting as primary

Environment

  • BIG-IQ
  • HA
  • error message "Secondary TokuMX (<IP_of_HA_peer>) reporting as primary"

Cause

Configuration DB corruption

Recommended Actions

  1. Break HA (return both BIG-IQs to Standalone)
  2. return the previous Secondary to default settings
  3. rebuild HA from the HA peer (adding the problem BIG-IQ as Secondary)

Additional Information

None
