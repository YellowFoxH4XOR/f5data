Known Issue

This is the result of a known issue. When installing BIG-IP version 10.x software, the destination you specify for installation target must be a hard drive volume or partition on the BIG-IP system; you should not use the CompactFlash media drive as the installation target. However, the BIG-IP Configuration utility and command line do not warn users about using the CompactFlash drive as an installation target, or prevent a suer from attempting to install version 10.x software on the CompactFlash drive.

For example, if you attempt to use the Configuration utility to install version 10.1.0 build 3341 on the CompactFlash drive on a partitioned system, the installation will initiate and fail to complete. When this occurs, the following symptoms may be present:

  • The bigpipe software command output indicates that the installation failed:

    +-> SOFTWARE STATUS
    | Key Slot Product Version Build Active Status
    | CF1.1 0 BIG-IP 9.4.5 1049.10 no complete
    | CF1.2 0 BIG-IP 10.1.0 3341.0 no failed to install
    | HD1.1 0 BIG-IP 10.0.0 5399.0 yes complete
    | HD1.2 0 BIG-IP 10.0.0 5399.0 no complete

  • Error message indicating the failed installation are logged to the /var/log/liveinstall.log file:

    cat /var/log/liveinstall.log.0 *** Live install starting at 2009/02/16 11:11:50
    *** info: Daemon-driven execution indicated by ENV variable. trace:
    /usr/sbin/image2disk: args=--verbose --verbose --verbose --instslot=CF1.2
    product=BIG-IP version=10.1.0 build=3341.0 /shared/images/BIGIP-10.1.0.3341.0.iso
    debug: caching /shared/images/BIGIP-10.1.0.3341.0.iso to /tmp/URnmCrSbF3. info:
    Repository tm_install version/release is 2.4/34.0 info: System tm_install
    version/release is 2.4/34.0 trace: scan; ignoring extended partition hda 3 (5)
    trace: scan; ignoring extended partition sda 4 (5) trace: scan; ignoring empty
    partition hda 1 (0) trace: scan; ignoring extended partition hda 4 (5) trace:
    scan; ignoring extended partition sda 3 (5) "CF1.2" is not acceptable media
    for TMOS *** Live install complete: status=512 ***

F5 Product Development tracked this issue as ID 293496 (formerly CR116929), and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

You can work around the issue by returning the drive to its original state. To do so, perform the following procedure:

  1. Log in to the command line.
  2. To clear the CompactFlash drive, use the following command syntax:

    bigpipe software <CF_key> product none version none build none

    For example, if you attempted to install the software on CF1.1, use the following command:

    bigpipe software CF1.1 product none version none build none
  3. Type the following command:

    bigstart restart lind
