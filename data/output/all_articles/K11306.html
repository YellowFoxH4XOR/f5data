Known Issue

This is the result of a known issue. If the FirePass standalone client has been installed in a directory other than the default C:\Program Files\F5 VPN directory, the user may be continually prompted to update their client software when connecting to a FirePass controller. The FirePass controller looks at the version of the f5fpclientW.exe file located in the default directory to determine if it should prompt the user to update the client software. If the f5fpclientW.exe file is not found in the default directory, the FirePass controller assumes that an updated is needed.

F5 Networks Product Development tracked this issue as CR125795 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-610-2 issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can stop the update prompts by uninstalling their current standalone client and installing it in the default directory. For instructions, refer to K8253: Removing FirePass client components from Windows 2000, 2003, XP, and Vista systems.
