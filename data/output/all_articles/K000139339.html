K000139339: F5OS port group and interface speed mismatch may cause port flapping on SFPs / optics

Type
Support Solution
Published
2024-04-18
Updated
2024-04-26
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000139339

Description

F5OS ports flapping, optics removed, and optics inserted messages as well as port down, port up messages may be due to a port group and interface speed mismatch on other interfaces on the same device.

Environment

  • F5OS
  • r10900

Cause

Disagreement between the port group speed and interface speed, even on disconnected interfaces, can impact all interfaces on the device.

For example you have connected 40G QSFPs on 1.0 and 2.0 interfaces with interface speeds of 100G causing a MODE_MISMATCH, but you disregard it because you are not using the 1.0 and 2.0 interfaces. Then you observe port flapping and other interface errors on the 3.0, 4.0 and 5.0 interfaces which have the correct optics connected and matching speeds. After updating 1.0 and 2.0 interfaces with 40G speed aligning with the optics connected, the port flaps and errors on interfaces 3.0,4.0 and 5.0 stop.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Make sure port group speed and interface speed agree for all interfaces in all port groups.
