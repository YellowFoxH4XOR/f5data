Known Issue

DNS zone transfers may fail when using the DNS Express feature with Transaction Signatures (TSIG) keys.

This issue occurs when the following conditions are met:

  • The configuration contains a DNS Express zone
  • The zone is configured to use TSIG keys for secure zone transfers

Impact

The zone transfer operation fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H373570 on the Diagnostics > Identified > Medium screen.
  • The zone transfer operation fails.
  • The BIG-IP system logs error messages to the /var/log/ltm file indicating that the zone transfer failed. The error message appear similar to the following:

    zxfrd[5530]: 01531010:3: Transfer of zone <zone_name> failed b/c there are no records.
    zxfrd[5530]: 01531015:3: Failed to retrieve next RR in XFR for zone <zone_name>
    zxfrd[5530]: 01531018:3: Failed to transfer zone <zone> from <addr>, will attempt AXFR.
