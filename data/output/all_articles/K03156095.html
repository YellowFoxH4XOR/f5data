Description
Customize a Windows client package to specify the client components to install, and to customize settings for BIG-IP Edge Client and Dialup Settings components if you wish to include them.

Environment

Windows client package generation

Recommended Actions

To customize and download Windows client package follow below steps:

Note: A connectivity profile is needed. The BIG-IP comes with a "default" profile, however, it cannot be used for this - at least one needs to be created (even if you make 0 changes compared to the default profile). If you do not have one, please follow the below process.

  1. Go to Access > Connectivity/VPN > Connectivity > Profiles 
  2. Click Add
  3. Fill all needed options for your deployment
  4. Click OK
  5. Click on created Connectivity Profile

If you already have a Connectivity profile, open it from under  Access > Connectivity/VPN > Connectivity > Profiles  , and proceed with package generation and download:

  1. Click on black arrow on Customize Package button
  2. Choose Windows option
  3. Mark all needed for your deployment components in Available Components
    See the following document for information on each component: Manual Chapter : BIG-IP Edge Client for Windows
  4. If needed make changes in BIG-IP Edge Client tab
  5. If needed make changes in Dialup Settings tab
  6. If needed make changes in the other tabs
  7. Click Download

Distribute customized package in your organization and install it with administrator rights. If some package is already installed, it is recommended to remove it first by following Removing BIG-IP APM client components from Windows client systems , and only then install the new one. Make sure to reboot the device afterwards.
