K57534305: After replacing LDAP certificate, login fails.

Published
2021-11-10
Updated

Applies to

  • BIG-IP LTM: 15.1.4, 15.1.3

  • BIG-IP DNS: 15.1.4, 15.1.3
Source
https://my.f5.com/manage/s/article/K57534305

Description
After replacing LDAP certificate authentication stops working

Environment

  • Remote LDAP auth enabled
  • Administrative users are authenticated with the 'cert-ldap' source
  • The admin user tries to log in.
  • You can see the following log in /var/log/daemon.log:
     warning systemd[1]: nslcd.service failed.

Cause
Bug ID922185

Recommended Actions

Edit the /etc/nslcd.conf and set the referrals to no.
You can get more details on how to proceed with this change by following K17311.

Additional Information
K17311: Globally disable LDAP referrals for the BIG-IP system
