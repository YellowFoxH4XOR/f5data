Description

  • The bigip.conf file which contains the configuration for the device is duplicated. This causes the file to be twice as large, and may be different than a peer device's.
  • This may cause your system configuration to not load.

Environment

  • BIG-IP
  • Two or more administrative partitions.

Cause

  • Bug ID 462315

Recommended Actions

  • See the BugTracker for ID462315 for mitigation or workaround options.
