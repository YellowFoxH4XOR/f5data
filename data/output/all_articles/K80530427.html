Description

Importing a new certificate on the GUI, using the PKCS 12 (IIS) Import Type option, fails with an error similar to:

Import Failed: OpenSSL error: Exception caught in Management::urn:iControl:Management/KeyCertificate::pkcs12_import_from_file_v2()
Exception: Common::OperationFailed
primary_error_code : -7 (0xFFFFFFF9)
secondary_error_code : 0
error_string : error:06065064:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt

Environment

  • PKCS#12 format certificate (.pfx)

Cause

This error shows when the certificate and key included in the PKCS#12 format file (.pfx), do not match or the file is corrupt.

Recommended Actions

There are 2 options to resolve this issue:

  • Try exporting the certificate again from server side using the correct format, to then import to the BIG-IP.
  • You can convert the .pfx certificate to PEM file, by separating into certificate and key files as explained on K6549: Converting PKCS certificates to PEM format for use with the BIG-IP system. And then importing to the BIG-IP as PEM files, selecting the option Import Type: Certificate and Import Type: Key instead of PKCS 12 (IIS).
