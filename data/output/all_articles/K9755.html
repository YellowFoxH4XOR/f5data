Known Issue

This is the result of a known issue. The Application Language setting specifies the default language encoding for the BIG-IP ASM web application.

The Policy Builder and Auto-Accept features do not function properly when the web application is configured to use the following language encodings:

  • ISO 8859-10 - Nordic
  • ISO 8859-16 - Romanian
  • Windows-874 - Thai

When you set the Application Language setting for the web application to one of the above language encodings, and attempt to run Policy Builder, the Configuration utility reports a message similar to the following example
Policy Builder failure. Please check your configuration.

In addition, when the web application encoding is set to Romanian (8859-16) or Nordic (8859-10), the following message may be logged to the /var/log/ts/policy_builder/pb-#.log file:

[pb.BuilderConfig]: No start point url(s) specified

Note: The listed language encodings were integrated into BIG-IP ASM starting with the release of 10.2.0.
