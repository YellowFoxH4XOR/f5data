Description

When deploying BIG-IP Virtual Edition (VE) version 17.5.x on Nutanix Acropolis Hypervisor (AHV), error 51133 may occur during license activation. The error message typically states: F5 registration key is not compatible with the detected platform. This platform, "", cannot be activated with this registration key "XXXXXXX-XXXXXXX". 

Environment

  • BIG-IP LTM Virtual Edition (VE)
  • Nutanix Acropolis Hypervisor (AHV)
  • Software version: 17.5.x

Cause

Known licensing issue affecting BIG-IP VE instances using UEFI boot mode on Nutanix hypervisor. The UEFI boot mode prevents proper SMBIOS hardware detection during license activation, causing the licensing system to fail to read the platform details.

Recommended Actions

  • The workaround is booting the VM using Legacy mode instead of UEFI mode.
  • If you are on software version 17.5.x, roll back or downgrade to a supported BIG-IP VE version (17.1.x, 16.1.x) when using Nutanix AHV. Refer to K14568: Overview of upgrading and downgrading software on a BIG-IP system.
  • Always review the latest F5 BIG-IP VE Supported Platforms Matrix and relevant setup documentation before performing upgrades or deployments. Refer to F5 BIG-IP Virtual Edition Supported Platforms

Important: Attempting to use unsupported versions may result in service disruption or loss of functionality.
