Known Issue

The BIG-IP system may fail to load a configuration that has an IPv6 wildcard forwarding virtual server.

This issue occurs when all of the following conditions are met:

  • You have created the forwarding virtual server using Traffic Management Shell (tmsh) with the destination address containing the keyword any6 which represents the wildcard IPv6 address.
  • A non-default route-domain is specified (where the default route-domain id is 0).

For example:

tmsh create /ltm virtual forward_vs destination any6%2:0 mask any6 ip-forward

The /config/bigip.conf file will have a virtual server configuration that looks something similar to the following example:

ltm virtual /Common/forward_vs {
destination /Common/any6%2.0
ip-forward
mask any6
profiles {
/Common/fastL4 { }
}
translate-address disabled
translate-port disabled
}

This example shows a virtual server named forward_vs that has a destination address of any6%2.0, which translates to an IPv6 wildcard forwarding virtual server with a route-domain id of 2 and a wildcard service port 0. The BIG-IP system will fail to load this configuration on the affected BIG-IP versions that are listed in the Applies To box located in the upper-right corner of this article.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system fails to load the configuration with the tmsh load /sys config command, and generates an error message similar to the following example:

    A port number or service name is missing for '/Common/any6%2.0'. Please specify a port number or service name using the syntax '/Common/any6%2.0:<port>'.

Workaround

To work around this issue, you can manually edit the /config/bigip.conf configuration file to replace the any6 keyword with the "::" notation for IPv6 addresses. To do so, perform the following procedure:

Impact of workaround: Any syntax errors in the /config/bigip.conf file may result in the BIG-IP system being unable to load the configuration, until the error is rectified.

  1. Log in to the command line of the BIG-IP system.
  2. Copy the /config/bigip.conf configuration file to /config/bigip.conf.SOL60507424 by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.SOL60507424

  3. Modify the /config/bigip.conf file with a text editor.
  4. Replace the any6 keyword in the destination and the virtual-address field with the "::" notation in the /config/bigip.conf file.

    The destination field should look similar to the following example:

    destination /Common/::%2.0

    The virtual-address should look similar to the following example:

    virtual-address /Common/::%2

  5. Save the changes to /config/bigip.conf.
  6. Load the configuration by typing the following command:

    tmsh load /sys config
