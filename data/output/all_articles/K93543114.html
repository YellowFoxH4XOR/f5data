Security Advisory Description

When APM is configured on a virtual server and the associated access profile is configured with APM AAA NTLM Auth, undisclosed requests can cause an increase in internal resource utilization. (CVE-2022-27181)

Impact

System performance can degrade while the system is handling the undisclosed requests. This vulnerability allows a remote, unauthenticated attacker to cause a degradation of service that can lead to a denial-of-service (DoS) on the BIG-IP system that results in preventing legitimate users from successfully authenticating. There is no control plane exposure; this is a data plane issue only.
