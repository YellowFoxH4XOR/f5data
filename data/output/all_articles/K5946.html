Topic

This article applies to BIG-IP 9.x and 10.x. For information about other versions, refer to the following article:

  • K16221: Adding a static ARP entry (11.x)

You can add a static ARP entry to the BIG-IP system from the Configuration utility or the command line.

Adding a static ARP entry using the Configuration utility

  1. From the Configuration utility, click Network.
  2. Click ARP
  3. Click Create.
  4. Enter the IP address of the host for which you are creating a static ARP entry.
  5. Enter the MAC address that is associated with the IP address that you entered in step 4.
  6. Click Finished.

Adding a static ARP entry using the command line

  1. Log in to the BIG-IP command line.
  2. Create a new static ARP entry by typing the following command syntax:

    bigpipe arp <arp key list> <mac addr>

    For example, to create a static arp entry for IP address 10.10.10.1 with a MAC address of f5:90:27:65:d6:b4 type the following command:

    bigpipe arp 10.10.10.1 f5:90:27:65:d6:b4

  3. Verify that the static ARP entry was created successfully by typing the following command:

    bigpipe arp

  4. Save the configuration by typing the following command:

    bigpipe base save

  5. If your BIG-IP system is configured as a redundant pair, also add the ARP entry on the peer BIG-IP unit.
