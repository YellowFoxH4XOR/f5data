Description

The add‑on license was activated on the incorrect appliance/device. You intend to transfer this add‑on so it can be used on the correct unit. However, when attempting to remove the add‑on module during the license activation process, the module is not removed and continues to appear as an “Active Module” in both the WebGUI and the license file.

 

Environment

  • Add-On license
  • Base Registration key
  • Appliance
  • Webgui
  • bigip.license file

 

Cause

The add‑on license cannot be removed because it is bundled with the appliance’s base registration key, preventing it from being reassigned to another device.

 

Recommended Actions

Try removing the add‑on by following the steps below:

 

K34948229 : Add-on license keys can only be activated on one device

 

If the add‑on module appears as “Inactive Module” after removal and meets the criteria outlined in K34948229, contact F5 Support to request retirement of the add‑on license.

If the add‑on module still appears as “Active Module” in the WebGUI or in the license file, contact your F5 Account Manager, as the add‑on is bundled with the appliance’s base registration key and cannot be removed through the license reactivation process.

Note: F5 Support is unable to assist with the re-issue of a replacement key as you are unable to remove/inactivate the add-on module.
