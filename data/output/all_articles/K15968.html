Known Issue

An IP forwarding virtual server may fail to forward an RST packet from the server to the client. This issue occurs when all of the following conditions are met:

  • The IP forwarding virtual server is associated with a FastL4 profile that has Loose Initiation option enabled, together with one of the following configurations:
     
    • The Reset on Timeout option is disabled and the Idle Timeout value is less than the server's Idle Timeout value.
    • The Loose Close option is enabled and the Idle Timeout value is set to Immediate.
  • No secure network address translation (SNAT) configuration is enabled on the IP forwarding virtual server.

Impact

The BIG-IP system fails to forward the server's RST packet to the client, and the client may be left with a hanging TCP connection.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H499782 on the Diagnostics > Identified > Medium screen.
  • A packet capture of the affected traffic shows that the system received an RST packet from the server but did not forward it to the client.

Workaround

To work around this issue, you should ensure that the server's Idle Timeout value is less than the Idle Timeout value of the affected FastL4 profile.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
