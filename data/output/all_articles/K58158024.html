K58158024: Removing vulnerable components from Log4j2 on the BIG-IQ system

Type
Knowledge
Published
2022-01-11
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K58158024

Topic

You should consider using this procedure under the following condition:

  • Your BIG-IQ system's version contains vulnerable components from Log4j2 as described in K19026212: Apache Log4j2 Remote Code Execution vulnerability CVE-2021-44228.

Description

The BIG-IQ system is not vulnerable to Log4j2 as it cannot be exploited by an unauthenticated user. However, the system still contains the vulnerable Log4j jar. You can remove the Log4j vulnerable components by using the tool provided on the F5 Downloads site.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IQ system.
  • You have an account to download the package from F5 Downloads.

Procedures

  • Download the tool file
  • Remove the Log4j vulnerable components

Download the tool file

F5 provides the tool file on the F5 Downloads site. You can download the TAR and MD5 files, and transfer the files to the BIG-IQ system. To download the tool file, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to F5 Downloads.
  2. Select Find a Download.
  3. Select BIG-IQ Centralized Management.
  4. Select your BIG-IQ version.
    • BIG-IQ 8.x:

      Within the product container, select Utilities.

    • BIG-IQ 7.x:

      Within the product container, select the exact matching version to the fourth element of your BIG-IQ version.

  5. From your local system, select and download the Log4jVul.tar and Log4jVul.tar.md5 files.
  6. From your local system, use the .md5 file to validate the checksum of the TAR file.
  7. After verifying the checksum, transfer the files Log4jVul.tar and Log4jVul.tar.md5 to the BIG-IQ system using secure-copy (SCP). For example, you can store the files in the BIG-IQ system /shared directory.

Remove the Log4j vulnerable components

After you transfer the TAR and MD5 files to the BIG-IQ system, remove the Log4j vulnerable components by performing the following procedure:

Impact of procedure: The procedure includes stopping and starting the restjavad, searchd, appiqservices, and elasticsearch services, which interrupts the BIG-IQ system functionality. F5 recommends performing this procedure during a maintenance window.

  1. Log in to the BIG-IQ system using administrator credential to access the Advanced Shell (bash) command prompt.
  2. Change directories to the directory you used to transfer the TAR and MD5 files in the previous procedure. For example, go to the /shared directory if you transferred files to the BIG-IQ /shared folder in Step 8 of the previous procedure.
  3. Extract files from the Log4jVul.tar file by entering the following command:

    tar xvf Log4jVul.tar

    The command extracts the directory Log4jVul, which contains the following files:

    Log4jVul/BOOT-INF/
    Log4jVul/BOOT-INF/lib/
    Log4jVul/BOOT-INF/lib/log4j-core-2.11.1.jar
    Log4jVul/log4j_update.sh
    Log4jVul/README         
    Log4jVul/zip-3.0-1.el6.x86_64.rpm
    Log4jVul/zip-3.0-11.el7.x86_64.rpm

  4. Change directories to the Log4jVul directory by entering the following command:

    cd Log4jVul

  5. List the directory to ensure you can see the sub-folder and the files listed in Step 3.
  6. Install the RPM file by entering one of the following commands:
    • BIG-IQ 8.x:

      rpm -ivh zip-3.0-11.el7.x86_64.rpm

    • BIG-IQ 7.x:

      rpm -ivh zip-3.0-1.el6.x86_64.rpm

    Note: Do not perform both RPM installation commands on the same system. If unsure, use the cat /VERSION command to check the version of your BIG-IQ system.

  7. Grant executable file permissions for the log4j_update.sh file by entering the following command:

    chmod 700 log4j_update.sh

  8. Update and remove the Log4j vulnerable components by entering the following command:

    ./log4j_update.sh

    The command output appears similar to the following example:

    Stopping services: restjavad, searchd, appiqservices, elasticsearch
    Removed vulnerable code from jar.
    deleting: BOOT-INF/lib/log4j-core-2.11.1.jar
      adding: BOOT-INF/lib/log4j-core-2.11.1.jar (deflated 11%)
    Removed vulnerable code from jar.
    Starting services: restjavad, searchd, appiqservices, elasticsearch

  9. If you do not receive error messages and the command output appears similar to the example in Step 8, the system update is complete. Since the zip utility was added to the system in Step 6, it is no longer required. To remove the zip utility RPM file, enter the following command:

    rpm -ev zip-3.0

  10. You can delete the Log4jVul directory, Log4jVul.tar, and Log4jVul.tar.md5 files since they are no longer required. Move the current directory to a different location before deleting the Log4jVul directory. 

    For example, if you saved the Log4jVul directory, Log4jVul.tar, and Log4jVul.tar.md5 files in the /shared directory from Step 3, perform the following procedure:

    1. Move the current directory to a different location by entering the following command:

      cd /shared

    2. Delete the Log4jVul directory by entering the following command:

      rm -rf /shared/Log4jVul

    3. Delete the Log4jVul.tar and Log4jVul.tar.md5 files by entering the following command:

      rm -f /shared/Log4jVul.tar /shared/Log4jVul.tar.md5
