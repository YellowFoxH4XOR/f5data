Description

You attempt to create or modify an OAuth Claim resource, using a reserved word for its Claim Name.
To create or modify a Claim resource, on the Configuration utility for example, go to Access  >  Federation > OAuth Authorization Server > Claim.
The resource creation or modification operation you are attempting fails with the following error:

err mcpd[<PID>]: 01071c88:3: The word (<Claim Name>) is a reserved word and cannot be used as claim name for the claim (/Common/name).

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <word> is the value of Claim Name in a OAuth Claim resource.
  • <name> is the name of a OAuth Claim resource.

For example:

err mcpd[245]: 01071c88:3: The word (username) is a reserved word and cannot be used as claim name for the claim (/Common/username).

 

Environment

  • OAuth
  • SAML
  • Trying to claim Reserved Fields (ex: username) in JWT token

Cause

Cannot use reserved words when providing a value for Claim Name when creating or modifying resources on the BIG-IP Configuration utility.
The following is a list of all the reserved words:
username, iss, aud, sub, exp, nbf, iat, jti, x-jti, at_hash, c_hash, azp, acr, amr, sub-jwk, nonce, auth_time, _claim_names, _claim_sources, scope, scope_data, token_type, and id_token.

Recommended Actions

To work around this limitation, you can use a field named "Username" (uppercase!), if the end client software could accept that, or do so after a small modification.
You can also use variables named username1 username2 etc...

Additional Information

The reserved words are predefined words used in the BIG-IP software and using them in your configuration will cause a conflict and result in system errors and may cause other issues. For more information about BIG-IP reserved words, refer to K6869: Reserved words that should not be used in BIG-IP configurations.
