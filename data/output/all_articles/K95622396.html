Description

How to configure a DNS-resolver for the EndPoint Management System

Environment

Relevant environmental factors specific to the topic

  • APM
  • EndPoint Management System
  • DNS Resolver

Cause

None

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Go to Network  ››  DNS Resolvers : DNS Resolver List
  2. Click Create
  3. Assign a name (Example: Resolv)
        Important! The DNS Resolver must be assigned to Route Domain 0. 
  4. Click Finished
  5. Back on Network  ››  DNS Resolvers : DNS Resolver List click on the newly created object
  6. Click on Forward Zones
  7. Click Add
  8. Configure a forward zone with "." in FQDN name
  9. Configure the DNS server IP address
  10. Click Add
  11. Click Finished
