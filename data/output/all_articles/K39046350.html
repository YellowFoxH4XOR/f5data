Description

The BIG-IP i5000, i7000, and i10000 series platforms use a 2.2” color LCD panel to provide platform status and accept user input. The LCD panel includes a feature to adjust the brightness for a given platform. The default brightness setting for the LCD panel is 100%.

The LCD is specified to meet ISO-9241 Class 0 display standard (zero initial pixel defects of any kind). The LCD luminosity and chromaticity specifications are shown in the following table:
