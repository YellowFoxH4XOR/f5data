K000147426: How to increase the idle timeout of a request on F5® Distributed Cloud Services load-balancers?

Description

You (or your website visitors) may occasionally receive timeout errors when making requests on a website behind F5® Distributed Cloud Services. When these errors occur too frequently, one workaround is to increase the timeout that the our load-balancer waits for before closing the connection.

Environment

  • F5® Distributed Cloud load-balancer

Cause

Timeout errors may occur when the load balancer closes idle connections before the web server or application has responded. This can happen if the default idle timeout is too short for certain requests or application behaviors, leading to premature connection termination and user-facing errors.

Additional Information

  • Increasing the idle timeout on the load balancer allows connections to remain open longer, which can help reduce timeout errors for slow or long-running requests.
  • This adjustment is a workaround, not a root solution. If the web server or application is slow to respond, increasing the timeout may temporarily mask the issue but can increase server load and average response times.
  • Continuously increasing the idle timeout without addressing underlying application or server performance issues can create a "vicious circle" of longer waits and more resource consumption.
  • The idle timeout should be set based on the expected maximum response time of your application, but it is best practice to optimize the application and server responsiveness.
  • Changes to idle timeout settings take effect after saving the configuration and may impact all new connections handled by the load balancer.
