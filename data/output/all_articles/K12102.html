Topic

In BIG-IP versions prior to 10.1.0, the menus accessible from the LCD panel provided data on a number of Traffic Management Microkernel (TMM) statistics.

For example:

Max Conns: <value>
Curr Conns: <value>

Beginning in BIG-IP 10.1.0, all statistics screens have been removed from the LCD panel menu. For BIG-IP 10.1.0 and later, the BIG-IP Configuration utility and the command line interface should be used for statistics reporting.

Note: For more information about using the BIG-IP Configuration utility to report statistics, refer to the Configuration Guide for BIG-IP Local Traffic Manager and the TMOS Management Guide for BIG-IP Systems. For more information about using the BIG-IP command line interface to report statistics, refer to the BIG-IP Command Line Interface Guide and the Bigpipe Utility Reference Guide.
