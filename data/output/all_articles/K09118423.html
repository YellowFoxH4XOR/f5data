K09118423: MacOS vpn clients cannot connect to VPN

Type
Support Solution
Published
2021-12-16
Updated
2023-02-21
Applies to
  • BIG-IP APM: 16.X.X
Source
https://my.f5.com/manage/s/article/K09118423

Description

MacOS client gets disconnected right after connection initiation.

  • CTU report messages: 
    PackageDownloader, PackageDownloader, Downloading package, https://hostname/public/download/mac_oesisInspector.tar
PackageDownloader.mm, 91, PackageDownloader, PackageDownloader, Cannot create temporary file name
InspectionHostView.mm, 415, InspectionHost, InspectionHost, Package Downloader failed, Cannot create temporary file name
  • APM logs:
    Session deleted (network_error; code - 16388)

Environment

  • BIG-IP APM
  • Network access resource
  • Edge client for MacOS

Cause

Permissions under "/Library/F5Networks/Inspectors" directory. This folder needs to be user-writable.

Recommended Actions

# Make the directory in case it doesn't exist
sudo mkdir -p /Library/F5Networks/Inspectors
# CD to that directory
cd /Library/F5Networks/Inspectors
# download the file direct from APM
curl -kO https://10.X.X.X/public/download/mac_oesisInspector.tar
# unpack the file into the same directory
sudo tar -xvf  mac_oesisInspector.tar
# Remove the tar file
sudo rm  mac_oesisInspector.tar
#Check for the correct version 7090.2020.xxxx.1
cat OesisInspector.ver
