Description

Depending on the type of persistence profile, there is a default timeout value set by F5.  You may wish to modify that default timeout value to a custom one. 

Environment

  • BIG-IP LTM
  • Persistence profile

Cause

None.

Recommended Actions

Follow the below steps to modify the persistence timeout value:

Using the Configuration Utility (GUI):

  1. Navigate to Local Traffic >  Profiles > Persistence.
  2. Click the name of the profile you wish to modify.
  3. Click on the Custom checkbox on the right.
  4. Enter the timeout value in seconds that you wish to set.
  5. Click Update.

 

Using the command line (TMSH):

  1. Log in to TMSH by typing the following command.

tmsh

  1. View the current options of the profile by listing its properties.

list ltm persistence <persistence type> <profile name>

  1. Modify the persistence timeout value

modify ltm persistence <persistence type> <profile name> timeout <value>

Note: this would be an example - modify ltm persistence dest-addr test-profile timeout 1200

  1. Check the profile's properties again to verify the changes have been applied.

list ltm persistence <persistence type> <profile name>

  1. Save the configuration to make the changes persistent.

save /sys config
