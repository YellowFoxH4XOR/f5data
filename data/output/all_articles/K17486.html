Known Issue

When an unsigned referral response is signed by the BIG-IP system using DNS Security (DNSSEC), the NextSECure3 (NSEC3) resource record has an empty type bitmap. The empty bitmap should contain a Name Server (NS) type.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to sign Domain Name System (DNS) server responses using DNSSEC. 
  • The BIG-IP system has received an unsigned referral response from a remote DNS server.

Impact

DNSSEC referral responses signed by the BIG-IP system are not RFC compliant.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When viewing NSEC3 resource records created by the BIG-IP system, the type bitmap is empty.
