Known Issue

This is the result of a known issue. You cannot delete a distributed application containing one or more wide IPs using iControl. Attempting to delete the distributed application results in an iControl error.

Note: A distributed application is a grouping of one or more wide IPs. The distributed application allows you to create dependencies based on BIG-IP GTM objects, such as data centers, servers, and links. For more information, refer to the Configuration Guide for BIG-IP Global Traffic Management.

F5 Product Development tracked this issue as CR68525 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.

This issue was fixed in Hotfix-BIGIP-9.4.8-396.1-HF3 issued for BIG-IP 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Workaround

You can work around this issue by removing the wide IPs from the distributed application configuration before attempting to delete the distributed application.
