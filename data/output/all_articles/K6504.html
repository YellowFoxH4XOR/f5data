Topic

In order to diagnose hardware problems, FirePass provides a feature called End-User Diagnostics (EUD). EUD is implemented as a boot option. Once booted in EUD mode, FirePass provides a menu of tools for testing hardware components. This Solution describes the use of these tools to perform troubleshooting.

Warning: You should not run these test tools on a system that is in production. These tests stop the unit, and prevent it from passing traffic while these tests are run. Run this tool only if you are instructed by a an F5 Networks Support representative, or if you are verifying a hardware issue with a unit that is already removed from production.

Supported Platforms

Note: Only newer FirePass controllers (including the 4300 platform) ship with EUD installed. For information about which FirePass controllers ship with EUD installed, and options for some older models, refer to K6547: Installing End-User Diagnostics on FirePass 4100 platforms.

Note: For information about obtaining and installing EUD hotfixes, refer to K7960: Obtaining and installing the latest version of End-User Diagnostics

Starting the EUD

Starting the EUD requires restarting the FirePass, then booting the EUD image. You can only start and run the EUD from a console connected to the FirePass controller's serial port.

You can start the EUD by performing the following procedure:

  1. Connect a terminal or PC to the serial console port of the FirePass controller using a null-modem cable.

    Important: A null-modem cable is required for the serial connection. Other types of cables such as crossover or rollover cables will not work.

  2. Disconnect all cables before starting the EUD tests, except for the null-modem cable that is connecting your terminal or PC.
  3. Open a console session on the FirePass controller's serial port using the following settings:

    Baud rate: 19200 Data bits: 8 Parity: none Stop bits: 1 Flow control: hardware

    A login prompt appears.

  4. At the login prompt, type maintenance.

    A password is not required, by default.

    A conditions of use screen appears.

  5. Type y or press the Enter key to agree to the conditions.

    The maintenance menu appears.

  6. Select option 7 - Restart/shutdown controller by typing 7 and pressing the Enter key.

    The Restart/shutdown submenu appears.

  7. Select option 2 - Restart FirePass controller by typing 2 and pressing the Enter key.

    Depending on the version of FirePass software, a confirmation menu may appear. If so, pressing the Enter key will restart the controller. Otherwise, the controller will restart automatically.

  8. After the following message appears, press the Tab key to enter the boot menu:

    Booting from local disk...

    A boot: prompt and three options, Linux, Recover and Diag appear.

    Note: If the Diag option does not appear, refer to K6547: Installing End-User Diagnostics on FirePass 4100 platforms.

  9. Type Diag at the prompt and press the Enter key.

    The following message will display along with period characters to indicate progress:

    Loading Diag

    The FirePass controller will begin booting into the EUD image. When the boot process finishes, the EUD menu will display.

Running the EUD

Important: Beginning in EUD version 10.0.9.14, the fsck (option 14) has been removed. All menu option numbers greater than 14 will have moved up by 1. For more information about the change, refer to K12763: Change in Behavior:The fsck option has been removed from End User Diagnostics

When the EUD starts, a menu similar to the following example appears:

Product: HSIBJ Family End User Diagnostics Build: build 10.0.9.11.0 Build date: Mon Mar 24 10:04:05 PDT 2008

01 - Hardware Report 02 - Run the switchboard CPLD tests 03 - Verify switchboard I2C devices 04 - Verify PCI devices 05 - Run the System Ram test 06 - Run the LCD functionality test 07 - Internal Packet Path test 08 - Run the Disk Drive test 09 - Run the PVAx memory test 10 - Run the SSL test 11 - Run the FIPS test 12 - Run the Compression test 13 - S.M.A.R.T test 14 - Run fsck on all drive partitions 15 - Run all of the above Non User Interactive tests 16 - Run all of the above applicable tests 17 - Display Test Report Log 18 - Exit EUD Test and Reboot System Select a Menu item # -

To run one of the EUD tests, type the number of the test and then press the Enter key (leading zeroes are not required for options 1 through 9). These options are described in the Understanding the EUD options section.

Warning: To exit the EUD, you must use option 18 - Exit EUD Test and Reboot System. Using any other method to exit the utility could cause system instability.

Note: Many of the tests will display results that scroll off the terminal screen quickly. Use option 17 to review your results in a paged format.

Understanding the EUD options

Note: After each of these tests complete, the results of the test are displayed, then the EUD menu appears.

01 - Hardware Report

This option provides a comprehensive test of all system hardware components, including the following:

  • System information, such as the processor version, socket designation, and size of memory installed in each memory socket.
     
  • Total memory installed, in Megabytes (MB).
     
  • Devices on each PCI bus.
     
  • Motherboard sensor tests, including the CPU fan speed (RPMs), Chassis temperature (Celsius), and CPU temperature (Celsius).
     
  • SCCP version information, including the product ID number, board version, and CPLD version.
     
  • Chassis information, including interior and exterior switchboard temperatures (Celsius), and fan speeds (RPMs).

02 - Run the switchboard CPLD tests

This test checks the switchboard CMOS Programmable Logic Device (CPLD) on the motherboard. This test requires you to view the status LEDs on the front panel of the system. After you select this option, you will be prompted to answer several questions.

03 - Verify switchboard I2C devices

This option verifies any Inter Chip Communication Bus (I2C) devices in the system.

04 - Verify PCI devices

This option runs a test that reports and verifies the PCI devices on the PCI bus.

05 - Run the System Ram test

Use this option to verify the system RAM. This test may take several seconds to complete. The system RAM test performs an SDRAM data bus and address bus test. The test reserves a 15 MB block of available system RAM and performs the following tests:

  • Stuck address test
     
  • Random value test
     
  • XOR comparison test
     
  • SUB comparison test
     
  • MUL comparison test
     
  • DIV comparison test
     
  • OR comparison test
     
  • AND comparison test
     
  • Sequential increment test

06 - Run the LCD functionality test

The functionality tested includes LCD serial communications, pixels, and keys.

Note: These tests require user interaction. To successfully perform these tests, you need access to the front panel on the unit you want to test, in order to view prompts and results on the LCD and to operate the keypad.

  • LCD and keypad backlight test

    The LCD functionality test performs the following tasks regarding LCD serial communications:

    • Lists the firmware version of the LCD panel
       
    • Displays the LCD panel voltage tests.
       
    • Checks the viability of the key pad backlight and the LCD backlight

     
  • Pixels

    After you complete the backlight tests, you are prompted to test the pixels and contrast changes for the LCD.


     
  • Keys

    After you verify the LCD contrast change, the next series tests the keys on the LCD keypad. For this series of tests, you must press keys on the LCD keypad, as indicated by the prompts. After you press the correct key for each prompt and the test is successful, the word PASS is displayed.

07 - Internal Packet Path test

You can use this option to test the Ethernet interfaces in the system. This test sends ping packets from the motherboard Ethernet interface back to the switchboard Ethernet interface and validates the result.

08 - Run the Disk Drive test

The disk drive test checks the integrity of the hard drive in the system. Use this option to test all the standard read/write devices, such as hard drives and compact flash cards. This test compares the size of each device to a table of size ranges specified for the applicable motherboard in the system. Then, some blocks on each device are tested with a read, write, read, compare, write, read, compare sequence. The test also reports the size of the drive in megabytes (MB).

09 - Run the PVAx memory test

Use this test to display the version of the PVA installed in the system. This test also verifies the functionality of the external memory used by the PVA. This test runs only if the system has the Packet Velocity ASIC version 2 or later installed.

10 - Run the SSL test

Use this option to test the SSL acceleration hardware installed in the system.: This test runs only if the system has SSL acceleration hardware installed.

11 - Run the FIPS test

Use this option to test the FIPS hardware installed in the system This test runs only if the system has a FIPS module installed.

12 - Run the Compression test

This test runs only if the system has additional hardware compression installed. The test performs read, write, and data verification tests.

13 - S.M.A.R.T test

The self-monitoring, analysis, and reporting technology test (S.M.A.R.T.) tests the internal status of the hard drive, including the following:

  • Read error rate
     
  • Start/Stop count
     
  • Re-allocated sector count
     
  • Power on hours count
     
  • Spin-up retry count
     
  • Drive calibration retry count
     
  • Drive power cycle count
     
  • Offline scan uncorrectable sector count
     
  • Ultra ATA CRC error rate and multi-zone error rate

The hard drive updates and stores these attributes in a reserved area of the hard drive. The hard drive also stores a set of threshold values that correspond to the calculated value. Each threshold indicates the point at which the corresponding value will produce negative results.

Important: Beginning in EUD 10.0.9.14 the fsck (option 14) has been removed. For more information on the change refer to K12763: Change in Behavior:The fsck option has been removed from End User Diagnostics

14 - Run fsck on all drive partitions  

Use this option to run fsck on all drive partitions. The test runs fsck with the -y option.

15 - Run all of the above Non User Interactive tests

Use this option to run all EUD tests that are applicable to the system and do not require user interaction.

16 - Run all of the above applicable tests

Use this option to run all EUD tests that are applicable to the system.

17 - Display Test Report Log

Use this option to display a test report. Use a capture of this data when you work with a support representative.

18 - Exit EUD Test and Reboot System

After you have completed the tests you want to run, use this option to exit the EUD and reboot the system. You must use this option to exit the EUD. Using other methods, such as rebooting using power switches, can destabilize the system.
