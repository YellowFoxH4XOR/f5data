Description

When performing an upgrade, the configuration fails to load﻿ with the below error in ltm log.

01071837:3: The pool (/Common/http_pool) contains a reference to a gateway failsafe device (/Common/bigip1.example.com), which does not exist on the system. Please specify a valid device for this configuration. Unexpected Error: Loading configuration process failed.

Environment

This issue occurs when all the following conditions are met:

  • BIG-IP HA
  • Gateway Pool
  • System Gateway Failsafe

Cause

ID 636348

Recommended Actions

Remove Gateway Failsafe before resetting the device trust

Additional Information

Bug ID 636348 only applies up to 14.x, however, there is by far no fix in any available versions.
