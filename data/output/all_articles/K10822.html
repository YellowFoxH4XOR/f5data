Topic

This article applies to BIG-IP 9.x. and 10.x. For information about other versions, refer to the following article:

  • K13469: Determining the compression capability of your BIG-IP system (11.x - 12.x)

The BIG-IP system offers various levels of software and hardware HTTP compression capability, depending on the platform and the software license. A software compression license is included in some BIG-IP base products and module licenses. You may also purchase HTTP Compression Add-On licenses in specific increments. An unlimited compression license is also available, allowing compression throughput limited only by the capability of the system.

Note: For information about the available increments and pricing, contact your F5 Sales Representative.

Determining software compression licensing limits

To determine the licensed compression limit for your system, type the following command at the command line:

bigpipe version | grep -i "HTTP compression"

The following command output displays:

HTTP Compression <license_limit>

For example, a system with an unlimited compression license displays the following output:

HTTP Compression unlimited

A BIG-IP LTM system licensed with the default 5 MBPS compression limit displays the following output:

HTTP Compression 5

Determining hardware compression availability

The following list includes some BIG-IP platforms that shipped with hardware compression cards installed:

  • BIG-IP 11000 Series
  • BIG-IP 8900 Series
  • BIG-IP 8800
  • BIG-IP 8400
  • BIG-IP 6900
  • BIG-IP 6800
  • BIG-IP 6400 (optional on this platform)

Note: Customers using the 8800 platform should refer to K10806: HTTP hardware compression is unavailable on BIG-IP 8800 platforms running version 9.4.7.

To determine whether your system includes the hardware compression card, type the following command at the command line:

bigpipe version | grep -i "HTTP hardware"

If the system contains a hardware compression card, the following command output will be displayed:

HTTP Hardware Compression

If no card is present, no output is displayed.
