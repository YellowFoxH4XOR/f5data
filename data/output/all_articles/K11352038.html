K11352038: Can not log in to CLI of BIG-IP Cloud as root

Type
Support Solution
Published
2021-01-15
Updated
2025-02-06

  • BIG-IP
  • Alibaba Cloud
  • Microsoft Azure

Source
https://my.f5.com/manage/s/article/K11352038

Description

It is not possible to log in to CLI of BIG-IP/BIG-IQ cloud (AWS, Azure, GCP and Alibaba) as root.

Environment

  • AWS, Azure, Google Cloud Platform and Alibaba cloud
  • BIG-IP/BIG-IQ
     

Cause

root account is disabled by default.
 

Recommended Actions

  • Use Admin or other administrative account you created for login to the CLI.
  • Use Admin or other administrative account you created for SCP and SFTP.
    When you use the scp or sftp commands to transfer files from/to the BIG-IP system, the user must have the Administrator role and access to Advanced Shell (bash) for BIG-IP versions that has the fixes described in
    • SCP: K03585731: F5 secure shell vulnerability CVE-2020-5873
    • SFTP: K38941195: BIG-IP Resource Administrator vulnerability CVE-2019-6617
    • Only Administrators can be granted Advanced Shell (bash): K07702240: BIG-IP Resource Administrator vulnerability CVE-2019-6618

Additional Information

Reset BIG-IP VE password in Azure
