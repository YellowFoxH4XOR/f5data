Description

The event log generated by ASM for the violation "Illegal meta character in URL" does not show the violation details.

Environment

  • ASM event log
  • Illegal meta character in URL

Cause

This behavior can be caused after a change of the value of asm system variable ecard_max_http_req_uri_len to a value of >= 13060. This is expected as the system is surpassing the limit on the size of the protobuf files used in the reporting system.

Recommended Actions

One of the following workarounds can be used:

  1.  Reduce the value of the ASM system variable ecard_max_http_req_uri_len to a value <=13059.
  2. Alternatively, increase the size of the max_protobuf_data_msg_size system variable. The default value for this is 51200. For example, the CLI commands below will double that value.

# /usr/share/ts/bin/add_del_internal add max_protobuf_data_msg_size 102400 --default 51200
# bigstart restart asm

Note! This is disruptive as it requires an ASM restart and that may have a resource impact, it should be tested during a maintenance window.
