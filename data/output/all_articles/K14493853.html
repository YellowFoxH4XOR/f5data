K14493853: Unable to update attack signature automatically

Type
Support Solution
Published
2020-09-23
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K14493853

Description

Unable to update attack signature automatically with error:

Check for updates failed for the following modules:
ASM Attack Signatures - Could not retrieve latest file for asm-attack-signatures
Browser Challenges - Could not retrieve latest file for browser-challenges
Server Technologies - Could not retrieve latest file for server-technologies

Environment

  • ASM attack signatures
  • BIG-IP DNS configuration is set to IPv6

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 945789

Recommended Actions

There is no fix available at the time of creation of this article. As workaround you can set the DNS settings for the device from IPv6 to IPv4 (note the IPv6 address of the DNS server is still okay in IPv4 mode as this only controls the record type requested first).

  1. On GUI go to System  >  Configuration > Device > DNS
  2. On IP Version drop-down menu select IPv4
  3. Click Update

Additional Information

None.
