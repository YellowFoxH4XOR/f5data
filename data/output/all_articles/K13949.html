Known Issue

In rare occasions, the BIG-IP ASM bd process may produce a core file when the IP Intelligence feature is enabled.

Impact

As a result, the bd process restarts and dumps a core file, and the BIG-IP ASM system may temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The bd process dumps a core file and creates files in the /var/core/ directory. The file names appear similar to the following example:

    bd_bld473_0_core_7328.gz
  • A stack trace may be logged to the /var/log/ts/bd.log file. The entries appear similar to the following examples:

    Signal 11 caught.
    Stack trace:
    frame 0: 0x2b3cf264663a
    frame 1: 0x2b3cf264670c
    frame 2: 0x48a050


    Signal 11 caught.
    Stack trace:
    frame 0: 0x2b559686663a
    frame 1: 0x2b559686670c
    frame 2: 0x48a5f
