Known Issue

Description

Microsoft Office documents may fail to open when accessed through a FirePass web portal.  

This issue occurs when all of the following conditions are met:

  • FirePass is configured with an SSL certificate that is not trusted by the client system. 
  • The documents are being opened in Microsoft Office 2010.
  • The documents are stored on a Microsoft SharePoint server.

In Office 2010, Microsoft has added additional layers of security that require an SSL certificate that is trusted by the client system in order to download office documents. 

Impact

Users are unable to access Microsoft Office documents though a FirePass wed portal.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • User receives the following error message:

    The internet address 'https://<firepass>/<path>' is not valid.

    In the previous error message, note the following:
     
    • <firepass> is the FQDN of the FirePass controller.
    • <path> is the path of the file being opened .

Status

Workaround

To work around this issue, you can either Install a certificate that is trusted by the client systems, or add the FirePass controller to the web browser trusted sites listed on the client system.
