K000091590: ASM/AdvWAF IP Exceptions when using Route Domains.

Description


An IP Exception list is used to allow IPs that would otherwise be blocked per the configuration of the security policy. These would be setup for known clean traffic. For instance a subnet used for internal traffic, internal tools that your company uses such as penetration tools, manual or automatic scanners, or web scraping tools.


Environment


  • Traffic may be being unexpectedly blocked even though there is an IP Exception for that IP address or subnet.
  • IP Intelligence, Brute Force Detection, IP Exception list, Learning Suggestions

Cause


By default when an exception list entry is created it applies only to the default Route Domain '0'.


Recommended Actions


  1. For each route Route Domain the address will use you will need to add an entry for that specific address or subnet. For example for Route Domain 1...
    1. Specific address: 192.168.1.1 255.255.255.255 would look like this... 192.168.1.1%1 255.255.255.255
    2. Subnet: 192.168.10.0 255.255.255.0 would look like this... 192.168.10.0%1 255.255.255.0
