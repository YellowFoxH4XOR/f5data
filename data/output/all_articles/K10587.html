Topic

FirePass Admin accounts can either authenticate locally or against an external authentication server. To create an account with Admin permissions that authenticates against an external authentication server, you must first create a master group, and then create a user for the master group.

Creating a Master Group

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Users: Groups: Master Groups.
  3. Click the Create New Group button.
  4. In New group name, enter a name for the group.
  5. In the Users in group drop-down menu, select Local.
  6. Select the appropriate authentication method from the Authentication Method drop-down menu.
  7. Click the Create button.
  8. Click on the Authentication tab and ensure that all necessary information has been submitted.

Creating a user with Full Access or Admin permissions

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Users: User Management.
  3. Select individual entry from the Create user accounts by drop-down menu.
  4. Click Go.
  5. In the panel on the right side of the screen, select the Master Group you have created from the drop-down menu.
  6. Click the Change button.
  7. Populate the New User information with the appropriate information for the admin account.
  8. Click Add user.
  9. To give the new user administrator Full Access, navigate to Device Management : Security : Administrative Realms.
  10. Click on the Edit link under either Full Access or Administrators.
  11. Type the name of the user account in the blank field.
  12. Click Add.

Enabling Webifyer

The newly created master group will need to have Webifyer enabled in order for the users in that group to have a link in the right side of their Webtop for the Administrative Console.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Users : Groups : Master Groups.
  3. Select the master group you created from the Master Group drop-down menu.
  4. Click the User Experience tab.
  5. Select Show both Favorites and Webifyer icons.
