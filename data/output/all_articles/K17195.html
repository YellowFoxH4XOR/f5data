Known Issue

iRules may return incorrect data when the BIG-IP configuration has multiple administrative partitions or folders that contain objects with the same name.

This issue occurs when all of the following conditions are met:

  • The configuration includes objects with the same name but in different folders or administrative partitions.
  • An iRule references one of the objects without using the fully-qualified path. For example, the iRule references pool example_pool rather than pool /Common/folder1/example_pool.

Impact

Client connections receive incorrect data or are load balanced incorrectly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • iRules may return incorrect data when the BIG-IP configuration has folders or multiple administrative partitions that contain objects with the same name which can lead to one or more of the following symptoms:
    • Client connections receive incorrect data.
    • The BIG-IP system incorrectly load balances client connections.

Workaround

To work around this issue, always specify full paths to objects referenced in iRules. For example, specify pool /Common/folder1/example_pool rather than pool example_pool.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
