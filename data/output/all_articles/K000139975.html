Description

  • You want to upgrade your BIG-IP VE software version.
  • You want to verify the appropriate image file to download. 
  • Do I need to download the ISO or OVA image file from the F5 download page?

Environment

  • BIG-IP LTM VE
  • Upgrade 

Cause

None

Recommended Actions

  • You do not need an OVA file to upgrade BIG-IP Virtual Edition.
  • The OVA file is used for new installations of BIG-IP VE, not for upgrading the software version.
  • Upgrading a standalone BIG-IP system requires a different procedure, which does not involve using an OVA file.
  • To upgrade BIG-IP Virtual Edition, you need to select the desired version and then download the corresponding ISO file for that version you intend upgrading to.
  • The specific upgrade path and planning reference can be found in the Related Content section below.
