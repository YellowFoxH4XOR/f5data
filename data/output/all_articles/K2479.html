Preventing the configuration utility from listening on a specific VLAN

To prevent the Configuration utility from listening on a specific VLAN, perform the following procedure:

  1. Log in to the command line.
  2. Create a backup of the httpd.conf file by typing the following command:

    cp /config/bigconfig/httpd.conf /config/bigconfig/httpd.conf.ORIG
  3. Using a text editor, edit the /config/bigipconfig/httpd.conf file.
  4. Locate the <IfDefine SSL> statement near the bottom of the httpd.conf file.

    For example:

    <IfDefine SSL>
    Listen 10.0.0.2:443
    Listen 192.168.1.2:443
    <VirtualHost 10.0.0.2:443 192.168.1.2:443>
  5. Remove all x.x.x.:443 statements as needed in both the Listen and VirthualHost sections, leaving only the self IP addresses you want to allow access to the Configuration utility.

    For example, if you only want to allow access from the self IP 10.0.0.2, you would remove the self IP 192.168.1.2:443 statement from the Listen and VirtualHost section, as follows:

    <IfDefine SSL>
    Listen 10.0.0.2:443
    <VirtualHost 10.0.0.2:443>
  6. Save any changes made to the httpd.conf file and close the file.
  7. To allow the changes to be loaded, restart the httpd process by typing the following command:

    bigstart restart httpd

You can test the changes by connecting to the allowed self IP address.

 

Restoring the original configuration

If you need to back and restore the original configuration, peform the following procedure:
 

  1. Log in to the command line.
  2. Restore the original httpd.conf file by typing the following command:

    cp /config/bigconfig/httpd.conf.ORIG /config/bigconfig/httpd.conf
  3. Restart the httpd process by typing the following command:

    bigstart restart httpd

Adding VLANs back to your Configuration utility interface

If you need to add VLANs back to your Configuration utility interface, perform the following procedure:
 

  1. Log in to the command line.
  2. Type the following command:
    setup
  3. Select option W - Configure web servers.
  4. Follow the instructions.
