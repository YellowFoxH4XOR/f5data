K000151677: F5OS T2 image virtual disk allocation encounters disk full error

Type
Support Solution
Published
2025-06-04
Updated
2025-07-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000151677

Description

Tenants running the T2 image when installing a new ISO image in a new hard disk partition will run into disk full error similar to the following:

[root@localhost:Active:Standalone] images # tmsh show sys software status

---------------------------------------------------------------------
Sys::Software Status
Volume  Product   Version    Build  Active    Status  Allowed Version
---------------------------------------------------------------------
HD1.1 BIG-IP 17.1.2 0.0.8 yes complete yes
HD1.2 BIG-IP 17.5.0 0.0.15 no failed (Disk full (volume group). See SOL#10636) yes

 

Environment

F5OS tenant
rSeries
Upgrading

 

Cause

1707921

 

Recommended Actions

Increase the tenant disk allocation to a value that is greater than 45G.
