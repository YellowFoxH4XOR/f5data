Description

  • You successfully logged in to NGINX Private repo, following command "docker login private-registry.nginx.com --username=<output_of_jwt_token> --password=none"
  • You now want to list all available NGINX Ingress Controller Images from the command line

Environment

  • NGINX Ingress Controller
  • Docker
  • Image
  • Licensing

Cause

  • None

Recommended Actions

  • To access NGINX repo and list image, you have to have a valid subscription for product type NGINX Ingress Controller.
  • You can access the repo using the below curl command nginx-repo.cert/key pair. With this out of the way, we would then need to focus with the JWT token itself.
                  curl https://private-registry.nginx.com/v2/nginx-ic/nginx-plus-ingress/tags/list --key nginx-repo.key --cert nginx-repo.crt | jq
