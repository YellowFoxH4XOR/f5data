Description

The BGP Error "BGP[2424]: BGP : [SOCK CB] sock_getpeer() failed (107:Transport endpoint is not connected), FD(10)"  can be seen in the /var/log/user.log or configured zebos.log files.  This error indicates a network connectivity issue.  

Environment

  • BGP  

Cause

 BGP[2424]: BGP : [SOCK CB] sock_getpeer() failed (107:Transport endpoint is not connected), FD(10) error indicates that the BGP (Border Gateway Protocol) process on your chassis or vCMP (Virtual Clustered Multiprocessing) instance is having trouble establishing or maintaining a connection with its peer.

 Here’s a breakdown of the error:

  • BGP[2424]: 
    • This part specifies the process ID of the BGP instance that is generating the error message. The number 2424 is the process ID.
  • BGP :  [SOCK CB] sock_getpeer() failed (107:Transport endpoint is not connected):
    • This indicates that there was an issue with the socket connection. The function sock_getpeer() is used to retrieve the address of the peer connected to the socket, but it failed with error code 107, which means "Transport endpoint is not connected." Essentially, it means that BGP is trying to communicate with its peer but the connection is not established.
  • FD(10): 
    • This indicates the file descriptor number associated with the socket connection.  This error typically occurs in scenarios where the BGP session is trying to establish a connection but the peer is not reachable or the connection was reset. Possible causes include network issues, configuration problems, or the peer BGP daemon not being active.

Recommended Actions

  • Ensure that the network connectivity between the two BGP peers is intact. This includes verifying the Trunks and Interfaces are up and stable.
  • Verify that the BGP configuration on both ends is correct and that they are configured to communicate with each other.
  • Check if there are any new firewall rules or security policies that might be blocking the BGP traffic.
  • Look at the logs on both BGP peers for any additional error messages that could provide more context.
  • Check the logs to verify the interfaces aren't flapping. Note: If BGP is configured on a vCMP guest, you may need to check the Host logs.
