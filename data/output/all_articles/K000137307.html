Cause

None


Recommended Actions

  • CVE-2021-39144: This issue can be mitigated by having signatures in the "Server Side Code Injection Signatures" set applied to your security policy.

Either the built-in "Server Side Code Injection Signatures" set can be applied to the policy, or a new user-defined set (filter-based) can be created with Attack Type set to "Server Side Code Injection Signatures" so this will automatically add all those relevant signatures to this set which can then be applied to your policy.


  • CVE-2023-34036: Product Dev is working on building signatures, and no ETA is available when writing this article. Tracked ID1361053
  • CVE-2023-38286: Product Dev is working on building signatures, and no ETA is available when writing this article. Tracked ID1361053

As part of mitigating CVE-2023-34036 & CVE-2023-38286, a new signature will be introduced in a future Attack Signature Update (ASU) file in the near future

You may also choose to open a new request in future and refer to the IDs listed above for an update about the readiness of the signature.
