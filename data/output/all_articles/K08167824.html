Description

When booting a physical BIG-IP device, you may see the following messages during startup:

  • insmod: error inserting '/lib/hv_vmbus.ko'
  • insmod: error inserting '/lib/hv_storvsc.ko': -1 Unknown symbol in module

Environment

  • BIG-IP appliance platform
  • Serial console output

Cause

This is a known issue tracked as Bug ID 880133. The Messages are related to Hyper-V drivers which would not be loaded on a physical device. There are scripts that determine what platform the software is being run on, and loads drivers and filesystems appropriate to the platform. These error messages appear due to the processes that run very early in the Linux boot process, before the previously mentioned scripts.

Recommended Actions

No action required as these messages can be safely ignored.

None.
