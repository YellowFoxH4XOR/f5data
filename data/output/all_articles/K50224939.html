Description

You may get the example warning logs in /var/log/ltm:

Warning generated :  apm aaa saml (/Common/TEST) 'sp-host' value is not valid: Hostname www.test.com:10000 can only contain characters [a-zA-Z0-9-._]

Environment

  • You want to specify the service port for the host in the BIG-IP APM SAML service provider config.

  • BIG-IP APM software upgrade from v12 to v13/v14/v15/v16/v17.

Cause

Bug ID 1088433

Recommended Actions

If you are not planning to change the current port config, you can leave alone the warnings.

Note: Due to the Bug ID 1088433, you can only change the port config back to the default port 443.

Additional Information

None.
