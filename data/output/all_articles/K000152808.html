K000152808: After a replacement of system controller "show system image" shows mismatch in version between system controllers

Type
Support Solution
Published
2025-07-30
Updated
2025-07-30
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.8.X, 1.8.1, 1.8.0, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000152808

Description

After an RMA and subsequent replacement of a system controller, the system controllers shows version mismatch as shown below:

# show system image
SERVICE ISO INSTALL 
NUMBER OS VERSION VERSION VERSION STATUS 
----------------------------------------------------
1 1.6.2-26579 1.6.2-26579 - success 
2 1.8.0-26321 1.8.0-26321 - success

Environment

F5OS-C

System Controllers

Replacement of System Controller

Cause

ID1993457

Recommended Actions

Reboot the newly replaced system controller one more time and determine if the "show system image" indicates that both system controllers are running the same version.

Additional Information

The issue is cosmetic.
