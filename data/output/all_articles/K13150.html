Issue

You should consider using this procedure under the following condition:

  • Resources such as Network Access, Web Application, or Application Tunnel favorites do not appear on a user's webtop, as expected.

Symptoms

As a result of some common misconfigurations, you may encounter the following symptom:

  • User does not see a link for an expected resource on their webtop after successfully authenticating to a FirePass controller.

Recommended Actions

The webtop is the user's home page when they connect to a FirePass controller by way of a web browser. The webtop contains links to the favorites that are configured for the user's master group. Some common misconfigurations can result in a favorite not being displayed to the user. Following are some steps you can take to troubleshoot a missing resource.

Procedures

When experiencing missing links to resources, you can use the following troubleshooting steps to determine the root cause:

  • Confirm that the Protected Configuration includes resource.
  • Confirm that the resource has been assigned to the user's master group.
  • Confirm that Webifyer has not been disabled.

Confirm that the Protected Configuration includes resource

After a user has successfully completed a pre-logon sequence, they enter a protected configuration. Protected configurations provide a way for you to collect a set of safety requirements from the user and assign the user resources under specified conditions. For a specific resource to appear on a user's webtop, it must have a Protected Configuration assigned to the resource. To assign a Protected Configuration to a resource, perform the following procedure:

Impact of procedure: None

  1. From the FirePass Admin console, navigate to Users: Endpoint Security: Protect Resources.
  2. Ensure that the missing resource has a Protected configuration assigned to it.
  3. If I Protected configuration has not been assigned, click the Select link for the resource that is missing from the user's webtop.
  4. Select the applicable protected endpoint configuration from the Protected configuration drop-down menu.
  5. Click the Select button.

Confirm that the resource has been assigned to the user's master group

A resource group must be assigned to the user's master group for the resource to appear on the user's webtop. To confirm that the resource group has been assigned correctly, perform the following procedure:

Impact of procedure: None

  1. From the FirePass Admin console, navigate to Users: Groups: Master Groups.
  2. Click the Group Name for the user's Master Group.
  3. Click the Resource Groups tab.

    The Resource group should be in the Selected box. If it is not, continue with this procedure.

  4. Highlight the Resource Group that contains the missing favorite in the Available box.
  5. Click the Add button to move the group to the Selected box.
  6. Click the Update button.

Confirm that Webifyer has not been disabled

The resource group that contains the missing favorite will need to have Webifyer enabled for the users' master group to have the link appear on their webtop. Webifyers are set to Beginner by default. However, if the webifyer for a specific resource group has been set to Don't Use, a webifyer icon will not be displayed. To confirm that Webifyer has not been disabled, perform the following procedure:

Impact of procedure: None

  1. From the FirePass Admin console, navigate to Users: Groups: Master Groups.
  2. Click the User Experience tab.
  3. Ensure that either the Beginner or Advanced radio button has been selected for the missing resource.
  4. Click the Update button in the lower right corner to commit any changes.
