K000134868: [F5RST: Internal error (NTLM requested abort (open error))]

Type
Support Solution
Published
2023-05-31
Updated
2023-05-31
Source

Description

Connections to a virtual server configured with an NTLM profile are reset. When taking a tcpdump the error below is shown as the RST cause on the F5 Ethernet Trailer Protocol.


[F5RST: Internal error (NTLM requested abort (open error))]

Environment

  • LTM
  • Standard virtual server
  • NTLM profile

Cause

Unknown at the time of publication.

 Recommended Actions

Remove the NTLM profile from the virtual server and add it again.

  1. Access the GUI.
  2. Go to Local Traffic ›› Virtual Servers: Virtual Server List ›› <Virtual server name>.
  3. For NTLM Conn Pool select None.
  4. Click update.
  5. Modify again the NTLM Conn Pool and select the name of your NTLM profile.
  6. Click update.
