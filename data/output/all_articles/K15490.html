Known Issue

The BIG-IP configuration may fail to load after an upgrade to version 11.5.0.

This issue occurs when the following conditions are met:

  • Your BIG-IP configuration contains a Secure Socket Layer (SSL) profile that:

    • Inherits the cert/key pair specified in the parent profile.
    • Uses a passphrase and/or chain certificate independent of the parent profile.
  • You upgrade the BIG-IP system from BIG-IP 11.4.1 or earlier, to BIG-IP 11.5.0.

If the configuration contains an SSL profile that uses the cert/key pair specified in a parent SSL profile, but is configured with a passphrase or chain certificate independent of the parent profile, the configuration fails to load after upgrading, or when attempting to load the user configuration set (UCS) file using the Traffic Management Shell (tmsh) from BIG-IP 11.4.1 or earlier.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After upgrading to BIG-IP 11.5.0, the configuration fails to load.
  • A UCS file from BIG-IP 11.4.1 or earlier fails to load on BIG-IP 11.5.0.
  • You receive an error message similar to the following example when attempting to load the configuration using the tmsh utility:

    Syntax Error:(/config/bigip.conf at line: 111) one or more configuration identifiers must be provided.

Workaround

To mitigate the issue, you can boot back to the partition that contains the earlier BIG-IP version, and then upgrade to BIG-IP 11.5.1.
