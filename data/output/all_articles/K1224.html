Topic

The BIG-IP SSL Proxy does support POPS, IMAPS, and SMTPS. Once configured, the proxy will pick up SSL/TLS traffic for the appropriate protocol on that port, decrypt it, and send it to the internal servers.

To do this, configure the SSL accelerator on the appropriate TCP port, defined as follows:

ProtocolTCP Port
IMAPS993
POP3S995
SMTPS465

Important: SMTPS is not supported when STARTTLS functionality is used, because STARTTLS does not change ports to 465 to become encrypted. Rather, STARTTLS converts the existing clear-text connection into an encrypted connection without requiring a new connection.

Note: For specific information about configuring SSL accelerator proxies, refer to the BIG-IP Reference Guide. For a complete list of TCP ports, refer to the following link: http://www.iana.org/assignments/port-numbers
