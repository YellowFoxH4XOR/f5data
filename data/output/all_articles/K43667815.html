K43667815: Unable to import ASM device to BIG-IQ with error: The discovery configuration has ''protocolIndependent'' value set to ''false'' but BIG-IQ configuration has it set to ''true''.

Description

  • Unable to import ASM configuration to BIG-IQ
  • The following error message appears on the GUI
    The discovery configuration has "protocolIndependent" value set to "false" but BIG-IQ configuration has it set to "true"

Environment

  • BIG-IQ CM
  • BIG-IP ASM
  • Discover/Import ASM device to BIG-IQ

Cause

The seen behaviour is the result of differences between policies with the same exact name potentially contained on two different devices. ASM security policy Language, case sensitivity and protocol independence can't be modified.

The discovery configuration has "protocolIndependent" value set to "false" but BIG-IQ configuration has it set to "true".

Recommended Actions

You can consider to apply one of the three following alternatives.

  • Select the BIG-IQ to overwrite the BIG-IP configuration when importing is being done.
  • Force protocolIndependent to true on ASM device.
    BIG-IP GUI: Security  ››  Application Security : Security Policies : Policies List : select Policy > General Settings > Advanced Settings > Differentiate between HTTP/WS and HTTPS/WSS URLs > Select Enabled
    Click Save
    Click Apply Policy
  • Manually Delete all conflicting policies from BIG-IQ.
