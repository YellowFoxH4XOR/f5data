Description

Upgrade to 14.1.4.x failed with an error similar to the following when loading the configuration:

err mcpd[4475]: 01070734:3: Configuration error: DB validation exception, unique constraint violation on table (ips_inspection_compl) object ID (/Common/http_server_webapp_net_attempt). A duplicate value was received for a non-primary key unique index field. DB exception text (Cannot update_indexes/checkpoint DB object, class:ips_inspection_compl status:13)

The object /Common/http_server_webapp_net_attempt does not exist in any of the configuration files.

Environment

  • After upgrade

Cause

At the time of this article's publication, the exact root cause is not known. However, this is believed to be linked to the protocol inspection update files used by AFM:

Recommended Actions

An immediate workaround is to roll back and attempt the upgrade again. This usually resolves the issue.

To determine the root cause, gather a qkview while in the broken state and open a service request with F5 Support for continued investigation.

Additional Information

This issue might happen even without AFM provisioned.
