Known Issue

This is the result of a known issue. When connecting to a FirePass Java Terminal Server favorite with a Mac client using Safari, the scroll bars do not appear and the target machine's task bar is not accessible when the following settings are configured:

  • The screen resolution is set to percent of screen or full screen
  • The target client's resolution is bigger than the Terminal Server window size

This behavior does not occur if the Mac OS X user runs Firefox.

F5 Product Development tracked this issue as CR124732 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.
