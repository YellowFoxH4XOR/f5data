Known Issue

The BIG-IP system may send SNMP traps without using the configured SNMP trap-source address.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to send SNMP traps.
  • When sending traps, the SNMP version used is v1.
  • You have configured the system to send SNMP traps with a specific trap-source address.

Impact

The trap-source address is not used when the system sends SNMP traps.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SNMP traps sent from the BIG-IP system use the trap-source address of the system management IP address.
