Topic

The FirePass controller provides a webtop experience for users based on the the User-Agent string sent from the user's browser in the HTTP header.  User-Agent strings indicate which type of browser is being used, which the FirePass maps to one of the following categories:

  • Desktop Browser
  • Mini-browser
  • I-mode phone
  • HDML/WAP 1.0 phone
  • WAP 1.1 or later phone
  • Pocket PC Browser

These categories correspond to the values in the Type drop-down menu on the Device Management: Configuration: New Browsers page. Each category will display the webtop in a format appropriate to the browser and device type.

If a user's webtop is displayed in a manner that seems incorrect for the type of device and browser, check the browser's User-Agent string to see if the string is consistent with other browsers of the type and version. The User-Agent string for each user logon is listed in the User Agent column on the Reports: Logons page. Compare the User-Agent string of any problematic users with users logging in normally with the same type and version of browser to determine if an unusual User-Agent string is being sent. Some browser-based tools allow a user to modify the User-Agent string for development and troubleshooting of web applications. In such a case, resetting the User Agent string to the default may allow for the correct webtop to be displayed.

If the User-Agent string cannot be modified or reset, you can manually map the User-Agent string of the problematic browser to the desired webtop type. To do so, perform the following procedure:

  1. Log in to the Administrative Console.
  2. Using the navigation menu in the left frame, click Device Management.
  3. Click Configuration.
  4. Click New Browsers.
  5. In the Classify new browser type section, enter the User-Agent string being sent by the problematic browser into the User-Agent field.
  6. Map the string to the correct webtop type with the Type drop-down menu.
  7. Select any other optional characteristics of the browser with the check boxes in the section.
  8. Click the Add button.
