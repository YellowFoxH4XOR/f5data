Issue

Error Message

01070979:3: The specified vlan <vlan_name> for route domain <rd_name> is in use by a self IP

In this error message, note the following:

  • <vlan_name> is the name of the VLAN for the route domain.
  • <rd_name> is the name of the route domain.

For example:

01070979:3: The specified vlan (/Common/vlan978) for route domain (/Common/rd10) is in use by a self IP

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You attempt to remove a VLAN from the configuration that has an associated self IP address.

Impact

You are unable to remove the VLAN until you first remove the association with the self IP address.

Recommended Actions

To remove the VLAN from the configuration, first ensure that no self IP addresses are associated with the VLAN.
