Description
The informational log message "The monitor probing frequency has been adjusted because more than 20 synchronous monitors were detected." which can be found in /var/log/gtm does not indicate a problem and can be safely ignored. 

Environment

  • DNS/GTM module provisioned
  • A non-zero number of DNS/GTM-based monitored objects

Cause
This log message is reported when the number of DNS/GTM monitor instances at a specific interval (in seconds) is sufficiently large that the gtmd process switches from executing per second to executing more frequently than once a second. It is normal for the gtmd process to execute more frequently than once per second and will not be the cause of any monitoring-based problems. This will occur when the number of configured monitor instances reaches the point sub-second executions are needed or when a BIG-IP with a configuration which requires sub-second executions resumes monitoring after a reboot.

Recommended Actions

No action is needed based on this informational message and it can be safely ignored. This message is reduced to debug level in 15.1.0 via ID763065 so it is no longer seen by default.

Additional Information
A very large number of DNS/GTM-based monitor instances at a specific interval can potentially cause issues however that can only occur well after the gtmd process has transitioned to sub-second executions. This specific message on it's own is not an indication of too many DNS/GTM-based monitor instances.

ID756470 was added in 15.0.0 to provide a better mechanism for monitoring this behavior and can be read about in more detail in K15894475.
