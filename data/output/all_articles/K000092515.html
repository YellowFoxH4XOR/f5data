Description

When trying to perform a password recovery via the grub menu, it does not display during boot.

Cause

The grub.conf timeout in the AWS or Azure image may be set to 0, in addition to missing other EC2 or Azure VM Serial Console requirements.

Recommended Actions

To allow the grub menu to display, refer to the sub-section that applies to your public cloud provider environment:

AWS

  • Overview: EC2 Serial Console for Linux instances - Amazon Elastic Compute Cloud
  • Instance type requirements: Instance types - Amazon Elastic Compute Cloud
  • User permission requirements: Configure access to the EC2 Serial Console - Amazon Elastic Compute Cloud

Azure

  • Overview: Azure Serial Console for Linux
  • Serial console requirements: Enable and disable the Azure Serial Console

Impact of procedure: Modifying the grub timeout and adding additional parameters to the grub.conf will have no impact on traffic processing capabilities of the BIG-IP itself. Your BIG-IP system will have a delayed boot equal to the timeout setting you configure. The example below configures the timeout to be 25 seconds.

 

  1. Login to your BIG-IP using SSH
  2. Enter the bash shell
  3. From bash perform the following:
    • vi $(grub_open)
    • change: timeout=0 to timeout=25
    • add two entries below the timeout= line modified above:
      • serial --speed=115200
      • terminal serial
    • modify kernel line ttyS0 section:
      • from: console=ttyS0
      • to: console=ttyS0,115200n8
    • :wq
    • grub_close

After performing the above, your BIG-IP will now permit you to access the grub menu in the EC2 or Azure VM Serial Console. The file being modified by grub_open and grub_close is /var/run/grub.conf which is updated after rebooting. 

 

Additional Information

With the configuration added to the grub.conf file the grub menu will display at boot time. To access this menu, connect to the EC2 or Azure VM Serial Console for your BIG-IP instance and then from your SSH or GUI session reboot the BIG-IP. No special key presses are required for the menu to display, it will show on its own. Once the menu appears it will start a countdown time based on what you configured earlier. If there is no interaction by the user, the BIG-IP will boot to the active volume automatically. An example of what the grub menu looks like is below.
