Description

BIG-IP is showing Array status: degraded warning message.

Running tmsh show /sys raid command will show a hard disk in undefined status. Refer to the example below.

tmsh show /sys raid

------------------------------------------------------------------------------
Sys::Raid::Bay
Bay  Shelf  Name  Serial Number          Array Member  Array Status
------------------------------------------------------------------------------
1    1      HD2   WD-WWAW11111111        no            undefined
2    1      HD1   WD-WCWW99999999        yes           ok

------------------------------------------------------------------------------
Sys::Raid::Disk
Name  Serial Number            Array   Array Status  Model
                               Member
------------------------------------------------------------------------------
CF1   CD222222222000000L01     no      undefined     SILICONSYSTEMS INC 8GB
HD1   WD-WCWW99999999          yes     ok            ATA     WDC WD1000FFFZ-0
HD2   WD-WWAW11111111          no      undefined     ATA     WDC WD1000FFFX-0

Environment

  • BIG-IP
  • Array status: degraded warning
  • Hard disk array status is undefined

Cause

The issue is with the disk and it's RAID array. You will need to perform a logical rebuild of the RAID array.

Recommended Actions

Perform a logical rebuild of the RAID array using K12756.

Additional Information

None.
