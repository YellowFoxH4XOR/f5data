Known Issue

This is the result of a known issue. When a Linux or Mac OS X user applies Firefox to connect to the FirePass device and needs to install the VPN client components, the installation will fail. This issue occurs only when the Firefox profile name includes a space. The connecting users will be able to successfully install the F5 plugin, but the installation process will subsequently fail. 

F5 Networks Product Development is tracking this issue as ID 294236 (formerly CR134566) for FirePass version 7.0.0, and as ID 317692 (formerly CR134566-1) for FirePass version 6.1.0.

This issue was fixed for ID 317692 (formerly CR134566-1) in cumulative hotfix HF-610-3-1 for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by changing the name of the Firefox profile to not include a space.

Note: For more information about configuring Firefox profile names, refer to the Managing profiles knowledge base article on the Firefox Support site. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://support.mozilla.com/en-US/kb/managing+profiles
