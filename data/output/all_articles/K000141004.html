Description

Manually adding instance to CM after deployed but cannot ssh

 

Environment

BIG-IP NEXT

 

Cause

N/A

 

Recommended Actions

1) From BIG-IP NEXT CM run the command:

curl -sk -X PUT https://<replaceIP>:5443/api/v1/me -u admin:oldpassword -H 'Content-Type: application/json' -d '{"newPassword": "password", "currentPassword": "oldpassword"}'| jq.

 

2) And finally add the instance to the CM by using the username admin and the new password.
