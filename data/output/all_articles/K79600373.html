Description

On BIG-IP there are two possible ways to override values returned by DHCP server (for instance 'domain-name', 'domain-name-servers', etc.) when DHCP is enabled on BIG-IP mgmt interface:
  1. Use 'supersede-options' to push user defined settings to the dhclient itself. For example, to add 192.0.2.100 as user defined DNS server on BIG-IP run: tmsh modify sys management-dhcp sys-mgmt-dhcp-config supersede-options add { domain-name-servers { value add { 192.0.2.100 } } }
  2. Use 'request-options' to not request user defined settings from dhclient at all.  As no value comes from dhclient, MCPD configured value won't be overwritten. For example, to remove 'domain-name-servers' entries from the request-options run: tmsh modify sys management-dhcp sys-mgmt-dhcp-config request-options delete { domain-name-servers }
Note: 'request-options' is more useful from 15.x onwards because of the fix for ID744740.

However on BIG-IP running software version 15.1.0 or 16.0.0, it’s not possible to override 'domain-name' and 'domain-name-servers' values returned by DHCP server using the methods listed above. This happens due to the following known issues:
  • ID939489 - BIG-IP doesn't persist the DNS and domain name settings on reboot

Environment

BIG-IP running 15.1.0 or 16.0.0 with DHCP enabled on the management interface.

Cause

It’s not possible to override the 'domain-name' and 'domain-name-servers' values returned by DHCP server.
 

Recommended actions

None
