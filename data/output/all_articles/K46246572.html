K46246572: BIG-IQ Devices may show a memory usage graph that is trending up prior to a crash

Type
Support Solution
Published
2021-12-17
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K46246572

Description

BIG-IQ appears to having increasing memory usage.

  • When viewing the graphs in Ihealth or noting memory usage in the command line.
  • BIG-IQ memory usage increases
  • Device will eventually reach a point where it will restart on its own.

Environment

Relevant environmental factors specific to the topic

  • Overall Memory usage
  • BIG-IQ CM and DCD 8.x, prior to 8.1.0.1

Cause

This is due to a known issue.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Periodically manually restart the BIG-IQ
  2. Upgrade to version 8.1.0.1 or above.

Additional Information

Bug ID 903905: BIG-IQ or BIG-IP devices experience a service disruption during certain circumstances
