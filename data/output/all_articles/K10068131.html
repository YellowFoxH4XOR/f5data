Topic

You can use this release candidate1 iApp template to configure the BIG-IP APM system to act as a Security Assertion Markup Language (SAML) Identity Provider for commonly-used Software as a Service (SaaS) applications. This iApp template enables users to configure the BIG-IP APM system as an Identity Provider (IdP) to perform single sign-on (SSO) for the following SaaS applications: Office 365, Salesforce, Workday, Amazon Web Services, Concur, Service Now, Jive, Wombat, Zendesk, WebEx, Box, and Google Apps.

1Release Candidate iApp templates are created, tested, and supported by F5. However, the templates differ from the official F5-supported iApps (those found in the root directory of the iApp package) in the following ways:

  • While Release Candidate iApp templates have been tested by F5 engineers, the templates have not yet passed the extensive automated test suite required to achieve the official F5-supported iApp status.
  • Release Candidate iApp templates are supported by F5 only until an official F5-supported iApp template is provided. Once an official F5-supported iApp template is available, any previous Release Candidate versions of the iApp template will no longer be supported. The official F5-supported iApp templates are supported according to K8986: F5 product support policies.
  • Release Candidate iApp templates are not archived. Once an official F5-supported iApp template is provided, the Release Candidate version is removed from the iApp package.
