Known Issue

This is the result of a known issue. Importing an access profile may fail with an error message that appears similar to the following example:

Import Error: BIGpipe parsing error (/tmp/import-29768.conf Line 88): 012e0022:3: The requested value ({ expression) is invalid (show | <resource assign rule list> | none) [add | delete]) for 'rules' in 'agent resource assign'

This error message occurs because parts of the configuration file are renamed during the export process, and the new names cannot be read properly during the import process.

F5 Product Development tracked this issue as ID 337829 and it was fixed in BIG-IP APM version 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP APM version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
