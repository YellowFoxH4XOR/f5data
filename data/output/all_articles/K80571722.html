Description

Attempting to reactivate a license on the Activate F5 Product page is resulting in the following error message:

Unable to grant license key: Error 51081, Previous Activation Dossier cannot be decrypted - The stored dossier cannot be decrypted.

Environment

  • Licensing
  • BIG-IP 
  • ELA License (Enterprise License Agreement)
  • Virtual Edition
  • Hardware

Cause

Inbound dossier did not get saved in the license server during the initial activation of the base registration key. During license reactivation, the current inbound dossier is compared to the one locked on to the license to make sure it is not a different instance. If the previous dossier isn’t there, it fails.

Recommended Actions

  1. Contact F5 Support to request an "Allow Move" to be done on the license.
  2. Once the license has been released, do a license reactivation using the Manual Activation method. Refer to the steps below:

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility using an account with the administrator role.
  2. Navigate to System > License and select Re-activate
  3. Select Manual and click Next.
  4. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  5. On the F5 Licensing Tools page, select Activate F5 product registration key.
  6. Paste the dossier into the Enter Your Dossier box, and then select Next.
    1. The F5 Product Licensing page produces your license.
  7. Copy the license and paste it into the License box in the Configuration utility.
  8. Select Next and wait for configuration to reload.
