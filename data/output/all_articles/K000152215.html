K000152215: Behaviour of TMM with regard to existing connections when BIG-IP is shutdown

Type

Published

Source

Description

This article explains Big-IP's standard behaviour for existing TCP connections when it is issued a "shutdown" command by an admin.

Big-IP does not reset existing connections upon TMM shutdown by default, for example if using the “tmsh shutdown” or “shutdown -h now” commands in bash/CLI.

 

Environment

BIG-IP LTM

 

Cause

This is normal behaviour for TMM, to allow for things like connection mirroring to work correctly in the event that TMM is shutdown or restarted due to an internal error.

If there was an error state in TMM, we could not then rely on TMM to perform further actions such as sending resets to all active connections anyway, so it makes sense to keep the default shutdown behaviour for TMM the same as the error state behaviour, even if connection mirroring is not in use or the box is not in a HA pair.

None.
