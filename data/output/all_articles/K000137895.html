Description

This article discusses possible reasons an admin may see a directory called RPMS.save in /var/config/rest/iapps/ on a BIG-IP device.

 

Environment

LTM

 

Cause

A temporary directory called RPMS.save is automatically created in /var/config/rest/iapps/ during the UCS creation process, and is automatically deleted at the end of that process under normal circumstances.
However, if the UCS creation process is interrupted or does not complete successfully, it is possible that this RPMS.save directory gets left behind on the box - in this case it can add to the size of future UCSs created on the box, as the existing contents of the RPMS.save directory may be added to the UCS as well.
It should not have any other negative effects (apart from potentially increasing the size of future UCSs created on the box).
 

Recommended Actions

Since an existing RPMS.save directory can unnecessarily add to the size of newly-created UCSs on that box, it is recommended that if there is an unwanted RPMS.save directory present in /var/config/rest/iapps/ , that it should be deleted (or at least moved to a different location if you wish to analyse its contents).
