Topic

What you'll learn

Before the BIG-IP can process SSL traffic, you need to define the cipher string that the system uses to negotiate security settings with a client or server system. To avoid the issues that come with typing a raw cipher string on the system, you can use cipher rules and cipher groups. Cipher rules and cipher groups help you instruct the BIG-IP system which cipher suites to include and exclude, and the system builds the cipher string for you.

This video introduces you to the cipher rules and cipher groups features of BIG-IP 13.0 and later.
