Description

BIG-IP can terminate the SSL handshake with the following critical messages reported within /var/log/ltm:
01260000:2: Profile /<partition-name>/<client-ssl-profile-name>: Forward Proxy is enabled without a license

Additionally, you can also see the following error reported by tmm within /var/log/ltm:
01260009:4: Connection error: hud_ssl_handler:910: invalid profile (40)

Environment

  • BIG-IP: 12.x - 16.x
  • Client SSL profile configured with SSL Forward Proxy

Cause

These errors indicate that the device is lacking license for SSL Forward Proxy feature. 

Recommended Actions

Please contact your F5 Sales Representative or F5 Technical Support to get confirmation and address the licensing issue.

Additional Information
None.
