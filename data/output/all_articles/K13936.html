Known Issue

The BIG-IP system incorrectly allows you to create packet filter rule and rate shaping objects outside of the /Common partition.

This issue occurs when the following condition is met:

  • You create a packet filter rule or rate shaping object in a partition other than the /Common partition using either the Configuration utility or tmsh.

Impact

When upgrading to a later release, the BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After you upgrade and boot into the upgraded BIG-IP volume, an error message that appears similar to the following example displays in the Configuration utility:

    The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.

  • After you upgrade and boot into the upgraded BIG-IP volume, the following error messages are displayed in the /var/log/ltm file:

    err mcpd[<pid>]: 01070734:3: Configuration error: Rate-shaping configuration items must exist in /Common.
    err tmsh[<pid>]: 01420006:3: Loading configuration process failed.

Workaround

To work around this issue, you need to change the partition on which the packet filter rule or rate shaping object resides, to the /Common partition. You can do this by deleting and re-creating each object in the /Common partition on version 11.0.0, or by manually editing the bigip.conf configuration file on all other 11.x versions:

Deleting or re-creating the packet filter / rate shaping objects (11.0.0)

If you are running BIG-IP 11.0.0, and have created packet filter / rate shaping objects in a partition other than the /Common partition, you can delete and re-create the objects. To do so, perform the following steps:

Impact of workaround: None

  1. Log in to the Configuration utility as an administrative user.
  2. From the Partition menu, select the partition from which you want to delete objects.
  3. On the Network tab, navigate to the packet filter or rate shaping sections.
  4. Open the object you want to delete, and make a note of all the configuration options.
  5. Click Delete.
  6. Repeat the previous steps for all objects.
  7. From the Partition menu, select the /Common partition.
  8. Re-create the deleted objects.

Manually changing the packet filter to specify the /Common partition

If you created the packet filter rule or rate shaping objects in version 11.0.0 in a partition other than /Common and then upgraded to a later version of the BIG-IP system, you must manually change the objects to specify the /Common partition. To do so, perform the following procedure.

Note: You may use this procedure on version 11.0.0 instead of using the previously-listed deleting/recreating procedure.

Impact of workaround: None

  1. Log in to the BIG-IP command line shell as the root.
  2. Edit the /config/bigip.conf file using a text editor such as vi or pico.
  3. Find all instances of packet filter and rate shaping definitions, and edit the partition name to /Common.

    Packet filter definitions all start with the text 'net packet-filter', and rate-shaping definitions all start with 'net rate-shaping class'.

    For example:

    Take the following partition name of a packet filter:

    net packet-filter /Partition1/packetfilter1 {
    action continue
    order 5
    vlan /Common/external
    }

    To manually modify it, you would change it to:

    net packet-filter /Common/packetfilter1 {
    action continue
    order 5
    vlan /Common/external
    }

    Take the following rate-shaping object:

    net rate-shaping class /Partition1/test_rate_shape {
    ceiling 1kbps
    drop-policy /Common/fred
    max-burst 1k
    queue /Common/pfifo
    rate 1kbps
    }

    To manually modify it, you would change it to:

    rate-shaping class /Common/test_rate_shape {
    ceiling 1kbps
    drop-policy /Common/fred
    max-burst 1k
    queue /Common/pfifo
    rate 1kbps
    }

  4. Manually re-load the BIG-IP configuration by typing the following command:

    tmsh load sys config
