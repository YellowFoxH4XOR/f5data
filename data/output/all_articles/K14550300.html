Known Issue

When you have configured Access Groups, and you upgrade the BIG-IQ system from 5.3.0 to 5.4.0, the upgrade may fail.

This issue occurs when all of the following conditions are met:

  • You are using the BIG-IQ system to manage multiple BIG-IP APM devices.
  • The BIG-IQ system is configured to use Access Groups.
  • You remove a BIG-IP APM device from one device group and add it to another device group.
  • You created an Access Group snapshot while the BIG-IP APM device belonged to the initial device group.
  • You upgrade the BIG-IQ system before creating a new or updated Access Group snapshot.

Impact

You are unable to upgrade the BIG-IQ system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice the BIG-IQ upgrade fails to complete.
  • In the /var/log/tokuupgrade.log file, you notice an error message similar to the following example:

Workaround

To work around this issue, you can delete all of the Access Group snapshots before you perform the upgrade. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ 5.3.0 user interface.
  2. At the top of the page, click the Deployment tab.
  3. Navigate to Snapshots > Access.
  4. Select the box to the left of Name.
  5. To delete all of the snapshots, click Delete.
  6. Perform the BIG-IQ upgrade to 5.4.0.
