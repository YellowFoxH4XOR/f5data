K000141489: Chrome Browser Fails to Load Bot Defense Profiles After Upgrade to Version 17.1.x or 17.5.x

Type
Support Solution
Published
2024-10-17
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141489

Description

The Chrome browser is unable to load the 'Security  ››  Bot Defense : Bot Defense Profiles, <<Profile Name>>' properties page following a software upgrade to version 17.1.x or 17.5.x. The issue does not occur when using earlier releases.

Environment

  • ASM (17.1.x / 17.5.x)
  • Bot Defense
  • Chrome Web Browser

Cause

Defect ID: 1469393

Recommended Actions

  • Use Chrome's incognito mode or a different browser as a temporary solution..
  • Reach out to F5 support requesting an engineering hotfix (EHF) associated with Defect ID 1469393.
