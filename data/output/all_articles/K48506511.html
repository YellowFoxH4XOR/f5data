Issue

Error Message

sod[<PID>]: 010c0063:5: Waiting for Mcpd without a response. Try again...

In this error message, note the following:

  • <PID> is the process ID for the sod process

For example:

notice sod[5410]: 010c0063:5: Waiting for Mcpd without a response. Try again...

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The sod process has not established a connection with the mcpd process.

Impact

The error message is generated once during every connection attempt to the mcpd process until a successful connection is established. The sod process will not operate until this connection is established.

Recommended Actions

  • Review the /var/log/ltm log file for messages such as licensing or configuration that may be related to the mcpd process not responding.
  • Restart the mcpd process by typing the following command from the command line:

    bigstart restart mcpd

  • If restarting the mcpd process is not successful, contact F5 Technical Support.
