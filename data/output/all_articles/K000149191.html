Description

While trying to use the option to update F5 packages through GUI:

System  ››  Software Management : Update Check

Or from tmsh:

tmsh run util updatecheck -d

There is no response from update server

Already checked and verify:

  • Connectivity to Internet
  • CURL Check from CLI to callhome.f5.com
  • DNS
  • FW traffic Accepted

Environment

  • BIG IP
  • Updatecheck (callhome.f5.com)

Cause

Sys DB variable  - proxy.host modified to a non-default

Recommended Actions

Run the following commands to set the DV variable to Defaults:

#tmsh modify sys db proxy.host reset-to-default

#tmsh save sys config

#tmsh run util updatecheck -d
