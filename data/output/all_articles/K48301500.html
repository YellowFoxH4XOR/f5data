K48301500: iQuery connection fails even after adding using gtm_add with no connectivity issues

Type
Support Solution
Published
2021-08-19
Updated
2023-02-21
Applies to
  • VIPRION Platforms
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP GTM
Source
https://my.f5.com/manage/s/article/K48301500

Description

After renewing the certificate on the BIG-IP GTM/DNS, the iQuery connection doesn't come up.

  • There are no connectivity issues between the GTM/DNS devices.
  • gtm_add fails with"iQuery connection to 10.10.10.10 failed. Is big3d running? Is tcp port 4353 access allowed?"
  • big3d is running on both BIG-IP GTM/DNS devices.

Environment

  • BIG-IP GTM
  • Device certificates were renewed recently

Cause

This can happen if there are multiple certificates are present for the same device. Like new certificates were added but the old certificates were not removed.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. On both devices, navigate in GUI to - DNS ›  GSLB : Servers : Trusted Server Certificates.
  2. Make sure there is only one certificate for each device and remove all old/expired certificates.
  3. Once deleted, the iQuery connection should come back automatically.
  4. This can be verified using the command below:
    # tmsh show gtm iquery
