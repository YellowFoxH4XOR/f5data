Issue

When the wide IP reviews the topology statements, it only finds the names of the pools and the source address of the client, but does not find the corresponding pool names. Since there is no applicable topology statement, it defaults to round robin. The following two options can correct this issue.

 

Solution 1

Change the topology statements to reference pool names.

For example:

Korea_pool        192.13.97.0/24            30
Korea_pool         192.14.68.0/24            30
American_pool       192.14.93.0/24            30
American_pool       192.14.85.0/24            30

The wide IP will now be able to find the applicable pool names and the topology statements will be honored.

Solution 2

Change the wide IP so that it contains only one pool that contains all of the servers, regardless of location, and then change the preferred load balancing method to topology.

Note: For specific instructions, refer to the 3-DNS Controller manual.

Incoming queries will go through the pool, which will review the topology statements. Because the pools now know the server IP addresses, the topology statements will be honored.
