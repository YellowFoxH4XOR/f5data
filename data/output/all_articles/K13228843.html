Issue

Error Message

notice tmsh[<PID>]: 01420004:5: <script_log_message>

In this error message, note the following:

  • <PID> is the process ID for the tmsh process.
  • <script_log_message> is a user-defined message logged using Tool Command Language (Tcl) script commands.

For example:

notice tmsh[18935]: 01420004:5: "Created pool pool_http with members member1"

Message Location

You may encounter this message in the following locations, depending on your configuration:

  • The /var/log/ltm file
  • The command line terminal screen

Description

This message occurs when all of the following conditions are met:

  • You have configured a Tcl script to log messages.
  • The script is subsequently run.

Using the script component within the cli TMOS Shell (tmsh) module, you can generate custom logs with the tmsh::log command. For example, to log the creation of a new pool and its pool members to the /var/log/ltm file using a cli script, you can add code to the script, similar to the following example:

tmsh::create ltm pool $poolname members add \{ $members \}
tmsh::log_dest file
tmsh::log_level notice
tmsh::log "Created pool $poolname with members $members"

Impact

There is no impact; this is a user-defined message.

Recommended Actions

None
