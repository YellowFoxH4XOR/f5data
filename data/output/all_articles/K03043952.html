Description

Unable to log in to the BIG-IP Configuration Utility, getting Access forbidden! Error 403 error

a log message similar to the one below can be seen in /var/log/httpd/httpd_errors log:

Nov 26 16:40:31 bigip1.example.com err httpd[31593]: [authz_core:error] [pid 31593] [client 172.18.204.196:57764] AH01630: client denied by server configuration: proxy:ajp://localhost:8009/tmui/tmui/system/settings/redirect.jsp, referer: https://bigip1.example.com

Environment

  • BIG-IP

Cause

Access to the BIG-IP Configuration Utility has been restricted to certain IP addresses/IP ranges only.

To view the list of allowed IP addresses, use the command tmsh list sys httpd allow. In the below sample output, access to the Configuration Utility is only allowed from 10.201.146.67

sys httpd {
    allow { 10.201.146.67 }
}

Recommended Actions

Modify the httpd allow list to include the IP addresses that require access to the Configuration Utility. You can either add an IP address to the current allowed list or replace the current list with a new list.

To add:

 # tmsh modify /sys httpd allow add { <IP address or IP address range> }

Example: This command will add 172.18.204.196 to the current allowed list

 # tmsh modify /sys httpd allow add { 172.18.204.196 }


To replace:

 # tmsh modify /sys httpd allow replace-all-with { <IP address or IP address range> }
 
Example: This command will replace the current allowed list with 172.18.204.196

 # tmsh modify /sys httpd allow replace-all-with { 172.18.204.196 }
 
 
Once the desired modifications to the httpd allow list has been made, make sure to save the changes by running this command:

 # tmsh save sys config
