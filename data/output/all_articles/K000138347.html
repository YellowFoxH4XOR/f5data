K000138347: BIG-IP URI builder used in rewrite profile adds ‘none’ for missing parts to create a complete looking URI in the GUI

Source
https://my.f5.com/manage/s/article/K000138347

Description

After upgrade to recent versions, you may notice addition of ‘none://none//none/’ or ‘none://none/’ in the URI path of the existing rewrite profile. This is because the Rule builder attempts to create a full URI path making up for the missing components such as ‘scheme’ or ‘host’ even though the manual suggests it is not required to have a combination of scheme+host+path and previous versions would allow you to create a path-only rule in the rewrite profile.

https://clouddocs.f5.com/cli/tmsh-reference/v16/modules/ltm/ltm_profile_rewrite.html

This is the result of a regression being introduced in the recent versions and F5 is tracking it under Bug ID1321713. 

Environment

  • BIG-IP
  • Rewrite Profile
  • URI builder


Cause

This is due to a known Bug ID1321713 . 

Recommended Actions

There is no application service impact. The issue is only affecting the GUI display. If you wish to get it fixed, please feel free to create a support ticket and request Engineering Hotfix for this ID.
