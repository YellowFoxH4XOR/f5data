Known Issue

This is the result of a known issue. If you configure the Windows antivirus checker in a pre-logon sequence, Windows clients running Norton 360 version 2.0 may fail the antivirus check. This issue occurs when the following three conditions are met:

  • The client system is running Windows Vista or later versions of the Windows operating systems
  • The user's Windows account does not have local administrator privileges
  • The pre-logon sequence requires that real-time protection (RTP) is enabled

    Note: RTP corresponds to the Monitor is running action in the pre-logon sequence.

The FirePass Windows antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT, Inc. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT is aware of the issues described in this Solution and is working on a resolution. Once a resolution is available from OPSWAT, F5 Networks will issue a hotfix to address this issue.

F5 Networks Product Development is tracking this issue as CR116639.

Workaround

Users can work around this issue by upgrading to Norton 360 version 3.0. Norton 360 version 3.0 is not affected by the issue described in this Solution.
