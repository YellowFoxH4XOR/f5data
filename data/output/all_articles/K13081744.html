Description

After upgrading one (1) BIG-IP GTM / BIG-IP DNS you will notice the following symptoms:

  • GTM service are not functioning correctly.
  • Server objects (like wide IP, Servers, Pool) from BIG-IP GTM / BIG-IP DNS are marked down.
  • Monitor status show no reply from big3d.

Environment

  • Not all BIG-IP GTM / BIG-IP DNS have been upgraded
  • BIG-IP GSLB Server objects running on another software version are marked down

Cause

gtmd and big3d needs to run on the same software version to work correctly. When all BIG-IP GTM / BIG-IP DNS are not running on the same software version, this will cause big3d not communicate correctly and mark the server objects down.

Recommended Actions

You will need to upgrade all the remaining BIG-IP GTM / BIG-IP DNS to the same software version.

Additional Information

None

Updating the big3d process on all BIG-IP devices

To facilitate proper iQuery communication in your environment, you should be aware of the following big3d version management information:

  • F5 recommends that all devices communicating over iQuery run the same big3d version.

    When installing big3d on devices in the iQuery mesh, install the big3d agent from the BIG-IP DNS (formerly BIG-IP GTM) or Enterprise Management system that is running the latest software version to the other devices in the iQuery mesh. For example, if the devices in the iQuery mesh are running different BIG-IP software versions, install the big3d agent from the device running the newest BIG-IP version to the other devices. This ensures that a device in the mesh does not run a big3d Sversion that is older than its installed software version.

  • BIG-IP DNS synchronization group communication

    Sync group members should run the same big3d version.

  • BIG-IP DNS/BIG-IP GTM communication

    Monitored BIG-IP systems must run the same or newer big3d version as the BIG-IP DNS/BIG-IP GTM devices that are monitoring them.

To ensure that all the BIG-IP device of the DNS synchronization group are running the latest big3d version, you can use the big3d_install command-line utility.
