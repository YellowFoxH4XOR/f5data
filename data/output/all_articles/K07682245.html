[ERROR][01 Mar 2022 15:12:00 CET][ConfigException] ERROR: Object /Common/1.1.1.1 does not exist, URI http://localhost:8100/shared/storage?key=cm/adc-core/working-config/ltm/snat-translation/44bc545e-d0e0-3ded-8da0-00e46b48c926; reason com.f5.rest.workers.storage.KeyNotFoundException: Get document for key: cm/adc-core/working-config/ltm/snat-translation/44bc545e-d0e0-3ded-8da0-00e46b48c926 returned nothing

BIG IQ Configuration > Local Traffic > SNAT Pool contains SNAT Pool  which does not exist on BIG-IP and  you can not delete is via GUI

Environment

  • BIG-IQ Centralized Management 
  • BIG-IP LTM import of configuration
  • Not Existing SNAT pool on LTM
  • Virtual Server Template in Application > Application Templates >Service Catalog Templates referring to SNAT Object 

Cause

Unknown

Recommended Actions

Identify Application template  in Service Catalog containing reference to snatpool, remove it and reimport configuration using following procedure
  1. Verify in Configuration > LOCAL TRAFFIC > SNAT POOL which pool contains  object referred in logs  ( example /Common/1.1.1.1)
  2. After finding name click on SNAT POOL which was referred in error message. 
  3. Write down ID from the  URL  for snatpool object  https://10.10.10.1/ui/configuration/ltm/snatPools/view/<ID>
    EXAMPLE:  
    When clicking on snatpool test-snatpool   browser opens https://10.10.10.1/ui/configuration/ltm/snatPools/view/be19a82c-16f6-34e4-9a7b-4f4298f3d6cc
  4.  Go to Application tab > Application Templates >  Service Catalog Templates
  5. Identify Virtual server template which refers to SNATPOOL
  6. Delete template
  7. In CLI remove  Snatpool  using ID collected in point 3
    restcurl -u admin:a -X DELETE /mgmt/cm/adc-core/working-config/ltm/snatpool/<id>" 
    Example:
    restcurl -u admin:a -X DELETE /mgmt/cm/adc-core/working-config/ltm/snatpool/be19a82c-16f6-34e4-9a7b-4f4298f3d6cc" 
  8. Rediscover and reimport  of affected BIG-IP
