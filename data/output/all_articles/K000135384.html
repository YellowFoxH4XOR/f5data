K000135384: Scheduled termination of a session using cron job

Type
Support Solution
Published
2023-09-06
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000135384

Description

If you would like to terminate a session from the LTM connection table at a specific time daily, weekly or yearly manner, this can be achieved using a cron job.

Environment

  • Scheduling a cron job
  • SSH
  • Bash script

Cause

None

Recommended Actions

  1. SSH into the device move into directory "/etc/cron.daily" in bash.
  2. Using any text editor like nano,vi or vim create a bash file.
  3. Create a file with the name "<filename>.sh". command: #nano sessionkill.sh
  4. Paste the bash script you need to run in file.

A sample bash script for deleting all client session to a virtual server :

#!/bin/bash
tmsh delete sys connection cs-server-addr <virtual server ip>
echo "Daily cron job executed for" $HOSTNAME "at" $(date) "virtual server <virtual server ip> all client session deleted" > /var/tmp/Cronjob_output.txt
  1. Save the above file and making an executable of the file. command : #chmod +x sessionkill.sh
  2. Go to the crontab & do a list first to see the existing cron jobs running. command: #crontab -l
  3. Should see some jobs for disk monitors check etc.
  4. Edit the cron job. command: #crontab -e
A sample cron job schedule would look like below:
0 1 * * * /usr/bin/bash /etc/cron.daily/sessionkill.sh
Note: the above job will run daily at 1AM.
