K000160100: Changed the port groups on all the 10/25 ports to 10 and the IPs on the tenants became unpingable

Published
2026-02-20

  • F5OS-A: 1.5.4, 1.5.3, 1.8.0
Source
https://my.f5.com/manage/s/article/K000160100

Description

After changing all 10/25GbE ports on an F5 rSeries system to 10GbE port groups, tenant interfaces became unreachable (unpingable).

 

Environment

  • F5 rSeries (BIG-IP) platform, r5000, r10000, or r12000-series appliance
  • F5OS version 1.8.0, 1.8.1
  • Multiple interfaces configured in LAGs (Link Aggregation Groups)
  • Port groups changed from 25GbE to 10GbE on all 10/25GbE ports

 

Cause

Bug ID 1601985

 

Answer/Recommended Actions

  1. Upgrade F5OS to the latest available version to resolve the port group/interface transmission issue.
  2. After changing port group configurations, perform a system reboot and reconfigure any affected protocols (such as LAG/LACP or LLDP) as needed.
  3. Monitor interface status and verify connectivity after making port group changes.
