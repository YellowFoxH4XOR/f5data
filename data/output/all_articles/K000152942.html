K000152942: Browser-based Network Access connection fails with message "Navigation to this webpage was canceled" after upgrade to version 17.1.2

Type
Support Solution
Published
2025-08-30
Updated
2025-08-30
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000152942

Description

Following the BIG-IP software upgrade to version 17.1.2, users are unable to establish a browser-based VPN session with a pop-up window displaying the message:

 "Navigation to this webpage was canceled"

Establishing the VPN connection using the Edge Client functions as expected.

Endpoint Inspection is enabled in the access policy.

Environment

  • BIG-IP APM
  • Browser-based VPN
  • Endpoint Inspection
  • Software upgrade

Cause

ID1818461 

Skipping the endpoint inspection prevents the policy from granting network access.

Recommended Actions

  • Ensure users complete the Endpoint Inspection during login.
  • If endpoint inspection is not strictly required, remove these checks from Access Policy configuration.
  • If skipping the endpoint inspection is necessary for your environment, upgrade to the BIG-IP version that includes a fix.
