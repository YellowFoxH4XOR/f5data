Description

  • After upgrading to BIG-IP 13 or later, issues loading configuration
  • Error message: Artifact resolution URI contains 'https' protocol, but SSL profile is not configured in SAML IdP Connector

Environment

  • BIG-IP APM 13.x or later
  • SAML Artifact Resolution aka ARS

Cause

BZID 647004: Upgrade to 13.0 may result in config load failure with error 'Artifact resolution URI contains 'https' protocol, but SSL profile is not configured in SAML IdP Connector

Recommended Actions

To resolve this issue you will need to edit the bigip.conf file and manually add in serverside ssl profiles for each of the IdP connectors listed as follows:

    serverssl-profile-name /Common/serverssl

  1. Open your bigip.conf file in the editor of your choice
     
  2. Search and do the following for each of the following IdP connectors
     
  3. Find each connector and add in the following line:

    apm aaa saml-idp-connector /Common/idp_connector {
            artifact-resolution-service-port 443
            artifact-resolution-service-url https://ars.example.com/broker/ars
            entity-id https://idp.example.com
            serverssl-profile-name /Common/serverssl     <<<------!!! ADD THIS LINE
            idp-certificate idp_saml_idp_metadata_cert.crt
            single-logout-response-uri https://idp.example.com/saml/idp/profile/post/slr
            single-logout-uri https://idp.example.com/saml/idp/profile/post/sls
            sso-uri https://idp.example.com/saml/idp/profile/redirectorpost/sso
        }
     
  4. Save the file with the updated configuration
     
  5. Verify the configuration with the following command:
    tmsh load sys config verify 
     
  6. If there are no futher errors, load the configuration:
    tmsh load sys config
