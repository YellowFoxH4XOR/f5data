Topic

You should consider using these procedures under the following condition:

  • You want to enable debug logging when troubleshooting BIND DNS configurations.

Description

When troubleshooting BIND DNS configurations, it may be helpful to temporarily increase the logging verbosity for the named and zrd services.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the BIG-IP system.

Procedures

  • Enabling debug logging for the named and zrd services
  • Disabling debug logging and returning to the default log levels for the named and zrd services

Enabling debug logging for the named and zrd services

Impact of procedure: Verbose debug logging over time may result in an exhaustion of disk space. Debug level messages for the BIND DNS configuration will now log to the /var/log/daemon.log file, and debug level messages for the ZoneRunner configuration will now log to the /var/log/gtm file. You should only enable debug logging while actively troubleshooting BIND DNS issues. You should disable debug logging after you have collected the desired information.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Set the logging level for the zrd service to debug by typing the following command:

    modify /sys db log.zrd.level value debug

  3. Configure syslog to log daemon debug level messages by typing the following command:

    modify /sys syslog daemon-from debug

  4. Save the configuration by typing the following command:

    save /sys config

  5. If BIG-IP DNS (formerly known as BIG-IP GTM) is licensed and provisioned on the system, continue to step 6. If BIG-IP DNS is not licensed and provisioned on the system, skip the steps 6-13.
  6. Log in to the Configuration utility.
  7. Navigate to DNS > Zones > ZoneRunner > named Configuration.

    Note: For BIG-IP 10.x through 11.4.1, navigate to Global Traffic > ZoneRunner > Named Configuration.

  8. In the named Options field, locate the logging stanza.

    For example:

    logging {
    channel logfile {
    syslog daemon;
    severity error;
    print-category yes;
    print-severity yes;
    print-time yes;
    };

  9. Change the severity level to debug.

    For example:

    logging {
       channel logfile {
       syslog daemon;
       severity debug;
       print-category yes;
       print-severity yes;
       print-time yes;
    };

  10. Click Update.
  11. Return to tmsh.
  12. Restart the named service by typing the following command:

    restart /sys service named

  13. Restart the zrd service by typing the following command:

    restart /sys service zrd

    Note: If you want to log information about individual DNS queries, you can enable this functionality, as needed, by typing one of the following commands from the command line:

    To enable query logging, type the following command:

    rndc querylog on

    To disable query logging, type the following command:

    rndc querylog off

Debug level messages for the BIND DNS configuration are now logged to the /var/log/daemon.log file.

Disabling debug logging and returning to the default log levels for the named and zrd services

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Set the logging level for the zrd service to notice by typing the following command:

    modify /sys db log.zrd.level value notice

  3. Configure syslog to log daemon notice level messages by typing the following command:

    modify /sys syslog daemon-from notice

  4. Save the configuration by typing the following command:

    save /sys config

  5. If BIG-IP DNS is licensed and provisioned on the system, continue to step 6. If BIG-IP DNS  is not licensed and provisioned on the system, skip the steps 6-13.
  6. Log in to the Configuration utility.
  7. Navigate to DNS > Zones > ZoneRunner > named Configuration.

    Note: For BIG-IP 10.x through 11.4.1, navigate to Global Traffic > ZoneRunner > Named Configuration.

  8. In the named Options field, locate the logging stanza.

    For example:

    logging {
    channel logfile {
    syslog daemon;
    severity debug;
    print-category yes;
    print-severity yes;
    print-time yes;
    };

  9. Change the severity level to error.

    For example:

    logging {
       channel logfile {
       syslog daemon;
       severity error;
       print-category yes;
       print-severity yes;
       print-time yes;
    };

  10. Click Update.
  11. Return to tmsh.
  12. Restart the named service by typing the following command:

    restart /sys service named

  13. Restart the zrd service by typing the following command:

    restart /sys service zrd

Messages for the BIND DNS configuration are now logged at their default levels.
