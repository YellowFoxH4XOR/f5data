Description

The device enters into a reboot loop, with the following message logged into the /var/log/ltm file. 
For Example:  LTM log for the VLAN fail-safe event:

warning overdog[1234]: 01140029:4: HA vlan_fs /Common/vlan_xx fails action is reboot.
crit overdog[1234]: 01140102:2: Overdog daemon requests reboot.

Environment

  • BIG-IP
  • Fail-safe is enabled, like VLAN fail-safe or gateway fail-safe.
  • VLAN or Gateway pool is down.

Cause

If VLAN/Gateway failsafe is configured and the network environment causes the VLAN/gateway pool down, trigger the fail-safe action, and the action is a reboot.

Recommended Actions

You may consider either of the below to fix the issue. 
  1. Fix the network environment, make sure the VLAN or the gateway pool is up. Which will not trigger the failsafe condition. 
  2. If you cannot fix the network environment and to avoid reboot loop, when the device boot up, before it reboots, login to the device, check and modify the fail-safe configuration via GUI / tmsh before the device reboots.

Additional Information

Please review the guide about the fail-safe feature, for example:
https://techdocs.f5.com/en-us/bigip-14-1-0/big-ip-system-essentials-14-1-0/high-availability-fail-safe.html
