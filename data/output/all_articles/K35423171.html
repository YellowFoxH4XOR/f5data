Known Issue

The BIG-IP AFM system applies an access control list (ACL) rule policy to a standby device.

This issue occurs when all of the following conditions are met:

  • You have deployed an active-standby configuration.
  • You have configured a virtual server with Connection Mirroring enabled.
  • You have configured an ACL policy with an ACL rule that has a schedule attached, and during periods of transition, a schedule may cause the system to enforce or expire the ACL rule.

Impact

The system unexpectedly generates an ACL rule that hits logs from the standby device, which you do not want to happen. There is no impact on traffic handling.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system logs and reports the ACL log hits on the standby device. The standby device does not need to handle or report hits for the ACL policy.
