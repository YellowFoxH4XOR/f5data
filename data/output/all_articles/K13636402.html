Description
To clear TLS/SSL statistics from the tmsh is desired
 

Environment

  • TLS/SSL statistics

Cause
None

Recommended Actions

To clear statistics in all profiles, run the next command:
# tmsh reset-stats /ltm profile [client-ssl|server-ssl] 

To do it for a particular profile:
# tmsh reset-stats /ltm profile [client-ssl|server-ssl] [profile name]
