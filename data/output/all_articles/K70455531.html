Issue

Error Message

01070822:3: Access Denied: <message>

In this error message, note the following:

  • <message> provides specific details of the access failure

For example:

01070822:3: Access Denied: user (Test) does not have access to partition (PartA)

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The BIG-IP Configuration utility
  • The BIG-IP command line
Description

This message occurs when one of the following conditions is met:

  • A user attempts to read, modify, or delete a configuration without authorization based on partition settings.
  • A user attempts to perform an action that is not allowed for the user's assigned role.

Impact

The user is prevented from performing unauthorized actions.

Recommended Actions

You can provide authorization for the user by modifying the partition or role settings. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative effect on your system.
  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to System > Users.
  3. Select the name of the affected user.
  4. In the Partition Access section, select the current role and partition assignment, then select Edit.
  5. Modify the Role and Partition settings to provide access for the user.
  6. Select Add.
  7. Modify the Terminal Access setting as needed.
  8. Select Update.
