Description

Auto prompt on keeping nginx config file in current state while upgrading on Ubuntu OS

Environment

  • Nginx Plus on Ubuntu OS

Cause

While upgrading Nginx Plus on Ubuntu OS the apt tool will send a prompt on keeping nginx config file in current state.
When upgrade process is used by automation it will fail due to prompt not being inputed.
To bypass this prompt more parameters must be used for upgrade command.

Recommended Actions

Here is a sample of command with required parameters to keep config in current state.

sudo -E apt-get --yes -o Dpkg::Options::="--force-confdef" -o Dpkg::Options::="--force-confold" upgrade nginx-plus

Additional Information

Ubuntu OS documentation and/or Ubuntu support channel can be used.
