K9018: Error message: The private key of the machine certificate is not verified.

Topic

If you enable the Windows machine certificate checker in a pre-logon sentence, users may receive an error message similar to the following example on the logon denied page:

The private key of the machine certificate is not verified.

This message occurs when one of the following two conditions are met:

  • The private key associated with the machine certificate is not installed on the client system.
  • The user does not have the necessary privileges to access the private key associated with the machine certificate.

To resolve the first condition, install the machine certificate private key on the client system. To resolve the second condition, refer to the workaround section of K7866: Private key verification and configuration for the Windows machine certificate checker pre-logon inspector.
