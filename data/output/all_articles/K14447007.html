K14447007: Configuration objects are missing after Software Upgrade

Type
Support Solution
Published
2022-01-03
Updated
2025-01-14
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K14447007

Description

Some objects are missing after a recent software upgrade.

  • Other objects are present and working fine.
  • A pool may be missing a monitor, Virtual Servers might restore previous configuration.

Environment

  • BIG-IP
  • Software upgrade.
  • Boot from another volume

Cause

  • Due to long time difference between software installation date and new volume activation date and while activating the new Boot Location, the "Install Configuration" option wasn't selected. So all the new configuration addition or modification done after installation will be lost if activation is done after some time without selecting the install configuration to yes.

Recommended Actions

Boot the device from old partition and boot the device with new volume again while selecting the Install Configuration option to 'yes'  and the Source Volume for configuration installation.

Additional Information

By default BIG IP loads the latest configuration into new volume during image installation, and it will boot with the loaded configuration while activating the new volume if the install configuration option is not selected. So if the activation is not done immediately after the installation and configuration changes has been performed during this time, then BIG IP will load with preloaded(loaded at the time of installation) configuration.
