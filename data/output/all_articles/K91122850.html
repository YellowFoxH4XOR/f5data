Known Issue

When you create resource records, you should treat the ZoneRunner utility reverse zones as case insensitive.

This issue occurs when the following condition is met:

  • By navigating to DNS > Zones > ZoneRunner > Resource Record List > Create > New Resource Record in the Configuration utility, you create a reverse zone with capital letters using the ZoneRunner utility.

    For example:

    10.10.10.IN-ADDR.ARPA.
    11.10.10.IN-ADDR.Arpa.
    12.10.10.in-addr.ARPA.

Impact

You cannot create a PTR resource record for the created reverse zones.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you create a reverse zone in the ZoneRunner utility that ends with case variations other than .arpa, such as .ARPA, the BIG-IP system does not treat that zone as a reverse zone.
  • When you create a new resource record for a zone, the PTR is not available from the Type menu.

Workaround

To work around this issue, you can create reverse zones that end with .arpa, in that exact lowercase style.
