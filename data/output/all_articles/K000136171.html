Description

  • ASM policy block status is different from the active unit and standby unit
  • ASM policy settings are different from the active unit and standby unit

Environment

  • BIG-IP ASM

Cause

An ASM policy consists of an entry in the bigip.conf file, when a policy is created and syncs the configuration this is created also in the peer, but some settings like enforcement mode could be different.

 

i.e.

A transparent policy created in the active unit will be created as blocked in the standby unit.

 

The reason for this is because ASM settings are stored in MySQL databases, this is what ASM synchronization manages, and replicates the database between devices.

 

 Recommended Actions

Follow the steps in K12200102: Enabling Application Security Synchronization on a device group. to have ASM synchronization working accordingly.
