Topic

You should consider using this procedure under the following condition:

  • You want to modify the CAPTCHA response page templates for the DOSL7, Brute Force, or Bot Defense features.

Description

You can modify the CAPTCHA response page templates for the following features: DOSL7 (layer 7 denial-of-service), Brute Force, and Bot Defense.

By default, the CAPTCHA response page includes text, a CAPTCHA image, and an audio token that the system sends during a suspected security event. You can change the appearance and behavior of the CAPTCHA page by modifying the HTML, text or the appropriate tokens. The available tokens are the following:

DOS L7 tokensBrute Force tokensBot Defense tokens
%DOSL7.captcha.support_id%%ASM.captcha.support_id%%BOTDEFENSE.captcha.support_id%
%DOSL7.captcha.image%%ASM.captcha.image%%BOTDEFENSE.captcha.image%
%DOSL7.captcha.change%%ASM.captcha.change%%BOTDEFENSE.captcha.change%
%DOSL7.captcha.audio%%ASM.captcha.audio%%BOTDEFENSE.captcha.audio%
%DOSL7.captcha.solution%%ASM.captcha.solution%%BOTDEFENSE.captcha.solution%
%DOSL7.captcha.submit%%ASM.captcha.submit%%BOTDEFENSE.captcha.submit%

For example, to change the position or remove the audio option from the DOSL7 CAPTCHA page, edit the page and change or remove the following token: %DOSL7.captcha.audio%.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the Configuration utility.

Procedures

  • Modifying the CAPTCHA response page template for the DOSL7 feature
  • Modifying the CAPTCHA response page template for the Brute Force feature
  • Modifying the CAPTCHA response page template for the Bot Defense feature

Modifying the CAPTCHA response page template for the DOSL7 feature

For the DOSL7 feature, you can modify the CAPTCHA page the system sends:

  • When it challenges users with the first CAPTCHA response.
  • To users after they fail the first CAPTCHA response.

To modify the CAPTCHA response pages users see during DoS events, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Configuration utility.
  2. Go to Security > DoS Protection > Protection Profiles.
  3. Select the DoS profile you want, or select Create to create a new DoS profile.
  4. Under Application Security, select General Settings.
  5. In CAPTCHA Response, select Edit, and do one or both of the following:
    • To change the first CAPTCHA response page users see during a DoS event, in the First Response Type list, select Custom, and then, in the box, make the changes you want.
    • To change the failure CAPTCHA response page users see during a DoS event, in the Failure Response Type list, select Custom, and then, in the box, make the changes you want.
  6. Select Show to preview the changes to the CAPTCHA response page.
  7. Select Update, or select Finished if you created a new profile.

Modifying the CAPTCHA response page template for the Brute Force feature

For the Brute Force feature, you can modify the CAPTCHA page the system sends:

  • When it challenges users with the first CAPTCHA response.
  • To users after they fail the first CAPTCHA response.

To modify the CAPTCHA response page template for the Brute Force feature, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. Select the security policy name.
  4. Under Security Policy Configuration, select Response and Blocking Pages.
  5. Do one or both of the following:
    • To change the CAPTCHA response page users see for brute force events:
      1. In the CAPTCHA section, in the Response Type list, select Custom Response.
      2. Select Response Body and, in the box, make the changes you want.
    • To change the failure CAPTCHA response page users see for brute force events:
      1. In the CAPTCHA Fail section, in the Response Type list, select Custom Response.
      2. Select Response Body and, in the box, make the changes you want.
  6. Select the CAPTCHA response body preview icon ([ ]) to preview the changes to the CAPTCHA response page.
  7. Select Save.
  8. Select Apply Policy.

Modifying the CAPTCHA response page template for the Bot Defense feature

For the Bot Defense feature, you can modify the CAPTCHA page the system sends:

  • When it challenges users with the first CAPTCHA response.
  • To users after they fail the first CAPTCHA response.

To modify the CAPTCHA response page template for the Bot Defense feature, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Configuration utility.
  2. Go to Security > Bot Defense > Bot Defense Profiles.
  3. Select the bot defense profile name or select Create to create a new bot defense profile.
  4. Under Bot Profile Configuration, select General Settings.
  5. Under Response and Blocking Pages, do one or both of the following:
    • To change the first CAPTCHA response page users see during a bot event, in First CAPTCHA Response, select Custom, and then make your changes in the box that displays.
    • To change the failure CAPTCHA response page users see during a bot event, in Failure CAPTCHA Response, select Custom, and then make your changes in the box that displays.
  6. Select Response Preview to preview the changes to the CAPTCHA response page.
  7. Select Save.
