Topic

You can use the Dynamic Sessions in URL option to remove session information from the originally requested URI. This option prevents BIG-IP ASM from flagging each request as a new web object when it is the same web object with session information included.

Removing session information from the URI

The following three examples demonstrate how you can use the Dynamic Sessions in URL option to remove session information from the URI:

Example 1

In this example, you will be altering the following URL:

http://auction.f5demo.com/sell.php/any_text/END1/blah/END?param1=value1

  • To remove /any_text/END1/blah/END from the example URI and leave the /sell.php web object, use the following regular expression:

    /any_text(.*)END

  • To remove /any_text/END1 from the example URI and leave the /sell.php1/blah/END web object, use the following regular expression:

    /any_text(.*?)END

Example 2

In this example, you will be altering the following URL:

http://auction.f5demo.com/forum.jsp;jsessionid=12345678901234567890123456789012

  • To remove ;jsessionid=12345678901234567890123456789012 from the URI and leave the /forum.jsp web object, use the following regular expression:

    ;jsessionid=.{32}

Example 3

In this example, you will be altering the following URL:

http://auction.f5demo.com/sell.php/any_text/END?param1=value1

  • To remove /any_text/ from the URL and leave the /sell.phpEND?param1=value1 web object, use the following regular expression:

    (?<=sell.php).+(?=END)

  • To remove /any_text/ from the URL and leave the web object /sell.phpEND?param1=value1, use the following regular expression:

    (?<=sell.php).*(?=END)

Note: You can also use a look-around regular expression that contains a look-ahead and a look-behind to filter out the dynamic session information (any_text) in the example URL.
