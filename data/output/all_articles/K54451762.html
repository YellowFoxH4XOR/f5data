K54451762: Disk limit exceeded when adding another module to Azure BIG-IP

Type
Support Solution
Published
2019-11-14
Updated
2025-02-06
Applies to
  • Public Cloud
  • BIG-IP
  • BIG-IP LTM: 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.1.0
  • Microsoft Azure
Source
https://my.f5.com/manage/s/article/K54451762

Description

After deploying a BIG-IP in Azure and trying to to provision an additional module, you receive the error: 

  • Disk limit exceeded. 44238 MB are required to provision these modules, but only 25115 MB are available.

Environment

  • BIG-IP in Azure
  • Adding a second  or third module

Cause

By default the templates for BIG-IP in Azure have a 78GB for disk size. 

Recommended Actions

  1. Shutdown the BIG-IP instance
  2. Increase disk size within the Azure configuration for the BIG-IP.
  3. Power on the BIG-IP Instance
  4. Follow this article K14952: Extending disk space on BIG-IP VE for more details on how to extend the diskspace in the BIG-IP Instance.
