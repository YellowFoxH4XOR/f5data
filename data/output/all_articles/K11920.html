Known Issue

This is the result of a known issue. If you are accessing a URL protected by Oracle Access Manager (OAM) and the URL is listed as protected by OAM, BIG-IP APM may still grant access. This issue is due to a rare timing issue between BIG-IP APM and an OAM server, which results in access being granted to the URL.

F5 Product Development tracked this issue as ID 226848 (formerly CR142261) and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue was fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1 for BIG-IP version 10.2.0. You may download this hotfix or a later version of the hotfix from the F5  Downloads site.
