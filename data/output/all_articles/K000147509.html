K000147509: Can Secondary DNS modify Primary DNS records?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-11
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147509

What Happened?

  • Your F5® Distributed Cloud Primary DNS servers contain all relevant resource records and handle DNS queries for your  domain
  • You want to know if your Primary DNS records can be modified from your F5® Distributed Cloud
    Secondary DNS

Environment

  • F5® Distributed Cloud Secondary DNS

Resolution/Answer

  • No, Secondary DNS cannot modify or manipulate Primary DNS records.
  • Your Secondary DNS servers contain zone file copies that are read-only
  • They receive pertinent information from a primary server in a communication process known as a zone transfer
  • If you want to be sure that no one can tamper with your zones, Domain Name System Security Extensions (DNSSEC) is the answer
