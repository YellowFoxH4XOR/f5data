Known Issue

This is the result of a known issue. When using the ARX CLI copy command to copy a file to an NFS mount, if the copy is aborted, the ARX CLI may become unresponsive and the ARX exports may become unavailable. As a result, new client mount attempts will fail with an error message that appears similar to the following example:

mount: RPC: timed out

F5 Product Development tracked this issue as ID 38462 and it was fixed in ARX 5.1.7. For information about upgrading, refer to the ARX release notes.

This issue was fixed in hotfix release ARX 5.1.5 HF3 (build 11972). Customers affected by this issue may download this hotfix or a later version of the hotfix from the F5 Downloads site.
