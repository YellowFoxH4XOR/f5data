Description

Getting the above error when making automation calls

  • Internal error, can't load folder or nested folder
  • running 'tmsh show running-config' gives mcpd error
  • errors logged in LTM logs

Environment

Relevant environmental factors specific to the topic

  • BIG-IP V13.1
  • Multiple partitions exist
  • Discrepancy between running config and config files

Cause

The cause looks to be some corruption in the MCPD database. Specific cause is unknown

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Check config files for errors using 'tmsh load sys config verify'
  2. Force MCPD reload as per K13030

Additional Information

K13030: Forcing the mcpd process to reload the BIG-IP configuration
