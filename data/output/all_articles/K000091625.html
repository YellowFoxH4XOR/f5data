K000091625: Modifying Port Lockdown will lost custom open ports

Type
Support Solution
Published
2022-06-15
Updated
2022-06-23
Source
https://my.f5.com/manage/s/article/K000091625

Description

When change port lockdown setting from Allow custom(include Default) to Allow custom, the previous configured open ports are not open anymore. Only manually delete them and re-enable them can make those ports open again.



Environment

  • BIG-IP v15.1.x


Cause

BUG ID 1113181 : TMM deletes too many ports from a selfip's allow list when transitioning from "Allow Custom (Include Default)" to "Allow Custom".



 Recommended Actions


  1. You can work around this issue by temporarily setting the affected Self-IP to "Allow None" and then again to "Allow Custom", specifying your desired custom list of ports and protocols.
  2. You can work around this issue by temporarily setting Port Lockdown to "Allow All" first, and then set it to "Allow Custom", specifying your desired custom list of ports and protocols.
