K000152891: Kerberos authentication using AES 256-bit encryption on BIG-IP APM may fail

Type
Support Solution
Published
2025-08-06
Updated
2025-08-06
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP APM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000152891

Description

Kerberos authentication using AES 256-bit encryption on BIG-IP APM may fail with the following error in the logs:

GSS-API error gss_accept_sec_context: 00000 : Request ticket server HTTP/example.local.com@DOMAIN not found in keytab (ticket kvno 7)

This error indicates that the requested Kerberos principal was not found in the keytab file, often due to a mismatch between the ticket and keytab configuration.

Environment

  • Product: BIG-IP APM
  • Kerberos authentication using a keytab file
  • AES 256-bit encryption enabled for the service account in Active Directory

Cause

The issue occurs when the domain portion of the principal specified in the ktpass command is entered in lowercase letters (e.g., @domain.com). For AES encryption to function correctly, this domain must be specified in uppercase (e.g., @DOMAIN.COM). Using lowercase causes incompatibility with AES and results in authentication failure.

Recommended Actions

When generating a keytab file with ktpass, always specify the domain portion of the principal in uppercase. For example:

ktpass -out c:\f5.keytab -princ HTTP/example.com@DOMAIN.COM

Ensure that "This account supports Kerberos AES 256 bit encryption" is enabled for the service account in Active Directory.
