Known Issue

Importing more than 2048 keys to a FIPS card fails.

This issue occurs when one of the following conditions is met:

  • The system has converted more than 2048 normal keys to a FIPS security-type.
  • You have created more than 2048 FIPS keys in a high availability (HA) setup. The standby BIG-IP system experiences an error.

Impact

Depending on the condition, as a result of the error on the standby device, either the conversion operation fails or leads to a configuration synchronization (ConfigSync) failure.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Importing more than 2048 keys to the on-board Cavium FIPS HSM card fails with the following error message:

    private f5km_fips_get_keys failed: -18 

  • In the /var/log/ltm log file, you observe an error message similar to the following example:

    01420006:3: private fips_find_key failed: 183 "HSM Error: Response buffer size is small, allocate more
