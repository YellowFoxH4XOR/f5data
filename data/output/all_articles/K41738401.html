Description

When exporting a large amount of Web Application Security Event Logs from the BIG-IQ at the same time, the BIG-IQ fail with the following error message:

The system returned an unexpected error (413 Request Entity Too Large)

This issue does not happen when exporting a smaller amount of event logs (less than 1800 events).

To export the Web Application Security Event Logs on the BIG-IQ, you will need to navigate to:
Monitoring > EVENTS > Web Application Security > Event Logs > Events

Environment

  • BIG-IQ
  • BIG-IP ASM
  • Web Application Security Event Logs from BIG-IQ
  • Exporting more than 1800 event logs

Cause

This issue is related to the limitation of the BIG-IQ's webd (nginx) process. When this limitation has been reached, you will not be able to export more event logs.

Recommended Actions

Since this issue is related to the BIG-IQ export limitation, you will need to fragment the event logs before exporting. Limit the event logs to 1800 events per export.

There is no options or workaround to export all of the event logs at the same time.

Additional Information

To increase the export limit for the Web Application Security Event Logs from the BIG-IQ, you can follow the following steps.
Note: This will increase exporting more than 1800 events but you will not be able to export all events at the same time if there are too many events.

  • Increase the client_max_body_size in webd.conf
  • Export event logs via REST API
Increase the client_max_body_size in webd.conf
  1. Login to the BIG-IQ CM Command Line.
     
  2. Make a backup copy of the webd.conf
    cp /etc/webd/webd.conf /etc/webd/webd.conf.mybackup
    Important: Making a backup of the webd.conf is required to revert the changes if or when needed
     
  3. Edit /etc/webd/webd.conf
    vi /etc/webd/webd.conf
     
  4. Under http context, search for client_max_body_size 10M; and increase the size from 10M to 20M.
     
  5. Restart webd
    bigstart restart webd
     
  6. This change will allow you to export up to 1950 event logs.
    Important: Even though you can increase the client_max_body_size to more than 20M but it might have a negative impact to your BIG-IQ.
Export event logs via REST API
You can use REST API to export the logs to a JSON format. From the JSON format, you can convert it to CSV or XLS format.
  1. Login to the BIG-IQ CM Command Line.
     
  2. Turn on HTTP basic authentication (K43725273).
    set-basic-auth  on
     
  3. Use curl command to get the first 50 records.
    curl https://localhost/mgmt/cm/shared/es/logiq/asmindex/_search -X POST -d '{  "from":0, "size":50,"sort":{ "date_time":"desc"}}' -k -u admin:admin | jq .
    Note: admin:admin is the BIG-IQ GUI username and password. Please change this according to your BIG-IQ settings.
     
  4. The next 50 records use the following command.
    curl https://localhost/mgmt/cm/shared/es/logiq/asmindex/_search -X POST -d '{  "from":50, "size":50,"sort":{ "date_time":"desc"}}' -k -u admin:admin | jq .
    Note: the "from" value in this curl command has changed from 0 to 50 indicating the starting point of the record to export.
     
  5. To export more records, change the "size" value accordingly.
     
  6. Convert the JSON output to CSV or XLS format as needed.
    Note: F5 does not have any recommendation of third party tools to convert the JSON output to CSV nor XLS format.
     
  7. Turn off HTTP basic authentication after you done using the REST API command.
    set-basic-auth off
