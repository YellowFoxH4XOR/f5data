Known Issue

Large numbers of application security policies can exhaust XML/JSON processing memory.

This issue occurs when one of the following conditions is met:

  • Your BIG-IP ASM system is configured with more than 255 security policies that were created using the policy builder's Fundamental option.
  • Your BIG-IP ASM system is configured with more than 255 security policies that use an XML security profile.

Impact

XML traffic is not processed and requests may be blocked.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/asm file, you observe error messages that appear similar to the following example:

    emerg perl[<pid>]: 01310003:0: ASM out of memory error: event code X112 Exceeded maximum memory assigned for XML/JSON processing

  • In the /var/log/ts/bd.log file, you observe an error message that appears similar to the following example:

    BD_XML|ERR |<date and time>|<pid>|xml_validation.cpp:0113|Cannot allocate 24064 more bytes for XML parser. current memory size 1999981913 (in bytes)

  • When configured in the application security policy blocking settings, legitimate XML requests are blocked with an XML_MALFORMED violation.
