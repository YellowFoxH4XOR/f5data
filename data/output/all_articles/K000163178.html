K000163178: BIG-IQ show "Only one task can be created at a time" error while renewing the F5 SSL certificates for LBaaS automation

Support Solution
Published

Applies to

Source
https://my.f5.com/manage/s/article/K000163178

Description

BIG-IQ Centralized Management certificate-renewal automation fails when multiple certificate-management requests are submitted concurrently or too closely together. Errors may occur while updating the SSL key or certificate working-configuration object before deployment to managed BIG-IP LTM systems.

Example errors include:

400: "Only one task can be created at a time."

task /mgmt/cm/adc-core/tasks/certificate-management/<task-id> returned status=FAILED

Unable to PATCH SSL Key object.

command: ADD_KEY

progress: "Updating SSL Key config object"

Environment

  • BIG-IQ Centralized Management certificate-management automation.
  • Rundeck or another external automation system submitting certificate-management API requests.
  • Multiple client SSL certificates associated with the same virtual server.
  • Certificate renewal operations involving SSL key and certificate working-configuration objects.
  • Automation that submits multiple certificate requests during the same job or within a very short interval.
  • LaBaaS

Cause

The automation submits multiple certificate-management requests before the previous BIG-IQ Centralized Management task has completed.

BIG-IQ Centralized Management permits only one certificate-management task to be created at a time. When several requests are submitted in rapid succession, the requests overlap. This can produce the Only one task can be created at a time error and cause multiple certificate tasks to fail at different processing stages.
