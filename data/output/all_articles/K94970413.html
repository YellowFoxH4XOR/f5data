Description
External users are connecting to internal resources by the help of the BIG-IP APM VPN.
And the internal applications are using ADFS as the identity providers.
As such, APM can be configured to perform SSO against ADFS.

Environment

  • You're using BIG-IP APM;
  • The APM configuration is configured usage of Kerberos SSO.
  • The SSO is performed against Microsoft ADFS.

Cause
The ADFS service may require additional configuration to agree on performing Kerberos based authentication.

Recommended Actions

Please follow the steps as described:

  • in the following document: Configure browsers to use Windows Integrated Authentication (WIA) with AD FS

  • in the following paragraph: "Change WIASupportedUserAgent settings"
