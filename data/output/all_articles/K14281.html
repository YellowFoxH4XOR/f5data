Topic

The directory that is used as the primary reference directory for the ARX system is called the master directory.

Description

The master directory is the directory used for CIFS activity. The system identifies the master directory as the first directory to respond to a Find_First call to the ARX system during import.

For example, when a client attempts to access the shares through the ARX VIP, a Query_Path_Info call is made, and the ARX VIP responds with the ACLs that are associated with the master directory.

If you review the permissions for files in the imported directories directly, you may notice that the directory permissions are different than what the ARX VIP displays. The permissions might indicate no access, but the user might have full access for a file in that directory, or the permissions might indicate access, but the user might get Access Denied messages when opening a file in that directory.

Mismatched permissions happen when attributes are not the same across multiple imported shares, and the ARX feature sync-attributes is not specified. When the sync attributes is specified, the master directory synchronizes all directory occurrences.

Note: NFS-only managed volumes do not use a master directory for access control, because F5 uses only the root user to connect, instead of establishing a session using the user credentials.

Recommendations

You can control the location of the master directory by adjusting the share’s import priority before the shares have been imported. If you want to find the location of the master directory or change its location, refer to K14280: Locating and modifying the ARX master directory.
