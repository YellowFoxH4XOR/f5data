Description

  • While explicit proxy HTTP profile is in use, HTTP_STATCODE is not present in the logs
  • Requests sends to 2 VSs (test1 and test2)
    • VS test1 has explicit http profile
    • VS test2 has regular http profile
  • Request to test1 shows no CODE in /var/log/syslog:
    Jul 20 17:53:27 192.168.172.25 '2021-07-20' '10:53:27' '-0700' '/Common/vstest1' '30' '10.10.172.88' '' '' 'CONNECT' '' 'www.f5.com:443' '' 'curl/7.58.0' '192.168.172.25' '172.16.144.77' '0' '' ''
  • Request to test2 shows 200 CODE in /var/log/syslog:
    Jul 20 17:53:56 192.168.172.25 '2021-07-20' '10:53:56' '-0700' '/Common/vstest2' '360' '10.10.172.88' '' '200' 'CONNECT' '' 'www.f5.com:443' '' 'curl/7.58.0' '10.10.172.88' '10.10.172.50' '0' '' ''

Environment

  • VSs got: "Request Logging Profile" configured
  • In the "Request Logging Profile" we have : Response Settings > Template > '$HTTP_STATCODE'
  • Request Logging Profile is configured to send HSL to syslog server

Cause

Bug ID 1034953

Recommended Actions

None.

Additional Information

This will occur only when using explicit proxy in HTTP profile.
