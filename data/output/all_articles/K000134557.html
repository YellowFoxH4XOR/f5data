K000134557: How to display Virtual Servers/Pools/Nodes and availability in CLI.

Type
Support Solution
Published
2023-05-11
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000134557

Description

You want to display Virtual Servers/Pools/Nodes and availability in CLI.

Environment

BIG-IP

Cause

None

Recommended Actions

 

Please use the following command:

tmsh -c 'cd /; show ltm virtual detail recursive' | grep -E "Ltm::Virtual|Ltm::Pool|Ltm::Node|Availability"
 

Example of the output:
 

Ltm::Virtual Server: Common/http2

Availability : unknown

| Ltm::Virtual Address: Common/10.10.10.245 (10.10.10.245)

| Availability : unknown

Ltm::Virtual Server: Common/https_vs

Availability : unknown

| Ltm::Virtual Address: Common/10.171.140.70 (10.171.140.70)

| Availability : unknown

Ltm::Virtual Server: Common/test

Availability : unknown

Ltm::Virtual Server: Common/testBIGIQ-VS

Availability : offline

| Ltm::Pool: Common/test

| Availability : offline

| Ltm::Pool Member: Common/10.10.10.10:80

| Availability : offline

| Ltm::Node: Common/10.10.10.10 (10.10.10.10)

| Availability : unknown

| Ltm::Virtual Address: Common/10.10.20.123 (10.10.20.123)

| Availability : offline
