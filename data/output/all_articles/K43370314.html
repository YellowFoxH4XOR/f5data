Issue

Error Message

01260000:2: Profile <profile_name>: <error_message>

In this error message, note the following:

  • <profile_name> is the name of the Secure Sockets Layer (SSL) profile.
  • <error_message> is the error message reason detail.

For example:

01260000:2: Profile ssl_example: clientssl profile has no key/cert pair

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system is unable to load an SSL profile due to a missing or corrupted SSL key or certificate, SSL Certificate Revocation List (CRL), or Certificate Authority (CA) file.
  • The SSL Forward Proxy feature is enabled without appropriate licensing.
  • The SSL profile is configured with a cipher string that resulted in no available ciphers.
  • The BIG-IP system is unable to access a FIPS protected SSL key.
  • The Online Certificate Status Protocol (OCSP) configuration is corrupt or invalid.

Impact

A virtual server referencing the affected SSL profile may fail to process SSL traffic.

Recommended Actions

The error message should offer the relevant details to further troubleshoot and resolve the issue.

For example, if the error message mentions "clientssl profile has no key/cert pair," you should determine which SSL key or certificate the SSL profile is unable to load and ensure that:
  • The SSL profile is configured to reference the appropriate SSL key and certificate files.
  • The files are imported into the BIG-IP system.
