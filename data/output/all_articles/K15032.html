Topic

You should consider using these procedures under the following conditions:

  • You want to view the access sessions license limit for the BIG-IP APM system.
  • You want to view the User Connectivity License (CCU) limit for the BIG-IP APM system.

Description

The BIG-IP APM system is licensed for cumulative user access in two distinct methods.

  • The access session license value represents the total concurrent user sessions for the BIG-IP APM system.
  • The number of VPN/CCUs represents the total concurrent connectivity sessions based on a specific set of user access profiles using SSL VPN, port forwarding, and reverse proxies.

For more information, refer to K13267: BIG-IP APM connectivity license use.

Note: To view the number of concurrent access sessions or connectivity sessions on the BIG-IP APM system, refer to K19131297: Viewing the number of concurrent access sessions and connectivity sessions on the BIG-IP APM system.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to the TMOS Shel (tmsh) on the BIG-IP APM system.

Procedures

The BIG-IP APM /config/bigip.license file contains the license limits of access sessions and VPN/CCUs for the system. You can display these values using tmsh or view the license file directly. To do so, perform one of the following procedures:

  • Displaying the license limits for total concurrent access sessions and VPN/CCUs using tmsh (12.x and later)
  • Displaying the license limits for total concurrent access sessions and VPN/CCUs using the tmsh utility (11.x and earlier)

Displaying the license limits for total concurrent access sessions and VPN/CCUs using tmsh (BIG-IP 12.x and later)

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. To determine the license limit for all access sessions, enter the following command:

    tmsh show /apm license

    The command output appears similar to the following example:

    --------------------------------------------
    Global Access License Details:
    --------------------------------------------
     total access sessions: 2.5K
     current active sessions: 0
     current established sessions: 0
     access sessions threshold percent: 75
     total connectivity sessions: 500
     current connectivity sessions: 0
     connectivity sessions threshold percent: 75
     total swg sessions: 0
     current swg sessions: 0
     swg sessions threshold percent: 75
     total swg limited sessions: 2.5K
     current swg limited sessions: 0
     swg limited sessions threshold percent: 75

Displaying the license limits for total concurrent access sessions and VPN/CCUs using the tmsh utility (BIG-IP 11.x and earlier)

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. To determine the license limit for all access sessions, enter the following command:

    tmsh show /sys license detail | grep apm_access_sessions

    The command output appears similar to the following example:

    apm_access_sessions [2500]

  2. To determine the license limit for VPN/CCU, enter the following command:

    tmsh show /sys license detail | grep apm_sessions

    The command output appears similar to the following example:

    apm_sessions [250]

BIG-IP APM license information

License statementInformation
total access sessionsThe total licensed access session database entries that can be created on the BIG-IP APM system.
Note: Access session licenses are consumed when a user starts any new session.
This number is based on the BIG-IP APM license and platform type. For more information, refer to the Supplemental Information section regarding BIG-IP APM licensing.
current active sessionsThe total number of the current consumed Access sessions database entries.
Note: This value represents the total number of access sessions (including active sessions that have not already been authenticated).
current established sessionsTotal number of access sessions that are in the Allowed (completed authentication) state. 
Note: The BIG-IP APM creates access session entries to track users during the login process, rather than after the login process.
access sessions threshold percentAccess sessions threshold warning percent set by the user (default 75 percent).
Note: The percentage used is derived from the total licensed access sessions and the current active access sessions.
total connectivity sessionsThe total number of allowed simultaneous access sessions that can be assigned connectivity resources (SSLVPN, Application Tunnel, Portal Access).  
Note: User connectivity licenses (VPN/CCUs), are consumed when a user is assigned one or more BIG-IP APM resources with tunnel-type access as with a Network Access VPN session. This number is based on the BIG-IP APM license and platform type. For more information, refer to the Supplemental Information section regarding BIG-IP APM licensing.
current connectivity sessionsThe current number of access sessions (VPN/CCU) that have been assigned connectivity resources.
connectivity sessions threshold percentThe connectivity sessions threshold warning percent set by the user (default is 75 percent).
Note: The percentage used is derived from the total licensed VPN/CCU and the total of the actively consumed VPN/CCU sessions.
total swg sessionsThe total Secure Web Gateway sessions that are currently in use.
current swg sessionsThe current SWG sessions that are in use.
swg sessions threshold percentThe SWG sessions threshold warning percent set by the user (default is 75 percent).
Note: The percentage used is derived from the total licensed SWG sessions and the total current active SWG sessions.
total swg limited sessionsSWG Limited session limits are applied when SWG is provisioned and used but not fully licensed.
Note: This number is based on the BIG-IP APM license and platform type. For more information, refer to the Supplemental Information section regarding BIG-IP APM licensing.
current swg limited sessionsThe SWG limited sessions that are currently in use.
Note: SWG limited session limits are applied when SWG is provisioned and used but not fully licensed.
swg limited sessions threshold percentThe SWG limited sessions threshold warning percent set by the user (default is 75 percent).
Note: The percentage used is derived from the total licensed SWG sessions and the current active SWG sessions.
total api protection sub-sessionsThe maximum number of sub-sessions that can be created is five times that of the value of total access sessions. This limit is global per BIG-IP Access Manager instance.
To list the number of api sub-sessions, type the following command sessiondump -subs.
The API protection feature is available beginning in BIG-IP APM 14.1.0 and total api protection sub-sessions is displayed beginning in BIG-IP APM 15.0.0.
