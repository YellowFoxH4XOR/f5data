Known Issue

This is the result of a known issue. The BIG-IP GTM and BIG-IP LTM systems use the big3d daemon to communicate over the iQuery protocol. In versions 9.2.x through 9.4, the big3d daemon returns inaccurate data for translated virtual server probe response in the following manner:

  • The big3d daemon will return a translated virtual server probe response with the translated port set to zero (0).
  • The big3d daemon sets both IP addresses in a translated virtual server probe response to the value of the translated IP address.

F5 Networks Product Development tracked this issue as CR75126 and it was fixed in versions 9.3 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM and GTM Release Notes.
