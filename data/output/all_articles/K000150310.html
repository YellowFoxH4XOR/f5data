Description

Approximate size of a single log record generated by F5 Distributed Cloud for SIEM integration. Log records are JSON objects; size may vary depending on event content. Typical size is about 14 KB per event.

Environment

  • Product: F5 Distributed Cloud
  • Feature: Log forwarding for SIEM integration
  • Log format: JSON objects

Cause

N/A

Answer/Recommended Actions

  • Log records for SIEM integration are formatted as JSON objects.
  • The size of each log record varies based on event content.
  • A rough estimate for a single log event is 14 KB.
  • For storage planning, multiply the estimated number of log events by 14 KB to determine total storage requirements for the retention period.

Additional Information

  • Actual log record size may differ depending on the data included in each event.
  • Monitor log sizes in your environment for more accurate storage planning.
