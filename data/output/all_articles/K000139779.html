K000139779: VELOS partition frequently logging "Monitor Error Event" for partition_fpga from platform-monitor

Description

The platform-monitor service is frequently printing Monitor Error Event messages for one or more blades in a VELOS chassis:

blade-1(p1) platform-monitor[8]: priority="Err" msg="Monitor Error Event" kind="service:monitor-error" error="ReadyRequest failed for 'partition_fpga' @ 'tcp://127.0.0.1:1060', Inner -> 'receive timeout'" interface="console-output"

These messages are observed in the partition's velos.log.

Environment

  • VELOS blade
  • platform-monitor
  • diag-agent

Cause

The purpose of this monitoring out of platform-monitor is to ensure the fpgamgr software service is available.

However, the monitoring is handled by fpgamgr at low priority, and it might fail if fpgamgr is busy with other work.

Bug ID1575433 tracks this issue.

Recommended Actions

No action is required if the system is otherwise operating normally. You can safely ignore the errors.

Additional Information

In some cases the errors might appear tens of times per hour. This is more likely to occur with very large configurations.
