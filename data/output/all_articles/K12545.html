Topic

F5 has recently discovered and corrected a number of issues that affect customers running ARX version 5.1.7. F5 recommends that all customers currently running version 5.1.7 install the latest cumulative rollup hotfix available.

The following table lists the rollup hotfixes available for ARX version 5.1.7. Each hotfix lists the ID number and description for the issues fixed by the hotfix:

Note: These rollup hotfixes are cumulative. Therefore, each hotfix will contain the fixes included in the previous hotfixes.

ARX VersionID NumberDescription
5.1.7 HF4
(build-12064)		343499Some operations (in particular metadata migration) fail to use the configured SPN as they should, preventing the operations from working when using a clustered Windows file server.

(build-12063)		343426Windows 7 clients may be unable to delete top level folders in mapped home directories.
343546Failing over a Netapp filer after an ARX failover could cause NFS clients connected to ARX VIPs to have mount issues.
344119The NFS v3 TCP connection list can be adversely affected by an ARX fail over causing NFS client hung mounts.

(build-12061)		39817

5.1.7 HF1

337650Fixed NSM resource exhaustion and/or crash due to stale connections to the filer not being cleaned up on a busy NSM processor.
336193When processing a directory with an ACL larger than 64k, the ARX now properly denies the request. Previously migrations could be stuck repeatedly trying to move a directory that would never work.

338250Fixed NSM core due to a client issuing a "locking andx" call for a range of bytes in a file. If the file is closed before the lock response is received from the filer, the NSM could crash.
338546Fixed an issue in the ASA that could cause warnings to show up on a domain controller.
339051Fixed a crash in the dmountd process during NFS ACL configuration.
