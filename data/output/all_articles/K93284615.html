Issue

Error Message

notice sod[<PID>]: 010c006e:5: All devices in traffic group <name> <should|now> have a HA group

In this error message, note the following:

  • <PID> is the process ID for the sod process
  • <name> is the name of the traffic group
  • <should|now> is the literal value should or now

For example:

notice sod[6926]: 010c006e:5: All devices in traffic group /Common/traffic-group-1 now have a HA group

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • You activate or update the traffic group configuration and either all the devices in a traffic group contain a correct high availability (HA) group configuration, or one or more devices in a traffic group are not configured correctly for the HA group.

For example, you configure HA groups for the traffic group and you modify or update one of the devices in the device group.

Impact

If the message indicates that all devices now have a traffic group, the devices are configured correctly and no action is required. If the message indicates that all devices should have an HA group, the HA group will not operate correctly for this traffic group.

Recommended Actions

Review the HA group configuration for the affected traffic group on all devices that display this error message. Ensure the configuration for the traffic group, HA group, and failover communication are correct and functioning properly.
