K000161011: Application Gets Session Timeout with TCP resets with messages such as "flow expired" and "no flow found"

Description

Users encountered session timeout errors when accessing an application through a BIG-IP LTM virtual server. TCP resets with messages such as "flow expired" and "no flow found" were observed, indicating that connections were terminated after periods of inactivity. Session persistence was not configured, resulting in session interruptions.

Environment

  • Virtual server using default TCP profile (idle timeout: 300 seconds)
  • No persistence profile initially applied
  • Application accessed via TCP/443 through the BIG-IP LTM virtual server

Cause

The lack of a persistence profile caused user sessions to be distributed across different pool members, resulting in session timeouts. The default TCP idle timeout led to termination of idle connections, causing resets and session interruptions.

Answer/Recommended Actions

Apply a Persistence profile to the virtual server to ensure session affinity for users.
