K40809343: Configuring custom snmp traps for AS3 failed Declarations log messages

Description

How to configure the BIG-IP system to generate custom snmp traps for failed AS3 declarations log messages such as below:

Tue, 15 Sep 2020 11:42:48 GMT - severe: [appsvcs] {"message":"Declaration failed: connection to http://admin:XXXXXX@localhost:8100/mgmt/tm/task/cli/script run cli script timed out","level":"error"}

Environment

  • BIG-IP
  • AS3
  • Syslog

Cause

By default restnoded logs are not sent to syslog but they are written directly to the /var/log/restnoded/restnodedx.log files, as a result the BIG-IP system doe not generate SNMP traps for restnoded related log messages.

Recommended Actions

Note: The configuration below may not be preserved after a system upgrade

  1. Modify the default syslog configuration to include log messages from /var/log/restnoded/restnoded.log.
tmsh modify /sys syslog include "source s_restjavad {file(\"/var/log/restnoded/restnoded.log\" follow-freq(1) flags(no-parse) log-fetch-limit(1) log-iw-size(1));};destination d_alertd {pipe(\"/var/run/alert.pipe\");};log {source(local);source(s_restjavad);destination(d_alertd);};"

        2. Create a custom snmp trap for the 'failed declaration' messages by editing /config/user_alert.conf and adding the lines below:

alert BIGIP_RESTNODED ".*Declaration failed.*" {
    snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.34"
}

        3. Restart both alertd and syslog-ng for the above changes to take effect

tmsh restart sys service syslog-ng
tmsh restart sys service alertd
