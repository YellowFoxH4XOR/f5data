Issue

Error Message

Source file not found:
<Edge Client component> Verify that the file exists and that you can access it.

In this error message, note the following:

  • <Edge Client component> is the path and the name of the component that cannot be extracted.

For example:

Source file not found:
C:\Users\testuser\AppData\Local\Temp\F5_MSI_TMPfb183d1\F5 VPN\f5netprov.dll. Verify that the file exists and that you can access it.

You may encounter this message in the following location:

  • The dialog window of the install program

Description

This message occurs when the following condition is met:

  • The /a option is being used to extract the BIG-IP Edge Client component files.

    For example:

    bigipedgeclient.exe /a

Normally, to perform an administrative install, a windows program will use the /a option to extract the components that the MSI installer will use. Because the BIG-IP Edge Client is able to selectively package components, the /a will fail, as it cannot find components that were not included in the package when it was created.

Impact

You are unable to extract the BIG-IP Edge Client component files.

Recommended Actions

The BIG-IP Edge Client installation file supports the use of /x to extract the component files.
