Note: This Solution applies only to BIG-IP WebAccelerator version 9.4.x. For information regarding changes to large response handling in version 10.x, refer to K10953: Change of Behavior: Large responses are proxied with new S-code S10413.

The BIG-IP WebAccelerator will manage server responses up to the maxResponseDataSize setting configured in the /config/wa/pvsystem.conf file. The default maxResponseDataSize setting is 67,108,864 bytes (64MB). When the BIG-IP WebAccelerator receives an HTTP response from a server that is larger than the value of the maxResponseDataSize setting, the connection is terminated and the client will receive an HTTP 500 error message that appears similar to the following example:

The size of the response received by the server exceeds the permitted size.

To configure the maximum size of an HTTP response accepted by the BIG-IP WebAccelerator, perform the following procedure:

Important: To avoid negatively impacting system performance, you should change the maxResponseDataSize entry only if you have been advised to do so by F5 Networks Technical Support.

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Change directories to the /config/wa directory by typing the following command:

    cd /config/wa
  3. Backup the original pvsystem.conf file by typing the following command:

    cp pvsystem.conf pvsystem.conf.sol9207
  4. Open the pvsystem.conf file in a text editor.
  5. Locate the following maxResponseDataSize entry:

    <maxResponseDataSize>67108864</maxResponseDataSize>
  6. Edit the maxResponseDataSize entry to the desired value.
  7. Save the pvsystem.conf file.
  8. Stop the BIG-IP WebAccelerator process by typing the following command:

    bigstart stop pvac
  9. Start the BIG-IP WebAccelerator process by typing the following command:

    bigstart start pvac
