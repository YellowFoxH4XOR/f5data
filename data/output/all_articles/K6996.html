Known Issue

This is the result of a known issue. The BIG-IP GTM import functionality located on the System >> Device Certificates >> Trusted Device Certificates page stores the certificate in the wrong file. The BIG-IP GTM incorrectly stores the certificate in the /config/gtm/client.crt file instead of the /config/big3d/client.crt file.

F5 Product Development tracked this issue as CR72963 and it was fixed in BIG-IP GTM versions 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

You can work around this issue by moving the trusted device certificate to the proper file. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Append the existing certificates to the new imported certificate by typing the following command:

    cat /config/big3d/client.crt >> /config/gtm/client.crt

  3. Rename the file containing the new imported certificate to the proper filename by typing the following command:

    mv /config/gtm/client.crt /config/big3d/client.crt
