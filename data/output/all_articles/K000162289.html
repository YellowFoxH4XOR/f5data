K000162289: Config loading may fail with error message "01020055:3: Cannot create circular profile relationships." after upgrading to 21.1.0

Description

When upgrading BIG-IP LTM to version 21.1.0, the configuration validation process may fail with the error message:

01020055:3: Cannot create circular profile relationships. Unexpected Error: Validating configuration process failed.

This error occurs during schema loading and is associated with a loop in SSL profile references.

Environment

  • Product: BIG-IP LTM
  • Version: Upgrade to 21.1.0
  • Configuration object: SSL profile /Common/clientssl-legacy
  • Action: Upgrade from previous version to 21.1.0
  • Error observed during configuration validation

Cause

The issue is caused by a circular reference in the SSL profile configuration. The clientssl-legacy profile is set to inherit from itself via the defaults-from /Common/clientssl-legacy directive, creating a loop. During an upgrade from earlier versions, custom clientssl profiles that previously used defaults-from clientssl are automatically updated to use defaults-from clientssl-legacy to maintain legacy TLS behavior.  K000161291

Answer/Recommended Actions

To resolve the configuration validation failure:

  • Backup the configuration file:cp /config/bigip.conf /config/bigip.conf.bak.$(date +%Y%m%d%H%M%S)
  • Edit /config/bigip.conf using your preferred editor.
  • Locate the affected SSL profile:ltm profile client-ssl /Common/clientssl-legacy
  • Remove the following line from the profile definition:defaults-from /Common/clientssl-legacy
  • Save the configuration file and exit the editor.
  • Verify the configuration:tmsh load sys config verify
  • If verification passes, load the configuration:tmsh load sys config

Additional Information

  • The error is directly related to changes in SSL profile inheritance behavior in BIG-IP 21.1.0.
  • Removing the self-referencing defaults-from directive eliminates the circular relationship and allows the upgrade to proceed.
