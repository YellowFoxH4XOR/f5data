K000158052: [F5OS-A] K3S installation fails to start when using weak hmac-sha1-96 MAC Algorithm under SSH settings

Type
Support Solution
Published
2025-12-03
Updated
2025-12-03
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000158052

Description

K3S installation does not start automatically upon upgrading F5OS-A to 1.8.X or when doing manual reinstallation on 1.8.X versions.

/var/log/manage_k3s_service.log indicates it is unable to SSH into localhost as there is no matching MAC found:

fatal: [127.0.0.1]: UNREACHABLE! => {"changed": false, "msg": "Failed to connect to the host via ssh: Unable to negotiate with 127.0.0.1 port 22: no matching MAC found. Their offer: hmac-sha1-96", "unreachable": true}

The same error is returned when trying to SSH to localhost.

[root@appliance-1(R5900-R5-S7):Waiting for cluster status] ~ # ssh localhost
Unable to negotiate with ::1 port 22: no matching MAC found. Their offer: hmac-sha1-96

Furthermore, tenants fail to deploy with error "Tenant deployment failed - Server is not responding" and F5OS CLI prompt says "Waiting for cluster service".

F5OS SSHD settings are customized and uses weak hmac-sha1-96 MAC algorithm. Example:

R5900-R5-S7# show running-config system security services service sshd
system security services service sshd
 config ciphers [ aes128-cbc aes128-ctr aes128-gcm@openssh.com aes256-cbc aes256-ctr aes256-gcm@openssh.com ]
 config macs  [ hmac-sha1-96 ]
 config kexalgorithms [ diffie-hellman-group14-sha1 diffie-hellman-group14-sha256 diffie-hellman-group16-sha512 ecdh-sha2-nistp256 ecdh-sha2-nistp384 ecdh-sha2-nistp521 ]
!

Environment

  • F5OS-A upgraded from 1.5.2 to 1.8.X or running 1.8.X
  • K3S installation unable to start due to weak hmac-sha1-96 MAC Algorithm under SSH settings

Cause

Weak hmac-sha1-96 MAC Algorithm configured in F5OS SSHD settings. 
ID2163677 was created for tracking this issue.

Recommended Actions

Remove hmac-sha1-96 algorithm from SSHD settings or add at least one strong MAC algorithm (e.g. hmac-sha2-256).
If K3S installation does not start automatically, manually trigger it by following https://my.f5.com/manage/s/article/K000140429.

Additional Information

K3S is reinstalled when upgrading to 1.8.0 due to https://cdn.f5.com/product/bugtracker/ID1349677.html
