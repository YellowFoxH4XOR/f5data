Known Issue

iControl representational state transfer (REST) calls fail when you use remote authentication and a username that contains special characters. For example, the 'at' (@), period (.), and dollar sign ($) characters.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to use RADIUS or Lightweight Directory Access Protocol (LDAP) remote authentication.
  • You have created a BIG-IP system user account on the remote authentication server with a username that contains one or more special characters.
  • The user attempts to access the BIG-IP system using the iControl REST interface.

Impact

Users cannot access the BIG-IP system using iControl REST.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You cannot use the iControl REST interface to manage your BIG-IP system.
  • You receive an Authentication Failed message when attempting to access your BIG-IP system using iControl REST.
