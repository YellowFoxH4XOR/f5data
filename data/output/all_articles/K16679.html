Known Issue

The BIG-IP system may replace an ampersand (&) character with an &amp; entity reference when generating or renewing a Secure Sockets Layer (SSL) certificate.

This issue occurs when all of the following conditions are met:

  • You generate or renew a certificate using the Configuration utility.
  • The certificate contains an ampersand (&) character in one of the following fields:
    • Common Name
    • Organization Name
    • Division
    • Subject Alternative Name

Impact

You cannot use the Configuration utility to generate or renew an SSL certificate that contains an ampersand (&) character.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After generating or renewing an SSL certificate using the BIG-IP Configuration utility, you notice that ampersand (&) characters are replaced with &amp; entity references
  • You cannot use the BIG-IP Configuration utility to generate or renew an SSL certificate that contains an ampersand (&) character.
