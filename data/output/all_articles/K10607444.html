Known Issue

The system displays an incorrect tooltip for the Request length exceeds defined buffer size violation.

The tooltip displays as follows:

The system checks that the request length is not larger than the maximum memory buffer size of the BIG-IP ASM system. By default this limit is set to 10 megabytes. In case a website receives large file uploads, consider raising this limit by changing the parameter request_buffer_size on the Advanced Configuration screen. F5 recommends consulting with support before modifying advanced options.

The tooltip erroneously suggests adjusting the request_buffer_size parameter rather than the long_request_buffer_size parameter.

This issue occurs when the following condition is met:

  • In the Configuration utility, you click the icon to the left of the Request length exceeds defined buffer size violation to display the tooltip.

Impact

The tooltip error may cause misconfiguration of the BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The tooltip erroneously refers to the request_buffer_size parameter for the Request length exceeds defined buffer size violation.
