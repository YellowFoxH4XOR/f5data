K17573: The BIG-IP ASM system does not need to be disabled to allow large file uploads

Type
Knowledge
Published
2015-11-06
Updated

Applies to

Source

Issue

Old Behavior

In versions prior to BIG-IP ASM 11.5.0, the system does not inspect the payload of requests that exceed the long_request_buffer_size value, and the requests are either blocked or allowed per policy configuration.

New Behavior

Beginning in BIG-IP ASM 11.5.0, when the Request length exceeds defined buffer size violation is not set to block, the system inspects the first 10 KB of large requests (larger than 10 MB, by default) for slow post attacks. With this behavior, administrators can allow large requests and the BIG-IP ASM system can inspect and enforce the first part of the data instead of passing all data without inspection.

Impact

You do not need to disable the BIG-IP ASM system to allow large file uploads.

Note: Depending on your BIG-IP ASM system's System Variables settings for the slow_transaction_timeout and max_slow_transactions variables, large post requests can trigger a slow post attack violation. When a slow post violation is triggered, the BIG-IP ASM system blocks the request even if the security policy enforcement mode is set to Transparent.

Recommended Actions

None
