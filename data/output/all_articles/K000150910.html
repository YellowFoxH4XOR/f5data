Description 

Because of the change from ID818673, starting in v17 and above the SID session variable session.ad.last.attr.objectSid is now SID format string instead of hex.

Environment

  • BIG-IP APM v17.x
  • Session Variable SID format

Cause

Updates to ID818673 changes the session variable format

For example:

In v16.x (and below)

session.ad.last.attr.objectSid = 0x010500000000000515000000302A06FEA03C5BA8923203BE7C040000

In v17.x (and above)

session.ad.last.attr.objectSid = S-1-5-21-4123456780-2123456784-3112345694-1111

Recommended Actions

Modify variable assign using session.ad.last.attr.objectSid session variable to accommodate this change in behavior
