K000137782: BGP running configuration not saved

Type
Support Solution
Published
2023-12-04
Updated
2023-12-04
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000137782

Description

Zebos running config is not saved with tmsh save sys config, or save sys ucs.


Environment

BIG-IP with dynamic routing licensed and configured.


Cause

save sys config / save sys ucs, neither saves the "running" zebos config, but only archive the last written zebos config.


Recommended Actions

After making any zebos routing changes make sure to write the zebos config.


Additional Information

RFE id 1401869 will save running zebos config when saving the BIG-IP config with save sys config.
