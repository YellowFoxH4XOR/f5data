Known Issue

This is the result of a known issue. Some pipelined data causes the HTTP CONNECT method to crash. The HTTP CONNECT method is used to establish a proxy tunnel through HTTP.

When the CONNECT request is followed by trailing data (a pipelined request), the BIG-IP terminates the connection receiving an HTTP 200 OK message for the CONNECT request, without forwarding the pipelined data. As a result, the CONNECT method plugin becomes unstable and crashes.

F5 Networks Product Development tracked this issue as CR89679 and it was fixed in versions 9.4.4 and 9.6.1. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.

This issue was fixed in Hotfix-BIG-IP-9.4.3-HF2, which has been issued for BIG-IP version 9.4.3. You may download this hotfix or a later version of this hotfix from the F5 Networks Downloads site.
