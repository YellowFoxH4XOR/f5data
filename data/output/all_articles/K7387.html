Known Issue

This is the result of a known issue. The BIG-IP LTM system properly forwards gratuitous Address Resolution Protocol (ARP) requests to systems in a Virtual Local Area Network (VLAN) group. However, the BIG-IP system does not add the gratuitous ARP request entries to the ARP table. As a result, when a system sends a gratuitous ARP reply across the VLAN group, the BIG-IP system has no record of the ARP request, and does not forward the gratuitous ARP reply.

F5 Product Development tracked this issue as CR75146 and it was fixed in BIG-IP LTM 9.3 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
