Description
If you want to list all BIG-IQ managed BIG-IP devices from command line

Environment

  • BIG-IQ Central Management
  • BIG-IQ version 7.x 8.x
  • Command line access
  • Managed BIG-IP devices

Cause
None

Recommended Actions

  1. Run the following command from bash:
    # restcurl /shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/
