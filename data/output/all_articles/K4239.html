Topic



Although there are many reasons a link to a Portal Access Web Applications Favorites can fail, one of the most common reasons is that you have not yet configured the host site's internal domain name on FirePass.

When you configure FirePass, you enter default domain suffixes, which FirePass uses to resolve host names that are not fully qualified. If a web site that is accessed though a Portal Access Web Applications Favorite contains a link to a host that belongs to a domain that is not yet configured on FirePass, that link will not work until you configure a suffix for that domain.

Configuring additional domain suffixes

To configure additional domain suffixes so that the Portal Access Web Applications Favorites links work correctly, perform the following steps:

  1. Log in to the Administration Console.
  2. From the main navigation pane, click Device Management.
  3. From the upper navigation pane, click Configuration.
  4. From the menu, click Network Configuration.
  5. Click the DNS tab.
  6. In the Default domain suffixes section, enter each domain suffix that your web application uses.
  7. Click the Update button.
  8. Click the Finalize tab.
  9. After reviewing the summary of changes, click the Finalize Changes button.
