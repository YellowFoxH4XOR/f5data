Description

You are running BIG-IP 14.1.4.1 and you are getting high CPU / CPU spikes when delete net fdb command is initiated.

At the same time, TMM service will restarts when delete net fdb command is initiated.

Further check shows TMM core files are generated during the tmm restart.

Environment

  • BIG-IP 15.1.4.1
  • Issues happens when delete net fdb command is initiated
  • Symptoms are:
    • TMM restarts
    • TMM core file generated
    • high CPU / CPU spike

Cause

The high CPU / CPU spike is caused by generating the TMM core file.

TMM service will restart and generate the TMM core file due to Bug ID 1064649.

Recommended Actions

Bug ID 1064649 will be resolved by upgrading to BIG-IP 15.1.5 or later.

Follow K84554955 on the upgrade steps.
