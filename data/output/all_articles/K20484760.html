Description

The following error message is related to this article.

Invalid Node, the IP address <x.x.x.x> already exists

<x.x.x.x> is the node IP address you are attempting to configure. If the IP address of the node is 192.168.1.1, the error message is as follow:

0107176c:3: Invalid Node, the IP address 192.168.1.1 already exists
 

Environment

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The TMOS Shell (tmsh)

Cause

This message occurs when one of the following conditions are met:

  • You attempt to configure a duplicate IP address.
  • You attempt to load bigip.conf configuration file after an upgrade, which contains duplicate IP addresses. For example, you are attempting to upgrade from BIG-IP 11.x to a later version.
  • Re-activate the device or change the license on the device.

In some cases, you may observe that your BIG-IP LTM configuration with duplicate node IP addresses may cause loading configuration issue for other modules (BIG-IP ASM, BIG-IP APM, and so on) configured on your system.

Recommended Actions

  1. Identify the duplicate node with the same IP address.
  2. Remove one of the node.
  3. If this issue is causing the BIG-IP configuration not to load, you will need to edit /config/bigip.conf and manually delete one of the node.
