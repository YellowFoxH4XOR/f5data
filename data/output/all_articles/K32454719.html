Description
When trying to manage the F5 software with leveraging the Microsoft SCCM tool, the process of uninstalling the F5 software may fail.

While uninstalling, it appears one of the SCCM services (SMS Agent Host (CcmExec.exe)) locking a file of the Edge Client (C:\WINDOWS\SysWOW64\f5netprov64.dll).
As the F5 uninstaller program tries to kill all services and processes that lock files it wants to uninstall, it also kills the SCCM service (Microsoft software distribution) which causes it to malfunction directly after uninstallation of Big-IP Edge Client.
The problem was that SCCM was accessing a specific F5 DLL (related to the users credentials management service) while the uninstallation was running.
This results in a deadlock.

Environment

You may hit this difficulty when all conditions are met:
  • BIG-IP APM
  • EdgeClient built with the option "User Logon Credentials Access Service"
  • Microsoft SCCM

Cause
F5 software leverages MRP (Multiple Provider Router) to get loaded when Windows validates the network access account and creates a user context.
The OS component MPR have “F5 Networks Network Provider” which is used and this loads f5netprov64.dll to ccmexec process.

Recommended Actions

There's no fix or workaround, at this time.

Additional Information
https://docs.microsoft.com/en-us/windows/win32/secauthn/multiple-provider-router
The Multiple Provider Router<https://docs.microsoft.com/en-us/windows/win32/secgloss/m-gly> (MPR) handles communication between the Windows operating system and the installed network providers. It enables Windows to present an integrated network to the user.
When the MPR starts, it checks the registry to determine which network providers are installed on the system and the order they should be cycled through. It loads all registered network provider DLLs and uses them to process subsequent WNet calls made by the user interface or other applications.
A credential manager is similar to a network provider in that it provides entry points that are called by the Multiple Provider Router<https://docs.microsoft.com/en-us/windows/desktop/SecGloss/m-gly> (MPR). In fact, some network providers are also credential managers.
