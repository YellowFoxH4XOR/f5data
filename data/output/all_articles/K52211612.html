Description
iControl Powershell Snapin connection issue after  BIG-IQ  CMs and DCDs upgrade to version 7.0

Initialize-F5.iControl : Could not initialize connection with supplied information 

At line:1 char:1
+ Initialize-F5.iControl -HostName <Hostname> -U ...
+ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Environment

  • BIG-IQ Centralized Management v.7.0
  • BIG-IQ Data Collection Device v.7.0
  • iControl Powershell Snapin

Cause

Unknown at time of publication

Recommended Actions

Add additional cmdlet:
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
