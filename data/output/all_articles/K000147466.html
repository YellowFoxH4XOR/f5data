Description

  • The customer wants to block specific HTTP request methods.

Environment

  • F5® Distributed Cloud WAF
  • HTTP LB

Resolution/Answer

To create a service policy:

1. Go to Web App & API Protection.

2. Select the Namespace we will be working on.

3. Go to Service Policies.

4. Input a name & select Custom Rule List. 

5. Select Add Item on the next screen.

6. Configure as below with action to Deny. 
 

7. Select the necessary methods required by the customer. 

8. Apply.

9. Save & Exit.

10. Visit the Load Balancers section 

11. Go to Manage Configuration.  

12. Go to Common Security Controls > Service Policies > Apply Specified Service Policies. 

13. Select the policy you have just created.
14. Apply.
15. Save and Exit.

Additional Information

  • The GET method is the default way used by web browsers to fetch data from a specific server resource. It transmits data through the query string of the URL.
  • POST is a method used to send data to a specific resource for processing. It transmits data within the HTTP request body, commonly utilized for form submissions and file uploads.
  • PUT is utilized to upload a representation of a given resource, which will replace any existing representation of the resource.
  • The HEAD method requests a response similar to a GET request, but without including the response body. It is commonly utilized to monitor alterations in resources, such as files, stored in the browser cache.
  • The CONNECT method creates a tunnel to the server that the destination resource has specified. It is commonly utilized to establish a secure SSL/TLS connection using a proxy server. These methods are part of the HTTP protocol and are fundamental for communication between clients and servers on the web.
