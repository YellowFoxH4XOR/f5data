Description

Perform the following up/downgrade on R2600 hardware:

v1.8.4-26491 ⇒ v2.0.0-HR2 ⇒ v1.8.4-26491 

After downgrading from v2.0.0-HR2 to v1.8.4, save a backup file of F5OS, noticed that the "services-version" in backup file displays 2.0.0-27774 rather than v1.8.4-26491.

F5OS.backup

----------------------------

<?schema-metadata

services-type: F5OS-A R2R4

services-version: 2.0.0-27774 <---!!!

schema-fingerprint: 2mnsldj2w3epsjfposnspdfnm323

iowejkKI923jhdoHJV2nvosnvcnqwio8i8sunKKUgjjskljJJLnUIOINON23343FJH9HNWSlsj9pwnefniwe==

?>

----------------------------

 

Environment

R2600

F5OS-A v1.8.4

 

Cause

Undetermined, not able to reproduce.

 

Answer/Recommended Actions

A reboot can fix this issue, then use below commands to confirm the version of the running machine, e.g.

#cat /etc/PRODUCT

#show system image
