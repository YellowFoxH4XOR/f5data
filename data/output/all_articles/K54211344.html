Description

  • The big3d service appears to be in a restart loop.
  • Log messages similar to the following can be seen on /var/log/daemon.log

May 8 16:38:42 DC1-F5-LTM-TEST-INT-02.example.com emerg logger[12706]: Re-starting big3d
May 8 16:38:43 DC1-F5-LTM-TEST-INT-02.example.com emerg logger[12740]: Re-starting big3d
May 8 16:38:44 DC1-F5-LTM-TEST-INT-02.example.com emerg logger[12774]: Re-starting big3d

  • Log messages similar to the following are logged to /var/log/gtm:

    err big3d[12648]: 012b3001:3: Private key /config/httpd/conf/ssl.key/server.key did not load
    err big3d[12648]: 012b3003:3: CreateSSL_CTX: SSL error:0B080074:x509 certificate routines:X509_check_private_key:key values mismatch

Environment

  • BIG-IP
  • big3d service

Cause

Server key used for big3d seems missing or references a mismatched certificate and key pair.

Recommended Actions

Verify the key pair used for big3d matches:

  1. Log on to the command line of the BIG-IP.
  2. Run the following openssl commands:
    openssl rsa -in /config/httpd/conf/ssl.key/server.key -pubout |  md5sum
    openssl x509 -in /config/httpd/conf/ssl.crt/server.crt -pubkey -noout | md5sum
     
  3. Verify that the md5sum values returned from each command are identical.
     

Should the md5sum values not match, replace the following SSL certificate and key with a backup version (UCS) or generate a new certificate and key using OpenSSL commands.

  • /config/httpd/conf/ssl.key/server.key
  • /config/httpd/conf/ssl.crt/server.crt

Note: For more information on generating certificates and keys using OpenSSL refer to: K14534: Creating SSL certificates and keys with OpenSSL (11.x - 16.x).
