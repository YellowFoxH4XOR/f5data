Known Issue

This is the result of a known issue. Web Application Tunnel Favorites fail when launched inside Protected Workspace on Windows Vista clients using User Account Control (UAC). UAC is enabled by default in Windows Vista.

When a user enters Protected Workspace, logs in to the FirePass controller, and launches a Web Application Tunnel, the Tunnel attempts to connect to the server, and the Tunnel pop-up window displays the following error message:

Status: Failed

Clicking the arrow displays the following error message:

Failed to connect to local tunnel server

When the user exits Protected Workspace, a Windows Vista pop-up window appears with text that appears similar to the following example:

TunnelServer has stopped working

A problem caused the program to stop working corrrectly.
Windows will close the program and notify you if a solution is available.

Clicking the Close program button returns the user to the Windows Vista desktop.

F5 Networks Product Development tracked this issue as CR85859 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-601-7 issued for FirePass version 6.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Note: FirePass version 6.0.1 requires cumulative hotfix HF-601-6 or a later version of the cumulative hotfix to support Protected Workspace on Windows Vista clients. Previous versions of FirePass software do not support Windows Vista clients.

Workaround

You can work around this issue by disabling the Windows Vista's User Account Control, which will permit Web Application Tunnels to run inside Protected Workspace. For instructions about disabling UAC, refer to your Windows Vista documentation.

Alternatively, you can use a Static Application Tunnel in place of the Web Application Tunnel.
