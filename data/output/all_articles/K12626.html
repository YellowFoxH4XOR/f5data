Known Issue

Note: For information about the ARX Secure Agent software, refer to K10026: Overview of the ARX Secure Agent software.

This is the result of a known issue. As a result of a possible race condition present in the ARX Secure Agent software, a Domain Controller with the ASA software installed may experience frequent pop-up error messages that appear similar to the following example:

Event Type: Information
Event Source: Application Error
Event Category: (100)
Description: Reporting queued error: faulting application md4service.exe, version 0.0.0.0, faulting module ntdll.dll, version 5.2.3790.3959, fault address 0x0004afb2.

F5 Product Development tracked this issue as ID 338546 and it is fixed in ARX Secure Agent 5.1.9. For information about upgrading, refer to the ARX release notes.

Additionally, this issue was fixed in ARX Secure Agent 5.1.7 HF1 (build 12055) available for download from the F5 Downloads site. For information about downloading the ARX Secure Agent Software, refer to K8784: Obtaining the ARX Secure Agent software.

Note: Beginning with ARX 5.2.0, the ARX Secure Agent software is no longer bundled within the ARX software. For more information, refer to K12394: The ARX Secure Agent software is no longer bundled with the ARX software.

Note: For information about determining the version of your ARX Secure Agent software, refer to K11713: Displaying the software version for the ARX Secure Agent.
