K000134537: tmm.access.maxrequestsize parameter not synced to standby

Type
Support Solution
Published

Updated
2023-05-19
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.0
Source

Description

This is for you who is planning to modify the database variable "tmm.access.maxrequestsize" and is wondering if this will be replicated to the standby device.

 

Environment

  • BIG-IP

Cause

This database variable will not be replicated to the standby device as it is not part of the high availability configuration objects, this is by design.

 Recommended Actions

Due to the database variable not being synchronized, please, perform the changes / modifications on both devices in the high availability group.

Additional Information

For more information about what specific database variables are synchronized contact F5 Support with the specific variable your are considering.
