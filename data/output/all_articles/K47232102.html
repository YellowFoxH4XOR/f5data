Description

BIG-IP appliance reboots without any apparent reason 


Environment

It is probable to see an unexpected reboot of the appliance and logs similar to the following samples:

  • BIG-IP Hardware environment
  • Logs with messages like:  "Host Reset Event" & "Memory #08 Uncorrectable ECC"

Cause

Undetermined, However, this events followed by this type of logs, can be interpreted as an error of "catastrophic" type.
Though no specific component is implied (probably related with a DIMM Memory), it does not seem like it's in response to any software activity. 
Logs like the following can be found on  /var/log/sel

  10/01/20 12:56:01 INF BMC  OEM(c6) #90 CPU Fault CATERR asserted 6f [03 ff ff]   
  10/01/20 12:56:11 INF BMC  OEM(c6) #90 CPU Fault CATERR asserted 6f [03 ff ff]   
  10/01/20 12:56:41 INF Host Reset Event                                             
  10/01/20 12:56:49 INF BMC  OEM(c6) #90 CPU Fault CATERR deasserted ef [03 ff ff]   
  10/01/20 12:57:31 INF SMI  Memory #08 Uncorrectable ECC, DIMM[0] 6f [a1 01 00]
  10/01/20 12:57:44 INF BIOS Handoff Event Code: 0xa2
  10/01/20 12:59:32 INF Set MFG Mode Lockout

 

Recommended Actions

Run an EUD K7172: Overview of the End User Diagnostics software
Open a Support Case with F5 tech support, provide the EUD Results and Qkview of the BIGIP system. 
*  Even though EUD shows no errors, most of the times this will end in an RMA of faulty device.
