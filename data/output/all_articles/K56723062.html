Description
When trying to disable a IPv6 DNS listener through REST API or TMSH command,  you may see below error message in the output, and the DNS listener failed to be disabled

tmsh modify gtm listener test disabled
0107176c:3: Invalid Virtual Address, the IP address 2001:DB8:1:1::1:1 already exists.

REST call will get the same error message as below shows

curl -sk -u admin:admin -H "Content-Type: application/json" -X PATCH https://localhost/mgmt/tm/gtm/listener/~Common~UDP_IPv6?ver=15.1.4.0.0.0.0.2 -d '{"disabled":true}' | jq .
{
  "code": 400,
  "message": "0107176c:3: Invalid Virtual Address, the IP address 2001:DB8:1:1::1:1 already exists.",
  "errorStack": [],
  "apiError": 3
}

Environment

  • BIG-IP
  • REST/TMSH
  • IPv6 DNS listener

Cause
This issue happens only when the IPv6 DNS listener is created through configure utility and when the address is not shorted with ::
For example:
2001:DB8:1:1::1:1    will not have issue
2001:DB8:1:1:0:0:1:1  will have issue
Recommended Actions

Try to apply the change on the corresponding LTM object, for example
tmsh modify ltm virtual test disabled
curl -sk -u admin:admin -H "Content-Type: application/json" -X PATCH https://localhost/mgmt/tm/ltm/virtual/~Common~test1?ver=15.1.4.0.0.0.0.2 -d '{"disabled":true}' | jq .
