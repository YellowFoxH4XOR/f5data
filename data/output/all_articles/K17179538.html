Description

When attempting to load the configuration, you receive the following error message:

  • In the Web-UI: 
    • "This BIG-IP system has encountered a configuration problem that may prevent the Configuration utility from functioning properly."
  • In /var/log/ltm: 
    • "01070523:3: No Vlan association for STP Interface Member x.x Unexpected Error: Loading configuration process failed."

Environment

  • BIG-IP VE with multi NIC

Cause

This error occurs when there is a presence of a STP (Spanning Tree Protocol) interface member configuration on a multi NIC VE. 

Per K61172462: Disabling or enabling the Spanning Tree Protocol for a trunk (11.x - 16.x) "STP is not supported on BIG-IP Virtual Edition (VE).". 

Despite STP being non-functional on VE, TMOS still writes net stp configuration into bigip_base.conf when interfaces are assigned to VLANs. This is because the STP configuration object is automatically created/maintained by mcpd as part of the standard TMOS configuration model — it's a side effect of the VLAN-to-interface association, not something a user explicitly configures. On physical hardware, this is meaningful; on VE, it's vestigial but harmless — unless the interface-to-VLAN relationship becomes inconsistent.

Thus when this happens it can safely be removed to correct the situation.

Recommended Actions

Perform the following steps to resolve this issue:

  1. Before editing /config/bigip_base.conf, make a backup file using the following command:cp /config/bigip_base.conf /config/bigip_base.conf_backup
  2. Use an editor such as nano/vi/vim to open the bigip_base.conf. 
  3. Hash out or delete the entire block in the bigip_base.conf file. For example: 
    # net stp /Common/cist {
    #    interfaces {
#        1.1 {
#            external-path-cost 200000
#            internal-path-cost 200000
#        }
#        1.2 {
#            external-path-cost 200000
#            internal-path-cost 200000
#        }
#        1.3 {
#            external-path-cost 200000
#            internal-path-cost 200000
#        }
#        1.4 {
#            external-path-cost 200000
#            internal-path-cost 200000
#        }
#        1.5 {
#            external-path-cost 200000
#            internal-path-cost 200000
#        }
#        1.6 {
#            external-path-cost 200000
#            internal-path-cost 200000
#        }
#    }
#    vlans {
#        /Common/DMZ_4_VLAN
#        /Common/DMZ_7_VLAN
#        /Common/DMZ_8_VLAN
#        /Common/HA
#       /Common/internal
#    }
#}

    NOTE: Path values can vary by interface speed.
  4. Save the config file.
  5. Verify the config file you modified using the command: 
    tmsh load sys config verify
  6. If no errors, load and save the configuration using the following commands: 
    tmsh load sys config
    tmsh save sys config

When the configuration is loading you may see the named daemon and others restart. This is expected.
