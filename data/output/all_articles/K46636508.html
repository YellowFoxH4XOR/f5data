Known Issue

BIG-IP VE may fail to boot and remain in a Stopped state when deployed on the Amazon Web Services (AWS) platform.

This issue occurs when the following condition is met:

  • You deployed BIG-IP VE on the AWS platform using the c4.8xlarge instance type.

Impact

The BIG-IP VE instance fails to boot.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP VE instance remains in a Stopped state and fails to boot up.
  • The AWS system console does not provide any output.

Workaround

To work around this issue, you can choose the c4.4xlarge or other instance types when deploying BIG-IP VE on the AWS platform.
