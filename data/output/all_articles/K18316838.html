Description

Under Local Traffic > Profiles, the Persistence category is missing from the selection.
When selecting another Profile category, the Persistence tab shows up at the top of the page but the Cookie Persistence option in Persistence profile is not seen.

Environment

  • ASM add-on evaluation key 
  • Cookie persistence profile 
  • Persistence profile

Cause

The ASM add-on evaluation key license expired. When an evaluation/demonstration add-on license expires, features included in both the evaluation add-on as well as the regular, perpetual license stop working.
This behavior is covered in the F5 article K4679: BIG-IP evaluation and demonstration licenses do expire 

Recommended Actions

Remove the expired ASM add-on evaluation key and re-activate the license:

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. Select Re-activate.
  4. For Add-On Registration Key List, select the add-on key to be removed.
  5. Select Delete.
  6. For Activation Method, select Manual.
  7. Copy the dossier.
  8. Go to the F5 Licensing Tools page and select Activate F5 product registration key.
  9. In the Enter your dossier box, paste the dossier, and select Next.
  10. The F5 Licensing Tool page produces your license.
  11. Copy the license and paste it into the License box in the Configuration utility.
  12. Select Next and wait for configuration to reload.
