Description

Starting in version 12.1.0, BIG-IP APM as IdP supports multi-value attributes within an attribute configuration via pipe delineated strings in session variables.

  • For example, given session variable value '| a | b | c |', the assertion attribute will look similar to the following:

    <saml2:Attribute Name="name">
        <saml2:AttributeValue>a</saml2:AttributeValue>
        <saml2:AttributeValue>b</saml2:AttributeValue>
        <saml2:AttributeValue>c</saml2:AttributeValue
    </saml2:Attribute>

Important: invalid spacing between the pipes and attribute values will result in the attribute value becoming a single string (instead of multiple attribute values) and containing the pipe values that were used to delineate attributes in the first place.

  • For example, given session variable value '| a | b | c|', the assertion attribute will look similar to the following:

    <saml2:Attribute Name="name">
        <saml2:AttributeValue>| a | b | c|</saml2:AttributeValue>
    </saml2:Attribute>
     

    Examples of valid and invalid strings:
    Valid:  '| a | b | c |'
    Invalid: ' | a | b | c |'
    Invalid: '| a |b | c |'
    Invalid: '| a | b | c | '

Environment

  • BIG-IP Access Policy Manager (APM)
  • APM as Identity Provider (IdP)
  • Attribute Values
  • Session Variables with pipe delineated values

Cause
None

Recommended Actions

Implement valid pipe delineated values in session variables used to define multi-value BIG-IP APM as IdP attribute values
  1. Login to the BIG-IP Admin GUI.
  2. Navigate to Access>Federation>SAML Identity Provider>Local IdP Services.
  3. Select the Local IdP configuration.
  4. Click Edit.
  5. Select SAML Attributes.
  6. Click Add.
  7. Select the Attribute.
  8. Click Edit.
  9. In the "Value" field enter valid pipe delineated values.
