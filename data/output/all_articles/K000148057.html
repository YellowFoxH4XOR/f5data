K000148057: How do I download F5XC content pack for QRadar integration?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-27
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000148057

Description

  • You were trying to configure log streaming to Qradar and you were unable to find where to download the F5XC content pack in the Qradar store.

 

Environment

  • F5® Distributed Cloud (XC)
  • Global log streaming
  • F5XC console
  • Qradar store

 

Answer/Recommended Actions

To be able to download the content pack:

  1. Go to https://exchange.xforce.ibmcloud.com/
  2. In the dropdown menu select IBM Security App Exchange (APP) instead of ALL
  3. Search for F5 XC Content Pack
  4. Select QRadar SIEM - F5 XC Content Pack

 

Cause

  • There is no direct link to download the F5XC content pack

Additional Information

  • App filter recommended to be able to find it more easily.
