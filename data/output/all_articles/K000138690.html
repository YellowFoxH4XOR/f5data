Description

When attempting to logon to the APM Edge Client, users may receive a script error pop-up, similar to:

'An error has occurred in the script on this page'

Error: Object doesn't support propoerty or method 'addEventListener'

Do you want to continue running scripts on this page?

 

Other error codes may include:

Error: 'jquery' is undefined'

Error: Unexpected identifier

 

Environment

  • Big-IP APM Edge Client
  • Access Policy that utilizes MFA with an external logon page (ie: Duo with Radius or oAuth)

 

Cause

The APM Edge Client requires a unique registry key to be in place on the client workstation, in order to properly render external logon pages that may be associated with third party MFA resources, like Duo.

The registry key required is: rundll32.exe with a value of: 2af8 (Hexadecimal) or 11000 (Decimal)

This registry must be present in this registry location on the client workstation:

HKEY_CURRENT_USER\SOFTWARE\Microsoft\Internet Explorer\MAIN\FeatureControl\FEATURE_BROWSER_EMULATION

 

Starting with APM Edge Client version 7.2.3.1, this registry key will be included automatically in this location.

This was introduced as a change in behavior, tracked with Bug ID 1107385: [APM[EC][WIN]Edge Client fails to render external logon page

However, some users may still recieve script error pop ups, even while running an updated APM Edge Client with this registry key in place.

Some customer environments may have a security policy that includes an enabled registry key called 'Security_HKLM_only', which restricts the Internet Explorer settings to only be used from the HKEY_LOCAL_MACHINE location in the registry.

Any settings under HKEY_CURRENT_USER will be ignored.

Due to administrative restrictions against the Edge Client, it cannot automatically write the registry key rundll32.exe to the HKEY_LOCAL_MACHINE registry location on the client workstation, so this key will not be present and the script error pop up can be triggered.

 

Recommended Actions

Verify that affected users are first running an APM Edge Client version 7.2.3.1 or later.

  • If not, then it is recommended to upgrade to the latest APM Edge Client version.

 

Check the Windows registry on the client workstation, for the presence of this registry key:

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\CurrentVersion\Internet Settings ->

Security_HKLM_only

 

You can access the Windows registry settings by launching the 'regedit' application as 'administrator' on the client workstation. If the Security_HKLM_only registry key is present, then you can disable this key via the following steps:

 

  • Within the Registry Editor application, navigate to: 'HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\CurrentVersion\Internet Settings'
  • Right-Click on the Security_HKLM_only registry key, select 'modify'
  • Under the 'Value Data' field, change the value to '0'.
  • Click OK

 

If the user is unable to disable the Security_HKLM_only registry key, then they can also resolve this issue by adding the rundll32.exe registry key into the HKEY_LOCAL_MACHINE registry location, via the following steps:

 

  • Launch the 'regedit' application as 'administrator' on the client workstation
  • Within the Registry Editor application, navigate to: 'HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION'
  • Right-click in the empty space and select -> 'New' -> 'DWORD (32-bit) Value' -> enter rundll32.exe for the value name
  • Right-click the newly added rundll32.exe registry key, select 'modify'
  • Under the 'Value Data' field, change the value to 2af8 (if hexadecimal is selected) or 11000 (if decimal is selected)
  • Click OK

 

After any registry changes are made, reboot the client workstation and re-launch the APM Edge Client.
