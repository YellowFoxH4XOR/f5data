Topic

A custom blocking response page allows an administrator to specify the content that the BIG-IP ASM system sends to the user when the security policy blocks a client request. The BIG-IP ASM blocking response page is currently limited to 9500 bytes in size.

If the custom blocking page size exceeds 9500 bytes, the BIG-IP ASM truncates the response, and may return illegal HTTP response codes.

With larger blocking page sizes, the BIG-IP ASM may return one of the following error messages, depending on the page size:

  • HTTP response code 200, with a truncated page
  • HTTP response code 2, with no payload
  • HTTP response code 0, with no payload

For example, a blocking response page of 9945 bytes will likely return an HTTP 200 response code with a truncated page. A blocking response page of 10123 bytes may return an illegal HTTP response code of 2, and no message body.

F5 Product Development tracked a Request For Enhancement (RFE) to increase the size limitation. The response page size limitation was raised to 51200 bytes in BIG-IP ASM 11.0.0. This RFE was tracked as ID 223185 (formerly CR128136).
