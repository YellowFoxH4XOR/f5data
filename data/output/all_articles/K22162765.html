Description



An authentication token can be requested for the affected iControl REST user, however a 401 Authorization failed response is returned when using the token in a REST API query.

Environment

  • BIG-IP
  • iControl REST
  • 401 Authorization failed

Cause

Bug ID 718796: iControl REST token issue after upgrade

Recommended Actions

Delete the state maintained by iControlRoleMigrationWorker and let it rerun by restarting restjavad process:

restcurl -X DELETE "shared/storage?key=shared/authz/icontrol-role-migrator"
bigstart restart restjavad

 

Note: There is no expected service impact in deleting the key file as this will be recreated when new related connections are established to the device. Restart of restjavad is also non-service impacting.

None
