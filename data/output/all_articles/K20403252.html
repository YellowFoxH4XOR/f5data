Environment

  • Two boot volumes - the current boot volume (example HD1.1) and an existing boot volume that has been previously booted (example HD1.2)
  • Attempting to activate a boot volume at System  ››  Software Management : Boot Locations, that has been previously booted and already has a configuration, with the 'install configuration' option set to 'yes'.

Cause

Since the boot location that you are trying to activate already has a configuration we are not able to overwrite it.

Recommended Actions

  1. Delete the existing boot volume that you are trying to install the configuration on.
    • System  ››  Disk Management  ››  HD1
  2. Reinstall and create a new boot volume.
    • System  ››  Software Management : Image List
