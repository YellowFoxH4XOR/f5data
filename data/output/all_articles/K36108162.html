Description

  • UDP profiles cannot be configured when licensed for ASM only
  • Under Local Traffic  ››  Profiles : Protocol, UDP is not present and cannot be configured or selected.
  • When configuring objects such as a virtual server the UDP protocol is not present.

Environment

  • ASM only license
  • UDP Profile

Cause

Licensed for ASM only. 

Recommended Actions

If a UDP protocol or profile is necessary then work with your account team to get an LTM license.
