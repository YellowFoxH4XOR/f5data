Known Issue

An 'ERR_BOUNDS connflow' error message may appear in the /var/log/ltm log file, when traffic other than Point-to-Point Tunneling Protocol (PPTP) traffic is being directed to port 1723.

This issue occurs when all of the following conditions are met:

  • Your system is configured for PPTP ALG.
  • Your system is configured for F5 BIG-IP Carrier-Grade NAT (CGNAT).
  • Non-PPTP traffic is being directed to port 1723.

Impact

None. This error message can be safely ignored, but may indicate that another protocol is using port 1723.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Errors similar to the following example appear in the /var/log/ltm log file:

    err tmm5[<PID>]: 01700008:3: Error ERR_BOUNDS connflow <IP>:1723 -> <SRC-IP>:<SRC-PORT> processing pullup of control message.
    err tmm8[<PID>]: 01700008:3: Error ERR_BOUNDS connflow <IP>:1723 -> <SRC-IP:<SRC-PORT> processing egress message.

    In this example error message, note the following:

    <PID> is the Process ID of the tmm process
    <IP> is the PPTP endpoint IP address
    <SRC-IP> is the PPTP client address
    <SRC-PORT> is the PPTP client port
