K000093032: Modifying an IPv6 Virtual Server results in a TMM crash

Type
Support Solution
Published
2022-12-07
Updated
2022-12-07
Source
https://my.f5.com/manage/s/article/K000093032

Description

TMM crashes and the traffic is disrupted after performing changes to the IPv6 configuration. You may observe the same or similar logs to the following:
notice virtio[0:7.0]: MAC filter[27]: 33:33:ff:00:10:01 - deleted
notice virtio[0:7.0]: MAC filter[27]: 33:33:ff:00:10:01 - added

Environment

  • TMM utilizing virtio driver
  • Changes commited to IPv6 listeners

Cause

It is caused by a virtio driver defect. This issue classifies as the bug ID1079769.

Recommended Actions

The solution is upgrading the BIG-IP device to the 17.0.0 software version, in which the virtio driver defect was fixed.

Additional Information

Bug ID 1079769: Tmm utilizing the virtio driver might crash after modifying several IPv6 virtual servers
