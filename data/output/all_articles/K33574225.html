K33574225: ASM Data Guard might masked out Java Script file content if SSN checking been enabled

Source

Description
ASM Data Guard might masked out Java Script file content if "Social Security Numbers" checking been enabled.
Chrome console showing error similar to below,

VM87:1 Uncaught ReferenceError: launchForm is not defined
    at <anonymous>:1:1
(anonymous) @ VM87:1

Environment

  • ASM
  • Data Guard

Cause
Data Guard masked out Java Script file content unexpectedly.

Recommended Actions
You could consider one of the action below,

  • Disable "Social Security Numbers" if not in-used.
    • GUI > Security > Application Security > Data Guard > U.S. Social Security Numbers > uncheck
  • Update exception for that Jave Script URL.
    • GUI > Security > Application Security > Data Guard > Enforcement Mode > Ignore URLs in list > New URL > Input (without quote) "/xxx/xxxx/xxx.js" > click Add button
