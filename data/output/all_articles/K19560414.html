Description

After upgrading the device from older versions to 13.x LDAP monitor fails when LDAP monitor is configured with SSL or TLS for secure LDAP. Pools configured with the LDAP monitor attached are marked down. 
Looking a packets (tcpdump) you see an error similar to the following:

Alert (Level: Fatal, Description: Handshake Failure)

Environment

  • BIG-IP
  • LDAPS communication between BIG-IP and authentication server
  • Upgrade

Cause

LDAP server needs specific ciphers to communicate or GCM ciphers requiring SHA256 and SHA384. 

Recommended Actions

1. Modify openldap configuration file to change the ciphers used for LDAPS monitors. 
With the text editor of your choice modify the /etc/openldap/ldap.conf file to add the following entry:
Note: TLS_Cipher_Suite configures what ciphers will be accepted and the preference order.

TLS_CIPHER_SUITE

Example ciphers:

  • TLS_CIPHER_SUITE ECDHE-ECDSA-AES256-GCM-SHA384
  • TLS_CIPHER_SUITE ECDHE:TLSv1:TLSv1_1


 


 


Your config file should then look similar to the following example:

# LDAP Defaults
#
# See ldap.conf(5) for details
# This file should be world readable but not world writable.
#BASE   dc=example,dc=com
#URI    ldap://ldap.example.com ldap://ldap-master.example.com:666
#SIZELIMIT      12
#TIMELIMIT      15
#DEREF          never
TLS_REQCERT     never
TLS_CACERTDIR   /etc/openldap/certs
TLS_CIPHER_SUITE ECDHE-ECDSA-AES256-GCM-SHA384 



Important: Cipher definition syntax must be closely observed, as configuration errors in /etc/openldap/ldap.conf file will cause the cipher suite not to work as expected. Refer to Cipher Strings with openldap / NSS



2. Save the config using below command:
tmsh save sys config 


Note: You can also configure LDAP servers to not be dependent on ciphers which BIG-IP is presenting in SSL handshake


Additional Information


You can use the command  openssl ciphers -v ALL  to obtain a verbose list of available cipher specifications.
Besides the individual cipher names, the specifiers HIGH, MEDIUM, LOW, EXPORT, and EXPORT40 may be helpful, along with TLSv1, SSLv3, and SSLv2.
