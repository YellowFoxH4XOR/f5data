Description

  • After migration, seeing intermittent ping packet loss to the Gateway device to reach the vCMP guest Management IP address; thus, cannot get to the vCMP Mgmt GUI at times.
  • Intermittent issue of reaching the vCMP Management GUI.  To reach the vCMP guest, have to go through a Gateway device.
  • Seeing ping packet loss of 15% to 30% pinging the Gateway device IP address. Ping packet loss is being seen on the vCMP guest itself and on the vCMP HOST pinging the Gateway IP address.
  • tcpdump taken on the vCMP guest on the Gateway IP address shows multiple ARP requests coming from many different IP addresses which should not be the case since the ping test was done from a single device IP address.

Environment

  • vCMP guest
  • vCMP HOST
  • Intermediary Gateway device between vCMP guest and vCMP HOST. 

Cause

Not BIG-IP.   The network allocated duplicate IP addresses on the same management network as on the vCMP guest and vCMP HOST.

Recommended Actions

Determine if duplicate IP address exists on the network.  An example would be the network is allocating IP addresses from a DHCP device that is duplicating the management IP of the BIG-IP.  

Additional Information

None.
