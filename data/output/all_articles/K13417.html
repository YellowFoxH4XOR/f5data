Topic

 

Summary

Beginning in BIG-IP APM 11.0.0, you can use session variables to dynamically pass values to resource objects.

Description

The BIG-IP APM system supports the use of session variables to provide dynamic data to resource objects based on the contents of the session variable. You can use an access policy to access external information, for example, Active Directory group information or client data, such as the client platform. You can assign this data directly to a resource object or assign values to custom variables based on the information that the access policy returns that can be assigned to a resource object.

The following resource object fields can use session variables to dynamically set properties of the object:

  • Portal Access Application URI
  • Redirect ending action URL
  • Network access launch application path and parameters
  • Network access drive mapping path
  • Application tunnel host, application path, and parameters
  • Remote desktop host

Recommendations

When configuring a resource to use a session variable, you should consider the following factors:

  • You must configure the BIG-IP APM system with a type of resource object that you want to assign a session variable.
  • The following example shows how to assign the value of the session variable to each resource type. You must format the session variable for it to be properly evaluated by the resource object. When assigning a session variable to a resource object, use the following format:

    %{<session variable>}

    In this example, note the following:
     
    • <session variable> is the session variable you are assigning to the resource object

      For example:

      %{session.example.uri}

Portal Access Application URI

You can dynamically assign the Application URI of a portal access object using a session variable, as follows. The following example assigns the value of the %{session.example.uri} session variable to the Application URI field. For more information about configuring portal access resources, refer to the Configuring Resources for Portal Access chapter of the BIG-IP Access Policy Manager Portal Access Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Portal Access.
  4. Click the name of the profile to which you are assigning a session variable.
  5. In the Application URI box, type the following:

    %{session.example.uri}

  6. Click Update.

Redirect ending action URL

You can dynamically assign the redirect ending URL of the access policy using a session variable, as follows. The following example assigns the value of the %{session.example.uri} session variable to the Url field. For more information about configuring the Redirect ending action, refer to the Creating Access Profiles and Access Policies chapter of the Configuration Guide for BIG-IP Access Policy Manager.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles.
  4. Click the Edit next to the name of the access policy that contains the Redirect ending action that the session variable will be assigned to.

    The Visual Policy Editor opens.
  5. Click Edit Endings.
  6. In the Url: box, type the following:

    %{session.example.uri}

  7. Click Save.

Network access launch application path and parameters

You can dynamically assign a network access launch application or application parameters using session variables, as follows. The following example assigns the value of the %{session.example.app} session variable to the Application Path field. For more information about configuring network access resources, refer to the Configuring Network Access Resources chapter of the BIG-IP Access Policy Manager Network Access Configuration Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Network Access.
  4. Click the name of the network access resource that you want to configure using session variables.
  5. Click the Launch Applications tab.
  6. In the Application Path box, type the following:

    %{session.example.app}

  7. Click Save.

Network access drive mapping path

You can dynamically assign the network access drive mapping using a session variable, as follows. The following example assigns the value of the %{session.example.drivepath} session variable to the Path field. For more information about configuring network access resources, refer to the Configuring Network Access Resources chapter of the BIG-IP Access Policy Manager Network Access Configuration Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Network Access.
  4. Click the name of the network access resource on which you want to configure an application using session variables.
  5. Click the Drive Mappings tab.
  6. In the Path box, type the following:

    %{session.example.drivepath}

  7. Click Save.

Application tunnel host, application path, and parameters

You can dynamically assign an application tunnel host, application path, or application parameters using session variables, as follows. The following example assigns the value of the %{session.example.app.parameters} session variable to the Parameters field. For more information about configuring application tunnel resources, refer to the Configuring App Tunnel Access chapter of the BIG-IP Access Policy Manager Application Access Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Application Access.
  4. Click the name of the application resource for which you want to configure an application using session variables.
  5. Click the name of the Resource Item you want to configure to use session variables. 
  6. In the Parameters box, type the following:

    %{session.example.app.parameters}

  7. Click Save.

Remote desktop host

You can dynamically assign a remote desktop host using session variables, as follows. The following example assigns the value of session variable %{session.example.host} to the remote desktop Host Name. For more information on configuring remote desktop resources, refer to the Configuring Remote Desktop Access chapter of the BIG-IP Access Policy Manager Application Access Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Application Access.
  4. Click the Remote Desktops tab.
  5. Click the name of the remote desktop resource that you want to configure using a session variable.
  6. In the Host Name box, type the following:

    %{session.example.host}

  7. Click Save.
