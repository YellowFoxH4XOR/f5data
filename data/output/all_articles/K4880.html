K4880: FirePass may insert an HTML navigation script into a JavaScript source file

Topic



FirePass inserts a small section of HTML that contains JavaScript that displays the Home and Logout navigation links for FirePass, into HTML files. If a file's MIME content type is not set correctly, FirePass may insert this section of JavaScript into file types other than HTML. If FirePass inserts the JavaScript into a file that contains JavaScript, Java, or other types of code, it may cause issues.

To specify the types of files in which FirePass should not include the JavaScript for the Home and Logout navigation functions, perform the following procedure:

  1. Log in to the Administration Console.

  2. From the main navigation pane, click Portal Access.

  3. From the upper navigation pane, click Web Applications.

  4. From the menu, select Content Processing.

  5. Click the Global Settings tab.

  6. In Enter the comma-separated list of URL patterns... field of the Home/Logout tab injection section, enter the full URL for the file in which you do not want the JavaScript included.

  7. Click the Update button.
