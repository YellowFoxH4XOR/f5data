K6959: The FirePass Web UI is inaccessible after an SSL cipher strength change

Published
2010-06-30

Applies to

  • FirePass: 6.0.2, 6.0.1, 6.0.0
Source

Topic

When you change the SSL Cipher Security setting on the Device Management: Security: User Access Security page, you must restart the FirePass services before leaving the page. When you change the SSL cipher security grade (strength of the cipher), the following message appears:

You must restart the FirePass services before leaving this page, or you will not be able to log back into the FirePass Administrative Console (unless you manually restart the FirePass controller). Click here to restart the FirePass services.

Failure to restart the FirePass services before leaving the Device Management: Security: User Access Security page will prevent administrators from logging on to the FirePass Administrative Console, and it will prevent users from logging on to the FirePass webtop. Browsing other FirePass pages before restarting services may produce an error message similar to the following example:

SSL ciphersuite RC4-MD5 not permitted. Please see your system admin.

You can recover from this situation by logging on to the FirePass Maintenance Console as the user maintenance, and restarting the FirePass controller from the maintenance menu. For more information about connecting to and using the FirePass Maintenance Console, refer to the FirePass Controller Getting Started Guide.
