Description

An ASM Apply Policy operation may appear to hang when an automatic Attack Signature or Bot Signature update is being installed concurrently. The operation completes automatically after the signature update finishes.

Example: 

Automatic signature update starts at ~10AM

User applies a policy after some modification few minutes later.
asm:Aug 20 10:05:45 bigip1 info perl[4257]: 01310053:6: ASMConfig change: Apply Policy Task Apply Policy Task (1787227905.113534) [add]: Target Policy was set to /Common/WAF-Policy_1. { audit: username = user1, client IP = 192.168.100.100 } 

asm:Aug 20 10:05:46 bigip1 info perl[4257]: 01310053:6: ASMConfig change: Apply Policy Task Apply Policy Task (1787227905.113534) [update]: Status was set to STARTED. Execution Start Time was set to 1787227905. { audit: username = user1, client IP = 192.168.100.100 }

Signature update takes few minutes to complete, policy apply action only gets completed after that, during this time BIG-IP GUI could be buffering/stuck with policy apply action.

asm:Aug 20 10:09:01 bigip1 info perl[4257]: 01310053:6: ASMConfig change: Apply Policy Task Apply Policy Task (1787227905.113534) [update]: Status was set to COMPLETED. End Time was set to 1787229401. { audit: username = user1, client IP = 192.168.100.100 }

Environment

  • BIG-IP ASM
  • Signature installation setting configured for Real-time
  • Apply Policy initiated while a signature installation was in progress

Cause

The Apply Policy operation is held by the ASM configuration process while a real-time signature update is running. ASM serializes these configuration operations to prevent policy changes while signature data is being modified, avoiding conflicting policy versions or inconsistent configuration.

Answer/Recommended Actions

  1. Wait for the signature update to complete. The Apply Policy operation should complete automatically afterward.
  2. To prevent similar delays during business hours, change the signature installation setting from Real-time to Scheduled.
  3. Schedule signature installations during a defined time, such as overnight where administrative operations are not performed.
