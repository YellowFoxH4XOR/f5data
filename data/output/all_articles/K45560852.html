Known Issue

The Configuration utility's partition selector may not show all objects when you have selected the All [Read Only] option.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system configuration contains multiple administrative partitions that contain configuration objects.
  • You use the Configuration utility's partition selector to view configuration objects in multiple partitions by selecting the All [Read Only] option.

Impact

The Configuration utility does not show all of the objects in each administrative partition.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Some objects are not available when you use the Configuration utility's All [Read Only] option.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
