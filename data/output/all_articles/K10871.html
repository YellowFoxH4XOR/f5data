Known Issue

This is the result of a known issue. The BIG-IP GTM system reports a status of Unknown and is unable to retrieve statistics for the following BIG-IP GTM object types configured with a name longer than 63 characters:

  • Data Center
  • Server
  • Pool
  • Pool Members
  • Links

This issue only affects reporting of the status for an object; it does not affect the actual availability of the object for load balancing.

Note: Configurations using virtual server auto-discovery, and containing duplicate virtual server names in different data centers are more likely to be affected by this issue. In this scenario, the BIG-IP GTM system prefixes the hosting server name to the virtual server name, which keeps the virtual server names unique within the BIG-IP GTM configuration.

F5 Product Development is tracking this issue as ID 335618 (formerly CR133288); BIG-IP iHealth may list Heuristic H383257 on the Diagnostics > Identified > Medium screen.

Workaround

You can work around this issue by reducing the object name to fewer than 64 characters or numbers.
