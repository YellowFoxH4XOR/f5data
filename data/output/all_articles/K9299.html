K9299: New administrative password must contain at least eight characters

Source

Topic

The default administrative (superuser) password for FirePass is admin. However, if you change the administrative password on the Device Management : Security : Admin Name and Password page, the new password must contain at least eight characters. You cannot reset the password to admin on the Device Management : Security : Admin Name and Password page; however, you can reset the password to admin using the FirePass Maintenance Console.

Note: For more information, refer to K2829: Resetting the FirePass administrative password to the default setting.
