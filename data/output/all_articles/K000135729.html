Description

Activation/reactivation SPK License.

The SPK supports two licensing modes:

  • disconnected - When the CWC does not have access to the internet, each licensing task must be performed manually.
  • connected - When the CWC has access the internet, it can automatically perform each of the licensing tasks.

Environment

  • SPK

Cause

Instruction for activation/reactivation SPK License

Recommended Actions

Preparation steps before applying SPK license:

  • Determine the location of CWC API certificates folder “~/api-server-secrets/ssl/” for  client_certificate.pem, ca_certificate.pem cwc_api, client_key.pem cwc_api files

  • Obtain the name of oc for CWC Pod in the cluster:

oc get pods -n spk-telemetry | grep f5-spk-cwc

e.g.

f5-spk-cwc-75b9c9c956-fmzk6   2/2     Running

  • Obtain the IP address for the node the CWC Pod is scheduled on

oc describe pod f5-spk-cwc-75b9c9c956-fmzk6 -n spk-telemetry | grep Node:

e.g.

Node:             wask-spk180-worker2/10.105.174.138

Activation SPK license  

  1. Generate JWT token license based on CAT:
    Node: In the case of disconnected mode, the following command should be run from another server that has an Internet connection.

curl --location --request POST 'https://f5-nonprod-ihealth-test.apigee.net/ee/v1/utility/cats/generate' --header 'Content-Type: application/json' --data-raw '{  "sourceCAT": "TST-XXXXXXXXXXXXXXXXXXXXX", "program": "limit-enforce", "generateJWT": true, "extendedLimits": true }' | jq

or download JWT token license from MyF5  account

  1. Check CWC license status and wait for state: Config Report Ready to Download

curl -s -k --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key client/secrets/client_key.pem https://<IP node with CWC>:30881/status | jq

  1. Download the CWC license report for the cluster

curl -k  --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key  client/secrets/client_key.pem https://<IP node with CWC>:30881/report | jq

  1. Send license report to F5 licensing server for acknowledgement
    Node: In the case of disconnected mode, the following command to send the license report to the F5 license server for confirmation should be run from another server that has an Internet connection.

curl --location --request POST 'https://product-tst.apis.f5networks.net/ee/v1/entitlements/telemetry' --header 'F5-DigitalAssetId: <DigitalAssetId from status>' --header 'User-Agent: SPK' --header 'F5-TraceId: <uniq trace id>' --header 'Authorization: Bearer <new JWT from generate>' --header 'Content-Type: application/json' --data-raw '{"report": "<data from report>"}'

  1. Send the acknowledged manifest to CWC pod

curl -k --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key client/secrets/client_key.pem https://<IP node with CWC>:30881/receipt -d <manifest from telemetry>

  1. Check CWC license status - > should be Verification Complete

curl -k --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key client/secrets/client_key.pem https://<IP node with CWC>:30881/status | jq
 
Reactivation SPK License:

  1. Generate JWT token license based on CAT:
    Node: In the case of disconnected mode, the following command should be run from another server that has an Internet connection.

curl --location --request POST 'https://f5-nonprod-ihealth-test.apigee.net/ee/v1/utility/cats/generate' --header 'Content-Type: application/json' --data-raw '{  "sourceCAT": "TST-XXXXXXXXXXXXXXXXXXXXX", "program": "limit-enforce", "generateJWT": true, "extendedLimits": true }' | jq

or download JWT token license from MyF5  account

  1. Reactivate SPK License using new JWT token

curl -k  --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key  client/secrets/client_key.pem https://<IP node with CWC>:30881/reactivate -d  <new/old JWT>

Node: For disconnected mode continue point 3.

  1. Check CWC license status and wait for state: Config Report Ready to Download

curl -s -k --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key client/secrets/client_key.pem https://<IP node with CWC>:30881/status | jq

  1. Download the CWC license report for the cluster

curl -k  --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key  client/secrets/client_key.pem https://1<IP node with CWC>:30881/report | jq

  1. Send license report to F5 licensing server for acknowledgement
    Node: In the case of disconnected mode, the following command to send the license report to the F5 license server for confirmation should be run from another server that has an Internet connection.

curl --location --request POST 'https://product-tst.apis.f5networks.net/ee/v1/entitlements/telemetry' --header 'F5-DigitalAssetId: <DigitalAssetId from status>' --header 'User-Agent: SPK' --header 'F5-TraceId: <uniq trace id>' --header 'Authorization: Bearer <new JWT from generate>' --header 'Content-Type: application/json' --data-raw '{"report": "<data from report>"}'

  1. Send the acknowledged manifest to CWC pod

curl -k --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key client/secrets/client_key.pem https://<IP node with CWC>:30881/receipt -d <manifest from telemetry>

  1. Check CWC license status - > should be Verification Complete

curl -k --cert-type PEM --cacert ca/certs/ca_certificate.pem --cert client/certs/client_certificate.pem --key client/secrets/client_key.pem https://<IP node with CWC>:30881/status | jq
 

Additional Information

Abbreviations:

  • JWT - JSON Web Token

  • CAT - Customer Association Token – unique CAT

  • CWC - Cluster Wide Controller - enables SPK’s software licensing and billing capabilities. Once the SPK software is installed and licensed, the CWC collects and reports software usage telemetry statistics based on the number of SPK CRs used by the licensed BIG-IP Controller instances in the cluster. SPK uses F5’s flexible consumption software licensing model, billing only for the SPK features used.
