Description

SUDO command not found on BIG-IP appliance.

Environment

  • BIG-IP appliance platforms
  • SUDO command

Cause

Beginning in version 12.0.0 up, the SUDO rpm is shipped with the ISO. The first SUDO version shipped is 1.8.6p3 and was updated to 1.8.6p7 in version 14.1.0. This rpm was included ONLY for CLOUD environments.

On BIG-IP appliances generally, bash access is limited to root/admin roles limiting the impact of any privilege escalation vulnerabilities. No other users are allowed to have bash access. So no SUDO rpm is in our hardware platforms.

Recommended Actions

None, it is by design.

Additional Information

None.
