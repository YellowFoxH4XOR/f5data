K000135144: Multiple connections per peer in SDC

Type
Support Solution
Published
2023-06-25
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K000135144

Description

  • The SDC supports multiple connections between one dynamic client peer and the FEP. The client peer needs to be configured with a peer profile that invokes a Capabilities Exchange Answer script. Once this script is invoked, each new connection of the same peer is considered as a new peer with the same Origin Host name followed by a suffix (SN_<index #>).
  • This depends on customer requirement, if customer has peers that open multiple connection , this must be turned on. 

Environment

  • Traffix SDC 5.x

Cause

By Design.

 Recommended Actions

None.

Additional Information

See Section 3.3.1.4 of SDC user guide.
