Known Issue

Using the Traffic Management Shell (tmsh) to create or modify a monitor send or receive string may fail with an error.

This issue occurs when the following condition is met:

  • You use the tmsh utility to create or modify a monitor with a send or receive string that uses a backslash (\) to escape a double quotation mark (") character.

Impact

Users may not be able to modify monitor send or receive strings using the tmsh utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H508458 on the Diagnostics > Identified > Low screen.
  • The system displays an error message similar to the following example:

    01070642:3: Monitor /Common/<monitor_name> parameter contains unescaped " escape with backslash

Workaround

To work around this issue, you can use the Configuration utility to create or modify your monitor send or receive string. Alternatively, using the tmsh utility, you may use a triple backslash to escape double quotation marks. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. The following is an example of a receive string which would be entered into the Configuration utility:

    RESPONSE ERROR=\"0\"

    To enter this receive string using the tmsh utility, use the following command syntax, replacing <monitor_name> with the name of the monitor you want to modify:

    modify ltm monitor http <monitor_name> recv "RESPONSE ERROR=\\\"0\\\""

  3. Save the changes by typing the following command:

    save /sys config
