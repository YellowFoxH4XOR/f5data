Description
 

On rare occasions, one may see something like the following error when newly importing a BigIP to Big IQ:


Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: %s: (ava.lang.lllegalArgumentException: Property'name' value 'HTML5Client_primaryToolbarButton-mypage@2cs.png 364595829_176’ has an invalid character that is not in the allowed set of characters '-a-zA-Z .0-9'.

Environment

  • BIG-IP
  • BIG-IQ
  • APM

Cause

A filename as found in the BIG-IP configuration contains one or more characters that are not accepted by BIG-IQ.  The only characters that are acceptable to Big IQ are any combination of letters, numbers, a hyphen, an underscore, or a period - the same as any configuration object in BIG-IP.  The difference is that BIG-IP will not check the filename for this syntax and will accept the file independently of the BIG-IQ

Recommended Actions

If this error ever occurs, go back to the Big IP, locate the file, and either a) rename it or b) remove the file from BIG-IP and re-upload with a corrected name.  

Additional Information

If BIG-IQ returns this error and the file does not exist in the expected location (for instance, certain custom image files for APM policies), please see K99520832.
