K000158821: F5OS-A - Not recording mgmt interface link down/up events

Type
Support Solution
Published
2025-12-17
Updated
2025-12-17
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000158821

Description

On F5OS-A version 1.8.3 running on r4600 (C131) hardware, management interface link down/up events (such as unplugging the cable or disabling the port on the connected switch) are not detected or logged in platform.log.

Environment

  • F5OS-A version 1.8.3
  • Actions: Management interface physical cable unplug/plug or port disable/enable on connected switch

Cause

Bug ID 2185853

Recommended Actions

  • None at this time. However, when more details become available, this solution article may be updated.
  • There is no functional impact. Interface state changes can be still read from Confd.

Additional Information

None
