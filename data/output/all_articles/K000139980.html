K000139980: Does BIG-IP provide bandwidth usage statistics for virtual servers

Published
2024-09-04
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000139980

Description

Does BIG-IP provide bandwidth usage statistics for virtual servers

Environment

  • BIG-IP
  • Network Bandwidth
  • Network Statistics

Cause

No, BIG-IP only provides point-in-time network statistics.

Recommended Actions

Use SNMP to regularly poll the BIG-IP to gather statistics over time and use a 3rd-party Network Management product to query the data to provide the reporting needed.

Additional Information

None
