K000132911: [F5OS] Does F5OS support hardware acceleration for tenant on DNS query load balancing and validating resolver cache.

Source

Description

  • Does F5OS support hardware acceleration for tenant on DNS query load balancing and validating resolver cache.

Environment

  • F5OS-C (VELOS)
  • Tenant (DNS provisioned)
  • DNS query load balancing and validating resolver cache.

Cause

None.

 Recommended Actions

We never have this functionality performed by FPGA.

Currently, on VELOS systems, BIG-IP tenants are running like a vCMP guest and vCMP guests are not supported to have these features.
