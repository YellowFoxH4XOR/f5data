K10165: The show nsm command now displays a per processor status

Type
Knowledge
Published
2009-10-06
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • ARX: 5.0.5, 5.0.1, 5.0.0
Source
https://my.f5.com/manage/s/article/K10165

Issue

Beginning in ARX 5.0.0 the show nsm command will display a per processor status for NSM Recovery and NSM Binary Core Files. The show nsm command output will appear similar to the following:

Recovery:

                Status
Proc     Admin        Operational
------   ----------   ------------
1.2      Enabled      Enabled       
1.3      Enabled      Enabled       
1.4      Enabled      Enabled       
1.5      Enabled      Enabled      

Binary Core Files:

                Status
Proc     Admin        Operational
------   ----------   ------------
1.2      Enabled      Enabled       
1.3      Enabled      Enabled       
1.4      Enabled      Enabled       
1.5      Enabled      Enabled

Previous ARX versions of the show nsm command will display a per slot status for NSM recovery and NSM binary core files. The show nsm command output for previous versions will appear similar to the following example:

Note: For information about modifying the enabled/disabled status of the NSM recovery and NSM binary core files features, refer to the nsm recovery and nsm binary-core-files sections of the ARX CLI Reference Guide.

Recovery:

                Status
Slot     Admin        Operational
------   ----------   ------------

1        enabled      enabled

Binary Core Files:

                Status
Slot     Admin        Operational
------   ----------   ------------
1        enabled      enabled
