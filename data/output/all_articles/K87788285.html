Issue

Error Message

notice sod[<PID>]: 010c006d:5: Leaving Standby for Active: No network failover, serial only

In this error message, note the following:

  • <PID> is the process ID of the sod process.

For example:

notice sod[6738]: 010c006d:5: Leaving Standby for Active: No network failover, serial only

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions is met:

  • Network Failover is disabled in the sync-failover device group

This message is logged when the BIG-IP system is configured to be a member of a sync-failover device-group that does not have Network Failover enabled. Because you cannot use serial failover in BIG-IP Virtual Edition (VE) high availability (HA) systems and device group configurations containing more than two BIG-IP systems, you won't observe this error message in both situations.

Impact

The BIG-IP system transits to the active state on the local system and depends only on the serial failover cable to maintain the active-standby state of the HA pair. Network failover is not used. This message is usually accompanied by the two BIG-IP systems in the HA pair entering the active-active state.

Recommended Actions

F5 recommends that you enable Network Failover in the HA device group of your BIG-IP systems. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Device Groups.
  3. Click the name of your sync-failover device group.
  4. For Configuration, click Advanced.
  5. For Network Failover, select the Enabled check box.
  6. Click Update.

When configuring network failover, you should also dedicate one interface on each system to perform only failover communications and configure two channels for network failover communications. One using the management address and the other using a Traffic Management Microkernel (TMM) network address.
