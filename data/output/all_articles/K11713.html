Note: For information about displaying the version information for the ARX system, refer to K8757: Displaying the software version for the ARX system.

Note: For information about displaying the version information for other F5 products, refer to K914: Displaying the software version of your F5 Networks product.

You can display ARX Secure Agent software version information using the following procedure:

  1. Log in to the Microsoft Windows domain controller on which the ARX Secure Agent is installed.
  2. Open the Control Panel.
  3. Select Secure Agent.
  4. Click the Control tab.
  5. The Software Version displays, appearing similar to the following example:

    Version 5.01.005.11972 (May 17 2010 22:07:37) [jc] HF2 [32-bit]
