K52454288: Management IP address is set to 127.0.0.1 after upgrade to v14.1.x or later

Type
Support Solution
Published
2022-02-14
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K52454288

Description
After an upgrade to a v14.1.x or later in a Cloud Environment, you lose access to the Graphic User Interface (GUI).
The GUI was working fine before the upgrade.
After accessing the GUI through a self-IP, and running the command "tmsh list /cm device", the output for the management interface is:

management-ip 127.0.0.1

Environment

  • Cloud Environment
  • Upgrade to v14.1.x or later
  • Auto-last Hop

Cause
For BIG-IP VE 14.1.0 and later, you must configure a management IP and route if you use the management interface to access the BIG-IP system from outside of the local subnet. The management interface no longer supports Auto Last Hop for management connections.

Recommended Actions

  1. Re-configure the management IP

tmsh create /sys management-ip <address>/<netmask>

  1. Configure a management route
tmsh create /sys management-route <name> network <destination network>/<netmask> gateway <management gateway>

Replace <name> with the name you want to use to identify this route. Replace <destination network>/<netmask> with the IP address and netmask of the network you are routing to. Replace <management gateway> with the IP address of the router used to access the destination network.

  1. Save the configuration

tmsh save /sys config
