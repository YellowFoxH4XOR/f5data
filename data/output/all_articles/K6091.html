Topic

Understanding which Tool Command Language (Tcl) version on BIG-IP is used to process iRules.

Description

Tcl version for iRules

The BIG-IP iRules feature uses the industry-standard Tcl, which you can use to create scripts for managing local network traffic. The BIG-IP iRules command set was developed from Tcl base version 8.4.6, which is used in all BIG-IP versions.

You can see the iRule Tcl version by writing an iRule similar to the following example, and then viewing the version output in the /var/log/ltm file:

when RULE_INIT {
 log local0. "puts $tcl_patchLevel"
}

Example output from the /var/log/ltm file:

info tmm[17203]: Rule /Common/tcl_version : puts 8.4.6

Tcl version for Extended Application Verification (EAV) monitors

The BIG-IP system also includes a separate Tcl interpreter, which can be used to write Extended Application Verification (EAV) monitors, but this interpreter is not used for iRules processing. You can see the Tcl version available to EAV monitors by running the following command from the BIG-IP Advance Shell (bash):

echo 'puts [info patchlevel];exit 0' | tclsh

On BIG-IP 15.0.0, the output looks similar to the following example:

8.5.13

Note: You cannot use all Tcl commands with iRules. For a list of Tcl commands that have been disabled, refer to the following articles:

  • K36322151: List of disabled Tcl commands for iRules (12.x - 17.x)
  • K15909: List of disabled Tcl commands for iRules (11.x)
