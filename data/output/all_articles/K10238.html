Known Issue

This is the result of a known issue. After connecting and disconnecting the Network Access client numerous times on a Windows Mobile 5 device, Network Access may fail to reconnect with an error message that appears similar to the following example:

driver load error = 2
 
F5 Product Development tracked this issue as CR120600 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.
 
This issue has been fixed in cumulative HF-603-3 issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
Users can work around this issue by performing a soft reset on the Windows Mobile device.
