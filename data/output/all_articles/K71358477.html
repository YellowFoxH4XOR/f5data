Description

Only the past hour of logs or 1 day of logs are displayed in BIG-IP AFM device under Security > event logs > network > firewall.

Environment

  • Logging is enabled for traffic rule under for Network Firewall policies
  • Logging profile is configured to log locally for Network Firewall events
  • BIG-IP AFM logs are appearing locally

Cause

When using local-db-publisher,  number of messages stored is capped at 1.25 million. Oldest logs are get automatically removed.

Recommended Actions

 We recommend to use external log server for high amount of logging,
