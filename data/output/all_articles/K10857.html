K10857: The vs_depends_server_state global variable is not configurable using the Configuration utility in BIG-IP GTM version 10.0.x

Topic

In BIG-IP GTM 10.0.x, the vs_depends_server_state global variable allows a BIG-IP GTM administrator to specify whether the virtual server status depends on the current state of an iQuery connection between the BIG-IP GTM system and the BIG-IP LTM device hosting the virtual servers.

In versions 10.0.0 through 10.0.1, this variable is not configurable using the Configuration utility and can only be configured using tmsh, or by editing the wideip.conf file directly.

F5 Product Development tracked a Request for Enhancement (RFE) to allow this variable to be configured using the Configuration utility as CR91741, and it was added to BIG-IP GTM 10.1.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Note: For information about configuring the global variable in BIG-IP GTM 10.x, refer to K10835: Specifying GTM virtual server dependence on the iQuery connection state in GTM 10.x.
