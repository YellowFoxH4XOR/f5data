Known Issue

The istatsd process may produce a core file in the /shared/core directory when it encounters invalid data.

This issue occurs when the following condition is met:

  • The istatsd process attempts to read corrupt iStats data files.

Impact

The istatsd process restarts due to resource exhaustion.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The istatsd process continually consumes memory, producing a core file which causes the istatsd process to restart.

Resolution

Status

Workaround

To work around this issue, you can remove the iStats files and restart the istatsd process. To do so, perform the following procedure:

Impact of workaround: The following procedure will reset all statistics in the iStats data files.

  1. Log in to the BIG-IP command line.
  2. To stop the istatsd and related processes, type the following command:

    tmsh stop sys service istatsd avrd merged

  3. To delete the iStats data files, type the following command:

    find /var/tmstat2/ -depth -type f -delete

  4. To start the istatsd and related processes, type the following command:

    tmsh start sys service istatsd avrd merged
