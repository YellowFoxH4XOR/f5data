K000134790: rSeries sends DNS Queries to Google Servers 8.8.8.8 and 8.8.4.4

Description

rSeries sends DNS query to public DNS servers 8.8.8.8 and 8.8.4.4.

Environment

  • rSeries
  • Docker
  • DNS

Cause

When there is no DNS server configured on host, docker will use 8.8.8.8 and 8.8.4.4 to forward the DNS requests from docker containers. This is how docker behaves by default.

Recommended Actions

Configure a DNS server on the system, then restart the appliance system.

Note: Restarting the appliance can cause a brief impact to system availability. A maintenance window is recommended.

If you are unable to configure a valid DNS server, you can set a fake internal IP which does not exist. This will prevent queries going to 8.8.8.8 and 8.8.4.4. Appliance system restart is still required.
