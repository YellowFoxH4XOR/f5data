Topic

FirePass stores a variety of details about a user's session in a series of variables called session variables. You can use session variables in a pre-logon sequence to log information and perform actions based on session data. Session variables are populated with information about the user's session during the pre-logon sequence. Additional session variables are defined during group mapping and user authentication. During dynamic group mapping and user authentication, the FirePass controller retrieves user attributes from the external Active Directory and LDAP servers. The system then converts these attributes to session variables.

The following procedures outline how to use a session variable for logging and performing custom actions based on the value of session variables:

Testing the information logging pre-logon sequence

Using session variables to log information

  1. Log on to the FirePass Administrative Console using your admin account.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence page.
  3. In the Create new sequence field, enter a name for the pre-logon sequence.
  4. In the Based on menu, select template: Empty.
  5. Click the Create button.

    The new pre-logon sequence appears in the Select Sequence to Use section.
  6. Click edit next to the pre-logon sequence you just created.

    The Pre-Logon Sequence Editor opens.
  7. Mouse over the Go action.

    A plus sign (+) appears to the right of the Go action.
  8. Click the plus sign.

    The Change Sequence panel opens.
  9. Select the Write to Logon log option button.
  10. Click the Apply changes button.

    The Edit Action panel opens.
  11. Click Logger under the Inspectors section.

    The Endpoint Inspector Details panel opens.
  12. In the Expression text box, type text and session variable names that will be written to the log.

    For example:

    Client IP address : %session.network.client.ip%
    Client OS : %session.os.platform%
    Client Browser : %session.browser.user_agent%
  13. Click the Update button.

    The Endpoint Inspector Details panel closes.
  14. Click the Close Panel link.
  15. Click the Back to console link at the upper right corner of the page.

    Important    : Applying a pre-logon sequence will cause the sequence to immediately take effect.
  16. Under the Select Sequence to Use section, click the option button next to the pre-logon sequence you just edited.
  17. Click the Apply button.

Testing the information logging pre-logon sequence

  1. Log in to Firepass using the username and password of a test user.
  2. Log out of FirePass.
  3. Log in to FirePass again using the same test user account.
  4. Navigate to the Reports : Logons page.
  5. Click the user name you used to log in from Step 1.

    The report window opens.
  6. Scroll to the Pre-logon log messages section.

    Log entries will appear similar to the following example:

    pre-logon: Client IP address : 010.001.001.010
    Client OS : Win7
    Client Browser : Mozilla/4.0 (compatible; MSIE 7.0; Windows NT 6.1; WOW64; ...)

Testing session variables in a pre-logon sequence action

FirePass has the ability to perform comparisons of session variables and take action on the results of the comparison in a pre-logon sequence. You can use any of the listed operators to combine multiple comparison tests:

Boolean operators

  • AND
  • OR
  • NOT

Relational operators

  • <  (less than)
  • <= (less than or equal to)
  • > (greater than)
  • >= (greater than or equal to)
  • == (equal to)
  • != (not equal to)
  • EXIST()

Function

  1. Log on to the FirePass Administrative Console using your admin account.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence page.
  3. In the Create new sequence field, enter a name for the pre-logon sequence.

    For example:

    WeekendNoLogon
  4. In the Based on menu, select template: Empty.
  5. Click the Create button.
  6. The new pre-logon sequence appears in the Select Sequence to Use section.
  7. Click edit next to the pre-logon sequence you just created.

    The Pre-Logon Sequence Editor opens.
  8. Mouse over the Go action.

    A plus sign (+) appears to the right of the Go action.
  9. Click the plus sign.

    The Change Sequence panel opens.
  10. From the Using drop-down menu, select New action.
  11. Click the Apply changes button.

    The Edit Action panel opens and the new action is inserted into the sequence.
  12. Mouse over the output branch of the New action action.

    A plus sign (+) appears on the branch.
  13. Click the plus sign.

    The Insert Rule panel opens.
  14. In the name field, enter a name for the output branch.

    For example:

    Day is Weekend
  15. In the Expression text box, enter a rule expression that will be evaluated.

    For example:

    session.datetime.dayofweekstr == "Sat" OR session.datetime.dayofweekstr == "Sun"

    Note: In the example, the session variables are not surrounded by  percent characters (%) because we are performing a comparison of the session variable. The percent character is used when assigning or retrieving the value of a session variable. The rules expressions can be complex and evaluate several conditions. All rules must evaluate to a true or false condition. You cannot assign values to session variables in a rule.

    Important: Checks are case sensitive; for example, Sun and sun are treated differently. Keywords are case sensitive and are entered in upper case; for example OR, AND, and NOT.
  16. Click the Update button.

    You will see a new branch created on the output of the New action action that connects to a Logon Denied Page ending.
  17. Click Logon Denied Page.

    The END PAGE PROPERTIES panel opens.
  18. In the Message for User text box, enter text that you want to display to the user.

    For example:

    Logon is prohibited on the weekend.
  19. Ensure that the Fallback branch has a Logon Allowed Page ending.
  20. Click the Update button.
  21. Click the Back to console link at the upper right corner of the page.

    Important: Applying a pre-logon sequence will cause the sequence to immediately take effect.
  22. Under the Select Sequence to Use section, select the option button next to the pre-logon sequence you just edited.
  23. Click the Apply button.
