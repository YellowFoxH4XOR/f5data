Topic

The RTSP protocol is based on the same structure as HTTP/1.1; therefore, you can use the same mechanisms to make content decisions in RTSP as you would in HTTP/1.1. The support for RTSP is valid back to the initial implementation of rules in BIG-IP version 3.0.

Note: For details about HTTP/1.1, refer to RFC2616. For details about RTSP/1.0, refer to RFC2326.

Although BIG-IP rules are named as if they are HTTP-specific, they are actually flexible enough to use any protocol designed in the same structure as HTTP.

Following is an example of a RTSP rule:

rule rtsptest { 
   if (http_method equals 'ANNOUNCE') { 
    redirect  to 'rtsp://www.bob.com/' 
   }              
}

Although this is a simple rule, any of the advanced rule features available to HTTP are also available to RTSP and similar protocols. Notice that ANNOUNCE is used as the method. This is not a valid HTTP method, but this rule works anyway. In addition, notice that the rule performs a redirect to an RTSP host, rather than an HTTP host.

Note: The redirect functionality used in the example rule is new to BIG-IP version 4.2.
