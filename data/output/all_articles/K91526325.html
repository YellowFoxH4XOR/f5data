Description
This article describes the method to verify SafeNet client version when used with BIG-IP platform HSM.

Environment

  • SafeNet client is used with BIG-IP hardware appliance 

Cause
None

Recommended Actions

  1. To list the version, run the command
    # more /shared/safenet/nethsm_safenet_supportInfo.txt
  2. Sample of the output
    =====================================================================
            CLIENT INFORMATION and DATE/TIME
    =====================================================================
    vtl version: 5.2.1.6
     

Additional Information
If the version of SafeNet client is not compatible with the HSM platform, SSL handshake fails. To determine the compatible version refer the below information. 
Supplemental Document : Interoperability Matrix for BIG-IP TMOS with SafeNet Clients and HSM
