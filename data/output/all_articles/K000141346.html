Description

BIG-IP may log error message "Error Message: 01010011:3: Persistence cookie hash failed <connection_info>"

In this error message, note the following <connection_info> which is related to the BIG-IP system configuration information pertaining to the error:

  • Client side or Server side - The side of the proxied connection.
  • vip - The virtual server for the connection.
  • profile - The cookie hash persistence profile for the connection's persistence entry.
  • pool - The load balanced pool name for the connection.
  • client_ip or server_ip - The IP address of the client or server.

 

  • Error messages logged in /var/log/ltm

01010011:3: Persistence cookie hash failed (Client side: vip=/Common/http_vs profile=http pool=/Common/http_pool client_ip=192.0.2.1)

01010011:3: Persistence cookie hash failed (Server side: vip=/Common/http_vs profile=http pool=/Common/http_pool server_ip=198.51.100.10)

Environment

  • BIG-IP module which has an HTTP virtual server
  • Cookie hash persistence profile configured to persist client connection requests to a given pool member
  • Cookie hash profile attached to the HTTP virtual server

Cause

Client side error: The client makes an HTTP request inserting the cookie name configured in the cookie hash persistence but the cookie value is NULL.

Server side error: The pool member response to an an HTTP request inserting the cookie name configured in the cookie hash persistence but the cookie value is NULL.

Recommended Actions

The log information is informational, no action on the BIGIP but recommended to check why the client or pool member are not inserting the relevant cookie value.

Additional Information

Note: If a client makes a request and the request contains the cookie defined in the cookie hash persistence and has a valid value but there is no persistence entry the BIGIP will load balance the request and create a persistence entry linked to the load balanced pool member.
