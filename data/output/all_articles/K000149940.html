K000149940: How to generate report with virtual servers from imported config on BIG-IQ using API call

Description

Following article describes the steps to generate CSV report with imported virtual servers, containing name, ip, port, snat details, 
using REST API call on BIG-IQ.

Environment

  • BIG-IQ CM
  • virtual server report

example:
Device name, VS name, Ip, port , status, snat type, snat pool
ltm1.local, VS_1, 10.0.0.100, 443, enabled, , automap, 
ltm1.local, vs_443, 10.0.0.200, 443, enabled, pool1, snat, ssnat1
ltm1.local, vs2_443, 10.0.0.201, 443, enabled, pool2, snat, ssnat2

Cause

None

Recommended Actions

Note: Basic authentication is disabled on BIG-IQ by default and requests requires token creation.

1. Request token: 
curl -sk -X POST https://10.100.100.100/mgmt/shared/authn/login -d "{"username":"admin", "password":"<password>"}"

 

2. Use token to obtain necessary information:

curl -sk -H "X-F5-Auth-Token: __TOKEN_FROM_PREVIOUS_COMMAND_" https://10.100.100.100/mgmt/cm/adc-core/working-config/ltm/virtual | jq -r '.items[] | {device: .deviceReference.name,name,destinationAddress,destinationPort,state,poolName: .poolReference.name, SNATType: .sourceAddressTranslation.type, SNATName: .sourceAddressTranslation.snatpoolReference.name } | join(", ")'
