Known Issue

This is the result of a known issue. When all of the following conditions are met, Internet Explorer 7 (IE7) will fail to run inside Protected Workspace (PWS) and will not automatically display the FirePass login page:

  • A Windows Vista system enters Protected Workspace (PWS)
  • The URL of the FirePass controller is contained in the IE7 Trusted sites list
  • The Protected Mode feature is turned off for the Trusted sites zone

An exception to this condition occurs if the Internet zone of IE7 also has Protected Mode turned off.  In this configuration, IE7 runs normally after you enter PWS, and displays the FirePass login page.  However, the default configuration of IE7 is for the Trusted sites zone to have Protected Mode off, and the Internet zone to have Protected Mode turned on.

F5 Networks Product Development tracked this issue as CR89644 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-601-10 issued for FirePass version 6.0.1 and cumulative hotfix HF-602-1 issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads page.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround


Multiple workarounds are possible, depending on your organization's security policy and other considerations.

Users can manually start IE once the user has entered PWS, then manually enter the URL of the FirePass controller in IE7 to load the FirePass login page, and enter login credentials normally.

Enabling Protected Mode

 

Users can enable Protected Mode for the Trusted sites zone in IE7. To enable Protected Mode, perform the following procedure:

  1. Select Internet Options from the Tools menu from the IE7 menu bar
  2. Click the Security tab.
  3. Click the Trusted sites icon.
  4. Select the Enable Protected Mode (requires restarting Internet Explorer) check box.
  5. Click the OK button.
  6. Close all IE windows.

Removing the FirePass URL from the Trusted sites list

Users can remove the FirePass URL from the Trusted sites list. To remove the FirePass URL, perform the following procedure:

  1. Select Internet Options from the Tools menu from the IE7 menu bar.
  2. Click the Security tab.
  3. Click the Trusted sites icon.
  4. Click the Sites button.
  5. Highlight FirePass URL in the Websites: field.
  6. Click the Remove button.
  7. Click the Close button.
  8. Click the OK button.

Important: To understand the security implications of each of these procedures, consult the Microsoft Internet Explorer documentation.
