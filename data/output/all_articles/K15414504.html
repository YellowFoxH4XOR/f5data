Issue

Error Message

01531015:3: Failed to retrieve next RR in XFR for zone <zone_name>

In this error message, note the following:

  • <zone_name> is the name of the DNS zone file that failed to transfer.

For example:

01531015:3: Failed to retrieve next RR in XFR for zone example.f5.net.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file.
Description

This message occurs when all of the following conditions are met:

  • You have configured DNS Express to perform a zone transfer from a master DNS name server.
  • One of the following occurs during the zone transfer from the master DNS name server:
    • The data in the server response is incomplete or corrupt. 
    • The number of records in the ANSWER section does not match the number indicated in the DNS header.

Impact

If this is the initial zone transfer, DNS Express will not host the zone. If the zone was successfully transferred previously, DNS Express will not receive updates to the zone. If the zone transfer continues to fail and the zone exceeds the expiration time, DNS Express will stop hosting the zone until the next successful transfer.

Recommended Actions

  • If the issue is persistent, configuration and logs on the master nameserver or intermediate network devices should be investigated to determine why the BIG-IP system cannot successfully complete a zone transfer.
  • The BIG-IP system continues to attempt to transfer the zone. Once the issue on the master DNS name server is resolved, DNS Express will be able to transfer and host the zone.
