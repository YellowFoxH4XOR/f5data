K000138213: Enable logging to display flow for an Access Policy VPE

Type
Support Solution
Published
2024-01-12
Updated
2024-01-12
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000138213

Description

This solution will explain how to enable a session variable to log the Object path from a Access Policy Virtual Policy Editor.

  • This will be logged in the apm log file and set the session variable "session.policy.result.policy_path"
  • You can view these in /var/log/apm:

<apm_hostname> notice apmd[13035]: 014902b8:5: /Common/<access_policy_name>:Common:<session_id>: | Start (fallback) | Logon Page (fallback) | Decision Box (Option 1) | LocalDB Auth (Successful) | Advanced Resource Assign (fallback) | Allow | Ending is: Allow


<apm_hostname> info apmd[13035]: 01490007:6: /Common/<access_policy_name>:Common:<session_id>: Session variable 'session.policy.result.policy_path' set to ' | Start (fallback) | Logon Page (fallback) | Decision Box (Option 1) | LocalDB Auth (Successful) | Advanced Resource Assign (fallback) | Allow | '


Environment

  • Access Policy Manager (APM)
  • Virtual Policy Editor (VPE)

Cause

You want to log the Object path from a Access Policy Virtual Policy Editor flow.


Recommended Actions

Enable the db key "tmm.access.policytrace" by command line.

  1.  Login to the APM CLI.
  2. Enter the following tmsh command:

tmsh command:tmsh modify sys db tmm.access.policytrace value enable


[root@<hostname>:Active:Standalone] log # tmsh list sys db tmm.access.policytrace

sys db tmm.access.policytrace {

  value "enable"

}


Additional Information

Typically F5 Support recommends only enabling this logging for troubleshooting purposes.
