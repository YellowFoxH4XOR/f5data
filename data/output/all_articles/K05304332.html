Known Issue

User-run processes may not generate core files when they stop responding.

This issue occurs when all of the following conditions are met:

  • You upgrade your BIG-IP software from a version earlier than 12.0.0 to an affected version.
  • You run a process from within an interactive shell.
  • The process encounters a condition that causes the process to stop responding.

Impact

The failed process does not generate a core file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Processes that encounter conditions that causes the process to stop responding do not produce a core file.

Workaround

To work around this issue, you can modify the system ulimit to allow processes to write core files. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected system with root privileges.
  2. Type the following command to allow processes to write core files:

    ulimit -c unlimited
