K1432: Configuring SNAT for an entire network without using a default SNAT

Topic

You can use a Network SNAT to translate an entire range of IP address without requiring you to enter each IP source address individually or have a default SNAT.

The syntax for the Network SNAT configuration is as follows:

bigpipe snat map <source network> to <SNAT address>
bigpipe snat <source network> netmask <IP netmask>

Important: For the Network SNAT to work, you must include both commands. If you do not include the bigpipe snat <source network> netmask <IP netmask>, the SNAT will exist and you will be able to view it, but it will not translate traffic. The Network SNAT definition will not default to the class subnet mask.

For example, to configure a Network SNAT for the source network 10.10.10.0/24 to the IP address 192.168.23.118, the syntax would be:

bigpipe snat map 10.10.10.0 to 192.168.23.118
bigpipe snat 10.10.10.0 netmask 255.255.255.0

After you configure this Network SNAT, it will translate all packets originating from the 10.10.10.0 network to the external address of 192.168.23.118.

To verify that the SNAT is correctly configured, type the following command:

b snat show

You should see output similar to the following:
