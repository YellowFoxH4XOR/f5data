Description

This is verify if the modulus of the SSL certificate matches the modulus in FIPS using command line. 

Environment

  • BIG-IP
  • FIPS 140

Cause

None

Recommended Actions

    1. Log in to the BIG-IP command line.
       
    2. Locate the SSL certificate and key pair used by the SSL profile using the following table:
       
      FileLocationExample
      certificate/config/filestore/files_d/<partition>_d/certificate_d//config/filestore/files_d/Common_d/certificate_d/
      key/config/filestore/files_d/<partition>_d/certificate_key_d//config/filestore/files_d/Common_d/certificate_key_d/
    3. To obtain the modulus for the SSL certificate, use the following command syntax:
       # openssl x509 -noout -text -modulus -in /config/filestore/files_d/<partition>_d/certificate_d/<name of the certificate>
      For example, if the SSL certificate used by the SSL profile resides on the Common partition, and is named www.test.com.crt, use the following command:
        # openssl x509 -noout -text -modulus -in /config/filestore/files_d/Common_d/certificate_d/\:Common\:www.test.com.crt_65432_1
    4. To obtain the modulus for the SSL private key, use the following command syntax:
       # openssl <rsa|dsa|ec> -noout -modulus -in <path_to_key>/<key_name>
      For example: 
       # openssl rsa -noout -modulus –in /config/filestore/files_d/Common_d/certificate_key_d/\:Common\:www.test.com.key_65432_1
       
    5. To list the key in the HSM.
       # tmsh show sys crypto fips key /<partition>/<name of the key> all-properties
      For example: 
       # tmsh show sys crypto fips key /Common/www.test.com all-properties
