K000162067: Edge Client install / upgrade failed when the macOS client is in the closed network

Description

Installation or upgrade of BIG-IP Edge Client on macOS devices fails in closed network environments where outbound access to ocsp2.apple.com is blocked. The process may repeatedly retry and ultimately fail without displaying a specific error message. Packet capture analysis shows that macOS attempts to reach ocsp2.apple.com for certificate validation during the installation or upgrade process. The issue is observed when network policy prevents outbound access to Apple’s certificate validation servers.

Environment

  • Product: BIG-IP APM
  • Client OS: macOS
  • Feature: Edge Client installation and auto-upgrade
  • Network: Closed/restricted network environment (no outbound access to ocsp2.apple.com)
  • Firewall: Outbound access controlled by IP address and port, not by domain name
  • Observed behavior: Installation/upgrade fails on all macOS clients in the restricted environment; succeeds when outbound access is temporarily allowed

Cause

The failure occurs because macOS requires access to Apple’s certificate validation servers (such as ocsp2.apple.com) to validate the code-signing certificate of the installer. When this access is blocked, the installation or upgrade process cannot complete successfully.

Answer/Recommended Actions

  • Confirm that the installation package is valid and the client OS is healthy.
  • If installation or upgrade fails only when outbound access to ocsp2.apple.com is blocked, the likely cause is macOS code-signing certificate validation requirements.
  • There is no F5-supported method to bypass or disable code-signing certificate validation during Edge Client installation or upgrade on macOS.
  • If your environment restricts outbound access by IP and cannot allow access to ocsp2.apple.com, consider the following:
    • Research possible macOS system configuration changes to disable or modify certificate validation behavior (note: this is outside F5 support scope and may have security implications, for example, https://developer.apple.com/forums/thread/673057  maybe helpful).
    • Contact Apple support for guidance on managing code-signing certificate validation in closed network environments.
  • If possible, temporarily allow outbound access to ocsp2.apple.com during installation or upgrade, then revert to the original firewall policy.

Additional Information

  • This behavior is not unique to BIG-IP Edge Client; other macOS applications that require code-signing certificate validation may encounter similar issues in closed network environments.
  • When the installation fails, the process may retry multiple times without displaying a clear error message to the user.
