Policy Information

With the introduction of iControl REST in BIG-IP 11.6.0, F5 declared the deprecation of the iControl SOAP interface.

Starting in BIG-IP 11.6.0, F5 no longer adds new functionality to the iControl SOAP interface. Only critical vulnerabilities will be addressed on existing iControl SOAP interface functionality until F5 provides an End of Life (EOL) notification for a future version of the BIG-IP system.

All new features and updates will have only an iControl REST interface.
