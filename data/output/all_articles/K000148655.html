Description

Active System Controller was rebooted and failovered.

Then tenants lost connections, especially management port , and active tenants were failovered.

Environment

  • F5OS-C
  • Velos
  • Tenant
  • Failover

Cause

  • Bug ID 1224261
  • Bug ID 1556173
  • Bug ID 1555457

Recommended Actions

Do not failover or reboot Active Velos System Controller during Active tenants.

If it is required, please do it in a maintenance window.
