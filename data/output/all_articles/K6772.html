Known Issue

Important: The information in this Solution applies to FirePass versions 5.5.2 and 6.0.0. All issues described in this Solution were fixed in FirePass version 6.0.1.

For information about F5 hotfixes for Internet Explorer 7 support, refer to K6740: Support for Internet Explorer 7.

Both hotfixes for Internet Explorer 7 support have the following known issues:

Internet Explorer 7 handling of new ActiveX controls (CR70584)

Many FirePass functions (such as Cache Cleaner, Network Access and Application Access) work by downloading and running F5 ActiveX controls in your web browser. You must download new versions of the controls, which are written for Internet Explorer 7, when you upgrade to Internet Explorer 7. However, due to security changes in Internet Explorer 7, F5 ActiveX controls may not run automatically after downloading. Failure to run the controls may occur on systems in the following situations:

  • No previous version of F5 ActiveX controls have been downloaded
  • Previous versions of F5 ActiveX controls were downloaded under a previous version of Internet Explorer but are in a disabled state in Internet Explorer 7

Controls that are in a disabled state can be seen in Internet Explorer's Manage Add-ons window located at Tools : Manage Add-ons : Enable or Disable Add-ons : Show: Downloaded ActiveX Controls (32-bit). Activating the control requires highlighting the control and selecting the Enable option button in the Manage Add-ons window, then clicking the OK button. Failure to activate an F5 control may cause a pop-up window to request the user download and run the control each time the control is needed. You may also see an information balloon that indicates that the add-on is disabled and provides a link to enable the add-on.

Important: The above procedure was written for Internet Explorer version 7, and is subject to change. For more information, refer to Microsoft documentation for the version of Internet Explorer that you are running.

In version 6.0.0 of FirePass software, a single ActiveX control, the F5 Networks Auto Update control is responsible for downloading all other function-specific ActiveX controls. This control is the first control downloaded when a new version of controls is needed.

As an example, if you configure a FirePass version 6.0.0 controller to download the Cache Cleaner ActiveX control (Inject ActiveX/Plugin to clean-up client browser web cache is selected on the Users: Endpoint Security: Post-Logon Actions page of the Admin Web UI), and then use Internet Explorer 7 to log into FirePass for the first time, you will be presented with a pop-up window to download the F5 Networks Auto Update control's installer (InstallerControl.cab). The pop-up window information bar displays the following message:

The previous site might require the following add-on:
'InstallerControl.cab' from 'F5 Networks'. Click here to install...

If you click the information bar, then select Install ActiveX Control, then click the subsequent Install button, the FirePass will download and run the Auto Update control, assuming no other security settings or configuration prevents installation or execution. As a result, the pop-up window information bar displays the following message:

The website wants to run the following add-on: 'CacheCleaner.dll' from 'F5 Networks'. If you trust the website and the add-on and want to allow it to run, click here.

If you click the information bar, then select Run ActiveX Control, then click the subsequent Run button, FirePass will run the Cache Cleaner control, assuming no other security settings or configuration prevents installation or execution.

If the controls do not run, or if the information bar never appears, check Internet Explorer's Manage Add-ons feature for disabled controls.

F5 Product Development tracked this issue as CR70584, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

This issue still exists for the FirePass 5.5 software branch.

This issue has been fixed in cumulative hotfix 552-1, which has been issued for FirePass version 5.5.2, and cumulative hotfix 600-6, which has been issued for FirePass version 6.0.0. You may download these hotfixes or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Internet Explorer 7 breaks Cache Cleaner functions (CR70586)

The FirePass Cache Cleaner ActiveX control cannot remove cookies, browser history entries, cached form data and stored passwords in web pages accessed through FirePass Portal Access, which Cache Cleaner would normally delete. Additionally, the Cache Cleaner ActiveX control is responsible for component removal when the Uninstall FirePass client components and Remove dial-up entries used by Network Access client options are selected on the Users: Endpoint Security: Post-logon Actions page.

Important: Failure to remove cookies, browser history entries, cached form data and stored passwords may be considered a security risk. You can configure FirePass to prevent Internet Explorer 7 users from accessing applications that use client-side information. A Pre-Logon Sequence that detects Internet Explorer 7 can be combined with one or more Protected Configurations that deny access to certain applications. For information about configuring a Pre-Logon Sequence that detects Internet Explorer 7, refer to K6740: Support for Internet Explorer 7. For information about configuring Protected Configurations to provide resources based on results of a Pre-Logon Sequence, refer to K6646: Known Issue: Non-Windows systems cannot use Network Access Only Webtop.

F5 Product Development tracked this issue as CR70586, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

This issue still exists for the FirePass 5.5 software branch.

This issue has been fixed in cumulative hotfix 552-1, which has been issue for FirePass version 5.5.2, and cumulative hotfix 600-6, which has been issued for FirePass version 6.0.0. You may download these hotfixes or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Internet Explorer 7 in tabbed mode is minimized and hidden when launching Cache Cleaner (CR 71091)

Launching the Cache Cleaner will minimize and hide the Internet Explorer 7 window if you enable the following two options on Internet Explorer 7:

  • Tabbed Browsing
  • Always open pop-ups in new tab

When these options are enabled, you can only access or close the Internet Explorer 7 window through the Task Manager, using the Switch to or End Task options, respectively. In the Task Manager, the Internet Explorer window associated with the FirePass logon is labeled as FirePass Session Manager - don't close!

F5 Product Development tracked this issue as CR71091, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

This issue still exists for the FirePass 5.5 software branch.

Internet Explorer 7 in tabbed mode is minimized when launching Network Access (CR71094)

Launching Network Access will minimize the Internet Explorer 7 window in the following situation:

  • The Tabbed Browsing option is enabled in Internet Explorer 7
  • The Always open pop-ups in new tab option is enabled in Internet Explorer 7
  • The Minimize window after successfully connecting Network Access client option is enabled on the FirePass controller under the Network Access: Resources page, under the Customization tab

The window will be minimized to the Taskbar unless the Use Tray icon instead of Taskbar entry when minimized setting is selected under the Customization tab.

F5 Product Development tracked this issue as CR71094, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass release notes.

This issue still exists for the FirePass 5.5 software branch.
