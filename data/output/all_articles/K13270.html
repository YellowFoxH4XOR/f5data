Known Issue

Description

The network access wizard fails when the Datagram Transport Layer Security (DTLS) option is selected.

This issue occurs when the following condition is met:

  • The DTLS option is selected when using the wizard to create a new network access configuration.

For more information on DTLS refer to K11246: DTLS support for BIG-IP.

Impact

Users are unable to create network access configurations with the wizard.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Clicking Next on the Review Configuration screen will display the following error messages, :

    01071111:3: Cannot delete access policy (/Common/<access_policy>) because it is owned by a profile.
    01070734:3: Configuration error: Can't associate (/Common/Common/<access_policy>_vs_dtls) with folder (/Common/Common) folder does not exist

    In the above error message, note the following:
    • <access_policy> is the name of the access policy the wizard is attempting to create
  • Policy objects may be created

Workaround

Removing policy objects created by failed wizard

If the wizard failed to complete it may have created some objects that will need to be removed. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Expand Local Traffic.
  3. Click Virtual Servers.
  4. Select the check box next to any objects that start with the name you used in the Network Access wizard.
  5. Click Delete.... The Confirm Delete window opens.
  6. Click Delete.
  7. Expand Access Policy.
  8. Click Access Profiles.
  9. Repeat steps 4 through 6.

Enable DTLS on Network Access configuration

To work around this issue, you can create the network access configuration and then configure DTLS for the configuration. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Use the wizard to create your network access configuration. Do not select the DTLS option.
  3. Expand Access Policy.
  4. Click Network Access.
  5. Click the name if the network access resource created by the wizard. It will be in the following syntax, where <policy name> is the name of the policy you entered in the wizard:

    <Policy Name>_na_res

    The network access resource opens.
  6. Click the Network Settings tab.
  7. From the Client Settings drop-down menu, select Advanced.
  8. Select the DTLS check box.
  9. Click Update.
