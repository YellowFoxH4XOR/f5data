K000139771: Hang and loss of web gui when running tmsh load sys config verify

Type
Support Solution
Published
2024-05-24
Updated
2024-05-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000139771

Description

  • BIG-IP takes an unusual amount of time when loading/verifying the configuration via CLI with tmsh commands.
  • The web GUI logs out and shows 'unable to contact BIG-IP device', you cannot ssh into the unit whilst the config loading/verifying is ongoing.
  • Everything is fine after the config loading/verifying finishes.
  • Messages similar to the following can be seen /var/log/ltm

    notice mcpd[4999]: 0107165d:5: init_system_epsec_software_status: EPSEC:: loading of Epsec software status start
    warning snmpd[13878]: 010e0004:4: MCPD query response exceeding 30 seconds.
    warning snmpd[13878]: 010e0004:4: MCPD query response exceeding 60 seconds.
    warning snmpd[13878]: 010e0004:4: MCPD query response exceeding 90 seconds.
    warning snmpd[13878]: 010e0004:4: MCPD query response exceeding 120 seconds.
    notice mcpd[4999]: 0107165d:5: init_system_epsec_software_status: EPSEC:: loading of Epsec software status

Environment

  • BIG-IP
  • GUI
  • tmsh load sys conmfig verify

Cause

Loading sys config fails and mcpd may not be running properly due to corruption of EPSEC rpm database.

Recommended Actions

Force remove the current epsec install rpm libraries, and refresh them:

  1. Connect to CLI
  2. Run

rm -rf /var/apm/lib/rpm
epsec -f refresh​​​

Additional Information

None
