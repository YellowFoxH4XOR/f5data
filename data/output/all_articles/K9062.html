Topic

The newObjectCacheRatio setting in the pvsystem.conf file was introduced in Hotfix-BIG-IP-9.4.0-HF4 for BIG-IP WebAccelerator 9.4, to provide a method of specifying the ratio at which BIG-IP WebAccelerator will randomly cache new objects.

The newObjectCacheRatio entry in the /config/wa/pvsystem.conf file appears similar to the following example:

<newObjectCacheRatio>1</newObjectCacheRatio>

The following values specify the ratio at which BIG-IP WebAccelerator will randomly cache new objects:

  • For the default value of 1, the ratio is 1:1 and the BIG-IP WebAccelerator will always cache new objects.
  • For a value of 2, the ratio is 1:2, and the BIG-IP WebAccelerator will randomly cache 50 percent of new objects.  
  • For a value of 4, the ratio is 1:4, and the BIG-IP WebAccelerator will randomly cache 25 percent of the new objects.

Note: The maximum value for the ratio is 2147483647. However, a negative value, or value of 0 (zero) is also accepted. For a negative value, BIG-IP WebAccelerator will not cache new objects. For a 0 value, BIG-IP WebAccelerator will always cache new objects.

Note: When BIG-IP WebAccelerator does not cache the object as a result of the newObjectCacheRatio setting, the X-PvInfo header will have an S10201 code. For information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter of the BIG-IP WebAccelerator Policy Management Guide.

Note: When BIG-IP WebAccelerator does not cache the object as a result of the newObjectCacheRatio setting, compression for the object is also disabled. For more information, refer to K9070: Content assembly is disabled and compression is not performed on a newObjectCacheRatio miss.

F5 Product Development tracked this enhancement as CR78910. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.
 
Modifying the newObjectCacheRatio value

To modify the newObjectCacheRatio value, perform the following procedure:

  1. Log in to the command line of BIG-IP WebAccelerator.
  2. Change directories to the /config/wa directory, by typing the following command:

    cd /config/wa
  3. Back up the original pvsystem.conf file, by typing the following command:

    cp pvsystem.conf pvsystem.conf.sol9062
  4. Open the pvsystem.conf file in a text editor.
  5. Edit the newObjectCacheRatio setting to the desired value.
  6. Save the pvsystem.conf file.
  7. Clear the BIG-IP WebAccelerator cache and restart the BIG-IP WebAccelerator pvac process, by typing the following command:

    wa_clear_cache

Important: The wa_clear_cache command will restart the BIG-IP WebAccelerator pvac process and temporarily interrupt BIG-IP WebAccelerator optimization.
