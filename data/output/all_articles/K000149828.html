K000149828: VCMP Guest cannot be accessed via management IP

Type
Support Solution
Published
2025-03-02
Updated
2025-03-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000149828

Description

VCMP Guest is not accessible from the management ip even if the guest is up and accessible from vconsole.

 

vcmp guest is accessible via vconsole command:

 

[root@LTM:Active:Standalone] config #vconsole <vcmp_guest_name>
Trying 127.3.0.1...
Connected to 127.3.0.1.
Escape character is '^]'.

 

However, the management ip of the vcmp guest is not pingable and inaccessible via the GUI. There is a configured management-ip and management-route

 

[root@LTM:Active:Standalone] config # tmsh list sys management-ip

sys management-ip 10.10.10.10/16 {

  description configured-statically

}

[root@LTM:Active:Standalone] config # tmsh list sys management-route

sys management-route default {

  description configured-statically

  gateway 10.10.10.254

  mtu 1500

  network default

}

 

IP route is not going directly through the management interface but through other routes.

 

[root@LTM:Active:Standalone] config #ip r g 10.10.10.254

10.10.10.254 dev external src 10.170.170.36
    cache 

 

Environment

VCMP Guest

 

Cause

Unknown

 

Recommended Actions

Put the vcmp guest into Configured state and redeploy.

  1. Log in to the Configuration utility of the vCMP hypervisor.
  2. Go to vCMP > Guest List.
  3. Select the name of the vCMP guest having an issue.
  4. Under Requested State, select Configured.
  5. Click on Update and wait for at least 5 minutes.
  6. Under Requested State, select Deployed.
