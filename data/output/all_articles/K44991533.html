Known Issue

The mkdisk utility may not list all supported BIG-IP platforms.

This issue occurs when all of the following conditions are met:

  • You want to create a system disk USB thumb drive to install or upgrade your BIG-IP system.

  • You are running the following types of BIG-IP platforms (or base series):
    • BIG-IP 2000 (C112)
    • BIG-IP 4000 (C113)
    • BIG-IP 5000 (C109)
    • BIG-IP 7000 (D110)
    • BIG-IP 10000 (D112/D113)
    • BIG-IP 12000 (D111)

You can use the mkdisk utility to create a system disk USB thumb drive that contains a software installation image. You can then use that thumb drive as the installation source to install the software on your BIG-IP system.

Impact

The mkdisk utility fails to display the affected platform. As a result, you may not create a system disk USB thumb drive based on the exact platform.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the mkdisk utility, you cannot find the required BIG-IP platform (Model Name) from the list of supported platforms. The list of supported platforms for a 12.0.0 installation may appear similar to the following example:

    In the previous example, the BIG-IP 2200 platform is listed, but the BIG-IP 2000 platform is missing from the list.

Resolution

Workaround

To work around this issue, you can choose a platform that belongs to the same base series that you need. From the previous example, if you want to create a system disk USB thumb drive for a BIG-IP 2000 platform, you can create the thumb drive for a BIG-IP 2200 platform instead, as they belong to the same base series of BIG-IP 2000 (C112).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
