Topic

BIG-IP APM Remote Desktop Protocol (RDP) remote printer redirection utilizes client-side ActiveX to initiate connections to the RDP remote printer using MSTSC (Microsoft Terminal Services Client). The Microsoft 64-bit operating system security configuration may affect BIG-IP APM remote desktop RDP printer redirection functionality.

Description

The Microsoft 64-bit operating system restricts ActiveX and Java functions by default. Restricting ActiveX functionality may impact the reliability of the client-side ActiveX launch of RDP printer redirection.

Recommendations

When application access RDP printer redirection does not perform consistently across multiple Windows host systems in an environment, you can configure the BIG-IP APM system with an application app tunnel for RDP remote printer redirection. This step eliminates the client-side ActiveX initiating the remote printer connection. To configure an app tunnel for desktop RDP printer redirection, you will need to perform the following two procedures:

  • Creating a remote printer app tunnel
  • Associating the remote printer app tunnel with an existing access policy

Creating a remote printer app tunnel

To create an app tunnel for RDP printer redirection, perform the following procedure:

Impact: The following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles > Application Access > App Tunnels.
  3. Click Create.
  4. Enter the Name of the new App Tunnel (all other fields are optional).
  5. Click Create.
  6. For Resource Items, click Add.
  7. Enter a description in the Description text box.
  8. Enter the Hostname or IP address of the destination print server.
  9. Enter the Port or Port Range of the destination print server (typically RDP TCP port 3389).
  10. For the Application Protocol, select None.
  11. Set the Compression setting to Disabled.
  12. Set the Launch Application Path to use mstsc.exe.
  13. In the Parameters text box, enter the following:

    /v:%HOST%:%PORT%
  14. Click Finish.

Associating the remote printer app tunnel with an existing access policy

To associate the remote printer app tunnel with an existing access policy, perform the following procedure:

Impact: For access profiles configured with SSO, use of the newly defined remote printer application access app tunnel may cause automatic SSO to stop functioning.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Access Profiles.
  3. Locate the affected access policy in the Access Profile List.
  4. In the Access Policy column, select Edit to the right of the access profile to open the visual policy editor.
  5. Click on the name of the resource assignment box.
  6. Under the resource assignment expression, click Add/Delete.
  7. Select the App Tunnel tab.
  8. Select the check box for the new remote printer app tunnel resource.
  9. Click Update.
  10. To save changes to the access policy item, click Save.
  11. In the upper left-hand corner of the Configuration utility, click Apply Access Policy.
  12. In the Access Profile List page, click Apply Access Policy.
