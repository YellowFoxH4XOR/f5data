Known Issue

When the BIG-IP system processes invalid SIP requests, the CPU utilization may be high.

This issue occurs when the following condition is met:

  • SIP virtual servers receive invalid formatted SIP requests.

Impact

Invalid SIP requests may require more CPU utilization than expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • TMM experiences high CPU utilization when processing SIP requests.
