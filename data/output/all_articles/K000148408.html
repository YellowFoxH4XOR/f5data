K000148408: Committing Velos mgmt LAG configuration aborts with illegal reference

Type
Support Solution
Published
2024-11-06
Updated
2024-11-06
Source
https://my.f5.com/manage/s/article/K000148408

Description

When creating a new Velos mgmt LAG, both the 'lacp interfaces interface' object and the 'interfaces interface' objects need to be defined for the LAG, or the system is unhappy.

This demonstrates many of the gotchas/annoyances:

syscon-2-active# config
Entering configuration mode terminal
syscon-2-active(config)# lacp interfaces interface foobar
syscon-2-active(config-interface-foobar)# commit
Aborted: illegal reference 'lacp interfaces interface foobar name'
syscon-2-active(config-interface-foobar)# config name foobar
syscon-2-active(config-interface-foobar)# commit
Aborted: illegal reference 'lacp interfaces interface foobar config name'
syscon-2-active(config-interface-foobar)# top
syscon-2-active(config)# interfaces interface foobar config type ieee8023adLag
syscon-2-active(config-interface-foobar)# commit
Aborted: illegal reference 'interfaces interface foobar name'

Environment

  • Velos mgmt LAG configuration

Cause

Expected behavior. Illegal reference is triggered when creating a partial config (rather than both the 'interfaces interface mgmt-aggr' and 'lacp interfaces interface mgmt-aggr') and trying to commit it piecewise.

Recommended Actions

Specify both the name of the object ('lacp interfaces interface mgmt-aggr') and specify the same name as 'config name mgmt-addr'.

syscon-2-active(config)# lacp interfaces interface foobar
syscon-2-active(config-interface-foobar)# config name foobar
syscon-2-active(config-interface-foobar)# commit
Commit complete.
