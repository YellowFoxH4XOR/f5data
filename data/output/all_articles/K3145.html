Topic

The bigpipe base load command performs the following functions:

  • Resets the running configuration in its entirety (base and shared configuration)
  • Loads into memory the base configuration of the system (by reading the /config/bigip_base.conf file)

The bigpipe load command performs the following functions:

  • Resets the running configuration in its entirety (base and shared configuration)
  • Loads into memory the full configuration of the system (by reading the /config/bigip_base.conf and /config/bigip.conf files)

Important: Exercise extreme caution when issuing the bigpipe base load command. After this command has been entered, the BIG-IP system will be running no shared configuration. Issuing the bigpipe save command in this context will result in the BIG-IP system writing a blank /config/bigip.conf file.

Note: Starting in BIG-IP version 9.4, the BIG-IP system uses binary image files to load the configuration during system startup. However, the bigpipe base load and bigpipe load commands use the text-based configuration files /config/bigip_base.conf and /config/bigip.conf to load the BIG-IP system configuration.

Loading a new base configuration while retaining the existing shared configuration

To load a new base configuration while retaining the existing shared configuration, perform the following procedure:

  1. Log in to the BIG-IP command line.
  2. Back up the /config/bigip_base.conf file to an alternate directory.
  3. Replace or edit the /config/bigip_base.conf file.
  4. Type the following command:

    bigpipe load

  5. Examine and confirm the configuration by typing the following commands:

    bigpipe list
    bigpipe base list

  6. Once confirmed, save the new configuration by typing the following command:

    bigpipe save all

Loading only a new base configuration

To load only a new base configuration, without loading the existing shared configuration, perform the following procedure:

Important: This procedure will reset the shared configuration and write a blank /config/bigip.conf file.

  1. Log in to the BIG-IP command line.
  2. Back up the /config/bigip_base.conf file to an alternate directory.
  3. Replace or edit the /config/bigip_base.conf file.
  4. Type the following command:

    bigpipe base load

  5. Examine and confirm the configuration by typing the following command:

    bigpipe base list

  6. Once confirmed, save the new configuration by typing the following command:

    bigpipe save all
