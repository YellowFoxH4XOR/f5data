K000147125: What will happen if I exceed my request threshold ? Will all requests be blocked?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147125

What Happened?

  • F5® Distributed Cloud WAAP (Web App and API Protection) Services quotation/ purchase order, mentions the amount of request
  • Your want to know if exceeding your amount of request threshold will block any request

Environment

  • F5® Distributed Cloud WAAP Services quotation

Resolution/Answer

  • When the limits are exceeded, there won't be any changes in the way the product behaves. i.e we won't block all requests.
  • The metrics will be tracked on a monthly basis and during renewals , the purchased quotas and price will be adjusted based on historical usage (if usage is greater than purchased limits ).

Additional Information

Example:

  • Distributed Cloud Mesh User Rate Limiting Good Requests (1 Million Requests, App Delivery Network, Organization Plan, Per Month) - 1Yr
  • Distributed Cloud Mesh API Protection (1 Million Requests, App Delivery Network, Organization Plan, Per Month) - 1Yr
