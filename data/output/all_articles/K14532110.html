Topic

This article discusses the considerations and procedures for using the BIG-IQ disk-sizing tools to increase the size of the disk directory volumes on the BIG-IQ system active and inactive slots prior to updating or upgrading.

Description

You use the resizevol tool on the BIG-IQ system on which you want to increase the disk space of the disk directory volumes. resizevol upsizes the disk directory on both the active and inactive software volumes. On a BIG-IQ system or Data Collection Device (DCD) with BIG-IQ 6.0.0 or later installed, the disk-sizing tool files, addvol, imageplan, and resizevol are available in the /usr/bin folder. This folder is already in your path definition, so you can use these scripts directly.

If the scripts are not pre-installed in /usr/bin, you must first download the F5_Networks_Disk_Size_Tools.tar file which contains the three disk-sizing tools, addvol, imageplan, and resizevol. For details on downloading this script, refer to Downloading the disk-sizing tools if not already pre-installed in this article.

The disk-sizing tools are useful for to assist you planning the software update or upgrade. For example:

  • To know what the image-sizing plan coded in the ISO image file is and how it affects your update or upgrade plan.
  • To verify how much disk space is available, allocated, and free on the system.
  • To create new software volume to the system according to the ISO image.
  • To resize the target disk directory to a new size to accommodate to your needs.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the BIG-IQ system.

Procedures

  • Download the disk-sizing tools if not already pre-installed
  • Discover the image-sizing plan coded on the ISO image file
  • Verify the disk space allocated and used on a disk directory
  • Create a new software volume to the system according to the ISO image
  • Resize the disk directory

Download the disk-sizing tools if not already pre-installed

If the the disk-sizing tool files addvol, imageplan, and resizevol are not pre-installed on the BIG-IQ system, F5 provides these on the F5 Downloads site. You can download and transfer the TAR file to the BIG-IQ system. The extracted TAR file contains the three tools.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Perform the following procedure to get the disk-sizing tools:

  1. Log in to F5 Downloads.
  2. Select Find a Download.
  3. Select BIG-IQ Centralized Management.
  4. Select the BIG-IQ version that you are using in the product list.
  5. For the product container, select BIG-IQ_Sizing_Tools.
  6. Read and accept the End-User License Agreement.
  7. Select and download the F5_Networks_Disk_Size_Tools.tar and F5_Networks_Disk_Size_Tools.tar.md5 files
  8. From your local system, you can use the .md5 file to validate the checksum of the TAR file.
  9. After verifying the checksum, you can transfer the TAR and MD5 files to the BIG-IQ system using secure-copy (SCP). For example, you can store the files in the BIG-IQ system /shared directory.
  10. SSH log in to the BIG-IQ system using the Administrator credential to access the advanced-shell command prompt.
  11. You can extract files from the F5_Networks_Disk_Size_Tools.tar file to retrieve a directory that contains the following three files:
    • F5_Networks_Disk_Size_Tools/addvol
    • F5_Networks_Disk_Size_Tools/imageplan
    • F5_Networks_Disk_Size_Tools/resizevol

    To extract files from the TAR file, use the following command syntax:

    tar xpf <Tar Filename> -C <Directory to store>

    For example, to extract the files that is stored in /shared directory and to store the three files in /shared as well, use the following command:

    tar xpf /shared/F5_Networks_Disk_Size_Tools.tar -C /shared/.

  12. The three disk-sizing tools are now ready for use with the full directory path where the files reside.

    For example, if you extract the files to the /shared directory, they have the following full paths:

    • /shared/F5_Networks_Disk_Size_Tools/addvol
    • /shared/F5_Networks_Disk_Size_Tools/imageplan
    • /shared/F5_Networks_Disk_Size_Tools/resizevol
  13. The disk-sizing tools are now ready for use.

    For example, to use the resizevol tool residing in /shared/F5_Networks_Disk_Size_Tools/, use the full directory path command together with the following syntax:

    /shared/F5_Networks_Disk_Size_Tools/resizevol <Disk Directory> <New Size in KB>

    For example to increase the /var disk directory volumes to be 28GB (28 * 1024 * 1024 = 29360128KB) disk space, enter the following command:

    /shared/F5_Networks_Disk_Size_Tools/resizevol /var 29360128

Discover the image sizing plan coded on the ISO image file

Understand the image sizing plan that is coded on the ISO image file is important when you are planning to update or upgrade a system with a customized disk directory size that differs from the standard deployment size. Attempting to update or upgrade a larger disk directory size to a new software slot with a standard disk directory size may result in an upgrade failure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To use the imageplan command to discover the image sizing plan of the ISO image to which you are planning to update or upgrade, perform the following procedure:

  1. Log in to the BIG-IQ system using the Administrator credential to access the advanced shell command prompt.
  2. Use the imageplan command with the following command syntax:

    imageplan <ISO_filename>

  3. For example, the BIG-IQ 8.0.0 ISO image file, the imageplan output appears similar to the following:

    product BIG-IQ version 8.0.0 build 0.0.594 (BIGIQ800) selected
    Standard plan
     Mount point: /, Size: 450000k
     Mount point: /usr, Size: 10485760k
     Mount point: /config, Size: 3320000k
    Mount point: /var, Size: 78643200k
    Tiny plan
     Mount point: /, Size: 450000k
     Mount point: /usr, Size: 10485760k
     Mount point: /config, Size: 500000k
     Mount point: /var, Size: 26214400k

    The directory size structure lists two plans: Standard and Tiny. The type of plan used depends on the deployed BIG-IQ Virtual Edition (VE) image size.

    For example:

    • On a Large BIG-IQ VE image deployment, in which the system allocates 500 GB of disk space, the addvol tool uses the Standard plan disk structure to create the new software volume.
    • On a Standard BIG-IQ VE image deployment, in which the system allocates 95GB of disk space, the addvol tool uses the Tiny plan disk structure to create the new software volume.

    You can use the vgdisplay command and inspect the value for VG Size to find out which type of the BIG-IQ VE image size is deployed on your system.

    Note: Similar image-plan guidance applies when using the tmsh command to install new software volume.

  4. Before an update or upgrade, F5 recommends that you discover the usage structure of your system's existing active slots disk using the lvs command. Enter the lvs command syntax as follows:

    lvs | grep "set.<SlotNumber>"

    For example, if the BIG-IQ active slot is on HD1.1 and this is where you want to upgrade from, enter the following command:

    lvs | grep "set.1"

    The lvs command output appears similar to the following:

    set.1._config vg-db-sda -wi-ao---  3.17g
    set.1._usr  vg-db-sda -wi-ao---  10.00g
    set.1._var  vg-db-sda -wi-ao--- 120.00g
    set.1.root  vg-db-sda -wi-ao--- 440.00m

  5. The output from the lvs command shows that the existing software volume HD1.1's /var disk directory has 120GB of allocated disk space. Output from the imageplan command on the BIG-IP 8.0.0 ISO image file's Standard plan only has 75GB allocated for the /var disk directory where the sample references the Large BIG-IQ VE image deployment. This means that the update or upgrade installation may fail if more than 63% of the allocated 120GB disk space is used. The system copies the data from the /var disk directory, with a 120GB allocated size, to the new software slot with BIG-IQ 8.0.0, where the /var disk directory only has 75GB allocated.

    This is a critical consideration about disk size tasks involving update or upgrade of the BIG-IQ system. For more information about other disk-size considerations with regards to system update or upgrade, refer to What disk size tasks should I perform before an upgrade? in BIG-IQ Centralized Management Disk Space Management.

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Verify the disk space allocated and used on a disk directory

Before you create a new software volume or upsize any disk directory on the BIG-IQ system, you need to check the physical disk space available against the amount of disk space already allocated.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

To check on the amount of free disk space and the amount used, perform the following procedure:

  1. Log in to your BIG-IQ system using the Administrator credential to the advanced shell command prompt.
  2. Use the vgdisplay command to view the volume group details on the system by entering the following:

    vgdisplay

    Output from the vgdisplay command appears similar to the following:

      --- Volume group ---
      VG Name               vg-db-sda
      System ID             
      Format                lvm2
      Metadata Areas        1
      Metadata Sequence No  32
      VG Access             read/write
      VG Status             resizable
      MAX LV                0
      Cur LV                12
      Open LV               7
      Max PV                0
      Cur PV                1
      Act PV                1
      VG Size               498.50 GiB
      PE Size               4.00 MiB
      Total PE              127617
      Alloc PE / Size       75133 / 293.49 GiB
      Free  PE / Size       52484 / 205.02 GiB
      VG UUID               rBJ28q-wl28-n9ub-KWG9-wcHW-u2Ef-nS6lTn

    VG Size refers to the physical disk space on the BIG-IQ system.

    Alloc PE / Size refers to the disk space size that is already allocated to the logical volumes that are already created on the system. To see what these allocated logical volumes are, you can use the lvs command. All the lines under the LV column from the lvs command output refer to the allocated logical volumes, regardless of whether they are already in use.

    Free PE/Size refers to the disk space size that is not yet allocated. This means that the amount of free disk space that can be used for creating a new software volume or to upsize an existing allocated logical volume.

  3. Using imageplan, you can compare the free disk space size amount and calculate the amount of required disk space from the upcoming installation to know whether the remaining free space size will be sufficient. If you plan to resize any of the disk directory the BIG-IQ system uses, F5 recommends that you calculate the total amount of disk space required before you perform an update or upgrade installation.

Create a new software volume to the system according to the ISO image

After you determine whether the amount of disk space available is sufficient to create a new software volume, you can perform the following procedure to create the software volume using addvol.

Impact of procedure: The following procedure requires you to restart the system, so you should perform this procedure during a suitable maintenance window.

  1. Log in to your BIG-IQ system using the Administrator credential to the advanced shell command prompt.
  2. Download the target ISO image that you intend to use to install the new software volume on the BIG-IQ system.
  3. Verify existing software volume numbering used by entering the following command:

    tmsh show sys software status

    Output appears similiar to the following:

    ---------------------------------------------------
    Sys::Software Status
    Volume  Product  Version    Build  Active    Status
    ---------------------------------------------------
    HD1.1    BIG-IQ  7.1.0.3   0.0.41     yes  complete
    HD1.2    BIG-IQ  7.1.0.2   0.0.21      no  complete

  4. To create a new software volume, use the following addvol command syntax:

    addvol <install volume> <ISO filename>

    To create a new software volume to allocate HD1.3 as the new software volume, use 1.3 as in the following example:

    addvol 1.3 /shared/images/BIG-IQ-8.0.0-0.0.594.iso

    When the addvol command successfully completes, it displays output similar to the following:

    create volume 1.3 for image /shared/images/BIG-IQ-8.0.0-0.0.594.iso
    product BIG-IQ version 8.0.0 build 0.0.594 (BIGIQ800) selected
    Creating new location sda, 3...
    info: zero sblock for member device; /dev/vg-db-sda/set.3.root
    info: zero sblock for member device; /dev/vg-db-sda/set.3._usr
    info: zero sblock for member device; /dev/vg-db-sda/set.3._config
    info: zero sblock for member device; /dev/vg-db-sda/set.3._var

  5. To use the newly created software volume, you first need to restart the BIG-IQ system to activate it. To do so, use the following command:

    reboot

  6. When the system successfully restarts, you can use verify the newly allocated software slot using the following tmsh command:

    tmsh show sys software status

Resize the disk directory

After you discover whether the amount of disk space available is sufficient to resize, use the allocated disk directory in any of the following locations:

  • /
  • /config
  • /usr
  • /shared
  • /var
  • /var/log

The location you choose must be an allocated disk directory volume that exists on the BIG-IQ system, regardless it is in the active and inactive software volume(s). The resizevol tool resizes the disk directory location that exists in all the software volumes regardless of whether they are active or inactive or whether the software volume is used or unused.

Impact of procedure: The procedure requires you to restart the system, so you should perform this procedure during a suitable maintenance window.

Important: Increasing the disk size on the BIG-IQ VE system is irreversible because F5 does not support disk shrinking.

Perform the following procedure to resize the chosen disk directory location:

  1. Log in to your BIG-IQ system using the Administrator credential to the advanced shell command prompt.
  2. Ensure that you have sufficient space to increase the disk size in the chosen location in all the software volumes. Refer to the earlier procedure with the lvs and vgdisplay commands to review and calculate the required disk space before proceeding to the next step.

    Important: Increasing the disk size beyond 1.9 TB may render the system unbootable. F5 recommends the extended disk space should not exceed 1.9 TB.

  3. To resize the chosen location, use the following resizevol command syntax:

    resizevol <disk directory location> <new size in kb>

    For example, to resize the /var disk directory, which exists in all software volumes (active and inactive), to 120GB, the KB value is 1024 x 1024 x 120GB = 125829120 KB and you enter the following command:

    resizevol /var 125829120

    The resizevol command requires your confirmation to proceed because this procedure is not reversible.
