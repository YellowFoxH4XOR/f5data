Known Issue

The BIG-IP GTM Session Initiation Protocol (SIP) monitor does not accept multiple header entries.

This issue occurs when one of the following conditions is met:

  • You add more than one header entry to a BIG-IP GTM SIP monitor using the Traffic Management Shell (tmsh) utility.
  • You add more than one header entry to a BIG-IP GTM SIP monitor using the Configuration utility.

Impact

You are unable to add multiple headers to a BIG-IP GTM SIP monitor.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After saving the BIG-IP GTM SIP monitor configuration using the Configuration utility, only the first header added is saved.
  • After saving the BIG-IP GTM SIP monitor configuration using the tmsh utility, you observe that the monitor sends multiple headers on one line.
