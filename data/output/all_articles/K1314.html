K1314: Changing the serial console speed (baud rate) on a BIG-IP 2000 or BIG-IP 5000

To change the baud rate, perform the following steps:

  1. Attach a serial device to the serial port of BIG-IP to ensure that BIG-IP uses the serial port as the console.
  2. From the BIG-IP console, disable quiet boot by typing the following commands:

    bigpipe global quiet_boot disable
    bigpipe save

  3. Reboot the BIG-IP 2000 or BIG-IP 5000 switch appliance and quickly press the S key as soon as the BIG-IP displays the message:

    System is Booting Please Wait.

    It may take you a few times to get the timing down and it may be necessary to press the S key multiple times for this to take effect.

    You are now in BIOS mode.

    Important: When you are in BIOS mode, any changes you make to other settings may leave your system inoperable. If this occurs, contact F5 Technical Support.

  4. Use the arrow keys to navigate to the Advanced menu.

    Note: In Windows 2000 and earlier versions of HyperTerminal, the Esc and arrow keys do not perform correctly. If you have one of these versions, you will need to use a terminal emulation application that properly emulates a VT100 terminal.

  5. Select Remote Access Configuration.
  6. Select the Serial Port Mode option and choose the desired baud speed from the list.
  7. Press the Esc key.
  8. Pressing O (the letter, not the number) to save the changes and exit.
  9. Change the speed in your terminal emulation software (refer to your terminal emulation software documentation for specific instructions).

    After you make the changes, BIG-IP will reboot.

  10. After BIG-IP boots up, enable quiet boot by typing the following commands:

    bigpipe global quiet_boot enable
    bigpipe save
