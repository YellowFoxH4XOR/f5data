Description

You want to modify or update the certificate and key of an existing SSL profile using the Traffic Management Shell (tmsh) utility.

Environment

  • You have console/SSH access to the BIG-IP.
  • You don't have access to the GUI (BIG-IP Configuration Utility) or prefer not to use the GUI.
  • Client or server SSL profile.
  • SSL certificate and key.

Cause

None

Recommended Actions

You can modify the SSL profile by using the tmsh commands below:

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Type the following command substituting the appropriate names for the clientssl/serverssl profiles, certificate and key.

    modify ltm profile [client-ssl | server-ssl] <SSL_profile_name> key <private_key_name.key> cert <certificate_name.crt>

    For example:

    modify ltm profile client-ssl my_profile key my_key.key cert my_cert.crt

  3. Save the configuration:

    save sys config

  4. Verify the update by displaying the profile using the following command:

    list ltm profile [client-ssl | server-ssl] <SSL_profile_name>

    For example:

    list ltm profile client-ssl my_profile
