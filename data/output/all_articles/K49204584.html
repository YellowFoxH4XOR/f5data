K49204584: Change the text that contains the text displayed when user browsers that do not support JavaScript

Type
Support Solution
Published
2022-02-24
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP ASM: 15.1.4
Source
https://my.f5.com/manage/s/article/K49204584

Description
Browser received the error below from ASM

Please enable JavaScript to view the page content.
Your support ID is: xxxxx.

You would like to change the text that when they use browsers that do not support JavaScript

Environment

  • ASM

Cause
None

Recommended Actions

  1. There is a db key known as dosl7.noscript_text to change the text value when browsers do not support JavaScript
    • tmsh list sys db dosl7.noscript_text
    • sys db dosl7.noscript_text {
          default-value "Please enable JavaScript to view the page content.<br/>Your support ID is: %DOSL7.noscript.support_id%."
          scf-config "true"
          value "Please enable JavaScript to view the page content.<br/>Your support ID is: %DOSL7.noscript.support_id%."
          value-range "string"
      }
  2. For example, if you would like to change the text value to TESTING
    • tmsh modify sys db dosl7.noscript_text { value "TESTING.<br/>Your support ID is: %DOSL7.noscript.support_id%." }
    • Browser should receive the similar text below
      • <noscript>TESTING.<br/>Your support ID is: xxxxx.<link rel="stylesheet" href="/TSPD/?type=25" " /></noscript>
