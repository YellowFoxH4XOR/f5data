K000148967: Creating new user roles

Type
Support Solution
Published
2024-12-20
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000148967

Description

Can't find the option to create new LTM user roles to allocate specific access rights to different user categories. For example, a specific group of users can view only one specific web application.

 

Environment

  • BIG-IP LTM
  • LTM User Role

Cause

The LTM user roles are predefined and cannot be changed or customized.

 

Recommended Actions

Instead of creating a new role, the specific web application can be handled by a Virtual Server that is created in a new partition. Then during the creation of a user, you can choose the created partition.

 

To create new partitions use the following article.

 

K74264919: Managing Administrative Partitions
