K03200328: How to assign and revoke FCP license keys on BIG-IQ using Postman

Type
Support Solution
Published
2022-03-23
Updated
2025-03-18
Applies to

  • BIG-IQ Centralized Management: 8.0.0, 8.0.X, 8.1.0, 8.1.X, 8.2.0, 8.2.X, 8.3.0, 8.3.X, 8.X.X
Source
https://my.f5.com/manage/s/article/K03200328

Description
You want to remotely assign or revoke a license key from a FCP pool on a BIG-IQ using iControl REST and Postman as the REST client.

Environment

  • BIG-IQ v8.x and later
  • BIG-IP
  • Licensing
  • iControl REST
     

Cause

You need the ability to remotely assign and revoke licenses to BIG-IP devices.

Recommended Actions

In this procedure you will review the license SKU you wish to assign or revoke then use the schema below customized with the options to match your set up. Using Postman you will send the schema and then review the response and review Assignments on the BIG-IQ. 
 

  1. Log into BIG-IQ and go to Devices > LICENSE MANAGEMENT > Licenses.
  2. Select the name of the license to open the details page and make a note of the Offering Name you want to assign or revoke in the Offerings section.
  3. Open the Postman software and change the method to POST.
  4. Change the address or hostname to match that of your BIG-IQ and copy the example below

    https://10.155.153.209/mgmt/cm/device/tasks/licensing/pool/member-management/

  5. Select Body, raw and JSON and copy in the example schema below:
    {
        "licensePoolName": "Load-6",
        "command": "revoke",
        "address": "192.0.2.1",
        "assignmentType": "UNREACHABLE",
        "macAddress": "FA:16:3E:1B:6D:34",
        "hypervisor": "vmware",
        "skuKeyword1": "F5-BIG-MSP-AFM-08-LIC-DEV",
        "skuKeyword2": "",
        "unitOfMeasure": "yearly"
    }
  6. Edit the schema to include your license pool name, the command to revoke or assign, the IP address and MAC address of your BIG-IP, and your hypervisor type (aws, azure, gce, vmware, hyperv, kvm, xen).
  7. In skuKeyword1 copy in the offering name from (2) above.
  8. Click on Send
  9. Review the response in Postman.
  10. On Big-IQ, go to Devices > LICENSE MANAGEMENT > Assignments, review the newly assigned or removed license.
  11. To obtain the license file for the newly assigned device from the BIG-IQ refer to K000135402: Use Postman with iControl REST on a BIG-IQ to generate unreachable FCP licenses for BIG-IP.
