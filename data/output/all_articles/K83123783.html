Known Issue

The IP::tos iRule command returns an incorrect value when used within a FLOW_INIT event.

This issue occurs when the following condition is met:

  • You use the IP::tos iRule command from within a FLOW_INIT event.

Impact

The IP::tos command returns a value of 0 (Normal-Service), regardless of the actual Type of Service (TOS) value present in the initial client packet.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system cannot make the correct service or routing decision from the FLOW_INIT event, based on the TOS provided in the initial packet in the flow.
