Known Issue

Creating a 0.0.0.0:0 virtual server in the Configuration utility may result in a slow-loading virtual server page and name resolution errors.

This issue occurs when the following condition is met:

  • You create a virtual server with a 0.0.0.0:0 destination address using the Configuration utility.

Impact

The Configuration utility user experience is degraded due to slow-loading pages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H615202 on the Diagnostics > Identified > Low screen.
  • You experience a slow Configuration utility response on the virtual server page.
  • In the /var/log/tomcat/catalina.out file, you observe an error message similar to the following example:

    java.net.UnknownHostException: locallb.virtual_server.AnyIPv4: Temporary failure in name resolution
