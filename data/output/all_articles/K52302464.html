Description

BIG-IP software upgrade fails with the follow status in CLI

[root@BIG-IP:LICENSE INVALID:Disconnected]
On the Configuration Console, when you try to re-license the device, the dossier will not be generated.

Environment

This article is relevant when the following conditions are met.

  • Upgrading to BIG-IP software 14.x, 15.x or above.
  • Will use BIG-IP software 13.0.0, 12.1.2 or 12.1.1 as a intermediary software before upgrading to 14.x, 15.x or above.
  • This happens on iSeries devices.

Cause

The cause is related to bug ID 658853.
When loading BIG-IP software 14.x, 15.x or higher, the AOM did not upgrade correctly. Because of this the AOM will fail to load thus the license verification will fail.

Recommended Actions

Force reboot the devive again and allow AOM to finish up

  1. Force reboot the device again to allow AOM to complete its upgrade.
  2. Monitor via serial console to ensure that the AOM upgrade is complete.
  3. Do not reboot the device during the AOM upgrade process.
