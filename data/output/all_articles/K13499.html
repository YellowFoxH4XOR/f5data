Known Issue

You are not able to view the session variables of active sessions through Access Policy >> Reports >> Current Sessions >> View Session Variables using the Configuration utility.

This issue occurs when the following condition is met:

  • BIG-IP 11.1.0 HF2 is installed

Impact

You are unable to view session variables using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When attempting to view the session variables page of the BIG-IP Configuration utility, the page fails to load with a Loading... status.
  • An error message that appears similar to the following example is displayed in the browser error console:

    'undefined' is null or not an object

    reportBuilderApp.js Line:277
    Code:0 Char:5
    URI:https://<BIG-IP name>/sam/admin/reports/reportBuilderApp.js?ver=843617

Workaround

To work around this issue, you can view the session variables from the command line. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Click Access Policy.
  3. Click Reports.
  4. Click the + (plus) next to Built In Reports.
  5. Click Current Sessions.
  6. Click Run Report.
  7. Note the Session ID for the user session that you want to inspect the session variables.
  8. Log in to the command line.
  9. Enter the following command:

    sessiondump <sessionid>

    Where sessionid is the session id of the users session you noted in step 7.
