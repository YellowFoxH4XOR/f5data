Known Issue

F5 rSeries systems may silently restart after upgrading to F5OS-A 1.8.0.

This issue occurs when all of the following conditions are met:

  • You have an F5 r5000, r10000, or r12000 series system.
  • The rSeries system is running F5OS-A 1.8.0 build 16036.

Impact

All tenants residing on the rSeries system stop processing traffic and go offline while the rSeries system spontaneously restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Tenants residing on the rSeries system go offline and failover if configured for high availability.
  • The rSeries system restarts unexpectedly.
  • Log messages similar to the following examples appear in the /var/log/platform/pel.log file on the rSeries system:

    11/04/2024 18:21:31 | 5753 | AOM | 255 | Na | 0 | CPU internal error event
    11/04/2024 18:21:31 | 5754 | AOM | 255 | Na | 5 | ME PECI is not functional, resetting host
    11/04/2024 18:21:31 | 5755 | AOM | 255 | Na | 5 | ... reason: 0xFF ME IPMI 'other error'
    11/04/2024 18:21:31 | 5756 | AOM | 255 | Na | 6 | lop host reset event

Workaround

Important: If you have not yet upgraded to version 1.8.0, it is recommended to skip the 1.8.0 version and upgrade directly to the 1.8.0 engineering hotfix (EHF).

To work around this issue, you can disable the CMS ENABLE DRAM PM setting in the rSeries system BIOS. This requires that you have serial console access to the F5 rSeries system. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: If you have ever upgraded your rSeries system to F5OS 1.8.0 build 16036, your system is impacted. Downgrading to a previous version does not resolve the issue. You must still perform the workaround described in this article.

To watch a video demo of this procedure, go to  Update F5 rSeries BIOS CMS ENABLE DRAM setting to fix silent restart after installing F5OS-A 1.8.0.

  • Establish serial console access to the F5 rSeries system and log in as root. To gain serial console access to the rSeries system, refer to K000139067: Connecting to the serial console on the rSeries and VELOS.
  • Restart the system by entering the following command:

    reboot

  • Monitor the console output for the BIOS menu and quickly press the c key to enter the BIOS setup. If you miss it, the system will restart and you can try again. The BIOS menu screen should appear similar to the following example:

    Version 2.22.1282. Copyright (C) 2023 AMI
    Platform: C128 PGF-0262_xx BIOS (Build: 2.02.145.1) Date: 12/12/2023

    Select <c> to enter setup.
    Select <e> to launch F5 Disk Erase Utility.

  • Select the Right arrow key on the keyboard to highlight Continue.
  • Select the Enter key.
  • In the next screen, press the Right arrow key to select the Socket Configuration tab.
  • Under Socket Configuration, select the Down arrow key until you highlight Advanced Power Management Configuration.
  • Select the Enter key.
  • Under Advanced Power Management Configuration, select the Up arrow key once to highlight Memory Power & Thermal Configuration.
  • Select the Enter key.
  • Under Memory Power & Thermal Configuration, ensure DRAM RAPL Configuration is highlighted.
  • Select the Enter key.
  • Note that the CMS ENABLE DRAM PM setting is set to Enable.
  • Select the Down arrow key to highlight CMS ENABLE DRAM PM.
  • Select the Enter key to configure this setting.
  • Select the Up arrow key to highlight Disable.
  • Select the Enter key.
  • Press the F4 key to bring up the Save & Exit Setup prompt.
  • Ensure Yes is highlighted and select the Enter key.
  • The screen will refresh and you should start to see the normal boot up messages until the login prompt is seen. If you want to verify the BIOS setting, you can repeat the procedure to check that the CMS ENABLE DRAM PM setting is set to Disable.
