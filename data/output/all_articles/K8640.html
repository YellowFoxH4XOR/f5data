Topic

To create a Microsoft Windows Terminal Server (WTS) favorite in FirePass, you can configure a Terminal Server favorite or an Application Tunnel. Configuring a Terminal Server favorite is the easier method, and it requires no WTS client software on the client system. When a user launches the Terminal Server favorite, an ActiveX control that functions as the WTS client is loaded into the browser. An Application Tunnel requires WTS client software on the client system, but the client software may have additional features and options that are not available in the Terminal Server favorite ActiveX control.

Note: The client software typically used to access WTS servers is Remote Desktop Connection (RDC), and is also referred to as Remote Desktop.

Configuring a Terminal Server favorite for accessing a Microsoft Windows Terminal Server

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access: Terminal Servers: Resources page.
  3. Click the Add New Favorite link.
  4. In the Name field, enter a name for the favorite.
  5. In the Host field, enter the hostname or IP address of the Windows Terminal Server.
  6. In the Port menu, select Microsoft Terminal Server.
  7. If your Windows Terminal Server does not use the default port number of 3389, enter the non-default port number in the Port field.
  8. Click the Add New button.

Configuring an Application Tunnel for accessing a Microsoft Windows Terminal Server

Perform the following procedure based on the version of your FirePass controller:

FirePass version 6.0.0 and later

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access: App Tunnels: Resources page.
  3. Click the Add New Favorite link.
  4. In the Name field, enter a name for the favorite.
  5. In the Allow List field, enter a list of hosts, networks, and ports that users are allowed to access.

    For example:    

    wts.siterequest.com:3389
        172.30.11.0/24:3389
        192.168.120.32:3389

  6. Click the Add Favorite button.
  7. Click the Add New Dynamic Tunnel button.
  8. In the New Dynamic Tunnel menu, select Microsoft Terminal Server Client.

    Note: Selecting Microsoft Terminal Server Client configures %SYSTEMROOT%/SYSTEM32/mstsc.exe in the Application field. If the client systems use a different WTS client, or if the WTS client is installed in a non-default location, enter the correct application path in the Application field.

  9. In the Name field, enter a name for the Dynamic Application Tunnel.
  10. Click the Add New Dynamic Tunnel button.

FirePass version 5.5.2 and earlier

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access: App Tunnels: Resources page.
  3. Click the Add New Favorite link.
  4. In the Name field, enter a name for the favorite.
  5. In the Add new menu, select MS Terminal Services.
  6. In the Add new text field, replace Remote Host with the hostname or IP address of the WTS server.

    Note: If you specify a network name (a DNS name, WINS name, or a static host name) instead of an IP address in the Add new text field, the Application Tunnel modifies the hosts file on the client system when the user launches the Application Tunnel. This temporary patch allows the Application Tunnel to override the network name settings, while preserving the existing network name settings for the client applications. The Application Tunnel restores the original hosts file when the user closes the tunnel.

  7. Click the Add New button.

    FirePass creates the Application Tunnel and displays its configuration settings.
  8. If your WTS server uses a non-default port number, enter that port number in the Remote Port field. By default, FirePass sets the Remote Port field to the standard WTS port number (3389).
  9. Note the information in the Local Host : Port or Range fields. After the user launches the Application Tunnel, the WTS client must connect to the host and the port listed in the Local Host : Port or Range fields.

    Note: You may need to change the local host port selected by FirePass if the port number conflicts with a service already running on the client system(s).

  10. Optionally, in the Command Line field, enter the command that the FirePass client-side component should launch after establishing the Application Tunnel.

    For example, if the local host is set to 127.211.124.180 and the local port is set to 4321, you can enter the following command in the Command Line field:

    mstsc.exe /v: 127.211.124.180:4321

  11. If you configured the Command Line field, click the check mark icon to the right of the Command Line field to save the change. If you did not configure the Command Line field, this procedure is complete.
