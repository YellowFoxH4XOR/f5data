Issue

Description

In certain cases, SAML SSO can fail on an IdP-initiated logon, while SP functions as expected.

Environment

  • BIG-IP APM
  • Security Assertion Markup Language (SAML)
  • Single sign-on (SSO)
  • Identity Provider (IdP) and service provider (SP)

Cause

Bindings of IdP connectors are only allowed to be connected to one SP connector when configured with SSO.

Recommended Actions

  • Manual Chapter : Using APM as a SAML IdP no SSO portal
  • Manual Chapter : Using APM as a SAML IdP SSO portal
