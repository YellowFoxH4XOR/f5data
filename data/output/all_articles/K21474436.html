Description

  • You cannot connect to the Configuration Utility (GUI)  with Chrome. The message says "unusual and incorrect credentials"
  • There is no way of accepting and continuing.

Environment

  • The Device is configured with a self signed certificate (which is the Default)

Cause

The Management IP that is being using by the device was previously used by a different device with a self signed certificate.
After accepting that prior certificate Chrome prohibits using a different certificate.

Recommended Actions

  1. Change management  IP.
  2. Change browser.
  3. Remove the security exception  previously associated with that address  from Chromes'   cache. This is contained in "site data". This will clear all sites.
  4. The current site can also have its exception removed by:
    1. Go to the  address bar,
    2. Click on the "Not Secure"
    3. Click on Re enable warnings
