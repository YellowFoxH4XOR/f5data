Known Issue

When you use the search string function within the Configuration utility, the total number of records on the File Management page is incorrect.

This issue occurs when the following condition is met:

  • You use the search string function within the Configuration utility by navigating to  System > File Management and searching for records for any of the following pages:
    • Data Group File List
    • iFile List
    • lw4o6 File Object List

Impact

The Configuration utility reports that there are two pages, but the second page is empty.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Configuration utility reports additional pages that contain no results.

Resolution

Status

F5 Product Development has assigned ID 606799 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles

Workaround

To work around this issue, you can avoid using the search function for the total number of records on the File Management page, and instead use the Show All option in the lower right corner of the table.
