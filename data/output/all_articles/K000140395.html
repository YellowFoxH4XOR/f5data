K000140395: LTM Pool detected as UP even when there is no available pool member

Type
Support Solution
Published
2024-07-30
Updated
2024-07-30
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K000140395

Description

BIG-IP LTM Pool configured with "Virtual Location" monitor type, found with Pool detected as "UP" even though the configured pool member is not available.

Environment

  • BIG-IP
  • LTM
  • Health Check Monitor "Virtual Location"
  • Unavailable Pool marked as UP instead of DOWN

Cause

This is as design as the LTM monitor Virtual Location will always be marked as available for the pool member.

Recommended Actions

It is necessary to use an additional monitor to check the availability status of the pool member together with the Virtual Location monitor profile.
