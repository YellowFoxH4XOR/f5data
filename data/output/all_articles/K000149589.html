Description

You are trying to change the machine type of F5 system in Google Cloud from c2-standard-4 to c3d-highmem-4. The change is not successful. Google documentation says that this machine type requires support for the NIC gVNIC (linux kernel modul gve).

Environment

BIG-IP in GCP.

Cause

C3D virtual machine type is not supported because it uses gVNIC driver module.

BIG-IP doesn't support this module. Currently supported NIC's use the older virtio driver module.

Recommended Actions

Use another series / type of machine like: C2D, M1, C2, N2D etc. which are supported by F5.

Additional Information

None.
