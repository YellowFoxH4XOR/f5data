Known Issue

This is the result of a known issue. Typically, FirePass OPSWAT hotfixes are issued separately from FirePass cumulative hotfixes. However, cumulative hotfix HF-603-3 mistakenly included some OPSWAT cab files. If you install HF-603-3 after installing OPSWAT 2.5.18 (hotfix-119205-1) or OPSWAT 3.4.0 (hotfix-122307-2), users must re-install the OPSWAT client components every time they access the pre-logon sequence.

F5 Product Development is tracking this issue as CR124884.
 
Workaround
 
To prevent this issue from occurring, install cumulative hotfix HF-603-3 prior to installing OPSWAT 2.5.18 (hotfix-119205-1) or OPSWAT 3.4.0 (hotfix-122307-2). If OPSWAT 2.5.18 or OPSWAT 3.4.0 is already installed, remove these hotfixes prior to installing cumulative hotfix HF-603-3.

Note: For instructions about removing hotfixes, refer to K3430: Installing FirePass hotfixes.
