K7150: A TMM memory leak can result if the BIG-IP LTM system receives a chunked HTTP response containing no data

Known Issue

This is the result of a known issue. If the BIG-IP LTM system receives an empty chunked HTTP response in the same packet as the HTTP response headers, a single empty xbuf is leaked. Over time, this can result in memory exhaustion in the TMM.

F5 Networks Product Development tracked this issue as CR70761, CR70807, and CR70808 and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
