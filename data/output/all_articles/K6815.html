Known Issue

This is the result of a known issue. The BIG-IP ASM process may not start properly after a new installation of the BIG-IP ASM system.

For example, if you install BIG-IP ASM on an empty slot on the BIG-IP system, and then activate the license from the command line, the BIG-IP ASM process will not start. When this issue occurs, the following error message appears when logging in to the BIG-IP ASM Configuration utility:

User is Inactive!

F5 Product Development tracked this issue as CR68830 and it was fixed in BIG-IP ASM 9.4 for the 9.4 software branch. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue still exists for the BIG-IP ASM 9.3 software branch. To monitor the status of this CR, refer to the BIG-IP ASM release notes.

Workaround

To resolve this issue, you can restart BIG-IP ASM by typing the following command from the BIG-IP ASM command line:

bigstart restart asm
