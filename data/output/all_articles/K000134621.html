K000134621: The use of HTTP connections in BIG-IP Edge Client is disabled by default

Type
Support Solution
Published
2023-05-19
Updated
2023-05-19
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000134621

Description

BIG-IP Edge Client for Windows and MacOS support the use of HTTP connection for certain use cases. For example, the captive portal scenario as documented in K05434484: BIG-IP Edge Client captive portal page rendering.

Beginning in BIG-IP Edge Client for Windows and Mac OS, APM Clients 7.2.4.1, the use of HTTP connections in BIG-IP Edge Client is disabled by default.

Environment

  • BIG-IP Edge Client on Windows and Mac OS
  • BIG-IP Edge Client establishing connection to BIG-IP APM Virtual Server from behind a captive portal.

Cause

Upgrade to BIG-IP Edge Client for Windows and MacOS to APM Clients 7.2.4.1

Recommended Actions

Beginning in BIG-IP Edge Client for Windows and MacOS, APM Clients 7.2.4.1, BIG-IP Edge Client disables the use of plain HTTP communication by default. Depending on your environment, if the use of plain HTTP connections is acceptable, it can be enabled by modifying the config.f5c file on Windows and the config_tmp.f5c file on MacOS Edge Client installation packages before installing BIG-IP Edge Client version 7.2.4.1.

Prerequisite

  • Administrator role access to BIG-IP APM system
  • Administrative access to an end user system to modify the config.f5c file or config_tmp.f5c and the installation zip packages

After you install APM Client 7.2.4.1 on your BIG-IP APM system, to enable the use of HTTP connections, perform one of the following procedures as appropriate for your environment:

Note: For more information on installing APM Client, review K23159056: Upgrade the BIG-IP Edge Client | BIG-IP update and upgrade guide.

  • BIG-IP Windows Edge Client on Windows (modify the config.f5c file)
  • BIG-IP Windows Edge Client on MacOS (modify the config_tmp.f5c file)

BIG-IP Windows Edge Client on Windows (modify the config.f5c file)

  1. Login to the BIG-IP Configuration utility.
    1. Download the BIG-IP Edge Client package from the BIG-IP APM connectivity profile

      Access ›› Connectivity / VPN 

    2. Select the connectivity profile associated with the virtual server.
    3. Select Customize Package.
    4. Select Download.
  2. On your Windows client device, perform the following procedure to create a installer package that can be installed on your end users' Windows systems:
    1. Open the downloaded package in an archive manager and extract all files.
    2. Browse to the folder F5 VPN.
    3. Inside the extracted folder, open the config.f5c in a text editor and add the following line:

      <ALLOW_HTTP_CONNECTIONS>YES</ALLOW_HTTP_CONNECTIONS>

      For example:
      <?xml version="1.0" encoding="UTF-8"?>
      <PROFILE VERSION="2.0">

      <ALLOW_HTTP_CONNECTIONS>YES</ALLOW_HTTP_CONNECTIONS>
      <SERVERS TRUSTED="YES">
      </SERVERS>
      <SESSION LIMITED="YES">
      <STAYCONNECTED>YES</STAYCONNECTED>
      <RECONNECTIONS>5</RECONNECTIONS>
      <SAVEONEXIT>YES</SAVEONEXIT>
      <SAVEPASSWORDS>NO</SAVEPASSWORDS>
      <REUSEWINLOGONCREDS>NO</REUSEWINLOGONCREDS>
      <REUSEWINLOGONSESSION>NO</REUSEWINLOGONSESSION>
      <PASSWORD_POLICY>
      <MODE>DISK</MODE>
      <TIMEOUT>240</TIMEOUT>
      </PASSWORD_POLICY>
      <UPDATE>
      <MODE>YES</MODE>
      </UPDATE>
      </SESSION>
      <LOCATIONS>
      <CORPORATE>
      </CORPORATE>
      </LOCATIONS>
      <UI>
      <CUSTOMIZE>
      <LANGUAGE>
      </LANGUAGE>
      </CUSTOMIZE>
      </UI>
      </PROFILE>

    4. Create a zip file containing all the extracted BIG-IP Edge Client files including the modified config.f5c file and folders.
    5. Provide an appropriate name to the zip file. For example,

      Mod_EdgeClient.zip

    6. Download the file setupstub.exe from BIG-IP APM virtual server from the following location

      <VirtualServer>/public/download/setupstub.exe

      For example, paste the following URL on a browser that can access the BIG-IP APM virtual server:

      https://vpn.example.com/public/download/setupstub.exe

    7. Merge setupstub.exe and Mod_EdgeClient.zip (created in step 9) using the following command:

      copy setupstub.exe /b + Mod_EdgeClient.zip /b updatedBIGIPEdgeClient.exe

      This will create an updated installer package called updatedBIGIPEdgeClient.exe. This package can now be installed on your Windows end user's systems.

BIG-IP Windows Edge Client on MacOS (modify the config_tmp.f5c file)

  1. Login to the BIG-IP Configuration utility.
    1. Download the BIG-IP Edge Client package from the BIG-IP APM connectivity profile

      Access ›› Connectivity / VPN 

    2. Select the connectivity profile associated with the virtual server.
    3. Select Customize Package dropdown.
    4. Select MAC.
    5. Select Download.
  2. On your Windows client device, perform the following procedure to create a installer package that can be installed on your end users' MAC systems:
    1. Open the downloaded package in an archive manager and extract all files.
    2. Inside the extracted folder, open the config_tmp.f5c in a text editor and add the following line:

      <ALLOW_HTTP_CONNECTIONS>YES</ALLOW_HTTP_CONNECTIONS>

      For example:<?xml version="1.0" encoding="UTF-8"?>
      <PROFILE VERSION="2.0">

      <ALLOW_HTTP_CONNECTIONS>YES</ALLOW_HTTP_CONNECTIONS>

      <SERVERS>
      </SERVERS>
      <SESSION LIMITED="YES">
      <STAYCONNECTED>YES</STAYCONNECTED>
      <RECONNECTIONS>5</RECONNECTIONS>
      <SAVEONEXIT>YES</SAVEONEXIT>
      <SAVEPASSWORDS>NO</SAVEPASSWORDS>
      <REUSEWINLOGONCREDS>NO</REUSEWINLOGONCREDS>
      <REUSEWINLOGONSESSION>NO</REUSEWINLOGONSESSION>
      <PASSWORD_POLICY>
      <MODE>DISK</MODE>
      <TIMEOUT>240</TIMEOUT>
      </PASSWORD_POLICY>
      <UPDATE>
      <MODE>YES</MODE>
      </UPDATE>
      </SESSION>
      <LOCATIONS>
      <CORPORATE>
      </CORPORATE>
      </LOCATIONS>
      <UI>
      <CUSTOMIZE>
      <LANGUAGE>
      </LANGUAGE>
      </CUSTOMIZE>
      </UI>
      </PROFILE>

    3. Create a zip file containing all the extracted BIG-IP Edge Client files including the modified config_tmp.f5c file and folders.
    4. Provide an appropriate name to the zip file. For example,

      Mod_MACEdgeClient.zip

      This package can now be installed on your end user's MAC systems.
