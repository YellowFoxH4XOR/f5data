K000134719: F5OS: Downloading backup via RESTCONF API

Type
Support Solution
Published
2023-05-22
Updated
2025-10-06
Source
https://my.f5.com/manage/s/article/K000134719

Description

The article presents how to use REST API calls to get an F5OS backup file content in the response body.

Environment

  • RESTCONF API
  • F5OS

Cause

None.

 Recommended Actions

1. To use an auth token rather than basic auth. The auth token is returned in the X-Auth-Token header when making a request to, e.g., /restconf/ with basic auth.

    curl -su admin -D - https://<hostname or IP>:8888/restconf

  <data/>
  <operations/>

</restconf>

 

2. You may consider saving the X-Auth-Token value to a variable:

    token=$(curl -fsS -u admin -I https://<hostname or IP>:8888/restconf | grep -i '^x-auth-token:' | awk -F: '{print $2}' | tr -d ' \r')

3. Post a form using multipart/form-data or application/x-www-form-urlencoded that contains:

- file-path
- file-name
- token (this is the API token retrieved earlier)

# multipart/form-data

   curl -s https://<hostname or IP>:8888/restconf/data/f5-utils-file-transfer:file/f5-file-download:download-file/f5-file-download:start-download -F file-path=configs/ -F file-name=<name> -F token=$token | head

Additional Information

If you encounter HTTP 429 Too Many Requests response code with the message "Current download requests exceeded the configured Maximum allowed value. Try later", please either wait for a timeout or restart http-server via docker.
