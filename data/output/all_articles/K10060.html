Known Issue

This is the result of a known issue. The Packet Lost Ignore Rate setting specifies the threshold of lost packets at which the system performs congestion control. The Packet Lost Ignore Burst setting specifies when the system performs congestion control when multiple packets are lost. The Packet Lost Ignore Rate and/or Packet Lost Ignore Burst settings are not operational, and adjusting the settings in the TCP profile have no effect.

F5 Product Development tracked this issue as CR113431 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, Link Controller, WebAccelerator, or WAN Optimization Release Notes.

This issue has been fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1, which has been issued for BIG-IP version 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
