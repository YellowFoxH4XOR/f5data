Description

After following the SM directions Install NGINX Agent and Set up Instances for Security Monitoring with Instance Manager, getting error in Instance Manager ui when pushing App Protect ‘tgz’ files:

Instance config failed to publish. See details for more information.
<nginx_instance_name>: unsupported file type for Nginx App Protect. Please use Nginx App Protect JSON file

Environment

NMS
Security Monitoring

Cause

Configuration

Recommended Actions

Ensure the correct NMS NAP Compiler version is installed on the NMS platform, according to the version of NAP WAF installed on the NGINX+ instance(s). For example:

  • From NGINX+ instance:  
    $ dpkg -s app-protect | grep Version
Version: 28+4.218.0-1~focal
  • From NMS platform:  
    $ dpkg -s nms-nap-compiler-v4.218.0 | grep Status
Status: install ok installed

On the NGINX+ instance, edit /etc/nginx-agent/nginx-agent.conf and ensure the NGINX App Protect precompiled_publication parameter is present:

nginx_app_protect:
  # Report interval for NGINX App Protect details - the frequency the NGINX Agent checks NGINX App Protect for changes.
  report_interval: 15s
  # Enable precompiled publication from the NGINX Management Suite (true) or perform compilation on the data plane host (false).
  precompiled_publication: true

Restart NGINX Agent:

sudo systemctl restart nginx-agent.service
