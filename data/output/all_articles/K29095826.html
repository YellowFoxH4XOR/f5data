Known Issue

The big3d_install script may fail to install or update a remote big3d process.

This issue occurs when all of the following conditions are met:

  • From the BIG-IP DNS (formerly known as BIG-IP GTM) command line, you use the big3d_install script to install or update the big3d process on a BIG-IP remote device.
  • The remote device is configured with the secure shell (SSH) banner enabled.

Impact

Attempts to install or update the big3d process fail for the remote BIG-IP device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to install or update the big3d process on the remote BIG-IP device, the system displays an error message similar to the following example:

    Can't copy big3d to $ip

  • Removing the SSH banner on the remote BIG-IP device allows the big3d_install script to successfully install or update the big3d process.

Workaround

To work around this issue, you can disable the SSH banner on the remote BIG-IP device and re-run the big3d_install script. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) of the affected remote BIG-IP device by typing the following command:

    tmsh

  2. Disable the SSH banner on the target device by typing the following command:

    modify /sys sshd banner disabled

  3. Log in to the command line of the BIG-IP DNS device.
  4. Run the big3d_install script referencing the remote BIG-IP device by using the following command syntax:

    big3d_install <remote BIG-IP-IP-address>

  5. Return to the tmsh utility of the affected remote BIG-IP device (the same device from step 1).
  6. Re-enable the SSH banner by typing the following command:

    modify /sys sshd banner enabled

  7. To exit the tmsh utility on the remote BIG-IP device, type the following command:

    quit

  8. To exit the command line of the BIG-IP DNS device, type the following command:

    exit
