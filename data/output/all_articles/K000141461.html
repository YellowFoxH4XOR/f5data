K000141461: ICAP server communication problems

Description

  • communication between BIG-IP and anti-virus ICAP server intermittently fails
  • file uploads fail intermittently
  • error messages in /var/log/ts/bd.log: "... Problem sending data to icap server for job ..."

Environment

  • BIG-IP with ASM
  • ICAP server configured and "Anti-Virus Protection" enabled on ASM policy

Cause

Communication with the ICAP server may fail due to a large amount of lost packets and the associated required retransmits.


Recommended Actions

Check the network path between the BIG-IP and the ICAP server and eliminate lost or out-of-order packets as much as possible. If the problem persists, create a Layered Virtual Server following the steps below:

  1. create a pool with IP of the ICAP server as member and port 1344 (no monitor)
  2. create a Standard TCP Virtual Server to listen on the IP of the ICAP server, port 1344
    1. - Protocol Profile (Client): f5-tcp-progressive
    2. - Protocol Profile (Server): (Use Client Profile)
    3. - Source Address Translation: None
    4. - Address Translation: disabled
    5. - Port Translation: disabled
    6. - Default Pool: <pool created in step #1>
  3. edit Virtual Address List for IP of ICAP server and uncheck "ARP"
