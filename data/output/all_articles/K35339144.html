Description
BIG-IP ASM CSRF (cross-site request forgeries) detection configuration, wild card (* asterisk) can be configured in URL.
What is the difference between an URL with asterisk and an URL without asterisk?

Example URL /pandora_console/index.php?sec=general&sec2=godmode/setup/setup§ion=general

In the example that you would not need the asterisk. If you were wanting all URLs that started with /pandora_console/ then you can use asterisk as/pandora_console/*

For the example you gave that is the whole path so no asterisk is needed. If you do need to specify parameters as well then you can use the 'Advanced Edit Mode'. That will give the option to add parameters to the URL as needed.

Environment

  • BIG-IP ASM
  • CSRF config

Cause
None

Recommended Actions

  1. Unless customer does hot have multiple scripts in same directory, CSRF URL does not need asterisk.
  2. If customer want to take care of multiple scripts in same directory, asterisk will be used. For URL parameters, asterisk will NOT need. The actions or steps required to address the topic covered in the description.
