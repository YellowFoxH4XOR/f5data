Known Issue

Connections to the iControl representational state transfer (REST) daemon (icrd) may time out.

This issue occurs when the following condition is met:

  • You use the iControl REST application programming interface (API) to obtain data from or modify the configuration of your BIG-IP system.

Impact

The iControl REST API is not available for configuration queries or modifications.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • An iControl REST request returns an error message similar to the following example:

    "code": 400,
    "errorStack": [
    "java.util.concurrent.TimeoutException: remoteSender:192.168.10.100, uri:http://localhost:6789/tm/sys, method:GET ",

  • An error message similar to the following example is logged to the /var/log/icrd file:

    icrd: 6386,12921, RestServer, SEVERE,accept(...) returned unknown errno 24

Workaround

There is no workaround. You can restart the icrd process to restore connectivity. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. To restart the icrd process, type the following command:

    tmsh restart sys service icrd
