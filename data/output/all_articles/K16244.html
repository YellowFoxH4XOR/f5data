Known Issue

Access to the BIG-IP APM system's access profile for Citrix StoreFront may fail.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP APM system with an access profile for StoreFront.
  • You attempt to access the StoreFront resource using the Citrix Wyse Zero client (terminal).

Impact

Access to the StoreFront resource fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to access the StoreFront resource, the request fails as unauthenticated.
  • When you attempt to access the StoreFront resource directly, the request is successful.
  • When you view the HTTP headers sent by the BIG-IP APM system to the StoreFront destination resource, the NSC_AAAC cookie value is set with a double value.

    For example:

    Cookie: NSC_AAAC=6cb9479c1c91ed71abe97975643a2c3e; NSC_AAAC=xyz; NSC_DLGE=xyz

Workaround

To work around this issue, you can implement an iRule to correct the cookie behavior of the session. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. In the new iRule text Name box, type a name for the iRule.

    For example:

    Wyse_cookie_workaround
  5. In the Definition box, enter the following text:

    when HTTP_REQUEST {
    set string [HTTP::header value Cookie]
    if {$string contains "NSC_AAAC=xyz"}{
    regsub {NSC_AAAC=xyz;?} $string {} tmp
    regsub {NSC_DLGE=xyz;?} $tmp {} result
    HTTP::header replace Cookie $result
    }
    }
  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers.
  8. Click the name of the virtual server that is affected by this issue.
  9. Click the Resources tab.
  10. In the iRules section, click Manage.
  11. From the Available column, select the iRule you previously created.
  12. To move the iRule to the Enabled column, click <<.
  13. Click Finished.
