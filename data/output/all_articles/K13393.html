Issue

Error Message

01260015:3: Certificate supplied by server was not configured on virtual: <virtual server name>

For example:

01260015:3: Certificate supplied by server was not configured on virtual: /Common/proxyssl-vs

From version 11.2.0 additional information is provided in the error message:

01260015:3: Certificate supplied by server (subject CN: <IP>) was not configured on virtual: /Common/<virtual server name>

For example:

01260015:3: Certificate supplied by server (subject CN: 10.3.64.101) was not configured on virtual: /Common/proxyssl-vs

In the above examples, note the following:

  • <virtual server name> is the name of the virtual server configured to process Proxy SSL connections
  • <IP> is an IP address

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The affected virtual server is configured to use the Proxy SSL feature
  • The SSL profiles associated with the affected virtual server are configured with a certificate key pair that does not match that presented by the destination server

If the certificate presented by the destination server during the SSL handshake does not match that configured on the BIG-IP system, the BIG-IP system resets the connection and logs the described error message. The connection reset is by design to ensure the security and integrity of the ProxySSL connection.

Impact

Proxy SSL connection may fail to establish.

Recommended Actions

You can rectify this error by configuring the affected SSL profiles with the certificate key pair that is presented by the destination server. To do this, perform the following procedures:

  • Importing the destination server certificate key pair to the BIG-IP system
  • Reconfiguring the SSL profiles to use the destination server's certificate key pair

Importing the destination server certificate key pair to the BIG-IP system

If the destination server's certificate key pair has not been imported to the BIG-IP system, perform the following procedure:

Impact of procedure: None.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > SSL Certificate List.
  3. Click on the Import button.
  4. Select Key from the Import Type drop-down menu.
  5. Type a name for the certificate key pair in the Key Name box.
  6. Click on the Browse button and select the key file for the Key Source.
  7. Click on the Import button to import the key file.
  8. Click on the name of the certificate key pair created in step 5.
  9. Click on the Import button.
  10. Click on the Browse button and select the certificate file for the Certificate Source.
  11. Click on the Import button to import the certificate file.

Reconfiguring the SSL profiles to use the destination server's certificate key pair

Impact of procedure: None.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Click on the name of the affected Client SSL profile.
  4. Select the destination server's certificate from the Certificate drop-down menu.
  5. Select the destination server's key from the Key drop-down menu.
  6. Click on the Update button to save the modifications.
  7. Navigate to Local Traffic > Profiles > SSL > Server.
  8. Click on the name of the affected Server SSL profile.
  9. Repeat steps 4 through 6 to reconfigure the Server SSL profile.
