Issue

Error Message

notice chmand[<PID>]: 012a0045:5: <PSU_number> Status <PSU_status>

In this error message, note the following:

  • <PID> is the process ID of the chmand process.
  • <PSU_number> is the power supply unit slot number.
  • <PSU_status> is the power supply unit status.

For example:

notice chmand[8484]: 012a0045:5: PSU2 Status absent
notice chmand[8484]: 012a0045:5: PSU2 Status input active
notice chmand[8484]: 012a0045:5: PSU2 Status config match
notice chmand[8484]: 012a0045:5: PSU2 Status PSU identified
notice chmand[8484]: 012a0045:5: PSU2 Status present

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system is in the process of initializing after a reboot.
  • A power reading returns to a normal status after an abnormal reading.

Impact

This is a power supply change-of-state message that appears during normal system startup. However, repeated change-of-state messages, after the system is fully booted, may indicate a faulty power supply module. When affected by a faulty power supply module, the BIG-IP system may lack power redundancy.  

Recommended Actions

For more information about determining the power supply status, refer to K52015891: Troubleshooting BIG-IP power supply issues.
