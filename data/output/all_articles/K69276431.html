Description

You have recently rolled back from BIG-IQ ver 8.1 to 7.1, and you are now attempting to add a standby unit to create HA. However, you are unable to do so, and the error message states that an error occurred while adding the BIG-IQ.

Environment

  • BIG-IQ ver 8.1 (HA)
  • Roll back to version 7.1

Cause

The root cause of this issue is that BIG-IQ 8.1 is based on TMOS 15.1, while BIG-IQ 7.0 is based on 12.1. Due to the difference in ssh libraries between these versions, the ssh version used in 7.0 does not support the more secured keys used in version 8.1. Specifically, version 8.1 supports ecdsa-sha2 and ssh-ed25519 keys, which are not supported on version 7.0. As a result, the attempt to add an HA standby unit on version 7.0 fails.

The location of these files is /var/ssh/root/known_hosts. In version 8.1, you can find the following entries:

<IP address> ssh-rsa
<IP address> ecdsa-sha2
<IP address> ssh-ed25519

However, in version 7.0, you can only find the following entry:

<IP address> ssh-rsa

Recommended Actions

To resolve this issue, follow these recommended steps:

  1. Roll back from BIG-IQ Ver 8.1 to Ver 7.0.
  2. Boot up version 7.0.
  3. Modify the known_hosts file by deleting the ecdsa-sha2 and ssh-ed25519 entries.
  4. Add standby BIG-IQ unit
