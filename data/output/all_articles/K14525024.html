Description

For troubleshooting purposes you may need to collect the cipher suite that is negotiated between your client and virtual server.  The iRule below will allow you to log in /var/log/ltm the cipher suite that is used during a clients session.

Environment

You must meet the following environment requirements in order to log SSL handshake information.

  • Virtual Server
  • Client SSL Profile
  • iRules

Cause

None

Recommended Actions

To create the iRule to pull the negotiated cipher suite out of the SSL Handshake data, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. Type a name for the iRule.
  5. Enter the iRules syntax in the Definition field.

    when CLIENTSSL_HANDSHAKE {
      log local0. "Client-IP Address: [IP::client_addr] to VIP - [virtual name] used Cipher: [SSL::cipher name]"
    }

  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers
  8. Click on the Virtual Server name you want to apply the iRule
  9. Navigate to Resources tab > iRules > Manage
  10. Move to the Left the iRule you just created
  11. Click Finished.

Once implemented you should see  log statements in /var/log/ltm like:

<CLIENTSSL_HANDSHAKE>: Client-IP Address: 192.168.145.10 to VIP - /Common/http_vip used Cipher: ECDHE-ECDSA-AES128-GCM-SHA256
