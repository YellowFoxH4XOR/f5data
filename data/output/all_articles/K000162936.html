K000162936: GLobal Log Receiver: How to send logs from all or specific namespaces to my SIEM?

Description

While configuring the Global Log Receiver to connect it with your SIEM you want to ingest the logs of more than 1 namespace but you not find the option and see that the only option is "Select logs from current namespace"

Environment

  • Global Log Receiver

Solution

You have to use the Global Log Receiver from the "Shared Configuration". If you search in the XC console for Global Log Receiver you will see 2 options:
- Multi-Cloud Network Connect / Manage / Log Management
- Shared Configuration / Manage 

The Shared Configuration one have the options to select all the namespace or specific ones

Additional Information

This also count for Security Events, Audit Logs, DNS Request Logs.
