Known Issue

This is the result of a known issue. BIG-IP version 9.x systems use big3dshim, a backward-compatible iQuery daemon, to communicate with 3-DNS version 4.5 and 4.6 systems. When processing a high number of path probing requests, the big3dshim daemon can stop sending requests to the big3d daemon, causing iQuery communication between 3-DNS version 4.x and BIG-IP version 9.x to stall.

F5 Product Development tracked this issue as CR69156, CR67753, and CR69459, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, and 9.3.0. For information about upgrading, refer to the BIG-IP LTM release notes.
