Description
The peer device cannot get ARP reply for SNAT address from BIG-IP when define the SNAT address on iRule only. 

E.g. below iRule defined 10.10.10.5 as SNAT address.

when RULE_INIT {
  set static::snat_xxx(0) 10.10.10.5
}
when CLIENT_ACCEPTED {
   snat $static::snat_xxx([expr {[crc32 [IP::client_addr]] % [array size static::snat_xxx]}])
}

Environment

  • iRule
  • SNAT

Cause

  • No SNAT Pool configured on BIG-IP for IP 10.10.10.5
  • No self IP address or Floating IP address for the SNAT address 10.10.10.5

The peer device cannot get SNAT's MAC address using ARP.
This is expected behavior when define the SNAT address on iRule only. 

Recommended Actions

Create a SNAT Pool or Floating IP address (once create SNAT Pool, BIG-IP is starting to reply ARP)
