K25645107: BIG-IP is sending data exceeding the receive window of the client.

Type
Support Solution
Published
2022-08-12
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K25645107

Description

BIG-IP is sending data exceeding the advertised receive window size of the client. This can result in the client terminating the connection.

  • TCP RST from the client.
  • This can result in truncated files.

Environment

  • BIG-IP LTM.
  • Hardware SYN cookie has been enabled and is active.
  • Client and server enable TCP timestamp option.
  • Client enables TCP windows scale option.

Cause

This is caused due to a known bug tracked under ID1125733.

When SYN cookie is active, during the TCP 3WHS, PVA won't send the TCP window scaling option (thereby disabling Windows Scaling for that TCP session). Using SYN cookie and the TCP timestamp option, tmm rebuilds the connection with windows scale TCP option enabled and then installs it to the connection table. At this point, from the client's perspective, windows scaling is disabled. From tmm's perspective, the Windows scale TCP option is enabled. This results in tmm sending more data than the receive window size specified by the client.
 

Recommended Actions

  1. Upgrade to a fixed version.
    (OR)
  2. Use Software SYN cookie. For enabling Software only SYN cookie, refer to K74451051

Additional Information

None.
