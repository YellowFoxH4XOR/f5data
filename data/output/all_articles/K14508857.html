Known Issue

The running dynamic route configuration on your BIG-IP system is truncated and dynamic routing may not function as expected.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP system for dynamic routing.
  • You modify the route configuration using the IMI Shell (imish) and add an interface description.
  • You load the route configuration file.

Impact

When you load the modified route configuration, it is incomplete, and dynamic routing may not function as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view the /config/zebos/rd0/ZebOS.conf route configuration file and the imish show run interface command output, the configuration settings after the interface description are missing from the running configuration.
  • When you manually modify the configuration file and remove the description, the configuration load is complete.

Workaround

To work around this issue, you can remove any interface descriptions from the route configuration file and reload the configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will temporarily disrupt dynamic routing.

  1. Log in to the command line of the affected BIG-IP system.
  2. To create a backup copy of the route configuration file, type the following command:

    cp /config/zebos/rd0/ZebOS.conf /config/zebos/rd0/ZebOS.conf.backup

  3. Using a text editor, open the /config/zebos/rd0/ZebOS.conf file.
  4. Remove all lines in the file that start with the word description.

    For example, remove lines similar to the following example:

    description Testing Internal

  5. Remove the no shutdown command that follows the description.
  6. Save the configuration file changes.
  7. To load the configuration file, type the following command:

    tmsh restart /sys service tmrouted
