Known Issue

The TMOS Shell (tmsh) is unable to display the records of an external data group.

This issue occurs when all of the following conditions are met:

  • A user-defined external data group is configured on the BIG-IP system.
  • You want to display the records present in the external data group using tmsh.

In BIG-IP software 11.0.0 through 11.3.0, you can use the tmsh list /ltm data-group external <data group name> records command syntax to display the records of an external data group. However, this command syntax does not work on the BIG-IP software versions listed in the Applies to (see versions) box, located in the upper-right corner of this article.

Impact

You cannot display the records of an external data group using tmsh on the affected BIG-IP software version.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the tmsh list /ltm data-group external <data group name> records command syntax on the BIG-IP system, the output of the command stops short of showing the user-defined records. The command and output of an external data group named test may appear similar to the following example:

    tmsh list /ltm data-group external test records

    ltm data-group external test { }

  • When you use the tmsh show /ltm data-group external <data group name> external-records command syntax on the BIG-IP system, the command returns an error message similar to the following example:

    Syntax Error: "external" unexpected argument

Resolution

Status

F5 Product Development has assigned ID 420558 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article.
