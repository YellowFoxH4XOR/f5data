K25492181: Export/Import existing AS3 Application Templates on a BIG-IQ

Description

This article explains how to export and import an existing AS3 Application Template from and to a BIG-IQ.

Use this to:

  • Use an existing AS3 Application Template from one BIG-IQ to another
  • Make an External Backup of an existing AS3 Application Template
  • Edit or author an AS3 Application Template on a workstation using an IDE

Environment

  • CLI access to the BIG-IQ

Cause

None

Recommended Actions

  • Exporting an existing AS3 Application Template from a BIG-IQ
  • Importing an AS3 application template from a json file into a BIG-IQ
Exporting an existing AS3 Application Template from a BIG-IQ
  1.  List the existing AS3 application Template to find the UUID of the template that is to be exported:
    restcurl cm/global/appsvcs-templates | jq '.items[] | {name, selfLink}'
     
  2.  Locate the name of the template you wish to export and copy the portion of the selfLink left to right starting at cm and leaving off the ending quotation mark:
     
    For the Template named "regular-service":
    {
    "name": "regular-service",
    "selfLink": "https://localhost/mgmt/cm/global/appsvcs-templates/0c2e1d74-43f1-3332-bf9a-a9248486bd96"
    }

    Copy:
    cm/global/appsvcs-templates/0c2e1d74-43f1-3332-bf9a-a9248486bd96
     
  3. Make a REST  request for the template and save the resulting json to a file:
    restcurl cm/global/appsvcs-templates/<template UUID> >/var/tmp/<temple-name>.json

    Example:
    restcurl cm/global/appsvcs-templates/0c2e1d74-43f1-3332-bf9a-a9248486bd96 >/var/tmp/regular-service.json 

    Note: The above command create the file /var/tmp/regular-service.json
Importing an AS3 application template from a json file into a BIG-IQ
  1.  Use curl to make a POST to import the template using the saved json file as the POST body:
    curl -s -H "Content-Type: application/json" http://localhost:8100/cm/global/appsvcs-templates -X POST --upload-file /var/tmp/<temple-name>.json | jq .

    Example using file regular-service.json :
    curl -s -H "Content-Type: application/json" http://localhost:8100/cm/global/appsvcs-templates -X POST --upload-file /var/tmp/regular-service.json  | jq .  

    Note: At this point, the template should be visible in the GUI and available for use
