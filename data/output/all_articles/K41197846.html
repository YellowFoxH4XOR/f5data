K41197846: Big-IQ Error message during device discover/import if object name starts with special character or whitespace

Type
Support Solution
Published
2019-10-01
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K41197846

Description

This article is related to the following error message during Big-IQ device discovery/import:
 

Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Property 'name' value '<xx>' first character is not in the allowed set of characters 'a-zA-Z_'(white space is invalid).


During the "Import" phase of the discovery process, Big-IQ tries to validate the config that is being imported. Big-IQ has a more restrictive set of parameters that it uses to confirm if a config object is valid or not. In the case of the error message above, if the first character(s) is a numerical value(or really anything besides "a-zA-Z_") then the object that Big-IQ is trying to import will trigger the error message. When this occurs, device discovery/import fails.

Environment

  • Big-IQ
  • Device Discovery
  • Big-IP configuration objects that start with non-alphabet characters

Cause

Big-IQ does not allow for objects to start with characters outside the following parameters: "a-zA-Z_"

Recommended Actions

This issue can only be resolved by renaming the offending Big-IP object(s).  You will need to:

  1. Login to the Big-IP that you are trying to discover
  2. Change the name of the offending object that is called out in the error message.
    Often times objects can't simply be renamed in the Big-IP, so you need to delete the offending object from the GUI and then re-create it with a more appropriate name.
    If you run into problems deleting the object please contact F5 support.
