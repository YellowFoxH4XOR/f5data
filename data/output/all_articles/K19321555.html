Description

  • You attempt to import Citrix client packages onto BIG-IQ
  • The files in question are associated with APM hosted content, specifically with Citrix client packages.
  • Importing config into Big-IQ fails because there are several files in the APM configuration that include an "@" character, which the Big-IQ doesn't like.
  • The BIG-IQ throws the below error when import fails 

Failed to copy configuration to working-config; reason: Failed copying from source subcollections to target subcollections: %s: (ava.lang.lllegalArgumentException: Property'name' value 'HTML5Client_primaryToolbarButton-mypage@2cs.png 364595829_176’ has an invalid character that is not in the allowed set of characters '-a-zA-Z .0-9'.

  • Example of file

HTML5Client_primaryToolbarButton-mypage@2cs.png

Environment

  • BIG-IP
  • HTML5Citrix bundle
  • APM

Cause

  • Filename containing special character "@"

Recommended Actions

Rename all the files that contain the @ sign before importing to BIG-IQ
  1. Extract HTML5Client bundle 
  2. Rename files which contains  
  3. Compress HTML5Client Bundle
  4. Remove previously imported Client Bundle from BIG-IP (Access  ››  Connectivity / VPN : VDI / RDP : Citrix Client Bundles)
    Note If it was used by connectivity profile  for time of replacing  files  change  Citrix Bundle on profiles to default bundle
  5. Rediscover and reimport APM service on BIG-IQ
If  similar error appears in GUI while removing bundle from BIG-IP:
01070712:3: failed in syscall link(/config/filestore/files_d/Common_d/sandbox_file_d/:Common:citrix-client-package::HTML5Client3.zip-1658220919315_83674_1, /config/filestore/.trash_bin_d/.current_d/Common_d/sandbox_file_d/:Common:citrix-client-package::HTML5Client3.zip-1658220919315_83674_1) errno=(No such file or directory)
????? perform following workaround:
  1. Create empty files for cache-paths
    #touch `grep "cache-path" /config/bigip.conf | grep HTML5Client | awk '{print $2}'`
  2. Try to remove Citrix bundle again
