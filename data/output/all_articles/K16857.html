Known Issue

Mac OS X 10.10 (Yosemite) devices that use BIG-IP Edge Client for Mac may be unable to properly download the Proxy Auto-Config (PAC) file when establishing a network access connection.

This issue occurs when the following condition is met:

  • The /etc/hosts file on the Mac OS X 10.10 device has a static entry of the host that contains the PAC file.

During network access establishment, BIG-IP Edge Client first updates DNS settings (including in /etc/hosts) and then tries to download the PAC file. A race condition occurs if the PAC file is being downloaded before the DNS resolver service picks up the changes in /etc/hosts.

Impact

Because the PAC file is not downloaded, the user is unable to establish a functional network access connection.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Edge Gateway network access tunnel temporarily functions, then disconnects, and the user is unable to establish the connection again.
  • In the Library/Logs/F5Networks/svpn.log file, you observe error messages similar to the following example:

    15763,15767,svpn, 1, , 183, CMacUrlLoader::LoadUrl, Failed to download data, 12, 8
    15763,15767,svpn, 1, , 315, CPACHelper::WritePACFileFromURL(), Failed to download pac file, 8
    15763,15767,svpn, 48, , 317, CPACHelper::WritePACFileFromURL(), exit,
    15763,15767,svpn, 1, , 75, CPACHelper::WriteRemote(), Failed to download remote, 12, 8
    15763,15767,svpn, 1, , 76, CPACHelper::WriteRemote(), EXCEPTION - Failed to download remote pac file
    15763,15767,svpn, 1, , 176, , EXCEPTION caught
