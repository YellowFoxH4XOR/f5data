K000130338: High Speed Logging of BIG-IP LTM cannot work with QRadar

Published
2022-12-27
Updated
2022-12-27
Applies to

Description

IBM Qradar is a kind of client's server, that collects log data by Syslog service.

Events can be logged either locally on the system and viewed in the Event Logs, or remotely by the client's server.   
For this purpose, BIG-IP LTM allows you to send data to a pool of remote servers server via HSL (High Speed Logging) and remote logging.  
The system forwards the log messages to the client's server using the Syslog service.

This is for version support on IBM Qradar for BIG-IP.
 

Environment

  • LTM
  • QRadar
  • Remote logging

 

Cause

When you configure BIG-IP LTM, understanding the specifications of remote server can help ensure a successful integration.

On Qradar, the supported version of BIG-IP LTM is up to BIG-IP software version 14.x, because there is no QRadar official DSM (Device Support Module) to support its events.
Because of QRadar official DSM, events from BIG-IP LTM (after BIG-IP software version 14.x) are likely not being parsed properly by QRadar system.

Hence, after BIG-IP software version 14, events of LTM is recognized to be unknown event on Qradar.
This leads that High Speed Logging and remote logging of BIG-IP LTM from the Big-IP software version 15, cannot run with QRadar.
Note: Regarding the unknown event on IBM Qradar, an official version of the DSM on IBM Qradar to provide support, may solve this issue.
 

Recommended Actions

None

 

Additional Information

  • For the supported version on Qradar, remote logging of BIG-IP ASM and BIG-IP AFM are not impacted by BIG-IP software version.
  • For remote logging of BIG-IP APM, the supported software version of BIG-IP by Qradar is up to 14.x.
