K000139659: AOM Network configuration silently fails if duplicate IP address is used

Description

You are experiencing an issue where the AOM network configuration fails without any error message when a duplicate IP address is used. This can result in the configuration not being applied as expected.

 

Environment

  • Software version 17.1.0
  • rSeries devices
  • AOM

Cause

When the AOM network configuration is committed, the rSeries device sends an ARP probe (as described in RFC 5227 section 2.1.1) out of the management interface to check if the IP address is already in use on the network. If the ARP probe receives a response, indicating the IP address is already in use, the configuration is silently discarded.

Future Mitigation:

  • A bug (ID 1585569) has been created to provide an alert to the user when a duplicate IP address is detected during configuration. To determine if the issue is resolved, refer to BugID 1585569.

Additional Information

This silent failure behavior is specific to the AOM network configuration process. Users must manually verify IP address uniqueness until the bug fix is implemented. This is to prevent potential network conflicts and ensure smooth operation of the network management interface.
