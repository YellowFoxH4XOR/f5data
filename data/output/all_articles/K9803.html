Known Issue

This is the result of a known issue. Mac OS X users that are using Safari to connect to their FirePass device may experience regular session disconnections from FirePass. In addition, an error message that appears similar to the following example will display:

Connection Dropped

This behavior typically occurs when a Network Access connection has been established and a continual ping is sent from the client to a resource. It takes approximately 10 minutes for the connection to fail. However, if the client remains idle, the connection remains up.

F5 Product Development tracked this issue as CR110342 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-1 issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
