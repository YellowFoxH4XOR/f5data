Issue

The remote syslog server is configured under the System Logs section of the Device Management: Logs page. When you modify the syslog server settings and apply the changes, the following message appears in red text at the top of the page:

DNS is unreachable - Remote Syslog cannot be enabled

Note: This error message appears in version 6.0.0 of FirePass software with the cumulative hotfix for version 6.0.0 of FirePass Software. Prior to the cumulative hotfix, the word "unreachable" was misspelled.
 

This message occurs when the DNS server or servers configured on the DNS tab of the Device Management: Configuration: Network Configuration page are unresponsive to a ping (ICMP echo request packet) sent from the FirePass controller. When you apply changes to the System Logs configuration, the FirePass controller attempts to ping the DNS servers. If the FirePass controller does not receive an ICMP echo response packet within 10 seconds, the FirePass controller will display this message. The FirePass controller will also disable the remote syslog server configuration (the Enable Remote Log Server check box will be cleared).

This process occurs because the FirePass controller's syslog daemon will request name resolution lookups on the remote syslog server's name and IP address. If the DNS servers are unavailable, the lookups can take a significant amount of time before timing out. By pinging the DNS server, FirePass can determine whether the DNS servers are reachable. If the servers are not reachable, FirePass will not enable remote logging and will therefore avoid the timeout issue.
