Issue

Error Message

01360008:3: ERROR: Cannot connect to GWM server <IP_address>; Will try again in 30 seconds.

In this error message, note the following:

  • <IP_address> is the IP address of the Group Workload Manager (GWM) server

For example:

01360008:3: ERROR: Cannot connect to GWM server 10.10.10.10; Will try again in 30 seconds.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure the Server/Application State Protocol (SASP) monitor to obtain the availability of pool members.
  • The SASP monitor daemon is unable to communicate with a GWM server.

Impact

The BIG-IP system is unable to receive status updates for the monitored pool members.

Recommended Actions

  • If this message is not the result of a user-initiated action, such as GWM server maintenance, verify the configuration of the GWM server and ensure it is available on the network. When the GWM server becomes available, the SASP monitor should resume automatically.
  • If the GWM server is otherwise available, verify the SASP monitor configuration by following the procedures in K02172125: Troubleshooting the SASP monitor (13.x).
