Description

BIG-IP DNS reporting a monitored LTM server as offline with the reason “No enabled VS available,” causing GTM-to-LTM connectivity to fail.

 

 

Environment

  • BIG-IP DNS version 17.1.3
  • GTM/DNS listener communicating with monitored LTM devices
  • Affected LTM server status changed from available to offline
  • Expired GTM device certificate discovered

 

Cause

An expired certificate on the BIG-IP DNS/GTM system invalidated the trust relationship used for communication with the LTM devices. As a result, the GTM could not properly validate or maintain connectivity to the LTM virtual servers, causing the monitored LTM server to appear offline.

 

 

Answer/Recommended Actions

  • Temporarily disable the affected DNS listener before certificate maintenance to reroute DNS queries to backup system (if configured).
  • Replace or renew the expired GTM device certificate.
  • Rerun bigip_add for each monitored LTM device to re-establish trust.
  • Verify that the LTM server status is now available and that GTM-to-LTM connectivity is operational.
  • Re-enable the DNS listener.
  • Monitor certificate expiration dates and renew certificates before expiration to prevent recurrence.
