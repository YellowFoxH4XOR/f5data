K000161080: CheckMK Monitoring – Incomplete information discovery from F5OS via SNMP

Type
Support Solution
Published
2026-05-04
Updated
2026-05-05
Applies to
  • F5OS
  • F5OS-A: 1.5.0, 1.8.X, 1.7.X, 1.5.X, 1.8.4, 1.8.3, 1.8.0, 1.7.0, 1.5.4, 1.5.3, 1.5.2, 1.5.1
Source
https://my.f5.com/manage/s/article/K000161080

Description

When monitoring F5OS systems with CheckMK via SNMP, only basic services such as interface information and uptime are discovered. Metrics like memory utilization, CPU load, disk/storage utilization, power supply unit status, chassis temperature, and deployed/active tenants are not visible in CheckMK. SNMP connectivity and SNMP walk output confirm these metrics are present in F5OS, but CheckMK does not display them.

Environment

  • F5OS
  • SNMP connectivity established
  • CheckMK monitoring tool
  • F5OS MIB files available

Cause

CheckMK’s plugin architecture does not dynamically interpret vendor MIB files or OIDs. It relies on custom plugins that hard-code OIDs for monitoring.

Recommended Actions

  1. Confirm SNMP connectivity and perform an SNMP walk to verify the presence of required metrics.
  2. Ensure the complete set of F5OS MIB files is available from your F5OS device.
  3. Develop or request custom CheckMK plugins that map F5OS-specific OIDs for (not an exhaustive list):
    • CPU Utilization: F5-PLATFORM-STATS-MIB::cpuUtilizationStatsTable
    • Memory Usage: F5-PLATFORM-STATS-MIB::memoryStatsTable
    • Temperature: F5-PLATFORM-STATS-MIB::temperatureStatsTable (raw value ÷ 10 = °C)
    • PSU/Fan Status: F5-PLATFORM-STATS-MIB::platformPsuStatsTable
    • Tenant Status: F5-OS-TENANT-MIB
    • System Info: F5-OS-SYSTEM-MIB::f5OsSystem
  4. Consult CheckMK documentation and forums for guidance on plugin creation and OID mapping.
  5. Monitor for updates from CheckMK regarding F5OS SNMP support.

Additional Information

  • Temperature OID caveats may require plugin customization.
  • CheckMK plugins do not use MIB files in real-time; OIDs are coded into the plugin during development.
  • CheckMK currently uses classic BIG-IP MIB plugins, some of which overlap with F5OS hence it is able to partially interpret some of the F5OS OIDs
  • SNMP walk output from F5OS confirms the presence of all required metrics, but plugin customization is needed for CheckMK to display them.
  • F5OS uses MIB ID12276 by design, supporting dual enterprise OIDs or remapping between them is not supported by SNMP standards and would cause compatibility and support issues.
