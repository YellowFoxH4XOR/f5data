Known Issue

The BIG-IP APM apd process may restart continuously after you install a hotfix.

This issue occurs when all of the following conditions are met:

  • You install a hotfix ISO file over an existing base operating system installation that you have provisioned with BIG-IP APM.
  • The hotfix includes BigDB.dat changes.
When installing a hotfix that contains BigDB.dat changes on a system provisioned with BIG-IP APM, the associated database variables may not update properly. As a result, the apd process restarts continuously.

Impact

Users are unable to connect to the BIG-IP APM system while the apd process restarts continuously.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After installing a hotfix, the BIG-IP APM apd process restarts continuously.

Workaround

To work around this issue, you can first delete the existing image on the target volume, and then reinstall the hotfix. To do so, perform the following procedure:

Impact of workaround: The following procedure will delete all existing software and configurations from the specified target volume.

Important: The following procedure requires you to import the desired base ISO and hotfix ISO files to the /shared/images directory. For information about importing software images to the BIG-IP system, refer to K34745165: Managing software images on the BIG-IP system using the tmsh utility.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Delete the existing software image on the desired target volume using the following command syntax:

    delete sys software volume <target volume>

    For example, for a desired target volume of HD1.2, type the following command:

    delete sys software volume HD1.2

  3. Install the desired software image on the desired target volume using the following command syntax:

    Important: The following command requires you to import the desired base OS ISO and hotfix ISO files to the /shared/images directory. For example, when installing 11.3.0 HF4, you must import both the BIG-IP-11.3.0.2806.0.iso and Hotfix-BIGIP-11.3.0-3093.0-HF4.iso images to the /shared/images directory. 

    install sys software hotfix <Hotfix-BIGIP-version.iso> volume <target volume> create-volume

    For example, when installing 11.3.0 HF4 on HD1.2, type the following command:

    install sys software hotfix Hotfix-BIGIP-11.3.0-3093.0-HF4.iso volume HD1.2 create-volume

  4. To show the status of the installation, type the following command:

    show sys software status

    For example, the following output indicates that hotfix build 3093.0 is installing on volume HD1.2:

    --------------------------------------------------
Sys::Software Status
Volume  Product  Version   Build  Active    Status
--------------------------------------------------
HD1.1    BIG-IP   11.3.0  2806.0     yes  complete
HD1.2    BIG-IP   11.3.0  3093.0      no  installing hotfix
HD1.3    BIG-IP   11.3.0  2806.0      no  complete
