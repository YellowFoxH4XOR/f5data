Description

Does BIG-IP Central Manager support high availability?

Environment

  • BIG-IP Next Central Manager

Cause

BIG-IP Next Central Manager can manage highly available BIG-IP Next instances. Starting in BIG-IP Next Central Manager 20.2.0, it can be configured to be highly available. Prior to BIG-IP Next Central Manager 20.2.0, it does not support high availability configuration for itself. 

Recommended Actions

If you are running BIG-IP Next Central Manager 20.2.0 or later, you can consider setting up high availability for the BIG-IP Next Central Manager. For information on how to set up high availability for BIG-IP Next Central Manager, refer to the Setup the Standalone Node or High Availability (HA) using BIG-IP Next Central Manager section of the Install BIG-IP Next Central Manager on VMware guide.

If you are running BIG-IP Next Central Manager 20.1.0 or earlier, or if you prefer to run BIG-IP Next Central Manager as a standalone, you should take frequent backups of BIG-IP Next Central Manager.

While logged into the command-line as admin, run the following command:

/opt/cm-bundle/cm backup

To restore a backup:

/opt/cm-bundle/cm restore <file>
