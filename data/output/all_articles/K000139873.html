Description

Unable to generate license with error

Licensing Error: Error 51133, F5 registration key is not compatible with the detected platform - This platform, "", cannot be activated with this registration key "xxxxxxx-xxxxxxx".

Environment

  • BIG-IP installed under KVM version 8.1.0 or later

Cause

Issues with System Management BIOS (SMBIOS) v3.x (64-bit entry point), leading to license dossier missing the "bios_id" value.

Recommended Actions

Upgrade to KVM(QEMU) 9.0.0 or later

OR

Downgrade SMBIOS to v2.x (32-bit entry point). This can be achieved by adding the following to the virt-install command 

  --qemu-commandline='-machine smbios-entry-point-type=32'

OR

Upgrade to BIG-IP version that supports BIOS(SMBIOS) v3.x via ID2130485

Additional Information

KVM setup guide:  https://clouddocs.f5.com/cloud/public/v1/kvm/kvm_setup.html

Note that the virt-install command will still require "--virt-type kvm" as per K42353413: Error 51133 when activating license on new KVM platform

Note that the virt-install command may require specific line ordering. Here is an example of the virt-install line ordering that may work for you:

sudo virt-install \
  --qemu-commandline='-machine smbios-entry-point-type=32' \
  --name bigip1 \
  --memory 4096 \
  --vcpus 2 \
  --disk /media/user/hdd/pool/BIGIP-17.1.1.3-0.0.5.qcow2 \
  --import \
  --virt-type kvm \
  --network bridge=bri0 \
  --os-variant=rhel6.0
