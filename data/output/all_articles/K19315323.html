K19315323: Error: SYNC_ZONES from <IP> skipped. Reason: sync_zones currently running from ip <IP>

Type
Support Solution
Published
2021-04-11
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP DNS: 14.1.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.X.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K19315323

Description

BIG-IP GTM/DNS is showing the following error message.

/var/log/gtm

notice gtmd[14344]: 011a001c:5: SYNC_ZONES from < IP >  skipped. Reason: sync_zones currently running from ip < IP >

This error message will repeat multiple times.

This error message is seen on only one (1) BIG-IP GTM/DNS device.

Environment

  • BIG-IP GTM/DNS
  • Only one (1) BIG-IP device is showing this error message.

Cause

Unknown at time of publication.

Recommended Actions

To resolve the issue, you will need to restart the gtmd service.
  1. Login to the impacted BIG-IP DNS/GTM via Command Line.
  2. Run the following command:
    bigstart restart gtmd
  3. If issue is not resolved, refer to article K04095282.

Additional Information

None.
