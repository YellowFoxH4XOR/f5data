Issue

In BIG-IP versions prior to 10.2.0 and Hotfix-BIGIP-10.1.0-3372.0-HF1, the WebAccelerator module is optimized for the i386 processor architecture.

In BIG-IP 10.2.0 and later and Hotfix-BIGIP-10.1.0-3372.0-HF1, the WebAccelerator module is optimized for the pentium4 processor architecture.

This change was a result of CR136626.
