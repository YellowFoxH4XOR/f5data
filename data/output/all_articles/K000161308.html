K000161308: BIG-IQ Support for CrowdStrike Falcon Sensor Installation

Type
Support Solution
Published
2026-05-19
Updated
2026-05-22
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.X, 8.4.1, 8.4.0, 8.3.X, 8.2.X, 8.1.X, 8.3.0, 8.2.0, 8.1.0, 8.0.0
Source
https://my.f5.com/manage/s/article/K000161308

Description

CrowdStrike Falcon Sensor installation is not supported on BIG-IQ in current releases, from version 8.4.1 and below. There is no capability to install Falcon Sensor on BIG-IQ at this time. Certain BIG-IP versions support Falcon Sensor installation, but this does not apply to BIG-IQ.

Environment

  • Product: BIG-IQ

Cause

BIG-IQ does not include the code changes required to support Falcon Sensor installation in any released version.

Recommended Actions

  1. Installation of CrowdStrike Falcon Sensor is not supported on BIG-IQ.
  2. For Falcon Sensor installation on BIG-IP, refer to the related content articles below.

Additional Information

  • BIG-IP versions 17.1.3 and 17.5.1.3 support Falcon Sensor installation; this support does not extend to BIG-IQ.
  • BIG-IQ and BIG-IP are distinct products; Falcon Sensor support on BIG-IP does not imply support on BIG-IQ.
