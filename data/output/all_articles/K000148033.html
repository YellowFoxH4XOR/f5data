K000148033: Why is my API discovery not discovering all the requests that are being made?

What Happened?

You want to do an API discovery to have it mapped on the Distributed Cloud Console, but not all the requests and methods are being discovered.

Environment

  • API Endpoint Discovery

Resolution/Answer

  • API discovery only works and maps the endpoints once you get HTTP 2XX or 3XX responses on your traffic.
  • The same applies to all methods (GET, POST, DELETE, PUT...).
  • All traffic with an HTTP response of 4XX or 5XX will not get mapped.
  • Traffic, which is identified as a malicious bot, is excluded from API discovery to prevent poisoning of the discovery.
