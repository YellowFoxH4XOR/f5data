K83210155: LTM log shows ''0118000a:4: The Service Check Date check was skipped''

Type
Support Solution
Published
2020-10-30
Updated
2023-11-14
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K83210155

Description

The /var/log/ltm logs are being filled with error:  
"0118000a:4: The Service Check Date check was skipped"

Environment

  • BIG-IP
  • BIG-IP Virtual Edition

Cause

  • These logs are there because of BUG ID 714705 which is tracked internally and has no impact on the operation of the device.
  • The logs are harmless, however no fix available at this time.
Recommended Actions
You can create a High Speed Logging filter to suppress these messages and that will survive a reboot as well as a UCS or upgrade.

To create the filter using the management utility:

  1. Navigate in the GUI to :  System ›› Logs : Configuration : Log Filters
  2. Click the Create button
  3. Give it a name that makes sense for you : For example: Blackhole_Check_Date
  4. Set the dropdown for Severity to "Warning"
  5. In the message ID field enter "0118000a" (without the "")
  6. Leave Log Publisher as "None" so that they don't get sent anywhere.
  7. Click Finished.

To create the filter using tmsh:

tmsh create sys log-config filter Blackhole_Check_Date level warn message-id 0118000a

The final object looks like this in /config/bigip.conf

sys log-config filter /Common/Blackhole_Check_Date {
    level warn
    message-id 0118000a
}
