Description

DNSSEC Keys are removed from the configuration before they expire.

  • Second Generation KSK DNSSEC Key is removed from configuration
  • iQuery Connection is restarted between BIG-IP DNS devices
  • No relevant error message, however it can cause an outage if clients are unable to query for the KSK Key for the duration of the TTL of signed records that may be cached with that previous generation

Environment

  • BIG-IP DNS
  • DNSSEC Keys with auto rollover engaged
  • Software upgrade

Cause

Bug ID 1205061

Recommended Actions

Use the following command to verify that there is only one key generation (the second key generation is no longer present):

tmsh list ltm dns dnssec key 

We recommend the following to minimise impact due to this issue:

DS records need to be updated before upgrading software. In such a case when the old generation is removed there is a DS record matching the new generation.

Avoid upgrading BIG-IP DNS when DNSSEC keys are due to rollover.

Restore UCS to recover missing keys if available.

Upgrade to fixed software version. Once upgraded to fixed version, subsequent upgrades will not exhibit these symptoms.
