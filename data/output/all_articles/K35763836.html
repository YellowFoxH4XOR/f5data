Description
After suspend an BIG-IP VE then power on that BIG-IP VE, when you try to delete the management route,

config # tmsh delete sys management-route default
config #
config # tmsh list sys management-route
config #
config # tmsh save sys config

  /config/bigip_base.conf
  /config/bigip_user.conf

done
 - saving ...done
config #
config # netstat -rn

Environment

  • BIG-IP VE
  • Management route

Cause
Currently this is tracked by ID1145149.

Recommended Actions

You could consider one of the below for workaround,
  1. Reboot the VE.
  2. Delete the management IP first, then the default managemet route will also be deleted properly.
