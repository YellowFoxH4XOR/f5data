Topic

The VIPRION system is based on the concept of a cluster of blades within a VIPRION system chassis. When you install a VIPRION platform, you must assign a management IP address to the cluster. The management IP address, also referred to as the cluster IP address, is associated with the primary blade in the system and should be used to access the Configuration utility.

F5 also recommends that you define a management IP address for each blade in the chassis. This allows you to access any blade in the cluster if the cluster IP address is inaccessible.

The cluster IP address should be used to administer the VIPRION system; access to certain Configuration utility screens is not supported when connected to a secondary blade. For example, if you connect to a secondary blade using the Configuration utility, and then navigate to the Network Statistics screen, Overview > Statistics > Network, the following message is displayed:

General Database error retrieving information

Note: The same message is displayed when selecting the Statistics tab on the Interfaces screen.

If you logged into a secondary blade and received the above message, you must log in again using the cluster IP address to display the page properly.
