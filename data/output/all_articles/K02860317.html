K02860317: Non-Diagnostic: SSL Orchestrator only supports 7 paths when configuring an L2 service

Topic

SSLO L2 Service Paths

An L2 service in SSL Orchestrator requires pairs of VLANS, called paths, to function correctly.

Limitations
The configuration must not exceed 7 paths when configured or the deployment will fail.  This limitation is not enforced in the GUI, but the deployment will generate an error if more than 7 paths are configured.
