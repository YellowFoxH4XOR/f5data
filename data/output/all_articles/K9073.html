Known Issue

This is the result of a known issue. The Configuration utility does not correctly update the appropriate directories when you stop or start services from the System Services List page. As a result, the following error message is logged:

unknown status runsvstat: warning: /service/<service name>: unable to change directory: file does not exist

For example, if you attempt to stop the named service from the Configuration utility by selecting the service and clicking the Stop button, the following error messages will be reported for the service:

unknown status runsvstat: warning: /service/named: unable to change directory: file does not exist

Note: This issue also occurs if you attempt to stop multiple services simultaneously by selecting two or more services and clicking the Stop button.

F5 Product Development tracked this issue as CR84454 and it was fixed in BIG-IP 9.6. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, and WebAccelerator Release Notes.

This issue still exists in the BIG-IP 9.4 software branch.

Workaround

You can work around this issue and stop and/or start services individually by using the command line. To do so, perform the following procedure:

  1. Log in to the command line.
  2. Use the following command syntax to stop the service:

    bigstart stop <service_name>

    For example, to stop the named service, type the following command:

    bigstart stop named
  3. Verify the service is stopped by using the following command syntax:

    bigstart status <service_name>

    For example, to verify the status of the named service, type the following command:

    bigstart status named
  4. To restart the service, use the following command syntax:

    bigstart start <service_name>

    For example, to start the named service, type the following command:

    bigstart start named
