K30571581: Searching logs on the BIG-IP

Type

Published
2025-03-07
Updated
2025-07-23
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source

Description

You need to search the logs on the BIG-IP to investigate an issue.

Environment

  • Requires SSH access to the Big-IP or extracted log files from a qkview
  • Search within 7 or less days from event otherwise logs may have rotated out

Cause

Use the following grep commands to find log results. 

Recommended Actions

  1. View all non-compressed results (from the last 24 hours):
    grep -i <search-term-here> /var/log/ltm*
    • -h hides the LTM log name 

  2. View all results, including compressed (*.gz) logs (older than 24 hours): 
    zgrep -i <search-term-here> /var/log/ltm*

  3. Determine when these logs started or ended
    grep -i <search-term-here> /var/log/ltm* -h | cut -c -6 | sort | uniq -c
    • Change the 6 to 9 or 12 to view minutes & seconds
    • Cut uses the first 6 characters in the logs

  4. View compressed results:
    zgrep -i <search-term-here> /var/log/ltm.2.gz | cut -c -9 | sort | uniq -c
    • Remove the -h and specify the file

  5. Write results to file:
    zgrep -i <search-term-here> /var/log/ltm* -h > /var/tmp/<filename>.txt

  6. Write uncompressed LTM logs to file:
    grep -i <search-term-here> /var/log/ltm* -h > /var/tmp/<filename>.txt

  7. View the top or bottom of the document:
    • head /var/tmp/<filename>.txt
    • tail /var/tmp/<filename>.txt
