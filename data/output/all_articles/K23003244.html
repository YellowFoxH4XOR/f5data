K23003244: How to walk down the BIG-IQ Pool License Hierarchy

Type
Support Solution
Published
2021-05-22
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K23003244

Description

You should consider using this procedure under the following condition:

  • You are using License Pools from BIG-IQ (subscription model)
  • You need to troubleshoot or gather more data regarding a license or license assignment

Environment

  • You must have command line access to the BIG-IQ
  • You must have the appropriate role(s) to access Pool License information on the BIG-IQ License Manager

Cause
None.

Recommended Actions

  • Registration Keys
  • Active Subscriptions
  • License Assignments
  • Licensing Status
  • License Text

Impact of procedure: These procedures are all for information-gathering. No negative effects are expected from running these commands.

Registration Keys

This command will show the registration keys currently activated in the BIG-IQ License Manager

# restcurl /cm/device/licensing/pool/utility/licenses?\$select=regKey,status

Active Subscriptions

This lists the active subscriptions available under this registration key - shown as id / name / status sets.

# restcurl /cm/device/licensing/pool/utility/licenses/<registration key>/offerings/?\$select=id,name,status

Where:

  • <registration key> is a registration key from the Registration Key procedure

License Assignments

This lists the BIG-IP(s) associated with the chosen active subscription:

# restcurl cm/device/licensing/pool/utility/licenses/<registration key>/offerings/<offering id>/members?\$select=id,deviceName,status

Where:

  • <registration key> is a registration key from the Registration Key procedure
  • <offering id> is an appropriate offering ID from the Active Subscriptions procedure.

Licensing Status

This shows the status of the license file as it processes to the BIG-IP.

# restcurl cm/device/licensing/pool/utility/licenses/<registration key>/offerings/<offering id>/members/<member id>?\$select=deviceName,deviceMachineId,deviceAddress,status

Where:

  • <registration key> is a registration key from the Registration Key procedure
  • <offering id> is an appropriate offering ID from the Active Subscriptions procedure
  • <member id>  is a member id listed under the License Assignment procedure

License Text

Extract the actual license text that should also display on the BIG-IP:

# restcurl cm/device/licensing/pool/utility/licenses/<registration key>/offerings/<offering id>/members/<member id> | jq -r .licenseText

Where:

  • <registration key> is a registration key from the Registration Key procedure
  • <offering id> is an appropriate offering ID from the Active Subscriptions procedure
  • <member id>  is a member id listed under the License Assignment procedure
