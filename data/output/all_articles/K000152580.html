Description

Newly added VELOS blade is not joining the cluster, but appear to be pingable.

--------------------------------------------------------------------------------------------------
1      blade-1.chassis.local  true      true     true     true  true   In Cluster      partition-1
2      blade-2.chassis.local  true      false    false    true  false  Not In Cluster             
                                                            ^^   ^^

                                                             |__________ *Can* ping

Active controller's /var/log/messages contains repeated entries similar to the following:

omd_container.sh: nodename=controller-1 WARNING: Your password has expired.
omd_container.sh: nodename=controller-1 Password change required but no TTY available.

Environment

  • VELOS blades
  • OpenShift cluster

Cause

  • Bug ID 1575585: Unable to add blade to Openshift cluster if newly-installed blade is not member of active partition

Recommended Actions

Add the blade to an enabled partition.
