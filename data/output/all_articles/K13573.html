Known Issue

Description

ARX devices are unable to properly communicate or join a failover pair.

This issue occurs when the following conditions are met:

  • A subnet conflict occurs on the ARX RON tunnel.
  • You are attempting to re-establish a failover pair that was recently broken.

An incorrect UUID has been stored on the primary device during initialization of the RON tunnel configuration. This may occur on an ARX device that has been recently replaced using the Return Materials Authorization (RMA) process, or on an ARX that has been reset to factory defaults.

Impact

You are unable to create an active/standby pair.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You are unable to create a failover pair.
  • You see  Status: SUBNET CONFLICT in the show ron command output.
  • The UUID in the show ron command is not the UUID of the peer device.

Workaround

To work around this issue, you can evict the incorrect UUID. To do so, perform the following procedure:

Impact of workaround: None

  1. Log in to the command line.
  2. Gather the UUID of the devices, by typing the following command:

    show chassis chassinfo

    You see output that appears similar to the following example:

    show chassis chassinfo
    Identification:
     Hostname                             UUID
     ------------------------------------ --------------------------------------
     SupARX500-2b                          514483c6-6b23-11e0-91b7-231dc3720a9

     Chassis:
     Chassis Type  Model Number                          HW Ver.  Serial
     ------------  ------------------------------------  -------  -------------
     ARX-500+       ARX1                                  B 20     03003262

     Chassis Environment:
     Base MAC Address    Power            Chassis Revision
     -----------------   --------------   ----------------
     00:0a:49:0c:be:00   Online           37 6

  3. Review the Ron status by typing the following command:

    show ron devicename

    You see output that appears similar to the following example:

    SupARX500-2a# show ron SupARX500-2b

          Switch Name: SupARX500-2b

          HA Peer Switch: (None)

          Status: SUBNET CONFLICT

          Uptime: Unknown

          UUID: d358674a-7a88-11e1-b408-6906200a13aa < wrong UUID

  4. Evict the incorrect UUID information by typing the following syntax:

    ron evict <incorrect peer UUID>

    For example:

    ron evict SupARX500-2a# ron evict d358674a-7a88-11e1-b408-6906200a13aa
