Known Issue

This is the result of a known issue. The qkview utility accesses a large number of files in a short period of time. Running qkview will generate IDE interrupts, which may decrease Traffic Management Microkernel (TMM) performance. The performance degradation is most severe when the Compact Flash (CF) card is accessed, because the CF card does not support DMA.

F5 Product Development tracked this issue as CR57883 and CR58211, and it was fixed in BIG-IP 9.1.2 for the BIG-IP 9.1 software branch and in version 9.2.3 for the BIG-IP 9.2 software branch. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller Release Notes.

For more information about IDE interrupts, refer to K5697: IDE interrupts may impact TMM performance.
