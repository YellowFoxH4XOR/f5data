Description

In rare instances, F5 Support may ask to enable "trace" debugging level for the bd_agent daemon.

Environment

ASM is provisioned.

Cause

None.

Recommended Actions

Disabling additional bd_agent debugging

To enable "trace" logging for the bd_agent process, issue the following from the CLI:

tmsh modify sys db log.asm.bdagent.level { value "trace" }

Additional messages will be logged to the /var/log/ts/bd_agent.log file.

Note: The change should be detected automatically by the bd_agent daemon.  No restart should be required.

Disabling additional bd_agent debugging

To turn off the additional debugging, change the modified priority back to the default and save:

tmsh modify sys db log.asm.bdagent.level debug

Additional Information

If using the reset-to-default option with the "tmsh modify sys db log.asm.bdagent.level" command, the bd_agent daemon has to be restarted.
