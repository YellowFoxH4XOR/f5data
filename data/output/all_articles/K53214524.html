Known Issue

Users assigned the Manager role are unable to manipulate Secure Web Gateway (SWG) objects.

This issue occurs when the following condition is met:

  • Your BIG-IP SWG objects are configured with a user that is assigned the Manager role.

    Impact

    Users with the Manager role are unable to manipulate SWG objects through the Configuration utility.

    Symptoms

    As a result of this issue, you may encounter the following symptom:

    • In the Configuration utility, users with the Manager role are unable to create, delete, or modify the following SWG objects:
      • Access > Secure Web Gateway > URL Categories
      • Access > Secure Web Gateway > URL Filters
      • Access > Secure Web Gateway > Applications
      • Access > Secure Web Gateway > Application Filters

    Workaround

    To work around this issue, you can use the TMOS Shell (tmsh) to manipulate SWG objects. For example, to create a new URL Category, perform the following procedure:

    Impact of workaround: Performing the following procedure should not have a negative impact on your system.

    1. Log in to the tmsh utility by typing the following command:

      tmsh

    2. To create a new custom category, use the following command syntax:

      create /sys url-db url-category /<partition>/<category name> display-name <category display name> urls add { <url> }

      For example:

      create /sys url-db url-category /Common/new-category display-name new-category urls add { https://www.example.com }

    3. Save the new category by typing the following command:

      save /sys config

    4. To exit the tmsh utility, type the following command:

      quit
