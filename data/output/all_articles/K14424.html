Known Issue

The TMOS Shell (tmsh) may display the incorrect tlvmap value of 114552.

This issue occurs when you use the Configuration utility to manually update the properties of a BIG-IP network interface, regardless whether the global network setting on Link Layer Discovery Protocol (LLDP) is set to Enabled or Disabled.

Impact

None. This is a cosmetic issue.

Symptoms

As a result of this issue, you may encounter one or more of the following symptom:

  • When you use the list net interface all lldp-tlvmap command to display the lldp-tlvmap values, you see values that deviate from the default of 130943 on the affected interfaces.
  • As a result of the network interface update via the Configuration utility, the unused bits in the Type, Length, Value (TLV) bitmask of the LLDP setting are incorrectly set to 114552. However, it does not affect the functionality of the network interface.
  • If the network interface level LLDP setting is set to any value other than Disabled, this lldp-tlvmap value will be affected. In addition, if the network interface level LLDP setting is set to Disabled, the lldp-tlvmap value will not be affected.

Resolution

Workaround

To work around this issue, you can manually set the tlvmap value to the default value of 130943. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To set the tlvmap value to the default of 130943, use the following command syntax, where <interface> is the interface that you want to change:

    modify net interface <interface> lldp-tlvmap 130943

    For example:

    modify net interface 1.1 lldp-tlvmap 130943

  3. Save the change by typing the following command:

    save /sys config
