Description

The BIG-IP Connectivity Profile is configured with the option "Reuse Windows Logon Credentials".

Upon connecting the VPN, users are prompted to put their credentials, when they expect the EdgeClient software to reuse their Windows credentials, for a seamless login experience.


Environment

  • APM EdgeClient

Cause

The client machine may not trust the the APM gateway.


Recommended Actions

Please configure the APM gateway name (or FQDN) as a "Trusted Sites".


Additional Information

With collecting some EdgeClient logs, you may spot the following significant record:

1970-01-01,12:00:00:012, 5336,5208,Standalone, 48, , 1771, CStandaloneProfile::IsWinlogonSessionReuseEnabled, Dynamic profile not trusted
