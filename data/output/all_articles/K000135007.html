Topic

This article explains how you can configure BIG-IP APM to use a DHCP server for dynamic DNS to assign IP addresses to clients connecting to BIG-IP APM network access, VPN.

Description

Ordinarily, you assign IP addresses to clients connected to BIG-IP APM network access VPN from the addresses configured in the network access lease pool. There may be use cases where you need to assign IP addresses from a DHCP server in your environment. This DHCP server manages all available client addresses and handles dynamic DNS for all client devices. 

To achieve this, you can use the APM-DHCP iApp template. For more information about installing and configuring the iApp, refer to APM-DHCP Access Policy Example and Detailed Instructions on DevCentral.
