K000160088: Authentication failure with Form‑Based Client‑Initiated SSO when secure password field is enabled

Description

When using form-based client-initiated SSO with the password field set to  Secure in the configuration, users experience authentication failure when accessing the intended application.

Access succeeds only when the Secure password setting is disabled.

Environment

  • APM
  • Form-based Client-Initiated SSO

Cause

SSO password control references a session variable without the secure flag -secure in the access policy. When the password field is set as secure in the SSO configuration, APM expects the session variable to be encrypted. 

Answer/Recommended Actions

  1. Create a secure password variable in the access policy.
  2. Update the password control in the SSO configuration to reference the secure variable.
