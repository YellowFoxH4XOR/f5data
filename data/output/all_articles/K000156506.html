K000156506: TMM restart in secondary slot following access policy creation

Type
Support Solution
Published
2025-09-18
Updated
2025-09-26
Applies to
  • BIG-IP
  • BIG-IP APM: 15.0.0, 15.0.X, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 16.0.X, 16.1.0, 16.0.1, 16.0.0, 15.0.1
Source
https://my.f5.com/manage/s/article/K000156506

Description

After creation of access policy, mcpd restarted and triggered failover.

The following log messages can be found in /var/log/ltm:

slot2 warning mcpd[4368]: 01071859:4: Warning generated : apm log-setting (/Common/default-log-setting) is attached to apm profile access (/Common/apmpolicy-name). You may replace this log setting with your own setting.

slot2 err mcpd[4368]: 010713cf:3: Configuration group '/Common/apmpolicy_name' has invalid source '/Common/standard'

Environment

  • BIG-IP APM
  • MCPD restart
  • Multi-blade VIPRION chassis  

 

Cause

Bug ID 974241

 

Recommended Actions

Upgrade to fixed BIG-IP version 

 

Additional Information

None
