Topic

This article applies to BIG-IP 9.0.0 - 9.3.1. For information about other versions, refer to the following articles:

  • K14996: Configuring a virtual server to automatically redirect HTTP requests to HTTPS (11.4.0 and later)
  • K7125: Configuring a virtual server to automatically redirect HTTP requests to HTTPS (9.4.0 - 11.3.0)

You can use the following rule to automatically redirect users to HTTPS when they connect to a virtual server using HTTP:

rule redirect_rule { when HTTP_REQUEST { HTTP::redirect "https://[getfield [HTTP::host] ":" 1][HTTP::uri]" }}

Note: The [getfield [HTTP::host] ":" 1] function in the above iRule extracts the hostname from the host header and, if a non-standard port is specified, removes the port from the host header.

You must adhere to the following requirements for this rule to work properly:

  • The rule must be enabled for use with the HTTP virtual server.
  • Virtual servers must exist for both the HTTP and HTTPS ports.
  • The HTTP and HTTPS virtual servers must have the same IP address.

Creating the rule using the BIG-IP LTM Configuration utility

You can create the rule by performing the following procedure:

  1. Log in to the BIG-IP LTM Configuration utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Click Create.
  5. In the Name box, type a name for the iRule.

    For example:

    redirect_rule

  6. In the Definition box, enter the following iRule code:

    when HTTP_REQUEST {
    HTTP::redirect "https://[getfield [HTTP::host] ":" 1][HTTP::uri]"
    }

  7. Click Finished.

Definitions of the rule components

Definitions of the rule components are as follows:

ComponentDescription
rule redirect_ruleThis portion of the rule begins the rule and specifies the name of the rule.
when HTTP_REQUESTThis portion of the rule tells the rule to trigger whenever a new HTTP request is received, such as a GET request.
HTTP::redirectThis rule command tells the rule to issue a redirect to the client and is followed by the URL that will be used in the redirect.
[HTTP::host]This portion of the rule is replaced with the host name to which the client attempted to connect.
[HTTP::uri]This portion of the rule is replaced with the content path (URI) requested by the client.
getfield <string> <split> <field_number>This iRule function splits a string on a character or string, and returns the string corresponding to the specific field.
