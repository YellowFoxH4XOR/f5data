K000092698: SDC 5.2 installation is not progressing

Type

Published

Source

Description

SDC 5.2 introduces 6 new and 2 changes to the GRUB boot mandatory parameters:

New parameters

  • ip0 - IP address of management network interface
  • ip1 - IP address of interconnection (IC) network interface
  • netmask0 - ip0 netmask
  • netmask1 - ip1 netmask
  • device0 - ip0 ethernet interface name
  • device1 - ip1 ethernet interface name

Change parameters

  • master0 - ip1 of first vInstaller
  • master1 - ip1 of second vInstaller

In SDC 5.1 installation guide, master0 and master1 use the management interface IP address of the vInstaller nodes instead.

Next, you need to ensure the vInstaller Application Instance listenInterfaceName element uses ic in the Site Topology File.

<applicationInstance IPv="v4" listenInterfaceName="ic-ens161" name="VInstaller" type="vInstaller"/>

If either boot parameters is not defined correctly or Site Topology File vInstaller is not updated to use ic listenInterfaceName, you may observe any of the following symptoms:

  • salt commands only work on the local vInstaller and not other vInstaller

Environment

  • SDC 5.2
  • Installation

Cause

SDC 5.2 Salt Master communicates over IC network and firewalld only accept salt traffic over IC and drop them on other networks.

Recommended Actions

Review and follow SDC 5.2 Installation Guide
