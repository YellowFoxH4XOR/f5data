Description
The BIG-IP OneConnect profile (Local Traffic >> Profiles >> Other >> OneConnect) has Maximum Reuse setting which specifies the maximum number of times that a server-side connection can be reused by the system, and the default value is set to 1000; however, what does value 0 mean for this setting?

Setting Maximum Reuse to 0 (zero) means it's disabling reuse and no server side connection can be reused. 

Environment

  • BIG-IP
  • OneConnect profile

Cause
None

Recommended Actions

None

Additional Information
When setting Maximum Reuse to 1, the system uses a server side connection once after the initial use; therefore, you see each server side connection being used twice if you check the stats (K8688)
