Issue

Error Message

notice bigd[<PID>]: 01060136:5: Received links up - monitoring starts

In this error message, note the following:

  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.

For example:

notice bigd [23976]: 01060136:5: Received links up - monitoring starts

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • This message is logged in BIG-IP 11.6.0 and earlier when the bigd process receives a links-up message indicating that monitoring can proceed. At that point, the bigd process begins monitoring (sending probes and processing responses).

Starting in BIG-IP 11.6.1, this message is removed. However, a message similar to the following example is inserted to note status changes:

(_set_db_variable): adaptive tmstat logging enabled: true

Impact

This message is not an error, but a notification that the bigd process began its logging (including sending probes and processing responses).

Recommended Actions

None
