Topic

You should consider using this procedure under the following condition:

  • The configuration synchronization (ConfigSync) operation is failing due to a large number of FIPS keys in the BIG-IP configuration.

Description

When a large number of FIPS keys (typically 1,000 or more) are configured on a BIG-IP platform that supports the FIPS hardware security module (HSM), a ConfigSync operation may take longer than the default 300 second (5 minute) timeout to complete. In this scenario, the ConfigSync operation fails, and a message similar to the following example is displayed:

Checking configuration on local system and peer system...
Peer's IP address: 10.0.0.1
Synchronizing Master Keys...
Saving active configuration...
Configsync Mode: Push
Transferring UCS to peer...
Installing UCS on peer...
SOAPException: 'Unexpected return Content-Type: text/html; charset=iso-8859-1'

Transport and install failed
Error running config sync all.
BIGpipe parsing error:
01110001:3: Error running config sync all

If you have approximately 1,000 or more FIPS keys configured on the BIG-IP system, you may need to increase the timeout setting to allow ConfigSync to complete.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the BIG-IP command line.

Procedures

Increasing the ConfigSync timeout value

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To configure the appropriate timeout value, use the following command syntax:

    modify /sys httpd fastcgi-timeout <seconds>

    For example, to configure a timeout of 600 seconds (10 minutes), type the following command:

    modify /sys httpd fastcgi-timeout 600

  3. Confirm the change by typing the following command:

    list /sys httpd fastcgi-timeout

    The command output should appear similar to the following example:

    sys httpd {
        fastcgi-timeout 600
    }

  4. Save the configuration by typing the following command:

    save /sys config partitions all

  5. Restart the httpd service by typing the following command:

    restart /sys service httpd
