K000140441: F5OS-A rSeries r2x00 / r4x00 not showing interface associated with VLAN in tenant after assigning VLAN to interface in F5OS

Type
Support Solution
Published
2024-07-26
Updated
2026-08-18
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 15.1.X, 17.1.1, 17.1.0, 15.1.10, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0
Source
https://my.f5.com/manage/s/article/K000140441

Description

After assigning a VLAN to an interface in F5OS, the VLAN does not show any associated interface in the BIG-IP tenant , or shows an interface that was previously assigned to it.

For example, given the following interface and VLAN association in F5OS:

vlans vlan 100
 config vlan-id 100
 config name v100
!

interfaces interface 5.0
 config type ethernetCsmacd
 config enabled
 ethernet switched-vlan config trunk-vlans [ 100 ]
!

The VLAN in the BIG-IP tenant is missing an interface:

net vlan /Common/v100 {
    tag 100
}

You may also observe a chmand error similar to the following in /var/log/ltm:

012a0003:3: hal_mcp_process_error: result_code=0x1070094 for result_operation=eom result_type=eom

Environment

  • F5OS-A
  • rSeries r2x00 / r4x00

Cause

Bug ID 1231889: Mismatched VLAN names (or VLANs in non-Common partitions) do not work properly BIG-IP tenants running on r2000 / r4000-series appliances

Note: The affected VLAN does not need to have a mismatched name or reside in a non-Common partition. This problem will occur if any VLAN meets the conditions.

Recommended Actions

There is no fix for bug ID 1231889 at the time of this article's publication, but a workaround is to assign the interface to the VLAN directly within the tenant.

Note: In some customer's environment, performing a bigstart restart may be needed for traffic to flow properly.

Additional Information

Given the example in the description of this article, a trunk VLAN on interface 5.0 should appear similar to the following inside the tenant:

net vlan /Common/v100 {
    interfaces {
        1.5 {
            tagged
        }
    }
    tag 100
}
