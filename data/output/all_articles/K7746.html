Topic

The Online Certificate Status Protocol (OCSP) is a standard protocol used for obtaining X.509 digital certificate revocation status. On the BIG-IP system, the SSL OCSP authentication module may be used to authenticate client connections by checking the revocation status of an SSL certificate, as a part of authenticating that certificate.

Configuring an SSL OCSP authentication module requires creating the OCSP responder object and then configuring the SSL OCSP profile.

For more information about the SSL OCSP authentication module, refer to the Configuring Remote SSL OCSP Authentication chapter of the BIG-IP Local Traffic Manager: Implementations manual.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

When creating the OCSP responder object, you can define one or more external OCSP responder servers that check the revocation status of an SSL certificate. If you define more than one OCSP responder, the Configuration utility orders the list of OCSP responders alphabetically. The BIG-IP system then uses the ordered list to determine which OCSP responder to query first.

You can define the order in which the BIG-IP system selects OCSP responders by prepending letters to the names of the OCSP responders when you create the OCSP responder object list. For example, the OCSP responder name, a_responder, will appear in the BIG-IP configuration before the name, b_responder. The OCSP responder appearing at the top of the list will be queried first by the BIG-IP system.

To define the order in which the BIG-IP selects OCSP responders to be used in the SSL OCSP profile, perform all of the following procedures:

  • Creating the OCSP responder objects
  • Creating the SSL OCSP profile

Creating the OCSP responder objects

To create a list of alphabetically ordered OCSP responders, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. Under Authentication, click OCSP Responders.
  5. Click Create to create the first OCSP responder.
  6. For Name, type a name for the OCSP responder, prepending the letter a to the name. This will be the OCSP responder that you want the BIG-IP system to query first.
  7. Complete the OCSP responder configuration.
  8. Click Finished.

Repeat this procedure to create additional OCSP responders, prepending a letter to the name depending on what order you want the BIG-IP system to query the server.

Creating the SSL OCSP profile

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. Under Authentication, click Configurations.
  5. Click Create.
  6. For Name, type a name for the SSL OCSP profile.
  7. Under Type, click SSL OCSP.
  8. For Responders, move the list of OCSP responders that you created in the previous procedure from Available to Selected.
  9. Click Finished.

Note: The list of OCSP responders will be sorted alphabetically after you click Finished.
