K000139194: vCMP host disk partition /appdata running out of space

Type
Support Solution
Published
2024-04-05
Updated
2024-07-25
Status
Final
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000139194

Description

  • vCMP Host reports partition /appdata nearly full
  • Log messages similar to the following can be seen on /var/log/ltm

err diskmonitor[3380]: 011d0004:3: Disk partition /appdata has only XX% free

Environment

  • vCMP Host
  • vCMP Guests
  • virtual disk
  • /appdata on Host

Cause

Guest disk images are stored in /appdata. It is expected for vCMP guest vdisks to grow in size over time due to upgrades and general use.

Recommended Actions

In order to increase or recover disk space on the vCMP host /appdata, there are several options:

Increase disk space:

Increasing the size of the appdata volume with the lvextend utility. For additional information, please refer to K13355459

Recover disk space:

  • Create a UCS backup from each vcmp guest, then delete, recreate and deploy new guests and restore the configuration from UCS on each guest. This allows the new vmdisks volumes to be recreated using less disk space. Refer to K000140235
  • Delete any unused vCMP guests and delete their disk images.
  • Migrate Guests to other environments to free space.Increasing the size of the appdata volume with the lvextend utility
