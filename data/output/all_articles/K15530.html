Description
Increasing the amount of system information logged, also known as verbosity, increases system resource utilization as well. For example if you set the log level to Warning, all messages from Emergency level to Warning level are logged. If you set the log level to Debug, all messages from Emergency level to Debug level are logged.

There are up to 8 levels of logging depending on the type of logs being modified:

  • Emergency (lowest amount of verbosity)
  • Alert
  • Critical
  • Error
  • Warning
  • Notice
  • Informational
  • Debug (highest amount of verbosity)

Important: F5 does performance and sizing tests with logging set at default levels. While our products offer more verbose logging at debug level for troubleshooting purposes, we do not recommend using debug logging in production scenarios because the additional load incurred may cause instability. If debug logging is required for your deployment, the system capacity may be greatly reduced.

The most verbose level, Debug, produces large amounts of data and can cause significant resource utilization. You should use the Debug logging level only during an active troubleshooting session.

Environment

  • Any BIG-IP product line with variable logging levels.
  • A need to increase logging for a troubleshooting session.

Cause

None

Recommended Actions

Important: In rare cases, the additional resource demands of Debug logging may cause poor performance or a system failure if the BIG-IP system is at high resource utilization before you enable Debug logging. You must review your environment, and consider carefully if your system is under heavy load, or has high resource utilization (CPU/memory/disk space)

  1. To minimize impact on the BIG-IP system, F5 recommends that Debug logging only be enabled when advised by F5 Technical Support, and for as short a time as possible to collect the necessary diagnostic data.
    Important: Always note the default logging level before changing it, and be certain to re-enable the default logging level immediately after collecting diagnostic data.
