Description

F5 Support may ask you to collect profiling data to help identify the cause of high CPU or other resource utilization issues.
 

Environment

  •  ASM / Advanced WAF provisioned

Cause

None

Recommended Actions

Note: The oprofile data should be collected in real-time, whilst the high CPU issue is occurring.

Run the following commands from the CLI:

opcontrol --deinit
modprobe oprofile timer=1
echo 0 > /proc/sys/kernel/nmi_watchdog
opcontrol --no-vmlinux; opcontrol --setup --separate=lib;
opcontrol --reset
opcontrol --start
sleep 30
opcontrol --stop
opcontrol --dump
tar -czf /var/tmp/oprofile_dump.tar.gz /var/lib/oprofile/

Note: This will have a minor effect on the CPU—about 3% between the opcontrol start and stop.

After the commands complete, which should take half a minute, provide the /var/tmp/oprofile_dump.tar.gz file and fresh asmqkview output to F5 Support.
