Description

BIG-IP SSL Orchestrator and BIG-IP APM with Secure Web Gateway use Forcepoint URL Database updates. Forcepoint recently announced a migration from their legacy 32-bit database to a new 64-bit version; in addition, Forcepoint indicated that 32-bit database services will end on September 30, 2025.

Impact

On an existing deployment with TMOS versions that do not support the 64-bit database, URL database classification will continue to function correctly because the urldb plug-in has the databases in memory. However, if the system is rebooted, the urldb plug-in can load the old databases from disk during startup. As a result, the deployment will not receive any database updates, which poses a security risk. On a new deployment with TMOS versions that do not support the 64-bit database, URL database classification will fail and policy execution will follow the failure path out of category lookup.

Recommended Actions

To continue to receive Forcepoint  URL Database updates, you must update your BIG-IP system to a version that uses the new 64-bit database. This issue is fixed in:

  • BIG-IP 17.5.0
  • BIG-IP 17.1.3
  • BIG-IP 16.1.6

For more information about supported BIG-IP versions, refer to K5903: BIG-IP software support policy. 

Forcepoint URL Database updates will cease to provide new data on the 32-bit version. F5 recommends upgrading to a supported fixed version as soon as possible.

To test that URL Database updates are working correctly, manually initiate a urldb download after upgrade by clicking the “Download Now” button in the BIG-IP UI and monitor /var/log/urldbmgr-trace.log. If there is no error log in urldbmgr-trace.log, then the 64-bit database download is successful. Another option is to check the downloaded database version in the BIG-IP UI and verify that the version gets incremented after the next download window. To do so, enter the following command:

tmsh list sys url-db all-properties

For more information, refer to the Manually Updating Database section on Clouddocs.
