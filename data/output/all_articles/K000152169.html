K000152169: The system returned an unexpected error (400 Bad Request). Failed to get token.

Type
Support Solution
Published
2025-06-26
Updated
2025-09-30
Applies to
  • BIG-IQ
  • F5OS
Source
https://my.f5.com/manage/s/article/K000152169

Description

When adding an F5OS device into BIG-IQ F5OS/Platform/Devices the following error is given - The system returned an unexpected error (400 Bad Request). Failed to get token.

Environment

  • BIG-IQ 
  • Adding F5OS device for managing

 

Cause

The error message is not precise enough as to why the BIG-IQ fails to get the token - potentially the BIG-IQ cannot reach the F5OS device due to routing issues or a firewall in between.

 

Recommended Actions

Check connectivity between the BIG-IQ and the device.

 

Additional Information

RFE ID1965601 created to improve the error message when there is indeed a connectivity issue.
