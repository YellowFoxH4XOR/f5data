Topic

The FirePass Windows Mobile SSL VPN client does not support split tunneling. For Windows Mobile applications that use the Microsoft Connection Manager API, you can configure the Work URL Exceptions list to specify a list of hostnames that should not route through the SSL VPN tunnel. Traffic from applications that do not use the Connection Manager API will be routed through the SSL VPN tunnel, regardless of whether the remote hostname is in the Work URL Exceptions list.

Note: For information about adding a hostname to the Work URL Exceptions list on a Windows Mobile device, refer to the following location:

http://www.microsoft.com/windowsmobile/en-us/help/synchronize/make-connections.mspx
