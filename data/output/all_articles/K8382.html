Known Issue

This is the result of a known issue. A boot_marker log entry similar to the following example should appear in the /var/log/ltm file when the BIG-IP system is rebooted:

boot_marker: ---===[ HD1.1 - BIG-IP 9.4.3 Build 1.4 ]===---

However, in BIG-IP version 9.3.1, the boot_marker log entry does not appear in the system log file following a reboot.

F5 Product Development is tracking this issue as CR85689.

This issue has been addressed in Hotfix-BIG-IP-9.3.1-HF2, which has been issued for BIG-IP versions 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
