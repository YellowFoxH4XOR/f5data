Description
Cross Site Scripting Attack Signature Triggered.

Environment

  • Request Blocked
  • Signature ID : 200101414
  • Skype Application

Cause

The request headers contains the following headers:

Content-Type: multipart/alternative;boundary=<random_characters>;type="text/plain"
Accept: application/vnd.microsoft.com.ucwa+json

This type of Content is currently not supported by BIG-IP ASM.

Hence the attack signature is triggered and request is blocked.

Recommended Actions

Create a header-based content profile for the affected URI to bypass BIG-IP ASM.  For example, this configures the BIG-IP ASM to ignore requests to /exampleuri when the Accept is application/vnd.microsoft.com.ucwa+json:
  1. Log in to the Configuration utility (GUI)
  2. Navigate to Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs
  3. Click Create to build a new Allowed URL definition
  4. Click Advanced to display the Header-Based Content Profile
  5. For URL, enter /exampleuri
  6. Click the Header-based Content Profiles tab and enter the following information:
    Request Header Name:  Accept
    Request Header Value:  application/vnd.microsoft.com.ucwa+json
    Body handling: Do nothing
  7. Click Add
  8. Click Create to save
  9. Click Apply Policy to apply the changes to the policy.

Additional Information
In some cases, administrators decided to disable the Attack Signature.
