Known Issue

BIG-IP CGNAT may leak memory when rejecting certain inbound traffic.

This issue occurs when all of the following conditions are met:

  • You have a Large Scale NAT (LSN) pool with inbound connections, or Hairpin Mode is set to Enabled.
  • The virtual server rejects non-TCP/UDP inbound traffic.

Impact

System performance may degrade over time, and the system may become unresponsive or reboot due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • When rejecting non-TCP/UDP inbound traffic, the system leaks a small amount of memory with each packet. Depending on the volume of affected traffic, this leak can be slow or fast.
