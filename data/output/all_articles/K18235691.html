Description
Configuration fails to load after upgrade with the error message in /var/log/ltm file or in TMSH. 

01070088:3: The requested object name (profile) is invalid.

Environment

  • Software upgrade from 11.4.1 to 11.5.x and above. 
  • Configure profiles

Cause
Profile names configured with the name profile fails to load the configuration after the upgrade. 

Recommended Actions

Rename profile name (profile) with a different name to work around the issue.
