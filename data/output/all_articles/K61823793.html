Description

New neorond errors showing up in the logs while the box is rebooting.

err neurond[9270]: rule_add: database ipv4_dst; client ruleno 0x00000200fb500338 already in table
err neurond[9270]: rule_add: database ipv4_dst; client ruleno 0x00000200fb500350 already in table

Environment

  • Upgrade from 15.1.1 to 15.1.2.1

Cause

ID1009981

There are 2 possibilities for this to happen.
1) The client rule number is duplicated.
2) We are adding the same rule twice as we didn’t get an ack for the first rule addition in time triggering a re-add.

The logs indicate that the rule we are attempting to add already exists in the table.

Recommended Actions

These error messages are benign and can be safely ignored.
