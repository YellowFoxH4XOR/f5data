Known Issue

This is the result of a known issue. The BIG-IP ASM bd process may core when the Multiple Decoding feature is configured to perform three or more decoding passes and attempts to decode a large input parameter.

Note: Multiple Decoding is set under Policy > Blocking > Evasion Technique. For more information, refer to the Configuration Guide for BIG-IP Application Security Management.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

F5 Product Development tracked this issue as CR108153 and it was fixed in BIG-IP ASM 9.4.7. For information about upgrading, refer to the BIG-IP ASM release notes.
