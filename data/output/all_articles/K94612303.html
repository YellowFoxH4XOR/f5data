Known Issue

The BIG-IP ASM Policy Diff feature may erroneously indicate a difference with the HTTP HEAD method.

This issue occurs when the following condition is met:

  • You compare two BIG-IP ASM security policies with Policy Diff (by navigating to Application Security > Security Policies > Policy Diff).

Impact

Policy Diff erroneously indicates a difference with the HTTP HEAD method.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Policy Diff erroneously indicates a difference with the HTTP HEAD method.
