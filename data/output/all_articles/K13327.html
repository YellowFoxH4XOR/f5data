Topic

Purpose

You should consider using this procedure under the following condition:

  • You want to allow users to create application tunnel favorites or be able to enter direct application connections.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your FirePass controller is configured with application tunnel access.

Description

When you use the FirePass Application tunnels feature, an application tunnel provides a secure, application-level, TCP/IP connection from the client to the network. By clearing the Show administrator-defined favorites only option for a master group, you can allow users to add their own application tunnel favorites and directly enter connections to applications through the direct connect option. 

Note: The user-defined favorites feature is available only to FirePass local user accounts.

Procedures

Configuring FirePass to allow use- defined application tunnel favorites and direct application access

This procedure configures FirePass to allow users to create their own application tunnel favorites and directly enter application connections.

Impact of procedure: None

  1. Log in to the FirePass Administrator console.
  2. Go to Application Access : App Tunnels : Master Group Settings.
  3. Select the master group in which you want to allow user defined favorites, from the Master Group drop-down menu. 
  4. Clear the Show administrator-defined favorites only check box.
  5. Click the Allow List: text box.
  6. Enter the host information for hosts to which you want to grant access.
  7. Click the Update button.
