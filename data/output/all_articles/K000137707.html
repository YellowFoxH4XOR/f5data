Source

Description

In BIG-IP APM Citrix Replacement mode, after upgrading Citrix VDA to versions 2303/2305/2308, it is not possible to launch a second application from the BIG-IP APM Webtop.
The first application is successfully launched, but while clicking on the second application, it fails with the pop up message:


Application Launch failed
ErrorId (unspecified), BrowserError (None), MPSError (None), RemedyHint (None)

 

﻿

 

Environment

  • BIG-IP APM
  • Configure Citrix Replacement mode on BIG-IP APM
  • Citrix VDA 2303/2305/2308

Cause

A change on the Citrix VDA versions 2303/2305/2308

Recommended Actions

Please upgrade to the latest version of all software versions - v15.1.10.2, v16.1.4.1, v17.1.1

Additional Information

None
