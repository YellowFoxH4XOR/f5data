Description

When running BIG-IP APM Edge Client version 7.2.6 (build 7260) or earlier on MacOS 26.1 (Tahoe), VPN connections may fail to establish correctly. The Edge Client icon displays a red triangle warning, even though session logs indicate the access policy was completed successfully. This issue occurs regardless of endpoint inspection status and with the latest OPSWAT EPSEC package installed.

Environment

  • Product: BIG-IP APM
  • Version: 17.1.2
  • Edge Client: 7.2.6 (build 7260) or earlier
  • MacOS: 26.1 (Tahoe)
  • OPSWAT EPSEC package: 1915 or newer
  • Endpoint Inspection enabled

Cause

The problem is due to incompatibility between BIG-IP Edge Client version 7260 or earlier and changes introduced in MacOS 26.1 (Tahoe). These changes prevent the Edge Client from establishing a VPN connection, even when all endpoint checks pass.

Recommended Actions

  • Upgrade the BIG-IP Edge Client to version 7.2.6.1 (build 7261) or higher, which restores compatibility with MacOS 26.1.
    • Download Edge Client build 7261
    • Upgrade instructions
    • Release notes for Edge Client
  • Ensure that the latest OPSWAT EPSEC package (1915 or newer) is installed for endpoint inspection:
    • EPSEC upgrade instructions
  • After upgrading, verify that affected users can connect successfully using the new client.
