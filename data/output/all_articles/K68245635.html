Description

How to update self-signed certificates with CA (internal or external) signed certificates on GTM/DNS, LTM devices which are part of an iQuery mesh

  • Want to update these self signed certificates to internal or external CA signed certificates.
  • There may be an intermediary CA certificate present.

Environment

BIG-IP GTM/DNS and LTM devices

  • These GTM/DNS and LTM devices are part of an existing iQuery mesh
  • They are running currently with self signed certificates.

Cause

N/A

Recommended Actions

Follow the steps in order to update the certificates.

  1. Generate the CSR from all GTM/DNS and LTM devices and get it signed by the root or intermediate CA.
  2. After these certificates signed, import them to the respective devices (both GTM and LTM devices).
  3. Article K16951115 provides a very good outline for performing the above steps.
  4. After verifying that the devices are using the updated certificates visiting the management WebUI from browser proceed to next step.
  5. Get the PEM bundle containing (1 - leaf/server cert, 2 - intermediate ca cert, 3 - root ca cert in order) in order. PEM bundle can be obtained from the CA which signs the CSR.
  6. Only on GTM/DNS devices, go to DNS ›› GSLB : Servers : Trusted Server Certificates, import the PEM bundle.
  7. Once imported successfully, run command below from GTM/DNS devices to bring the iQuery command with new certificates.
    # bigip_add <LTM-IP>
    Example if the LTM IP is 10.10.10.50, use the following command:
    # bigip_add 10.10.10.50
  8. Following command can be used to verify if the iQuery connection has been established successfully.
    # tmsh show gtm iquery
