Known Issue

This is the result of a known issue. If BIG-IP 10.1.0 is installed on a WebAccelerator 4500 platform using the image2disk utility, and the image2disk utility is invoked with the --format option specifying either disk-formatting scheme, the installation will fail. When these conditions are met, the installation will hang when attempting to process the BIND package. The BIG-IP WebAccelerator displays the following output on the serial console before the installation hangs:

info: RPM: TS-tsui-10.1.0-3341.0
info: RPM: dashboard-10.1.0-3341.0
info: RPM: f5-console-serial-10.1.0-3341.0
info: RPM: sam-www-10.1.0-3341.0
info: RPM: WA-10.1.0-3341.0
info: RPM: sam-client-10.1.0-3341.0
info: RPM: sam-linux-svpn-10.1.0-3341.0
info: RPM: sam-mac-svpn-10.1.0-3341.0
info: RPM: sam-main-10.1.0-3341.0
info: RPM: wa-master-10.1.0-3341.0
info: RPM: bind-9.6.1.P1-3341.0   <--- hangs here

If the BIG-IP WebAccelerator is rebooted after the issue has occurred, the GRUB menu will only feature the Maintenance Operating System (MOS).

Note: This issue does not affect BIG-IP 10.2.0.

F5 Product Development is tracking this issue as ID 327374 (formerly CR140956).

Workaround

In order to install BIG-IP 10.1.0 on a WebAccelerator 4500 platform, perform one of the following workarounds:

  • Install BIG-IP 10.1.0 without reformatting the disk array. To do so, you can either invoke the image2disk utility without the --format option, or if you are upgrading from BIG-IP 10.0.x, you can use the Configuration utility or the bigpipe utility.

    Note: For more information, refer to the BIG-IP     WebAccelerator release notes.
  • Perform a clean installation of BIG-IP 10.1.0. To do so, refer to K10819: Performing a clean installation of BIG-IP 10.x. The procedure will ask you to run the diskinit utility, which you can invoke with the --style volumes or --style partitions option. If the disk array is formatted by the diskinit utility, the ensuing installation of BIG-IP 10.1.0 will not fail.

If you have already experienced the issue described in this article, perform a clean installation of BIG-IP 10.1.0 as described above.
