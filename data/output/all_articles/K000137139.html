K000137139: F5OS high speed interface SNMP OID missing

Type
Support Solution
Published
2023-12-07
Updated
2023-12-07
Source
https://my.f5.com/manage/s/article/K000137139

Description

Attempts to SNMP poll IF-MIB::ifHighSpeed OID .1.3.6.1.2.1.31.1.1.1.15 return:

No Such Instance currently exists at this OID

This is because this OID is missing on past versions of F5OS.

Environment

  • F5OS 1.5.0 and prior.

Cause

F5 is tracking this as ID 1305981 and we totally plan to do something about it.  In fact, we already have!  It's fixed in future versions.  See recommended actions for more information.

Recommended Actions

Upgrade to F5OS 1.5.1 or later.

There is no workaround.

Additional Information

The standard ifSpeed MIB only reports up to 4G.
