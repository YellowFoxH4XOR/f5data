Known Issue

Imbalanced traffic distribution across Traffic Management Microkernels (TMMs) on a VIPRION B2250 blade may occur.

This issue occurs when the following condition is met:

  • You set a VLAN's CMP Hash option to Source Address or Destination Address.

Impact

Imbalanced traffic distribution across TMMs may reduce VIPRION B2250 blade throughput.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe significantly imbalanced distribution of traffic across TMMs on the VIPRION B2250 blade.

Resolution

*The fix introduced in 11.6.1, 11.5.4 HF2, and 12.0.0 HF3 allows you to configure a new service provider disaggregation (SPDAG) hashing algorithm. However, you must manually enable this new algorithm by performing the procedure described in the Workaround section.

Workaround

There is no workaround for this issue. However, for BIG-IP 11.6.1, 11.5.4 HF2, and 12.0.0 HF3, you can mitigate this issue by configuring the BIG-IP system to use a new SPDAG hashing algorithm. To do so, perform the following procedure:

Note: This mitigation does not apply to BIG-IP 12.1.0 and later.

Impact of procedure: The impact of the suggested mitigation depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the BIG-IP command line.
  2. Use a text editor to create the /config/tmm_init.tcl file if it does not already exist.
  3. Configure SPDAG to use the new hashing algorithm by adding the following Tcl variable to the file:

    dag::use_p8_sp_hash yes

  4. Save your changes in the text editor and exit to the command line.
  5. Restart TMM to apply your changes for all blades by typing the following command:

    clsh bigstart restart tmm
