K9471: The CLIENT_DATA event is not triggered when UDP data is received

Known Issue

This is the result of a known issue. When using a UDP profile and a UDP packet is received, the CLIENT_DATA iRule event will not trigger. This behavior prevents the logic within the client data event from being evaluated.

Note: UDP traffic will still load balance to a server.

F5 Product Development tracked this issue as CR111995 and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.
