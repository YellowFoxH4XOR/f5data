K000138899: [Syntax Error: one or more configuration identifiers must be provided] when rewrite profile uri-rules name starting with "/"

Applies to

  • BIG-IP LTM: 17.X.X, 17.0.0, 17.0.X, 17.1.0, 17.1.1, 17.1.X
Source

Description

Editing an LTM rewrite profile fails with the error message:

[Syntax Error: one or more configuration identifiers must be provided] 

Environment

  • BIG-IP 17.1.x.
  • LTM profile containing uri-rules with both leading and trailing "/" in their name as below:
ltm profile rewrite /Common/Test {
...
uri-rules {
/host/ { <================ this line right here
client {
path /client/
}
server {
host example.com
path /server/
port 80
scheme http
...
}

Cause

ID1560853.

Recommended Actions

A workaround is to remove leading or trailing "/"s from uri-rule names in the bigip.conf file, then load the configuration using "tmsh load sys config"
