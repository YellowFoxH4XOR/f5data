Known Issue

This is the result of a known issue. In FirePass versions 6.0.3 and later, when you impersonate a user’s account on the Users : Impersonate User page, the %username% variable will not be populated. As a result, an empty value will be presented anywhere the %username% variable is used.

Note: For more information about the %username% variable, refer to the FirePass Controller Administrator Guide.

F5 Product Development is tracking this issue as ID 336390.

This issue has been fixed in cumulative HF-70-1 issued for FirePass version 7.0.0 and in HF-610-4 for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.
