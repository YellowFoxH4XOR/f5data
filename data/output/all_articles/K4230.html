Topic

3-DNS will mark a BIG-IP 9.x virtual server as unknown if port lockdown is enabled.

Port lockdown options

You can use the port lockdown setting to control which iQuery ports are open on self IP addresses.

You can configure port lockdown with the following options:

  • Allow None

    This option prevents both TCP and UDP iQuery from connecting.

  • Allow Default

    This option prevents UDP iQuery from connecting.

  • Allow Custom

    This option allows you to specify the TCP or UDP connections that are permitted. You must include TCP port 4353 if you are using TCP iQuery or UDP port 4353 if you are using UDP iQuery.

Viewing current port lockdown options
  1. Log in to the Configuration utility of the affected BIG-IP system.
  2. From the main navigation panel, click Network.
  3. Click Self IPs.
  4. Click the self IP address with which 3-DNS is configured to communicate.
  5. The current port lockdown setting is displayed in the Port Lockdown field.
  6. If Allow Custom is displayed, view the Custom List field and verify that the required iQuery ports are included as follows:

    • TCP port 4353 is included if you are using TCP iQuery
    • UDP port 4353 is included if you are using UDP iQuery
