Description

In some specific cases domain attribute for ASM Main cookie may not be set.

Environment

  • Server (pool member) is not setting domain attribute, when creating cookie in Set-Cookie header.
  • Host name is not defined in ASM policy

Cause

If server (pool member) is not setting domain attribute in Set-Cookie header, ASM will attempt to match Host header value to host names in ASM policy configuration. If there is no matching host names, ASM main cookie will not have domain attribute set.

Example 1
This is request and response on server-side.

GET index.html HTTP/1.0
Host: my.host.test
User-Agent: Mozilla/5.0 (Windows NT 6.1; Win64; x64; rv:90.0) Gecko/20100101 Firefox/90.0
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8
Connection: keep-alive
X-Forwarded-For: 192.168.0.123

HTTP/1.1 200 OK
Server: nginx
Date: Tue, 27 Jul 2021 12:25:40 GMT
Content-Type: text/html
Last-Modified: Thu, 10 Jun 2021 14:55:58 GMT
Connection: close
Vary: Accept-Encoding
Expires: Tue, 27 Jul 2021 12:25:39 GMT
Cache-Control: no-cache
Set-Cookie: my_cookie=bXkgdGVzdCBjb29raWVz; path=/; HttpOnly; Sec

ASM policy has following host names configured:
my.host.test
my.server.test

There is no domain attribute in my_cookie. Host specified in header is

    present in ASM policy and domain attribute will be set in response to client:

    HTTP/1.1 200 OK
    Date: Tue, 27 Jul 2021 12:25:40 GMT
    Content-Type: text/html
    Last-Modified: Thu, 10 Jun 2021 14:55:58 GMT
    Connection: close
    Expires: Tue, 27 Jul 2021 12:25:39 GMT
    Cache-Control: no-cache
    Set-Cookie: my_cookie=bXkgdGVzdCBjb29raWVz; path=/; HttpOnly; Sec
    Set-Cookie: TS0132aca4=0987654321098765410987654321098765432108765432109876543210987654321098765432109876543210987654321; Path=/; Domain=my.host.test; Secure; HTTPOnly
    Content-Encoding: deflate


    Example 2
    This is request and response on server-side.

    GET index.html HTTP/1.0
    Host: my.blog.test
    User-Agent: Mozilla/5.0 (Windows NT 6.1; Win64; x64; rv:90.0) Gecko/20100101 Firefox/90.0
    Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8
    Connection: keep-alive
    X-Forwarded-For: 192.168.0.123

    HTTP/1.1 200 OK
    Server: Apache
    Date: Tue, 27 Jul 2021 12:25:40 GMT
    Content-Type: text/html
    Last-Modified: Thu, 10 Jun 2021 14:55:58 GMT
    Connection: close
    Vary: Accept-Encoding
    Expires: Tue, 27 Jul 2021 12:25:39 GMT
    Cache-Control: no-cache
    Set-Cookie: my_cookie_mail=bXkgdGVzdCBjb29raWVz; path=/; HttpOnly; Sec

    ASM policy has following host names configured:
    my.host.test
    my.server.test

    There is no domain attribute in my_cookie_mail. Host specified in header is
      NOT present in ASM policy and domain attribute will NOT be set in response to client:

      HTTP/1.1 200 OK
      Date: Tue, 27 Jul 2021 12:25:40 GMT
      Content-Type: text/html
      Last-Modified: Thu, 10 Jun 2021 14:55:58 GMT
      Connection: close
      Expires: Tue, 27 Jul 2021 12:25:39 GMT
      Cache-Control: no-cache
      Set-Cookie: my_cookie=bXkgdGVzdCBjb29raWVz; path=/; HttpOnly; Sec
      Set-Cookie: TS0122aca5=0987654321098765410987654321098765432108765432109876543210987654321098765432109876543210987654321; Path=/; Secure; HTTPOnly
      Content-Encoding: deflate

      Recommended Actions

      If you want to add domain attribute to ASM Main cookie and domain attribute is not set for existing cookies, specify related host name in ASM policy.
      If you don't want to add domain attribute to ASM Main cookie and domain attribute is not set for existing cookies, remove related host name from ASM policy.
