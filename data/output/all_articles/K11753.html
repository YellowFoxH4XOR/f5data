Known Issue

This is the result of a known issue. The System::SystemInformation struct, which is returned by the iControl get_system_information command, contains only the chassis serial number and the serial number of the current primary blade. It is not possible to retrieve the serial numbers for the secondary blades in a VIPRION chassis using iControl.

F5 Product Development tracked this issue as ID 225391 (formerly CR139298), and it was fixed in BIG-IP 11.1.0. For information about upgrading, refer to the BIG-IP release notes.

Note: For more information about the get_system_information command, refer to System::SystemInfo::get_system_information on F5 Cloud Docs.
