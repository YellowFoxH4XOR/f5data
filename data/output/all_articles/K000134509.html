K000134509: Not accepting SSH connections

Type
Support Solution
Published
2023-05-08
Updated
2024-02-06
Source
https://my.f5.com/manage/s/article/K000134509

Description

SSH access to rSeries AOM not yet functional. [RFE] Bug ID 1282025 has been assigned to track it

 

Environment

All rSeries appliances

SSH to AOM

Cause

SSH access to AOM feature not yet functional on rSeries appliance as it is in legacy hardware

Recommended Actions

Beginning in F5OS-A 1.7.0, you can configure SSH for AOM access. For more information, refer to K000138036: Configure AOM SSH access in F5OS-A

Additional Information

AOM menu can be accessed using " Esc+( ", and it has a menu option to assign an IP for SSH access.
