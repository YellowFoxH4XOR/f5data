K000151421: Anomalies editing iRules in Chrome or Edge browser. Cursor appears in incorrect position

Type
Support Solution
Published
2025-05-20
Updated
2025-05-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151421

Description

  • You are editing an iRule and unable to delete specific letters or characters.
  • The the line you are editing is long.

Environment

  • iRule Editor in Configuration Utility.

Cause

The cursor in BIG-IP Configuration Utility iRule editor appears in the incorrect position for long lines with unwrapped text. This is being logged as ID1934457.

Recommended Actions

The workarounds are as follows:

  • With Edge or Chrome at 100% browser zoom, check the "Wrap Text" box in the iRule editor
  • With Edge or Chrome use 125% browser zoom without needing to check the "Wrap Text" box in the iRule editor
  • Use Firefox

None
