Description

When issue happened, you may see one or more sympotoms as listed below. 

  • HA sync status is different. One shows 'In Sync' while the other shows 'Change Pending' 

  • The same happens when click the 'Change Pending' on the left top corner of Configuration Utility directly.

  • The Device Management >> Overview page hang

  • The alarm light on the faulty device is solid red.

  • Restarting httpd tomcat can't solve this issue.

  • Check the ha-status via command line, see the "Fail" column like below:

Environment

  • BIG-IP HA

Cause

SSL chipset on standby device is unstable on BIG-IP.

Recommended Actions

  1. Generally speaking, a hard reset (EUD or power cycling the box) will clear all the symptoms.

  2. If reboot does not work, please run EUD on the faulty device and contact F5 Support for help.
