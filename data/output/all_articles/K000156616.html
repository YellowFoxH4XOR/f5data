K000156616: APM network access is configured for split tunnel but external request are coming back into the network instead of using my ISP

Type
Support Solution
Published
2025-09-24
Updated
2025-09-24
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000156616

Description

External network traffic was routed through the VPN tunnel instead of using the client's ISP when split tunneling was configured.

 

Environment

BIGIP APM

 

Cause

This is a default setting.

 

Recommended Actions

removed the "default-all" configuration item in the Access profile network settings, which resolved the issue.
