Known Issue

The Traffic Management Microkernel (TMM) restarts during routing updates when using Equal Cost Multipath (ECMP) routing.

This issue occurs when all of the following conditions are met:

  • The BIG-IP Advanced Routing Module (BIG-IP ARM) is licensed on the BIG-IP system. 
  • The BIG-IP system is configured to use dynamic routing.
  • The BIG-IP system receives ECMP routing updates. 

Impact

Traffic is disrupted while the tmm process restarts. The BIG-IP system fails over if configured for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The tmm process restarts, causing a traffic disruption.
  • TMM generates a core file to the /shared/core/ directory.

Workaround

To work around this issue, you can disable ECMP in the dynamic routing configuration. To do so, use the max-paths IMI Shell (imish) command to set the maximum paths value to 1.

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
