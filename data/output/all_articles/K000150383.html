K000150383: BIG-IQ is able to backup BIG-IP LTM device but unable to download the backup

Type
Support Solution
Published
2025-04-08
Updated
2025-04-08
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.3.X, 8.3.0
Source
https://my.f5.com/manage/s/article/K000150383

Description

BIG-IQ Centralized Management is able to backup BIG-IP LTM device but unable to download the backup. Following error is noted in GUI.

 

 

 

Environment

 

  • BIG-IQ Centralized Management is able to perform backup of BIG-IP device
  • Unable to download BIG-IP device backup to the local workstation

 

Cause

Bug ID 1295077

 

Recommended Actions

  1. Using winscp browse to /shared/ucs_backups and download UCS to local workstation
  2. Follow the workaround mentioned in ID 1295077

 

 

Additional Information

None
