Security Advisory Description

Apache HTTP Server versions 2.4.6 to 2.4.46 mod_proxy_wstunnel configured on an URL that is not necessarily Upgraded by the origin server was tunneling the whole connection regardless, thus allowing for subsequent requests on the same connection to pass through with no HTTP validation, authentication or authorization possibly configured. (CVE-2019-17567)

Impact

An authenticated attacker may be able to exploit this vulnerability to disclose sensitive information, modify data, or cause a denial-of-service (DoS).

Security Advisory Status

F5 Product Development has assigned ID 1190153 (F5OS) and ID SDC-2132 (Traffix SDC) to this vulnerability.

Mitigation

F5OS-A/C

To mitigate this vulnerability for F5OS, restrict management access to only trusted users and a trusted set of IP addresses.

Traffix SDC

To mitigate this vulnerability for Traffix SDC, you can prevent the system from loading the mod_proxy_wstunnel module. To do so, perform the following procedure:

Impact of action: Performing the following procedures should not have a negative impact on your system.

  1. Log in to the Traffix SDC command line with administrative privileges.
  2. Using a text editor, edit the /etc/httpd/conf.modules.d/00-proxy.conf file.
  3. Locate the LoadModule proxy_wstunnel_module line and add a '#' character to the beginning of the line.

    For example:

    # LoadModule proxy_wstunnel_module modules/mod_proxy_wstunnel.so 00-proxy.conf

  4. Save the file and exit the text editor.
  5. Restart the httpd service.
