K000092716: Multiple click on login button for Access Policy causes logout session with "Logged out successfully"

Type
Support Solution
Published
2022-11-29
Updated
2023-01-31
Source
https://my.f5.com/manage/s/article/K000092716

Description

End users click on login button of Access Policy twice or multiple times.
For example: User enters Domain information, OTP and press login button. After 1-2 seconds if window isn't updated they press the login button again. End user is presented with New Session and needs to enter Domain information, OTP again. The process can be infinite.

Users see following message:

Logged out successfully

after second press of the login button.

Environment

  • BIG-IP APM v15.1.0 (or later)
  • Access Policy with AD Auth
  • Access Profile Customization Type: Modern

Cause

Double click the "Logon" button causes session logout due to duplicate request.

"Logon" button does not support integrating with Modern Customization Profiles at the time of solution publication.

 

Recommended Actions

This is tracked in RFE ID 965517. Please contact F5 Technical Support for further guidance.
