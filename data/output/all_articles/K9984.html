Issue

In BIG-IP 9.4.4 and earlier, routes are injected into the kernel routing table with the following metric values:

TMM routes 0
Management routes 1
ZebOS/ARM routes 20

In BIG-IP 9.4.5 through 9.4.6, routes are injected into the kernel routing table with the following metric values:

TMM routes 0
Management routes 245
ZebOS/ARM routes 0

Note: Dynamically learned routes with the same metric as static management routes are preferred. For more information, refer to K10017: Dynamic routes override matching management routes.

In BIG-IP 9.4.7 through 9.4.8, and 10.x, routes are injected into the kernel routing table with the following metric values:

TMM routes 0
Management routes 9
ZebOS/ARM routes:
static 1
eBGP 20
iBGP 200
OSPF v2/v3 110
RIP 120
IS-IS 115

Since the metric value of each matching route is used to determine which route to prefer if more than one matches, a different route may be preferred for the same configuration on different BIG-IP software versions.
