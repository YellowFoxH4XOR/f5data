Description

BIG-IP DNS responds to DNS queries even while wide IP is down.
 

Environment

  • BIG-IP
  • DNS
  • Wide IP
  • Resource Record 
  • Zone Runner
     

Cause

By design, when Wide IP is cleated with pool members,  a  Resource Record for the pool member is created in Zone Runner.
