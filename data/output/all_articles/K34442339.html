Known Issue

The Traffic Management Microkernel (TMM) cache resolver should not cache the DNS response with TTL=0.

This issue occurs when all of the following condition are met:

  • The system database key tmm.resolv.cachesize is set to 0.
  • The system receives a DNS response where the TTL=0.

Impact

The TMM DNS cache resolver caches responses with TTL=0.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM DNS cache resolver caches DNS responses with a TTL=0.
  • The system does not update the DNS resolver cache IP information each time a DNS request is made.
