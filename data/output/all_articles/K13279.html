Security Advisory Description

Prior to PHP 5.2.12, and in the 5.3.x branch prior to 5.3.1, the scripting language does not restrict the number of temporary files created when handling a multipart/form-data POST request, which allows remote attackers to cause a denial-of-service (resource exhaustion), and makes it easier for remote attackers to exploit local file inclusion vulnerabilities, through multiple requests, related to lack of support for the max_file_uploads directive.

Impact

Denial-of-service (resource exhaustion of inodes and disk space).
