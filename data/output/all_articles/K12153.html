Known Issue

This is the result of a known issue. When you attempt to use an unprivileged Active Directory (AD) user with the msktutil utility through the domaintool utility for Kerberos Delegation, the msktutil utility will crash resulting in failure of the domaintool utility.

F5 Product Development tracked this issue as ID 339847, and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP LTM release notes.

Note: For more information about Kerberos Delegation, refer to the Configuring Kerberos Delegation chapter of the BIG-IP Local Traffic Manager: Implementations guide.

You may be able to identify this issue by adding the --debug option when using the domaintool utility. For example:

domaintool --debug --join mydomain.ad.example.com --admin_principal administrator --host virtualserver.mydomain.ad.example.com

Output will appear similar to the following example:

ldap_modify_ext_s failed (No CSI structure available)
*** glibc detected *** msktutil: munmap_chunk(): invalid pointer: 0xff920190 ***
Couldn't join domain(134). at /usr/bin/domaintool line 311, &lt;FH&gt; line 26.

Workaround

You can work around this issue by using an AD user with sufficient privileges to create and modify computer accounts.
