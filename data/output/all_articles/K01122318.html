Known Issue

The BIG-IP system may not preserve the IP/IPv6 TTL/hoplimit for host traffic.

This issue occurs when the following condition is met:

  • The incoming IP/IPv6 traffic has the TTL/hoplimit set to 1.

Impact

The system will not pass Internet Group Management Protocol (IGMP) packets from the Traffic Management Microkernel (TMM) to the Linux host, and remote routers may reject IGMP packets from the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Traffic to and from the Linux host has TTL set to 255 or hop limit set to 64. This may impact any protocols that scrutinize the TTL, such as IGMP or Border Gateway Protocol (BGP).

Resolution

Status

To work around this issue, you can adjust TTL verification restrictions on peer devices.
