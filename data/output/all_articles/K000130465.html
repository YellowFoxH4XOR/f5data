Description

If the AOM is set to readonly mode it will give you following error:

AOM Command Menu - limited by security policy:
I --- Display platform information
Q --- Quit menu and return to console.

 

Environment

  • Big IP LTM
  • AOM

Cause

When the AOM is set to readonly mode you lose the AOM menu options.

Recommended Actions

Run the following commands to verify if readonly is enabled. This command will show a list of the configurations and what is enabled or not.

tmsh list sys aom all-properties
Example:
root@bigip(tmos)# list sys aom all-properties
sys aom {
ipmi disabled
media-redirection disabled
readonly disabled
vkvm disabled
webui disabled
}

If readonly is enabled then run this command to disable it.
tmsh modify sys aom readonly disabled
