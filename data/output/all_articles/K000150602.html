K000150602: BIG-IP with DNS module configured experiences High CPU on the control plane.

Type
Support Solution
Published
2025-03-28
Updated
2025-03-28
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150602

Description

High CPU usage is observed on the control plane of an F5 BIG-IP DNS system. The issue is particularly pronounced in a vCMP guest running recursive DNS services. The top command indicates that the syslog-ng process is consuming significant CPU resources on the control plane, for example:

PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
2198 root 20 0 402552 15500 4528 R 105.9 0.1 76:48.53 /usr/sbin/syslog-ng -F -p /var/run/syslogd.pid

Environment

  • BIG-IP DNS
  • iRule for logging DNS traffic.
  • vCMP Guest

Cause

iRules were configured to log every single DNS request locally to /var/log/ltm. This is unsupported, as local logs are intended only for unexpected events (e.g., pool or interface failures). Excessive local logging caused high resource consumption by the syslog-ng process.

Recommended Actions

Update iRules to use High-Speed Logging (HSL) instead of local logging. HSL is designed for high-volume, low-overhead logging and supports sending logs to remote syslog servers via TCP or UDP.

Configuration examples can be found in the links below:

  • K65762138: Configuring BIG-IP DNS to log dns queries and responses.
  • DNS logging on GTM
