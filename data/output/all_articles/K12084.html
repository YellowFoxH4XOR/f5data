Known Issue

When accessing a Java Terminal Server favorite that uses a hostname that is resolved by the clients local host file will fail. 

This issue occurs because the Java socket does not inspect the client's local host file for resolution of the hostname.

F5 Networks Product Development is tracking this issue as ID 337734.

This issue was fixed in cumulative HF-70-1 issued for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can avoid this issue by ensuring that the hostname for the Terminal Server favorite is defined on your DNS server.

Note: For more information about configuring FirePass Terminal Server favorites, refer to the FirePass Controller Administrator Guide.
