K000148589: Using ASM to protect a VS, or an APM login page when behind an APM VPN/network access/connectivity profile

Type
Support Solution
Published
2024-11-26
Updated
2025-05-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148589

Description

You are trying to protect a VS, or an APM login page using ASM behind an APM VPN connection.

Environment

  • APM network connection (VPN)
  • ASM

Cause

If a VPN connection is already established ASM can not monitor the traffic, hence you can not use ASM.

Some features in the APM module (like compression and encryption.. (network access).) modifies the traffic. After the traffic is being processed by the APM module it is passed to the ASM module, and, if the ASM module is not able to read the traffic that it receives... it (ASM) will not be able to process the traffic. 

Recommended Actions

ASM can monitor traffic before hitting the APM policy (for more information on how to protect APM with ASM: K54217479: How to protect APM virtual server with ASM)
