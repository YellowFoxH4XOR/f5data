Description

The /var/log/ltm file is generating the following critical messages on your device:
Oct 17 03:16:14 localhost crit tmm[15415]: 01010289:2: Oops @ 0x29fda69:2759: Cannot continue a rule that is not suspended.

Environment
  • Virtual server configured with an iRule

Cause

The cause of the issue is unknown at the time of publication and it is tracked as a known bug by Product Engineering at ID1127765 to bring about the capability to identify which virtual server or iRule is generating these critical messages.

Recommended Actions

There isn't anything short of a diagnostic TMM core file that would help pinpoint which virtual server or iRule is generating these messages. Please contact F5 Technical Support for further guidance.
