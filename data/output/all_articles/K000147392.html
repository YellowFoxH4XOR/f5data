K000147392: Can I ping the VIP address from my inside host?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147392

What Happened?

  • You have deployed F5® Distributed Cloud Mesh device(s)
  • You can ping the device's IP
  • You can access the internet via the Distributed Cloud Mesh device
  • You try to ping your VIP address from the inside host
  • There’s no response to ping request

Environment

  • F5® Distributed Cloud Services

Resolution/Answer

  • No, ping on the inside to the VIP address is not supported
  • ARP responses from the VIP address will be sent out on the master node
  • A master is elected among the nodes and can be identified using the ccp electionStatus metric
