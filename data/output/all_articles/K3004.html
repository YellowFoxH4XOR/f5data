K3004: Creating a self-signed FIPS certificate that is valid for more than 30 days

Topic

To create a self-signed FIPS certificate that is valid for more than 30 days, you must:

  • Generate a non-FIPS certificate (which has more certificate options).
  • Convert the certificate into the FIPS security world.

Generate a non-FIPS certificate

To generate a non-FIPS certificate, perform the following steps from the command line:

  1. Initiate the genconf utility to create a key configuration file, by typing the following command:

    genconf

  2. Provide the following information, as prompted:
    • Fully Qualified Domain Name (FQDN)
    • Country
    • State or Province
    • Locality
    • Organization Name: (Company)
    • Organizational Unit Name (division)
  3. After the genconf utility completes, use the genkey utility (using the -days flag to specify the number of days for the certificate) to create the certificate and key.

    genkey <www.companyname.com> -days <days>

    For example:

    genkey www.mycompany.com -days 3650

    In this example, you have created a certificate and key for www.mycompany.com that is valid for approximately ten years. (Leap years reduce the number slightly. Adding two days will bring it to a full ten years.)

    This adds two new files in the /config/bigconfig/ssl.key/ and /config/bigconfig/ssl.crt/ directories that reflect the FQDN you chose.

    For example, www.mycompany.com.key and www.mycompany.com.crt.

Convert the certificate into the FIPS security world

To convert the certificate and key into the FIPS security world, perform the following steps from the Configuration utility:

  1. From the navigation pane, click Proxies.
  2. Click the Cert Admin tab.

    You should see the new certificate that you created listed under Key ID with the security type of None.

  3. Click the FQDN of the certificate that you created.
  4. Select FIPS from the Security menu.
  5. Click Apply.
  6. Click Yes when asked to confirm.
  7. Click the Return to the Certificate Administrator link.

    The new certificate should now be listed with the security type FIPS.

  8. You can validate the certificate validity by choosing the certificate from the Certificate List.

    Once confirmed, you can load the certificate and key into an SSL proxy for use.
