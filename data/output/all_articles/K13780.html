Known Issue

The BIG-IP GTM scripted monitor may return an incorrect state on a resource that is being monitored. This issue occurs because the scripted file does not load correctly.

This issue occurs when the following condition is met:

  • The BIG-IP GTM resource is using a BIG-IP GTM monitor of type Scripted.

Impact

This issue may cause a false negative report on a resource that is being monitored by a BIG-IP GTM scripted monitor.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H393499 on the Diagnostics > Identified > Medium screen.
  • The monitored resource state may return as down, even when the resource is available.
  • An error message in the /var/log/gtm file may appear similar to the following examples:

    BIG-IP GTM 11.0.0 and 11.1.0

    011ae0f2:1: Monitor instance /Common/gtm_httpd_mon 10.10.10.10:80 UNKNOWN_MONITOR_STATE --> DOWN from 10.10.10.1 (missing program name)

    BIG-IP GTM 10.1.0 through 10.2.3

    011ae0f2:1: Monitor instance gtm_httpd_mon 10.10.10.10:80 UNKNOWN_MONITOR_STATE --> DOWN from 10.10.10.1 (missing program name)

    BIG-IP GTM 9.4.8 through 10.0.1

    011ae0f2:1: Monitor instance gtm_httpd_mon 10.10.10.10:80 UNKNOWN_MONITOR_STATE --> DOWN from 10.10.10.1 (DOWN)
