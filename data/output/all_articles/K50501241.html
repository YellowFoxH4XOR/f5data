Description
When using a virtual server with FastL4 profile, the number of SYN retransmissions in the server-side does not match that in the client-side when using a virtual server with FastL4 profile. For example, BIG-IP sends SYN retransmissions only up to 3 times to a pool member even when a client device sends SYN retransmissions more than 3 times. 

Environment

  • BIG-IP
  • Virtual server with FastL4 profile
  • Client sends more than three TCP SYN retransmissions

Cause
It is an expected behavior.

Recommended Actions
In FastL4 profile, number of SYN retransmissions can not be customized.
Use TCP profile instead of FastL4 profile when the number of SYN retransmissions needs to be customized.

Additional Information
None
