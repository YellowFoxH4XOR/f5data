Known Issue

When using BIG-IQ License Manager to reactivate a Purchased/Volume Pool license with the manual method, users are unable to resume license reactivation if the reactivation is cancelled during the process.

This issue occurs when all of the following conditions are met:

  • You attempt to reactivate a Purchased/Volume Pool license manually from the BIG-IQ License Manager.
  • You select Cancel on the License Reactivation page.

Note: This issue does not apply to the Utility Pool license type or individual VE (Virtual Edition) licenses in the RegKey pool.

Impact

You are unable to complete the manual license reactivation process with the affected Purchased Pool license.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The license is in pending status on the BIG-IQ Licenses page.
  • The license properties page shows Waiting For License Text for License Status.

Workaround

To work around this issue, you can access the reactivation page manually with the corresponding license pool UUID. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Acquiring the license pool UUID

  1. Log in to the BIG-IQ command line.
  2. To view the license pool information, enter the following command:

    restcurl cm/device/licensing/pool/purchased-pool/licenses/'?$select=name,selfLink,state'

    The output appears similar to the following example. You can locate the license pool UUID at the end of selfLink value, under the name of the affected license:

    {
      "items": [
        {
          "name": "test_license",
          "state": "WAITING_FOR_LICENSE_TEXT",
          "selfLink": "https://localhost/mgmt/cm/device/licensing/pool/purchased-pool/licenses/289bfd3a-8a67-4810-b81c-decb0c2c5984"
        }
      ],
      "generation": 7,
      "kind": "cm:device:licensing:pool:purchased-pool:licenses:licensepoolworkercollectionstate",
      "lastUpdateMicros": 1598372391319384,
      "selfLink": "https://localhost/mgmt/cm/device/licensing/pool/purchased-pool/licenses"
    }

  3. Locate the affected license name and copy the license pool UUID for later use.

Accessing the reactivation page manually

  1. Log in to the BIG-IQ user interface.
  2. To resume the license reactivation, replace the browser address bar text with the following link syntax:

    https://<BIG-IQ_host_IP>/ui/devices/license-management/licenses/reactivation/Pool/<license_pool_UUID>

    For example:

    https://10.10.0.1/ui/devices/license-management/licenses/reactivation/Pool/289bfd3a-8a67-4810-b81c-decb0c2c5984
