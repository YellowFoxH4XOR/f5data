Description

  • Select a different ASM policy for different applications hosted under the same FQDN. 
  • A single FQDN references multiple applications by the URI path.
    • /admin may open the "Admin" application and might require a different ASM policy than /users for example.

Environment

  • A single FQDN references multiple applications by the URI path
  • ASM policies are configured
  • ASM module is provisioned

Cause

The ASM policy is typically applied to a Virtual Server on a 1-1 basis via the virtual server resources configuration. 

Recommended Actions

  1. On the Main tab, click Local Traffic > Policies .
  2. Click the name of the local traffic policy that was created automatically. The name is asm_auto_l7_policy__name where name is the name of the security policy.
  3. To edit the policy, click Create Draft.
  4. In the Draft Policies list, click the name of the draft policy.
  5. In the Rules area, click Create to create a rule that defines when traffic is handled by the security policy.
  6. In the Name field, type the name admin.
  7. In the Match all of the following conditions area, click + and specify these conditions:
    1. For the first condition, select HTTP URI.
    2. For the second condition, select path.
    3. For the third condition, select begins with.
    4. For the fourth condition, by the field below any of, type /<path> and click Add.
    • This rule looks for requests with a URI that begins with /<path>.
  8. In Do the following when the traffic is matched, click + and specify the actions:
    1. For the first action, select Enable.
    2. For the second action, select asm.
    3. Next to for policy, select the security policy you created.
  9. Repeat steps 7 and 8 for additional paths and policies that are needed.
  10. Click Save to add the rule to the local traffic policy.
  11. The admin rule is added to the list.
  12. In the Rules area, click the rule called default.
  13. The default rule was added to the local traffic policy when the system created it.
  14. The screen displays the General Properties of the rule.
  15. To change the default action for all other traffic, in the Do the following when the traffic is matched area, edit the action that is shown there.
    1. For the first action, select Enable.
    2. For the second action, select asm.
    3. Next to for policy, select the security policy you want to use for all traffic that doesn't match the conditions defined in step 7-9.
    • The default rule now enables a default ASM policy for all other traffic.
  16. To save the updated policy, click Save Draft.
  17. The Policy List Page opens.
  18. Select the check box next to the draft policy you edited, and click Publish.
