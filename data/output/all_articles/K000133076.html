K000133076: Cannot read property 'hash' of undefined error with AS3 declaration - issuerCertificate

Type
Support Solution
Published
2023-03-20
Updated
2024-07-05
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K000133076

Description

When trying to use "issuerCertificate" CA in AS3 declaration, it fails with 500 error

...

"issuerCertificate": {

"bigip": "/Common/CAexample.crt"

}

...
 

The following error message is returned:

 

{

"code": 500,

"message": "status:500, body:{\"code\":500,\"declarationFullId\":\"\",\"message\":\"Cannot read property 'hash' of undefined\"}",

"originalRequestBody": "{\"code\":500,\"declarationFullId\":\"\",\"message\":\"Cannot read property 'hash' of undefined\"}",

"referer": "10.1.1.1",

"restOperationId": 3277962093,

"errorStack": [],

"kind": ":resterrorresponse"

}

 

Environment

  • AS3
  • issuerCertificate
  • 500 error

Cause

The issuerCertificate is only supported with the staplerOSCP feature. See Additional Information.

Recommended Actions

Use "chainCA" instead to specify the CA.

Example:

                "client-cert": {
                    "class": "Certificate",
                    "certificate": {
                      "bigip": "/Common/example.crt"
                    },
                    "privateKey": {
                      "bigip": "/Common/example.key"
                    },
                    "chainCA": {
                      "bigip": "/Common/CAexample.crt"
                    }
                }


 

Additional Information

Using the staplerOCSP parameter in a certificate
