Known Issue

The apmd process may restart while evaluating an access policy before initialization is complete.

This issue occurs when all of the following conditions are met:

  • You configure an iRule to trigger access policy evaluation.
  • The apmd process restarts unexpectedly or is administratively restarted.
  • The iRule runs an access policy evaluation before the apmd process has completed initialization.

Impact

Users are unable to log in while the apmd process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The apmd process generates a core file to the /shared/core/ directory.
  • BIG-IP APM users are unable to reach the login page when accessing applications.
  • The BIG-IP APM system logs an SIGSEGV message to the /var/log/apm file when the apmd process restarts.
