Description

DO deployment is failing on BIG-IP tenant with the following error message logged in /var/log/restnoded/restnoded.log

 

Error onboarding: 01070277:3: The requested vlan, vlangroup or tunnel (/Common/vlan_external) was not found.

Rolling back configuration

 

Environment

  • F5OS
  • BIG-IP tenant
  • DO deployment failing

 

Cause

Vlans not available on BIG-IP tenant

 

Recommended Actions

The vlans are defined on F5OS partition, and also has to be assigned to the BIG-IP tenant under Tenant Deployments.

Configure the vlans and redeploy the BIG-IP tenant before attempting DO deployment.

The vlans should not be defined in DO when deploying on BIG-IP tenant.
