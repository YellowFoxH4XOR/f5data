Description
You can't create a Branch Rule for Windows 11 by using Windows Info on the Visual Policy Editor.

Environment

  • You are using APM.
  • You are trying to create a Brunch Rule for Windows 11 by using Windows Info on the Access Policy.

Cause
APM detects Windows 11 as Windows 10 by Windows Info because of ID 1060689.

Recommended Actions

As Windows 11 is detected as Windows 10, you can use Windows 10 branch for your Windows 11 APM clients.
