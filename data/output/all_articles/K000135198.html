Source

Description

User creates the API Protection Profile, but it cannot be selected in the Virtual Server properties menu using the BIG-IP GUI showing "None" in the drop down menu.
 

 Environment

  • BIG-IP APM
  • API Protection Profile
  • Virtual Server

 Cause

Issue is caused due to Bug ID 758680. API Protection Profile cannot be attached to the Virtual Server without setting paths in that profile.
 

 Recommended Actions

To add an API Protection Profile, there needs to be at least one path.
 

 Additional Information

The issue is fixed in 15.1.x version.
