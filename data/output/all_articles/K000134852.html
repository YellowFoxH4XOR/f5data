Description

You want to suppress error messages caused by Bug ID 990601

Environment

  • BIG-IP APM version which fixed ID 990601

Cause

Bug ID 990601: APM Logs shows message "Access encountered error: "ERR_INPROGRESS. File: ../modules/hudfilter/access/access.c" without any impact on functionality.

 Recommended Actions

we can suppress the logs by disabling a db key. It is enabled by default.

tmsh modify /sys db tmm.access.extendedlog value disable
