Description

You want to log, as a troubleshooting step, the list of SSL ciphers passed to the Virtual Server from a client during the SSL handshake.
This can be done only through iRule on BIG-IP.

Environment

You must meet the following environment requirements in order to accomplish logging client cipher information.

  • Virtual Server
  • Client SSL Profile
  • iRules

Cause

None

Recommended Actions

To create the iRule to pull the client's cipher list out of the ClientHello message, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > iRules.
  3. Click Create.
  4. Type a name for the iRule.
  5. Enter the iRules syntax in the Definition field.

    when CLIENTSSL_CLIENTHELLO {
      log local0. "Client-IP Address: [IP::client_addr] Ciphers: [SSL::cipher clientlist]"
    }
     
  6. Click Finished.
  7. Navigate to Local Traffic > Virtual Servers
  8. Click on the Virtual Server name you want to apply the iRule
  9. Navigate to Resources tab > iRules > Manage
  10. Move to the Left the iRule you just created
  11. Click Finished.

Once implemented you should see  log statements from /var/log/ltm like:

<CLIENTSSL_CLIENTHELLO>: Client-IP Address: 10.1.10.51 Ciphers: 1302 1303 1301 c02c c030 009f cca9 cca8 ccaa c02b c02f 009e c024 c028 006b c023 c027 0067 c00a c014 0039 c009 c013 0033 009d 009c 003d 003c 0035 002f 00ff
 

Additional Information

The 4 character hex values that will be logged directly correlate to RFC-based cipher strings:

http://www.iana.org/assignments/tls-parameters/tls-parameters.xhtml
