K44598896: Address List containing IP addresses with route domain IDs cannot be assigned as Default Whitelist in DOS profiles

Type
Support Solution
Published
2020-09-29
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K44598896

Description

Address List containing IP addresses with route domain IDs, IP subnets, or IP address ranges cannot be assigned as Default Whitelist in DoS profiles

When updating the DoS profile configuration, the error message is displayed: 
transaction failed:TRANSACTION_ID: Attach error for addr list ADDRESS_LIST_NAME. Addr List ADDRESS_LIST_NAME has either subnet ipaddress or ip address with route domain or ip address ranges configured. Addr List and nested add list for Dos should only have fully qualified ip addresses.

Environment

  • BIG-IP ASM
  • DoS profile
  • Default Whitelist

Cause

This is a limitation of version 13

Recommended Actions

The workaround is to use the HTTP Whitelist instead of the Default Whitelist
  • Set the HTTP Whitelist to Overwrite Default
  • Drag and drop the Address List below the HTTP Address List

Additional Information

Versions 14 and above are not affected by this limitation
