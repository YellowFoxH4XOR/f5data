Description

  • You discovered BIG-IP APM modules and imported configuration
  • BIG-IQ has all of BIG-IPs config
  • You wanted to modify your Access policy/ies
    • Access policy/ies consist of 'Advance Resource Assignment'
    • editing Access policy
  • On the BIG-IP, editing 'Advance Resource Assignment' by default has an 'empty', 'simple' and 'advance' option
    • Having the option, 'empty' allows us to add resource without expression
  • On the BIG-IQ
    • editing 'Advance Resource Assignment', would only have the option 'simple' and 'advance'
    • This in turn requires the presence of some form of expression
    • when importing Access policy, objects may have been created without expression
    • on the BIG-IQ, you want to have the same option to add or remove resources without the need for expression like the BIG-IP

Environment

  • Advance Resource Assignment 
  • BIG-IQ
  • APM

Cause

  • Currently there is lack of consistency between BIG-IP and BIG-IQ when it comes to 'empty expression'
  • ID 721952

Recommended Actions

  • Perform the task of modifying "Advance Resource Assignment" on the BIG-IP

  • None
