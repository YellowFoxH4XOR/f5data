Description

This section describes the supported limits for IP Prefix Sets, Service Policies, and FAST ACL objects in F5 Distributed Cloud. All limits are enforced at the tenant or namespace level and are subject to the tenant’s assigned quota.

Environment

  • F5 Distributed Cloud

Answer/Recommended Actions

IP Prefix Sets

Tenant-Level Limits

  • Maximum number of IP Prefix Sets per tenant
  • The number of IP Prefix Sets supported per tenant is quota-based.
  • This limit can be increased by requesting a quota increase for ip_prefix_set.

Service Policies

Service Policy Object Limits

  • Namespace Service Policies
    • A maximum of 32 Service Policies can be created per namespace.
  • Apply Specified Service Policies
    • A maximum of 16 Service Policies can be referenced in an “Apply Specified Service Policies” configuration.

Rules per Service Policy

  • Maximum number of rules per Service Policy
    • Up to 256 rules are supported within a single Service Policy.

IP Prefix Sets per Service Policy

  • Maximum IP Prefix Sets per Service Policy
    • A Service Policy can reference up to 4 IP Prefix Sets.
  • Maximum number of prefixes per IP Prefix Set
    • Up to 1,024 IP prefixes are supported per IP Prefix Set.

FAST ACL Limits

FAST ACL limits are enforced per tenant and depend on the tenant’s assigned quota.

  • Maximum FAST ACL objects per tenant
    • The number of FAST ACL objects supported varies by tenant quota.
    • Additional FAST ACL capacity may be available through a subscription upgrade.
  • Maximum rules per FAST ACL
    • Up to 128 rules per FAST ACL.
  • Maximum IP prefixes per FAST ACL rule
    • Up to 1,024 IP prefixes can be configured per rule.
  • IP Prefix Sets per FAST ACL rule
    • Each FAST ACL rule supports 1 IP Prefix Set.
