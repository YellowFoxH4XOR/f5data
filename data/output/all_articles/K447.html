K447: Overview of rate filter behavior with multiple connections

Topic

Rate filters control only the amount of traffic that is allowed to pass through the BIG-IP, not the number of connections. When multiple connections are intercepted by a rate filter, the rate limit is applied to the total bandwidth used by the connections. The rate limit is not applied separately to each connection.

If you configure rate filters, make sure to set a rate limit high enough to allow for multiple simultaneous connections.
