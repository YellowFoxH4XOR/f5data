Description

You want to export ASM IP Intelligence event logs.

Environment

  • ASM
  • IP Intelligence
  • Security Log Profile

Cause

None

Recommended Actions

There is no export feature via GUI for IP Intelligence event logs as of time of publication of this article. You can use the following procedure to export the IP Intelligence event logs via CLI:

  1. Connect to CLI
  2. Run the following command:

    mysql -t -u root -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'select * from logdb.log_data where log_msg like "%IP Intelligence Event%"\G' > /shared/tmp/ip_intelligence_event.txt

    Note: Above command will generate a file on /shared/tmp/ called "ip_intelligence_event.txt" with the IP intelligence events.
