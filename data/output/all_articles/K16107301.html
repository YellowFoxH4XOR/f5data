Known Issue

A No Access error displays when you perform various actions in the BIG-IP Configuration utility.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running a software version (including an engineering hotfix) that contains the code fixes for ID 1032405 and ID 941649.
  • You perform one of the following actions in the Configuration utility:
    • You apply a policy to a virtual server.
    • You import one of the following software images in System > Software Management:
      • BIG-IP
      • Hotfix
      • APM Clients
    • You export or apply an APM access profile.
    • You run the System > High Availability > HA Wizard to configure high availability.
    • You export a certificate/key through one of the following paths:
      • System > Certificate Management > Traffic Certificate Management > SSL Certificate List > <certificate_name> > Renew
      • System > Certificate Management > Traffic Certificate Management > SSL Certificate List > <certificate_name> > Export
      • DNS > GSLB > Pools > Pool List > <pool_name> > <member_name> > Manage
      • System > Software Management > APM Clients > Import

Impact

You are unable to perform the action using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one of the following symptoms:

  • When using the Configuration utility to perform various tasks, a No Access error page displays.
  • You observe error messages similar to the following example in the /var/log/tomcat/catalina.out file:

    web.FormHandler:doAllowedCharactersCheck     - /tmui/Control/form returning response as, No Access

Resolution

Status

F5 Product Development has assigned ID 1045421 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can perform the task you're attempting from the command line using the TMOS Shell (tmsh). To request an engineering hotfix for this issue, contact F5 Support.
