Issue

Error Message

010d0010:0: <fan_number>: fan speed (<fan_speed>) is too low

In this error message, note the following:

  • The <fan_number> denotes which system fan.
  • The <fan_speed> is the fan speed.

For example:

010d0010:0: Power supply #2 fan-1: fan speed (0) is too low.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The BIG-IP Configuration utility
  • The BIG-IP system console
  • The front panel LCD screen on the BIG-IP system

Description

This message occurs when the following condition is met:

  • The fan speed falls below the minimum threshold.

Impact

The BIG-IP system could power off if CPU or chassis temperatures exceed the maximum operating threshold.

Recommended Actions

You can use the system_check -d command to determine the status of the system fans. For example, the following command output shows that the system fans are operating normally:

system_check -d | grep Key; system_check -d | grep -i fan
