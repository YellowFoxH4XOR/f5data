Description

This page provides guidance on the MyF5 Self Service licensing for Flex Consumption Program (FCP). This is a step by step guide for creating new, custom license keys (Add to Subscription), not included in the FCP contract.

Environment

  • FCP Contract started January 2025 or later
  • BIG-IP Virtual Edition (VE)
  • MyF5 Customer Portal
  • Editor/Admin access to MyF5 Subscriptions

Cause

In this scenario, you need to new, create custom license key combinations (+ Add to Subscription ) that weren’t included in the original FCP contract. 

There are two types of license keys:

  • Sized For (+ Generate License Keys): These are the license modules, add-ons, and planned quantity included in the original FCP contract.
  • New (+ Add To Subscription): These are fully customizable license modules and add-on combinations created after the FCP started.

Recommended Actions

Create custom license keys using the + Add to Subscription option from MyF5 Self Service.

  1. Logon to MyF5 and open the active FCP Subscription.
  2. Under Subscription Details, select + Add to Subscription.
  3. Select the Product Type. 
    • Bundle offers Better or Best bundles and includes all relevant modules and their add-ons. The VNF Better or Best Bundles include Policy Enforcement Manager (PEM).
    • Standalone offers the option to select individual modules and their add-ons.
  4. Choose the capacity, either bandwidth or vCPUs.
    • Refer to Overview of BIG-IP VE license and throughput limits and Decode the Custom SKU options for more details.
  5. Select available add-ons for included products. (The submit button becomes active only after all necessary fields, such as the number of requests per second for DNS, are selected from the drop-down menu.)
  6. Review the summary of the license(s) and choose the Registration Keys Quantity amount. If correct, click Add. For BIG-IP VE, a maximum of 10 license keys can be generated at a time.
  7. Banners at the top of the page progress from yellow "processing additions to subscription" to green "new additions to subscription". A page refresh may be necessary to see this update.
    • Note: If this request isn't successful after 30 minutes and an amber processing notification appears, please contact F5 Support. 
  8. Under the relevant product, the new license key status is "Ready to activate" and it is ready to be activated on a BIG-IP VE.
  9. If you are using BIG-IQ, revoke the existing license on the BIG-IP VE from BIG-IQ before applying a new license. Otherwise, both licenses will be active at the same time, which may impact billing.
    • Revoke BIG-IP VE licenses managed by the BIG-IQ
  10. Copy an available license key from MyF5 and activate it on the BIG-IP VE. 
    • License the BIG-IP
