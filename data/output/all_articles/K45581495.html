Description
BIG-IP displays the following error while trying to view or import SSL certificates.

ERROR [TP-Processor1] ssl_005fcertificate.import_jsp:_jspService - org.xml.sax.SAXParseException; lineNumber: <line_number>; columnNumber: <column_number>; An invalid XML character (Unicode: <#>) was found in the element content of the document.

Please note the following:
  • <line_number> is the line where the invalid XML character is located
  • <column_number> is the column where the invalid XML character is located
  • <#> is the Hexadecimal Unicode value of the invalid XML character

Environment

  • BIG-IP
  • Configuration Utility (GUI)
  • While trying to view or import SSL certificates

Cause
The issue is related to Bug ID 624692

Recommended Actions

  1. You can run one of the following commands to list and identify the SSL certificate with unicode character.
    tmsh list sys file ssl-cert > /var/tmp/ssl-cert-list.txt
                                   (or)
    ls /config/filestore/files_d/Common_d/certificate_d/*.crt* | xargs -L1 openssl x509 -text -noout -in > /var/tmp/ssl-cert-list.txt
     
  2. Delete the SSL certificate with unicode character.
    tmsh delete sys file ssl-cert <certificate-name>
