Topic

You should consider using this procedure under the following condition:

  • You want to increase or decrease the size of the logterminal.txt file created by BIG-IP Edge Client.

Description

BIG-IP Edge Client stores Windows client-side messages in the logterminal.txt file located in the %tmp% directory. By default, this file stores up to 5 MB of log messages. After the log file reaches the maximum size, BIG-IP Edge Client saves the log file to the disk and appends .bak to the name, and creates a new logterminal.txt file.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have sufficient privileges to modify the Windows registry.
  • You have installed BIG-IP Edge Client on a Windows client machine.

Procedures

Adding the registry key

You can adjust the size of the logterminal.txt file by adding the MaxLogFileSize registry key.

Impact of procedure: Make these changes at your own risk. Additionally, use the registry editor with extreme caution. If you make an error while editing the Windows registry settings, you can create issues that you can solve only by reinstalling the operating system.

  1. Log in to the Windows client system using an account with privileges to edit the registry for users on the system.
  2. Click the Start menu.
  3. In the Search box, type the following text and press Enter:

    regedit.exe

    Note: If User Account Control (UAC) is enabled, you may need to click Yes when prompted before the regedit utility opens.

  4. In the navigation pane of the regedit utility, click the icon to expand the HKEY_CURRENT_USER box.
  5. Click the icon next to Software.
  6. Click the icon next to F5 Networks.
  7. Click the icon next to Remote Access.
  8. Click the folder labeled Logging.
  9. In the Edit > New list, click DWORD (32-bit) Value.
  10. When prompted to name the key, type the following text:

    MaxLogFileSize

  11. Right-click the new MaxLogFileSize key and click Modify.
  12. Click Base.
  13. Under Value data, enter the desired new size for the logterminal.txt file.

    Note: The value is based on a default 5*1024*1024 size. For example, if you want the file to be approximately 10 MB, enter the value 10000000.

  14. Click OK
  15. Close the regedit utility.
