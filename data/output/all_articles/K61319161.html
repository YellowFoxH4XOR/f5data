K61319161: F5 Access fails to Auto launch from a URL on Android devices

Type
Support Solution
Published
2021-05-03
Updated
2023-02-21
Applies to
  • BIG-IP
  • F5 Access
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K61319161

Description

  • You have installed F5 Access App
  • Your Access policy is configured with Network Access and VPN APM objects 
  • You want to start VPN connections without having to manually start the application ( auto launch F5 Access from a URL ).
  • The described feature is discussed in F5's Manual article 
    • F5 Access and BIG-IP Edge Client
  • example of URL, f5access://start?name=exampleVPN&server=myvpn.siterequest.com
  • But, F5 Access fails to start from a URL on Android  devices
  • You also note, the same URL works on an iOS device where the F5 Access launches with the expected Network Access configuration

Environment

  • F5 Access
  • APM 
  • Android 
  • BIG-IP

Cause

  • URL auto launch on Android depends on a feature called 'Intents with Chrome / Android Intent'
  • This feature is no longer available natively in Chrome version 18 and above (Chrome for Android, versions 25 and later).

Recommended Actions

  • Possible to launch an Android app by setting an iframe's src attribute but this implementation is a none F5 Solutions
  • Please refer an external document refenced in the Related section of this article

Additional Information

  • None
