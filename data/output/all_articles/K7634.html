Known Issue

This is the result of a known issue. If you are using active FTP in conjunction with persistence and you access an active FTP data connection persistence record, TMM can crash.

F5 Product Development tracked this issue as CR66211, CR68289, CR66210, and CR66202, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.
