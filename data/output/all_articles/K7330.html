Known Issue

This is the result of a known issue. The BIG-IP LTM system fails to load a second default SNAT when each SNAT is created on its own VLAN. This is a result of the TMM process failing to recognize each SNAT's VLAN list. When this issue occurs, the following message is logged to the /var/log/ltm file:

mcp error: 1031000 in mcpmsg_to_database

F5 Product Development tracked this issue as CR76632, and it was fixed in BIG-IP LTM 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
