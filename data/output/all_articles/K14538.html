Known Issue

The BIG-IP 2000 and 4000 series platforms fail to detect the 1 gigabit LX Fiber SFP Module (Module Number: OPT-0011-00).

This issue occurs when the following condition is met:

  • The 1 gigabit LX Fiber SFP Module (Module Number: OPT-0011-00) is installed on one of the following BIG-IP platforms:
     
    • BIG-IP 2000s, 2200s (C112)
    • BIG-IP 4000s, 4200v (C113)

Impact

The 1 gigabit LX Fiber SFP Module (Module Number: OPT-0011-00) does not function on the BIG-IP 2000/4000 series platforms.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425759 on the Diagnostics > Identified > Medium page.
  • When a 1 gigabit LX Fiber SFP Module (Module Number: OPT-0011-00) is inserted in an interface socket on a BIG-IP 2000/4000 series platform, the interface status reports as miss (missing).

    For example:

    # tmsh show net interface 2.2
    -------------------------------------------------------------------
    Net::Interface
    Name   Status    Bits   Bits   Pkts   Pkts  Drops  Errs       Media
                       In    Out     In    Out
    -------------------------------------------------------------------
    ...
    2.2      miss       0      0      0      0      0     0        none
  • You may observe an error message in the /var/log/ltm file that appears similar to the following example:

    mcpd[5958]: 01070318:3: The requested media for interface <X.Y> is invalid.

    In this example, note the following:

    • <X.Y> is the interface populated with the affected Fiber SFP Module.

    Workaround

    There is no workaround for this issue. However, you may be able to mitigate the issue by using either the 1 Gigabit SR or 10 Gigabit LR Fiber SFP, depending on your environment.
