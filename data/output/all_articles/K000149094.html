K000149094: Monitoring per virtual service CPU usage with SNMP.

Type
Knowledge
Published
2024-12-27
Updated
2024-12-27
Source
https://my.f5.com/manage/s/article/K000149094

Description

You want to find SNMP OID for CPU utilization by each virtual service.

Environment

  • SNMP
  • Per virtual service CPU utilization
  • BIG-IP LTM

Cause

None

Recommended Actions

You can use the below SNMP OIDs to retrieve the CPU utilization for every CPU.

OID

Description

.1.3.6.1.4.1.3375.2.2.10.2.3.1.31

Average CPU utilization over the last 5 seconds.

.1.3.6.1.4.1.3375.2.2.10.2.3.1.32

Average CPU utilization over the last 1 minute.

.1.3.6.1.4.1.3375.2.2.10.2.3.1.33

Average CPU utilization over the last 5 minutes.

 

The output will be something similar to the following:    

 

CPU utilization over the last 5 seconds

# snmpwalk -v 2c -c public x.x.x.x .1.3.6.1.4.1.3375.2.2.10.2.3.1.31    
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatVsUsageRatio5s."/Common/test1" = Gauge32: 0
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatVsUsageRatio5s."/Common/test2" = Gauge32: 5

 

CPU utilization over the last 1 minute

# snmpwalk -v 2c -c public x.x.x.x .1.3.6.1.4.1.3375.2.2.10.2.3.1.32
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatVsUsageRatio1m."/Common/test1" = Gauge32: 0
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatVsUsageRatio1m."/Common/test2" = Gauge32: 3

 

CPU utilization over the last 5 minutes

# snmpwalk -v 2c -c public x.x.x.x .1.3.6.1.4.1.3375.2.2.10.2.3.1.33
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatVsUsageRatio5m."/Common/test1" = Gauge32: 0
F5-BIGIP-LOCAL-MIB::ltmVirtualServStatVsUsageRatio5m."/Common/test2" = Gauge32: 1
