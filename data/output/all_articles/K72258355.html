K72258355: BIG-IQ DCD Cluster configuration with destination NAT is not supported

Source

Description

Configuring cluster of BIG-IQ CM and DCD nodes where DCDs are hidden by NAT  doesn't work 
BIG IQ cannot add DCD  device to the cluster and receiving popup window with error:

An error occurred while adding the Device. Error: BIG-IQ is unable to find this device in the Data Collection Device (DCD) cluster. To resolve this issue, check that there is network connectivity between this BIG-IQ and the DCD then verify that the BIG-IQ system's management address and the DCD's IP address settings are correct. Correct any errors and try adding this device again.

Environment
  • New Big-IQ Cluster deployment
  • BIG-IQ CM and DCD nodes  in version 6.x 7.x 8.x
  • DCDs hidden behind NAT
 

Cause

Elasticsearch and application layer is not aware about NAT which is between devices. It will use address which it received on application layer with configuration.

Recommended Actions

This type of setup is not supported.
Avoid using Destination NAT between BIG-IQ devices

Additional Information

None.
