Known Issue

This is the result of a known issue. ZoneRunner may fail to display some AAAA resource records after they were created. When this issue occurs, instead of displaying the properties of the requested AAAA resource record, the Configuration utility returns the following error message:

Error trying to access the database.

Note: BIND resolution for these resource records is not affected. This issue is cosmetic and affects only ZoneRunner.

This issue occurs because ZoneRunner and BIND may represent the same IPv6 address using different notations. For example, BIND removes leading zeros in an IPv6 address, and ZoneRunner does not. These differences in notation cause an issue when ZoneRunner and BIND are required to exchange data.

F5 Product Development tracked this issue as CR130665 and it was fixed in BIG-IP GTM version 10.1.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

To work around this issue, you may delete and recreate the resource record. To do so, perform the following procedure:

  1. Log on to the BIG-IP GTM Configuration utility.
  2. Expand the Global Traffic section and click on ZoneRunner.
  3. Click on the Zone List tab.
  4. Click on the Zone Name that hosts the AAAA resource record requiring editing.
  5. Click on the Resource Records tab.
  6. Select the check box next to the AAAA resource record that requires editing.
  7. Click the Delete button.
  8. Confirm the delete action by pressing Delete.
  9. Recreate the AAAA resource record using the new settings.
