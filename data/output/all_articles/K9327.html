Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.6.1. F5 recommends that all customers currently running 9.6.1 install Hotfix-BIGIP-v9.6.1-HF2, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in HF2 for BIG-IP 9.6.1:

CR
ArticleDescription
CR100734K8878The bigd process incorrectly bases monitor ICMP timeouts on previous ping time 
CR101357K9027Installing hotfixes may not keep changes made to the profile_base.conf file or the config_base.conf file
CR103905K9051The BIG-IP system does not forward a FIN packet to the client for certain sessions using chunked transfer encoding 
CR104068K9054Setting connection limits on pool members or nodes may cause a file descriptor leak
CR96936K9329VIPRION default temperature thresholds are incorrectly configured
CR97531K8728TMM may crash while running tcpdump if a packet filter rejects an incoming packet
CR98904K9330A time shift of 10 seconds or more may cause the blades to become out of sync
CR99135K8938BIND DNS cache poisoning vulnerability - CVE-2008-1447 - VU#800113
CR99315K9331The mcpd process may exhaust memory during normal operations
CR99754K8864The TCP monitor marks pool members down before the timeout expires
CR99759K9333Traffic destined for a host over a trunked VLAN is not forwarded
CR99825K8790Connection limits for nodes are enforced per blade and not per cluster
CR99838K8939SNMPv3 HMAC verification vulnerability - CVE-2008-0960 - VU#878044

The hotfix is available for download at the F5 Downloads site. For information about downloading software from F5, refer to K167: Downloading software from F5.
