K15694: The BIG-IP system may fail to find an available inet port when the configured port range is small

Known Issue

The BIG-IP system may fail to find an available inet port. This issue occurs when all of the following conditions are met:

  • A virtual server is configured with LSN for its Source Address Translation setting and is associated with a LSN pool.
  • The LSN pool is configured with a small number of translation addresses and a small port range. 

    Note: You can determine the port range by finding the difference in values between the Port Range High and Port Range Low settings in the affected LSN pool. A small port range value is typically defined as smaller than the value of the tm.portfind.linear database key. The default value of the tm.portfind.linear database key is 16.

Impact

Client connection attempts may fail initially, but succeed subsequently.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H481964 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system reports inet port exhaustion for each LSN failure even though there are available ports in the configured port range.

Workaround

To work around this issue, you can either increase the port range or increase the number of translation addresses in the affected LSN pool or increase both as appropriate for your application environment. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Carrier Grade NAT > LSN Pools > LSN Pool List.
  3. Click on the name of the affected LSN pool.
  4. To increase the port range for the affected LSN pool, adjust the Port Range Low and Port Range High settings as appropriate for your application environment.
  5. To increase the number of translation addresses, enter the desired translation address in the Address/Prefix Length setting and click Add for the Member List section.
  6. To save the changes, click Update.
