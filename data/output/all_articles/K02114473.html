Description

Syslog server Pool (such as Splunk) has been configured as part of remote-high-speed-log destination with 2 or more other publishers.
All of a sudden, BIG-IP is no longer sending the logs to their destinations.

Example config with 2 destinations configured:

sys log-config publisher /Common/myHSLPublishers {
    destinations {
        /Common/dest_log_remote1 { } 
        /Common/dest_log_remote2 { }
    }
}

Environment

  • BIG-IP
  • High Speed Logging
  • Multiple publishers
  • Logging stops working to all destinations

Cause

If any of the destinations fail, the log publisher fails to publish logs to all of the logging destinations. 
This is the default behaviour on BIG-IP.

Recommended Actions

Ensure all publisher destinations are available or change the default behaviour as per the following article:
K03912652: Enable Log Publisher to log when a logging destination becomes unavailable
 

Additional Information

See the following article if local logging is configured as a destination:
K94501508: Local logging stopped when pools down/offline with logpublisher.atomic value 'false'
