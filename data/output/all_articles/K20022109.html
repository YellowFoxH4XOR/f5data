Issue

Error Message

notice mcpd[<PID>]: 01071764:5: HA order list in traffic group (/<partition>/<group_name>) cleared because there is no self failover device group found.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <partition> is the partition in which the traffic group is located.
  • <group_name> is the name of the traffic group.

For example:

notice mcpd[8484]: 01071764:5: HA order list in traffic group (/Common/traffic-group-1) cleared because there is no self failover device group found.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The self device is not assigned to a Sync-Failover group.
  • The high availability (HA) Order failover method is used in the related traffic group.

Impact

There is no impact. This is an expected notice level message from the configuration change of a device group.

Recommended Actions

None
