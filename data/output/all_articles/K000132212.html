K000132212: APM: About oAuth x5t (cert-thumbprint-sha1) parameter calculation

Type
Support Solution
Published
2023-01-25
Updated
2023-05-04
Source

Description

Following RFC7517, the "x5t" (X.509 certificate SHA-1 thumbprint) parameter is a base64url-encoded SHA-1 thumbprint (a.k.a. digest) of the DER encoding of an X.509 certificate.


When JSON Web Key is configured on APM in 'Access ›› Federation : JSON Web Token : Key Configuration', for RSA or Elliptic Curve key type there is 'SHA-1 Thumbprint' (aka 'x5t' aka 'cert-thumbprint-sha1') parameter. If the 'Certificate File' field is filled in, this x5t value is auto-generated. The purpose of this article to show how x5t value can be calculated manually for certificate in PEM or DER format when the certificate is not defined under the 'Certificate File' field.


Environment

  • APM
  • oAuth
  • x5t (aka 'SHA-1 Thumbprint' aka 'cert-thumbprint-sha1')

Cause

The procedure of x5t calculation for X.509 certificate in DER or PEM format.

x5t value calculation for certificate in PEM format:


1) calculate sha1 fingerprint of PEM format certificate using openssl tool


[root@apm.local:Active:Standalone] exampleCA # openssl x509 -in kb.crt -noout -fingerprint

SHA1 Fingerprint=3B:3C:E7:26:F7:CB:5F:0B:CC:94:AC:FF:26:DF:DD:25:DF:63:73:99


2) the same fingerprint value but without 'SHA1 Fingerprint=' and ':' in output:


[root@apm.local:Active:Standalone] exampleCA # openssl x509 -fingerprint -noout -in kb.crt |cut -f2 -d'=' | sed 's/://g'

3B3CE726F7CB5F0BCC94ACFF26DFDD25DF637399


3) calculate base64 encoding of the above thumbprint. Use xxd tool with the -r and -p arguments to convert from hex to plain binary/octets and base64 to convert the binary/octet form to base64.


[root@apm.local:Active:Standalone] exampleCA # echo '3B3CE726F7CB5F0BCC94ACFF26DFDD25DF637399' | xxd -r -p | base64

OzznJvfLXwvMlKz/Jt/dJd9jc5k=


4) convert base64 to base64url(in base64 replace "+" with "-" and "/" with " _" to get a base64url encoded string):


[root@apm.local:Active:Standalone] exampleCA # echo 'OzznJvfLXwvMlKz/Jt/dJd9jc5k=' | sed 's/+/-/g; s/\//_/g'

OzznJvfLXwvMlKz_Jt_dJd9jc5k=


5) removing padding '=':


[root@apm.local:Active:Standalone] exampleCA # echo 'OzznJvfLXwvMlKz_Jt_dJd9jc5k=' | sed 's/=//g'

OzznJvfLXwvMlKz_Jt_dJd9jc5k


'OzznJvfLXwvMlKz_Jt_dJd9jc5k' matches with 'cert-thumbprint-sha1' value when the certificate was explicitly provided for JWK configuration.


x5t value calculation for certificate in DER format:


1) convert from PEM to DER format


[root@apm.local:Active:Standalone] exampleCA # openssl x509 -outform der -in kb.crt -out kb.der


2) compute SHA1 message digest for certificate


[root@apm.local:Active:Standalone] exampleCA # sha1sum kb.der 

3b3ce726f7cb5f0bcc94acff26dfdd25df637399 kb.der


3) calculate base64 encoding of the above thumbprint. Use xxd tool with the -r and -p arguments to convert from hex to plain binary/octets and base64 to convert the binary/octet form to base64.


[root@apm.local:Active:Standalone] exampleCA # echo '3b3ce726f7cb5f0bcc94acff26dfdd25df637399' | xxd -r -p | base64

OzznJvfLXwvMlKz/Jt/dJd9jc5k=


4) convert base64 to base64url (in base64 replace "+" with "-" and "/" with " _" to get a base64url encoded string):


[root@apm.local:Active:Standalone] exampleCA # echo 'OzznJvfLXwvMlKz/Jt/dJd9jc5k=' | sed 's/+/-/g; s/\//_/g'

OzznJvfLXwvMlKz_Jt_dJd9jc5k=


5) removing padding '=':


[root@130a-oauth-c-rs:ModuleNotLicensed::Active:Standalone] exampleCA # echo 'OzznJvfLXwvMlKz_Jt_dJd9jc5k=' | sed 's/=//g'  

OzznJvfLXwvMlKz_Jt_dJd9jc5k


'OzznJvfLXwvMlKz_Jt_dJd9jc5k' matches with 'cert-thumbprint-sha1' value when the certificate was explicitly provided for JWK configuration
