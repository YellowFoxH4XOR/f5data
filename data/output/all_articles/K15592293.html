Description

Reason of Warnings in var/log/ltm log error:

warning icr_eventd[7511]: 01a10008:4: Resuming log processing at this invocation; held 3 messages.
Apr 28 23:54:01 localhost warning icr_eventd[7511]: 01a10008:4: Schema object encode failed: No foreign keys found for nested object with tag 17547

 

Environment

  • BIG-IP LTM or AFM
  • Log messages after upgrade/after reboot/ after full sync/modification of  firewall rule

Cause
Bug ID 738284: Creating or deleting rule list results in warning message: Schema object encode failed
 

Recommended Actions

This shows up  and has no impact on functionality. That is actually an internal warning and should not display to users.
Upgrade BIG-IP to one of not affected version pointed in Bug.

Additional Information

This is seen after an upgrade, or when "load sys config", or when performing a full-sync (non-incremental).
