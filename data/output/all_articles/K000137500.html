Description

To prevent any disruption to traffic or services, F5 recommends that you renew a certificate before the existing traffic certificate expires.

Environment

  • BIG-IP
  • Traffic Certificate
  • CA Signed SSL Certificate

Cause

The current SSL certificate used in SSL profile is going to expire.

Recommended Actions

When renewing Traffic SSL certificates on the BIG-IP system you may need to perform one or more of the following tasks:

  • Renew the certificate by creating CSR and submit it to the CA for signature
  • Export the SSL private key
  • Import the renewed SSL certificate
  • Import the SSL private key


Renew the certificate by creating CSR and submit it to the CA for signature

  1. Log in to the Configuration utility.
  2. Go to the SSL Certificate List page: go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List. 
  3. Select the name of the certificate you want to renew.
  4. Select Renew.
  5. For Issuer, select Certificate Authority.
  6. Complete the remaining information as required.
  7. Select Finished.
  8. On the Certificate Signing Request page, copy the CSR from the Requested Text box; or to download the CSR, select Download.
  9. Select Finished.
  10. After the CSR is signed and returned by the CA, continue to the next procedure.


Export the SSL private key

  1. Go to the SSL Certificate List page: go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  2. Select the name of the certificate you are renewing and whose key you want to export.
  3. Select the Key tab.
  4. Select Export.
  5. On the Key Export page, select Download.


Import the renewed SSL certificate

  1. Go to the SSL Certificate List page: go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  2. Select Import.
  3. In the Import Type list, select Certificate.
  4. For Certificate Name, select New and enter a name for the certificate.
  5. For Certificate Source, select either Upload File and browse to the file or Paste Text and paste plain text into the box.
  6. Select Import.

Import an SSL private key

  1. Go to the SSL Certificate List page: go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  2. Select Import.
  3. In the Import Type list, select Key.
  4. For Key Name, select New and enter the same name used when importing certificate.
  5. For Key Source, select Upload File and select Choose File to browse to the file location of the Exported SSL private Key.
  6. Optional: If you want to set a password for the key, in the Security Type list, select Password and enter a password.
  7. Select Import.

Now you can assign the new certificate and key pair to SSL profile.
