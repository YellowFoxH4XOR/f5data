K000091530: NGINX Instance Manager (NIM) unable to publish config file with error "<filename/directory> is outside the allowed directory list"

Type
Support Solution
Published
2022-04-26
Updated
2022-04-27
Source
https://my.f5.com/manage/s/article/K000091530

Description

  • Failure in publishing config to NGINX Instance
  • Error message example - "file /etc/ssl/nginx/my_own_cert.crt is outside the allowed directory list"

 

Environment

  • NGINX Instance Manager 2.1.0
  • NGINX Plus Instance R26 

 

Cause

 The file directory is not defined in nginx-agent.conf 

 Recommended Actions

  • In NGINX Instance, take a backup of /etc/nginx-agent/nginx-agent.conf
    • cp /etc/nginx-agent/nginx-agent.conf /etc/nginx-agent/nginx-agent.conf_backup
  • Edit /etc/nginx-agent/nginx-agent.conf with file editor, by appending the desired directory to the config_dirs section. Below example to add /ets/ssl/nginx directory:
    • config_dirs: "/etc/nginx:/usr/local/etc/nginx:/usr/share/nginx/modules:/etc/nms", to 
    • config_dirs: "/etc/nginx:/usr/local/etc/nginx:/usr/share/nginx/modules:/etc/nms:/etc/ssl/nginx"
  • Run systemctl restart nginx-agent
