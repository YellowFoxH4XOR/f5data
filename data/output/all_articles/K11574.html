Known Issue

When connected to a protected workspace, users are unable to correctly save files in the PowerPoint 97-2003 format. If the user tries to open a previously saved PowerPoint 97-2003 file, they will receive an error message stating that the file has been corrupted and cannot be opened.

Note: This issue has not been reported for any other versions of PowerPoint.

F5 Product Development tracked this issue as ID 243480 (formerly CR136883), and it was fixed in BIG-IP 10.2.0 and in FirePass 7.0.0. For information about upgrading, refer to the BIG-IP APM or FirePass release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
