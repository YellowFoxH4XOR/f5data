Issue

Old Behavior

In BIG-IP 11.2.1 through 11.4.1, when you disable a virtual server, the BIG-IP system sends gratuitous ARPs (GARPs) for all configured self IP addresses and ARP-enabled virtual servers, excluding disabled virtual servers. Additionally, when you enable a disabled virtual server, the system sends GARPs for ARP-enabled virtual servers.

New Behavior

In BIG-IP 11.5.0 and later, when you enable or disable a virtual server, the BIG-IP system sends GARPs for all configured self IP addresses and ARP-enabled virtual servers, even if those servers are disabled.
