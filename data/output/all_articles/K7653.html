Known Issue

This is a result of a known issue. When the BIG-IP host system issues an ARP request for a TMM controlled IP, the BIG-IP LTM may crash TMM. This issue is rare and occurs only when the following two conditions are met:

  • The IP address is in a transition state, such as a failover state.
  • The BIG-IP host system issues an ARP request.

As a result, the ARP response is incorrectly directed back to TMM instead of being directed back to the BIG-IP host.

F5 Product Development tracked this issue as C68244, CR68163, CR68243, and CR68226 and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.
