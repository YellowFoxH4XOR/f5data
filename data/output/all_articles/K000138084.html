Description

Using 'HTTP::payload ' in iRule is incompatible with chunked HTTP response therefore, you will encounter iRule execution error.
/var/log/ltm:
[RST, ACK] Seq=52129 Ack=7751 Win=0 Len=0 [F5RST(peer): iRule execution error]


Hypertext Transfer Protocol

   HTTP/1.1 200 OK\r\n
   Transfer-Encoding: chunked\r\n <----


Environment

  • BIG-IP
  • iRule
  • HTTP traffic

Cause

HTTP::payload is generally not intended to be used on its own. Data should first be captured with HTTP::collect and then you can use HTTP::payload in HTTP_REQUEST_DATA/HTTP_RESPONSE_DATA events. Alternatively, HTTP::payload can be used in HTTP_REQUEST/HTTP_RESPONSE only when incoming HTTP data is in single packet and not chunked.

 

Recommended Actions

Update the iRule accordingly if expecting chunked HTTP response. For further assistance with iRule, please contact F5 Professional Services team.
