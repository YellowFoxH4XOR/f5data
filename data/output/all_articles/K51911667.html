K51911667: Limit of total fields [5000] in index [global] has been exceeded

Type
Support Solution
Published
2022-09-16
Updated
2024-03-19
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X
Source
https://my.f5.com/manage/s/article/K51911667

Description

When you have a large number of Applications it can cause tokumond to never finish indexing.  You will see "Limit of total fields [5000] in index [global] has been exceeded" in /var/log/tokumon/current.
 

Environment

  • A large number of Applications on the Big-IQ
  • "grep percentComplete /var/log/tokumon/current" shows progress never getting to 98% before restarting.
  • /var/log/guiserver/current shows indexing is pending

Cause

ID1182737
This is caused by the RBAC entries automatically created by each Application.  There can be so many that it exceeds the size limit for indexing for tokumond.

Recommended Actions

The following change will not survive an upgrade.  If you upgrade the device you will need to perform them again.

  1. Make /usr readwrite: 
    mount -o remount,rw /usr
  2. Backup global.js
    cp /usr/share/rest/tokumon/config/modules/global.js /usr/share/rest/tokumon/config/modules/global.js.orig
  3. Edit /usr/share/rest/tokumon/config/modules/global.js
    Note: Experience of editing files on Linux system required
    vi /usr/share/rest/tokumon/config/modules/global.js
  4. Make the below changes:
    ...
    mappings: {
            "properties": {
                "_value": {
                    "type": "object",
                    "properties": {
                        "resources": {
                            "enabled": false
                        },
                        "appSvcsDeclaration": {
                            "enabled": false
                        },
                        "declaration": {
                            "enabled": false
                        },                               <=== Add a comma at the end of this line
                        "body": {                        <=== Add this line
                            "enabled": false             <=== Add this line
                        }                                <=== Add this line
                    }
                }
            }
        }
  5. Make /usr readonly:
    mount -o remount,ro /usr

  6. Clean and restart tokumond by running these three commands:
    bigstart stop tokumond
    /usr/share/rest/tokumon/clean.sh
    bigstart start tokumond

    Repeat on peer BIG-IQ
