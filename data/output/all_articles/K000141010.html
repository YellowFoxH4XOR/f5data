Description

A HTTP/HTTPS monitor is shows a pool as Down.

Environment

  • BIG-IP
  • HTTP/HTTPS monitor

Cause

Possibly the Send or the Receive string syntax is not correct.

The Send/Receive string is case sensitive. Check if there are no extra white spaces.

Example this is might what server responds: 

HTTP/1.1 200 OK
Date: Tue, 10 Sep 2024 08:33:05 GMT
Server: Apache/2.4.41 (Ubuntu)
Content-Type: text/html

For example if you are trying to match the receive string "200 OK".

None of these will match because:

200  OK   >> There is extra space between 200 and OK

200 ok     >> "ok" is lower case

200 Ok    >> The "O" is in capital and "k" is small case. 

Recommended Actions

For this string to match it needs to be exactly the same which is:

200 OK     >> There is only one space between 200 and OK and the OK is in capital.
