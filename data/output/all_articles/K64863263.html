K64863263: BIG-IP ASM Microservices Override not an option without Advanced WAF License

Type
Support Solution
Published
2019-09-05
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.0
Source
https://my.f5.com/manage/s/article/K64863263

Description

In ASM version 14.1.0+ the option to add Overrides in the Microservices menu may not be available.

Environment

  • BIG-IP ASM

Cause

Advanced WAF license is required to add this functionality.

Recommended Actions

If this functionality is required then an Advanced WAF license upgrade is required.

Additional Information

Under ASM license the following functionality will be allowed:
  • Allowing to configure only URL, Host, and Enforcement mode (all options - including Blocking).
  • GUI will hide violation overrides.
  • It will be possible to retrieve suggestions for Microservices with REST.
  • BD will implement Enforcement mode for Microservice.
