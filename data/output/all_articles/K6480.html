Topic

When a client or a local DNS (LDNS) server directs a DNS request to the BIG-IP DNS system, the BIG-IP DNS system attempts to probe the LDNS server to obtain path metrics. In addition, other F5 devices that are equipped with a big3d agent and are included in the configuration may also probe the LDNS server. The system uses metric information collected by the big3d agents to make wide-area load balancing decisions based on network conditions between the big3d agent and the LDNS server.

Description

By default, big3d agents attempt to probe the LDNS server using Internet Control Message Protocol (ICMP) echo requests. You can additionally configure big3d to probe LDNS servers using the following metrics collection protocols:

  • DNS_REV query
  • DNS_DOT query
  • UDP echo
  • TCP port 53 socket connection

In some cases, the BIG-IP DNS probing may appear to be an attack or a prelude to an attack and the system intrusion detection systems may report it.

If your system uses BIG-IP DNS probing, you may notice the following BIG-IP DNS symptoms:

  • Local DNS servers are excessively pinged by the source addresses of F5 devices.
  • Border routers intercept an unusual number of pings from the source addresses of F5 devices.
  • Unusually large numbers of attempted connections to TCP or UDP port 53 appear to be an attack.
  • Unusual methods are used to query a DNS server (DNS_REV or DNS_DOT).

The path metrics provided by the BIG-IP DNS probing are required to make dynamic load balancing decisions. When the default methods are not acceptable to administrators of destinations that the BIG-IP DNS probes, you can try the following strategies to resolve the issue:

  • Change the probing protocol used by big3d agents.
  • Disable probing of specific destinations by creating an address exclusion list.

Changing the probing protocol used by big3d agents

In most cases, F5 recommends using the default probe protocols. However, you can configure the DNS_REV and DNS_DOT probing methods. These probing methods perform DNS queries to generate path metrics as follows:

  • DNS_REV performs a reverse-name lookup of the local DNS server IP address.
  • DNS_DOT performs an address lookup for the Internet root nameservers from the LDNS.

Creating an address exclusion list to disable probing of specific destinations

To disable probing of a specific LDNS destination, you can create an address exclusion list. To do so, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the Configuration utility.
  2. Navigate to DNS > Settings > GSLB > Metrics Collection.
  3. Under Address Exclusions, enter the appropriate subnet for IP Subnet and click Add.
  4. Click Update.
