K000147274: What do I need to access the shared and system namespace of my tenant?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-20
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147274

Description

  • You want access to the shared and system namespaces
  • You see a lock over the Shared Configuration service and see the message "You cannot access this feature with your current role" when you click it                                                

Environment

  • F5® Distributed Cloud
  • Account Management

Answer/Recommended Actions

  • You need a role for the shared namespace and another for the system namespace
  • Your tenant owner can add these roles in Administration > Users > Meatball menu (...) of the user > Edit User > Assign roles and namespaces
  • See this image for reference on the different namespaces
  • Click Save changes
