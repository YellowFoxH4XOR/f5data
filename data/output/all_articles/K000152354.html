Description

BIG-IP iSeries platform was rebooted unexpectedly. And the /var/log/ltm does not indicate reason for reboot.


Environment

  • iSeries platform
  • All BIG-IP versions

Cause

On the iSeries platform the /var/log/sel log will help to troubleshoot unscheduled reboots. In this case the System rebooted due to High Temperature.


0001 04/18/22 04:21:43 INF BMC Temperature #0c Hi Crit thresh act=2d thr=2d

0002 04/18/22 08:10:32 INF BMC Temperature #0c Hi Unrec thresh act=30 thr=30

0003 06/18/22 08:10:33 INF Host Power Cycle Event

0004 04/18/22 08:10:37 INF Host Reset Event

0005 04/18/22 08:10:38 INF Thermal Shutdown Event. Sensor: 12 Value: 48 Threshold: 48

0006 04/18/22 08:10:52 INF BMC Temperature #0c Hi Crit thresh act=2f thr=2d


Recommended Actions

  • Check the temperature in the datacenter to see if it's breaching temperature threasholds.
  • If the temperature is normal it maybe the result of a faulty sensor.

  • Run All (non-interactive) tests on EUD.
    • Please refer the platform specific document in: K7172: Overview of the End User Diagnostics software
  • Once the EUD testing has completed, contact F5 Support, reference this article, and provide the EUD test output for analysis.
