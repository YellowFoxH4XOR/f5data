Known Issue

The BIG-IP ASM system may fail to display detailed information for violation occurrences. This issue occurs when all of the following conditions are met:

  • The ASM system is running version 10.2.4 HF4.
  • You attempt to view detailed occurrences of the violations listed on the Application Security > Manual Policy Building > Traffic Learning screen.

Impact

The BIG-IP ASM system does not provide details for the learned violations.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to view detailed occurrences of the violations listed on the Application Security > Manual Policy Building > Traffic Learning screen, the ASM system displays a blank screen.
  • The ASM system reports an error message similar to the following example in the /var/log/httpd/httpd_errors file:

    err httpd[<pid>]: [error] [client <client IP>] PHP Fatal error: Call to undefined function hide_ip_default_rd() in /var/ts/dms/policy/win_open_request.php on line 59, referer: https://<ASM system managment IP>/dms/policy/lrn_http_checks.php
