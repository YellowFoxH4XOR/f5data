Known Issue

The BIG-IP Virtual Edition (VE) may fail to load the default configuration. This issue occurs when all of the following conditions are met:

  • The BIG-IP VE system is deployed on the Microsoft Azure cloud service.
  • You attempt to reset the BIG-IP VE to the default configuration using the tmsh load sys config default command.

Impact

The BIG-IP VE system fails to load the default configuration and reports an error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP VE system fails to load the default configuration and reports an error message similar to the following example:

    Loading configuration...
      /defaults/defaults.scf
    Syntax Error:(/defaults/defaults.scf at line: 97) "description" may not be specified more than once

Workaround

To work around this issue, you must delete the affected BIG-IP VE instance in the Microsoft Azure cloud service, and then start a new instance. When the new instance is up, contact F5 Technical Support to receive authorization to move the license to the new instance.
