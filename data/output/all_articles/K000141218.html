Description

  F5 Telemetry Streaming supports following tables:

  • System
  • Syslog
  • LTM request log
  • CGNAT log
  • AFM log
  • ASM log
  • APM log
  • AVR log

Following documentation contains  System and Syslog events  output examples and how it is formatted to JSON
