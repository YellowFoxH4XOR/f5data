Issue

If the standalone client software becomes corrupted, users may see the following error message when launching the FirePass standalone client:

Unable to load client configuration file.  Please re-install the application

To resolve this issue, users should uninstall and reinstall the standalone client. For instructions about installing the standalone client, refer to the FirePass Controller Administrator Guide.

The corruption may result from someone manually editing the file typically located at %USERPROFILE%\Application Data\F5 Networks\VPN\client.f5c. F5 Networks highly recommends that you do not manipulate that file on the user's machine.
