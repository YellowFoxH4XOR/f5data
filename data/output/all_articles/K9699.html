Known Issue

This is the result of a known issue. The Traffic Management Microkernel (TMM) may crash when RAM Cache is enabled and an iRule is used to mark a cache entry as stale, based on age.

A TMM crash may occur when all of the following conditions are met:

  • RAM Cache is enabled on a virtual server through an HTTP profile
  • An iRule is configured to expire the contents of the cache, based on the age of the contents
  • Multiple and concurrent HTTP GET requests are received by the virtual server after the iRule has expired the cache contents
  • The server (node associated to virtual server) responds with an HTTP OK message

If all of these conditions are met and a TMM crash occurs, a core file will be created and the system will reboot after the core file has been written to disk.

F5 Product Development tracked this issue as CR84861 and it was fixed in version 9.4.2 for the BIG-IP 9.4 software branch. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-9.3.1-HF5, which has been issued for BIG-IP 9.3.1 for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
