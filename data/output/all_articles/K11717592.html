K11717592: Qkview from a DCD doesn't show graphs

Support Solution
Published
2022-02-27
Updated
2023-10-17
Applies to

  • BIG-IQ Platforms

Source
https://my.f5.com/manage/s/article/K11717592

Description

Qkview data does not show CPU and Memory usage even though the Configuration utility, Performance > Overview > Monitor" displays CPU and memory usage statistics.

The "Graphs" section of the qkview displays:

No standard graphs were found in this QKView. The QKView may be corrupt or it may have been taken from a freshly installed system that didn't have time to accumulate graph data. 

Environment

  • DCD not licensed
  • Qkview
  • Configuration utility (gui)
  • CPU and Memory statistics

Cause

A base DCD license has not been applied. 

Recommended Actions

Since BIG-IQ release 7.1.0 a license is not required for DCD functionality. A DCD license is still required for the statsd process that generates the data used in the qkview.

 

Additional Information

BIG-IQ license no longer required for Data Collection Devices
