K8282: Failed SSL connections using compat ciphers can affect other SSL connections

  • BIG-IP LTM: 9.4.2, 9.4.1, 9.4.0, 9.3.1, 9.3.0, 9.2.5, 9.2.4, 9.2.3, 9.4.3, 9.2.0, 9.1.3, 9.1.2, 9.1.1, 9.1.0, 9.2.2
Source

Compat ciphers are part of the OpenSSL suite and must be specified within the SSL profile. If an SSL connection uses a compat cipher and fails or encounters an error, it can cause subsequent SSL connections to fail.

F5 Product Development tracked this issue as CR88223 and it was fixed in BIG-IP LTM 9.4.4. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.1.3-HF1 issued for BIG-IP 9.1.3, in Hotfix-BIG-IP-9.3.1-HF2 issued for BIG-IP 9.3.1, and in Hotfix-BIG-IP-9.4.3-HF4 issued for BIG-IP 9.4.3. You may download these hotfixes or later versions of these hotfixes from the F5 Downloads site.
