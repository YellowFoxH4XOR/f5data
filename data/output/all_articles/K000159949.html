K000159949: F5 Access for Android may fail to validate the Server Certificate if OCSP Stapling is enabled.

Type
Support Solution
Published
2026-02-10
Updated
2026-02-10
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 21.X.X, 17.X.X, 21.0.X, 21.0.0, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
  • F5 Access
Source

Description

F5 Access for Android may fail to validate the Server Certificate if OCSP Stapling is enabled. During this problem in the F5 Access App-side logs (F5Access.log), the following types of logs may be observed:

Failed to validate the certificate chain, error: Chain validation failed
[ERROR:net/socket/ssl_client_socket_impl.cc:916] handshake failed; returned -1, SSL error code 1, net_error -202
onReceivedSslError:primary error: 3 certificate: Issued to: CN=xxx,O=yyy,L=zzz;

In the F5 Access App, a pop-up window may appear with "SSL Error ...".

Environment

  • BIG-IP APM
  • Client SSL Profile has OCSP Stapling enabled
  • Client SSL Profile is configured with a partial chain (server certificate → intermediate CA certificate)
  • F5 Access for Android

Cause

To track this issue, we have filed ID2218189; however, because we rely on the underlying Android OS for server certificate verification, Android-side changes might be required.

Answer/Recommended Actions

There can be two options:

  • Configure the APM Client SSL profile to include the complete certificate chain (server certificate → intermediate CA certificate → root CA certificate) instead of only the partial chain (server certificate → intermediate CA certificate). OR,
  • Disable OCSP Stapling on the client ssl profile (in this case, the F5 Access will verify the server certificate based on CRL-related information from the server certificate).
