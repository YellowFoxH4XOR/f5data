K000135794: F5 Viprion C2400 offline after upgrade

Published
2023-08-09

Applies to

Source
https://my.f5.com/manage/s/article/K000135794

Description

The configuration is not loading after the upgrade.

The error from tmsh load sys config verify

 

10715cd:3: Cannot use order 0 on firewall rule (_sys_allow_tcp_defaults). Already used by _sys_allow_udp_defaults in (/Common/_sys_self_allow_defaults).

 Unexpected Error: Validating configuration process failed.

 

Environment

  • BIG-IP
  • LTM
  • Upgrade
  • Config validation error
     

Cause

Invalid configuration. 

 

Recommended Actions

1. Make backup of the bigip_base.conf

cp /config/bigip_base.conf /config/bigip_base_backup

2. Using vim or vi - Remove section from the /config/bigip_base.config:

security firewall rule-list /Common/_sys_self_allow_defaults {
 

3. Load the config:

tmsh load sys config

 

The commented/removed config will be automatically recreated
