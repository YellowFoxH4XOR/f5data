Environment

  • VIPRION
  • Multi-blades
  • Failsafe Fault


Cause

  • minimum number of blade funcion is enabled
     

Recommended Actions

Setting the Minimum Blades Up option from the GUI

  1. Go to Device Managament >> Devices
  2. Select the device
  3. Go to the Failover Network tab
  4. Modify the value under Cluster options : Minimum Number Of Blades Up Before Device Is Considered Available to 1


Setting the Minimum Blades Up option from the CLI

bash mode,  execute the following commands

    tmsh modify /sys cluster default min-up-members 1 min-up-members-enabled no
    tmsh save sys config
