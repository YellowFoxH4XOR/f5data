Description

Configuring a TCP health monitor to use a binary send and receive string is not working as expected.

Environment

  • TCP Health Monitor

Cause

None

Recommended Actions

You can send any binary string with a TCP health monitor using hexadecimal escape sequences.

Follow these steps as a guide on how to configure a TCP Health Monitor using hexadecimal escapes:

  1. Using the BIG-IP configuration utility (GUI), navigate to Local Traffic > Monitors, click Create and select Type: TCP.

  2. Insert each character for the send and receive strings in hexadecimal code with this syntax: \xHH.

    For example:

    Send String: Hello this is a test
    ASCII value       H   e   l   l   o       t   h   i   s       i   s       a       t   e   s   t
    HEX value:       48  65  6c  6c  6f  20  74  68  69  73  20  69  73  20  61  20  74  65  73  74
    BIG-IP syntax: \x48\x65\x6c\x6c\x6f\x20\x74\x68\x69\x73\x20\x69\x73\x20\x61\x20\x74\x65\x73\x74

  3. Configure the receive string to match the expected response from the server, for example:

    Receive String: Test Received
    ASCII value:      T   e   s   t       R   e   c   e   i   v   e   d
    HEX value:       54  65  73  74  20  52  65  63  65  69  76  65  64
    BIG-IP syntax: \x54\x65\x73\x74\x20\x52\x65\x63\x65\x69\x76\x65\x64

Additional Information

The monitor on the example above, will look like this:

ltm monitor tcp /Common/Hex_Monitor {
    adaptive disabled
    defaults-from /Common/tcp
    description none
    destination *:port
    interval 5
    ip-dscp 0
    recv \x54\x65\x73\x74\x20\x52\x65\x63\x65\x69\x76\x65\x64
    recv-disable none
    send \x48\x65\x6c\x6c\x6f\x20\x74\x68\x69\x73\x20\x69\x73\x20\x61\x20\x74\x65\x73\x74
    time-until-up 0
    timeout 16
}
