Description

iRulesLX workspace is missing from GUI but still showing up on CLI output

Environment

  • BIG-IP LTM
  • iRulesLX

Cause

iRulesLX config doesnt restrict you from deleting the configured workspace even if its used by a plugin, once that is done the GUI will properly reflect its state to workspace is "none" but it can still show up in CLI output. The command below can be used to verify if its still referenced:

tmsh list ilx plugin all-properties

Recommended Actions

Recreate the workspace and assign it back to this plugin, or delete the plugin and create new one with proper workspace

None
