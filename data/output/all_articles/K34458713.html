Description
K94361213 describes APM Application Tunnel connections fail if configured with a Host Name. But APM Application Tunnel connections also fail if configured with IP based and DNS Relay Proxy service is not installed on the Windows client.

Environment

  • You are using APM
  • You are using Application Tunnel based on host name or IP
  • DNS Relay Proxy service is not installed on the Windows client

Cause
DNS Relay Proxy service is required to use Application tunnel.

Recommended Actions

Install the DNS Relay Proxy service on the APM client if it's not installed on the client. You can refer to K9694 how to install the DNS Relay Proxy.

Additional Information
The DNS Relay Proxy service is a default component setting for the BIG-IP APM and BIG-IP Edge Gateway client download. To check if the DNS Relay Proxy service is installed on the Windows client, you can launch Services app and check if F5 Networks DNS Relay Proxy Service is running or not.
