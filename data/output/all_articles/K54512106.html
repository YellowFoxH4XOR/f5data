Description

After upgrading the BIG-IP software, you observe that the "Create New Policy" button no longer works and results in the following error message on the GUI:

[object Object]

Environment

  • BIG-IP ASM
  • Creating a new ASM policy from the GUI
  • Large number of VIP objects in the configuration
  • Upgrade to impacted software version v14 or above

Cause

ID903357

Recommended Actions

Upgrade software to a fixed software version.  Follow ID link for more details.

If you are unable to upgrade to a fixed version, you can apply the following workaround:

Create a blank ASM Policy using tmsh, then edit it in the GUI and assign it to the Virtual Server.

Example:

tmsh create asm policy test1
 

Additional Information

On selecting "Create New Policy" a REST API call requests all the VIP objects to populate the Virtual Server Menu drop box.  This process can exceed the restjavad timeout (60s default) if there are many VIP objects.  ID903357 resolves this issue.
