Description

When you try to enable Dynamic Routing Protocols, below error messages may be observed from /var/log/ltm:

 info audit_forwarder[12446]: audit_forwarder started.
 warning mcpd[8587]: 01071030:4: RIP feature not licensed.

or

 info audit_forwarder[1579]: audit_forwarder started.
 warning mcpd[9163]: 01071030:4: OSPFv2 feature not licensed.

 

Environment

  • BIG-IP LTM All
  • Dynamic Routing Protocols

Cause

To enable dynamic routing protocols feature, it is necessary to include Advanced Routing Module (ARM) license.

Recommended Actions

To verify the license information run command:

 # tmsh show /sys license

 

For more advanced dynamic routing protocols like RIP, OSPF, BGP or IS-IS, you'll need to contact your F5 Sale representative and purchase and enable the Advanced Routing Module (ARM) license.

 

Additional Information

If you're only using basic static routing, policy-based routing (PBR), or directly connected routes, then no additional licensing is needed — these features are free to use within the base BIG-IP LTM license.
