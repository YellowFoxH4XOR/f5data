Description
For BIG-IP v14.1.x and later, the default testing page of the Apache web-server is accessible at <mgmt-ip>/noindex.

Environment

  • BIG-IP v14.1.x.x
  • Unable to upgrade to fixed version
  • This is encountered when navigating to the /noindex page from the web browser.

Cause
This due to BUG ID864321.

Recommended Actions

  1. Add the following to sys httpd include

    # tmsh list sys httpd
    sys httpd {
        include "
        <Directory \"/usr/local/www/noindex\">
            AllowOverride None
            Require all denied
        </Directory>
        "
    }
  2. To add the include content use the following command:

    # tmsh edit sys httpd
     
  3. After adding save your config by running this command:

    # tmsh save sys config
     
  4. After adding the include content,  this time when you access <mgmt-ip>/noindex gets Access forbidden

Additional Information

As per BUG ID864321 you can also upgrade to v16 to fix the issue
