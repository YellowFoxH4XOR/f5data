Known Issue

In rare situations, the Traffic Management Microkernel (TMM) process may leak memory or produce a core file when using some iRules events.

This issue occurs when the following condition is met:

  • You use the FLOW_INIT event in an iRule.

Impact

Memory exhaustion may cause TMM to become unstable and produce a core file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM memory consumption steadily increases over time. You can monitor TMM memory usage using the tmstat command, or the following TMOS Shell (tmsh) command:

    tmsh show sys memory

  • If configured as a high availability (HA) pair, the BIG-IP system fails over to the standby system.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
