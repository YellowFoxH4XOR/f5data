Known Issue

Attempts to delete and re-create objects within the same transaction may fail.

This issue occurs when all of the following conditions are met:

  • You perform the delete and re-create operations for an object, in batch mode, as a single transaction using one of the following:
    • iControl Services Manager (iSM)
    • The Traffic Management Shell (tmsh)
    • A device group configuration synchronization (ConfigSync) operation
  • The configuration object that you attempt to delete refers to another object. For example, this condition occurs if you attempt to delete and re-create a virtual server that references a profile.

Impact

Attempts to perform delete and re-create operations for an object, within the same transaction, may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system logs error messages to the /var/log/ltm file that appear similar to the following example:

    err mcpd[7597]: 01020066:3: The requested virtual server profile (/Common/vs1 /Common/tcp) already exists in partition Common

Workaround

To work around this issue, you can perform a single transaction to delete an object and then a subsequent transaction to re-create the object. For example, if you want to delete a virtual server that references a profile, you should first create one transaction to remove the virtual server, and then create a second transaction to re-create virtual server.
