Description

I want to configure load balancing with an HTTP Load Balancer to distribute the traffic based on Geo location on my Origin Pool servers. Can it be configured?

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer

Answer/Recommended Actions

Yes, you can configure it following the next steps:

1. First, we have to create the label (Key) for our Origin Servers.

  • For that label(key) creation you have go to "Other Settings" > "Origin Server Subsets" > Enable Subset Load Balancing

2. Then we proceed to create the Origin Servers and attach the label(key) to them. (You have to enable “Show Advanced Fields”)

3. Once you finish, save the configuration and go to the HTTP Load Balancer where you planned to apply it. Go to the section Origins and enable Show Advanced Fields to access to Origin Server Subset Rules

4. On Origin Server Subset Rules create a Rule:

  1. Name the rule
  2. Under Action you have to add your label created on Origin Server Subsets

  3. Under Clients select the country that you want to target your rule, in my case is Spain

  4. Click on Apply and repeat for the other label, that in my case was for Poland.
