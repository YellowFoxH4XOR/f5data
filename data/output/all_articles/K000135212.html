Description

Upon initiating the logout process, the SAML SLO workflow will take the browser to the Identity Provider [IDP] to log the session out.

Once done, the browser is forwarded by the IDP to the BIG-IP Service Provider [SP] to complete the logout.

And as the browser does so, it displays an error message.

Environment

  • SAML
  • BIGIP APM as SAML SP
  • (maybe) Chrome browser

Cause

This may be because the browser does add the mandatory APM session cookies to the SAML logout/SLO response.

Recommended Actions

Please update the SAML SP AccessProfile "samesite" to "None".

With the BIG-IP Configuration Utility:

  1. Navigate to Access ›› Profiles / Policies : Access Profiles (Per-Session Policies)
  2. Click the affected Access Profile
  3. Click the tab #2 "SSO / Auth Domains"
  4. For "Cookie Options", check "Samesite" and select "None" from the dropdown menu
  5. Click the Update button
  6. Click "Apply Access Policy", on the top left of the page
