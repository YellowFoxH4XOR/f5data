Description

Can not import a new device certificate

  • Error messages:  Management: private key export: keys (server) in Web Server mode exp orted by user "admin" via KeyCertificate_impl::key_export_to_pem()

Environment

  • BigIP LTM 12.1.3

Cause

Problems with the configuration

Recommended Actions

  1. Created two blank files: bigip.conf and bigip_base.conf.
  2. Loading the default configuration tmsh load sys config default 
  3. You should be able to import the new device certificate (certificate and key)
