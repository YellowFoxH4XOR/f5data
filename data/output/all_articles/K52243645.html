K52243645: Subscription license end date cannot be changed

Type
Support Solution
Published
2022-10-04
Updated
2026-02-05
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K52243645

Description

Only virtual subscription programs allow you to select a start and end date. Subscription licenses associated with perpetual base registration keys do not provide an option to configure activation dates. 

Environment

  • VE Subscriptions
  • Perpetual base registration key
  • Subscription license

Cause

None
 

Recommended Actions

If you have a VE Subscription license and need to modify the subscription program’s start or end date, please contact your F5 Account Manager for assistance.


As for Subscription license for Perpetual base registration keys (Non-Evaluation), if the End date doesn't show correctly, you may contact F5 Support or email supportone@f5.com to open a Service Request.
 

Additional Information

None
