K000140113: GTM Health Monitor fails

Type
Support Solution
Published
2024-06-25
Updated
2024-06-25
Applies to
  • BIG-IP
  • BIG-IP DNS: 16.1.4
Source
https://my.f5.com/manage/s/article/K000140113

Description

DNS http health monitor fails using recv "HTTP/1.1 200|HTTP/1.1 30?" with error connect: redirected, search result: true


Environment

-DNS HTTP monitor marked down

-error connect: redirected, search result: true

Cause

recv "HTTP/1.1 200|HTTP/1.1 30?" is validating the header

Recommended Actions

Modify GTM HTTP Monitor with the following:


1. recv-status-code 301 200 302


2. modify recv string that is in http payload to blank

Additional Information

when recv-status-code is set, header is not validated, response body is validated
