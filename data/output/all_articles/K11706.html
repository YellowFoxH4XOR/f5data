Issue

Error Message

The username or password is not correct. Please try again. (error: no matching users found)

For example, you may see this error message syntax on the user log in page

Your session could not be established.
The session reference number:  <number>
The username or password is not correct. Please try again. (error: no matching users found)

Message Location

You may encounter this message in the following locations:

  • The /var/log/apm page
  • The user login page

Description

This message occurs when the following condition is met:

  • You are attempting to authenticate with a user account that may be inactive.

Impact

The user is unable to log in and the system displays the error message.

Recommended Actions

To resolve this issue, confirm that the user name that the user is supplying is an active account and ask the user to try again.

To further troubleshoot this issue, inspect the logs located in the /var/log/apm file. The error message on the users' log in page corresponds to the following error message syntax in the BIG-IP APM system logs:

Note: You can see the user name submitted in the sAMAccountName portion of this message.

LDAP module: authentication with '(sAMAccountName=<username that was submitted>)' failed in ldap_search_s(): no matching users found
