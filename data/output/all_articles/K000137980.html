Description

In the GUI, when trying to add a node as an address (IP address) in LTM Node list, it does not display the Reverse PTR record FQDN but instead does shows up as IP address in NAME and Address column.

Environment

  • BIG-IP LTM
  • IP address type node configured

Cause

Option 'Display Host Names' on 'GUI > System > Preferences > Display Host Names When Possible' is disabled.

Recommended Actions

On GUI:

  1. go to System --> Preferences
  2. check the 'Display Host Names When Possible' as enabled
  3. click update

None
