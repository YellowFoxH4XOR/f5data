Known Issue

Plug-in event errors may cause a Traffic Management Microkernel (TMM) processing loop.

This issue occurs when the following condition is met:

  • An enabled plug-in event encounters an error condition.

An issue in TMM's plug-in error handling may allow TMM to enter a processing loop when an error condition is encountered during a plug-in event.

Impact

TMM may produce a core file, and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • TMM consumes system resources, fails to answer an sod heartbeat, and produces a core file.
  • Messages similar to the following example are logged to the /var/log/tmm file:

    notice ** SIGABRT **
    notice sender pid: 6725 (unknown)
    notice fault code: 0x0
    notice fault time: Wed Sep 04 09:01:39 EDT 2013
    notice version: default x86_64 padc TMM Version 11.2.1.1148.0
    notice ticks since last clock update: 11838
    notice ticks since start of poll: 11438
    notice next heartbeat expiration in 461 ticks
    notice TMM aborted @ 1378299687.463926
