Topic

You should consider using this procedure under the following condition:

  • You want to bulk migrate multiple Secure Sockets Layer (SSL) certificates and keys to the BIG-IP system.

Description

The BIG-IP Configuration utility includes an option to bulk archive and import multiple SSL certificates and keys. The SSL certificates must be in PEM format, and the SSL certificates and keys must be archived in GZIP (.gz) format. After you archive the SSL certificates and keys, these items can then be bulk imported for use on the BIG-IP system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrative access to the Configuration utility.
  • Your SSL certificates are in PEM format.
  • You can access a file-archiving program that is compatible with the GZIP format.

Procedures

You can use the BIG-IP Configuration utility to archive and then import multiple SSL certificates and keys to the BIG-IP system. After you import these items, the SSL certificates and keys are available for use in SSL client and SSL server profiles on the BIG-IP system. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Archive the SSL certificates and keys
    • Use the Configuration utility
    • Create a tar file
  • Import the SSL certificates and keys

Archive the SSL certificates and keys

To archive the SSL certificates and keys, you can use either the Configuration utility or create a tar file.

Use the Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. Go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  3. Select Archive.
  4. For Archive File Name, enter an appropriate name. For example, enter:

    k15021

  5. For Key List, in the Available Keys list, select the keys you want to export and move them to the Keys to Archive list.

    Note: Your system may have Key List greyed out when you enable Common Criteria mode. To verify if Common Criteria is enabled on your system, enter tmsh list sys db security.commoncriteria.

  6. For Certificate List, in the Available Certificates list, select the certificates you want to migrate and move them to the Certificates to Archive list..
  7. Select Generate and Download Archive.
  8. Select Save to save the archive to your client's local storage.

Create a tar file

  1. Verify that the SSL certificates you want to archive are in PEM format. To do so, you can view the contents of the SSL certificate files, and verify that each file begins with -----BEGIN CERTIFICATE----- and ends with -----END CERTIFICATE-----:

    For example:

    big-ip# cat test1.crt

    -----BEGIN CERTIFICATE-----
    [Certificate data...]
    -----END CERTIFICATE-----

  2. Create two directories, ssl.crt and ssl.key, by entering the following commands.                                                   

    Note: Make sure to use lowercase letters.                                                                                                      

            mkdir ssl.crt
            mkdir ssl.key

  1. Copy your certificates and keys to ssl.crt and ssl.key, respectively.
  2. Create a GZIP archive of the directories that contain all SSL certificates and keys to be imported to the BIG-IP system.

    Using the tar utility on a BIG-IP system,  use the following syntax:

    tar -zcvf <filename.tar.gz> ssl.crt ssl.key

    For example, if you want to create an archive named k15021.tar.gz, enter the following command:

    tar -zcvf k15021.tar.gz ssl.crt ssl.key

  3. Copy the GZIP archive file to the local system that is used to access the Configuration utility.

Import the SSL certificate and keys

  1. Log in to the BIG-IP Configuration utility.
  2. Go to System > Certificate Management > Traffic Certificate Management > SSL Certificate List.
  3. Select Import.
  4. For Import Type, select Archive.
  5. Select Choose File.
  6. Go to the location of the GZIP archive file you created in the previous procedure, and select the file.
  7. Select Load.
  8. After selecting the file, select Load.
  9. Optional: Choose any SSL certificate and keys to exclude from the import by selecting and moving them to the Excluded Keys window.

    Note: If you do not observe some certificate files, you may need to rename them with the .crt extension before creating the GZIP archive in the previous procedure.

  10. Select Import.

    The SSL certificate and keys are imported and available for use in SSL client and SSL server profiles.
