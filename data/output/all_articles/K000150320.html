K000150320: Application deployed via BIG-IP FAST restore original configuration

Type
Support Solution
Published
2025-03-11
Updated
2025-03-11
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0
Source
https://my.f5.com/manage/s/article/K000150320

Description

FAST application configurations are reverted to their original declaration when a new FAST template deploy application with a "tenant" name that exists on the system.

Environment

Relevant environmental factors specific to the topic

  • BigIP
  • FAST Template
  • AS3(utilised by FAST)
  • Deployed Application is modified manually via TMSH or webui
  •  New Application deployment via FAST uses existing tenant name

Cause

New application deployment via FAST with a "tenant" name that exists on BIG-IP will cause all applications with the same "tenant" name to be overwritten with their original declaration.

 

Recommended Actions

  1.  This is an expected behavior, and its explained in the user guide under additional information.
  2. Use a unique tenant name for each application deployment using FAST as a workaround to avoid AS3 to modify configuration to the original declarative values.
