Topic

Before you can configure the BIG-IP DNS (formerly known as BIG-IP GTM) or Link Controller to process name resolution requests, you must define a listener object. You can define listener objects for local resolution (node mode) or listener objects for traffic forwarding (bridge or router mode).  How the modes are enabled differs according to what BIG-IP version you are running:

  • In BIG-IP 10.x and earlier, if the listener object matches a self IP address, then local BIND resolution is automatically enabled. If the listener object does not match a self IP address, local BIND resolution is disabled and query forwarding is enabled. If you define a listener object for local resolution and the listener does not match a self IP address, wide IP pools configured with the Return to DNS load balancing method will not return the desired results.
  • In BIG-IP 11.x and later, the Use BIND Server on BIG-IP option in the DNS profile dictates local BIND resolution. If the option is enabled on a listener object, it can answer from BIND. If the option is disabled, and the listener does not match a self IP address, then query forwarding is enabled. If the option is disabled and the listener object does match a self IP address, then neither BIND resolution nor forwarding is enabled, so queries that would have otherwise been handled by those methods are dropped.

Note: For more information about DNS query processing, refer to K14510: Overview of DNS query processing on BIG-IP systems.

Defining a listener object for local resolution means the listener directs name resolution requests to wide IP objects that are configured on the local BIG-IP DNS or Link Controller system (as opposed to forwarding requests to a separate DNS server on the network). F5 recommends that you define listener objects for local resolution differently depending on how the systems are configured. The following summarizes five possible configurations:

  • A standalone BIG-IP DNS or BIG-IP Link Controller system
  • A BIG-IP pair in which one unit is licensed for either the BIG-IP DNS or BIG-IP Link Controller software module
  • A BIG-IP pair in which both units licensed for either the BIG-IP DNS or BIG-IP Link Controller, and both units answer DNS queries regardless of the BIG-IP active-standby state
  • A BIG-IP pair in which both units licensed for the BIG-IP DNS or BIG-IP Link Controller and both units answer DNS queries in an active-active configuration
  • A BIG-IP pair in which both units licensed for either the BIG-IP DNS or BIG-IP Link Controller, and only the BIG-IP active unit responds to DNS queries

A standalone BIG-IP DNS or BIG-IP Link Controller system

On a standalone BIG-IP DNS or BIG-IP Link Controller system, you can configure a listener to use a self IP address or other IP address on which the system listens for connections.

A BIG-IP pair in which one unit is licensed for either the BIG-IP DNS or BIG-IP Link Controller software module

When a BIG-IP pair includes only one unit with either the BIG-IP DNS or BIG-IP Link Controller module, and you add a listener on the unit licensed for BIG-IP DNS or Link Controller, the listener must be configured to use a local IP address. For example, in this case the listener address can be configured as the non-floating self IP address or other local IP address on which the system listens for connections. This configuration ensures that only the unit with the licensed BIG-IP DNS or BIG-IP Link Controller module will receive DNS queries.

A BIG-IP pair in which both units are licensed with BIG-IP DNS or BIG-IP Link Controller and both units answer DNS queries regardless of the BIG-IP active-standby state

On each unit you can configure a listener to use the non-floating self IP address or other local IP address on which the system listens for connections. This configuration allows either unit to respond to DNS queries regardless of the BIG-IP active-standby state.

A BIG-IP pair in which both units are licensed for BIG-IP DNS or BIG-IP Link Controller and both units answer DNS queries in an active-active configuration

On each unit you can configure a listener to use the non-floating self IP address or other local IP address on which the system listens for connections. This configuration allows either unit to respond to DNS queries.

A BIG-IP pair in which both units are licensed for BIG-IP DNS or BIG-IP Link Controller, and only the BIG-IP active unit responds to DNS queries

On each unit, you can configure the listener to use either the floating self IP address or another floating IP address. This configuration ensures that the listener can be reached only on the current BIG-IP active unit.
