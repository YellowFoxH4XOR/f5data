Known Issue

The mcpd process may produce a core file when processing large queries.

This issue occurs when all of the following conditions are met:

  • You are performing a tmsh query that returns a large result.

    For example, you run the following command and it returns several million lines:

    tmsh show sys connection

  • You are performing an action in the Configuration utility that returns a large result.
  • The BIG-IP CPU is heavily loaded.

Impact

If the BIG-IP system is a member in a redundant configuration, traffic may fail over to the standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic may be interrupted.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The mcpd process produces a core file in the /shared/core directory with a date and timestamp corresponding to the mcpd failure.
  • In the /var/log/kern.log file, you observe an error message similar to the following example:

    info kernel: mcpd[7240]: segfault at ffffffff ip 0000000056298258 sp 00000000ff951fb0 error 4 in libmcpdcommon.so[55f4d000+652000]

  • When the mcpd process attempts to automatically restart, you observe an error message similar to the following example in the /var/log/ltm file:

    notice mcpd[6834]: 01071539:5: Mcpd is starting.
