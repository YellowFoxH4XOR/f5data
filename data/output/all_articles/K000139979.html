Description

When checking the virtual servers health using the Network Map, pool members added in the actions of a policy rule are not showing up in Network Map if there are nodes and pools named with the form "<IPv4>:<port>, even though you can still see the pool members in the command line

 

Environment

  • BIG-IP LTM
  • Network Map
  • Policy
  • Pool
  • Node

Cause

Bug ID 1223589

 

Recommended Actions

1. In this example the commented lines are nodes and pools named with the form "<IPv4>:<port> causing the issue, this can be found in /config/bigip.conf configuration file:

 

#ltm node /Common/10.10.10.10:53 {

ltm node /Common/10.10.10.10 {

address 10.10.10.10

}

#ltm node /Common/11.11.11.11:53 {

ltm node /Common/11.11.11.11 {

address 11.11.11.11

}

ltm pool /Common/dns_server_pool {

members {

# /Common/10.10.10.10:53:53 {

/Common/10.10.10.10:53 {

address 10.10.10.10

}

# /Common/11.11.11.11:53:53 {

/Common/11.11.11.11:53 {

address 11.11.11.11

}

}

}

 

2. After modifying the configuration, then load using the following command:

tmsh load sys config

 

3. Visit Network Map again, the problem should be resolved and Network Map will show pool members.
