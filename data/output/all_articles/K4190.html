Topic

Beginning in version 4.6.3, BIG-IP and 3-DNS support the HP Proliant DL380 server appliance.

Supported hardware options

BIG-IP and 3-DNS support the following HP Proliant DL380 server appliance hardware options:

Hardware optionSupport provided
Memory1GB - 12GB
Serial Ports1 standard DB-9 port
NICs2 Broadcom 5704 based Tri-speed NICs
USB Ports3
Video PortYes
PS2 KeyboardYes
PS2 MouseYes
CD-ROMYes
ASR-2 WatchdogYes
SCSI ControllersHP Smart Array 6i SCSI controller
HP Smart Array 5i SCSI controller

Unsupported hardware options

BIG-IP and 3-DNS do not support the following hardware options:

Xeon processor hyper-threading
Processor Hyper-Threading must be disabled in the BIOS.
Network PXE Installation
Network PXE installation is not supported on this platform. BIG-IP software must be installed from an attached CD-ROM.
Multi-Processor Support
Multiple processors are not supported on this platform. The platform will only use one processor.

 

Network interface card (NIC) names

The two installed LOM NC7782 NICs are named 1.1 (bge0) and 1.2 (bge1).

If you install additional NICs, they will be named as follows:

PCI card slotInterface numbers
PCI Slot 12.x
PCI Slot 23.x
PCI Slot 34.x

Power management features

You can shut down the HP Proliant DL380 system using one of the following methods:

  • Power button

    To shut down the system under normal circumstances, press the power button briefly.

    To turn the system off immediately, press the power button for more than 4 seconds.

  • Console

    To shut down the system from the console, type the following command:

    poweroff
