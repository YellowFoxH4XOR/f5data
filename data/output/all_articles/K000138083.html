K000138083: Does the BIG-IP admin GUI login page support Multi-factor authentication or Two-factor authentication?

Type
Support Solution
Published
2023-12-29
Updated
2023-12-29
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000138083

Description

This article clarifies that Two-Factor Authentication (or Multi-Factor Authentication, MFA) is not currently supported for the BIG-IP admin GUI login page.

 

Environment

  • BIG-IP

 

Cause

We do not currently support Two-Factor Authentication or Multi-Factor Authentication on the BIG-IP admin GUI login screen.

 

Recommended Actions

None

 

Additional Information

None
