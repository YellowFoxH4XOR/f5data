Description

You have the PSU on status down. You have unplugged an plugged but the state is still down. Other devices in the same rack are ok. What is the procedure to raise an RMA?

Environment

  • Suspected failed power supply.

Cause

Unknown

Recommended Actions

  1. Follow the troubleshooting issues in K52015891: Troubleshooting BIG-IP power supply issues
  2. If these do not resolve, generate a QKview from the host while faulty power supply is installed. K12878: Generating diagnostic data using the qkview utility
  3. Open a case with F5 support, include the QKview and your troubleshooting results.
