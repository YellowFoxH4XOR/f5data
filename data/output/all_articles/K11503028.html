Known Issue

You are unable to exit or quit the Always-On Management (AOM) menu during an AOM DHCP request.

This issue occurs when all of the following conditions are met:

  • You configure the AOM management IP address to use DHCP on one of the following platforms:
    • i2x00
    • i4x00
    • i5x00
    • i7x00
    • i10x00
    • Herculon i2x00
    • Herculon i5x00
    • Herculon i10x00 iSeries
  • The DHCP server that you are using for configuration is unavailable.

When you configure the AOM's management IP address using DHCP on iSeries platforms, the configuration screen does not correctly timeout and returns to the AOM menu if the DHCP server is unavailable.

Impact

The AOM menu becomes unresponsive, and serial console access is not available.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The AOM menu becomes unresponsive and continuously prints "......." to the screen.
  • Console access to the AOM menu or host by way of the serial console port no longer functions.

Resolution

Workaround

To work around this issue, you can prevent or recover from the issue by ensuring that the DHCP server is accessible. Alternatively, to recover from this issue, you can power cycle the BIG-IP system.

Impact of workaround: Ensuring that the DHCP server is accessible will not have a negative impact on your system. However, if you need to power cycle the system, the BIG-IP system temporarily fails to process traffic as it recovers from the restart, and devices configured as a high availability (HA) pair may fail over.
