K7044: BIG-IP SMTP monitor sends HELO before receiving a 220 Ready message

Published

Source

Topic

The BIG-IP SMTP monitor can send a HELO command before it receives a 220 Ready message from the SMTP server. Mail servers that adhere to RFC 821 - Simple Mail Transfer Protocol, can view this behavior as an SMTP violation and reject the connection. This causes the BIG-IP SMTP monitor to mark the node DOWN, because the connection was terminated and did not receive a 250 response.

Due to the simplicity of the SMTP monitor in its ability to quickly determine whether or not a mail server is responding, no changes can be made to alter the behavior of the monitor.

Some mail servers allow their behavior to be altered to accept a HELO before a 220 Ready banner is issued. Consult your mail server documentation if you are experiencing this issue with a mail server.
