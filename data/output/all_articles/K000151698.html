Description

Custom user role privileges cannot be created or modified directly on BIG-IP LTM systems. The platform only supports a fixed set of predefined user roles, and there is no option to define or manage custom roles or assign granular permissions to user accounts through the BIG-IP LTM interface.

Environment

  • BIG-IP
  • User management and role-based access control (RBAC) requirements

Cause

BIG-IP LTM is designed with a set of predefined user roles for access control. The system does not include functionality for creating, editing, or customizing user roles beyond those provided by default.

Recommendations

  • Use the available predefined user roles on BIG-IP LTM for managing user access.
  • For more granular or custom RBAC needs, utilize F5 BIG-IQ Centralized Management, which allows creation and assignment of custom user roles and permissions.
  • Consider using administrative partitions in combination with predefined roles to restrict users’ access to specific configuration objects within BIG-IP LTM.
  • Refer to official documentation for details about available predefined roles and their associated permissions.
