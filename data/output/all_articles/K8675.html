Note: For information about the pre-defined acceleration policies for WebAccelerator 5.x, refer to K7274: Default policies included with the WebAccelerator 5.x.

The BIG-IP WebAccelerator 9.4.x includes the following pre-defined acceleration policies:

  • BEA AquaLogic (Plumtree with Collaboration)  
  • BEA AquaLogic (Plumtree without Collaboration)  
  • BEA Weblogic  
  • Ecommerce  
  • Hyperion Financial  
  • IBM WebSphere  
  • Level 1 Delivery  
  • Level 2 Delivery  
  • Lotus Domino  
  • MatrixOne eMatrix  
  • Microsoft Internet Information Service (IIS)  
  • Microsoft Outlook Web Access (OWA) 2003  
  • Microsoft Outlook Web Access (OWA) 2007  
  • Microsoft Sharepoint Services 2003  
  • Microsoft Sharepoint Services 2007  
  • Oracle 11i  
  • Oracle JD Edwards ERP  
  • Oracle Peoplesoft  
  • Oracle Portal  
  • Oracle Siebel CRM  
  • Oracle - Peoplesoft 9 (versions 9.4.5 and later)
  • SAP Portal  
  • Symmetric Deployment
