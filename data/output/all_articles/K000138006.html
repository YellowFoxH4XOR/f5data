Recommended Actions

1.- Connect to the serial console of the BIG-IQ system.

2.- Reboot BIG-IQ system.

3.- While the BIG-IQ is restarting, you have a short time (by default, only a few seconds) to press a keyboard key to interrupt auto-boot. After the GNU GRUB menu appears, immediately press the down arrow key.

The following example shows MOS menu options:

  GNU GRUB version 0.97 (619K LOWER / 3653927K UPPER MEMORY)
 ******************************************************************
 * BIG-IQ 8.3.0 - drive sda.1           *
 * TMOS maintenance                     *
 *                                      *
 ******************************************************************
Select TMOS maintenance.
Press Enter.

4.- Run the following commands:

e2fsck -yf /dev/mapper/vg--db--vda-dat.share.1

resize2fs /dev/mapper/vg--db--vda-dat.share.1

reboot
