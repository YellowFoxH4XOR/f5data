Description

Even though DNS split tunnel is configured, the client sends all DNS queries to the DNS server(s) configured in Network Access resource without error messages in client logs. 

Environment

  • DNS Split tunneling 
  • "DNS Address Space" configured with corporate DNS suffixes
  • "Allow Local DNS Servers" checked
  • "Enforce DNS search order" unchecked
  • Windows 10
  • EdgeClient or Browser connection
  • BIG-IP v11.6.0HF6 or above
  • F5 DNS Relay Proxy service is v7110.2014.0807.1842

Cause

F5 DNS Relay Proxy service v7110.2014.0807.1842 (from BIG-IP v11.6.0) is not compatible with Windows 10 for DNS split tunnel.

Recommended Actions

Upgrade F5 DNS Relay Proxy service to v7110.2015.0815.0150 (from BIG-IP v11.6.0HF6) or later versions. 
Note: This may require uninstalling and re-installing of the Edge Client software
