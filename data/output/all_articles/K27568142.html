Known Issue

The BIG-IP ASM system device group full sync may continue to fail after an initial failure.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured as part of a device group that has Full Sync configured.
  • One of the following events happens when running a synchronization:
    • The /var hard drive partition becomes fully used.
    • The device experiences an out-of-memory error.
  • After addressing the initial synchronization error (hard drive or memory use), you attempt a subsequent device group full synchronization.

Impact

The device group full sync continues to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to run a full sync to the configured device group, the /var/log/ts/asm_config_server.log log file on the initiating device contains error messages similar to the following example:

    asm_config_server.pl|ERR|<date and time>|<pid>|F5::ASMConfig::Handler::SyncHandler::sync_send_ucs,,Could not save configuration to send full sync to <Device Name>: DBD::mysql::db do failed: File '/ts/var/sync/ts_db.save_dir_4056.cstmp/ts_db.data.DCC.ACCOUNT_SESSION_AWARENESS_SETTINGS.cstmp' already exists at /usr/local/share/perl5/F5/ConfigSync.pm line 476.

  • Memory used by BIG-IP ASM-related processes is significantly higher than normal memory used by the device.

Workaround

To work around this issue, you can delete the contents of the /ts/var/sync directory. To do so, perform one of the following procedures:

  • Correcting BIG-IP ASM synchronization 11.6.0 and later
  • Correcting BIG-IP ASM synchronization 11.5.4 - 11.3.0

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Correcting BIG-IP ASM synchronization 11.6.0 and later

  1. Log in to the command line of the affected device.
  2. Change directories to /ts/var/sync by typing the following command:

    cd /ts/var/sync

  3. To delete the contents of the /ts/var/sync directory, type the following command:

    rm -f /ts/var/sync/*

  4. Restart the asm_config_server.pl process by typing the following command:

    pkill -f asm_config_server

  5. Check that the asm_config_server.pl process has restarted by typing the following command:

    ps ax | grep asm_config_server.pl

  6. Repeat steps 1 through 5 on all peer devices.
  7. Initiate a device group full sync from the primary BIG-IP ASM device.

Correcting BIG-IP ASM synchronization 11.5.4 - 11.3.0

  1. Log in to the command line of the affected device.
  2. To delete the contents of the /ts/var/sync directory, type the following command:

    rm -f /ts/var/sync/*

  3. Restart the asm_config_server.pl process by typing the following command:

    /usr/share/ts/bin/kill_asm_config_server.pl

  4. Check that the asm_config_server.pl process has restarted by typing the following command:

    ps ax | grep asm_config_server.pl

  5. Initiate a device group full sync.
