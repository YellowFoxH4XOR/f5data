What Happened?

  • If "Not configured" or "Disable" is set in "More Options > Buffer Policy" in Load Balancer settings, is it the same behavior ?

Environment

  • HTTP Load Balancer
  • F5® Distributed Cloud

Resolution/Answer

  • Not Configured Buffer Policy buffers 0 bytes . Disabled buffer policy disables buffering . 
  • They are the same behavior.
