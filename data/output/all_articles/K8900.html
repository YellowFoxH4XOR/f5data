Topic

You can use administrative partitions to create user accounts with authorization to administer individual security policies on the BIG-IP ASM system. This functionality is useful if you want to create a user account to administer certain BIG-IP ASM security policies, but not others. For example, you can create a user account with authorization to edit web application A, but not web application B.

To create a BIG-IP ASM user account with authorization to administer certain security policies, but not others, perform the following procedures:

  • Creating a new administrative partition
  • Creating a new user account
  • Creating a new HTTP Class under the new partition
  • Creating the security policy using the new user account

Creating a new administrative partition

To create a new administrative partition, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click Users.
  4. Click the Partition List menu.
  5. Click Create.
  6. Type a name for the new partition.
  7. Click Finished.

Creating a new user account

To create a new user account, perform the following procedure:

  1. Click System.
  2. Click Users.
  3. Click the User List menu.
  4. Click Create.
  5. Type a name and password for the new user.
  6. Select Application Editor from the Role menu.

    Note: In some versions, user accounts with the Application Editor role have no access to the BIG-IP PSM system. For more information, refer to K11001: User accounts that have the Application Editor role have no access to the BIG-IP PSM system.

  7. Select the new partition that you created in the first procedure from the Partition Access drop-down menu.
  8. Click Finished.

Creating a new HTTP Class under the new partition

To create a new HTTP Class under the new partition, perform the following procedure:

  1. Select the new partition name that you created in the first procedure from the Partition drop-down menu.

    Note: The Partition drop-down menu is in the upper right corner of the Configuration utility.

  2. Click Application Security.
  3. Click Classes.
  4. Click Create.
  5. Type a name and complete the configuration for the new Class.
  6. Click Finished.

Creating the security policy using the new user account

To create the security policy using the new user account, perform the following procedure:

  1. Log in to the Configuration utility using the new user account.
  2. Click Application Security.
  3. Click Web Applications.
  4. Set the Language for the new security policy and configure the policy as required.
