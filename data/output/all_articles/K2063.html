Session ID (SID) reuse is defined between the client and the SSL proxy (the device that is decrypting the SSL). By default, the BIG-IP system allows SID reuse for up to 5 minutes. You can reconfigure the default with the global variable: sslproxy serverssl cache timeout.

Typically, Microsoft Internet Explorer (versions 4.0 and later) and Netscape default to a 2-minute session ID reuse timeout. This means that for the average client implementation, as defined by the browser vendor, a single session ID is good for approximately two minutes.

Note: The 2-minute session ID timeout for the browser is approximate and may vary from version to version. You can find more specific information about the session ID timeout in the Microsoft Knowledge Base: http://support.microsoft.com.
