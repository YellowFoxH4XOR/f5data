Topic

To mark the server as up, the following criteria must be met:

  • The 3-DNS Controller must receive an HTTP 200 OK message for the page indicated.
  • The HTTP 200 OK message must contain the required test for the health monitor, as defined in the wide IP, within the body of the HTTP 200 OK message.

If the 3-DNS Controller does not receive an HTTP 200 OK message, or the HTTP 200 OK message does not contain the required text, the virtual server will be marked as down.
