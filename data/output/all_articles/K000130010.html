Description

SNMP OID value should update in real time. If BIG-IP continuesly receive the SNMP requests (even for different SNMP OID), the OID value may cannot update in time.

For example:

BIG-IP receive the SNMP requests for the virtual server statistics.

BIG-IP receive the SNMP requests for other OID, huge number of SNMP requests.

BIG-IP receive the SNMP requests for the virtual server statistics again, but the value is not updated.

Environment

  • BIG-IP
  • SNMP

Cause

System is busy, has no chance to update the OID value.

 Recommended Actions

For the same OID, please limit the frequency, and make sure system has chance to update the value. 

Additional Information

SNMP is for the monitor usage, please avoid to configure too much SNMP requests which consume the system CPU resource.
