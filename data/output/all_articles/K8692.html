Topic

When a BIG-IP redundant pair includes one system licensed only for BIG-IP LTM, and the second system licensed for BIG-IP LTM and either the GTM or Link Controller module, the redundant pair will fail a ConfigSync operation to the first system licensed with only BIG-IP LTM. This behavior occurs if a listener object is defined at any virtual address.

The ConfigSync operation output contains an error message that appears similar to the following example:

BIGpipe: virtual server profile creation error:
     01020036:3: The requested profile (dns) was not found.

This output is expected behavior. The listener is defined as a shared configuration object when associated with a virtual address. Therefore, the listener object must be added at a static (non-floating) self IP address.

Note: For more information about choosing listener IP addresses, refer to K5427: Selecting BIG-IP GTM and Link Controller self IP addresses for local resolution listener objects.
