K8958: Enabling the Loose Initiation option within a FastL4 profile may result in connections failing to close

Known Issue

This is the result of a known issue. Enabling the Loose Initiation option within a FastL4 profile may result in the connection failing to close properly, and not being removed from the connection table until the idle timeout value is reached.

Note: The Loose Initiation option allows the BIG-IP to initialize a connection when any TCP packet is received, rather than requiring a SYN packet for connection initiation.

When this issue occurs, the BIG-IP system does not correctly update and track sequence numbers. This issue may prevent the BIG-IP system from recognizing the final ACK packet of a TCP close connection, which would cause the connection flow within the BIG-IP system to transition to a closed state. As a result, a larger number of connections coupled with a large idle timeout may cause a large number of idle connections. If the number of idle connections is large enough, the BIG-IP system may initiate its connection sweeper to remove the connection to allow new connections to be established.

F5 Networks Product Development tracked this issue as CR99306 and it was fixed in BIG-IP LTM version 9.4.6, and version 10.0.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

This issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, which has been issued for BIG-IP version 9.4.5, and in BIGIP-9.6.1-839.0-HF3, which has been issued for BIG-IP version 9.6.1. You may download these hotfixes or later versions of the hotfixes from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 Networks product hotfixes, refer to K6845: Managing F5 Networks product hotfixes.

Workaround

You can work around this issue by choosing one of the following two options:

  • Disable the Loose Initiation option and allow the Packet Velocity Accelerator (PVA) to handle the connections.
  • If enabling the Loose Initiation option is a requirement, F5 Networks recommends that you also enable the Loose Close option. This allows the BIG-IP system to close a loosely-initiated connection when the BIG-IP system receives the first FIN packet from either the client or the server.
