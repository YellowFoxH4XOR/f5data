K000137460: Traffic processed by the BIG-IP is arriving at server using self-ip floating address

Type
Support Solution
Published
2023-11-03
Updated
2023-11-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.X.X, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000137460

Description

Traffic being processed by an iRule enabled virtual server is being sent to the destination server using the floating enabled self IP of the BIG-IP system though SNAT is not enabled for the virtual server.

Environment

  • BIG-IP
  • iRule

Cause

The IRule contains the setting snat automap as part of the traffic processing.

Example:
when CLIENT_ACCEPTED {
      snat automap
}

Recommended Actions

Review your environment routing and server requirements to determine if the use of snat automap is needed for traffic processed by the iRule.

Additional Information

  • iRules > snat
