Known Issue

The Switch Over Daemon (SOD) process may log an Out of shmem error message.

Note: SOD manages the BIG-IP system's active or standby states, and also provides failover and restart capability.

Impact

Failover might not function fully or as expected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H497801 on the Diagnostics > Identified > Medium screen.
  • In the /var/log/ltm file, you observe an error message similar to the following example:

    err sod[9876]: 01140003:3: Out of shmem, increment amount' in /etc/ha_table/ha_table.conf

Workaround

To work around this issue, you can allocate additional memory to SOD. To do so, perform the following procedure:

Impact of workaround: This workaround requires you to reboot the system, and you should perform the procedure only during a scheduled maintenance period.

  1. Log in to the command line.
  2. Edit the /etc/ha_table/ha_table.conf file using the following vi editor file:

    vi /etc/ha_table/ha_table.conf

  3. Press the ESC key.
  4. Use the J key to move the cursor down to the ha segment path: /sod table pages: 2 line.

    Note: The K key moves the cursor up.

  5. Use the L key to move the cursor right, until you reach the number 2.

    Note: The H key moves the cursor left.

  6. Replace the number 2 with 4 by pressing the ESC key and then the r key. Type the number 4.

    The modified line should appear as follows:

    ha segment path: /sod table pages: 4

  7. Save the file by pressing the ESC key and then typing the following command:

    :wq!

  8. Reboot the BIG-IP system by typing the following command:

    reboot
