Issue

If you have not installed the ARX Cloud Extender S3 Connector, an ARX Cloud Extender agent fails to migrate files to an Amazon S3 cloud target, and the system logs error messages that appear similar to the following example to the C:\Program Files (x86)\F5 ARX CE Agent\console.log file:

2011-01-02 12:34:56.000 (GMT+01:00) an ERROR occurred at 2011-01-02 12:34:56.000 (GMT+01:00):
[0] ERR_DMCOMMSSSL_CONNECTION [] [10.10.20.1:54994] dmcommsssl.cpp:386
 [1] ERR_DMDISPATCHERSSL_FAILED [] [migrate win://filer1/C/Tier2_share/Docs%20F5/Data_Manager_Quick_Start.pdf to s3://filer1.domain.com/arx-ce-test/] dmdispatcherssl.cpp:347
  [2] ERR_DMAGENT_MIGRATE_FAILED [] dmagent.cpp:2419
   [3] ERR_DMAGENT_MIGRATEDATATODESTINATION_FAILED [ERR_ADD_NULL] [s3://filer1.domain.com/arx-ce-test/filer1_C/7F/DB/7FDB3845XE19C1L.mwi] dmagent.cpp:2694
    [4] ERR_DMSTREAMFACTORY_GETSTREAM_FAILED [] dmstreamfactory.cpp:383
     [5] ERR_DMSTREAMFACTORY_GETFRESHSTREAM_FAILED [ERR_ADD_SCHEME_NOT_SUPPORTED] [Scheme s3: not supported (perhaps a plugin is not correctly installed or is not properly licensed)] dmstreamfactory.cpp:434

Another indication that you have not installed the S3 Connector is when you do not see S3 configuration load messages in the console.log file immediately after the --- LOG STARTED --- message. In this case, the initial messages following the --- LOG STARTED --- message may appear similar to the following example:

 --- LOG STARTED ---
 F5 ARX CE Agent - Release 1.8.1.17
 Command Line is [-noconsole]
 log path is .
 config path is ./
 plugin path is ./plugins
 certificateFile is ./license.crt
 keyFile is ./pkey
 authFile is ./auth
 port is 4604
 migrationSupport is on
 logsize is 50
 logkeep is 10
 --- begin os info ---

To migrate to an Amazon S3 target you must install the ARX Cloud Extender S3 Connector on the filer. For ARX Cloud Extender S3 Connector installation instructions, refer to the Amazon Simple Storage Service (S3) section of the Supported Sources and Destinations chapter in the ARX Cloud Extender Administration Guide.

When you have installed the S3 Connector, the initial messages following the --- LOG STARTED --- message indicates that the s3.cfg configuration file is loaded, and the message may appear similar to the following example:

  --- LOG STARTED ---
 S3: reading configuration file [./s3.cfg] ...
 s3.socketTimeout=60 (default)
 s3.badNodeCacheCapacity=256 (default)
 s3.badNodeCacheTimeout=3600 (default)
 valid ARX Cloud Extender™ connector [amazons3.dll]:
 name [Amazon S3 (Simple Storage Services)/2006-03-01
