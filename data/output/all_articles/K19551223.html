Known Issue

Traffic policies may apply rules out of order.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a traffic policy that contains multiple rules.
  • At least one traffic policy rule is referenced with an ordinal value greater than 65536.

Impact

Unexpected traffic policy behavior may result in degraded performance or interruptions in traffic processing.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Traffic processed by the policy fails to follow the expected policy actions, and users do not receive the expected application content or a connection reset from the BIG-IP virtual server.
  • When using the Traffic Management Shell (tmsh) to view the traffic policy configuration, you observe rule ordinal values that exceed 65536.

Workaround

To work around this issue, you can use the tmsh utility to locate the affected rule and then use the Configuration utility to reorder the rule-assigned ordinal values. To do so, perform the following procedures:

  • Identifying rules with ordinal values greater than 65536
  • Modifying the affected rule set using the Configuration utility

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Identifying rules with ordinal values greater than 65536

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. View the traffic policy configuration by typing the following command:

    list /ltm policy

  3. Examine the command output for ordinal values that exceed 65536, and note the policy and rule name.

    Policy output should appear similar to the following example:

    ltm policy http_no_use_policy {
        requires { http }
        rules {
            abc_rule {
                ordinal 1
            }
            bad_cnn {
                actions {
                    0 {
                        http
                        enable
                    }
                }
                conditions {
                    0 {
                        http-host
                        host
                        contains
                        values { cnn.com }
                    }
                }
                ordinal 65590
            }
        }
        strategy first-match
    }

Modifying the affected rule set using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Policies > Policy List.
  3. Select the affected policy.

    Note: You should select the noted policy from step 3 of the previous procedure.

  4. In the Rules subsection, click Reorder.
  5. Select and drag the affected rules to update the sequence.
  6. Click Update.
