Description

When the BIG-IP uses NAT/SNAT for all IP addresses on it's Origin setting, outbound connection to the pool members (nodes/backend servers) will be the NATed IP address.

The pool members (nodes/backend servers) will not be able to see the real client IP address as it will see the NATed IP address on the BIG-IP.

To allow a specific group of pool members to view the real client IP address, NAT/SNAT has to be disabled for the specific Virtual Server (VS).

Environment

  • BIG-IP
  • NAT or SNAT is configured
  • SNAT's Origin is set to All IPv4 Addresses
  • NAT or SNAT's  VLAN / Tunnel Traffic is set to All
  • Virtual Server's Source Address Translation is None

Cause

None.

Recommended Actions

You will need disable NAT/SNAT on the pool associated with the Virtual Server.

  1. Login to the Configuration Terminal.
  2. Navigate to Local Traffic > Pools > Pool List.
  3. Click the Pool Name associate with the Virtual Server you want to disable NAT/SNAT.
  4. Change Configuration to Advanced.
  5. Change Allow SNAT to No.
  6. Change Allow NAT to No.
  7. Click Update.
Important: Once NAT/SNAT has been disabled, ensure that the pool server is able to return the traffic back to the BIG-IP. If the traffic returns to another gateway, this will cause an asymmetric routing issue. One way to avoid this is to configure the BIG-IP internal facing self IP as the pool server's gateway. 

Additional Information

When configuring a pool, you can specifically disable any secure network address translations (SNATs) or network address translations (NATs) for any connections that use that pool. By default, these settings are enabled. You can change this setting on an existing pool by displaying the Properties screen for that pool.

One case in which you might want to configure a pool to disable SNAT or NAT connections is when you want the pool to disable SNAT or NAT connections for a specific service. In this case, you could create a separate pool to handle all connections for that service, and then disable the SNAT or NAT for that pool.

Once SNAT and NAT has been disabled on the pool, you can check what IP address is the BIG-IP communicating with the pool using the command below.
tmsh show sys connection cs-server-addr <virtual server IP address>

If the the Virtual Server IP is 192.168.1.1, the command would be:
tmsh show sys connection cs-server-addr 192.168.1.1
