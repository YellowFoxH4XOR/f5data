Issue

In FirePass 6.0.2 and earlier, FirePass did not support Terminal Server favorites for Mac OS X client systems.

Starting in FirePass 6.0.3, FirePass supports Microsoft Terminal Server and Citrix MetaFrame Java Terminal Server favorites for Mac OS X client systems. You can configure Java Terminal Servers favorites on the Application Access: Terminal Servers: Resources page in the FirePass Administrative Console. When configuring a Terminal Server favorite, select the Java client check box to support Mac OS X clients.

Note: Some features are not available in the Java Terminal Servers clients. For more information, select the Help link in the top right corner of the Application Access: Terminal Servers: Resources page.

Note: For information about which versions of Mac OS X are supported, refer to the FirePass Controller Client Compatibility Matrix for your version of FirePass software.

F5 Product Development tracked this enhancement as CR90844 and CR94199 and it was included in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.
