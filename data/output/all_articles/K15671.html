Topic

BIG-IP DNS must have a BIG-IP system server defined to represent the BIG-IP DNS system. The server definition must contain at least one local self IP address.

Description

When defining BIG-IP system servers, the BIG-IP DNS system allows the definition of remote servers without defining the local BIG-IP DNS system. When the configuration has no definition for the BIG-IP DNS system, monitoring remote resources, such as servers, virtual servers, or generic hosts, will fail because the gtmd process has no local address from which to source monitor connection attempts.

When initially configuring the BIG-IP DNS system, you must define the following elements:

  • A data center
  • A BIG-IP system server object for each BIG-IP DNS system that contains at least one local self IP address
