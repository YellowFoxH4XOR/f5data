Topic

To configure LDAP remote authentication with Microsoft Active Directory, perform the following procedure

  1. Log in to the command line.
  2. Run the setup utility by typing the following command:

    config

  3. Select option C: Remote Authentication.
  4. Select LDAP for the remote server type.
  5. Enter your Base Distinguished Name information.

    For example:

    CN=users,DC=askf5,DC=com

  6. Enter the Bind username.
  7. Enter the password for that username.
  8. Change the directory to /config/bigconfig by typing the following command:

    cd /config/bigconfig

  9. Using a text editor, edit the httpd.conf file.
  10. Locate the line that contains AuthLD PCompareCase on.
  11. Change AuthLDAPCompareCase on to AuthLDAPCompareCase off.
  12. Immediately after the line containing AuthLDAPCompareCase off, add the following new line, using the information appropriate for your specific network:

    AuthLDAPBindDN CN=<account>,CN=<your_base_DN_info>,DC=<your_base_DN_info>,DC=<your_base_DN_info>

    Where:

    • <account> is the name of an LDAP user that has sufficient rights to bind to the Active Directory server and perform reads and searches.
    • <your_base_DN-info> is the same as the one you entered in Step 5.

    For example:

    AuthLDAPBindDN CN=administrator,CN=users,DC=askf5,DC=com

  13. Immediately after the line you added in Step 12, add the following line where <password> is the password for the account that you created in Step 12:

    AuthLDAPBindPassword <password>

    For example:

    AuthLDAPBindPassword 3xAmp1e!

  14. Locate the line that contains AuthLDAPUrl ldap:.
  15. Change the line that contains AuthLDAPUrl ldap: to appear as follows, using the information appropriate for your specific network:

    AuthLDAPUrl ldap://<LDAP Server IP Address>/<Your Base DN Information>?samaccountname??

    For example:

    AuthLDAPUrl ldap://172.16.101.51/CN=users,DC=askf5,DC=com?samaccountname??

  16. Save the file and exit.
  17. Restart the httpd processes by typing the following command:

    bigstart restart httpd

  18. Verify that the httpd processes started by typing the following command:

    bigstart status httpd

    The output should appear as follows:

    status httpd: (pid X) running

    If this is not the result, check Steps 10 through 15 for errors.

Configuration example

Following is a configuration example. Your configuration will vary based on your specific Microsoft Active Directory settings.

AuthLDAPIgnoreTLSError on
AuthLDAPAuthoritative on
AuthLDAPCompareCase off
AuthLDAPUrl ldap://172.16.101.51/CN=users,DC=askf5,DC=com?samaccountname??
AuthLDAPBindDN CN=administrator,CN=users,DC=askf5,DC=com
AuthLDAPBindPassword 3xAmp1e!
AuthLDAPNonAuthoritativeUser root admin
AuthLDAP2Url ldap://localhost/ou=People,dc=askf5,dc=com???(!(disable=TRUE))
AuthLDAP2Authoritative on
AuthLDAP2CompareCase on
AuthType Basic
AuthName "BIG-IP"
