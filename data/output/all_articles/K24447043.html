Known Issue

The BIG-IP system uses an incorrect source media access control (MAC) address for host traffic whose vlangroup had a TCP RST.

This issue occurs when the following condition is met:

  • BIG-IP system traffic is exiting by way of Virtual Local Area Networks (VLANs) in a VLAN group.

Impact

A TCP RST occurs for traffic that exits the BIG-IP system with an incorrect source MAC address; this could include monitor traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP outbound host TCP RST packets have an incorrect source MAC address.

Workaround

To work around this issue, you can use transparent mode on the VLAN group.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
