K000136120: Unable to ssh to command line interface (CLI)

Type
Support Solution
Published
2023-09-07
Updated
2023-09-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 17.1.0
Source
https://my.f5.com/manage/s/article/K000136120

Description

You are using 3rd party software which is using SSH-RSA as host key algorithm key to set SSH connection, and connection is failing after upgrade to version 17.1.0.X.
It's expected behavior, F5 removed support for the SSH-RSA as part of the fix of Bug ID1238693 .


Environment

  • BIG IP v17.1.0.1
  • BIG IP v17.1.0.2
Cause
Unknown at time of publication

 Recommended Actions

 1. Reconfigure your 3rd party software with the host key algorithms listed below to support what is being sent by the BIG-IP:
 

17.1.0
debug2: peer server KEXINIT proposal
debug2: KEX algorithms: ecdh-sha2-nistp256,ecdh-sha2-nistp384,diffie-hellman-group14-sha1,diffie-hellman-group-exchange-sha1
debug2: host key algorithms: ssh-rsa,rsa-sha2-512,rsa-sha2-256,ecdsa-sha2-nistp256,ssh-ed25519

 

17.1.0.1
debug2: peer server KEXINIT proposal
debug2: KEX algorithms: ecdh-sha2-nistp256,ecdh-sha2-nistp384,diffie-hellman-group14-sha1,diffie-hellman-group-exchange-sha1
debug2: host key algorithms: rsa-sha2-512,rsa-sha2-256,ecdsa-sha2-nistp256,ssh-ed25519

 

17.1.0.2
debug2: peer server KEXINIT proposal
debug2: KEX algorithms: ecdh-sha2-nistp256,ecdh-sha2-nistp384,diffie-hellman-group14-sha1,diffie-hellman-group-exchange-sha1
debug2: host key algorithms: rsa-sha2-512,rsa-sha2-256,ecdsa-sha2-nistp256,ssh-ed25519
