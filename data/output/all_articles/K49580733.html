Description

You want to temporarily reduce the size of TMM memory in order to easily test features such as adaptive connection reaping.

However, you don't want to change Provision or VE memory size.

Environment

  • BIG-IP LTM

Cause

None

Recommended Actions

Complete the following steps:

1. Change tmm memory size using db key below 

    tmsh modify sys db tmm.devel.max_memory_mb value <value>

    For example:
    Reduce the memory allocated for TMM (e.g. 2 GB)
    tmsh modify sys db tmm.devel.max_memory_mb value 2048
    bigstart restart tmm 
 

2. Reset the db key once your tests are verified

    tmsh modify sys db tmm.devel.max_memory_mb reset-to-default
    bigstart restart tmm

Important: Please perform these Recommended Actions in test environment. Restarting TMM process will interrupt traffic processing on the BIG-IP system.

Important: The memory that is no longer used by the smaller TMM process is not available for anything else.  Memory reprovisioning can free and break up TMM huge pages into host (4KB page) memory. This means this procedure is only suitable for testing behaviour of a smaller TMM and not as a substitute for full memory reprovisioning - such as use of the sys db provision.extramb variable.
