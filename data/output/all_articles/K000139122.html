K000139122: BIG-IP tenant booted in FORCED OFFLINE mode is not able to authenticate with LDAP server

Type
Support Solution
Published
2024-03-31
Updated
2025-02-07
Applies to
  • BIG-IP
  • F5OS
Source
https://my.f5.com/manage/s/article/K000139122

Description

When putting BIG-IP tenant under FORCED OFFLINE and reboot it, the device will not be able to authenticate with remote authentication server upon booting up.


Environment

rSeries platform

BIG-IP tenant under F5OS


Cause

The issue is due to current unfixed bugs ID1291121 and ID1301897


Recommended Actions

There's no fix available at the time this article is created. Monitor the links under Related Content for progress.
