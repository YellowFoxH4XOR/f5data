Known Issue

The show fastpath resources command will only display details for the first fastpath processor.

This issue occurs when the following condition is met:

  • The platform is an ARX 1500 or ARX 2500.

Impact

Cosmetic

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The show fastpath resources command will only display details for the 1.3 fastpath processor.

Workaround

To work around this issue, you can specify the fastpath processor to display by using the show fastpath resources command. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the ARX CLI.
  2. Display the fastpath processor details by using the following command syntax:

    show fastpath resources <slot.proc>

    For example, display details for the 1.4 fastpath processor by typing the following command:

    show fastpath resources 1.4
