Topic

You should consider using this procedure under the following conditions:

  • The BIG-IP system is handling large SSL certificates that may exhaust the default SSL handshake buffer memory size of 32 KB.
  • Client SSL connections are failing and in the /var/log/ltm file you may observe error messages similar to the following example:

    err tmm1[17511]: 01230140:3: RST sent from 10.10.10.1:80 to 10.10.10.2:57521, [0x1b5adb9:2003] {peer} SSL error (handshake_failure(40))
    err tmm1[17511]: 01230140:3: RST sent from 10.10.10.3:47290 to 10.10.10.4:443, [0x1b5adb9:2003] SSL error (handshake_failure(40))
    err tmm3[13206]: 01230140:3: RST sent from 10.10.10.1:80 to 10.10.10.2:35317, [0x18dda11:1656] {peer} SSL error (record_overflow(22))
    err tmm3[13206]: 01230140:3: RST sent from 10.10.10.3:34290 to 10.10.10.4:443, [0x18dda11:1656] SSL error (record_overflow(22))

Description

Under certain conditions, you may need to increase the default 32 KB size of the SSL handshake buffer on the BIG-IP system. In most cases, this is due to large SSL certificates that are exhausting the SSL handshake buffer. Starting in BIG-IP 11.4.0, the size of the SSL handshake buffer is configurable. Refer to the following procedure for instructions on how to increase the size of the SSL handshake buffer on the BIG-IP system.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have access to the BIG-IP Traffic Management Shell (tmsh).

Procedures

Increasing the size of the SSL handshake buffer

Impact of procedure: The impact of the suggested procedure depends on the specific environment. F5 recommends that you test any such changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To list the current size of the SSL handshake buffer, type the following command:

    list sys db tmm.ssl.maxhandshakesize

    The size of the SSL Hanshake buffer is displayed, as in the following example:

    sys db tmm.ssl.maxhandshakesize {
        value "32768"
    }

  3. To increase the size of the SSL Handshake buffer, use the following command syntax:

    modify sys db tmm.ssl.maxhandshakesize value <value>

    In the previous syntax, <value> is the number of bytes of memory to allocate.

    For example, to double the size of the SSL handshake buffer from the default value of 32768, type the following command:

    modify sys db tmm.ssl.maxhandshakesize value 65536

    [root@march247:Active:Standalone] config # tmsh list sys db tmm.ssl.maxhandshakesize
    sys db tmm.ssl.maxhandshakesize {
        value "65536"
    }

  4. Save the change by typing the following command:

    save /sys config
