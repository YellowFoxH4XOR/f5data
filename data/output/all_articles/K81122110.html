Description

Need to configure ASM/AWAF to send uploads to an ICAP server.

What ICAP messages does ASM/AWAF send out, and what does it expect back?

Environment

  • ASM/AWAF ICAP

Cause

None

Recommended Actions

None

Additional Information

ASM/AWAF uses REQMOD mode for ICAP, as described in the ICAP RFC:

  • RFC 3507 - Internet Content Adaptation Protocol (ICAP)

The full request is sent (if applicable to be sent, see K70941653), encapsulated within an ICAP request, using the REQMOD method.

Here is an example request showing the ICAP request line and headers:

REQMOD icap://10.10.10.1:1344/av-url ICAP/1.0
Host: 10.10.10.1:1344
Date: Thu 15 Apr 2021 15:07:50 GMT
Allow: 204
Connection: keep-alive
X-Client-IP: 10.10.30.1
Encapsulated: req-hdr=0, req-body=1718

<..HTTP request follows..>

The RFC also has several examples. Section 4.8.2 lists general requirements for ICAP responses.

ASM/AWAF should be configured according to K70941653. Ensure the virus_header_name parameter is the name of the header which indicates a virus was detected.

ASM/AWAF does not detect a virus if the "virus detected" response is part of the response status line, instead of the headers. Some ICAP servers are known to send such messages, in which case the iRule in bug tracker entry ID 695394 may be used, along with configuring virus_header_name with a value of X-Virus-ID.
