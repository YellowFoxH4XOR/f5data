Known Issue

The BIG-IP APM websso daemon may restart when processing log messages.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system to provide authentication using single sign-on (SSO).
  • Memory corruption occurs in the websso daemon while processing a log message.

Impact

The BIG-IP APM system is unable to provide SSO authentication services while the websso daemon restarts. 

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system generates a websso core file to the /shared/core/ directory.
  • Users are unable to authentication using SSO methods.
  • In the /var/log/daemon.log file, you observe messages similar to the following example:

    emerg logger: Re-starting websso
