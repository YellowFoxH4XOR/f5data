K000141117: Cannot add members to pool that contains "xsl" in name via GUI

Type
Support Solution
Published
2024-09-24
Updated
2024-09-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10, 17.1.1
Source
https://my.f5.com/manage/s/article/K000141117

Description

This article describes issue when you try to add members to pool that contains "xsl" in the name via GUI and encounter blank page:

It's possible to add members to pool via tmsh.

Environment

  • BIG-IP
  • Pools/Pool members

Cause

webui.log with tomcat debug indicates that, when trying to add pool member to xsl pool there are no SQL statements related to pool_member. 

Recommended Actions

Don't use "xsl" in the name of pool or if it's already in use you can add pool members by using tmsh.
