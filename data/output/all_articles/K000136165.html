Source

Description

After deploying an application to a BIG-IP Next instance using Central Manager, the application will not pass traffic

Environment

  • A BIG-IP Next instance is managed by Central Manager
  • An application has been deployed to the instance
  • The web servers corresponding to the application endpoints have been confirmed to be up
  • You are able to ping the SelfIP address of BIG-IP Next
  • You are not able to ping the Virtual Address of the application.

Cause

BIG-IP Next is not licensed. 

Recommended Actions

  1. Follow the instructions for licensing a BIG-IP Next instance from Central Manager.

Additional Information

None
