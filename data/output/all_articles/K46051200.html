Topic

You should consider using this procedure under the following condition:

  • You want to install a hotfix on an Enterprise Manager 3.x system.
  • You want to remove a hotfix build from an Enterprise Manager 3.x system.

Description

F5 periodically releases cumulative hotfixes that contain fixes for software defects that may need to be addressed between minor or maintenance Enterprise Manager software releases. You can download cumulative hotfixes from the F5 Downloads site.

Note: This article does not address engineering hotfixes, which are provided only through a support case. For information about managing engineering hotfixes, and whether a specific engineering hotfix is included in the next cumulative hotfix, contact F5 Technical Support and reference the appropriate case number.

When installing a hotfix, you must run the hotfix installation from an active boot location and specify an inactive boot location as the target install location. This behavior allows you to prepare an inactive boot location, in advance, by installing the necessary software image and hotfix, and then boot to the new location when you are ready to run the configuration.

For example, if the Enterprise Manager system is running 3.1.1 on the active boot location (for example, HD1.1), and you want to install HF5, prepare an inactive boot location for the installation (for example, HD1.2). If the inactive boot location is running an older software version, such as 3.1.0, you must first install the base version 3.1.1 ISO image to the inactive boot location, and then install HF5. The configuration and license from the current boot location is copied to the target installation location. During the maintenance window, you can then designate HD1.2 as the active boot location and boot the system to it. If you need to revert to the previous hotfix version, you can boot to the former-active boot location that contains the hotfix (HD1.1 in this example).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Your Enterprise Manager system runs 3.x software.
  • Your Enterprise Manager system must have the appropriate 3.x base image in its software repository.

Procedures

  • Downloading the hotfix files
  • Importing the hotfix image to the Enterprise Manager
  • Verifying the MD5 checksum of the hotfix image
  • Installing a hotfix image
  • Changing the active boot location on the Enterprise Manager system
  • Reverting to a previous hotfix version or base software build

Downloading the hotfix files

When preparing to install a hotfix image on the Enterprise Manager system, F5 recommends that you download the following three types of files for each hotfix:

  • ISO files

    Enterprise Manager hotfix files are ISO archive files. For example, an Enterprise Manager hotfix file may appear similar to the following example:

    Hotfix-EM-3.1.1-68.0-HF4.iso

  • MD5 files

    The ISO installation file has a corresponding MD5 file for checking the integrity of the ISO file. For example, an Enterprise Manager hotfix MD5 file may appear similar to the following example:

    Hotfix-EM-3.1.1-68.0-HF4.iso.md5

  • Hotfix release notes

    The ISO installation file has a corresponding hotfix release note. You should always read the hotfix release note before you install a hotfix. This file contains important notes about each particular hotfix. For example, an Enterprise Manager 3.1.1 hotfix release note file may appear similar to the following example:

    Hotfix-EM-3.1.1-68.0-HF4.readme

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Using your workstation browser, access the F5 Downloads site.

    Note: For information about downloading files from the F5 Downloads site, refer to K167: Downloading software and firmware from F5.

  2. Locate the appropriate hotfix.
  3. Download the hotfix ISO, MD5 files to your local workstation.

Importing the hotfix image to the Enterprise Manager

After the hotfix and MD5 files are downloaded to your local workstation, you can use the Hotfix Image List page (Enterprise Management > Repository > Hotfix Image List) in the Configuration utility to import the files to the Enterprise Manager system. Importing the hotfix image file will automatically install the hotfix image file to the software repository on the Enterprise Manager system.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Enterprise Manager Configuration utility.
  2. Navigate to Enterprise Management > Repository > Hotfix Image List.
  3. Click Import.
  4. Navigate to the location on your local drive where the hotfix ISO file reside.
  5. Select the hotfix ISO file and click Import.
  6. Wait for the import process to complete.

Verifying the MD5 checksum of the hotfix image

After the hotfix image is imported to the Enterprise Manager system, and before you perform the installation, F5 recommends that you test the integrity of the hotfix image file to ensure file quality. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Enterprise Manager Configuration utility.
  2. Navigate to Enterprise Management > Repository > Hotfix Image List.
  3. Click on the name of the hotfix image.
  4. Locate the MD5 Checksum field and note the MD5 checksum for this hotfix image.
  5. On your local workstation, open the MD5 file you have downloaded in the previous procedure.
  6. Compare the MD5 checksums from both sources; if they match, the integrity of the imported hotfix image file is preserved and can be used for installation in the next procedure. If they do not match, you must delete the imported hotfix image file, import the hotfix image file using the previous procedure, and verify the MD5 checksum again.

Installing a hotfix image

After you have verified the MD5 checksum for the hotfix image, you can use the Configuration utility to install an Enterprise Manager hotfix. To do so, perform the following procedure:

Impact of procedure: Depending on the options you choose, your device may reboot and disrupt any process that is currently running such as scheduled backups.

  1. Log in to the Enterprise Manager Configuration utility.
  2. Navigate to Enterprise Management > Tasks > Task List.
  3. Click New Task.
  4. Select Copy and Install Software and Hotfix Images from the Software Installation section.
  5. To proceed to Step 1: Image and Device Selection, click Next >>. 
  6. Select the desired Enterprise Manager base image from the Software Image setting.

    For example:

    EM v3.1.1 (Build 40.0)

  7. Select the desired Enterprise Manager hotfix image from the Hotfix Image setting.

    For example:

    HF5 (Build 105.0)

  8. Select Copy and Install Image(s) from the Task Type setting.
  9. Select *All Devices from the Device List setting.
  10. Select Compatible with Software Image from the Device Filter setting; this should populate the Compatible Devices section with the list of Enterprise Managers that can be installed with the selected software/hotfix image.
  11. Check the desired Enterprise Manager from the list of devices in the Compatible Devices section.
  12. To proceed to Step 2 of 3: Task Options, click Next >>. 
  13. Select the options for the Configuration, Post-Install Run Location, Configuration Archive and Device Error Behavior settings as desired.

    Note: If you select Continue running on current location for the Post-Install Run Location setting, you must proceed on to the next procedure to boot to the newly installed location when desired. If you select Reboot to install location for the Post-Install Run Location setting, the system will automatically reboot itself to the newly installed location after successfully installing the hotfix image.

  14. To proceed to Step 3 of 3: Task Review, click Next >>. 
  15. Review your selected settings and click Start Task when you are ready to proceed the installation.
  16. Wait for the installation to complete.

Changing the active boot location on the Enterprise Manager system

If you have not selected to reboot the Enterprise Manager system to the newly installed location in the previous procedure, you can do so after the previous task has completed successfully by changing the active boot location on the Enterprise Manager system. To do so, perform the following procedure:

Impact of procedure: Your device will reboot and disrupt any process that is currently running such as scheduled backups.

  1. Log in to the Enterprise Manager Configuration utility.
  2. Navigate to System > File System Management > Boot Locations.
  3. Click the desired boot location that you would like to activate.
  4. Click Activate.
  5. Wait for the system to completely boot up to the selected boot location.

Reverting to a previous hotfix version or base software build

If you need to revert to the previous hotfix version, you can boot to the formerly active boot location that contains the previous hotfix installation.

If you need to remove a hotfix installation, you must restore the Enterprise Manager base build on the boot location by performing the Installing a hotfix image procedure previously described in this article. For example, if the Enterprise Manager system runs 3.1.1 HF5 on HD1.2, and you want to remove the hotfix, you must back up the configuration, change to a different boot location (for example, HD1.1), and then reinstall the base 3.1.1 build on HD1.2.
