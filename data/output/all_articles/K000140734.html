K000140734: 500 Internal Server Error when attempting to add vSphere as a Provider

Type
Support Solution
Published
2024-08-17
Updated
2025-09-02
Status
Legacy Content
Applies to
  • BIG-IP Next
  • BIG-IP Next LTM: 20.2.0
Source
https://my.f5.com/manage/s/article/K000140734

Description

When attempting to add an Instance using vSphere provider a 500 internal error message is received after doing a successful Connect.

Environment

Big-IP Next

vSphere Next Instance Provider

Cause

No Content Library for F5 on the vSphere Instance

Recommended Actions

Configure an appropriate Content Library with at least one F5 BIG-IP Next template image. Essentially the steps in Create BIG-IP Next instance template on VMware must be completed before you can attempt to utilize the vSphere environment as a provider for these Next images (even if you can successfully login to the vSphere environment, it will fail when trying to gather information about the content library/templates)
