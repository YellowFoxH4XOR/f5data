Description

This article provides an overview of different options available to configure pool member discovery on BIG-IP VM running in AWS. With pool member discovery configured, as new application server instances launch in AWS, they are automatically added to the BIG-IP pool based on predefined criteria. This is a convenient feature as it eliminates the need to manually add application server instances to BIG-IP pool.

There are three options to configure pool member discovery on BIG-IP in AWS:
  1. Use f5-iAppLX-aws-autoscale iApp. This iApp relies on AWS Auto Scaling service which automatically launches or terminates application servers based on predefined thresholds specified in AWS CloudWatch alarms. When configuring f5-iAppLX-aws-autoscale iApp on BIG-IP, one need to specify name of the AWS Auto Scaling group as well as pool name on BIG-IP to which auto scaled application servers will be added. Details: https://clouddocs.f5.com/cloud/public/v1/aws/AWS_autoscaling.html#auto-scaling-application-servers-in-aws
     
  2. Use Service Discovery iApp. This iApp is designed to provide service discovery within different cloud environments (including AWS) and is only intended to be installed from F5 cloud templates found in f5-aws-cloud-formation, f5-azure-arm-templates, etc. It is possible to install this iApp manually (outside of a deployment made from one of F5 cloud templates) however this is not supported and not recommended. Details:
    https://github.com/F5Networks/f5-cloud-iapps/tree/master/f5-service-discovery
     
  3. Use AS3 Service Discovery. AS3 v3.3.0 introduced the ability to use F5’s service discovery feature for Amazon Web Services (AWS) and Google Cloud Platform. AS3 v3.4.0 added service discovery for Microsoft Azure. Details: https://clouddocs.f5.com/products/extensions/f5-appsvcs-extension/latest/userguide/service-discovery.html

Environment

BIG-IP VM running in AWS.

Cause

None

Recommended Actions

F5-iAppLX-aws-autoscale iApp and Service Discovery iApp are considered deprecated (technical support is no longer provided in case of any issues with these two iApps). It’s recommended to use AS3 Service Discovery instead.
