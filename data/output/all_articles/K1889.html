Topic

The BIG-IP globalStatNoHandlerDeny OID is a counter that increments each time BIG-IP finds a packet that meets all of the following conditions:

  • The packet is not part of a current connection in the connection table.
  • The packet is not a SYN that is meant to establish a new connection.
  • The packet has L2/L3 forwarding disabled.

For example, if BIG-IP receives a packet that does not match an object on the network (such as a virtual server or a SNAT) and L2/L3 forwarding is disabled, then BIG-IP will deny the packet because it does not contain an appropriate user-specified handler. This packet denial will increment the globalStatNoHandlerDeny counter.

Note: If L2 or L3 forwarding is enabled, the globalStatNoHandlerDeny counter is not incremented, because BIG-IP accepts and forwards the packet regardless of state, much like a router would.
