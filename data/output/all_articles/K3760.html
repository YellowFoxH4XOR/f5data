Topic

You should consider using this procedure under the following condition:

  • You want to enable secure network address translations (SNATs) to forward other IP protocols, in addition to TCP and User Datagram Protocol (UDP) traffic.

Description

By default, SNATs forward only TCP and UDP traffic. Other IP traffic, such as Internet Control Message Protocol (ICMP) traffic, is dropped. You can configure SNATs to forward any IP packets by modifying the SNAT Packet Forwarding setting. To do so, perform one of the following procedures.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP system.

Procedures

Using the Configuration utility to enable the Any IP option

Impact of procedure: After performing this procedure, SNAT objects will pass all IP protocols.

  1. Log in to the Configuration utility.
  2. Navigate to System > Configuration > Local Traffic > General.
  3. From the SNAT Packet Forwarding menu, select All Traffic.
  4. Click Update.

Using the tmsh utility to enable the Any IP option

Impact of procedure: After performing this procedure, SNAT objects will pass all IP protocols.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Enable the Any IP option for SNATs by typing the following command:

    modify sys db snat.anyipprotocol value enable

  3. Save the configuration by typing the following command:

    save sys config
