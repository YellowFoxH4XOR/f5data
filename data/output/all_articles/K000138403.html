K000138403: Installing additional packages with unprivileged Nginx Plus Installation

Type
Support Solution
Published
2024-01-30
Updated
2025-02-07
Applies to
  • NGINX Products
  • NGINX Plus
Source
https://my.f5.com/manage/s/article/K000138403

Description

  • You performed unprivileged Nginx Plus Installation in a custom directory following article NGINX Plus Unprivileged Installation
  • You want to install additional modules with the above Nginx Installation
  • You want to know how to install these additional packages

Environment

  • Nginx Plus
  • NGINX Plus Unprivileged Installation

Cause

  • None

Recommended Actions

  • Install additional modules using same script used to install Nginx in unprivileged mode
./ngxunprivinst.sh install [-y] -p <path> <file1.rpm> <file2.rpm>

Additional Information

  • None
