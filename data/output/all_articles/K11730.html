Topic

If a user logs into the BIG-IP command line and uses the df (disk free) command to display information about free disk space, the output may indicate that the /dev/mprov/tmm device is full or nearly full.

For example, the following ouput from the df -h command shows the /dev/mprov/tmm device at 100 percent usage:

Filesystem            Size  Used Avail Use% Mounted on
/dev/vg-db-hdc/set.1.root
                      248M   55M  181M  24% /
/dev/vg-db-hdc/set.1._config
                      496M  9.1M  462M   2% /config
/dev/vg-db-hdc/set.1._usr
                     1008M  576M  382M  61% /usr
/dev/vg-db-hdc/set.1._var
                      3.2G  101M  3.0G   4% /var
/dev/vg-db-hdc/dat.share.1
                       30G  1.3G   27G   5% /shared
/dev/vg-db-hdc/dat.log.1
                      6.9G   33M  6.6G   1% /var/log
none                  2.0G  312K  2.0G   1% /dev/shm
none                  2.0G  6.4M  2.0G   1% /var/tmstat
prompt                4.0M  4.0K  4.0M   1% /var/prompt
none                  2.0G  1.6M  2.0G   1% /var/tmpfs
none                  3.2G  3.2G   10M 100% /dev/mprov/tmm

This behavior is normal on F5 systems. The /dev/mprov/tmm device is a virtual memory mount used exclusively by the Traffic Management Microkernel (TMM) process for managing add-on feature modules, such as BIG-IP ASM or WebAccelerator; however, no modules need to be provisioned on the system for the mount point to display as detailed above.

Note: In BIG-IP 10.1.0 and later, the /dev/mprov/tmm device has been moved from the /dev file system, and no longer appears in the output from the df -h command.

Note: You can provision resources for add-on feature modules on the System > Resource Provisioning screen in the Configuration utility.

Note: The df command is used to display the amount of available disk space on mounted file systems. For more information, refer to the man page for the df command.
