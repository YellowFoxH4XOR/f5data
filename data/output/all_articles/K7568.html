The serial number is located on the barcode sticker, and is also stored in the system configuration database. The registration key is located in the license file.

Important: You must have the serial number or the last seven digits of the registration key to open a service case with F5 Technical Support. If you are unable to provide either, your Support technician may be able to locate your system in the support entitlement database.

Serial number format

For platform model 4000, the serial number format is F5-XXXX-XXXX. The serial number begins with the letters F5, followed by a dash character ( - ), followed by four alphanumeric characters, followed by a dash, followed by four alphanumeric characters.

For example:

F5-123A-BC45 

For platform models 500 and 3000, the serial number format is bipXXXXXXs. The serial number begins with the letters bip, followed by six numeric characters, and ends with the letter s.

For example:

bip012345s

Serial number barcode sticker

For platform model 4000, the serial number barcode sticker is white and is located on the front of the system, below the LCD panel.

For model 3000, the serial number barcode sticker is silver and is located on the lower left, front corner of the system.

For model 500, the serial number barcode sticker is located on the front of the system on the left side, or on the front of the system below the LCD panel.

Note: For model 500 shipped prior to February 2006, the barcode sticker was placed on the right side next to the mounting bracket.

Displaying the serial number and Registration key from the command line

Enterprise Manager 2.x and 3.x

For Enterprise Manager 2.0.0 and later, you can display the serial number and Registration key using the command line by typing the tmsh show sys license command:

tmsh show sys license

The command output appears similar to the following example:

bigpipe platform

For Enterprise Manger versions 1.6.0 through 1.8.0, obtain the registration key from the Platform Information section of the /config/bigip.license file by typing the following command:

grep Registration /config/bigip.conf

The command output appears similar to the following example:

Registration Key :        T323-297802-425045-224092-6381561

Locating the registration key on an unlicensed system

If the license has not yet been activated on your Enterprise Manager system, you can find the registration key in the /config/RegKey.license file. This file is present only on factory-installed systems.

Obtaining additional license information from F5 using the serial number or registration key

  1. Open a browser session and connect to the following site:

    https://secure.f5.com/validate/validate.jsp

  2. Type your email address into the Contact Email box.
  3. Type the serial number or base Registration Key into the box titled F5 Licenses / Serial Numbers.
  4. Click the Submit Info Request button at the bottom of the page.
