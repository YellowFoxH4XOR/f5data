K000133428: [F5OS-A] Scrambled console output after system upgrade/downgrade on rSeries

Type
Support Solution
Published
2023-04-24
Updated
2024-06-12
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000133428

Description

Scrambled console output after software upgrade or downgrade on rSeries systems.

Serial settings are configured with the following settings:

  • Baud rate: 19200
  • Data bits: 8
  • Stop Bits: 1

Environment

  • F5OS-A
  • rSeries
  • Corrupted console output

Cause

  • Unknown

Recommended Actions

  • Confirm console settings, referring to K000139067: Connecting to the serial console on the rSeries and VELOS.
  • Change the console baud rate to 9600, referring to K000138117: After attempting an upgrade, the F5OS GUI is unavailable after reboot, only the AOM menu is available.
  • Optionally, perform a clean install from USB. For more information, refer to the Clean installation using a USB flash drive section of the F5 rSeries Systems: Installation and Upgrade Install or Upgrade Software manual chapter.

If you see the same behavior after a clean install, please contact F5 support for further analysis.
