Description

Edge clients stuck on "initializing" after upgrading


Environment

BIG-IP APM

Cause

You have an HTTP profile associated to a DTLS virtual server

Recommended Actions

Remove the HTTP profile


ltm virtual /Common/VS_APM_DTLS {

creation-time 2023-08-09:14:06:15

destination /Common/192.168.0.10%1:4433

ip-protocol udp

last-modified-time 2023-10-29:21:46:27

mask 255.255.255.255

profiles {

/Common/AutoConnect_cp {

context clientside

}

/Common/clientssl-default {

context clientside

}

/Common/http_profile { } <-----remove

/Common/ppp { }

/Common/udp { }

}

serverssl-use-sni disabled

source 0.0.0.0%1/0

source-port preserve-strict

translate-address disabled

translate-port disabled

}

Additional Information

Note no HTTP profile on the DTLS VS:
