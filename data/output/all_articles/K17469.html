Known Issue

The BIG-IP APM rewrite profile may incorrectly process event handlers defined using Document Object Model (DOM).

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The BIG-IP APM system rewrites HTML pages that contain event handlers defined using DOM.
  • The JavaScript code in the HTML page uses the toString() function on event handlers.
  • The web application dynamically edits event handlers.

The toString() function called on an event handler returns a string representing the source code of the event handler. Because the returned code is rewritten by the BIG-IP APM rewrite profile, web applications are unable to properly process and dynamically edit event handlers.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use portal access, requested pages that include the event handler fail to display.
  • Web applications malfunction or fail to render properly in browsers.
