Known Issue

BIG-IP database monitors may report an incorrect pool member status.

The exact conditions are not well-defined, but on rare occasions this issue may occur when the following condition is met:

  • One or more pool members are monitored using the following database monitor types:
    • Oracle
    • MSSQL
    • MySQL
    • PostgreSQL

Impact

The BIG-IP system incorrectly marks the affected pool members as up or down.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When viewing a packet capture the database monitor sends a correct response, but the associated monitor marks the pool member down.
  • The BIG-IP system intermittently marks an available pool member as down.
  • The BIG-IP system intermittently marks an unavailable pool member as up.
