Description

Unable to ping an IP behind BIG-IP from BIG-IP itself. Self-IP and destination IP are both in same network.
Packet capture shows there is no response to the ARP request from destination server,

 Time             Source               Destination   Protocol   Length            Info
32.553174    00-00-5E-00-53-00:00:00    Broadcast     ARP        60          Who has 10.0.2.1? Tell 10.0.2.1
37.553174    00-00-5E-00-53-00:00:00    Broadcast     ARP        60          Who has 10.0.2.1? Tell 10.0.2.1
43.553174    00-00-5E-00-53-00:00:00    Broadcast     ARP        60          Who has 10.0.2.1? Tell 10.0.2.1
48.553174    00-00-5E-00-53-00:00:00    Broadcast     ARP        60          Who has 10.0.2.1? Tell 10.0.2.1

Environment

  • Pool Members
  • Establishing connection
  • ARP
Cause

No ARP entry for the destination IP address.

Recommended Actions

  1. Make sure there is an ARP entry for destination IP. To check ARP entry use below command. 
    # arp -a <destination IP>
    For Example:
    # arp -a 10.0.2.1

  2. If the ARP broadcast is blocked in the next hop device, and if you know the destination MAC, add a static ARP entry using below command, 
    # arp -s <destination IP> <destination MAC>
    For Example:
    # arp -s 10.0.2.1  00-00-5E-00-53-00:00:00
