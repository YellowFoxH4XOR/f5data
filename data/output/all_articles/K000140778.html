K000140778: Updates to FCP usage script

Type
Support Solution
Published
2024-08-22
Updated
2024-08-22
Source

Description

In certain situations older versions of the FCP usage script would use an existing Inventory list or create a new inventory list and continue to use the same inventory list each time it was run.

This led to outdated inventories and as such outdated reporting on managed BIG-IP devices.

The latest version of the script has been updated to ensure a fresh inventory is created each time it is run.

Environment

  • BIG-IQ 8.3

  • FCP Usage tool (Update)

Cause

We found in certain BIG-IQ when the FCP usage script was run it used the last generated inventory report and this could cause inaccurate usage reports.

Recommended Actions

Please download / update to the latest version of the script (follow instructions in the link below)

How to install and use the F5 FCP usage script on BIG-IQ Centralized Manager (CM)

To verify you have the latest version of the script, you can type the following:

./bigIQCollect.sh -v 

This will output details on how to run the script and will have a clear line stating: "FCP Usage Script - 20240821"

You will also see a version presented when you run the script with the -i option.

Note older versions of the script do not show a version and will need to be updated.

Observation:  When you rerun the script, if you see 1 or more inventories in a "Started" state and the script fails to run, you will need to restart RESTJAVAD using the command below:

bigstart restart restjavad

This restarts the service and will not impact BIG-IP devices connected to the BIG-IQ, it usually takes less than 2 minutes and BIG-IQ GUI will not be available / will also restart.

Once complete rerun the script again.
