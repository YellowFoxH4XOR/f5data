Description

If server greeting contains client_auth extension and the customer wishes to use old_passwords (which are deprecated in most current db software versions) their server needs to follow proper handshake guidelines to notify us that it intends to switch password authentication methods.

Environment

  • BIG-IP LTM
  • Mysql Monitor
  • Back end user has old_password Authentication method (visible in pcap)

Cause

  • When a server wishes to use a user with old_password authentication method and the F5 monitor sends the client_authenticaion extention as part of the handshake (default in v14.x+) then the server must reply with an Auth Switch request to notify us of what they wish to use. Failure to do so will cause the monitor handshake to fail.

Recommended Actions

  • Create a user with current and supported authentication types. Do not use users to login to the db with old_password 

Additional Information

It should look like this:

    5  55.576543 10.74.103.227 ? 10.74.103.225 MySQL 172 Server Greeting proto=10 version=5.5.62-log
    7  55.634550 10.74.103.225 ? 10.74.103.227 MySQL 183 Login Request user=oldpass db=mysql
    9  55.635003 10.74.103.227 ? 10.74.103.225 MySQL 135 Auth Switch Request
   11  55.635818 10.74.103.225 ? 10.74.103.227 MySQL 103 Auth Switch Response
   12  55.636102 10.74.103.227 ? 10.74.103.225 MySQL 101 Response OK
   13  55.668547 10.74.103.225 ? 10.74.103.227 MySQL 977 Request Query
