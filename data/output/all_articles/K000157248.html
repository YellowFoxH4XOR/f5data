K000157248: Unable to upload qkview file directly to iHealth after upgrading BIG-IP to 17.5.1.3 or 17.1.3

Type
Support Solution
Published
2025-11-02
Updated
2025-11-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3, 17.5.1
Source
https://my.f5.com/manage/s/article/K000157248

Description

While uploading qkview to iHealth through BIG-IP GUI "System >> Support >> Support : Upload to iHealth" menu, an error message is thrown and upload fails.

The Client ID or Client Secret you entered is invalid. Try to re-upload the last generated QKView or generate a new QKView

 

  • After upgrading to 17.5.1.3 or 17.1.3, you are unable to upload qkview from BIG-IP directly to iHealth.
  • You did not observe this issue in previous version like 17.5.1.
  • You have verified all the iHealth credentials (Client ID and Secret) configured in the BIG-IP are correct.
