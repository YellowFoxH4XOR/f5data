K000152928: VELOS controller's diag-agent reporting 'LOP Analog Alert Handler initialization error' after software upgrade

Type
Support Solution
Published
2025-08-08
Updated
2025-08-08
Applies to
  • F5OS
  • F5OS-C: 1.8.1, 1.8.0
Source
https://my.f5.com/manage/s/article/K000152928

Description

The following errors are reported by a standby VELOS controller after upgrade:

LOP Analog Alert Handler initialization error

diag-agent service reported overall health: value=Unhealthy

These messages appear in system logs and in the output of show system health. The error state may persist even when the firmware update (FWU) for velocity fan controllers (VFC) completes successfully and all hardware components are otherwise healthy.

Environment

  • F5OS - Chassis
  • Software Version: 1.8.1
  • VFC firmware update performed during software upgrade

Cause

During a VFC firmware update, diag-agent on the standby controller may report the error. This transient failure can result in a persistent unhealthy status within diag-agent, even after the firmware update has completed successfully and hardware health is restored.

Recommended Actions

If these errors remain after a successful VFC firmware update and overall system health appears normal, restart the diag-agent service on the affected controller:

# From bash on the affected controller
docker container restart diag-agent

  • Re-check system health using show system health to confirm that alerts have cleared.
  • If restarting diag-agent does not resolve the issue, consider rebooting the affected controller.
  • No further action is required if system operation is normal and alerts clear after restarting diag-agent.
  • This behaviour has been identified as a software bug in diag-agent; ID2008593

Additional Information

The error state might also appear if a firmware update failed to be applied. In this case, failing over the system controllers may allow the FWU to be re-applied. Inspect the velos.log and pel_log to determine whether a FWU was applied successfully.
