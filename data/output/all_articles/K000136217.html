Description

When you navigate to the management IP address of a BIG-IP Next tenant running on an rSeries appliance, the F5OS-A login screen (GUI) appears.

Environment

  • BIG-IP rSeries hardware platform
  • A BIG-IP Next tenant is installed
  • You navigate to https://<mgmt-ip> of the BIG-IP Next tenant

Cause

The BIG-IP Next tenant has no GUI on TCP port 443, so the F5OS-A host system processes the URL and serves the login page of the F5OS system.

Recommended Actions

  1. Use port 5443 of the management IP address of the BIG-IP Next tenant to access the API.
  2. Manage BIG-IP Next from Central Manager, as BIG-IP Next does not have a GUI.
