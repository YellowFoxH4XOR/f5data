Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator inserts a pv tag for canonical URLs when Intelligent Browser Referencing (IBR) is enabled. Beginning in 2009, many search engines began supporting a new link tag <link rel="canonical"> to help deal with content referenced by different URLs. When the BIG-IP WebAccelerator inserts a pv tag in canonical URLs, search engines may report multiple locations for the same content instead of the preferred location.

F5 Product Development is tracking this issue as ID 226240 and CR141066.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
