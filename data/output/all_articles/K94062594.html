Known Issue

When you enable or disable an interface, the BIG-IP system might not issue the standard LinkUp/LinkDown traps.

This issue occurs when the following condition is met:

  • As administrator, you enable or disable an interface on BIG-IP i2x00, i4x00, 2x00, and 4x00 platforms.

Impact

The system might issue only the F5 link change trap and not the additional standard management information base (MIB) trap. The system also might not issue the standard LinkUp/LinkDown traps.

Symptoms

As a result of this issue, you might encounter one or more of the following symptoms:

  • The system issues the standard LinkUp/LinkDown traps when a port's status changes, for example, the link goes up or down. Additionally, you can, as administrator, enable and disable ports.
  • For some platforms, the system does not reliably issue a standard LinkUp/LinkDown trap when you, as administrator, enable or disable a port.

Resolution

Status

F5 Product Development has assigned ID 696731 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can use the F5-proprietary MIB: 1.3.6.1.4.1.3375.2.4.0.37 F5-BIGIP-COMMON-MIB::bigipExternalLinkChange trap to track administrative changes to links.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
