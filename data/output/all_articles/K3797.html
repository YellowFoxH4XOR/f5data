K3797: Reasons why 3-DNS may not probe addresses when a prober is defined

Topic

There are a number of possible reasons this issue can occur; however, it occurs most commonly when you define an ACL for a 3-DNS prober, but do not enter an address. Under these circumstances, 3-DNS functions as if the ACL is applied to all addressees, which prevents 3-DNS from probing any address.

To check the ACL prober addresses, perform the following steps.

  1. Log in to the command line.
  2. Using a text editor, such a vi or pico, edit the /config/3dns/include/region.ACL file.
  3. Remove any region statements that do not contain an IP address.
  4. Save the file and exit the editor.
  5. Reload the configuration, by typing the following command:

    3ndc restart

Probing should now work properly.
