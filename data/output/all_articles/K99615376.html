Source

Description

Using MySQL commands to export ASM attack signatures from the CLI and redirecting the list to a text file.

Environment

  • ASM
  • CLI
  • Exporting attack signatures

Cause

GUI has limitations to show a maximum of 100 signatures per page from: 
Security  ››  Options : Application Security : Attack Signatures : Attack Signature List

Recommended Actions

  1. Login to CLI

  2. Switch to bash shell

  3. Execute the following command to view the ASM attack signatures and redirect the command output to a CSV file:
    # mysql -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e "select sig_id,sig_name,sig_desc from PLC.NEGSIG_SIGNATURES;" >> /var/tmp/attack-sigs-descrption.csv

  4. Open the file to check the attack signatures list
    # cat /var/tmp/attack-sigs-descrption.csv
