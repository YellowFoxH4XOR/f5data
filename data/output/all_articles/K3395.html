Wildcard certificates contain a wildcard ( * ) character in the host portion of the address, so that the host will be valid for multiple hosts within a domain. For example, the hostname used for a wildcard certificate could be *.askf5.com.

The BIG-IP system fully supports wildcard certificates with SSL proxies and certificate requests for wildcard certificates.

Note: For information about wildcard certificates in BIG-IP versions 9.x and 10.x, refer to K6823: Configuring multiple HTTPS sites on the same SSL client profile by creating a wildcard certificate request.
