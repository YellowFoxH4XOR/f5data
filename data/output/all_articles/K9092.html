Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.4.4. F5 recommends that all customers currently running 9.4.4 install BIGIP-9.4.4-94.0-HF3, or a later version of the cumulative hotfix rollup, as soon as possible.
