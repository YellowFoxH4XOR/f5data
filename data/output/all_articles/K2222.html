Issue

When attempting to access NameSurfer from the Configuration utility, you may receive the following error:

Connecting to NameSurfer process: connect: Connection refused

If NameSurfer has crashed and produced a core file, you may not be able to connect to NameSurfer from the Configuration utility. To eliminate the core file and restart NameSurfer, perform the following steps.

  1. From the command line interface of the 3-DNS Controller, locate and remove the ns.core file.

    This file is located in the /usr/local/namesurfer/bin directory or the /var/core/ directory.

  2. Change directories to the NameSurfer binary directory, by typing the following command:

    cd /usr/local/namesurfer/bin/

  3. From the /usr/local/namesurfer/bin/ directory, type the following command:

    ./stop

  4. Restart NameSurfer by typing the following command:

    ./namesurferd

NameSurfer should now operate properly.
