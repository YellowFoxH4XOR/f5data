Known Issue

The Configuration utility may not display the full VLAN name in the route domain configuration screen. As a result, users are unable to determine the correct VLAN to select when performing certain operations.

This issue occurs when all of the following conditions are met:

  • Two or more VLAN names share the same first 15 characters.
  • You attempt to modify or create a new route domain configuration.

Impact

When you attempt to modify or create a new route domain configuration, you are unable to determine the correct VLAN to select.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you attempt to view or modify a route domain configuration, the Configuration utility displays a truncated VLAN name in the Configuration > VLANs Members box.
  • When you attempt to create a new route domain configuration, the Configuration utility displays a truncated VLAN name in the Configuration > VLANs Available box.

For example, the Configuration utility may display the production-vlan-external VLAN as production-vlan. Therefore, if there are two VLANs named production-vlan-external and production-vlan-internal, the Configuration utility may display both VLANs as production-vlan.

Workaround

You can avoid this issue by using VLAN names that are unique within the first 15 characters. Alternatively, to work around this issue, you can use tmsh utility to associate the required VLANs to a route domain. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

To display an existing route domain configuration

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. You can view a route domain configuration using the following tmsh command syntax:

    list /net route-domain <name>

    For example, to display a route domain configuration named rd1_example, you would type the following command:

    list /net route-domain rd1_example

  3. To exit the tmsh utility, type the following command:

    quit

  4. Press Enter.

To create a new route domain configuration

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. You can create a new route domain with the desired VLAN using the following tmsh command syntax:

    create /net route-domain <name> id <number> vlans add { <space separated list of vlan names> }

    For example, to create a new route domain named rd1_example with ID 50 and a list of VLAN names, you would type the following command:

    create /net route-domain rd1_example id 50 vlans add { production-vlan-external production-vlan-internal }

  3. Save the change by typing the following command:

    save /sys config

  4. To exit the tmsh utility, type the following command:

    quit

  5. Press Enter.

To modify an existing route domain configuration

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. You can modify the VLANs to add or remove VLANs to an existing route domain using the following tmsh command syntax:

    modify /net route-domain <name> vlans <add or delete> { <space separated list of vlan names> }

    For example, to remove VLAN production-vlan-internal from the route domain rd1_example, you would type the following command:

    modify /net route-domain rd1_example vlans delete { production-vlan-internal }

  3. Save the change by typing the following command:

    save /sys config

  4. To exit the tmsh utility, type the following command:

    quit

  5. Press Enter.
