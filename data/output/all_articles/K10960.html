Topic

The ARX Secure Agent has used various programs to access the Microsoft Windows password database that consists of user names and MD4 password hashes. To determine the program used for your specific ASA version, refer to the following table:

ARX Secure Agent versionProgram
5.1.5 HF1 (build 11966) and latermd4dump.exe and md4service.exe
5.1.0 to 5.1.5fgdump.exe
5.0.6 and earlierpwdump.exe

Important: Passwords are not dumped, accessed, or obtained in clear-text.

Some virus scanning software may erroneously flag these programs as malware. Using these programs within the Secure Agent does not compromise or weaken network security. The MD4 password hashes are never exchanged between the Secure Agent and the ARX. Only usernames, random challenges, and 24-byte responses are shared between the Secure Agent and the ARX. This behavior is no different than the normal information exchange between a client and server in a native CIFS authentication exchange, except the connection between the Secure Agent and the ARX is an encrypted and authenticated session, requiring knowledge of a shared secret.

To ensure that the Secure Agent can run properly, configure the antivirus software on systems running the Secure Agent software to ignore the following programs:

  • C:\Program Files\Acopia\Acopia Secure Agent\md4dump.exe (versions 5.1.5 HF1 (build 11966) and later)
  • C:\Program Files\Acopia\Acopia Secure Agent\md4service.exe (versions 5.1.5 HF1 (build 11966) and later)
  • C:\Program Files\Acopia\Acopia Secure Agent\fgdump.exe (versions 5.1.0 to 5.1.5)
  • C:\Program Files\Acopia\Acopia Secure Agent\pwdump.exe (versions 5.0.6 and earlier)
  • C:\windows\temp\fgdump.exe
  • C:\windows\temp\fgexec.exe
  • C:\windows\temp\lsremora.dll
  • C:\windows\temp\lsremora64.dll
  • C:\windows\temp\pstgdump.exe
  • C:\windows\temp\servpw.exe
  • C:\windows\temp\servpw64.exe
  • C:\windows\temp\pwdump.exe (versions 5.0.6 and earlier)

Note: For more information about the Secure Agent software, refer to K10026: Overview of the ARX Secure Agent software.
