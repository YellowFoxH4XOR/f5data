K000135744: Disable X-Envoy-Peer-Metadata and X-Envoy-Peer-Metadata-Id request headers

Type
Support Solution
Published
2023-08-04
Updated
2023-08-23
Applies to
  • Aspen Mesh: 1.11
Source
https://my.f5.com/manage/s/article/K000135744

Description

Envoy sidecar (istio-proxy container) adds headers x-envoy-peer-metadata and x-envoy-peer-metadata-id to requests. These headers are incurring extra bytes for each packet and contain sensitive information about the Kubernetes environment.


Environment

Aspen Mesh 1.11.x
 

Cause

Envoy adds these headers to requests with base64 encoded information as the header value.
 

Recommended Actions

These headers can be removed using a VirtualService (preferred way) or using an EnvoyFilter.

VirtualService - Preferred Way

apiVersion: networking.istio.io/v1beta1
kind: VirtualService
metadata:
  name: remove-headers
spec:
  hosts:
  - httpbin.org
  http:
  - match:
    - uri:
        prefix: /headers
        ignoreUriCase: true
    route:
    - destination:
        host: httpbin.org
        port:
          number: 80
      headers:
        request:
          remove:
          - X-Envoy-Peer-Metadata
          - X-Envoy-Peer-Metadata-Id


EnvoyFilter - Keep in mind that EnvoyFilter configuration and features may change in future versions and these EnvoyFilter may not work or provide the desired results. Likewise, the EnvoyFilter needs to be tested thoroughly to prevent unexpected behavior on a production environment.

apiVersion: networking.istio.io/v1alpha3
kind: EnvoyFilter
metadata:
  name: remove-headers-filter
  namespace: istio-system
spec:
  configPatches:
  - applyTo: HTTP_FILTER
    match:
      listener:
        filterChain:
          filter:
            name: "envoy.filters.network.http_connection_manager"
            subFilter:
              name: "envoy.filters.http.router"
    patch:
      operation: INSERT_BEFORE
      value:
        name: envoy.lua
        typed_config:
          "@type": "type.googleapis.com/envoy.extensions.filters.http.lua.v3.Lua"
          inlineCode: |
            function envoy_on_request(request_handle)
              request_handle:headers():remove("X-Envoy-Peer-Metadata")
              request_handle:headers():remove("X-Envoy-Peer-Metadata-Id")
            end

or

apiVersion: networking.istio.io/v1alpha3
kind: EnvoyFilter
metadata:
  name: remove-headers
  namespace: istio-system
spec:
  configPatches:
  - applyTo: NETWORK_FILTER
    match:
      listener:
        filterChain:
          filter:
            name: "envoy.filters.network.http_connection_manager"
    patch:
      operation: MERGE
      value:
        typed_config:
          "@type": "type.googleapis.com/envoy.extensions.filters.network.http_connection_manager.v3.HttpConnectionManager"
  - applyTo: ROUTE_CONFIGURATION
    patch:
      operation: MERGE
      value:
        request_headers_to_remove:
        - "X-Envoy-Peer-Metadata"
        - "X-Envoy-Peer-Metadata-Id"

Remember for external traffic you may need a ServiceEntry

apiVersion: networking.istio.io/v1beta1
kind: ServiceEntry
metadata:
  name: se-httpbin-org
spec:
  hosts:
  - httpbin.org
  location: MESH_EXTERNAL
  ports:
  - name: http
    number: 80
    protocol: HTTP
  resolution: DNS
