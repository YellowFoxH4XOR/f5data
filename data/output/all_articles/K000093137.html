K000093137: Virtual server reset valid connections in hardware Syncookie mode.

Type
Support Solution
Published
2022-12-09
Updated
2023-09-22
Source
https://my.f5.com/manage/s/article/K000093137

Description

After upgrade to v14.1.5.x, 15.1.5.1-15.1.8.x, or after hardware syncookie is activated on a device you can notice drop in traffic volume, for example by observing connection graphs. Users may report that some valid traffic is being dropped. 
 

Environment

  • BIG-IP
  • v14.1.5.x, 15.1.5.1-15.1.8.x
  • Hardware with ePVA support: iSeries appliances or the B2250 and B44xx VIPRION blades
  • Hardware SYN cookie mode is activated.

Cause

  • Bug ID 1121085

Due to an algorithm mismatch in software and hardware that some valid TCP connections may get rejected with "No flow found for ACK' reset-cause when the hardware SYN cookie mode is active.

Recommended Actions

Follow the link to disable the hardware SYN cookie mode globally.
After a reboot, restart the TMM for an additional time:
tmsh restart sys service tmm
Note: for VIPRION platform use: 
clsh restart sys service tmm
