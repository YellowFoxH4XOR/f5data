Issue

For information about troubleshooting general NameSurfer issues, refer to the following articles:

  • Determine if NameSurfer is running, by performing the steps described in K1051: Verifying that the NameSurfer process is running.
  • If NameSurfer is not running, restart it by performing the steps described in K1092: Restarting the NameSurfer process from the command line.
  • If NameSurfer will not start successfully, analyze the NameSurfer log files by performing the steps described in K1205: Troubleshooting NameSurfer startup problems.
  • If specific files are causing errors, remove the references to those files by performing the steps described in K1237: Isolating NameSurfer problems by removing zone files.

If you are unable to determine the NameSurfer issue using these articles, contact F5 Technical Support for further assistance, or consider rebuilding the NameSurfer database by performing the steps described in K1239: Creating a new NameSurfer zone database.

Important: Creating a new database requires that you re-enter or re-import all zone information. Create a new NameSurfer zone database only if NameSurfer has corrupted data or will not start, and you have exhausted all other troubleshooting options.
