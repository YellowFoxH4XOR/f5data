Description

Customer want to force the client to access internet via VPN tunnel, include IPv4 and IPv6 stack, and add exceptions for some subnets / hosts, access them via physical interface.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Network Access
  • Split tunnel

Cause

It is customer requirement.

Recommended Actions

Please follow the article K55104964 to configure the Network Access tunnel, K55104964: Network Access - Split Tunnel configuration.
When configure "IPV4 LAN Address Space", input the CIDR "0.0.0.0/0". As in the client, the network environment maybe complex, and "0.0.0.0/0" may cannot overwrite the default IPv4 route, so change to CIDR "0.0.0.0/1" and CIDR "128.0.0.0/0" if "0.0.0.0/0" cannot work.
When configure "IPV6 LAN Address Space", input the CIDR "::/0". As in the client, the network environment maybe complex, and "::/0" may cannot overwrite the default IPv6 route, so change to CIDR "2000::/3" if "::/0" cannot work.

Additional Information

Refer to the link below:

IPv6 Global Unicast Address Assignments

It contain all allocated global unicast IPv6 addresses.  Up to now, the prefix 2000::/3 cover all of of them.
