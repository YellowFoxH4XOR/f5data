Known Issue

This is the result of a known issue. Enabling connection mirroring on a BIG-IP redundant pair running different software versions may cause a memory leak.

Important: F5 Networks does not support BIG-IP redundant pair configurations that run different software versions, as this configuration can have a detrimental affect on failover features. For more information, refer to K8665: BIG-IP systems in a redundant pair must run the same version of software.

F5 Networks Product Development tracked this issue as CR96792 and it was fixed in BIG-IP version 9.4.5. For information about upgrading, refer to the BIG-IP LTM Release Notes.
