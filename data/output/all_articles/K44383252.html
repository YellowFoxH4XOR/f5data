Known Issue

The Traffic Management Microkernel (TMM) process may restart and produce a core file when using an HTTP iRule command within a server-side event.

This issue occurs when all of the following conditions are met:

  • The virtual server is configured with a OneConnect profile and an iRule.
  • The iRule contains an HTTP command such as HTTP::header within a server-side event such as HTTP_REQUEST_SEND.
  • The virtual server referencing the iRule processes traffic, which triggers a server-side event.

Impact

If the BIG-IP system is a member in a redundant configuration, traffic fails over to the standby BIG-IP system. If the BIG-IP system is not part of a redundant pair, traffic is interrupted until the TMM process restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to another host in the device group.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.

Workaround

To work around this issue, you can use the clientside command in conjunction with the affected server-side event, or if using the HTTP_REQUEST_SEND event, replace it with the HTTP_REQUEST_RELEASE event.

Impact of workaround: Changing the design of an iRule may have additional effects on traffic processing. Ensure that any modification you make is compatible with your environment.

The following example shows an iRule configured to log the Host header of an HTTP request:

when HTTP_REQUEST_SEND {
log local0. "The host header is [HTTP::header value Host]"
}

You can modify the previous iRule by adding the clientside command, as shown in the following example:

when HTTP_REQUEST_SEND {
clientside {
log local0. "The host header is [HTTP::header value Host]"
}
}

Alternately, you can replace HTTP_REQUEST_SEND with HTTP_REQUEST_RELEASE as shown in the following example:

when HTTP_REQUEST_RELEASE {
log local0. "The host header is [HTTP::header value Host]"
}

For more information about iRules commands, refer to the iRules Home on F5 CLoud Docs.
