Source
https://my.f5.com/manage/s/article/K20151093

Description

BIG-IP has 1000 APM license (500 from base license and more 500 CCU add license)
Getting a messaging that cannot accept connections because of the 500 license limit
Example of such a message:
warning tmm[PID]: 01490527:4: a9495c0c13cd64d15993f5e83803f5d9: Global concurrent connectivity session limit reached.

Environment

  • The Big-IP is provisioned with APM;
  • You have NetworkAccess objects created to handle APM VPN connections;
  • You're running one of the Big-IP software version listed above.

Cause

This is due to the known Bug ID 564496.

Recommended Actions

To address this issue, perform either of the following actions:
  • Upgrade to a BIG-IP version where Bug ID 564496 is fixed
  • Complete the Workaround for your version as described in Bug ID 564496
