Description
After updating certain FIPS platforms to 15.1.0.4, the configuration fails to load:
 
The /var/log/ltm may contain logs like these:
Jul  14 08:29:42 [Device Name] err mcpd[11863]: 01b50049:3: FipsUserMgr Error: Master key load failure.
Jul  14 08:29:52 [Device Name] err mcpd[11863]: 01070712:3: Caught configuration exception (0), FIPS 140 operations not available on this system.
Jul  14 08:29:52 [Device Name] err tmsh[14528]: 01420006:3: Loading configuration process failed.
 

Environment
  • Specific FIPS-enabled hardware platforms:
    • 5250v-F
    • 7200v-F
    • 10200v-F
    • 10350v-F
    • i5820-DF
    • i7820-DF
  • Version 15.1.0.4
 
Cause
Bug ID 925989
 
Recommended Actions
 
Do not install 15.1.0.4 / Roll back to previous version
 
If you are running one of the above platforms, do not install the standard release of 15.1.0.4.  If you have already installed 15.1.0.4 and are experiencing this issue, do not attempt to resolve it.  Immediately boot back into the previous boot volume and prior version of software.
 
Install 15.1.0.4 Engineering Hotfix
 
An Engineering Hotfix based on 15.1.0.4 is available for download at MyF5 Downloads in the 15.1.0.4 release directory.  The filename is Hotfix-BIGIP-15.1.0.4.0.40.6-ENG.iso
 
To navigate there from MyF5 Downloads select “Find a Download”, “BIG-IP v15.x / Virtual Edition with Traffic Management Operating System® (TMOS®)”, and finally “15.1.0.4”.
 
Hotfix Installation

Please refer to K13123: Managing BIG-IP product hotfixes (11.x - 17.x) before beginning installation.


Note: Ensure that the base 15.1.0.4 ISO and Hotfix-BIGIP-15.1.0.4.0.40.6-ENG.iso are both in /shared/images before beginning installation.
 
Important: It is recommended to create a UCS backup of the device before updating the software.
