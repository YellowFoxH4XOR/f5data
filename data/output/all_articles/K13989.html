Topic

You should consider using this procedure under the following condition:

  • You want to detect a Windows 8 or Windows 8 RT client with a BIG-IP APM access policy.

Description

You can customize BIG-IP APM access policy actions to evaluate a client operating system (OS) and branch to specific actions based on the OS and version. The BIG-IP APM system contains a built-in action, Windows Info, that checks for several popular versions of the Windows OS. However, the BIG-IP APM access policy actions may not yet include newly released operating systems, such as Windows 8. You can customize an action to evaluate the user-agent string returned by the client OS and create a new branch that can perform actions specific to the OS.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • A BIG-IP APM access policy is defined with an action.

Procedures

Adding Windows 8 or Windows 8 RT detection to an access policy action

The following procedure adds new branches to an access policy action, to detect Windows 8 and Windows 8 RT clients.

Impact of workaround: Changes to the access policy take effect immediately when clicking Apply Access Policy; this only affects new sessions logging in after the changes are applied.

Note: You can add the Windows 8 branch to any action.

  1. Log in to the Configuration utility.
  2. Click Access Profiles.
  3. Click Edit next to the name of the access policy to edit.
  4. Click the action name for which you want to add the Windows 8 branch.

    For example:

    Windows Info
  5. Click the Branch Rules tab.
  6. Click Add Branch Rule.
  7. In the Name box, type a name for the branch.

    For example:

    Windows 8
  8. Click change.
  9. Click the Advanced tab.
  10. Paste the following text in the text box:

     expr { [mcget { session.user.agent}] contains " Windows NT 6.2;" }
  11. Click Finished.
  12. Click Add Branch Rule.
  13. In the Name box, type a name for the branch.

    For example:

    Windows 8 RT
  14. Click change.
  15. Click the Advanced tab.
  16. Paste the following text in the text box:

    expr { [mcget { session.user.agent}] contains " Windows NT 6.2;" && [mcget {session.user.agent}] contains " ARM;" }

  17. Click Finished.
  18. Click Save. 
  19. Two new branch rules will appear. Add the actions you want to perform to the new branches.
  20. Click Apply Access Policy.
  21. Click Close.
