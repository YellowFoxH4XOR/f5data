K000154589: Message boxes configured in VPE does not appear in the F5 Access application

Type
Support Solution
Published
2025-09-03
Updated
2025-09-03
Applies to

  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source

Description:

Message boxes configured in BIG-IP Access Policy Manager (APM) may not appear in the F5 Access application. Instead of displaying custom messages, only the default system error message is shown. This occurs even when modifying general error messages in Advanced Customisation. APM logs indicate that the relevant policy branch is being processed, but the custom message box does not display within the F5 Access app.

Environment:

  • Big-IP APM
  • F5 Access Mobile Client 

Cause:

The "Web Login" feature in the F5 Access app is disabled by default.
Without this option enabled, the app does not invoke the browser-based authentication flow and message box rendering, preventing custom APM message boxes from appearing to users.

Recommended Actions:

  • Enable "Web Login" in the settings of the F5 Access app.
    F5 Access app relies on the operating system's web browser (WebKit for iOS/Android) to present authentication prompts, message boxes and other interactive elements.
  • After enabling "Web Login," restart or re-install the F5 Access app to ensure changes take effect.
  • Confirm that affected users are traversing the correct branch in your access policy where a message box is configured.
