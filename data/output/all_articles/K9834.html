Known Issue

This is the result of a known issue. The tcpdump command outputs extraneous data when using the maximum snaplen (-s0) option.

For example:

tcpdump -s0 -ni 1.1

The example tcpdump command would produce output displaying extraneous TMM-related information. The output would appear similar to the following example:

16:10:50.3814 100.5.50.1.http > 100.5.50.22.47287: R 0:0(0) ack 5642770849 win 0 (DF) out slot1/tmm0 lis= flowtype=66 flowid=6B5C940 peerid=0 conflags=EA6 inslot=0 inport=0 haunit=0 peerremote=00000000:00000000:00000000:00000000 peerlocal=00000000:00000000:00000000:00000000 remoteport=0 localport=0 proto=0 vlan=0

F5 Product Development tracked this issue as ID 328983 (Formerly CR116464). It has been fixed in BIG-IP 10.0.0 HF1.

This issue has been fixed in Hotfix-BIGIP-10.0.0-5460.0-HF1, which has been issued for BIG-IP version 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
