K000146927: My certificate is not generated for my domain

Type
Support Solution
Published
2024-11-08
Updated
2025-12-08
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Apps
  • F5 Distributed Cloud Multi-Cloud App Connect
Source
https://my.f5.com/manage/s/article/K000146927

What Happened?

  • You try to add automatic certificate to your HTTPS Load Balancer
  • The certificate is never generated
  • It's stuck in the "AUTO CERT STARTED" state
  • You have tried adding it and deleting it several times
  • Other domains don't have the same problem

Environment

  • F5® Distributed Cloud Services
  • Load Balancers
  • Automatic certificate

Resolution/Answer

If you did too much changes and requests, you’ll need to wait until the rate limit expires after a week.

If you issued 25 certificates on Monday and 25 more certificates on Friday, you’ll be able to issue them again starting Monday.

Cause

  • The rate limit set by Let's Encrypt was reached - more information here
  • The main limit is Certificates per Registered Domain (50 per week)
