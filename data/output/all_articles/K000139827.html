Description

I am currently running BIG-IP versions prior to BIG-IP Next version 20.2.0. Can I upgrade BIG-IP from version 17.1.0 to version 20.2.0?

Environment

  • You have running BIG-IP instances using version 17.x.x or older
  • You are considering BIG-IP Next, which begins at version 20.0.0

Cause

BIG-IP Next is a new product and it is not possible to upgrade BIG-IP versions prior to version 20.0.0 to BIG-IP Next version 20.0.0 or higher.

Recommended Actions

  1. Contact your account team to have a discussion about BIG-IP Next.
  2. The recommended migration path to BIG-IP Next is to migrate individual applications. For more information see Overview: Migrate BIG-IP application configurations onto BIG-IP Next Central Manager
