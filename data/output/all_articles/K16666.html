Known Issue

Users may encounter an operating system driver fault during app tunnel sessions.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access policy references a secure connectivity profile is customized to include the DNS Relay proxy service.
  • Users are running the Windows XP SP3 operating system.
  • Users establish BIG-IP APM app tunnel session using the BIG-IP Edge Client or a browser.

Impact

Sporadically users may encounter a Windows operating system driver fault.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • During an established app tunnel session the user's device displays a driver fault blue screen and their device reboots.
  • When debugging the Windows stack trace the F5FltDrv.sys driver is identified as the trigger of the operating system fault.
