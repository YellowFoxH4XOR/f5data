Description

When a bot defense profile is added, the client see their browsers generating random HTTP requests like:

 GET http://127.0.0.1:8888/400_random_url_with_numbers_403
 GET http://127.0.0.1:8888/random_url
 GET http://127.0.0.1:8888/404

Environment

  • BIG-IP version: 17.1.0.3
    DoS profiles

Cause

These requests are caused by the bot profile to test the different browser capabilities.

Recommended Actions

None, working as designed
