Known Issue

This is the result of a known issue. When the user attempts to log on to a FirePass controller, the BIG-IP Edge Portal app for the Apple iPhone, iPad, and iPod touch may display the following error message:

Logon Failed
The operation couldn't be completed. (NSXMLParserErrorDomain error 65.)

This error message occurs when the FirePass controller does not have an active pre-logon sequence.

F5 Product Development is tracking this issue as ID 343747.

Workaround

You can work around the issue by activating a pre-logon sequence. To so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence page.
  3. Click the option button next to the sequence you want to use.

    Note: If you have not defined a pre-logon sequence, you can use the empty pre-logon sequence. The empty pre-logon sequence does not perform client-side checking and will not change the FirePass controller functionality.

    Note: For more information about pre-logon sequences, refer to the FirePass Controller Administrator Guide.
