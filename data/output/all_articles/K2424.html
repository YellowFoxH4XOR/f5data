K2424: Reasons why BIG-IP may not mark down a node when services on the node are disabled

Topic

While for the most part, BIG-IP versions 4.0 and later perform health checks on nodes differently than earlier versions of BIG-IP, these versions still send an ICMP ping or a TCP echo to the node. BIG-IP uses the ICMP ping or TCP echo to check the status of a node address, not the services on the node.

If you have not configured a monitor on the BIG-IP and have only shut down the service on the node itself, the BIG-IP will continue to mark the node as up because it can still contact the server's network interface.

To resolve this issue, configure a monitor to check for services on the nodes (for example, TCP port 80, the HTTP protocol) for a web server. For detailed instructions about how to configure and use health monitors, refer to the BIG-IP manual.
