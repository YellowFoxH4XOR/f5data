K7309: The BIG-IP ASM system will not process the second request from a client under certain conditions

Known Issue

This is the result of a known issue. The BIG-IP ASM system processes the client side and server side of a connection individually. If a client initiates a connection and sends the first request resulting in the server side of the connection remaining open, and the client side of the connection being closed, subsequent requests from the client are not processed by the BIG-IP ASM system.

F5 Product Development tracked this issue as CR71428 and it was fixed in BIG-IP ASM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.
