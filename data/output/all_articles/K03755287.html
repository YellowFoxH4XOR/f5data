Description

Setup Utility requesting Forward Proxy Certificate and Logging configuration.

Does not show the resource management and the network configuration as expected.

Environment

  • BIG-IP
  • Setup Utility
  • New license

Cause

If license contains F5 SSL Orchestrator option, the Setup utility will request the Forward Proxy Certificate and Logging to be configured before releasing user to the Configuration utility.

Recommended Actions

To get access to the Configuration Utility, you may do either of the following:

  • Request a license without F5 SSL Orchestrator included
  • Disable the BIG-IP Setup Utility:
    1. Log in to the BIG-IP command line
    2. To disable the Setup Utility, type the following command:
      tmsh modify /sys global-settings gui-setup disabled
    3. To save the changes, type the following command:
      tmsh save /sys config

Note: The ability to disable the Configuration utility setup can only be accomplished using TMSH or by completing all the setup steps presented by the Configuration utility.
