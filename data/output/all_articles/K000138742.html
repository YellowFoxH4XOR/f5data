K000138742: More Information on Downloading F5OS Velos Backups from BIG-IQ

Type
Support Solution
Published
2024-02-28
Updated
2024-03-19
Applies to

  • BIG-IQ Centralized Management: 8.3.0
Source
https://my.f5.com/manage/s/article/K000138742

Description

When you add the Velos Controller to BIG-IQ, it will query the Controller for the Active Partitions, and you will also be asked for the Username/Password for each Active Partition.

Downloading an F5OS backup can be confusing, as it has two parts to the backup, the Controller Backup and Partition Backups.

Once you have made the Backup, the Backup Files shows the Backup of the Controller, but it is also a Hyper Link to the Backup of the Partitions.

Environment

From BIG-IQ 8.3.0, F5OS backup is supported.

Cause

None

Recommended Actions

None

Additional Information

 

To download the Controller Backup, you need to check the Box beside "Test_F5OS_Backup_F5OS_Velos_81_7_20240130170905" and then Click the Download button.

To download the Partition Backups, click on the link "Test_F5OS_Backup_F5OS_Velos_81_7_20240130170905" and you will be presented with:

Here you will see multiple backups if you have multiple partitions.
