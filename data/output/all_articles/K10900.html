Known Issue

This is the result of a known issue. The Status page of the ARX Manager GUI may incorrectly display the disk status for a failed drive. The Status may continue to display as green and good for a disk that has experienced a failure.

F5 Product Development tracked this issue as ID 32642 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

An accurate disk status can be displayed using the ARX Manager GUI on the Chassis > Disks page. In addition, the state of the disks can be accurately displayed using the show chassis diskuse ARX CLI command.

Note: For information about the show chassis diskuse command, refer to the ARX CLI Reference Guide.
