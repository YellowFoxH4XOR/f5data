Known Issue

This is the result of a known issue. When you perform the collect all command from the ARX CLI or the GUI, and you specify the NFS option, the operation will fail if the target is a VIP for a multi-protocol volume. The operation fails when looking for the proxy-user credentials.

For example, the following command will fail:

collect all nfs Namespace1 /vol1 FullCollect.tgz

An error message is then displayed that appears similar to the following example:

% ERROR: REPL_CREDS_NOT_FOUND (40829026):
  Proxy-user credentials not found for ''.

F5 Product Development tracked this issue as ID 34695 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX release notes.

Workaround

On occasions when you perform the collect all command and the target is a VIP for a multi-protocol volume, specify the CIFS protocol.
