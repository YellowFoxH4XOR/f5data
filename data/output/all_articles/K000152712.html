Description

Locked out of the active device due to a forgotten/lost password after changing on 1 system in HA pair.

 

Environment

  • Password change on 1 system in an HA pair but password chosen was lost or misconfigured.
  • Changes haven't been synced to peer yet.
  • Peer is still accessible
  • Configuration on the locked system wants to be saved and not lost. (optional)

 

Cause

Mistakenly changed the passwords for the admin and root accounts to an unknown password and immediately locked out of GUI.

 

Recommended Actions

Complete the recovery steps using the standby system which still has known passwords and access.

  • If configuration on the locked out system can be overwritten, push the configuration from the standby to the active system (from the working-password system to the non-working system).

 

  • If configuration on the locked out system needs to be saved:
    • Login to a bash session on the standby system and also into the configuration utility on the standby system.
    • Sync the devices by pulling the active changes (bad passwords included) to the standby system. (This will force a logout of the GUI, but don't worry about that at this point; ssh session should not be logged out)
    • Using the active ssh session, immediately update the root and admin passwords with these commands:
tmsh modify auth password admin
tmsh modify auth password root
  • Login to the GUI of the standby using the new password defined above.
  • Issue a sync pushing these new passwords on the standby system back to the group (the active system)
  • Confirm that you can login to both systems now with the GUI and ssh.
