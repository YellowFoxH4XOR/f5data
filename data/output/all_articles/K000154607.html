Description

BIG-IP devices may continue to send IPv6 neighbor solicitation (ICMP6) traffic to decommissioned or previously configured IPv6 addresses, even after hostnames and device trust have been updated. This results in repeated neighbor solicitation packets visible in packet captures, targeting IPs that no longer exist in the network. These solicitations can be confirmed by inspecting packet captures for ICMP6 neighbor solicitation messages to the stale addresses.

Environment

  • Product: BIG-IP LTM
  • Configuration: Devices configured in HA cluster, previously managed by BIG-IQ, with management IP addresses changed as part of migration or reconfiguration.
  • Issue observed in HA environments.

Cause

Stale REST endpoints referencing decommissioned management IPv6 addresses persist in the system’s memory and configuration. These endpoints may not always be removed automatically when management IP addresses are changed, resulting in the system continuing to broadcast neighbor solicitations to unreachable IPs.

Recommended Actions

  1. Identify Stale Endpoints:
    • Use QKView and search for the old IP addresses and hostnames in files such as /var/tmp/storage_text_dump.txt` and mcp_module.xml.
    • Confirm the presence of stale endpoints referencing the old IPs.
  2. Remove Stale Endpoints:
    • Create a UCS backup of the system before making changes:
      tmsh save sys ucs $(echo $HOSTNAME | cut -d'.' -f1)-$(date +%H%M-%m%d%y)
    • Use restcurl commands to delete specific endpoints referencing old IP addresses:
      restcurl -X DELETE /shared/resolver/device-groups/cm-bigip-allDevices/devices/
      restcurl -X DELETE /shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices/
      Replace <UUID> with the UUIDs associated with the stale endpoints found in your QKView or storage dump.
  3. Verify Resolution:
    • After deletion, monitor packet captures to confirm that neighbor solicitation traffic to the stale IPs have stopped.
    • If traffic persists, a forced reload of the mcpd process may be required:
      touch /service/mcpd/forceload
      reboot

    Note: This will interrupt traffic and should be performed during a maintenance window.

  4. Additional Notes:
    Remnant hostname entries in configuration files (such as bigip_base.conf or mcp_module.xml) that are not tied to active IP addresses do not cause network traffic and can be ignored unless they are associated with active endpoints.
