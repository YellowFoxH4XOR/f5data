K000158841: F5OS-A LCD module bounced with "Fault detected in LCD module" error

Type
Support Solution
Published
2025-12-18
Updated
2025-12-18
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.3, 1.8.0
Source
https://my.f5.com/manage/s/article/K000158841

Description

  • A transient error "Fault detected in LCD module" is reported on an F5OS-A 1.8.x system. 
  • Events similar to the following can be seen on "show system events" output

log "66306 lcd lcd-fault ASSERT ERROR \"Fault detected in LCD module\"
log "66306 lcd lcd-fault EVENT Network Access \"LCD Health is Not OK\"
log "66306 lcd lcd-fault CLEAR ERROR \"Fault detected in LCD module\"
log "66306 lcd lcd-fault EVENT Network Access \"LCD Health is OK\"

 

  • /var/F5/system/log/lcd.log may show one or both of the following:

lcd bmcservice[<pid>]  ValueError: invalid literal for int() with base 16: '>'
lcd bmcservice[<pid>]  OSError: [Errno 12] Cannot allocate memory

 

  • The error is active for approximately one minute, during which the LCD subsystem experience a service crash, but the issue self-resolves and normal system health is restored.

Environment

  • F5OS-A version 1.8.x
  • RSeries r2xxxx/r4xxxx systems only

Cause

Bug ID 2185045

Recommended Actions

  • No fix available at the time of creating of this article.
  • LCD functionality will be impacted for a period of 1-2 minutes, then recover itself. No impact to traffic will occur.

Additional Information

None
