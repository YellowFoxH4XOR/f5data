Known Issue

If you create or manage global server load balancing (GSLB) CNAME pool members, the system may produce an error message.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP DNS system is configured with a GSLB CNAME pool.
  • Using the Configuration utility, you attempt to modify the GSLB CNAME pool Member List.
  • Pool members are available to add to the GSLB pool.
  • You attempt to create a new DNAME pool member or manage an existing DNAME pool member, and set the Static Target option for the pool member.
  • You click Add to include the pool member in the GSLB pool Member List.

    Note: Static Target specifies that the member's name defines a static DNAME, rather than a name linked to a wide IP defined on the system.

Impact

The system does not apply the configuration change, and the system displays an error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you click Add in the Member List to add the DNAME pool member that is set with the Static Target option, the system displays an error message similar to the following example:

    Entry could not be matched against existing objects.

  • When you use the TMOS Shell (tmsh) to attempt the same configuration settings, the system accepts the configuration.

Workaround

To work around this issue, you can use tmsh to configure GSLB pool members. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To modify an existing CNAME pool with a DNAME pool member, use the following command syntax:

    modify /gtm pool cname <pool name> members add { <target dname> { static-target yes } }

  3. To create a new CNAME pool with a DNAME pool member, use the following command syntax:

    create /gtm pool cname <new pool name> members add { <target dname> { static-target yes }}

  4. To save the configuration change, type the following command:

    save /sys config gtm-only

  5. Exit tmsh by typing the following command:

    quit
