Topic

This article applies to BIG-IP 11.x. For information about other versions, refer to the following article:

  • K16297: Configuring the BIG-IP GTM topology load-balancing behavior for pool members with a zero score (10.2.2 - 10.2.4)

Purpose

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP GTM topology load-balancing behavior for pool members with a zero score.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the BIG-IP GTM command line.
  • You are using a topology load-balancing method.

Description

Starting in BIG-IP GTM 11.x, you can use the topology-allow-zero-scores Traffic Management Shell (tmsh) command to control whether topology load-balancing returns pool members with a zero score. The default behavior is enabled.

Procedures

Configuring the BIG-IP GTM topology load-balancing behavior for pool members with a zero score

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh
  2. To modify the topology load-balancing behavior for pool members with a zero score, use the following command syntax:

    modify /gtm global-settings load-balancing topology-allow-zero-scores <yes/no>

    For example, to disable whether topology load-balancing returns pool members with a zero score, you would type the following command:

    modify /gtm global-settings load-balancing topology-allow-zero-scores no
     
  3. Save the change by typing the following command:

    save /sys config
