Issue

Error Message

notice tmm[<PID>]: 01490555:5: Initializing Access with max global concurrent url filtering session limit: <value>

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <value> is the licensed limit for global concurrent URL filtering sessions.

For example:

notice tmm[22215]: 01490555:5: Initializing Access with max global concurrent url filtering session limit: 10000

Message Location

You may encounter this message in the following location:

  • The /var/log/apm file

Description

This message occurs when all of the following conditions are met:

  • URL filtering is licensed on the BIG-IP APM system. and one of the following events occurs:
    • The BIG-IP APM system boots up.
    • The license for the BIG-IP APM system is reactivated.
    • An add-on license is installed on the BIG-IP APM system.
    • The standby BIG-IP APM system in a high availability (HA) configuration becomes active for the first time.

In the /config/bigip.license file, you may observe the number of global concurrent URL filtering sessions available to the BIG-IP APM system.

For example:

apm_urlf_sessions :                10000

Impact

There is no impact; this is an informational message and reflects the maximum number of concurrent URL filtering sessions licensed for the BIG-IP APM system.

Recommended Actions

None
