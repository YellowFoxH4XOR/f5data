Known Issue

This is the result of a known issue. The TCP profile removes IP Type of Service (ToS) values set by the server when passing traffic to a client.

ToS values, also referred to as Differentiated Services Code Point (DSCP) values, are used in Quality of Service (QoS) configurations to give specific traffic priority on the network. The BIG-IP LTM removes the ToS value specified by the server, which results in priority traffic receiving a low priority on the network. In QoS network configurations, this behavior may prevent upstream and downstream devices from routing traffic properly.

F5 Product Development tracked this issue as CR97397, and it was fixed in BIG-IP 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue has been fixed in Hotfix-BIG-IP-9.3.1-HF3, which has been issued for BIG-IP 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For a list of the latest hotfixes for each BIG-IP software branch, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Note: This issue does not affect BIG-IP 10.x.

Workaround

Hotfix-BIG-IP-9.3.1-HF3 introduces a new value (65535) that can be applied to in the IP ToS field within a TCP profile to allow copying of IP ToS across client and server sides. To configure a TCP profile to allow copying of IP ToS across client and server sides, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click Profiles.
  4. From the Protocol menu, select TCP.
  5. Select the TCP profile you want to modify to allow IP ToS to be passed across.

    Note: F5 recommends that only custom TCP profiles be modified, and not the default or base TCP profile.
  6. Locate the IP ToS field within the TCP profile.
  7. Enter the following value:

    65535
    The TCP profile is now configured for IP ToS pass through mode.
  8. Click Update.
