K11005: ARX support for Windows 2008 clusters as file servers

Topic

Starting in ARX version 5.1.0, Windows 2008 clusters have been certified as file servers behind the ARX. If you attempt to configure a Windows 2008 cluster as a file server on an earlier version of ARX software, certain features such as the snapshot feature will not function properly.

Note: Windows Server 2008 R2 requires a configuration change in order to function as a file server behind the ARX. For more information, refer to the ARX Release Notes.
