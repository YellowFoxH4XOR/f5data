K000140650: How to represent a resource in non-default partition by using iControl REST API

Description

 

For example, when you create a partition called myPartition1 and then create a Client SSL profile called myClientSsl1 in the partition (/myPartition1/myClientSsl1), you can specify the Client SSL profile by using the following URL.

 

https://<BIG-IP IP Addr>/mgmt/tm/ltm/profile/client-ssl/~myPartition1~myClientSsl1

 

Environment

BIG-IP

iControl REST

 

Cause

Because the representation of folder and partition names in tmsh often includes a forward slash (/), URI encoding of folder and partition names must use a different character to represent a forward slash in iControl REST. 

 

Recommended Actions

To accommodate the forward slash in a resource name, iControl REST maps the forward slash to a tilde (~) character
