Known Issue

This is the result of a known issue. One of the options for installing the end-user diagnostics (EUD) utility is to use the mkdisk utility to create a bootable USB thumb drive. You can then run the EUD software from the USB thumb drive. However, the mkdisk utility fails to create a USB thumb drive for EUD version EUD_B 11.3.

This issue occurs for the following BIG-IP platforms:

  • BIG-IP 1500 (C36)
  • BIG-IP 3400 (C62)
  • BIG-IP 3410 (C100)
  • BIG-IP 4100 (D46)
  • BIG-IP 6400 (D63)
  • BIG-IP 6800 (D68)
  • BIG-IP 8400 (D84)
  • BIG-IP 8800 (D88)
  • Secure Access Manager 4300
  • Enterprise Manager 500

When you attempt to run the mkdisk utility to create the bootable USB thumb drive for EUD_B 11.3, the process fails and displays command options and switches as shown in the following output:
