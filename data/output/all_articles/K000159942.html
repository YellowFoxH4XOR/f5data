K000159942: Ramcache fails to update

Type
Support Solution
Published
2026-02-09
Updated
2026-02-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000159942

Description

The cache is no longer updated on the BIG-IP when HTTP request is forwarded to the backend server. The server correctly responds with “304 Not Modified”, but the BIG-IP does not update its cache accordingly. This means that the BIG-IP continues to send HTTP requests to the server instead of serving from its own cache.

Environment

  • BIG-IP LTM
  • BIG-IP WebAccelerator
  • RAM cache (Web Acceleration Profile) enabled on the virtual server

Cause

  • Bug alias 2208817, Web Acceleration RAMCACHE cache expiration not refreshed on 304 responses due to ID1620785 fix side-effect in v17.1.3+

Recommended Actions

Open a support case and request for an EHF to fix this bug.

Additional Information

Check BugTracker link to verify if your version affected.
