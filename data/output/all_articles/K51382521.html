K51382521: Unable to discover ASM device from BIG-IQ with error: Failed to check for running service tasks

Type
Support Solution
Published
2021-04-01
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IP
  • BIG-IP ASM: 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.X.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K51382521

Description

  • Unable to discover/import ASM device configuration onto BIG-IQ
  • An error similar to the following can be seen on GUI

    Failed to check for running service tasks: Task https://localhost/mgmt/cm/security-shared/tasks/discover-config/69dafb55-dc0e-4e44-a93f-50d393f25e74 is still in process, wait for this task to complete

Environment

  • BIG-IQ CM
  • BIG-IP ASM

Cause

Import tasks are stuck.

Recommended Actions

Restart the restjavad service

  1. Connect to BIG-IQ CM CLI
  2. Restart restjavad

    bigstart restart restjavad

Additional Information

None
