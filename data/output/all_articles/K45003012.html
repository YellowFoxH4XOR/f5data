Description
BIG-IP logs errors when posting a second Declarative Onboarding declaration. This occurs if the declaration is identical to the initial, or a change is made to the declaration.

# tail -f /var/log/restnoded/restnoded.log  | grep 01070597

finest: [f5-declarative-onboarding: restWorker.js] tryUntil: retryOrReject: numRemaining: 30 , code: 400 , message: 01070597:3: Monitor /Common/http is read only.
severe: [f5-declarative-onboarding: gslbHandler.js] Error creating Monitors: 01070597:3: Monitor /Common/http is read only.
severe: [f5-declarative-onboarding: gslbHandler.js] Error processing GSLB declaration: 01070597:3: Monitor /Common/http is read only.
severe: [f5-declarative-onboarding: declarationHandler.js] Error processing declaration: 01070597:3: Monitor /Common/http is read only.

Environment

  • Declarative Onboarding v1.25.0
  • Posting a second Declarative Onboarding declaration that is identical to the initial, or a change is made to the declaration.

Cause
Unknown at time of publication. 

Recommended Actions
You can workaround it by running clear-rest-storage command.
Impact of workaround: This will remove existing RPMs including the Declarative Onboarding RPM and will need to be reinstalled.

  1. Run clear-rest-storage command.
    # clear-rest-storage

    <Sample output>
    Stopping restnoded
    Stopping restjavad
    Removing storage files
    Removing index files
    Starting restjavad
    Starting restnoded
     
  2. Reinstall Declarative Onboarding
  3. Post the declaration
