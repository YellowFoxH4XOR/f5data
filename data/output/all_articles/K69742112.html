Description

You may find the below error message occasionally when you are performing configuration synchronization operations

  • Error messages: 

    01071aea:4: CMI heartbeat timer expired, status: x.x.x.x

Environment

  • Configuration Synchronization
  • BIG-IP LTM
  • HA or DSC

Cause

The MCPD might be busy with configuration saving and loading so that a single time of heartbeat might be expired.

Recommended Actions

The log message can be safely ignored if it only happens during the configuration synchronization operations.

You may verify the configuration synchronization event by refer to: K34291400: Understanding ConfigSync log messages

None
