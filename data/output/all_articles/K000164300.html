K000164300: Unable to upload the GEO-IP DB into BIG-IQ

Type
Knowledge
Published
2026-11-18
Updated
2026-11-18
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.2
Source
https://my.f5.com/manage/s/article/K000164300

Description

Uploading a GEO-IP database package through the BIG-IQ GUI fails with the following warning:

Error: An upload with the same file name is already taking place.

The upload does not complete even after the package is re-downloaded.

Environment

  • BIG-IQ Centralized Management 8.4.2
  • Standalone BIG-IQ device
  • Feature: GEO-IP database package management
  • Upload path: Configuration > GEO-IP Database Management > Add GeoIP Database

Cause

A stuck or already running upload task in the restjavad service prevents the new .zip upload from completing.

Answer/Recommended Actions

  1. Verify the MD5 checksum of the GEO-IP .zip file in the CLI. Refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.
  2. If the checksum does not match, download the .zip and .md5 files again from F5 Downloads, using the same package version. Confirm that both files come from the same download.
  3. Upload the .zip file and the .md5 file through Configuration > GEO-IP Database Management > Add GeoIP Database, then click Save & Close.
  4. If the upload stays in progress or does not complete, restart restjavad from the BIG-IQ CLI:
    bigstart restart restjavad
  5. Retry the upload and confirm that the database package is saved and can be distributed to managed devices.
