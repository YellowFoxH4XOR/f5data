Description

Upgrade vCMP guest failed with error message 

01071008:3: Provisioning failed with error 1 - 'Memory limit exceeded. <#> MB are required to provision these modules, but only <#> MB are available.' . Unexpected Error: Loading configuration process failed

Environment

  • vCMP guest 
  • v11.x and above
  • Installed new image or install point release and Engineering Hotfix.
     

Cause

This error means lack of memory allocated to the guest. Depending on the version and releases, required memory size is different by module combination.
Note: Memory allocation to the guest is defined by numbers of core allocated to the guest, and the ratio memory and numbers of core is different based on the platform/blade. Please refer further details for your platform/blade to K14218: vCMP guest memory/CPU core allocation matrix. 
 

Recommended Actions

  1. Check vHost system if there are unused core, if there are allocate more core to the guest.
  2. Consider combination of provisioned modules and the level. When you make module provision minimum, then required memory will be reduced.
  3. Check the version you upgrading to is supported. Please refer: K14088: vCMP host and compatible guest version matrix
     

Additional Information

This memory allocation is not related how many memories are used or reserved. Checking command output of tmsh show sys memory is not related.
