Known Issue

This is the result of a known issue. Editing an export after using the browser's Back button will cause the ARX Manager GUI to dump core.

For example, if you select an export, and click the Edit button, the Edit Export page will display. If you click a selection on the left navigational menu, you will navigate away from the Edit Export page. If you then use your browser's Back button to return to the Edit Export page, and press the OK button to apply changes, the ARX Manager GUI will become unresponsive and dump core. In addition, the changes you attempted will not be applied.

Important: ARX system traffic is unaffected and will continue normally. The ARX Manager GUI operation is affected; however, the ARX system can still be configured from the command line.

F5 Product Development tracked this issue as ARX ID 35266 and it was fixed in ARX version 5.0.5. For information about upgrading, refer to the ARX release notes.

Note: Using the browser's Back button on an ARX system running a fixed version will no longer lead to the ARX Manager GUI becoming unresponsive and dumping core; however, using the browser's Back button is still not recommended.

Workaround

To work around this issue, do not use the browser's Back button when navigating in the ARX Manager GUI.

To restore ARX Manager GUI functionality, you must reload the ARX system. To do so, perform the following procedure:

  1. Log in to the ARX command line.
     
  2. Enter Privileged mode by typing the following command:

    enable
  3. Reload the ARX system by typing the following command:

    reload

    A Reload the entire chassis? prompt will be displayed.
     
  4. At the Reload the entire chassis? prompt, type Yes.
