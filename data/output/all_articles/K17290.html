Known Issue

BIG-IP GTM wide IP alias updates may use varying degrees of memory.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is configured with wide IP aliases.
  • You add, delete, or modify wide IP aliases using the Configuration utility or the Traffic Management Shell (tmsh).

Impact

A small amount of memory used to perform the wide IP alias action is not returned to the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When adding, deleting, or modifying wide IP aliases, each action causes the amount of memory that the zrd process uses to increase slightly.
  • When adding, deleting, or modifying hundreds or thousands of wide IP aliases, the amount of memory that the zrd process uses can be significant.
  • In extreme memory utilization scenarios, the BIG-IP GTM system may experience performance degradation (over time) and reboot.

Workaround

To work around this issue, you can restart the zrd process to clear the excess utilized memory. To do so, perform the following procedure:

Impact of workaround: ZoneRunner DNS resolution will be temporarily unavailable while the zrd process restarts.

  1. Log in to the command line of the affected device.
  2. To restart the zrd process, type the following command:

    bigstart restart zrd
