K000151170: Sync Failed after update

Support Solution

  • BIG-IP LTM: 16.1.2, 16.1.0, 16.1.1, 17.5.0, 17.1.2, 17.1.1, 17.1.0, 16.1.5, 16.1.4, 16.1.3, 16.1.6
  • BIG-IP APM: 16.1.2, 16.1.0, 17.5.0, 16.1.1, 17.5.X, 17.1.2, 17.1.1, 17.1.0, 16.1.6, 16.1.5, 16.1.4, 16.1.3
Source
https://my.f5.com/manage/s/article/K000151170

Description

Sync fails after upgrade.

Similar errors seen in ssh session and/or LTM logs:

crit tmsh[5287]: 01420001:2: Can't create temp directory, /var/system/tmp/tmsh/tvmXm3, errno 28] No space left on device : framework/TempDir.cpp, line 211

and

err diskmonitor[7458]: 011d0004:3: Disk partition /config has only 2% free"

 

Environment

Recently upgraded

APM installed

 

Cause

Multiple EPSEC packages installed filling up the config partition.

 

Recommended Actions

Remove any EPSEC packages installed.

Sync the devices.

Re-install any necessary EPSEC packages.

 

Additional Information

None
