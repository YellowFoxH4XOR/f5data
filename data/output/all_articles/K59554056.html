Description

Network Map feature in the configuration GUI fails to load properly.

  • Loading the Network Map from the GUI (also known as the Configuration utility)
  • The text appears to be garbled

Environment

  • Upgraded to BIG-IP 13.1.0
  • Network Map in the Configuration utility
  • Seen in the following browsers:
    • Microsoft Edge
    • Mozilla Firefox

Cause

A local browser cache issue causes the Network Map to fail to display as expected.

Recommended Actions

Clear the local browser cache.

For more information about clearing the Microsoft Edge and Mozilla Firefox browser cache, refer to:

  • View and delete browser history in Microsoft Edge
  • How to clear the Firefox cache
