For the 1500, 3400, 3410, 6400, 6800, 8400, and 8800 BIG-IP platforms, you can reboot and power on and off the BIG-IP system using the Switch Card Control Processor (SCCP). For the 1600, 3600, 3900, 6900, 8900, 8950, and 11050 platforms, refer to K9403: Overview of the AOM subsystem.

Note: For general information about the SCCP, refer to K3454: Overview of the SCCP. If you have not yet configured the SCCP, refer to K3753: Configuring the switch card control processor so that it can be accessed over the network.

To reboot the BIG-IP system remotely, perform the following procedure:

  1. Using SSH, log in to the SCCP with the root account.
  2. Type the following command:

    hostconsh
  3. Press the Esc, Shift, and 9 (Esc-Shift-9) keys.

    You will see the following menu:

    [hostconsh] Command Menu:
    1 --- Connect to Host subsystem console
    2 --- Select Host subsystem boot mode: boot from local drive
    3 --- Select Host subsystem boot mode: netboot from SCCP
    4 --- Select Host subsystem boot mode: netboot from external server
    5 --- Reboot Host subsystem (sends reboot command)
    6 --- Halt Host subsystem (sends halt command)
    7 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!)
    8 --- Reboot SCCP subsystem (issues hardware reset--USE WITH CARE!)
    9 --- Halt SCCP subsystem (issues hardware shutdown--USE WITH CARE!)
    B --- SCCP baud rate configuratorL --- SCCP login
    N --- SCCP network configuratorYou are now logged in to the SCCP.
  4. To select the Reboot Host subsystem option, type 5.
  5. To select the Halt Host subsystem option, type 6.

Note: If the remote BIG-IP system is unresponsive and the reboot and halt options do not work, type 7 to select the Reset Host subsystem option to force a BIG-IP hardware reboot.
