K000151131: 011f0016:3: http_handle_pipelined_data - Invalid action:0x107000 Server sends too much data. serverside

Type
Support Solution
Published

Applies to

Source
https://my.f5.com/manage/s/article/K000151131

Description

Users unable to download certain PDF files and ltm logs show:

/var/log/ltm

err tmm6[28353]: 011f0016:3: http_handle_pipelined_data - Invalid action:0x107000 Server sends too much data. serverside (10.10.10.1:443 -> 172.26.1.2:32815) clientside (1.1.1.1:75561 -> 1.2.3.4:443) (Server side: vip=/Common/myVS profile=http pool=/Common/myPool= 10.10.10.1)

 

Environment

  • BIG-IP LTM
  • HTTP Profile
  • Downloading files

 

Cause

The message indicates that the response received from the back end server is not RFC compliant. According to HTTP RFC 7231 this is a violation, in the HTTP response (Essentially we have two HTTP responses in the same TCP re-assembled segment)

 

Recommended Actions

Unfortunately there no solution to be applied on the BIG-IP itself other than not applying any HTTP profile on the Virtual Server. However, it is advised to correct the backend servers making it compliant with RFC 7230.
