Description
BIG-IP receives an encrypted persistence cookie from the client and transmits a Cookie header with an empty cookie on the server side.

The cookie is corrupted, was encrypted with a different passphrase, or fails to decrypt for some other reason.

Environment

  • BIG-IP
  • Cookie persistence profile with encryption enabled

Cause
When BIG-IP fails to decrypt an encrypted cookie, it forwards the cookie to the server empty.

Recommended Actions
None.

Additional Information
Additional cookies with the same name received after the cookie which fails to decrypt are sent to the server unmodified.
