Known Issue

When you upgrade your system from BIG-IP 10.x to BIG-IP 12.1.0 or later, the required virtual address Spanning option may not be enabled.

This issue occurs when all of the following conditions are met:

  • Your system is running BIG-IP 10.x.
  • You have a virtual address with address resolution protocol (ARP) disabled.
  • You upgrade directly to BIG-IP 12.1.0 or later.

Impact

Environments that require spanning do not process traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Prior to upgrading, the virtual address is configured with ARP disabled. After you upgrade, the virtual server address is still configured with ARP disabled; however the virtual server address does not have the required Spanning option enabled.

Resolution

Status

F5 Product Development has assigned ID 640395 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can upgrade from  BIG-IP 10.x to an intermediate version (BIG-IP 11.x) and then upgrade to BIG-IP 12.1.0 or later. Alternatively,  after upgrading the system, you can manually modify the virtual server address to enable spanning. To manually enable spanning, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Address List.
  3. Click the affected virtual server address.
  4. Under Configuration, select the Spanning check box to enable spanning.
  5. Click Update.
