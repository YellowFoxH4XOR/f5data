Topic

You should consider using this procedure under the following condition:

  • You want to view all configured iRules of your BIG-IP LTM system.

Description

When administering a BIG-IP LTM system, it is useful to be able to recursively view all configured iRules. The procedures in this article show you how to view iRules configured on the following:

  • the default /Common partition
  • non-default partitions

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP command line or TMOS Shell (tmsh).

Procedures

  • View configured iRules across all partitions
  • View configured iRules of the default /Common partition
  • View configured iRules for individual non-default partitions


View configured iRules across all partitions.

The following tmsh command recursively lists all the configured LTM iRules across all configured partitions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Use the following command to view all configured iRules across configured partitions:

    tmsh -q -c "cd / ; list /ltm rule  recursive"

    Note: The output from this command can be verbose. Use the more command to page through the output. For example: tmsh -q -c "cd / ; list /ltm rule  recursive" | more


View configured iRules of the default /Common partition

The following tmsh commands lists all the configured LTM iRules of the default /Common partition:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Enter the following command to list the configured iRules:

    tmsh list /ltm rule all

Alternatively you can log in to tmsh and enter the following command:

  • list /ltm rule all

View configured iRules for individual non-default partitions

The following tmsh commands list all the configured LTM iRules for a specified non-default partition:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Use the following command syntax to list the configured iRules of the specified partition:

    tmsh list /ltm rule /<partition name>/*

    Note: In the command syntax, the last character is the wildcard (*) that lists all iRules of the partition.

    For example:

    tmsh list /ltm rule /Sales/*

Alternatively you can list the configured iRules of the partition from within tmsh:

  1. Log in to tmsh.
  2. Change partitions to the partition you want by entering the following command:

    cd <partition name>

    For example:

    cd Sales/

    Note: The prompt changes to the partition name to indicate the partition change.

  3. Enter the following command to see iRules for the specified partition:

    list /ltm rule all

  4. To exit tmsh enter the following command:

    quit
