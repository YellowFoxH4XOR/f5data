Known Issue

This is the result of a known issue. By default, the LDAP application health monitor follows referrals and references when they are returned in response to a query. There is no monitor setting by which this behavior can be disabled.

F5 Product Development tracked this issue as CR116377 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.
