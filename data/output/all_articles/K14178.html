Issue

Error Message

simple_syslog failed (no connection to syslog available - unix dgram connect: Connection refused at /usr/lib/perl5/site_perl/F5/Syslog.pm line 39) at /usr/lib/perl5/site_perl/F5/Syslog.pm line 45

Message Location

You may encounter this message in the following locations:

  • The Configuration utility
  • The /var/log/configsync_peer.log file

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP system is part of a high available pair
  • The high available systems are licensed and provisioned with either ASM or PSM
  • The syslog-ng process is not running on one of the high available systems
  • The ConfigSync process is either:

    • pushing the configuration to the BIG-IP system on which the syslog-ng process has stopped (the Synchronize TO Peer option)
    • pulling the configuration from the BIG-IP system on which the syslog-ng process is running (the Synchronize FROM Peer option)

The Configuration utility reports the error message when the ConfigSync process is initiated from either system. Additionally, when the ConfigSync process is initiated from the system on which the syslog-ng process is running, the error message is logged to the /var/log/configsync_peer.log file. In both scenarios, the ASM/PSM configuration is synchronized successfully.

This issue does not affect BIG-IP ASM and PSM systems running version 11.x due to architectural changes in the ConfigSync process.

Impact

None.

Recommended Actions

To prevent the systems from reporting this error message, you must ensure that the syslog-ng process is running on all of the high available systems. To do so, perform the following procedure:

Impact of procedure: None.

  1. Log in to the command line on the system that has stopped the syslog-ng process.
  2. Start the syslog-ng process by entering the following command:

    bigstart start syslog-ng
