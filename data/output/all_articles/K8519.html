Topic

When switchboard failsafe is enabled on the BIG-IP system, LACPDU packets are exchanged between internal links to monitor the switchboard hardware. If no LACPDU packet is received during the timeout period, the link is declared unavailable and the switchboard failsafe action is triggered. The default switchboard failsafe action is:

  • BIG-IP 10.0.0 - 11.1.0: Go Offline Abort TMM
  • BIG-IP version 9.4.0 - 9.4.7: Fail Over and Restart TMM
  • BIG-IP version 9.0.0 - 9.3.1: Fail Over and Abort TMM

The switchboard failsafe action causes the BIG-IP system to fail over to the standby system and restart the TMM process. Before the system restarts the TMM process, the system generates a TMM core file that F5 Technical Support can use to determine the cause of the switchboard failsafe action. The core file size that the system generates is determined by the total amount of memory allocated to TMM.

For example, if the amount of memory allocated to TMM is 2 GB, and the BIG-IP system initiates the switchboard failsafe action, the BIG-IP system generates a 2 GB core file, compresses the core file, and saves it to the /shared/core directory.

Note: To determine the total amount of memory allocated to the TMM process, use the bigpipe memory command.

If the amount of memory allocated to TMM is 2 GB or more, it can take several minutes to generate and save the core file. The BIG-IP system that generates the core file cannot become the active BIG-IP system until the core file is saved to the hard drive, and restarts the TMM process.

Changing the switchboard failsafe action

If your BIG-IP system has a large amount of memory, and you do not want the system to generate a core file during system failsafe, you can change the failsafe action by performing the following procedure:

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click High Availability.
  4. Select System from the Fail-safe menu.
  5. Select a setting other than the default failsafe action for your version from the Switch Board Failure drop-down menu.
  6. Click Update.
