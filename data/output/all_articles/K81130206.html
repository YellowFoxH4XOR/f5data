Topic

You should consider using this procedure under the following condition:

  • You want to determine the scope of all objects for a custom role in the BIG-IQ system.

Description

The BIG-IQ system allows you to create custom user roles, so you can tailor permissions of your administrative users to fit your business needs. You assign a custom role with a custom role type and a custom resource group.

When managing BIG-IQ roles, you may need to review the scope of all objects in custom roles. To do so, you can access the role properties page to view objects and object type permissions.

Objects list and Object Types list

When viewing a custom role's permissions, you can display:

  • The Objects list that contains specific object instances assigned from the custom resource groups.
  • The Object Types list that contains object categories assigned from the custom role type.

The associated object type must be assigned for the user to access an object instance. For example, if a BIG-IP DNS data center named DC1 is in the Objects list, the Object Types list must contain Data Centers.

Conversely, the associated object instance must be assigned for the user to access it from the object types they have permissions to see. Continuing with the previous example, if the BIG-IP DNS data center named DC1 is not in the Objects list, the user can access the Data Centers area of the user interface, but they will not see the DC1 instance.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have Administrator privileges for the BIG-IQ user interface.

Procedures

View objects and object type permissions for custom roles

You can review the scope of all objects for custom roles by accessing the role properties page.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ user interface.
  2. Go to System > ROLE MANAGEMENT > Roles.
  3. From the Roles page, in the left menu, expand the CUSTOM ROLES list.
  4. Select Service Roles.
  5. In the Custom Service Roles pane, select a custom role from the list.
  6. Scroll to the bottom of the custom role page and select View Permissions.
  7. Select Objects in the list to view the role's permissions for specific object instances, such as a the BIG-IP DNS data center named DC1. These are assigned by custom resource groups.
  8. Select Object Types to view the role's permissions for object categories, such as Data Centers or Client SSL Profiles.

    Note: For more details about the how the Objects list and Object Types list relate to each other, refer to the Objects list and Object Types list section.
