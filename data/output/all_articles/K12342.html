Known Issue

This is the result of a known issue. The BIG-IP ASM 10.2.0 Policy Builder may learn entities from within a FORM tag in an HTTP response and incorrectly add them to the policy.

For example:

form name="input" action="html_form_action.asp" method="get"> <input size="20" name="userfile" type="file">       <SELECT NAME="id_it">     <OPTION VALUE="014"></OPTION>     <OPTION VALUE="11">Item1</OPTION>     <OPTION VALUE="91">Item2</OPTION>   </SELECT> <input name="action" value="first12" type="hidden">

When processing the example HTTP response, the Policy Builder may learn the following URL and add it to the policy:

html_form_action.asp

In addition, the Policy Builder may learn the following entities as parameters and add them to the policy:

  • userfile
  • id_it
  • action

F5 Product Development tracked this issue as ID 339553 and it was fixed in BIG-IP 10.2.1.

This issue has also been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
