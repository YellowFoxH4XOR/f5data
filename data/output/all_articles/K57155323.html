Description

Failover occurred, and you can see similar to below log in /var/log/ltm: 

notice mcpd[<PID>]: 01070638:5: Pool /<partition>/<pool_name> member /<partition>/<pool_member_name>:<port_no(usually 0)> monitor status down. [ /<partition>/<monitor_name>: down; last error: ] [ was up for *hrs:*mins:*sec ]
...
err tmm*[<PID>]: 01010028:3: No members available for pool /<partition>/<pool_name>
...
warning sod[<PID>]: 01140029:4: HA pool_memb_down /<partition>/<pool_name> fails action is failover.

 

Environment

  • BIG-IP
  • Failover
     

Cause

This indicate Gateway fail-safe is triggered due to monitor failure for the gateway pool.

Recommended Actions

Check the pool_member (often gateway router) accessibility that time the above messages are logged.
 

Additional Information

    Gateway fail-safe
    With gateway fail-safe, the BIG-IP system monitors traffic between an active BIG-IP system in a device group and a pool containing a gateway router. Configuration for the pool is similar to below:

    ltm pool /<partition>/<pool_name> {
        gateway-failsafe-device /Common/<device_name>
        members {
            /Common//<partition>/<pool_member_name>:<port_no> {
                address <IP_address>
            }
        }
        min-up-members *   
        min-up-members-checking enabled    <<<------
        monitor /<partition>/<monitor_name>
    }

    You can also check if the Gateway fail-safe is enabled by the following command:

    tmsh show sys ha-status all-properties | egrep '(-----|Status|Feature|Enabled|pool-mbr-down)'


    The output should be similar to below:

    -----------------------------------------------------------------------------------------------------------------------
    Sys::HA Status
    Feature               Key              Action                        Fail  Feature  Take  Client  Proc          Timeout
                                                                               Enabled  Act   Data                  (sec)
    -----------------------------------------------------------------------------------------------------------------------
    pool-mbr-down         <pool_name>    failover                      no    yes      no    1       mcpd          0
