Known Issue

If you modify the bigip.conf file and attempt to load the new configuration, you may receive an error similar to the following:

/config/bigip.conf: "Invalid service name htttp" in line 48

This is most likely the result of a known issue. The bigpipe verify command does not detect misspelled monitor names or monitors that do not exist. If you edit the bigip.conf file and misspell or do not include a monitor name, the bigpipe verify command will not report it.

When you load the erroneous configuration, BIG-IP will stop loading the file at the point at which the error occurs and will display an error. The system will then be running a partial configuration until you fix the error.

F5 Networks Product Development tracked this issue as CR28451 and CR41901.
