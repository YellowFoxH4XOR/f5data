K03858031: License is stuck in pending state after the manual reactivation is cancelled

Type
Support Solution
Published
2022-04-19
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K03858031

Description

The license assignment can not be deleted or revoked from BIG-IQ GUI.

Environment

  • BIG-IQ
  • Unable to delete or revoke license

Cause

License has already been applied to BIG-IP

Recommended Actions

If license has been directly applied on BIG-IP, then revoke the license from BIG-IP: K41458656: Reusing a BIG-IP VE license on a different BIG-IP VE system
You may attempt to remove the license from BIG-IQ using restcurl commands: K84120003: Remove license from BIG-IQ using restcurl

Additional Information

None
