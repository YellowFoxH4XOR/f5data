Topic

The auto_lasthop function does not work for TCP connections to self IP addresses.This behavior is expected because the auto_lasthop function is not built into the Linux kernel.

F5 Product Development tracked this issue as CR80661 and it was fixed in BIG-IP 9.6.0 For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator Release Notes.
