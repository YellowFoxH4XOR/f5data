Description

Upon upgrade from 15.1.5.1 to 17.1.1.2 iApps >> Application Services :: Applications LX page displays Not Found.


Environment

Upgrade to 17.1.1.2 with Application LX packages presented on a system.


Cause

ID1079817.


Recommended Actions

Once the customer is on 17.x remove all LX packages under iApps >> Package Management LX and then reinstall them starting with the AS3 package (f5-appsvcs), then installing the f5-appsvcs-templates for FAST.


The order is important - if FAST templates are installed or reinstalled before the AS3 the Applications LX cannot fetch them.


The actual configuration previously deployed using FAST on 15.x will remain on the device.
