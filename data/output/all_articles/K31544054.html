Known Issue

Extensive use of syntax-rich Tool Command Language (Tcl) commands may cause a long configuration load time.

This issue occurs when the following condition is met:

  • You have a long iRule that extensively uses syntax-rich commands, such as string or regex.

Impact

BIG-IP system performance may be degraded during loading, which may cause the system to stop responding.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Loading the configuration takes a long time.
  • CPU usage sharply increases and remains high during configuration loading.

Resolution

Status

F5 Product Development has assigned ID 713585 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, if you are extensively using string or regex matches, F5 recommends that you put the data to a list or array and use a simple algorithm to find a string match.

Impact of workaround: Using the suggested workaround should not have a negative impact on your system.
