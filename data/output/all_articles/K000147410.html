Description

  • You want to redirect a site to another site with specific path and query parameters.

 

Environment

  • F5® Distributed Cloud HTTP Load Balancer

 

Recommended Actions

  • Add a Route in the HTTP Load Balancer section.

  • Chose the Route Type as Redirect.

 

  • In the Redirect Parameters section of the route configuration page, separate the URL values into the following categories:
  1. Host
  2. Path
  3. Query Parameters (Replace All Parameters)
