Description

When we check Bug Tracker, we often see only "BIG-IP LTM" in Affected Product.

LTM functionality is provisioned automatically to allow creation of virtual servers, TCP profiles, and other functionality from LTM that is required to implement other-based (e.g. APM-based, ASM-based etc,,,) services. Even if you have only licensed or provisioned the APM module, the system may be affected by the Bug ID which have only BIG-IP LTM in Affected Product.


Environment

BIG-IP system


Cause

None


Recommended Actions

None


Additional Information

For example, please see Bug ID 966785.

Both Rate Shaping and Virtual Server functionality are provided by the LTM functionality in tmm, so ID966785 is classified as an LTM issue.

This is base functionality of all BIG-IP products so the system should be affected even if you have only licensed or provisioned the APM module.
