Known Issue

This is the result of a known issue. The Proxy Exclusion List setting is not aware of administrative partitions. As of BIG-IP 10.1.0, VLAN group objects reside in administrative partitions. This means that you can create a VLAN group in an administrative partition, and then give users the authority to view and manage the object in only that partition. Proxy exclusion is a VLAN group setting, so the partition restrictions should be in effect. However, the system does not prevent you from adding proxy exclusion for a VLAN group in another partition. Doing so may result in issues for the VLAN group.

For example, in the following configuration, the VLAN group named vlangrp_common exists in the common partition. If you change from the common partition to the partition_abc partition, most configuration parameters for the VLAN group are unavailable (because the vlangrp_common object resides in a different partition). However, it is possible to edit the proxy exclusion list for the vlangrp_common VLAN group from the partition_abc partition.

}
partition Common {
description "Repository for system objects and shared objects."
}
partition partition_abc {
default rd id 1
}
vlan internal {
tag 4093
interfaces 1.2
}
vlangroup vlangrp_common {}
self 10.10.65.11 {
netmask 255.255.255.0
vlan internal
allow default
}
