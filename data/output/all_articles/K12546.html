Topic

F5 has recently discovered and corrected a number of issues that affect customers running ARX version 5.2.0. F5 recommends that all customers currently running version 5.2.0 install the latest cumulative rollup hotfix available.

The following table lists the rollup hotfixes available for ARX version 5.2.0. Each hotfix lists the ID number and description for the issues fixed by the hotfix:

Note: These rollup hotfixes are cumulative. Therefore, each hotfix will contain the fixes included in the previous hotfixes.
