K48359203: The configuration containing the OCSP stapling profiles may fail to load after an upgrade

Type

Published

Applies to

Known Issue

The configuration containing the Online Certificate Status Protocol (OCSP) stapling profiles may fail to load after an upgrade.

This issue occurs when all of the following conditions are met:

  • You upgrade to BIG-IP 13.0.0.
  • You configure a Client SSL profile with OCSP stapling enabled.
  • The system is unable to find the issuer certificate from the certificate itself or from the chain certificate.

During the upgrade process, the BIG-IP system fails to associate the OCSP profile to the certificate because the system is unable to find the issuer certificate from the configured chain or certificate. 

Impact

The BIG-IP configuration fails to load after an upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The configuration fails to load.
  • When you attempt to load the configuration using the TMOS Shell (tmsh), you view an error message that appears similar to the following example:

    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all " - failed. -- 01071bb2:3: The issuer certificate (/Common/default.crt) does not match the certificate (/Common/rsa-valid.crt). Unexpected Error: Loading configuration process failed

Workaround

To work around this issue, you can modify the /config/bigip.conf file and replace the invalid chain with another certificate file that is a valid issuer of the certificate. To do so, perform the following procedure:

Impact of workaround: F5 recommends performing the following workaround during a maintenance window.

  1. Log in to the command line of the affected BIG-IP system.
  2. To create a backup copy of the /config/bigip.conf file, type the following command:

    cp /config/bigip.conf /config/bigip.conf.649315

  3. Use a text editor to open the /config/bigip.conf file.
  4. Locate the affected Client SSL configuration and replace the valid certificate file:

    Example affected Client SSL configuration:

    ltm profile client-ssl /Common/my_cssl6 {
        app-service none
        cert /Common/rsa-valid.crt
        cert-key-chain {
            rsa-valid_default {
                cert /Common/rsa-valid.crt
                chain /Common/default.crt
                key /Common/rsa-valid.key
                ocsp-stapling-params /Common/my_ocsp_stpl4
            }
        }
        chain /Common/default.crt
        defaults-from /Common/clientssl
        inherit-certkeychain false
        key /Common/rsa-valid.key
        passphrase none
    }

    Example updated Client SSL configuration with the valid certificate (valid_issuer.crt):

    ltm profile client-ssl /Common/my_cssl6 {
        app-service none
        cert /Common/rsa-valid.crt
        cert-key-chain {
            rsa-valid_default {
                cert /Common/rsa-valid.crt
                chain /Common/valid_issuer.crt
                key /Common/rsa-valid.key
                ocsp-stapling-params /Common/my_ocsp_stpl4
            }
        }
        chain /Common/valid_issuer.crt
        defaults-from /Common/clientssl
        inherit-certkeychain false
        key /Common/rsa-valid.key
        passphrase none
    }

  5. Save the changes to /config/bigip.conf file.
  6. To load the updated configuration, type the following command:

    tmsh load /sys config

Alternatively, you can resolve this issue by performing the following procedure:

  1. Complete steps 1 through 3 in the previous procedure.
  2. Locate the affected Client SSL configuration and remove the following line from the configuration:

    ocsp-stapling-params /Common/my_ocsp_stpl4

  3. Replace chain's /Common/valid_issuer.crt with none.
  4. Save the changes to the /config/bigip.conf file.
  5. To load the updated configuration, type the following command:

    tmsh load /sys config

  6. You can manually reconfigure the OCSP for the Client SSL profile. For more information, refer to K75106155: Configuring OCSP stapling (13.x - 14.x).
