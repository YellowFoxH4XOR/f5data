Known Issue

The system may use increased memory when you configure the system with anti-virus protection.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with Anti-Virus Protection and the Internet Content Adaptation Protocol (ICAP) profile.
  • Requests sent to the ICAP server exceed 128 KB.

Impact

The BIG-IP system uses increased memory (by the UMU memory buffer).

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you view memory utilization by the UMU memory buffer, you observe that the total allocated memory increases when large requests are sent to the ICAP server.

    For example, the following provides an example method to view UMU memory buffer utilization:

    /var/log/ts/bd.log | grep -i "UMU: total"

    BD_MISC|NOTICE|<date time>|<pid>|temp_func.c:3832|UMU: total 368888 (754M) VM (2196M) RSS (1394M) SWAP (232M) trans   227

Workaround

To work around this issue, you can modify how the BIG-IP ASM system processes large requests and concurrent requests. To do so, refer to K11434152: Configuring BIG-IP ASM to process large requests.

Impact of workaround: One of the steps outlined in K11434152: Configuring BIG-IP ASM to process large requests requires that you restart the asm service by using the tmsh restart /sys service asm command. Restarting the asm service temporarily stops BIG-IP ASM traffic processing.
