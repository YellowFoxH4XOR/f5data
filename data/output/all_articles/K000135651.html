K000135651: Change Docker Network from 100.64.0.0/10 (RFC6598) to 10.0.0.0/8 (RFC1918)

Type
Support Solution
Published
2023-08-24
Updated
2024-06-25
Applies to
  • F5OS
  • F5OS-A: 1.5.1, 1.5.0, 1.3.2, 1.2.0
Source
https://my.f5.com/manage/s/article/K000135651

Description

It is unable to change Docker Network from Predefined Network => 100.64.0.0/10 (RFC6598) to 10.0.0.0/8 (RFC1918)
Docker network is not updating as part of internal IP ranges configurations. With command: system network config network-range-type RFC prefix 1 :

k3s:

appliance-1# show system network
system network state configured-network-range-type RFC1918 
system network state configured-network-prefix 1
system network state configured-network-range 10.[16-31].0.0/16
system network state configured-chassis-id 1
system network state active-network-range-type RFC1918
system network state active-network-prefix 1
system network state active-network-range 10.[16-31].0.0/16
system network state active-chassis-id 1

[root@appliance-1 ~]# grep -v -E '^#|^$' /etc/sysconfig/chassis_network_active.txt
chassis_network_selection=1
chassis_id=1
network_prefix=10.16
network_range_type=RFC1918

Docker:

[root@appliance-1 ~]# docker network inspect bridge
[...]
"Subnet": "100.64.10.0/16",
"Gateway": "100.64.10.0"
}
 [...]

Environment

  • F5OS-A

Cause

Bug ID 1283641. For information about the fixed versions, refer to Bug ID 1283641.

Recommended Action

To change the docker bridge network apply the following procedure:

# Mount /usr with rw to modify some config files

mount -o remount,rw /usr

# Make a copy just in case

cp /usr/share/vanquish-config/docker /usr/share/vanquish-config/docker.bak

# Then manually edit the file with the desired network

vim /usr/share/vanquish-config/docker

For example:

## Original

OPTIONS=' --selinux-enabled    --log-driver=journald --log-level=error --selinux-enabled --signature-verification=false --ip=127.0.0.1 --bip=100.64.10.0/16 --host tcp://0.0.0.0:4243 --host unix:///var/run/docker.sock --signature-verification=False'

...

INSECURE_REGISTRY='--insecure-registry 100.64.0.0/16 --insecure-registry appliance-1.chassis.local:5000 --insecure-registry 10.0.0.0/8'

## Updated

OPTIONS=' --selinux-enabled    --log-driver=journald --log-level=error --selinux-enabled --signature-verification=false --ip=127.0.0.1 --bip=10.16.10.0/16 --host tcp://0.0.0.0:4243 --host unix:///var/run/docker.sock --signature-verification=False'

...

INSECURE_REGISTRY='--insecure-registry 10.16.0.0/16 --insecure-registry appliance-1.chassis.local:5000 --insecure-registry 10.0.0.0/8'

# Copy the file to /etc/sysconfig/docker

cp /usr/share/vanquish-config/docker /etc/sysconfig/docker

# Restart docker

systemctl restart docker.service
