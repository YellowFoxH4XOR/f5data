Known Issue

This is the result of a known issue. The clusterd process may leak memory on VIPRION systems. This issue occurs when the clusterd process reads certain MCP messages and stores the messages in memory indefinitely.

Note: The clusterd process controls the clustering technology for the VIPRION platform by sending multicast packets over the management backplane to other clusterd processes.

You can verify the clusterd memory utilization by running the ps command. For example, the following command output indicates that the amount of total memory consumed by the clusterd process is 18 MB:

ps -auxwf |grep clusterd

USER     PID    %CPU   %MEM     VSZ     RSS  TTY  STAT  START  TIME COMMAND
root     2591    0.2    0.2    18836   18828  ?    SL   09:20  0:00  |   \_ /usr/bin/clusterd

F5 Product Development tracked this issue as ID 349872 and ID 350982 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM release notes.

In addition, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
