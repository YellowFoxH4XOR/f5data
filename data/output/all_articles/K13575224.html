Known Issue

The mcpd process may restart when BIG-IP APM customization group template files are validated.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration contains advanced customizations.
  • The mcpd process encounters an error while performing either of the following:

    • A ConfigSync operation
    • A customization group template file modification using a Traffic Management Shell (tmsh) transaction

When you modify customization group template files using tmsh, or perform a configuration synchronization (ConfigSync), the BIG-IP APM system validates the customization group file objects. If the mcpd process encounters an error while performing either task, the validation process fails and causes the mcpd process to exit.

Impact

The BIG-IP system may temporarily fail to process traffic and fail over if configured as part of a high availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • An mcpd core file is generated to the /shared/core/ directory.
  • A failover occurs if the system is configured for HA.
  • In the /var/log/ltm file, you observe error messages similar to the following example:

    err mcpd[12395]: 01070734:3: Configuration error: Cannot apply template as cache path for (customization template file logon.inc customization group /Common/ap-example_act_logon_page_ag) cannot be empty
