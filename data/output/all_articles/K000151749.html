Description

In a BIG-IP LTM high availability (HA) setup, devices may show as synchronized, but Virtual Server (VS) configurations do not appear on the standby device. There are no error messages or log entries indicating a problem, and attempts to create new Virtual Servers and sync the configuration do not resolve the issue.

Environment

  • BIG-IP LTM
  • HA deployment with two devices
  • Use of multiple partitions

Cause

Virtual Servers and their associated partitions were configured with the "traffic-group local only" setting. This restricts these objects to the local device only, preventing them from being synchronized or appearing on the standby unit—even though device sync status reports as successful.

Recommended Actions

  1.  Check all Virtual Server addresses and partitions configurations for their traffic group assignment.
  2. Change any "traffic-group local only" assignments of Virtual Server addresses to a shared traffic group such as "traffic-group-1":-
    1. Navigate to Local Traffic >> Virtual Servers >> Virtual Address List, and select the Virtual Address for the Virtual Server that needs to be moved.
    2. Select the appropriate Traffic Group from the Virtual Address's Traffic Group drop-down selector.
    3. Click the Update button to save the change. 
  3. Now do change of traffic group for partitions :-
    1. Navigate to System ›› Users : Partition List, and select the Partition that needs to be moved.
    2. Select the appropriate Traffic Group from the Partition's Traffic Group drop-down selector.
    3. Click the Update button to save the change.
  4. Perform a configuration sync after updating traffic group assignments.
  5. Confirm that Virtual Servers are now visible and properly configured on both active and standby devices.
