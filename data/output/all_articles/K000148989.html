Description

How to add multiple IPs to IP Prefix Sets via XC console.

Environment

  • IP Prefix Sets
  • Multiple IPs
  • F5® Distributed Cloud Console

 

Recommended Actions

  1. Click on button to create/edit IP prefix set.

    • IP Prefixes from shared namespace can be managed in Home -> Shared Configuration -> Security -> Shared Objects -> IP Prefix Sets

    • IP Prefixes from system namespace can be managed in Home -> Multi-Cloud Network Connect -> Manage Firewall -> IP Prefix Sets

  2. Fill in the basic information (name, labels, description) and add one empty record:
  3. Switch tab to JSON view. Click on "JSON" button in the left upper corner.
  4. Prepare list of IPs in below format and add it to JSON (every record needs network mask). Check "Additional information" section to see example on how to prepare such data.
    {"ipv4_prefix": "1.1.1.1/32"},
    {"ipv4_prefix": "2.2.2.2/32"}

    Example: 
  5.  Click "Save and exit". That will create new prefix set.

 

Additional Information

To format easily IP list to required JSON form, you can use Visual Code Studio and follow steps below.

  1. Paste IP list to new file (one per line)
  2. Press "Ctrl + F", it will open a find box on the right upper corner.
  3. Click on "Use regular expression" (".*" button) and "Toggle replace" (">" button):
  4. Add network mask (/32) to all IPs that don't have it.
    Fill "Find" and "Replace" fields with below regular expressions and click "Replace all". 
    Find: ^[\.0-9]*$
    Replace: $&/32
  5. Use another regular expression to add needed formatting to all records.
    Find: .*
    Replace: {"ipv4_prefix": "$&"},
  6. Remove comma "," from last line, it's not needed. 
  7. IP list is ready to use.
