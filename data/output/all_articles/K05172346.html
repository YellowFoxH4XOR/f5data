Known Issue

The client connection limit for a Large Scale NAT (LSN) pool may incorrectly include mirrored connections.

This issue occurs when all of the following conditions are met:

  • A virtual server is configured with Connection Mirroring enabled.
  • The virtual server is associated with an LSN pool.
  • The LSN pool is enabled with the Client Connection Limit setting.
The Client Connection Limit setting in an LSN pool determines the maximum number of simultaneous translated connections a client or subscriber is allowed to have. The default value is zero, which disables the setting.

Impact

Clients or subscribers may fail to open as many connections as they are allowed.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A client or subscriber is unable to create as many connections as allowed.
  • The lsndb list client command output includes both the actual connection and the mirrored connection when reporting the number of active connections for a specific client or subscriber. You can determine the total number of connections including mirrored connections for a specific client or subscriber from the BIG-IP connection table using the tmsh show sys connection cs-client-addr <client/subscriber IP address> command syntax.

    For example, you observed that client 192.168.1.25 has a total of 4 active connections, including mirrored connections, from the lsndb list client command:

    LSN Client Connections
    Client                                              Connections
    -------------------------------------------------------------------------------------------------------------
    192.168.1.25                                         4
    1 client with 4 connections found.
        
    You can determine the total number of connections, including mirrored connections, for client 192.168.1.25 in the connection table using the tmsh show sys connection cs-client-addr 192.168.1.25 command:

    192.168.1.25:51162  10.40.1.1:20000  4.4.0.0:51162  10.40.1.1:20000  tcp  0   (slot/tmm: 1/2)  none
    192.168.1.25:51162  10.40.1.1:20000  4.4.0.0:51162  10.40.1.1:20000  tcp  97  (slot/tmm: 2/2)  none
    192.168.1.25:52912  10.40.1.1:20000  4.4.0.1:52912  10.40.1.1:20000  tcp  3   (slot/tmm: 2/0)  none
    192.168.1.25:52912  10.40.1.1:20000  4.4.0.1:52912  10.40.1.1:20000  tcp  97  (slot/tmm: 1/0)  none
