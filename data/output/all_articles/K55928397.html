K55928397: DO on BIG-IQ upgraded to 1.33.0-7 not working

Type
Support Solution
Published
2022-10-11
Updated
2026-01-09
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.1.0
Source
https://my.f5.com/manage/s/article/K55928397

Description

DO declaration fails with the following error:

        "result": {
            "class": "Result",
            "code": 422,
            "status": "ERROR",
            "dryRun": false,
            "message": "failed",
            "errors": [
                "Failed to complete onboarding task. code: 422, message: invalid config - rolled back, error: one or more properties must be specified"
            ]
        },

Environment

  • BIG-IQ 8.1.0.2
  • Declarative Onboarding v1.33

Cause

https://github.com/F5Networks/f5-declarative-onboarding/issues/325

Recommended Actions

Downgrade DO version to a working version, such as 1.32:

rpm -Uv /shared/tmp/f5-declarative-onboarding-1.32.0-3.noarch.rpm --oldpackage
Preparing packages...
f5-declarative-onboarding-1.32.0-3.noarch
f5-declarative-onboarding-1.33.0-7.noarch

tmsh restart /sys service restjavad restnoded

 

Alternatively, upgrade BIG-IQ to v8.2.x.

Additional Information

Verify the DO version installed:

curl http://localhost:8105/shared/declarative-onboarding/info
