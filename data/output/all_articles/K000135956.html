Description

Virtual server configured with server ssl profile gets the following reset cause:

BIG-IP: [0x3181641:3503] SSL error (unknown_ca(48))

Environment

  • Virtual server
  • Server ssl profile
  • Connection reset

Cause

In the server ssl profile, parameter name: Server certificate is set with 'Require'

Recommended Actions

Configure the server ssl configuration to meet the requirements, the default value is set  'Ignore':

  1. Go to: Local Traffic  ››  Profiles : SSL : Server  ›› <Server SSL Profile name>
  2. Under 'Server Authentication' section replace the Server certificate to be set with 'Ignore'

Additional Information

Using different Server SSL profile got different values.

When using "f5aas-default-ssl", it set by default for Server certificate with 'Require'.

While using 'serverssl' profile, the default for Server certificate is 'Ignore'.
