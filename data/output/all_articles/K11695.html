Known Issue

This is the result of a known issue. When the Enterprise Manager discovers a device that has a non-ASCII character in the description field of an administrative partition, or if such a partition is added to the configuration, the device is marked as Impaired. The device status, located on the Configuration utility Device screen, reports an error message that appears similar to the following example:

get_partition_list: iControl error: 'iControl::char*:SOAPException:
'Error while parsing SOAP XML payload: not well-formed (invalid token)''

For example, a partition that includes the è character (a lowercase e with a grave accent) will result in Impaired status:

partition Test {
description "La partition est très important"
}

F5 Product Development is tracking this issue as ID 291800 (formerly CR138709).

Workaround

You can work around this issue by using only basic ASCII characters in the description field of user-defined administrative partitions.

Note: For information about the contents of the ASCII character set, refer to the list of ASCII Printable Characters. This link takes you to a resource outside of AskF5; the third party could remove the document without our knowledge.
