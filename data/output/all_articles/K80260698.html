K80260698: Static content fails to load when accessing the virtual server with error: net: :ERR_CONTENT_DECODING_FAILED 200 (OK)

Support Solution

Description

When accessing the virtual server setup on BIG-IP, some static content from the server will fail to load on the webpage. 

  • When inspecting the HTTP data (HTTP request/response) in developer tool, the response contains below error:  

    net: :ERR_CONTENT_DECODING_FAILED 200 (OK)

  • Sometimes webpage will throw below error:

    HTTP Error 411. The request must be chunked or have a content length.

Environment

  • Standard virtual server

  • HTTP profile with Response Chunking set to 'selective' 

Cause

HTTP response is modified to due Transfer-Encoding header value is set to chunked. 

Recommended Actions

You can try changing the value of Response Chunking option in HTTP profile. 
  1. Log in to the Configuration utility.
  2. Select Local Traffic > Profiles > Services > HTTP.
  3. To create a new HTTP profile, select Create. Alternatively, you can select an existing profile to modify.

    Note: If you are using default HTTP profile, its suggested to create a custom HTTP profile with parent profile as HTTP. 
     
  4. If you are creating a new profile, enter a name for the profile, for Parent Profile, select http.
  5. Under Settings, set Response Chunking to unchunk. 
  6. Select Finished.

    Note: If you created a new profile, you must now associate it with the virtual server having issues.
