K6750: The BIG-IP ASM feature flag in the BIG-IP license can prevent use of multiple nodes in the pool

Known Issue

This is the result of a known issue. On a BIG-IP LTM system licensed with BIG-IP ASM, the license file contains feature flag elements for both the BIG-IP LTM and BIG-IP ASM modules. The mod_ltm feature flag allows for unlimited pool members, and the mod_asm feature flag limits the number of pool members to one member.

Currently, the feature flag library uses the first module that occurs in the license file to determine the number of allowable pool members. Therefore, if the mod_asm feature flag occurs before the mod_ltm feature flag, the license can prevent the use of multiple nodes in the pool.

If your BIG-IP system is using the mod_asm feature flag, the following message will appear after you type the b load command:

Loading the configuration ...
BIGpipe: HTTP class profile creation error:
01070617:3: Not licensed for multiple pool members (test_pool)

F5 Product Development tracked this issue as CR59292 and it was fixed in BIG-IP ASM 9.2.3. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

If upgrading is not an option, you can work around this issue by obtaining a new license from the license server. The feature flags will be listed in their proper order in the new copy of the license. To reactivate the BIG-IP license, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click System.
  3. Click License.
  4. Click the Re-activate License button.
  5. Choose either the Automatic or the Manual activation method and follow the steps to reactivate the license.
