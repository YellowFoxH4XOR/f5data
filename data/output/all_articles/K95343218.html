Description
The following message is repeatedly observed at the command line after the upgrade:
Re-starting tomcat
Re-starting tomcat
Re-starting tomcat
Re-starting tomcat
Re-starting tomcat

Environment

  • BIG-IP ASM is provisioned
  • Upgrade to version 14.x or 15.x
  • datasyncd show multiple logs similar to this:
    |29370|datasyncd_main.c:1517|is_generator_running: generator process (10202) for table CS_ASM_DOSL7 does not exist anymore
    |29370|datasyncd_main.c:1517|is_generator_running: generator process (16854) for table CS_ASM_DOSL7 does not exist anymore
    |29370|datasyncd_main.c:1517|is_generator_running: generator process (30347) for table CS_ASM_DOSL7 does not exist anymore
    |29370|datasyncd_main.c:1517|is_generator_running: generator process (17597) for table CS_ASM_DOSL7 does not exist anymore
  • Top command output show multiple processes like the following one:
    /usr/lib/jvm-64/jre/bin/java -jar -XX:-UseLargePages -XX:-UseSplitVerifier -Xss1024k -Xms32m -Xmx128m -XX:MaxPermSize=16m -XX:Re

Cause
This is a known issue tracked under ID 920301.

Recommended Actions

Upgrade to a fixed version. Refer to the bug tracker of ID 920301 for Fixed versions.
