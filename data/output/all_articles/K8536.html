Known Issue

This is the result of a known issue. If a user connects to the FirePass alternate webtop using Internet Explorer 7 (IE7), and an application on the client system opens a web page using IE7, the page may open as a tab in the Network Access (alternate webtop) window instead of opening in a new browser window.

Note: You can enable the alternate webtop by selecting the Use Alternate Webtop check box on the Network Access: Resources page under the Client Settings tab. When you enable the alternate webtop option, FirePass automatically launches a user’s Network Access connection upon successful authentication.

This issue occurs when the following two conditions are met:

  • The user connects to the FirePass controller using IE7 for Windows Vista.
  • The web page opened by the client application belongs to the same IE7 security zone as the FirePass controller. For more information about IE7 security zones, refer to the Microsoft IE7 documentation.

Note: For more information about using tabs in IE7, refer to the following website:
http://www.microsoft.com/windows/IE/ie7/tour/tabs/how.html

F5 Networks Product Development tracked this issue as CR88728 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-601-9 has been issued for FirePass version 6.0.1 and Cumulative Hotfix HF-602-2 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
