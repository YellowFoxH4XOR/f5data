Description

You need to understand how an HTTP Load Balancer (LB) in F5 Distributed Cloud handles Host headers, and what value is forwarded to the origin server.

 

Environment

  • F5 Distributed Cloud HTTP Load Balancer

Cause

By default, the F5 Distributed Cloud HTTP LB will perform Host Rewrite when the Origin Server is defined by a DNS name.

For example:
  • If the origin server is defined as appserverpool.pop1.example.com and the incoming client request has the Host header host: myapp.example.com, the request will be forwarded to the origin with Host: appserverpool.pop.example.com.

Recommended Actions

Key points: 

  • SNI Selection: Typically, when Host Rewrite is enabled, it is recommended to retain the default SNI Selection setting on the Origin Pool as ‘Host header.’ Changing this setting could lead to an SNI/Host mismatch and result in a 421 response from the origin server.
  • Default Origin Pool: Host Rewrite applies when the Load Balancer is defined with a Default Origin Pool, referenced at the base LB configuration, not within a Route.
  • No Host Rewrite for IP-based Origins: When the origin server is defined by an IP address, Host Rewrite is not performed, as it would not make sense to rewrite the Host header to an IP address.

If Host Rewrite is inappropriate for the application (i.e., the application responds correctly when the Host header is set to Host: myapp.example.com), you need to configure a Route to override the Host Rewrite behavior.

  • Configure a Simple Route: Set up a route on the LB with match conditions that apply to all requests (for example, prefix match on /).
  • Disable Host Rewrite: Use the disable_host_rewrite setting to retain the client’s Host header in the request sent to the origin.

Additional Information

  • The key setting to modify is "disable_host_rewrite"
  • This will result in the Host header presented by the client being retained in the request sent to the origin.
  • It is usually acceptable to keep the default SNI selection as Host Header in the origin pool.

Example:

  • If disable_host_rewrite is enabled, an incoming request with Host: myapp.example.com will forward the same Host header to the origin
