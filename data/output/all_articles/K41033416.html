Description
Hardware BIG-IPs are capable of not only passing and manipulating Class of Service indicators (802.1p or  DSCP), it can also prioritize egress packets based on either 802.1p or DSCP.
This document describes configuring Class of Service.

Environment

  • Supported BIG-IP version on BIG-IP hardware platforms
  • external network supporting Class of Service via 802.1p or  DSCP

Recommended Actions

  1. Create Traffic Priority definitions and assign relative weight to those definitions
     
    net cos traffic-priority Priority1 {
        weight 1
    }
    net cos traffic-priority Priority2 {
        weight 2
    }
    net cos traffic-priority Priority3 {
        weight 3
    }
    net cos traffic-priority Priority4 {
        weight 4
    }
    net cos traffic-priority Priority5 {
        weight 5
    }
    net cos traffic-priority Priority6 {
        weight 6
    }
    net cos traffic-priority Priority7 {
        weight 7
    }
    net cos traffic-priority Priority8 {
        weight 8
    }
  2. Create mappings for either 802.1p or DSCP
     
    net cos map-8021p 802.1p-0 {
        traffic-priority Priority1
    }
    net cos map-8021p 802.1p-1 {
        traffic-priority Priority2
        value 1
    }
    net cos map-8021p 802.1p-2 {
        traffic-priority Priority3
        value 2
    }
    net cos map-8021p 802.1p-3 {
        traffic-priority Priority4
        value 3
    }
    net cos map-8021p 802.1p-4 {
        traffic-priority Priority5
        value 4
    }
    net cos map-8021p 802.1p-5 {
        traffic-priority Priority6
        value 5
    }
    net cos map-8021p 802.1p-6 {
        traffic-priority Priority7
        value 6
    }
    net cos map-8021p 802.1p-7 {
        traffic-priority Priority8
        value 7
    }
     
  3. In the Class of Service Global Settings, set the default traffic priority, define the default map source as either 802.1p or DSCP, and populate the default mappings.
    You also enable the Class of Service feature at this stage.
     
    net cos global-settings {
        default-map-8021p {
                             /Common/802.1p-0
                             /Common/802.1p-1
                             /Common/802.1p-2
                             /Common/802.1p-3
                             /Common/802.1p-4
                             /Common/802.1p-5
                             /Common/802.1p-6
                             /Common/802.1p-7 }
        default-traffic-priority Priority1
    }

     

Additional Information

The 8 packet queues are drained in a round-robin fashion, and the number of packets sent from each queue is specified by the Traffic Priority weight assigned to the queue.
You can calculate the Traffic Priority ratio for a queue by dividing the weight of a single queue by the sum of the weights of all queues.

From the above configuration, the weights (1+2+3+4+5+6+7+8) sum to 36. This means that for Priority8, the ratio will be 8/36, or ~22%
