Description

Sudden CPU spikes on DNS provisioned BIGIP.
TMM port exhaustion events found in /var/log/ltm logs

 

Environment

  • BIGIP DNS
  • CPU spikes


Cause

Possible DNS flood attack

K33355231: Error Message: 01010201:2: Inet port exhaustion on <ip_address> to <ip_address:port> (proto <protocol>)


Recommended Actions


Investigate the increased number of queries sourced by a given IP address

 

A high number of incoming DNS connections cause the CPU to rise to a high level.
You can identify IP addresses directly involved using the following command:

zcat /var/log/ltm* | grep 'Inet port' | awk '{print$14}' | sort | uniq -c
 

Consider enabling DoS/DDoS protection via the article:
K14813: Detecting and mitigating DoS/DDoS attacks (11.4.x - 16.x)
 

Additional Information
