Description

Attempts to remove a add-on license key from an F5OS VELOS chassis or an F5 rSeries appliance are unsuccessful.

When reactivating the license and removing a add-on key, the license reloads with the add-on key still present.

Environment

  • F5OS-C (VELOS)
  • F5OS-A (rSeries)
  • Add-on License

Cause

F5OS does not support the removal or deactivation of add-on license keys (such as FIPS) from an existing license. Unlike BIG-IP, there is no feature in F5OS to deactivate or retire add-on key directly from the system.

Recommended Actions

Important: While F5OS does not support manual removal of add-on keys before expiration, expired add-on keys (including evaluation add-ons) are automatically removed upon license reactivation.

 

  1. If the add-on key has already expired

Expired add-on keys (including evaluation add-ons) are automatically removed upon license reactivation. No manual intervention is required.

    • Wait until the add-on license has reached its expiration date.
    • Reactivate the license through the F5OS GUI or CLI.
    • The expired add-on will be automatically removed from the newly generated license file.

 

  1. If the add-on key has NOT expired, and you need to remove it
F5OS does not support the manual removal or deactivation of non‑expired add‑on license keys directly from the system.
