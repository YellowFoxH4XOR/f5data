Source

Description

Does TLSv1 work in NGINX Plus and Red Hat Enterprise Linux 8.9?

 

Environment

NGINX Plus and Red Hat Enterprise Linux 8.9

 

Cause

system-wide cryptographic policies in Red Hat Enterprise Linux 8.9

 

Recommended Actions

Set system-wide cryptographic policies to LEGACY

 

Additional Information

Even though the output of the command openssl ciphers -s -V command shows TLSv1 as supported, RedHat will prevent this protocol from being used if the system-wide cryptographic policies are set to other than LEGACY. You can check what's available on each policy by visiting this Red Hat link.
Likewise, Some suites on the list show SSLv3 in the protocol column. This is nothing to worry about. It only means that the suite is compatible with this old (and obsolete) protocol version. Your configuration will not downgrade to SSL 3.0 if these suites are used.
