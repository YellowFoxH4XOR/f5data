Known Issue

Changes to the Logging section of a BIG-IP WebAccelerator policy only take effect after the pvac process is restarted.

F5 Networks Product Development is tracking this issue as CR94338.

Workaround

After making changes to the Logging section of a BIG-IP WebAccelerator policy and publishing the updated policy, you must restart the pvac process by performing the following procedure:

Note: Restarting the pvac process using the bigstart restart pvac command may sometimes fail to apply the changes. F5 Networks recommends stopping then starting the pvac process.

  1. Log in to the BIG-IP WebAccelerator command line.
  2. Stop the pvac process by typing the following command:

    bigstart stop pvac
  3. Start the pvac process by typing the following command:

    Important: Restarting the pvac daemon will briefly disrupt connections and invalidate objects in the BIG-IP LTM RAM Cache. Restarting the pvac daemon should be scheduled accordingly.  

    bigstart start pvac
