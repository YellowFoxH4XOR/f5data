Known Issue

The VIPRION blade may fail to recover the Host PIC firmware automatically.

This issue occurs when all of the following conditions are met:

  • The VIPRION blade is one of the following types:
    • B4100 (A100)
    • B4200 (A107)
    • B4300 (A108)
  • An update to the Host PIC firmware failed.

Impact

The VIPRION blade is unable to boot properly and fails to join the cluster.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H427626 on the Diagnostics > Identified > Medium page.
  • The VIPRION blade is unable to boot properly
  • The Host PIC is in an inoperative state, which prevents the VIPRION blade from starting properly. In addition, you observe error messages during the boot process that appear similar to the following example:

    Unable to obtain slot via CAN. Attempting firmware recovery
    (may take up to 4 minutes)
    recovering CAN hostpic firmware unable to obtain slot (CAN status:4)
    error: unable to obtain slot over CAN : Unable obtain slot - reply status error

Resolution

Status

F5 Product Development has assigned ID 399323 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Type of fixFixes introduced inRelated articles
Release11.3.0K2200: Most recent versions of F5 software
Point release/hotfix11.2.1 HF8K9502: BIG-IP hotfix matrix

Workaround

Impact of workaround: Performing a clean installation on the affected blade will destroy all information on that blade and should be performed during a maintenance window if the affected blade is the only blade in the VIPRION system.

To recover from this issue, you can perform a clean installation on the affected VIPRION blade using BIG-IP 11.3.0 to recover the blade. To do so, perform the procedures described in K13117: Performing a clean installation of BIG-IP 11.x - 13.x or Enterprise Manager 3.x.
