Description

Remote Desktop RDP resources are missing on the webtop after upgrading to version 15.1.2.x / 15.1.3

Environment

  • BIG-IP APM with RDP resources configured and assigned in the access policy

Cause

Bug ID 1007869: Upgrade from v14.1.x to v15.1.2.1 or later fails for app-tunnel, RDP and config migration

Recommended Actions

There is no fix available for it yet.

However, you can workaround the issue by going through the affected Advanced Resource Assign agent items in the VPE and manually re-adding the 'missing' RDP resources.
