Known Issue

This is the result of a known issue. When you use a Windows operating system to access a Terminal Servers Favorite, the following error message may be displayed, prior to the browser crashing:

Creating Control Error

This issue occurs under the following conditions:

  • The Disable top level ActiveX controls update check box is selected (on the Device Management: Configuration: Client Update page in the FirePass controller's Administrative Console)

  • The user has loaded the following version 6.0 and 6.0.1 ActiveX controls for Terminal Servers Favorites:

    • F5 Networks Host Control 5600,0,60606,640 (version 6.0 control)

    • F5 Networks SSL Tunnel 6010,2007,223,314 (version 6.0.1 control)

Note: You can view these controls in the C:\Windows\Downloaded Program Files directory.

F5 Networks Product Development tracked this issue as CR78660 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
 

Workaround

If the end user has an account on the Windows system with sufficient permissions, the end user may delete the ActiveX control files from the C:\Windows\Downloaded Program Files directory. The end user must close all browser windows, and may need to use the Task Manager to close all iexplore.exe processes or reboot.  Subsequently, when the Terminal Server Favorite is launched, the user should not be affected by this issue.
 

You can also work around this issue by clearing the Disable top level ActiveX controls update check box, which is located on the Device Management: Configuration: Client Update page in the FirePass controller's Administrative Console. This configuration option will download the F5 Networks Auto Update ActiveX control, which will then communicate with the FirePass controller to update all F5 Networks ActiveX controls.
