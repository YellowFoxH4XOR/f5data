Known Issue

The BIG-IP system may prematurely close the client-side of an HTTP Keep-Alive connection.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with an HTTP profile and a OneConnect profile.
  • The number of keep-alive requests in a connection exceeds the server's maximum Keep-Alive setting.

In a OneConnect configuration, when a server's maximum number of keep-alive requests is exceeded, the server sends a Connection: close HTTP header to the BIG-IP system to close the connection between itself and the BIG-IP system. The BIG-IP system transforms the HTTP header and sends an HTTP X-Cnection: close header to the client as part of OneConnect process but incorrectly closes the client-side connection by propagating a TCP FIN.

Impact

The system unexpectedly closes client-side connections and drops subsequent requests.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that your BIG-IP system forwards an X-Cnection: close HTTP header and a TCP FIN to the client.
  • Subsequent HTTP keep-alive requests from the client on the affected connection are dropped.

Resolution

Status

F5 Product Development has assigned ID 591659 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

You can work around this issue by modifying the value of the Maximum Reuse setting in the affected OneConnect profile to the value that is two fewer than the value of the maximum Keep-Alive setting of the HTTP services on the pool members.

For example, if the value of the maximum Keep-Alive setting of the HTTP services on the pool members is 100, you should set the value of the Maximum Reuse setting in the affected OneConnect profile to 98. For information about the maximum Keep-Alive setting of the HTTP services on your pool members, refer to the documentation provided by your HTTP services vendor.

To modify the value of the Maximum Reuse setting of the affected OneConnect profile, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Other > OneConnect.
  3. Click on the name of the affected OneConnect profile.
  4. For Maximum Reuse, enter the value appropriate for your application environment. See the previous example for guidance.
  5. Click Update.
