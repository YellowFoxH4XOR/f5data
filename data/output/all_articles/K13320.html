Description

The ARX system does not support any types of NTFS reparse points (also referred to as junction points).

Additionally, if a reparse point is found during a file system inventory, the Data Manager inventory report will include an error message that appears similar to the following example:

ERROR: REPARSE: arx-cifs1.domain.com\test\reparse: Reparse point found on the file system 

Supplemental Information

  • The NTFS filesystem allows for the creation of reparse points, which include hard links, symbolic links, and junction points/directory junctions. For more information about NTFS reparse points, refer to the following Wikipedia document.
