Description

This article covers how to renew a BIG-IP device certificate with CA-provided keys and certificate from the CLI of a BIG-IP LTM or another BIG-IP module except DNS. For BIG-IP DNS, additional steps are required and you should follow the procedures described in K16951115: Changing the BIG-IP system device certificate using the Configuration utility instead.

Environment

  • BIG-IP (any module except BIG-IP DNS)
  • Device certificate
  • CA

Cause

The device certificate is expiring and the BIG-IP GUI is currently unstable/unavailable.

Recommended Actions

Important: For BIG-IP DNS, additional steps are required and you should restore access to the GUI and follow the procedures described in K16951115: Changing the BIG-IP system device certificate using the Configuration utility instead.

  1. Use SCP or SFTP to upload the new server.crt from the CA to the BIG-IP in /config/httpd/conf/ssl.crt/ or login to the CLI and overwrite the server.crt file. To overwrite perform the following series of steps:

    cd /config/httpd/conf/ssl.crt/
    echo "" > server.crt
    nano server.crt
    -- copy the new server/bundled certificate from CA --
    ctrl O / ctrl X

  2. Use SCP or SFTP to upload the new server.key from the CA to the BIG-IP in /config/httpd/conf/ssl.key/ or login to the CLI and overwrite the server.key file. To overwrite perform the following series of steps:

    cd /config/httpd/conf/ssl.key
    echo "" > server.key
    nano server.key
    -- copy the new key from CA --
    ctrl O / ctrl X

  3. Log into the BIG-IP CLI if you have not done so already.
  4. Restart the httpd service by typing the following command:

    bigstart restart httpd

  5. Verify the certificate and check validity by typing the following command:

    openssl x509 -in /config/httpd/conf/ssl.crt/server.crt -text -noout
