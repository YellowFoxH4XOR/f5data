K000151555: [F5OS] Appliance cored everytime when access GUI after applying LDAP config. GUI shows "User session terminated. You will be logged out from the application".

Type
Support Solution
Published
2025-05-28
Updated
2025-11-11
Applies to
  • F5OS
  • F5OS-A: 1.8.3, 1.8.0
  • F5OS-C: 1.8.0
Source
https://my.f5.com/manage/s/article/K000151555

Description

  • On F5OS systems, applying an LDAP configuration for authentication may result in repeated core dumps of the validator process and prevent access to the GUI. The following error message is displayed:

    "User session terminated. You will be logged out from the application."

  • HTTPD logs show repeated 401 authorization errors on API endpoints related to authentication and system information. Removing the LDAP configuration alone does not restore GUI access; SSH access remains functional.

Environment

  • F5OS-A, F5OS-C
  • Software Version: 1.8.0
  • LDAP authentication enabled (Active Directory/LDAPS with group mapping)
  • Accessing management GUI via web browser
  • SSH access available

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 1858617

Recommended Actions

  1. Remove LDAP Group Mapping:

    Delete any ldap-group entries under system aaa authentication roles role <role> config ldap-group from your configuration.   Commands to delete from config when GUI is unavailable  # config
          # no system aaa authentication roles  <role>    config ldap-group 
          # commit and-quit 
  2. Reboot the Appliance:

    After removing all LDAP group mappings, perform a full reboot of the appliance to clear any residual faulty state.
