K35115510: BIG-IQ DCD /var space is filled with traffic_tl0 indices

Type
Support Solution
Published
2022-02-28
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source

Description

DCD /var is filling up quickly. We see lots of big traffic_tl0 indices like below: 

curl -sk https://localhost:9200/_cat/indices?v | grep traffic_

NOTE:  For version 7.x  use http inseed https

Environment

  • BIG-IQ 7.x, 8.x
  • BIG-IP analytics profiles 
  • Statistic collection
  • Enabled Traffic Captured Logging in Analytics profile

Cause

BIG-IP can capture a portion of the application traffic and send it to BIG-IQ.

Recommended Actions

Disable packet captures send to the BIG-IQ DCD: 
  1. Go to analytics profile on BIG-IP
    Local Traffic  >  Profiles > Analytics > HTTP Analytics 
  2. Choose your analytics profile
  3. Disable traffic captures collection in BIG-IP analytics profile -  unset "Traffic Capturing Logging Type" external
