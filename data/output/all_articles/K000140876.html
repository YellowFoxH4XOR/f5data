Description

In some scenarios you will need to add an additional logging profile to your APM Access Profile to enable debug logging. If the original profile is not removed and 2 profiles are attached to the Access Profile, you will result in an error message: Error Message: "In profile access (/Common/<profile_name>), duplicate log destination (/Common/local-syslog) is found with configured publishers (/Common/sys-db-access-publisher) and (/Common/sys-db-access-publisher)." not allowing you to load/save/sync your configuration.

Environment

  • APM Access Profile
  • Multiple Logging Profile

Cause

Duplicate logging profiles are not allow and result in noted error message

Recommended Actions

To resolve the error message, note the Access Profile listed in the error message and remove all but one logging profile.

Follow the steps you used to add the profile to remove the profile located here:
K24826763: Configuring the BIG-IP APM Logging Levels (12.x and newer)

Note: Debug logging profiles should only be added when troubleshooting and removed when data is collected. Please see: K48046125: Duplicate log lines in /var/log/apm
