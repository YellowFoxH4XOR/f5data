K000157258: BIG-IQ: Importing BIG-IP device fails when Address List includes address "SS"

Type
Support Solution
Published
2025-10-31
Updated
2025-10-31
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000157258

Description

Attempting to import a BIG-IP device on BIG-IQ fails with an error similar to the following:

Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: Invalid geolocation in XXX. Invalid country code : SS

Environment

BIG-IQ

Importing a BIG-IP device fails when its Address List includes the address SS.

Cause

F5 is tracking the issue as ID 2099633.

Recommended Actions

As a workaround you can remove SS from the address list, or contact F5 support to request an updated geolocations.json file.

Additional Information

None
