Description
Without GARP devices may not be able to resolve IP address to MAC address breaking communications
SNAT address returning TCP RST

Environment

  • AWS
  • BIG-IP
  • GARP
  • SNAT pool

Cause
AWS does not allow GARP

Recommended Actions

Workaround:
Resolved with static route for SNAT pool pointing to the address on the BIG-IP.

Fix:
Work within the ENI paradigm used by AWS.
 

Additional Information

Since GARP is not supported by AWS, a new methodology termed Elastic Network Interface (ENI) is incorporated. ENI includes an IP address, MAC and security group (if any), and Port rules (if any). When an ENI moves, all associated attributes including MAC, IP, and firewall rules (if any) move with ENI.
