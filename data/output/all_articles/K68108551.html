Known Issue

The BIG-IP system erroneously displays the BIG-IP Edge Client Save Password checkbox.

This issue occurs when all of the following conditions are met:

  • You create a BIG-IP APM Secure Connectivity profile and clear the Win/Mac Edge Client setting for Allow Password Caching (the default setting).
  • You assign the connectivity profile to a virtual server that is configured with an access profile.
  • Users launch the BIG-IP Edge Client to log on to the access profile.

Impact

The system displays the Save Password checkbox.

Note: When you have not enabled the Allow Password Caching setting, the system should not display the Save Password checkbox.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Users cannot use the Save Password function, even though the option is presented.
