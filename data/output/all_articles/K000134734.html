Topic

The BIG-IP Advanced WAF / ASM system checks that the request includes a total HTTP header length that does not exceed the length specified in the security policy.

Description

When you configure the learning and blocking settings for Illegal HTTP header length violations and the BIG-IP Advanced WAF / ASM system detects a request in which the header length exceeds the acceptable length specified in the policy, the system logs the following violation to the /var/log/asm file and the Requests screen in the Configuration utility:

  • Illegal header length

For example, the Illegal header length violation occurs if a client sends a request with a very long HTTP header. Such requests can consume excessive resources on the web server and may be an indication of an attack.

Configure Learning and Blocking settings for Illegal header length violations

To configure Learning and Blocking settings for Illegal header length violations, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select Headers.
  4. For Illegal header length, select the check boxes for Block, Learn and Alarm, as needed.
  5. Select Save.
  6. Select Apply Policy.

Configure the allowed HTTP header length

To configure the allowed HTTP header length, perform the following steps:

  1. Log into the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List > <Security Policy Name>.
  3. Select Policy Configuration.
  4. Select General Settings.
  5. In the Basic HTTP Message Settings section, select Length for Maximum HTTP Header Length.
  6. Enter the maximum number of bytes to be allowed for HTTP header length.
  7. Select Save.
  8. Select Apply Policy.
