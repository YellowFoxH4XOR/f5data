Known Issue

Remote desktop access fails due to the virtual server configuration.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access profile access policy includes a Remote Desktop Protocol (RDP) resource.
  • The access profile is assigned to a virtual server where the source port is set to Change.
  • A user establishes an access session and attempts to connect to the remote desktop resource.

Impact

The connection to the remote desktop fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When launching the remote desktop resource, you observe an error message similar to the following examples:

    • Your computer can't connect to the remote computer because an error occurred on the remote computer that you want to connect to. [...]

    • Your computer can't connect to the Remote Desktop Gateway Server. Contact your network administrator for assistance

  • When viewing the network level communication between the BIG-IP APM system and the destination resource, the destination resource sends a TCP reset to connection request.

Workaround

To work around this issue, you can modify the virtual server source port configuration or disable Clustered Multiprocessing (CMP) for the virtual server. To do so, perform one of the following procedures:

Impact of workaround: Changing the virtual server source port from Change to Preserve will maintain the source port used by the client. Disabling CMP on the virtual server may reduce the performance of the virtual server.

  • Modifying the virtual server source port setting
  • Disabling CMP on the affected virtual server

Modifying the virtual server source port setting

To modify the specified virtual server source port handling of the virtual server, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Click on the name of the affected virtual server.
  4. Set Configuration to Advanced.
  5. From the menu, set the source port to Preserve.
  6. Click Update.

Disabling CMP on the affected virtual server

To disable CMP for the specified virtual server, perform the following procedure:

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To disable CMP on the affected virtual server, use the following command syntax:

    modify /ltm virtual <partition><virtual server name> cmp-enabled no

  3. To save the configuration change, type the following command:

    tmsh save /sys config
