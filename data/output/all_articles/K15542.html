K15542: Obtaining the admin account credentials for a BIG-IP system that is provisioned in the AWS EC2 environment, using the BIG-IQ Cloud system

Topic

You should consider using this procedure under the following condition:

  • You want to obtain the BIG-IQ Cloud-provisioned BIG-IP Virtual Edition (VE) administrator's password in the Amazon Web Service (AWS) EC2 environment.

Description

When provisioning a BIG-IP VE system using the AWS EC2 connector, the BIG-IQ Cloud system uses admin as the default administrator user name and generates a strong random password, by default. You can use the following procedure to obtain the random password for the administrator account on the target BIG-IP VE system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have REST API authentication access privileges for the BIG-IQ system.
  • You have the required BIG-IQ system configuration information, like the management IP address.
  • You have access to the BIG-IQ system's management IP using a REST client add-on/plugin installed on your browser.
  • You have a valid AWS account, and the EC2 environment that has the BIG-IQ Virtual Edition (VE) in operation has a valid license.
  • The BIG-IQ system has provisioned at least one BIG-IP VE system in the AWS EC2 environment.

Procedures

To obtain the default admin account's password for the target BIG-IP VE system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Access the workstation where the REST client can connect to the BIG-IQ system that has the target AWS EC2 connector, where the BIG-IP VE was provisioned.
  2. Use the following API to access the BIG-IQ system's management IP:

    Method: GET
    URL: https://<BIG-IQ_ManagementIP>/mgmt/cm/cloud/connectors/ec2

    For example:

    Method: GET
    URL: https://10.0.0.1/mgmt/cm/cloud/connectors/ec2

  3. Inspect the API response to locate the EC2 connectorID that is associated with the target BIG-IP VE system.

    For example, an EC2 connector ID displayed for Virginia may appear as follows:

    "displayName": "Amazon EC2",
    "connectorId": "eff17e25-fd1a-487b-5f9c-fa7121e5c488",
    "name": "Virginia",

  4. Use the following API to access the EC2 connector nodes:

    Method: GET
    URL: https://<BIG-IQ_ManagementIP>/mgmt/cm/cloud/connectors/ec2/<EC2_connectorID>/nodes

    For example:

    Method: GET
    URL: https://10.0.0.1/mgmt/cm/cloud/connectors/ec2/eff17e25-fd1a-487b-5f9c-fa7121e5c488/nodes

  5. Inspect the API response and locate the id with DeviceMgmtPassword of the target BIG-IP VE system, and the following value attribute contains the admin account's password.

    For example, the API response returns the following:

     "value": "admin"
            },
            {
              "id": "DeviceMgmtPassword",
              "isRequired": false,
              "description": "Password to use for managing this device - this is only relevant when node represents a managed device.  If unspecified then it will be auto-generated for BIG-IQ provisioned BIG-IP and otherwise set to default admin password",
              "value": "fdgc41fd-0848-2160-b15b-23f1437rh0f0d"
            }
          ],
          "ipAddress": "NNN.NNN.NNN.NNN",
          "networkInterfaces": [
            {
              "localAddress": "10.0.0.61",
              "virtualAddress": "NNN.NNN.NNN.NNN",
              "subnetAddress": "10.0.0.0/24"

    Note: In the previous example, the string "NNN.NNN.NNN.NNN" denotes a Public IP address that does not have an illustrated value.

    To interpret the attribute-value pairs from the previous example API response, look for the following items:
    • "value" : "admin"
    • "id": "DeviceMgmtPassword"
    • "value" : "fdgc41fd-0848-2160-b15b-23f1437rh0f0d"
    • "localAddress": "10.0.0.61"

    In this example, the admin account's password is "fdgc41fd-0848-2160-b15b-23f1437rh0f0d", and the internal Self IP of the BIG-IP system is "10.0.0.61".

  6. Using the previous example API response, you can navigate to the target BIG-IP VE system's Configuration utility and log in as follows:

    Username: admin
    Password: fdgc41fd-0848-2160-b15b-23f1437rh0f0d
