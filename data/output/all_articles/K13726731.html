Description
when upgrading a VCMP Host, one or more guests fail to load the configuration after restarting with the following error: 

Configuration error: Can't create symlink from /config/bigip/auth/pam.d/ldap/system-auth.conf to /etc/nslcd.conf, File exists

Environment

  • BIG-IP LTM
  • VIPRION - VCMP Guests loading config
  • Configuration load error. 

Cause
The file /etc/nslcd.conf is created by the symlink from /config/bigip/auth/pam.d/ldap/system-auth.conf.   If the file already exists in the symlink location, the system will not overwrite the file.

Recommended Actions

From Command line: 
  1.  cd /etc/
  2. rm nslcd.conf
  3. tmsh load sys config verify
  4. If no other errors are encountered verifying the config, 
  5. tmsh load sys config partitions all
note:  if any other errors are encountered, you will need to identify the problem and correct the error before loading the config.
