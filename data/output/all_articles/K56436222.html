Description

When editing the Third Party CA Management Policy (Venafi), there is an error retrieving the Policy Folders

The system returned an unexpected error (400 Bad Request). Request Failed with Error: "Find all matching Distinguished Names derived from class Policy failed; ObjectDoesNotExist."

Verified Policy Folder Path and Device Folder Path with customer and Venafi

 

Environment

  • BIG-IQ VE 8.1.0
  • Venafi 3rd party certificate management

Cause

Incorrect user rights on the Venafi server 

Recommended Actions

Have Venafi verify the user rights are correctly configured

Additional Information

Had Venafi run tcpdump and have Venafi decode it.
The request is correct.
The server returns 200 OK but no payload.
