K22669340: Chrome 80 samesite feature causes OWA login loop

Type
Support Solution
Published
2021-03-04
Updated
2025-05-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K22669340

Description

A recent update to Exchange 2016 caused a login loop in Chrome 80 due to the SameSite cookie not also having the Secure attribute set

  • Cookies with SameSite attribute but not the Secure attribute

Environment

  • Chrome 80
  • HTTP Cookies

Cause

Chrome requires all cookies that use the SameSite attribute to its behaviour on the handling of HTTP Cookies

Recommended Actions

Use this iRule to add the Secure attribute to all Cookies that are being set with the SameSite attribute

when HTTP_RESPONSE_RELEASE {
    foreach myCookie [HTTP::cookie names] {
        if { [HTTP::cookie attribute $myCookie exists {SameSite}] }{
            HTTP::cookie secure $myCookie enable
        }
    }
}
