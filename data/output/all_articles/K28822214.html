Known Issue

DNS Express zone RR (resource record) type count statistics may display incorrect data.

This issue occurs when all of the following conditions are met:

  • You have configured DNS Express with multiple zones.
  • You use the Traffic Management Shell (tmsh) to display all DNS Express zone RR statistics.

    For example, you type the following command:

    tmsh show ltm dns zone

  • RR statistics for a displayed zone that precedes other zones has statistics that are zero values.

Impact

Displayed RR zone statistics may be incorrectly displayed as zero values.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When displaying all DNS Express RR zone statistics, and a zone has statistic values of zero, the displayed zone that follows will also display statistic values as zero.
  • When displaying each DNS Express RR zone statistic individually, the statistic values are displayed correctly.

    For example, you would use the following command syntax:

    tmsh show ltm dns zone <zone_name>

Workaround

To work around this issue, you can use the tmsh utility to display the individual zone RR statistics.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
