Known Issue

If the BIG-IP system has created a large core file (larger than 2 GB), the qkview command may generate output that iHealth cannot parse.

This issue occurs when all of the following conditions are met:

  • You attempt to create a qkview file.
  • A core file larger than 2 GB exists in the /var/core directory.

Impact

iHealth is unable to use the qkview file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • iHealth is unable to process the qkview file.
  • Manually extracting the qkview file using the tar command may display error messages similar to the following example:

    tar: Skipping to next header
    tar: Archive contains ‘\0004/0.11’ where numeric mode_t value expected
    tar: Substituting `.' for empty member name
    tar: .: Cannot open: Is a directory

Resolution

Status

F5 Product Development has assigned ID 630546 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

You can delete or move the core file from the /var/core directory to a different directory before you create a qkview file.
