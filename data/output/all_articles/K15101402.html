Security Advisory Description

An authenticated iControl REST user with at least guest role privileges can cause processing delays to iControl REST requests via undisclosed requests. (CVE-2022-1468)

Impact

Processing delays to iControl REST requests can occur until the iControl REST daemon is either forced to restart or manually restarted. This vulnerability allows a remote authenticated attacker to cause a degradation of service that can lead to a denial-of-service (DoS) on the iControl REST daemon. There is no data plane exposure; this is a control plane issue only.

Mitigation

To mitigate this vulnerability for affected BIG-IP systems, you can use the following sections as mitigations until it is possible to install a fixed version:

  • Permit iControl REST access to the BIG-IP system only over a secure network and limit access to trusted users. For more information about securing access to BIG-IP systems, refer to K13309: Restricting access to the Configuration utility by source IP address (11.x - 16.x) and K13092: Overview of securing access to the BIG-IP system.

  • Increase the timeout values of the following database variables:

    Note: The default value for all three database variables is 60 seconds. For more information on the DB variables, refer to Bug ID 858189 in F5 Bug Tracker.

    • restjavad.timeout
    • restnoded.timeout
    • icrd.timeout
Depending on the delay you are experiencing with the iControl requests, increase the values of the database variables so that requests do not timeout.

To increase the values of the database variables, perform the following procedure:

Impact of action: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. Determine the current values of the database variables by entering the following commands:

    list sys db restjavad.timeout
    list sys db restnoded.timeout
    list sys db icrd.timeout

  3. To increase the values of the database variables, use the following command syntax:

    modify sys db <DB variable name> value <new value>

    For example, to increase the timeout values to 120 seconds, enter the following commands:

    modify sys db restjavad.timeout value 120
    modify sys db restnoded.timeout value 120
    modify sys db icrd.timeout value 120

  4. Restart the restjavad and restnoded services by entering the following commands:

    restart sys service restjavad
    restart sys service restnoded
