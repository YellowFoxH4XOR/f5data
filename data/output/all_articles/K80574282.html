Description

  • Users unable to establish connection after increasing VPN license

Environment

  • APM
  • VPN (Network Access)

Cause

  • Not enough addressable lease pool address

Recommended Actions

  1. Go to Access > Connectivity / VPN > Network Access (VPN) > IPV4 Lease Pools > (name of Lease-pool)
  2. Under Configuration > Member List, add range of IP addresses
  3. Click Update
  4. Apply Access Policy to apply the changes
