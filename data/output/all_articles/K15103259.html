K15103259: Monpd process reports down in vCMP Guest CLI

Support Solution
Published

Description

Monpd appears down in CLI of vCMP Guest similar to the following:

[root@big-ip-13-1-3-6:monpd DOWN:Standalone] config #

The monpd process is used in conjunction with the avrd process for reporting and charts.

Checking services with bash command:  

# bigstart status 

You might see monpd and mysql down.

You also see similar logs to the following in /var/log/mysql.out

ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: NO)

Environment

  • BIG-IP LTM
  • vCMP Guest

Cause

The mysql database did not initialize completely. The system is very busy or has no entropy. This makes setting up mysql permissions take a long time.

Recommended Actions

  1. Restart mysql and then monpd:

    # bigstart restart mysql
# bigstart restart monpd

Note: If after restarting the services you see mysql and monpd still down, step 2 and possibly step 3 will be needed.

  2. ?Reboot the vCMP guest.

  3. If after the reboot monpd and mysql are still showing down, a rebuild of the vCMP Guest will be needed in the same or different blade.
