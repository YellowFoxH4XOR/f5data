K000092648: RCA for reboot of blade B4450N on slot1 of Viprion C4800

Type
Support Solution
Published
2022-11-17
Updated
2022-11-17
Source

Description

After an unexpected reboot the following error is seen after the boot marker in /var/log/ltm:


Host Watchdog timeout count: #


Where # is a value such as 1


Environment

BIG-IP hardware


Cause

This error indicates that the Lights Out Processor on the hardware rebooted the system after failing to receive a heartbeat from the operating system. This could be caused by a hardware failure, a software bug, or simply a busy system. There is no one cause of this error, and no way to definitively lock down the cause because, by definition, the software had stopped responding.


Recommended Actions

Customer should run an EUD to rule out hardware. It may also be prudent to ensure that the BIG-IP is on the latest code version for the chosen branch to eliminate as many possible software bugs as possible. Customer should also look for evidence of overload on the BIG-IP, such as clock advance messages or excessive loads via system reporting tools. If the problem persists, please contact Network Support.
