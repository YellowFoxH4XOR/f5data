Issue

Error Message

warning tmm[<PID>]: 01010040:4: Clock has unexpectedly adjusted by <#> ms

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <#> is the number of milliseconds

For example:

warning tmm[10954]: 01010040:4: Clock has unexpectedly adjusted by 2050 ms

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A time adjustment occurs on the internal Traffic Management Microkernel (TMM) clock.

The BIG-IP system uses an internal clock that synchronizes with the time on the Linux host. This message generally appears when the ntpd process updates the time on the BIG-IP system and the internal TMM clock adjusts accordingly.

Impact

The internal TMM clock time adjusts by the number of milliseconds in the message.

Recommended Actions

Multiple occurrences of this message may indicate an issue with network time protocol (NTP) peer communication. You should verify the NTP configuration on the BIG-IP system and ensure proper communication between the BIG-IP system and the NTP server. For more information, refer to K10240: Verifying NTP peer server communications.

If you have verified the NTP peer communication and the messages are still generating excessively, TMM may be unable to converge on an accurate representation of its internal time. For example, when the TMM clock advances by more ticks than expected, TMM may have been preempted or have a lagging internal clock. Reviewing the log files for related messages at the time of the occurrence may help determine the cause.
