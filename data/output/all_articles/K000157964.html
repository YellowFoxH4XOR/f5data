K000157964: F5OS displays "Waiting for cluster status" in the GUI and CLI prompt after an upgrade

Type
Support Solution
Published
2025-11-25
Updated
2026-04-01
Applies to
  • F5OS
  • F5OS-A: 1.8.0, 1.8.3
Source
https://my.f5.com/manage/s/article/K000157964

Description

After upgrading an rSeries system, the CLI prompt and webUI/GUI remained on Waiting for cluster status indefinitely.

A reboot cleared the issue.

Environment

  • F5OS-A 1.8.0 , F5OS-A 1.8.3
  • K3s cluster

Cause

Bug ID 1620921

This problem happens if k3s restarts unexpectedly while the K3s cluster is being updated after the upgrade.

The show cluster command will show a K3s IMAGE update has failed event.

Recommended Actions

Rebooting the system will clear the issue and allow the K3s cluster upgrade to complete successfully. This should be a one time thing and the problem should not occur with subsequent reboots.

Additional Information

If the problem is not cleared with a reboot, generate a qkview and open a case with F5 Support for further investigation; there may be an additional issue that requires troubleshooting.
