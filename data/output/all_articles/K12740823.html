Description

Analysis Plane showing high CPU on Standby

  • Analysis Plane showing High CPU on the standby
  • Even after the failover the current standby shows high CPU on the Analysis Plane
  • The data, control, and analysis plane stats are too high as reported by  #tmsh show sys performance system detail.

Environment

  • Big IP 13.1.4
  • HA configuration

Cause

Bug 818097 The bug is fixed in v15.1.0, but if customer is unable to upgrade now, there is a workaround which can correct the high analysis usage.

Recommended Actions

Upgrade to V15.1.0 and higher or perform the following actions:

1. ssh to the guest having high analysis usage
2. run the following commands:
     # clsh --slot=2 rm -vf /var/tmstat/blade/statsd
     # clsh --slot=2 bigstart restart merged
