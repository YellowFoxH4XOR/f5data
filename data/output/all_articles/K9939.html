Known Issue

This is the result of a known issue. If you enable Compatibility Mode 2 on the FirePass controller, users may experience issues when accessing Microsoft Outlook Web Access (OWA) through Portal Access. When this issue occurs, the Portal Access reverse-proxy engine duplicates a portion of the URL, causing the browser to connect to an invalid URL. 

Important: When upgrading to FirePass version 6.0.3 from FirePass version 6.0.1 or earlier, Compatibility Mode 2 is enabled by default.
 
For example, the reverse-proxy engine should rewrite the URL as follows:
 
https://firepass.example.com/f5-w-687474703a2f2f3139322e3136382e312e3130
e6e6574776f726b$$/owa/?ae=Item&t=IPM.Note&id=RgAAAABvBd2QsKa0RqAizYBOtFqABwBID
0sVkbwSSLQH8BtYC1awABgMh4awAABID0sVkbwSSLQH8BtYC1awABi07ldOAAAJ
 
However, the reverse-proxy engine rewrites the URL as follows:
 
https://firepass.example.com/f5-w-687474703a2f2f3139322e3136382e312e3130
e6e6574776f726b$$/f5-w-687474703a2f2f3139322e3136382e312e3130e6e65747
76f726b$$/owa/?ae=Item&t=IPM.Note&id=RgAAAABvBd2QsKa0RqAizYBOtFqABwBID
0sVkbwSSLQH8BtYC1awABgMh4awAABID0sVkbwSSLQH8BtYC1awABi07ldOAAAJ
 
F5 Product Development tracked this issue as CR112589 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.
 
Additionally, cumulative hotfix HF-603-2.1 has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
You can work around this issue by disabling Compatibility Mode. To do so, perform the following procedure:
 
Important: Disabling Compatibility Mode enables the current version of the Portal Access reverse-proxy engine. Most web applications perform better through the current version of the reverse-proxy engine; however, some web applications may function better when Compatibility Mode is enabled.
 
  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Portal Access > Web Applications > Content Processing page.
  3. Click the Global Settings tab.
  4. In the Web Applications Global Settings section, clear the Compatibility Mode (enable legacy versions of Web Applications engine) check box.
  5. In the top right corner of the Web Applications Global Settings section, select the service restart link.
  6. Click Restart to restart the FirePass services.
