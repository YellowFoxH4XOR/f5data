Topic

By default, BIG-IP Link Controller gathers bandwidth measurements for links through its internal counters. The BIG-IP Link Controller can also be configured to retrieve bandwidth measurements for the links through SNMP queries to the routers.

The BIG-IP Link Controller queries for the following standard UCD MIB OIDs:

.1.3.6.1.2.1.1.1
.iso.org.dod.internet.mgmt.mib-2.system.sysDescr octetstr
A textual description of the entity. This value should include the full name and version identification of the system's hardware type, software operating system, and networking software. This OID must contain only printable ASCII characters.

.1.3.6.1.2.1.1.4
.iso.org.dod.internet.mgmt.mib-2.system.sysContact octetstr
The textual identification of the contact person for this managed node, together with information on how to contact this person.

.1.3.6.1.2.1.1.6
.iso.org.dod.internet.mgmt.mib-2.system.sysLocation octetstr
The physical location of the node (for example, telephone closet, 3rd floor).

.1.3.6.1.2.1.1.3
.iso.org.dod.internet.mgmt.mib-2.system.sysUpTime timeticks
The time (in hundredths of a second) since the network management portion of the system was last reinitialized.

.1.3.6.1.2.1.4.3
.iso.org.dod.internet.mgmt.mib-2.ip.ipInReceives counter
The total number of input data grams received from interfaces, including those received in error.

.1.3.6.1.2.1.4.10
.iso.org.dod.internet.mgmt.mib-2.ip.ipOutRequests counter
The total number of IP datagrams that the local IP user-protocols (including ICMP) have supplied to IP in requests for transmission. Note that this counter does not include any datagrams counted in ipForwDatagrams.

.1.3.6.1.2.1.6.4
.iso.org.dod.internet.mgmt.mib-2.tcp.tcpMaxConn integer
The limit on the total number of TCP connections the entity can support. In entities where the maximum number of connections is dynamic, this object should contain the value -1.

.1.3.6.1.2.1.6.5
.iso.org.dod.internet.mgmt.mib-2.tcp.tcpActiveOpens counter
The number of times TCP connections have made a transition from CLOSED to SYN-SENT.

.1.3.6.1.2.1.6.6
.iso.org.dod.internet.mgmt.mib-2.tcp.tcpPassiveOpens counter
The number of times TCP connections have made a transition from LISTEN to SYN-RCVD.

.1.3.6.1.2.1.6.9
.iso.org.dod.internet.mgmt.mib-2.tcp.tcpCurrEstab gauge
The number of TCP connections for which the current state is either ESTABLISHED or CLOSE- WAIT.

.1.3.6.1.2.1.4.20.1.2
.iso.org.dod.internet.mgmt.mib.ip.ipAddrTable.ipAddrEntry.ipAdEntIfIndex integer
The index value that uniquely identifies the IP interface to which this entry is applicable. The interface identified by a particular value of this index is the same interface as identified by the same value of ifIndex.

ifHCInOctets 1.3.6.1.2.1.31.1.1.1.6
.iso.org.dod.internet.mgmt.mib-2.ifMIB.ifMIBObjects.ifXTable.ifXEntry.ifHCInOctets counter64
The total number of octets received on the interface, including framing characters. This object is a 64-bit version of ifInOctets.

ifHCOutOctets 1.3.6.1.2.1.31.1.1.1.10
.iso.org.dod.internet.mgmt.mib-2.ifMIB.ifMIBObjects.ifXTable.ifXEntry.ifHCOutOctets counter64
The total number of octets transmitted out of the interface, including framing characters. This object is a 64-bit version of ifOutOctets.
