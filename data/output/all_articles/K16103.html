Topic

This article applies to BIG-IQ 5.3.0 and earlier. For information on other versions, refer to the following article:
  • K58621633: Extending disk space on a BIG-IQ Virtual Edition

You should consider using these procedures under the following condition:

  • You want to increase the disk space on a BIG-IQ Virtual Edition (VE) system that does not have sufficient disk space for the following tasks:
    • Upgrading software or installing hotfixes
    • Preparing for increased logging that requires additional disk space

    Important: The supported maximum disk space is 1.9 TB.

Description

The BIG-IQ VE image is available in two different sizes for the supported hypervisors. If you have deployed a BIG-IQ VE system using one of these images, and find the disk size inadequate, you can upsize the BIG-IQ VE system disk size. You do this by using the tmsh modify /sys disk directory /<target directory> new-size <new size in KB> command syntax. However, before increasing the disk size of individual directories in the BIG-IQ VE system, you must first increase the disk size in the hosting hypervisor configuration. The BIG-IQ VE system disk size increase does not take effect until after a reboot. You can use the tmsh show /sys disk directory command to verify if the changes have taken effect. A value in the New Size column in the command output indicates disk size increases that have not taken effect.

For example, the following output from the tmsh show /sys disk directory command indicates that the extension of the /shared directory to 20 GB has not taken effect:

Directory Name                  Current Size    New Size
--------------                  ------------    --------
/config                         1048576         -
/shared                         10240000        20971520
/var                            10485760        -
/var/log                        7168000         -

The following output indicates that the extension of the /shared directory to 20 GB has taken effect after the restart:

Directory Name                  Current Size    New Size
--------------                  ------------    --------
/config                         1048576         -
/shared                         20971520        -
/var                            10485760        -
/var/log                        7168000         -

The BIG-IQ VE supports growing the following directories in BIG-IQ 4.4.0 and later:

  • /var/log
  • /shared
  • /var

Note: The shrinking of disk size is not supported because the majority of hypervisors do not support disk shrinking.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have deployed the BIG-IQ VE system using a BIG-IQ 4.4.0 or later BIG-IQ VE image.
  • You have sufficient access rights to modify the BIG-IQ VE guest settings on the hypervisor that is hosting the BIG-IQ VE system.
  • You have administrative access to the BIG-IQ VE system.

Procedures

  • Extending disk space for upgrading software or installing hotfixes on an additional slot
  • Extending disk space for increased logging

Extending disk space for upgrading software or installing hotfixes on an additional slot

This procedure is most applicable to BIG-IQ VE systems that use the 55 GB image. You can also use this procedure on BIG-IQ VE systems that use the 500 GB or LARGE image. To extend disk space for upgrading software or installing hotfixes on an additional slot, perform the following procedure.

Impact of procedure: You must shut down the BIG-IQ VE system during the disk provisioning steps, and the system will not be available for traffic processing. You should perform this procedure during a suitable maintenance window. Increasing the disk size on the VE system is irreversible because F5 does not support disk shrinking. Increasing the disk size beyond 1.9 TB may render the system unbootable. F5 recommends the extended disk space should not exceed 1.9 TB.

  1. Log in to the command line on the BIG-IQ VE system.
  2. To shut down the system, type the following command:

    shutdown -h now

BIG-IQ
  • Provision the disk space you want for the BIG-IQ VE system on the hypervisor. For example, if you need only one additional slot for upgrade or hotfix installation on a BIG-IQ VE system that is using the standard 55 GB image, you would modify the BIG-IQ VE guest disk space setting from 55 GB to 500 GB on the hypervisor. For information about disk provisioning on the hypervisor, refer to the documentation from your hypervisor vendor.
  • Start up the BIG-IQ VE guest instance on your hypervisor. For information about starting a guest instance on the hypervisor, refer to the documentation from your hypervisor vendor.
  • When the BIG-IQ VE system is up, log in to the command line on the BIG-IQ VE system.
  • To extend the /shared directory, use the following command syntax:

    tmsh modify /sys disk directory /shared new-size <new size in kilobytes>

    For example, you would enter the following command to extend the /shared directory to 20 GB:

    tmsh modify /sys disk directory /shared new-size 20971520

  • Save the configuration by typing the following command:

    tmsh save /sys config

  • Restart the BIG-IQ VE system by typing the following command:

    reboot

  • When the BIG-IQ VE system is up, log in to the command line on the BIG-IQ VE system.
  • To verify that the /shared directory is successfully extended to the size you have specified in step 6, type the following command:

    tmsh show /sys disk directory

  • Upload the ISO images or hotfixes using the Configuration utility and install the new version or hotfix to the next available slot.

    • Extending disk space for increased logging

    If the BIG-IQ VE system ran out of disk space due to increased logging, you can extend the disk space for logs by performing the following procedure.

    Impact of procedure: You must shut down the BIG-IQ VE system during the disk provisioning steps, and the system will not be available for device management. You should perform this procedure during a suitable maintenance window. Increasing the disk size on the VE system is irreversible because F5 does not support disk shrinking. Increasing the disk size beyond 1.9 TB may render the system unbootable. F5 recommends the extended disk space should not exceed 1.9 TB.

    1. Log in to the command line on the BIG-IQ VE system.
    2. To shut down the system, type the following command:

      shutdown -h now

    3. Provision the disk space you want for the BIG-IQ VE system on the hypervisor. For information about disk provisioning on the hypervisor, refer to the documentation from your hypervisor vendor.
    4. Startup the BIG-IQ VE guest instance on your hypervisor. For information about starting a guest instance on the hypervisor, refer to the documentation from your hypervisor vendor.
    5. When the BIG-IQ VE system is up, log in to the command line on the BIG-IQ VE system.
    6. To extend the /var/log directory, use the following command syntax:

      tmsh modify /sys disk directory /var/log new-size <new size in kilobytes>

      For example, you would type the following command to extend the /var/log directory to 10 GB:

      tmsh modify /sys disk directory /var/log new-size 10485760

    7. Save the configuration by typing the following command:

      tmsh save /sys config

    8. To restart the BIG-IQ VE system, type the following command:

      reboot

    9. When the BIG-IQ VE system is up, log in to the command line on the BIG-IQ VE system.
    10. To verify that the /var/log directory is successfully extended to the size you have specified in step 6, type the following command:

      tmsh show /sys disk directory
