Description

An HTTP monitor can mark a pool member down with a status code that appears to match the expected receive string such as 'Response Code: 200 (OK)'

  • An example of a logged http monitor message may look something like this: 
Jul 7 21:24:23 my.prod.bigip notice mcpd[5418]: 01070638:5: Pool /Common/MyPool member /Common/pool_member_1:80 monitor status down. [ /Common/my_http_monitor: down; last error: /Common/my_http_monitor:  Response Code: 200 (OK) @2021/07/07 21:24:23.  ]  [ was up for 0hr:3mins:1sec ]

Environment

  • BIG-IP LTM
  • http or https monitor

Cause

Bug ID 874877

Recommended Actions

You should take note of this when troubleshooting the monitors or when you have customized alerts created to monitor log messages

Additional Information

None.
