Description

You see the autodos process is using a high percentage of CPU following an upgrade to 14.1.x or 15.x
  • The following command outputs the CPU recent usage per core:

    ls /shared/tmstat/snapshots/blade*/public/3600/* | xargs -I {} sh -c 'echo "\n"{}; tmctl -f {} proc_pid_stat -s proc_name,processor,cpu_usage_recent -OK cpu_usage_5mins | head -n 15;'

    proc_name       processor cpu_usage_recent
    --------------- --------- ----------------
    tmm.0                   0            14530
    autodosd                1             9250

Environment

  • BIG-IP AFM
  • Recent upgrade to 14.1.x or 15.x

Cause

This behavior is caused by Bug ID 851745

Note: See Related Content for more information about this ID

Recommended Actions

As a workaround you can disable the autodos feature
  1. Connect to CLI
  2. Remove autodos
    tmsh modify sys service autodosd remove
  3. Reboot the unit
    reboot
After the reboot, the autodos feature will remain disabled
