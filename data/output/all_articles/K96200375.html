Known Issue

Creating a custom filter on the ASM Application Charts page may generate an error message.

This issue occurs when the following condition is met:

  • You create a custom filter using fields from Advanced Filters on the Charts page in the BIG-IP ASM Configuration utility.

Impact

The ASM Application Charts page fails to load the charts and generates an error message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The ASM Application Charts page fails to load the charts and generates an error message that appears similar to the following example:

    Filter Settings for <Attack_Type> were skipped, they are currently unsupported
