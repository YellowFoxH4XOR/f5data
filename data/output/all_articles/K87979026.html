Known Issue

A BIG-IP Edge Client customized logo image does not display correctly.

This issue occurs when all of the following conditions are met:

  • You customize a connectivity profile by replacing the default logo image with an image using the recommended dimensions of 48 pixels by 48 pixels.
  • You install the BIG-IP Edge Client for macOS from the access profile on a macOS Sierra version 12.10 device. 
  • The macOS device establishes an access session with the access profile.

Impact

The custom logo image does not display correctly. This issue is cosmetic and does not affect functionality.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP Edge Client for macOS displays the customize logo image in a reduced size.
  • A custom logo image with the dimensions of 100 pixels by 121 pixels displays correctly in the BIG-IP Edge Client for macOS.

Resolution

Status

F5 Product Development has assigned ID 653324 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can use a custom image of 100 pixels by 121 pixels. 

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
