Known Issue

Windows 7 users may experience intermittent system crashes or Blue Screen of Death when they attempt to transfer data over a Network Access connection.

This issue occurs when all of the following conditions are met:

  • The user is connected using Windows 7 with Service Pack 1
  • The user is connected through a Network Access favorite
  • The user attempts to transfer data to or from a file share

This issue occurs because the Windows 7 operating system does not allocate enough stack space for the network drivers required to complete the data transfer.

Impact

The user's system may crash while attempting to transfer data.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The user receives a Stop error message, which is commonly referred to as a system crash or Blue Screen of Death.

    For example:

    STOP: 0x0000007F (parameter1, parameter2, parameter3, parameter4) UNEXPECTED_KERNEL_MODE_TRAP
