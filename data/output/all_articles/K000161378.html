K000161378: Retrieve the status of the primary key from F5OS Velos using API

Type
Support Solution
Published
2026-05-22
Updated
2026-05-22
Applies to
  • F5OS
  • F5OS-C: 1.8.2
Source
https://my.f5.com/manage/s/article/K000161378

Description

You may want to know how to retrieve the status of the primary key from F5OS Velos.

Environment

  • F5OS-C
  • API

Cause

None.

Answer/Recommended Actions

You may use the command below to retrieve the status of primary key from F5OS Velos.

$ curl -sku admin:$password -H "Content-Type: application/yang-data+json" https://$IP:8888/restconf/data/openconfig-system:system/openconfig-system:aaa/f5-primary-key:primary-key/state/status|jq .

{

 "f5-primary-key:status": "COMPLETE    Initiated: Wed Jan 21 09:47:58 2026"

}

Replace $password with the appropriate password.

Replace $IP with the appropriate IP address of Velos controller.

Additional Information

None.
