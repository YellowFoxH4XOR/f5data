Known Issue

This is the result of a known issue. If you use the bigpipe mgmt route command to delete a management port route, the BIG-IP system removes the route from the Traffic Management Microkernel (TMM) route table, but not from the Linux route table.

F5 Product Development tracked this issue as CR58208 and CR58209, and it was fixed in BIG-IP 9.1.2 and 9.4. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, or Link Controller Release Notes.

Workaround

To remove the management port route from the BIG-IP TMM route table, and remove the corresponding route from the Linux route table, perform the following procedure:

  1. Log in to the BIG-IP system command line.
  2. Delete the management port route from the BIG-IP TMM route table, by typing the following command:

    bigpipe mgmt route <route_address> netmask <route_netmask> delete

    For example:

    bigpipe mgmt route 172.25.25.0 netmask 255.255.255.0 delete

  3. Delete the corresponding route from the Linux route table, by typing the following command:

    route delete -net <route_address> netmask <route_netmask>

    For example:

    route delete -net 172.25.25.0 netmask 255.255.255.0

  4. Verify the management port route has been removed from the BIG-IP TMM route table, by typing the following command:

    bigpipe mgmt route

  5. Verify the corresponding route has been removed from the Linux route table, by typing the following command:

    netstat -rn

  6. Save the configuration, by typing the following command:

    bigpipe save
