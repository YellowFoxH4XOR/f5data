Description

This article describes an issue that you may observe a noticeable latency when using iControl RESTful API. 
During the troubleshooting process, you may notice ALL those phenomenons:
  1. The requests on the device using localhost or 127.0.0.1 address do not have prominent latency. At the same time, it will have noticeable latency using mgmt address even on BIG-IP. 
For example, tests using curl with mgmt address show latency as:
# time curl -sku user:pass https://<mgmt-ip>:443/mgmt/tm/sys  > /dev/null
 
real    0m10.030s
user    0m0.057s
sys     0m0.024s
tests using curl with localhost or 127.0.0.1 show latency as:
# time curl -sku user:pass https://127.0.0.1:443/mgmt/tm/sys  > /dev/null
 
real    0m0.150s
user    0m0.054s
sys     0m0.022s
 
  1. When taking traffic capture on the mgmt and lo interfaces, you may observe that the httpd daemon may receive the requests but it takes some time(eg. 3 seconds or more) to forward your request to the restjavad daemon. Environment

  • BIG-IP LTM
  • iControl RESTful API

Cause

Due to Bug ID 1113385, the expired REST tokens are not deleted. The number of token entries under the /run/pamcache will also increase when the time elapsed. While the number of token entries becomes larger, the httpd daemon searches for a valid token for a longer time, too.

Recommended Actions

You may use the below command to delete the token files for a temporary workaround: 
find /run/pamcache -regextype posix-extended -type f -regex '/run/pamcache/[a-Z0-9]{filename_length}' -delete
# For example,if you have tokens with length 40 like: /run/pamcache/MPedkXsvr0L6ytxuo3mdxuobhiIXB4J42xRWBGOR
find /run/pamcache -regextype posix-extended -type f  -regex '/run/pamcache/[a-Z0-9]{40}' -delete
IMPORTANT: It could also delete some valid tokens so it might influence ongoing RESTful API requests and you may need to request a valid token again. 
Note: You may need to check and verify the token length and replace the filename_length placeholder to execute the command.

For long-term considerations, you should upgrade your software version to the fixed version listed under Bug ID 1113385.
