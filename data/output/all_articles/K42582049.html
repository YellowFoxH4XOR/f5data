Description

  • The AD Query AAA object in an APM Profile uses port 389. Can this be changed to port 636? (LDAPS)

Environment

  • APM provisioned.
  • AAA resource of type Active Directory  created.
  • Creating AD Query Object in the Policy.

Cause

  • No, the Active Directory AAA server  uses GSSAPI security over port 389. This cannot be changed.

Recommended Actions

  1. If you must use port 636, configure an LDAP AAA object to use LDAPS and use a LDAP Query object in the Policy.
