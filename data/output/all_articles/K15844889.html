Description

Upgrading a BIG-IP GTM or DNS to a software version higher then current discovered BIG-IP LTMs

You may see a monitor status of no reply from big3d: timed out on one or more BIG-IP GSLB server objects

Environment

  • BIG-IP GTM or DNS
  • BIG-IP LTM
  • The BIG-IP GTM or DNS has been upgraded to a version higher then the current then that on the currently configured LTM server objects
  • BIG-IP GSLB managed server objects

Cause

Upgrading a BIG-IP GTM or DNS to a software version that is higher then that of the configured LTM server objects can cause the big3d agent to time out. Most current versions of software you will no see issues with this.

Recommended Actions

You do either of the following :

  • Upgrade the BIG-IP LTMs first Note: See Related Content below for best practices
  • In cases where the BIG-IP GTM or DNS must be upgraded first, monitor the iQuery status between devices using tmsh show gtm iquery. If you see connectivity issues occur, refer to K13312 for steps on using big3d_install to upgrade the other BIG-IP's iQuery version.

Additional Information

Note: GTMs must be on the same software version to be able to sync
