Description

Observing messages similar to the following in /var/F5/system/log/platform.log:

appliance-1 appliance-orchestration-manager[8]: priority="Info" version=1.0 msgid=0x6701000000000004 msg="INFO." details="Failed to ssh to 127.0.0.1.".
appliance-1 appliance-orchestration-manager[8]: priority="Err" version=1.0 msgid=0x6704000000000001 msg="ERROR ." details="PINGLOOP Failed to ssh to127.0.0.1".

The second message may appear multiple times.

What is the root cause of these messages? Are they cause for concern?

Environment

  • F5OS-A
  • rSeries
  • Appliance Orchestration Manager (AOMD)

Cause

Appliance Orchestration Manager runs a check every 30 seconds to determine if the host system (127.0.0.1) is available. These messages appear when the check fails.

Recommended Actions

If the messages appear as an occasional one-off, days or weeks apart, and there is only a single instance of them, they should not be cause for concern. This can happen due to a busy AOMD, busy sshd, or other transient issue.

If the check was continuously failing, the PINGLOOP Failed to ssh message would be printed continuously, every 30 seconds.

Review the output of show cluster to verify that the appliance's cluster state is healthy.

If the messages are continuously appearing, this means that there is a problem with the system, possibly related to availability of the root user account or sshd service. Further investigation is required. Bug ID1393269 is one possible root cause.
