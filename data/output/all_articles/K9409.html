Known Issue

This is the result of a known issue. If the prelogon sequence rule Check Files (MacOSX) is applied, Power Mac users using Firefox will experience a crash of their browser. If Firefox does not crash immediately, it will hang indefinitely. This behavior is the result of an issue with the InspectionHost plugin. As an immediate workaround, users can use an alternate browser, such as Safari.

F5 Product Development is tracking this issue as CR89277. This issue does not exist in FirePass version 6.0.3.

Additionally, this issue was fixed in FirePass cumulative hotfix HF-602-8, which has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
