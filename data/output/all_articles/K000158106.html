K000158106: ASM Live Update not working after upgrade to the 17.5.1.3

Type
Support Solution
Published
2025-12-08
Updated
2025-12-08
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000158106

Description

After upgrading BIG-IP ASM to version 17.5.1.3, users may encounter the following issues with the Live Update feature:

  • On the active device, navigating to System > Software Management > Live Update displays: "There are no provisioned modules that support live update," even though the ASM module is provisioned and actively blocking malicious traffic.
  • On the standby device, attempts to save Live Update configuration result in a "Failed to save configuration" error.

Environment

  •  BIG-IP ASM
  • Software upgrade
  • Live Update feature

Cause

Bug ID 1856513

Recommended Actions

  1. Apply the workaround described in Bug ID 1856513 to restore Live Update functionality.
  2. Reconfigure Live Update scheduling and installation settings as needed.
  3. Verify successful signature updates manually and via scheduled tasks.
  4. Maintain a backup of configuration prior to upgrades for recovery if needed.
