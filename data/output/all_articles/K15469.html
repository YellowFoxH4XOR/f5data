Known Issue

Loading the BIG-IP configuration from the command line may incorrectly enable ICMP Echo for virtual addresses.

This issue occurs when the following condition is met:

  • The Traffic Management Shell (tmsh) is used to load the BIG-IP configuration.

    For example:

    tmsh load /sys config

Due to a condition in code, when you use tmsh to manually load the BIG-IP configuration, some virtual addresses that were previously configured with ICMP Echo disabled may have ICMP Echo set to enabled after the configuration load is completed.

Impact

The BIG-IP system may respond to ICMP Echo requests for IP addresses that are actually offline or non-existent. This may impact troubleshooting and could adversely affect devices that have ICMP monitors configured.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system responds to ICMP Echo requests for network virtual IP addresses that are offline or do not exist.
  • The BIG-IP system responds to ICMP Echo requests for host virtual IP addresses that are offline or were not previously configured to respond to ICMP echo.

Workaround

There is no workaround.

To mitigate this issue, disable ICMP Echo for each virtual address after loading a configuration from the command line. To do so, perform the following procedure:

Impact of workaround: ICMP Echo may be enabled the next time you perform a configuration load.

Disable ICMP Echo for the virtual address

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Confirm which virtual addresses have ICMP Echo enabled by typing the following command:

    list ltm virtual-address icmp-echo

  3. Disable ICMP Echo for a virtual address using the following command syntax:

    tmsh modify ltm virtual-address <virtual address> icmp-echo

    For example:

    tmsh modify ltm virtual-address 10.11.12.0 icmp-echo disabled

    Note: Repeat this command for each virtual address where you want to disable ICMP Echo.

  4. Once all virtual addresses have been updated, save the change by typing the following command:

    save /sys config
