Known Issue

This is the result of a known issue. When you create more than 127 IP Address Pools, the 128th and subsequent pools are unusable. When you assign one of the unusable pools to a Network Access Favorite, users will not receive IP addresses from the range configured in the pool. Instead, users will receive IP addresses from the Default pool. IP Address Pools are configured on the Network Access: Global Settings page.

F5 Product Development tracked this issue as CR78954 and it was fixed in FirePass version 6.0.2. For information about upgrading refer to the FirePass release notes.

Additionally, a hotfix has been issued. For version 6.0.1 of FirePass software, this issue was fixed in Cumulative Hotfix HF-601-5. For version 5.5.2 of FirePass software, this issue was fixed in Cumulative Hotfix HF-552-9. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
