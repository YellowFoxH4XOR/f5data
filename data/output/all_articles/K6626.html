Known Issue

This is the result of a known issue. When you remove the only active member from a pool, the bigpipe command may inaccurately display the active members in a pool as 1. This issue does not affect the Configuration utility, which will correctly display that all members in the pool are unavailable.

F5 Product Development tracked this issue as CR66808 and CR68144 and it was fixed in BIG-IP LTM versions 9.1.3 and 9.2.4. For information about upgrading, refer to the BIG-IP LTM release notes.
