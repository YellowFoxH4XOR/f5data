Known Issue

On VIPRION hosts with multiple 10-Gb interfaces bundled into a Brocade switch, interfaces may remain down after a reboot.

This issue occurs when all of the following conditions are met:

  • You are running on a 4300 or 4340 VIPRION blade.
  • You have one or more 10-Gb interfaces in a bundle connected to a Brocade switch.

Impact

Interfaces remain down, causing loss of connectivity.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H507810 on the Diagnostics > Identified > Medium page.
  • Brocade switches display PHY sync failure on affected interfaces.
  • The BIG-IP system shows interfaces as down.

Workaround

To work around this issue, you can disable and reenable the affected interfaces. To do so, perform the following procedure:

Impact of workaround: Affected interfaces will be forced down and all data temporarily stopped.

  1. Log in to the Configuration utility.
  2. Navigate to Network > Interfaces > Interface List.
  3. Select all the interfaces associated with the affected bundle.
  4. Click Disable.
  5. Reselect all the interfaces associated with the affected bundle.
  6. Click Enable.
