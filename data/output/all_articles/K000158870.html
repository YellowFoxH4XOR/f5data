K000158870: XC Configurations - why is expired configuration is still visible in the console?

Type
Support Solution
Published
2025-12-20
Updated
2026-06-18
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud Shared Configuration
Source
https://my.f5.com/manage/s/article/K000158870

Description

You created a temporary configuration (e.g. a rule or a deny-list) with an expiration date.

When that date arrives you still see the rule or deny-list in your configuration and you want to know if that is the default behavior and if it is still active.

Environment

  • F5® Distributed Cloud (XC)

  • HTTP Load Balancer
  • Service Policies

Answer/Recommended Actions

F5 XC will not automatically purge data that you created if it expires, F5 will only deactivate it. 

If you do not want to see it in your configuration, you need to delete it. F5 lets you choose to remove temporary configuration or leave them for future reference. Once the expiration date passed they are no longer active.
