Known Issue

BIG-IP APM access policy session variable data may be unavailable for iRule use.

This issue occurs when the following condition is met:

  • A BIG-IP APM access policy uses an iRule that attempts to retrieve session data variables from the ACCESS_SESSION_CLOSED event.

Impact

The access policy iRule is unable to retrieve session data variables.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H457120 on the Diagnostics > Identified > Medium screen.
  • Access policy iRules that are configured to perform an action based on session variable data from the ACCESS_SESSION_CLOSED event do not function.
  • Access policy iRules that are configured to log session variable data for the ACCESS_SESSION_CLOSED event do not log the intended data.
  • Access policy iRules that trigger on ACCESS_SESSION_CLOSED events log messages similar to the following example in the /var/log/apm file:

    info tmm1[9977]: Rule /Common/POLICY_IRULE : CLOSING SESSION
    info tmm1[9977]: Rule /Common/POLICY_IRULE :
