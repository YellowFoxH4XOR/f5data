Description

When access the AFM module on Configuration Utility, the system keeps displaying "Task not found" error on Configuration Utility. You may observe similar error messages as below:

An error occurred:
Task not found - ID: xxxxxxxxxxxxxxxx user: yyyy

You may observe similar error message in /var/log/icrd shown as below:

notice icrd_child[<PID>]: 21077,21099, iControl REST Child Daemon,WARNING,Task not found - ID: xxxxxxxxxxxxxxxx user: yyyy

Environment

  • BIG-IP AFM
  • After software upgrade.

Cause

This issue is related to the control plane REST API functions and it should not cause any traffic impact.

Recommended Actions

To fix this issue, please restart the below two services:

tmsh restart sys service restnoded
tmsh restart sys service restjavad

Restarting those two services should not cause significant impact on your systems, but you may not be able to access the control plane, until they are restarted. After the restart, you may use the below two commands to check those services:

tmsh show sys service restnoded
tmsh show sys service restjavad
