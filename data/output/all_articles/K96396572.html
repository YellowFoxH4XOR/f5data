Description
You would like to check the irule execution count of an irule.

Environment

  • BIG-IP
  • iRule

Cause
None

Recommended Actions

  1. Login into command line and use the command below to show the execution count of an irule
    • # tmsh show ltm rule <replace-with-irule-name>
  2. Login into command line and use the command below to reset the statistics of an irule
    • # tmsh reset-stats ltm rule <replace-with-irule-name>
