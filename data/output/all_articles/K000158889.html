Description

 This article describes how to request file removal after uploading the data to the case. 

Environment

BIG-IP

BIG-IQ

Cause

Customer security policy requirement to ensure sensitive files shared during troubleshooting are removed from the support case record

Recommended Actions

Contact F5 Support and request file removal, providing:

  • Case number
  • The reason for the removal of the files

F5 Support will submit an internal IT ticket to perform the deletion.

Ask F5 Support for written confirmation once the removal is completed.

Additional Information

There is no automatic process/timer that deletes all files from a TAC case; deletion is handled only through an internal IT ticket/request.
