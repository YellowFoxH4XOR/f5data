Description

This article provides support and configuration details for Crypto Offloading (SSL handshake offload to external BIG-IP hardware) and Intel QuickAssist Technology (QAT) on BIG-IP Virtual Edition (VE) running on Microsoft Hyper-V, rSeries appliances, and KVM environments. Symptoms include questions about SSL throughput enhancement, whether rSeries appliances can act as Crypto Server, and whether Intel QAT is supported on Hyper-V.

Environment

  • BIG-IP VE running on Microsoft Hyper-V (Generation 1)
  • BIG-IP VE running on KVM
  • BIG-IP tenants (vCMP Guests) on rSeries appliances
  • BIG-IP LTM version 17.1.2.2 and 17.5.0
  • Intel QAT hardware
  • Crypto Offloading deployment scenarios

Cause

  • BIG-IP tenants on rSeries appliances have SSL accelerator support and can act as Crypto Server for Crypto Offloading, enabling offload of SSL encryption/decryption.
  • BIG-IP VE does not support Intel QAT on Microsoft Hyper-V hypervisor; QAT support is limited to KVM environments.

Recommended Actions

  • To offload SSL handshakes from BIG-IP VE, deploy BIG-IP tenants on rSeries appliances as Crypto Server. Configure the crypto client/server relationship using appropriate SSL profiles and ciphers.
  • For cryptographic acceleration using Intel QAT, use BIG-IP VE on KVM hosts only. Follow platform-specific configuration guides for enabling QAT and SR-IOV.
  • BIG-IP VE running on Microsoft Hyper-V does not support Intel QAT. Do not attempt QAT configuration on Hyper-V.
  • For optimal SSL performance on Hyper-V, ensure host CPU supports AES-NI and follow F5 recommendations for Hyper-V throughput optimization.
  • Refer to platform-specific documentation for supported deployment scenarios and configuration steps.

Additional Information

  • Lab verification confirms rSeries appliances can act as Crypto Server for Crypto Offloading.
  • Intel QAT support for BIG-IP VE is documented for KVM and not for Hyper-V.
  • No official documentation or support exists for QAT on Hyper-V; confirmed by F5 Product Development.
  • Crypto Offloading is available for BIG-IP tenants on VELOS and rSeries platforms.
  • For Hyper-V, ensure recommended CPU and memory settings for best performance; QAT is not available.
