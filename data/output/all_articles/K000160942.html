K000160942: Addressing high interface OUT errors on BIG-IP APM Connectivity profile tunnel interfaces

Type
Support Solution
Published
2026-04-22
Updated
2026-04-22
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160942

Description

Persistent "Interface OUT Errors" alerts are triggered by monitoring tools on BIG-IP APM connectivity profile tunnel interfaces (such as /CES/ces-sslvpn-connectivity). These alerts occur when monitoring systems poll the ifOutErrors OID for all interfaces, including virtual tunnel interfaces, and report high error rates. The issue is characterized by:

  • Repeated alerts for high Interface OUT Errors on APM connectivity profile tunnel interfaces.
  • High out_errors statistics visible via tmctl or SNMP polling.
  • No similar errors observed on physical interfaces.
  • Most prominent on BIG-IP Virtual Edition devices with high VPN usage.

Environment

  • BIG-IP APM version 17.5.1
  • BIG-IP Virtual Edition
  • APM connectivity profile tunnel interface attached to a Network Access VPN virtual server
  • Compression enabled on the connectivity profile (initially)
  • Monitoring system polling IF-MIB OIDs (e.g., ifOutErrors) for all interfaces, including tunnel interfaces

Cause

High Interface OUT Errors on the APM connectivity profile tunnel interface are typically caused by enabled compression and insufficient VPN egress buffer size, leading to buffer exhaustion and error accumulation in environments with heavy VPN usage.

Answer/Recommended Actions

  1. Disable Compression:
    • Turn off compression on both the APM connectivity profile and the associated Network Access resource.
  2. Increase VPN Egress Buffer Size:
    • Incrementally increase the vpn.buffervolumekb database variable (e.g., to 128 or higher).
    • Monitor the vpn_egress_buffer_full counter to ensure it stabilizes.
    • Example commands:

    tmsh modify sys db vpn.buffervolumekb value <value>

    tmsh save sys config

  3. Adjust Monitoring Configuration:
    • Consider excluding APM connectivity profile tunnel interfaces from interface error monitoring.
    • Alternatively, adjust alert thresholds to avoid false positives, as high out_errors can be expected in high-usage VPN environments.
  4. Monitor Results:
    • Continue to monitor out_errors and buffer statistics after applying these changes to confirm improvement.

Additional Information

  • Disabling compression and increasing buffer size can help resolve high Interface OUT Errors on tunnel interfaces.
