K000139063: RDP connection with RDP Gateway settings fails on NA with Client Proxy enabled

Type
Support Solution
Published
2024-04-17
Updated
2024-04-17
Source
https://my.f5.com/manage/s/article/K000139063

Description

 

RDP connection with RDP Gateway settings fails on Network Access tunnel with Client Proxy enabled

 

This message appears:

 

There was a problem connecting to the remote resource. Ask your network administrator for help.

 

Environment

 

  • BIG-IP APM v17.X
  • Network Access with Client Proxy settings enabled
  • Windows RDP client with Gateway manually set or MSTSC command with Gateway set.

 

Cause

 

Unknown at the time of this writing

 

 Recommended Actions

 

  • Disabling Client Proxy enabled for the affect RDP service.
  • Add a new Client Type branch on VPE in order to filter out this kind of connection (optional)
