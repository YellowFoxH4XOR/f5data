Known Issue

A FirePass MS File Shares static tunnel application favorite fails to mount on computers running Windows 7.

This issue occurs when the following condition is met:

  • The FirePass MS File Shares static tunnel application favorite uses the FQDN of the server to mount the file share.

Impact

Users are unable to access file shares through FirePass.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Users may receive an error message that appears similar to the following example:

    An error occurred while mounting remote share <share name> to <drive letter>
    The network path was not found

  • The system may continually prompt users for their username and password.

Workaround

To work around this issue, you can either Statically define the Local Host IP address, or use the server IP address to mount the file share. To do so, perform the following procedure:

Statically defined localhost IP configuration

This procedure will map the localhost IP address to 127.0.0.1.

Impact of workaround: This workaround will limit the favorite to mapping a single share.

The DNS Relay Proxy Service must be installed on the client computer. Refer to the following Solution for more information on the DNS Relay Proxy Service: K9694: Overview of the DNS Relay Proxy service

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access : App Tunnels : Resources page.
  3. Select the resource group that contains the MS File Shares favorite you are editing from the Resource Group: dropdown menu.
  4. Click the name of the App Tunnel Favorite you are editing.
    The favorite will expand.
  5. Scroll to the STATIC TUNNELS section.
  6. Replace the value in the Local Host textbox with 127.0.0.1.

Replacing the FQDN of the share server with an IP address

Impact of workaround: This procedure will limit the file share to a single server, breaking distributed file sharing.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Application Access : App Tunnels : Resources page.
  3. Select the resource group that contains the MS File Shares favorite you are editing from the Resource Group: dropdown menu.
  4. Click the name of the App Tunnel Favorite you are editing.
    The favorite will expand.
  5. Scroll to the STATIC TUNNELS section.
  6. Replace the server DNS name in the application text box with the server IP address.
