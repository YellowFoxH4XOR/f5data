Topic

FirePass versions 7.0.0 and later include the option to control password caching on the BIG-IP Edge Client and BIG-IP Edge Portal applications. In order to make access convenient for the user, this option allows the user to store a password on the client device to transparently log on to FirePass without entering a password for authentication. Conversely, enabling password caching creates a security risk allowing anyone with access to the client device to be able to access resources configured through the client device without knowing the user password to FirePass. You can enable or disable this ability through the FirePass Administrative Console.

Configuring the password caching policy

Note: The BIG-IP Edge Client and BIG-IP Edge Portal applications only support the Allow user to save encrypted password on disk option.

  1. Log on to the FirePass Administrative Console.
  2. Navigate to Device Manager : Client Downloads : Windows (x86).
  3. Click the BIG-IP Edge Client tab.
  4. Scroll to the User Permissions section.
  5. Select the Dynamically Download Session Settings During Logon check box.

    Note: When this option is enabled, a user cannot change the session settings when connected to a FirePass controller. If this option is not enabled, the session settings configured in the connectivity profile are not enforced, and current user preferences are used instead.
  6. Scroll to the Session Settings section.
  7. Select the Maintain History check box.

    Note: This option must be enabled to enable user password caching.
  8. Selecting the Enable User Password Caching check box will enable the user to save their password on the client device.

    Clearing the Enable User Password Caching check box will prevent the user from saving their password on the client device; the password field in the configuration in the BIG-IP Edge application will be grayed out and display the following message:

    Disabled by the Server Policy
  9. Click the Allow user to save encrypted password on disk option.
