Known Issue

This is the result of a known issue. When using the image2disk utility without the --nosaveconfig option or the --nomoveconfig option to upgrade the BIG-IP system from BIG-IP version 9.3.x or 9.4.x to 10.x, the installation module creates a UCS archive file and stores it temporarily in the /shared directory as part of the upgrade process. If the storage space on the /shared directory is insufficient to store this UCS archive file, the installation module will fail with the following error messages:

info: /tmp/configsync.spec: Error creating package
info: 
info: WARNING:There are error(s) during saving.
info:         Not everything was saved.
info:         Be very careful when using this saved file!
info: 
info: Error creating package
info: BIGpipe: 01110001:3: Error running config save
info: ----
Terminal error: create_ucs failed; Illegal seek

Note:  For more information about the contents of a UCS archive file, refer to K4422: Viewing and modifying the files that are configured for inclusion in a UCS archive.

Note: For more information about the –nosaveconfig and –nomoveconfig options for the image2disk command, refer to K11267: Controlling configuration import when performing installations from Configuration utility.

F5 Product Development is tracking this issue as ID 343554.

Workaround

You can work around this issue by performing storage utilization checks on directories that the UCS archive file backs up, such as the /config, /home, and /shared directories, and removing any unnecessary files, such as network captures during troubleshooting (typically tcpdumps with the .dmp or .pcap extension) and ISO image files before proceeding with the upgrade. To do so, perform one of the following procedures:

Removing unnecessary files before proceeding with the upgrade

  1. To list out the size of file(s) in megabytes residing in a directory and sort in descending order with respect to the file sizes, type the following command:

    du -m -cs <path/to/directory/*> | sort -k 1n 
     
    For example, to list out the size(s) of file(s) in the /config directory, you would type the following command:

    du -m -cs /config/* | sort -k 1n

    The following command output displays the tcpdump file lb1_vlangroup1.dmp of 242 megabytes, and the ISO image file BIGIP-10.1.0.3341.0.iso of 746 megabytes:

    1       /config/user_alert.conf
    1       /config/wa
    242     /config/lb1_vlangroup1.dmp
    746     /config/BIGIP-10.1.0.3341.0.iso
    990     total
  2. To remove the unnecessary file(s) in a directory, type the following command:

    rm –rf <path/to/filename>

    Using the example output from Step 1, to remove both the ISO image file and the tcpdump file from the /config directory, you would type the following command:

    rm –rf /config/BIGIP-10.1.0.3341.0.iso /config/lb1_vlangroup1.dmp

Removing unnecessary files after creating the UCS archive file

If you have already created a /config.ucs UCS archive file as recommended by the BIG-IP Systems: Getting Started Guide, you can follow the steps outlined in K12278: Restoring a UCS archive may fail due to insufficient free disk space to reduce the size of the /config.ucs UCS archive file before proceeding with the upgrade. Alternatively, you can follow the steps in the Remove unnecessary files before proceeding with the upgrade section within this workaround, and recreate the /config.ucs UCS archive file before proceeding with the upgrade.
