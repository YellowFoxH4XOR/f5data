Description

An iCall script could not run and produced an error similar to:

err scriptd[15203]: 014f0013:3: Script (/Common/my_icall_script) generated this Tcl error: (script did not successfully complete: ("$" unknown property

Environment

iCall script included ${variable} substitution within nested curly braces. For example,

tmsh::<command> { ${variable} }

Cause

The issue is due to how TCL (Tool Command Language) processes strings enclosed in curly braces { }. In TCL, strings within { } are treated as literals, meaning no substitutions or evaluations occur for variables like ${action} in the following example:

tmsh::modify gtm pool a testpool { members modify { genericserver0:vs0 { ${action} }}}

Here, ${action} is treated as a literal string "${action}" rather than being substituted with its value.

Recommended Actions

To enable variable substitution within the iCall script, you can use double quotes " instead of curly braces {} for the string containing the variable. For example:

tmsh::modify gtm pool a testpool "members modify { genericserver0:vs0 { ${action} }}"
