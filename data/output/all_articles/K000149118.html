K000149118: High TMM Memory Usage Observed with Low Traffic on BIG-IP with ASM Provisioned

Type
Support Solution
Published
2024-12-27
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000149118

Description

You observed slightly high TMM memory usage on a BIG-IP ASM provisioned system, even when there is very little traffic passing through the device. An examination of the memory_usage_stat tmstat table indicates significant memory usage by "DoS Layer ACY," which is an ASM function within TMM.

Environment

  •  BIG-IP ASM provisioned

  • Low traffic passing through the system

  • DoS Layer ACY shows significant usage in memory_usage_stat output

Cause

The memory usage by "DoS Layer ACY" is expected behavior. When ASM is provisioned, memory allocation for the DoS Layer 7 ACY function within TMM is reserved, regardless of whether ASM is actively being used.

Answer/Recommended Actions

We recommend monitoring the memory usage to ensure it stays within the expected range. If memory usage significantly exceeds the expected range, further investigation might be needed to ensure no other underlying issues are present.

Additional Information

Memory usage per TMM thread for ACY Layer 7 is expected to range from 70 to 100 MB.

For example, in an appliance with 8 CPU cores (and thus 8 TMM threads), the total memory allocation for DoS Layer 7 ACY could be up to 800 MB. This memory allocation is used for different signature sets.
