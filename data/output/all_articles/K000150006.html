Description

This solution will explain why Session Variables do not display in a Custom Report and how to configure the APM to display them.

  • Session Variables do not display in a Custom Report

Environment

  • Session Variables
  • Custom Report
  • VPE (Virtual Policy Editor)
  • APM

Cause

For session variable names and values to be available in custom reports, the policy must include the Logging action and the Logging action must specify the session variables to log.

Recommended Actions

For example you want to display Active Directory session variables such as session.ad.last.attr.cn


Add a Logging Profile to the Virtual Policy Editor

  1.  Login to the Admin GUI
  2. Navigate to Access>Profiles / Policies : Access Profiles (Per-Session Policies)
  3. Click on the Edit icon under the Per-Session Policy column.
  4. In the VPE add a Logging object from the General Purpose tab.
  5. Click on the Logging object name.
  6. Click Add Entry and select Active Directory from the drop down.
  7. You now see if adds session.ad.last.* to be logged.

You can then use the following to create a custom report:

K09102347: How to create a Custom Report for APM logging
