Issue

Error Message

alert <daemon>[20843]: pam_unix(<daemon>:account): could not identify user (from getpwnam(<username>))

In this error message, note the following:

  • <daemon> is indicative of the login method used
  • <username> is the user name of a remote user account

For example:

  • alert sshd[21052]: pam_unix(sshd:account): could not identify user (from getpwnam(devuser))
  • alert httpd[20843]: pam_unix(httpd:account): could not identify user (from getpwnam(devuser))

Message Location

You may encounter this message in the following location:

  • The /var/log/secure file

Description

This message occurs when all of the following conditions are met:

  • Remote authentication is enabled and configured on the BIG-IP system.
  • A remote user without a corresponding local user account logs in to the BIG-IP system.

Impact

None. You can safely ignore this message.

Recommended Actions

None
