K000149507: Low space available on vCMP Host in the /appdata folder

Type
Support Solution
Published
2025-02-04
Updated
2025-02-21
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149507

Description

 A low disk space error was identified in /var/log/ regarding the /appdata partition, with the following error message:

011d0004:3: Disk partition /appdata has only 16% free.

Environment

  • BIG-IP
  • vCMP Host environment
  • Multiple vCMP Guests configured

Cause

Deflated images from older versions previously utilized by the guests taking up a large amount of space in the /appdata folder.

The image file will likely look like this:

/appdata/mprov/global/vmdisks/templates/BIGIP-15.1.5.1-0.0.14.iso.img.deflated

Recommended Actions

Remove the deflated iso img files with below command:

#rm /appdata/mprov/global/vmdisks/templates/BIGIP-15.1.5.1-0.0.14.iso.img.deflated

Additional Information

The '/appdata' directory is a crucial component in the system, and issues related to it can impact the system's functionality.
