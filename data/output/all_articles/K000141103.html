Description

When restoring an existing UCS archive using 'bigip_ucs' Ansible module getting

fatal: [192.168.2.1]: FAILED! => {"changed": false, "msg": "Expecting value: line 1 column 1 (char 0)"}

error message although on the end device the UCS restoration process kicks in and successful.

 

Environment

f5-ansible 1.29.0 is in use to collect UCS archives.

 

Cause

Software error.

 

Recommended Actions

Fix is available in f5-ansible 1.30.0 version.
