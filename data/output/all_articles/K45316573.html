Description

Routes are injected to Kernel even when the virtual-address is down.
 

Environment

  • Dynamic Routing
  • BIG-IP LTM
  • Static route present for the virtual-address which went down

Cause

When there is a static route configured for a Virtual Address, this route will be injected into Zebos as a kernel (K) route. Even if a virtual server goes down, the kernel route coming from a static route will still remain in the Zebos routing table and be redistributed into OSFP. This is working as intended/configured.

Recommended Actions

None

Additional Information

Working as designed
