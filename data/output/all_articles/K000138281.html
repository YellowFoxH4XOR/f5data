Description

You performed a security scan, which highlighted the use of a potentially dangerous JavaScript eval() function, in the loader.js file. This file is part of the public JavaScript resources of a BIG-IP system. Its location is https://apmprotectedwebsite/public/include/js/modern/loader.js, used in the modern layout of the logon page. The primary concern is whether the presence of eval() in loader.js poses a security risk, and if there are any plans to alter or remove this feature to enhance site security.

 

Environment

Modern Layout for the APM Logon Page

Cause

The eval() function is identified as a potential security risk due to its ability to execute arbitrary code.

Recommended Actions

No action is required regarding the use of eval() in the loader.js file. We concluded that the function's usage in this context does not pose a security risk. The eval() function is part of the require.js library used for Asynchronous module definition (AMD) modules, there has been confirmation that no custom loader plugins requiring eval are in use here. Consequently, the loader.js, which is a combination of different files, does not execute any code associated with it.

Following detailed reviews and testing, we have affirmed that the eval() function’s presence does not compromise security within the BIG-IP system’s setup.
