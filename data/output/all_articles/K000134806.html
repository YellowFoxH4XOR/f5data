Description

After upgrading the TMOS, the iRule LX extension doesn't work. You find logs similar to the following on /var/log/ltm.

 

018e0010:3: Extension <extention name> exceeded the maximum number of restarts (5) over the last 60 seconds and has been disabled

 

018e000e:3: Process heartbeat timeout exceeded for extension <extention name>, terminating the extension

 

Environment

You are using iRule LX.

 

Cause

Those logs show that the iRule LX extension has reached the maximum number of restart times (Maximum Restarts). The default value is set as 5. If it exceeds the threshold the extension is not restarted automatically.

 

Recommended Actions

You can change the Maximum Restarts by accessing the Configuration Utility and selecting Local Traffic > iRules > LX Plugins > [LX Plugin Name] > Extensions > [Extention Name] > Maximum Restarts. The value needs to be more than 5 (e.g. 500).
