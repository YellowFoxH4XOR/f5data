Topic

In BIG-IP 13.1.0, F5 introduces multiple improvements for BIG-IP APM systems configured in high availability (HA) deployments.

Description

Beginning in BIG-IP 13.1.0, the following improvements are available:

  • The system does not limit BIG-IP APM configuration objects to traffic-group-1. However, you must configure all BIG-IP APM related objects in a single traffic group.
  • BIG-IP APM systems can support up to eight members in a device service clustering (DSC) device group.
  • BIG-IP systems can support multiple traffic groups, also referred to as an active-active deployment, but you must restrict APM traffic objects to a single traffic group. The system cannot have BIG-IP APM related traffic objects in multiple traffic groups. This means that you must deploy HA configurations for APM traffic groups in an active-standby-standby (N + M) topology.

Important: Only a single BIG-IP APM system can be active for a traffic group; therefore, active-active deployments of BIG-IP APM in a single DSC are not possible.

BIG-IP 13.0.0 and earlier versions have the following limitations:

  • APM systems must have single traffic group deployments with two BIG-IP systems in a DSC device group (also referred to as active-standby).

    Note: Any other deployment may result in unwanted behaviors, including the possibility of the apd process exiting and producing a core file.

  • You must limit BIG-IP APM configuration objects to traffic-group-1.

Recommendations

When you configure more than two BIG-IP APM systems in a device group, all members in the device group must be running BIG-IP 13.1.0 or later.
