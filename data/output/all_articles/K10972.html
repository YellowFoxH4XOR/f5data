Known Issue

This is the result of a known issue. The description section of the show health command displays a leading period for an spnAliasUpdateRaise event. The description appears similar to the following example:

System Health Information
Date                     ID      Event                       Description
---------------------------------------------------------------------------------------
Fri Dec 25 12:34:56 2009 (725) - spnAliasUpdateRaise         . global server: testGlobalServer (domain: testDomain)

Note: This is a display issue and does not impact the ARX system's functionality.

F5 Networks Product Development tracked this issue as ARX ID 37035 and it was fixed in ARX version 5.1.5. For information about upgrading, refer to the ARX Release Notes.
