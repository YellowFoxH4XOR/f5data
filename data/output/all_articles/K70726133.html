Topic

The BIG-IP APM system supports Security Assertion Markup Language (SAML) single logout (SLO) by exchanging SAML logout messages over the asynchronous HTTP POST binding or HTTP Redirect binding.

Description

SAML SLO allows near simultaneous logout of all associated Principal (user) sessions provided by a particular session authority (Identity Property). The logout can be directly initiated by the Principal or by the session authority.

You establish a local session when authenticating at the Identity Provider (IdP). You can later establish sessions with several service providers (SP) by means of SAML single sign-on (SSO). As the IdP generates SAML responses, it is aware of all SP connections associated with the user's session. Therefore, when the user logs out from the IdP or from one SP, the IdP can notify all other relevant SPs.

The BIG-IP APM system supports SAML SLO both for SP and IdP. In addition, SAML SLO can be initiated at the SP and the IdP.

SP-initiated SLO (HTTP POST binding)

The following diagram shows the flow for SP-initiated SLO:

Note: The following steps assume the BIG-IP APM system is configured as both SP and IdP. If using a third-party vendor as SP or IdP, the sequence remains, but paths for SLO messages may be different.

Sequence

  1. You initiate the logout in the application.
  2. SP1 triggers SAML SLO by sending a POST Logout Request message to the IdP.
  3. The IdP validates the request and send new POST Logout Request messages to all other participant SPs (with which the user has established a session).
  4. All other participant SP’s (with the exception of the original SP) validate the Logout Request message and respond with a POST Logout Response message to the IdP.
  5. The IdP delete the user session and send a POST Logout Response message to the original SP.

Sequence

1. The user/administrator initiates the logout at the webtop.
2/4. The IdP validates the request and sends new POST Logout Request messages to all participant SPs.
3/5. All other participant SPs validate the Logout Request message and responds with a POST Logout Response message to the IdP.
