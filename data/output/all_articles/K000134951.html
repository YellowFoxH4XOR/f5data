K000134951: LTM GUI and tmsh pool connection statistics are incorrect

Type
Support Solution
Published
2023-06-07
Updated
2023-06-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.3
Source
https://my.f5.com/manage/s/article/K000134951

Description

GUI and tmsh pool connection statistics are incorrect
For some pool members the current connections shows as "0" when there is actual traffic/connection. This can be confirmed via show sys connection output and tcpdump.

Environment

  • LTM
  • Pool members
  • Connections
  • Statistics

Cause

The merged process is not getting the cluster stats

Recommended Actions

You can restart the merged process

1. Connect to CLI
2. Run the following command:

tmsh restart sys service merged

Additional Information

None
