Known Issue

This is the result of a known issue. In deployments where FirePass Portal Access is used to access Citrix resources, the FirePass controller automatically starts an Application Tunnel for the Citrix ICA traffic between the remote client and Citrix servers. The Application Tunnel assigns an IP address in the loopback range (127.0.0.1 to 127.255.255.255) to the client's loopback interface to process the ICA traffic.

When the date on the FirePass controller is April 12th, 2008 or later, an incorrect calculation of run-time variables that generates the loopback IP address causes the Application Tunnel to fail. No ICA communication will be possible.  When users attempt to access a Citrix resource, they may receive an error message in a pop-up window that appears similar to the following example:

Error
Could not create tunnel on loopback interface
Reason: An invalid argument was supplied.

A second pop-up window, which is the browser pop-up from the Application Tunnel normally opened for the ICA communication, may show the IP address or DNS name of the Citrix server being mapped to an IP address that is not in the loopback range, but rather in a range with the first octet of 126.

For example:

(172.30.1.1:1494 => 126.146.43.209)

F5 Networks Product Development tracked this issue as CR98051 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-552-12 issued for FirePass version 5.5.2, cumulative hotfix HF-601-11 issued for FirePass version 6.0.1, and cumulative hotfix HF-602-5 issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

Additionally, a hotfix has been issued for FirePass maintenance release versions 5.5.2 and 5.5.1. To obtain the hotfix, contact F5 Networks Technical Support.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
