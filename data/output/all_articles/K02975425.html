Source

Description
Device is licensed with Better/Best license and first level menu appears for IPS system despite IPS not being licensed

Environment

  • Device is licensed with a Better/Best License
  • AFM is provisioned

Cause
Better/Best licenses have AFM and PSM enabled. PSM is an additional AFM related licensed product that is related to IPS and has a similar menu path to IPS.

Recommended Actions

  1. If IPS is needed, add license as detailed in K25265787.
