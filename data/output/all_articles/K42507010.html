Known Issue

The BIG-IP system displays duplicate security policies after an upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM configuration has multiple security policies that use the same revision number.
  • You upgrade your BIG-IP ASM system to an affected release.
  • You use the Configuration utility or REST interface to view the configured security policies.

Impact

None. The actual number of security policies is not affected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the Configuration utility or REST interface to view security policies, some policies are listed multiple times.
  • When you use the Traffic Management Shell (tmsh) to view the number of configured security policies, the listed policies match the pre-upgrade policies.

Workaround

To work around this issue, you can modify each of the duplicated policies and then apply the policies. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Security Policies.
  3. Select the affected security policy.
  4. In the Security Policy Description box, modify the contents.
  5. Click Save.
  6. Click Apply Policy.
  7. Repeat steps 2 through 6 for each duplicated security policy.
