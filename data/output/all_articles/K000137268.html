Source
https://my.f5.com/manage/s/article/K000137268

Description

  • Some BIG-IP AS3 declarations fail with HTTP 500 error
  • REST requests timeout after 30 seconds regardless of sys db variables setting
  • REST reply output is similar to the following:

    <html>
    <head>
    <meta http-equiv="Content-Type" content="text/html;charset=ISO-8859-1"/>
    <title>Error 500 AsyncContext timeout</title>
    </head>
    <body><h2>HTTP ERROR 500 AsyncContext timeout</h2>
    <table>
    <tr><th>URI:</th><td>/mgmt/shared/appsvcs/declare</td></tr>
    <tr><th>STATUS:</th><td>500</td></tr>
    <tr><th>MESSAGE:</th><td>AsyncContext timeout</td></tr>
    <tr><th>SERVLET:</th><td>com.f5.rest.app.RestServerServlet-11f39f9</td></tr>
    </table>
    <hr/><a href=https://eclipse.org/jetty>Powered by Jetty:// 9.4.49.v20220914</a><hr/>
    </body>
    </html>

Environment

  • BIG-IP
  • AS3
  • iControl REST API

Cause

Bug ID 1325685, which is identical to Bug ID 1040573.

Recommended Actions

At the time this article was published:

  • For 15.1.x versions, upgrade to software version 15.1.10 or later.
  • For 16.1.x versions, upgrade to software version 16.1.5 or later
  • For 17.x versions, upgrade to software version 17.1.1 or 17.5.0 or later.

If you are encountering a "failed to save BIG-IP configuration" error, it may be caused by a lack of disk space. Refer to K000133208: Unable to save configuration for more information.
