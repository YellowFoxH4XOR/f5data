Answer/Recommended Actions

Security logging and monitoring failures are frequently a factor in major security incidents. The BIG-IP system includes advanced logging and monitoring functionality and provides security features to protect against attacks that can result from insufficient system and application logging and monitoring.

For more information, please visit: A09:2021-Security Logging and Monitoring Failures 

 

How to access your security logs

1. Select the Security option from the left menu, and you can check all the Load Balancers that belong to the tenant.

2. Organize by Security events, so you can identify which LB is under attack, and select the Load Balancer in question.

3. Once you select the Load balancer, you will get all the information of the security events, or top signatures hit Top Attack Types, etc, over the Dashboard tab.

Filter by the Security


1. You can navigate also to the Security Analytics tab and filter by different types of events.

2. The request tab option, will show the different types of client IP, Origin Server with more traffic or request, along with the date/time.
