K11886: Multiple System IDs that use the same System Name may result in incorrect attack signature associations after upgrading to BIG-IP ASM version 10.2.0

Known Issue

This is the result of a known issue. If a BIG-IP ASM configuration defines multiple System IDs that reference the same System Name, and the BIG-IP ASM system is upgraded to version 10.2.0, the resulting attack signature associations may be incorrect.

The intended behavior is for the BIG-IP ASM system to combine the records from multiple System IDs referencing the same System name into a single System ID to which the related signatures and filters are then associated. However, the BIG-IP ASM system erroneously associates some of the related records to a different system name. As a result, the post-upgrade configuration may contain incorrect attack signature associations for some System Names.

Note: For information about examining the attack signature sets configured on your BIG-IP ASM system, refer to K11680: Comparing signature sets on different systems.

F5 Product Development is tracking this issue as ID 226639 and ID 324377 (formerly CR141891).

This issue has been fixed for ID 324377 in Hotfix-BIGIP-10.2.0-1744.0-HF1 for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
