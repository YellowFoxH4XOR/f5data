Known Issue

The bd process may stop responding when the remote logger profile is changed from User Datagram Protocol (UDP) to TCP.

This issue occurs when all of the following conditions are met:

  • You change the remote logger profile from UDP to TCP.
  • The BIG-IP ASM system is configured with web scrapping detection and is undergoing a web scrapping attack.

Impact

The BIG-IP ASM system may temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP ASM system generates a bd core file to the /shared/core directory.
