Environment

  • Telemetry Streaming running a Prometheus Pull every 30 seconds.
  • AS3 declaration is downloading security Policies XML files from a url.

Recommended Actions

Workarounds

- Disable the Prometheus Pull operation when deploying the AS3 declaration.
or
- Copy the Security Policies XML files to the bigIP and update the AS3 declaration to reflect that change

                     "TEST_WAF_Policy": {
                             "class": "WAF_Policy",
                             "file": "/<local path to security profile file>",
                             "ignoreChanges": false
                         }

Fix

This issue is fixed in AS3 v3.36.0
