Known Issue

When you search and reset the audit log in the Configuration utility, the BIG-IP system does not behave as expected.

This issue occurs when the following condition is met:

  • You click the Search or Reset button on an audit log.

Impact

You are unable to search or reset audit logs.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If you click the Search or Reset buttons on audit logs, the BIG-IP system displays the following error message:

    An error has occurred while trying to process your request

Workaround

To work around this issue, you can use TMOS Shell (tmsh) or Advanced Shell (bash) commands to search the audit log from the command line.

If you use tmsh, you can use the tmsh show /sys log audit command, or if you want, create a bash script to parse the /var/log/audit log file.
