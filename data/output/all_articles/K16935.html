Topic

The support for Transport Layer Security (TLS) Fallback Signaling Cipher Suite Value (SCSV) is introduced in BIG-IP 12.0.0, BIG-IP 11.6.0 HF3, 11.5.2, 11.5.1 HF6, 11.5.0 HF6, 11.4.1 HF6, 11.4.0 HF9, 11.2.1 HF13, and 10.2.4 HF10.

Description

The support for the TLS Fallback SCSV in SSL ClientHello transactions is introduced to make TLS virtual server connections more resilient against protocol downgrade attacks on the TLS protocol. When the ClientHello message contains the SCSV marker and the client protocol offered is not the latest that the Client SSL virtual server supports, a fatal alert is sent. Additionally, the BIG-IP system logs a warning message similar to the following example in the /var/log/ltm file: 

warning tmm3[18260]: 01260009:4: Connection error: ssl_select_suite:7988: TLS_FALLBACK_SCSV with a lower protocol (86)

SSL communication with clients that support the TLS Fallback SCSV are more resilient against downgrade attacks. However, both the client and the Client SSL virtual server must support this feature for it to be enforced.

TLS Fallback SCSV is enabled system-wide with the ssl.fallback_scsv db variable.
