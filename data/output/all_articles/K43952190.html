Description

  • When trying to add, then apply an ASM policy to a virtual server a GUI error appears showing "No Access"
  • Error messages:
    • WebUI Log (/var/log/webui.log): /tmui/Control/form returning response as, No Access
    • GUI: No access is displayed within a grey banner with yellow triangle

Environment

  • Enabling an ASM policy on a Virtual Server
    or
  • Running the HA Setup wizard
    or
  • Other GUI configuration elements including APM configuration items can display this error

Cause

This is due to a known bug, ID 1042993: Provisioning high availability (HA) setup wizard fails to load, reports "No Access"

Recommended Actions

Please contact F5 support to request an EHF on your code version to resolve this issue.
