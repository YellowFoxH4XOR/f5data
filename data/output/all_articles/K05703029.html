Topic

The BIG-IP system responds to Address Resolution Protocol (ARP) and Internet Control Message Protocol (ICMP) Echo requests for secure network address translation (SNAT) pool addresses by default, even if they are not referenced by objects in the running configuration.

Description

When you configure a SNAT pool using the Configuration utility or the TMOS Shell (tmsh), the BIG-IP system sends gratuitous ARP requests for the member IP addresses and begins responding to ARP requests and ICMP Echo requests for the IP addresses.

This behavior is by design and allows iRules to reference the SNAT pool, even if the SNAT pool is not currently referenced by any configuration objects. For example, the following iRule dynamically selects the appropriate SNAT pool based on the request URI:

when HTTP_REQUEST { 
    if { [HTTP::uri] starts_with "path1" } {
        snatpool pool1 
        }
    if { [HTTP::uri] starts_with "path2" } {
        snatpool pool2
        }
}

Because the iRule dynamically selects a SNAT pool that is not associated with the virtual server, disabling ARP for the addresses in the SNAT pool causes unexpected behavior and traffic disruptions. 

Recommendations

There is no option to disable ARP for the member IP addresses when creating a new SNAT pool. You can disable ARP on the individual SNAT pool addresses. However, this will also affect any other SNAT pool that references the address. To disable ARP for individual SNAT pool member IP addresses, perform one of the following procedures:

Configuration utility

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Local Traffic > Address Translation > SNAT Translation List.
  3. Click the name or IP address.
  4. Clear the Enabled box for the ARP setting.
  5. Click Update.

tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Configure ARP for the SNAT pool address using the following command syntax:

    modify /ltm snat-translation <IP address> arp <enabled | disabled>

    For example, to disable ARP for the SNAT pool address 10.10.10.10, type the following command:

    modify /ltm snat-translation 10.10.10.10 arp disabled
