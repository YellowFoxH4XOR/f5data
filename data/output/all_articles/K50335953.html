Description

You have an external monitor marked as down, after activating monitor logging for the pool member or node affected and reviewing the monitor log you see the following error message:

(spawn_external_pinger): EAV execve: No such file or directory

Environment

  • External monitor

Cause

This happens due to internal Bug ID 401443: FileObject should better handle dos-style (CR+LF) newline.

The most common scenario for this happening is importing an external monitor from Windows and not sanitizing it for UNIX.

Recommended Actions

  1. Log in to the BIG-IP Configuration utility as an administrative user.
  2. Navigate to System > File Management > External Monitor Program File List.
  3. Open the external monitor you want to fix.
  4. Remove any commented/empty line in the EAV file starting from the second line.
  5. Click Update.

An example for step 4, if these are the first three lines of your EAV file:

#!/bin/sh
# external-monitor
# Created by: Username

Remove the second line so the first two lines look like this:

#!/bin/sh
# Created by: Username
