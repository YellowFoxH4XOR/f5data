Known Issue

The sysObjectID SNMP OID returns the incorrect string.

This issue occurs when the following condition is met:

  • An SNMP client requests the sysObjectID SNMP OID from a BIG-IP system.

Impact

Unpredictable behavior occurs for monitoring systems that rely on the correct sysObjectID SNMP OID response string.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Requests for the sysObjectID SNMP OID return "net-SNMP Linux" instead of "F5 Load Balancers Generic."
