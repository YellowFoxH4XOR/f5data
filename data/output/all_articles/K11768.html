Known Issue

This is the result of a known issue. The Diameter profile Overwrite Destination Host setting, which is enabled by default, specifies whether the BIG-IP system uses the existing destination host or overwrites the destination host value in the Diameter request with the pool member's IP address. The Overwrite Destination Host setting does not overwrite the destination host value in the request with the pool member's IP address as expected.

F5 Product Development is tracking this issue as ID 224786 (formerly CR137700).

This issue has been fixed in a hotfix. To request the hotfix, contact F5 Technical Support, referencing this Solution number and the associated ID numbers. For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Note: Additionally, the BIG-IP system sends Device-Watchdog-Answer messages with empty Origin-Host and Origin-Realm fields. For more information, refer to  K11767: The BIG-IP system sends Device-Watchdog-Answer messages with empty Origin-Host and Origin-Realm fields.
