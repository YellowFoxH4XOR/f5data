Known Issue

This is the result of a known issue. Using an On-Demand Cert Auth action in an access policy on BIG-IP APM Virtual Edition (VE) will fail. As a result, the client browser will hang when attempting to load the SSL session.

This issue is caused by the SSL re-handshake process handled in the hardware layer of BIG-IP. In BIG-IP APM VE, the hardware layer is emulated and does not provide the full functionality of an actual controller. The request for a client certificate is never sent to the client and causes a condition in which the client browser continues to wait for additional information, and the On-Demand Cert Auth action waits for the client browser to respond with a client certificate.

F5 Product Development tracked this issue as ID 226465 and was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.
