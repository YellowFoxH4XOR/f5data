Known Issue

This is the result of a known issue. 3-DNS adds a forward slash (/) to the beginning of the text that you add in the File Name field. If you enter an absolute path in the File Name field, 3-DNS will still add the forward slash. This results in a file name that begins with two forward slashes (//). Since this is not a valid path, the ECV health monitor will fail.

F5 Networks Product Development tracked this issue as CR27823 and CR41897.
