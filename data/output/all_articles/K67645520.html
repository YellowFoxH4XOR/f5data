Description

Transparent policies started blocking traffic after upgrade

Environment

  • ASM
  • Transparent policies
  • Upgrade

Cause

ASM DCC database got corrupted during the upgrade

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Save new UCS if no pre-upgrade UCS is available:

    tmsh save sys ucs test.ucs

  2. Extract UCS to temporary directory:

    rm -rf /var/tmp/UCS; mkdir -p /var/tmp/UCS; cd /var/tmp/UCS; tar -xzf /var/local/ucs/test.ucs

  3. Make it executable:

    chmod a+xw /var/tmp/UCS; chmod a+xw /var/tmp/UCS/var/tmp

  4. Run upgrade script with a slight spoof of the UCS version.  This will force a re-activation of all policies from the UCS essentially repopulating the DCC DB.  This process may take 20+ minutes and can be monitored in /var/log/asm:

    /usr/share/ts/bin/ts_configsync.pl -a load --ucs_version <source version> --bigip_version <target version> --dir /var/tmp/UCS/var/tmp

    Example:

    /usr/share/ts/bin/ts_configsync.pl -a load --ucs_version 15.1.5.0 --bigip_version 15.1.5.1 --dir /var/tmp/UCS/var/tmp
