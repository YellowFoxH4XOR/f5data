Known Issue

The destination server may appear to drop Internet Control Message Protocol (ICMP) packets sent by the BIG-IP system.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured with TCP virtual servers that use the FastL4 profile.
  • You enable SYN cookie protection.
  • The BIG-IP system initiates ICMP messages.
  • The destination device responds to the ICMP request with a Fragmentation Needed (Type 3 Code 4) message.

Impact

The ICMP communication fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When analyzing ICMP communication for the BIG-IP system and destination device, the destination appears to stop responding after receiving a reply to the Fragmentation Needed message.
  • When analyzing ICMP communication between the BIG-IP and the destination device, the packet level SEQ number and/or ACK number set by the BIG-IP system is incorrect when responding to the Fragmentation Needed message.
  • The TCP level communication between the BIG-IP system and the destination device is aborted.
