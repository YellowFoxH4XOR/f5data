Description

High CPU usage may be observed on BIG-IP systems when SSL profiles are configured with RSA keys of non-standard sizes, such as 4094 bits. This configuration can lead to performance degradation and traffic disruption. Standard key sizes (2048 or 4096 bits) are recommended for optimal hardware acceleration.

 

Environment

  • Product: BIG-IP LTM
  • SSL Configuration: Server SSL profiles using RSA keys with a size other than standard.

 

Cause

RSA keys with non-standard sizes (such as 4094 bits) are not supported by hardware acceleration modules in F5 appliances. As a result, all cryptographic operations for these keys are processed in software, significantly increasing CPU utilization during SSL handshake and data processing.

 

Recommended Actions

  • Use Standard Key Sizes for Hardware Acceleration
  • Generate a new certificate and private key using a standard length.
  • Replace the existing certificate/key in the affected server SSL profile(s) with the newly generated one.

To update the certificate/key:

        1. Create the new certificate/key pair.
        2. Import it into BIG-IP.
        3. Assign it to the relevant server SSL profile(s).
        4. Save and apply changes.

 

Additional Information

  • Always validate changes in a test environment before applying them to production systems.
  • Review your organization’s security policy regarding minimum key lengths before making changes.
