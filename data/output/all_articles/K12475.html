Topic

On busy BIG-IP WebAccelerator systems, the performance report data stored on the device may grow very large. As a result, displaying performance reports using the Configuration utility may become slow or stop working entirely.

The pvsystem.conf file contains a section that controls the collection of data used to generate performance reports. You can customize certain aspects of the data collection process in order to best suit your needs and/or resolve possible issues with the display of performance reports.

BIG-IP WebAccelerator version 10.x

The /config/wa/pvsystem.conf file contains the following section:

<perfMonitor>
<enablePerfMonitor>true</enablePerfMonitor>
<dataRetentionPeriod>30</dataRetentionPeriod>
</perfMonitor>

You can change the following settings:

  • To disable performance data logging entirely, change the <enablePerfMonitor> setting from true to false.
  • To change how long performance data is retained, change the <dataRetentionPeriod> setting from its default value of 30. This value is measured in days.

After making any changes, restart the required services by typing the following command that applies to your version:

  • BIG-IP WebAccelerator version 10.1.0 or later:

    bigstart restart pvac tomcat

  • BIG-IP WebAccelerator version 10.0.x:

    bigstart restart pvac tomcat4

BIG-IP WebAccelerator versions 9.x and 5.x

The pvsystem.conf file (located in the /config/wa/ directory in version 9.x and in the /opt/pivia/dac/conf/ directory in version 5.x) contains the following section:

<perfMonitor>
<enablePerfMonitor>true</enablePerfMonitor>
</perfMonitor>

In these versions, you can only disable performance data logging entirely. To do so, change the <enablePerfMonitor> setting from true to false. You can then restart the required services by typing the following command that applies to your version:

  • BIG-IP WebAccelerator version 9.x:

    bigstart restart pvac tomcat4

  • BIG-IP WebAccelerator version 5.x:

    service pivia restart
