Topic

You cannot install BIG-IP 11.0.0 or later on BIG-IP 10.x systems that run in partitions disk format.

Description

You cannot upgrade BIG-IP 10.x systems that run in partitions disk style to BIG-IP 11.0.0 or later, which uses only volumes disk format.

If you use the image2disk command to attempt to install or upgrade a BIG-IP 10.x system that is running in partitions disk format, you will receive a terminal error.

If you attempt to install or upgrade to BIG-IP 11.3.0 or later, you observe an error message similar to the following example:

sfdisk: ERROR: sector 164304 does not have an msdos signature
sfdisk: ERROR: sector 8338176 does not have an msdos signature
Terminal error: Can't find requested disk HD1.

If you attempt to install or upgrade to BIG-IP 11.0.0 through 11.2.1, you observe an error message similar to the following example:

Terminal error: The current system disk format, partitions, is not compatible with the selected product and version. Please consult the 'Getting Started Guide' chapter on the 'image2disk' utility for reformatting options.

The installation or upgrade process will fail due to incompatibility of the disk format.

Recommendations

  1. Save the user configuration set (UCS) file and copy it to another workstation.
  2. Perform a clean installation of BIG-IP 11.0.0 or later using the instructions in K13117: Performing a clean installation of BIG-IP 11.x - 13.x or Enterprise Manager 3.x.
  3. Restore the configuration using the saved UCS file.

    For more information, refer to the Restoring UCS archives on BIG-IP systems running later software versions section in K13132: Backing up and restoring BIG-IP configuration files (11.x - 13.x)
