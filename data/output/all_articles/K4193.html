Topic

You can customize the BIG-IP status window settings as follows:

  • Enable or disable the status window.
  • Specify the polling rate.
  • Specify bits or connections displayed per second.

You can modify the BIG-IP status window settings using the Configuration utility or the command line.

Configuration utility

To modify the BIG-IP status window settings using the Configuration utility, perform the following steps:

  1. Log in to the Configuration utility.
  2. Open the status window.
  3. Click anywhere in the status window to bring up the configuration menu.
  4. Specify the settings as follows:
    • Check or uncheck the Status Window Enabled checkbox to enable or disable the status window.

      Note: BIG-IP updates the information in the status window every 60 seconds, even when the status window is disabled.

    • In the Polling Rate field, enter the number of seconds (a value between 1 and 1000) that BIG-IP should wait before updating the information displayed in the status window.

      Note: The default value is 15 seconds.

    • Configure the status window to display connections or bits per second. From the Show Statistic menu, specify Connections/sec or Bits/sec.
  5. Click the Apply button.

The settings are updated, but any changes made to the Polling Rate will not take effect until the current Polling Rate updates the window.

Command line

To modify the BIG-IP status windows settings using the command line, perform the following steps:

  1. Log in to the command line.
  2. Specify the settings as follows:
    • Enable or disable the status windows as follows:
      • To enable, type the following command:

        bigpipe db set Common.Bigconf.JavaStatus.Enabled = 1

      • To disable, type the following command:

        bigpipe db set Common.Bigconf.JavaStatus.Enabled = 0

        Note: BIG-IP updates the information in the status window every 60 seconds, even when the status window is disabled.

    • Change the Polling Rate, by typing the following command:

      bigpipe db set Common.Bigconf.JavaStatus.PollRate = <seconds>

      Where <seconds> is the number of seconds (a value between 1 and 1000) that BIG-IP should wait before updating the information displayed in the status window.

      For example:

      bigpipe db set Common.Bigconf.JavaStatus.PollRate = 15

      Note: The default value is 15 seconds.

    • Configure the status window to display connections or bits per second, as follows:
      • To display bits per seconds, type the following command:

        bigpipe db set Common.Bigconf.JavaStatus.StatOption = 0

      • To display connections per seconds, type the following command:

        bigpipe db set Common.Bigconf.JavaStatus.StatOption = 1

        Note: The default value is 0 (bits per second).
