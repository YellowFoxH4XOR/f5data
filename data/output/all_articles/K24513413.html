Issue

Error Message

warning tmm<#>[<PID>]: 01200012:4: Warning, connections equals limit <client_IP>:<client_port> -> <virtual_IP>:<virtual_port>, proto <protocol>, VS <virtual_name>: Connection limit reached

In this error message, note the following:

  • <#> is the number of the Traffic Management Microkernel (TMM) process that generated the message.
  • <PID> is the process ID for the TMM process.
  • <client_IP> is the IP address of the client connecting to the BIG-IP system.
  • <client_port> is the port used by the client.
  • <virtual_IP> is the virtual IP address of the BIG-IP system for the connection.
  • <virtual_port> is the port number used by the virtual address for the connection.
  • <virtual_name> is the name of the configuration object that reached the connection limit.

For example:

warning tmm1[<pid>]: 01200012:4: Warning, connections equals limit 10.10.10.10:37384 -> 10.10.10.20:80, proto TCP, VS /Common/example_virtual: Connection limit reached

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The configured connection limit has been reached for one of the following objects in the BIG-IP configuration:
    • virtual server
    • virtual address

The BIG-IP system divides the configured connection limit for a given object by the number of TMMs running on the system, and distributes the remainder among the lower-ordered TMMs.

Note that connections may not be distributed evenly across TMM instances, and, if the number of the running TMMs is high, the configured connection limit on each single TMM may be easier to reach. For more information on how the connections are distributed, refer to: K14358: Overview of Clustered Multiprocessing (11.3.0 and later)

Impact

Subsequent connections to the affected address processed by this TMM process are rejected.

Recommended Actions

To mitigate this issue, you can modify the configured connection limit to a value that is more appropriate for your environment. To do so, perform the following procedures as needed:

Impact of procedures: The following procedures increase the the allowed number of connections to the BIG-IP system, which may impact resources. You should perform testing in order to determine an appropriate connection limit value for your environment.

  • Modifying the connection limit for a virtual server
  • Modifying the connection limit for a virtual address

Modifying the connection limit for a virtual server

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers > Virtual Server List.
  3. Select the name of the affected virtual server.
  4. For Configuration, select Advanced.
  5. For Connection Limit, enter an appropriate value.
  6. Select Update.

Modifying the connection limit for a virtual address

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Virtual Servers > Virtual Address List.
  3. Select the name of the affected virtual address.
  4. For Connection Limit, enter an appropriate value.
  5. Select Update.
