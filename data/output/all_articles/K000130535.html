K000130535: All interfaces down on replacement appliance

Type
Support Solution
Published
2023-01-09
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5, 15.1.8
Source
https://my.f5.com/manage/s/article/K000130535

Description

While attempting to install a replacement appliance, most of the interfaces are down.

Environment

  • Links are enabled.
  • Trunk/Vlan is configured.
  • SFPs and cables reseated
  • End user Diagnostic passes

Cause

Bundling is enabled on the interface, but it is unnecessary. It needs to be disabled to match the 10 GB configuration on the switch side.

Recommended Actions

Disable bundling on the interfaces.

tmsh modify net interface 3.0 4.0 5.0 6.0 disabled bundle disabled
tmsh save sys config

Note: Updating the bundle status causes the broadcom process (bcm56xxd) to restart. This impacts traffic on ALL links. Perform this work during a maintenance window.

Additional Information

  • Check the bundling status on the interface:
tmsh list net interface <#>

net interface 3.0 {
bundle enabled
description none
enabled
...
vendor F5 NETWORKS INC.
vendor-partnum OPT-0036
}
  • Check the status of this link the LTM logs:
/var/log/ltm
012c0015:6: Link: 3.0 is DOWN
012c0015:6: Link: 4.0 is DOWN
012c0015:6: Link: 5.0 is DOWN
012c0015:6: Link: 6.0 is DOWN
