Known Issue

Dynamic routing may fail for self IP addresses with modified VLAN associations.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured for dynamic routing.
  • You modify a self IP address VLAN association.

Impact

Dynamic routing removes route entries for the self IP address.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Networks that the dynamic routing protocol advertised or learned may not be reachable if the networks depend on the self IP address as a connected route.

Workaround

To work around this issue, you can use the tmrouted process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will temporarily disrupt dynamic routing by the BIG-IP system. 

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Type the following command:

    restart /sys service tmrouted

  3. To exit the tmsh utility, type the following command:

    quit
