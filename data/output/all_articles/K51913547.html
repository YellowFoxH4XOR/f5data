Description

  • Unable to login via GUI with valid user and password
  • Getting password error when trying to login
  • The following error message can be seen on /var/log/httpd/httpd_errors

    err httpd[20805]: [auth_pam:error] [pid 20805] [client 10.10.10.1:49545] AUTHCACHE PAM: Could not start pam service: Critical error - immediate abort

  • The output from the following command is different than 755

    stat --format '%a' /config
    700                           <--- Should be 755

Environment

  • BIG-IP GUI
  • Configuration utility

Cause

Directory /config file permission is not set to correctly which prevents the auth service to start.

Recommended Actions

  1. Connect to CLI
  2. Correct /config directory permission running the following command

    chmod 755 /config

  3. Validate using the following command that now output is 755

    stat --format '%a' /config

  4. Restart services on the system to restore normal access

    bigstart restart httpd && bigstart restart tomcat
