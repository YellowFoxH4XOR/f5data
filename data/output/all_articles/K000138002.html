K000138002: logrotate[XXXX]: ALERT exited abnormally with [1] message occurring after upgrade

Description

After an upgrade, the message logrotate[17568]: ALERT exited abnormally with [1] is continuously generated in /var/log/message 

Environment

  • BIG-IP LTM
  • Upgrade 

Cause

Incorrect directory permissions

Recommended Actions

  1. Verify the directory permission for the directory /var/log/ts by using the command
    # ll /var/log/.


    The directory permission should look like this:

    drwxr-xr-x. 7 root root 4096 < Date> ts

  2. If file permissions don't match, run the command
    # chmod 755 /var/log/ts

Additional Information

For more information on directory permissions, refer to Linux / Unix mod permissions
r - read (4) 
w - write (2) 
x - execute (1) 

Total value indicates what permissions a folder/file has. 
example: rwx = 4 + 2 + 1 = 7 
The first permission is for the owner, the second permission is for the group, and the third is for the rest of the users. 
In the above scenario (755) is the permission for (owner, group, and others)
