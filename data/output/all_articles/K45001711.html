Known Issue

Under rare conditions, the Traffic Management Microkernel (TMM) may restart when a virtual server with a Fast HTTP profile receives fragmented IP packets.

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the TMM restart, and devices configured as a high availability (HA) pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • In the /var/log/tmm file, your BIG-IP system logs an entry that appears similar to the following example:

    panic: Assertion 'l4hdr set' failed

Workaround

To work around this issue, you can use a standard virtual server with TCP and HTTP profiles instead of a Fast HTTP profile.
