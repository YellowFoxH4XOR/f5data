Security Advisory Description

When a virtual server is configured with HTTP explicit proxy and has an attached HTTP_PROXY_REQUEST iRule, POST requests sent to the virtual server cause an xdata memory leak. (CVE-2020-5883)

Impact

The BIG-IP system may become vulnerable to conditions that result when it is out of memory because of a memory leak.
