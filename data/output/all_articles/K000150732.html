K000150732: Attempting to change GSLB Pools names via AS3 declaration, but the changes aren't showing up.

Type
Support Solution
Published
2026-08-26
Updated
2026-08-26
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.1.0
Source
https://my.f5.com/manage/s/article/K000150732

Description

Attempting to rename all GTM (BIG-IP DNS) GSLB pools with AS3 declaration. The declaration gets submitted successfully but the changes aren't showing up in the BIG-IP DNS system.


Environment

BIG-IP DNS

AS3


Cause

GSLB pools cannot simply be renamed.


Recommended Actions

GSLB pools must be deleted and then recreated with the new name.


Additional Information

None
