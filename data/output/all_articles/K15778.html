Known Issue

The BIG-IP APM access profile forms-based client-initiated authentication may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile is configured to use the BIG-IP APM single sign-on (SSOv2) forms-based client-initiated authentication.
  • Users are attempting to authenticate with the Internet Explorer browser.

Impact

User authentication may intermittently fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP APM user can intermittently fail to authenticate when attempting to access configured resources.
