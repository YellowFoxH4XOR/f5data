Known Issue

The BIG-IP system does not respond to connections to self IP addresses when the SYN Check Activation Threshold is exceeded

This issue occurs when the following conditions are met:

  • The SYN Check Activation Threshold is exceeded
  • The BIG-IP system receives a connection attempt or a packet for an existing connection on a self IP address

The default value for the Syn Activation Threshold setting is 16384 connections.

Impact

Connections to self IP addresses may stall or fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Connections to self IP addresses may stall or fail to initiate as expected.
  • A tcpdump indicates that the BIG-IP system silently drops connection attempts to self IP addresses.
