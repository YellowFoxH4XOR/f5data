Description

The versionDatetime value from /tm/asm/policies API is showing a different value to that of the security policy version via the GUI

 

Environment

  • BIG-IP ASM
  • API
  • versionDatetime is different in GUI

Cause

These values are stored in different databases on BIG-IP

Recommended Actions

Query the same source for consistency
