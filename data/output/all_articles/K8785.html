Known Issue

This is the result of a known issue. If you install OPSWAT 2.5.6 (hotfix-97554) or OSPWAT 2.5.7 (hotfix-99074) on the FirePass controller, and you configure the Windows firewall checker in a pre-logon sequence, users may fail the pre-logon check even if the Microsoft Windows Firewall is enabled on the client system. When this issue occurs, the Windows firewall checker correctly detects that the Microsoft Windows Firewall is installed, but it cannot determine whether the firewall is enabled.

F5 Networks Product Development tracked this issue as CR99915 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in OPSWAT 2.5.7 Update (hotfix-99915) issued for FirePass version 5.5, 5.5.1, 5.5.2, 6.0.1, and 6.0.2. You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Networks Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
