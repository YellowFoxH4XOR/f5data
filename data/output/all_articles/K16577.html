Topic

You should consider using this procedure under the following condition:

  • You want to reset the LineRate configuration.

Description

You may want to reset the current LineRate configuration to the state when the system was first installed.

This operation requires you to rename the existing /home/linerate/data/startup-config file and reboot the system. Without the designated file, the system will automatically regenerate the default configuration. The previous configuration is retained under the different file name.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have console command line interface (CLI) access to the LineRate system (not SSH).

Procedures

Resetting the LineRate configuration

Important: This procedure requires use of the FreeBSD mv command through the LineRate bash CLI command. Note that F5 does not officially recommend configuring LineRate using FreeBSD commands.

This procedure resets only the system configuration and the settings you have made through the LineRate CLI commands. Operation data, such as log files and traffic statistics, are kept untouched. The file-based scripts are also retained. However, the scripts embedded inline in the configuration file will be removed.

For example, the myScript.js script, which is stored in the /home/linerate/data/scripting directory, will remain in that directory. The following example configuration that calls the myScript.js file will no longer exist:

script myScript
 source file "myScript.js"
 admin-status online

Impact of procedure: Performing this procedure disconnects all active traffic. IP addresses assigned to interfaces will be removed. You will need direct console access (not SSH) to access the system. All licensing information will also be deleted.

  1. Log in to the LineRate system using the console.
  2. To display the registration key, type the following command:

    show licensing regkey

    The command output appears similar to the following:

    AYWTCR-RHQKE-ASKF5-JLYT-BEDLOHD

    Note: Save this information in order to relicense the system when you have completed this procedure.

  3. To save your current configuration, type the following command:

    write

  4. To rename the existing startup-config file, type the following command:

    bash "sudo mv /home/linerate/data/startup-config /home/linerate/data/startup-config.sol16577"

    Note: You must use double quotes (as noted in the previous example) to enclose the command string.

    The example command renames the startup-config file to startup-config.sol16577. Any file name extension is acceptable.

  5. To reboot the system, type the following command:

    reload

    1. The system will prompt you to save the currently active configuration. Answer no:

      System configuration has been modified.  Save? [yes/no]: no

    2. The system will display messages similar to the following and prompt you to confirm. Press Enter:

      Executing reload command - user: admin

      WARNING: This command will terminate all operations and reboot the system immediately.

      Proceed with reload? [confirm]

    3. The system will display messages similar to the following and reboot:

      *** FINAL System shutdown message from root@linerate.askf5.local ***

      System going down IMMEDIATELY

When the system finishes rebooting, you can begin to rebuild your configuration.
