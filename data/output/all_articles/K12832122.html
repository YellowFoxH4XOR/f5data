Issue

Error Message

011ae20a:5: CRL not found for certificate with subject <subject> from issuer <issuer>

In this error message, note the following:

  • <subject> is the entity or organization to which a certificate belongs.
  • <issuer> is the entity that verified the information and signed the certificate.

For example:

011ae20a:5: CRL not found for certificate with subject C = US, ST = WA, L = Sea, O = F5, OU = ES, CN = server from issuer C = US, ST = WA, L = Sea, O = F5, OU = ES, CN = server.

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • The system is configured to check for revoked SSL certificates for iQuery communication; however, the CRL file and the SSL certificate used by iQuery are not signed by the same issuer.

Starting in BIG-IP 16.x, you can configure the system to check for revoked SSL certificates for components that use the iQuery communication mechanism, such as BIG-IP DNS synchronization. To use the feature, you must install a valid PEM-encoded CRL to the BIG-IP system.

Impact

The BIG-IP system may reject remote iQuery connections.

Recommended Actions

Make sure the /config/revoked_certs.crl file and SSL device certificate are signed by the same issuer.
