Known Issue

This is the result of a known issue. The Applie iOS Edge Client fails to connect when accessing a web application that contains a landing URI. This occurs because the client does not pass the VHOST cookie to the controller. A landing URI directs the browser to a specific web page or virtual directory.

For example:

https://www.siterequest.com/owa/ or https://www.siterequest.com/stats.html

F5 Product Development is tracking this issue as ID 348117.
