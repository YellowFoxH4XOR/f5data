Known Issue

BIG-IP GTM wide IP alias updates may cause memory to leak.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is configured with wide IP aliases.
  • You add, delete, or modify a wide IP alias using the Configuration utility or the Traffic Management Shell (tmsh).

Impact

A small amount of memory used to perform the wide IP alias action does not return to the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When adding, deleting, or modifying wide IP aliases, each action causes the amount of memory that the zrd process uses to increase slightly.
  • When adding, deleting, or modifying hundreds or thousands of wide IP aliases, the amount of memory that the zrd process uses may be significant.
  • In extreme memory utilization scenarios, the BIG-IP GTM system may experience performance degradation (over time) and reboot.

Workaround

To temporarily work around this issue, you can restart the zrd process to clear the excess utilized memory. To do so, perform the following procedure:

Impact of workaround: ZoneRunner DNS resolution will be temporarily unavailable while the zrd process restarts.

  1. Log on to the tmsh utility of the affected system.
  2. Restart the zrd process by typing the following command:

    tmsh restart /sys service zrd
