K4145: Recovering the configuration if the one-time conversion utility (OTCU) does not properly convert it

Topic

When you upgrade from version 4.x to version 9.x, the one-time conversion utility (OTCU) will attempt to convert your existing configuration. If the configuration is complex, the conversion may fail. To recover from this situation, perform the following procedure:

  1. View the OTCU log file and look for errors, by typing the following command:

    more /var/tmp/otcu.log

    Note: The errors provided are generally descriptive enough to help you isolate the statements in the configuration that are causing the issue. If you need help interpreting the error messages, contact F5 Technical Support.

  2. Load the converted configuration, by typing the following command:

    bigpipe load /var/tmp/otcu_9.0/config/bigip.conf.otcu

  3. The BIG-IP system should report any errors that it encountered while loading the configuration, including the line number at which the error occurred.
  4. Remove the configuration statement that is causing the error.
  5. Repeat Step 2 to reload the configuration.
  6. If the BIG-IP system reports another error, repeat Step 3. You may need to repeat this process multiple times if there are multiple errors.
  7. When you eliminate all the errors that occur while loading the configuration, copy the temporary configuration file to the /config directory, by typing the following command:

    cp -p /var/tmp/otcu_9.0/config/bigip.conf /config/bigip.conf

  8. Recreate the configuration statements that you removed, using the appropriate BIG-IP version 9.x commands.

Your configuration should now work correctly in BIG-IP version 9.x.
