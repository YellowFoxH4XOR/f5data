Known Issue

Note: All interfaces accept jumbo frames; therefore, they should record the frames as Good Oversize Frames whether or not the VLAN is configured for them. For more information, refer to the Configuring Layer 2 chapter in the ARX CLI Network Management Guide.

This is the result of a known issue. The show channel <#> stats command will always display 0 (zero) for the number of Good Oversize Frames, even if the the channel has received oversize frames. This behavior is a display issue and it does not affect the ARX system behavior.

Note: For information about the show channel command, refer to the ARX CLI Reference Guide.

The show channel <#> stats command output will appear similar to the following example:

show channel 1 stats

Channel Id  : 1
[...]
-------------------------------------------------------------------
                                  Ether Stats
-------------------------------------------------------------------

Packet Size:64                   725163
            65-127              8517942
            128-255             2358634
            256-511              445922
            512-1023               3684
            1024-1518             30474
            1522-2047            117704
            2048-4095                 0
            4096-9216                 0
[...]
Good Oversize Frames                  0

F5 Product Development tracked this issue as ID 37905 and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.
