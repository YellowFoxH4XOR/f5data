K25412735: BIG-IQ is not able to populate the Statistical data in Dashboard

Type
Support Solution
Published
2021-07-13
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K25412735

Description

BIG-IP devices are no longer showing up in the BIG-IQ Dashboard in the GUI:

Monitoring -> DASHBOARDS -> Device -> Health

The device hostname count shows more device over a longer time period (1 month) compared to recent time period (1 hour).

Environment

  • BIG-IQ
  • Dashboard was working previously and suddenly stopped working
  • DCD out of disk space

Cause

ID1033809

Disk space full for /var/log/ on one of the DCD's

Recommended Actions

Identify and free up disk space using the following steps:
  1. Identify volume that is out of disk space:
    df -h

    Filesystem            Size  Used Avail Use% Mounted on
    /dev/mapper/vg--db--sda-set.1.root
                          427M  173M  232M  43% /
    none                   32G  2.2M   32G   1% /dev/shm
    /dev/mapper/vg--db--sda-set.1._config
                          3.2G   90M  2.9G   3% /config
    /dev/mapper/vg--db--sda-set.1._usr
                          5.0G  3.3G  1.4G  71% /usr
    /dev/mapper/vg--db--sda-set.1._var
                           74G   13G   58G  18% /var
    /dev/mapper/vg--db--sda-dat.share.1
                           30G  5.3G   23G  19% /shared
    /dev/mapper/vg--db--sda-dat.log.1
                          9.9G  9.9G     0 100% /var/log  <--------------!!
  2. Find the largest files in /var/log:
    find /var/log/ -xdev -type f -exec du {} \; | sort -rn | head -20
    3598620 /var/log/ecm
    2264188 /var/log/sa6/saxml
    2243532 /var/log/sa6/saxml.1
    1220460 /var/log/sa6/sa
    144584  /var/log/webd/access.log
    ....
     
  3. In the above output /var/log/ecm is over 3Gb.  Clear the contents using the following command to free up disk space:
    > /var/log/ecm
  4. Verify disk space has been freed:
    df -h
  5. Restart stats collection agent on same DCD:
    tmsh restart sys service appiqagent
