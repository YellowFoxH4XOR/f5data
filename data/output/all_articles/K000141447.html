Description

When click the native RDP item and download the rdp file, open the rdp file, get the error:

There was a problem connecting to the remote resource. Ask your network administrator for help.

Show Details:

Error code:  0x3000008

Extended error code: 0x0

Timestamp (UTC): MM/DD/YY hh:mm:ss AM

The APM was able to connect to the RDP server.

When the issue happened, BIG-IP APM did not initial the connection to the RDP server.

Environment

  • BIG-IP APM
  • Virtual server
  • Client SSL profile
  • Access profile
  • Native RDP object
  • Windows 10 and Remote Desktop Connection

Cause

The client SSL file request the certificate from the client. The browser was able to complete the TLS handshake, but the Remote Desktop Connection client "mstsc.exe" cannot complete the TLS handshake, cause the TLS handshake failed.

Recommended Actions

The Remote Desktop Connection client "mstsc.exe" cannot support client certificate authentication, so please disable client certificate authentication in the client SSL profile.

Additional Information

If client certificate authentication is required, the ideas:

A, Make sure mstsc.exe was able to complete the TLS handshake when receive the Certificate Request.

B, Other idea to expose the RDP server to the client.
