Description

  • LTM configuration not loading
  • You may encounter the following error message on /var/log/ltm or as an output after running tmsh load sys config verify

    /Common/management-ip: Conflicting configuration. Management-ip can't be created manually while DHCP is enabled. Do 'tmsh modify sys global-settings mgmt-dhcp disabled' before manually changing the management-ip.
    Unexpected Error: Validating configuration process failed.

Environment

  • BIG-IP
  • Loading configuration

Cause

This message occurs when DHCP is enabled globally.

Recommended Actions

Attempt to disable DHCP globally with the doing following:

  1. Connect to CLI
  2. Disable DHCP

    tmsh modify sys global-settings mgmt-dhcp disabled

  3. Then save and reload the configuration

    tmsh save sys config
    tmsh load sys config

If the configuration is still not loading, then you can try manually disabling dhcp in the bigip_base.conf file:
  1. Connect to CLI
  2. Open bigip_base.con with the editor of your prefernce
  3. Located the following:

    sys global-settings {
        gui-setup disabled
        hostname ]
    }

  4. Add the following line

    sys global-settings {
        gui-setup disabled
        hostname ]
        mgmt-dhcp disabled               <----- add in this line
    }

  5. Load and save the configuration

    tmsh load sys config
    tmsh save sys config
