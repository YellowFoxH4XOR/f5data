Description

You want to know what user role you need to have in order to manage the Global Log Receiver.

Environment

  • F5® Distributed Cloud
  • Global Log Receiver
  • Users Roles

Answer/Recommended Actions

There are 3 ways to set up a role that will let you manage the Global Log Receiver

Option 1: ves-io-admin-role

The ves-io-admin-role is a generic role that provides administrator privileges. To set-up that role

1. Got to Administration

2. Click on IAM

3. Got to Users

4. Click on Edit User

5. Go to Assign Roles and Namespaces 

6. Check the Make Admin box

            

Option 2: ves-io-admin-role and  ves-io-infra-admin-role

To set up the role

1. Go to Administration

2. Go to Users

3. Click on Edit User

4. Go to Assign Roles and Namespace

6. add namespace Shared for both roles (ves-io-admin-role and  ves-io-infra-admin-role)

7. add namespace System for both roles (ves-io-admin-role and  ves-io-infra-admin-role)

 

Option 3: ves-io-infrastructure-read and ves-io-infrastructure-write

To create a new role that includes the API groups ves-io-infrastructure-read and ves-io-infrastructure-write 

1. Go to Administration

2. Go to IAM

3. Go to Roles

4. Click New Role
