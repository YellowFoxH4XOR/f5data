Description

Encountering an error: "Invalid region type" when modifying gtm region-members using REST API

[root@bigip:Active:Standalone] config # curl -sk -u admin:admin https://localhost/mgmt/tm/gtm/region -H 'Content-Type: application/json' -X POST -d '{"name":"region_test","regionMembers":[{"name": "country CN"}]}' | jq .

{ "code": 400, "message": "Invalid region type: \"country CN\"", "errorStack": [], "apiError": 26214401 }

Environment

  • BIG-IP GTM
  • Modifying GTM region members using REST API
  • Encountered 400 code error: Invalid region type

Cause

ID501258

Recommended Actions

Use tmsh to modify GTM Regions.
