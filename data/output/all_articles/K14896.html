Known Issue

An invalid stream profile target may cause the TMM processes to restart.

This issue occurs when all of the following conditions are met:

  • You created a stream profile with an invalid string on the target option.
  • You created a new virtual server and associated it with the affected stream profile.

For example, an invalid string used on a target option of a stream profile may appear similar to the following:

@123@456@abc@abc-b@

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the TMM restarting. If the BIG-IP system is configured as part of a high-availability system, a device failover may occur.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H441925 on the Diagnostics > Identified > High screen.
  • The BIG-IP system fails over to the standby system if the system is configured for high-availability.
  • The BIG-IP system may generate TMM core files to the /shared/core directory.
  • You may observe an error message similar to the following example on the /var/log/ltm log file:

    err tmm[10177]: 01220005:3: Can't compile regular expression - (123)|(bc@)c-) (profile=stream)
    err tmm1[10178]: 01220005:3: Can't compile regular expression - (123)|(bc@)c-) (profile=stream)

  • You may observe segmentation fault messages similar to the following example in the /var/log/tmm* log files:

    notice panic: ../modules/hudproxy/hudproxy.c:433: Assertion "reinit success" failed.

Workaround

There is no workaround for this issue. However, you can avoid this issue by configuring the appropriate string format on the stream profile's target option. For more information, refer to K7027: Replacing multiple strings using a Stream profile
