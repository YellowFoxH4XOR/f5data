K000150803: Device does not boot after upgrade to 17.5.0

Type
Support Solution
Published
2025-04-10
Updated
2025-04-10
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000150803

Description

The device is extremely slow after an upgrade to version 17.5.0. Even running simple commands in cli can take seven minutes to the point where working with the device is not possible. The kern.log contains entries such as the ones below:

Aug 8 22:12:52 labunit err kernel: : [2129509.629920] INFO: task logrotate:13451 blocked for more than 120 seconds.
Aug 8 22:12:52 labunit err kernel: : [2129509.629922] "echo 0 > /proc/sys/kernel/hung_task_timeout_secs" disables this message.

Environment

  • Upgrade

Cause

The exact cause of the behavior is not known as troubleshooting is not possible due to the lag/slowness. Possibly something went wrong during the installation process of the new image.

Recommended Actions

Revert back to the previous version.

1.List the boot locations.

# switchboot -l

2.Boot into the previous boot location.

# switchboot -b HD1.2

Delete the volume with the problematic installation and reinstall it.
