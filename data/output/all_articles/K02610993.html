Description

SNAT pool not working correctly when using multiple traffic groups in Active-Active scenario.

Environment

  • Multiple traffic groups
  • HA is working in Active-Active mode

Cause

SNAT pool's IP addresses are by default added to traffic-group-1 when created in Common partition.

Recommended Actions

Make sure that SNAT pool's IP addresses are assigned to correct traffic group:
Local Traffic ›› Address Translation : SNAT Translation List

Note: SNAT Translation List will contain IP addresses after creating SNAT pool and defining IP addresses in SNAT pool.
