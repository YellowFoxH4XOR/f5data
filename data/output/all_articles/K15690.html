Topic

You should consider using this procedure under the following condition:

  • You want to change the cluster IP or cluster member IP addresses for your VIPRION platform.

Description

The BIG-IP VIPRION platform contains two management IP address types:

  • Cluster IP address
  • Cluster member IP address(es)

The cluster IP address is also called the management IP address, which is a floating address that accesses the primary blade to configure the BIG-IP system. If the primary blade becomes unavailable, the primary designation moves to a different blade, and the cluster IP address floats to that blade as well. This behavior ensures that you can always access the cluster using the cluster IP address, even if the primary blade changes.

The cluster member IP address is a unique non-floating IP address assigned to each blade in the chassis, and is used for intra-chassis blade communication for failover, in addition to direct login access for configuration and management purposes.

There may be occasions when you need to change one or both address types. For example, if you want to change the addresses to a new network, you will need to change both address types.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP CLI or Configuration utility.

Procedures

  • Changing the cluster IP address
    • Changing the cluster IP address from the Configuration utility
    • Changing the cluster IP address from the command line
  • Changing the cluster member IP addresses
    • Changing the cluster member IP addresses from the Configuration utility
    • Changing the cluster member IP addresses from the command line

Note: Using the Configuration utility to change the cluster IP address may fail, depending on the BIG-IP version you are using. For more information, refer to K15692: The VIPRION system may fail to change the cluster IP address when you attempt to change it from the BIG-IP Configuration utility.

Changing the cluster IP address from the Configuration utility

When changing the cluster IP address from the Configuration utility, your browser will automatically redirect to the new address after the change.

Impact of procedure: Once you make this change, all connections using the previous cluster IP address are immediately dropped.

  1. Log in to the Configuration utility.
  2. Navigate to System > Clusters > Management IP Address.
  3. Type the IP address, Network Mask, and Management Route you want to use.
  4. Click Update.

Changing the cluster IP address from the command line

To change the cluster IP address from the command line, you can do so using either the serial console or SSH. However, you must complete this change from the primary blade. Attempting to change the IP address from a secondary blade results in an error message that appears similar to the following example:

0107092e:3: user:root remote_host:none pid:5793, updates to the configuration are not allowed on a secondary (only on the primary)

Changing the IP address while connected using the current cluster IP address causes your current connections to drop.

To determine the primary blade, use the tmsh show /sys cluster command, and then connect to either the serial console or cluster member address for your primary blade, as appropriate for your environment.

Impact of procedure: Once you make this change, all connections using the previous cluster IP address will drop immediately.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To change the cluster IP address, use the following command syntax:

    modify /sys cluster default address <address or address/prefix length>

    For example, to change your IP address to 10.0.0.5 with a 24-bit subnet mask (255.255.255.0), you would type the following command:

    modify /sys cluster default address 10.0.0.5/24

  3. Save the change by typing the following command:

    save /sys config

Changing the cluster member IP addresses from the Configuration utility

When changing the cluster member IP address from the Configuration utility, F5 recommends connecting to the Configuration utility using the cluster IP (management IP) address.

Impact of procedure: Once you make this change, all connections using the previous cluster IP address will drop immediately.

  1. Log in to the Configuration utility.
  2. Navigate to System > Clusters > Management IP Address.
  3. In the Cluster Member IP Address section, enter the desired IP address for each blade in the appropriate Slot IP Address field.
  4. Click Update.

Changing the cluster member IP addresses from the command line

To change the cluster member IP addresses from the command line, you can do so using either the serial console or secure shell (SSH). However, you must complete this change from the primary blade. Attempting to change the IP address from a secondary blade results in an error message that appears similar to the following example:

0107092e:3: user:root remote_host:none pid:5793, updates to the configuration are not allowed on a secondary (only on the primary)

Changing the IP address while connected using the cluster member IP address causes your current connection to drop.

If using SSH, F5 recommends using the cluster IP address (management IP) to avoid losing your connection.

Impact of procedure: Once you make this change, all connections using the previous cluster member IP addresses will drop immediately.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To change the cluster IP address, use the following command syntax:

    modify /sys cluster default members { <slot> { address <IP address> } }

    For example, to change the cluster member IP address for slot 2 to 10.0.0.2, you would type the following command:

    modify /sys cluster default members { 2 { address 10.0.0.2 } }

  3. Save the change by typing the following command:

    save /sys config
