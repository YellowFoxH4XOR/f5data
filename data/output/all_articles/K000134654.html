Description

Unable to generate the qkview. The qkview -v command shows the qkview is stuck at qkshared.so.

 

Environment

GUI or CLI access.

 

Cause

The qkview was stuck and the ps -ef | grep -i <pid of qkview> shows it is trying to run a rpm command:

 

/opt/usr/lib/rpm/rpmq -q --all --define _dbpath /var/config/rest/rpm

 

[root@test:Standby:In Sync] config # ps -ef | grep 31139

root 372 19403 0 16:42 pts/0 S+ 0:00 grep 31139

root 31139 16791 0 16:41 pts/1 S+ 0:00 qkview -v

root 31228 31139 0 16:41 pts/1 S+ 0:00 sh -c /opt/bin/rpm -qa --dbpath /var/config/rest/rpm > /var/tmp/plugin_rpm_dump.txt 2>&1

[root@test:Standby:In Sync] config # ps -ef | grep 31228

root 940 19403 0 16:43 pts/0 S+ 0:00 grep 31228

root 31228 31139 0 16:41 pts/1 S+ 0:00 sh -c /opt/bin/rpm -qa --dbpath /var/config/rest/rpm > /var/tmp/plugin_rpm_dump.txt 2>&1

root 31229 31228 0 16:41 pts/1 S+ 0:00 /opt/usr/lib/rpm/rpmq -q --all --define _dbpath /var/config/rest/rpm

[root@test:Standby:In Sync] config #

 

 

Trying to manually running the same command gets stuck as well, which indicates the rpm may be corrupted.

 

Recommended Action

 

rebuild the rpm following the below steps:

 

 

1. Collect a tarball of the rpm db files:

 

# tar -czf /shared/tmp/rpm-db.tar.gz /shared/lib/rpm/* /var/config/rest/rpm/*

 

2. Kill the running rpm or processes:

 

# ps aux | grep -E '[P]ID|[r]pm'

 

# kill -9 <pid>

 

 

3.. Ensure "ps aux" didnt return any rpm processes in the output.

 

4. Execute the below commands to rebuild the rpm db:

 

# rm -f -v /shared/lib/rpm/* /var/config/rest/rpm/*

 

# /opt/bin/rpm --dbpath /shared/lib/rpm --rebuilddb

 

# /opt/bin/rpm --dbpath /var/config/rest/rpm --rebuilddb
