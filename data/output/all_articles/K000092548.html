K000092548: Virus or malware detected in UCS file

Type
Support Solution
Published
2022-11-04
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K000092548

Description

When handling UCS files (configuration snapshots) taken from BIG-IP ASM systems, virus scanners and other endpoint inspection engines may sometimes erroneously flag the UCS as containing a virus or malware.

In this situation you may see messages from your virus scanner noting that a virus has been detected within a file inside the UCS whose name ends with ".cstmp" located within the "/var/tmp" directory contained in the UCS archive. e.g.:

Virus Detected: Trojan-Downloader.Shell.Miner.j
Location: ASM1.example.com.ucs//var/tmp/ts_db.save_dir_1536.cstmp/ts_db.data.PLC.THREAT_CAMPAIGNS_MATCH_RULES.cstmp

The alert should reference file paths ending with the name "ts_db.data.PLC.THREAT_CAMPAIGNS_MATCH_RULES.cstmp" or "ts_db.data.PLC.NEGSIG_SIGNATURES.cstmp".

Note: If the alert is on any other file then care must be taken as it may indicate the presence of a legitimate, malicious file contained within the UCS (for example if the filename ends with ".sh" or is not contained within the /var/tmp/ts_db* path), please contact F5 Support for assistance and see K11438344 for further advice.

Environment

  • BIG-IP ASM (all versions)
  • UCS file copied from BIG-IP to local system (e.g., an Administrator's Windows PC)

Cause

F5 BIG-IP Advanced WAF and ASM UCS files contain database dumps of the database tables used to store security policies, signatures and logs.

Some ASM Signatures (and/or Threat Campaign signatures) contain sequences of bytes designed to search for known trojans, malware or viruses in binary content. Third party virus scanners (i.e., those running on the Administrator's local workstation) often search for the same sequence of bytes to determine the presence of a trojan, malware or virus and will therefore falsely assume that the bytes they have found indicate the presence of a virus. Instead, the bytes the virus scanner has found are signature definitons designed to find the same virus.

Recommended Actions

None. Virus alerts on these files may be safely ignored as they are false positives.
