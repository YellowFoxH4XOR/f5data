Description

On a MAC OS client, when it connects to a BIG-IP APM VPN server via a browser or the F5 Edge client, the file /etc/hosts will be backed up and a copy will be updated with an entry containing the IP address and FQDN of the VPN server.

For example:

cat /etc/hosts
#F5 Networks Inc. :File modified by VPN process
##
# Host Database
#
# localhost is used to configure the loopback interface
# when the system is booting.  Do not change this entry.
##
127.0.0.1    localhost
255.255.255.255    broadcasthost
::1             localhost

192.0.2.1 apmvpn.example.com


If a system proxy is configured, the IP address will be the IP address of the proxy. When you disconnect the VPN, the file /etc/hosts will be restored with the original copy.

Environment

  • BIG-IP APM
  • Virtual server
  • Access profile
  • Network Access
  • Browser plugin or Edge client on MAC OS
  • The /etc/hosts file

Cause

This is expected behavior.

Recommended Actions

Do not modify the file /etc/hosts when the VPN is connected. Ensure that other software will not modify the file /etc/hosts when the VPN is connected.

Additional Information

On a Windows client, the browser plugin/Edge client will not update the file C:\Windows\System32\drivers\etc\hosts.
