Description

When setting up via GUI SNMPv3, the system reports the error:  "Unsupported Security Level".

Environment

  • Only GUI (Configuration Utility)
  • SNMPv3 Configuration

Cause

Bug ID 761981: information in snmpd.conf files may be overwritten

Recommended Actions

  1. Delete existing SNMPv3 user configuration.
    Note: Hold onto your password(s).
    # tmsh
    # modify sys snmp users none
    # q

  2. Next, delete user information from "/config/net-snmp/snmpd.conf". This needs to be done on both HA units.
    run /util bash
    #bigstart stop snmpd ; rm -f /config/net-snmp/snmpd.conf ; bigstart start snmpd

  3. Configure SNMPv3 user configuration by using TMSH.
    example:
    # tmsh
    # modify sys snmp users add { imssmunix_1 { username mssmunix auth-protocol sha privacy-protocol aes security-level auth-privacy oid-subset .1 auth-password "iIGZk*Mj2Wg#pWhy" privacy-password "75DwhC*fzt%3X8Fa" } }
    # save sys config
    # q

  4. Now, test the command
    snmpwalk -v3 -u mssmunix -l authPriv -a SHA -A "iIGZk*Mj2Wg#pWhy" -x AES -X "75DwhC*fzt%3X8Fa"  localhost F5-BIGIP-SYSTEM-MIB::sysSystemNodeName

    # grep mssmunix  /config/net-snmp/snmpd.conf
    usmUser 1 3 0x80001f88803aa2d82854f13c5b "mssmunix" "mssmunix" NULL .1.3.6.1.6.3.10.1.1.3 0xf6e21d54a0cef803ea7b631e318a368e3de7ee34 .1.3.6.1.6.3.10.1.2.4 0xf639d81a3f5a1dc2f12fb2a1c0ec5956 ""

    Note: The snmpwalk test will need to match your own username and password. The above command is just an example.
