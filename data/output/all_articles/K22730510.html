Known Issue

Under rare circumstances, the apd process may produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access policy that includes authentication.
  • The apd process authentication service fails to establish a socket to the aced process.

Impact

Attempts to access the BIG-IP APM system fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Access to BIG-IP APM access profile authentication temporarily stops functioning while the apd service writes a core file and automatically restarts.
  • Users attempting to authenticate to an access profile are redirected to a logout page.

    Note: Clicking the logout page hyperlink, to create a new session, loops users back to the access profile logout page.
