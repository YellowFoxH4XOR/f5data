Description

For persistence profiles that contain a timeout value set, any persistence entry will be refreshed to 0 each time a packet for the connection is sent during the timeout period of time. (Default 180 seconds)
 

Environment

  • BIG-IP LTM
  • Persistence profiles

Cause

Design of persistence timeout profile setting.

Recommended Actions

To show the Age in seconds for a specific timeout persistence entry, use the following tmsh command:

tmsh show /ltm persistence persist-records all-properties | grep -A 10 <client-ip address>

None.
