K7351: Queries to a self IP address from a network that is accessible through a gateway pool fails

Known Issue

This is the result of a known issue. If a query to a self IP address, such as an SNMP query, is received from a network that is accessible only through a configured gateway pool, the request fails. Additionally, the response to the query is sent to the local host address for BIG-IP LTM, instead of going to the gateway specified in the gateway pool.

Note: This issue only occurs when there is no static route configured, and gateway pools are used.

F5 Product Development tracked this issue as CR77421, and it was fixed in BIG-IP LTM 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

To work around this issue, create a static route to the network from which the queries originate. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Select Network, then select Routes.
  3. Click Add.
  4. From the Type menu, select Route.
  5. Specify the Destination network.
  6. Specify the Netmask for the Destination network.
  7. Specify the Gateway IP address for the Resource.
  8. Click Finished.
