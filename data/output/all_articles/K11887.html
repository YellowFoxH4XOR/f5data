Known Issue

This is the result of a known issue. The BIG-IP ASM Configuration utility does not impose a timeout on proxy log search requests. If you submit a request to the Configuration utility that results in a lengthy query, the Configuration utility becomes unresponsive until the browser receives the query results. Depending on the amount of relevant data in the logs, the Configuration utility may remain unresponsive for several minutes.

For example, if you choose All web applications on a busy system and search for a specific string in the Proxy log, the reporting page may take a long time to load. As a result, the Configuration utility is unusable until the results are returned.

The desired behavior is for the BIG-IP ASM Configuration utility, after a reasonable timeout, to display an error message indicating that the query has taken too long, and return control of the browser to the user. 

F5 Product Development tracked this issue as ID 226670 and ID 324379 (formerly CR141955) and it was fixed in BIG-IP version 10.2.1 (BIG-IP now imposes a 120 second proxy log query timeout). For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue has been fixed in in Hotfix-BIGIP-10.2.0-1744.0-HF1 for BIG-IP version 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
