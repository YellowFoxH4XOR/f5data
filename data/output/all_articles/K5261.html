K5261: All 3-DNS probing, resolution, and communication with other F5 devices may fail

Topic

If the 3-DNS server statement for the 3-DNS is missing from the wideip.conf file, any operations that depend on the 3-DNS server statement, such as probing, name resolution, and iQuery communications, may fail.

The wideip.conf file should contain at least a minimal 3-DNS server statement in the following format:

server {
type            3dns
name            "<host name>"
box             <IP address>
}
