Description

Console shows nothing but hex in the center of the screen that appears to "count up"
        K7683: Connecting a serial terminal to a BIG-IP system
Then after a while cycles again.

Environment

  • After reboot
  • BIG-IP hardware platforms
Cause

During boot it is normal for a series of Hexidecimal numbers to appear in the Console
However, if the boot does not progress any further, it is possible a hardware failure has occurred

Recommended Actions

To confirm a hardware failure has occurred, perform an End-User Diagnostic (EUD) from either the GRUB menu or a USB Thumbdrive
  • Manual Chapter : Running the EUD Tests
  • K93403310: Running EUD from a USB thumb drive
Save the serial console output of the EUD tests to a file for upload to F5 Support.

Now contact F5 Support for further investigation
K2633: Instructions for submitting a support case to F5???????

Additional Information

The following procedure may help to confirm a hardware failure has occurred:

  1. Access the AOM menu:
    K14594: Accessing the AOM Command Menu
     
  2. Use "Display error report" to look for errors or hardware faults.  For example:
    Error Report:

    No Errors

    Sensors out of range:
    CPU-1                       : Faulted!
