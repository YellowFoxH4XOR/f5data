Description

BIG-IQ  Fails to add Secondary unit to cluster  ( System > BIG-IQ HA > Add Secondary ) with error:
restjavad.0.log

[/shared/ha/sync-files-task/886d04bd-bbd1-4330-8cf0-cf1391bbf721/worker SyncFilesTaskWorker] [/bin/bash, -c, /usr/bin/ha_sync_files 192.168.1.25] failed with exit code 143

Environment

  • BIG-IQ 7.x Centralized Management
  • Configuring BIG-IQ HA
  • Lot of ucs backup files to be synced between BIG-IQ devices

Cause

Unknown.

Recommended Actions
 

Remove failed standby device and perform rsync operation manully before creating BIg-Iq cluster
  1. On Secondary BIG-IQ  perform 'Reset to standalone' In System > BIG-IQ HA > HA configuration
  2. On Primary BIG-IQ cli ( bash) execute:
    ha_reset -f <Local_discovery_address>
    Note:  Discovery Address was set at the beginning of creating BIG IQ cluster and You can verify in  GUI SYSTEM > This Device > General Properties > Discovery Address
  3. On Primary BIG-IQ cli  manualy syncfiles by( bash) executing:
    ha_sync_files  <ip Secondary>
  4. Attempt to establish cluster using System > BIG-IQ HA > Add Secondary
 

Additional Information

None.
