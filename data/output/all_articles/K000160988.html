K000160988: [F5OS] Tenant stuck in boot after a hard reboot of the device

Description

F5OS Tenant is not booting up after a hard reboot of the device. Console logs shows:

[  OK  ] Reached target Remote File Systems.
[  **  ] A start job is running for dev-disk...b22.device (10min 4s / no limit)

Environment

F5OS

Cause

Device was rebooted without putting the tenants in Configured/Provisioned state which corrupted the tenant.

Answer/Recommended Actions

If the device is in the booting loop already, you can try to re-provision and re-deploy the tenant. If it is still not coming up, rebuild the tenant with your UCS file.

Installing UCS files containing encrypted passwords or passphrases (11.5.x and later)

Additional Information

Follow the article Shut down and restart a tenant on the VELOS and F5 rSeries systems  in shutting down the tenant prior to the device reboot/shutdown.
