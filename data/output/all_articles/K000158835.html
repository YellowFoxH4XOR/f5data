Description

You want to use the HTTP pseudo-headers of HTTP2 protocol like :authority instead of using the header "Host" and you want to know if it is possible and if it is compatible if the requests received will be done via HTTP1.1

Environment

  • HTTP Load Balancer

Answer

Yes they can be used.

It is generally safer to use Host header versus :authority pseudo header. Authority will always be converted to Host for compatibility.  Today, our XC proxy implementation will ensure H1.1 and H2 headers for compatibility with upstream and browsers.
