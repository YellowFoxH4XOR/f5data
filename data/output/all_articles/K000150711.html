Answer/Recommended Actions

Blindfolding API keys is a critical security step when working with Volterra secrets, but doing it manually can be tedious and error-prone. To make this process easier and more accessible, we've created a public-facing Python script that securely automates blindfolding using vesctl.

What does this  automated script offer?

  • Automates all the required steps like fetching the public key, pulling the policy document, encrypting each secret, and generating the final blindfolded secret bundle.
  • No need to manually write YAML or construct vestctl commands, which are prone to human error and extensive in documentation search. Just supply your .p12 and credentials.

Why should i blindfold my API keys? As a security best practice, Blindfolding encrypts your API keys using a public key tied specifically to your tenant. This ensures that only authorized services, those with access to the corresponding private key and policy can decrypt and use them. This aligns with zero-trust principles for secret management.

Requirements:
Note: You must have vestctl utility installed & configured: https://gitlab.com/volterra.io/vesctl/blob/main/README.md

  1. A valid API Certificate, this can be generated from Home > Administration > Personal Management
    Note:     Enter any credential name label, select API Certificate, and a password you will remember. Set your expiry date to your preference. 
  2. A valid secrets.yaml file; this can be obtained from your Virtual k8 secrets configuration (if it exists).

    Else you may create a YAML file yourself; this is an example template: name this file secrets.yaml. Note: API keys must be base64 encoded; please use online converters for this, like CyberChef. 
apiVersion: v1
kind: Secret
metadata:
  name: alert-app-test-secrets
  namespace: default
data:
  API_VALUE: ZXhhbXBsZQ==
  ENVIRONMENT_V: ZXhhbXBsZQ==
  HEALTH_TEAMS_WEBHOOK_URL: ZXhhbXBsZQ==
type: Opaque

3. Place the secrets.yaml in the same directory where the script will be. 

4. Create a Python virtual environment by running this command:

python3 -m venv venv

5. Depending on your environment, activate the virtual environment:

  • Command for Mac/Linux: 
    source venv/bin/activate
  • Command for Windows: 
    venv\Scripts\activate

6. Install the dependencies by running command: pip install -r requirements.txt
7. Run the script: python3 encrypt.py 
8. Once you follow the script procedure, you will see a generated blindfolded-secret.json, which will contain your secret keys encrypted and ready to be used by your application:
