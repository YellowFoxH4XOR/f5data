Description

Cisco's SMTP firewall will hide the domain of a mail server with asterisks ( * ). The BIG-IP's SMTP monitor will not handle this.

For instance the monitor will send helo with the domain specified but the domain on the server is masked with ****

 

helo mail.mydomain.com
220 ****
 

Environment

BIG-IP is monitoring SMTP servers that are protected with a Cisco firewall.

 

Cause

This is expected behaviour as Cisco do this to protect the mail server from being scanned and domains scraped.

 

Recommended Actions

A scripted monitor can be used instead of the SMTP monitor
 

  • Use vi or similar to create a file config/eav/scriptedsmtp that contains
expect "220"
send "HELO mail.bigipmonitor.net\r\n"
expect "250"
send "quit\r\n"

 

  • Create a new monitor under
    • Local Traffic  ››  Monitors  ››  New Monitor...
    • Type:  scripted 
    • Set scriptedsmtp as the filename.
