Description

Whenever failover happens, there is some downtime.
You see the below warning logs in /var/log/ltm:

warning tmm[<PID>]: 01190004:4: address conflict detected for <IP_address> (<MAC address>) on vlan <vlan>
 

Environment

  • BIG-IP any version
  • HA
  • Failover
     

Cause

Various reasons, but common reason is unicast is used for HA pair, and management IP is not set to the unicast address along site self IPs.
 

Recommended Actions

Review your HA unicast config if there are management IP and Self IP set properly.
Please refer further information about HA settings:

  • K37361453: Configuring network failover for redundant VIPRION systems
  • Manual Chapter : Creating an Active-Standby Configuration Using the Setup Utility
     

Additional Information

None.
