Description

The configuration fails to load after the upgrade with the following error message:
01071819:3: At least one RSA key exchange cipher must be configured for SSL Forward Proxy in SSL profile (/Common/<name_of_SSL_profile>)

This error message will be displayed in /var/log/ltm log and when running the following command:  tmsh load sys config verify

Environment

  • BIG-IP upgrade 
  • Cipher Group configured on SSL profile

Cause

Bug ID989577

Recommended Actions

To workaround the issue you may remove the cipher-group and use traditional cipher string
K17370: Configuring the cipher strength for SSL profiles (12.x - 13.x)
