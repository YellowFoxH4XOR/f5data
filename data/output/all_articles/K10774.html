Known Issue

This is the result of a known issue. After installing cumulative hotfix HF-603-5.x, or after upgrading to FirePass version 6.1.0, the Active Directory password expiration feature no longer functions. As a result, users are not warned when their Active Directory passwords are set to expire.

Note: For more information about the password expiration feature, refer to K9790: Change in Behavior: FirePass now warns users when their Active Directory password is set to expire.

F5 Product Development tracked this issue as CR132385 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-610-1, which has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
