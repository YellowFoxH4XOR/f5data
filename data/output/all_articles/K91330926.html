Description

You wish to confirm if configured Connection Rate Limit of Node works properly.
It may be difficult to confirm by using 'tmsh show ltm node' because the command only display the number of Current Connections.

Environment

  • BIG-IP LTM

  • Connection Rate Limit of Node has been configured

Cause

None

Recommended Actions

There is MIB to confirm Connection Rate Limit to be worked.

   ltmNodeAddrStatCurrentConnsPerSec

ltm node 172.16.147.64 {
    address 172.16.147.64
    rate-limit 5               <---------
}

If there is enough traffic to reach the rate-limit, you will see below.

# snmpwalk -c public -v2c localhost ltmNodeAddrStatCurrentConnsPerSec
F5-BIGIP-LOCAL-MIB::ltmNodeAddrStatCurrentConnsPerSec."/Common/172.16.147.64" = Gauge32: 5   <----
