Known Issue

The iControl Simple Object Access Protocol (SOAP) application programming interface (API) and the browser interface cannot generate a Secure Sockets Layer (SSL) certificate or certificate signing request (CSR) for a password-protected SSL key.

This issue occurs when the following condition is met:

  • The SSL key is password-protected.

Impact

You are unable to generate a certificate or CSR for a key using iControl SOAP or the browser interface.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You cannot use iControl SOAP commands or the browser interface to generate an SSL certificate or CSR for a password-protected SSL key.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to generate an SSL certificate or CSR for a password-protected SSL key. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Using tmsh to create the certificate or CSR

  1. Create an SSL certificate from an existing private key using the following command syntax:

    tmsh create sys crypto cert <cert name> key <key name> common-name <name>

    For example:

    tmsh create sys crypto cert cert.example.com key key.example.com common-name www.example.com

  2. When prompted by the system to enter the key's password, enter it at the prompt provided.

    For example:

    Enter the PEM pass phrase:

  3. Create a CSR from an existing private key using the following command syntax:

    tmsh create sys crypto csr <csr name> key <key name> common-name <name>

    For example:

    tmsh create sys crypto csr csr.example.com key key.example.com common-name www.example.com

  4. When prompted by the system to enter the key's password, enter it at the prompt provided.
