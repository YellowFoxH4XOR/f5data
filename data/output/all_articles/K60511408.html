Known Issue

iControl representational state transfer (REST) may receive an error message when accessing BIG-IP GTM wide IP records.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is configured with a wide IP name that contains the asterisk character (*).
  • You use iControl REST to gather the wide IP records.

Impact

The iControl REST action fails.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using iControl REST to gather wide IP statistics, the action receives an error message similar to the following example:

    {"code":400,"message":"Invalid URI","errorStack":[]}

Resolution

Workaround

To work around this issue, you can gather all wide IP records that include the affected wide IP record.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
