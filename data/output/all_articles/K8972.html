Known Issue

This is the result of a known issue. The Layer 2 forwarding proxy portion of the Traffic Management Microkernel (TMM) releases incorrect next-hop reference counts, which may cause TMM to crash.

This behavior affects configured Virtual Local Area Network (VLAN) groups that handle a substantial amount of traffic, and may cause the system to reference an incorrect next-hop count.

F5 Product Development tracked this issue as CR100005 and it was fixed in BIG-IP LTM 9.4.6. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP 9.4.5, for the BIG-IP 9.4 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing BIG-IP product hotfixes (9.x).
