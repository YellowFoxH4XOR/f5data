Issue

Error Message

transaction failed:01020036:3: The requested iRule (<object_name>) was not found

In this error message, note the following:

  • <object_name> is the name of the iRule that is invalid or does not exist on the target BIG-IP AFM device.

For example:

On the BIG-IQ device:

Failed submitting iControl REST transaction 1443595496588441: transaction failed:01020036:3: The requested iRule (/Common/set100) was not found.

On the BIG-IP AFM device:

{"code":409,"message":"transaction failed:01020036:3: The requested iRule (/Common/set100) was not found.","errorStack":[]}

Message Location

You may encounter this message in the following locations:

  • On the BIG-IQ device, you may observe the error message in the following locations:

    • In the /var/log/restjavad.0.log log file.
    • On Deployment panel of the BIG-IQ interface, in the Deploy Status column.
  • On the BIG-IP AFM device, in the /var/log/restjavad.0.log log file.

Description

This message occurs when all of the following conditions are met:

  • The BIG-IP AFM device is being managed by the BIG-IQ device.
  • On the BIG-IQ device, a new AFM policy is being created and it contains a rule that references an iRule that does not exist on the target BIG-IP AFM device.
  • You attempt to deploy the new AFM policy to the target BIG-IP AFM device.

The BIG-IP objects (for example, an iRule) validation check will occur only when the object is being deployed into the BIG-IP devices. When the BIG-IQ device performs a deployment with a referenced object that does not exist on the target BIG-IP device, an error may result. This is expected behavior.

Impact

The BIG-IQ deployment will fail and result in an error. The failed deployment will not import any changes to the target BIG-IP AFM device.

Recommended Actions

When you create a new policy rule using the BIG-IQ device, and deploy to the BIG-IP devices, always validate the correct iRule object name before the system uses it.
