Description

You are configuring two or more BIG-IP devices for High Availability, HA. The configuration is failing and you are seeing that both devices are still marked as Active-Active.

While troubleshooting, you see in the  /var/log/ltm a line similar to this:

checkDeviceTrustSupported failed: [CheckHandlers.cpp: checkDevic] devmgt:/Common/<<Big-IP Hostname>>:::The device (/Common/<<Big-IP Hostname>>) does not have a config sync address configured.

Environment

  • High Availability Cluster
  • Active-Active

Cause

When there is a misconfiguration in the Config-Sync and Fail-over setting, the devmgmtd and sod processes will generate above log message in the LTM log files. Due to the misconfiguration, The BIG-IP cluster devices will go to an active – active status 

Recommended Actions

Configure Config-Sync setting following below steps:
  1. Confirm that you are logged in to the actual device you want to configure.
  2. On the Main tab, click Device Management > Devices. This displays a list of device objects discovered by the local device.
  3. In the Name column, click the name of the device to which you are currently logged in.
  4. From the Device Connectivity menu, choose ConfigSync.
  5. For the Local Address setting, retain the displayed IP address or select another address from the list. F5 Networks recommends that you use the default value, which is the self-IP address for VLAN internal. This address must be a non-floating self-IP address and not a management IP address.                                                                                                                                                                                                                                               Important: If the BIG-IP device you are configuring is accessed using Amazon Web Services, then the internal self IP address that you specify must be the internal private IP addresses that you configured for this EC2 instance as the Local Address.
  6. Click Update.

Configure Fail-over setting following below steps:
  1. Confirm that you are logged in to the actual device you want to configure.
  2. On the Main tab, click Device Management > Devices. This displays a list of device objects discovered by the local device.
  3. In the Name column, click the name of the device to which you are currently logged in.
  4. From the Device Connectivity menu, choose Fail-over.
  5. For the Fail-over Unicast Configuration settings, click Add for each IP address on this device that other devices in the device group can use to exchange fail-over messages with this device. we recommend this to be the self-IP for the HA VLAN and the Management IP.
  6. Click Update.
