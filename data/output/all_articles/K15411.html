Topic

Starting in BIG-IP APM 11.0.0, Terminal Access Controller Access-Control System Plus (TACACS+) authentication is available for use in access policies. BIG-IP APM access policy TACACS+ configuration supports the following authentication methods:

  • ASCII
  • PAP
  • CHAP
  • ARAP
  • MSCHAP

You can configure the TACACS+ authentication type for access policies by using the Configuration utility to navigate to Access Profiles > AAA Servers > TACACS+, and then modifying the Authentication Type setting.
