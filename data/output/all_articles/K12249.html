Topic

OPSWAT versions older than 3.4.17.1 do not detect AVG Anti-Virus Free Edition 2011 as antivirus software. OPSWAT has introduced support for AVG Anti-Virus Free Edition 2011 starting in OPSWAT version 3.4.17.1.

If the OPSWAT version is older than 3.4.17.1 that is installed on FirePass or BIG-IP APM, users with AVG Anti-Virus Free Edition 2011 without any other supported antivirus software may fail to pass a pre-logon inspection or an access policy that requires the connecting user to have antivirus software installed.

Note: For more information about AVG Anti-Virus Free Edition 2011, refer to the following site. The following link will take you to a resource outside of AskF5, and it is possible that the document may be moved without our knowledge:

http://free.avg.com/us-en/homepage

FirePass and BIG-IP APM use software libraries from a software development kit (SDK) created by OPSWAT. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT has provided updated software to resolve this issue, which F5 has issued as a hotfix for BIG-IP APM. A hotfix for FirePass will be released shortly.

For information about downloading software from F5, refer to K167: Downloading software from F5.

For information about installing OPSWAT hotfixes on BIG-IP APM, refer to K10942: Installing OPSWAT hotfixes on BIG-IP APM systems.
