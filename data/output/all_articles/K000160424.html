K000160424: tpm-integrity-status is Unavailable on certain F5OS versions released since October 2025

Type
Support Solution
Published
2026-03-23
Updated
2026-04-09
Applies to
  • F5OS
  • F5OS-A: 1.8.3
  • F5OS-C: 1.8.2
Source
https://my.f5.com/manage/s/article/K000160424

Description

When you check the system components on affected F5OS software running on F5 hardware platforms equipped with a Trusted Platform Module (TPM), the TPM Integrity Status check will display “Unavailable” after April 4, 2026.

# show components component state tpm-integrity-status
          TPM
          INTEGRITY
NAME      STATUS
-----------------------
platform  Unavailable

The “Unavailable” status means that the integrity status could not be reported.

Environment

  • Any one of these environments:
    • VELOS systems running F5OS-C versions 1.8.2, 1.8.2-EHF, or 1.6.4
    • rSeries systems running F5OS-A versions 1.8.3, 1.8.3-EHF, or 1.5.4
    • EHFs built after October 15, 2025, including EHFs posted to MyF5 downloads in October such as:
      • F5OS-A-1.8.3-23493.R5R10.EHF-1
      • F5OS-C-1.8.2-28324.CONTROLLER.EHF-1
      • F5OS-C-1.8.2-28324.PARTITION.EHF-1
  • The date is April 4th, 2026 or later

Cause

A signing certificate used to validate integrity databases was issued with a 6-month lifetime in October, 2025. That certificate expires on April 4, 2026, after which integrity validation reports as Unavailable until systems are updated with newer software.

Refer to ID 2227221: tpm-integrity-status is Unavailable on certain F5OS versions released since October 2025.

Answer/Recommended Actions

Prior to April 4, 2026:

Run the show components component state tpm-integrity-status command to gather and store the output.

Upcoming F5OS releases will include a fix for ID 2227221.
