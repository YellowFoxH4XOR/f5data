K000134778: ExactBalance as default setting for all sidecars

Type
Support Solution
Published
2023-05-24
Updated
2023-05-24
Applies to
  • Aspen Mesh: 1.14
Source
https://my.f5.com/manage/s/article/K000134778

Description

The throughput of an Envoy sidecar proxy can be increased by configuring its listeners for exact balancing so that TCP connections are nearly evenly distributed between worker threads, however this task requires setting up EnvoyFilter resources per workload or nammespace.
Starting Aspen Mesh 1.14.5-am1 we can configure sidecar listeners for exact balancing without using Envoy filters.


Environment

Aspen Mesh 1.14.5-am1 or later.
 

Cause

This feature was added to Aspen Mesh 1.14.5-am1 and later because the process of managing multiple EnvoyFilter resources per workload or namespace is cumbersome and prone to error.
 

Recommended Actions

Modify the Aspen Mesh overrides values file by adding the following and perform a clean installation or an upgrade to enable this feature.

meshConfig:
  defaultConfig:
    proxyMetadata:
      ISTIO_META_INBOUND_LISTENER_EXACT_BALANCE: "true"
      ISTIO_META_OUTBOUND_LISTENER_EXACT_BALANCE: "true"

 

Additional Information

Use exact balancing when there are a small number of connections that rarely cycle (for example, service-mesh gRPC egress). Exact balancing may also be beneficial in other situations, but you should verify that using it provides the throughput you expect. For ideas on how to test throughput and information on how to enable sidecar connection-level metrics, see related content below.
