K000132317: BIG-IQ not collecting APM statistics after upgrade from 7.1 to 8.2

Type
Support Solution
Published
2023-01-27
Updated
2023-01-27
Source
https://my.f5.com/manage/s/article/K000132317

Description

After upgrade from 7.1 to 8.2 BIG-IQ is not able to collect APM information from Big-IP devices including active sessions. Netstat shows multiple connections to DCDs but all are sitting at SYN_RECV status rather than ESTABLISHED:

tcp    0   0 10.10.36.33:9997    192.185.129.203:2957   SYN_RECV  

tcp    0   0 10.10.36.33:9997    192.233.129.31:2964   SYN_RECV  

tcp    0   0 10.10.36.33:9997    192.233.129.202:2949   SYN_RECV

<<SNIPPET>>


Environment

BIG-IQ DCD

Cause

Missing TMM route on DCDs

Recommended Actions

Add a TMM route on each DCD
