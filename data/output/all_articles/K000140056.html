K000140056: Migrate objects between partitions

Type
Support Solution
Published
2024-06-20
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000140056

Description

The BIG-IP system does not allow you to migrate configuration objects from one partition to another.

 

Environment

  • BIG-IP
  • Configuration objects: (VLANs, self IPs, virtual server name, pool name, and profile names, and so on)

Cause

This is by design.

 

Recommended Actions

F5 recommends deleting the old object from the old partition and recreate it in the new partition.

 

Additional Information

None
