K000148520: How to Manage the Priority for Multiple TACACS+ or RADIUS Servers on F5OS

Type
Support Solution
Published
2024-11-13
Updated
2024-11-13
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000148520

Description

When using F5OS, it is currently not possible to manually set the priority of multiple TACACS+ or RADIUS servers. The system automatically selects the remote authentication servers based on the numerical order of their IP addresses, with smaller IP addresses having higher priority.

Environment

  • F5OS
  • TACACS+
  • RADIUS

Cause

The F5OS platform does not support custom ordering of TACACS+ and RADIUS servers. The system defaults to an ASCII-based ordering of IP addresses, which may not meet specific user requirements for prioritizing authentication servers.

Recommended Actions

Currently, there is no way to manually prioritize TACACS+ or RADIUS servers on the F5OS platform. However, an enhancement request (RFE 1642045) has been filed for this feature. This RFE aims to introduce a new capability to F5OS, allowing customers to order servers within the same server group according to their specific needs.

In the meantime, if you are experiencing issues due to the automatic ordering of TACACS+ or RADIUS servers, please consider the following workarounds:

  1. IP Address Allocation: When setting up your TACACS+ and RADIUS servers, consider assigning IP addresses in a sequence that aligns with your desired priority order.
  2. Monitoring Updates: Stay updated on the progress of RFE 1642045 by checking F5 support channels and release notes for any announcements regarding new features or updates that address this issue.

For further assistance or to express the importance of this feature for your operations, please contact F5 support and reference RFE 1642045.
