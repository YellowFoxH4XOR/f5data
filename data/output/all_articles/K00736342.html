Topic

This article applies to BIG-IP ASM 14.0.0 and earlier. For information about other versions, refer to the following article:

  • K42323285: Overview of the unified Bot Defense profile

You should consider using these procedures under the following condition:

  • You want to configure bot protection for your web application.

Description

You can protect your web applications against Internet bot traffic by configuring a DoS profile and enabling the Proactive Bot Defense and Bot Signature Checking features. You can then directly associate the DoS profile with your virtual server. When you configure the Proactive Bot Defense feature, the system uses JavaScript to evaluate bot signatures and determine whether browsers visiting your web site are legitimate. When you configure the Bot Signature Checking feature, the system parses the user-agent string in the HTTP header for the bot's domain name. The ASM system then performs a reverse DNS lookup on the domain name and identifies bots as either legitimate or malicious.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have access to the Configuration utility.
  • You have configured the BIG-IP system to resolve DNS host names and created a DNS resolver.
  • Client browsers accessing your web application are configured to accept JavaScript.

Procedures

  • Configuring Proactive Bot Defense
  • Configuring bot signature checking
  • Associating the DoS profile with the virtual server

Configuring Proactive Bot Defense

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > DoS Profiles.
  3. Click Create.
  4. Type a name for the DoS profile and click Finished.
  5. Click the name of the DoS profile that you just created.
  6. Click the Application Security tab.
  7. Click Edit next to Application Security, and then select the Enabled check box.
  8. Click Proactive Bot Defense.
  9. Click Edit next to Operational Mode and then click one of the following options from the list, as appropriate for your profile:
    • During Attacks - Proactive bot defense starts during a detected DoS attack. The system checks all traffic during the attack and prevents attacks from escalating.
    • Always - Proactive bot defense is always running and helps prevent attacks from starting.
  10. Click Edit to change the following Proactive Bot Defense settings from their default values as needed:
    • The Block requests from suspicious browsers and CAPTCHA settings are enabled by default. When these settings are enabled, the system validates browser legitimacy using a set of JavaScript challenges and blocks detected bots.
    • The Grace Period setting is the length of time before the system blocks suspected bots. The default value is 300 seconds.
    • The Cross-Domain Requests setting controls how the system responds when receiving a request for non-HTML resources (images, CSS, XML, JavaScript, and Flash) without a valid cookie and has a Referer header with a different domain than the host domain. The default setting is Allow All Requests.
    • The URL Whitelist setting denotes a list of URLs that are not blocked by Proactive Bot Defense.
  11. Click Update to save the DoS profile.

Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

Configuring bot signature checking

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > DoS Profiles.
  3. Click the name of the DoS profile (or click Create to create a new DoS profile).
  4. Click the Application Security tab.
  5. Click Edit next to Application Security, and then select the Enabled check box.
  6. Click Bot Signatures.
  7. Click Edit next to Bot Signature Check, and select the Enabled check box.
  8. Click Edit to change the following Bot Signatures settings from their default values as needed:
    • For Bot Signature Categories, select actions the system takes for each type of bot category.
    • For Bot Signatures List, disable specific bot signatures during signature checking by selecting them from the Available Signatures box and moving them to the Disabled Signatures box.
  9. Click Update to save the DoS profile.

Associating the DoS profile with the virtual server

After you create the DoS profile, you can associate it with the appropriate virtual server. To do so, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the name of the virtual server with which you want to associate the DoS profile.
  4. Click the Security tab and click Policies.
  5. In the DoS Protection Profile list, click Enabled.
  6. In the Profile list, click the name of the profile you want to associate with the virtual server.
  7. Click Update.
