K8513: DNS resolution fails for Linux and Mac OS X clients after a DHCP renewal

Known Issue

This is the result of a known issue. If a Linux or Mac OS X client launches a Network Access connection, and the client device performs a DHCP renewal while the Network Access connection is active, the DNS servers added to the /etc/resolv.conf file by the FirePass client component are overwritten by the DNS servers provided in the DHCP response. When this issue occurs, the user may be unable to access resources across the Network Access connection due to the client device’s inability to perform DNS resolution using the DNS servers provided by the FirePass controller.

The /etc/resolv.conf file is a text file used by the client operating system to perform DNS resolution. This file lists the DNS servers that should be queried in order to translate a domain name into an IP address. For more information about the /etc/resolv.conf file, refer to your Linux or Mac OS X documentation.

F5 Product Development tracked this issue as CR95173 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by disconnecting and reconnecting the Network Access connection.
