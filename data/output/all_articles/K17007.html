Topic

You should consider using this procedure under the following condition:

  • You want to limit BIG-IQ user interface access to clients using high-encryption Secure Sockets Layer (SSL) ciphers and/or protocols.

Description

High-encryption SSL ciphers include those with key lengths larger than 128 bits, and some cipher suites with 128-bit keys.

By default, the BIG-IQ user interface allows you to use a large range of SSL ciphers for SSL clients to connect to the user interface. If you require a more specific and secure list of SSL ciphers, you can modify the cipher list that the BIG-IQ user interface uses.

For BIG-IQ 4.4.0 and later, refer to the following default SSL ciphers and protocols enabled on the BIG-IQ user interface:

  • SSL ciphers

    ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2;

  • SSL protocols

    SSLv2 SSLv3 TLSv1 TLSv1.1 TLSv1.2;

    For example, you can customize the SSL ciphers and protocols to allow access from a client that uses only TLSv1, and keys that are 128 bits or higher. The following replacement strings will allow only high and medium (128 bits or larger) key lengths; only TLSv1 cipher suites, and no export or null cipher suites are allowed:

    • SSL ciphers

      ALL:!SSLv3:!SSLv2:!EXPORT40:!EXP:!LOW;

    • SSL protocols

      TLSv1 TLSv1.1 TLSv1.2;

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have advance shell access to the BIG-IQ system with administrator credentials.
  • You must have familiarity with a command line text editor.

Procedures

Modify the SSL ciphers and/or SSL protocols for BIG-IQ 4.4.0 or later

To modify the SSL ciphers and/or protocols used by the BIG-IQ user interface, perform the following procedure:

Impact of procedure: The procedure will cause access disruption to the BIG-IQ user interface. Perform this procedure only during a scheduled maintenance window.

  1. Log in to the advance shell command line of the BIG-IQ system with administrator credentials.
  2. To display the configured SSL ciphers/protocols used by the BIG-IQ user interface, type the following command:

    egrep "\ ssl_ciphers|\ ssl_protocols" /etc/webd/webd.conf

    For example:

    ssl_ciphers ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2;
    ssl_protocols SSLv2 SSLv3 TLSv1 TLSv1.1 TLSv1.2;

  3. To back up a copy of the /etc/webd/webd.conf file, type the following command:

    cp -p /etc/webd/webd.conf /var/tmp/webd.conf.K17007

  4. Edit the /etc/webd/webd.conf file using a text editor of your choice.
  5. To modify the SSL protocols, locate the line that begins with ssl_protocols in the /etc/webd/webd.conf file:

    For example:

    ssl_protocols SSLv2 SSLv3 TLSv1 TLSv1.1 TLSv1.2;

  6. Edit this line to a preferred list SSL protocols.
  7. To modify the SSL ciphers, locate the line that begins with ssl_ciphers in the /etc/webd/webd.conf file:

    For example:

    ssl_ciphers ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2;

  8. Edit this line to a preferred list of SSL ciphers.
  9. Save the changes and exit the text editor.
  10. To restart the webd process, type the following command:

    tmsh restart /sys service webd
