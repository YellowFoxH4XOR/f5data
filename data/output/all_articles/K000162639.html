K000162639: Wide IP alias masterpiecetst.chubb.com of type AAAA is an alias to non-existent wide IP

Support Solution
Published
2026-07-29
Updated
2026-07-29
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.1
Source
https://my.f5.com/manage/s/article/K000162639

Description

BIG-IP DNS configuration validation fails when an aliased A Wide IP and an AAAA Wide IP with the same hostname are stored at different folder paths.

Example error:

01070213:3: Wide IP alias masterpiecetst.example.com of type AAAA is an alias to non-existent wide IP /partition_1/WIPs/masterpiecetst.gtm.example.com of type AAAA

Environment

  • Product: BIG-IP DNS
  • Feature: Wide IP aliases
  • Configuration validation command:
    tmsh load sys config verify
  • Example configuration:
    • A Wide IP:

/partition_1/WIPs/masterpiecetst.gtm.example.com

    • AAAA Wide IP:

/partition_1/masterpiecetst.gtm.example.com

    • Alias on the A Wide IP:

masterpiecetst.example.com

Cause

When a Wide IP alias is configured, all Wide IP types that share the same hostname must exist under the same partition and folder path.

In this case, the A and AAAA Wide IPs were stored at different paths. During validation, BIG-IP DNS attempted to resolve the alias to the corresponding AAAA Wide IP at the A Wide IP’s path and reported that the object did not exist.

 

Recommended Actions

  1. Identify all Wide IP types that share the aliased hostname, including A, AAAA, and any other applicable types.
  2. Confirm that all matching Wide IPs use the same partition and folder path.
  3. Recreate or move the AAAA Wide IP so that it uses the same path as the aliased A Wide IP. For example:

/partition_1/WIPs/masterpiecetst.gtm.example.com

  1. Confirm that the alias is configured on the intended Wide IP.
  2. Verify that the referenced pools and pool paths are valid.
  3. Validate the configuration:
    tmsh load sys config verify
  4. Install the available fix according to the applicable BIG-IP DNS maintenance procedure.

Additional Information

  • All same-hostname Wide IP objects must use a common folder path when an alias is configured.
  • Successful DNS responses do not confirm that the stored configuration is valid.
  • Removing the alias or the AAAA Wide IP may allow validation to complete, but this changes the intended configuration and should not be used as the permanent solution unless appropriate.
  • A configuration that is initially accepted may still fail during configuration validation or reload if the Wide IP paths remain inconsistent.
