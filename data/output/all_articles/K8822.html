Issue

If the active controller in a FirePass failover pair can no longer ping an IP address configured for external monitoring, the active controller switches to standby mode and logs the following message to the Reports: System Logs page:

User space forced the status to :forced_to_stdby
 
Once the controller can ping the IP address configured for external monitoring, the controller logs the following message to the Reports: System Logs page:

User space forced the status to :exit_forced_stdby

You can enable external monitoring by selecting the Enable External IP Address Monitoring check box under the Failover tab on the Device Management: Network Configuration page. Under that check box, you can enter a list of IP addresses to monitor in the External IP Addresses for monitoring field.

For more information about the external monitoring feature, refer to the Device Management: Network Configuration: Failover page in the FirePass online help.
