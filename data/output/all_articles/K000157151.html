Description

This article addresses an issue encountered when attempting to activate a license on F5OS platforms, specifically where the dossier generated by the system is rejected by the F5 licensing server.

Error 51075: "Invalid Dossier - Unable to decrypt - The inbound dossier cannot be decrypted by the F5 Licensing server."

This situation typically arises during manual licensing attempts for rSeries appliances or similar F5OS-based systems. 

 

Environment

  • Licensing
  • Invalid dossier
  • error 51075 
  • F5 Licensing server

Cause

Licensing was attempted from within a tenant or using an incorrect procedure, resulting in an invalid dossier that could not be decrypted by the F5 licensing server.

 

Recommended Actions

Follow the steps below to manually activate the license via the Activate F5 Product page using the get_dossier command.

Important: For rSeries appliances, always perform licensing operations on the F5OS platform layer. The tenant(s) will automatically inherit the license from the platform layer. This same principle applies to vCMP systems.

 

  1. Using CLI, Login to the F5OS platform (not the tenant)
  2. Generate the dossier using the command:
    system licensing get-dossier
  3. Copy the generated dossier
  4. Activate the license through Activate F5 Product. 
  5. Complete the license activation at the F5OS platform layer. The service check date will be updated upon successful license activation
  6. Verify the license status using tmsh show /sys license from the tenant (if needed)
