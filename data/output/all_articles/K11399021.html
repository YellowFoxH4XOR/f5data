Description
When configuring auth providers in the BIG-IP, if the certificates or list of certificates bypasses the 32766 KB size limit you will see a similar message like the following in the /var/log/tokumon/current :

original message: bytes can be at most 32766 in length; got <cert actual size>","caused_by":{"type":"max_bytes_length_exceeded_exception","reason":"bytes can be at most 32766 in length; got <cert actual size>"}} see searchd log for complete error.

Also, the configured auth provider will not be visible in the GUI.

Environment

  • BIG-IQ
  • Auth Providers
  • SSL certificate

Cause

BIG-IP can only accept certificates or a list of certificates that is not larger than 32766 KB in size, otherwise, the object will not be indexed in the system.

Recommended Actions

  1. Configure the auth provider with only the corresponding certificates making sure that the size does not bypass 32766 KB
  2. Consider using only the root certificates, or only the certificates that will allow authentication to work
