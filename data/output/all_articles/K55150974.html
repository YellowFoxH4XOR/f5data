Description

ECDSA algorithm is currently not supported for DNSSEC in DNS cache, below similar errors will showing up from DNS cache logs

info tmm[10716]: DNScache: super is example.com. A IN
debug tmm[10716]: DNScache: Failed to match any usable DS to a DNSKEY.
info tmm[10716]: DNScache: Did not match a DS to a DNSKEY, thus bogus.

Environment

  • LTM
  • DNSSEC
  • DNS cache

Cause

Customer uses BIG-IP as validating resolver cache for verifying identity of DNS response. DNSSEC validation resolver rejects RR as bogus:

# tmsh show ltm dns cache validating-resolver validate-resolver.a.cache
  ... snip ...
Response Validation Status       Total           %
  Unchecked                          0           0
  Bogus                              3          75
  Indeterminate                      0           0
  Insecure                           1          25
  Secure                             0           0

Check the pcap, can see a DS record with ECDSA signature was being used:

$ tshark -nr dns_DNSSEC_SERVFAIL.pcap -Y "dns.ds.digest_type == 1" -O dns
..snip..
        Example.com: type DS, class IN
            Name: example.com
            Type: DS (Delegation Signer) (43)
            Class: IN (0x0001)
            Time to live: 86400 (1 day)
            Data length: 24
            Key id: 0x10c4
            Algorithm: ECDSA Curve P-256 with SHA-256 (13)
            Digest Type: SHA-1 (1)
            Digest: e5b28f74f83ad172efc657f9268265bd08a346e2

Recommended Actions

Avoid using "ECDSA" algorithm signed DS records.
