Security Advisory Description

net/netfilter/nf_dup_netdev.c in the Linux kernel 5.4 through 5.6.10 allows local users to gain privileges because of a heap out-of-bounds write. This is related to nf_tables_offload. (CVE-2022-25636)

Impact

BIG-IP, BIG-IQ Centralized Management, BIG-IP SPK, F5OS-A, and F5OS-C

There is no impact; these products are not affected by this vulnerability.

Traffix SDC

A local attacker can escalate their privileges on a vulnerable system to gain access to restricted resources, modify files, or cause a denial-of-service (DoS).

Mitigation

To mitigate this vulnerability, you can configure the Linux host system to disable the use of user namespaces. To do so, perform the following procedure:

Impact of action: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffix SDC command line.
  2. Create a file using the following naming format in /etc/sysctl.d/, but do not overwrite an existing file:

    <two-digit number>-<name>.conf

    For example:

    99-custom.conf

    Note: Per the sysctl.d manpage: "If multiple files specify the same option, the entry in the file with the lexicographically latest name will take precedence. It is recommended to prefix all filenames with a two-digit number and a dash, to simplify the ordering of the files." For more information, refer to the sysctl.d manpage by entering man sysctl.d from the command line.

  3. To disable the use of user namespaces, add the following line to the file you created:

    user.max_user_namespaces = 0

  4. Reload the system configuration files so the changes will take effect by entering the following command:

    sudo sysctl --system
