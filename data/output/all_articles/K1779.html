K1779: Limits on the amount of HTTP data that can be parsed by rules

Published

Status

  • BIG-IP 4.X: 4.6.4
Source

Topic

BIG-IP rules that evaluate data within the payload from a client (such as HTTP request information) can read up to 16 kilobytes of data from the client.

For more information about rules, refer to the BIG-IP Reference Guide.
