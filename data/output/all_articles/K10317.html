K10317: The TunnelServer.exe process continues to run after a Static Application Tunnel closes

Issue

Previously, when a user opened one or more App Tunnels, the TunnelServer.exe process on the client system immediately exited when the last App Tunnel was closed.

Starting in cumulative hotfix HF-603-2, if a user opens one or more Static App Tunnels, the TunnelServer.exe process does not exit when the last App Tunnel is closed. Instead, the TunnelServer.exe process exits at different times depending on the status of the parent process:

  • When the parent process is gracefully terminated, the TunnelServer.exe process exits immediately.

    For example, this occurs when the user exits the browser or the standalone VPN client.
  • When the parent process is not terminated gracefully, the TunnelServer.exe process will continue to run until the client system is restarted.

    For example, this occurs when the browser crashes or the user kills the browser process instead of exiting.
  • When the parent process continues to run, the TunnelServer.exe process exits approximately 15 minutes after the last App Tunnel is closed.

If the user opens one or more Dynamic App Tunnels, but does not open a Static App Tunnel, the TunnelServer.exe process exits immediately after the last Dynamic App Tunnel is closed.
