K18324833: BIG-IP configuration can be loaded without a license

Type
Knowledge
Published
2017-12-20
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K18324833

Issue

Beginning in BIG-IP 13.1.0, the BIG-IP configuration loads without a license but does not pass traffic until you apply a license.

This change allows you to edit the BIG-IP configuration using tmsh or the Configuration utility, even without the correct module being licensed.

F5 Product Development tracked this change as ID 605514.

Impact

Although the BIG-IP configuration loads even if it encounters unlicensed elements, the system still marks these elements as being in an offline state and does not pass traffic. You are still required to either add the appropriate license or remove the configuration elements for the module that is not licensed.

The following symptoms occur if the configuration load detects an unlicensed element:

  • The command line interface returns a ModuleNotLicensed message or the Configuration utility displays a banner indicating that one or more of the modules are not licensed.
  • The system logs a message containing license_exceeded_t to the /var/log/ltm file.

Recommended Actions

If you recently applied a different license that reduces the number of software modules available to your device without first removing the affected configuration elements, you can either remove the configuration elements, or you can re-apply the original license so that the device passes traffic.

The BIG-IP system does not have the ability to provide a listing of all of the configuration elements that fail to load, but you can get an indication of this by looking in the /var/log/ltm file for messages similar to the following:

Jul 24 14:17:06 bigip1 err mcpd[6780]: 01070356:3: Exceeding pool member limit (3). Cannot add pool member to pool:(/Common/p80_pool). Local traffic management feature not licensed.

This message indicates that the BIG-IP LTM module is not licensed and the pool cannot have additional pool members.  You can either add the BIG-IP LTM license or remove the pool members so the configuration loads without exceeding the license.
