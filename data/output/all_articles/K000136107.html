Description

You may want to send layer 7 dos logs in /var/log/dosl7/dosl7d.log to a remote logging server so you can get on time notification of dos events in your production environment.

Environment

  • ASM provisioned
  • dos profile enabled on virtual server
  • DOS attack

Cause

None

 Recommended Actions

The only publisher supported for DOS events for High Speed Logging is Splunk, however we're unable to choose the pool directly when when choose splunk in log destination. So the workaround is to create two log destination, one is for type 'Remote HSL', and the other will be splunk, which will forward to the first log destination. 

  1. Create a Pool with the remote log server as the member.
  2. Go to System ›› Logs : Configuration : Log Destinations and create one of these two types of Destinations depending on whether you want to use TMM or management for the traffic.
  3. For a High Speed Logging Destination Click Create Select the pool you created in step 1.
    1. Name the Log Destination.
      1. Click Finished.
    2. Select 'Remote High-Speed Log'.
    3. Select the pool you created in step 1.
    4. Select TCP or UDP.
    5. Select the Distribution method (leave in default if only one pool member).
  4. To use the management interface (only one IP can be used in this method)
    1. Enter IP and port of logging server.
      1. Click Finished.
    2. Select Protocol.
  5. Now create another Log Destination (this will in essence trick the BIG-IP to use HSL logging).
    1. Choose type Splunk.
    2. Forward to either the HSL or management interface.
    3. Click Finished.
  6. Go to System ›› Logs : Configuration : Log Publishers
    1. Click Create.
    2. Name it.
    3. Choose the Destination from step 3.
    4. Click Finished.
  7. Go to Security ›› Event Logs : Logging Profiles
    1. Click Create.
    2. Check the DoS Protection to enable it.
    3. In the Remote Publisher section choose the Publisher from step 4.
    4. Complete the rest of the logging profile as needed.
    5. Click Create.

An example configuration looks like below:

sys log-config publisher /Common/dos-publisher {
  destinations {
    /Common/second-dos-destination { }
  }
}
sys log-config destination remote-high-speed-log /Common/dos-destination {
  pool-name /Common/pool-logging
}
sys log-config destination splunk /Common/second-dos-destination {
  forward-to /Common/dos-destination
}
