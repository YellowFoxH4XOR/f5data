Description

  • APM users getting stuck on "Connecting" when trying to establish Network Access VPN tunnel
  • Message in /var/log/apm contains string "LCP_UNKNOWN_OPTIONS 1,LCP_PROTO_REJ 1"

Environment

  • BIG-IP with APM provisioned
  • Users connecting to Network Access tunnel either with EdgeClient or web browser
  • Network Access profile is configured with PAC file

Cause

The PAC file contains a syntax error, preventing the client from interpreting it after it was downloaded during the Network Access tunnel start.

Recommended Actions

Check the PAC file for syntax errors.

None
