Topic

You should consider using this procedure under the following condition:

  • You need to connect a workstation to your rSeries or VELOS systems to access the console.
  • You need to connect a console server to your rSeries or VELOS systems to access the console.

Description

You can access the command line of your rSeries or VELOS system through the serial console port. This is useful when network access to the system is not available.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a console server or a workstation with a VT100-capable terminal emulator such as PuTTY.
  • You have a RJ45 to DB9 serial console port cable or RJ45F to RJ45M rolled serial adapter and CAT5 cable.

Procedures

  • Connecting a workstation to the serial console port
  • Connecting a console server to the serial console port
  • Setting the baud rate

Connecting a workstation to the serial console port

Perform the steps below to access the command line of your device by connecting to the console port.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect the RJ45 to DB9 console port cable to the RJ45 console port on the VELOS system controller or rSeries device.
  2. Connect the cable to the DB9 port on the management workstation.
  3. Launch the serial terminal emulator on the workstation and configure it with the default serial port settings unless you changed the defaults. The rSeries and VELOS default settings are listed below:
    • Baud rate: 19200
    • Data bits: 8
    • Parity: None
    • Stop bit: 1
  4. Log in to the system. If you see garbled text, there is a baud rate mismatch so double check the settings on the device and the workstation. Refer to the Setting the baud rate section below for more information.

Connecting a console server to the serial console port

Perform the steps below to access the command line of your device by connecting a console server to the console port.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Connect the RJ45F to RJ45M rolled serial adapter to the RJ45 console port on the VELOS system controller or rSeries device.
  2. Connect a CAT5 cable to the adapter. The adapter provides the appropriate pinout connection to your equipment.
  3. Connect the cable to a serial console server.
  4. Configure the console server with the default serial port settings unless you changed the defaults. The rSeries and VELOS default settings are listed below:
    • Baud rate: 19200
    • Data bits: 8
    • Parity: None
    • Stop bit: 1
  5. Access the console server and log in to the system. If you see garbled text, there is a baud rate mismatch so double check the settings on the device and the server. Refer to the Setting the baud rate section below for more information.

Setting the baud rate

  • K000139070: Setting the baud rate of the VELOS system controller serial console port
  • K000139071: Setting the baud rate of the rSeries system serial console port

Note: Currently on the VELOS system you can only change the baud rate from the AOM menu by connecting to the console so if the output is unreadable, you will have to try other baud rate settings on the workstation or console to find a match and correct the output.
