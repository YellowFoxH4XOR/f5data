Issue

Error Message

err mcpd[<PID>]: 01070392:3: Self IP <self_IP> / <self_IP_netmask>: This IP shares a network with the management IP (<mgmt_IP> / <mgmt_IP_netmask>).

In this error message, note the following:

  • <PID> is the process ID of the mcpd process.
  • <self_IP> is the IP address you are attempting to configure.
  • <self_IP_netmask> is the netmask of the self IP address you are attempting to configure.
  • <mgmt_IP> is the existing management address that is in conflict with the self IP address you are attempting to configure.
  • <mgmt_IP_netmask> is netmask of the existing management IP address that is in conflict with the self IP address you are attempting to configure.

For example:

err mcpd[5646]: 01070392:3: Self IP <192.0.2.2> / <255.255.255.0>: This IP shares a network with the management IP (<192.0.2.3> / <255.255.255.0>).

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The TMOS Shell (tmsh)

Description

This message occurs when the following condition is met:

  • You attempted to configure a self IP address with a subnet that overlaps the subnet defined for a management IP address.

Impact

The requested operation fails validation, with no changes made to the system.

Recommended Actions

You can modify either the self IP address or the management IP address so that they do not share the same network. To reconfigure the networking options for the management interface, you can use the serial console port. To do so perform the following procedure.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Connect a terminal emulator to the BIG-IP system by using the serial port.

    Note: For more information about configuring terminal emulation, modifying baud, and the null modem serial cable requirements, refer to the following articles:

    • K7683: Connecting a serial terminal to a BIG-IP system
    • K9156: Setting the baud rate of the serial console port
    • K587: Pinouts for serial terminal cables used to connect the 9-pin serial port on F5 products
  2. From the BIG-IP command line, start the F5 Management Port Setup tool by typing the following command:

    config

  3. Enter data in the IP address, netmask, and default management route pages so that it does not conflict with the self IP address you are attempting to configure.
