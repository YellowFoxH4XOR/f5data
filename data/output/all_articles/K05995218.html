Description

The mysqld incorrectly classifies the lost+found directory as a database location resulting in benign errors in the mysql log.

The log messages can be found in:

/var/lib/mysql/mysqld.err

[ERROR] /usr/sbin/mysqld: Can't find file: './lost+found/AVR_STAT_ASM_CPU_T.frm' (errno: 13)
[ERROR] Invalid (old?) table or database name 'lost+found'

Environment

  • AVR
  • ASM provisioned

Cause

Bug ID 375997

Recommended Actions

The issue is cosmetic. It can be safely ignored.

Version 14 and later uses a newer version of MariaDB which is not affected by this issue.
