Known Issue

This is the result of a known issue. When attempting to back up an access policy from an administrator account that is not in the common partition, the backup will fail with the following error message:

! Error executing shell command

F5 Product Development tracked this issue as ID 226487 (formerly CR141597) and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP version 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download hotfixes or later versions of hotfixes from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

Workaround

You can work around this issue by backing up access policies using accounts that are in the common partition. For more information about administrative partitions, refer to K7230: Overview of administrative partitions.
