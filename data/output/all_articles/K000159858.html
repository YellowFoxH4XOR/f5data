K000159858: [F5OS] False Alarm "One or more openshift certificates has expired or is expiring."

Description

The orchestration-manager daemon on F5OS-C (VELOS) system controllers may fail to automatically clear the CRITICAL alarm "One or more openshift certificates has expired or is expiring". Running the command  show system alarms provides the following output.

# show system alarms
ID      RESOURCE      SEVERITY  TEXT                                                          TIME CREATED
-----------------------------------------------------------------------------------------------------------------------------------
524289  controller-1  CRITICAL  One or more openshift certificates has expired or is expiring. 2025-10-19 12:27:23.173271311 UTC

Environment

  • F5OS Controller
  • Openshift Cluster

Cause

  • Bug ID1959341

Answer/Recommended Actions

  • Verify certificate expiry dates using the show_certs.sh script using K64001020.
  • If none of the certificate is expired or in warning state, use the following command to clear the false alarm: 
    docker exec alert-service /confd/test/sendAlert --source controller-1 --name openshiftCertificatesExpiring --report clear --id <Alarm_ID> --severity critical
  • Monitor the system and if the alarm reappear, contact F5 technical support for further assistance.

Additional Information

OpenShift certificate expiration alarms may persist even after certificates have been renewed or are not actually expired. This is a false positive alarm that doesn't automatically clear.
