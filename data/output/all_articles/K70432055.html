Issue

Error Message

010c0048:5: Bcm56xxd and lacpd connected - links up

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • During system start up, the switch daemon (bcm56xxd) and link aggregation control protocol daemon (lacpd) attempt to connect to the switch over daemon (sod) over TCP port 1030. After connecting successfully to sod, the bcm56xxd and lacpd daemons initialize the external interfaces, and the sod daemon logs the message indicating that the links are up.

The sod process causes the BIG-IP system to become active or standby, and provides failover capability through a high-availability table.

Impact

None. The message is informational.

Recommended Actions

None
