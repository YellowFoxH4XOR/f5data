Description

When an Elastic Load Balancer (ELB) is created via Neutron, it stays in a Faulty state, not in a running state.

Environment

  • F5 Integration for OpenStack Neutron LBaaS
Cause

Undetermined at time of publication

Recommended Actions

When you get this particular issue, you should contact F5 Technical Support for assistance.
You must follow the steps detailed in the following sections to correctly collect and submit the diagnostic data that the support representative will require in order to assist you.
  1. Check the agent list in the OpenStack Horizon dashboard, or run the neutron agent-list on the Neutron controller (or any other host where you installed F5 Agent).
    If f5-openstack-agent, or f5-oslbaasv2-agent, doesn’t appear in the agent list the F5 Agent isn’t running.
     
  2. Set the DEBUG log level output for Neutron:
    sudo vi /etc/neutron/neutron.conf
    [DEFAULT]
    ...
    # Print debugging output (set logging level to DEBUG instead of default WARNING level).
    debug = True
     
  3. Set the DEBUG log level output for F5 Agent.
    sudo vi /etc/neutron/services/f5/f5-openstack-agent.ini
    #
    [DEFAULT]
    # Show debugging output in log (sets DEBUG log level output).
    debug = True
    ...
     
  4. Recreate the object again until the error is seen
     
  5. Check the logs for error messages:
    grep "ERROR" /var/log/neutron/f5-openstack-agent.log
     
  6. Check the status of the f5-openstack-agent service
    sudo systemctl status f5-openstack-agent.service \\ CENTOS
    sudo service f5-oslbaasv2-agent status           \\ UBUNTU
     
  7. Make sure you can connect to the BIG-IP
    ssh admin@<big-ip_mgmt_ip>
     
  8. Verify that the following entries in the F5 Agent configuration file are correct:
    • iControl hostname (can be a DNS-recognized hostname or the BIG-IP device’s management IP address)
    • username (account must have permission to manage LTM objects in the OpenStack tenant’s partition; see )
    • password
  9. When finished please share the output of 5, 6 and 7 and send the following files: 
    i. neutron.conf -> found at /etc/neutron 
    ii. f5-openstack-agent.ini -> found at /etc/neutron/services/f5 
    iii. f5-openstack-agent.log -> found at /var/log/neutron 
    iv. f5-openstack-agent status v. output of command: neutron agent-list
     
  10. Return the log level for Neutron & F5 Agent to normal by setting "debug = False" (see steps 2 & 3)
