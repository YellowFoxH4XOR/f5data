Description

You want to modify theMACs used by the secure shell (SSH) service on the BIG-IP F5OS. 

Environment

  • F5OS-A
  • F5OS-C 

 

Cause

  • Informational

 

Answer/Recommended Actions

 1. Check the available MACs using admin login and from bash type the command below:

# show running-config system security services service sshd

 

example:

rSeries# show running-config system security services service sshd

system security services service sshd

 config ciphers [ aes128-cbc aes128-ctr aes128-gcm@openssh.com aes256-cbc aes256-ctr aes256-gcm@openssh.com ]

 config kexalgorithms [ diffie-hellman-group14-sha1 diffie-hellman-group14-sha256 diffie-hellman-group16-sha512 ecdh-sha2-nistp256 ecdh-sha2-nistp384 ecdh-sha2-nistp521 ]!

 

Note: Although "show system security services service sshd" displays MAC algorithms, they will only appear in the CLI output if they have been explicitly configured. If the state macs line is missing, the system is utilizing internal factory defaults.

 

2. Check the available MACs. Login using root and from bash type the command below:

# ssh -Q mac

Note: These are the factory default MACs used

 

example:

[root@appliance-1(rSeries) ~]# ssh -Q mac

hmac-sha1

hmac-sha1-96

hmac-sha2-256

hmac-sha2-512

hmac-md5

hmac-md5-96

hmac-ripemd160

hmac-ripemd160@openssh.com

umac-64@openssh.com

umac-128@openssh.com

hmac-sha1-etm@openssh.com

hmac-sha1-96-etm@openssh.com

hmac-sha2-256-etm@openssh.com

hmac-sha2-512-etm@openssh.com

hmac-md5-etm@openssh.com

hmac-md5-96-etm@openssh.com

hmac-ripemd160-etm@openssh.com

umac-64-etm@openssh.com

umac-128-etm@openssh.com

 

Save the output of the command "ssh -Q mac" into a txt file for later reference.

 

3. To modify the list of MAC currently in used by the SSH service, you must first enter into the configuration mode by entering this command:

 

# config

 

4. Then enter the following command syntax:

 

# system security services service sshd config macs[ <replacement list of MACs> ]

 

For example, to configure MAC to use hmac, enter:

# system security services service sshd config macs [ hmac-sha1 hmac-ripemd160 hmac-ripemd160@openssh.com ]

 

5. To save the change, enter the following command:

 

# commit and-quit

 

The system then prompts you to confirm if you want to proceed with committing the change as the process will restart the SSH service and the SSH service will be momentarily unavailable:

 

The following warnings were generated:

 'system security services service sshd': Changing SSH configuration will restart the SSHD service.

Proceed? [yes,no]

 

To proceed, enter yes.

 

6. To verify the change, enter the following command:

 

# show system security services service sshd
