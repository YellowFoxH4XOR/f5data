Known Issue

This is the result of a known issue. The administrative partitions feature allows you to assign BIG-IP LTM system objects into logical partition groups, and then grant or restrict user access to those partitions. When the administrative partition is set to All (Read Only), the virtual server Protocol Profile (Client) setting displays incorrect configuration information. This behavior is a display issue, and it does not impact the running configuration.

For example, if you create a virtual server in the common partition, with Protocol Profile (Client) set to FastL4, and then change it to the All (Read Only) partition, the BIG-IP LTM system incorrectly displays the Protocol Profile (Client) as TCP.

F5 Product Development tracked this issue as CR98047 and it was fixed in BIG-IP LTM 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue still exists in the BIG-IP LTM 9.4.x software branch.
