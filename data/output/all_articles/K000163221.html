K000163221: Configuration is not copied to a new BIG-IP software volume when Install Configuration is set to No

Type
Support Solution
Published
2026-09-07
Updated
2026-09-07
Source
https://my.f5.com/manage/s/article/K000163221

Description

A BIG-IP LTM boots from a new software volume without the expected configuration. Customer may experience configuration loss issues.

Environment

BIG-IP LTM

Cause

The default Install Configuration setting of No does not copy the configuration from the source volume to the new software volume.

Answer/Recommended Actions

When booting the target software volume, set Install Configuration to Yes and select the source volume containing the existing configuration. Verify that the configuration loads successfully after booting the target volume.

Additional Information

The audit log will not show the Install Configuration setting, you may see the following logs in user.log when Install Configuration is set to Yes

info: Getting configuration from HD1.1

info: Copying configuration to HD1.2

info: Applying configuration to HD1.2
