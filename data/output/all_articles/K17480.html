Known Issue

The BIG-IP APM rewrite process may incorrectly handle the HTML form submit() method.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • The JavaScript code in the HTML page invokes the submit() method with arguments.

In the following example, the submit() method is invoked with the form f as an argument:

<form id=f name=f action='/test-some-form'>
</form>

<script>
with (f) {
submit(f);
}
</script>

The submit(f) expression will not be rewritten by APM portal access, causing the request to fail.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using portal access, HTML forms are not submitted.
  • When using portal access, requested pages fail to display.
