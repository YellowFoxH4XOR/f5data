K000092005: Poor RDP Performance through APM Webtop

Type
Support Solution
Published
2022-08-04
Updated
2022-08-04
Source
https://my.f5.com/manage/s/article/K000092005

Description

In an RDP architecture where BIG-IP APM is the gateway - RDGW / Remote Desktop GateWay - users may experience poor performances.

 Environment

  • BIG-IP APM
  • Microsoft RDP

 Cause

This may be due to the setting "RSC in the vSwitch".

 Recommended Actions

With getting confirmation from Microsoft Support, we can suggest we investigate the option to disable RST or RSC on the server's network interfaces.

 Additional Information

None
