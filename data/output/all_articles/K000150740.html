Description

You just want to understand what the 'DATE' column means when you ran 'show system image' in the F5OS cli.

See the sample output below:

  • # show system image 
                                                                          IN            
VERSION OS   STATUS  DATE        SIZE      USE    TYPE   
---------------------------------------------------------
1.8.0-17564  ready   2024-11-24  899.31MB  true   EHF-1  
1.5.1-12283  ready   2023-08-14  937.02MB  false         
1.5.0-5781   ready   2023-04-30  937.01MB  false         
1.3.2-13054  ready   2023-01-26  933.11MB  false

Environment

  • F5OS
  • CLI
  • show system image command

Cause

None

Recommended Actions

No action is required.

The 'DATE' column is the build time - the date the image was created. It is not the date the image was uploaded to the system nor the date when the image is published in the F5 download site and to be downloaded.

In the sample above, the image 1.8.0-17564 build date is 2024-11-24. It was ready to be downloaded from F5 download site since Dec, 03, 2024.
