Known Issue

This is the result of a known issue. When you access a Windows file share, FirePass attempts to auto-logon to the file share with your FirePass logon credentials even if the Auto-logon to Windows File shares using FirePass user logon credentials check box is cleared on the Portal Access : Windows Files : Master Group Settings page.

F5 Product Development tracked this issue as CR77962 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-600-13 has been issued for FirePass version 6.0.0, and cumulative hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download thes hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
