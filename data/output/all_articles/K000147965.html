What Happened?

I want to show the error page from the origin server instead of an F5 Distributed Cloud (XC) error page like the one shown below:

 

 

Environment

  • F5® Distributed Cloud (SaaS)
  • F5® Distributed Cloud (XC) Load Balancer

Resolution/Answer

To show the error page from the origin server:

  1. Go to the Load Balancer Setting page
  2. Click More Options
  3. Check Disable Default Error Pages
  4. The default error page returned by F5 XC Load Balancer will be disabled and it will return your error page from the origin server, this option is for the response with 4xx and 5xx code.
    1.   

 

Cause

The F5 XC Load Balancer will return the default custom error page if the origin server returns error to LB, but if this error contains the detail or log of the error, the customer can't analyze it, so they can use this way to fix this.
