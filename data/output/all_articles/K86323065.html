Description

In rare instances, F5 Support may ask to enable debugging for the asmlogd daemon.

Environment

ASM is provisioned.

Cause

Not applicable.

Recommended Actions

Enabling asmlogd debugging

Impact of procedure: The extra logging can cause some additional load (particularly I/O load) on the unit.

To enable the trace logging, the highest debug level for the asmlogd process, issue the following from the CLI:

tmsh modify sys db log.asm.asmlogd.level { value "trace" }

Additional messages will be logged to the /var/log/ts/asmlogd.log file.

Note: The change should be detected automatically by the asmlogd daemon.  No restart should be required.

Disabling asmlogd debugging

To turn off the additional debugging, change the modified priority back to the default and save:

tmsh modify sys db log.asm.asmlogd.level { value "info" }

Additional Information

If using the reset-to-default option with the "tmsh modify sys db log.asm.asmlogd.level" command, the asmlogd daemon has to be restarted.
