Topic

This article explains the Version Plus license offerings for BIG-IP Virtual Edition (VE).

Note: F5 is replacing Version Plus with a new perpetual licensing model for BIG-IP VE called Version Select. The final Version Plus SKU reaches End of Sale (EoS) on January 1st, 2027. For more information about Version Select refer to K000163422: BIG-IP VE Version Select license offerings.

Description

Starting with BIG-IP 11.4.1, customers can purchase all BIG-IP Virtual Edition (VE) SKUs with Version Plus licenses.

Version Plus licenses enable customers to use BIG-IP VE with perpetual usage. However, upgrades are limited to software versions within a pre-established range of software releases.
Note: The other VE license options are subscription, pay-as-you-go, and the Flex-Consumption Program (FCP).

With Version Plus licenses, the software license version serving as the upper bound of the pre-established set of software releases that a customer is authorized to use is embedded within the names of BIG-IP VE SKUs. The additional versions will be allowed as part of license reactivation during the software upgrade process.

For example, a BIG-IP VE SKU F5-BIG-xxx-xxx-V16 enables customers to have perpetual usage with upgrades up to and through the last major, minor, maintenance, and point release of BIG-IP 16.x.x. The latest set of BIG-IP VE SKUs F5-BIG-xxx-xxx-V23 permit usage up to and including the last major, minor, maintenance, and point release of BIG-IP 23.x.x.

Note that prior to discontinuing BIG-IP Next, F5 adjusted the BIG-IP versioning methodology, resulting in a nomenclature difference between the version number indicated in the V18 VE SKU (F5-BIG-xxx-xxx-V18) and the actual software versions that are supported. As such, BIG-IP TMOS 17.5 is the final software version that V18 VE customers should upgrade to. While V18 VE licenses permit upgrades to BIG-IP Next 20.x, F5 does not recommend doing so because BIG-IP Next has been discontinued and is now unsupported. The final BIG-IP Next software release was BIG-IP Next 20.3, which reached the end of its lifecycle on April 30, 2025. For more information about this change, refer to K000152956: BIG-IP Strategic Update: Modernizing BIG-IP TMOS and Discontinuing BIG-IP Next.

The standard F5 software lifecycle and support policies apply to the BIG-IP VE SKUs with Version Plus licenses. The software development and support timelines are established through the policies and published upon each major and minor release. The lifecycle for BIG-IP VE Version Plus SKUs aligns with the software lifecycle of the last minor release within the pre-established set of software releases that a customer is authorized to use.

For example, a BIG-IP VE SKU F5-BIG-xxx-xxx-V16 establishes software development and support timelines from the last major, minor, maintenance, and point release of BIG-IP 16.x.x. Similarly, a BIG-IP VE SKU F5-BIG-xxx-xxx-V18 establishes software development and support timelines from the last major, minor, maintenance, and point release of BIG-IP 17.5.x. For a new BIG-IP VE SKU F5-BIG-xxx-xxx-V23, the end of software development (EoSD) and End of Technical Support (EoTS) milestones align with that of BIG-IP 23.x.x.
