Known Issue

The BIG-IP system incorrectly includes the elliptic_curves extension in the Server Hello message during a Transport Layer Security (TLS) handshake.

This issue occurs when all of the following conditions are met:

  • A virtual server configured with a Secure Sockets Layer (SSL) profile receives a Client Hello message to initialize a TLS session.
  • The SSL profile applied to the virtual server is configured to use Elliptic Curve Cryptography (ECC) cipher suites.
  • The BIG-IP chooses an ECC cipher suite for the TLS session.
Some clients will terminate the TLS handshake when they receive the inappropriate extension in the Server Hello.

Impact

TLS handshakes may fail to virtual servers with an SSL profile.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Some or all clients will fail to establish a TLS session with affected virtual servers.
  • The BIG-IP system logs error messages to the /var/log/ltm file that appear similar to the following example:

    info tmm1[12345]: 01260013:6: SSL Handshake failed for TCP 10.1.1.2:20000 -> 10.1.1.1:15000

  • A packet capture of the affected traffic shows that the client ends the TLS handshake with an Unsupported Extension Fatal Alert message.
