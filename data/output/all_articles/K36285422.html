Known Issue

The BIG-IP system may fail to rebuild the SELinux policy after you perform a hotfix upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is in a device group configuration.
  • You perform a hotfix installation on a target software slot that already has the required base software.
  • You previously booted into the target software slot.
  • The BIG-IP hotfix contains a SELinux policy update.

Impact

The configuration synchronization (ConfigSync) may fail after you perform a hotfix upgrade.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you run the ConfigSync, you observe an error message that appears similar to the following example:

    01071488:3: Remote transaction for device group /Common/device_group to commit id 3 6085773701354286521 /Common/bigip.example.com 0 failed with error 01070712:3: Caught configuration exception (0), verify_sync_result:() :Failed to sync files. - sys/validation/FileObject.cpp, line 6276..

Resolution

Status

F5 Product Development has assigned ID 556277 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To prevent this issue from occurring, you can install the base build into a volume and install the hotfix onto that volume, without booting the volume in-between.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
