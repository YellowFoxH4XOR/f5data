Topic

A regular expression is a string used to describe or match a set of strings, according to certain syntax rules.

iRules allow the use of basic regular expressions (BRE), extended regular expressions (ERE), and advanced regular expressions (ARE). AREs are introduced by the Tool Command Language (TCL) implementation, and are basically EREs with some significant extensions.

While iRules allow the use of regular expressions, F5 recommends that you use built in iRules string comparison commands, such as contains, whenever possible, since they are optimized for speed and efficiency.

For information and examples regarding regular expression use in iRules , refer to the iRules 101 -#10: Regular Expressions document located on the F5 DevCentral website.
