Description

This article explains how the "arping" linux command can be used to send out an ARP announcement (aka Gratuitous ARP/GARP) for a specific non-floating self-IP on a specific vlan on the Big-IP. 

 

Environment

Big-IP i5800, no interfaces which are allowed to be cycled DOWN/UP by an admin

 

Cause

The usual methods to force the Big-IP to send GARPs for all owned IPs outlined in https://my.f5.com/manage/s/article/K50014322 aren't suitable for your platform, or cannot be followed due to administrative restrictions in the environment.

This article is intended for the scenario where an upstream switch/router needs to update its MAC to physical port mapping table for some reason, but logging into the switch itself to clear out any erroneous entries is not an option.

However, the procedure outlined should not have any adverse effects and can be used in other situations as the admin sees fit, and provide an alternative method to send out a specific GARP from any Big-IP, although we are limited to doing this only for non-floating self-IP addresses.

 

Recommended Actions

The following command issued in the bash shell on the Big-IP should send an ARP announcement (ie. GARP) on a specific vlan for a specific non-floating self-ip:

arping -c 4 -A -I vlan_name 10.10.10.4 

The example command above would send 4 GARPs on the vlan 'vlan_name' for the pre-configured self ip '10.10.10.4'.
