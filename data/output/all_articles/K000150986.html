Description

  • GTM to LTM health checks failing.
  • Device certificates were recently updated.
  • iQuery is not working
  • SSL errors in the /var/log/gtm file.
    • err gtmd[14274]: iqmgmt_receive: SSL error: error:#:SSL routines:ssl3_read_bytes:sslv3 alert certificate expired from connection x.x.x.x

 

Environment

  • DNS to LTM iQuery communication
  • Recent device certificate updates or changes.

 

Cause

  • The issue appears to be related to a known bug in the BIG-IP system. Specifically, when device certificates are renewed via the GUI, they may not be correctly appended to the required certificate files (big3d/client.crt and gtm/server.crt), leading to SSL errors and broken iQuery connections.
  • Bug ID 858905

 

Recommended Actions

  • Use bigip_add on the DNS to re-add LTM.
  • Additionally, recommend upgrading to a supported version of BIG-IP software where this bug has been addressed. Version 15.1.4 is no longer supported, which limits the availability of fixes and further assistance for software-related issues. F5 strongly recommends upgrading first to version 16.x, followed by 17.x, both of which include significant stability and security improvements.
  • Refer to this article on proper bigip_add usage: Overview of the BIG-IP DNS big3d_install, bigip_add, and gtm_add utilities (11.x - 17.x)
