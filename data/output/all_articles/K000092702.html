Published

Source

Description

Automation with Lets Encrypt and BIG-IP LTM that can fetch and replace an expired SSL certificate on a BIG-IP Appliance

Environment

  • BIGIP-LTM
  • SSL Certificate Management
  • Lets Encrypt

Cause

This was a general question of any way to automatically fetch and replace a SSL certificate about to expire on a Virtual Server

Recommended Actions

There is no automation on LTM. However, if there is a BIG-IQ, then we have a solution to automate this procedure. This is articulated in the below manual:

Integrating Let's Encrypt with BIG-IQ for Certificate Management

https://techdocs.f5.com/en-us/bigiq-7-1-0/integrating-third-party-certificate-management/integrating-le-with-big-iq-for-cert-management.html
