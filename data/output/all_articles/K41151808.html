Known Issue

Inconsistencies exist in Gx usage reporting when the BIG-IP PEM policy contains multiple rules that use the same monitoring key and filter categories.

This issue occurs when all of the following conditions are met:

  • While processing traffic on the BIG-IP PEM system, the system associates a subscriber session with the following policies:
    • At least one PEM policy with multiple rules that contain the same usage monitoring key as the Application ID or URL categorization.
    • At least two PEM policies that contain one or more policy rules with the same monitoring key across the policies.

Impact

The system cannot generate correct usage records or correctly report traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When multiple rules contain the same usage monitoring key as the Application ID or URL, the categorization filter creates duplicate usage records.
  • When two or more BIG-IP PEM policies contain one or more policy rules with the same monitoring key across the policies, the system does not produce the expected usage records.
  • You may see inconsistencies in how the system reports usage.

Workaround

This issue has no workaround. However, you can avoid this issue by not using multiple policy rules with the same monitoring key as the Application ID or URL Categorization filters. Additionally, make sure that the usage reporting criteria does not use the same monitoring key across multiple policies for the same subscriber.
