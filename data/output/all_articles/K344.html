Beginning with 3-DNS Controller version 2.1, the protocol used for iQuery data can be configured as TCP or UDP.

You can specify the default protocol for iQuery traffic, and specify the protocol used by the BIG-IP and 3-DNS systems for iQuery traffic by performing the following procedures:

Specifying the default protocol for iQuery traffic

  1. Log in to the Configuration utility.

  2. Click System.

  3. Select the desired iQuery Protocol from the iQuery Protocol drop-down menu.

  4. Click Update.

Specifying the protocol used by a specific BIG-IP system for iQuery traffic

  1. Log in to the Configuration utility.

  2. Expand the Servers menu tree.

  3. Click BIG-IP.

    The BIG-IP List is displayed.

  4. Select the desired BIG-IP that you want to specify for iQuery traffic.

  5. Select the desired iQuery Protocol from such as the iQuery Protocol drop-down menu.

  6. Click Update.

Specifying the protocol used by a specific 3-DNS for iQuery traffic

  1. Log in to the Configuration utility.

  2. Expand the Servers menu tree.

  3. Click 3-DNS.

    The 3-DNS List is displayed.

  4. Select the desired 3-DNS that you want to specify for iQuery traffic.

  5. Select the desired iQuery Protocol from the iQuery Protocol drop-down menu.

  6. Click Update.
