K59122324: Venafi certificates won't import

Type
Support Solution
Published
2024-04-03
Updated
2025-06-30
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K59122324

Description

Importing SSL certificates from a third-party CA provider (Venafi) into BIG-IQ fails, particularly when managing certificates across multiple BIG-IP devices.


Environment

  • BIG-IQ integrated with Venafi Trust Protection Platform (TPP)
  • BIG-IP devices already discovered by BIG-IQ
  • Certificates managed via Venafi and/or BIG-IQ

Cause

  • BIG-IQ is designed to manage certificates only for BIG-IP devices it has discovered.
  • Structural changes in Venafi policy folders after BIG-IQ configuration can cause mismatches.
  • Manual actions in Venafi (e.g., auto-renewal, direct deployment to BIG-IP) bypasses BIG-IQ and break synchronization.
  • Reimporting certificates without cleanup can create duplicate or invalid entries in BIG-IQ.

Recommended Actions

  1. Use BIG-IQ Exclusively:
    Perform all certificate creation, deployment, and renewal actions through BIG-IQ. Avoid direct imports from Venafi to BIG-IP.
  2. Maintain Policy Folder Integrity:
    Ensure no structural changes are made to Venafi policy folders after BIG-IQ configuration. If changes occur, update both TPP and BIG-IQ configurations accordingly.
  3. Avoid Manual Actions in Venafi:
    Do not enable auto-renewal or perform manual deployments in TPP. 
  4. Reimport with Cleanup:
    If incorrect or duplicate certificates exist, delete them from BIG-IQ. Then reimport certificates directly from BIG-IP and perform a full sync.
  5. Understand Sync Behavior:
    BIG-IQ pulls certificates marked as "missing" using metadata (name, policy folder, checksum, UUID). Only certificates from valid, configured policy folders are considered.
  6. Respect BIG-IQ as Source of Truth:
    Once BIG-IQ is configured, it becomes the authoritative manager for BIG-IP certificates. Do not restart Venafi services that BIG-IQ has disabled.

Additional Information

  • Certificates created on BIG-IQ using Venafi and deployed to BIG-IP can be kept in sync across BIG-IQ, BIG-IP, and Venafi.
  • If Venafi pushes a certificate directly to BIG-IP, users must manually reimport it into BIG-IQ to maintain synchronization.
  • Improper reimporting can lead to broken imports and incorrect entries in BIG-IQ.
