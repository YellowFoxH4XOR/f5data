Known Issue

This is the result of a known issue. After upgrading or installing new BIG-IP software, the SCCP init level may remain set to boot the BIG-IP system from a remote PXE server. You can resolve this issue by performing the following procedure:
  1. Interrupt the netboot cycle and enter the SCCP command menu, by simultaneously pressing the (Esc+Shift+9) keys.
  2. From the SCCP menu, select option 2 --- Select Host subsystem boot mode: boot from local drive.
  3. From the SCCP menu, select option 7 --- Reset Host subsystem (issues hardware reset--USE WITH CARE!).
  4. When prompted, type Y to confirm that you want to reset the host subsystem.
  5. From the SCCP menu, select option 1 --- Connect to Host subsystem console.

    The host system should boot from its hard drive.

Note: You must hard reset the host subsystem. Option 5 from the SCCP menu will not work in this situation because the Host subsystem is not up. Therefore, the SCCP cannot use SSH to send the reboot command to the host.
