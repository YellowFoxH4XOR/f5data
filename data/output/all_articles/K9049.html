Known Issue

This is the result of a known issue. Interface settings are removed from the /config/bigip_base.conf file after running the bigpipe load command. This issue can occur if you manually edit the /config/bigip.conf file, resulting in a syntax error, and subsequently attempt to load the configuration by using the bigpipe load command.

For example, this issue will occur if you manually edit the /config/bigip.conf file and add a route with a gateway that is not on a directly connected network. In addition to removing the interface settings from the /config/bigip_base.conf file, the BIG-IP system will generate a BIGpipe route modification error message.

F5 Networks Product Development is tracking this issue as CR104694.

Workaround

You can work around this issue by using the Configuration utility or bigpipe shell to modify the BIG-IP configuration.
