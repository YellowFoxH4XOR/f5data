K000162985: Receiving "Directory listing JSON does not contain required URLs" error log when integrating ACME with Classic BIG-IP

Type
Support Solution
Published
2026-08-24
Updated
2026-09-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 21.1.X, 21.1.0
Source
https://my.f5.com/manage/s/article/K000162985

Description

BIG-IP rejects activation of an ACME account. Getting errors about 'Directory listing JSON does not contain required URLs'.

Environment

  • BIG-IP
  • Version 21.x
  • ACME Provider List configured

Cause

The desire CA ACME directory do not provide all endpoint URLs required by the BIG-IP ACME integration. Consequently, BIG-IP keymgmtd considers the directory listing invalid and prevents account activation.

Answer/Recommended Actions

According to RFC8555, the response should contain below fields:

+------------+--------------------+
| Field      | URL in Value       |
+------------+--------------------+
| newNonce   | New nonce          |
|            |                    |
| newAccount | New account        |
|            |                    |
| newOrder   | New order          |
|            |                    |
| newAuthz   | New authorization  |
|            |                    |
| revokeCert | Revoke certificate |
|            |                    |
| keyChange  | Key change         |
+------------+--------------------+

If ACME integration fails with visible log entries 'Directory listing JSON does not contain required URLs' in /var/log/ltm, execute curl from BIG-IP towards the configured directory-url and confirm that all of above fields provides a value.

Example curl:

curl https://acme-v14.CA-14133741/directory
