Known Issue

This is the result of a known issue. Using the Enterprise Manager device properties screen, you can open the Configuration utility for the selected device in a new browser window by clicking the Launch link. When you use the Enterprise Manager device properties screen to launch the BIG-IP ASM Configuration utility, and then navigate to Application Security > Web Applications, the following error message is displayed by the ASM Configuration utility:

Session is missing!
BIG-IP(r) Application Security Manager

F5 Product Development tracked this issue as CR99110 and it was fixed in BIG-IP 9.4.5. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in Hotfix BIGIP-9.4.4-94.0-HF3 issued for BIG-IP 9.4.4. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about how to manage F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.

Workaround

To work around this issue, do not use the Enterprise Manager to launch the BIG-IP ASM Configuration utility. Instead, navigate directly to the BIG-IP ASM Configuration utility.
