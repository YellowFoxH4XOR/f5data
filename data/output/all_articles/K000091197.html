K000091197: Configuring HA with multiple VRRP instances fails on NGINX Controller

Type
Support Solution
Published
2022-01-10
Updated
2022-01-19
Source
https://my.f5.com/manage/s/article/K000091197

Description

  • You have a pair of NGINX+ instances configured.
  • You want to set up High Availability(HA) with multiple vrrp_instance between the NGINX+ instances
  • However, when setting the HA pairing on the NGINX Controller, you encounter the following error:

"keepalived configuration file does not contain or contains more than a pair of markers: /etc/keepalived/keepalived.conf"

 Environment

  • Keepalived
  • VRRP instances
  • NGINX+
  • NGINX Controller
  • API Gateway

 Cause

  • By design

 Recommended Actions

  • None

 Additional Information

  • Only one pair of markers is currently supported, where a pair of markers NGINX_CONTROLLER_HA_BEGIN and NGINX_CONTROLLER_HA_END must be added to the keepalived virtual_ipaddress configuration section.
