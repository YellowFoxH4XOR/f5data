Known Issue

The BIG-IP Edge Client may fail to install on Windows 8.1.

This issue occurs when all of the following conditions are met:

  • You previously installed the BIG-IP Edge Client on a Windows 8.1 system.
  • You then uninstall the BIG-IP Edge Client components and attempt to re-install the BIG-IP Edge Client.

Impact

The Virtual Private Network (VPN) adapter component is not properly removed during the uninstall process, causing the re-installation of the BIG-IP Edge Client to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Re-installing the BIG-IP Edge Client fails on Windows 8.1 systems.
  • The Windows client system displays one of the following error messages on a blue screen:

    driver_irql_not_less_or_equal

    kernel_security_check_failure

  • A Windows core (DMP) file is generated on the client system.

Workaround

While there is no workaround for this issue, you should be able to upgrade the installed BIG-IP Edge Client components rather than removing them first and re-installing. Otherwise, you may be able manually remove the VPN adapter component before attempting to re-install the BIG-IP Edge Client. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Windows 8.1 client system.
  2. Navigate to Device Manager in the Control Panel.
  3. Ensure that Show hidden devices is enabled in the View menu.
  4. Expand Network adapters.
  5. Right-click F5 Networks VPN Adapter, and select Uninstall.
  6. In the next window, select the Delete the driver software for this device check box, and click OK.
  7. Attempt to re-install the BIG-IP Edge Client again.
