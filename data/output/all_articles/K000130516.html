Description

You want to change the Admin password for NGINX Instance Manager or NGINX Management Suite.

Environment

  • NGINX Instance Manager
  • NGINX Management Suite
  • Password file creation utility such as apache2-utils (Debian, Ubuntu) or httpd-tools (RHEL/CentOS/Oracle Linux).

Recommended Actions

  1. Enter the following command:

    # htpasswd -c /etc/nms/nginx/.htpasswd admin

  2. Follow the output to input the new password as below:

    New password:

    Re-type new password:

    Note: The system displays the following result message:

    Adding password for user admin
