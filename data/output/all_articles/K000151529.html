Description

When configuring SSL cipher groups on BIG-IP LTM, there may be a requirement to create a strong cipher group for TLS 1.3 that excludes CHACHA and POLY ciphers, and disables Diffie-Hellman (DH) groups with key sizes above 2048 bits. This is often necessary to comply with security policies or to mitigate risks identified in security assessments.

Environment

  • BIG-IP LTM
  • SSL Cipher Group

Cause

The default cipher group configuration may include ciphers or DH groups (such as FFDHE2048) that are not compliant with certain security requirements. Additionally, some ciphers like CHACHA and POLY may be included by default in TLS 1.3 cipher suites, which may need to be excluded for compliance or performance reasons.

Recommended Actions

To disable specific DH groups (e.g., FFDHE2048), create a cipher rule that targets the unwanted group and add it to the Exclude list in your cipher group configuration.

  1.  Navigate to Local Traffic  ››  Ciphers : Rules  ››  New Cipher Rule... 
    Set the name of your custom rule. In DH Groups box, type e.g. FFDHE2048. You should be able to see output like below:
     
    The following cipher suites, DH groups and signature algorithms match:
    Cipher Suites
    DH Groups
    FFDHE2048
    Signature Algorithms
  2. Save the changes using finish button.

Now, use the created rule in your custom Cipher Group: Local Traffic  ››  Ciphers : Groups  ››  New Cipher Group

  1. In New Cipher Group tab, find your custom rule under the Available Rules window and select it.
  2. Under Exclude the following from the Allowed List use left arrows (<<) to add your rule to the specific selection to exclude e.g. FFDHE2048 group.
  3. Save the changes using Finish button.
