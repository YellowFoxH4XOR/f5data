Description

You started using our F5 XC API Discovery feature and started seeing the the column "Sensitive Data" is populated with terms like "credit-card" for example

Environment

  • HTTP Load Balancer
  • API Discovery 

Answer

API endpoints are discovered by Console using AI/ML and are based on traffic to them. For example, for an HTTP 200 response code, the credit card number is required, but probably was not supplied. It can be verified if you click on the endpoint and check the "Discovered" tab. Here is an example:
