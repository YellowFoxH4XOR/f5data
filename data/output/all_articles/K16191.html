Known Issue

If you delete an AAA server profile, the system may not remove all related configuration objects.

This issue occurs when the following condition is met:

  • You use the BIG-IP APM Configuration utility to delete a previously configured OAM AAA server profile.

Impact

The system does not delete some OAM profile-related configuration objects.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you delete an OAM AAA profile, the Configuration utility no longer displays the profile.
  • When you view configuration objects from the command line in /config/aaa/oam/<partition>, the deleted OAM AAA profile objects directory is still present.

Workaround

To work around this issue, you can manually delete the remaining objects at the command line. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected system.
  2. Change directories to the AAA configuration directory by using the following command syntax:

    cd /config/aaa/oam/<partition_name>/

    For example:

    cd /config/aaa/oam/Common/

  3. To remove the residue AAA OAM configuration objects, use the following command syntax:

    Important: The rm -rf command runs a recursive deletion. Ensure that you have the proper directory and profile name before running this command.

    rm -rf ./<name of deleted OAM profile>

    For example:

    rm -rf ./oam_server2
