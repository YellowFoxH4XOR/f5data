Description

Limiting the number of connections to a Virtual Server
For example:  How to limit the number of connections to a Virtual Server for any Source IP address

Environment

  • Virtual Server
  • Limiting connections

Cause

There are several different ways to limit the number of connections to a Virtual Server:

Limit modeDefinition
Per virtual serverApplies rate limiting only to this virtual server
Per virtual server and source addressApplies rate limiting to this virtual server and source IP using the netmask provided - connections are rate limited if they share the same subnet
Per virtual server and destination addressApplies rate limiting to this virtual server and destination IP using the netmask provided - connections are rate limited if they share the same subnet
Per virtual server, destination, and source addressApplies rate limiting to this virtual server, source and destination IP using the netmask provided - connections are rate limited if they share the same subnets
Per source address (all rate limiting virtual servers)Applies rate limiting across all virtual servers, based on source IP, using the netmask provided - connections are rate limited if they share the same subnet
Per destination address (all rate limiting virtual servers)Applies rate limiting across all virtual servers, based on destination IP, using the netmask provided - connections are rate limited if they share the same subnet
Per source and destination address (all rate limiting virtual servers)Applies rate limiting across all virtual servers, based on source and destination IP, using the netmask provided - connections are rate limited if they share the same subnet

Recommended Actions

Setting a connection limit for a virtual server is done in the virtual server's configuration:

  1. Go to Local Traffic > Virtual Servers
  2. Click on the desired virtual server
  3. Set Configuration = Advanced
  4. Select the desired Connection Rate Limit Mode
  5. Specify the Connection Rate Limit
  6. If visible, specify the Connection Rate Limit Source/Destination Mask(s)

    Note: The source/destination mask applies the rate limit to connections sharing the same subnet. For example, if the Connection Rate Limit Source Mask is set to 24, the connection rate limit is applied to IP addresses with source mask of /24. The mask specifies the number of bits in the IP address to use as a limit key.

  7. Click Finished

Additional Information

Configuring a connection limit or a connection rate limit for a virtual server prevents an excessive number of connection requests during events such as a Denial of Service (DoS) attack or a planned, high-demand traffic event.
