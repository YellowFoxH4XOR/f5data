Mysql process CPU usage went  from 0% to 55% and down to  27.4% within 8 seconds.
This corresponds with CPU spike to 100%.

Environment

  • Application Visibility and Reporting (AVR) enabled.

Cause

K15606: The BIG-IP system now aggregates all statistics every five minutes and includes old statistics

Recommended Actions

This should not affect the performance of Traffic Management Microkernel (TMM) data plane tasks because the AVR-related processes are non-TMM control plane tasks that use separate logical cores and are throttled down when TMM needs the resources.

Additional Information

For more information about separate logical cores, refer to K15003: Data plane and control plane tasks use separate logical cores when the BIG-IP system CPU uses Hyper-Threading Technology.
