Topic

The BIG-IQ system supports multiple public cloud providers and occasionally you may be required to customize the support of a new BIG-IP Virtual Edition (VE) image version or a different instance type. This article provides a list of how-to articles about performing the supported customization on the BIG-IQ system.

Description

To add a new Azure image version, refer to one of the following articles:

  • K80916682: Adding support for a newly published Azure BIG-IP VE image version on the BIG-IQ system
  • K34843143: Adding support for a newly published Azure BIG-IP VE image version on the BIG-IQ system (7.1.0)
  • K00830239: Adding support for a newly published Azure BIG-IP VE image version on the BIG-IQ system (6.1.0 - 7.0.0)
  
To add a different instance type for the Azure or AWS cloud environment, refer to one of the following articles:
  • K72548107: Adding a new instance type for the AWS or Azure cloud environment on the BIG-IQ system
  • K97233143: Adding a new instance type for the AWS or Azure cloud environment on the BIG-IQ system (7.1.0)
  • K13321252: Adding a new instance type for the AWS or Azure cloud environment on the BIG-IQ system (6.1.0 - 7.0.0)
