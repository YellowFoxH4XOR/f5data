Topic

When you enable or disable bundling for a 40 Gigabit Ethernet (GbE) interface, the BIG-IP system restarts the bcm56xxd process to reconfigure the onboard switch. This behavior causes a brief traffic disruption or a failover event if configured for high availability (HA).

Description

The following BIG-IP platforms contain 40GbE interfaces, which can be configured as a single-bundled 40 gigabit interface or four individual 10 gigabit interfaces:

  • B2250 blade installed in a VIPRION 2200 or 2400 chassis
  • B4300 blade installed in a VIPRION 4400 or 4800 chassis
  • BIG-IP 10000 series platforms
  • BIG-IP 12000 series platforms

When transitioning between 10 gigabit standalone and 40 gigabit bundled interfaces, you must restart the bcm56xxd switch daemon to allow reconfiguration of the onboard switch.

Important: Restarting the bcm56xxd daemon will interrupt traffic across all interfaces, and in the case of an HA pair, will result in a failover if the current system is active.

When changing the bundle status using the interface panel in the Configuration utility, the BIG-IP system logs the following message:

Modify Interface Bundle state will interrupt traffic.  Do you want to continue?

When changing the Interface Bundle status from the interface details panel, the BIG-IP system logs the following message:

Changing this setting will impact traffic after you click "Update".

After accepting the change, the BIG-IP system logs messages in the /var/log/ltm file indicating the bcm56xxd process restarted in order to configure the change.

For example:

info bcm56xxd[30423]: 012c0012:6: Scheduling a delayed bcm56xxd daemon restart in 5 sec
emerg bcm56xxd[30423]: 012c0001:0: Restarting bcm56xxd to setup new bundling configuration.
warning sod[8816]: 01140029:4: HA proc_running bcm56xxd fails action is go offline and down links.
err bcm56xxd[22734]: 012c0011:3: action Redirect Trunk failed: SDK error Invalid port

For more information about configuring bundling for a 40GbE interface, refer to the platform guide for your platform.
