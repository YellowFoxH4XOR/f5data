Known Issue

Performing software upgrades, configuration loads, or configuration synchronization (ConfigSync) operations may fail for systems with large configurations.

This issue occurs when the following conditions are met:

  • The configuration is large (for example over 15 MB).
  • The configuration contains large configuration objects (for example, objects over 256K in size).

Impact

Software upgrades, configuration loads, or ConfigSync operations may fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Attempting to load a large configuration with large objects results in the system generating an error message that appears similar to the following example:

    err mcpd[7366]: 01070710:3: Database error (52), Can't write blob data, attribute:implementation status:52 - EdbBlobData.cpp, line 57

  • Attempting to perform a ConfigSync operation results in error messages that appear similar to the following examples:

    err mcpd[8210]: 01071693:3: Incremental sync: Caught an exception while adding a transaction to the incremental config sync cache: unexpected exception.
    err mcpd[8210]: 01070734:3: Configuration error: MCPProcessor::processRequestNow: Can't write blob data, attribute:msgs status:52
    err mcpd[8210]: 01070596:3: An unexpected failure has occurred, request_group destroyed while processing, exiting...

  • The mcpd process produces a core file.

Workaround

To work around this issue, you can reduce the size of the larger configuration objects.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
