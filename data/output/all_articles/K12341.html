Known Issue

This is the result of a known issue. In BIG-IP ASM version 10.2.0, the system evaluates connection data against attack signatures that are disabled in the Configuration utility. This issue affects only the matching logic applied internally, resulting in inefficient use of system resources. Disabled signatures that are still evaluated by the BIG-IP ASM system do not incorrectly cause violations.

F5 Product Development tracked this issue as ID 338671 and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
