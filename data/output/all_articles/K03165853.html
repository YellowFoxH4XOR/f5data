K03165853: Additional icon on the Windows ''Network sign-in'' logon screen Windows Logon Integration

Type
Support Solution
Published
2022-02-28
Updated
2023-08-01
Applies to
  • Virtual Editions
Source
https://my.f5.com/manage/s/article/K03165853

Description

After deploying APM Client with Windows Logon Integration, WLI using:

K40131499: Configuring Dialup Entry/Windows Logon Integration

You may experience double icons in the lower left corner with the same label as configured in the Phonebook Entry Name while deploying the BIG-IP Edge Client package for Windows as follows:

Environment

  • BIG-IP APM Edge Client with Windows Logon Integration option

Cause

Issue is caused by known issue ID750648.

Recommended Actions

Modify registry on affected Windows Client Machine:

  1. Inspect windows registry under:
    HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Authentication\PLAP Providers
     
  2. You should see two providers:

    HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Authentication\PLAP Providers
     F5 Networks Credential Provider CLID
     RasProvider CLID

    Note: Those two WLI providers CLID are located under PLAP providers (Pre-Logon Access Provider)
     
  3. Under "RasProvider" create DWORD:
    "Disabled"=dword:00000001
     
  4. Restart Windows.
