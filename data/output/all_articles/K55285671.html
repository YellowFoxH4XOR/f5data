Known Issue

The Border Gateway Protocol (BGP) may advertise the wrong nexthop floating self IP address.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in a high availability (HA) configuration.
  • Your HA configuration involves multiple active traffic groups. This is also known as an active-active configuration.
  • Your BIG-IP systems have BGP dynamic routing enabled.

Impact

Traffic for advertised routes may fail if sent to a standby device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The local BIG-IP system advertises a nexthop address using the peer system's active floating self IP address.
  • Traffic for BGP advertised routes fails and is sent by peer routers to a standby device.

Workaround

To work around this issue, you can use the IMI shell (imish) to configure a route-map that sets the nexthop to the floating self-IP address of a traffic group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Advanced Shell (bash) of the BIG-IP system that is active for a traffic group.
  2. Start the imish utility by typing the following command:

    imish

  3. Enter privileged mode by typing the following command:

    enable

  4. Enter terminal configuration mode by typing the following command:

    configure terminal

  5. Enter router mode using the following command syntax:

    router bgp <ASN>

    For example, to enter router mode using ASN (Autonomous System Number) 10, type the following command:

    router bgp 10

  6. Create a route-map using the following command syntax:

    route-map <name> permit <serial_no.>

    For example, to create a route-map named NEXTHOP with serial number 10, type the following command:

    route-map NEXTHOP permit 10

  7. Set the nexthop to the floating self-IP address of the active system using the following command syntax:

    set ip next-hop <floating_self-IP> primary

    For example, to set the nexthop to the active system's floating self-IP address 192.168.10.10, type the following command:

    set ip next-hop 192.168.10.10 primary

  8. Exit router mode and save the running configuration by typing the following commands:

    end

    copy running-config startup-config

  9. Exit the imish utility by typing the following command:

    exit
