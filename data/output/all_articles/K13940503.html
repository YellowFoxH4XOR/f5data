Description

After upgrade, the BIG-IP fails to load the configuration.

It displays the error message in /var/log/ltm

load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. -- Loading schema version: 11.5.0 Loading schema version: 11.6.3 01071769:3: Decryption of the field (passphrase) for object (/Common/<SSL_Profile_Name>) failed. Unexpected Error: Loading configuration process failed.
01070425:3: Full configuration load failed.

Take note of the (/Common/<SSL_Profile_Name>).

Environment

  • BIG-IP LTM
  • Upgrade Software to v11.6 or newer

Cause

Unable to load the configuration because some profiles contain passphrase.

Recommended Actions

  1. Roll back to the previous boot location.
  2. Login to BIG-IP with command line session.
  3. Edit the BIG-IP configuration (you can use vi, nano, etc ...)
    Note: In this scenario, using nano editor
    # nano /config/bigip.conf
  4. Go to the object mentioned in the /var/log/ltm (/Common/<SSL_Profile_Name>), then insert # in front of the passphrase as the example below.
    # passphrase ***scrubbed***
  5. Save the configuration.
  6. Proceed to upgrade.
