Description

When the avrd process (used by BIG-IP Analytics module) is initialized after an upgrade and reboot, or after applying an Analytics profile, it communicates with mcpd to process BIG-IP configuration details to set up performance data collection. If the BIG-IP system contains a large configuration with several thousand objects, this will lead to avrd consuming 100 percent CPU for up to 30 minutes. The impact of the high CPU utilization can lead to numerous symptoms, one of which is the BIG-IP Configuration utility (informally referred to as the GUI) becomes unavailable or it only partially loads.

Environment

  • BIG-IP 11.6.x and later.
  • The BIG-IP Analytics (AVR) module is provisioned.
  • Several thousand configuration objects.
  • A BIG-IP system upgrade or enabling Analytics

Cause

The issue described in this article is caused by Bug ID 857381.

Recommended Actions

After upgrading or applying Analytics profiles, plan for up to 30 minutes of high CPU utilization on the BIG-IP system. The CPU should return to normal after avrd completes processing the configuration. If the issue persists for longer, contact F5 Support.
