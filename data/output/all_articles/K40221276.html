Description

LDAP authentication to login to BIG-IP stopped working after upgrading to BIG-IP v14.1.x

  • LDAP authentication which was working fine in previous versions, stops working after upgrading to BIG-IP v14.1.x
  • Even when entering the correct credentials, the user is unable to login to BIG-IP Web UI.
  • It always keeps saying incorrect password.

Environment

Relevant environmental factors specific to the topic

  • Recently upgraded to BIG-IP v14.1.x
  • Using LDAP authentication to login to BIG-IP

Cause

There can be multiple causes for this to happen because the LDAP authentication has been revamped from version BIG-IP v14.1.x.
Most common are:

  1. AD Referrals causing authentication to fail.
  2. Listing format of LDAP servers is incorrect.

Recommended Actions

  1. In versions 14.1.2.3 and later, you can disable AD Referrals by executing the following commands:

    tmsh modify sys db systemauth.referrals value no
    tmsh save sys config
    tmsh load sys config

  2. Fix the listing format of AD/LDAP servers.

The old format would be (comma separated).
AD-server1, AD-server2, AD-server3

The new format should be (space separated).
AD-server1 AD-server2 AD-server3
