Description

Cannot upgrade rSeries system from F5OS-A v1.3.2 to later version, such as v1.7.0.

When attempting to initiate upgrade, system returns:

System database upgrade compatibility check failed

Furthermore, the /var/log/sw-util.log file contains entries similar to the following:

upgrade_vers_1.7.0-8741 | CDB: Upgrade failed: Upgrade transaction failed to validate: /oc-sys:system/aaa/authentication/f5-aaa-ldap:ldap/ssl (value "start_tls"): ssl cannot be start-tls with server type ldaps
upgrade_vers_1.7.0-8741 | confd_load: 337: maapi_start_trans() failed: operation in wrong state (17): Can't start read-write transaction before phase1
upgrade_vers_1.7.0-8741 | "CDB: Upgrade failed: Upgrade transaction failed to validate: /oc-sys:system/aaa/authentication/f5-aaa-ldap:ldap/ssl (value \"start_tls\"): ssl cannot be start-tls with server type ldaps\n"
upgrade_vers_1.7.0-8741 | =ERROR REPORT==== 15-Feb-2024::20:46:22.192158 ===
upgrade_vers_1.7.0-8741 | init:boot_msg: "CDB: Upgrade failed: Upgrade transaction failed to validate: /oc-sys:system/aaa/authentication/f5-aaa-ldap:ldap/ssl (value \"start_tls\"): ssl cannot be start-tls with server type ldaps\n"
upgrade_vers_1.7.0-8741 | connection refused (start_phase2)
upgrade_vers_1.7.0-8741 | connection refused (wait_started)
upgrade_vers_1.7.0-8741 | connection refused (stop)
upgrade_vers_1.7.0-8741 | Upgrade Check failed
upgrade_vers_1.7.0-8741 | 2024-02-15T20:46:33.951479+00:00 System Manager Upgrade Check 1.7.0-8741 Exited
upgrade_vers_1.7.0-8741 exited with code 1

Note in particular this entry:

ssl cannot be start-tls with server type ldap

Environment

  • rSeries
  • Upgrade attempt

Cause

This is happening as a result of the fix for bug ID 1137341.

LDAP is configured to use start_tls:

system aaa authentication ldap ssl start_tls

However, there is no LDAP server group configured (system aaa server-groups), or an LDAP server group of type LDAPS is configured.

Recommended Actions

To prevent this issue, you must either turn off SSL in the LDAP configuration, or configure an LDAP server group (without LDAPs, i.e. plain LDAP).

For example:

system aaa authentication ldap ssl off

Or:

system aaa server-groups server-group test-ldap
 config name test-ldap
 config type LDAP
 servers server 10.10.10.1
 config address 10.10.10.1
 ldap config auth-port 389
 ldap config type ldap
 !
!

Additional Information

The System database upgrade compatibility check failed message has numerous possible root causes. If your system does not have LDAP configured with start_tls, it is not affected by this issue and further investigation may be required.
