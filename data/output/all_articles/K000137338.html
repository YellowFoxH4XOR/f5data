Description

The big3d_install script is an interactive script that allows you to install the current version of the big3d process on remote F5 systems.
If the target system is running a newer version of big3d agent (even from a previous major release), the installation will be skipped. 

For example:
BIG-IP DNS is running 16.1.3.4, BIG-IP LTM is running 15.1.9.1 
If you run big3d_install from BIG-IP DNS 16.1.3.4, the script will skip installation as 15.1.9.1 is newer than 16.1.3.4.

Please refer to K33062581: Software Release Date Information
16.1.3.4 released on 03/28/2023
15.1.9.1 released on 07/17/2023

Environment

  • BIG-IP DNS
  • big3d_install

Cause

This is expected behaviour. 

Recommended Actions

Install the big3d agent from the BIG-IP DNS system that is running the latest software version
