Description

When, in TMUI, attempting to upload SSL certificates under "System » Certficate Management : Traffic Certificate Management : SSL Certificate List » Import SSL Certificates and Keys" fails, displaying a webpage error similar to the one below, during the import process:

It looks like the webpage at https://<device-IP/URL>/tmui/Control/form?_handler=/tmui/locallb/ssl_certificate/import&_source=finished&_linked=false&_fromError=false might be having issues, or it may have moved permanently to a new web address.

Environment

  • SSL Certificate

Cause

This error message may appear when an external application and/or device is blocking the upload of the SSL certificate to the BIG-IP.

Recommended Actions

Check for any applications/devices (such as any DLP features on security software on client devices or firewalls) that may be blocking the certificates from being uploaded and make sure it is allowed.
