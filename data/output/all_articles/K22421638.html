Description

  • Network Access is configured with full tunnel, but remote clients can still access network resource (e.g. printer) on their local LAN.

Environment

  • BIG-IP APM
  • Network Access resource configured with
    Supported IP Version: IPV4
    Traffic Options: Force all traffic through tunnel
    Allow Local Subnet: Unchecked (Disabled)
  • Client has IPv6 stack enabled
  • Local network device (e.g. printer) has IPv6 stack enabled

Cause

Remote client is using IPv6 to communicate with IPv6 capable devices on his local network. Only IPv4 traffic is forced to go via the Network Access tunnel.

Recommended Actions

  • Configure Network Access resource to have "Supported IP Version" set to "IPV4 & IPV6" and configure IPV6 Lease Pool.
