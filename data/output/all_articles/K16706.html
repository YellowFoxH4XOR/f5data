Known Issue

A standby BIG-IP LTM system may send an Open Shortest Path First (OSPF) summary link-state advertisement (LSA) with the same metric value as the active BIG-IP LTM system.

This issue occurs when the following condition is met:

  • A high-availability pair of BIG-IP systems is configured in an OSPF stub area with Designated Router (DR) and Backup Designated Router (BDR) OSPF routers.

Impact

Traffic from DR or BDR nodes in the stub area may be sent to the standby BIG-IP LTM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The standby BIG-IP LTM system sends summary LSAs for a default route into a stub area, with a metric value of 1 instead of the expected value of 65535.
  • DR and BDR OSPF routers, in the stub area, learn both active and standby BIG-IP LTM systems as default routes with the same metric, and send traffic to both devices.
