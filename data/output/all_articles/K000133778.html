Description

You deleted the old epsec packages manually by using WinSCP or you went to the /config/filestore/files_d/Common_d/epsec_package_d directory and deleted the files using the rm command


Environment

  • BIG-IP
  • EPSEC Packages

Cause

The bigip.conf file will have reference to the locations but since the change was not done via the GUI nor TMSH, the bigip.conf file will not be updated and the epsec packages will still appear in the GUI even if they are no longer present in the directory.


Recommended Actions

Option A:


1. Copy the iso file to the epsec package directory (/config/filestore/files_d/Common_d/epsec_package_d) and make sure to rename them using the file name referenced in the bigip.conf file (ie :Common:epsec-1.0.0-570.0.iso_50148_1)

# cd /config/filestore/files_d/Common_d/epsec_package_d

# mv epsec-1.0.0-570.0.iso :Common:epsec-1.0.0-570.0.iso_50148_1


2. Once the files have been copied over, delete the epsec packages again via the GUI by going to System >> Software Management >> Antivirus Check Updates >> Click the Epsec Package >> Press Delete



Option B:


1. Create a "dummy" epsec pakage by using the touch command. File name should be the same as the deleted epsec package reference in the bigip.conf file


# touch :Common:epsec-1.0.0-570.0.iso_50148_1


2. Once the files have been copied over, delete the epsec packages again via the GUI by going to System >> Software Management >> Antivirus Check Updates >> Click the Epsec Package >> Press Delete
