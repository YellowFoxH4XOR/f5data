In this video, AskF5 shows you how to use the Configuration utility to create an iRule to display a maintenance page when the pool is down.

This demo uses BIG-IP 16.0.1

  • 00:00 Intro
  • 01:51 Associate the iRule with the virtual server

Syntax referenced in the video that you can copy and paste:

Syntax item 1

Note: The syntax used in the video replaces "<content>" with "Sorry, this page is not currently available." You can replace that message with your own message.

when HTTP_REQUEST {
if { [active_members [LB::server pool]] == 0 } {
HTTP::respond 200 content "＜content＞"
} }

Syntax item 2

Note: This is an example where you can replace "<content>" from Syntax item 1 with a formatted HTML response.

when HTTP_REQUEST {
if { [active_members [LB::server pool]] == 0 } {
HTTP::respond 200 content "
<html>
<head>
<title>Maintenance Page</title>
</head>
<body>
We are sorry, but the site you are looking for is temporarily out of service.
If you feel you have reached this page in error, please try again. </body>
</html>
"
}
}
