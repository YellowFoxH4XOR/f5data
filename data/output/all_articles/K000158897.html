K000158897: Unable to find configuration objects with grep for /config/bigip.conf file

Description

While trying to find some configuration with grep, for example:

cat /config/bigip.conf | grep <object_name>

you are not finding anything, even though that configuration objects are visible with GUI and with tmsh command outputs.

Environment

  • BIG-IP

  • Multiple partitions

Cause

Configuration for non-default partition are stored in different file than /config/bigip.conf, those are stored in /config/partitions/<partition_name>/bigip.conf

Recommended Actions

Instead of using grep only on /config/bigip.conf file, use below command:

grep -ir --include="bigip.conf" <object_name>

which will result in searching in bigip.conf files for all partitions.
