Known Issue

The BIG-IP APM system and FirePass controller currently do not support the Windows Group Policy action on Windows 8 client systems. If a Windows Group Policy action is configured, Windows 8 clients will always default to the fallback branch.

Impact

Users running Windows 8 will not receive group policy information.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The group policy action that is applied to the client system does not reflect the configured group policy.
  • Client systems may exhibit varying failures depending on the content of the group policy.

Workaround

To work around this issue, configure the BIG-IP APM access policies and FirePass pre-logon sequences that use the Windows Group Policy action to detect Windows 8 client systems and prevent the Windows Group Policy action from executing.

For more information about detecting Windows 8 in an access policy refer to, K13989: Detecting Windows 8 clients with the BIG-IP APM.

Impact of workaround: You cannot apply Group Polices to a Windows 8 client through the BIG-IP APM system. Also, the group policy action executes its fallback branch, causing the client to take the action of the downstream fallback branch.
