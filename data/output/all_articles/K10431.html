Known Issue

This is the result of a known issue. The BIG-IP GTM topology load-balancing behavior depends on the strict ordering of the topology records as listed in the /config/gtm/topology.inc file. The Configuration utility should display the records in the same order as they appear in the topology.inc file; however, the Configuration utility does not display topology records in the correct order.

Note: This issue is cosmetic, as the topology records are sorted correctly in the topology.inc file. However, this issue can cause confusion if you are troubleshooting a topology load-balancing issue and refer to the Topology screen in the Configuration utility to determine how the records are sorted.

F5 Product Development tracked this issue as ID 227275 (formerly CR84525), and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

If you are having issues with topology load-balancing, and are attempting to verify how the BIG-IP GTM system has sorted the topology records, view the records from the command line. For example, the following command displays the topology records as they appear in the /config/gtm/topology.inc file:

cat /config/gtm/topology.inc

Note: For more information about how BIG-IP GTM topology records are sorted, refer to K10721: Overview of the Longest Match algorithm (9.x - 10.x).
