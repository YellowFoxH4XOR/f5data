Description

Performed a software upgrade, then rolled back to the previous version.

Log rotation is no longer working, resulting in large log files, and the following appears in /var/log/messages daily:

notice logrotate: ALERT exited abnormally with [256]

Messages similar to the following are also seen in /var/log/auditd/audit.log:

avc: denied { search } for pid=24812 comm="logrotate" name="tomcat" dev=dm-2 ino=145641 scontext=system_u:system_r:logrotate_t:s0-s0:c0.c1023 tcontext=system_u:object_r:unlabeled_t:s0 tclass=dir

Environment

  • Downgraded to pre-14.1.0
  • Log rotation

Cause

Bug ID 878365: Logrotate may fail after downgrading to an older version

When this issue occurs, logrotate will also fail when invoked manually:

[root@ltm1:Active:In Sync] ~ # logrotate -f /etc/logrotate.conf
error: stat of /var/log/boot.log failed: Permission denied
error: stat of /var/log/platform_check failed: Permission denied
error: stat of /var/log/tomcat/catalina.out failed: Permission denied

Recommended Actions

Perform an automatic SELinux relabel operation:

touch /.autorelabel

reboot
