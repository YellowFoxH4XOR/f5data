Topic

FirePass provides several pre-defined sequence templates that you can use or modify to configure a pre-logon sequence. Pre-defined templates allow you to configure a pre-logon sequence quickly and easily for most common tasks.

The following procedure uses the AV and Firewall pre-logon sequence template to check for antivirus and firewall software on the client system prior to user logon:

Important: You must have an Anti-Virus/Firewall Inspector license on the FirePass controller to inspect the client system for antivirus and firewall software. If you do not have a license, contact your F5 Sales Representative to obtain one. 

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Users : Endpoint Security : Pre-Logon Sequence page.
  3. In the Create new sequence field, enter a name for the new pre-logon sequence.

    For example:

    AV and FW
     
  4. In the Based on menu, select template: AV and Firewall.
  5. Click the Create button.

    The pre-logon sequence you created appears in the Select Sequence to Use section.
  6. Next to the pre-logon sequence name, click the edit link.

    The Pre-Logon Sequence Editor appears.
  7. Click the Firewall check action.

    The Edit Action panel appears.
  8. In the Edit Action panel, click the Windows firewall checker link.

    The Endpoint Inspector Details screen opens.
  9. If you would like to change the default setting for the Enable Windows Firewall if other firewalls are not enabled option, configure the new settings and then click the Update button.

    If you do not want to change the default setting for the Enable Windows Firewall if other firewalls are not enabled option, click the Cancel button.
  10. In the Edit Action panel, click the Close Panel link in the top right corner.
  11. Click the Check for Antiviruses action.

    The Edit Action panel appears.
  12. Click the Windows antivirus checker link.

    The Endpoint Inspector Details screen opens.
  13. If you would like to change the default settings for the Windows antivirus checker, configure the settings you want to change and then click the Update button.

    Note: For more information about the configuration options on this screen, click the Help link in the top right corner of the page.

    If you do not want to change the default settings for the Windows antivirus checker, click the Cancel button.
     
  14. In the Edit Action panel, click the Close Panel link in the top right corner.
  15. Optionally, make additional changes or additions to the pre-logon sequence based on the requirements of your specific environment or security policy.
  16. When you are finished making changes to the pre-logon sequence, click the Back to console link in the top right corner.

    The Pre-Logon Sequence Editor closes and you are redirected to the Users : Endpoint Security : Pre-Logon Sequence page.
  17. In the Select Sequence to Use section, click the option button to the right of the pre-logon sequence you just created.
  18. Click the Apply button to activate the pre-logon sequence.
