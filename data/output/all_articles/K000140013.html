K000140013: Understanding Application Security Logging Profile Filter Logic

Type
Support Solution
Published
2024-06-26
Updated
2024-06-26
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000140013

Description

Configuring an Application Security Logging Profile and using the Advanced view of the Storage Filter section may result in unexpected requests being logged.  This is due to the default filter Logic Operation (OR) and the default value of the filter fields (All) appearing to be counterintuitive.

Environment

  • ASM Custom Security Log Profile applied

When using the Advanced view of the Storage filter section, if the Request Type field is set to any value other than “All Requests” and any of the other storage filter fields (Protocols, Response Status Codes, HTTP Methods, etc) are changed from their default value of “All”, you may see many legal requests being logged.

Cause

The default value of the Logic Operation is “OR”.  When the other Storage Filter fields are left to their default values of “All” the resulting configuration is, counterintuitively, that these fields are omitted.  Thus, the storage filter pseudo-logic is (for example):

if { request type is “Illegal Requests Only” } {

 log request

}

And only illegal requests are logged.

If the Storage Filter fields are changed to “Only” and any values are moved into the “Selected Items” column, the resulting configuration includes these fields with the selected values.  Thus, the storage filter pseudo-logic is:

if { request type is “Illegal Requests Only”

OR

protocol is anyof [“HTTP”, “HTTPS”]

OR

Response code is anyof [“200”, “301”, “302”] } {

 log request

}

 

And illegal requests are logged as well as any requests that used the HTTP or HTTPS protocol as well as any requests that resulted in a response code of 200, 301, or 302.

 

Recommended Actions

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  • Change the Protocols, Response Status Codes, or HTTP Methods of the utilized Security Log Profile to the default value "all" if you're using the Logic Operation: OR

When configuring an Application Security Logging profile do not define values for any of the Storage Filter fields other than Request Type unless you intend to include such requests in your logs.
