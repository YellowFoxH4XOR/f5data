K49507549: Configuring a secure password policy for the BIG-IQ system

Published
2021-05-25

Applies to

Topic

You should consider using this procedure under the following condition:

  • You want to implement a secure password policy for local users on the BIG-IQ system.

Description

You can configure a secure password policy when generating passwords for local user accounts. To do so, you must have an account assigned an administrator or resource administrator role; all other users can only view the policy. The secure password policy affects passwords for local user accounts only. Passwords for remotely stored user accounts are not subject to this local password policy, but may be subject to the remote authentication system’s password policy.

Configuration settings

The BIG-IQ web UI provides the following settings to configure the web UI secure password policy on the System > USER MANAGEMENT > Auth Providers > local page:

SettingDescription
Maximum Login AttemptsThis setting determines the number of times a user can enter the wrong username and password combination on the BIG-IQ web UI login page before the BIG-IQ system blocks the user account from its web UI for the configured time value of the Lockout Duration setting. The default setting is five attempts, and the range of acceptable values is 0 through 100 inclusive. This setting affects login to the web UI only; it does not affect login to the Advanced Shell (bash) or the TMOS Shell (tmsh).
Lockout DurationThis setting determines the amount of time in minutes the BIG-IQ system blocks a user account from logging in to the web UI after the Maximum Login Attempts configured value has been breached. The affected user account can only attempt to log in to the web UI after this amount of time. The default time is five minutes, and the range of acceptable values is 0 through 60 inclusive. This setting affects login to the web UI only; it does not affect login to bash or tmsh. Note that the TMOS secure password setting lockout-duration may have an impact on this web UI setting depending on the values set. The BIG-IQ system imposes a lockout for the affected user account to the web UI based on the longer time value between the two settings. For example, if the value for the lockout-duration setting is shorter than the value for the Lockout Duration setting, the BIG-IQ system imposes a lockout for the affected user account to the web UI based on the value for the Lockout Duration setting; If the value for the lockout-duration setting is longer than the value for the Lockout Duration setting, the BIG-IQ system imposes a lockout for the affected user account to the web UI based on the value for the lockout-duration setting. For more information about the lockout-duration setting, refer to the next table.

The underlying TMOS provides the following settings to configure the system secure password policy:

SettingDescription
expiration-warningThis setting determines the number of days before a password expires and the BIG-IQ system sends a warning message to the affected users. The default value is 7 and the range of acceptable values is 1 through 255 inclusive.
lockout-durationThis setting determines the amount of time in seconds that a locked user account must wait before logging in again, unless the account is manually unlocked. The default value is 0 (zero), meaning the locked user account must be manually unlocked by an administrator. The range of acceptable values is 0 through 999999 inclusive. This setting is available in BIG-IQ 8.0.0 and later. Prior to BIG-IQ 8.0.0, the default behavior requires an administrator to manually unlock the user account, and this behavior cannot be changed.
max-durationThis setting determines the maximum number of days a password is valid. The default value is 99999 and the range of acceptable values is 1 through 99999 inclusive.
max-login-failuresThis setting determines the number of consecutive unsuccessful login attempts that the system allows before locking the user account. All unsuccessful login attempts through the web UI, bash, and REST API are included in the failed login attempts count for this setting. The default value is 0, which indicates the setting is disabled. The range of acceptable values is 0 through 65535 inclusive. If the lockout-duration setting is set to its default value of 0 (zero), the locked user account requires an administrator to reinstate access. For more information about manually unlocking an affected local user account, refer to K44493725: Manually unlocking a local user account on the BIG-IQ system.
min-durationThis setting determines the minimum number of days a password is valid before allowing users to change their password. The default value is 0 and the range of acceptable values is 0 through 255 inclusive.
minimum-lengthThis setting determines the minimum number of characters required for a valid password. The default value is 6 and the range of acceptable values is 6 through 255 inclusive.
password-memoryThis setting determines the number of former passwords that the BIG-IQ system retains to prevent the user from reusing them. The default value is 0 and the range of acceptable values is 0 through 127 inclusive.
policy-enforcementThis setting determines the enforcement of password policy on the BIG-IQ system. The default value is disabled.
required-lowercaseThis setting determines the number of lowercase alpha characters that must be present in a password for the password to be valid. The default value is 0 and the range of acceptable values is 0 through 127 inclusive.
required-numericThis setting determines the number of numeric characters that must be present in a password for the password to be valid. The default value is 0 and the range of acceptable values is 0 through 127 inclusive.
required-specialThis setting determines the number of special characters that must be present in a password for the password to be valid. The default value is 0 and the range of acceptable values is 0 through 127 inclusive.
required-uppercaseThis setting determines the number of uppercase alpha characters that must be present in a password for the password to be valid. The default value is 0 and the range of acceptable values is 0 through 127 inclusive.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • If you are configuring the BIG-IQ web UI password policy settings, you have administrator role access to the BIG-IQ web UI.
  • If you are configuring the underlying TMOS secure password policy settings, you have administrator role or root user access to the BIG-IQ system's tmsh.

Procedures

  • Configuring the web UI password policy using the BIG-IQ web UI
  • Configuring the system secure password policy using tmsh

Configuring the web UI password policy using the BIG-IQ web UI

To use the BIG-IQ web UI to configure the web UI password policy for local user accounts, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ web UI.
  2. Go to System > USER MANAGEMENT > Auth Providers.
  3. Select local.
  4. Configure the Maximum Login Attempts and/or Lockout Duration settings according to your organization’s internal security requirements.
  5. To save the changes, select Save & Close.
  6. After enforcing the new changes to the web UI password policy, verify the changes using at least one of the affected user accounts, and ensure the system is appropriately enforcing the changes you made for your environment.

Configuring the system secure password policy using tmsh

To configure the system secure password policy for the local user accounts, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To enforce the required secure password policy according to your organization’s internal security requirements, you can modify the following authentication settings:
    • To enable or disable the password policy enforcement, use the following command syntax:

      modify /auth password-policy policy-enforcement <enabled | disabled>

      Note: This setting must be enabled for the BIG-IQ system to enforce the password minimum length and/or required characters.

    • To specify the minimum number of characters in a valid password, use the following command syntax:

      modify /auth password-policy minimum-length <value from 6 through 255 inclusive>

    • To specify the minimum number of lowercase characters for a valid password, use the following command syntax:

      modify /auth password-policy required-lowercase <value from 0 through 127 inclusive>

    • To specify the minimum number of numeric characters for a valid password, use the following command syntax:

      modify /auth password-policy required-numeric <value from 0 through 127 inclusive>

    • To specify the minimum number of special characters for a valid password, use the following command syntax:

      modify /auth password-policy required-special <value from 0 through 127 inclusive>

    • To specify the minimum number of uppercase characters for a valid password, use the following command syntax:

      modify /auth password-policy required-uppercase <value from 0 through 127 inclusive>

    • To specify the number of days before a password expires and the BIG-IQ system sends a warning message to the affected user, use the following command syntax:

      modify /auth password-policy expiration-warning <value from 1 through 255 inclusive>

    • To specify the amount of time in seconds that locked user account must wait before logging in again (unless manually reinstated), use the following command syntax:

      modify /auth password-policy lockout-duration <value from 0 through 999999 inclusive>

      Note: This setting is available in only BIG-IQ 8.0.0 and later.

    • To specify the maximum number of days a password is valid, use the following command syntax:

      modify /auth password-policy max-duration <value from 1 through 99999 inclusive>

    • To specify the number of consecutive unsuccessful login attempts that the system allows before locking the user account, use the following command syntax:

      modify /auth password-policy max-login-failures <value from 0 through 65535 inclusive>

    • To specify the minimum number of days a password is valid before allowing the user to change their password, use the following command syntax:

      modify /auth password-policy min-duration <value from 0 through 255 inclusive>

    • To specify the number of former passwords that the BIG-IQ system retains to prevent the user from reusing them, use the following command syntax:

      modify /auth password-policy password-memory <value from 0 through 127 inclusive>

  3. To review the full list of settings configured for the password-policy setting, enter the following command:

    list /auth password-policy all-properties

  4. To save your changes, enter the following command:

    save /sys config

  5. After enforcing the new changes to the system password policy, verify the changes using at least one of the affected user accounts, and ensure the system is appropriately enforcing the changes you made for your environment.
