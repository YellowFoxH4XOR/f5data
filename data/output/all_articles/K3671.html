K3671: Removing password encryption from an SSL private key

Topic

Prior to version 9.0, BIG-IP does not support password-encrypted private keys. If you have a password-encrypted private key, you can remove the password by using the following steps:

  1. Log in to the command line.
  2. Change directories to the /config/bigconfig/ssl.key/ directory, by typing the following command:

    cd /config/bigconfig/ssl.key/

  3. Remove the password, by typing the following command:

    openssl rsa < <existing_key_name> > <new_key_name>

    For example:

    openssl rsa < myencrypted.key > mynew.key

  4. Type the existing passphrase when prompted.

This will produce a new key file without a password. The original key file will remain unchanged.
