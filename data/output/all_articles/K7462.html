Known Issue

The bigpipe command b ha table reports the hardware failover cable as not being present, regardless of whether or not it is physically attached. This can cause confusion when determining whether or not the cable is attached to the system with only remote access available.

For example, the hardware failover cable may be physically attached to both units and in use but the b ha table command shows that it is not attached, as shown in the following example:

# b ha tableHIGH AVAILABILITY TABLEFeature               Key  Action       En? Act Proc   Time       Datahardwired failover    sod  go active    no  no  sod       0          0

If the cable is attached, the correct entry in the En? (Enabled field) should say yes.

F5 Product Development tracked this issue as CR65057 and it was fixed in BIG-IP LTM version 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.
