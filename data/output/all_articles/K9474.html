Known Issue

This is the result of a known issue. If a user accesses a Portal Access Windows Files favorite, selects a file formatted for a Microsoft Office 2007 application (such as a .docx or .xlsx file), and then clicks the Load into browser link, the browser prompts the user to download the file as a ZIP (.zip) file instead of loading it into the browser. Similarly, if the user right-clicks the Load into browser link and selects the option to download the file, the user is prompted to download the file with the .zip filename extension instead of the original filename extension.

For example, if a user downloads the file1.docx file through a Windows Files favorite, the user is prompted to save the file as file1.zip on the client system.

This issue occurs because the Microsoft Office Open XML file formats introduced in Microsoft Office 2007 use ZIP compression, causing these files to be recognized as ZIP files by the FirePass web service.

Note: For more information about the Microsoft Office Open XML file formats, refer to http://msdn.microsoft.com/en-us/library/aa338205.aspx.

F5 Product Development tracked this issue as CR110631 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-1, which has been issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by downloading the Microsoft Office 2007 file instead of loading it into the browser. When downloading the file, users should enter the original filename extension instead of using the .zip filename extension suggested by the browser.

If the browser automatically downloads the file without prompting the user for an alternate filename, users can work around this issue by renaming the file to the original filename after download. For example, if original filename was file1.docx, the user could rename the file from file1.zip to file1.docx after downloading it through a Windows Files favorite.
