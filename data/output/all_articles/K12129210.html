K12129210: Error - This type of report not supported for device bigip.example.com of version 14.x

Type
Support Solution
Published
2020-01-28
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K12129210

Description

  • When navigating to Monitoring > Reports > Security > Web Application Security > Reporting in BIG-IQ GUI and then selecting a managed BIG-IP device running software version v14.x or above a warning message is generated
  • Error message: This type of report not supported for device bigip.example.com of version 14.1.0.6 Point Release 6

Environment

  • BIG-IQ v7.x
  • BIG-IP running software version 14.x or above
  • ASM reporting

Cause

The seen behavior is expected

Recommended Actions

  • ASM reports for BIG-IPs version 14.0 and above are located on  Monitoring > Dashboards > Web Application Security on BIG-IQ GUI
  • ASM reports for BIG-IPs version below 14.0 are located on Monitoring > REPORTS > Security > Web Application Security  on BIG-IQ GUI

Additional Information

None
