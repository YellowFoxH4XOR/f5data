K000157854: ServiceCatalogInstall stuck "InProgress" in "show cluster" after upgrading F5OS-C to 1.8.2

Type
Support Solution
Published
2025-11-14
Updated
2025-12-24
Applies to
  • F5OS
  • F5OS-C: 1.8.2
Source
https://my.f5.com/manage/s/article/K000157854

Description

After upgrading a VELOS chassis to 1.8.2+EHF, The CLI prompt displays "Cluster update in-progress," and the cluster status shows "ServiceCatalogInstall InProgress," even though the cluster and tenants appear to be healthy.

STAGE NAME STATUS 
-------------------------------------
AddingBlade Done 
HealthCheck Done 
HostedInstall Done 
MasterAdditionalInstall Done 
MasterInstall Done 
NodeBootstrap Done 
NodeJoin Done 
Prerequisites Done 
ServiceCatalogInstall InProgress 
etcdInstall Done

Environment

  • F5OS-C version 1.8.2+EHF
  • VELOS CX410 chassis with SX410 blades (F101)
  • OpenShift cluster running on the VELOS platform
  • Upgrade performed from F5OS-C 1.6.4 to 1.8.2+EHF

Cause

The in-progress status is caused by a known issue where, after upgrading F5OS-C, a race condition or failure during the OpenShift apiserver certificate update process leaves the ServiceCatalogInstall state as "InProgress". The root cause is documented in Bug ID 2078485.

Recommended Actions

1. Connect to the active controller as root
2. Run
 
docker exec orchestration_manager sed -i.bak s/force=0/force=1/ /usr/omd/scripts/check_apiserver_certs.sh; sleep 300; docker exec orchestration_manager sed -i.bak s/force=1/force=0/ /usr/omd/scripts/check_apiserver_certs.sh
This will cause orchestration-manager to re-run the certificate updates, which will re-run the ServiceCatalogInstall playbook and fix the status in show cluster
