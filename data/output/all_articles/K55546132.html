Known Issue

The BIG-IP system may not gather BIG-IP Analytics data for DNS virtual servers.

This issue occurs when either of the following conditions are met:

  • Your BIG-IP system is not provisioned with the BIG-IP AFM module and the following is true:
    • You have a virtual server configured with DNS and Analytics profiles.
    • The virtual server processes traffic.
  • Your BIG-IP system is provisioned with the BIG-IP AFM module and the following is true:
    • The DNS profile DNS Security option is enabled (enable-dns-firewall yes).
    • A DoS profile is associated with the virtual server.
    • The virtual server processes traffic.

Impact

The system does not gather BIG-IP Analytics statistics for the virtual server traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the Configuration utility, when you navigate to Statistics > Analytics > DNS, the system displays an error message similar to the following example:

    There is no data to display either due to the lack of relevant traffic, or due to the settings of the filter.
