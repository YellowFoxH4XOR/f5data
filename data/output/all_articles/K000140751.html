Description

Sometimes when you try to renew the f5.api.com you can encounter a situation where certificate nad key are not visible in GUI, but you are able to see them /config/ssl/ssl.crt.

Environment

  • BIG-IP LTM

Cause

It is a cosmetic problem where GUI doesn't load the information about f5.api.com correctly. 

Recommended Actions

To solve this problem, first you need delete all references to f5.api.com by:

# rm -f /config/ssl/ssl.crt/f5.api.com.crt

# rm -f /config/ssl/ssl.key/f5.api.com.key

Then, you need to verify your license with command:

# tmsh show sys license

And at the end you need to reactive the license via CLI:

# tmsh install /sys license registration-key <license-key> add-on-keys { <add-on-key> }
