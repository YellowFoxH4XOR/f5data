K000091622: Attempting to Upgrade NGINX Controller fails with "Error: Kubernetes control plane is not ready after updating cloud provider configuration"

Type
Support Solution
Published
2022-06-12
Updated
2022-07-17
Source
https://my.f5.com/manage/s/article/K000091622

Description

Performing an upgrade of Nginx Controller may fail if a global proxy is used on the system. You may get the following error during the install script execution. "Error: Kubernetes control plane is not ready after updating cloud provider configuration".

 

Environment

  • Nginx Controller configured with a whole system proxy.
  • NO_PROXY value is using CIDR with subnet notation.
  • Specific IP address not defined in NO_PROXY value.

 

Cause

The update.sh script uses curl which does not appear to honor the no_proxy value if subnet CIDR notation is used.

 

Recommended Actions

If an HTTPS proxy is configured for the whole system, you should disable the proxy for the IP address and hostname of the host that you’re running the NGINX Controller install script on. For example, run the command export NO_PROXY=<current_ip>,<current_hostname>. Use of subnet CIDR notation does not appear to work currently.
