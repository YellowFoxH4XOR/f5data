K62940681: BIQ-IQ Script jobs stuck in running state - Unable to cancel

Type
Support Solution
Published
2022-06-30
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K62940681

Description

Using the script management feature to deploy scripts on multiple managed BIG-IP devices
The status of one or more devices in the Script Log is showing as "Failed to get device information."
The job will appear to be stuck.

Environment

  • BIG-IQ
  • Script Management

Cause

"Failed to get device information." is a result of a mismatched uuid and machineId.
In other words the BIG-IP /config/f5-rest-device-id has changed since it was last imported into BIG-IQ

Recommended Actions

For the impacted BIG-IP device on BIG-IQ in the DEVICES tab >> BIG-IP DEVICES
  1. Remove the services
  2. Remove the device
  3. Re-import the device
  4. Re-discover / import the configuration

Additional Information

Use the following commands from BIG-IQ CM for additional detail:
restcurl shared/user-script-execution
restcurl shared/resolver/device-groups/cm-bigip-allBigIpDevices/devices
