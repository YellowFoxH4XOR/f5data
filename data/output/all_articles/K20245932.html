K20245932: Accessing a blade console from Velos System Controller

Type
Support Solution
Published
2021-11-16
Updated
2023-02-21
Applies to
  • VELOS Platforms
  • F5OS
  • F5OS-C: 1.2.2, 1.2.1, 1.2.0, 1.2.X
  • VELOS BX110 Blade
  • VELOS CX410
Source
https://my.f5.com/manage/s/article/K20245932

Description
When you want to access one of the blade console from Velos System Controller

Environment

  • Velos CX410
  • Velos BX110 Blade
  • Velos System Controller v1.2
  • Console access

Cause
None

Recommended Actions

  1. To access the blade console, from the console of any system controller hit the esc-shift-9 and you will see the following:

    Example:

    Active console               : system controller 1
    Physically connected console : system controller 1 serial port

    AOM Command Menu:
    B --- Set baud rate
    C --- Capture blade console
    CC -- Capture system controller console
    I --- Display chassis information
    P --- Power on/off blade
    PC -- Power on/off system controller
    R --- Reset blade CPU
    RC -- Reset system controller CPU
    U --- Front panel USB port
    Q --- Quit menu and return to console

    Enter Command: C
    Blade to capture console output from (1-8)? 1

    Connecting to blade in slot 1...success.

    CentOS Linux 7 (Core)
    Kernel 3.10.0-862.14.4.el7.centos.plus.x86_64 on an x86_64

Additional Information
None
