Topic

This message indicates that the Network Configuration for a FirePass failover pair is not synchronized.

This occurs most commonly when you have made changes to the Network Configuration for one of the systems in a redundant pair, but have not yet committed the changes. While the previous configuration is still synchronized, FirePass will send an alert because the recent changes are not yet saved, and therefore, are not synchronized with the peer.

To resolve this issue, commit or cancel the configuration changes by performing the following steps.

Committing configuration changes

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Configuration.
  4. Click Network Configuration.
  5. Click Finalize.
  6. Click Finalize Changes.

The new changes are now saved. Depending on the changes and the version of FirePass software, FirePass may reboot. FirePass will then synchronize with the peer unit and stop sending the alert.

Canceling the configuration changes

  1. Log in to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Configuration.
  4. Click Network Configuration.
  5. Click Finalize.
  6. Click Cancel Changes, Rollback.

FirePass will discard the changes and stop sending the alert.
