Issue

Error Message

err mcpd[<PID>]: 01071ceb:3: Operation failed for CA bundle manager <bundle_name> due to other pending operation.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <bundle_name> is the name of the Certificate Authority (CA) bundle manager.

For example:

err mcpd[8484]: 01071ceb:3: Operation failed for CA bundle manager /Common/test_bundle due to other pending operation.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system receives a CA bundle manager update request while the previous update operation is not completed.

Impact

The CA bundle manager update operation is rejected.

Recommended Actions

The message may indicate that the BIG-IP system receives multiple CA bundle manager update requests in a short period of time. To work around this issue, you can verify the certificate content of the CA bundle manager is updated before requesting more update operations.
