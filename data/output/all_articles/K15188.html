Summary

Enterprise Manager may be unable to connect to the F5 update server to download the BIG-IP ASM attack signature updates.

Description

Due to necessary security improvements to the F5 update server, Enterprise Manager systems may be unable to connect to the update server to retrieve BIG-IP ASM attack signature updates.

Recommendations

If your Enterprise Manager system is unable to connect to the F5 update server to download the BIG-IP ASM attack signature updates, refer to the following recommendations:

Upgrade to Enterprise Manager 3.1.1 HF1 or later

Enterprise Manager 3.1.1 HF1 contains a connection security update that will allow the BIG-IP ASM attack signature update feature to function correctly.

Note: For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

Manually download the BIG-IP ASM attack signature updates and import to Enterprise Manager

To manually download BIG-IP ASM attack signature files and import them to the Enterprise Manager system, perform the following procedure:

  1. Browse to https://downloads.f5.com.
  2. Manually download the latest signature file to your local workstation.
  3. Log in to the Enterprise Manager Configuration utility.
  4. Navigate to Enterprise Management > Repository > Attack Signature List.
  5. Click Import.
  6. Click Browse and browse to the location of the Attack Signature file.

You can now install the downloaded attack signatures to managed BIG-IP ASM devices.
