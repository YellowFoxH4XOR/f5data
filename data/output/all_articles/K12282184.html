Description

How to check the maximum number of node member one pool can support.
This will help to check the Default value  of maximum number of nodes that can be added to a pool. 

Environment

  • BIG-IP LTM  
  • Pool and Node Members

Cause
None 

Recommended Actions

The actions or steps required to address the topic covered in the description.
  • Login into the CLI via admin account
  • Go to the tmos shell by command
    tmsh
  • Execute the below command 
    show sys license detail | grep ltm_lb_pool_member_limit
For example output will be like below 
ltm_lb_pool_member_limit [unlimited]    >>>>    shows the limit of pool memeber from license.

Note:  If you exceed the number, your system displays an error message similar to the following example: bigpipe: Pool, Maximum number of node boxes exceeded.
