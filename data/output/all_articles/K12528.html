Known Issue

This is the result of a known issue. When rebooting the BIG-IP 6900, 8900, 8950, 11050, and PB200 platforms, an error message may display on the system console for approximately 15 seconds. The error message will appear similar to the following examples:

  • ACPI: Unable to locate RSDP
  • ACPI Error: A valid RSDP was not found (20090903/tbxfroot-219)

This message is benign and indicates that an ACPI capable kernel is booted on a system without ACPI support.

Note: This message is also generated while booting to EUD versions 12.7.0 through 12.7.3.

F5 Product Development is tracking this issue as ID 226113.

Note: The console may also display an error message that appears similar to the following example during the reboot cycle: Memory for crash kernel (0x0 to 0x0) notwithin permissible range. For information about this error message, refer to K11620: Error Message: err kernel: Memory for crash kernel (0x0 to 0x0) notwithin permissible range.
