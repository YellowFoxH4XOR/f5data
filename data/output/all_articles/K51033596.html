Description

An error message similar to the following is generated when attempting to modify a configuration object:

010715bc:3: The application service (/Common/test.app/test) has strict updates enabled, the object (Persistence Profile /Common/test.app/test_cookie-persistence) must be updated using an application management interface.

Environment

  • iApps configured

Cause

It is not possible to modify objects directly when they were created by an iApp due to the Strict Updates setting. This is the default setting and can be disabled for each deployed application service.

Recommended Actions

It is recommended to reconfigure the deployed application service in order to modify the configuration object in question.

If the object in question cannot be modified through reconfiguration of the application service, disable Strict Updates and make changes with the following procedure:

  1. Go to iApps > <Application Services > <Application name> > Properties > Advanced.
  2. Clear the Strict Updates check box.
  3. Select Update.
  4. Make the changes you want to the configuration object.
  5. Re-enable strictness by selecting the Strict Updates check box again.

Additional Information

Strict Updates protects against accidental changes to an application service's configuration. F5 recommends leaving Strict Updates enabled. For more information, refer to K51699308: Modifying or deleting an iApp.
