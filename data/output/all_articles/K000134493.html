Description

You would like to force a GARP for a specific virtual server that is configured on the BIG-IP

 

Environment

BIG-IP

 

Cause

None

 

Recommended Actions

If you would like to force a GARP for a specific virtual server / virtual address you can use the following tmsh commands:

# tmsh modify ltm virtual-address 192.168.100.1 arp disabled
# tmsh modify ltm virtual-address 192.168.100.1 arp enabled

In this example 192.168.100.1 is the ip address of the virtual server
