Description

Intermittent Disconnections to the Virtual Server when there is increase in the load or traffic increases on respective Virtual Server.

261849 50.350878 0.000074 700 < Virtual Server IP > → <Backend Server IP> 40 443 41992 TCP OUT s1/tmm0 : 443 → 41992 [RST, ACK] Seq=1 Ack=1 Win=0 Len=0 [F5RST: No flow found for ACK]
Capture shows a ton of connections in an embryonic state - client opens with a SYN, we send a SYN/ACK, then no ACK from the client.

Error messages when running curl: 
curl: (35) LibreSSL SSL_connect: Network is down in connection to <URL>   
 

Environment

  • BIG-IP LTM
  • Virtual Server enabled with single CPU CMP Mode and SYN cookies
  • TCP profile is set to f5-tcp-progressive
     

Cause

Unknown at time of publication
 

Recommended Actions

Follow any one of the steps to resolve the issue:

  1. Creating a custom profile based on f5-tcp-progressive and tried tweaking the settings or Switching to another tcp profile (e.g. 'tcp' or 'f5-tcp-wan') fixes it though.
  2. Changing the SYN Cookies Threshold value to higher value. Please find the below procedure to change the threshold value 
Using the Configuration utility to modify the Default Per Virtual Server SYN Check Threshold
Impact of procedure: Performing the following procedure should not have a negative impact on your system
  • Log in to the Configuration utility.
  • Go to System > Configuration > Local Traffic > General.
  • To change the default value, enter the value you want for Default Per Virtual Server SYN Check Threshold under Properties.
  • Select Update.
