K000138229: SMTP service not working when creating Hybrid Exchange deployment via FAST template

Type
Support Solution
Published
2024-01-15
Updated
2024-01-15
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000138229

Description

The article describes a common issue after deploying Hybrid Exchange application from FAST template. Here is the list of ports that should be created for Hybrid deployment:

https://learn.microsoft.com/en-us/exchange/hybrid-deployment-prerequisites#hybrid-deployment-protocols-ports-and-endpoints

The FAST template does not create any object on port 25 hence SMTP will not work.

Environment

  • Microsoft Hybrid Exchange
  • FAST template

Cause

Current Exchange FAST template is not intended for Hybrid deployments.

Recommended Actions

  1. Configure SMTP service from SMTP Fast template.
  2. Configure fastL4 virtual server on port 25 with the same destination IP that was configured in FAST template.

Additional Information

The template change was reported to Product Development but the change will not be implemented for now.
