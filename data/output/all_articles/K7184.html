Known Issue

Note: Feature release 6.0.1 of FirePass software is the first release to support Microsoft Windows Vista clients.

This is the result of a known issue. Automatically mapping a networked drive using a Network Access Favorite fails for Microsoft Windows Vista clients.

Networked drives that share files through the SMB/CIFS protocol, such as Microsoft Networking fileshares, can be automatically mapped to the local system through a Network Access Favorite. The mapping is configured on the Drive Mapping tab of the Network Access: Resources page. However, users connecting to the FirePass controller with the Microsoft Windows Vista operating system will not be able to successfully map the network drive. Instead, an authentication prompt will appear, requesting username and password credentials for the fileshare. Even after the correct credentials are supplied, the authentication window will reappear, as if the credentials were entered incorrectly. The user can only click the Cancel button to reject the logon to the fileshare, and proceed with the Network Access connection without a mapped drive.

F5 Networks Product Development tracked this issue as CR75721 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in Cumulative Hotfix HF-601-4 for FirePass version 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.
