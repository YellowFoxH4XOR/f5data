Topic

Beginning in BIG-IP 9.6.0 and 10.0.0, the high availability table includes a feature named Ready for World for each Traffic Management Microkernel (TMM) instance running on the BIG-IP system.

For example, if the bigpipe ha table command is run on a BIG-IP 3900 system, the command output will include the following lines:

Feature              Key      Action                       En? Act   Data
Ready for World      tmm      no action                    yes yes      0
Ready for World      tmm1     no action                    yes yes      0
Ready for World      tmm2     no action                    yes yes      0
Ready for World      tmm3     no action                    yes yes      0

The Ready for World feature is used to signal when TMM is transitioning from down to up (that is, when TMM is starting). When this event occurs, the sod process reads that the links can be enabled.

Note: A yes in the take action field usually means that something unexpected and adverse has happened to a particular component or feature of the BIG-IP system. However, that is not the case for the Ready for World feature; seeing yes in the take action field is expected. Additionally, the Ready for World feature does not indicate whether a particular TMM instance is currently running. You can ignore these table entries; no action is required.

The same high availability table feature exists in BIG-IP 9.4.x; however, it is named expect link down.

For example, if the bigpipe ha table command is executed on a BIG-IP 3900 system running 9.4.8, the command output will include the following lines:

Feature              Key      Action                       En? Act    Data
expect link down     tmm      no action                    yes yes       0
expect link down     tmm1     no action                    yes yes       0
expect link down     tmm2     no action                    yes yes       0
expect link down     tmm3     no action                    yes yes       0
