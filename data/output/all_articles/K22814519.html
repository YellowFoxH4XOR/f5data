Description
When deploying the telemetry configuration for Azure Sentinel on BigIP APM, you are prompted with an error message similar to this one:
{
    "code": 422,
    "message": "java.net.ProtocolException: status:422, body:{\"code\":422,\"message\":\"Unprocessable entity\",\"error\":\"Error: [{\\\"keyword\\\":\\\"f5secret\\\",\\\"propertyName\\\":\\\"passphrase\\\",\\\"dataPath\\\":\\\"/My_Consumer/passphrase\\\",\\\"params\\\":{},\\\"message\\\":\\\"Cannot read property 'indexOf' of undefined\\\"}]\"}",

Environment

  • BigIP APM
  • Azure Sentinel

Cause
This may be because some "alias" being set up in your environment. such as:
cli alias private list {
    command bash
    user admin
}

Recommended Actions

  1. SSH to BIG-IP as root.
  2. Open /config/bigip_user.conf file for editing: vim /config/bigip_user.conf
  3. Locate the following config block in this file:
    cli alias private list {
        command bash
        user admin
    }
  4. Remove the above block. Save changes.
  5. Run: tmsh load sys config partitions all
    >> Confirm there are no errors.
  6. Run: tmsh save sys config
