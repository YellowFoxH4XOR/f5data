Description

Unable to manually configure Tenant Memory allocation in GUI.

Environment

  • F5OS
  • Tenant Configuration

Cause

When configuring a Tenant from the GUI, manual configuration of Memory cannot be carried out if the "Resource Provisioning Field" is not set to 'Advanced'.

Recommended Actions

Set Resource Provisioning to Advanced

  1. Log into the F5OS system GUI.
  2. Shutdown the tenant by changing the running state to either one of the following options:
    • Configure: The tenant is shutdown and does not pass application traffic. The tenant's hardware resources are temporarily de-allocated while in this state.
    • Provision: The tenant is shutdown and does not pass application traffic. The tenant's hardware resources continue to be allocated.
  3. Navigate to the tenant properties page and for Resource Provisioning, select Advanced (see screenshot).
  4. Change the tenant memory allocation.
  5. Restart the tenant by changing the running state to Deploy.
