Description

When attempting to activate a new trial or evaluation-based registration key through the GUI, the following error is displayed:

Error 51133: “F5 registration key is not compatible with the detected platform. This platform, ‘Z100’, cannot be activated with this registration key.”

Environment

  • License activation
  • VMware

Cause

Activating a Cloud Edition VE license on VMware is not supported. Cloud Edition VE licenses are intended exclusively for cloud platforms such as AWS or Azure and cannot be used on on‑premises hypervisors like VMware.



Recommended Actions

  1. Request a new trial key via https://downloads.f5.com/trial and select the first option "BIG-IP VE and BIG-IQ".
  2. Allow up to 15 to 30 minutes to receive an email on the new key and try to reactivate with the new BIG-IP VE trial registration key.

Additional Information

 

Please keep in mind that you may contact F5 Sales to request a new key if needed.
