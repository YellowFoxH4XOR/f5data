Issue

Error Message

notice mcpd[<PID>]: 0107168c:5: Incremental sync complete: This system is updating the configuration on device group <name> device <peer_device> from commit id { <ID> <local_device> } to commit id { <ID> <local_device> }.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process
  • <name> is the name of the affected device group
  • <peer_device> is the hostname of the remote BIG-IP system receiving the update
  • <ID> is the transaction commit ID number
  • <local_device> is the hostname of the local BIG-IP system

For example:

notice mcpd[9272]: 0107168c:5: Incremental sync complete: This system is updating the configuration on device group /Common/sync_failover_group device %cmi-mcpd-peer-/Common/peer.example.com from commit id { 35 6413756774652482143 /Common/local.example.com } to commit id { 2 6416743348267947945 /Common/local.example.com }.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following condition are met:

  • You configure BIG-IP systems for high availability (HA).
  • An incremental ConfigSync completes successfully on the local BIG-IP system.

Impact

There is no impact; this message is a notification.

Recommended Actions

None
