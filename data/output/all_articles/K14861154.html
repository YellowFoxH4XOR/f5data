Issue

Error Message

value strict is deprecated.  Forcing to allow-underscore

For example, in the Traffic Management Shell (tmsh):

There were warnings:
value strict is deprecated.  Forcing to allow-underscore

For example, in the /var/log/ltm file:

01071859:4: Warning generated : value strict is deprecated.  Forcing to allow-underscore
01071057:4: Configuration warning: value strict is deprecated.  Forcing to allow-underscore

Note: This issue affects BIG-IP 12.0.0, 11.6.0, and 11.5.4 only when a hotfix is applied.

Message Location

You may encounter this message in the following locations:

  • tmsh
  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • You have a BIG-IP DNS (formerly GTM) system and perform one of the following actions:
    • You run the tmsh modify gtm global-settings general domain-name-check strict command.
    • You upgrade your BIG-IP DNS system to one of the versions listed in the Applies to (see versions) menu.

      Note: After upgrading, the strict domain validation setting will be set to allow-underscores.

The strict domain validation functionality was deprecated from software, but the option remains in the Configuration utility. F5 Product Development tracked this change as ID 561333 and the options have been removed in BIG-IP 12.1.0 and later.

Impact

None. This message is informational only.
