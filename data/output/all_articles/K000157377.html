Description

When using SSL passthrough Virtual Server (no SSL profiles), SSL persistence will not work for TLS1.3 sessions.


Environment

- TLS1.3

- SSL passthrough Virtual Servers

- SSL persistence


Cause

Session ID (used for SSL persistence in TLS1.2 and earlier) is obsolete in TLS 1.3, and Session Ticket is used instead for SSL resumption.

However, the Session Ticket is encrypted between the client and server, so Virtual Server in SSL passthrough configuration is unable to obtain it and use it for persistence.


Recommended Actions

Don't use SSL persistence when TLS1.3 sessions are established on SSL passthrough Virtual Server


Additional Information
