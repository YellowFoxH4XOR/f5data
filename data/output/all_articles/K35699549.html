Description

You see that a virtual server is not providing a redirect to the configured fallback host when it's connection limit is reached

Environment

  • BIG-IP LTM
  • Virtual Server with a Connection limit
  • HTTP Profile with Fallback Host configured

Cause

The virtual server's configured connection limit rejects traffic before the HTTP profile's fallback host can be returned

Recommended Actions

Moving the connection limit from the virtual server to the pool will allow the HTTP profile to provide the fallback host to the client before the connection limit rejects the client connection

Additional Information

None
