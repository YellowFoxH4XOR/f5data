K83161927: Unable to load properties file on BIG-IQ

Type
Support Solution
Published
2021-06-16
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K83161927

 

Description

After making changes to the /var/config/rest/config/restjavad.properties.json file the following may occur:

  • The BIG-IQ discovery address is not populated in the WebUI and the customer is unable to add an HA peer.

    You may encounter the following error messages:
  • Unable to load properties file" is seen in /var/log/restjavad.log 
  • Please verify URI is supported and wait for /available suffix to be responsive" is seen in /var/log/restjavad.log 

Environment

  • Unable to add HA peer in BIG-IQ 
  • Modifications made to /var/config/rest/config/restjavad.properties.json file

Cause

Syntax issues in restjavad.properties.json file

Recommended Actions

  1. Verify if there are syntax errors in the restjavad.properties.json file
    jq . /var/config/rest/config/restjavad.properties.json 

    This command will either display the contents of the restjavad.properties.json file or display an error message similar to the following example:

    jq .platform.deviceRefresh /var/config/rest/config/restjavad.properties.json
parse error: Expected separator between values at line 70, column 19

In this case the error was referencing a missing "," (comma) that was needed 

     {
     "bigipPollingFrequencyMS": 120000,
     "bigiqPollingFrequencyMS": 10000,
     "rebalanceAfter": 25,
     "checkDeviceListMS": 60000     ----- Missing comma here 
     "expirationMS": 20000
 },
  2. Once error is resolved, run the command in step 1 to verify no more error statements are seen.

    {
         "bigipPollingFrequencyMS": 120000,
         "bigiqPollingFrequencyMS": 10000,
         "rebalanceAfter": 25,
         "checkDeviceListMS": 60000,   ----- comma is added to correct the syntax issue
         "expirationMS": 20000
     },
     
  3. Restart restjavad

    bigstart restart restjavad 

  4. Log into WebUI and should now be able to add HA peer device
