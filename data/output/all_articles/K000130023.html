K000130023: RCA for Interfaces down after untagged vlan was enabled on Interface

Source

Description

Effect of vwire-propagate-linkstatus setting

Environment

BIG-IP configured with virtual wire

Cause

Setting propagate linkstatus to enabled causes the BIG-IP to set both interfaces in the vlan group to down if either interface is down.


Recommended Actions

NA
