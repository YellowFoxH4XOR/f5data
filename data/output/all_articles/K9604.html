Known Issue

This is the result of a known issue. Users may be unable to successfully launch a Portal Access web application favorite when accessing pages configured on the Portal Access: Web Applications: Content Processing page. A page not found (404) error may occur when users are running a Firefox browser and FirePass has been configured to use Compatibility Mode 2 on the Portal Access: Web Applications: Content Processing: Global Settings page in the Web Applications Global Settings section. If the user is running Internet Explorer, they do not receive a page not found (404) error.

F5 Networks Product Development is tracking this issue as CR111697. This issue is limited to FirePass version 6.0.3.

This issue has been fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

Users can work around this issue by using Internet Explorer.
