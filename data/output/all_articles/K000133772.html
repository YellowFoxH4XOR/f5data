Description

Unable to re-activate the License for BIG-IQ in AWS, getting the following error when trying to re-activate using GUI or CLI:

Error: Unable to get license for RegKey: ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG, try manual activation.
Detail: Command failed: /usr/bin/get_dossier -b ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG Exit code: 1 Stderr: <131>Apr 27 09:02:58 ip-11-88-99-11 get_dossier[6137]: 01170003:3: halGetDossier returned error (1): Dossier generation failed.

 

Environment

  • BIG-IQ instance on AWS
  • Re-activation of license

Cause

The AWS instance is using IMDSv2 which isn't supported by BIG-IQ. This instance may have originally used Instance Metadata Service Version 1 (IMDSv1), but then it changed to IMDSv2.

Recommended Actions

Revert the IMDS version back to version 1 in AWS per the following link. 
Note: This link accesses a resource outside of F5 and may be removed without our knowledge.

  • Restore the use of IMDSv1 
    1. Within the AWS instance settings, modify the metadata options so IMDSv2 is set to Optional.

Or upgrade to BIG-IQ 8.4, which has added support for AWS IMDSv2.

Additional Information

Other errors that may be encountered while attempting to activate the device license if using IMDSv2 include the following:

  1. The system returned an unexpected errors (400 Bad Request). Could not create dossier.
  2. Could not create dossier
