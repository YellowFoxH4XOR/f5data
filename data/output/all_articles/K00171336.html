Description

Client send HEAD method and it reset the response from virtual server with HTTP2 profile.
The client may produce error similar to:

http2 error: Invalid HTTP header field was received: frame type: 1, stream: 1, name: [transfer-encoding], value: [chunked]
 

Environment

  • BIG-IP v14 and later
  • HTTP2 proxy Virtual server (Backend server side is HTTP1.*)
  • HTTP2 profile
  • Head method
  • reset
     

Cause

Bug ID 1024225

Recommended Actions

Follow the workaround written in Bug ID 1024225
e.g. set below iRule 
when HTTP_REQUEST {
     set HTTP_method [HTTP::method]
}
when HTTP_RESPONSE {
     if {$HTTP_method eq {HEAD}} {
          HTTP::header remove {Transfer-Encoding}
     }
}
