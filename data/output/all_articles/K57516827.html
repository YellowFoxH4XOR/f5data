Description

After changing a Microsoft Exchange deployment using the iApp reconfigure option, users are getting warnings about expired certificates when using Outlook.

Environment

  • Microsoft Exchange application deployed using iApp template
  • iApp strict updates option is disabled
  • Recently expired certificate was replaced
  • iApp was redeployed

Cause

When old certificate used by Exchange deployment expired, it was replaced directly under the ClientSSL profile configuration.
When performing the redeployment of the application service, BIG-IP deploys the settings defined in the template.
As a result manual change to the certificate was reverted to initial setting.

Recommended Actions

In order to reconfigure iApp to use correct certificate, please perform the following procedure:
  1. Navigate to iApps > <Application Services > <Application name> > Reconfigure
  2. Find section where you specify SSL certificate and key
  3. Choose correct SSL certificate and key
  4. Click Update
