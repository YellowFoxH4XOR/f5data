Issue

Error Message

warning tmm<#>[<PID>]: 01200016:4: Warning, node IP <IP> has reached its connection limit.

In this error message, note the following:

  • <#> is the number of the Traffic Management Microkernel (TMM) process that generated the message.
  • <PID> is the process ID for the Traffic Management Microkernel (TMM) process.
  • <IP> is the IP address for the node.

For example:

warning tmm3[587]: 01200016:4: Warning, node IP 10.10.10.100 has reached its connection limit.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure the Connection Limit setting for a node on the BIG-IP system.
  • The number of concurrent connections to the node exceeds the configured limit.

The BIG-IP system divides the configured connection limit for a given object by the number of TMMs running on the system and distributes the remainder among the lower-ordered TMMs.

Note that connections may not be distributed evenly, and, if the number of the running TMMs is high, the configured connection limit on each single TMM may be easier to reach.

For more information on how the connections are distributed, refer to K14358: Overview of Clustered Multiprocessing (11.3.0 and later)

Impact

A TMM process sends a TCP reset in response to a new connection while the number of connections to the node exceeds the limits available to this TMM process from the limit configured for the node.

Recommended Actions

To mitigate this issue, you can increase the connection limit for the node to an appropriate value for your environment. To do so, perform the following procedure:

Impact of procedure: The following procedure increases the the allowed number of connections to the BIG-IP system, which may impact resources. You should perform testing in order to determine an appropriate connection limit value for your environment.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Nodes.
  3. Select the name of the affected node.
  4. Under Configuration, for Connection Limit, enter an appropriate value.
  5. Select Update.
