Known Issue

The BIG-IP system may fail to forward Dynamic Host Configuration Protocol version 6 (DHCPv6) packets to the back-end server when packets arrive through an IPv6IPv4 tunnel.

This issue occurs when the following condition is met:

  • You have a multi-bladed VIPRION system.

Impact

The BIG-IP system does not forward DHCPv6 packets to the back-end server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe that the BIG-IP system forwards DHCPv6 packets to the virtual server but not the back-end server. You can observe this behavior by using the tcpdump packet tracing utility. For more information, refer to K1893: Packet trace analysis.
