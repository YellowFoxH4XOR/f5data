Description

Windows 10 Enterprise multi-session clients are getting denied logon to the APM

Environment

  • BIG-IP APM
  • Windows 10 Enterprise multi-session
  • Network Access Resources Assigned (VPN)

Cause
Windows 10 Enterprise multi-session is currently not supported on the BIG-IP APM. Network access VPN is not currently supported in virtual desktop environments such as Windows 10 Enterprise multi-session.

Recommended Actions

If it's mainly for 'client OS detection' purposes, you can add this expression for the respective branch/es in the Client OS check/agent in the access policy VPE


 [mcget {session.client.platform}] == "Win2015"

This will let Windows 10 Enterprise multi-session clients through the Client OS access policy checks on the APM.

Note: Adding the above-mentioned expression does not add support for Windows 10 Enterprise multi-session clients on the APM, in general.


For a list of OS and browsers supported by the BIG-IP APM, please refer to the respective APM Client Compatibility Matrix for your BIG-IP version
K14047: Supported operating systems and web browsers for the BIG-IP APM system

Windows 10 Enterprise multi-session FAQ

Windows 10 Enterprise multi-session, formerly known as Windows 10 Enterprise for Virtual Desktops (EVD), is a new Remote Desktop Session Host that allows multiple concurrent interactive sessions. Previously, only Windows Server could do this. This capability gives users a familiar Windows 10 experience while IT can benefit from the cost advantages of multi-session and use existing per-user Windows licensing instead of RDS Client Access Licenses (CALs).
