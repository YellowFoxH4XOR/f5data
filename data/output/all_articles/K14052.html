Topic

When an iRule is used to direct HTTP traffic to a specific pool member for a virtual server with cookie persistence enabled, the cookie is not inserted in the HTTP response.

This behavior is by design and it assumes that since a custom iRule is being used to direct the HTTP traffic to select pool members, further shaping of the HTTP traffic such as cookie persistence should also be handled through the iRule. For example, a virtual server referencing a cookie persistence profile and the following iRule would experience this issue:

when HTTP_REQUEST {
    if {[HTTP::uri] contains "cgi-bin"}{
        pool test_pool member 10.10.10.30
    } else {
        pool test_pool
    }
}

The following is an example of using an iRule to insert a BIG-IP encoded HTTP cookie in the HTTP_RESPONSE event:

Note: This example is for demonstration purposes only, and should not be considered a complete solution. This example also assumes that along with this iRule, the virtual server has a cookie persistence profile and a default pool configured. For more information about this iRule, refer to How can I get a persistance cookie when a pool member is selected by an iRule? on DevCentral.

when HTTP_REQUEST {
    if { [string tolower [HTTP::uri]] contains "cgi-bin" } {

        ## set the desired pool
        set this_pool "test_pool"

        ## send traffic to pool and specific member
        pool $this_pool member 10.10.10.30 80

        ## if persistence cookie doesn't exist, set a flag to create one
        if { not ( [HTTP::cookie exists BIGipServer$this_pool] ) } {
            set insertcookie [list $this_pool "10.10.10.30" "80"]
        }
    }
}
when HTTP_RESPONSE {
    if { [info exists insertcookie] } {
        ## encode the IP
        scan [lindex $insertcookie 1] %d.%d.%d.%d a b c d
        set ip1 [format %02x $a]
        set ip2 [format %02x $b]
        set ip3 [format %02x $c]
        set ip4 [format %02x $d]
        scan $ip4$ip3$ip2$ip1 %x ip

        ## encode the port
        scan [format %04x [lindex $insertcookie 2]] %2s%2s e f
        scan $f$e %x port

        ## insert the cookie
        HTTP::cookie insert name BIGipServer[string map {"/Common/" ""} [lindex $insertcookie 0]] value "$ip.$port.0000"
        HTTP::cookie path BIGipServer[string map {"/Common/" ""} [lindex $insertcookie 0]] "/"

        ## unset the variable
        unset insertcookie
    }
}
