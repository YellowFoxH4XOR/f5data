Known Issue

The Configuration utility may erroneously set the Terminal console access of a remote role group to none.

This issue occurs when all of the following conditions are met:

  • You navigate to the Configuration utility > System > Users > Remote Role Groups page to create a remote role group.
  • You create a remote role group with the Terminal Access option set to Other… while leaving the text box empty.

By default, the Terminal Access option is set to disabled. You can set the Terminal Access option to use the variable substitution method by selecting the Other… option from the Configuration utility. A text box appears next to the option, which allows you to specify a text string variable preceded by a leading % character. You should only specify one of the following values, namely disabled, tmsh, or the text string variable. As a result of this issue, the Terminal Access option is set to none.

Impact

The Terminal Access value of none is not a configurable option in the Traffic Management Shell (tmsh). However, you can configure the value using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You create the remote role group successfully. However, from the tmsh utility, the console option is set to none. The command and output to list a remote role group named dc1 may appear similar to the following example:

    tmsh list /auth remote-role role-info { dc1 }

    auth remote-role {
             role info {
               dc1 {
                 attribute "F5-LTM-User-Info-1=DC1"
                 console none
                 line-order 1
                 role %F5-LTM-User-Role
                 user-partition %F5-LTM-User-Partition
               }
        }
    }

Workaround

To work around this issue, you can navigate to Configuration utility > System > Users > Remote Role Groups > {Group Name}, Update the Terminal Access option of the affected remote role group with a value of either disabled, tmsh, or a valid text string variable, instead of leaving the text box empty.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
