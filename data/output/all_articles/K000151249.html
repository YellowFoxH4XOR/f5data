K000151249: 'ERR_SSL_KEY_USAGE_INCOMPATIBLE' error in the browser

Updated
2025-05-16
Applies to
  • BIG-IP

Description

Web browser displays 'ERR_SSL_KEY_USAGE_INCOMPATIBLE' error message when accessing web server.

Environment

  • Public certificate presented by the web server has "X509v3 Key Usage" extension set to 'critical'.
  • "X509v3 Key Usage" critical extension does not include "Digital Signature" or "Key Encipherment".

Cause

Public certificate is used during SSL handshake.

  • For RSA key exchange the public key is used to encrypt Client Key Exchange message.
    If certificate contains "X509v3 Key Usage" extension and it is set as 'critical' some client software (web browsers) require "Key Encipherment" option.

  • For ECDHE and DHE key exchange the public key is used to sign Sever Key Exchange message.
    If certificate contains "X509v3 Key Usage" extension and it is set as 'critical' some client software (web browsers) require "Digital Signature" option.

Some browsers do not allow connections to servers presenting certificates with "X509v3 Key Usage" extension set to "critical" when negotiated cipher suite is not compatible with "X509v3 Key Usage".

 

For example:

  1. Server selects RSA key exchange algorithm but public certificate contains "X509v3 Key Usage" extension set to critical and "Key Encipherment" option is missing.
  2. Server selects ECDHE or DHE key exchange algorithm but public certificate contains "X509v3 Key Usage" extension set to critical and "Digital Signature" option is missing.

Recommended Actions

This is not an F5 issue; rather, it is related to the incorrect "X509v3 Key Usage" extension.

Contact Certificate Authority issuing the public certificate to obtain certificate with correct "X509v3 Key Usage" extension.

Additional Information

An example of public certificate extension containing both options:

  • X509v3 Key Usage: critical
  • Digital Signature, Key Encipherment

An example of public certificate extension containing only "Digital Signature" option but "X509v3 Key Usage" extension is not set to "critical"

  • X509v3 Key Usage:
  • Digital Signature
