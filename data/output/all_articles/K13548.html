Known Issue

Provisioning BIG-IP LTM, APM, and WebAccelerator on the same system may not allocate sufficient memory for efficient operation.

This issue occurs when the following condition is met:

  • LTM, APM, and WebAccelerator have been licensed and provisioned on the same BIG-IP host.
  • The platform is one of the following:

    • BIG-IP 8900 (D106)
    • BIG-IP 8950 (D107)

Impact

BIG-IP WebAccelerator performance is degraded, which may impact page load times.

Workaround

To work around this issue, you can manually create a new provisioning table for this configuration. To do so, perform the following procedure:

Impact of workaround: A reboot is required. Perform this change during a maintenance window.

Manual provisioning for BIG-IP 8900

  1. Log in to the Configuration utility.
  2. Navigate to System > Resource Provisioning.
  3. Confirm that the resource level for LTM, WAM, and APM is set to Nominal.
  4. Log in to the BIG-IP command line as the root user.
  5. Mount the /usr filesystem as read-write by typing the following command:

    mount -o remount,rw,noatime /usr

  6. Create a new LTM/WAM/APM provisioning template. Copy and paste the following command:

    cat > /usr/lib/provisioning/d106_16g/ltmNom_wamNom_apmNom <<'EOM'
    memory.apm.host=4096
    memory.host=5184
    memory.ltm=7106
    memory.wam.host=64
    memory.wam=4032
    memory.ui=62
    EOM

  7. Put the /usr filesystem back into read-only mode by typing the following command:

    mount -o remount,ro,noatime /usr

  8. Reboot your BIG-IP system.
