K2631: Updating the root nameserver list on 3-DNS

Topic

The list of DNS root address nameservers and their IP addresses is stored in the root.hint file. Because the DNS system relies on contacting these servers to discover which nameservers are responsible for different domains, this is an important file. While the addresses do not change very often, you should try to keep the list as up-to-date as possible.

To update the root.hint file, use the dig command to connect to one of the root nameservers, perform an NS query for the "dot" domain (the root namespace), and send the output to the root.hint file. To do this, use the following command syntax:

dig @e.root-servers.net . ns > <namedb_directory>/root.hint

In this example, <namedb_directory> is the directory where your domain zone files are kept. In 3-DNS 2.0 through 3.0, domain zone files were stored in the /etc/namedb directory. In 3-DNS 4.0 and later, domain zone files are stored in the /config/3dns/namedb directory.

You may want to consider creating an automatic update process for this task by using a system tool such as cron. For more information on automating tasks with cron, refer to the cron man pages.
