K000092556: Upgrade failed with GUI error: License invalid for <Licensed Version>

Type
Support Solution
Published
2022-11-05
Updated
2022-11-05
Source
https://my.f5.com/manage/s/article/K000092556

Description

Upgrade failed and error is seen from the Configuration Utility (GUI) like the one below:

 

License invalid for 15.1.7
This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device.
The license for this device is not operational.

 

Environment

  • BIG-IP Virtual Edition (VE)
  • Software Upgrade
  • Version Plus license offerings

 

Cause

The upgraded version is not supported by the license. You can only upgrade within the version listed in Exclusive version.

 

Recommended Actions

To verify if Exclusive version limitation applies to your license, run following command:

grep Exclusive_version /config/bigip.license

Exclusive_version : 10.*.*
Exclusive_version : 11.*.*
Exclusive_version : 12.*.*
Exclusive_version : 13.*.*
Exclusive_version : 14.*.*
Exclusive_version : 15.0.* <<<---

 

In this output, you are only allowed to upgrade up to version 15.0.x. Upgrading to version 15.1.x will fail.

 

Additional Information

If your desired software version is not on the exclusive version list, you will need to obtain a new license.
Please contact your local sales representative to determine the appropriate BIG-IP VE SKU to purchase.
