Known Issue

Stream filter expressions that make use of parenthesis may not match the expected strings.

This issue occurs when all of the following conditions are met:

  • You have the stream profile associated with a virtual server.
  • You are using an expression that uses either an opening or closing parenthesis, for example, ( or ).

Impact

Stream filters may not function as expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Stream filters do not match strings as expected.

Workaround

To work around this issue, you can use the octal representation of the parenthesis. To do so, take the following action:

Impact of workaround: Taking the following action should not have a negative impact on your system.

Use octal character encoding to resolve stream filter conflicts, as shown in the following example:

Where an opening parenthesis is required, for example, ( , substitute it with \050, and for the closing parenthesis, for example, ) , substitute it with \051.

For example:

Take the following syntax:

function\(param1\)

You would substitute the previous syntax with the following syntax:

function\050param1\051
