Known Issue

iRules beginning with a number symbol (#), also referred to as a comment, may fail to load.

This issue occurs when the following conditions are met:

  • The iRule has an associated checksum
  • The BIG-IP configuration is loaded using the tmsh command

When iRules are saved into the bigip.conf file, the first line is automatically indented with four white space characters. Usually the system removes the white space characters when the configuration is loaded. However, when an iRule begins a commented line (using the # character), the system fails to remove the white space, and adds four additional white space characters after every subsequent configuration load. If a checksum is associated with the iRule, the configuration fails to load, and the system generates a checksum error message.

Impact

The BIG-IP configuration may fail to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP configuration may fail to load.
  • Your BIG-IP system generates an error message that appears similar to the following example:

    01071493:3: iRule (/Common/<iRule_name>) content does not match the checksum.
    Unexpected Error: Loading configuration process failed.

Workaround

To work around this issue, you can delete all commented lines in the beginning of the rule, or to move them after the event line and generate a new checksum. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Edit the /config/bigip.conf file and find the iRule that is failing to load.
  3. Delete the commented line, with number symbol at the beginning of the rule, or move it directly after the event line.
  4. Delete the definition-checksum line.
  5. Save the edited file.
  6. Enter the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  7. To load the configuration, type the following command:

    load sys config

  8. To generate a new checksum, type the following command:

    generate ltm rule <rule_name> checksum

    In this command, note the following:

    • <rule_name> is the name of the modified iRule
  9. To save the configuration, type the following command:

    save sys config
