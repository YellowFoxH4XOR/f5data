Known Issue

The BIG-IP system may compress chunked responses sent to the client. This issue occurs when all of the following conditions are met:

  • A virtual server is associated with an HTTP profile, HTTP Compression profile, and an Analytics profile.
  • The HTTP profile is configured with the Selective method for the Response Chunking option.

    Note: By default, the Response Chunking option is configured with the Selective method.

  • The affected virtual server receives HTTP chunked responses from its associated pool member.

Impact

The client may fail to properly render the content.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H379812 on the Diagnostics > Identified > Medium screen.
  • The client may incorrectly display the hexadecimal chunk sizes and the 0 last chunk indicator as part of the regular content.

Workaround

To work around this issue, you can configure the HTTP profile to use a method other than Selective for the Response Chunking option. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > HTTP.
  3. Click the name of the affected HTTP profile.
  4. Select a method other than Selective for the Response Chunking option.

    For example:

    Rechunk

  5. To save the changes, click Update.
