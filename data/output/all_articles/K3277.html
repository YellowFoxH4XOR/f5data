There is a format string vulnerability in the ssl_log() function of the mod_ssl module that could allow an attacker to potentially execute arbitrary code.

Information about this advisory is available at the following location:

http://www.kb.cert.org/vuls/id/303448

F5 Product Development tracked this issue and it was fixed in BIG-IP and 3-DNS version 4.5.11 and 4.6.2.

For instructions about downloading software from F5, refer to K167: Downloading software from F5.

A VU303448 patch has been issued for BIG-IP and 3-DNS versions 4.5 PTF-07 through 4.5.10, and versions 4.6 through 4.6.1. You can download the patch by navigating to the BIG-IP >> BIG-IP v4.x >> 4.5.x or 4.6.x section of the F5 Downloads site. You can find installation instructions in the VU-303448.txt file.
