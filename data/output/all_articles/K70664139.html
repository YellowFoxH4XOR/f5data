Issue

Error Message

014b0002:3: radius persist error <message>

In this error message, note the following:

  • <message> provides details of the specific error 

For example:

014b0002:3: radius persist error Illegal value

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • A RADIUS profile associated with a virtual server has the Persist Attribute setting configured.
  • You encounter an error when the BIG-IP system attempts to determine which persistence record should be used for the connection.

Impact

The BIG-IP system will load balance the RADIUS message, regardless of existing persistence records.

Recommended Actions

The BIG-IP system generates this message when it receives malformed RADIUS messages. Inspect the traffic sent from the client to determine if the messages are malformed and take appropriate actions to correct the issue.
