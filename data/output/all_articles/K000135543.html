Description

  • You are unable to log into either the BIG-IP Next console or the Central Manager console as the 'admin' user and F5 Support is asking you to gather information that can only be obtained via the console.

 
Environment

  • BIG-IP Next deployed from Central Manager, or deployed without using cloud-init to provision a user account 
    • This procedure also works for BIG-IP Next Central Manager if you forgot the admin password for the console.
  • You have the ability to interact directly with the VM console

 
Recommended Actions

Follow this procedure to set or reset the admin password.  You need to have the ability to access the VM console in your VM environment in order to do this.

From the VM console of a running BIG-IP Next VM, send Ctrl-Alt-Delete to reboot it


 
When the grub menu appears, press the escape key and then press the 'e' key

The boot options menu appears.  Use the down-arrow to move the cursor to the row that contains 'linux' in it

Press the end key to reach the end of that line.  In VMware you can use the backspace key to delete all the text leading up to the portion that says "ro" and change it to "rw init=/bin/bash".  In KVM you should change "ro" to "rw" and add " init=/bin/bash" to the end of the line, without deleting the other parameters.

This is what it will look like for VMware:

This is what it will look like for KVM (the line is highlighted yellow):

Press CTRL-X to exit.  The system will boot.

When you get to the terminal in single user mode, type 'passwd admin' and then set the admin password.



After you've set the password, type 'exec /sbin/init' to continue booting



Once the system has booted, you can log in as admin.
