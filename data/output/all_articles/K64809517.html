Description
Configuration load fails with and error similar to

Configuration error: Unable to modify the traffic group of self-ip (/Common/IP) because it is in use by application (/Common/MyApp.app/MyApp)

Environment

  • LTM with an iApp provisioned.

Cause
Despite the message the issue isn't with the iApp. There is a LTM Virtual Address (used by a Virtual Server) which is the same as a Self IP. This is not a error, however if they are on different Traffic Groups, that is an error.

Recommended Actions
  1. There is no way to fix this using the Configuration Utility as the Configuration has not loaded.
  2. Backup the /config/bigip-base.conf file
  3. Edit the bigip_base.conf to change the Self IP's Traffic Group. This may require adding another Self IP in traffic-group-local-only for that VLAN.
  4.  tmsh load sys config to load the updated configuration
