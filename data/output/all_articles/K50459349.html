Security Advisory Description

Buffer overflow in the XML parser in Mozilla Firefox before 38.0, Firefox ESR 31.x before 31.7, and Thunderbird before 31.7 allows remote attackers to execute arbitrary code by providing a large amount of compressed XML data, a related issue to CVE-2015-1283. (CVE-2015-2716)

Impact

An attacker with valid login credentials may be able to run arbitrary code.

Security Advisory Status

F5 Product Development has assigned ID 662850 (BIG-IP), ID 605579-6 (BIG-IQ), ID 642744 (Enterprise Manager), ID 644123 (F5 iWorkflow), and ID 528541 (ARX) to this vulnerability. Additionally, BIG-IP iHealth may list Heuristic H50459349 on the Diagnostics > Identified > Medium page.
