Known Issue

Configuring tunnels with unreachable endpoints may result in a memory leak.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured to use an IP tunnel.
  • The BIG-IP system does not have a route configured to reach endpoint IP addresses.

Impact

Performance may degrade over time and the Traffic Management Microkernel (TMM) may eventually become unresponsive due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system experiences decreased performance and instability.
  • The BIG-IP system fails to process traffic.

Workaround

To work around this issue, you can add a route to ensure that the BIG-IP system can reach the endpoint IP addresses. For more information about adding routes, refer to K13833: Managing static routes (11.x).
