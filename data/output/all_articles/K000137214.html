Type
Support Solution
Published

Updated

Applies to

  • BIG-IP LTM: 16.1.3, 16.1.4, 17.X.X, 17.1.X, 17.1.0, 17.0.X, 17.0.0
Source

Description

Upon adding new user, notice Log Manager exist and there is no description about what its privilege.

Environment

BIG-IP Version 16.1.3 or above

Cause

New feature- full description about Log Manager is not yet added to the help menu in the GUI

Recommended Actions

Review the chapter manual:

  • New Features in BIG-IP Version 16.1.3

A new Log Manager role allows users to view all configuration data on the system, similar to an Auditor role. Users with this role can modify the system log configuration settings, including creating log filters, destinations, and publishers, and have access to all partitions on the system.
