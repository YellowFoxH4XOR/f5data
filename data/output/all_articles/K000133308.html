Environment

  • F5OS-A 1.4.x or 1.5.x

 

Cause

ID1273861

 

Recommended Actions

Option 1:

Clean install should fix the issue.

 

Option 2:

Remove the CDB datafiles and reboot

Note: Below command will wipe all the configuration on the appliance, please save the configuration saved it in another place before performing the workaround.

You need to log in to F5OS as root and run:

rm -f /var/F5/system/cdb/*.cdb

reboot

After the system boots up, you will need serial console to configure a management IP address again.
