Description

When many certificates are expiring simultaneously, the system does not log expired or expiring certificates after the fifth message. Therefore, the system may not send a custom email alert as expected. After the first five certificate log messages, you see messages similar to the following in the /var/log/ltm file:

mcpd[2239]: 01070727:6: Per-invocation log rate exceeded; throttling.

In some scenarios, applying the workaround from article K14318: Monitoring SSL certificate expiration on the BIG-IP system (11.x - 16.x) doe not help to stop message throttling.
When this happens, /var/log/ltm does not lot certificate expiry log for all the certificates present on the system. 


Environment

  • Multiple certificates are expiring 
  • BIG-IP system is resuming log processing with 'Per-invocation log rate exceeded; throttling.' in /var/log/ltm
     

Cause

Due to very high number of expiring certificates on BIG-IP, more than five log messages or multiple messages with the same message ID were logged within a one-second interval which results in BIG-IP system resuming the log processing. 
 

Recommended Actions

You can refer any one of the below workarounds:
Create log publisher: 
To workaround this throttling issue, create another local log publisher and it should prevent against this limitation: 
  1. Browse to System > Logs > Configuration > Log Publishers
  2. Create a new log publisher
  3. Specify a log destination of "local-syslog"
  4. Browse to System > Logs > Configuration > Log Filters
  5. Create a new log filter.
  6. Set the Source as "tmsh"
  7.  Set the Message ID to 01070727. 

    Note: Replace above message ID with the message ID of 'Per-invocation log rate exceeded; throttling.' from /var/log/ltm. 

  8. Set the Log publisher to the one created in step 1. 
     

OR

Create a cronjob:
  1. Create a cronjob using below command:
    crontab -e
     
  2. Click 'i' to edit and add line "53 22 * * * /usr/bin/tmsh run sys crypto check-cert | logger -p local0.warning" at the end.
    It should look sometime like below:

    1-59/10 * * * * /usr/bin/diskmonitor
    0 */4 * * * /usr/bin/diskwearoutstat
    15 03 * * * /usr/bin/updatecheck -a
    15 03 08 * * /usr/bin/phonehome_upload
    0 */6 * * * /usr/bin/coreexpiration
    56 * * * * /usr/bin/copy_rrd save
    53 22 * * * /usr/bin/tmsh run sys crypto check-cert | logger -p local0.warning

    Note: Since this is a cronjob, you can change above min and hour fields to a suitable value for you to run the cronjob for certcheck.
     
  3. Test the throttling logs by running below command:
    tmsh run /sys crypto check-cert
     
  4. Check the ltm logs when the cronjob is running or when running the command:
    tail -f /var/log/ltm
