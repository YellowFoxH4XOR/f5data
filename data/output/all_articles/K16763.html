Known Issue

SAML metadata import leads to SSL configuration failure with Memory exhausted message.

This issue occurs when all of the following conditions are met:

  • You import SAML metadata into a BIG-IP APM SAML profile.
  • You then attempt to create or modify an SSL profile.

Impact

You are unable to create or modify SSL profiles.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to create or modify SSL profiles, the system logs an error message similar to the following example to /var/log/ltm:

    err mcpd[<pid>]: 01070313:3: Error reading cert PEM file /config/filestore/files_d/<partition>_d/certificate_d/:<partition>:<certificate name> for profile /<partition>/<ssl profile name>: Memory exhausted

Workaround

To work around this issue, you can recover from this condition by restarting the mcpd process. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you restart the mcpd process during a scheduled maintenance window. Restarting mcpd will temporarily impact traffic processing.

  1. Log in to the traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the mcpd process, type the following command:

    restart /sys service mcpd
