K000147261: How to configure Websockets correctly on F5 XC platform?

Published

Applies to

Source

Description

You want to configure the HTTP Load Balancer to work with Websockets.

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Cause

  • WebSockets generally do not work directly with HTTP/2 proxy servers because they are designed to work with HTTP/1.1.
  • The WebSocket protocol establishes a handshake using an HTTP/1.1 upgrade header to switch from an HTTP connection to a WebSocket connection.
  • Since HTTP/2 does not handle connection upgrades in the same way as HTTP/1.1, a WebSocket client cannot directly upgrade a connection through an HTTP/2 proxy.

Answer/Recommended Actions

In order to configure WebSockets correctly, you have to configure the Origin Pool to use only HTTP1.1 protocol.

You can find this option if you go to the configuration of the Origin Pool > Other Settings > Miscellaneous Options > Select HTTP/1.1
