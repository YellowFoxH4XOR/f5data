Description

When you want to modify an existing SSL profile setting in the BIG-IP Configuration utility, on the profile properties page, you select the Custom check box next to the SSL profile setting, change the setting value, and select Update to save the changes to the profile. To revert the setting to the value inherited from the parent profile, you clear the Custom check box for the setting and select Update.

However, if you select the Custom check box for the setting, modify the value, and clear the Custom check box before selecting Update, the BIG-IP system does not save the new value and automatically reverts to the value inherited from the parent profile. In this case, the BIG-IP system does not track the value of the modified profile setting and does not provide a warning. This behavior is by design. 

The following example illustrates the existing behavior:

  1. You log in to the Configuration utility.
  2. You go to Local Traffic > Profiles > SSL > Client.
  3. You select a ClientSSL profile to load its properties.
  4. Under Client Authentication, for Frequency you select the Custom check box.
  5. The value for Frequency is set to once, as inherited from its parent profile. You change the value by selecting always.
  6. You clear the Custom check box.
  7. You select Update to save the profile; however, Frequency reverts to the inherited value, once, and the system does not warn you that the value reverted.
