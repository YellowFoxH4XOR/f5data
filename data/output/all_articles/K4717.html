Known Issue

This is the result of a known issue. If you use the Setup utility, by running the config command, to make a configuration change after you have already configured BIG-IP or 3-DNS, the Setup utility may incorrectly change the interface media settings. If your interfaces are set to full duplex, the Setup utility may change them to half duplex.

F5 Networks recommends that you use the Setup utility only for initial configuration, not for configuration changes. If you must use the Setup utility on a configured system, verify that the interface media settings are correct after you use the Setup utility.

F5 Networks Product Development tracked this issue as CR34267 and CR42147.
