K000137879: How to enable BGP debug logging

Type
Support Solution
Published
2023-12-14
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000137879

Description

There are instances when debug logging needs to be done to monitor and troubleshoot problems related to BGP protocol from within ZebOS. This article provides the steps to define the destination log file and the commands to enable/disable BGP logging. Note that enabling debug logging will result in more verbose messages being written to disk.

Environment

  • BIG-IP
  • ZebOS
  • tmrouted

Cause

None 

Recommended Action

Define the destination log file.

To access the IMI Shell (imish), type the following command from Bash CLI: 
# imish
To enter enable mode, type the following command: 
# enable
To enter configuration mode, type the following command: 
# config terminal
To create the debug log file, type the following command: 
# log file /var/log/zebos.log
Exit configuration mode by typing the following command: 
# end
To write the configuration, type the following command: 
# write

Enable BGP debugging

After the debug log file is defined, enable debug logging by typing the following commands: 
# debug nsm all
# debug bgp all
# debug bfd all
To verify that BGP debug logging is enabled, type the following command: 
# show debug bgp

Disable BGP debugging

To disable BGP debugging, type the following commands: 
# undebug nsm all
# undebug bgp all
# undebug bfd all
