K29324748: Error message: RPC exception: Failed to verify checksum of the packet

Type
Support Solution
Published
2022-02-24
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.X, 14.0.X, 15.1.0, 15.0.1, 15.0.0, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 15.0.X, 16.0.1, 16.0.0, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 14.0.0
Source

Description
When using NTLM to authenticate users, you observe that the following message can be seen in the APM log files:

Jan  1 12:00:00 bigip.company err nlad[31392]: 01620000:3: <0x2af5affc0700> client[4]: DC[1.2.3.4]: schannel[1]: RPC exception: Failed to verify checksum of the packet
As a consequence, users fails to connect to the services.

Environment

  • You're using BIGIP APM;
  • The AccessProfile or the AccessPolicy is configured to authenticate users with NTLM
  • The NLAD daemon is not configured with the "-encrypt No" option (the configuration file is: /etc/bigstart/scripts/nlad)

Cause
This is due to the following bug: ID949477.

Recommended Actions

The suggested workaround is to:
  1. edit the file "/etc/bigstart/scripts/nlad"
  2. locate the line "exec /usr/bin/${service} -use-log-tag 01620000" (at the end of the file);
  3. append the option "-encrypt No" to that line. Such line now looks like: "exec /usr/bin/${service} -use-log-tag 01620000 -encrypt No";
  4. restart the NLAD daemon: (bash#) bigstart restart nlad

Additional Information
