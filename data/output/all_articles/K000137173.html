K000137173: About cron.daily error messages

Type
Support Solution
Published
2023-10-09
Updated
2025-09-17
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000137173

Description

You may find the following logs daily around 3am in /var/log/maillog and /var/log/cron after upgrading to V17.1.

In /var/log/maillog

err sSMTP[<PID>]: Unable to connect to "localhost" port 25.
err sSMTP[<PID>]: Cannot open localhost:25

In /var/log/cron

err anacron[<PID>]: Tried to mail output of job `cron.daily', but mailer process (/usr/sbin/sendmail) exited with ststus 1

Environment

• BIG-IP LTM

• Anacron

Cause

Bug ID 1366013

Recommended Actions

Follow below procedure:

1. Login to bash and use your preferred text editor to edit the file /etc/init.d/f5functions, we use vi

vi /etc/init.d/f5functions

2. Press "i" to enter edit mode  

3. Move the cursor to the line logger -p auth.notice -t "FIPS Integrity Check" FIPS is disable and comment out the following lines shown below:

#   logger -p auth.notice -t "FIPS Integrity Check" FIPS is disable
#   echo $"FIPS Integrity Check: FIPS is disable"
