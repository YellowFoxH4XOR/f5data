K000160747: Removal of Netscape Certificate Type Extension from BIG-IP LTM Certificates

Type
Support Solution
Published
2026-04-13
Updated
2026-04-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160747

Description

Certificates on BIG-IP LTM may contain the Netscape Certificate Type extension (OID 2.16.840.1.113730.1.1). This article clarifies that this extension is not required and can be safely removed when re-signing certificates.

Environment

  • Product: BIG-IP LTM
  • Version: 17.5.1
  • TLS Versions: 1.2 and 1.3
  • Scenario: Certificates on BIG-IP LTM contain the Netscape Certificate Type extension and are being considered for re-signing without this extension.

Cause

None

Answer/Recommended Actions

  • The Netscape Certificate Type extension is not required by BIG-IP LTM.
  • BIG-IP LTM does not evaluate or depend on this extension for:
    • SSL/TLS profile processing
    • Device certificate authentication
    • Device Service Clustering (DSC) trust operations
  • It is safe to remove the Netscape Certificate Type extension from certificates when re-signing them.
  • No functional impact is expected on BIG-IP LTM operation after removal of this extension.

Additional Information

  • The Netscape Certificate Type extension is a legacy feature from the late 1990s and is not relevant to modern TLS protocols or BIG-IP LTM functionality.
  • The standardized Extended Key Usage (EKU) extension, as defined in RFC 5280, has replaced the need for the Netscape Certificate Type extension.
