Known Issue

Software auto update schedule settings are not synchronized to other members within the synchronization group.

This issue occurs when all of the following conditions are met:

  • Multiple BIG-IP systems are configured within a synchronization group.
  • You perform a full system synchronization.
  • Each system in the synchronization group has different auto-update settings.

Impact

This issue can lead to software auto update settings being inconsistent across devices within the synchronization group.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Software auto update settings are not synchronized between devices in a synchronization group.

Workaround

To work around this issue, you can manually set the Update Check settings on each system within the synchronization group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management > Update Check.
  3. Change the listed settings to match those of the other system.
  4. To save the changes, click Apply Settings.
