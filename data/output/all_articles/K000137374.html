K000137374: After upgrading BIG-IP APM connections are being reset randomly

Type
Support Solution
Published
2023-10-26
Updated
2024-01-17
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000137374

Description

After upgrading BIG-IP APM to 15.1.10, client connections get reset randomly.

  • HA connection between peers may also flap.
  • TMM memory usage starts gradually increasing with no apparent increase in number of connections.
  • Connections are being killed by adaptive connection reaper indicated by log line "Aggressive mode sweeper ..... n Connections killed"

Environment

  • BIG-IP APM provisioned
  • Edge client is being used extensively.

 

Cause

This is due to a known bug ID1355117

 

Recommended Actions

There is no workaround for this bug. ID1355117 is fixed beginning with v15.1.10.3. Upgrade to the latest fix version of v15.1.x

 

Additional Information

Reviewing tmctl snapshots in a QKView or on the BIG-IP will show filter memory increasing over time:
