Description

ASM triggers the "illegal parameter value length" violation, even when the number of characters in the parameter is not longer than the defined value

Environment

  • ASM security policy
  • Parameter with a value length defined (For example: 10)
  • Request contains a parameter with 10 character and one or more of the character are for example ( "à" or "é" )

Cause

Seen behaviour is expected. The parameter value length corresponds to the number of bytes, not the number of characters. Unicode characters like à and é, are 2 bytes in length.

Recommended Actions

If required you can consider increase the parameter value length to allow such requests

  1. On GUI go to Security > Application Security > Parameters > Parameters List
  2. Click on the parameter in question
  3. On Maximum Length set the new value
  4. Click Update
  5. Click Apply Policy
