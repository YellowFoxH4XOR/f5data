Description

Exporting ASM event logs as PDF may result in error "Export failed".
Eventually, PDF file is created but it may not include all specified events.

Environment

  • BIG-IP ASM 

Cause

To create PDF, /var/ts/dms/common/classes/fpdf/tfpdf.php is invoked behind the Web UI.
It seems tfpdf is taking time to parsing/escaping strings and so it reaches the max_execution_time then aborted.

Recommended Actions

Try to increase max_execution_time of php.
max_execution_time is the number of seconds a script is allowed to run before it is terminated. (Default 30 seconds)

# mount -o remount,rw /usr
# vim /usr/local/lib/php.ini

 max_execution_time = 180

# mount -o remount,ro /usr
# bigstart restart httpd
