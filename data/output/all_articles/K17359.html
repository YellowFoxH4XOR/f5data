Known Issue

BIG-IP APM application tunnels may be removed from the webtop when DNS resolution fails for a resource.

This issue occurs when all of the following conditions are met:

  • The application tunnel configuration includes multiple resource items.
  • The host name for one of the resource items is unresolvable using DNS.

Impact

Users cannot access the application tunnel on the BIG-IP APM webtop.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP APM webtop fails to display configured application tunnel resources.
  • Application tunnels become unavailable, even though there are associated resource items resolvable using DNS.
