When BIG-IP ASM Learning Mode is set to Manual or Automatic, some modifications are made to the (*) wildcard entities, such as wildcard * URL, wildcard * parameter, and so on.

The following tables outline the expected changes based on policy configuration.

Cookies configuration

Signature sets configurationChanges to wildcard "*" cookie
Any signature set has Learning set to Enabled
  • Attack Signatures Check will be set to Enabled
  • Perform Staging will be set to Enabled
All signature sets have Learning set to Disabled
  • Attack Signatures Check will be set to Disabled
  • Perform Staging will be set to Disabled

Filetypes configuration

Violation configurationLearn New File Types modeChanges to wildcard * file type
Not applicableAlways
  • Perform Staging is set to Enabled
  • URL Length is set to Any
  • Request Length is set to Any
  • Query String is set to Any
  • POST Data Length is set to Any
Learning is set to Enabled in any of the following:
  • Illegal query string length
  • Illegal request length
  • Illegal POST data length
  • Illegal URL length
Selective/Compact/Never
  • Perform Staging will be set to Enabled
  • URL Length will be set to 100 (or previously set length limit)
  • Request Length will be set to 5000 (or previously set length limit)
  • Query String will be set to 1000 (or previously set length limit)
  • POST Data Length will be set to 1000 (or previously set length limit)
Learning is set to Disabled in all of the following:
  • Illegal query string length
  • Illegal request length
  • Illegal POST data length
  • Illegal URL length
Selective/Compact/Never
  • Perform Staging will be set to Disabled
  • URL Length will be set to Any
  • Request Length will be set to Any
  • Query String will be set to Any
  • POST Data Length will be set to Any
