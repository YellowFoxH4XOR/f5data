K15572588: Do not use hyphen character in F5 SSL Orchestrator object names

Type
Support Solution
Published
2019-09-11
Updated
2023-02-21
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 15.X.X, 15.1.X, 15.0.X, 14.1.X, 14.0.X, 15.1.1, 15.1.0, 14.X.X, 14.1.4, 14.1.2, 14.1.0, 14.0.0, 15.0.0
Source
https://my.f5.com/manage/s/article/K15572588

Description

When configuring SSL Orchestrator topology and related objects, do not use the hyphen (-) character in the names of the object.  You can use underscore (_) character instead.  For example, use my_proxy instead of my-proxy.  

If you use the hyphen character in SSL Orchestrator object names, depending on your topology, it can produce unexpected error.  For example, in the case of explicit proxy topology, you may encounter an error similar to the following when you try to access a http site (not https):

01220001:3: TCL error: /Common/sslo_my-proxy.app/sslo_my-proxy-xp <HTTP_PROXY_REQUEST> - unable to find virtual '/Common/sslo_my-proxy.app/sslo_my-in-t-4' (line 1)     invoked from within "virtual "${mypfx}-in-t-[IP::version]" $addr $port"

In this specific example, the actual virtual service is /Common/sslo_my-proxy.app/sslo_my-proxy-in-t-4 and not /Common/sslo_tgt-proxy.app/sslo_my-in-t-4.

Environment

  • F5 SSL Orchestrator 14.0.0-4.x through 15.0.0-6.x
  • Hyphen is used in the names of the SSL Orchestrator configuration objects.

Cause

The root cause of this error is irule parsing issue.

Recommended Actions

Avoid using the hyphen character in the names of the SSL Orchestrator configuration objects, use the underscore character if needed.
