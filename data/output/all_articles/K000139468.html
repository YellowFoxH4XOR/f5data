F5 NGINX is announcing the End of Sale (EoS) for existing NGINX Instance Manager SKUs, effective October 1, 2024. This applies to SKUs containing F5-NGX-IM. Customers can get NGINX Instance Manager as a part of the NGINX Open-Source Subscription bundle or NGINX Connectivity Stack for Kubernetes bundle.

This notice applies to the following product SKUs.

Technical Support

F5 maintains generous lifecycle policies that allow customers to continue support and receive product updates. Existing NGINX Instance Manager customers can continue to consume the product past the EoS date.
