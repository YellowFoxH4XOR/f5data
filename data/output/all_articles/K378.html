K378: Forcing a BIG-IP or 3-DNS redundant pair to fail over

Topic

Although commands exist to force a BIG-IP or 3-DNS from standby mode to active mode, F5 Networks recommends that you do not use them, as it can cause both systems in a redundant pair to become active simultaneously.

The correct way to force a failover is to change the active system to standby mode. When the active system is in standby mode, the peer system will become active.

You can force a failover from the Configuration utility or the command line.

Forcing a failover using the Configuration utility

To force a system failover using the Configuration utility perform the following steps:

  1. From the Configuration utility, click Systems.
  2. Click the Redundant Properties tab.
  3. Click the Force Standby button.
  4. Click OK.

Forcing a failover using the Command line

To force a system failover from the command line, type the following version-specific command:

  • BIG-IP versions 2.1 through 4.6.4, and 3-DNS version 4.0 through 4.6.4:

    bigpipe failover standby

  • BIG-IP versions 1.8.3 through 2.0.4, and 3-DNS version 1.0.3 through 2.1.2:

    bigpipe fo slave

Forcing a system into active mode

For versions 2.1 through 3.3.1 PTF-06, a command is available to force a system from standby mode to active mode. Although F5 Networks does not recommend this method in normal circumstances, it may be required in rare instances (for example, due to an as yet undiscovered and unforeseen issue with your system).

Before using the command to force a standby system into active mode, you must have attempted all of the following:

  • Issued the bigpipe failover standby command on the currently active system
  • Attempted to reboot the currently active system
  • Powered down the currently active system

If you have attempted all of these procedures and the system has still not failed over, it indicates that there is an unknown issue with your system. In this situation, you can run the following command to try to force the standby system into active mode:

bigpipe failover active

Running this command may make the standby system active, although the previous attempts should already have resulted in an active system. Even if the bigpipe failover active successfully fails over your system, you must contact F5 Technical Support to have the issue further examined.
