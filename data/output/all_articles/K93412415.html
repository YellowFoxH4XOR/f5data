Description

  • Transfer Timeout when bigip.conf file is sent to TFTP server
  • File size on TFTP server is 0 Bytes
  • 1 out of 10 transfer is transferred successfully

Environment

  • Command used: tftp server_ip -c put bigip.conf bigip.conf
  • Route to the TFTP server is set through self-ip which is not management-ip
  • Port lockdown is set as "allow all" on used self-ip
  • Ping is successfull  BIG-IP <-> TFTP server
  • UDP/69 is allowed between BIG-IP <-> TFTP server

Cause

TFTP is dropped when using non management-port.

Recommended Actions

Use management port while using TFTP protocol to sent .conf file

  1. Make sure to use route through management-ip
  2. Use command to send .conf file:
    tftp tftp_server_ip -c put bigip.conf bigip-$(date +%Y-%m-%d_%H-%M-%S).conf
     

Additional Information
You may need to configure route to TFTP server through management interface:
   tmsh create sys management-route <name> network <tftp-server-ip>/32 gateway <management-gateway>

Example:
  tmsh create /sys management-route tftpServer network 1.1.0.1/32 gateway 10.1.0.145
