Security Advisory Description

The BIG-IP system is vulnerable to a denial-of-service (DoS) attack when performing URL classification. (CVE-2019-6610)

Impact

A remote attacker may be able to disrupt services by causing the Traffic Management Microkernel (TMM) to restart. There is no exposure in the control plane.

Security Advisory Status
