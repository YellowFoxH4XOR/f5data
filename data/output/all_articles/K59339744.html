The following list represents characters and words that should not be used when defining BIG-IP DNS (formerly known as BIG-IP GTM) object names.

Description

BIG-IP DNS profiles

  • all
  • delete
  • disable
  • enable
  • help
  • list
  • None
  • none
  • show

Custom characters for BIG-IP DNS

Custom characters are allowed with the following exceptions:

  • double quote (")
  • open curly brace ({)
  • end curly brace (})
  • control characters (for example "^M")
  • ampersand (&)
  • colon (:)

The object name must start with an alphabetic character or underscore.
