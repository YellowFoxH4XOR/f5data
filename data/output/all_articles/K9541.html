Note: For information about the X-PvInfo header information, refer to the Viewing X-PvInfo response headers section of the Using HTTP Headers chapter in the BIG-IP WebAccelerator Policy Management Guide. 

The C code is the second field of the X-PvInfo header, and it indicates the number of the application policy that was applied to the request. In the example below, the C code is C22773:

X-PvInfo: [S10203.C22773.A1789.RA0.G1ACD.U7D464AE1].[OT/html.OG/pages]

The C code corresponds to the value of the policyInstance id parameter in the application policy's XML file. The C code (policyInstance id) is not directly displayed in the Configuration utility. However, you can determine the C code value for an application by using the Configuration utility. The C code value is equal to the application's recId plus 1. You can view the application's recId by clicking on the link to an application. The application's recId is located at the end of the URL for the link to the application.

For example, the URL for the link to an application appears similar to the following:

https://172.24.68.30/waui/edit_application.do?recId=22772

You can determine the corresponding C code for the application by adding 1 to the recId value. The C code for this application is C22773.
