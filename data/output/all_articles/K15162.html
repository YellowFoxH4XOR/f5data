Known Issue

Adding an IPv6 link-local self IP address to a Virtual Local Area Network (VLAN) may fail.

This issue occurs when one of the following conditions is met:

  • You attempt to create an IPv6 link-local self IP address using %vlan notation.

    For example:

    tmsh create net self ext-v6-link-local address fe80:0:0:0:0:0:0:12%vlan60/64 vlan ext

  • You attempt to create an IPv6 link-local self IP address by specifying the VLAN ID in the second group of the IPv6 address.

    For example:

    tmsh create net self ext-v6-link-local address fe80:3c:0:0:0:0:0:12/64 vlan ext

    Note: 3c is the hex value of the VLAN ID 60 that was added to the second group of the IPv6 link-local address using the big endian byte ordering scheme.

  • You attempt to use the same IPv6 link-local self IP address on more than one VLAN.

In certain configurations, you may want to use the same IPv6 link-local self IP address on multiple VLANs. You could previously accomplish this by appending the VLAN ID to the self IP address using the %vlan notation, or by adding the hex value of the VLAN ID to the second group of the IPv6 link-local addresses using the big endian byte ordering scheme. However, due to this issue, you cannot use either method when creating the IPv6 link-local self IP address using the Configuration utility or Traffic Management Shell (tmsh).

Impact

You are unable to create an IPv6 link-local self IP address, or add an IPv6 link-local self IP address to more than one VLAN.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe an error message similar to the following example when you attempt to create an IPv6 link-local self IP address using the %vlan notation, or when you specify the VLAN ID in the second group of the IPv6 address:

    The Self IP address (<IPv6-addr><%vlanID>) is not a valid IPv6 link local address (see RFC 4291 - Section 2.5.6)

  • You observe an error message similar to the following example when you attempt to create an IPv6 link-local self IP address on a VLAN using an IPv6 link-local self IP address that exists on another VLAN:

    Invalid self IP, the IP address fe80::1 already exists

Workaround

To work around this issue, you can initially create the IPv6 link-local self IP address using the Configuration utility or tmsh utility. After you create the initial self IP, you can edit the bigip_base.conf file, manually add the %vlan notation, and then reload the configuration. To do so, perform the following procedure:

Impact of workaround: You will not be able to subsequently modify the IPv6 link-local self IPs using either the Configuration utility or the tmsh utility.

  1. Log in to the command line.
  2. Create the IPv6 link-local self IP address by using the following command syntax:

    Note: If the self IP address has already been created, proceed to the next step.

    tmsh create /net self <self-IP-name> address <IP-addr/mask> vlan <VLAN-name> allow-service <options>

    For example, to create a self IP with address fe80::12/64 on the VLAN ext, type the following command:

    tmsh create /net self ext-v6-link-local address fe80::12/64 vlan ext allow-service none

  3. Save the configuration by typing the following command:

    tmsh save /sys config
  4. Make a backup copy of the /config/bigip_base.conf file by typing the following command:

    cp -p /config/bigip_base.conf /var/tmp/bigip_base.conf.sol15162

  5. Edit the /config/bigip_base.conf file using a text editor of your choice.
  6. Locate the self IP stanza for the IPv6 link-local address that you previously added.

    For example, if you have created an IPv6 link-local self IP address on VLAN ext named ext-v6-link-local, the stanza appears similar to the following example:

    net self /Common/ext-v6-link-local {
    address fe80::12/64
    traffic-group /Common/traffic-group-local-only
    vlan /Common/ext
    }

  7. Edit the stanza, and add the %vlan notation to the address.

    For example, if your vlan ID is 60, you would append %vlan60 to the fe80::12 address, as follows:

    net self /Common/ext-link-local {
    address fe80::12%vlan60/64
    traffic-group /Common/traffic-group-local-only
    vlan /Common/ext
    }

  8. Save your changes and exit the text editor.
  9. Reload the BIG-IP configuration by typing the following command:

    tmsh load /sys config

  10. To create additional self IP addresses, repeat steps 2 through 8.
