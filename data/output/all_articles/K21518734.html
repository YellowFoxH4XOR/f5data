Description

Neighbor soft or hard reset is required to allow route-map filter to be effective to allow/deny routes in BGP outbound update.
This is expected behaviour in BIG-IP Zebos module, however, soft reset doesn't work when route-map is updated to allow/deny the routes.
Same applies to redistributed default route but it is bit different for default route generated by 'neighbor x.x.x.x default-originate' command.

Route BGP configuration example:

 router bgp 65000
bgp graceful-restart restart-time 120
neighbor 10.85.33.226 remote-as 65000
neighbor 10.85.33.226 default-originate
neighbor 10.85.33.226 soft-reconfiguration inbound
neighbor 10.85.33.226 route-map test out

Peer will shows default route in BGP table.

BGP table version is 3, local router ID is 10.85.33.226
Status codes: s suppressed, d damped, h history, * valid, > best, i - internal, l - labeled
              S Stale
Origin codes: i - IGP, e - EGP, ? - incomplete

   Network          Next Hop            Metric     LocPrf     Weight Path
*>i0.0.0.0/0        10.85.33.225             0        100          0 i

Now, soft-reset is performed in local BIG-IP.

#clear ip bgp 10.85.33.226 soft out

Now peer doesn't show that default route in BGP table. In this repro, it show nothing there is no other routes in BGP table.

#show ip bgp

Recommended Actions

Use 'default-originate' to generate the default route instead of using command 'network 0.0.0.0' or redistributing static or kernel routes.

  1. Go to 'imish' shell of your respective route-domain, In this example it is 'RD0'

    #imish

  2. Enter privileged mode by entering the following command:

    #enable

  3. Go to config mode:

    #config t

  4. Go to BGP configuration mode:

    (config)#router bgp 65000

  5. Generate and send default route to specific neighbor. Use the following syntax to inject the IPv4 or IPv6 default route in BGP table:

    (config-router)#neighbor <IPv4 or IPv6 addr> default-originate

    For example,

    (config-router)#neighbor 10.85.33.226 default-originate

  6. Apply route-map to allow/deny default route to specific neighbor by using the following syntax:

    (config-router)#neighbor <IPv4 or IPv6 addr> route-map test out

    For example,

    (config-router)#neighbor 10.85.33.226 route-map test out
