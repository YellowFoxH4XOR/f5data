Known Issue

This is most likely the result of a known issue. If you change the self IP address of a 3-DNS system by using the Configuration utility or editing the bigip_base.conf file, two associated database records are not changed. The database records are used for communication between members of a redundant pair, and operations such as the configsync command, may fail if you do not update the records.

To update the database records, perform the following steps:

  1. Log in to the command line.
  2. Set the FSSL Host address, by typing the following command:

    bigpipe db set Local.Bigip.CORBA.FSSLHost = <address>

    Replace <address> with the new 3-DNS self IP address.

  3. Set the IIOP Host address, by typing the following command:

    bigpipe db set Local.Bigip.CORBA.IIOPHost = <address>

    Replace <address> with the new 3-DNS self IP address.

The configsync process should now work properly.
