Topic

The VPN On-Demand feature seamlessly establishes a connection to the BIG-IP APM system when a client application attempts to access a system that is defined in an On-Demand Always Connect domain list. VPN On-Demand disconnects under the following conditions:

  • Upon entering sleep mode
  • When the connection remains idle and reaching the idle timeout value, 120 seconds (default)

Upon entering sleep mode

To conserve battery power, the iOS device enters sleep mode if there is no activity. There are many factors that are device controlled that can influence whether the device enters sleep mode. After entering sleep mode, VPN On-Demand is not active. If an application or service tries to access a system that requires the VPN On-Demand connection, such as retrieving email, the connection fails. After the iOS device becomes active, VPN On-Demand resumes.

Note: If the screen turns off, this does not indicate that the device is in sleep mode. There is no external indication whether or not the phone is in sleep mode.

When the connection is idle reaching the idle timeout value

If VPN ON-Demand does not detect activity for the idle timeout value (120 second default) it disconnects the connection. The connection automatically reestablishes when activity is detected.
