Known Issue

Reconfiguring a security policy may trigger the BIG-IP ASM system to gracefully restart.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system has a virtual server configured with a security policy.
  • You simultaneously modify the security policy and remove the same security policy from the virtual server configuration. 

Impact

The BIG-IP ASM system temporarily stops processing traffic and gracefully restarts. Systems configured for high availability (HA) may fail over to a peer device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When the condition is triggered, the system logs messages to the /var/log/ltm file that appear similar to the following example:

    notice mcpd[<pid>]: 01070406:5: Removed publication with publisher id bd
    warning sod[<pid>]: 01140029:4: HA proc_running bd fails action is go offline and down links.

  • When the condition is triggered, the system logs messages to the /var/log/ts/bd.log file that appear similar to the following example:

    IO_PLUGIN|NOTICE|MMM DD HH:MM:SS.s|<pid>|io_plugin.c:0565|In io_plugin_config_update profile_name=/Common/pluginasm
    IO_PLUGIN|NOTICE|MMM DD HH:MM:SS.s|<pid>|io_plugin.c:0565|In io_plugin_config_update profile_name=/Common/pluginasm
    IO_PLUGIN|CRIT  |MMM DD HH:MM:SS.s|<pid>|io_plugin.c:0675|tm_init failed
    New ALL module: ALL
    New ALL level: TS_ERR
    New ALL level: TS_CRIT
    New ALL level: TS_WARNING
    New ALL level: TS_NOTICE

    BD_MISC|NOTICE|MMM DD HH:MM:SS.s|<pid>|main.c:0929|Version info from /VERSION.LT

Resolution

Status

F5 Product Development has assigned ID 644725 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can execute the configuration changes while leaving sufficient time between changes for each change to complete prior to executing the next configuration change.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
