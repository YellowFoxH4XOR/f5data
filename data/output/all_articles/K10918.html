Known Issue

This is the result of a known issue. When multiple shadow copy rules are configured for a single VPU domain, and more than four rules are executed simultaneously, some of the copy rules may fail with a handshake timeout error message that appears similar to the following example:

Connection to target failed to establish; Handshake timeout

F5 Networks Product Development tracked this issue as ARX ID 34430 and it was fixed in ARX version 5.1.0. For information about upgrading, refer to the ARX Release Notes.
