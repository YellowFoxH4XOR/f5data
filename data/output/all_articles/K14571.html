Known Issue

Connections to a Proxy SSL-enabled virtual server may fail.

This issue occurs when all of the following conditions are met:

  • You have enabled Proxy SSL on the Client and Server SSL profiles associated with the affected virtual server.
  • You use the TLS version 1.1 or 1.2 protocol to negotiate the SSL handshake.

Impact

Clients are not able to establish SSL connections through the Proxy SSL feature.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H425811 on the Diagnostics > Identified > High screen.
  • SSL handshakes will fail when the client requests to use the TLS 1.1 or TLS 1.2 protocol through the Proxy SSL-enabled virtual server.
  • When the log.ssl.level database key is set to debug, the BIG-IP system logs the following error messages:
    • BIG-IP 11.3.0

      debug tmm4[9751]: 01260009:7: Connection error: ssl_hs_pxy_scan:7118: unavailable protocol (70)
      debug tmm4[9751]: 01260009:7: Connection error: ssl_hs_pxy_scan:6834: unknown protocol (70)
      info tmm4[9751]: 01260013:6: SSL Handshake failed for TCP from ss-client-ip:ss-client-port to pool-member:443
      info tmm4[9751]: 01260013:6: SSL Handshake failed for TCP from client-ip:client-port to virtual-server:443

    • BIG-IP 11.0.0 through 11.2.1

      debug tmm[7490]: 01260009:7: Connection error: ssl_hs_pxy_scan:5961: unsupported protocol (40)
      info tmm[7490]: 01260013:6: SSL Handshake failed for TCP from client-ip:client-port to virtual:port
      debug tmm[7490]: 01260009:7: Connection error: ssl_hs_pxy_scan:5961: unsupported protocol (40)

    For more information about setting the database key to enable the related logs for symptom observation, refer to K13455: Overview of BIG-IP logging BigDB database keys (11.x).
