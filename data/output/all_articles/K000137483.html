K000137483: BIG-IP after hotfix update or reboot cannot sync due to FIPS error

Type
Support Solution
Published
2023-11-07
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000137483

Description

FIPS card is not operational after a reboot or an upgrade. You will see the following error message in the ltm log.

err mcpd[XXXXX]: 01b50048:3: FipsUserMgr Error: An internal login failure is being experienced on the FIPS card. Please issue 'fipsutil loginreset -r' followed by 'bigstart restart' for a password reset. You will need your FIPS Security Officer password to reset the password..

Environment

  • BIG-IP FIPS
  • Upgrade
  • Reboot

Cause

FIPS fails to load it's config

Recommended Actions

Run the following commands

  1. # fipsutil loginreset -r
  2. # bigstart restart 

You will need your FIPS Security Officer password to reset the password.

Additional Information

None
