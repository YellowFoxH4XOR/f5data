Description

You have configured BIG-IP ASM Attack Signature Live Updates to be downloaded via a proxy, however it is not working.

When you do a curl to either activate.f5.com or callhome.f5.com from the BIG-IP, it is failing with a 403 Forbidden error:

> GET / HTTP/1.1
> Host: callhome.f5.com
> User-Agent: curl/7.47.1
> Accept: */*
>
< HTTP/1.1 403 Forbidden
< Connection: close
< Content-Type: text/html; charset=UTF-8
< Cache-Control: no-cache
< Date: Fri, 14 Oct 2022 11:12:48 GMT
<

Environment

  • ASM Live Updates
  • proxy

Cause

The most likely reason for the 403 Forbidden error is that the proxy server requires some form of authentication

Recommended Actions

Configure the following db variables:

 # tmsh modify sys db proxy.username value <username>
 # tmsh modify sys db proxy.password value <password>
