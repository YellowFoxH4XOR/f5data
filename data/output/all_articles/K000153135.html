K000153135: Unable To Receive Reset Password Email Due To Error 400 Bad Request

Type
Support Solution
Published
2025-08-22
Updated
2025-08-22
Applies to
  • F5 Distributed Cloud Services
Source
https://my.f5.com/manage/s/article/K000153135

Description

When creating a new user in the F5 Distributed Cloud Console, invitation or password reset emails may not be received. Attempts to reset the password for such users result in the following error message:

Http failure response: 400 Bad Request password reset not allowed for users in 'StateCreateFailed' state

This issue is triggered when special characters—specifically parentheses—are included in the user's display name during creation.

Environment

  • Product: F5 Distributed Cloud

Cause

The user creation process fails if unsupported special characters (such as parentheses) are present in the display name or other input fields. This leaves the user account in a 'StateCreateFailed' state, which blocks delivery of invitation and password reset emails and prevents further password management actions.

Recommended Actions

  • Do not use parentheses or other unsupported special characters in user display names or input fields when creating users.
  • If a user is stuck in 'StateCreateFailed', delete that user and recreate it without using special characters.
  • Ensure that email delivery from F5 sender domains (such as us-east-2.amazonses.com) is permitted by your mail system and not blocked by spam filters or firewalls.
  • If these steps do not resolve the issue, collect relevant error messages and screenshots showing the user state, then contact F5 Support for further assistance.

Additional Information

A feature request has been submitted to display a warning message when unsupported characters, such as parentheses, are used in user display names during account creation.
