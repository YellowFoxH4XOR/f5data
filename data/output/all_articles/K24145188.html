Description

You may want to disable DNSSEC temporarily in a validating resolver DNS cache configuration.

Environment

  • BIG-IP DNS
  • Validating resolver DNS cache
  • DNS query may fail against a specific Domain.

Cause

To troubleshoot a DNS query issue, you may disable DNSSEC temporarily in a validating resolver DNS cache configuration.

Recommended Actions

To disable DNSSEC temporary in a validating resolver DNS cache configuration, you can delete Trust Anchors in an existing validating resolver DNS cache configuration following.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > Caches > Cache List.
  3. Click name of Validating Resolver you want to edit
  4. Click the Trust Anchors tab.
  5. Click All Anchor
  6. Click Remove
  7. Log in to the command-line interface of the BIG-IP system.

In addition, you may want to clear specific records from a validating resolver cache for testing purpose. For example you can delete all RRSET records or only the records in the specific cache.

In tmsh, you can use the command completion feature to discover the types of records that are available for deletion.

At the shell prompt, use the following tmsh commands:

Following example deletes all rrset, nameserver, key, and msg records in a validating resolver cache.

tmsh delete ltm dns cache records rrset cache <validating resolver cache profile name>
tmsh delete ltm dns cache records nameserver cache <validating resolver cache profile name> 
tmsh delete ltm dns cache records key cache <validating resolver cache profile name>
tmsh delete ltm dns cache records msg cache <validating resolver cache profile name>
