K000091551: How to verify nginx-repo.cert validity before pulling or building Nginx Plus image

Type
Support Solution
Published
2022-05-05
Updated
2022-05-05
Source
https://my.f5.com/manage/s/article/K000091551

Description

  • You want to build your own Ingress Controller image using Nginx source code following Building the Ingress Controller Image
  • For NGINX Plus, you would to have a valid NGINX Plus license as well as valid subscription to successfully complete building the image.
  • Before you start the build process, you would need to
    • verify if the Nginx.repo.crt is valid
    • verify you are using a valid certificate from the right and valid subscription by refer

 Environment

  • Nginx Ingress Controller Image
  • NGINX Plus

 Cause

  • none

 Recommended Actions

  • Use the below openSSL command to print human readable details of the certificate

openssl x509 -in <path to nginx-repo.crt> -text -noout

  • You would see an output like the below, confirm cert validity as well as that the cert is of the right subscription

check


Validity

Not Before: Feb 19 11:19:46 2021 GMT

Not After : Feb 19 00:00:00 2023 GMT <--- valid date

Subject: CN = F5-A-S00012345 <--- check if subscription is also valid


  • if there is a mismatch, please download fresh cert/key from your myF5 portal https://account.f5.com
