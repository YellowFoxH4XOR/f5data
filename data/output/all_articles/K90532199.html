K90532199: False positives for attack signatures 200018023 and 200018029

Type
Support Solution
Published
2020-10-07
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K90532199

Description

You receive false positive violations for legitimate traffic, due to attack signatures:

ID 200018023

ID 200018029

Environment

  • Attack signatures

Cause

An older revision of these attack signatures may be in use, which were quite prone to false positives. Older versions can typically be found in attack signatures included with the software ISO for your version.

For example, the default install from the 13.1.1.5 ISO does not include the latest revisions for these signatures.

Recommended Actions

Verify that you have the latest attack signature update from F5 installed. If using Signature Staging, ensure the signatures are Enforced after installing the update.

If false positive violations still occur and you are unable to determine why, you may consider disabling the attack signatures for the entity in question, or opening a service request with F5 Support for further investigation.
