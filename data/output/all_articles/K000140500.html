Description

The DNS Express responds to a non-existent record with a NOERROR response instead of with a NXDOMAIN response.

 

Environment

  • BIG-IP
  • DNS Express
  • NOERROR instead of NXDOMAIN

Cause

Unknown

Recommended Actions

Clear the DNS Express db to trigger fresh zone transfer:

 

bigstart stop zxfrd

rm -rf /shared/zxfrd/*

bigstart start zxfrd
