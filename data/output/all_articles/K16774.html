Known Issue

A BIG-IP APM system configured as a Security Assertion Markup Language (SAML) service provider (SP) fails to validate a signed assertion from an IBM Tivoli Federated Identity Manager.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP APM system as a SAML SP, and you configure the SAML SP service to require signed SAML assertion.
  • You configure the IBM Tivoli Federated Identity Manager as a SAML Identity Provider (IdP).
  • The BIG-IP APM SAML SP receives a signed SAML assertion from the IBM Tivoli Federated Identity Manager.

Impact

The BIG-IP APM system fails to verify the signed SAML assertion, causing the authentication to fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP SAML SP system is unable to process signed SAML assertions.
  • In the /var/log/apm file, you observe messages similar to the following example:

    failed to process signed assertion, error: Digest of SignedInfo mismatch
