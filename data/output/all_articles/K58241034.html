Issue

Description

BIG-IP DNS is showing a virtual server as available that is marked down on a BIG-IP LTM, when the iQuery connection between the devices is working properly.

Environment

  • BIG-IP DNS system's LTM server object is using virtual server discovery
  • Discovered two of the same IP:PORT virtual servers, but with different protocols (TCP and UDP)
  • BIG-IP DNS shows both virtual servers as marked up
  • BIG-IP LTM shows one virtual server marked up, and one virtual server marked down

Cause

BIG-IP DNS is not aware of protocol on the virtual servers and marks both as up if only one is up on the LTM. This is a result of Bug ID 646491.

Recommended Actions

To work around this issue, you can manually define the virtual server names via the ltm-name setting. To do so, perform the following procedure:

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Modify the affected server objects by typing the following commands:

    modify gtm server gtm_myself virtual-servers modify { /Common/vs1_tcp { ltm-name vs1_tcp }}

    modify gtm server gtm_myself virtual-servers modify { /Common/vs1_udp { ltm-name vs1_udp }}

  3. Save the configuration by typing the following:
    save sys config
