K5089: A BIG-IP LTM SNAT may reuse a source port before the destination server TIME_WAIT state expires

Topic

In certain configurations, a BIG-IP LTM system may reuse a source port for a SNAT connection. BIG-IP LTM preserves the origin server source port of a SNAT connection. An origin server can be configured to use a limited number of source ports for an application, which enables it to reuse a source port. This behavior may cause BIG-IP LTM to reuse a source port before the destination server is ready to accept another connection from that source port. For example, the destination server may still be in a TIME_WAIT state from a previous connection when BIG-IP LTM tries to create a new connection on the same source port.

In BIG-IP LTM 9.1.2 though 9.6.0, you can force BIG-IP LTM to increment the source port for each new SNAT connection by logging in to the command line and typing the following command:

bigpipe db TM.PreserveClientPort disable

When the TM.PreserveClientPort variable is enabled, the BIG-IP LTM system attempts to preserve the client's source port when connecting to the server.

When TM.PreserveClientPort is disabled, the BIG-IP LTM system selects ephemeral ports based on an incrementing algorithm rather than preserving the original source port. This behavior is beneficial for isolating client-side and server-side port selection, and for older TCP/IP stacks that don't exit the TIME-WAIT state properly.

F5 Product Development tracked this enhancement request as ID 310049 (formerly CR59006), ID 252940 (formerly CR50846), and ID 249733 (formerly CR59007), and it was added in BIG-IP LTM 9.1.2, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Note: Beginning in BIG-IP 9.6.1 for the VIPRION platform, and 10.0.0 for all other platforms, the system no longer uses the TM.PreserveClientPort bigpipe database variable. Instead, the client source port preservation behavior can be customized on a per-virtual-server and per-SNAT basis. For more information, refer to K11003: Configuring source port preservation for virtual servers.

Note: You can also mitigate port collisions by creating SNAT pools or adding additional self IP addresses to the VLAN.
