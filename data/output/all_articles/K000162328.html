Description

Sometimes you will see the symbol "-" when checking your API Discovery and you want to understand what it means

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer
  • API discovery

Answer/Recommended Actions

In the context of API discovery, the "-" symbol is often used as a placeholder to represent:

  • No value (i.e., the field is empty or missing)
  • Null (i.e., the value was not provided or does not exist)
  • Unknown (i.e., the system could not determine the value)

It may happen because SNI (Server Name Indication) is a field in TLS/SSL traffic that specifies the hostname the client is attempting to connect to.
If your backend telemetry collects API traffic, some requests might not include an SNI value. This can happen if:

  • The client did not send an SNI extension in the TLS handshake.
  • The traffic is not TLS-encrypted (e.g., plain HTTP).
  • The API discovery tool or backend did not capture or parse the SNI field.

When you see "-" as an option in your filtering dropdown, it means:
"Show me all APIs where the SNI field is missing, empty, or not applicable."
