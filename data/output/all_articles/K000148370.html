K000148370: F5OS-C does not send FQDN hostname in log messages sent to remote syslog on VELOS platforms

Type
Support Solution
Published
2025-01-15
Updated
2025-01-15
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000148370

Description

Logs received from your VELOS unit contain only the name of the blade or the controller emitting the log, without reference to the hostname or fully-qualified domain name of the chassis. Without the hostname it is impossible to tell from which chassis a log line came from.

Environment

  • VELOS
  • F5OS-C
  • Syslog

Cause

ID1300749

Recommended Actions

ID1300749 will introduce a new setting in a future F5OS-C release that can accomplish this.

Currently, you can use the iRule listed in ID1300749 to add the hostname into outbound log messages.

None
