K25269441: vCMP host reports high memory/CPU utilization

Applies to

Description

vCMP host is reporting high Memory/CPU utilization.

Environment

Virtual Clustered Multiprocessing (vCMP) host.

Cause

Available cores are allocated to vCMP guests, which automatically assigns a fixed amount of memory/CPU. This memory/CPU reflects on the host as being fully utilized. You may need to check the cause of high memory/CPU usage in the guest.

Recommended Actions

When certain core is showing high CPU usage on host system,  check which core is assigned to which guest with the following command.

tmsh show /vcmp guest all-properties

Additional Information

Each vCMP core represents a fixed amount of CPU and memory, which varies by platform.

For example, on a i10800 system with 128 GB of memory, and 16 cores, each core represents 8 GB of memory (128 / 16 = 8). Allocating 4 cores to a guest will automatically assign approximately 32 GB of memory to the guest. When a vCMP host has all slots assigned to guests, it will appear to have very high memory utilization.
