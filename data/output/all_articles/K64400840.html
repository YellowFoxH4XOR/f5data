Known Issue

Configurations that contain VLAN names that do not meet updated validation requirements fail to load following an upgrade.

This issue occurs when all of the following conditions are met:

  • You are currently running F5OS 1.1.x.
  • Your configuration or scripts contain a VLAN name that does not meet the following requirements:
    • The VLAN name must start with an alpha character (a-z, A-Z).
    • The VLAN name must contain only alpha numeric characters (a-z, A-Z, 0-9), period (.), hyphen (-), or underscore (_).
    • The VLAN name must not exceed 56 characters in length.
    • The VLAN name must be unique.
  • You upgrade to F5OS 1.2.0 or later and attempt to save the configuration or run the scripts.

In F5OS versions prior to 1.2.0, the naming requirements for a VLAN allowed a free-form string. In F5OS 1.2.0 and later, VLAN names are validated against the previously listed requirements. If you upgrade a previous version to F5OS 1.2.0 and do not change the VLAN names to be compliant, the configuration fails to load and any configuration scripts that reference the previous VLAN names do not function properly.

Impact

Following an upgrade, you are unable to load the configuration, and configuration scripts referencing the previous VLAN names fail to complete successfully.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to upgrade, the configuration fails to load.
  • Configuration scripts that reference previously named VLANs malfunction after an upgrade.

Workaround

To work around this issue, you can change the affected VLAN name to meet the validation requirements before you perform the upgrade. You may also be able to change the VLAN name after you upgrade but before you save the configuration or run affected scripts. To change the VLAN name, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the chassis partition webUI as admin.
  2. Go to Network Settings > VLANs.
  3. Select the affected VLAN to edit.
  4. For Name, enter a new name that meets the validation requirements.
  5. Select Save and Close.
