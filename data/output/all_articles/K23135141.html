Issue

Error Message

Error while transforming <object1>, Details: java.lang.IllegalStateException: Cannot transform from device for <object2> from <object3> because Failed to transform secure field value

In this error message, note the following:

  • <object1> is some commonly encrypted item, such as a clientssl profile.
  • <object2> is a specific reference to something within object1, such as certKeyChain.
  • <object3> is the full path to object2, such as  /Common/cim-dev.xcelenergy.com_443_clientssl.

The following examples show a few variations of this error:

  • Error while transforming Persistence Cookie, message 'java.lang.IllegalStateException: Cannot transform from device for [cookieEncryptionPassphrase] from /Common/cookie because Failed to transform secure field value'
  • Failed to transform secure field value for field adminEncryptedPassword from icrd class=LdapIcrdState, value=$M$9K$pprH87YH2JqfgT4bIS0GQA== , Details=java.lang.IllegalStateException: Failed to transform secure field value
  • Error while transforming Monitor LDAP, message 'java.lang.IllegalArgumentException: Failed to transform secure field value

Message Location

You may encounter this message in the following locations:

  • The /var/log/restjavad.0.log file
  • The BIG-IQ user interface

Description

This message occurs when one of the following conditions is met:

  • You attempt to discover a BIG-IP device from the BIG-IQ system.
  • You attempt to import a configuration from a BIG-IP device.

Impact

You are unable to import services from the BIG-IP device.

Recommended Actions

You can recover your system from the error by restarting the restjavad service on the affected BIG-IP device by typing the following command on the BIG-IP device:

tmsh /sys service restart restjavad
