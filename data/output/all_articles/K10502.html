Apple released Mac OS X version 10.6 (Snow Leopard) on August 28, 2009. Support for Mac OS X version 10.6 was introduced in ARX 5.1.0. For information refer to K10909: F5 Data Solutions Compatibility Matrix.

ARX 5.0.5 and earlier do not support Mac OS X version 10.6 as a client; however, some features may function through ARX.

Note: For more information about Mac OS X version 10.6, refer to http://www.apple.com/macosx/. This link takes you to a resource outside of AskF5, and it is possible that the information may be removed without our knowledge.
