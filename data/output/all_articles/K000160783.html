Description

You want to add multiple custom files to logrotate configuration.

Environment

  • Logrotate
  • Multiple files

Cause

None

Answer/Recommended Actions

Example syntax for adding multiple files to logrotate:

 include "
    /var/log/one.log
    {
       compress
       missingok
       notifempty
       copytruncate
    }
    /var/log/two.log 
    {
       compress
       missingok
       notifempty
       copytruncate
    }"
