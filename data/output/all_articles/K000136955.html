Description 

Long term support releases (LTS) refer to a specific set of software versions for F5OS (F5OS and F5OS-C). LTS software releases have a 3-year support lifecycle (from first customer ship date). Version 1.5 (F5OS-A) and version 1.6 (F5OS-C) are the first LTS release branches for the rSeries appliance and VELOS chassis platforms respectively.

LTS releases are different from other F5OS releases (STS - Short Term Support) in that the LTS releases will prioritize software stability, reliability where STS releases are more focused on providing new features, enhancements, and new platform support. Additionally support for STS release is 6 months.

Common questions regarding LTS releases

  • How often an F5OS LTS will be released?
  • How often are patches released for an LTS release?
  • Does the EoSD/EoTS date for an LTS get extended with a new LTS patch release?
  • Do we provide EHF for an LTS release?
  • Does the hardware ship with LTS or STS version?

How often an F5OS LTS will be released?

F5OS plans to release a new LTS annually to pick up the features and enhancements. F5OS-A 1.5.x and F5OS-C 1.6.x are the first LTS releases in Q3CY23.

How often are patches released for an LTS release?

Within a LTS release, patches will be released every 3-6 months to fix bugs and CVE vulnerability as a new patch release, for example, within F5OS-A 1.5.x, F5OS-A 1.5.2 as a new patch release will be released 3-6 months after F5OS-A 1.5.1 is released.

Does the EoSD/EoTS date for an LTS get extended with a new LTS patch release?

No, within one LTS release, the EoSD and EoTS date is set with the initial LTS release, all following patch releases share the same EoSD/EoTS date. For example, F5OS-A 1.5.1 release set the EoSD/EoTS date as August 23, 2026 and later F5OS-A 1.5.x patch releases (F5OS-A1.5.2, F5OS-A 1.5.3) share the same EoSD/EoTS date.

Are engineering hotfixes (EHF) provided for existing LTS release?

An EHF for an LTS release will only be considered and built on top of the latest patch releases within the LTS.

Does the hardware ship with LTS or STS version?

Newly built rSeries and VELOS hardware systems will be shipped with the latest F5OS-A 1.5.x and F5OS-C 1.6.x respectively when they are available. However, new platforms such as rSeries 12000 or VELOS CX1610 will be shipped with the specific versions of F5OS and BIG-IP that support the platforms, they might be LTS or STS.
