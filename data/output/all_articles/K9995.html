Topic

Server Message Block (SMB) is the primary protocol used by Microsoft Networking to provide network file sharing (CIFS). SMB signing is an optional security mechanism that uses digital certificates to protect SMB network packets. Each packet is signed with a digital signature, which provides authentication and data integrity.

Note: For detailed information about SMB signing, including default settings for each Windows version and procedures for disabling SMB signing, refer to the following Microsoft article. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

Overview of Server Message Block signing

Beginning in ARX 5.2.0, support for SMB signing by the client and/or server was introduced. For information about configuring the ARX system to support SMB signing, refer to the SMB Signing section of the Configuring CIFS chapter in the ARX CLI Storage Management Guide.

ARX systems prior to 5.2.0 do not support SMB signing. SMB signing must be disabled for any clients or servers that will interact with ARX systems earlier than ARX 5.2.0.
