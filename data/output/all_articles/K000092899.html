K000092899: [F5OS-A] How to block external access to tenant console over SSH port 7001 for an rSeries device

Type
Support Solution
Published
2022-11-30
Updated
2023-04-21
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A
Source
https://my.f5.com/manage/s/article/K000092899

Description

When you deploy a tenant on an F5 rSeries platform, the F5 rSeries platform automatically creates a user account using the same name as the tenant and assigns the tenant-console role to the account. The purpose of this user account is to provide remote access to the tenant’s console using the F5 rSeries platform management address and port 7001. It may be desired to block external access to tenant console over SSH port 7001.

 

Environment

  • F5OS-A
  • any version
  • rSeries

 

Cause

By default, external and internal access to port 7001 is allowed.
NOTE: Internal refers to the F5OS SSH/BASH Shell or Console session.
External refers to a separate SSH session external from F5OS.

 

Recommended Actions

Block external access to tenant console over SSH port 7001 for an R-series device:

 

1. Log in to CLI with admin account or if you have logged in with root, then run; command:

su admin

 

2. Enter the configuration mode by typing the following command:

config

 

3. Configure a "system allowed-ips allowed-ip" entry named "vconsole" to limit SSH access on port 7001 to IP address 127.0.0.1:

system allowed-ips allowed-ip vconsole config ipv4 address 127.0.0.1 port 7001

NOTE: By setting 127.0.0.1 you will not be able to SSH to port 7001 from F5OS SSH/BASH or Console session.

 

4. Save and confirm the changes by typing the following command:

commit and-quit
