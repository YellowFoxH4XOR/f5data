Description

The log message "Current session has been terminated" is observed in the /var/log/message after disabling default 'admin' account as stated in K15632.

Example: 

/var/log/messages:

...
Nov  9 03:48:22 example.com Current session has been terminated.
Nov  9 03:48:22 example.com Current session has been terminated.
...

/var/log/user.log:

...
Nov  9 03:48:22 example.com Current session has been terminated.
Nov  9 03:48:22 example.com Current session has been terminated.
...

 /var/log/audit:
...
Nov  9 03:48:22 example.com notice icrd_child[15476]: 01420002:5: AUDIT - Cannot load user credentials for user "admin"
Nov  9 03:48:22 example.com notice icrd_child[15476]: 01420002:5: AUDIT - Cannot load user credentials for user "admin"
...

Environment

  • BIG-IP 
  • Disabling the default admin account
  • Error Message: "Current session has been terminated" seen in several log files


Cause

There is a related Bug ID 563144 that there are many error messages related to the default admin account after the admin account is disabled as stated in K15632.
  • Bug ID 563144: Changing the system's admin user causes many errors in the REST framework.


Recommended Actions

For VCMP systems:
As of this publication there is no workaround for VCMP systems, refer to:

  • Bug ID 694765: Changing the system's admin user causes vCMP host guest health info to be unavailable


For non-VCMP systems:
When seeing the error message, restart the restjavad on the BIG-IP. This should help to work around the issue if you can not revert the primary administrative account to be the default "admin" user as stated in K44041985 because of company's security policy.

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the restjavad process, type the following command:

    restart sys service restjavad
