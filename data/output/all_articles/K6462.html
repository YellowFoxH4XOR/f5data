Known Issue

This is the result of a known issue. The Accessibility Scope feature of Portal Access provides Allow and Deny lists comprised of URL patterns. URLs that a FirePass user attempts to access are compared against one or more URL patterns in the Allow and Deny lists to determine whether to permit the user to access the URL. These lists are configured on the Portal Access: Web Applications: Master Group Settings page, under the Accessibility Scope section.

An issue exists when the total number of characters in either list exceeds a certain number of characters. The exact number is a function of the number of patterns. URL patterns which exceed the character limit will be ignored by the FirePass, including patterns that start before the character limit and finish after the character limit. No indication of the lists being truncated will be seen in the user interface. The Allow and Deny lists will continue to display characters in excess of the limit, but the patterns will not be used.

F5 Product Development tracked this issue as CR65302 and it was fixed in FirePass 6.0.1. For information about upgrading, refer to the FirePass Release Notes.

Additionally, cumulative hotfix HF-600-1 has been issued for FirePass 6.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

For information about how this issue affects FirePass 5.4 through 5.5.1, refer to K6461: Accessibility Scope Allow and Deny lists fail when a list exceeds 1009 characters.
