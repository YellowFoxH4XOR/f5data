Topic

You should consider using this procedure under the following condition:

  • You want to display configuration synchronization (ConfigSync) information dynamically for device group members.

Description

The watch-devicegroup-device TMOS Shell (tmsh) utility displays dynamic information about the devices in a device group. You can view information such as what device groups are defined on the system, the ConfigSync status of device group members--including the configuration change identifier (commit ID) for each device, and what time the BIG-IP system last performed a ConfigSync for the device group.

Note: The BIG-IP system may experience a memory leak when running a CMI watch script for an extended period of time. For more information, refer to K21473530: CMI watch scripts experience a memory leak.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have access to tmsh.

Procedures

Viewing dynamic ConfigSync information

The watch-devicegroup-device utility displays dynamic information about the device group; the watch-devicegroup-device columns display the following information:

  • devices - The suffix of the ConfigSync IP address that is configured on the device.
  • devgroup - The name of the device group.
  • device - The name of the device.
  • cid.id - The commit ID, which is a configuration change identifier. The highest commit ID number indicates the device with the most recent configuration.
  • cid-orig - The name of the device on which the configuration change was made.
  • cid.time - The time the configuration change was made.
  • last_sync - The time the device configuration was last synchronized with the device group.

To run the watch-devicegroup-device utility, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To run the watch-devicegroup-device utility, type the following command:

    run /cm watch-devicegroup-device

    Note: Type c to toggle the view from a collapsed view to a full view.
