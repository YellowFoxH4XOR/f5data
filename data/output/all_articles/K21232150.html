Topic

Before upgrading your BIG-IQ or F5 iWorkflow system, you should consider the following information:
  • Significant name changes have been made to the various BIG-IQ product offerings. 
  • Compatibility between BIG-IQ or F5 iWorkflow systems and remote systems may be impacted. 

Description

Product name changes

To determine the necessary upgrade path for your BIG-IQ system, you should understand the BIG-IQ product offering name changes:

  • The BIG-IQ products used to manage BIG-IP systems, which include BIG-IQ Cloud, BIG-IQ Device, BIG-IQ Security, and BIG-IQ ADC, were renamed as BIG-IQ Centralized Management.
  • The BIG-IQ product used to manage Cisco ACI and VMware NSX based systems, formerly known as BIG-IQ Cloud and Orchestration, was renamed as F5 iWorkflow.

The following table maps the initial BIG-IQ products and versions to the renamed BIG-IQ products and versions to help you determine the correct upgrade path.

Remote system compatibility

To ensure management of remote systems is not negatively impacted, review the following compatibility requirements for the BIG-IQ product that you plan to upgrade:

  • BIG-IQ Centralized Management 4.6.0 and later
    K34133507: BIG-IQ Centralized Management compatibility matrix
  • F5 iWorkflow 2.0 and later
    K11198324: F5 iWorkflow compatibility matrix
  • All BIG-IQ 4.5.0 and earlier
    K45824491: BIG-IQ 4.0.0-4.5.0 and BIG-IQ Cloud and Orchestration compatibility matrix

Product release notes

Before upgrading your BIG-IQ or F5 iWorkflow system, F5 recommends that you review the product release notes to learn about the latest functional changes and known issues.
