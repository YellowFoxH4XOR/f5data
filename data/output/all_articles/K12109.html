Known Issue

This is the result of a known issue. When upgrading from BIG-IP ASM 9.4.x to BIG-IP ASM 10.0.x, custom attack signature sets will not include signatures that were added to the set prior to the upgrade. This issue occurs when the following two conditions are met:

  • The custom attack signature set is of the Manual type
  • The Signatures settings have multiple signatures listed in the Assigned signatures list

After the upgrade, only the last signature in the assigned signatures list will be present in the signature set. For example, a custom attack signature set named MY_SET_1 contains the following signatures in BIG-IP ASM 9.4.7:

  • .createDocument(Headers)
  • .createDocument(Parameter)
  • .createDocument(URI)

After upgrading to BIG-IP ASM 10.0.0, the MY_SET_1 attack signature set will only contain the following:

  • .createDocument(URI)

F5 Product Development tracked this issue as ID 329811 (formerly CR142288) and it was fixed in BIG-IP ASM 10.1.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.
