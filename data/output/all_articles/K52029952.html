Known Issue

The system may erroneously reset a configured default-node-monitor to none.

This issue occurs when all of the following conditions are met:

  • You have two or more devices configured in an active-standby device service clustering (DSC) configuration.
  • You have configured a default-node-monitor on a BIG-IP system with one of the available health monitors.
  • The default-node-monitor is not in use by any of the nodes. In other words, all the nodes have been configured with a node-specific health monitor that differs from the default-node-monitor.
  • You perform one of the following actions:
    • You upgrade the standby device and boot into the upgraded software volume.
    • You perform a configuration synchronization (ConfigSync) using the set-sync-leader command option from the Traffic Management Shell (tmsh). The tmsh command syntax may appear similar to the following example:

      tmsh modify cm device-group <Device Group Name> devices modify { <Device Name> { set-sync-leader } }

Impact

The BIG-IP system will stop monitoring nodes that are configured with the default-node-monitor.

Symptoms

As a result of this issue, you may encounter one of the following symptoms:

  • After performing a ConfigSync operation or rebooting into an upgraded software volume on the standby unit, you notice that the standby device has the default-node-monitor value, instead of the desired monitor value, changed to none. The tmsh command and output of the default-node-monitor configuration may appear similar to the following example:

    tmsh list /ltm default-node-monitor
    ltm default-node-monitor {
    rule none   

    }

Workaround

To work around this issue, after an upgrade or a ConfigSync operation, you can use the tmsh utility to reconfigure the default-node-monitor and include the health monitor you want on the affected device. To do so, perform the following procedure:

Impact of workaround: The impact of the following procedure depends on the health monitor that you specify. Always ensure that modifications are compatible with your environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the tmsh utility of the affected BIG-IP device by typing the following command:

    tmsh

  2. To reconfigure the default-node-monitor and include the health monitor you want, type the following command syntax:

    modify /ltm default-node-monitor <health_monitor>

  3. Save the configuration by typing the following command:

    save /sys config
