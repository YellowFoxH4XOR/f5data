Topic

You should consider using these procedures under the following condition:

  • You want to change the default boot image for VIPRION platforms.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrator role access to the VIPRION system using the TMOS Shell (tmsh) or Configuration utility.

Description

A VIPRION chassis with two or more blades form a cluster. When the default boot image location needs to be changed, it can only be performed from the primary blade. When the change is initiated, the VIPRION system will restart all blades to use the new default boot image location immediately. Hence, when you change the default boot image on a VIPRION system using any of the command-line utilities, such as switchboot and tmsh, the system saves the configuration and immediately restarts all blades upon exiting the utility. This behavior is by design.

Procedures

 

Important: F5 recommends that you schedule a maintenance window before performing these procedures.

Impact of procedure: Perform these procedures during a maintenance window, as the procedures involve restarting the blades when changing the default boot image location on a VIPRION system.

You can use any of the following procedures to assist in selecting a new default boot location on the VIPRION system:

  • Use the Configuration utility to select a new boot image location
  • Use tmsh to select a new boot image location
  • Use the switchboot interactive utility to select a new boot image location

Use the Configuration utility to select a new boot image location

  1. Log in to the Configuration utility of the VIPRION system.
  2. Go to System > Software Management > Boot Locations.
  3. Select the desired boot partition to be used as the new default boot location.
  4. To confirm the selection, select Activate.
  5. To confirm the action to boot into the newly selected boot location, select OK.

    All of the blades restart immediately.

    Important: While waiting for the VIPRION cluster to restart, if you have console access to the VIPRION system, do not use the GRUB menu to change the boot location manually from the console access. This action may result in an additional reboot to the blade where the console is linked to. For more information, refer to K14140: An unexpected reboot occurs when using the GRUB menu to change the boot location on a VIPRION system.

Use tmsh to select a new boot image location

  1. Log in to the command-line prompt of the VIPRION system's primary blade.
  2. Determine the current default software slot by entering the following command:

    tmsh show sys software status

    Output may appear similar to the following example:

    --------------------------------------------------------
    Sys::Software Status
    Volume  Slot  Product  Version   Build  Active    Status
    --------------------------------------------------------
    HD1.1      1   BIG-IP   10.2.3   112.0      no  complete
    HD1.1      2   BIG-IP   10.2.3   112.0      no  complete
    HD1.1      3   BIG-IP   10.2.3   112.0      no  complete
    HD1.1      4   BIG-IP   10.2.3   112.0      no  complete
    HD1.2      1   BIG-IP   11.2.0  2446.0     yes  complete
    HD1.2      2   BIG-IP   11.2.0  2446.0     yes  complete
    HD1.2      3   BIG-IP   11.2.0  2446.0     yes  complete
    HD1.2      4   BIG-IP   11.2.0  2446.0     yes  complete
    HD1.3      1     none     none    none      no  complete
    HD1.3      2     none     none    none      no  complete
    HD1.3      3     none     none    none      no  complete
    HD1.3      4     none     none    none      no  complete

    The example output shows that the current active boot image is using HD1.2, which is also the default boot image for a VIPRION system.

  3. To change the default software boot location, use the following command syntax:

    Important: The VIPRION system immediately restarts all blades when this command is executed.

    tmsh reboot volume <location>

    For example:

    tmsh reboot volume HD1.1

    All of the blades restart immediately.

    Important: While waiting for the VIPRION cluster to restart, if you have console access to the VIPRION system, do not use the GRUB menu to change the boot location manually from the console access. This action may result in an additional reboot to the blade where the console is linked to. For more information, refer to K14140: An unexpected reboot occurs when using the GRUB menu to change the boot location on a VIPRION system.

Use the switchboot interactive utility to select a new boot image location

  1. Log in to the command line of the VIPRION system's primary blade.
  2. Enter the switchboot interactive utility by entering the following command:

    switchboot

  3. From the switchboot interactive menu, you will see the current boot image as indicated with (default). To change the default boot image to another location, use the up or down cursor keys to go to the desired location.
  4. To confirm the selection of the boot location, use the left or right cursor keys to toggle and select OK.
  5. To complete the selection and request the VIPRION system to restart all blades to the new boot location, press Enter.

    All of the blades restart immediately.

    Important: While waiting for the VIPRION cluster to restart, if you have console access to the VIPRION system, do not use the GRUB menu to change the boot location manually from the console access. This action may result in an additional reboot to the blade where the console is linked to. For more information, refer to K14140: An unexpected reboot occurs when using the GRUB menu to change the boot location on a VIPRION system.
