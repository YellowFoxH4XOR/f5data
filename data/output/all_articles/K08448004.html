Description

After a software upgrade, the configuration fails to load with the following error message

Disk limit exceeded. <amount 1> MB are required to provision these modules, but only <amount 2> MB are available

Environment

The following error message can be seen when running the following command.

  • tmsh load sys config verify

Cause

Previously unused volume is taking up unnecessary disk space.

Recommended Actions

Please follow the steps below to resolve the issue.

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management.
  3. Once you have identified which software (volume) to delete please click on its Disk example HD1.
  4. Select the specific volume under Contained Software Volumes and click Delete.
  5. Once the volume has been deleted, go back to the SSH terminal and run the following command to load the config file.
    • tmsh load sys config

Additional Information

Not applicable.
