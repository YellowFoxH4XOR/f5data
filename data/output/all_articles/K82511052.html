Description

When modifying the object which created by the SSLO:

  • Virtual server
  • Client SSL profile
  • Server SSL profile
  • TCP profile
  • iRule
  • Access profile

Will get the error below:

010715bc:3: The application service (<object name>) has strict updates enabled, the object (<object type> <object name>) must be updated using an application management interface.

Environment

  • SSLO
  • Topology
  • Service
  • Service Chain
  • SSL Configuration

Cause

It is expected result, the object was protected.

Recommended Actions

Please refer to the object type and object name, find the SSLO object, unlock the object in the SSLO configuration, then modify it.

  1. In the page of the error message, Under General Properties of the object, find the Application name.

  2. Navigate to SSL Orchestrator  ››  Configuration.

  3. Find the corresponding object, it maybe under different tab, like Topologies, Services, Service Polices, SSL Configurations.

  4. click the lock icon in the right side, get the prompt below:

Unprotect Configuration?

This allows you to modify objects for this instance outside of Guided Configuration. We strongly recommend that you keep the configuration protected.
Are you sure you want to unprotect the configuration?

OK Cancel                                                    

  1. Click OK

  2. Modify the object to match your requirement.

Note: Please document the customized modification. As if deploy the SSLO configuation again, will reset any customized modification and protect the object again, need to customize it again

Additional Information

None.
