K000157018: ZebOS (BGP) imish crash while checking for CLI help string in "neighbor x.x.x.x fall-over bfd ?"

Description

While configuring BGP in a BIG-IP via imish, running the command "neighbor x.x.x.x fall-over bfd ?" will provide no output, and crash imish producing a core file.

 

Environment

  • BIG-IP
  • Dynamic Routing (BGP)
  • imish shell configuring a BGP neighbor via `configure terminal`

 

Cause

The cause is due to the question mark "?" at the end of the command "neighbor x.x.x.x fall-over bfd ?". The help string returned is null, thus crashing the imish. 

 

Impact

Note, Although imish crashes, BGP functionality is not impacted.

 

Workaround

Avoid using the question mark "?" after the command "neighbor x.x.x.x fall-over bfd". This should not affect other commands; adding question marks to other commands should provide the relevant output as intended.

 

Fix Information
