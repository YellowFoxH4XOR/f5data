Known Issue

This is the result of a known issue. The bigpipe memory or bigpipe global commands, and the Memory Used graph in the Configuration utility, will incorrectly report the memory usage of the Linux operating system rather than the memory usage of the Traffic Management Microkernel (TMM). Using these methods to view memory utilization will display an almost constant value, despite varying system load.

F5 Product Development tracked this issue as CR46597, and it was fixed in BIG-IP 9.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If upgrading is not an immediate option, you can work around this issue by using the tmstat command. This command will report TMM memory utilization correctly.
