Description

  • When trying to edit an APM Policy in the Virtual Policy Editor, VPE, the following error shows up. The VPE contains an Antivirus check component.
    • 'pSource::parseSource: Error while reading source file : (pSourceMapEntry::setDefinitionFromNode: Error while reading class schema (EDOM::load: Unable to find XML file /var/sam/www/admin/vpe2/private/xml/opswat_v4/windows/Windows_ANTIMALWARE_Support_Chart_4.xml))' has occurred on server... Dialogue loading has failed.
  • The error may appear after an upgrade or after the configuration is reloaded.

Environment

  • BIG-IP APM VPE
  • Antivirus Check component.
  • OPSWAT Epsec.

Cause

The filesystem for the Epsec component gets corrupted. The exact details are still unknown at the time of publication.

 Recommended Actions

Upgrade or reinstall the Epsec component to recreate the missing files. Please, follow K48955220 to do so.
