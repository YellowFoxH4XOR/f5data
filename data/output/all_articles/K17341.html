Known Issue

The scriptd process may restart when creating a new iApp using the f5.http or f5.ip_forwarding iApp template.

This issue occurs when all of the following conditions are met:

  • You log in to the BIG-IP system using an account with the role of Guest in the /Common partition.
  • You attempt to create a new iApp using either the f5.http or f5.op_forwarding iApp template.

Impact

Users are unable to create a new iApp.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to create a new iApp.
  • When attempting to create a new iApp, you receive an error message that appears similar to the following example:

    Error parsing template:stopping worker process (<pid>) socket error.
