K000163101: IP Intelligence Connectivity on BIG-IP AFM May Use TCP/80 for Protocol-connectivity Probe

Type
Support Solution
Published
2026-08-26
Updated
2026-08-26
Applies to
  • BIG-IP
  • BIG-IP AFM
Source
https://my.f5.com/manage/s/article/K000163101

Description

BIG-IP AFM IP Intelligence can generate TCP/80 connectivity probes when "iprep.protocol" is set to 'auto-detect', the iprepd process performs a TCP connectivity test to an IP Intelligence update service. This probe is not an HTTP application request. Setting "iprep.protocol" to 'ipv4' selects IPv4 connectivity and avoids the auto-detection probe.

Environment

  • Product: BIG-IP AFM
  • BIG-IP TMOS 17.5.x
  • Feature: IP Intelligence database connectivity
  • Process: iprepd
  • Initial setting: iprep.protocol=auto-detect

Cause

The iprepd 'auto-detection' mechanism performs a TCP connectivity test over destination TCP/80 to determine the available IP protocol. The traffic is a protocol-connectivity probe and does not represent HTTP application traffic.

Answer/Recommended Actions

If you prefer IPv4 and would like to avoid the 'auto-detection' probe:

Important: It's recommended to consider performing this activity under a planned Maintenance Window to avoid any unexpected service disruption.

1) Check the current protocol setting:

# tmsh list sys db iprep.protocol

2) Set the IP Intelligence protocol to IPv4:

# tmsh modify sys db iprep.protocol value ipv4
# tmsh save sys config

3) Restart the IP Intelligence process:

# tmsh restart sys service iprepd

4) Confirm the setting:

# tmsh list sys db iprep.protocol

5) Verify IP Intelligence database status:

# tmsh show sys iprep-status

Additional Information

  • TCP/80 activity during iprepd initialization or restart can occur when iprep.protocol is set to auto-detect.
  • The TCP/80 probe does not indicate that HTTPS application traffic was converted to HTTP.
  • Selecting the IP protocol and selecting the egress interface are separate functions:
    • iprep.protocol=ipv4 selects the IP address family.
    • BIG-IP route selection determines the egress interface.
