Known Issue

This is the result of a known issue. The connection limit feature specifies the maximum number of concurrent connections that a node can accept. The Node address connection limit feature can cause the mcpd process to crash and generate a core file during a configuration load.

F5 Networks Product Development tracked this issue as CR102269 and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the BIG-IP LTM Release Notes.

This issue has been fixed in Hotfix-BIGIP-v9.6.1-HF2, which has been issued for BIG-IP version 9.6.1. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.
