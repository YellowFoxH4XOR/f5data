Description

cat /proc/meminfo shows a different value in MemTotal than the actual RAM on the device.

 

Environment

  • Memory
  • BIG-IP

Cause

The MemTotal value is displayed in kB.

 

Recommended Actions

 

Divide the MemTotal value kB  by /1024/1024 to get GB the real memory of the device.

For Example:

 

cat /proc/meminfo

 

MemTotal 49401232 kB

MemFree 342584 kB

MemAvailable 1455748 kB

Buffers 529836 kB

Cached 961552 kB

SwapCached 456 kB

 

49401232 kB/1024/1024 = 47,11 GB Total Usable Memory
