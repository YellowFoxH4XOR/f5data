K000137331: Attach 2nd virtual disk to VE to increase disk size for upgrade is not supported.

Type
Support Solution
Published
2024-07-23
Updated
2024-07-23
Applies to
  • Virtual Editions
  • Vmware ESXI and vCloud Director
Source
https://my.f5.com/manage/s/article/K000137331

Description

Software installation failed, after adding the 2nd virtual disk to the VE and trying to create a new HD volume to upgrade the device.

  • Software installation failed with the following log:

err lind[6585]: 013c0004:3: volumeset does not exist HD1.2

 

Environment

  • BIG-IP VE
  • Add another virtual disk to this VE, instead of expanding the existing virtual disk.

Cause

This is by design, even manually adding the 2nd virtual disk into the logical volume, the 2nd disk can only work in "NONE" or "DATASTORE" mode.

  • When you try to manually change the disk mode, you may get the following log:

err mcpd[7683]: 01071372:3: Cannot change the mode for logical disk (HD2) from (NONE) to (MIXED). Disks cannot be changed to MIXED or CONTROL modes.

 

Recommended Actions

Expand the existing virtual disk, instead of adding a new virtual disk to the VE.
