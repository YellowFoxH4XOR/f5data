Topic

The SNMP DCA performance monitor polls the SNMP agent running on each pool member or node for CPU, memory, and disk utilization statistics, and then uses those statistics to calculate a dynamic ratio for each pool member or node. The CPU utilization OIDs polled by the monitor are raw CPU cycle counters, and the dynamic ratio calculation uses them as if they represent percentages of CPU utilization.

The SNMP DCA and DCA BASE monitor utilize the following UCD OID values for CPU usage:

ssCpuRawUser  .1.3.6.1.4.1.2021.11.50.0
ssCpuRawNice  .1.3.6.1.4.1.2021.11.51.0
ssCpuRawSystem .1.3.6.1.4.1.2021.11.52.0
ssCpuRawIdle   .1.3.6.1.4.1.2021.11.53.0

The monitors use the following formulas to determine a percentage value for the CPU load:

  • used_cpu = ssCpuRawUser + ssCpuRawNice + ssCpuRawSystem
  • available_cpu = used_cpu + ssCpuRawIdle
  • Load=(used_cpu/available_cpu)*100

    Note: This formula results in the CPU load as a percentage, and is used along with Memory and Disk data to determine a weight to assign to a node. For more information, refer to K9125: Overview of Dynamic Ratio load balancing.
