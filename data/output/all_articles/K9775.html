K9775: Portal Access support for NTLM version 2 authentication

Topic

Starting in FirePass version 6.0.3, the Portal Access reverse-proxy engine supports NTLM version 2 (NTLMv2) authentication. If a user accesses a web page that requires NTLMv2 authentication, the reverse-proxy engine can now successfully proxy the request. However, NTLMv2 is not supported for Compatibility Mode 1 or Compatibility Mode 2. Additionally, FirePass does not support 128-bit session security encryption for NTLMv2. If your authentication server is configured to allow only 128-bit session security encryption, NTLMv2 authentication will fail.

Note: You can enable or disable Compatibility Mode on the Portal Access: Web Applications: Content Processing page under the Global Settings tab.
 
F5 Product Development tracked this enhancement as CR54724 and it was included in FirePass 6.0.3. For information about upgrading, refer to the FirePass release notes.
