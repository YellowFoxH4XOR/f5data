Known Issue

Users may be unable to view tunnel properties.

This issue occurs when any of the following conditions are met:

  • A non-administrative user logs in to the BIG-IP Configuration utility, navigates to the Network > Tunnels > Tunnel List page, and attempts to view the properties of a tunnel in the list.
  • A non-administrative user logs in to the Traffic Management Shell (tmsh) utility and attempts to view the properties of all tunnels using the list net tunnels command.

Impact

A non-administrative user is unable to view the properties of a tunnel using the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to view the properties of a tunnel in the list, the Configuration utility displays a blank page.
  • When you attempt to view the properties of all configured tunnels using the list net tunnels command, the tmsh utility displays an error message that appears similar to the following example:

    Unexpected Error: Can't display all items, can't get object count from mcpd

Workaround

To work around this issue, you can use the tmsh utility to view the properties of a specific tunnel by specifying the tunnel name. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Viewing tunnel properties using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. View the tunnel properties using the following command syntax:

    list net tunnels tunnel <tunnel name>

    For example:

    # list net tunnels tunnel http-tunnel
    net tunnels tunnel http-tunnel {
    description "Tunnel for http-explicit profile"
    profile tcp-forward
    }
