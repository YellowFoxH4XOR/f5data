Topic

Purpose

You should consider using this procedure under the following condition:

  • You want to allow users to create Web Application favorites or be able to enter direct web links

Prerequisites

You must meet the following prerequisite to use this procedure:

  • FirePass configured with Portal Access web applications

Description

Using the FirePass Portal Access Web Applications feature, users can access internal web servers in a unified and secure way. A user can browse internal websites by name or IP address, or use preconfigured favorites and aliases. By clearing the Show administrator-defined favorites only option for a master group, you can allow users to add their own Web Application favorites and enter URLs that are not predefined.

Note: The user-defined favorites feature is only available to FirePass local user accounts.

Note: A user can only access a web favorite or direct URL if it is allowed by the Access Control List.

Procedures

Configuring FirePass to allow user defined Portal Access Web Application favorites and direct URL access

This procedure will configure FirePass to allow users to create their own Portal Access Web Application favorites and directly enter website addresses.

Impact of procedure: None.

  1. Log on to the FirePass Administrative console.
  2. Go to Portal Access : Web Applications : Master Group Settings.
  3. Select the master group you want to allow user-defined favorites for from the Master Group drop-down menu. 
  4. Clear the Show administrator-defined favorites only check box.
  5. Click the Allow List: text box.
  6. Enter the host information for hosts you want to grant access to.
  7. Click the Update button.
