Description

  • A CAA record associates one or more Certificate Authorities that are approved to issue SSL/TLS certificates for a domain
  • CAA records provide a mechanism to report invalid certificate requests to an email address and a real-time defense endpoint.

Environment

  • F5® Distributed Cloud Primary DNS

Working with CAA records

  • By adding a CAA record to your domain, a certificate authority can look for a matching authorization when determining whether they're eligible to issue a certificate for your domain.
    • For example, the following CAA records state:
      • example.com. CAA 0 issue "letsencrypt.com"
      • example.com. CAA 0 iodef "mailto:certificates@example.com"
    • The example authorizes Let's Encrypt to issue certificates for the example.com domain.
    • The second record specifies that a Certificate Authority can send notifications to certificates@example.com".
  • The CAA record specification is specified by RFC 6844.
  • The Incident Object Description Exchange Format (IODEF) format is defined in RFC 6546.
  • To add a Certificate Authority for IODEF in the F5® Distributed Cloud Console, the prefix "mailto:" has to be added in the value field.
