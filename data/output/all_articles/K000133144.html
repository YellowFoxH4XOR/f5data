K000133144: Azure VE, no connection to SSH/ GUI

Source

Description

Unable to reach the management interface of BIG-IP deployed in Azure when Accelerated networking feature is enabled on the mgmt NIC.

Environment

  • Azure
  • Accelerated networking
  • BIG-IP Management Interface

Cause

Accelerated networking on mgt NIC is not supported on BIG-IP

Recommended Actions

Check if accelerated networking is enabled on the management interface in Azure, if yes, turn it off.

1-Login to Azure CLI

#az network nic show -g <resource-group> -n <NIC name> --query "enableAcceleratedNetworking"

true

2-Stop the VM

# az vm deallocate --resource-group <resource_group_name> --name <name_of_VM>

3-Disable accelerated networking on the affected Management Nic on the BIG-IP VE

az network nic update --n <NIC name> -g <resource_group_name> --accelerated-networking false

 

4-Validate and restart the VM in Azure

# az network nic show -g <resource-group> -n <NIC name> --query "enableAcceleratedNetworking"

# az vm start --resource-group <resource_group_name> --name <name_of_VM>
