K000161896: Configuring Server Signature Algorithms for BIG-IP LTM Management GUI Access

Description

This article addresses the ability to configure or restrict server signature algorithms used for management GUI access on BIG-IP LTM systems. Security scans may flag the use of weak server signature algorithms as a security concern. The question is whether these algorithms can be disabled or controlled via configuration on BIG-IP LTM.

Environment

  • Product: BIG-IP LTM
  • Management GUI access subject to security scans
  • Algorithms flagged: rsa_pkcs1_sha1, dsa_sha1, ecdsa_sha1, rsa_pkcs1_sha224, dsa_sha224, ecdsa_sha224, dsa_sha512

Cause

The inability to configure or restrict server signature algorithms for management GUI access on BIG-IP LTM is due to limitations in OpenSSL 1.0.2, which does not provide functionality to filter or enforce specific server signature algorithms. As a result, weak algorithms such as SHA1-based signatures may still be used if offered by the client, and there is no mechanism to enforce stricter policies.

Answer/Recommended Actions

  • There is currently no configuration option to restrict or disable weak server signature algorithms for management GUI access on BIG-IP LTM.
  • An RFE (Request for Enhancement, RFE1297741) has been raised to request this functionality and an OpenSSL upgrade in future releases.
  • Customers who require prioritization of this enhancement should contact their F5 account team to initiate a Customer Special Request (CSR).
  • Monitor future BIG-IP releases for updates regarding server signature algorithm configuration.
