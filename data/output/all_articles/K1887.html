Topic

When your BIG-IP system is in L4 mode (not using cookie persistence, HTTP-inspecting rules, and so forth), it does not modify TCP or IP packet optimizations; everything a client or server supports is sent directly through the network. In this configuration, your BIG-IP system passively supports all WAP TCP optimizations.

When your BIG-IP system uses delayed binding (such as cookie persistence, HTTP-inspecting rules, and so forth), it supports the following WAP TCP optimizations:

  • Large window sizes
  • Large initial window
  • Round Trip Time (RTT) load balancing metrics
  • Maximum Transfer Unit (MTU) path discovery
