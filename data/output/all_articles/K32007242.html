K32007242: Configuring Brute Force on a Virtual Server using NTLM

Type
Support Solution
Published
2021-05-21
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.X.X, 14.0.X, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.X, 14.0.1, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K32007242

Description

You are trying to configure Brute Force on a Virtual Server that uses NTLM.

In reviewing a packet capture taken on the BIG-IP, GET looks something like this:

GET /autodiscover/autodiscover.xml
HTTP/1.1 Host: 10.1.10.10
Connection: keep-alive
Authorization: Negotiate TlRMTVNTUIIBAAABl6II4gAAAAABBBACAAAAAAABBBAKALpHBAACDx==
sec-ch-ua: "Chromium";v="88", "Google Chrome";v="88", ";Not A Brand";v="99"

Environment

BIG-IP ASM v14.x

Cause

Bug ID 785873: ASM should treat 'Authorization: Negotiate TlR' as NTLM

Recommended Actions

As the workaround given in the bug ID suggests, you need an iRule which changes Authorization: Negotiate TlR to NTLM on the client side (before ASM) and sets is back to the original value on the server side (after ASM).

Additional Information

You can try the iRule below:

when HTTP_REQUEST {
    if {[HTTP::header exists "Authorization"]} {
        if { [HTTP::header value Authorization] contains "Negotiate TlR" } {
            log local0. "Rule triggered!"
            set authheader [split [HTTP::header value "Authorization"] " "]
            log local0. "[lindex $authheader 1]"
            HTTP::header remove "Authorization"
            HTTP::header insert "Authorization" "NTLM [lindex $authheader 1]"
            log local0. "AUTH Header on Ingress: [HTTP::header value Authorization]"
        }
    }
}
when HTTP_REQUEST_SEND {
   clientside {
      if {[HTTP::header exists "Authorization"]} {
        if { [HTTP::header value Authorization] contains "NTLM TlR" } {
            set authheader1 [split [HTTP::header value "Authorization"] " "]
            HTTP::header remove "Authorization"
            HTTP::header insert "Authorization" "Negotiate [lindex $authheader1 1]"
            log local0. "AUTH Header on Egress: [HTTP::header value Authorization]"
        }
      }
    }
}
