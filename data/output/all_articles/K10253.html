Topic

In spring 2005, F5 Networks began using a new motherboard for the FirePass 4100 platform. This motherboard has two AMD Opteron 2.0GHz single-core processors installed, which are displayed as two CPUs on the Device Management: Monitoring: System Health page in the FirePass Administrative Console.

Previously, the FirePass 4100 platform shipped with two Intel Xeon 2.4GHz dual-core processors. When viewing the Device Management: Monitoring: System Health page on one of these models, four CPUs are reported. Additionally, when viewing the CPU Usage graph on the Device Management : Monitoring : System Load page, the Y-axis of the graph will differ based on the processor installed. The Y-axis displays the sum processor usage (in percent). For example, if you have a unit with the Opteron single-core processor installed, the maximum value on the Y-axis would be displayed as 100, representing 100 percent usage. If you have a unit with two dual-core Xeon processors installed, the maximum value on the Y-axis would be displayed as 400, representing 400 percent usage (100 percent per core x 4 cores).
