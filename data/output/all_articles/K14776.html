Policy Information

The F5 software support policy described in this article applies to the Microsoft Windows 8.1 inbox VPN capability available on Windows 8.1 and Windows 8.1 RT.

The Windows Operating System controls the management of VPN connections. Because of this, F5 will provide fixes and enhancements based on only the latest release of the software, and only Microsoft will provide the fixes to customers, either through releases or updates. F5 has no way to independently patch the inbox VPN client regarding the F5 functionality.

F5 strongly recommends that you upgrade to the current release of Windows 8.1 and confirm that the latest updates are installed through Windows Update.
