Description

You want to re-activate or revoke the license but the Re-activate or Revoke buttons are greyed out in GUI.

Environment

  • BIG-IP systems
  • GUI
  • Reactivate license
  • Revoke license

Cause

You have not logged in using an Administrator account.

Recommended Actions

Login to GUI using an Administrator account.

Additional Information

Revoking of license is only available for BIG-IP VE Perpetual licenses.
