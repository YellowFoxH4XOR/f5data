Description

How to configure log severity levels for local log storage and remote syslog forwarding on F5OS. The requirement is to forward local logs and F5 system log to a remote syslog server.

Environment

  • F5OS-A
  • F5OS-C
  • Log storage locations:
    • /var/log (Linux local host log files)
    • /var/F5/system/log (F5OS system and services log files)
  • Remote syslog server configured for log forwarding

Cause

F5OS supports granular log severity configuration for both local storage and remote syslog forwarding via selector settings.

Answer/Recommended Actions

To configure log severity for local storage and remote syslog forwarding on F5OS:

  1. Set local log severity:
    • Use the WebGUI and navigate to the Software Component Log Levels menu.
  2. Configure remote syslog forwarding:
    • For logs in /var/F5/system/log:
      1. Go to the Remote Log Server menu.
      2. Create a Remote Log Server entry.
      3. Add a selector for facility LOCAL0 and set severity that you want to forward.
      4. For audit logs, use facility AUTHPRIV.
    • For logs in /var/log:
      1. Go to Host Log Settings.
      2. Enable Host Log Forwarding.
      3. Add a selector for facility LOCAL0 and sset severity that you want to forward.

Additional Information

  • LOCAL0 facility includes all logs.
  • AUTHPRIV facility is used for audit logs.
