K8193: The BIG-IP GTM can mark a BIG-IP 4.5.x virtual server down when the virtual server refers to an iRule that selects multiple pools

Known Issue

This is the result of a known issue. When a BIG-IP 4.5.x virtual server refers to an iRule that selects multiple pools, and all of the pool members in one pool are down, the BIG-IP GTM system will mark the virtual server down.

For example, if the BIG-IP 4.5.x virtual server references an iRule that selects two pools, PoolA and PoolB, and all pool members in PoolA are marked down, but members in PoolB are marked up, the BIG-IP GTM system marks the virtual server down.

F5 Product Development tracked this issue as CR89944 and CR91030, and it was fixed in BIG-IP 9.4.4. For information about upgrading, refer to the BIG-IP GTM release notes.

This issue still exists in BIG-IP GTM 9.3.x. Hotfix-BIG-IP-9.3.1-HF2 has been issued for BIG-IP 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
