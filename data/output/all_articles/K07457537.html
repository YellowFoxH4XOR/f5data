Issue

Old Behavior

In versions prior to BIG-IP 14.0.0, F5 SSL Orchestrator functionality is enabled when you successfully license SSL Orchestrator on the BIG-IP system.

After you install the license for SSL Orchestrator on the BIG-IP system, SSL Orchestrator is fully operational and can be configured. The SSL Orchestrator configuration objects are exposed in the Configuration utility and the TMOS Shell (tmsh).

New Behavior

Beginning in BIG-IP 14.0.0, SSL Orchestrator functionality is enabled by provisioning the new SSL Orchestrator module.

After you license SSL Orchestrator on the BIG-IP system you can provision the SSL Orchestrator module. When you provision the SSL Orchestrator module, the BIG-IP system allocates CPU, memory, and disk space resources to the module and enables the SSL Orchestrator configuration objects in the Configuration utility and tmsh.

When you attempt to view SSL Orchestrator configuration objects when the SSL Orchestrator (SSLO) module is not provisioned, you observe the following error message in the Configuration utility:

SSL Orchestrator (SSLO) is not provisioned. Navigate to System > Resource Provisioning to provision the system.

F5 Product Development tracked this change as ID 678107.

Impact

In BIG-IP 14.0.0 and later, you are unable to configure SSL Orchestrator until the SSL Orchestrator module is licensed and provisioned.

Recommended Actions

After licensing SSL Orchestrator on the BIG-IP system, ensure the SSL Orchestrator module is provisioned before you attempt to configure the system.  For more information about provisioning modules, refer to K12111: Provisioning licensed BIG-IP modules.
