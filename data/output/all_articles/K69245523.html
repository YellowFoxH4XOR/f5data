Description

After updating to a version listed below, iControl REST calls may take significantly longer to complete.

Environment

  • iControl REST
    • Basic Authentication
  • Remote User Authentication
    • LDAP
    • RADIUS
    • TACACS+
    • Active Directory
  • BIG-IP Versions
    • 16.0.1.1 and later
    • 15.1.2.1 and later
    • 14.1.4 and later
    • 13.1.3.6 and later
    • 12.1.5.3 and later

Cause

Starting in BIG-IP Versions listed above iControl REST calls using Basic Auth will generate a new auth request for each API call. This issue is compounded when the user is remotely authenticated (LDAP for example).

Recommended Actions

Use X-F5-Auth-Token

If at all possible, we highly encourage you to use Token Based Authentication.

Note: See Related Content below for reference material.

F5 Product Engineering has filed ID 1010341 to track this issue.

Additional Information

This behavior is not expected to change. You must use Token Authentication when leveraging the iControl REST API to achieve better security and better performance.

Related Log Messages

You may observe a substantial number of messages in /var/log/secure which contain rest(pam_audit).

For Example:

bigip1.example.com info rest(pam_audit)[<PID>]: 01070417:6: AUDIT - user <username> - RAW: rest(pam_audit): user=<username>(<username>) partition=[All] level=Administrator tty=(unknown) host=(unknown) attempts=1 start="<datetime>" end="<datetime>".
