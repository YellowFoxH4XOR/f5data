Environment

  • BIG-IP with ASM provisioned.
  • BADoS configured.

Cause

ID1019557

Recommended Actions

  • There is a workaround available:
    • Copy the missing files appear in the error log from the peer BIGIP (if the affected BIGIP is part of DSC).
  • Or upgrade to BIGIP version (v17.0.0, v16.1.5) which contains the fix for ID1019557.

 

Additional Information

AFM creates json files in /var/bdosd/ for each context that has BaDoS running (one for netflow, one for device and one for each virtual server with a DoS profile with BDoS enabled) at every 10 minutes. Also these files are synced between peers in a DSC environment.

These JSON files contain historical data for each virtual server.

If these files are not available, then BDOS for DDoS works on current data in memory but cannot to depend on the historical data for all virtual servers

Even if these files are deleted, they're expected to get re-created after 10 minutes.
