K000137517: AS3 deployment fails after upgrade to 3.44.0

Type
Support Solution
Published
2023-11-09
Updated
2023-11-09
Applies to
  • BIG-IQ
  • F5 Automation and Orchestration
  • BIG-IQ Centralized Management: 8.3.X, 8.3.0
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K000137517

Description

AS3 deployments are failing after upgrading BIG-IQ to 8.3 with the following error message:

AS3 Error: The requested SNAT Translation (/Common/<IP Address>) already exists in partition Common.

 

Environment

  • AS3 v3.44
  • BIG-IQ 8.3 comes with AS3 v3.44 by default
  • AS3 is deployed via BIG-IQ

Cause

K000137161: AS3 Error: The requested SNAT Translation (/Common/) already exists in partition Common.

Recommended Actions

Upgrade to the latest version of AS3 and test again

Additional Information

AS3 releases on Github
