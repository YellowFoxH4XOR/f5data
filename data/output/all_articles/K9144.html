Topic

The Load Status Access Security link can only be used when using a standalone FirePass controller, the primary (master) controller in a cluster environment, or the active controller in a high availability deployment. If the FirePass controller does not show the Device Management: Monitoring: Load Status Access Security link, log on to the primary (master) or active FirePass controller.

Note: For more information, refer to K9142:External Monitoring of a FirePass Controller by using the Load Status Page.
