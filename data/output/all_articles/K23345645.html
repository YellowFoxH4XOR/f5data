Known Issue

BIG-IP Analytics (AVR) statistical data for BIG-IP ASM grows to consume available disk space, causing traffic disruptions and system instability.

This issue occurs when all of the following conditions are met:

  • BIG-IP ASM is licensed and provisioned on the BIG-IP system.
  • The BIG-IP ASM system processes traffic patterns with many combinations of IP addresses, device IDs, and other BIG-IP ASM dimensions over a long period of time

Impact

When the file system containing the MySQL instance fills with data from the AVR_STAT_ASM_HTTP_CLIENT_IP table, it causes traffic disruptions and system instability.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system becomes unresponsive or unstable.
  • Services that are dependent on the MySQL database degrade or malfunction.
  • Output of the df -h command shows little to no available space left in the file system mounted on the /var/lib/mysql directory.
  • MySQL database files grow large, as evidenced by the output of the ls command.  For example:

    ls -alh /var/lib/mysql/AVR/AVR_STAT_ASM_HTTP_CLIENT_IP*.MY[DI]
    -rw-rw----. 1 mysql mysql 2.8G Oct 31 08:25 2017
    AVR_STAT_ASM_HTTP_CLIENT_IP_H#P#H_2017_1031_000001_1509606001.MYD
    -rw-rw----. 1 mysql mysql 2.1G Oct 31 08:25 2017
    AVR_STAT_ASM_HTTP_CLIENT_IP_H#P#H_2017_1031_000001_1509606001.MYI

Workaround

To work around this issue, you can clear the AVR data by manually deleting the files. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure removes all collected AVR statistics from the BIG-IP system and resets the AVR statistics database. Restarting mysqld and monpd affects chart reporting and event log reporting.

Important:  This workaround may cause a failover event and should be performed during a maintenance window.

  1. Log in to the Advanced Shell (bash).
  2. Optional: Back up the existing data to the /shared/tmp/avr.dmp.gz file by typing the following command:

    mysqldump -uroot -p`perl -I/ts/packages -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` AVR | gzip -9 > /shared/tmp/avr.dump.gz

  3. Stop the monpd process by typing the following command:

    tmsh stop /sys service monpd

  4. Remove the AVR files by typing the following command:

    rm -rf /var/lib/mysql/AVR/*

  5. Create the /var/avr/init_avrdb file by typing the following command:

    touch /var/avr/init_avrdb

  6. Restart the mysql process by typing the following command:

    tmsh restart /sys service mysql

  7. Restart the monpd process by typing the following command:

    tmsh restart /sys service monpd
