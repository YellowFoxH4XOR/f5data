Description

Unable to find support ID in the Event logs for violation.

The following log messages are found in /var/log/ts/asmlogd.log:

F5::RequestLog::delete_unused_protobuf_files,,Dropping protobuf file /var/asmdata1/request_log/0000000001
F5::RequestLog::delete_unused_protobuf_files,,Dropping protobuf file /var/asmdata1/request_log/0000000002
 

Cause

By default, the local log storage is finite with a maximum capacity of 3 million records stored across all BIG-IP ASM security policies and 2 GB in database table size.

When the limit is reached, ASM has to delete the records to make space for new one and in that case, support ID may no longer be found in the Event Logs.
 

Recommended Actions

F5 recommends to send all log requests which included legal and illegal to a remote server and only log illegal logs locally on the BIG-IP.
