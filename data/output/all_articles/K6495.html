Topic

The BIG-IP 9.x software branch uses the runsv utility to monitor specific daemons and will restart the daemon in the event of a system failure.

In the BIG-IP 9.1.x software branch, the following daemons are monitored using the runsv utility:

  • alertd
  • bcm56xxd
  • big3d
  • big3dshim
  • bigd
  • bigdbd
  • bigsnmpd
  • chmand
  • cssd
  • eventd
  • fpdd
  • lacpd
  • mcpd
  • named
  • nokiasnmpd
  • pvad
  • radvd
  • rmonsnmpd
  • snmpd
  • sod
  • statsd
  • stpd
  • syscalld
  • tamd
  • tmm
  • tmrouted
  • tmsnmpd
  • tomcat4
  • zebosd

For information about daemons that are monitored by the runsv utility in other BIG-IP versions, refer to the following articles:

The list of daemons monitored with the runsv utility is static and can only be modified by F5 Product Development. If you need the runsv utility to monitor additional daemons, you can submit a request for enhancement (RFE) through F5 Technical Support.
