Issue

Old Behavior

In versions prior to BIG-IP WebAccelerator 11.0.0, the system designates ;pv as the Intelligent Browser Referencing (IBR) prefix.

For example, following is an example response from the origin server:

<html><body>
this is an image link:<br>
<img src=../myimage.jpg>
</body></html>

When the IBR feature is enabled, the system rewrites the response and appends the ;pv prefix (and corresponding IBR tag) as follows:

<html><body>
this is an image link:<br>
<img src=../myimage.jpg;pv8fe8f6f4496837da11cad298f0a4fdef>
</body></html>

New Behavior

Starting in BIG-IP WebAccelerator 11.0.0, and BIG-IP AAM 11.4.0, the system designates ;wa as the IBR prefix.

For example, following is an example response from the origin server:

<html><body>
this is an image link:<br>
<img src=../myimage.jpg>
</body></html>

When the IBR feature is enabled, the system rewrites the response and appends the ;wa prefix (and corresponding IBR tag) as follows:

<html><body>
this is an image link:<br>
<img src=../myimage.jpg;wa8fe8f6f4496837da11cad298f0a4fdef>
</body></html>
