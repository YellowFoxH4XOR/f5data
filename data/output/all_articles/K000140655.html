Known Issue

The OPT-0054-01, Innolight (TR-PY13L-NF5, Rev ‘R1A’) optic experiences intermittent link problems when connected to r2000/r4000 platforms on Port 5.0.

This issue occurs when the following condition is met:

  • The OPT-0054-01, Innolight (TR-PY13L-NF5, Rev ‘R1A’) optic is connected to a r2000/r4000 platform on Port 5.0.

The OPT-0054-01 Innolight optic label includes the following information:

  • Optics number: OPT-0054-01
  • Revision number: R1A
    This identifies the module as OPT-0054-01 Innolight (TR-PY13L-NF5, Rev ‘R1A’).

Figure: OPT-0054-01 Innolight optic label

You can display the optic module connected to port 5.0 by entering the following command on the  F5OS management CLI, confD:

show portgroups portgroup 5

You may observe an output similar to the following when OPT-0054-01 Innolight (TR-PY13L-NF5, Rev ‘R1A’) is connected:

 state vendor-name "F5 NETWORKS INC."
 state vendor-oui 447c7f
 state vendor-partnum "OPT-0054        "
 state vendor-revision 1A
 state vendor-serialnum "<your serial number> "
 state media      25GBASE-LR
 state optic-state QUALIFIED
[...]

Impact

The link is not detected on port 5.0 resulting in network issues. 

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You observe network issues on applications that are using the OPT-0054-01 Innolight optic on port 5.0.
  • When you display the interface status on confD, the status is DOWN:
    show interfaces interface 5.0
    You may observe an output similar to the following:
    state type        ethernetCsmacd
    state mtu        9600
    state enabled      true
    state oper-status    DOWN
    state counters in-octets 0
  • When you enter the following command on bash to display the link status, the link is not detected:
    ethtool sfp_5
    You may observe an output similar to the following:
    Settings for sfp_5:
            Supported ports: [ FIBRE ]
    [...]
            Link detected: no

Workaround

To work around this issue, in place of the OPT-0054-01, Innolight Rev '1A' optic, you can use one of the following optics:
Note: The differences in the revision numbers

  • OPT-0054-01 Finisar/II-VI (FTLF1436P3BCL-F5, Rev ‘RA1’) optic on Port 5.0. The OPT-0054-01 Finisar optic label includes the following information:
    • Optics number: OPT-0054-01
    • Revision number: RA1
      This identifies the module as OPT-0054-01 Finisar/II-VI (FTLF1436P3BCL-F5, Rev ‘RA1’).

Figure: OPT-0054-01 Finisar/II-VI optic label

  • OPT-0054-01 Innolight (Rev ‘R2C’) optic on Port 5.0. This OPT-0054-01 Innolight optic label includes the following information:
    • Optics number: OPT-0054-01
    • Revision number: R2C
      This identifies the module as OPT-0054-01 Innolight (Rev ‘R2C’).

Figure: OPT-0054-01 Innolight Rev 2C optic label
