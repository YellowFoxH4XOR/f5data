Description

You are seeking to determine the operational mode of the Application Firewall Manager (AFM) within your network infrastructure. Specifically, you wish to know whether AFM is functioning in its default Application Delivery Controller

(ADC) mode or if it has been configured to act primarily as a firewall. This information is crucial for understanding how the AFM is processing traffic and can be found by examining the qkview diagnostic file.

Environment

  • AFM (Application Firewall Manager) installed
  • qkview diagnostic file generated for analysis

Cause

None

Recommended Actions

  1. Access the qkview file and navigate to the following location: Files -> config -> BigDB.dat
  2. Search within the BigDB.dat file for the entry labeled: [TM.FW.DefaultAction]
  3. Review the value parameter. If the value is set to drop, the AFM is operating in Firewall mode. The presence of an accept value would indicate that it is in ADC mode. 
    Example:

    The following shows an example of the value being set to drop, which means this is in Firewall mode.

    [TM.FW.DefaultAction]
default=accept
type=enum
realm=common
enum=|accept|drop|reject|
scf_config=true
display_name=TM.FW.DefaultAction
value=drop
  4. Ensure that, if in Firewall mode, appropriate allow rules are configured to permit desired traffic, as traffic will not pass solely based on the existence of a listener.

Additional Information

Understanding the mode in which your AFM is operating is essential for proper configuration and traffic management. In Firewall mode, the AFM adheres to a stricter security posture where all traffic is denied unless explicitly allowed by a rule. Conversely, in ADC mode, the default action is to accept traffic unless specified otherwise by configured policies
