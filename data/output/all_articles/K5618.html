Topic

Note: For information about UCS archives, refer to K4423: Overview of UCS archives.

In BIG-IP 9.0.0 through 9.3.x, the /config/BigDB.dat.cstmp file is contained in .ucs files. During the installation of a .ucs file from configsync or an archive restore, the /config/BigDB.dat.cstmp file will be installed as the /config/BigDB.dat file.

However, if the UCS installation encounters errors while loading, the /config/BigDB.dat.cstmp file will be saved as the /config/BigDB.dat.cs file.

Note: This behavior often occurs as a side effect if a license issue is encountered during the installation of a .ucs file.

If the UCS installation encounters errors, in addition to saving the /config/BigDB.dat.cs file, a warning message indicating that the installation has failed will appear similar to the following example:

Loading the new /config/BigDB.dat failed.01080023:3: Error return while getting reply from mcpd: 0x1070370,01070370:3: Failover (redundant mode) is not licensed.After updating your license, runloaddb -local /config/BigDB.dat.cs

This warning message instructs you to correct the issue that caused the installation to fail and to run the following command:

loaddb -local /config/BigDB.dat.cs

To run this command, perform the following procedure:

Important: The following procedure will interrupt traffic passing through the BIG-IP system.

  1. From the BIG-IP command line, install the /config/BigDB.dat.cs file by typing the following command:

    loaddb -local /config/BigDB.dat.cs

  2. Restart the BIG-IP system by typing the following command:

    bigstart restart
