Issue

Error Message

tmm[<PID>]: 01860007:5: MR SIP: Generated response was not sent '<response_code>' (<src_IP_port> -> <dst_IP_port>)

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <response_code> is the SIP failure response code and string.
  • <src_IP_port> is the source IP address and port number of the SIP transaction.
  • <dst_IP_port> is the destination IP address and port number of the SIP transaction.

For example:

tmm[8484]: 01860007:5: MR SIP: Generated response was not sent '484 - Malformed or incomplete Request-URI' (10.10.0.1:5060 -> 10.20.0.1:5060)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure a virtual server with Session Initiation Protocol (SIP) profiles on the BIG-IP system.
  • The BIG-IP system encounters an unrecoverable SIP failure response condition while processing the incoming SIP message.

Similar to the HTTP response code, the SIP response codes indicate the status of the SIP transaction as defined in Request for Comment (RFC) 3261. The 4xx request failure codes and the 5xx server failure codes in this error message specify failure responses of the SIP transaction.

Impact

The BIG-IP system drops the SIP message with a failure response code.

Recommended Actions

You can verify the current SIP failure response statistics using the TMOS Shell (tmsh). To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To display the SIP failure response statistics associated with a SIP session profile, type the following command:

    show ltm message-routing sip profile session <sip_session_profile>

    For example, the following command and output shows the failure response statistics of the associated SIP session profile sipsession:

    show ltm message-routing sip profile session sipsession
