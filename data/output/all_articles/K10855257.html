Known Issue

Modifying files in a Protected Workspace access session may cause file corruption.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM access profile access policy is configured with a Protected Workspace agent.
  • Protected Workspace access session users attempt to download, rename, or move files that are 16 bytes or smaller.

Impact

File contents may become corrupted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you download, move, or rename a file that is 16 bytes or smaller, subsequent access to the file contents is denied.
