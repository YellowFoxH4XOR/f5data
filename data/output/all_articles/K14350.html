Known Issue

BIG-IP APM network access may fail to direct traffic to a configured proxy server.

This issue occurs when the following condition is met:

  • The BIG-IP APM network access resource is defined with the following options:
    • Split tunneling is enabled
    • IPV4 LAN Address Space is set to 0.0.0.0/0.0.0.0
    • Client Proxy Settings is enabled

You can configure a BIG-IP APM network access resource to generate a proxy configuration file. If the network access resource is configured to use a LAN address space of 0.0.0.0/0.0.0.0, it creates a default route that directs network traffic that is not specifically identified to the proxy host.

Impact

Users cannot connect to resources that are accessed through the proxy server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • No network traffic is routed to the proxy server.

Workaround

To work around this issue, you can divide the LAN Address Space into two subnets. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Navigate to Access Policy > Network Access.
  3. Click the name of the network access resource that contains the proxy configuration.
  4. Click the Network Settings tab.
  5. In the IPV4 LAN Address Space box, highlight 0.0.0.0/0.0.0.0.
  6. Click Delete.
  7. In the IP Address box, type 0.0.0.0.
  8. In the Mask box, type 128.0.0.0.
  9. Click Add.
  10. In the IP Address box, type 128.0.0.0.
  11. In the Mask box, type 128.0.0.0.
  12. Click Add.
  13. Click Update.
