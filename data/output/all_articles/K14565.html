Known Issue

Clients who access the BIG-IP APM system using mobile devices may trigger error messages in the /var/log/http_errors file. The system generates these error messages due to a duplicate line of code in the access webtop for mobile device clients.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with a policy.
  • A client using a mobile device attempts to access the BIG-IP APM policy.

Impact

None

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The /var/log/http_errors file contains error messages that appear similar to the following example:

    err httpd_sam[13917]: [error] [client 127.1.1.4] PHP Parse error: syntax error, unexpected '&amp;lt;' in /var/sam/www/php_include/webtop/renderer/customization/general_ui/Common/policy-name-apm_general_ui/en/apm_mobile_ppc.css on line 2

Workaround

You can work around this issue by manually editing the affected policy's mobile access webtop code and removing the duplicate first line. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Removing the duplicate line from the policy's associated apm_mobile_cpp.css file

To eliminate errors when clients access the BIG-IP APM system with mobile devices, you must modify the code of the BIG-IP APM access page (webtop). The following procedure modifies the affected webtop file named apm_mobile_ppc.css and removes a duplicate line at the beginning of the file.

  1. Log in to the BIG-IP APM command line.
  2. Locate the policy file you want to edit by typing the following command:

    find /var/sam/www -name apm_mobile_ppc.css| grep -i <Policy Name>

    For example, for a policy named MyPolicy, the command would appear as follows:

    find /var/sam/www -name apm_mobile_ppc.css | grep -i mypolicy

  3. Using the vi text editor, open the apm_mobile_ppc.css file that matches the policy name in Step 2, by using the following syntax:

    vi /var/sam/www/php_include/webtop/renderer/customization/general_ui/<Partition Name>/<Policy Name>_general_ui/en/apm_mobile_ppc.css

    For example, a policy named MyPolicy in the common partition would appear as follows:

    vi /var/sam/www/php_include/webtop/renderer/customization/general_ui/Common/MyPolicy_general_ui/en/apm_mobile_ppc.css

  4. The text editor should default to the first line of the apm_mobile_ppc.css file. The first and second lines should be identical.

    For example:

    <?
    <?

    Important: If the apm_mobile_ppc.css file does not contain the same first and second lines with a duplicate value of <?, do not edit the file. Exit the text editor without modifying the file by pressing the Esc key, typing :q!, and pressing the Enter key.

  5. Ensure that the text editor cursor is on the first line in the file. Using the keyboard arrow keys, move the cursor to the first line.
  6. To remove the first line of the file, type the following:

    dd

  7. To exit the text editor and save the edited file, press the Esc key.
  8. To write the file and quit the editor, type the following:

    Note: Make sure to include the colon ( : ) prefix.

    :wq

  9. To finalize the text editor commands, press the Enter key.
