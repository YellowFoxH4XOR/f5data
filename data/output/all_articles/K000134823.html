Description

When trying to upgrade from 11.3.5 installation stucks at 91%

 

Environment

  • 11.3.5 VE installed from OVA template

  • Upgrade to 13.x version

Cause

OVA Template has defined only 500 MB for /var partition

 

 Recommended Actions

  • Log in to CLI (before upgrade)

  • Edit hidden file .tmi_config/global_attributes using following command: nano /shared/.tmi_config/global_attributes

  • Change the value "TMI_VOLUME_FIX_VAR_MIB" from 500 to 3000.

It should look like:

{"TMI_VOLUME_FIX_VAR_MIB":"3000","TMI_VOLUME_FIX_CONFIG_MIB":"500"}

 

  • Press Ctrl+X, press "Y" on the keyboard, and hit Enter to save changes.

  • Reboot the system by typing a command reboot

  • Perform an upgrade
