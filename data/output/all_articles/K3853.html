Topic

You can use the System Variables page to change internal, development, or experimental settings on the BIG-IP ASM system.

Important: Do not change settings on the System Variables page unless you have been instructed to do so by an F5 Technical Support engineer or by way of an AskF5 article.

BIG-IP ASM 11.3.0 and later

  1. Log in to the Configuration utility.
  2. Click Security.
  3. In the Security menu, click Options.
  4. Click Application Security.
  5. Click Advanced Configuration.
  6. Click System Variables.

BIG-IP ASM 10.2.0 through 11.2.1

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. In the Application Security menu, click Options.
  4. Click Advanced Configuration.

BIG-IP ASM 9.4.5 through 10.1.0

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web applications.
  4. On the Application Security Main tab, click Options.
  5. Click Advanced Configuration.
