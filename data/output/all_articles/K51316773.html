Known Issue

If you create a wide IP or wide IP alias with a name that does not contain a dot character ( . ), the gtmd process may produce a core file.

This issue occurs when all of the following conditions are met:

  • The Domain Validation setting is set to none.
  • The user attempts to create a wide IP with a name that does not contain a dot character.

Impact

DNS resolution will fail while gtmd restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP DNS stops responding to requests.
  • BIG-IP DNS creates a gtmd core file in the /shared/core directory.

Workaround

To work around this issue, ensure your wide IP names conform to the following criteria:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  • The name must contain at least one dot.
  • The name must not end with a dot.
  • The name must not begin with a dot, unless the dot is the entire name.
  • The name contains no consecutive dots.
