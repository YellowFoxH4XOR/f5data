Description

Instance Metadata support v2 (IMDSv2) support for BIG-IQ on Amazon Web Services

Environment

  • Amazon Web Services (AWS)
  • BIG-IQ AMI (AWS Machine Image) Deployment
  • IMDSv2 (Instance Metadata)
  • Unable to generate a dossier

Cause

BIG-IQ doesn't support IMDSv2 in AWS. This behavior is tracked under ID1270169.

Recommended Actions

To workaround this issue, use IMDSv1 to deploy BIG-IQ in AWS.
  • Modify instance metadata (IMDS) options for existing instances
