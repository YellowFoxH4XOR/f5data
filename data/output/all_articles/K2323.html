Some web servers, most notably Microsoft Internet Information Server (IIS), use SSL certificates in PKCS format. The BIG-IP system can use only SSL certificates that are stored in PEM format.

Depending on your web server software, you may first need to export the certificate and key in PKCS format. The PKCS file will have a .pfx extension, and contain both the certificate and the private key.

Note: Refer to your web server documentation for more information about SSL certificates.

Converting the PKCS file to PEM formatted file

Convert the exported PKCS certificate and private key file into PEM format by performing the following procedure:

  1. Copy the .pfx PKCS file to the BIG-IP /var/tmp directory.

    For more information about copying files to and from BIG-IP or 3-DNS, refer to K175: Transferring files to or from an F5 Networks system.

  2. Convert the PKCS file into a PEM file by typing the following command:

    openssl pkcs12 -in <PKCSfile> -out <filename>.pem -nodes

    Note: The -nodes switch means the password on the key will be discarded and will not be required when importing the file to the Big-IP system. To maintain the password on the BIG-IP system, do not use the -nodes switch. You will be required to supply the password when importing the key to the BIG-IP system.

    This command will produce a single PEM-encoded file.

  3. Using a text editor, divide the new PEM-encoded file into separate certificate and private key files by performing the following procedure:

    1. Cut the text beginning with BEGIN CERTIFICATE and ending with END CERTIFICATE, making sure to include the BEGIN CERTIFICATE and END CERTIFICATE statements.
       
    2. Save the certificate text as a new text file with a .crt extension.

      For example:

      mynewcert.crt

    3. Cut the text beginning with BEGIN RSA PRIVATE KEY and ending with END RSA PRIVATE KEY, making sure to include the BEGIN RSA PRIVATE KEY and END RSA PRIVATE KEY statements.
       
    4. Save the key text as a new text file with a .key extension.

      For example:

      mynewkey.key

  4. Copy the certificate file to the /config/bigconfig/ssl.crt/ directory, using the following command syntax:

    cp <filename>.crt /config/bigconfig/ssl.crt/

  5. Copy the key file to the /config/bigconfig/ssl.key/ directory, using the following command syntax:

    cp <filename>.key /config/bigconfig/ssl.key/

  6. Test the new certificate and private key, using the following command syntax:

    gwutil -v /config/bigconfig/ssl.key/<filename>.key /config/bigconfig/ssl.crt/<filename>.crt && echo "Success"

    The output should appear similar to the following example:

    Success

You now have PEM-formatted certificate and private key files that you can use with BIG-IP SSL proxies.

If the command reports an error instead of Success, perform the procedure again to verify that you did not miss steps. If that does not resolve the issue, contact F5 Networks Technical Support for assistance.
