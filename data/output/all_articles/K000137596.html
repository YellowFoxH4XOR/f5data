Description

  • You have a vCMP Host with a guest in the deployed state.
  • While upgrading the Host you put the guest into the provisioned state.
  • After booting the Host into the new volume, you notice the guest is now in the deployed state.

 

Environment

BIG-IP LTM
vCMP
Software Upgrade

Cause

The vCMP guest  was put into the provisioned state after the software installation had already taken place.

Note: When upgrading a vCMP Host, the state of its guest after booting into the new version is determined by its state prior to starting the software installation step of the upgrade process.
Changes made to the state of the guest after the software installation step ( for example just before booting into the new version) will not be maintained upon booting into the new version.

Recommended Actions

Put the guest into the provisioned state before starting the software installation step of the upgrade process.
