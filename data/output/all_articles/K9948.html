Known Issue

This is the result of a known issue. If the value of the Command field in a custom WMI performance monitor is changed, and the GetCPUInfo command is no longer first in the list, the monitor will report the target node's CPU utilization as 100 percent.

F5 Product Development is tracking this issue as ID 249302 (formerly CR118163).

Workaround

You can work around this issue by ensuring that the GetCPUInfo command is listed first in the Command field for custom WMI monitors.

Note: The default setting for the Commands field in the WMI monitor template lists the GetCPUInfo command first.
