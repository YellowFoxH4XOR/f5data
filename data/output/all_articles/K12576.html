Known Issue

When using the Citrix XenApp Plugin (formerly known as PNAgent) with the BIG-IP APM system, the BIG-IP APM system may fail to recognize the Citrix XenApp Plugin. As a result, the Citrix XenApp client reports an error message that appears similar to the following example:

Unable to connect to server

The Citrix XenApp client check in the Citrix iRule fails because the test is case sensitive. Citrix has changed the case of the client spelling in recent versions of the client.

Note: For more information about configuring BIG-IP APM with Citrix XenApp, refer to the Deploying BIG-IP Access Policy Manager with Citrix XenApp deployment guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

F5 Product Development is tracking this issue as ID 340500 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP APM 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can work around this issue by replacing the original iRule defined in the deployment guide with this newer iRule. A separate DevCentral login is required to access this content; you will be redirected to authenticate or register (if necessary):

https://devcentral.f5.com/wiki/iRules.Citrix_APM.ashx
