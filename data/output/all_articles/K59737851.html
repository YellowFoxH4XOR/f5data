Description

Custom Bot defense signature using Regex matching does not trigger when receiving a request that should match the regex expression.  

Environment

  • BIG-IP ASM
  • Custom Bot signature with regex match rule

Cause

Bug ID 898413

Recommended Actions

Use 'Advanced Mode', and rewrite the custom Bot signature regex rule manually.
Note: Make sure to leave 'contains' in both options of the simple mode.

Additional Information

None.
