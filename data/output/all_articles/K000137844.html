K000137844: Location of minidump (.dmp) files when BIG-IP APM client-side components crash

Type
Support Solution
Published
2023-12-08
Updated
2023-12-08
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K000137844

Description

BIG-IP APM provides different components for Windows that perform different tasks like endpoint inspection, Windows Logon Integration, VPN services, etc. If such components crash for some reason, Windows Event logs (Application Event Logs) can log like:
 

Faulting application name: F5PolicyServer.exe, version: 7245.2023.1006.843, time stamp: 0x651fce62
Faulting module name: libwaapi.dll, version: 2023.8.31.140, time stamp: 0x64f05301
Exception code: 0xc0000409
Fault offset: 0x00062f26
Faulting process id: 0x279c
Faulting application start time: 0x01da2892eede0bd3
Faulting application path: C:\Windows\Downloaded Program Files\F5PolicyServer.exe
Faulting module path: C:\Windows\Downloaded Program Files\libwaapi.dll
Report Id: 4xxxxxxx-7xxx-4xxx-bxxx-2xxxxxxxxxxx
Faulting package full name: 
Faulting package-relative application ID: 

Environment

  • Windows
  • Different client-side components (endpoint inspection, Windows Logon Integration, VPN, etc. components)

Cause

A typical reason for such a crash is incompatibility issues between different software components of a client PC. However, to determine exact root cause analysis of crash dumps will be necessary.

Recommended Actions

When such crash logs are observed, a minidump file is usually generated under the below location:

%LOCALAPPDATA%\CrashDumps\

C:\Users\<username>\AppData\Local\CrashDumps>dir f5PolicyServer.exe.10140.dmp
 Volume in drive C is OSDISK
 Volume Serial Number is xxxx-yyyy

 Directory of C:\Users\<username>\AppData\Local\CrashDumps

12/07/2023  07:25 AM        69,426,925 f5PolicyServer.exe.10140.dmp
               1 File(s)     69,426,925 bytes
               0 Dir(s)  29,648,015,360 bytes free

C:\Users\<username>\AppData\Local\CrashDumps>


Collect the above minidump (.dmp) file along with an F5 Report generated using Client Troubleshooting Utility when opening up a support case.
