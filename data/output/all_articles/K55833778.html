K55833778: How to list in BIG-IQ all the BIG-IP units affected by the same heuristics issue

Type
Support Solution
Published
2022-11-10
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Platforms
Source
https://my.f5.com/manage/s/article/K55833778

Description


For automation purposes, it is necessary to use restcurl commands to gather results from BIG-IQ unit.

This is an example of how to use restcurl commands, to gather the heuristics affecting a specific OS version and all affected BIG-IP devices monitored in such BIG-IQ unit.


Environment

  • BIG-IQ
  • BIG-IP
  • CVEs
  • IDs


Cause


For automation purposes, it is necessary to retrieve  information from BIG-IQ of a list, in plain text, of heirustics data and affected, monitored BIG-IP units.


Recommended Actions


To generate a list of affecting heuristics, do the following sequence:

- Ensure desired BIG-IP units are being monitored in BIG-IQ unit.
- Generate and upload QKView files from all desired BIG-IP units from BIG-IQ unit.
- Identify at least one BIG-IP unit by its ID string in BIG-IQ unit.
- Run commands in BIG-IQ:


restcurl cm/device/ihealth/reports/650b7395-e97d-4972-8c37-820f32b5c314
