K000137881: F5 /Shared folder shows 100% full even after deleting some files

Source
https://my.f5.com/manage/s/article/K000137881

Description

The /shared directory shows it is 100% full. After deleting some files in the /shared directory it does not make any difference and the usage still shows 100%.

There are no deleted files being held by mcpd.

Environment

  • BIG-IP

Cause

Packet capture previously ran encountered an issue and is still running in the background (writing to /var/tmp)

Recommended Actions

Run the command below:

# ps aux | grep tcpdump     <<<----- Identifies the PID of the problematic tcpdump process (2nd column)

# kill -9 <PID>             <<<----- Change the PID to the value found in the previous command
