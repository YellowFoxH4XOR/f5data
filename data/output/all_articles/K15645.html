Known Issue

When using the Configuration utility, you cannot view Secure Socket Layer (SSL) certificate filestore instances with names that contain special characters.

This issue occurs when all of the following conditions are met:

  • While importing the SSL Certificate Revocation List (CRL), the name of an instance contains special characters, such as ampersands (&), asterisks (*), colons (:), question marks (?), equal signs (=), at signs (@), periods (.), and/or commas (,).
  • After importing is complete, you attempt to view the SSL certificate file instance name that contains special characters by using the Configuration utility System > File Management > SSL Certificate List menu.

When importing SSL certificate file instances such as keys, certificates, or CRLs into the Configuration utility, you must provide a unique name for the instance. The Configuration utility may allow you to create names with special characters. However, F5 recommends that you use only alphanumeric characters for the name field.

Impact

You cannot use the Configuration utility to view certificate instances with names that contain special characters.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Configuration utility System > File Management > SSL Certificate List page correctly displays the imported certificate instance with special characters.

    For example:

    sample-&123.crl
  • After you click the affected certificate instance name, the Configuration utility displays a message similar to the following example:

    Instance not found:/Common/sample-

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to view the certificate's related file instances whose names contain special characters. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. View the desired certificate using the following command syntax:

    list /sys crypto <certificate type> <name of certificate>

    Note: The tmsh utility treats certain special characters, such as asterisks and question marks, as wildcard characters. You must escape these characters by using the backslash character (\).

    For example, to view a CRL file named sample-&123.crl, you would type the following command:

    list /sys crypto crl sample\-\&123.crl
  3. To exit the tmsh utility, type quit.
  4. Press the Enter key.
