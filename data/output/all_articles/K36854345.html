Topic

The BIG-IP system allocates memory, CPU, and hard drive space to each provisioned module. Statically allocated memory is allocated in HugePage pools, with additional memory allocated to the host in support of the module.

A HugePage pool is a dedicated pool of contiguous, mapped memory that addresses both physical memory and virtual memory. This allows the BIG-IP system to more efficiently use paging when sequentially transferring large pieces of information from physical memory to virtual memory (disk), and virtual memory to physical memory.

Description

If you use the TMOS shell (tmsh) command show /sys provision, you can view the resource allocation for BIG-IP modules, or view the resource that is allocated to specific modules.

CPU utilization on single CPU or single core systems

CPU resources are explicitly provisioned in the BIG-IP configuration. When the Traffic Management Microkernel (TMM) is idle or processing low volumes of traffic, it yields idle cycles to other processes.

CPU utilization on multi-CPU or  multi-core systems

Prior to BIG-IP 11.5.0, each logical CPU core is assigned a separate TMM instance, and each core processes both data plane (TMM-specific) tasks and control plane (non-TMM-specific) tasks.

Beginning in BIG-IP 11.5.0, data plane tasks and control plane tasks use separate logical cores on systems with Intel Hyper-Threading Technology (HT Technology) CPUs. Even-numbered logical cores (hyperthreads) are allocated to TMM, while odd numbered cores are available for other processes.

Available command flags of the tmsh command are: afm, am, apm, asm, avr, cgnat, dos, fps, gtm, ilx, lc, ltm, pem, sslo, swg and vcmp.

The command output contains the following module resource allocation information:

  • CPU (%) column indicates the percentage of CPU that is allocated to the module.
  • Memory (MB) column indicates statically allocated memory (using huge pages, except for host, where it uses default 4KB pages)
  • Host-Memory column indicates memory allocated from the host for the module.
  • Disk (MB) column indicates the provisioned hard drive space allocated to the module.
