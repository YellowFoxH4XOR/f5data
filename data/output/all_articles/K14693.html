Issue

Error Message

CHASSIS_NOT_READY_REASON (38010969):

The switch is not ready for the operation: Non-Volatile RAM ECC error

Message Location

You may encounter this message in the following location:

  • In the ARX CLI

Description

This message occurs when the following conditions are met:

  • The ARX system has encountered a Non-Volatile RAM ECC error.
  • You are attempting to run a system or configuration level command.

Impact

The ARX system is in a standby state, and you are unable to configure the ARX system.

Recommended Actions

If you are encountering a Non-Volatile RAM ECC error message, you may clear the Non-Volatile RAM using the following procedure:

Impact of recommended action:  All pending namespace transactions will be lost. Any data that is in transition may become corrupted. The chassis halts immediately after clearing the NVRAM, and you must have physical access to the unit to power cycle it.

  1. Log in to the ARX CLI.
  2. Enable privileged mode by typing the following command:

    enable

  3. Clear the NVR messages by typing the following command:

    clear nvr

    You see output similar to the following example:

    WARNING WARNING WARNING WARNING WARNING WARNING WARNING WARNING

    This will erase the non-volatile RAM (NVRAM).

    The effects are:

    All pending namespace transactions will be lost.

    Any data that is in transition may become corrupted.

    The chassis will halt immediately after clearing the NVRAM.

    The chassis must be power-cycled to boot up.

    This should only be done on a switch that has been completely

    unconfigured and removed from the network,

    or on the advice of technical support.

    Are you sure you want to clear non-volatile RAM and halt the system? [yes/no]

    Please enter your userid to confirm clearing the non-volatile RAM: admin

    % INFO: Success clearing non-volatile RAM. Halting system....

  4. Physically turn off the ARX system, and then turn it on again.
