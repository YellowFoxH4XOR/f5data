Known Issue

The dpid process may leak memory.

This issue occurs when all of the following conditions are met:

  • You have provisioned the BIG-IP system with the PEM module.
  • Your BIG-IP system processes traffic for multiple subscribers.

Impact

The dpid process restarts, and may affect the application statistics collected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H438066 on the Diagnostics > Identified > Medium screen.
  • You observe a progressive increase in the amount of memory that the dpid process uses. To monitor the memory usage, you can use the top command.
  • When the dpid process restarts, you find that the /var/log/daemon log file contains a message similar to the following example:

    emerg logger: Re-starting dpid
