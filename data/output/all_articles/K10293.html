Topic

The FirePass Maintenance Console offers a variety of maintenance options for managing the FirePass controller, such as downloading a diagnostic dataset, repairing the FirePass database, and resetting a FirePass controller to its default settings.

Note: For information about accessing the Maintenance Console, refer to K9286: Accessing the FirePass Maintenance Console.
 
Configuring a password or resetting the existing password for the Maintenance Console

By default, there is no password set for the Maintenance Console. If you want to configure a password, or if you want to reset the existing password, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Security: Console Access Security page.
  3. Select the Enable Password for Maintenance Console check box if it is not already selected.
  4. Select the Change password check box.
  5. In the Password field, enter the new password for the Maintenance Console.
  6. In the Confirm Password field, re-enter the new password.
  7. Click the Go! button to save the changes.

Disabling a password requirement for the Maintenance Console

If you do not want to require a password for the Maintenance Console, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Security: Console Access Security page.
  3. Clear the Enable Password for Maintenance Console check box if it is selected.
  4. Click the Go! button to save the change.
