Description

XenApp servers are configured with the "Session window size" to be a percentage
This sets a parameter in the ICA file called for example: ScreenPercent=75
BIG IP is creating own ICA files and is ignoring this setting set by XenApp server

Environment

  • Webtop replacement
  • Citrix XenApp
  • APM Remote Desktop 

Cause

Unknown at time of publication 

Recommended Actions

In order to change the size, you may add custom parameter: ScreenPercent=<#>
  1. Go to  Access > Connectivity / VPN > VDI / RDP > Remote Desktops
  2. Click Remote Desktop object 
  3. Insert into Custom Parameters: ScreenPercent=<#>
    Note: Replace <#> with the desired value
  4. Click Finished
