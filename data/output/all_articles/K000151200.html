K000151200: Unexpected failover after recovery from /var full errors on active device.

Source
https://my.f5.com/manage/s/article/K000151200

Description

  • /var partition ran out of space on active F5 and the BIG-IP threw /var full errors.
  • /var files were cleaned up and /var space was restored.
  • F5 active device unexpectedly failed over to the standby a short time later.
  • Errors found in the logs match this article: BD/CP table discrepancy causing failover

 

Environment

BIG-IP LTM

 

Cause

  • No reboot of the active system after restoring /var storage space.
  • After running out of /var storage, a restart must be completed because the BIG-IP can be in a degraded state after the /var storage runs out.

 

Recommended Actions

Note: The following action is traffic impacting.  Perform a failover of the active to standby before restarting the system.

If /var fills up, clear space and issue "bigstart restart" as described in this article: BD/CP table discrepancy causing failover

bigstart restart
