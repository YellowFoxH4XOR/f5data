Description

Connections fail to a virtual server that uses a policy with a TCP port matching rule.

Reset logging may show the following causes when this issue occurs:

No server selected

No flow found for ACK

Environment

  • Policy rule matching against destination TCP port

Cause

Rule Options are configured to evaluate the remote TCP source port. This is the default configuration

Recommended Actions

Change the Policy Rule Options to apply traffic to local side of external interface.

Additional Information

The Options feature defines what the conditions of the rule are evaluated against. In the case of TCP port, it is important to use this option since TCP port applies in 4 places with a typical connection:

  • Client source
  • Client destination
  • Server-side source
  • Server-side destination
