Description

When attempting to deploy a BIG-IP APM virtual server using an Acceleration HTTP/2 profile and the HTTP MRF Router option is enabled, the virtual server no longer passes traffic.

Environment

  • BIG-IP APM
  • HTTP/2 profile
  • HTTP MRF Router

Cause

Currently attaching a HTTP/2 profile to a BIG-IP APM virtual server is not a supported configuration.
 

Recommended Actions

None
