Topic

Production BIG-IP system license files don't expire; however, evaluation and demonstration BIG-IP licenses do expire. This applies to add-on module evaluation licenses for all modules. Evaluation and demonstration license expire at 23:59:59 on the expiration date.

Important: If the BIG-IP system contains an evaluation or demonstration license, the BIG-IP system stops processing traffic when the license expires. You can renew evaluation or demonstration licenses only through your F5 Sales Representative.

Viewing the type of BIG-IP license your system contains

  1. Log in to the Configuration utility.
  2. Go System > License.
  3. Locate License Type.
    • If the License Type is Evaluation or Demonstration, the License Expiration Date is also listed.
    • If the License Type is Production, no License Expiration Date is listed.

Evaluation licenses and subscription service licenses granted by F5 have their own subscription service and expiration dates. When an evaluation license ends, the module becomes inactive and all configuration items are expected to stop functioning.

When a subscription period ends, the system service no longer receives updates. In the case of the IP Intelligence service, the IP address database becomes outdated. The subscription-based feature is expected to continue functioning as designed, but with outdated data.

Recommendations

If you convert an evaluation or demonstration BIG-IP system to a production BIG-IP system, you must activate the new BIG-IP production license. After activating the new BIG-IP production license, you must re-initialize the system to use the new license. For more information about license activation, refer to K2595: Activating and installing a license file from the command line.

If you purchased a time-limited or perpetual add-on license and used an evaluation or demonstration add-on earlier, F5 recommends deactivating the evaluation license (before or after it expires) and activating the purchased license. This is because, when evaluation and demonstration features expire, features enabled by evaluation and perpetual licenses also expire.  For more information, refer to Bug ID 469724. To use the get_dossier command to deactivate the eval/unwanted key while activating the purchased key, use the following command syntax:

get_dossier -b <Base_License> -a <Add-on_License> -i <Eval/Inactive_License>

Note: To apply the command to multiple keys using the -a or -i option, separate the keys with commas..

For example, the following command deactivates an expired key using example licenses:

get_dossier -b ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG -a ABCDEFG-YYYYYYY,ABCDEFG-XXXXXXX -i ABCDEFG-ZZZZZZZ
