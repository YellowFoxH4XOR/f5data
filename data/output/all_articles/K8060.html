Known Issue

This is the result of a known issue. The BIG-IP GTM Configuration utility has a client certificate field for the HTTPS monitor. The client certificate setting specifies a fully-qualified path for a client certificate that the monitor sends to the target SSL server. The BIG-IP GTM HTTPS monitor does not currently support client certificates, and the field is not functional on the BIG-IP GTM system.

F5 Product Development tracked this issue as CR83324 and it was fixed in BIG-IP GTM 10.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.

Workaround

If you want to configure an HTTPS monitor on the BIG-IP GTM system that supports client certificates, you can work around this issue by creating a custom Extended Application Verification (EAV), and installing the script in the /usr/bin/monitors directory on the BIG-IP GTM system. You can then create a monitor type named external and input the script name in the External Program field in the monitor template.

Note: You can use the following example monitor script as a template for your custom EAV:

/usr/bin/monitors/sample_monitor
