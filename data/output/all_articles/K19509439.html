Description

You want a way to selectively redirect incoming traffic so that internal and external networks go to different URLs.

Environment
  • BIG-IP LTM
  • Virtual Server
  • Local Traffic Policy or iRule

Cause

None

Recommended Actions

You can use an iRule or local Traffic Policy to compare an inbound connections source address with the built in private_net datagroup to determine if traffic is from the internal network or an external network.

iRule
  1. Go to Local Traffic > iRules > iRule List.
  2. Select Create.
  3. Name the iRule.
  4. Write your iRule in the Definition field. For example if you want internal traffic to go to web1 and external traffic to go to web2 you could use an iRule similar to the following:
    when HTTP_REQUEST {
      if { ( [class match [IP::client_addr] eq private_net] ) } {
        HTTP::redirect "https://web1[HTTP::uri]"
      } else {
        HTTP::redirect "https://web2[HTTP::uri]"
      }
    }
  5. Select Finished.
  6. Apply the iRule on your virtual server's Resources page.

Local Traffic Policy
  1. Go to Local Traffic > Policies > Policy List.
  2. Select Create.
  3. Name the policy.
  4. Choose first for Strategy.
  5. Select Create Policy.
  6. Open the draft policy if the Configuration utility doesn't open it automatically.
  7. Select Create in the Rules list.
  8. Name the first rule.
  9. In the conditions section select the + character.
  10. Choose TCP address matches in datagroup private_net at request time from the drop down menus. Leave options at the default of remote and external.
  11. In the actions section select the + character.
  12. Choose Redirect to location and at request time from the drop down menus.
  13. In the location field enter the URL you want to redirect internal traffic to. Prepend tcl: if you're using Tcl command substitution. For example:
    tcl:https://web1[HTTP::uri]
  14. Select Save.
  15. Select Create in the Rules list.
  16. Name the second rule.
  17. In the conditions section select the + character.
  18. Choose TCP address does not match in datagroup private_net at request time from the drop down menus. Leave options at the default of remote and external.
  19. Repeat steps 11 to 14, but this time include the URL you want to redirect external traffic to. For example:
    tcl:https://web2[HTTP::uri]
  20. Select the arrow next to Save Draft and select Save and Publish Policy.
  21. Apply the policy on your virtual server's Resources page.
