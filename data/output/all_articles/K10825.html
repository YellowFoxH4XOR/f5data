Known Issue

This is the result of a known issue. TMM may core during a system shutdown if the iRule NAME::lookup command is not finished processing a response.

The BIG-IP system behaves as though the iRule NAME::lookup command did not receive a response and the BIG-IP system issues another request while simultaneously tearing down data structures as part of the shutdown process. As a result, when the system attempts to communicate with the obsolete data structures, TMM dumps core.

F5 Product Development tracked this issue as CR131106 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
