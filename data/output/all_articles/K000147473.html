K000147473: Can I use a Delegated Domain in the DNS Load Balancer?

Type
Support Solution
Published
2024-11-08
Updated
2024-11-08
Applies to

  • F5 Distributed Cloud DNS Load Balancer
Source

What Happened?

  • I want to create a DNS Load Balancer with a Delegated Domain, is that possible?

Environment

  • Distributed Cloud (SaaS)
  • F5® Distributed Cloud
  • DNS Management
  • DNS Load Balancer

Resolution/Answer

  • No, it's not possible to use a delegated domain to create a DNS Load Balancer
    • delegated domains only allow the automatic creation of an A DNS record when an HTTP LB is created.
