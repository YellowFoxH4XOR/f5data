Issue

Note: This article applies only to the BIG-IP 8400 and 8800 platforms.

The following set of error messages may appear in the linux kernel message log (/var/log/dmesg) after booting the BIG-IP 8400 or 8800 platform from the compact flash drive:

VFS: Unknown err on root device "sdb5" - -6
VFS: Retrying... 1
hub.c: new USB device 01:07.2-2, assigned address 2
scsi4 : SCSI emulation for USB Mass Storage devices
VFS: Unknown err on root device "sdb5" - -6
VFS: Retrying... 2
Vendor: SILICONS Model: YSTEMS INC 512MB Rev: 0000
Type: Direct-Access ANSI SCSI revision: 02
Attached scsi disk sdb at scsi4, channel 0, id 0, lun 0
SCSI device sdb: 1019088 512-byte hdwr sectors (522 MB)
sdb: sdb2 sdb3 < sdb5 sdb6 sdb7 sdb8 sdb9 >

This error message indicates the system was unable to mount the root filesystem on the boot device. This error message may be logged when booting the BIG-IP from the compact flash drive due to the increased amount of time required to access the drive. The system attempts to mount the root filesystem five times before giving up. If all attempts fail, the system fails to boot. When seen subsequent to a successful boot, the error message is benign, indicating that a subsequent mount attempt succeeded.
