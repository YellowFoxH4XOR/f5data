Environment

  • LTM
  • HTTP Explicit Proxy

Cause

  • For scenario 1, it's the BIG-IP local-only self IP initiating the DNS query, the uplink firewall blocks this request and leads to BIG-IP not able to get the DNS record of the requested domain.
  • For scenario 2, it's the BIG-IP snat IP (the floating self IP for automap) initiating the TCP request, the uplink firewall blocks this request and leads to BIG-IP not able to build TCP handshake with the requested domain.

Recommended Actions

  • For scenario 1, allow the DNS query from the BIG-IP local-only self IP to public Internet in the uplink firewall.
  • For scenario 2, allow the TCP request from the BIG-IP snat IP to public Internet in the uplink firewall.
