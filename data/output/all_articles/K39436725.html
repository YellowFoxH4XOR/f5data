K39436725: Allow larger POST parameters for a URL (BIG-IP ASM)

Type
Support Solution
Published
2020-07-06
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K39436725

Description

Violation 'Illegal Parameter Value Length' occurred for a specific URL.

Allow larger POST parameters for the URL.

Environment

  • BIG-IP with ASM
  • ASM policy enforcement mode set to Blocking
  • Wildcard '*' Parameter
  • Parameter 'Detected Value length' is higher than the 'Expected value length'

Cause

The violation was generated as the length detected by ASM was larger than the configured 'Parameter Value Length'.

Recommended Actions

The following section describe steps for creating specific URL and specific parameter with required Parameter Value length.

Configure Allowed URL
Configure Allowed URL using the article K29418033: Configuring allowed or disallowed URL lists

Note: Please make sure that in the Header-based Profile section, the Content-Type that the Post contains is included.

Configure Parameter and Parameter Value Length

  1. Browse to Security > Application Security > Parameters > Parameters List
  2. Click on Create
  3. Fill the following accordingly:
    Parameter Name: <name_of_parameter>
    Parameter Level: URL (select the URL to which this parameter will be assigned)
    Parameter Value Length: <desired_value>
  4. Save 
  5. Apply Policy
