Description

Beginning in version 13 and later you may see the following log message.

01200015:4: Warning, ICMP error limit reached.

Environment

  • BIG-IP
  • ICMP

Cause

The error message can happen at the time when ICMP error notification from BIG-IP exceeds TM.MaxICMPRate db value. 
Additional information is found in K15089210. 

Recommended Actions

Following K411, you can get a packet capture taken from the BIG-IP to review ICMP traffic generated by the BIG-IP. After review if it is determined to be legitimate traffic, you can increase this value by the following:
  1. Log into the Command Line Interface (CLI).
  2. Enter TMOS by typing the following:
    tmsh
  3. Modify the value to the desired number by typing the following:
    modify sys db tm.maxicmprate value <desired value>
  4. Save the config by typing the following:
    save sys config

Additional Information

Prior to version 13, TMM did not log a message when it throttles ICMP messages due to TM.MaxICMPRate enforcement. This makes it difficult to diagnose why important ICMP messages, such as ICMP fragmentation needed, are not sent by TMM as expected.

It is best to review why the BIG-IP generated the amount of ICMP Traffic. Floods of traffic may/can trigger this message. But this message can happen even with (high volume of) legitimate traffic.
