Description

  • After manual failover, new Active node immediately turn to DoS Attack Status Dropped causing service disruption

Environment

  • AFM
  • Network Security enabled DoS profile
  • DoS Auto-thresholds

Cause

The Auto-threshold feature does not sync threshold and stats DoS vector history between DSC peers. This issue is tracked with the Bug ID 909409

Recommended Actions

No fix available at the time of creation of this article. As a workaround you can configure a high Auto-threshold floor.

  1. On GUI go to Security  >  DoS Protection > Protection Profiles 
  2. Click on the Network Security DoS profile in question
  3. Click on Network to expand and see the Attack vectors
  4. Click on the name of the vector in question
  5. On Properties locate Attack Floor EPS and set it to a high Auto-threshold floor.
  6. Click Commit Changes to System
