Description

BIG-IQ Bit Traffic Dashboard is showing the same statistics for every day.

Environment

  • BIG-IP ASM monitored by BIG-IQ
  • botd process keeps reporting following error in /var/log/botd/botd.log: 
    botd|ERR|Aug 04 06:05:56.640|6018|botd_asm_config.cpp:70|update_incident: ASM error: Async process socket is full - ignoring

Cause

botd process is probably stuck.
botd correlates bot detection data for reporting.

Recommended Actions

Restart botd process:
bigstart restart botd
This procedure should not impact traffic processing.

None
