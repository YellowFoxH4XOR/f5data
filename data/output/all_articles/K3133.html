Topic

The 3-DNS Controller does not refresh all path metrics at the Path Data Refresh interval; it limits the number of probes and selects probes based on priority. The 3-DNS Controller handles path metrics in this manner, because it is not possible to check tens of thousands of paths every few minutes. F5 recommends that you use the default setting for the Path Data Refresh interval.

Note: Prior to version 4.5.0, the 3-DNS Controller used a method called Regulation Increment, which was viewable through the Configuration utility. Starting in version 4.5.0, the 3-DNS Controller uses a more advanced method that is not viewable through the Configuration utility.

Verifying that paths are being probed

  1. From the navigation pane of the Configuration utility, click Statistics.
  2. From the Statistics screen, click Summary.
  3. Locate the Wide IP section and look at the By Preferred value.

If you get 80% to 90% using your preferred load balancing method, it indicates that the path probing/reap intervals setting is fine and that the 3-DNS Controller is probing all the paths that it can handle.
