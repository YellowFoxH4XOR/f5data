K73813035: When installing BIG-IQ, the options for License Manager and Data Collection Device are disabled.

Type
Support Solution
Published
2021-12-01
Updated
2023-02-21
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 7.X.X
Source
https://my.f5.com/manage/s/article/K73813035

Description
When installing a new BIG-IQ, the System Personality screen may display all three options

  • BIG-IQ Central Manager
  • BIG-IQ Data Collection Device
  • BIQ-IQ License Manager
But only the BIG-IQ Central Manager option radio button is available to be selected.

Environment

  • BIG-IQ as a License Manager or Data Collection Device

Cause
BIG-IQ License Manager and Data Collection Devices do not require licensing.
F5 is tracking this bug with ID1072905

Recommended Actions

  1. If your license does not include BIG-IQ Central Management, or you do not wish to use the BIG-IQ for Central Management, return to the License step of the setup wizard.
  2. Select "Skip License" and do not enter the base registration key information into the GUI.
  3. Proceed forward again through the setup wizard until you arrive at the System Personality screen once more.  You may now select "BIG-IQ License Manager" personality.

Additional Information
None.
