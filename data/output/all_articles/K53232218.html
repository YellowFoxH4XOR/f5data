Known Issue

In rare conditions, the sod daemon may produce a core file at shutdown during memory cleanup.

This issue occurs when the following condition is met:

  • The BIG-IP system is shutting down.

Impact

This issue causes minimal additional impact on services because the shutdown is already in process.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system generates a sod core file to the /shared/core directory before the system shutdown.

Resolution
