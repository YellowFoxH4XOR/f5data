Known Issue

Note: The Link Down Time on Failover setting specifies the amount of time that the interfaces are down when a unit fails over to standby. The setting is only available when the BIG-IP system is configured as the member of a redundant pair. By default, the Link Down Time on Failover setting is disabled, which means it is set to 0 (zero). The length of time the interfaces must remain down is expressed in tenths of a second, and legal values range from 0 (zero) to 10 (ten) seconds.

This is the result of a known issue. The BIG-IP system fails to accept values between 0.1 and 0.9 seconds for the Link Down Time on Failover setting.

If you attempt to configure the Link Down Time on Failover setting to a value between 0.1 and 0.9 seconds, using either the Configuration utility or the command line, the BIG-IP system fails to accept the new value and returns the following error message:

01070911:3: The requested value () is invalid for standby_link_down_time in failover

The BIG-IP system also returns the error message if you restore a UCS archive where the Link Down Time on Failover setting is set to a value between 0.1 and 0.9 seconds. This may occur during an upgrade from an unaffected version to one of the affected versions.

The BIG-IP system should not throw this validation error because values between 0.1 and 0.9 seconds are legal values.

F5 Networks Product Development tracked this issue as CR93877 and it was fixed in BIG-IP version 9.4.5. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator Release Notes.
