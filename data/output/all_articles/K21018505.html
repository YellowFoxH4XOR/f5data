Security Advisory Description

Unspecified vulnerability in the Java Runtime Environment (JRE) component in Oracle Java SE 7 Update 7 and earlier, 6 Update 35 and earlier, 5.0 Update 36 and earlier, and 1.4.2_38 and earlier allows remote attackers to affect availability, related to JSSE. (CVE-2012-5081)

Impact

A remote attacker can disrupt service on the vulnerable system.

Security Advisory Status

F5 Product Development has assigned ID 699973 (Enterprise Manager) and ID 552323 (ARX) to this vulnerability. Additionally, BIG-IP iHealth may list Heuristic H21018505 on the Diagnostics > Identified > Medium page.
