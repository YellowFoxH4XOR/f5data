Description

Scriptd cores when running backup iApp.

Note: The f5.automated_backup iApp is not developed by F5 and is not supported by F5.  This iApp was created in the DevCentral community, and support for this iApp is only available via DevCentral.

Environment

  • BIG-IP
  • f5.automated_backup iApp
  • scriptd core file generated

Cause

Bug ID 842193

Recommended Actions

The recommended and officially supported method for automating UCS backups can be found in the following article.
    K13418: Archiving UCS files using the logrotate and crontab utilities (11.x - 17.x )

Additional Information

Use the following command to check how long it takes to generate a UCS archive on BIG-IP:
time tmsh save sys ucs backup.ucs
