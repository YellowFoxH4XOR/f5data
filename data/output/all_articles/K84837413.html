Known Issue

The BIG-IP system may set the packet Quality of Service (QoS) priority to 3 when traffic is processed by an IP forwarding virtual server.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system configuration includes one or more IP forwarding virtual servers. 
  • The BIG-IP system receives packets with QoS priority set to any value other than 3.

Impact

Application performance may be affected based on how peer networking devices process packets with QoS priority 3.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice application performance issues when traffic is processed by a forwarding virtual server.

    Note: This may be particularly evident after you upgrade to an affected software version.

  • You notice that the BIG-IP system sets a packet QoS priority to 3 when you review packet captures.

Workaround

To work around this issue, you can modify the QoS values in the FastL4 profile. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure sets the QoS value for each processed packet to 0.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > FastL4.
  3. Click the name of the FastL4 that is associated with the IP forwarding virtual server.
  4. On the right side of the page, select the Custom check box.
  5. Under Settings, in the Link QoS to Client list, click Specify and set the value to 0.
  6. Under Settings, in the Link QoS to Server list, click Specify and set the value to 0.
  7. Click Finished.
