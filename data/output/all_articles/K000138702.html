K000138702: Edge Client for Windows: The error code is 2739

Type
Support Solution
Published
2024-02-23
Updated
2025-06-03
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000138702

Description

You are trying to uninstall Edge Client on Windows 10 from panel Programs > Programs and Features or using F5 Client Troubleshooting Utility application and you can see following error:

The installer has encountered an unexpected error installing this package. This may indicate a problem with this package. The error code is 2739

Environment

  • BIG-IP APM
  • BIG-IP Edge Client on Windows 10

Cause

Error 2739 is a result of the JScript engine not being registered on Windows 10

Recommended Actions

The Internal Error 2739 problem can be solved by registering the JScript.dll and VBScript.dll modules

Open Windows command prompt and navigate to

cd C:\windows\SysWow64

Register modules with commands:

regsvr32 jscript.dll

regsvr32 vbscript.dll

Additional Information

Windows files may be opened during the uninstallation process. If the issue persists, reboot the device and perform one or both of the following as needed:

  • use the Client Troubleshooting Utility to uninstall BIG-IP Edge Client again.
  • manually remove BIG-IP Edge Client components, taking care to verify each component is removed after running each command.

To do so, refer to K8253: Removing BIG-IP APM client components from Windows client systems.
