Description

  • Device becomes INOPERATIVE after reboot to newly installed version 17.x.

  • Logs contain:

01b90053:3: Match-direction 'both' has been deprecated and renamed to 'either' since this version. Please use 'either' instead.
01420006:3: Loading configuration process failed.

Environment

  • BIG-IP
  • AFM module

Cause

Match-direction 'both' has been deprecated as described in K000134859.

 Recommended Actions

  1. Log in to CLI/bash
  2. Backup the configuration file

cp /config/bigip.conf /config/bigip.conf.bckp

   ​​​​​3. Execute a command to replace "both" with "either":

sed -i -e 's/match-direction both/match-direction either/' /config/bigip.conf

   4. To save the configuration run:

tmsh save sys config

     5. To load the configuration run:

tmsh load sys config 

Additional Information

None.
