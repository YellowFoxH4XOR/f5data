Known Issue

The tmm process may restart and produce a core file when the virtual server receives a response with invalid Location headers.

This issue occurs when all of the following conditions are met:

  • The affected virtual server has the Redirect Rewrite setting enabled on the HTTP profile.
  • An incoming response from the remote server contains invalid Location headers.

Impact

The BIG-IP system may temporarily fail to process traffic while the tmm process restarts, and the system fails if configured for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • If the affected BIG-IP system is configured for HA, the system fails over to the standby system.
  • The tmm process restarts and produces a core file in the /shared/core directory.
