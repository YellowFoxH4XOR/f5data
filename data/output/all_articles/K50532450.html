Description

You see low strength protocols are being used under Statistics ›› Module Statistics : Local Traffic ›› Profiles Summary : <Client or Server> SSL or within the output of  show /ltm profile client-ssl global or show /ltm profile server-ssl global and want to identify which profiles are allowing these protocols

Environment

  • BIG-IP LTM
  • ClientSSL or ServerSSL Profiles

Cause

None

Recommended Actions

Use command line tools from the TMOS shell to find the affected profiles
  1. From the TMOS shell run the following command:
    show /ltm profile client-ssl | grep -E "TLS|Ltm::ClientSSL" | grep -v 1.2 | grep -v DTLS | grep -v ' 0'
From this command, you will see an output of any profiles that have processed TLS 1.0 or 1.1 connections.

Ltm::ClientSSL Profile: /Common/example_ssl_profile1
