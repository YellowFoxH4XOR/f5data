K000138365: [F5OS-A]Operator role is receiving an unauthorized error and not receiving the full page content

Type
Support Solution
Published
2024-01-25
Updated
2024-01-25
Applies to
  • F5OS
  • F5OS-A: 1.5.1
Source
https://my.f5.com/manage/s/article/K000138365

Description

When a user with an operator role tries to access the following pages from GUI:
  • Tenant Images
  • Software Management
  • File Utilities
  • Configuration Backup
  • System Report
Unauthorized error may displayed.

Furthermore, there are may be no items displayed on the below pages for users with the operator role:

  • File Utilities
  • Configuration Backup
  • System Report

Environment

  • F5OS-A
  • Operator role

Cause

This known issue is identified as ID1492401.

Recommended Actions

Monitor the progress of ID1492401.

Additional Information

None at this time.
