Issue

Error Message

notice mcpd[<PID>]: 01070931:5: Clustering quorum reached

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.

For example:

notice mcpd[5554]: 01070931:5: Clustering quorum reached

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • Any chassis platform performs normal start up.

Impact

None

Recommended Actions

None
