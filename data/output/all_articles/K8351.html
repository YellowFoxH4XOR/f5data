Known Issue

This is the result of a known issue. A timestamp conversion issue causes the BIG-IP ASM process, also referred to as the bd process, to use 100 percent of the CPU.

This issue occurs internally when the system is converting time values from millisecond counters. This issue can occur every 49.7 days, which corresponds with the millisecond counters wrapping or resetting back to 0 (zero).

F5 Product Development tracked this issue as CR92021 and it was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in hotfix BIGIP-9.4.3-14.3-HF3 issued for BIG-IP version 9.4.3. You may download this hotfix or a later version of this hotfix from the F5 Downloads site.
