Issue

Description

  • Network interfaces are flapping
  • Frequent log messages similar to the following in /var/log/ltm:

    info bcm56xxd[7553]: 012c0015:6: Link: <interface> is DOWN
    info bcm56xxd[7553]: 012c0015:6: Link: <interface> is UP

Environment

  • Network interface

Cause

Network interface flapping is typically caused by one of the following:

  • Speed or duplex mismatch
  • Faulty cable
  • Faulty SFP
  • Faulty interface

Recommended Actions

Perform the following procedures to troubleshoot this issue:

  • Checking the logs on the attached switch
  • Checking for a speed or duplex mismatch
  • Verifying SFP transceivers
  • Verifying cables
  • Verifying optical connections

Checking the logs on the attached switch

Review the logs on the attached switch. A layer 1 issue should be reported on both ends of the link. If there is no flapping reported on the switch, check for usage of a DEMUX or fiber patch channel between the devices.

Checking for a speed or duplex mismatch

By default, the BIG-IP interfaces are configured to auto-negotiate the media settings.

Run the following command to view the media settings for an interface:

list net interface <interface> media-active

Note: Replace <interface> with the interface that you wish to view media settings.

Confirm the speed and duplex settings match with those of the switch.

It may be necessary to manually set the speed or duplex setting if there is a mismatch.
For more information refer to: K14107: Configuring the media speed and duplex settings for network interfaces (11.x - 13.x).

Verifying SFP transceivers

Perform the following procedures and check if the issue persists after each step:

  1. Remove and re-insert the SFP transceiver on both ends of the cable.
  2. Place the same SFP on a different BIG-IP interface.
  3. Place the same SFP on a different switch interface.
  4. Swap the SFP for a known working SFP.

Verifying cables

Perform the following procedures and check if the issue persists after each step:

  1. Remove and re-insert the cable on both ends
  2. Put the same cable on a different BIG-IP interface
  3. Put the cable on a different switch port
  4. Swap the cable for a known working cable

Verifying optical connections

To troubleshoot issues relating to different aspects of optical connections, use the Digital Diagnostic Monitoring feature.

For more information refer to: K83253027: Overview of the BIG-IP Digital Diagnostic Monitoring feature
