Known Issue

When you use the Configuration utility to modify sFlow settings, the Configuration utility may report incorrect changes that do not match the TMOS Shell (tmsh).

This issue occurs when the following condition is met:

  • You use the Configuration utility to view or modify sFlow settings.

Impact

The BIG-IP system may incorrectly revert an object’s sFlow settings to the global sFlow configuration's values.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the Configuration utility to configure sFlow settings on a Virtual Local Area Network (VLAN), interface, or HTTP profile, specifying a poll interval or sample rate of 0 does not work consistently; your BIG-IP system may treat the modified rate as a value of 0 or "Default" (which is inherited from the global sFlow settings).

    Note: To view global sFlow settings in the Configuration utility, navigate to System > sFlow > Global Settings.

Workaround

To work around this issue, you can use tmsh to view or modify sFlow settings. To do so, perform the following procedures:

  • Using tmsh to view or modify sFlow settings for an interface
  • Using tmsh to view or modify sFlow settings for a VLAN
  • Using tmsh to view or modify sFlow settings for an HTTP profile

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Note: The following commands require access to the CLI.

Using tmsh to view or modify sFlow settings for an interface

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the current sFlow settings for an interface, use the following command syntax:

    list net interface <name> all-properties

    Output appears similar to the following example:

    net interface 1.3 {
        bundle not-supported
        bundle-speed not-supported
        description none
        enabled
        flow-control tx-rx
        force-gigabit-fiber disabled
        forward-error-correction not-supported
        if-alias none
        if-index 80
        lldp-admin txonly
        lldp-tlvmap 114552
        mac-address 00:50:56:92:4a:22
        media-active none
        media-fixed 10000T-FD
        media-max 10000T-FD
        media-sfp auto
        module-description none
        mtu 1500
        prefer-port sfp
        qinq-ethertype 0x8100
        serial none
        sflow {
            poll-interval 0
            poll-interval-global yes
        }
        stp enabled
        stp-auto-edge-port enabled
        stp-edge-port true
        stp-link-type auto
        vendor none
        vendor-oui none
        vendor-partnum none
        vendor-revision none
    }

    Note: A poll-interval value of 0 and poll-interval-global value of yes indicates the global default value (10) is used.

  3. To modify the sFlow settings for an interface, use the following command syntax:

    modify net interface <name> sflow { poll-interval [integer] poll-interval-global [no | yes] }

    Important: When changing poll interval values, you must set the corresponding global command to no to prevent a conflict with the global setting.

    For example:

    modify net interface 1.3 sflow { poll-interval 5  poll-interval-global no }

  4. Save the changes by typing following command:

    save sys config

Using tmsh to view or modify sFlow settings for a VLAN

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To view the current sFlow settings for a VLAN, use the following command syntax:

    list net vlan <vlan name> all-properties

    Output appears similar to the following example:

    net vlan test {
        app-service none
        auto-lasthop default
        cmp-hash default
        customer-tag none
        dag-round-robin disabled
        dag-tunnel outer
        description none
        failsafe disabled
        failsafe-action failover-restart-tm
        failsafe-timeout 90
        if-index 176
        interfaces {
            1.3 {
                app-service none
                tag-mode none
                untagged
            }
        }
        learning enable-forward
        mtu 1500
        partition Common
        sflow {
            poll-interval 0
            poll-interval-global yes
            sampling-rate 0
            sampling-rate-global yes
        }
        source-checking disabled
        tag 4092
    }

    Note: A poll-interval value of 0, poll-interval-global value of yes, sampling-rate value of 0, and sampling rate-global value of yes indicates the global polling interval default value (10) and global sampling rate (2048) are used.

  3. To modify the sFlow settings for the VLAN, use the following command syntax:

    modify net vlan <vlan name> sflow { poll-interval [integer] poll-interval-global [no | yes] sampling-rate [integer] sampling-rate-global [no | yes] }

    Important: When changing the poll interval or sampling rate, you must set the corresponding global command to no to prevent a conflict with the global setting.

    For example:

    modify net vlan test sflow { poll-interval 5 poll-interval-global no sampling-rate 1024 sampling-rate-global no }

  4. Save the changes by typing the following command:

    save sys config

Using tmsh to view or modify sFlow settings for an HTTP profile

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To view the current sFlow settings for an HTTP profile, use the following command syntax:

    list ltm profile http <http profile name>

    Output appears similar to the following example:

    ltm profile http http-test {
        accept-xff disabled
        app-service none
        basic-auth-realm none
        defaults-from http
        encrypt-cookies none
        enforcement {
            known-methods { CONNECT DELETE GET HEAD LOCK OPTIONS POST PROPFIND PUT TRACE UNLOCK
            max-header-count 64
            max-header-size 32768
            max-requests 0
            pipeline allow
            truncated-redirects disabled
            unknown-method allow
        }
        fallback-host none
        fallback-status-codes none
        header-erase none
        header-insert none
        hsts {
            include-subdomains enabled
            maximum-age 16070400
            mode disabled
        }
        insert-xforwarded-for disabled
        lws-separator none
        lws-width 80
        oneconnect-transformations enabled
        proxy-type reverse
        redirect-rewrite none
        request-chunking preserve
        response-chunking selective
        response-headers-permitted none
        server-agent-name BigIP
        sflow {
            poll-interval-global yes
            sampling-rate-global yes
        }
        via-request preserve
        via-response preserve
        xff-alternative-names none
    }

  3. To modify the sFlow settings for an HTTP profile, use the following command syntax:

    modify ltm profile http <http profile name> sflow { poll-interval [integer] poll-interval-global [yes|no] sampling-rate [integer] sampling-rate-global [yes|no] }

    Important: When changing the poll interval or sampling rate, you must set the corresponding global command to no to prevent a conflict with the global setting.

    For example:

    modify ltm profile http http-test sflow { poll-interval 5 poll-interval-global no sampling-rate 512 sampling-rate-global no }

  4. Save the changes by typing the following command:

    save sys config
