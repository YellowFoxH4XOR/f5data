K000152682: Remove the 'Server' HTTP response header in REST API

Type
Support Solution
Published
2025-07-23
Updated
2025-07-23
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000152682

Description

A customer reported that Jetty server detailed version information is exposed in the REST API response value.

The referenced URL in REST API is ;

https://<MGMT-IP>/mgmt/shared/authz/users/<username>

HTTP/1.1 200 OK
Date: Wed, 23 Jul 2025 20:59:19 GMT
Server: Jetty(9.2.22.v20170606)
Set-Cookie: BIGIPAuthCookie=gbCBBC3sFCzsNOytI92HkfWRlW4FRWF0K7OVHUIT; path=/; Secure; HttpOnly; SameSite=Strict
X-Frame-Options: SAMEORIGIN
Strict-Transport-Security: max-age=16070400; includeSubDomains
Content-Type: application/json; charset=UTF-8
Pragma: no-cache
Cache-Control: no-store
Cache-Control: no-cache
Cache-Control: must-revalidate
Expires: -1
Content-Length: 736
X-Content-Type-Options: nosniff
X-XSS-Protection: 1; mode=block
Content-Security-Policy: default-src 'self'  'unsafe-inline' 'unsafe-eval' data: blob:; img-src 'self' data:  http://127.4.1.1 http://127.4.2.1

And so, customer concerns that the Jetty server-related information is not exposed in the response header as a vulnerability.

Environment

  • BIG-IP LTM
  • REST API

 

Cause

None.

 

Recommended Actions

None. It is not possible to remove the Server HTTP response header in REST API.

On BIG-IP, Jetty is used as the embedded web server for the iControl REST API and the management GUI (control plane).
The presence of Jetty and its version is visible in HTTP response headers from the management interface, e.g., Server: Jetty(9.2.22.v20170606).
