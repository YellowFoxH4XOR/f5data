K72057215: Content Security Policy blocking HTTP content

Type
Support Solution
Published
2020-10-29

Source
https://my.f5.com/manage/s/article/K72057215

Description

HTTP content or pages is not loaded or displayed properly on my web browser.

  • The page doesn't t load and displays the error message "Requests to the server have been blocked by an extension."
  • Using the browser's dev tools or HTTP watch the following error is found: net::ERR_BLOCKED_BY_CLIENT
  • In Google Chrome when a Content Security Policy Script Violation happens you get a message like this one in the Chrome Developer Tools: Refused to load the script 'script-uri' because it violates the following Content Security Policy directive: "your CSP directive"
  • In Firefox you might see messages like this in the Web Developer Tools: Content Security Policy: A violation occurred for a report-only CSP policy ("An attempt to execute inline scripts has been blocked"). The behavior was allowed, and a CSP report was sent.


Environment

  • Content Security Policy (CSP) directives in use in the browser 
  • HTTP content being blocked 


Cause

The page or content is blocked because it violates the browser's CSP.
Some browsers incorporate the concept of Content Security Policy (CSP)  in order to mitigate a large class of potential cross-site scripting issues.

Recommended Actions

Modify the page's CSP directives that violated the policy. For more, please refer to the additional information listed below.
