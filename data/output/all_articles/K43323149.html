Topic

This article covers the BIG-IP system's default gateway failsafe threshold value.

Description

The gateway failsafe feature allows each BIG-IP system in a high-availability (HA) configuration to monitor a gateway pool and, by using a threshold value, specify the minimum number of gateway pool members that must always be available. If the number of available pools falls below the configured threshold value, the BIG-IP system triggers a gateway failsafe action.

By default, the Configuration utility sets the gateway failsafe threshold value to zero. A gateway failsafe action does not trigger when the threshold value is zero. When you configure the BIG-IP system to use gateway failsafe and trigger a failsafe action, ensure that the threshold value is greater than zero.
