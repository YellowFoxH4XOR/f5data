K000141466: Received multiple alertd error messages "read from timer_fd had missed timeouts: 2" post-upgrade

Type
Support Solution
Published
2024-11-19
Updated
2024-12-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000141466

Description

The BIG-IP system logs error messages to the /var/log/ltm file that appears similar to the below example.

 

Oct 11 06:27:02 bigip.example.com err alertd[7202]: 01100051:3: read from timer_fd had missed timeouts: 2.

Oct 11 06:29:02 bigip.example.com err alertd[7202]: 01100051:3: read from timer_fd had missed timeouts: 2.

Oct 11 06:31:02 bigip.example.com err alertd[7202]: 01100051:3: read from timer_fd had missed timeouts: 2.

Environment

  • BIG-IP 17.1.1
  • Upgrade

Cause

Unknown

Recommended Actions

Restart alertd with below command:

bigstart restart alertd

If the issue still persists after the alertd restarted, need to verify the dns setting and outbound SMTP configuration to ensure the dns resolve and outbound smtp in working condition.
