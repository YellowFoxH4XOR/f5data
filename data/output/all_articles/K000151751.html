K000151751: Adding devices to a sync failover group fails with error message "01070734:3: Configuration error: Invalid Devicegroup Reference."

Description

  • You may encountred this error when apply the device-group

01070734:3: Configuration error: Invalid Devicegroup Reference. The virtual_server_profile (/Common/<object_name> /Common/<folder>/<object_name>) requires profile_clientssi (/Common/<folder>/<object_name>) to be syncd to the same devices

  • And error from command "show cm sync-status" similarly below

 Sync_failover_DeviceGroup (Sync Failed): A validation error occurred while syncing to a remote device
 Sync error on bigip1.local: Load failed from /Common/bigip1.local 01020036:3: The requested profile (/Common/<folder>/<object>) was not found.
 Recommended action: Review the error message and determine corrective action on the device
 Sync_failover_DeviceGroup (Sync Failed): A validation error occurred while syncing to a remote device

Sync_Only_DeviceGroup (Sync Failed): A validation error occurred while syncing to a remote device
Sync error on bigip2.local: Load failed from /Common/bigip2.local 01070151:3: Rule [/Common/<folder>/<object>] error: Unable to find pool (/Common/<pool_object>) referenced at line 24: [pool /Common/<pool_object>]

Environment

  • DSC cluster-group
  • 2 Devices in the same Sync-Only group
  • 2 Devices in the same Sync-Failover group
  • Use folder as the sub category configuration

Cause

  • The Sync_Only_DeviceGroup could not sync the "traffic object" such as Virtual server, Pool, , and Floating IPs. This is expected behavior.
  • The Sync_failover_DeviceGroup could sync the "traffic object" however, if the object/folder belong to incorrect "device-group" the "Sync_failover_DeviceGroup" will not have permission to sync a configuration from that "folder".
  • The "folder" is belong to incorrect device-group 
    • For example
      sys folder <folder> {
  device-group Sync_Only_DeviceGroup
  inherited-devicegroup false
  inherited-traffic-group false
  traffic-group traffic-group-1
}

Recommended Actions

  • If the "folder" has "traffic object" the folder should belong to "Sync_failover_DeviceGroup" instead of "Sync_Only_DeviceGroup", then the system will be able to sync "traffic object" between system.
  • However, if you don't want to use the "Sync_failover_DeviceGroup", please remove the traffic object from "folder", then the "Sync_Only_DeviceGroup" will be able to sync.
