K000138847: Importing an XML-formatted ASM Policy to BIG-IQ using iControl REST API

Description

While there is a GUI-based procedure to import an XML-formatted ASM policy, there are use cases where using BIG-IQ's iControl REST API is the preferred method of importing an ASM policy. 

 

Environment

  • BIG-IQ
  • Web Application Security (ASM) Policy
  • iControl REST API

Cause

None.

 

Recommended Actions

 

1. Get the size of the ASM policy XML file in bytes.

$ ls -al ASMPolicy.xml

-rw-r--r--@ 1 user staff 1169078 29 Feb 11:30 ASMPolicy.xml

 

2. Send a POST request towards BIG-IQ iControl REST API endpoint "/mgmt/cm/asm/policy-files/upload/" with the Content-Range header set to the format of 0-(size-1)/size.

$ curl --insecure --location "https://${BIGIQ_IP_ADDR}/mgmt/cm/asm/policy-files/upload/ASMPolicy.xml?name=myImportedAsmPolicy" \

--header 'Content-Type: text/plain' \

--header "x-f5-auth-token: ${F5TOKEN}" \

--header 'Content-Range: 0-1169077/1169078' \

--data-binary '@/path/to/file/ASMPolicy.xml'
