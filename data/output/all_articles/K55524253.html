Description

In this article, we will explain the APM AAA Radius event "Access-Reject packet from host.." that you might find in the APM logs.
For example:

"RADIUS module: authentication with '<user>' failed: Access-Reject packet from host <IP_address>:1812 (3)"

    Environment

    • BIG-IP APM
    • RADIUS

    Cause

    These events indicate that your user account encountered a RADIUS Access-Reject authentication failure. This essentially means that the user RADIUS request was rejected by the RADIUS server for one of the following reasons:

    • The user entered an incorrect password
    • The password is expired
    • The user account is suspended or locked out

    Recommended Actions

    To resolve this issue, please contact your server administrator to address the specific user account issue within the RADIUS server itself.
