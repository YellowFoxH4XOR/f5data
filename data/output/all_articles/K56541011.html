Description

After updating the SSL certificate for the Active Directory LDAP server used for user authentication it no longer includes the IP address as a SAN for the certificate and users cannot log into the BIG-IP with LDAP Credentials.

Environment

  • BIG-IP
  • Remote - LDAP authentication for BIG-IP users

Cause

The new certificate on the Active Directory LDAP server uses a hostname instead of an IP address and the BIG-IP configuration (System > Users > Authentication > Remote - LDAP) host is using an IP address.

Recommended Actions

To change the host value within the LDAP authentication settings of the BIG-IP use the following procedure:
  1. Log on to the BIG-IP Configuration utility (gui).
  2. Go to System > Users  > Authentication.
  3. Click
    Change.
  4. In the Primary section set Host: to the hostname used by the SSL certificate.
    Note: The BIG-IP must be configured with DNS to resolve the hostname to the IP address of the LDAP server.
  5. Click Finished.
