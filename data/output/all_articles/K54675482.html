Issue

Error Message

010d0005:0: Chassis fan <fan> status <speed> is bad.

In this error message, note the following:

  • <fan> is the failed chassis fan.
  • <speed> is the rotation speed reported by the sensor.

For example:

010d0005:0: Chassis fan 4: status (0) is bad.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The platform LCD panel

    Note: The platform alarm LED may also turn red.

Description

This message occurs when the following condition is met:

  • A sensor on the BIG-IP system reports that the fan speed is zero (0) RPM, which indicates that the chassis fan is not rotating.

Impact

The cooling capacity of the BIG-IP system is reduced, increasing the risk of overheating.

Recommended Actions

You can run the system_check -d command from the BIG-IP system command line to determine the status of the system fans. If a hardware failure is suspected, you should perform End-User Diagnostics (EUD) tests to generate a diagnostic report.

For information about EUD tests, refer to K7172: Overview of the End User Diagnostics software.
