Description

Renaming a GTM (GSLB) pool via an AS3 declaration fails with the following error when the pool is referenced by a WideIP (GSLB_Domain) object

 

```

"code": 422,

"message": "declaration failed",

"response": "01070233:3: Wideip Pool refers to nonexistent Pool <...>"

```

 

This error indicates that the WideIP object still references the old pool name, which no longer exists after the object has been renamed.

Environment

 

  • BIG-IP DNS
  • AS3 Deployment with WideIP object

 

Cause

Bug ID 1962085

AS3 does not support renaming a GTM (GSLB) pool when it is actively referenced by a WideIP (GSLB_Domain) object within the same declaration. 

During processing, the reference from the WideIP to the old pool name causes a validation failure because the renamed pool no longer matches the expected reference.

Recommended Actions

To rename a GTM (GSLB) pool successfully, use this multi-step process:

1. Remove or Update WideIP Reference:

    Submit an AS3 declaration that removes or updates any WideIP (GSLB_Domain) objects referencing the target pool.

2. Rename the Pool:

    Submit an AS3 declaration that renames the GTM (GSLB) pool as needed.

3. Re-add or Update WideIP Reference:

    Submit an AS3 declaration that re-adds or updates the WideIP object(s) to reference the newly named pool.

 

Example Sequence:

Declaration 1: Remove or update all references to the target GSLB_Pool in GSLB_Domain objects.

Declaration 2: Rename GSLB_Pool as desired.

Declaration 3: Re-add or update GSLB_Domain objects to reference new GSLB_Pool name.
