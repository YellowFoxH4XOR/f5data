Topic

This article applies to BIG-IP version 11.x and later. For information about earlier BIG-IP versions, refer to the following article:

  • K8817: Preventing a standby member of a sync-failover group from rebooting when a VLAN failsafe event is triggered (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to prevent a non-active member of a sync-failover group from rebooting when a Virtual Local Area Network (VLAN) failsafe event is triggered.

Description

The failover.vlanfailsafe.standbynoaction BigDB variable allows an administrator to prevent a standby unit with VLAN failsafe enabled from rebooting when network traffic is not detected on a vlan-failsafe-enabled VLAN. This behavior overrides the default behavior and effectively configures a standby unit to ignore VLAN failsafe alerts.

This behavior is common in high-availability firewall and switch configurations that remain in standby or ready mode, and do not allow traffic to pass until they become the active unit.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You must have a properly-configured sync-failover group.

Procedures

Enabling the DB variable

Impact of procedure: The High Availability table will no longer accurately affect the status of the VLAN failsafe configuration on a standby unit.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Enable the failover.vlanfailsafe.standbynoaction database key by typing the following command:

    modify /sys db failover.vlanfailsafe.standbynoaction value enable

    Note: To disable the database key, you can type the following command:

    modify /sys db failover.vlanfailsafe.standbynoaction value disable

  3. Save the change by typing the following command:

    save /sys config

  4. Propagate the changes to other members of the sync group with either of the following options:
     
    • Repeat steps 1 through 3 on all members of the sync-failover group.
    • Sync the change to all the members of the sync-failover group by using the following command syntax:

      run /cm config-sync to-group <name of sync-failover group>

      For example, you would enter the following command to sync the change to all member of the myhagrp sync-failover group:

      run /cm config-sync to-group myhagrp
