Description

The Cloud Failover Extension (CFE) may not be properly installed or functioning, resulting in a '404' error when attempting to access specific CFE endpoints. When a user tries to retrieve responses for the following CFE endpoints, a '404' error code is returned:

Example commands:

# curl -su admin: -X GET http://localhost:8100/mgmt/shared/cloud-failover/info | jq .  
{  
  "code": 404,  
  "message": "",  
  "referer": "Unknown",  
  "errorStack": []  
}  

# curl -su admin: -X GET http://localhost:8100/mgmt/shared/cloud-failover/declare | jq .  
{  
  "code": 404,  
  "message": "",  
  "referer": "Unknown",  
  "errorStack": []  
}  

 

Environment:

BIG-IP LTM
Cloud Failover Extension (CFE)
HA

 

Cause

This issue may be related to improper installation or configuration of CFE or a system provisioning problem.
 


Recommended Actions

Reinstall the latest version of the Cloud Failover Extension (CFE).
Verify the system provisioning by navigating to System > Resource Provisioning.
Ensure the Management provisioning is set to Large.
