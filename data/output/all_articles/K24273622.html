K24273622: After a BIG-IP device is added to BIG-IQ framework upgrade will not work.

Type
Support Solution
Published
2019-10-10
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 6.X.X, 5.4.X
Source
https://my.f5.com/manage/s/article/K24273622
Description

When adding a device in BIG-IQ and presented with question of whether or not you'd like to 'upgrade device framework' - do not bypass this as you will not be able to upgrade the framework for this device at a later date without having to remove the device and re-discover again. 

Environment

  • BIG-IQ
  • adding another device such as a BIG-IP
    • more specifically an AFM ASM or other module
Cause

When using BIG-IQ to manage BIG-IP devices, the BIG-IQ design requires rest framework on both BIG-IQ and BIG-IP to be current or compatible between both systems. As such F5 recommends that if a rest framework upgrade is presented as an option during the upgrade then it is recommended to perform the rest framework upgrade first. This is due to framework protocols having a dependency and thus need to be compatible between both systems (BIG-IQ & BIG-IP) in order to properly to manage the devices.

Important: For these reasons it's best practice to perform the framework upgrade if prompted when adding a BIG-IP device to BIG-IQ

Recommended Actions

  1. Do not bypass the framework upgrade step when adding a device.   
  2. If you don't see the option to upgrade the framework then you don't need to.
