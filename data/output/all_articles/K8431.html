Ending a user's active FirePass session

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Reports: Sessions page.
  3. In the Current sessions section, locate the user's session that you want to terminate.
  4. Next to the user's session ID, click the Kill link.
  5. In the confirmation window that appears, click the OK button.

Ending all active FirePass sessions (except the current administrator session)

  1. Logon to the FirePass Administrative Console.
  2. Navigate to the Device Management: Maintenance: User Session Lockout page.
  3. Click the Kill all sessions (except this one) link.
  4. In the confirmation window that appears, click the OK button.
