Description

Configured password policy is not being enforced for local users. BIG-IP LTM unit is logging the following:

/var/log/ltm

warning mcpd[5523]: 01b50047:4: The system auth source type <auth-type> does not support rewrite system-auth for update on auth password policy.

In this error message, note the following:

  • <auth-type> is the configured authentication mode such as Active Directory or TACACS.

For example:

warning mcpd[5523]: 01b50047:4: The system auth source type (activedirctory) does not support rewrite system-auth for update on auth password policy.

Environment

  • BIG-IP LTM

Cause

  • You are using AAA provider such as Active Directory or TACACS.
  • Trying to enforce password policy for users with an unsupported authentication type.

Recommended Actions

Defining users need a supported password policy when using AAA auth, if you encounter this error then make sure to remove the any unsupported password policy which affects local users.
