Known Issue

Note: The allowIncompleteChunkedResponses setting in the /config/wa/pvsystem.conf file allows the BIG-IP WebAccelerator to process incorrectly chunked responses, such as those that do not include the terminating zero-sized chunk. For more information, refer to K10740: Allowing incomplete chunked responses.

This is the result of a known issue. Beginning in BIG-IP WebAccelerator version 10.0.0, the allowIncompleteChunkedResponses setting in the /config/wa/pvsystem.conf file is no longer functional. As a result, the BIG-IP WebAccelerator does not respond with an HTTP 500 Internal Server Error response when the origin web server returns incomplete chunked responses if the allowIncompleteChunkedResponses setting is set to false (default).

F5 Product Development is tracking this issue as ID 340158.
