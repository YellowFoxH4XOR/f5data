Known Issue

The BIG-IP AFM firewall policy properties page may not display all rules associated with a policy.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration contains a firewall policy with more than 100 rules.
  • From the Configuration utility, you navigate to the Security > Network Firewall > Policies page.
  • You select a policy that contains more than 100 rules.

Impact

When accessing a network firewall policy from the Configuration utility, users cannot view all associated rules.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you navigate to the Configuration utility Security > Network Firewall > Policies page, and select a policy with more than 100 rules, the system only displays the first 100 rules.
  • At the bottom of the Security > Network Firewall > Policies page list, the page indicator always shows Page 1 of x (where x is the total number of pages).
