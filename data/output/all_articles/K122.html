Topic

To view the type of network card installed in BIG-IP, type the following command:

ifconfig -a

The output will display an installed network interface card that matches one of the following interface names:

Interface NameType of card
expVarious Intel 100BaseTX, 100BaseT4, and 10BaseT Ethernet cards
wxIntel 82543 fiber gigabit Ethernet card
hmcHamachi fiber gigabit Ethernet card
fxpPacket Engines GNIC-II fiber gigabit Ethernet card
fpaDEC DEFPA-DB FDDI card
