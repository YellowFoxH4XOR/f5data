Description

External references in policy are defined as any code blocks that can be used as part of the policy without being explicitly pasted within the policy file. This means that you can have a set of pre-defined configurations for parts of the policy, and you can incorporate them as part of the policy by simply referencing them. one desired way is over HTTP protocol by using URL reference, This is a very useful method when trying to combine or consolidate parts of the policy that are present on different server machines.

Environment

Relevant environmental factors specific to the topic

  • NGINX App Protrct
  • WAF Declarative Policy
  • HTTP Protocol

Cause

Save a lot of overhead having to concentrate everything into a single policy file.

Recommended Actions

In the Declarative Policy page, there is an indication for each element if it supports such reference under the "Reference" column. here's an example configuration:


"override-rules": {

"$ref" : "http://<link>"

}
