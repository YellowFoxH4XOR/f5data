Topic

Beginning in FirePass version 5.4, the behavior of the failover system was changed. The new failover system improves on the old failover system in the following ways:

  • The new failover system is not impacted by user space resource constraints
  • The failover timeout has been reduced from 30 seconds to 3 seconds
  • The new heartbeat signal is now sent ten times per second, rather than once per second
  • In the event that both members of a redundant pair become active or standby simultaneously, node 1 becomes active, while node 2 becomes standby

Using the legacy failover heartbeat

If you want to use the legacy failover heartbeat, you can configure a version 5.5 and later FirePass controller by performing the following procedure:

Note: F5 recommends using the new failover subsystem because of the benefits provided in the bulleted list. For information about configuring FirePass version 5.4.x for the legacy failover heartbeat, refer to K5611: Configuring FirePass to use new failover features introduced in version 5.4.

Important: You must configure both the active and standby controllers with the same failover heartbeat configuration.

  1. Log in to the Administrative Console.
  2. In the main navigation pane, select Device Management.
  3. In the upper navigation pane, select Maintenance.
  4. In the sub-menu, select Troubleshooting Tools.
  5. Click the Please click here to start a Telnet session to the Maintenance Account link.
  6. Log in to the console as maintenance.
  7. Press Enter on Yes to acknowledge the conditions.
  8. Select the following option for your version:
    • For FirePass version 5.5.x, select the d Enable/Disable legacy failover heartbeat mechanism option.
    • For FirePass versions 6.0.0 and later, select the b Enable/Disable legacy failover heartbeat mechanism option.
  9. Select Yes to enable legacy failover heartbeat or select No to disable legacy failover heartbeat.
  10. Select the 0 Exit option.
  11. Repeat this procedure on the other unit in the redundant pair.
