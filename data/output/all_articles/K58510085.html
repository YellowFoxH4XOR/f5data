Description

CPU usage increased on the idle system after an upgrade from v12 to v14 or higher.

Environment

  • BIG-IP Virtual Edition
  • VMware Host
  • CPU usage increase after an upgrade on idle system

Cause

There is a major driver change between v12.1 and v14.1. From the 'unic' driver to the 'vmxnet3' driver. The unic driver polls at around 1-2K polls/sec, whereas the vmxnet3 polls at over 10K poll/s. It is expected to see an increase in CPU on an idle v14.1 system as a result of this. This does not scale through and under load, the difference should be negligible.

Recommended Actions

None. This is expected behavior.

None.
