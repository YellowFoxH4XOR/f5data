K62214153: The BIG-IQ system no longer returns diagnostic result in Upgrade Advisor Reports

Topic

On January 1, 2020, F5 discontinued the upgrade adviser feature of the F5 iHealth service. With this change in behavior, the system cannot return any diagnostic results in BIG-IQ Upgrade Advisor Reports. For more information about the discontinued upgrade adviser service, refer to: K18074701: iHealth Upgrade Advisor feature is discontinued

Note: Beginning in BIG-IQ 7.1, the Upgrade Adviser Reports functionality is removed from the BIG-IQ system.
