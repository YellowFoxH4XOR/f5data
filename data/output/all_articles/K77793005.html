Description

Trying to renew the default Traffic Certificate, default.crt, using the GUI option to Renew on: System > Certificate Management > Traffic Certificate Management > SSL Certificate List > default.crt

You get the following error displayed on the GUI:

Key management library returned bad status: -99, 01070712:3: Access check failed for (/Common/default.crt).

The following error appears on /var/log/ltm:

err mcpd[<PID>]: 01070712:3: Caught configuration exception (0), Access check failed for (/Common/default.crt)..

Environment

  • Default Traffic Certificate

Cause

Unknown at time of publication.

Recommended Actions

Renew the default.crt using the BIG-IP command line to re-generate the certificate, following the procedure on: K13579: Generating new default certificate and key pairs for BIG-IP SSL profiles.


Note: After previous procedure, the certificate new expiration date might still not show updated when listing the certificate details with: tmsh list sys crypto cert default.crt or on the GUI. This is due to the issue described on: K46527534: The Configuration utility may not display the correct expiry date of the renewed default SSL certificate and key pair. If this issue presents, reload MCPD as explained on: K13030: Forcing the mcpd process to reload the BIG-IP configuration.
