K000139042: BIP-IP APM Policy Sync is not compatible with Network Access Address spaces

Type
Support Solution
Published
2024-03-27
Updated
2024-03-27
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.0, 16.1.2, 16.1.1, 17.X.X, 16.1.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.4, 16.1.3
Source
https://my.f5.com/manage/s/article/K000139042

Description

When using the BIG-IP APM Policy Sync feature to synchronise an Access Policy to multiple BIG-IP APM units, you may encounter error messages related to "address spaces".

Sample error messages related to this unsupported configuration:

"01b7010d:3: The APM resource network-access (/Common/networkaccess_resource1) that is associated with the APM resource address-space (/Common/myspace1) does not exist."

"01b70105:3: System built-in APM resource address-space (/Common/default-all) cannot be modified."

 

Network Address spaces is a feature of Network Access which has been introduced in version 16.1 in order to allow dynamic exclusion of cloud traffic for application such as Office 365 or Zoom.

This feature is not compatible with the use of Policy Sync.

 

Environment

BIG-IP APM Network Access resource configured with address spaces.

Policy Sync is used to propagate a policy with that Network Access resource.

 

Cause

Policy Sync is not compatible with Network Access address spaces

 

Recommended Actions

You can either manually synchronize the policies or avoid using address spaces in your Network Access resources.

Note: Any previously configured address space, even if not currently enabled and visible in the Configuration utility, will be retained in the bigip.conf configuration file and need to be removed manually if configured once.

 Sample configuration related to address spaces:

 apm resource network-access /Common/networkaccess-resource1 {

   address-space-include {

       /Common/myaddress-space1 { }

   }

   address-space-exclude {

       /Common/myaddress-space2 { }

   }
