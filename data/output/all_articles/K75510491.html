Known Issue

On rare occasions, the Traffic Management Microkernel (TMM) may restart when the Class of Service (CoS) Global Settings option is enabled.

This issue occurs when the following condition is met:

  • You have enabled the CoS Global Settings option, located in the Configuration utility at Network > Class of Service > Global Settings.

Impact

Traffic processing is interrupted while TMM restarts and a failover event occurs if the BIG-IP system is in a high availability (HA) configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system fails to process traffic for a brief period.
  • Your BIG-IP system fails over to another host in the device group.
  • TMM has produced a core file in the /var/core directory.
