Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following article:

  • K14107: Configuring the media speed and duplex settings for network interfaces (11.x - 12.x)

Description

By default, the BIG-IP interfaces are configured to auto-negotiate the media speed setting. Ethernet devices do not implement auto-negotiation in the same way, which can cause issues when attempting to negotiate the correct link speed.

To avoid this issue, you can manually configure the media speed setting for all 10Mbps, 100Mbps, and 10/100Mbps interfaces.

Important: Fiber and copper gigabit interfaces use a different auto-negotiation mechanism and should be left at the auto setting.

Media speed setting options

The media speed setting on BIG-IP systems equipped with 10Mbps, 100Mbps, 10/100Mbps, and 1000Mbps interfaces can be configured to one of the following options:

  • 10baseT
  • 100baseTX
  • 1000baseT
  • 1000baseSX
  • 1000baseLX
  • 10GbaseT
  • 10GbaseSR
  • 10GbaseLR
  • 10GbaseER
  • auto

Duplex setting options

The options for the duplex setting for BIG-IP systems equipped with 100Base-TX interfaces are full and half.

Procedures

    Viewing the existing media speed and duplex settings

    1. Log in to the BIG-IP command line.
    2. To view the existing media speed and duplex settings for the interface, type the following command:

      bigpipe interface <interface> media show

      For example:

      bigpipe interface 1.1 media show

      The output should appear similar to the following example:

      INTERFACE 1.1 - media auto (100baseTX full)

      If the output matches your desired media speed, you do not need to manually configure the speed.

    Manually configuring the media speed and duplex setting

    Important: F5 recommends that you connect to the administrator or console port when you make any changes to the media setting. If you make an error while changing this setting, it is possible that you will interrupt service to the affected interface.

    1. Log in to the BIG-IP command line.
    2. To set media speed and duplex settings for the interface, type the following command:

      bigpipe interface <interface> media <speed> <duplex>

      For example:

      bigpipe interface 1.1 media 100baseTX full
    3. Confirm that the system is working properly with the new settings.
    4. To save the new setting, type the following command:

      bigpipe base save
    5. Confirm the saved settings by viewing the interfaces section of the /config/bigip_base.conf file. The configuration should appear similar to the following example:

      interface 1.1 {
      media 100baseTX full

    The system is now configured to use the new media speed and duplex settings upon boot up.
