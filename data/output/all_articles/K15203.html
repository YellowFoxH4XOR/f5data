Topic

This article applies to BIG-IP 10.x through 15.x. For information about other versions, refer to the following article:

  • K9067: Configuring IPv6 link-local self IP addresses (9.x)

You should consider using these procedures under the following condition:

  • You want to configure IPv6 link-local self IP addresses on the BIG-IP system. For example, the BIG-IP system is configured to use an advanced routing protocol (IS-IS) and is required to advertise IPv6 prefixes.

Description

The BIG-IP system automatically generates an IPv6 link-local address in the fe80::0/64 network for each VLAN configured on the system (based on the MAC address of the VLAN). If the BIG-IP system is configured to use an advanced routing protocol and is required to advertise IPv6 prefixes, you must configure an IPv6 link-local self IP addresses and floating self IP address so that failover occurs without interruption.

To configure an IPv6 link-local floating self IP address on the BIG-IP system, perform the following procedures:

  • Determining the VLAN tag using tmsh
  • Determining the VLAN tag using the Configuration utility
  • Configuring an IPv6 link-local self IP address on each system using tmsh
  • Configuring an IPv6 link-local self IP address on each system using the Configuration utility
  • Configuring an IPv6 link-local floating self IP address using tmsh
  • Configuring an IPv6 link-local floating self IP address using the Configuration utility
  • Converting the VLAN tag to hexadecimal (optional)

Important: Due to a known issue in certain BIG-IP versions, adding an IPv6 link-local self IP address to a VLAN may fail. For more information, refer to K15162: Adding an IPv6 link-local self IP address to a VLAN may fail.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have access to the Configuration utility or the TMOS Shell (tmsh).

Procedures

Determining the VLAN tag using tmsh

You must determine the VLAN tag for the VLAN in which you want to configure the IPv6 link-local floating self IP address. To do so, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To list the VLAN tag, use the following command syntax:

    list /net vlan <vlan_name> tag

    For example, the following command lists the VLAN tag for the VLAN named external:

    list /net vlan external tag

    net vlan external {
        tag 2020
    }

Determining the VLAN tag using the Configuration utility

You must determine the VLAN tag for the VLAN in which you want to configure the IPv6 link-local floating self IP address. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Network > VLANs.
  3. In the Tag column, locate the VLAN tag value.

Configuring an IPv6 link-local self IP address on each system using tmsh

Before you can configure an IPv6 link-local floating self IP address, you must configure an IPv6 link-local self IP address on each BIG-IP system, and append the VLAN tag to the end of the address.

For example, if the VLAN tag is 60, the following is a valid IPv6 link-local self IP address in the fe80:/64 network:

fe80::10%vlan60

After you have determined the IPv6 link-local self IP address you want to assign to the VLAN, you can create the self IP address using tmsh. To do so, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To create the IPv6 link-local self IP address, use one of the following command syntaxes:

    11.6.0 and later

    create /net self <selfIP_name> address <ipv6_addr>%vlan<vlan_tag>/<mask> vlan <vlan_name> traffic-group <non_floating_traffic_group>

    11.0.0 to 11.5.1

    create /net self <selfIP_name> address <ipv6_addr>/<mask> vlan <vlan name> traffic-group <non_floating_traffic_group>

    For example:

    11.6.0 and later

    create /net self MySelf address fe80::10%vlan60/64 vlan external traffic-group traffic-group-local-only

    11.0.0 to 11.5.1

    create /net self MySelf address fe80::10/64 vlan external traffic-group traffic-group-local-only

  3. Save the configuration by entering the following command:

    save /sys config

  4. Repeat the procedure on the redundant peer systems.

Configuring an IPv6 link-local self IP address on each system using the Configuration utility

  1. Log in to the Configuration utility. 
  2. Go to Network > Self IPs.
  3. Select Create.
  4. Enter the new non-floating self IP address name.
  5. For IP Address, enter the IPv6 address and VLAN tag using the following format:

    <IPv6 Address>%vlan<vlan tag>

    For example:

    fe80::10%vlan60

  6. For Netmask, enter the IPv6 netmask in hexadecimal notation similar to the following example:

    ffff:ffff:ffff:ffff::

  7. From the VLAN / Tunnel list, select the name of the VLAN to assign the self IP address to.
  8. For Traffic Group, ensure that traffic-group-local-only(non-floating) is selected.

    Note: traffic-group-local-only(non-floating) is the default value.

  9. Select Finished.
  10. Repeat this procedure on the redundant peer systems.

Configuring an IPv6 link-local floating self IP address using tmsh

After configuring the IPv6 link-local non-floating self IP addresses, you must configure an IPv6 link-local floating self IP address on one of the BIG-IP systems, and append the VLAN tag to the end of the address.

For example, if the VLAN tag is 60, the following is a valid IPv6 link-local self IP address in the fe80:/64 network:

fe80::12%vlan60

After you have determined the IPv6 link-local floating self IP address you want to assign to the VLAN, you can create the self IP address by performing the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To create the IPv6 link-local self IP address, use the following command syntax:

    create /net self <selfIP_name> address <ipv6_addr>%vlan<vlan_tag>/<mask> vlan <vlan_name> traffic-group <floating_traffic_group>

    For example:

    create /net self MySelf address fe80::12%vlan60/64 vlan external traffic-group traffic-group-1

  3. Save the configuration by entering the following command:

    save /sys config

Configuring an IPv6 link-local floating self IP address using the Configuration utility

  1. Log in to the Configuration utility.  
  2. Go to Network > Self IPs.
  3. Select Create.
  4. Enter the new floating self IP address name.
  5. For IP Address, enter the IPv6 address and VLAN tag using the following format:

    <IPv6 Address>%vlan<vlan tag>

    For example:

    fe80::10%vlan60

  6. For Netmask, enter the IPv6 netmask in hexadecimal notation similar to the following example:

    ffff:ffff:ffff:ffff::

  7. From the VLAN / Tunnel list, select the name of the VLAN to assign the self IP address to.
  8. For Traffic Group, select the name of the traffic group to assign the floating IP address to.
  9. Select Done.

Converting the VLAN tag to hexadecimal (optional)

As an alternative to using the %vlan60 syntax to specify the VLAN tag in the IPv6 link-local self IP addresses, you can convert the VLAN tag to hexadecimal and insert the tag into the IPv6 address directly. For example, a VLAN with a tag of 60 would be the following in hexadecimal:

0x3C

The syntax for IPv6 link-local self IP addresses is as follows:

fe80:<vlan tag in hex using big endian byte ordering>::<arbitrary value (1-ffff)>

As with the previous examples, if the VLAN tag is 60, the following is a valid IPv6 link-local self IP address:

fe80:3c::10
