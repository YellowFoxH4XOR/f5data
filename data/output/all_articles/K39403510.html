Topic

You should consider using this procedure under the following conditions:

  • You want to modify the port lockdown configuration on a system-wide level.
  • You want to modify the port lockdown configuration on an individual self IP address level.

Description

The port lockdown feature allows you to secure the BIG-IQ system from unwanted connection attempts by controlling the level of access to each self IP address defined on the system. The system refuses traffic and connections made to a service or protocol port that is not on the list. You can configure this list of allowed protocols and services either at a system-wide level using the network self-allow setting, or at the self IP address level with the self IP's allow-service setting using the TMOS Shell (tmsh).

Port lockdown default configuration

By default, every newly created self IP address associates with the default self-allow list of services. This system-wide port lockdown list applies to all associated self IP addresses through the allow-service setting with the default keyword. The list specifies that connections to the self IP address are allowed according to the protocols and services listed.

For the different default port lockdown configurations that vary across BIG-IQ versions, refer to the following table.

For optimal security, F5 recommends that you use the port lockdown feature to allow only the protocols or services required for a self IP address. For example, you can set the allow-service setting of a self IP address to none first, and add only protocols and services that are required for the self IP address.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have tmsh access to the BIG-IQ system with Administrator credentials.

Procedures

To manage the list of allowed protocols and services to the self IP address, you can choose either or both of the following methods to customize according to your environment:

  • Modifying the port lockdown configuration on a system-wide level
  • Modifying the port lockdown configuration on an individual self IP address

Modifying the port lockdown configuration on a system-wide level

To view the configuration of the default self-allow setting on your system, type the following tmsh command:

tmsh list /net self-allow

You can modify the list of allowed protocols and services that apply to the system-wide port lockdown configuration. In addition, when you configure a self IP address with the default keyword using the allow-service setting, this self IP address will inherit the system-wide port lockdown list.

To configure the system-wide port lockdown configuration using the self-allow setting, refer to the following examples:

  • Allowing all on self-allow
  • Allowing none on self-allow
  • Adding back the default list on self-allow
  • Adding a new protocol and port on self-allow
  • Removing a configured protocol and port on self-allow

Impact of procedures: F5 recommends that you perform the changes during a scheduled maintenance period. Changes to the list of self-allow settings will apply to all self IP addresses that are configured to use the default setting on a system-wide level. Ensure that you are changing the correct protocol(s) and service(s). If the changes are targeted only on the services affecting a specific self IP address, F5 recommends that you configure the changes on the allow-service of the specific self IP address level instead.

Allowing all on self-allow

To allow all types of protocols and services for self-allow, type the following command: 

tmsh modify /net self-allow defaults all

Allowing none on self-allow

To restrict all protocols and services for self-allow, type the following command:

tmsh modify /net self-allow defaults none

Important: F5 does not recommend setting self-allow to none without configuring any allowed protocols and services. This action will disrupt all services on your BIG-IQ system and trigger a failover on a high availability (HA) setup. F5 recommends that you perform this command in a scheduled maintenance window.

Adding back the default list on self-allow

To add back the default list of protocols and services of the self-allow setting according to your BIG-IQ version (refer to this table), use the following command syntax:

tmsh modify /net self-allow defaults replace-all-with { <PROTOCOL1>:<PORT1> <PROTOCOL2>:<PORT2> ... }

For example, to set the default list of protocols and services based on BIG-IQ 8.0.0, type the following command:

tmsh modify /net self-allow defaults replace-all-with { igmp:0 ospf:0 pim:0 tcp:161 tcp:22 tcp:4353 tcp:443 tcp:53 tcp:5432 tcp:9300 udp:1026 udp:161 udp:4353 udp:520 udp:53 }

Adding a new protocol and port on self-allow

To add a new protocol and port on the default self-allow list, use the following command syntax:

tmsh modify /net self-allow add { <PROTOCOL>:<PORT> }

For example:

tmsh modify /net self-allow add { tcp:8080 }

Removing a configured protocol and port on self-allow

To remove a configured protocol and port from the default self-allow list, use the following command syntax:

tmsh modify /net self-allow delete { <PROTOCOL>:<PORT> }

For example:

tmsh modify /net self-allow delete { tcp:8080 }

Modifying the port lockdown configuration on an individual self IP address

You can view the port lockdown configuration for the self IP's allow-service setting using the following tmsh command syntax:

tmsh list /net self <SELFIP-NAME> allow-service

To modify the port lockdown configuration on the allow-service setting assigned to any self IP address that you have configured on the system, refer to the following examples:

  • Allowing all on allow-service
  • Allowing none on allow-service
  • Allowing default on allow-service
  • Adding a new protocol and port number on allow-service
  • Removing a configured protocol and port on allow-service

Impact of procedure: F5 recommends that you perform the changes during scheduled maintenance period. Incorrect configuration on allow-service may cause connection disruptions of services.

Allowing all on allow-service

To allow all types of protocols and services access to a self IP address, use the following command syntax:

tmsh modify /net self <SELFIP-NAME> allow-service all

For example, to set the self IP address called my100sfip to allow all, type the following command:

tmsh modify /net self my100sfip allow-service all

Allowing none on allow-service

To restrict all protocols and services access to a self IP address, use the following command syntax:

tmsh modify /net self <SELFIP-NAME> allow-service none

Important: F5 does not recommend setting allow-service to none without configuring allowed protocols and services. This action will disrupt all services on your BIG-IQ system and trigger a failover on an HA setup. F5 recommends performing this command in a scheduled maintenance time.

For example, to set the self IP address called my100sfip to allow none, type the following command:

tmsh modify /net self my100sfip allow-service none

Allowing default on allow-service

To inherit the list of allowed protocols and services according to the port lockdown configuration for system-wide (self-allow setting), use the following command syntax:

tmsh modify /net self <SELFIP-NAME> allow-service default

Note: When using the default setting on allow-service for a self IP address, you can also add additional protocols and services as required.

For example, to set the self IP address called my100sfip to allow default, type the following command:

tmsh modify /net self my100sfip allow-service default

Adding a new protocol and port number on allow-service

To add a new protocol and port to the list of allowed services to a self IP address, use the following command syntax:

tmsh modify /net self <SELFIP-NAME> allow-service add { <PROTOCOL>:<PORT> }

For example, to add TCP port 8111 to the self IP address called my200sfip, type the following command:

tmsh modify /net self my200sfip allow-service add { tcp:8111 }

Removing a configured protocol and port number on allow-service

To remove a configured protocol and port in the list of allowed services to a self IP address, use the following command syntax:

tmsh modify /net self <SELFIP-NAME> allow-service delete { <PROTOCOL>:<PORT> }

For example, to remove the UDP port 8080 from the self IP address called my300sfip, type the following command:

tmsh modify /net self my300sfip allow-service delete { udp:8080 }
