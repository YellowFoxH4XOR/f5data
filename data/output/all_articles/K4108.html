K4108: Reasons why virtual servers that use a service timeout of less than eight seconds are demoted to software acceleration

Topic

Note: This articles applies only to BIG-IP 2400.

If the TCP or User Datagram Protocol (UDP) service timeout is less than the Packet Velocity ASIC (PVA) scrub period, virtual servers that use that service will be demoted to software acceleration mode.

You can set the PVA scrub period using the bigdb variable, Local.Bigip.FST.scrub_period_in_ms. Setting this value higher than thirty seconds is not recommended. The default value is eight seconds.

Starting in BIG-IP 4.5.11 and 4.6.3, virtual servers are demoted to software acceleration under the following conditions:

  • The TCP or UDP service timeout is set to 0.
  • The TCP or UDP service timeout is greater than the maximum PVA scrub period. The maximum PVA scrub period is equal to ((2^13)*scrub period).
