Security Advisory Description

Qemu, as used in Xen 4.0, 4.1 and possibly other products, when emulating certain devices with a virtual console backend, allows local OS guest users to gain privileges via a crafted escape VT100 sequence that triggers the overwrite of a "device model's address space." (CVE-2012-3515)

Impact

An attacker may gain privileged access by using a crafted escape sequence.
