K21121651: Creating an Address List with Ansible or iControl Rest using Firewall in the string, will require provisioning AFM.

Type
Support Solution
Published
2021-12-15
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.2
Source
https://my.f5.com/manage/s/article/K21121651

Description

Creating an Address List with Ansible or iControl Rest using Firewall syntax in the string will require provisioning AFM. If only LTM is provisioned, you will get the following output:

"One of the following features must be licensed/provisioned for the URI security/firewall/address-list : afm asm dos cgnat"

Environment

  • Ansible
  • iControl Rest
  • BIG-IP LTM

Cause

AFM needs to be provisioned when creating address lists using the firewall module.

Recommended Actions

  • Provision AFM. K12111
  • If AFM is not needed then you can consider the following:
    • For Ansible consider using the "bigip_command" module.
    • For iControl change the Rest string to use "/net/address-list" on the string.

Additional Information

Example of a successful curl to create an address list using /net/address-list:

# curl -k -u "admin:admin" -X POST -H 'Content-Type: application/json' -d '{ "name":"my_list_test", "addresses":["<IP_ADDRESS_1>","<IP_ADDRESS_2>"] }'

Example of an address list using Ansible with bigip_command module:

  - name: BIG-IP Command Module to add address lists
    hosts: <host_ip>
    connection: local
    gather_facts: no

    tasks:
      - name: run show version on remote devices
        bigip_command:
          commands:
            - create net address-list test_ansible addresses add { <IP_Address_1> <IP_Address_2>}
            - list net address-list test_ansible
          provider:
            server: <host_ip>
            server_port: 443
            password: admin
            user: admin
            validate_certs: no
        delegate_to: localhost

NOTE: Currently there is an ongoing RFE to allow the address list creation using the bigip_virtual_server module, please consider reviewing it and posting a comment to bring more visibility.
