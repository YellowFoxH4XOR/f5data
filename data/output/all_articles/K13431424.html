Description
Some scanners might show an issue with CBC mode ciphers and show them as weak

Environment

  • BIG-IP 
  • Client SSL profile
  • CBC ciphers

Cause
Most of the cipher suites supported by BIG-IP are CBC mode, even when they do not explicitly name it. This includes most AES and all Camellia cipher suites, as well as DES ciphers which are considered insecure and obsolete and so are disabled by default.

Cipher suites which do not use CBC include:

  • RC4 (insecure, obsolete, disabled by default)
  • AES-GCM
  • AES-CCM (introduced in v16)
  • ChaCha20-Poly1305 (disabled by default) 

All of the above ciphers are identifiable by the cipher suite name, e.g. AES256-GCM-SHA384

Recommended Actions

Removing CBC Ciphers using a cipher list

If you are using the DEFAULT cipher list, you can disable CBC ciphers by using the following cipher string:

DEFAULT:!AES:!CAMELLIA

Note that, in the cipher string, AES only refers to CBC ciphers.

For example, to remove CBC cipher for a Client SSL profile, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client.
  3. Select the name of the client SSL profile to modify.
  4. Set Configuration to Advanced.
  5. For Ciphers, select the Custom check box.
  6. Under Configuration, for Ciphers, select Cipher Suites.
  7. For Cipher Suites, enter the cipher string:
    DEFAULT:!AES:!CAMELLIA
    In this example, the following string allows the default ciphers for the SSL profile and blocks the AES and CAMELLIA cipher block chaining (CBC) mode ciphers:
  8. Configure remaining profile settings.
  9. Select Finished.

For more information on configuring ciphers on for SSL profiles, refer to K01770517: Configuring the cipher strength for SSL profiles (14.x - 21.x).

Removing CBC Ciphers using a cipher group:

  1. Create a New Cipher Rule
    1. Local Traffic >> Ciphers >> Rules
  2. Insert the following string into Cipher Suites: 
    AES:CAMELLIA
  3. Click Finished
  4. Navigate to the Cipher Group you want to modify.
    1. Local Traffic >> Ciphers >> Groups
  5. Select the newly created cipher rule under 'Available Rules' and move it to the section that reads 'Exclude the following from the Allowed List'
  6. Click Finished

For more information about configuring cipher suites for your clientSSL profile, refer to K01770517: Configuring the cipher strength for SSL profiles (14.x - 17.x).

Additional Information

CBC is historically the most commonly used AES mode, but it is being phased out as it is less secure than GCM and CCM. Most modern TLS clients support AES-GCM.
