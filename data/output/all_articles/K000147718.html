K000147718: Can I update values under the ves-system namespace?

What Happened?

I have a Kubernetes Cluster and want to update values like "VER_MASTER_LOCAL_IPS" that is on the ves-system namespace.

 

Environment

  • Managed Kubernetes
  • Virtual Kubernetes

Resolution/Answer

No. If you try you will receive an error message like the following one:

"Operation patch not allowed on resource daemonsets in namespace ves-system"

 

Cause

Some namespaces are reserved and restricted to being modified like kube-system, monitoring or ves-system
