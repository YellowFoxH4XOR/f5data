Issue

Error Message

err mcpd[<PID>]: 01b40001:3: A cipher group must be configured when TLS 1.3 is enabled (profile /<partition>/<ssl_profile>).

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <partition> is the partition in which the SSL profile is located.
  • <ssl_profile> is the name of the SSL profile.

For example:

err mcpd[8484]: 01b40001:3: A cipher group must be configured when TLS 1.3 is enabled (profile /Common/example_ssl).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You attempt to configure an SSL profile with TLS1.3 enabled.
  • The SSL profile is not associated with a cipher group.

Beginning in BIG-IP 14.0.0, you can enable TLS1.3 in an SSL profile with a prerequisite that a cipher group is associated with the profile. The cipher group configuration is expanded with cipher rules to include Elliptic Curve Diffie-Hellman key exchange algorithm (DH) groups and signature algorithms as required by TLS 1.3.

Impact

The creation or changes of the SSL profile configuration is not saved.

Recommended Actions

You should associate a cipher group before saving a TLS1.3 enabled SSL profile, to do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > SSL > Client.
  3. Click the SSL profile for which you want to associate with a cipher group.
  4. For Configuration, click Advanced.
  5. Select the Custom check box.
  6. For Ciphers , click Cipher Group.
  7. In the list, click a cipher group.
  8. Click Update.
