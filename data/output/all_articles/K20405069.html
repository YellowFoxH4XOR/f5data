Description

  • You want to redirect a client to a maintenance page when all pool members are down.
  • You want to display text and images on the maintenance page.
  • The image to be displayed will be hosted on the BIG-IP.
  • The image is not displaying correctly on the maintenance page.

Environment

  • BIG-IP
  • Redirect to maintenance page with text and image
  • Redirect to maintenance page using an iRule
  • Image for maintenance page hosted on the BIG-IP

Cause

None

Recommended Actions

  1. On the GUI (configuration utility), Navigate to System > File Management > iFile List > Click on Import and upload an image. For example: mylogo.png.
  2. Navigate to Local Traffic > iRules > iFile List > Click on Create and enter the same name mylogo.png and select the image previously uploaded, mylogo.png from the drop down list.
  3. Navigate to Local Traffic > iRules > iRule List > Create to create an iRule (see below). When the page is accessed by the client, the browser will get the image from the virtual server.
    Example iRule:
    Note: Please bear in mind this is an example iRule, with example HTML code, you can modify the text and name of the image, and most importantly, make sure to change http to https for the img src if you're using an HTTPS virtual server.

    when HTTP_REQUEST {
        if { [active_members [LB::server pool]] == 0 } {
            switch [HTTP::uri] {
                "/mylogo.png" {HTTP::respond 200 content [ifile get "mylogo.png"]}
                default {HTTP::respond 200 content "
                    <html>
                    <head>
                    <title>Maintenance Page</title>
                    </head>
                    <body>
                    <h2>Sorry</h2>
                    <p>
                    We are sorry, but the site you are looking for is temporarily out of service.
                    If you feel you have reached this page in error, please try again.
                    </p>
                    <img src=\"http://[HTTP::host]/mylogo.png\" style=\"width:228px;height:228px;\">
                    </body>
                    </html>"
                  }
             }
        }
    }
  4. Attach the iRule created to the respective virtual server.
  5. Test the maintenance page by disabling all pool members.
