Topic

This article provides information about how DNS prefetching features in various browsers may affect F5 products.

Description

DNS prefetching is a common feature in some modern client browsers, such as Internet Explorer, Firefox, and Chrome. The main goal of the DNS prefetching feature is to improve latency response by proactively performing DNS resolution for all links on a web page before a user tries to navigate to a link. Certain browsers may cache some of these DNS resolutions in its own memory over a period of time, while others may have an algorithm to reduce evictions of its DNS resolutions from the underlying operating system's DNS cache. Some browsers store these DNS prefetched resolutions for as long as 24 hours, while others store for the DNS prefetched resolutions for minutes and continuously use the cached entries until they are expired or the browser session is closed.

The behavior of the client browser's DNS prefetching feature may affect some F5 products, such as BIG-IP GTM. For example, the BIG-IP GTM system can be configured to respond to DNS requests based on availability of sites or applications, geolocation, or best round trip time to data center. Rather than using the intended DNS resolution from the BIG-IP GTM system, due to DNS prefetching in advance and the prolonged caching, the client browser may use a stale DNS resolution from its local cache. As a result, the client browser may experience intermittent slow loading of web pages, partially loaded web pages, or might even be unable to fetch web pages.

Recommendations

If you have determined that the client browser's DNS prefetching is altering the effectiveness of your F5 products, you should consider the following factors:

  • Disable DNS prefetching on the client browser. For information about disabling the DNS prefetching feature on the client browser, refer to the client browser documentation.
  • Flush the DNS entries on the client browser by closing/restarting the client browser.
