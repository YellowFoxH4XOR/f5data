Known Issue

This is the result of a known issue. When viewing the network map in the Configuration utility, the same iRule and/or pool member may be listed multiple times.

Note: You may view the network map by clicking Network Map on the Local Traffic menu, then clicking the Show Map button.

If more than one iRule is applied to a virtual server, and more than one pool member is defined in the default pool assigned to the virtual server, the number of instances of each iRule appearing in the tree is equal to the number of default pool members. For example, if you have a virtual server with three members in the default pool, and two iRules applied to the virtual server, each iRule will be listed three times.

Pool members may be listed multiple times if more than one iRule is applied to the virtual and two or more pool members in the default pool share a node address. For example, if you have a virtual server with three members in the default pool sharing the same node address, and two iRules applied to the virtual server, each pool will be listed two times.

F5 Product Development tracked this issue as CR99366 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.
