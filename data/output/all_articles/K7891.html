Issue

After launching a Portal Access Mobile E-Mail favorite, the FirePass controller may display a message similar to the following example:

Account could not be open.
Mail Server: {192.168.1.100/pop3/notls}
User name: my_username

The error message displays the IP address of the mail server, the email protocol (POP3 or IMAP), and the transport-layer security (TLS) protocol, if used (tls or notls), respectively.

This error message typically indicates that the username or password used to log in to the email server were incorrect, or that the email server was unreachable.

By default, when a user launches a Mobile E-mail favorite, the FirePass controller uses the FirePass login credentials to log in to the email server. Depending on whether the user is a local user or an external user, you can select the source of user information with the Logon Information drop-down menu on the Portal Access: Mobile E-Mail page.

In the case of incorrect credentials, the web page with the error message is typically rendered within seconds. In the case of an unreachable server, the web page with the error message will take several minutes to display.
