Known Issue

This is the result of a known issue. In some cases, when a plugin process such as pvac aborts, the TMM enters a recursive loop. As a result, this behavior causes the TMM and the plugin process to dump core.

F5 Product Development tracked this issue as CR130254 and it was fixed in BIG-IP version 10.1.0.  For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in BIGIP-10.0.1-378.0-HF3 issued for BIG-IP WebAccelerator version 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
