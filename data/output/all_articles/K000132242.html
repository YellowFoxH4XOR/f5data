Description

Dos Protection profile and Bot Defense Profile applied to Virtual Server affects the website.

 

After the user has entered username and password and clicked on "Login", the user is redirected to the login page again.

 

The following was also observed:

 

  • When both profiles are removed, it works
  • When Bot Defense profile is allowed but Dos protection profile is removed, it works
  • When Dos Protection profile is allowed but Bot Defense profile is removed, it works

 

Environment

  • Login Session timeout unexpectedly
  • Sometimes login page content missing
  • Sometimes the login button disappears
  • Users refresh the page several times for content to display
  • No Errors or event logs seen

Cause

Using the browser Developer, it was seen that Bot Defense Profile injects script after user clicks on "Login" to access the website.

 

In the Bot Defense Protection profile > Browsers , the Device ID mode is set to "Generate After Access" which is responsible for the script injection.

 

Simultaneously Dos Protection is injecting script for the Mitigation: "Client Side Integrity Defense".

 

These two injecting script simultaneously are affecting the website.

 

Recommended Actions

Device ID mode could be set to "Generate Before Access" or None.

Note: Should the recommended action fail to work, please contact Support for further assistance.
