Issue

Error Message

notice tmm[<PID>]: 01010044:5: <feature> feature <status> licensed

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <feature> is the name of the BIG-IP system component or feature.
  • <status> is the license status for the feature with a value of either is or is not.

For example:

notice tmm[13422]: 01010044:5: AFM feature is licensed

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions are met:

  • You start the BIG-IP system.
  • You activate or reactivate the license on the BIG-IP system.

Impact

If the message indicates that the feature is not licensed, you are unable to use the feature on the BIG-IP system.

Recommended Actions

To obtain licensing for BIG-IP features and modules, contact your F5 sales representative or F5 Technical Support.
