K6770: Content length limits for HTTP and HTTPS health monitors

Topic

An HTTP health monitor reads up to 5,120 bytes into HTTP data. If the monitor cannot find a match to the configured search string within the first 5,120 bytes, the BIG-IP marks the node as DOWN.

Note: When configured with an HTTP health monitor, the BIG-IP searches the HTTP header and data sections of the HTTP response.

If you require a health monitor that searches for a string deeper than 5,120 bytes into an HTTP response, you must create an Extended Application Verification (EAV) health monitor. The amount of data an EAV health monitor can read is determined by the program that the EAV uses (such as cURL) to read the data.

For specific instructions about configuring an EAV health monitor, refer to the BIG-IP Reference Guide.
