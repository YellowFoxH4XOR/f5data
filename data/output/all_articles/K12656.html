K12656: FirePass Forest mode Active Directory authentication may generate 'KDC_ERR_PREAUTH_FAILED' error messages

Topic

When Forest mode is configured for FirePass, the controller may generate KDC_ERR_PREAUTH_FAILED error messages. The user may view these messages in the Microsoft Windows security event logs and in network trace analysis. Under normal operation, users can safely ignore these messages. Environments that have tight security enabled in Active Directory, such as a low value in the Account lockout threshold or a high value in the Reset account lockout counter after attributes, may cause occasional user account lockouts in Active Directory.

This behavior is expected; it occurs because FirePass is unable to determine the domain for the user account in Forest mode and sends unknown domain information to the Active Directory KDC.
