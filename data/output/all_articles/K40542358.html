Description

Access/verification of  non-default value of internal ASM parameters is required in an automated way ( ie.: script )

Environment

  • BIG-IP ASM
  • value of internal parameter changed to non-default
  • Command Line Access

Cause

None

Recommended Actions

Execute following bash command: 
mysql -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'SELECT field_name,current_value FROM DCC.INTERNAL_CONFIG_ITEMS;'
