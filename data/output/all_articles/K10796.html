Important: F5 Product Development has recalled BIGIP-9.4.8-379.3-HF1 due to a possible memory leak. The memory leak issue is being tracked in CR133528, which is addressed in Hotfix-BIGIP-9.4.8-385.0-HF2. For more information, refer to K10903: BIG-IP 9.4.8 HF2 cumulative hotfix.

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.4.8. F5 recommends that all customers currently running 9.4.8 install BIGIP-9.4.8-379.3-HF1, or a later version of the cumulative hotfix rollup, as soon as possible.

The following CRs are fixed in BIGIP-9.4.8-379.3-HF1 for BIG-IP 9.4.8:
