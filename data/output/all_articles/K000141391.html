Description

  • Generate qkview from CLI on rSeries and Velos platform

Environment

  • rSeries
  • Velos

Cause

  • Generate qkview from CLI 

Recommended Actions

  • From confd (admin user access)
system diagnostics qkview capture
R5900# system diagnostics qkview capture 
result  Warning: Qkview may contain sensitive data such as secrets, passwords and core files. Handle with care. Please send this file to F5 support.

return code 200

system diagnostics qkview status

R5900# system diagnostics qkview status

resultint 0
  • Download qkview from WebGUI 
System Settings > File Utilities > Base Directory > diags/shared > qkview
  • Download via WinSCP

Directory: /var/F5/system/shared/qkview

    • From Linux bash (root user access) in case confd is down

    docker exec qkviewd qkview -filename qkview.tgz -max-file-size 1000 -max-core-size 1000

      • Verify the status

    docker exec qkviewd qkview -status

      • Destination folder is

    /var/shared/qkview/

    • From Linux bash (root user access) in case qkviewd is down

    qkview-collect

    Note. The resulting tarball does contain a manifest,json file, but not the sort that iHealth expects (it is missing a manifest.json file where 'package_type' is 'root'.) Thus, iHealth will fail to process a tarball generated using qkview-collect. Instead, please send the file to securefiles.f5com for F5 Support review.
