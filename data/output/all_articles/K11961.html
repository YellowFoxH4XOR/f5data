Topic

When attempting to view or change file permissions, the Mac OS X 10.6 DAVE client will only receive a User has read and write permission response.

This is the expected behavior for the DAVE client and is not an issue with the ARX software. Thursby Software recommends using ADmitMac software to change the file permissions.

Note: The ADmitMac software has not been qualified for use by F5 Product Development. For information about the current products qualified by F5, refer to K10909: F5 Data Solutions Compatibility Matrix.

F5 Product Development is tracking this behavior as ID 37324.
