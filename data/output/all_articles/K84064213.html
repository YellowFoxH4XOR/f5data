Known Issue

The BIG-IP APM configuration may fail to load after you perform an upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a Network Access profile that uses split tunneling.
  • The split tunnel configuration is set for Supported IP Version IPV4 and IPV6.
  • The IPV6 LAN Address Space is configured with the IPv6 any address of ::/0.
  • You upgrade to one of the listed versions.

Impact

The BIG-IP APM system fails to load the configuration after you upgrade the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to load the system configuration, you may observe an error message similar to the following example:

    01071164:3: apm resource network-access (/<partition>/<network access profile name>) param (IPv6 include subnet/LAN Address Space) can not be empty Unexpected Error: Validating configuration process failed.

  • When you view the bigip.conf file syntax for the network access configuration, the IPV6 split tunnel setting is set to none.

    For example:

    ipv6-address-space-include-subnet none

Workaround

To work around this issue, you can use a text editor to modify the IPv6 any address to the correct syntax. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Edit the /config/bigpipe/bigip.conf file using either the vi or pico text editor.
  3. Locate all configuration statements that match the following syntax:

    ipv6-address-space-include-subnet none

  4. Modify the syntax statement with the following lines:

    ipv6-address-space-include-subnet {
    {
    subnet ::/0
    }
    }

  5. Save the changes and exit the text editor.
  6. Reload the configuration by typing the following command:

    tmsh load /sys config

  7. After a successful load of the system configuration, save the running configuration by typing the following command:

    tmsh save /sys config
