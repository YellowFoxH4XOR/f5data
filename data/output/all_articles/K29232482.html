Description
Unable to create a CNAME

Environment

  • BIG-IP DNS 

Cause
A CNAME record cannot exist with any other records for the same name.  A name cannot both be an alias (CNAME) and something else at the same time.

Recommended Actions

  1. Look to see if the same name is being used for an MX record or is the apex record of a domain and remove it.

Additional Information
RFC1912 section 2.4
"A CNAME record is not allowed to coexist with any other data."
https://datatracker.ietf.org/doc/html/rfc1912
