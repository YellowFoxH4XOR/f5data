Description

You want to upgrade the BIG-IP software version.

  • You have uploaded the image to /shared/images.
  • The image md5 value is correct.
  • You can't find the image file at GUI menu System › Software Management : Image List or Hotfix List.
  • You may can see follow error log at /var/log/tomcat/catalina.out: 
2021-08-04 14:10:13,858 ERROR [TP-Processor8] sw_updates.SoftwareUploadHandlerBS3:doOperations - /tmui/system/sw_updates/software_list.jsp

Environment

  • BIG-IP
  • Upgrade software version

Cause

Unknown.

Recommended Actions

You may try any one of the following workarounds: 

  • You can try using TMSH to install a software image, point release, or software hotfix, use the following command syntax:

install /sys software <hotfix | image> <software>.iso volume <volume_number>

For example, to install BIG-IP 12.0.0 to new volume HD1.5, type the following command:

install /sys software image BIGIP-12.0.0.0.0.606.iso volume HD1.5 create-volume

Note: You can use tab completion in TMSH. To see the available images for installation, press the Tab key after you type the install sys software image command. For more details, please check K34745165: Managing software images on the BIG-IP system

  • You can attempt to install the base image first. For example, if you can't find the image file 11.6.5.3 in the configuration utility. Then you can attempt to upload its base image 11.6.5 and upgrade to this base version first.
