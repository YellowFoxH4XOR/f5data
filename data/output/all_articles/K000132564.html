K000132564: Random Meta Characters shows up on the website after upgrade

Source
https://my.f5.com/manage/s/article/K000132564

Description

Post upgrade, random meta characters show up on the website.


Environment

  • Without ASM policy the characters disappear
  • No updates to application made

Cause

This is due to Bug ID 1087005: Application charset may be ignored when using Bot Defense Browser Verification


Recommended Actions

Impact of Procedure: There should not be impact on production, however, F5 recommends implementing the action during maintenance window,.


From the CLI, run the command:


# tmsh modify sys db dosl7.parse_html_inject_tags value "after,body"

# tmsh save sys config


Additional Information

None.
