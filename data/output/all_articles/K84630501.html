Topic

You should consider using this procedure under the following condition:
  • You want to change the BIG-IP system host name for a vCMP guest

Note: This article applies to vCMP guest systems only. For information about changing the host name for other BIG-IP systems, refer to K26057357: Changing the BIG-IP system host name.

Description

The BIG-IP host name represents the fully qualified domain name for the BIG-IP system. The system displays its host name in the upper-left of the Configuration utility and in the command prompt of the Advanced Shell (bash). If you are using a DNS server to resolve the host name of the BIG-IP system to an IP address, you can use the host name when you make administrative connections to the system.

To change the host name for a BIG-IP vCMP guest system, log into the vCMP host system and make the change using the Configuration utility or TMOS shell (tmsh). When you update the guest's host name from the vCMP host, the new host name is immediately reflected on the vCMP host and guest.

Note: If you update the guest's host name from the vCMP guest, the new host name is not reflected on the vCMP host system, and the next time you upgrade or redeploy the guest, the guest reverts to using the old host name.

You can use the following procedures to change the BIG-IP vCMP guest's host name:

  • Change the vCMP guest's host name using the Configuration utility
  • Change the vCMP guest's host name using tmsh
  • Change the vCMP guest's name for other configuration objects (optional)

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You have administrative access to the BIG-IP vCMP host's Configuration utility or tmsh utility.

Procedures

Change the vCMP guest's host name using the Configuration utility

To change the vCMP guest's host name using the Configuration utility, perform the following steps:

Impact of procedure: If you are using a DNS server to resolve the host name of the BIG-IP system, make sure to update the host name on the DNS server.

  1. Log into the Configuration utility of the vCMP host system.
  2. Go to vCMP > Guest List.
  3. Select the name of the vCMP guest.
  4. Under Properties, for Host Name, enter the new BIG-IP vCMP guest system's host name.

    For example, you enter the following name:

    guest1.example.com

  5. Select Update.

    The change to the vCMP guest's host name takes immediate effect on both the vCMP host and guest; there is no need to change the state of the guest to affect the change.

Change the vCMP guest's host name using tmsh

To change the vCMP guest's host name using the Configuration utility, perform the following steps:

Impact of procedure: If you are using a DNS server to resolve the host name of the BIG-IP system, make sure to update the host name on the DNS server.

  1. Log in to tmsh for the vCMP host system by entering following command:

    tmsh

  2. Change the BIG-IP vCMP guest system's host name by entering the following syntax:

    modify /vcmp guest <guest_name> hostname <hostname>

    For example, you enter the following syntax:

    modify /vcmp guest Guest1 hostname guest1.example.com

  3. Save the configuration by entering the following command:

    save /sys config

    The change to the vCMP guest's host name takes immediate effect on both the vCMP host and guest; there is no need to change the state of the guest to affect the change.

Change the vCMP guest's name for other configuration objects (optional)

The system identifies two other visible configuration objects using the BIG-IP system host name, and they are not updated when the host name changes. While the BIG-IP system functions normally in this configuration, you may want to also change the configuration objects in the following table to avoid confusion.

Configuration objectDescription
Device Service Clustering (DSC) Device NameThis DSC Device Name appears on all remote DSC peer systems when you view the Device Trust Members list. You can update the DSC Device Name using the procedures in K15700: Changing the BIG-IP host name does not update the device name when the device is a member of a DSC device group.
Device Certificate Common NameThe Device Certificate Common Name appears in the SSL certificate information you receive when you connect to the BIG-IP system Configuration utility. You can update the Device Certificate Common Name using the procedures in K16951115: Changing the BIG-IP DNS system device certificate using the Configuration utility.

Note: Use the procedure described in the Renewing the device certificate section in K1685115 for BIG-IP LTM only systems.
