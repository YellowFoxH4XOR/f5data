Security Advisory Description

A specially crafted request could have crashed the Apache HTTP Server prior to version 2.4.30, due to an out of bound access after a size limit is reached by reading the HTTP header. This vulnerability is considered very hard if not impossible to trigger in non-debug mode (both log and build level), so it is classified as low risk for common server usage. (CVE-2018-1301)

Impact

This vulnerability allows a remote disruption of service.

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column. Mitigation

There is no mitigation. However, this vulnerability is considered very hard if not impossible to trigger in non-debug mode. If debug log level is required for httpd, F5 recommends that you enable it only during active troubleshooting and do not leave debug logging enabled in production on a normal basis.
