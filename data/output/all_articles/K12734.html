Issue

Error Message

% ERROR: OPEN_SSL_ERROR (40828966): Internal SSL error: error:06065064:digital envelope routines:EVP_DecryptFinal_ex:bad decrypt [101077092].

Message Location

You may encounter this message in the following location:

  • The ARX CLI

Description

This message occurs when the following conditions are met:

  • You use the show master-key command to view a master key in the ARX system CLI.
  • The incorrect master key system password was entered.

Note: The master key system password is case sensitive.

Impact

The ARX system master-key will not display.

Recommended Actions

Re-enter the show master-key command and enter the correct master key system password when prompted.
