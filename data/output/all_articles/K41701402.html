Description

The REST API endpoint "/mgmt/tm/asm/policies/<ASM Policy HASH>/whitelist-ips" is limited to accept a single ipAddress/ipMask. However, there are use cases where it is necessary to add multiple ipAddress/ipMask entries into an ASM policy's whitelist (IP Address Exceptions List) using a single POST request. This is where the REST endpoint "/mgmt/tm/asm/tasks/bulk" comes in handy.

Environment

  • BIG-IP ASM
  • Multiple ipAddress/ipMask needs to be added into an ASM policy.

Cause

None.

Recommended Actions

To add multiple IP prefixes (for example 1.1.1.1/32 and 2.2.2.2/32), create a POST request towards https://<Management_IP>/mgmt/tm/asm/tasks/bulk with the following JSON payload:

{
    "commands": [
        {
            "body": {
                       "ipAddress": "1.1.1.1",
                       "ipMask": "255.255.255.255"
                    },
            "method": "POST",
            "uri": "https://localhost/mgmt/tm/asm/policies/<ASM policy HASH>/whitelist-ips"
        },
        {
            "body": {
                      "ipAddress": "2.2.2.2",
                      "ipMask": "255.255.255.255"
                    },
            "method": "POST",
            "uri": "https://localhost/mgmt/tm/asm/policies/<ASM policy HASH>/whitelist-ips"
        }
    ]
}
