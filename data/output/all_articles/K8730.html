Known Issue

This is the result of a known issue. When an administrator uses the Maintenance Console to perform a reset of the FirePass controller configuration settings to the factory default settings, certain customization settings are not reset.

From the FirePass controller's serial port, the Maintenance Console provides a text menu of options that allow an administrator to perform setup and maintenance tasks. When choosing menu option 1, Reset settings and/or admin password, then the subsequent option 1, Reset settings and admin password, the FirePass controller will return the configuration to the state in which it was shipped from F5 Networks or your reseller.

However, the following customization settings will not be returned to the default configuration:

  • Custom images

    Any custom images uploaded to the FirePass controller under the Custom Images section on the Global Customization tab of the Device Management: Customization page will be present after the reset.
  • URI-based customization

    Any customization performed under the URI-based Customization tab of the Device Management: Customization page will be present after the reset.
  • WebDAV customization

    Any custom web pages uploaded to the FirePass controller through WebDAV (located under the Advanced Customization section on the Global Customization tab of the Device Management: Customization page) will continue to be present in the WebDAV sandbox directory. However, the Allow WebDAV sandbox customization check box will be cleared, and no WebDAV password will be configured, which prevents WebDAV access until these settings are reentered.

Note: For more information, refer to K4715: Resetting a FirePass controller to its default settings.

Versions of FirePass software that do not have URI-based customization or WebDAV customization will still be affected by this issue for custom images.

F5 Networks Product Development is tracking this issue as CR75498. To monitor the status of this CR, refer to the FirePass Release Notes.
