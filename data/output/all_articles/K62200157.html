Description
You have customized client package and upgraded the BIG-IP version, and noticed that all the previously customized options are being reset to default values.

Environment

  • BIG-IP APM
  • Customizing Client Package

Cause
By default, client package options are not stored in database or files; therefore, once an upgrade is complete, the customized configuration is lost.
 

Recommended Actions

Take a screen shot of customized client package options before upgrading the BIG-IP.
