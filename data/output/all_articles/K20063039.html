Known Issue

Setting the tmm.ssl.loggingcreatedcerts BigDB variable may cause a double-free memory issue.

This issue occurs when all of the following conditions are met:

  • You set the tmm.ssl.loggingcreatedcerts BigDB variable.
  • You implement SSL forward proxy.
  • An error occurs when reading the certificate serial number.

Impact

Traffic is disrupted while the Traffic Management Microkernel (TMM) restarts.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you set the tmm.ssl.loggingcreatedcerts BigDB variable, a double-free error (an attempt to free memory that is already freed) occurs.
