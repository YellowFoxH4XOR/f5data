Description

The BIG-IP file system may become read-only while writing to the disk, which can prevent writing to the disk. 

You may notice a message similar to: 

Error: EXT3-fs error (device dm-4): read_inode_bitmap: Cannot read inode bitmap

Environment

  • BIG-IP file system errors

Cause
File system state is marked as read-only and BIG-IP system cannot start the installed software. Console displays file system errors. 

Recommended Actions

When your BIG-IP system experiences files system issues, the device is possibly entered into Linux OS maintenance mode. 
You can use the following troubleshooting procedures to attempt to repair the erroneous file system(s) to resolve file system inconsistencies.  
  1. Log in to the serial console of the device.
     
  2. Type the following command:
    fsck -y 
     
  3. After the fsck command completes, restart the device by typing the following command:
    reboot
