Known Issue

This is the result of a known issue. The switch-over daemon (sod) causes the BIG-IP system to become active or standby, and provides failover and restart capability through the high availability table. You can use the Configuration utility or the command line to configure the sod process to use unsupported actions for its heartbeat monitor.

For example, the sod process supports configuring the Restart All and the None heartbeat monitor actions. However, the BIG-IP system also allows you to configure unsupported heartbeat monitor actions for the sod process, such as Reboot and Restart. If you configure an unsupported heartbeat monitor action for the sod process, the setting has no effect; the default Restart All setting remains.

F5 Product Development is tracking this issue as ID 246695 (formerly CR100544).
