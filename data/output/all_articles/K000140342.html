Description

You want to use the "docker exec" command to back up the ConfD config.

Environment

  • F5OS-A
  • docker exec
  • rSeries CLI
  • bash

Cause

You want to use the docker exec command to back up the ConfD config, rather than the methods introduced from Backing Up F5OS on F5 Cloud Docs.

Recommended Actions

You can use the # docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;system database config-backup name <File Name>' proceed yes command to back up the ConfD database into a file.

  • <File Name>: You can replace the <File Name> with the name you prefer for the backup file.

For example, if you want to back up the file with the name of test, then you can run the command: 

# docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;system database config-backup name test' proceed yes

If the command running successfully, then you should see a similar command output: 

[root@appliance-1(RXXX) ~]# docker exec system_manager /confd/scripts/f5_confd_run_cmd 'config;system database config-backup name test' proceed yes
# config;system database config-backup name test proceed yes
result Database backup successful. configs/test is saved.
[root@appliance-1(RXXX) ~]# 

Additional Information

If you want to copy the backup file to an external location, you can read Exporting F5OS Backup to an External Location on F5 Cloud Docs for details.
