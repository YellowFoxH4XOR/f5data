Issue

Prior to OPSWAT 3.4.4, OPSWAT client components for Windows were installed under the %PROGRAMFILES%\F5 directory on client systems. In addition, users had to use the Windows Control Panel to remove the OPSWAT client components.

Starting in OPSWAT 3.4.4, OPSWAT client components for Windows are installed as ActiveX controls. This behavior is consistent with the FirePass and BIG-IP SAM client components, which are also installed as ActiveX controls.

Note: The old OPSWAT client components under the %PROGRAMFILES%\F5 directory are not automatically removed when OPSWAT 3.4.4 or later is installed. Use the Windows Control Panel to remove the old components after the new components are installed.

Note: For instructions about removing FirePass client components from Windows systems, refer to K8253: Removing FirePass client components from Windows 2000, 2003, XP, and Vista systems.

The FirePass and BIG-IP SAM Endpoint Security feature uses software libraries from a software development kit (SDK) created by OPSWAT, Inc. OPSWAT provides a vendor-independent framework for endpoint security management.
