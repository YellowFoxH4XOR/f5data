K000154665: f5_cspm cookie does not have HttpOnly and Secure flag

Type
Support Solution
Published
2025-09-23
Updated
2025-09-23
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1
  • BIG-IP Analytics: 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000154665

Description

Your security team reports that HttpOnly and Secure flag is missing in f5_cspm cookie. You would like to know if F5 will add these flags in the future.

Environment

  • BIG-IP AVR
  • Page Load Time
  • CSPM

Cause

None

Recommended Actions

  • HttpOnly flag will not be added to f5_cspm cookie.
  • There is an RFE (Request for Enhancement) ID 473421 to add Secure flag.

Additional Information

None
