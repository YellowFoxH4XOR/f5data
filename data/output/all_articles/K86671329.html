Description

You are unable to access the OneLogin page (IDP) and encounter script errors when connecting via Edge Client. A white screen is displayed. The following errors are found in the edge client logs:

Environment

  • Edge Client
  • AD Authentication
  • SAML
  • Alchemy Dedicated Server Solution

Cause

Using the script server results in user cache corruption.

Recommended Actions

  1. Clear the INet cache located at C:\Users<username>\AppData\Local\Microsoft\Windows\INetCache*

-OR-

  1. Add Loading configuration URL: 
    https://<Hostname>/pre/config.php?version=2.0
    to the Alchemy Dedicated Server Solution.
  2. Use the User Agent for the Edge Client, as mentioned in the Knowledge Article below.
