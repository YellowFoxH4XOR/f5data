K000139949: Browser challenge signatures cannot be updated.

Published

Source

Description

Browser challenge updates.

  1. Updating in Live updates and an error occurs.
  2. Cannot update Browser Challenge signatures.
  3. Other signatures can update but Browser challenge signatures cannot.

Environment

  1. ASM
  2. Live Updates

Cause

  1. Set isDatasyncMaster = false
  2. Datasync-global-dg device group hasn't been updated on the Active device.

Recommended Actions

In sequence running the following and then sync the datasync-global-dg device group from the Active device.

  1. tmsh save sys config
  2. tmsh load sys config
  3. sync the device group from the Active. 
  4.  

Additional Information

By default, the datasync-global-dg device group is not configured to perform an automatic synchronization, as such you must manually perform the synchronization for the datasync-global-dg device group. This action is required when you add a new device to the trust domain or you reload the configuration. Additionally, you will need to perform the synchronization for all device groups when you run the tmsh save sys config and the tmsh load sys config commands in sequence. Before you perform a synchronization for this device group, you must decide what device will hold the master copy of the system scripts and keys, and synchronize this device to the device group.

After syncing from the Active device for datasync-global-dg the logs can be checked for DatasyncMaster under /var/log/tomcat/liveupdate.log

Also, you can tail the logs before syncing to verify the change - tail -f /var/log/tomcat/liveupdate.log

You should see in the logs 

  1. Set isDatasyncMaster = true
