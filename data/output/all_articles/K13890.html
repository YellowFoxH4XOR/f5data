Known Issue

Textual information that contains a single straight quotation mark ( ' ) may be preceded with a backslash ( \ ) character on the user's webtop.

For example:

This isn\'t correct.

This issue occurs when the following condition is met:

  • Localized or customized text contains a single straight quotation mark.

Impact

Users may be confused by the inclusion of a backslash character in the text.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Text that includes the single straight quotation mark will display with a backslash preceding it.

    Note: This issue only appears on the user's webtop; it does not appear in the BIG-IP Configuration utility.

Workaround

To work around this issue, you can remove the single straight quotation mark.

Impact of workaround: The meaning of the word may change.
