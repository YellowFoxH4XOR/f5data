K000159690: Global Log Receiver (GLR) special characters are not supported in passwords

Type
Support Solution
Published
2026-01-23
Updated
2026-07-12
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000159690

Description

Article describes Global Log Receiver (GLR) limitations regarding use of special characters in GLR passwords.

Environment

  • Global Log Receiver
  • Special characters (e.g. $, #) in GLR password
  • 500 Server Error

Cause

Config files don't support special characters and they can break the config.

Recommended Actions

Password used in GLR config should be without any special characters e.g. $,#. 

Pasting special characters encoded in Base64 also creates issue.

If you will use special characters in password, e.g. "$", GLR will stop sending logs and test connection will return 500 error.
