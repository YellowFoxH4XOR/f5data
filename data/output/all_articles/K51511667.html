Description

Multicast traffic through BIG-IP is not being hardware accelerated.

Environment

  • BIG-IP platforms supporting hardware acceleration (PVA, ePVA).
  • Multicast forwarded traffic (ie: traffic with destination IP 224.0.0.0/4 and destination mac-address 01:00:5e:xx:xx:xx).

Cause

Multicast traffic is explicitly blocked from being h/w acceleration due to functional requirements of the protocol.
 

Recommended Actions

 None (information only)

Additional Information

IP multicast traffic through BIG-IP platforms with PVA/ePVA hardware acceleration will not be hardware accelerated.

This is by design and is due to architectural differences between regular TCP/UDP traffic and multicast traffic. Regular traffic uses the routing table for forwarding decisions whereas multicast uses the multicast forwarding cache (MFC). Regular traffic egresses on a single vlan whereas multicast, depending on client subscription, can egress on multiple vlans.

You can check support & usage of hardware acceleration as follows:

# tmsh show ltm virtual <virtual-server> | grep Acceleration
...
  PVA Acceleration : partial                  <=== "partial/assisted acceleration supported on virtual server"

# tmsh show sys conn virtual-server <virtual-server> raw" | grep Acceleration
...
  Acceleration  none                        <=== "no hardware acceleration"
