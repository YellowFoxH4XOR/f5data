Known Issue

This is the result of a known issue. The BIG-IP GTM sync_zones utility synchronizes DNS zone files between BIG-IP GTM systems in a synchronization group. When sync_zones is enabled, the synchronization process creates a backup file by appending a tilde ( ~ ) to the end of the zone file. If there are existing backup zone files on the system, the sync_zones utility will create extra copies of the existing backup zone files each time a synchronization event occurs.

F5 Product Development tracked this issue as CR60771 and CR64376, and it was fixed in BIG-IP GTM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
