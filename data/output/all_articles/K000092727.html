K000092727: Peers getting disconnected when FEP discarded messages.

Type
Support Solution
Published
2022-11-26
Updated
2022-11-26
Source
https://my.f5.com/manage/s/article/K000092727

Description

  • This error is generated when the overall number of bytes in netty socket write queue/buffer exceeds a predefined limit (1048576) AND a single message in the queue is stuck for longer than 50 ms, then the FEP discards all messages in the queue. This is being triggered in netty level.

2021-01-07 02:46:32,591 ERROR [12583] Discarded all messages in Netty write queue of channel [id: 0xf3a46a02, L:/<PEER_IP>:54923 - R:/<FEP_IP>:3868] with exception: io.netty.channel.FlushedBytesAgedException: flushed bytes of [id: 0xf3a46a02, L:/<PEER_IP>:54923 - R:/<FEP_IP>:3868] failed to be written to network on time. Discarded all 1058780 flushed bytes of 1187 messages. FlushedBytesAgingDetectionConfiguration(bytesThreshold=1048576, delayMs=50). [Silo-EventLoop-thread-3-3_23] [TraffixChannelActivityHandler_netty4.userEventTriggered()]

Environment

  • SDC 5.1
  • FEP

Cause

Due to discarded messages, all peers towards the FEP is disconnected.

 Recommended Actions

Restart affected peers and FEP. Collect TTA and TCPdump for the affected peers immediately and open a case with F5 Support for further checking.
