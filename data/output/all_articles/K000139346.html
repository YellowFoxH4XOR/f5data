K000139346: Cannot Display Network Map and Device Management Overview After Upgrade

Type
Support Solution
Published
2024-05-21
Updated
2024-05-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.X, 17.1.1, 17.1.0
Source
https://my.f5.com/manage/s/article/K000139346

Description

After upgrade cannot display Network map and Device Management Overview page

 

Environment

  • BIG-IP 17.1.x
  • Upgrade

Cause

Bug alias 1353957 GUI Pages failing to load and displaying "Error getting auth token from login provider" if AuthPAM_IdleTimeout is not 1200

Recommended Actions

1. Retrieve the current idle timeout value for the Configuration utility:

      # tmsh list sys httpd auth-pam-idle-timeout

2. Reset the Configuration utility idle timeout value to the default value:

    Note: The default idle timeout is 1200 seconds (20 minutes).

     # tmsh modify sys httpd auth-pam-idle-timeout 1200

     # tmsh save sys config

3. Remove the current cookies from the /var/run/pamcache directory:

     # rm -f /var/run/pamcache/*

4. Restart the HTTPD service:

     # bigstart restart httpd (wait for 2mins)

Note: If this is an HA setup and the BIG-IP systems are not in sync or if the status changes to Pending state, perform the previous steps on both the standby and active systems and then log in again to both systems.

 or consider upgrade BIG-IP to version 17.1.1.2
