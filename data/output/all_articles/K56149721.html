Description
Certain LTM Policy match conditions, such as "TCP port", offer the option:

Apply to traffic on remote side of external interface

"remote" can be changed to "local" and "external" can be changed to "internal".

This option is undocumented.

Environment

  • BIG-IP
  • LTM traffic polocy

Cause
Because conditions which match on L3 or L4 options can match client-side or server-side traffic, and client or server address or port, this allows selecting which endpoint will be used to match traffic. "local" and "remote" are from the perspective of BIG-IP. "external" interface means client-side, and "internal" interface means server-side.
