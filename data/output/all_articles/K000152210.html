K000152210: XFF header missing the true client IP for traffic passing over Zscaler proxy

Type
Support Solution
Published
2025-06-27
Updated
2025-06-27
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud WAF
Source
https://my.f5.com/manage/s/article/K000152210

Description

Traffic received from Zscaler proxy doesn't contain true client IP in XFF header.

Environment

  • F5® Distributed Cloud
  • Webapp & API protection

 

Cause

The X-Forwarded-For header contains only Zscaler's IP address.

 

Answer/Recommended Actions

When Zscaler is configured to bypass SSL inspection, the XFF header may not contain the true client IP information. Only the Zscaler IP is present.
