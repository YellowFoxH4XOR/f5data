Known Issue

Accessing or modifying a system device file may trigger the Traffic Management Microkernel (TMM) process to produce a core file and remain in a non-functional state.

This issue occurs when the following condition is met:

  • You attempt to access or modify the /dev/vnic BIG-IP system file.

Impact

The TMM process produces a core file and remains in a non-functional state.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • Your BIG-IP system logs a SIGABRT message to the /var/log/tmm file at the time the TMM process produces a core file.
  • The BIG-IP system does not process traffic.
  • Log messages similar to the following are logged to /var/log/ltm at the time of the event:

Workaround

To recover from this issue, you can restart the affected device. To do so, perform the following procedure:

Impact of workaround: The BIG-IP device is unavailable to process traffic during restart. 

  1. Log in to the command line of the BIG-IP device.
  2. Type the following command to restart the device:

    reboot
