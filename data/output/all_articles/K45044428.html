Description

Following upgrade to v16.0.0.x, v16.0.1.x, v15.1.0.x, v15.1.1.4, snmpd restarts and leaves a core file roughly once an hour

Environment

  • BIG-IP
  • Recent upgrade to v16.0.0.x, v16.0.1.x, v15.1.0.x, v15.1.1.4
  • snmpd core files
  • SNMP client that uses snmpv3

Cause

Issue is caused by ID924961

Recommended Actions

Install the point release that fixes ID924961 stated in K45212738
If a point release fix is not available, request and Engineering Hotfix for ID and install it
