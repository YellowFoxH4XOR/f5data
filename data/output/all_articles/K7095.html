Topic

The FirePass controller can generate a diagnostic dataset file, which contains information useful to F5 Networks Technical Support.

Options for generating and sending the dataset to F5 Networks are located under the F5 Support Diagnostic tool section of the Device Management: Maintenance: Troubleshooting tools page. The dataset is encrypted before you can download or send it to F5 Networks. Encrypting the dataset ensures that your organization's configuration is protected in storage or transit. Encryption also protects any F5 Networks proprietary information in the dataset. For this reason, F5 Networks requires customers to send the dataset to F5 Networks Technical Support in order to decrypt the dataset.

Note: For more information about generating and downloading a diagnostic dataset file refer to K9078: Downloading a diagnostic dataset from the FirePass Administrative Console.
