K11525314: Error Message: 01960013:3: netHSM: PKCS11d stopped. Verify password, and restart PKCS11d

Issue

Error Message

err pkcs11d[<PID>]: 01960013:3: netHSM: PKCS11d stopped. Verify password, and restart PKCS11d.

In this error message, note the following:

  • <PID> is the process ID for the pkcs11d process.

For example:

err pkcs11d[28484]: 01960013:3: netHSM: PKCS11d stopped. Verify password, and restart PKCS11d.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system fails to access network hardware security module (HSM) with the provided password.

Impact

The network HSM function configured on the BIG-IP system fails to work properly.

Recommended Actions

To work around this issue, you can ensure that the BIG-IP system is configured with the correct network HSM password, and restart the pkcs11d process. To restart the pkcs11d process, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To restart the pkcs11d process, type the following command:

    restart /sys service pkcs11d
