Topic

You should consider using this procedure under the following condition:

  • For troubleshooting purposes, you want to temporarily configure the BIG-IP DNS system (formerly known as BIG-IP GTM) to log wide IP request information to the system log files.

Description

By default, the BIG-IP DNS system does not log wide IP request information to the system log files. In some cases, you may want to temporarily enable wide IP request logging so that you can determine how the system processes certain requests.

For example, suppose you want to determine why the wide IP statistics indicate that a large number of wide IP requests are bypassing the preferred load balancing methods and using the Return to DNS method. You may be able to determine this by temporarily enabling the gtm.querylogging database variable and gathering the wide IP request information in the /var/log/gtm files. After obtaining the appropriate logging information, you would disable the gtm.querylogging variable.

Important: F5 recommends that you only modify log-related database variables for troubleshooting purposes, and that you always return their values to the default when the system is in production mode.

The following log statements are examples of wide IP request logging:

  • The following log statement indicates the system received an A record request for wide IP www.example.org from LDNS 10.11.16.221. The system load-balanced the request to the GTM_pool1 pool and LTM_VS1 pool member:

    tmm notice tmm[7284]: 011ae024:5: RESOLVED rrtype = A, wip = www.example.org, LDNS(10.11.16.221) to vs(/Common/LTM_VS1) using /Common/GTM_pool1

  • The following log statement indicates the system received an AAAA record request for wide IP www.example.org from LDNS 10.11.16.221. The system bypassed the preferred and alternate load-balancing methods and used the Return to DNS method, possibly because no AAAA record exists for www.example.org:

    tmm notice tmm[7284]: 011ae025:5: UNRESOLVED rrtype = AAAA, wip = www.example.org, LDNS(10.11.16.221), Return to DNS

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have command line access to the BIG-IP DNS system.

Procedures

Enabling wide IP request logging

  • Enabling wide IP request logging
  • Disabling wide IP request logging

Impact of procedure: Enabling wide IP request logging when the system is in production mode can impact system performance.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To enable the gtm.querylogging variable, type the following command:

    modify /sys db gtm.querylogging value enable

  3. Save the change by typing the following command:

    save /sys config

  4. Review the /var/log/gtm file.

    For example:

    cat /var/log/gtm

Disabling wide IP request logging

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To disable the gtm.querylogging variable, type the following command:

    modify /sys db gtm.querylogging value disable

  3. Save the change by typing the following command:

    save /sys config
