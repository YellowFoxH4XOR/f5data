Topic

Beginning in BIG-IP WebAccelerator 11.0.0 and BIG-IP AAM 11.4.0, if you set the Always Proxy Requests for this Node Proxying Rule, the system caches an object when matching the request node.

Description

Beginning in BIG-IP WebAccelerator 11.0.0 and BIG-IP AAM 11.4.0, if you set the Always Proxy Requests for this Node Proxying Rule, the system caches an object when matching the request node.

In BIG-IP WebAccelerator 10.x and earlier, if you set the Always Proxy Requests for this Node Proxying Rule, the system caches an object when matching the response node.

Impact

If you are upgrading from BIG-IP WebAccelerator 10.x to WebAccelerator 11.x or AAM 11.4.0 and later, you may find that objects that were previously cached are no longer cached, or objects that were not previously cached are now cached.

Recommended Actions

Review your policies and your X-WA-Info headers to determine which nodes are being used on both requests and responses. This information will help you examine which nodes are determining an objects cache status within the policy.
