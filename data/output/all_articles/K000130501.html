K000130501: Settings in existing configuration objects are grayed out and can't be changed.

Type
Support Solution
Published
2023-01-05
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000130501

Description

When attempting to modify an existing configuration object (LTM/DNS Profiles, Virtual Servers, etc.), certain settings may be grayed out and are unable to be changed.


Environment

BIG-IP


Cause

When editing an existing configuration object, there are check boxes on the right hand side of the page which need to be enabled in order to change the corresponding setting.


Recommended Actions

Check the boxes on the right side of the settings page of the configuration object to enable the ability to change the corresponding setting. You can either enable all of them at once by clicking the topmost checkbox, or individually by checking the check box next to the item you wish to change. These boxes themselves have no impact on the configuration of the BIG-IP. Enabling or disabling them will not change how the BIG-IP is configured. They only enable the option to change settings from within the configuration page itself.
