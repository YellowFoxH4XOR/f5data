Issue

If you are in the process of defining new BIG-IP LTM and GTM systems, and you add the BIG-IP LTM server object to the BIG-IP GTM configuration before adding the BIG-IP GTM server object itself, an error message that appears similar to the following example may be logged to the /var/log/gtm file:

Error Message: Will not probe <IP:Port> in DC <Data_center> because will be done by other GTM (<unknown>:<unknown>)

For example, if the BIG-IP virtual server IP address and port is 192.168.1.1:80, and the BIG-IP GTM data center name is DataCenter1, the error message will appear as follows:

gtmd[1721]: 011ae03a:7: Will not probe 192.168.1.1:80 in DC DataCenter1 because will be done by other GTM  (<unknown>:<unknown>)

You can avoid this error message by adding the BIG-IP GTM server object before attempting to add any other BIG-IP LTM server objects. To correct the issue, remove the BIG-IP LTM server object from the BIG-IP GTM configuration, and add the BIG-IP GTM object. After you define the BIG-IP GTM server object, you can re-add the BIG-IP LTM server object to the BIG-IP GTM configuration.
