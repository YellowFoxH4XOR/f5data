Description
The following procedure provides the steps to decrypt traffic of the BIG-IP Configuration utility (GUI).

Environment

  • BIG-IP administration using the Configuration utility (GUI).

Cause

You would like to capture and decrypt Configuration utility network level packets to troubleshoot connection and/or performance issues.

Recommended Actions

  1. Logon to the Traffic Management Shell (tmsh)
  2. Print the configured  cipher suite used by the Configuration utility.  

    list /sys httpd ssl-ciphersuite  
    Important. Be sure to note the configured cipher suite as this will be modified by a subsequent procedure.  
  3.  To modify the cipher suite to use the AES128-SHA cipher suite use the following command syntax:

    modify /sys httpd ssl-ciphersuite NONE:AES128-SHA 
  4. To apply the configuration change to the Configuration utility (GUI), save the configuration and restart the BIG-IP httpd and tomcat service with the following commands:

    save /sys config
    restart /sys service httpd
    restart /sys service tomcat
     
  5. Logout of any active Configuration utility (GUI) sessions.
  6. Logon to the command line of the BIG-IP and start the tcpdump using the following command syntax.

    tcpdump -w <capture file name> -vnni eth0 -s0 port 443
    Note: Replace <capture file name> with the desired name for the tcpdump capture.
     
  7. Generate some traffic by reproducing the issue you are investigating.
  8. To stop the tcpdump packet capture enter the following command syntax:

    Ctrl-C
     
  9. To revert the cipher suite change of the Configuration utility to the original cipher suite (as noted in procedure step 2) use the following command syntax: 

    modify /sys httpd ssl-ciphersuite <original cipher suite> 
    Note: Replace <original cipher suite> with the cipher suite listed in step #2.
    Note:  If an error like "!RSA event not found" appears, refer to K61363565
     
  10. Save the configuration change and restart the httpd and tomcat service using the following commands:

    save /sys config
    restart /sys service httpd
    restart /sys service tomcat
  11. To decrypt the packet capture you will need to create a Pre-Mastered Secret (pms) file for use by the packet capture analisys tool using the following command syntax:

    ssldump -n -k <big-ip ssl key> -r <tcpdump capture file> -M <pre-mastered secret file name> 
    Note: Replace <tcpdump capture file> with the tcpdump capture file name used in the procedure step #6, and replace <pre-mastered secret file name> with the desired PMS file name.

    Example: 

    ssldump -n -k /config/httpd/conf/ssl.key/server.key -r /shared/tmp/capture_file.pcap -M /shared/tmp/capture_file.pms
