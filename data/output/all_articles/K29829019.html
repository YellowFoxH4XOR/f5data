Description
Each ASM Policy will create one or more ASM Main cookies which are provided to the client. The ASM Main cookie name does not cite the BIG-IP nor the originating ASM Policy name on the BIG-IP. For troubleshooting purposes a BIG-IP administrator may need to map ASM Main cookie(s) received at a client with ASM Policies on a BIG-IP. This can be accomplished on the BIG-IP via the "getcrc" utility.

Note that each BIG-IP provides its own unique ASM Main cookies from each of it's ASM policies so the getcrc utility would need to be used on all BIG-IPs with ASM Policies in the traffic flow. 

Environment

  • BIG-IP with ASM module provisioned
  • One or more ASM Policies present on the BIG-IP's virtual servers
  • Ability to observe HTTP cookies sent from BIG-IP to client

Cause
None.

Recommended Actions

The getcrc utility is provided with the name of the ASM Policy in question (full path) along with any non-default domain and/or path. The utility then provides the name of the corresponding ASM Main cookie. That name can then be matched to the ASM Main cookie(s) received at the Client to determine if the cookie in question is associated with the ASM Policy. Different command arguments are provided if a domain and or path is also provided. There are four different permutations of domain and path that can occur, each with their own flag. Below are examples of the four permutations with the ASM Policy name of "example_policy":
  1. No domain and default (root /) path, the "primary" ASM Main cookie
    command: /usr/share/ts/bin/getcrc -t /Common/example_policy
    example output: TS01f939ad
  2. Custom domain (test.f5.com) and default path
    command: /usr/share/ts/bin/getcrc -td /Common/example_policy test.f5.com
    output: TS01cc02ae
  3. No domain and custom path (/forms)
    command: /usr/share/ts/bin/getcrc -tp /Common/example_policy /forms
    output: TS0121685f
  4. Custom domain (.test.f5.com) and custom path (/content)
    command: /usr/share/ts/bin/getcrc -tdp /Common/example_policy .test.f5.com /content
    output: TS0114535c
If the utility is run without any arguments provided ("/usr/share/ts/bin/getcrc") it will display user help.

Additional Information
If the source ASM Policy is unknown, it may be helpful to generate ASM Main cookie names for all policies and all domains/paths for those policies. The following restcurl command provides an example for one method of generating this information. Note that this restcurl only generates the ASM Main cookie names without domains/paths however it can be adopted for your specific needs using the syntax shown above.

restcurl -u admin:admin "/mgmt/tm/asm/policies/?\$filter=type+eq+security&\$select=fullPath" | jq -r '.items[].fullPath' | xargs -I % sh -c "echo Policy Name: %; /usr/share/ts/bin/getcrc -t %; printf '\n'"

Example output:

TS01f939ad

TS01413cd8
