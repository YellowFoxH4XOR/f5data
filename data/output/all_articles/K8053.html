Known Issue

This is the result of a known issue. In FirePass version 6.0.2, synchronization of configuration changes in FirePass clusters will fail. The initial synchronization that occurs upon booting will succeed, and synchronize the full configuration from the cluster primary to the cluster secondaries. However, configuration changes on the cluster primary that are normally synchronized to the secondaries will not be synchronized.

F5 Networks Product Development tracked this issue as CR88044 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

This issue has been fixed in FirePass hotfix HF-602-8, issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
