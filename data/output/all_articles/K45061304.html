Description

You want to view the SSL Certificate Chain in command line using openssl.

Environment

  • Any BIG-IP and BIG-IQ software versions.
  • command line access (CLI)
  • openssl

Cause

None

Recommended Actions

  1. View the chain from the command line:

    # openssl crl2pkcs7 -nocrl -certfile <FILENAME GOES HERE> | openssl pkcs7 -print_certs -noout -text | grep "Issuer:\|Subject:\|Not Before:\|Not After :"
    Example:
    [root@bigip1:Active:Standalone] big3d # openssl crl2pkcs7 -nocrl -certfile client.crt | openssl pkcs7 -print_certs -noout -text | grep "Issuer:\|Subject:\|Not Before:\|Not After :"
