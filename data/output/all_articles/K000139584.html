K000139584: GTM Synchronization not working or working in one direction only

Support Solution

Source

Description

  • You have 2 GTMs ( Unit-A and Unit-B) in a sync group.
  • You import an SSl cert/key file on Unit-A only and apply to a https monitor then observe that any config changes made on unit-A are not syncing to unit-B.
  • On unit-B there are log messages similar to below in the /var/log/ltm file
    err mcpd[8850]: 01071488:3: Remote transaction for device group /Common/gtm to commit id 614 7348820143296417932 /Common/Unit-A 0 failed with error 01070712:3: Caught configuration exception (0), Values (/Common/xxxxx) specified for SSL key monitor parameter (/Common/https 2 KEY=): foreign key index (to_file) do not point at an item that exists in the database...

Environment

BIG-IP DNS
Synchronization Of Objects

Cause

SSL cert/key files are not synchronized as part of DNS synchronization.
The Key/Cert file being referenced in the https monitor on unit-A is missing on unit-B, therefore preventing any config changes made on unit-A to sync to unit-B. 

Recommended Actions

Manually import ssl cert/key files on all BIG-IP DNS which are part of a sync group.
