Issue

Error Message

warning chmand[<PID>] 012a0050 Chassis power module 1 turned off.

In this error message, note the following:

  • <PID> is the process ID for the chmand process.

For example:

warning chmand[8902] 012a0050 Chassis power module 1 turned off.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The power supply status changes from powered on to powered off. This error message occurs when a chassis power module is present in slot 1 but does not have an input power supply. This may be caused by any of the following reasons:
    • The power supply is powered off.
    • The power supply unit is not seated properly.
    • The external source to the power supply is inadequate.
    • The power supply unit has malfunctioned or failed.

Impact

The power supply unit in slot 1 does not supply power to the unit.

Recommended Actions

  • Verify that the power supply is powered on.
  • Verify that the power supply unit is seated properly in the chassis.
  • Verify that the external source to the power supply is adequate. 
  • Determine whether there has been a power outage at the device's physical location.
  • Review the /var/log/ltm file for power-related alarms as indications of potential malfunctions.
