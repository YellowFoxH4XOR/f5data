K19871315: Create VE cannot update the management ip address on new VMWare VM

Type
Support Solution
Published
2021-01-07
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K19871315

Description

When using the BIG-IP VE CREATION feature with an IP pool to provide a management IP, it will fail to configure a mgmt IP if the Cloud Environment setting "IP Pool Alias Mapping" is set.

  • The VE will be created
  • No IP address will be assigned from the specified IP pool
  • No error messages will be logged

Environment

  • BIG-IQ configured to interact with vCenter to create new VEs
  • No Device Template configured

Cause

This is functioning as designed. IP Pool Alias Mapping is designed to work with Device Templates and Declarative Onboarding of devices. During VE creation an IP pool can be specified to use for the management-IP.

Recommended Actions

  1. Navigate to Applications > Cloud Environments > <Cloun Envronment Name>
  2. Leave these set to the default:
    PropertyValue
    IP Pool Alias<leave blank>
    IP Pool"None"
