Topic

The BIG-IP APM supports portal access from the BIG-IP Edge Portal application. The BIG-IP Edge Portal application is designed to use portal access and does not currently support network access. To configure the BIG-IP APM system with portal access to support the BIG-IP Edge Portal application, perform the following procedures:

  • Running the Portal Access wizard
  • Disabling the Home Tab injection
  • Adding access control lists (ACLs) to limit access to resources
  • Customizing an advanced access policy
  • Editing the Client Classification and pre-logon checks macro that allow only the F5 BIG-IP Edge Portal client login
  • Adding the ACLs to the access policy

Running the Portal Access wizard

  1. Log in to the BIG-IP APM Configuration utility. 
  2. Click Templates and Wizards.
  3. Click Device Wizards. 
  4. Under the Wizard Section in the detail pane, select the Portal Access Setup Wizard option button.
  5. Click Next.
  6. In the Policy Name box, type a name for your policy.
  7. Select the Default Language of the portal.
  8. Select the Full Webtop check box if a webtop landing page is desired.
  9. Clear the Enable Antivirus Check in Access Policy check box.
  10. Click Next.

    The System DNS/NTP Configuration page will open.
  11. Fill out the DNS Lookup Server List, DNS Search Domain List, and Time Server List as appropriate for the network environment.
  12. Click Next.

    The Select Authentication page will open.
  13. Select Create New or Use Existing and the appropriate sub-selections for selected AAA authentication type.

    Note: Configuring the various authentication types is beyond the scope of this article. For more information about configuring BIG-IP APM authentication, refer to the Configuring Authentication Using AAA Servers chapter in the Configuration Guide for BIG-IP Access Policy Manager.

    Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  14. Click Next. The Portal Access Setup page will open.
  15. For Select Application, select the application type most similar to the destination resource, if there is no matching entry select Custom.
  16. Fill in the Portal Access Start URI with the starting URI for the destination resource (http:// FQDN or ip address>/<specific URL if required>).
  17. Click Next.
  18. To configure single sign-on (SSO) for the portal, select Create New or Use Existing. When selecting Create New, select the SSO method of the new SSO profile.
  19. Click Next.
  20. Enter the IP address in the Virtual Server IP Address box.
  21. To create an additional HTTP virtual server to redirect requests to the portal HTTPS virtual server, select the Create Redirect Virtual Server check box.
  22. Click Next.
  23. Review your configuration.
  24. Click Next.
  25. Click Finished.

Disabling the Home Tab injection

  1. Log in to the BIG-IP Configuration utility. 
  2. Click Access Policy. 
  3. Navigate to Customization > Advanced.
  4. Select the Branding tab.
  5. Expand Customization Settings.
  6. Expand Webtops. 
  7. Expand the folder for the webtop you want to customize.
  8. Click Web Applications Hometab Settings.
  9. Click Set of elements to be displayed. 
  10. Delete the following text:

    ,url
  11. Press the Enter key.
  12. Click Save. 
  13. Click the Apply Access Policy link in the upper-left corner of the Configuration utility. 
  14. Click Apply Access Policy.

    Note: F5 recommends that you turn off the Home/Logout tab injection feature for the F5 BIG-IP Edge Portal application client.

Adding access control lists (ACLs) to limit access to resources

Note: Configuring ACLs is beyond the scope of this article. For more information about configuring APM ACLs, refer to the Configuring Resources section in the Configuration Guide for BIG-IP Access Policy Manager.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Note: This procedure is an example of creating an ACL.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Click Access Policy.
  3. Click ACLs.
  4. Click Create.
  5. In the Name box, type a name.

    Leave all other setting for this page at their defaults.
  6. Click Create.

    An Access Control Entries section is added to the bottom of the page.
  7. In the Access Control Entries section, click Add.
  8. In the Type menu, select L7.
  9. In the Scheme menu, select http.
  10. In the Host Name field, type an asterisk ( * ) to allow access to all resources.
  11. In the Action menu, select Allow.
  12. Leave the Log setting at the default of None.
  13. Click Finished.

Customizing an advanced access policy

  1. Log in to the BIG-IP APM Configuration utility.
  2. Click Access Policy.
  3. Click Access Profiles.
  4. In the same row as the name of the access policy you created, click Edit in the Access Policy column.
  5. Click Add New Macro.
  6. In the Select macro template section, select Client Classification and Prelogon checks from the menu.
  7. Click Save.
  8. Click the plus (+) icon that appears before the Logon Page action.
  9. In the Macrocalls section, click the Client Classification and Prelogon checks radio button.
  10. Click Add Item.
  11. Set the Portal Access branch of the Access Policy action to Allow.

Editing the Client Classification and pre-logon checks macro to allow only the F5 BIG-IP Edge Portal client login

  1. Log in to the BIG-IP APM Configuration utility.
  2. Click the + next to Macro: Client Classification and Prelogon checks.
  3. Set all actions to Failure excluding the Edge Portal branch.
  4. Click Save.

Adding the ACLs to the access policy

  1. Log in to the BIG-IP APM Configuration utility.
  2. Click the + on the Edge Portal branch connected to the Client Classification and Prelogon checks action.
  3. In the General Purpose section, click ACL Assign.
  4. Click Add/Delete for Static ACLs.
  5. Select the check box next to each of the ACLs you want to include in this policy.
  6. Click Save.
  7. Click the Visual Policy Editor Close button.
  8. Click the Apply Access Policy link in the upper-left corner of the Configuration utility. 
  9. Click Apply Access Policy.
