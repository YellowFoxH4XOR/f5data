K50905345: Determining the Application Service Name of an object in the BIG-IQ Configuration tab

Type
Support Solution
Published
2021-10-14
Updated
2025-05-22
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K50905345

Description

An application is a container that houses multiple application services in the BIG-IQ user interface. An Application Service Name(ASN) refers to the name of the service configured during the AS3 deployment of the service. 
 

 Environment

  • Using the Global Applications feature in BIG-IQ 
  • Using AS3 to deploy services to BIG-IPs
  • ASN

Cause

None

Recommended Actions

In the BIG-IQ GUI:

  • The ASN will show as the Path column value
  • In the details for an object, the ASN will show as the right side of the Partition / Path value 
    • The partition will be the Tenant(BIG-IQ) or Partition(BIG-IP) name
    • The path will be the ASN
