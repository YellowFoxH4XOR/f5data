Description
After deploying an F5OS LTM tenant, in the /var/log/ltm file, this entry is logged continuously:

err platform_agent[agent_ID]: 01d50004:3: handle_generic_grpc: Bad return code from gRPC call to platform ...
 

Environment

  • F5OS
  • Velos / rSeriese
  • Tenant
  • Deployment

Cause

  • Bug ID 1015001

Recommended Actions

None, the log entry is cosmetic and it can be ignored.

If you wish to get rid of these log entries anyway, please navigate to

 System  ››  Logs : Configuration : Log Filters 

And create a new log filter like this:

Name: workaround_1015001

Source: all

Severity : Error

Message ID: 01d50004

Log Publisher  : None

Impact of workaround: Hides all Error level messages with Message ID 01d50004.
