K000092743: How to determine when FCP add on subscription for hardware was activated

Type
Support Solution
Published
2022-11-28
Updated
2025-08-12
Source
https://my.f5.com/manage/s/article/K000092743

Description

You want to see when your subscription was activated.

Note: Activation time and last update time are in UNIX EPOCH format and you will need to convert these to see a real time e.g "date e.g date -d @1725463576"
Note: Subscriptions are billed annually and you can opt out at the end of each billing cycle by contacting your CSM / Account team.

Environment

  • FCP hardware
  • URL Filtering
  • Threat Campaigns (TC)
  • Secure Web Gateway (SWG)
  • Intruder Protection signatures (IPS)
  • IP Intelligence (IPI)

Cause

You want to know when the subscription was activated.

 Recommended Actions

You can view the subscription details either from the BIG-IP web interface (GUI) or the command line (CLI)

From the GUI:

  1. Log into the BIG-IP
  2. On the left side menu click on System
  3. On the left side expanded menu, Click on License 
  4. Review "License Summary"

example:

License Tokens for Module TC, FCP, 3Yr, (I2XXX/I4XXX/R2800/R4800) key XXXXXXX-YYYYYYY 

subscr_threat_campaigns : 1725463576   (activation time in UNIX EPOCH time)

subscr_bot_signatures : 1725463576 (last signatures update in UNIX EPOCH time)

From the CLI:

  1. Log into the CLI
  2. type:
     tmsh show sys license | grep subscr
  3. Review output

example:
License Tokens for Module TC, FCP, 3Yr, (I2XXX/I4XXX/R2800/R4800) key XXXXXXX-YYYYYYY

subscr_threat_campaigns : 1725463576 (activation time in UNIX EPOCH time)

subscr_bot_signatures : 1725463576 (last signatures update in UNIX EPOCH time)

Additional Information

Support for add on subscriptions is valid for the lifetime of the FCP.
