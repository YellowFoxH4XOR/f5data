Known Issue

This is the result of a known issue. SSL connections to a clientssl virtual server will stall when the BIG-IP LTM system receives connections with a maximum segment size (MSS) of 500 bytes and large SSL record sizes. The MSS and SSL record size mismatch will cause the xfrag cache object size to continually increase.

F5 Product Development tracked this issue as CR63470, CR68270, and CR63474, and it was fixed in BIG-IP 9.1.3, 9.2.4, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM release notes.
