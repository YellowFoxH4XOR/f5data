Description
Upgrading BIGIP to V14.1.x or later fails to load config with the following error message 

01070734:3: Configuration error: Please configure one or more DNS nameservers. Unexpected Error: Loading configuration process failed.

Environment

  • BIGIP V14.1.x or Later 
  • Software Upgrade 
  • Config fails to load
  • DNS server 

Cause
In BIGIP V14.1.x and later at least oneDNS name-server must be configured,when Fully Qualified Domain Name (FQDN) pool members or nodes are configured.
To check for fqdn pool members or nodes then search the /config/bigip.conf for FQDN pool members or nodes.

An example of a FQDN pool member is:
 

ltm pool fqdn_pool {
    members {
        test.fqdn.f5.com:http {
            fqdn {
                autopopulate enabled
                name test.fqdn.f5.com
            }
        }
    }
}



An example of a FQDN node is:
 

ltm node /Common/test.fqdn.f5.com{
    fqdn {
        autopopulate enabled
        name test.fqdn.f5.com
    }
    monitor /Common/none
}

Recommended Actions

Configure DNS server by editing the bigip_base.conf. 

  1. Login to the CLI 
  2. Edit /config/bigip_base.conf  using text editor, such as such as pico or vi 
    # vi /config/bigip_base.conf
  3. Add the following lines, If using vi, enter i to enter insert mode before adding,where X.X.X.X is a valid DNS name server

       sys dns {
          name-servers { X.X.X.X }
       }

  4. Save the file,  If using vi, select ESC and enter the following command
    :wq
  5. Reload the configuration 
    # tmsh load sys config
