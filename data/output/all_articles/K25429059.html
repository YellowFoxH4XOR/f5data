K25429059: Can not deploy ciphers groups from BIG-IQ to BIG-IP

Type
Support Solution
Published
2022-09-15
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K25429059

Description

If you are using Cipher Groups which have been created on one BIG-IP, and are referenced by SSL Profiles on that BIG-IP, BIG-IQ is not able to deploy those SSL Profiles to another BIG-IP. This also applies to other objects that reference those SSL Profiles, such as Virtual Servers.

Environment

  • BIG-IQ 
  • BIG-IP 
  • SSL profiles using cipher groups

Cause

Bug ID 966533: Deployment error when SSL Profiles using custom Cipher Groups are deployed to another BIG-IP device.

Recommended Actions

Create the same custom Cipher Groups directly on each BIG-IP of interest. Once they are present, BIG-IQ will be able to deploy the affected SSL Profiles to the BIG-IP, along with other objects that reference those SSL Profiles, such as Virtual Servers.
