Description

  • You need to configure LDAP AAA server for use in non-default Route Domains

Environment

  • APM
  • LDAP AAA server
  • Route Domains

Cause

None

Recommended Actions

You need to configure LDAP AAA server with "Use Pool" option:

  1. On the Main tab, click Access > Authentication > LDAP. The LDAP AAA servers list screen opens.
  2. Click Create. The New Server properties screen opens.
  3. In the Name field, type a unique name for the authentication server.
  4. In the Configuration area, for the Server Connection setting, select Use Pool option
  5. In the Server Addresses setting add IP addresses of LDAP servers with Route Domain tag, ie 192.168.1.1%4
  6. Other settings (Base Search DN, Admin DN, Admin Password, Verify Admin Password) are not covered in this article. Please refer to Manual Chapter : LDAP and LDAPS Authentication for more details. 
  7. Click Finished. The new server displays on the list.

Additional Information

2 objects will be created by configuration utility:

  1. APM LDAP AAA server
  2. LTM Pool
