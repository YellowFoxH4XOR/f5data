Known Issue

Note: This issue does not affect BIG-IP WebAccelerator 11.0.0 and later due to architectural changes.

This is the result of a known issue. If you configure a proxy rule for a leaf node, the BIG-IP WebAccelerator system fails to apply Intelligent Browser Referencing (IBR) to the leaf node and fails to append a pv tag to the URL of the object that matches the leaf node, even if the object does not match the configured proxy rule.

For example, if you configure a leaf node for a JavaScript object with a proxy rule that matches an HTTP request User-Agent with .*MSIE 6.*, IBR fails if the HTTP request for a JavaScript object has User-Agent MSIE 8.0, which does not match the proxy rule and therefore is eligible for IBR.

Note: For more information about configuring a proxy rule, refer to the Configuring Proxying Rules chapter of the Policy Management Guide for the BIG-IP WebAccelerator System.

F5 Product Development tracked this issue as ID 348185.

Workaround

You can work around this issue by removing the configured proxy rule for the affected leaf node. To do so, perform the following procedure:

  1. Log in to the Configuration utility using a privileged account such as admin.
  2. Navigate to WebAccelerator > Policies.
  3. Click on the affected Acceleration policy.
  4. Click the plus (+) sign to expand the Site nodes.
  5. Click the plus sign to expand the Application Generated nodes or Static nodes, depending on where the affected leaf node resides.
  6. Click on the affected leaf node.
  7. Click on the Matching Rules drop-down menu.
  8. Select Acceleration Rules.
  9. Click on the Proxying tab.
  10. Select the check box next to the configured proxy rule.
  11. Click Delete to initiate the deletion process.
  12. Click Delete to confirm the deletion of the configured proxy rule.
  13. Click Save.
  14. Click Publish.
  15. Click Publish Now.
