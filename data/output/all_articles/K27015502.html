Known Issue

The BIG-IP system does not enforce the HTTP profile Maximum Requests option when you have not configured the OneConnect profile.

This issue occurs when all of the following conditions are met:

  • You have configured the HTTP profile Maximum Requests option.
  • You have not configured the OneConnect profile.

Impact

The BIG-IP system does not enforce the Maximum Requests setting.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the maximum requests value has been reached, the system does not enforce the setting.

Workaround

To work around this issue, you can assign a OneConnect profile to the virtual server that is using the HTTP profile with Maximum Requests configured.
