K000138346: Attack Vectors menu are missing in AFM Device DoS Protection page

Type
Support Solution
Published
2024-01-24
Updated
2024-01-24
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000138346

Description

Attack Vectors are missing in Security ›› DoS Protection : Device Protection page.

 

Because of this issue, you are unable to configure Device DoS Protection for the BIG-IP device.

 

Sometimes, if you wait long enough, you might encounter this Cannot read properties of undefined (reading 'network') error too:

 

Environment

  • AFM Device DoS Protection
  • missing attack vectors

 

Cause

The exact cause of this issue is not clear. However, based on the symptoms, this appears to be a variant of bug ID 1353957

 

Recommended Actions

To workaround the issue, run the following commands: (in CLI bash prompt)

  # tmsh modify sys httpd auth-pam-idle-timeout 1200

  # rm -rf /var/run/pamcache/*

At this point, you'll get logged out from the GUI

Log back in to the GUI and the attack vectors settings are now available.
