Description

You have the following environment:

  • VPC-A / CE-A <--> CE-B / VPC-B
  • This applies to Azure & GCP too, where you want to create a connection between them

Environment

  • F5® Distributed Cloud
  • Manage Site 
  • Network Connectors

Answer/Recommended Actions

Yes, it is possible.

To enable workloads in VPC-A to communicate with workloads in VPC-B at the Network layer - a Global Network Object needs to be configured, attached and referenced on both sites. (Refer to the picture below)

Follow the official guide: Network Connectors

Additional Information

Configuring a Site-Mesh-Group will only make the traffic flow directly between CE-A and CE-B without going to the RE, but won't solve the workload<->workload connectivity problem - you need a global network for that.

Site Mesh Group is a feature where an IPSec tunnel is created between the CE sites participating in Site Mesh Group. Once the IPSec tunnel is up, the traffic between the sites flows between the CEs through the IPSec tunnel which otherwise would have taken the RE path.
