K23035624: When SNMP Trap destination is set to FQDN and there's a change in DNS resolution the destination IP will not update automatically

Description

When you configure SNMP Trap destination in a FQDN format (For ex. snmp.test.local) and there's a change in DNS resolution/record for this hostname, the SNMP Trap destination IP address will not update automatically.

Environment

  • BIG-IP LTM
  • SNMP Trap destination is set to FQDN (For ex. snmp.test.local)
  • The DNS record / resolution for snmp.test.local has been changed
sys snmp {
    agent-addresses { tcp6:161 udp6:161 }
    communities {
        comm-public {
            community-name public
            source default
        }
    traps {
        isnmp_test_local_1 {
            community public
            host snmp.test.local
        }
    }
}

Cause

The snmpd service or the SNMP Trap Agent needs to be restarted for the changes to take effect.

Recommended Actions

Method 1:
  1. Go to Systems > SNMP > Traps > Configuration
  2. Uncheck/Disable Agent Start / Stop
  3. Click Update
  4. Check/Enable Agent Start / Stop
  5. Click Update
Method 2:
  1. Log In to Command Line
  2. Enter the command below:
    bigstart restart snmpd
