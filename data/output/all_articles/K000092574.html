K000092574: BGP route not recovered in Linux routing table after BGP route flap causing monitor to fail

Description

BGP route not recovered in Linux routing table after BGP route flap causing monitor to fail

 

Environment

  • BGP dynamic routing.
  • Routes to pool members injected dynamically via BGP.
  • Overlapping management and dynamic tmm routes.

Cause

Known issue caused by ID1026989.

 

Recommended Actions

Do not have overlapping management and dynamic routes on software versions where ID1026989 is not resolved.

Use BGP ECMP where multiple equal dynamic routes exist as the Linux route entry will point to tmm avoiding route loss in the Linux kernel.
