This article discusses the Diameter profile settings. You can find the Diameter profile in the Configuration utility by navigating to Local Traffic > Profiles > Services > Diameter.

Description

The BIG-IP Diameter session profile enables the BIG-IP system to manage Diameter traffic. The profile allows you to configure the properties of a Diameter session as a set of messages between two diameter nodes on behalf of a user.

The BIG-IP Diameter session profile settings are organized into the following sections and are described in the following tables.

  • General Properties
  • Settings
  • To Client
  • To Server

General Properties

SettingDescription
NameThe Name setting is required. To create a Diameter sessions profile, you must specify a unique name for the profile. For more information about the profile name requirements, refer to the following articles:
  • K6869: Reserved words that should not be used in BIG-IP configurations (10.x - 17.x)
  • K13209: BIG-IP configuration object names must begin with an alphabetic character
Parent ProfileSpecifies an existing profile to use as the parent profile. A profile inherits settings from its parent, unless you override the setting by selecting its Custom box and modifying the value. The default is the diameter profile.

Settings

This section describes the most common Diameter settings for a Diameter sessions profile.

SettingDescription
Persist AttributeSpecifies the attribute the system uses as the persistence key for load balancing decisions. The default is Session-Id.

Additional attribute options:

  • None: Turns off persistence.

  • Auth-Application-ID: Specifies that the connection persists based on the Authentication and Authorization identifier defined for an application.

  • Destination-Host: Specifies that the connection persists based on the identity of the destination server.

  • Destination-Realm: Specifies that the connection persists based on the realm of the destination server.

  • Origin-Host: Specifies that the connection persists based on the origin identity of the request.

  • Origin-Realm: Specifies that the connection persists based on the origin realm of the request.

  • Session-Id: Specifies that the connection persists based on the session identifier of the request.

  • Subscription-Id-Data: Specifies that the connection persists based on data in the subscription identifier.

  • Specify: Presents a box where you can enter your own persist attribute string. Note that the system supports only a subset of strings specified in RFC 3588, as specified in this list.

    Note: You can also enter a number from 1 to 4294967295.

Grouped/Parent AttributeSpecifies the parent attribute when the persist attribute is embedded in a grouped attribute. The default is Not Grouped.

Additional attribute options:

  • Not Grouped: Indicates that the persist attribute is not embedded in a grouped attribute.

  • Subscription-Id: Indicates that the persist attribute is embedded in subscription identifier attribute.

  • Specify: Presents a box where you can enter your own grouped attribute string. Note that the system supports only a subset of strings specified in RFC 3588, as specified in this list.

    Note: You can also enter a number from 1 to 4294967295.

Host IP Address RewriteSpecifies whether the system uses the existing host IP address or overwrites the host IP address value in the request with the pool member's IP address. The default value is selected, Enabled.
Handshake TimeoutIndicates the number of seconds before the handshake times out. The default is 10.
Watchdog TimeoutIndicates the number of seconds before the watchdog times out. The default is 0, meaning that the watchdog does not time out.
Maximum Watchdog FailureIndicates the maximum number of failures the watchdog can experience before closing the connection. The default is 10.
Reset on TimeoutSpecifies whether the system resets the connection when the handshake or watchdog times out. The default value is selected, Enabled.
Connection PrimeSpecifies whether the system uses prime connection protocol. The default value is cleared.
Maximum Retransmit AttemptsSpecifies the maximum number of retransmit attempts. This setting specifies the maximum number of attempts that the BIG-IP system takes to retransmit the request messages if it does not receive the answer messages. If the retransmit is unsuccessful, after the maximum number of attempts, the BIG-IP system sends an error response. The default value is 1.
Retransmit TimeoutSpecifies the retransmit timeout in seconds. This setting specifies the number of seconds the BIG-IP system waits to retransmit the request messages if it does not receive the corresponding answer messages. The default value is 10.

To Client

BIG-IP 11.3.0 and later

SettingDescription
Origin HostSpecifies the origin-host-to-client of the BIG-IP system. The origin-host-to-client is used to overwrite the server's actual origin host attribute when it responds to the client. The value can be an ASCII string such as an FQDN. See RFC 3588 section 6.3. A blank field indicates that origin-host-to-client is disabled. The default is blank.
Origin RealmSpecifies the origin-realm-to-client of the BIG-IP system. The origin-realm-to-client is used to overwrite the server's actual origin realm attribute when it responds to the client. It can be an ASCII string such as an FQDN. See RFC 3588 section 6.4. A blank field indicates that origin-realm-to-client is disabled. The default is blank.

SettingDescription
Origin HostSpecifies the origin-host-to-server of the BIG-IP system. The origin-host-to-server is used to overwrite the client's actual origin host attribute when it responds to the server. It can be an ASCII string such as an FQDN. See RFC 3588 section 6.3. A blank field indicates that origin-host-to-server is disabled. The default is blank.
Origin RealmSpecifies the origin-realm-to-server of the BIG-IP system. The origin-realm-to-server is used to overwrite the client's actual origin realm attribute when it responds to the server. It can be an ASCII string such as an FQDN. See RFC 3588 section 6.4. A blank field indicates that origin-realm-to-server is disabled. The default is blank.
