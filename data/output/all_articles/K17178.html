Known Issue

The BIG-IP APM Machine Certificate Auth agent may fail when retrieving user device keys.

This issue occurs when all of the following conditions are met:

  • Your access policy is configured with Endpoint Security Client-Side Machine Certificate Auth agent.
  • The Machine Certificate Auth agent is configured to match found certificate information other than Match Subject CN to FQDN.
  • The user's device is running the Windows operating system and has the BIG-IP Edge Client Machine Certificate Checker service installed.
  • The user's Windows administrative privileges does not permit the user to read the local device private key.

Impact

You are unable to access the access session.

Workaround

To work around this issue, you can use the Windows UAC power user option to elevate the privileges of the Machine Certificate Checker service "f5certchk.dll". Alternatively, you can modify the Machine Certificate Auth agent to only check for Match Subject CN to FQDN.

Impact of workaround: Performing the workaround should not have a negative impact on your system.
