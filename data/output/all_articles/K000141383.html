Description

When Central Manager imports an existing Classic BIG-IP AWAF policy, it may fail with an error:

policy validation failed: Requested rest version is beyond current version.

 

Environment

  • Central Manager
  • Import WAF policy.

 

Cause

Importing an AWAF policy that was exported from TMOS version 17.1.x fails a supported version check on Central Manager versions prior to 20.3.0.


ID1610865

 

Recommended Actions

Use BIG-IP Next version 20.3.0 or modify the policy by changing the softwareVersion parameter. For example:

Modify:

"softwareVersion" : "17.1.0",

to become:

"softwareVersion" : "16.1.0",

The configuration should be imported although several warnings may appear.
