Description

You want to know that if you setup 2 Health Check at the same time, 1 HTTP and 1 TCP would it work or not, and what will be the outcome of this configuration

Environment

  • F5 XC HTTP Load Balancer

Answer

It will not work.
The way our Proxy is setup, it has a limitation on mapping the Health Check status. All the Health Checks associated with the endpoint has to be healthy for the endpoint to be marked healthy. Even if one of them fails then that endpoint would be removed from the pool and wont receive any traffic.
