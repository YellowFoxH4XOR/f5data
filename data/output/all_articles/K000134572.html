Description

Device Certificate Expiry Notification fixed at 30 days, cannot be modified

 

Environment

All BIG-IP systems
Device Certificates
SNMP

 

Cause

  • 30 day notification of device certificate expiration is built in to all BIG-IP systems.
  • RFE ID 474551 submitted to allow customization of the value used by 'tmsh run sys crypto check-cert' (and its standard maintenance invocation via /etc/cron.weekly/5checkcert) used to determine pending expiration of SSL certificates to something other than the implied 30-day default. Value should be modifiable via both 'tmsh' and web GUI.
  • Operational schedules and lead times may be longer than 30-days, modifying the value would allow remediation of the pending expiration and prevent an outage.
