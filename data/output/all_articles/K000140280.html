K000140280: "admin" is automatically disabled when an BIG-IP Next instance is added to CM

Type
Support Solution
Published
2024-07-09
Updated
2025-09-02
Status
Legacy Content
Applies to
  • BIG-IP Next
  • BIG-IP Next Central Manager: 20.2.1
Source
https://my.f5.com/manage/s/article/K000140280

Description

We can enable users using the "BIG-IP Next API".

# curl -sk -X PUT https://<BIG-IP Next mgmt IP>:5443/api/v1/users/<User ID> -H "Authorization: Bearer <Token>" -H "Content-Type: application/json" -d '{ "status": "enabled" }'

However, "admin" is automatically disabled when an BIG-IP Next instance is added to CM.

Environment

BIG-IP NEXT

Cause

This is by design.

Recommended Actions

We recommend using a user configured at the time of instance add to CM, such as "admin-cm".

Additional Information

None.
