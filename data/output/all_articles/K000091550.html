K000091550: VirtualServerRoute <namespace>/<name of VirtualServer> doesn't exist or invalid; but was not applied: Error when updating config from configMap: could not get newest config version: could not get expected version: 1 after 1m0s

Type
Support Solution
Published
2022-05-04
Updated
2022-05-04
Source
https://my.f5.com/manage/s/article/K000091550

Description

  • You have multiple ingress controller deployments in multiple namespaces and all working
  • You wanted to protect your application with Nginx App Protect
  • You proceeded to add Nginx-ingress controller with Nginx App Protect [NAP], and replicated your ingress setup onto a different Namespace
  • While the comparison of configuration between NAP ingress and normal ingress indicates minimal difference, from time to time when making change to a virtualServer/VirtualServerRoute in the namespace where Ingress controller with NAP installed, you note the below error message

error

Configuration for live/care-carepcs-waf was added or updated with warning(s): VirtualServerRoute <namespace>/<name of VirtualServer> doesn't exist or invalid; but was not applied: Error when updating config from configMap: could not get newest config version: could not get expected version: 1 after 1m0s


  • Following the above error, you verified the presence of referred configmap on the ingress controller
  • You compared working with that of a none working but both configmaps is shown to have the same data

 Environment

  • Nginx Ingress controller
  • Nginx App Protect

 Cause

  • Configuration update from configMap cannot exceed more than one minute other wise the creation of virtualServe objects in Nginx Plus would fail

 Recommended Actions

  • Redeployment virtualServer

 Additional Information

  • none
