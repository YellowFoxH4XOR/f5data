Topic

In FirePass versions prior to 6.0.3, when a FirePass session variable contained multiple values, FirePass used the space character as the delimiter between values.

For example:

%SomeSessionVariable% = "Value1 Value2 Value3"
 
With the introduction of advanced session variables in FirePass version 6.0.3, FirePass had to support session variables whose values contained space characters. Therefore, the space character could no longer be used as a delimiter. As a result, starting in FirePass version 6.0.3, session variables created from Active Directory, LDAP, or RADIUS attributes with multiple values are separated with the vertical bar ( | ) character.

For example:
 
%SomeSessionVariable% = "Value1|Value2|Value3"
 
The Network Access LAN address space field requires each value to be separated by a space, comma ( , ), or semi-colon ( ; ) character. As a result, you cannot enter an Active Directory, LDAP, or RADIUS session variable that may contain multiple values in the LAN address space field, without first converting all vertical bar characters to spaces, commas, or semi-colons. If you do not convert these characters, the LAN address routes will not be configured correctly on the client system.

Configuring a session variable in the Network Access LAN address space field
 
To convert the vertical bar characters to spaces, you must create an advanced session variable and enter that advanced session variable in the LAN address space field. To do so, perform the following procedure.
 
  1. Log on to the FirePass Administrative Console.
     
  2. Navigate to the Users: Session Variables page.
     
  3. Click the Add New Session Variable link.
     
  4. In the Name field, enter a unique name for the advanced session variable.

    For example:

    LanAddressSpace

    Note: The name must start with a letter or digit, and it can contain one or more of the following characters: letters, digits, hyphens ( - ) and underscores ( _ ).

  5. In the Description field, enter a description that will help you remember the purpose of this advanced session variable.

    For example:

    Convert vertical bar characters in session.ldap.groupmapping.mobile to spaces.

  6. In the Expression field, enter the following syntax where <Lan.Address.Session.Variable> is the session variable that contains the list of values for the LAN address space field:

    REGEX_R(<Lan.Address.Session.Variable>, "|(.*)|", "$1 ")

    For example, if session.ldap.groupmapping.networks is the session variable that contains the list of LAN networks you would enter the following syntax:

    REGEX_R(session.ldap.groupmapping.networks, "|(.*)|", "$1 ")

    Important: Ensure that there is a space character after $1.

    Note: The session variable session.ldap.groupmapping.networks is used only as an example. Use the attribute retrieved from your authentication server that contains the list of LAN networks. If you are unsure which session variable to use, you can temporarily enable the Save user's session variables to Logon Reports option on the Device Management: Maintenance: Troubleshooting Tools page to have all session variables logged to the Logon Reports. Enabling the Save user's session variables to Logon Reports option increases the load on the FirePass controller. Therefore, F5 Networks recommends leaving this option disabled when not required for troubleshooting.
     
  7. Click the Save button.
     
  8. Navigate to the Network Access: Resources page.
     
  9. In the Resource Group menu, select the name of the resource group you want to configure.
     
  10. In the LAN address space field, enter the name of the advanced session variable you just created.

    For example:

    %session.asv.LanAddressSpace%

    Note: Advanced session variables use the format session.asv.<name> where name is the unique name you configured for the advanced session variable. Advanced session variable names are case-sensitive. Therefore, if you entered LanAddressSpace in Step 4, you must enter %session.asv.LanAddressSpace%, and not %session.asv.lanaddressspace%.

    Note: The LAN address space field only appears if the Use split tunneling for traffic option button is selected.
     
  11. Click the Update button.
