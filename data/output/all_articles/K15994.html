Known Issue

iRule creation fails when using the iControl REST API.

Impact

You cannot create iRules using the iControl REST API.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You are unable to create iRules using the iControl REST API.

Resolution

Status

F5 Product Development has assigned ID 428736 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of Fix
Versions Fixed
Related Articles
Release11.5.0K2200: Most recent versions of F5 software
HotfixNoneNone

Workaround

To work around this issue, you can create iRules using the BIG-IP Configuration utility.

Impact of workaround: Performing this workaround should not have a negative impact on your system.
