Known Issue

The Server Side SSL option is not saved when the Citrix Remote Desktop resource is created or updated.

This issue occurs when the following condition is met:

  • A user sets the SSL option from the Configuration utility

This issue does not affect setting the option using the Traffic Management Shell (tmsh), due to ID 375289. For more information, refer to K13556: Enabling Citrix remote desktop server side SSL breaks network connectivity.

Impact

You cannot configure the BIG-IP system to connect to the Citrix server using SSL.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The Server Side SSL option will not be set when the remote desktop resource is opened.
