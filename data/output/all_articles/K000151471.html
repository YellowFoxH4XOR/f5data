Description

BIG-IP device licensed is managed by BIG-IQ. License is not updated with latest license to perform software upgrade.  After the upgrade into new software volume BIG-IP device console shows reactivate the license.

Following errors are noted in the /var/log/ltm in affected BIG-IP device

httpd[8423]: 01180006:3: Software version not covered by service agreement service check date xxxxxxxx version date xxxxxxxx. 

 

Environment

 

  • BIG-IP device license is managed by BIG-IQ
  • Software upgrade fails 

Cause

BIG-IP license managed by BIG-IQ, was not updated to cover the new software version after the upgrade.

 

Recommended Actions

  1. Reactive the license from BIG-IQ. Follow steps mentioned under "Reactivate the Catalog License on the BIG-IQ" topic in K84488720: How to reactivate an FCP license on BIG-IQ
  2. Refresh license to affected BIG-IP device 
    Note: Refresh process is traffic impacting in affected BIG-IP
