K000153006: [SSLO] Deployment will fail when creating a topology in the same VLAN as an existing service

Type
Support Solution
Published
2025-08-13
Updated
2025-08-13
Applies to
  • F5 App Protect
  • BIG-IP SSL Orchestrator: 17.1.1
Source
https://my.f5.com/manage/s/article/K000153006

Description

SSLO Deployment will fail with an error when attempting to create a new topology in a VLAN where a topology already exists.

[OrchestratorConfigProcessor] Deployment failed for Error: [HAAwareICRDeployProcessor] Error: transaction failed:01070333:3: Virtual Server /Common/<virtual server> illegally shares destination address, source address, service port, ip-protocol, and vlan with Virtual Server /Common/<virtual server>.

Environment

SSLO

Cause

This is expected

Recommended Actions

For new topologies, please specify a vlan that does not contain a pre-existing topology.

Additional Information

If you have already created a Service, there will be a VS named ssloS_<services>-D-0-t-4.

This is enabled for the VLAN specified in 'From Service Configuration' in Service Properties.

 

---

ssloS_FOO-D-0-t-4

  destination /Common/0.0.0.0:0

  vlans {

    /Common/EXT_VLAN

  }

---

In this case, if you specify the same vlan 'EXT_VLAN' in 'From Service Configuration' for a newly created service, an error will occur when SSLO attempts to create a new 0.0.0.0:0 listener in the same VLAN.
