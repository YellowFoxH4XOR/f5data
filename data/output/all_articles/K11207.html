Known Issue

This is the result of a known issue. PASV FTP data connections sent by the client may fail when a transparent FTP virtual server has no pool resource defined, but the BIG-IP configuration contains a route entry for the FTP traffic or the virtual server references a default gateway pool. When the client attempts the PASV FTP data connection, the BIG-IP system may reply with an ICMP network unreachable error message.

F5 Product Development tracked this issue as CR128955 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue was fixed in Hotfix-BIGIP-9.4.8-396.1-HF3 issued for BIG-IP version 9.4.8, and Hotfix-BIGIP-10.0.1-402.7-HF4 issued for BIG-IP version 10.0.1. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
