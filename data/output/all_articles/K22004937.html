Description

 /var/log/ltm logs similar to 
          warning tmm[<PID>]: 01260017:4: Connection attempt to insecure SSL server (see RFC5746)

Environment

  • BIG-IP v11 and later
  • Server SSL profile is set to virtual server which caused this message.
     

Cause

The back-end SSL server lacks support for the Transport Layer Security (TLS) renegotiation indication extension described in RFC5746.
 

Recommended Actions

Depending the Server SSL profile’s Secure Renegotiate setting Impact/Symptom is different, please refer linked article below.

Request
K80728510: Impact of Error Message: Connection attempt to insecure SSL server (see RFC5746): <address>:<port>, when Server SSL has "Request" for Secure Renegotiate attribute
 
Require or Require Strict
K13860: Impact of Error Message: 01260017:4: Connection attempt to insecure SSL server (see RFC5746) aborted: <address>:<port>, when Server SSL has "Require" or "Require Strict" for Secure Renegotiate attribute.
