Issue

Error Message

012b3100:5: CRL file <filename> created, enabling CRL validation on all remote iQuery connections

In this error message, note the following:

  • <filename> is the name of the certificate revocation list (CRL) file used to revoke SSL certificates for iQuery connections.

For example:

012b3100:5: CRL file /config/revoked_certs.crl created, enabling CRL validation on all remote iQuery connections

Message Location

You may encounter this message in the following locations:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • The following PEM-encoded CRL file is installed on the BIG-IP system:
    • /config/revoked_certs.crl

Starting in BIG-IP 16.x, you can configure the system to check for revoked SSL certificates for components that use the iQuery communication mechanism, such as BIG-IP DNS synchronization. To enable the feature, you must install a valid PEM-encoded CRL to the BIG-IP system.

Impact

CRL validation is enabled for iQuery connections.

None
