K000134593: Remote authentication with ignore-unknown-user enabled could fallback to BIG-IP system

Type
Support Solution
Published
2023-05-12
Updated
2023-05-12
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000134593

Description

When ignore-unknown-user is enabled for remote authentication, the BIG-IP system can fallback to local authentication for users who do not exist in the remote authentication server, even if Fallback to Local is disabled.

 

auth ldap /Common/system-auth {
    bind-dn cn=test,ou=accounts,dc=example,dc=com
    bind-pw ***scrubbed***
    check-roles-group enabled
    debug enabled
    ignore-unknown-user enabled  -->!!!!
    login-attribute sAMAccountName
    port 636
    search-base-dn OU=accounts,DC=example,DC=com
    servers { 192.0.2.1 }
    ssl enabled
}

auth source {
    type active-directory
}

 

Environment

  • Remote auth
  • AD server

Cause

Remote authentication with ignore-unknown-user enabled.

Recommended Actions

BIG-IP verifies remote authentication with the server, and if a user does not exist in the remote authentication server, BIG-IP will use local authentication for that user because the ignore-unknown-user option is enabled. This happens even if Fallback to local has not been enabled on BIG-IP.
