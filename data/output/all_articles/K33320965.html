K33320965: SWG stops working after upgrade due to iRule Event in HTTPS path of Per-Request Policy

Type
Support Solution
Published
2025-07-01
Updated
2025-07-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K33320965

Description

  • After upgrading from a pre-v14.1.0 version HTTPS traffic is no longer forwarded
  • Error messages logged in /var/log/apm:
    "... Wait to raise per-request policy iRule Agent event, need more data (HTTP)"

Environment

  • BIG-IP with SWG
  • Upgrading to v14.1.0 or above from a pre-v14.1.0 version
  • An "iRule Event" object exists in the HTTPS path of the SWG Per-Request Policy

Cause

A new property "Expect Data" for the "iRule Event" object when used in a Per-Request Policy (PRP) was introduced in v14.1.0 . The default value for this property is "HTTP" and this value causes the PRP to hang if used in the HTTPS path.

Recommended Actions

Change the "Expect Data" of any "iRule Event" objects in the HTTPS path of the Per-Request Policy to either "SSL Client Hello" or "SSL Server Cert".
