Description

You would like to know if upgrade is limited to a pre-established range of software releases for Flex Consumption Program (FCP) licenses.

Environment

  • BIG-IP Virtual Edition (VE)
  • BIG-IQ
  • Flex Consumption Program (FCP)
  • Licensing

Cause

None

Recommended Actions

FCP licenses do not have a static software version limitation. The ability to use a specific BIG-IP software version depends on the Service Check Date associated with your BIG-IP license. 

Additional Information

K000152314: Verify Service Check Date prior to upgrading FCP BIG-IP VE
