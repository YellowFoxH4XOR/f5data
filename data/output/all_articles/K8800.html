Topic

The default Client SSL and Server SSL profiles support a different set of Secure Sockets Layer (SSL) ciphers depending on the software version you are running. The default Client SSL profile in BIG-IP LTM 9.2.x through 9.4.x allows ciphers from both the NATIVE and COMPAT SSL stacks.

Note: For information regarding BIG-IP 10.0.x, refer to K10262: SSL ciphers used in the default SSL profiles in BIG-IP 10.x.

Note: For more information, refer to K8802: Using SSL ciphers with BIG-IP clientssl and serverssl profiles.

The following table lists the ciphers used in the default Client SSL profile in BIG-IP 9.2.x through 9.4.x:

Note: The default Client SSL profile supports only the SSLv3 and TLSv1.0 cryptographic protocols.

RC4-MD5128
RC4-SHA 128
AES128-SHA 128
AES256-SHA256
DES-CBC3-SHA192
DES-CBC-SHA 64
EXP1024-RC4-MD556
EXP1024-RC4-SHA56
EXP1024-DES-CBC-SHA56
EXP-RC4-MD540
EXP-DES-CBC-SHA40
ADH-RC4-MD5128
ADH-AES128-SHA128
ADH-AES256-SHA256
ADH-DES-CBC3-SHA192
ADH-DES-CBC-SHA64
DH-RSA-AES128-SHA128
DH-RSA-AES256-SHA256
DH-RSA-DES-CBC-SHA64
DH-RSA-DES-CBC3-SHA192
DHE-RSA-AES128-SHA128
DHE-RSA-AES256-SHA256
DHE-RSA-DES-CBC-SHA 64
DHE-RSA-DES-CBC3-SHA192
EXP1024-RC2-CBC-MD556
EXP-RC2-CBC-MD540
EXP-ADH-DES-CBC-SHA40
EXP-ADH-RC4-MD540
EXP-DH-RSA-DES-CBC-SHA40
EXP-EDH-RSA-DES-CBC-SHA40

The default Server SSL profile in BIG-IP LTM 9.2.x through 9.4.x allows ciphers from the native SSL stack. The following table lists the ciphers used in the default Server SSL profile in BIG-IP 9.2.x through 9.4.x:

Note: The default Server SSL profile supports only the SSLv3 and TLSv1.0 cryptographic protocols.

CipherBits
RC4-MD5128
RC4-SHA128
AES128-SHA128
AES256-SHA256
DES-CBC-SHA64

Note: For more information about the cipher suites registered with IANA, including cipher string and cipher suite IDs, refer to RFC5246: The Transport Layer Security (TLS) Protocol.
