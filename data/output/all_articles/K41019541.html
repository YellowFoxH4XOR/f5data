Description

This article will cover the recommend practice for managing the DNS or GTM products from a BIG-IQ.

A specific use case would be as follows:
Attempting to deploy a new Virtual Server to an LTM that is connected to a DNS or GTM with auto discover the DNS or GTM automatically adds the Virtual Server to it's config

Environment

  • Using BIG-IQ to manage DNS or GTM
  • Deploying a new Virtual Server to GTM

Cause

None

Recommended Actions

If you are going to manage DNS or GTM from the BIG-IQ, you need to ensure you re-discover and re-import prior to building DNS or GTM on the BIG-IQ.  Once the device is managed by the BIG-IQ you should be execute auto imports from the BIG-IQ.
Warning: The product will not stop you from deploying without doing this, however, if this recommendation is not followed it can later cause issues syncing between BIG-IQ and the DNS or GTM.
