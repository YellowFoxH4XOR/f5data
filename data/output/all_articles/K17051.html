Known Issue

Attempts to delete a Secure Sockets Layer (SSL) certificate or key may fail.

This issue occurs when all of the following conditions are met:

  • You create an SSL certificate or key without a corresponding .crt or .key extension.
  • You import the SSL certificate or key to the BIG-IP system.
  • You subsequently attempt to delete the SSL certificate or key by using iControl SOAP.

Impact

Users are unable to delete an SSL certificate or key using iControl SOAP.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to delete an SSL certificate or key.
  • When you attempt to delete an SSL certificate or key using iControl SOAP, the system displays an error message similar to the following example:

    "The requested Certificate Key File was not found"

  • In the /var/log/ltm file, you observe an error message similar to the following example:

    err mcpd[9630]: 01020036:3: The requested Certificate Key File (/Common/certname) was not found

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to delete the affected SSL certificate or key. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Using the tmsh utility to delete an SSL certificate or key

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Delete the SSL certificate or key by using the following command syntax:

    delete sys crypto [cert|key] <name>

    For example, to delete an SSL certificate named myCert you would type the following command:

    delete sys crypto cert myCert

  3. Save the change by typing the following command:

    save /sys config
