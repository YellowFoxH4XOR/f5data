Topic

Windows 10 introduces the Universal Windows Platform (UWP), which provides a common app platform on every device that runs Windows 10. UWP apps (formerly known as Windows Store apps) run across all compatible Windows devices, such as PCs, mobile devices, XBox, and Surface Hub. UWP apps differ from traditional desktop apps in that they are distributed through the Microsoft Store. Developers can release both a UWP app and a desktop app for a product; for example, F5 Access and the BIG-IP APM Edge Client, respectively.

For more information, refer to the What's a Universal Windows Platform (UWP) app? Microsoft Docs article, which discusses BIG-IP APM application tunnels and optimized application support for UWP apps.

Description

BIG-IP APM app tunnels and optimized applications are incompatible with UWP apps. These include UWP applications like F5 Access, Edge Browser, and other browsers or apps that you download and install from the Microsoft store. App tunnels and optimized applications are BIG-IP APM features that provide a set of compression characteristics to configure and apply to traffic flowing from client devices to a specific IP address, network, or host, on a specified port or range of ports.

For more information about app tunnels, refer to the Configuring App Tunnel Access chapter of the BIG-IP Access Policy Manager: Application Access Guide. For more information about optimized applications, refer to the Creating Optimized Application Tunnels chapter of the BIG-IP Access Policy Manager: Network Access manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Note: Optimized application tunnel is a BIG-IP APM network access feature that is supported only for Windows client systems and require administrative rights on the client system to install.

Recommendations

When using BIG-IP APM app tunnels or optimized applications, F5 recommends the following practices:

  • Use a supported browser, such as Google Chrome or Mozilla Firefox to access your protected resources.

    For BIG-IP APM-supported web browsers, refer to K14047: Supported operating systems and web browsers for the BIG-IP APM system.

  • Use the BIG-IP Edge Client to establish a network access VPN connection.
