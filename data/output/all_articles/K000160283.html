K000160283: APM: session fails with errorcode=22

Type
Support Solution
Published
2026-03-10
Updated
2026-03-10
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160283

Description

BIG-IP APM sessions fail to establish after upgrade or roll back when virtual server is configured with address-list. Users receive an error message in the browser:

"(Your session could not be established. The session reference number: XXXXXXXX. Access policy configuration has changed on gateway. Please login again to comply with new access policy configuration"

No session ID is recorded in the APM logs, though it may be visible in the browser or packet capture.

Environment

  • Product: BIG-IP APM
  • Address-List

Cause

Bug ID 2229285: APM VPN sessions fail with errorcode=22 after upgrade/rollback when Virtual Server uses address-lists.

Answer/Recommended Actions

To work around this issue, perform the following steps:

  1. Remove the address-list (destination or source) from the affected Virtual Server.
  2. Restart the APM daemon (apmd) on the BIG-IP system:
    tmsh restart sys service apmd
