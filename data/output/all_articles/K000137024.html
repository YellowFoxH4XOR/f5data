Description

After changing BIG-IP vCMP host VLAN name, the BIG-IP vCMP guest no longer can view the VLAN status from imish shell, all routing configuration fail to load via this vlan

When viewing the interface status from imish shell, you cannot see the the affected VLAN interfaces

show ip int brief

VLAN interface is missing

Environment

  • BIG-IP LTM
  • BIG-IP vCMP guest running on a vCMP host
  • Changing named VLAN from BIG-IP vCMP host while its assigned to BIG-IP vCMP guest
  • The VLAN being changed was used under specific partition and that VLAN is also part of routing-domain

Cause

Deleting the vlan and creating new one by the same name and assign it to the guest, the vlan will not show up under interfaces of tmrouted process.

Recommended Actions

Reboot the BIG-IP vCMP guest to resolve bring back the interfaces.

Additional Information

If you have BGP configured, the issue will lead BGP to announce next-hop as 0.0.0.0 to neighbor routers and they will reject the session.
