Topic

You should consider using this procedure under the following condition:

  • You need to change the log levels for the asm_config_server process for certain situations, such as troubleshooting BIG-IP ASM ConfigSync issues.

Description

The asm_config_server process is one of the processes that handle the configuration synchronization between the BIG-IP ASM systems. When troubleshooting BIG-IP ASM ConfigSync issues, you may have to require more verbose logging by changing the following two parameters in the /etc/ts/tools/asm_config_server.cfg to the log level of trace:

  • rpc_log_level
  • event_dispatcher_log_level

The default log level for these two parameters is info.

Turning on more verbose logging increases the amount of hard disk activity and may degrade the system performance, depending on the amount of configuration changes taking place. F5 recommends that you turn on verbose logging only when required, and you should turn it off immediately after troubleshooting.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • The BIG-IP ASM system is part of a high-availability configuration.
  • You must have command line access to the desired BIG-IP ASM system.
  • You must have familiarity with a command line text editor.

Procedures

Enabling verbose logging for the asm_config_server process

You can turn on more verbose logging by changing the log level from info to trace in the /etc/ts/tools/asm_config_server.cfg file. To do so, perform the following procedure:

Impact of procedure: An overloaded BIG-IP system may experience performance degradation if the logging intensity is high.

  1. Log in to the BIG-IP command line.
  2. Make a back-up copy of the /etc/ts/tools/asm_config_server.cfg file by typing the following command:

    cp -p /etc/ts/tools/asm_config_server.cfg /var/tmp/asm_config_server.cfg.sol14185.info

  3. Edit the /etc/ts/tools/asm_config_server.cfg using a text editor of your choice.
  4. Locate the following two parameters:

    rpc_log_level=info
    event_dispatcher_log_level=info

  5. Change the log level from info to trace for these two parameters:

    rpc_log_level=trace
    event_dispatcher_log_level=trace

  6. Save the changes and exit the text editor.
  7. Restart the asm_config_server process by typing the following command:

    pkill -f asm_config_server

    Note: Restarting the asm_config_server process does not affect traffic processing and security enforcement on the BIG-IP ASM system.

Disabling verbose logging for the asm_config_server process

You can turn off more verbose logging by changing the log level from trace to info in the /etc/ts/tools/asm_config_server.cfg file. To do so, perform the following procedure:

Impact of procedure: Configuration utility access to the policy configuration is disrupted while the asm_config_server process is stopped.

  1. Log in to the BIG-IP command line.
  2. Make a back-up copy of the /etc/ts/tools/asm_config_server.cfg file by entering the following command:

    cp -p /etc/ts/tools/asm_config_server.cfg /var/tmp/asm_config_server.cfg.sol14185.trace

  3. Edit the /etc/ts/tools/asm_config_server.cfg using a text editor of your choice.
  4. Locate the following two parameters:

    rpc_log_level=trace
    event_dispatcher_log_level=trace

  5. Change the log level from trace to info for the following two parameters:

    rpc_log_level=info
    event_dispatcher_log_level=info

  6. Save the changes and exit the text editor.
  7. Restart the asm_config_server process by entering the following command:

    pkill -f asm_config_server
