K72450081: Enabling SSL Certificate Verification in BIG-IQ Centralized Manager can mark all devices unavailable

Type
Support Solution
Published
2022-01-18
Updated
2025-02-07
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K72450081

Description

BIG-IQ offers a check box in the GUI to enable SSL Certificate Verification of managed devices

  • When enabled, managed devices can become immediately unavailable
  • javax.net.ssl.SSLException: Certificate at IP address x.x.x.x  is not trusted. Please verify the host is correct, and set up SSL Certificate Verification settings for the server certificate or one of its trust chain certificates.

Environment

Relevant environmental factors specific to the topic

  • SSL Certificate Verification is enabled by checking the box.
  • Configuration Utility >>>> System >>>> SSL Certificate Verification
  • BIG-IQ Centralized Manager 

Cause

By Default, the F5 devices have self-signed certificates that the BIG-IQ will not be able to verify, or the BIG-IQ will not have the required certificate needed to verify the assigned certificate on the managed device.

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Do not enable this feature (check the box) unless the BIG-IQ has the required certificate(s) needed for verification.
  2. The result of checking/unchecking the box is IMMEDIATE
