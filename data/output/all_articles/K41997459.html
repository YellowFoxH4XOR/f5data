Security Advisory Description

A reflected cross-site scripting (XSS) vulnerability exists in the resource information page for authenticated users when a full webtop is configured on the BIG-IP APM system. (CVE-2021-23054)

Impact

An attacker can craft a malicious URL and send it to an authenticated user to launch a XSS attack.

This vulnerability affects BIG-IP APM access profiles with both Modern and Standard Frameworks. To determine which framework your access profile is using, on the BIG-IP configuration utility, go to the affected access profile. The Customization Type field displays the framework.
