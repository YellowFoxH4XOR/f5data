Topic

When the snmpwalk command is used from the command line, and no OID argument is specified, the snmpwalk command process only searches the MIB-2 class management information bases (MIBs), by default.

Note: This is the default behavior for the NET-SNMP suite and is outlined in the NET-SNMP help documentation. The help documentation can be viewed by typing the following command at the command syntax line, where <snmp command name> represents the name of the SNMP protocol you are using: man <snmp command name>.

When the snmpwalk command is entered with no OID argument, the information displayed includes (but is not limited to) the following MIB-2 class MIB files:

  • SNMPv2-MIB
  • RFC1213-MIB
  • TCP-MIB
  • UDP-MIB
  • IPV6-MIB

F5-specific MIBs that are not displayed, by default, include the following:

  • F5-BIGIP-LOCAL-MIB
  • F5-BIGIP-SYSTEM-MIB
  • F5-BIGIP-GLOBAL-MIB
  • F5-BIGIP-APM-MIB
  • F5-BIGIP-WAM-MIB

F5-BIGIP-LOCAL-MIB

This MIB defines LTM objects such as virtual servers, pools, members, and profiles, and can be used with BIG-IP LTM and Link Controller.

To walk the F5-BIGIP-LOCAL-MIB file, type the following command syntax from the command line:

snmpwalk -v 2c -c <community string> localhost bigipLocalTM

F5-BIGIP-SYSTEM-MIB

This MIB defines BIG-IP system information such as global statistic data, network and platform information, and can be used with any BIG-IP modules.

To walk the F5-BIGIP-SYSTEM-MIB file, type the following command syntax from the command line:

snmpwalk -v 2c -c <community string> localhost bigipSystem

F5-BIGIP-GLOBAL-MIB

This MIB defines GTM objects such as links, applications, datacenters, servers, and wide IP addresses, and can be used with BIG-IP DNS/GTM and Link Controller.

To walk the F5-BIGIP-GLOBAL-MIB file, type the following command syntax from the command line:

snmpwalk -v 2c -c <community string> localhost bigipGlobalTM

F5-BIGIP-APM-MIB

This MIB is available in BIG-IP 11.0.0 and later; it defines APM objects, such as access and connectivity statistics, pool statistics, and general APM information, and can be used with BIG-IP APM.

To walk the F5-BIGIP-APM-MIB file, type the following command syntax from the command line:

snmpwalk -v 2c -c <community string> localhost bigipApm

F5-BIGIP-WAM-MIB

This MIB is available in BIG-IP 11.0.0 and later; it defines AAM/WebAccelerator traffic objects, such as AAM/WebAccelerator specific statistic data, connection stats, or build information, and can be used with BIG-IP AAM/WebAccelerator.

To walk the F5-BIGIP-WAM-MIB file, type the following command syntax from the command line:

snmpwalk -v 2c -c <community string> localhost bigipWAM
