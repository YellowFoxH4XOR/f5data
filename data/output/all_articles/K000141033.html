K000141033: TACACS Authentication does not work on VELOS System Controller

Type
Support Solution
Published
2024-09-11
Updated
2024-09-11
Applies to
  • F5OS
  • F5OS-C: 1.6.X, 1.6.2, 1.6.1, 1.6.0
Source
https://my.f5.com/manage/s/article/K000141033

Description

TACACS Authentication does not work on VELOS System Controller. It works on Chassis Partition.



Environment

F5OS-C



Cause

TACACS authentication for a System Controller does not work when a floating IP address is added (on the TACACS Server side).


It only works when you add the local IP address of each System Controller (Active and Standby).



Recommended Action

Configure the local IP address of each System Controller on the TACACS Server side.



Additional Information

None
