K000156565: ASM Learning Suggestions are flushed during Active-Active Sync

Type
Support Solution
Published
2025-09-22
Updated
2025-09-22
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000156565

Description

When running an Active-Active configuration, please be aware that any unaccepted or un-ignored ASM learning suggestions will be flushed when the devices sync. This is a consequence of the design, which treats learning suggestions as temporary data. 

This behavior, combined with traffic distribution, can also lead to the following:

  • ASM Suggestions may only be generated on one device.
  • The Enforcement Readiness Summary may change and could have pending suggestions on one device but not on the others.
  • The ASM learning suggestions may mismatch between the BIG-IP devices.

Environment

  • ASM Learning Suggestions in an Active-Active Configuration

Cause

None

Recommended Actions

  • To ensure consistency, set the HA configuration in Active-Active mode to Manual Sync, and sync each BIGIP system individually.
  • To speed up the learning process, we recommend adding a known IP address as a trusted IP in the security policy.
