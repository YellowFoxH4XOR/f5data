K4011: Reasons why static routes may no longer work after changes are made to a self IP address, interface address, or a VLAN configuration

Topic

When you change a self IP address, interface address, or VLAN configuration, static routes do not update automatically to work with the new settings. In versions prior to 4.5.11, if you use the Configuration utility to make changes to the self IP, interface, or VLAN configuration, the default route and any static routes may become invalid.

Starting in BIG-IP and 3-DNS versions 4.5.11 and 4.6.3, F5 Networks Product Development modified the Configuration utility to ensure that static routes are not invalidated unintentionally:

  • The Configuration utility will not allow you to delete a self IP address that is used to reach a node.
  • The Configuration utility will warn you if you try to delete a self IP address that is associated with a static route.
  • If you change the VLAN associated with a self IP, the Configuration utility will reload any associated static routes.

For information about upgrading, refer to the BIG-IP Release Notes.

Workaround

To correct this issue in versions prior to versions 4.5.11 and 4.6.3, reload the static routes stored in the /config/routes file by typing the following command:

b load
