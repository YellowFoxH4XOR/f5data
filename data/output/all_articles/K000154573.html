K000154573: Clarification on License Reactivation from v16 SKU to v18 SKU in BIG-IP VE: Tech Refresh vs. License Upgrade

Description

Clarification is required regarding whether re-activating or renewing a BIG-IP VE license from a v16 SKU to a v18 SKU qualifies as a "Tech Refresh." This process involves updating the license to enable newer software versions or features. No error messages, system faults, or operational issues are associated with this procedure.

Environment

  • Product: BIG-IP Virtual Edition (VE), BIG-IQ VE
  • Platform: F5-BIQ-VE-LOG-NODE
  • Software Version: Upgrading from v16.x.x (V16 SKU) to v17.x.x or v18.x.x (V18 SKU)
  • Deployment: Virtualized environments (e.g., VMware, AWS, Azure)

Cause

Re-activating or upgrading a BIG-IP VE license from v16 SKU to v18 SKU is considered a standard license or software upgrade. This does not involve significant changes to the underlying infrastructure or platform and therefore does not meet the definition of a "Tech Refresh." A Tech Refresh typically refers to major updates such as hardware replacement or substantial migration to new platforms/architectures.

Recommended Actions

  • Treat license re-activation or upgrade from v16 SKU to v18 SKU as a license/software upgrade rather than a Tech Refresh unless it coincides with significant infrastructure/platform changes.
  • To perform the upgrade:
    1. Reactivate or update the license according to the requirements of the new software version.
    2. Migrate configuration files as needed for compatibility with the newer version.
    3. Ensure that your virtualized environment supports the target software version.
  • If migrating from hardware appliances to virtual/cloud platforms, or if performing an overhaul of underlying infrastructure, this may be considered a Tech Refresh.
