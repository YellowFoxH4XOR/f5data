Description

  • You get a warning log similar to the following, indicating that a certificate on the default BIG-IP CA-bundle has expired :

    warning tmsh[<PID>]: 01420008:4: Certificate 'CN=<CertificateName> CA,O=<CertIssuer>, Inc.,C=US' in file /Common/ca-bundle.crt expired on <Month> <Day> <HH:MM:SS> <YEAR> <TIME ZONE>

  • Output of command "run /sys crypto check-cert verbose enabled" shows some certificates from CA-bundle had expired as below:                               
    CN=<CertificateName>,OU=<OU Name>,O=<CertIssuer>,C=NL in file /Common/ca-bundle.crt expired on <Month> <Day> <HH:MM:SS> <YEAR> <TIMEZONE>

  • You want to delete the expired certificate from the bundle ca-bundle.crt

Environment

  • Ca-bundle certificates on BIG-IP

Cause

The default CA certificate bundle file used by the system contains some expired certificates.

Recommended Actions

Impact of procedure: BIG-IP system traffic processing is interrupted while the system restarts.   

  1. Log in to the BIG-IP system command line.
     
  2. Run below command to view the expired certificates: 
    # tmsh run sys crypto check-cert                  
    CN=SwissSign Personal Gold CA 2008 - G2,O=SwissSign AG,C=CH in file /Common/ca-bundle.crt expired on Jul  7 17:24:18 2023 GMT
                                                                                                        
  3. Change directories to the /config/ssl/ssl.crt/ directory by typing the following command under bash: 
    # cd /config/ssl/ssl.crt/                                              
                                                   
  4. Back up the original ca-bundle.crt file by typing the following command:                 
     # cp ca-bundle.crt ca-bundle.crt.original          
                                                                                                                 
  5. Using a text editor, open the ca-bundle.crt file.
