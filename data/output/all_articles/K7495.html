Known Issue

This is the result of a known issue. A CRLDP authentication module can be used on a BIG-IP system to authenticate client traffic using the CRLDP protocol. The purpose of a CRLDP authentication module is to manage the revocation of client SSL certificates on a network. Client authentication based on the CRLDP module causes a memory leak in the tamd process.

F5 Product Development tracked this issue as CR79037, and it was fixed in BIG-IP LTM 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
