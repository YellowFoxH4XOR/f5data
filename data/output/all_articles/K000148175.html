K000148175: Unexpected error while authenticating with Identity provider for F5® Distributed Cloud Services

Type
Support Solution
Published
2024-11-08
Updated
2025-10-10
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000148175

What Happened

  • You have trouble to login to support tenant/Distributed Cloud console via SSO.
  • While trying to login, you might get the error "Unexpected error when authenticating with identity provider".

Environment

  • F5® Distributed Cloud SSO
  • Distributed Cloud (XC) Console

Cause

  • The issue is most likely due to the Azure SSO error where the client secret from Azure console would has expired.

Resolution/Answer

  • The tenant owner should have access to the Azure console
  • From there, the tenant owner needs to renew the client secret from Manage >> Certificates and Secrets >> Client secrets
  • Steps are mentioned in the TechDocs - SSO - Azure AD under the category "Register Application and Setup SSO" -> Step 4: Configure client secret

Remember that you have to copy the Value not the Secret ID once created;
