Known Issue

When you press Ctrl+C while a tshark process is running on the BIG-IP system, the process does not exit and stop capturing.

This issue occurs when all of the following conditions are met:

  • You use the tshark utility to capture packets on a Virtual Local Area Network (VLAN) or on interface 0.0.
  • You attempt to exit the tshark process by pressing Ctrl+C.

Impact

You are unable to exit the tshark utility and it may capture more data than expected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Pressing Ctr+C does not gracefully exit tshark.

Workaround

To work around this issue, you can use Advanced Shell (bash) job control tools to exit and then manually terminate the tshark process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Press Ctrl+Z.

    The system output appears similar to the following example:

    ^Z
    [1]+  Stopped                 tshark -ni Vlan

  2. To terminate the tshark process, type the following command:

    kill -9 `pidof tshark`

    The system output appears similar to the following example:

    [1]+  Killed                  tshark -ni Vlan
