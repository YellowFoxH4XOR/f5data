Known Issue

The BIG-IP ASM system expects WhiteHat Sentinel scans to originate from certain source IP addresses. These expected IP addresses are coded into the BIG-IP ASM system software. Due to changes, WhiteHat has made to the Sentinel scanning configuration, the BIG-IP ASM system may have an incomplete list of expected source IP addresses.

This issue occurs when the following condition is met:

  • The BIG-IP ASM system is being integrated with the WhiteHat Sentinel vulnerability scanning service.

Impact

WhiteHat Sentinel scans may fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The WhiteHat Sentinel scanner software may indicate a failure to contact or scan the target BIG-IP ASM system.
