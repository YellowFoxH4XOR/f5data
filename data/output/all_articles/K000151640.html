Description

During a software upgrade, you notice Changes Pending on the BIG-IP. However, since you have already upgraded one of the devices (typically the standby), you can no longer sync the devices.

Note: If you forgot to sync the devices before the upgrade, continue with the upgrade process. After both units are upgraded, perform a full config sync to make sure both devices are fully aligned.

Environment

  • LTM
  • Software Upgrade
  • Sync state

Cause

Some configuration changes were made before the upgrade. Since auto-sync is not enabled on the BIG-IP, the changes were not synced before the upgrade.

Recommended Actions

1. Always upgrade the standby unit first when performing an upgrade in an HA pair.

2. Before starting any upgrade, make sure all pending changes are saved and both BIG-IPs are synchronized.
