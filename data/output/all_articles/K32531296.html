Description

  • Unable to import/discover ASM device from BIG-IQ
  • A similar error message appears on the BIG-IQ GUI:
    Error while creating 'ASM Policy - Url' 'null' in current-config: http://localhost:8100/cm/asm/current-config/policies/442aaaa0-941f-370d-94a4-3da332112fd8/urls, and while creating 'ASM Policy - Url' 'null' in current-config: http://localhost:8100/cm/asm/current-config/policies/44aaa80-941f-370d-94a4-3da332112fd8/urls, and while creating 'ASM Policy - Url' 'null' in current-config: http://localhost:8100/cm/asm/current-config/policies/442a2b80-941f-370d-94a4-3da332112fd8/urls, message 'Duplicate item. Key already exists: protocol : http, name : /nn/nnv3/api/v1/answer/*' was returned

Environment

  • BIG-IQ CM ASM device discovery/import
  • ASM policy with two or more of the same URLs but with different methods

Cause

This issue is tracked under ID1022441 and ID1316593

Although, BIG-IQ presents the ability to specify URL method types, BIG-IQ does not currently support method types, so it considers two or more of the same URLs (with different methods) as duplicates.

 

Recommended Actions

WORKAROUND

Delete all duplicate URLs that have a method type and keep only one URL (without a method type):

Security  ››  Application Security : URLs

or

Open a support case and get an Eng-hf including ID1316593
