Known Issue

The import_all_from_archive_stream and import_all_from_archive_file iControl methods fail to properly install Secure Sockets Layer (SSL) keys and certificates.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is versioned for 11.5.4, 11.6.0, 11.6.1, or 12.0.0.
  • You use one of the following iControl methods to import SSL keys and certificates using a 10.x archive file:
    • import_all_from_archive_stream
    • import_all_from_archive_file

Impact

SSL keys and certificates are not available for use by BIG-IP objects, such as Client or Server SSL profiles.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Imported SSL keys and certificates are not viewable from either the Traffic Management Shell (tmsh) or the Configuration utility.
  • Imported SSL keys and certificates are not available for use by BIG-IP objects.
  • Imported SSL keys and certificates exist in the 10.x directories: /config/ssl/ssl.key and /config/ssl.crt, but not in the 11.x and later directories: /config/filestore/files_d/Common_d/certificate_d and /config/filestore/files_d/Common_d/certificate_key_d.
