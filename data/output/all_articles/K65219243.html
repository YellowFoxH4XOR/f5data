Description

Configuring SNI for HTTPS monitors

Environment

  • BIG-IP
  • 13.1.* and later
  • HTTPS health monitors
  • SNI (Server Name Indicator)

Cause

Use of SNI in HTTPS health monitors is officially supported through the use of in-TMM monitoring only.
Note: While SNI can be configured on an HTTPS monitor with in-TMM monitoring disabled, the desired functionality will not operate until in-TMM monitoring is enabled globally on the BIG-IP.

Recommended Actions

  • Versions prior to BIG-IP 13.1.0 require the use of an external monitor script to exercise SNI in HTTPs monitors.
  • The following DevCentral article provides information about creating external monitors that support SNI for HTTPS health monitoring: HTTPS SNI Monitoring How-to
    Note: The mentioned external monitor script is community supported via DevCentral.
    Note: By default, the In-TMM feature is disabled in BIG-IP 13.1.0 and you must enable it if you want to run monitors using TMM.


Enabling In-TMM monitoring

Please refer to: K11323537: Configuring In-TMM monitoring


Configure SNI in the related serverssl profile

Using the Configuration utility

  1. Go to Local Traffic > Profiles > SSL > Server.
  2. Select Create.
  3. Create a name for the profile.
  4. For Configuration , select Advanced.
  5. Select the check box for Server Name and enter your server name.
  6. Select Finished.

Using tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Create the SNI enabled profile using the following syntax:

    create ltm profile server-ssl Server_Name { server-name www.example.com}

  3. Save the configuration change:

    save sys config
     

Applying the SNI-enabled serverssl profile to the HTTPS monitor

Using the Configuration utility

  1. Go to Local Traffic > Monitors.
  2. Select Create.
  3. Create a name for the profile.
  4. For Type, select HTTPS.
  5. For Configuration, select Advanced.
  6. For SSL Profile, select the profile that you created.
  7. Select Finished.

Using tmsh

  1. Log in to tmsh by entering the following command:

    tmsh

  2. Create the SNI enabled monitor using the following example:

    create ltm monitor https Server_Name_Monitor { ssl-profile Server_Name }

  3. Save the configuration change:

    save sys config
     

Additional Information

Note: If you configure an HTTPS monitor with a serverssl profile when In-TMM monitoring is disabled, bigd uses the configured cipher string from the serverssl profile.
