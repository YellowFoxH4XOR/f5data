K1522: Maximum number of members (nodes) allowed in a pool

Published
2006-02-17

Status
Legacy Content
Applies to

  • BIG-IP 4.X: 4.6.4
Source

Topic

You can have up to 16,385 nodes in each BIG-IP pool. If you exceed this number, your system displays an error message similar to the following example:
 
bigpipe: Pool, Maximum number of node boxes exceeded.
