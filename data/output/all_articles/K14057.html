Topic

Summary

The ARX system preserves limited CIFS Security Descriptor information during normal operations. Normal operations include file migration, directory replication, share-farm striping, shadow copy, and any other operation where the ARX system acts as the source of the request rather than a proxy for clients.

Description

When requesting information from the filer about an object, the ARX system sends a request for the following CIFS Security Descriptors: 

  • OWNER
  • GROUP
  • Discretionary Access Control List (DACL)

The ARX system receives the requested information from the source filer and forwards the information along to the target filer, intact. The system does not request any additional security information that is maintained by the filer for the objects, and the information is, therefore, unpreserved. This includes the System Access Control List (SACL) information and any other security information that may be available, except for the previously-listed items. For more detailed description of the contents in the security information, please refer to the Microsoft document listed in the following Supplemental Information section.

Recommendations

If you want to retain changes to the security information that the ARX system did not preserve, you must manually modify the object. You can make the changes through the ARX VIP or directly on the filer.

Note: Changes to a directory outside of the ARX VIP are not propagated to all filers containing that directory.
