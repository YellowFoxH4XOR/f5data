K000137999: rSeries both PSUs status grey/off after shutting down system, re-seat did not help

Source

Description

Performed initial configuration of rSeries appliance, then shut it down and removed power.

Restored power, but system does not boot and is inaccessible.

Power supply lights are off.

Connecting to console shows Press <ESC>( for AOM Command Menu.

Environment

  • rSeries
  • F5OS

Cause

This is expected after power cycling the system.

Recommended Actions

The system must be powered back on via the AOM menu. The AOM can be accessed via esc-shift+9 at the console on most keyboards.

Example showing AOM menu procedure:

    --- Press <ESC>( for AOM Command Menu.      <-- System is powered off at this point
   
     
    AOM Command Menu:
    A --- Reset AOM
    B --- Set baud rate
    I --- Display platform information
    N --- Configure AOM network
    P --- Power on/off host subsystem
    R --- Reset host subsystem
    S --- Configure SSH server
    U --- Front panel USB port
    Q --- Quit menu and return to console
     
    Enter Command: p                            <-- Power it back on
    0 -- Turn host subsystem off
    1 -- Turn host subsystem on
     
    Select power option: 1
    Are you sure you want to power the host subsystem on? (y/n) y
    Powering on the host subsystem...
    ...done.                                    <-- It will now boot
