Description

You have ASM provisioned and may have AFM provisioned and when you load the configuration, two warnings appear:

Compliance '/Common/gtp_unknown_tunnel_id' is deprecated and removed from '/Common/protocol_inspection'.

Compliance '/Common/smtp_command_length_overflow' is deprecated and removed from '/Common/protocol_inspection'.

Environment

  • AWAF/ASM
  • AFM

Cause

AFM/IPS is licensed and may or may not be provisioned and while loading the config, the warning message occurs. IPS is the reason ips_base.conf is included in the BIG-IP system.

The warnings are due to /defaults/ips_base.conf or /usr/share/defaults/ips_base.conf containing the compliance checks gtp_unknown_tunnel_id and smtp_command_length_overflow that are deprecated and removed from the default protocol inpection profile protocol_inspection.

These compliance checks should already be marked as deprecated and removed from the associated service. Note the deprecated yes in the following example:

security protocol-inspection compliance gtp_unknown_tunnel_id {
deprecated yes
description "Unknown Tunnel ID"
documentation "This compliance check will match if GTP-C has not created a TEID session for its respective GTP-U session."
id 10209
protocol "udp, sctp"
risk medium
service gtp
subscription no 
} 

When you add the GTP or SMTP service to a protocol inspection profile these checks should not appear.

Recommended Actions

Both compliance checks have been deprecated and can be safely ignored. You can verify that they have been removed by navigating to any protocol inspection profiles that use the services GTP and SMTP and view the list of signatures and compliance checks. To do so perform the following:

  1. Go to Security > Protocol Security > Inspection Profiles
  2. Look in the Enabled Services column for any profiles that have GTP and SMTP enabled.
  3. Select the name of the profile.
  4. Expand the service list at the bottom of the profile page by clicking on the service name.
  5. Verify that the compliance checks in question have been removed.
  6. If the compliance checks have not been removed, contact F5 Support for assistance.
