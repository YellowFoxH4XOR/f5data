Topic

You can configure the BIG-IP ASM to check server responses for certain elements in the security policy. In some cases, when the server response is compressed, the BIG-IP ASM system decompresses a copy of the content based on the Content-Encoding header and analyzes the response according to the security policy. If the BIG-IP ASM system does not find a violation in the content, the BIG-IP ASM system sends the original compressed response to the client and deletes the decompressed copy of the response. Additionally, when you have configured the BIG-IP ASM system to modify server response content as with the Data Guard and cross-site request forgery (CSRF) protection features, the BIG-IP ASM system will decompress the content and apply the required modifications to the content. The system then sends the updated compressed content response to the client.

The BIG-IP ASM system decompresses a copy of the HTTP response if one of the following conditions are met:

  • The Check Response file type property is enabled for an object type.

    When Check Response is enabled, it applies negative security to the server response. If the response arrives compressed, the BIG-IP ASM system decompresses a copy of the content and applies the negative security according to the security policy.

  • Dynamic parameter extractions are configured.

    When the BIG-IP ASM system receives a request that contains a dynamic parameter, the system uses the configured extraction properties to obtain the parameter value or name from the web application's response to the request. Once the system has extracted the dynamic parameter values, the BIG-IP ASM system knows what to enforce the next time a request contains the dynamic parameter.

    Since dynamic parameter extractions occur on the response side of the connection, when the response arrives compressed, the BIG-IP ASM system decompresses the content and parameter extractions occur. Additionally, the BIG-IP ASM checks the dynamic parameters on the next request.

  • Dynamic flows, dynamic sessions in the URL, and dynamic parameter names are configured:

    When dynamic flows, dynamic sessions in the URL, and dynamic parameter names are configured, the system can extract the dynamic session information from the server response. When the response arrives compressed, BIG-IP ASM decompresses a copy of the content and analyzes the content according to the security policy.

  • The Data Guard feature is enabled for the security policy.

  • The CSRF protection feature is enabled for the security policy.
