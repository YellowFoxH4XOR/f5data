Topic

Domestic versions of BIG-IP and 3-DNS do not have the Telnet daemon (telnetd) enabled by default. The following procedure describes how to configure the Telnet port and start Telnet.

Important: Telnet is not as secure as SSH, so it is best to disable the Telnet port as soon as it is no longer needed. Once configured, you can open and close the Telnet port without rebooting by using the following command:

sysctl -w bigip.open_telnet_port=1

Enabling Telnet

To enable Telnet after you have run the First Time Boot/Setup utility, perform the following procedure:

  1. From the command line, type the following command to initiate the config script:

    config

    This script modifies the /etc/inetd.conf and /etc/hosts.allow files as required to run telnetd.

  2. From the config script options, select Configure Telnetd
  3. Follow the prompts to specify a list of hosts or networks that can access BIG-IP through Telnet, or you can leave it open to all (default).

    Once you have finished configuring Telnet, you will return to the config menu.

  4. From the config menu, select Quit.
  5. From the command line, type the following command to initiate the inetd process:

    bigstart restart inetd

Verifying the status of Telnet

You can verify that telnetd is running by viewing the following files:

  • /etc/inetd.conf
  • /etc/hosts.allow

When telnetd is running, the /etc/inetd.conf file will contain a line similar to the following example:

telnet stream tcp nowait root /usr/libexec/tcpd telnetd -h

When telnetd is not running, the same line will still appear, but will be commented out.

When telnetd is running, the /etc/hosts.allow file will display as follows, where <ip address> is the administrative address that you entered when configuring telnetd:

telnetd : <ip address>

If you configured an administrative IP address of *.*.*.*, the /etc/hosts.allow file will display as follows:

telnetd : ALL
