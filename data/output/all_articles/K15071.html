Known Issue

You may be unable to access content when you use Kerberos authentication with the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access policy is configured for Kerberos request-based authentication.
  • The Single Sign-On (SSO) configuration uses the Send Authorization On 401 Status Code Kerberos authentication method.
  • The BIG-IP APM system is running 11.4.1 HF1.

Impact

Users are unable to access content that requires Kerberos authentication.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H449167 on the Diagnostics > Identified > Medium screen.
  • Webpages that require Kerberos authentication appear to stop responding.
  • The apmd process may produce a core file in the /shared/core/directory:

    For example:

    /shared/core/apmd.bld625.0.core.gz

  • The following log messages may appear in the /var/log/apm file:

    notice apmd[6914]: 01490000:5: ** SIGABRT **
    notice apmd[6914]: 01490000:5: fault code: 0xfffffffa
    notice apmd[6914]: 01490000:5: stack trace:
    notice apmd[6914]: 01490000:5: [0x55572430]
