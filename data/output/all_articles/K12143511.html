Description

When trying to do a configuration sync between two members in the HA pair configuration, you receive a similar error to the one below: 

Sync Failed
A validation error occurred while syncing to a remote device.

Sync error on <device> Load failed from <device> Caught configuration exception (0), failed in syscall link(/config/filestore/files_d/Common_d/certificate_key_d/:Common<key_name>, /config/filestore/.trash_bin_d/.current_d/Common_d/certificate_key_d/:Common<key_name> errno=(No such file or directory)

Environment

- BIG-IP
- HA configuration

Cause

Missing configuration object

Recommended Actions

1. Login to ssh on standby unit and go to directory below and verify if the file listed in the error message exists there:

cd /config/filestore/files_d/Common_d/certificate_key_d

2. If the file doesn't exist then create it. For example, asuming the error message refers to a file name "Common:portal.mydomain.key_34534_2" , the command will be:
touch :Common:portal.mydomain.key_34534_2

3. Try to sync from active unit to standby with overwriting option

Additional Information

 

If recommended actions don't fix the issue then you coud try an mcpd reload
K13030: Forcing the mcpd process to reload the BIG-IP configuration
