Description

You may find that BIG-IP doesn't send any ICMP error packets when BIG-IP logs the error below in /var/log/ltm:

warning tmm[XXXX]: 01200015:4: Warning, ICMP error limit reached.

Environment

  • BIG-IP system receives a lot of multicast packets.
  • Run tcpdump while the warning is logged.
  • Confirm that the tcpdump doesn't contain any ICMP errors.

Cause

This is expected behavior. BIG-IP does not send any ICMP errors for UDP multicast because of RFC1812; however, BIG-IP increments the tm.maxicmprate counter which will trigger the Warning, ICMP error limit reached log message.

Recommended Actions

The fix for ID859717 implements the ICMP error counters. You can run the tmctl icmp_stat command and review the drop_mcast counter.
The drop_mcast definition: ICMP4 error packet was not sent, multicast destination (RFC1812-Section4.3.2.7)

Run the following command:
tmctl icmp_stat

For example:
[bigip1:Active:Standalone] config # tmctl icmp_stat
