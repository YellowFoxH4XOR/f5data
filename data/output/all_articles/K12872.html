Known Issue

Description

The show firmware upgrade verbose command displays a status of Upgrade available when a lower firmware version is available. The system should indicate a status of Downgrade available.

This issue occurs when the following condition is met:

  • The most recent firmware version available for the upgrade (Current) is lower than the firmware version that the system is currently running (Running).

Note: This condition may occur if you boot the ARX system to an older version of the software after having previously upgraded the firmware using a newer ARX version. It is also possible if an RMA unit has been received with a newer firmware installed by the manufacturer.

Impact

None. The status is cosmetic and you may safely ignore this issue.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The show firmware upgrade verbose command displays a status of Upgrade available when the most recent firmware version available for the software (Current) is actually lower than the firmware version that the system is currently running (Running).

For example, if you upgraded the firmware while the ARX was running version 5.0.5, and then you booted the ARX to version 4.1.0, the show firmware upgrade verbose command would indicate a status of Upgrade available that appears similar to the following example:

Show Firmware Update Verbose
----------------------------
Slot  Firmware     Running         Current         Status
--------------------------------------------------------------------
2    NSM Diag      5.00.005.11734  4.01.000.11270  Upgrade available
2    NSM BootLdr   5.00.005.11734  4.01.000.11270  Upgrade available
2    Uturn         49              49              Up to date
2    Merge         65              65              Up to date
