Description

When a network adapter / interface is added to or removed from a BIG-IP Next VE, the change is not immediately reflected by Next or Central Manager.

 

Environment

  • BIG-IP Next VE
  • Add or remove a network adapter. For example:
    1. Add a network adapter to the BIG-IP Next VE:
    2. The Linux host will see the interface connect (check dmesg).
    3. TMM does not register the new NIC (tmsh show net interface).

Cause

TMM does not support hot-plug network interfaces.

 

Recommended Actions

Shut down the Next instance before adding, removing or changing the network adapters attached to the VE.

 

Additional Information

You can plug any SFP or pluggable into an F5OS Appliance and the interface will work immediately. That's because TMM already knows of the existence of that interface and "show net interface" will show you the interface regardless of whether anything is plugged in. In that case, TMM is ready to work with any supported pluggable that is inserted.
