Issue

Error Message

err mcpd[<PID>]: 01070687:3: Link Aggregation Control Protocol (LACP) is not supported on this platform.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process

For example:

err mcpd[4827]: 01070687:3: Link Aggregation Control Protocol (LACP) is not supported on this platform.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The BIG-IP command line interface

Description

This message occurs when all of the following conditions are met:

  • You create a user configuration set (UCS) archive on a BIG-IP hardware platform with LACP enabled trunks.
  • You then load the UCS archive on BIG-IP Virtual Edition (VE), Virtual Clustered Multiprocessing (vCMP) guest, or a F5OS tenant.

For example, the message is generated when you load the UCS archive using the following command:

tmsh load /sys ucs platform-migrate

Impact

The configuration fails to load.

Recommended Actions

To work around this issue, remove any trunks from your configuration before creating the UCS archive on the hardware platform.
