Topic

You should consider using this procedure under the following condition:

  • You want to display the F5 iWorkflow software version information.

Description

To display the iWorkflow software version, you can use the Traffic Management Shell (tmsh) or the iWorkflow user interface.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You can access the iWorkflow system using the tmsh utility.
  • You have a valid user account to access the iWorkflow user interface.

Procedures

To display the iWorkflow software version, perform one of the following procedures:

Using the tmsh utility

To display the iWorkflow software version using the tmsh utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Display the iWorkflow software version by typing the following command:

    show /sys version

Using the iWorkflow user interface

To display the iWorkflow software version using the iWorkflow user interface, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the iWorkflow system.
  2. In the upper-right corner of the screen, move your pointer over the host name of the iWorkflow system, and the iWorkflow software version will display.

    The version may appear similar to the following example:

    iWorkflow 2.0.0.0.0.9631

    In this example, the iWorkflow system is running 2.0.0 and the build number is 0.0.9631.
