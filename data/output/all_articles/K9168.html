Known Issue

This is the result of a known issue. The following error message may be reported in the /shared/log/ts/bd.log file:

IO_PLUGIN|NOTICE|<date> <time>|20071|io_plugin.c:2632|NON RFC: Header name with no value  found CRLF/LF before colon.
    UMU|ERR   |<date> <time>|20071|Pool.cpp:169|UMU 88B58C0 free damaged F19FB430 - ignore
 BD_SSL|ERR   |<date> <time>|20071|io_plugin.c:2081|Failed to free buffer
    UMU|ERR   |<date> <time>|20073|Pool.cpp:169|UMU 88B58C0 free damaged F1A10610 - ignore
 BD_SSL|ERR   |<date> <time>|20073|io_plugin.c:2081|Failed to free buffer
IO_PLUGIN|NOTICE|<date> <time>|20071|io_plugin.c:2632|NON RFC: Header name with no value  found CRLF/LF before colon.

The error message occurs when the BIG-IP ASM writes an ASM cookie that is larger than the UMU memory buffer used by the Policy Enforcer. When the cookie is read from the buffer, the error messages are generated because the information being read is larger than the defined buffer size.

The error messages are benign and can be safely ignored. The BIG-IP ASM system uses another system defined variable that specifies the maximum cookie length to verify the information read when the cookie is parsed. Therefore, the contents of the cookie are not corrupted and are read correctly.

F5 Product Development tracked this issue as CR99723 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.

This issue was fixed in Hotfix-BIG-IP-9.4.4-94.0-HF3, issued for BIG-IP 9.4.4, and in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP 9.4.5. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
