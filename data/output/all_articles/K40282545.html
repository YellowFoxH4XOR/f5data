Description

When creating a local account with administrator rights (other than 'admin' or 'root') and setting local password we are not able to login with those credentials when remote authentication is configured.
When we try to log in to this local account the Load Balancer sends a query to remote authentication server and does not check the local user database.

Environment

  • Remote Authentication Configured
  • Additional Local admin users configured different than admin

Cause

Work as designed

Recommended Actions

When you configure remote authentication, the system authenticates users against the remote server only and not locally for security reasons. Consider the following to use local accounts:
  • Login using the admin and root accounts
  • Do not configure remote authentication. Use local authentication.
  • You can also configure the system to use local authentication when the remote server is not available. For more information, refer to 
    • K49218438: Configuring local authentication as a backup method for remote authentication (13.x - 16.x)
    • K65475221: The BIG-IP system allows using local authentication as a backup method

Additional Information
The only option is to modify primary Admin user but it will lock Admin user for local authentication
K15632: Disabling the admin and root accounts using the Configuration utility or tmsh
K14943: Removing the default BIG-IP administrative user
