Description

The Istio Proxy sidecar container is a container injected into every POD in the Istio service mesh. The istio-proxy proxies all incoming and outgoing traffic to the POD. The proxy container used by Istio is built at the top of the Envoy proxy. Istio pulls and merges the source code from the Envoy upstream GitHub repository before building the istio-proxy containers. The source code used to build the istio-proxy is kept in the proxy repository on GitHub:

In this article we will document which Envoy branch and version was used by different Istio versions.

The Envoy release notes can be found here.
