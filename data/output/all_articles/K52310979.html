Description

Need to enable vulnerability assessment tool in ASM.

  • Is there any additional integration required when enabling this feature?
  • What advantage will we get when we enable this feature?

Environment

The ASM Vulnerability Assessments tool allows you to import scan results from supported vulnerability scanners (such as HP WebInspect, IBM AppScan, Qualys, Quotium Seeker, Trustwave App Scanner, and WhiteHat Sentinel) or from a generic scanner in XML format. The tool then suggests updates to your security policy to mitigate the discovered vulnerabilities.

How it works:

  • You run a vulnerability scan on your web application using a supported scanner.
  • Export the scan results in XML format.
  • Import the results into ASM using the "Vulnerability Assessment Baseline" policy template or integrate with an existing policy.
  • ASM suggests policy changes to address the vulnerabilities. You can review, accept, or reject these changes.
  • You can retest to confirm the vulnerabilities are mitigated, then enforce the updated policy.

Recommended Actions

To use vulnerability assessment tools with a security policy, it's recommended to start with a new security policy, using the Vulnerability Assessment Baseline policy template. The reason a new policy should be used is because it disables unrelated security features, focusing the policy on mitigating the vulnerabilities found by the scanner. 

Run the scan against the application, then import the results into the security policy, review and resolve the vulnerabilities.

For best results, use one of the scanners that are officially supported, such as:

  • Trustwave App Scanner
  • HP WebInspect
  • IBM AppScan
  • ImmuniWeb
  • Qualys
  • Quotium Seeker
  • WhiteHat Sentinel (European and US server)

You can also implement generic scanner output, which should be an XML file that confirms to the BIG-IP's generic_scanner.xsd schema file.

Additional Information

There are no special security protections enabled by building a policy using vulnerability assessment tool output. The main benefit is that it's easier to build your security policy around those specific targeted vulnerabilities that the scanner might detect, as opposed to using other methods like the learning system.
