Description

The tmsh show cm failover-status command shows failover connection status "Error", but manual failover functions as expected.

tmsh show cm failover

--------------------
CM::Failover Status
--------------------
Color    gray
Status   STANDBY
Summary  1/1 standby
Details

-----------------------------------------------------------------------------------------------------
CM::Failover Connections
Local Failover Address  Remote Device          Packets  Transitions  Received Last Packet  Status
-----------------------------------------------------------------------------------------------------
192.168.0.111:1026      bigip1.example.com       0           1       -                     Error
172.16.0.100:1026       bigip1.example.com       1478588     5       2021-Jan-29 07:49:54  Ok 
 

Environment

  • BIG-IP
  • HA
  • The management IP is changed on one of the devices
     

Cause

ID901669
 

Recommended Actions

The workaround in ID901669 will cause a failover when run on the Active unit. Please run the command in a maintenance window after making status Offline  or Standby.
 

Additional Information

There is another known issue with the same error and symptom, please refer to K55406801: HA failover connection for management IP does not work on cVMP quests on VIPRION
