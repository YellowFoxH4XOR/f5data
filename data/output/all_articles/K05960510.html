Topic

The BIG-IP Edge Client's system tray uses various icons to display the status of connections.

Description

System Tray IconConnection Status
Grey circle
 		Disconnected
Grey circle with red animation
 		Attempting to connect
Red circle
 		Connected
Grey circle with yellow exclamation mark
 		Login is pending additional user input
Grey circle with white letter x
 		A connection attempt has failed due to error. The icon should change when the client attempts to reconnect

Note: The system tray icons are based on the default icon set.
