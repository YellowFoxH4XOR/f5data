K7704: Performing an FTP backup creates a full backup file even if partial backup is selected

Known Issue

This is the result of a known issue. You can configure and perform backups on the Device Management : Maintenance : Backup/Restore page in the FirePass Administrative Console. When you configure a nightly FTP backup and click the Backup Now button, a full backup will be uploaded to the FTP server even if the Partial backup check box is selected.

Note: This issue only occurs with the Backup Now option. Nightly backups will correctly upload a partial backup file when the Partial backup check box is selected.

F5 Networks Product Development tracked this issue as CR81552 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.
