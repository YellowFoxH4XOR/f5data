Known Issue

The multicast interface entry is not properly saved when you configure the Failover Multicast setting.

This issue occurs when the following condition is met:

  • You use the Configuration utility to define the Failover Multicast configuration.

The Failover Multicast configuration specifies the interface, IP address, and port that you want to use for failover communication between BIG-IP device group members. The setting is available in the Configuration utility by navigating to Device Management > Devices > <device_name> > Device Connectivity > Failover. The BIG-IP system does not save the interface entry to the bigip_base.conf file.

Impact

Failover functionality may not work as expected between device group members.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H407958 on the Diagnostics > Identified > High screen.
  • The Use Failover Multicast Address setting appears to be enabled when viewed from the Configuration utility.
  • The bigip_base.conf file contains the multicast IP address and port, however the multicast interface entry is missing.

    For example, the bigip_base.conf file contains entries that appear similar to the following example:

    multicast-ip 224.0.0.245
    multicast-port 62960

    The following entry is missing:

    multicast-interface eth0

  • Failover functionality may not work as expected between device group members.

Workaround

To work around this issue, you can define the multicast interface using the tmsh shell. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh shell by entering the following command:

    tmsh

  2. To define the multicast interface, use the following command syntax:

    modify /cm <device> multicast-interface <interface>

    For example, to define the mgmt interface as the multicast failover interface, you would enter the following command:

    modify /cm device bigip.local.net multicast-interface eth0

  3. Save the configuration by entering the following command:

    save /sys config
