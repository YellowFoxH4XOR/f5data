Description

When trying to activate or reactivate a license on BIG-IP, the below error is encountered:
Error Message: 51085: Invalid Base Registration Key - No Base Registration Key in the Dossier

Environment

  • License activation
  • License reactivation

Cause

  • A valid Base Registration Key is missing in the dossier. The dossier contains naught but Add-On keys.

Recommended Actions

  • Make sure the Base Registration Key is correct when trying to license the BIG-IP device.

Additional Information

  • A Base Registration Key for BIG-IP is a pattern of: ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG (5-5-5-5-7)
  • An add-on registration key for BIG-IP is a pattern of: ABCDEFG-ABCDEFG (7-7)
