Topic

This article applies to BIG-IP ASM 10.x through 11.x. For information about other versions, refer to the following articles:

  • K34154012: Configuring Data Guard exception patterns (12.x - 13.x)
  • K12890: Configuring Data Guard exception patterns (9.4.x)

Data Guard custom and exception patterns are Perl-Compatible Regular Expression (PCRE) patterns that you can configure. A custom pattern is designed to match a string of sensitive data sent by the web server and mask the data before returning it to the client. An exception pattern is designed to match a sub-string of the data string to be masked, and if found, mark the entire data string as nonsensitive, and return the data unmasked to the client.

For example, after the BIG-IP ASM system finds response data matching a custom pattern, the system prepares the data to be masked. The BIG-IP ASM system then applies the exception pattern (if defined) to the matched data, and if an exception match is found, the BIG-IP ASM system sends the entire unmasked data string to the client. Example: United States Social Security numbers

To create a custom pattern that would instruct Data Guard to match Social Security numbers returned by the web server and then mask the data before sending it to the client, you could add the following PCRE expression in the Custom Pattern field:

[\d][\d][\d]-[\d][\d]-[\d][\d][\d][\d]

If you want Data Guard to return Social Security numbers containing a middle number of 52 to the client in its entirety, you can add the following PCRE expression in the Exception Pattern field:

[\d][\d][\d]-[5][2]-[\d][\d][\d][\d]

Note: For more information about regular expressions and Data Guard, refer to K8322: The BIG-IP ASM Data Guard feature supports using Perl Compatible Regular Expressions.

Configuring Data Guard exceptions

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Locate the Data Guard utility by performing either of the following tasks:
    • In BIG-IP 11.4.0 through 11.6.x, navigate to Security > Application Security > Data Guard.
    • In BIG-IP 10.x through 11.3.0, from the Application Security Main tab, click Data Guard.
  3. Click the Enable Custom Patterns box and enter a PCRE expression in the New Pattern box.
  4. Click Add.
  5. To add an exception to the custom pattern, click the Enable Exception Patterns box and enter a PCRE expression in the New Pattern box.
  6. Click Add.
  7. Click Save.
