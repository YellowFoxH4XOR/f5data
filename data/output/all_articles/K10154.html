Known Issue

This is the result of a known issue. If the Portal Access Web Applications Show administrator-defined favorites only option is enabled for a user’s master group, ActiveSync connections fail.

F5 Product Development tracked this issue as CR117737 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative HF-603-3 for FirePass version 6.0.3 and in cumulative HF-602-11 for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by disabling the Show administrator-defined favorites only option. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Portal Access > Web Applications > Master Group Settings page.
  3. In the Master Group menu, select the name of the master group you want to configure.
  4. Clear the Show administrator-defined favorites only check box.
