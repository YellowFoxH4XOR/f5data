K000133229: F5OS MGMT interface and Tenant Self IP

Type
Support Solution
Published
2023-03-28
Updated
2023-04-12
Source
https://my.f5.com/manage/s/article/K000133229

Description

  • For BIG-IP devices, the system does not allow to configure MGMT interface and Self IP in the same subnet.
  • For F5OS, the system allows customer to configure the MGMT interface of F5OS in the same subnet as Tenant Self IP.

Environment

  • F5OS with BIG-IP Tenants

Cause

MGMT interface of F5OS in the same subnet as Tenant Self IP is a supported configuration.


Recommended Actions

  1. From best practice perspective, F5 suggested to isolate control plane interface and data plane interface. 
  2. If MGMT interface of F5OS has to be configured in the same subnet as Tenant Self IP, F5 suggested:
    1. Configure allow Source IP to access F5OS MGMT interface;
    2. Configure ACL rules must be in place on switch to restrict access to MGMT interface.
