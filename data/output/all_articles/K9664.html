Topic

The Script Debugging feature was introduced in FirePass version 6.0.3. F5 Technical Support may ask you to use this feature by sending you a script that you will be required to run. Save the script in a location that you can browse to while connected to your FirePass device. To use the Script Debugging feature, perform the following procedure:

  1. Log in to your FirePass device as an administrator.
  2. Go to Device Management: Maintenance: Troubleshooting Tools.
  3. Locate the Script Debugging section.
  4. Click Browse.
  5. Select the script sent to you by F5 Technical Support.
  6. Click Upload.
  7. Click Start to run the script.

    The script takes approximately five minutes to run.

    Note: The timer on the FirePass GUI may not accurately reflect the run time. After five minutes, refresh the screen. A Script Stopped message should display.
  8. Click the Download link next to the Script Stopped message.

    Note: At this time, the file size will state 0 KB, regardless of the actual file size.
  9. Once the file has downloaded, you may delete the script by clicking the Delete button.
