K000152842: APM Suddenly stop working all VPN user unable to connect

Type
Support Solution
Published
2026-08-27
Updated
2026-08-27
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000152842

Description

Customer having issues with connecting to VPN

 

Environment

BIG-IP APM

Edge Client

 

Cause

There was a static pool assigned which had a non functional server present (marked down), which was being assigned during the resource assignment.

 

This appeared to be the 'Illegal Argument' portion of this error: [F5RST: Access encountered an error (Illegal argument)]

 

Recommended Actions

Ensure all assigned resources are valid

 

Additional Information
