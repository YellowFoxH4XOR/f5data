Important notes

These are unified recommendations for Control Plane memory provisioning relative to BIG-IP LTM object counts.

  • Object counting method: Objects are counted as defined in K35004520: How to determine the number of LTM objects currently present on your BIG-IP system.
  • Heavy AS3/DO/TS usage: If you expect high Automation Tooling load, refer to K00505373: Automation Toolchain restjavad extra memory allocation guidance.
  • Multiple modules provisioned: For systems running multiple BIG-IP modules, refer to K26427018: Overview of Management provisioning.
  • Impact of provision.extramb: Adding provision.extramb increases Control Plane memory by taking it from Traffic Management Microkernel (TMM) reserved memory, which can reduce data-plane headroom and potentially affect TMM performance.
  • TMM performance: TMM impact depends on actual data-plane load and traffic profile. For more information, refer to K05003715: Is there a virtual server limit for BIG-IP appliances?
  • Service disruption: Changing provision.extramb restarts TMM, which will impact data traffic.
  • Manual restarts required:
    • Changing provision.restjavad.extramb requires a manual restart of restjavad.
    • Changing provision.tomcat.extramb requires a manual restart of tomcat.
  • SWAP sizing: For systems with more than 8 GB RAM, adjust SWAP to at least 1/8 of total RAM. For more information, refer to K30219717: Modify swap memory volume capacity.

  • provision.restjavad.extramb max alvalue = 8192

Example: Check and apply extramb values

The following example shows how to view the current provision.extramb database variables, update them to new values, and restart the relevant services so the changes take effect.

tmsh list sys db provision.extramb
tmsh modify sys db provision.extramb value 200
tmsh list sys db provision.restjavad.extramb
tmsh modify sys db provision.restjavad.extramb value 448
tmsh restart sys service restjavad
tmsh list sys db provision.tomcat.extramb
tmsh modify sys db provision.tomcat.extramb value 64
tmsh restart sys service tomcat
