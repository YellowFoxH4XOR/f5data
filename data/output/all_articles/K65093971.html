Description

When trying to load bigip_gtm.conf, encountered the error: 'Syntax Error:(/config/bigip_gtm.conf at line: ###) the "create" command does not accept wildcard configuration identifiers'

Environment

  • BIG-IP DNS
  • You have a GTM pool member, which has a wildcard patterns/character on it's name

Cause

Backslash (\) escape character is not automatically prepended to the wildcard character by the system when the configuration is saved.

Recommended Actions

To work around this issue, you can edit the /config/bigip_gtm.conf file and escape any wildcard pattern within any GTM pool member's name. To do so, perform the following procedure:

Impact of workaround: This workaround is a temporary fix that enables the configuration to load. The issue will persist on the next config reload.

  1. Log in to the command line.
     
  2. Create a backup of the bigip_gtm.conf file, by running the following command:

    # cp /config/bigip_gtm.conf /config/bigip_gtm.conf.backup
     
  3. Edit the bigip_gtm.conf file and escape any wildcard pattern within any GTM pool member's name with the backslash (\) character.

    For example this is the current config:

    gtm pool a test-\*.domain.com_pool {
    members {
            Generic:test-*.domain.com_member {
            member-order 0
            }
        }
    }

    When finished, the pool member name in the configuration file should appear similar to the following example:

    gtm pool a test-\*.domain.com_pool {
    members {
            Generic:test-\*.domain.com_member {
            member-order 0
            }
        }
    }
     
  4. Save the changes to the file.
     
  5. Reload the configuration using the following command:

    # tmsh load sys config gtm-only
