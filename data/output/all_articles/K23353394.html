Known Issue

The Traffic Management Microkernel (TMM) logs an incorrect error message when an invalid regex pattern is specified in BIG-IP LTM profiles.

This issue occurs when the following condition is met:

  • You configure an invalid glob or regular expression within a BIG-IP LTM profile using Traffic Management Shell (tmsh) commands.

Impact

None

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you use the tmsh utility to create or edit BIG-IP LTM profiles that have an invalid glob or regular expression, you observe an error message that appears similar to the following example in the /var/log/ltm log file:

    Invalid command name....

  • The tmsh command line interface logs the correct message that appears similar to the following example:

    Profile XYZ error - couldn't compile regular expression....
