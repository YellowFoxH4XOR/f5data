Known Issue

The Traffic Management Microkernel (TMM) may result in an out-of-memory state on a Client SSL-related connection.

This issue occurs when all of the following conditions are met:

  • The configuration contains a virtual server that uses the Client SSL profile.
  • The affected SSL session has one of the following conditions:

    • The virtual server has an iRule that corrupts the FINISHED record.
    • The connected client resumes the SSL session with slow or no reading of ingress post-handshakes.

Impact

The BIG-IP system may temporarily fail to process traffic while TMM restarts. If the BIG-IP system is a member of a redundant configuration, traffic fails over to the standby BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H508758 on the Diagnostics > Identified > High screen.
  • The BIG-IP system temporarily fails to process traffic.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • You may observe large memory usage in the xfrag and xdata counters when using the tmctl command.

    For example:

    tmctl -w132 memory_usage_stat | egrep '(xfrag|xdata)'
