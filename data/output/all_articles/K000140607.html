Description

ZoneRunner daemon(zrd) may repeat restart, because of some configuration issue in /var/named/config/named.conf configuration file. In this case, you need to edit the configuration file manually to correct the configuration issue, however, the manual changes made to the configuration file is not synchronized.

Environment

  • BIG-IP DNS
  • ZoneRunner daemon(zrd) repeats restart due to named.conf configuration issue
  • Synchronize DNS Zone Files is enabled

Cause

Manual changes made to /var/named/config/named.conf is not detected while ZoneRunner daemon(zrd) repeats restarting due to some configuration issue in the named.conf.

For example, zone file referred from the /var/named/config/named.conf does not exit.

/var/named/config/named.conf defines the zone following

...
    zone "f5.com.com." {
        type master;
        file "db.external.f5.com.com.";
        allow-update {
            localhost;
        };
    };
...

The file "db.external.f5.com.com." does not exist following.

# named-checkzone f5.com.com. /var/named/config/namedb/db.external.f5.com.com.

zone f5.com.com/IN: loading from master file /var/named/config/namedb/db.external.f5.com.com. failed: file not found
zone f5.com.com/IN: not loaded due to errors.

Recommended Actions

Correct the configuration issue in the /var/named/config/named.conf in all BIG-IP DNS systems in DNS synchronization group.

For example, remove the zone definition in the named.conf that refers to the zone file which does not exist.

If you want to make sure to synchronize the named.conf from a BIG-IP DNS system in DNS synchronization group, update the named.conf on the BIG-IP DNS system without any change.

To initialte the synchronization process,

Impact of procedure: The following procedure replaces the configuration of the remote BIG-IP DNS systems in the DNS synchronization group, with the configuration of the BIG-IP DNS system on which it is run.

Use the Configuration utility to initiate the the synchronization process

  1. Log in to the Configuration utility.
  2. Go to DNS>Zones:ZoneRunner>named Configration
  3. Press Update

Use the command line utility to initiate the the synchronization process

  1. Log in to the command line of the BIG-IP DNS system
  2. Run the following command:
    # touch /var/named/config/named.conf
