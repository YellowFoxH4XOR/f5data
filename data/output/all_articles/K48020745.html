Known Issue

Using iControl representational state transfer (REST) application programing interface (API) commands to view, modify, or delete topology objects may fail.

This issue occurs when the following condition is met:

  • The iControl REST command uses the selfLink property.

Impact

Administrators cannot remotely manage BIG-IP DNS topology records by using the iControl REST API.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the iControl REST API to view, modify, or delete a topology objects, commands using the selfLink property fail with an error message similar to the following example:

    {
    "code": 400,
    "errorStack": [],
    "message": "Topologies must specify both regions: ldns: server:"
    }

Workaround

To work around this issue, you can create topology records by using the Configuration utility or Traffic Management Shell (tmsh).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
