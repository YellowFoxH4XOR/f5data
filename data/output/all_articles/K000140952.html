K000140952: Unable to activate service Web Application Security listener from BIG-IQ CM GUI

Type
Support Solution
Published
2024-09-27
Updated
2024-09-27
Source
https://my.f5.com/manage/s/article/K000140952

Description

Unable to activate service Web Application Security listener port 8514 from BIG-IQ BIG-IQ Centralized Management for BIG-IQ Data Collection Device.

Following error are noted  in GUI of BIG-IQ Centralized Management 

 

Error: Failed to get the list of indices from es health worker - Unable to get Logging Configuration currently, if the process is currently restarting this is expected and this message can be ignored.

 

Following errors are noted in the restjavad.0.log



Unable to get elasticsearch node metrics. java.lang.NumberFormatException: Expected an int but was 7997314568 at line 1 column 14510 path $.nodes..thread_pool.search.completed

 

Environment

  • BIG-IQ Centralized Management  configured with BIG-IQ Data Collection Device 
  • BIG-IP WAF event log is not appeared in BIG-IQ Centralized Management. So tried to activate and reactivate service listener port 8514.
  • Above error is encountered when reactivating Web Application Security service 

Cause

Elastic search(ES) cluster status is unstable 

Recommended Actions

  1. Delete the affected BIG-IQ Data Collection Device and add back the BIG-IQ Data Collection Device  in BIG-IQ Centralized Management 
  2. Activate the service Web Application Security service listener 8514 in the BIG-IQ Centralized Management  in GUI

None
