Topic

You should consider using this procedure under the following condition:

  • You want to configure the BIG-IP system to distribute uncommon IP protocol traffic across available Traffic Management Microkernels (TMM).

Description

By default, the BIG-IP system forwards uncommon IP protocol traffic to a single TMM for processing. However, beginning in BIG-IP 13.1.0 and 12.1.3, F5 introduced the ipproto.lookupip and ah.lookupip database variables. These variables allow the default Disaggregation (DAG) mode to distribute uncommon IP protocol traffic based on source and destination IP address, across available TMMs.

The following table provides a description of these database variables.

Database variableDefinitionDefault setting
ipproto.lookupipWhen enabled, allows default DAG to disaggregate traffic of uncommon IP protocols based on source and destination IP address except for TCP, UDP, SCTP, IGMP, AH, ESP, GRE, ICMP, and ICMPv6.  Possible values are enable and disable.Disabled
ah.lookupipWhen enabled, allows default DAG to disaggregate Authentication Header (AH) protocol traffic based on source and destination IP address. Possible values are enable and disable.Disabled

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Have administrative access to the TMOS Shell (tmsh).

Procedures

Changing the default database variables

Impact of procedure: F5 recommends that you test any such changes during a maintenance window, and consider the possible impact on your specific environment.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Optionally, you can view the currently configured DB value using the following command syntax:

    list /sys db <db key name> all-properties

    For example, to list the default DB setting for the ipproto.lookupip variable, type the following command:

    list /sys db ipproto.lookupip all-properties

    The command output appears similar to the following example:

    sys db ipproto.lookupip {
        default-value "disable"
        scf-config "true"
        value "disable"
        value-range "disable enable"
    }

  3. To enable the database variables you want, use the following command syntax:

    modify /sys db <db key name> value <enable|disable>

    For example, to enable the ipproto.lookupip variable, type the following command:

    modify /sys db ipproto.lookupip value enable
