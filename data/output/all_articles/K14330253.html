K14330253: BIG-IQ with 1 NIC, GUI not available after upgrade.

Description

After an upgrade to version 8 in a BIG-IQ device that only has one interface, you might notice that the Configuration Utility (GUI) is not available

Environment

  • BIG-IQ
  • Configuration Utility (GUI)
  • 1 NIC

Cause

BIG-IQ VE support for 1 NIC deployment is only available starting version 8.0.0, previous versions should have at least 2 interfaces
Upgrading to version 8 using a BIG-IQ VE using only one interface can trigger bug ID1010525 which will cause network issues after the upgrade

Recommended Actions

  1. Configure an additional NIC to the BIG-IQ VE virtual machine prior to the upgrade, this will avoid having network issues after the upgrade.
  2. If you have already upgraded, roll back to the previous version and configure an additional NIC to the BIG-.IQ.
