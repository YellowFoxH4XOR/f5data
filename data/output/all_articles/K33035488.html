Known Issue

The BIG-IP system may fail to synchronize iApps LX applications to other devices in the same device group. This issue occurs when one of the following conditions is met:

  • You have upgraded the affected BIG-IP system from BIG-IP 12.1.1 to a later version listed in the Applies to (see versions) box in the upper right corner of this article (including the hotfixes in the BIG-IP 12.1.1 branch, for example BIG-IP 12.1.1 HF1).
  • You have restored a user configuration set (UCS) archive taken from BIG-IP 12.1.1 onto a BIG-IP system running BIG-IP 12.1.1 HF1 and later, for the BIG-IP 12.1.1 branch, as well as for the versions listed in the Applies to (see versions) box.

Impact

After an upgrade, the iApps LX applications restored or modified will not synchronize to other devices in the device group. As a result, traffic processed by the affected iApps LX applications is impacted when a failover occurs.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that the iApps LX applications are not synchronized to the other devices in the device group.
  • You observe that a log entry similar to the following example is logged to the /var/log/restjavad.0.log file approximately once every hour:

    [8100/tm/shared/bigip-failover-state BigipFailoverStateWorker] Failed to discover [address]: java.lang.IllegalStateException: Authentication Failure to host [address]. Please check the credentials provided.

Resolution
