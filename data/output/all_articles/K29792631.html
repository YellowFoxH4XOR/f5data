Description

  • Events and logs for one access policy is not sent to remote server
Environment
  • APM
Cause
  • Associated event log was not recording/logging  details of users activity as it should  
  • APMD was not logging event associated with access policy 

Recommended Actions

  • create an new event log following article K24826763
    • K24826763: Configuring the BIG-IP APM Logging Levels (12.x and newer)
  •  and replace existing one
    1. Go to Access > Profiles / Policies > Access Profiles (Per-Session Policies) > <name of access policy>
    2. Click Logs tab
    3. Move existing Log profile to Available
    4. Move new Log profile to Selected
    5. Click Update
