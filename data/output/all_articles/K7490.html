K7490: An HTTP 0.9 response from a server that does not contain HTTP headers can cause the HTTP profile parser to stall

Known Issue

This is the result of a known issue. If a proxy device or server responds to an HTTP request with an HTTP 0.9 response and without HTTP headers, the HTTP profile parser will search for HTTP header information. As a result, the HTTP profile parser stalls and the BIG-IP LTM system sends a reset to the client because the connection times out.

Note: This issue occurs on the BIG-IP LTM system only when the virtual server is configured with an HTTP profile and the server or proxy device sends an HTTP 0.9 response without HTTP headers.

F5 Product Development tracked this issue as CR77679 and it was fixed in BIG-IP LTM 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
