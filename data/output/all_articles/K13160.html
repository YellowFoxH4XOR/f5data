Topic

You should consider using this procedure under the following condition:

  • You require more timely updates to remote syslog-ng servers.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have configured your BIG-IP system to use a remote syslog-ng server, as described in K13080: Configuring the BIG-IP system to log to a remote syslog server (11.x - 17.x).

Description

After configuring the BIG-IP system to use a remote syslog-ng server, a 60-second delay may occur between viewing the log message in the /var/log file and viewing the message at the remote syslog-ng server. The time_reopen option with a 0 (zero) value can be added to the syslog-ng configuration to eliminate this delay.

Note: When no value is specified in the syslog-ng configuration, the default time_reopen value is 60 seconds.

Procedures

Lower the update delay time by adding the appropriate time_reopen value to the syslog-ng configuration.

Impact of procedure: Lowering the time_reopen value may cause increased BIG-IP CPU usage. F5 recommends that you do not set the value below 10 seconds. F5 recommends experimenting and finding an appropriate value based on needs, current device conditions, and environment.

  1. Log in to the TMOS shell (tmsh) using the following command:

    tmsh

  2. Use the following command syntax to modify the time_reopen value:

    modify /sys syslog include "options {time_reopen(<seconds>);};"

    For example, to set the time_open value to 20 seconds, use the following command:

    modify /sys syslog include "options {time_reopen(20);};"

  3. Save the changes using the following command:

    save /sys config

  4. Restart syslog-ng using the following command:

    restart /sys service syslog-ng
