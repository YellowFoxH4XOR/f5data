Description

The following matrix lists third-party software that runs on the Linux host operating system on iWorkflow systems.

Important: F5 hotfix releases may include upgrades and security fixes for the following third-party software packages. As a result, when evaluating vulnerability status for third-party software, F5 recommends that you refer to Security Advisory articles to determine if an iWorkflow release is vulnerable.

Example 1: To find out the ZebOS version by using the rpm command, type the following command:

rpm -qa | grep -i zebos

The output from a iWorkflow system running 2.0.0 may appear similar to the following example:

ZebOS-7.10.4-0.0.9631

The numeric value after the first dash ( - ) indicates the ZebOS software version, which is 7.10.4.

Example 2: To find out the Java OpenJDK version, type the following command:

/usr/lib/jvm/jre/bin/java -Xmx2m -version

The output from a iWorkflow system running 2.0.0 may appear similar to the following example:

java version "1.7.0_75"
OpenJDK Runtime Environment (rhel-2.5.4.0.el5_11-x86_64 u75-b13)
OpenJDK 64-Bit Server VM (build 24.75-b04, mixed mode)

The Java OpenJDK version is 1.7.0_75, which refers to Java 7 update 75.
