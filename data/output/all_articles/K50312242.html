Description

On BIG-IQ, when modifying the Policy Building Mode:

Configuration tab -> Web Application Security -> Policies
Select policy -> Policy Building -> Settings
Modify the Policy Building Mode from "Local" to "Central"
Save & Close

The following pop message is displayed:

Number of Errors: 2

    1. You are not authorized
    Details:
    POST to /mgmt/cm/asm/tasks/update-devices-cpb is unauthorized.
    2. No error message.

Environment

  • BIG-IQ
  • Security Policy

Cause

ID1135785

Recommended Actions

The following workaround can be implemented to authorize access to the endpoint:
1. Create a Resource Group with problematic API.  On the BIG-IQ CLI execute the command:
    
restcurl -X POST /shared/authorization/patch-resource-groups -d '{"resourceGroupName":"Devices CPB Resource Group","resourceGroupDisplayName":"Devices CPB Resource Group" ,"resourceGroupDescription":"Resource group containing Devices CPB API for use with modifyPolicy","referenc eExpressionsPatches":[{"targetKind":"cm:asm:tasks:update-devices-cpb:updatedevicescentralizedconfigurationtaskstate" ,"referenceExpressions":[{"expression":"/cm/asm/tasks/update-devices-cpb/*"}]}]}'


2. Create a Custom Role Type with missing permission for problematic API. On the BIG-IQ CLI execute the command:
    
restcurl -X POST /shared/authorization/role-types -d  '{"name":"AddRoleTypeToUpdateCPBPermission","displayName":"AddRoleTypeToUpdateCPBPermission","isBuiltIn":false,"isPublic":true,"permissions":[{"itemKind":"cm:asm:tasks:update-devices-cpb:updatedevicescentralizedconfigurationtaskstate","actions":["read","edit","create","delete"]}]}'


3. Create a Custom Role using the above Role Type and Resource Groups in GUI
    Go to System >> Role management >> Roles >> Custom roles >> Service Roles
    Enter unique name in the Name field eg. CPB_custom_role
    Select the Role Type which is created in Step 2 (RoleType is 'AddRoleTypeToUpdateCPBPermission')
    Select the Resource Groups which is created in Step 1 (Resource Group is 'Devices CPB Resource Group')
    Select the User Group or local user that you want to have the ability of modifying the policy building mode.
    Click on Save&Close Button.

4. Test again.
