K79021421: After upgrade to 15.1.4, APM portal access to remote Big-IP fails

Type
Support Solution
Published
2022-03-28
Updated
2024-09-13
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.4
Source
https://my.f5.com/manage/s/article/K79021421

Description

APM utilizes a portal access via a webtop to manage remote BIG-IPs. After upgrading a remote BIG-IP from 15.1.x to 15.1.4, the connection fails. It now returns a 401 Unauthorized message. Portal Access to these remote BIG-IPs worked on the previous version of 15.1.x.

Environment

  • Configure APM Portal Access via a Webtop to manage remote BIG-IPs
  • Upgrade a remote BIG-IP from 15.1.x to 15.1.4
  • Attempt to access this upgraded BIG-IP via Portal Access

Cause

This is due to recent CVE updates to secure BIG-IP TMUI.

Recommended Actions

Add an iRule to the virtual server on the APM and specify the rewrite string for each remote BIG-IP.

when HTTP_REQUEST {
 if { [HTTP::has_responded] } { return }
  #
  # For each remote BIG-IP, convert its IP from string to hex.
  # Add a code block for each URI/rewrite
  # This example includes rewrites for just two BIG-IP
  #
switch -glob [HTTP::path] {
    "/f5-w-68747470733a2f2f312e312e312e31$$/f5-h-$$/tmui/login.jsp" { ; # BIG-IP1 1.1.1.1
    if {[HTTP::header exists referer]} {
        HTTP::header replace referer {https://<virtual server IP on APM>/f5-w-68747470733a2f2f312e312e312e31$$/}
      }
    }
    "/f5-w-68747470733a2f2f312e312e312e31$$/tmui/login.jsp" { ; # BIG-IP1 1.1.1.1
    if {[HTTP::header exists referer]} {
        HTTP::header replace referer {https://<virtual server IP on APM>/f5-w-68747470733a2f2f312e312e312e31$$/}
      }
    }
    "/f5-w-68747470733a2f2f322e322e322e32$$/f5-h-$$/tmui/login.jsp" { ; # BIG-IP2 2.2.2.2
        if {[HTTP::header exists referer]} {
        HTTP::header replace referer {https://<virtual server IP on APM>/f5-w-68747470733a2f2f322e322e322e32$$/}
      }
    }
    "/f5-w-68747470733a2f2f322e322e322e32$$/tmui/login.jsp" { ; # BIG-IP2 2.2.2.2
    if {[HTTP::header exists referer]} {
        HTTP::header replace referer {https://<virtual server IP on APM>/f5-w-68747470733a2f2f322e322e322e32$$/}
      }
    }
  }
]
