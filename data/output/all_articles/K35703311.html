Description

When accessing DoS dashboard (Security > Reporting > DoS > Dashboard), following error message is seen on the Configuration Utility:

"Unable to load application. Error getting is clustered.environment status; Unable to connect to BIG-IP"

Environment

  • Different Browsers tested, still the same
  • tomcat and mysqld daemons restarted, yet still the same

Cause

The issue is still unknown and being investigated.

Recommended Actions

To recover from this anomaly, the following workaround has been provided.
  1. Log in to the CLI
  2. Run the following commands:
    bigstart restart restjavad
    bigstart restart restnoded

Additional Information
None.
