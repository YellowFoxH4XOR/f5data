K000132470: CPU throttling occurring even though disabled

Type
Support Solution
Published
2023-02-09
Updated
2023-02-09
Source
https://my.f5.com/manage/s/article/K000132470

Description

Observed CPU throttling occurring even though specifically disabled in the TMM pod

Environment

  • RedHat OpenShift
  • F5 SPK TMM pod definition configured to disable CPU throttling:
    • cpu-load-balancing.crio.io: disable
    • cpu-quota.crio.io: disable
    • irq-load-balancing.crio.io: disable

Cause

In RedHat OpenShift, a pod can only disable CPU throttling if the pod is allocated at least one full CPU.

Recommended Actions

If CPU throttling is needed, allocated at least one full CPU to the pod in OpenShift.

Additional Information

RedHat OpenShift - Performance Addon Operator for low latency nodes
