K000134715: "ssl_conf_command" to specify cipher suites on TLSv1.3

Type
Support Solution
Published
2023-05-21
Updated
2023-05-21
Applies to
  • NGINX Products
  • NGINX Plus: R28, R25, R26, R27, R23, R24, R29
Source
https://my.f5.com/manage/s/article/K000134715

Description

You need to use "ssl_conf_command" to specify cipher suites on TLSv1.3.

 

Environment

- NGINX Plus

Cause

This is by design.

Recommended Actions

Please use "ssl_conf_command" similar to the following,

ssl_conf_command Ciphersuites 'TLS_AES_256_GCM_SHA384:TLS_CHACHA20_POLY1305_SHA256';

 

Additional Information

None
