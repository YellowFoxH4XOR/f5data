Description
Failed to access about SSH port forwarding to BIG-IQ GUI

Environment

  • SSH port forwarding access to GUI
  • BIG-IQ

Cause
BIG-IQ restricts redirecting to /ui/login/.

Recommended Actions

  1. On client, please access to add "/ui/login/" 
e.g. https://127.0.0.1:8081/ui/login/

Additional Information
When accessing BIG-IP, the client can access to use the following URL and BIG-IP automatically adds /ui/login/.
https://127.0.0.1:8081
