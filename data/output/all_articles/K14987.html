Known Issue

Using the BIG-IP Configuration utility to modify the list of allowed ports for a self IP port lockdown may result in an erroneous list of allowed ports.

This issue occurs when all of the following conditions are met:

  • You have a custom list of ports configured for your self IP Port Lockdown.
  • You attempt to modify the list of allowed ports.

Impact

You may be unable to access your BIG-IP self IP address through the intended ports.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H447284 on the Diagnostics > Identified > Medium screen.
  • After updating the allowed ports, the Port Lockdown may revert to the Allow Custom (Include Default) state, or another state.
  • The existing list of allowed ports may be lost.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) utility to manually make the necessary changes. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Using the tmsh utility to manipulate self IP Port Lockdown allowed ports

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Use the following commands to manipulate the self IP allow list.

    In the following examples, note the following:

    • <self-ip> is the name of the self IP address you would like to manipulate
    • <protocol> is the name of the protocol--either tcp or udp
    • <port> is the port number

    Listing allowed ports for a self IP address:

    list net self <self-ip> allow-service

    For example:

    list net self test-vlan allow-service

    Adding an allowed port for a self IP address:

    modify net self <self-ip> allow-service add { <protocol>:<port> }

    For example:

    modify net self test-vlan allow-service add { tcp:22 }

    Deleting an allowed port for a self IP address:

    modify net self <self-ip> allow-service delete { <protocol>:<port> }

    For example:

    modify net self test-vlan allow-service delete { tcp:22 }

  3. Save changes by typing the following command:

    save /sys config
