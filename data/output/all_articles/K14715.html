Issue

Error Message

metaLogLatencyRaise (291) : metalog latency is too high (disk/network/total completion time) [disk_microseconds]/[network_microseconds]/[totaltime_microseconds]

In this error message, note the following:

  • [disk_microseconds] is the metalog latency experienced on the ARX system disk.
  • [network_microseconds] is the metalog latency experienced on the ARX system due to network traffic.
  • [totaltime_microseconds] is the total metalog latency experienced on the ARX system.

For example:

metaLogLatencyRaise (291) : metalog latency is too high (disk/network/total completion time) 911/3201/1075

Message Location

You may encounter this message in the following location:

  • The ARX traplog

Description

The metaLogLatencyRaise error message indicates that the ARX system has exceeded a configured metalog latency threshold.

This message may occur when one the following conditions are met:

  • You are using an ARX 1500 or 2500 platform.

    The ARX 1500 and 2500 platforms no longer use the NVRAM, and write the metalog to disk. After writing the metalog to disk, the active ARX device synchronizes the metalog to the peer device. If the internal disk drives within the ARX cluster experience latency, the latency can trigger error messages and cause performance issues on the active unit.
  • Logging settings on the ARX are causing high disk I/O.

    The ARX system may be experiencing a metalog latency issue caused by an incorrect Policy_Action logging level. For information, refer to K13549: The ARX system may incorrectly log Policy_Action messages at debug level.

Impact

Metalog latency may impact system performance

Recommended Actions

If you are experiencing metalog latency, F5 recommends that you work with F5 Technical Support to identify and resolve the root cause of your issue.
