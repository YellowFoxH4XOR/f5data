Topic

Beginning in APM Clients 7.2.6, this release introduces F5 Access Mac 7.2.6, a modern VPN client built on Apple’s Network Extension framework. It extends the capabilities of the MacOS App Store version of F5 Access Mac with desktop‑class features and an interface optimized for macOS. For more information, refer to the APM Client 7.2.6 release notes.

Apple has recommended VPN vendors to switch to network extensions framework for building VPN Clients. For more information, refer to Plan your migration from Packet Filter to Network Extension. Following Apple's recommendations F5 is working on a project to migrate all macOS customers to F5 Access including those using BIG-IP Edge Client.

Description

At time of publishing, F5 Access for macOS does not offer all functionality that BIG-IP Edge Client does. F5 is enhancing F5 Access to cover these feature gaps in a phased approach. We have the first version of client released as part of APM Client 7.2.6 in August 2025. We encourage all existing Mac F5 Access customers to deploy the new version at the earliest as prior F5 Access versions will no longer be supported. In case some functionality isn't working as expected, we suggest you to K000135931: Contact F5 Support.

Recommendations

Refer to the following as appropriate for your use case:

  • Existing F5 Access customers
  • Existing BIG-IP Edge Client customers

Existing F5 Access customers

If you are an existing F5 Access customer, the new F5 Access Mac 7.2.6 client introduces some changes to the deployment model, particularly if you are used to installing the App directly via the App Store. The addition of new capabilities requires key architectural changes, including the use of system extensions, which are not compatible with App Store distribution.

To accommodate this, the client will now be distributed as a .pkg installer. All major Mobile Device Managment (MDM)/Unified Endpoint Management (UEM) vendors support .pkg deployment, so we expect minimal disruption for most customers. To align versioning across platforms, the new F5 Access client begins at v7.2.6, consistent with BIG-IP Edge Client versions for Windows and macOS included in the client's ISO bundle. The installer package is made available on the F5 Downloads site for direct download and MDM/UEM-based deployment.

We will also certify and publish F5 Access iOS client to the macOS App Store for Apple Silicon devices. However, please note that this version will have a limited feature set compared to the native application on macOS and will only be available on Mac Apple Silicon devices. As such, we strongly recommend using the native App by updating to F5 Access Mac 7.2.6 or later, unless the App Store deployment is specifically required.

Note: Going forward F5 is planning to provide new functionality and bug fixes only on new F5 Access client version i.e. on top of 7.2.6 and we encourage you to migrate to the new version at the earliest. In case some functionality isn't working as expected, we suggest you to K000135931: Contact F5 Support.

Existing BIG-IP Edge Client customers

If you are a BIG-IP Edge Client customer on MAC, we encourage you to begin evaluating the new F5 Access Mac client as we prepare for a broader transition away from BIG-IP Edge Client - especially on macOS, where Apple is deprecating support for legacy VPN frameworks in favor of Network Extensions. Refer to Plan your migration from Packet Filter to Network Extension.

While F5 Access Mac does not support all features available in BIG-IP Edge Client, we are addressing these gaps in phases. This build includes the initial set of newly added features, which are detailed in APM Client 7.2.6 release notes.

The primary request is for you to test the new F5 Access Mac client in your environment and plan for a migration from BIG-IP Edge Client if all your use cases are met. If you anticipate challenges in migrating to the new client, we would appreciate your feedback, particularly regarding any missing functionality or bugs encountered during testing. We especially encourage customers to pay close attention to endpoint inspection features, where applicable.

Note:

  • F5 makes best effort to keep deployment and configuration changes to a minimal. However, some minor adjustments to the access policy configuration may be necessary. The required changes are mentioned in the Client 7.2.6 release notes.
  • If you need endpoint inspection, auto-upgrade or OIDC support, BIG-IP 17.5.1 or later is required.
