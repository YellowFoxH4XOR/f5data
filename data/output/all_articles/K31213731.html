Issue

Description

The BIG-IP ASM may erroneously block requests with content type application/vnd.ms-sync.wbxml.

Environment

  • BIG-IP ASM
  • application/vnd.ms-sync.wbxml

Cause

The content type application/vnd.ms-sync.wbxml is not currently supported by BIG-IP ASM.

Recommended Actions

Create a header-based content profile for the affected URI to bypass BIG-IP ASM.  For example, this configures the BIG-IP ASM to ignore requests to /Microsoft-Server-ActiveSync when the Content-Type is application/vnd.ms-sync.wbxml:

  1. Log in to the Configuration utility (GUI)
  2. Navigate to Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs.
  3. Click Create to build a new Allowed URL definition.
  4. Click Advanced to display the Header-Based Content Profile.
  5. For URL, enter /Microsoft-Server-ActiveSync.
  6. Click the Header-based Content Profiles tab and enter the following information:
    •  Request Header Name:  Content-Type
    •  Request Header Value:  application/vnd.ms-sync.wbxml
    •  Body handling: Do nothing
  7. Click Add.
  8. Click Create to save. 
  9. Click Apply Policy to apply the changes to the policy.
