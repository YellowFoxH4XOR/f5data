Known Issue

This is the result of a known issue. When multiple aliases are defined for a wide IP address, the aliases appear on the same line on the wide IP list page, separated by a comma character ( , ) and a space. If more than 10 aliases are defined for a wide IP, the alias list extends beyond the page border and causes page layout issues.

F5 Product Development tracked this issue as CR99849 and it was fixed in BIG-IP GTM 10.0.0. For information about upgrading, refer to the BIG-IP GTM release notes.
