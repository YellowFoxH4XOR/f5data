Description

In BIG-IP ASM/WAF with layered (parent/child) security policies, parameter creation in the parent policy is not permitted for inheritance by child policies.

Environment

  • BIG-IP (ASM/WAF)

Cause

BIG-IP ASM layered security policy architecture is designed so that Parameters, Sensitive Parameters, and Navigation Parameters are not inherited from parent to child policies.

This means each child policy must have its own configuration for these entities; only violation and learning settings related to parameters are shared between parent and child.

The Inheritance Settings might seem redundant since parameters themselves are not inherited, but their broader purpose is for:

 Violation and Learning Settings Consistency: Ensuring the same security responses and learning methodologies are shared across child policies when evaluating traffic based on the configured 'Learning and Blocking Settings' for parameters.

 Enabling Frameworks: Ensuring parent policies act as templates for behaviors (not configurations) for organizations maintaining multiple policies across different tiers.

Recommended Actions

Refer to the parent policy’s 'Learning and Blocking Settings' page and adjust the parameter settings as appropriate. 

Additional Information

Sensitive parameters must be manually configured in each child policy, as inheritance of these entities is not supported.
