Description

You wish to modify SNMP threshold for the Partitions monitoring as /var, /appdata, etc.

Environment

  • BIG IP
  • SNMP

Cause

Wishing to modify partitions threshold value 

Recommended Actions

To set the threshold with a different value (Warning and Alerting):

1. Connect with tmsh and run the following command, replacing the <> with the partition and value.

For SNMP  trap and log when free space is very low:

tmsh modify sys db platform.diskmonitor.freelast.var value <percent free space>

For Warniing level (Logs a warning when free space drops below this value):

tmsh modify sys db platform.diskmonitor.limitwarn.var value <percent free space>

For Alert level:

tmsh modify sys db platform.diskmonitor.limitalert.var value <percent free space>

i.e.:

(Active)(/Common)(tmos)# modify sys db platform.diskmonitor.freelast.var value 30
(Active)(/Common)(tmos)# modify sys db platform.diskmonitor.limitwarn.var value 30
(Active)(/Common)(tmos)# modify sys db platform.diskmonitor.limitalert.var value 30

2. Save the configuration using the following command: 

tmsh save sys config

Additional Information

To verify that your new settings were set:

(Active)(/Common)(tmos)# list sys db platform.diskmonitor.limitalert.var
sys db platform.diskmonitor.limitalert.var {
    value "30"
}
