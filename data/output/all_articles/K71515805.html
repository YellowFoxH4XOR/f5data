K71515805: The /var/log/ltm accidentally renamed or deleted. No logging

Type
Support Solution
Published
2021-08-06
Updated
2025-04-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.2
Source
https://my.f5.com/manage/s/article/K71515805

Description

ltm.log file was accidentally renamed or deleted and is no longer logging,

Environment

  • BIG-IP LTM
  • deleted main ltm.log log file
  • file location - /var/log/ltm

Cause

The main active ltm log file in /var/log/ltm was renamed or deleted and is not longer logging
Reviewing /var/log/ltm the ltm.log and ltm.1 are missing
   # ll | grep ltm

Recommended Actions

To resolve the missing main ltm log file,

  1. Re-start the syslogging to recreate the ltm.log file
    # bigstart restart syslog-ng
     
  2. Check the /var/log/ltm directory to confirm that the ltm.log has been created
    # cd /var/log/
    # ll | grep ltm
     
  3. Confirm the ltm.log file is now logging as expected
    # tailf /var/log/ltm

Additional Information
Note: deleting logs shouldn't be done unless directly requested by support
