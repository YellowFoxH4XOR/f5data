K000134975: BigIP - Intune Authentication Failing

Type
Support Solution
Published
2023-06-08
Updated
2023-06-08
Applies to
  • BIG-IP
  • BIG-IP APM: 17.0.0
Source
https://my.f5.com/manage/s/article/K000134975

Description

Microsoft InTune MDM authentication error:

Jun 5 01:01:01 bigip1 err mdmsyncmgr[17019]: 019dffff:3: (null)::00000000: {} /Common/Inspect: Error during updating device details: Authentication error (Authentication error for query authentication token request)



Environment

BigIP APM

Cause

Invalid credentials or configuration failing authentication

Recommended Actions

Referencing endpoint management config, craft the following curl command to confirm a token can be generated successfully,


apm aaa endpoint-management-system /Common/Inspect {

client-id CLIENT_ID_VALUE

client-secret ***

tenant-id TENANT-ID-VALUE

type ms-intune

}


# curl -X POST -d 'grant_type=client_credentials&client_id=CLIENT_ID_VALUE&client_secret=&resource=https%3A%2F%2Fgraph.windows.net' https://login.microsoftonline.com/TENANT-ID-VALUE/oauth2/token
