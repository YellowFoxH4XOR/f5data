Description

This is about how to customize the message of the blocking page listed in the following documents.

4.4. Managing Cryptography
https://clouddocs.f5.com/sslo-deployment-guide/chapter4/page4.4.html
4.4.5. Managing certificate validation and revocation
A third option exists when the Server Certificate Status Check option is enabled on the Security Policy page in an SSL Orchestrator outbound topology and when the Expire Certificate Response option is set to ignore. With this set, SSL Orchestrator will forge a good certificate and present a blocking page to the client when it receives an expired server certificate.

Manual Chapter : Features and Terminology in F5 Guided Configuration for SSL Orchestrator
https://techdocs.f5.com/en-us/bigip-16-0-0/ssl-orchestrator-setup/terminology-for-herculon-ssl-orchestrator-ct.html
Topologies (Guided Configuration Steps)
·Security Policy
You can select Server Certificates Status Check if you want to add a new per-request policy agent for server certificate status and to allow administrators to select ignore/mask options and generate a blocking page for untrusted and expired server certificates. In addition, you can select Proxy Connect if you want to add an upstream explicit proxy to your security rule chaining. You can add multiple proxy devices, or pool members, as necessary.


[ the message of the blocking page ]
- Access to this page is blocked. Certificate verification error: certificate has expired.
- Access to this page is blocked. Certificate verification error: self signed certificate in certificate chain.

  • BIG-IP SSLo

This page is customizable, under Access -> Advanced Customization -> Logout.
