Known Issue

Under rare conditions, a BIG-IP Analytics (AVR) initialization error may corrupt webpages.

This issue occurs when the following condition is met:

  • You have configured the Analytics profile with the Page Load Time feature enabled to view webpages.

Impact

Invalid JavaScript is injected into HTML webpages.

Workaround

There is no workaround for this issue. However, you can attempt to recover from the issue by restarting the tmm process. To do so, perform the following procedure:

Impact of workaround: Restarting the Traffic Management Microkernel (TMM) interrupts traffic processing; you should perform this procedure during a maintenance window.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Restart the tmm process by typing the following command:

    restart sys service tmm
