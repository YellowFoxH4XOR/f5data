K000133225: BIG-IQ not deleting old ASM event logs

Type
Support Solution
Published
2023-03-28
Updated
2023-03-28
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000133225

Description

The Index count in System tab > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Cluster > CONFIGURATION > Logging Data Collection > Web Application Security (ASM) is higher than the value set in the "Configure" menu for asmindex Retained index Count.

Environment

  • BIG-IQ
  • Web Application Security (ASM) Index count is higher than expected

Cause

The Web Application Security (ASM) Index count includes asmindex, bruteforcesecindex, doslogindex, bruteforceprimindex and botindex

Recommended Actions

Use the following command to output asmindex count from bash cli:

curl -sku admin:admin https://localhost:9200/_cat/indices?v | grep "asmindex_" | wc -l

Additional Information

The indexes can be viewed from BIG-IQ GUI: System tab > BIG-IQ DATA COLLECTION > BIG-IQ Data Collection Cluster > SUMMARY > Indexes
