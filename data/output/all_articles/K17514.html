Known Issue

The BIG-IP configuration fails to load when the persist.wellknownproxyclass database variable references a deleted proxy configuration file.

This issue occurs when the following condition is met:

  • The configuration file is removed from the running configuration.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates an error to the /var/log/ltm file that appears similar to the following example:

    01020036:3: The requested value_list (/Common/<file_name>) was not found.
  • The BIG-IP configuration fails to load. For example, attempting to install a UCS file or run the tmsh load /sys config command fails.

Workaround

To work around this issue, you can load the user configuration set (UCS) file a second time. For example, if you previously used the tmsh load /sys ucs my-ucs-file.ucs command to load a UCS file, repeat that command a second time.

Impact of workaround: Performing the suggested procedure should not have a negative impact on your system.
