Description

You have an AFM "any any rule" which is set to Accept but the BIG-IP AFM has stopped processing traffic.

Environment

  • BIG-IP AFM provisioned
  • Firewall mode as per K92958047

Cause

In Firewall mode, the AFM is set as a default deny / default reject. The "any any rule" which is set to Accept will not allow traffic for each Virtual Servers and Self-IPs.

Recommended Actions

To resolve the issue, perform one of the following procedures:

  • Change to ACD mode
  • Change to action to Accept Decisively


Change to ACD mode

  1. Follow article K92958047 to change to ACD mode.
  2. Make changes to your AFM rules to accommodate ACD mode.

Change to action to Accept Decisively

  1. Navigate to Security > Network Firewall > Policies.
  2. Click on the policy name.
  3. Click on the rule name.
  4. Change the Action from Accept to Accept Decisively.
  5. Click Done Editing.
