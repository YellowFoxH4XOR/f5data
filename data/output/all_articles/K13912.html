Topic

You should consider using this procedure under the following condition:

  • You want to disable Guaranteed Logging for a remote logging profile.

Description

By default, a remote logging profile has the Guaranteed Logging option enabled. If a logging host is unreachable, the BIG-IP ASM system will continue to attempt to deliver the log data, which may slow access to the associated web application. When the BIG-IP ASM system is set to Guaranteed Logging, the system will prioritize logging events over system performance. Disabling the Guaranteed Logging setting for remote storage profiles will prioritize web-application performance above logging performance.

Note: For more information about disabling Guaranteed Logging for local storage profiles, refer to the Configuration Guide for BIG-IP Application Security Manager. For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP ASM system is configured with a remote logging profile.
  • Your BIG-IP ASM system runs BIG-IP 10.2.1 HF2 or later.
  • You have advanced shell access.

Procedures

  • Setting guarantee_remote_logging parameter to disabled value from the command line
  • Setting guarantee_remote_logging parameter to disabled using the Configuration utility

Setting guarantee_remote_logging parameter to disabled value from the command line

Impact of procedure: BIG-IP ASM services must be restarted. For redundant systems, the active system may fail over to the standby partner, and some traffic may be briefly interrupted. For standalone systems, traffic may be briefly interrupted.

  1. Log in to the BIG-IP ASM command line.
  2. To change the guarantee_remote_logging parameter value to zero (0), type the following command:

    /usr/share/ts/bin/add_del_internal add guarantee_remote_logging 0

  3. To restart the asm process, type the following command:

    tmsh restart /sys service asm

    Important: This step may interrupt processing of traffic on the device.

Setting guarantee_remote_logging parameter to disabled using the Configuration utility

Impact of procedure: BIG-IP ASM services must be restarted. For redundant systems, the active system may fail over to the standby partner, and some traffic may be briefly interrupted. For standalone systems, traffic may be briefly interrupted.

Note: The guarantee_remote_logging parameter is not exposed in the Configuration utility by default. In order to modify the parameter using the Configuration utility, you must first perform the previous procedure to expose the parameter.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Advanced Configuration > System Variables.
  3. Locate the guarantee_remote_logging Parameter Name.
  4. Change the guarantee_remote_logging Parameter Value to zero (0).
  5. Click Save.
  6. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  7. To restart the asm process, type the following command:

    restart /sys service asm

    Important: This step may interrupt processing of traffic on the device.

  8. Exit tmsh by typing the following command:

    quit
