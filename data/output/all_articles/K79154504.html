Description
A JSON policy created via REST/AS3 and then overwritten via tmsh will result in an error:

Unexpected Error: Import policy failed. Messages: [fatal] Failed action: Imported and replaced policies have different encodings.

Environment

  • REST API or AS3 used

Cause
This is caused by Bug ID 1064821: ASM v15.1.4 REST/AS3-imported and replaced policies have different encodings.

Recommended Actions

To resolve this issue, the existing policy must be deleted and a new one to be created again.

To create the policy, use the following command:

# tmsh load asm policy JbossWafPolicy file /dir/<policy_name>.json overwrite

Additional Information
None.
