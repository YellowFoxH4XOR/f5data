Known Issue

The BIG-IP APM system may incorrectly rewrite JavaScript expressions.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM access profile references a rewrite profile.
  • The rewrite profile encounters a JavaScript code expression that contains comma characters, similar to the following example:
       
    <script>
        var obj = {
        'o': 'OK',
        'f': 'FAIL'
         };
        var test = obj['f', 'o'];
        document.write<pre>'+ test +'</pre>
       </script>

    Note: The rewritten JavaScript expression may contain only the first comma separated expression value stated.

Impact

Rewritten JavaScript expressions are incorrect.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Rewritten JavaScript expressions trigger exceptions or broken logic when interacting with applications.
