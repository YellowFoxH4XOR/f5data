K40652173: IP Intelligence auto database updates fails with 401 Unauthorized

Type
Support Solution
Published
2022-01-13
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM
  • BIG-IP AFM
Source
https://my.f5.com/manage/s/article/K40652173

Description

When IP reputation database is configured to automatically update. The BIG-IP connects to Brightcloud's IP intelligence database to download the contents. please review the recommendation section if it fails to download updates and report back a 401 Unauthorized error.

Environment

  • IP Intelligence license enabled.
  • IP reputation database is configured to automatically update.

Cause

The unit's Device ID is not supported by the Webroot IP Reputation subscription service. 

Recommended Actions

Open a case with support for further investigation.
