Known Issue

This is the result of a known issue. The native SSL stack is the default SSL stack for BIG-IP LTM client SSL profiles. When the cipher list for a client SSL profile contains only native SSL ciphers, certificate revocation lists defined in the profile will not be honored during SSL authentication. This behavior allows users to connect to the client SSL virtual server with revoked SSL certificates.

F5 Product Development tracked this issue as CR89549 and it was fixed in BIG-IP LTM 9.4.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.3.1-HF3 issued for BIG-IP 9.3.1, for the BIG-IP 9.3 software branch. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
