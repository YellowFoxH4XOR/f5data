Description

Remote syslog messages may be replaced by "tmm" and reported to syslog server. It will not be sure about which device is sending it by looking at remote syslog messages.

You will get similar to the following messages when it is affected. In this example, hostname is replaced by tmm0 and we do not know which device is reporting from.

May 23 14:29:27 tmm0 tmm[4456]: Rule /Common/LOG <HTTP_REQUEST>: HTTP_REQUEST
May 23 14:29:27 tmm0 tmm[4456]: Rule /Common/LOG <HTTP_REQUEST>: HTTP_REQUEST
May 23 14:29:28 tmm0 tmm[4456]: Rule /Common/LOG <HTTP_REQUEST>: HTTP_REQUEST


This may happen when custom syslog configuration uses "source(local);" statement.

 

log {
source(local); <-------------!!!!!!!!!!!!!!!
filter(test);
destination(server);
};

Environment

  • BIG-IP system

Cause

Bug ID 998649: Log hostname should be consistent when it contains ' . '

Recommended Actions

Replace "source(local);" statement to "source(s_syslog_pipe);"
