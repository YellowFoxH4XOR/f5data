K54010324: BIG-IQ new deployment there is an error message when trying to set up HA

Source
https://my.f5.com/manage/s/article/K54010324

Description
       You are trying to add a standby BIG-IQ Centralized Management for High Availability and get an error saying "not a BIG-IQ device"

Environment

  • BIG-IQ 7.1

Cause
        Environmental -- Duplicate IP addresses. If there is another host with the same IP address as the HA IP of the standby BIG-IQ device that you are trying to add, then this error message may be seen.

Recommended Actions

  1. Make sure the standby BIG-IQ discovery IP address is unique on your network

None
