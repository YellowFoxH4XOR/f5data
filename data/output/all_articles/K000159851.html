K000159851: iRule HTTP::respond Command Doesn't Work on VS with HTTP3/QUIC Profile

Type
Support Solution
Published
2026-02-03
Updated
2026-02-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000159851

Description

You configure a VS with an HTTP3/QUIC profile and attach an iRule that contains the HTTP::respond command. However, the BIG-IP doesn't respond with the content.


You see a log similar to the following when you use the curl command:


# curl -kv --http3-only https://192.168.0.10

<snip>

curl: (18) end of response with 32 bytes missing

 

Environment

BIG-IP

HTTP3/QUICK Profile

iRule HTTP::respond command

 

Cause

ID 2130729


Answer/Recommended Actions

The issue is fixed in versions 21.0.0 and 17.5.1.4, so you can upgrade to either version or their successors.

 

Additional Information

None
