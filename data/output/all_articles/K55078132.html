Description

When attempting to upgrade the Software on the BIG-IP. The installation process fails and displays error similar to following in /var/log/liveinstall.log:

error: tm_install::Process::Process_full_install -- predicted size for BIGIP15104 is 12315728 and vg has 0 remaining.
Terminal error: Disk full (volume group). See SOL#10636

Environment

  • BIG-IP 
  • iSeries
  • Upgrade Process
  • Software installation

Cause

Bug ID927033

Recommended Actions

Create the expected symlink manually:

cd /dev/md
ln -s ../md127 _none_\:0
