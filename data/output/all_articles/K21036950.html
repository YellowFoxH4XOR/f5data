Topic

This article links to videos that show you how to configure a site-to-site (S2S) VPN tunnel connection from a corporate data center to an Azure virtual network (VNet).

Description

The following eight videos show you how to use IPsec on the BIG-IP system to establish a secure tunnel from a corporate data center to an Azure virtual network.

  • Define an Internet Key Exchange (IKE) phase 2 security policy.

    Video: Define an Internet Key Exchange (IKE) Phase 2 security policy

  • Define eligible web traffic for the secure tunnel.

    Video: Define eligible web traffic for the secure tunnel

  • Define IKE phase 1 tunnel negotiation parameters by configuring negotiation to authenticate IKE peers and encrypt IKE communication.

    Video: Define IKE Phase 1 tunnel negotiation parameters

  • Create a virtual interface for routing traffic through the tunnel by creating an IPsec profile to filter through the tunnel for the traffic selector you specify.

    Video: Create a virtual interface for routing traffic through the tunnel

  • Create an IPsec tunnel on the BIG IP system and specify how the tunnel carries traffic by assigning endpoints and direction.

    Video: Create a tunnel by assigning endpoints and direction

  • Create a tunnel local endpoint, and then repeat the steps to create a tunnel remote endpoint.

    Video: Create IP addresses for local and remote tunnel endpoints

  • Route traffic from the BIG-IP system to an Azure virtual network and specify the virtual interface as the gateway for the route.

    Video: Add a static route for Web traffic

  • Disable load balancing and forward web traffic through the tunnel.

    Video: Disable load balancing and forward Web traffic through the tunnel
