K86054000: Error 51134 when reactivating a VE Pool license using BIG-IQ

Description

Reactivation of a pool license in BIG-IQ is resulting in error:
“Error 51134, F5 registration key is not compatible with the detected version. This software version, "4.6.0" cannot be "activated with this registration key "XXXXXXX-XXXXXXX".
 

Environment

  • BIG-IQ
  • Pool license
  • Reactivation via BIG-IQ

Cause

The BIG-IQ software version is incompatible with the license or the license key needs to be released.

Recommended Actions

  1. Confirm the BIG-IQ version. If the BIG-IQ is running a compatible version, contact F5 Support to request to release the pool license.
  2. Once the key is released, try to reactivate the pool license again.

Additional Information

Further issues such as below may be encountered from the GUI when the pool license is released:
 

  • "Reactivate" button is greyed out. 
  • Status changed from "failed" to "pending". 
  • At the bottom of the page, it shows – “Status: WAITING_FOR_LICENSE_TEXT ”

    If the above happens, try the steps below:
     
  1. Delete and add the pool license again.
  2. After re-adding the pool license in BIG-IQ, re-assign the pool license to all VE devices that were assigned previously.
  3. Log a support case with F5 Support should the above steps fail to resolve the issue.
