Description

After upgrading to version 15.1.2.1 when the password for device management users expire and they access the BIG-IP GUI, they get the authentication page with field for new password, but after submitting page will throw error "Authentication failed: Password expired. Update password via /mgmt/shared/authz/users"

Environment

  • Users managing BIG-IP through the Configuration utility (a.k.a. web GUI)

Cause

Issue was being caused by Bug ID 996593 - Password change through REST or GUI not allowed if the password is expired

Bug ID 996593 is fixed in 16.1.0, 16.0.1.2, 15.1.4, 14.1.4.3. 

Recommended Actions

  1. Use tmsh to update the password using command tmsh modify auth password <username>
  2. Upgrade to a fixed version.
