Description

When trying to create/modify a password for an IPsec IKE peer via GUI (Network > IPsec > IKE peers), if the password contains a semicolon character ";" then the GUI will display an error "General database error".

Environment
BIG-IP GUI (all modules)

Cause

This is due to a known issue tracked as ID940757 .

 Recommended Actions

- Use TMSH instead to create/modify password

Example:

[root@bigip:Active:Standalone] config # tmsh

root@(bigip)(cfg-sync Standalone)(Active)(/Common)(tmos)# modify net ipsec ike-peer peer-01 preshared-key "abc123;12"

 

Note The above is just an example. Please replace peer-01 with the correct peer name and "abc123;12" with the correct pre-shared key.
