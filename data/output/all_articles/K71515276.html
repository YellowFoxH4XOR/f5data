Topic

You should consider using this procedure under either one of the following conditions:

  • You want to create a pre-login message banner that appears before the user logs in using a secure shell session (SSH).
  • You want to create a post-login message banner after the user logs in using SSH or the serial console.

Description

The pre-login message banner sends a message to the remote user who attempts to log in to the system using SSH. The pre-login message banner is useful for enforcing security policy; for example, to inform the remote user all activities are logged.

The post-login message banner appears after a user successfully authenticates to the advance shell access on the system, either using SSH or the serial console. This message banner is useful to inform your users about the system; for example, to inform users of an upcoming scheduled maintenance.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have access to the advance shell with an administrator role credential on the BIG-IQ system.
  • You are familiar with a Linux text editor.

Note: For more information about enabling administrator roles to have advance shell, refer to K16413: Enabling Advance Shell or tmsh utility access for BIG-IQ user accounts.

Procedures

  • Adding a multiple line pre-login message banner using tmsh and bash
  • Adding a single line pre-login message banner using tmsh
  • Adding a post-login message banner using bash

Adding a multiple line pre-login message banner from a file using tmsh and bash

To use the Traffic Management Shell (tmsh) to add a pre-login message banner from a file that will send the message to the remote user who attempts to log in using SSH, perform the following procedure:

Impact of procedure: These changes may not be present after an upgrade or re-installation. Therefore, F5 does not officially recommend these changes. However, if the changes are required due to a security policy, ensure that the changes are verified after any upgrades. In addition, these changes may not propagate to high-availability peers and you must perform this procedure to all devices in the device group, if required.

  1. Log in to the BIG-IQ command line with an administrator role credential.
  2. Using a text editor of your choice, open the /config/ssh/ssh_banner file. If it does not exist, create the file.

    Note: Alternatively, you can create the message banner using another filename. If you use another filename, you must apply the matching filename to Step 5.

  3. Type the desired content for the pre-login message banner.
  4. Save the file and exit the text editor.
  5. To add the sshd-banner, use the following command syntax:

    tmsh modify /sys sshd include "<enter value>"

    For example:

    tmsh modify /sys sshd include "Banner /config/ssh/ssh_banner"

    Note: If you have specified a different filename in Step 2, you have to use the matching filename in this step.

    To disable this message banner, type the following tmsh command:

    tmsh modify /sys sshd include none

  6. To enable the message banner text, type the following command:

    tmsh modify /sys sshd banner enabled

    To disable this message banner, type the following command:

    tmsh modify /sys sshd banner disabled

  7. To save the changes, type the following command:

    tmsh save /sys config

Adding a single line pre-login message banner using tmsh

To use the tmsh utility to add a pre-login single-line message banner that will send the message to the remote user who attempts to log in using SSH, perform the following procedure:

Impact of procedure: These changes may not be present after an upgrade or re-installation. Therefore, F5 does not officially recommend these changes. However, if the changes are required due to a security policy, ensure that the changes are verified after any upgrades. In addition, these changes may not propagate to high-availability peers and you must perform this procedure to all devices in the device group, if required.

  1. Log in to the BIG-IQ command line with an administrator role credential.
  2. To enable and add the single-line message banner text, use the following command syntax:

    tmsh modify /sys sshd banner enabled banner-text "<Banner-Text>"

    For example, to enable the single-line banner text and use NOTICE: This is for authorized users only. as the text, type the following command:

    tmsh modify /sys sshd banner enabled banner-text "NOTICE: This is for authorized users only."

    To disable this message banner, type the following command:

    tmsh modify /sys sshd banner disabled banner-text none

  3. To save the changes, type the following command:

    tmsh save /sys config

Adding a post-login message banner using bash

To create a post-login message banner that displays after a user successfully authenticates to the system using SSH or the serial console, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ command line with an administrator role credential.
  2. Using a text editor, open the /etc/motd file. If the file does not exist, create the file.
  3. Type the content for the post-login message banner.
  4. Save the file and exit the text editor.

To disable this message banner, you can remove the content of the /etc/motd file by typing the following command:

cat /dev/null > /etc/motd
