Description

  • Requests blocked with Violation: Illegal HTTP status in response
  • Server HTTP response code is not allowed by default (For example: 502)

Environment

  • ASM Security Policy
  • Learning and Blocking settings

Cause

The default BIG-IP ASM configuration allows by default response codes 200 through 399 and 400, 401, 404, 407, 417 and 503. All other HTTP response codes are blocked by the BIG-IP ASM

Recommended Actions

You can configure the BIG-IP ASM to allow additional HTTP response codes by adding them to the Allowed Response Status Codes in the ASM security policy in question.

Additional Information

It is recommended to avoid allowing any response codes which may return information leaking error messages in the application
