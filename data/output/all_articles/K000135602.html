K000135602: The number of interfaces shown on a Tenant is smaller than the number of VLANs/Trunks assigned to it.

Type
Support Solution
Published
2023-07-25
Updated
2025-05-28
Applies to
  • F5OS
Source
https://my.f5.com/manage/s/article/K000135602

Description

When deploying a Tenant, from the host F5OS device, you are assigning it a certain number of VLANs and/or Trunks. Yet, when the tenant is fully deployed, the number of interfaces inside is considerably smaller than the number of VLANs or trunks.

Environment

  • Tenant deployment
  • Interfaces don't match what is expected.
  • r5000/r10000 
  • F5OS-A

Cause

The number of interfaces or it's status inside a tenant does not depend on the number of VLANs and/or Trunks assigned through the host. It is closely correlated to the number of CPUs. 

"The tenant will see virtual interfaces and the number of interfaces within a tenant will be based upon the number of CPUs assigned to the tenant. The r5000 and higher platforms will have one virtual interface per TMM""

For example:

If a tenant has been configured with 10 vCPUs, this equate to 5 physical CPUs due to hyper-threading (HTSplit feature). The even-numbered hyper-threads are dedicated to data plane /TMM. Therefore, the tenant will have 5 virtual interfaces, which are based on the data plane vCPUs

 Recommended Actions

None -  All the interfaces that have been assigned to the tenant have been virtualized and presented to the tenant through the interfaces that are visible under Network>>Interfaces.

The traffic will flow correctly through them.
