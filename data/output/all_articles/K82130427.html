Issue

01070734:3: Configuration error: Can't associate classification overview selection (/[All]/<item>) folder does not exist Unexpected Error: Loading configuration process failed.

In this error message, note the following:

  • <item> is the configuration item causing the configuration error.
For example:

01070734:3: Configuration error: Can't associate classification overview selection (/[All]/uwid55751cc14c600) folder does not exist Unexpected Error: Loading configuration process failed.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A configuration item is set for the [all] partition instead of a specific partition.
Beginning in BIG-IP 13.1.0, the system no longer supports the [All] partition in the configuration file.

Impact

Configuration fails to load.

    Recommended Actions

    To load the configuration, replace the [All] partition with the /Common partition or specify another partition of your choice. You can do this using any of the following methods:

    • Manually edit the affected configuration file and replace all instances of the /[All]/ (or unspecified) partition with the default /Common/ partition name or the partition name of your choice, then reload the configuration. (For example, you can use the following command on the CLI to do the replace inside bigip.conf: 
      • sed -ie 's/\[All\]/Common/g' bigip.conf.
    • Boot the BIG-IP system to the previous boot location (roll back) and modify the configuration by replacing the /[All]/ partition with the default /Common/ partition name. Restart the system to boot new location and install (roll forward) the updated configuration. (For example, you can use the following command to do the replace inside bigip.conf:
      •   sed -ie 's/\[All\]/Common/g' bigip.conf
