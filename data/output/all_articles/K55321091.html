K55321091: sys state-mirroring peer-addr not supported

Description

If you are configuring mirroring on your BIG-IP system using the tmsh command line interface or the tmsh manual, you may come across the "modify sys state-mirroring" command. However, this is not the correct command to use for configuring mirroring. Instead, the correct command is "modify cm device," which was introduced as a replacement for the older "modify sys state" command.

Environment

  • BIG-IP system
  • Mirroring function enabled

Cause

The "modify sys state-mirroring" command is a leftover from older versions of BIG-IP where there was only one global mirror connection for each device. With the introduction of devices, device-groups, and traffic-groups in v11, the mirroring functionality has changed, and the "modify cm device" command was introduced. However, the command line manual and help have not been updated accordingly.

Recommended Actions

To configure mirroring, use the "modify cm device" command instead of the "modify sys state-mirroring" command. This is the command to set the mirror IP address and secondary mirror IP address. Here are the specific steps you should follow:

  1. Log in to the BIG-IP system using an account that has administrative privileges.
  2. Access the tmsh command line interface.
  3. Use the following command to set the mirror IP address: 
    tmsh modify cm device bigip1.local mirror-ip <mirror_IP_address>
    Replace "<mirror_IP_address>" with the IP address of the mirror.
  4. Use the following command to set the secondary mirror IP address: 
    tmsh modify cm device bigip1.local mirror-secondary-ip <secondary_mirror_IP_address>
    Replace "<secondary_mirror_IP_address>" with the IP address of the secondary mirror.
  5. Save the configuration changes using the following command: 
    tmsh save sys config
