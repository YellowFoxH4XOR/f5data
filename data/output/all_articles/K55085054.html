Description

A multi-bladed chassis with secondary blades both showing Alarm LED solid red or solid amber
Status LED is solid green

Environment

  • A multi-bladed VIPRION

Cause

Issue could be caused by synchronisation failure between the primary-secondary blades

'tmctl csync_stat' command output is similar to below

name    src_slot_id    dst_slot_id    rc    count    comment
Totals  17   7    68    219003075    n/a
row0    1    1    0    41    Success
row1    2    1    0    112556856    Success
row2    3    1    0    106446129    Success
row3    3    1    23    33    Partial transfer due to error
row4    2    1    23    13    Partial transfer due to error
row5    3    1    12    1    Error in rsync protocol data stream
row6    3    1    10    2    Error in socket I/O

 

Recommended Actions


Restart the csyncd to clear the stat (alert) and reboot the chassis:

# clsh bigstart restart csyncd
# clsh shutdown -r now
