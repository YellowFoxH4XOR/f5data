Known Issue

Your attempt to compile the F5-BIGIP-LOCAL-MIB file may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running 11.6.x.
  • You download the F5 MIB files from the BIG-IP system onto a Network Management System (NMS).
  • You attempt to compile the MIB file named F5-BIGIP-LOCAL-MIB.txt on the NMS.

The F5-BIGIP-LOCAL-MIB file has a missing comma (,) for certain MIB objects, which may lead to a compilation error on the NMS. The following example shows the ltmFwRuleStatRuleStatType object with a missing comma that is supposed to separate the defined values of enforced(1) and staged(2):

ltmFwRuleStatRuleStatType OBJECT-TYPE
    SYNTAX INTEGER {
        enforced(1)staged(2),
        active(3),
        overlapper(4)
    }
    MAX-ACCESS read-only
    STATUS current
    DESCRIPTION
        ""
    ::= { ltmFwRuleStatEntry 6 }

Impact

You are unable to compile the F5-BIGIP-LOCAL-MIB file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to compile the F5-BIGIP-LOCAL-MIB file, you notice an error message similar to the following example:

    Unexpected token: in /.../mibs/F5-BIGIP-LOCAL-MIB.mib line no: 27738.

Workaround

To work around this issue, you can edit the F5-BIGIP-LOCAL-MIB file manually before attempting to compile it. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. On the NMS system, edit the MIB file named F5-BIGIP-LOCAL-MIB.txt file using a text editor of your choice.
  2. Locate all the MIB objects with the incorrect enforced(1)staged(2) value within the file.
  3. Add a comma to the affected MIB objects, so that enforced(1) and staged(2) are displayed as two separate values instead of one.

    For example, the ltmFwRuleStatRuleStatType object should appear similar to the following example configuration:

    ltmFwRuleStatRuleStatType OBJECT-TYPE
    SYNTAX INTEGER {
            enforced(1),
            staged(2),
            active(3),
            overlapper(4)
        }
        MAX-ACCESS read-only
        STATUS current
        DESCRIPTION
            ""
        ::= { ltmFwRuleStatEntry 6 }

  4. Save your changes.
  5. Recompile the MIB file again.
