Description

Config-Sync between devices in the same Sync-Failover device-group, fails to sync showing an error on the GUI of the receiving device, similar to the following:

Sync error on LTM2.example.com: Load failed from LTM1.example.com 01070355:3: Self IP <IP_address> is declared as a floating address but there is no non-floating address defined for this network

Environment

  • Config-Sync
  • Self IP

Cause

The active device is trying to sync a floating Self IP configured for a specific VLAN, but the receiving device does not have a local-only (non-floating) Self IP configured for that VLAN.

Note: Local Self IPs do not sync between devices, and floating Self IPs cannot sync unless a non-floating Self-IP is configured for the VLAN on both devices.

Recommended Actions

Configure a local-only, non-floating Self IP on the receiving device for the specific VLAN, before trying the sync again.
You may also need to break device trust (delete peer device) and re-discover the peer device from scratch to restart the sync / re-validate.
