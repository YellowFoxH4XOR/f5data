Description

 

BIG-IP 15.0.0 and later

  • The BIG-IP system supports TLS 1.3 client side session resumption.

You don't see BIG-IP sending out New Session Ticket with the default client-ssl profile during TLS1.3 handshake,

192.0.0.1 → 10.1.1.1  265 60695 443 TLSv1 Client Hello
10.1.1.1 → 192.0.0.1 1500 443 60695 TLSv1.3 Server Hello, Change Cipher Spec
10.1.1.1 → 192.0.0.1 1257 443 60695 TLSv1.3 Encrypted Extensions, Certificate, Certificate Verify, Finished
192.0.0.1 → 10.1.1.1 120 60695 443 TLSv1.3 Change Cipher Spec, Finished
192.0.0.1 → 10.1.1.1 68 60695 443 TLSv1.3 [TLS segment of a reassembled PDU]
10.1.1.1 → 192.0.0.1 711 443 60695 TLSv1.3 New Session Ticket, New Session Ticket, Application Data
10.1.1.1 → 192.0.0.1 64 443 60695 TLSv1.3 Alert (Level: Warning, Description: Close Notify)

 

Environment

BIG-IP v15.0.0 and later
TLS v1.3
Client ssl profile
 

Cause

ltm profile client-ssl /Common/clientssl {

...

    session-ticket disabled    ---> Enable it
    session-ticket-timeout 0

...

}

Session Ticket

Enables or disables the use of session tickets per RFC 5077. By default, this setting is disabled, which causes the system not to use session tickets. When enabled, causes SSL profiles to use session tickets per RFC 5077.

Session Ticket Timeout

Specifies the timeout for the session ticket. The default is 0 seconds, which means the system uses the cache timeout.

 

Recommended Actions

Enable the session ticket in the client-ssl profile.
