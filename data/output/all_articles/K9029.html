Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 9.3.1. F5 recommends that all customers currently running 9.3.1 install Hotfix-BIG-IP-9.3.1-HF4, or a later version of the cumulative hotfix rollup, as soon as possible.
