Description

You are trying to configure OAUTH2 JWT Token with custom groups claim

 

Environment

BIG-IP APM

Cause

This is expected behavior and we have an existing RFE (Bug alias 724666) [RFE][OAuth AS] Support array of strings in claim

Recommended Actions

There was a workaround described in the RFE that might help:

 

You can add a private claim with an array of strings using either of the following procedures.

 

Procedure 1

1. Specify claim type 'custom'.

2. Set its value as a session variable, e.g., %{session.user.myclaim}.

3. In your policy, propagate the variable with a JSON-formatted array, e.g., ["str1", "str2"].

 

Procedure 2

Directly enter the JSON-formatted array in the GUI, with the quotation marks escaped, e.g., [\"str1\", \"%{session.user.nickname}\"].
