K000149590: No new learning suggestion for parameters defined in the BIG-IP ASM/advanced WAF security policy.

Type
Support Solution
Published
2025-03-08
Updated
2025-12-22
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.0.0, 16.0.X, 16.0.1, 17.X.X, 16.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000149590

Description

No new parameters getting learned in the security policy whereas a list of previously learned and added parameters can be seen under the Security  ››  Application Security : Parameters : Parameters List. You can see learning suggestions of other types.  

Environment

  • BIG-IP ASM
  • Security Policy with Automatic learning enabled
  • Parameter learning method is set to Compact with the default 100 limit

Cause

Maximum Learned Parameters limit set in the policy global configuration. 

Recommended Actions

Navigate to the Security  ››  Application Security : Policy Building : Learning and Blocking Settings, make sure you select the correct policy. Increase the Maximum Learned Parameters value.

Additional Information

None.
