K67909221: Big-IP Edge Client Fails to Connect if Another SSL VPN is Running

Type
Support Solution
Published
2022-01-06
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM
  • APM Clients
Source
https://my.f5.com/manage/s/article/K67909221

Description

In order to establish the VPN tunnel and route traffic through the tunnel, an SSL VPN needs to modify the client's route table. Some Edge Client features also interact with DNS and other networking parameters of the client. Because of this, having another VPN client running alongside the Edge Client will usually cause a conflict as each VPN software tries to write the necessary changes to the client's networking configuration. As a result, this is not a supported operation mode for the Big-IP Edge client.

Environment

  • BIG-IP Edge Client
  • Clientless (Browser) connections
  • Third-party VPN clients
    • Cisco AnyConnect
    • FortiClient
    • OpenVPN

Cause
Multiple VPN clients competing for necessary route table adjustments

Recommended Actions

Running multiple VPN clients at the same time is Not supported by BIG-IP Edge client.

3rd party VPN services can often interfere with VPN traffic in the Windows networking stack. It is recommend to disable or uninstalling the 3rd party VPN service and see if that corrects the issue.
