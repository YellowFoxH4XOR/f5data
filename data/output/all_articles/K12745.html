Known Issue

This is the result of a known issue. When an Apple iOS Edge Client connects to a Network Access configuration that has the Force all traffic option enabled and the user terminates the session, BIG-IP APM will still interpret the session as active. This issue does not occur when split tunneling has been enabled for the Network Access configuration.

F5 Product Development is tracking this issue as ID 350383.
