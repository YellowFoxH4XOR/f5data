Topic

This article discusses the importance of the /etc/services file on a BIG-IP system.

Description

By default, the BIG-IP system references the /etc/services file every time the tmm process starts up. If the /etc/services file is missing from the BIG-IP system while the tmm process starts up, the tmm process restarts and logs an error message to the /var/log/tmm file that appears similar to the following example:

notice Could not open file /etc/services for reading.

This behavior persists continuously until the /etc/services file is restored. The tmm process restarts whenever you run one of the following commands on the BIG-IP system:

  • reboot
  • bigstart restart
  • tmsh restart sys service tmm
  • tmsh restart sys service all

Recommendations

Ensure that the BIG-IP system has a valid copy of the /etc/services file before you restart the system.
