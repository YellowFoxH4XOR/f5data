Known Issue

This is the result of a known issue. Memory corruption can occur in the BIG-IP ASM when buffers that are received by the BIG-IP ASM process are summed incorrectly and not freed.

If this issue occurs, the system will log an error message to the /shared/log/asm directory and errors logs that appears similar to the following example:

01310006:3: ASM system failure

In addition, the system will log a memory-related error message to the /shared/log/ts/errors.log file that appears similar to the following example:

Error: free memory entry failed

F5 Product Development tracked this issue as CR69122 and it was fixed in BIG-IP ASM 9.2.4 and 9.3.0. For information about upgrading, refer to the BIG-IP ASM release notes.
