Known Issue

The Master Control Program Daemon (MCPD) ignores changes to the management interface maximum transmission unit (MTU). If you attempt to use the Traffic Management Shell (tmsh), or a bigpipe command in 10.x or earlier, to configure a custom MTU for a management route, the mcpd process does not propagate the new MTU value to the host subsystem. As a result, the management interface retains the default MTU value of 1500.

For example, the following tmsh command should change the MTU for the default management route to 1400:

tmsh modify sys management-route default {mtu 1400}

After you use the previous command and save the configuration, the new MTU value appears in the bigip_base.conf file as follows:

sys management-route /Common/default {
description configured-by-dhcp
gateway 10.10.10.1
mtu 1400
network default
}

The mcpd process should propagate the new setting to the Linux host's routing table as shown in the following ip route command output. For example:

# ip route
default via 10.10.10.1 dev mgmt metric 9 mtu 1400

However, due to the known issue, you will notice that the MTU has retained the default value and does not appear when you run the ip route command:

# ip route
default via 10.10.10.1 dev mgmt metric 9

This issue occurs when the following condition is met:

  • You attempt to use the tmsh utility (or a bigpipe command in 10.x or earlier) to configure a custom MTU for a management route.

Impact

You cannot change the MTU of a management route.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After you modify the MTU, management traffic continues to use the previous MTU value.

Workaround

To work around this issue, you can set a custom MTU for the management interface by using the ifconfig command. To do so, perform the following procedure:

Impact of workaround: The impact of changing the MTU depends on the specific environment. F5 recommends that you test these changes during a maintenance window, and consider the possible impact on your specific environment.

Setting a custom MTU

  1. Log in to the BIG-IP or Enterprise Manager command line.
  2. Use the ifconfig command to set the management interface to the desired MTU by using the following command syntax:

    ifconfig eth0 mtu <mtu_value>

  3. Add the ifconfig command to the /config/startup file.

    Note: For information about configuring the system to run a command at system startup, refer to K11948: Configuring the BIG-IP system to execute commands or scripts upon system startup.
