Known Issue

This is the result of a known issue. When the clientssl profile is configured to request client SSL certificates, the BIG-IP LTM system should request a valid certificate from a client, while always authenticating the client. However, BIG-IP LTM may deny client requests when the client certificate is set to Request in the clientssl profile, and the Trusted Certificate Authorities field is set to None.

F5 Product Development tracked this issue as CR77553 and CR72799, and it was fixed in BIG-IP LTM 9.1.3, 9.3, and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.
