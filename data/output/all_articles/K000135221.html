Description

How to capture LDAPS traffic with tcpdump on the BIG-IP and inspect it using Wireshark.

 

Environment

BIG-IP, BIG-IP APM, LDAPS configured.

 

Cause

You would like to examine decrypted traffic between the BIG-IP and an LDAPS server for troubleshooting purposes.

 

Recommended Actions

  • If you are running BIG-IP v15.0 or later, you can collect an SSL decodable network capture using the "--f5 ssl" tcpdump option. For further details, see K31793632.

  • If you have implemented LDAPS using a BIG-IP APM AAA LDAPS server in pool-mode, you can collect directly the un-encrypted traffic using the tcpdump command below:

tcpdump -nn -s0 -i tmm:h -w /shared/tmp/$(date +%d_%b_%H_%M_%S)_$HOSTNAME.pcap port 636

Note: The command above assumes that the LDAPS traffic flows over standard port 636.

  • If you are running a version of BIG-IP older than v15.0 and you are not using a pool-mode AAA server, you might want to follow the procedure below:

Note: You must have the RSA private key of the LDAPS server in PEM format to successfully decrypt the traffic. Without the private key, the SSL/TLS encryption cannot be decrypted.

 

    1. Capture the network traffic using tcpdump:

      tcpdump -nn -s0 -i 0.0:nnn -w /shared/tmp/$(date +%d_%b_%H_%M_%S)_$HOSTNAME.pcap host x.x.x.x and port 636

      Replace x.x.x.x with ip address of the LDAPS server

    2. Stop the tcpdump capture after you have captured enough traffic.
    3.  Download the captured traffic file in /shared/tmp off the BIG-IP and open the file in /shared/tmp in Wireshark.
    4.  Load the private key in Wireshark:

      Go to "Edit" > "Preferences" > "Protocols" > "TLS".

      Click on "Edit" next to "RSA keys list".

      Add the server's private key by providing the IP address, port (636), protocol (ldap), and the path to the key file.

    5. Analyze the decrypted LDAPS traffic:

 

Now, Wireshark will decrypt the LDAPS traffic using the private key and display the decrypted packets. You can analyze the decrypted traffic and view the LDAP-related details.
