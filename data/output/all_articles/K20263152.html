Description

  • Static BIG-IP's configuration utility [GUI] content are Cacheable and can be accessed offline

Environment

  • BIG-IP GUI

Cause

  • By default, the BIG-IP GUI cache static content for two minutes 
  • BIG-IP GUI doesn't use "Cache control: no cache" and no-store, "prama: no-cache" HTTP header. 
Important: Password information is NOT cached and the login credentials are maintained via a session cookie that is deleted upon closing the browser session.

Recommended Actions

To prevent the GUI caching any static files/content, then you may consider modifying the 'Time To Cache Static Files':
  1. Go to System > Preferences
  2. Expand System Settings by selecting Advance option
  3. Modify Time To Cache Static Files From Configuration Utility
  4. Specify the number of seconds you wish the browser caches static content in the Configuration utility.
    • The range of acceptable values is from 1 to 2,147,483,647
    • The default is 120
      Note: Larger values increase browser responsiveness when using the Configuration utility over slow or unreliable connections, such as a WAN
      Important:  Reducing the value below the Default could increase load on the BIG-IP
  5. Click Update
