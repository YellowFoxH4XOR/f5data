Environment

  • APM
  • EMS
  • Microsoft Intune
  • HTTP 403
  • Azure AD Graph
  • Microsoft Graph

Cause
The lack of 'Azure Active Director Graph -> Application.Read.All' permission or the lack of  'Microsoft Graph -> Application.Read.All' permission depending on APM TMOS version.

Recommended Actions

1) Before TMOS 16.1.X
Make sure that the 'Azure Active Director Graph -> Application.Read.All' permission is added under application in Azure Portal and admin's consent is granted.

Note:
Microsoft announced the end of support timelines for Azure AD Graph API:  Update your applications to use Microsoft Authentication Library and Microsoft Graph API
Due to that, you may be unable to add Azure Active Directory Graph permissions to an application in Azure Portal (the option is greyed out).

The possible workarounds:
Workaround 1:
  1. In Azure Portal, under app configuration to go to 'Add Permissions' -> 'APIs my organisation uses' tab -> then type 'Windows Azure Active Directory' OR '00000002-0000-0000-c000-000000000000’
  2. Choose ‘Windows Azure Active Directory’.
  3. The Admin will be able to add the corresponding 'Application.Read.All' permission name and grant admin's consent.
Workaround 2:
To add permission via Azure CLI as mentioned on GitHub community talk:
Unable to add Azure Active Directory Graph permissions to an application in Azure Portal #19818
Workaround 3:
Check with Microsoft support for how to add the Azure AD Graph permission
 
2) After TMOS 16.1.X
Instead of 'Azure Active Director Graph -> Application.Read.All' permission, make sure that the 'Microsoft Graph -> Application.Read.All' permission is added under application in Azure Portal and admin's consent is granted.
