K10765728: BIG-IP randomly responds its base MAC or management interface's MAC to peers for management access, if AOM IP is the same as management IP

Type
Support Solution
Published
2022-10-11
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K10765728

Description

Always-On Management (AOM) is a separate subsystem that provides lights-out management for the BIG-IP system using the 10/100/1000 Ethernet management port over secure shell (SSH) or the serial console.

In addition, the AOM IP address must be different than the BIG-IP management address, but on the same IP subnet, according to K11400446: Configuring AOM network access (i2000, i4000, i5000, i7000, and i10000 series platforms).

However, randomly responds its base MAC or management interface's MAC to peers for management access, if all of the following conditions are met:

  • You have configured the IP address for AOM network.
  • The IP address of AOM is the same as Management IP.

Environment

  • Always-On Management (AOM)
  • Management IP
  • MAC address

Cause

BIG-IP uses base MAC for AOM IP, and management interface's MAC for management IP respectively. If they are having the same IP address, BIG-IP may randomly respond its base MAC or management interface's MAC to peers for management access.

Recommended Actions

To resolve this issue, you may need to choose one of the methods below:

  • Change AOM IP to be different from management IP
  • Disable the AOM network configuration if you no longer requires AOM access over the network, by configuring 0.0.0.0 for the IP address.
          Note: The removal of the AOM IP address will take effect immediately after performing the steps described in this section.

To accomplish either of the two methods, you may refer to the two knowledge articles below, by accessing AOM command menu first and configuring AOM network access correspondingly.

  • K14594: Accessing the AOM Command Menu
  • K11400446: Configuring AOM network access (i2000, i4000, i5000, i7000, and i10000 series platforms)

Note: This is a separate account that is created on the AOM subsystem, and does not exist in the BIG-IP configuration. This account does not exist on the AOM subsystem by default.
