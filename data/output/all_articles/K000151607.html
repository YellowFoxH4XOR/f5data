Description

Is Container Ingress Services (CIS) 2.x compatible with Openshift 4.17, 4.18 and 4.19?

Environment

  • CIS
  • Openshift
  • K8s

Cause

This is a functional question.

Recommended Actions

CIS 2.20 supports operator for OCP 4.17 and 4.18.

CIS 2.21 Supports operator OCP 4.19. Tentative timelines for the release of CIS 2.21 is September 2025 at the time of publishing this article.
