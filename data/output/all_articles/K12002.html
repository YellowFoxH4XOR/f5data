Issue

If you use the image2disk command to install a BIG-IP version 10.1.0 or 10.2.0 hotfix from a BIG-IP version 9.x boot location, the installation will fail. In addition, the system will report error messages that appear similar to the following example to the system console:

warning: System has no isoinfo utility; guessing that /shared/images/Hotfix-BIGIP-10.1.0-3367.0-HF1.iso is a product image.
Terminal error: Hotfix requested, but /shared/images/Hotfix-BIGIP-10.1.0-3367.0-HF1.iso is not a hotfix (type is: product)

If you encounter this error message, perform the appropriate alternative installation procedure from K11033: Managing BIG-IP version 10.1.x and 10.2.x hotfixes on systems using the partitions disk formatting scheme.
