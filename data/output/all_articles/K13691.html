Known Issue

A BIG-IP APM network access tunnel client compresses sent data when compression level is set to zero (0).

This issue occurs when all of the following conditions are met:

  • GZIP Compression is enabled on the network access resource.
  • The connectivity gzip Compression Level profile is set to 0.

Impact

Clients may experience poor performance.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Clients may experience poor performance.
  • The client connection compression status displays a sent percentage that is greater than 0.
  • The client connection compression status displays a received percentage of 0.

Workaround

To work around this issue, you can disable the compression setting in the network access resource. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Access Policy.
  3. Click Network Access.
  4. Click the name of the network access resource to edit.
  5. From the Compression box, select No Compression.
