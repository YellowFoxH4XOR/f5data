Known Issue

This is the result of a known issue. Windows XP users that are running Internet Explorer 8 (IE8) may encounter issues with Protected Workspace (PWS). PWS will fail to launch automatically and cannot be launched manually. The issue only occurs when Windows XP Service Pack 2 (SP2) has been installed and users are running IE8.

F5 Networks Product Development is tracking this issue as CR97086.

Workaround

Users may work around this issue by installing Windows XP Service Pack 3 (SP3), using an earlier version of Internet Explorer, or using a different supported browser (such as Firefox).
