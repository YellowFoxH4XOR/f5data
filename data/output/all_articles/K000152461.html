Description

How to obtain a complete list of all DNS names (including Wide IPs, BIND zones, and other DNS records) configured on a BIG-IP LTM VE system. This includes all DNS entries regardless of environment or naming convention. No specific error messages are associated with this request.

Environment

  • DNS and/or GSLB provisioned
  • May include BIND, DNS Express, DNS Cache, and iRules configurations

Cause

None

Recommended Actions

To obtain a comprehensive list of all DNS names/records on BIG-IP:

1. Wide IPs (GSLB/GTMs):
- GUI: Navigate to DNS > GSLB > Wide IPs > Wide IP List.
- CLI: Review the /config/bigip_gtm.conf file for entries beginning with gtm wideip using the command below:
# cat bigip_gtm.conf | grep "gtm wideip"

2. BIND DNS Zones and Records:
- GUI: Go to DNS > Zones > ZoneRunner > named Configuration.
- CLI: Check /etc/named.conf for zone definitions.
- For detailed records, review files in /var/named/config/namedb/

3. DNS Express:
- GUI: Check DNS > Zones > Zone List for zones managed by DNS Express.

4. DNS Cache:
- GUI: Review DNS > Caches > Cache List for any configured DNS caches.

5. iRules:
- Review any iRules that may be configured to respond to specific DNS queries or hostnames.
