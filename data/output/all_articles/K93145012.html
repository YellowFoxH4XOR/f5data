Known Issue

The BIG-IP system may not update the MCP database correctly after you have deleted a software image.

This issue occurs when all of the following conditions are met:

  • You have uploaded the software image and hotfix files to a BIG-IP system.
  • You remove the software image file before you perform a hotfix installation.

    For example, you perform the hotfix installation to an inactive boot location by using the following command syntax:

    tmsh install /sys software hotfix <hotfix> volume <boot_location> create-volume

When you delete the base software image file from the system, installing the hotfix to an inactive boot location fails, as expected. However, the system generates additional error messages when the lind process fails to correctly update the MCP database.

Impact

The hotfix installation fails, as expected, but the BIG-IP system continuously logs additional error messages to the /var/log/ltm file.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to proceed with the hotfix installation.
  • You notice log messages that appear similar to the following example are continuously logged to the /var/log/ltm file:

    notice lind[<PID>]: 013c0006:5: Image (BIGIP-<version>.iso) has a software image entry in MCP database but does not exist on the filesystem

Workaround

There is no workaround. However, you can recover from this issue by importing the required software image file back to the BIG-IP system, and then restarting the lind service and performing the hotfix installation again. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Import the software image to the /shared/images directory of the BIG-IP system using the procedure from K175: Transferring files to or from an F5 system.
  2. Log in to the command line of the BIG-IP system.
  3. Restart the lind service by typing the following command:

    tmsh restart /sys service lind

  4. Perform the hotfix installation again.
