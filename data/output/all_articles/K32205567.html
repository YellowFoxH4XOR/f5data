K32205567: Cannot edit BIG-IP VE disk configuration on VM in vSphere

Type
Support Solution
Published
2022-07-11
Updated
2026-07-17
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K32205567

Description

  • Unable to edit the VM settings for an BIG-IP VE in VMware vSphere
  • VM cpu/memory settings can be edited but disk setting is greyed out

Environment

  • BIG-IP VE
  • VMware vSphere
  • Virtual disk

Cause

 The VM has a snapshot and VMware does not permit resizing disks when a snapshot is in use.

Recommended Actions

Remove VM snapshot from hypervisor

Additional Information

None
