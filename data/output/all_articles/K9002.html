Known Issue

This is the result of a known issue. Starting in July 2008, F5 Networks began manufacturing the BIG-IP 6800 and 6400 platforms with dual AMD Opteron 252 CPUs. Prior to July 2008, the BIG-IP 6800 and 6400 platforms shipped with dual AMD Opteron CPUs that have since reached their End of Life.

F5 Networks has thoroughly tested the new Opteron CPUs on the 6800 and 6400 platforms and has determined that a hotfix is required in order to properly run versions 9.1.2, 9.1.3. This issue does not affect the 9.2.x, 9.3.x, and 9.4.x software branches.

Note: To avoid this issue, F5 Networks recommends running the latest version of 9.3.x or 9.4.3 or later software on BIG-IP 6800 and 6400 platforms with the AMD Opteron 252 CPUs.

If you install BIG-IP versions 9.1.2 or 9.1.3 software on a BIG-IP 6800 or 6400 platform with the AMD Opteron 252 CPUs, you will experience the following symptoms:

  • TMM is unable to detect the correct link status for the internal interfaces. As a result, a switchboard failsafe event occurs and the TMM process will restart.
  • The Cavium SSL cards will not function. As a result, the following errors are logged to the /var/log/ltm file:

    tmm tmm[770]: 01010025:2: Device failure: cn0: invalid core set

    tmm tmm[770]: 01010025:2: Device failure: cn0: attach failure
  • TMM improperly detects the 6800 platform CPU speed as 0.04 GHz, causing the CPU utilization to spike to 100 percent. As a result, the following informational message is logged to the /var/log/tmm file:

    default TMM Version 9.1.2.40.0.0 (2x0.04GHz AuthenticAMD) 3804MB @ 228MB

    Note    : TMM should report the 6800 CPU speed as 2.38 GHz.
  • TMM improperly detects the 6400 platform CPU speed as 0.3 GHz, causing the CPU utilization to spike to 100 percent. As a result, the following informational message is logged to the /var/log/tmm file:

    default TMM Version 9.1.2.40.0.0 (2x0.03GHz AuthenticAMD) 3804MB @ 228MB

    Note: TMM should report the 6400 CPU speed as 2.2 GHz.

F5 Networks Product Development is tracking this issue as CR100608.

F5 Networks Product Development has issued an engineering hotfix that resolves this issue for BIG-IP versions 9.1.2 and 9.1.3. To obtain this hotfix, contact F5 Networks Technical Support, referencing this Solution number and CR100608.
