Description

The issue involves the BIG-IP SSL Orchestrator (SSLO) resetting connections with the error message:

Cause: Failed to find service cmp info.

Cause: Failed to find sync data.

This occurs when SSLO receives an HTTP request from the Service and subsequently resets the connection, as the server side connection was closed already.

Environment

  • BIG-IP SSLO
  • Inline L2 / L3 Service

Cause

The Inline L2 Service or Inline L3 service did not close the connection properly, the server side connection was closed, but the client side connection is still established. When client send more request to the SSLO, SSLO forward the data to the service, and the service re-create connection to SSLO, send the HTTP request to the SSLO, but SSLO cannot send the HTTP request to the server.

For example:

The client create the connection to the SSLO, then SSLO create the connection to the service and then to the server, now it is normal. The data path is:

Client === SSLO === Inline L2 / L3 service === SSLO === Server

BIG-IP receive the FIN from the server, forward the FIN to the service, but the service did not forward the FIN to SSLO. Now the Inline service remain the client side connection and close the server side connection.

The client send more HTTP request to the SSLO, SSLO forward to the service, now the service create new connection to SSLO, send the HTTP request to SSLO, this issue will happen.

Recommended Actions

Please make sure the Inline L2 / L3 Service is working as L2 / L3 device, forward the FIN / RESET when closing the connection.
