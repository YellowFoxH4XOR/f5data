Known Issue

Loading a single configuration file (SCF) on the BIG-IP system may fail.

This issue occurs when all of the following conditions are met:

  • You save an SCF backup using the one-line command option.
  • The BIG-IP configuration contains an iRule.

Impact

Users are unable to load the SCF backup on the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to load an SCF backup, you receive an error message similar to the following example:

    BIGpipe rule creation error:
    01070151:3: Rule [...] error:

Resolution

Status

Workaround

There is no workaround for this issue. However, to mitigate the issue, you can avoid using the one-line command option when saving an SCF backup.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
