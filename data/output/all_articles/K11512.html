Known Issue

This is the result of a known issue. The Allow Custom Port Lockdown setting in the Configuration utility does not accept the valid values All or None when configuring custom port lockdown lists for the TCP or UDP protocol. If you attempt to do so, the BIG-IP system reports the following error message:

Invalid service port error

F5 Product Development tracked this issue as ID 224797 (formerly CR137732) and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

You can work around this issue by specifying port 0 instead of All, and by specifying port 65535 instead of None.

Alternatively, you can enter the bigpipe self command at the BIG-IP command line:

  • To allow access to all ports over a specific transport protocol, use the following syntax:

    bigpipe self <selfIP> allow <proto> all
  • To prevent access to all ports over a specific transport protocol, use the following syntax:

    bigpipe self <selfIP> allow <proto> none

Note: In both commands, replace <selfIP> with the self IP address for which you want to create a custom port lockdown list, and replace <protp> with the appropriate transport protocol: TCP or UDP.
