K000149501: Migrate BIG-IP license from BIG-IQ LOAD/CAT license offerings to MyF5 Self Service license keys

Type
Support Solution
Published
2025-01-31
Updated
2026-09-08
Applies to
  • BIG-IP
  • Virtual Editions
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K000149501

Description

The BIG-IP from LOAD/CAT license offerings from the previous Flex Consumption Program (FCP) contract are about to expire and you need to migrate to MyF5 Self Service license keys.

Environment

  • FCP Contract after January 13th, 2025
  • Expiring CAT/LOAD license offerings on BIG-IQ
  • License key from MyF5 Self Service
  • BIG-IP Virtual Edition (VE)

Cause

The BIG-IP license settings cannot be updated on the BIG-IP if it's licensed by a BIG-IQ. The license must be revoked from the BIG-IQ to allow license updates directly on the BIG-IP VE. After the BIG-IQ CAT license offering is revoked, apply the new MyF5 license directly to the BIG-IP VE.

Recommended Actions

From the BIG-IQ, revoke the license offering for the BIG-IP VE then apply the MyF5 Self Service license key directly on the BIG-IP VE.
Important: Applying a license impacts traffic on the BIG-IP as its service restart to process the new license.

  1. Create the new license key from MyF5 Self Service.
    • Generate Self Service license keys in MyF5
  2. Revoke the license offering for this BIG-IP from the BIG-IQ. 
    Important: The BIG-IQ/CAT license offering must be revoked first. If revoked after applying the new MyF5 license key to the BIG-IP, the BIG-IQ removes the new MyF5 license, which is traffic impacting.
    Note: Additionally, revoking the BIG-IQ/CAT license offering enables the license option from the WebUI on the BIG-IQ and avoids duplicate billing. 
    • Revoke BIG-IP Virtual Edition licenses from the BIG-IQ
    • If the BIG-IQ isn't available, follow Reactivate BIG-IP VE license when BIG-IQ isn't available
  3. Apply the new license key from MyF5 Self Service to the BIG-IP. 
    • License the BIG-IP system
  4. Generate Historical Report on BIG-IQ once the relevant licenses are revoked and email the report to vesubscriptions@f5.com.
    • Collect Historical Report for revoked licenses
  5. Confirm all license offerings for a CAT/LOAD are revoked before decommissioning the CAT/LOAD key or BIG-IQ, otherwise, duplication could occur in the utilization reports.

Additional Information

The BIG-IQ/CAT license offering must be revoked first. If revoked after applying the new MyF5 license key to the BIG-IP, the BIG-IQ removes the new MyF5 license, which is traffic impacting.
