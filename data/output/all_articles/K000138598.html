Description

Radius Authentication for remote user accounts logging into the F5OS management interface fails when attempting to login to the webUI. However, logging into the CLI is successful.

Environment

  • F5OS-A
  • Remote User authentication using Radius

Cause

F5 attribute group IDs are required to be present on the external Radius server.
If these are missing, then the Radius server may reject or not respond to authentication requests, when logging into the F5OS webUI.

Recommended Actions

These group IDs are specified in a user configuration file on the external server (file locations vary on different servers).
You must assign these F5 user attributes on the external server:

F5-F5OS-UID=1001
F5-F5OS-GID=9000
F5-F5OS-HOMEDIR=/tmp
F5-F5OS-USERINFO=test_user
F5-F5OS-SHELL=/var/lib/controller/f5_confd_cli

Additional Information
