Description

GUI/Configuration Utility disclose vulnerability due to the ETag header providing sensitive information that could aid an attacker, such as the inode number of requested files. Scanner/3rd party can find similar to below contents.


  File modification time : MMM. DD, YYYY at HH:MM:SS GMT
  File size              : * bytes
  Inode number           : <inode_number>
  Source                 : ETag: ""<Etag_number>""

 

Environment

  • BIG-IP v11.x -14.0.x
  • Configuration Utility / GUI
  • HTTP header
  • Etag
  • inode
     

Cause

14.0.x and before are using older version of Apache.
 

Recommended Actions

Follow K14206: Configuring the BIG-IP system to exclude inode information from Etags (11.x - 14.0.x)
