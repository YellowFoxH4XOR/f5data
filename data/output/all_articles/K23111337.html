Topic

You should consider using this procedure under the following condition:

  • You want to set the value for DNS header flags using iRules.

Description

The BIG-IP DNS system has a set of iRules available for applying on DNS streams. You can create an iRule to change the DNS header flag value for a DNS request before the BIG-IP DNS system forwards the request to its destination.

You can use the following DNS events and key command to build the iRule:

  • The DNS_REQUEST event is triggered when the BIG-IP DNS system processes a DNS request.
  • The DNS_RESPONSE event is triggered when the BIG-IP DNS system responses to a DNS request.
  • The DNS::header command sets the value for the given flag name with the following syntax:

    DNS::header <flag> <value>

    For example, the following command sets the recursion desired (rd) flag to 0:

    DNS::header rd 0

The supported header flags for the DNS::header command are defined as follow:

FlagDescriptionValue
qrSpecifies that if the message is a query (0), or a response (1)0 - 1
opcodeSpecifies the type of the queryString1
aaSpecifies if the response is an authoritative answer0 - 1
tcSpecifies if the message is truncated0 - 1
rdSpecifies if recursion is desired0 - 1
raSpecifies if recursion is supported0 - 1
adSpecifies if the data included has been verified by the server (DNSSEC)0 - 1
cdSpecifies if non-verified data is acceptable to the resolver (DNSSEC)0 - 1
rcodeSpecifies the response codeString1

1To set opcode and rcode, refer to the supported flag strings in the F5 Cloud Docs DNS::header iRules page.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP Configuration utility.
  • The BIG-IP system has DNS module licensed and provisioned.
  • You have a DNS listener configured on the BIG-IP DNS system.

Procedures

Creating an iRule to set DNS header flag

To create an iRule to set the value for DNS header flag, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to DNS > Delivery > iRules > iRule List.
  3. Select the Create button.
  4. For Name, type a name for the iRule.
  5. For Definition, enter the DNS iRule code.

    For example, the following iRule code sets the recursion desired (rd) flag to 0:

    when DNS_REQUEST {
      DNS::header rd 0
    }

  6. Select the Finished button.

Applying the iRule to a DNS listener

To apply the previously created iRule to a DNS listener, perform the following procedure:

Impact of procedure: The suggested procedure alters the content of DNS messages and the impact depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Go to DNS > Delivery > Listeners > Listener List.
  3. Select the name of the listener you want to apply the iRule.
  4. Select the iRules tab.
  5. For iRules, select Manage.
  6. In the Available list, select the iRule you previously configured, and move it to the Selected list.
  7. Select the Update button.
