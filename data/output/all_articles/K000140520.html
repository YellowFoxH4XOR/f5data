Environment

  • Two or more BIG-IP DNS are in a DNS sync group with zone sync enabled
  • The more zones are configured, the higher the reproducibility would be
  • Configuration changes happen on more than one BIG-IP DNS

Cause

When BIG-IP DNS configuration changes are made on two or more BIG-IP DNS devices, some of devices may not be able to perform incremental sync and triggers full sync due to ID 1100197, which in turn triggered ID 920817.

Recommended Actions

  • When zrd is continuously restarting, follow K10066 to remove .jnl files from all the affected BIG-IP DNS systems to recover from the state.
  • Make configuration changes related to BIG-IP DNS only on one of devices in the sync group to prevent it from occurring.
  • Upgrade to a version with the fix of ID 1100197 to prevent it from occurring.
