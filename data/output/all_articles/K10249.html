K10249: The BIG-IP Configuration utility generates an error message when resetting the statistics for a pool that has a member in a route domain

Known Issue

This is the result of a known issue. When you attempt to reset the pool statistics for a pool that has a member in a route domain, the BIG-IP Configuration utility generates the following error message:

An error has occurred while trying to process your request

If the pool member is not part of a route domain, the system does not log an error message.

F5 Product Development tracked this issue as ID 209029 (Formerly CR 123445) and it was fixed in BIG-IP LTM 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.
