K66448902: Unable to generate qkview from Configuration Utility

Support Solution

Description

  • When trying to generate a qkview from the configuration utility the following error is displayed:
    • URI path /mgmt/tm/sys/diags/ihealth-request not registered. Please verify URI is supported and wait for /available suffix to be responsive.
  • When trying to generate the qkview from CLI, it generates a file, however, its 10% of expected size and cannot be opened.
  • Restjavad process is frequently restarting. The following messages are logged on var/log/daemon.log
    Jul  1 03:07:10 LTM1.example.com emerg logger[31027]: Re-starting restjavad
    Jul  1 03:07:23 LTM1.example.com emerg logger[31602]: Re-starting restjavad
    Jul  1 03:07:38 LTM1.example.com emerg logger[32125]: Re-starting restjavad

Environment

  • BIG-IP set up to use an http REST API.

Cause

Unknown

Recommended Actions

  1. Connect to CLI
  2. Restart restjavad processes.
    bigstart restart restjavad

Additional Information

None
