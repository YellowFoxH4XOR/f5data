Description

  • d11d0004:3: Disk partition /var has only 0% free

Environment

  • Many UCS files in /var/local/ucs

Cause

  • Many large UCS files filling up /var partition

 Recommended Actions

  1. Check /var/local/ucs for old or large UCS files
  2. Delete or copy files to external disk
  3. Consider resize the /var partition

K34126971: Extending /var disk space on appliances.
