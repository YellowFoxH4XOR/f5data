Cause

 Recommended Actions

  1. Touch the screen to activate the LCD menu.
  2. Tap on System field:
  4. Choose interesting you reboot/reset option from display screen:
  6. Tap Confirm to proceed with chosen feature.

Additional Information

Soft Reboot:
Soft Reboot performs a graceful reboot of the unit.
This is same as runing 'reboot' on the commandline.
A reboot command run from the CLI will have the same effect as a reboot on any other UNIX/Linux OS. 
All system processes will be shutdown and the device inaccessible (except via serial console).


Hard Reset:
Hard Reset performs a hard reset on the unit.
This is same as hitting the reset button on a desktop PC - unclean reboot of the system. 
File system errors and file system check would likely be performed during that.
