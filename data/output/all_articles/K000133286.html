Description

Howt to disable named daemon when not using it

Environment

  • BIG-IP
  • named -- named is the daemon (or background process) that operates as the DNS server for BIND.

Cause

Disabling named may mitigate security concerns.

 Recommended Actions

Below are the steps to stop a named daemon using CLI commands.

Each command is highlighted in grey, while the expected output is included right below each command for verification.

  1. Restart named daemon  
    bigstart stop named
    Stopping named (via systemctl):                           [ OK ]
  2. Disable the service
     systemctl disable named.service
    Removed symlink /etc/systemd/system/multi-user.target.wants/named.service.
  3. Take a backup of the file for future reference.
    mv /etc/init.d/named /etc/init.d/named.bak
  4. Check the status of the named by running the below command
    bigstart status named
    Couldn't find service: named
  5. Additional steps, perform only in maintenance window.  
    While it is not necessary to reboot to complete this process, if you would like to demonstrate that the BIG-IP unit will now restart and not start up named, you can do this:
    reboot
    bigstart status named
    Couldn't find service: named

    Note: Procedure listed above will survive a reboot, however, it needs to be re-disable after a software upgrade
