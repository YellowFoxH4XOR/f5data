Topic

User-defined attack signatures are created by a BIG-IP ASM administrator and added to the attack signature pool. When creating user-defined attack signatures, you can use the pipe symbol ( | ) to escape special characters that cannot be represented in the attack signature rule argument. The hexadecimal equivalents for the ASCII characters to be escaped should be placed between two pipe characters, and each hexadecimal value must be delimited by a space character.

For example, the |22 22| string in the following user-defined attack signature rule represents two double quotation marks and matches the ABC""XYZ string:

content:"ABC|22 22|XYZ";

Whereas the string ABC" "XYZ would be matched by the following rule where the escaped hexadecimal values represent two double quotation marks separated by a space:

content:"ABC|22 20 22|XYZ";

Note: For information about a known issue regarding escape characters in user-defined attack signatures, refer to to K12667: User-defined attack signature escape sequences are not validated.

Note: For more information about managing user-defined attack signatures and working with escape characters, refer to the BIG-IP ASM Configuration Guide.
