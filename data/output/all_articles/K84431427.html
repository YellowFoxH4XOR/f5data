Topic

You should consider using this procedure under the following conditions:

  • You want to install Docker on Centos/Redhat Enterprise Linux (RHEL) 7 with packages from the Red Hat repository to run Kubernetes for NGINX Controller.
  • Your Centos/RHEL server 7 does not have an internet connection to download RPM packages from the Red Hat repository.

Description

When setting up NGINX Controller, you may be required to run Docker instead of Docker CE and use only RPM packages from the Red Hat repository in your production environment. To install Docker on your offline server, first download the required RPM packages onto an online server that is connected to the Red Hat repository, and then transfer the RPM packages to your offline server for installation. There are 2 ways to do so:

  • Use yumdownloader to download only Docker and the software that it is directly dependent on, and manually copy the files to the offline server for installation. This method requires that the software packages and versions installed on both your online and offline servers are identical. This ensures that yumdownloader downloads all the required RPM packages required by the offline server.
  • Mirror the repositories on your online server to provide packages for your offline servers. This method automatically resolves any package dependency issues during installation and is useful when the RPM packages installed on your offline server are not identical to the online server and require a significant number of updates and new packages. However, this method requires a significant amount of disk space on your online system. For more information, refer to How to mirror a repository in Linux.

This article describes the steps required for the first method.

Note: You must install a Docker version that is compatible with a Kubernetes version that the NGINX Controller supports. In this article you install Docker 1.13.1, which is supported by Kubernetes 1.15.5 for NGINX Controller. For more information on Docker and Kubernetes requirements for NGINX Controller, refer to the Docker Requirements and Kubernetes Requirements section of the NGINX Controller Admin guide.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Have a Centos/RHEL server with a valid subscription ID that is registered with a Red Hat entitlement server and has an internet connection to access the Red Hat repository.
  • Have administrative access on the online Centos/RHEL server to register and enable Red Hat repositories.
  • Have at least sudo privileges on the offline Centros/RHEL server.
  • Make sure the online Centos/RHEL server runs the same Operating System as the offline server on which you want to install Docker.
  • Make sure the RPM software packages and versions installed on both online and offline systems are identical.

Procedures

To install Docker for production on an offline Centos/RHEL 7 server, perform the following procedures:

Impact of procedures: Performing the following procedures should not have a negative impact on your system.

  • Register your online Centos/RHEL 7 server
  • Enable the required Red Hat software repositories
  • Download the required RPM packages for Docker
  • Copy the RPM packages from the online Centos/RHEL 7 server to the offline server
  • Install Docker 

Register your online Centos/RHEL 7 server

To register your system and enable the Red Hat repositories, perform the following procedure on a Centos/RHEL system that has an internet connection.

  1. Log in as root to the command line shell of your Centos/RHEL 7 server.
  2. To register your system, enter the following command:

    subscription-manager register

  3. When prompted, enter your username and password.

    These are your login credentials for the Red Hat Customer Portal.

  4. To display a list of all subscriptions that are available for your system, enter the following command:

    subscription-manager list --available

  5. To attach the pool ID of a pool that meets the requirement, use the following command syntax:

    subscription-manager attach --pool=<pool_id>

Enable the required Red Hat software repositories

Red Hat repositories currently support X86_64 and PowerPC 8 64-bit architectures. The following procedure enables repositories for X86_64 architectures. See Supported Architectures for Containers on RHEL to learn the names of PowerPC 8 64-bit repositories.

  1. Log in as root to the command line shell of your Centos/RHEL 7 server.
  2. To enable the repositories required to download Docker and its related software packages, enter the following commands:

    subscription-manager repos --enable=rhel-7-server-rpms
    subscription-manager repos --enable=rhel-7-server-extras-rpms
    subscription-manager repos --enable=rhel-7-server-optional-rpms

Download the required RPM packages for Docker

To download the RPM packages for Docker and its dependencies on your online Centos/RHEL system, perform the following procedure:

  1. Log in to the command line shell of your Centos/RHEL 7 server.
  2. To gain sudo privilege, enter the following command:

    sudo -s

  3. To install YUM utilities so that the online server can download packages correctly, enter the following command:

    yum install -y yum-utils

  4. To display the list of Docker versions in the Red Hat repositories, enter the following command:

    yum list docker --showduplicates | sort -r

  5. You may observe output similar to the following truncated example:

    Loaded plugins: product-id, search-disabled-repos, subscription-manager
    Installed Packages
    docker.x86_64      2:1.13.1-96.gitb2f74b2.el7          rhel-7-server-extras-rpms
    docker.x86_64      2:1.13.1-94.gitb2f74b2.el7          rhel-7-server-extras-rpms
    docker.x86_64      2:1.13.1-91.git07f3374.el7          rhel-7-server-extras-rpms
    [...]

  6. To download Docker, use the following command syntax:

    Note: This command downloads the Docker version that is the default for the current release of RHEL. This is the stable version of Docker that is compatible with the current versions of Kubernetes and OpenShift, available with Red Hat Enterprise Linux. 

    yumdownloader --assumeyes --destdir=<destination> --resolve docker

    Note: You can also download a specific Docker version. For example:
    yumdownloader --assumeyes --destdir=<destination> --resolve docker-1.13.1

    For example, to download and save the Docker packages to the /home/john/docker directory, enter the following command:

    yumdownloader --assumeyes --destdir=/home/john/docker --resolve docker

  7. To download the Docker dependencies RPM packages, use the following command syntax:

    yumdownloader --assumeyes --destdir=<destination>/yum --resolve yum-utils
    yumdownloader --assumeyes --destdir=<destination>/dm --resolve device-mapper-persistent-data
    yumdownloader --assumeyes --destdir=<destination>/lvm2 --resolve lvm2
    yumdownloader --assumeyes --destdir=<destination>/se --resolve container-selinux

    In the previous syntax, note the following:

    • yum utilities are YUM utilities to download packages correctly.
    • device-mapper-persistent-data and lvm2 are Docker file drivers.
    • container-selinux are SELinux policy files for Container Runtimes.

Copy the RPM packages from the online Centos/RHEL 7 server to the offline server

Copy the RPM packages you downloaded from the Red Hat repository in the previous procedure to the same directory at your offline Centos/RHEL 7 server, for installation.

Install Docker 

To install Docker, perform the following procedure on the system that is offline.

Note: This step installs Docker and the RPM packages that Docker is directly dependent on. If the RPM packages installed on your online and offline servers are not identical, as indicated in the Prerequisites section of this article, you may encounter install errors that require you to update or install RPM packages that these packages are, in turn, dependent on. To do so, you can fulfill the dependency requirements by performing the previous procedure, Download required RPM packages for Docker, to download the additional packages and copy them to the offline server for installation. If your offline server requires significant updates to a large number of packages, you should consider mirroring the repositories on your online server to provide packages for your offline servers as described in the Description section of this article.

  1. To gain sudo privilege, enter the following command:

    sudo -s

  2. To uninstall any old Docker software on the system, enter the following command:

    Note: It is OK if you observe messages stating that there is no match for any Docker software and no packages are marked for removal.

    yum remove docker \
    docker-ce \
    docker-client \
    docker-client-latest \
    docker-common \
    docker-latest \
    docker-latest-logrotate \
    docker-logrotate \
    docker-selinux \
    docker-engine-selinux \
    docker-engine

  3. To install YUM utilities, use the following command syntax:

    yum install -y --cacheonly --disablerepo=* <rpm_directory>/yum/*.rpm

  4. To install Docker file drivers, use the following command syntax:

    yum install -y --cacheonly --disablerepo=* <rpm_directory>/dm/*.rpm
    yum install -y --cacheonly --disablerepo=* <rpm_directory>/lvm2/*.rpm

  5. To install the container-selinux, use the following command syntax:

    yum install -y --cacheonly --disablerepo=* <rpm_directory>/se/*.rpm

  6. To install Docker, use the following command syntax:

    yum install -y --cacheonly --disablerepo=* <rpm_directory>/docker/*.rpm

  7. To enable and start the docker service, enter the following commands:

    systemctl enable docker
    systemctl start docker

  8. To verify your Docker version, enter the following commands:

    systemctl status docker
    docker version
