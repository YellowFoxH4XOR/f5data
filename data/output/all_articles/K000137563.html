Description

When attempting to SSH into the BIG-IP system as the admin user, the admin password is accepted but the ssh session is ended and you are not logged in

Environment

Relevant environmental factors specific to the topic
  • BIG-IP system
  • A valid admin user and password is used

Cause

The admin account does not have Advanced Shell access enabled.  You can confirm this in either tmsh or the GUI
tmsh: 
tmsh list auth user admin
 In the GUI, (1) navigate to System >> Users, find the admin user and (2) look at the Terminal Access setting.

Recommended Actions

The following recommended actions will allow the admin user to have access to the Bash shell.

If you wish to enable ssh access for the admin user, you can change the Terminal Access field in the GUI from Disabled to "Advanced Shell".

Or, at the command prompt while logged in as root: 
tmsh modify auth user admin shell bash
tmsh save sys config
