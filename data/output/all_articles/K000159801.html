Description

You are trying to import/re-import BIG-IP configurations in BIG-IQ. You are unable to do so and get below error message:

Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.RuntimeException: not authenticated 

Environment

  • BIG-IQ
  • Managed BIG-IP

Cause

There is mismatch with the log filter settings. Example, BIG-IPs have no publisher or descriptions or different log filter assigned comparing to configuration present in BIG-IQ.

Answer/Recommended Actions

Match the log filter settings - filter, publisher, description, etc.

Example BIG-IP-A and BIG-IP-B has no log publisher for the filter but it exist in BIG-IQ.

1) Add publisher on both BIG-IP A and B or remove publisher on the BIG-IQ

2) Re-discover and re-import configuration for example BIG-IP-B. You might see different error message. For example:

Failed to synchronize clustered devices; reason: Worker http://localhost:8100/cm/adc-core/working-config/net/tunnels/tunnel failed validation with status 500: com.f5.rest.workers.configmgmtbase.config.WorkingCollectionHelper$ConfigItemInUseException: /Common/http-tunnel is in use by Route Domain '/Common/0'.

3) Re-discover and Import configuration on BIG-IP-A. Configuration should be successfully imported.

4) Re-discover and Import configuration on BIG-IP-B. Configuration should be successfully imported.

Additional Information

Sometimes BIG-IP log filter will have a specific source which does not exist on BIG-IQ. BIG-IQ will have an empty source. This is seems to be fine and import works even though the "source" is not matching.
