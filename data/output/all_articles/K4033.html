Topic

3-DNS uses an internal database for geo-targeting. 3-DNS does not support external geo-targeting databases with topology load balancing.

It is possible to enter geo-targeting data by using a user-defined region. Refer to the Topology chapter of the 3-DNS Reference Guide for specific information about topology load balancing and user-defined regions.
