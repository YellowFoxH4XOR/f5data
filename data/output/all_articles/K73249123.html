Description

After enabling variable tm.tcpsendrandomtimestamp, configuration utility is unstable.
Connection to the GUI (Configuration Utility) keeps disconnecting and also when navigating to Device management >> Overview, nothing is displayed.

Environment

  • BIG-IP 
  • Configuration Utility
  • HA

Cause
Bug ID 853613: Improve interaction of TCP's verified accept and tm.tcpsendrandomtimestamp

Recommended Actions

After enabling the variable tm.tcpsendrandomtimestamp, please apply the following workaround:

Important: The bigstart restart command temporarily interrupts traffic processing. If the system is configured as part of a HA pair, the device may fail over. F5 recommends that you perform this procedure during a scheduled maintenance window.

  1. Create /config/tmm_init.tcl
    vi /config/tmm_init.tcl

  2. Insert the following entries:
    profile tcp _cgctcp_out {

        auto_nagle          disabled
        ack_on_push         enabled
        fin_wait_timeout    5
        close_wait_timeout  5
        idle_timeout        10
        keep_alive_interval 5
        sndbuf              131072
        rcvwnd              65535
        verified_accept     false
        syn_maxrtx          3
        maxrtx              4
        timestamps          1
    }
    profile tcp _cgctcp_in {
        auto_nagle          disabled
        ack_on_push         enabled
        fin_wait_timeout    5
        close_wait_timeout  5
        idle_timeout        10
        keep_alive_interval 5
        sndbuf              131072
        rcvwnd              65535
        syn_maxrtx          3
        maxrtx              4
        timestamps          1
    }

  3. Save the file

  4. Run the following command:
    # bigstart restart

  5. Repeat the process in all the HA members

  6. Now you should refresh your browser to test the WebUI (Configuration Utility)
