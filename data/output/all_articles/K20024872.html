Topic

This article applies to rSeries systems. For more information about other systems, refer to the following articles:

    • K05531172: Restoring the VELOS configuration to factory default settings
    • K13127: Restoring the BIG-IP configuration to factory default settings (11.x - 17.x)

You should consider using this procedure under the following condition:

    • You want to restore the rSeries system configuration to the factory default settings.

Description

You can restore the configuration of the rSeries system to the factory default settings using the system database reset-to-default command. When you run the system database reset-to-default command, the system deletes all tenant and user configuration and loads the default configuration into the running database. You will need to perform a one time reboot of the appliance after resetting the system database.

Prerequisites

You must meet the following prerequisite to use this procedure:

    • You have administrative access to the rSeries system serial console.

Procedures

Before resetting the configuration to factory default settings, back up the current configuration. For more information about backing up the configuration on rSeries systems, refer to K47512994: Back up and restore the F5OS-A configuration on an rSeries system.

To restore the rSeries system to the default configuration settings, perform the following procedure:

Impact of procedure: Performing the following procedure removes the current configuration from the rSeries system, loads the default configuration and reboots the appliance.

    1. Log in to the rSeries system command line interface as the administrator user.
    2. Enter the configuration mode terminal by entering the following command:

      config

    3. Reset the system to the default settings by entering the following command:

      system database reset-to-default

      The system prompts you to select either yes or no, as displayed in the following example. Entering yes instructs the system to boot to the default settings:

      Removing all user configuration will delete all tenants and stop traffic processing.
      Proceed? [yes/no]:

    4. Confirm that you want the system to load the default settings by entering the following command:

      Note: Run this command only when you are connected to the rSeries system serial console. If you connected using SSH, the SSH session disconnects.

      yes

    5. After exiting the configuration mode terminal, reboot the appliance by entering the following command:

      system reboot
