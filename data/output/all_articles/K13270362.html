Environment

  • APM policy 
  • AD query / LDAP query on VPE
  • adtest on BIGIP CLI

Cause

LDAP has a limit of returning 1000 Objects in one query (For Microsoft AD)
Note that this limit may vary between different directory services (DS) providers.

Recommended Actions

You may follow one of the below methods to work around this:

  1. Modify the AD query to return results less than 1000 Objects at once, Narrow the search parameter under query. For more information, refer to K11308: Overview of the adtest tool.
  2. Modify the limit on Microsoft AD Server

Important: Please try the below instructions at your own risk. Depending on your setup there may be a negative impact as increasing the returned results can consume more memory/resources on the receiving end.

On the Domain Controller, login in as the domain administrator. Open Command Prompt as administrator and perform the following:

C:\Users\Administrator>NTDSUTIL
NTDSUTIL: ldap policies
ldap policy: connections
server connections: connect to server AD1.example.com

server connections: q
