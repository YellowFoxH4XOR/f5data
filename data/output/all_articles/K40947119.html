Description
If you would like to limit TACACS+ remote user or a group to specific partitions, you can configure the remote role group in TACACS+ configuration and on BIG-IP. If you are using Open Source Linux module, tac_plus, the default configuration may not work. 

Environment

  • TACACS+
  • AAA Protocol
  • TCP or UDP

Cause
None

Recommended Actions

For instance, to configure user group, Administrator (adm) to access all partitions, and Operator (ops) to access the partition ' partition1 ', follow the below procedure to configure. 

  • Assign the appropriate user role value to the group
  • Configure BIG-IP to access the remote role configuration
  • Enable authentication source in BIG-IP

Assign the appropriate user role value to the group:

The configuration looks similar to:

group = adm {
  service = ppp {
    protocol = ip {
      set F5-LTM-User-Info-1 = adm
      set F5-LTM-User-Console = 1
      set F5-LTM-User-Role = 0
      set F5-LTM-User-Partition = all
    }
  }
}

group = ops {
  service = ppp {
    protocol = ip {
      set F5-LTM-User-Info-1 = ops
      set F5-LTM-User-Console = 1
      set F5-LTM-User-Role = 400
      set F5-LTM-User-Partition = partition1
    }
  }
}

Note: The above configuration should be updated in TACACS+ configuration file tac_plus.

Configure BIG-IP to access the remote role configuration: 

After the TACACS+ configuration is complete, BIG-IP needs to be configured to access the service. 

  1. Log in to the Configuration utility.
  2. Navigate to System > Users > Remote Role Groups.
  3. Click Create
  4. For Group Name, type the remote role group name
  5. For Line order specify the order of the line.
  6. For attribute string type attribute value defined in TACACS+ configuration file 
    Example: F5-LTM-User-Info-1=adm
  7. Remote Access choose enable. 
  8. For assigned role, choose appropriate role assigned to the group. 
  9. For partition access, choose the partition that a used from this group is allowed to access. 
  10. Choose appropriate terminal access. 
  11. Click Finished.


For Example: 
auth remote-role {
  role-info {
    adm {
      attribute F5-LTM-User-Info-1=adm
      console %F5-LTM-User-Console
      line-order 1
      role %F5-LTM-User-Role
      user-partition %F5-LTM-User-Partition
    }
    ops {
      attribute F5-LTM-User-Info-1=ops
      console %F5-LTM-User-Console
      line-order 4
      role %F5-LTM-User-Role
      user-partition %F5-LTM-User-Partition
    }

For additional information refer K8811 to configure TACACS+ authentication for BIG-IP administrative users using configuration utility. 

Note: Since each remote role behavior is configured in tac_plus by using ‘ % ’, these configurations need not redefine in BIG-IP. If you prefer to do so, you may refer to the below example. 

    adm {
      attribute F5-LTM-User-Info-1=adm
      console enabled
      line-order 1
      role administrator
      user-partition All
    }

Enable authentication source in BIG-IP: 

In the final step, enable the authentication source on BIG-IP to TACACS+ server.

  1. Log in to the Configuration utility.
  2. Navigate to System > Users > Authentication.
  3. Click Change.
  4. For User Directory, click Remote - TACACS+.
  5. For Servers, type the IP address and the port of the TACACS+ server and click Add.
  6. For Secret, type the TACACS+ shared key.

    Note: The TACACS+ secret key does not support using the pound sign (#) character.

  7. For Confirm Secret, retype the TACACS+ shared key.
  8. For Encryption, leave the default value (Enabled) or click Disabled.
  9. For Service Name, type ppp for the name of the service.

    Note: The TACACS+ server must be configured to respond to the appropriate Service Name configured on the BIG-IP system. F5 recommends that you use the ppp service.

  10. Optional: For Protocol Name, type ip for the name of the protocol.

    Note: The TACACS+ server must be configured to respond to the appropriate Protocol Name configured on the BIG-IP system. F5 recommends that you use the ip protocol.

  11. Optional: For Configuration, click Advanced. For Authentication, click Authenticate to first server or Authenticate to each server until success.
  12. Optional: For Configuration, click Advanced. For Accounting Information, click Send to first available server or Send to all servers.

    Note: Support for TACACS+ accounting was introduced in BIG-IP 10.2.0.

  13. Optional: For Configuration, click Advanced. For Debug Logging, click Disabled (default) or Enabled.

    This option allows an administrator to troubleshoot communication or authentication problems with the TACACS+ server by logging debug information to the /var/log/secure file.

  14. Click Finished.
