Policy Information

Note: The FirePass software support policy described in this article also applies to FirePass Virtual Edition (VE).

The following support policy is in effect as of January 19, 2005. For more information about the F5 End of Life (EoL) and End of Software Development (EoSD) policies currently used by FirePass, refer to K4476: F5 software lifecycle policy.

Versions of FirePass software currently supported with active software development

Versions of FirePass software supported with active software development are normally eligible for hotfixes to provide defect correction and security updates, configuration support, and Return Materials Authorization (RMA) services.
