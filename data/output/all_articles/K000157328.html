K000157328: MacOS Edge Client SAML Auth fails with "Your sign-in was successful but does not meet the criteria to access this resource"

Type
Support Solution
Published
2025-11-07
Updated
2025-11-07
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000157328

Description

Mac users were unable to authenticate to Microsoft O365 via SAML using the BIG-IP Edge Client (native F5 VPN client) on Intune-managed devices. The authentication failed because the Microsoft login site did not recognize the device as compliant with Intune policies, resulting in an error: "Your sign-in was successful but does not meet the criteria to access this resource." The issue did not occur when using the browser-based Helper client, which successfully reported device compliance.


Environment

  • Mac devices managed by Microsoft Intune
  • Microsoft SAML authentication with device compliance conditional access

Cause

Use of the embedded webview in the BIG-IP Edge Client for Mac during SAML authentication, which does not communicate with the Apple Enterprise plugin (Company Portal). As a result, Microsoft Entra ID (Azure AD) could not verify device compliance for Intune-managed Macs, causing conditional access failures.


Recommended Actions

Upgrade to a supported version of BIG-IP Edge Client for Mac and BIG-IP APM that includes the "use default browser for authentication" feature (7.2.5.1+), and follow the steps in the article BIG-IP Edge Client MAC uses default browser for authentication to configure BIG-IP APM to force the Edge Client to use the system’s default browser for SAML authentication. Ensure all prerequisites in the KB are met before applying the configuration.
