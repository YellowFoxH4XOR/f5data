K000137970: Add a request header based on the upstream server

Type
Support Solution
Published
2023-12-19
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus: R21
Source

Description

Can we add a request header with the value of the upstream server selected?


Environment

NGINX


Cause

No, It's not possible to pass the value of the $upstream_addr variable in a request header as this value is declared once NGINX receives the response from the upstream.


Recommended Actions

None
 

Additional Information

The directive add_header can be used so the client can identify what upstream processed the request looking at the defined response header. E.g.:

upstream example {
	server 127.0.0.1:3000;
	server 127.0.0.1:3100;
	server 127.0.0.1:3101;
}

server {
	listen 80;
	server_name example.com;

	location / {
		proxy_pass http://example;
		proxy_http_version 1.1;
                add_header X-Up-IP $upstream_addr;
	}
}
