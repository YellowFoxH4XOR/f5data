Known Issue

This is the result of a known issue. The versions of big3d included in 3-DNS versions 4.5 PTF-04 and later will not run on BIG-IP 4.5. If you attempt to run updated versions of big3d on BIG-IP 4.5, you will receive the following error:

Slave: Error connecting/querying BIG-IP: The BIGapi caller is expecting a different BIGapi version.:iqslave.cpp:1391

Note: F5 is working to eliminate exclusionary language in products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

Workaround

To work around this issue, upgrade to BIG-IP 4.5 PTF-05 or later. For information about upgrading, refer to the BIG-IP Release Notes.

F5 Product Development tracked this issue as CR30243.
