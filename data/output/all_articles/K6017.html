Topic

The BIG-IP secure network address translation (SNAT) automap object has a static idle timeout that you cannot change. The SNAT automap object has an indefinite idle timeout for TCP, User Datagram Protocol (UDP), and IP protocols.

Note: If the connection matches a virtual server and automap SNAT object, the BIG-IP system uses the idle timeout specified in the protocol profile. For more information about idle session timeouts, refer to K7606: Overview of BIG-IP idle session timeouts.

You can create a SNAT object with a customizable timeout value by configuring a SNAT with a defined translation IP address or a SNAT pool, and then setting the desired idle timeout for the translation address.

Creating a SNAT object with a translation address

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Perform the task appropriate to your version:
    • For BIG-IP 11.3.0 and later, click Address Translation.
    • For BIG-IP 11.2.1 and earlier, click SNATs.
  4. Click Create.
  5. Type a name for the SNAT object.
  6. In the Translation field, select IP Address from the menu and enter the translation IP address that you want this SNAT object to use. The translation IP address should be accessible through the egress VLAN and can be a self IP.

    Note: If you are configuring a BIG-IP redundant pair, and you choose to use a self IP for the translation IP address, make sure that you choose a floating self IP.

  7. Click Finished.

Setting the desired idle timeout for the SNAT object

To set the desired idle timeout for the SNAT object created in the Creating a SNAT object with a translation address procedure, perform the following procedure:

Note: Changing the idle timeout value for a SNAT does not alter the timeout used for existing connections; existing connections continue to use the previous idle timeout value. To force an existing connection to use the new timeout value, you must manually remove the existing connection from the connection table using the tmsh delete sys connection command.

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Perform the task appropriate to your version:
    • For BIG-IP 11.3.0 and later, click Address Translation.
    • For BIG-IP 11.2.1 and earlier, click SNATs.
  4. Click SNAT Translation List.
  5. Click the SNAT translation IP address for which you want to set the idle timeout.
  6. Under Configuration, choose the protocol for which you want to set an idle timeout and select Specify from the menu.
  7. Type the desired number of seconds for the idle timeout.
  8. Click Update.
