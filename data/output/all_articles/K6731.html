Note: For information about UCS archives, refer to K2250: Overview of UCS archives.

You can verify the integrity of a UCS file by using the following command syntax from the command line:

gzip -t -v -S .ucs /<directory>/<name of file>

In the following example, the backup UCS file location is /usr/local/ucs/myconfig.ucs:

gzip -t -v -S .ucs /usr/local/ucs/myconfig

This command will search for files ending in .ucs that match myconfig.

The -t flag verifies the integrity of the file's compression. The -v flag provides verbose output, and will display a message similar to the following example if the file integrity is verified as OK:

# gzip -t -v -S .ucs myconfig myconfig.ucs: OK

Note: This command cannot verify whether individual files held in the UCS file contain a BIG-IP loadable configuration—it can only verify that the UCS file was created and compress the file without corruption.
