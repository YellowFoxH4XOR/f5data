K64130835: Configuration failed to load following upgrade from 14.1.4.4 to 14.1.4.6

Description
Configuration failed to load following upgrade from 14.1.4.4 to 14.1.4.6 due to a configuration error.

The following log messages may be seen:

Jul 21 02:44:32 example.f5.com notice tmsh[9749]: 01420012:5: Loading schema version: 14.1.4.4
Jul 21 02:44:32 example.f5.com info tmsh[9749]: cli schema (14.1.4.4) has been loaded from schema data files.
Jul 21 02:44:33 example.f5.com err tmsh[9749]: 01420006:3: "a" unknown property
Jul 21 02:44:33 example.f5.com emerg load_config_files[9747]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- Loading schema version: 14.1.4.4
Jul 21 02:44:33 example.f5.com err mcpd[4221]: 01070425:3: Full configuration load failed.
Jul 21 02:44:34 example.f5.com info promptstatusd[3286]: 01460007:6: semaphore mcpd.running(1) released
Jul 21 02:44:34 example.f5.com notice promptstatusd[3286]: 01460006:5: mcpd.running(1) released, subscribe to mcpd
 

Environment

  • BIG-IP
  • Upgrade performed from 14.1.4.4to 14.1.4.6
  • LTM objects with quotation marks in the description fields

Cause
Single, unclosed quotation marks in the description field can cause the configuration to be parsed incorrectly, leading to a configuration load failure condition.

Recommended Actions
If you suspect there are unclosed quotation marks, they can be found using the grep command from the CLI:

[root@example:Offline:Standalone] config # grep \"\" bigip.conf
    description ""Example Description"
[root@example:Offline:Standalone] config #

The configuration issue may also be seen by running the tmsh load sys config command from the BIG-IP command line and looking for the line number of the error in the command output.

Once you determine where the error is, use a text editor, such as vi, to correct the error, then run tmsh load sys config  from the BIG-IP CLI to reload the configuration.
