https://my.f5.com/manage/s/article/K000150293

Description

Gui not starting after failover "Waiting for services to become available..."

Elasticsearch constantly restarting:

elasticsearch run (pid 2464) 1 seconds, 13 starts, 26793 restarts

df -h /var is full (/var/lib/pgsql/data/pg_wal)

df -i output shows / (root) full of inodes

/var/log/restjavad.0.log refers to not existing ES certificates and hangs at the end

errors in /var/log/elasticsearch/eslognode.log

Caused by: org.elasticsearch.ElasticsearchException: Unable to read /var/config/rest/elasticsearch/config/es_node.pem (/var/config/rest/elasticsearch/config/es_node.pem). Please make sure this files exists and is readable regarding to permissions. Property: opendistro_security.ssl.transport.pemcert_filepath

Environment

  • BIG-IQ CM
  • Gui Not accessible
  • Elasticsearch restarting

Cause

The GUI failed to start due to a lack of available inodes on the root filesystem (/) caused by elasticsearch restart.

Recommended Actions

  • Change elasticsearch  /var/config/rest/service.config.json SSHENABLED value to false

 "elasticsearch": {

      "BIGIQ_ES_CONFIG_HOST": "127.0.0.1",

      "BIGIQ_ES_CONFIG_SSHENABLED": true,  >>>>>> false

      "BIGIQ_ES_CONFIG_AUTHENTICATION_TYPE": "basic",

      "BIGIQ_ES_CONFIG_PORT": 9200,

      "BIGIQ_ES_CONFIG_EXTERNALLY_MANAGED": false

    },

  • Restart restjavad service:

bigstart restart restjavad

 

Additional Information

There is inconsistency between Elasticsearch and system configuration

/var/config/rest/elasticsearch/config/elasticsearch.yml

opendistro_security:

  disabled: true

/var/config/rest/service.config.json SSHENABLED value is false

 "elasticsearch": {

      "BIGIQ_ES_CONFIG_HOST": "127.0.0.1",

      "BIGIQ_ES_CONFIG_SSHENABLED": true, 

Fresh BIG-IQ does not have ES certificates available under /var/config/rest/elasticsearch/config
