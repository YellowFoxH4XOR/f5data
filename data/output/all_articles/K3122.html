Topic

You can configure the BIG-IP system or Enterprise Manager system to synchronize its clock with a network time protocol (NTP) server. You can use the Configuration utility to add NTP servers that are appropriate for your installation. To do so, perform the following procedure:

Note: Using the Configuration utility to define NTP servers may conflict with advanced NTP configuration defined in the NTP include stanza, such as authenticated NTP servers. This may cause the system to prefer the NTP servers configured using the Configuration utility over NTP servers defined in the NTP include stanza.

Configuring the BIG-IP system or Enterprise Manager system to use an NTP server

  1. Log in to the Configuration utility.
  2. Go to System > Configuration > Device.
  3. Select NTP.
  4. On the Properties page, for Address, enter the IP address of the NTP server.
  5. Select Add.
  6. Repeat steps 4 and 5 to add all NTP servers.

    Note: F5 recommends that you configure at least three external NTP servers to ensure reliability.

  7. Select Update.

    Note: The NTP servers should reside either on the management network or route domain 0 of the BIG-IP system. Additionally, you must also ensure that the BIG-IP routing table is configured appropriately to support the intended routing path for NTP traffic. For more information, refer to K13284: Overview of management interface routing (11.x - 17.x).
