K68488650: How to add CPU and Memory resources to the BIG-IQ or BIG-IP on the VMWare ESX hypervisor

Type
Support Solution
Published
2020-11-06
Updated
2025-04-01
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K68488650

Description
When upgrading BIG-IQ and the pre-upgrade check indicates a need for more CPU or Memory.
This may be seen as F5 BIG-IQ Central Manager/DCD nodes fail pre-upgrade checks.

If the need arises to add memory to a BIG-IP due to resource issues, upgrade, or an increase in usage the need to look into increasing memory may also be needed.
 

Environment

  • BIG-IQ VE running on a ESX hypervisor
  • F5_Networks_BIG_IQ_PreUpgradeCheck_Tool was run
  • BIG-IP

Cause
The BIG-IQ/BIG-IP has less than the recommended resources to run well on the target software version.
 

Recommended Actions

To assign more CPU and/or Memory to the existing BIG-IQ instance:
1. Shutdown the BIG-IQ/BIG-IP in ESX.  K7369: Shut down and restart the BIG-IP system
A) Same steps are used to shutdown a BIG-IQ.
2. Add the needed CPU and memory assignment in ESX to that BIG-IQ/BIG-IP instance from the VMWare interface.
3. Bring the BIG-IQ/BIG-IP back up.

If the added resources do not show,  Force the mcpd process to reload the BIG-IP configuration - See article K13030
 

Additional Information
F5_Networks_BIG_IQ_PreUpgradeCheck_Tool can be downloaded from downloads.f5.com under BIG-IQ Centralized Management
