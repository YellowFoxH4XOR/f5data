K26591410: Change the management IP cause the SSLO Configuration error (14.x)

Type
Support Solution
Published
2021-01-16
Updated
2023-02-21
Applies to
  • F5 App Protect
  • F5 SSL Orchestrator: 14.X.X, 14.0.X, 14.1.4, 14.1.2, 14.1.X, 14.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K26591410

Description
On the SSL Orchestrator 14.x, after change the management IP, cannot access the SSL Orchestractor Configuration, see the error:

The iApp LX sub-system is currently unresponsive. The JavaScript sub-system is currently unavailable. Please open TMSH or ssh shell and try restarting restnoded. Also look for errors in /var/log/restnoded/restnoded.log.

In the log file /var/log/restnoded/restnoded, the log like below:

severe: [Auditor] Failed to run audit cycle connect ECONNREFUSED <original IP>:443
severe: [Auditor] Failed to get application service objects. {"code":"ECONNREFUSED","errno":"ECONNREFUSED","syscall":"connect","address":"<original IP>","port":443}

Environment

  • SSL Orchestractor v14.x

Cause
ID 725514.
Recommended Actions
Follow the steps below can fix the issue.
 Impact of procedure: none

  1. Login the bash shell.

  2. Run the command below to find the block ID managementAddress.

restcurl shared/resolver/device-groups/tm-shared-all-big-ips/devices | grep -E "hostname|managementAddress|selfLink"

The output, for example:

"hostname": "SSLO-1.example.com",
"managementAddress": "10.10.10.10",          <<< old manangement IP address
"selfLink": "https://localhost/mgmt/shared/resolver/device-groups/tm-shared-all-big-ips/devices/ac8e3c80-6560-4b9b-bb24-1bd4b7df044b"

  1. Run the command below to update the block ID for managementAddress.

restcurl -X PATCH -d '{"managementAddress":"<new IP>"}' /shared/resolver/device-groups/tm-shared-all-big-ips/devices/<block ID>

For example, the new management IP is 10.10.10.20:

restcurl -X PATCH -d '{"managementAddress":"10.10.10.20"}' /shared/resolver/device-groups/tm-shared-all-big-ips/devices/ac8e3c80-6560-4b9b-bb24-1bd4b7df044b

  1. Restart restnoded process.

bigstart restart restnoded
