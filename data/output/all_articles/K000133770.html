K000133770: [F5OS] - SNMP Standard Get requests appear to be failing,

Type
Support Solution
Published
2023-05-02
Updated
2023-05-02
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000133770

Description

F5OS may appear to not support "standard" SNMP requests and OIDs.

Typically, you may not receive response to the following OIDs:

  • ifOutOctets
  • ifInUcastPkts
  • ifOutUcastPkts
  • ifInNUcastPkts
  • ifOutNUcastPkts
  • ifInMulticastPkts
  • ifInBroadcastPkts
  • ifOutMulticastPkts
  • ifOutBroadcastPkts

Environment

  • F5OS-A / F5OS-C
  • rSeries / Velos
  • SNMP monitoring

Cause

If some of those are deprecated, F5OS supports the 64-bit counter versions of these OIDs:

  • ifOutOctets ---------------> ifHCOutOctets.1
  • ifInUcastPkts -------------> ifHCInUcastPkts.1
  • ifOutUcastPkts ------------> ifHCOutUcastPkts.1
  • ifInMulticastPkts ---------> ifHCInMulticastPkts.1
  • ifInBroadcastPkts ---------> ifHCInBroadcastPkts.1
  • ifOutMulticastPkts --------> ifHCOutMulticastPkts.1
  • ifOutBroadcastPkts --------> ifHCOutBroadcastPkts.1


Deprecated "ifInNUcastPkts" is superseded with:

  • ifHCInMulticastPkts.1
  • ifHCInBroadcastPkts.1


Deprecated "ifOutNUcastPkts" is superseded with:

  • ifHCOutMulticastPkts.1
  • ifHCOutBroadcastPkts.1

Recommended Actions

Please update your SNMP console configuration accordingly.

Additional Information

Deprecated OIDs:

  • ifInNUcastPkts --> http://www.oid-info.com/get/1.3.6.1.2.1.2.2.1.12
  • ifOutNUcastPkts -> http://www.oid-info.com/get/1.3.6.1.2.1.2.2.1.18
