Known Issue

This is the result of a known issue. After installing OPSWAT 3.4.0 or 3.4.1, the Windows antivirus checker no longer detects the state of Symantec Endpoint Security. If you use a pre-logon sequence that requires real-time protection (RTP) be enabled, clients running Symantec Endpoint Security fail the antivirus check.

Note: RTP corresponds to the Monitor is running rule in the pre-logon sequence.

The FirePass Windows antivirus checker uses software libraries from a software development kit (SDK) created by OPSWAT. OPSWAT provides a vendor-independent framework for endpoint security management. OPSWAT is aware of the issue described in this Solution and is working on a resolution. Once a resolution is available from OPSWAT, F5 will issue a hotfix to address this issue.

F5 Product Development tracked this issue as CR126025 and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue was fixed in HF-126105-1 OPSWAT 3.4.2. You may download this hotfix or a later version of the OPSWAT hotfix from the F5 Downloads site.
