K000153147: VELOS drops egress IPv6 Neighbor Discovery Protocol Neighbor Adverstisement packets when tenant transitions from Standby to Active.

Type
Support Solution
Published
2025-08-25
Updated
2025-08-25
Applies to
  • F5OS
  • F5OS-C: 1.8.1
Source
https://my.f5.com/manage/s/article/K000153147

Description

 

IPv6 Neighbor Advertisement (NDP NA) packets for floating IPv6 self-IP and virtual-addresses sent from a tenant when it transitions from Standby to Active during a failover may get dropped at the VELOS platform layer, causing extended outage for IPv6 virtual servers.

 

Environment

  • VELOS
  • BIG-IP tenant

 

Cause

 

  • BCAST/DLF rate limiter in VELOS partition_fpga drops bursts of NDP NA packets during failover due to aggressive rate limiter configuration. Unfortunately, the default value for BCAST_DLF_RATE_LIMIT (400000) is already the ceiling. This is being tracked as ID2016349.

 

Recommended Actions

 

  • Install an EHF containing the fix for ID2016349.

 

Additional Information

  • None.
