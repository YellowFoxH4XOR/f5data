K000092907: TCP::setmss can set a smaller MSS value than the MSS value the client advertises

Type
Support Solution
Published
2022-12-01
Updated
2022-12-01
Source

Description

iRule Command TCP::setmss can only set a smaller value than the MSS value the client advertises.


Environment

BIG-IP system

Cause

This is by design.

None
