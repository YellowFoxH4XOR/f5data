Known Issue

Users who attempt to remove the BIG-IP Edge Client from a Windows workstation using the f5wininfo.exe file may still see BIG-IP Edge Client Components (All Users) listed in the Add/Remove Programs list.

This issue occurs when all of the following conditions are met:

  • The client system is a Windows Operating System.
  • The user runs the f5wininfo.exe to remove the BIG-IP Edge Client.

Impact

The BIG-IP Edge Client is not fully removed from the client's workstation.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP Edge Client Components (All Users) is listed in the Add/Programs list.
  • Individual files that were installed as part of the BIG-IP Edge Client have not been removed.

Workaround

To work around this issue, you can manually remove the BIG-IP Edge Client. To do so, perform the following procedure:

Impact of workaround: None

Manually removing BIG-IP Edge Client components

The following procedure enables you to remove BIG-IP Edge Client components from a Windows client system. This procedure requires that you have administrator privileges on the Windows system.

  1. Log out of any active BIG-IP Edge Client sessions.
  2. Close all browser windows.
  3. Close the BIG-IP Edge Client, if running.
  4. Run the following commands from the Windows command line:

    net stop "F5 Networks Component Installer"
    sc delete "F5 Networks Component Installer"
    del %WINDIR%\System32\F5InstallerService.exe

    Note: If the F5 Component Installer Service is not installed on your Windows system, you will receive errors when running these commands. You can safely ignore these errors.

  5. Using the Windows Control Panel, remove (uninstall) the following programs if they are installed:

    For more information about removing programs, refer to your Microsoft Windows documentation.

     
    • F5 VPN Client for Windows
    • GPAnywhere for VPN
    • OPSWAT AntiVirus and Firewall Integration Libraries
    • Citrix Clients (if installed through a Portal Access connection)
  6. Remove all ActiveX controls that start with F5.

    Important: Perform this step even if you use Firefox to log in to BIG-IP APM. F5 ActiveX controls installed through Firefox are also available to Internet Explorer, and performing the previous steps is required in order to remove the registry keys associated with the ActiveX controls.

    Note: For instructions about removing ActiveX controls in Internet Explorer versions 4 through 6, refer to http://support.microsoft.com/kb/154850/en-us?spid=2073&sid=216.

    For instructions about removing ActiveX controls in Internet Explorer 7 and Internet Explorer 8, refer to http://windowshelp.microsoft.com/Windows/en-GB/help/e85a03aa-c7c6-428e-9891-67ea76df9b7e1033.mspx.

    These links take you to a resource outside of AskF5, and it is possible that the documents may be removed without our knowledge.

  7. Remove all ActiveX controls that start with OPSWAT, if installed.
  8. Remove the Microsoft RDP Client Control (redist) ActiveX control, if installed.
  9. Remove the URVNCX Class ActiveX control, if installed.
  10. If you use Firefox to log in to BIG-IP APM, remove all F5 Firefox plugins. F5 plugins start with NPuroam and they are located in the Firefox plugins directory.

    Note: For default installations, the Firefox plugins directory is located at %PROGRAMFILES%\Mozilla Firefox\plugins. If you performed a customized Firefox installation, refer to http://kb.mozillazine.org/Installation_directory for information about locating the Firefox installation and plugin directories on your system.

    This link takes you to a resource outside of AskF5, and it is possible that the documents may be removed without our knowledge.

  11. Run the following commands from the Windows command-line or by using a batch script:

    Note: Depending on which BIG-IP Edge Client components you installed, and which version of Windows you are running, not all of the files and directories listed below will be present on your Windows system. When running the commands below, Windows may report that it could not find the file or directory you entered. You can safely ignore these errors.

    del "%WINDIR%\Downloaded Program Files\f5*.*"
    del "%WINDIR%\Downloaded Program Files\CacheCleaner.*"
    del "%WINDIR%\Downloaded Program Files\ur*.*"
    del "%WINDIR%\Downloaded Program Files\InstallerControl.*"
    del "%WINDIR%\Downloaded Program Files\HookDll.dll"

    del "%WINDIR%\Downloaded Program Files\*opswat*"

    del "%WINDIR%\Downloaded Program Files\set9x16.dll"
    del "%WINDIR%\Downloaded Program Files\set9x32.dll"
    del "%WINDIR%\Downloaded Program Files\setup2000.dll"
    del "%WINDIR%\Downloaded Program Files\setupdrvdll.dll"
    del "%WINDIR%\Downloaded Program Files\TunnelServer.exe"
    del "%WINDIR%\Downloaded Program Files\TunnelServerX.dll"
    del "%WINDIR%\Downloaded Program Files\utunres.dll"
    del "%WINDIR%\Downloaded Program Files\vdeskctrl.dll"
    del "%WINDIR%\Downloaded Program Files\vdeskctrl.inf"
    del "%WINDIR%\Downloaded Program Files\VNCClientX.dll"
    del "%WINDIR%\Downloaded Program Files\Win32SystemCheck.dll"

    del "%PROGRAMFILES%\Mozilla Firefox\plugins\NPuroam*"

    rmdir /S /Q "%PROGRAMFILES%\F5"
    rmdir /S /Q "%PROGRAMFILES%\F5 VPN"
    rmdir /S /Q "%USERPROFILE%\Application Data\F5 Networks"

    del %TEMP%\Low\f5*.txt
    del %TEMP%\Low\logterminal.txt
    del %TEMP%\f5*.*
    del %TEMP%\logterminal.txt
    del %WINDIR%\Temp\f5*.*
    del %WINDIR%\Temp\logterminal.txt
    del %WINDIR%\Temp\decompress_log.txt

  12. In the %WINDIR%\System32 and %WINDIR%\Downloaded Program Files directories, remove any directories that start with Conflict.
  13. Delete all BIG-IP APM Dial-up Adapters. These adapters may have been renamed on your system. However, by default, these adapters are named:

    [Network Access Favorite Name] - Go to [BIG-IP APM hostname or IP address] instead of dialing directly

    Note: For more information about deleting Dial-Up Adapters, refer to your Microsoft Windows documentation.

  14. In the Windows Device Manager, select Show hidden devices from the View menu and then expand the Network adapters section. If the F5 VPN Adapter appears under Network adapters, right-click the F5 Networks VPN Adapter and select Uninstall.

    Note: For more information about managing devices using the Device Manager, refer to your Microsoft Windows documentation.

  15. Use a registry editor tool to remove the following registry keys, if they exist:

    Important: Use the registry editor with extreme caution. If you make an error while editing the Windows registry settings, you may cause severe issues that can be solved only by reinstalling the operating system.

     
    • HKEY_CURRENT_USER\SOFTWARE\F5 Networks
    • HKEY_CURRENT_USER\ SOFTWARE \uRoam
    • HKEY_LOCAL_MACHINE\ SOFTWARE\F5 Networks
    • HKEY_LOCAL_MACHINE\ SOFTWARE\uroam
  16. Run the following commands from the Windows command line:

    net stop "F5FltSrv"
    sc delete "F5FltSrv"
    del %WINDIR%\System32\F5FltSrv.exe

    Note: If the F5 DNS Relay Proxy Service is not installed on your Windows system, you will receive errors when running these commands. You can safely ignore these errors.

Note: For more information about the CTU, refer to K12444: Overview of the Client Troubleshooting Utility for Windows and K9133: Overview of the FirePass Components Troubleshooting Utility.

Note: For more information about removing programs, refer to your Microsoft Windows documentation.
