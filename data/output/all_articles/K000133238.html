Description

"nginx -s reload" command may terminate HTTP keepalive connections.

 

Environment

- NGINX Plus

- Run "nginx -s reload" command


Cause

This is by design.


Recommended Actions

Please consider impacts on your network environment before running "nginx -s reload" command.
