Known Issue

This is the result of a known issue. When importing a bundled SSL certificate through the Configuration utility, only the first certificate in the bundle is imported. As a result, the BIG-IP system, the client, or both will not correctly validate the certificate.

Bundled certificates are common when using certificate authorities that are validated by other certificate authorities, and contain intermediate certificates that are used to validate the certificate chain.

F5 Networks Product Development tracked this issue as CR82095 and it was fixed in BIG-IP LTM version 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

If upgrading to BIG-IP version 9.4.2 is not possible, you can upload the bundled certificate(s) using an SCP client application, and placing the certificate bundle file in the /config/ssl/ssl.crt/ directory.

Once the file is uploaded to the /config/ssl/ssl.crt directory, you can view the file within the Configuration utility. Additionally, you can use the certificate bundle file within any SSL profile.
