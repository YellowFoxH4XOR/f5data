Description
When attempting to delete or move an ASM policy to inactive the action may fail with the following error in /var/log/asm:

crit g_server_rpc_handler_async.pl[<PID>]: 01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback): Cannot remove manually configured L7 policy <LTM policy>.

In the GUI you may receive a shorter but similar message:

Cannot remove manually configured L7 policy <LTM policy>

Environment

  • BIG-IP ASM or Advanced WAF version 11.4 and above

Cause
This error indicates that the ASM policy is being referenced by a Local Traffic Policy.  A Local Traffic Policy is the primary means of activating ASM for a virtual server.  Deleting the ASM policy is not possible until it is not referenced by any other configuration.

Recommended Actions

If the Local Traffic Policy's only purpose is to activate the ASM policy in question:

  1. Ensure the Local Traffic Policy is not assigned to any virtual server
  2. Navigate to Local Traffic  ››  Policies : Policy List
  3. Delete the Local Traffic Policy from Published Policies and any drafts within Draft policies
If the Local Traffic Policy is performing functions in addition to activating the ASM policy in question:
  1. Navigate to Local Traffic  ››  Policies : Policy List and select the policy
  2. Select "Create Draft"
  3. Select the new policy draft
  4. Delete the rule that is activating the ASM policy
  5. Select the dropdown next to "Save Draft" and select "Save and Publish Policy"

Additional Information
This Local Traffic Policy is dedicated to activating the ASM policy "ASM-policy1" so could be fully deleted before deleting or deactivating the ASM policy:

ltm policy manual-LTM-policy1 {
    controls { asm }
    last-modified 2019-09-30:10:51:38
    rules {
        activate-asm {
            actions {
                0 {
                    asm
                    client-accepted
                    enable
                    policy /Common/ASM-policy1
                }
            }
        }
    }
    status published
    strategy first-match
}

This Local Traffic Policy is performing a change of the Host header value based on the Host header value of the HTTP request and activating ASM policy "test1" but is also activating the ASM policy "ASM-policy1" as the default action.  The header change may be important to the functionality of the application so deleting only the single rule activating the ASM policy to be deleted is the preferred method.  (Delete the rule "activate-asm" but leave the rule "change-host").

ltm policy manual-LTM-policy2 {
    controls { asm }
    last-modified 2019-09-30:14:41:56
    requires { http }
    rules {
        activate-asm {
            actions {
                0 {
                    asm
                    enable
                    policy /Common/ASM-policy1
                }
            }
            ordinal 1
        }
        change-host {
            actions {
                0 {
                    http-header
                    replace
                    name Host
                    value f5.com
                }
                1 {
                    asm
                    enable
                    policy /Common/test1
                }
            }
            conditions {
                0 {
                    http-host
                    values { test.com }
                }
            }
        }
    }
    status published
    strategy first-match
}
