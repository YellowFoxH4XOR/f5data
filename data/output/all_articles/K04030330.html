Description

Administrator is unable to see (Fully-qualified Domain Name) FQDN node auto-populated after configuring when auto-populated option enabled, even though the logs shows that the FQDN is actually resolved to an IP address.

Cause

  • There is already manually configured IP address node with the same IP address that the FQDN node resolve to
  • By default, the auto-populated feature in normal IP address node is set to disabled, and that option is not configurable

Recommended Actions

  • Delete the non-FQDN IP address node that have the same IP address
