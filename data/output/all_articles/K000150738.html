K000150738: Viprion Blade keeps on rebooting even if EUD passed

Type
Support Solution
Published
2025-05-05
Updated
2025-05-05
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150738

Description

Viprion Blade keeps on rebooting, and when EUD was run to the reported blade, it passed. on the boot logs, you can see that BIOS is trying to recover:

 

$ grep -hair "BIOS recovery" var/log/ltm.*

Mar 22 21:30:01 slot1/viprion.blade.slot warning chmand[9399]: 012a0004:4: BIOS recovery error: 1

Mar 22 22:04:44 slot1/viprion.blade.slot warning chmand[9409]: 012a0004:4: BIOS recovery error: 1

Mar 22 22:38:16 slot1/viprion.blade.slot warning chmand[9421]: 012a0004:4: BIOS recovery error: 1

 

Environment

Viprion

B4450

Cause

 

BIOS is probably having an issue causing the reboot

 

Recommended Actions

 

RMA the blade
