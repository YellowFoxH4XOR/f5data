Description

logmysqld daemon is restarting continuously, and qkview generation fails.

There are many logs containing (errno:24) in /var/lib/mysql/mysqld.err.

Environment

  • logmysqld

Cause

Bug ID 773925: Sometimes MariaDB generates multiple error 24 (too many files open) for AVR DB tables files

Recommended Actions

Impact of workaround: BIG-IP services that rely on the MySQL database, such as BIG-IP ASM, BIG-IP AVR, and BIG-IP APM reporting, do not function properly when MySQL service is restarted. 

In /etc/my.cnf file:

1. Change the value of the open_files_limit parameter from 2500 to 5000.
2. Add the following parameter (right after open_files_limit):
   table_open_cache=2000
3. Restart MySQL:
   bigstart restart mysql
