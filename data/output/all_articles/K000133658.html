Description

New DNS resolver list f5-aws-dns with its own forward zones has been added after upgrade from 14.1 to 16.1

Environment

  • LTM
  • DNS resolver

Cause

This is a default feature added starting TMOS v15.x

Recommended Actions

f5-aws-dns object is referenced by f5-cloud-service-ingress-aws-global which is a default object and cannot be removed.

Additional Information

None
