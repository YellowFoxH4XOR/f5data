K000149228: Requests forwarded from Nginx Reverse Proxy to F5® Distributed Cloud are failing

Type
Support Solution
Published
2025-01-08
Updated
2025-02-22
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud WAF
Source
https://my.f5.com/manage/s/article/K000149228

Description

I am using a Nginx Reverse Proxy in front of an F5® Distributed Cloud (XC) HTTP Load Balancer or XC CDN

  • I am seeing that all requests are failing

or 

  • I am receiving a 505 HTTP Version Not Supported errors

or

  •  I am not seeing any traffic within the XC logs from your Nginx Reverse Proxy.

 

Environment

  • F5® Distributed Cloud (XC) HTTP Load Balancer
  • XC CDN

 

Cause

By default, if the proxy_http_version setting is not explicitly defined, Nginx will use HTTP/1.0 which is not supported by XC/XC CDN.

 

Recommended Actions

Ensure that that your Nginx configuration includes the proxy_http_version setting with specific HTTP versions your Niginx Reverse proxy will be utilizing

 

Example:

proxy_http_version 1.1;
