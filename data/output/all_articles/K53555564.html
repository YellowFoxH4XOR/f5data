Description

When setting Virtual Server with DSR tunnel with GRE profile, by default Client IP address will be used as tunnel local IP address, if it is needed to use Self-IP as tunnel local IP address, some options needs to be set.

Environment

  • BIG-IP
  • DSR tunnel

Cause

Direct Server Return (DSR) tunnels use the same client-side address of the encapsulated flow as their tunnel local address.

Recommended Actions

Enable  db variable  according to below procedure (tmsh):
  1. SNAT option of Virtual Server needs to be set to Automap
  2. Database value TM.DsrLocalEncap on BIG-IP needs to be enabled with following command:
            # modify sys db tm.dsrlocalencap value enable

none.
