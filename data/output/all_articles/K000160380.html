K000160380: VPN Edge Client Connectivity Loss When Launching Local Applications Due to TCP MSS Value

Type
Support Solution
Published
2026-03-17
Updated
2026-03-17
Applies to
  • BIG-IP
  • BIG-IP APM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160380

Description

Users connecting via F5 BIG-IP APM Edge Client experience loss of connectivity to both Internet and Intranet resources when launching certain local applications (e.g., SAP client). This issue occurs only when using the F5 Edge Client VPN, not when connected to the local LAN. The VPN session remains active, but network access is lost during periods of increased client-side traffic.


Environment

  • Big-IP
  • Edge client

Cause

Higher Maximum Segment Size (MSS) value in the TCP profile used by the VPN, which can cause packet fragmentation or drops if the MSS is set too high for the VPN tunnel.


Recommended Actions

To resolve the issue of connectivity loss when launching local applications over the F5 Edge Client VPN:

  1. Access the BIG-IP Configuration utility.
  2. Navigate to the relevant TCP profile used by the Network Access (NA) resource.
  3. Lower the MSS (Maximum Segment Size) value in the TCP profile to 1360.
  4. Apply the changes and monitor user connectivity.
  5. Confirm with affected users that launching local applications (such as SAP) no longer causes loss of network connectivit
