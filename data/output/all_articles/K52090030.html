Description

High Memory utilization is reported by monitoring tool (SNMP)
 

Environment

  • BIG-IP
     

Cause

BIG-IP reserves memory for TMM.
But actual memory usage can be low.
 

Recommended Actions

Depending on the combination of provision, memory reservation for TMM will be different.
To check how resource allocation is done, run below command
 show /sys provision
