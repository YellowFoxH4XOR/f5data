K83565105: Configuration Utility indicates that device already exists event though it is not listed as a discovered device

Type
Support Solution
Published
2020-04-10
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K83565105

Description
Attempts to discover and add a second BIG-IP Device fail, GUI may indicate that device already exists, event though it is not listed as a discovered device.

The following may be observed in /var/log/restjavad.0.log on the BIG-IQ:
[ERROR][28 Feb 2017 11:46:02 PST][/cm/global/tasks/device-trust/b728542c-a62d-408f-bff3-163ce8753e51/worker BigIPTrustTaskWorker] Failed to post to group (cm-bigip-allBigIpDevices) : java.lang.IllegalArgumentException: A device with IP address '192.0.2.10' has already been discovered in this group.
[ERROR][28 Feb 2017 11:46:02 PST][/cm/global/tasks/device-trust/b728542c-a62d-408f-bff3-163ce8753e51/worker BigIPTrustTaskWorker] A device with IP address '192.0.2.10' has already been discovered in this group.

Environment

  • BIG-IQ CM with at least one discovered device.

Cause
Unknown at time of publishing.

Recommended Actions

Remove the device from the config that is not seen in the Device List based on the UUID using the REST API
Note: Perform the following on CLI of the BIG-IQ

  1. Use the following command to find the UUID associated with the IP address in the log error:
        restcurl cm/system/machineid-resolver | jq '.items[] | {uuid,address,hostname,managementAddress,selfLink}'

  2. Save the UUID and use the following solution to remove the device from the config:
       K01131523: Removing a managed device from BIG-IQ using REST API and UUID
            

Additional Information

  • K15938: Error Message: BIG-IQ has already discovered a device (<IP-Address>) with this machine ID
