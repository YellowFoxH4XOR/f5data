Known Issue

When you re-license a BIG-IP system using the Configuration utility, the system may interrupt the session.

This issue occurs when one of the following conditions are met:

  • You are logged in as a user other than admin with administrator rights.
  • After re-licensing, the administrator is prompted to re-authenticate to the system.

Impact

None. Despite the error messages and re-authentication request, the system updates the license as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • For Version 10.x, the system may log an error message that appears similar to the following example to the /var/log/webui.log file:

    SQLException from LicenseUtils.isLicenseInvalid() and User.getAllowedPartitions()

  • For version 10.x the system may log an error message that appears similar to the following example to the /var/log/ltm file:

    User login disallowed: User (UserName) is not an administrator, does not have a UID of zero, and has not been assigned a role on a partition.

  • For version 9.x, the system may log an error message that appears similar to the following example to the /var/log/ltm file:

    Disconnecting user UserName

Resolution

Status

F5 Product Development has assigned ID 247398 (formerly CR 118250) to this issue, and has confirmed that this issue exists in the products listed in the Applies To box. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can log in as the admin user, instead of the alternate user with administrative rights, to re-license your BIG-IP system.
