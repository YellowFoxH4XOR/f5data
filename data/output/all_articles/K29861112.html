Description

How to create and edit HTML profile rules via GUI

Environment

  • You need to create and/or modify an HTML profile rule.

Cause

Recommended Actions

Creating a new HTML rule

To create an HTML rule, perform the following procedure:

Impact of procedure: This procedure is not impactful.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Content > HTML > Rules.
  3. Select Create New to create a basic rule or select the down arrow beside Create New to create a more advanced rule with the following options:
    • Remove Comments
    • Raise Event on Comments
    • Remove Attribute
    • Append HTML
    • Prepend HTML
    • Raise Event on Tag
    • Remove Tag
Note: See the manual chapter linked below for details on each of the options listed above.
  1. Define the options in the rule then select OK to save the rule.

Edit an existing HTML rule

To edit an HTML rule, perform the following procedure:

Impact of procedure: This procedure is not impactful.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Content > HTML > Rules.
  3. Select the rule you would like to edit then select Edit at the bottom of the page.
  4. Make the changes then select OK to save.
