Issue

Error Message

warning tmm[<PID>]: 01010290:4: TCP: Memory pressure activated

In this error message, note the following:

  • <PID> is the process ID for the tmm process.

For example:

warning tmm[8484]: 01010290:4: TCP: Memory pressure activated

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • The tm.tcpmemorypressure database variable is set to enabled (default).
  • Traffic Management Microkernel (TMM) memory usage exceeds the threshold set in the tm.tcpmemorypressure.lowater database variable.

Impact

While memory usage exceeds TCP memory pressure thresholds, the BIG-IP system may drop ingress TCP packets and service may be disrupted due to the lost TCP payload and packets.

Recommended Actions

This message may indicate that the BIG-IP system does not have sufficient memory resources for TMM under high traffic load. To mitigate the issue, you can reduce the traffic load to the high traffic load virtual server or reduce overall traffic to the BIG-IP system. If the BIG-IP system is a virtualized instance, such as a BIG-IP Virtual Edition (VE) or a Virtual Clustered Multiprocessing (vCMP) guest, you can increase the amount of allocated memory for the BIG-IP instance.
