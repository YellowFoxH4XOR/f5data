K000160275: How to Redirect a Local Camera Through RDP Connection Using BIG-IP APM

Description

Camera redirection from a local device to a remote virtual machine through an RDP connection via BIG-IP APM is not enabled by default. This requires configuration of custom RDP parameters to allow the remote session to access and use the camera connected to the local device.

Environment

  • BIG-IP APM
  • User connects to a remote VM via RDP and requires camera redirection from the local laptop

Cause

None

Recommended Actions

To enable camera redirection through an RDP connection in BIG-IP APM, follow these steps:

1. Log in to the BIG-IP APM GUI.

2. Navigate to: Access ›› Connectivity / VPN ›› VDI / RDP ›› Remote Desktops

3. Select the relevant RDP resource.

4. In the "Custom Parameters" field, add the parameter: camerastoredirect:s:* 

5. Click "Update" and apply the Access Policy.

Additional Information

The parameter camerastoredirect:s:* is based on Microsoft RDP properties and enables camera redirection for all available cameras.
