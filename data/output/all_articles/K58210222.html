K58210222: Unable to see ASM reports on BIG-IQ under Monitoring>>Dashboards>> Web Application Security When dosl7d down on BIG-IP

Type

Published
2022-03-04
Updated
2025-02-06
Applies to

  • BIG-IP
Source
https://my.f5.com/manage/s/article/K58210222

Description

Unable to see ASM reports on When attempting to view BIG-IP ASM reports on BIG-IQ under Monitoring > Dashboards > Web Application no data is displayed.

Environment

  • BIG-IQ CM
  • BIG-IP ASM/AWAF

Cause

The dosl7d service is down on BIG-IP ASM.

Recommended Actions

Determine why the dosl7d service is not running on the BIG-IP ASM.
You can attempt to manually restart the dosl7d service from the command line of the BIG-IP ASM:

tmsh restart /sys service dosl7d
