Description

A virtual server issues syncookies even though no attack has been detected by the virtual server.

When you run the command:
tmsh show ltm virtual <Virtual Name>

SYN Cookies
  Status                         not-activated
  Hardware SYN Cookie Instances              0
  Software SYN Cookie Instances              0
  Current SYN Cache                          0
  SYN Cache Overflow                         0
  Total Software                             0
  Total Software Accepted                  123
  Total Software Rejected                  345
  Total Hardware                             0
  Total Hardware Accepted                 1567

  • We see that syncookies are not currently activated, and the SYN Cache Overflow is 0, so they have never been activated.
  • We see that Total Software and Total Hardware are 0, but we see that Software/Hardware Accepted have positive values.

Environment

  • AFM is provisioned
  • Wildcard Forwarding Virtuals are configured

Cause

This issue is caused by Bug ID 1012581.

Recommended Actions

This issue is not fixed in any version yet, you need to contact F5 Support, query the status for your version, and request an Engineering Hotfix.
