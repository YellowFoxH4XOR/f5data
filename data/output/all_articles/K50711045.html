K50711045: System performance graph on the BIG-IQ shows drop to zero for all devices CPU/Memory and Traffic although there is no such drop on the devices.

Type
Support Solution
Published
2020-06-19
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.1.X, 7.0.X
Source
https://my.f5.com/manage/s/article/K50711045

Description

  • F5 BIG IQ shows zero Percentage CPU/Mem & Traffic of CPU utilization to on graph
  • about to generate a new device-inactivity alert for hostname


/var/log/appiq/health-calculator.log
==========================

020-05-02 04:01:00,225 INFO c.f.a.a.s.MetricAlertsGenerator [scheduling-1] MetricAlertsGenerator is about to generate a new device-inactivity alert for {hostname=name.local} with metric value MetricValues{observationValue=-1.0, referenceObservationValue=null}, alert definition is NestedMetricAlertDefinition{alertTypeId='device-inactivity', ruleName='default-active-device-health', parent=default-active-device-health, producerType=Device, enabled=true, default=true, alertType='active', alertContext='health', shouldPublish=true, observationTimeInMinutes=5, referenceObservationTimeInMinutes=null, operator=less-than, unit='percent', errorThreshold=0.0, warningThreshold=1.0, errorDelta=null}, current active alert is null, new severity is Critical

Environment

  • BIG-IQ CM

Cause

  • The BIG-IQ logged these messages because it was not getting timely response/update. 
  • BIG-IQ generating device-inactivity alert as a result of it not getting timely response.

Recommended Actions

  • Check external network setup

Additional Information

  • The BIG-IQ generates an alert of device inactivity round about reported time and the alert actually encompasses all monitored devices.
  • Issue is not specific to a device specific but rather all monitored systems.
