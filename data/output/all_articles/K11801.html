K11801: The source port may be translated for server-initiated traffic over a Network Access connection

Known Issue

This is the result of a known issue. When a device behind the BIG-IP APM system initiates a connection to a Network Access client, and Clustered Multi-Processing (CMP) is enabled on the virtual server, BIG-IP APM may modify the source port when forwarding the packet to the client. Some applications and protocols, such as Voice over Internet Protocol (VoIP), are not compatible with port address translation. As a result, these applications and protocols may not function properly over a Network Access connection.

Note: You can change this behavior by setting Source Port to Preserve Strict on the virtual server; that setting only applies to client-initiated connections.

F5 Product Development tracked this issue as ID 225769 (formerly CR140110) and it was fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2 issued for BIG-IP version 10.1.0, and Hotfix-BIGIP-10.2.0-1755.1-HF1 issued for version 10.2.0. You may download these hotfixes or later versions of the hotfixes from the F5 Downloads site.
