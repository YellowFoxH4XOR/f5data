K000161680: After upgrading vCMP guest to version 17.1.3.2 or 17.5.1.6, guestagentd keeps logging "01810007:6: Rest request failed" with 400 status code

Description

After upgrading vCMP guest to version 17.1.3.2 or 17.5.1.6, the guestagentd process logs recurring REST request failure messages every five minutes. These messages do not appear when running the previous version and cease upon reverting to it.

Error messages observed in /var/log/ltm on the vCMP guest:

info guestagentd[5147]: 01810007:6: Rest request failed: {"code":400,"referer":"Unknown","restOperationId":948944,"kind":":resterrorresponse"}

info guestagentd[5147]: 01810007:6: Rest request failed: {"code":400,"referer":"Unknown","restOperationId":3153150,"kind":":resterrorresponse"}

Additionally, the following warning messages are logged in /var/log/restjavad.x.log every five minutes:

[com.f5.rest.common.RestWorker] dispatch to worker http://localhost:8100/shared/authz/tokens caught following exception: java.lang.NullPointerException
 

A secondary symptom is that on the vCMP host GUI in the vCMP -> Guest Status tab, guest status may not be displayed for all vCMP guests.

Environment

  • vCMP guest upgraded to version 17.1.3.2 or 17.5.1.6
  • guestagentd

Cause

Bug ID 2313505 

Answer/Recommended Actions

An Engineering Hotfix containing a fix can be provided. Contact F5 Technical Support to request the Engineering Hotfix.

If the volume of guestagentd log messages is a concern, it is possible to suppress these entries by configuring a Log Filter with no publisher:

sys log-config filter Filter_RestError {
    level info
    message-id 01810007
    source guestagentd
}
