Known Issue

Secure network address translation (SNAT) statistics omit File Transfer Protocol (FTP) port traffic.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration uses SNAT.
  • FTP traffic traverses the SNAT.
  • You use the Configuration utility or TMOS Shell (tmsh) to view SNAT statistics.

Impact

SNAT statistics do not show FTP port traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the tmsh show ltm snat command or the Configuration utility to view SNAT statistics, the values are not updated for port 21 traffic (FTP).
