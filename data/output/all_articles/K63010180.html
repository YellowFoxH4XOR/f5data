Known Issue

The BIG-IP system may fail to forward SOCKS requests to a target IP address in a non-default route domain.

This issue occurs when all of the following conditions are met:

  • You configured a SOCKS profile to use a non-default route domain.
  • You configured a virtual server to use the SOCKS profile.
  • The virtual server receives a SOCKS request.

The issue occurs because the system ignores the non-default route domain setting in the SOCKS profile and attempts to forward SOCKS traffic using the default route domain instead.

Note: The route domain with an ID of 0 (zero) signifies the default route domain.

Impact

SOCKS connections to virtual servers fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • SOCKS connections fail to virtual servers configured with a SOCKS profile that uses a non-default route domain.
  • SOCKS requests are incorrectly forwarded to the default route domain.
