Description

Prior to BIG-IP 13.1, you should use the single traffic group traffic-group-1 since BIG-IP APM HA is only supported in active-standby peer configurations.
Starting in BIG-IP 13.1, you can use any traffic group, but all BIG-IP APM traffic objects must exist in the same traffic group.

Environment

Relevant environmental factors specific to the topic

  • BIG-IP APM 
  • Multiple Traffic groups 
  • Version 13.1+

Cause
This is working as designed. 
The system does not limit BIG-IP APM configuration objects to traffic-group-1.
Important: You must configure all BIG-IP APM related objects in a single traffic group.

Recommended Actions
Configure all BIG-IP APM related objects in a single traffic group.
