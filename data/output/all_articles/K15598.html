Topic

Summary

The automatic license activation method may not be available when the BIG-IP system is configured with a Traffic Management Microkernel (TMM) default route that is not reachable. However, when the automatic method is available, and the F5 license server cannot be reached, the automatic license activation fails.

Description

In BIG-IP 10.0.0 through 11.3.0, the automatic license activation method may not be available when the BIG-IP system is configured with a TMM default gateway route that is not reachable.

The TMM always prefers the TMM default gateway route over the management route, so when the TMM default gateway route on the BIG-IP system is not reachable, the automatic license activation method will not be available when you navigate to System > License > Reactivate using the Configuration utility.

In BIG-IP 11.4.0 and later, the automatic license activation method is available even when the BIG-IP system has not been configured with a valid default gateway route. However, the automatic license activation will fail if the BIG-IP system cannot connect to the F5 license server.

For example, the BIG-IP system is configured with a TMM default gateway route and a management default route as follows:

net route default {
    gw 10.3.3.199
    network default
}

sys management-route default {
    gateway 192.168.1.254
    network default
}

If the TMM default gateway route IP address in the previous example, 10.3.3.199, is not reachable by the 11.3.0 BIG-IP system, you will be unable to select Automatic as the Activation Method when you use the Configuration utility to navigate to  System > License > Reactivate.

If the same TMM default gateway route, which is not reachable, is configured on a BIG-IP system running BIG-IP 11.4.0, you will be able to select Automatic as the Activation Method when you use the Configuration utility to navigate to  System > License > Reactivate; however, the license activation will fail.

For more information about management interface routing and TMM routes, refer to the following articles:

  • K13284: Overview of management interface routing (11.x)
  • K3669: Overview of management interface routing (9.x - 10.x)

Recommendations

When you prefer automatic license activation for the BIG-IP system, always ensure that the TMM default route IP address that the BIG-IP system uses can access the Internet before you perform the license activation procedure.

For more information on managing static routes, refer to one of the following articles:

  • K13833: Managing static routes (11.x)
  • K5465: Managing static routes (9.x - 10.x)

When the BIG-IP system has no default route that can access the Internet, you should consider using the manual license activation method.

For more information on manual license activation, refer to K7752: Overview of licensing the BIG-IP system.
