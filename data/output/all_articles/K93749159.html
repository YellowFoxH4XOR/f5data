Known Issue

Web resources may fail to render when web scraping protection is configured.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured for Brute Force Attack Prevention and Web Scraping.
  • Client-side challenges sent by web scraping are not executed on the client.

Impact

Web resources are unavailable or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users receive a blank page when attempting to retrieve web resources.
  • Web resources are unavailable or fail to render properly.
