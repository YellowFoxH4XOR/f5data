Issue

Error Message

err mcpd[<PID>]: 01071485:3: <object> <name> content does not match the signature.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <object> is the type of configuration object.
  • <name> is the name of the configuration object.

For example:

err mcpd[2255]: 01071485:3: AppTemplate (/Common/f5.bea_weblogic) content does not match the signature.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • The signature on an AplScript, AppTemplate, CliShellScript, or iRules object does not match its contents.

Impact

You are unable to make configuration changes involving the affected signature or content.

Recommended Actions

Depending on the specific object that caused the error and conditions, the workarounds differ. The following lists examples of known issues with workarounds:

  • ID 460500: Signed iRule may cause load config error.
  • ID 807397: IRules ending with a comment cause config verification to fail
  • K00448761: mcpd and lind processes restarting on secondary blades due to configuration error: AppTemplate (<name>) content does not match the signature
