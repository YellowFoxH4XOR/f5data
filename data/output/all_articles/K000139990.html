Description

Bigip platforms with DDoS Hybrid Defender capabilities have different compatibility levels.

 

OptionDescription
LEVEL 0Specifies a system with basic hardware DoS capabilities (provides device protection and Rich Whitelist). Valid for all systems, and is the default value.
LEVEL 1Specifies either a VE system with no hardware offload or a system with hardware DoS and sPVA capabilities (in addition to LEVEL 0 features provides hardware DoS protection per protected object, Whitelist Address List, IP intelligence, and bad actor/attacked destination discovery).
LEVEL 2Specifies a system with hardware DoS, sPVA, and Neuron capabilities (in addition to LEVEL 1 features provides extended whitelist).

 

When trying to change the compatibility level for a system to a level that is not supported the following error can occur.

01071d49:3: Specified compatibility level-1 is too high. That level includes feature settings that are not supported for this platform.

The above is expected as not all platforms support all compatibility levels. This can be a bottleneck when trying to create a cluster with devices that have different compatibility level settings.

Environment

  • HA cluster
  • DDoS Hybrid Defender

Cause

The configuration for units that should be in the same cluster should be the same.

Recommended Actions

Configure the bigip units with the appropriate compatibility level.
