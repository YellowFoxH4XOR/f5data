Description

Clients not able to access any HTTPS website when going through SSLO.
/var/log/apm keep showing below error messages:

(ERR_LICENSE) URL category lookup failed
(ERR_REJECT) Error processing URL Classification query from CatEngine

Environment

  • SSLO
  • SWG
  • License
Cause

SWG license has been expired or disabled.

(tmos)# show sys license field-fmt | grep inactive-modules -A 1
    inactive-modules {
        "Secure Web Gateway, VE-25M-1G, 500 Sessions, 3Yr" {

Recommended Actions

Contact F5 Sales to renew the SWG license
