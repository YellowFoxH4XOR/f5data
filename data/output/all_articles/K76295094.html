Description

F5 publishes regular updates for the OPSWAT OESIS F5 EPSEC package. This provides updated detection signatures for endpoint access enforcement (Anti-malware, Firewall, Disk encryption etc) used by the Edge Client applications on Windows, MacOS and Linux. 

The updates are published as iso file images (epsec-1.0.0-xxx.0.iso where xxx is the release number), and can be downloaded from the specific release container on the F5 Public downloads site. The updates are installed on the BIG-IP APM, and clients are automatically updated whenever they initiate an access session. The update process checks that the OPSWAT OESIS update is signed with an F5 key.

The download folder contains the file readme_minimum_version.txt. This file contains a list of compatible BIG-IP APM devices for the update.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client
  • using OPSWAT EPSEC endpoint inspection for VPN access control

Cause

Previously the latest version of epsec could be installed (not officially supported) on older versions of BIG-IP APM, as of  December 2019 the code signing keys for the updates were changed. 
Users attempting to initiate an access session that connect to a BIG-IP APM that have an OPSWAT OESIS update without the new signing key will cause the client to reinstall the OPSWAT OESIS software on each access session initiation.

Recommended Actions

  1. When upgrading to the latest OPSWAT epsec, you should also update to the latest BIG-IP release that is listed in the 'readme_minimum_version.txt' for that epsec release.
  2. For BIG-IP APM's from 13.1.0 and later, you should also update to the the latest apmclient.iso (this contains the latest Edge Client files and can be updated independently of the base software).
  3. F5 Recommends that you should also have a test APM system where updated AntiVirus (A/V), AntiMalware or Firewall products that you are using to restrict client access can be tested for compatibility with the latest epsec releases. Potentially new releases from a Vendor will not be compatible and will result in end clients failing endpoint checks and being unable to connect to the VPN.
