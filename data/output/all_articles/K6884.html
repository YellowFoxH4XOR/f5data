Known Issue

This is the result of a known issue. BIG-IP GTM may send probe requests for a translated virtual server to inaccessible or non-existent self IP addresses when the BIG-IP GTM wide IP configuration contains a BIG-IP system with multiple self IP addresses, and some of the self IP addresses are inaccessible to the BIG-IP GTM system or are not configured on the remote BIG-IP system. As a result, BIG-IP GTM will mark the BIG-IP system as down.

F5 Product Development tracked this issue as CR61003, CR68170, CR68682 and it was fixed in BIG-IP GTM 9.2.4, 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP GTM Release Notes.
