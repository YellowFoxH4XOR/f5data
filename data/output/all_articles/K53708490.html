Known Issue

The Traffic Management Microkernel (TMM) may leak memory when BIG-IP ASM DoS L7 protection is loaded in the configuration.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is provisioned with ASM.
  • The BIG-IP configuration uses bot signatures.

    Note: Bot signatures are available in the configuration to add to DoS profiles; they appear in the Application Security tab of the profile. In the bigip.conf file, bot signatures appear as security dos bot-signature <name>.

  • You use the tmsh load sys config command to load the configuration.

Impact

BIG-IP system performance is degraded due to resource exhaustion, failover, and an eventual out-of-memory condition.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The tmsh show sys memory command indicates that the amount of used TMM memory is near the amount of allocated TMM memory.
  • When viewing memory statistics, you observe an increase in the DoS Layer 7 TMM memory subsystem allocations during configuration load. For example, you can run the following command from the Advanced Shell (bash) and load the configuration using a separate shell window:

    watch -n1 -- 'tmctl -s name,allocated,max_allocated,cur_allocs memory_usage_stat | grep -E "^name|---|^DoS Layer 7"'

  • TMM restarts unexpectedly and high availability (HA) systems may fail over.
