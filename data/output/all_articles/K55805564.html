K55805564: Dynamic CRL gets alert(46) unknown certificate error

Support Solution
Published
2022-10-29

Source
https://my.f5.com/manage/s/article/K55805564

Description

err tmm1[<PID>]: 01a40008:3: Unable to build certificate trust chain for profile /clientssl_profile

tmm1[<PID>]: 01260009:4: <IP_address>:<Port> -> <VIP>:443: Connection error: ssl_hs_do_crl_validation:6014: alert(46) unknown certificate error

Environment

  • Dynamic CRL is configured for the client-ssl profile

Cause
In the client-ssl profile, the ca-file needs to contain the whole chain including the root certificate.

Recommended Actions
Add a whole certificate chain in the ca-file of a client-ssl profile.

None
