Issue

If a FirePass controller is licensed for SSL hardware acceleration, and FirePass cannot locate the SSL accelerator card, FirePass displays an error message similar to the following example on the Reports: System Logs page:

Mar 19 12:40:58 localhost modprobe: modprobe: Can't locate module char-major-125

On a heavily loaded FirePass controller, FirePass may display a series of messages similar to the following example on the Reports: System Logs page:

Mar 19 12:40:58 localhost modprobe: modprobe: Can't locate module char-major-125
Mar 19 12:41:32 localhost last message repeated 70 times
Mar 19 12:42:34 localhost last message repeated 124 times
Mar 19 12:43:12 localhost last message repeated 40 times

An SSL accelerator card is required to perform SSL hardware acceleration. When FirePass reports this error message, the SSL accelerator card is either not functioning properly or is not installed on the FirePass controller. If you observe this error message, contact F5 Networks Technical Support.
