Description

How to load the GTM (now known as DNS) configuration file /config/bigip_gtm.conf into memory.

You can use this to restore the GTM configuration from a previous known good configuration file instead of restoring the UCS.

Environment

GTM / DNS
CLI access

Cause

N/A
Use case: Restore a known good DNS configuration file /config/bigip_gtm.conf into memory.

Recommended Actions

The actions or steps required to address the topic covered in the description.

1) Disable GTM sync (see K15479: Disabling synchronization on a BIG-IP GTM)

2) Copy the known good DNS configuration file to /config/bigip_gtm.conf 

3) Validate the configuration files with the below commands:

 # tmsh load sys config verify <--- for base configuration files

 # tmsh load sys config gtm-only verify <--- for the DNS /config/bigip_gtm.conf

4) Load the DNS configuration file into memory

 # tmsh load sys config gtm-only <--- to load the good /config/bigip_gtm.conf

 # tmsh save sys config gtm-only <--- to save the good /config/bigip_gtm.conf

5) Update a GTM configuration object such as a monitor to set the GTM with the latest commitID so that GTM server syncs to the other GTM servers in the GTM sync group.

6) Enable GTM sync (see K45907236: Overview of BIG-IP DNS synchronization)

Additional Information

Note: The command "tmsh load sys config" does not load the DNS configuration; instead you should use "tmsh load sys config gtm-only" to load the /config/bigip_gtm.conf DNS configuration into memory.
