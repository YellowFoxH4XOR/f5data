K96724184: AS3 Application Deployment via BIG-IQ Should Not Target an Existing Partition

Type
Support Solution
Published
2021-02-19
Updated

Applies to

  • BIG-IQ Centralized Management: 7.X.X, 6.1.X
Source

Description

AS3 Application templates deployed from a BIG-IQ should not be deployed into an existing administrative partition.
  • AS3 Applications create Tenants and are deployed into a Tenant partition on the target BIG-IP
  • A Tenant is equivalent to a Partition on the BIG-IP and a Partition will be created with the Tenant name given
  • If deployed into an existing partition any configuration objects that existed prior to the deployment will be removed
  • Multiple applications can be deployed into the same Tenant so they can be used as a partition once it is created via the AS3 deploy

Environment

This is only for AS3 deploys from a BIG-IQ to a managed BIG-IP device

Recommended Actions

It is not recommended to deploy AS3 Applications into a pre-existing partition on a BIG-IP that was not created with an AS3 deployment.
