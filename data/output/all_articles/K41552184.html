Issue

Error Message

warning tmm[<PID>]: 01260024:4: OCSP failure on profile </Directory/SSL Profile Name>, certificate with issuer <Issuer Information> and serial number <Serial Number>: <Error Type> - - <Error Number>

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • </Directory/SSL Profile Name> is the location and name of the SSL profile where the problem is occurring.
  • <Issuer Information> is the name of the issuer that signed the certificate.
  • <Serial Number> is the serial number of the signed certificate.
  • <Error Type> is the type of error being reported. HTTP is the type.
  • <Error Number> is the error number being reported, typically an HTTP error code.

For example:

warning tmm[12599]: 01260024:4: OCSP failure on profile /Common/My_SSLProfile, certificate with issuer /C=US/O=thawte, Inc./CN=thawte SSL CA and serial number ffffffffffffffff: HTTP error - - 503

Message Location

You may encounter this message in the following location:

  • The /var/log/tmm file

Description

This message occurs when the following condition is met:

  • The BIG-IP system failed to get a response from the Online Certificate Status Protocol (OCSP).

Impact

None

Recommended Actions

None
