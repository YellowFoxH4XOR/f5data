Issue

Error Message

err mcpd[<PID>]: 01071c04:3: Cannot find device group (/<Directory>/<Device Group Name>).

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <Directory> is the name of the directory where the device group is configured.
  • <Device Group Name> is the name of the device group synchronization setup.

For example:

err mcpd[12663]: 01071c04:3: Cannot find device group (/Common/APM_Sync).

Message Location

You may encounter this message in the following location[s]:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The specified device group name configuration is missing. This is required to synchronize policy information.

Impact

Policy sync validation fails.

Recommended Actions

You should create a device group and use it for policy sync.
