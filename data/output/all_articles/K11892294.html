Description
The BIG-IP connection table contains information about the sessions that are currently established on the BIG-IP system. You can display and delete the contents of the BIG-IP connection table from REST API and this article details the steps on how you can do that.

Environment

  • Connection table
  • Virtual Server
  • Pool Member/Server

Cause
None

Recommended Actions

To view the connection table, you may mix/match these options as necessary to isolate the connections you are interested in.
You can narrow the connection table information by specifying the filters of the endpoints listed below.
FilterDescription
cs-client-addrThe (client) source IP address on the clientside of the connection
cs-client-portThe (client) source port on the clientside of the connection
cs-server-addrThe (server) destination IP address on the clientside of the connection (i.e. the Virtual Server IP address)
cs-server-portThe (server) destination port on the clientside of the connection (i.e. the Virtual Server port)
ss-client-addrThe (client) source IP address on the serverside of the connection (i.e. the SNAT address)
ss-client-portThe (client) source port on the serverside of the connection (i.e. the SNAT port)
ss-server-addrThe (server) destination IP address on the serverside of the connection (i.e., the Pool Member address)
ss-server-portThe (server) destination port on the serverside of the connection (i.e., the Pool Member port)

The following examples show a number of options that you can use to display or delete only those connection entries that correspond to specific IP address or port value.
Important:  On systems with a large number of connections, executing the following commands with a large output may result in excessive output causing device instability.  It is recommended you limit the output to specific IP address and/or port combination as demonstrated in the examples below.
  • Displaying connection table entries
  • Deleting connection table entries
Displaying connection table entries
  1. To display the BIG-IP connection table entries for a particular, you can use the following REST API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/connection?options=cs-server-addr+<vs_ip>+cs-server-port+<vs_port>

    For example, to display the connection table entries for a 10.10.2.2:443 virtual server, you can use the following API query

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/connection?options=cs-server-addr+10.10.2.2+cs-server-port+443

  2. To display the BIG-IP connection table entries for a particular client IP address, use the following REST API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/connection?options=cs-client-addr+<client_ip>

    For example, to display the BIG-IP connection table entries for 10.10.20.2 client IP address, you can use the following API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/connection?options=cs-client-addr+10.10.20.2

  3. To display the BIG-IP connection table entries for a particular pool member, use the following REST API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/connection?options=ss-server-addr+<pool_member_ip>+ss-server-port+<pool_member_port>

    For example, to display the BIG-IP connection table entries for 192.168.10.2:80 pool member, you can use the following API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/connection?options=ss-server-addr+192.168.10.2+ss-server-port+80


Deleting connection table entries
To delete the BIG-IP connection table entries for a particular client IP and virtual server, you use the following REST API query:

curl -ku [username]:[password] -H "Content-Type: application/json" -X DELETE https://[IP Address]/mgmt/tm/sys/connection?options=cs-client-addr+<client_ip>+cs-server-addr+<vs_ip>+cs-server-port+<vs_port>

For example, to delete the BIG-IP connection table entries for 10.10.20.2 client IP address and 10.10.2.2:443 virtual server, you can use the following API query:

curl -ku [username]:[password] -H "Content-Type: application/json" -X DELETE https://[IP Address]/mgmt/tm/sys/connection?options=cs-client-addr+10.10.20.2+cs-server-addr+10.10.2.2+cs-server-port+443
