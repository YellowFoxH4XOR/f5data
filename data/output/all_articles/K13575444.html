Description

TMM core after enabling mirroring.

Core seen shortly after mirroring connection established with peer:

err tmm[26535]: 01340001:3: HA Connection with peer 192.168.1.12:32772 for traffic-group /Common/traffic-group-1 established.

Environment

  • Mirroring enabled

Cause

Bug ID 1009161: SSL mirroring protect for null sessions
Bug ID 1008009: SSL mirroring null hs during session sync state

Recommended Actions

A workaround is to disable connection mirroring.

Alternatively, open a service request with F5 Support and provide the core files for analysis.

At the time of this article's publication, there is no fixed version, but it may be possible to provide an engineering hotfix containing the fixes for bug ID 1009161 and bug ID 1008009.
