Topic

Common Criteria Certification for BIG-IP 10.2.2.

Description

National Information Assurance Partnership (NIAP) has certified BIG-IP 10.2.2 on the 6900, 8900, and 11050 platforms as Common Criteria EAL level 2+ certified. For more information about the Security Target and related information, refer to the following NIAP website:

http://www.niap-ccevs.org/st/vid10408/

Common Criteria is an international initiative to standardize security functionality and assurance measures. For more information about Common Criteria Certification, refer to the following Common Criteria website:

http://www.commoncriteriaportal.org

Installation

To install BIG-IP in accordance with the evaluation's expectations, refer to the following document:

  • Common Criteria Supplement EAL2 (10-2020-R-0039) Version 3.1
