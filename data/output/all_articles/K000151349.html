K000151349: Upgrading the NGINX Ingress Controller to 3.7.0 to 3.7.x or later may fail due to label validation error

Type
Support Solution
Published
2025-05-15
Updated
2025-05-15
Applies to
  • NGINX Products
  • NGINX Ingress Controller
Source
https://my.f5.com/manage/s/article/K000151349

Description

Upgrading the NGINX Ingress Controller using Helm from versions prior to 3.7.0 to 3.7.x or later may fail with the following error message:

UPGRADE FAILED: rendered manifests contain a resource that already exists. 
Unable to continue with update: 
Lease "ingress-controller-nginx-ingress-leader-election" in namespace "ingress" exists and cannot be imported into the current release: 
invalid ownership metadata; label validation error: missing key "app.kubernetes.io/managed-by": must be set to "Helm"; 
annotation validation error: 
missing key "meta.helm.sh/release-name": must be set to "ingress-controller"; 
annotation validation error: missing key "meta.helm.sh/release-namespace": must be set to "ingress"

 

Environment

  • NGINX Ingress Controller deployed with Helm
  • Upgrading from versions prior to 3.7.0 to 3.7.x or later  

Cause

  • Starting with NGINX Ingress Controller version 3.7.0, Helm manages the Lease resource for leader election and requires specific labels and annotations for ownership.
  • If the existing Lease resource was created by an older version, it may lack the required Helm metadata. This prevents Helm from taking ownership of the resource during the upgrade, resulting in the error.

Recommended Actions

To resolve the upgrade failure, use one of the following approaches:

Option 1: Manually update the Lease resource

  1.  Edit the Lease resource in the relevant namespace as shown below and then retry the upgrade again: 
    kubectl edit lease ingress-controller-nginx-ingress-leader-election -n <namespace>
  2. Add or update the following labels and annotations in the metadata section: 
       metadata:
     labels:
       app.kubernetes.io/managed-by: Helm
       app.kubernetes.io/instance: <release-name>
       app.kubernetes.io/name: nginx-ingress
       app.kubernetes.io/version: <target-nic-version>
       helm.sh/chart: nginx-ingress-<chart-version>
     annotations:
       meta.helm.sh/release-name: <release-name>
       meta.helm.sh/release-namespace: <namespace>
  3. Save and exit the editor, then retry the Helm upgrade.

Option 2: Recreate the deployment

  1. Uninstall the existing Helm release: 
    helm uninstall <release-name> -n <namespace>
  2. Ensure that any remaining Lease resources are deleted: 
    kubectl delete lease ingress-controller-nginx-ingress-leader-election -n <namespace>
  3. Reinstall NGINX Ingress Controller using an updated Helm chart as per official documentation.
