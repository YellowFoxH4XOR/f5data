Description

After you install a new BIG-IP Virtual Edition software version and attempt to boot into it you may see an error:

This license does not support the software version you are rebooting into. Are you sure you want to boot into the specified boot volume?

Environment

  • BIG-IP Virtual Edition (VE)
  • Version exclusive license
  • New software version on the the exclusive list

Cause

If the license file limits the allowed software versions, upgrades to non-licensed versions are not allowed. 

Recommended Actions

You can confirm if version limitation applies to your license by issuing following command:

grep Exclusive_version /config/bigip.license

The following example output indicates you can upgrade the system to BIG-IP VE versions through 16.x.x: 

Exclusive_version : 11.6.*
Exclusive_version : 12.*.*
Exclusive_version : 13.*.*
Exclusive_version : 14.*.*
Exclusive_version : 15.*.*
Exclusive_version : 16.*.*
Exclusive_version : 5.*.*
Exclusive_version : 6.*.*
Exclusive_version : 7.*.*
Exclusive_version : 8.*.*
 

If your desired software version is not on the exclusive version list, you will need to obtain a new license.

Additional Information

K15643: BIG-IP VE Version Plus license offerings
K42091606: Determine your BIG-IP VE SKU and permitted software version range
