Description

Deployment from BIG-IQ is failing with unable to save configuration error and/or "Device Not available".

 

Environment

  • BIG-IQ
  • BIG-IP AFM
  • AFM policy deployment

 

Cause

/var filling up on BIG-IP during deployment
Stats collection polling interval is too frequent
