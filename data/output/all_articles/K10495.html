Topic

F5 has recently discovered and corrected a number of critical issues that affect customers running BIG-IP 10.0.0. F5 recommends that all customers currently running 10.0.0 install Hotfix-BIGIP-10.0.0-5519.0-HF3, or a later version of the cumulative hotfix rollup, as soon as possible.

Note: CRs new to the release are in bold text.

The following CRs are fixed in Hotfix-BIGIP-10.0.0-5519.0-HF3 for BIG-IP 10.0.0:
