K000160625: Troubleshooting Uncorrectable ECC Memory Errors Causing Tenant Disconnection on F5OS rSeries

Support Solution
Published

Updated
2026-04-21
Applies to

Source
https://my.f5.com/manage/s/article/K000160625

Description

A tenant on an F5OS rSeries platform becomes disconnected or fails to recover, with other tenants remaining operational. The issue is accompanied by tenant status stuck at "Liveness probe failed: building SEP devices" and system logs reporting uncorrectable ECC memory errors (UE), hardware device faults, and memory page poisoning with errors such as:

 

  • mce: Uncorrected hardware memory error in user-access at <address>
  • Memory failure: <page>: already hardware poisoned
  • 65536 appliance hardware-device-fault ASSERT ERROR "Hardware device fault detected"
  • Error mapping client DMA memory to VFIO IOMMU. Disconnecting client.

Environment

F5OS

Cause

The issue is caused by an uncorrectable ECC memory error (UE) on the host system's DIMM. The kernel detects the error, poisons the affected memory page, and attempts to isolate it. This can result in tenant VM eviction and failure to remap memory, preventing the tenant from recovering. The underlying cause is hardware degradation or failure of the memory module.

Answer/Recommended Actions

Review system logs for uncorrectable ECC memory errors and hardware device faults:

    65536 appliance hardware-device-fault ASSERT ERROR "Hardware device fault detected" "2026-04-03 13:57:53.791866942 UTC"                     
    65536 appliance hardware-device-fault EVENT NA "RAS MCE uncorrectable errors detected, count=1" "2026-04-03 13:57:53.791890646 UTC"          
    65536 appliance hardware-device-fault EVENT NA "RAS MCE unknown errors detected, count=10" "2026-04-03 13:57:53.812779720 UTC" 

Use the following command on the F5OS host CL as root.

grep -i "uncorrect\|hardware poisoned\|mce" /var/F5/system/log/platform.log

If uncorrectable ECC memory errors are found and tenants are impacted, re-provision and redeploy the affected tenant.

If issue still persists, please open a case with F5 Support.
