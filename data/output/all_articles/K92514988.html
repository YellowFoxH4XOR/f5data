K92514988: Traffic is reseted by virtual server with 'log' command in iRule with Error message: TCL error: : /<partition>/<irulename> <Event> - Traffic rejected (line X) (line X) invoked from within...

Source

Description

Connection resetd with the following log lines appear in /var/log/ltm :

err tmm[<PID>]: 01220001:3: TCL error: TCL error: : /<partition>/<iRule_name> <Event> - Traffic rejected (line X) (line X) invoked from within "log <IP of Remote Syslog Server> ....

where <iRule_name> is the name of the iRule that generated the log message.

Environment

  • BIG-IP 
  • iRule
  • log command

Cause

  • Functional limitation: : Every time the log function in an iRule is called, they are queued, and the queues size has limit.

Recommended Actions

Workaround 1:  Add 'after 1000' statement after 'log' command in iRule as below:

ltm rule /Common/iRule_Example {
when CLIENTSSL_HANDSHAKE {
        switch -glob [SSL::cipher version] {
         "*1.1*" -
         "*1.2*" {
           log 192.168.1.1 "[IP::client_addr] uses either TLS 1.1 or TLS 1.2."
            after 1000
         }
         default {
           log 192.168.1.1 "[IP::client_addr] uses tls1 or lower."
            after 1000
         }
      }
}
}

Workaround # 2: Enable HSL logging for the virtual server.
