Description

BIG-IP does not currently implement an SNMP OID that returns consumed Connectivity Connectivity Sessions (CCU) counts. To do this you must configure a custom SNMP OID.

Environment

  • APM
  • SNMP

Cause

None, this is expected behavior.

Recommended Actions

To configure a custom SNMP OID that returns a consumed CCU count, perform the following procedure:

1. Log in, with administrative privileges, to the command line of the affected device.
2. Using a text editor, create the following file
    /config/snmp/ccuUsage.sh
3. Enter one or the other of the following command syntax into the /config/snmp/ccuUsage.sh file, based on BIG-IP version.
        BIG-IP version 11.x - 13.x:
     #/bin/sh
    count=$(tmsh show apm license|grep "current connectivity sessions"|cut -d":" -f2)
    if [[ "$count" == *"k"* ]]
    then
      count=$(echo $count | awk -FK '{print $1 * 1000 }')
    fi
    echo $count      
       
        BIG-IP version 14.x and newer:
    #/bin/sh
    count=$(tmsh show apm license raw|grep "current connectivity sessions"|cut -d":" -f2)
    echo $count

4. Save the changes.
5. To change the file mode bits, type the following command:
    chmod 755 /config/snmp/ccuUsage.sh
6. Using a text editor, create the following file:
    /config/snmp/custom_mib.tcl
7. Enter the following command syntax in the /config/snmp/custom_mib.tcl file:
register_mib ".1" ccu_count GAUGE
    proc ccu_count {} {
        set status [catch { exec /bin/bash /config/snmp/ccuUsage.sh } result]
        return $result
    }
8. Save the changes.
9. To restart the SNMP service, type the following command:
tmsh restart /sys service snmpd
10. To verify that the workaround is functional, type the following command:
    snmpwalk -Os -c public -v 2c localhost .1.3.6.1.4.1.3375.2.100.1

Additional Information

CCU consumption count differs from connectivity connection counts provided by the following OIDs:

  • apmPcStatTotConns
  • apmPcStatCurConns
  • apmPcStatMaxConns
  • apmGlobalConnectivityStatTotConns
  • apmGlobalConnectivityStatCurConns
  • apmGlobalConnectivityStatMaxConns

APM CCU consumption count can be pulled from the BIG-IP via APM licensing statistics:

tmsh show /apm license | grep "current connectivity sessions"
