Known Issue

This is the result of a known issue. The Proxy Options setting, in the TCP profile, is disabled by default and specifies that the system advertises TCP time stamps to the server only when the option is negotiated with the client.

The Proxy Options setting is not currently functional and has no effect when the setting is changed.

F5 Product Development tracked this issue as ID 346829, and it was fixed in BIG-IP 12.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.
