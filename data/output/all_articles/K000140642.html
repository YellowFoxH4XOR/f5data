Description

The LTM policy is not forwarding logs to the configured remote Syslog server. The policy can look like below.

...
collector-apiservice-resettraffic {
actions {
0 {
log
write
facility local0
ip-address 172.13.34.2                                <--
message tcl:[IP::client_addr][HTTP::uri]
port 514
priority info
}
1 {
shutdown
connection
}
}
conditions {
0 {
http-host
host
values { test.com}
}
}
ordinal 1}
...

Environment

  • LTM policy
  • Remote Syslog

Cause

This behavior is noticed when the remote Syslog IP address is reachable through the management interface.

Recommended Actions

1. Verify how bigip is reaching the remote Syslog:

# ip r g <remote_syslog_ip>

2. If bigip is reaching the remote Syslog through management, a route can be configured to reach the remote syslog through TMM, or another ip that is reachable through TMM can be used.
