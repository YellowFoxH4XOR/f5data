Known Issue

This is the result of a known issue. A leading asterisk in a BIG-IP health monitor receive string prevents the monitor status from updating properly. For example, the following health monitor receive string contains a leading asterisk, which will prevent the monitor status from updating properly:

monitor testing {
   defaults from http
   recv "*example"
}

F5 Product Development tracked this issue as CR75546 and it was fixed in BIG-IP versions 9.1.3,  9.3.0, and 9.4.2. For information about upgrading, refer to the BIG-IP LTM release notes.
