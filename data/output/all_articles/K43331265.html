Known Issue

The EUD Blade Sensor Test may fail, indicating a false positive for the VIPRION blades.

This issue occurs when all of the following conditions are met:

  • You are running EUD_VF build 15.0.0.786.0 or earlier, or any version of EUD_S.
    • For information about determining your EUD version, refer to K8002: Determining the End-User Diagnostics version.
  • You perform the Blade Sensor Test on one of the following VIPRION blades:
    • VIPRION B2100 with the part number 400-0068-00
    • VIPRION B2150 with the part number 400-0069-0

Note: You can find the part number specified in the EUD system report.

Impact

The EUD sensor displays an erroneous error message that you can safely ignore.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system reports an error message that appears similar to the following example:

    Mezzanine +1.0V_OCT2 voltage (0x009B) (mV): 1100
    ERROR: Mezzanine +1.0V_OCT2 voltage (0x009B) (mV): Measured Value=1100, High Limit=1050
    Test Complete: Blade Sensor Test: FAILED

  • EUD_VF and EUD_S fail the +1.0V_OCT2 measurement within the sensor tests, due to incorrect thresholds for the compression chipset.

Resolution

Status

F5 Product Development has assigned ID 442131 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases, point releases, or hotfixes that resolve this issue, refer to the following table.

Workaround

To work around this issue, you can upgrade your EUD build to 15.0.1.10.0 or later before running the test.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.

Note: In BIG-IP 13.0.0 and later, F5 no longer includes the EUD images in the base .iso image file. You must either install the latest EUD package from a BIG-IP-x.y.z.n.n.nnn-RECOVERY.iso image or download the EUD image of your specific platform from the Platform / EUD product page of the F5 Downloads site. For more information, refer to K03203114: Multiple BIG-IP iso images are available (13.x - 14.x).
