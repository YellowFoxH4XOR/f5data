Issue

The grub_default command is used to view and modify boot partition information on the BIG-IP system. When the grub_open command is run, a lock file is created to prevent other users or processes from making changes concurrently. If the grub_close command is not run after the grub_open command, running the grub_default command will result in the following error message:

Failed to open boot configuration file: status = 3

You can prevent this error message from occurring by closing the grub.conf file and removing the lock file after running the grub_open command and before running the grub_default command. To close the configuration file and remove the lock file, type the following command at the command line:

grub_close

When the command returns, you can run the grub_default command.

Note: For more information about the use of the grub_default command, refer to K8937: The switchboot -d option has been removed.
