Topic

If you are using a cookie persistence profile with encryption enabled, you can view encryption statistics related to the profile using the tmctl command.

Description

When you configure a cookie persistence profile you have the option of configuring the system to encrypt the persistence cookies. Encrypting the persistence cookies protects against attacks such as, cookie tampering and cookie injection, and obscures sensitive data which may be present in the persistence cookie.

The BIG-IP system uses a 192-bit AES cipher to encrypt persistence cookies and then encodes the cookies using the Base64 encoding scheme. You can use the tmctl command to display encryption statistics such as, the total number of AES encryption / decryption operations, the total bytes encrypted / decrypted, the number of encryption keys generated and the keys cached by TMM.

Note: For information about configuring cookie encryption for BIG-IP persistence cookies, refer to K23254150: Configuring cookie encryption for BIG-IP persistence cookies from the cookie persistence profile.

View encryption statistics for the cookie persistence profile

To view encryption statistics for the cookie persistence profile, run the tmctl tmm_aes_stat command.

For example,

tmctl tmm_aes_stat
keys keys_cached keys_evicted keys_found keys_reused keys_derived encrypts
---- ----------- ------------ ---------- ----------- ------------ --------
   1           1            0          1           0            0      203

encrypts_compat encrypted_bytes decrypts decrypts_compat decrypted_bytes
--------------- --------------- -------- --------------- ---------------
              0            4263        0               0               0

verifies_failed salts_generated
--------------- ---------------
              0               1

For information about the relevant AES statistics for cookie persistence encryption, refer to the following table:

 
FieldDefinitionDetails
keysThe number of AES encryption keys generated by TMM instances.When a cookie persistence profile with encryption is assigned to a virtual server, each running TMM instance generates a new AES key.
keys_cachedThe number of AES encryption keys cached by TMM instances.When TMM starts up and a cookie persistence profile is assigned to a virtual server, each running TMM instance generates a new AES key and caches it internally.
keys_evictedThe number of AES encryption keys evicted from the cache.Keys may be evicted when the number of generated AES keys exceeds the cache size.
keys_reusedThe number of AES encryption keys reused in decryption operations.AES encryption keys are reused during decryption operations.
keys_derivedNew keys may be derived when a cookie is received with invalid encrypted data.In some cases the system derives new keys. For example, if an attacker supplies invalid encrypted cookie data, then it is likely that the initialization vector will not match an existing one, so a new key will be derived.
encryptsThe number of AES encryption operations.The encrypts operations increment when the system encrypts persistence cookies.
encrypted_bytesThe total number of bytes during AES encryption operations.The encrypted bytes increments when the system encrypts persistence cookies.
decryptsThe number of AES decryption operations.The decrypts operations increment when the system decrypts persistence cookies.
decrypted_bytesThe total number of bytes during AES encryption operations.The decrypted bytes increments when the system decrypts persistence cookies.
verifies_failedThe system failed to verify the key.This may occur if the Message Authentication Code verifying the cipher text has been altered.
salts_generatedThe total number of salts generated.The salt is randomly generated and used in combination with a passphrase to generate the key used to encrypt or decrypt the data.
