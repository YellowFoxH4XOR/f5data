K000147513: What is the order of precedence for DNS Load Balancer rules?

Description

I would like to know what the order of precedence is for DNS LB rules.

Environment

  • F5® Distributed Cloud DNS Load Balancer

Answer

  • Order of precedence:
    • Region (i.e user IP address) is checked initially
    • If user IP address falls in multiple Regions then the Region with the highest score wins

  • Example 1: There are 2 Load Balancing rules:
    • EU - European users
    • Anywhere - users from all over the world

       

    • In this example, European users will be served by the Anywhere rule due to the higher score

  • Example 2: There are 3 Load Balancer rules
    • Anywhere - users from all over the world
    • North America - users from the North America region
    • USA - users from the United States

       

    • Users from Kansas, USA, will be served by the USA  rule because
      • Client IP address matches 3 Regions (Anywhere, North America, USA)
      • USA proximity rule has a higher scope among these 3 rules
    • Users from Montreal, QC, Canada will be served by the North America  rule because
      • Client IP address matches 2 Regions (Anywhere, North America).
      • North America  rule has a higher scope among these 2 rules.

NOTE: The response could be affected by the local DNS resolver and the DNS cache on the client-side
