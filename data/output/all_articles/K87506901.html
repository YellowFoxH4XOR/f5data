Known Issue

The Configuration utility fails to display non-English characters as configured in the System Preferences page.

This issue occurs when the following condition is met:

  • You configure the following settings from the Configuration utility > System > Preferences page with non-English characters:
    • Username Prompt
    • Password Prompt
    • Advisory Text

      Note: The Advisory Text banner is not visible in the Security Settings section of the Preferences page from the default Basic view. You may view the Advisory Text banner when you switch to the Advanced view. Additionally, the Advisory Text banner will only take effect if you enable the Show Advisory Banner.

Impact

The Configuration utility does not correctly display non-English characters configured in the System Preferences page.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The login or password prompt with non-English characters configured in the System Preferences page do not display correctly on the Configuration utility login page.
  • The Advisory Text banner located at the top of the Configuration utility pages do not display non-English characters correctly.
