Known Issue

The monpd process may periodically log harmless messages.

This issue occurs when the following condition is met:

  • You have provisioned the BIG-IP Analytics (AVR) module with any of the following modules:

    • BIG-IP AFM
    • BIG-IP APM
    • BIG-IP ASM
    • BIG-IP PEM

    Note: The BIG-IP system uses the monpd process with the avrd process to report application performance data.

    Impact

    None. The harmless messages do not impact data accuracy or performance.

    Symptoms

    As a result of this issue, you may encounter the following symptom:

    • Messages similar to the following example are logged to the /var/log/ltm and /var/log/avr/monpd.log files:

      err stat_bridge_thread[1234]: monpd|ERR|<timestamp>|23456| [stat_bridge_thread::validateCorrectNumberOfPartitions, ] Too many partitions (4) defined for DB table AVR_STAT_ASM_HTTP_ATTACK_DATA_T
