Description

 

When AS3 addressDiscovery fqdn pools are updating, they react to different DNS failures, so here we will try to list these, and how the pool reacts to these.

When AS3 addressDiscovery fqdn pool sends a DNS Request, it expects a response within 5 seconds. 
If it does not get a response, no changes are made to the pool members, and it will then wait for the required interval, before sending another DNS Request.

 

  1. If it does get a DNS Response, it first check if the Rcode is NOERROR
    It then checks if the DNS Response contains answers, and if it does, it then checks if the IP Addresses differ from the current pool members, and if the are different, updates the pool members. Otherwise there is no change to the pool members, and will then wait for the required interval before sending another DNS Request


  2. If the Rcode is anything other than NOERROR, it will delete all Pool Members, and will then wait for the required interval before sending another DNS Request
