K2970: Reasons why a newly configured network interface card does not detect link when connected to the network

Applies to

  • BIG-IP 4.X: 4.6.4
Source

Topic

Starting in version 4.0, BIG-IP will establish link only if an interface is included in a VLAN.

To resolve this issue, add the new interface to a VLAN and reconnect to the network. BIG-IP should now report link accurately. For specific instructions about how to add an interface to a VLAN, refer to the BIG-IP Reference Guide.

If this does not resolve the issue, contact F5 Technical Support for assistance.
