Description

CPU usage spikes hourly, and only odd cores are affected (control plane).

Environment

  • BIG-IP 11.4 and later

Cause

Behavior is by design. The BIG-IP generates new Diffie-Hellman (DH) parameters on an hourly basis.

For further details, please see: K14818: Generation of new Diffie-Hellman parameters occurs hourly.

Recommended Actions

To determine the cause:

  1. Check if the hourly spike is happening to even number cores or odd number cores.
  2. If odd number core is spiking hourly, monitor what is using high CPU, with top command.
  3. openssl or genkey-1024 should be the processes causing the temporary CPU spike.

Additional Information

If you want to keep the top output as text file for 24 hours for every 5 min, you can run this command on CLI:

for i in {1..576} ; do top -bcn 1 >> /var/tmp/top_oneday.txt ; sleep 300; done;

Note: {} defines how many times the script runs. And the number after sleep defines how often, in seconds.
