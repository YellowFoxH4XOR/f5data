Description

GUI Dashboard Security ›› Reporting : DoS not showing any data
When testing dos attacks or in Dos attack event, BIG-IP detects the Dos attack, however No data reported under dashboard for Dos and no details for attack reported under event logs. 

Environment

  • Dos attack detected
  • Dos profile attached to virtual server
  • BIG-IP ASM/AFM managed by BIG-IQ
  • Stats collection is enabled
  • Security ›› Reporting : DoS Dashboard not working

Cause

This could happen due to few reasons:

  1. No Dos logging profile is enabled on virtual server 
  2. Device is configured with BIG-IQ analytics to use offbox analytics, meaning all statistics are sent to BIG-IQ

Recommended Actions

  1. Make sure dos logging profile attached to virtual server with local-db-publisher.
  2. By default, use-offbox setting is enabled and BIG-IP system will send the statistics to BIG-IQ without saving the data locally on the device.
    To verify how the BIG-IP system keeps analytics data, run the below command on the BIG-IP system.

    # tmsh list analytics global-settings 
            analytics global-settings {
            avrd-interval 30
            ecm-port 443
            enable-bigiq-configuration enabled
            offbox-protocol https
            offbox-tcp-addresses { 10.0.0.1 10.0.0.2 }
            offbox-tcp-port 443
            source-id 62038ca1-07bd-4bb4-9e93-c697b00c37d1_10.0.0.3
            use-offbox enabled               
            }
     
  3. Disable use-offbox setting using below command: 
    # tmsh modify analytics global-settings use-offbox disabled

Additional Information

Bug ID 1016473: Collected-stats-internal-logging is disabled when BIG-IP is removed from BIG-IQ

If "collected-stats-internal-logging" is disabled the DoS Dashboard will not populate with new attack data.
You may enable with the following commands:

tmsh modify security analytics settings { collected-stats-internal-logging enabled }
tmsh save sys config

Stats collection must still be disabled for this device on BIG-IQ
