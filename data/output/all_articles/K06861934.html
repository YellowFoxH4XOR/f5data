Description

APM logs   "Access encountered error: ERR_NOT_FOUND. File: ../modules/hudfilter/access/access.c, Function: access_save_init_req_to_sessiondb" at priority "err"

Environment
  • APM in use
  • Using irule with APM

Cause

  • A irule is calling ACCESS::remove
  • A client is subsequently doing a POST
  • APM is attempting to set a session variable on a session that no longer exists

Recommended Actions

The message can be ignored. Its priority should be "debug" rather than "err".

Additional Information

Bug ID 567503: ACCESS::remove can result in confusing ERR_NOT_FOUND logs
