Description

Users are not submitting domain information in the username field and an alternative method for defining the VMWare "Domain" information is not configured.

Environment

  • BIG-IP APM
  • VMWare Horizon Client

Cause

In a VDI - VMWare Horizon View connection attempt, this error is a failure indication indicating no domain name, or a bad Domain name is provided by the user when connecting thru VDI to the VMWare Horizon View environment using the Vmware Horizon client, or web-based access.

Recommended Actions

  • Setting a "domain" variable in Variable Assign object before the VDI Resource assign objects.   
    This could be achieved by performing an AD Query, before the Variable Assign, then using "session.ad.last.actualdomain" value from AD which should set the appropriate Domain value for the SSO credentials assign variable.
  • Having the user correctly provide  domain and username in the username field.  For example domain\user or user@domain.ext. depending on your backend username requirements
