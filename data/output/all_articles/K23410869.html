Known Issue

Nested configuration objects may cause tmsh list/save commands to execute slowly or iControl REST API calls to time out.

This issue occurs when the following condition is met:

  • The configuration contains thousands of configuration objects that have other nested configuration objects.

    For example, a virtual server configuration object has profile configuration objects nested within the virtual server configuration, similar to the following:

    ltm virtual vs {
    destination 10.10.10.10:http
    ip-protocol tcp
    mask 255.255.255.255
    profiles {
    http { }
    http_security { }
    tcp { }
    }
    source 0.0.0.0/0
    translate-address enabled
    translate-port enabled
    vs-index 26
    }
In this example, the http, http_security, and tcp profiles are the nested profile configuration objects.

Impact

Traffic Management Shell (tmsh) commands for an affected configuration can take longer than 30 seconds to complete, or iControl REST API calls may time out and fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Executing the tmsh list command for a configuration that is approximately 2 MB in size, with thousands of nested objects, takes longer than 30 seconds to complete.

    For example, in a configuration that contains thousands of virtual servers with nested objects, it might take longer than 30 seconds to run either of the following commands:

    • tmsh list ltm virtual
    • tmsh save config
  • iControl REST API calls for an affected configuration time out and fail.
