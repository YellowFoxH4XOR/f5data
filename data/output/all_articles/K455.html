Topic

To log actions from IP filters, you must:

  • Enable logging within the filter statement
  • Run the ipfwlog program, which accepts the output from the IP filters and logs them to a file or presents them to the screen.

Note: Because logging of IP filters can have significant impacts on general performance, disk I/O, and disk space, F5 does not recommend the constant use of logging.

Enabling logging within an IP filter statement

To enable logging within an IP filter statement, you must add a value to the statement that specifies how much of the packet, in bytes, should be captured and passed to the logging mechanism. For example, the following rule would deny packets from the loopback network and log the first 50 bytes of the packet:

deny 50 ip from 127.0.0.0/8 to any

Without logging, the statement would appear as follows:

deny ip from 127.0.0.0/8 to any

Running ipfwlog

You can run the ipfwlog program in two forms:

  • Interactively

    Prints any logging information to the screen.

    To run ipfwlog interactively, type the following command:

    ipfwlog

  • As a daemon

    Saves any logging information to a file.

    To run ipfwlog in this mode, use the following syntax:

    ipfwlog -dl <logfile>

    For example:

    ipfwlog -dl /var/log/filter.log
