Known Issue

The BIG-IP ISO image installation may be unable to format using the partitions disk style.

This issue occurs when all of the following conditions are met:

  • The BIG-IP platform supports version 10.2.3
  • You perform the BIG-IP version 10.2.3 ISO image installation using the image2disk command with the format=partitions option

Impact

You may not be able to boot up the BIG-IP system after the installation failure.

Symptoms

As a result of this issue, you may encounter one of the following symptoms:

  • You attempt the installation from the BIG-IP command line using the image2disk command with the --format=partitions option. After the installation, the system reboots and after passing the BIOS screen, the system will hang with the word, GRUB, on the top-left corner of the console screen.
  • You attempt to install version 10.2.3 using a USB DVD-ROM drive with the product DVD. At the MOS prompt, you attempt to perform the installation with the image2disk command using the --format=partitions option.

    For example:

    image2disk --format=partitions --nosaveconfig

    The installation process will fail and abort with a similar error message:

    Terminal error: Platform initialization failed.

Workaround

To work around this issue, you can enter the diskinit command from the MOS prompt to format the disks to the partitions style before using the image2disk command to perform the installation. To do so, perform the following procedure:

Impact of workaround: This issue reported only occurs during an installation procedure; therefore, the system is assumed to be in a maintenance window.

  1. Download the product image ISO for BIG-IP version 10.2.3, and prepare the product image ISO file into a DVD disc.
  2. Use a USB DVD-ROM drive with the DVD disc from step 1 and boot the system into the MOS prompt.
  3. When prompted for the terminal type, press Enter to use vt100 emulation, or type the name of the terminal emulator you are using.

    For example, the terminal type prompt will display similar to the following example:

    Terminal type? [vt100]
  4. To break the automatic installation process and enter into the MOS prompt, press Ctrl+C.
  5. Perform disk initialization to format the disk to partitions style by typing the following command:

    diskinit --style partitions
  6. After the diskinit process completes, perform the installation by typing the following command:

    image2disk --instslot=HD1.1 --nosaveconfig

    In this command, note the following:
    • <HD1.1> is the desired slot to install 10.2.3
  7. After the installation completes, the system is ready for use after a reboot. To reboot, type the following command:

    reboot
  8. Press Enter.

Recovering from this issue

To recover from this issue, you must perform a clean installation of the BIG-IP system. For more information, refer to K10819: Performing a clean installation of BIG-IP version 10.x or Enterprise Manager 2.x.
