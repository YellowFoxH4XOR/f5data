Description:

Unexpected blocking of previously allowed application traffic occurs on BIG-IP Advanced WAF after changing Policy Builder learning mode to Manual. System logs may show configuration changes such as enabling meta character enforcement and setting parameter value length limits, resulting in false positives for violations like "Illegal meta character in parameter name" and "Illegal parameter value length." Example log entries:

ASMConfig change: Policy Building Settings [update]: Learning Mode was set to Manual.

ASMConfig change: Parameter * [update]: Maximum Length was set to 10. Metachars on Parameter Value Check was set to enabled. Metachars on Parameter Name Check was set to enabled.

Environment:

  • Product: BIG-IP Advanced WAF
  • Version: 17.1.2
  • Platform: F5-BIG-BT-R10600, C128
  • WAF policy with Policy Builder enabled
  • Learning mode changed from Disabled/Automatic to Manual
  • Violations for "Illegal parameter value length" and "Illegal meta character in parameter name" set to blocking

Cause:

Changing the learning mode for the WAF policy from Disabled or Automatic to Manual triggers automatic updates by the system:

  • The wildcard parameter maximum length is reset to 10 (per F5 KB K73071141).
  • Meta character enforcement is automatically enabled for both parameter names and values—even if these violations were previously set as blocking-enabled but not actively enforced. This stricter enforcement can result in legitimate requests being blocked due to newly applied limits or character restrictions.

Recommendations:

  • After changing learning mode, review all affected violation settings—especially those related to meta characters and parameter lengths.
  • Manually adjust the wildcard parameter maximum length as needed for your application requirements.
  • If false positives occur due to meta character enforcement, review and update the allowed character sets for both parameter names and values.
  • Consider disabling or setting violations like "Illegal meta character in parameter name" and "Illegal parameter value length" to staging if they cause unexpected blocking of legitimate traffic.
  • Regularly audit policy changes and logs after modifying learning modes or accepting learning suggestions, as multiple violation settings may be impacted automatically.
  • Refer to F5 KB articles K73071141 (parameter length) and implementation guides for details on how Policy Builder changes affect entity enforcement.
