Known Issue

This is the result of a known issue. F5 issued Hotfix-114391-2 (OPSWAT 2.5.15) for FirePass 6.0.3 on January 6, 2009. However, the client update mechanism included with this hotfix does not function properly. After installing Hotfix-114391-2 on a FirePass controller, clients with OPSWAT 2.15.12 (Hotfix-108137-1) client components do not automatically download the updated OPSWAT 2.5.15 package when accessing the pre-logon sequence.

Note: Hotfix-114391-2 was also issued for other versions of FirePass software. However, this issue only affects FirePass 6.0.3.
 
F5 issued Hotfix-114391-3 for FirePass 6.0.3 on January 8, 2009 to replace Hotfix-114391-2. Hotfix-114391-3 contains the same version of the OPSWAT SDK, version 2.5.15, but it resolves the automatic update issue found in Hotfix-114391-2. You may download Hotfix-114391-3 or later versions of the OPSWAT Hotfix from the F5 Downloads page.
 
Note: You do not need to remove Hotfix-114391-2 before installing Hotfix-114391-3.
