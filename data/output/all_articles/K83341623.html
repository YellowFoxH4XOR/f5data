K83341623: Re-discover attempt produces error ''Failed to update (post or patch) device-group cm-bigip-allDevices keys on device''

Type
Support Solution
Published
2021-09-10
Updated
2023-05-09
Applies to
  • BIG-IQ
  • BIG-IQ Platforms
  • BIG-IQ Centralized Management: 7.1.0, 8.1.0, 8.0.0, 8.3.0, 8.2.0
Source
https://my.f5.com/manage/s/article/K83341623

Description

  • Unable to re-add a managed BIG-IP after deleting it from BIG-IQ
  • Attempt to re-discover BIG-IP produces error "Failed to update (post or patch) device-group cm-bigip-allDevices keys on device"

Environment

  • BIG-IQ version 7 or higher
  • BIG-IP Configuration was previously discovered by BIG-IQ

Cause

  • Unknown at this time but it is suspected that services related to REST on the BIG-IP could be in an inconsistent state

Recommended Actions
Restart the REST related services on the BIG-IP

  1. Run the following command on target BIG-IP:

    bigstart restart restjavad restnoded avrd

  2. Re-discover the BIG-IP from BIG-IQ WebUI

None
