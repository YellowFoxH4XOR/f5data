Issue

Old Behavior

In versions prior to BIG-IP APM 10.2.0 HF2, the following log message appears in the /var/log/apm file with the default log level setting of Notice:

SSO: Cannot get peer flow context 2

This message is expected any time a connection is closed between a client that authenticated using SSO and a server. The server attempts to find the client, but the client has already ended the session.

New Behavior

Beginning in BIG-IP APM 10.2.0 HF2, the log level for the preceding log message has been changed to Informational.

F5 Product Development tracked this Request for Enhancement (RFE) as ID 336827, and it was added in BIG-IP APM 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

Impact

There is no impact. You can safely ignore this message.

Recommended Actions

None
