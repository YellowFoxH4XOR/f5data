K000139372: Error: "Key Values Mismatch" in the GUI after uploading CA-signed certificate to the LTM

Type
Support Solution
Published
2024-11-05
Updated
2024-11-06
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000139372

Description

GUI access is lost after uploading CA-signed certificate to the LTM.  SSH access still working.

  • Error: Key Values Mismatch

Environment

  • LTM
  • GUI
  • CA-signed server certificate
  • OpenSSL

Cause

Key values mismatch and incorrect certificate format uploaded

Recommended Actions

1.  Verify modulus of server certificate and server key via CLI.

openssl x509 -noout -modulus -in /config/httpd/conf/ssl.crt/server.crt
openssl rsa -noout -modulus -in /config/httpd/conf/ssl.key/server.key

2. If doesn't match, create self-signed certificate via CLI

openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -sha256 -keyout /config/httpd/conf/ssl.key/server.key -out /config/httpd/conf/ssl.crt/server.crt

3.  Restart httpd service.

tmsh restart sys service httpd

4.  Reconnect to the GUI and Renew the CA-signed device certificate
