Known Issue

This is the result of a known issue. If a standby BIG-IP GTM system is responsible for sending bigip_link monitor probes, restarting the gtmd process on the standby system can cause the link status to alternate between up and down on the active unit. This issue occurs because the gtmd process waits 30 seconds before sending out the first bigip_link probe.

F5 Product Development is tracking this issue as CR88771.

Workaround

You can work around this issue by increasing the bigip_link timeout value. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Global Traffic.
  3. Click Monitors.
  4. Click Create.
  5. Type a name for the monitor.
  6. From the Type drop-down menu, select BIG-IP Link.
  7. In the Timeout field, enter 40 seconds.
  8. Click Finished.

You must now associate the new monitor with the BIG-IP GTM link.
