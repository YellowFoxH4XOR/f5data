Description

After upgrading BIG-IP device to version 17.x, bot defense configuration page (Security  ››  Bot Defense : Bot Defense Profiles) is not loading or showing empty configuration when viewing one of the Bot defense profile. Rest of the BIG-IP GUI configuration pages are loading normally after upgrade.

 

Environment

  • Upgrading BIG-IP to version 17.x from version 15.x/16.x
  • Device is upgraded successfully and all configs are loaded
  • All configuration in BIG-IP GUI is loading normally except bot defense configuration page (Security  ››  Bot Defense : Bot Defense Profiles) 

Cause

The issue seems to be when browser installed with Plug-in  (Ad Blocker Plus or Ad Blocker) and that is preventing the a set of library from being load.

 

Recommended Actions

  1. Use browser with incognito mode (were extensions are not enabled by default) or disable ad-block and possibly other extension you maybe using, then access the BIG-IP GUI bot defense policy page.
  2. Delete cache and history from the currently used Google Chrome browser/ any browser and try to access the Bot Defense profile again.
