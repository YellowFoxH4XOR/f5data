Known Issue

The BIG-IP system allows you to specify the MD5 algorithm for the Internet Key Exchange (IKE) Phase 1 Authentication Algorithm but does not recognize the MD5 algorithm.

This issue occurs when the following condition is met:

  • You specify MD5 for the IKE Phase 1 Authentication Algorithm using either the Configuration utility or the TMOS Shell (tmsh).

Impact

The system cannot establish an IP Tunnel.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system shows that MD5 is selected but will not recognize it, preventing the system from establishing the IP Tunnel.
