Known Issue

The BIG-IP system may save Secure Sockets Layer (SSL) certificates with truncated names.

This issue occurs when all of the following conditions are met:

  • You use the Configuration utility to create an SSL certificate with the Issuer set to Self.
  • You enter a certificate name that exceeds 63 characters and click Finished.

Impact

The BIG-IP system saves the certificate name with a truncated name.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H557185 on the Diagnostics > Identified > Low screen.
  • After creating the SSL certificate, the system truncates the certificate name at 63 characters.
