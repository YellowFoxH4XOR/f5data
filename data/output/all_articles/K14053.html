Known Issue

The BIG-IP ASM system reports an error message in the BIG-IP ASM log file for every rejected connection.

This issue occurs when all of the following conditions are met:

  • A virtual server has BIG-IP ASM enabled.
  • The virtual server rejects traffic using an iRule with the reject command.

    For example, the following iRule snippet rejects the client connection when the client HTTP request has a URI that starts with /bug405436:

    when HTTP_REQUEST {
    if {[string tolower [HTTP::uri]] starts_with "/bug405436"} {
    reject
    }
    }

This issue occurs because the BIG-IP ASM system attempts to process traffic after the client connection has been aborted with the reject iRule command.

Impact

The BIG-IP ASM system performance may degrade if the logging intensity is high.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H381527 on the Diagnostics > Identified > Low screen.
  • The BIG-IP ASM system reports an error message to the /var/log/ltm file for every rejected connection. For example:

    01220001:3: TCL error: _plugin_rule_/Common/pluginasm <HTTP_CLASS_SELECTED> - Failed on current side. invoked from within "ASM::enable"
  • The BIG-IP ASM system performance may degrade.

Note: This issue does not affect BIG-IP ASM 11.4.0 due to an architectural change.

Workaround

To work around this issue, you can rewrite the iRule to run the ASM::disable command before the reject command in the HTTP_CLASS_SELECTED event. Using the example iRule snippet in the previous section, the rewritten iRule snippet may look similar to the following example:

Impact of workaround: The following iRule may not apply to all environments. F5 recommends you author an iRule that may work best for your application environment. F5 recommends testing any such changes in an appropriate environment.

when HTTP_REQUEST {
set reject_conn 0
if {[string tolower [HTTP::uri]] starts_with "/bug405436"} {
set reject_conn 1
}
}
when HTTP_CLASS_SELECTED {
if { $reject_conn == 1 } {
if { [HTTP::class asm] == 1 } {
ASM::disable
}
reject
}
}
