K89088305: A lost or forgotten BIG-IQ Master Key passphrase is not recoverable

Type
Knowledge
Published
2025-02-12
Updated
2025-02-26
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.2.X, 8.3.X, 8.3.0, 8.2.0
Source
https://my.f5.com/manage/s/article/K89088305

Description

In the event that the Master Key Passphrase used when initially setting up a BIG-IQ system is lost or forgotten, the only way to recover is to restore the system and start from initial configuration.

Environment

  • BIG-IQ all version

Cause

This is by design and was intended as a security feature by the BIG-IQ product.

Recommended Actions

To start from initial configuration, please follow K15886: Restoring the BIG-IQ system to factory default settings to restore the system to factory defaults.

Additional Information

None
