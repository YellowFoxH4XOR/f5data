Description

SFTP external monitor on standby unit is failing, while successful on active unit.

Environment

  • BIG-IP LTM
  • External Monitors

Cause

File needed for external monitor script is missing on standby unit.

Recommended Actions

Make sure the files specified in external monitor script is available on both units for successful health monitor checks.

For Example:

If you have a following command or ( any sftp command ) in your script, executing the command from BIG-IP CLI will provide more details on error.

output=$(sftp -i /config/filestore/files_d/Common_d/certificate_key_d/:Common:SFTP-TEST_55750_1 -o StrictHostKeyChecking=no -b /config/filestore/files_d/Common_d/certificate_key_d/cmd $user@$ip)

Executing same command by specifying username and IP address from BIG-IP CLI, tells that files is missing.

[admin@bigip2:Standby:In Sync] ~ # sftp -i /config/filestore/files_d/Common_d/certificate_key_d/:Common:SFTP-TEST_55750_1  -o StrictHostKeyChecking=no -b /config/filestore/files_d/Common_d/certificate_key_d/cmd <username>@x.x.x.x

You may see output similar to below if a file is missing

No such file or directory (/config/filestore/files_d/Common_d/certificate_key_d/cmd).
