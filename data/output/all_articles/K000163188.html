Description

Recent F5 BIG-IP Edge GeoLocation update packages may include a separate `geoip-data-City2` RPM. This package provides **City-level geolocation data** for the BIG-IP **Edge** database. The package is specific to F5 BIG-IP and is not a general-purpose Linux RPM.

 

Example filename: 

geoip-data-City2-1.0.1-<date>.<release>.i686.rpm

The date and release values vary by GeoLocation database update.

 

Where to Obtain the Package

The package is available from the F5 **MyF5 Downloads** site as part of the GeoLocation update content for the applicable BIG-IP version:

  1. Open **MyF5 > Resources > Downloads**.
  2. Select the **BIG-IP** product family.
  3. Select the applicable BIG-IP product line and version.
  4. Select the **GeoLocationUpdates_Edge** container.
  5. Select the applicable `ip-geolocation` update package.

The City2 RPM, when included in the selected Edge update package, is identified with a filename similar to:

geoip-data-City2-*.i686.rpm

Use only the package provided by F5 for the applicable BIG-IP version. F5 does not support GeoLocation databases that were not released by F5.

For current download guidance, see

K11176: Downloading and installing updates to the IP geolocation database https://my.f5.com/manage/s/article/K11176

 

When the City2 RPM Is Needed

Use the City2 RPM when the BIG-IP environment requires **City-level geolocation information**, such as:

  • City or municipality data
  • City-level geolocation lookups
  • Applicable City-level location fields

When the City2 RPM Is Not Required

The City2 RPM is not required for every standard Edge GeoLocation update.

It is not required when the environment uses only other supported geolocation attributes, such as:

  • Continent
  • Country
  • Region or state
  • ISP
  • Organization

If City-level geolocation is not used, do not obtain or use the City2 RPM solely because it appears in the Edge download container.

 

Impact of Not Using the City2 RPM

If the City2 RPM is not used:

  • City-level geolocation information will not be available from the active Edge database.
  • Normal BIG-IP operation is not expected to be affected.
  • Other supported geolocation attributes remain available through the applicable GeoLocation database components.
  • A BIG-IP feature that specifically requires City-level data may not return the expected City-level result.

The impact depends on whether the BIG-IP configuration or application uses City-level geolocation.

 

BIG-IP Module Usage

The City2 RPM is not specific to LTM, AFM, ASM/AWAF, APM, DNS, or another individual module.

It is part of the common BIG-IP GeoLocation data layer. Any BIG-IP feature or module that supports and uses the applicable City-level GeoIP fields may consume this data.

 

Edge and Pulse Considerations

The City2 RPM is intended for the Edge GeoLocation database.

According to K78974041: F5 IP geolocation database support for Edge and Pulse databases:

  • Edge supports City-level geolocation data.
  • Pulse does not support City-level geolocation data.
  • Edge and Pulse use different GeoLocation database types.
  • The Pulse database requires at least 900 MB of system memory.

Only one GeoLocation database type—Edge or Pulse—can be active at a time. Edge and Pulse databases cannot be used simultaneously. See K000151303: Can Edge and Pulse IP Geo databases be used on the BIG-IP at the same time?.

 

Additional Information

  • Package names, release numbers, and update dates may change between GeoLocation database releases.
  • Use only the F5-provided package that corresponds to the applicable BIG-IP version.
  • Refer to K11176: Downloading and installing updates to the IP geolocation database for the applicable GeoLocation database update documentation.
