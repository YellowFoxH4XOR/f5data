Description

When there is a need to create an alert for a specific HTTP error code besides 403, 404, 500, 502, 503, 504 as predefined in the Metric.

 

Environment

Nginx controller

 

Recommended Actions

  1. Log in to the controller GUI
  2. Go to [Alerts], [Alert Rules]
  3. Click [Create Alert Rule] button from the top right of the page
  4. Create an alert rule as below:
    1. Name: <Input desired name>
    2. Metric: http.request.count
    3. Is: greater or equal
    4. The threshold of: 1
    5. Over the past: <input desired time duration>
    6. Filter: http.response_code=<input desired http error code>
    7. Email Notification Addresses: <input desired email>
  5. Click [Submit]
