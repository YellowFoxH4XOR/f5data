Description

Service check is up to date, the upgrade procedure however fails, the GUI shows:

"The configuration has not yet loaded. If this message persists, it may indicate a configuration problem.", or:

"This device is not operational because the loaded configuration contained errors or unlicensed objects. Please adjust the configuration and/or the license, and re-license the device."


The CLI's prompt may show a "Not licensed" banner

Environment

  • Software Upgrade
  • Service check date is up to date in current boot location

Cause

       License re-activation was performed after the boot location with the new software release was created.

Recommended Actions

Re-activate the license before creating/installing the new boot location, so the updated service check date will be installed  in the new boot location
  1.  Roll back to the previous version
  2.  Remove the boot location with the new SW release
  3.  Re-activate the license
  4.  Install the new SW release in a new boot location

Additional Information

K7727: License activation may be required before a software upgrade for BIG-IP
