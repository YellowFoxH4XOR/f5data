K2287: Configuring BIG-IP to close idle connections

Topic

While BIG-IP is passing normal network traffic, there are times when connections are not finished properly by either the client or the node. If these idle connections are not removed from the BIG-IP connection table, they will continue to use memory, which reduces the amount of memory available for new connections. To avoid this, you need to configure a reaper/timeout setting for every virtual port on BIG-IP.

To set the timeout value for idle connections, use the service port timeout protocol command. The service port timeout protocol command has essentially the same functionality as the treaper command except that it has been enhanced to allow you to specify udp or tcp timeouts.

Important: With the BIG-IP 2400 platform, which contains the Packet Velocity ASIC, setting a service port timeout protocol at 5 seconds or less will invalidate any hardware acceleration to all virtual server objects for the service in question.

For example, to set the tcp timeout to 30 seconds you would type:

bigpipe service 53 timeout tcp 30

To set the udp timeout to 10 seconds, you would type:

bigpipe service 53 timeout udp 10

Note: Since udp is a stateless connection it is not necessary to keep the port open for extensive periods of time.
