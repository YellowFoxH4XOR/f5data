Known Issue

This is the result of a known issue. The csTest.pl script is a troubleshooting and diagnostic tool for configsync that queries peer data, and checks several db variables over the network. If the Connection Mirror Address setting (StateMirror.PeerIpaddr db key) is not configured on a redundant system, the csTest.pl script generates the following error message:

Warning: No failover address configured for self.
Error: No peer IP address defined for configsync.

This issue occurs even when the Configsync.PeerIpaddr db key is set on the system and the configsync operation is successful.

Note: The Configsync.PeerIpaddr db key is the IP address of the system to be used for configsync. If Configsync.PeerIpaddr is not set, the system uses the StateMirror.PeerIpaddr db key for configsync.

F5 Networks Product Development is tracking this issue as CR107294.

Note: For more information about the csTest utility, refer to K7024: Overview of the configsync process

Note: For more information about a related issue, refer to K10147: The csTest.pl script does not test the Configsync.PeerIpaddr and Failover.Ipaddr database keys.
