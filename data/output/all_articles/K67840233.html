K67840233: BIG-IQ is unable to deploy SNAT pool on BIG-IP - ''SNAT translation in partition (Common) references a route domain (1) in a different partition''

Type
Support Solution
Published
2022-02-28
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K67840233

Description

When you try to deploy SNAT on non-common partition on BIG-IP you will observe a similar error: 

Transaction 1641521933032657 on BIG-IP 10.0.0.1 failed after 0 seconds: 0107098a:3: The ip address (10.10.10.10%1) for a SNAT translation in partition (Common) references a route domain (1) in a different partition (PARTITION-TWO). Objects may only reference objects in the same or the 'Common' partition

Environment

  • BIG-IQ 7.x, 8.0.x, 8.1.x
  • SNAT pool deployment under non-common partition

Cause

BIG-IQ has the code designed to set the partition for the SNAT Translation as "Common" when creating any SNAT Translation based on the SNAT Pool creation request.

F5 is tracking this issue under ID1081221.

Recommended Actions

  Configure SNAT pool on BIG-IP directly
  1. Deploy SNAT pool at BIG-IP locally according to article:
    K47945399: Create basic SNATs and SNAT pools
  2. Re-discover and re-import BIG-IP configuration on BIG-IQ
