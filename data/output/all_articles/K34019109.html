K34019109: The BIG-IP system supports TLS extended master secret extensions when Proxy SSL is enabled

Issue

Old Behavior

In versions prior to 13.0.0, the BIG-IP system's Proxy SSL feature does not support the Transport Layer Security (TLS) extended master secret extension described in RFC 7627.

If both the client and the server attempt to use the TLS extended master secret extensions described in RFC 7627, SSL handshakes fail.

New Behavior

Beginning in version 13.0.0, the BIG-IP system's Proxy SSL feature supports the TLS extended master secret extension described in RFC 7627.

F5 Product Development tracked this change as ID 563488.

Impact

The BIG-IP system can process TLS extended master secret extensions when configured to use the Proxy SSL feature.

Recommended Actions

In versions prior to BIG-IP 13.0.0, you should disable TLS extended master secret extensions on the SSL pool members associated with the SSL virtual server.
