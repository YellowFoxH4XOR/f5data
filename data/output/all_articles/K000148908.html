Description

You might be encountering following errors in /var/log/ltm.log and /var/log/webui.log while trying to build the HA after restoring the BIG-IP system through UCS file from another device or same device.

/var/log/ltm

Nov 13 16:28:21 slot2/LTM1.example.com err mcpd[9729]: 01020036:3: The requested devicegroup (/Common/device_trust_group) was not found.
Nov 13 15:44:24 slot2/LTM1.example.com err mcpd[9729]: 01070712:3: Caught configuration exception (0), Values (/Common/device_trust_group) specified for device group device (/Common/device_trust_group /Common/LTM1.example.com): foreign key index (devicegroup_fk) do not point at an item that exists in the database.
Nov 13 15:44:24 slot2/LTM1.example.com err devmgmtd[11286]: 015a0000:3: <unknown> failed on <unknown>.<unknown>: 01070712:3: Values (/Common/device_trust_group) specified for device group device (/Common/device_trust_group /Common/LTM1.example.com): foreign key index (devicegroup_fk) do not point at an item that exists in the database.
Nov 13 15:44:24 slot2/LTM1.example.com err devmgmtd[11286]: 015a0000:3: mcp operation failed: 01070712:3: Values (/Common/device_trust_group) specified for device group device (/Common/device_trust_group /Common/LTM1.example.com): foreign key index (devicegroup_fk) do not point at an item that exists in the database.
 

/var/log/webui.log

2024-11-13 16:28:21,961 ERROR [ajp-bio-127.0.0.1-8009-exec-3] system.xuistatus_jsp:_jspService - Error rendering HA indicator: com.f5.mcp.io.McpQueryException: 01020036:3: The requested devicegroup (/Common/device_trust_group) was not found.
 
You can also use the CLI command tmsh show cm device-group device_trust_group or configuration utility Device Management  ››  Overview to verify the default system level device group configuration.

Environment

  • Platform BIG-IP
  • High Availability 
  • UCS

Cause

  • Default device-groups named as device_trust_group is missing in the UCS backup file.
  • Default system level configuration was removed from the device before taking the configuration backup.

Recommended Actions

  1. Restore the device from a functional backup taken before the system level configuration was removed.
  2. Reset the device to Factory Default Settings and have it joined the HA cluster after doing the initial Basic Configuration.

Additional Information

  • You can follow KB K23507223 to know when was the configuration removed as BIG IP keep record of the previous 250 patches information.
