Known Issue

This is the result of a known issue. The BIG-IP ASM system does not support URIs with object names longer than 256 characters. The Configuration utility does not support using the Auto-Accept feature or manually adding object names longer than 256 characters.

F5 Product Development tracked this issue as CR76772 and it was fixed in BIG-IP ASM 9.3 and 9.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.
