Description

ARP entry is not found in Linux ARP table for management gateway IP address. For example, when viewed with the arp -a command.

Environment

  • Auto Last Hop enabled on management interface
  • Management gateway configured as VRRP IP

Cause

The system is not ARPing for the management gateway IP. Traffic is returned via a different IP, due to Auto Last Hop functionality.

The Linux ARP table only contains records the system is actually ARPing for, or static entries.

Recommended Actions

Consider disabling Auto Last Hop on the management interface. To disable Auto Last Hop on the management interface, refer to the following article:

  • K52592992: Overview of the Auto Last Hop feature on the management interface
Traffic will then be routed to the configured management gateway, which is the VRRP IP.

Additional Information

To validate the MAC address a particular IP resolves to when troubleshooting, use a command similar to the following:

arping -I mgmt <x.x.x.x>

Note: Responses to the arping command do not populate the ARP table.
