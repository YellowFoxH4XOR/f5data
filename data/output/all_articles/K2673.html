K2673: Configuring VLAN groups not to forward Cisco Discovery Protocol (CDP)

Topic

When BIG-IPs are running Cisco Discovery Protocol (CDP) and are configured with a VLAN group that connects to a Cisco switch, the standby BIG-IP continues to forward the CDP multicast packets.

To correct this issue, enable the opaque vlangroups variable on BIG-IP. When this variable is enabled, the BIG-IP will no longer forward the CDP packets, because opaque vlangroups require a source and destination MAC address and CDP packets do not contain a source and destination MAC address.

You can make this change through the Configuration utility or the command line.

Configuration utility

To enable opaque vlangroups through the Configuration utility, perform the following steps:

  1. From the navigation pane of the standby BIG-IP, click System.
  2. Click the Advanced Properties tab.
  3. From the Layer2 menu, choose opaque.
  4. Click Apply.
  5. Repeat steps 1 through 4 on the active BIG-IP.

Command line

To enable opaque vlangroups through the command line, perform the following steps:

  1. On the standby BIG-IP, type the following command:

    b global vlangroups opaque

  2. Save the change, by typing:

    b save

  3. Repeat steps 1 and 2 on the active BIG-IP.
