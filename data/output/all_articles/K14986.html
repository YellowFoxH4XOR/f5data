Topic

You should consider using this procedure under the following condition:

  • You want to reset the device keys and certificates associated with the trust domain when loading a user configuration set (UCS) file by using the TMOS Shell (tmsh).

Description

When loading a UCS file using tmsh you can use the reset-trust option to reset the device and trust domain certificates and keys.

For example, you can use the reset-trust option to mitigate a situation where the UCS has missing trust certificate/key files or an inconsistent configuration for the trust certificate/key files.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrator access to tmsh.

Procedures

To use the reset-trust option to reset device and trust domain certificates and keys when using tmsh to load a UCS file, perform the following procedure:

Impact of procedure: When you use the reset-trust option on a device that is part of a trust domain, you are required to rejoin the trust domain for the device. For more information about managing device trust, refer to the BIG-IP Device Service Clustering: Administration guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to tmsh by typing the following command:

    tmsh

  2. To load the UCS using the reset-trust command, use the following command syntax:

    tmsh load sys ucs <UCS File> reset-trust

    For example, to load a UCS file named myexample.ucs, type the following command:

    tmsh load sys ucs myexample.ucs reset-trust
