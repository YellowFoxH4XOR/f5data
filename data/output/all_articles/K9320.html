Known Issue

This is the result of a known issue. The saving or loading of a configuration larger than 300 MB causes the system to consume all resources, resulting in the creation or installation of a UCS file to exceed the time allowed by the system. This behavior causes the system to panic as it attempts to refresh the save or load action, resulting in a possible TMM core.

F5 Product Development tracked this issue as CR96392 and it was fixed in 9.4.5 for the BIG-IP 9.4.x software branch. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in Hotfix-BIG-IP-9.4.4-9.4.0-HF3, issued for BIG-IP 9.4.4. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
