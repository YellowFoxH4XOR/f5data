Known Issue

This is the result of a known issue. If a user accesses Citrix Web Interface through Portal Access, a FirePass application tunnel is launched when the user selects a Citrix published application. The application tunnel status appears in a pop-up window, along with the options to terminate or relaunch the application tunnel. If a user launches additional published applications, the corresponding application tunnels are listed in the existing pop-up window. Since the pop-up window does not have scroll bars and cannot be resized, users cannot select the terminate or relaunch buttons for application tunnels displayed outside of the visible area of the pop-up window.

F5 Product Development is tracking this issue as ID 296403 (formerly CR121200).
 
Workaround
 
Users running Internet Explorer 7 or Internet Explorer 8 can work around this issue by setting the zoom level to 125% in the application tunnel pop-up window. The zoom level option appears in the right corner of the status bar; selecting 125% adds horizontal and vertical scroll bars to the application tunnel window.

For more information about the zoom level option, refer to:
 
http://www.microsoft.com/enable/training/windowsvista/webzoom.aspx
