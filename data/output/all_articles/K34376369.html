Issue

TCP reset attack, also known as "forged TCP resets," "spoofed TCP reset packets," or "TCP reset attacks," is a method of tampering with Internet communications.

The BIG-IP AFM system is built on full-proxy architecture. The system can determine valid traffic flow and drop TCP RST traffic floods using the BIG-IP AFM DoS device-level protection Flood category. This TCP RST flood attack can also be mitigated using the BIG-IP AFM DoS Protection profile.

Environment

  • BIG-IP AFM module is provisioned

Cause

TCP RST flood traffic is suspected to be hitting the BIG-IP system.

Recommended Actions

To mitigate TCP RST flood attack, you can configure the detection and mitigation thresholds for TCP RST flood attack type. Depending on your environment needs, you can perform either one or both of the following procedures:
  • Tuning device-level DoS protection
  • Configuring the Network Security-enabled DoS Protection profile

Tuning device-level DoS protection

To tune the device-level DoS protection settings for mitigating TCP RST flood attack type, perform the following procedure:

Impact of procedure: Depending on your application environment, you need to determine the threshold values acceptable for your application environment.

BIG-IP AFM 14.x

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > Device Protection.
  3. Click Network to expose the TCP RST Flood attack type.
  4. Click TCP RST Flood attack type to expose its properties
  5. Modify the values for the following settings acceptable to your application environment:
    • Mitigation Threshold EPS
    • Detection Threshold %
    • Detection Threshold EPS*
  6. Click Commit Changes to System.

BIG-IP AFM 13.x

  1. Log in to the Configuration utility
  2. Navigate to Security > DoS Protection > Device Configuration > Network Security.
  3. Click the Add icon (+) next to the Flood category to expose the TCP RST Flood attack type.
  4. Click TCP RST Flood attack type to expose its properties.
  5. Modify the values for the following settings to those acceptable to your application environment:
    • Mitigation Threshold EPS
    • Detection Threshold %
    • Detection Threshold EPS*
  6. Click Update.

BIG-IP AFM 12.x

  1. Log in to the Configuration utility
  2. Navigate to Security  >  DoS Protection > Device Configuration.
  3. Click the Add icon (+) next to the Flood category to expose the TCP RST Flood attack type.
  4. Click TCP RST Flood attack type to expose its properties.
  5. Modify the values for the following settings to those acceptable to your application environment:
    • Detection Threshold PPS*
    • Detection Threshold Percent
    • Rate Limit
  6. Click Update.
For BIG-IP AFM DoS device-level protection, the threshold and rate limit values are applied per TMM. For more information, refer to K15023: The BIG-IP AFM system enforces configured thresholds and limits for each TMM. 

* For Detection Threshold EPS/PPS value, as a sample possible value, allow an acceptable value to accommodate expected increase of this type of traffic. For example, if the Stats Rate value has an average value of 5000 packets per second, you are configuring four TMMs in the BIG-IP AFM, and the Detection Threshold EPS/PPS value is set to 8000, this allows the BIG-IP AFM system to potentially handle a total of 31996 TCP RST flood packets before BIG-IP AFM detects the TCP RST flood attack vector. However, if one of the TMM exceeds the Detection Threshold EPS/PPS value of 8000, say 8100, the BIG-IP AFM detects the TCP RST flood attack and generates a log similar to the following example in the /var/log/ltm file:

err tmm[12689]: 01010252:3: A Enforced DOS attack start was detected for vector TCP RST flood, Attack ID 3835661049.

When the TCP RST flood attack traffic falls below the Detection Threshold EPS/PPS value, a log similar to the following example is generated in the /var/log/ltm file noting that the attack stopped and referencing the corresponding TCP RST Flood Attack ID:

notice tmm[12689]: 01010253:5: A Enforced DOS attack has stopped for vector TCP RST flood, Attack ID 3835661049.

Note: The provided Detection Threshold EPS/PPS values are examples. You need to review and periodically observe the Stats Rate value to determine an appropriate Detection Threshold and Mitigation/Rate limit value according to the needs of your environment.

Configuring Network Security-enabled DoS Protection profile

To configure the thresholds for TCP Flood attack type in the DoS Protection profile, perform the following procedure:

Impact of procedure: Depending on your application environment, you need to determine the threshold values acceptable for your application environment.

BIG-IP AFM 14.x

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > Protection Profiles.
  3. Click the name of the Network Security-enabled DoS Protection profile that you want to modify.
  4. Click Network.

    Note: If you do not see the Network setting, you must enable Network Security by selecting Network for the Families setting.

  5. Click TCP RST Flood under the Vector table. The Configuration utility displays the TCP RST Flood properties page.
  6. For State, click Mitigate to expose the settings.
  7. For Threshold Mode, choose the appropriate setting. If you want to configure the three settings manually, click Fully Manual.
  8. Modify the value for the following settings:
    • Detection Threshold EPS
    • Detection Threshold %
    • Mitigation Threshold EPS
  9. Click Commit Changes to System.

BIG-IP AFM 13.x

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > DoS Profiles.
  3. Click the name of the Network Security-enabled DoS Protection profile you want to modify.
  4. Click the Network Security tab.
  5. In the Attack Type table, click TCP RST Flood.
  6. For State, click Mitigate.
  7. For Threshold Mode, choose an appropriate setting. If you want to configure the three settings manually, click Fully Manual.
  8. Modify the value for the following settings:
    • Detection Threshold EPS
    • Detection Threshold Percent
    • Mitigation Threshold EPS
  9. Click Update.

BIG-IP AFM 12.x

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > DoS Profiles.
  3. Click the name of the Network Security-enabled DoS Protection profile you want to modify.
  4. Under Network General Settings, expand Known Attack Types to expose the TCP RST Flood attack type.
  5. Click Edit for the TCP RST Flood attack type.
  6. For Detection Status, click Enabled to expose the thresholds and rate limits for configuration.
  7. Modify the value for the following settings:
    • Threshold (in packets per second)
    • Rate increase (in percent)
    • Rate Limit (in packets per second)
  8. Click Update.
For BIG-IP AFM DoS Protection profile, the thresholds and rate limit values are applied globally. For more information, refer to K40477555: BIG-IP AFM DoS Protection profile thresholds are enforced globally.

The BIG-IP AFM detects the TCP RST flood attack once the Detection Threshold EPS/PPS value is exceeded and generates a log similar to the following example in the /var/log/ltm file:

err tmm[12689]: 01010252:3: A NETWORK /Common/VS1 DOS attack start was detected for vector TCP RST flood, Attack ID 1094288092.

When the TCP RST flood traffic falls below the Detection Threshold EPS value, a log similar to the following example is generated in the /var/log/ltm file noting that the attack stopped and referencing the corresponding TCP RST Flood Attack ID:

notice tmm1[12689]: 01010253:5: A NETWORK /Common/VS1 DOS attack has stopped for vector TCP RST flood, Attack ID 1094288092.
