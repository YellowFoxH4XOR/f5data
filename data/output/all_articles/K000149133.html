K000149133: Unable to create and reference TLS profiles in a single declaration

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K000149133

Description

When multiple TLS profiles defined in an AS3 declaration, only one of them can be assigned to a TLS profile.

 

Environment

AS3

Declaration similar to the following:

 

{
    "class": "AS3",
    "action": "deploy",
    "declaration": {
        "class": "ADC",
        "schemaVersion": "3.40.0",
        "tenant": {
            "class": "Tenant",
            "app": {
                "class": "Application",
                "template": "https",
                "serviceMain": {
                    "class": "Service_HTTPS",
...
                    "clientTLS": [
                        {"bigip": "/tenant/app/sni1_srv_ssl_profile"},
                        {"bigip": "/tenant/app/sni2_srv_ssl_profile"}
                    ],
...
                "sni1_srv_ssl_profile": {
                    "class": "TLS_Client",
...
                "sni2_srv_ssl_profile": {
                    "class": "TLS_Client",
...
}

 

will fail with something like:

 

{
"code": 422,
"declarationFullId": "",
"message": "Unable to find /tenant/app/sni1_srv_ssl_profile for /tenant/app/serviceMain/clientTLS/0",
"declarationId": "dec_ID"
}

 

Cause

"bigip" can only reference a profile that already exists on the end device and doesn't create a new one.

ID1755469 raised to change this behavior and add the ability to both create and reference profiles from the same declaration.

 

Recommended Actions

None.
