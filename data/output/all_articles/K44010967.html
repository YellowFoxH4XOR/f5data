Description

Creating an Excel file that contains the current network map, is desired.

Environment

Network Map to an Excel File.

Cause

None

Recommended Actions

Run the following command on bash. Choose the partition from which to obtain the virtual server Information and replace <PartitionName> with the partition name. The command output is saved to /var/tmp/virtuals.csv.

tmsh list ltm virtual /<PartitionName>/* | awk '/virtual/{printf "%s,",$3}/destination/{printf "%s,",$2}/pool$/{printf "%s,",$2; system("tmsh list ltm "$0" {members} | awk '\''/:/{gsub(/ /, \"\", $0);gsub(/{/, \",\", $0);printf $s,$1}'\''");printf "\n"}' > /var/tmp/virtuals.csv

If you need a list of pool member IPs as well, you can use this command:

tmsh list ltm virtual /<PartitionName>/* all-properties one-line | perl -ne '($vs) = /ltm virtual (\S+)/; ($dest) = / destination (\S+)/; ($pool) = / pool (\S+)/; { print "$vs $dest $pool\n" }' | (while read vs dest pool; do if [[ $pool != none ]]; then members=$(tmsh list ltm pool $pool members | perl -ne 'if (/^        (\S+) {/) {print "$1\t" } elsif (/ address (\S+)/) { print "$1\t" }'); echo $vs $dest $pool $members; else echo $vs $dest; fi; done) > /var/tmp/virtuals.csv
