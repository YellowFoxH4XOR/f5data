Description

Kerberos SSO fails but you do not see kerberos traffic between APM and DC.

There are no websso logs associated to the sessid that failed

 

Environment

BIG-IP APM

APM deployed with Kerberos SSO

 

Cause

APM sends a reverse DNS lookup for the pool member before sending Kerberos AS-REQ to DC

Kerberos SSO will fail if APM does not receive a response with the dns name.

 

You need to check websso logs before error "Kerberos failed"

 

debug websso.0[20238]: 014d0046:7: /Common/kerberos_sso:Common:735be224: adding item to WorkQueue

err websso.0[20238]: 014d0019:3: /Common/kerberos_sso:Common:00000000: Kerberos: Failed to resolve IP address: ::ffff:10.10.10.10

err websso.0[20238]: 014d0048:3: /Common/kerberos_sso:Common:735be224: failure occurred when processing the work item: Kerberos failed

 

Recommended Actions

1. Capture tcpdump catching also dns traffic besides kerberos traffic

2. Verify on BIG-IP APM CLI which dns server is failing running this command

nslookup -type=PTR <pool member ip> <dns server ip>
