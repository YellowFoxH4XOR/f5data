Known Issue

The connection intermittently fails with secure network address translation (SNAT) automap, Service Provider Disaggregation (SP-DAG), and virtual server Source-Port preservation.

This issue occurs when all of the following conditions are met:

  • SNAT automap is enabled on the virtual server.
  • SP-DAG is enabled on the Virtual Local Area Network (VLAN).
  • Source Port is set to its Default Preserve option for the virtual server.

Impact

The service is interrupted due to the intermittent connection failures.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Connections can intermittently fail when multiple clients use the same ephemeral port to connect to the BIG-IP system and have SNAT enabled to the same address.
