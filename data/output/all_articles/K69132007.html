Description

The Network Map in Configuration Utility shows a summary. After upgrade, the summary shows fewer pool members.

Environment

  • BIG-IP
  • Upgrading from v13.1.0-13.1.1.4
  • Upgrading to v13.1.1.5 - latest v13.1.x
  • Having one or more pool member that is associated with multiple pools

Cause

In v13.1, there was a change to the back-end processing for the Network Map. Unfortunately, this leads to slowness in loading the Network Map for large configurations - Bug ID 757414. In v13.1.1.5, F5 fixed this bug by bringing back the original behavior of Network Map which shows unique pool members.

Recommended Actions

Take note of the difference in behavior between versions. No other action is necessary.

Additional Information

For example, you have a pool member 10.10.10.10:80 that is associated with 3 pools. Before upgrade (v13.1.0-13.1.1.4), the Network Map summary shows a total of 3 pool members. However, after upgrade (v13.1.1.5 - latest v13.1.x), it shows only 1 pool member.

Versions that have Network Map that counts unique pool members:
Pre-13.1 (v12, v13.0), v13.1.1.5 - latest v13.1.x

Versions that have Network Map that counts all including repeated pool members:
v13.1.0-13.1.1.4, v14.0.0-14.0.1.1

From v14.1, Network Map no longer shows a summary.
