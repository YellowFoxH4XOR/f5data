Known Issue

Using iControl to modify the Client SSL profile creates an invalid configuration object.

This issue occurs when the following condition is met:

  • You use iControl to delete all the certificates and keys for a Client SSL profile.

Impact

The Client SSL profile becomes an invalid configuration object.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing the Client SSL profile configuration, the required certificate and key pair is not listed.
  • When attempting to upgrade to BIG-IP 11.6.0 and later, the configuration fails to load with an error message that appears similar to the following example:

    01070281:3: Invalid "http lws width" value for profile /<partition>/<client-ssl profile name>.
    Value must be greater than 0. Unexpected Error: Validating configuration process failed.

  • When attempting to upgrade to BIG-IP 11.6.0 and later, the system logs an error message to the /var/logltm file that appears similar to the following example:

    err tmsh[19631]: 01420006:3: Loading configuration process failed.
    emerg load_config_files: "/usr/bin/tmsh -n -g load sys config partitions all" - failed. --
    010717e1:3: Client SSL profile cannot contain more than one set of same certificate/key type.
    Unexpected Error: Loading configuration process failed.
    warning mcpd[<pid>]: 01071423:4: High config load failed during a license reset. Fallback to base load.

Resolution

Workaround

To work around this issue, you can when delete the entire Client SSL profile instead of deleting all configured certificates and keys from a Client SSL profile.

Note: Client SSL profiles that are not configured with certificates and keys are invalid.

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.
