K84548044: HTTPS monitor offline with reason connect: protocol mismatch search result false

Type
Support Solution
Published
2024-08-06
Updated
2024-08-08
Applies to
  • BIG-IP DNS: 16.X.X
Source
https://my.f5.com/manage/s/article/K84548044

Description


BIG-IP DNS HTTPS Monitor is marked offline with reason connect: protocol mismatch search results false.

tmsh show /gtm pool members

  -----------------------------------------------------
  | Gtm::Pool Member: /Common/ <pool member name>
  -----------------------------------------------------
  | Status
  |   Availability : offline
  |   State        : enabled
  |   Reason       :  Monitor /Common/<Monitor Name> from <BIG-IP Device> : connect: connect failed search result false
  |
  | Load Balancing
  |   Preferred             0
  |   Alternate             0
  |   Fallback              0


You will see a similar log message in the gtm log:

alert gtmd[7946]: 011a4003:1: SNMP_TRAP: Pool /Common/<Pool Name> member <Name> (ip:port= <IP and Port) state change blue --> red ( Monitor /Common/<Name> from < BIG-IP Device > : connect: protocol mismatch search result false)
 

Environment

  • BIG-IP DNS
  • HTTPS Monitor
  • 13.1, 14.x, 15.x, 16.x

Cause


Bug ID 918169: The GTM/DNS HTTPS monitor may fail to mark a service up when the SSL session undergoes an unclean shutdown.

Recommended Actions

  • Upgrade to a version that contains the fix for Bug ID 918169
  • Ensure the server issues a close notify alert before it closes the underlying TCP connection.
  • Ensure the server's HTTP response ends with a new line.

Additional Information

None
