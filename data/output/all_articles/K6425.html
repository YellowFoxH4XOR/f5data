Known Issue

This is the result of a known issue. The BIG-IP ASM Auto-Accept and Policy Builder features do not properly handle modified domain cookies. Modified domain cookie violations are issued if the BIG-IP ASM Policy was configured to accept modified domain cookies using the Auto-Accept feature in versions 9.2.0 through 9.2.3, or using the Policy Builder feature in version 9.2.4 through 9.2.5.

F5 Product Development tracked this issue as CR68636 and it was fixed in BIG-IP 9.4.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by allowing modified domain cookies. To manually add the modified domain cookie to the Allow modified cookies configuration, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Web Applications.
  4. Click the name of the web application that you want to modify.
  5. From the Policies List section, click the policy name of the policy that you want to modify.
  6. From the Allow Modified Cookies section, click Create.
  7. Type the name of the domain cookie in the Cookie Name field.
  8. Click OK.
