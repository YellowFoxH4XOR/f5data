K000139120: TMM may crash when handling DNS request

Type
Support Solution
Published
2024-03-31
Updated
2026-07-17
Status
Legacy Content
Applies to

  • BIG-IP DNS: 15.1.10
Source
https://my.f5.com/manage/s/article/K000139120

Description

A TMM crash with a core file may occur while handling a DNS request if another TMM thread is simultaneously reloading DNS database files.

This issue also impacts LTM with enabled DNS caching, such as those using a DNS resolver.

Environment

  • TMM
  • DNS
  • DNS caching
  • DNS resolver

Cause

This is caused by ID1154313.

Recommended Actions

Monitor the progress of the fix in the software version for ID1154313.

You may also consider contacting F5 Support to inquire about the possibility of an engineering hotfix for ID1154313.

Additional Information

None.
