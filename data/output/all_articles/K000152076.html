Question

Is Distributed Cloud DDoS routed solution capable of dropping traffic from particular ASNs?

  • Can traffic sourced from specified ASNs be dropped by Distributed Cloud DDoS protection?

 

Environment

  • Distributed Cloud
  • Routed DDOS

 

Answer

  • This option is not available in the Distributed Cloud DDoS routed solution
  • Distributed Cloud can block source IP's or IP ranges
