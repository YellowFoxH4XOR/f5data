Description

This article explains how to rename an ASM policy name on BIG-IP ASM version 12.x.

Environment

  • BIG-IP ASM Version 12.x
  • Configured ASM policy

Cause

A policy can be exported in XML format, and the name can be changed by editing the file with a text editor before re-importing it.

Recommended Actions

Follow these steps to change the policy name:

Export policy in XML format:

  • From the GUI menu, navigate to Security > Application Security > Security Policies > Active Policies.
  • Select XML format and proceed with the export.

Edit the exported file:

  • Open the exported file with a text editor.
  • Locate the policy name and change it to the desired name.

Example: change from /Common/rename-policy-before to /Common/rename-policy-after

=== Before modifying XML file ===

<policy integrity_check="cfbc2c2ab118ed9e440024da9fc7b074"bigip_version="12.1.3"

name="/Common/rename-policy-before">

=== After modifying XML file ===

<policy integrity_check="cfbc2c2ab118ed9e440024da9fc7b074" bigip_version="12.1.3"

name="/Common/rename-policy-after">

Import the edited policy:

  • From the GUI menu, navigate to Security > Application Security > Security Policies > Import Security Policy.
  • Choose the edited XML file and import it.

Activate the imported policy:

  • From the GUI menu, navigate to Security > Application Security > Security Policies > Inactive Policies.
  • Select the new policy and click "Activate".

Confirm the updated policy name:

  • From the GUI menu, navigate to Security > Application Security > Security Policies > Active Policies.
  • Verify that the new policy name appears in the list.

Additional Information

Starting from version 13.1.x, you can simply copy a policy and give it a new name directly within the GUI.

  • Navigate to Security > Application Security > Security Policies > Policies List.
  • Select the policy and then click "Copy Policy" in the upper right menu.
  • Under "Policy name", you can specify the new name for the copied policy.
