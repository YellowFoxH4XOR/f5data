Issue

Error Message

WARNING: listening to wildcard address, broadcast IKE packet may kill you

Note: Beginning in BIG-IP 11.4.0, this message was shortened to "WARNING: listening to wildcard address."

Message Location

You may encounter this message in the following location:

  • /var/log/racoon.log

Description

This message occurs when the following condition is met:

  • The log-level setting for the ike-daemon is set to a severity of warning or lower.

Impact

None. You can safely ignore this message.

Recommended Actions

If you want to suppress this message, you can increase the ike-daemon log level severity.

For example, to increase the log-level severity from warning to error, perform the following procedure:

Note: The default ike-daemon log-level setting changed from error to info beginning in BIG-IP 11.3.0.

  1. Log in to the command line.
  2. Set the log-level to error by typing the following command:

    tmsh modify net ipsec ike-daemon ikedaemon log-level error

  3. Save the configuration by typing the following command:

    tmsh save sys config
