Topic

The maximum number of entries per class is only limited by the amount of memory on a system and the capacity of the storage media.

As a gauge, the storage media capacity of the BIG-IP 5000 is approximately 350,000 - 400,000 entries in a class due to the 16MB partition used to store configuration files.
