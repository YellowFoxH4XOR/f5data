K000091355: Request parameters are missing when viewing access log

Type
Support Solution
Published
2022-10-20
Updated
2022-10-20
Source
https://my.f5.com/manage/s/article/K000091355

Description

Nginx does not log the URL parameters(sometimes referred to as args) for the HTTP POST requests.

 

 Environment

  • Nginx
  • HTTP 

 Cause

Nginx does not log HTTP request parameters from a POST body with the Nginx variable $request. In order to log these parameters, you need to use the variable $request_body in your logging format to capture these values in the logs.
 

 Recommended Actions

Add the $request_body variable to your logging format.
 

 Additional Information

https://nginx.org/en/docs/http/ngx_http_core_module.html#var_request_body
