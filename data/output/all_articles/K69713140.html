Known Issue

A monitor with a backslash character (\) in the description may fail to load.

This issue occurs when the following condition is met:

  • You create a monitor with a description that contains a backslash character (\).

Impact

Configuration changes that the system makes may result in a potential load failure.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When a monitor description contains a backslash character (\), the system adds another backslash character (\) for every save-load operation. After enough save/load operations, the description eventually hits the maximum length, causing the following error message when the system loads the configuration:

    01020057:3: The string with more than 65535 characters cannot be stored in a message

Resolution

Status

F5 Product Development has assigned ID 653930 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table.

Workaround

Do not use backslash characters (\) in monitor descriptions.
