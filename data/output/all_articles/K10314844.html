Description

You want to disable SNMPv1.

Environment

  • BIG-IP
  • Using SNMP services
  • SNMPv1 is enabled on the BIG-IP device.

Cause

None.

Recommended Actions

  1. Log in to the CLI.
  2. To disable the SNMPv1 on the BIG-IP, use the following command syntax:

    tmsh modify /sys db snmp.v1.enabled value disable
     
  3. Save the configuration.

    tmsh save /sys config
     
  4. If you want to confirm that SNMPv1 has been disabled, please perform the command:

    tmsh list /sys db snmp.v1.enabled all-properties

    You should see something similar to:

    sys db snmp.v1.enabled {
        default-value "enable"
        scf-config "true"
        value "disable"          <------------------------- this variable shows if is enable or disable.
        value-range "disable enable"
    }
If you have multiple BIG-IP systems in a high-availability configuration, you should perform a configuration synchronization after modifying a DB key.

Additional Information

None.
