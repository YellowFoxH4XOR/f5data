Description

OpenSSL version has been upgraded to 1.0.2p which support ALPN h2.

In versions prior to BIG-IP 14.0.0, when running curl command against  HTTP/2 web server, the HTTP response will be downgraded to HTTP/1.1.

# curl -k -i https://URL
HTTP/1.1 200 OK
Content-Length: 2
Server: Microsoft-HTTPAPI/2.0

Beginning in  BIG-IP 14.1.0, when running curl command against HTTP/2 web server with ALPN supporting, the HTTP server may prefer HTTP/2 as a response.

# curl -k -i https://URL
HTTP/2.0 200
content-length:2
server:Microsoft-HTTPAPI/2.0

Environment

  • OpenSSL 1.0.2p 
  • ALPN h2

Cause

None

Recommended Actions

None 

Additional Information

Some external monitors that use curl or OpenSSL may fail due to the response string has been changed by this behavior change.
