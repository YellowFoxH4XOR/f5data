Description
Troubleshooting a BIG-IP that is not accessible via the network

Environment

  • BIG-IP hardware unit

Cause
A BIG-IP may not be accessible via SSH, HTTPS, remote console.

Recommended Actions

Note: On-site physical access is required if you cannot access the device via ssh, https or remote-console. It is recommended to schedule a maintenance window to perform these troubleshooting steps. It may also be advisable to disconnect the device in question from the network (with the exception of the management network).
  1. Verify if the LCD panel is displaying messages and make a note of these.
  2. Verify the Status, Alert and Power Supply LEDs. Note the color of each LED and whether they are blinking or solid.
  3. Connect to the BIG-IP® via the console port and verify if you are receiving output. If you receive garbled output, you may need to adjust the baud rate settings on the BIG-IP and your client so they match. If you receive no output, please try power cycling the BIG-IP® while still connected to console. Ensure that you save the console output to a log file. The output produced while the BIG-IP® attempts to boot may be useful. 
  4. If you are receiving console output and the BIG-IP® is failing to boot completely, or is in a boot loop, please run End User Diagnostics.
  5. If you are unable to access the End User Diagnostics (EUD) menu, please try resetting the Host subsystem and the AOM subsystem via the AOM menu. Make sure that you save the console output to a file.
    1. Display the AOM Command Menu by typing the following key sequence (Esc + Shift + 9)
    2. Select option #3 "Reset  Host subsystem", then immediately display the AOM menu again by pressing "Esc + Shift +9" and select option #1 "Connect to Host subsystem console"
    3. If the device did not boot successfully after step #2, select option #4 "Reset AOM subsystem", then immediately display the AOM menu again by pressing "Esc + Shift + 9" and select option #1 "Connect to Host subsystem console"
  6. Contact F5 support and provide the console output that was collected as well as the EUD output.
