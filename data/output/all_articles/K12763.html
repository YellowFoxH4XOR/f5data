Issue

F5 has removed the fsck option, beginning in FirePass End-User Diagnostics (EUD) version 10.0.9.14. The fsck option falsely reported errors with the file system. Fsck is the operating system utility responsible for finding and correcting any file system errors.

F5 Product Development tracked this change in behavior as ID 295800 (formerly CR140272).

The fsck utility runs automatically when the FirePass controller is booted. If you need to run the fsck utility on your FirePass system, refer to the Shutting down and restarting the FirePass Controller chapter in the FirePass Controller Administrator Guide.

Beginning in FirePass 6.1.0 HF-610-6.1 and FirePass 7.0.0 HF-70-4.1-1, F5 has added an option to run the fsck utility to the Administrator console. For more information, refer to K13709: FirePass option for running the fsck utility.
