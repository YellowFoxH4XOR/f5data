K000137212: Server Errors when making changes in the F5OS Web Configuration GUI

Type
Support Solution
Published
2023-10-11
Updated
2023-10-26
Applies to
  • F5OS
  • F5OS-A
  • F5OS-C
Source
https://my.f5.com/manage/s/article/K000137212

Description

  • When attempting to make changes to the configuration in the Web Configuration GUI, get Server Errors with message similar to:
    • An internal error occurred. Please try again later. If the problem persists, contact technical support for assistance.
  • When running the command show components in the CLI gives the following error:
    • Error: application error

Environment

  • F5OS-A
  • F5OS-C

Cause

The issue is caused by a known bug that is being tracked as ID 1165973. When a hardware sensor returns faulty data, the show components command will return an error; as the web gui uses this command as well for some actions, this can result in the gui displaying server errors when attempting to perform some actions. The sensor may return faulty data due to a fluke event in which something is "stuck" and causing the sensor to send bad data, or due to a hardware fault with the sensor or other hardware component.

 Recommended Actions

  1. Reboot the unit to see if that resets the sensor
  2. If the GUI and CLI errors persist after a reboot, generate a qkview and open a case with F5 Support.
