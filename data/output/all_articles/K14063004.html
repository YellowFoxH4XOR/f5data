Issue

Error Message

notice tmrouted[<PID>]: 01910601:5: Unsuppressing route <IP Address/Mask> matched previous admin network.

In this error message, note the following:

  • <PID> is the process ID for the tmrouted process.
  • <IP Address/Mask> is the IP address subnet and associated mask.

For example:

notice tmrouted[14066]: 01910601:5: Unsuppressing route 192.0.2.0/24 matched previous admin network.

Message Location

You may encounter this message in the following location[s]:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The administrator IP network changes and the BIG-IP system puts a previously suppressed dynamic route back into the kernel.

Impact

There is no impact. You can safely ignore this error message.

Recommended Actions

None
