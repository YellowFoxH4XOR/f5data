Known Issue

The BIG-IP APM endpoint security check for Trend Micro firewall may fail.

This issue occurs when all of the following conditions are met:

  • You have an access policy configured with an endpoint security client-side agent to check for firewall software.
  • Users attempt to establish access sessions to the BIG-IP APM system from devices running Trend Micro firewall 10.6.

Impact

Users are unable to establish access sessions to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP APM system denies access to users when they attempt to log in, and the system displays an error message similar to the following example:

    Your session could not be established.
    The session reference number: <session id number>
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

  • Users can successfully log in to the BIG-IP APM system when you remove the endpoint security client-side firewall check agent from the access policy.
