Known Issue

After changing the management IP address, it may revert back to the previous IP address after a reboot.

This issue occurs when all of the following conditions are met:

  • You change the management IP address using the BIG-IP LCD panel.
  • You do not have a management route configured.
  • You perform a system reboot.

Impact

You may be unable to connect to the BIG-IP management IP address after a reboot.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You are unable to contact the BIG-IP management port after a reboot.
  • The Management IP address changes to the previously-used address.

Workaround

To work around this issue, you can change the IP management through the BIG-IP Configuration utility or using the Traffic Management Shell (tmsh) command line utility. To do so, perform one of the following procedures:

Using the BIG-IP Configuration utility to change the Management IP address

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility as an administrator.
  2. Navigate to System > Platform.
  3. Under the Management Port section, change the management IP address.
  4. Click Update.

These changes take effect immediately and persist through a reboot.

Using the tmsh utility to change the Management IP address

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Delete and re-create the management IP address. To do so, use the following command syntax, where xxx.xxx.xxx.xxx is the old management address, nnn.nnn.nnn.nnn is the new management IP address, and netmask is the netmask:

    delete sys management-ip xxx.xxx.xxx.xxx/netmask
    create sys management-ip nnn.nnn.nnn.nnn/netmask

    For example:

    delete sys management-ip 192.168.2.2/24
    create sys management-ip 192.168.1.1/24
  3. Save the change by typing the following command:

    save /sys config

These changes take effect immediately and persist through a reboot.
