Known Issue

The local6 syslog facility is not properly set for the httpd daemon.

Impact

The httpd SSL access and request activities sent to the BIG-IP Configuration utility are not written to the designated log files.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The httpd SSL logs in the /var/log/httpd/ directory may not be available.

Resolution

Status

F5 Product Development has assigned ID 375569 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the top right corner of the article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can enable logging manually. To enable the logging of all httpd SSL requests to the BIG-IP Configuration utility, refer to K13565: Enabling HTTPS logging for the BIG-IP Configuration utility.

Impact of workaround: None
