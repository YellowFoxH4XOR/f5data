Known Issue

This is the result of a known issue. The BIG-IP GTM system incorrectly sets the dynamic ratio for outbound load balancing on pool members. However, dynamic ratio (member) load balancing only works with BIG-IP 9.4.0 and later. As a result, dynamic ratio load balancing does not inherit link ratios properly for outgoing traffic in BIG-IP GTM and Link Controller 9.2.0 through 9.2.4.

F5 Product Development tracked this issue as CR70187 and CR70188 and it was fixed in BIG-IP 9.3.0 and 9.4.0. For information about upgrading, refer to the BIG-IP GTM and Link Controller release notes.
