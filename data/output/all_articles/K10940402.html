Description

Connecting to the APM VPN using Edge Client is not working as expected on a brand new Windows 10 laptop with only a wireless NIC in some scenarios. For instance, when connecting using the wireless NIC this works fine. However when connecting to USB wired Ethernet NIC. The properties of the wired NIC in Windows 10 suddenly shows as "Unidentified network No Internet" and the laptop loses all network connectivity.

From the CTU logs show the client is able to establish the tunnel but network is unable to direct the traffic through VPN.

Additional Information

"The method for determining the presence of an Internet connection these services use involves checking for a route. When the VPN program creates a VPN tunnel, the routing in the Microsoft operating system is changed for security associated with the VPN tunnel. The two Microsoft services above are unable to recognize the new VPN route and the existence of a way to get to the Internet, so a message comes back claiming there is no Internet access or no network connection. This is a failure on the part of Microsoft and the NLA and NCSI services."
