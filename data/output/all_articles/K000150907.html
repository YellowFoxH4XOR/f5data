K000150907: In ASM DoS Layer 7, the "Record Traffic" feature captures HTTPS traffic but does not decrypt it.

Type
Support Solution
Published
2025-04-17
Updated
2025-04-17
Applies to
  • BIG-IP
  • F5 Distributed Cloud Services
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150907

Description

The feature "Record Traffic" in ASM DoSL7 profile, perform a TCP dump when a DoS attack is underway, in order to diagnose the attack vectors and attackers, observe whether and how it was mitigated, and draw conclusions for changing the DoS profile configuration.

However, this feature does not capture the master key required to decrypt packet captures, which makes it inefficient for analyzing HTTPS/2 traffic. 

This is an example of a PCAP file captured using the "Record Traffic" feature during a DoS attack. While the packets are present, we are unable to decrypt frames #13 and #15 due to the absence of the master key.

Environment

  • DoSL7 profile
  • Record Traffic

Cause

Functioning as designed

Answer/Recommended Actions

Although the feature is working as expected, you may enable the system variable using the following command:

tmsh modify sys db tcpdump.sslprovider value enable

However, enabling this variable will consume additional CPU and memory resources. Therefore, it is important to carefully assess the system’s performance beforehand and avoid keeping this setting enabled for extended periods of time.
