Known Issue

This is the result of a known issue. When a manual failover is performed on a high availability BIG-IP ASM pair configured with network failover, the Configuration utility on both units incorrectly reports a Sync Recommended message. The message is displayed although no other configuration changes were made. This behavior is due to an updated internal time variable, which causes the BIG-IP ASM system to interpret that a policy change occurred.

F5 Product Development tracked this issue as ID 337180 and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.

In addition, this issue has been fixed in Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing a hotfix, refer to K10025: Managing F5 product hotfixes for BIG-IP 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

Workaround

You can work around this issue and prevent the Configuration utility from reporting a false Sync Recommended message following a manual failover. To do so, perform the following procedure on both units:

Note: This change may require a reboot. Therefore, perform this change during a maintenance period in order to prevent any disruption to traffic in the event a reboot is required.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. In the navigation pane, expand Application Security, point to Options, and click Preferences.

    The Preferences screen opens.
  3. Clear the Recommend Sync When Policy Is Not Applied check box.
  4. To keep your changes, click Save.
  5. Reboot if prompted.
