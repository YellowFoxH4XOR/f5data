To get bigtop to function correctly in a serial vt100 connection, modify the tty00 line in the /etc/ttys file by change the following line from:

tty00 off

to:

tty00 "/usr/libexec/getty default" vt100 in secure

Note: It is likely that you will also have to set the TERM variable. To set the TERM for a tty, add the following lines to the end of /root/.bash_profile file:

if [ 'tty' = '/dev/tty00' ] then
TERM=vt100
else
TERM=ibmpc3
fi
export TERM
