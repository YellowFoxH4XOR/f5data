Description

Capture traffic using tcpdump on RH CoreOS Openshift node

Environment

  • OpenShift 4.X
  • BIG-IP Next CNF 
  • BIG-IP Next SPK

Cause

Check intra pod connectivity 

Recommended Actions

 

Packet captures with specific port and IP collected on the worker nodes, 
 

1. check port ,
 

# oc get ep -n <namespace where pod deployed>


2. check node on which pod deployed ,

# oc get pod -owide -n <namespace where pod deployed>


3. collect pcap for from relevant node taken from #2 and port #1,
 

# oc get node
# oc debug node/<node name> 
# chroot /host
# toolbox

run tcpdump - narrow filter per port & ip for required time and break it , just find example :

# tcpdump -s0 -ennvi any port <port from point #1.1> -w /host/var/tmp/${HOSTNAME}_$(date +\%d_%m_%Y-%H_%M_%S-%Z)_issue.pcap  


4. before exiting debug point #3 , from second console copy pcap to jumphost , like below :
 

# oc get pod -A | grep debug
 openshift-debug-7dg87               node-worker2-debug              1/1   Running   0         111m

# oc project openshift-debug-7dg87
Now using project "openshift-debug-7dg87" on server "https://api.ocp41230.openshift.lab.int:6443".

# oc cp node-worker2-debug:/host/var/tmp/node-worker2-debug_16_11_2023-08_03_18-UTC_issue.pcap node-worker2-debug_16_11_2023-08_03_18-UTC_issue.pcap 
  tar: Removing leading `/' from member names

# ll -h
-rw-r--r-- 1 root root 244M Nov 16 09:52 node-worker2-debug_16_11_2023-08_03_18-UTC_issue.pcap


5. exit from debug point #3, debug pod will be removed accordingly.
