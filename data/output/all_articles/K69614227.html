Known Issue

The BIG-IP configuration file may reference a deleted SSL key, certificate, or certificate signing request (CSR) file.

This issue occurs when the following condition is met:

  • You have deleted an SSL key, certificate, or CSR file from BIG-IP Configuration utility > System > File Management > SSL Certificate List.
By default, changes from the BIG-IP Configuration utility should automatically save to the BIG-IP configuration files.

Impact

During a configuration reload, the deleted files may be restored because they are referenced in the /config/bigip.conf file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • During a configuration reload, the deleted files may be restored because they are referenced in the /config/bigip.conf file.

Workaround

To work around this issue, you can save the configuration changes manually after deleting the SSL key, certificate, or CSR file using the Traffic Management Shell (tmsh) command. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Save the changes by typing the following command:

    save /sys config
