Known Issue

This is the result of a known issue. When running an LCD test on version 10.0.6.94 of the End-User Diagnostics (EUD) program, the following error message may display:

LCD test started.
unable to open device
Could not open com port...verify root access.
Could not open com port Test Failed!

The LCD functionality test is selection number 6 from the main EUD menu. Additionally, you may receive the error message if you select menu item 17, which will run all hardware tests.

This error message does not indicate an issue with the front panel LCD; the issue exists in the EUD software.

F5 Product Development tracked this issue as CR86846 and CR86058, and it was fixed in EUD version 10.0.7. For information about upgrading your EUD, refer to K7960: Obtaining and installing the latest version of End-User Diagnostics.

In addition, BIG-IP 9.4.5 and beyond ship with EUD 10.0.7 or later. For information about upgrading the BIG-IP software, refer to the BIG-IP LTM release notes.

Note: For information about obtaining the EUD version, refer to K8002: Determining the End-User Diagnostics version.
