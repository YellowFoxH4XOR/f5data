K17041023: Unable to add /27 IP to split tunnel in APM BIG-IP APM 16.1.2

Applies to

Source
https://my.f5.com/manage/s/article/K17041023

Description
While configuring the IPv4 Include Address Space or the IPv4 Exclude Address Space parameter of an APM Network Access object, you are prompted with an error message such as:
01071126:3: apm resource network-access </Common/NA_object> destination 10.20.30.40 and netmask 255.255.255.224 are not valid for IPv4 exclude subnet address space.

Environment

  • BIG-IP APM
  • Network Access

Cause
The parameters IPv4 Include Address Space and IPv4 Exclude Address Space require we put the "Network Address" and not one address of one of the host, within that range.

Recommended Actions

Example, with using the command line / TMSH prompt:
  1. Invalid: (tmos)# modify apm resource network-access <NetworkAccess_object_name> address-space-exclude-subnet {{ subnet 10.20.4.1/27}}
  2. Valid: (tmos)# modify apm resource network-access <NetworkAccess_object_name> address-space-exclude-subnet {{ subnet 10.20.4.0/27}}
