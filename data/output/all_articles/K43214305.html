Description

Changes made to a SSL profile only impact new SSL connections.

Resumed SSL connections will continue to use the previous SSL profile settings.

Clearing the SSL session cache will force all SSL connections to use the new settings.

Environment

You use a SSL profile on the BIG-IP.
  • Client SSL
  • Server SSL
You make a change to a SSL profile, and want the changes applied immediately, including to resumed SSL sessions.

Cause

You make changes to the SSL profile, and want the changes implemented immediately for all SSL connections that use the modified SSL profile.

Recommended Actions

To clear the SSL session cache for a client-ssl profile, change the cache-timeout value to 0, then change it back to the previous value.

# tmsh modify ltm profile client-ssl <SSL profile name> cache-timeout 0
# tmsh modify ltm profile client-ssl <SSL profile name> cache-timeout 3600

For a server-ssl profile, replace 'client-ssl' with 'server-ssl'.

    Example: The SSL profile modified is named 'MyClientSSLProfile' :

    Display the current value of the cache-time (default 3600):

    # tmsh list ltm profile client-ssl MyClientSSLProfile cache-timeout
    ltm profile client-ssl MyClientSSLProfile {
        cache-timeout 3600
    }

    Set the cache-timeout to 0:

    # tmsh modify ltm profile client-ssl MyClientSSLProfile cache-timeout 0


    Now set the cache-timeout back to the original value (3600):

    # tmsh modify ltm profile client-ssl MyClientSSLProfile cache-timeout 3600

    Additional Information

    To view the current SSL session cache data for a client SSL profile:

    # tmsh show ltm profile client-ssl <SSL profile name> | grep -A5 'Session Cache'

    Example:

    # tmsh show ltm profile client-ssl MyClientSSLProfile | grep -A5 'Session Cache'
