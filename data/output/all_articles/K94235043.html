Description

Traffic is classified as client side traffic from command tmsh show pem sessiondb all

  • tmsh show pem sessiondb all
---------------------------------------------- Session Information ----------------------------------------------
IP Address 192.168.10.109
Policy Server Session Id
Quota Server Session Id
Session State provisioning-pending      
Session Origin "client side traffic"           <<

Environment

  • PEM

Cause

GGSN send data plan traffic before accounting update(radius) has reached F5

Recommended Actions

If the radius server sends an accounting update for that user IP on the control plane, the status will change from client side traffic to radius..
