Known Issue

The BIG-IP ASM system may be unable to import a security policy.

This issue occurs when all of the following conditions are met:

  • The affected BIG-IP ASM policy was originally created with the Create a policy using third party vulnerability assessment tool output option enabled.
  • The policy was exported using the Export security policy in XML format option

Impact

BIG-IP ASM will be unable to import the security policy.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Importing the policy will result in error messages in the Configuration utility. The error messages will appear similar to the following example:

    Error: Field '/policy/parameters/parameter/user_input_format' may not contain the value ''.
