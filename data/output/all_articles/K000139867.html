Description

You observe high CPU usage in the system graphs or the output of top command, after enabling the ASM Bot Defense profile for the first time (after attaching the Bot Defense profile to a virtual server).

Environment

  • ASM module provisioned
  • Bot Defense profile attached to a Virtual Server

Cause

When enabling Bot Defense profile, the Java obfuscator process is initiated which resulting into higher CPU utilization, until it is completed. And after a while, the CPU consumption should come down normally.

So, the noticed behavior should be expected. This process can take several minutes to a few hours to be completed.

Recommended Actions

If the obfuscation task takes an abnormally longer time (more than 4-5 hours), and you cannot see any other processes consuming CPU time, open a service request with F5 Support for further investigation.

 

Additional Information

The datasyncd process consumes available resources with a lower priority. So, If more important processes need CPU/Memory, the obfuscation is de-prioritized or waits until resources are available.
