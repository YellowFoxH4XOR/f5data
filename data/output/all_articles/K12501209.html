Description

The partition / is fulfilled with hs_error.log under /tmp or /tmp/jvm-<number> with java core dump file. 

/tmp/hc_err_pid<number>.log 
/tmp/jvm-<number>/hs_error.log 

From the file /tmp/jvm-7499/hs_error.log, you might see the following warning message about insufficient memory for Java.

# There is insufficient memory for the Java Runtime Environment to continue.
# Native memory allocation (malloc) failed to allocate 165136 bytes for Arena::Amalloc
# Possible reasons:
#   The system is out of physical RAM or swap space

Environment

  • Partition / has space issue due to hs_error.log files
  • Java core dump is created constantly
  • It reports 'java.lang.OutOfMemoryError' in restjavad log

Cause
The hs_error.log is a dump file that gets created when java crashes. Insufficient memory causes a java core dump with these files.

Recommended Actions
To free up the space, remove the hs_err_pid<number>.log files in /tmp/ or /tmp/jvm-<number> by following the below command:

rm -rf /tmp/hs_err_pid*
rm -rf /tmp/jvm-*

Additional Information
To avoid the issue, consider allocating more memory for the management. For more details, please refer to the following article:
  • K26427018: Overview of Management provisioning
  • K12410040: restjavad restarts frequently
