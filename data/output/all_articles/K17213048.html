Known Issue

You are unable to open the Virtual Server page using the Configuration utility.

This issue occurs when all of the following conditions are met:

  • You license and provision BIG-IP APM for your BIG-IP system.
  • From the Configuration utility, you attempt to open the Virtual Server page to add or modify a virtual server.

Impact

You are unable to access the Virtual Server page.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to open the Virtual Server page from the Configuration utility, the page is blank.

Workaround

To work around this issue, use the TMOS Shell (tmsh) to add, modify, or delete virtual servers.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
