K000139993: TLS handshake fails when ECC Brainpool curves used with TLS 1.3

Type
Support Solution
Published
2024-06-20
Updated
2024-06-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000139993

Description

After configuring client-ssl profile following the steps from K000137488, TLS handshake fails when TLS 1.3 is used.

In the packet capture you can observe error:  TLS Alert (Level: Fatal, Description: Handshake Failure)

In ltm logs there is a message similar to:

01260009:4: 10.10.10.10:33738 -> 10.10.20.20:443: Connection error: ssl_select_suite:11132: alert(40) cannot find matching cert

Environment

  • BIG-IP LTM
  • virtual server with custom client-ssl profile
  • cipher rule with default signature-algorithm
  • ecdsa_brainpool signature-algorithms sent in Client Hello

Cause

ECDSA Brainpool signature alghortihms are not included in DEFAULT algorithm set and TLS Handshake fails because signature algorithm on BIG-IP side does not match data sent by Client.

Recommended Actions

Add ECDSA brainpool signature algorithm.

1. In GUI go to Local Traffic  ››  Ciphers : Rules.
2. Choose the rule you want to modify or click Create to create new one.
3. For Signature Algorithms, type missing signature algorithms.

The available signature algorithms are: DSA-SHA1, DSA-SHA256, DSA-SHA384, DSA-SHA512, ECDSA-SHA1, ECDSA-SHA256, ECDSA-SHA384, ECDSA-SHA512, RSA-PKCS1-SHA1, RSA-PKCS1-SHA256, RSA-PKCS1-SHA384, RSA-PKCS1-SHA512, RSA-PSS-SHA256, RSA-PSS-SHA384, RSA-PSS-SHA512, ECDSA-BRAINPOOL256-SHA256, and ECDSA-BRAINPOOL384-SHA384.

Example:

ltm cipher rule /Common/test_brainpool {
cipher ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES128-CCM:ECDHE-ECDSA-AES128-CCM8:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES256-CCM:ECDHE-ECDSA-AES256-CCM8:ECDHE-ECDSA-CHACHA20-POLY1305-SHA256:TLS13-AES256-GCM-SHA384:TLS13-AES128-GCM-SHA256:TLS13-CHACHA20-POLY1305-SHA256
dh-groups DEFAULT:BRAINPOOLP256R1:BRAINPOOLP384R1:BRAINPOOLP256R1TLS13:BRAINPOOLP384R1TLS13
signature-algorithms DEFAULT:ECDSA-BRAINPOOL256-SHA256
}
