Description

  • You successfully discovered and imported BIG-IP LTM/APM configuration onto BIG-IQ
  • On the BIG-IQ, you configured new access log profile,
  • Associate this new log profile with an access policy and the access policy is linked with a virtual server
  • You then successfully deployed your new configuration onto the managed BIG-IP/s
  • But when viewing for events in /var/log/apm file, the apm file does not contain the expected access logs

Environment

  • BIG-IQ
  • BIG-IP
  • APM
  • Event Logs

Cause

  • Access log profile on the BIG-IQ  may have been created with the wrong publisher

Recommended Actions

Under Access   >>   Access Groups   >>   < name of the Access Group >   >>   Event Logs Settings   >>   <name of the Event Log>, verify or modify the setting for 'Access Logs Publisher' to be /common/sys-db-access-publisher
