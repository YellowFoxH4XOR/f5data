Known Issue

iControl commands to create a BIG-IP DNS (formerly known as BIG-IP GTM) virtual server are unavailable.

This issue occurs when all of the following conditions are met:

  • You use iControl to create BIG-IP DNS virtual server.
  • You want to create a BIG-IP DNS virtual server that requires address translation.

Impact

Creating a virtual server with address translation is not possible.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When reviewing the available iControl commands, there are no commands to create a BIG-IP DNS virtual server with address translation.

Workaround

To work around this issue, you can use the Configuration utility to create the virtual server. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to DNS > GSLB > Data Centers > Data Center List. 
  3. Click the destination data center name.
  4. Click the Servers tab.
  5. Click the Virtual Servers tab.
  6. Click Add.
  7. Enter the name of the virtual server.
  8. Enter the IP address of the virtual server.
  9. Select the Service Port for the virtual server from the drop-down menu.
  10. Enter the translation IP address of the virtual server in the Translation text box.
  11. Select the Translation Service Port from the drop-down menu.
  12. In the Configuration Health Monitor section, select the appropriate health monitor in the Available column.
  13. Move the monitor to the Selected column using the << button.
  14. Click Create.
