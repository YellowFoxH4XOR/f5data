Topic

You can use this F5-supported iApp template to configure availability and Secure ICA proxy remote access for Citrix XenApp or XenDesktop environments. This iApp template configures BIG-IP LTM, BIG-IP APM, and BIG-IP AFM for XenApp or XenDesktop services. For the versions of Citrix XenApp/XenDesktop that are supported in this iApp template, refer to the BIG-IP APM Client Compatibility Matrix manual for your specific BIG-IP APM version.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching MyF5 and finding product documentation.

When used with the BIG-IP APM system, this iApp template supports proxy authentication and secure remote access for all XenApp and XenDesktop HTTP-based protocols without requiring a Virtual Private Network (VPN) client. The iApp template enables you to configure BIG-IP APM for two-factor authentication with RSA SecurID and it supports smart card authentication.

Before using this iApp template, F5 recommends that you refer to the Deploying F5 with Citrix XenApp or XenDesktop manual for information about using the template, including information about how to configure your XenApp/XenDesktop environment for use with the BIG-IP system.

To download and install the iApp template, perform the following procedures:

  • Download the iApp template
  • Install the iApp template

Download the iApp template

Important: You must download the file, not copy and paste the content.

  1. Go to the F5 Downloads site.
  2. From the Downloads Overview page, select Find a Download.

    The Select a Product Line page displays.

  3. From the Product Line column, select iApp-Templates.
  4. Read the End User Software License Agreement and either accept the license by clicking I Accept or cancel the process by selecting Cancel.

    If you accept the End User Software License Agreement, the Select a Download page appears, with a table detailing the filename, product description, and size of the file.

    Note: After you have accepted the End User Software License Agreement, the system does not present the agreement again for subsequent downloads that you perform during the same browser session.

  5. From the Filename column of the table, select the iapps-x.x.x.x.x.zip file. For example, the file for the January 2019 iApp release is iapps-1.0.0.542.0.zip.

    The Select a Download Method page appears.

  6. F5 supports the FTP, HTTP, and HTTPS protocols for downloading files from F5. Select one of the three supported protocols using the down arrow button.

    A pop-up window appears, asking you to either open or save the file.

    Note: Some browsers save the file to a default location. You can review your specific browser's documentation to change the default location of where you want to save files.

  7. Select the option to save the file.

Install the iApp template

  1. Unzip the iapps-x.x.x.x.x.zip zip file that you downloaded in the previous procedure to a location accessible from your BIG-IP system.
  2. Log in to the Configuration utility.
  3. From the iApp tab, select Templates.
  4. Select Import.
  5. Select the Overwrite Existing Templates box.
  6. Select Browse.
  7. Browse to the location where you saved the iApp file.
  8. Select the template file that corresponds to the iApp version you want to install.

    For example, the file for the January 2019 release of this iApp is named f5.citrix_vdi.v2.4.6.tmpl.

  9. Select Upload.

When the upload completes, the iApp is available to use.

f5.citrix_vdi.v2.2.0

Features added

  • The iApp now supports Citrix Secure Ticket Authority (STA) when using StoreFront servers. In previous versions, STA was supported for only Web Interface Servers.
  • The iApp now provides you the option to choose None for the Active Directory health monitor question.
  • The iApp now has a Client SSL handshake IdleTimeout value of 60 seconds, to give users enough time to enter their smartcard pin before timing out.
  • You can now create and attach a BIG-IP APM-specific logging profile (BIG-IP 12.0.0 and later only).
  • The iApp now has a new branch in the Access Policy to handle the StoreFront protocol specific to Receiver client connections (BIG-IP 12.0.0 and later only).
  • The iApp now has a new Access Policy item for the Citrix StoreFront protocol for two-factor authentication with RSA SecurID (BIG-IP 12.0.0 and later only).
  • The iApp now has an advanced option to include a configuration option for per-application ICA parameter overrides (BIG-IP 12.0.0 and later only).

Issues resolved

  • None

Known issues

  • If you are deploying two-factor authentication using native StoreFront protocol 2.5 or later, and BIG-IP 11.6.0 HF5 or a later hotfix in the BIG-IP 11.6.x branch, F5 has a required workaround for the deployment to work correctly. This is not an issue in other BIG-IP versions, including BIG-IP 11.6.0 and HF1 through HF4, and BIG-IP 12.0.0 or later. For more information, see the Hotfix Release Information page that accompanies the HF5 and later. See the Deploying F5 with Citrix XenApp or XenDesktop manual for specific details on the workaround.
  • Support for StoreFront 3.0 requires BIG-IP 12.0.0 or 11.6.0 HF6.
  • Support for StoreFront 3.0 was introduced after the f5.citrix_vdi.v2.2.0 iApp template was released. As a result, the Welcome section of the iApp template does not currently state support for StoreFront 3.0. This will be changed in the next revision of the iApp template.
  • If you are using StoreFront 3.0, for the question "Did you deploy Citrix StoreFront?," you must select Yes, my Citrix environment uses StoreFront 2.5 or 2.6.
  • If you are using StoreFront 3.0, for an important change to the health monitor produced by the iApp template, refer to the Deploying F5 with Citrix XenApp or XenDesktop manual.
