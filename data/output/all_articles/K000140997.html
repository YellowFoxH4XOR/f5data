K000140997: How to change BIG-IP(hostname) in BIG-IQ CM to new one

Type
Support Solution
Published
2024-10-08
Updated
2024-10-08
Source

Description

Your BIG-IQ operate as a License Manager and you has added the BIG-IP to BIG-IQ with the wrong device name(hostname) or you would like to change the device name of the BIG-IP(Hostname) that is displayed in the BIG-IQ to a new one.

Environment

BIG-IQ License Manager

BIG-IP

Cause

None

Recommended Actions

If you use the BIG-IQ License Manager to license BIG-IP:

Impact of procedure: Revoking the license disables traffic management features and returns the BIG-IP system to an unlicensed state. 

  1. Log in to the Configuration utility.
  2. Navigate to System > License.
  3. On the License page, click Revoke.
  4. When prompted to remove the license, click OK.
  5. Install the license on the BIG-IP VE system again.
