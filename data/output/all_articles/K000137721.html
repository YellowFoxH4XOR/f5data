Description

  • Device Management >> Overview
  • Device Management >> Traffic Groups => traffic-group-1 (or other traffic-group object)

  • Local Traffic >> Network Map => only "Loading..." message is displayed.

Figure: qkview error screen

Environment

TMSH cli shared alias is configured for list command, as follows.

[root@bigip1:Active:In Sync] config # awk '/cli alias shared.*list \{/,/\}/' /config/bigip_base.conf
cli alias shared /Common/list {
    command bash
}
[root@bigip1:Active:In Sync] config #
 

Cause

TMSH cli shared alias for list command made internal REST communication on GUI not working.
 

Recommended Actions

Delete cli shared alias for list command and restart restjavad by following commands.
  
# tmsh delete cli alias shared list ; tmsh save sys config
# tmsh restart sys service restjavad

Note: Shared aliases for ‘bash’ have been noted as potential Indicators of Compromise and are flagged by iHealth Heuristic H52145254-5. F5 strongly recommends generating a qkview, uploading it to iHealth, reviewing the flagged heuristics and then following the guidance in K11438344 unless there is reason to believe these aliases were created by a legitimate system administrator.
