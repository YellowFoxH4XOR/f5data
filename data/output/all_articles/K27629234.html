Description

When attempting to log in with SSH you receive an error message similar to the following:
SSH Client returns  no supported authentication methods available.

Log messages are logged in  /var/log/secure.
Example:
sshd[7159]: error: Received disconnect from 10.10.10.1 port 64400:14: No supported authentication methods available [preauth]
sshd[28374]: pam_bigip_authz: No shell or bad shell for user admin

Environment

  • SSH

Cause

The accessed account is disabled on the destination device. This is commonly seen when using "admin" and the "admin" account has terminal access disabled.
 

Recommended Actions

Enable terminal access when required using the following procedure:
  1. Log on to the Configuration utility.
  2. Go to   System > Users >User List  select  admin.
  3. Set Terminal Access to Advanced Shell.
Note: Advanced will enable the Bash shell.
