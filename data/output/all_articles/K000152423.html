K000152423: VLAN interface is not created when reinstalling F5 SPK

Source

Description

VLAN interface is not created when reinstalling F5 SPK

Environment

  • SPK
  • VLAN
  • TLS

Cause

CWC failed to connect to RabbitMQ, incorrectly detecting a valid TLS certificate as expired.

Error: Failed to establish connection to rabbitmq server. Error tls: failed to verify certificate: x509: certificate has expired or is not yet valid: </span>

Recommended Actions

1. Verify TLS certificate validity

kubectl get certificate -A -ojsonpath="{range .items[*]}{.metadata.name} not before: {.status.notBefore} not after: {.status.notAfter} renewal time: {.status.renewalTime}{'\n'}{end}" | column -t

 

2. Delete the secrets for CWC and RabbitMQ AMQP

oc delete secret <rabbit-amqp> -n namespace

oc delete secret <cwc-amqp>t -n namespace

 

2. Once new secrets are created, recreate both cwc and rabbitmq pods.

oc delete pod <rabbitmq-pod> -n namespace

oc delete pod <cwc-pod> -n namespace
