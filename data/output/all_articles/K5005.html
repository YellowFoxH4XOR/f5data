Known Issue

This is the result of a known issue. When changing the BIG-IP hostname setting using the Configuration utility, you may receive the following error message if the hostname has a single character subdomain:

Host name must be a fully qualified DNS name

F5 Networks Product Development tracked this issue as CR50443 and it was fixed in BIG-IP version 9.2.2. For information about upgrading, refer to the BIG-IP LTM or ASM Release Notes.
