K10949: Error message: Security exception: Non-HTML data has been blocked for security reasons

Topic

Mac OS X and Linux clients will be unable to download files through FirePass Web Applications if the Require cache cleanup ActiveX/Plugin to be loaded to allow attachment downloads in Mobile E-Mail and downloads via Web Applications setting has been enabled on the Users: Endpoint Security: Post-Logon Actions page. Mac OS X and Linux clients do not support Active X Plugins. As a result, FirePass will not be able to detect the cache clean-up Active X Plugin and will generate the following error message:

Security exception: Non-HTML data has been blocked for security reasons

Workaround

To avoid this error message and allow Mac OS X and Linux clients to download files via Web Applications, you can either disable the aforementioned option, or you can create a separate Master Group specifically for Mac OS X and Linux Clients that does not enable that Post-Logon Action for the Master Group.
