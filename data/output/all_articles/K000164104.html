K000164104: Telemetry Streaming (f5-telemetry) REST Endpoints Return 404 After Upgrade to BIG-IP 17.5.1 Due to Incomplete iApps LX Package

Type
Support Solution
Published
2026-11-04
Updated
2026-11-04
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000164104

Description

Telemetry Streaming (TS) REST calls return HTTP 404 on BIG-IP 17.5.1, so the TS declaration cannot be posted or reconfigured. Affected endpoints:

  • /declare (declaration POST)
  • /info
  • /pullconsumer


The TS iApps LX package (f5-telemetry) is listed as installed in the BIG-IP GUI (iApps > Package Management LX), but its files are missing or not loadable under "/var/config/rest/iapps/f5-telemetry/".

Log message:

restnoded: Warn LoaderWorker Could not get list of files to load from directory: /var/config/rest/iapps/f5-telemetry/nodejs

Because restnoded does not load the package, the TS REST routes are not registered, and the request fails before TS reads the declaration.

Environment

  • BIG-IP LTM 17.5.1.x
  • F5 Telemetry Streaming (f5-telemetry iApps LX package) in use

Cause

The f5-telemetry iApps LX package was not in a loadable state. Because restnoded could not load the package files from "/var/config/rest/iapps/f5-telemetry/nodejs", the TS REST routes were never registered, and every TS call returned 404. Reinstalling the package restored the routes.

Answer/Recommended Actions

Perform these steps on each device in the deployment. Complete the reinstall in a maintenance window.

1) Check whether the package directory and its files exist. From the CLI on each device, run: "ls -l /var/config/rest/iapps/f5-telemetry/" Confirm that package.json, package-lock.json, and version are present. If the directory is missing or incomplete, continue to the next step.

2) Back up the current Telemetry Streaming declaration.

3) Uninstall the package. In the BIG-IP GUI, go to iApps > Package Management LX, select f5-telemetry, and click Uninstall.

4) Reinstall the package. Click Import, provide the path to the f5-telemetry RPM, and complete the installation.

5) Re-POST the TS declaration to the /declare endpoint. 

6) Verify that the TS REST endpoints respond (no longer return 404) on your device.

For installation details, see Downloading and installing F5 BIG-IP Telemetry Streaming. 

Additional Information

  • Increasing the sys db variable "iapplxrpm.timeout" value does not address this issue. If the sys db value was already 600, the 404 behavior might be caused by the package state, not the timeout.
  • Expected behavior: The command output "ls -l /var/config/rest/iapps/f5-telemetry/" shows the package files, and TS REST endpoints respond to requests.
  • Unexpected behavior: the GUI lists the package as installed, but the directory is empty or incomplete, and TS REST endpoints return 404.
