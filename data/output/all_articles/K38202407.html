K38202407: Script ran on BIG-IQ hung and shows ''Cancel Requested''

Type
Support Solution
Published
2022-09-06
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K38202407

Description

  • When running scripts in BIG-IQ CM, post cancelling the script it got hung and still shows "Cancel Requested" on GUI.
  • Script stuck in "Cancel requested" state.
  • There is no end date and 'delete' tab is greyed out for these two script.

Environment

  • BIG-IQ CM
  • Script

Cause

Stuck task

Recommended Actions

With the "task ID" and "selfLink" identified, you can send a cancel request to request that the BIG-IQ system cancels the target process that is stuck.

  1. Connect to BIG-IQ CM CLI
  2. Run

    Note: Replace <password> with the admin password

    curl -k  -l -H'Accept:application/json' -H'Content-Type:application/json' --user admin:<password> https://localhost:8100/shared/user-script-execution/<URL-PROCESS-TASK-ID> -X PATCH -d '{"currentStep":"CLEAN_UP", "status":"FAILED"}'| json-format
