Known Issue

The tmm process may fail when using a WebAcceleration profile.

This issue occurs when all of the following conditions are met:

  • You have a WebAcceleration profile associated with a virtual server.
  • The Cache Size setting in the WebAcceleration profile is set to 0.

Impact

The BIG-IP host may crash and fail over to another host in the device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • TMM core files may be found in the /var/core directory.
  • The BIG-IP host may fail over to another host in the device group.

Workaround

To work around this issue, you can avoid setting the WebAcceleration cache to 0.
