K00758357: Err scriptd: script has exceeded its time to live, terminating the script.

Description

When BIG-IP is managed by Big-IQ and there are many Virtual Server objects (thousands) configured on BIG-IP, below error logs may be observed in /var/log/ltm on BIG-IP.

err scriptd[PID]:<message code>: script has exceeded its time to live, terminating the script

Environment

  • BIG-IP
  • BIG-IQ
  • Scriptd

Cause

When BIG-IQ running scripts to check the virtual server configured on BIG-IP and there are too many Virtual server configured, the list virtual server cannot be finished within 300s (max-script-run-time)
The alerts will be triggered.
The cause can be confirmed with audit logs, you can also check /var/log/audit with timestamps of 300s before the alert triggered, when the list virtual server activity started, and the list virtual server audit logs terminated with the same time of scriptd error log.

Recommended Actions

There should be no service impact on BIG-IP, you can safely ignore the alert.
You can also extend the max-script-run-time to a larger value, eg 600s.
Checking default setting

tmsh list sys scriptd max-script-run-time
sys scriptd {
    max-script-run-time 300
}

Modify the value to 600s

tmsh modify  sys scriptd max-script-run-time 600
tmsh save sys config
