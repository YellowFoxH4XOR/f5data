Description

Management is down interface down.

# tmsh show net interface

----------------------------------------------------------------

                 In     Out     In    Out

mgmt    down  77.4G  299.5M  47.7M  26.6K   1.2K     0      none

 

# tmsh list net interface mgmt media-active

net interface mgmt {
    media-active none
}

Environment

  • BIG-IP
  • Management interface

Cause

None

Recommended Actions

Verify and troubleshoot physical layer. 

  1. Check the Link (L) light of management port shows a connection to a remote switch.
  2. Try connecting to a different switchport of the switch.
  3. If BIG-IP management interface does not show up in # tmsh show net interface, then check any faults in the cable.
  4. Replace the cable used for connecting to BIG-IP management interface.

If the issue does not get fixed, run an EUD and then contact F5 support.
