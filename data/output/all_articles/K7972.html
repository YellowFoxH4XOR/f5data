Known Issue

This is the result of a known issue. The BIG-IP ASM system sets the following cookies in the client response to enforce elements in the security policy:

  • Main ASM cookie
  • ASM Frame cookie

Note: For information about BIG-IP ASM cookies, refer to K6850: Overview of BIG-IP ASM cookies.

When the BIG-IP ASM system sets the main cookie, it erroneously embeds two Set-Cookie headers in the response to the client. Browsers are expected to keep only the last set cookie; therefore, this issue is benign.

F5 Product Development tracked this issue as CR84747 and it was fixed in BIG-IP ASM 9.4.4.  For information about upgrading, refer to the BIG-IP ASM Release Notes.
