K7232: Clearing the Statistics and Forensics data from the BIG-IP ASM database before creating a UCS file for archival or installation use

Topic

The BIG-IP ASM 9.2 through 9.2.5 archive both the Statistics data (Events and Attacks) and the Forensics data are in a UCS archive.

Important: Beginning in versions 9.3 and 9.4, the BIG-IP ASM UCS archive no longer contains the Forensics data. Beginning in version 9.4.5, the BIG-IP ASM UCS archive no longer contains the Events data.

Statistics and Forensics data can be exceedingly large, thereby creating a large UCS file, depending on the number of web applications and the length of time the data has been gathered.

This large amount of information may result in a lengthy load time of the UCS file, as the UCS file must copy the Statistics and Forensics information into the BIG-IP ASM database. F5 Networks recommends clearing the Statistics and Forensics data before creating a UCS file for archival use or for use with installation on another system. To do so, perform the following procedures:

Note: The following procedures will delete all BIG-IP ASM related Events, Attacks, and Forensic information from the BIG-IP ASM database.

  • Clearing the Events and Attacks for all web applications
  • Clearing the events from the Forensics section for each web application
  • Creating a UCS file for archival or installation use

Clearing the Events and Attacks for all web applications

  1. Expand the Application Security menu.
  2. Select Web Applications.

    Note: A new window will open.

  3. Select Statistics.
  4. Set the filter to Not Filtered.
  5. Click Clear to clear the Events.
  6. Select the Attacks tab.
  7. Set the filter to Not Filtered.
  8. Click Delete to delete the Attacks.

Clearing the events from the Forensics section for each web application

  1. Expand the Application Security menu.
  2. Select Web Applications.

    Note: A new window will open.

  3. Select the first Web Application name.
  4. Select the Forensics tab.
  5. Set the filter Custom.
  6. Select the All option button for each filter.
  7. Click Go to list all events.
  8. Click Clear All to clear all events.
  9. Repeat these steps for each web application.

Creating a UCS file for archival or installation use

  1. Select System.
  2. Select Archives.
  3. Select Create.
  4. Fill in the appropriate information and select Finished.
