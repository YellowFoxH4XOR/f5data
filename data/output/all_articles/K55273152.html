Known Issue

The rsync program generates log files that may accumulate in the /var/run directory of a Virtual Clustered Multiprocessing (vCMP) guest.

This issue occurs when all of the following conditions are met:

  • The vCMP guest has a large number of configuration objects.
  • The guestagentd process of the vCMP guest attempts to transfer a statistics file that exceeds the 6 MB limit, to the vCMP host.

vCMP guests periodically upload statistics to the vCMP host using rsync. The rsync program creates a log file in /var/run, which is deleted upon success. When the transfer fails due to the file size limit, the log files remain and accumulate upon subsequent transfer failures. Because /var/run is mounted to a temporary file system in memory, the accumulation of files can lead to memory exhaustion.

Impact

vCMP guest performance may degrade over time, and the system may eventually become unresponsive and restart due to memory exhaustion.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The /var/run directory contains numerous log files named tmstats-rsync.<pid>. The name of the file will appear similar to the following example:

    tmstats-rsync.12345

  • The BIG-IP Configuration utility intermittently restarts.
  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • The BIG-IP system may become unstable due to a lack of memory.

Workaround

To work around this issue, you can you can disable guest health statistic collection on the vCMP host. To do so, perform the following procedure:

Impact of workaround: This procedure affects values returned by the tmsh show vcmp health statistics command.

  1. Log in to the Traffic Management Shell (tmsh) of the vCMP host by typing the following command: 

    Note: If the device is a VIPRION, ensure that you are logged in to the primary blade.

    tmsh

  2. To disable statistic collection, type the following command:

    modify /vcmp guest all capabilities add { stats-isolated-mode }

    Note: If you need to revert the change you made in this workaround, type the following command for this step:

    modify /vcmp guest all capabilities delete { stats-isolated-mode }

  3. Save the changes by typing the following command:

    save /sys config
