K000164118: GUI displays DNS Cache Resolver's "No Route IPv4|IPv6" error values under "No Free Port IPv4|IPv6" label.

Type
Support Solution
Published
2026-11-18
Updated
2026-11-18
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000164118

Description

With DNS cache resolver configuration, "No Route IPv4" or "No Route IPv6" statistics counter increments when DNS cache resolver fails to query to upstream servers or root servers due to any reasons (e.g., no route to upstream servers or root servers), as shown on below example on TMSH.

root@(bigipdns1)(cfg-sync Standalone)(Active)(/Common)(tmos)# show ltm dns cache resolver my_resolver_cache | grep -E "No Free Port|No Route"
  No Free Port IPv4                    0
  No Free Port IPv6                    0
  No Route IPv4                        65
  No Route IPv6                        65
root@(bigipdns1)(cfg-sync Standalone)(Active)(/Common)(tmos)#

 

However, on GUI, the value of "No Route IPv4|IPv6" counters were wrongly shown under different label "No Free Port IPv4|IPv6".

Figure: "No Free Port IPv4|IPv6" counter wrongly displays values of "No Route IPv4|IPv6" counters

 

Note: "No Route IPv4|IPv6" counter is currently unavailable on GUI, as described on K12708865.

 

Environment

  • DNS cache resolver in use.
  • GUI DNS cache resolver statistics page.

 

Cause

Bug ID2719645.

 

Answer/Recommended Actions

Use TMSH to view DNS cache resolver statistics.

# tmsh show ltm dns cache resolver [cache resolver object name]

 

Additional Information

None.
