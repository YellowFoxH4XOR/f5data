Topic

FirePass administrators use the Administrative Console to configure, monitor, and troubleshoot the FirePass controller. For greater security, you may want to restrict access to the FirePass Administrative Console. The following procedure restricts administrator logon to specific web services, and limits access based on the source IP address of the client browser.

Enabling and disabling administrator logon for web services

For each web service configured on the FirePass controller, you have the option to enable or disable administrator logon for that web service. For example, you may want to enable administrator logon for web services with internal IP addresses, but disable administrator logon for web services with external IP addresses.

You can enable and disable administrator logon by performing the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Device Management: Configuration: Network Configuration page.
  3. Click the Web Services tab.
  4. In the Services column, look for a capital letter A. Each web service with a capital letter A in its Services column allows administrator logon.
  5. Click the Configure link next to the web service you want to configure.
  6. If the Admin Logon check box is selected, and you want to disable administrator logon, clear the Admin Logon check box.

    If the Admin Logon check box is cleared, and you want to enable administrator logon, select the Admin Logon check box.

    Important: You must have at least one SSL-enabled web service that allows administrator logon.

  7. Click the Update button.
  8. Repeat steps 3 through 7 for each web service you want to configure.
  9. Click the Finalize tab.
  10. Click the Finalize Changes button.
  11. Click the Apply Changes and Restart button.
  12. To restart the FirePass controller, click the Restart button.

Limiting access to the Administrative Console based on source IP address

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Device Management: Security: Admin Access Security page.
  3. In the Option 1 field, enter a comma-separated list of IP addresses and network ranges that should have access to the Administrative Console.

    For example:

    192.168.1.15, 192.168.1.20, 192.168.10.0/24

    Note: FirePass automatically adds your current IP address to the list of allowed IP addresses to ensure that you do not lose access to the Administrative Console while you perform this change.

  4. Click Apply.

Additional security with administrative realms

Once you complete the procedure outlined in this article, you may want to configure administrative realms, which provide more granular access control. A realm consists of a set of defined master groups, resource groups, and realm administrators with feature access delegated to each group by a superuser. Administrative realms are configured on the Device Management: Security: Administrative Realms page. For more information about configuring administrative realms, refer to the FirePass Controller Administrator Guide.
