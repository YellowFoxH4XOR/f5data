Description

When viewing Instances within NMS/Instance Manager an instance is reporting Offline or does not show at all.
The following instance log messages will appear within /var/log/nginx-agent/agent.log: 

time="<date&time>" level=debug msg="Creating commander client"
time="<date&time>" level=error msg="Unable to create command channel: rpc error: code = Unavailable desc = connection error: desc = \"error reading server preface: http2: frame too large\""
time="<date&time>" level=info msg="Commander retrying to connect to nginx-instance.example.com:443"

Environment

NMS/Instance Manager

Cause

TLS is disabled within the instance's NGINX-Agent configuration

Recommended Actions

On the affected instance edit the NGINX-Agent configuration:

sudo vim /etc/nginx-agent/nginx-agent.conf


Find and uncomment or create the tls setting and enable it:

tls:
  enable: true


Restart NGINX-Agent:

sudo systemctl restart nginx-agent.service
