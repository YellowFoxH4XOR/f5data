Description
Disable or enable interfaces bundle causes bcm56xxd restarting.
Restarting bcm56xxd lead to all links down/up
For example:

root@(<host name>)(cfg-sync Disconnected)(Active)(/Common)(tmos)# modify net interface 4.0 bundle disabled
Are you sure? Y/N (changing the interface bundling will restart bcm56xxd and impact traffic) y
root@(<host name>)(cfg-sync Disconnected)(Active)(/Common)(tmos)# <date time> <host name> emerg bcm56xxd[<PID>]: 012c0001:0: Restarting bcm56xxd to setup new bundling configuration.
<date time> <host name> emerg logger: Re-starting bcm56xxd

Environment

  • BIG-IP platform

  • 40G interface

Cause
It is by design.
Recommended Actions

F5 suggest doing it on maintenance window. 
Important: Disable or enable interfaces bundle causes bcm56xxd restarting. Restarting the bcm56xxd daemon will interrupt traffic across all interfaces, and in the case of an HA pair, will result in a failover if the current system is active.
