Description

High CPU consumption observed on control plane. Top command shows cbrd process is consuming most of them.
 

Environment

  • BIG-IP
  • v14.1.* and later
  • CPU
     

Cause

Bug ID 901225
 

Recommended Actions

To confirm please take for few min
strace -p `pidof cbrd` -f -T -o /var/tmp/cbrd_strace.out

You will see the similar entry in the cbrd_strace.out.
This shows the process was attempted to terminated but it does not, so that goes to infinitive loop
