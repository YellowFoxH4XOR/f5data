Known Issue

A BIG-IP high availability (HA) standby device may erroneously respond to an Internet Control Message Protocol (ICMP) request that was sent to a virtual server address.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP devices are deployed in an HA configuration.
  • Your BIG-IP devices are configured with non-floating self IP addresses.
  • You configure a virtual server-type Forwarding IP, enable Connection Mirroring, and synchronize the configuration.
  • You simultaneously send ICMP traceroute packets to the virtual server addresses of both the active and standby devices.

Impact

The BIG-IP standby device virtual server address responds to the ICMP traceroute packets.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view network-level communication of the standby BIG-IP virtual server address, you notice that the virtual server address erroneously responds to the ICMP traceroute request with an ICMP time exceeded in-transit message.
  • When Connection Mirroring is disabled on the affected virtual server, the virtual server address no longer erroneously responds to ICMP traceroute requests.
