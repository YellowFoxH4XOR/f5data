Description

When deploying BIGIP on an OpenStack by using f5-openstack-hot templates, the following error may be encountered.

2022-02-10T16:59:02.440Z error: 2022-02-10T16:59:02.440Z error: [pid: 17231] [lib/util.js] Onboard failed: connect ETIMEDOUT 172.217.16.238:443

Environment

  • f5-openstack-hot
  • No Internet access on the BIGIP

Cause

By default, f5-openstack-hot templates will access the following URL for metric collection.

https://www.google-analytics.com/collect

If the BIGIP has no Internet access, the issue will occur.

Recommended Actions

 For the environment that doesn't have an Internet connection, please disable the following options in the template.

allow_usage_analytics
