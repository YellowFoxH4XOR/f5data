Issue

Old Behavior

Previously, the BIG-IP Edge Portal app for iOS did not contain support for Passcode Locking.

New Behavior

Beginning in BIG-IP Edge Portal app for iOS 1.0.2, the ability to lock the app with a PIN code was added.

This option allows the user to lock active sessions on the BIG-IP Edge Portal app independently of the main PIN lock of the iOS device.

Impact

If you enable the Passcode Lock, you will be required to enter your passcode before you can access the BIG-IP Edge Portal app.

Recommended Actions

You can enable the Passcode Lock option in the BIG-IP Edge Portal app by performing the following the procedure:

  1. Open the Edge Portal app on your iOS device.
  2. Select Settings.
  3. Select Passcode Lock.
  4. Select Turn Passcode On.
  5. Enter a 4-digit passcode.
  6. Reenter the 4-digit passcode.
