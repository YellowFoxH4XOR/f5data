Topic

The bigpipe tcp show command provides global statistics about TCP traffic that has been handled by BIG-IP LTM.

Output of the bigpipe tcp show command is displayed in the following format:

BIG-IP 9.0.0 through 9.3.1:

GLOBAL TCP STATISTICS --

    (open, close-wait, fin-wait, time-wait) = (0, 0, 0, 0)

    (accept, accept fail) = (0, 0)

    (connect, connect fail) = (0, 0)

    (expire, abandon, rxrst) = (0, 0, 0)

    (rxooseg, rxbadseg, rxbadsum, txrexmit) = (0, 0, 0, 0)

    (syncacheover, rxcookie, rxbadcookie) = (0, 0, 0)

BIG-IP 9.4.0 and later:

GLOBAL TCP STATISTICS

| Conn (open, CLOSE-WAIT) = (0, 0)

| Conn (FIN-WAIT, TIME_WAIT) = (0, 0)

| Conn (accept, not accept) = (0, 0) (estab, fail) = (0, 0)

| Conn (abandon, expire) = (0, 0) Resets = 0 Bad cksm = 0

| (rxbadseg, rxooseg, txrexmits) = (0, 0, 0)

| SYN cache overflow = 0 (rxcookie, rxbadcookie) = (0, 0)

 

The Global TCP Statistics display the following information:

Global TCP StatisticInformation displayed by the statistic
openThis statistic displays the number of connections that have completed a TCP 3-way handshake but have not yet been closed.

close-wait

(CLOSE-WAIT)

This statistic displays the number of connections in the close process that are waiting for response from the remote system.

fin-wait

(FIN-WAIT)

This statistic displays the number of connections waiting for acknowledgement for a FIN request.

time-wait

(TIME-WAIT)

This statistic displays the number of connections waiting to close after sending acknowledgement of the FIN to the remote systems.
acceptThis statistic displays the number of incoming connections for which BIG-IP has successfully opened a socket.

accept fail

(not accept)

This statistic displays the number of incoming connections for which BIG-IP has failed to open a socket.

connect

(estab)

This statistic displays the number of outgoing connections for which the destination successfully opened a socket.

connect failed

(fail)

This statistic displays the number of outgoing connections for which BIG-IP could not open the connection or the destination failed to open a socket.
expireThis statistic displays the number of connections that were closed because the timeout value was reached.
abandonThis statistic displays the number of attempted connections that received no response.

rxrst

(reset)

This statistic displays the number of connections that received a reset (RST).
rxoosegThis statistic displays the number of connections that received an out of order TCP segment.
rxbadsegThis statistic displays the number of connections that received a bad TCP segment.

rxbadsum

(Bad cksm)

This statistic displays the number of connections that received a TCP segment with a bad checksum.
txrexmitThis statistic displays the number of connections on which a TCP segment was retransmitted.

syncacheover

(SYN cache overflow)

This statistic displays the number of times the outstanding number of syncookie responses was larger than the threshold specified in the Connection.SynCookies.Threshold configuration database variable.
rxcookieThis statistic displays the number of valid syncookie responses received by the BIG-IP system.
rxbadcookieThis statistic displays the number of invalid syncookie responses received by the BIG-IP system.

Note: Items listed within () indicate how the entries are listed in BIG-IP version 9.4.0 and later.
