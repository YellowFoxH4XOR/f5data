Topic

You can use the bigpipe http show command to display Ram Cache statistics on the BIG-IP system.

The output of the bigpipe http show command appears similar to the following example:

GLOBAL HTTP STATISTICS
| requests (total, max in conn, GET, POST) = (0, 0, 0, 0)
| requests (v0.9, v1.0, v1.1) = (0, 0, 0)
| responses (v0.9, v1.0, v1.1) = (0, 0, 0)
| responses (2xx, 3xx, 4xx, 5xx) = (0, 0, 0, 0)
| response size ( <1k, 1-4k, 4-16k, 16-32k, 32-64k)
| ( 0, 0, 0, 0, 0)
| Set-Cookie header insertions = 0
| RAM cache (entries, size, evict) = (0, 0, 0)
| RAM cache hit count (hits, misses, misses all) = (0, 0, 0)
| RAM cache byte count (hits, misses, misses all) = (0, 0, 0)
|
| COMPRESSION STATISTICS --
| total bytes (pre, post, null, saved) = (0, 0, 0, 0.00%)

The following tables define the RAM Cache statistics parameters:

RAM Cache statisticDescription
entriesThe number of objects currently stored in the cache
sizeThe current size of the total cache in bytes
evictThe number of objects that have been evicted from the cache in order to make room for newer objects

RAM Cache hit count statisticDescription
hitsThe total number of objects that were served from the cache
missesThe total number of objects that were not served from the cache, but were cacheable objects
misses allThe total number of objects that were not served from the cache, including objects that are not cacheable

RAM Cache byte count statisticDescription
hitsThe total number of bytes served from the cache
missesThe total number of bytes that were not served from the cache, but were for objects that were cacheable
misses allThe total number of bytes that were not served from the cache, including for objects that are not cacheable

Note: For information about how to display all RAM Cache entries, refer to K10200: Displaying and deleting RAM Cache entries from the command line.
