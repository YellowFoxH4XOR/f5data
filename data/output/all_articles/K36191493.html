Known Issue

The BIG-IQ system may fail to read and import the BIG-IP AFM configuration.

This issue occurs when all of the following conditions are met:

  • The BIG-IQ system is running BIG-IQ 7.0.0. 
  • The BIG-IP AFM system is running BIG-IP 14.1.0.5 or 14.1.0.6.
  • The BIG-IP AFM system is not licensed with the Protocol Inspection module.
  • You attempt to import the BIG-IP AFM configuration to the BIG-IQ system.

Impact

You are unable to manage the BIG-IP AFM configuration from the BIG-IQ system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IQ system fails to import the BIG-IP AFM configuration with a status 400 error.
