Description

In SSL/TLS, the most commonly used authentication algorithms are:

  1. RSA
  2. DSA
  3. ECDSA

In this, DSA has been deprecated in the latest FIPS standard FIPS-186-5 [Feb, 2023], for DSS (Digital Signature Standard), due to long term security concerns.

Environment

  • BIG-IP 

  • SSL/TLS

Cause

DSA algorithm has been deprecated officially from the FIPS 186-5 standard (Feb, 2023).

Recommended Actions

Thus we advise customers to avoid using DSA. Instead use ECDSA (Elliptic Curve Digital Signature Algorithm) which is much more secure and efficient.  In case if you are having much older devices in your environment which may not support ECDSA, you can stick to RSA.

Additional Information

When choosing the key sizes for RSA or ECDSA, you can check the below table as a thumb rule:

AlgorithmKey Size (bits)Estimated Security Level (bits)Notes
RSA102480No longer considered secure. Do not use.
RSA2048112Recommended minimum for most applications as of 2024.
RSA3072128Higher security, but slower than 2048-bit keys.
RSA 4096140Even higher security, primarily used in high-security environments where performance is less critical.

ECDSA (e.g. NIST P-384 curve)384192Equivalent security to 7680-bit RSA.
