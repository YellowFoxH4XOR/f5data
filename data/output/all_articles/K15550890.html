Known Issue

The Client SSL profile's inherit-certkeychain option may not sync correctly to the standby BIG-IP system.

This issue occurs when all of the following conditions are met:

  • You configure the Client SSL profile on the active BIG-IP system in a high availability (HA) configuration.
  • The configuration syncs to the standby system.

Impact

The inherit-certkeychain option mismatch may cause the BIG-IP system to display unexpected behavior.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The inherit-certkeychain field is set to false on the standby system instead of true for the same Client SSL profile. The tmsh /ltm profile client-ssl test.1 command output appears similar to the following examples:

    Active BIG-IP system:

    ltm profile client-ssl test.1 {
        app-service none
        cert default.crt
        cert-key-chain {
            default {
                cert default.crt
                key default.key
            }
        }
        chain none
        defaults-from clientssl
        inherit-certkeychain true
        key default.key
        passphrase none
    }

    Standby BIG-IP system:

    ltm profile client-ssl test.1 {
        app-service none
        cert default.crt
        cert-key-chain {
            default {
                cert default.crt
                key default.key
            }
        }
        chain none
        defaults-from clientssl
        inherit-certkeychain false
        key default.key
        passphrase none
    }
