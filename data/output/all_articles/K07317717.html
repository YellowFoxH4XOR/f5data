Description

Error Message

01140029:4: HA <HA table monitor> <HA object> fails action is <action>

In this error message, note the following:

  • <HA table monitor> is the high availability (HA) table monitor
  • <HA object> is the monitored object or system process
  • <action> is the remedial action being taken

You may encounter this message in /var/log/ltm.

Examples

  • 01140029:4: HA daemon_heartbeat tmm fails action is go offline down links and restart.
  • 01140029:4: HA vlan_fs /Common/Internal fails action is reboot.
  • 01140029:4: HA proc_running bd fails action is go offline and down links.
  • 01140029:4: HA nic_failsafe tmm fails action is reboot.

Environment

  • High availability
  • Failsafe

Cause

This message may occur when any of the following conditions are met:

  • A system process fails to respond to HA daemon heartbeat messages
  • A system process is no longer running (for example, it crashed)
  • A failsafe configuration is triggered (for example, VLAN failsafe)

A failure action is triggered, which includes one of the following:

  • Restart process that failed
  • Reboot System
  • Restart All
  • Go Offline
  • Go Offline Abort TMM
  • Failover and Restart TMM

Recommended Actions

None

Additional Information

Traffic processing may be affected while processes restart, the BIG-IP system reboots, or fails over to a peer member in the device group.
