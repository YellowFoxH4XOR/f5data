K8052: Windows Vista clients cannot restart Firefox after installing FirePass client-side components

Source

Topic

If a Windows Vista client attempts to restart Firefox after installing a Firefox plug-in, such as a FirePass client-side plug-in, Firefox may fail to start and report an error message similar to the following example:

The program must close to allow a previous installation attempt to complete. Please restart.

This error occurs due to a known issue in Firefox and it is unrelated to the FirePass software. For more information about this error, including a workaround, refer to the following website:

http://kb.mozillazine.org/Browser_will_not_start_up
