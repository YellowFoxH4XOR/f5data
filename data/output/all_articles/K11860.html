Known Issue

This is the result of a known issue. If you are accessing a Web Application Tunnel favorite that requires your web browser to launch an external process, such as Java, ActiveX, or Microsoft web RDP, the external process may fail to start. As a result, your Web Application Tunnel window may appear blank or parts of the page may be missing. This issue first occurred in version 7 of the F5 VPN client components.

You can verify the version of F5 VPN components installed on the client system with the FirePass Component Troubleshooting Utility (CTU), and you can verify the version of Protected Workspace components. To verify the version, navigate to the Application Tunnels : Protected Workspace entry in the navigation pane to the left of the CTU. The affected version is 7000,2010,331,1909.

Note: For more information about downloading and using the FirePass CTU, refer to K9133: Overview of the FirePass Components Troubleshooting Utility.

F5 Product Development is tracking this issue as ID 337365 and ID 337127.

This issue has been fixed in cumulative hotfix HF-70-1, which has been issued for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
