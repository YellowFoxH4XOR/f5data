Known Issue

This may be the result of a known issue. If you open an FTP session through BIG-IP and enable passive mode, BIG-IP opens a second connection for FTP data. The node then sends an FTP 229 (EPSV mode entered) message to BIG-IP. If BIG-IP does not acknowledge the message, or if the node does not receive the acknowledgement, the node will retransmit the FTP 229 message. When BIG-IP receives the retransmitted message, it closes the data connection and opens a new data connection. As a result, when the client or node next use the data connection, BIG-IP will respond with a TCP reset.

F5 Networks Product Development tracked this issue as CR46723, CR46724, and CR46746 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP Release Notes.

This issue still exists in the BIG-IP version 4.6 branch.
