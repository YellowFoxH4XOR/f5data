K000137359: Clients unable to connect to VPN after the upgrade from 16.1.3.3 to 16.1.4.1

Type
Support Solution
Published
2023-10-25
Updated
2023-10-28
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.4
Source
https://my.f5.com/manage/s/article/K000137359

Description

BIG-IP platform is having connectivity problem with VPN after the upgrade from 16.1.3.3 to 16.1.4.1

Environment

  • BIG-IP APM
  • Network access
  • DTLS Virtual Server
  • TCP Profile

Cause

  • You are using TCP profiles in the DTLS Virtual Server
  • DTLS Virtual Server is using UDP

 

Recommended Actions

Remove TCP profiles from the DTLS Virtual Server

 

Additional Information

If you have an HTTP profile on this virtual server, it will need to be removed, as HTTP is a TCP protocol and is not compatible with a UDP virtual server.
