Source

Topic

The Symantec heuristic service, which can be found in various Norton and Symantec antivirus applications, may falsely report that the F5Dialsrv.exe file is infected. The F5Dialsrv.exe file is part of the BIG-IP Edge Client components and is necessary for the VPN client to work correctly.

F5 Product Development tracked this issue as ID 340987.

Note: As of the Symantec software update for 01/21/2016 the f5dialsrv.exe file is no longer detected as an infected file.

Workaround

As a temporary workaround, you can put the F5Dialsrv.exe file on your antivirus software's approved list (also referred to as allow list). For instructions about adding files to the approved list, refer to your antivirus software documentation.
