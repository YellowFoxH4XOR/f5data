K8699: Network Access favorites are not displayed when using a customized logon page

Knowledge
Published
2010-09-20
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • FirePass: 6.1.0, 6.0.3, 6.0.2, 7.0.0, 6.0.0, 6.0.1
Source
https://my.f5.com/manage/s/article/K8699

Topic

When you upload a customized FirePass logon page using WebDAV at user logon, FirePass may display all configured favorites except the user’s Network Access favorites. The typical cause of this issue may be that the tzoffsetmin form variable was not set during logon.

Important: If this issue only occurs for a single user, ensure that JavaScript is enabled in the client browser. The web interfaces for F5 Networks products rely heavily on HTML style sheets and JavaScript to display graphics and other objects. For more information, refer to K665: Web interfaces of F5 Networks products may fail to display properly.

The tzoffsetmin variable indicates whether JavaScript support is enabled in the client browser. To resolve this behavior, add the following line to the logon form on the customized logon page:

Important: You must place this line between the <form> and </form> tags in your HTML source code.

<input type="hidden" name="tzoffsetmin" value="1">

When you add this line to the logon form, your HTML source code will appear similar to the following example:

Customized logon form<BR>
<form name="e1" method="post" action="/my.activation.php3">
<input type=hidden name="vhost" value="standard">
Username:<br>
<input type=text size="13" name="username" value="" autocomplete="off">
<br>
Password:<br>
<input type=password size="13" name="password" autocomplete="off"><br>
<input name=login type=submit value="Logon">
<input type="hidden" name="mrhlogonform" value="1">
<input type="hidden" name="tzoffsetmin" value="">
<input type="hidden" name="vhost" value="">
<input type="hidden" name="tzoffsetmin" value="1">
</form>
