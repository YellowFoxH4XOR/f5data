Description

You wish to disallow a character of JSON value by using Character Sets.
 Security > Application Security > Content Profiles > Character Sets > JSON Content

Environment

  • BIG-IP ASM

  • JSON Profiles

Cause

None

Recommended Actions

You have to uncheck "Parse Parameters" in JSON content profile.
Then, confirm "Check characters" is checked in "Value Meta Characters" tab. 

  1. Log in to the Configuration utility.

  2. Navigate to Security > Application Security > Content Profiles and click a content profile type JSON.

  3. Select the name of the security policy you want to update in Current edited security policy.

  4. Disable Parse Parameters. ( default : enable )

  5. Select  "Value Meta Characters" tab to check "Check characters" to be enabled.

  6. Click Update. 

  7. Click Apply Policy to apply the changes.
