Known Issue

This is the result of a known issue. When using iControl to perform a restart on the httpd service on the BIG-IP LTM system, a bigstart restart is instead performed, causing all system services to restart. If the BIG-IP LTM system is in an active state when the bigstart restart is performed, a traffic outage results.  

F5 Product Development tracked this issue as CR97865 and it was fixed in BIG-IP LTM 10.0.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issues still exists in the BIG-IP 9.4 software branch.
