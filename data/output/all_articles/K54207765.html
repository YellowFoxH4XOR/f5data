Description

Your ASM sync group shows Changes Pending, and this status returns shortly after performing a sync.

Environment

  • ASM sync
  • Session Awareness enabled

Cause

Bug ID 750352

Bug ID 750353

Recommended Actions

The available options are to enable automatic sync, or disable session awareness.

Additional Information

Session awareness information must be synced so that the peer has access to this in the event of a failover and can continue tracking / blocking sessions as appropriate.
