Topic

This article covers the compatibility of BIG-IQ Centralized Management and BIG-IP with F5 Application Services 3 extension (AS3) and F5 Declarative onboarding (DO) releases. The article also covers procedures for working with AS3 Redhat Package Manager (RPM) packages.

Description

Beginning in BIG-IQ 6.1.0, the system supports deploying AS3 declarations to managed BIG-IP devices. Beginning in BIG-IQ 7.0.0, support for deploying DO declarations is also included.

For a compatibility overview, refer to the following sections:

  • BIG-IQ Centralized Management compatibility with AS3 and DO
  • Managed BIG-IP device compatibility with AS3 and DO
  • BIG-IQ compatibility with BIG-IP releases

For display and upgrade procedures, refer to the following sections:

  • Displaying the running AS3 and DO version on the BIG-IQ system
  • Upgrading AS3 on the BIG-IQ system
  • Upgrading DO on the BIG-IQ system

Procedures

Display the running AS3 and DO version on the BIG-IQ

You can determine the version of AS3 or DO the BIG-IQ is running by sending an HTTP request to the restnoded service.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IQ command line.
  2. To display the AS3 version, enter the following command:

    curl http://localhost:8105/shared/appsvcs/info

  3. To display the DO version, enter the following command:

    curl http://localhost:8105/shared/declarative-onboarding/info

Upgrade AS3 on the BIG-IQ system 

To upgrade AS3 on the BIG-IQ system, you must first upload the new RPM package to the AS3 packages directory so that, during an AS3 deployment, if your BIG-IP system does not have AS3 installed or if an older version is installed, the BIG-IQ system installs the new version of AS3. After you complete that step, you can upgrade AS3 on the BIG-IQ system itself by installing the new package. The BIG-IQ version of AS3 must be equal or higher than the version on the BIG-IP systems. The following procedure describes the steps to accomplish this.

Impact of procedure: Restarting the services in this procedure causes them to become temporarily unavailable.

  1. Download the RPM package for the version of AS3 you want from F5 Networks GitHub site to your workstation.

    Important: You should only upgrade to the specific versions listed in the compatibility table in the previous section.

  2. Optional: If your BIG-IQ environment has high availability (HA) setup, you should upgrade the AS3 on the Standby unit before upgrading the active unit. The BIG-IQ HA systems are required use the same AS3 version.
  3. Use an SCP client to copy the RPM file to the /shared/tmp directory of the BIG-IQ system.
  4. Log in to the BIG-IQ command line. 
  5. To remount the /usr file system in read-write mode, enter the following command:

    mount -o remount,rw /usr

  6. Copy the new RPM file to the to the AS3 packages directory (/usr/lib/dco/packages/f5-appsvcs) by using the following command syntax. The BIG-IQ uses the package in this directory to install or upgrade AS3 on a target BIG-IP system.

    cp /shared/tmp/f5-appsvcs-<X.Y.Z-V>.noarch.rpm /usr/lib/dco/packages/f5-appsvcs/

    For example:

    cp /shared/tmp/f5-appsvcs-3.24.0-5.noarch.rpm /usr/lib/dco/packages/f5-appsvcs/

    Important: By default, during an AS3 deployment, the BIG-IQ system installs the latest version of the AS3 RPM package from its /usr/lib/dco/packages/f5-appsvcs directory on the managed BIG-IP system. If you require a specific AS3 version on the managed BIG-IP system instead of the latest AS3 version, you should remove the new AS3 RPM package after installing it on the BIG-IQ system and ensure that only the desired AS3 version RPM package exists in the /usr/lib/dco/packages/f5-appsvcs directory.

  7. To remount the /usr file system in read-only mode, enter the following command:

    mount -o remount,ro /usr

  8. Upgrade AS3 on the BIG-IQ system itself. Use the following command syntax to install the AS3 package:

    rpm -Uv /usr/lib/dco/packages/f5-appsvcs/f5-appsvcs-<X.Y.Z-V>.noarch.rpm

    For example:

    rpm -Uv /usr/lib/dco/packages/f5-appsvcs/f5-appsvcs-3.24.0-5.noarch.rpm

    Note: If you have previously updated the restjavad configuration (restjavad.properties.json) with the path of an AS3 RPM package (rpmFilePath), you must remove the rpmFilePath entry from the restjavad.properties.json file before proceeding to restart the restjavad service.

  9. Restart the restjavad and restnoded services by entering the following command:

    tmsh restart /sys service restjavad restnoded

  10. After the services restart, you can confirm the new version is running by using curl to send an HTTP request to the restnoded service by entering the following command:

    curl http://localhost:8105/shared/appsvcs/info

  11. Optional: If your BIG-IQ environment has high availability (HA) setup, after you upgrade the AS3 on the standby unit, you can repeat this procedure to upgrade the active unit.

After deploying an AS3 application from the BIG-IQ system, you can confirm the AS3 installation or upgrade on a BIG-IP system by performing one of the following steps:

  • Verify that the correct AS3 package versions are displayed on the iApps > Package Management LX page of the target BIG-IP Configuration utility.
  • Use a system with the curl utility to send the following HTTP request syntax to the info REST endpoint on the target BIG-IP system to verify that the correct AS3 package versions are displayed:

    curl -kvu <username>:<password> -H Expect: https://<IP address of target BIG-IP>/mgmt/shared/appsvcs/info

    For example:

    curl -kvu admin:admin -H Expect: https://192.0.2.1/mgmt/shared/appsvcs/info

Upgrade DO on the BIG-IQ system

You can upgrade DO by uploading and installing the new RPM package on the BIG-IQ device. To do so, perform the following procedure.

Impact of procedure: Restarting the services in this procedure causes them to become temporarily unavailable.

  1. Download the RPM package for the version of DO you want from F5 Networks GitHub site to your workstation.

    Important: You should only upgrade to the specific versions listed in the compatibility table in the previous section.

  2. Optional: If your BIG-IQ environment has high availability (HA) setup, you should upgrade the DO on the Standby unit before upgrading the active unit. The BIG-IQ HA systems are required use the same DO version.
  3. Use an SCP client to copy the RPM file to the /shared/tmp directory of the BIG-IQ system.
  4. Log in to the BIG-IQ command line. 
  5. Upgrade DO on the BIG-IQ system itself. Use the following command syntax to install the DO package:

    rpm -Uv /shared/tmp/f5-declarative-onboarding-<X.Y.Z-V>.noarch.rpm

    For example:

    rpm -Uv /shared/tmp/f5-declarative-onboarding-1.16.0-8.noarch.rpm

  6. Restart the restjavad and restnoded services by entering the following command:

    tmsh restart /sys service restjavad restnoded

  7. After the services restart, you can confirm the new version is running by using curl to send an HTTP request to the restnoded service by entering the following command:

    curl http://localhost:8105/shared/declarative-onboarding/info

  8. Optional: If your BIG-IQ environment has high availability (HA) setup, after you upgrade the AS3 on the standby unit, you can repeat this procedure to upgrade the active unit.
