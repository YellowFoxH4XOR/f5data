Issue

Old Behavior

Previously, the BIG-IP system did not support iRules commands for DNS.

New Behavior

Beginning in BIG-IP 11.0.0 HF-1, the BIG-IP system supports DNS iRules commands.

F5 Product Development tracked this change as ID 350360.

Impact

You can now use iRules commands that are specifically designed to work with DNS queries on the BIG-IP system.

Recommended Actions

For more information about supported DNS iRules commands and usage, refer to the DNS iRules page on Clouddocs.
