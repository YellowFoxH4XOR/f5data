Known Issue

Simple Object Access Protocol (SOAP) calls using the System::Failover::get_peer_address iControl method may return an empty value.

This issue occurs when the following condition is met:

  • Your BIG-IP system is configured as a member of a device service clustering (DSC) device group.

Note: The DSC technology is also referred to as centralized management infrastructure (CMI).

F5 introduced the DSC architecture in BIG-IP 11.x. DSC provides the framework for ConfigSync, and other high availability (HA) features, such as failover for BIG-IP device groups. When querying a member of a DSC device group, SOAP calls using the System::Failover::get_peer_address iControl method will return an empty array. For DSC configurations, you should use the Management::Device::get_configsync_address iControl method instead.

Impact

SOAP calls using the System::Failover::get_peer_address iControl method return an empty array and the queried system may be misinterpreted as a standalone device.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SOAP calls using the System::Failover::get_peer_address iControl method return an empty array.

Resolution

Status

Workaround

To work around this issue, you can use the Management::Device::get_configsync_address iControl method.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
