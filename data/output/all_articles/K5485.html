K5485: The BIG-IP Application Security Module cannot be installed on the CompactFlash slot

Topic

The BIG-IP ASM packages are too large to be installed on a CompactFlash drive. Therefore, BIG-IP ASM packages will not be installed if you install BIG-IP ASM 9.2 onto the CompactFlash drive. You must install BIG-IP ASM on slot HD1.1 or HD1.2.

If you license the BIG-IP ASM system on the CompactFlash drive installation, the BIG-IP ASM options will be visible in the Configuration utility. However, clicking the BIG-IP ASM menu options results in the following error message:

An error has occurred while loading this page

Furthermore, if you license the BIG-IP ASM system on the CompactFlash drive installation, and run the command bigstart restart asm from the command line, the system will produce the following error message:

Couldn't find service: asm

Workaround

To work around this issue, you can install and license the BIG-IP ASM system on one of the available hard drive slots. For installation options and instructions, refer to the BIG-IP ASM release notes.

Note: Beginning in BIG-IP 10.0.0, you can no longer install BIG-IP modules on a CompactFlash drive; you must install the modules on an available hard drive slot.
