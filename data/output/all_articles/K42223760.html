Description

BIG-IP GUI is inaccessible intermittently.

Given enough time, the BIG-IP might failover traffic to the peer device while generating a tmm core file. tmm core can be seen at:
/var/core/tmm.1.bld0.0.00.core.gz

Environment

  • Running BIG-IP 16.0.0, 16.0.1, 15.1.0, 15.1.1
  • BIG-IP GUI is intermittently no responsive
  • tmm core generated

Cause

This issue is caused by bug ID943081.

Recommended Actions

To resolve this issue, you will need to upgrade your device to BIG-IP software 16.0.1.1 or 15.1.3.

You can read further on this from this article. K90603426.
