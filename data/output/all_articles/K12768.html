Policy Information

F5 has announced the End of Software Development (EoSD) for the Microsoft Internet Explorer 6 (IE6) web browser support feature in FirePass. Support for IE6 was discontinued with the release of FirePass version 7.0.0; additionally, support for IE6 in FirePass 6.1.0 is not supported after February 28, 2011.

Microsoft announced the end of Extended Support for IE6 July 13, 2010. Security patches and bug fixes will no longer be available as a part of Microsoft's support options, as stated in following URL:

Note: The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

http://support.microsoft.com/gp/lifesupsps/#Internet_Explorer

Software End of Life schedule

ProductFeatureEnd of Software Development (EoSD)
FirePassSupport for Microsoft Internet Explorer 62/28/2011

After the EoSD date, F5 will not provide software fixes for any technical issues with IE6 connecting to FirePass. In addition, after the EoSD date, F5 will provide technical support for IE6 on a best-effort basis.

If you are experiencing problems with your Web Application through FirePass's Portal Access when using IE6, try testing with a later generation browser, such as Internet Explorer 7 or Firefox 3.6.

For information about End of Life terms and definitions, refer to the End of Life Cycle Glossary located in K8986: F5 product support policies.
