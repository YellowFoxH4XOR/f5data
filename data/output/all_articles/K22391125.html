Known Issue

The BIG-IP APM logon page title may not render correctly.

This issue occurs when all of the following conditions are met:

  • Your access policy contains a logon page.
  • The logon page has been customized to use a dynamic session variable value as part of the title.

Impact

The logon page is not rendered correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you access the access policy logon page, the value of the dynamic session variable value is not displayed.
  • The logon page title contains JavaScript errors.

Workaround

To work around this issue, you can modify the logon.inc code of the affected access profile, adding a function so the system can display the session variable. To do so, perform the following procedure:

Impact of workaround: F5 recommends that you perform the following procedure during a scheduled maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Customization > Advanced.
  3. Expand the Access Profiles section.
  4. Select the affected access profile.
  5. Expand the Access Policy section.
  6. Expand the affected access profile Logon Pages section.
  7. Expand the Logon Page section.
  8. Click logon.inc.
  9. Add the following function to the logon.inc code (approximately at line 111, prior to the first function statement).

    function getSoftTokenPrompt(){
    if ( softTokenFieldId != "" && edgeClientSoftTokenSupport()) {
    var div = document.getElementById("formHeaderSoftToken");
    if (div) {
    return div.innerHTML;
    }
    }
    return null;
    }
  10. Replace the following code section:

    Original code:

    function OnLoad()
    {
    var header = document.getElementById("credentials_table_header");
    var softTokenHeaderStr = getSoftTokenPrompt();
    if ( softTokenHeaderStr ) {
    header.innerHTML = softTokenHeaderStr;
    }

    Replacement code:

    function OnLoad()
    {
    var header = document.getElementById("credentials_table_header");
    var softTokenHeaderStr = "<? echo $formHeaderSoftToken; ?>"
    if ( softTokenFieldId != "" && softTokenHeaderStr != "" && edgeClientSoftTokenSupport()) {
    header.innerHTML = softTokenHeaderStr;
    } else {
    header.innerHTML = "<? echo $formHeader; ?>";
    }
  11. Replace the following code section.

    Original code:

    <td colspan=2 id="credentials_table_header" ></td>

    Replacement code:

    <td colspan=2 id="credentials_table_header" ><? echo $formHeader; ?></td>

  12. Add the following code before the closing </body> tag.

    <div id="formHeaderSoftToken" style="overflow: hidden; visibility: hidden; height: 0; width: 0;"><? echo $formHeaderSoftToken; ?></div>
  13. In the upper-right corner of the code editor, click Save Draft.
  14. In the Do you want to save your changes? window, click Yes.
  15. In the upper-left corner of the editor, click Save.
  16. In the upper-left corner of the Configuration utility, click Apply Access Policy.
  17. Click the Apply Access Policy button.
