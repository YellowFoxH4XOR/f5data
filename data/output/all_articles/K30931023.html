Issue

Error Message

err mcpd[<PID>]: 0107032f:3: The vlan (</Partition/VLAN Name>) associated with the static route <IP Address/Mask> must have a Self IP.

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • </Partition/VLAN Name> is the partition name and the name of the VLAN.
  • <IP Address/Mask> is the configured IP address and mask.

For example:

err mcpd[7571]: 0107032f:3: The vlan (/Common/My_VLAN) associated with the static route 192.0.2.0/24 must have a Self IP.

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The Configuration utility
  • The serial console

Description

This message occurs when the following condition is met:

  • The BIG-IP system is attempting to create a static route when none of the self IP addresses for the static route are on the same interface, and the addresses do not use the same IP protocol format (IPv4 or IPv6).

Impact

The BIG-IP system cannot create a static route.

Recommended Actions

Create all self IP addresses for the static route on the same interface and ensure that the addresses use the same IP protocol format.
