Known Issue

In rare instances, the BIG-IP system may experience a Traffic Management Microkernel (TMM) core file and traffic disruption when processing HTTP traffic.

This issue occurs when all of the following conditions are met:

  • You have configured an HTTP virtual server.
  • The origin web server (OWS) sends a response before the BIG-IP system has completed processing the entire incoming HTTP request from the client.

Impact

The BIG-IP system is unable to process traffic while the TMM process restarts, and the system fails over if you have it for high availability (HA).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The TMM process restarts and the BIG-IP system temporarily fails to process traffic.
  • Your BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
  • The system logs the stack trace to the /var/log/tmm file.
