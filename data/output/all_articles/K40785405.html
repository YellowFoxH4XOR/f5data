Topic

You can configure the BIG-IP APM system to use a proxy for portal access resources.

Description

When you configure the Proxy Host and Proxy Port options of the Portal Access configuration, the BIG-IP APM system will accordingly proxy traffic for portal access resources.

For security reasons, hostnames of portal access resources that are configured to use a proxy are required to be resolvable by the BIG-IP APM system. Instead of sending a request directly to the proxy, the BIG-IP APM system will first attempt to resolve the hostname of the portal access resource. If no DNS record is available, the request will be blocked by an APM ACL, and result in an APM DNS error page.

Recommendations

When you configure the APM system to use a proxy for Portal Access, make sure that the BIG-IP APM system can resolve the hostnames of resources behind the proxy.
