Description

Modified management route under System >> Platform.

Change does not take effect after clicking Update; old management route still displayed and in use.

Environment

  • GUI
  • Management route

Cause

Bug ID 1012377: Unable to display/edit 'management route' via GUI

Recommended Actions

Bug ID 1012377 is not fixed in any current version at the time of this article's publication.

A workaround is to use tmsh, for example:

tmsh modify sys management-route default gateway <gateway>
