K000147088: Response cookie is getting blocked when origin is Azure endpoint

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147088

What Happened?

You have an origin pool that the server is a Public DNS pointing to an Azure endpoint and you need that the cookie generated is not getting removed.

Environment

  • F5® Distributed Cloud
  • HTTP Load Balancer 

Resolution

 

Create an HTTP Route and setup a Host Rewrite to the host needed

Cause

Azure instances have a function called Affinity cookie that is used for sticky sessions. When request pass thru F5 XC it removes it
