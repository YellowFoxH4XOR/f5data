Description

After migrating BIG-IP to new hypervisor you see is intermittent sync failure.

Sync Failed
A validation error occurred while syncing to a remote device
Sync error on BIG-IP01.f5.com: Load failed from /Common/BIG-IP02.f5.com 01070712:3: Caught configuration exception (0), Failed to sync files..
Recommended action: Review the error message and determine corrective action on the device

Similar error message in LTM logs.

Jan 15 11:45:00 BIG-IP01.f5.com err mcpd[20207]: 0107134b:3: (rsync: failed to connect to <IP address> (<IP address>): Connection refused (111)
Jan 15 11:45:00 BIG-IP01.f5.com err mcpd[20207]: 0107134b:3: (syncer /usr/bin/rsync failed! (2560) ()
Jan 15 11:45:00 BIG-IP01.f5.com err mcpd[20207]: 0107134b:3: (rsync process failed.) errno(255) errstr().
Jan 15 11:45:00 BIG-IP01.f5.com err mcpd[20207]: 01070712:3: Caught configuration exception (0), Failed to sync files..
Jan 15 11:45:00 BIG-IP01.f5.com err mcpd[20207]: 01071488:3: Remote transaction for device group /Common/device-group-failover to commit id 4 7679819533436518922 /Common/BIG-IP02.f5.com 0 failed with error 01070712:3: Caught configuration exception (0), Failed to sync files... 

Environment

  • BIG-IP Virtual Edition
  • Auto sync enabled

Cause

Intermittent network drops between two BIG-IP on port 4353.

Answer/Recommended Actions

Check on host level for any packet drops.
