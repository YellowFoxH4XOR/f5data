Description

  • I am trying to update an SSL certificate to an existing profile.
  • My SSL certificate expired, and I need to upload the new certificate.

Environment

  • F5® Distributed Cloud Services
  • Certificates

Cause

SSL certificates have a defined validity period and will eventually expire. When a certificate expires, it must be replaced with a new, valid certificate to maintain secure communications and avoid service disruptions.

Recommended Actions

To update the SSL certificate:

1. Select relevant namespace

2. Navigate to Multi-Cloud App Connect/Shared Configuration -> Manage -> Certificate Management -> TLS Certificates

 

3. Locate the relevant certificate and click on the three dots underneath Actions

4. Click Manage Configuration

5. Click Edit Configuration, located in the top right corner

6. Under Certificate, click Import From File

7. You can upload any of the following file types: crt, cer, pem, pkcs12, p12 or pfx

  •  If your certificate is encoded, input the Password 

8. Select the appropriate Key Type and Policy Type

9. Click Import

 

The updated certificate will now be listed in Manage -> Certificate Management -> TLS Certificates

 

Additional Information

  • Supported certificate file types for upload include: crt, cer, pem, pkcs12, p12, and pfx.
  • If the certificate file is password-protected (such as pkcs12/pfx), you must provide the password during the upload process.
  • After updating, the new certificate will be used for all services referencing the updated profile.
  • It is recommended to update certificates before expiration to avoid service interruptions or browser security warnings.
  • You can manage and view all certificates in the "TLS Certificates" section under Certificate Management.
  • For best practices, consider scheduling certificate updates during maintenance windows to minimize potential impact.
