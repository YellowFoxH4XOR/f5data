Description

What is action required to get last scan time work?

 

Environment

  • BIG-IP APM
  • Endpoint Security (Client-side)
  • Antivirus Software check
  • "Last Scan Time not Older than (days)" is configured.

Cause

  • Last scan value is taken for "Full Scan", not "quick scan".

 

Recommended Actions

  • Make sure you run Full Scan within the day VPE Antivitus check last scan's days.
  • Recommend to run Full scan after installing Edge Client.
  • If still there is issue, gather info following below solution and escalate to F5 Support.
    K11643: Troubleshooting with the OPSWAT OESIS Diagnose tool

 

Additional Information

  • Some of antivirus software doesn't support "Quick Scan", only "Full scan".
