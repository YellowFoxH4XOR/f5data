Known Issue

Cisco IOS XR Intermediate System-to-Intermediate System (IS-IS) routers may report Authentication TLV not found.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system for dynamic routing using the IS-IS protocol, and the system is peered with an IOS XR router, or with another BIG-IP system that is running software later than BIG-IP 11.6.1.
  • You have configured IS-IS authentication and set a value for lsp-refresh-interval or for max-lsp-lifetime.

Impact

There is no impact. You can safely ignore this issue. Routing is not affected, and the LSP routing information contains the Auth TLV information.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the BIG-IP system is peered with IS-IS to the Cisco IOS XR routers, you observe messages similar to the following example:

    isis[1003]: %ROUTING-ISIS-5-AUTH_FAILURE_DROP : Dropped L2 LSP from TenGigE0/0/0/1 SNPA 0001.47fd.a801 due to authentication TLV not found.
