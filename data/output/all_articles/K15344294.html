K15344294: Allow SNMP access to F5 rSeries

Source

Description

In addition to configuring a community name and configure its access via an SNMP user, you must also configure a  "system allowed-ips allowed-ip" entry to allow SNMP traffic from a management station.
 

Environment

  • rSeries
  • SNMP

Cause
rSeries appliance will drop SNMP traffic sent to its control plane by default.
 

Recommended Actions

Add IP address of your SNMP manager in the allow list, for example, 10.10.10.10 is the IP address of your SNMP manager:

*******************************************
system allowed-ips allowed-ip SNMP
 config ipv4 address 10.10.10.10
 config ipv4 port 161
!
*********************************************

To add more than one allowed IP address, you can specify a network address and a prefix length or you can create a separate entry for each IP address with a different name for each entry. For more information, refer to the rSeries F5OS-A SNMP Monitoring and Alerting section of the F5 rSeries Planning Guide on F5 Cloud Docs.


 You can use below command to capture the SNMP packets going through the management interface:

tcpdump -nni mgmt "port 161 or port 162"
