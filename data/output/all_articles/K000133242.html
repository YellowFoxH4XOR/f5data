Description

STREAM::expression iRule command might not have effect when several STREAM::expression commands are used in a single iRule event.

  • STREAM::expression command described here

Environment

  • BIG-IP
  • iRule with several STREAM::expression commands

Cause

As a result, only the last STREAM::expression command has any effect.

For example, when following is used:
 

STREAM::expression {@https://example1.com/@https://example1-result.com/@}
STREAM::expression {@https://example2.com/@https://example2-result.com/@}
STREAM::enable 

In the example above, only second STREAM::expression has an effect, meaning just https://example2.com will be rewritten to https://example2-result.com

Recommended Actions

Combine the expressions to make a single call.
As per documentation: Replaces the current stream expression with a new one

For example:

STREAM::expression {@https://example1.com/@https://example1-result.com/@ @https://example2.com/@https://example2-result.com/@}
STREAM::enable
