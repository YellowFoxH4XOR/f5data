Description
You wish to verify the installed version of F5 Guided Configuration (GC).

Environment

  • BIG-IP version 13.1.0.8+

Cause
N/A

Recommended Actions
Check the GC version using your preferred method

  • Configuration Utility
    • BIG-IP APM: Access > Guided Configuration
    • BIG-IP Advanced WAF: Security > Guided Configuration
  • CLI
    # tmsh list mgmt tm access usecase-pack-info
  • iControl REST API
    Query the /mgmt/tm/access/usecase-pack-info endpoint

    For example, using curl from the CLI:

    curl -sku admin:<password> -H "Content-Type: application/json" https://<BIG-IP hostname or mgmt IP address>/mgmt/tm/access/usecase-pack-info | jq .

Additional Information

The F5 Guided Configuration software is installed on the system but only activated after a user navigates to it for the first time. The version information is not displayed until the Guided Configuration has been activated.
