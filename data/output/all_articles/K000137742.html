Description

  • You have only updated one of the two cluster members.
  • HA pair is showing status Disconnected in the top left corner of configuration utility.
  • In the Device Management ›› Overview screen you see error:

Version Mismatch. Devices are executing different software versions. One or more devices are unreachable. Resolve any communication problems before attempting to sync.

Environment

  • BIG-IP
  • High Availability
  • Software upgrade activity

Cause

This is expected behaviour.

Recommended Actions

Upgrade second cluster member to the same software version as first one.

Additional Information

None.
