Description

Environment

  • F5OS-C
  • Primary key migration

Cause

Bug ID 2046597: Setting the primary key on VELOS will intermittently cause a failover and primary key inconsistency

Recommended Actions

To recover from this issue, perform a clean install or system database reset-to-default, then rebuild the configuration or load backups after setting the primary key to a previous known value.

To avoid this issue:

  • Power off the standby system controller via AOM
  • Run the primary key change operation
  • Wait for the key migration to complete (show system aaa primary-key, reports a status of complete)
  • Power the standby system controller back on via AOM
