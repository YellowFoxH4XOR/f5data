Description

Single network interface card (NIC) is supported beginning in BIG-IQ 8.0.0.

Note: For more information, refer to K54221096: A single NIC configuration is not supported prior to BIG-IQ VE 8.0.

However, there are known issues that require the steps described in this article to be performed in order to get single-nic working properly on BIG-IQ 8.0.0/8.1.0.

Environment

  • If you have not yet setup a BIG-IQ 8.0.0/8.1.0 instance then you can use the steps outlined in this article to apply necessary workarounds during the installation process.
  • If you have already setup a BIG-IQ 8.0.0/8.1.0 instance then you will still need to reinstall the device.

Note:  If you are upgrading from a single NIC configuration on an older version of BIG-IQ (for example: BIG-IQ 7.x) to BIG-IQ 8.0.0/8.1.0, then please note that such an upgrade is not supported. For more information, refer to K71442235: BIG-IQ upgrade of single NIC to version 8.0 results in network communication failures.

Cause

This is caused by ID 1033765. The problem occurs when there is a single NIC during installation of device.  The issue can be mitigated by following the steps in the Recommended Actions section of this article.

Recommended Actions

The workaround process involves temporarily adding an additional NIC before installation and updating the database after installation.

  1. Perform a clean installation of BIG-IQ 8.0.0/8.1.0 ensuring there are two NICs in the installation.

    Note: Do not perform an upgrade.
    Note: For more information on clean installation, refer to K13117: Performing a clean installation of BIG-IP 11.x - 16.x.

  2. After the device boots up the first time following installation, before you run setup wizard, launch a command prompt and perform the following steps:
    1. Confirm that the getdb provision.1nic command prints disable. If this command prints enable then above steps have not been performed correctly.
    2. Confirm that the cat /HWINFO command does not print variant=1nic. If it does print variant=1nic then above steps have not been performed correctly.
    3. Run setdb provision.1nic forced_disable.
    4. Confirm that the getdb provision.1nic command prints forced_disable.
  3. Remove the unused NIC by performing the following steps:
    1. Power off the device.
    2. Remove additional NICs and keep your original single NIC.
      Note: Before booting, you could consider making this virtual unit a template for future single-NIC virtual units.
    3. Power on the device.
    4. Confirm that the getdb provision.1nic command still prints forced_disable.
At this point your BIG-IQ device is ready for operation in single-nic mode and any additional configuration you need. See the ‘Additional Information’ section of article to configure BIG-IQ as you normally would.
