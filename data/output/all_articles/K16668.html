Known Issue

A BIG-IP system upgrade may fail with ambiguous error message.

This issue occurs when the following condition is met:

  • You attempt to upgrade BIG-IP software when the root file system is full.

Impact

You are unable to proceed with software upgrade process.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You may observe the following tmsh show /sys software status command output, which displays that the installation failed:

    --------------------------------------------------------------------------------------------------------------
    Sys::Software Status
    Volume  Product  Version   Build  Active                                                 Status
    --------------------------------------------------------------------------------------------------------------
    HD1.1    BIG-IP   11.4.0  2384.0     yes                                                complete
    HD1.2    BIG-IP   11.4.1   608.0      no  failed (create_ucs failed; No such file or directory)

  • The BIG-IP system logs an error message to the /var/log/liveinstall.log file that may appear similar to the following example:

    .
    Terminal error: create_ucs failed; No such file or directory
    .

Note: The /var/log/liveinstall.log file always contains the full log of the installation once the installation is complete.

Resolution

Status

Workaround

To work around this issue, you can free up additional space on the full partition(s).

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
