Topic

To disable RADIUS authentication and enable local authentication, perform the following procedure

Note: This article is intended for administrators so they can disable RADIUS authentication and revert the users to local authentication if an issue has occurred with the RADIUS server, which is preventing users from logging in to the Configuration utility. For information about configuring or disabling RADIUS authentication using the Configuration utility, refer to the Managing remote user accounts section in the BIG-IP Network and System Management Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

  1. Log in to the command line.
  2. Enable local authentication by typing the following command:

    BIG-IP 9.4.2 - 10.x:

    bigpipe db SystemAuth.source local

    BIG-IP 9.0 - 9.4.1:

    /usr/bin/tw_activate_keys SystemAuth.source

  3. Remove the RADIUS configuration by typing the following command:

    bigpipe auth radius system-auth delete

  4. Save the configuration by typing the following command:

    bigpipe save

  5. In BIG-IP 9.0 - 9.4.2, change directories to the /config/bigip/auth/pam.d/ directory by typing the following command:

    cd /config/bigip/auth/pam.d/

  6. In BIG-IP 9.0 - 9.4.2, create a symbolic link to the /etc/pam.d/local/system-auth directory by typing the following command:

    ln -f -s /etc/pam.d/local/system-auth

The BIG-IP system will now use local authentication, and no longer use remote RADIUS authentication.

Removing the disabled RADIUS server

If you need to remove the disabled RADIUS server completely to reinstall the server or troubleshoot issues, perform the following steps, in addition to the first procedure:

  1. List the current RADIUS server by typing the following command:

    bigpipe radius server list

    The command output appears similar to the following example:

    radius server system_auth_name1 {   server "192.168.1.88"   secret "test"}radius server system_auth_name2 {   server "192.168.1.89"   secret "test"}
  2. For each RADIUS server listed in the output of step 1, remove the RADIUS server from the configuration by using the following command syntax, where <system_auth_name1> is the name of the RADIUS server listed in the output:

    bigpipe radius server <system_auth_name1> delete

  3. Save the configuration by typing the following command:

    bigpipe save
