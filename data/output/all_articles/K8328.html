Known Issue

This is the result of a known issue. The edit option is documented in certain bigpipe man pages; however, the edit option is not yet implemented in the product.

For example, the bigpipe syslog edit command is displayed in the bigpipe syslog man page, but the command returns the following error message:

BIGpipe parsing error:
01020005:3: The requested operation is not implemented yet.

F5 Networks Product Development tracked this issue as CR91841 and it was fixed in BIG-IP version 9.4.4. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, or WebAccelerator Release Notes.
