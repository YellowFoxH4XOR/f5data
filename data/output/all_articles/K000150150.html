K000150150: BIG-IP reset connection with "No local listener" reset cause for clients SYN

Type
Support Solution
Published
2025-03-07
Updated
2025-03-07
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.0, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000150150

Description

On newly configured/recently modified virtual server, during troubleshooting you observe reset after clients SYN with reset cause: [F5RST: No local listener]

Environment

  • BIG-IP LTM

Cause

Connection will be reset with reset cause "No local listener" while IP address, port and VLAN are correct, but clients IP address does not match "Source" in virtual server configuration.

Answer/Recommended Actions

Verify if clients IP address matches "Source" in virtual server configuration.

Additional Information

None
