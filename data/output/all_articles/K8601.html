Issue

Your FirePass license determines the total number of concurrent user sessions supported by your FirePass controller. If a user attempts to logon to the FirePass controller, and the licensed concurrent session limit is already reached, FirePass denies the logon attempt and reports an error message that appears similar to the following example:

The number of concurrent sessions exceeds the licensed limit!

For more information about concurrent session limits, including how to view the total number of concurrent user sessions included in your FirePass license, refer to K8597: Overview of concurrent session limits.
