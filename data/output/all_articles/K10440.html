Known Issue

This is the result of a known issue. HTTP requests preceded by one or more CR/LF characters may result in a corrupt HTTP header. If the BIG-IP system removes the value of the HTTP header or request line due to an overwrite caused by an incorrect length, TMM may crash.

F5 Product Development tracked this issue as CR124577 and it was fixed in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, or WOM release notes.

This issue was fixed in Hotfix-BIGIP-10.0.1-342.0-HF1 issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
