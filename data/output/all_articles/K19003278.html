K19003278: The Learn from responses setting cannot be disabled when a security policy has its Learning Mode setting changed to Manual

Type
Known Issue
Published
2017-05-02
Updated
2025-02-06
Applies to

  • BIG-IP ASM: 13.0.0
Source

Known Issue

You cannot disable the Learn from responses setting when a security policy has its Learning Mode setting changed to Manual.

This issue occurs when all of the following conditions are met:

  • The Learn from responses setting is enabled (checked) while the Learning Mode setting of the security policy is set to Automatic.
  • The Learning Mode setting of the security policy is subsequently changed to Manual.

You can find the Learn from responses setting under the Policy Building Process section on the Learning and Blocking Settings page (Security > Application Security > Policy Building > Learning and Blocking Settings).

Impact

You are unable to modify the Learn from responses setting.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM Configuration utility locks the Learn from responses setting after a security policy has changed its Learning Mode setting to Manual.

Workaround

To work around this issue, you can temporarily revert the Learning Mode setting of the affected security policy back to Automatic and then disable the Learn from responses setting before changing the Learning Mode setting to Manual again. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select the affected security policy from the Current edited security policy setting.
  4. For the Learning Mode setting, select Automatic.
  5. Under the Policy Building Process section, clear the Learn from responses box.
  6. For the Learning Mode setting, select Manual.
  7. Click Save.
  8. To effect the changes, click Apply Policy.
