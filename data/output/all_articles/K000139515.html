K000139515: Getting 403 forbidden error when updating NGINX Plus using 'apt-get update'

Type
Support Solution
Published
2024-05-06
Updated
2024-05-06
Applies to
  • NGINX Products
  • NGINX Plus: R35, R34, R33, R32
Source
https://my.f5.com/manage/s/article/K000139515

Description

  • You may encounter an error similar to the below when updating NGINX Plus using 'apt-get update': 
    Err:3 https://plus-pkgs.nginx.com/ubuntu focal InRelease
  403 Forbidden [IP: XX.XX.XX.XX 443]

Environment

  • NGINX Plus
  • Linux Ubuntu
  • Package Manager (e.g. apt update)

Cause

  • NGINX Plus repository's address changed

Recommended Actions

  • Replace the old repository address from 'https://plus-pkgs.nginx.com/ubuntu' to 'https://pkgs.nginx.com/plus/ubuntu' using the following command: 
    printf "deb [signed-by=/usr/share/keyrings/nginx-archive-keyring.gpg] https://pkgs.nginx.com/plus/ubuntu `lsb_release -cs` nginx-plus\n" | sudo tee /etc/apt/sources.list.d/nginx-plus.list
