K000136098: Can we disable the flow control option for rSeries machines?

Applies to

Source

Description

Can we disable flow control with F5OS-A to rSeries platform?

Environment

  • F5OS-A
  • rSeries platform

Cause

The option "Enable flow control" is enabled by default.

At the moment, there's no way to disable it.

Recommended Actions

F5Support suggests raising a Service Request, so that visibility over this can be increased.

Additional Information

None
