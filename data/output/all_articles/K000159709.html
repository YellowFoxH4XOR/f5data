Description

The Hybrid Flexible Consumption Program (HFCP) contract is renewing and the BIG-IP hardware relies on Feature Based Subscriptions. 

Environment

  • Hybrid Flexible Consumption Program (HFCP)
  • iSeries/rSeries
  • Viprion/VELOS
  • Feature Based Subscriptions (FBS)
    • Threat Campaign (TC), IP Intelligence (IPI), Intrusion Prevention System (IPS), Secure Web Gateway (SWG), Uniform Resource Locator (URL), Policy Enforcement Manager URL (PURL)
    • SSL Orchestrator (SSLO), Federal Information Processing Standards (FIPS)

Cause

Previously, time limited Feature Based Subscription (FBS) add-on keys needed to be replaced and reactivated every year, but now perpetual add-on keys for each FBS per BIG-IP hardware appliance are provided for the duration of the FCP contract.

Recommended Actions

Confirm which FBS add-on keys, time limited or perpetual, are applied to the BIG-IP hardware appliance.

  1. From the command line of the BIG-IP:
    1. Run tmsh show sys license | grep -i subscription
    2. Run grep -i 'timelimited' /config/bigip.license
  2. From the WebUI of the BIG-IP:
    1. Search System > License for the specific add-on key

If any result returns an expiration date or states timelimited, then contact customersupport@f5.com to request a perpetual FBS key. Include the subscription number and email contact.

Otherwise, existing perpetual FBS add-on keys are listed as "active module" and no further action is required. 

  • This key is entitled for the duration of the FCP contract.
  • Its activation date displays in Epoch format.
  • The "1Yr" or "3Yr" text is cosmetic. 

Additional Information

Determine when FCP add on subscription for hardware was activated
Use an EPOCH time converter to translate the activation date for the FBS add-on.
