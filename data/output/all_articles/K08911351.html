Known Issue

Auto-sync with save-on-sync may not save non-default partition configuration objects.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is licensed and provisioned with the BIG-IP DNS or GTM modules.
  • Your BIG-IP system is configured with partitions.
  • Your BIG-IP system is configured as part of a device group.
  • The device group is configured with automatic-sync and save-on-sync enabled.
  • You create BIG-IP DNS objects that reside in a non-default partition.

Impact

The BIG-IP DNS objects are automatically synchronized to peer devices; however, the configuration is not saved on the peer device.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view peer devices for the BIG-IP DNS objects, the Configuration utility and Traffic Management Shell (tmsh) display the objects.
  • When you view the partition configuration file bigip_gtm.conf, the synchronized BIG-IP DNS objects are not included in the configuration.
  • When you manually save the configuration, the running configuration populates the partition configuration file bigip_gtm.conf  with the synchronized DNS objects.

Workaround

To work around this issue, you can periodically, manually save the running device configuration. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility of the affected device by typing the following command:

    tmsh

  2. To save the running configuration of the device, type the following command:

    save /sys config partitions all

  3. To exit the tmsh utility, type the following command:

    quit
