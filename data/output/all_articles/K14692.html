Known Issue

BIG-IP systems using copper CuSFP modules fail to auto-negotiate to 10/100 speeds.

This issue occurs when the following conditions are met:

  • The interface using the CuSFP module is configured to use the auto-negotiate media speed.
  • The CuSFP module is is installed in one of the following platforms:

    • 1600,3600, 3900, 6900, 8900, 8950, 10200v, 11000, or 11050
    • VIPRION 2400 with the B2100 blade
    • VIPRION 4400 with the following blades B4100 (PB100), B4200 (PB200), B4300 (PB300)

Impact

The CuSFP interfaces will not initialize and will not have network connectivity.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The CuSFP interface fails to initialize and will not have network connectivity.
  • The tmsh show net interface command lists the interface as down.
