Known Issue

A pool containing a node within a route domain is not displayed in the network map.

This issue occurs when the following condition is met:

  • One or more pool members are configured as containing a node that is within a route domain.

Impact

A broken link occurs in the network map.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • In the network map, when you click a route domain pool member, you observe an error message similar to the following example:

    Instance not found
