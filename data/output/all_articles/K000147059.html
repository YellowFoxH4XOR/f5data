What Happened?

I want to understand how HTTP headers and pseudo headers work and what changes (if any), I can see in the headers when I pass an HTTP2 or 1/1 request to the origin through F5® Distributed Cloud's HTTP Load Balancers

Environment

  • F5® Distributed Cloud (XC) HTTP Load Balancer

Resolution/Answer

The answer depends on the configuration of the HTTP Load Balancer. Here are the examples:

  1. "Client -> (HTTP/2) -> XC LB -> (HTTP/2) -> Origin". In this case our Load Balancer is http2, same as client so it will send ":authority" pseudo-header
  2. "Client -> (HTTP/2) -> XC LB -> (HTTP/1.1) -> Origin". In this case our Load Balancer will send the "host:" header.

Additional Information

You can find this option under the Origin Pool configuration > Other Settings > Miscellaneous Options > HTTP Protocol Configuration
