DESCRIPTION

When adding SSLo devices in L2 topologies to the BIG-IQ the second device fails to be added and throws the below error in the GUI (Configuration Utility):

[ERROR][22 Oct 2020 12:22:22][/cm/sslo/tasks/discover-config/0d050a6c-2da8-497e-9054-637870327a70/worker SsloDiscoveryTaskWorker] Duplicate names  sslo_bbtest, ssloT_flexatsup, sslo_flexatuat, sslo_L2_TCP, ssloP_L2_UDP, ssloT_flexatuat, sslo_L2_TCP_IPv6, ssloN_Arbor_IN, ssloN_Arbor_OUT, ssloP_bbtest, ssloP_flexatuat, ssloT_L2_TCP, ssloP_L2_TCP, ssloP_flexatsup, ssloS_Arbor_DDOS, sslo_portaluat, ssloT_portaluat, ssloT_L2_TCP_IPv6, sslo_flexatsup, ssloP_portaluat, ssloT_bbtest, ssloP_L2_TCP_IPv6, sslo_L2_UDP  detected between the BIG-IP device and BIG-IQ, please delete them on either side, then discover again.

ENVIRONMENT

  • BIG-IQ 7.1.x
  • SSL Orchestrator (L2 Topologies)

CAUSE

Bug ID 963993 BIG IQ: Unable to discover additional SSLO devices to BIQ

RECOMMENDED ACTIONS

Upgrade to 7.1.0.3
