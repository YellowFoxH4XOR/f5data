Known Issue

The BIG-IP APM rewrite engine may malfunction when processing HTTP headers.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • Response traffic from back-end servers contains large HTTP headers.

Impact

The BIG-IP APM rewrite engine may incorrectly write HTTP headers causing web applications to malfunction, or may fail unexpectedly preventing access to resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • HTTP headers are malformed when sent to the client.
  • The web application malfunctions, or fails to render properly.
  • The BIG-IP APM rewrite process exits and generates a core file to the /shared/core directory.
  • Users are temporarily unable to connect to portal access resources through the BIG-IP APM system.
