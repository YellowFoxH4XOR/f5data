K000149395: Request not visible in Event Logs

Type
Support Solution
Published
2025-01-21
Updated
2025-01-21
Applies to
  • BIG-IP
  • BIG-IP ASM: 16.X.X, 17.X.X, 17.1.X, 17.1.2, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.5, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.X, 16.0.1, 16.0.0
Source
https://my.f5.com/manage/s/article/K000149395

Description

  • In Security ›› Event Logs : Application : Requests, few or no event logs are shown.
  • Relevant event logs are only shown when log filters are keyed in.
  • GUI Message is shown after the log search: "This request is not shown in the list because it was marked for delete"

Environment

  • ASM module is enabled.
  • Logging profile is configured in Virtual Servers.

Cause

This is caused due to the request being manually deleted or deleted by the system for being outdated.

Recommended Actions

  1. Search for the request by Support ID

If it is not found, and not stored on a remote logging system, then the request is most likely lost.

Additional Information

None.
