Topic

You should consider using this procedure under the following condition:

  • You need to license the F5 iWorkflow system.

Description

Before you can configure and use the iWorkflow system, you must activate a valid license on the system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Before you can activate the license for the iWorkflow system, you must obtain a base registration key. The base registration key is a 23-character string that indicates to the license server what F5 products you can license. The base registration key is pre-installed on new iWorkflow systems. When you connect to the user interface, the Licensing screen opens and displays the registration key.

    If you do not have a base registration key, contact your F5 Sales representative or F5 Technical Support.

    The format of the iWorkflow base registration key is as follows:

    ABCD-ABCD-ABCD-ABCD-ABCDEFG

  • The F5 license server requires a dossier to create a license for the iWorkflow system. The dossier is an encrypted list of key characteristics used to identify the platform.

    Your F5 product generates the dossier after you choose a license activation method. When choosing the Automatic activation method, the system automatically generates the dossier and submits it to the F5 license server. When choosing the Manual activation method, the system generates and displays the dossier so you can copy it and manually submit it to the F5 license server.

  • Access to the F5 license server

    The automatic activation method requires that the iWorkflow system has Internet access to automatically access the F5 license server.

    The manual activation method requires that you have Internet access from a management workstation. This is the workstation that you use to access the user interface and generate the dossier. However, if required, you can transfer the dossier to an independent system that has Internet access.

Procedures

To activate the license on the iWorkflow system using the user interface, you can use either the automatic activation method or the manual activation method. The activation method specifies the method by which you want the system to communicate with the F5 license server.

Activating the license using the automatic activation method

You can use the automatic method if the iWorkflow system's management port is configured to route traffic to the Internet to access the F5 license server. If the iWorkflow system's management port is not configured to route traffic to the Internet, use the manual method.

To activate the license on the iWorkflow system using the automatic activation method, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the iWorkflow user interface with administrator role access credentials.
  2. Navigate the menu according to the version in use: 
    • For iWorkflow 2.0.1 and later, navigate to System Settings.
    • For iWorkflow 2.0.0, navigate to System > Configuration.
  3. Under the iWorkflow Cluster panel, double-click the entry for localhost.
  4. Click the Licensing tab.
  5. Click Reactivate.
  6. In the Base Registration Key box, enter the base registration key.
  7. In the Add-On Keys box, enter the add-on registration keys for additional modules.

    Optional: To add an additional add-on key, click the plus (+) symbol to get another Add-on Keys box.

  8. For the Activation Method, select Automatic.
  9. Click Activate.
  10. The iWorkflow system automatically connects to the F5 license server and activates the license.

Activating the license using the manual activation method

To activate the license on the iWorkflow system using the manual activation method, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the iWorkflow user interface with administrator role access credentials.
  2. Navigate according to the version in use: 
    • For iWorkflow 2.0.1 and later, navigate to System Settings.
    • For iWorkflow 2.0.0, navigate to System > Configuration.
  3. Under the iWorkflow Cluster panel, double-click the entry for localhost.
  4. Click the Licensing tab.
  5. Click Reactivate.
  6. In the Base Registration Key box, enter the base registration key.
  7. In the Add-On Keys box, enter the add-on registration keys for additional modules.

    Optional: To add an additional add-on key, click the plus (+) symbol to get another Add-on Keys box.

  8. For the Activation Method, select Manual.
  9. On Device Dossier, click Get Dossier.
  10. Copy the Device Dossier text.
  11. Connect to the F5 Product Licensing page at the following address:

    https://secure.f5.com

  12. On the F5 Product Licensing page, in the row that lists iWorkflow, click Activate F5 product registration key.
  13. Paste the dossier into the Enter your dossier box, and click Next.
  14. Copy the license returned by the F5 Product Licensing page, and paste it into the License Text box in the iWorkflow system.
  15. Click Activate.

Activating an add-on module

For additional functionality, you can add iWorkflow feature modules to the iWorkflow system. To add a feature module, you must obtain an add-on registration key and reactivate the license. After you have obtained an add-on registration key, you can activate the feature using the iWorkflow user interface.

The format of the iWorkflow add-on registration key is as follows:

ABCDEFG-ABCDEFG

To use the manual activation method to reactivate the license with the add-on registration, perform the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the iWorkflow user interface with administrator role access credentials.
  2. Navigate according to the version in use: 
    • For iWorkflow 2.0.1 and later, navigate to System Settings.
    • For iWorkflow 2.0.0, navigate to System > Configuration.
  3. Under the iWorkflow Cluster panel, double-click the entry for localhost.
  4. Click the Licensing tab.
  5. Click Reactivate.
  6. In the Add-On Keys box, enter the add-on registration key.

    Optional: To add an additional add-on key, click the plus (+) symbol to get another Add-on Keys box.

  7. Click Manual.
  8. On Device Dossier, click Get Dossier.
  9. Copy the Device Dossier text.
  10. Connect to the F5 Product Licensing page at the following address:

    https://secure.f5.com

  11. On the F5 Product Licensing page, in the row that lists iWorkflow, click Activate F5 product registration key.
  12. Paste the dossier into the Enter your dossier box, and click Next.
  13. Copy the license returned by the F5 Product Licensing page and paste it into the License Text box in the iWorkflow system.
  14. Click Activate.
