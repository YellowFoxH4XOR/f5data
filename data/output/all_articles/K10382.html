Known Issue

This is the result of a known issue. When configuring a data group list of the type String, the Configuration utility allows you to create a data group list member consisting of a string containing double quote ( " ) characters. However, when you add or update the data group through the Configuration utility, existing string entries containing double quotation marks are truncated after the first embedded double quote, and only the portion preceding the first double quote is saved in the updated configuration.

For example, a data group named QuotedStrings that contains the following string is created through the Configuration utility:

ab"c

This string results in the following configuration:

class QuotedStrings {
   {
      "ab\"c"
   }
}

However, using the Configuration utility to add a new data group list entry of "ddd" to the list results in the following class configuration in which the original entry has been truncated after the first double quote:

class QuotedStrings {
   {
      "ab"
     "ddd"
   }
}

F5 Product Development tracked this issue as ID249345 (formerly CR124554), and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, or WebAccelerator release notes.

Workaround

You can work around this issue by avoiding updates to the data group list using the Configuration utility. To do so, enter the bigpipe class command to manage the data group:

For example:

  • To add an entry containing the string abc, type the following command:

    bigpipe class mystrings \"abc\" add    
  • To delete an entry containing the string abc, type the following command:

    bigpipe class mystrings \"abc\" delete
  • To add an entry containing the string d"e"f, type the following command:

    bigpipe class mystrings \"d\"e\"f\" add

After modifying the class using the bigpipe class command, save the configuration by typing the following command:

bigpipe save
