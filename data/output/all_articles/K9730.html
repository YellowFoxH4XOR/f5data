Known Issue

This is the result of a known issue. If a user connects to a Virtual Network Client (VNC) Terminal Server favorite, the favorite may disconnect after 3 to 4 minutes, even if the user was actively working in the VNC session. When this issue occurs, an error message that appears similar to the following example displays to the user:

Couldn't connect to terminal server VNC.
 
Users can resume their original VNC session by reconnecting to the VNC Terminal Server favorite.
 
F5 Product Development tracked this issue as ID 296107 (formerly CR102305) and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.
 
Additionally, this issue was fixed in cumulative hotfix HF-603-1 issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
 
For a list of current hotfixes, refer to K10322: FirePass Hotfix Matrix.
 
For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.
 
For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
 
Workaround
 
You can work around this issue by setting the Screen resolution option to Full Screen for the VNC Terminal Server favorite. To do so, perform the following procedure:
 
  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Application Access: Terminal Servers: Resources page.
  3. In the Resource Group menu, select the name of the resource group you want to configure.
  4. Select the name of the Terminal Server favorite you want to configure.
  5. In the Screen resolution menu, select Full Screen.
  6. Click the Update button.
