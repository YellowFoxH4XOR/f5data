Description
A SAML request returns Status 502.

Environment

  • Using a BIG-IP system with APM as a SAML endpoint

Cause
The browser has made a request which is incorrect for the URI, such as making a GET request to a POST  URI.
APM cannot process this in any way. It doesn't proceed far enough to be logged.

Recommended Actions

  1. Your configuration is incorrect and must be fixed.

The SAML endpoints used by APM for Logout are described here
