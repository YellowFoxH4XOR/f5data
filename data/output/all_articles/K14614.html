Known Issue

Installation of uploaded EPSEC OPSWAT updates may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured as part of a Device Group.
  • You used the Configuration utility to upload an EPSEC OPSWAT ISO.
  • You attempt to install the uploaded EPSEC OPSWAT ISO to a Device Group.

Impact

The installation of the EPSEC ISO to the Device Group fails.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H427510 on the Diagnostics > Identified > High screen.
  • When you attempt to install the EPSEC ISO to the Device Group, the installation fails with an error message similar to the following example:

    *** Upload Failed:
    got throwablejava.lang.Exception File /Common/EPSEC/Upload/epsec-1.0.0-236.0.iso not found!

  • You find the following error message in /var/log/ltm*:

    err mcpd[6182]: 01070734:3: Configuration error: Can't associate (/Common/EPSEC/Images/epsec-1.0.0-236.0.iso) with folder (/Common/EPSEC/Images) folder does not exist

  • The system does not update the EPSEC OPSWAT libraries when you attempt to install the uploaded OPSWAT ISO file.

Workaround

To work around this issue, you can use the tmsh utility to create the required directory, and then use the Configuration utility to attempt to upload and install EPSEC ISO again. To do so, perform the following procedure:

Creating the EPSEC upload directory with tmsh

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Create the directory images in the /Common/EPSEC directory by typing the following command:

    create /sys folder /Common/EPSEC/Images

  3. To view the newly-created directory, type the following command:

    list /sys folder /Common/EPSEC/Images

Uploading the EPSEC AV update ISO from the Configuration utility

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

After you create the required directory, you should re-upload the OPSWAT update ISO to the BIG-IP APM system and install the update to the Device Group.

  1. Log in to the Configuration utility.
  2. Navigate to System > Software Management > Antivirus Check Updates.
  3. Click Upload Package.
  4. Click Browse and select the EPSEC update ISO from the local drive.
  5. Select the appropriate Install Option for your configuration.
  6. Select the appropriate Device Group for your configuration.
  7. Click Upload.
