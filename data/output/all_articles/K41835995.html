Known Issue

Creating a user configuration set (UCS) archive may fail due to a missing patch file in the /config/.diffVersions directory.

This issue occurs when all of the following conditions are met:

  • You attempt to create a UCS archive file using the TMOS Shell (tmsh). For example, by using the following command syntax:

    • tmsh save sys ucs example.ucs

  • During the UCS creation process, a background process tmsh save sys config, runs at the same time.

During the UCS creation process, when the background process tmsh save sys config runs, it can cause the system to delete a patch file in the /config/.diffVersions directory. When the UCS creation process is unable to find the missing patch file, the process fails and exits with an error.

Impact

You are unable to create a UCS archive file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When attempting to create a UCS file, the command output mentions that a patch file does not exist. The output appears similar the following example

    # tmsh save sys ucs example.ucs
    Saving active configuration...
    /config/.diffVersions/config/BigDB.dat/<patch number>.patch: (at /config/.diffVersions/config/BigDB.dat/<patch number>.patch) does not exist
    /config/.diffVersions/config/bigip_base.conf/<patch number>.patch: (at /config/.diffVersions/config/bigip_base.conf/<patch number>.patch) does not exist

Workaround

To work around this issue, you can run the same UCS creation command again. You can ignore the error message because the missing patch file is not required. To run the UCS creation command again, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Use the following command syntax:

    tmsh save sys ucs example.ucs
