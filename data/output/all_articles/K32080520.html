Description

Topic

Beginning in BIG-IP 16.1.0, F5 SSL Orchestrator and SSL Forward Proxy add support for HTTP/2 with the TLS Application-Layer Protocol Negotiation (ALPN) extension.

Description

Prior to BIG-IP 16.1.0, F5 SSL Orchestrator and the SSL Forward Proxy feature do not support HTTP/2 with the TLS Application-Layer Protocol Negotiation (ALPN) extension. The SSL Orchestrator and the SSL Forward Proxy feature fall back to HTTP 1.1 when they are configured to intercept HTTP/2 traffic. As a result, HTTP/2 clients may experience performance issues when SSL Orchestrator or the SSL Forward Proxy is deployed to proxy HTTP/2 connections to a HTTP/2 backend server. To enable TLS ALPN to proxy the ALPN extension to support protocols like HTTP/2, refer to the following sections:

  • Enable ALPN extension in BIG-IP 16.1.0 SSL Forward Proxy
    • Enable ALPN extension in the Client SSL profile
    • Use an iRule to disable the HTTP profile
  • Enable ALPN extension in BIG-IP 16.1.0 F5 SSL Orchestrator
Enable ALPN in BIG-IP 16.1.0 SSL Forward Proxy

Beginning in BIG-IP 16.1.0, for deployments using SSL Forward Proxy, to use HTTP/2 with the TLS ALPN extension, perform the following procedures:

Enable ALPN extension in the Client SSL profile
Perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client.
  3. Select your Client SSL Profile.
  4. Under SSL Forward Proxy, for Verified Handshake, select Enabled.
  5. For Hello Extensions, select Extensions List
  6. Select Application-Layer Protocol Negotiation.
  7. Select Enable.
  8. Select Update.
Use an iRule to disable the HTTP profile

You must disable the HTTP profile if the client traffic is HTTP/2 and the ALPN extension is enabled. To do so, you can configure an iRule similar to the following example and associate it to the Forward Proxy virtual server:

Note: The example iRule may not apply to all environments. F5 recommends you author an iRule that works best for your application environment. Additionally, adding an iRule increases the resources used by the associated virtual server. Depending on the type and volume of the connections, this processing may introduce noticeable latency. F5 recommends testing any such changes in an appropriate environment.

when SERVERSSL_SERVERHELLO {
    if { !([SSL::alpn] starts_with "http")} {
         HTTP::disable
    }
}

This iRule disables any HTTP profile associated with the affected virtual server and proxies the ALPN extension received from the client to be forwarded to the backend server. To use this workaround, you must also enable the Verified Handshake setting on the SSL profiles associated with the affected virtual server.

Enable ALPN in BIG-IP 16.1.0 F5 SSL Orchestrator

Beginning in BIG-IP 16.1.0, F5 SSL Orchestrator added support for HTTP/2 with the TLS Application-Layer Protocol Negotiation (ALPN) extension. To enable ALPN extension, you configure your deployment through SSLO Guided Configuration, GC. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Access > Guided Configuration.
  3. Select the name of your SSLO deployment.
  4. Select SSL Configuration at the top row.
  5. For ALPN, select the Proxy ALPN check box.
  6. Select Save & Next.
  7. Select Deploy.
