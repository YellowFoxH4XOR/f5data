Known Issue

The Traffic Management Microkernel (TMM) may not be ready after a system start or restart if a route domain configured with a Bandwidth Control (BWC) policy exists.

This issue occurs when all of the following conditions are met:

  • You have configured a route domain to use a static BWC policy.
  • You have configured the system to use a Web Acceleration profile.
  • You have restarted or rebooted the system.

Impact

The affected TMMs fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H664205 on the Diagnostics > Identified > Low screen.
  • The affected TMM fails to process traffic.
  • The tmsh show sys ha-status all-properties command indicates a Fail status of yes for the ready-for-world feature, similar to the following example:

Workaround

To work around this issue, you can temporarily remove the BWC policy from the route domain configuration and then reapply the BWC policy to the route domain. To do so, perform the following procedure:

Impact of workaround: The suggested workaround is only temporary, and if you restart or reboot the system, you need to perform the procedure again.

  1. Log in to the Configuration utility.
  2. Click Network.
  3. Click Route Domains.
  4. Click the name of the affected route domain.
  5. From the menu for the Bandwidth Controller option, select None.
  6. Click Update.
  7. From the menu for the Bandwidth Controller option, select the desired BWC policy name.
  8. Click Update.

Repeat this procedure for each affected route domain.
