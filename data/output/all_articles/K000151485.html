K000151485: The DoS Device vector TCP BADACK Flood(Flood) does not support auto configure threshold.

Description

When importing configuration from an F5 AFM device into BIG-IQ, the following error may occur:

Failed to copy configuration to working-config; reason: Failed copying from source to target: java.lang.IllegalArgumentException: The DoS Device vector TCP BADACK Flood(Flood) does not support auto configure threshold.

This issue can prevent successful discovery or import of AFM configurations related to DoS vectors.

Environment

  • BIG-IQ version 8.3.0
  • BIG-IP AFM version 17.x

Cause

The "TCP BADACK Flood" vector has been deprecated in AFM version 17.x and replaced by "TCP ACK Flood" However, BIG-IQ may still reference the deprecated vector internally. If the "TCP ACK Flood" vector is set to "fully-automatic" threshold mode, BIG-IQ may fail to import the configuration due to this mismatch and outdated reference.

Recommended Actions

Change the threshold mode for the "TCP ACK Flood" vector from "fully-automatic" to "manual" in the Device Protection settings on the AFM device, commit the configuration change and then re-discover and re-import the AFM device configuration in BIG-IQ.
