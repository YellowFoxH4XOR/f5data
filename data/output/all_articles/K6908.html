Known Issue

This is the result of a known issue. The BIG-IP LTM process, eventd, responds slowly to subscription messages from the mcpd process. If the BIG-IP LTM system has a large configuration and the configuration is repeatedly loaded by running the bigpipe load command, for example, the mcpd process will leak memory.

If this issue occurs, the system logs a message to the /var/log/ltm file that appears similar to the following example:

bigip mcpd[1924]: The size of the configuration DB has been extended by <number of bytes> bytes

F5 Product Development tracked this issue as CR72137, CR72136, and CR71138 and it was fixed in BIG-IP versions 9.1.3, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.
