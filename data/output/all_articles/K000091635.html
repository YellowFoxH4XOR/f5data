K000091635: BIG-IP will not sync after configuration load failure

Type
Support Solution
Published
2022-06-23
Updated
2022-06-23
Source
https://my.f5.com/manage/s/article/K000091635

Description

HA sync failure after configuration load failure. Error may be present:

01070710:3: Error loading object from cursor, status:60 - cave/lib/EdbDataIterator.h

 

 

 Environment

  • BIG-IP APM
  • High Availability

 Cause

Bad configuration state from APM policy with macro(s)

 Recommended Actions

  1. backup errant configuration (mv bigip.conf bigip.conf.old)
  2. forceload mcpd ( K13030: Forcing the mcpd process to reload the BIG-IP configuration )
  3. full load from peer device:

﻿#tmsh run cm config-sync to-group force-full-load-push

 Additional Information

None
