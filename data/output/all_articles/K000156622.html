Description

Is it possible to populate a GSLB pool using a FQDN (fully qualified domain name)?

 

Environment

BIG-IP DNS using GSLB pools

 

Cause

N/A

 

Recommended Actions

No, this is not possible. GSLB pool members are virtual server(s) attached to specific DNS server(s) as such there is no way to use an FQDN to populate the list.
