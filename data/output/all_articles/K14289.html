Known Issue

Changes made to base profiles are not synchronized to other hosts in a device group.

Impact

Virtual servers using modified base profiles may show inconsistent behavior across hosts in a device group.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • After making a modification to a base profile, the BIG-IP system continues to show the Sync Status as In Sync.
  • Changes made to a base profile are not synchronized to other hosts in the device group after performing a successful configuration synchronization (ConfigSync).

Resolution

Status

F5 Product Development has assigned ID 404134 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the top right corner of the article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

F5 recommends that you do not modify base profiles. To work around this issue, you can perform the following:

  • Restore the base profile to its default settings
  • Create a new custom profile using the base profile as a parent
  • Associate the new profile with your virtual servers

Note: For more information about how to perform these steps, refer to the Profile Concepts chapter of the BIG-IP Local Traffic Manager: Concepts guide. For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.
