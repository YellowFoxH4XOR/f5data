Description

When using Terraform to deploy LTM configuration, the following AS3 message error is seen:

   {"code":401,"message":"Authorization failed: no user authentication header or token detected}

Environment

  • BIG-IP LTM
  • AS3
  • Terraform

Cause

The following Known Issues may result in the error message described in the Description section:

  • ID 1025513
  • ID 1035661

Recommended Actions

  • Review the workarounds in ID 1025513 and ID 1035661
  • Restart the "restnoded" and "restjavad" processes. 

 

     - The restnoded process provides control-plane access to the BIG-IP using an HTTP REST API.
     - The restjavad process provides control-plane access to the BIG-IP system using an HTTP REST API.

The procedure to do this is:

  1. Log in to the BIG-IP command line.
  2. Run the following two commands:
       # bigstart restart restjavad
       # bigstart restart restnoded

       3. Verify the status of the process:
       # bigstart status <service name>
