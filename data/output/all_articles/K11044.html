Important: The information in this Solution applies to Windows XP, Windows 2000, and earlier versions of Windows. Windows Vista and Windows 7 use a new TCP/IP stack, which auto-senses and auto-tunes various network parameters. For more information about the new TCP/IP stack, refer to the following Microsoft TechNet article:

http://technet.microsoft.com/en-au/library/bb878108.aspx.

The FirePass Displayed bandwidth setting is located on the Network Access: Resources page under the Customization tab. You can configure the value of Displayed bandwidth in bits per second, and it is used for reporting the SSL VPN Network Access connection media speed to Windows. Windows displays this value as the connection speed for the SSL VPN network adapter, and Windows also uses it to set the maximum TCP window size advertised over the Network Access connection. In certain instances, such as for high-bandwidth or high-latency WAN links, this window size may adversely affect performance.

Note: The connection speed displayed by Windows does not reflect the actual bandwidth between the FirePass controller and the client. For example, if you set the Displayed bandwidth setting to 5767168, Windows will report the connection speed as 5.7 Mbps even if the remote client connects to the Internet using a 1.5 Mbps DSL connection.

The following table displays the maximum TCP window sizes used by Windows according to the value configured for the Displayed bandwidth setting:

Displayed BandwidthMaximum TCP window size
1 to 99999 (under 100 Kbps)8 KB
100000 to 99999999  (100 Kbps to 99 Mbps)16 KB
100000000+ (100 Mbps and above)64 KB

Note: The Network Access : Resources : Customization page of the FirePass online help incorrectly lists the maximum TCP window sizes associated with the Displayed bandwidth setting. For more information, refer to SOL11136: Documentation errata: The maximum TCP window sizes for the Displayed bandwidth setting are incorrect.
