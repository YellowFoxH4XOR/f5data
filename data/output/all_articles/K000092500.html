Description
When troubleshooting an issue related to LTM or Portal Access in APM, we might require to disable HTTP/2 in Chrome in order to force Chrome to use only HTTP/1.1
Environment

  • BIG-IP LTM Virtual Server
  • BIG-IP APM Portal Access

Cause
N/A
Recommended Actions

  1. Right click on the Start Menu in Windows and select Run:
    chrome.exe --disable-http2
  2. The previous command will force Chrome to not use HTTP/2, you will need to clear cache and close the browser before doing this procedure.

Additional Information

To disable HTTP/2 in Chrome on MacOS, perform the following:

  1. Close Chrome completely (Cmd + Q).
  2. Open Terminal (Cmd + Space, type "Terminal").
  3. Copy and paste the following command in the Terminal:
    /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --disable-http2

Note that the latest versions of Chrome may not support the --disable-http2 anymore. Depending on your use case, you may consider using the curl command. For example:

curl -I --http1.1 https://example.com
