Topic

Starting in FirePass version 6.0.2, you can use Client Certificate Two-Factor Authentication with the FirePass Windows Logon Integration component. Client Certificate Two-Factor Authentication is an authentication scheme that allows you to use client certificates to authenticate end-users in addition to a primary authentication method, such as Active Directory or RADIUS. The FirePass Windows Logon Integration component allows users to establish a FirePass VPN connection when they logon to their Windows systems without modifying Microsoft GINA components.

Note: The Client Certificate Two-Factor Authentication option will not appear under a Master Group’s Authentication tab until you install a Client Root Certificate on the Device Management: Security: Certificates page.

When users import client certificates for use with Windows Logon Integration, they must import the certificates into the Local Computer certificate store in addition to the Current User certificate store. The FirePass Windows Logon Integration component cannot access the Current User certificate store prior to user logon. In order to authenticate a user prior to logon (at the Windows logon screen), the FirePass Windows Logon Integration component must retrieve the user’s client certificate from the Local Computer certificate store.

Note: Importing a certificate into the Local Computer certificate store may require administrator privileges on the Windows system.

You can use the Microsoft Management Console (MMC) with the Certificates snap-in to import certificates into the Current User and Local Computer certificate stores. You can open the MMC by running the mmc.exe command from the Windows command prompt. For more information about using the MMC to import and manage certificates, refer to your Microsoft Windows system documentation.

Note: For more information about configuring Client Certificate Two-Factor Authentication, refer to the FirePass Controller Administrator Guide. For more information about configuring Windows Logon Integration, refer to K8092: Configuring Windows Logon Integration.
