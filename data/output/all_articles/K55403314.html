Description

Customer will sometimes confuse attack signature accuracy and attack signature set accuracy, however they are totally different.
Accuracy indicates the ability of the attack signature to identify the attack including susceptibility to false-positive alarms:

  • Low: Indicates a high likelihood of false positives.
  • Medium: Indicates some likelihood of false positives.
  • High: Indicates a low likelihood of false positives.

However, for attack signature set, the definition for accuracy is listed as below:

  • Low Accuracy Signatures set

Signature Set Properties: Accuracy "Greater Than/Equal To Low"

  • Medium Accuracy Signatures set

Signature Set Properties: Accuracy "Greater Than/Equal To Medium"

  • High Accuracy Signatures set

Signature Set Properties: Accuracy "Greater Than/Equal To High"

Environment

  • BIG-IP ASM
  • Attack Signature

Cause

None

Recommended Actions

This means low accuracy signature set will include low, medium and high accuracy signature IDs, and medium accuracy set will include medium and high accuracy signature IDs, and high accuracy signature set will only include high accuracy signature IDs. They are in a relation of inclusion.
This is by design and customers need to fully understand the two concepts and don't confuse them.
