Description

When executing gtm_add the command fails with an error message similar to the following logged /var/log/gtm:

err iqsyncer[21472]: 011ae104:3: Gtm config sync result from local mcpd: result {    result_code 17237778    result_message "01070712:3: Values (/Common/external_monitor_script) specified for external monitor parameter (/Common/external_monitor 2 RUN_I=): foreign key index (to_file) do not point at an item that exists in the database." }

Note: This error message is stating that the external monitor object can not be found.

 

Environment

  • BIG-IP DNS
  • gtm_add
  • External monitor

Cause

External monitor objects are defined in /config/bigip.conf and are not synchronised using gtm_add

Example /config/bigip_gtm.conf external monitor configuration:

gtm monitor external /Common/test_ex {
defaults-from /Common/external
destination *:*
interval 4
probe-timeout 1
run /Common/test_ex
timeout 16
}

Example /config/bigip.conf external monitor reference: 

sys file external-monitor /Common/test_ex {
cache-path /config/filestore/files_d/Common_d/external_monitor_d/:Common:test_ex_xxxxx_x
revision 1
}

 

Recommended Actions

Configure an LTM device group to sync local files between the GTMs or remove the external monitor before rerunning the gtm_add command. 

 

Additional Information

Partitions are also not synchronised by gtm_add, so if the source BIG-IP DNS has multiple partitions configured, you must configure these on the destination BIG-IP DNS before using gtm_add.
