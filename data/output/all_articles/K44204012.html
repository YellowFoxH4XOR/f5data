Description

When viewing the statistics collected on a virtual server with analytics profile attached, (Analytics_Source_IP), you notice it is only collecting a few client source IPs. However, the number of statistics seems inaccurate and less than expected compared to the amount of connections arriving to the Virtual server.

You can view this on: GUI > Statistics  > Analytics > TCP : Connections > Remote Host IP Addresses

Environment

  • Virtual Server with pva-acceleration enabled
  • Virtual Server with tcp-analytics profile attached

Cause

Bug ID 921997: Hardware-offloaded connections omitted from TCP statistics

Recommended Actions

There is no fix for this ID at the time of publication of this article. To workaround the issue on affected platforms you can disable PVA acceleration from the virtual server in question, and after this you should collect the statistics as normal.

Note: Before applying this workaround, you should consider if it could affect the performance of your virtual server and if you still want to benefit from the PVA acceleration feature.

To disable PVA acceleration from the Fast L4 profile attached to the Virtual Server:

  1. On the GUI, navigate to Local Traffic > Profiles : Protocol : Fast L4
  2. Select the Fast L4 profile attached to the affected virtual server
  3. Select the custom box next to PVA Acceleration
  4. Select None
