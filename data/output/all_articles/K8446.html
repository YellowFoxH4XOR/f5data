Known Issue

This is the result of a known issue. When you import a digital certificate into the FirePass controller to use as an SSL server certificate, if the expiration of the certificate (the valid to field of the certificate) is later than January 19, 2038, the expiration date will be displayed incorrectly during the import process and after. However, the certificate will function correctly with respect to its expiration date.

An SSL server certificate enables SSL/TLS-based communication between the FirePass controller and its remote access clients. The SSL server certificate contains a valid to field, which indicated the date and time that the certificate will expire. When a client root certificate with an expiration date beyond January 19, 2038 is installed by clicking on the Configure SSL Certificates >> link under the Web Services tab of the Device Management: Configuration: Network Configuration page, then clicking the Install Certificate button, the page that is displayed once the certificate is loaded will appear similar to the following example:

The date listed in the Expiration row will be incorrect. In the above example, the correct expiration year for the certificate is 2058.

When the certificate database is subsequently displayed, by clicking on the Configure SSL Certificates >> link under the Web Services tab of the Device Management: Configuration: Network Configuration page, another incorrect date will be displayed in the row for that certificate under the Expiration column.

For example:

Validcert1.pem, key1.pemwww.siteconfig.comca.siteconfig.com, US, CA, San Jose, F5 Networks, Inc10/13/2024

Additionally, if the incorrect date displayed is a date in the past, you may see a message above the certificate table, that appears similar to the following example:

The certificate that you entered is valid from Feb-19-2008 till Dec-31-1969 and it was expired or faked!

When displaying the certificate database, the certificate which generated the above message results in a Status of Fake, and the Expiration date is highlighted in red, as in the example below:
