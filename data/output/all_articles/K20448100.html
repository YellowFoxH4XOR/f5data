K20448100: RDP Connectivity Drop Intermittently

Type
Support Solution
Published
2020-12-02
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K20448100

Description
While you are connected to RDP, the connection drops intermittently. You are able to open a new RDP session but the drops come up again.

Environment

  • BIG-IP APM
  • RDP resources are ActiveX and Java based.
  • You upgraded from to version 13.x or above.
  • While you are connected to RDP, connection drops with no apparent reason

Cause

ActiveX and Java based RDP resources are not supported, this feature was removed in BIG-IP APM release 14.1.0.
Native RDP support was added in APM release 13.0.0.

Recommended Actions

Use Native RDP resources (Client Type - Native) instead.

Additional Information
Bug ID 721274: ActiveX and Java based RDP resources are not support
Bug ID 688651: ActiveX/Java based RDP resources are deprecated
