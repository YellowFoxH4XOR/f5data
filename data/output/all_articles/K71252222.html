K71252222: iRule with IPI reputation check request will drop traffic if unlicensed

Type
Support Solution
Published
2021-09-01
Updated
2025-02-06
Applies to
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K71252222

Description

If there is an iRule that would use IP Reputation Check, and IPI is either not licensed or wrongly licensed, the iRule will drop Virtual Server traffic.

This issue is accompanied by the following logs:

tmm3[21680]: 01220001:3: TCL error: /Common/IP_Reputation_Check <CLIENT_ACCEPTED> - IP Reputation database (/var/IpRep/F5IpRep.dat) not loaded (line 1)     invoked from within "IP::reputation $cip"

Environment

  • BIG-IP
  • iRule with IPI calls

Cause

Unlicensed or wrongly licensed IPI, will stop communication with the IPI database, so when the IP Reputation Check is triggered via the iRule, this will cause the iRule to drop the traffic.

Recommended Actions

  1. Review that the IPI module is properly licensed.
  2. The irule can be temporarily removed to allow traffic while the IPI license issue is resolved.

Additional Information

In order for the IPI module to work correctly, your license output, should look similar to this:

show /sys license detail

Sys::License
Licensed Version    <Version>
Registration Key    <Registration_Key>
Licensed on         <Date>
Service Check Date  <Date>
Platform ID         <Platform>

Active Modules
  APM, Limited
  App Tunnel
  Base Endpoint Security Checks
  Firewall Checks
  Local Traffic Manager, i2600
  Secure Virtual Keyboard
  timelimited module :               IP Intelligence, 1Yr, 3900/4XXX/i4XXX|<Registration_Key for IPI>|<Date>|<Date>|SUBSCRIPTION

If the output, doesn't show the timelimited module, then you don't have the IPI license properly loaded.

If the license does not show as timelimited then you can re-license the unit. If the license is not returned properly by the F5 Licensing Server then reach out to both your Account representative or Support for a review on the license.
