Known Issue

Remote Lightweight Directory Access Protocol (LDAP) authentication fails when the remote role group attribute string contains a space character.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to authenticate BIG-IP user accounts using remote LDAP.
  • You have created a remote role group that has an attribute string containing a space character. For example, Our Company Name.

Impact

LDAP authentication fails and users are unable to access the Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • LDAP users defined in a remote role group fail to authenticate and are unable to access the Configuration utility.
  • After upgrading to software 11.4.1 or later, LDAP users are unable to access the Configuration utility.

Workaround

To work around this issue, you can either remove space characters or encode the space character using \20. For example, you should modify Our Company Name to Our\20Company\20Name.

Impact of workaround: Performing the recommended procedure should not have a negative impact on your system.
