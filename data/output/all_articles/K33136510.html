Known Issue

The default SNMP community may be deleted when upgrading to 11.2.1 HF15.

This issue occurs when all of the following conditions are met:

  • You upgrade the BIG-IP 11.2.1 base version to 11.2.1 HF15.
  • At the time of the upgrade, the only SNMP community configured on the system is the system-supplied default IPv4 public:default SNMP community.

Impact

An upgraded system no longer replies to SNMP queries.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After upgrading to 11.2.1 HF15, the system does not reply to SNMP GET requests sent to the localhost, management IP, or self IP address of the BIG-IP system.
  • After upgrading to 11.2.1 HF15, when you navigate to System > SNMP > Agent > Access (v1,v2c) in the Configuration utility, the IPv4 public:default community is no longer listed.

Workaround

To work around this issue, you can re-configure the IPv4 public:default SNMP community after upgrading to 11.2.1 HF15. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > SNMP > Agent > Access (v1,v2c).
  3. Click Create.
  4. In the Community field, type the following text:

    public
  5. From the Source menu, select Select.

    A new Source field will appear.
  6. In the new Source field, type the following text:

    default
  7. Click Finished.
