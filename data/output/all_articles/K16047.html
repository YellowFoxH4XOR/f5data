Known Issue

When you attempt to view zone statistics, the BIG-IP GTM Configuration utility may report an error message.

This issue occurs when all of the following conditions are met:

  • From the BIG-IP GTM Configuration utility, you navigate to the Statistics > Module Statistics : DNS : Zones > Zones page.
  • You choose Zones from the Statistics Type drop-down menu.
  • You attempt to filter the list of zones by Status.

Impact

You are unable to view zone statistics using the BIG-IP GTM Configuration utility.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to filter the list of zones by Status, the Configuration utility displays an error message that appears similar to the following example:

    General database error retrieving information
  • Subsequent attempts to view the Statistics > Module Statistics : DNS : Zones > Zones page results in the same error message.

Resolution

Status

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) utility to view the zone statistics.

Impact of workaround: Performing this workaround should not have a negative impact on your system.
