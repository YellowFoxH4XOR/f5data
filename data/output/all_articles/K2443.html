When ArrowPoint SLB is selected for the Host Server SNMP probe type, the 3-DNS Controller probes the following OIDs:
IdentifierOID
Owner Name1.3.6.1.4.1.2467.1.16.4.1.1
Rule Name1.3.6.1.4.1.2467.1.16.4.1.2
Rule IP1.3.6.1.4.1.2467.1.16.4.1.4
Rule Port1.3.6.1.4.1.2467.1.16.4.1.6
Rule Enable1.3.6.1.4.1.2467.1.16.4.1.11
Rule Bytes1.3.6.1.4.1.2467.1.16.4.1.25
Rule Frames1.3.6.1.4.1.2467.1.16.4.1.26
Owner Name1.3.6.1.4.1.2467.1.18.2.1.1
Rule Name1.3.6.1.4.1.2467.1.18.2.1.2
SERVICE Name1.3.6.1.4.1.2467.1.18.2.1.3
State1.3.6.1.4.1.2467.1.18.2.1.12
Total Conns1.3.6.1.4.1.2467.1.18.2.1.4
SERVICE Name1.3.6.1.4.1.2467.1.15.2.1.1
Current Conns1.3.6.1.4.1.2467.1.15.2.1.20

To find OIDs for other vendors, use the strings Unix command on big3d and the grep command to get the manufacturer string.

For example:

strings /usr/sbin/big3d | grep 2467

Will return the following:
