Known Issue

The Traffic Management Microkernel (TMM) may leak memory when the BIG-IP ASM system is enabled for a virtual server.

This issue occurs when the following condition is met:

  • The virtual server that is processing the traffic is configured with a BIG-IP ASM security policy.

Impact

When processing requests, the TCP proxy in TMM leaks memory and may eventually exhaust all available system memory, causing TMM to restart.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system generates a core file to the /shared/core/ directory.
  • TMM memory allocation increases steadily over time.  You can monitor the relevant memory usage by typing the following command:

    tmsh show /sys memory | grep -P 'SubSystem   |hud_oob'

    Output may appear similar to the following example:

    SubSystem                        Alloc (bytes)  Max Alloc (bytes)  Object Size
    hud_oob                            3072             3072              64

  • The BIG-IP ASM system fails over to a standby system if configured for high availability (HA).
