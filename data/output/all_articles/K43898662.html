Issue

Error Message

01510013:1: vCMP guest <guest_name> lost heartbeat

In this error message, note the following:

  • <guest_name> is the name of the vCMP guest instance

    For example:

    01510013:1: vCMP guest MyGuest lost heartbeat

In addition, the vCMP host may log the following, related messages:

01510014:1: vCMP guest <guestname> heartbeat timeout at the halfway mark.
01510011:1: vCMP guest <host_name> powered off.

Message Location

You may encounter this message in the following locations:

  • The vCMP host system's /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • When the vCMP guest is prevented from incrementing its watchdog counter for 30 seconds, and the host vcmpd process restarts the guest.
  • The vCMP guest is experiencing resource issues, such as high CPU utilization.

Impact

The vCMP guest restarts, interrupting traffic processing. In some cases the guest powers off and becomes unreachable until it is powered back on.

Recommended Actions

To diagnose the issue, you may need to perform logging on the serial console to a file for the vCMP guest. For more information, refer to K68404255: Configuring serial console logging to a file for a vCMP guest.
