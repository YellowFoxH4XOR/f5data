Description

You performed an upgrade and observed "Provision warning" error under the device status. On vCMP you may not be able to deploy Guests. In System > Resource Provisioning modules that previously had Licensed status are now Unlicensed.

Before:

After:

In /var/log/ltm folder you can see following messages:

Nov 14 14:41:14 <device name> err tmipsecd[17315]: 01180006:3: Software version not covered by service agreement service check date 20230114  version date 20230208.

Environment

  • BIG-IP
  • Upgrade
  • vCMP

Cause

It's caused by outdated service check date. 

Recommended Actions

You can find information how to renew service check date under below link:

K7727: License activation may be required before a software upgrade for BIG-IP

Note: Please note that the service check date varies from software to software. In the article above, you can see the dates that belong to a specific release version. You can refer to these to see if renewal is necessary.
