Issue

Error Message

crit tmm[<PID>]: 01230002:2: Interface <Interface.Number> not found

In this error message, note the following:

  • <PID> is the process ID for the tmm process
  • <Interface.Number> is the specific interface in x.x format that is being reported.

Note: For VIPRION systems, the format will appear similar to the following example:

<Blade Number>/<Interface.Number>

For example:

tmm[1133]: 01230032:2: Interface 0.1 not found

Or

crit tmm3[23081]: 01230032:2: Interface 2/1.8 not found

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • When processing a trunk member configuration change, the tmm process can not find the interface in its interface list before logging the error message.

Impact

The trunk configuration or status may not be configured properly and does not deliver traffic.

Recommended Actions

To workaround this issue, you can check the configuration and make sure the interface is available.
