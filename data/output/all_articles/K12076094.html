Description

Upgraded from 13.x or 14.x to 15.x or 16.x.

After the upgrade, CGNAT was automatically de-provisioned.

Environment

  • Software Upgrade
  • CGNAT

Cause

Bug ID 888765

This happens when upgrading from a version where CGNAT is enabled:

sys feature-module cgnat {
    enabled
}

To a version where CGNAT is provisioned:

sys provision cgnat {
    level nominal
}

Recommended Actions

Provision CGNAT, then save the configuration.

tmsh modify sys provision cgnat level nominal
tmsh save sys config

The issue should not return on subsequent config loads or upgrades.

Additional Information

CGNAT is provisioned from 15.x onwards.
