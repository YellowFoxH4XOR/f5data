K05648102: SSL Offloading is not compatible with LDAP Channel Signing and Binding

Type
Support Solution
Published
2022-02-15
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.4
Source
https://my.f5.com/manage/s/article/K05648102

Description
Many Microsoft Active Directory environments are beginning to require that requests be handled through a single consistent end-to-end channel. This security feature, called LDAP Channel Signing and Binding, requires that the AD server have a direct SSL session with the client system, meaning that it cannot function across a Big-IP virtual server that terminates the client's SSL session.

Environment

  • Big-IP Local Traffic Manager (LTM)
  • Secure Lightweight Directory Access Protocol (LDAPS) Virtual Server
  • SSL Termination
    • SSL Offload
    • SSL Re-encryption
  • LDAP Channel Signing and Binding

Cause
LDAP Channel signing and Binding require a consistent, direct SSL session between the client and the AD server

Recommended Actions

  1. Remove all SSL profiles from the LDAPS virtual server if this is a requirement. This will prevent the Big-IP from reading or modifying LDAP attributes

Additional Information
None
