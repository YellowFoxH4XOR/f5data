Known Issue

Log filters can be configured to reference an invalid source.

This issue occurs when the following condition is met:

  • You create or modify a high-speed logging (HSL) log filter to reference Source > dummy.

Impact

Log filters are ineffective.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After configuring a log filter with a Source value of dummy, no filter-specific logs are produced when using the log filter.
