Description

  • I want to achieve an A+ grade in Qualys with a good range of interoperability with older systems. 
  • This article will provide the configuration required on F5® Distributed Cloud (XC) in order to achieve an A or A+ grade from the Qualys SSL Labs scan. 

Environment

  • F5® Distributed Cloud WAF
  • HTTP LB

Answer/Recommended Actions

To configure the SSL configuration in the LB:

1. Go to Load Balancers.

2. Within Actions, select Manage Configuration. 

3. Select Domains and LB Type in the sidebar menu. 

4. Find TLS Certificates and select Edit Configuration. 

5. In TLS Security Level, select Custom. 

6. Set Minimum TLS version: 1.2
7.  Set Maximum TLS version: 1.3

8. Configure the following cipher suites:

TLS_AES_128_GCM_SHA256
TLS_AES_256_GCM_SHA384
TLS_CHACHA20_POLY1305_SHA256
TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384
TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256

9. Save, apply, and exit on all screens.

** Verify the cipher list is compatible and supported by your backend.

 

Additional Information

These cipher suites are preferred for default TLS configurations for several reasons:

  1. Security: They use modern cryptographic algorithms like AES and SHA, which are considered secure and widely trusted.
  2. Key Exchange: ECDHE provides forward secrecy, meaning that even if the server's private key is compromised, past communications remain secure.
  3. Performance: They strike a balance between security and performance. AES is a fast encryption algorithm, and ECDHE offers efficient key exchange.
  4. Compatibility: The majority of contemporary web browsers and servers support these cipher suites, ensuring compatibility with a wide range of systems.
