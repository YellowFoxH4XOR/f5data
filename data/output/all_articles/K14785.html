Known Issue

When you use the BIG-IP APM iRule for Microsoft ActiveSync, the connection may reset.

This issue occurs when all of the following conditions are met:

  • You configure a BIG-IP APM system with a virtual server for Microsoft-Server-ActiveSync.
  • You configure the virtual server to use the F5-provided ActiveSync iRule named _sys_APM_activesync.

Impact

The BIG-IP APM system resets the ActiveSync connection.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Client devices that connect to the BIG-IP APM resource for Microsoft-Server-ActiveSync receive a TCP reset.
  • Connections to the BIG-IP APM resource for Microsoft-Server-ActiveSync trigger a log message similar to the following example in the /var/log/ltm file:

    TCL error: /Common/_sys_APM_activesync <HTTP_REQUEST> - can't read "actsync_401_http_body": no such variable while executing "HTTP::respond 401 content $actsync_401_http_body Connection close"

Workaround

To work around this issue, you can copy the affected iRule and then correct the offending TCL syntax. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Click Local Traffic.
  3. Click iRules.
  4. Click _sys_APM_activesync.
  5. Right-click inside the Definition box.
  6. Click Select All.
  7. Right-click inside the Definition box again.
  8. Click Copy.
  9. Click <<Back in the lower-left corner of the Configuration utility.
  10. Click Create in the upper-right corner of the Configuration utility.
  11. Assign a name to the new iRule copy of _sys_APM_activesync.
  12. Right-click inside the Definition box.
  13. Click Paste.

    Note: The Definition box fills with the text of the original _sys_APM_activesync iRule.

  14. Scroll to the bottom of the TCL text in the Definition box.
  15. Remove the last line of the iRule that starts with "definition-signature."
  16. Search the iRule text for the following line (approximately line 33):

    HTTP::respond 401 content $actsync_401_http_body Connection close

  17. Modify the TCL syntax of this line by adding static:: immediately after the dollar sign, similar to the following example:

    Original TCL variable syntax: $actsync_401_http_body
    Updated TCL variable syntax: $static::actsync_401_http_body

    After you modify the TCL variable syntax, the line appears similar to the following example:

    HTTP::respond 401 content $static::actsync_401_http_body Connection close

  18. Click Finished.
  19. Click Local Traffic.
  20. Click Virtual Servers.
  21. Click the Virtual Server name that is used by the BIG-IP APM system for Microsoft-Server-ActiveSync connections.
  22. Click Resources.
  23. Click Manage for iRules.
  24. In the Enabled column, click _sys_APM_activesync.
  25. To move the iRule to the Available column, click >> .
  26. In the Available column, click the newly-created ActiveSync iRule.
  27. To move the iRule to the Enabled column, click << .
  28. Click Finished.
