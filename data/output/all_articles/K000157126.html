K000157126: Cert Manager HELM charts no resource specs defined (unbound/limitless)

Type
Support Solution
Published
2025-12-23
Updated
2026-01-07
Applies to
  • BIG-IP Next DNS CNF: 2.0.1
  • BIG-IP Next CNF
Source
https://my.f5.com/manage/s/article/K000157126

Description:

 

When deploying BIG-IP Next DNS CNF using the f5-cert-manager Helm charts, several pods—including f5-cert-manager, f5-cert-manager-cainjector, and f5-cert-manager-webhook—lack resource specifications (CPU and memory requests/limits) in their container definitions. This absence of resource constraints can result in unbounded resource consumption, potentially leading to excessive usage due to bugs, threats, or misconfiguration. Running kubectl get pod -n <namespace> -o jsonpath='{.spec.container[*].resources}' will show empty resource definitions for these containers.

Environment:

  • Product: BIG-IP Next DNS CNF
  • Version: 2.0.1, 2.1.0
  • Platform: Kubernetes
  • Deployment Method: Helm charts for f5-cert-manager, f5-cert-manager-cainjector, and f5-cert-manager-webhook
  • Resource requests/limits not defined in most deployment templates or values.yaml entries
  • Only the fluentbit container within the f5-cert-manager pod has confirmed resource configuration (CPU: 100m, Memory: 200Mi)
  • Overall pod resources may be set (e.g., CPU: 200m, Memory: 3000Mi), but not broken down by individual containers

Cause:

The Helm chart templates for f5-cert-manager do not include resource specifications for most containers. Although values.yaml allows for resource entries, these are not applied unless referenced by the template files. Consequently, containers are deployed without CPU or memory requests/limits.

Recommendations:

  • Define Resource Requests and Limits in Templates:
    • Update all relevant Helm chart deployment templates (such as cainjector-deployment.yaml, webhook-deployment.yaml, deployment.yaml) to include a resources section for each container.
    • Example configuration: 
      resources:
  requests:
    cpu: 10m
    memory: 100Mi

webhook:
  image:
    repository: artifactory.f5net.com/f5-f5ingress-docker/cert-manager
  resources:
    requests:
      cpu: 10m
      memory: 100Mi
  • Ensure that these sections exist in every container spec within the deployment templates—not just in values.yaml.
  • Set Default Values:
    • Establish sensible default values for both requests and limits to prevent unbounded usage.
    • Adjust based on expected workload and environment requirements.
    • Verify Resource Application Post-Deployment:
    • After updating Helm charts/templates and redeploying pods, verify that resources have been correctly applied.
