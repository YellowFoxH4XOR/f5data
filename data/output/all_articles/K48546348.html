Description

Failover occurred, and you can see similar to below log in /var/log/ltm: 

notice sod[<pid>]: 010c006d:5: Initiating Auto-Failback.
notice sod[<pid>]: 010c006d:5: Leaving Standby for Active: Next Active, Auto-Failback.
notice sod[<pid>]: 010c0053:5: Active for traffic group /Common/<traffic_group_name>
notice sod[<pid>]: 010c0019:5: Active
 

Environment

  • BIG-IP
  • Failover
     

Cause

This indicate Auto failsafe is triggered, so that preferred Active unit becomes Active.


Recommended Actions

Force Standby will be effective with Auto Failsafe, so that you will see similar to the following log in /var/log/ltm:
info sod[<pid>]: 010c0096:6: Next active for traffic group <traffic_group_name>.
notice sod[<pid>]: 010c0018:5: Standby
notice sod[<pid>]: 010c0080:5: Auto-Failback for traffic <traffic_group_name> is disabled due to user initiated standby.
notice tmm[<pid>]: 01340011:5: HA unit 1 state change: from 1 to 0.
 
However this status will NOT stay once you rebooted this machine. 
When you are in maintenance window (e.g. upgrade system), set Force Offline to avoid unexpected failover. Please read further information about Force Offline: 
K15122: Overview of the Force Offline option for devices and traffic groups
Auto-failback operation causing the preferred unit to come back active the configured seconds after release offline.
 

Additional Information

    Auto Failsafe
    When you enable auto-failback, a traffic group that has failed over to another device fails back to a preferred device when that device is available.

    The following command will list the config similler to below:

    tmsh list /cm traffic-group all-properties
    cm traffic-group /Common/<traffic_group_name> {
        app-service none
        auto-failback-enabled true  <<----
        auto-failback-time #        <<---- After # second later auto-failsafe will be triggered. 
        default-device none
        description none
        ha-group none
        ha-load-factor 1
        ha-order {
            /Common/<device_name_1>
            /Common/<device_name_2>
        }
        is-floating true
        mac none
        partition Common
        unit-id *
    }
