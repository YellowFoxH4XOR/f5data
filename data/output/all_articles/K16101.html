Known Issue

In some low resource situations, the Traffic Management Microkernel (TMM) may restart and produce a core file.

This issue occurs when all of the following conditions are met:

  • A virtual server configured with Session Initiation Protocol (SIP) and message-based load balancing (MBLB) profiles is under high traffic conditions.
  • TMM has a low amount of free memory.

Impact

The BIG-IP system temporarily fails to process traffic as it recovers from the TMM restart, and devices configured as a high-availability (HA) pair may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Under high traffic conditions, the BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
  • The BIG-IP system unexpectedly fails over to another system in the device group.
  • You observe a TMM core file in the /shared/core directory.
  • The core file backtrace indicates a TMM segfault occurred in the MBLB mlb_proxy.
