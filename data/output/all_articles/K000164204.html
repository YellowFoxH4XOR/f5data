K000164204: BIG-IQ Unreachable license generation fails with "offerings found for regkey pool license, but none are available for use"

Type
Support Solution
Published
2026-11-12
Updated
2026-11-12
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.1, 8.4.2
Source
https://my.f5.com/manage/s/article/K000164204

Description

BIG-IQ fails to generate Unreachable licenses from a RegKey pool populated with MyF5 Self-Service licenses after a previously assigned Unreachable license is revoked.

The error "# offerings found for regkey pool license... but none are available for use" appears even though licenses remain available in the pool.

Environment

  • Flex Consumption Plan (FCP)

  • MyF5 Self Service licenses
  • RegKey Pool on BIG-IQ
  • Unreachable license revoked
  • Attempt to generate new unreachable license
  • Available license keys in RegKey Pool

Cause

This is due to Bug ID 2567821: BIG-IQ RegKey Pool API fails to assign licenses to unreachable BIG-IP Devices.

Recommended Actions

Open a ticket with F5 Support to request the files and instructions to resolve Bug ID 2567821. 

Additional Information

None
