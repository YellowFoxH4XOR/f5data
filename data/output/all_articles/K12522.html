Topic

Beginning in BIG-IP APM 10.2.0, the Active Directory AAA server administrator name is case sensitive. If the administrator name entered is not an exact match to the administrator name defined in the Active Directory, the AD Query action will fail and log the following error message in the /var/log/apm file:

'Local error, SASL(-1): generic failure: GSSAPI Error: Unspecified GSS failure. Minor code may provide more information (Cannot find ticket for requested realm)'

The BIG-IP APM system uses the administrator account configured for the Active Diectory AAA server to perform queries against Active Directory. The BIG-IP APM can support multiple AAA server profiles.

Verifying the name configured on the Active Directory AAA server

  1. Log in to the BIG-IP APM Configuration utility.
  2. In the navigation pane, expand Access Policy.
  3. Click Access Profiles.
  4. On the row for the Access policy you want to verify, click Edit….

    The Visual Policy Editor will open.
  5. Click the AD Query action.
  6. Note the name listed in the Server drop-down menu.
  7. Click Cancel.
  8. Click Close.
  9. Click AAA Servers.
  10. Click the name of the AAA server you noted in the Ad Query action above.
  11. Verify the name entered in the Admin Name field is spelled exactly as it is in Active Directory. If it is not the same, enter the correct spelling.

If you updated any settings in the access policy or AAA server, you will need to apply the access policy again. To do so, perform the following procedure:

  1. Click Access Profiles.
  2. Select the check box next to the access policy you updated.
  3. Click Apply Access Policy.
