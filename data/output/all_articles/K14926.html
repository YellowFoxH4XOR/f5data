Topic

You should consider using this procedure under the following condition:

  • You want to use underscore ( _ ) characters in wide IP names.
  • You want to use underscore ( _ ) characters in the BIG-IP GTM system's hostname.

Description

In BIG-IP 12.0.0 and earlier, the BIG-IP DNS system does not allow underscore ( _ ) characters in wide IP names, by default. Additionally, if the BIG-IP DNS system's hostname includes an underscore character, and the ZoneRunner utility will fail to create DNS zones. You can configure the BIG-IP DNS system to accept underscore characters using the Configuration utility or the TMOS Shell (tmsh). Due to a change in behavior introduced in BIG-IP DNS 12.1.0, the BIG-IP DNS system allows underscore characters in wide IP names, by default. For more information, refer to K02525936: The BIG-IP DNS system accepts underscore characters, by default.

Although the BIG-IP DNS system allows underscore characters in wide IP names by default, ZoneRunner may continue to log a warning message about the underscore character similar to the following example in the /var/log/gtm file:

01150216:5: Notice from named-checkconf: db.external.example.com.:6: my_web.example.com: bad owner name (check-names)

If you want to stop ZoneRunner from logging these warning messages, you may consider performing the Modifying named configuration to ignore check-names procedure detailed in K70513366: Error Message: 01150216:5: Notice from named-checkconf: zone.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have admin access to the Configuration utility or the TMOS Shell (tmsh).

Procedures

To configure the BIG-IP DNS system to accept underscore characters, perform one of the following procedures:

  • Using the Configuration utility to configure the BIG-IP DNS system to accept underscore characters (BIG-IP 11.5.0 and later)
  • Using the Configuration utility to configure the BIG-IP DNS system to accept underscore characters (BIG-IP 11.0.0 - 11.4.1)
  • Using tmsh to configure the BIG-IP DNS system to accept underscore characters

Using the Configuration utility to configure the BIG-IP DNS system to accept underscore characters (BIG-IP 11.5.0 and later)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to DNS > Settings > Zones.
  3. For Domain Validation, select Allow Underscores.

Using the Configuration utility to configure the BIG-IP DNS system to accept underscore characters (BIG-IP 11.0.0 - 11.4.1)

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to System > Configuration > Global Traffic > General.
  3. For Domain Validation, select Allow Underscores.

Using tmsh to configure the BIG-IP DNS system to accept underscore characters

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To set the system to accept underscore characters in wide IP names, enter the following command:

    modify /gtm global-settings general domain-name-check allow-underscore

  3. Save the configuration by entering the following tmsh command:

    save /sys config gtm-only
