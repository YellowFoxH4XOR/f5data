Description

The error message "Configuration not allowed in SLAVE state" appears when attempting to enter configure t mode in ZebOS:

[test@BIG-IP:/S1-green-P::Active:Standalone] ~ # imish
BIG-IP-example-com[0]>en
BIG-IP-example-com[0]#configure t
Configuration not allowed in SLAVE state

 

Environment

VIPRION multi-blade.

Cause

The current blade is not the Master/Primary blade.

 

Recommended Actions

1.- From bash, confirm the current primary blade, by entering the command:

tmsh show sys cluster all-properties.

 

The output should look similar to:

Sys::Cluster: default
----------------------------------------------------------------------

2.- Logging into the Primary blade by use command:

ssh <slot number>

For the example above, you would have to use:

ssh slot2

 

3.- Make the change in the primary slot.
