Description

This article applies to iControl SOAP. For iControl REST, refer to the following article:

  • K50035502: How to determine if a BIG-IP system is using iControl REST

iControl SOAP is an open API using SOAP/XML to communicate between systems. You can verify if user-initiated SOAP API calls are recently being utilized on the system by reviewing log messages in /var/log/ltm that appear similar to the following format:

info soap[<PID>]: src=<source_IP>, user=<user_name>, method=<SOAP_method>, action=<SOAP_action>

In this message, note the following:

  • <PID> is the process ID for the SOAP process.
  • <source_IP> is the source IP address that initiated the API request.
  • <user_name> is the user account used to make the API request.
  • <SOAP_method> is the SOAP method used in the API request.
  • <SOAP_action> is the SOAP action used in the API request.

For example:

info soap[8484]: src=10.10.1.84, user=admin, method=get_all_statistics, action=urn:iControl:LocalLB/VirtualServer

If a user visited the the Web Services Description Language (WSDL) index by accessing the iControl FastCGI endpoint /iControl/iControlPortal.cgi on the system, a log will be generated in /var/log/ltm that appears similar to the following format:

info soap[<PID>]: query: WSDL=<WSDL_interface>

In this message, note the following:

  • <PID> is the process ID for the SOAP process.
  • <WSDL_interface> is the queried WSDL interface, if any.

For example:

info soap[8484]: query: WSDL=System.ConfigSync

Environment

  • BIG-IP system
  • iControl SOAP

Recommended Actions

To determine if the system is recently utilizing iControl SOAP, you can review the logs in /var/log/ltm and check for specific messages related to the SOAP calls. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To check the iControl SOAP requests, enter the following command:

    grep 'soap\[' /var/log/ltm

    You can find SOAP messages in the output if the API has been requested, for example:

    info soap[8484]: src=10.10.1.84, user=admin, method=save_configuration, action=urn:iControl:System/ConfigSync#save_configuration

Additional Information
  • The BIG-IP system may initiate SOAP calls for certain configuration items being viewed/modified from the Configuration Utility. For such calls, some parts of of the message are omitted compare to the user initiated calls, for example:

    info soap[8484]: src=127.0.0.1, user=
