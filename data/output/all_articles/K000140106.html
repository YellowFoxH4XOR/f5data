K000140106: VCMP Guests crashed unexpectedly, took some offline to allow others to run.

Type
Support Solution
Published

Updated

Applies to

  • BIG-IP LTM: 17.1.1
Source

Description

When the VCMP host disk space is over provisioned, the VCMP host might eventually start reporting disk full errors. Certain VCMP guest tasks (e.g. software upgrades, copying large files) require large amount of disk space and are very likely to cause an expansion of the VCMP guest virtual disk. There is no process to automatically compact the virtual disk. This will eventually cause the VCMP host to run out of disk space. This usually happens when all the guests are being upgraded at the same time.

 

Environment

VCMP host with multiple guests

Over provisioned VCMP guest virtual disk size

 

Cause

Each VCMP guest virtual disk will keep expanding until it reaches the configured maximum size for the virtual disk.

 

Recommended Actions

In order to recover the maximum amount of disk space. Take a UCS, delete and recreate the VCMP guests and their virtual disk files.

If it is not feasible to recreate the guest follow K000140235 to shrink the virtual disk files. This may not recover all the free space due to fragmentation within the virtual disk file.
