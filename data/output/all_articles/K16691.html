Known Issue

Object references that are deleted during a ConfigSync or batch mode transaction may fail.

This issue occurs when all of the following conditions are met:

  • You perform a ConfigSync operation or run a batch mode transaction using iControl or the Traffic Management Shell (tmsh), which deletes a configuration object.
  • The configuration object being deleted is referred to by another object. For example, you attempt to remove a protocol profile from a virtual server and delete the profile.

Impact

The ConfigSync operation or batch mode transaction will fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • A device group ConfigSync operation or a batch mode transaction fails.
  • Messages similar to the following appear in the /var/log/ltm file:

    01020036:3: The requested virtual server profile (/Common/vs1 http1) already exists in partition Common.
    01020036:3: The requested virtual server profile (/Common/vs1 http1) was not found.

Workaround

There is no workaround for this issue. The removal of the object reference must be done before the ConfigSync operation, or in a separate batch mode transaction. For example, if you want to delete a profile that is being used, create one transaction, removing it from virtual servers, then create a second transaction, deleting the profile.
