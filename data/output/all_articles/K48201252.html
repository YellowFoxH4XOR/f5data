K48201252: After BIG-IP device is booted, mcpd may have defunct/zombie child ''run'' and ''xargs'' processes

Description

After initial boot of device and mcpd is started, it may be left with zombie processes such as 'run' and 'xargs'.

For example, ps command may have similar output:

[root@LTM1.example.com:Active:Disconnected] config # ps auxwf | grep -C2 defunct
root      6617  0.0  0.0   2128   220 ?        S    12:01   0:00  \_ runsv mcpd
root      6640  1.7  1.1 218648 48512 ?        Sl   12:01   0:05  |   \_ /usr/bin/mcpd -dbmem 512 -listen 127.0.0.1 -f
root      6979  0.0  0.0      0     0 ?        Z    12:01   0:00  |       \_ [run] <defunct>
root      6980  0.0  0.0      0     0 ?        Z    12:01   0:00  |       \_ [xargs] <defunct>

Environment

  • BIG-IP LTM is provisioned
  • Running BIG-IP 14.1.x - v15.1.x
     

Cause

Bug ID 822253

None
