Description

You have a Virtual Server running on a custom TCP port number (not TCP port 80 and TCP port 443) and you want to redirect http traffic to https.

For example you want to redirect http://www.example.com:5544 to https://www.example.com:5544.

Environment

  • BIG-IP
  • Virtual Server running custom TCP port number
  • HTTP profile is required

Cause

You will not be able to redirect http to https using the same custom TCP port.

Based on K10090418 for a redirection, you require 2 Virtual Server to process http and https traffic. The problem with a custom TCP port, both Virtual Servers for http and https will have the same TCP port and so traffic to those Virtual Servers will not know if it is processing http or https traffic.

Recommended Actions

There are other options you can venture which are:

  • Virtual Server with TCP port 80 to Virtual Server with custom TCP port
  • Virtual Server A with custom TCP port to Virtual Server B with custom TCP port
Virtual Server with TCP port 80 to Virtual Server with custom TCP port
An example for this is redirecting http://www.example.com:80 to https://www.example.com:5544.
  1. Login to the BIG-IP Configuration Utility.
  2. Create a new Virtual Server as per the current Virtual Server but make changes to:
    1. The Service Port is configured to 80.
    2. Remove all SSL Profile (Client) and SSL Profile (Server)
  3. Refer article K15117465, for the general iRule syntax to create the redirection.
    Note: You will be using the redirect syntax explained in K15117465 and appending the custom port. 
Virtual Server A with custom TCP port to Virtual Server B with custom TCP port
An example for this is redirecting http://www.example2.com:5544 to https://www.example.com:5544.
  1. Login to the BIG-IP Configuration Utility.
  2. Create a new Virtual Server as per the current Virtual Server but make changes to:
    1. The Destination Address is different than the current Virtual Server.
    2. Remove all SSL Profile (Client) and SSL Profile (Server)
  3. Refer article K15117465, for the general iRule syntax to create the redirection.
    Note: You will be using the redirect syntax explained in K15117465 and appending the custom port.
