Topic

This article applies to BIG-IP APM 11.x and later. For information about other versions, refer to the following article:

  • K13680: Removing the home tab from a portal access web application (10.x)

Purpose

You should consider using this procedure under the following condition:

  • You want to remove the home tab from a portal access resource item.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP APM system is configured with a portal access profile.
  • The web application resource configuration uses Full Patching.

Description

The BIG-IP APM system allows you to remove the home tab from all web resources accessed through a portal access profile. The home tab is an overlay that displays a Logout button, Home button, and a box for the user to enter a direct URL. The Home Tab option only affects web hosts defined in the Destination box of the resource item. You can modify access to the home tab in the associated portal access resource items.

Procedures

Using the Configuration utility to remove the home tab for an associated resource of the portal access profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access Policy > Portal Access > Portal Access List.
  3. From the list, select the name of the portal access resource.
  4. In the Resource Items section, click the resource item name.
  5. For the Resource Item Properties setting, select Advanced.
  6. Clear the Home Tab check box.
  7. Click Update.
  8. In the upper-left corner of the Configuration utility screen, click the Apply Access Policy link.
  9. Click Apply Access Policy.

Using the Traffic Management Shell (tmsh) to remove the home tab for an associated resource of the portal access profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Use the following command syntax, where <portal_profile> is the name of the Portal Access profile:

    modify /apm resource portal-access <portal_profile> items modify { item { home-tab false } }
  3. Save the configuration by typing the following command:

    save /sys config
  4. Apply the updated Access Policy to the running access policy configuration by using the following command syntax, where <access_policy_name> is replaced by the modified access policy name:

    modify /apm profile access <access policy name> generation-action increment
