Known Issue

Microsoft Exchange client connection requests to the BIG-IP APM system may fail

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an access profile for Exchange clients, such as ActiveSync.
  • You modify the BIG-IP system tmm.access.maxrequestbodysize database variable to a value larger than the default 64 KB value.
  • An Exchange client access session connection attempts to send a message body that is larger than 64 KB.

Impact

The BIG-IP APM system does not successfully process the request.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The user receives an error message noting an ActiveSync connection failure or a failure to reach the ActiveSync mail server.
  • When the user attempts to send an email message from their device, the email message remains in the Outbox.
  • Error messages appear in the /var/log/apm file, similar to the following example:

    err tmm3[<pid>]: 01490514:3: 00000000: Access encountered error: ERR_NOT_SUPPORTED. File: ../modules/hudfilter/access/access.c, Function: hud_access_process_ingress, Line: 2298
    err tmm[<pid>]: 01490514:3: 00000000: Access encountered error: ERR_NOT_SUPPORTED. File: ../modules/hudfilter/access/access.c, Function: hud_access_process_ingress, Line: 2298
