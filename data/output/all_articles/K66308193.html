K66308193: Could not list EM ceritifcate directory '/shared/em/ssl.crt' in function EmCertsModified: Permission denied

Description

There's a known certificate issue which may impact big3d operation. Customer may observe the following errors in /var/log/ltm and /var/log/gtm files.

12b10000:3: Could not list EM ceritifcate directory '/shared/em/ssl.crt' in function LoadEmCertificates: Permission denied
12b10000:3: Could not list EM ceritifcate directory '/shared/em/ssl.crt' in function EmCertsModified: Permission denied

On any device managed by BIG-IQ, this may break BIG-IQ device group trust. However, these errors can also be seen in any BIG-IP device not managed by BIG-IQ/EM as well.

For example, between LTM and GTM devices, it may cause GTM iquery connection to fail.

The following error can also be observed in /var/log/gtm
notice gtmd[12314]: 011ae01c:5: Connection complete to x.x.x.x. Starting SSL handshake
notice gtmd[12314]: 011ae01c:5: Connection complete to x.x.x.x. Starting SSL handshake
iqmgmt_ssl_connect: SSL error:14090086:SSL routines:SSL3_GET_SERVER_CERTIFICATE:certificate verify failed
iqmgmt_ssl_connect: SSL error: error:14090086:SSL routines:SSL3_GET_SERVER_CERTIFICATE:certificate verify failed (336134278)
iqmgmt_ssl_connect: SSL error:14090086:SSL routines:SSL3_GET_SERVER_CERTIFICATE:certificate verify failed
err gtmd[12314]: 011ae0fa:3: iqmgmt_ssl_connect: SSL error: error:14090086:SSL routines:SSL3_GET_SERVER_CERTIFICATE:certificate verify failed (336134278)

Environment

  • BIG-IP
  • big3d daemond
Cause

Incorrect permissions on /shared/em cert files.

1.On GTM device, run iqdump to confirm the error

[root@localhost:Active:Standalone] ~ # iqdump <self-IP or mgmt IP of the target BIG-IP>
