Description

With BIG-IP Application Security Manager (ASM), you can configure Logging Format which specifies the type of remote server used to log traffic in a logging profile. 
  •  Comma-Separated Values: Specifies that the system stores all traffic on a remote logging server using comma separated values in the logs.
  •  Key-Value Pairs (Splunk): Specifies that the system stores all traffic on a reporting server using a preconfigured storage format where key-value pairs are used in the log messages.
  •  Common Event Format (ArcSight): Specifies that the system stores all traffic on a remote logging server using the predefined ArcSight settings for the logs. The log messages are in Common Event Format (CEF).
  •  BIG-IQ: Specifies that the system stores all traffic on a BIG-IQ system.

However, even if "Comma-Separated Values" is specified, anomaly events will have "Key-Value Pairs" format.

Environment

  • BIG-IP ASM
  • Configuring Anomaly Detection in Security Policies
  • Specifying Logging Format as Comma-Separated Values

Cause

This is by design.
Having anomaly events as CSV (only values, without key names) would be non-readable, this is the reason why it is hardcoded name=value pairs format.
