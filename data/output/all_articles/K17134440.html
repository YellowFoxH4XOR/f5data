K17134440: BIG-IP statistics from one member of HA pair not being collected in BIG-IQ

Type
Support Solution
Published
2022-06-07
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K17134440

Description

  • Statistics collection from a BIG-IP is failing, HA peer is working properly
  • 'Stats Processing Delay' errors
  • Last Stat Collection day shows the last time the stats collection worked

Environment

  • BIG-IP provisioned with AVR
  • BIG-IQ collecting statistics

Cause

  • the management IP of the DCD was also configured as an IP of a Virtual Server on the misbehaving BIG-IP resulting in packets destined for the DCD to be incorrectly routed to the VS instead
  • IP conflict

Recommended Actions

  • review traffic to the DCD using tcpdumps
  • correct any observed misconfiguration of IP addresses

Additional Information

None
