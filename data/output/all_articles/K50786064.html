Description
Possible values for ClientSSL protocol when creating Local Traffic Policies

Environment

  • BIG-IP LTM v14.1.4
  • Local Traffic Policies
  • ClientSSL protocol
  • Rules conditions

Cause
N/A

Recommended Actions

  1. The possible values for ClientSSL protocol when creating Local Traffic Policies are:
    • all
    • SSLv3
    • TLS
    • TLSv1
    • TLSv1.1
    • TLSv1.2
    • TLSv1.3
  2. Insert the desired value to match the policy rule
  3. Click Add.
