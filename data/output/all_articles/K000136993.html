Description

  • BIG-IP Azure CFE failover attempt fails with "Error message:" [f5-cloud-failover] Problem with discovering network interfaces parsedNics.
  • This is noted on attempting failover on Azure BIGI-IP virtual machines using Failover Cloud Extension.
  • Error message logged in /var/log/restnoded/restnoded.log

 

[f5-cloud-failover] Problem with discovering network interfaces parsedNics.

 

Environment

  • BIG-IP Azure High Availability failover cluster.

Failover not working with error message "[f5-cloud-failover] Problem with discovering network interfaces parsedNics".

Cause

Cloud Failover objects not declared properly on not created in Azure.

Recommended Actions

Follow Azure Failover documentation and ensure all required objects are created in Azure before declaring them on the BIGIP.

Azure CFE Prerequisites
