Description
Sometimes when creating a user account via tmsh, the BIG-IP responds with an error:
Account woodstock is disabled due to using banned password.  (User_ID will vary of course).

Environment

  • BIG-IP prior to version 13
  • Remote authentication being used

Cause
In versions prior to BIG-IP 13.0.0, the BIG-IP system does not support configuring local authentication as a backup method when remote authentication fails.  If remote authentication is used, the BIG-IP will only allow local users 'admin' and 'root' - no other user names / accounts.

Recommended Actions

  1. If you need to use a local account other than 'admin' or 'root' disable remote authentication.
