Description

When restarting httpd, you receive the following error:
 

#bigstart restart httpd
Stopping httpd: [ OK ]
/bin/bash: line 1: 11290 Aborted /usr/sbin/httpd -DTrafficShield -DAVRUI -DWebAccelerator -DSAM
Starting httpd: [FAILED]

Environment

  • BIG-IP
  • Restarting httpd

Cause

This can happen when SSL session cache gets corrupted. The cache files are found in /var/cache/mod_ssl directory. 

Note: This however seems to be a rare occurrence and as of writing, the issue has not been reproducible.

Recommended Actions

The system can be recovered by removing the corrupted cache files. To do so, you can perform the following steps:
  1. Change to the /var/cache/mod_ssl directory.
    cd /var/cache/mod_ssl
  2. Move the scache.dir file to another directory (such as /var/tmp):
    mv scache.dir /var/tmp/
  3. Move the scache.pag file to another directory (such as /var/tmp):
    mv scache.pag /var/tmp/
  4. Restart httpd:
    bigstart restart httpd
