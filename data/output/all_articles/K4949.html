Topic

Important: BIG-IP 9.0 through 9.1 do not work properly with Step-Up/Server Gated Cryptography (SGC) Certificates without installing a patch. For more information, refer to K4948: SSL connections fail when using a Step-Up/Server Gated Cryptography Certificate.

Step-Up/Server Gated Cryptography (SGC) Certificates, such as Verisign's Global Certificate, allow users with a low complexity encryption browser (40-bit or 56-bit) to access a site that allows only high complexity encrypted connections. Standard certificates consist of two parts: the public certificate and the private key. Step-Up/SGC Certificates consist of three parts: the public certificate, the private key, and a Certificate Authority (CA) certificate.

Installing a Step-Up/SGC Certificate
  1. Obtain the necessary CA certificate from your certificate vendor.
  2. Upload the three files that comprise the Step-Up/SGC Certificate to the BIG-IP system.

    Note: For information about transferring files to the BIG-IP system, refer to K175: Transferring files to or from an F5 system.

  3. Log in to the BIG-IP command line.

  4. Move the public certificate into the /config/ssl/ssl.crt/ directory, using the following command syntax:

    mv <file> /config/ssl/ssl.crt/

    Replace <file> with the path to the public certificate file that you uploaded.

  5. Move the CA certificate into the /config/ssl/ssl.crt/ directory, using the following command syntax:

    mv <file> /config/ssl/ssl.crt/

    Replace <file> with the path to the CA certificate file that you uploaded.

  6. Move the private key into the /config/ssl/ssl.key/ directory, using the following command syntax:

    mv <file> /config/ssl/ssl.key/

    Replace <file> with the path to the private key file that you uploaded.

  7. Create a clientssl profile that uses the three certificate components, using the following command syntax:

    bigpipe profile clientssl <name> defaults from clientssl key <key> cert <cert> ca file <cacert>

    Replace:

    • <name> with the name you want to use for the new profile
    • <key> with the file name of the private key
    • <cert> with the file name of the public certificate
    • <cacert> with the file name of the CA certificate

    Note: Do not enter a path for the file names; the command automatically uses the correct path.

    For example:

    bigpipe profile clientssl new defaults from clientssl key mynew.key cert mynew.crt ca file mynewcacert.crt

  8. Save the profile configuration by typing the following command:

    bigpipe save

The Step-Up/SGC Certificate is now installed with a clientssl profile that you can associate with virtual servers.
