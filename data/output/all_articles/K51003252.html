Policy Information

This article applies to F5 BIG-IP SSL Orchestrator 14.x and later. For information about other versions, refer to the following article:

  • K30498134: F5 SSL Orchestrator software support policy (12.x - 13.x)

BIG-IP SSL Orchestrator is sold in the following two license models:

  • A standalone product on specific BIG-IP hardware
  • An SSL Orchestrator add-on LTM (Good-Better-Best)

The BIG-IP SSL Orchestrator module is built on the iAppLX framework, and as a result, is tied to a BIG-IP release. The BIG-IP SSL Orchestrator support policy is, therefore, based on the iAppLX version associated with that release. The combination of the BIG-IP version and the SSL Orchestrator version enables you to have out-of-band updates (RPMs) on F5 Downloads. These out-of-band releases follow the base release unless otherwise indicated.

This policy addresses the BIG-IP version and the SSL Orchestrator version that ship together. For example, BIG-IP 14.0.0 ships with SSL Orchestrator 4.0.0, and BIG-IP 14.1.0 ships with SSL Orchestrator 5.0.0. The combined versions are represented as a single string, for example 14.0.0-4.0.0 and 14.1.0-5.0.0, respectively. As a result, this policy maps to both versions and aligns with the F5 release model.

Software version support of BIG-IP SSL Orchestrator

For major releases (x.0.0), the Standard Support phase begins with the first customer ship date of the release and continues for 15 months. When this milestone is reached, the major release has reached its End of Software Development (EoSD) and End of Technical Support (EoTS) milestones.

Each x.1.0 release marks the start of the long-term stability release. The initial release (x.1.0) contains new features, stability improvements, and new hardware support. Subsequent maintenance releases (x.1.1 to x.1.n) address product defects, security fixes, diagnostic and supportability improvements, minor functional improvements, and new hardware support. Software development support activities occur only on the latest maintenance release of each long-term stability release (x.1.latest), while the long-term stability release is within the Standard Support phase.

The Standard Support phase for the long-term stability release begins with the first customer ship date of the x.1.0 release and extends for the following duration:

  • Five years - BIG-IP versions prior to 16.1.0
  • Four years - BIG-IP version 16.1.0 and subsequent x.1.0 releases

Note: For more information about Major, Feature, and Maintenance release numbering, refer to K8986: F5 product support policies.

At the end of a release's Standard Support phase, the release enters its EoSD and EoTS milestone. Software versions that have reached their EoSD date are no longer supported with active software development. F5 does not provide software fixes (hotfixes) or consulting services for a version that has reached the EoSD milestone.

For software releases, unless specifically declared and announced by F5, the EoTS date marks the end of the software version's support phase.
