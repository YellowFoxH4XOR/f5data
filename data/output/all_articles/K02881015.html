Issue

Error Message

warning snmpd[<PID>]: 010e0002:4: Establishing new connection to MCPD server

In this error message, note the following:

  • <PID> is the process ID for the snmpd process.

For example:

warning snmpd[6978]: 010e0002:4: Establishing new connection to MCPD server

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The snmpd process successfully establishes a new connection to the mcpd process.

When the BIG-IP system starts, the snmpd process attempts to create a connection to the Master Control Program Daemon (MCPD) for internal messaging. This message is generated each time a communication channel is established between the alertd and mcpd processes.

Impact

None. This message is informational.

Recommended Actions

None
