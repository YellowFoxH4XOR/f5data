Issue

Error Message

crit perl[<PID>]: 01310027:2: ASM subsystem error (<process>,<function>): <error>

In this error message, note the following:

  • <PID> is the process ID for the perl process
  • <process> is the process that encountered the error
  • <function> is the operation being performed at the time of the error

For example:

crit perl[17425]: 01310027:2: ASM subsystem error (learning_manager.pl,main::invoke_learning): Unable to retrieve runtime info

Message Location

You may encounter this message in the following location:

  • The /var/log/asm file
Description

This message occurs when the following condition is met:

  • The BIG-IP ASM subsystem encountered a fault in one of the control plane processes.

This error message is generated when one of the BIG-IP ASM control plane daemons, such as asm_start, asm_config_server.pl, asmlogd, or asmcrond, encounters a fault.

Impact

Control plane functionality for the BIG-IP ASM system is degraded and the affected processes may restart. In some cases, the BIG-IP ASM system may be unable to process traffic and may fail over if configured for high availability (HA).

Recommended Actions

  • You should review log files for related messages and issues that may have preceded this event. 
  • Review the /shared/core/ directory for core files that occurred during the time of the logged messages. For more information about core files, refer to K10062: Working with BIG-IP core files.
