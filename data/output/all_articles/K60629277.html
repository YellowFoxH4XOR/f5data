Description

Download button for  Windows BIG-IP Edge Client Package is grayed out after upgrade from 11.6.1-HF1 to 12.1.2-HF1

Environment

  • BIG-IP APM
  • After upgrade to 12.1.2
  • Edge Client for Windows
  • Phonebook entry containing invalid characters

Cause

Beginning in 12.0.0, the BIG-IP Configuration Utility will prompt you with the following error when attempting to use invalid characters:

Valid characters are a-z A-Z 0-9 ' _ - and space

If a Phonebook Entry was created in a version prior to 12.x and then the BIG-IP is upgraded, the option for Download will be greyed out until the invalid characters are removed.

F5 Product Development tracked this change as ID 455640.

Recommended Actions

Removing the invalid symbols from the Phonebook entry
  1. Navigate to the EdgeClient download dialog page Access Policy > Secure Connectivity > [Profile] > Customize Package button > Windows
  2. Select the Available Components item found in the left pane of the dialog box:
  3. Check Dialup Entry/ Windows Logon Integration
  4. Click on Dialup Settings found in the left pane of the dialog box:
  5. Phonebook Entry Name field, edit/delete all dots "." and/or invalid symbols, or completely remove the text.
  6. The Download button should now be available.
