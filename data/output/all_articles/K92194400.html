Description

After a certificate was renewed and installed for a virtual server, it's working fine in IE but not working in Google Chrome browser.

  • Getting certificate untrusted message in Chrome

Environment

Certificate was changed recently

  • The new certificate doesn't have Subject Alternative Name (SAN) field or is empty.
  • This certificate is valid and working without issue in Internet Explorer (not Edge)

Cause

This is because modern browsers require Subject Alternative Name field to be populated along with CN field. If SAN is left empty, old browsers like Internet Explorer 11 will work. But Chrome, Firefox will not accept the certificate if hostname is not present in SAN. 

Recommended Actions

There is workaround which can be performed on the BIG-IP. Generate a new CSR with SAN field containing all domains as that of CN field and after signing it install it to the virtual server to resolve the issue. If the certificate was imported along with the private key, please make sure that the certificate contains SAN filed as well.
