K8631: Network Access favorites do not appear when using Windows Mobile 5 or 6

Topic

The FirePass controller supports Network Access functionality for Windows Mobile 5 and 6 devices through the F5 Networks SSL VPN Agent.  When a Windows Mobile user logs into the FirePass controller, the user's webtop will display a link for Network Access, but not Network Access favorites. Clicking on the link will present a page from which the F5 Networks SSL VPN Agent can be downloaded and installed.  Once installed, the F5 Networks SSL VPN Agent is configured with the URL of the FirePass controller that provides Network Access functionality.  Additionally, the networks and resources tunneled over the SSL VPN are configured in Windows Mobile Settings. Thereafter, whenever an application generates network traffic to a configured network or resource, the F5 Networks SSL VPN Agent is automatically started, and used to provide Network Access functionality.

Note: In order for the F5 Networks SSL VPN Agent to be automatically invoked, the application generating the network traffic must be compatible with the Microsoft Windows Mobile Connection Manager. For applications that are not compatible, the F5 Networks SSL VPN Agent must be started manually, prior to the application's network requests.

Because the F5 Networks SSL VPN Agent and Windows Mobile provide the configuration for the Network Access, normally a user who logs into the FirePass webtop with a Windows Mobile 5 or 6 device will not see Network Access favorites listed under the Network Access section, even if the user's master group is configured with one or more Network Access favorites.  Any Network Access favorites associated with the user's master group are displayed only when the user is employing a full browser running on a non-PDA operating system.

If Network Access favorites appear on the webtop of a Windows Mobile 5 or 6 user, the User Agent string transmitted by the browser (such as Internet Explorer Mobile) may not be recognized by the FirePass controller. The User Agent string can be associated with PocketPC-style browsers on the Device Mangement: Configuration: New Browsers page of the Administrative Console. 

For more information, refer to K8630: Overview of User-Agent string mapping to webtop type.

Network Access favorites that do appear on a Windows Mobile 5 or 6 user's webtop will not provide Network Access. Network Access favorites do not invoke the F5 Networks SSL VPN Agent.
