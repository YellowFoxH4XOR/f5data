Known Issue

This is the result of a known issue. Beginning with BIG-IP 9.4.2, the BIG-IP ASM introduces BIG-IP ASM path cookies. When the web server issues domain cookies that specify the same cookie name, but different path arguments, the cookies will be encoded in the relevant BIG-IP ASM path cookie.

If the BIG-IP ASM path cookie is modified by an attacker, the BIG-IP ASM system should log the following violation message to the /var/log/asm file:

Modified ASM cookie(s)

Instead, the BIG-IP ASM system incorrectly logs the following violation message:

Modified domain cookie(s)

F5 Product Development tracked this issue as CR85701 and it was fixed in BIG-IP 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.
