Description

After an upgrade, you notice all OSPF dynamic routes are missing from the routing table. However, they are still showing on the OSPF database.

You can also find similar logs on /var/log/zebos-rd.log

informational: OSPF Instance Id [1]: SPF[0.0.0.0]: Calculation timer scheduled (delay 0.500000 secs)
informational: OSPF Instance Id [1]: SPF[0.0.0.0]: Calculation timer scheduled (delay 0.500000 secs)
informational: OSPF Instance Id [1]: SPF[0.0.0.0]: Calculation timer scheduled (delay 0.500000 secs)

Environment

  • Using OSPF routing
  • After upgrage

Cause

Bug ID 910201: OSPF - SPF/IA calculation scheduling might get stuck infinitely

Recommended Actions

If you suspect your system is affected by this ID, please open a case with F5 support and reference this support solution. F5 support will provide you with an Engineering HotFix to correct this ID on currently affected versions.   

Additional Information

To see if the routes are on the routing table:

zebos -a cmd show ip ospf route

To see if the routes are on the OSPF database:

zebos -a cmd show ip ospf database
