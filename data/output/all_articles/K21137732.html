Description
Customer is unable to see ASM event charts in Monitoring --> Reports --> Security --> Web Application Security.

Environment

  • BIG-IQ 7.x
  • BIG-IP ASM 

Cause
The Monitoring --> Reports --> Security --> Web Application Security form has been deprecated.

Recommended Actions

  1. Monitoring --> Dashboard --> Web Application Security is the correct location to see the ASM report data now.

Additional Information
Bug ID761873 has been filed to remove the deprecated page from the BIG-IQ user interface.
