Description
When you boot Maintenance Operating System (MOS) using 16.1.2 ISO image, you can't run diskinit.

switch_root:/# diskinit --style=volumes
info: The following disks will be modified: HD1
info: The disks are currently in the requested "volumes" format.
***
*** WARNING:
*** All software and data on this system is about to be destroyed!
*** No bootable software images will remain.
*** You will then need to install software to the system before
*** it will again be bootable.
*** (it is always possible to boot from USB devices)
***
Ready to reformat.  Continue? (y|n) [n] --> y

You don't get any response after you answer y or n.

Environment

  • You boot MOS using 16.1.2 ISO image and run diskinit command.

Cause
This is a regression of ID 1036609 which is fixed in 16.1.2. This issue doesn't occur when you are using 16.1.1 or older ISO. F5 re-opened ID 1036609 because of this regression.

Recommended Actions

You can use 16.1.1 or older ISO to run diskinit on MOS.
