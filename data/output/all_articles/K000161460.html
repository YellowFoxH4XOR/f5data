Description

API endpoints and application pages are inaccessible when accessed via custom ports (e.g., 7176, 7173, 7195) through a BIG-IP LTM virtual server. Pages fail to load , while traffic on port 443 works without issue. Packet captures show the BIG-IP responds with [F5RST: No server selected] for custom port traffic. The Host header for custom ports includes the port (e.g., Host: test.com:7176), causing LTM policy hostname-only matching to fail and no pool to be selected.

Environment

  • Product: BIG-IP LTM
  • Version: 17.1.3
  • Virtual server configured for port 443 and multiple custom ports (e.g., 7176, 7173, 7195, etc.)
  • LTM policies forwarding traffic to pools based on HTTP Host header matching
  • Backend nodes serving traffic on custom ports

Cause

The LTM policy rule used a hostname-only matching condition. When clients connect via a non-standard port, the HTTP Host header includes the port number (e.g., test.com:7176). The hostname-only condition does not match this value, so no pool is selected and the BIG-IP resets the connection with [F5RST: No server selected].

Recommended Actions

Update the LTM policy to match both the hostname and the custom port in the Host header:

  1. In the LTM policy rule, add a condition for the hostname (e.g., test.com).
  2. Add a condition for the port (e.g., 7195, 7176, 7173, etc.) as a list.
  3. Set the action to forward to the appropriate pool.
  4. Create a separate policy rule for port 443 to ensure continued accessibility.
  5. Test the application after policy changes and sync the configuration to peer devices.

Additional Information

  • Per RFC 7230, HTTP clients include the port number in the Host header when connecting to a non-standard port.
  • Port 443 is typically omitted from the Host header, so hostname-only LTM policy conditions work for port 443 but not for custom ports.
  • The [F5RST: No server selected] reset message indicates that the BIG-IP virtual server received a connection but no policy rule or iRule selected a pool or target for the traffic.
