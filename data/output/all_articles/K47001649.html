K47001649: Experiencing Blank Configuration Utility Pages and Observing 403 Codes on the Background Requests

Type
Support Solution
Published
2021-11-19
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.X.X, 15.1.X, 15.0.X, 14.1.X, 14.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 14.X.X, 15.0.1, 15.0.0, 14.1.5, 14.1.4, 14.1.3, 14.1.2, 14.1.0, 14.0.1, 14.0.0, 15.1.0
Source
https://my.f5.com/manage/s/article/K47001649

Description

  • Your Configuration Utility (WebUi) might be blank on one or multiple pages.

  • You may find some of the requests are showing HTTP response code 403 in web browser developer tools by using  K10370211: Generate an HTTP Archive using a browser
    For example, if you click any of the red-highlighted failed requests, you will find a general message like below:

Request URL: https://<GUI_IP_addr>/restui/default/js/session-authn.js
Request Method: GET
Status Code: 403 Forbidden

  • You may find similar log messages in the log file /var/log/httpd/httpd_errors:

Nov  1 00:00:00 bigip.ltm.local err httpd[<PID>]: [rewrite:error] [pid <PID>] [client <ip_address>:<port>] AH00670: Options FollowSymLinks and SymLinksIfOwnerMatch are both off, so the RewriteRule directive is also forbidden due to its similar ability to circumvent directory restrictions : /usr/local/www/restui/default/js/session-authn.js, referer: https://<ip_address>/<path>

Environment

  • BIG-IP LTM
  • Configuration Utility or WebUI
  • Blank Configuration Utility pages
  • You have customized httpd include configuration with RewriteEngine On configuration

Cause

While the RewriteEngine On is set for the httpd, the Options +FollowSymLinks, or equal setting Options +SymLinksIfOwnerMatch, must be enabled. This configuration may be introduced as a result of performing workaround in  K74566933: How to disable HTTP OPTIONS method at global level for the Configuration Utility

Recommended Actions

You may use the below command to check whether the RewriteEngine On is in use or not:

tmsh list sys httpd include

For example, you may observe the below configuration output that has the option in use:

sys httpd {
    include "
        <Location />
            RewriteEngine On
            RewriteCond %{REQUEST_METHOD} ^(OPTIONS)
            RewriteRule .* - [F]
        </Location>
        <Directory /usr/local/www/rrdstats>
            Options +SymLinksIfOwnerMatch
        </Directory>
        <Directory /usr/local/www/mcpq>
            Options +SymLinksIfOwnerMatch
        </Directory>
        <Directory /usr/local/www/rtstats>
            Options +SymLinksIfOwnerMatch
        </Directory>
        <Directory /var/www/tmui/tmui/system/stats/images>
            Options +SymLinksIfOwnerMatch
        </Directory>
        "
}

You may add a Directory section to append the Options +SymLinksIfOwnerMatch. For example, if you find the error log message like below:

Nov  1 00:00:00 bigip.ltm.local err httpd[<PID>]: [rewrite:error] [pid <PID>] [client <ip_address>:<port>] AH00670: Options FollowSymLinks and SymLinksIfOwnerMatch are both off, so the RewriteRule directive is also forbidden due to its similar ability to circumvent directory restrictions : /usr/local/www/restui/default/js/session-token.js, referer: https://<ip_address>/<path-of-the-page-you-are-accessing>

You can find the restriction directory /usr/local/www/restui/ in the log messages, so you can use the steps below to insert the Directory sections.

  1. Login to the TMSH utility.
    tmsh 

  2. Edit the sys httpd  configuration.
    edit sys httpd 

  3. Press i to insert.

  4. Append the below section at the end of the include section.
    <Directory /usr/local/www/restui>             
           Options +SymLinksIfOwnerMatch
    </Directory>

  5. Press ESC, : and wq, choose y for the coming prompt.

  6. Now the full include configuration section should look like:
    Note: this configuration can be synced within your clusters automatically while you're performing synchronization.
    sys httpd {
        include "
            <Location />
                RewriteEngine On
                RewriteCond %{REQUEST_METHOD} ^(OPTIONS)
                RewriteRule .* - [F]
            </Location>
            <Directory /usr/local/www/rrdstats>
                Options +SymLinksIfOwnerMatch
            </Directory>
            <Directory /usr/local/www/mcpq>
                Options +SymLinksIfOwnerMatch
            </Directory>
            <Directory /usr/local/www/rtstats>
                Options +SymLinksIfOwnerMatch
            </Directory>
            <Directory /var/www/tmui/tmui/system/stats/images>
                Options +SymLinksIfOwnerMatch
            </Directory>
            <Directory /usr/local/www/restui>              
                Options +SymLinksIfOwnerMatch
            </Directory>
            "
    }

  7. Restart the httpd process following the below command.
    Note: this should have no traffic impact on your system, the Configuration Utility will be unavailable shortly during the restart.

    bigstart restart httpd

  8. Force refresh your Configuration Utility to test the result
