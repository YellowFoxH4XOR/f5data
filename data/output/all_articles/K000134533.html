Description

  • SAML authentication request to BIG-IP as IdP fails
  • BIG-IP logs message in /var/log/apm:

... SAML SSO: Error(16) Signature verification failed for SAML Authentication Request

 

Environment

  • BIG-IP with APM acting as IdP
  • External SP connector has "Require Signed Authentication Request" unchecked and no "Signing Certificate" selected
  • Client sends signed SAML AuthN request

Cause

Even though the BIG-IP is configured with "Require Signed Authentication Request" unchecked, it will try to verify a SAML request if it it arrives signed. For that it needs to have the matching certificate selected for the external SP connector ("Security Settings" --> "Signing Certificate"). The certificate should be included in the SAML request and can be extracted from there.

 

 Recommended Actions

  1. Extract the certificate from the signed SAML request
  2. Import the certificate to the BIG-IP
  3. Check "Security Settings" --> "Require Signed Authentication Request" for the external SP connector
  4. Select the certificate under "Security Settings" --> "Signing Certificate"
  5. Uncheck "Security Settings" --> "Require Signed Authentication Request"
  6. Save the changes
