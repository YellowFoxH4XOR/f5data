Known Issue

This is the result of a known issue.The Data Guard component in BIG-IP ASM does not recognize credit card numbers from Bankcard or Maestro Cards (Switch / Solo). Although these cards use valid Luhn numbers, the BIG-IP ASM does not recognize the specific prefixes.

The card prefixes that will not be matched are:

ProviderPrefixExample of valid card number
Bankcard56105610591081018250
Switch / Solo / Maestro6334, 6333, 63046331101999990016

Note: For more information about matching credit card numbers with the Data Guard feature, refer to K8638: Data Guard credit card matching.

F5 Product Development tracked this issue as ID 337419, and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1789.0-HF2, which has been issued for BIG-IP 10.2.0. You may download this hotfix or later versions of the cumulative hotifx from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
