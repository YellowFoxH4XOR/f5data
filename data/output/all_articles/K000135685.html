Description

The gtmd agent on BIG-IP DNS uses the iQuery protocol to communicate with the local big3d agent, and the big3d agents installed on other BIG-IP systems. To authorize communications between BIG-IP systems, perform the following tasks on the Recommended Action section.
 

Environment

  • BIG-IP DNS
  • gtmd agent
  • iQuery protocol
 

Cause

None
 

Recommended Actions

On BIG-IP DNS, you create a server object to represent the BIG-IP DNS system itself.

1. On the Main tab, click DNS > GSLB > Servers. Click Create.
2. In the Name field, type a name for the server.
3. From the Data Center list, select the data center where the server resides.
4. For the Devices setting, click Add.
    a. Type a name in the Device Name field.
    b. Type a non-floating IP address in the Address field.
    c. If you use NAT, type an internal (private) IP address in the Translation field, and then click Add.
    d. Click Add. Click OK.
5. In the Health Monitors setting, assign the bigip monitor to the server by pressing "<<" to move it from the Available list to the Active list.
6. You can configure the other settings or leave it in default values.  
7. Click Finished.

Then, you need to define another server object to represent the other BIG-IP DNS system.
Repeat the steps 1-7 above.

 

Additional Information

Running the bigip_add script
You run the bigip_add script on the BIG-IP DNS system when you are installing on a network that includes other BIG-IP systems of the same version. This script exchanges SSL certificates so that each system is authorized to communicate with the other. You now have an implementation in which the BIG-IP systems can communicate with each other via iQuery.

Running the gtm_add script
You run the gtm_add script on the BIG-IP DNS system when you are adding to your network to acquire the configuration settings from a BIG-IP DNS system that is already installed on your network. The new BIG-IP DNS system that you added to the network will be part of a BIG-IP DNS synchronization group.
