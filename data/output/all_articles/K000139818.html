K000139818: No debugging symbols found with NGINX plus

Type
Support Solution
Published
2024-05-29
Updated
2024-05-30
Applies to
  • NGINX Products
  • NGINX Plus: R29
Source
https://my.f5.com/manage/s/article/K000139818

Description

  • You followed guide provided for use of gdb debugger following documentation
  • However, when attempting to debug, you encountered the below error
Reading symbols from /usr/sbin/nginx-debug...
(No debugging symbols found in /usr/sbin/nginx-debug)

Environment

  • NGINX Plus
  • gdb debugger
  •  Debugging

Cause

  •  Nginx Plus debug binary is delivered without debugging symbols. This causes issues for the OS debugger gdb when a more complex debug activity is required. 

Recommended Actions

  • Install the debugging symbols for nginx plus, depending on your platform -
    • ubuntu
           apt install nginx-plus-dbg
    • Centos/RHEL
           yum install nginx-plus-dbg
  • then stop and start nginx-debug
           service nginx stop && service nginx-debug start
  • gdb to the worker process will then indicate that the debug symbols for nginx plus have been loaded. For example -
           Reading symbols from /usr/sbin/nginx-debug...
           Reading symbols from /usr/lib/debug/.build-id/fb/7b3c731f653bd78b0a017e7ee61e99e61ca670.debug...

Additional Information

  • The NGINX Plus binary is stripped before being packaged for distribution. This ensures NGINX to be  compact, efficient, and secure executable.
  • Stripping a binary like NGINX Plus is a common practice aimed at optimizing the software for production use by reducing its size, enhancing performance, and improving security, though at the cost of more complex debugging. This article advises the method to provide those symbols when they are required
