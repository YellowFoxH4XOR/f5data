Known Issue

BIG-IP APM portal access rewrite of large cookie headers may trigger a memory leak.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with portal access.
  • Cookie headers rewritten by the BIG-IP APM system for the portal access application are larger than 1024 bytes.

Impact

The rewrite process memory usage increases and may eventually affect other services and overall system performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You notice a progressive increase in the amount of memory that the rewrite process uses.
  • The rewrite process produces a core file in the /shared/core directory.
  • The BIG-IP APM system unexpectedly fails over to another system in the device group.
