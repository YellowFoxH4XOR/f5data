Issue

Error Message

debug statsd[<PID>]: 011b0999:7: <action>: <message>

In this error message, note the following:

  • <PID> is the process ID for the statsd process
  • <action> is the operation being performed
  • <message> is a description providing details of the issue

For example:

debug statsd[5577]: 011b0999:7: updateRRDFile arg[1]='/var/rrd/bladeconnections'

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • An administrator enables debug level logging for the statsd process.

Impact

Verbosity of logging for the statsd process increases.  As a result, the size of the /var/log/ltm file may increase over time.

Recommended Actions

Setting the log level for the statsd process to debug can aid in troubleshooting services related to statistical data for the BIG-IP system. You should return the log level to the default value once troubleshooting is complete. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative affect on your system.

  1. Log in the the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Set the log level for the statsd process to the default value by typing the following command:

    modify /sys db log.statsd.level value warning
