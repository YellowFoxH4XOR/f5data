K000139123: The "system diagnostics ihealth config" command no longer accepts username and password parameters

Type
Support Solution
Published
2024-03-31
Updated
2024-03-31
Applies to
  • F5OS
  • F5OS-A: 1.7.0
Source
https://my.f5.com/manage/s/article/K000139123

Description

The system diagnostics ihealth config command no longer accepts username and password parameters.

These have been replaced with clientid and clientsecret.

Environment

  • F5OS
  • system diagnostics ihealth config

Cause

This is due to ID1305909 and ID1436373.

Recommended Actions

The iHealth upload service has changed its authentication schema to OKTA, and requires a Client ID and Client Secret rather than a Username and Password.

Additional Information

None.
