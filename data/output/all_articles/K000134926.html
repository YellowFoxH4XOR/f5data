K000134926: After upgrade to 16.1.3.4 client receives an error: /my.logout.php3?errorcode=25

Type
Support Solution
Published
2023-06-06
Updated
2023-06-07
Applies to
  • BIG-IP
  • BIG-IP APM: 16.1.3, 15.1.8
Source
https://my.f5.com/manage/s/article/K000134926

Description

After the upgrade to BIG-IP version 16.1.3.4 You observed the Access Policy returning logout page "/my.logout.php3?errorcode=25" when getting the logon page. This issue affects Windows and MacOS systems but it does not occur on Linux systems.

Environment

  • BIG IP 16.1.3.4
  • APM
  • iRule with TCL syntax
  • Upgrade
  • MacOS
  • Windows 10

Cause

At least one TCL error found for an iRule , which is assigned to virtual server.

Recommended Actions

Correct the iRule TCL syntax as per following article:

K13905: Error Message: 01220001:3: TCL error:
