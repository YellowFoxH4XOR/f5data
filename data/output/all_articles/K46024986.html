Description

Running a PEN test against APM flags Litespeed Web Server Source Code Disclosure Vulnerability (CVE-2010-2333 )

Environment

  • APM
  • Virtual server with associated access policy 
  • Penetration test

Cause

  1. You are using nmap script "litespeed web server source code disclosure" (https://nmap.org/nsedoc/scripts/http-litespeed-sourcecode-download.html)
  2. What does the script do (full details here: https://svn.nmap.org/nmap/scripts/http-litespeed-sourcecode-download.nse):
  • it sends a HTTP GET request like GET /index.php\000.txt HTTP/1.1"
  • and if it gets a response "HTTP 200", it assumes that the server is vulnerable.

When you run it against an APM vs (that has a simple access policy, say on v16.1.2 build 0.0.18):

Recommended Actions

It is safe to ignore this.
F5 doesn't use Litespeed Web Server (CVE-2010-2333) for any of our products.
We are exclusively Apache HTTPD (BIG-IP/F5OS/Traffix) or NGINX (BIG-IQ/NGINX).
Refer K51874520: BIG-IP third-party software matrix (15.x)
