Description

Sync failed after you have configured a Security Logging Profile on a virtual server, showing errors similar to: 

(Sync Failed): A validation error occurred while syncing to a remote device. 
Sync error on F5_BIG-IP_02: Load failed from /Common/F5_BIG-IP_01 01070734:3: Configuration error: Modify of node attribute is not permitted.
Sync error on F5_BIG-IP_02: Load failed from /Common/F5_BIG-IP_01 01070712:3: Caught configuration exception (0), Values (/Common/Virtual_Server_01) specified for firewall virtual log profile (/Common/Virtual_Server_01)/(/Common/VS_Log_Profile): foreign key index (vs_FK) do not point at an item that exists in the database.
 

Environment

  • BIG-IP
  • Device Group with "Sync-Only" configuration
  • Security Logging Profile
  • Virtual Server

Cause

Both F5s have different objects configured (e.g. virtual servers, pools, etc.) either with different names or do not have the same number of virtual servers, or pools on the two F5s. 
 

Recommended Actions

Make sure both F5s have the same object configuration such as virtual servers, pools, nodes, etc.
