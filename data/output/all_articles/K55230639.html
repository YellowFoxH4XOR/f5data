K55230639: Auth Provider is not visible from BIG-IQ GUI

Type
Support Solution
Published
2021-03-31
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K55230639

Description

After configuring the Auth Provider (e.g. TACACS) on the BIG-IQ, it gets created but is not visible from the GUI. 
(System  ››  USER MANAGEMENT  ››  Auth Providers)

Because of this, BIG-IQ administrators are unable to create users for the desired remote auth provider.

Environment

  • BIG-IQ (CM or DCD)

Cause

Unknown at time of publication

Recommended Actions

1. Take a HAR (HTTP Archive) or httpwatch capture while reproducing the issue. Provide this to F5 Support for use with their analysis. 

2. Restart both tokumond and searchd using this command:
       
       # bigstart restart tokumond searchd

None
