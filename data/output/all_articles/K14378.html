General Information

Provide the following information when you open a case with F5 Support:

  • A full description of the issue, including the following:
    • The symptoms of the issue
    • The approximate time the issue first occurred
    • The number of times the issue has recurred
    • Any error output provided by the system
    • Steps to reproduce the issue
    • Any changes you made to the system before the issue first occurred
    • Any steps you have taken in an attempt to resolve the issue
  • A description of the impact that the issue is having on your site, using the following definitions:
    • Site Down

      Your network or application is down, or critical business functions have stopped due to the issue.

    • Site at Risk

      Your network or application is severely and negatively impacted by the issue.

    • Performance Degraded

      The performance of your network or application has been severely reduced due to the issue.

    • General Assistance Required

      The subject of the case does not currently impact your network or application.

  • The hours that you are available to work on the issue, and any alternative contacts who can work on the issue if you are not available
  • Remote access information, if possible

    Remote access to your network environment is important because it is the most effective method to collect information and troubleshoot technical issues. If you cannot provide remote access, F5 Technical Support will work directly with you to resolve the issue over the phone and through email; however, this approach can often be more time consuming and may require file transfers, replication, and additional testing.

Product-specific information

Collect the following information from the affected systems and provide the information when you open the case. For information about sending files to F5, refer to K000090853: Exchange files with F5 Support.

BIG-IQ configuration details to provide

  • The BIG-IQ version
  • The name and version of the device or devices, if applicable
  • The BIG-IP module that the BIG-IQ system is managing, such as APM or LTM, that you need help with. These are known as Services in the BIG-IQ system
  • The configuration objects you are deploying that are associated with the Service, if applicable
  • The name of the BIG-IQ Application that is deployed to a BIG-IP managed device, if applicable

QKView files

The qkview utility generates a file that contains the configuration files that F5 Technical Support most frequently needs when troubleshooting an issue. You should run the qkview utility on the BIG-IQ system before opening a case. F5 Support may also request QKView output files from one or more managed devices. For more information about qkview, refer to K12878: Generating diagnostic data using the qkview utility.

Log files

The QKView file contains 5 MB of log files from the BIG-IQ system. If the issue requires that you collect all system log files on the system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To run the qkview command and specify the file size allowed, use the -s option.

    For example, to specify no file size limit, enter the following command:

    qkview -s0

If you prefer to collect all system log files separately, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. Create a TAR archive named logfiles.tar.gz in the /var/tmp directory that contains all files in the /var/log directory, by entering the following command:

    tar -czpf /var/tmp/logfiles.tar.gz /var/log/*

Packet traces

If the issue involves the network, perform a packet trace while the issue is occurring and provide the packet trace when you open the case. For more information about performing packet traces with tcpdump, refer to K4714: Performing a packet trace and providing the results to F5 Technical Support.

UCS archives

If you cannot give F5 Technical Support remote access to your system, you must provide a user configuration set (UCS) archive of the current configuration. In some cases, UCS archives for managed systems may also be requested. For more information, refer to K4423: Overview of UCS archives.

Core files

Core files contain the contents of the system memory at the time a crash occurred. If the system is not responding and producing core files, the core files will be located in the /var/core directory. Submit any existing core files when you open the case. For information about identifying and submitting core files, refer to K10062: Submitting core files for analysis to F5 Technical Support.

Web browser information

For issues that occur while the user performs API calls using a supported web browser with RESTful ability to interact with the BIG-IQ system, you are required to provide information on the type and version of web browser, the error reported on the Developer Tool Console, and a screenshot of the error returned from the BIG-IQ system (if available). This information is required because the errors generated from an issue in the JavaScript console exist in the user's web browser and cannot be captured by the BIG-IQ system. Supported web browsers include Microsoft Edge, Mozilla Firefox, and Google Chrome. To retrieve the required information, perform the following procedure:

  1. To locate your web browser version, use the following instructions for your web browser:
    • For Microsoft Edge, go to Settings and more (...) > Settings.
    • For Mozilla Firefox, press the Alt or F10 key (for users with the hidden Firefox menu bar), and go to Help > About Firefox or Firefox > About Firefox on MacOS.
    • For Google Chrome, in the URL bar, enter chrome://version, and press Enter.
  2. Capture any logged error messages in the Developer Tools Console when you reproduce the issue. To access the Developer Tools Console, use the following instructions for your web browser:
    • For Microsoft Edge, go to Settings and more (...) > More Tools > Developer Tools.
    • For Mozilla Firefox, press the Alt or F10 key (for users with the hidden Firefox menu bar), and go to Tools > Web Developer > Web Console.
    • For Google Chrome, select Options and go to Tools > Developer tools or More tools > Developer tools.
  3. Save a screen shot of the fully expanded error message returned by the BIG-IQ system (if available).

BIG-IP Cloud Edition

BIG-IQ 6.0.0 and later is a component of BIG-IP Cloud Edition. For more information about the components that you may need to collect the previously mentioned data from, refer to K33431282: Overview of BIG-IP Cloud Edition components.
