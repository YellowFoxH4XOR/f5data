Known Issue

This is the result of a known issue. When you use the command line to make changes to members of a pool that are associated with a virtual server, the MCP process can incorrectly report the following:

member must be directly connected

The MCP validates the configuration prior to loading the configuration. When the error in validation occurs, the BIG-IP LTM reports the following error message:

BIGpipe: pool member creation error: 01070358:3: Pool <pool name> member <IP address> must be directly connected to this machine

F5 Product Development tracked this issue as CR65583, CR68131, and CR65648, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, and 9.3. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

You can work around this issue by editing the configuration file and then loading it. To do so, perform the following procedure:

  1. Create a backup of the bigip.conf file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.original

  2. Using a text editor, edit the bigip.conf file.
  3. Make the changes to the pool by adding or modifying the member.
  4. Save the changes.
  5. Load the changes by typing the following command:

    bigpipe load
