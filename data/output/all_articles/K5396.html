Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following articles:

  • K14783: Overview of the Client SSL profile (11.x - 12.x)

The BIG-IP LTM client SSL cache, alert, and handshake timeout values are as follows:

Cache timeout

The cache timeout specifies the maximum lifetime an entry will remain in the SSL session cache.

  • Specify

    This setting specifies the number of seconds an entry will remain in the SSL session cache. The default is 3600 seconds.
  • Immediate

    This setting specifies that entries in the SSL session cache will time out immediately.

    Note: Starting in BIG-IP version 10.0.0, the Immediate setting is no longer available. If you are running BIG-IP version 10.0.0 or later, configure the Specify setting instead.
  • Indefinite

    This setting specifies that entries in the SSL session cache will not time out.

    Important: F5 Networks does not recommend setting the cache timeout to indefinite, because longer cache timeout periods can increase the risk of SSL session hijacking. For more information, refer to K6767: Overview of the BIG-IP SSL session cache profile settings.

Alert timeout

The alert timeout is the time until a connection is reset after transmitting an alert or initiating an unclean shutdown.

  • Specify

    This setting specifies the number of seconds until a connection is reset after transmitting an alert or initiating an unclean shutdown. The default is 60 seconds.
  • Indefinite

    This setting specifies that the connection should not be reset after transmitting an alert or initiating an unclean shutdown.

Handshake timeout

The handshake timeout is used to specify shortened connection expiration timeouts during SSL session establishment.

  • Specify

    This setting specifies the number of seconds until a connection times out during SSL session establishment. The default is 60 seconds.
  • Indefinite

    This setting specifies that connections do not time out during SSL session establishment.

Note: For more information about the Client SSL profile, refer to K10167: Overview of the Client SSL profile (9.x - 10.x).
