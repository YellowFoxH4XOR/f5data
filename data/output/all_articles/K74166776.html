K74166776: Message about HSB LBB address XLMAC status update in log file

Type
Support Solution
Published
2022-04-20
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K74166776

Description

Messages similar to bcm56xxd[1]: 012c0012:6: HSB 13 HGM 0 LBB address 0xd8000000 XLMACs status updated to 0x80000001 are seen in file /var/log/ltm after tmm restart.

Environment

  • Big-IP Hardware
  • HSB
  • TMM restarted 

Cause

These log messages are informational and benign about bcm56xxd daemon and HSB altering address space and accompanied with HSB interface down/up messages and TMM restarts.

Recommended Actions

Nothing recommended during TMM restart as these messages are informational and benign.

If TMM has not recently restarted and Big-IP device is experiencing these messages, please open a support case.
