Topic

The BIG-IP Edge Client pop-up window may not render web pages that use the History API in JavaScript.

Description

The History API allows developers to navigate or manipulate users' browser history using JavaScript. Due to security concerns, the BIG-IP Edge Client explicitly does not support the use of the History API and may fail to render pages that reference the History API in JavaScript. This behavior is by design to limit security exposure to the BIG-IP Edge Client starting in APM Clients 7.1.7.

For example, if a login page uses the history.pushState method or the history.replaceState method in JavaScript, the BIG-IP Edge Client pop-up window (WebBrowser Control Instance) may fail to fully render the page.

To prevent this from occurring, remove any references to the History API in the code for the web page or contact the vendor providing the content to inquire about removing that code.
