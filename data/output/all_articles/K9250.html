Known Issue

This is the result of a known issue. If you install OPSWAT version 2.5.8 on the FirePass controller, and configure the Avast version 4.8 (ALWIL) antivirus check to not allow the logon page, users may fail the pre-logon check even if the ALWIL software is not older than the value set.

You can configure the ALWIL antivirus check to not allow the logon page by clearing the Database is not older than option on the Users: Endpoint Security: Pre-logon Sequence page.

This issue appears to be limited to users running Internet Explorer 7 (IE7 version 7.0.5450.4). The issue does not appear when using other releases of IE7, IE6 or FireFox.

F5 Networks Product Development is tracking this issue as CR104457. It is unclear at this time if this issue is the result of a bug in the browser or the ALWIL software.

Workaround

You can work around this issue by performing one of the following two methods:

  • Request your user to downgrade their IE7 browser to a version older than 7.0.5450.4.
  • Clear the database age check box on the Users: Endpoint Security: Pre-logon Sequence page.
