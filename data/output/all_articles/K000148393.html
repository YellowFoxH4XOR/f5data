K000148393: Adding an HTTP Analytics profile causes white spaces in the request

Type
Support Solution
Published
2024-12-02
Updated
2024-12-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.0, 15.1.3, 15.1.2, 15.1.1, 15.1.9, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.10
Source
https://my.f5.com/manage/s/article/K000148393

Description

You have noticed that after adding an HTTP Analytics profile to a virtual server, your response contains padding (0x20 or %20) and/or white spaces between lines. This behavior may result in exceeding URL length and cause errors. In HTTP Validation you may see following error:

"Unparsable request content. URL length: <value> exceeded maximum limit of: 2048"

Environment

  • BIG-IP
  • AVR Module

Cause

This behavior is intentional. AVR checks response header for Content-Type: text/html and body for <head> tag. When AVR sees the first segment of response data and sees Content-Type: text/html, it increases Content-Length size and the forwards it to the client. Later, all the body data comes in and AVR finds that there is no <head> tag, then AVR does not inject JS. Content-Length is already increased so AVR needs to send paddings (0x20 or %20) (the white space noticed) to match up Content-Length and actual body size.

Recommended Actions

There are 2 workarounds:

 

1. Disable CSPM injection for this particular URI or for a particular condition on the VS:

K13859: Disabling CSPM injection with iRules

 

or:

 

2. Disable "collect-page-load-time" feature on the analytics profile:

ltm profile analytics /Common/analytics_profile_41 {
app-service none
collect-geo enabled
collect-http-timing-metrics enabled
collect-ip enabled
collect-max-tps-and-throughput enabled
collect-page-load-time enabled             <--------
collect-url enabled
defaults-from /Common/analytics
description none
notification-by-snmp disabled
traffic-capture {
/Common/capture { }
}
}

In Configuration utility go to Local Traffic >> Profiles >> Analytics >> HTTP Analytics >> <profile_name> and deselect the Page Load Time option.

Click Update to save the change.
