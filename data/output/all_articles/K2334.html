Topic

The maximum character length of a message logged from a rule event varies per version as follows.

BIG-IP versions 4.5 PTF-04 through 4.6.4

Starting in version 4.5 PTF-04, the maximum number of characters logged for a rule is 63 for all literals; however, starting in version 4.5 PTF-05, strings may be strung together with the + operator.

For example:

log "this string" + "this string"

Would log the following:

<date><time> - this stringthis string

Note: You can also log information about the client and virtual server, such as client_addr (which will log the IP address of the client) or http_uri (which will log the URI the client sent in).

If you previously configured rules that contain literal strings longer than 63 characters, these rules may fail after you upgrade to BIG-IP 4.5 PTF-04. Rules that worked correctly in previous versions could produce the following error message:

In rule test: String literal too long (max 63 chars)

If you receive this error, F5 Networks recommends that you modify the rule syntax to use literal strings that contain less than 63 characters.

BIG-IP versions 4.5 through 4.5 PTF-03

In versions 4.5 through 4.5 PTF-03, the maximum number of characters logged for a rule event is 255.
