Issue

Error Message

err mcpd[<PID>]: 01071bad:3: The certificate (</PATH/Certificate>) can not simultaneously use a cert-validator (</PATH/OCSP_Profile>) and be configured as the trusted responders certificate of a cert-validator (</PATH/OCSP_Profile>).

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • </PATH/Certificate> is the path and the name of the certificate.
  • </PATH/OCSP_Profile> is the path and the name of the Online Certificate Status Protocol (OCSP) profile.

For example:

err mcpd[5697]: 01071bad:3: The certificate (/Common/MyCert.crt) can not simultaneously use a cert-validator (/Common/My_OCSP_Profile) and be configured as the trusted responders certificate of a cert-validator (/Common/My_OCSP_Profile).

Message Location

You may encounter this message in the following location[s]:

  • The /var/log/ltm file
  • Console
  • iControl
  • Configuration utility

Description

This message occurs when one of the following conditions is met:

  • The certificate already has a cert-validator configured, but you are trying to configure this certificate as a cert-validator's trusted responder or signer certificate.
  • The certificate is already a trusted responder or signer certificate of a cert-validator, but you are trying to assign a cert-validator to it.
