Known Issue

This is the result of a known issue. The End User Diagnostic (EUD) utility version 11.2 and later does not run on all BIG-IP 3400 platforms.

Note: This issue applies to only the initial release of the BIG-IP 3400 platforms that have the C62 system designator.

When you run EUD version 11.2 or later on a C62 platform, the system will display output that appears similar to the following example, and then stall:

------------------------------------------------

Booting 'End User Diagnostics'

root (hd1,0)
Filesystem type is fat, partition type 0xb

[Linux-bzImage, setup=0x1400, size=0x1710c9]
initrd /initrd.img.eud
[Linux-initrd @ 0x361be000, 0x1e31646 bytes]

------------------------------------------------

If you encounter this situation, you cannot use the EUD utility and you must reboot the system to allow the BIG-IP operating system to load.

To check if a BIG-IP 3400 platform has the C62 system designator, type the following command from the command line:

bigpipe platform

Workaround

To work around this issue, obtain a previous version of the EUD and start it from a USB thumb drive.

Requirements

  • One of the following previous versions of the EUD (Contact F5 Technical Support to obtain the appropriate file):
    • EUD_B-11.1.0544.0.im file
    • EUD-11.0.3.3.0.im file (This version of the EUD is required if the 3400 platform has a 20 GB hard drive. For information and to deterimine if your 3400 platform is affected, refer to SOL10265: A 3400 platform with a 20 GB hard drive may fail to boot to the End-User Diagnostics (EUD) software when EUD version 11.1.0 is installed.)
  • USB thumb drive (1 GB or larger)

Important: You must have direct access to a BIG-IP platform, as the steps in the following procedures require that you use the BIG-IP system to format and copy the EUD utility to the USB thumb drive.

Once you have obtained the appropriate EUD file from F5 Technical Support, perform the following procedures.

Load the EUD onto a USB Mass storage device

You can load a USB mass storage device from a BIG-IP system by mounting the IM file. To create a USB mass storage device on a BIG-IP system to startup the EUD, perform the following procedure:

Note: In the following procedure, the EUD_B-11.1.0544.0.im is used as an example.

  1. Download the IM file to the /var directory.
  2. Loopback mount the IM file by typing the following command:

    mkdir /tmp/eud; mount -o ro,loop /var/EUD_B-11.1.0544.0.im /tmp/eud

  3. Insert a USB mass storage device into the platform on which you mounted the IM file.
  4. Type the following command to run the mkdisk utility:

    cd /tmp/eud; ./mkdisk

  5. After you have completed the installation, remove the USB mass storage device from the BIG-IP system.

Startup the EUD from a USB mass storage device

You must use this method to run the EUD if you loaded a USB mass storage device.

  1. If the system is turned on, turn it off.
  2. Plug in the USB mass storage device.
  3. Turn on the system.
    The EUD boots.
  4. When the EUD starts, the EUD menu displays.

Note: For more information about the EUD utility and links to the latest release notes, refer to K7172: Overview of the End User Diagnostics software.
