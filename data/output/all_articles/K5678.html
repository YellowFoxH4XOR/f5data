Topic

In BIG-IP version 4.x, the ifconfig command can be used to display all of the IP addresses active on a system, including all virtual and floating self IP addresses.

In BIG-IP versions 9.x and later, the ifconfig command will only display the non-floating self IP addresses configured on the system. In BIG-IP versions 9.x and later, the Traffic Manager Microkernel (TMM) is responsible for handling and controlling all floating self and virtual IP addresses. The TMM is separate from the Linux kernel. Although the ifconfig command queries the Linux kernel for information, ifconfig command will not provide the information for virtual or floating self IP addresses, as TMM controls this information.

To display the virtual and floating self IP addresses from the command line, use the following commands:

bigpipe virtual show

This command displays all virtual IP addresses configured.

bigpipe self show

This command displays all self and floating IP addresses configured.
