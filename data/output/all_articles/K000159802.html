K000159802: License move for VE from VMWare to Nutanix is failing

Description

License move for VE from VMWare to Nutanix is failing with error:

err chmand[4851]: 012a0003:3: munmap failed, with error: Invalid argument and errno: 22

 

Environment

- license move

- Nutanix hypervisor

- error log in /var/log/ltm

012a0003:3: munmap failed, with error: Invalid argument and errno: 22


 

Cause

Known licensing issue affecting BIG-IP VE instances using UEFI boot mode on Nutanix hypervisor. The UEFI boot mode prevents proper SMBIOS hardware detection during license activation, causing the licensing system to fail to read the platform details.


 

Answer/Recommended Actions

Switch boot mode from UEFI to Legacy BIOS on the Nutanix hypervisor.
