K000161255: Orchestration Manager process crashed and restarted on both VELOS controllers

Description

The Orchestration Manager (OMD) process crashed and restarted on both VELOS controllers when enabling a partition.

Environment

  • F5OS-C 1.8.x
  • Enabling a partition

Cause

  • Bug ID 2290657: Orchestration Manager crash when partition configured with mgmt-vlans

This issue occurs when a partition is created with management VLANs (mgmt-vlans). For example:

partitions partition <partition> config iso-version <ver> enabled mgmt-vlans untagged mgmt-ip ipv4 address <mgmt-ip> prefix-length <prefix> gateway <gateway>

Recommended Actions

Create partition without mgmt-vlans, where possible:

partitions partition <partition> config iso-version <ver> enabled mgmt-ip ipv4 address <mgmt-ip> prefix-length <prefix> gateway <gateway>
commit

Alternatively, remove from existing partition:

no partitions partition <partition> config mgmt-vlans
