Description

The alert daemon monitors system error messages and triggers proper actions, such as sending snmptrap and displaying messages on the panel. when the system is not able to load the recent changes to /config/user_alert.conf file. the ltm logs will report over and over error logs similar to:

alertd[9984]: 01100021:3: Couldn't process the /config/user_alert.conf: problems at line <XX>.
alertd[9984]: 01100010:3: Couldn't load file /config/user_alert.conf

Environment

  • BIG-IP.
  • The system is configured with custom SNMP traps, for more info see: K3727

Cause

Syntax issues within /config/user_alert.conf file.

Recommended Actions

  • To resolve syntax issues, review the /var/log/ltm messages. Syntax issues are reported in messages that appear similar to the following examples:
alertd[9984]: 01100021:3: Couldn't process the /config/user_alert.conf: problems at line <XX>.

alertd[9984]: 01100010:3: Couldn't load file /config/user_alert.conf

  • The right format to add a comment within /config/user_alert.conf file is: /* comment */

Additional Information

  • K14397: Running a command or custom script based on a syslog message
