Topic

BIG-IP version 1.8 introduced extended syntax in order to make it easier to manage large configuration files. You can now contain configuration statements in curled braces, rather than using backslashes, to continue long lines.

When BIG-IP reads a configuration file and it encounters an open curled brace, BIG-IP treats all new lines as spaces until it reaches a closed curled brace.

For example, previously, a vip configuration statement could be written only as follows:

vip 172.16.22.10:80 define 10.90.100.1:80 10.90.100.2:80

Beginning in BIG-IP version 1.8, the same configuration statement can also take the following forms:

vip 172.16.22.10:80 define { 10.90.100.1:80 10.90.100.2:80 }

vip 172.16.22.10:80 define { 10.90.100.1:80

10.90.100.2:80

}
