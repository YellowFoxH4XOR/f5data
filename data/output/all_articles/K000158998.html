K000158998: GUI operation of Inspection Profiles can cause memory leak on icrd_child process

Type
Support Solution
Published
2026-01-05
Updated
2026-01-05
Applies to
  • BIG-IP
  • BIG-IP AFM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000158998

Description

GUI operations of Inspection Profiles can cause memory leak on icrd_child process. Due to the impact of the memory leak, sometimes it cause tmm to restart and increase the swap usage.

In order to assess the symptoms, it is suggested to use the command line operation examples as follow.


Example of the symptom #1 , Memory leak on icrd_child

  • Open a web browser tab to access BIG-IP AFM management access and click "Inspection Profiles"
  • Confirm the process ID of icrd_child by top command

[root@hostname:Active:Standalone] tmp # top -cb | grep icrd

19338 root   20  0 315264 85020 18952 S  0.0 0.5  0:05.21 icrd_child -p 8100 -l 2 -i 7adcfb80-bafa-4d51-b308-xxxxxxxxxxx -t 60

in this example, the process ID is 19338

  • Measure the consumed amount of memory at icrd_child process by reviewing the value of rss at tmctl command

[root@hostname:Active:Standalone] tmp # tmctl proc_pid_stat -s proc_name,modules,pid,command_line,rss pid=19338

proc_name modules  pid

---------- ------- -----

icrd_child mgmt  19338

command_line                           rss

--------------------------------------------------------------- -----

icrd_child -p 8100 -l 2 -i 7adcfb80-bafa-4d51-b308-xxxxxxxxxxx 21281

in this example, rss was recorded as 21281

  • Repeat the operations above and review the value of rss, if it increase higher than 21281


Example of the symptom #2 , Out of memory by icrd_child process

  • In BIG-IP AFM, the kernel log messages is recorded as similar to the following example at /var/log/kern.log 

MM DD HH:MM:SS hostname err kernel: Out of memory: Kill process 14911 (icrd_child) score 51 or sacrifice child

MM DD HH:MM:SS hostname kernel: Killed process 14911 (icrd_child) total-vm:2035076kB, anon-rss:1685800kB, file-rss:17420kB, shmem-rss:16kB


Example of the symptom #3 , Restarting icrd_child process

  • In BIG-IP AFM, the restjavad log messages is recorded as similar to the following example at /var/log/restjavad.log 

[I][XXX][DD MM YYYY HH:MM:SS UTC][ChildWrapper] Issuing SIGKILL command to the icrd_child process with PID: [30412] went successful

[I][XXX][DD MM YYYY HH:MM:SS UTC][ProcessManager] Spawned a new icrd_child (id: d6f3273d-074f-4b59-a592-ebc49fe3ac3e); current user: root



Environment

  • BIG-IP AFM is provisioned
  • Using GUI from management access
  • Opening multiple tabs of web browsers
  • Multiple times of clicking Inspection Profiles

Cause

F5 tracks this behavior as ID2048001


Recommended Actions

To apply a workaround. The recommended workaround is to use a single tab to avoid the leak of icrd_child process.
