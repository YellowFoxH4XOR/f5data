K000147633: Why do alerts show WAF security events but none are shown on the Security Dashboard of the HTTP LB?

What Happened?

The system is detecting potential security issues that are being caught in the Alert Dashboard (Web and API protections > Default > Notifications > Alerts) but they are not displayed on the Security Monitor of the HTTP Load Balancer (LB).

Environment

  • Web and API protection Alerts
  • Security Monitor

Resolution/Answer

When a system detects something that could be a security problem, it generates a record of that event, called a security event. The system then analyzes these events and generates an alert when it detects a pattern or behavior that could be a sign of a security issue.

The alert is a notification that is sent to IT or Security teams to let them know that something is happening that could require their attention.

To summarize, a security event is a record of something that might impact the security of a system, and an alert is a notification sent to IT or Security teams to inform them of potential security issues.

 

Additional Information

Sometimes, an alert might appear even when there's no actual security event. This could be due to a false alarm, a system error, or overly sensitive settings.
