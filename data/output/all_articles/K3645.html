Topic

F5 modifies the base host operating system and responds to all reported vulnerabilities for that base operating system. You must install only the patches that F5 supplies. For more information about the latest available versions of BIG-IP software and its point releases refer to the following articles:

  • K2200: Most recent versions of F5 software
  • K9502: BIG-IP hotfix and point release matrix

The BIG-IP system processes tasks in both the data plane, Traffic Management Microkernel (TMM) tasks, and control plane, non-TMM tasks; however, the Linux base host operating system is not involved in processing TMM tasks and all data plane traffic is processed by TMM.

In some versions, the BIG-IP system uses components from multiple CentOS versions. The BIG-IP custom Linux kernels are built based on 64-bit kernels only. The following table contains the base version information for the BIG-IP system.

Base host operating system support lifecycle

F5 provides support for the base operating system shipped integrated with F5 software via F5 software updates. This support includes security updates, bug fixes, vulnerability fixes, and mitigations for the base operating system. The F5 support lifecycle for the base operating system is the same as the containing product’s lifecycle. If the base operating system reaches its end of support or end of life before its F5 product counterpart, F5 will continue to offer support for the base operating system under the containing product’s support lifecycle.

For more information, refer to K000137849: What are F5 support plans for products when the base OS reaches End Of Life (EOL)
