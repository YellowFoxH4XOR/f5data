K11747: Normalization fails when OWS sends a Cache-Control header containing the must-revalidate directive

Known Issue

This is the result of a known issue. When an object is subject to URL normalization, but the origin web server responds with the must-revalidate directive in a Cache-Control header, the BIG-IP WebAccelerator sends the expected HTTP 302 Found response to the client, redirecting the client to the normalized URL. However, the BIG-IP WebAccelerator responds to the request for the normalized URL with an HTTP 503 Service Unavailable status, and a page containing the following error message:

Cannot retrieve normalized object

F5 Networks Product Development is tracking this issue as CR140062.

Workaround

You can work around this issue by disabling Content Based Identity for affected objects. For details on disabling Content Based Identity, refer to K8379: Overview of advanced assembly features for BIG-IP WebAccelerator policies or the BIG-IP WebAccelerator Policy Management Guide.
