K000152605: BIG-IP 17.5.1 unable to be discovered by BIG-IQ 8.4.0

Type
Support Solution
Published
2025-07-16
Updated
2025-12-10
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000152605

Description

When attempting to discover a BIG-IP 17.5.1 device with BIG-IQ 8.4.0 you see the below error message:

Error getting resource provisioning from /mgmt/tm/sys/provision on hostname.example.com (10.11.12.13), network communication failed due to protocol error

In the restjavad.0.log you see:

[WARNING][554][11 Jul 2025 16:50:11 UTC][com.f5.rest.common.RestWorker] dispatch to worker http://localhost:8100/tm/auth/remote-role caught following exception: java.lang.IllegalArgumentException: Version 17.5.0 is not supported.

Environment

  • BIG-IQ 8.4.0
  • BIG-IP 17.5.1

Cause

All REST calls from BIG-IQ version 8.4.0 are sent with schema ver=17.5.0 added to the request. Due to bug ID1983185, 17.5.1 does not believe itself to be compatible with version 17.5.0 requests.

Recommended Actions

Upgrade to BIG-IP version 17.5.1.2 or above (currently 17.5.1.3)
