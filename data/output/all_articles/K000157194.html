Description

When attempting to upload a BIG-IP tenant image to an F5OS device, users may encounter a "Verification Failed" error and the following message is logged to platform.log:

2025-10-28T14:36:56 appliance-1 image-agent[1]: priority="Err" version=1.0 msgid=0x2002000000000010 msg="Failed to verify image signature. Removed." IMAGE="BIGIP-17.1.3-0.0.11.ALL-F5OS.qcow2.zip.bundle" FAILURE="signature".

Environment

  • Product: F5OS-A, F5OS-C
  • Attempted Image Format: qcow2.zip.bundle

Cause

In October 2025, F5 rotated its signing certificates and keys. As described in K000157005, this means:

  • Tenant images released after Oct 2025 use new cryptographic signatures.
  • Older F5OS cannot validate the signatures for the qcow.zip.bundle images; newer hosts may not validate old ones.
  • On F5OS-A 1.7.0 and later and all supported F5OS-C versions, only use the tar.bundle image format for deploying new tenants.
  • On F5OS-A 1.5.4, use the qcow2.zip.bundle image format for deploying new tenants.
  • The failure message indicates signature verification failed due to this incompatibility.

See full details at K000157005 - F5 signing certificate and key rotation, October 2025.

 

Recommended Actions

  • Use only .tar.bundle files for tenant installs on current releases.
  • If you see signature verification errors ("Verification Failed"), check both your host version and file format.
  • If needed, upgrade your host OS to a version released in October 2025 or later per KB guidance.
  • Review K000157005 for compatibility tables & further troubleshooting steps.
