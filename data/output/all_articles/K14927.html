Known Issue

The BIG-IP APM system does not rewrite cross-domain URIs requested with the XDomainRequest object.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access using HTTPS.
  • The virtual server is configured with a rewrite profile.
  • JavaScript in the web application uses the XDomainRequest object for cross-domain HTTP requests.
  • The client system is using Internet Explorer 8 or 9.

The XDomainRequest object allows for cross-domain AJAX requests using Internet Explorer 8 and 9. When the BIG-IP APM system is configured for portal access using HTTPS, the system does not rewrite HTTP schemes for HTTP requests generated by the XDomainRequest object. As a result, the requests will fail.

Impact

Cross-domain requests using the XDomainRequest object in JavaScript fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You view Access denied error messages in the browser when requesting portal access objects.
  • Web page objects fail to load or refresh in the browser when using portal access.

Workaround

To work around this issue, you may be able to use an iRule to replace instances of the XDomainRequest object with the XMLHTTPRequest object. However, changes to the JavaScript may negatively affect the web application. F5 recommends that you test changes during a maintenance window with consideration to the possible impact on your specific environment.
