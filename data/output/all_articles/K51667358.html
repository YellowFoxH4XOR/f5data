Issue

Error Message

01900024: SCTP %s association (%F) path %F restored

In this error message, note the following:

  • <%s> is the Stream Control Transmission Protocol (SCTP) association established between two endpoints.
  • <%F> is the path used to transfer data between the SCTP endpoints.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The path used to transfer data between the SCTP endpoints has been restored.

After peers establish a SCTP association, the BIG-IP systems exchange heartbeat packets between all IP addresses to determine the optimal network path to use for communication. The BIG-IP systems select primary and secondary network paths over which to exchange data. When one of the established paths fails and is later restored, the BIG-IP system logs the above error message.

Impact

There is no impact. The message is informational and can be safely ignored.

Recommended Actions

None
