Description

When deploying an AS3 declaration with a large number of tenants (partitions), a warning similar to the following is returned:

"AS3 was unable to verify that the configuration was persisted. To avoid this issue in the future, try increasing the following DB variables: icrd.timeout, restjavad.timeout, restnoded.timeout"

 

Log message similar to the following precedes the core dump message in /var/log/user.log or /var/log/messages:

err icrd_child[{pid}]: *** buffer overflow detected ***: icrd_child terminated

 

When this occurs, temporary files are left in /var/tmp/.config.tmp/{temp_folder_name} and never gets cleaned up. If this issue keeps re-occurring, /var/tmp/ will eventually run out of free disk space.

 

Environment

  • BIG-IP
  • AS3
  • Number of tenants (partitions) in the configuration is greater than 200. 

Cause

 

icrd_child abnormally exits. PD has assigned ID1036461 for this issue.

 

Recommended Actions

 

Options to workaround the issue:

 

a) If deploying an AS3 declaration, set persist=false in the declaration (this is set to true by default), then save the config using /mgmt/tm/util/bash iControl REST with the following JSON payload:

{
    "command": "run",
    "utilCmdArgs": "-c 'tmsh save sys config'"
}

 

b) If saving the config through iControl REST, use the /mgmt/tm/util/bash endpoint as described in option (a) instead of the REST endpoint /mgmt/tm/sys/config.

 

c) Install an EHF containing the fix for ID1036461.
