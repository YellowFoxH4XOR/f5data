Description

HA pair reverting to Changes Pending, seconds after a successful ConfigSync operation.

Environment

  • ConfigSync
  • ASM provisioned

Cause

One system in the device group is experiencing an inconsistent ASM configuration state, due to BUG ID 912149 and BUG ID 993613.

The /var/log/ts/dcc.log file on this unit contains no recent log messages, and does not log any messages when a configuration change is made (for example, applying a security policy or log profile to a virtual server).

After each ConfigSync, an inactive security policy is being reactivated, resulting in the Changes Pending state.

Recommended Actions

To work around this bug, restart the asm_config_serv process on all affected units:

pkill -f asm_config_serv

Then sync the configuration.

To resolve the issue, upgrade to a fixed version. Follow the Bug Tracker article links referenced previously to review which versions introduce a fix for each bug.

Additional Information

There may be other issues or known behaviour that causes Changes Pending to appear shortly after a sync, for example:

  • K92462725: BIG-IP ASM HA devices constantly showing "changes pending", even after performing a sync
  • K54207765: Changes pending status persists even after syncing for ASM sync group
