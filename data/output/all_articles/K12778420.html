Description

While updating SNMP trap destinations, you may see the following message in /var/log/ltm

HA daemon_heartbeat % snmpd disabled
HA daemon_heartbeat % snmpd enabled

Environment

  • BIG-IP
  • SNMP
  • Logs

Cause

When changes are made to SNMP configuration, the service is restarted. When the SNMP service is restarted you will see the log message.

Recommended Actions

These messages are informational and does not cause impact.

Additional Information

If these messages are too excessive and triggering snmp trap alerts to monitoring systems, these messages can be filtered out using the steps in the following article:

 

K35284961: Filtering BIG-IP log messages
