Known Issue

The Traffic Management Microkernel (TMM) may restart when processing traffic for a connection flow that has been suspended to process an iRule command.

This issue occurs when the following condition is met:

  • TMM receives a new packet for an existing connection flow that has been suspended to process a parking iRule command (such as table or after).

Impact

TMM may restart and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period of time.
  • The BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
