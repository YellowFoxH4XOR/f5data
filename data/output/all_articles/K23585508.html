Description

BIG-IP login events will not be logged by any remote logging configuration defined under High Speed Logging.

Environment

  • BIG-IP system configuring High Speed Logging. 

Cause

This is by design. 

Recommended Actions

  1. When you plan BIG-IP to send user login events to remote syslog servers, please refer to K13080. 
  2. When you plan BIG-IP to send user login events to either TACACS+ or RADIUS accounting server(s), please refer to K13762. 

Additional Information

None.
