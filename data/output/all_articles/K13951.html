Known Issue

When enabling configuration replication through the ARX management GUI, the password entered may be stored incorrectly.

Configuration replication was implemented in ARX 5.2.0 as a feature to facilitate the use of an ARX system as part of a disaster recovery solution. This feature allows you to replicate the ARX configuration to a remote ARX system in preparation for a disaster.

Impact

The configuration replication will not occur.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The replication fails with an authentication failure message in the ARX manager GUI.
  • Error messages will appear in the syslog similar to the following example:

NETSNMP-0-NOTE-MSG5:: SNMP TRAP: configReplicationFailRaise (38) name 'system-replication': 'Authentication failure'.

Workaround

To work around this issue, you can either use the CLI  or enter the correct password each time configuration replication is enabled in the GUI. To do so, perform one of the following procedures:

Enable configuration replication through the ARX CLI

To permanently work around this issue, you can enable config replication through the ARX CLI by performing the following procedure:

Impact of workaround: None

  1. Log in to the ARX CLI.
  2. Enable privileged mode by entering the following command:

    enable

  3. Enter global configuration mode by entering the following command:

    global

  4. Enable configuration Replication using the following command:

    config-replication [name] cluster [cluster-name]

    For example:

    ARX1(gbl)# config-replication Example2 cluster Examplecluster

  5. Exit the share configuration mode by entering the following command:

    exit

Specify the password when enabling through the GUI

To temporarily work around this issue, you can specify the password when enabling config replication through the GUI by performing the following procedure:

Note: This procedure will not permanently work around the issue. You must enter the password each time the Config Replication setting is configured.

Impact of workaround: None

  1. Log in to the ARX GUI.
  2. Navigate to Disaster Recovery and select Config Replication.
  3. Select the Recovery Cluster that you want to enable and click Edit.
  4. Enter the correct Username and password/password confirmation.
  5. Select the Enable check box.
  6. To commit the password and enable, click Save.
