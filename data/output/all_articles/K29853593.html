Description

Sync between 15.1.0.1 and 15.1.0.4 fails with the below error:

Sync error on host_name: Load failed from /Common/<peer_hostname> 01b9004f:3: User string contains unknown storage-field or extra '%' character in Application Security log profile '/Common/internal-remote-logger-cloud-security-services'.

NOTE: This error may occur when ASM is not provisioned/licensed.

Environment

  • BIG-IP
  • ASM/AFM do not have to be provisioned
  • V15.*
     

Cause

Default config should not be changed, but this minor version there is some difference for default profiles.
 

Recommended Actions

Upgrade other unit to same version.
 

Additional Information
