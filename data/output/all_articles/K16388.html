Known Issue

When you use the Configuration utility, Access Policy Sync functionality may not function properly.

This issue occurs when all of the following conditions are met:

  • There is a large number of BIG-IP APM devices configured in the device group, or the environment is experiencing WAN latency between devices.
  • You use the Configuration utility to run the Access Policy Sync functionality to synchronize BIG-IP APM access policies to the device group.
  • You attempt, again, to use the Configuration utility to run the Access Policy Sync functionality.

Impact

The Access Policy Sync functionality appears to be processing the previous synchronization request.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After you run the Access Policy Sync functionality using the Configuration utility, the system appears to have completed the synchronization, but some devices continue to display the Cancel policy sync button, as though synchronization is still in progress, blocking the system's ability to initialize a synchronization.
  • You are unable to delete access policies.
