Description 
Merge sync-only with sync-failover device group on ASM systems.
 

Environment

  • BIG-IP ASM 
  • Device groups configured
  • BIG-IP devices configured in high availability

Cause
Redundant use of device groups (sync-only and sync-failover)
 

Recommended Actions

  1. Navigate to Security  ››  Options ›› Application Security ›› Synchronization ›› Application Security Synchronization
  2. Select the failover-sync group
  3. click save 
  4. Remove the sync-only group
          4a. Navigate to Device management ›› device groups
          4b. Click sync-only group.
          4c. Move all members from includes to available 
          4d. click update 
  5. Repeat steps 1-4 on unit 2 
  6. Test that an ASM policy syncs with the sync-failover group
  7. Navigate to Security  ››  Application Security : Security Policies : Policies List
  8. Click create new policy
  9.  Name it sync-test the click create policy
  10. Click changes pending and sync group 
  11. Verify that the test group policy is sync to unit 2 
  12. On unit 1 remove the test policy and sync again.
