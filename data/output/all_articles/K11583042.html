Issue

Error Message

err clusterd[<PID>]: 013a0018:3: <Cluster member availability status>

In this error message, note the following:

  • <PID> is the process ID for the clustered process.
  • <Cluster member availability status> is the current availability status of the member being reported.

For example:

err clusterd[5936]: 013a0018:3: Blade 2 turned RED: Run, HA TABLE offline
err clusterd[5763]: 013a0018:3: Blade 1 turned RED: Quorum: waiting for lind, HA TABLE offline

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • A cluster member has transitioned to clusterd Availability State RED.

Impact

A cluster member is indicating that it has transitioned to Availability State RED. This coincides with the cluster member reporting a status of Slot Failed.

Recommended Actions

The afflicted cluster member that has transitioned to Availability State RED might require a reboot to restore cluster functionality. Before rebooting the affected cluster member, it is highly recommended to gather a QKView file of the BIG-IP system and using the iHealth diagnostic utility to check if your system may have some known issue that is causing the behavior to occur.

For more information on using the diagnostic utility, refer to K27404821: Using F5 iHealth to diagnose vulnerabilities

For information on shutting down and restarting a blade, refer to K98142338: Shutting down and restarting a single blade in a VIPRION system
