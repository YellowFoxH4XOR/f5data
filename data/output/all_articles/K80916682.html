K80916682: Adding support for a newly published Azure BIG-IP VE image version on the BIG-IQ system

Topic

You should consider using this procedure under the following condition:

  • You want to enable the BIG-IQ system to support a newly published Azure BIG-IP Virtual Edition (VE) image version in the Azure cloud environment.

Description

This article explains how to modify the restjavad properties to enable BIG-IQ 8.0.0 and later to support the latest image version for BIG-IP VE in the Azure Marketplace.

By default, the newly installed BIG-IQ system, running 8.0.0 or later, provides the restjavad properties file (restjavad.properties.json) with no property values in the JSON structured content. You can use this file to customize the restjavad properties according to the application environment. The customization setting configured in this file will overwrite the default settings, which are hardcoded.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have a valid Azure cloud environment configuration on the target BIG-IQ system.
  • You use the BIG-IQ system to deploy a new BIG-IP VE device to the Azure cloud environment.
  • You have Advanced Shell (bash) access to the BIG-IQ system with administrator credentials.

Procedures

By default, the restjavad properties file does not contain configuration stanzas for customizing the Azure environment on image versions. The system has a default list of the supported environment built-in and updated on each new BIG-IQ release. 

To view the supported list of BIG-IP VE versions, you can use the BIG-IQ system interface and navigate to Applications > ENVIRONMENTS > Cloud Environments, and select the BIG-IP Image Name drop-down list.

Important: If your restjavad.properties.json file does not contain the azure properties, refer to the Workaround section in K02972920: The restjavad.properties.json file does not contain F5-defined default properties after upgrading the BIG-IQ system using the ISO file of any of the versions from BIG-IQ 8.x.

Adding a new image version number

You can customize the restjavad properties file to support a new image version for Azure BIG-IP VE on the BIG-IQ system. To modify the file, perform the following procedure:

Impact of procedure: You must restart the restjavad process after you modify the property file as it will interrupt BIG-IQ services. F5 recommends performing this procedure only during a scheduled maintenance period.

  1. Log in to bash on the BIG-IQ system.

  2. Save a backup copy of the restjavad property file by entering the following command:

    cp -a /var/config/rest/config/restjavad.properties.json /shared/tmp/restjavad.properties.json.backup_K80916682

  3. Use a file editor to edit the /var/config/rest/config/restjavad.properties.json property file.
  4. Look for the azure section in the file. In BIG-IQ 8.0.0, the Azure configuration stanza appears similar to the following example:

    "azure" :
    {
         "instanceTypes" :
         {
         },
         "ssgMonitoring" :
         {
         },
         "polling" :
         {
         }
    }

    Note: In BIG-IQ 8.0.0, the images configuration stanza for Azure may not exist in the /var/config/rest/config/restjavad.properties.json file, however customization is still permissible by adding the image stanza with the required configuration.

  5. To add new image version, add the images configuration stanza within the Azure stanza.

    For example, you want to add BIG-IP 16.0.1 to the images configuration stanza above the instanceTypes line entry:

            "images" :
            {
                 "includeImageVersions": [ "16.0.100000" ]
            },

    Important: You must include the trailing comma ( , ) in the remaining configuration stanzas if you append the new stanza before an existing stanza. However, if you add the new stanza to the end of a previous stanza, you need to add a trailing comma to the prior stanza before appending the new stanza. If the new stanza is the last, you are not required to have a trailing comma.

    After you add the images stanza, the azure section appears similar to the following example:

        "azure" :
        {
            "images" :        
            {
                "includeImageVersions": [ "16.0.100000" ]        
            },
            "instanceTypes" :
            {
            },
           "ssgMonitoring" :
           {
           },
           "polling" :
           {
           }
        }

  6. After you save the changes, you must restart the restjavad service by entering the following command:

    tmsh restart /sys service restjavad

    Once the BIG-IQ system resumes service, you can see the newly added Azure BIG-IP VE version when you create a new cloud environment for Azure.
