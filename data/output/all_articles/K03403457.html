K03403457: Telemetry streaming stops working

Description

Telemetry streaming stops publishing data or fails after being successfully configured.

Environment

  • Bigip GTM
  • Telemetry Streaming configured

Cause

An incorrect pool in a cname pool can cause telemetry to fail

gtm pool cname /Common/CNMAMEPOOLNAME{
    members {
        https://hostname {
            member-order 0
            static-target yes
        }
    }
}

In /var/log/restnoded/restnoded.log you will see a message similar to this:

Wed, 27 Oct 2021 20:47:08 GMT - severe: [telemetry] systemPoller:safeProcess unhandled exception in promise-chain
Traceback:
Error: Bad status code: 404 Not Found for http://localhost:8100/mgmt/tm/gtm/pool/cname/~Common~CNAMEPOOLNAME/members/stats
 

Recommended Actions

Correct the cname pool member name. The solution here was to take off the https:// prefix, but it is possible that other mistyped cname pool name member names could cause the same issue.
