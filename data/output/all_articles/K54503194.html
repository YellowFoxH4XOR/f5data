Topic

This article applies to the the management of Domain Name System (DNS) on a MacOS client after connecting to BIG-IP APM network access.

Description

The BIG-IP APM network access resource contains a list of DNS-related settings that allow you to control the behavior of DNS on a client device when your users connect to a VPN. It is important to note that not every DNS setting in the network access resource is supported on MacOS clients. For a list of supported DNS settings on MacOS, refer to the General settings, Split tunnel settings, and DNS/hosts settings tables in K23653432: BIG-IP APM client feature matrix. The following sections explain the DNS related settings in BIG-IP APM network resource.

DNS address space in full and split tunnel modes

In full tunnel mode, all DNS requests are sent to the name servers configured in the network access resource.

In split tunnel mode, you must explicitly configure the DNS Address space setting for the DNS request to target the name servers defined in the network Access Resource. DNS requests for domain names defined in the DNS Address Space setting are sent to the name server you configured in the network access resource, while the remaining requests are sent to to the local name server of the Mac client.

Search domains

You can use the DNS Address Space and DNS Default Domain Suffix settings as the DNS search domains for the internal network. If you define both settings, they are treated as a single entry. The search domain search order is configured and maintained in the order specified in the DNS Default Domain Suffix setting. This order is maintained regardless of the Enforce DNS search order setting you configure on the network access resource on BIG-IP APM.

Allow Local DNS Servers option

When you enable the Allow Local DNS Servers option, the BIG-IP Edge Client for Mac adds routes to the routing table to ensure that DNS requests targeting the local DNS servers use the tunnel interface while the VPN is connected. For example, when your Mac client is configured to use the local name server 8.8.8.8, a route to 8.8.8.8/32 is added to the Mac routing table after the VPN connection is established. To display the routing table, type the following command on your Mac client:

netstat -r

The command output displays an added route to 8.8.8.8/32 for interface en0 (primary), similar to the following example:

Static Hosts setting

The Static Hosts setting in the BIG-IP APM network access settings defines a list of static host to IP address mappings for your Mac client devices. The BIG-IP Edge Client for Mac creates a backup file and then modifies the local /etc/hosts file with the static entries when the VPN connects. The svpn process monitors the file through the lifecycle of the tunnel and restores it if it is changed. When the tunnel disconnects, the /etc/hosts file restores it to the original version. Additionally, the following changes are also added to the hosts file:

  • Virtual server host name 
  • All static DNS host entries are always appended to the existing entries on the system. If duplicate host names (canonical host names or any aliases) are found, the existing entry is removed.

Resolver and scoped queries

The MacOS DNS resolver(s) and search strategies are documented in the man pages. To access the page, type the following command on the Advanced Shell (bash) of your Mac device:

man 5 resolver

The BIG-IP Edge Client uses tunnel mode (full or split), DNS Address Space, Search Domains, and Allow Local DNS server settings to to configure the client's DNS settings by performing the following actions:

  • Informing the MacOS System Configuration Database of the DNS settings
  • Patching the /etc/resolv.conf file

The BIG-IP Edge Client for Mac also creates a resolver for scoped queries using the F5 utun interface.This ensures that only the defined domain names can use the tunnel name servers on that interface. To display the DNS configuration for scoped queries on your Mac client, type the following command:

scutil --dns

The following command output shows that BIG-IP Edge Mac client created a second resolver for the DNS servers defined in the DNS settings in the BIG-IP APM network access resource. Troubleshooting

When troubleshooting DNS functionality of your VPN connection on MacOS, you can perform the following procedures:

  • Verifying the DNS configuration using the scutil and dig commands
  • Reviewing the log files on the MAC client
  • Using the tcpdump command to capture DNS queries and responses

Verifying the DNS configuration using the scutil and dig commands

The DNS settings for the VPN and F5 virtual adapter (utun0) contain the search domains from the BIG-IP APM network access resource and from the highest priority local interface, in addition to the tunnel name servers. You can use the scutil tool to check this configuration. To use the scutil and dig commands, type the following commands on your Mac client device:

  • To display all the DNS settings on your Mac, type the following command:

    scutil --dns

    This command is an authoritative command to verify DNS resolver settings. Review the resolvers as well as the scope queries section at the bottom section of the output. A scoped DNS query can use only specified network interfaces. For example, ethernet, Wi-Fi, or utun interfaces.

  • You can also view the DNS servers for each search domain by listing the F5 ppp service DNS settings in the scutil utility. To do so, perform the following procedure:

    Note: You must connect your Mac client to the VPN before performing this procedure.

    1. From the Mac command line, enter the scutil utility by typing the following command:

      scutil

    2. To display the DNS settings of the F5 ppp service, type the following command:

      show State:/Network/Service/F5NetworksServicePPP/DNS

    3. To exit the scutil utility, type the following command:

      quit

  • You can use the scutil command to test reachability to a domain using the following command syntax:

    scutil -r <doman_name>

    For example:

    scutil -r host.example.com

  • The dig command also displays DNS information. To display DNS query information on your Mac client, use the following command syntax:

    dig <domain_name>

    For example:

    dig host.example.com

Reviewing the log files on the Mac client

The client-side log files for the BIG-IP Edge Client for Mac are located in the ~/Library/Logs/F5Networks directory. You should review the svpn.log file for DNS issues. You can look specifically for DNS entries by typing the following command:

grep UDNSPatcher ~/Library/Logs/F5Networks/svpn.log

Using the tcpdump command to capture DNS queries and responses

To capture DNS packets on your local Mac client, use the following command syntax:

sudo tcpdump -nni <interface> port 53

For example, to capture DNS packets on the VPN tunnel, type the following command:

sudo tcpdump -nni utun1 port 53

For example, to capture DNS packets on your local en0 interface, type the following command:

sudo tcpdump -nni en0 port 53
