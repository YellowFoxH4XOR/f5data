Topic

When you configure Dynamic Ratio as your load balancing method, the BIG-IP LTM system uses the Windows Management Interface (WMI) performance monitor to collect performance data from a node and determine ratio weight.

The WMI monitor is for Windows Servers running Microsoft Internet Information Services (IIS). To properly use this monitor, you need the following components:

  • A BIG-IP system on which you configure a WMI monitor. The BIG-IP system queries the Windows Server for performance data.
  • A Windows Server on which you install one of the following Data Gathering Agent files. The WMI monitor queries the Data Gathering Agent for the requested performance data.
    • F5Isapi.dll
    • F5Isapi64.dll
    • F5.IsHandler.dll

    For more information about installing the Data Gathering Agent, refer to the Dynamic Ratio Load Balancing chapter of the BIG-IP Local Traffic Management: Basics manual (BIG-IP 11.6.x and later) or the Dynamic Ratio Load Balancing chapter of the BIG-IP Local Traffic Management: Concepts manual (BIG-IP 11.5.x).

    Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

Description

WMI monitor fields and descriptions

The following are the WMI monitor fields and descriptions:

  • Interval

    The interval at which the BIG-IP system performs a monitor check. The default is five seconds. You can change the interval to the number of seconds you want.

  • Timeout

    The number of seconds in which the node or service must respond to the BIG-IP monitor request. If the target responds within the set time period, the target is considered up. If the target does not respond within the set time period, the target is considered down. The default is 16 seconds.

    If you want to change the Timeout value, it should be three times the interval, plus one. This action prevents the monitor from marking the node down when the last check is sent.

  • User Name

    The user name for authentication on the WMI service. WMI services require authentication.

  • Password

    The corresponding password for the user name.

  • Method

    POST

    Note: This attribute appears by default; you cannot change it.

  • URL Path

    The path to the Data Gathering Agent file: F5Isapi.dll, F5Isapi64.dll, or F5.IsHandler.dll. If you install the file to the default directory, you do not need to edit this field. If you install it to a different directory, enter that URL path in this box.

    The following URL is the default path that displays in this field:

    /scripts/F5Isapi.dll

    Note: For all versions of IIS, always use /scripts/F5Isapi.dll as the URL path. For example, the Data Gathering Agent file name on IIS 5.0 and 6.0 is F5Isapi.dll or F5Isapi64.dll, while on IIS 7.0 and later it is F5.IsHandler.dll. However, you still use /scripts/F5Isapi.dll as the URL path.

  • Command

    The following values appear in the Command field, by default:

    • GetCPUInfo
    • GetDiskInfo
    • GetOSInfo
  • Metrics

    The following values appear in the Metrics field, by default:

    • LoadPercentage
    • DiskUsage
    • PhysicalMemoryUsage:1.5
    • VirtualMemoryUsage:2.0
  • Agent

    Mozilla/4.0 (compatible: MSIE 5.0; Windows NT)

    Note: This attribute appears by default; you cannot change it.

  • Post

    RespFormat=HTML

    Note: This attribute appears by default; you cannot change it.

The Metrics field

The Coefficient and Threshold attributes have the most impact on the ratio value assigned to a member. You can change these attributes in the Metrics field of the WMI monitor using the following syntax:

<Metric name>:<Coefficient>:<Threshold>

Each metric entry is separated by a comma. If you do not define the Coefficient or Threshold attribute, the defaults are assumed.

In the following example, PhysicalMemoryUsage and VirtualMemoryUsage are assigned different Coefficient values than the default:

LoadPercentage, DiskUsage, PhysicalMemoryUsage:1.5, VirtualMemoryUsage:2.0

The threshold values do not change on any of the metrics listed; they remain at their default values.

WMI monitor logging

You can enable logging for the WMI performance monitor to assist in troubleshooting load balancing issues. For more information, refer to the following article for your system version:

  • For BIG-IP 11.x, refer to K13853: Enabling logging for the WMI performance monitor (11.x).
  • For BIG-IP 9.x to BIG-IP 10.x, refer to K4690: Enabling logging for the WMI performance monitor (9.x - 10.x).
