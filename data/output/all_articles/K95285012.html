Known Issue

A BIG-IP system configured with a custom certificate and key may fail to upgrade from version 10.x to 11.x.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system configuration contains one or more Secure Sockets Layer (SSL) profiles with associated custom SSL certificates and keys.
  • You attempt to upgrade the system from BIG-IP 10.x to an affected BIG-IP 11.x version listed in the Applies to (see versions) box.

Impact

The BIG-IP system becomes inoperative after the upgrade, you cannot log in to the Configuration utility, and the system fails to process network traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H621945 on the Diagnostics > Identified > High screen. 
  • After restarting the BIG-IP system to the newly installed software volume, you notice error messages similar to the following in the /var/log/ltm file:

    emerg load_config_files: "/usr/libexec/bigpipe load" - failed. -- BIGpipe parsing error (/config/bigpipe/bigip.conf Line 67):    012e0020:3: The requested item (exampleclientssl {) is invalid (<profile arg> ` show ` list ` edit ` delete ` stats reset) for 'profile'.

  • After the upgrade, the /config/bigip.conf configuration file is missing from the BIG-IP system.

Workaround

To work around this issue, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To make a backup copy of the /config/bigpipe/bigip.conf file, type the following command:

    cp /config/bigpipe/bigip.conf /config/bigpipe/bigip.conf.save

  3. Using a text editor, edit the /config/bigpipe/bigip.conf file and delete the following line from each of the affected SSL profiles:

    inherit-certkeychain false

  4. To load the initial portion of the upgraded configuration, type the following command:

    Important: You should use the following command only when instructed to do so in an article or by F5 Technical Support.

    /usr/libexec/bigpipe daol

  5. To save the upgraded configuration, type the following command:

    tmsh save sys config

  6. To load the upgraded configuration into memory, type the following command:

    tmsh load sys config
