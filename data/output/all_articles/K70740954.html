Description

You may want to check information of installed packages on BIG-IP for auditing or security purpose.

rpm is a powerful Package Manager, which can be used to build, install, query, verify, update, and erase individual software packages. A package consists of an archive of files and meta-data used to install and erase the archive files. The meta-data includes  helper scripts,  file attributes, and  descriptive information about the package. Packages come in two varieties: binary packages, used to encapsulate software to be installed,  and source packages,  containing the source code and recipe necessary to produce binary packages.

The three major options for this operation are:

-q, --query   query packages
-a, --all     query all installed packages.
-i, --info    display package information, including name, version, and description.

Environment

  • Package information
  • Package version
  • RPM

Cause

None

Recommended Actions
You may use -a option to query (list) all installed packages and use grep to filter out the package you want.

For example, to check which log4j package version BIG-IP contains, you may use the following command:

# rpm -qa  | grep log4j 
log4j-1.2.17-16.el7_4.0.0.39.noarch

In addition, you may use -i to check further information of any specific package, including name, version, and description.
For example, to check further information of log4j, you may use the following command:

# rpm -qi log4j

Additional Information

"Vendor : F5 Networks, Inc." means that the software has been altered by F5, so it will not be listed as third-party software.
