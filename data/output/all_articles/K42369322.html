Description

FIPS was recently initialized or had it's password reset and logs the following error message when attempting to create a FIPS key:

Key management library returned bad status: -15, System does not support FIPS option

This message indicates that FIPS has not been initialized correctly and therefore the system does not support FIPS.

Environment

  • Initialize FIPS or change password
  • The following hardware platforms are impacted:
      + i5820-DF / i7820-DF
      + 5250v-F / 7200v-F
      + 10200v-F
      + 10350v-F
      + vCMP guest on i5820-DF / i7820-DF
      + vCMP guest on 10350v-F

Cause

ID953845

Recommended Actions

Follow the workaround documented in the bug ID or upgrade to a fixed software version.
