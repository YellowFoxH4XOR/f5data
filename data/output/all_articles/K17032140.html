Description

BIG-IP is generating a lot of DNS query traffic to unknown destinations on port 53.

Destination IPs in question belong to root DNS servers.

Why are these queries being made?

Environment

  • DNS

Cause

A DNS resolver is configured on the system, with a non-matching or non-existent forward zone.

The DNS resolver is used by various features, for example:

  • OCSP stapling
  • HTTP explicit proxy
  • APM SWG
  • ASM bot defense verification of search engine bots

When one of these features require DNS resolution via a DNS resolver, and no forward zone is matched, a root hints DNS server will be used.

This behaviour is also explained in:

  • K12140128: Overview of the DNS resolver

Recommended Actions

No action is required, since this is expected behaviour.

If you would like to ensure all DNS queries go to a local DNS server, configure a forward zone for . (matching all names) in the resolver. For example:

tmsh modify net dns-resolver f5-aws-dns forward-zones replace-all-with { . { nameservers add { 10.1.1.1:53 } } }
