Description

Getting below error when associating an iRule to DNS listener / DNS virtual server. The iRule consists of DNS related iRule events for e.g.  DNS_REQUEST, DNS_RESPONSE, DNS::question, etc.  

01071912:3: DNS_REQUEST event in rule (/Common/DNS_iRule) requires an associated DNS profile on the virtual-server (/Common/DNS_Listener).

This message occurs when the following conditions are met:

  • You have created an iRule that processes a DNS related traffic.

    For example:

    when HTTP_REQUEST {
        HTTP::respond 200
    }
     

    OR 
    ltm rule /Common/DNS_irule{
    when DNS_REQUEST {
  log local0. "\[DNS::question name\]: [DNS::question name], \[DNS::question type\]: [DNS::question type]"
  if {[DNS::question type] == 65} {
    log local0. "returning NOERROR"
    DNS::header rcode NOERROR
    DNS::return
  }
}
}

  • You attempt to associate the iRule with a virtual server/ DNS listener. 

  • The virtual server does not reference a traffic processing profile required to support the iRule.

 

Environment

  • Virtual servers (Standard type)

  • DNS / GTM listener objects

  • Irule with DNS related events for e.g. DNS_REQUEST, DNS_RESPONSE, DNS::question, etc.  

Cause

Virtual servers, iRules, and traffic processing profiles must work together when processing traffic. Virtual servers use iRules to direct network traffic and to modify payload data, but must have the proper associated traffic processing profile to understand the type of traffic being processed.
In this case when using DNS event in an LTM iRule on a DNS listener, either a GTM license or DNS Services add on license must be enabled. When using this event in an LTM iRule a DNS profile must be enabled on the listener.
 

Recommended Actions

DNS iRule events and commands require a GTM or DNS Services license. Make sure device have GTM or the DNS Services add-on license. 
OR
If device is already licensed with GTM or DNS add-on, ensure that at least one DNS profile (default or customer) that is configured on the DNS listener / virtual server. 

  1. On the Main tab, click Local Traffic > Virtual Servers. The Virtual Server List screen opens.

  2. Click the name of the virtual server you want to modify.

  3. From the Configuration list, select Advanced. 

  4. From the DNS Profile list, select the custom DNS profile you created or default DNS profile. 

  5. Click Update to save the changes.
