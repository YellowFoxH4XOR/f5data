K1428: NameSurfer offers less configuration options when configured as a secondary DNS server

Topic

Any proprietary NameSurfer field is not available if the Master NS SOA record points to a system other than the one that NameSurfer is running.

If NameSurfer appears to be configured to manage zones for a system other than the one running NameSurfer, it will not provide you with the option of using proprietary NameSurfer features, such as Remote Secondary Resource Records (remsec).

Note: The host name of the system that is running NameSurfer is listed in the upper-middle of the screen, in parentheses.

To correct this, modify the zone so that the system running NameSurfer is displayed in the SOA record as the Master NS. After you apply this change, the Remote Secondary (or other proprietary NameSurfer) field should reappear immediately.
