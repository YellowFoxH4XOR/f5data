Known Issue

This is the result of a known issue. When viewing a root UNC using a Windows Files Favorite, the contents of the directory are not listed in alphabetical order.

A Portal Access Windows Files Favorite is used to view network drives which are shared through the CIFS/SMB protocol. Windows Files Favorites are configured with a path of the following form:

\\servername\path\to\shared\foldername

When a Windows Files Favorite is configured to use only the root UNC, such as \\servername, the files and folders will not be listed in alphabetical order, unless by coincidence. The listing order will be identical from invocation to invocation of the Favorite.

When a Windows Files Favorite is configured to use a UNC with a path, such as \\servername\foldername, then the contents of foldername will be listed in alphabetical order.

Note: Adding a trailing backslash character to the root UNC will not restore the correct behavior.

F5 Product Development tracked this issue as CR72701, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass Release Notes.
