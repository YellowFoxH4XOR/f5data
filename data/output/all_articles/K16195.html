Known Issue

Microsoft Windows RT users may be prompted to install browser extensions.

This issue occurs when all of the following conditions are met:

  • Your device runs the Microsoft Windows RT operating system.
  • The BIG-IP APM access policy is configured with the Windows Cache and Session Control agent.

Impact

Attempts to access the BIG-IP APM system fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When prompted to install browser extensions for the Windows Cache and Session Control agent, the installation fails with an error message similar to the following example:

    Windows 8.1 failed to install "VPN adapter"

Workaround

To work around this issue, you can modify the access policy to detect Windows RT devices and allow access without the Windows Cache and Session Control agent.

  1. Log in to the Configuration utility.
  2. Navigate to Access Profiles > Access Profile List.
  3. In the Access Policy column, to the right of the affected access profile, click the Edit link to open the VPE editor.
  4. Click Windows Info.
  5. Click the Branch Rules tab.
  6. Click Add Branch Rule.
  7. Change the name of the new Branch Rule to Windows RT.
  8. Click the Expression change link.
  9. Click the Advanced tab.
  10. In the Advanced box, enter the following text:

    expr { [mcget {session.client.platform}] == "Win8" && [mcget {session.client.cpu}] == "ARM" || [mcget {session.client.platform}] == "Win8.1" && [mcget {session.client.cpu}] == "ARM" }
  11. Click Finished.
  12. Click Save.
  13. Click the Change Ending Deny link.
  14. Click the radio button for Allow.
  15. Click Save.
  16. In the upper-left corner of the VPE editor, click the Apply Access Policy link.
  17. In the upper-right corner of the VPE editor, click the Close button to exit the editor.
