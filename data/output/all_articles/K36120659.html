Description

Decrypt the TLS 1.3 packet capture taken on BIG-IP by generating a pre-master secret file

Environment

  • TLS 1.3 
  • iRule

Cause

The ssldump option and SSL::sessionsecret iRules command do not work for decoding TLS 1.3.

Recommended Actions

  •  Go to Local Traffic > iRules > iRules List.
  •  Select Create and define an iRule using an SSL::tls13_secret iRules command syntax similar to the following example:

    Note: In the following example, <client_IP_addr> is the IP address of the remote client accessing the BIG-IP virtual server.

    # Set a static global variable pointing to your test client IP address.
    # Objective is to log the Secrets only for traffic exchanged by the test client.
    # We don’t want to record sensitive data for any production traffic in a real-life deployment.
    when RULE_INIT {
                  set static::TEST_CLIENT_IP <client_IP_addr>/32
    }
    when CLIENTSSL_HANDSHAKE {
            if { [ IP::addr [IP::client_addr] equals $static::TEST_CLIENT_IP]} {
            log local0. "CLIENT_HANDSHAKE_TRAFFIC_SECRET [SSL::clientrandom] [SSL::tls13_secret client hs]"
            log local0. "SERVER_HANDSHAKE_TRAFFIC_SECRET [SSL::clientrandom] [SSL::tls13_secret server hs]"
            log local0. "CLIENT_TRAFFIC_SECRET_0 [SSL::clientrandom] [SSL::tls13_secret client app]"
            log local0. "SERVER_TRAFFIC_SECRET_0 [SSL::clientrandom] [SSL::tls13_secret server app]"
            }
    }

    Note: If the server side also needs to be decrypted, you should add the SERVERSSL_HANDSHAKE stanza from the Additional Information section to the same iRule.

  • Associate the iRule with the virtual server.
  • From the BIG-IP command line, run the tcpdump command on the BIG-IP system.
  • From the client system, access the virtual server.
  • Stop the tcpdump command.
  • Download the generated tcpdump file.
  • Use the following bash command line to generate the pre-master secret file for the previous TLS1.3 secured connection from the ltm log file:

     grep TRAFFIC_SECRET /var/log/ltm | sed 's/.*_HANDSHAKE>:\ //' > /var/tmp/iRuleTLS13Secret.pms

Additional Information

  • K16700: Decrypting SSL traffic using the SSL::sessionsecret iRules command (11.6.x)
  • K12783074: Decrypting SSL traffic using the SSL::sessionsecret iRules command (12.x and later)

If you do not know which protocol would be used, then use condition for the SSL cipher version as in this iRule:

when CLIENTSSL_HANDSHAKE {
 if {[IP::addr [IP::client_addr] equals <client_IP>] } {
   if {[SSL::cipher version] == "TLSv1.3" } {
      log local0. "========CLIENT SIDE  TLS1.3==================="
      log local0. "TCP source port: [TCP::remote_port]"
      log local0. "CLIENT_HANDSHAKE_TRAFFIC_SECRET [SSL::clientrandom] [SSL::tls13_secret client hs]"
      log local0. "SERVER_HANDSHAKE_TRAFFIC_SECRET [SSL::clientrandom] [SSL::tls13_secret server hs]"
      log local0. "CLIENT_TRAFFIC_SECRET_0 [SSL::clientrandom] [SSL::tls13_secret client app]"
      log local0. "SERVER_TRAFFIC_SECRET_0 [SSL::clientrandom] [SSL::tls13_secret server app]"
      log local0. "CSIP: [IP::client_addr]"
      log local0. "========TLS1.3 =============================="
   } else {
      log local0. "========CLIENT SIDE Other TLS==================="
      log local0. "TCP source port: [TCP::remote_port]"
      log local0. "RSA Session-ID:[SSL::sessionid] Master-Key:[SSL::sessionsecret]"
      log local0. "CSIP: [IP::client_addr]"
      log local0. "========Other TLS =============================="
   }
  }
}

If the server side also needs to be decrypted, add the following text in the same iRule as above:

when SERVERSSL_HANDSHAKE {
 if {[SSL::cipher version] == "TLSv1.3" } {
   log local0. "========SERVER SIDE  TLS1.3==================="
   log local0. "TCP source port: [TCP::local_port]"
   log local0. "CLIENT_HANDSHAKE_TRAFFIC_SECRET [SSL::clientrandom] [SSL::tls13_secret client hs]"
   log local0. "SERVER_HANDSHAKE_TRAFFIC_SECRET [SSL::clientrandom] [SSL::tls13_secret server hs]"
   log local0. "CLIENT_TRAFFIC_SECRET_0 [SSL::clientrandom] [SSL::tls13_secret client app]"
   log local0. "SERVER_TRAFFIC_SECRET_0 [SSL::clientrandom] [SSL::tls13_secret server app]"
   log local0. "SSIP: [IP::local_addr]"
   log local0. "========TLS1.3 =============================="
 } else {
   log local0. "========SERVER SIDE other TLS==================="
   log local0. "TCP source port: [TCP::local_port]"
   log local0. "RSA Session-ID:[SSL::sessionid] Master-Key:[SSL::sessionsecret]"
   log local0. "SSIP: [IP::local_addr]"
   log local0. "========Other TLS =============================="
   log local0. " "
 }
