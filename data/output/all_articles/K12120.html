K12120: Dashboard and Performance Graphs do not report new connections from Performance (HTTP) virtual servers

Known Issue

This is the result of a known issue. New connections on Performance (HTTP) virtual servers are not included in the statistics count displayed in the Dashboard utility located under New Connections, or the Performance Graphs utility located under New Connections / Client Accepts.

F5 Product Development is tracking this issue as ID 341019.

Workaround

You can track new connections using the bigpipe virtual or bigtop commands. For example, type one of the following two commands:

  • watch -n1 bigpipe virtual <virtual name> show
  • bigtop -n -delay 1

Note: For more information about the bigpipe virtual and bigtop commands, refer to the BIG-IP Utility Reference Guide, or the the online man page for each command.
