Known Issue

The tmm process may produce a core file when packet filtering is enabled.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system has packet filtering enabled.
  • The tmm process receives an IP fragment that it does not own.
  • The system is running one of the following affected versions:
     
    • 11.6.0 HF6
    • 11.5.2 - 11.5.3
    • 11.5.1 HF6 - HF10
    • 11.4.1 HF9
    • 11.2.1 HF15
    • 10.2.4 HF12 - HF13

Impact

The BIG-IP system may temporarily fail to process traffic as it recovers from the Traffic Management Microkernel (TMM) restarting, and systems configured as part of a high availability (HA) group may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H560493 on the Diagnostics > Identified > High screen.
  • If configured for HA, the BIG-IP system fails over to the standby system.
  • The BIG-IP system generates TMM core files to the /shared/core directory, which include a time stamp that correlates with the traffic interruption.

Workaround

There is no work around for this issue. However, you can mitigate the tmm core issue by disabling packet filtering.

Impact of workaround: Packet filters are no longer enforced.
