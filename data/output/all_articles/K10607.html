Topic

Old Behavior

In versions prior to BIG-IP GTM 10.1.0, the gateway_icmp monitor sends a zero byte (null) payload.

As a result of sending a zero byte (null) payload, gateway_icmp probes will fail if they are sent to systems residing behind a firewall that is configured to block ICMP messages that do not contain a payload.

Note: The BIG-IP LTM gateway_icmp monitor sends a 12 byte data payload.

New Behavior

Beginning in BIG-IP GTM 10.1.0, the gateway_icmp monitor now sends a 12 byte data payload. The GTM gateway_icmp monitor behavior is now consistent with the LTM gateway_icmp monitor behavior.

F5 Product Development tracked this change as ID 207442.

Impact

BIG-IP GTM gateway_icmp probes will no longer fail when sent through a firewall that blocks ICMP messages that do not contain a payload.
