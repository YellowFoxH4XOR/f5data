Description

How to create a virtual server for FTPS or SFTP which re-encrypts traffic passing through BIG-IP.

Environment

  • BIG-IP LTM
  • FTPS/SFTP
  • SSL profiles
  • Traffic re-encryption/SSL bridging

Cause

None

Recommended Actions

You cannot configure a virtual server for FTPS or SFTP with traffic re-encryption/SSL bridging. Instead review the following recommendations:

  • FTPS: Refer to the recommendation in the FTPS mode row of K08859735: Overview of the FTP profile (14.x - 17.x) 
  • SFTP: Refer to K24595255: Creating a load-balanced SFTP virtual server.

Additional Information

  • FTPS: SSL profiles are not able to handle the FTP 220 server ready message and AUTH SSL request in FTPS connections
  • SFTP: F5 recommends using a Performance (Layer 4) virtual server to load balance SFTP traffic
