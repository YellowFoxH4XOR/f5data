Description

License with ASM module installed but Security Menu is missing Sub-menus:

Environment

  • License file shows ASM under Active Modules
  • Only Sub-Menu 'Cloud Service' is available under Security Menu


Cause

ASM Module is required to be provisioned for the ASM sub-menu to be available.
 

Recommended Actions


To provision ASM module, follow the steps provided below.

Impact of procedure: The BIG-IP system briefly interrupts traffic processing while the system reloads the configuration. This may result in a failover. F5 recommends that you perform the following procedures on the standby BIG-IP device. 

  1. Log in to the BIG-IP GUI
  2. Browse to System > Resource Provisioning
  3. Check the box next to Application Security (ASM)
  4. Select the preferred Provisioning ( default is Nominal )
  5. Click on Update


Additional Information

This applies to any other Module that is intended to be used.
