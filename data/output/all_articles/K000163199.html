Description

You see below error message in Top CPU and Top Used Partition statistics (not exclusively, it could be in other graphs or statistics that you are looking at) in Monitoring tab.

QUERY_NOT_SUPPORTED: Something is wrong around $.template.queries[0]: Elasticsearch exception [type=named_object_not_found_exception, reason=[1:1022] unable to parse BaseAggregationBuilder with name [multiple-aggregation]: parser not found]

Environment

  • BIG-IQ
  • 8.4.2.1/8.4.2.2

Cause

ID2489213

Recommended Actions

To immediately work around this issue, you can reinstall the F5 Elasticsearch plugins on all the BIG-IQ devices in your cluster, including the BIG-IQ Centralized Management primary, BIG-IQ Centralized Management secondary, and DCDs. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure will restart the elasticsearch process on each system which will temporarily interrupt statistic or event collection.

  1. Go to the BIG-IQ Centralized Management 8.0.0 page on the F5 Downloads site, and download the following files:
    • aggregation_plugins.tar.gz
    • aggregation_plugins.tar.gz.md5
  2. Use an SCP client to copy the downloaded files to the /shared/tmp directory of the target Elasticsearch node (BIG-IQ Centralized Management or DCD).
    Note: For information about uploading files to an F5 system, refer to K175: Transferring files to or from an F5 system.
  3. Log in to the command line of the BIG-IQ device where the files are copied.
  4. To change to the /shared/tmp directory, enter the following command:
    cd /shared/tmp
  5. To verify the MD5 checksum of the TAR file, enter the following command:
    md5sum -c aggregation_plugins.tar.gz.md5
  6. To extract the upgrade plugin files, enter the following command:
    tar -zxvf aggregation_plugins.tar.gz
  7. To change to the directory where the plugin files are located, enter the following command:
    cd aggregation_plugins
  8. To upgrade the Elasticsearch plugins, enter the following command:
    ./reinstall_plugins.sh
  9. Repeat the procedure until the Elasticsearch plugin files are applied to all BIG-IQ Centralized Management devices and DCDs in the cluster.
  10. After all systems have the files applied, verify the Elasticsearch cluster health and ensure it has a green status using the following command run from any of the systems:
    curl -sk https://localhost:9200/_cluster/health?pretty
    Note: Depending on the amount of information on the DCDs, it may take some time for the status to return to green.

Or you can request for EHF by opening case with F5 Technical Support team.
Important: If you choose to use EHF, check if your current version contains fix for Bug ID 2313605, if not, follow manual workaround mentioned in K000161674: Big-IQ: Upgrade will fail when DCDs are attached prior to upgrade. If you do not do this, upgrade will fail. Additionally make sure the EHF you are planning to upgrade contains fix for Bug ID 2313605 as well. Otherwise the next software version upgrade you will need to K000161674: Big-IQ: Upgrade will fail when DCDs are attached prior to upgrade.
