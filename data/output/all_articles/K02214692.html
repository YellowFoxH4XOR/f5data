Description

Clients uploading files or sending POST requests with a body larger than 64 KB through a BIG-IP virtual server configured with an APM access profile receive TCP RST packets, causing the upload or API call to fail. Requests below the 64 KB threshold succeed normally.

Observed error messages:

In /var/log/ltm

RST sent from <VS_IP>:443 to <Client_IP>:<port>, APM HTTP body too big

In packet captures (F5 Ethernet Trailer)

[F5RST: APM HTTP body too big]

In /var/log/apm

Access encountered error: ERR_NOT_SUPPORTED. File: ../modules/hudfilter/access/access.c, Function: hud_access_process_ingress

Client-side application error: 

httpx.ReadError

Environment

  • Virtual server: Configured with an APM access profile (OAuth Resource Server type)
  • Backend: API/AI gateway backend (e.g., LiteLLM server)

Cause

Bug ID1085629 — APM sends "HTTP body too big" reset message when POST body is greater than 64 KB

The underlying behavior is:

  1. Client sends an initial POST with body < 64 KB → APM session is created successfully.
  2. Client sends a subsequent POST with body > 64 KB → APM enforces the 64 KB limit and resets the connection with [F5RST: APM HTTP body too big]

 

Resolution

APM enforces a maximum HTTP request body size controlled by the tmm.access.maxrequestbodysizesys db variable. The default value is 64,000 bytes (64 KB). When a client establishes an APM session with an initial POST request under 64 KB, any subsequent POST request with a body exceeding this limit is rejected by APM with a TCP RST.

 

The maximum configurable value of tmm.access.maxrequestbodysize is capped at 25,000,000 bytes (25 MB), which may still be insufficient for large file uploads ( in some cases), if that is the case then v17.5.1.4 or greater has been upped to 250 MB.

 

The bug is classified as "Functions as Designed" by F5 Engineering, with no standard code fix planned. 

For file uploads:

  • Smaller than 25 MB: increase the value of the sys db variable up to 25 MB using the below command 
    tmsh modify sys db tmm.access.maxrequestbodysize value <value_in_bytes>
  • For file uploads more than 25MB, you will need to install 17.5.1.4 or greater, the value is increased to 250 MB.
