K000151118: Excessive logging to remote syslog

Type
Support Solution
Published
2025-05-01
Updated
2025-05-01
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151118

Description

Excessive and repetitive logging is sent from BIG-IP to a remote syslog server, resulting in a flood of messages such as:

hostname="big-ip.local",errdefs_msgno="011b090e:7:",msg="getTMValueUNKeyed start."
hostname="big-ip.local",errdefs_msgno="011b0907:7:",msg="column name: slot_id."
hostname="big-ip.local",errdefs_msgno="011b0908:7:",msg="column value (QUAD) 0."

Environment

  • Product: BIG-IP
  • Logging Configuration:

    sys log-config filter (e.g., hsl-filter)
    sys log-config publisher
    sys log-config destination remote-high-speed-log
    sys syslog remote-servers

Cause

The device is configured with syslog filter and the filter is set to 'debug' severity (that's the default).

Example:

sys log-config filter /Common/hsl-filter {
publisher /Common/hsl-pub
}

Recommended Actions

Change the log severity on the filter to a lower level:

  1. Connect to CLI
  2. Change filter log level

    tmsh mod sys log-config filter <log_filter> level notice
    Note: Replace <log_filter> with the syslog filter name

Example:

tmsh mod sys log-config filter hsl-filter level notice
