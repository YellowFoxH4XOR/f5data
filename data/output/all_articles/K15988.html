Known Issue

Custom Client SSL profile settings may be overwritten during a configuration load.

This issue occurs when all of the following conditions are met:

  • The Client SSL profile is the child of a non-default Client SSL profile.
  • The Client SSL profile references a custom certificate key chain and has the Chain setting configured.

If a Client SSL profile is configured as the child of a non-default Client SSL profile, but has custom Certificate, Key, and Chain settings configured, the certificate key chain settings may be overwritten during a configuration load operation. For example, this issue can occur when a user configuration set (UCS) archive is installed during an upgrade or when the tmsh load sys config command is executed.

Impact

The certificate key chain settings, in the child Client SSL profile, are altered or reverted to the parent's settings.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H499659 on the Diagnostics > Identified > Medium screen.
  • After upgrading BIG-IP system software, the certificate key chain settings in Client SSL profiles are unexpectedly changed.
  • When attempting to connect to virtual servers configured with the affected Client SSL profiles, Secure Socket Layer (SSL) warning messages appear.
  • Users cannot connect to virtual servers configured with the affected Client SSL profiles.
