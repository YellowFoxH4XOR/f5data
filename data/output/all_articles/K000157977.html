Description

You want to use our F5 XC Load Balancers for your VPN connections, those can be on the same domain or in a different ones.

Environment

  • HTTP Load Balancer
  • TCP Load Balancer

Answer

Yes, it is possible:

For example we have the following situation:

 We have the domain vpn.example.com setup as an HTTPS Load Balancer. The VPN connection is made to the same domain and since it is not an HTTPS connection it breaks on ingress of XC.

In order to make it work, we have to use the same FQDN and a different port and also create TCP Load balancer reflecting this port pointing to the same Origin server (but also changing the port on the Origin Server.)

That way you will conserve the HTTPS port 443 to make connections to that WebApp and the TCP Load Balancer with a different port for the VPN connections.
