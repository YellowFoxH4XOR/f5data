Description

While using HTTPS connection - client certificate request enabled in the client SSL profile, certificate not supply to BIG-IP from Client.

  • During SSL handshake, cert is required and not getting by BIG-IP to the backend servers.
  • Some clients constant failing to connect to server
  • Using a SHA1 client certificate

Environment

  • Client SSL profile:
    • Client Certificate: request
  • Certificate type: self-signed or issued by any CA
  • f5-default cipher group

Cause

  • Signature algorithms are part of the cipher-group/cipher rules definition.

  • Default cipher group is f5-default, which not included with SHA-1

Recommended Actions

In case you would like to use SHA-1, it can be enabled by creating a custom cipher group via GUI/tmsh (add RSA-PKCS1-SHA1 to the signature algorithms).

Important: SHA-1 consider as a weak cipher to use with a secure connection.

  1. Go to Local Traffic  >  Ciphers : Rules  >  New Cipher Rule...
    1. Set Name (i.e. 'SHA1_enabled')
    2. Description (i.e. 'Add RSA-PKCS1-SHA1 to the signature algorithms')
    3. Cipher Suites - Set to DEFAULT
    4. DH Groups - Optional
    5. In the 'Signature Algorithms' field: RSA-PKCS1-SHA1
    6. Finish

To see the default Cipher's used from tmsh, use the following command:

show ltm cipher group f5-default all-properties
