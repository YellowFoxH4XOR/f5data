Known Issue

This is the result of a known issue. If the BIG-IP ASM system receives a POST request containing an Expect: 100-continue header and no message body, it will not forward the request to the destination server. When this issue occurs, the session will stall for the duration of the TCP profile timeout.

F5 Product Development tracked this issue as CR78369 and was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in HOTFIX-BIG-IP-9.3.1-HF2 issued for BIG-IP 9.3.1, for the BIG-IP 9.3.0 software branch. You may download this hotfix or later versions of this hotfix from the F5 Downloads site.
