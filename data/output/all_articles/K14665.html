Known Issue

Multiple Virtual Clustered Multiprocessing (vCMP) guests may use the same media access control (MAC) address.

This issue occurs when any of the following conditions are met:

  • You are loading a user configuration set (UCS) or single configuration file (SCF) configuration containing vCMP objects in the provisioned or deployed state, while the running system is not provisioned for vCMP.
  • During re-licensing, the BIG-IP system has vCMP guests provisioned or deployed, and the BIG-IP system is restarted before you apply an updated license.

Impact

This issue can cause traffic disruption, the system to direct traffic to the wrong vCMP guest, and incorrect learning on upstream devices.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H427508 on the Diagnostics > Identified > High screen.
  • Multiple vCMP guests have the same MAC address.

Workaround

To work around this issue, you can set all vCMP guests to the configured state and re-deploy them. To do so, perform the following procedure:

Impact of workaround: vCMP guests are temporarily disabled, and they process no traffic.

  1. Log in to the Configuration utility as the admin user.
  2. Navigate to vCMP > Guest List.
  3. Select your vCMP guests and click Disable.
  4. Re-select the vCMP guests and click Deploy.
