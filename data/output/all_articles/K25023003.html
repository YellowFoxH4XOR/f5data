Description
When upgrading or installing an Engineering Hotfix, the upgrade fails with an error message similar to the following:

Terminal error: RPM transaction failure.
*** Live install end at 2021/08/03 18:42:10: failed (return code 1) ***

When viewing the software status using tmsh you see the error "RPM transaction failure" in relation to the destination installation volume.

Example
tmsh show sys software

-----------------------------------------------------------------------------
Sys::Software Status
Volume  Product  Version     Build  Active                             Status
-----------------------------------------------------------------------------
HD1.1    BIG-IP   15.1.3  0.102.11      no  failed (RPM transaction failure.)
HD1.2    BIG-IP   14.1.4  0.144.11     yes                           complete
HD1.3    BIG-IP   15.1.3  0.102.11      no  failed (RPM transaction failure.)

A log message similar to the following is logged to /var/log/liveinstall.log:
info: RPM: error: %preun(fpga-tools-atlantis-15.1.3-0.0.11.i686) scriptlet failed, exit status 2

Environment

  • BIG-IP i4600 / i4800
  • BIG-IP i2600 / i2800
  • BIG-IP i850
  • Installation of EHF

Cause
Bug ID 1039049-2

Recommended Actions

Upgrade to a fixed version listed in 1039049-2.
