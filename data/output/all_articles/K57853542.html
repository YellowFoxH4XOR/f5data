Known Issue

DNS Express responses are missing a Start of Authority (SOA) record in NoData responses if CNAMEs are present.

This issue occurs when all of the following conditions are met:

  • You have configured DNS Express.
  • A partial CNAME chase occurred, resulting in an incomplete resolution.

Impact

A valid DNS response exists with a partial chase, but since it is missing the SOA record, the response may not be considered authoritative.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • A valid NoData response contains CNAMEs if a partial chase occurred without a final resolution. DNS Express does not include the expected SOA record in this scenario.
