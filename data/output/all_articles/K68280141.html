Description

You have a bwc policy to control bandwidth of tcp traffic.

 net bwc policy vs-bwc {
     max-rate 1mbps        
 }

The policy usually controls bps(out) as follows.

Net::bwc-policy:
------------------------------------------------
Policy Name                         vs-bwc
  Bits/sec (in)                     4.4M    4.4M
  Bits/sec (out)                    1.0M    1.0M   <---- 
  Packets/sec (in)                  241
  Packets/sec (out)                 75
  Bytes (in)                        203.7M
  Bytes (out)                       37.3M
  Bytes (dropped)                   166.4M
  Packets (in)                      67.2K
  Packets (passed)                  19.7K
  Packets (dropped)                 47.4K
  Time since data Collected (secs)  330
  Active Policies                   0
  Inactive Policies                 0
  Total Policies                    0

However, bps (out) may greatly exceeds max-rate as follows.

Net::bwc-policy:
------------------------------------------------
Policy Name                         vs-bwc
  Bits/sec (in)                     2.3M    2.3M     
  Bits/sec (out)                    1.5M    1.5M   <----
  Packets/sec (in)                  1.2K
  Packets/sec (out)                 1.0K
  Bytes (in)                        179.1M
  Bytes (out)                       116.6M
  Bytes (dropped)                   62.5M
  Packets (in)                      774.1K
  Packets (passed)                  638.7K
  Packets (dropped)                 135.4K
  Time since data Collected (secs)  828
  Active Policies                   0
  Inactive Policies                 0
  Total Policies                    0

Environment

  • BIG-IP LTM

  • BWC policy has been configured

  • Viewing controlled bandwidth by using "tmsh show net bwc policy"

Cause

This is by design. 
BWC does not drop tcp handshake SYN and closure FIN packet. For example, when http response|payload size is small, we attempt to drop, but TCP SYN FIN packet rate is higher, so drop rate will get down. This will result in high Bits/sec (out) over max-rate.
