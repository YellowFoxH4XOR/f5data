Known Issue

The vxland process may repeatedly restart. This issue occurs when the following condition is met:

  • Your BIG-IP configuration uses 8,000 Virtual eXtended LAN (VXLAN) tunnels.

Impact

VXLAN traffic through the BIG-IP system is disrupted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If 8,000 VXLAN tunnels are configured, the BIG-IP system repeatedly displays a message similar to the following example in the command line:

    emerg logger: Re-starting vxland
