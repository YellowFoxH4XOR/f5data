Description

When changing a  device certificate from self-signed to a CA and trying to access the BIG-IP with the IP address, instead of the hostname, you see:

"The security certificate presented by this website was issued for a different website's address"

Environment

  • BIG-IP LTM
  • Renewed device certificate

Cause

This is because the certificate was issued only for that specific FQDN if you try accessing with another hostname or by IP you will have that error.
If your website is secured by a certificate with the name www.example.com you will receive this error if you connect using any of the following names:

  1. example.com
  2. example.local
  3. 10.1.1.7

Even though all of the above addresses would get you to a site with a valid certificate, you could still get a name error if you are connecting to a name other than the one that the certificate was issued to.

 

Recommended Actions

Use only the FQDN of the certificate to access the BIG-IP.
