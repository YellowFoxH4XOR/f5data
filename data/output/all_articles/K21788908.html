Description

Change max age for HTTP Strict Transport Security ( HSTS ) on Management interface

HSTS is enabled by default, with these values:

Strict-Transport-Security "max-age=16070400; includeSubDomain

Environment

  • BIG-IP Management configuration utility interface
  • Change the value for max age of HSTS
  • httpd configuration

Cause

Recommended Actions

Connect to the BIG-IP CLI:

  1. Enter TMOS:
    tmsh
  2. Edit the httpd configuration
    edit sys httpd
  3. Enter insert mode with the insert key or "i" 
    Add the following lines to the configuration:

include "Header always set Strict-Transport-Security \"max-age=31536000; includeSubdomains;\""

Example:

modify httpd {
    auth-pam-idle-timeout 360000
    include "Header always set Strict-Transport-Security \"max-age=31536000; includeSubdomains;\""
}

  1. Once the changes have been confirmed, then press the ESC key to quit interactive mode, then type :wq
  2. Select 'y' when prompted 'Save Changes? (y/n/e)'
  3. Save the configuration: 
    save sys config
  4. Restart the httpd process:
    bigstart restart httpd
  5. Test with the following command, this will show you if the new value is working:
    curl -I -k https://<Management-Address of the bigip> 

  6. Example curl output:
