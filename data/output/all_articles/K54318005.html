K54318005: Do we need an add-on key to activate a new base registration key?

Type
Support Solution
Published
2021-10-21
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K54318005

Description
After purchasing a base-registration key, is an add-on key required to activate this base-registration key?

Environment

  • New Base Registration Key
  • License Activation
  • Add-On Key
  • Optional Module

Cause
None.

Recommended Actions
Activation of a new base registration key does not require any add-on key. 

Additional Information
Add-on keys seen in Optional Modules are available for purchase from F5 Sales.
