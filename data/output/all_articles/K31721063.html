Description

SAML authenticated users do not display usernames in the Active Session Table but you want to display a user name. Since users do not complete a login form, no information is captured to populate the Active Session Table.

Environment

  • BIG-IP APM

Cause

Since users do not complete a login form, no information is captured to populate the Active Session Table.

Recommended Actions

To add a value to the Username within the Active Session Table, capture a valid variable that contains username information and insert it into the session.logon.last.username field if it is not in use.

  1. Within the Visual Policy Editor, after authentication and assignments have occurred, create a 'Variable Assign' object.
  2. Click 'Add new entry'
  3. Click 'Change'
  4. Set a 'Custom Variable' 'Unsecure' and insert session.logon.last.username
  5. Then select a 'Session Variable' and enter a session variable you with to populate the username field, such as session.saml.last.identity
