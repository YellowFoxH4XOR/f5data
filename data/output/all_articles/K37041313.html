Known Issue

High thread count for the pkcs11d process may result in high CPU utilization.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system is configured to use a SafeNet network hardware security module (HSM) device.

  • The allowed thread count for pkcs11d process has been set higher than the default value.

Impact

The BIG-IP system may experience a decrease in performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When running the tmsh show sys tmm-info command, you observe the Traffic Management Microkernel (TMM) using a high CPU percentage.
  • The BIG-IP system may experience performance degradation.

Resolution

Status

Workaround

To work around this issue, leave the allowed thread count for pkcs11d process at the default value.

Impact of workaround: Performing this workaround should not have a negative impact on your system.
