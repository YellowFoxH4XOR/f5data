Issue

Error Message

err mcpd[PID]: 01071aed:3: Peer <IP address> time exceeds threshold <timesync_threshold> sec - difference - <time_difference> sec

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <IP_address> is the peer IP address in a device group.
  • <timesync_threshold> is the configurable threshold time in seconds.
  • <time_difference> is the time difference between the system time of the current device and the time sent by the peer in a heartbeat packet.

For example:

err mcpd[5250]: 01071aed:3: Peer 10.3.1.4 time exceeds threshold 3 sec - difference -86400 sec

In addition, the BIG-IP system prompt also updates to indicate that the time between a peer is out of sync.

For example:

[root@BIGIP-1:Peer Time Out of Sync:In Sync (Trust Domain Only)] config #

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • The BIG-IP system prompt

Description

This message occurs when all of the following conditions are met:

  • You are running BIG-IP 13.0.0 or later on BIG-IP systems in a high availability (HA) configuration.
  • The system clock on peer devices becomes out of sync greater than the value specified by the configsync.timesyncthreshold variable.

Your configuration synchronization (ConfigSync) operation may not function properly if the network time protocol (NTP) server is not configured on all the devices in a device group. F5 has improved the error messages when the BIG-IP system clock is out of sync on peer devices in a device group. Heartbeat packets are sent among peers with the current time of the device to track time sync issues. The BIG-IP system logs an error message if the time is greater than the configurable threshold value. Additionally, the BIG-IP system prompt also updates to indicate that the device system clock is out of sync. The configsync.timesyncthreshold database variable controls the threshold to trigger this error message.

Note: The default value of the configsync.timesyncthreshold database variable is three seconds.

Impact

The system clock is out of sync on a peer device, which may cause the ConfigSync operation to fail.

Recommended Actions

You should configure the NTP server on all members of the device group. For more information, refer to the following articles:

  • K3122: Using the BIG-IP Configuration utility to add an NTP server
  • K13380: Configuring the BIG-IP system to use an NTP server from the command line (11.x - 13.x)

If you encounter the error message even though NTP servers are configured on all members of the device group, you should verify NTP connectivity. For more information, refer to K10240: Verifying NTP peer server communications.
