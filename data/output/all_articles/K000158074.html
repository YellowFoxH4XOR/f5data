Description

You are unable to generate a ucs archive

In audit log you see the following error:

Dec 4 11:04:07 ltm1 notice tmsh[6777]: 01420002:5: AUDIT - pid=6777 user=support folder=/Common module=(tmos)# status=[Unexpected Error: UCS saving process failed.] cmd_data=save sys ucs test

Environment

  • BIGIP

Cause

Undetermined

Recommended Actions

Run the following steps:

  • cd /var/tmp
  • tmsh -m save sys ucs /var/tmp/test.ucs

Let the process run for another 20 minutes and if the process does not stop on its own please cancel the UCS with Ctrl+C.

Upload the follow files to the case once completed and search for an error at the end of tmsh.out:

/var/tmp/tmsh.out

/var/tmp/test.ucs

If needed, escalate the case with the tmsh.out file for review
