Known Issue

Viewing a resource configuration with the Traffic Management Shell (tmsh) one-line option may not render the correct format.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a remote desktop resource.
  • You use the tmsh one-line option to list the remote desktop resource configuration.

Impact

The remote desktop resource configuration does not display in the one-line format.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When viewing a remote desktop resource configuration using the tmsh one-line option, the format does not adhere to one line.

    For example:

    tmsh list /apm resource remote-desktop one-line

    apm resource remote-desktop rdp example {
        color-depth 24-bit
        customization-group example_resource_remote_desktop_customization
        description onliner
        ip 10.0.100.5
        java-client enabled
        port ms-wbt-server
        window-height 800
        window-width 1024
    }

    The correct remote desktop resource configuration should display in one line similar to the following example:

    tmsh list /apm resource portal-access one-line

    apm resource portal-access example_portal { acl-order 1 application-uri http://10.0.0.10/ customization-group example_portal_resource_web_app_customization publish-on-webtop true scheme-patching true }
