Known Issue

This is the result of a known issue. Under rare conditions, a corrupt MySQL password prevents the Configuration utility from loading. When this issue occurs, the following message is displayed by the BIG-IP ASM Configuration utility:

An error has occurred while loading this page

In addition, the following error messages are displayed in the /var/log/webui.log file:

ERROR [Thread-20] db.DBConnection:getConn - Could not init connection for a transaction: java.lang.RuntimeException: Could not find database credentials.
ERROR [Thread-20] util.F5Error:<init> - An error has occurred while loading this page.
java.lang.IllegalStateException: DBConnection on this thread has not been allocated.
at com.f5.model.db.DBConnection.getConnection(DBConnection.java:210)
at com.f5.model.db.DBConnection.execute(DBConnection.java:296)
at com.f5.model.db.DBConnection.execute(DBConnection.java:318)
at com.f5.model.db.SelectHelper.selectAll(SelectHelper.java:105)
at web.tmui.locallb.profile.httpclass.list_jsp._jspService(list_jsp.java:213)
at org.apache.jasper.runtime.HttpJspBase.service(HttpJspBase.java:137)
at javax.servlet.http.HttpServlet.service(HttpServlet.java:853)

F5 Product Development tracked this issue as ID 214288 (formerly CR101785) and it was fixed in BIG-IP ASM 10.0.0. For information about upgrading, refer to the BIG-IP ASM release notes.

Workaround

You can work around this issue by resetting the MySQL password. To do so, refer to the instructions in K6979: Managing the MySQL database password for BIG-IP system.
