Description

After GUI user session expired (i.e., exceeded "/sys httpd auth-pam-idle-timeout"), when user tried to re-login to GUI by pressing "Log in" button, an error message similar to below may be displayed.

----------
This BIG-IP system has encountered a configuration problem that may prevent the Configuration utility from functioning properly.

To prevent adverse effects on the system, F5 recommends that you restrict your use of the Configuration utility to critical tasks only until the problem is resolved. Beware that attempting to modify your configuration in this state with the Configuration utility may cause your configuration to be overwritten.
----------

Although GUI error indicates something critical happened, by clicking "Continue" button on GUI error screen, user can successfully get back to login screen and can successfully login to BIG-IP GUI.

 

Environment

All of the following conditions need to be met.

  • User was logging in GUI and selected non-Common partition at top right corner.
  • User GUI session had expired and automatically logged out while working with objects on non-Common partition.
  • After user session expired, partition object, which user was referring to on previous GUI session, was deleted by any means (e.g., TMSH, config-sync from peer...etc).
  • After partition object is deleted, user tried to re-login to GUI.

 

Cause

Bug ID407849.

 

Answer/Recommended Actions

After partition object is deleted, to prevent users from seeing aforementioned GUI error, you can restart tomcat process and can flush previous GUI session information.

# tmsh restart /sys service tomcat

Note: Restarting tomcat does not affect traffic processing although it temporarily affects GUI accesses while tomcat process is restarting.

None.
