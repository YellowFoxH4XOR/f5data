Topic

This article applies to the BIG-IP systems only.  The serial number is located on your system barcode sticker and is also stored in the system configuration database. The registration key is located in the license file. For more information, refer to the following sections of this article:

  • Serial number format
  • Serial number barcode sticker
  • Displaying the serial number from the command line
  • Displaying the serial number in the Configuration utility
  • Displaying the serial number with SNMP
  • Displaying the serial number using an iControl REST command
  • Displaying the registration key from the command line
  • Displaying the registration key in the Configuration utility
  • Displaying the registration key using an iControl REST command
  • Locating the registration key on an unlicensed system 

 

To watch a video demo of some of these procedures, go to  Finding the serial number or registration key of your BIG-IP system.

Serial number format

  • Platform models 1600, 2000s, 2200s, 3600, 3900, 4000s/4200v, 5000s/5200v/5250v, 6900-NEBS, 6900s, 7000s/7200v/7250v, 7050s, 7055, 7255, 8950s, 10000s/10200v/10250v, 6900, 10050s, 10055s, 10150s, 10255v, 10350v, 11000, 11050, 12250v, i850, i2000, i2600, i2800, i4000, i4600, i4800, i5000, i5600, i5800, i5820-DF, i7000, i7600, i7800, i7820-DF, i10000, i11000, i15000, i15600 and i15800.

    The serial number format is F5-XXXX-XXXX. The serial number begins with F5, followed by a dash character ( - ), followed by four alphanumeric characters, followed by a dash, followed by four alphanumeric characters.

    For example:

    F5-ABCD-EFGH

  • Platform models 1000, 1500, 2000, 2400, 3400, 3410, 4100, 4500, 5000, 5050s, 5100, 5110, 6400, 6800, 8400, 8800, 8900, and 8950

    The serial number format is bipXXXXXXs. The serial number begins with the letters bip, followed by six numeric characters, and ends with the letter s.

    For example:

    bip012345s

  • VIPRION platform models (VIPRION, 2200, 2400, 4400, 4480, and 4800)

    The chassis and each blade has a unique serial number. The serial number format for the VIPRION chassis is chsXXXXXXs. The serial number begins with the letters chs, followed by six numeric characters, and ends with the letter s.

    For example:

    chs012345s

    The serial number format for a VIPRION blade is bldXXXXXXs. The serial number begins with the letters bld, followed by six numeric characters, and ends with the letter s.

    For example:

    bld012345s

  • BIG-IP VE

    A BIG-IP Virtual Edition (VE) system does not have a similar serial number format to the previously mentioned hardware platforms. If you encounter any issue that requires F5 Support assistance, you cannot use the BIG-IP VE serial number to open a support case. You must use the last seven digits of the BIG-IP VE registration key.

    Note: For information about finding the registration key of your BIG-IP virtual edition (VE) system, refer to K54213125: Finding the registration key of your BIG-IP virtual edition (VE) system.

Serial number barcode sticker

  • Platform models i2000, i4000, i5000, i7000, i10000, i15600 and i15800.

    The serial number barcode sticker is white and located on the front of the system on the left side below the management interface.

  • Platform models 1600, 3600, 3900, 4000s/4200v, 5000s/5200v/5250v, 7000s/7200v/7250v, 10000s/10200v/10250v, 6800, 6900/6900s, 8900, 8950, 11000, 11050, r5900 and r10900.

    The serial number barcode sticker is white and located on the front of the system below the LCD panel.

  • Platform models 1500, 3400, 3410, 4100, 4500, 6400, 8400, and 8800

    The serial number barcode sticker is white and located on the front of the system on the left side or on the front of the system below the LCD panel.

    Note: For models 1500, 3400, 6400, 8400, and 8800 shipped prior to February 2006, the barcode sticker is located on the right side next to the mounting bracket.

  • Platform models 1000, 2000, 2400, 5000, 5100, and 5110

    The serial number barcode sticker is silver and located on the lower-left front corner of the system.

  • VIPRION platform models (VIPRION, 2400, 4400, 4480, and 4800)

    The chassis and each blade has a unique serial number. The chassis serial number barcode sticker is white and located on the front of the chassis, under the bezel. The blade serial number barcode sticker is white and located on the front of the blade.

Displaying the serial number from the command line

Displaying the chassis serial number (BIG-IP 11.0.0 and later)

  1. Log in to the BIG-IP command line.
  2. To display the serial number, enter the following command:

    tmsh show sys hardware

    The Platform and System Information sections of the command output appear similar to the following example:

    Platform
    Name BIG-IP 8900
    BIOS Revision OBJ-0296-02 - Build: 90029
    Base MAC 0:1:d7:74:50:80

    System Information
    Type D106
    Chassis Serial F5-ABCD-EFGH
    Level 200/400 Part 200-0308-00 REV 07
    Switchboard Serial
    Switchboard Part Revision
    Host Board Serial
    Host Board Part Revision

Displaying the VIPRION blade serial numbers (BIG-IP 11.0.0 and later)

  1. Log in to the BIG-IP command line.
  2. To display all the blade serial numbers, enter the following command:

    clsh tmsh show sys hardware | grep 'Host Board Serial'

    The blade serial numbers appear similar to the following example:

    Host Board Serial bldXXXXXXs
    Host Board Serial bldXXXXXXs

Displaying the serial number in the Configuration utility

Displaying the Chassis serial number (BIG-IP 10.x and later)

  1. Log in to the Configuration utility.
  2. Go to System > Configuration > Device.
  3. Select General.
  4. Under Properties and Operations, locate the Chassis Serial Number.

Displaying the VIPRION blade serial numbers (BIG-IP 10.x and later)

  1. Log in to the Configuration utility.
  2. Go to System > Clusters.
  3. Under the Properties, locate the Blade Serial Number next to the appropriate Slot ID.

Displaying the serial number with SNMP

BIG-IP platform or BIG-IP virtual editions

You can get the serial number of a BIG-IP platform or BIG-IP VE by polling the F5 BIG-IP-system management information base (MIB) object identifier (OID): sysGeneralChassisSerialNum or its numeric equivalent, .1.3.6.1.4.1.3375.2.1.3.3.3.0.

Note: You cannot use the serial number of a BIG-IP VE to open a support case. You must use the last seven digits of the BIG-IP VE registration key. 

For example:

snmpwalk -v 2c -c public localhost sysGeneralChassisSerialNum
F5-BIGIP-SYSTEM-MIB::sysGeneralChassisSerialNum.0 = STRING: F5-ABCD-EFGH

or

snmpwalk -v 2c -c public localhost  .1.3.6.1.4.1.3375.2.1.3.3.3.0
F5-BIGIP-SYSTEM-MIB::sysGeneralChassisSerialNum.0 = STRING: F5-ABCD-EFGH

VIPRION systems

You can get the serial number for a VIPRION chassis and the individual blades by polling the following F5-BIG-IP-system MIB OIDs:

  • (Chassis) sysGeneralChassisSerialNum or the numeric equivalent, .1.3.6.1.4.1.3375.2.1.3.3.3.0
  • (Blades) sysChassisSlotSerialNumber or the numeric equivalent, .1.3.6.1.4.1.3375.2.1.10.3.2.1.2

For example:

Chassis serial number:

snmpwalk -v 2c -c public localhost sysGeneralChassisSerialNum
F5-BIGIP-SYSTEM-MIB::sysGeneralChassisSerialNum.0 = STRING: chs12345s

or

snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.3.3.3.0
F5-BIGIP-SYSTEM-MIB::sysGeneralChassisSerialNum.0 = STRING: chs12345s

Blade serial numbers:

snmpwalk -v 2c -c public localhost sysChassisSlotSerialNumber
F5-BIGIP-SYSTEM-MIB::sysChassisSlotSerialNumber.1 = STRING: bld12345s
F5-BIGIP-SYSTEM-MIB::sysChassisSlotSerialNumber.2 = STRING: bld12345s

or

snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.10.3.2.1.2
F5-BIGIP-SYSTEM-MIB::sysChassisSlotSerialNumber.1 = STRING: bld12345s
F5-BIGIP-SYSTEM-MIB::sysChassisSlotSerialNumber.2 = STRING: bld12345s

Displaying the serial number using an iControl REST command

You can obtain the BIG-IP serial number using the following iControl REST command syntax:

curl -sk -u <username>:<password> -H "Content-Type: application/json" -X GET  https://<ip address>/mgmt/tm/sys/hardware | jq -M . |  awk '/bigipChassisSerialNum/ {getline;print $2}'

Note: Replace <username> and <password> with the administrative username and password to access the BIG-IP, and <ip address> with the IP address of the BIG-IP device.

Note: The command retrieves the BIG-IP serial number in quoted (") format.

For example:

curl -sk -u admin:admin -H "Content-Type: application/json" -X GET https://10.0.0.100/mgmt/tm/sys/hardware | jq -M . | awk '/bigipChassisSerialNum/ {getline;print $2}'

Displaying the registration key from the command line

Using the TMOS shell (tmsh)

  1. Log in to the BIG-IP command line.
  2. To display the registration key, enter the following command:

    tmsh show sys license

    The Sys::License section of the command output appears similar to the following example:

    Sys::License
    Licensed Version 11.0.0
    Registration key J1744-76883-90149-96395-1680471
    Licensed On 2016/02/07
    License Start Date 2016/02/06
    License End Date 2016/09/17
    Service Check Date 2016/08/18
    Platform ID D106
    Appliance Serial Number F5-ABCD-EFGH

Searching the /config/bigip.license file

  1. Log in to the command line.
  2. Enter the following command:

    grep Reg /config/bigip.license

    The command prints the registration key.

    For example:

    Registration Key: X1234-12345-12345-12345-1234567

Displaying the registration key in the Configuration utility

  1. Log in to the Configuration utility.
  2. Go to System > License.
  3. Select Re-activate.
  4. After the license activation page loads, locate the Base Registration Key.

Displaying the registration key using an iControl REST command

You can obtain the BIG-IP serial number using the following iControl REST command syntax:

curl -sk -u <username>:<password> -H "Content-Type: application/json" -X GET https://<bigip ip address>/mgmt/tm/sys/license |   jq -M . | awk '/registrationKey/ {getline;print $2}'

Note: Replace <username> and <password> with the administrative username and password for the BIG-IP device.

Note: The command retrieves the BIG-IP registration key in quoted (") format.

For example:

curl -sk -u admin:admin -H "Content-Type: application/json" -X GET https://10.0.0.100/mgmt/tm/sys/license |  jq -M . | awk '/registrationKey/ {getline;print $2}'

 

Locating the registration key on an unlicensed system

If the license has not yet been activated on your BIG-IP LTM, BIG-IP DNS, BIG-IP APM, BIG-IP ASM, BIG-IP PSM, or WebAccelerator system, you can find the registration key in the /config/RegKey.license file. This file is present only on factory-installed systems.

Note: F5 sends registration keys for Return Materials Authorization (RMA) devices in an email. For more information about the F5's RMA process, refer to K12882: Overview of the F5 RMA process.
