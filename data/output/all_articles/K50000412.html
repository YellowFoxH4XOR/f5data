Topic

  • You want to verify the proper operation of your BIG-IP Next Service Proxy for Kubernetes (SPK).
  • You want to provide a QKView file to F5 Support to aid in troubleshooting an issue with BIG-IP Next SPK.

Description

The qkview utility is a program that you can use to automatically collect diagnostic and logging information from BIG-IP SPK. The qkview utility is an executable program that generates machine-readable (XML) diagnostic data and combines the data into a single compressed Tape ARchive (TAR) format file. You can upload this file, called a QKView file, and provide it to F5 Support to help them troubleshoot any issues.

Note: F5 Support requires a QKView file in all cases in which remote access to the product is not available.

For BIG-IP Next SPK, you can run the qkview utility from a local workstation by downloading the QKView package from F5 Cloud Docs, or you can run the qkview utility using the QKView API.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have BIG-IP Next SPK running in an OpenShift cluster.
  • You have a Linux or macOS workstation with Go installed.

Procedures

To generate diagnostic data for BIG-IP Next SPK using the qkview utility, perform one of the following procedures, as needed:

  • Run the qkview from a local workstation
  • Run the qkview using the QKView API

Run the qkview from a local workstation

Note: The BIG-IP Next SPK QKView package is currently only available as an Early Access (EA) feature.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Download the QKView tarball and the QKView md5sum files from F5 Cloud Docs.
  2. Using the Linux workstation, verify the integrity of the files using the following command:

    cat qkview-packaging.tar.gz.md5 ; md5sum qkview-packaging.tar.gz

    The resulting output should match as in the following example:

    19e2de4fd4ee1edc9a62fffa6095984f qkview-packaging.tar.gz
    19e2de4fd4ee1edc9a62fffa6095984f qkview-packaging.tar.gz

  3. Extract the qkview-packaging.tar.gz file using the following command:

    tar xvf qkview-packaging.tar.gz

  4. Enter the following command to list the files:

    ls -1

    Output should appear similar to the following:

    qkview-collector.sh
    qkview-packaging.tar.gz
    qkview-packaging.tar.gz.md5
    qkview-wrapper-darwin
    qkview-wrapper-linux

  5. Ensure the qkview utility files are executable by entering the following command:

    chmod 755 qkview-wrapper-* qkview-collector.sh

  6. The package includes a separate qkview-wrapper utility for Linux and Darwin (macOS) systems. Run the appropriate qkview-wrapper utility for your workstation using the following syntax:

    ./qkview-wrapper-<linux | darwin> -f ./qkview-collector.sh -n <namespace>

    For example, when using a Linux workstation and BIG-IP Next SPK resides in the spk-ingress namespace, enter the following command:

    ./qkview-wrapper-linux -f ./qkview-collector.sh -n spk-ingress

  7. When complete, the qkview utility will generate the following file in the current directory:

    iHealth_qkview-packaging.tar.gz

  8. To upload the qkview file to iHealth, open a web browser and log in to https://ihealth.f5.com/qkview-analyzer/.
  9. Select Upload.
  10. Select Choose and select the iHealth_qkview-packaging.tar.gz file on the local workstation.

    Note: As an alternative to using F5 iHealth, you can also provide the QKView file to F5 Support. To do so, refer to K000090853: Exchange files with F5 Support using MyF5.

Run the qkview utility using the QKView API

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

In BIG-IP Next SPK 1.9.0 and later,  the SPK Cluster Wide Controller (CWC) supports running the qkview command using the QKView API. You can use the QKView API to collect diagnostic information from running containers. To do so, refer to the Qkview API on CloudDocs .
