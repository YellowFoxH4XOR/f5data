Description

A significant number of the next errors are seen on the BIG-IP console:

ltm  - Error - 01680002: <device name> pkcs11d[PID] Key table lookup failed. error.
user - Warn - <device name> pkcs11d[PID] Send failure: Io(Os { code: 104, kind: ConnectionReset, message: "Connection reset by peer" }).
user - Error - <device name> pkcs11d[PID] session has expired, authenticating again.

  • Log messages appear across test and production environments.
  • Not related to any upgrades.
  • Big-IP connected to Azure HSM (Hardware Security Module).

Environment

  • BIG-IP LTM.
  • HA Pair.
  • Azure Managed HSM.
  • VMSS (Virtual Machine Scale Sets).

Cause

Unknown at the time of publication.

Recommended Actions

  1. If the mode of the BIG-IP system is "Active", force it to "Standby" mode and verify if the errors are still present for the new "Active" device.

          Then, return the BIG-IP as "Active" and verify again if errors are present.

       2. If the issue persists, restart the "pkcs11d" process:

           # tmsh restart sys service pkcs11d

        3. Verify the communication between the BIG-IP and HSM, it could be an intermittent communication issue.

        4. Re-create keys (K60015029).

        5. Re-import keys (K60015029).

        6. Restart "pkcs11d" again with:

            # tmsh restart sys service pkcs11d

        7. Reboot the VMSS (Virtual Machine Scale Sets).
