Description

When connected to the F5 VPN, Windows Explorer is scrolling to the top automatically, even without human intervention.

For example, you are searching for a particular file in Windows Explorer. While going through the files, you notice that it auto-scrolls to the top of the list, for no apparent reason.

Environment

  • F5 VPN
  • Windows Explorer on Windows machine
  • Zscaler Client

Cause

There is a Zscaler service running on the Windows machine which appears to be conflicting with the F5 VPN client, which causes this issue.

Recommended Actions

Don't use F5 VPN Client and Zscaler simultaneously.

Contact Zscaler support should you need further assistance determining which Zscaler service is conflicting with the F5 VPN client.
