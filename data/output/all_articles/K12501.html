Known Issue

After importing an Access Policy, the files that are created in the /config/customization directory are set with incorrect permissions. As a result, you cannot use the Configuration utility to modify customizations made to that Access Profile. The customizations will be visible in the Visual Policy Editor; however, any changes made to the existing configuration will fail without an error message.

F5 Product Development tracked this issue as ID 342204, and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP APM or Edge Gateway release notes.

Workaround

To manually correct the permissions on the necessary files, perform the following procedure:

  1. Log in to the BIG-IP command line with root privileges.
  2. Change directories to the /config/customization directory by typing the following command:

    cd /config/customization

  3. Change the permissions of all files in the directory to drwxrwxr-x by typing the following command:

    chmod 775 *

  4. To confirm that the change was effective, use the Visual Policy Editor to edit the Access Profile.
