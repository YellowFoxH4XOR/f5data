Known Issue

Users are unable to enter Windows Protected Workspace using Internet Explorer 10 and 11, and Edge Client for Windows.

This issue occurs when all of the following conditions are met:

  • The access policy has the Windows Protected Workspace Endpoint Security (Client-Side) check enabled.
  • Users connect to the BIG-IP APM system using the Internet Explorer 10 or 11 browser, or Edge Client for Windows.

Impact

Users are unable to enter Protected Workspace after successfully authenticating to the BIG-IP APM system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client browsers stall when attempting to enter protected workspace.
  • When connecting to the BIG-IP APM system, users are able to successfully install ActiveX components, but are unable to enter Protected Workspace.
