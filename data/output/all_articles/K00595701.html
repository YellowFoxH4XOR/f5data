Description
certificate exchange, for gossip framework, will fail to exchange if config SYNC IP is not part of SSH Allow range.

Environment

  • HA pair with device configured as OAUTH Client/Resource server.

Cause
The gossip sync will fail to start the task on the standby device. Leading to problems when the standby device takes over Active role.

Recommended Actions

  1. Its recommended to ensure that the config Sync IP addresses are part of SSH allow range, if configured.
