Known Issue

This is the result of a known issue. The Configuration utility uses the same cookie to control auto refresh for both the BIG-IP LTM Performance section and the BIG-IP WebAccelerator Performance Reports section. As a result, enabling the auto refresh option for the BIG-IP LTM Performance section (located under Overview > Performance in the Configuration utility) results in the BIG-IP WebAccelerator Performance Reports section to also constantly refresh.

F5 Product Development tracked this issue as CR126996 and it was fixed in BIG-IP WebAccelerator 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

To prevent this behavior, turn off the auto refresh option under Overview > Performance before viewing Performance Reports located under WebAccelerator > Performance Reports.
