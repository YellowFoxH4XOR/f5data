K000149876: Brute Force Protection with JSON Login Page Doesn't Honor Insensitivity

Type
Support Solution
Published
2025-02-19
Updated
2025-02-19
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000149876

Description

In the context of Brute Force Protection with JSON Login Page, the issue identified under ID995889 was resolved in version 17.1.0 and later. However, an improperly configured insensitive security policy with varying case sensitivity JSON login credentials element can cause the brute force blocking mechanism to fail in detecting unauthorized login attempts.

Environment

  • Adv.WAF

Cause

Adv.WAF will successfully trigger the brute force block mechanism, irrespective of the case sensitivity of the 'username' and 'password' JSON elements in received traffics. if the 'username' and 'password' JSON elements are entered in lowercase letters.

Recommended Actions

Update the 'username' and 'password' JSON elements in the JSON login credentials page configuration to lowercase letters.
