K000149139: AS3 cannot create a new node when a SNAT object for the same IP already exists

Type
Support Solution
Published
2026-09-08
Updated
2026-09-08
Applies to
  • F5 Automation and Orchestration
  • F5 Application Services 3 Extension
Source
https://my.f5.com/manage/s/article/K000149139

Description

Deploying a declaration containing a new pool or a node definition will fail if a SNAT object for the same IP already exists.

 

Environment

AS3 is in use to deploy pools or nodes to BIG-IP.

Error message similar to below may be given

{
"code": 422,
"message": "declaration failed",
"response": "01020036:3: The requested Node (/tenant/192.168.2.1) was not found.",
"host": "localhost",
"tenant": "tenant",
"runTime": 3371,
}

 

Cause

ID1780037.

 

Recommended Actions

Delete any existing SNAT objects prior to deployment.
