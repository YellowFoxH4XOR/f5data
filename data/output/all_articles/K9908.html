Note: Secure shell (SSH) and serial console idle timeout does not start counting down until a user exits the TMOS Shell (tmsh), or when the tmsh session has timed out. If the user is still logged in to the tmsh session, the SSH or serial console session idle timeout will not be enforced. To impose an automatic logout from the BIG-IP system for a remote or serial console connected tmsh user, you must set the idle timeout for the tmsh session as well as the SSH or serial console session.

Important:  If a system broadcast message occurs while you are logged in to a tmsh session, the tmsh idle timeout is reset.  This can result in the tmsh session remaining active if the broadcast message repeats.  The Advanced Shell (bash) idle timeout is not affected by system broadcast messages.

Configure automatic logout for idle Configuration utility sessions using Configuration utility

To watch a video demo of this procedure, go to K000157858: Configure automatic logout for idle sessions on the BIG-IP system using the Configuration utility.

To automatically log out inactive Configuration utility sessions after a specified idle time, perform the following procedure using Configuration utility:

  1. Log in to the Configuration utility.
  2. Go to System > Preferences.
  3. For Security Settings, enter an appropriate value for the Idle time before automatic logout setting.

    Note: The value is the number of seconds an administrative session should remain idle before the session is automatically logged out. Values may be in the range of 120 to 2,147,483,647 seconds and cannot be disabled. The default is 1200 seconds.

  4. To save the new configuration, Select Update.

Note: The new timeout immediately applies to all existing web logon sessions.

Configure automatic logout for idle Configuration utility sessions using tmsh

To automatically log out inactive Configuration utility sessions after a specified idle time, perform the following procedure using tmsh:

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To automatically log out inactive Configuration utility sessions, use the following command syntax:

    modify /sys httpd auth-pam-idle-timeout <seconds>

    For example, to configure a 15-minute automatic logout idle time, enter the following command:

    modify /sys httpd auth-pam-idle-timeout 900

  3. Save the change by entering the following command:

    save /sys config

Note: The new timeout immediately applies to all existing web logon sessions.

Configure automatic logout for idle Configuration utility sessions using REST API

To automatically log out inactive Configuration utility sessions after a specified idle time, perform the following procedure using REST API:

  1. To modify the automatic idle timeout value for inactive Configuration utility sessions, you can issue the following API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/httpd/ -d '{"authPamIdleTimeout": <seconds>}'

    For example, to configure a 15-minute automatic logout idle time, you can use the following API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" https://[IP Address]/mgmt/tm/sys/httpd/ -d '{"authPamIdleTimeout": 900}'

  2. To view the updated automatic logout for inactive Configuration utility sessions, you can use the following API query:

    curl -ku [username]:[password] -H "Content-Type: application/json" "https://[IP Address]/mgmt/tm/sys/httpd/?$select=authPamIdleTimeout" | jq .

Note: The new timeout immediately applies to all existing web logon sessions.

Configure automatic logout for idle SSH connections (command line sessions)

By default, no idle timeout is configured for BIG-IP SSH command line sessions.

Note: The SSH idle timeout does not begin counting down until a user exits the tmsh session, or when the tmsh session has timed out. If the user is still logged in to the tmsh session, the SSH session idle timeout will not be enforced. To impose an automatic logout from the BIG-IP system for a remote tmsh user, you must set the idle timeout for the tmsh session as well as the SSH session.

To configure an automatic logout for idle command line sessions over SSH, perform the following procedure:

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure an automatic logout idle time for SSH sessions, use the following command syntax:

    modify /sys sshd inactivity-timeout <seconds>

    For example, to configure a 15-minute automatic logout idle time, enter the following command:

    modify /sys sshd inactivity-timeout 900

  3. Save the change by entering the following command:

    save /sys config

Future shell sessions will close when the session has been idle for the specified number of seconds.

Note: The new timeout does not apply to the current shell session. The user must log out and back into the shell for the new setting to take effect.

Configure automatic logout for idle serial console sessions (command line sessions)

By default, no idle timeout is configured for BIG-IP serial console command line sessions.

Note: The serial console idle timeout does not begin counting down until a user exits the tmsh session, or when the tmsh session has timed out. If the user is still logged in to the tmsh session, the serial console session idle timeout will not be enforced. To impose an automatic logout from the BIG-IP system for tmsh user connected to the serial console, you must set the idle timeout for the tmsh session as well as the serial console session.

To configure an automatic logout for serial console idle sessions, perform the following procedure:

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure an automatic logout idle time for serial console sessions, use the following command syntax:

    modify /sys global-settings console-inactivity-timeout <seconds>

    For example, to configure a 15 minute automatic logout idle time, enter the following command:

    modify /sys global-settings console-inactivity-timeout 900

  3. Save the change by entering the following command:

    save /sys config

Note: The new timeout does not apply to the current serial console session. The user must log out and back into the serial console for the new setting to take effect.

Configure automatic logout for idle tmsh sessions (BIG-IP 11.0.0 and later)

By default, idle timeout is disabled for BIG-IP tmsh sessions.

To configure an automatic logout for tmsh idle sessions, perform the following procedure:

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To configure an automatic logout idle time for tmsh sessions, use the following command syntax:

    modify /cli global-settings idle-timeout <minutes>

    For example, to configure a 15-minute automatic logout idle time, enter the following command:

    modify /cli global-settings idle-timeout 15

  3. Save the change by entering the following command:

    save /sys config

Note: The new timeout immediately applies to all existing tmsh sessions.
