Description

Rediscover and Re-import failing for LTM devices containing FastHTTP Virtual servers with Irule containing HTTP events


In Devices tab after marking both clustered devices and click more... re-discover and re-import, process fails with:

 Failed to synchronize clustered devices; reason: Worker http://localhost:8100/cm/adc-core/working-config/ltm/virtual failed validation with status 500: java.lang.IllegalArgumentException: iRule with HTTP_REQUEST needs an associated HTTP profile. Please ensure you have selected the TCP protocol, check the associated HTTP profile or the Universal Persistence profile and try again.


Environment

  • BIG-IQ CM
  • Managed BIG-IP Cluster
  • Virtual server with FastHTTP profile with HTTP irule assigned
  • LTM discover/Import for cluster device via More> Rediscover and Reimport option

Cause

BIG-IQ doesn't support PerformanceHTTP VS with irule containg HTTP_ events

ID created to track this issue ID 1408501

Recommended Actions

Currently no workaround is provided. ID should be fixed in future release.

If immediate fix is required please open Support Ticket referring to this article and ID
