Description

SNMPv2 tests gives successful results in SolarWinds. You now want to switch to SNMPv3. You confirmed all SNMPv3 parameters (username, passwords, algorithms, etc) are the same on both SolarWinds and BIG-IP device. However, SolarWinds keeps saying tests failed.

Environment

  • BIG-IP
  • SolarWinds
  • SNMPv3

Cause

According to SNMPv3 test fails when adding and/or editing nodes in Orion Website, tests will fail when the below OIDs return no response or an empty response:

1.3.6.1.2.1.1.1 sysdescr
1.3.6.1.2.1.1.2 sysobjectid
1.3.6.1.2.1.1.3 sysuptime

Recommended Actions

These OIDs will not be accessible until you change OID value in BIG-IP SNMPv3 configuration to .1. For more information, refer to K36310360: Unable to retrieve specific information from the BIG-IP when SNMPv3 is configured.
