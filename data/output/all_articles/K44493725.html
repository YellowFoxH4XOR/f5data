K44493725: Manually unlocking a local user account on the BIG-IQ system

Topic

You should consider using this procedure under the following condition:

  • You want to manually unlock a local user account that has been locked on the BIG-IQ system. If you want to configure the BIG-IQ system to automatically unlock an affected local user account, refer to K49507549: Configuring a secure password policy for the BIG-IQ system.

Description

You can configure the BIG-IQ system secure password policy to lock a local user account after a specified number of failed login attempts. For more information about configuring the secure password policy, refer to K49507549: Configuring a secure password policy for the BIG-IQ system.

If a local user account is locked due to breaching the specified number of failed login attempts, you can manually unlock the affected local user account by performing the following procedure.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have administrator or root user access to the BIG-IQ system's TMOS Shell (tmsh) or Advanced Shell (bash).
  • You have not enabled the BIG-IQ system to automatically unlock the affected local user account after a configured number of seconds. For more information, refer to K49507549: Configuring a secure password policy for the BIG-IQ system.

Procedures

Manually unlocking an affected local user account using tmsh

To manually unlock an affected local user account, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To view the list of local user account(s) with login failures, enter the following command:

    show /auth login-failures

  3. Review the Locked out column to determine which local user account breached the configured value of the max-login-failures setting. A local user account is locked when its Locked out column indicates yes.
  4. To unlock the affected local user account(s), use the following command syntax:

    reset-stats /auth login-failures <user1> <user2> …

    For example, to unlock the local user account testuser1, enter the following command:

    reset-stats /auth login-failures testuser1

  5. To verify that the local user account is unlocked, enter the following command:

    show /auth login-failures

    The Locked out column now indicates no.
