K000157124: Data Collection Device is unable to load a configuration after upgrade to 8.4.1

Type
Support Solution
Published
2025-11-13
Updated
2026-03-04
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.X, 8.4.1, 8.4.0
Source
https://my.f5.com/manage/s/article/K000157124

Description

After upgrading BIG-IQ Data Collection Devices (DCDs) from version 8.3.0 to 8.4.1, the DCDs may fail to load configuration and display the error message “StandardError: Master key is not set. The master key must be set before the system can start.” 

Environment

  • Data Collection Device
  • Upgrade
  • Master Key

Cause

The issue is related to a change is  made to the bigip.conf file which causes the initial config to fail to load.  This causes a failure to load the master key only, which gives the indication that the key is not set. No changes to the master key are needed as part of this process. PE has assigned ID 2227629 to track the permanent resolution.  

Recommended Actions

******

A) Login to bash as root and boot back to previous partition ( rollback upgrade

B) Remove the software volume containing the failed upgrade

  1) List the volumes that contain Big-IQ software: tmsh show sys software status

  2) Identify the volume associated to the failed upgrade to 8.4.1

  3) Remove the volume identfied in step 2: tmsh delete sys software volume

Example:

  [root@bigiq-cm:Active:Standalone] config # tmsh show sys software status

 

  --------------------------------------------------------------------

  Sys::Software Status

  Volume Product Version Build Active Status Allowed Version

  --------------------------------------------------------------------

  HD1.1 BIG-IQ 8.3.0 0.0.811 yes complete      yes

  HD1.2 BIG-IQ 8.4.1 0.0.90  no complete      yes

   

  [root@bigiq-cm:Active:Standalone] config # tmsh delete sys software volume HD1.2

   

******

C) Modify the /config/startup script so the upgrade will complete:

  1) Preserve the existing file:  /bin/cp -p /config/startup{,.orig}

  2) Make the file writeable:  /bin/chmod u+w /config/startup

  3) Make the needed change:  /bin/echo "/bin/sed -i.upgrade 's/TMSH-VERSION: 8.4.1/TMSH-VERSION: 17.5.1.2/g' /config/bigip.conf" >> /config/startup

 

******

D) Perform the upgrade process normally.  

Note: The customer will need to rebuild the new volume manually as appropriate to ensure proper sizing.

******

E) Once the upgrade has completed and validated for all devices, return the /config/startup file to original and remove the preserved bigip.conf file:

  1) /bin/cp -p /config/startup{.orig,}

  2) /bin/rm /config/bigip.conf.upgrade
