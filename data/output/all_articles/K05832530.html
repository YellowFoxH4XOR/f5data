Description

Network setup is as follows:
[Client machine] - [BIG-IP LTM] - [Pool member: NGINX proxy]

JMeter is used to test the connectivity to the pool member (NGINX proxy) and the test will fail when OneConnect profile is enabled on the BIG-IP LTM.

JMeter will fail with an error message similar to below:
Premature end of content-length delimited message body (expected:  91,672; received 88,666)

Other testing tools might also fail with or without OneConnect enabled.

Environment

  • BIG-IP
  • NGINX proxy as a pool member (node)
  • JMeter test will fail when OneConnect is enabled
  • Other test will/might fail with or without OneConnect enabled

Cause

This is a NGINX proxy setting issue.

Recommended Actions

The issue is related to the NGINX proxy settings.

You will need to modify the hold time and packet size settings on the NGINX proxy configuration.

Important: Please consult with the NGINX certified engineer before making changes to the NGINX proxy configuration. F5 will not take responsibility for any unexpected outcome.
