Issue

Error Message

info sod[<PID>]: 010c0085:6: First failover status message received from device <device_name> (<mgmt_IP Address>) (unicast: -> <unicast_IP_Address>)

In this error message, note the following:

  • <PID> is the process ID of the sod process.
  • <device_name> is the hostname of the high availability (HA) peer device that sent the failover status message.
  • <mgmt_IP address> is the administrative IP address of the HA peer device.
  • <unicast_IP_Address> is the IP address added to the failover unicast address on the local system.

For example:

info sod[5925]: 010c0085:6: First failover status message received from device example_device_name (192.0.2.2) (unicast: -> 198.51.100.3)

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You are attempting to configure HA failover on a device by adding a local address to the failover unicast configuration.
  • The local sod process receives a failover message from the HA peer device on the specified unicast IP address for the first time.

Impact

The specified IP address is added to the HA configuration and failover communication is established with this IP address on the local system.

Recommended Actions

You should verify the HA status of the devices by displaying the details of the failover status. To do so, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. Display the status of the traffic group on the device by typing the following command:

    show /cm failover-status
