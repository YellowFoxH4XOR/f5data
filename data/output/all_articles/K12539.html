Known Issue

This is the result of a known issue. When running the csTest.pl script on BIG-IP versions 10.1.0 or later, the system reports an error message that appears similar to the following example:

Warning: BigDB daemon (bigdbd) is not running.

This error message is benign and is generated because the bigdbd process was removed from the BIG-IP software starting in version 10.1.0.

Note: The csTest.pl script is a troubleshooting and diagnostic tool for the ConfigSync process. For more information, refer to K7024: Overview of the ConfigSync process.

F5 Product Development tracked this issue as ID 348578 and it was fixed in BIG-IP version 11.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.
