Known Issue

The Traffic Management Microkernel (TMM) may restart while processing a suspending iRules command during a CLIENT_CLOSED or SERVER_CLOSED event.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server that uses an iRule.
  • The iRule uses a command that suspends iRules processing within the CLIENT_CLOSED or SERVER_CLOSED event.

    Note: The term suspend is commonly referred to as park or parking.

Impact

The BIG-IP system fails to process traffic while TMM restarts, and devices in a high availability (HA) configuration may fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to another host in the device group.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system temporarily fails to process traffic while TMM restarts.

Workaround

To work around this issue, ensure that the iRule does not use a suspending iRules command within a CLIENT_CLOSED or SERVER_CLOSED event.

Impact of workaround: F5 recommends that you test any iRules changes during a maintenance window.
