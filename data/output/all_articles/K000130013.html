K000130013: Unable to set claim in JWT (SSO-Bearer) as JSON List

Type
Support Solution
Published
2023-01-31
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000130013

Description

You would like to set claim in the SSO Bearer JWT (JSON Web Token) as a list.

Environment

  • JWT, token_id or user_info claim configuration

Cause

Not currently supported.
There is a request for improvement on this with the ID of: 724666

Recommended Actions

1.   Create a Claim with the Claim Type "String".
      Query AD (Claim Value) for memberOf or whatever attribute holds all the information that gets returned as a list.

2.   Make the claim available in one, two or all three of these locations:
  • In the Visual Policy Editor: OAuth Authorization (Add new entry): Access Token Claims
  • Access: Federation: OAuth Authorization Server: OAuth Profile: <your profile>: JWT Claims
  • Access: Federation: OAuth Authorization Server: Client Application: <your application>: JWT Claims

The claim will be populated as a list separated by pipe characters ( | ).

The list will be separated by | (pipes), you can make it more JSON-like by a small iRule
