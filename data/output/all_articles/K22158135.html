Description

The CPF uses a third-party library  for compiling groovy scripts. 
In version 2.4.5. there is a memory leak reported by Apache

    Note: That bug was fixed in version 2.4.8.

    Environment

    • Traffix SDC/EMS
    • CPF use Apache version 2..4.5

    Cause

    On this version, a memory leak bug was detected and reported by Apache, see explanation in :
    Note: The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge

    • OutOfMemoryError starting from groovy-2.4.5 version

    Recommended Actions

    Procedure for update groovy-all-2.4.5.jar to groovy-all-2.4.9.jar file.

    Note: This procedure requires restarting the processes and therefore it is recommended to be performed during a scheduled maintenance window.
     

    • Backup groovy-all-2.4.5 lib files

    1. Login to SDC 1st node via SSH
    2. Backup the current groovy lib file 
    # cd /opt/traffix/sdc<version>/lib
# mv groovy-all-2.4.5.jar  groovy-all-2.4.5.jar.orig
     
    3. Update groovy.all-2.4.9.jar file.
    Put groovy.all-2.4.9.jar in /opt/traffix/sdc<version>/lib/
      
    # chmod +x groovy.all-2.4.9.jar
# chown traffix:traffix groovy.all-2.4.9.jar
    Repeat steps #1-3 per on all SDC nodes
     

    • Apply Changes

    1. Make sure all processes are running 
     # monit summary
     
    2. Restart the CPF1  process and make sure the process is running 
    # monit  stop / start  <node_name>CPF1 process
    3. Review the process logs at /opt/traffix/sdc<version>/logs/<process_name> 
    # cat /opt/traffix/sdc<version>/logs/<process name>
    4. Make sure that there are no failures (such as startup failure or restarts)
    5. Monitor traffic
     
    After completing this step, repeat on the next node
     

    • Rollback

     To rollback we will restore the backed-up groovy lib file  
    # cd /opt/traffix/sdc/opt/traffix/sdc<version>/lib
# mv groovy-all-2.4.9.jar  groovy-all-2.4.9.jar.orig
# mv groovy-all-2.4.5.jar.orig  groovy-all-2.4.5.jar
    Execute Apply Changes section
