Topic

You cannot use the loopback, and by default you cannot use link-local addresses as a virtual server address, pool member address, self IP address, and SNAT/NAT address on the BIG-IP system.

Starting in BIG-IP 11.4.1 and the 11.3.0 HF8 and 11.2.1 HF10 hotfixes, you can use the IPv4 link-local addresses to configure on any of the BIG-IP system data plane addresses by setting the config.allow.rfc3927 database key to enable.

Note: The database key is not applicable to the management plane of the BIG-IP system. You can configure the management IP address with IPv4 link-local addresses, but only with a /16 netmask.

Description

The loopback and link-local addresses are a range of addresses designated for special uses per IETF RFC5735: Special Use IPv4 Addresses, as well as RFC4291: IP Version 6 Addressing Architecture.

The loopback address range 127.0.0.0/8 for IPv4 and ::1/128 for IPv6 is assigned for the purpose of looping traffic within a host and must never be sent outside the host. When you attempt to configure the BIG-IP system to use an address from the Loopback address range for various objects such as virtual server, pool member, self IP, and SNAT/NAT, the BIG-IP system fails to assign the address to the object and reports the following error message in both the Configuration utility and command line:

01020061:3: IP Address 127.100.0.1 is invalid, loopback not allowed.
01020061:3: IP Address ::1 is invalid, loopback not allowed.

The IPv4 link-local address range 169.254.0.0/16 is assigned for the purpose of IP auto-configuration when a DHCP server is not available and is limited for communication between hosts within a single link. When you attempt to configure the BIG-IP system to use an address from the link-local address range for various objects, the BIG-IP system fails to assign the address to the object and reports the following error message in both the Configuration utility and command line:

01020062:3: IP Address 169.254.0.1 is invalid, link-local address not allowed.

Unlike IPv4, every IPv6-enabled interface requires an address assigned from the link-local address range FE80::/10 for the purpose of Neighbor Discovery Protocol and any other IPv6 protocols that require link-local address to operate. If you attempt to configure the BIG-IP system to use an address from the IPv6 link-local address range for various BIG-IP objects, the BIG-IP system accepts the address range and creates the object without errors.

Recommendations

When you configure an address for a BIG-IP object, you should use any IP address that does not fall in the loopback or link-local address ranges.
