Known Issue

The connection limit on a virtual server may not be enforced.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server on the BIG-IP system with the following settings:

    • You have set a connection limit on the virtual server.
    • You have set the default pool to None.
  • The virtual server processes connections beyond the configured connection limit.

Impact

The connection limit is not enforced, and the affected virtual server continues to accept connections beyond the configured limit.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe that the number of connections exceeds the connection limit set on the affected virtual server.
