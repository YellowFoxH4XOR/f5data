Topic

 The remote logging profile allows an administrator to configure the BIG-IP ASM system to direct log information to a syslog server.

The Storage Format options allow the administrator to specify what data is sent to the remote syslog server.

The following table contains details about the Storage Format options.

blocking_exception_reasonThe blocking exception reason when a configured violation was not blocked. Available in BIG-IP 13.0.0 and later.
captcha_resultThe result of the BIG-IP ASM presented captcha challenge. Available in BIG-IP 13.1.0 and later.
client_typeThe type of client utilized of the request. Available in BIG-IP 13.1.0 and later.
compression_methodThe compression method used in the request ("none", "gzip", "deflate" or "compress").
conviction_trapsA flag that indicates whether traps were injected to the response.
credential_stuffing_lookup_resultCredential stuffing lookup result (possible values "N/A", "true" or "false").
date_timeThe date and time information reported in the following format: YYYY-MM-DD HH:MM:SS This is the same format that is used in the Request page within the Configuration utility. Available in BIG-IP 10.0.0 and later.
dest_ipIP address of the virtual server. Available in BIG-IP 10.1.0 and later.
dest_portThe port used on the BIG-IP ASM local virtual server. Available in BIG-IP 10.1.0 and later.
device_idThe device identification number of the device that made the request. Available in BIG-IP 12.1.0 and later.
enforced_byEnforcement policy type which was applied on the request, either asm policy or cloud based service instruction ("asm-basic-policy", "asm-policy", "tap-strict-policy", "tap-basic-policy" or "tap-action").

request_status

The status of client request made to Web Application as assigned by the BIG-IP ASM.

The possible values reported by this option are the following:

blocked - The request was blocked due to a violation encountered. A blocking response page was returned to the client.
alerted - The request contain violations but does not blocked (Typical in cases where the enforcement mode is set to transparent)

staged_sig_set_namesThe signature set names of the currently staged signatures. Available in BIG-IP 12.1.3.2, 13.0.0 and later.

The amount of information that can be sent in a message to a remote logging facility depends on the type of protocol chosen. TCP has a default allowed message size of 2048 bytes or 2k and is configurable to a maximum of 64k using the Maximum Entry Length setting. TCP-RFC3195 has a maximum allowed message size of 2048 bytes or 2k and is non-configurable. User Datagram Protocol (UDP) has a default allowed message size of 1024 bytes or 1k and is configurable to a maximum of 64k using the Maximum Entry Length setting.

The maximum allowed message size of the different protocol options is important when determining which items you want to include, as well as the order they are placed.

For example, if a client requests an item that is as large or larger than the allowed maximum size at the beginning of the list, the request may take all of the available message size. As a result, there may not be any room left for additional items to be sent to the remote server.
