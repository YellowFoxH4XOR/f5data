Description

Creating a Certificate Signing Request (CSR) on BIG-IP LTM version 16.1.3.5 that matches the content of a CSR generated in version 14.0 (and earlier), specifically regarding the inclusion of the "Key Usage" parameter. Need to confirm whether any additional configuration is required in v16 to ensure the CSR content will be equivalent to that of v14, given that "Key Usage" in configuration utility or "key-usage" in tmsh became an available option in v16.

Environment

  • LTM 16.1.3.5 and later
  • Creating CSR request to match previous versions (Versions prior to 16.1.3.5)

 

Cause

The difference in CSR content between BIG-IP versions is due to the introduction of the optional "key-usage" or "Key Usage" parameter in v16. In earlier versions (v13/v14), this extension was not available and thus not included in CSRs. In v16, unless the user specifies "key-usage" during CSR creation, the extension is omitted, resulting in a CSR that matches the content of those generated in previous versions.

 

Recommended Actions

  • To generate a CSR in BIG-IP v16 that matches the content of a CSR from v14 (i.e., without the key-usage extension), do not specify the "key-usage" parameter when creating the CSR via tmsh and leave "Selected" empty if using the configuration utility.
  • If the key-usage extension is required for compliance or specific use cases, it can be added explicitly in v16 using the appropriate TMSH command options or also via the configuration utility.
