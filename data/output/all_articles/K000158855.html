Description

This article describes how to apply a specific server SSL profile to match a given Portal Access resource Host.
It can be used if the default server SSL profile assigned to your Virtual Server has some settings that do not work well with that specific Portal Access resource Host, or it can be used to apply specific settings for that Host only (like a specific SSL parameter, such as Server Name Indication value).

Environment

  • BIG-IP APM Portal Access
  • Server SSL profile

Cause

  •  Some servers require specific SSL parameters 

Recommended Actions

 The below iRule workaround example can be used:

when REWRITE_REQUEST_DONE {
    if { [HTTP::host] == "example" } {
        set changeSSLProfile 1
    }
}
when SERVER_CONNECTED {
    if { [info exists changeSSLProfile] && $changeSSLProfile } {
        SSL::profile your-specific-serverssl-profile
        unset changeSSLProfile
    }
}

You only need to replace "example" with the Host header fqdn value  expected by that specific server and "your-specific-serverssl-profile" by your custom server SSL profile.
