Known Issue

This is the result of a known issue. When a virtual address is disabled in the BIG-IP LTM Configuration utility or from the command line, the status is displayed incorrectly. For example, if you disable a virtual address in the BIG-IP LTM Configuration utility and refresh the browser page, the status continues to be displayed as available (green).

F5 Networks Product Development tracked this issue as CR74816 and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.3, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP LTM Release Notes.
