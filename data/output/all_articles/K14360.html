K14360: Logging profile is now associated with a virtual server

Type
Knowledge
Published
2015-11-07
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 11.4.1, 11.4.0, 11.3.0
Source
https://my.f5.com/manage/s/article/K14360

Issue

Old Behavior

In versions prior to BIG-IP ASM 11.3.0, a logging profile is associated with a security policy. You can configure this functionality on the Security Policy Properties page (Application Security > Policy > <policy name> > Properties).

New Behavior

Beginning in BIG-IP ASM 11.3.0, a logging profile is associated with a virtual server. You can configure this functionality in the Policy Settings section under the Security tab of the Virtual Server Properties page.

If you do not configure a virtual server with a logging profile before you create a new security policy using the ASM Deployment Wizard, the ASM Deployment Wizard reports a message that appears similar to the following example, and associates the default logging profile (Log illegal requests) with the virtual server:

Note: Selected HTTP Virtual Server has no assigned logging profile with Application Security enabled

If you create a new security policy without using the ASM Deployment wizard, the system does not report a message or associate any logging profile with the virtual server.

If you upgrade your system from versions prior to 11.3.0 to version 11.3.0, the logging profiles of all active security policies are re-associated with their respective virtual servers based on their last HTTP Class profile associations. However, if a virtual server has more than one HTTP Class profile before the upgrade, the system associates the logging profile of the last HTTP Class profile in the HTTP Class profile list with the virtual server.

Impact

  • Depending on the method you used to create a new security policy for a virtual server that is not associated with a logging profile, the system either associates a default logging profile or no logging profile with the virtual server.
  • For a system that is upgraded from versions prior to 11.3.0 to version 11.3.0, the system may not associate the desired logging profile with a virtual server that has multiple HTTP Class profiles.

Recommended Actions

Depending on your application environment, you may have to reconfigure the virtual server with the desired logging profile. For information about configuring a logging profile and associating it with a virtual server, refer to the Logging web application data section of the Configuring General System Options chapter of the Configuration Guide for the BIG-IP Application Security Manager.
