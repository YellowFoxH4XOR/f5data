Known Issue

Note: The issue described in this Solution affects only those platforms that include a Packet Velocity ASIC (PVA) chip. These are the BIG-IP 2400, 3400, 6400, 6800, 8400, and 8800 platforms. For more information about the PVA chip, refer to K4832: Overview of Packet Velocity ASIC (PVA) Acceleration features and sub features.

This is the result of a known issue. When merging a file into the configuration of the BIG-IP system, the pvad process crashes and dumps core if the file contains multiple declarations of the same pool. For example, the pvad process would crash and dump core if you ran the bigpipe merge /var/tmp/config.txt command, and the /var/tmp/config.txt file included the following code:

pool http_pool {
monitor all tcp
members
10.0.0.10:80
10.0.0.11:80
}
pool http_pool {
monitor all tcp
members
10.0.0.10:80
10.0.0.11:80
}

When this issue occurs, the pvad process automatically restarts and the BIG-IP system quickly resumes normal operation. However, you may experience brief traffic disruptions while the pvad process is down. Additionally, an error message which appears similar to the following example is logged to the /var/log/ltm file:

pvad[1952]: 01130005:3: ../LogStream.cpp:89 - No existing object with key=http_pool 10.0.0.10 80 - Expression 'obj != Global::cfg.end()' failed in '../MainEventHandler.cpp', line: 542

Although the pvad process crashes because of the identical pool declarations, the file is correctly merged into the running configuration of the BIG-IP system (the offending pool is added only once).

Note: The details of the pool do not need to be identical to cause the merge to fail. Two identically named pools configured with different pool members will also cause this issue.

F5 Product Development tracked this issue as ID 327993, ID 307888, ID 206583, ID 307889, ID 317445 (formerly CR118188), and ID324871 (formerly CR99350) and it was fixed in BIG-IP versions 9.4.8 and 10.0.1. For information about upgrading, refer to the BIG-IP LTM, ASM, PSM, Link Controller, WebAccelerator, or WOM release notes.
