K13417045: ''ModuleNotLicensed: :Disallowed version'' error in console after upgrade

Type
Support Solution
Published
2023-08-07
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K13417045

Description

After the upgrade, your big-ip is not processing traffic and in CLI you are observing prompt similar to this:

[user@bigip.hostname:ModuleNotLicensed: :Disallowed version:Disconnected] / #

Environment

  • BIG-IP upgrade
  • Virtual Edition (VE)
  • Version Plus License 

Cause

Starting with BIG-IP 11.4.1, customers can purchase all BIG-IP Virtual Edition (VE) SKUs with Version Plus licenses.
Version Plus licenses enable customers to use BIG-IP VE with perpetual usage. However, upgrades are limited to software versions within a pre-established range of software releases. Refer to K15643: BIG-IP VE license offerings

Recommended Actions

Rollback to the previous working version and install version supported by your license or contact your sales team and get a new license with support for the desired version. 
If you don't know which versions are supported by your license, you can refer to K15643: BIG-IP VE Version Plus license offerings .
