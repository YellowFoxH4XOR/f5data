Description

After loading UCS from a BIG-IP Virtual Edition to an Appliance or VIPRION, you've encountered "Configuration error: vmw-compat: vlan may only have one interface"

Environment

  • BIG-IP Appliance or VIPRION
  • Error Encountered: Configuration error: vmw-compat: vlan may only have one interface

Cause

The value of vmw-compat in the DB variable vlan.macassignment is only specific for Virtual Edition systems.

K14513: MAC address assignment for interfaces, trunks, and VLANs (11.x and later)

Recommended Actions

Change the setting of vlan.macassignment to either unique (default) or global.
You can do this by editing bigip_base.conf file.

ltm global-settings general {
share-single-mac vmw-compat <---!!! Change the value or remove this line to set as default
}
