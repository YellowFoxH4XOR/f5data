Description

Despite enabling cookie encryption on the BIG-IP virtual server as per the CISA advisory, the desired encryption behavior is not being observed.

  • K000141473: Overview and impact of persistence cookie encryption as per CISA advisory
  • K14784: Configuring cookie encryption within the HTTP profile

Environment

  • BIG-IP LTM
  • Persistence Cookie
  • HTTP Profile
  • Cookie Encryption
  • CLI
  • GUI

Cause

Incorrect configuration of the HTTP Cookie Encryption profile, specifically the use of the "encrypt-cookies" entry with an incorrect name.

Example:
tmsh list ltm profile http /Common/http-cookie-encryption-profile
...
encrypt-cookies { BIGipCookieName }
}

Recommended Actions

To resolve this issue, ensure the "encrypt-cookies" entry name in the HTTP Cookie Encryption Profile adheres to the BIG-IP naming convention: "BIGipServer<pool-name>". Follow the steps outlined in Option A or B below.

Option A. Please refer to below on how to get the correct HTTP Cookie Name.

  1. Login to BIG-IP GUI
  2. Check the Virtual Server assigned Pool_name
    Example: Pool assigned: pool_00xxxxxx_cookie_encrypt  
  3. Referring to the KB article K14784, the cookie naming convention is "BIGipServer<pool-name>", in short, it will be BIGipServer + <Pool_Name>
    Example: With above Pool name as an example, it will be BIGipServer + pool_00xxxxxx_cookie_encrypt, hence, the cookie name will be BIGipServerpool_00xxxxxx_cookie_encrypt

  4. Log in to the BIG-IP device.
    1. Navigate to Local Traffic > Profiles > Services > HTTP.
    2. Locate and select the desired Custom_HTTP_Profile_Name.
    3. Enter the correct Cookie Name under "Encrypted Cookies" section (e.g. BIGipServerpool_00xxxxxx_cookie_encrypt).

  5. Once you've completed the configuration, you can start a new browsing session to access the Virtual Server IP and verify that the cookie is encrypted properly.

Option B. Please refer to below example steps to extract the the correct HTTP Cookie Name, this information can be extracted from Chrome browser Developer Tools.

  1. Open Chrome browser
  2. Run developer tools "Ctrl + Shift + I " --> Application [tab] --> Expand Storage > Cookies
  3. Browse to the Virtual Server VIP
  4. Check the Cookie name from the developer tools
                                                                                                                            Figure: Chrome Developer Tool Application Cookie Name 
  5. Figure: Chrome Developer Tool Application Cookie Name 
  6. Log in to the BIG-IP device.
    1. Navigate to Local Traffic > Profiles > Services > HTTP.
    2. Locate and select the desired Custom_HTTP_Profile_Name.
    3. Enter the displayed Cookie Name from Chrome's under "Encrypted Cookies" section (e.g. BIGipServerpool_00xxxxxx_cookie_encrypt).

  7. Once you've completed the configuration, you can start a new browsing session to access the Virtual Server IP and verify that the cookie is encrypted properly.
