Security Advisory Description

The TCP stack in the Linux kernel 3.x does not properly implement a SYN cookie protection mechanism for the case of a fast network connection, which allows remote attackers to cause a denial of service (CPU consumption) by sending many TCP SYN packets, as demonstrated by an attack against the kernel-3.10.0 package in CentOS Linux 7. NOTE: third parties have been unable to discern any relationship between the GitHub Engineering finding and the Trigemini.c attack code.(CVE-2017-5972)

Impact

In a default configuration, the BIG-IP system is not vulnerable. However, BIG-IP systems can be vulnerable when you disable the SYN cookie protection (the SYN cookie protection is enabled by default), and the self IP address has the ability to ingress more than 10G of traffic throughput.

Security Advisory Recommended Actions

To mitigate this vulnerability, ensure that the SYN cookie protection is enabled with the default threshold. Additionally, you can use the Port Lockdown feature to block ingress traffic to exposed services and/or filter ingress connections to self IP addresses from untrusted sources using either upstream devices or packet filters. For more information about these features, refer to the respective articles listed in the Supplemental Information section.
