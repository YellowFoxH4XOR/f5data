K000140332: iAppsLX FAST template shows "Not Found The requested URL was not found on this server"

Type
Support Solution
Published
2024-08-27
Updated
2024-08-27
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000140332

Description

You are trying to access iApps --> Application Services --> Application LX --> F5 Application Services Templates after a restoring of UCS/migration and see the following error message:

 

Not Found

The requested URL was not found on this server

 

Environment

iAppsLX

Cause

The FAST rpm package is corrupted or not updated.

Recommended Actions

Update the AS3 rpm package and the f5-appsvcs-templates:

 

1. Update the AS3 rpm package by following the article: Downloading and installing the BIG-IP AS3 package (f5.com) 

2. Download the latest f5-appsvcs-templates from the article: https://clouddocs.f5.com/products/extensions/f5-appsvcs-templates/latest/userguide/install-uninstall.html
