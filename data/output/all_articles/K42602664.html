Description

ARP and ICMP Echo on the Virtual Address is disabled if DoS profile is applied to the Big-IP LTM virtual Server or Big-IP DNS Listener 

  • ICMP and ARP request fails
  • ICMP and ARP is disabled on Virtual Address

    ltm virtual-address /Common/192.168.1.1 {
    address 192.168.1.1
    arp disabled
    icmp-echo disabled
    inherited-traffic-group true
    mask 255.255.255.255
    server-scope none
    traffic-group /Common/traffic-group-1
    }

Environment

  • Apply DOS profile via Security >> DoS Protection  >> Protected Object

Cause

Applying DoS profile via DoS Protection page creates the Virtual Server as Protected Object (PO). The primary reason to disable ARP/ICMP for PO is, that PO not necessarily hosted on a BIG-IP. The BIG-IP is just transparently watching the traffic (imagine this as L2 deployement). When threshold breaches, it takes action as per PO configuration. Since Protect Objects could be any IP behind BIG-IP, it shouldn't respond to ARP/ICMP on it's behalf.

Recommended Actions

Apply DoS profile using Security tab of the Virtual Server property

Enable ARP and icmp-echo manually on the Virtual Address
