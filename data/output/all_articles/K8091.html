Known Issue

This is the result of a known issue. When a Windows Vista system uses a solid color desktop background, logging into Protected Workspace on the FirePass controller will hang the Vista system. Both the browser and all other processes will be unresponsive. You can launch the Windows Task Manager and terminate the browser process or the processes associated with Protected Workspace, but this will not typically restore the system to a functioning state. You can use the Task Manager to log off or reboot in order to restore system functionality.

This issue will not appear if the Vista system has not been rebooted since the desktop was configured with a solid color.

F5 Networks Product Development is tracking this issue as ID 269220 (Formerly CR88761) and has been fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue has been fixed in cumulative hotfix HF-601-9 issued for FirePass version 6.0.1 and cumulative hotfix HF-602-1 issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

The Vista desktop configurations that trigger this issue are set by the Personalization Control Panel. To work around this issue you can configure the Windows Vista Desktop to avoid using solid colors with the Personalization setting from the following selections:

  • Window Color and Appearance
  • Desktop Background
  • Theme

For example:

  • The Windows Standard setting of the Color Scheme field from Window Color and Appearance
  • The Solid Colors setting of the Picture Location field from Desktop Background
  • The Windows Classic setting of the Theme field from Theme

Other settings that create solid colors will also trigger this issue.
