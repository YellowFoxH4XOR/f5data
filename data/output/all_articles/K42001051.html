K42001051: Upstream Proxy setting for APM Secure Web Gateway

Description

You are trying to configure an upstream proxy for your BIG-IP APM system with Secure Web Gateway, as your network policies do not allow direct internet access for downloading data.

Environment

  • BIG-IP APM
  • Secure Web Gateway

Cause

The URL database is only accessible on a BIG-IP APM system with an SWG subscription.

Recommended Actions

To configure an upstream proxy for the BIG-IP system:

  1. Navigate to SYSTEM > CONFIGURATION > DEVICE > UPSTREAM PROXY on the Main tab.
  2. Type a name for the proxy server in the Name field.
  3. Type the IP address for the proxy server in the IP Address field.
  4. Type the port number for the proxy server in the Port field.
  5. If needed, provide credentials for an account on the proxy server in the User Name and Password fields.
  6. Click Save.

Additional Information

The upstream proxy configuration is saved in /config/bigip_base.conf. You can view the configuration using the command:

tmsh list sys management-proxy-config

Sample output:

sys management-proxy-config <Name> {
    password <Password>
    proxy-ip-addr <IP Address>
    username <User>
}
