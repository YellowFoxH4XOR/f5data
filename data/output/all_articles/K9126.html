Known Issue

This is the result of a known issue. When Win2000 is chosen for the agent type, the snmp_dca monitor uses the generic HOST.mib file to poll Microsoft Windows systems. However, the HOST.mib file does not contain OIDs appropriate for monitoring memory utilization on Windows 2000 and Windows XP systems. As a result, when Win2000 is chosen as the Agent Type for the snmp_dca monitor, and the monitor is applied to a Windows 2000 or Windows XP system, the memory threshold calculation will always be zero. In addition, the memory threshold calculation will not be used in determining the weight assigned to the node.

By default, the snmp_dca monitor checks the following three resources to determine the weighted ratio value for a given pool member:

  • The CPU Threshold, which determines the member’s amount of CPU use.
  • The Memory Threshold, which determines the member’s amount of memory use.
  • The Disk Threshold, which determines the member’s amount of disk space use.

Note: For more information, refer to K9125: Overview of Dynamic Ratio load balancing.

F5 Product Development is tracking this issue as CR106296.
