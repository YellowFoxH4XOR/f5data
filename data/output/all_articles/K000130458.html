Description

This article describes support for Multiple Base64 decoding for parameters.


Environment

  • Multiple Decoding

Cause

Currently for all BIG-IP software versions, ASM can perform only decode Base64 once.


Recommended Actions

As an alternate, enable multiple decoding on the backend application servers.


Additional Information

 There is a Request for Enhancement ID 403871 submitted.
