K000140583: Distinguishing monitor traffic and data traffic on packet captures from BIG-IP 17.1.x

Description

This article describes how we can distinguish between monitor traffic and data traffic on packet captures from 17.1.x.

Environment

  •  BIG-IP LTM
  •  Load-balancing
  •  Monitors 

Cause

Not able to view HTTP content of monitors on pcap due to encryption.

Recommended Actions

If the packet captures are taken for the device from version 17.1.x, you can follow below steps to validate if the packet is monitoring packet:

  1. Open the pcaps on Wireshark.
  2. Open the communication stream between BIG-IP self-IP and backend-server.
  3. On Wireshark, open F5 Ethernet Trailer protocol section in the Wireshark.
  4. Browse to "Low Details" >> "Virtual Server".
    If the packet is data traffic then you would see the name of the virtual server configured on the BIG-IP device.
    If the packet is from monitoring traffic, then you would see the name of the monitor in the value for "Virtual Server" in the below format: 
    /<partition_name>/<monitor_name>_ivs
