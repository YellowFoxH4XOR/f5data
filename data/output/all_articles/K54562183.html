Security Advisory Description

TMM may restart when processing a specifically crafted page through a virtual server with an associated PEM policy that has content insertion as an action. (CVE-2018-5503)

Impact

An attacker may be able to cause a remote denial of service (DoS).

Security Advisory Status

F5 Product Development has assigned IDs 691504 and 698080 (BIG-IP) to this vulnerability.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by upgrading to a version listed in the Fixes introduced in column. Mitigation

To mitigate this issue, do not configure content insertion actions in BIG-IP PEM policies.
