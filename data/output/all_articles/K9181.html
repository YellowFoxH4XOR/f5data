Known Issue

This is the result of a known issue. When the BIG-IP ASM system processes an HTTP 100 (continue) response internally, and the system overwrites the initial memory space that was allocated to process the HTTP 100 (continue) response, a memory leak may occur.

When this issue occurs, the BIG-IP ASM system gradually consumes additional resources until it is unable to process any traffic.

F5 Product Development tracked this issue as CR104367 and it was fixed in BIG-IP ASM 9.4.6. For information about upgrading, refer to the BIG-IP ASM release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-9.4.4-94.0-HF3, issued for BIG-IP 9.4.4, and in Hotfix-BIG-IP-9.4.5-HF2, issued for BIG-IP 9.4.5. You may download this hotfix or a later version of the hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
