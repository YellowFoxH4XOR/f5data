Issue

Error Message

err mcpd[<PID>]: <interface_number>: (<forwarding_mode>) mode is not supported on this platform (<model_name>).

In this error message, note the following:

  • <PID> is the process ID.
  • <interface_number > is the identified interface number.
  • <forwarding_mode> is the port forwarding mode.
  • <model_name> is the engineering model name of the platform.

For example:

err mcpd[8484]: 01071c37:3: 1.1: (passive) mode is not supported on this platform (C115).

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions is met:

  • The selected interface forwarding mode is not supported on the platform.

Impact

The port forwarding mode on the interface is unchanged.

Recommended Actions

None
