K000140194: The interfaces have not been inherited by the Tenant

Type
Knowledge
Published
2024-06-29
Updated
2024-06-29
Applies to
  • F5OS
  • F5OS-A: 1.7.X, 1.5.X, 1.7.0, 1.5.2, 1.5.1, 1.5.0
Source
https://my.f5.com/manage/s/article/K000140194

Description

Interfaces created on F5OS-A (host) are not visible in the Tenant

Environment

F5OS-A (r2600)

BIG-IP Tenant version 15.1.5.1

Cause

Tenant version is not supported by the F5OS-A version.

Recommended Action

Tenant version must be compatible with the F5OS-A version.
