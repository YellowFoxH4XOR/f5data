K3515: FirePass unable to connect to Microsoft Windows Server 2003 file shares

Topic

Microsoft Windows performs file shares based on the Server Message Block (SMB) protocol. By default, Microsoft Windows Server 2003 uses a security functionality called SMB signing, which uses digital certificates to sign each SMB network packet. Prior to version 6.0.0, FirePass did not support SMB signing. As of version 6.0.0, FirePass supports SMB signing.

For versions prior to 6.0.0, to allow Microsoft Windows Server 2003 file sharing through the FirePass Portal Access Windows File Favorites feature, you must disable the Microsoft Windows Server 2003 SMB signing security function by performing the following steps:

  1. Log in to the Microsoft Windows Server 2003 system using an account that has administrator privileges.
  2. Access the Active Directory management application by clicking Start > Programs > Administrative Tools > Active Directory Users > Computers.
  3. From the console tree, click the domain under which the Microsoft Windows Server 2003 system resides.

    A list of subfolders appears.

  4. Right-click the Domain Controllers subfolder.
  5. Click Properties.
  6. Click the Group Policy tab.
  7. Click Default Domain Controllers Policy.
  8. Click Edit.
  9. From the console tree, click Computer Configuration.
  10. Click the + next to each of the following:

    • Windows Settings
    • Security Settings
    • Local Policies
    • Click Security Options.
    • From the main window, right-click Microsoft network server: Digitally sign communications (always).
    • Click Properties.
    • On the Property page, click Disabled.
    • Click OK.
