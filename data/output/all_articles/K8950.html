Known Issue

This is the result of a known issue. A large ramfs file system is created when the eud_info command is performed. Creating the large ramfs file system may lead to CPU and memory exhaustion, which can trigger performance loss, daemons restarting, or unexpected reboots.

For the 1500 and BIG-IP 3400 platforms, which contain a single CPU and less memory than other platforms, the most common symptoms are performance degradation and the possibility of unexpected reboots.

For other affected platforms, the most common symptoms are mild to moderate performance degradation and the possibility of daemons restarting.

Important: This issue will also occur by running qkview version 6.2.5 or 6.2.6, because version 6.2.5 and 6.2.6 of the qkview utility will run the eud_info command. However, the default version 6.2.4 of qkview installed on a 9.3.x system will not experience this issue because qkview version 6.2.4 does not run the eud_info command. For information about the qkview utility, refer to K1858: Overview of the qkview utility.

F5 Product Development tracked this issue as ID 214618 (Formerly CR102402) and it was fixed in BIG-IP version 10.0.0. For information about upgrading, refer to the LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator release notes.

Note: The version of EUD released with version 10.0.0 for the 1500 and 3400 platforms is 11.1. Using EUD version 11.1 or later will correct the issue detailed above.

Workaround

Do not run the eud_info command. Do not run the qkview version 6.2.5 or 6.2.6 utility.

To verify the version of qkview installed, type the following command:

qkview -v

If you have a BIG-IP system with qkview version 6.2.5 or 6.2.6 installed, download and install the latest version of the qkview utility (currently, version 6.2.7) available for download at the F5 Networks Downloads site. For information about downloading software from F5, refer to K167: Downloading software from F5.

Important: Installing qkview version 6.2.7 does not resolve the issue experienced when running the eud_info command. However, version 6.2 7 of the qkview utility does not run the eud_info command.
