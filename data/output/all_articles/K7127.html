Known Issue

This is the result of a known issue. When the current priority group's connection limit is reached, the TMM does not correctly move new connections to the next priority group. Instead, the TMM resets the new connections.

Note: This issue only affects pools that are configured with limits on the pool members, and are configured for Priority Group Activation.

F5 Product Development tracked this issue as CR54291 and it was fixed in versions 9.3 and 9.4. For information about upgrading, refer to the BIG-IP LTM or Link Controller Release Notes.
