Topic

You should consider using this procedure under the following conditions:

  • You have clients establishing network access sessions to the BIG-IP APM system
  • You want the clients to be able to connect to a separate virtual server on the same BIG-IP APM system

Description

Depending on the configuration of your network environment, virtual servers may not be accessible when clients have an established network access session to a virtual server on the same BIG-IP APM system.

You can allow access to virtual servers through network access sessions by adding the virtual local area network (VLAN) associated with the connectivity profile on the network access virtual server, to the VLANs and Tunnels option of the virtual server you want to reach. For example, this configuration may provide access to existing virtual servers when adding BIG-IP APM to a BIG-IP system.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You must configure the access profile on the BIG-IP APM system for network access.
  • You have administrative access to the BIG-IP Configuration utility.

Procedures

Adding the connectivity profile VLAN to a virtual server

This procedure adds the the connectivity profile VLAN used for network access to the virtual server you want to reach through network access sessions.

Impact of procedure: Modifying the VLANs for the virtual server may cause other connections to fail if you do not manually add all necessary VLANs.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the virtual server currently configured to provide network access.
  4. Note the name of the connectivity profile in use.
  5. Navigate to Local Traffic > Virtual Servers.
  6. Click the name of the virtual server you want to access through network access sessions.
  7. For VLAN and Tunnel Traffic click Enabled On.
  8. For VLAN and Tunnels, add the VLAN with the same name as the connectivity profile noted previously, along with any appropriate VLANs for your network.
  9. Click Update.
