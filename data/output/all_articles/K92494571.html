Known Issue

The BIG-IP ASM system fails to detect WebSocket URLs.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured to explicitly allow or deny WebSocket Secure (wss://) URLs.
  • The security policy is configured with the Differentiate between HTTP/WS and HTTPS/WSS URLs setting disabled.
  • The security policy is attached to both a non-Secure Sockets Layer (SSL) virtual server and an SSL virtual server.

Impact

The BIG-IP ASM system incorrectly detects WebSocket URLs.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP ASM system incorrectly detects WebSocket URLs processed through the SSL virtual server as a wildcard URL.
  • Your BIG-IP ASM system incorrectly detects WebSocket URLs processed through the non-SSL virtual server as a wss:// URL.

Workaround

To work around this issue, you can enable the Differentiate between HTTP/WS and HTTPS/WSS URLs setting in the security policy. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Application Security > Security Policies.
  3. Click the affected security policy.
  4. Set Differentiate between HTTP/WS and HTTPS/WSS URLs to Enable.
  5. Click Save.
  6. Click Apply Policy.
