Issue

Error Message

notice big3d[<PID>]: 012b3008:5: SSL Context Cipher list set to: <cipher_list>.

In this error message, note the following:

  • <PID> is the process ID for the big3d process.
  • <cipher_list> is the list of ciphers that is set for the iQuery SSL Context.

For example:

notice big3d[8484]: 012b3008:5: SSL Context Cipher list set to: AESGCM:AES:!ADH:!AECDH:!PSK:!aECDH:!DSS:!ECDSA:!AES128:-SHA1:AES256-SHA.

Message Location

You may encounter this message in the following location:

  • The /var/log/gtm file

Description

This message occurs when the following condition is met:

  • The big3d process creates SSL Context for iQuery connections as part of the normal start-up sequence.

The big3d process provides metrics collection data on behalf of the BIG-IP DNS system using the iQuery protocol. This notice message is generated during the big3d process start up, and displays the current SSL Context set in the big3d.ssl.cipherlist system variable.

Impact

There is no impact. You can safely ignore this error message.
