Description

You may encounter GUI error Error: 404 - data/openconfig-system:system/f5-system-install:install/state not found when downgrade from v1.8.0 to v1.5.x or v1.7.0.

Environment

  • F5OS-A
  • GUI

Cause

The system install state is a new endpoint introduced in the v1.8.0 and this API is not available in 1.7.0. 

It could be that the web browser was still having the stale v1.8.0 GUI bundle. 

In this case, the old GUI bundle tries to fetch this API which is not available in 1.5.x nor 1.7.0 and thus results in HTTP 404 error.

Recommended Actions

After an downgrade, the web browser reload must be done to refresh the GUI to avoid the web browser fetch the stale GUI bundle.
