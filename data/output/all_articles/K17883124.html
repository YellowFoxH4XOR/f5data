Description

AFM Network Firewall uses Address and Port lists to collect multiple IP addresses and service ports in single configuration objects.
Firewall policies are then configured to reference the appropriate address and port list.
You can create firewall policies that contain many individual IP address and service port entries.

Environment

  • BIG-IP AFM
  • Address-list
  • Port-list

Cause

The maximum entries is limited by the amount of memory allocated to mcpd.

Recommended Actions

The limit on the firewall address-list / port-list, it is due to the mcpd DB size.
If it reaches the mcpd.maxdbsize for the objects created, it will start recording an error in the log and won't be able to load the config.
If BIG-IP has sufficient memory, additional memory can be allocated by increasing the db value to create more objects.

By default, the mcpd.maxdbsize is 512. You can increase it to 1,024, by following the procedure given below:

  1. Login to the BIG-IP command line
  2. Set mcpd.maxdbsize to 1024
    tmsh modify sys db mcpd.maxdbsize value 1024
  3. Save the change:
    tmsh save sys config

Additional Information

Here an example of the error you might see in the logs /var/log/ltm when you reach the limit:

    01070710:3: Can't extend DB size by 5159040 bytes, error code:82 - EdbDbConnection.cpp, line 933
    Unexpected Error: Loading configuration process failed.
