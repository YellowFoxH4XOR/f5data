K24449423: Unable to use Declarative Onboard Cluster to deploy BIG-IP devices

Type
Support Solution
Published
2020-07-14
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IQ
  • BIG-IQ Centralized Management: 7.X.X
Source
https://my.f5.com/manage/s/article/K24449423

Description

  • BIG-IQ CM Declarative Onboard fails to deploy initial BIG-IP configuration
  • You would find the below entries in the BIG-IQ resetjavad.log and BIG-IP /restjavad-audit.0.log
BIG-IQ CM == /var/log/resetjavad.log
[I][124][04 Jun 2020 15:57:49 UTC][ForwarderPassThroughWorker] {"user":"local/admin","method":"PATCH","uri":"http://localhost:8100/mgmt/tm/sys/management-dhcp/sys-mgmt        -dhcp-config","status":200,"from":"<ip address of bigIQ CM>"}
BIG-IP ==  /var/log/restjavad-audit.0.log
[I][124][04 Jun 2020 15:57:49 UTC][ForwarderPassThroughWorker] {"user":"local/admin","method":"PATCH","uri":"http://localhost:8100/mgmt/tm/sys/management-dhcp/sys-mgmt        -dhcp-config","status":200,"from":"<ip address of bigIQ CM>"}

Environment

  • BIG-IQ CM
  • Declarative Onboard [DO]

Cause

  • DO still looks for DHCP update despite dhclient is disabled following update v1.5.0.
    • https://github.com/F5Networks/f5-declarative-onboarding/releases/tag/v1.5.0
  • BIG-IP Declaration fails when DHCP is available #129
    • https://github.com/F5Networks/f5-declarative-onboarding/issues/129

Recommended Actions

  • DO v1.11.1 template can be found in F5 github page-- F5Networks/f5-declarative-onboarding v1.11.1  
  • Update DO template on BIG-IQ Centralized Management to run template version 1.11.1-1
  • Update DO template on BIG-IP managed BIG-IP devices to run template version 1.11.1-1
  • For more Information on compatibility matrix,refer K54909607: BIG-IQ Centralized Management compatibility with F5 Application Services 3 Extension and F5 Declarative Onboarding
