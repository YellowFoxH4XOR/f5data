Description

This article explains how to add in counters to an allow and deny branch on an Access Policy and send it to a High Speed Logging pool on a 24 hour interval.

Environment

  • BIG-IP APM
  • iRules

Cause

Recommended Actions

You can create the following iRule and modifications to the VPE to count the sessions.

Please note:

A.) The hsl_pool will need to be updated in the iRule to reflect the HSL pool B.) There is logging statement that counts each increment, hash this out to keep logs clean.

  1.  Log in to the BIG-IP - Navigate to iRule and create the following:
when RULE_INIT {
    set static::is_allow_counter_initialized 0
    set static::is_deny_counter_initialized 0
    set static::next_log_time [expr {[clock seconds] + 86400}]
}
 
when ACCESS_POLICY_AGENT_EVENT {
    # Initialization checks
    if { $static::is_allow_counter_initialized == 0 } {
        table set allow_counter 0
        set static::is_allow_counter_initialized 1
    }
    if { $static::is_deny_counter_initialized == 0 } {
        table set deny_counter 0
        set static::is_deny_counter_initialized 1
    }
 
    # Incrementing counters
    if { [ACCESS::policy agent_id] eq "allow_inc_branch" } {
        set count [table lookup allow_counter]
        set count [expr {$count + 1}]
        table set allow_counter $count
        log local0. "Incremented Allow Counter: $count"
    } elseif { [ACCESS::policy agent_id] eq "deny_inc_branch" } {
        set count [table lookup deny_counter]
        set count [expr {$count + 1}]
        table set deny_counter $count
        log local0. "Incremented Deny Counter: $count"
    }
 
    # Log sending and counter reset
    if {[clock seconds] >= $static::next_log_time} {
        set hsl [HSL::open -proto UDP -pool hsl_pool]
        set allow_count [table lookup allow_counter]
        set deny_count [table lookup deny_counter]
        HSL::send $hsl "Total Allow Access Policy Events for the day: $allow_count"
        HSL::send $hsl "Total Deny Access Policy Events for the day: $deny_count"
        log local0. "Sent logs. Allow: $allow_count, Deny: $deny_count"
        table set allow_counter 0
        table set deny_counter 0
        set static::next_log_time [expr {[clock seconds] + 86400}]
    }
}
