K7316: FirePass Windows Files Favorites do not support deleting folders or directories

Topic

The FirePass controller's Windows Files Favorites do not support a delete operation on folders or directories on a file server. In the current design of FirePass software, only files can be deleted.

F5 Networks Product Development is tracking this enhancement as CR69349. If your organization requires this functionality, open a support case with F5 Networks Technical Support, describe your requirements in detail, and indicate that your case should be linked to this enhancement. Include the CR number and the number of this Solution in your correspondence.

Workaround

You can configure a Network Access Favorite that allows access to the file server IP address and file sharing ports if the client operating system can natively perform network file sharing operations, including folder deletion. Consult your file server's documentation for the correct port numbers if you configure packet filters for the Network Access Favorite. Optionally, a pre-logon sequence can be used to detect the user's operating system, and a protected configuration can use the information from the pre-logon sequence to provide the Network Access favorite for those users with the appropriate operating systems. The Network Access Favorite can also auto-launch the file share, and map it to a drive letter on Windows client systems.

Additionally, for Windows clients, you can configure an Application Tunnel (FirePass version 5.x) or a Static Application Tunnel (FirePass version 6.x) to map a network drive. For instructions on configuring an application tunnel to map a network drive, refer to the FirePass Controller Administrator Guide.
