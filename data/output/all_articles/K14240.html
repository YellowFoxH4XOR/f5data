Known Issue

The BIG-IP ASM Configuration utility Application Security > Overview page may fail to load properly. This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is able to resolve the F5 Host servers using the configured DNS Lookup server or an F5 DNS nameserver
  • The BIG-IP ASM system is unable to access the F5 Host servers through the HTTPS protocol

This issue occurs because the BIG-IP ASM Configuration utility attempts to contact the F5 Host servers to determine if the BIG-IP ASM system requires an attack signature update when loading the Application Security > Overview page.

The DNS Lookup server configuration is located on the System > Configuration > Device > DNS page. To view the F5 DNS nameserver and F5 Host servers list, refer to K8217: Updating the BIG-IP ASM attack signatures.

Impact

Users may not be able to view the Application Security > Overview page properly.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H380109 on the Diagnostics > Identified > Low screen.
  • When you navigate to the Application Security > Overview page, the BIG-IP ASM Configuration utility times out and displays an error message. The error message appears similar to the following example:

    Unable to contact BIG-IP device
  • The BIG-IP ASM system logs error messages in the /var/log/asm file. The error messages appear similar to the following example:

    01310027:2: ASM subsystem error (asm_config_server_rpc_handler.pl,F5::ASMConfig::Handler::handle_error): Code: 401, Error message = Could not reach the update server. Error: 500 Connect failed: connect: Connection timed out; Connection timed out
    01310027:2: ASM subsystem error (asm_config_server_rpc_handler.pl,F5::ASMConfig::Handler::log_error_and_rollback): Could not reach the update server. Error: 500 Connect failed: connect: Connection timed out; Connection timed out
  • The BIG-IP ASM Configuration utility displays an error message in the Attack Signatures Update section of the Application Security > Overview page. The error message appears similar to the following example:

    Could not reach the update server. Error: 500 Connect failed: connect: Connection timed out; Connection timed out
