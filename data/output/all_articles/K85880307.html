K85880307: BIG-IQ cannot manage or import DER encoded certificates

Type
Support Solution
Published
2021-02-09
Updated
2023-02-21
Applies to
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K85880307

Description

BIG-IQ will not allow import of DER encoded certificates.

  • BIG-IQ cannot manage DER encoded certificates (.cer)
  • Attempt to import a DER Binary Encoded certificate into BIG-IQ
  • You may see and error:

    "Error on server request, unable to retrieve SSL Cert information"

Environment

  • Certificate import direct or from CSR request.
  • Configuration >>> Local Traffic >>> Certificate Management >>> Certificates and Keys
  • BIG-IQ Centralized Manager

Cause

BIG-IQ does not support DER encoded certificates (.cer) 

Recommended Actions

Convert the DER certificate into PEM format:
K04040195: Converting DER format certificates to PEM format certificates and keys for BIG-IP import 

Additional Information

Bug alias 651186 SSL certificate in non-PEM format can not be imported and managed
