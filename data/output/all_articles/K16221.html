Topic

This article applies to BIG-IP 11.x - 17.x. For information about other versions, refer to the following articles:

  • K5946: Adding a static ARP entry (9.x - 10.x)

You should consider using this procedure under the following condition:

  • You want to add a static ARP entry to the BIG-IP system.

Description

To add a static Address Resolution Protocol (ARP) entry to the BIG-IP system ARP table that maps a host IPv4 address to the associated Media Access Control (MAC) address, perform one of the following procedures:

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the BIG-IP system.

Procedures

Adding a static ARP table entry using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. If required, change to the relevant Administrative Partition.
  3. Click Network.
  4. Click ARP.
  5. Click Create.
  6. In the Name box, type a name for the ARP mapping configuration object.
  7. In the IP Address box, type the IPv4 address of the host for which you are creating an ARP entry.
  8. In the MAC Address box, type the MAC address associated with the IP address.
  9. Click Finished.

Adding a static ARP table entry using the tmsh utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. If required, change the partition to the relevant administrative partition using the following command syntax:

    cd /<partition name>

    For example:

    cd /partitionA

  3. Create a static ARP entry using the following command syntax:

    create net arp <name> ip-address <IP address> mac-address <MAC address>

    For example, to create a static ARP entry named myARP for IP address 10.10.10.20 with a MAC address of 00:0b:09::88:00:9a, type the following command:

    create net arp myARP ip-address 10.10.10.20 mac-address 00:0b:09:88:00:9a

  4. To verify that the static ARP entry was created, as expected, type the following command:

    show net arp static

    The entry appears in the ARP table similar to the following example:

    ---------------------------------------------------------------------------------------------------
    Net::Arp
    Name                       Address       HWaddress          Vlan              Expire-in-sec  Status
    ---------------------------------------------------------------------------------------------------
    /partitionA/myARP  10.10.10.20   00:0b:09:88:00:9a    -                 -              static

  5. If you want the ARP entry to persist a system reboot, you must save the configuration. To do so, type the following command:

    save /sys config
