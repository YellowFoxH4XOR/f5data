Topic

The security policy is comprised of several important elements specific to the BIG-IP ASM system. Understanding the security policy elements, and how they relate to the web application itself, is critical to creating and maintaining the security policy.

The following HTTP POST header illustrates a typical request to the web application that would be processed by the BIG-IP ASM security policy:

POST /main/login.jsp HTTP/1.1
Accept: image/gif, image/x-xbitmap, image/jpeg,
image/pjpeg, application/x-shockwave-flash,
application/vnd.ms-excel, */*
Accept-Language: en-us
Accept-Encoding: gzip, deflate
User-Agent: Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1; SV1)
Host: www.example.com:80
Connection: Keep-Alive
Cookie: pref=style1; window=nav2

user=john&pass=1234

Key elements in the HTTP request, and how these elements are defined in the security policy are as follows:

  • Object type

    The file type or file extension contained in the request. The object type in the example request is as follows:

    .jsp

  • Web object

    The web object defines the path to the file, including the file and file extension. The web object in the example request is as follows:

    /main/login.jsp

  • Flow

    The flow defines a logical path within the web application leading to a web object. A flow is comprised of the start point, request method, protocol and requested object. The flow in the example request is as follows:

    Entry Point -> POST via HTTP -> /main/login.jsp

  • Flow parameters

    Flow parameters are located in the HTTP POST data or query string. The flow parameters in the example request are as follows:
    • user
    • pass
  • Flow parameter values

    A flow parameter value is a value for a given parameter. The flow parameter values in the example request are as follows:
    • john
    • 1234
  • Cookies

    Cookies are located in the HTTP Cookie header. Cookies are listed in the following format:

    <cookie name>: <cookie value>; <cookie name>: <cookie value>

    The cookies in the example request are as follows:

    • pref
    • window
  • Cookie values

    Cookie values define the value for the cookies in a request. The Cookie values in the example request are as follows:
    • style1
    • nav2
