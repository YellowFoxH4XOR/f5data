Description

Effective March 30, 2024, Duo will no longer support the traditional Duo Prompt. Due to this change, Duo has recommended administrators must update or configure each eligible Duo-protected application for compatibility with the Universal Prompt.

If administrators utilize the BIG-IP APM to handle Duo authentication, Duo had previously recommended a Radius authentication solution to use with APM.
Administrators will now need to replace this solution in the APM, with a Universal Prompt configuration option.

UPDATED December 2, 2024 - If you have references in your configuration to the Traditional Prompt after moving to the Universal Prompt you may receive the following error:

Environment

  • BIG-IP APM
  • Duo Authentication

Cause

Starting on March 30th, 2024, Duo will no longer support traditional Duo prompt, which was commonly configured with Radius authentication, when utilizing with the BIG-IP APM

Recommended Actions

A. Duo has recommended Big-IP APM administrators, to change to a Universal Prompt configuration.
This community article provides detail on one common configuration option for supporting Duo authentication through the APM, using a Universal Prompt:
APM Configuration to Support Duo MFA using iRule

B. Ensure you have removed any refences to the API JS in the header.inc file:
1. Login to the BIG-IP
2. Navigate to: Access  ››  Profiles / Policies : Customization : Advanced 
3. Navigate to down: Access Profiles --> <DUO_AP> --> Common --> header.inc
4. Remove Your API reference:

<script src="https://api-XXXXXXXX.duosecurity.com/frame/hosted/Duo-F5-BIG-IP-v2.js"></script>

Note: You may need to copy the entire file header.inc to a text editor and remove the line noted above, then paste and
save the file using the save buttons above. Deleting the line directly may not work.
