Description


When admin attempt to configure RDP resource with non-zero route domain, you observe following error message:

"IP address with route domain is not supported"

The procedure to get this error through Configuration utility is as follows:

1. Create Access => Connectivity/VPN => VDI/RDP => Remote Desktop List.
2. In IP Address "Destination", configure IP address 10.10.10.10%5
3. Save the config.

Environment

  • APM policy configured
  • RDP resource added on non-default route domain.
     

Cause

The feature works as designed. VDI does not support Route Domains specified in the Terminal Server resource.

This applies to all current VDI resource types: Citrix, VMware, RDP.

Recommended Actions

N/A

Additional Information

F5 Product Development has assigned ID 615005 to this. BIG-IP versions that contain the fix for ID 615005 contains validation rules to prevent a user from assigning a route domain to a remote desktop terminal server resource.
