Description

NGINX modules can be built and distributed as static or dynamic modules. Static modules are defined at build-time, compiled, and distributed in the resulting binaries. Refer to the Modules reference section. 
Unlike Static modules, dynamically built modules can be downloaded, installed, and configured after the core NGINX binaries have been built. If desired, dynamic modules can also be built statically into NGINX at compile time. Refer to Dynamic Modules on NGINX. 

Environment

  • NGINX Plus
  • Static and dynamic modules

Cause

Need to determine the NGINX modules on NGINX Plus 

Answer/Recommended Actions

Determine running static modules

You can use the nginx -V command to display the exact configuration arguments used when NGINX was compiled to determine the static running modules. Then use bash commands to filter for modules and display the information as desired. For example:

# nginx -V 2>&1 | tr ' ' '\n' | grep -i mod
--modules-path=/usr/lib/nginx/modules
[...]
--with-stream_mqtt_preread_module
--with-stream_proxy_protocol_vendor_module

Determine running dynamic modules

You can use the nginx -T command to display the entire merged NGINX configuration. Then use bash commands to filter for modules and display the information as desired. For example:

# nginx -T | grep -i module
nginx: the configuration file /etc/nginx/nginx.conf syntax is ok
nginx: configuration file /etc/nginx/nginx.conf test is successful
load_module modules/ngx_http_app_protect_module.so;

Alternatively, you can also confirm the dynamic modules by displaying information from the runtime memmory. 
Important: Although the cat command is read-only and should not have an impact on your system however, the following example requires root privileges and you should always exercise caution when running commands that interact directly with system memory as root.

# cat /proc/$(cat /var/run/nginx.pid)/maps | grep module
7f7088b9c000-7f7088ba1000 r--p 00000000 fd:00 395946                     /usr/lib/nginx/modules/ngx_http_app_protect_module.so
