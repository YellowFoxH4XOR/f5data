K4054: Reasons why clients fail to resolve to wide IPs that are using CDN dynamic delegation

Topic

Clients using a Windows 2003 server as their LDNS may fail to resolve wide IPs using CDN dynamic delegation, due to a Windows 2003 bug.

Windows 2003 DNS enables caching by default. Once it has cached and expired a CNAME entry, it will refuse to add the entry again. Because CDN dynamic delegation wide IPs are resolved as CNAMEs, clients may not be able to resolve the wide IP through a Windows 2003 LDNS.

Microsoft has created a patch for this issue. For more information, refer the following Microsoft knowledge base article:

DNS clients may not be able to access sites where the CNAME resource record for the site has been cached on a Windows Server 2003 DNS server
