Description

The BIG-IP Edge Client VPN proxy PAC file is incorrectly restored by Windows on the client system's setting after VPN disconnects. This occurs under the following conditions:

  • On the BIG-IP system, in the network access resource that VPN users are assigned, the client proxy settings with PAC file is configured.
  • On the Windows client system, open Control Panel and select Internet Options > Connections > LAN settings, the client proxy settings display a link to the PAC file. For example: 

    http://127.0.0.1:<port number>/

On establishing VPN, the BIG-IP Edge Client applies the VPN proxy PAC file configured in the BIG-IP APM network resource on the Windows client system. When VPN disconnects, the Edge Client restores the original proxy settings on the client system by removing the VPN proxy settings it applied during VPN establishment. After some time, it may be observed that the VPN proxy PAC file configured on the BIG-IP APM system reappears unexpectedly on the Windows system's proxy settings even after VPN is disconnected. This may affect internet connectivity for users who have used the BIG-IP Edge Client to establish VPN connection.

Environment

  • BIG-IP Edge Client on Windows connection
  • Client Proxy PAC file is configured on the BIG-IP APM network access resource.

Cause

This is a known issue caused by the Office App, an application from the Microsoft Office Suite used for interfacing with Office365. The localbridge.exe process that is part of the Microsoft Office suite, specifically an application called the Office App is responsible for the re-application of the VPN proxy settings even after VPN is disconnected. 

Recommended Actions

  • Update Office App to the latest release (18.2001.1241.0 or greater) and then remove the PAC file URL from Internet Options.
  • Contact Microsoft support as this is not linked to the design or behavior of the BIG-IP Edge Client.
