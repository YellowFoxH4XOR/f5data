Topic

You should consider using this procedure under the following conditions:

  • You want to upgrade F5 BIG-IP Guided Configuration on your BIG-IP system.
  • You want to verify the BIG-IP Guided Configuration version on your BIG-IP system.

Description

This article provides you step-by-step procedures to upgrade BIG-IP Guided Configuration on your BIG-IP system.

Important: F5 recommends that you upgrade to the latest BIG-IP Guided Configuration version when it is available. However, you can only upgrade up to one of two major versions later than your current version. For example, you can upgrade BIG-IP Guided Configuration 4.0 to BIG-IP Guided Configuration 5.0 or 6.0; however, you should not directly upgrade BIG-IP Guided Configuration 4.0 to BIG-IP Guided Configuration 7.0.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative privileges to the BIG-IP system.

Procedures

To upgrade BIG-IP Guided Configuration, perform the following procedures:

  • Download the BIG-IP Guided Configuration use case pack
  • Install the BIG-IP Guided Configuration use case pack

Download the BIG-IP Guided Configuration use case pack

In this procedure, you download the use case pack for BIG-IP Guided Configuration from F5 Downloads.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to F5 Downloads.
  2. On the Downloads Overview page, select Find a Download.
  3. On the Select a Product Line page, under BIG-IP, select Guided Configuration.
  4. Select a product version.
  5. Select Guided Configuration.
  6. In Software Terms and Conditions select I Accept.
  7. On the Select a Download page, select the TAR file, select your region, and then complete the steps to download the file.

    Note: You can use the included MD5 utility to validate the checksum. For more information, refer to K8337: Verifying the MD5 checksum for the downloaded F5 software file.

Install the BIG-IP Guided Configuration use case pack

You can upgrade BIG-IP Guided Configuration on your BIG-IP system from either the Configuration utility or through iControl REST API.

Upgrade using the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility
  2. Go to Access > Guided Configuration or Security > Guided Configuration
  3. Note the current version at the top right corner of the page.
  4. Select Upgrade Guided Configuration.
  5. Select Choose File.
  6. Select Upload and Install.

Upgrade using iControl REST API

Perform the following procedure on your remote client device using an iControl REST tool such as Postman or the curl command.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Use an appropriate file transfer tool such as SCP to transfer the use case pack downloaded in the previous procedure to the /var/config/rest/downloads directory of the BIG-IP system.
  2. To install the use case pack, make a POST request to the BIG-IP system with values from the following table.
    ItemDescription
    URIhttps://<bigip_address>/mgmt/tm/access/bundle-install-tasks
    MethodPOST
    Request Body{"filePath": "/var/config/rest/downloads/<usecase-pack-filename.tar.gz"}

    For example, with the curl command line tool, use the following command syntax:

    Note: The following command optionally pipes the response to the JSON processor jq for easier reading. You can choose not to use jq by removing it at the end of the command if you do not have it installed.

    curl -k -u <username>:<password -X POST -d '{"filePath": "/var/config/rest/downloads/<usecase-pack-filename>.tar.gz"}' -H 'Content-Type: application/json' https://<BIG-IP IP address>/mgmt/tm/access/bundle-install-tasks | jq

    For example, to install the use case pack for BIG-IP Guided Configuration 7.0, enter the following command:

    curl -k -u admin:C0mPlicatedP@ssword -X POST -d '{"filePath": "/var/config/rest/downloads/f5-iappslx-agc-usecase-pack-7.0-0.0.1481.tar.gz"}' -H 'Content-Type: application/json' https://10.10.1.1/mgmt/tm/access/bundle-install-tasks | jq

Troubleshooting

When troubleshooting, you can verify information such as installation status using from the following:

  • Issue iControl REST API GET requests as described in step 3 of the Upgrade using iControl REST API procedure.
  • As you perform the installation, observe the output from the following logs files:
    • /var/log/restjavad.0.log
    • /var/log/restjavad-audit.0.log
    • /var/log/restnoded/restnoded.log

    To do so, enter the following command:

    tailf /var/log/rest*
