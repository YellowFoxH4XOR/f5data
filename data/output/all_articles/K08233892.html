Description

Have configured ECS on the BIG-IP DNS but resolution via OpenDNS is not accurate.

Environment

The following condition must be met for this article to be applicable.

  • Have correctly configured GSLB Topology Load Balancing and Wide IP on the BIG-IP DNS.
  • ECS feature has been configured on the BIG-IP DNS.
  • The is no issue resolving IP via other public DNS such as Google Public DNS.

Cause

At this moment, OpenDNS does not support ECS.

Recommended Actions

  • OpenDNS uses anycast so that users would end up using variety of LDNS.
  • You will need to get the IP addresses of their LDNS and build a topology setup.
