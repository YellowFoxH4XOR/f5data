Description

You can configure an ASM security policy to block uploads while allowing downloads for a specific file type. However, this method is only effective when the filename extension is included in the URLs.

Example:

Allow GET /foo/files/abc.zip

Block POST /foo/file/add/def.zip

Environment

BIG-IP ASM

File Uploads and Downloads

Cause

None, functional information.

Recommended Actions

1. Navigate to the Security  ››  Application Security : Security Policies : Policies List ›› <Policy_Name> ›› HTTP Message Protection : File Types

2. Add to the required file type to the list of allowed file-types with post data length set to "0"

Example: 

4. Make sure that you have enabled the violation "Illegal POST data length".

Note: These changes are global for the policy, any URL having the configured file-type will have uploads blocked.
