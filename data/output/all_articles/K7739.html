Known Issue

This is the result of a known issue. If you restore the factory default snapshot on your FirePass controller, then upgrade to the desired version of FirePass software and restore a backup with OPSWAT-based pre-logon sequences, you may not see these pre-logon sequences listed in the Users: Endpoint Security: Pre-logon Sequence page.

If you do not see these pre-logon sequences listed, you can verify that you are affected by this issue by navigating to the Device Management: Maintenance: Activate License page and clicking on the Click here to view license details link. You are affected by this issue if you see the Anti-Virus/Firewall End-Point Security entry in the Disabled state.

F5 Networks Product Development is tracking this issue as CR83895.

Workaround

You can work around this issue by reinstalling your FirePass controller's license, by using the Activate License section of the Device Management: Maintenance: Activate License page. Reinstallation of the FirePass license should change the Anti-Virus/Firewall End-Point Security entry to the enabled state. The OPSWAT-based pre-logon sequences should then appear on the Users: Endpoint Security: Pre-logon Sequence page, or you can then reload them from your backup file.
