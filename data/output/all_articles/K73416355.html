K73416355: Suspicious property can be set to other TCP-related vectors on the BIG-IP AFM DoS Protection configuration

Type
Knowledge
Published
2018-12-11
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP AFM: 14.1.0
Source
https://my.f5.com/manage/s/article/K73416355

Issue

Old Behavior

In versions prior to BIG-IP AFM 14.1.0, the suspicious property is only applicable to the DNS Response Flood vector when configuring the DoS Protection configuration.

To view this setting on the DNS Response Flood vector, use the following TMOS Shell (tmsh ) command:

list /security dos device-config dos-device-config dos-device-vector { dns-response-flood { suspicious } }

New Behavior

Beginning in BIG-IP AFM 14.1.0, you can enable the suspicious property to the following DoS Protection vectors:

  • TCP RST Flood
  • TCP PUSH Flood
  • TCP SYN ACK Flood
  • DNS Response Flood

By default, the suspicious property is set to false. When it is set to true, the suspicious property allows the vector on the specific attack type to be triggered if the packet does not belong to an existing flow.

Impact

None

Recommended Actions

You can manage the suspicious property of the applicable vectors by using either one of the follow methods:

Managing the suspicious property using the Configuration utility

  1. Log in to the Configuration utility.
  2. Navigate to Security > DoS Protection > Device Protection.
  3. Click Network to expand the list of attack types available.
  4. Click the attack type you want to choose. Select the check the box for Only Count Suspicious Events to enable it. To disable it, clear the check box.

Managing the suspicious property using tmsh

  1. Log in to tmsh by typing the following command:

    tmsh

  2. Enable or disable the suspicious vector:
    • To enable the suspicious vector:, use the following command syntax:

      Note: <Attack-Type> is the DOS vector type you want to configure for the suspicious property.

      modify /security dos dos-device-config dos-device-vector { <Attack-Type> { suspicious true } }

      For example, to enable suspicious property on the TCP RST Flood vector, type the following command:

      modify /security dos dos-device-config dos-device-vector { tcp-rst-flood { suspicious true } }

    • To disable the suspicious vector, use the following command syntax:

      modify /security dos dos-device-config dos-device-vector { <Attack-Type> { suspicious false } }

      For example, to disable suspicious property on the TCP RST Flood vector, type the following command:

      modify /security dos dos-device-config dos-device-vector { tcp-rst-flood { suspicious false } }
