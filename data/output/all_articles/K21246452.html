Description

An add-on key cannot be activated on multiple devices. Once the add-on key has been activated, it is associated to the base registration key permanently and should not be applied again on another device. If an add-on key was accidentally activated on an incorrect device, for instance, adding two add-on keys with the same function in one base key, the following symptoms occur:
 

  • Module not displaying in the GUI
  • No add-on key on correct Base Registration Key 
  • Message displaying on GUI (Unlicensed)
     

Environment

  • License Activation
  • Add-on License Key

Cause

K34948229: Add-on license keys can only be activated on one device

Recommended Actions

Note: 

  • Misapplied add-on keys can only be replaced if the request was made within 2 weeks of initial activation, otherwise it will be rejected. However, if multiple add-on keys of the same SKU (example: the duplicated add-on didn't increase the throughput/feature of the base license) have been activated, an exception will be given, and the request can still be processed.  
  • If the mis-applied add-ons are subscription add-ons, all add-on keys (with the same function) tied to the unit must be removed, not just the extra(s).

Removing a mis-applied add-on key and re-activating the license by the following procedure:

Before contacting F5 Technical Support, you should first remove the mis-applied add-on key and re-activate the license for the device you are removing the add-on key from. To do so, perform the following procedure:
The F5 Licensing Tool page produces your license.

  1. Log in to the Configuration utility.
  2. Navigate to System > License.
  3. Click Re-activate.
  4. For Add-On Registration Key List, click the add-on key to be removed.
  5. Click Delete.
  6. For Activation Method, select the appropriate option.

    Important: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you reactivate while they are in standby mode.

    • If you select Automatic:             
                  Optional: For Outbound Interface, select the appropriate option to contact the F5 License Server.
                  Click Next. The BIG-IP system automatically connects to the F5 License Server and activates the license.
     
    • If you select Manual:             
                  1. Click Next.
                  2. Copy the dossier.
                  3. Go to the F5 Licensing Tools page and click Activate F5 product registration key.
                  4. In the Enter your dossier box, paste the dossier and click Next.
                      The F5 Licensing Tool page produces your license.
                  5. Copy the license and paste it into the License box in the Configuration utility.
                  6. Click Next 
     
  7. Contact F5 Technical Support to request retirement of the mis-applied add-on key(s) and generate a new add-on license key
