K82063753: BIG-IP APM v15.1 (and later) with Modern Customization does not support DUO logon page integration.

Type
Support Solution
Published
2020-04-17
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.0
Source
https://my.f5.com/manage/s/article/K82063753

Description

DUO logon page integration does not work with APM Modern Customization available in BIG-IP APM version 15.1.0 and later.

Environment

  • BIG-IP APM v15.1.0 (or later)
  • DUO 2FA
  • Access Profile Customization Type: Modern

Cause

DUO 2FA does not support integrating with Modern Customization Profiles at the time of solution publication.

Recommended Actions

Check documentation on the DUO site to see latest status and options.

https://duo.com/docs/f5bigip
