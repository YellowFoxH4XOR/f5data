K12445: The session terminates if the browser user-agent string changes

Topic

In certain situations, for example when using an Internet Service Provider's custom browser, if the user is logged on to a FirePass session and the user-agent string changes, FirePass will terminate the session and log off the user. The user-agent string is information provided by the browser, which allows a web server to determine the type of browser. This information allows web services to tailor the content to the particular features of the user's browser. FirePass tracks this information, and if the user-agent string changes during a VPN session, FirePass will terminate the session to prevent a potential attack.

F5 Product Development is tracking a request for enhancement (RFE) as ID 266738 to allow the FirePass administrator to disable browser user-agent string tracking.

This feature has been added in cumulative hotfix HF-70-2, which has been issued for FirePass version 7.0.0, and in cumulative hotfix HF-610-4, which has been issued for FirePass version 6.1.0. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.
