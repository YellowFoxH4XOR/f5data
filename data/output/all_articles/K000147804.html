K000147804: How does Show Child Objects / Status work?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-23
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147804

Description

  • The Show Child Object and Show Status options for any object in Console used to display a JSON view with either Global Status, Status, or Local Status tabs depending on the context of object.
  • Now this is being changed to show a read-only mode view of the object (similar to the Manage Configuration option which shows a read-only view).
  • This allows you to verify that all configuration objects are created and applied, and it can also help for debugging purposes.

Environment

  • F5® Distributed Cloud Console

Answer/Recommended Actions

To see the child objects, click `...` for objects listed in Console, and then select Show Child Objects, Show Status, or Show Local Status, depending on the object type.

This will bring up the Child Objects view showing various components in your setup, as shown below:

 

Click on an object's name to view its configuration.  For instance, click on a virtual host name to view the configuration for that specific virtual host.  From there, you can click Edit Configuration to make any required changes.

 

Click View to see the status of the associated object.  If you click View in a Local Status column, you will first select a local site in order to see the local status of the associated object for that site.  See below:

Use the Site drop-down menu to view the local status on other sites.
