K7710: BIG-IP LTM does not check for a NULL peer when processing mirroring messages

Known Issue

This is the result of a known issue. The BIG-IP LTM uses SCTP as the mirroring transport protocol in the 9.2 software branch. In some cases, the BIG-IP LTM does not check for a NULL peer when it processes SCTP mirroring messages. As a result, the TMM process crashes.

F5 Product Development tracked this issue as CR60843, CR65810, CR60843, and CR65809, and it was fixed in BIG-IP LTM versions 9.1.3, 9.2.4, 9.3.0, and 9.4.0. For information about upgrading, refer to the BIG-IP LTM release notes.
