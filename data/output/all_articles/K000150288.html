K000150288: iAppLX packages not included in generated UCS

Type
Support Solution
Published
2025-03-07
Updated
2025-04-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.1.5, 17.1.2
Source
https://my.f5.com/manage/s/article/K000150288

Description

When saving a UCS (User Configuration Set) file using either CLI (Command Line Interface) or GUI (Graphic User Interface), iAppLX packages are not included in the UCS file. This issue occurs under specific conditions and may result in incomplete backups of the system configuration. Error messages or logs may include:

  • "Failed to clean up spec file"
  • "Failed to get RPM build response within timeout for [package name]"
  • "ENOENT: no such file or directory, unlink '[file path]'"
info iAppsLX_save_pre[4706]: Exporting: f5-iappslx-ssl-orchestrator - /var/config/rest/iapps/f5-iappslx-ssl-orchestrator
err iAppsLX_save_pre[4706]: Failed task: /shared/iapp/build-package/f9efc929-8d3b-432d-8f1a-d861c10242d9: Failed to clean up spec file /var/config/rest/node/tmp/995c734a-d44f-4ea1-a2db-9da2cc69217d.spec
err iAppsLX_save_pre[4706]: Failed to get getRPM build response within timeout for f5-iappslx-ssl-orchestrator

info: IappRpmSpecFileCreatorWorker.js onDelete failed with exception: Error: ENOENT: no such file or directory, unlink '/var/config/rest/node/tmp/995c734a-d44f-4ea1-a2db-9da2cc69217d.spec'

Environment

  • BIG-IP software version that includes ID985329 fix
  • iAppLX packages installed such as AS3, Telemetry Streaming, or SSLO

Cause

ID1626337

Recommended Actions

If possible, temporarily remove unnecessary iAppLX packages before saving the UCS file and reinstall them afterward. Check for future software updates or patches that address Bug ID1626337 directly.
