K000133433: Upgraded from 1.3.2 to 1.4. System no longer allows any access except root via console\ssh.

Type
Support Solution
Published
2023-04-06
Updated
2023-04-06
Source

Description

You recently upgraded your rSeries device from version 1.3.2 to 1.4.0, and now the configuration utility does not load. You can only access the device through console or SSH.

 

Environment

  • rSeries device

  • Upgraded from version 1.3.2 to 1.4.0

 

Cause

The device was initially upgraded to version 1.3.2 using an improper ISO file with "(1)" in its name. The system was then upgraded to 1.4.0 without correcting this issue, which is a known bug (ID1273021-1) that is planned to be fixed in version 1.5.0.

 

Recommended Actions

  1. Download a new copy of the proper ISO file and save it to /var/import/staging.

  2. Wait for about five minutes for the system to import the file. As the configuration daemon (confd) is unavailable, you can check the import status by examining the logs in /var/log/sw-mgmt.debug.

  3. After the import is complete, reboot the device. The system should recover and be upgraded to version 1.4.0.
