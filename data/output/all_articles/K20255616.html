Known Issue

The LB::status iRule command does not always return a value.

This issue occurs when all of the following conditions are met:

  • A pool is disabled or all members are disabled.
  • The pool has never triggered an LB_SELECTED event after a reboot.
  • The pool is specified to be used in an iRule event prior to LB_SELECTED.

Impact

The iRule command returns a null value instead of the session_disabled or down value when used in the LB_SELECTED event.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Since the LB::status iRule command does not always return a value, an iRule may not perform the next action that is dependent on the information returned.
