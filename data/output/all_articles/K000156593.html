Description

Environment

Cause

 

Answer/Recommended Actions

  1. Policy Creation and Monitoring Mode

    • When a new WAF policy is created, it is set to "Monitoring" mode by default
    • For Managed Customers, the SOC requires at least 7 days of traffic traversing the load balancer with the attached policy to provide comprehensive feedback and recommendations

  2. Methods to Create a WAF Policy

    • You can create a WAF policy either:
      • Directly via the Load Balancer configuration
      • From the "App Firewall" option under "Manage" in the WAAP console
    • Both methods provide the same policy configuration options; only the navigation steps differ

  3. SOC Recommendations and Blocking Mode

    • To minimize risk of impactful false positives on production applications, it is recommended to leave WAF in monitoring mode for a sufficient period (typically 1-7 days) to collect legitimate application traffic and tune protections if any false positives are detected.
    • Depending on the application and its owner's tolerance for false positives, more aggressive approaches can be considered to expedite transition to active enforcement.
    • The default WAF policy with only Medium and High accuracy signatures enabled has a negligible false positive rate for more applications.

  4. Recommended Policy Configuration

    • The default WAF policy has Automatic Attack Signatures Tuning enabled, which suppresses WAF blocking for requests evaluated as 'probable false positive' by a heuristic engine.
      • Note: despite the name, this feature does NOT make permanent modifications to the WAF config.  It suppresses/unblocks individual requests only.
    • The feature lowers overall FP risk and can therefore accelerate transition to enforcement.  However, its enablement switches an otherwise deterministic blocking decision to a probablistic one that might not desirable in all environments.
    • In other words, enablement of Automatic Attack Signatures Tuning is a trade-off: likelihood of FPs are decreased, but likelihood of false negatives is incrementally increased as well.
    • To maintain a purely deterministic WAF posture, disable the feature:
      • Go to Security Policy Settings.
      • Click the dropdown for Security Policy and select Custom.
      • The only recommended change from the default is to set Automatic Attack Signatures Tuning from "Enable" to "Disable".
