Description

After upgrading the BIG-IP, REST API call PUT request is not working and gives a 400 response code error.

This issue happens after upgrading to BIG-IP 14.x and above. This includes BIG-IP 15.x and 16.x.

Examples of 400 response code error when using a REST API call PUT are:
{???????"code":400,"message":"01070822:3: Access Denied: user (EXAMPLE-USER) does not have modify access to attribute (pool_member_app_id) of object (pool_member)","errorStack":[],"apiError":3}???????
{"code":400,"message":"01071610:3: Profile /Common/example-SSLClientProfile's SSL forward proxy RSA CA key is missing.","errorStack":[],"apiError":3}

Environment

  • BIG-IP
  • Upgraded to BIG-IP 14.x and above (includes v15.x and v16.x)
  • REST API call PUT was working before the upgrade
  • Getting a 400 response code error

Cause

Based on F5 official article on REST API commands (K13225405), it suggest to use POST and PATCH instead of PUT.

Changes has been made to BIG-IP 14.x which causes issue when using REST API call PUT.

Recommended Actions

To resolve the problem, you will need to change the REST API call PUT to POST and/or PATCH. Refer to K13225405.

None.
