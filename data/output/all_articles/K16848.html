Known Issue

Description

The Traffic Management Microkernel (TMM) may restart when a user logs out of Office 365 by using Security Assertion Markup Language (SAML) single logout (SLO).

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured as a SAML Identity Provider (IdP).
  • Office 365 is configured as the SAML service provider (SP).
  • The external SAML SP connector for Office 365 on the BIG-IP APM system is configured with the SLO request URL.
  • A SAML SLO request from Office 365 to the BIG-IP APM system contains unsupported parameters.

Impact

The BIG-IP APM system fails to process traffic while the TMM process restarts and systems configured for high availability (HA) fail over.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users cannot access the BIG-IP APM system, or they experience a traffic disruption.
  • The tmm process generates a core file to the /shared/core directory.
  • The BIG-IP system generates a SIGSEGV fault and stack trace in the /var/log/tmm file.

Workaround

There is no workaround for this issue. However, to prevent the tmm process from restarting, you can disable SAML SLO in your environment.
