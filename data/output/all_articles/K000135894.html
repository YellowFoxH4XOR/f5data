K000135894: APM Access Reports - Server Error, The request timed out before the server could respond.

Type
Support Solution
Published
2023-08-29
Updated
2023-08-29
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000135894

Description

While trying to print an APM Access Report - you receive the error message:

Server Error

The request timed out before the server could respond. Please constrain your report to return fewer rows and rerun the report

 

Environment

  • BIG-IP
  • APM

Cause

This is likely due to a short timeout for a big report to be generated.

 Recommended Actions

1. You can try to limit the report or increase the wait before timeout by doing the following:
  • Increase AJAX timeout:
    • Edit /var/sam/www/admin/reports/reportBuilderApp.js line number 23 to set a higher timeout in milliseconds and save
    • Ex: Ext.Ajax.timeout = 600000 (for 10min)
2. Increase httpd timeout:
  • tmsh modify /sys httpd include 'Timeout 600'

 

Additional Information

The workaround suggested above have been shown to resolve the issue connected with the bug ID 927289 as well.
