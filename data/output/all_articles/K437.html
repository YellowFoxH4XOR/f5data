Known Issue

This is the result of a known issue. If you have not defined a router for a datacenter, you will receive the following error message in the /var/log/3dns file:

CFG:gateway_put: Can't find GATEWAY target member <address> for pool :iqmaster.c:2428

This message is harmless; 3-DNS does not require that you define a router for a datacenter.

F5 Networks Product Development tracked this issue as CR27791 and CR41829.
