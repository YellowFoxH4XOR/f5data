K5139: The Microsoft SharePoint Shared Workspace may fail to load when accessed through FirePass

Published
2006-12-26

Applies to
  • Legacy Products
  • FirePass: 6.0.1, 6.0.0
Source

Topic



A Microsoft SharePoint server transmits its real IP address to the client through an ActiveX control. The client may then attempt to contact the SharePoint server directly. Because FirePass proxies the connection between the client and the SharePoint server, attempts to connect to the SharePoint server by its real IP address will fail.

This issue occurs when a user attempts to edit a document located in the Shared Documents area. Instead of loading the Shared Workspace pane and editing window, SharePoint displays an error.

Workaround

FirePass version 5.5.2 and later

To work around this issue in FirePass version 5.5.2 and later, perform the following procedure:

  1. Navigate to the Portal Access: Web Applications: Content Processing page.

  2. Click the Global Settings tab.

  3. Under the Feature Web Applications section, select the Support Microsoft SharePoint check box.

  4. Click the Update button.

FirePass version 5.5.1 and earlier

To work around this issue in FirePass version 5.5.1 and earlier, you will need to install a content processing script that changes the real SharePoint server IP address, transmitted by the ActiveX control, to the FirePass IP address. To install this content processing script, perform the following steps:

  1. Log in to the Administration Console as an administrator.

  2. In the main navigation pane, select Portal Access.

  3. In the upper navigation pane, select Web Applications.

  4. In the sub-menu, select Content Processing.

  5. Click the Global Settings tab.

  6. In the Web Applications Content Processing Scripts section, click the Add New Favorite button.

  7. Add a descriptive name for the script in the Processing script name field.

  8. Enter the following line in the URL match patterns field:

    http*://<hostname>/*/_vti_bin/webs.asmx

    Replace <hostname> with the host name of the SharePoint server.

  9. Enter the following line in the Content Type field:

    text/xml; charset=utf-8

  10. Enter the following line in the Sed processing script field:

    s!http*://<address>!https://FP_ServiceAddr!g

    Replace <address> with the real IP address of the SharePoint server.

  11. Select Pre-process response data (before content patching) in the Processing menu box.

  12. Click the Update button.

If you have more than one SharePoint server, repeat these steps for each server.
