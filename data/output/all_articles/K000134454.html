K000134454: Set worker_shutdown_timeout to terminate Nginx worker

Type
Support Solution
Published
2023-06-26
Updated
2023-06-26
Applies to
  • NGINX Products
  • NGINX Plus: R13, R16, R15, R14, R29, R27, R26, R25, R24, R23, R22, R21, R20, R19, R18, R17, R28
Source
https://my.f5.com/manage/s/article/K000134454

Description

  • New configuration failed to be applied after 'nginx -s reload' command

Environment

  • Nginx Plus or Nginx OSS

Cause

The existing Nginx worker process couldn't be replaced by the new Nginx worker process with the latest configuration because of some existing long connections.

 Recommended Actions

Use worker_shutdown_timeout directive with a proper timeout value to terminate the existing Nginx process. 
 

Additional Information

None.
