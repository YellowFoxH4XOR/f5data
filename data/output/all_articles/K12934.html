K12934: The 'domain-join' command requires a forward slash to separate layers in a nested OU

Issue

Prior to ARX 5.2.0, the domain-join command would accept a backslash ( \ ) or a forward slash ( / ) to separate layers in a nested OU. However, ARX documentation and ARX Manager GUI online help indicated that you should use a backslash ( \ ).

For example:

domain-join dsforest1.com ou "testOU\testOU"

Beginning in ARX 5.2.0, a forward slash ( / ) is required to separate layers of a nested OU in the domain-join command.

For example:

domain-join dsforest1.com ou "testOU/testOU"

In ARX 5.2.0 and later, if the domain-join command uses a backslash ( \ ) to separate layers of a nested OU, the domain join fails with a generic error that appears similar to the following example:

% ERROR: ADJOIN_GENERIC (44892216):
  The domain-join operation failed due to a generic error. See documentation for next steps.
