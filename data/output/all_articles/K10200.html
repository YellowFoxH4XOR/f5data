Topic

This article applies to BIG-IP 9.x - 10.x. For information about other versions, refer to the following article:

  • K13255: Displaying and deleting HTTP cache entries from the command line (11.x - 13.x)

You can display and delete the contents of the RAM Cache from the BIG-IP command line using the bigpipe profile command.

Important: In some versions, if you attempt to display RAM Cache entries, the Traffic Management Microkernel (TMM) may stop responding. For more information, refer to K11355: Using the 'ramcache entry show' bigpipe command to display RAM Cache entries may cause TMM to crash.

Important: In versions prior to BIG-IP 10.1.0, if you delete RAM Cache entries while documents are being served from the cache, TMM will stop responding. For more information, refer to K10597: Deleting RAM Cache entries while documents are being served causes TMM to crash.

Note: There is no corresponding Configuration utility feature that makes it possible to display or delete RAM Cache entries. F5 Product Development is tracking a request to add this functionality as ID 222227 (formerly CR115374).

Displaying entries

To display a specific number of entries associated with a certain http profile, use the following command syntax:

bigpipe profile http <profile_name> ramcache entry max response <value>

Note: Replace profile_name with the name of the HTTP profile whose RAM Cache entries should be displayed or deleted.

For example, to display 1000 RAM Cache entries for the http-lan-optimized-caching profile, you would type the following command:

bigpipe profile http http-lan-optimized-caching ramcache entry max response 1000

To display all entries associated with a certain http profile, use the following command syntax:

bigpipe profile http <profile_name> ramcache entry all show

Note: Replace profile_name with the name of the HTTP profile whose RAM Cache entries should be displayed or deleted. Use the keyword all to manage entries for all profiles.

For example, to display all RAM Cache entries for the http-lan-optimized-caching profile, you would type the following command:

bigpipe profile http http-lan-optimized-caching ramcache entry all show

Note: If you attempt to display the RAM Cache entries for a nonexistent http profile or one that does not have RAM Cache enabled, a message that appears similar to the following example is displayed:

BIGpipe unknown operation error:
Couldn't find ramcache info for profile given.

Deleting entries

To delete all entries associated with a certain http profile, use the following command syntax:

bigpipe profile http <profile_name> ramcache entry all delete

Note: Replace profile_name with the name of the HTTP profile whose RAM Cache entries should be displayed or deleted. Use the keyword all to manage entries for all profiles.

For example, to clear all RAM Cache entries for the http-lan-optimized-caching profile, you would type the following command:

bigpipe profile http http-lan-optimized-caching ramcache entry all delete

The bigpipe utility also includes a number of other arguments which may be used to display or delete only those RAM Cache entries that correspond to specific URIs, URI branches, or hosts.

Note: For more information about using the bigpipe utility to manipulate RAM Cache entries, refer to the BIG-IP Command Line Interface Guide for your version.For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.
