K43230362: BIG-IQ Cluster state is shown in yellow

Type
Support Solution
Published
2021-10-08
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K43230362

Description
When you view the BIG-IQ cluster health, the state is shown in yellow with unassigned shards

Environment

  • BIG-IQ Central Management with 1 DCD (Data Collection Device) deployment
  • Cluster Health state is shown in yellow
  • There are unassigned shards

Cause

  • This is expected behaviour
  • This is because there is only 1 DCD in your BIG-IQ deployment

Recommended Actions

None

Additional Information
A red status can indicate that one or more cluster shards are not assigned to the cluster, and can result in missing data in a report or failure to incorporate new incoming logs.
