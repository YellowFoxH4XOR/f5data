Known Issue

The BIG-IP ASM Configuration utility may display the number of Rejected Connections and Dropped Requests for a brute force attack to be 10% lower than the actual number of dropped requests.

This issue occurs when all of the following conditions are met:

  • You are mitigating brute force attacks.
  • You are monitoring the number of Rejected Connections and Drop Requests in the Configuration utility or from the bd.log file

Impact

Statistics displayed by the Configuration utility may be skewed by approximately 10%.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The displayed number of Rejected Connections or Drop Requests will differ from the actual number.
