Known Issue

Connections to a virtual server enabled with both a BIG-IP APM access profile and a BIG-IP ASM security policy are reset.

This issue occurs when all of the following conditions are met:

  • Your system is running BIG-IP 13.0.0 HF1 or HF2.
  • The virtual server is configured with a BIG-IP APM access profile and a BIG-IP ASM security policy.

Impact

Clients are unable to connect to a virtual server that is enabled with both a BIG-IP APM access policy and a BIG-IP ASM security policy.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Clients are unable to connect to a virtual server that is enabled with both a BIG-IP APM access profile and a BIG-IP ASM security policy.
  • Connections to the affected virtual server are reset.

Workaround

To work around this issue, you can add a denial-of-service (DoS) security profile that has the Application Security option enabled to the affected virtual server. To do so, perform the following procedure:

Impact of workaround: The impact of the following procedure depends on the specific environment. F5 recommends that you test any such changes during a maintenance window and consider the possible impact on your specific environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click the affected virtual server.
  4. Click the Security tab and click Policies.
  5. In the DoS Protection Profile list, click Enabled.
  6. From the Profile list, click the DoS profile.

    The selected DoS profile must have the Application Security Policy setting enabled.

  7. Click Update.
