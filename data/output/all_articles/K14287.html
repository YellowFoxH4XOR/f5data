Topic

In versions prior to BIG-IP 11.5.0, setting AAA server addresses with the Configuration utility was limited to the default route domain (no route domain suffix). To address this limitation, you can use the Traffic Management Shell (tmsh) to add AAA servers, referencing non-default route domains to the AAA profile servers.

Workaround

To work around the route domain suffix limitation, you can add a route domain suffix to the configured domain controllers using the tmsh utility. To do so, perform the following procedure:

Impact of workaround: Once configured to use a non-default route domain, the Active Directory AAA server profile can no longer be modified using the Configuration utility. Attempts to do so will fail with an "Invalid IP Address" error message.

Note: BIG-IP APM does not support DNS in route domains. You must make all DNS queries to a DNS server in the common domain.

  1. Log in to the BIG-IP command line.
  2. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  3. Access the BIG-IP APM configuration settings by typing the following command:

    /apm
  4. List the current AD AAA server configuration using the following command syntax:

    list aaa active-directory <aaa server profile name>

    For example:

    list aaa active-directory ad-aaa-profile
    apm aaa active-directory ad-aaa-profile {
    domain ad.example.com
    domain-controllers {
    host1.example.com {
    ip 10.11.12.1
    }
    host2.example.com {
    ip 10.11.12.2
    }
    }
    pool ad-aaa-pool
    }
  5. Modify the domain controller entries to add the route domain information using the following command syntax:

    modify aaa active-directory <aaa server profile name> domain-controllers modify { <hostname> { ip <host ip address>%<route domain> } }

    For example:

    modify aaa active-directory ad-aaa-example-profile domain-controllers modify { host1.example.com { ip 10.11.12.1%2 } }
    modify aaa active-directory ad-aaa-example-profile domain-controllers modify { host2.example.com { ip 10.11.12.2%2 } }

    For aaa active directory configurations that use a direct domain controller configuration instead of a pool configuration (Direct):

    modify aaa active-directory ad-aaa-example-profile domain-controllers replace-all-with { 10.11.12.1%2:any }
  6. Modify the AAA active directory pool members for the AAA profile ddd by typing the following command:

    modify /ltm pool ad-aaa-example-profile-pool members replace-all-with { 10.11.12.1%2:any 10.11.12.2%2:any }
  7. The previous step should automatically create BIG-IP LTM node references for the new domain controller with the route domain suffix. If the new nodes do not automatically populate in Local Traffic > Nodes, as with AAA Direct server configurations, you can create the associated BIG-IP LTM node references for the route domain's domain controllers by typing the following commands:

    create /ltm node 10.11.12.1%2
    create /ltm node 10.11.12.2%2

    Important: This step is required when modifying an AD AAA profile that uses Direct (single AAA server instead of a pool of AAA servers).
  8. Save the configuration by typing the following command:

    save /sys config
