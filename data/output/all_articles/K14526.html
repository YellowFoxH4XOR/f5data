Known Issue

Deterministic NAT address translations may fail for Carrier-Grade Network Address Translation (CGNAT) virtual servers.

This issue occurs when one of the following conditions is met:

  • More than one CGNAT virtual server, using different source address ranges, is associated with the same LSN pool that is configured for deterministic mode.
  • A CGNAT virtual server configured with a source address network larger than /16 is associated with an LSN pool that is configured for deterministic mode.

When multiple CGNAT virtual servers with different source address ranges are configured and they reference the same LSN pool, identical mappings may be allocated to different source networks. 

When a CGNAT virtual server is configured with a source address range larger than /16, the number of available source address ports may be exceeded, and translations may fail.

Impact

Service to certain CGNAT subscribers may be disrupted.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Deterministic NAT address translations fail or result in mappings that cannot be reverse-mapped correctly.

Workaround

To work around this issue, you can perform one of the following actions:

  • In cases where more than one CGNAT virtual server is associated with an LSN pool in deterministic mode, you can limit the number of CGNAT virtual servers per LSN pool to one.
  • In cases where a CGNAT virtual server is configured with a source address network larger than /16, you can reconfigure the CGNAT virtual server to use a network mask smaller than /16.
  • In either of the conditions mentioned above, you can configure the LSN pool to use Network Access Port Translation (NAPT) mode.

Impact of workaround: Impact depends on the network environment and number of virtual servers to be reconfigured.
