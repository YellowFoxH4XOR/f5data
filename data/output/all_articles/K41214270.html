Known Issue

The BIG-IP system may fail to load the configuration if a health monitor send/receive string contains a backslash and double quotation mark ( \ " ), but does not contain a character that requires quoting.

This issue occurs when all of the following conditions are met:

  • You configure a health monitor with a send/receive string.
  • The string contains a backslash double quotation character but does not contain a character that requires quoting. For example, one of the following: ', |, {, }, ;, #, literal newline, or literal space.

Impact

The BIG-IP configuration fails to load.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H560905 on the Diagnostics > Identified > Medium page.
  • The configuration fails to load.

There is no workaround for the issue; however, you may be able to mitigate this issue by using an external monitor.
