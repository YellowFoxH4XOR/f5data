Issue

Attempting to perform a PXE installation using NFS will result in an error message and failed installation.

The following error message is reported immediately after specifying the nfs://mountpoint for the installation location:

Installer 9.4.7-320.0 is not compatible with the following builds: BIG-IP 9.4.7

For BIG-IP 9.4.8, the message appears similar to the following example:

Installer 9.4.8-355.0 is not compatible with the following builds: BIG-IP 9.4.8

BIG-IP version 9.4.6 is also affected by this behavior. To install version 9.4.6 through 9.4.8 using PXE,  you must use the HTTP installation option.

BIG-IP version 10.x is not affected by this behavior as it does not offer NFS as an option for installation.
