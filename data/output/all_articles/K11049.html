Known Issue

This is the result of a known issue. On rare occasions, an error message that includes the trunk name as the interface is logged to the /var/log/ltm file. For example:

lacpd[2233]: 01160008:6: HalMsgHandler.cpp:181 - Unknown LACPDU from hal interface: trunk1 port:0

This issue is known to occur when STP is enabled on a trunk and the bcm56xxd process sends a properly formatted BPDU packet to the stpd process, and then incorrectly sends a LACP BPDU packet to lacpd with the interface equal to the trunk name of the previous stpd packet. This causes lacpd to ignore the LACP BPDU packet.

F5 Product Development tracked this issue as ID 242408 (formerly CR133845) and it was fixed in BIG-IP version 10.2.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, or WOM release notes.
