Topic

The BIG-IP PSM system allows an administrator to configure remote logging to send BIG-IP PSM specific logs to a remote logging server.

Note: For information about configuring remote logging for BIG-IP PSM, refer to Configuration Guide for BIG-IP Protocol Security Module.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.

The log information sent to the remote logging server uses the following structure:

Note: The structure of the messages sent by BIG-IP PSM remote logging profile are not configurable.

FTP and SMTP:

  • Protocol
  • Client IP
  • Virtual Server IP
  • Virtual Server Name
  • Profile Name
  • Violation Name
  • Managment IP
  • Unit Hostname
  • Request Blocked
  • Message

HTTP:

  • Protocol
  • Client IP
  • Virtual Server IP
  • Virtual Server Name
  • Profile Name
  • Violation Names
  • Managment IP
  • Unit Hostname
  • Request Blocked
  • Support_id
  • Request (first line max 128bytes)
  • XFF header value

The information contained within a log entry written locally in the /var/log/asm file and the information contained within a log entry written remotely using the remote logging profile is similar.

For example, a locally written log file viewed in the /var/log/asm file would appear similar to the following example:

Nov 20 14:07:39 6400 bd[3493]: 01310017:6: [SECEV] Request violations: Illegal object length,Illegal object type. support id: 5713655784835907608, source ip: 10.1.1.120, xff ip: 10.1.1.120, HTTP classifier: HTTP_PSM_Remote_Logging, scheme HTTP, request: <GET /1.txt HTTP/1.0>

Alternately, a remotely written log file using the BIG-IP PSM remote logging profile would appear similar to the following example:

Nov 20 14:07:39 6400.askf5.com ASM:"HTTP","10.1.1.120","10.1.1.25","test_psm_remote_logging","HTTP_PSM_Remote_Logging","Illegal object length,Illegal object type","10.1.10.10","6400.askf5.com","","5713655784835907608","GET /1.txt HTTP/1.0","10.1.1.120"

The two log entries differ in the following areas of the BIG-IP PSM logging profile:

  • Full BIG-IP PSM hostname
  • Virtual server IP
  • Virtual server name
  • BIG-IP PSM management IP address
