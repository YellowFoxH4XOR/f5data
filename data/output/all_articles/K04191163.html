Description

This describes how to view CPU usage statistics on the BIG-IP as broken down into the Data Plane, Control Plane and Analysis Plane categories via the BIG-IP Configuration utility and TMSH. Per-plane CPU usage statistics are only available for BIG-IP physical devices (including vCMP guests). vCMP hosts do not have per-plane CPU statistics as their resources are provided to vCMP guests. Virtual Edition BIG-IPs do not currently have per-plane CPU statistics.

Environment

  • BIG-IP physical devices

Cause

None

Recommended Actions

  • Displaying per-plane CPU statistics via GUI
  • Displaying per-plane CPU statistics via TMSH


Impact of procedure: Performing the following procedure should not have a negative impact on your system.

 

Displaying per-plane CPU statistics via GUI

  1. Log into the Configuration Utility
  2. Navigate to Statistics -> Performance Reports -> Performance Reports
  3. Go to the System CPU Usage graph
  4. Click the hyperlink for View Detailed Graph
  5. Per-plane CPU usage is provided in the Plane CPU Usage graph

 

Displaying per-plane CPU statistics via TMSH

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the BIG-IP
  2. Issue "tmsh show sys performance system detail"
  3. Locate the Plane CPU Usage section to view the relevant data.

Example:

Sys::Performance System
---------------------------------------------------------------------------------
System CPU Usage(%)                Current  Average  Max(since 01/23/19 03:58:45)
---------------------------------------------------------------------------------
Utilization                              6        7                            32

---------------------------------------------------------------------------------
Plane CPU Usage                    Current  Average  Max(since 01/23/19 03:58:45)
---------------------------------------------------------------------------------

Control Plane                            2        4                            32
Analysis Plane                           0        3                           100

---------------------------------------------------------------------------------
CPU Utilization(%)                 Current  Average  Max(since 01/23/19 03:58:45)
