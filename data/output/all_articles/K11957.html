Known Issue

When opening Office documents through a BIG-IP LTM system licensed with the BIG-IP APM module, the Office application will fail to retrieve and load the requested document. This issue occurs because Office SharePoint Server 2007 (MOSS) instructs linked Office applications using Office 2007 integration to retrieve and save documents to it directly using URLs instead of passing the content through the browser session. This issue causes the MRHSession cookie to not be passed when these references are passed into Office. As a result, Office will attempt to access the file without the cookie and cause the BIG-IP system to prompt for authentication again.

F5 Product Development is tracking this issue as ID 226914 (formerly CR142377).

Workaround

You can work around this issue by configuring Network Access through BIG-IP APM.

Note: For more information about configuring Network Access for BIG-IP APM, refer to the Configuration Guide for BIG-IP Access Policy Manager.
