Description

Requests timeout when using User-Agent GoogleBot.

Environment

  • Bot Defense Profile in Transparent mode
  • DNS Servers Configured
  • Test requests are sent using curl
  • DNS Resolver configured
Cause

When a request arrives with User-Agent GoogleBot, the BIG-IP system is required to validate if the source is Google itself.
This validation is performed by a reverse look up of the IP address in the X-Forwarded-For header of the request and for this BIG-IP contacts a DNS Resolver such as Google.
Without Forward Zones in the DNS Resolver, the BIG-IP is not able to send the request for validation, hence, the request timeout.

Recommended Actions

Configure Forward Zones in the DNS Resolver profile:

  1. Log in to the BIG-IP Configuration Utility
  2. Browse to the section Network > DNS Resolver > DNS Resolver List
  3. Click the DNS Resolver profile created for the Application
  4. Click the Forward Zones tab
  5. Click Create
  6. In the Name field enter '.' which represents All Zones
  7. In the Address field, enter the IP address of the DNS Server (for e.g. 8.8.8.8 to contact Google DNS Resolver)
    Note: An internal DNS server can be configured as long as it is capable of reverse look up.
  8. Click Add
  9. Click Finish
