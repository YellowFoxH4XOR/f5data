Known Issue

Description

The BIG-IP APM Machine Certificate Auth agent may fail to Match Subject CN with FQDN.

This issue occurs when all of the following conditions are met:

  • Your access policy is configured with a Machine Certificate Auth agent.
  • The Machine Certificate Auth agent is configured to Match Subject CN with FQDN.
  • The client machine is not yet part of the domain that is configured with a certificate issued to the domain.

Match Subject CN with FQDN set to Yes specifies that the common name in the machine certificate must match the computer's fully qualified domain name (FQDN). As a result of this issue, Machine Certificate Auth will fail if the Certificate's CN does not literally match with the machine FQDN. For example, a domain certificate with CN = computer.domain.com configured on a client machine with FQDN = computer will not be able to authenticate. 

Impact

Users on non-domain client machines are unable to log on.
