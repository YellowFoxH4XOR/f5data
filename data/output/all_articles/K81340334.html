Description

This article some examples of how to log connections to BIG-IP (GUI & CLI); and send an email notifying about this activity

Environment

  • Tested on BIG-IP 13.x. 14.x, 15.x, 16.x

Recommended Actions

Use this procedure when there is the need of log the logging attempts to your BIGIP GUI or CLI.

  1. Use a text editor (like 'vi' or 'nano') and configure the custom SNMP traps into the user_alert.conf file (complete path is: at /config/alert.conf)
  2. You can use this examples of custom SNMP traps for this purpose, or you can create yours:
        alert BIGIP_CUSTOM_GUI_LOGIN_FAILED "httpd\(pam_audit\): User=(.*) tty=(.*) host=(.*) failed to login after (.*) attempts" {
            snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.300";
            email toaddress="mymail@mydomain.com"
            fromaddress="root"
            body="This is a custom alert OID .1.3.6.1.4.1.3375.2.4.0.300 (GUI LOGIN FAILED)"
        }

        alert BIGIP_CUSTOM_GUI_LOGIN_SUCCESS "httpd\(pam_audit\): user=(.*) partition=(.*)" {
            snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.302";
            email toaddress="mymail@mydomain.com"
            fromaddress="root"
            body="This is a custom alert OID .1.3.6.1.4.1.3375.2.4.0.302 (GUI LOGIN SUCCESS)"
        }

        alert BIGIP_CUSTOM_SSH_LOGIN_SUCCESS "sshd\(pam_audit\): user=(.*) partition=(.*) level=(.*) tty=(.*)" {
            snmptrap OID=".1.3.6.1.4.1.3375.2.4.0.303";
            email toaddress="mymail@mydomain.com"
            fromaddress="root"
            body="This is a custom alert OID .1.3.6.1.4.1.3375.2.4.0.303 (SSH LOGIN SUCCESS)"
        }


*Do not forget to configure your outbound-smtp configuration. Tu can do it with command similar to this: 
        (tmos)# modify sys outbound-smtp mailhub <your.mailhub>
For example:
        (tmos)# modify sys outbound-smtp mailhub mail.f5.com:25


    After that configuration is done, you should received emails every time you see an event that triggers the alert, From /var/log/audit you can see that events that will trigger those mails shold be seen as the following examples:

    Unsuccessful Login event:
    Jun 23 09:08:11 bigip_A_test info httpd(pam_audit)[11423]: 01070417:6: AUDIT - user admin - RAW: httpd(pam_audit): User=admin tty=(unknown) host=172.18.129.125 failed to login after 1 attempts (start="Wed Jun 23 09:08:09 2021" end="Wed Jun 23 09:08:11 2021").

    Successful Login event: 
    Jun 23 09:08:22 bigip_A_test info httpd(pam_audit)[11414]: 01070417:6: AUDIT - user admin - RAW: httpd(pam_audit): user=admin(admin) partition=[All] level=Administrator tty=(unknown) host=172.18.129.125 attempts=1 start="Wed Jun 23 09:08:22 2021" end="Wed Jun 23 09:08:22 2021". Jun 23 09:08:22 bigip_A_test notice httpd[11414]: 01070417:5: AUDIT - user admin - RAW: httpd(mod_auth_pam): user=admin(admin) partition=[All] level=Administrator tty=/bin/bash host=172.18.129.125 attempts=1 start="Wed Jun 23 09:08:22 2021".
