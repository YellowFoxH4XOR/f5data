Description

HTTP URL Redirect configured via iRule or LTM Policy is working from internal networks, but not working when clients access website from external networks.

Environment

  • HTTP Redirection configured via iRule or LTM Policy
  • Redirect configured to location that contains pool member's IP address, for example: http[s]://<pool_member_IP>/>URL>

Cause

HTTP Redirection to location that contains pool member's IP will instruct client's web browser to send request directly to pool member. In most cases pool members use private IP addresses and are not accessible from external network.

Recommended Actions

Configure redirect location without IP address, for example instead of "https://10.1.1.1/new_url.php" use "/new_url.php".
