Description

After following K80425458 to modify the list of ciphers and MAC and key exchange algorithms, the new settings are not reflected in /config/ssh/sshd_config.

Environment

  • BIG-IP
  • sshd_config

Cause

  • The file /config/ssh/sshd_config has been directly modified and resulted in the symlink to /var/run/config/sshd_config currently broken.
    Note: F5 does not support editing the /config/ssh/sshd_config file directly.

Recommended Actions

  1. Make a backup of /config/ssh/sshd_config
    # cp -pv /config/ssh/sshd_config /config/ssh/sshd_config.$(date +%s)
  2. Recreate the broken symlink
    # ln -sf ../../var/run/config/sshd_config /config/ssh/
  3. Restart the sshd process
    # tmsh /restart sys service sshd

Additional Information
K80425458: Modifying the list of ciphers and MAC and key exchange algorithms used by the SSH service on the BIG-IP or BIG-IQ systems
