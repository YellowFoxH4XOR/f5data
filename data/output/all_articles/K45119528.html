Description
You wish to upgrade F5OS-C on Velos to 1.5.x (or later) from 1.2.x or 1.3.x?

Environment

  • F5OS-C
  • Velos
  • Upgrade

Cause
n/a

Recommended Actions

Download software 
You can download latest F5OS-C version from here:
https://my.f5.com/manage/s/downloads?productFamily=F5OS&productLine=F5OS_for_VELOS

Select:
1.5.1    Release    Dec 27, 2022    Single pkg. for entire F5OS VELOS release. Inc. complete System Controller...

IMPORTANT:  Check md5sum after download: K8337: Verifying the MD5 checksum for the downloaded F5 software file

Upload the software to Controller
  1. Log in to GUI of Floating IP
    IMPORTANT: Floating IP always select Active System Controller thus it is important to use Floating IP  
  2. Go SOFTWARE MANAGEMENT >> Controller Images
     
  3. Click "UPLOAD" and select file you downloaded and checked md5sum
     
  4. Wait till the uploaded file's status becomes Ready for Active&&Standby Controller.
    IMPORTANT: Do not navigate away while file is uploading or an issue may occur.  From time to time, refresh GUI to check the upload status.
You can run following command to check the status via CLI.
Login to CLI as "admin" and run

show image

You will see similar to below outputs (much longer one), and what you ned to check is all Column for all version has a data.
empty column means some issue, and STATUS should be "ready" before you install 1.5.0

VERSION OS                                   IN
CONTROLLER   CONTROLLER  STATUS  DATE        USE

----------------------------------------------------
1.1.0-3698   1           ready               false  <<---- this software can not be installed (but this is old you can safely ignore)
1.2.1-10781  1           ready   2021-09-01  false
1.2.2-12471  1           ready   2021-10-21  false
1.3.1-5968   1           ready   2022-01-14  true


Installing 1.5.x (or later):
  1. Log in to GUI of Floating IP
    IMPORTANT: Floating IP always select Active System Controller thus it is important to use Floating IP
  2. Go SYSTEM SETTINGS >> Controller Management
  3. In the section Update Software >> Update System Controller Software, keep selecting "Bundled", and then Select ISO image 1.5.0.
  4. Click "Save"
    IMPORTANT: This process takes time and multiple reboots could happen.  Please do not interrupt the upgrade process or problems may occur.
To check the installation status, you can login to CLI as "admin" and run command:
show system image

You should see success for INSTALL STATUS similar to below

                    SERVICE     ISO      INSTALL
NUMBER  OS VERSION  VERSION     VERSION  STATUS

--------------------------------------------------
1       1.3.1-5968  1.3.1-5968  -        success
2       1.3.1-5968  1.3.1-5968  -        success
