Description

iHealth Heuristics  H703192 "Log messages report hard drive errors" is detected after running file system checks.
 

Environment

  • BIG-IP
  • iHealth H703192
     

Cause

H703192 detects by older log.
 

Recommended Actions

Check if the log name is same or changed in H703192 in Additional Information

e.g.
on Qkview generated on 1st Jan 2011
1 occurrences of 'Buffer I/O error' were found in '/var/log/kern.log.2_transformed'.
on Qkview generated on 2nd Jan 2011
1 occurrences of 'Buffer I/O error' were found in '/var/log/kern.log.3_transformed'.

Log will be rotated, so the name of the log will be changed, and in this case, number of occurrence isn't changed then you can tell this is detecting due to the same log.

You can also check if there is "Buffer I/O error" in kern.log after you rebooted. If there is no further recurrence, you can safely ignore.
 

Additional Information

K73827442: Forcing a file system check on the next system reboot
