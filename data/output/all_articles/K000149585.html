K000149585: F5OS 1.8.0 removes some SNMP options for "show full-configuration" command

Type
Support Solution
Published
2025-02-01
Updated
2025-02-01
Source
https://my.f5.com/manage/s/article/K000149585

Description

You notice that you can't find following options for show full-configuration command after upgrading to F5OS 1.8.0

 

SNMP-COMMUNITY-MIB

SNMP-NOTIFICATION-MIB

SNMP-TARGET-MIB

SNMP-VIEW-BASED-ACM-MIB 

 

Environment

F5OS 1.8.0

 

Cause

The change is intentional.

 

Recommended Actions

You can refer to F5 rSeries Planning Guide to know how to view and configure SNMP configuration on F5OS.

 

Additional Information

None
