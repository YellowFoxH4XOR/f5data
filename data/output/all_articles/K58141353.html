Description

TMM start showing memory usage increase after you set value for db key dnssec.maxnsec3persec.
 

Environment

  • BIG-IP
  • v13.1.4.1 and later
  • db key dnssec.maxnsec3persec (set to non default value: 0)
     

Cause

Bug ID 1076401
 

Recommended Actions

Upgrade to a fixed version before modifying the dnssec.maxnsec3persec value. See Bug ID for fixed versions.

Otherwise do not change db key dnssec.maxnsec3persec value.
 

Additional Information

The dnssec.maxnsec3persec variable controls the upper limit of NSEC3 authoritative NXDOMAIN messages that BIG-IP DNS will send per second. 0 is unlimited and the default. A more restrictive value, such as between 10 and 100 per second, may prevent BIG-IP DNS itself from being used during an attack.
