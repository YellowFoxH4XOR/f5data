Topic

Always-On Management (AOM) is a separate subsystem that provides lights-out management for F5OS systems using the 10/100/1000 Ethernet management port over secure shell (SSH) or the serial console.

Description

AOM enables you to manage F5OS platforms using SSH (most platforms) or the serial console, even if the host subsystem is turned off. The F5OS host subsystem and the AOM subsystem operate independently. If AOM is reset or fails, the F5OS host subsystem continues to operate and there is no interruption to load-balanced traffic. AOM is always turned on when power is supplied to the platform. If the F5OS host subsystem stops responding, you can use the AOM Command Menu to reset it.

To determine the latest AOM version supported for your F5OS platform, refer to K86001294: F5OS hardware/software support matrix.
