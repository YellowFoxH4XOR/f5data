Description

Upgrade failed due to manual change in cs.dat file



Environment

  • BIG-IP
  • UCS


Cause

Under /var/log/liveinstall.log , noticed below error;

 - Unexpected error : UCS saving process failed

 - File path must be absolute;

 save.12100.file = "etc/ntp/keys"

- Error accessing database

-Error during config save



Recommended Actions


Seems theres an error in the file cs.dat located under - usr/libdata/configsync/cs.dat

Navigate to the path and open the file cs.dat in Vi Editor

Locate the line etc/ntp and correct it with "/etc/ntp"
