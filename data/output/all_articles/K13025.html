Topic

You should consider using this procedure under the following conditions:

  • User sessions are being disconnected from FirePass
  • FirePass logs an error message that appears similar to the following:

    Possible intrusion attempt detected against account <user> from source IP address <IP>
    for URI=[/vdesk/hangup.php3](USER-AGENT changed.[<User Agent String>]. )

    In this error message, note the following:

    • <user> is the User login name.
    • <IP> is the client IP address.
    • <User Agent String> is the user-agent-string of the client browser.

    For example:

    Possible intrusion attempt detected against account kimbo from source IP address 10.1.1.1
    for URI=[/vdesk/hangup.php3](USER-AGENT changed.[Mozilla/4.0 (compatible; MSIE 8.0; Windows NT
    5.1; Trident/4.0; .NET CLR 1.1.4322; InfoPath.1; .NET CLR 2.0.50727; MS-RTC LM 8)->Mozilla/4.0
    (compatible; MSIE 7.0; Windows NT 5.1; Trident/4.0; .NET CLR 1.1.4322; InfoPath.1; .NET CLR
    2.0.50727; MS-RTC LM 8)]. )

Description

By default, FirePass is configured so that if it detects a change, it monitors the user's browser user-agent string, terminates the session, and logs the user off. This is a security measure to help prevent potential session hijacking attacks. Under certain circumstances, such as if the user uses a custom browser provided by their internet service provider, the user-agent string may change while it is connected to FirePass,  causing the user's session to terminate.

Beginning in FirePass 7.0.0 HF-70-2 and FirePass 6.1.0 HF-610-4 F5 Product Development added a new option to allow a FirePass session to continue when the users browser user-agent string changes.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • Using FirePass 6.1.0 with HF-610-4 or FirePass 7.0 with HF-70-2.

Procedures

Enabling the 'Allow session to continue when user-agent string changes' option

This procedure enables the Allow session to continue when user-agent string changes option that maintains a user's VPN session if the user's browser user-agent string changes.

Impact of procedure: Enabling this feature reduces the security of FirePass by increasing the risk of a session hijacking attack.

  1. Log in to the FirePass administrator console.
  2. Click Device Management.
  3. Click Security.
  4. Click User Access Security.
  5. Select the Allow session to continue when user-agent string changes checkbox.
