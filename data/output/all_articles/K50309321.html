Topic

You should consider using this procedure under the following condition:

  • You want to view throughput-related statistics for your BIG-IP system.

Description

Viewing throughput, or the amount of network traffic traversing the BIG-IP system, can help you determine if sufficient bandwidth is provisioned or if you are approaching the licensed bandwidth limit for your BIG-IP Virtual Edition (VE). To view the following BIG-IP system throughput statistics, you can use the Configuration utility, the TMOS Shell (tmsh), or SNMP.

StatisticDescription
ThroughputThe total throughput in and out of the BIG-IP system collected from all interfaces, including traffic processed by all Traffic Management Microkernel (TMM) and Packet Velocity ASIC (PVA), except the management interface. The following fields are represented in bits per second and packets per second:
  • In: The ingress traffic to the system through its interfaces
  • Out: The egress traffic from the system through its interfaces
  • Service: The larger of the two values of combined client and server-side ingress traffic or egress traffic, measured within TMM. You can compare this to VE-licensed bandwidth.
TMM Client-side ThroughputThe sum throughput of all Traffic Management Microkernel (TMM) and Packet Velocity ASIC (PVA) traffic on the client side. The following fields are represented in bits per second and packets per second:
  • Client In: The sum of all ingress traffic
  • Client Out: The sum of all egress traffic
TMM Server-side ThroughputThe sum throughput of all TMM and PVA traffic on the server side. The following fields are represented in bits per second and packets per second:
  • Server In: The sum of all egress traffic
  • Server Out: The sum of all ingress traffic

In summary:

  • Client In (ingress) and Server In (egress) are the same direction through BIG-IP from client to server
  • Server Out (ingress) and Client Out (egress) are the same direction through BIG-IP from server to client

To view a diagram of this traffic flow, refer to Figure 2 Client-oriented model in K9077: Overview of BIG-IP traffic flow

To view BIG-IP system throughput statistics, perform one of the following procedures.

Prerequisites

You must meet the following prerequisite to use these procedures:

  • You can access the Configuration utility or tmsh.

Procedures

  • Use the Configuration utility to view throughput statistics
  • Use tmsh to view throughput statistics
  • Use SNMP to view throughput statistics

Use the Configuration utility to view throughput statistics

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Statistics > Performance Reports.

    Note: In each of the following steps, you can use the Graph Interval drop-down menu in the Display Options section of the page to also view 3 hour, 24 hour, 7 day, and 30 day historical increments.

  3. To view the current total throughput represented in bits and packets, select the Throughput tab.
  4. To view the current total TMM throughput statistics represented in bits, select View Detailed Graph to the right of Throughput (bits).
  5. To view the current total TMM throughput statistics represented in packets, select View Detailed Graph to the right of Throughput (packets).

Use tmsh to view throughput statistics

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh) by entering the following command:

    tmsh

  2. To view the current total throughput represented in bits and packets, enter the following command:

    show sys performance throughput

    You can add the historical option to also view 3 hour, 24 hour, 7 day, and 30 day historical increments by entering the following command:

    show sys performance throughput historical

  3. To view the current total TMM throughput statistics represented in bits and packets, enter the following command:

    show sys performance throughput detail

    You can add the historical option to also view 3 hour, 24 hour, 7 day, and 30 day historical increments by entering the following command:

    show sys performance throughput detail historical

Use SNMP to view throughput statistics

To view throughput statistics using SNMP, you must perform two separate polls using one or more SNMP object identifiers (OIDs) listed in the Throughput OIDs table. After you use the two poll results to derive the delta value, you can calculate the throughput statistic using the Throughput calculations table. To obtain and use the delta value to calculate throughput, perform the following procedure.

1 Note: Refer to the Client In/Out, Server In/Out definitions at the beginning of the article to understand the reason for the OIDs you use for the calculation.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: Verify that your management station has been granted access to the Configuration utility by going to System > SNMP > SNMP Access > Client Allow List. For more information, refer to K52219241: Configuring SNMP access to the BIG-IP system.

  1. Log in to your SNMP management station.
  2. Choose one or more throughput statistic management information bases (MIBs) to poll.

    Note: Your management station must use SNMP v2 for polling.

  3. Poll the BIG-IP system. The following example determines TMM Client-side Throughput / Client Bits In statistics using the sysStatClientBytesIn MIB:

    snmpget -v 2c -c public 192.168.10.100 .1.3.6.1.4.1.3375.2.1.1.2.1.3.0

    The output appears similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysStatClientBytesIn.0 = Counter64: 1059147649

  4. Wait for a timed interval of your choosing. The examples in this procedure use a 10 second interval.
  5. Poll the BIG-IP system again. The following example polls the same sysStatClientBytesIn MIB:

    snmpget -v 2c -c public 192.168.10.100 .1.3.6.1.4.1.3375.2.1.1.2.1.3.0

    The output appears similar to the following example:

    F5-BIGIP-SYSTEM-MIB::sysStatClientBytesIn.0 = Counter64: 1098410749

  6. Use the following calculation to derive the delta value:

    <delta_value> = <poll_2> - <poll_1>

    For example, if you use the example results from steps 3 and 5, the delta value is 39263100.

    39263100 = 1098410749 - 1059147649

  7. Use the delta value and the Throughput calculations table to obtain the throughput statistic.

    For example, if you use the example delta value from step 6, the TMM Client-side Throughput / Client Bits In throughput statistic is 31410480 bits or 3.9 MB of ingress traffic per second.
