K000149805: Vulnerability scanner reports web-accessible backup files via F5OS-A WebUI

Type
Support Solution
Published
2025-02-14
Updated
2025-02-14
Applies to
  • F5OS
  • F5OS-A: 1.8.X, 1.8.0
Source
https://my.f5.com/manage/s/article/K000149805

Description

Vulnerability scanner reports backup files accessible via F5OS-A webUI.

For example, by accessing:

  • https://<management IP>/backup.tar.gz

Environment

    • rSeries
    • F5OS-A WebUI

Cause

Accessing random URLs (including /backup.tar.gz) via the F5OS-A webUI will return an HTML response that sources JavaScript. When the JavaScript runs in a web browser it will redirect to the login page.

These responses are gzip-compressed from F5OS-A v1.8.0 to improve network performance.

However, the gzip-compressed responses may trigger a false positive from some vulnerability scanners. Bug ID1798869 tracks that issue.

Recommended Actions

None
