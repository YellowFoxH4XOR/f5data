Topic

You should consider using this procedure under the following condition:

  • You are interfacing your BIG-IP system to a virtual PortChannel on a Cisco Nexus Switch.

Description

This article provides procedures on how to configure a Link Aggregation Control Protocol (LACP) trunk in passive mode on a BIG-IP system and a virtual PortChannel (vPC) on a Cisco Nexus switch, so that the devices can properly interface with each other.

Link Aggregation allows multiple physical links to be treated as one logical link on a BIG-IP system and provides redundancy in the event of a physical link failure. For more information about LACP trunks, refer to the Trunks chapter in the BIG-IP TMOS: Routing Administration manual.

Note: For information about how to locate F5 product guides, refer to K98133564: Tips for searching MyF5 and finding product documentation.

Cisco vPC allows a pair of Cisco Nexus switches to appear as a single logical entity to the neighboring device.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • Your BIG-IP system must be running BIG-IP 10.1.0 or later.
  • The Cisco Nexus switch must be running Nexus NX-OS software.

Procedures

Refer to the following two procedures for information on configuring the BIG-IP system and the Cisco Nexus switch:

  • Configure the BIG-IP system to interface with vPC on a Cisco Nexus switch
  • Configure the Cisco Nexus switch to interface with the BIG-IP system

Note: You may apply the following procedures to Cisco Nexus switches that support vPC

Configure the BIG-IP system to interface with vPC on a Cisco Nexus switch

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Network > Trunks > Trunk List.
  3. Select Create to create a new trunk.
  4. Enter a name for the trunk.
  5. Select at least two interfaces in the Available box and select <<.

    Note: The number of interfaces you select should be a power of two. For example, 2, 4, 8.

  6. To enable LACP, select the LACP check box.
  7. For LACP Mode, select Passive.
  8. When the LACP Mode is set to Passive, the values of Long LACP Timeout and Auto Link Selection Policy are selected. Leave these settings as they are unless you want to use a more suitable setting for your environment.

    Note: When both systems are set to Passive mode, LACP does not send control packets. For more information on LACP Timeout and Link Selection Policy settings, refer to the Trunks chapter of the BIG-IP TMOS: Routing Administration manual. 

  9. Select the appropriate Frame Distribution Hash algorithm for your environment.

    Note: The selection of Frame Distribution Hash algorithm depends on your network design. For more information on Frame Distribution Hash settings, refer to the Trunks chapter of the BIG-IP TMOS: Routing Administration manual. 

  10. The other settings may be left at their default. It is not necessary to match settings with the Cisco device.

Configure the Cisco Nexus switch to interface with the BIG-IP system

Note: Refer to your Cisco Nexus switch documentation for the commands to perform the following steps.

  • Turn off IP redirects. If this is not turned off, the switch receives traffic such as duplicate TCP packets, TCP or IP fragments, out-of-order TCP packets, buffer mismatches, or lost packets.
  • Turn off the Cisco Discovery Protocol (CDP). If this is not turned off, the BIG-IP system drops the CDP frames from the Cisco switch, and the BIG-IP interface drop count increases.
  • Turn on Flow control. This setting facilitates auto-negotiation on the interfaces.
