Description

F5OS tenant BIG-IP VE may log an error message like below.

warning mcpd[<PID>]: 01071323:4: Vlan (/<Partition_name>/<vlan_name>:<tag>) is configured, but NOT on hypervisor allowed list.

  • <PID> is the process ID
  • <Partition_name> is the name of the partition/folder
  • <vlan_name> is the name of the vlan
  • <tag> is the vlan tag assigned to the vlan

For example,

warning mcpd[<1234>]: 01071323:4: Vlan (/Common/VLAN001:1) is configured, but NOT on hypervisor allowed list.

Environment

These messages occurs when one of the following conditions are met:

  • When a VLAN is removed on a tenant config on F5OS, while the tenant is deployed.
  • When a VLAN is directly created on the tenant.

Cause

 In F5OS, VLANs should be configured at the F5OS network settings. The configured VLAN is then available for selection on the tenant as needed.

Recommended Actions

When there is an unused VLAN in the tenant, which has already been removed from the tenant config in F5OS, you may follow K000137096: Removing VLAN, vWire and trunk from F5OS tenant config may not remove them from the tenant BIG-IP to remove unnecessary configuration from tenant BIG-IP VE.

Additional Information

The message may also be logged due to a known issue ID 1289705. For more information, refer to the Bug Tracker page below.

Bug ID 1289705: MCPD always logs "01071323:4: Vlan (/<partition_name>/<vlan_name>:<ID>) is configured, but NOT on hypervisor allowed list" on F5OS tenant
