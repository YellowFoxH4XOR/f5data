K7939: Security scans report that administrative URL access is possible when using low-strength SSL ciphers

Topic

Security auditing tools may report that the FirePass controller allows SSL connections to the Administrative Console (/admin or /stats) with lower-strength security ciphers or protocols than are permitted by the FirePass controller's configuration.  

Note: Allowed ciphers and protocols are configured in the SSL Cipher Security and SSL Protocol Versions sections on the Device Management: Security: User Access Security page.

This behavior is by design. The login page for the Administrative Console can be accessed with lower-strength ciphers than are configured on the User Access Security page. However, all login attempts will be rejected, so that no man-in-the-middle attacks or other exploits can obtain information contained within the Administrative Console. Information about a failed login due to low-strength ciphers can be found in the Logon details section of the logon's record, accessed from the Reports: Logons page.

Note: While the possibility is unlikely, the administrative credentials can be subjected to attack if entered into the logon page of the Administrative Console while using a weak cipher. F5 Networks recommends restricting Administrative Console access to known hosts and IP addresses contained within your network. Restrictions on access to the Administrative Console can be configured using the filtering functionality available on the Device Management: Security: Admin Access Security page. By restricting the source IP address to networks for which you control the physical network security and content, you can reduce the chance of attacks on SSL connections with weak ciphers. However, F5 Networks recommends avoiding the use of browsers that use weak ciphers.

Note: Starting in FirePass version 6.0.3, SSL sessions that do not meet a miniumum SSL cipher strength can be mitigated. For more information, refer to K10971: Overview of enforcing SSL cipher strength.
