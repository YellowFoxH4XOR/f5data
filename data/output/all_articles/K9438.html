K9438: Manually installing the FirePass Network Access client components on a Linux client

Topic

When a user launches a Network Access connection for the first time on a Linux client system, the user is prompted to automatically install the Network Access client components. This automatic installation method requires that the user have root or sudo privileges on the client system or the installation will fail.

Note: For more information, refer to K9439: Network Access client components may fail to automatically install on a Linux client.

If your users do not have the necessary permissions to install the Network Access client components, or you prefer to pre-install the client components on corporate workstations, you can manually install the Network Access client components on a Linux client system by performing the following procedure: 

  1. Log in to the Linux client system.
  2. Open a browser and log in to the FirePass webtop or Administrative Console.
  3. While the FirePass session is active, download the np_F5_SSL_VPN.so and SSLVpn.tgz files by entering the following URLs into the browser’s address bar, where <FirePass_Hostname> is the hostname or IP address of the FirePass controller.

    For example:

    https://<FirePass_Hostname>/vdesk/vpn/nogzip/downloads.php/linux/np_F5_SSL_VPN.so

    https://<FirePass_Hostname>/vdesk/vpn/nogzip/downloads.php/linux/SSLVpn.tgz

  4. If you did not log in as the user root, su to the root account using the Linux command line.

    For example:

    su root

    Note: This command prompts you for the root password.

    or:

    sudo su root

    Note: If prompted for a password, enter your Linux password (not the root password). Not all Linux systems use the sudo program. Additionally, if your Linux system uses the sudo program, you must have the necessary sudo permissions to execute the su command.
  5. Move the SSLVpn.tgz file to the root ( / ) directory by entering the following command, where /path/to/SSLVpn.tgz is the full path to the SSLVpn.tgz file you downloaded in Step 3:

    mv /path/to/SSLVpn.tgz /
  6. Change directories to the root ( / ) directory by entering the following command:

    cd /

    Important: Do not skip this Step. The archive must be unpacked from the root directory.
     
  7. Unpack the SSLVpn.tgz file using a command that will preserve the directory structure, ownership, and permissions contained in the archive.

    For example:

    tar xpzvf /SSLVpn.tgz

    As the command executes, the client components are installed into the /usr/local/lib/F5Networks directory.

    Important: Do not attempt to unpack the files to a different directory, since they must be installed under /usr/local/lib/F5Networks to work properly. For security reasons, it is important to preserve the ownership and permissions for each file and directory included in the package.

    Note: The example command provided above should work on most Linux distributions. If the command does not execute properly on your system, refer to your Linux system documentation to determine the appropriate command and options.
  8. Optionally, delete the SSLVpn.tgz file by entering the following command:

    rm /SSLVpn.tgz
  9. Copy the np_F5_SSL_VPN.so file to the user’s plugins directory or to the system-wide (shared) plugins directory.

    For example:
    • User's plugins directory:

      cp /path/to/np_F5_SSL_VPN.so ~<username>/.mozilla/plugins
    • System-wide (shared) plugins directory, where /path/to/np_F5_SSL_VPN.so is the full path to the np_F5_SSL_VPN.so file you downloaded in Step 3, and <username> is the user’s Linux username:

      cp /path/to/np_F5_SSL_VPN.so /usr/local/lib/mozilla/plugins

    Note: The paths above are provided as examples; the locations of the plugins directories may vary on your Linux system. Refer to your vendor browser documentation to determine the location of the plugins directories on your Linux system.
     
  10. Ensure that the user or users have the necessary file permissions to execute the np_F5_SSL_VPN.so file.

    For example:

    chmod 755 /usr/local/lib/mozilla/plugins/np_F5_SSL_VPN.so
