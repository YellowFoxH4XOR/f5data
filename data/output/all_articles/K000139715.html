Known Issue

In BIG-IP APM, F5 Access client does not connect to VPN on MacOS when you configure BIG-IP APM to authenticate users using client certificate.

This issue occurs when all of the following conditions are met:

  • You are using the F5 Access 2.0.3 client on MacOS Sonoma 14.4 and later.
  • You configure client certificate authentication to authenticate users on BIG-IP APM. This includes the following:
    • Client SSL profile with Client Certificate Authentication set to request or require.
    • BIG-IP APM access policy Client Cert Inspection agent.

Impact

You are unable to connect and establish network access VPN.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • On the Graphical user interface, the F5 Access client remains stuck at the "Connecting..." state.
  • You observe logs similar to the following in PacketTunnel.log on the MAC client:

Workaround

To work around this issue, you can configure On-Demand Certificate Authentication in place of the affected client certificate authentication configuration (Client SSL profile with Client Cert Inspection agent). To remove the affected client certificate authentication configuration, you set the Client Certificate Authentication in the affected Client SSL profile to ignore and remove the Client Cert Inspection agent from the access policy.

For more information on On-Demand Certificate Authentication, refer to the On-Demand Certificate Authentication chapter of the BIG-IP Access Policy Manager: Authentication Methods manual.
