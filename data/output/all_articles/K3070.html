Known Issue

The man pages outline the command syntax for the SYN cookie feature as follows; however, the enable and disable functions do not work.

bigpipe global syncookie_threshold enable
bigpipe global syncookie_threshold disable
bigpipe global syncookie_threshold [show]

F5 Networks Product Development tracked this issue as CR33214 and CR42098.

The correct command syntax is as follows, where <value> is the total number of open connections to all virtual servers:

bigpipe global syncookie threshold <value>

Once the defined threshold is reached, BIG-IP will respond to further connection requests with a SYN cookie. This is not a special piece of information that BIG-IP adds to the response; rather, it is a special way that BIG-IP generates the initial sequence number (ISN) that it sends back to the requesting client. Provided the client is real, and not an attacker, the client will properly respond to the ISN and BIG-IP will start the connection as usual.

An attacking client will not respond to the SYN-ACK messages that BIG-IP sends, therefore, that connection request will be ignored, in turn, saving system resources.
