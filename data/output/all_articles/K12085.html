Known Issue

This is the result of a known issue. The FirePass controller does not pass the logon credentials to the Citrix Java Client (JICA) client. As a result, the Auto-Logon feature will not pass the logon credentials, and the session will prompt the user for Windows logon credentials.

F5 Networks Product Development is tracking this issue as ID 337305.

Workaround

To work around this issue, Microsoft Windows clients should use the Citrix ActiveX client.

Note: For more information about configuring FirePass Terminal Server for Citrix, refer to the FirePass Controller Administrator Guide.
