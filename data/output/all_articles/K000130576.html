K000130576: ISO file missing after rSeries clean install from PXE or USB DVD/CD-ROM device

Source
https://my.f5.com/manage/s/article/K000130576

Description

ISO file is missing from /var/import/staging after an rSeries clean install from DVD/CD-ROM device or PXE.

Environment

  • Clean install from PXE or DVD/CD-ROM device
  • rSeries

Cause

Bug ID 1213185

This will happen when a clean install is performed using a non USB stick method. For example, USB DVD or PXE install.

Recommended Actions

Explicitly copy the ISO file to the device at the location /var/import/staging manually after clean install.

Additional Information

None
