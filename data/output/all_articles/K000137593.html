Description

There are built in certificates in the BIG IP.
The following will elaborate about each of the certificate and optional updates.

Environment

  • BIG-IP

Cause

None.

Recommended Actions

To find a list of the built in certificates, navigate to System  ››  Certificate Management : Traffic Certificate Management : SSL Certificate List :

  • ca-bundle
  • default   
  • f5-ca-bundle
  • f5-irule

ca-bundle

It is the BIG-IP default CA certificate bundle file located in the /config/ssl/ssl.crt directory

The file is updated automatically during the BIG-IP upgrade process.

To manually update the BIG-IP default CA certificate bundle file, please refer to

  • K60612439: Manually updating the BIG-IP default CA certificate bundle file

default
It is a self-signed certificate. Each BIG-IP comes with a default Secure Sockets Layer (SSL) certificate and key pair.

To manually update it, please refer to

  • K13579: Generating new default certificate and key pairs for BIG-IP SSL profiles

f5-ca-bundle
By default, it is only used for authenticating ca-bundle.crt after ca-bundle.crt is downloaded from the public by the bundle manager.
This certificate can be located at /config/ssl/ssl.crt on CLI.
Other manual update methods are not supported.

f5-irule
It is used to verify the integrity of F5-issued iApps or iRules on the system when the configuration is added/loaded.
It is pre-installed in the BIG-IP image file and must be updated by version upgrade. 
Other manual update methods are not supported.
