K11056033: BIGIQ getting Internal Server Error(500) when try to add a BIGIP device

Type
Support Solution
Published
2021-12-13
Updated
2025-02-06
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K11056033

Description
BIGIQ getting below error message from /var/log/restjavad.0.log when try to add a BIGIP device

Failed to connect to 10.10.10.10 : Internal Server Error(500)

Curl from BIGIQ curl -vk https://10.10.10.10 showing SSL protocol error

Unknown SSL protocol error in connection to 10.10.10.10:443

Tcpdump from BIGIQ showing that after BIGIQ send the "Client Hello" packet, remote device reset the packets.

Environment

  • BIGIQ

Cause
There is a Firewall in between BIGIQ and BIGIP that resetting the connections between BIGIQ and BIGIP

Recommended Actions

Make sure Firewall does not filter any SSL/TLS packets between BIGIQ and BIGIP.

Additional Information
None
