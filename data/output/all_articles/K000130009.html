Description

User wants to be able to send the JSON payload for inspection for some JSON requests, but not all requests with the JSON content type.

 User wants to send the Base64 encoded JSON payload (in the "Content" parameter) for ICAP inspection, specifically for the CreateAttachment action

Environment

  • BIG-IP ASM
  • ICAP server Inspection
  • base64 JSON Payload

Cause

It is working as designed and there is an improvement for it and the Product Engineering team is working on it. 

 Recommended Actions

There might be a way to decode and send only the base64 using an iRule, Writing an irule outside the scope of support. Professional services team needs to be engaged for further help on this. 

 If you would like to configure LTM ICAP, there are manuals describing how to do so as mentioned below,

Configuring Content Adaptation for HTTP Requests and Responses 

Additional Information

Article K47008252 states under recommended actions that the customer can configure LTM ICAP (i.e. content adaptation) to send HTTP requests or responses to their ICAP server - but it won't decode a base64 parameter and send only the resulting image file, which appears to be base64-JSON payload, It will send the full HTTP request content.

So any decoding/checking/verifying would need to be done on the ICAP server side.
