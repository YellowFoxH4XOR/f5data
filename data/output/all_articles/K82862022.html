Description

Unable to uninstall f5-telemetry rpm, error message like the following can be seen: 

"Failed to uninstall: Maximum number of query attempts reached at task worker: /mgmt/shared/iapp/package-management-tasks/995d799e-b54c-4cff-843b-5c24beeb882d"

Environment

  • Trying to uninstall F5 telemetry rpm package

Cause

This is a problem with the iControlLX extension framework.

Recommended Actions

The workaround that can be applied is the following:

Important: Running clear-rest-storage command is disruptive to the REST configuration database used by iLX apps and contains important device-trust information, read the following article before proceeding: K67220984: Clear-rest-storage. What does it do?

Important: The clear-rest-storage command is not supported in an SSLO HA environment, as it will erase SSLO configuration data and require either a full rebuild or a UCS restore (see K30528103), resulting in downtime for the SSLO HA setup.

  1. Clearing the REST storage. You can do that with command: "clear-rest-storage".

That command will show an output like this:

# clear-rest-storage
Stopping restnoded
Stopping restjavad
Removing storage files
Removing index files
Starting restjavad
Starting restnoded


Now, you will be able to uninstall it.
