Topic

This article applies to BIG-IP 11.5.3 HF2, and 12.0.0 through 12.0.0 HF3. The OneConnect virtual server may preserve the pool selection across multiple HTTP requests.

Description

When a client connects to a OneConnect virtual server that uses an iRule or policy, the pool selection operates as expected:

  • Requests that do not match pool selection conditions are sent to the same pool if the pool was already selected for a previous request on the same connection.
  • If no iRule or policy condition resulting in a pool selection matches the new connection, the request will not fall back to the default pool configured on the virtual server.

Recommended Actions

If you are running BIG-IP 11.5.3 HF2, or 12.0.0 through 12.0.0 HF3 and prefer the behavior described in K9800: Using an iRule to load balance HTTP requests to multiple pools, you may be required to configure default pool selection in your iRule that selects the default pool.
