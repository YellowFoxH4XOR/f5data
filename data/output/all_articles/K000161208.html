Description

On F5OS-Appliance (F5OS-A) platforms such as the rSeries (e.g., R5600, R2600), there are two distinct hostname values:

  • The Linux subsystem hostname (used by the underlying OS and visible in the bash shell).
  • The F5OS system hostname (configured via the F5OS CLI/GUI/API and used by the platform for management and display).

This article explains the difference between these hostnames, why they are not synchronized, and how to retrieve both values from the bash shell.

NOTE: What is mentioned in this article also applies for F5OS-C, though the Linux hostnames will be different depending on the controller or blade that you're on. For example, for controller 1, the hostname will be "controller-1.chassis.local"

Environment

F5OS Linux Hostname

Cause

None

Answer/Recommended Actions

1. Hostname Separation: By Design

  • The F5OS system hostname is set using the F5OS configuration interface (CLI/GUI/API) and is used for management, logging, and display in the F5OS environment.
  • The Linux subsystem hostname is set at the OS level and is used by the bash shell and some system services.
  • These two hostnames are not synchronized. Changing the F5OS system hostname does not update the Linux subsystem hostname.
  • Attempts to manually change the Linux subsystem hostname (e.g., using hostnamectl or editing /etc/hostname) are not supported. The system will revert any such changes to the default value (e.g., appliance-1.chassis.local).

2. Retrieving Hostname Values from the Bash Shell

To display both the Linux subsystem hostname and the F5OS system hostname from the bash shell, use the following commands:

echo $HOSTNAME

echo $SYS_CONFIG_HOSTNAME

Example Output:

[root@appliance-1(R2600-R84-S14):Active] ~ # echo $HOSTNAME
appliance-1.chassis.local

[(root@appliance-1(R2600-R84-S14):Active] ~ # echo $SYS_CONFIG_HOSTNAME
R2600-R84-S14

  • $HOSTNAME returns the Linux subsystem hostname (typically appliance-1.chassis.local).
  • $SYS_CONFIG_HOSTNAME returns the F5OS system hostname as configured in the platform.

 3. Supported Operations

  • To change the F5OS system hostname:
    • Use the F5OS CLI:
    • config
    • system config hostname( <desired-hostname>
    • commit
  • Do NOT attempt to change the Linux subsystem hostname. Any manual changes are unsupported, they will be reverted by the system and could cause something to break.
