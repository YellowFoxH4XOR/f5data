Known Issue

Migrating an NFS metadata to or from an Isilon filer may fail if the ARX metadata size is greater than 4 GB.

Impact

You are unable to complete NFS metadata migration.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  •  The ARX syslog may display an error message that is similar to the following example:

    ERROR: MDMIGRATE_DOT_ACOPIA_FAILED (44695559):

      Initialization of metadata tree in /ifs/rtmeta2 on SH_1_Filer failed; Create of .acopia directory failed

Workaround

To work around this issue, you may destage the metadata and rebuild it in the new location. To do so, perform the following procedure.

Impact of workaround: Services will be unavailable while the metadata is removed and the metadata is initialized in the new location.

Removing and redefining the ARX metadata location

  1. Log in to the ARX CLI.
  2. Enter privileged mode by typing the following command:

    enable
  3. Destage the volume metadata using the following command syntax:

    nsck <namespace> destage volume <volume>

    For example:

    nsck ns1 destage volume /vol1
  4. Enter global configuration mode by typing the following command:

    global
  5. Enter namespace configuration mode using the following command syntax:

    namespace <namespace>

    For example:

    namespace ns1
  6. Enter volume configuration mode using the following command syntax:

    volume <volume>

    For example:

    volume /vol1
  7. Remove the metadata share, using the following command syntax:

    no metadata share filer {nfs3 | nfs3tcp | cifs} path [cluster cl-name]

    For example:

    no metadata share nas3 cifs acp_meta
  8. Define the new metadata share, using the following command syntax:

    metadata share filer {nfs3 | nfs3tcp | cifs} path

    For example:

    metadata share nas1 nfs3 /vol/vol1/meta1
  9. Enable the modified share by typing the following command:

    enable shares
  10. Exit the volume configuration mode and return to privileged mode by typing the following command:

    end
