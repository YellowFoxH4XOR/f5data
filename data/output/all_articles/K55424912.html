Known Issue

Diagnostic data gathered by the qkview utility may be incomplete.

This issue occurs when the following condition is met:

  • You run the qkview utility on a BIG-IP device running an affected version.

Impact

The qkview utility does not gather all memory information.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you analyze data gathered by the qkview utility, HugePage data is missing from the /proc/meminfo file.

Resolution

Status

Workaround

To work around this issue, you can view the HugePage units directly in the /proc/meminfo file. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To view HugePage units, type the following command:

    grep -i huge /proc/meminfo

    For example:

    grep -i huge /proc/meminfo

    AnonHugePages:         0 kB
    HugePages_Total:    3401
    HugePages_Free:       17
    HugePages_Rsvd:        0
    HugePages_Surp:        0
    Hugepagesize:       2048 kB

    Note: F5 recommends including the full contents of the /proc/meminfo file when submitting a support case with F5 Technical Support.
