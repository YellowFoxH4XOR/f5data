K04600350: Using a common set of directives in the NGINX Plus configuration

Description

When the number of contexts increases with similar content (for example, server or location), you should define the same set of directives.

Environment

  • NGINX Plus

Cause

None

Recommended Actions

The best way to manage it is by using the include directive.

  1. Create a dedicated file with a common set of directives.

    For example, create the general.settings file with the following contents:

    proxy_set_header Host $host;
    proxy_http_version 1.1;
    proxy_set_header Connection "";

  2. Use the include directive to call the contents of the general.settings file.

    For example:

    location / {
        include general.settings;
        proxy_pass https://example.com;
        #...
    }

    location /upload {
        include general.settings;
        proxy_pass https://example.org;
        proxy_set_header X-Real-IP $remote_addr;
        #...
    }

  3. Reload the nginx process by entering the following command:

    sudo nginx -t && sudo service nginx reload

This way, '/' location will respect only three proxy_set_header directives from general.settings, whereas '/upload' location will use proxy_set_header X-Real-IP as well.
