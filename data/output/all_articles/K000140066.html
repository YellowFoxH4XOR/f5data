K000140066: After loss of management interfaces the message "Floating IP is not present for enabled partition" every 5 second

Type
Support Solution
Published
2024-06-20
Updated
2024-08-01
Applies to
  • F5OS
  • F5OS-C: 1.6.1
Source
https://my.f5.com/manage/s/article/K000140066

Description

The log message "Floating IP is not present for enabled partition; do not change controller state" is being generated every 5s.

This error will show if floating IP for the controller is not configured under:

system mgmt-ip config ipv4 floating address

If floating IP it is configured these log messages are due to the bug.

Environment

  • VELOS
  • Floating IP
  • Partition ID

Cause

This is due to bug ID1592221 

Recommended Actions

Recreate a partition (no need to enable it). It will use the missing ID in the list.

On active controller, on bash issue the commands:

docker exec -it vcc-partition-agent ifconfig -a | grep 100.65
su admin
config terminal
partition partition default ; exit
commit 
exit
docker exec -it vcc-partition-agent ifconfig -a | grep 100.65
