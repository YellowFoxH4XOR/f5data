What Happened?

You are trying to deploy an Azure VNET site on a region that is not on the list of available regions, so you use the Alternate Region option.

Environment

  • F5® Distributed Cloud (XC)
  • Site Management

 

Answer/Resolution

In order to deploy an alternate region for Azure VNET, we recommend to use the following configuration:

  1. Azure Region Type = Alternate Azure Region Name
  2. Ingress Gateway or Ingress/Egress Gateway = Ingress or Ingress/Egress Gateway (Two Interface) on Alternate Region

 

3. Configuring Azure nodes

4. Update Number of fault domains = 2 under Advanced Options (the switch on the right side)
