K2438: NameSurfer creates an authoritative top level zone when users create a wide IP that does not begin with www

Known Issue

If enabled, NameSurfer creates an authoritative zone file for all wide IPs that are created through the 3-DNS Controller's Configuration utility. By default, NameSurfer creates the authoritative zone file in the following format:

host.zone.tld

If you create a wide IP named www.mycompany.com, NameSurfer creates an authoritative zone file named mycompany.com.

However, if you create a wide IP named mycompany.com (without www), NameSurfer creates an authoritative zone file named .com. In this case, NameSurfer assumes authority for any requests that end in .com and, when using the 3-DNS Controller as the LDNS, any requests sent to the 3-DNS Controller for a .com name may not resolve.

F5 Product Development tracked this problem as CR27235.
