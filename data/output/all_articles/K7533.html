Known Issue

This is the result of a known issue. If a customized negative regular expression contains a carriage return, it may prevent the BIG-IP ASM from starting properly.

The issue occurs when a customized negative regular expression contains a carriage return and is written to file between two other negative regular expressions. As a result, the carriage return creates an ^M and adds an additional line to the /ts/files/site_1/config/fresh/reg_exp_pool.cfg file. This addition prevents the file from being parsed properly and prevents the file's contents from properly loading.

Note: If the ^M appears at the end of the file, the carriage return does not cause this issue to occur.

If this issue does occur, a message that appears similar to the following example is written to the /var/log/asm log file:

*Not allowed activity - two identical records () in /ts/files/site_1/config/fresh/reg_exp_pool.cfg*

F5 Product Development is tracking this issue as CR80596.

Workaround

To prevent traffic disruption, F5 recommends removing carriage returns from any negative regular expressions before applying a policy.
