Known Issue

This is the result of a known issue. BIG-IP version 10.0.0 does not support the use of encrypted private keys (private keys protected with a passphrase) on VIPRION systems. If you import an encrypted private key onto a VIPRION system, and then configure either a Client SSL or Server SSL profile with the key and its associated passphrase, many daemons (including mcpd, lind, and stpd) will restart continuously. During this time, the VIPRION system will not be operational, and the following error messages will be repeatedly logged to the /var/log/ltm file:

local/viprion1 err mcpd[2527]: 0107102b:3: Master Key decrypt failure - decrypt failure
local/viprion1 notice mcpd[2527]: 01071029:5: Master decrypt
local/viprion1 notice mcpd[2527]: 01071027:5: Master key OpenSSL error

F5 Product Development tracked this issue as ID 317396 and ID 205835 (formerly CR116238), and it was fixed in BIG-IP version 10.0.1. For information about upgrading, refer to the BIG-IP LTM, ASM, or PSM release notes.
