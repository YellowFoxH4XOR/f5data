Description

Disable power off button on LCD panel BIG-IP iSeries

Environment

  • BIG-IP iSeries

Cause

None

Recommended Actions

For iSeries, the power button cannot be disabled on LCD panel, which is by design. The LCD panel can't be completely disabled as is used for power control.

    Additional Information

    Command “tmsh modify /sys global-settings lcd-display disabled” will block the following 

    • the setup options
    • alert clear capability
    • mgmt ip and hostname on splash
