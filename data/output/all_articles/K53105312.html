Description

The browser's preferred language is Simplified Chinese, Access Profile language settings contain Simplified Chinese, but the page content is English or other language.
The browser's preferred language is Traditional Chinese, Access Profile language settings contain Traditional Chinese, but the page content is English or other language.

Environment

  • BIG-IP APM
  • Access Profile language setting contains Traditional Chinese, Simplifed Chinese, English, etc.
  • EDGE / IE11 on windows 10 Endlish version, preferred language is Traditional Chinese or Simplifed Chinese.

Cause

Install Chinese language on the Windows 10 English version, change the prefererred Language to Chinese, EDGE and IE11 browser send unsupported language tag to the BIG-IP APM.

Recommended Actions

Follow the steps below to convert the language tag:
  1. Log in to the Configuration Utility
  2. Navigate to Local Traffic  ››  iRules
  3. Click Create
  4. Provide the name of the iRule
  5. Enter the below iRule.
when HTTP_REQUEST {
# Get the current string of Accept-Language
set AL [HTTP::header value Accept-Language]
# if the client cannot get the Simplified Chinese content, replace the language tag for Simplified Chinese.
set AL [string map {zh-Hans-CN zh-CN} $AL]
# if the client cannot get the Traditional Chinese content, replace the language tag for Traditional Chinese.
set AL [string map {zh-Hant-TW zh-TW} $AL]
# Replace the language tag
HTTP::header replace Accept-Language $AL
}
  1. Click Finish
Assign the newly created iRule to the virtual server.

Note: Please test the iRule before you implement the change in the production system. For complete and detailed information iRules syntax, see the F5 Networks DevCentral website. 
F5 Support does not design or configure iRules.  If you are in need of any assistance configuring an iRule to best work for your environment, F5 Professional Services can assist.

Additional Information

Windows 10 Simplified Chinese version will send the supported language tag to the BIG-IP APM, get the Simplified Chinese content.
Windows 10 Traditional Chinese version will send the supported language tag to the BIG-IP APM, get the Traditional Chinese content.
