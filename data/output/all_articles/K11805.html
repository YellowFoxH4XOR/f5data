Known Issue

This is the result of a known issue. If you disable a 10GBASE-LR SFP+ port on a VIPRION PB200 blade, the port remains down after you re-enable it. When this issue occurs, the BIG-IP system logs an error message to the /var/log/ltm file that appears similar to the following example:

slot1/bip01 err bcm56xxd[24473]: 012c0010:3: Trouble setting interface enable for 1/2.1 bsx.c(1016)

F5 Networks Product Development is tracking this issue as ID 328311 and CR140192.

Note: This issue does not affect BIG-IP versions 10.2.0 and later.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, which has been issued for BIG-IP version 10.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

Workaround

You can work around this issue by restarting the bcm56xxd daemon. To do so, enter the following command:

Important: Issuing the following command will briefly interrupt all production traffic. F5 Networks strongly recommends running this command during a scheduled maintenance window.

bigstart restart bcm56xxd
