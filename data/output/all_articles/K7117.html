K7117: Manually configuring the BIG-IP GTM to answer TCP DNS requests

Topic

Prior to version 9.3.0, the BIG-IP GTM system answers UDP DNS queries from LDNS servers by default. You can manually configure the BIG-IP GTM system to answer TCP DNS queries.

Note: Starting in version 9.3.0, you can use the Configuration utility to configure the BIG-IP GTM to answer TCP or UDP DNS requests. For more information, refer to K7716: Change in Behavior: The BIG-IP GTM can be configured to answer TCP or UDP DNS requests.

To configure the BIG-IP GTM system to answer TCP DNS queries, you must perform the following two procedures:

Defining a BIG-IP GTM listener object using the Configuration utility

Note: You may skip this procedure if you have already defined a BIG-IP GTM listener.

  1. Log in to the Configuration utility.
  2. Click Global Traffic.
  3. Click Listeners.
  4. Click Create.
  5. Type the IP address on which the system listens for DNS requests in the Destination field.
  6. Choose the appropriate VLAN from the VLAN Traffic drop-down menu.
  7. Click Finished.

Changing the listener object to TCP using the command line

  1. Log in to the command line.
  2. Using a text editor, edit the /config/bigip_local.conf file.
  3. If the BIG-IP GTM listener address you defined is 10.10.0.1, the BIG-IP GTM listener object will appear as follows in the /config/bigip_local.conf file:
    virtual address 10.10.0.1 {
   floating disable
   unit 0
}
virtual vs_10_10_0_1_53_gtm {
   destination 10.10.0.1:domain
   ip protocol udp
   translate address disable
   translate service disable
   profile dns udp
}
  4. Change the listener object by changing UDP to TCP as follows:
    virtual address 10.10.0.1 {
   floating disable
   unit 0
}
virtual vs_10_10_0_1_53_gtm {
   destination 10.10.0.1:domain
   ip protocol tcp
   translate address disable
   translate service disable
   profile dns tcp
}
  5. Save the changes and exit the text editor.
  6. To load the configuration into memory, type the following command:

    bigpipe load
