Known Issue

The BIG-IP system may log erroneous "chassis fan tray removed" or "chassis fan tray inserted" messages.

This issue occurs when all of the following conditions are met:

  • The platform is a VIPRION 2400 chassis with B2100 blade(s) installed.
  • The lights-out processor (LOP) restarts as a result of a watchdog timeout.

If the lopd process loses connectivity with the LOP subsystem, a watchdog timeout may restart the LOP. When the LOP restarts, the lopd process sends an unsolicited sensor alert to BIG-IP system. The BIG-IP system interprets the alert as indicating that the fan tray has been removed. After LOP has restarted, the BIG-IP system then detects the fan tray as inserted.

Impact

Users may inaccurately interpret "chassis fan tray removed" or "chassis fan tray inserted" messages as a hardware failure.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H427627 on the Diagnostics > Identified > Medium page.
  • The /var/log/ltm file contains error messages that appear similar to the following examples:
     
    • emerg chmand[<pid>]: 012a0000:0: Chassis fan tray REMOVED
    • notice chmand[<pid>]: 012a0005:5: Chassis fan tray inserted
