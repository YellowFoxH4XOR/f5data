Description

How to configure one vlan with multiple interfaces on rSeries 2000/4000 series?

Environment

  • rSeries 2000/4000
  • F5OS-A
  • Interface
  • Vlan

Cause

  • rSeries 2000/4000 does not support applying a vlan to multiple interface before version 1.8.0.
  • For versions 1.8.0 and later, it starts supporting using multiple interfaces per VLAN.

Recommended Actions

  • Create LAGs. (LAGs are trunks for Tenants)
  • Upgrade to version 1.8.0 and later, then enable the configuration below to make the feature available:

NOTE: Adding the same VLAN ID to multiple interfaces could result in L2 loops. Special considerations should be made to the network topology to avoid L2 loops. 

NOTE: Due to Bug ID 1586717, you might need to set the vlan.macassignment to either uniq or global to make the F5OS HOST to pass the interface configuration to the tenant before assigning the VLAN to the tenant. For more details regarding the vlan.macassignment on Tenant, you may further check K000135325: F5OS Tenant with db key vlan.macassignment.

config
system network config multi-interfaces-vlan enabled
commit
