K24141116: APM session remaining time not displayed on browser webtop if MaxSessionTimeout is >= 7 days

Support Solution

Description

When using a browser to connect to the APM, the remaining time for an APM session is not displayed on the APM webtop if the Maximum Session Timeout setting in the Access Profile is set to the default value of 604800 secs (7 days) or greater.

Environment

  • Access Profile
  • Maximum Session Timeout
  • Browser-based connection

Cause

This behavior is by-design. If the MaxSessionTimeout is set to 7 days or greater, the remaining time for the APM session is not displayed on the APM webtop.

The timer itself is functioning properly (i.e., the existing user session will get logged out once the timeout has been reached, and he/she will have to log in again to the APM). It's just that, it is not getting displayed on the APM webtop (so the user does not have any idea when the session is going to timeout).

Recommended Actions

As this is a 'by-design' behavior, no action is required.

However, if you really want the session remaining time to be visible to your users, consider changing the Maximum Session Timeout value to 6 days (518400 secs) or lower.
