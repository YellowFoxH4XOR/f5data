Topic

You can use the IP address intelligence database with the BIG-IP ASM security policy to log or block requests from IP addresses with untrustworthy or questionable reputations.

Description

The IP Intelligence database is a list of IP addresses that may have untrustworthy or questionable reputations. When you use the IP Intelligence feature in the BIG-IP ASM security policy, the system checks the source IP address against a list of denylisted addresses, which is continually updated. The system can then identify IP addresses that may be associated with high risk entities, such as anonymous proxies, Tor exits, phishing proxies, botnets, or scanners. For example, you may want to block IP addresses from known hosting phishing sites and other kind of fraud activities, such as ad click fraud.

The IP Intelligence feature works as follows:

  1. You configure one or more IP Intelligence categories to trigger a block or alarm action.
  2. A client attempts to log in to the web application.
  3. The system compares the client's source IP addresses to those in the IP intelligence database. When it finds a match, the system blocks the request and issues the following violation to the event logs:

    Access from malicious IP address
