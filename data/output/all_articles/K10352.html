K10352: The qkview utility may not collect all necessary BIG-IP WebAccelerator log files

Known Issue

This is the result of a known issue. The qkview utility may not collect all necessary BIG-IP WebAccelerator log files due to the default behavior that instructs qkview to skip all files exceeding 5 MB. As a result, critical or necessary files required by F5 Networks Technical Support may be excluded from the qkview output.

F5 Product Development tracked this issue as CR123109 and it was fixed in BIG-IP WebAccelerator version 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Resolution

Workaround

To prevent this behavior from occurring, run the qkview command and use the -s flag to specify the size allowed. For example, to specify no file size limit, you would type the following command:

qkview -s0
