K000137087: VELOS: Software Image Services import failure

Type
Support Solution
Published
2024-11-28
Updated
2025-11-13
Source
https://my.f5.com/manage/s/article/K000137087

Description

If a software ISO image is copied to the /var/import/staging/ directory (i.e. by using scp), a "services import failure" error will be displayed.

Environment

  • F5OS-C
  • VELOS Controller
  • OS ISO file

Cause

ISO files must be uploaded or imported via the GUI for them to be processed and installed correctly.

Symptoms

If an ISO file is only copied (i.e. with SCP), a "services import failure" status will be shown:

   syscon-2-active# show image
   VERSION OS                                            IN
   CONTROLLER   CONTROLLER   STATUS                   DATE         SIZE      USE
   -------------------------------------------------------------------------------
   1.5.0-8535    1          ready                 2022-08-08    836.67MB    true
   1.5.1-14085   1          services import failure    2022-12-17    836.66MB    false   <----------

Recommended Actions

Upload or import the ISO file via the GUI and verify that the process finishes correctly.

Procedure

  1. In the GUI, access the System Controller and navigate to Software Management >> Controller Images.
  2. Click on the Upload button to upload an ISO OS file previously downloaded to your local workstation, or
  3. Click on the Import button to download an ISO OS file from an accessible web server (provide valid credentials if required).
  4. Wait for the Upload/Import task to finish and ensure the file is marked as ready.

     

Additional Information

If the OS ISO file status already shows "services import failure" because it was only copied, try running the following commands in the Controller's CLI interface (replace with the correct ISO file name):

   touch /var/import/staging/F5OS-C-1.5.1-14085.CONTROLLER.iso
   touch /var/import/staging/F5OS-C-1.5.1-14085.PARTITION.iso
   systemctl restart sw-mgmt

Verify that the installation process restarts and completes successfully.

If these steps do not resolve the issue, generate and upload a Controller qkview file and contact F5 Customer Support.
