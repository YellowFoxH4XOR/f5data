Known Issue

The software installation failure status may not display an error message related to the missing image signature file.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration enforces software signature verification in one of the following scenarios:
    • You configure the BIG-IP system in Common Criteria mode (ccmode).

      Note: The security.commoncriteria system database variable on the BIG-IP system displays a value of 'true'.

    • You configure the BIG-IP system with a FIPS 140-2 Compliance license.

      Note: The security.fips140.compliance system database variable on the BIG-IP system displays a value of 'true'.

    • You set the liveinstall.checksig system database variable manually to 'enable'.
  • You perform a software installation with the image file (.iso), without the corresponding signature file (.sig) in the /shared/images directory.
  • You verify the software installation status using the tmsh show /sys software status command.

Impact

You may need to verify the software installation failure through the /var/log/liveinstall.log file instead of the TMOS Shell (tmsh).

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP software installation fails. Additionally, you notice that the tmsh show /sys software status command reports that the installation failed with an unknown reason. The status of the installation appears similar to the following example:

    failed (reason unknown)

  • The /var/log/liveinstall.log file reports that the installation failure is related to a signature verification issue. The error message appears similar to the following example:

    Terminal error: No signature verification possible for image : /shared/images/BIGIP-13.0.0.0.0.1645.iso

Workaround

To work around this issue, you can review the /var/log/liveinstall.log file to verify the reason for the software installation failure, and then recover from the failed software installation. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To display the last few messages of the software installation log, type the following command:

    tail /var/log/liveinstall.log

    The output appears similar to the following example:

    *** Live install start at 2017/03/13 02:24:08 ***
    info: Daemon-driven execution indicated by ENV variable.
    Terminal error: No signature verification possible for image : /shared/images/BIGIP-13.0.0.0.0.1645.iso*** Live install end at 2017/03/13 02:24:10: failed (return code 2) ***

  3. To recover from this software installation failure, before attempting a re-installation of the software, you can copy the appropriate signature file (.sig) from F5 Downloads to the /shared/images directory of the BIG-IP system.
