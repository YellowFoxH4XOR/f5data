K7787: LDAP group mapping method passwords containing square bracket characters are not synchronized in a failover pair

Known Issue

This is the result of a known issue. If you configure an LDAP group mapping method and enter a password containing square bracket characters in the User password field, the user password will not be synchronized from the active FirePass controller to the standby FirePass controller.

In order to be affected by this issue, the password must contain both left and right square bracket characters and the left square bracket character must precede the right square bracket character.

For example, the following passwords would be affected by this issue:

  • [abc]

  • abc[abc]abc

However, the following passwords would not be affected by this issue:

  • [abc

  • ]abc[

Note: Mapping methods are configured on the Users : Groups : Dynamic Group Mapping page.

F5 Product Development tracked this issue as CR68279 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-552-10 has been issued for FirePass version 5.5.2, cumulative hotfix HF-600-15 has been issued for FirePass version 6.0.0, and cumulative hotfix HF-601-5 has been issued for FirePass version 6.0.1. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
