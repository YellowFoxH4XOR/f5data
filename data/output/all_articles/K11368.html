K11368: The Alternate Webtop feature does not support Mac OS X or Linux clients

Topic

The Alternate Webtop feature (referred to as the Network Access Only Webtop feature in versions prior to FirePass 6.0.0) does not support Mac OS X or Linux clients. If a Mac OS X or Linux client attempts to connect to an alternate webtop, the normal FirePass webtop is displayed.

Note: For an overview of the Alternate Webtop feature, refer to K8126: Change of Behavior: Network Access-only webtop configurations moved in Administrative Console.

F5 Networks Product Development is tracking a request for enhancement (RFE) as CR139280 to support the Alternate Webtop feature for Mac OS X and Linux clients.
