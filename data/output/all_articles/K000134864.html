Description

When TMM restarts on an F5OS-A tenant in forced offline mode, high CPU utilization occurs. Releasing forced offline will restore CPU to normal levels.

Environment

  • rSeries/F5OS-A
  • BIG-IP tenant in forced offline mode
  • TMM restart

Cause

Bug ID1301897

Recommended Actions

Release forced offline mode on the BIG-IP tenant.

None
