K000138451: The CLIENT_DATA event is not triggered when TCP data is received

Type
Support Solution
Published
2024-02-01
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP LTM
Source
https://my.f5.com/manage/s/article/K000138451

Description

For TCP, the CLIENT_DATA event triggers when new data arrives from the client after you issue the TCP::collect command (use arguments to TCP::collect to control whether this event fires for each TCP segment received or after a specified quantity of data has arrived).
 

Environment

iRule
LTM
 

Cause

Expected behavior
 

Recommended Actions

Issue the TCP::collect command in CLIENT_ACCEPTED or simply use CLIENT_ACCEPTED instead of CLIENT_DATA
