Known Issue

This is the result of a known issue. A BIG-IP WebAccelerator system under heavy load may occasionally miss its heartbeat timer. As a result, the system triggers the default failover action for the pvac process.

The pvac process shares a single timer thread for the following separate functions: 

  • Heartbeat management
  • GTM scores
  • MCP subscription events

Under heavy load, one of these functions may prevent the others from executing. In extreme cases, this behavior may prevent the pvac process from incrementing its heartbeat within the 30-second timeout period.

When the pvac heartbeat timeout expires, the system logs the following message to the /var/log/ltm file:

sod[1639]: 01140029:5: HA daemon_heartbeat pvac fails action is restart.

F5 Product Development tracked this issue as CR129670 and it was fixed in BIG-IP WebAccelerator 10.1.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue was fixed in Hotfix-BIGIP-10.0.1-378.0-HF3 issued for BIG-IP 10.0.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
