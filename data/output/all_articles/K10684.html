Known Issue

This is the result of a known issue. Internet Explorer may crash, disappear, or hang during a FirePass pre-logon sequence when the OPSWAT library detects system files as infected. This issue was reported with the following AntiVirus softwares:

  • Avira AntiVirus
  • Kaspersky Internet Security
  • McAfee VirusScan Enterprise 8.5.0i

F5 Product Development tracked this issue as ID 265591 (formerly CR121687) and it was fixed in FirePass version 6.1.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in hotfix HF-127682-1 (OPSWAT version 3.4.3) issued for FirePass versions 6.0.3 and 6.0.2. You may download this hotfix or later versions of the OPSWAT hotfix from the F5 Downloads site.

For instructions about obtaining and installing an OPSWAT hotfix, refer to K6664: Obtaining and installing OPSWAT hotfixes.
