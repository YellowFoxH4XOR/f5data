Known Issue

Carrier-grade network address translation (CGNAT) virtual server connections may fail when using Deterministic NAT (DNAT).

This issue occurs when the following conditions are met:

  • The Large Scale NAT (LSN) pool mode is set to Deterministic.
  • The network configuration is such that the same destination has two different routes. For example, using route pools or Equal Cost Multipath (ECMP) routing.
  • The virtual server processes two connections from the same client to the same destination.

Impact

CGNAT virtual server connections may fail.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H459747 on the Diagnostics > Identified > High screen.
  • The first connection from a client to the CGNAT virtual server succeeds, and the second connection from the same client experiences a TCP RST.
  • Connections are successful when the LSN pool mode is set to use Network Access Port Translation (NAPT).
