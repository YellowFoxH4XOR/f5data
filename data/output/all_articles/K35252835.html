Known Issue

The BIG-IP APM rewrite plug-in may incorrectly implement the 'append_to_tag' rule on the client side.

This issue occurs when the following condition is met:

  • The BIG-IP APM rewrite process uses the HTML patching 'append_to_tag' rule on the client side of the application.
The 'append_to_tag' HTML rule should add text after the tag closing delimiter. However, on the client side, the rule inserts text inside of the tag.

Impact

Web applications may malfunction or fail to render properly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When using the 'append_to_tag' HTML rule, text is incorrectly inserted inside of the tag.
  • When using portal access, web applications malfunction or fail to render properly in browsers.
