Description

You are running BigIP and SSLo versions as following.

  TMOS VERSION:   16.1.0
  SSLO VERSION:   16.1.0
  SSLO RELEASE:   9.0.24

You deployed an inbound topology and when access the https sites through the topology it got connection reset. 

In /var/log/ltm log file with reset cause log enabled, you would see similar logs as below are logged 

err tmm2[30572]: 011f0007:3: http_process_state_prepend - Invalid action:0x107030 serverside (172.16.1.1:443 -> 172.16.1.138:18818) clientside (10.10.100.212:56822 -> 10.10.100.139:443) (Server side: vip=/Common/sslo_inbound_tcp.app/sslo_inbound_tcp profile=http pool=/Common/POOL_LAN_GW server_ip=172.16.1.1)
err tmm2[30572]: 01230140:3: RST sent from 172.16.1.138:18818 to 172.16.1.1:443, [0x2ea3232:552] HTTP internal error (bad state transition)
err tmm2[30572]: 01230140:3: RST sent from 10.10.100.139:443 to 10.10.100.212:56822, [0x2ea3232:552] {peer} HTTP internal error (bad state transition)

Environment

  • SSL Orchestrator v16.1.0-9.0.24 and earlier versions.
  • Inbound topology

Cause

SSL Orchestrator does not support Inbound mode bypass on BIG-IP version 16.1.0 with SSL Orchestrator 9.0 or previous versions. This feature works for IP-based and regular SSL bypass in all versions after BIG-IP 16.1.2.2 with SSL Orchestrator 9.1. 

Recommended Actions

Inbound mode IP based SSL bypass support for SSLO is implemented starting BIG-IP 16.1.2.2 with SSL Orchestrator 9.1.

Please upgrade to the supported BIG-IP and SSL Orchestrator versions.
