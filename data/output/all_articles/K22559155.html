Description

Unable to discover BIG-IP DNS with BIG-IQ, error below:
"Error while transforming WideIP A, exception 'NullPointerException' was returned"
  • Getting  the above error in restjavad logs when trying to discover BIG-IP DNS through BIG-IQ
  • Unable to discover device

Environment

BIG-IQ 8.1

  • Importing BIG-IP DNS
  • Configuration fails to import due to issue with gtm.conf

Cause 

Review of gtm.conf showed white spaces in the names of several of the iRules:
gtm rule "/Common/customer-irule.net _irule" {            <---see net _irule instead of net_irule
when DNS_REQUEST {
   host 10.10.10.10

Same in below:

gtm rule "/Common/second-customer-irule.net _irule" {
when DNS_REQUEST { host 10.10.10.11 }

Recommended Actions

Rename the iRules to remove the space between the underscore, for example:

Modify the name to show as below removing the white space:

gtm rule "/Common/customer-irule.net_irule" {       
  when DNS_REQUEST {
   host 10.10.10.10
