K82040454: BIG-IQ Configuration Discovery Shared Security failed with error

Type
Support Solution
Published
2021-12-06
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K82040454

Description
BIG-IQ Configuration Discovery Shared Security(SSM) failed with error message below,

/var/log/restjavad.0.log
message 'Missing/empty parameter: partition' was returned

Environment

  • BIG-IQ
  • Configuration Discovery
  • SSM

Cause
One of the object is missing partition in the configuration,

        DOS_PROFILE {
                <OMITTED>
                icmpv4-flood {
                    <OMITTED>
                    blacklist-category bad-actors 

blocklist-category bad-actors missing the partition.

Recommended Actions

You could consider one of the following
  • Disable the icmpv4-flood from Dos profile
  • Manually add the missing partition
    • blacklist-category /Common/bad-actors

Additional Information

  • You could use the below to check the dos profile output from BIGIP itself
    • config # restcurl -s -u admin:admin https://localhost/mgmt/tm/security/dos/profile/<replace with appropriate dos profile>/dos-network | jq .
  • You could use the below to capture on BIGIQ itself during BIGIQ configuration discovery
    • config # tshark -P -nni lo -s0 -f "port 8100" -w /var/tmp/$HOSTNAME-ssm-condig-discover.pcap
