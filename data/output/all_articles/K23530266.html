Topic

You should consider using this procedure under the following condition:

  • You want to export BIG-IP Dashboard statistics to a comma-separated values (CSV) file.

Description

The BIG-IP Dashboard displays system statistics in selectable graphs, gauges, and tables. You can export them to a CSV file from the Configuration utility.

Note: Dashboard requires Adobe Flash Player for BIG-IP versions prior to 14.x. However, Adobe no longer supports Flash Player and blocked Flash content from running in Flash Player. F5 recommends that you upgrade your BIG-IP system to at least BIG-IP 14.x for the BIG-IP Dashboard. For information about upgrading to BIG-IP 14.x or later, refer to K84554955: Overview of BIG-IP system software upgrades.

Note: F5 does not support exporting BIG-IP Dashboard statistic from command line.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to the Configuration utility.

Procedures

Export BIG-IP Dashboard statistics to a CSV file

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility on the first BIG-IP system.
  2. Go to Statistics > Dashboard.
  3. For BIG-IP Dashboard, select ACTIONS.
  4. Select Download Data (CSV).
  5. For History, select the length of history you want to export.
  6. For Metrics and Data, select or clear the statistics options.
  7. Select Download.
