K000164074: Radius user authentication with 1nic fails until a vlan is configured

Description

When using 1nic, users cannot log into BIG-IP using radius authentication until a vlan is configured


Environment

  • A BIG-IP that does not have vlans configured yet
  • The BIG-IP is using one-arm deployment or 1nic (this is the default for Azure Marketplace and Hyper-V deployments)
  • You want to management users onto BIG-IP using radius authentication

Cause

When using one-arm deployment (1nic), both the management network (linux) and tmm (BIG-IP) networking stacks share the same interface. When a vlan is not configured, tmm cannot receive and proxy the radius return packets to the linux host. Therefore the linux pam authenticator does not receive the radius response from the radius server.


Answer/Recommended Actions

Complete the initial configuration of the BIG-IP, and configure VLANs and self-IPs. Without VLAN configurations, no traffic can be processed on BIG-IP.
