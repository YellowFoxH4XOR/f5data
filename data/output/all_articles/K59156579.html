Description

After upgrading to any release above version 14, the BIG-IP might show duplicated MAC addresses.

Environment

  • Virtual Edition
  • Version 14 or above
  • Upgrading

Cause

This issue might happen when the MTU is set to less than 1280 and the BIG-IP is upgraded to any version above 14. This issue is related to the following ID:

Bug ID 956133: MAC address might be displayed as 'none' after upgrading

Recommended Actions

  1. Make sure to comment out any line that hardcodes the MTU in /config/startup. For example:
    vi /config/startup
    Comment this line by adding '#' at the beginning, and save the file:
    "nohup /root/ifconfig_change_mtu.sh 1200 >> /root/ifconfig_change_mtu.log 2>&1 &"
  2. Make a UCS backup
  3. Load system default configuration
  4. Now load the UCS saved on step 2
  5. Hardcode the MTU for the interfaces to anything higher than 1280 (e.g. 1400)
  6. Save configuration 

Additional Information

Interfaces might show as down before applying the workaround.
