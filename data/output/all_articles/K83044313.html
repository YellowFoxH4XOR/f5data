Description

You are looking for a way to extract the 'X-Real-IP' header.

Environment

BIG-IP
HTTP profile applied

Cause

BIG-IP doesn't provide a profile with 'X-Real-IP' header.

Recommended Actions

For this purpose, you will need to Write an iRule and then associate it to the virtual server in question.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > iRules.
  3. Select Create.
  4. Enter a name for the iRule.
  5. For Definition, enter the following iRule:

    when HTTP_REQUEST {
    HTTP::header insert X-Real-IP [IP::remote_addr]
    }

    Important: F5 recommends that you consult with your security team before any HTTP header manipulation to ensure that such change is aligned with your information security policy guidelines.

  6. Select Finished.

    You must now associate the new iRule with the virtual server.
