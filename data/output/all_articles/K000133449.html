Description

Bot signature update feature for the BIG-IP has been disabled and you can't perform real-time or scheduled updates.

Environment

BIG-IP ASM 14.1.0 and later.

Cause

Without a Threat Campaigns license, bot signatures cannot be updated using manual or automatic updates.

This is expected behavior. Please refer to K82512024: Managing BIG-IP ASM Live Updates (14.1.x and later) for details.

Recommended Actions

Obtain a Threat Campaigns license. You can view active (licensed) modules on the BIG-IP system by going to System > License in the GUI or typing tmsh show sys license on the CLI.

Additional Information

None.
