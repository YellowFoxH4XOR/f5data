Description

/var/log/ltm is occuplied with similear to below message:

info alertd[<PID>]: 01100049:6: logcheck Info: /var/log disk avail <value>
info alertd[<PID>]: 01100049:6: logcheck Info: /var/log is % <value>
 

Environment

  • BIG-IP
  • alertd
     

Cause

Log filter is set to "informational", and location is set to local.

sys log-config filter /Common/<filter_name> {
    level info
    publisher /Common/local
}
sys log-config publisher /Common/<publisher_name> {
    destinations {
        /Common/local-syslog { }
    }
}

Recommended Actions

Level should set Notice for level, as Informational level log will log too many info.
It is not recommended to use BIG-IP itself as syslog server so set remote syslog server. Please refer further detail for K13080: Configuring the BIG-IP system to log to a remote syslog server.
