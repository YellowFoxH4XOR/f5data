Issue

Error Message

Error Message: DNS Services request rate limiter engaged

For example:

warning statsd[6916]: 011b090f:4: DNS Services request rate limiter engaged
warning statsd[6916]: 011b0910:4: DNS Services request rate limiter disengaged

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The DNS Services RPS license limit has been exceeded.

The BIG-IP LTM system is licensed to provide a maximum number of DNS requests processed by the DNS Services module on a per second (RPS) calculation. These specific limits are determined by the license on the BIG-IP system.

Impact

  • When the DNS Service RPS license limit has been exceeded, subsequent requests are returned with a SERVFAIL response until the number of requests fall below the RPS threshold.
  • When the RPS limit has been exceeded, the DNS Services request rate limiter engaged error message appears in the /var/log/ltm log file.
  • When RPS returns within the licensed limit, the DNS Services request rate limiter disengaged error message appears in the /var/log/ltm log file.

Recommended Actions

You can view the licensed DNS rate limit (RPS) statistics using the tmsh show ltm profile dns command.

The Licensed Service Rates section of the command output appears similar to the following example:

Licensed Service Rates             DNS    GTM
  Effective Rate Limit (RPS)        50     25
  Configured Object Count            1      7
  Rate Rejected Requests         19989   1162

The licensed DNS Services (RPS) rate limit can also be found in the /config/bigip.license file by typing the following command:

cat /config/bigip.license | grep ltm_dns_rate_limit

The output of the command appears similar to the following example:

ltm_dns_rate_limit : 50

F5 recommends that you monitor traffic volumes to allow the license limit to be proactively managed. If the rate limit warnings persist, you can contact your F5 Sales representative about acquiring an update to the license, allowing a higher threshold. Additionally, you can configure the BIG-IP system to send SNMP traps and email messages to a specified address whenever a message is logged as a result of the system reaching the RPS limit. For information about these notification and email message options, refer to the articles in the Supplemental Information section.
