K13500: The Static Application Tunnel fails to connect when Trend Micro Virus Buster Cloud 2011 is installed

Topic

A FirePass Static Application Tunnel may fail to connect when Trend Micro Virus Buster is installed. The session will appear to connect, but attempts to pass network traffic over the tunnel fail. This issue is caused by the Trend Micro Virus Buster service redirecting the application tunnel connection to its own proxy service.

Workaround

To work around this issue, you can replace the Static Application Tunnel with a Dynamic Application Tunnel. To do so, perform the following procedure:

Impact of workaround: Not all applications are compatible with a Dynamic Application Tunnel. 

  1. Log in to the FirePass Administrative Console.
  2. Click Application Access.
  3. Select the resource group that contains the static tunnel favorite you are updating from the Resource Group: drop-down menu. 
  4. Click the name of the application favorite you want to update. 
  5. Select the plus sign (+) next to DYNAMIC TUNNELS.
  6. Click the Add New Dynamic Tunnel button.
  7. Enter a name for the dynamic tunnel in the Name text box.
  8. Copy the information from the static tunnel Application text box to the dynamic tunnel Application text box. 
  9. Click the Add New Dynamic Tunnel button.
