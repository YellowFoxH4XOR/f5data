Description

SNMP traps can be sent out from a BIG-IP device during boot-up, even if the BIG-IP has been configure to have SNMP traps disabled.

Environment

The conditions for this issue are:

  • SNMP config setup with
    • One or more trap destinations are configured.
    • Agent-trap and bigip-traps are set to disabled.
      • In GUI go to System > SNMP > Traps (all items have been unchecked)
    • sys snmp {
    agent-addresses { tcp6:161 udp6:161 }
    agent-trap disabled					<-----------------HERE
    <SNIP>
    bigip-traps disabled                <-----------------HERE
  • BIG-IP device is rebooted
  • During startup phase, some traps can be sent out which may not be desirable.

Cause

This is due to a race condition where the alertd processes SNMP traps before the mcpd can apply the SNMP configuration which disables traps.
This issue is being tracked as ID 894481.

Recommended Actions

None.
