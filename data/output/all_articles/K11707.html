Issue

This article applies to BIG-IP APM and BIG-IP Edge 10.x. For information about other versions, refer to the following article:

  • K15025: Error Message: Session variable _active_directory_query_ag.errmsg set to no matching user found with filter

In the event that the search filter in an Active Directory query access policy action contains a typographical error, you may see a log message that appears similar to the following example in the /var/log/apm log file:

AD module: query with '(sAMAccountNam=<username>)' failed in queryActiveDirectoryUser(): no matching user found with filter (sAMAccountNam=<username>) (-1)

AD agent: Query: query with '(sAMAccountNam=<username>)' failed

In this example, sAMAccountName is misspelled in the Search Filter field and is missing the last character e. No error message was generated at the time the Search Filter was configured. Users will be able to authenticate correctly with no error messages because authentication only inspects the user's credentials; however, any action that requires an Active Directory query will fail to run correctly.

If you view an error message that appears similar to the previous error message, confirm that the search filter does not contain any typographical errors.
