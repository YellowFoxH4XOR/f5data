Known Issue

A standby device sends gratuitous ARP (GARP) messages when you have configured the Virtual eXtended LAN (VXLAN) tunnel local address to use a floating self IP.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in a high-availability (HA) configuration.
  • You have created a VXLAN tunnel with the local address configured to use the BIG-IP system's floating self IP address.

Impact

Client connections fail because the upstream switch sends IPsec packets to the standby BIG-IP system.

IP address conflict events on peer switches occur because both BIG-IP systems send GARP messages for the same IP address.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Client connections fail and the upstream switch sends IPsec packets to the standby BIG-IP system.
  • Peer switches experience IP address conflict events.
