Topic

The technology used by the BIG-IP APM system to perform endpoint inspection has changed over time. This article explains the technologies used for each browser, depending on the deployed version.

Important: Microsoft announced the end of support for Internet Explorer on June 15, 2022. As a result, BIG-IP APM no longer supports Internet Explorer. You should use the other supported browsers as listed in this article.

Description

In BIG-IP APM 13.0.0, F5 replaced NPAPI plug-ins with F5 Helper Applications for all browsers except Internet Explorer, and then replaced ActiveX control for Internet Explorer in version 14.1.0.

F5 Helper Applications rely on the client operation system to execute another app with a registered protocol handler. This external app launch mechanism has security implications, and some browsers issue pop-up windows with warning messages. These warnings appear differently depending on browser type.
