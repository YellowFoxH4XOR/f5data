Known Issue

Regular expression attack signature matching for excluded headers may cause memory corruption.

This issue occurs when the following condition is met:

  • The security policy is configured to exclude cookies for attack signature matching.

Excluded headers are headers that are not included in the BIG-IP ASM system's attack signature matching process. All header-based attack signatures assigned to the security policy will not match a request's header name and its value if that header name is configured as excluded. This issue only affects policies that are configured to exclude cookie headers.

Impact

The BIG-IP ASM bd process may restart and produce a core file, and the BIG-IP ASM may temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP ASM system produces a bd core file.
  • The system sends a SIGSEGV to the bd process and logs a message to the /var/log/ts/bd.log file. For example:

    BD_MISC|CRIT |<timestamp>|21213|signals.c:0055|Received SIGSEGV - Core Dumping
