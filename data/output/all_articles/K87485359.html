Description
If disk usage of the /var partition on DCDs gets higher than the disk usage threshold of 80%, indices will be deleted to maintain adequate disk space for Elasticsearch to continue functioning. When this occurs, requests for specific time granularities may return larger timespans than the one requested. In short, some smaller time granularities will not be available if they have been removed to free up disk space. 

Evidence of removed indices can be found in the /var/log/appiq/configserver.log on the CM.

Environment

  • BIG-IQ CM with attached DCDs

Cause
Inadequate disk space on the DCDs. Specifically, the /var is getting more than 80% usage. 

Recommended Actions

Increase the /var partition size on the DCDs.
See:
  • K30902515: Resizing the /var, /var/log, or /shared file system on a BIG-IQ Virtual Edition
