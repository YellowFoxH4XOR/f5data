K8350: Path parameter is required for WebAccelerator to trigger an invalidations rule

Topic

When configuring an invalidations rule, you must define a Path parameter for the Request Header Matching Criteria and the Cached Content to Invalidate. If the Path parameter is not specified, the WebAccelerator system will not trigger the invalidations rule. The Path parameter is required; however, all other parameters are optional.

For information about configuring an invalidations rule, refer to the WebAccelerator Policy Management Guide for your specific WebAccelerator version.
