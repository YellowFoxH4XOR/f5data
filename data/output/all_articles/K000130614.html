K000130614: ERR_CONNECTION_RESET no access to BIG-IP via HTTP even though the HTTPD process is up and running

Type
Support Solution
Published
2025-01-09
Updated
2025-01-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K000130614

Description

The BIG-IP device does not permit access to either HTTP even when the HTTPD service is allowed, up, and running.

• Management IP may be reachable by a ping test

Environment

• Security policies applied to management only
• GUI may be only accessible by SELF-IP

Cause

The BIG-IP has different management security levels, therefore even if the HTTPD service is up and running  the BIG-IP can reject the access if a management firewall policy is enabled

Recommended Actions

Run the below command by SSH CLI or console connection to verify if there is any security policy applied to management GUI access

tmsh show security firewall management-ip-rules

Additional Information

None.
