Known Issue

The remote client certificate Lightweight Directory Access Protocol (LDAP) authentication profile's Check SSL Peer setting may not display.

This issue occurs when all of the following conditions are met:

  • You attempt to configure a remote client certificate LDAP authentication profile using the Configuration utility.
  • You configure the client certificate LDAP authentication profile with SSL enabled.
  • You want to use the SSL Check Peer setting.

Impact

You do not have the option to set SSL Check Peer.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to specify the SSL Check Peer option when the Configuration utility administers the configuration.
  • When configuring a client certificate LDAP authentication profile using the Traffic Management Shell (tmsh) utility, the Check SSL Peer option is available for SSL-enabled configurations.

Resolution

Workaround

To work around this issue, you can use the tmsh utility to create or modify client certificate LDAP authentication modules to use the Check SSL Peer setting. For more information, refer to the Auth chapter of the Traffic Management Shell (tmsh) Reference Guide.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
