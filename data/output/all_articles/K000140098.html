K000140098: Vulnerable Local interface IP is part of Vulnerable list, so do not add allow local subnet entry for it

Type
Support Solution
Published
2024-06-24
Updated
2024-06-24
Applies to
  • BIG-IP
  • BIG-IP APM: 16.0.0, 16.1.0, 16.0.X, 16.0.1, 17.X.X, 16.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0, 16.1.X, 16.1.4, 16.1.3, 16.1.2, 16.1.1, 15.1.10
  • APM Clients
Source
https://my.f5.com/manage/s/article/K000140098

Description

Users cannot start a VPN connection after the APM client is updated to 7246 or later.

On the device,

Vulnerable Local interface IP is part of Vulnerable list, so do not add allow local subnet entry for it, A.B.C.D

The connected network is vulnerable of tunnel crack as LocalIP falls under the public IPs

Is logged.

Environment

  • Browser Client or Edge Client
  • IPV4.
  • The Client is connecting from a public routable address. A.B.C.D above is not a RFC1918 address.

Cause

This is a design change to protect against TunnelCrack attacks CVE-2023-43124 & CVE-2023-43125.

The Client IPV4 address must be RFC1918.

Recommended Actions

A device connecting in this manner is no longer supported.

Additional Information

This behaviour can not be disabled due to security considerations.
