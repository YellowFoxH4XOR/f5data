Description

Is Cache/Disk fragmentation possible while using NGINX Plus configured with local cache?


Environment

NGINX Plus Cache


Cause

Disk fragmentation is a side effect of how data is written to system memory on hard disk drives (HDDs) and some other types of storage. It occurs when a computer writes data to the first available block on the drive, splitting up contiguous files.


Recommended Actions

Linux file systems are less prone to fragmentation as these keep the files scattered across the HDD therefore fragmentation only becomes an issue when a disk is so full that there's no enough space for a large file to be put into the disk without splitting it up. As long as the disk is less than about 80% full, fragmentation is unlikely to happen. You could then split the cache into a second HDD as mentioned here.
