K000153103: Why tenants are not reflecting under the Delegated Access Overview tab?

Type
Support Solution
Published
2025-08-21
Updated
2025-08-21
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud Delegated Access
Source
https://my.f5.com/manage/s/article/K000153103

Description

Tenants are not appearing under the Delegated Access Overview tab for the user after Delegated Access is enabled.

 

Environment

  • F5® Distributed Cloud Console
  • Delegated Access

Answer/Recommended Actions

The user needs to be added to the managed group, e.g.,managed-admin/managed-monitor to view the Managed Tenants listed under the Delegated Access Overview tab from the Operating Tenant.
