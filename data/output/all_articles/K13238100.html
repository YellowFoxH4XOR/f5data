Description

What is the display order of items which are displayed on BIG-IP APM webtop?

Environment

  • BIG-IP APM
  • Webtop with resources assigned

Cause

When using the APM full webtop, this is the default display order of resources: Applications and Links, and Network Access.

Beginning in version BIG-IP APM v12.0, there is a new feature called "webtop sections" which gives you the ability to organize resources in to 'sections'. Within these sections, resources are displayed in alphabetical order.
