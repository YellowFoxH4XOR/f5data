Description

Configuring BIG-IQ to automatically create a logging profile


Environment

BIG-IQ

Automation in create logging profile and associating to a Virtual Server


Cause

None


Recommended Actions

It appears that BIG‑IQ does not directly offer an out‐of‐the‐box option to automatically generate a logging profile and associate it with a Virtual Server based on an application name (such as abc.com). In other words, the BIG‑IQ GUI and standard configuration processes require that logging profiles be created and associated manually.
