Description
/var/log/ltm showing the error below indicates that exhaustion of memory resource.

tmm[23728] Aggressive mode sweeper: /Common/default-eviction-policy (1) (global memory) 13 Connections killed

Environment

  • LTM

Cause
tmsh show sys memory reveals that persist subsystem is having high memory utilization.

------------------------------------------------------------------------------------------------
Sys::SubSystem Memory
SubSystem                     Alloc (bytes)  Max Alloc (bytes)  Object Size  Current Allocations
------------------------------------------------------------------------------------------------

persist                                6.4G               6.4G          160              42703383

This is caused by known issue ID 942185

Recommended Actions

Contact F5 Support.

Additional Information
Reboot of the device should relief the high memory utilization temporary.
