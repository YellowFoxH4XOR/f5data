Issue

Error Message

Unexpected Error: Could not add device (error from devmgmtd): The device <device_name> certificate expired on <date/time>

or

devmgt:<device_name>:::The device (<device_name>) certificate expired on <date/time>

In this error message, note the following:

  • <device_name> is the name of the BIG-IP device in which the device certificate expired.
  • <date> is the device certificate's date and time of expiration.

For example:

Unexpected Error: Could not add device (error from devmgmtd): The device (/Common/bigip1.org) certificate expired on May 15 18:57:30 2016 GMT

or

devmgt:/Common/bigip1.org:::The device (/Common/bigip1.org) certificate expired on May 15 18:57:30 2016 GMT

Message Location

You may encounter this message in the following locations:

  • The TMOS Shell (tmsh) or command line terminal screen
  • The Configuration utility

Description

This message occurs when the following condition is met:

  • You attempt to add a BIG-IP device with an expired SSL device certificate to a device trust.

Impact

The BIG-IP device with the expired SSL device certificate is not added to the trust domain and will be unable to perform high availability (HA) operations, such as configuration synchronization (ConfigSync) and failover.

Recommended Actions

For information about renewing a self-signed device certificate on the BIG-IP system, refer to K6353: Updating an SSL device certificate on a BIG-IP system.
