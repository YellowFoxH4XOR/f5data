K12893: BIG-IP Edge Portal users are unable to open non-HTML documents using Web Application favorites

Topic

BIG-IP Edge Portal users are unable to successfully open non-HTML Web Application favorites. For example, if a Web Application favorite links to a Documents2Go or GoodReader document, the BIG-IP Edge Portal application attempts to open it with the user's browser and the document fails to load.

For more information about the BIG-IP Edge Portal application, refer to K12328: Overview of the BIG-IP Edge Portal application for Apple iPhone, iPad, and iPod touch

F5 Product Development is tracking a Request for Enhancement (RFE) as ID 349960 to give the users the ability to open non-HTML content.
