Topic

You should consider using this procedure under the following condition:

  • You want to determine how long the BIG-IP system has been running.
  • You want to determine how long the BIG-IP VIPRION blades have been running.

Description

You can use the uptime command to determine how long the BIG-IP system has been running. By default, the uptime command output shows the current time, how long the system has been running, how many users are currently logged on, and the system load averages for the past 1, 5, and 15 minutes.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have access to the TMOS shell utility, the bash shell or iControl REST API.

Procedures

Determine the BIG-IP uptime using tmsh

To determine the uptime of the BIG-IP system using the tmsh utility, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the TMOS shell by typing the following command:

    tmsh

  2. Determine the uptime of the BIG-IP system by typing the following command:

    run /util bash -c uptime

    For example, the following output shows the current time (15:08:10), how long the system has been running (25 days), how many users are currently logged on (1 user), and the system load averages for the past 1, 5, and 15 minutes (0.42, 0.42, 0.41):

    15:08:10 up 25 days, 10:50, 1 user, load average: 0.42, 0.42, 0.41

Determine the BIG-IP uptime using the bash shell

To determine the uptime of the BIG-IP system using the bash shell, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the bash shell.
  2. Determine the uptime of the BIG-IP system by typing the following command:

    uptime

    For example, the following output shows the current time (15:08:10), how long the system has been running (25 days), how many users are currently logged on (1 user), and the system load averages for the past 1, 5, and 15 minutes (0.42, 0.42, 0.41):

    15:08:10 up 25 days, 10:50, 1 user, load average: 0.42, 0.42, 0.41

Determine the BIG-IP uptime using the iControl REST API

To determine the uptime of the BIG-IP system using the iControl REST API, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into a client system that has the cURL and jq utilities.
  2. To determine the uptime of the BIG-IP system use the following syntax:

    curl -sku <username:password> -H "Content-Type: application/json" -X POST https://<bigip_IP_addr>/mgmt/tm/util/bash -d "{\"command\":\"run\",\"utilCmdArgs\":\"-c 'uptime'\"}" | jq -r .commandResult

    In the following example the username and password are admin:admin and the management IP address of the BIG-IP system is 192.0.2.245:

    curl -sku admin:admin -H "Content-Type: application/json" -X POST https://192.0.2.245/mgmt/tm/util/bash -d "{\"command\":\"run\",\"utilCmdArgs\":\"-c 'uptime'\"}" | jq -r .commandResult

    For example, the following output shows the current time (15:08:10), how long the system has been running (25 days), how many users are currently logged on (1 user), and the system load averages for the past 1, 5, and 15 minutes (0.42, 0.42, 0.41):

    15:08:10 up 25 days, 10:50, 1 user, load average: 0.42, 0.42, 0.41

Determine the BIG-IP uptime of a BIG-IP VIPRION system

To determine the uptime of a BIG-IP VIPRION system, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log into the TMOS shell of the primary VIPRION blade by typing the following command:

    tmsh

  2. Determine the uptime of the VIPRION blades by typing the following command:

    run util bash -c 'clsh uptime'

    For example, the following output shows the current time for each blade, how long the blades have been running (9 days), how many users are currently logged on, and the system load averages for the past 1, 5, and 15 minutes:

    === slot 2 addr 127.3.0.2 color green ===
    13:24:41 up 9 days, 11:37, 0 users, load average: 0.52, 0.70, 0.84
    === slot 1 addr 127.3.0.1 color green ===
    13:24:42 up 9 days, 11:38, 1 user, load average: 0.65, 0.67, 0.68
