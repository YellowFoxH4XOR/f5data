Description

GUI not using new certificate.


Environment

BIG-IP all where device certificate for the GUI was updated with CLI by renaming existing certificate to new file in same /config/httpd/conf/ssl.crt/ directory.


Cause

httpd tries to load all files in the /config/httpd/conf/ssl.crt/ and /config/httpd/conf/ssl.key/ directories.


Recommended Actions

delete old crt/key files from /config/httpd/conf/ssl.crt/ and /config/httpd/conf/ssl.key/ directories.
