K000092529: [ASM] - Unable to import ASM policy by JSON format

Published
2022-11-02
Updated

Source

Description

Advanced WAF allows a new policy to be created from an imported SWAGGER file in JSON format.  This file is imported as part of the creation menu using the following settings:

Security ›› Application Security : Security Policies : Policies List ›› Create New Policy...
Policy Template: API Security
Upload File: <Upload File>

After selecting the file and hitting upload, the follow error may be shown in a popup menu; 

            [ASM] - Unable to import ASM policy by JSON format

When this occurs, the settings in the SWAGGER file will not be imported as part of the policy creation even if the policy is saved.

 Environment

Adv WAF

Swagger file in JSON format containing policy configuration information to import

 Cause

There may be several causes.  This article discusses the following two related to the SWAGGER file content:
1.  The syntax of the file may have an error.  The JSON maybe missing a character or some other syntactical issue such as a missing comma or closing bracket.
2.  The format of the file may not be readable by the upload function.  The file type maybe not be of type ASCII text or ASCII text with long lines (compact JSON format) but rather maybe something like ASCII text with CRLF eol characters (DOS formatting)

 Recommended Actions

These recommendations are guidelines naming methods that may be useful.
1. Fix the errors by first identifying checking the JSON syntax using a JSON Linter which can list the syntactical errors and possible changes to repair them.  Then modify the file to reflect the fixes.
2. Identify the type and then convert it to an ASCII text format or an ASCII text format with very long lines
 

 Additional Information

Tools that may be of use include both "Online" and local JSON linters for syntax (ie "json_xs"), conversions tool such as "dos2unix" or "jq", and filetype identifiers such as "file"
