Description

The BIG IP is failing to boot up. While connecting to the console, the below error observed:

CPU_VTT_DDR power fault detected, retries=0
CPU_VTT_DDR power fault detected, retries=1
CPU_VTT_DDR power fault detected, retries=2

Fault clear attempts failed. Please power cycle to retry.

Environment

  • BIG IP iSeries 

Cause

Unknown at time of publication.

Recommended Actions

    1. Full reboot to the BIG IP box 
    2. If the device is still failed to boot up, follow K7172  to run the EUD test
    3. Open a Support Case with F5

    None.
