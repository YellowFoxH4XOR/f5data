Known Issue

This is the result of a known issue. The BIG-IP system does not consistently accept special characters in cookie persistence profile names. Special characters are defined as the following:

  • Period ( . )
  • Asterisk ( * )
  • Forward slash ( / )
  • Dash ( - )
  • Colon ( : )
  • Underscore ( _ )
  • Question mark ( ? )
  • Equals ( = )
  • At ( @ )
  • Comma ( , )
  • Ampersand ( & )
  • Space ( )

Although some versions of BIG-IP system are known to accept certain special characters in cookie persistence profile names, F5 does not currently recommend the use of special characters.

Versions 9.0.0 through 9.0.5

In BIG-IP versions 9.0.0 through 9.0.5, special characters are not accepted in cookie persistence profile names.

Versions 9.1.0 and later

In BIG-IP versions 9.1.0 and later, the following special characters can be used in cookie persistence profile names:

  • Period ( . )
  • Dash ( - )
  • Underscore ( _ )

F5 Product Development is tracking this issue as ID 248291 (formerly CR83072).
