Description
While using logrotate utility, it may be observed that the previous day's UCS file size gets changed to 0 bytes when it is configured to logrotate a UCS with a unique name (like bigip-2021-09-13.ucs.1)instead of the default one (like bigip1.ucs). 

Environment

  • BIG-IP
  • UCS back-up
  • Logrotate utility

Cause

UCS backup file becomes 0 Mb in size when using the unique name of UCS file (such as including the date) while using logrotate utility.

Recommended Actions

Logrotate expects the UCS filename to be the same or it will not rotate it.  In the configuration, the file is named as <hostname>-<date>.ucs. The following day it has a different date and therefore logrotate views it as a different file. Thus end up with a .0 file every day that is awaiting the overwrite.

The fix is to save the file as <hostname>.ucs and then it will rotate it each day and will keep multiple copies based on configuration settings. It has to match the prior filename and be a non 0 or it won't be rotated. In the below instance, UCS filename is configured as hostname.ucs
 

[root@bigip1:]# crontab -l
MAILTO=""
1-59/10 * * * * /usr/bin/diskmonitor
0 */4 * * * /usr/bin/diskwearoutstat
34 09 * * * /usr/bin/updatecheck -a
34 09 21 * * /usr/bin/phonehome_upload
0 */6 * * * /usr/bin/coreexpiration
55 * * * * /usr/bin/copy_rrd save
30 * * * * tmsh save /sys ucs /var/ucs/$(/bin/hostname).ucs
45 * * * * tmsh save /sys ucs /var/local/ucs/$(/bin/hostname).ucs

[root@bigip1:] # logrotate -f /etc/logrotate.conf

Additional Information

Configure the logrotate utility to rotate UCS archive files in addition to log files. The UCS archive files placed in /var/ucs are rotated by logrotate and appended with a number that indicates the status of the file rotation.
The rotate <count> option specifies the number of times log files are rotated before being removed. If the rotate option is omitted, files are archived for a period of 24 days by default and specified by the .1 through .24 extension appended to the file name.
The current archive file does not contain a <number> extension. After 24 days, the last archive file is removed, and previous archive files are incremented by 1.
