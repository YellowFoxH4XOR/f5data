Description

Change the hardware with more TMM instances, or extend the blades on the VIPRION system, the pool member may get more concurrent connections.

Environment

  • BIG-IP
  • OneConnect profile

Cause

OneConnect profile will reduce the resource for the connection create / close process, but maybe cause some idle server-side connections. Because each TMM handles load balancing independently of the other TMM instances, and each TMM instance maintenance private idle server-side connections to the same pool member, it is possible that the total server-side idle connections increase, and then pool member get more concurrent connections, as more idle connections are maintained.

Recommended Actions

If necessary, please refer to the K7208, change the setting for Maximum Size.

None.
