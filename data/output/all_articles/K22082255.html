Description

  • In certain BIG-IP versions it's not possible for remote BIG-IP administrative users to view/modify the security policies that are assigned to a virtual server.
  • In the web UI, when you click any virtual server, and then attempt to click on the Security > Policies tab of that virtual server then the web UI throws the following error message:

    An error has occurred while trying to process your request.

  • You may observe the following error message in the /var/log/ltm log:
Nov  9 15:59:02 bigipa info soap[31027]: src=127.0.0.1, user=

Environment

Relevant environmental factors specific to the topic:

  • BIG-IP 15.1.1 and BIG-IP 16.0.1
  • AFM/LTM virtual server
  • Remote User (A BIG-IP administrative user account on a remote authentication server such as Active Directory or TACACS+)

Cause

BUG ID 957337

Note: The impact of the bug on the shared REST path causes the errors described in this article.

Recommended Actions

The actions or steps required to address the topic covered in the description:

  1. Upgrade to BIG-IP 15.1.2 and later or BIG-IP 16.1.0 and later
