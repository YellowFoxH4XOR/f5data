Known Issue

BIG-IP ASM Explicit File Type names may be limited to eight characters.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured to explicitly allow certain file types.
  • The Illegal file type length violation is set to blocking.

Impact

The BIG-IP ASM system triggers blocking violations on legitimate traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system triggers blocking violations on legitimate traffic.
  • When importing a BIG-IP ASM policy that contains an Explicit File Type name longer than eight characters, the Configuration utility displays a message similar to the following example:

    Unknown error after running import policy script.
    Could not import the Security Policy; Error: Explicit Filetype Name is limited to 8 characters.
