Known Issue

BIG-IP APM access policy file check may fail for Mac OS X and Linux systems.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with an Endpoint Security client-side Mac File or Linux File check.
  • Clients connecting to the BIG-IP APM access policy are running the Mac OS X or Linux-based operating system.
  • The access policy Endpoint Security client-side file check is configured to check a file on the client that is 1024 bytes or larger.

Impact

Clients are denied access to the configured BIG-IP APM resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Clients who access the BIG-IP APM access policy receive an error message similar to the following example after entering credentials:

    The session reference number: <session id value>
    Access was denied by the access policy. This may be due to a failure to meet access policy requirements.

  • When comparing md5sum values of the checked file from the BIG-IP APM system and the local client's system, the returned values differ.
