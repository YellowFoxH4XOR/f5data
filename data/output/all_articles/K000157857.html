Description

TMM pod which is crashbacklooping when deployed in v1.7.x


This error can be found when described:


Too many pci buses encountered (32 max)

tmm_start: device_init failed (ERR_UNKNOWN).


Environment

  • TMM in crashloop
  • SPK pre 1.9.x Version

Cause

This is functions as designed for versions previous to 1.9.x

Recommended Actions

Upgrade to SPK 1.9.x, or later, where the value was increased from 32 to 128.
