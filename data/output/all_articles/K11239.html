Known Issue

This is the result of a known issue. The Configuration utility does not identify the minimum configuration elements that are required to create a SOAP monitor. You must set at least the following configuration elements when you create a SOAP monitor:

  • URL path
  • Namespace
  • Method

If any of these configuration elements are not set, the monitor will still be created; however, the monitor will not function.

In addition, after a SOAP monitor with an insufficient configuration is created, a BIG-IP administrator may enable debugging to determine why the monitor is not working. However, doing so will trigger a different known issue that causes SOAP monitors to not function in all cases.

Note: For more information, refer to K11227: The SOAP monitor does not function if debugging is enabled in the monitor configuration.

F5 Product Development is tracking this issue as ID 224861 (formerly CR137880).
