Known Issue

SMTPS connections that do not use Transport Layer Security (TLS) may reset when email bodies contain very long lines.

This issue occurs when all of the following conditions are met:

  • You have configured a virtual server with the SMTPS profile, and you set the activation-mode to allow.
  • An SMTPS client connects to the virtual server that does not use STARTTLS.
  • The client connection sends an SMTPS DATA section with a text line that is longer than approximately 8192 characters.

    Note: 8192 characters is an approximation for the maximum line length. The actual problem length can be affected by the maximum segment size (MSS) value and the particular way that the TCP traffic is segmented.

Impact

Email transported over SMTPS will not be delivered.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • You encounter multiple TCP resets on SMTPS connections.
