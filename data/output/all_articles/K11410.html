Topic

The BIG-IP Configuration utility and the bigpipe dns command enable you to configure basic BIND resolver services. You can specify the nameservers that the BIG-IP system should use for requests, the forwarders list, and the search domain list. Other resolver options, such as the query timeout, which are typically configured in the host's /etc/resolv.conf file, may only be configured using the bigpipe dns include command. For example, the following resolv.conf file includes a DNS query failure timeout smaller than the default value of 5 seconds, which is intended to shorten the overall resolution time during a partial outage:

#
# THIS IS AN AUTO-GENERATED FILE -- DO NOT EDIT!!!
#
# Use the bigpipe shell utility to make changes to the system configuration.
# For more information, see bigpipe dns help.
#
nameserver      1.1.1.1
nameserver      1.1.1.2
options timeout:3

Since the BIG-IP system's resolv.conf file is auto-generated at configuration load time, any changes made to the resolv.conf file will be lost when the configuration is next loaded. To modify the resolver options, you must enter the bigpipe dns include command to modify the running configuration followed by the bigpipe save command to save the modified configuration to the bigip.conf file. To do so, use the following syntax at the BIG-IP command prompt:

bigpipe dns include '"options <option>"'
bigpipe save

Note: The options parameter is preceded by a single quote, a double quote, and followed by a double quote and a single quote.

For example, to change the query timeout to 3 seconds, type the following command:

bigpipe dns include '"options timeout:3"'

Note: It is not necessary to restart any services for the change to take effect.

Note: If you receive the following error message, check that you have included all of the required quotation marks in the correct order:

BIGpipe parsing error:
   012e0051:3: The requested attribute (timeout:3) is invalid for 'dns'.
  
Note: For more information about the bigpipe dns command, refer to the dns man page by typing bigpipe dns help at the BIG-IP command line.
