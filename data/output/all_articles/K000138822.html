Description

This article is intended to help resolve concern of seeing an UNPOPULATED interface's MAC addresses showing up on connected network switches.

show interface status

Name Interface Status Mac-Addr MTU

1.0 miss     f4:15:63:A1:A1:A1 9198

show /sys mac-address

f4:15:63:A1:A1:A1   net vlan     /VLAN-1/VLAN-1    mac_true     

f4:15:63:A1:A1:A1   net interface    1.0       mac_addr   

 

Environment

BIG-IP 

MAC address of unpopulated interface seen in the network

Cause

The BIG-IP system uses the MAC address of its VLANs to pass L3 (and higher) traffic.

Packets entering the BIG-IP's physical interface won't be using the MAC address of the interface. Rather,  they will be using the MAC address of a BIG-IP VLAN that is associated with the physical port.

Recommended Actions

This is working as designed/intended.

For most purposes, you can ignore the mapping of physical interface & MAC addreses that appear in the BIG-IP's Interface List. Instead, focus on the MAC address that is found within the configuration window of the BIG-IP's VLANs.  (Networking > VLANs > VLAN List > 'view each individual configured VLAN'
