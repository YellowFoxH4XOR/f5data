Description

This article explains the procedure to initializing FIPS on rSeries after RMA 

 

Environment

RMA

rSeries

 

Cause

None

 

Recommended Actions

1) On the RMA device, run the following command using admin account in CLI. 

fips hsm factory-reset

 

2) This is what is displayed on the CLI.

appliance-1# config

Entering configuration mode terminal

appliance-1(config)# fips hsm factory-reset

Value for 'new-so-password' (<string, min: 7 chars, max: 30 chars>): *******

Value for 'confirm-new-so-password' (<string, min: 7 chars, max: 30 chars>): *******

 

3) Next, run the following command in CLI

fips hsm force-init 

 

4) This is what is displayed on the CLI.

appliance-1(config)# fips hsm force-init

Value for 'new-so-password' (<string, min: 7 chars, max: 30 chars>): *******

Value for 'confirm-new-so-password' (<string, min: 7 chars, max: 30 chars>): *******

Error: HSM force init failed: UNKNOWN: no error message

 

Note: When you see this message "Error: HSM force init failed: UNKNOWN: no error message", it's expected output and you may proceed to modify the FIPS partition.
