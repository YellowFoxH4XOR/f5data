K83040236: Unable to monitor SNMP process

Type
Support Solution
Published
2022-03-05
Updated
2023-02-21
Source
https://my.f5.com/manage/s/article/K83040236

Description
Beginning in NET-SNMP 5.8, SNMP query fails to detect ErrorMessage at UCD-SNMP.
Attempting to query with SNMP produces error messages similar to the following:

snmptranslate -On UCD-SNMP-MIB::prErrMessage
.1.3.6.1.4.1.2021.2.1.101

snmpwalk -c public -v 2c localhost UCD-SNMP-MIB::prErrMessage
UCD-SNMP-MIB::prErrMessage = No Such Instance currently exists at this OID

In prior to NET-SNMP5.7.2, it works as expected. 
snmpwalk -c public -v 2c localhost prErrMessage
UCD-SNMP-MIB::prErrMessage.1 = STRING:
UCD-SNMP-MIB::prErrMessage.2 = STRING:
UCD-SNMP-MIB::prErrMessage.3 = STRING:
UCD-SNMP-MIB::prErrMessage.4 = STRING:
UCD-SNMP-MIB::prErrMessage.5 = STRING:
UCD-SNMP-MIB::prErrMessage.6 = STRING: No tmm process running

snmpwalk -c public -v 2c localhost prTable | grep prErr
UCD-SNMP-MIB::prErrMessage.1 = STRING:
UCD-SNMP-MIB::prErrMessage.2 = STRING:
UCD-SNMP-MIB::prErrMessage.3 = STRING:
UCD-SNMP-MIB::prErrMessage.4 = STRING:
UCD-SNMP-MIB::prErrMessage.5 = STRING:
UCD-SNMP-MIB::prErrMessage.6 = STRING: No tmm process running
 

Environment

  • BIG-IP
  • Net-SNMP Version 5.8

Cause
Bug ID 1066305 
HOST-RESOURCES-MIB, UCD-SNMP-MIB: Report empty strings correctly

Recommended Actions

Avoid use of UCD-SNMP-MIB::prErrMessage

Additional Information

None
