Description

HTTP requests are blocked with violation "Illegal meta character in URL".

Environment

  • BIG-IP ASM security policy

Cause

Every Allowed URL is configured with Character Set: custom or default. Character set defines allowed and disallowed (meta) characters.
In this example event request log (Security > Event Logs > Application > Requests):

Violation Details
Illegal meta character in URL [2]
Requested URL     /test1/test2/enable&autoplay=1
Wildcard URL     *
Char     &
Hex     0x26

Requested URL     /test1/test2/enable&autoplay=1
Wildcard URL     *
Char     =
Hex     0x3d
Applied Blocking Settings     Block Alarm Learn

Request was blocked due to illegal meta characters: "&" and "=" for Wildcard URL "*".

Recommended Actions

If request is considered legitimate, you can:
  • Modify Character Set to allow related characters. You can do it on default Character Set in GUI "Security  ››  Application Security : URLs : Character Set"

    OR
     
  • Overwrite default Character Set for specific Allowed URL "Security > Application Security > URLs > Allowed URLs > Allowed HTTP URLs > Allowed HTTP URL Properties", Meta Characters tab and move character/s from Global Security Policy Settings to left and change State to Allow.
