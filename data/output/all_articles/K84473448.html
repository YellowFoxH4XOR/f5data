Topic

You should consider using this procedure under the following conditions:

  • You want to install the BIG-IP Edge Client on a Windows device.
  • You do not have access to the BIG-IP APM BIG-IP Edge Client customized install package.
  • You are able to successfully establish an access session to the BIG-IP APM virtual server using a browser.

    Important: F5 strongly recommends contacting your BIG-IP APM system administrator to obtain the specific customized BIG-IP Edge Client package for installation of the BIG-IP Edge Client.
    Using the steps outlined in this article in lieu of obtaining the customized BIG-IP Edge Client from your system administrator could impact the functionality of the BIG-IP Edge Client installation. 

Description

BIG-IP APM users can install the BIG-IP Edge Client software by downloading and installing the BIG-IP Edge Client for Windows directly from the public download URL of a known BIG-IP APM virtual sever. The following procedure steps download the required software and components from a BIG-IP APM virtual server that allow a base installation of the BIG-IP Edge Client. The installation is the minimum non-functional BIG-IP Edge Client. You make the BIG-IP Edge Client functional by performing the repair step of the Performing base installation of the BIG-IP Edge Client procedure. Most BIG-IP APM access configurations define specific features that are included in the BIG-IP Edge Client custom install package, which the BIG-IP APM system administrator distributes. These configurations are not specified when installing using the following procedures. The BIG-IP APM system may need to automatically update the BIG-IP Edge Client software when initiating the first access session to the BIG-IP APM virtual server using the BIG-IP Edge Client.

Note: The BIG-IP APM system administrator can allow general access to these files to external users by creating a dedicated virtual server on which the BIG-IP APM access policy contains Start > Allow. The access policy does not assign any resources and no access to internal resources is granted; however, users can access the listed files hosted on the BIG-IP APM by connecting to the virtual server as noted in the procedures of this article. This method does not require users to authenticate unless authentication is specifically configured in the access policy.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have the fully qualified domain name (FQDN) used for VPN access. This is the virtual server host name used to access the BIG-IP APM for VPN access.
  • When required by the BIG-IP APM virtual server access policy configuration, you can successfully authenticate to an Allowed branch of the access policy using a web browser.

    Note: Successful authentication may not be sufficient to establish an access session other configuration criteria may be considered when allowing VPN access.

  • You have a general understanding of how to create Microsoft directory folders and creating a custom file suffix using a text editor.

    Important: Access to the BIG-IP APM VPN virtual server and the access policy configuration is maintained by the BIG-IP APM system administrator for your organization.

    When seeking assistance regarding accessing the files listed in this article or establishing the VPN access session, direct inquiries to the the BIG-IP APM system administrator for your organization.

Procedures

  • Creating installation folders
  • Creating the config.f5c file
  • Downloading EXE and DLL files to the F5 VPN folder
  • Downloading CAB files to the F5 VPN\F5_TMP subfolder
  • Downloading MSI files to the Downloads folder
  • Performing base installation of the BIG-IP Edge Client

Creating installation folders

When users install the BIG-IP Edge Client, the listed download files must be stored on the user devices in specific folders located in the Downloads folder.

Perform the following procedure to create the required folders:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Create the following folder in the user device Downloads folder:

    F5 VPN

    For example:

    Downloads\F5 VPN

  2. Create the following folder inside the F5 VPN folder:

    F5_TMP

    For example:

    Downloads\F5 VPN\F5_TMP

Creating the config.f5c file

Installing the BIG-IP Edge Client requires the presence of the config.f5c file in the Download\F5 VPN folder. This file is included in the BIG-IP Edge Client customized installation package to inform the installer of any additional components or configuration options for the installation.

Use the following procedure to create an empty config.f5c file when the user first establishes an access session. Automatic download of components and an update of the configuration options, as well as the installed config.f5c file, may be required for the BIG-IP Edge Client to match the requirements for the access session.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  • Using a text editor, create the empty file config.f5c in Downloads\F5 VPN folder.

    Important: You must save the file with the suffix .f5c, not the default .txt suffix.

Downloading EXE and DLL files to the F5 VPN folder

The following procedure downloads the required EXE (executable) and DLL (Dynamic-link library) files for a base installation of the BIG-IP Edge Client. You must store these files must in the Downloads\F5 VPN folder.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Note: F5 recommends using Google Chrome when performing the manual file download procedures.

  1. Open a browser and log in to the BIG-IP APM virtual server.
  2. Open a second tab in the browser to download files.
  3. In the second tab, use the following URL syntax:

    https://<big-ip apm virtual server>/public/download/<file name>

    Replace <big-ip apm virtual server> with the virtual server host name or IP address.

    Replace <file name> with each of the file names in the list.

    For example:

    https://vpn.example.com/public/download/F5fpAPI.dll

Required EXE and DLL files to download

  • F5fpAPI.dll
  • f5fpc.exe
  • f5fpclientW.exe
  • f5vpn_setup.exe
  • scew_uls.dll
  • Optional: f5wininfo.exe

    Note: You can use the f5wininfo.exe executable file to troubleshoot the BIG-IP Edge Client installation. For more information refer to K12444: Overview of the Client Troubleshooting Utility for Windows.

Important: The URL path and file names are case sensitive.

Downloading CAB files to the F5 VPN\F5_TMP subfolder.

Use the following procedure to download required CAB (cabinet) files required for the base installation of the BIG-IP Edge Client. You must store these files in the Downloads\F5 VPN\F5_TMP folder.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. In your browser, use the following URL syntax:

    https://<big-ip apm virtual server>/public/download/<file name.cab>

    Replace <big-ip apm virtual server> with the virtual server hostname or IP address.

    Replace <file name> with each of the file names in the list.

    For example:

    https://vpn.example.com/public/download/cachecleaner.cab

Required CAB files to download

  • cachecleaner.cab
  • f5certchk.cab
  • f5InspectionHost.cab
  • f5syschk.cab
  • f5tunsrv.cab
  • InstallerControl.cab
  • OesisInspector.cab
  • urxhost.cab
  • urxshost.cab
  • urxvpn.cab
  • vdeskctrl.cab

Important: The URL path and file names are case sensitive.

Downloading MSI files to the Downloads folder

Use the following procedure to download the required MSI (Microsoft Windows Installer) files to perform the base line installation of the BIG-IP Edge Client. Ensure that you store the MSI files in the user device's Downloads folder.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

Download the following two MSI files to the user device's Downloads folder:

  • f5fpclients.msi
  • BIGIPComponentInstaller.msi

For example:

https://vpn.example.com/public/download/BIGIPComponentInstaller.msi
https://vpn.example.com/public/download/f5fpclients.msi

Performing base installation of the BIG-IP Edge Client

Use the following procedure to install a base line BIG-IP Edge Client using the files downloaded in the previous procedures. You must complete all of the steps in the procedure to install a functional BIG-IP Edge Client system.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Select and hold (or right-click) BIGIPComponentInstaller.msi.
  2. Select Install.
  3. Double-click f5fpclients.msi.
  4. Select Next > Choose Setup Type > Typical > Install.
  5. For Do you want to allow the following program to install software on this computer?, select Yes.
  6. Restart the Windows device.
  7. Go to the Downloads directory.
  8. Select and hold (or right-click) f5fpclients.msi and select Repair.

    Note: This operation may take a few minutes to complete.

    Important: Running Repair installs additional critical components required for the BIG-IP Edge Client to function.

  9. Restart the Windows device.
  10. Go to Start > Run.
  11. Enter f5fpclientW.
  12. Optional: Select Start > search and enter f5fpclientW.
  13. Optional: In the search results, select and hold (or right-click) BIG-IP Edge Client > Pin to Taskbar.
  14. Optional: Select the BIG-IP Edge Client icon.
  15. Enter the BIG-IP APM VPN FQDN.
  16. Select Next.
  17. Enter your credentials to launch the access session.

    Note: The BIG-IP Edge Client automatically minimizes after the access session establishes.
