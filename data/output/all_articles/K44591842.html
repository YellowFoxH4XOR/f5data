Description

The GTM/DNS devices inside of a sync-group can log the following messages when they detect that one of the sync-group members disconnect or  join the sync-group:

  • Feb  5 13:25:49 GTM-A.gslab.local alert gtmd[7400]: 011a5009:1: SNMP_TRAP: BIG-IP GTM /Common/GTM-B (10.10.1.67) left sync group dns_sync-group
  • Feb  5 13:30:01 GTM-A.gslab.local alert gtmd[7400]: 011a5008:1: SNMP_TRAP: BIG-IP GTM /Common/GTM-B (10.10.1.67) joined sync group dns_sync-group

Environment

  • BIG-IP GTM / DNS.
  • DNS sync-group with more than 1 device in the sync-group.

Cause

The "left sync group" log message can be triggered by any of the following reasons:

  • One of the devices in the sync-group was rebooted.
  • There is latency in the device network.
  • The DNS device was too busy that did not send heartbeat messages to its sync-group peers in the last 30 seconds.

The message "joined sync group" is logged under any of the following reasons:

  • A new GTM/DNS device has been added to the sync-group.
  • A device that belongs to the sync-group recovers connectivity and starts sending heartbeat messages to the sync-group peers.

Recommended Actions

  1. Verify that the affected GTM /DNS device is reachable .
  2. Analyze the workload and CPU usage in the affected device.
  3. Review that there is no network latency that can interfere with the heartbeat probes from the affected device.
