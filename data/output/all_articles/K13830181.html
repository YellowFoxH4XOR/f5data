Description

You can modify the configurations in UCS archive file before restoring.

Environment

  • BIG-IP
  • BIG-IQ

Cause

None

Recommended Actions

Follow the steps to extract UCS, make changes, and re-archive as a new UCS file.

  1. Log on to the BIG-IP system command line.
     
  2. Create a temporary directory by typing the following command:
    mkdir /shared/UCS_EXAMPLE
     
  3. Extract the UCS archive into the temporary directory by typing the following command:
    tar xzvf <full path to your UCS archive and ucs archive name> -C /shared/UCS_EXAMPLE
    For example:tar xzvf /var/local/ucs/backup.ucs -C /shared/UCS_EXAMPLE/
    Note: By default when a ucs is created via the GUI or via the CLI it will be in the /var/local/ucs directory. The exception to that would be if it was created via the CLI or SCP was used to move it to the BIG-IP and it was placed in another directory.
     
  4.  Go to the shared/UCS_EXAMPLE/ folder and you will see the following file and folders inside:config  etc  home  root  SPEC-Files  SPEC-Manifest  var 
  5.  Go to the /config directory and edit the bigip_base.conf file as needed. If you want to change the management IP and route of the system, those settings can be found under "sys management-ip" and "sys management-route". see below for example:sys management-ip 192.168.1.1/16 { }
    sys management-route /Common/default {
          gateway 192.168.1.2
         network default     
  6. Once editing is done you can repack the UCS archive using the following step:
    1. Change directories to the /shared/UCS_EXAMPLE/ directory by typing the following command:
      cd /shared/UCS_EXAMPLE/
    1. Repack the UCS archive by typing the following command to save the new ucs file to /shared/tmp/ location:
      tar czvf /shared/tmp/new_backup.ucs *
