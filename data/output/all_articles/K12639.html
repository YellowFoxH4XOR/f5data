Topic

While troubleshooting a connection issue between BIG-IP APM and a PC client, it may be helpful to change the logging level. The following document describes how to adjust the log level on the client.

Description

Changing the logging level

To change the logging level for the Edge Client, perform one of the following two procedures:

  • Setting extended logging on the Edge Client
  • Enabling logging using the CTU

Setting extended logging on the Edge Client

  1. Start the Edge Client.
  2. Click View Details.
  3. Click View Logs.
  4. Ensure that the Debug log level is enabled.
  5. To generate the diagnostic report, click Diagnostics Report.

Enabling logging using the CTU

  1. Run the f5wininfo.exe file.

    For more information about the CTU, refer to K12444: Overview of the Client Troubleshooting Utility.

  2. Click Tools.
  3. Click Enable logs.
  4. Click File.
  5. Click Generate Report.

    The Report pop-up window opens.

  6. Click the text format option.
  7. Optional: To compress the log files, select the compressed check box.
  8. Click Save As.

    The Save As pop-up window opens.

  9. Choose a path and filename for the report.
  10. Click Save.

Resetting the log files

To reset the log files on the Windows system, perform the following procedure:

  1. Navigate to the directory containing the log files.  Depending on the configuration and user permissions, log files can be in the following locations on Windows systems:
    • %userprofile%\Local Settings\Temp or %TEMP%
    • C:\Windows\Temp
    • C:\Users\<user>\AppData\Local\Temp\Low
  2. Delete all f5*.txt and f5*.txt.bak files.
  3. Delete the logterminal.txt and logterminal.txt.bak files.

After you set the logging level, have the user log in or attempt to connect using the BIG-IP APM system in order to generate new logs. Then generate the report in HTML format
