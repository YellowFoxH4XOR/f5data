Description

Modifying monitor properties gives an error, if it is attached to a pool with Node/Pool member instance.

0107082c:3: Cannot modify the destination address of monitor /Common/my_monitor

Environment

  • Monitor is attached to the pool
  • Trying to modify monitor on the GUI results in an error

Cause

Bug ID 955617: Cannot modify the destination address of a monitor

Recommended Actions

Remove monitor, modify it, and then add it back.

Additional Information

Monitor properties can't be modified if they are in use by a pool.
