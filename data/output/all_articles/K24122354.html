Description

You want to create or modify Virtual Local Area Networks (VLANs) using the Configuration Utility.

Environment

  • BIG-IP Configuration utility
  • VLAN
  • You can access Configuration Utility as an administrative user.
Cause
N/A


Recommended Actions:

You can use Configuration Utility to create or modify VLANs. To do so, perform the following procedures:

Note: In certain situations, you may need to use tmsh, instead of the Configuration utility, to create a new VLAN.

  • Creating a VLAN with an untagged interface
  • Modifying the untagged interface associated with an existing VLAN
  • Creating a VLAN with a tagged interface
  • Modifying a VLAN to be associated with another tagged interface
  • Modifying the VLAN tag number on an existing tagged interface

Creating a VLAN with an untagged interface

A VLAN can only be associated with a single untagged interface. To create a new VLAN with an untagged interface, perform the following procedure:

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to Configuration utility.
  2. To create a VLAN on an untagged interface, click on the 'create' option under Network > VLAN > VLAN List
  3. Choose the properties of the new VLAN (Name, Interface, etc) and ensure to select the option 'Untagged' under the tagging field.
  4. Once completed click on 'Finished' to save the changes.
  5. To view the BIG-IP system's VLAN configuration under  Network > VLAN > VLAN List.

Modifying the untagged interface associated with an existing VLAN

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to Configuration utility.
  2. To modify the interface associated to an existing untagged VLAN , click on the VLAN name under  Network > VLAN > VLAN List
  3. Remove the unwanted interface from the Resources section by click on the interface name and then click on the 'Delete' option.
  4. Add the new interface from the Resources section by click under Interface and then choose the interface from the option list.
  5. Once completed click on 'Update'  at the bottom of the GUI menu to apply and update the changes.

Creating a VLAN with a tagged interface

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to Configuration utility.
  2. To create a VLAN on an untagged interface, click on the 'create' option under Network > VLAN > VLAN List
  3. Choose the properties of the new VLAN (Name, Interface and tag ID) and ensure to select the option 'Tagged' under the tagging field.
  4. Once completed click on 'Finished' to save the changes.
  5. To view the BIG-IP system's VLAN configuration under  Network > VLAN > VLAN List.

Modifying a VLAN to be associated with another tagged interface

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to Configuration utility.
  2. To modify the interface associated to an existing Tagged VLAN , click on the VLAN name under  Network > VLAN > VLAN List
  3. Remove the unwanted interface from the Resources section by click on the interface name and then click on the 'Delete' option.
  4. Add the new interface from the Resources section by click under Interface and then choose the interface from the option list, ensure to select the option 'Tagged' under the tagging field.
  5. Once completed click on 'Update'  at the bottom of the GUI menu to apply and update the changes.

Modifying the VLAN tag number on an existing tagged interface

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to Configuration utility.
  2. To modify the Tag ID associated to an existing Tagged VLAN , click on the VLAN name under  Network > VLAN > VLAN List
  3. Erase the Current Tag ID from the General Properties section by click on the Tag  text field  and then delete the previously value.
  4. Add the new Tag ID from the General Properties section by click under Tag text field and type the new value
  5. Once completed this task click on 'Update'  at the bottom of the GUI menu to apply and update the changes.
