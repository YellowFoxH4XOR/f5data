Description

BIG-IP VE went down with the below error log messages in /var/log/kern.log : 

Jun 30 04:25:00 bigip.01 err kernel: INFO: task jbd2/dm-24-8:1113 blocked for more than 120 seconds.
Jun 30 04:25:00 bigip.01 err kernel: "echo 0 > /proc/sys/kernel/hung_task_timeout_secs" disables this message.
Jun 30 04:25:00 bigip.01 err kernel: INFO: task jbd2/dm-1-8:1119 blocked for more than 120 seconds.
Jun 30 04:25:00 bigip.01 err kernel: "echo 0 > /proc/sys/kernel/hung_task_timeout_secs" disables this message.
Jun 30 04:25:00 bigip.01 err kernel: INFO: task jbd2/dm-3-8:1138 blocked for more than 120 seconds.
Jun 30 04:25:00 bigip.01 err kernel: "echo 0 > /proc/sys/kernel/hung_task_timeout_secs" disables this message.
Jun 30 04:25:00 bigip.01 info kernel: jbd2/dm-3-8     D ffff880037183f60     0  1138      2 0x00000000

Environment

  • BIG-IP VE

Cause

The Linux kernel in the BIG-IP VE was unable to access the filesystem/RAID, causing the system to hang for more than 120 seconds. As a result, the BIG-IP VE stopped functioning properly. 

Recommended Actions

Hypervisor administrator should check: 

  1. Resource utilization at the hypervisor host level.
  2. Disk drive and filesystem health, using health-check tools such as SMART.
  3. Avoid using the virtual machine snapshot function on a BIG-IP VM. Refer to K000093184 for details.
