K28130823: After upgrading from 15.1.3 to 15.1.6, BIG-IP mgmt interface is unreachable

Type
Support Solution
Published
2022-07-21
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.3
Source
https://my.f5.com/manage/s/article/K28130823

Description
The BIG-IP management interface can become unreachable for some clients

Environment

  • BIG-IP TMOS version not patched for ID1008077
  • TMM interface with a FastL4 wildcard Virtual Server configured (0.0.0.0:0)
  • Clients in the same VLAN as the TMM interface cannot access the management interface
  • Clients on a different VLAN from the TMM interface can access the management interface

Cause
As of the fix for ID1008077 (introduced in versions 13.1.5, 14.1.4.4, 15.1.4.1, 16.1.0), Loose Close is required for asymmetric traffic and Loose Init is optional.  In previous versions, Loose Close was not required. If you upgrade to a fixed version, you will need to update the Loose Close setting in the FastL4 profiles to make sure asymmetric traffic processes successfully.

Recommended Actions
In the FastL4 profile of the Virtual Server, set the Loose Close option:

  1. In the BIG-IP GUI, click on Local Traffic > Profiles > Protocol > Fast L4
  2. Click on the link for the FastL4 profile to be modified
  3. On the right hand side of the window, click the Custom checkbox associated with Loose Close.  Clicking the checkbox should enable the other checkbox on the left hand side of the window directly to the right of Loose Close.
  4. Click the checkbox next to Loose Close.
  5. Click the Update button.
