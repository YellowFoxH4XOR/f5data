Description
You encounter all interfaces were down unexpectedly.
tmm were restarted unexpectedly and core file generated.

/var/log/tmm showing BIGIP system sends SIGNAL to tmm,
notice ** SIGSEGV **

/var/log/ltm showing links down,
Link: 1.1 is DOWN
Link: 1.2 is DOWN
Link: 1.3 is DOWN
Link: 1.4 is DOWN
Link: 2.1 is DOWN
Link: 2.2 is DOWN

/var/log/messages showing core file generated,
Started writing core file: /var/core/tmm.xxx.core.gz for PID xxx
Finished writing xxx bytes for core file: /var/core/tmm.xxx.core.gz for PID xxx

Environment

  • BIGIP
  • LTM
  • Core file
  • tmm

Cause
Core file analysis reveals that the issue is caused by ID756150.
The issue usually caused by software issue on Virtual Server running with SCTP protocol.

Recommended Actions

  1. Contact F5 Support and upload core file for analysis request.
  2. If the issue confirmed is caused by ID756150, you could consider to request a possible Engineering Hotfix on top of latest maintenance software release.
You should constantly monitor the software version release note and Engineering Hotfix may not be necessary if specific software version does include the fix of ID756150.
