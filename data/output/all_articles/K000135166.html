K000135166: Httpd service not starting after replacing device certificate

Type
Support Solution
Published
2023-09-13
Updated
2025-02-07
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000135166

Description

After replacing device certificate with CA-signed certificate, and you restart httpd as per K51035715, you notice httpd service fail to start. You see similar logs in /var/log/httpd/httpd_errors:

Jun 21 02:55:21 lab-lb1-b err httpd[18914]: [error] Init: Unable to read pass phrase [Hint: key introduced or changed before restart?]

Environment

  • BIG-IP LTM
  • Passphrase protected SSL key

Cause

BIG-IP unable to read the passphrase protected key

Recommended Actions

  1. Copy encrypted private SSL key to directory /var/tmp
cp /config/httpd/conf/ssl.key/server.key /var/tmp/encrypted_server.key
  1. Generate a new unencrypted key

openssl rsa -in /var/tmp/encrypted_server.key -out /var/tmp/unencrypted_server.key

  1. ​​​​​​Replace the encrypted private SSL key with the newly generated unencrypted key
cp /var/tmp/unencrypted_server.key /config/httpd/conf/ssl.key/server.key
  1. Restart httpd
bigstart restart httpd
