Description

You can not install a fresh Edge Client v7270 package on a Windows computer where Edge Client had not been installed previously.

Installation rolls-back after trying to install 'Windows System Inspector'.

Environment

  • BIG-IP is provisioned with APM
  • APM is deployed with a Network Access resource
  • EPSEC package 'epsec-1.0.0-1972.0 (Jan 13, 2026)' or earlier is installed on APM
  • Windows Edge Client package is deployed with 'Endpoint Security' component
  • Edge Client has not been installed previously on this computer.

Cause

In October 2025, F5 rotated the cryptographic certificates and keys used to sign software update packages. As a result, the verification logic within the BIG-IP APM Installer Service (auto-updater) has been updated to recognize and validate packages signed with the new certificates and keys (K000157005)

Certificate store "Cert:\LocalMachine\F5FirePassRoot" with F5 certificates on this computer does not exist so CAB files' signature is verified using new certificates. 

'OesisInspector.cab' depends on the EPSEC package installed on APM. 'OesisInspector.cab'  file was signed with new certificate and keys since 'epsec-1.0.0-1988' (Feb 17, 2026)

Recommended Actions

Install EPSEC package 'epsec-1.0.0-1988.0' or higher. It is recommended to install the latest one.

You need to review EPSEC, Edge Client and APM release notes to verify there are not more restrictions.
