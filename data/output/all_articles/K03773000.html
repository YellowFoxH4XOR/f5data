Known Issue

Attempts to load the configuration or re-key the BIG-IP system master key fail when the configuration includes unreferenced encrypted objects.

This issue occurs when all of the following conditions are met:

  • You attempt to load a BIG-IP configuration that contains the following items:
    • Unreferenced encrypted objects. For example, the configuration contains an auth radius-server object with an encrypted secret that is not used for authentication.
    • The RADIUS secret was encrypted using a different master key than the current master key.
  • The BIG-IP system's current master key does not encrypt.
  • You attempt to perform one of the following actions:
    • Loading the configuration using the Traffic Management Shell (tmsh).
    • Re-keying the BIG-IP master key using the f5mku utility.

Impact

Attempts to load the BIG-IP system configuration or re-key the BIG-IP system's master key fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to load the BIG-IP system configuration, you receive an error message that appears similar to the following example:

    01071769:3: Decryption of the field (secret) for object (/Common/radius_auth_name) failed.

  • When attempting to re-key the BIG-IP system master key, you receive an error message that appears similar to the following example:

    0107102b:3: Master Key decrypt failure - decrypt failure - final

Workaround

To work around this issue, you can remove the encrypted objects from the configuration and re-key the BIG-IP system using the master key. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP system.
  2. Make a copy of the /config/bigip.conf file by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.SOL03773000

  3. Use a text editor to edit the /config/bigip.conf file and remove the unreferenced encrypted object.
  4. Load the configuration by typing the following command:

    tmsh load sys config

  5. Log in to the peer BIG-IP system command line.
  6. From the active peer BIG-IP system, obtain the master key by typing the following command:

    f5mku -K

    The command output appears similar to the following example:

    oruIVCHfmVBnwGaSR/+MAA==

  7. Copy the output.
  8. Log in to the affected BIG-IP system command line.
  9. Install the master key that you copied in step 7 using the following command syntax:

    f5mku -r <key_value>

    For example:

    f5mku -r oruIVCHfmVBnwGaSR/+MAA==

  10. Verify that the master key is the same on the active peer BIG-IP system and the affected BIG-IP system by typing the following command from the command lines of both systems:

    f5mku -K

  11. Restore the configuration by typing the following command:

    cp /config/bigip.conf.SOL03773000/config/bigip.conf

  12. To load and save the configuration, and to ensure no errors, type the following commands on the affected BIG-IP system command line:

    tmsh load sys config

    tmsh save sys config
