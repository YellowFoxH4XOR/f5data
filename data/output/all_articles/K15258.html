Topic

A last resort pool is a pool of virtual servers that the BIG-IP DNS system uses to resolve DNS name resolution requests in the event that all other pools associated with the wide IP are unavailable.

Description

A last resort pool is a wide IP configuration option that defines a pool of virtual servers that the BIG-IP DNS system uses to load balance DNS requests in the event that all other pools for the wide IP are unavailable. The system uses the resources included in the last resort pool only if no other resources are available to handle DNS name resolution requests for the wide IP.

Consider the following when configuring a last resort pool for a wide IP:

  • Load balancing pools associated with the wide IP should not use the Return to DNS load balancing method. By default, wide IP pools use Return to DNS as the fallback load balancing method. Using the Return to DNS method will prevent the BIG-IP DNS system from using the last resort pool in the event that all other pools associated with the wide IP are unavailable.
  • Ensure that you use a pool of virtual servers that is not part of the normal global server load balancing configuration for the last resort pool.
  • Like other pools, the last resort pool supports health monitors, load balancing, and other configuration options.

Configuring a last resort pool for a wide IP

To configure a last resort pool for a wide IP, perform the following procedure:

Impact of procedure: The following procedure should not have a negative impact on your system.

  1. Navigate to DNS > GSLB > Wide IPs.

    Note: In BIG-IP GTM 10.x through 11.4.1, navigate to Global Traffic > Wide IPs.

  2. Click the wide IP for which you want to enable a last resort pool.
  3. Under the Pools section, select a pool from the Last Resort Pool list.
  4. Click Update.

Recommendations

When configuring a last resort pool, you should consider the following factors:

  • When you design your network, ensure that the virtual servers used in the last resort pool are not used as part of the normal global server load balancing.
  • Consider using a last resort pool to define cluster of servers that return a maintenance page.

Additional Information

In some cases, customer wants to ignore the last resort pool health status. For this requirement, customer may consider to create a new GSLB pool with uncheck "Verify Member Availability" option.

This "Verify Member Availability" setting verifies the availability of the pool members before sending a connection to those resources. When set to disabled, pool members that are marked down (red) by a monitor will be treated as if they were up (green). The default setting is enabled.

For more information, please refer to K13805: The BIG-IP GTM system may fail to verify virtual server availability.
