Known Issue

This is the result of a known issue. The time displayed in the BIG-IP ASM Configuration utility reporting logs may not match the actual system time. This issue occurs because PHP functions do not set the date correctly for specific timezones.

F5 Networks Product Development tracked this issue as CR87850 and it was fixed in BIG-IP ASM version 10.0.0. For information about upgrading, refer to the BIG-IP ASM Release Notes.

This issue has been fixed in Hotfix-BIGIP-9.4.8-407.0-HF4, which has been issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 Networks hotfix policy, refer to K4918: Overview of F5 Networks critical issue hotfix policy.

For information about installing a hotfix for version 9.x systems, refer to K6845: Managing F5 Networks product hotfixes for BIG-IP version 9.x systems.
