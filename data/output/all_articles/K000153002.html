K000153002: Deprecated SSH-RSA host key algorithm detected in latest 17.1.X and 17.5.X

Description

Detection of the deprecated ssh-rsa host key algorithm on BIG-IP LTM systems. Security scans or audits may report the presence of ssh-rsa in the list of supported SSH host key algorithms, which is considered insecure. Example output from ssh -Q key may include ssh-rsa among the available algorithms.

Environment

  • SSHD configuration

Cause

The ssh-rsa host key algorithm is deprecated due to security vulnerabilities. In BIG-IP 17.1.x and later, this algorithm is removed from both FIPS and non-FIPS modes. However, if the SSHD configuration is not explicitly updated, ssh-rsa may still appear as a supported algorithm.

Recommended Actions

To remove the deprecated ssh-rsa host key algorithm and ensure only secure algorithms are used, update the SSHD configuration from a tmsh prompt as follows:

  1. Edit the SSHD configuration
    • edit /sys sshd all-properties
  2. Modify the include statement to specify only secure algorithms:
    • include "Ciphers aes128-ctr,aes256-ctr
      MACs hmac-sha2-256,hmac-sha2-512
      KexAlgorithms ecdh-sha2-nistp256,ecdh-sha2-nistp384
      HostKeyAlgorithms ecdsa-sha2-nistp256,ecdsa-sha2-nistp384,ecdsa-sha2-nistp521,ssh-ed25519,rsa-sha2-512,rsa-sha2-256"
  3. Save and exit the editor (:wq)
  4. Save the configuration:
    • save /sys config
  5. Validate the configuration:
    • list /sys sshd all-properties
  6. Restart the SSHD service:
    • restart sys service sshd

Perform a security scan or packet capture to confirm that ssh-rsa is no longer advertised as a supported host key algorithm.
