Description

Generic Routing Encapsulation (GRE) is a tunneling protocol that can encapsulate a wide variety of network layer protocols inside virtual point-to-point links over an IP network. Because GRE allows huge payloads to be encapsulated and sent, adding the processing overhead of IP defragmentation to impact a target, it is abused and used in GRE Flood attacks.  

BIG-IP AFM rules can recognize GRE traffic and limit it to intended end points, and they can be configured to allow GRE traffic to intended end points or drop unwanted GRE Flood traffic. 

Environment

  • BIG-IP AFM module is licensed and provisioned

Cause

You suspect your BIG-IP system is receiving a GRE Flood attack.

Recommended Actions

You can configure an AFM rule in an existing AFM network firewall policy to drop GRE Flood traffic. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Navigate to Security > Network Firewall > Active Rules.
  3. Click Add Rule.
  4. For Name, enter the name of the AFM Rule.
  5. For Order, specify a position of the rule, Last, Before.. or After.. (an existing in rule in the policy), or First.
  6. For Protocol, under Other Protocols, select GRE.
  7. For Source, specify a Source IP Address - a single IP, Address Range or List  or Country/Region, then click Add. A VLAN or tunnel can also be specified. 
  8. For Destination, specify a Destination IP Address or Country/Region.    
  9. Set Action to Drop.    
  10. Set Logging to Disabled.
  11. Click Finished.
  12. Verify that the created AFM rule Count column value is incrementing.
  13. Navigate to Security > Network Firewall > Active Rules.
  14. Verify that the created AFM rule Count column value is incrementing. Review the Count column value for the created AFM Rule for dropping GRE Flood traffic. When the rule matches the traffic, the Count value increases.

Additional Information

If you're expecting GRE traffic from certain IP addresses, create a specific AFM rule for these known GRE traffic sources to allow it. Create a general GRE traffic Drop AFM rule for the unexpected GRE traffic. Take note of the AFM policy context where the GRE Traffic Drop rule will be created. To prevent further processing of the GRE traffic on other AFM Policy Context, create the GRE Traffic Drop AFM Rule in the Global Context Policy.

The Network Firewall uses the same three context settings as IP Intelligence: global, route domain, and virtual server. In each context, the IP Intelligence packet handling occurs first, followed by the Network Firewall handling. For more information, refer to K31591013: BIG-IP AFM operations guide | Chapter 2: Packet flow.
