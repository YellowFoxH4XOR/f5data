Description

Unable to delete an http monitor using the Configuration Utility (GUI) or tmsh


Environment

BIG-IP

Cause

Unknown

Recommended Actions

*NOTE* This procedure requires you to reload the configuration which will cause a disruption to traffic


You can manually delete the monitor by editing the bigip.conf configuration file and removing the object:


1. Backup the file first with the command "cp /config/bigip.conf /config/bigip.conf_backup"


2. Edit the configuration file with your preferred text editor like vi or nano with "vi /config/bigip.conf" or "nano /config/bigip.conf"


3. Find the pool(s) that have the monitor assigned to them, here are examples from the file"


ltm pool /Common/HTTPS_Pool {

members {

/Common/Node_1:443 {

address 192.168.100.33

}

}

monitor /Common/custom_monitor <--------------

}


Manually change the custom_monitor to a default monitor like /Common/tcp_half_open


4. Delete the custom_monitor object, here is an example:


ltm monitor tcp /Common/custom_monitor {

adaptive disabled

defaults-from /Common/tcp

destination *.44425

interval 5

ip-dscp 0

recv none

recv-disable none

send none

time-until-up 0

timeout 16

}


5. Save the file and reload the configuration with the command "tmsh load sys config"
