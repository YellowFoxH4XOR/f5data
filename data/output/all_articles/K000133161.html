Description

User is unable to browse internet sites using different user in Chrome, while connected to the F5 VPN. User logs into to Chrome with 'Run as different user' and uses different user credentials than the one used to authenticate to the F5 VPN. When internet sites are browsed they are not reachable. There is a proxy in the environment.

 Environment

  • BIG-IP APM
  • Network Access
  • Proxy

 Cause

This is currently not supported. Registry is modified only for current user profile.

 Recommended Actions

None

None
