Known Issue

Stream Control Transmission Protocol (SCTP) custom profile configurations may cause the Traffic Management Microkernel (TMM) service to produce a core file and restart.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a virtual server that uses a custom SCTP profile.
  • The custom SCTP profile's Transmit Chunks and/or Receive Chunks settings are not within the valid range of 1 through 65535.

    Note: The default value for the Transmit Chunks and Receive Chunks settings is 256.

  • The virtual server attempts to process SCTP traffic.

Impact

The BIG-IP system temporarily fails to process traffic while the TMM process restarts. If the BIG-IP system is configured for high availability (HA), it fails over to a peer system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • TMM generates a core file in the /shared/core directory.
  • Your BIG-IP system logs a SIGSEGV to the /var/log/tmm file at the time TMM produces a core file and restarts.
  • In the /var/log/tmm file, you observe log messages similar to the following example:

    notice ** SIGABRT **
    notice ** SIGFPE **

  • If you set the affected SCTP profile to a value within the valid range of 1 through 65535, the issue does not occur.

Workaround

To work around this issue, ensure that the custom SCTP profile Transmit Chunks and Receive Chunks settings are within the valid range of 1 through 65535. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > SCTP.
  3. Select the affected profile.
  4. For the Transmit Chunks setting in the associated text box, enter a value within the valid range of 1 through 65535.
  5. For the Receive Chunks setting in the associated text box, enter a value within the valid range of 1 through 65535.
  6. Click Finished.
