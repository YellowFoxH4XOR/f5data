Description

iApp failing to Reconfigure/Delete configuration elements
See Additional Information for examples of missing and good iApp configuration elements

Environment

  • Any BIG-IP supported version
  • iApp deployed

Cause

Missing app-service <iapp_path> configuration line in any of the iApp created elements can trigger the failure.

Recommended Actions

Update the iApp configuration elements in the bigip.conf to include the missing app-service <iapp_path> information:

Important:  F5 Support recommends completing the following procedure during a scheduled maintenance window.
  1. Create a UCS archive of the BIG-IP configuration:
    K13132: Backing up and restoring BIG-IP configuration files with a UCS archive
  2. Check the config elements created by the iApp template for any missing app-service <iapp_path>
  3. At the BIG-IP command line, use a text editor to edit the bigip.conf and add the missing app-service lines
  4. Load the configuration with command:

    tmsh load sys config

  5. Make sure the app-service is now present in the running config itself

    tmsh list ltm <configuration_object> /Common/<App_name>.app/<configuration_object_name>

    For example:

    tmsh list ltm pool /Common/Example.app/Example_pool

       Note: you should see the app-service lines after the object names

Additional Information

App-service information missing from configuration:

ltm pool /Common/Example.app/Example_adfs_pool {
    load-balancing-mode least-connections-member      <<<<---- app-service line is missing
    members {
...
ltm virtual /Common/Example.app/Example_adfs_vs {
    destination /Common/192.0.2.1:443      <<<<---- app-service line is missing
    ip-protocol tcp
    mask 255.255.255.255

App-service information present in configuration:

ltm pool /Common/Example.app/Example_adfs_pool {
    app-service /Common/Example.app/Example      <<<<---- Line is properly set
    load-balancing-mode least-connections-member
    members {
...
ltm virtual /Common/Example.app/Example_adfs_vs {
    app-service /Common/Example.app/Example      <<<<---- Line is properly set
    destination /Common/192.0.2.1:443
    ip-protocol tcp
    mask 255.255.255.255
