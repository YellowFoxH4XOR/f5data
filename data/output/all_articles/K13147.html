Known Issue

The BIG-IP Edge Client for iOS fails to connect on devices running Apple iOS 5.

This issue occurs when all of the following conditions are met:

  • You are connecting with an Apple iOS device that is running iOS 5.
  • The BIG-IP APM or Edge Gateway client SSL profile is configured to request or require a client certificate in the client SSL profile.

This issue occurs because the SSL negotiation between the Apple iOS device and the BIG-IP SSL profile is causing a server reset when the SSL cipher is TLS v1.2.

Impact

Apple iOS devices running iOS 5 cannot connect to BIG-IP APM or BIG-IP Edge Gateway using the BIG-IP Edge Client.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • Apple iOS devices connecting to BIG-IP APM or BIG-IP Edge Gateway display an error message that appears similar to the following example:

    Server rejected the supplied client certificate or one was not sent

  • When the SSL logging level is set to debug, the system logs an error message that appears similar to the following example in the /var/log/ltm file:

    tmm debug tmm[<PID>]: 01260009:7: Connection error: ssl_hs_rx_certvfy:1426: unsupported signature algorithm (47)

    In this error message, note the following:

    • <PID> is the process ID
