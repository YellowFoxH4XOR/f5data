Topic

When you apply a Kerberos delegation profile to a virtual server, it is best practice to also apply a Client SSL profile. The Kerberos delegation feature includes a set-cookie operation, making the cookie valuable if intercepted. To ensure that an attacker cannot intercept the set-cookie HTTP header, use a Client SSL profile in conjunction with the Kerberos delegation profile.

For information about configuring a Client SSL profile, refer to the Managing SSL Traffic chapter of the Configuration Guide for BIG-IP Local Traffic Manager.

For information about configuring Kerberos delegation, refer to the Configuring Kerberos Delegation chapter of the BIG-IP Local Traffic Manager: Implementations guide.
