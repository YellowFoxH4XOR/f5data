Description

  • Unable to login to BIG-IP using Putty.
  • This symptom does not occur consistently. 

Environment

  • Putty v0.71

Cause

Unknown at time of publication.

Recommended Actions

  1. In Putty, go to section Connection > SSH > Auth > GSSAPI
  2. Disable the option Attempt GSSAPI authentication (SSH-2 only)

Additional Information

None.
