Description

Web application getting ERR_TOO_MANY_REDIRECTS error when using CloudFlare with BIG-IP SSL offloading. Pool members redirect the http request with "X-Forwarded-Proto: https" header back to http with the same URI.

 

Environment

  • SSL offloading
  • CloudFlare
  • HTTP
  • x-forwarded-proto

Cause

CloudFlare insert "X-Forwarded-Proto: https" header

 

Recommended Actions

Remove "X-Forwarded-Proto" header with an iRule

Example:

when HTTP_REQUEST { HTTP::header remove "X-Forwarded-Proto" }

None
