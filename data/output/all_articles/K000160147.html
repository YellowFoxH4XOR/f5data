K000160147: Restoring Missing CPU and Memory Statistics on BIG-IP LTM

Source

Description

CPU and memory statistics are missing from the BIG-IP system and QKView diagnostic files. Commands such as tmsh show sys cpu, tmsh show sys memory, and tmsh show sys tmm-info return empty or zero values, preventing effective performance monitoring and troubleshooting.

 

Environment

  • BIG-IP 
  • Missing resources statistics

 

Cause

Unknown at time of publication.

 

Recommended Actions

To restore CPU and memory statistics collection, perform the following steps during a maintenance window:

  1. Stop the statsd service:
    • bigstart stop statsd
  2. List files in /var/rrd/ to identify statistics files:
    • ls /var/rrd/
  3. Remove corrupted or incomplete statistics files (examples below, adjust as needed for your environment):
    • rm -rf /var/rrd/blade0cpu
    • rm -rf /var/rrd/access
  4. Start the statsd service:
    • bigstart start statsd
  5. Reboot the device.
