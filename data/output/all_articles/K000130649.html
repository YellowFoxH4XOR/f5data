Description

When you assign one iRule to one of your Virtual Servers, and that iRule contains a Global Variable sharing name with another iRule, you may experience iRule execution (reject command) resets for your Virtual Servers.


Environment

  • BIG-IP LTM
  • Global variable in iRules

Cause

The Global variable static name is shared between iRules with a different value.


Recommended Actions

Avoid using global variables in iRules if it is not strictly required.

If a global variable is required for your deployment, do not place the same global variable name in different iRules with different values.

None.
