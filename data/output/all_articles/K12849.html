Known Issue

In BIG-IP WebAccelerator version 10.2.1 HF1, the BIG-IP system may dereference a null pointer, causing the pvac process to core.

This issue occurs when the following condition is met:

  • WebAccelerator version 10.2.1 HF1 is installed

Impact

The pvac daemon restarts, dumps core, and the BIG-IP WebAccelerator virtual server may temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The pvac process dumps core, creating files that are named similarly to the following examples in the /var/core/ directory:

    pvac.bld473.0.core.25869.gz

  • The system may write log entries that appear similar to the following example to the /var/log/wa/pvac.log file:

    debug WA Debug ( 9198): * File: PvAccelerator.cxx, Line: 2001
