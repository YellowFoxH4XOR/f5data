K26036428: Error when accessing the applications tab on BIG-IQ

Type
Support Solution
Published
2021-02-03
Updated
2025-04-01
Applies to
  • BIG-IQ
Source

Description

When accessing the Applications tab in BIG-IQ following errors may be noted in the GUI
System Unavailable
Number of Errors: 2
The system returned an unexpected error (500 Server Error). Connection refused.

Environment

  • BIG-IQ Centralized Management(CM)
  • GUI
  • BIG-IQ DCD

Cause

Connectivity issues between BIG-IQ cluster members could cause this issue.

Recommended Actions

  1. Check the cluster status using below command from BIG-IQ CM bash.
    # curl -s localhost:9200/_cluster/health?pretty
    Note: In below output, cluster status is red because there are lot of unassigned primary shards in cluster.
     "cluster_name" : "63c5c366-dfea-408d-b23d-cf5829227539",
     "status" : "red",  
     "timed_out" : false
      "number_of_nodes" : 4,
     "number_of_data_nodes" : 3,
     "active_primary_shards" : 3486,
     "active_shards" : 6972,
     "relocating_shards" : 0,
     "initializing_shards" : 0,
      "unassigned_shards" : 58,   

    OR in BIG-IQ v8:
    curl -su admin: -k "https://localhost:9200/_cat/health?pretty"
     
  2. Check the connectivity between CM and DCD vice-versa listening on TCP 9300. If successful proceed to Step 3. If connectivity is not successful investigate the connectivity issue between CM and DCD.
  3. Remove  DCD association from BIG-IQ Centralized Management as discussed in K02014651.

    Note: Before removing DCD association, perform UCS backup of CM, DCDs and download to local workstation. 
    Navigate to System--->BIGIQ Data Collection Device---->Click on each DCD  and perform screen capture. This settings are required to revert after performing step 3.
