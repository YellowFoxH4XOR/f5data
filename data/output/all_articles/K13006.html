Known Issue

Description

Android Edge Portal app users receive a 'session expired' message and the session immediately terminates after they log in to a BIG-IP APM system that is configured to require a client certificate. This is a result of the Android OS browser not properly handling client certificate requests.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured to require a client certificate
  • User is using the Android Edge Portal app
  • The Android Edge Portal app is configured with a client certificate

Impact

Android Edge Portal users are unable to view resources through the BIG-IP APM system.

Symptoms

As a result of this issue, the user may encounter the following symptoms:

  • User receives a 'Session expired' message on the Android device
  • Session immediately terminates after the user logs in

Workaround

To work around this issue, you can disable the BIG-IP request for a client certificate. To do so, perform the following procedure:

Impact of workaround: Disabling the client certificate request bypasses two-factor authentication, thus eliminating the requirement for the client to present a valid certificate.

  1. Log in to the BIG-IP Configuration utility.
  2. Click Local Traffic.

    The Local Traffic navigation panel expands.
  3. Click Virtual Servers.

    The list of configured virtual servers displays in the right pane.
  4. Click the name of the virtual server.

    The virtual server properties display in the right pane.

    Note the name of the SSL Profile (Client) that is assigned to this virtual server.
  5. Click the Profiles under the Local Traffic navigation pane.
  6. Mouse over the SSL tab.

    The SSL menu displays below the SSL tab.
  7. Click Client.

    The list of configured SSL Client profiles is displayed.
  8. Click the name of the SSL Client profile you noted in Step 2.
  9. Navigate to the Client Authentication section.
  10. Select ignore from the Client Certificate drop-down menu.
  11. Click Update.
