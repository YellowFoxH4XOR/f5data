K23317100: TMM on BIG-IP PEM is constantly crashing

Type
Support Solution
Published
2022-04-06
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP PEM: 15.1.X, 15.1.8, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.1.7
  • BIG-IP LTM: 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.1, 15.1.0, 15.1.X
Source
https://my.f5.com/manage/s/article/K23317100

Description

  • This article intend to solve a tmm crashing in BIG-IP PEM

Environment

  • BIG-IP PEM
  • Setting pem session custom attribute value with length more than (1024- attribute name length)
Cause
  • This is caused due to ID1089829 PEM A112 15.1.5.0.69.10 - Constant SIGSEGV cores on both peers

Recommended Actions

  • In the iRule, make sure the custom attribute value size + custom attribute name length is not more than 1024.
