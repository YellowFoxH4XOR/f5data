K71206522: BIG-IP APM only supports the default route domain when configuring SecurID AAA servers

Topic

You must configure SecurID AAA servers in the default route domain, which has the ID 0. The BIG-IP APM system does not support other route domains.

Description

The BIG-IP APM system always uses route domain 0 to connect to the RSA SecurID servers for authentication, regardless of the configured route domain. When the Agent Host IP address for the SecurID AAA server is configured in a route domain other than 0, the BIG-IP APM system cannot connect to the RSA SecurID servers.

Recommendations

To configure the BIG-IP APM system to authenticate with RSA SecurID servers using route domains, choose one of the following options:

  • Configure a SecurID AAA server using the default route domain.
  • Configure a Remote Authentication Dial-In User Service (RADIUS) AAA server using a route domain other than the default, and use the RADIUS protocol with the RSA SecurID servers.

    Note: RSA Adaptive Authentication (AA) does not function with the RADIUS protocol.
