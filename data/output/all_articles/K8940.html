Known Issue

The BIG-IP system processes traffic for virtual servers after disabling the virtual address.

This issue occurs when the following condition is met:

  • You disable the virtual address for one or more virtual servers.

A virtual address is defined as the IP address with which you associate one or more virtual servers. A virtual server is represented by an IP address and a service.

For example, if you define virtual servers of 10.10.10.2:80, and 10.10.10.2:443 on the BIG-IP system, then 10.10.10.2 is the virtual address. If you disable the virtual address of 10.10.10.2, the BIG-IP system continues to process traffic for the virtual servers.

Impact

The BIG-IP system may process traffic that you expect to be disabled.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system continues to process traffic for virtual servers after disabling the related virtual address.

Workaround

To work around this issue, you can disable the virtual servers. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Select the check box next to the virtual servers that you want to disable.
  4. Click Disable.
