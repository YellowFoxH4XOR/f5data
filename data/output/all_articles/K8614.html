K8614: Portal Access does not support cookies that persist across FirePass sessions

Topic

Certain web applications require information to be stored in cookies that are kept on a user's browser for long periods of time. For example, the information in a cookie can be used to tailor the appearance of an initial login page, or keep the state of a user's application so that the user can log out of the application and return to the same point in the application at a later time.

The FirePass Portal Access feature can either manage cookies for browser clients, eliminating the storage of the cookie on the client, or pass cookies from web server to browser client, with modifications. Modifications to cookies are required to work in a reverse proxy scenario, where the client must issue requests for URLs that use the URLs of the FirePass controller, rather than the actual server. The cookie's Domain field is changed from the name of the issuing server to the name of the FirePass controller. The Path field is also modified to /.  The cookie name is also modified to enable the FirePass controller to track and de-multiplex the cookies.

By default, all three versions of the Web Application engine (for software version 6.0.2, this is the current version plus Compatibility Modes 1 and 2) store cookies on the FirePass controller. However, the FirePass controller can be configured to pass cookies to the client's browser. In either case, the user's cookies are deleted at the end of their FirePass session. When passed to the browser, cookies are modified with FirePass session-specific information, and are normally deleted when the user's FirePass session is terminated. Even if cookies were to be retained somehow, on the client side, the session-specific information would cause them to be invalid for subsequent FirePass logons.

Note:  The Do not block cookies at FirePass 4100, pass them to the browser for specified URL patterns check box is used to configure the FirePass controller to pass cookies back to the client browser. The check box is located in the Web Applications Global Settings section on the Portal Access: Content Processing page's Global Settings tab.

Because the FirePass maintains cookies on a per-session basis, a cookie cannot be maintained on the client's browser across FirePass sessions. Applications that need to maintain cookies across sessions should be accessed using an Application Tunnel favorite or a Network Access favorite.
