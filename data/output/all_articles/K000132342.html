Description

100% CPU utilization for two or more days on Standalone BIG-IP

Environment

  • STANDALONE BIG-IP
  • HIGH CPU

Cause

   The SNMPD proces uses almost 100% of the CPU

Recommended Actions

1. Run the following command from bash to confirm that SNMPD take 100% or more of CPU, find the PID number of the process which take the most CPU and copy it:

top -cb -n 2 -d 1.0

3. Restart the snmpd process

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

a) Log in to the Traffic Management Shell (tmsh) by typing the following command:

tmsh

b) Restart the snmpd process by typing the following command:

restart sys service snmpd
