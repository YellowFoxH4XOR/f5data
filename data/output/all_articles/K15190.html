Known Issue

BIG-IP GTM virtual server auto-discovery may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP GTM system is configured to automatically discover virtual servers.
  • The BIG-IP LTM system is configured as a Dynamic Host Configuration Protocol (DHCP) relay agent. For example, the BIG-IP LTM configuration contains a virtual server type of DHCP Relay using IPv4 address 255.255.255.255 or IPv6 address ff02::1:2.

Impact

The BIG-IP GTM system does not automatically discover BIG-IP LTM virtual servers.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H457539 on the Diagnostics > Identified > Medium screen.
  • In the /var/log/ltm file, you observe error messages similar to the following example:

    err mcpd[<pid>]: 01020060:3: IP Address 255.255.255.255 is invalid, must not be all ones.

  • The BIG-IP GTM system does not automatically discover virtual servers on a BIG-IP LTM system that is also configured as a DHCP relay.
