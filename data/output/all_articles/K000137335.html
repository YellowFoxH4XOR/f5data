Description

Since BIG-IP v16.1.4, v15.1.10 users may get prompted with a "Network Access" popup window as below when the connections are initiated from a browser:

 

Environment

  • APM (v15.1.10,v16.1.4,v17.1.0.2) or higher version
  • Resource Assignment (Network Access + Webtop)
  • Browser initiated login

 

Cause

This is an expected behaviour; this popup was introduced to fix the bug ID 1039941.

 

Recommended Actions

There's no workaround, as the popup was introduced to overcome a browser restriction.. Refer to ID 1039941 for more information.

 

Additional Information

This behavior change is not because of F5-oriented program but browser's behavior change in handling the custom protocol tied in with the Endpoint Inspector browser component.

When the user starts Network Access via the web browser, the browser needs to recognize the custom protocol (such as: f5-vpn://<URL>) and run f5vpn.exe, the browser-based VPN components. However, the browser does not allow it without user interaction even if it has been already installed.

It is because of the security reason introduced by the browser in order to prevent the computer from running "malicious" program / application automatically. Instead, the browser asks for permission to open the program / application, and then prompts you to confirm that you want to handle the protocol and the app you’d like to use for it. If you give permission, then the selected application opens with the specified content.
