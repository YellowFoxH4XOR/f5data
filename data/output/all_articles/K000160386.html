K000160386: SNMP IF-MIB::ifDescr walk fails due to non-ASCII characters in interface, LAGV or LAN description on F5OS host

Type
Support Solution
Published
2026-03-18
Updated

Applies to

  • F5OS-C: 1.8.0, 1.8.X, 1.8.2, 1.8.1

Source
https://my.f5.com/manage/s/article/K000160386

Description

SNMP monitoring of physical interfaces using IF-MIB::ifTable fails with errors when a VLAN name description contains non-ASCII characters. Error messages in the devel.log file include:

devel-snmpa value of type 'DisplayString' contains non-ascii characters

These errors occur when SNMP queries encounter an interface, LAG or VLAN description with non-ASCII characters, causing the SNMP agent to return errors and incomplete data. Example of non-ASCII character is "é".

Environment

  • F5OS 
  • SNMP
  • Interface description contains non-ASCII character(s)
  • LAG description contains non-ASCII character(s)
  • VLAN description contains non-ASCII character(s)

Cause

Interface, LAG, VLAN description contains non-ASCII characters, which are not supported for SNMP DisplayString fields such as ifDescr.

Answer/Recommended Actions

Rename the VLAN to use only ASCII characters as per K000135655

Additional Information

F5OS supports only ASCII characters for interface, VLAN, and LAG description. Non-ASCII characters (such as accented letters) are not supported and will cause SNMP errors. This restriction applies to all F5OS platforms and is necessary for SNMP compatibility.
