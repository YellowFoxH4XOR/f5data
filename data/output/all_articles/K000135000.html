Description

After creating a route domain on one of the HA unit, and assigning a partition to that route domain, HA units cannot be synced.

Output from show /cm sync-status

SYNC_GROUP (Sync Failed): A validation error occurred while syncing to a remote device

Sync error on LTM1.example.com: Load failed from /Common/LTM2.example.com 0107097f:3: The specified route domain (1) exists in a partition (PARTITION_A) different from the specified partition (PARTITION_B).

Environment

  • BIG IP-LTM
  • Route domain created only on one of the HA device or assigned to different partition

Cause

Route domain or partition assigned to route domain mismatch between HA peers.

Recommended Actions

Compare the bigip_base.conf for all partitions on both devices.

Assign the partitions to the same route domains on both HA units.

For example:

bigip_base.conf: route-domain assignment are mismatched

HA Active:

auth partition PARTITION_A {
default-route-domain 1
}
auth partition PARTITION_B {
default-route-domain 2
}

HA Standby:

auth partition PARTITION_A {
default-route-domain 2
}
auth partition PARTITION_B {
default-route-domain 1
}
