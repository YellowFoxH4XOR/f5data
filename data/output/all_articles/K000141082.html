Description

After upgrading to or installing BIG-IP v17.0.0 or later, the SSRF (Server-Side Request Forgery) protection hosts list in an ASM policy is pre-populated with default host entries, with actions set to Deny or Resolve.

Environment

  • ASM 17.0.0 or later

Cause

This is a change implemented starting in TMOS v17.0.0.

Recommended Actions

No action is required by default. Users may review the SSRF host entries and modify their actions, or add/remove entries based on their web security requirements.

GUI path:

Security ›› Application Security : Security Policies : Policies List

Select the affected policy, then go to:

Advanced Protection >> SSRF Protection

Review the entries under SSRF Hosts. 

Note: For the "Resolve" action, which is the default action for wildcard hostname entries, a properly configured DNS server is required on the BIG-IP system. Otherwise, traffic may be delayed in the ASM engine if DNS resolution cannot be completed in time. Refer to K000157199 for further information.
