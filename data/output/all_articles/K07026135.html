Known Issue

Restarting the bcm56xxd process may cause the BIG-IP system to unexpectedly revert the flow control setting to the default value of none.

This issue occurs when all of the following conditions are met:

  • You are running on one of the following BIG-IP platforms:
    • BIG-IP 10000 series appliances
    • BIG-IP 12000 series appliances
    • VIPRION B4300 series blades
    • VIPRION B2250 blades
  • You are using a Copper SFP module on the affected BIG-IP platform.
  • You configure the flow control setting of the network interface populated by the Copper SFP module with a non-default value (for example, rx, tx, or tx-rx).
  • You either manually restart the bcm56xxd process or it restarts unexpectedly.

Impact

The affected network interface on the BIG-IP system may be erroneously configured with an incorrect flow control setting. As a result, the network traffic passing through the network interface may be degraded.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to change the flow control setting (for example, to tx-rx) on the affected network interface, the desired flow control setting may not apply to the network interface correctly. Although the Traffic Management Shell (tmsh) command lists the flow control setting of the network interface accordingly, the flow control setting does not actually take effect.

    For example, the tmsh list command and output may appear similar to the following example:

    tmsh list /net interface 1.1 flow-control

    net interface 1.1 {
        flow-control tx-rx
    }

    However, the tmsh show command output reports the status of the flow control as none instead of tx-rx, and it may appear similar to the following example:

    tmsh show /net interface 1.1 all-properties field-fmt|grep pause-active

    pause-active none

Workaround

To work around this issue, you can use the tmsh utility to reconfigure the flow control of the affected network interface by setting the value to none and then back to the desired setting when restarting the bcm56xxd process. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Set the flow control of the affected network interface (for example, interface 1.1) to none by typing the following command:

    modify /net interface 1.1 flow-control none

  3. Set the flow control of the affected network interface to the desired setting (for example, tx-rx) by typing the following command:

    modify /net interface 1.1 flow-control tx-rx

  4. Save the configuration by typing the following command:

    save /sys config
