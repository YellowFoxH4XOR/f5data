Known Issue

This is the result of a known issue. The Perform additional client certificate check against Active Directory attribute feature was introduced in FirePass version 6.0.0. This feature appears as an option on the Authentication tab of a Master Group when Client Certificate Passwordless Authentication is the selected authentication method for that Master Group. If all of the following conditions are met, users who belong to the Master Group receive a blank Webtop when they log on to FirePass:
  • The Client certificate subject field used for comparison field is set to Client certificate ext subjectAltName field (regex extraction)
  • The Perform additional client certificate check against Active Directory attribute option is selected

F5 Networks Product Development tracked this issue as CR74298, and it was fixed in FirePass version 6.0.1. For information about upgrading, refer to the FirePass Release Notes.

Additionally, a hotfix has been issued for FirePass version 6.0.0. This issue was fixed in cumulative hotfix 600-11. You may download this hotfix or a later version of the cumulative hotfixes from the F5 Networks Downloads site.

For instructions about how to obtain a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
