You can enable or disable packet filter logging on a per-rule basis. If logging has been enabled, you may view the logs by going to the Reports: System Logs page. The logs appear similar to the following example:

Nov 6 14:37:56 Packet Filter GlobalFilter:New_Rule SRC=192.168.192.13 DST=192.168.160.180 LEN=56  TOS=0x00 PREC=0x00 TTL=127 ID=52615 PROTO=UDP SPT=53888 DPT=53 LEN=36  
Nov 6 14:37:55 Packet Filter GlobalFilter:New_Rule SRC=192.168.192.13 DST=192.168.160.180 LEN=56  TOS=0x00 PREC=0x00 TTL=127 ID=52611 PROTO=UDP SPT=32622 DPT=53 LEN=36  
Nov 6 14:37:55 Packet Filter GlobalFilter:New_Rule SRC=192.168.192.13 DST=192.168.160.182 LEN=61  TOS=0x00 PREC=0x00 TTL=127 ID=52599 PROTO=UDP SPT=58754 DPT=53 LEN=41  

All packet filter logs include the type of filter applied, name of the rule, source IP address, destination IP address, and protocol.

The logging level for packet filter logs is inherited from the configuration that is set in Device Management: Maintenance: Logs: Logging Options: Packet Filter. To change the type of logs for packet filters, change the drop-down menu to the appropriate logging level, and click Apply Changes.

F5 recommends that you do not always leave logging on, because the packet filter logs may create a large number of logs.

To enable or disable logging for an individual rule, perform the following procedure:

  1. From the Administrative Console, navigate to the rule you want to change.

    Note: For more information about where to find the rules, refer to K10747: Configuring packet filters.

  2. Click the Edit button next to the rule.
  3. Select or clear the Log All Matches check box.
  4. Click Save.
  5. Click the Apply these rules now button.
