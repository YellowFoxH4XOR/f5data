Description

You may observe the following symptoms:

  • Microsoft Outlook client displays an alert as below:

Allow this website to configure user1@test.com server settings?
https://mail.test.com/autodiscover/autodiscover.xml
Your account was redirected to this website for settings.
You should only allow settings from sources you know and trust.

  • Outlook client connects to exchange server through a BIG-IP virtual server. 
  • An iRule redirects HTTP service to HTTPS service on this virtual server.

Environment

  • Exchange server
  • Outlook client
  • iRule

Cause

When Microsoft Outlook redirects an AutoDiscover operation from HTTP to HTTPS, you may receive such a warning message. This is by design on Microsoft Outlook. 

Recommended Actions

You may check this behavior on your Outlook client by referring to:
How to suppress the AutoDiscover redirect warning in Outlook
