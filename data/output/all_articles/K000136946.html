Topic

You should consider using this procedure under the following conditions:

  • You want to verify the proper operation of your BIG-IP Next Central Manager by uploading a QKView file to F5 iHealth .
  • You want to provide a QKView file to F5 Support to aid in troubleshooting an issue with a BIG-IP Next Central Manager. 

Description

You can generate a QKView diagnostic file for the BIG-IP Next Central Manager to collect diagnostic information about the system. The QKView can then be uploaded to iHealth for inspection.

The QKView diagnostic file contains machine-readable (XML) diagnostic data which is combined into a single compressed Tape ARchive (TAR) format file. You can upload this file, called a QKView file, to F5 iHealth , or give it to F5 Support to help them troubleshoot any issues.

Note: F5 Support requires a QKView file in all cases in which remote access to the product is not available.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have administrative access to BIG-IP Next Central Manager command line.

Procedures

  • Generate a QKView file
  • Upload to iHealth

Generate a QKView file

To generate a QKView diagnostic file for the BIG-IP Next Central Manager, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Next Central Manager command line as admin.
  2. To generate a QKView diagnostic file, enter the following command:

    /opt/cm-bundle/cm qkview

    If successful, the command output will appear similar to the following example:

    info: Final QKView archive saved at /opt/cm-qkview/qkview.20230921-191511.tgz

  3. Copy the QKView file off the BIG-IP Next Central Manager to your workstation using the following syntax:

    scp /opt/cm-qkview/<qkview_filename> <user>@<workstation_ip>:<path_to_file>

    For example:

    scp /opt/cm-qkview/qkview.20230921-191511.tgz user@10.10.11.100:/var/tmp/qkview.20230921-191511.tgz

Upload to iHealth

To upload the QKView diagnostic file to F5 iHealth, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Open a web browser and log in to the F5 iHealth site.
  2. Select Upload.
  3. Select Choose.
  4. Go to the QKView file on your local system.
  5. Enter the F5 Support Case number.
  6. Enter a Description for the QKView.
  7. Select Upload QKView(s).
