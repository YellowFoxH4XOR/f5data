Known Issue

The SharePoint 2013 homepage may fail to render through the BIG-IP APM system.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured for portal access.
  • Users access the SharePoint 2013 homepage using Internet Explorer 11.

Impact

Users are unable to access SharePoint 2013 content.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users receive an error message that appears similar to the following example:

    SCRIPT5009: 'F5_r2u' is undefined
    File: script block (65), Line: 1 , Column: 144
