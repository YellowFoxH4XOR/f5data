Issue

Beginning in ARX 5.1.0, the policy-simple-age-fileset and simple-age-fileset commands have been renamed to policy-age-fileset and age-fileset. Additionally, the mode specific from command option has been removed from the policy-age-fileset and age-fileset commands. However, the from command option is available from the union-fileset and intersection-fileset command modes.

For information about the policy-age-fileset, age-fileset, union-fileset or intersection-fileset commands, refer to the ARX CLI Reference Guide or the ARX CLI Storage-Management Guide.

Note: The 5.1.0 ARX CLI Reference incorrectly indicates the from fileset command is an available option for age-based filesets. For information, refer to K11357: Documentation Erratum: The version 5.1.0 ARX CLI Reference Guide incorrectly indicates the from fileset command as an available option when using an age-based fileset.
