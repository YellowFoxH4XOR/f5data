Known Issue

Under rare conditions, congestion on the MPI channel may cause the TMM process to produce a core file.

This issue occurs when the following condition is met:

  • The BIG-IP system is experiencing low memory conditions.

Impact

The TMM may restart and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails over to another system in the device group.
  • The TMM generates a core file in the /var/core directory.
  • The system generates an SIGSEGV fault to the /var/log/tmm file.
