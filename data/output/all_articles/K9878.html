K9878: Imports may not be accessible for an NFS share on a Windows 2003 server using Windows Services for UNIX (SFU)

Topic

Windows 2003 server with Windows Services for UNIX (SFU) has not yet been qualified by the current ARX versions as a supported NFS filer. Imports may not be accessible for an NFS share on a Windows 2003 server using Windows SFU.
