Known Issue

The BIG-IP system may erroneously cache path maximum transmission units (MTUs) that are lower than the configured minimum path MTU.

This issue occurs when all of the following conditions are met:

  • A client responds with an ICMP type 3 code 4 (ICMP Fragmentation Needed) message with an MTU that is lower than the configured value of the TM.MinPathMTU database variable.

    Note: The default value of TM.MinPathMTU is 296.

By default, Path MTU is cached in the route metric for a connection, and the route metric has a lifetime of 600 seconds. The BIG-IP system may use and enforce the cached Path MTU for the affected connection.

Impact

If the connection endpoint is a shared NAT address, other clients behind the endpoint may be adversely affected.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Clients behind the affected endpoint may experience degraded performance.
  • If you perform packet captures of the affected traffic, you may observe multiple ICMP Fragmentation Needed messages with an MTU lower than TM.MinPathMTU database variable.
