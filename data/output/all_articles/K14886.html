In versions prior to BIG-IP 11.4.0, the BIG-IP Edge Gateway system allowed an administrator to provision the following BIG-IP modules:

  • BIG-IP Access Policy Manager (APM)
  • BIG-IP WebAccelerator (WAM)
  • BIG-IP WAN Optimization Manager (WOM)

With the End of Sale announcement for BIG-IP Edge Gateway, the previously described module combination is no longer available after you upgrade to 11.4.0 or later versions.

The BIG-IP 11.4.0 release integrates the WAM and WOM modules into the Application Acceleration Manager (AAM) module. When licensed, you can provision this functionality by configuring the AAM settings on the Resource Provisioning screen of the Configuration utility.

Users that upgrade from earlier versions can only provision BIG-IP APM and AAM. Please review the BIG-IP LTM and TMOS 11.4.0 release notes to understand any hardware exceptions when you provision AAM on supported platforms with 8 GB or less.
