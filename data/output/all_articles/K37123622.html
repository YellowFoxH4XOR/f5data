Description
Client platform is reported as "windows" causing client OS checker to take fallback branch, instead of specific version of Windows. 

For Example:

  • Your APM policy is configured with a Client OS check with an expression defined similar to this: 
    expression "expr {[mcget {session.client.platform}] == \"Win7\" || [mcget {session.client.platform}] == \"Win10\"}"

  • APM debug logs shows the session.client.platform variable set to "Windows", for example:
    01490007:6: <Policy name>:<Session ID>: Session variable 'session.client.platform' set to 'Windows'

Environment

  • BIG-IP APM
  • Windows 10
  • F5 Access for Windows 10

Cause
F5 Product Development is tracking this issue as ID 586684

Recommended Actions

As a workaround, modify the default OS checker to use the "Windows" platform ( [mcget {session.client.platform}] == "Windows"} )
To detect session variable correctly as Windows 10, update version  ( [mcget {session.client.platform_version}] == "10" ).
