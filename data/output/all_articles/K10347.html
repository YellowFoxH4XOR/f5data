Known Issue

This is the result of a known issue. When configuring an LACP trunk, the BIG-IP system may set the LACP actor key to a value of 0 (zero).

Note: The actor key is not a configurable setting when configuring a LACP trunk. The actor key value assigned is the trunk ID, and trunk ID is assigned sequentially beginning with zero for the first trunk created.

In most cases, an actor key value of zero does not result in any communication disruption on the trunk; however, it is not strictly compliant with the IEEE802.3ad-2000 standard. Peer devices may refuse the actor key, log related error messages, and fail to render the link.

Note: This issue has been reported to only affect Alcatel routers. No other devices have been reported to be affected.

You can display the actor key assigned to an LACP trunk by typing the following command at the BIG-IP command line, replacing <trunk_name> with the configured name of the trunk object:

bigpipe trunk <trunk_name> lacp show

Output will appear similar to the following example:

TRUNK t1 - LACP: enable active short timeout| Actor: SysID 00:01:D7:20:F7:00 Priority 63232 Key 1| Partner: SysID 00:01:D7:00:92:05 Priority 37381 Key 1+-> INTERFACE 1.8 Aggregation attached| Actor: PortID 1080108 Key 1 up| Partner: PortID 1080108 Key 1 up

F5 Product Development tracked this issue as CR120975 and it was fixed in BIG-IP versions 9.4.8 and 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, and WOM release notes.

Additionally, a hotfix has been issued for BIG-IP versions 9.3.1 and 9.4.7. Customers affected by this issue should contact F5 Technical Support, referencing this Solution number and the associated CR number, to request the hotfix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
