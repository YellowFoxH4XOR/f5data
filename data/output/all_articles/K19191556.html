Description

When BIG-IP boots UP, it will use hardware time first and then software time. If there is a big offset between these 2 times, it can be confusing as system switches between 2 times. For example, log messages may not be in chronological order.

Hardware clock is maintained by CMOS battery on the mother board. For more information, refer to K2848: Batteries included in F5 hardware platforms.

Software clock is regularly synced with NTP servers, if NTP is configured. For more information, refer to K3122: Using the BIG-IP Configuration utility to add an NTP server and K13380: Configuring the BIG-IP system to use an NTP server from the command line (11.x - 16.x).

Cause:

  • Hardware clock may be inaccurate in the first place
  • Hardware clock may slowly drift over time

Recommended Actions

You may regularly sync software time to hardware by performing the following procedure:
  1. Login to the BIG-IP via SSH.
     
  2. Create a script to perform software to hardware clock sync
    # echo -e '#!/bin/bash\nclsh hwclock --systohc' > /etc/cron.hourly/syncdatetoHWclock
     
  3. Make the script executable
    # chmod 755 /etc/cron.hourly/syncdatetoHWclock
