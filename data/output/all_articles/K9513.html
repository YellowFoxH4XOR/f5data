Topic

Starting in FirePass version 6.0.3, FirePass stores all RADIUS attributes received in a RADIUS response in the session.radius.auth and session.radius.groupmapping session variables.

If a user authenticates to a master group using RADIUS authentication, FirePass populates the session.radius.auth RADIUS session variables.

For example:
 
%session.radius.auth.6%= ' 2 '
%session.radius.auth.7%= ' 1 '
%session.radius.auth.8%= ' 172.16.3.33 '
%session.radius.auth.9%= ' 255.255.255.0 '
%session.radius.auth.10%= ' 3 '
%session.radius.auth.11%= ' std.ppp '
%session.radius.auth.12%= ' 1500 '
%session.radius.auth.13%= ' 1 '
 
If a user is dynamically assigned to a master group by the RADIUS master group mapping method, FirePass populates the session.radius.groupmapping RADIUS session variables.

For example:
 
%session.radius.groupmapping.6%= ' 2 '
%session.radius.groupmapping.7%= ' 1 '
%session.radius.groupmapping.8%= ' 172.16.3.33 '
%session.radius.groupmapping.9%= ' 255.255.255.0 '
%session.radius.groupmapping.10%= ' 3 '
%session.radius.groupmapping.11%= ' std.ppp '
%session.radius.groupmapping.12%= ' 1500 '
%session.radius.groupmapping.13%= ' 1 '
 
If the RADIUS server specified in the dynamic group mapping method is the same as the RADIUS server specified in the master group configuration, FirePass sends only one request to the RADIUS server. In these instances, the radius.groupmapping RADIUS session variables are populated but the session.radius.auth session variables are not. However, if the Retrieve Single Sign On Password from RADIUS attribute check box is selected in the master group configuration, FirePass populates both the session.radius.auth and the session.radius.groupmapping RADIUS session variables.
 
To save a user’s session variables (including RADIUS session variables) to the Logon Reports, select the Save user's session variables to Logon Reports check box on the Device Management : Maintenance : Troubleshooting Tools page. You can then view the users's session variables by selecting the user’s logon name on the Reports : Logons page.
 
Important: Enabling the Save user's session variables to Logon Reports setting will increase the load on the FirePass controller. This setting should only be enabled temporarily for troubleshooting purposes.
 
Note: For more information about using session variables, refer to the FirePass Controller Administrator Guide.
