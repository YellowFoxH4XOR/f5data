Known Issue

This is the result of a known issue. The BIG-IP WAN Optimization symmetric data duplication feature does not transfer large files correctly.

This behavior occurs when requesting files that are 5 GB or larger, the file will not be shared with the remote endpoint caches until approximately 4.3 GB has been transfered. Once the 4.3 GB mark has been reached, cache hits occur and prompt the system to transfer the file among the remote endpoints.

F5 Product Development tracked this issue as CR134530 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WAN Optimization or Edge Gateway release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
