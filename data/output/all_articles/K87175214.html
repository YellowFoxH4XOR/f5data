Description

Attempts to update or create an NS record for a zone can return the following error in some situations:
01150406:3: Operation failed: Update operation refused

Environment

  • BIG-IP DNS
  • Updating Resource Record for a Zone

Cause

The error is returned when the nameserver being specified for the zone is within the zone and doesn't have a matching A or AAAA record ("Glue Record") specified for it within the same zone. This is due to requirements of the BIND nameserver configuration, described within K14246: A nameserver record for a zone now requires a matching A record. For example, if you configure an NS record ns.example.com within the example.com zone, and you don't have a matching A/AAAA record, such as ns.example.com = 1.2.3.4, the attempt will fail and produce the error message.

The BIND nameserver does allow a zone to contain an NS record without a matching glue record, when the RDATA domain resides outside of the zone, as long as the RDATA string has a trailing period. For example, NS ns1.domain.com. would be allowed in the example.com zone without an A/AAAA record for ns1.domain.com being present in the example.com zone.

Recommended Actions

Creating an A record for ns.example.com in the zone example.com should allow for overcoming the observed error and be able to update the NS record for that zone as expected.
