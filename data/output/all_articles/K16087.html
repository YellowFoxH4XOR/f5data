Known Issue

BIG-IP APM reset of an RSA SecurID PIN may fail.

This issue occurs when all of the following conditions are met:

  • The BIG-IP APM system is configured with an access policy that uses RSA SecurID authentication.
  • The access profile Language Settings languages are set as French or Spanish.
  • The user's token PIN is reset by the SecurID RSA manager.
  • The BIG-IP APM system prompts the user to accept the new PIN.
  • The user responds to the BIG-IP APM prompt using their language locale as presented by the BIG-IP APM prompt.

    For example:

    A user accessing with French enters o (oui) as presented by the prompt.
    A user accessing with Spanish enters s (si) as presented by the prompt.

Impact

The PIN is not accepted and the user receives an error.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When users configured with the French or Spanish language locale respond with y/n yes/no, the BIG-IP APM system accepts the response.

Workaround

To work around this issue, the user can enter their response with English equivalents: y/n (yes/no).

Impact of workaround: Performing this workaround should not have a negative impact on your system.
