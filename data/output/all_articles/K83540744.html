Description

GUI becomes un-responsive and doesn't load.

  • GUI is slow to load.
  • Loading configuration has a long duration with no page loaded.
  • Tomcat has JDBC Driver messages logged.

Environment

  • BIG-IP
  • Management access
  • A recent upgrade to v15.1.x

Cause
If you notice the following messages in the var/log/tomcat/catalina.out file

# The web application [/tmui] registered the JDBC driver [com.mysql.jdbc.Driver] but failed to unregister it when the web application was stopped. To prevent a memory leak, the JDBC Driver has been forcibly unregistered.

If you notice the following messages in the var/log/restnoded/restnoded.log file

#  ErrorHandlingModule RestOperation failed: "/odata-registry/types/available". {"code":404,"message":"","referer":"restnoded","originalRequestBody":"","errorStack":[]}
 

Recommended Actions

To increase Tomcat memory run the following:

1. tmsh modify /sys db provision.tomcat.extramb value 256

   To view change run this command:
2. tmsh list sys db provision.tomcat.extramb

3. bigstart restart tomcat

Additional Information

Note: Restjavad may need increased memory also since this is used in conjunction with the GUI to make rest calls in the background when making configuration changes to the database.

Giving restjavad extra memory. This is a two-step process.

1. Update memory allocated to the control plane using TMUI. System, use K26427018 to determine the proper size for the management, for v15.1.x should be at least 500MB (Large):


2. Run the following two commands, in sequence:

   tmsh modify sys db restjavad.useextramb value true

   bigstart restart restjavad
