Topic

Namesurfer

Namesurfer is a third-party application that is used for zone file management on 3-DNS version 4.x systems. F5 Networks supports only Namesurfer security issues, and issues that impact interoperability with the 3-DNS Controller.

Beginning in version 9.2.2, BIG-IP Global Traffic Manager uses the ZoneRunner Feature for zone file management. For information about F5 Networks levels of support for ZoneRunner, refer to K7176: F5 Networks support for ZoneRunner, BIND, and the named daemon.

BIND

F5 Networks support for BIND is limited to issues that impact security and critical defects within the BIND feature. Enhancements and non-critical changes to BIND are not supported by F5 Networks. F5 Networks does not provide support for the actual configuration of BIND zones through the command line or Namesurfer.

named

F5 Networks will address any security vulnerability discovered in association with the named daemon. Additionally, F5 Networks will occasionally offer upgraded versions of BIND, which include the named daemon, in conjunction with upgrades of the 3-DNS Controller.

Any bugs related specifically to BIND, however, will not be supported or fixed by F5 Networks. F5 Networks will determine if the compromised portion of BIND directly impacts 3-DNS functionality and security.
