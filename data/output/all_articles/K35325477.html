Description

Running IoC Detection Tool on only LTM provisioned BIG-IP device reflects a failure for [+] BIG-IP Integrity check result: [FAIL]
=======================================================
missing     /var/sam/images/epsec-1.0.0-892.0.iso
missing     /var/sam/images/apmclients-7183.2020.108.2059-4753.0.iso
2 critical file(s) missing
=======================================================

Only running /usr/libexec/sys-eicheck.py on BIG-IP also shows same results.

Environment

  • v13.1.3.4
  • Module / Feature    Licensed    Provisioned
    Local Traffic (LTM)        X              Nominal

Cause

BIG-IP v13.1.3.4 ships with epsec-1.0.0-892.0.iso  &  apmclients-7183.2020.108.2059-4753.0.iso as part of the Base OS Manifest.
sys-eicheck.py is used to do the integrity check and it will check for the absence/presence (plus MD5SUM) of those files in /var/sam/images.
When those files do not exist on the device, they are being flagged as absent and will cause Integrity check result: [FAIL].

Example from SEA Lab 13.1.3.4 device:
# cd /var/sam/images
# ls -asl *.iso
304732 -rw-r--r--. 1 root root 311732224 2020-01-11 04:08 apmclients-7183.2020.108.2059-4753.0.iso
143584 -rw-r--r--. 1 root root 146876416 2020-02-21 17:34 epsec-1.0.0-892.0.iso

# rm -i *.iso
rm: remove regular file `apmclients-7183.2020.108.2059-4753.0.iso'? y
rm: remove regular file `epsec-1.0.0-892.0.iso'? y

# /usr/libexec/sys-eicheck.py
...
=======================================================
missing     /var/sam/images/epsec-1.0.0-892.0.iso
missing     /var/sam/images/apmclients-7183.2020.108.2059-4753.0.iso

2 critical file(s) missing
=======================================================

=======================================================
Integrity Check Result: [ FAIL ]
Contact F5 Networks Technical Support.


Recommended Actions

If the files were purposely deleted because APM is not provisioned, this can be safely ignored.
