Description

BIG-IP may log error message "01610004:3: publisher null"

Error messages logged in /var/log/ltm following 

Oct 19 22:56:09 bigip1.f5.com err mgmt_acld[21684]: 01610004:3: publisher null

Environment

  • BIG-IP All version
  • AFM provisioned
  • Firewall rules configured on the BIG-IP management port, and logging is enabled in the Firewall rules.

Cause

The firewall rules that enables loggins requires to configure the global-network logging profile appropriately.

The error happens when the configured log publisher definition is set to none in the global-network logging profile.

Recommended Actions

Configure the appropriate log publisher in the global-network logging profile.

None
