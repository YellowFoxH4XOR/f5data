Known Issue

Secure Sockets Layer (SSL) keys may fail to roll forward when you upgrade BIG-IP software.

This issue occurs when the following conditions are met:

  • You are performing an upgrade from BIG-IP 10.x to 11.x or 12.0.0.
  • The configuration contains SSL profiles that reference RSA keys.
When upgrading from BIG-IP 10.x to 11.x or 12.0.0, a small percentage of SSL keys may fail to roll forward. This issue occurs because the installation script does not properly account for an OpenSSL bug when verifying some SSL keys.

Impact

The configuration may fail to load when booting to the upgraded slot.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The system logs an error message to the /var/log/liveinstall.log file that appears similar to the following example:

    info: File <key_name> of type "certificate key" not rolled forward to file-object: the file is empty or contains invalid data

  • The configuration may fail to load when booting to the upgraded slot.
