Known Issue

This is the result of a known issue. If you configure the Windows Registry Checker in a pre-logon sequence, FirePass may fail to detect the registry key you configured even if it exists on the Windows client system. This issue occurs when the registry key you configured is not a subkey of the HKEY_LOCAL_MACHINE or HKEY_CURRENT_USER keys. For example, FirePass will not detect registry keys that are subkeys of the HKEY_CLASSES_ROOT key.

Note: Pre-logon sequences are configured on the Users: Endpoint Security: Pre-Logon Sequence page in the FirePass Administrative Console.

F5 Product Development tracked this issue as CR91961 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative Hotfix HF-601-11 has been issued for FirePass version 6.0.1 and Cumulative Hotfix HF-602-2 has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the Cumulative Hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
