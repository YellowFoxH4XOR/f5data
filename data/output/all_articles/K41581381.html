Known Issue

The BIG-IP PEM system may reuse TCP source ports too quickly on the server side.

This issue occurs when all of the following conditions are met:

  • The BIG-IP PEM system is configured with a VLAN configuration with CMP Hash set to either Source or Destination Address mode.
  • This VLAN configuration is associated to the affected PEM virtual server or the forwarding endpoint.
  • The source port of the connection is configured to Change on the affected PEM virtual server or the forwarding endpoint.

Impact

The peers with an established connection to the BIG-IP system may experience a connection reset.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • From tcpdump captures, you may observe that the BIG-IP system reuses some TCP source ports on the server side.
  • The peers with an established connection to the BIG-IP system may experience a connection reset.
