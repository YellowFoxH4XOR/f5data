Description

When you attempt to log into the Central Manager GUI, login fails and a banner displays "Login failed".

  • When viewing the HTTP request through the browser's developer tools, Central Manager is returning 500 internal server error.
  • Calls to /api/login also return 500 internal server error
  • One or more pods, especially mbiq-system-feature, may be restarting or in CrashLoopBackoff (note: pods that restart after the system boots is normal startup behavior)

Environment

  • BIG-IP Next Central Manager
  • The instance has recently been booted

Cause

It can take ten minutes or longer for Central Manager to come fully online, and you will be unable to log into the GUI until the whole system is online.

Recommended Actions

  1. Wait several minutes for the system to come fully online.
