Description

I configured Global Log receiver to send all logs to S3. However not all logs are sent to S3. I receive only a few logs or no logs. How can I make sure that all logs are send to S3?

Environment

  • F5® Distributed Cloud
  • Global Log Receiver

Answer/Recommended Actions

To send all logs to S3:

  1. Go to Global Log Receiver
  2. On the right side click on the 3 dots on the right side (...)
  3. Click View Configuration
  4. Go to the Log Message Section
  5. Select Select logs from all namespaces

Cause

  • Global Log Receiver is configured in the shared namespace and the Log Message Selection option is set for the Select logs from current namespace.
  • There might be few or no messages being logged in the Shared namespace.
