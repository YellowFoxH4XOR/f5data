Description

Unable to get the Nginx Controller WEB page shows the following error:

This site can’t be reached

<Controller IP> refused to connect.


From console return the following:

Check running version:

$ /opt/nginx-controller/helper.sh version
Installed version: 3.18.0
The connection to the server localhost:8080 was refused - did you specify the right host or port?

Check Controller status:

$ /opt/nginx-controller/helper.sh controller status
ERROR: No services are deployed. NGINX Controller is not installed.

    Environment

    • Nginx-controller

    Cause

    Certificate validation date expired.

     Recommended Actions

    1. Check the kubernetes certificates validation date from CLI:
    # sudo kubeadm alpha certs check-expiration
    1. If certificate expired, follow the steps:
    # sudo systemctl stop kubelet
# sudo kubeadm alpha certs renew all
cd to the home directory of the user who installed NGINX Controller.
# mv .kube/config .kube/config.old
# sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
# sudo chown $(id -u):$(id -g) $HOME/.kube/config
# sudo chmod 777 $HOME/.kube/config
# export KUBECONFIG=.kube/config
# sudo shutdown now -r
    1. Check to see if the kubelet server certificate is expired by entering the following command and observing the validity date:  
    sudo openssl x509 -in /var/lib/kubelet/pki/server.pem -text -noout 

    If it is expired, here are the steps to renew.

    1. Back up and remove the existing kubelet server certs:
    • From /var/lib/kubelet/pki/ backup the files: server.csr, server.key, and server.pem
    1. Create the following script to the NGINX Controller host and run it.
    # vi k8s-cert.sh            <<<< copy/paste below input
======== Copy start from the line below =========
#!/bin/bash
function join_by { local IFS="$1"; shift; echo "$*"; }
usrmask=$(umask)
mapfile -t altnames < <(awk '/32 host/ { print "IP:"f } {f=$2}' /proc/net/fib_trie | sort -u)
umask u=rwx,go=
sudo openssl genrsa -out /var/lib/kubelet/pki/server.key 2048
sudo openssl req -new -key /var/lib/kubelet/pki/server.key \
  -subj "/C=US/ST=Washington/L=Seattle/O=F5, Inc./OU=Controller/CN=kubelet" \
  -out /var/lib/kubelet/pki/server.csr
sudo bash -c "openssl x509 -req -in /var/lib/kubelet/pki/server.csr \
  -extfile <(printf \"subjectAltName=$(join_by , "${altnames[@]}")\") \
  -CA /etc/kubernetes/pki/ca.crt \
  -CAkey /etc/kubernetes/pki/ca.key -CAcreateserial \
  -out /var/lib/kubelet/pki/server.pem -days 365 -sha256"
umask "$usrmask"

    You can run the following script to check the secrets ./checkcerts.sh

    Note: You will need to create the script as it shown below

    # vi ./checkcerts.sh

======== Copy start from the line below =============
#! /bin/bash
#
# Check NGINX Controller pod certificates
NAMESPACE=nginx-controller

for node in $(kubectl get secrets | grep certs | awk '{print $1}'); do
    client=$(kubectl get secret $node -o "jsonpath={.data['client\.crt']}" | base64 -d | openssl x509 -enddate -noout 2>/dev/null)
    server=$(kubectl get secret $node -o "jsonpath={.data['server\.crt']}" | base64 -d | openssl x509 -enddate -noout 2>/dev/null)

    if [ -z "$client" ]
    then
       client="Not Found"
    fi

    if [ -z "$server" ]
    then
       server="Not Found"
    fi

    printf "$node\n"
    printf "\tclient cert: $client\n"
    printf "\tserver cert: $server\n"

done
