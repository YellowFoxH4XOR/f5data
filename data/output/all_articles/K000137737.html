Description

You may get TMSH error message like below when you change the BIG-IP APM log level config:
01071153:3: The ACL (<ACL Name>) contains an unspecified action in acl entry number 0

In this error message, note the following:
<ACL name> is the ACL name you are planning to change.

For example, you want to change the below example ACL test log level config from current none to packet:
apm acl test {
    description test
    entries {
        {
            action allow
            log none
        }
    }
}

You run # tmsh modify apm acl test entries { { log packet } }, but you find the change does not take effect, and you get the below TMSH error message:

01071153:3: The ACL (/Common/test) contains an unspecified action in acl entry number 0

Environment

  • BIG-IP APM
  • Access Control Lists(ACLs)
  • TMSH

Cause

Based on the F5 cloud documents here, if you plan to modify the log level config you need to specify the ACL action, as the action option is a required parameter.

Recommended Actions

If you want to change the ACL log level config, as required you must specify an ACL action.

For example, if you want to change the below example ACL test log level config from current none to packet, then the TMSH command should be like # tmsh modify apm acl test entries { { action allow log packet } }:
apm acl test {
    description test
    entries {
        {
            action allow
            log none
        }
    }
}
After you run the above command, the ACL test configuration should be like the example below:
apm acl test {
    description test
    entries {
        {
            action allow
            log packet
        }
    }
}
