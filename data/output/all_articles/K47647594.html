Known Issue

The SSH proxy profile may display as a virtual server configuration option.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is not licensed and provisioned with the BIG-IP AFM module.
  • Using the Configuration utility, you navigate to Local Traffic > Virtual Servers > Virtual Servers List and click Create.

Impact

The configuration option for the SSH proxy profile appears available.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility virtual server configuration option SSH proxy profile displays on BIG-IP systems that are not licensed for the BIG-IP AFM module.
  • Virtual servers configured with the SSH proxy profile configuration option send a reset to connection request sent to the virtual server.

Resolution

Status

F5 Product Development has assigned ID 595832 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. Workaround

To work around this issue, you can license and provision the BIG-IP AFM module to obtain the SSH proxy profile functionality.

For information about licensing and provisioning the BIG-IP AFM module, contact your F5 sales representative.
