K000134940: Determine the BIOS version for an F5 rSeries hardware product

Type
Knowledge
Published
2023-06-07
Updated
2023-06-22
Applies to
  • F5OS
  • rSeries Platforms
  • F5OS-A: 1.5.X, 1.3.X, 1.5.0, 1.3.2, 1.3.1, 1.3.0
  • rSeries 10000
  • rSeries 5000
  • rSeries 4000
  • rSeries 2000
Source

Topic

You should consider using these procedures under the following condition:

  • You want to determine the BIOS version of your F5 rSeries hardware product.

Description

At the time of publishing, the rSeries hardware products do not provide a way to determine the BIOS version using the webUI. To determine the BIOS version, you must use the CLI or REST API.

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have administrative access to the CLI or REST API as the admin user.
  • If you plan to use the REST API, you should have a local workstation with the curl and jq utilities installed.

Procedures

  • Use the CLI
  • Use the REST API

Use the CLI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of your rSeries system as the admin user.
  2. To display the BIOS version of your rSeries system, enter the following command:

    show components component platform properties property fw-version-bios

  3. The command returns output similar to the following example:

                                               UPDATE  
    NAME             VALUE       CONFIGURABLE  STATUS  
    ---------------------------------------------------
    fw-version-bios  2.01.134.1  false         none    

    From the example output, the VALUE column shows the current BIOS version is 2.01.134.1.

Use the REST API

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. From the local workstation that has the curl and jq utilities installed, enter the following command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <admin username>:<admin user password> "https://<management IP address>/api/data/openconfig-platform:components/component=platform/properties/property=fw-version-bios"

    For example,

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.80.5/api/data/openconfig-platform:components/component=platform/properties/property=fw-version-bios"

    The command returns output similar to the following example:

    {
      "openconfig-platform:property": [
        {
          "name": "fw-version-bios",
          "config": {
            "name": "fw-version-bios"
          },
          "state": {
            "value": "2.01.134.1",
            "configurable": false,
            "f5-platform:update-status": "none"
          }
        }
      ]
    }

  2. If the local workstation has the jq utility installed, you can use it to refine the output to display only the value. For example:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.80.5/api/data/openconfig-platform:components/component=platform/properties/property=fw-version-bios" | /usr/bin/jq '.[][] | {"BIOS version": .state.value }'

    The command returns output similar to the following example:

    {
      "BIOS version": "2.01.134.1"
    }
