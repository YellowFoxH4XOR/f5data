Description

Observing errors similar to the following in /var/log/touchscreen_lcd:

err lcdui[1234]: URL: http://127.4.2.1/mgmt/tm/sys/failover, result: 'Error downloading http://127.4.2.1/mgmt/tm/sys/failover - server replied: Proxy Error' (301), HTTP method 2, status 502
err lcdui[1234]: URL: http://127.4.2.1/mgmt/tm/sys/db/hostname, result: 'Error downloading http://127.4.2.1/mgmt/tm/sys/db/hostname - server replied: Service Unavailable' (301), HTTP method 2, status 503
err lcdui[1234]: URL: http://127.4.2.1/mgmt/tm/sys/alert/lcd, result: 'Error downloading http://127.4.2.1/mgmt/tm/sys/alert/lcd - server replied: Service Unavailable' (301), HTTP method 2, status 503
err lcdui[1234]: URL: http://127.4.2.1/mgmt/tm/sys/db/clustered.environment, result: 'Error downloading http://127.4.2.1/mgmt/tm/sys/db/clustered.environment - server replied: Service Unavailable' (301), HTTP method 2, status 503

Errors are intermittent and do not always appear.

Environment

  • Log files
  • LCD panel
  • iSeries

Cause

restjavad unavailable and unable to respond to requests from LCD panel.

Under normal operation, requests to these URIs are made every 20 seconds:

  • /mgmt/tm/sys/failover
  • /mgmt/tm/sys/db/hostname
  • /mgmt/tm/sys/db/clustered.environment

Requests here are made every 2 seconds:

  • /mgmt/tm/sys/alert/lcd

Those are not logged in restjavad-audit logs by default, but can be exposed by increasing the verbosity of restjavad logging to finest.

For example:

[F][109477][02 Mar 2023 13:23:41 UTC][ForwarderPassThroughWorker] {"user":"local/f5hubblelcdadmin","method":"GET","uri":"http://localhost:8100/mgmt/tm/sys/failover","status":200,"from":"127.4.2.2"}

The errors in /var/log/touchscreen_lcd are a result of Apache/httpd returning 502/503 to the requests made by the LCD panel while restjavad was unavailable.

Recommended Actions

Investigate why restjavad was unavailable - there can numerous reasons.

Research known issues for the version of BIG-IP in use.
