Known Issue

Important: This issue only affects the Server SSL profile and does not affect the Client SSL profile.

Note: This issue does not affect the 1500, 3400, 6400, 6800, 8400, or 8800 series platforms.

This is the result of a known issue. If you attempt to resume an SSL session while using a Server SSL profile on a BIG-IP LTM system that does not contain the Cavium SSL accelerator, TMM will crash. This behavior occurs when the BIG-IP LTM system switches to software to handle resuming the SSL session.

F5 Product Development tracked this issue as CR79098, and it was fixed in BIG-IP LTM 9.3.1 and 9.4.1. For information about upgrading, refer to the BIG-IP LTM Release Notes.

Workaround

Note: The following workaround is for systems that do not use the Cavium chipset for SSL acceleration, such as the 520/540, 5100/5110, 1000, and 2400 series platforms.

You can work around this issue by disabling SSL session resume. To do so, change the Session Cache Size in the Server SSL profile to 0 (zero).
