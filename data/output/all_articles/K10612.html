K10612: Antivirus software may falsely detect the OPSWATAVCommon.dll file as malware

Topic

The OPSWATAVCommon.dll file is an OPSWAT client component used to detect antivirus and firewall software on client systems. The OPSWATAVCommon.dll file is installed and updated automatically on client systems when the FirePass pre-logon sequence performs an antivirus or firewall check. After installing OPSWAT 3.4.3 (hotfix-127682) on the FirePass controller, some antivirus software falsely detect the OPSWATAVCommon.dll file as malware. This behavior is due to an issue with the antivirus software and not an issue with the OPSWAT client component.

In September of 2009, McAfee issued an update for McAfee VirusScan 8.7.0i that corrects this behavior. Users running McAfee VirusScan 8.7.0i should install the latest scan engine to correct this behavior. Users running other antivirus software should open a support case with their software vendor. Additionally, for tracking purposes, those users should also open a case with F5 Networks Technical Support, referencing this Solution number and CR129340.

Note: F5 Networks opened CR129340 for tracking purposes only. As stated earlier, this behavior is due to an issue with the antivirus software and not an issue with the OPSWAT client component.
