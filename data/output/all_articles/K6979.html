Topic

You can access the MySQL database on the BIG-IP system for troubleshooting purposes.

Determining the MySQL database password

BIG-IP 11.6.0 and later

The system randomly chooses the MySQL administrative password for the MySQL user account asm during the installation process. To view the current MySQL administrative password, type the following command:

Note: The following command outputs the password for the MySQL user account asm. Unlike the root user, the asm user does not have write access to all MySQL tables. If write access or access to other product tables (for example, AVR) is required, you must reset the root password to a known password by performing the Resetting the MySQL database password procedure at the end of this article and log in as root.

perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw.asm

BIG-IP 10.1.0 through 11.5.4

The system randomly chooses the MySQL administrative password during the installation process. To view the current MySQL administrative password, type the following command:

Note: Beginning in BIG-IP ASM 11.4.0, the following command outputs the password for the MySQL user account asm. Unlike the root user, the asm user does not have write access to all MySQL tables. If write access or access to other product tables (for example, AVR) is required, you must reset the "root" password to a known password by following the Resetting the MySQL database password procedure at the end of this article to log in as root.

perl -MF5::GenUtils -e "print get_mysql_password.qq{\n}"

BIG-IP 9.4.0 through 10.0.1

The system randomly chooses the MySQL administrative password during the installation process. To view the current MySQL administrative password, type the following command:

perl -I/ts/packages -MGenUtils -e 'print get_mysql_password().qq{\n}'

Resetting the MySQL database password

To reset the current MySQL password, use the following command syntax, replacing <newpassword> with the password of your choice:

Note: The following command changes the password for the MySQL root user account.

/usr/share/mysql/mysqlpw -p <newpassword>

After resetting the MySQL password on a BIG-IP ASM system, you must restart the localdbmgr process for the process to use the updated password.

To restart the localdbmgr process, type one of the following commands from the BIG-IP ASM command line:

tmsh restart /sys service localdbmgr

bigstart restart localdbmgr
