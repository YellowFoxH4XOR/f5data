K10509142: APM is not logging session information

Type
Support Solution
Published
2021-11-02
Updated
2025-12-04
Applies to
  • BIG-IP
  • BIG-IP Platforms
  • BIG-IP APM: 17.0.0, 17.1.1, 17.1.0, 17.0.X, 17.X.X, 21.X.X, 21.0.X, 21.0.0, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2
Source
https://my.f5.com/manage/s/article/K10509142

Description
APM is not logging session logs. Only few logs are seen in the APM Session Report or in /var/log/apm, like when a new session is started and PPP logs.

Environment

  • BIG-IP APM 
  • APM Session logs

Cause
Daemon apmd is not logging.

Recommended Actions

  • Restart daemon apmd using the following command:
bigstart restart apmd

 

Impact of action: This action can impact production traffic and user experience.F5 strongly recommends performing this operation during a scheduled maintenance window to minimize service disruption.

Additional Information
None.
