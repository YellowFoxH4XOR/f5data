Known Issue

This is the result of a known issue. Beginning in BIG-IP 10.0.0, the statistics menu accessible through the BIG-IP LCD panel will show incorrect values.

For example, the following bigpipe virtual command output shows positive values for current and maximum connections on a given virtual server:

VIRTUAL My_Virtual - stats:
| (cur, max, limit, tot) = (1, 1, 0, 6)
| (pkts,bits) in = (28, 15456), out = (22, 17032)
| requests (total) = 1

However, the LCD panel displays zeros for those same values:

Statistics:
Curr Conns: 0
Max Conns: 0

F5 Product Development tracked this issue as ID 291724 (formerly CR129776), and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, or WebAccelerator Release Notes.
