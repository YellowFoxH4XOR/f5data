Description

After re-activating license due to RMA, description at active-module in bigip_base.conf is changed.

  - Local Traffic Manager, r2800" was removed.

  - "Carrier Grade NAT (AFM ONLY)" and " Protocol Security Manager" were added.

Environment

r2800

Cause

It's not impact for functionality. This change was caused due to license server's response and F5 sometimes changes the description by internal maintenance.

F5 from time to time updates product functionality through the base software code and/or via licensing. We reserve the right to modify how product features are delivered without changing functionality, which can impact what is displayed in the license. Escalations should be for functional issues that appear to be caused by a change in the license.
