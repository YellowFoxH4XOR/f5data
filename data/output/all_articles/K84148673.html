Description

BIG-IP APM network access connections may fail while the user is attempting to connect to the VPN with the following messages on the client:

  • BIG-IP Edge Client may remain in an Initializing state.
  • The browser VPN client is disconnected and shows the following error:

    The connection was terminated by the remote computer before it could complete

The %temp%/logterminal.txt file on the Windows computer contains errors similar to the following example:

<date>,<time>, DIALER \URDialer.cpp, CURDialer::OnRasCallback(), RAS error (state=RASCS_Disconnected, error=628: The connection was terminated by the remote computer before it could be completed.)
<date>,<time>, DIALER \URDialer.cpp, CURDialer::OnRasCallback(), RAS error (state=RASCS_Disconnected, error=628: The connection was terminated by the remote computer before it could be completed.)

Environment

  • BIG-IP APM
  • Network access in Full or Split Tunnel mode
  • BIG-IP Edge Client on Windows 10
  • Browser network access client

Cause

There are various causes of the RAS 628 errors from either the client device or the BIG-IP APM system. F5 Support has determined that the issue can occur when an error occurs during tunnel negotiation and the BIG-IP APM system shuts down the tunnel. This can happen when the BIG-IP APM system is unable to allocate a lease pool address to the client. For a list of RAS error codes, refer to Routing and Remote Access Error Codes.

Recommended Actions

  • Verify that the Virtual Sever handling the DTLS traffic is assigned the same "Connectivity Profile" as is the Virtual Server handling the TLS traffic;
  • Verify that the lease pool object associated with the network access resource has available IP addresses. To display the statistics for the lease pool object, use the following command syntax:

    tmsh show apm resource leasepool <example_leasepool_name>

    For example:

    tmsh show apm resource leasepool example_leasepool

    The following is an example output where the value of Current Free is 0, indicating that there are no IP addresses available for the connecting client. This causes the client to disconnect with RAS error 628.

    ----------------------------l--------------------
    Apm::Leasepool Statistics: example_leasepool
    ------------------------------------------------
      Current Members          2
      Current Assigned         2
      Current Free             0
      Total Pick Requests     10
      Total Pick Failures      9  
      Total Reserve Requests   0
      Total Reserve Failures   0
      Total Release Requests   0
      Total Release Failures   0

    When this condition occurs, the corresponding /var/log/apm log file on the BIG-IP APM system also prints a log message similar to the following example:

    <date><time> <hostname> err tmm[14716]: 0149059c:3: /Common/NA_full_tunnel:Common:cb5d0155: IPv4 Allocation failure: leasepool /Common/example_leasepool is out of addresses

    In such cases, configure the lease pool object to provide it with more IP addresses.

  • Updating/reinstalling "WAN Miniport (IP)" device
    • A. Update "WAN Miniport (IP)" device:
      • a. Go to Device Manager -> Network adapters -> WAN Miniport (IP)
      • b. Initiate "Update Driver Software" for "WAN Miniport (IP)" device and click Update Driver Software
      • c. Choose Select Automatically for update driver software
      • d. Reboot the machine
      • e. Re-try to establish F5 SSL VPN
    • B. Re-install "WAN Miniport (IP)" device:
      • a. Go to Device Manager -> Network adapters-> WAN Miniport (IP)
      • b. Initiate "Update Driver Software" for "WAN Miniport (IP)" device and select bogus (i.e. incompatible) driver for it:
        • I. 'Browse my computer for driver' -> 'Let me pick from a list ...' -> Uncheck 'Show compatible hardware'
        • II. Select any wrong driver. (for example WAN Miniport (NetBEUI, Dial Out))
        • III. Press Yes then Done.
      • c. Initiate "Update Driver Software" for WAN Miniport (NetBEUI, Dial Out) and select WAN Miniport (IP) driver for it:
        • I. 'Browse my computer for driver' -> 'Let me pick from a list ...'
        • II. Select correct driver WAN Miniport (IP).
        • III. Press Done
      • d. Reboot the machine
      • e. Re-try to establish F5 SSL VPN
  • In some cases, you may need to remove the BIG-IP APM components on the client device. For more information, refer to K8253: Removing BIG-IP APM client components from Windows client systems.
  • If the RAS 628 error persists, you must perform more troubleshooting to isolate the problem. Enable RAS tracing on the Windows client. For more information, refer to K11135300: Enabling RAS tracing on Windows when troubleshooting BIG-IP APM network access issues.
