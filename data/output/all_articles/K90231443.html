Topic

You should consider using this procedure under the following condition:

  • You want to configure network failover traffic to pass over a secure channel.

Description

When you configure BIG-IP device group members to use network failover, the systems communicate over the configured failover addresses. By default, the systems use UDP port 1026 for unicast network failover traffic.

You can configure the BIG-IP system to pass network failover traffic over a secure channel. When you enable the failover.secure database variable, the system protects the failover connections to peer devices using Datagram Transport Layer Security (DTLS) and certificate authentication. Configuring secure network failover traffic may be beneficial when you configure network traffic to pass over a public network.

Important: Configuring secure network failover does the following:

  • Requires that that you define one or more unicast failover IP addresses for device group members
  • Disables the multicast network failover feature, which may negatively impact high availability configuration for VIPRION systems configured with multicast

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have access to the Traffic Management Shell (tmsh) utility.
  • You have access to the Configuration utility.

Procedures

Configuring a Failover Unicast address

Before you configure the system to pass network failover traffic over a secure channel, you must configure a failover unicast address (if one is not already configured). To configure a failover unicast address, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Devices.
  3. Click the local host name.

    For example:

    LTM1.example.com (Self)

  4. From the Device Connectivity menu, select Failover Network.
  5. In the Failover Unicast Configuration section, click Add.
  6. From the Address menu, select the self IP address associated with the failover VLAN.

    For example:

    10.0.0.1 (HA_VLAN)

  7. Accept the default port of 1026.
  8. Click Finished.

Enabling the failover.secure database variable

To enable the failover.secure database variable, perform the following steps:

Impact of procedure: Enabling the failover.secure database variable temporarily interrupts network failover communication until the variable is set on all device group members. You should perform this procedure during a maintenance window.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. Enable the failover.secure database variable by typing the following command:

    modify /sys db failover.secure value enable

  3. Repeat steps 1 and 2 for the remaining device group members.

Note: To disable the failover.secure variable and return the setting to the default value, type the following command:

tmsh modify /sys db failover.secure value disable
