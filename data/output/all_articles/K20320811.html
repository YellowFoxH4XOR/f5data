Known Issue

Connections using persistence may override node or pool member connection limits.

This issue occurs when all of the following conditions are met:

  • In the BIG-IP configuration, a Layer 4 (L4) or Layer 7 (L7) virtual server is associated with a node or pool member that is configured with a connection limit.
  • The virtual server is also configured with a persistence profile.
  • The BIG-IP system experiences excessive usage load.

Impact

Connection limits configured for affected nodes or pool members may not be honored.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system load balances connections to a node or pool member that has exceeded the configured connection limit.

Workaround

There is no workaround for this issue. However, you can avoid this issue by disassociating the persistence profile or using the connection limit or connection rate limit on the virtual server instead of the nodes and pool members.
