Description

Health check monitor for load balanced NTP servers

 

Environment

NTP virtual server

pool of NTP servers

health monitors

 

Cause

There is no built-in monitor suitable for checking NTP responses or service/ server status.

 

Recommended Actions

Create an external monitor that checks the stratum field from the NTP monitor responses. Sample scripts below can be used when creating said external monitor.

 

for IPv4:

#!/bin/sh

IP=`echo ${1} | sed 's/::ffff://'`

ntpdate -q -p 1 ${IP} 2> /dev/null | grep -Ewo 'stratum\s+([1-9]|1[0-5])' > /dev/null

return_codes="${PIPESTATUS[*]}"



if [ "${return_codes}" == "0 0" ]

then

echo "up"

fi
