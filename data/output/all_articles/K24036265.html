Issue

Error Message

pccd[<PID>]: 015d0000:0: pccd encountered a fatal error and will be restarted shortly

In this error message, note the following:

  • <pccd> is the Packet Correlation Classification Daemon
  • <PID> is the process ID for the pccd process

For example:

pccd[6043]: 015d0000:0: pccd encountered a fatal error and will be restarted shortly

Message Location

You may encounter this message in the following location:

  • The BIG-IP command line
  • The /var/log/ltm file
  • The /var/log/tmm file

Description

This message occurs when the following condition is met:

  • You attempt to configure fully qualified domain names (FQDN) that exceed the maximum supported limit using ACL, such as Security > Firewall > address-list.

    For example, you attempt to add a 257th FQDN entry using the TMOS Shell (tmsh):

    modify security firewall address-list fqdn_list fqdns add { www257.abc.com }

The BIG-IP AFM system supports a maximum of 256 unique FQDNs across all policies. This limit applies to any rule list or address list associated with FQDNs. However, the system supports 1024 maximum FQDN entries when FQDNs are mapped to IPI (IP Intelligence) categories.

Impact

The pccd process fails to compile the policy and enters a restart loop. The BIG-IP system does not prevent or warn you from exceeding the maximum FQDN entries.

Recommended Actions

To prevent a pccd restart loop, you should remove the FQDN entry that exceeds the FQDN maximum limit.

For example, you can remove the FQDN entry using the following tmsh command:

modify security firewall address-list fqdn_list fqdns delete { www257.abc.com }
