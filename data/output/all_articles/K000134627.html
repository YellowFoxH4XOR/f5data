Description

The minimum configuration for a RADIUS user for F5-OS is below.

 

Environment

  • F5-OS
  • RADIUS authentication

Cause

The minimum configuration for a RADIUS user for F5-OS is:

foouser Cleartext-Password := "default"
F5-F5OS-GID := 9000,
F5-F5OS-HOMEDIR := /tmp

The other Vendor-Specific-Attributes (VSA) can be configured also:

foouser Cleartext-Password := "default"
F5-F5OS-UID := 1001,
F5-F5OS-GID := 9000,
F5-F5OS-HOMEDIR := /tmp,
F5-F5OS-USERINFO := FooUser, <-- Optional user info
F5-F5OS-SHELL := /var/lib/controller/f5_confd_cli
F5-F5OS-SECONDARYGIDS := "9004,9101"

One thing to keep in mind for F5-F5OS-SECONDARYGIDS is that it is a String value, as it supports multiple values for Velos Partition access, so even if you only need to set 1 value, make sure that is of type string whereas F5-F5OS-UID and F5-F5OS-GID are integers.

When running traffic capture for radius authentication using command like the below:

tcpdump -s0 -ni mgmt -vw /var/tmp/radius_.pcap host <radius_remote_server_ip>
