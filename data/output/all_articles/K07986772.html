K07986772: error: Got an error reading communication packets on database server when load balancing on BIG-IP

Type
Support Solution
Published
2022-03-05
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.X.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K07986772

Description

When load balancing My-SQL database server on BIG-IP, the database server generates below errors:

 [Warning] Aborted connection 12879657 to db: 'username' user: 'username' host: 'x.x.x.x' (Got an error reading communication packets)
 [Warning] Aborted connection 12879659 to db: 'username' user: 'username' host: 'x.x.x.x' (Got an error reading communication packets)
 [Warning] Aborted connection 12879660 to db: 'username' user: 'username' host: 'x.x.x.x' (Got an error reading communication packets)
 [Warning] Aborted connection 12879662 to db: 'username' user: 'username' host: 'x.x.x.x' (Got an error reading communication packets)

Note: Where x.x.x.x will be self-IP address of the BIG-IP that is attempting to communicating with backend database server. 
Note: No errors are logged on BIG-IP. 

Environment

  • Virtual server load balancing MySQL database servers. 
  • TCP monitor 
  • Logs generated on the database server. 
  • No impact on traffic. 

Cause

Not known 

Recommended Actions
This needs to be checked from database server
