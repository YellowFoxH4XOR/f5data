FirePass provides the following Portal Access session variables for use with Web Applications content processing (sed) scripts:

  • FP_ServiceAddr

    The FP_ServiceAddr session variable contains the hostname of the FirePass web service used to access the FirePass controller.
  • FP_SessionID

    The FP_SessionID session variable contains the user’s session ID.
  • FP_ServiceProto

    The FP_ServiceProto session variable contains the protocol used to access the FirePass controller, either HTTP or HTTPS.

    Note: The FP_ServiceProto session variable was introduced in FirePass version 6.0.1.
 
For example:
 
<A HREF="/app.cgi?query=1&source=CorpLan">
 
If the source HTML code of a web application page contains the example line, and you wanted to change CorpLan to the hostname of the FirePass web service, you could use the following sed script:
 
s/app.cgi?query=1&source=CorpLan/app.cgi?query=1&source= FP_ServiceAddr/g
 
You can configure Web Applications content processing scripts on the Portal Access : Web Applications : Content Processing page in the FirePass Administrative Console.

Note: For more information about configuring Web Applications content processing scripts, refer to the FirePass Controller Administrator Guide.
