Note: For information about configuring members of a redundant pair to default to active or standby status for BIG-IP 9.x versions, refer to K8184: Configuring members of a redundant pair to default to active or standby status.

After a failover in which a BIG-IP system in a redundant pair reboots, the BIG-IP systems can reboot into active-active mode. As a result, both BIG-IP systems may attempt to ARP for virtual server, SNAT, and proxy addresses, causing a loss of service. To prevent an undesired active-active situation, it is possible to configure members of a redundant pair to default to an active or standby state after the system starts or restarts.

Important: If you are using VLAN failsafe in conjunction with hardware failover, use the settings in the following procedure with caution. If the system you configured to be the ForceActive unit has an interface failure, VLAN failsafe will reboot the system and the standby unit will take over. However, when the ForceActive system comes back up, the ForceStandby system will revert to standby and VLAN failsafe will reboot the ForceActive unit again (since the interface will still be down), at which point the ForceStandby will take over again. This back and forth process will repeat indefinitely; using network failover in conjunction with hardware failover will have no effect on this behavior as hardware failover takes precedence over network failover.

The BIG-IP and 3-DNS systems use the bigdb failover keys to determine whether to apply active or standby status upon reboot. The keys and their values are as follows:

Local.Bigip.Failover.ForceActive = 0 | 1
Local.Bigip.Failover.ForceStandby = 0 | 1

To specify the active and redundant system in a redundant pair, perform the following procedure:

  1. To set a BIG-IP or 3-DNS as the default active system in a redundant pair, type the following commands: 

    bigpipe db set Local.Bigip.Failover.ForceActive = 1
    bigpipe db set Local.Bigip.Failover.ForceStandby = 0
    b failover init

  2. To set a BIG-IP or 3-DNS as the default standby system in a redundant pair, type the following commands: 

    bigpipe db set Local.Bigip.Failover.ForceActive = 0
    bigpipe db set Local.Bigip.Failover.ForceStandby = 1
    b failover init

Once configured, the standby BIG-IP system will become active if it does not detect an active system.
