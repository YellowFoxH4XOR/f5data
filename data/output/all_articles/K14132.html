K14132: SNMP cannot poll interface status on the FirePass 4100 and 4300 platforms

Knowledge
Published
2013-01-17
Updated

Status
Legacy Content
Applies to

  • FirePass: 6.1.0, 7.0.0
Source
https://my.f5.com/manage/s/article/K14132

Topic

The network interface status cannot be polled by SNMP on the FirePass 4100 and 4300 platforms. This is due to a hardware design constraint.

F5 Product Development is tracking a Request for Enhancement (RFE) to support SNMP monitoring of the network interfaces. F5 is tracking this RFE as ID 404592.

Workaround

To work around this issue, you may be able to monitor the network interface status by monitoring the switch port to which the FirePass controller is connected.
