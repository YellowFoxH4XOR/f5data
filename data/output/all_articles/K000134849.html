Description

How to use the iControl REST API, to retrieve objects which do not reside in the /Common config partition?


Environment

BIG-IP

TMOS

Cause

None

Recommended Actions

Use syntax ~Partition_Name~


For example, to access a GSLB Server named "ServerA", which resides in configuration partition "AnotherParition" (/AnotherPartition/ServerA), use:

https://<Management_IP/mgmt/tm/gtm/server/~AnotherPartition~ServerA
