Topic

To comply with FIPS-197, you must configure an SSL profile to use only AES ciphers for SSL communication from either the command line or the Configuration utility. To do so, perform one of the following two procedures:

Note: These instructions describe how to limit the ciphers to AES ciphers, and are not necessarily mutually exclusive with other client SSL or server SSL profile configuration options, such as setting a certificate chain, certificates, keys, passphrases, or other SSL profile options. For more advanced options and additional settings available to SSL profiles, refer to the Managing SSL Traffic chapter of the Configuration Guide for BIG-IP Local Traffic Management.

For a list of ciphers supported by BIG-IP platform, refer to the following Solutions:

K6807:  SSL ciphers supported on BIG-IP platforms in versions 9.1.x
K6808:  SSL ciphers supported on BIG-IP platforms in versions 9.2 through 9.4.x
K11444:  SSL ciphers supported on BIG-IP platforms in version 10.x

For a list of BIG-IP platforms that support FIPS, refer to K6499:  BIG-IP platforms that support FIPS.


Configuring an SSL profile to use only AES ciphers from the command line

To configure an SSL profile to use AES ciphers from the command line, perform the following procedure:

  1. Log in to the command line.
  2. Create an SSL profile for either the client side or the server side by typing one of the following commands:
    • Client SSL Profile

      bigpipe profile clientssl <profile name> defaults from clientssl ciphers AES
    • Server SSL Profile

      bigpipe profile serverssl <profile name> defaults from serverssl ciphers AES

Configuring an SSL profile to use only AES ciphers from the Configuration utility

To configure an SSL profile to use AES ciphers from the Configuration utility, perform the following procedure:

  1. From Local Traffic in the Navigation menu, choose Profiles.
  2. From the SSL drop-down menu, choose either client or server.
  3. Click the Create button.
  4. Type a name for the profile.
  5. Change the Configuration drop-down to Advanced.
  6. Select the Custom check box next to Ciphers.
  7. Edit the text in the Ciphers text box to read AES.
  8. Click the Finished button.


Note: For more information about the AES algorithm, refer to the following location:

http://csrc.nist.gov/CryptoToolkit/aes/

Note: For more information about FIPS-197, refer to the following location:

http://csrc.nist.gov/publications/fips/fips197/fips-197.pdf
