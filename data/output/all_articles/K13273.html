Known Issue

The BIG-IP ASM system may generate an error message when the security policy is applied in a clustered environment.

This issue occurs when all of the following conditions are met:

  • BIG-IP ASM is configured in a clustered environment (VIPRION or vCMP)
  • You click Apply Policy in the Configuration utility

Impact

None. This error message is benign.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The system writes error messages to the /var/log/ltm file of the primary cluster member, which appear similar to the following example:

    0107092e:3: user:root remote_host:none pid:5485, updates to the configuration are not allowed on a secondary
