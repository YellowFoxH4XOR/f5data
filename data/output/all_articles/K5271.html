K5271: Configuration database settings that are automatically recreated after rebooting or running the bigstart command

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • 3-DNS: 4.6.4
  • BIG-IP 4.X: 4.6.4
Source
https://my.f5.com/manage/s/article/K5271

Topic

BIG-IP and 3-DNS use a database to store certain configuration options. You can use the bigpipe db unset command to remove settings from the database; however, after a reboot or whenever the bigstart command is run, BIG-IP and 3-DNS will automatically recreate some of the database settings.

Workaround

If you need to remove a setting that is automatically recreated by BIG-IP or 3-DNS, you can sometimes work around this issue by using an invalid value for the setting.
