K000133505: BIG-IQ qkview db dump fails with 'User was holding a relation lock for too long' error.

Type
Support Solution
Published
2024-08-07
Updated
2024-08-07
Source
https://my.f5.com/manage/s/article/K000133505

Description

You are unable to generate qkview file with Postgres db dump, the following error can be seen:

DETAIL: User was holding a relation lock for too long.
pg_dump: The command was: COPY bigiqcurrentconfig.asm_cc_policies_signatures (_id, _sid, _parentid, _parenturi, generation, expiration, _module, _system_search_tags, _searchmeta, _ranges, _rbac, _eras, _value) TO stdout;

Environment

  • BIG-IQ HA
  • Qkview generation attempt

Cause

A policy signature was edited during the backup and the table cannot be dumped.
This can happen while taking QKViews on secondary devices.

Recommended Actions

Retry qkview/db dump after a few minutes.

Additional Information

None.
