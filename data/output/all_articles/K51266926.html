Topic

You should consider using these procedures under the following condition:

  • You want to log information for traffic processed by the network firewall.

Description

Prerequisites

You must meet the following prerequisites to use these procedures:

  • Your BIG-IP AFM device is licensed, provisioned, and configured.
  • You have administrative access to the Configuration utility. 

Procedures

Configuring a default logging profile

The following procedures create a default logging profile for your BIG-IP AFM system.

  • Creating the default log publisher
  • Creating a Network Firewall policy and rule

Creating the default log publisher

This procedure creates a publisher profile for the default logging profile.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP AFM Configuration utility.
  2. Navigate to System > Logs > Configuration > Log Publishers.
  3. In the Name box, type a name for the log publisher.
  4. From the Available column, select a Log Destination (select local-db to publish logging to the local BIG-IP AFM device).

    Important: Depending on the network volume that the BIG-IP AFM system processed, logging can be verbose.

    For production environments, F5 recommends that you use remote logging.

    Note: For more information about configuring remote logging, refer to K13080: Configuring the BIG-IP system to log to a remote syslog server (10.x - 13.x)

  5. To add the log destination to the Selected column, click <<.
  6. Click Finished.
  7. Navigate to Security > Event Logs > Logging Profiles.
  8. Click the default Profile Name link global-network.
  9. In the Logging Profile Properties, select the box for Network Firewall.
  10. In the Publisher box, type the log publisher name configured in step 3.
  11. In the Network Firewall section, select the event Log Rule Matches check boxes for Accepted, Drop, and Reject, that best reflect the intent of the logging profile.
  12. Select the log settings you want for Log IP Errors, Log TCP Errors, Log TCP Events, and Log Translation Fields that best reflect the intent of the logging profile.
  13. In the Storage Format section, configure the data output to match your deployment requirements.
  14. Click Update.

Creating the Network Firewall policy and rule

This procedure creates a Network Firewall policy and rule to enable logging of network firewall traffic.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP AFM Configuration utility.
  2. Navigate to Security > Network Firewall > Policies.
  3. Click Create.
  4. In the General Properties Name box, type a name for the policy.
  5. Click Finished.
  6. Navigate to Network Firewall > Policies, and click the name of the new policy.
  7. To add a new rule to the policy, click Add Rule.

    Note: For BIG-IP versions prior to 13.0.0 click Add.

  8. In the Name box, type a name for the new rule.
  9. If you want to only log network traffic, from the menu, set Logging to Enabled and leave all other settings at their defaults.
  10. Click Done Editing.

    Note: For BIG-IP versions prior to 13.0.0, click Finished.

  11. Click Commit Changes to System.

    Note: For BIG-IP versions prior to 13.0.0, the Commit Changes to System button does not exist and is not required.
