Description

This article describes how ASM and Advanced WAF handle escaping double quotes in different formats of remote logging.

Environment

  • This applies to all versions of BIG-IP 12.X and higher provisioned with ASM or Advanced WAF.
  • Requirements are having a Security Policy and a Remote Logging Profile applied to a Virtual Server.

Cause

ASM/Advanced WAF will escape double quotes " different ways depending on the type of remote logging format selected in the logging profile. This is by design.

Recommended Actions
None

Additional Information

If you are using CSV format for remote logging:

ASM/Advanced WAF will escape the " with using "
An example of this would be the following:
 
Actual RequestRemote logging
user="test"user=""test"" 
"""test/ """"""test/ 

When using this format BIG-IP will just add a single " before any " in the request



If you are using BIG-IQ and Splunk formats for remote logging the BIG-IP will escape the " using %22
An example of this would be the following:
 
Actual RequestRemote logging
user="test" user=%22"test%22"
"""test/%22"%22"%22"test/


When using this format BIG-IP will just add %22 before any " in the request
