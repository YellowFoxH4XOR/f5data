Description
Upgrade fails with the following fatal error message:
crit tmsh[xxxx]: 01420001:2: Can't load keyword definition (user-account.session_limit) : framework/SchemaCmd.cpp, line 825.

Environment

Upgrade from one of the following releases:

  • v13.1.4 or later within the v13.1.x branch
  • v14.1.4 or later within the v14.1.x branch
  • v15.1.1 or later within the v15.1.x branch

to one of the following releases:

  • v14.0 through v14.1.3.1
  • v15.0 through v15.1.0.5
  • v16.0.0 and v16.0.0.1

Cause
Bug ID 947905: Upgrade from 13.1.4, 14.1.4, or 15.1.1 to 14.0.x, 15.0.x, 16.0.0 or 16.0.0.1 fails

Recommended Actions

  • To avoid the issue, if you're running an affected version listed in the Environment section, upgrade to 16.0.1 or later.
    Note: BIG-IP version 16.0.0.1 and 16.0.1 are different releases.
