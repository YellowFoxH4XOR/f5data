Description

This article provides a summary of the issues you may encounter when using F5 Access client on MAC Sonoma. 

Environment

  • BIG-IP APM network access, VPN
  • F5 Access client on MAC Sonoma

Cause

The following list of known issues may be the cause of the issue you are facing:

  • K000139679: F5 Access client does not launch without sudo on MacOS Sonoma (Fixed at F5 Access 2.1.0)
  • K000139715: F5 Access client does not connect on MacOS Sonoma with client certificate authentication (Fixed at F5 Access 2.1.0)
  • K000139434: F5 Access client proxy configuration does not work on MAC OS
  • K000137043: After upgrading to MacOS 14 Sonoma, VPN connections using Proxy configurations in the Network Access may fail (Fixed at APM Client 7.2.4.5)
  • Use the Rosetta emulator software on M-series MAC silicon processors with F5 Access. Refer to K000133380: F5 Access not running on M1 Apple Mac.
  • Refer to bug fixes, existing known issues in the latest F5 Access release notes:
    • F5 Access for macOS 2.1.0
    • F5 Access for macOS 2.0.2
    • F5 Access for macOS 2.0.1

Recommended Actions

Use the following recommendations actions as appropriate:

  • Upgrade to a fixed version or use the workaround in the description of the known issue when one exist. 
  • As you implement new features, review the supportability and compatibility matrix for F5 Access
    • F5 Access Apps Compatibility Matrix
    • K23653432: BIG-IP APM client feature matrix
  • Consider K000139501: Provide access control to F5 Access to reduce credential prompts on MAC OS.

Additional Information

Troubleshooting

  • When you encounter issues with F5 Access, as a
    • VPN user: As every BIG-IP APM access policy is unique and different IT administrators may implement different security requirements for each organization, please contact your IT administrator to report the issue.
    • BIG-IP APM administrator: Use the notes in this article which may resolve the issue you are facing at the first instance. Should you require assistance, please do not hesitate to contact F5 Support.
  • Log Files: F5 Access log files on MAC include the following:
    • Application.log
    • PacketTunnel.log
      To list these files on the MAC command line terminal, enter the following command:
      ls  ~/Library/Group\ Containers/*.group.com.f5.access.macos
  • There may be times where you need to uninstall and install F5 Access on your client. Use the following resources:
    • K25184950: Removing BIG-IP F5 Access from Mac OS.
    • K11060025: Downloading F5 Access mobile apps
