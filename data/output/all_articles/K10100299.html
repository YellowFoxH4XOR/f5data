K10100299: BIG-IQ *_writer index cause filling /var partition on DCD nodes

Type
Support Solution
Published
2022-05-18
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • Public Cloud
  • Private Cloud
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K10100299

Description

  • You are hitting issues with filling /var partition on BIG-IQ DCD nodes after performing  removal of  unassigned shards  according to  K81715478: Error Message: At least one primary shard (and all of its replicas) are missing. This means that you are missing data; searches will return partial results, and indexing into that shard will return an exception.
  • Retention is not happening and one or more indices are growing constantly
  • Name of the index has *_writer in the name without date of creation as in example below 
    Note: Command can be executed on any BIG-IQ in cluster 
    for version below 8.x # curl -s localhost:9200/_cat/indices?v | grep writer
    for versions  8.x# curl -sk https://localhost:9200/_cat/indices?v | grep writer
    green  open   access-event-logs_writer                         fgrIrd1iQsuDWEhaeC76jA   5   1   17419322            0      7.3gb          3.6gb
     
  • Status of Data Collection Cluster  cluster might be red under  System > BIG-IQ Data Collection > BIG-IQ Data Collection Cluster > Summary > Status


 

Environment
  • BIG-IQ Data Collection Device Cluster 
  • Enabled at least one of services on DCD nodes for collecting ASM, ACCESS, AFM etc. events 
  • /var on Data Collection Devices is full or near 100%
  • Not working retention
  • *_writer index exist in ElasticseachDB
  • Unassigned shard removal perforemed in the past 
  • Possible ElasticSearch Cluster RED status with  error:
     Error Message: At least one primary shard (and all of its replicas) are missing. This means that you are missing data; searches will return partial results, and indexing into that shard will return an exception 

Cause

Bug ID 909205: BIG-IQ statistics reports are missing the latest event data

Recommended Actions

Please follow recommended actions/ workaround  from Bug ID 909205: BIG-IQ statistics reports are missing the latest event data 

Additional Information
None.
