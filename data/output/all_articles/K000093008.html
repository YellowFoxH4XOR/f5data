Description

Bigip is unable to load a UCS file and showing the error message similar to below.

ERROR: Reprovisioning or another config/ucs save/load is in progress. Can't run config actions simultaneously.

Environment

  • BIG-IP 
  • UCS restoration

Cause

This error is caused either when another UCS/config save/load is already running.

 Recommended Actions

1. Check for any ucs processes running on the system
 # ps aux | egrep -i 'ucs|save sys config'

2.Kill the process if present any 
# kill -9 <pid>

3. Also check for any 'save sys config' in place either from external script or due to APM configuration at the same time as loading ucs file by running following command from bash 
# tail -f /var/log/audit | grep 'save sys config'

4. Once verified no other UCS process or save sys config in running, load UCS file again.
