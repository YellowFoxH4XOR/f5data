Known Issue

BIG-IP systems licensed with an ADF SKU may reboot repeatedly after licensing.

This issue occurs when the following condition is met:

  • The system is running an ADF license that was first activated before 1/30/2014.

Impact

The system reboots repeatedly after applying one of these licenses.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H457550 on the Diagnostics > Identified > High screen.
  • The BIG-IP system reboots repeatedly after applying the ADF license.
  • The BIG-IP system logs error messages that appear similar to the following to /var/log/ltm after every reboot:

    warning chmand[7123]: 012a0004:4: File I/O error:22 /sys/devices/system/cpu/cpu0/cpufreq/user_limit:2400000
    emerg chmand[7123]: 012a0000:0: The system must be rebooted for some changes to take effect. This is an expected behavior when upgrading performance license.

  • Duplicate license tokens appear in the /config/bigip.license file. The duplicate tokens may appear similar to the following example:

    # Accumulated Tokens for Modules
    # ADF, Aperf_CPU_frequency 1200000 key MKGQDRJ-SXULUIT
    # ADF, Aperf_CPU_frequency 1200000 key MKGQDRJ-SXULUIT
    #
    # Accumulated Tokens for Modules
    # ADF, Aperf_SSL_total_TPS 563 key MKGQDRJ-SXULUIT
    # ADF, Aperf_SSL_total_TPS 563 key MKGQDRJ-SXULUIT

Resolution

Status

F5 Product Development has assigned ID 446676 to this issue. F5 has confirmed that this issue existed on the F5 license server for ADF licenses activated prior to 1/30/2014. This issue was fixed for ADF licenses activated after 1/30/2014.

Workaround

If your BIG-IP system is affected by this issue, you must contact F5 Technical Support to have the duplicate license tokens removed from the F5 license server's copy of your BIG-IP system's license. You may then re-activate the BIG-IP system's license.
