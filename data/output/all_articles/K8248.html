Known Issue

The Bridge in Standby option is enabled by default within a Virtual Local Area Network (VLAN) group. As a result, bridging loops may affect network traffic.

F5 Product Development is tracking this issue as ID 248678 (formerly CR91786).

Note: This issue has been fixed in BIG-IP 12.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloadssite.

Workaround

To prevent this behavior from occurring, clear the Bridge in Standby check box when creating a VLAN group.
