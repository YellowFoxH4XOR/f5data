K000137381: Stopping security policy bot logging and allow curl based request

Support Solution
Published
2023-10-26

2023-10-31
Applies to

  • NGINX App Protect WAF: 4.X.X, 4.6.X, 4.6.0, 4.5.X, 4.5.0, 4.4.X, 4.4.0, 4.3.X, 4.3.0, 4.2.X, 4.2.0, 4.1.X, 4.1.0, 4.0.X, 4.0.0
Source
https://my.f5.com/manage/s/article/K000137381

Description

Your NGINX App Protect system is detecting and logging many bot signature name curl request.

Example log message: bot_signature_name="curl"

You would like to allow curl based access to the resource.

Environment

  • NGINX App Protect

Cause

Client access protected resource using curl.

Recommended Actions

Create a security policy to suppress the cURL access logging messages.

Example security policy:

{
"policy" : {
"name": "my_policy",
"template": { "name": "POLICY_TEMPLATE_NGINX_BASE" },
"applicationLanguage": "utf-8",
"enforcementMode": "blocking",
"bot-defense" : {
"mitigations" : {
"signatures" : [
{
"name": "curl",
"action" : "detect"
}
]
}
}
}
}
