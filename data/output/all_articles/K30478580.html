Description

SMTP using STARTTLS not working after enabling ASM Protocol Security. 

Packet capture shows a successful connection, however, after providing hashed password, BIG-IP responds with the following message:

"500 syntax error command not found"

or in the packet capture, the following would be seen:

"500 Syntax error, command not recognized"
 

Environment

  • Protocol Security Enabled on SMTP
    ( using the menu Security > Protocol Security > Security Profiles > SMTP ) 
  • Without Protocol Security, SMTP using STARTTLS work
     

Cause

In the packet capture, it is found that the server sends the HELLO containing the options:  | AUTH=LOGIN | AUTH LOGIN |

The client responds with option: AUTH LOGIN

BIG-IP ASM supports only single-line SMTP authentication methods such as AUTH PLAIN.

Unsupported authentication methods include AUTH LOGIN and AUTH CRAM-MD5.

Hence, when an unsupported authentication method is used in SMTP communication, it is expected to see SMTP to stop working.
 

Recommended Actions

Disable Protocol Security for SMTP.
