K16506028: GTM external monitor must be manually created on each GTM

Type
Support Solution
Published
2020-12-31
Updated
2023-02-21
Applies to
  • BIG-IP
  • BIG-IP GTM
  • BIG-IP DNS: 15.1.X, 15.0.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.X.X, 15.1.1, 15.1.0, 15.0.1, 15.0.0, 15.1.2
Source
https://my.f5.com/manage/s/article/K16506028

Description

  • After adding a new DNS Server Object, updated configuration fails to Sync.
  • /var/log/gtm may report the following messages:
    • 011ae044:3: Could not find monitor object <Monitor> on server:<DNS Server>
    • 01070712:3: Values (<Monitor>) specified for external monitor parameter (<DNS Server>): foreign key index (<file name>) do not point at an item that exists in the database.

Environment

  • BIG-IP DNS provisioned
  • DNS objects are created referring to External or EAV monitors
  • Created objects do not appear on other BIG-IP DNS devices after creation.

Cause

External or EAV monitors are not sync'd as part of the BIG-IP DNS configuration, and are not automatically created on peer BIG-IP DNSs.

Recommended Actions

  1. Manually replicate required External/EAV monitor(s) across all BIG-IP DNS in the Syncgroup.
  2. Configure required DNS Server.
