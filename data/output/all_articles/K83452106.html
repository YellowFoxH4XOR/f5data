Known Issue

An EPSEC OPSWAT software update may revert to the previously installed version.

This issue occurs when all of the following conditions are met:

  • You install an updated EPSEC OPSWAT image on the BIG-IP APM system.
  • You verify that the current EPSEC OPSWAT version installed successfully.
  • You reboot the BIG-IP APM system.

Impact

The BIG-IP APM system utilizes the EPSEC OPSWAT version already in use prior to the update.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When verifying the current EPSEC OPSWAT version immediately after the update, the utilized version is the newly installed update.
  • After rebooting the BIG-IP system, the EPSEC status is the same version utilized prior to installing the update.

Workaround

To work around this issue, prior to installing the OPSWAT EPSEC update, you can upload a file to the BIG-IP APM hosted content store. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log on to the BIG-IP APM Configuration utility.
  2. Navigate to Access Policy > Hosted Content > Manage Files.
  3. Click Upload.
  4. To select a file for uploading from your local user device, click Browse.

    Important: The file can be an empty text file; the intent is to have BIG-IP APM execute the process of uploading and storing a file.

  5. Leave the File Name and File Destination Folder settings at the default.
  6. Select Session from the Secure Level drop-down menu.
  7. Click OK.
  8. To install the update, refer to K10942: Installing OPSWAT hotfixes on BIG-IP APM systems.
