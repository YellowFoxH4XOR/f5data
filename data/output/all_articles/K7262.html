Topic

This article applies to BIG-IP ASM 9.x. For information about other versions, refer to the Displaying Reports section of the Configuration Guide for BIG-IP Application Security Manager.

Using the BIG-IP ASM Events screen, you can view client request information that does not comply with the relevant security policy. To export the BIG-IP ASM security events, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Statistics.
  3. On the Events screen, click Export.

Note: When using the option to export security events on the BIG-IP ASM system, the events are exported as a zipped archive containing XML files. The data in these files is encoded using a base64 encoding scheme, and is intended to be viewed using the Configuration utility. An exported event log can only be viewed in a BIG-IP ASM system of the same version.
