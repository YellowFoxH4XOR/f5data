K50500041: Can not apply new AS3 ConfigMap due to a broken ConfigMap

Type
Support Solution
Published
2025-06-18
Updated
2025-07-07
Applies to
  • F5 Automation and Orchestration
  • F5 BIG-IP Container Ingress Services
Source
https://my.f5.com/manage/s/article/K50500041

Description

When a broken AS3 ConfigMap (cm) is applied, the following correct AS3 could not be applied properly.
When CIS debug is enabled, errors like following could be seen repeatedly:

[DEBUG] [AS3] posting request to https://192.168.3.5/mgmt/shared/appsvcs/declare/
[ERROR] [AS3] Big-IP Responded with code: 422
[DEBUG] [AS3] Error handling for event statusCommonResponse

You can use following command to check the logs of CIS:

kubectl -n kube-system logs <CIS pod name>

For example:

kubectl -n kube-system logs k8s-bigip-ctlr-deployment-658586d886-jmnms

Environment

  • Container Ingress Services (CIS) 
  • AS3 agent
  • ConfigMap 

Cause

It will be fixed from CIS version 2.5.1.

Recommended Actions

Please delete the incorrect ConfigMap to workaround this issue.
Or please consider upgrading the CIS to the fixed version.

Additional Information

None
