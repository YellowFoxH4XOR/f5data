K2312: The BIG-IP Link Controller Link Evaluator page may display values as 0 (zero)

Topic

The Link Evaluator helps determine the best link to which users should be routed. The values for the Link Evaluator are populated by LDNS (path) probe results; however, the value fields will not populate until this probing is configured. This causes the BIG-IP Link Controller's Link Evaluator Statistics page to display all the values as 0 (zero).

Note: Link Evaluator is only associated with known LDNS requests and inbound load balancing to wide IP addresses, and is therefore not applicable to configurations where only outbound load balancing is used.

Note: Known LDNS requests and inbound load balancing means that when the BIG-IP Link Controller receives a DNS request for a wide IP, the BIG-IP Link Controller (when path probing is configured) will issue a probe to the LDNS that requested the information in order to determine the best link and resource on that link to provide.

To configure path probing, perform the following procedure:

  1. Configure at least one wide IP (domain names) to use a dynamic load balancing method, such as QoS or Round Trip Time.

    Note: For QoS, ensure that at least one of the parameters that require probe packets to be sent to LDNS is non-zero (for example, Round Trip Time).

    Note: For more specific information about configuring wide IP load balancing, refer to the BIG-IP Link Controller manual.

  2. Edit the /config/3dns/etc/wideip.conf file and add the following line to the globals section:

    include geoloc 'netIana.inc'

  3. Save and close the file.
  4. Type the following command to restart 3ndc:

    Warning: This command will cause a failover in redundant pair implementations.

    3ndc restart

The value fields on the Link Evaluator page should now populate with the appropriate values.
