Description

Customer need to change the management IP On BIG-IPs managed by BIG-IQ. Besides that customer is deploying AS3 applications via BIG-IQ. This cause situation where they couldn't remove BIG-IP without removing applications.

 

  1. How to do this without impact on BIG-IP existing applications and redeploy them again on BIG-IP?
  2. When you redeploy the same declaration on BIG-IQ, it doesn’t redeploy the Virtual server on BIG-IP?
  3. In addition, new changes made to the declaration will be reflected on the existing VIP on BIG-IP?

 

 

 

 

Environment

  • AS3
  • BIG-IQ
  • Application Deployment
  • Change Management address on BIG-IP

Cause

Work as designed

Recommended Actions

Q1 answer :

- Backup existing application declarations in notepad

- Force Delete application Based on our documentation we can force delete AS3 applications only on BIG-IQ. here is documentation for this operation:

https://clouddocs.f5.com/products/big-iq/mgmt-api/v0.0/ApiReferences/bigiq_public_api_ref/r_as3_force_delete.html

- Remove BIG-IP from BIG-IQ

- Change Management IP of BIG-IP

- Discover BIG-IP again

- Re-deploy applications via BIG-IQ setting up target device as hostname in declaration

 

"declaration": {

"class": "ADC",

"schemaVersion": "3.7.0",

"id": "example-declaration-01",

"label": "Sample 1",

"remark": "HTTP with custom persistence",

"target": {

"hostname": "test.f5.as3.local"

},

Note:

This will re-deploy applications in BIG-IQ without touching objects on BIG-IP until there is no change in declaration for existing objects

A2:

No there is no impact until declaration is not changed

 

A3: You still can manage application via BIG-IQ. Change in app will be reflected on BIG-IP. You still can add new applications
