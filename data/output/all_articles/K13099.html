Issue

Old Behavior

In versions prior to BIG-IP 10.1.0, the default value for the Slow Ramp Time pool setting is 0 (zero seconds), thereby disabling the Slow Ramp Time setting, by default, for all pools.

With Slow Ramp Time disabled, when a pool member goes offline and then comes back online, the pool member may become overloaded with connection requests, depending on the load balancing mode for the pool. For example, if you use the Least Connections load balancing mode, the system sends all new connections to the newly-enabled pool member (because that member has the least connections).

New Behavior

Beginning in BIG-IP 10.1.0, the default value for the Slow Ramp Time pool setting was changed to 10 seconds, thereby enabling the Slow Ramp Time setting, by default, for all pools.

With the Slow Ramp Time setting enabled, the system sends less traffic to the newly-enabled pool member, based on the ratio of uptime (in seconds) to the Slow Ramp Time value.

For example, assume Slow Ramp Time is set to 10 seconds, and a pool member becomes available. Once the pool member has been up for 1 second, the system begins sending to that pool member only 1/10 of the connections that would have been sent to the same pool member if it were not a member of a pool configured with the Slow Ramp Time setting. Each second, the system increases the amount of traffic sent to the pool member. After the pool member has been available for 9 seconds, the system is sending 90 percent of the normal load to the pool member. Once the pool member has been available for longer than the Slow Ramp Time value, the pool member receives its full proportion of the incoming traffic.

F5 Product Development tracked this change as ID 208624.

Impact

All pools that do not have an explicitly-set Slow Ramp Time value now inherit the default Slow Ramp Time of 10 seconds. Pools that already have non-zero Slow Ramp Time values are not impacted.  

Important: After you upgrade to BIG-IP 10.1.0, the new default value may cause load balancing failure as documented in SOL13100, which is included in the following Supplemental Information section.

Recommended Actions

If you use BIG-IP 10.1.0 through 10.2.4, you should explicitly disable the Slow Ramp Time setting on pools that also use priority groups. For the detailed procedure, refer to the Known Issue documented in SOL13100, included in the following Supplemental Information section.

For other versions, and for pools not using priority groups, no action is required.
