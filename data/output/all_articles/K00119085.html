Description

See the log below in the LTM log file /var/log/ltm:

notice tmm1[pid]: 01230114:5: port movement detected  for <MAC address>, vlan /Common<vlan name> none to vlan /Common/<vlan name> <interface / trunk name>
For example:
notice tmm1[12345]: 01230114:5: port movement detected for 00:00:5e:00:53:00, vlan /Common/VlanA none to vlan /Common/VlanA Trunk_A

Environment

  • BIG-IP
  • Vlan group
  • Log level for the net is changed to Notice or lower. The default vaule for db key log.net.level is warning.

Cause

The root cause is LTM query the MAC address for the pool member in a vlan group, when the LTM accesses the pool member, it sends ARP out on all child VLANs belonging to the VLAN-group, as it does not know where the pool member resides, it uses the VLAN-group MAC as a place holder until it know where it resides.
The impact of this should be none. So the messages level is set to "notice", user won't see the "Port movement" message unless the key log.net.level set to "notice" or lower.

Recommended Actions

Follow the K5532, change the log level log.net.level to default level.

Additional Information

None.
