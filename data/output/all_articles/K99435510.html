K99435510: Unable to delete Macro branch due to missing 'X' option in Edit Terminals setting

Source
https://my.f5.com/manage/s/article/K99435510

Description

When trying to delete a macro branch using "edit terminals" setting the option to delete "X" is missing.

Environment

  • BIG-IP APM with a Macro created and used in the access policy

Cause

This can happen if particular macro branch is configured/in-use in the access policy using this macro.

Recommended Actions

  1. In the access policy , identify all the configurations where the particular macro is called/configured and remove the branch configuration from all locations.
  2. Apply the access policy
  3. Delete the branch expression from Macro itself 
  4. Now you should see "X" option for the particular branch under "edit terminals" to remove the ending. Click on "X" to remove the macro branch ending and save it.  
  5. Apply the access policy. 
Note : If you still do not see "X" option in step 4 , try to toggle the branch terminal ending between allow/deny and you should see "X" option
