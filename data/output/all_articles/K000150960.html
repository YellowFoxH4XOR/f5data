K000150960: kswapd0 process consumes high CPU after upgrade to 17.5.0

Type
Support Solution
Published
2025-04-23
Updated
2025-05-14
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.0
Source
https://my.f5.com/manage/s/article/K000150960

Description

Using the top utility in a bash shell, you can see that the kswapd0 process consumes >90% of cpu after upgrade to 17.5.0

Figure: example output from the bash top command showing the kswapd0 process consuming a high amount of CPU.

 

Environment

  • BIG-IP LTM
  • 17.5.0
  • High CPU
  • kswapd0 process

Cause

ID1926989

Recommended Actions

First workaround can be implemented by doing the following:

  1. Run the following command from bash:
    sysctl -w vm.min_free_kbytes=24141 
  2. Save the change by running the following command: 
    sysctl -p

No reboot or tmm restart is needed.

Note: Please first perform First workaround as first step


Second possible workaround is to leave vm.min_free_kbytes at its current level, and instead increase the value of sys db provision.extramb. 

Additional Information

You may consider the steps below to create a startup script similar to the one described in article K11948, so that the changes persist after a reboot.

  1. Log in to the command line.
  2. Use a text editor to create the customized startup script /config/startup_script_sol11948.sh file. 
    #!/bin/bash
# Filename: /config/startup_script_sol11948.sh
 
source /usr/lib/bigstart/bigip-ready-functions
wait_bigip_ready
 
# Here you could perform customized command(s) after MCPD is found running when the BIG-IP system starts up.
# Customized startup command(s) can be added below this line.
 
# Workaround for ID1926989
# Uncomment the line below and replace 'xxx' with the appropriate value
# sysctl -w vm.min_free_kbytes=xxx
 
# Customized startup command(s) should end above this line.
 
# End of file /config/startup_script_sol11948.sh
  3. Enable executable mode for the /config/startup_script_sol11948.sh file. 
    chmod +x /config/startup_script_sol11948.sh
  4. Using a text editor, edit the /config/startup file. Append the following line to the end of the file: 
    /config/startup_script_sol11948.sh &
  5. Save the changes made to the /config/startup file and exit the text editor.
