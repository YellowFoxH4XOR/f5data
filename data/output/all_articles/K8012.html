Known Issue

This is the result of a known issue. If you install Cumulative Hotfix HF-601-1 or a later Cumulative Hotfix for version 6.0.1 of FirePass software, the FirePass Component Installer service will fail to update itself on client systems. Users who run the Component Installer service may observe error messages in the %USERPROFILE%\Local Settings\Temp\f5install.txt log file that appear similar to the following example:

17:03:15:281 (1216) (    0) USmartUpdateEx::RunObjectProc() - we have installer service - continue
17:03:15:343 (1216) (   63) USmartUpdateEx::RunObjectProc() - Service need update itself, waiting...
17:03:15:484 (1216) (  141) srvGetServiceVersion() - CallNamedPipe() failed, GetLastError = 2
17:03:20:484 (1216) ( 5000) USmartUpdateEx::RunObjectProc() - Service failed to update itself.

Additionally, if you enabled a pre-logon sequence, users running the Component Installer service may receive the Checking client / Installing message each time they access the pre-logon sequence page. The correct behavior is for users to receive the Checking client / Installing message the first time they access the pre-logon sequence page, when the necessary client components are initially installed.

The Component Installer is an optional Windows service that installs and upgrades client-side FirePass controller components on Windows clients. This service is useful for installing and upgrading client-side components when the user has insufficient rights to install or upgrade the components directly on the client system. For more information about using the Component Installer, refer to the FirePass Controller Administrator Guide.

Note: You can download the Component Installer on the Network Access: Client Downloads page.

F5 Product Development tracked this issue as CR83018 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass release notes.

Workaround

You can work around this issue by preventing the Component Installer service from attempting to update itself. To do so, install Cumulative Hotfix HF-601-7. F5 Product Development tracked this workaround as CR84627.

Important: Installing Cumulative Hotfix HF-601-7 will resolve the symptoms described earlier in this Solution, but it will not resolve the inability of the Component Installer to update itself.
