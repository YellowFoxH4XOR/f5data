Description

The BIG-IP system reports frequent kernel page allocation failures.

Environment

  • VIPRION with
    • B2250 (A112)
    • B4300 (A108)
    • B4340N (A110)
    • B4450 (A114)
  • Error messages similar to the following:
warning kernel: swapper/16: page allocation failure: order:2, mode:0x104020
warning kernel: CPU: 6 PID: 0 Comm: swapper/6 Tainted: P           O   ------------   3.10.0-514.26.2.el7.x86_64 #1
warning kernel: lowmem_reserve[]: 0 0 0 0

Cause

Bug ID 753650
vm.min_free_kbytes value  set too low 

Recommended Actions

  1. SSH to log into the bash prompt of the BIG-IP

  2. Run the following command:

    clsh "cat /proc/sys/vm/min_free_kbytes"

    Output returns low values:

    === slot 1 addr 127.3.0.1 color green ===
    32481
    === slot 2 addr 127.3.0.2 color green ===
    32481
    === slot 3 addr 127.3.0.3 color blue ===
    === slot 4 addr 127.3.0.4 color blue ===

    Note: "low value" is determined by blade type

3. Follow workaround in ID753650
