Topic

You should consider using this procedure under the following condition:

  • You want to view the Message Routing Framework (MRF) Diameter statistics using the Configuration utility

Description

With more Diameter protocol specific statistics collected per pool member (Diameter peer), you can view the detailed stats from the Configuration utility.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You have the necessary MRF Diameter configuration running on the BIG-IP system.
  • You have administrative access to the Configuration utility.

Procedures

Using the Configuration utility, you can view the Diameter message routing statistics from the following perspectives:

  • Per-pool member (Diameter peer)
  • Per-diameter transport configuration profile

Viewing Diameter message routing from the per-pool member (Diameter peer) perspective

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Message Routing > Diameter.
  3. Select Pool Member Stats.
  4. Select View for the pool member for which you want to view statistics.
  5. Under Profiles, for Select Profile, select the Diameter router profile.

Viewing Diameter message routing from the per-Diameter transport configuration profile perspective

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Message Routing > Diameter.
  3. Select Transport Config.
  4. Select the transport configuration for which you want to view statistics.
  5. Select Statistics.
  6. Under Profiles, for Select Profile, select the Diameter router profile.
