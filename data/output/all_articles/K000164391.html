K000164391: How to verify BIG-IP can reach activate.f5.com over outbound TCP 443

Published

Description

This procedure confirms that a BIG-IP system can resolve activate.f5.com, open a TCP connection on port 443, and complete a TLS handshake with the server. Run this check before license activation or reactivation using Automatic method. A successful result only shows the network path works and does not confirm that license activation will succeed. 

Environment

  • BIG-IP

  • Command Line (CLI)

Cause

None

Answer/Recommended Actions

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line on the BIG-IP device.
  2. Enter the following command:
    curl -ivk https://activate.f5.com
    • -i shows response headers.
    • -v shows connection details.
    • -k skips certificate verification. This test checks connectivity only.
  1. Confirm the output contains the lines in the table below.

 What to look for

    Output lineMeaning
    Trying <IP>...The hostname resolved to this IP address.
    Connected to activate.f5.com (<IP>) port 443The TCP connection to port 443 succeeded.
    < HTTP/1.1 301 Moved PermanentlyThe server responded. A 301 is a redirect to another URL.

    Result

      • If all three lines appear, the BIG-IP has outbound connectivity to activate.f5.com on TCP 443.
      • If a line is missing, the check failed at that stage:
        • No Trying line, or a "Could not resolve host" error: name resolution failed.
        • No Connected line, or the command times out: the TCP connection to port 443 failed.
