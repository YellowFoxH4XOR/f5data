Description

On F5OS tenant hosted by rSeries 5000/10000 model you cannot see interfaces name in GUI under Network >> VLANs: VLAN list, like here:

 

However on rSeries 2000/4000 you can see them:

Environment

  • F5OS-A
  • r5000/10000 platform
  • r2000/4000 platform

Cause

This is by design.

F5 rSeries r5000/10000 use FPGA drivers and rSeries 2000/4000 use SR-IOV.

So in rSeries 2000/4000 platforms each tenant is assigned a Virtual Function (VF) for each front-panel port. This allows TMM on BIG-IP tenant to "see" each front-panel port and control which interfaces it transmits on. 

This is not so on rSeries 5000/10000, because there is more complex architecture, where TMM has little control or visibility of the front-panel interfaces.
