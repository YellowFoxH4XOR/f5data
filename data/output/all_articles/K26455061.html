K26455061: F5 Access 3.x on iOS 12 fails to establish a VPN tunnel

Type
Knowledge
Published
2018-10-27
Updated
2023-02-21
Applies to
  • BIG-IP
  • F5 Access
  • BIG-IP APM: 13.0.X, 13.0.1, 13.0.0
Source
https://my.f5.com/manage/s/article/K26455061

Issue

You should consider using this procedure under the following conditions:

  • Your client device is running iOS 12.
  • You are connecting using F5 Access 3.0.0 through 3.0.2.
  •  Connections to the BIG-IP APM access profile fail.

Recommended Actions

The iOS 12 devices that use F5 Access 3.0.0 through 3.0.2 may fail to establish the VPN connection with the BIG-IP APM access profile. This issue occurs when the access profile assigned to a virtual server uses an admin-specified domain cookie.

Access sessions fail with an error message similar to the following example in the F5 Access app PacketTunnel.log file:

<date>,<time>, 417,8215,PacketTunnel, 1, VpnFavoriteListOperation.swift, 110, main(), VPN Favorites failed: Error Domain=NSXMLParserErrorDomain Code=111 "(null)"

Procedures

To help determine the access session failure, complete the following troubleshooting procedures:

  • Identifying if an access profile contains an admin-specified domain cookie
  • Checking F5 Access app logs for the domain error message

Identifying if an access profile contains an admin-specified domain cookie

The following procedure helps you identify if the access profile is configured with an admin-specified domain cookie.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Access > Profiles > Access Profiles (Per-Session Policies).

    Note: For BIG-IP APM systems earlier than 13.0.0, navigate to Access Policy > Access Profiles > Access Profiles List.

  3. Click the access profile applied to the affected virtual server.
  4. Click the SSO / Auth Domains tab.
  5. Check the SSO Across Authentication Domains section and verify that the Domain Cookie value is set to a domain name that you use for access.

Checking F5 Access app logs for the domain error message

The following procedure helps you locate the domain error within the F5 Access app PacketTunnel.log file.

Impact of procedure:  Performing the following procedure should not have a negative impact on your system.

  1. From the iOS device that is failing to establish an access session, open the F5 Access app.
  2. Go to Settings > Email Logs.
  3. In the To box, type your email address.
  4. Click Send.
  5. Save the email attachment F5AccessReport.zip file to a folder on your computer.
  6. Extract the zip archive F5AccessReport.zip.
  7. From the extracted archive, open the file PacketTunnel.log to locate an error message similar to the following example:

    <date>,<time>, 417,8215,PacketTunnel, 1, VpnFavoriteListOperation.swift, 110, main(), VPN Favorites failed: Error Domain=NSXMLParserErrorDomain Code=111 "(null)"

Resolution

If the access profile SSO / Auth Domains configuration includes an admin-specified domain cookie, and the iOS F5 Access app log file PacketTunnel.log also includes the Domain=NSXMLParserErrorDomain error message, perform one of the following procedures to restore normal access profile VPN connectivity:

  • Update the F5 Access app for iOS to 3.0.3 or later
  • Remove the domain cookie from the access profile

Remove the domain cookie from the access profile

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP Configuration utility.
  2. Go to Access > Profiles > Access Profiles (Per-Session Policies).

    Note: For BIG-IP APM systems prior to 13.0.0, navigate to Access Policy > Access Profiles > Access Profiles List.

  3. Click the access profile applied to the affected virtual server.
  4. Click the SSO / Auth Domains tab
  5. Remove the domain name from the SSO Across Authentication Domains > Domain Cookie box.
  6. Click Update.
  7. Click the Apply Access Policy link.
  8. Click Apply Access Policy.

For more information about obtaining and installing the latest version of F5 Access, refer to: K12462: Overview of the F5 Access for iOS application for Apple iPhone, iPad, and iPod touch.
