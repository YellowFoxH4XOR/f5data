Issue

After a Mac OS X or Linux user launches a Java AppTunnel, the following error message may display in the Java Console log:

java.io.FileNotFoundException: /etc/hosts (Permission denied)

This error message can typically be ignored. FirePass uses the /etc/hosts file in Mac OS X and Linux operating systems when Java AppTunnels have a hostname specified instead of an IP address. The hosts file will translate the hostname to the Java AppTunnels Local Host configured address instead of what the DNS servers would typically return. FirePass tests whether the /etc/hosts file is writeable and provides this error message to indicate that the end user does not have sufficient privileges. This test takes place even when an IP address was specified for the Remote Host as part of the Java AppTunnel configuration.
