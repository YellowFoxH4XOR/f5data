Description
When the LAN cable is disconnected from the mgmt port, the solid yellow light still remained on. 

Environment

  • BIG-IP device
  • Platform: i4000 series
  • Mgmt port
  • LED Color: Solid yellow

Cause: 
None
 

Recommended Actions

  1. Reboot the device and verify if the light on management port is off. 
    Note: Reboot the device in the maintenance window to avoid traffic disruption. 

  2. If the issue is not resolved, then proceed with running EUD diagnostic. Specifically run the LED test which is part of inter-active tests.

  3. An EUD report log is stored as the text file under /shared/log/eud.log, collect the Qkview and upload to iHealth for further analysis. 

  4. Contact F5 support for further analysis.
