Description

After starting a tcpdump session, the following error message is displayed: WARNING - The recommended number of tmm tcpdump instances (2) has been exceeded (2).


Environment

BIG-IP

tcpdump


Cause

Multiple tcpdump sessions are running on the system.


Recommended Actions

This is strictly a warning message to inform the user there are multiple instances of tcpdump running. You are allowed to run more than one tcpdump session after the warning is displayed. You can view what tcpdump processes are running on a system running the below command from bash:


ps aux | grep tcpdump


Then you can kill the process by running:


kill <pid>


If this doesn't stop it then you can try a more forceful termination:


kill -9 <pid>
