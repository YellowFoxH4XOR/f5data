Description

  • Console output is similar to the following but device is unresponsive:

    --- Press <ESC>( for AOM Menu.

  • EUD does not start when run from a USB flash drive.

Environment

  • 5200v device

Cause

Hardware failure.

Recommended Actions

Hardware replacement.

Additional Information
