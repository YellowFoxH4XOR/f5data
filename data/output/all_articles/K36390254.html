Known Issue

The NT LAN Manager (NTLM) authentication may fail when an early HTTP server response is received. This issue occurs when all of the following conditions are met:

  • The BIG-IP system is running BIG-IP 10.2.4 HF12.
  • The affected HTTP virtual server is associated with the BIG-IP NTLM profile.
An early HTTP server response occurs when the BIG-IP system is in the midst of sending the client request to the backend server, and the backend server responds with a response header without waiting to receive the entire client request.

Impact

Clients cannot upload attachments to backend servers that use NTLM authentication.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • NTLM authentication between the client and BIG-IP pool members may intermittently fail with repeated requests for re-authentication, or repeated notifications that their current credentials are incorrect.
  • Clients may fail to upload attachments to backend servers that use NTLM authentication.
