Topic

This article applies to BIG-IP 11.x. For information about other versions, refer to the following article:

  • K6768: Restricting Configuration utility access to clients using high encryption SSL ciphers (9.x - 10.x)

You should consider using this procedure under the following conditions:

  • You want to limit Configuration utility access to clients using high-encryption Secure Sockets Layer (SSL) ciphers.
  • Your BIG-IP system is running software between and including versions 11.0.0 through 11.4.1.

    Note: The Configuration utility for software versions 11.5.0 and later use only high-encryption SSL ciphers by default.

Description

High-encryption SSL ciphers include ciphers with key lengths longer than 128 bits, and some cipher suites with 128-bit keys.

By default, the Configuration utility allows for a wide range of SSL ciphers to be used in order for SSL clients to connect to the Configuration utility. If you require a smaller, more secure list of SSL ciphers for Configuration utility access, you can modify the cipher list to only allow access to SSLv3, TLSv1, and keys that are 128 bits or larger.

For example, the following default cipher string for the BIG-IP 11.0.0 Configuration utility allows short key lengths that include 56 and 64 bits:

ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2

Note: In BIG-IP 11.x, SSLv2 is disabled at the protocol level. It is not necessary to disable the SSLv2 cipher in 11.x and later.

The following replacement string allows only long and medium (128 bits or larger) key lengths; only SSLv3 or TLSv1 cipher suites, and no export or null cipher suites are allowed.

ALL:!ADH:!EXPORT40:!EXP:!LOW:!RC4

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access the Traffic Management Shell (tmsh).

Procedures

  • Listing the current Configuration utility cipher string
  • Restricting Configuration utility access to clients who use high-encryption SSL ciphers

Listing the current Configuration utility cipher string

Before you change the Configuration utility SSL cipher string, you should review the existing string for your specific BIG-IP version. To list the currently configured cipher string, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To list the currently configured cipher string, type the following command:

    list /sys httpd ssl-ciphersuite

    For example, the BIG-IP 11.0.0 system displays the following cipher string:

    ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4+RSA:+HIGH:+MEDIUM:+LOW:+SSLv2

Restricting Configuration utility access to clients who use high-encryption SSL ciphers

Impact of procedure: Clients using low-encryption SSL ciphers will not be able to access the Configuration utility.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To restrict Configuration utility access to clients using high-encryption ciphers, type the following command:

    modify /sys httpd ssl-ciphersuite 'ALL:!ADH:!EXPORT40:!EXP:!LOW:!RC4'

  3. Save the configuration change by typing the following command:

    save /sys config
