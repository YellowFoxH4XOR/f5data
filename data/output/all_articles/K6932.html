K6932: The BIG-IP ASM Policy Builder feature successfully executes in response mode but may not create the policy entities

Applies to

Topic

When the BIG-IP ASM Policy Builder feature is in response mode, and the host name configured in the Policy Builder Domains section does not match the host name in the host header of the request, the status mode will indicate that the Policy Builder feature successfully parsed all of the responses. However, the Policy Builder feature does not create the Web Objects, Object Types, Flows, and Parameter policy entities in the policy section.

You can ensure that policy entities are created by configuring the host name in the Policy Builder Domains entry to use the host name contained in the host header of the request. To do so, perform the following procedure:

  1. Log in to the BIG-IP ASM Configuration utility.
  2. Navigate to Application Security > Web Applications.
  3. Click the Web Application that you want to configure.
  4. Click Forensics.
  5. Select a request to view the full details.
  6. Locate the Host header under the Full Request section.
  7. Copy the host name used in the Host header.
  8. Click Web Applications.
  9. Click the Web Application that you want to configure.
  10. Select the Policy that you want to configure.
  11. In the Policy Builder section, click General Settings.
  12. Create a new Policy Builder Domains entry, or modify an existing Policy Builder Domains entry, using the host name copied in step 7.
  13. Run the Policy Builder feature again and ensure that the policy entities are created properly.
