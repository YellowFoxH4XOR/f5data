Description
When updating the admin password for BIG-IP deployed in AWS with BIG-IQ, the BIG-IQ responds "Unable to validate user admin" and the password update fails.

Environment

  • AWS
  • BIG-IQ 
  • BIG-IP VE

Cause
BIG-IQ uses an iControl call to the BIG-IP to determine if there is a user named 'admin' on the BIG-IP.  The BIG-IP responds with HTTP 400 "Bad Request".

Recommended Actions

It may be necessary to restart restjavad on the BIG-IP.  No negative impacts to traffic are expected from this process.

  1. From the command line of the BIG-IP, bash shell prompt, type the following:
    curl -u admin http://localhost:8100/mgmt/tm/auth/user/admin
  2. Enter the admin password when requested.
  3. If the response is something like the below text: 
    {"code":400,"message":"remoteSender:127.0.0.1, method:GET ","referer":"127.0.0.1"

    You will need to restart the restjavad service:
     tmsh restart sys service restjavad
     

Additional Information

Example of a successful response to curl -u admin http://localhost:8100/mgmt/tm/auth/user/admin should be something like this:
{
  "kind": "tm:auth:user:userstate",
  "name": "admin",
  "fullPath": "admin",
  "generation": 1,
  "selfLink": "https://localhost/mgmt/tm/auth/user/admin",
  "description": "Admin User",
  "encryptedPassword": "*****",
  "shell": "bash",
  "partitionAccess": [
    {
      "name": "all-partitions",
      "role": "admin",
      "nameReference": {
        "link": "https://localhost/mgmt/tm/auth/partition/all-partitions"
      }
