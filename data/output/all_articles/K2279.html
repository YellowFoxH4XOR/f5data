Known Issue

The LAN Adaptor LEDs on the rear panel of the 520/540 IP Server Appliances are not functioning properly in the systems that meet the following criteria:

  • 520/540 systems within the serial number range: bip037008s to bip042977s
  • Built during the following date range: 11-11-2002 and 1-27-2003

There are two failure modes:

  • Activity LEDs for ports 1.1 and 1.2 will not light when network traffic is present.
  • Activity LEDs for ports 1.1 and 1.2 will blink simultaneously even though only one 10/100 cable is connected.

Note: Although the LEDs do not function properly, this issue does not adversely affect the system in any other way.

This issue occurs because the cable connecting the motherboard to the annunciator board was not installed correctly. If you have a 520/540 that is exhibiting these symptoms, verify the motherboard part number.

Verifying the mother board part number

The motherboard part number is located on a bar-coded label near the IDE connector.

The motherboard part number is also stored in the system test file. To retrieve the motherboard part number from this file, run the following command:

grep 'MOB-00' /sbin/hwtest/bip*

If the motherboard part number is MOB-0011-xx REV xxx and the rear panel activity LEDs do not function normally, apply the following correction.

Important: Do not attempt to make this correction on systems built with MOB-0010-00 motherboards as the polarity of the LAN activity header is reversed.

Correcting the motherboard/annunciator board connection

To correct the connection, perform the following steps:

  1. Remove the PCI card access panel on the side of the 520/540 appliance.

  2. Locate the orange and green wires terminating at a 4-position header on the corner of the motherboard (Figure 1).

     

    Figure 1 - Picture of incorrect header position.

  3. Disconnect the header, reverse it and re-install it so that the white jumper wire is connected to pin 1 of the header. The white jumper wire should be closest to the corner of the motherboard (Figure 2).

     

     

    Figure 2 - Picture of correct header position.

  4. Reinstall the PCI card access panel of the 520/540 appliance.

The LEDs should now function correctly.
