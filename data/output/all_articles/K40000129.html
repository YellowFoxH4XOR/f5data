Issue

Error Message

01160009:6: Link <interface> added to aggregation

In this error message, note the following:

  • <interface> is the network interface identifier.

For example:

01160009:6: Link 1.1 added to aggregation

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following conditions are met:

  • Your BIG-IP configuration includes one or more trunks with Link Aggregation Control Protocol (LACP) enabled.
  • You have added an additional interface to the trunk configuration.

A trunk is created by configuring two or more interfaces as one link. For more information, refer to K15234: Adding trunked ports to a VLAN using the tmsh utility (11.x - 13.x)

Impact

None. The message is informational.

Recommended Actions

None
