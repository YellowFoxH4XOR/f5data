Description

"Malformed XML" violation may be displayed when the ASM XML/JSON parser runs out of memory.

Environment

  • BIG-IP ASM

Cause

ASM uses an XML/JSON parser to inspect XML/JSON requests, this parser is allocated a default amount of memory depending on the configuration, by default it is either 300 for 8GB systems or 450MB for 16GB systems or 1 GB on platforms with 32 GB of RAM or more .

Recommended Actions

You can display the current XML/JSON memory usage with the follwing commands to understand if this value should be increased.

  • Show the used XML/JSON memory use in percent:

    tmctl asm_memory_util_stats -s total_xml_mem_used,total_xml_max_mem |  awk '(c!=0&&c!=1&&$2) {print $1"KB "$2"KB " $1*100/$2"%"} {c++}'

    For example this command indicates the system has 4324KB of 300000KB (1.44133%) used:

    # tmctl asm_memory_util_stats -s total_xml_mem_used,total_xml_max_mem |  awk '(c!=0&&c!=1&&$2) {print $1"KB "$2"KB " $1*100/$2"%"} {c++}'
    4324KB 300000KB 1.44133%

  • Or show overall ASM memory stats including XML:

    tmctl -Pf /var/tmstat/blade/asm_memory_util_stats asm_memory_util_stats

    Example:

    # tmctl -Pf /var/tmstat/blade/asm_memory_util_stats asm_memory_util_stats
    Name                Value
    ------------------- -------
    blade_num                 0
    transactions              0
    vm_size             4268540
    rss_size             229700
    swap_size              1952
    total_mem_allocated      29
    total_mem_used            0
    total_max_mem       2469888
    total_xml_mem_used     4324  <-----
    total_xml_max_mem    300000  <-----
