Known Issue

curl connections with the local-port option may fail over IPsec tunnels.

This issue occurs when all of the following conditions are met:

  • You configured your BIG-IP system as an IPsec tunnel endpoint.
  • You disabled the connection.vlankeyed database variable.

Impact

The TCP handshake does not complete and the curl connection fails to establish.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H580524 on the Diagnostics > Identified > Medium screen.
  • curl connections with the local-port option fail with an error message that appears similar to the following example:

    curl: (7) couldn't connect to host

  • The TCP handshake does not complete and the curl connection fails to establish.

Workaround

To work around this issue, you can disable Clustered Multiprocessing (CMP) on the affected virtual server. To do so, perform the following procedure:

Impact of workaround: Disabling CMP may impact performance. Additionally, you should perform this procedure during a maintenance window or low traffic period to minimize any potential traffic interruption.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To disable CMP for the affected virtual server, use the following command syntax:

    modify ltm virtual <virtual_server_name> cmp-enabled no

    For example:

    modify ltm virtual CMP_vip cmp-enabled no

  3. Save the configuration by typing the following command:

    save /sys config
