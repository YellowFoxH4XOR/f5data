Description
COVID-19 has led to organizations worldwide, including F5, to ask many of their employees to work remotely. Many of these organizations are now looking at the BIG-IP Access Policy Manager (APM) as a solution, and want to:

  • Request an evaluation trial license to demo or try BIG-IP APM
  • Determine the license limits of an existing BIG-IP APM system
  • Viewing and optimize the number of established concurrent access sessions, or concurrent connectivity sessions on the BIG-IP APM system
  • Install a new APM license or an add-on APM license to your BIG-IP system
    • To enable APM features and functionality
    • To increase the maximum number of access sessions or concurrent connected users (CCU) for an existing BIG-IP APM license

Environment

  • BIG-IP APM

None

Requesting a BIG-IP APM evaluation trial license
