This article applies to BIG-IQ version 5.2. 

Add a new data collection device to your BIG-IQ cluster so that you can start managing it from your BIG-IP device data.

Description

You can use the BIG-IQ system to view and manage statistical data for your devices if you add a data collection device (DCD) to the BIG-IQ system. The DCD collects data from the BIG-IP system.

To learn how to view and manage statistical data using the BIG-IQ system, watch the following video.
