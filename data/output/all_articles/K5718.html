Multiple vulnerabilities exist in version 1 of the Internet Key Exchange protocol (IKE). IKE is used in conjunction with other protocols in the IPSec protocol suite to ensure authentication, data integrity and privacy, such as with Virtual Private Network (VPN) tunnels between remote access clients and VPN gateways or between two VPN gateways.

F5 has verified that the FirePass SSL VPN Client and FirePass controller technology do not use the vulnerable functionality of IKE. FirePass does implement an IPSec VPN feature that can be used by our customers to connect FirePass to an IPSec VPN gateway; however, the IPSec software in FirePass is configured to perform IKE authentication using a pre-shared secret.

Additionally, FirePass does not use Aggressive Mode in Phase 1 of the IKE negotiation to create the keying channel (IKE/ISAKMP Security Associations). This combination of configuration parameters eliminates the vulnerability to this attack.
