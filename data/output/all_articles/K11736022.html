Known Issue

You may be unable to connect to IPv6 virtual servers through a network access profile access session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a network access profile.
  • You configure the profile's access policy with the On-Demand Cert Auth agent.
  • You configure your BIG-IP APM system with an IPv6 virtual server.
  • You establish a network access profile access session.
  • You attempt to connect to the IPv6 virtual server using a DNS host name.

Impact

When you use a DNS host name to access IPv6 virtual servers through a network access session, the connection fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to connect to the IPv6 virtual server, the system displays an error message similar to the following example:

    Corrupted Connect Error

  • In the failed session's HTTP connection information, you find an HTTP 302 response with invalid syntax, which appears similar to the following example:

    HTTP/1.0 302 Found
    Server: BigIP
    Connection: Close
    Set-Cookie: F5_ST=1z1z1z1481156432z604800;path=/;secure
    Set-Cookie: LastMRH_Session=e60ae707;path=/;secure
    Set-Cookie: MRHSession=b98004ae93038d710191523ee60ae707;path=/;secure
    Content-Length: 0
    Location: https://[login.example.com]/my.policy

    Note: The brackets around the host name are invalid. They should only surround IPv6 addresses.
