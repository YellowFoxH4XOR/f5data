K000156035: Manually updating the protocol Inspection from a .im file

Type
Support Solution
Published
2025-09-16
Updated
2025-09-16
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.0.0, 17.1.1, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.2
  • BIG-IP AFM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000156035

Description

You have an .im file that you want to use to update the rules for inspection profiles.

Environment

AFM

Cause

You might have the .im file from another system, or provided to you by F5 as a fix for a known bug.

Recommended Actions

Follow the steps below to update the inspection profile manually from an .im file.

  1. Go to: Security > protocol security > Inspection updates:
  2. Disable auto-updates
  3. Press "Download Package", choose "From File"
  4. Upload the (.im) file
  5. After it has been uploaded, select and install the file
  6. When it is available to deploy, select and deploy it.
