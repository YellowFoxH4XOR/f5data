Description

This article clarifies the differences between the Service Check Date, Licensed Date and Licensed On.

Environment

  • Licensing
  • Virtual Edition
  • BIG-IP hardware 
  • r-Series
  • VELOS
  • Configuration Utility (Web UI/GUI)
  • Command Line (CLI)

Cause

None

Recommended Actions

Service Check Date

The service check date is located in the BIG-IP license and is the same as the date the license was last activated or the date the service contract for the device expires, whichever date is earlier.

Note: The service check date in the BIG-IP license is updated each time the license is reactivated, provided there is an active service contract for this BIG-IP system. 

Examples:

  • Active service contract ends December 31, 2020, license reactivated June 30, 2020 → Service Check Date = June 30, 2020 (license reactivation date is earlier)

  • Active service contract ends June 30, 2020, license reactivated December 31, 2020 → Service Check Date = June 30, 2020 (service contract expiration is earlier)


Licensed Date/Licensed On

The Licensed Date and Licensed On are the same field displayed in different interfaces. In GUI, it is Licensed Date whereas in CLI it is Licensed On. This date is the date that the license was first activated.
It is a semi-static value for F5's internal usage only and will only change if an allow-move has been performed on the license. 

Note:  In the event that the Licensed Date/Licensed On does change for some devices, this can be safely ignored.
