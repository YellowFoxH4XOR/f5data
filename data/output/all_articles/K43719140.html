Topic

This article discusses the expected behavior regarding Keep-Alive packets for mirrored FastL4 connections after a failover event.

Description

When a FastL4 virtual server is configured with the TCP Keep Alive Interval setting, the BIG-IP system will start sending Keep-Alive packets when these FastL4 connections have idled past the time, exceeding the value of the TCP Keep Alive Interval setting. This behavior prevents the system from timing out the FastL4 connections and expires them.

If you configure the BIG-IP system as a member of a high-availability system and you enable the FastL4 virtual server with connection mirroring, the FastL4 connections mirror to the next active system without the sequence numbers. When a failover occurs and subsequently the FastL4 connections are left idle without any traffic after the failover, the newly active BIG-IP system does not send Keep-Alive packets when these connections idle past the TCP Keep Alive Interval setting. This behavior is expected because the newly active device needs to receive at least one packet to determine the sequence number to start sending Keep-Alive packets. As a result, these connections will time out and the system will remove them.

Note: If there is traffic through the FastL4 connections after a failover and the newly active system does not send Keep-Alive packets, the system is experiencing an issue described in K08025400: Keep-Alive packets may fail to resume after a failover event.

Recommendations

You can mitigate this behavior by configuring the Idle Timeout setting to Indefinite on the FastL4 profile associated with the affected virtual server. To do so, perform the following procedure:

Impact of procedure: Depending on your application environment, configuring Idle Timeout to Indefinite may degrade the performance of the system over time.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Protocol > FastL4.
  3. Click on the name of the FastL4 profile associated with the affected virtual server.
  4. Select Indefinite from the Idle Timeout setting.
  5. To save the changes, click Update.
