K11261916: GUI > device management > overview page doesn't load after upgrading to 13.1.3.x

Updated

Source
https://my.f5.com/manage/s/article/K11261916

Description

After upgrading to 13.x, GUI page does not load completely when navigating to GUI > device management > overview or take almost 5 mins to load the page. 
No errors displayed on the page. 

/var/log/httpd/httpd_errors logs shows below errors:
Sep 15 18:46:39 L4_1 err httpd[24925]: [error] (111)Connection refused: proxy: AJP: attempt to connect to 127.0.0.1:8009 (*) failed
Sep 15 18:46:39 L4_1 err httpd[24925]: [error] proxy: AJP: failed to make connection to backend: localhost

After enabling verbose logging for configuration utility, below logs will be logged under /var/log/webui.log:
2021-09-15 18:43:20,552 DEBUG [ajp-bio-127.0.0.1-8009-exec-3] util.SystemSettings:getStartPageName - Unable to retrieve UI Start Screen value from BigDB. Defaulting to welcome page.
java.lang.NullPointerException

Environment

  • Device upgraded to 13.x 
  • Slowness in loading the page. 
     

Cause

Possible corruption somewhere in the upgrade process.
 

Recommended Actions

Log in to the command line and restart the below process. To do so, perform the following procedure:
Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To restart the tomcat process, type the following command:

    tmsh restart /sys service tomcat
    tmsh restart /sys service httpd

  3. Log back in to the Configuration utility once the processes has restarted and check if slowness persists.. 


If above steps does not resolve the issue, then upgrade the device again into new partition.
