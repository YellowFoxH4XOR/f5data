K000161407: F5OS-A 1.8.x - Memory-related SNMP OIDs in the F5-PLATFORM-STATS-MIB were changed from Counter64 to Gauge32

Type
Support Solution
Published

Updated
2026-05-25
Applies to

  • F5OS-A: 1.8.4
Source

Description

After upgrading to F5OS-A v1.8.x, memory-related SNMP OIDs (memAvailable, memFree, memPlatformUsed) in the F5-PLATFORM-STATS-MIB were changed from Counter64 to Gauge32.

As a result, SNMP queries for these OIDs return truncated values, unable to represent memory sizes above 4GB, leading to incorrect SNMP readings on large-memory systems.

 

Environment

・F5OS-A version 1.8.xx

・Memory-related SNMP OIDs in F5-PLATFORM-STATS-MIB

・SNMP monitoring tools querying memory statistics

 

Cause

 

Bug ID 2298349: F5OS: Memory-related SNMP OIDs (memAvailable, memFree, memPlatformUsed) in F5-PLATFORM-STATS-MIB truncated to 32-bit Gauge32, cannot represent values above 4GB

 

Answer/Recommended Actions

・No workaround is available; a code fix is required.
