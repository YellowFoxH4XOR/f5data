K56744244: BIG-IQ stops collecting Access events after upgrade

Type
Support Solution
Published
2020-12-16
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K56744244

Description
After Upgrade of BIG-IQ cluster to version 7.x Events from APM BIG-IP devices stops being collected by BIG-IQ Data Collection Devices.

Not seeing Events/Statistics/ Information about current  access  sessions in  BIG-IQ CM > MONITORING > Dashboard> ACCESS

Environment

  • BIG-IQ Centralized Management Cluster with Data Collection Devices
  • BIG IQ Upgrade to version 7.x
  • Stats Collection Enabled
  • Access service enabled ( SYSTEM > BIG-IQ Data Collection Devices > Services > Access )
  • No communication issues between BIG-IP and configured DCD as log destination

Cause

BIG-IQ access service hanged  after upgrade

Recommended Actions

Re-enable Access service  on BIG-IQ CM device:
  1. Go to SYSTEM > BIG-IQ Data Collection Devices
  2. Click on each DCD nodes > Services
  3. Deactivate Access service
  4. Activate Access service

Additional Information
None.
