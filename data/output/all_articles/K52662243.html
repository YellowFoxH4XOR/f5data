K52662243: ICMP traffic fails NAT traversal after upgrade to v16.1.x

Applies to

Description

ICMP traffic such as ping fails to be passed by an LTM NAT after upgrade - it is silently dropped when pinging the NAT's translation address.

Environment

  • After upgrade
  • NAT

Cause

Bug ID 1043805: ICMP traffic over NAT does not work properly.

Recommended Actions

This bug is not fixed at the time of this article's publication.

Open a Service Request with F5 Support and request an engineering hotfix for this issue.
