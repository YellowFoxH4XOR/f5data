K000148331: Client or Server drops packets if enabled PVA acceleration in blade B2150

Type
Support Solution
Published
2024-10-31
Updated
2025-04-28
Applies to
  • VIPRION Platforms
  • BIG-IP
  • VIPRION B2150 Blade
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000148331

Description

After upgrade to BIG-IP 17.1.x, if enabled pva acceleration, client or server drops packets because TCP Option Timestamp value and TCP Option Timestamp Echo Reply value are incorrect.

Hotfix for ID 1325681 do not work to fix this issue. 

Environment

  • VIPRION with A113 blade (B2150)
  • BIG-IP upgrade to BIG-IP 17.1.x
  • BIG-IP AFM enabled on BIG-IP
  • TCP timestamps used by client and server

Cause

TS cookie is enabled by default in new TCP ACK TS vector which is introduced in BIG-IP 17.1.x release.

However tscookie support is not there for A113 blade (B2150)

Bug ID 1691505

Recommended Actions

Disable tscookie of TCP ACK TS vector.

 

Show current value of tscookie of tcp-ack-ts.

#tmsh list security dos device-config dos-device-config dos-device-vector { tcp-ack-ts { tscookie }}

 

To disable tscookie of tcp-ack-ts, command as below.

#tmsh modify security dos device-config dos-device-config dos-device-vector { tcp-ack-ts { tscookie disabled }}

#tmsh save sys config
