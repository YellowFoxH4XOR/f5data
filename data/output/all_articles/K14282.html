Known Issue

The additional license capacity for BIG-IP APM may not be applied when adding a User Connectivity License (CCU) add-on key.

This issue occurs when the following condition is met:

  • BIG-IP APM is configured in a high availability environment.

The BIG-IP cluster maintains an in-memory copy of the current CCU that is replicated to all members of the device group. You must reboot all devices in order to clear the current state of the CCU.

Impact

BIG-IP APM may not allow the number of active sessions licensed.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP APM may log an error message in the /var/log/apm file that appears similar to the following example:

    warning tmm1[16201]: 01490508:4: 3b533fac: Global concurrent access session limit reached.

  • Users receive the following error message:

    The maximum number of concurrent user sessions has been reached. No new user sessions can start at this time.

Workaround

To work around this issue, you can reboot all the BIG-IP systems in the device group simultaneously.

Impact of workaround: Traffic to the BIG-IP cluster will be disrupted during the reboot process.
