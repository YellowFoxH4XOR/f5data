Known Issue

This is the result of a known issue. A pre-logon sequence that determines whether a Windows client is running Norton Antivirus 2007 or Norton Antivirus 2008 fails to detect a running instance of the software on Windows Vista clients. Windows Vista clients are directed to the other branches of the pre-logon sequence, even if the Norton Antivirus software is running. This issue occurs when both of the following conditions are met:

  • The user connects to the FirePass controller using Internet Explorer 7 (IE7) for Windows Vista
  • Protected Mode is enabled in IE7

Protected Mode is a security feature introduced in IE7 for Windows Vista. Information about Protected Mode, is available at the following location:

http://windowshelp.microsoft.com/Windows/en-US/Help/95211ecc-19b5-439a-b6c5-e2aefd8013031033.mspx

Note: This link takes you to a resource outside of AskF5, and it is possible that the documents may be removed without our knowledge.

F5 Product Development tracked this issue as CR89095 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Workaround

Users can work around this issue by performing one of the following four actions:

  • Add the URL of the FirePass controller to the IE7 Trusted Sites zone. For information about configuring the Trusted Sites zone, refer to the Microsoft IE7 documentation.

    Important: By default, Protected Mode is disabled in IE7 for the Trusted Sites zone. If Protected Mode is enabled for this zone, use one of the alternate workarounds listed below, instead.

  • Connect to the FirePass controller using an alternate browser, such as Firefox.
  • If the user has administrator privileges on the Windows Vista system, the user can right-click on Internet Explorer and select the Run as administrator option when launching Internet Explorer. This setting allows the FirePass client-side component to detect Norton Antivirus 2007 or Norton Antivirus 2008.
  • If the user does not have administrator privileges on the Windows Vista system, the user can disable Protected Mode in Internet Explorer. F5 does not recommend this workaround, as it may decrease the security of the Window Vista system. For information about disabling Protected Mode, refer to the Microsoft IE7 documentation.
