K16661: Installing the latest BIG-IP ASM signature file when the BIG-IQ system has no access to the Internet

Topic

You should consider using this procedure under the following condition:

  • Your BIG-IQ system does not have direct connectivity to the Internet to download current BIG-IP ASM signature files.

Description

Your BIG-IQ system may not have direct access to the Internet to update the locally stored ASM signature files. Using the BIG-IQ command line, you can create and install an ASM signature file into the BIG-IQ signature file database.

Once you have installed the ASM signature file, you can update the BIG-IP ASM devices in the network using the BIG-IQ user interface.

Prerequisites

You must meet the following prerequisites to use this procedure:

  • You are using BIG-IQ Security to manage multiple BIG-IP ASM devices.
  • You have a host computer that has access to the Internet.
  • You have root user access to the BIG-IQ system.

Procedures

Download ASM signature files to your local workstation

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to your local workstation.
  2. Locate the ASM attack signatures; they are available from the F5 Downloads site, under the version of the BIG-IP system that you plan to update.
  3. Select and download the ASM-LatestSignatureFile to your local workstation.
  4. To Secure Copy (SCP) the ASM signature file to the /shared/tmp directory on the BIG-IQ system, use the following command syntax:

    scp <ASM signature file name>.im root@<BIG-IQ_IP-Address>:/shared/tmp

    For example, to SCP the ASM signature file named ASM-SignatureFile_20150416_214214.im to the BIG-IQ system with IP address 192.168.1.100, type the following command:

    scp ASM-SignatureFile_20150416_214214.im root@192.168.1.100:/shared/tmp

Installing an ASM signature file into the BIG-IQ signature file database

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IQ system as root user.
  2. Convert the date stamp in the ASM signature file name to milliseconds, using the following command syntax:

    date -d "<Date from file name>" +"%s%N" |cut -b1-13

    For example, to convert the date stamp from the downloaded ASM signature file, 20150416_214214, type the following command:

    date -d "16-Apr-2015 21:42:14" +"%s%N" |cut -b1-13
    1429245734000

  3. Create a file with the relevant metadata for the BIG-IQ database using the following command syntax:

    file_contents=`cat /shared/tmp/<ASM signature file name>.im | base64`;printf "{fileName: \"<ASM signature file name>.im\",productVersion:\"<Product Version>\", signatureFileVersion:\"<millisecond conversion>\", isUserDefined:\"false\", file:\"%s\"\n}" "$file_contents" > <installation file>;

    For example, using the BIG-IP product version, the file name of the downloaded ASM signature file, and the millisecond conversion from step 2, create a file named create_sig_file.json to be installed in the BIG-IQ database by typing the following command:

    file_contents=`cat /shared/tmp/ASM-SignatureFile_20150416_214214.im |base64`; printf "{fileName: \"ASM-SignatureFile_20150416_214214.im\",productVersion:\"11.6.0\",signatureFileVersion:\"1429245734000\",isUserDefined:\"false\",file:\"%s\"\n}" "$file_contents" > create_sig_file.json;

  4. To install the ASM signature file into the BIG-IQ database, type the following command:

    curl -X POST -d @create_sig_file.json http://localhost:8100/cm/asm/signatures/repository/signature-files-handler --referer http://localhost: | json-format
