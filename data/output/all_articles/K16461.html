Known Issue

ECDHE_ECDSA and DHE_DSS ciphers do not work with OpenSSL 1.0.1k and later.

This issue occurs when all of the following conditions are met:

  • You have configured the BIG-IP system to process Secure Sockets Layer (SSL) traffic using a Client SSL profile.
  • You attempt to create a new SSL connection using OpenSSL version 1.0.1k or later s_client utility.
  • The new SSL connections attempt to negotiate any of the ECDHE_ECDSA or DHE_DSS ciphers.

Impact

SSL connections using OpenSSL s_client are not successful.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • SSL connection attempts fail with a bad signature error message when using OpenSSL s_client.

    For example:

    # openssl s_client www.test.f5.com -connect 192.168.10.100:443

    CONNECTED(00000003)
    depth=0 C = US, CN = F5 Networks, Inc.
    verify return:0
    139770220258976:error:1408D07B:SSL routines:SSL3_GET_KEY_EXCHANGE:bad signature:s3_clnt.c:1844:
