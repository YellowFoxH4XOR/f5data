Description

When a client makes an HTTP request to the server, the server issues a status code with a server response.

HTTP response status codes:

  • 1xx: Informational - Request received, continuing process
  • 2xx: Success - The action was successfully received, understood, and accepted
  • 3xx: Redirection - Further action must be taken in order to complete the request
  • 4xx: Client Error - The request contains bad syntax or cannot be fulfilled
  • 5xx: Server Error - The server failed to fulfill an apparently valid request
     

Environment

  • BIG-IP
  • Since F5 acts as a proxy between the client and server, identifying the source of the response code is crucial. 

     
     
  • If the response code is by the server, the troubleshooting focus should shift to the server response.
     

    For Example: 

    Client IP:                  10.10.20.16
    Virtual Server IP:          10.10.20.101
    Floating / Self IP:         10.10.20.19
    Server IP Address:          10.10.20.10

     

Cause

None.

Recommended Actions

  1. To identify the response code, you can collect a packet capture on F5 and decrypt the capture to view the plain text format.
  2. To collect the capture on F5, you may refer to the article K411, K10209 and K12783074.
