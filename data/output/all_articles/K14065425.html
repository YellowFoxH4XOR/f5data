Description

  • You want to configure your Virtual Server to use Client Certificate Constrained Delegation (C3D) feature.
  • This feature allows the BIG-IP to forge a client certificate for use in server-side client certificate authentication. The forged certificate is generated using information from a client certificate provided in the client-side ssl handshake.
To enable C3D for BIG-IP SSL Orchestrator, refer to K93385156: Enable C3D for BIG-IP SSL Orchestrator???????

Environment

  • LTM Constrained Delegation Feature.
  • Client side SSL Profile.
  • Server Side SSL Profile.

Cause

None

Recommended Actions

Prerequisites:

  • You must have a CA-Bundle used to validate incoming client certificates. This will be used in the Client SSL profile for Client Certificate Authentication.
  • You must have a Certificate and Key for Reverse Proxy. This will be used as the certificate and key for the Client SSL profile.
  • You must have a CA Certificate and Key that has the ability to create new certificates. This will be used in the Server SSL profile in both the main profile configuration and the Client Certificate Constrained Delegation (C3D) configuration.
To configure Client Certificate Constrained Delegation (C3D), perform the following steps:
  • Importing the required Certificates and Keys
  • Configuring the Client SSL profile
  • Configuring the Server SSL Profile
  • Attaching the Client SSL and Server SSL profiles to a Virtual Server
Importing the required Certificates and Key

To import the required Certificates and Keys, refer to the following articles:   

  • K14620: Managing SSL certificates for BIG-IP systems using the Configuration utility
  • K15462: Managing SSL certificates for BIG-IP systems using tmsh

Configuring the Client SSL profile

  1. Log in to the Configuration Utility
  2. Click Local Traffic
  3. Navigate to Profiles > SSL > Client
  4. Click the name of the Client SSL profile to modify, or click Create... to create a new one
  5. In the Certificate Key Chain field, click Add
  6. In the popup window, select the appropriate Certificate, Key, and Chain then click Add
  7. In the Client Certificate field, select either request or require
  8. In the Trusted Certificate Authorities field select the appropriate CA-Bundle
  9. In the Advertised Certificate Authorities field, select the appropriate CA-Bundle (optional)
  10. In the Client Certificate Constrained Delegation field, select Enabled
  11. In the OCSP field, select the appropriate OCSP profile (optional)
Configuring the Server SSL profile
  1. Log in to the Configuration Utility
  2. Click Local Traffic
  3. Navigate to Profiles > SSL > Server
  4. Click the name of the Server SSL profile to modify, or click Create... to create a new one
  5. In the Certificate and Key fields, select a certificate and key. This will be used as the template for forged client certificates and is recommended to be a local self-signed certificate and corresponding private key. It is acceptable to use the default.crt and default.key for this configuration item.
  6. In the Frequency field, select always

    Note: Under normal conditions, the BIG-IP system attempts to resume existing SSL sessions whereby the server does not send a Certificate Request message. To enforce the client certificate authentication, you set the frequency to Always. Alternatively, you can also set a zero-length cache value in the server SSL profile. F5 recommends performing this change and monitoring the time your application loads.

  7. In the Client Certificate Constrained Delegation field, select Enabled
  8. In the CA Certificate and CA Key fields, select the Certificate and Key used to forge new client certificates
Attaching the Client SSL and Server SSL profiles to a Virtual Server
  1. Log in to the Configuration Utility
  2. Click Local Traffic
  3. Navigate to Virtual Servers > Virtual Server List
  4. Click the name of the Virtual Server
  5. In the SSL Profile (Client) field, move the Client SSL profile that was created or modified to the Selected column
  6. In the SSL Profile (Server) field, move the Server SSL profile that was created or modified to the Selected column
  7. Click Update to save the changes
