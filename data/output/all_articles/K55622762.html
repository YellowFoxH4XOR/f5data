Known Issue

The gtm_add utility may fail if the BIG-IP DNS (formerly known as BIG-IP GTM) configuration of the target system contains a custom BIG-IP DNS monitor

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is running 12.0.0, 11.6.0 HF6, or 11.5.3 HF2.
  • You run the gtm_add utility to pull the BIG-IP DNS configuration to another BIG-IP DNS system
  • There is a custom BIG-IP DNS monitor on the BIG-IP DNS sync group member that you used as the target for the gtm_add utility.

Impact

Users cannot add new BIG-IP DNS systems to a sync group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • New BIG-IP DNS sync group members are not in sync with the rest of the sync group after running the gtm_add utility.
  • In the /var/log/ltm log file of the BIG-IP DNS system that gtm_add was used on, you observe an error message similar to the following example:

    err mcpd[1234]: 01070043:3: Monitor /Common/<monitor_name> parent not found.
