Description

While trying to filter with Client IP address with HTTP Analytics report, it not getting any data.

  • You have Analytics report and you'd like to get filter by Client IP
  • Your VS associated with Analytics report is different then default partition /Common  

Environment

  • Using BIG-IP AVR to generate HTTP analytics reports

Cause

The Analytics profile by default adding %0 to the Filtered IP address - Which means it 'tells' the filter to search it in default partition /Common (aka RD %0).

Recommended Actions

To generate the report, you should append the route domain ID notation (%X) to each IP in the list:
If the requested IP is 10.1.1.1, the user should add 10.1.1.1%X to the list (X is the id of the routing domain)
