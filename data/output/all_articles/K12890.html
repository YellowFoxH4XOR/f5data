Data Guard pattern matching and exception patterns

In BIG-IP ASM 9.x, all values that meet the defined Data Guard matching criteria generate a Data Guard Information Leakage violation and are blocked and masked appropriately, as defined in the configuration options of the specific security policy.

As a result of a Request for Enhancement (RFE), tracked as ID346377, you can now add an exception pattern to a BIG-IP ASM 9.4.8 configuration by using the new information_leakage_exception_pattern internal parameter. A value that matches the exception pattern defined by the information_leakage_exception_pattern parameter does not generate Data Guard Information Leakage violations, and is not masked.

Configuring an exception pattern in BIG-IP ASM 9.4.8

F5 has released this configuration option in a hotfix. To request the hotfix, contact F5 Technical Support, referencing this article number and the associated ID number.

After you have received the hotfix, configure the exception pattern with the information_leakage_exception_pattern parameter. To do so, perform the following procedure:

  1. Install the hotfix provided by F5 Technical Support.

    Note: For details on installing the hotfix, refer to K6845: Managing BIG-IP product hotfixes (9.x).

  2. Log in to the BIG-IP ASM command line.
  3. Add the information_leakage_exception_pattern parameter and the exception pattern using the following syntax:

    #/ts/off_tools/add_del_internal add information_leakage_exception_pattern '<regex>'

    In the syntax, <regex> is the Perl-Compatible Regular Expression (PCRE) you want to define as an exception pattern. For example, to add the regular expression [\d][\d][\d]-[5][2]-[\d][\d][\d][\d] as an exception pattern, you would type the following command:

    #/ts/off_tools/add_del_internal add information_leakage_exception_pattern '[\d][\d][\d]-[5][2]-[\d][\d][\d][\d]'

  4. Restart the BIG-IP ASM system by typing the following command:

    Important: This step causes a brief traffic disruption.

    bigstart restart asm

After you have set the information_leakage_exception_pattern parameter value using the previously-detailed process, you can make additional modifications to the exception pattern using the Configuration utility. The parameter is visible from the Application Security menu by navigating to Options > Advanced Configuration.
