Description

Want to extract the SNI server name


Environment

  • BIG-IP
  • iRule

Cause

Want to review and take advantage of the SNI server name information.

 Recommended Actions

The following iRule extracts the SNI server name.


when CLIENTSSL_HANDSHAKE {

  if { [SSL::extensions exists -type 0] } {

    binary scan [SSL::extensions -type 0] {@9A*} sni_name

    log local0. "sni name: ${sni_name}"

  }

}


Note: The "@9A*" in the example above moves the cursor by 9 bytes and scan the 10th bytes and the remaining bytes in string into the variable "sni_name".
