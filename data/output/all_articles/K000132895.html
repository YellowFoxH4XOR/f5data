Description

  • Unexpected failover event in HA environment
  • Cannot access the device via console, SSH and Configuration Utility, LCD.
  • In the log /var/log/sel, get the log below:
INF BMC OEM(c6) #90 CPU IERR asserted 6f [0b ff ff]
INF BMC OEM(c6) #90 CPU MCERR asserted 6f [0c ff ff]
INF BMC OEM(c6) #90 CPU IERR asserted 6f [0b ff ff]
INF CPU0 HW Correctable Error
INF CPU0 Non-Fatal Event
INF CPU0 Fatal Error
INF Host Reset Event
INF BMC OEM(c6) #90 CPU IERR deasserted ef [0b ff ff]

Environment

  • i4000 Series
  • BIG-IP

Cause

CPU hardware issue

 Recommended Actions

  1. Run the EUD.
  2. Contact F5 support and raise case. 

Additional Information

It should be hardware issue, F5 support will further investigate it, RMA it after confirmation.
