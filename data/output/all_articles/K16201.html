Known Issue

Searching for a wide IP (WIP) alias may fail if a WIP contains an alias in the same domain.

This issue occurs when all of the following conditions are met:

  • Both a WIP and an alias share the same domain name.
  • You are attempting to use the search function within the BIG-IP GTM Wide IP List menu.

Impact

Searching for a wide IP alias may fail to return results.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H509118 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system fails to return records when searching for a valid WIP alias search string.

Workaround

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Using tmsh to display all wide IP aliases

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. List wide IP aliases by typing the following command:

    list gtm wideip aliases

  3. To search for a specific wide IP alias, you may filter your search term through grep, by using the following command syntax:

    list gtm wideip aliases | grep <search_term>

    For example:

    list gtm wideip aliases | grep test.com
