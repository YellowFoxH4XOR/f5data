Description

When  trying to retrieve the MAC address of the device by running the command 'tmsh show sys mac-address | grep -i interface',  you get the following error message:
"Unexpected Error: Database connection could not be established."

Environment

  • SSLO is provisioned
  • Neither APM nor URLDB is provisioned
  • Run the generic tmsh list command

Cause
Bug ID 749036

Recommended Actions

Provision APM or URLDB. You can provision APM or URLDB even if they are not licensed. Although the full feature set is not available without a license, provisioning loads the daemons needed to support the generic 'tmsh list' command.
