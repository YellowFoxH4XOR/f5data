Known Issue

Installing the Thales hardware security module (HSM) components on the BIG-IP system may fail.

This issue occurs when the following condition is met:

  • You configured the Remote File System (RFS) component on the BIG-IP system.

Impact

You are unable to use the Thales HSM with the BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Thales installation script fails to complete and returns a message that appears similar to the following example:

    Adding BIG-IP to the RFS server ...
    You must supply an IP address with --gang-noauth.
    Usage: rfs-setup
    rfs-setup <ADDRESS> <ESN> <KEYHASH>
    rfs-setup --gang-client <ADDRESS> <ESN> <KEYHASH>
    rfs-setup --gang-client --write-noauth <ADDRESS>
    ERROR: Could not add BIG-IP to the RFS server using SSH.
    Run '/opt/nfast/bin/rfs-setup --force -g --write-noauth <BIG-IP IP address>'
    on the RFS server to add BIG-IP to the RFS server and then answer the below question.
    Did you successfully run the above 'rfs-setup' command on the RFS server? (Yes/No) :
  • Answering No to the previous prompt causes the script to exit.
  • Answering Yes to the previous prompt results in a ckinfo failure message.

Workaround

To work around this issue, you can run the installation script using the RFS server IP address. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. Run the nethsm-thales-install.sh script. Note the IP address used by the RFS server. You will use this IP address in step 5.

    For example:

    nethsm-thales-install.sh --hsm_ip_addr=<ip_addr> --rfs_interface=<interface>
  3. Pause at the following prompt and proceed to step 4:

    Did you successfully run the above 'rfs-setup' command on the RFS server? (Yes/No) :
  4. Open a second SSH connection to the BIG-IP system in a new window.
  5. Type the following command, replacing x.x.x.x with the RFS server IP address you noted in step 2:

    /opt/nfast/bin/rfs-setup --force -g --write-noauth x.x.x.x
  6. Return to the SSH screen from step 3 and type Yes.

    The script should now exit with a success message.
