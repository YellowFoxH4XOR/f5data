Description

Err (error) level messages in /var/log/gtm log when DNS (GTM) SSL monitors such as https are used and are unable to connect to the monitored target IP address:
err big3d[4658]: 01330014:3: CSSLSocket:: Unable to get the session.

These messages do not indicate the IP address or port of the target that failed to connect, and this ambiguity may cause concern.

Environment

  • BIG-IP GTM/DNS
  • Upgrade to version 13.1.0 or higher
  • 01330014:3: CSSLSocket:: Unable to get the session

Cause

Bug ID 885201

Recommended Actions
These messages can be safely ignored. Nevertheless, If you want to suppress these messages, you can configure a Syslog filter.

To modify an existing Syslog configuration to use a filter to suppress the unwanted CSSLSocket:: Unable to get the session messages, perform the following procedure:
Impact of procedure: The BIG-IP system will now suppress (filter) "CSSLSocket:: Unable to get the session" messages from the messages sent to remote Syslog servers.

  1. Log into tmsh by entering the following command:
    tmsh
  2. To edit the current Syslog configuration, enter the following command:
    edit /sys syslog all-properties

  3. Press i to go to the insert mode and modify the include option:

    list /sys syslog all-properties
    sys syslog {
        auth-priv-from notice
        auth-priv-to emerg
        console-log enabled
        cron-from warning
        cron-to emerg
        daemon-from notice
        daemon-to emerg
        description none
        include "
        filter f_local2 {
            facility(local2) and not match(\"01330014\");
        };
        destination d_gtm {
            file(/var/log/gtm create_dirs(yes));
        };
        log {
            source(s_syslog_pipe);
            filter(f_local2);
            destination(d_gtm);
        };
        "
            iso-date disabled
        kern-from debug
        kern-to emerg
        local6-from notice
        local6-to emerg
        mail-from notice
        mail-to emerg
        messages-from notice
        messages-to warning
        remote-servers none
        user-log-from notice
        user-log-to emerg
    }

  4. Press "ESC" to go out from insert mode
  5. Exit the text editor by typing the following key sequence:
    :wq!

    Press y to save the changes to the file:
    Save changes? (y/n/e)

    The tmsh utility prompt returns.

    Note: If the Syslog filter contained syntax errors, the tmsh utility returns the following prompt: There were errors. Continue editing (y) or discard changes (n) (y/n)

    The BIG-IP system now sends Syslog traffic to the remote servers using the defined Syslog filter.
     
  6. Save the configuration by entering the following command:
    save /sys config partitions all
