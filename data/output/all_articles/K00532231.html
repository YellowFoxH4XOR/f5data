Description

VIP with client-ssl profile attached stops passing traffic and the client-ssl profile stats in the GUI is showing 'No Data' for all stats.

Example:

Statistics  ››  Module Statistics : Local Traffic  ››  Virtual Servers : myVIP

Select Profile myclientssl

...

Certificates / Handshakes
Valid Certificates  No Data
Invalid Certificates  No Data
No Certificate  No Data
Mid-Connection Handshakes  No Data
Secure Handshakes  No Data
Current Active Handshakes  No Data
Insecure Handshakes Accepted  No Data
Insecure Handshakes Rejected  No Data
Insecure Renegotiations Rejected  No Data
Extended Master Secret Handshakes  No Data

....

This indicates that the client-ssl profile has failed to load and the VIP will fail to process traffic.  Review the /var/log/ltm logs to identify what caused the client-ssl profile failure.

In this example we see that the CRL file could not be loaded to the client-ssl profile:
 

crit tmm1[12868]: 01260027:2: Profile /Common/myclientssl - cannot load CRL /config/filestore/files_d/Common_d/certificate_revocation_list_d/:Common:mycrl_203953_8: Unknown error.
crit tmm1[12868]: 01260000:2: Profile /Common/myclientssl: could not load CRL

 

Environment

  • BIG-IP
  • VIP stops working
  • Client-ssl profile stats showing 'No Data' in GUI
  • Could not load CRL

Cause

ID964673

CRL file is invalid or corrupt.

Recommended Actions

Follow these steps to troubleshoot and recover from this error:
  1. Inspect the CRL file referenced in the error message.
  2. Re-import a known valid CRL file and replace the original object attached to the client-ssl profile.
  3. Detach the client-ssl profile from the VIP, click Save.
  4. Re-attach the client-ssl profile to the VIP, click Save.
Important: It is necessary to re-attach the client-ssl profile after a valid CRL file has been imported for the new changes to take effect.
