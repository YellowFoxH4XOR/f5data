K000148018: Is it possible to modify the Validation Record to not have underscores?

Type
Support Solution
Published
2024-11-08
Updated
2025-12-01
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Management
Source
https://my.f5.com/manage/s/article/K000148018

Description

This article addresses whether it is possible to customize the DNS validation record (such as for ACME/Let's Encrypt) to avoid underscores, which may be restricted by some DNS policies.
Some organizations have DNS policies that do not allow records containing underscores, and users may want to modify the validation record format to comply.

Environment

  • F5® Distributed Cloud
  • DNS management

Cause

The CNAME validation record is defined by the ACME protocol and cannot be customized to remove underscores.

Answer/Recommended Actions

No, it is not possible to modify the validation record to remove underscores. Customizing the CNAME record is not supported because the format is defined by the ACME protocol.
