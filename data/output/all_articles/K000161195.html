K000161195: Static Routes in Non-Common Partitions Not Visible in GUI

Type
Support Solution
Published
2026-05-10
Updated
2026-05-10
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1, 17.1.3
Source
https://my.f5.com/manage/s/article/K000161195

Description

When deploying BIG-IP LTM VE in AWS with HA across different availability zones, static routes created in a non-Common partition (such as LOCAL_ONLY) may not be visible in the GUI and can result in configuration errors. Key issues include:

  • Static routes created in the LOCAL_ONLY partition via the GUI are not visible or are incorrectly placed under /Common.
  • Routes created via tmsh in LOCAL_ONLY are correctly written to the partition configuration file but do not appear in the GUI and may not function as expected.
  • Attempts to add additional routes in LOCAL_ONLY result in a configuration error indicating a duplicate route exists, referencing an IPv6 (::) prefix for what should be an IPv4 route.
  • Example error message:

01070734:3: Configuration error: invalid static route, the dest/netmask pair ::/ffff:ffff:ffff:ffff:ffff:ffff:ffff:ffff already exists for /LOCAL_ONLY/10.10.1.0_24

  • This behavior is observed in BIG-IP LTM VE versions 17.1.3.2 and later.

Environment

  • Product: BIG-IP LTM VE
  • Deployment: AWS, HA across multiple availability zones
  • Partition: LOCAL_ONLY (non-Common)
  • Versions affected: 17.1.3.2 and later
  • Configuration: Static routes created in non-Common partitions via GUI and CLI

Cause

Bug ID 2264009.

Answer/Recommended Actions

  1. Workaround:
    • When creating routes via the GUI, specifying the full path (e.g., /LOCAL_ONLY/my_route) may force the route to the correct partition, but it will still not display in the GUI.
  2. Permanent Fix:
    • A fix is available to address this issue. Contact F5 Support to obtain and apply the fix for your affected version.
  3. Additional Guidance:
    • Review F5 article K4918: Overview of the F5 critical issue hotfix policy.
  4. If you encounter this issue:
    • Collect and provide qkview and configuration files to F5 Support.
    • Reference Bug ID 2264009 when contacting support.

Additional Information

  • The issue affects not only static routes but also the creation and management of other objects in non-Common partitions.
  • The GUI appears to default to the /Common partition, even when another partition is selected.
  • The fix should be tested in a non-production environment before deployment to production systems.
