Description

  • All services up, GTM responding with SERVFAIL
  • /var/log/ltm:
    Jan 1 12:00:00 bigip1 warning statsd[5529]: 011b090f:4: DNS Services request rate limiter engaged.
    Jan 1 12:00:14 bigip1 warning statsd[5529]: 011b0910:4: DNS Services request rate limiter disengaged.

Environment

  • BIG-IP GTM/DNS, with Rate-limited license.

Cause

If you are using a rate-limited license, the BIG-IP DNS will respond with SERVFAIL for all queries above the RPS limitation. This can be verified by running the following command:

tmsh show ltm profile dns

    Licensed Service Rates              DNS        GTM
    Effective Rate Limit (RPS)           50          8
    Configured Object Count               0        357
    Rate Rejected Requests             4.9M      75.8K          <--------------here

The Rate Rejected Requests are DNS queries which exceed the license limits on the system. In this example, the system is capped at 50 Requests Per Second (RPS). Those client requests will receive normal DNS replies, but anything above that RPS ceiling will receive SERVFAIL.

Recommended Actions:

Reduce traffic volume to the DNS system. Or, coordinate with your F5 Account/Sales team to acquire a bigger license.
