K5415: FirePass interaction with Microsoft Remote Desktop client access licensing

Topic

FirePass includes an ActiveX control that directs the Microsoft Remote Desktop client to connect to the server through FirePass. The FirePass ActiveX control does not change the behavior of the client or the server in any way, other than to direct the Microsoft Remote Desktop client to connect to the server through FirePass.

Microsoft Remote Desktop client access licensing is performed in exactly the same manner, whether or not FirePass is involved in the session.
