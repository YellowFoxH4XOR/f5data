K10406: The MySQL database may become corrupted after a power outage or power cycle

Topic

The BIG-IP ASM MySQL database may become corrupted after a loss of power or intentional power cycle, causing the MySQL daemon to repeatedly crash and restart. The ASM process, which is dependent on the msqld process, also repeatedly restarts, and the ASM system is unable to process traffic.

If you experience this issue, you may need to re-install the BIG-IP ASM software to restore functionality. For information about installing the BIG-IP ASM software, refer to the BIG-IP ASM release notes for your version.

F5 Product Development is tracking an enhancement as ID 208212 (formerly CR121832) to detect and recover any data they may have resulted due to a MySQL database corruption. This enhancement has been included in BIG-IP version 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.

In addition, the enhancement has been added in Hotfix-BIGIP-10.0.1-342.0-HF1, which has been issued for BIG-IP version 10.0.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.
