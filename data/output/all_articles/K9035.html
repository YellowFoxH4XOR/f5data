Known Issue

This is the result of a known issue. If you configure a FirePass master group to use Active Directory (AD) authentication, and your AD server is running the Windows Server 2008 operating system, AD authentication fails. Similarly, if you configure dynamic group mapping with an AD mapping method, and your AD server is running the Windows Server 2008 operating system, AD dynamic group mapping fails.

F5 Networks Product Development tracked this issue as CR100626 and it was fixed in FirePass versions 6.0.3 and 6.1.0. For information about upgrading, refer to the FirePass Release Notes.

This issue was fixed in cumulative HF-602-6, which has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

Important: FirePass versions prior to version 6.0.2 will not support Windows Server 2008 AD authentication.
