Known Issue

This is the result of a known issue. If a user mounts an NFS share using NFSv3 TCP, the user may experience slow performance when accessing that share through a redundant pair of ARX 500 systems.

If the user mounts the same share using NFSv3 UDP, no performance issues are observed. For example, copying a file from the NFS share may take several seconds when using NFSv3 UDP, and several minutes when using NFSv3 TCP.

F5 Product Development tracked this issue as ARX ID 35152 and it was fixed in ARX versions 3.2.3 and 5.0.5. For information about upgrading, refer to the ARX release notes.

This issue has been fixed in a hotfix available for ARX version 4.1.1. Customers affected by this issue should request the hotfix from F5 Technical Support, referencing this article number and ARX ID 35152.
