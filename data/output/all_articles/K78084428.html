K78084428: How to force ntpd to sync to a specific NTP server

Description

This article will provide steps for you to force your BIG-IP/BIG-IQ to do a NTP sync to a specific NTP server.

Environment

  • BIG-IP/BIG-IQ
  • NTP server (NTP has to be network reachable)

Cause

None.

Recommended Actions

Follow the steps below to force BIG-IP/BIG-IQ to sync it's time with a specific NTP server.

  1. Log in to the BIG-IP/BIG-IQ CLI.
     
  2. stop ntpd service:
    tmsh stop sys service ntpd
     
  3. manually trigger sync ( save the output of this command):
    ntpdate -bv <ntp_server_ip_address>
     
  4. restart ntp again:
    tmsh start sys service ntpd
     
  5. Leave it for sometime and check if the BIG-IP/BIG-IQ is syncing with the Windows NTP server with the following command:
    ntpq -pn
