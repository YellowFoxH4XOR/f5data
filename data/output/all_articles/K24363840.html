Description

HA shows config is in sync, however they are both in Active-Active while config expected to be Active-Standby.  The traffic group shows, Initializing / Not Synced. Device Management -> Devices shows the peer device Offline on both sides.

Environment

  • BIG-IP LTM
  • High-Availability Config

Cause

Failover IPs not configured on cm/device

Recommended Actions

Configuring a Failover Unicast and Management Address 

Before you configure the system to pass network failover traffic over a secure channel, you must configure a failover unicast address (if one is not already configured). To configure a Failover Unicast address and Management IP, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.
 
  1.   Log in to the Configuration utility.
  2.   Navigate to Device Management > Devices.
  3.   Click the local host name.
    For example:
    LTM1.example.com (Self)
  4.    From the Device Connectivity menu, select Failover Network.
  5.   In the Failover Unicast Configuration section, click Add
  6.   From the Address menu, select the self IP address associated with the failover VLAN.
     For example:
    10.0.0.1 (HA_VLAN)
  7.  From the Address menu, select the IP address associated with the Management IP.
  8.   Accept the default port of 1026.
  9.   Click Finished.
