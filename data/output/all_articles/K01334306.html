Known Issue

The BIG-IP ASM configuration may fail to load after an upgrade.

This issue occurs when all of the following conditions are met:

  • The affected system was previously running a version prior to BIG-IP 11.5.0.
  • The affected system is configured with a scheduled report using the Top alerted and blocked policies predefined filter.
  • The affected system is then upgraded to BIG-IP 11.5.0 or later.

This issue occurs because the Top alerted and blocked policies predefined filter has been renamed as Top alarmed and blocked policies in BIG-IP 11.5.0 and later; and the upgrade process failed to perform the name conversion.

Impact

The BIG-IP ASM configuration fails to load after an upgrade.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you attempt to view security policies in the Configuration utility, the system displays the ASM is not ready message.
  • When you attempt to manually load the configuration in the Traffic Management Shell (tmsh), the system reports an error message similar to the following example:

    010715ee:3: The predefined report Top alerted and blocked policies doesn't exist.
    ERROR: Failed during loading ASM configuration.
