K000148904: Creating a new CSR with key-usage extensions on a partition other than /Common via GUI fails.

Type
Support Solution
Published
2024-12-10
Updated
2024-12-24
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.1.X, 17.1.2, 17.1.1
Source
https://my.f5.com/manage/s/article/K000148904

Description

Creating new CSR in GUI on different partition than /Common and specifying key-usage extensions results in an error:

"Key file named "<certificate name>" must exist to create a corresponding certificate signing request."

Environment

  • BIG-IP LTM
  • Web GUI
  • CSR
  • CLI

Cause

Bug that is still being investigated.

Recommended Actions

Create the CSR in the Web GUI under the /Common Partition.

Login to Web GUI and change to partition to /Common
1. Go to System  ››  Certificate Management : Traffic Certificate Management : SSL Certificate List >> Create
2. Enter Name, Issuer - Certificate Authority, Common Name, select Key Usage, Finished

 

OR

Create CSR via tmsh under a partition.

Login to CLI 

1. Change partition

# cd /<partition>

2. Create private key

# create sys crypto key c.local.key key-size 2048 key-type rsa-private

3. Create CSR

# create sys crypto csr c.local key c.local.key common-name "My Company Inc." country "US" challenge-password "abcd" key-usage nonRepudiation
