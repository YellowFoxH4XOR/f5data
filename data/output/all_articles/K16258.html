Known Issue

The BIG-IP GTM system does not retain configuration details when you create a GTM server.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP GTM system is running 11.4.1.
  • You use the Configuration utility to create a GTM server.
  • To finalize creation the new GTM server, you click the Repeat button.

Impact

The Configuration utility leaves the GTM server configuration page.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to create a GTM server and click the Repeat button to commit the configuration, the system creates the GTM server. However, the system leaves the GTM server creation page and redirects you to the GTM server list page.

Resolution

Status

F5 Product Development has assigned ID 507115 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles

Hotfix11.4.1 HF9K9502: BIG-IP hotfix matrix

Note: This issue affects only BIG-IP 11.4.1 and 11.4.1 hotfix releases not listed in the Status table.

Workaround

To work around this issue, follow the same server creation steps used to create the initial server.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
