Description

The mongodb process cored after upgrading to BIG-IQ 7.1

Environment

  • BIG-IQ
  • Software upgrade from V 5.x, 6.x or 7.0 to 7.1

Cause

  • BIG-IQ 7.1.0 migrated from tokumx (mongo fork) to Postgres database
  • The mongodb cored likely after the data was migrated to Postgres
  • The mongod core file's backtrace is already output to tokumx.log
  • This is telling us that mongodb cored while it was attempting to shutdown:

Recommended Actions

  • As Tokumx is no longer needed as a process, it was intentionally shutdown.
  • Occasionally, this may result in mongo DB process coring.
  • It is important to ensure that Tokumx process is no longer running on the system
  • This can be verified by running the following command on the BIG-IQ console:
tmsh show /sys service tokumx

Example output:
tokumx       down 5 hours, normally up
