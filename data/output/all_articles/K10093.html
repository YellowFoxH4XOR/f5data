K10093: The Default Language menu may obscure part of the virtual keyboard on the FirePass logon page

Updated

Applies to

Source

Known Issue

This is the result of a known issue. If you select the Choice of language in logon page check box on the Device Management: Customization page, and you also enable the Show virtual keyboard action in the pre-logon sequence, the Default Language menu may obscure part of the virtual keyboard on the FirePass logon page.

Note: This issue has only been reported for Internet Explorer 6.0, but may it occur in other versions and browsers.
 
F5 Networks Product Development is tracking this issue as CR121149.
 
Workaround
 
To work around this issue, users can click in the Password field, or press the Tab button twice on their physical keyboard to move the virtual keyboard to another location in the browser window.
