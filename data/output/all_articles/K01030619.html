K01030619: [F5OS-C] System Controller shows Openshift cluster is NOT ready/is ready constantly after upgrading to v1.3.1 or v1.3.0

Type
Support Solution
Published
2022-03-30
Updated
2023-02-21
Applies to
  • VELOS Platforms
  • F5OS
  • F5OS-C: 1.3.1, 1.3.0
Source
https://my.f5.com/manage/s/article/K01030619

Description

After an upgrade of Velos System Controllers to F5OS  v1.3.1, Standby Controller keeps showing a loop of these logs:

/var/log/openshift.log has similar to the below logs:

Openshift cluster is NOT ready.
Summary Status: Openshift cluster is NOT ready.
Openshift cluster is ready.

Active Controller is working normal, and does not have these loop logs.

Environment

  • F5OS-C
  • Velos
  • Upgrade
  • v1.3.1

Cause

  • Bug ID 1077105

Recommended Actions

  • Upgrade to latest F5OS-C
  • Follow the workaround in Bug ID 1077105
