Issue

If you run 3dnsmaint and choose Install and Start big3d, 3-DNS contacts all of the BIG-IP Controllers in the 3-DNS configuration and attempts to update their copies of big3d. If 3-DNS attempts to install big3d on BIG-IP Controllers that are running software versions later than that of the 3-DNS, you will receive error messages similar to the following:

Can find no matching big3d. Will not copy big3d to <address>

This error message does not usually indicate a problem, as 3-DNS should not copy older versions of big3d over newer versions. If you receive this error when 3-DNS contacts a BIG-IP Controller running an older version than that of the 3-DNS, contact F5 Support for assistance.
