Known Issue

This is the result of a known issue. Under rare conditions, DMA memory writes for LACP data go to an unexpected buffer location in the memory pool. This can cause the bcm56xxd process to crash, and the BIG-IP LTM system to fail over to the standby unit.

F5 Networks Product Development tracked this issue as CR71129 and CR71201 and it was fixed in BIG-IP LTM versions 9.2.5, 9.3, and 9.4.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
