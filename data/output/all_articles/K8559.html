K8559: Local user accounts are deactivated or deleted by FirePass

Topic

If FirePass automatically deletes or deactivates local user accounts from the FirePass user database, the typical reason is that synchronization with an LDAP or Active Directory server is enabled, and the user account is no longer present on the LDAP or Active Directory server.

Note: You can view and manage local user accounts on the Users: User Management page.

To determine whether user account synchronization is enabled on the FirePass controller, perform one of the following two procedures, depending on which version of FirePass you are running:

FirePass version 6.x

To determine whether user account synchronization is enabled on the FirePass controller, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Click the Group mapping methods tab.
  4. If you have an LDAP mapping method configured, click the Configure link next to the mapping method. If you do not, proceed to Step 7.
  5. If the Synchronize FirePass user database with LDAP check box is selected, FirePass automatically deactivates or deletes local user accounts that were added by the LDAP mapping method, but  no longer appear in the LDAP user database.

    Note: You can configure which action FirePass performs (deactivate or delete) by selecting the appropriate action from the Action menu, located under the Synchronize FirePass user database with LDAP check box.
  6. Click the Group mapping methods tab.
  7. If you have an Active Directory mapping method configured, click the Configure link next to the mapping method. If you do not, this procedure is complete.
  8. If the Synchronize FirePass user database with Active Directory check box is selected, FirePass automatically deactivates or deletes local user accounts that were added by the Active Directory mapping method, but no longer appear in the Active Directory user database.

    Note: You can configure which action FirePass performs (deactivate or delete) by selecting the appropriate action from the Action menu, located under the Synchronize FirePass user database with Active Directory check box.

FirePass version 5.5.x

To determine whether user account synchronization is enabled on the FirePass controller, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Click the Request configuration tab.
  4. If you have an LDAP mapping method configured, select LDAP from the Select method to configure request menu.

    If you do not, proceed to Step 7.
  5. Click the Switch button.
  6. If the Synchronize FirePass user database with LDAP check box is selected, FirePass automatically deactivates or deletes local user accounts that were added by the LDAP mapping method, but no longer appear in the LDAP user database.

    Note: You can configure which action FirePass performs (deactivate or delete) by selecting the appropriate action from the Action menu, located under the Synchronize FirePass user database with LDAP check box.
  7. If you have an Active Directory mapping method configured, select Active Directory from the Select method to configure request menu.

    If you do not, this procedure is complete.
  8. Click the Switch button.
  9. If the Synchronize FirePass user database with Active Directory check box is selected, FirePass automatically deactivates or deletes local user accounts that were added by the Active Directory mapping method, but no longer appear in the Active Directory user database.

    Note: You can configure which action FirePass performs (deactivate or delete) by selecting the appropriate action from the Action menu, located under the Synchronize FirePass user database with Active Directory check box.
