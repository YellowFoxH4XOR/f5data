Topic

To view or extract the contents of an encrypted user configuration set (UCS) archive file, you must first decrypt the encrypted UCS archive file into a new decrypted archive file by performing the following procedure:

  • Decrypting an encrypted UCS archive file into a decrypted archive file

After performing the Decrypt an encrypted UCS archive file into a decrypted archive file procedure, you can view or extract the contents of the encrypted UCS archive file by performing one of the following procedures:

  • Viewing the contents of a decrypted archive
  • Extracting files from the decrypted archive
  • Viewing the contents of a file contained in a decrypted archive file

Decrypting an encrypted UCS archive file into a decrypted archive file

  1. Log in to the command line.
  2. Create a new directory within the /var/tmp/ directory, using the following command syntax. Replace <directory> with a name of your choice:

    mkdir /var/tmp/<directory>

  3. Copy the encrypted UCS archive into the new directory, using the following command syntax. Replace <filename> with the name of the encrypted UCS archive and replace <directory> with the name of the directed created in step 2:

    cp <filename> /var/tmp/<directory>/

  4. Change directories to the new directory, using the following command syntax. Replace <directory> with the name of the directory you created in step 2:

    cd /var/tmp/<directory>

  5. Decrypt UCS archive file into a new decrypted archive file, by entering the following command. Replace <output_filename> with the name of the decrypted output file and <UCS_filename> with the name of the encrypted UCS archive file:

    Note: Do not give <output_filename> a .ucs extension; this output file cannot be installed on the BIG-IP as a UCS archive file.

    /usr/bin/gpg -do <output_filename> <UCS_filename>

  6. At the Passphrase prompt, enter the passphrase for the encrypted UCS archive file, use the TAB key to move the cursor to <OK>, then press ENTER.

Viewing the contents of a decrypted archive

  1. Log in to the command line.
  2. To view a list of all files included in the UCS archive, use the following command syntax. Replace <filename> with the name of the decrypted archive file:

    tar -ztf <filename>

Extracting files from the decrypted archive

You can extract the files from the decrypted archive without overwriting your existing configuration, by performing one of the following procedures:

  • Extracting all files
  • Extracting a single file

Important: Extracted files will be placed in the current directory. To avoid overwriting your existing configuration, your current directory should be the /var/tmp/ that you created in Step 2 of the Decrypt an encrypted UCS archive file into a new decrypted archive file procedure.

Extracting all files

  1. Log in to the command line.
  2. Extract all files from the UCS archive and save to the current directory, using the following command syntax. Replace <filename> with the name of the decrypted archive file:

    tar -zxf <filename>

    This command extracts the files into the current directory, creating subdirectories to match the directories in which the configuration files are normally stored. For example, a config directory is created and contains all the files that are normally contained in the /config/ directory.

Extracting a single file

  1. Log in to the command line.
  2. Extract a single file into the current directory, creating a subdirectory to match the directory structure in which the file is normally stored, using the following command syntax. Replace <filename> with the name of the decrypted archive file and replace <file-to-extract> with the relative path and name of the file that you want to extract from the decrypted archive file:

    tar -zxf <filename> <file-to-extract>

    For example, to retrieve the bigip.conf file, you must specify the config directory without the root directory:

    tar -zxf decrypted_archive config/bigip.conf

    If you are currently in the /var/tmp/ directory, the bigip.conf file would be extracted to /var/tmp/config/bigip.conf.

Viewing the contents of a file contained in a decrypted archive file

  1. Log in to the command line.
  2. To view a file in the terminal without saving it to disk, use the following command syntax. Replace <filename> with the name of the decrypted archive file, and replace <file-to-view> with the relative path and name of the file that you want to view from the decrypted archive file:

    Note: The third character in the flags list is a capital letter O.

    tar -zxOf <filename> <file-to-view>

    For example, you would type the following command to view the bigip.conf file:

    tar -zxOf decrypted_archive config/bigip.conf

Note: You can use wildcards to display multiple files from an archive. For example, config/bigip.*.

Important: Some files contained in a UCS archive are binary files, which do not display correctly.
