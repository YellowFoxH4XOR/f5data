Description

Several pages on GUI fail to load. Below are some examples.

Sec​urity  >  Application Security : Policy Building : Traffic Learning ​​​​​​

Security  >  Application Security : Policy Building : Learning and Blocking Settings

Security  >  Application Security : Security Policies : Policies List

When trying to create a new policy, the page can't load and there is a pop up window saying [Object Object]

In /var/log/restjavad.log, there are logs similar to below one:

Caused by: java.net.ProtocolException: status:401, body:{"code":401,"message":"Authorization failed: no user authentication header or token detected.

Environment

  • BIG-IP

Cause

This BIG-IP is accessed via a virtual server on a different BIG-IP, thus there is a proxy in front of the affected BIG-IP.

Recommended Actions

This issue is tracked as ID1110893 and it can happen on software versions that are not listed on the affected version list.

One easy way is to follow the workaround to set httpd.matchclient to false. If this is not an option to your environment, please contact F5 Support to request an EHF for this ID to fix the issue.

﻿tmsh modify sys db httpd.matchclient value false
bigstart restart httpd
