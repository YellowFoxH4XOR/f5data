Description

Client doesn't receive BIG-IP DNS response after sending BIG-IP DNS request. This domain is only configured in ZoneRunner. Only BIG-IP DNS requests can be in captured pcap file

  • BIND don't reply BIG-IP DNS requests. 
No listener for UDP 53 on 127.0.0.1. There is no output like below.
# netstat -pan |grep "named"
udp    0   0 127.0.0.1:53        0.0.0.0:*                20854/named
  • Error messages in /var/log/daemon.log
warning named[<pid>]: /config/named.conf:30: undefined ACL '<zrd-acl-name>'
  • Named service restart in loop.

Environment

  • BIG-IP DNS
  • BIND

Cause

An undefined ACL makes BIND running abnormal.
In /var/named/config/named.conf, contain the configuration like below:

options {
  listen-on port 53 {
    127.0.0.1;
    "zrd-acl-000-000";
    "zrd-acl-000-001"; <===== undefined ACL
  };
.....
};
acl "zrd-acl-000-000" {
  127.10.0.0;
};

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. Remove the line of "zrd-acl-000-001" from named.conf
  2. Restart named service
#tmsh restart sys service named
