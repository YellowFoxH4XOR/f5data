Known Issue

This is the result of a known issue. In FirePass 6.0.3 and later and 6.0.2 HF-602-6, when the Portal Access : Web Applications : Content Processing compatibility mode is not enabled, forwarding or replying to emails containing embedded images using Microsoft Outlook Web Access 2007, the image(s) will be removed when the email is sent. The email recipient will see an unknown image symbol in place of the image in the email.

F5 Product Development tracked this issue as ID 317743 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Workaround

Important: This workaround is only valid for FirePass version 6.0.2 HF-602-6 and later, and when Portal Access : Web Applications : Content Processing is not in compatibility mode

You can work around this issue by creating the following pre-processing script:

  1. Navigate to Portal Access : Web Application : Content Processing.
  2. Click on the Preprocessing Scripts tab.
  3. Click Add New Favorite.
  4. Click the Processing script text box.
  5. In the Processing script name field, enter a name for the script.
     
    For example:

    OWA
  6. In the URL match patterns field, enter the following text:

    */ev.owa\?*&ns=EditMessage&*
  7. In the Content Type field, enter the following text:

    text
  8. In the Sed processing field, enter the following text:

    s@&amp;amp;F5CH=I@@g
  9. In the Processing drop-down menu, select Process request data.
  10. Click the Add New button.
