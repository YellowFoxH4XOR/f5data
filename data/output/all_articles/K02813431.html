Topic

  • This article describes the possible states that the LTM can be in and what they mean, where in the system this information is available, and more information about that state, if applicable.

Description

When a BIG-IP system is configured either as a standalone or in a redundant configuration, it operates in a specific state. Each state indicates the status of BIG-IP. The following table explains more information. 

Standalone or Redundant Systems
 
StateDescription
ActiveThe system is actively responding to user traffic.
No License                        The system is unlicensed. Install a registration key with tmsh install sys license registration-key <key> or via System / License in the GUI.             
InoperativeThe system is still starting, or is unable to start.
OfflineThe system is offline likely due to a service being down. Review the output of tmsh show sys ha-status command or the /var/log/ltm log.

Redundant Systems
 
StateDescription
ActiveThe system is actively responding to user traffic.
StandbyThe system is in standby state, and will become active if the existing active device fails.
Awaiting Initial SyncThe system is part of a device-group, but has not yet been synchronized. Perform a configuration sync.
Changes PendingThis system has changes that have not been replicated to other members of the device-group. Perform a configuration sync. 
Failsafe FaultVLAN or gateway failsafe has been configured, and has detected a failure. Review the output of tmsh show sys ha-status command or the /var/log/ltm log.
