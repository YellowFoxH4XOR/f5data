K000150397: Invalid JSON' Error in BIG-IP APM OAuth Workflow After Upgrade to Version 17.1.2.x

Support Solution
Published

2025-03-15
Applies to

Source

Description

When upgrading BIG-IP APM from version 17.1.1.4 to versions 17.1.2 or 17.1.2.1, the oAuth authentication workflow may fail with an "Invalid json" error during the OAuth scope query process. The following error messages may appear in logs:

 

OAuth Scope: failed for server '<server_name>' (resource_server_id=<id>), error: Invalid json

or

OAuth Client: failed for server '<server_name>' using 'authorization_code' grant type (client_id=<id>), error: Invalid json

 

This issue prevents users from completing the authentication process.

 

Environment

  • BIG-IP APM
  • 17.1.2, 17.1.2.1
  • OAuth.
  • JSON responses from the Identity Provider (IdP) containing non-standard UTF-8 characters such as Latvian characters ('ī,' 'Ē,' 'ļ') in claims.

Cause

The issue is caused by a parsing error in BIG-IP's OAuth client when processing JSON responses that include non-standard UTF-8 characters in claims returned by the IdP server after authorization. This has been identified as Bug ID 1826013.

 

Recommended Actions

An Engineering Hotfix has been developed to address this issue on version 17.1.2.x. Contact F5 Support to request the hotfix and apply it to your environment.
