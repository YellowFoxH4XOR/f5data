Topic

The Congestion Metrics Cache setting is an option in the TCP profile that specifies whether the system caches certain TCP metrics used for congestion control. The BIG-IP system sends SYN retransmissions at different intervals depending on whether or not the Congestion Metrics Cache setting is enabled in the TCP profile.

Note: For more information about the TCP profile, refer to K50411377: Overview of the TCP profile (16.x and later).

Congestion Metrics Cache enabled

By default, the Congestion Metrics Cache setting is enabled in the TCP profile, and the BIG-IP system sends SYN retransmissions as follows:

  • If the BIG-IP system sends a SYN packet to an unresponsive pool member for which the congestion metrics cache contains valid route metrics, the system sends SYN retransmissions at one-second intervals until the Maximum Syn Retransmissions value is exceeded.

    Note: For client-side connections, the BIG-IP will only cache route metrics if the connection consists of more than four non-SYN/FIN packets to a pool member.
    Note: The one-second intervals apply when TCP profile Initial Retransmission Timeout Base Multiplier for SYN Retransmission is set to default 3 seconds. When the configuration is set to a non-default value, the intervals follow the non-default value. If it is set to 2 seconds, the system sends SYN retransmissions at two-second intervals. If 3 seconds is the desired value, an approximation to 3000 (e.g. 2999 or 3001 ms)  is considered a non-default value.

  • If the BIG-IP system sends a SYN packet to an unresponsive pool member for which the congestion metrics cache contains no valid route metrics, the system sends SYN retransmissions at three-second intervals until the Maximum Syn Retransmissions value is exceeded.

When the Congestion Metrics Cache setting is disabled in the TCP profile, the BIG-IP system sends SYN retransmissions at 3-second intervals until the Maximum Syn Retransmissions value is exceeded.

View congestion metrics

Beginning in BIG-IP 11.x, you can view the congestion metrics. To do so, enter the following command from within the TMOS Shell (tmsh):

show /net cmetrics
