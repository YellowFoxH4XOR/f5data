Description
The Access Policy is failing on MacOS devices at the Windows Registry Check activity.
 

Environment

  • BIG-IP APM
  • Client Side Checks
  • Apple Macs / MacOS
     

Cause
The Windows Registry Check can only be done to a Windows client, it is not possible to check the Registry on a non-Windows device, this includes MacOS devices.

 

Recommended Actions

If you need to include a Windows Registry check in the Access Policy, it is recommend that you insert a Client OS check activity, and then only proceed to performing the Windows Registry check if the client has been detected as being Windows.  All other client types should not perform the Windows Registry check.

Additional Information
There a number of client side activity checks that can be performed on devices that are specific to the Operating System, so it is advisable to check the Client OS before performing these activities.
The list includes:

  • Hard Disk Encryption (Windows and Mac only)
  • Linux File
  • Linux Process
  • Mac File
  • Mac Process
  • System Health Agent (Windows and Mac only)
  • Windows Cache and Session Control
  • Windows File
  • Windows Info
  • Windows Process
  • Windows Protected Workspace
  • Windows Registry
