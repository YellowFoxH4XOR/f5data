Description

When using the command "system image remove iso <<version>>" to remove an old software version, the CLI returns this error:

appliance-1(config)# system image remove iso <<version>>

Error:

error: Image <<version>>: unexpected response back from API



Environment

  • F5OS disk space release
  • Removing old versions

Cause

Bug ID 1267201

 Recommended Actions

Unfortunately, there is no workaround for this issue. We recommend waiting for v1.6.0 to be released. It is natively fixed there.
