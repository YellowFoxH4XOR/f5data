K16917: How-to Configure a range of IP addresses for a virtual IP attached to a forward proxy

Topic

You should consider using this procedure under the following conditions:

  • You would like to configure a range of addresses for a virtual IP attached to a forward proxy.
  • You have an interface IP address that falls within the range of the new forward proxy.

Description

When configuring a range on a virtual IP that is attached to a forward proxy, it is possible to inadvertently create a loop that causes the LineRate system to connect to itself repeatedly. To avoid this situation, you must exclude interface IP addresses from any range configured on any virtual IP.

For example, if the management IP address 10.0.0.50 is configured for the em0 interface, and you attempt to create a range from 10.0.0.1 to 10.0.0.100, a loop condition may be created.

To avoid this issue, you can create two separate ranges which exclude the 10.0.0.50 address, and attach both of the ranges to the forward proxy configuration.

Prerequisites

None

Procedures

Create two separate IP address ranges

In the example, you want to create an IP address range from 10.0.0.1 to 10.0.0.100, excluding the management interface IP address 10.0.0.50. To accomplish this, you create range1 from 10.0.0.1 - 10.0.0.49 and range2 from 10.0.0.51 - 10.0.0.100, and then attach range1 and range2 to the virtual server.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the LineRate system CLI.
  2. Enter Configuration Mode by typing the following command:

    configure

  3. Review the current virtual IP address configuration by typing the following command:

    show ip interface brief

    The output appears similar to the following example:

    Interface  IP Address       Status  Protocol
    ----------------------------------------------

    em0        10.0.0.50/24     up      up
    lo0        ::1/128          up      unknown
    lo0        127.0.0.1/8      up      unknown

  4. Configure a new virtual IP address for the first range of addresses, using the following syntax:

    virtual-ip <name>

    For example, create a virtual IP named range1 by typing the following command:

    virtual-ip range1

  5. Configure the first IP range using the following syntax:

    ip range <starting IP address> <ending IP address> <TCP port number for range>

    For example, configure an address range of 10.0.0.1 - 10.0.0.49 for TCP port 8080, by typing the following command:

    ip range 10.0.0.1 10.0.0.49 8080

  6. Enable the virtual IP by typing the following command:

    admin-status online

  7. Configure a new virtual IP address for the second range of addresses, using the following syntax:

    virtual-ip <name>

    For example, create a virtual IP named range2 by typing the following command:

    virtual-ip range2

  8. Configure the second IP range using the following syntax:

    ip range <starting IP address> <ending IP address> <TCP port number for range>

    For example, configure an address range of 10.0.0.51 - 10.0.0.100 for TCP port 8080, by typing the following command:

    ip range 10.0.0.51 10.0.0.100 8080

  9. Enable the virtual IP by typing the following command:

    admin-status online

  10. Create a new forward proxy using the following syntax:

    forward-proxy <name>

    For example, create a forward proxy named fwd-proxy-1 by typing the following command:

    forward-proxy fwd-proxy-1

  11. Assign the virtual IP ranges created in steps 4 and 7, using the following syntax:

    attach virtual-ip <name>

    For example, to assign virtual IP range1 to the forward proxy, type the following command:

    attach virtual-ip range1

    Repeat this step for range2
  12. Enable the forward proxy by typing the following command:

    admin-status online

  13. Modify any other settings as desired, and then save changes by typing the following command:

    write
