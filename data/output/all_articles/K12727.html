K12727: Mac OS X 10.4.x clients using Finder to copy files and directories may receive 'File locked by another process' error messages

Known Issue

This is the result of a known issue. When a Mac OS X 10.4.x client uses Finder to copy files and directories, the ARX may send a client PID value of 0 (zero) rather than the correct value. As a result, the copy will fail and the client receives the following error message:

File locked by another process

F5 Product Development tracked this issue as ID 351078 and it was fixed in ARX version 5.2.2. For information about upgrading, refer to the ARX Release Notes.

Additionally, this issue has been fixed in hotfix release 5.2.0 HF4 (build 12642). Customers affected by this issue should request this hotfix from F5 Technical Support, referencing this Solution number and ID 351078.

For information about rollup hotfixes available for ARX version 5.2.0, refer to K12546: Overview of ARX version 5.2.0 rollup hotfixes.

Workaround

To work around this issue, copy the files using the ARX command line interface (CLI).
