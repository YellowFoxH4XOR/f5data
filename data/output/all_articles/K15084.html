Known Issue

The Configuration utility may report that an error has occurred when you update user properties.

This issue occurs when the following conditions are met:

  • Configuration utility access has been restored to allow only clients using AES_256 Secure Sockets Layer (SSL) ciphers.
  • You have attempted to modify user properties by navigating to System > Users > User List.

By default, the Configuration utility allows you to use a large range of SSL ciphers for SSL clients to connect to the Configuration utility. You can restrict Configuration utility access to allow only those clients using high encryption SSL ciphers.

Note: For more information, refer to K13405: Restricting Configuration utility access to clients using high encryption SSL ciphers (11.x).

Impact

You can safely ignore this issue. The system has correctly applied the update to the user properties you have modified.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H445752 on the Diagnostics > Identified > Low screen.
  • The Configuration utility displays an error message similar to the following example:

    "An error has occurred while trying to process your request."

  • In the /var/log/webui.log file, you observe an error message similar to the following example:

    2014-03-13 14:01:12,354 ERROR [TP-Processor2] user.UserPropertiesHandler:trigger -
    javax.net.ssl.SSLHandshakeException: Received fatal alert: handshake_failure

Workaround

There is no workaround for this issue. You can safely ignore the issue, as the system has correctly applied the configuration change. If you make frequent changes to user properties, you may, optionally, use the Traffic Management Shell (tmsh) to avoid this error message.
