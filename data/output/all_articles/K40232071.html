Description

This article will explain how to use TLS 1.2 compatible or RC4-SHA ciphers only for the GUI (Configuration utility) via management interface and its impact.

Environment

  • BIG-IP
  • Use TLS 1.2 only for GUI (Configuration utility)

Cause

None.

Recommended Actions

This action can only be done on the Command Line.

  1. Login to the Command Line.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. Before you change the SSL cipher string, you should review the existing string for your specific BIG-IP version. To list the currently configured cipher string, type the following command:

    list /sys httpd ssl-ciphersuite

    For example, the BIG-IP 16.1.5 system displays the following cipher string:

    ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES128-SHA:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA384:ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-ECDSA-AES128-SHA:ECDHE-ECDSA-AES256-SHA:ECDHE-ECDSA-AES128-SHA256:ECDHE-ECDSA-AES256-SHA384:AES128-GCM-SHA256:AES256-GCM-SHA384:AES128-SHA:AES256-SHA:AES128-SHA256:AES256-SHA256

    Note: Cipher suites are combined in a single cipher string using the plus (+) character. The exclamation (!) character removes a cipher suite from the list. Additionally, the cipher strings LOW, MEDIUM, and HIGH are used to group cipher suites by their encryption strength. To determine which specific ciphers are included in each of the cipher strings, you can use the tmm --clientciphers <string> command. For example, tmm --clientciphers LOW. For more information, refer to K15194: Overview of BIG-IP SSL/TLS cipher suites. The Traffic Management Microkernel (TMM) supports several ways to select groups of ciphers using a short string based on the traits of the ciphers. While the format is similar to OpenSSL, some strings differ and the results are not always the same.

  4. To restrict Configuration utility access to clients using TLS 1.2 or RC4-SHA ciphers, type the following command:

    modify /sys httpd ssl-ciphersuite 'ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:RC4-SHA:!SSLv2:-TLSv1:-SSLv3:-TLSv1.1'

    Alternatively, if you can restrict to only TLS 1.2 cipher, then type the following command instead:

    modify /sys httpd ssl-ciphersuite 'ALL:!ADH:!EXPORT:!eNULL:!MD5:!DES:!SSLv2:!SSLv3:!TLSv1:!TLSv1.1'

  5. Save the configuration change by typing the following command:

    save /sys config

  6. To validate of TLS1 and TLS1.1 is disabled, you can test with the following commands and should get SSL handshake failures for tls1 and tls1.1:

    openssl s_client -connect <Mgmt IP_Address>:443 -tls1_2
    openssl s_client -connect <Mgmt IP_Address>:443 -tls1_1
    openssl s_client -connect <Mgmt IP_Address>:443 -tls1

Impact: The Configuration utility will only use TLS 1.2. Your client browser will need to support TLS 1.2. Clients who do not support TLS 1.2 may not be able to connect. Updated browsers should support TLS 1.2.

Additional Information

The BIG-IP system (versions 17.x and earlier) do not support TLS 1.3 connections for the GUI (Configuration utility).
