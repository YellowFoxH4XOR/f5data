Description

Cookie encryption is not working when two http profiles (client-side and server-side) are applied on Virtual Server.


 

Environment

- cookie encryption configured on http profile,

- virtual server with two separate http profiles on the client-side and server-side.


 

Cause

Cookie encryption configuration is applied to the wrong http profile context. Cookie encryption for server-generated cookies (Set-Cookie headers) must be configured in the server-side HTTP profile.


 

Answer/Recommended Actions

Configure cookie encryption settings in the server-side http profile instead of the client-side profile.
