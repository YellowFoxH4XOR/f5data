Description

While connection to the BIG-IP TMUI (Configuration Utility, GUI), there is no SSL certificate chain is returned by the BIG-IP

  • Security scanning tools may report about untrusted connection due to SSL certificate chain missing

Environment

  • Third party CA signed device certificate are in use
  • Imported device certificate may or may not contain Intermediate CA and/or Root CA in the chain

Cause

This is expected behaviour. By default BIG-IP does not send SSL certificate chain while connecting to TMUI

Recommended Actions

To configure the BIG-IP to send SSL certificate chain while connecting to TMUI follow the steps below
  1. Copy SSL Certificate Chain file using any SCP tool to the following location:
    /config/httpd/conf/ssl.crt/<chain cert_name>.crt
  2. Configure httpd to use the new SSL Certificate Chain file to secure the management interface. To do so, use the following command syntax:
    tmsh modify /sys httpd ssl-certchainfile /config/httpd/conf/ssl.crt/<chain cert_name>.crt>

  3. Restart the httpd process to place the new certificate chain configuration into the running configuration. To do so, use the following command syntax:
    tmsh restart /sys service httpd
