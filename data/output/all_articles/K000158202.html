K000158202: How to check the current baud rate using a command on the rSeries

Type
Support Solution
Published
2025-12-15
Updated
2026-01-26
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000158202

Description

To check the current baud rate on rSeries, you can run the following docker command :

 

- r2k/r4k :

[root@appliance-1(R4600-R88-S7):Active] ~ # docker exec platform-hal psf GET:bmc/cmd/baud-rate
  field    | value      
-----------+------------
  baudRate | 19200 bps  

 

- r5k :

[root@appliance-1(R5900-R81-S11):Active] ~ # docker exec platform-hal psf GET:lop/object/front-panel-baud-rate
 field       | value  
---------------------+--------
 frontPanelBaudRate | 19200  

 

Environment

  • BIG-IP F5OS-A v1.8.3
  • BIG-IP r2k/r4k and r5k platform
