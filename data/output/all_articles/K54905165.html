Description
An ASM Main cookie is generated for each path within a domain observed in an HTTP response's Set-Cookie HTTP Header(s) in addition to a "primary" ASM Main cookie which also tracks Set-Cookie HTTP Headers without a specified path or with the root path specified.

Environment

  • ASM Security Policy
  • HTTP response from Web Server contains 1 or more Set-Cookie HTTP Header(s)

Cause
By design, an ASM Main cookie is created for every path in each domain observed in the Set-Cookie HTTP Header(s) in an HTTP response in addition to the ASM Main cookie that is always generated and covers the root path. The "primary" ASM Main cookie hashes all cookies without a domain and a path of root (or no path specified) while the additional ASM Main cookie(s) only hash the additional cookie(s) for a specific path in a single domain.

Recommended Actions

None needed.

Additional Information
When the ASM Main cookies are received by the client, they can be matched up to the specific paths they were generated for by reviewing their path attribute value.

For example an ASM Main cookie like:
