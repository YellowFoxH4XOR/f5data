Description

When rediscovering BIG-IP AFM config on BIG-IQ, it may fail with the following error:

Error querying 'Rule List' from path '/mgmt/tm/security/firewall/rule-list' on device localhost.local (x.x.x.x), network communication failed due to protocol error

Environment

  • BIG-IQ
  • BIG-IP AFM
  • Rule List

Cause

The trigger is due to restjavad timeout as described in K94602685

Recommended Actions

Follow the steps in K94602685 to increase the timeout.
