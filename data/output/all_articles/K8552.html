K8552: WebDAV sandbox size limit for high availability and cluster configurations

Topic

WebDAV is a set of HTTP protocol extensions that allow administrators to publish HTML content to a web server. FirePass implements WebDAV so that administrators can customize some aspects of the FirePass controller’s user interface. The WebDAV sandbox is the directory on the FirePass controller which contains the customized files uploaded through a WebDAV client.

The WebDAV sandbox is not intended as a repository for large files or executables. In a FirePass high availability or cluster configuration, the files in the WebDAV sandbox must be transferred from the active controller or primary cluster node to the standby controller or secondary cluster nodes. If the sandbox directory exceeds 20 MegaBytes, the excessive data transfer may interfere with the synchronization mechanism and potentially cause synchronization to fail. If synchronization fails, changes made to the active controller or primary cluster node will not be synchronized to the standby controller or secondary cluster nodes.

F5 Networks Product Development recommends limiting the size of your WebDAV directory to 20 MegaBytes or less if you use a FirePass high availability or cluster configuration. If you encounter a synchronization issue due to the size of the WebDAV sandbox, delete excess files in the WebDAV sandbox using a WebDAV client. If synchronization does not resume within several minutes, make a configuration change on the active controller or the primary cluster node (for example, create or update a user account on the Users: User Management page) and then restart the FirePass controller.

You can view the synchronization status on the Failover: Settings page on the active controller or the primary cluster node. If synchronization is working correctly, FirePass reports a message similar to the following example:

68 sec since last sync with firepass-2

If synchronization is failing, FirePass reports a message similar to the following example:

186 sec since last sync with firepass-2

Warning: Either the peer node is down, or the system is not configured properly!

For more information about WebDAV, refer to K4440: Overview of WebDAV.
