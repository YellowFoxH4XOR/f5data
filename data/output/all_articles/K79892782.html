Known Issue

The merged process may restart repeatedly.

This issue occurs when the following condition is met:

  • You have enabled debug logging on a high-speed logging (HSL) log filter.

    Note: If you have enabled debug logging on an HSL log filter in versions prior to BIG-IP 12.1.2 and then upgraded the system to BIG-IP 12.1.2, you may experience this issue after booting the system to the newly upgraded slot of BIG-IP 12.1.2.

Impact

The system may not collect statistics during the merged process repeated restarts. Additionally, qkview files generated during the affected period may not include the statistics data.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The merged process restarts repeatedly and produces a core file in the /shared/core directory.
  • During every restart of the merged process, your BIG-IP system logs an error message to the /var/log/user.log file that appears similar to the following example:

    err merged[<PID>]: isc/libev evGetNext: Bad File Descriptor: 5, errno: 9 Bad file descriptor.
    notice logger: Started writing core file: /var/core/merged.bld0.0.249.core.gz for PID <PID>.

Workaround

There is no workaround for this issue. However, you can prevent this issue from recurring by disabling debug logging on the affected HSL log filter. To do so, perform one of the following procedures:

  • Using the Configuration utility to disable debug logging on an affected HSL log filter
  • Using tmsh to disable debug logging on an affected HSL log filter

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Using the Configuration utility to disable debug logging on an affected HSL log filter

  1. Log in to the Configuration utility.
  2. Navigate to Systems > Logs > Configuration > Log Filters.
  3. Click the name of the affected HSL log filter.
  4. For the Severity setting, select Warning.
  5. Click Update.

Using tmsh to disable debug logging on an affected HSL log filter

  1. Log in to the TMOS Shell (tmsh) by typing the following command:

    tmsh

  2. To disable debug logging on the affected HSL log filter by setting level to warn, use the following command syntax:

    modify sys log-config filter <HSL log filter name> level warn

    For example, to disable debug logging for the myHSLfilter log filter, type the following command:

    modify sys log-config filter myHSLfilter level warn

  3. Save the changes by typing the following command:

    save sys config
