K43503050: Error Message: 01170003:3: halGetDossier returned error (7): Dossier generation failed.

Published

Applies to

  • Microsoft Azure

Source

Description
When licensing a cloud edition BIG-IP, you may encounter an empty dossier field in the management UI, or you may encounter this error from the command line:

Error Message: 01170003:3: halGetDossier returned error (7): Dossier generation failed.

Environment

  • Public cloud instance of BIG-IP

Cause
The BIG-IP generates a dossier using local information and meta-data information from http://169.254.169.254 that contains specific information about the virtual instance.  The BIG-IP needs a route to reach this link-local address.
Bug ID 720001

Recommended Actions

  1. Log into the command line shell of the BIG-IP.
  2. Set the database key that allows a route for a link-local address by typing the following command:
    tmsh modify sys db config.allow.rfc3927 value enable
  3. Create a route that points to the cloud provider's subnet default gateway.  (You will need to obtain this information from your cloud provider).
    create sys management-route meta-endpoint network 169.254.169.254/32 gateway <subnet gateway IP>
  4. If the virtual instance is a single-NIC instance, also add this route:
    create net route meta-endpoint network 169.254.169.254/32 gateway <subnet gateway IP>
  5. Proceed with the licensing process.
