Description

  • We have now updated our documentation and git checkout version to 1.7.0 and above. 
  • Uninstall any previously installed Nginx service mesh following " helm uninstall < release name> nginx-mesh ". 
  • Make sure all Nginx mesh pods are removed from previous instillation. 

 

Environment

  • Nginx Service Mesh

Cause

  • None

Recommended Actions

  • With the above complete, please follow the guide provided here, to complete Nginx Service Mesh instillation.
nsm@master:~/Documents/mesh/nginx-service-mesh/helm-chart$ helm install nsm . --namespace nginx-mesh --set enabledNamespaces={mesh} --set disableAutoInjection=true --wait
NAME: nsm

NAMESPACE: nginx-mesh
STATUS: deployed
REVISION: 1
TEST SUITE: None
NOTES:
NGINX Service Mesh has been installed. Ensure all NGINX Service Mesh Pods are in the Ready state before deploying your apps.
 

Additional Information

  • You must have configured persistentStorage before initiating the instillation. If not, you need to turned off persistentStorage Off under mtls of values.yaml file.
  • Also, if you can limit autoIngection to your preferred namespace, in the below command the namespace is set to mesh.
  • You may install Nginx service mesh through source using helm command " helm install nsm . --namespace nginx-mesh --set enabledNamespaces={mesh} --set disableAutoInjection=true --wait"
Provided procedure is valid and the instillation process can take a couple of minutes and so give time for the instillation to complete.
