Description

If you look under /usr/local/www/tmui/tmui/skins/Default/images/app_icons/ you will find some files with questionable names.

For example:

[root@ltm2:Standby:In Sync] app_icons # ls -l any porn
-r--r--r--. 1 root root 492 Mar 29 2017 any_0hop.png
-r--r--r--. 1 root root 492 Mar 29 2017 anydesk.png
-r--r--r--. 1 root root 492 Mar 29 2017 anydesk_remote_control.png
-r--r--r--. 1 root root 433 Mar 29 2017 anyterm.png
-r--r--r--. 1 root root 887 May 18 2017 porn555.png
-r--r--r--. 1 root root 462 Mar 29 2017 pornhub.png

Environment

BIGIP LTM
BIG-IP AFM

Cause

These files are used by the Classification Engine for the Traffic Intelligence feature of AFM

Recommended Actions

This is all by design and nothing to be concerned about. The images are icons of those sites and from the F5 library called the Classification Engine (CEC).
They are deliberately copied to the TMUI directory. These icons show up in Traffic Intelligence::Applications::Application List - open the category with the + sign to the right of the name and you'll see the icons there.
