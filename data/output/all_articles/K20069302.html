Source

Description

While connecting to the BIG-IP using HTTP2 client might send the following error message and RST the STREAM:

 Framer error: 20 (HPACK_INVALID_NAME_INDEX).

Environment

  • BIG-IP LTM
  • HTTP/2 profile 

Cause

This was identify with the following BUG ID1078197 to track this issue.

Recommended Actions

This issue is not present in BIG-IP version 14.1.0 and up. - recommend to upgrade to BIG-IP version 14.1 or to an higher version.
There were major changes to the HTTP2 code starting in 14.1.0 that affect this area.

    Additional Information
    The error indicates an issue with the HPACK compression table.
    The client wasn't able to decompress header information it received from the BIG-IP and the client RST the stream .
    This tends to happen when BIG-IP sends multiple HEADER frames inside one response the headers get mixed up between responses.
