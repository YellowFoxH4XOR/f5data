K000135152: iApp cannot be deleted because it contains configuration item

Type
Support Solution
Published
2023-06-21
Updated
2023-06-21
Applies to
  • BIG-IP
  • BIG-IP APM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000135152

Description

Can not delete iApp:

010713f9:3: The folder /Common/F5-ADFS-iApp.app cannot be deleted because it contains configuration item (APM Log Configuration /Common/iApp.app/sso-log-setting-Notice)



Environment

BIG-IP APM

Cause

It seems a customized logging was added and in order to delete the iApp, the logging object needs to be removed first.

Recommended Actions

Disassociate the logging object and delete it.

Additional Information

K51033596: Error Message: 010715bc:3: The application service (iApp name) has strict updates enabled, the object (iApp object) must be updated using an application management interface.
