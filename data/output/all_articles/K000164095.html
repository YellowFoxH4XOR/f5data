K000164095: Upgrade or reinstallation of k3s will fail if weak SSHd cipher is configured

Description

  • Upgrade to an affected version
  • Reinstallation of k3s

Environment

  • Only weak sshd ciphers are configured for sshd, i.e. aes128-cbc
  • Upgrade
  • Reinstallation of k3s

Cause

ID 2719225

Answer/Recommended Actions

To avoid the failure, revert the sshd cipher to default by adding the following ciphers back to list of sshd ciphers:

[ aes128-cbc aes128-ctr aes128-gcm@openssh.com aes256-cbc aes256-ctr aes256-gcm@openssh.com ]
