K14067: Multiple ARX NSM processors may core and return to standby state

Known Issue

Multiple ARX NSM processors may core simultaneously and return to a standby state due to an issue with an internal timer handler. As a result, the timer handler begins to run in an indefinite loop and will eventually crash due to the non-maskable interrupt (NMI).

Impact

NSM processors are not available to process traffic, which may cause possible delays due to lack of resources.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You will see error messages in the ARX syslog that appear similar to the following example:

    SNMP TRAP: cpuHalt (68) : failed slot:2 proc:8
    SNMP TRAP: moduleStatus (310) slot 2  : Online
    TCMD-0-NOTE-TCMD_DISABLING_NSM:: Disabling NSM slot 2 proc 6.
    TCMD-0-NOTE-TCMD_DISABLING_NSM:: Disabling NSM slot 2 proc 7.
    TCMD-0-NOTE-TCMD_DISABLING_NSM:: Disabling NSM slot 2 proc 8.
    SNMP TRAP: nsmStandby (411) : Processor 2.6 is in standby.
    SNMP TRAP: nsmStandby (411) : Processor 2.7 is in standby.
    clnt_call failed with error: WRITE: RPC: Timed out  [clnt_stat Nfs::my_clnt_call(long unsigned int, const char*, bool_t (*)(XDR*, void*, ...), char*, bool_t (*)(XDR*, void*, ...), char*)]
    SNMP TRAP: nsmStandby
  • The show processor command will display multiple NSMs processors offline similar to the following example:

    ARX1- show processor

    Proc     Module  State       Up Time             Total Kb  Free Kb  CPU1M   CPU5M
    ----     ------  ----------  ------------------  --------  -------  ------  -----

    2.1      NSM     Up          79 days, 13:24:05   2714622   606738   0       1
    2.2      NSM     Up          79 days, 13:24:05   2714622   606738   3       3
    2.3      NSM     Up          79 days, 13:24:05   2714622   606738   1       1
    2.4      NSM     Up          79 days, 13:24:05   2714622   606738   1       1
    2.5      NSM     Standby     0 days, 20:52:05    2714622   877403   0       0
    2.6      NSM     Standby     0 days, 20:52:05    2714622   877403   0       0

    2.8      NSM     Standby     0 days, 20:52:05    2714622   877403   0       0
  • A core file will be present on the ARX system.
