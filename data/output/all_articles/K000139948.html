K000139948: MyF5 Search results in error “Something went wrong”

Description

When searching MyF5 in Mozilla Firefox browser, your search returns an error reading Something went wrong. If the problem persists contact the administrator. For example:

Figure: Error message

Environment

  • My.F5.com
  • Firefox

Cause

Firefox’s Tracking content privacy setting interferes with search results delivery.

Recommended Actions

To remedy the issue, you can disable the Tracking content option in the Firefox browser settings using the following procedure:

  1. Open your Firefox browser, select the hamburger icon in the top right corner of your browser to open the browser controls menu.
  2. Select Settings.
  3. From the navigation menu, select Privacy & Security. The page shows three options for security: Standard, Strict, and Custom.
  4. Select Custom.
  5. Clear the Tracking content check box.

    Note: If you need to, you can also clear any of the other check boxes if you do not want the browser to block their corresponding scripts. Use caution when disabling as doing so can cause unexpected results and may diminish the security of your browser.

  6. Select Reload All Tabs.

    When you return to the tab with my.f5.com loaded, you should now see search results for your query. If not, refresh your browser.
