Description

Session Mirroring doesn't work.

tmsh show sys ha-mirror

shows closed.

/var/log/ltm has log messages of the form:

10.2.4.161:1029 -> 10.2.4.162:32775: Connection error: ssl_null_parse:3691: alert(10) invalid record type

(Port 1029 is used for mirroring.)

Environment

2 Devices with primary Mirror IP.

Devices are Virtual Edition or VCMP Guests or F5OS tenants.

Cause

Different number of CPU's on each guest.

Recommended Actions

Change Devices to match CPU count.

Additional Information

This is mentioned as a requirement in K54622241: Troubleshooting connection mirroring
