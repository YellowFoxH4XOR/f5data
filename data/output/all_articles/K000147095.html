K000147095: Why do I get a 500 Server error message while trying to create Blob Storage?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-19
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147095

What Happened?

  • I am receiving the below error message while trying to create Blob Storage -
  • Http failure response: 500 Server Error There was a server error in processing request Oconnection test status: error getting connection test result from test job logs

 

 

Environment

  • F5® Distributed Cloud

 

Resolution/Answer

  •  Please make sure the connection string has the access right to Azure BLOB storage.

    Configuration error. error=Sink "c59624b6-c312-4c20-b441-3d542a49750b_out": Generic error: Could not create a storage client from the provided connection string. Please validate that you have specified the account name and means of authentication (key, SAS, etc.).

 

Cause

  • The connection string provided does not have the right authorization to create and access blob storage.
