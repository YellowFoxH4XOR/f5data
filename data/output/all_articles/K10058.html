Important: The information in this Solution applies to FirePass version 6.x and 7.0.0. If you are running FirePass version 5.5.x, refer to K10059: Configuring Active Directory dynamic group mapping in FirePass version 5.5.x. 

The following procedures configure Active Directory dynamic group mapping. Master group mapping dynamically assigns users to a FirePass master group at logon based on their Active Directory group. Resource group mapping dynamically assigns users one or more FirePass resource groups at logon based on their Active Directory group. Based on your environment and requirements, you may decide to configure both master group mapping and resource group mapping, or you may decide to configure only one of the two.

Before beginning one of the following procedures, review the following documents:

  • K9061: Overview of FirePass group mapping
  • The Users: Groups: Dynamic Group Mapping: Group mapping sequence page in the FirePass online help. This page contains flowcharts of the dynamic group mapping sequence.

Configuring Active Directory master group mapping

The following procedure configures Active Directory master group mapping. For the purpose of this example, Example Company is configuring master group mapping, as follows:

  • If a user belongs to the Employees group in Active Directory, the user is assigned to the OfficeUsers master group at logon.
  • If a user belongs to the Primary Vendor or Secondary Vendor group in Active Directory, the user is assigned to the Vendors master group at logon.

In this procedure, F5 assumes that the required master groups have already been configured on the Users: Groups: Master Groups page.

Note: For information about configuring master groups, refer to the FirePass Controller Administrator Guide.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Under the Group mapping sequence tab, select the Determine the user's master group dynamically using the master group mapping table check box.
  4. Click the Group mapping methods tab.
  5. Select Active Directory from the Mapping Methods menu.
  6. Click the Add mapping method button.

    The Active Directory mapping method appears.
  7. Click the configure link next to the Active Directory mapping method.
  8. Configure your domain controller information. For a description of each field, refer to the Users: Groups: Dynamic Group Mapping: Active-Directory based mapping page in the FirePass online help. Additionally, when configuring your domain controller information, keep the following points in mind:

    • In the Domain name field, configure the fully qualified domain name (FQDN) of the Windows domain. For example, configure usa.example.com instead of USA.
    • F5 strongly recommends that you configure the domain controller’s Kerberos server name in the Kerberos server name (optional) field. For example, dc1.usa.example.com.
    • In the Domain admin name field, configure a domain administrator account or an account that is a member of the Active Directory Account Operators group. Additionally, on the domain controller, ensure that the password for this account will not expire.
    • For FirePass version 6.0.3 and later versions, the selection you make in the Mapping attribute menu determines whether resource groups will be assigned based on the Active Directory primaryGroupID attribute, the Active Directory memberOf attribute, or both attributes.

      Note: This option does not appear in versions prior to FirePass version 6.0.3.

  9. Click the Update button.
  10. Click the Master group mapping table tab.
  11. Select Active Directory from the Mapping Method menu.
  12. Click the Add button.
  13. In the Active Directory Group field, enter the name of the Active Directory group you want to map to a FirePass master group.
  14. In the FirePass Group menu, select the name of the FirePass master group to which the Active Directory group should map.
  15. Repeat Steps 13 and 14 for each additional group you want to map.

    For example, the mapping table entries for Example Company would appear as follows:

     

    Note: Users cannot belong to multiple master groups. If a user matches more than one entry in the master group mapping table, FirePass uses the first match it encounters. You can set the order in which matching operations occur by specifying the Priority number for the group in the master group mapping table.

  16. Click the Add button.
  17. Navigate to the Users: Groups: Master Groups page.
  18. Select the name of the master group you want to configure for master group mapping.
  19. Under the General tab, select the Allow users to be assigned to this master group using dynamic master group mapping check box to enable master group mapping for this master group.
  20. Click the Update button.
  21. Repeat Steps 17 through 20 for each master group you configured in the master group mapping table. For example, Example Company would perform these steps on the OfficeUsers and Vendors master groups.
  22. Navigate to the Users: Groups: Dynamic Group Mapping page.
  23. Click the Master group mapping table tab.
  24. At the bottom of the page, test master group mapping by entering an Active Directory username and password and then clicking the Test button. Review the test output to view which Active Directory groups are retrieved for the user account, and which master groups and resource groups are assigned based on the entries you configured in the group mapping tables. If a user matches multiple entries in the master group mapping table, the user will be assigned to the first match. You can change the matching order by updating the number in the Priority field for each master group mapping table entry.

Active Directory master group mapping is now configured. Users will be dynamically mapped to a master group at logon according to the mapping entries you configured in the Active Directory master group mapping table.

To validate or troubleshoot master group mapping, select an Active Directory account that belongs to a group you configured in the master group mapping table. Attempt to log in to FirePass using this account. In another browser window, navigate to the Reports: Logons page in the FirePass Administrative Console. Select the account name under the Logon column to view detailed information about the authentication and mapping process for that account (including reasons for failure).

Configuring Active Directory resource group mapping

The following procedure configures Active Directory resource group mapping. For the purpose of this example, Example Company is configuring resource group mapping, as follows:

  • If a user belongs to the Employees group in Active Directory, the user is assigned the OfficeUsers_resource resource group at logon.
  • If a user belongs to the Human Resources group in Active Directory, the user is assigned the HR_resource resource group at logon.
  • If a user belongs to the Domain Admins group in Active Directory, the user is assigned the SysAdmins_resource resource group at logon.
  • If a user belongs to the Primary Vendor group in Active Directory, the user is assigned the PrimaryVendor_resource resource group at logon.
  • If a user belongs to the Secondary Vendor group in Active Directory, the user is assigned the SecondaryVendor_resource resource group at logon.

Multiple resource groups can be assigned to a single user. At Example Company, all employees belong to the Employees group in Active Directory. Therefore, employees who work in human resources will be assigned the OfficeUsers_resource and HR_resource resource groups. Similarly, employees who are system administrators will be assigned the Employees_resource and SysAdmins_resource resource groups.

Note: If you enable dynamic resource group mapping for a master group, you can also statically assign resource groups under the Resource Group tab on the Users: Groups: Master Groups page. However, for simplicity and troubleshooting purposes, F5 recommends that you configure either static resource group mapping or dynamic resource group mapping, but not both.

In this procedure, F5 assumes that the required resource groups have already been configured on the Users: Groups: Resource Groups page.

Note: For information about configuring resource groups, refer to the FirePass Controller Administrator Guide.

  1. Log in to the FirePass Administrative Console.
  2. Navigate to the Users: Groups: Dynamic Group Mapping page.
  3. Under the Group mapping sequence tab, select the Determine the user's resource groups dynamically using global resource group mapping table check box.
  4. Click the Group mapping methods tab.
  5. If the Active Directory mapping method is not already configured, proceed to the next step. If you have already configured the Active Directory mapping method in the previous procedure, skip to Step 11.
  6. Select Active Directory from the Mapping Methods menu.
  7. Click the Add mapping method button.

    The Active Directory mapping method now appears.
  8. Click the configure link next to the Active Directory mapping method.
  9. Configure your domain controller information. For a description of each field, refer to the Users: Groups: Dynamic Group Mapping: Active-Directory based mapping page in the FirePass online help. Additionally, when configuring your domain controller information, keep the following points in mind:

    • In the Domain name field, configure the fully qualified domain name (FQDN) of the Windows domain. For example, configure usa.example.com instead of USA.
    • F5 strongly recommends that you configure the domain controller’s Kerberos server name in the Kerberos server name (optional) field. For example, dc1.usa.example.com.
    • In the Domain admin name field, configure a domain administrator account or an account that is a member of the Active Directory Account Operators group. Additionally, on the domain controller, ensure that the password for this account will not expire.
    • For FirePass version 6.0.3, the selection you make in the Mapping attribute menu determines whether resource groups will be assigned based on the Active Directory primaryGroupID attribute, the Active Directory memberOf attribute, or both attributes.

      Note: This option does not appear in versions prior to FirePass version 6.0.3.

  10. Click the Update button.
  11. Click the Resource group mapping table tab.
  12. Select Active Directory from the Mapping Method menu.
  13. Click the Add button.
  14. In the Active Directory Group field, enter the name of the Active Directory group you want to map to a FirePass resource group.
  15. In the FirePass Group field, select the name of the FirePass resource group to which the Active Directory group should map.
  16. Repeat steps 14 and 15 for each additional group you want to map.

    For example, the mapping table entries for Example Company would appear as follows:

     
     
  17. Click the Add button.
  18. Navigate to the Users: Groups: Master Groups page.
  19. Select the name of the master group you want to configure for resource group mapping.
  20. Under the General tab, select the Allow resource groups to be assigned to this master group using global dynamic resource group mapping check box to enable resource group mapping for this master group.
  21. Click the Update button.
  22. Repeat Steps 18 through 21 for each master group you want to configure for resource group mapping. For example, Example Company would perform these steps on the OfficeUsers and Vendors master groups.
  23. Navigate to the Users: Groups: Dynamic Group Mapping page
  24. Click the Resource group mapping table tab.
  25. At the bottom of the page, test resource group mapping by entering an Active Directory username and password and then clicking the Test button. Review the test output to view which Active Directory groups are retrieved for the user account and which master groups and resource groups are assigned based on the entries you configured in the group mapping tables.

Active Directory resource group mapping is now configured. Users will be dynamically assigned resource groups at logon according to the mapping entries you configured in the Active Directory resource group mapping table.

To validate or troubleshoot resource group mapping, select an Active Directory account that belongs to a master group you configured for dynamic resource group mapping (Steps 18 through 21). Attempt to log in to the FirePass controller using this account, and in another browser window navigate to the Reports: Logons page in the FirePass Administrative Console. Select the account name under the Logon column to view detailed information about the authentication and mapping process for that account, including reasons for failure.
