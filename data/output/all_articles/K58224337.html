Issue

Error Message

Failed to get file paths on device. One or more file paths missing.

Message Location

You may encounter this message in the following location:

  • The /var/log/restjavad.<age>.log file

    Note: <age> is a numeric value (typically 1 - 6) set when log files are rotated.

Description

This message occurs when the following condition is met:

  • You attempt to import a BIG-IP APM configuration into the inventory of BIG-IP devices.

Impact

This can prevent the BIG-IQ system from successfully importing the BIG-IP APM configuration into the inventory of BIG-IP devices.

Recommended Actions

To work around this issue, you can clear the restjavad cache on the target BIG-IP APM device. To do so, perform the following procedure:

  1. Log in to the BIG-IQ user interface.
  2. Navigate to Devices > BIG-IP Devices.
  3. Select the check box to the left of the Device Name.
  4. Click Remove All Services.
  5. Click Continue.
  6. Log in to the command line of the affected BIG-IP APM device.
  7. Type the following command.

    clear-rest-storage

  8. Log in to the BIG-IQ user interface.
  9. Navigate to Devices > BIG-IP Devices.
  10. Click Add Device.
  11. Enter the device IP Address, Port, User Name and Password.
  12. Click Add.

Note: For more information on managing the BIG-IQ system refer to the Device How do I start managing BIG-IP devices from BIG-IQ chapter of the BIG-IQ Centralized Management F5 BIG-IQ Centralized Management manual.
