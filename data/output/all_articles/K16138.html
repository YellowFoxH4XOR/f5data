K16138: Local traffic policy rules cannot be saved when using either an 'equals' or 'matches' condition

Known Issue

When adding a rule to a policy and including either an equals or matches condition, the Configuration utility unexpectedly changes the condition and fails to save the configuration. For example, when creating a policy using equals, the condition changes to the matches or when using matches,the conditional changes to equals.

This issue occurs when all of the following conditions are met:

  • You attempt to add a rule to a BIG-IP local traffic policy.
  • You include an equals or matches condition in the policy properties.

Impact

The Configuration utility does not allow users to create policies with an equals or matches condition.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When adding conditional rule properties, an equals condition is added as a matches condition or a matches condition is added as an equals condition.
  • An error similar to the following example appears in the Configuration utility screen and in the /var/log/ltm file:

    010716f4:3: Policy '/Common/<Policy_Name>', rule '<Policy_Rule>'; operand '<Operand>' does not support condition 'matches'.

    In this example, note the following:

    <Policy_Name> is the name of the policy
    <Policy_Rule> is the name of the policy rule within the policy
    <Operand> is the name of the operand configured in the policy rule

Workaround

To work around this issue, you should initially select a condition other than equals or matches in the Configuration utility, and then select the equals or matches condition. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Policies > Policy List.
  3. Select the policy you would like to add a rule to.
  4. Under Rules, click Add.
  5. Enter the properties for your rule.
  6. Under Condition, select a condition other than the equals or matches condition.
  7. Under Condition, select the equals or matches condition.
  8. To add your rule to the table, click Add.

    The rule will now be added with the equals or matches condition.

  9. Click Finished.
