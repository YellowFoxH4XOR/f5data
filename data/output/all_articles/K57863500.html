Description

When using non-ASCII chars, accounts in LocalDB cannot de unlock or be deleted.

Environment

  • Unable to delete/unlock the user account.
  • User accounts have non-ASCII chars.
  • The GUI can display them, but it's unable to delete them (popup window thrown).
  • The ldbutil can display the account if and only if the --allusers switch is used.

Cause

Bug ID 640267

Recommended Actions

  1. Use the command line utility ldbutil to delete an account:

    ldbutil --delete --uname="<Actual_UsernName>" --instance="<Full_path_to_Instance>"
