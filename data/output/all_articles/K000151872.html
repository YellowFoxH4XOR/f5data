K000151872: BIG-IP ASM/advanced WAF, OWASP Compliance page keep loading and ends up with "Unable to contact BIG-IP device"

Type
Support Solution
Published
2025-08-06
Updated
2025-08-17
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.0, 17.1.2, 17.1.1, 17.1.X, 17.5.X, 17.5.1, 17.5.0
Source
https://my.f5.com/manage/s/article/K000151872

Description

When accessing Security ›› Overview ›› OWASP Compliance in the BIG-IP GUI, you encounter an issue where the page doesn't load properly. A message appears stating: "Unable to contact BIG-IP device". You are operating with a large-scale security configuration.

Environment

  • BIG-IP ASM/advanced WAF
  • Many active policies with higher number of entities resulting in large security configuration
  • OWASP compliance overview 

Cause

This behaviour is documented in ID1701261.

Depending on configuration size and system resources, you may need to set it to a higher values for the browser-based Javascript status update interval and timeout.

Recommended Actions

Follow the workaround steps outlined in ID1701261. You may need to increase the values incrementally and test the results in multiple iterations.

Note: Restarting the UI daemons does not have any negative impact on the BIG-IP system’s traffic processing.
