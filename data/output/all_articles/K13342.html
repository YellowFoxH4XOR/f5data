Known Issue

If you use the config command of the F5 Management Port Setup Utility to change the Management Port settings to an IP address and subnet that conflicts with an existing Self-IP address, doing so results in the system deleting the original management interface settings.

This issue occurs when the following condition is met:

  • You use the config command to define a management IP address that conflicts with the subnet of an existing Self-IP address.

The IP address assigned to the management interface must be on a different network than the self IP addresses assigned to VLANs. If a conflicting IP address is configured with the config command, the command will correctly prevent the conflicting address from being set; however, the original management settings will have already been deleted, leaving the device with no management interface settings.

Impact

Connectivity to the management interface will be lost.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • When you specify conflicting network settings from the config command, the system will write error messages that appear similar to the following examples to the command line:
    • BIG-IP 11.x:

      01070391:3: Admin IP 1.1.1.2 / 255.255.255.0: This IP shares a network with a Self IP.
      Saving running configuration...
      /config/bigip_base.conf
      /config/bigip_user.conf

    • BIG-IP 9x-10x:

      Error publishing admin_ip = 1070391
      /config/bigip_base.conf was renamed to /config/bigip_base.conf.bak (42 lines).
      /config/bigip_sys.conf was renamed to /config/bigip_sys.conf.bak (28 lines).

  • Connectivity to the management interface will be lost.
  • The tmsh show sys ip-address command will show that the Management IP address and Management Route are no longer configured, as shown in the following example:

    -------------------------------
    Sys::IP Address
    Entry Component Object-ID
    -------------------------------
    127.0.0.1 cm device 11.1.com

  • The bigpipe mgmt and bigpipe mgmt route commands will show that the Management IP address and Management Route are no longer configured, as shown in the following examples:

    #bigpipe mgmt

    No management interface IP addresses were found.

    #bigpipe mgmt route

    No management route entries were found.

Workaround

To work around this issue, you can make changes to the management port settings from the Configuration utility. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: This workaround will not allow you to configure a Management IP on the same subnet as a Self-IP, as that is not an allowed configuration. However, if you attempt such a configuration change using the Configuration utility, the system will not delete the existing Management Port settings during the process.

  1. Log in to the Configuration utility.
  2. Navigate to the System > Platform menu.
  3. In the Management Port section, enter the new configuration data into the appropriate fields.
  4. Click Update.

Recovering from this issue

To recover from this issue you can configure the management port settings by connecting to the serial console port, connecting from the LCD panel of the device, or connecting from a Self-IP. To do so, perform one of the following procedures:

Configuring the management port settings using the serial console port

Configuring the management port settings from the LCD panel

Configuring the management port settings by connecting to the Configuration utility on a self-IP address

Configuring the management port settings using the serial console port

  1. Connect a terminal emulator to the BIG-IP system by using the serial port.

    Note: For more information about configuring terminal emulation, modifying baud rates, and the null modem serial cable requirements, refer to the following articles:

    K7683: Connecting a serial terminal to a BIG-IP system

    K4477: Setting the baud rate of the serial console port using the LCD panel

    K9156: Setting the baud rate of the serial console port

    K587: Pinouts for serial terminal cables used to connect to F5 products

  2. From the BIG-IP command line, start the F5 Management Port Setup tool by typing the following command:

    config

  3. Enter the appropriate data in the screens that follow to assign an IP address, netmask, and default management route to the management interface.

Configuring the management port settings from the LCD panel

You can set the management network settings by using the LCD display and keypad on the front panel of the device. For more information about this process, refer to the appropriate Platform Guide for your hardware platform.

Configuring the management port settings by connecting to the Configuration utility on a self-IP address

Note: By default, the BIG-IP system is not configured to allow connections to the Configuration utility on a self-IP address. F5 does not recommend this configuration; however, if you have modified the self-IP port lockdown settings to allow access to the Configuration utility, you can use this method to re-configure the management port settings.

  1. Log in to the Configuration utility.
  2. Navigate to the System > Platform menu.
  3. Enter the configuration data into appropriate fields in the Management Port section.
  4. Click Update.
