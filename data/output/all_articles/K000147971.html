K000147971: What ports are being used by the F5 Distributed Cloud platform?

What Happened?

  • I want to know what ports are reserved/used by the F5® Distributed Cloud (XC) platform to understand if after doing a vulnerability test its a false positive.
  • I did a vulnerability test and some dynamic ports are open, and I would like to know a reason for getting those ports open.

Environment

  • F5® Distributed Cloud HTTP Load Balancer

Resolution/Answer

  • Distributed Cloud Services uses port range 65000-65535

Additional Information

  • We also use the port 23790 (ETCD)
