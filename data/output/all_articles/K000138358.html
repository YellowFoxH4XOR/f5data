Description

In the Configuration Utility (GUI) There is a Local Traffic SSL profile called "Certificate Authority".

Local Traffic ›› Profiles : SSL : Certificate Authority

 

It is not clear what this is used for. The manuals of SSL profiles do not refer to it.

Environment

APM is provisioned.

Cause

Although this object is under "Local Traffic", it is not used by any Client or Server SSL profile.

 

Recommended Actions

This profile is used by the APM Endpoint Inspection Object "Machine Certificate" . A Machine Certificate is issued by Active Directory to all Domain Joined devices.

The "Certificate Authority" Profile is used to validate that certificate. As such it must be set to the Windows Root Certificate.

Additional Information

Despite being in "Local Traffic", this profile has nothing to do with Local Traffic.
