K000137971: How to integrate Kiali and Prometheus with Aspen Mesh

Description

This article will provide the steps on how to integrate Kiali with prometheus using Aspen Mesh.

Environment

Aspen Mesh 1.14.X

Cause

Kiali and Prometheus are not added after installing Aspen Mesh, and some specific configuration needs to be applied in order to be able to use Kiali with Prometheus.

Recommended Actions

1.  If you have already installed Kiali and Prometheus, please remove the deployments added into the cluster:

kubectl delete deployments.apps prometheus -n istio-system
kubectl delete deployments.apps kiali -n istio-system
kubectl delete deployments.apps kiali-operator -n kiali-operator
IF kiali was installed with helm: helm uninstall --namespace kiali-operator kiali-operator


2. Update your override values yaml file and add the following value:

meshConfig:
  enablePrometheusMerge: true

and apply it with the command:

helm upgrade istiod manifests/charts/istio-control/istio-discovery \
    --namespace istio-system \
    --values <aspenMeshOverrideValuesFilename>

You can verify if it has the correct value(true) with this command:

kubectl get cm istio -n istio-system -o jsonpath='{.data.mesh}' | grep Prometheus

Once this value is added into the Aspen Mesh istio config. You will have to restart the deployments of the applications you want to monitor with the inbound/outband traffic metrics, because the prometheus scrape annotation needs to be added into the pod for prometheus to monitor it. 
 

3. You have to install prometheus with tls. The prometheus config yaml is located on the AspenMesh folder under the path samples/addons/extras/prometheus_vm_tls.yaml

  
kubectl apply -f aspenmesh-carrier-grade-1.14.6-am5/samples/addons/extras/prometheus_vm_tls.yaml


4. Install the latest kiali release with helm:

  
helm repo add kiali https://kiali.org/helm-charts

helm install \
    --set cr.create=true \
    --set cr.namespace=istio-system \
    --namespace kiali-operator \
    --create-namespace \
    kiali-operator \
    kiali/kiali-operator


Additional Information

In order to access the dashboard, please follow these steps:

 
  • Use port-forwarding to access Kiali Dashboard by running this command:
kubectl port-forward svc/kiali 20001:20001 -n istio-system
  • And use the output of the following command to get the token to login:
kubectl -n istio-system create token kiali-service-account
