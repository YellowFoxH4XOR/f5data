K70322038: No Graph shows after upload a no license BIG-IQ DCD to iHealth

Applies to

Source

Description

Start from v7.1.0, BIG-IQ DCD do not require a license any more. After the qkview which generate from a no license BIG-IQ DCD system upload to iHealth system, the Graphs will not be there. No available data to check the system CPU/Memory usage from iHealth Graphs.

Environment

  • BIG-IQ DCD
  • iHealth
  • Qkview

Cause

This is expected behavior. iHealth system fetch the data from RRD which get data from daemon statsd. But statsd need a license to be functional.

Recommended Actions

Suggest to check the CPU/Memory from BIG-IQ DCD GUI "The Devices-->Statistics".
