Known Issue

The FTP pool member statistics for current connections may not decrement.

This issue occurs when all of the following conditions are met:

  • You have an FTP virtual server with address translation disabled.
  • You have a custom FTP profile with the Inherit Parent Profile option enabled.

During active FTP sessions with the above configuration, the current connections statistics value does not decrement when the FTP data connection closes.

Impact

This issue is primarily cosmetic. However, if you configure pool members with connection limits, the members may be disabled erroneously.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You observe incorrect current connections pool statistics using the Configuration utility, in the following location:

    Statistics > Module Statistics > Local Traffic > Pools
  • You observe incorrect current connections pool statistics using the Traffic Management Shell (tmsh) with the tmsh show /ltm pool <pool_name> command.

    For example:

    tmsh show /ltm pool ftp_pool

Workaround

To work around this issue, you can disable the Inherit Parent Profile option in the FTP profile. To do so, perform the following procedure:

Impact of workaround: The Inherit Parent Profile option enables the FTP data channel to inherit the TCP profile used by the control channel. If disabled, the data channel uses the FastL4 profile only. The default is not selected (disabled). When you apply changes to the FTP profile, virtual servers using the affected FTP profile may have service disruption. F5 recommends that you perform this modification during a maintenance window.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles > Services > FTP.
  3. Select the affected FTP profile.
  4. In the Settings section, clear the box next to Inherit Parent Profile.
  5. Click Update.
