Description

After relicense and system reboot, remote authentication is not working.

Remote authentication traffic is trying to use data route instead of management route.

 

Environment

  • BIG-IP
  • Remote Authentication
  • Licensing/Reboot

 

Cause

Missing management route

 

Recommended Actions

Use the following commands to verify the configuration and routing table:

 

tmsh list sys management-route

ip route

 

Verify the route entries are correct for the remote authentication server, and re-add if necessary.

 

Additional Information

K28172750: The Big-IP can be configured to use either tmm or mgmt interfaces for remote authentication (LDAP, TACACS, RADIUS, etc.) traffic.
