Known Issue

The BIG-IP Configuration utility and bigpipe commands incorrectly allow users to create hybrid disk volumes (HDx.x and MDx.x together).

This issue occurs when all of the following conditions are met:

  • You are running the BIG-IP 6900 or 8900 platform
  • You upgrade from BIG-IP 10.0.x to BIG-IP 10.1.0 through 10.2.4
  • You attempt to create a mirrored volume set

A BIG-IP 6900 or 8900 platform that is running BIG-IP 10.0.x does not use hard drive mirroring and uses one hard drive and non-mirrored volumes, such as HD1.1 and HD1.2. If you upgrade the system to BIG-IP 10.1.0 through 10.2.4, the system still does not use hard drive mirroring and continues to use one hard drive and non-mirrored volumes. However, after the upgrade, the BIG-IP system incorrectly allows users to create mirrored volume sets. The new mirrored volume sets, for example MD1.1 and MD1.2, are not useable.

Impact

The BIG-IP system fails to create a useable mirrored volume set.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP system displays MDx.x as a volume, but does not allow you to install images to that volume.
  • After you attempt to create the mirrored volume set, the bigpipe software command indicates that the system failed to create the volume set.

    For example:

    # bigpipe software status

    SOFTWARE - Status:
    +-> SOFTWARE STATUS
    | Key Slot Product Version Build Active Status
    | HD1.1 0 BIG-IP 10.2.1 297.0 yes complete
    | HD1.2 0 BIG-IP 10.0.1 283.0 no complete
    | HD1.3 0 none none none no complete
    | MD1.1 0 none none none no failed to create volumeset

Workaround

If you are running BIG-IP 10.1.0 through 10.2.4 with non-mirrored volumes and you need to change to mirrored volumes, you can use the image2disk installation method outlined in K10856: Overview of hard drive mirroring.
