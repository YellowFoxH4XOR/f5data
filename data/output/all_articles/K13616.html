Known Issue

Modifying the BIG-IP management interface media type to any value other than auto or 1000baseT full may disable Auto-MDIX.

This issue occurs when all of the following conditions are met:

  • The BIG-IP system platform is one of the following: 1600, 3600, 3900, 6900, 8900, 8950, 11000 or 11050.
  • You have modified the media of the management interface to a value that is not auto or 1000baseT full.

For more information on Auto MDI/MDIX, refer to K9787: Auto MDI/MDIX behavior for BIG-IP platforms.

Impact

Network connectivity through the management interface may be impaired.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H386550 on the Diagnostics > Identified > Medium screen.
  • The management interface's speed and activity LEDs are not lit, indicating there is no link.
  • Network connectivity via the management interface is no longer accessible.

Workaround

To work around this issue, you can change the media of the management interface to Auto MDI/MDIX by performing the following procedure:

Impact of workaround: None.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Modify the management interface to Auto MDI/MDIX by typing the following command:

    modify /net interface mgmt media auto

  3. Save the change by typing one of the following commands:

    BIG-IP 10.1.0 and later:

    save /sys config

    BIG-IP 10.0.x:

    save config
