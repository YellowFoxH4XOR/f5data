Description
When configuring router-id in ZebOS you may get the error below:

^ "% Invalid input detected at '^' marker."

For example, 

[$HOSTNAME][0](config-router)# router-id 2620:160:d1de:xx::xxxx 
^ "% Invalid input detected at '^' marker."

Environment

  • BIG-IP
  • ZebOS

Cause

Running "router-id  ?" command on CLI confirms it only expects an IPv4 argument.

Recommended Actions

Ensure router-id command is followed by IPv4.

[$HOSTNAME][0](config-router)#router-id aaa.bbb.ccc.ddd

ex.
[$HOSTNAME][0](config-router)#router-id 192.168.1.1
