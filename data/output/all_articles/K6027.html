Security Advisory Description

Note: Versions that are not listed in this Solution have not been evaluated for vulnerability to this security advisory. For information about F5 Networks' security policy regarding evaluating older and unsupported versions of F5 Networks products, refer to SOL4602: Overview of F5 Networks security vulnerability response policy.

Some of the nCipher FIPS SSL cards supplied by F5 Networks for the FIPS BIG-IP are potentially vulnerable to the attack described in nCipher Advisory #14, as follows:

http://www.ncipher.com/resources/97/sa14_presence_of_flaws_in_firmware_security

Due to the potential vulnerability, F5 Networks has received updated firmware for nCipher FIPS SSL accelerator cards. The nCipher FIPS SSL accelerator was used in FIPS-compatible BIG-IP systems running versions 4.5 and 4.6.

This issue does not affect any other SSL accelerators shipped by F5 Networks.

Vulnerable firmware versions and cards

All nCipher PCI and PMC FIPS cards are vulnerable. FIPS firmware version 1.x.x prior to 1.77.100 and version 2.x.x prior to 2.12.9 are vulnerable with the following cards:

  • nC1001P/nC3021P
  • nC1002P/nC3022P
  • nC1003P/nC3023P

Determining the nCipher firmware version

You must ensure that all FIPS cards in your BIG-IP system are in operational mode, which means that the M-O-I switch is set to the letter O, before running any commands to determine the version of your nCipher firmware. You should reboot the system before checking the version number if the system was not in operational mode.

To determine the nCipher firmware version installed on your BIG-IP system, perform the following steps:

  1. At the command line, type the following command:

    enquiry 1

    The firmware version and product name for the first card will display. For example:

    version 1.77.98
    product name nC1001P/nC3021P

  2. If you have two FIPS cards in the same system, type the following command:

    enquiry 2

    The firmware version and product name for the second card will display.

Preparing to upgrade

Important: nCipher has warned that the security world may be destroyed while upgrading this firmware if certain types of certificates are used; however, early testing indicates that this should not be the case for F5 Networks customers.

Before you upgrade your nCipher firmware, it is important to consider the following information:

  • You must have your administrator card available in order to upgrade. The upgrade process destroys any data on the nCipher FIPS card and you will need to restore the security world on the FIPS card when the process is complete. If you have more then one card, have additional cards and passwords available.
  • Upgrading the firmware is a delicate process. If an error occurs during the firmware upgrade, the FIPS card may be rendered completely inoperable and unrecoverable. If this occurs, contact F5 Networks Technical Support immediately to determine if an RMA will be required.
  • Perform the firmware upgrade while the BIG-IP system is in standby mode. If you have a BIG-IP redundant system, you can configure the active unit to handle traffic while you upgrade the standby unit. If you do not have a redundant system, place the BIG-IP system in maintenance mode during the upgrade process. To access standby and maintenance mode from the Configuration utility, click System in the navigation pane and select the Properties tab. If you have a redundant system, click System and select the Redundant Properties tab.
  • If your BIG-IP system contains more than one FIPS card, upgrade the FIPS cards one at a time.

Obtaining the upgrade software installation package

To obtain the upgrade package, contact F5 Technical Support.
