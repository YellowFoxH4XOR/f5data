Description

When trying to disable Network Failover in the failover device group configuration (under Device Management >> Device Groups >> your failover group name), it fails with

01071bce:3: Device /Common/<bigip_hostname> platform requires network-failover to be enabled for device-group /Common/<sync-failover_group>.


Also, if you have disabled Network Failover in the failover device group and upgrade to v13.0.0 or higher, you notice that the system enabled Network Failover during upgrade.

 

Environment

  • BIG-IP VE, vCMP guests v13.0.0 and later 
  • Guests are on VIPRION chassis
  • HA pair configured 
     

Cause

Starting in v13.0.0, the BIG-IP now validates to ensure that Network Failover is enabled in a high availability (HA) pair on platforms such as BIG-IP VE, vCMP guests, VIPRION chassis that cannot have serial (hard-wired) failover configuration.  This change is part of the fix for ID 611054.
 

Recommended Actions

Do not try diable Network Failover in HA configuration on BIG-IP VE, vCMP guests and VIPRION chassis.
