Description

BIG-IP AFM is not processing any user traffic going through the BIG-IP.

A pcap will show that the BIG-IP AFM will either drop or reject the incoming user traffic.

The BIG-IP AFM is in Firewall mode. To confirm this, navigate to Security > Options > Network Firewall and on Virtual Server & Self IP Contexts the option chosen is either Drop or Reject.

Environment

  • BIG-IP AFM provisioned
  • AFM is in Firewall mode

Cause

This is an expected behavior as AFM Firewall mode will Drop or Reject all traffics.

Recommended Actions

To allow traffic to be process, perform one of the following procedures:

  1. Create rule(s) to Accept traffic for each Virtual Servers
  2. Change the AFM to ADC mode by referring to K92958047: What is the difference between "ADC mode" and "Firewall mode" for AFM?
