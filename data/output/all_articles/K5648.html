Beginning in BIG-IP version 4.6.3, you can configure the number of retry attempts that the syslog utility will make to write messages. To change the number of retry attempts, perform the following steps:

  1. Log in to the command line.
  2. Create a symbolic link named /etc/syslogretries.conf and assign it a value, by typing the following command syntax:

    ln -s <value>* /etc/syslogretries.conf

    Replace <value> with the number of retry attempts you would like the syslog utility to make. The default value is 2; a reasonable starting value is 50.

    Important: Changing the number of retry attempts will impact performance of your system. F5 Networks Support recommends testing the new configuration before using it introduction to determine the effect.

  3. Restart the system daemons, by typing the following command:

    bigstart restart

The syslog utility will now log messages more frequently.
