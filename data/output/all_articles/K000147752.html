Description

  • How can I review in detail CSRF policy violations?
  • The event details only show 'svc_policy_sec_event' in the 'sec_event_type' field.

Environment

  • F5® Distributed Cloud
  • Cross-Site Request Forgery Protection

Resolution/Answer

To review CSRF violations in detail:

1. Go to Web App & API Protection

2. Select the Namespace.

3. Go to Overview > Security.

4. Select the desired load balancer from the list at the bottom of the page.

5. Go to the Security Analytics tab.

 

6. Click on the Cog button at the mid-right of the page and check the Event Name box.

7. The Event Name column will populate, and you will be able to see all related CSFR policy violations.

Additional Information

The CSRF protection in XC is set up differently from the norm. It is configured under the load balancer (LB) rather than the web application firewall (WAF). The following tooltip explains this further:
