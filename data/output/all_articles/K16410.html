Known Issue

Platforms with Cavium Nitrox cards may close Secure Sockets Layer (SSL) connections prematurely when processing highly fragmented SSL records.

This issue occurs when all of the following conditions are met:

  • You have a BIG-IP platform with a Cavium Nitrox card.

    Note: This issue does not affect the BIG-IP 1000, 2400, 51x0, 2000s, 2200s, 4000s, and 4200v platforms. All other current BIG-IP platform models are equipped with Cavium Nitrox SSL or hardware compression hardware.
  • You have configured the BIG-IP system to encrypt and decrypt SSL traffic using an SSL profile.
  • The BIG-IP system is processing SSL connections with highly fragmented SSL records.

Impact

The BIG-IP system disconnects SSL connections prematurely.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H517353 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system disconnects Client SSL connections prematurely.
  • The SSL profile shows a significant number of increasing Bad records:

    # tmsh show ltm profile client-ssl test_clientssl | grep -A 3 Records
    Records                                                     
      In                                                           213.0K
      Out                                                            9800
      Bad                                                            2300
