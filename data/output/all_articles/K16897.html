Topic

The BIG-IP system does not currently include IPv6 support for Terminal Access Controller Access-Control System Plus (TACACS+) and RADIUS authentication.

    Description

    If the BIG-IP system is configured to communicate with remote TACACS+ or RADIUS servers by using an IPv6 address, the BIG-IP system will not send any requests to the remote server. A packet capture will reveal that the BIG-IP system is not sending any authentication requests, as IPv6 addresses are not supported for remote TACACS+ and RADIUS authentication methods.

    Recommendations

    When planning to implement TACACS+ or RADIUS authentication for the BIG-IP system, you should consider the following factors:

    • You should configure the remote TACACS+ or RADIUS server with an IPv4 address.
    • You should configure the BIG-IP system to communicate with the remote TACACS+ or RADIUS servers by using IPv4.
