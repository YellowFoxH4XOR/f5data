K000148203: Why is the KVM site stuck in provisioning state?

What Happened?

  • KVM site is stuck in a provisioning state
  • From the Customer Edge (CE) console, you can see the following statuses:
    • VER NotReady
    • dnsmasq NotReady

Environment

  • KVM site running on Proxmox, QEMU, or any other virtualization platform.

Resolution/Answer

Currently KVM Site/CE deployment is in Early Access (EA) and can be use for proof of concept (PoC) or proof of value (PoV) deployments. There is no full support for that type of deployment. 

 

  • VER not ready:  The wrong HW type was chosen, you need to use kvm-voltstack-combo or kvm voltmesh

  • dnsmasq does not run:  Change CPU Type to "Host" (Proxmox) or "Copy host CPU configuration" (QEMU)
