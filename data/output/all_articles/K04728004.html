Description

As some CVEs may related with the microcode version of the CPU, this article is about how to check the microcode version on BIG-IP.

Environment

  • BIG-IP

Cause

None

Recommended Actions

Please login to the bash (SSH or console), then run the command below:

cat /proc/cpuinfo

For example:

# cat /proc/cpuinfo
processor       : 0
vendor_id       : GenuineIntel
cpu family      : 6
model           : 79
model name      : Intel(R) Xeon(R) CPU E5-1650 v4 @ 3.60GHz
stepping        : 1
microcode       : 0xb000022                    ///// the answer
cpu MHz         : 3601.000
cache size      : 15360 KB
.....omitted...
