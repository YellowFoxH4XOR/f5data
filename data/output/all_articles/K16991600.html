K16991600: Unable to post Cloud Failover extension JSON file error message ''Invalid request body''

Type
Support Solution
Published
2022-08-18
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP Cloud Edition
Source
https://my.f5.com/manage/s/article/K16991600

Description
When following the F5 Cloud Failover Extension QuickStart guide,  You are unable to post Cloud Failover Extension, CFE, JSON file. It fails while running the post request to BIG-IP returning the below error message as in the follow-up sample::

curl -su admin: -X POST -d @cfe-file.json http://localhost:8100/mgmt/shared/cloud-failover/declare | jq . 

The above command output will return the below error message:
{
  "message": "Invalid request body. Content type should be application/json"
}

In the BIP-IP, in the /var/log/restnoded, this error will be shown: 

restnoded   Severe  f5-cloud-failover Invalid request body. Content type should be application/json

Environment

  • BIG-IP Cloud Edition
  • Could Failover Extension

Cause
This issue is caused when we tried to post a CFE using a POST HTTP method and the content-type header is not specified in the REST call.

Recommended Actions

In order to fix this issue, the CFE file needs to be posted into the BIG-IP including the HTTP content-type header
 
curl -su admin: -X POST -d @cfe.json http://localhost:8100/mgmt/shared/cloud-failover/declare -H 'Content-Type: application/json' | jq
