K000160062: BIG-IP APM: Authentication failures occur when domain-cookie is set to parent domain across multiple environments

  • BIG-IP APM: 17.0.0, 17.1.0, 17.0.X, 17.X.X, 17.5.X, 17.5.1, 17.5.0, 17.1.X, 17.1.3, 17.1.2, 17.1.1
Source

Description

When using BIG-IP APM with multiple environments that share a parent domain (for example, example.com and sso-test.example.com), authentication failures may occur when switching between environments. This is due to Access Profiles configured with the "domain-cookie" value set to the parent domain, causing browsers to send the same MRHSession cookie to both environments. The test environment receives session cookies issued by the production environment, which it cannot validate, resulting in failed authentication attempts.

Environment

  • Two environments:
    • Production: example.com
    • Test: sso-test.example.com
  • Multiple Access Profiles configured with "domain-cookie" set to example.com
  • "domain-mode" set to single-domain, scope set to profile

Cause

The "domain-cookie" value in APM Access Profiles is set to the parent domain, causing MRHSession cookies to be valid for the entire domain. Browsers send these cookies to both production and test environments, but the test environment cannot validate session IDs issued by production, resulting in authentication failures.

Recommended Actions

  • Remove the "domain-cookie" value from all APM Access Profiles to restrict cookies to the specific host, preventing cross-environment cookie reuse.
  • After removing the domain-cookie value, instruct users to clear all existing APM cookies from their browsers to ensure only host-specific cookies are used.
  • If cross-environment authentication is required, consider implementing an iRule to check session validity and delete invalid cookies. This may force re-authentication if users access both environments simultaneously. Please not that F5 Technical Support does not provide iRule Support
  • Monitor for any further authentication issues after applying these changes.
