Description

A bigd HTTPS monitor can use different TLS cipher suites for TLS Client Hellos depending on whether the monitor's ssl-profile is set to none, or an explicit serverssl profile is assigned. This article details the behavior differences between the two.

 

 

Environment

- BIG-IP LTM

- bigd monitors in use (not In-TMM)

- HTTPS monitor ssl-profile set to none

- HTTPS monitor ssl-profile explicitly set to a serverssl profile

 

 

Cause

With ssl-profile set to none on a bigd HTTPS monitor, the monitor will use the system default OpenSSL default cipher suites for the ssl connection.

 

If a bigd HTTPS monitor is explicitly configured with an ssl-profile, the monitor will use that profile's settings.

 

 

Answer/Recommended Actions

Assign a serverssl profile explicitly to the HTTPS monitor when specific TLS ciphers are required.
