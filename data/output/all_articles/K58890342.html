Description

Statistics output results show as -nan when running the command tmsh show sys performance

  • tmsh show sys performance

    Sys::Performance Connections
    ---------------------------------------------------------------------------
    Active Connections           Current  Average  Max(since 10/20/20 23:43:51)
    ---------------------------------------------------------------------------
    Connections                     -nan     -nan                          -nan

 

Environment

  • CLI
  • BIG-IP performance report

Cause

When the system date output for the date command and the EPOCH format is different, statistics report output shows as nan. 

For Example:

  • #  date +%s
    1603248296
  • # /var/rrd/rrdtool info memory | head -4
    filename = "memory"
    rrd_version = "0003"
    step = 10
    last_update = 1664254325
  • # date -d '1970-01-01 1603248296 sec utc'
    Wed Oct 21 02:44:56 UTC 2020            <-----<< 
  • # date -d '1970-01-01 1664254325 sec utc'
    Tue Sep 27 04:52:05 UTC 2022            <-----<< 

Recommended Actions

  1. Make sure BIG-IP time is sync with ntp server
    #ntpq -np

  2. Reset the performance stats using the below command
    # tmsh reset-stats sys performance all-stats
