Known Issue

Secure Sockets Layer (SSL) connections may reset or experience degraded performance after failover events.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured as part of a high availability (HA) group.
  • Your BIG-IP system is configured with a virtual server that has an associated Client SSL profile configured with SSL session mirroring.
  • The virtual server that has an associated Client SSL profile configured with SSL session mirroring is also configured with connection mirroring enabled.
  • Your BIG-IP system is actively processing traffic for the virtual server.
  • The active BIG-IP device fails over to the peer device.
  • The newly active peer device fails over back to the original active device.

Impact

Mirrored connections may be reset by the associated BIG-IP virtual server or experience a degradation in response time.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After multiple BIG-IP failover events, returning virtual connections are reset.
  • Returning connections experience a lengthy response delay of up to several minutes when attempting to reconnect to the affected BIG-IP virtual server.

Workaround

To work around this issue, you can disable session mirroring in the Client SSL profile or disable connection mirroring in the virtual server configuration. To do so, perform one of the following procedures:

  • Disabling session mirroring of a Client SSL profile
  • Disabling connection mirroing of a virtual server

Disabling session mirroring of a Client SSL profile

Impact of Workaround: Performing the following procedure will remove the ability to mirror the state information for SSL connections processed by the Client SSL profile between BIG-IP HA peer devices.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Profiles SSL > Client.
  3. Click the name of the affected Client SSL profile.
  4. Clear the Session Mirroring check box.
  5. Click Finished.

Disabling connection mirroring of a virtual server

Impact of Workaround: Performing the following procedure will remove the ability to mirror the state information for SSL connections processed by the Client SSL profile between BIG-IP HA peer devices.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server Lists.
  3. Click on the name of the affected virtual server.
  4. Set Configuration to Advanced.
  5. Clear the Connection Mirroring check box.
  6. Click Update.
