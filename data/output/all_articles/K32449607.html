K32449607: Unable to add BIG-IP VM to License Manager

Type
Support Solution
Published
2022-06-29
Updated
2025-02-06
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K32449607

Description
Customer not able to add new ELA license to BIG-IP via BIG-IQ.

  • The system returned an unexpected error "400 Bad Request". This device has the same machineId, but a different macAddress as another license assignment for device IP.

Environment

  • ELA license
  • BIG-IQ VE 8.1
  • BIG-IP VE

Cause
The error specific to this VM is because we had to change the NIC assignments as this VM has more than 5 NICs and is impacted by the NIC reordering behavior change when upgrading to 15.1.5.1, see K40398645. This error persisted even after attempting to delete the license file on the VM before retrying.

 

Recommended Actions

  1. Forcibly remove licensed devices from BIG-IQ:
    a. Shut down the troublesome BIG-IP
    b. Then revoke the BIG-IP from BIG-IQ
  2. The above will allow another push of the ELA license in the event of a MAC change
