To check the syntax of the wideip.conf file, type the following command:

3dparse - picky

This command will parse and verify the syntax and validate the configuration semantics including global value ranges and multi-value dependencies (for example, TTL settings must be greater than timers for data categories). It will also verify that the load balancing and metric collection settings are configured properly.

For more information, refer to the 3dparse man page by typing the following command:

man 3dparse
