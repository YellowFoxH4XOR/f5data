Issue

The Disk Monitoring section located on the Device Management >> Monitoring System Health page of the FirePass controller's Administration console displays the following message when operating under normal conditions:
 
Disk Monitoringno errorsOK

If the Disk Monitoring section displays an ALARM message that is similar to the example below, the hard disk drive may fail and cause the FirePass controller to crash or fail to boot at the next restart:

Disk Monitoringerrors foundALARM

1Raw_Read_Error_Rate0x000-b200001051Pre-failAlwaysIn_the_past0

You may also receive messages located on the Reports >> System Logs page, similar to the following example:

DateTimeSourceMessage
Feb 1008:02:47firepass[-] Errors detected while monitoring disc drive. The drive is prone to permanent failure and need immediate attention. It is recommended that you check the status of the drive in the Health Monitor in the Administrative Console.

If this type of error message displays, the Self-Monitoring, Analysis, and Reporting Technology (SMART) firmware may be indicating a significant probability of hard disk drive failure. Open a support case with F5 Networks Technical Support, and provide all hard disk drive-related error messages from the Disk Monitoring and System Logs, including any repetitions of an error message. F5 Networks Technical Support will determine whether the errors indicate hard disk drive failure.

Important: If you see the ALARM displayed in the Disk Monitoring section, perform a full backup of your configuration and log messages as soon as possible. You can perform a backup of your configuration and log messages. Refer to the Device Management >> Maintenance >> Backup/Restore page for more information.

The hard disk drive is not a field-replaceable component. Therefore, your FirePass must be returned to F5 Networks if hard disk drive replacement is needed. To return your FirePass controller to F5 Networks, open a support case with F5 Networks Technical Support, if you have not done so already. F5 Networks Technical Support will issue a Return Merchandise Authorization (RMA).
