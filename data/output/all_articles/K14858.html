Topic

This article includes information about the idle time-out process for mirrored FastL4 connections on the standby system.

Description

To help prevent service interruption during failover, you can configure an active BIG-IP system to mirror FastL4 connection information to its standby system.

To mirror FastL4 connection information, the active system synchronizes the FastL4 connection information to the standby system during each packet or flow state update. When the standby system receives the mirrored FastL4 connection information, it decapsulates the packets, adds them to the connection table, and sets the idle time-out to six seconds for the mirrored FastL4 connection. The standby system then counts down the idle time-out for the mirrored FastL4 connection to zero, and then checks the mirrored FastL4 connection with the active system. If the mirrored FastL4 connection on the active system has timed out or closed, the standby system removes the mirrored FastL4 connection from its connection table. However, if the mirrored FastL4 connection is still open on the active system, the standby system resets the idle time-out for the mirrored FastL4 connection to six seconds and counts down to zero. The standby system continually repeats this behavior to prevent the mirrored FastL4 connection from timing out before the connection on the active system times out or closes.

You cannot configure the idle time-out value for mirrored FastL4 connections on the standby system. This behavior is by design.
