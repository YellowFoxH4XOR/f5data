Description

You would like to manually set or change the management IPv4 address and/or default gateway for the BIG-IP management interface.

Environment

  • BIG-IP

Cause

None

Recommended Actions

  1. Logon to the BIG-IP Configuration utility (webUI).
  2. Go to System > Platform.
  3. For Management Config IPv4 select Manual.
  4. In IP Address[.prefix] enter your IPv4 address for use by the BIG-IP.
  5. In Network Mask enter the network mask for the IPv4 address.
    Important:  Use of a /32 network mask will prevent the ability to set a Management Route.
  6. In Management Route enter the default gateway IPv4 address.
    Important: The Management Route must be on the same network as the Management IPv4 Address.
  7. Click Update.
    Important: When connecting to the BIG-IP using the management address, changing this address will require that you reinitiate access to the BIG-IP using the new IPv4 address.
