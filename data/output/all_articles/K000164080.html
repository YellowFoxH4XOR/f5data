K000164080: Using address as selector for policy strategy may result in an inoperable BIG-IP

Type
Support Solution
Published
2026-11-03
Updated
2026-11-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000164080

Description

Selecting "address" as the Selector for a custom policy strategy may result in a failure to reload configuration with the following error seen from commandline:

load_config_files[22114]: "/usr/bin/tmsh -n -g -a load sys config partitions all " - failed. -- 010716f6:3: Strategy '/Common/test_policy'; operand 'tcp' does not support selector 'all'.

Environment

  • Policy Strategy creation
  • BIG-IP v17.5.x
  • Configuration reload

Cause

ID 2694269

Answer/Recommended Actions

In the event that the BIG-IP is unable to load the configuration, to recover, manually remove the newly created policy strategy statements by editing the file /config/bigip.conf:  

  1.  Locate the configuration block starting with the name of the policy strategy.
  2. Delete the above policy strategy configuration block.
  3. Execute "reloadlic" from commandline to force the reloading of the entire configuration.

For example, delete the following policy strategy configuration block:

ltm policy-strategy /Common/test_policy {
    operands {
        1 {
            tcp
        }
    }
    strategy best-match
}

Additional Information

This issue does not affect v21.x
