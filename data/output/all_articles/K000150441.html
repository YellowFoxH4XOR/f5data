Description

Trying to add a new LTM device to iQuery mesh with bigip_add script. It fails, and the following logs start to appear in /var/log/gtm:

alert gtmd[18795]: 011ae0f3:1: SNMP_TRAP: big3d SSL cert EXPIRED at IP <IP_ADDRESS>

Environment

  • BIGIP GTM
  • BIGIP LTM
  • expired certificate

Cause

LTM device certificate is expired. This certificate can be found under System > Certificate Management > Device Certificate Management > Device Certificate.

Recommended Actions

Renew the LTM device certificate, remove the old certificate from the GTM device, and exchange the new certificate using the bigip_add scrip.

Additional Information

Information about updating the certificate and exchanging it can be found in K6353.
