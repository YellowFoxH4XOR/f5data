Important: Re-imaging the VIPRION platform is generally not required. Consult with F5 Technical Support to determine whether you should perform the procedure described in this Solution..

Note: A USB CD-ROM drive and a CD recordable are required to perform the procedure described in this Solution.

To re-image the VIPRION platform with BIG-IP LTM 9.6.1, perform the following procedure:

  1. Download the following BIG-IP LTM 9.6.1 ISO image and its corresponding MD5 file:

    Note: The following files are also available on the F5 Downloads site.

    BIGIP-9.6.1.779.0.iso
    BIGIP-9.6.1.779.0.iso.md5
  2. Compare the checksum of the downloaded BIG-IP LTM 9.6.1 ISO image to the pre-computed MD5 checksum for the file.

    For example, on a Linux system:

    md5sum BIGIP-9.6.1.779.0.iso
    854a33eeb6415c396c02ed6b7c4fbdaa  BIGIP-9.6.1.779.0.iso

    cat BIGIP-9.6.1.779.0.iso.md5
    854a33eeb6415c396c02ed6b7c4fbdaa  BIGIP-9.6.1.779.0.iso

    If the two values do not match, then the ISO file was corrupted during transfer. Download the file again and repeat the process.

    Important: Do not skip this step. The steps that follow will not verify the validity of the file. Continuing with a corrupted ISO image may lead to unpredictable results.

    Note: The md5sum utility is a core component of any Linux operating system. On Microsoft Windows systems, you may use the File Checksum Integrity Verifier utility (http://support.microsoft.com/kb/841290).

    Note: The MD5 checksum hash reported by the md5sum command will differ from the hash reported for the ISO file by the Configuration utility under Software Management. This behavior occurs because the hash reported when you run the md5sum command is the checksum for the ISO file itself, and is used to verify the integrity of the ISO file after downloading it from the F5 Networks Downloads site. The hash reported by the Configuration utility under Software Management is the iframeded MD5 checksum contained in the ISO file.
  3. Burn the BIG-IP LTM 9.6.1 ISO image to a CD.
  4. Connect the USB CD ROM drive to the VIPRION blade that requires re-imaging. In addition, load the disc you burnt with the BIG-IP LTM 9.6.1 ISO image.
  5. Connect to the serial console of the VIPRION blade that requires re-imaging.

    Note: For more information, refer to K7683: Connecting a serial terminal to a BIG-IP system.
  6. Reboot the VIPRION blade that requires re-imaging.

    Note: If the blade cannot be rebooted, you can reset it from the Blade Command Menu. Access the Blade Command Menu from the serial console by pressing the ESC key once, then press and hold down the SHIFT key while pressing the 9 key. The following menu is displayed:

    Blade <blade number> Command Menu:

    B -- Set baud rate
    C -- Capture blade console
    I -- Display blade info
    P -- Control blade power
    Q -- Quit menu
    R -- Reset blade

    Enter command:

    Enter R to select the Reset blade menu item. The system displays Blade to reset (1-8)?. Confirm the reset of the blade by entering the blade number, for example 1. Enter Q to quit the Blade Command Menu.
  7. Once the VIPRION blade has completed loading its firmware, it displays the GRUB menu. The GRUB menu includes the following two entries:

    USB mass storage device - sda1
    USB mass storage device - sr0
  8. Using the UP and DOWN arrow keys, select USB mass storage device - sr0, and then press Enter.

    Note: Upon completion of this step, the BIG-IP system will begin booting from the USB CD-ROM drive.
  9. The system will ask you to specify the type of terminal you are using. If you do not know what to enter, press Enter. The default setting is acceptable in most cases.
  10. The system displays the following:

    info: Using repository; /cdserver
    info: manufacturing plan for A100:
    info:  --- boot volume set is HD1.1
    info:  --- HD1.3 => BIG-IP 9.6.1 LTM.ROS
    info:  --- HD1.1 => BIG-IP 9.6.1 LTM.ROS
    info:  --- HD1.4 => BIG-IP 9.6.1 LTM.ROS
    info:  --- HD1.2 => BIG-IP 9.6.1 LTM.ROS
    This is the manufacturing installation!
    If you want to retain ANY data present on this system, do not continue.
    Use <ctrl-c> to enter a bash shell.
    Press [Enter] to begin installation.

    To begin the installation press Enter. All mass-storage devices will be wiped and BIG-IP LTM 9.6.1 will be installed on four boot locations: HD1.1, HD1.2, HD1.3 and HD1.4.

    Important: Proceeding beyond this step will destroy all data on the system. Do not proceed with this step if you have data that needs to be recovered from the system, for example a configuration archive.
  11. Once the system has completed re-imaging all four boot locations, it displays the following message:

    info: Installation finished.
    info: Unmounting /cdserver from /cdserver
    Remove media, then press [Enter] to reboot.

    Disconnect the USB CD-ROM drive and then press Enter to reboot the VIPRION blade.

If necessary, repeat this procedure on additional VIPRION blades.
