Known Issue

The Configuration utility may fail to install a hotfix on platforms with a solid-state drive (SSD).

This issue occurs when all of the following conditions are met:

  • You are running one of the following platforms that has an SSD:
    • BIG-IP 5250 or 5050 (C109)
    • BIG-IP 7250, 7050 or 7055 (C113)
    • BIG-IP 12050 or 12250 (D111)
    • BIG-IP 10150N, 10350, 10350F, 10050 or 10055 (D113)
    • BIG-IP i5000 series (C119)
    • BIG-IP i7000 series (C118)
    • BIG-IP i10000 series (C116)
    • BIG-IP Herculon i5800 (C121)
    • BIG-IP Herculon i10800 (C122)
    • VIPRION B2150 blade (A113)
    • VIPRION B2250 blade (A112)
    • VIPRION B4450N blade (A114)
  • You have imported the required base software and hotfix image files (.iso) to the BIG-IP system.
  • You attempt to perform a hotfix installation by navigating to System > Software Management > Hotfix List in the Configuration utility. For more information, refer to K13123: Managing BIG-IP product hotfixes (11.x - 13.x).
  • You have not prepared an inactive boot location with the base software that is required for the hotfix installation. For example, if the BIG-IP system is running BIG-IP 11.6.0 on the active boot location (for example, HD1.1), and you install 12.0.0 HF1 on an inactive boot location (for example, HD1.2), when you install the hotfix, the system will act as though it has the base version 12.0.0 software already installed on HD1.2.

When you install a hotfix, the Configuration utility validates if the required base software has been installed on a suitable target boot location on the BIG-IP system. This validation will incorrectly fail on an SSD platform.

Impact

You cannot install a hotfix on an SSD platform using the Configuration utility.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you select the hotfix image file to install the hotfix and click Install in the Configuration utility, you receive an error message that appears similar to the following example:

    No base image installed or compatible volume to install the Hotfix.

    Thus, you cannot initiate the hotfix installation from the Configuration utility.

Workaround

To work around this issue, you can use the TMOS Shell (tmsh) to perform the hotfix installation. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the BIG-IP system.
  2. Log in to tmsh by typing the following command:

    tmsh

  3. To install the hotfix, use the following command syntax:

    install /sys software hotfix <Hotfix Image File> volume <Target Boot Location>

    For example, to install BIG-IP 12.0.0 HF1 to an inactive target boot location HD1.2, type the following command:

    install /sys software hotfix Hotfix-BIGIP-12.0.0.1.0.628-HF1.iso volume HD1.2

    Note: Both the software image BIGIP-12.0.0.0.0.606.iso and the hotfix image Hotfix-BIGIP-12.0.0.1.0.628-HF1.iso must be present on the BIG-IP system. For more information, refer to K13123: Managing BIG-IP product hotfixes (11.x - 13.x).
