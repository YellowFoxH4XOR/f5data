Description

In version 14 or later, after importing the SSL certificate and key using the following command:

tmsh install sys crypto key sample.key from-local-file <path-to-the-key>

You may notice that the file extension disappears from the file name in the /config/filestore/files_d/Common_d/certificate_key_d directory. For example, in version 14, the output may look like this:

-rw-r-----. 1 root webservices 1704 Jun 10 09:01 :Common:sample_2020-06-10_73643_1   ------------------->  (No extension)

In version 12, the output would include the file extension:

-rw-r-----. 1 root webservices 1704 Jun 10 09:01 :Common:sample_2020-06-10_73643_1.key_49147_1

This behavior also applies to certificates.


Environment

  • Version 14 or later

Cause

This behavior is by design
