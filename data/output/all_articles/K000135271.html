Description

Tenant name can not be edited after it was created. There is no option in GUI or CLI to edit or modify the tenant name.

Environment

  • F5OS-C
  • F5OS-A

Cause

The tentant name cannot be changed due to configuration object dependencies that are established once the tenant is created and deployed. This behavior is expected as per design.

 Recommended Actions

  • Use the desired name while creating the tenant.
    or 
  • Make a UCS backup from the tenant, remove the tenant, and re-create the tenant with the new name and restore the UCS.

Additional Information

None.
