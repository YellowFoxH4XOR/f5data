K000132922: Active device has gone out of sync and all VIPs turned offline suddenly

Type
Support Solution
Published
2023-03-09
Updated
2023-03-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 16.0.0, 16.0.X, 16.0.1, 17.X.X, 16.X.X, 17.0.X, 17.0.0, 16.1.X, 16.1.3, 16.1.2, 16.1.1, 16.1.0
Source
https://my.f5.com/manage/s/article/K000132922

Description

All network activity goes down all of a sudden

VIPs are offline suddenly

BIG-IP HA pair goes out of sync

Environment

  • iSeries (i5000, i7000, i10000, i11000)
  • BIG-IP version 16.1.x, 17.0.x
  • Interfaces go down

Cause

The problem is caused by an issue with interaction between the HSB and internal switchboard interfaces, which receive a large number of pause frames from the HSB.

Recommended Actions

See K20042122: iSeries: 16.1.x / 17.0.x, connectivity issues, interfaces or trunks down

Additional Information

None
