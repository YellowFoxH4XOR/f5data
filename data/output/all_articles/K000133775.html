K000133775: Detecting if nginx was installed from official NGINX package, custom package or self-compiled build

Type
Support Solution
Published
2023-05-02
Updated
2023-05-02
Source
https://my.f5.com/manage/s/article/K000133775

Description

NGINX can be installed from either the an official NGINX pre-built package, a custom built package or from a self-compiled build. See NGINX documentation for details - https://docs.nginx.com/nginx/admin-guide/installing-nginx/installing-nginx-open-source/

Environment

NGINX

Ubuntu/Debian OS

Cause

NGINX Installation

Recommended Actions

Run the `dpkg` command to list the nginx packages installed and to discover which entity was responsible for creating the package.

Note: if there is no output or nginx cannot be found when running the `dpkg` command then this indicates nginx was installed from a self-compiled build.

  • From NGINX Plus package installation

$ dpkg -l | grep nginx

ii nginx-plus 28-1~jammy amd64 NGINX Plus, provided by Nginx, Inc.

ii nginx-plus-module-modsecurity 28+1.0.3-1~jammy amd64 NGINX Plus 3rd-party ModSecurity dynamic module

$ dpkg -s nginx-plus

Package: nginx-plus

Status: install ok installed

Priority: optional

Section: httpd

Installed-Size: 6647

Maintainer: NGINX Packaging <nginx-packaging@f5.com>

Architecture: amd64

Version: 28-1~jammy

Replaces: nginx, nginx-core, nginx-plus-debug

Provides: httpd, nginx, nginx-plus-r28

...

  • From NGINX OSS installed from official nginx repository

$ dpkg -l | grep nginx

ii nginx-plus 28-1~jammy amd64 NGINX Plus, provided by Nginx, Inc.

ii nginx-plus-module-modsecurity 28+1.0.3-1~jammy amd64 NGINX Plus 3rd-party ModSecurity dynamic module

$ dpkg -s nginx

Package: nginx

Status: install ok installed

Priority: optional

Section: httpd

Installed-Size: 3076

Maintainer: NGINX Packaging <nginx-packaging@f5.com>

...

  • From NGINX OSS self-compiled installation

$ dpkg -l | grep nginx

$ dpkg -s nginx

dpkg-query: package 'nginx' is not installed and no information is available

Use dpkg --info (= dpkg-deb --info) to examine archive files.


Additional Information

For RHEL use the rpm command, e.g. rpm -qi nginx
