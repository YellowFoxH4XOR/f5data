Description

  • IP Subnet Match VPE agent doesn't work. User doesn't follow the needed branch.
  • One of the following error messages could be seen in browser:
    • "we can not access to this page"
    • "the connection to the web site has been reset"
    • "error code : INET_E_DOWNLOAD_FAILURE"
  • The log entry like below is seen in /var/log/apm for the affected session:
    err apmd[15583]: 01490086:3: /Common/<Access_Policy_name>:Common:<session-id>: Rule evaluation failed with error:
Environment
  • IP subnet match is configured in Advanced Resource Assign object in VPE
  • IP address in IP subnet match value has a leading or trailing space

Cause

  • IP Subnet Match value has a leading or trailing space
  • While applying access policy, there is no configuration error but evaluation results in failure with apmd error message "Rule evaluation failed with error:"
  • This is an instance of a known software defect ID858005. Once that software defect is fixed VPE will warn admins regarding leading or trailing spaces
     

Recommended Actions

Remove all leading or trailing spaces from IP Subnet Match VPE agent.
