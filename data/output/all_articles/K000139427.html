Description

When update the Groups from Activity Directory, get the error: Unable to import groups, the screenshot:

And in the log file /var/log/apm, will print the log:

notice adutil[4840]: 01490274:5: (null):Common:00000000: New master key received.

err adutil[4840]: 01490200:3: unable to get domain groups

Environment

  • BIG-IP APM
  • Activity Directory server

Cause

BIG-IP APM cannot reach the Activity server, TCP port 88 and UDP port 88.

Recommended Actions

Please check the network connectivity between BIG-IP APM and Activity Directory server, make sure BIG-IP APM was able to access the server TCP port 88 and UDP port 88, get the correct response.

The command to test it:

# adtest -t auth -h <IP address or FQDN of Activity Directory server> -r "<realm name>" -A <username> -W <password>

For example,the success command:

 # adtest -t auth -h 192.168.1.100 -r "example.com" -A Administrator -W password-administrator
Test done: total tests: 1, success=1, failure=0

The failed command which caused by invalid credential:

# adtest -t auth -h 192.168.1.100 -r "example.com" -u administrator -w incorrect-password-administrator
WARNING: authentication with 'administrator' failed: Preauthentication failed, principal name: administrator@EXAMPLE.COM. Invalid user credentials.  (-1765328360)
Test done: total tests: 1, success=0, failure=1

The failed command when BIG-IP cannot reach the Activity Directory server:

# adtest -t auth -h 192.168.1.101 -r "example.com" -u administrator -w password-administrator
ERROR: authentication with 'administrator' failed: Cannot contact any KDC for realm 'EXAMPLE.COM', principal name: administrator@EXAMPLE.COM  (-1765328228)
Test done: total tests: 1, success=0, failure=1

The failed command which caused by invalid realm:

# adtest -t auth -h 192.168.1.100 -r "incorrect.realm" -u administrator -w password-administrator
ERROR: authentication with 'administrator' failed: Realm not local to KDC, principal name: administrator@INCORRECT.REALM. Realm not found. Please verify Domain Name configured.  (-1765328316)
Test done: total tests: 1, success=0, failure=1
