Description

ASM is giving following error when URL parameter is added to the existing allowed URL : "such url doesn't exist in policy"

 

 

Environment

ASM

URL parameter

Cause

This is because URL (/abc) is created in the policy without specifying any HTTP method as seen in below picture . However, In this case POST method is specified while creating the URL parameter ( qq).

Recommended Actions

Do not specify the POST method when creating the URL parameter or When creating the URL also specify the POST method

None.
