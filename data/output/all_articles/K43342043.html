Topic

Use BIG-IQ Centralized Management 5.1.0 to discover and import information from BIG-IP devices so you can manage them.

Description

Device discovery on BIG-IQ Centralized Management 5.1.0

To manage BIG-IP devices, the BIG-IQ system must first gather information from them. This process is called device discovery.

Video: Device Discovery on BIG-IQ Centralized Management 5.1 (Part 1 of 2)

Device import on BIG-IQ Centralized Management 5.1.0

After discovering the BIG-IP devices, import the device service configurations to complete the process. This allows you to use the BIG-IQ system to manage the BIG-IP devices.

Video: Device Import on BIG-IQ Centralized Management 5.1 (Part 2 of 2)
