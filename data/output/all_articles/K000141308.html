K000141308: Configuring Elasticsearch snapshot schedule returns an error "futureSchedule 'timeToStartOn' property must be at least 5 seconds from now"

Description

When creating a snapshot schedule for Elasticsearch through the BIG-IQ GUI, an error similar to the following pops up:


Error on server request

Number of Errors: 2

1. The system returned an unexpected error (400 Bad Request).

futureSchedule 'timeToStartOn' property must be at least 5 seconds from now

2. Bad Request


The error means that the value of 'timeToStartOn' in the JSON payload of the request is at least 5 seconds behind from what the BIG-IQ CM expects it to be.


This occurs when the client workstation clock lags relative to the BIG-IQ CM's clock.


Environment

BIG-IQ

Cause


Unsynchronized workstation and BIG-IQ CM clocks.

Recommended Actions


Ensure that the BIG-IQ CM and the client workstation clocks are synchronized to NTP servers.

None.
