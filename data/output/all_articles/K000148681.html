K000148681: NGINX Upgrade Problem with error message -- "NGINX Plus was NOT Upgraded

Type
Support Solution
Published
2024-11-22
Updated
2024-11-22
Applies to
  • NGINX Products
  • NGINX Plus: R28, R30, R29, R33, R31, R32
Source
https://my.f5.com/manage/s/article/K000148681

Description

  • You have been using NGINX for a while and want to upgrade it to version R33 (nginx/1.27.2)
  • You have a valid license and followed the usual upgrade process but the installation to R33 failed with the below error
                              ----------------------------------------------------------------------

                              !!! NGINX Plus was not upgraded !!!

                              NGINX Plus R33 introduces a breaking change.
                              Please read about new licensing scheme and required actions here:

                              https://docs.nginx.com/solutions/about-subscription-licenses

                              ----------------------------------------------------------------------
  • You want to know why the upgrade did not complete successfully 

Environment

  • NGINX Plus (version R33 / 1.27.2)
  • Upgrade

Cause

  • Starting from NGINX Plus Release 33, a JWT file is required for each NGINX Plus instance.

Recommended Actions

  • To complete planned upgrade, please follow the instruction provided here

Additional Information

  • The issue encountered neither relates to Operating System nor any additional modules installed with NGINX, but rather by recently communicated and introduced change with NGINX version R33, which is a breaking change.
  • Please make sure you copy a valid JSON Web Token from the subscription page
