Description

You are facing an issue related to the behavior of the "?" character in tmsh commands. By default, the "?" character functions as a command help menu in the tmsh command-line environment. However, when you include the "?" character within a string and send it as part of a tmsh command, it does not behave as expected.

 

Environment

  • BIG-IP tmsh command line

Cause

The issue is related to how the tmsh command-line environment handles the "?" character and certain escape sequences.

Recommended Actions

To address this issue and handle the input of the "?" character correctly, please follow these steps:

  1. Enter the tmsh command.
  2. Before typing the "?" character in the command, include a backslash "" (without pressing Enter). From ?  =>  \?
  3. Example: 
    1. create ltm monitor http a_test-pool-monitor_http1 { send "GET /uri/testpage\
  4. Continue entering the rest of the string that includes the "?" character. 
    1. ?status=up HTTP/1.1\r\nHost: test.domain.com\r\nConnection: Close\r\n\r\n" }
  5. After entering the string (without pressing Enter), remove the backslash "" that was entered in step 2.
  6. Press Enter to execute the command.

By following these steps, you should be able to send the "?" character correctly within the tmsh command and resolve the issue.

Alternatively, you can also type the entire command before entering the tmsh environment.

Example

tmsh create ltm monitor http a_test-pool-monitor_http1 { send "GET /uri/testpage?status=up HTTP/1.1\r\nHost: test.domain.com\r\nConnec^Con: Close\r\n\r\n" }
