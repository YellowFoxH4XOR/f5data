Topic

You should consider using these procedures under the following condition:

  • You want to configure the security policy to deny requests for certain file types.

Description

In some cases, you may want to configure the BIG-IP ASM security policy to deny requests for certain file types. For example, attackers may use techniques such as forceful browsing to gain access to restricted files or areas in the web server directory. In some cases, an attacker may be able to search for unlinked content in the web server directory and retrieve files, such as backup and configuration files. By configuring the security policy to deny requests for certain file types (disallowed file types), you can create a set of files on your site that you don't want users to access, such as BAK files. 

Prerequisites

You must meet the following prerequisites to use these procedures:

  • You have access to the Configuration utility.
  • You have identified a list of file types, such as BAK or EXE that should be disallowed by the security policy.

Procedures

  • Configure disallowed file types (16.1.0 and later)
  • Configure disallowed file types (12.x - 16.0.1)
  • Configure learning and blocking settings for disallowed file types

Configure disallowed file types (BIG-IP 16.1.0 and later)

To configure the security policy to deny requests for certain file types, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Security Policies > Policies List.
  3. Select the name of the security policy.
  4. Select HTTP Message Protection.
  5. Select File Types.
  6. Select Create.
  7. Select Disallowed File Types.
  8. For File Type, enter the name of the file type that the security policy does not allow (for example, bak or exe).
    Note: By default, the specified file types are case-sensitive.
  9. Select Add.
  10. Select Create.
  11. To apply the changes to the policy, select Apply Policy.

Configure disallowed file types (BIG-IP 12.x through 16.0.1)

To configure the security policy to deny requests for certain file types, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > File Types > Disallowed File Types.
  3. In the Current edited policy list near the top of the page, verify that the edited security policy is the one you want to work on.
  4. Select Create.
  5. In the File Type (Explicit only) box, enter the name of the file type that the security policy does not allow (for example, bak or exe).

    Note: By default, the specified file types are case-sensitive.

  6. Select Create.
  7. To apply the changes to the policy, select Apply Policy.

Configure learning and blocking settings for disallowed file types

The BIG-IP ASM system responds to requests for disallowed file types, depending on the settings you configure for the Illegal File Type violation on the Learning and Blocking Settings page. To configure learning and blocking settings for disallowed file types, perform the following steps:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Learning and Blocking Settings.
  3. Select the arrow next to File Types.
  4. For the Illegal File Type violation, select the Learn, Alarm, and Block check boxes, as required.
  5. Select Save.
  6. To apply the changes to the policy, select Apply Policy.
