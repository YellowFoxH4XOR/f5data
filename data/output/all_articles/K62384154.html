Description

The drop-down list in Security ›› Reporting : Application : Charts are empty.
It does not show any option to select in the dashboard.

Environment

  • ASM reporting
  • AVR reporting
  • Stats

Cause

External add-ons installed on the browser could block some parts of the configuration utility or GUI

Recommended Actions

  1. Test in different browsers without having external add-ons.
  2. Uninstall external add-ons on the browser.
  3. If you uninstall the add-ons ( "ublock origin" being a known cause for this issue) and the issue persists, please follow the instructions to generate HTTP Archive file (HAR) and contact F5 Support for further investigation.

Additional Information

K10370211: Generate an HTTP Archive using a browser
