Description

In BIG-IP ASM security policy, the "Server Technologies Detection" is enabled by default, this article aims to change it to disabled via REST API.

Environment

  • BIG-IP ASM
  • ASM policy
  • REST API

Cause

None

Recommended Actions

  1. First you need to find the "REST name" for your security policy so you can reference it in the POST to the IP address exception list. To find these names, run the following restcurl command on your BIG-IP:

restcurl -X GET tm/asm/policies'?$select=versionPolicyName'
You should receive an output similar to the following:
restcurl -X GET tm/asm/policies'?$select=versionPolicyName'
{
  "kind": "tm:asm:policies:policycollectionstate",
  "selfLink": "https://localhost/mgmt/tm/asm/policies?$select\u003dversionPolicyName\u0026ver\u003d15.1.2",
  "totalItems": 1,
  "items": [
    {
      "kind": "tm:asm:policies:policystate",
      "selfLink": "https://localhost/mgmt/tm/asm/policies/Y8vIJ_7TPlr2d_owBaGtsA?ver\u003d15.1.2",
      "versionPolicyName": "/Common/asm_test"
    }
  ]
}
The "selfLink" line above will contain the "REST name" for the policy. It will be the alpha-numeric value between "/policies/" and the "?"(start of parameters)
In my example above, the "REST name" for policy "asm_test" is "Y8vIJ_7TPlr2d_owBaGtsA"

  1. After you have the name of the policy, you will need to send a PATH request to "/mgmt/tm/asm/policies/<"REST name">/policy-builder-server-technologies" as example below:

curl -u admin: <password> -ks -X PATH -H "content-type:application/json" https://localhost/mgmt/tm/asm/policies/Y8vIJ_7TPlr2d_owBaGtsA/policy-builder -d '{"enableServerTechnologiesDetection": "false"}'
