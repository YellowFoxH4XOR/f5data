Known Issue

This is the result of a known issue. Staging attack signatures helps reduce the number of violations triggered by false positive matches. Requests that trigger an attack signature in staging are marked red in the Reporting log, and are not sent to the /var/log/asm file. This behavior may cause confusion because the BIG-IP ASM system allows the request even when the security policy is in blocking mode.

The expected behavior is that the BIG-IP ASM system allows the request, generates a learning suggestion, and does not display the request on the Reporting screen or log the request to the /var/log/asm file.

F5 Product Development tracked this issue as ID 209434 (formerly CR124259) and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP ASM release notes.
