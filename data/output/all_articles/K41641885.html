Description
Exposure of the URI "/pre/config.php?version=2.0" on F5 APM with Edge Client.

Environment

  • BIG-IP APM
  • BIG-IP Edge Client

Cause
The URI "/pre/config.php?version=2.0" is available on any BIG-IP virtual server that has an F5 APM access policy and a connectivity profile associated with it.  

The exposure of URI pre/config.php seems a security exposure, but it's not as it only reports the version of client components that are available to be downloaded.
 

Recommended Actions

When connection initiates using BIG-IP Edge Client, The "pre/config.php" URI is used in initial connection negotiation, F5 recommends not to block this URI as it could cause problems.
