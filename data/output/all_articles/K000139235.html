Description

The following error is logged after running clear-rest-storage on BIG-IQ:

/bin/clear-rest-storage: line 25: /bin/rm: Argument list too long 

Environment

  • BIG-IQ
  • clear-rest-storage

Cause

Too many files in folder to remove

Recommended Actions

Line 25 in the /bin/clear-rest-storage script is attempting to delete all files in /var/config/rest/fileobject/

25 rm -rf /var/config/rest/fileobject/*

 

Follow the steps below to remove these files manually:

  1. Change to the desired directory
    /var/config/rest/fileobject/
  2. Count number of objects:
    s -l /var/config/rest/fileobject/ | wc -l
  3. Delete all objects:
    ls /var/config/rest/fileobject/ | xargs rm -rf
  4. Verify objects have been deleted:
    ls -l /var/config/rest/fileobject/ | wc -l

Proceed to re-run the clear-rest-storage command again to complete the process.
