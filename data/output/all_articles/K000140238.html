K000140238: Reactivating CAT license on the BIG-IP devices from BIG-IQ License Manager - License INOPERATIONAL

Type
Support Solution
Published
2024-07-03
Updated
2025-02-27
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X, 8.0.0
Source
https://my.f5.com/manage/s/article/K000140238

Description

Pushing reactivated/activated CAT license from BIG-IQ to to BIG-IP VE causes license INOPERATIONAL. BIG-IP VE stops processing traffic.

Environment

  • BIG-IQ Centralized Manager or License Manager
  • CAT License key
  • License offering with manual activation
  • BIG-IP Virtual Edition (VE)

Cause

License Validator in BIG-IQ accepts pasting main (CAT) license for individual license offering activations. Therefore, when refreshing the license on the BIG-IP VE, the BIG-IQ pushes the main (CAT) license instead of the actual license offering which causes license invalid, license INOPERATIONAL issues on the BIG-IP.

Recommended Actions

Avoid copying dossier from the CAT key to its license offerings. During manual activation of the CAT key, each of its individual license offerings has its own dossier that needs to be activated for each offering.
