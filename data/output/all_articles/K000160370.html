Description

This document provides access to questionnaire templates used to collect the required deployment and configuration information for F5 Distributed Cloud services.

The templates are designed to streamline the information-gathering process for onboarding, configuration updates, security policy implementation, and operational requests. Providing the requested details through these standardized forms enables the F5 Security Operations Center team to review the requirements efficiently and proceed with the requested configuration or service implementation. 

Environment

  • Web Application Firewall
  • F5®Distributed Cloud (XC)
  • F5® Distributed Cloud HTTP Load Balancer
  • F5® Distributed Cloud TCP Load Balancer

Cause

To perform configuration tasks, security policy implementation, or operational changes, the F5 Security Operations Center requires specific information about the application environment, infrastructure, and security requirements.

Providing these details in a structured format helps ensure that requests are reviewed accurately and processed efficiently.

 

Answer/Recommended Actions

Download the appropriate questionnaire template from the list below and complete the required sections with the relevant deployment and configuration information.

Once completed, share the document with the F5 Security Operations Center team or attach it to the associated service request. The information provided will be reviewed to proceed with the requested configuration or operational activity.

Available Questionnaires

  1. F5 Distributed Cloud- Origin Pool Configuration Questionnaire
    Download: F5 Origin Pool Questionnaire

  2. F5 Distributed Cloud- HTTP Load Balancer Configuration Questionnaire
    Download: F5 HTTP Load Balancer Questionnaire

  3. F5 Distributed Cloud- TCP Load Balancer Configuration Questionnaire
    Download: F5 TCP Load Balancer Questionnaire

  4. F5 Distributed Cloud- WAF Configuration Questionnaire
    Download: F5 Distributed Cloud WAF Policy Questionnaire

Please ensure that all applicable fields are completed before submitting the document to facilitate timely review and implementation.

 

Additional Information

These templates are provided by F5 to standardize the collection of deployment and configuration details for F5 Distributed Cloud services.

Providing complete and accurate information helps the F5 Security Operations Center team validate requirements and proceed with configuration activities without unnecessary delays.

For further guidance on F5 Distributed Cloud services, refer to the official F5 Distributed Cloud Documentation.
