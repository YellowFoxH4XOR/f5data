Description

Guide to setting up NGINX Private offer in Azure (Pay as You Go) PAYG.

Environment

  • Azure (Pay as you Go) PAYG
  • NGINX

Cause

 

 Recommended Actions

  1. Log in to your Azure Portal  and navigate to Marketplace  
  2. In the Marketplace page, enter “nginx” in the search bar, and Private plan results should appear.  Select “View private plans” 

  3. In the Private plans page, select the NGINX listing associated with the purchased Private Offer 

  4. On the listing page, go to the Plan field and select the NGINX product from the dropdown.  Click “Create” or “Get it Now” to create a VM instance
  5. Follow these instructions to install NGINX Plus on Azure
