Description

After re-enabling statistics collection, the following error message is shown:

Statistics collection error: agentInstaller failed: java.lang.IllegalStateException: installIapp on device 10.0.0.1 failed: java.lang.IllegalStateException: file /var/config/rest/iapps/staging/f5.bigiq-analytics.tmpl from install of analytics-iapp2-8.1.0.1-0.0.36.noarch conflicts with file from package analytics-iapp-8.1.0-0.0.36.noarch. Please try again by clicking "Save and Close," below.

 

Environment

  • BIG-IQ
  • Stats collection

Cause

Unable to install analytics-iapp on BIG-IP

Recommended Actions

Run the following command in CLI on BIG-IP to remove the conflicting iapp package:

Command to verify currently installed iapp package:
rpm -qa | grep analytics

Command to remove iapp package:
rpm -e analytics-iapp

Re-enable stats collection from BIG-IQ. The rpm file will be pushed from BIG-IQ to the BIG-IP devices and the rpm file will be re-installed with the correct iapp package.
