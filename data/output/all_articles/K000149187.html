Description

You are getting the below error when 'tmsh load sys config verify'.

01070287:3: Static route destination xxxx:xxxx:xxxx:xxxx::xxxx and netmask ffff:ffff:: are invalid.
destination & netmask != destination.
Unexpected Error: Validating configuration process failed.

Environment

LTM

IPv6 static route

Cause

Subnet mask for IPv6 static route is wrong.

For example

  • Invalid configuration
net route /Common/route_IPv6 {
    gw xxxx:xxxx:xxxx:xxxx::xxxx
    network yyyy:yyyy:yyyy:yyyy::yyyy/32
}
  • The correct subnet mask for IPv6 is /128
net route /Common/route_IPv6 {
    gw xxxx:xxxx:xxxx:xxxx::xxxx
    network yyyy:yyyy:yyyy:yyyy::yyyy/128
}

Recommended Actions

Manually edit the static route in the big-ip.conf to replace /32 with /128
