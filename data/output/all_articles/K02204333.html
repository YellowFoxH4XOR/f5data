Description

After a reboot, the BIG-IP fails to load the configuration with an error similar to the following:

01020036:3: The requested device group (/Common/datasync-device-LTM1.example.com-dg) was not found. Unexpected Error: Validating configuration process failed.

Environment

  • Configuration load
  • Device-Group

Cause

The device-group does not exist on the configuration files of the BIG-IP, however the sys folder configuration related, remains in the system.

Recommended Actions

  1. Remove the sys folder configuration block related to the conflicting device-group from bigip_base.conf, for example: 
    sys folder /Common/datasync-device-LTM1.example.com {
    device-group /Common/datasync-device-LTM1.example.com-dg
    hidden true
    inherited-devicegroup false
    inherited-traffic-group false
    traffic-group /Common/traffic-group-local-only
}
  2. Reload the configuration again with: tmsh load sys config

Additional Information

None
