Known Issue

This is the result of a known issue. If multiple software version images are installed and multiple configuration archives exist on the system, the BIG-IP system may display the following warning during installation:

WARNING!
The saved configuration UCS found on the system is not compatible with
the version of software you are trying to install. This configuration UCS
cannot be rolled forward. Continue this installation if you want to
create a clean install without moving the configuration to the new
version.

This error message is displayed if any UCS configuration archive exists on the system that is incompatible with the version you are installing.

F5 Product Development tracked this issue as CR55562 and CR55911, and it was fixed in BIG-IP LTM 9.1.2. For information about upgrading, refer to the BIG-IP LTM Release Notes.
