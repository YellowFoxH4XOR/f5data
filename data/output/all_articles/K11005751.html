Description

  • You get NXDOMAIN or REFUSED response for querying a domain name that is not authoritative on your BIG-IP DNS.
  • You do not want BIG-IP DNS to reply with any information.

Environment

  • BIG-IP DNS
  • DNS Listener
  • iRule

Cause

By default, the response includes NXDOMAIN or REFUSED for querying a domain name that is not owned by BIG-IP DNS.

Recommended Actions

You can attach the following irule to all listeners to meet your requirement.

when DNS_REQUEST {
  if { ![class match [DNS::question name] equals datagroup_example] } {
    DNS::drop
    #log local0.notice "Query domain name is [DNS::question name], not in datagroup_example, drop the query."
  } else {
    return
  }
}

Note: You should first create the datagroup datagroup_example and add a string for all the domain names that your BIG-IP DNS owns.

    Additional Information

    The iRule applies to both wideip and zonerunner.
