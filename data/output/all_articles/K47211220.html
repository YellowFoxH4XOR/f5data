Description

RDP connections cannot be established.

/var/log/apm file contains:

Jan 01 00:00:00 device1 notice vdi[4973]: 019cffff:5: (null)::aaaaaa00: {2aa0.S} Operation '' failed, error: 'unspecified'
Jan 01 00:00:00 device1 notice vdi[4973]: 019cffff:5: (null)::aaaaaa00: {2aa0.S} Error reported for an outgoing connection
Jan 01 00:00:00 device1 info vdi[4973]: 019cffff:6: (null)::aaaaaa00: {2aa0.S} Error reported on initiated outgoing connection.
Jan 01 00:00:00 device1 notice vdi[4973]: 019cffff:5: (null)::aaaaaa00: {2aa0.S} Failed to connect to RDG target 10.10.10.10:3389: system:111: Connection refused

Environment

  • BIG-IP APM
  • RDP resources

Cause

This can be caused by a variety of reasons such as network issues that prevents the BIG-IP system from communicating with the RDG target.

Recommended Actions

Take a TCP packet capture either on the BIG-IP system or the RDG target to ensure there are no network issues between the BIG-IP system and the RDG target. For more information, refer to K411: Overview of packet tracing with the tcpdump utility.
