K000141156: Brute force login page with URL longer than 128 bytes causes ASM to go offline

Type
Support Solution
Published
2024-09-25
Updated
2024-09-25
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.X.X, 17.1.X, 17.1.1, 17.1.0, 17.0.X, 17.0.0
Source
https://my.f5.com/manage/s/article/K000141156

Description

  • A login page that is configured with a URL longer than 128 bytes while being assigned to a brute force profile, might cause ASM to be stuck in a restart loop.

Environment

  • BIG-IP ASM
  • Login page with URL exceeding 128 bytes

Cause

  • Restart loop is due to 128 byte limitation set in the brute_force.yaml file

Recommended Actions

  • The following work around maybe applied to remove the affected login URL:

# mysql -p$(perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw) -e 'delete FROM DCC.ACCOUNT_LOGIN_BRUTE_FORCE_OBJECT_ATTRIBUTES where length(obj) > 128;'
