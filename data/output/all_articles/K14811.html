Known Issue

High-speed logging (HSL) may cause TMM to produce a core file during initialization.

This issue occurs when the following condition is met:

  • The BIG-IP system is configured for HSL to use a pool of logging servers.

When the BIG-IP system starts, a rare race condition may cause HSL to attempt to use a pool of logging servers before all Traffic Management Microkernels (TMMs) have finished initializing. If HSL attempts to establish a connection through a TMM that has not finished initializing, TMM produces a core file and restarts.

Impact

TMM may produce a core file and temporarily fail to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • TMM may produce a core file and temporarily fail to process traffic.
  • The BIG-IP system generates a stack trace and panic string that contains messages similar to the following example:
