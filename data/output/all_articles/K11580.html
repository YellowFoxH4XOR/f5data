Topic

When using a bookmark to access FirePass using a URI-based customization, you are presented with the default global logon screen. This behavior occurs when you have bookmarked the logon page and you later attempt to access the page with the bookmark from a new browser session.

Examining the bookmark will show the URL ending with /my.logon.php3 instead of the landing URI:

example: https://firepass.siterequest.com/my.logon.php3

Workaround

You can work around this issue by editing the bookmark URL to replace /my.logon.php3 with the name of the landing URI.

For example:

example: https://firepass.siterequest.com/mycustomlogon/

Note: For more information about FirePass customization, refer to the FirePass Controller Administrator Guide.
