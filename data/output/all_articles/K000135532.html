K000135532: BIG-IP Next instance is unhealthy after creating it

Source

Description
  • After creating a new BIG-IP Next instance from Central Manager, Central Manager reports that the instance is unhealthy. 
 
Environment:
  • BIG-IP Central Manager using the vSphere provider
  • You provision a new BIG-IP Next instance
 
Possible causes:
  • Management IP address conflict
  • Duplicate IP address of the BIG-IP Next instance
 
Recommended Actions:
Check all of these recommended actions.
  • From the VMware vSphere environment:
    • Check the management IP address of the BIG-IP Next instance.  This is visible in the instance properties page of vSphere.
    • Check the interface assignment and ensure it is what you expect it to be.
  • From Central Manager, try pinging the management IP address of the BIG-IP Next instance by logging in to the command line and pinging the address
