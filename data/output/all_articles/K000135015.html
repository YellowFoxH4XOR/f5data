Description

The Azure AD Integration in APM AGC fails with the following errors seen in the GUI:

The query specified in the URI is not valid. The node count limit of '100' has been exceeded.

 

Additionally, this shows up in /var/log/restnoded/restnoded.log (you will only see these logs if you have restnoded logging set to FINE or FINEST):

 

Fri, 26 May 2023 16:29:41 GMT - fine: [[azureUtils] ] Received response: status=200, statusText=OK

Fri, 26 May 2023 16:29:41 GMT - fine: [[azureUtils] ] Perform GET on url=https://graph.microsoft.com/v1.0/identity/conditionalAccess/policies?$filter=id eq ...( All CA policies are listed here)... body={}

Fri, 26 May 2023 16:29:42 GMT - severe: [[azureUtils] ] doAzureADOperationWithRetry failed, error : The query specified in the URI is not valid. The node count limit of '100' has been exceeded. To increase the limit, set the 'MaxNodeCount' property on EnableQueryAttribute or ODataValidationSettings.

Fri, 26 May 2023 16:29:42 GMT - severe: Failed to GET CA Policies

 

Environment

BigIP APM

Azure AD Integration with Access Guided Configuration

More than 15 Conditional Access policies (CAs) added

Cause

This is due to a Microsoft Graph API limit that allows at most 15 CAs to be queried in one request.

Recommended Actions

This is limited by Microsoft Graph API and we cannot modify its behavior from the F5 side. The error can be limited by decreasing the number of CAs attached to the service - it cannot exceed 15 CAs.

Please note: If you are unable to detach a CA, it means that it is likely of type "ALL" - these policies cannot be detached. You will need to change the type before attempting it again.
