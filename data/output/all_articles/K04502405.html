K04502405: Unable to Push Policies from BIG-IQ

Applies to

Source

Description
Deployment push from BIG-IQ fails due to a network communication error with the BIG-IP.  Re-discovery of the BIG-IP device in the BIG-IQ will fail with errors similar to the following following on the BIG-IQ:

Error querying 'DNS Resolver' from path 'mgmt/tm/net/dns-resolver' on device example.f5.com (10.10.10.10), network communication failed due to protocol error. 
Error querying 'Route' from path 'mgmt/tm/net/route' on device example.f5.com (10.10.10.10), network communication failed due to protocol error.

Environment

  • BIG-IQ 
  • BIG-IP AFM
  • DNS Resolver (f5-aws-dns -- created by default when provisioning BIG-IP AFM with route domain 0)
  • Very large ruleset (10k+ objects)

Cause
The DNS Resolver could become a bottleneck or even system resource exhaustion due to its recursive nature, especially with a tons of related objects configured in the system.

Recommended Actions
As the DNS Resolver cannot be deleted, it can be moved to a new, isolated route domain, so as not to impact the configuration re-discovery/push process.

From the BIG-IP CLI, run the following commands:

tmsh modify security firewall global-fqdn-policy dns-resolver none
tmsh create net route-domain 1
tmsh modify net dns-resolver <problematic dns resolver> route-domain 1
tmsh modify net dns-resolver f5-aws-dns route-domain 1
tmsh save /sys config
Note: Replace <problematic dns resolver> with the FQDN of the problematic dns resolver.

Alternatively, from the BIG-IP AFM Configuration utility:
  1. Remove the default Resolver from the BIG-IP AFM
    1. Click Security -> Options -> Network Firewall -> Firewall Options
    2. Under FQDN Resolver -> Global Context select None
    3. Click Update
  2. Create a new Route Domain
    1. Click Network -> Route Domains -> Create
    2. Enter a name for the new Route Domain in the Name field
    3. Set ID to a value other than zero
    4. Click Finish
  3. Move the f5-aws-dns resolver to the new Route Domain
    1. Click Network -> DNS Resolvers -> f5-aws-dns
    2. Drop down the Route Domain selection and select the previously created Route Domain
    3. Click Update
