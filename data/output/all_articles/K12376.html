Topic

When you configure a receive string in an HTTP health monitor, the BIG-IP system looks for that string in the resource returned by the web server. If a match is found, the pool member is marked as up. While the BIG-IP system allows you to configure a receive string that includes both uppercase and lowercase letters, the case is ignored when the receive string is matched against the data returned by the web server.

This behavior usually does not represent an issue. If the receive string is set to a certain word, the BIG-IP system will return a positive match if the server response contains any of all possible case permutations for that word. For example, for the word hi, all possible case permutations are hi, Hi, hI, and HI.

However, you should take into consideration the behavior described in this article when configuring a receive string. In addition, you should choose a receive string that is unique enough to match only the expected response from a healthy web server.
