Known Issue

Licensing or license revocation fails when you configure BIG-IP virtual edition (VE) systems to use a proxy.

This issue occurs when all of the following conditions are met:

  • You configure the BIG-IP VE system to use a proxy server to access the internet.
  • You attempt to license or revoke the license of the BIG-IP VE system.
When your BIG-IP system is behind a proxy server, you can use the following database variables to configure the BIG-IP system proxy settings: proxy.host, proxy.port, or proxy.protocol. As a result of this known issue, the BIG-IP system does not use the values in these database variables to reach the internet when you license or revoke the license of the system using the Configuration utility or the TMOS shell (tmsh).

Impact

The licensing or license revocation process fails when you use the Configuration utility or tmsh.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • You are unable to license BIG-IP VE systems that use a proxy to reach the internet.
  • You are unable to revoke the license of BIG-IP VE systems that use a proxy to reach the internet.

Workaround

To work around this issue, you can license or revoke the BIG-IP VE system from the Advanced Shell (bash). To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP VE system bash.
  2. Use the following command syntax to license or revoke the license of the system:

    To license:

    /usr/local/bin/SOAPLicenseClient --proxy <proxy_IP_addr> --basekey <base-reg-key> --certupdatecheck

    For example:

    /usr/local/bin/SOAPLicenseClient --proxy 192.168.10.100 --basekey ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG --certupdatecheck

    To revoke:

    /usr/local/bin/SOAPLicenseClient --proxy <proxy_IP_addr> --basekey <base-reg-key> --revoke

    For example:

    /usr/local/bin/SOAPLicenseClient --proxy 192.168.10.100 --basekey ABCDE-ABCDE-ABCDE-ABCDE-ABCDEFG --revoke
