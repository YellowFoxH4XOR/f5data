Known Issue

F5 SSL Orchestrator may fail to install an RPM software package on BIG-IP systems running point release versions.

This issue occurs when all of the following conditions are met:

  • You have installed a BIG-IP 14.1.0.x point release.
  • From the Configuration page in the Configuration utility, you click the Upgrade SSL Orchestrator link to install an F5 SSL Orchestrator RPM software package.
  • You attempt to install one of the following software packages:
    • f5-iappslx-ssl-orchestrator-14.1.0-5.0.307.noarch.rpm
    • f5-iappslx-ssl-orchestrator-14.1.0-5.1.254.noarch.rpm
    • f5-iappslx-ssl-orchestrator-14.1.0-5.2.261.noarch.rpm

For example, this issue occurs when you attempt to install the f5-iappslx-ssl-orchestrator-14.1.0-5.0.307.noarch.rpm package on a system running BIG-IP 14.1.0.2.

When you attempt to install an RPM software package, the system checks the BIG-IP version as part of the RPM version compatibility test. This is to prevent installing the RPM software package on unsupported BIG-IP versions. This issue occurs because the system compares the BIG-IP version in the name of the RPM software package with the BIG-IP version running on the targeted system.

Impact

You cannot install F5 SSL Orchestrator RPM software packages on systems running BIG-IP point release versions.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to install an RPM software package, the installation fails and the Configuration utility displays an error message similar to the following example:

    Invalid File.
    Cannot install f5-iappslx-ssl-orchestrator-14.1.0-5.2.261.noarch.rpm, package version should be 14.1.0.2-x.x.x and higher than 14.1.0-5.1.254

Workaround

To work around this issue, you can import the affected RPM software package using the Package Management LX page. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to iApps > Package Management LX.
  3. Click Import.
  4. Click Choose File and select the RPM software package
  5. Click Upload.
