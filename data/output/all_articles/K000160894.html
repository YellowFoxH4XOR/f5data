K000160894: iOS 26 and later Version Devices Failing TLS Handshake When TLS 1.3 Is Disabled

Description

iOS 26 and later version devices receive timeout errors (-1001) when connecting over Wi-Fi to applications behind a BIG-IP LTM virtual server. The issue does not occur over mobile data. The connections fail silently without explicit TLS handshake errors due to TLS 1.3 being disabled on the BIG-IP Client SSL profile, which prevents iOS 26+ devices from negotiating a compatible handshake.

Environment

  • Virtual server with Client SSL profile configured with "no-tlsv1.3" enabled
  • iOS client devices version 26 or later
  • Custom cipher group with ECDHE and TLS 1.3 cipher suites
  • TLS 1.3 disabled on the Client SSL profile

Cause

TLS 1.3 is explicitly disabled on the BIG-IP Client SSL profile. iOS 26+ and later version devices require TLS 1.3 and specific key exchange groups (X25519, secp256r1). When TLS 1.3 is unavailable, iOS devices cannot complete the handshake and drop the connection, resulting in a timeout.

Answer/Recommended Actions

  • Enable TLS 1.3 via GUI on the Client SSL profile by removing the "No TLSv1.3" option:
    • Go to Local Traffic >> Profiles: SSL: Client >> [Profile Name]
    • Switch to Advanced view
    • Remove "No TLSv1.3" from the Enabled Options list
    • Save changes
  • Or via TMSH:
    • tmsh modify ltm profile client-ssl <profile_name> options replace-all-with { <existing_options_without_no-tlsv1.3> }
  • Ensure the cipher group includes the key exchange groups X25519 and secp256r1.
  • Test connectivity from iOS 26+ devices over Wi-Fi.
  • If issues persist, collect packet captures of the handshake and contact F5 Support.

Additional Information

  • Both the presence of TLS 1.3 cipher suites and enabling TLS 1.3 in the profile are required for compatibility.
  • Refer to K86554600: SSL ciphers supported on BIG-IP platforms (15.x) for more information on BIG-IP SSL ciphers and profile defaults.
  • Refer to Configure the SSL profile to allow TLS 1.2 and 1.3 only  for more information to enable TLS 1.2 and TLS 1.3.
