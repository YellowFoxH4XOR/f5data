Description

The IP Intelligence update fails with the error message, “Query(getipfile): Receive: Failed to parse incoming JSON.” This error is recorded in the file /var/log/iprepd/iprepd.log. 

 

Environment

BIG-IP AWAF

 

Cause

Beginning in BIG-IP version 15.1.4, the iprep server has been modified from vector2.brightcloud.com to api.bcti.brightcloud.com. To verify the server used, please review the iprep log file /var/log/iprepd/iprepd.log. 

The below log indicates the usage of the old configuration. 

iprepd|INFO|<Month> <Day> <time> |<id>|iprep.server=vector2.brightcloud.com

 

Recommended Actions

Reset the iprep server config to default

tmsh
modify sys db iprep.server reset-to-default
save sys config

 

Additional Information

K79990078: IP Intelligence does not work after upgrade to version 15.1.4 or later
