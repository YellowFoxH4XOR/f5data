Description

  • Setup mTLS authentication on Nginx Plus

Environment

  • Nginx Plus

Cause

None

 Recommended Actions

  1. Set the ssl_client_certificate and turn on ssl_verify_client, under the Nginx target server configuration.
  2. Example
http {
  server {
    listen 443 ssl;
    server_name your_server_name;

    ssl_certificate /path/to/server.crt;
    ssl_certificate_key /path/to/server.key;
    ssl_client_certificate /path/to/client-ca.crt;
    ssl_verify_client on;

    location / {
      # Your regular Nginx configuration
    }
  }
}
