K000160644: BIG-IQ is not sending logs to remote syslog server when syslog configuration is configured via GUI

Type
Support Solution
Published
2026-04-08
Updated
2026-04-30
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.0
Source
https://my.f5.com/manage/s/article/K000160644

Description

You have configured BIG-IQ CM or DCD to send logs to remote syslog server via GUI but you do not see BIG-IQ is not sending logs.

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • syslog configuration

Cause

None

Answer/Recommended Actions

  • You need create syslog configuration via CLI. You can follow this K13080: Configuring the BIG-IP system to log to a remote syslog server article on the BIG-IQ.
  • BIG-IQ will send its own device logs like /var/log/messages, daemon, ltm, etc.
  • Audit logs will not be sent. Restjavad logs can be sent by explicitly configuring them. For reference refer Related Content.
  • BIG-IP event logs stored in DCD will not be sent to remote syslog server.

Additional Information

None
