K83219433: Virtual Server not showing Statistics when application is deployed to a Standby Device

Type
Support Solution
Published
2020-04-02
Updated
2025-02-07
Applies to
  • Virtual Editions
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K83219433

Description
Unable to see HTTP statistics when application is deployed to a Standby Device

Environment

  • BIG-IQ
  • Application Creation in BIG-IQ 7.0
  • Selection of the Standby Device's name when deploying this application 

Cause
The BIG-IQ does not know that the target BIG-IP are under the same Device Service Cluster (DSC) group. 

Recommended Actions

The BIG-IQ needs discover all target devices in the DSC. 
In order for you to see the pair of device as Active and Standby it should be added under BIG-IP CLUSTERS 
  1. At the top of the screen, click Devices.
  2. On the left, click BIG-IP CLUSTERS DSC groups.
  3. Click the Discover button.
  4. Select the devices in the Available list, and then click the right arrow to add them to the Selected list. This list is populated from the BIG-IP Device inventory list. If you can't see all of the available devices listed, left-click the right bottom corner of the list and use your cursor to expand the dialog box.
  5. Click the Discover button. The DSC Groups list refreshes to display the discovered DSC group.

Additional Information

When deploying an application  (filling out the Server’s IP addresses/ports (nodes) and virtual servers names, IPs and ports) to an Active device, it is able to view Dashboard Statistics. 
This is not the case when deploying to Standby Device.
