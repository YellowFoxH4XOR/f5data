In this error message, note the following:

  • <volume> is the volume number of the device.
  • <4 digit random number> is a random number generated by the BIG-IP system at the time of the error.
  • <6 digit random number> is a random number generated by the BIG-IP system at the time of the error.

Message Location

You may encounter this message in the following location:

  • Configuration utility

Description

This message occurs when all of the following conditions are met:

  • You set Boot Location with the Install Configuration option set to Yes.
  • The Source Volume of the Install Configuration is set to the same volume as the destination configuration installation volume.

Impact

Activation of the boot volume fails.

Recommended Actions

When choosing the destination source volume for Install Configuration, ensure that the Source Volume is not the same volume for the destination configuration installation.
