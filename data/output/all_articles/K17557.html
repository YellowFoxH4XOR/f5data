Known Issue

The Configuration utility does not display the HTTP tab in the Security Profiles menu.

This issue occurs when the following condition is met:

  • From the Security > Protocol Security section of the Configuration utility, you have selected DNS from the Security Profiles drop-down menu.

When you navigate to Security > Protocol Security in the Configuration utility, you have the option of selecting either HTTP or DNS from the Security Profiles drop-down menu. The HTTP security profile section displays by default.

Impact

The HTTP menu item appears to be missing in the user interface.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After selecting the DNS menu item from the Security Profiles menu, you observe the following:

    • When you click the Security Profiles menu, you only see the menu entry for DNS.
    • The breadcrumb trail on the Configuration utility does not display the full path for the DNS security profile configuration object.

    Resolution

    Workaround

    To work around this issue, you can navigate back to Security > Protocol Security, which defaults to the HTTP security profile.

    Impact of workaround: Performing the suggested procedure should not have a negative impact on your system.
