Known Issue

Citrix applications may fail to start when accessed through a BIG-IP APM network access session.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM system is configured with a network access profile.
  • You attempt to initialize a Citrix application using the Citrix web interface through a BIG-IP APM network access tunnel.
  • The name of the destination Citrix web interface application includes non-ASCII characters.

For examples of ASCII printable characters, refer to the ASCII page.    

Note: This link takes you to a resource outside of AskF5. The third party could remove the document without our knowledge.

Impact

The Citrix application does not start.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The Citrix receiver client displays a Connection Error message that appears similar to the following example:

    This published application currently is not available. Try connecting again later.

  • The Citrix application resource fails to initialize.

Workaround

To work around this issue, you can rename the affected Citrix web interface application to include only ASCII characters.

Impact of workaround:  Performing the suggested workaround should not have a negative impact on your system.
