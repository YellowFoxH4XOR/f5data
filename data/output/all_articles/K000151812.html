K000151812: Logfile /var/log/ecm not rotated by logrotate

Type
Support Solution
Published
2025-06-20
Updated
2025-06-20
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.2
Source
https://my.f5.com/manage/s/article/K000151812

Description

A specific log file, /var/log/ecm, is not being rotated by the logrotate utility on BIG-IP systems. This issue can occur even though the file is a default or system-generated log file and should be managed by logrotate.

Environment

  • BIG-IP LTM
  • ecm log files

Cause

Bug ID 739904

Recommended Actions

To ensure that /var/log/ecm is rotated properly, manually add the file to the logrotate configuration using tmsh:

tmsh modify sys log-rotate common-include '"

/var/log/ecm {

compress

missingok

notifempty

}"'

None
