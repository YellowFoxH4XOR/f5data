Known Issue

Policy Sync may fail when the access policy includes a Windows Registry check action.

This issue occurs when all of the following conditions are met:

  • The access policy is configured with a Windows Registry Endpoint Security (Client-Side) check.
  • The Location Specific check box in the Policy Sync Advanced Settings is selected for static objects to be synchronized.

Impact

Policy synchronization fails using the Policy Sync feature.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The Configuration utility shows a Not all devices in Sync message at the top left corner of the screen.
  • The synchronization process stalls or fails to complete when using Policy Sync.

Workaround

While there is no workaround for this issue, you may be able to mitigate this issue by clearing the Location Specific check box for the static objects to be synchronized. To do so, perform the following procedure:

Impact of procedure: Static objects will be synchronized using the existing configuration from the unit from which you are syncing. Any location-specific settings must be manually reconfigured on the target units after the Policy Sync process has completed.

  1. Log in to the BIG-IP APM Configuration utility.
  2. Navigate to Access Policy > Access Profiles > Policy Sync.
  3. Click the policy to be synchronized, and click Sync Access Policy.
  4. Click Advanced Settings.
  5. Clear the Location Specific check boxes for all static objects, and click OK.
  6. Enter any remaining information, and complete the Policy Sync process.
  7. Review any location specific objects that may need to be reconfigured on target BIG-IP APM systems.
