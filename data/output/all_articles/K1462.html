Issue

This error message indicates that the BIG-IP or 3-DNS from which you are initiating the configsync command cannot establish a connection to the other BIG-IP or 3-DNS in the redundant pair. There may be several possible reasons for this condition. Following are some specific BIG-IP configuration settings you can check:
 

CORBA ports

On each unit in the redundant pair, verify that the CORBA ports are open by typing the following command:

bigpipe global show

The output should display the open corba ports as enabled. If it does not, type the following command:

bigpipe global open_corba_ports enable

Peer IP setting

On each unit in the redundant pair, type the following command:

bigpipe db get '*state*'

In the IP address bar of each BIG-IP, the Local.BIGIP.StateMirror.PeerIPAddr should reflect the IP address of the other unit in the synchronized pair. If the address is not correct, type the following command and follow the prompts to correct the IP address:

config interfaces

CORBA remote host setting

On each unit in the redundant pair, type the following command:

b db get '*corba*'

In the IP address bar of each unit, the Local.Bigip.CORBA.DefRemoteHost should reflect the IP address of the other unit in the redundant pair. If the address is not correct, type the following command and follow the prompts to correct the IP address:

config remote
