Known Issue

Description

You cannot configure the Traffic Management Shell (tmsh) to display host names instead of IP addresses.

In versions prior to BIG-IP 11.0.0, you could set the global-settings hostname-lookup setting in tmsh, and the setting only affected the bigpipe utility, which was removed in BIG-IP 11.0.0. As a result, the setting does nothing, and returns an error.

Impact

You cannot view host names from your tmsh command line output.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Attempting to modify the hostname-lookup option under the cli global-settings configuration from within tmsh returns an error message similar to the following:

    Syntax Error: "hostname-lookup" unknown property
