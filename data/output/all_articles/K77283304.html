Known Issue

The BIG-IP LTM system may drop DNS query requests.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured to process DNS requests with one of the following configurations:
    • A virtual server with a FastL4 profile that accepts requests on port 53 (wildcard or port specific)
    • A secure network address translation (SNAT)
  • The system receives DNS A and AAAA record requests, simultaneously, from the same source address and port.

Impact

The system does not process DNS query requests.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you analyze the network level traffic of the DNS requests, you notice that the system drops the first requests and processes subsequent requests that arrive in the same manner from the same source address and port.

Workaround

To work around this issue, you can create a Standard virtual server configured with a User Datagram Protocol (UDP) profile to handle DNS requests.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
