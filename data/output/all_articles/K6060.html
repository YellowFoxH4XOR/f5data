Issue

BIG-IP LTM may log an error message to the /var/log/ltm file that appears similar to the following example:

tmm tmm[709]: 01010025:2: Device failure: cn0: CMC double-bit

The TMM Cavium driver sends this error message to indicate a double-bit parity error inside the internal memory of the Cavium card.

Recommended Actions

This issue may be caused by environmental issues external to the BIG-IP system, such as extreme thermal conditions or improper voltage to the power supply. If your BIG-IP system logs this error message, you should run the EUD utility and provide the diagnostic report to F5 technical support.

For information about the EUD, refer to K7172: Overview of the End User Diagnostics (EUD) software.
