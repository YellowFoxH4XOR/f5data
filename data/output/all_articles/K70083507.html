Description

ASM Bot defense profile may disable Compression (remove Accept-Encoding header).

Environment

  • Bot profile attached to Virtual Server
  • Bot defense functionality requires JavaScript injection.

Cause

In order for ASM to inject JavaScript, server response has to be decompressed. Depending on functionality, Accept-Encoding header might be removed at the beginning of the session only or at the beginning and selectively removed  as session continues.

When ASM needs to inject JavaScript, without HTTP compression profile attached to VS, BIG-IP will not compress those responses when forwarded to client.

Recommended Actions

This behavior is expected. You can consider attaching HTTP compression profile to Virtual Server, if encoding is required all the time.

Additional Information

There is a known issue that caused ASM to always remove encoding, even when not needed:
Bug ID 881757: Unnecessary HTML response parsing and response payload is not compressed
