Topic

Summary

Accessing the ARX Management GUI may result in Java exception error messages.

Description

If a client accesses the ARX Management GUI configuration page out of sequence or after the Java session has ended, a Java exception error message will display. In addition, the client will no longer be able to perform any ARX Management GUI operations.

Note: This issue may occur with greater frequency on older web browsers.

In the ARX catalina.out log, you may observe error messages that appear similar to the following example:

An Error Occurred:

/CreateVirtualServiceBasicInfo.jsft No saved view state could be found for the view identifier: /CreateVirtualServiceBasicInfo.jsft

Recommendations

When an ARX Management GUI Java exception error message occurs, you can recover by ending the Management GUI session. To do so, fully close the web browser and re-open the ARX Management GUI at the default page.

If you are using an older browser, F5 recommends that you upgrade the browser to a newer release.
