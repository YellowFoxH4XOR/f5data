K34370161: The inband monitor can now mark a Diameter server up

Issue

Old Behavior

In versions prior to BIG-IP 15.1.0, the inband monitor can only mark a Diameter server down but not up. As a result, you may need to configure a Diameter monitor together with the inband monitor for proper monitoring.

New Behavior

Beginning in BIG-IP 15.1.0, the inband monitor can now mark a Diameter server up when the connection to the Diameter server is successful.

Impact

With the enhancement to the inband monitor, you can configure the inband monitor to properly monitor a Diameter peer.

Recommended Actions

For more information on how to configure an inband monitor for a Diameter server, refer to K68211314: Configuring an inband monitor for a Diameter pool.
