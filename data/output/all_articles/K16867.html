Known Issue

The BIG-IP system fails to respond when receiving a DNS NOTIFY message from a remote nameserver.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP configuration includes a virtual server that references a DNS profile.
  • The DNS profile references a DNS zone that has the Notify Action option set to Consume.
  • The virtual server receives a DNS NOTIFY message from a remote nameserver.

Impact

A remote nameserver sends multiple DNS NOTIFY messages to the BIG-IP system because the nameserver does not receive a response message.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Remote nameservers do not receive responses when sending DNS NOTIFY messages to the BIG-IP system.
