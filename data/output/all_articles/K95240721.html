K95240721: ASM not detecting XSS from HTTP header value

Type
Support Solution
Published
2020-09-16
Updated
2025-02-07
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.1.1
Source
https://my.f5.com/manage/s/article/K95240721

Description
ASM could not detect XSS attack from encoded HTTP header value

Environment

  • BIG-IP ASM

Cause
HTTP header normalization not been enabled on ASM policy

Recommended Actions

  1. Turn on the HTTP header normalization from Configuration Utility
  2. GUI > Security > Application Security > Headers > HTTP Headers > (click) * > Normalization Settings >
    • check the checkbox "Url Normalization"
    • check the checkbox "HTML Normalization"

Additional Information
None
