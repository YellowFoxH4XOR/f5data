K000134732: Delayed binding

Type
Support Solution
Published
2023-05-22
Updated
2023-05-22
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000134732

Description

Virtual server is not forwarding packets from the client to the pool member until

Environment

Virtual server is configured with type Standard and a TCP profile

Cause

For its load balancing decision the virtual server is using the mechanismis called delayed binding

Recommended Actions

While the behaviour is expected and generally does not require any customisation, it is possible to change the virtual server type to Performance (Layer 4) forwarding instead. K01155812: Overview of the Performance (Layer 4) virtual server
