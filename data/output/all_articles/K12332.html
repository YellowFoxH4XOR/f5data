Known Issue

This is the result of a known issue. The BIG-IP APM does not insert the MRHSHint cookie into specialized HTML requests that Microsoft Office applications utilize. As a result, the BIG-IP APM redirects the session to logon again. Therefore, if a user attempts to save a document from Microsoft Office to a Microsoft SharePoint Server when connected to a BIG-IP APM web application session, the attempt to save will fail.

F5 Product Development tracked this issue as ID 224692 and it has been fixed in BIG-IP version 10.2.1. For information about upgrading, refer to the BIG-IP APM release notes.

In addition, this issue has been fixed in cumulative Hotfix-BIGIP-10.2.0-1789.0-HF2 issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.
