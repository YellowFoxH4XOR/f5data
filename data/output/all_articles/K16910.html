Topic

Summary

Considerations when setting the media type for the BIG-IP management port.

Description

For a reliable link status between the BIG-IP management port and an Ethernet switch port, both sides of the connection must use the same media type settings. Even if one side of the connection is set to auto negotiate, you may notice unreliable behavior if the other side is set to a fixed media type (regardless of which side of the connection is set to auto negotiate).

Recommendations

When you plan to connect to the BIG-IP management port, you should consider the following factors:

  • If your switch port is set to auto negotiate, you should set the BIG-IP management port to auto negotiate (default).
  • If your switch port media type is set to a fixed value, you should set the BIG-IP management port to the same fixed value.

    For example, if your switch port is set to 100TX-FD, you would set the BIG-IP management port to 100TX-FD by using the following commands:

    tmsh modify net interface mgmt media 100TX-FD

    tmsh save sys config
