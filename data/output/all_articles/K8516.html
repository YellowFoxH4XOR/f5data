Known Issue

This is the result of a known issue. When a user connects to the FirePass controller using the SSL VPN client for Windows Mobile 5.0 and 6.0 devices, and configures a pre-logon sequence using the Check OS inspector, FirePass incorrectly detects the Windows Mobile device as a Windows 98 client. When this issue occurs, FirePass sets the %session.os.platform% variable to Win98 and performs the pre-logon actions the user configured for Windows 9x clients instead of the pre-logon actions configured for Windows Pocket PC clients.

F5 Networks Product Development tracked this issue as CR95971 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.

Workaround

You can work around this issue by adding the UI mode inspector prior to the Check OS inspector in your pre-logon sequence, and using the UI mode standalone client rule to define the appropriate ending (for example, Logon Allowed Page), or additional actions for Windows Mobile clients. For more information about configuring pre-logon sequences, refer to the FirePass Controller Administrator Guide.
