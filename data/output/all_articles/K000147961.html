K000147961: How many Load balancers can one public IP address be assigned to?

Source

What Happened?

  • While creating Load balancers with Public IP you would like to know the limit to create the load balancers with one Public IP.

Environment

  • F5® Distributed Cloud Console
  • Load balancer 

 

Resolution/Answer

  • You can create as many load balancers as you would like to have, we don't have any limit to that.
