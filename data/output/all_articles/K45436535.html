Description

BIG-IP unexpectedly caches content that has meta tag Cache-Control=no-cache .

  • The BIG-IP caching behavior is unexpected.
  • The web server utilizes the meta tag Cache-Control=no-cache to signal to BIG-IP to not cache certain pages.
  • When viewing the ramcache, BIG-IP shows that URLs that have the meta tag Cache-Control=no-cache set are in the ramcache.

Environment

  • LTM
  • web-acceleration profile

Cause

The BIG-IP does not scan meta tags and does not obey any cache directives set within.

Recommended Actions

Use the HTTP Cache-Control header instead. Specifically the "no-store" should be used instead of the "no-cache' directive.

Note: The Cache-Control HTTP header should be used to control whether or not an object is cached.
