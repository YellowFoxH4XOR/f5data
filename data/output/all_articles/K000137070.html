K000137070: Regarding licensing behavior when restoring Azure VM disk

Type
Support Solution
Published
2023-10-02
Updated
2023-10-02
Applies to
  • Public Cloud
  • BIG-IP
  • Microsoft Azure
  • BIG-IP LTM: 17.1.0
Source
https://my.f5.com/manage/s/article/K000137070

Description

You would like to understand the licensing behavior when restoring the Azure VM disk.

Environment

  • Azure
  • License

Cause

None

Recommended Actions

In version 17.1.0, the license is bound to the system UUID. Therefore, BIGIP will be in an invalid license state and cannot be used because the license is bound (locked) to the system UUID and other parameters of the first installed device.
