Description

ASM is unable to start and the following messages are logged repeatedly in /var/log/asm:

crit perl[30900]: 01310027:2: ASM subsystem error (asm_start,F5::ASMStart::__ANON__): DBD::mysql::db do failed: Unknown table engine 'InnoDB' at /usr/local/share/perl5/F5/RamCache.pm line 57.
crit perl[30900]: 01310027:2: ASM subsystem error (asm_start,F5::ASMStart::__ANON__): DBD::mysql::db column_info failed: Can't create/write to file '/var/tmp/#sql_5570_0.MYI' (Errcode: 13) at /usr/local/share/perl5/F5/DbUtils.pm line 199.
info perl[31104]: 01310053:6: ASM starting

Environment

  • BIG-IP ASM
  • /var/tmp is no longer accessible

Cause

Recent changes to the filesystem resulting in /var/tmp to be inaccessible to ASM

Recommended Actions

Verify symbolic link is intact with the correct owner and SELinux permissions:

Example for v13.1.3.4:

 ls -Z /var/tmp
lrwxrwxrwx. root root system_u:object_r:tmp_t:s0       /var/tmp -> ../shared/tmp

Restart services mysql and asm:

restart sys service mysql asm
