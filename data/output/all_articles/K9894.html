Known Issue

This is the result of a known issue. When accessing a folder through a Windows File favorite, the user has the option to download the folder as a ZIP archive by selecting the Download as Zip option. However some archive programs, such as WinZip, may detect the file as an invalid archive. These programs are unable to access or extract the contents of the ZIP file. Other programs, such as the Microsoft Compressed Folders utility, are able to successfully access and extract the contents of the ZIP file.

F5 Product Development tracked this issue as CR118658 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.

Additionally, this issue has been fixed in cumulative hotfix HF-603-2.1, which has been issued for FirePass 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
