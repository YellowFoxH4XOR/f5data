Description

You're unable to reboot the BIG-IP while initiating the command reboot on the device, receiving the following error message;

[root@bigip_Guest_01::Standby:Not All Devices Synced] config # reboot
Failed to start reboot.target: Connection timed out
See system logs and 'systemctl status reboot.target' for details.
Failed to open /dev/initctl: No such device or address
Failed to talk to init daemon.

Environment

  • BIG-IP vCMP system
  • BIG-IP running version 14.1.4
  • reboot command or changing the boot location

Cause

Linux reboot command fails or in hung process.

Recommended Actions

You can force reboot using systemctl command:

   systemctl --force --force reboot

Additional Information

None.
