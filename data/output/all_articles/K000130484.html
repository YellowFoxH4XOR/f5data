Description

This article explains how to reboot the F5 rSeries on the command line.

Environment

  • F5 rSeries
  • Command line
  • SSH or console access

Cause

None

Recommended Actions

There are 2 options to reboot the system.
You can reboot it by executing reboot command if you are root user.
You can reboot it by executing system reboot if you are admin user.

Important: The deployed BIG-IP tenants running on the rSeries system will not be available to process application traffic during the reboot. F5 recommends you reboot the rSeries system during a maintenance window appropriate for your application environment.

  • If you are the root user, reboot the system by typing the following command:

    reboot

  • If you are the admin user, reboot the system by typing the following command:

    system reboot

    The following output appears. Enter yes:
    The reboot of the system results in data plane and management connectivity to be disrupted. Proceed? [no,yes] yes
