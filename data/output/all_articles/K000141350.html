Description

You want to ping from source IP to a destination IP address. 

If you try to use ping using a floating self IP address or SNAT pool address you will get below message. This is expected behavior, ICMP requests cannot be generated from floating self IP's or IPs from a SNAT pool.

bind: Cannot assign requested address

Environment

BIG-IP

Cause

None.

Recommended Actions

You can either use non-floating self IP address or interface name as source to ping to destination IP address. The syntax is <non-floating self IP or interface name> and <destination IP address> needs to be replaced.

ping -I <non-floating self IP or interface name> <destination> 

If you have multiple partition in your BIG-IP. You need to switch to the partition where the source IP you are trying to ping from exist and then run the ping command as per above syntax. To change to bash partition first go to TMOS

1. Enter to TMOS shell

tmsh

2. Change the partition

cd /partition_name

3. Exit out of TMOS. Now you will be in the bash shell of the particular partition. 

bash

Note: Though you will not see difference in the hostname or location where you are at the moment directly, you could confirm that the partitions has actually changed by checking the route or interface  information by using route -n and ip a commands respectively.
