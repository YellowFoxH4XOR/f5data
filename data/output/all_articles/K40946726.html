Description

This article describes how to modify the SSL/TLS protocols used by the BIG-IQ Configuration Utility.
You should consider using this procedure if you want to modify the SSL/TLS protocols used by the Configuration utility

Environment

  • You must have Advanced Shell (bash) or access to the BIG-IP system's bash shell.
  • You must have familiarity with a Linux text editor.

Recommended Actions

Configuring the SSL/TLS protocols used by webd
  1. Log in to the BIG-IQ command line
  2. Back up a copy of the /etc/webd/webd.conf file
    cp -p /etc/webd/webd.conf /var/tmp/webd.conf.K40946726
  3. Edit the /etc/webd/webd.conf file using a text editor of your choice
  4. Locate the line that starts with "ssl_protocols..."
    example:
    ssl_protocols SSLv2 SSLv3 TLSv1 TLSv1.1 TLSv1.2;
  5. Modify this line to meet your needs. For example, if you only want to allow TLSv1.2 it would look like this:
    ssl_protocols TLSv1.2;
  6. Save the changes and exit the text editor
  7. Restart the webd process by typing the following command:
    tmsh restart sys service webd
    Note: This procedure will restart the webd process and temporarily disrupt the functioning of the Web Configuration utility
