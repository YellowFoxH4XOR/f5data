K34545042: Changing application language within ASM policy copy does not work

Type
Support Solution
Published
2020-05-15
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 14.1.X, 14.1.4, 14.1.3, 14.1.2, 14.1.5, 14.1.0
Source
https://my.f5.com/manage/s/article/K34545042

Description

  • Unable to modify the application language with "Copy ASM Policy"
  • Using feature "Copy policy..." if you select another application language, it copies the actual policy without taking account of the modification on GUI, it remains as the original

Environment

  • ASM Security policy

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 759449

Recommended Actions

  • Upgrade to software version 15.x where Bug ID 759449 is fixed
  • An EngHF based on software version 14.1.x with the fix for Bug ID 759449 can be provided. Please open a case with F5 Support if EngHF is required:  K2633: Instructions for submitting a support case to F5

Additional Information

None.
