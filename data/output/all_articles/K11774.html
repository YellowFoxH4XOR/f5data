Known Issue

Note: This Solution only applies to systems formatted with the partitions disk-formatting scheme, which is typically only used when running both version 10.x and 9.x on the same BIG-IP system. If you are unsure of the disk-formatting scheme used by your BIG-IP system, refer to K10817: Determining the disk-formatting scheme used by a BIG-IP version 10.x system.

Note: The Maintenance Operating System (MOS) is an additional boot location which is automatically created when BIG-IP version 10.x is installed. MOS is used for maintenance/recovery purposes. For example, the BIG-IP system automatically reboots into MOS to perform version 10.x installations that require reformatting the drives. For more information on MOS, refer to K12509: Overview of the recovery tasks performed from the Maintenance Operating System (MOS).

This is the result of a known issue. If a BIG-IP system is running version 10.x and is formatted with the partitions disk formatting scheme, installing version 9.x onto an empty slot will cause the GRUB entry for MOS to be removed. This issue occurs because the version 9.x installation process does not recognize the MOS boot location and deletes it. As a result, you will no longer be able to boot into MOS by either selecting the appropriate entry in the GRUB menu or by issuing the mosreboot command.

When no GRUB entry for MOS exists and the mosreboot command is entered, the system returns the following error message:

error: boot entry st.mos does not exist

Note: Because of the issue described in this Solution, you will not be able to install a BIG-IP version 10.1.x or later hotfix on a partitioned system when all other partitions are running version 9.x. For more information, refer to K11033: Installing a BIG-IP version 10.1.x hotfix on a system that uses the partitions disk formatting scheme.

F5 Product Development is tracking this issue as ID 336711.

Workaround

If you have not installed BIG-IP version 9.x yet, you can work around this issue by saving the GRUB entry for MOS and restoring it after the installation. To do so, perform the following procedure:

  1. Log on to the BIG-IP system command line.
  2. As a precautionary measure, create a UCS backup and store it in a safe location on the network. You can create a UCS archive by typing the following command:

    bigpipe config save /config.ucs
  3. Save the GRUB entry for MOS by typing the following command:

    grub_default -d | grep -A6 -B1 maintenance > /var/tmp/grub.mos
  4. Install BIG-IP version 9.x.
  5. Once the installation has completed, boot the BIG-IP system back into version 10.x.
  6. Restore the GRUB entry for MOS by typing the following command:

    modgrub=`grub_open`; cat /var/tmp/grub.mos >> $modgrub; grub_close; unset modgrub

If you have already experienced the issue described in this Solution and no GRUB entry for MOS currently exists, you can work around the issue by manually reinstalling MOS. To do so, perform the following procedure:

Note: The following procedure requires a BIG-IP version 10.x ISO image. If necessary, download a BIG-IP version 10.x ISO image from the F5 Downloads site and upload it to the /shared/images/ directory of the BIG-IP system.

Note: You must perform the following procedure from the version 10.x installation. If necessary, boot the BIG-IP system into version 10.x before continuing. If you perform the following procedure form the version 9.x installation, MOS will not be installed correctly.

  1. Log on to the BIG-IP system command line.
  2. As a precautionary measure, create a UCS backup and store it in a safe location on the network. You can create a UCS archive by typing the following command:

    bigpipe config save /config.ucs
  3. Create the /var/tmp/addmos file by typing the following command:

    touch /var/tmp/addmos
  4. Using a text editor, open the /var/tmp/addmos file.
  5. Paste the following code into the file:

    #!/usr/bin/perl
    use tm_install::Process;
    Process_add_mos($ARGV[0]);
  6. Save the file and exit the text editor.
  7. Modify the access permissions for the /var/tmp/addmos file by typing the following command:

    chmod 777 /var/tmp/addmos
  8. Install MOS by typing the following command:

    /var/tmp/addmos <BIG-IP version 10.x ISO image>

    For example:

    /var/tmp/addmos /shared/images/BIGIP-10.1.0.3341.0.iso

    The BIG-IP system will return output that appears similar to the following example:

    info: No MOS currently exists. Installing 2.6.0 - 234.0
