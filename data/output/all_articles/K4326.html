Known Issue

There are a number of rare conditions that can cause BIG-IP or 3-DNS to crash without any associated user behavior and without providing an error. The following table provides information about these known issues:

Although you cannot make configuration changes to prevent these problems from occurring, you can use this table to assess the potential risks of the version you are running and decide when it is necessary to upgrade to reduce risk.

F5 Networks Product Development tracked these issues under the specified CR numbers. These issues affect only the listed version ranges and were fixed in later versions. For information about upgrading, refer to the BIG-IP and 3-DNS Release Notes.
