K000147608: How do I create a Bot Defense profile with a Tenant ID over 12 characters?

Description

If you're enabling TMOS 17.0 Bot Defense profiles to work with F5 Distributed Cloud (F5 XC) Bot Defense, you might be getting error 01db0003:3: The field (tenant-id) length should be (12) characters only.

 

 

The new Bot Defense Profiles included as part of the TMOS 17.0 were originally developed and tested to work with the legacy F5 Cloud Services Portal. Some character and length limitations were included in the various form fields to work specifically with that platform, such as the Tenant ID field must be exactly 12 characters long.

The new F5 XC platform uses tenant IDs that are longer than 12 characters and will not work with the character limitations enforced in the module. However, a simple workaround can be implemented to enable the Bot Defense profiles.

 

Environment

  • F5® Distributed Cloud (XC) Services
  • BIG-IP v17.0 

Answer/Recommended Actions

 1. Create a BD Profile with the values obtained from the XC Portal

 

    • More documentation can be found in the Help tab as shown below 
    • For example, enter "abcdefghijkl" (or any twelve-character string) into the Tenant ID field. 
    •                

  2. Create an iRule with the following syntax:

    when HTTP_REQUEST {
  HTTP::header replace "sed-api-tenant-id" "<your-tenant-id>"
}

     

    Replacing <your-tenant-id> with your actual tenant ID as copied from the F5 XC Bot Defense portal                                                                                                                                                               

  3. Assign the iRule created in step 2 to the BD Profile created in step 1:

    • Expand the Advanced Features section of the BD profile and ensure that Advanced view is selected from the dropdown box
