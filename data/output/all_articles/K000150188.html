K000150188: Nginx error: client intended to send too large body.

Type
Support Solution
Published
2025-03-05
Updated
2025-03-05
Applies to
  • NGINX Products
  • NGINX Plus: R31
Source
https://my.f5.com/manage/s/article/K000150188

Description

Setting a higher client body limit with client_max_body_size only in the location block has no effect.

NGINX continues to restrict client request bodies and logs the following error:

client intended to send too large body

Environment

NGINX Plus

 

Cause

By default, the restriction is set to 1MB. client_max_body_size

Requests exceeding this limit are dropped at the server level before reaching the location level.

server { 
  ...
  location /foo {
   client_max_body_size 5m;
   ...
  }
  location /bar {
   client_max_body_size 2m;
   ...
  }
}

Recommended Actions

Ensure the limit set at the server level is equal to or higher than the limit at the location level.

Example:

server { 
  client_max_body_size 5m;
  ...
  location /foo {
   client_max_body_size 5m;
   ...
  }
  location /bar {
   client_max_body_size 2m;
   ...
  }
}
