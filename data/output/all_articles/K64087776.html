Known Issue

Setting the IPsec KBLifetime value in the Configuration utility may fail.

This issue occurs when the following condition is met:

  • You use the Configuration utility to set a KBLifetime value between 2147483648 and 4294967295.

Impact

Administrators cannot use the Configuration utility to set the KBLifetime value.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • BIG-IP iHealth lists Heuristic H585344 on the Diagnostics > Identified > Low screen.
  • When you attempt to set the KBLifetime value in the Configuration utility, the system generates an error message similar to the following example:

    General database error.

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to set the KBLifetime value. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. To set the KBLifetime value, use the following command syntax:

    modify net ipsec ipsec-policy <ipsec_policy_name> ike-phase2-lifetime-kilobytes <KBLifetime_value>

    For example, to set the KBLifetime value to 3555555555 for the test_policy IPsec policy, type the following command:

    modify net ipsec ipsec-policy test_policy ike-phase2-lifetime-kilobytes 3555555555
