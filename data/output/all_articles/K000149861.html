K000149861: "An error has occurred while trying to process your request" while viewing Security >> Policies in GUI with TACACS Remote Auditor Role

Type
Support Solution
Published
2025-02-20
Updated
2025-04-08
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149861

Description

"An error has occurred while trying to process your request" while accessing Security >> Policies Tab for a Virtual Server in the GUI. This occurs when using the remote TACACS role of Auditor

Environment

  • BIG-IP
  • LTM
  • ASM
  • TACACS Auditor Role

Cause

  • Bug ID 1037405

Recommended Actions

  • Follow workaround in Bug ID 1037405

Additional Information

  • command to verify icontrol-role-migrator output:

    # restcurl -u <username>:<password> shared/storage?key=shared/authz/icontrol-role-migrator

 

  • After following the workaround, no further changes or saving is required
