Topic

Purpose

You should consider using these procedures under the following condition:

  • You want to create or modify Virtual Local Area Networks (VLANs) using the TMOS Shell (tmsh).

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You can access tmsh as an administrative user.

Description

In certain situations, you may need to use tmsh, instead of the Configuration utility, to create a new VLAN.

Procedures

You can use tmsh to create or modify VLANs. To do so, perform the following procedures:

  • Create a VLAN with an untagged interface
  • Modify the untagged interface associated with an existing VLAN
  • Create a VLAN with a tagged interface
  • Modify a VLAN to be associated with another tagged interface
  • Modify the VLAN tag number on an existing tagged interface

Create a VLAN with an untagged interface

A VLAN can only be associated with a single untagged interface. To create a new VLAN with an untagged interface, perform the following procedure:

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To create a VLAN on an untagged interface, use the following command syntax:

    create /net vlan <vlan_name> interfaces add { <interface> }

    For example:

    create /net vlan test-vlan interfaces add { 1.1 }

  3. Save the change by entering the following command:

    save /sys config

  4. To view the BIG-IP system's VLAN configuration by entering the following command:

    show /net vlan

Modify the untagged interface associated with an existing VLAN

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

Note: The replace-all-with command in this procedure replaces all interfaces currently associated with the VLAN with the specified untagged interface while leaving the VLAN otherwise intact.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify the untagged interface for a VLAN, use the following command syntax:

    modify /net vlan <vlan_name> interfaces replace-all-with { <interface> }

    For example:

    modify /net vlan test-vlan interfaces replace-all-with { 1.3 }

  3. Save the change by entering the following command:

    save /sys config

  4. To view the BIG-IP system's VLAN configuration, enter the following command:

    show /net vlan

Create a VLAN with a tagged interface

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To create a VLAN with a tagged interface, use the following command syntax:

    create /net vlan <vlan_name> interfaces add { <interface> { tagged }} tag <vlan_tag>

    For example:

    create /net vlan test-vlan interfaces add { 1.1 { tagged }} tag 4093

  3. Save the change by entering the following command:

    save /sys config

  4. To view the BIG-IP system's VLAN configuration, enter the following command:

    show /net vlan

Modify a VLAN to be associated with another tagged interface

Impact of procedure: The impact of this procedure depends on the specific environment. F5 recommends testing any changes during a maintenance window, with consideration to the possible impact on your specific environment.

Note: The replace-all-with command in this procedure replaces all interfaces currently associated with the VLAN with the specified tagged interface while leaving the VLAN otherwise intact.

  1. Log in to tmsh by entering the following command:

    tmsh

  2. To modify the VLAN associated with an existing tagged interface, use the following command syntax:

    modify /net vlan <vlan_name> interfaces replace-all-with { <interface> { tagged }} tag <vlan_tag>

    For example:

    modify /net vlan test-vlan interfaces replace-all-with { 1.3 { tagged }} tag 4093

  3. Save the change by entering the following command:

    save /sys config

  4. To view the BIG-IP system's VLAN configuration, enter the following command:

    show /net vlan
