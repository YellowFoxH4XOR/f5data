K000156806: Trunking (802.1Q VLAN) Not Supported in AWS for BIG-IP VE

Type
Support Solution
Published
2025-10-09
Updated
2025-10-09
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000156806

Description

Trunking (802.1Q VLAN trunk) is not supported in AWS for BIG-IP Virtual Edition (VE) or any other instance type. AWS Elastic Network Interfaces (ENIs) only support untagged (access) mode, and each ENI is associated with a single subnet. VLAN-tagged (802.1Q) traffic is not supported in AWS, and any VLAN tags will be stripped or dropped by the AWS virtual network infrastructure. As a result, you cannot configure a trunk or assign multiple VLANs to a single interface in AWS.

Environment

  1. BIG-IP Virtual Edition (VE) deployed in Amazon Web Services (AWS)
  2. AWS Elastic Network Interfaces (ENIs)
  3. All AWS instance types

Cause

AWS ENIs do not support VLAN trunking or 802.1Q VLAN tags.

Each ENI is mapped to a single subnet and only supports untagged (access) mode.

AWS networking infrastructure strips or drops any VLAN tags.

Recommended Actions

Do not attempt to configure trunks or assign multiple VLANs to a single interface in AWS.

For connectivity to multiple networks, assign additional ENIs to your BIG-IP VE instance, each in a different subnet.

Ensure each BIG-IP VE interface (eth0, eth1, etc.) is mapped to a separate ENI and subnet.
