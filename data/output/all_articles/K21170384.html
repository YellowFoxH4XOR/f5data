Description

Unable to Sync ASM configuration to peer in the Device Group.

LTM logs show successful Configsync and no errors found in ASM logs.


Environment

  • GUI displays 'In Sync'
  • Since upgrade from 13.1.3.4 to 13.1.3.6


Cause

Bug ID 457391: Device Management: ASM Sync status is not represented in GUI
 

Recommended Actions

Restart the daemon asm_config_server using the following command:

pkill -f asm_config_server


Additional Information

None.
