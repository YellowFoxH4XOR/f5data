Known Issue

The Network Access Setup Wizard may fail and produce an error.

This issue occurs when all of the following conditions are met:

  • You navigate to Wizard Section > Network Access Setup Wizard for Remote Access.
  • You select the Authentication Option to create a new SecurID authentication profile.
  • You supply the required configuration information as prompted by the wizard.
  • You complete the configuration wizard.

Impact

The wizard produces an error and fails to create the configuration objects.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you complete the wizard, the system displays an error message similar to the following example:

    General database error.

  • When the wizard fails, the system logs a message similar to the following example to the /var/log/ltm file:

    err mcpd[<pid>]: 01071146:3: The child access profile (/<partition>/<profile name>) must have a valid access policy.

  • When the wizard fails, the system logs a message similar to the following example to the /var/log/webui.log file:

    ERROR [TP-Processor2] SAWizard.SACreateAccessPolicy:takeAction - java.io.FileNotFoundException: /shared/tmp/upload__<encoded>.tmp (No such file or directory)

Workaround

To work around this issue, you can select a different Authentication Option to complete the wizard. Once you have completed the wizard, you can create the SecurID authentication profile and modify the access policy to use the SecurID authentication profile. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Access > Authentication > SecurID.

    Note: For BIG-IP APM versions earlier than 13.0.0, navigate to Access Policy > AAA Servers > SecurID.

  3. Click Create.
  4. In the Name box, type a name for the SecurID profile.
  5. In the Agent Host IP Address, select an existing self IP address, or to enter the IP address manually, select Other.
  6. From your local device, select the SecurID Configuration File to upload to the BIG-IP APM system.
  7. Click Finished.
  8. Navigate to Access > Profiles / Policies > Access Profiles.

    Note: For BIG-IP APM versions earlier than 13.0.0, navigate to Access Policy > Access Profiles > Access Profile List.

  9. To open the VPE editor, click the Edit link to the right of the affected access profile.
  10. Click [+] to the right of the Logon Page agent.
  11. Click the Authentication tab.
  12. Select the button to the left of RSA SecurID and click Add Item.
  13. Select your newly created SecurID AAA profile from the AAA Server menu, and click Save.
  14. Locate the original wizard-created authentication agent to the right of the SecurID authentication agent.
  15. Click the [x] of the authentication agent.
  16. Click Delete.
  17. Click Apply Access Policy.
