Description

The tmm process crashes and generates core file after "release offline" hold following upgrading to 17.1.2.1.

Environment

  • System upgraded to 17.1.2.1
  • System is forced offline for the upgrade.
  • "Release offline" button pushed after system boots up.
  • TMM crashes and generates a core file.
  • In-tmm TCP monitor defined with no enable or disable (recv or recv-disable) strings defined.

Cause

Cause attributed to this: Bug ID 1819777: In-tmm TCP monitor with no RCV and RCV disable string might lead to a crash

Recommended Actions

Complete workarounds listed in the article: Bug ID 1819777: In-tmm TCP monitor with no RCV and RCV disable string might lead to a crash

- Disable in-tmm monitoring.

- OR, configure in-tmm TCP monitor with any string match.
