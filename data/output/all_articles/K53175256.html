K53175256: Tripo storage records grow rapidly when server session peer is not responding or down

Type
Support Solution
Published
2021-08-23
Updated
2023-02-21
Applies to
  • Traffix SDC: 5.2.X, 5.1.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K53175256

Description

SDC Session Management is enabled and includes at least one session binding rule using cache action. In an event where server session peer that is selected to handle the initial session request is either down or does not response within a timeout threshold, Tripo storage will be filled with invalid session record which does not include a success answer of session peer.

  • Tripo Session Repository Entries graph may observe a rapid growth in entries
  • Error message as follows appears:
    • WARN  [11332] External storage server error: Key:[remotepeer.example.com;1234;5678] OpCode:op_put Status:st_err_general Error message is:400  Table Full. [Tripo-EpollEventLoop-thread 4_2_23] [AsyncStorageProvider.answerReceived()]

Environment

  • SDC Session Management
  • Remote server session peer

Cause

Tripo storage will be filled with invalid session record which does not include a success answer of session peer.
Invalid session record used up the Tripo storage space and reduce the available space for storing valid session record.

Recommended Actions

SDC setup environment that enable session management and includes at least one session binding rule using cache action need to include this script as part of its deployment:

  1. Lookup any routing rule that handles Diameter session traffic such as Gx, Gy added those lines under Check Error In Answer:
def reqType = answer.getValue("CC-Request-Type")
def resultCode = answer.getValue("Result-Code");
if (resultCode >= 3000 && reqType ==1 ) {
    session.release();
}
return null;
  1. Added lines under Handle Server Error:
def reqType = requestFromClient.getValue("CC-Request-Type");
if (event == RemoteNodeEvent.CANNOT_ROUTE) {
    def answer = requestFromClient.createAnswer(3002);//DIAMETER_UNABLE_TO_DELIVER
    answer.setError(true);
    if (reqType == 1) {
        session.setPersistSessionData(false);
        session.setShouldReplicate(false);
        }
    return answer;
}
if (event == RemoteNodeEvent.CHANNEL_DISCONNECTED) {
    def answer = requestFromClient.createAnswer(3002);
    answer.setError(true);
    if (reqType == 1){
        session.release();
        }
    return answer;
}
if (event == RemoteNodeEvent.TIMEOUT) {
    def answer = requestFromClient.createAnswer(3004);//TOO_BUSY
    answer.setError(true);
    if (reqType == 1) {
        session.release();
        }
    return answer;
}
return answerFromServer;
