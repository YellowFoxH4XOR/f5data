K000141425: Hyper-V and High Availability

Type
Support Solution
Published
2024-10-11
Updated
2024-10-11
Source

Description

When using Hyper-V you find that High Availability is not working.

Environment

  • High Availability
  • Self IPs, NICs

Cause

For Hyper-V, three virtual NICs are required, at a minimum. More NICs are required if the high availability option is configured. Also, if you started with only 1 NIC and now need to move to multiples it will not work unless you "reset" the NICs

Recommended Actions

The actions or steps required to address the topic covered in the description.

  1. If HA is part of what you will be doing with the BIG-IP then configure at least 4 NICS.
  2. If you started with one NIC and now realize you need multiple NICS to reset the NICS...
    1. Use an SSH tool to connect to BIG-IP VE.
    2. Return to the default configuration. tmsh load sys config default
    3. Save the changes. tmsh save sys config
    4. Set a database variable so that the number of NICs will be recognized on reboot. setdb provision.1nic enable
    5. Reboot BIG-IP VE. reboot
    6. When the BIG-IP VE instance is up and running, multiple NICs will be recognized and you can begin configuring BIG-IP VE.
