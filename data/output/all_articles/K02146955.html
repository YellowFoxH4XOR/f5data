Description

iSeries BIG-IP appliance shows alert message display on console or on LCD panel
Fan_# fan rpm low (crit)

Environment

  • BIG-IP iSeries Appliances

Cause

None

Recommended Actions

Run the following commands to confirm the fan speed in the BIG-IP unit.

  1. Login to BIG-IP through CLI
  2. Clear the alarms of LCD panel through cli mode :
  3. tmsh reset-stats sys alert lcd
  4. Run command to see the fan speed in bash mode :
     # ipmiutil sensor -ct | grep -iE "sdrtype|fan_" -A1
     # tmctl -w 200 -d blade sensor_measurement_table

If there is a fan speed error in the output, please open an case with F5 Network Support and provide the output of these commands.
