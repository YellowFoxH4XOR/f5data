Description

When restoring from a UCS archive the configuration from the UCS is restored and unexpectedly synchronized to the devices in the device group.

Environment

  • UCS archive that was generated while Automatic Sync is enabled.
  • Restoration from UCS to a device that is a member of a device group.
  • The UCS maybe older and have an out of date configuration.

Cause

If the system had Automatic Sync enable when the UCS is generated the setting will be enabled when the UCS is restored and will immediately synchronize the configuration from the archive to the devices in the device group.  This happens because the restored configuration will have the most recent timestamp and this will be synchronized as the latest configuration change within the group.

Recommended Actions

To avoid this situation, you can perform the following tasks prior to installing the UCS file:

  1. Disconnect the interfaces on the device on which you are restoring the UCS file.
  2. Restore the UCS file on the device.
  3. Make a change on the peer device with the configuration you want to use.

    Note: This step ensures that the correct device has the most recent change and initiates the automatic ConfigSync operation.

  4. Reconnect the interfaces on the device on which you restored the UCS file.

Additional Information
 

  • This action may be unwanted if the UCS file contains an older configuration and you do not want to overwrite the configuration of the device group members.
  • This situation can be prevented by disabling Automatic Sync prior to generate UCS archive.
