Known Issue

The BIG-IP system incorrectly reports SSL hardware acceleration statistics.

This issue occurs when all of the following conditions are met:

  • You have configured an SSL Client or SSL Server profile using a ciphersuite that uses both hardware and software acceleration.
  • You use the tmsh show ltm profile client-ssl or tmsh show ltm profile server-ssl command.

Impact

None

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP system incorrectly reports ciphersuites that use both software and hardware acceleration as being fully hardware accelerated.

    For example, a Client SSL profile is configured to use the ECDHE ciphersuite, and a client connects and negotiates with the system to use the ECDHE-ECDSA cipher. On some platforms the ECDHE ciphersuite handshake is handled in software and then passed on to the hardware for bulk encryption or decryption. Since the handshake is not handled fully in hardware, when you type the tmsh show ltm profile client-ssl command, the system should report the connection as Partial under SSL Hardware Acceleration, however, the system reports the connection as Full.
