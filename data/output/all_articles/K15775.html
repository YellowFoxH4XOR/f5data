Known Issue

The Clusters or Templates page of the Configuration utility is blank and displays a General Database Error.

This issue occurs when all of the following conditions are met:

  • You are using a multi-blade VIPRION chassis system.
  • Using the Configuration utility, you navigate to the Clusters page and then attempt to navigate to the Templates page.

    or

    You navigate to the Templates page and then attempt to navigate to the Clusters page.

Impact

You cannot use the Configuration utility to modify the Templates or Clusters pages.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H486524 on the Diagnostics > Identified > High screen.
  • The system displays a blank page.
  • In the Configuration utility, you see an error message similar to the following example:

    General Database Error

  • In the /var/log/tomcat/catalina.out log file, you see an error message similar to the following example:

    ERROR [TP-Processor3] application_005ftemplate.list_jsp:_jspService - Column not found: SLOT_ID in statement [SELECT LIMIT 0 10 OPTIMIZED * FROM app_template ORDER BY slot_id ASC]

Workaround

To work around this issue, you can restart the tomcat service after encountering the error. To do so, perform the following procedure:

Impact of workaround: The Configuration utility will be temporarily unavailable while the tomcat service restarts.

  1. Log in to the BIG-IP system as the root user.
  2. At the command prompt, type the following command:

    bigstart restart tomcat
