Description

BIG-IP not connecting to Active Directory services for authentication

Environment

  • BIG-IP
  • Active Directory Remote Authentication

Cause

BIG-IP prefers using TMM routes over Management routes for remote authentication

Recommended Actions

Ensure one of your TMM routes can reach your authentication server or that the existing routes do not conflict with working management routes. 

Use the following commands and actions to troubleshoot and verify your systems network routing:

  • Review BIG-IP logs.
    • /var/log/ltm
    • /var/log/secure
For example, you may observe logs similar to the following in /var/log/secure:
err httpd[24124]: pam_ldap: ldap_simple_bind Can't contact LDAP server Jan  3 10:45:28 exampleHost 
err httpd[24124]: pam_ldap: reconnecting to LDAP server...
err httpd[24124]: pam_ldap: ldap_simple_bind Can't contact LDAP server Jan  3 10:45:40 exampleHost 
notice httpd[24124]: pam_ldap: Auth server unavailable, trying fallback 
notice httpd[24124]: pam_ldap: user A18048 not authenticated
  • Useful commands.
    • ip route get <IP address>
    • tmsh show net route
    • tmsh show net arp
  • Perform TCP capture.
    • mgmt: tcpdump -s0 -nni eth0 -w /shared/tmp/ldapmgmt.pcap port 636 -v
    • tmm: tcpdump -s0 -nni 0.0:nnn -w /shared/tmp/ldaptmm.pcap port 636 -v

Additional Information

Note: Review the Overview of TMOS Routing Manual in Releated Content for more information regarding routes on BIG-IP
