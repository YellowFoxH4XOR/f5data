Topic

To determine the amount of iQuery traffic generated between a 3-DNS Controller and a BIG-IP system, you can perform a packet trace on one or both of the controllers to determine how much traffic is passing between them.

To perform a packet trace, run the tcpdump command on one or both controllers and filter for UDP packets on ports 245 and 4353.

Note: You can run the command and watch the traffic in real time, or have it run and save the information that it captures to a file. If you choose to run tcpdump and save the output to a file, do not leave it running for too long; because the output file can grow very quickly and fill up the controller's filesystem.

For example, to display UDP traffic on ports 245 and 4353 through the exp0 NIC on a 3-DNS Controller, and save the output to a file for later viewing, type the following command on either controller:

tcpdump -n -i exp0 -w <filename> udp and port 245 or port 4353

To read the file created during a packet trace, type the following command:

tcpdump -n -r <filename>

For more information about iQuery communication, refer to K159: Overview of F5 Networks iQuery protocol.

For more information about the tcpdump command, refer to the tcpdump man pages.
