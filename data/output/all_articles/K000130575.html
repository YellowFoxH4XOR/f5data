Description

Starting from version 14.0.0 it is now possible to specify status codes for redirect actions.

Environment

  • BIG-IP 

  • Virtual Server

  • LTM policy

  • HTTP Redirect

Cause

F5 Product Development has assigned bug ID 441800 to this case. Previously, the only value available was 302.

 Recommended Actions

When creating an LTM policy in the Configuration Utility (GUI), choose "Redirect" as the action for the rule to execute. 
You will be able to specify Code in the "Options" section.
