Known Issue

Note: The issue described in this article does not affect BIG-IP systems running version 11.x due to an architectural change in the ConfigSync feature.

This is the result of a known issue. If you perform certain operations that do not require a ConfigSync operation on a BIG-IP redundant pair system, the BIG-IP redundant pair units incorrectly report that a ConfigSync is recommended. For example, after performing one of the following operations on a member of a BIG-IP redundant pair, the systems incorrectly report that a ConfigSync is recommended:

Note: Software images and the bigip_base.conf file are not synchronized between redundant pair members and neither of the following actions require a ConfigSync.

  • Downloading a software/hotfix image to one system in an high availability pair
  • Changing objects that reside in the bigip_base.conf file, such as disabling an interface

The ConfigSync autodetect feature automatically detects configuration synchronization status for BIG-IP systems in a redundant pair and displays the status in the Configuration utility.

F5 Product Development is tracking this issue as ID 223120 (formerly CR127731).

Workaround

Once the systems incorrectly report that a sync is recommended, you can perform a ConfigSync operation to clear the incorrect status.

Note: Performing a ConfigSync may not clear the incorrect status in all situations.
