Description

This article describes how to restore BIG-IQ HA after auto failover 

Environment

  • BIG-IQ HA
  • Auto failover
  • GUI

Cause

None

Recommended Actions

If one BIG-IQ system in HA auto failover goes offline, another BIG-IQ system can continue managing your devices without interruption. The previous active unit will show "Waiting for BIG-IQ services to become available..." on GUI

1. To recover the BIG-IQ, run the following command on bash for both BIG-IQ 

ha_reset -f <discovery_address>

2. Add the standby BIG-IQ for an HA configuration with auto failover according to the article below

Adding a Standby BIG-IQ to Create a High Availability Auto Failover Configuration
