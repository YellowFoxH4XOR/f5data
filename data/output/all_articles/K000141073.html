K000141073: Unexpected "upload_################### .dat" File Located in "/shared/images" Directory

Type
Support Solution
Published
2025-01-03
Updated
2025-01-03
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000141073

Description

When navigating to the /shared/images directory and utilizing the command "ls" or it's variations, the result are files titled  "upload_################### .dat". The "#" represents any number from 0 to 9 in a sequence similar to example provided below:

-rw-r--r--. 1 tomcat tomcat 220683728 Sep 14 02:07 upload_375792898377327250.dat

 

Environment

BIG-IP version 15.1.x and later

"upload_################### .dat" found in /shared/images directory

 

Cause

Upload process of a software image, hotfix, update or other file is interrupted or not completed successfully.

 

Recommended Actions

Remove files by following these steps:

Access the CLI:

You can access the CLI via SSH. Use an SSH client (like PuTTY) to connect to your BIG-IP system. You'll need the management IP address of the BIG-IP and appropriate login credentials. Please make sure that you are logging into "root" or into another user account that has the appropriate privileges to delete files.

 

1. Once logged in, navigate to the /shared/images directory by using the cd command:

cd /shared/images

2. List the files. It's always a good idea to list the files in the directory to ensure you're deleting the correct one. Use the "ls" command:

ls -l

3. Use the rm command and the asterisk symbol in the file name to remove all "upload_###.dat" files in the directory:

rm upload_*.dat

4. After deleting the file, you might want to list the files again to confirm it has been removed:

ls -l

 

Additional Information

This typically indicates an incomplete or partially uploaded image file. This often happens when a user attempts to upload a software image, hotfix, or some other update to the BIG-IP system, but the upload process is interrupted or not completed successfully. These files are usually temporary and can be safely deleted if the upload process is retried and completed properly. To avoid such issues, ensure a stable network connection and sufficient disk space before attempting the upload again.
