Description

Before you can configure and use the BIG-IP system, you must activate a valid license key, also known as the Base Registration Key on the system.

Note: If you do not have a valid license key, contact your F5 Account Manager or the F5 Sales.

You should consider using this article under the following conditions:

  • You want to activate and install a new license on a new BIG-IP system.
  • You want to activate and install a license containing one or more add-on registration keys on a BIG-IP system.
  • You want to re-activate and install an existing license on a BIG-IP system.

To license the BIG-IP system, review the following procedures

  • Video Demo - Licensing the BIG-IP system
  • Obtaining a registration key
  • Obtaining a dossier
  • Activating the license
    • Activating the license using the automatic activation method
    • Activating the license using the manual activation method
  • Activating an add-on module
    • Activating the add-on module using the automatic activation method
    • Activating the add-on module using the manual activation method

To watch a video demo of this procedure, go to  Licensing the BIG-IP system.

Note: A restart may be required after licensing the BIG-IP system.

Obtaining a registration key

Before you can activate the license for the BIG-IP system, you must obtain a base registration key. The base registration key is a 27-character string that instructs the license server which F5 products you can license. The base registration key is pre-installed on new BIG-IP systems. When you connect to the Configuration utility, the Licensing page opens and displays the registration key.

The format of the BIG-IP base registration key is as follows:

AAAAA-BBBBB-CCCCC-DDDDD-EEEEEEE

Obtaining a dossier

The dossier is an encrypted list of key characteristics used to identify the platform. You can obtain a dossier from the BIG-IP software.

Your F5 product generates the dossier after you choose a license activation method. See Activating the license for details.

Activating the license

If you have not yet licensed your BIG-IP system and you connect to the Configuration utility, the system prompts you to enter the base registration key. Certain systems may require you to enter keys for additional modules in the Add-On Registration Key List box. When you activate the license on a BIG-IP hardware platform, the system permanently associates the base registration key to the BIG-IP system's serial number; therefore, you cannot move licenses and base registration keys.

To activate the license on the BIG-IP system using the Configuration utility, you can use either the automatic activation method or the manual activation method. The activation method specifies how you want the system to communicate with the F5 License Server. The license activation date is unique to the device from which the dossier originates.

Activating the license using the automatic activation method

You can use the automatic method if you have configured the BIG-IP management port to route traffic to the Internet. You should use the manual method if you have not configured the BIG-IP management port to route traffic to the Internet.

To activate the license on the BIG-IP system using the automatic activation method, perform the following procedure:

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility using an account with the administrator role.

    Note: If this is a new BIG-IP system, open a web browser on a workstation attached to the network on which you configured the management port and type the following URL in the browser: https://<IP address>/. <IP_address> is the address that you configured for the management port.

  2. Select Activate.

    Note: If the BIG-IP system is already licensed, navigate to System > License and select Re-activate. Optionally, select the Enable License Comparison check box to compare a new license with the existing BIG-IP license.

  3. Select Automatic.
  4. Optional: For Outbound Interface, select the appropriate interface that has connectivity to the license server activate.f5.com for port 443.

    Note: This option is not available for BIG-IP Virtual Edition (VE).

  5. Select Next.
  6. The BIG-IP system automatically connects to the F5 License Server and activates the license.

Activating the license using the manual activation method

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility using an account with the administrator role.

    Note: If this is a new BIG-IP system, open a web browser on a workstation attached to the network on which you configured the management port and type the following URL in the browser: https://<IP address>/. <IP_address> is the address that you configured for the management port.

  2. Select Activate.

    Note: If the BIG-IP system is already licensed, navigate to System > License and select Re-activate. Optionally, select the Enable License Comparison check box to compare a new license with the existing BIG-IP license.

  3. Select Manual.
  4. Select Next.
  5. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  6. On the F5 Licensing Tools page, select Activate F5 product registration key.
  7. Paste the dossier into the Enter Your Dossier box, and then select Next.

    The F5 Product Licensing page produces your license.

  8. Copy the license and paste it into the License box in the Configuration utility.
  9. Select Next.

Activating an add-on module

You can add BIG-IP feature modules to a BIG-IP device for additional functionality. Adding a feature module requires you to obtain an add-on registration key and re-activate the license. After you obtain an add-on registration key, you can activate the feature using the Configuration utility. When licensing redundant BIG-IP systems, you must obtain a unique add-on registration key for each device.

Important: After you activate an add-on registration key, it is permanently associated with the base registration key you licensed it with.

The format of the BIG-IP add-on registration key is as follows:

AAAAAAA-BBBBBBB

Activating the add-on module using the automatic activation method

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility using an account with the administrator role.
  2. Go to System > License.
  3. Select Re-activate.
  4. Paste the add-on registration key into the Add-On Key box and select Add.
  5. Select Automatic.
  6. Optional: For Outbound Interface, select the appropriate interface that has connectivity to the license server activate.f5.com for port 443.

    Note: This option is not available for BIG-IP Virtual Edition (VE).

  7. Select Next.
  8. The BIG-IP system automatically connects to the F5 License server and activates the license.

Activating the add-on module using the manual activation method

Impact of procedure: Traffic processing is briefly interrupted while the BIG-IP system reloads the configuration. When licensing redundant BIG-IP systems, F5 recommends that you activate the license on your BIG-IP devices while they are in standby mode.

  1. Log in to the Configuration utility using an account with the administrator role.
  2. Go to System > License.
  3. Select Re-activate.
  4. Paste the add-on registration key into the Add-On Key box and select Add.
  5. Select Manual.
  6. Select Next.
  7. Copy the dossier and connect to the F5 Product Licensing page at secure.f5.com.
  8. On the F5 Licensing Tools page, select Activate F5 product registration key.
  9. Paste the dossier into the Enter your dossier box, and select Next.

    The F5 Product Licensing page produces your license.

  10. Copy the license and paste it into the License box in the Configuration utility.
  11. Select Next.
