K23304000: Sync Failed A validation error occurred while syncing to a remote device BIG-IP AFM 16.0.1

Type
Support Solution
Published
2021-10-27
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP AFM: 16.0.1
Source
https://my.f5.com/manage/s/article/K23304000

Description

A validation error occurred while syncing to a remote device

  • BIG-IP HA devices out of sync
  • Sync Failed
  • Error Message seen in TMSH command show /cm sync-status output:
  • show /cm sync-status

    --------------------------------------------------------------------------------
    CM::Sync Status
    --------------------------------------------------------------------------------
    Color    red
    Status   Sync Failed
    Mode     high-availability
    Summary  A validation error occurred while syncing to a remote device
    Details

                big-ip-1_example.com: connected
                mse_sync (Sync Failed): A validation error occurred while syncing to a remote device
                - Sync error on big-ip-1_test.com: Load failed from /Common/big-ip-2_test.com 01070100:3: Can't delete user (couldn't read from `/etc/passwd.lock': Failed to open file '/etc/passwd.lock': Permission denied) 01070100:3: Can't delete user (couldn't read from `/etc/passwd.lock': Failed to open file '/etc/passwd.lock': Permission denied)
               - Recommended action: Review the error message and determine corrective action on the device

Environment

BIG-IP HA group is set up in HA configuration.

  • At least 2 devices connected
  • On TMOS version 16.0.1
  • Configuration objects and settings.
  • Existence of file "/etc/passwd.lock".

Cause

None

Recommended Actions

  1. Run the following commands on device:
  2. cd /etc
    mv passwd.lock passwd.lock.bkup
    chmod 644 passwd

Additional Information

None
