K000135281: Attack signature learning accepted but still not accepting traffic

Type
Support Solution
Published
2023-06-28
Updated
2026-07-17
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000135281

Description

When accepting learning suggestions about an attack signature, it keeps blocking.


Environment

  • Recently updated signature
  • Signature in staging mode
  • Learning accepted

Cause

Previous version of the updated signature, which is in staging mode, keeps working until the new one goes from staging (manually or by staging period) to enforced.

Learnings were placed in the new signature and will start working once the signature is enforced.


 Recommended Actions

One of next:

  • Enforce the updated signature
  • Wait till it automatically becomes enforced

None
