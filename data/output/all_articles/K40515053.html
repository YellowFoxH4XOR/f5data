Known Issue

The IMI Shell (imish) command may fail to display log data.

This issue occurs when all of the following conditions are met:

  • You configure your BIG-IP system with dynamic routing.
  • You attempt to view dynamic route log messages using the imish command.

    For example:

    imish 'terminal monitor'

Impact

Log messages are not displayed.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When typing the imish command, you are brought to a vtysh terminal prompt and no other data is displayed.

Resolution

Status

Workaround

To work around this issue, you can configure dynamic routing to log to a file in the /var/log directory and view live log entries with the Linux tail command. To do so, perform the following procedure:

Impact of workaround:  Performing the following procedure should not have a negative impact on your system.

  1. Log in to the BIG-IP command line.
  2. To configure dynamic routing to log to a specific log file, enter the VTY Shell by typing the following command:

    vtysh

  3. To enable editing of the dynamic route configuration, type the following command:

    enable

  4. To edit the dynamic routing configuration, type the following command:

    configure terminal

  5. To set the destination log file, use the following command syntax: 

    log file /var/log/<log file name>  

    For example:

    /var/log/routing.log

  6. Save the configuration change by typing the following command:

    write

  7. To exit, type the following command:

    exit

  8. To exit the VTY Shell, type the following command:

    exit

  9. To live view log entries of the log file, use the following command syntax:

    tail -f /var/log/<log file name> 

    For example:

    tail -f /var/log/routing.log

  10. To exit the tail command, use the following key combination:

    Ctrl+C
