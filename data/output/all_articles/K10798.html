Known Issue

This is the result of a known issue. If you configure Active Directory dynamic group mapping and select the Synchronize FirePass user database with Active Directory check box, synchronization occurs every minute regardless of the value you configure in the Check interval (min) field.

Similarly, if you configure LDAP dynamic group mapping and select the Synchronize FirePass user database with LDAP check box, synchronization occurs every minute regardless of the value you configure in the Check interval (min) field.

Note: For FirePass version 6.0.3, this issue occurs after installing cumulative hotfix HF-603-5 or later versions of the cumulative hotfix.

F5 Product Development tracked this issue as CR132103 and it was fixed in FirePass 7.0.0. For information about upgrading, refer to the FirePass release notes.

Additionally, Cumulative HF-610-1 has been issued for FirePass version 6.1.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software and firmware from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.
