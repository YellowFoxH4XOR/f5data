Description

You may encounter a "General database error retrieving information" message when performing certain tasks in the BIG-IP Configuration utility.

Environment

Configuration utility (GUI) error when navigating.

Cause

This article includes explanations for different reasons for this error, including but not limited to:

  • Browser-related issues
  • Data-related inconsistencies (e.g., counter overflows, misconfigured objects)
  • Platform memory constraints
  • Permission issues

Recommended Actions

Before anything else
Begin with K000092894: Troubleshooting slow loading GUI , which addresses common GUI performance and error issues. If the issue persists, identify the specific location or activity where the error appears and follow the appropriate article below.

Note: Proceed with the above article first. If it does not help, scroll down to see if you can find your specific use case.
