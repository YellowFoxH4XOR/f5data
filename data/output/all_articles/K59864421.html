K59864421: APM VPN solution not routing properly

Type
Support Solution
Published
2019-09-30
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 13.1.0
Source
https://my.f5.com/manage/s/article/K59864421

Description

  • Traffic to client's assigned lease IP address from the local network, is not routed as expected.
  • Intermittent connectivity to connected vpn client.

Environment

  • BIG-IP APM
  • Version 13.1.0
  • Network Access configured with SNAT disabled for VOIP
    Note: This is not limited to VOIP traffic as all traffic to the lease IP can be affected.

Cause

This is the result of the following known issue being tracked as Bug ID 725545: Ephemeral listener might not be set up correctly

Recommended Actions

Upgrade, this known issue is fixed in version 13.1.1.2
