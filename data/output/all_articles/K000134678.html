Description

Getting "Error trying to access the database" when selecting the address Space option in APM Network access profile. 

Environment

  • APM
  • restjavad daemon

Cause

Sometimes the restjavad daemon can hang,  restarting it usually resolves the problem.

Recommended Actions

Enter the below command in bash mode to restart the restjavad daemon:

bigstart restart restjavad

None
