K12394: The ARX Secure Agent software is no longer bundled with the ARX software

Type
Knowledge
Published
2010-12-02
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • ARX: 5.2.2, 5.2.0, 5.3.1
Source
https://my.f5.com/manage/s/article/K12394

Topic

Beginning with ARX 5.2.0, the ARX Secure Agent software is no longer bundled within the ARX software. The ARX Secure Agent software must now be downloaded from the F5 Downloads site.

For information about downloading software from the F5 downloads site, refer to K167: Downloading software from F5.

For information about the ARX Secure Agent software, refer to K10026: Overview of the ARX Secure Agent software.

For information about obtaining the ARX Secure Agent software from an ARX version previous to 5.2.0, refer to K8784: Obtaining the ARX Secure Agent software.

For information about displaying the ARX Secure Agent software version, refer to K11713: Displaying the software version for the ARX Secure Agent.

For information about displaying the ARX software version, refer to K8757: Displaying the software version for the ARX system.
