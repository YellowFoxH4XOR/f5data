Description

Virtual servers are up and available after a network issue, but services are not reachable and ping fails to virtual address.

Environment

  • Virtual server
  • Failover

Cause

ARP table on upstream device has not been updated.

Recommended Actions

Review the ARP table in the upstream device to determine if ARP entries point to the previously active BIG-IP device.

If the ARP entries still point to the previously active device, clear the ARP table, and force the BIG-IP to resend GARP advertisements. Refer to the following article for more information:

  • K19910045: Forcing the BIG-IP system to resend GARP advertisements

To prevent future occurrences of this issue, consider implementing MAC masquerade, or use the arp.gratuitousrate and arp.gratuitousburst database variables.

  • K13502: Configuring MAC masquerade
  • K11985: Overview of the arp.gratuitousrate and arp.gratuitousburst database variables

Additional Information

There are various underlying reasons why an upstream ARP table may not be updated. The most common cause is a large amount of gratuitous ARP overloading the switch in the event of a failover.
