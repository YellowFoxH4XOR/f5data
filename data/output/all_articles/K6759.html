Known Issue

This is the result of a known issue. When attempting to add a Server (SRV) resource record with an integer in the Priority field, the following error message is returned:

Invalid priority '3' in 'SRV' record.

F5 Product Development tracked this issue as CR70030 and CR70051 and it is fixed in BIG-IP GTM 9.2.5, 9.3, and 9.4. For information about upgrading, refer to the BIG-IP GTM Release Notes.
