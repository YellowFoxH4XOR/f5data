Known Issue

The BIG-IP ASM Configuration utility may become slow and unresponsive when attempting to list active policies.

This issue occurs when all of the following conditions are met:

  • You have a very large number of virtual servers associated with ASM policies.
  • You navigate to Navigating to Security > Application Security > Security Policies.

Impact

The BIG-IP Configuration utility may become slow and unresponsive.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The requested page in the Configuration utility takes several minutes to render.
  • The asm_config_server.pl process is taking a large amount of CPU time.
