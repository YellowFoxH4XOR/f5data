K000149273: Can not install Edge Client when "Dialup Entry/ Windows Logon Integration" is not selected to make the installation exe.

Type
Support Solution
Published
2025-01-13
Updated
2025-01-13
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149273

Description

EdgeClient can not be installed when the exe file is created without selecting "Dialup Entry/ Windows Logon Integration"

Edge Client installation failed due to missing CustomDialer.ini under F5 VPN directory, or automatically revert the installation.


Environment

  • BIG-IP v17.1.1.4
  • apmclients v7247.2024.506.1332-6417.0
  • EdgeClient
  • installation


Cause

  • Unnoticed bug


Recommended Actions

  • The issue is fixed in later versions.
  • Please download the latest APM Client from our Download site and upgrade.


Additional Information

  • K23159056: Upgrade the BIG-IP Edge Client | BIG-IP update and upgrade guide
