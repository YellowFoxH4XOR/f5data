Topic

The default BIOS version on P100 (Puma 1) blades does not support the relocatable kernel implemented beginning in BIG-IP version 10.1.0. If you attempt to install BIG-IP version 10.1.0 or higher on a VIPRION platform that has P100 (Puma I) blades installed, the installer will close without installing the software and produce one of the following warning messages:

System uses lx-bios, but full revision information is not available <buildID>. See SOL#10633

Selected product is not compatible with system BIOS <buildID>. See SOL#10633

Note: For more information about displaying the BIOS version for your BIG-IP system, refer to K7119: Displaying BIOS version information for BIG-IP systems.

If you encounter this error message, you must update the system BIOS prior to upgrading. To do so, perform the following procedure:

  1. From an Internet connected workstation, browse to downloads.f5.com/esd/index.jsp.
  2. Click on the Platform link next to the Hardware-Specific F5 Product Family.
  3. Select VIPRION from the drop-down menu.
  4. Click bios.
  5. Download the fwmgr_bios-predator-10.1.0.3341.0.i686.im installation package. 
  6. Upload the downloaded installation package to the /shared/images directory of the primary blade.
  7. Log in to the VIPRION command line on the primary blade.
  8. Install the update by typing the following command:

    im /shared/images/fwmgr_bios-predator-10.1.0.3341.0.i686.im
  9. Reboot the blade.

    Important: Boot time will be longer than usual. Do not reset the blade before the boot is complete.
  10. Repeat steps 7 through 9 for each blade.

Important: If you are installing new blades running a software version prior to 10.1.0 in a VIPRION cluster whose member blades are running version 10.1.0 or later, you must instead perform the BIOS update on the newly added blade(s) as described in the workaround section of K11843: After installing an additional VIPRION blade, the new blade may reboot continuously.
