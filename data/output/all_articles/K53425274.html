Description
While configuring or loading a configuration that makes usage of a Mobile Device Management [MDM] object for Microsoft Intune, you are prompted with an error message, like this one:

01070734:3: Configuration error: Managed Endpoint Notification agent validation error: /Common/Example_act_managed_endpoint_notification_ag: Endpoint Management System object of Microsoft Intune type is not supported

Environment

  • You're using BIGIP APM;
  • You have configured an Endpoint Management System object for Microsoft Intune;
  • You're using - or you're trying to use - the agent "Managed Endpoint Notification" in the APM AccessPolicy.

Cause

The Intune endpoint management system does not support Endpoint Notification agent

Recommended Actions

F5 Support recommends to remove the agent "Managed Endpoint Notification" from the VPE/AccessPolicy.

Additional Information
Manual Chapter : Configuring Access Policy Manager for MDM applications
