Description

After activating a new time-limited add-on key (example: IPI, Threat Campaign etc), the subscription end date is wrong.

For Example:

After activating a new IPI add-on key (F5-SBS-BIGVE-IPI43YR | BIG-IP SUBSCRIPTION: IP INTELLIGENCE LICENSE 3YR) on 20210101, the subscription expiration date shows as 20220101 instead of 20240101. 
 

Environment

  • Time-limited module
  • Subscription
  • New add-on

Cause

F5 Licensing server issue

Recommended Actions

  1. Contact F5 Technical Support
  2. F5 Technical Support team will work and notify customer once the issue is resolved.
  3. License must be reactivated only after the issue on licensing server fixed. 

Additional Information

None
