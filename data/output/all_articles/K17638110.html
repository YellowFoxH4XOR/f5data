Known Issue

Application security policy JSON parameters may not be enforced.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM application security policy is configured with the JSON content profile.
  • Parameters are associated with the JSON profile.
  • The JSON profile is deleted manually or by the Policy Builder feature.

Impact

The BIG-IP system fails to enforce JSON parameters that are associated with the application security policy.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/bd.log file, you observe messages similar to the following example:

    ----------------------------------------------------------------------
    BD_XML|NOTICE|<date><time>|2685|xml_validation.cpp:1309|get from F5XMLProfilesTable obj 0 not found
    ----------------------------------------------------------------------
  • When viewing the application security policy association, the parameters of the deleted JSON profile appear to be associated with an existing profile (if configured).

Workaround

To work around this issue, you can modify the orphaned parameters to be activated as User-Input parameters. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected system.
  2. Enter the MySQL administrative shell by typing the following command:

    mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw`

    When accessing the MySQL administrative shell, the system displays a message similar to the following example:

    Welcome to the MySQL monitor. Commands end with ; or \g.
    Your MySQL connection id is 46
    Server version: 5.1.52-enterprise-commercial-advanced-log Source distribution

    Copyright (c) 2000, 2010, Oracle and/or its affiliates. All rights reserved.
    This is commercial software, and use of this software is governed
    by your applicable license agreement with MySQL

    Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.
     
  3. Set the MySQL database to apm by typing the following command:

    use PLC;
  4. Enter the following stanza into the MySQL shell, and then press the Return key:

    UPDATE PL_PARAM_ATTRIBUTES param
    LEFT JOIN PL_PARAM_CONTENT_PROFILES param_cont
    ON param.id = param_cont.param_attrib_id
    SET key_input_type = 4,
    key_ui_type = 32,
    flg_check_param_value_metachar = 1
    WHERE key_input_type = 64
    AND param_cont.param_attrib_id IS NULL;

    When the command action is complete, the system displays MySQL output similar to the following example:

    Query OK, 2 rows affected (0.01 sec)
    Rows matched: 2 Changed: 2 Warnings: 0
  5. To exit the MySQL administrative shell, type the following command:

    quit
