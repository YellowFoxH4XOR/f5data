Known Issue

The BIG-IP system may display incorrect version information following a hotfix installation.

This issue occurs when the following condition is met:

  • You install version 10.2.4 HF9 or HF10 on the BIG-IP 8400 or 8800 platforms.

The 10.2.4.HF9 and HF10 install script writes the boot loader version information to the incorrect drive.

Impact

The system will display incorrect software version information.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Affected systems will display the incorrect software version. The version of software installed previous to 10.2.4 HF9 or HF10 will be displayed.
