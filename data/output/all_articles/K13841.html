Known Issue

The BIG-IP system may incorrectly remove all trusted device SSL certificates with matching subject fields. This issue occurs when all of the following conditions are met:

  • The BIG-IP system has multiple trusted device certificates with matching subject fields.
  • One of the certificates with matching subject fields is removed from the Configuration utility.

Typically, when a certificate is renewed or exchanged multiple times between BIG-IP systems using bigip_add or big3d_install, the certificate is appended to the system certificate bundle. As a result, the BIG-IP system may contain multiple/duplicate certificates with matching subject fields.

Impact

iQuery connections fail as a result of the incorrect removal of a valid SSL certificate.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • iQuery connections between BIG-IP systems fail and the system logs an error message that appears similar to the following example to the /var/log/gtm file:

    SSL error:14090086:SSL routines:SSL3_GET_SERVER_CERTIFICATE:certificate verify failed

  • The affected trusted device SSL certificate is missing from the trusted server certificates page in the Configuration utility.

Workaround

To recover the removed trusted device certificate on the BIG-IP system, you can run the bigip_add utility on the local BIG-IP system. To do so, perform the following procedure:

Impact of workaround: None.

  1. Log in to the command line of the BIG-IP system that is missing the trusted device certificate.
  2. Re-add the removed trusted device certificate by entering the following command:

    bigip_add <IP address of the remote BIG-IP system that has the trusted device certificate>

  3. When prompted, enter the root password of the remote BIG-IP system.
