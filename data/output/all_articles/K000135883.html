Description

How to list and export iRules for review.

 

Environment

iRules

 

Cause

N/A

Recommended Actions

Use the 'tmsh list' command from the CLI and export the output to a txt file or print them on screen.

 

To see them on the screen:

# tmsh list ltm rule all-properties

 

To export them to a txt file.

# tmsh list ltm rule all-properties > /var/tmp/iRules.txt

 

Another option would be to copy the iRules directly out of the bigip.conf file and paste them into a text editor for review. Similar steps could be followed to review and export other configuration objects such as virtual servers, pools, etc.
