Known Issue

The ARX Manager GUI's Tiered Storage wizard may not display available shares for selection.

This issue occurs when all of the following conditions are met:

  • The shares are members of a share-farm.
  • The share-farm is deleted.

Impact

You are not able to select an available share using the ARX Manager GUI's Tiered Storage wizard.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If a share was a member of a share-farm that has been deleted, the share will not appear for selection in the ARX Manager GUI's Tiered Storage wizard.

Workaround

To work around this issue, you can configure tiered storage from the command line. For information about configuring tiered storage, refer to the Migrating Filesets and Tiering section of the ARX CLI Storage-Management Guide.

Impact of workaround: None
