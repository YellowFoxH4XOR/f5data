Issue

Error Message

01010250:3: Pool member <IP>:<port> exceeded configured rate limit.

In this error message, note the following:

  • <IP> is the IP address of the pool member.
  • <port> is the port number of the pool member.

For example:

01010250:3: Pool member 10.10.10.10:80 exceeded configured rate limit.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when all of the following conditions are met:

  • You configure the connection rate limit for a pool member.
  • The number of new connections per second to the pool member exceeds the configured connection rate limit for the pool member.

Impact

The BIG-IP system limits connections per second to the pool member and redirects additional connection requests.

Recommended Actions

Messages that reference the same pool member may indicate that the pool member is a target or is receiving an increased traffic load. If the messages reference all pool members for a pool, the virtual server may be experiencing a high traffic load or a denial-of-service (DoS) attack. The connection rate limit for a pool member may need to be adjusted to a value that is appropriate for your environment. To do so, perform the following procedure:

Impact of procedure: The following procedure modifies the allowed number of connections per second to the pool member, which may affect resources. You should test to determine an appropriate connection rate limit value for your environment.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Pools.
  3. Select the affected pool.
  4. Click Members.
  5. Select the affected pool member.
  6. For the Connection Rate Limit setting, enter an appropriate value.
  7. Click Update.
