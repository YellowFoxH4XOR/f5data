K000149881: Installation image stuck on PENDING

Type
Support Solution
Published
2025-02-20
Updated
2025-04-09
Source
https://my.f5.com/manage/s/article/K000149881

Description

Installing a new image to a specific boot location. Occasionally, the installation process may get stuck in a "PENDING" state, show no progress, or fail to proceed entirely

 

Environment

  • An image upgrade or installation process is being performed on the device

Cause

Installation process stuck

 

Recommended Actions

Verify the installation status: Use the command "tmsh show sys software" to check the status of the installation process. If the state is stuck in PENDING or no progress is shown, take the next steps.

  1. Delete and clear the affected boot location: If the image remains in the PENDING state and does not proceed, delete the target boot location.
  2. Reboot the device to reset the system state if needed: In some cases, deleting the boot location may leave the system unable to reattempt the installation. Reboot the device to establish a clean system state. Upon reboot, the previously problematic boot location should appear empty and ready for use.
  3. Retry the installation: After the reboot, confirm the target boot location is empty and retry the installation of the desired software image.
