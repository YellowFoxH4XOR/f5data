Known Issue

This is the result of a known issue. If you select Japanese as your language when logging on to the FirePass Administrative Console, and then update a setting for the RADIUS dynamic group mapping method, RADIUS dynamic group mapping fails. This issue occurs because the RADIUS shared secret previously configured is lost when the RADIUS mapping method is updated. 

Note: This issue only occurs when you select Japanese from the language drop-down menu on the FirePass Administrative Console logon page.

F5 Product Development tracked this issue as CR119156 and it was fixed in FirePass 6.1.0. For information about upgrading, refer to the FirePass release notes.
Additionally, this issue has been fixed in cumulative hotfix HF-602-10, which has been issued for FirePass version 6.0.2. You may download these hotfixes or later versions of the cumulative hotfixes from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by re-entering the RADIUS shared secret in the Shared Secret and Confirm Shared Secret fields when updating the RADIUS mapping method.
Alternately, you can work around this issue by selecting a different language such as English on the FirePass Administrative Console logon page.
