Description

Standby device on HA pair continuously logs the following error messages on /var/log/ltm

Jan 21 03:36:04 slot2/bigip.local err tmm7[21482]: 01850008:3: MR: Received HA message targeting missing transport-config
Jan 21 03:36:07 slot2/bigip.local err tmm5[21482]: 01850008:3: MR: Received HA message targeting missing transport-config

Jan 21 03:36:29 slot2/bigip.local err tmm5[21482]: 01850008:3: MR: Received HA message targeting missing transport-config

Environment

  • LTM
  • HA pair
  • Mirroring enabled
  • Diameter/SIP

Cause

Seen behavior is caused by a known issue tracked with the Bug ID 989753

Recommended Actions

Upgrade to a software version where Bug 989753 is fixed.
