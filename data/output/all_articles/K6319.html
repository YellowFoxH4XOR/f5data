Topic

This article applies to BIG-IP 9.x through 10.x. For information about other versions, refer to the following articles:

  • K36322151: List of disabled Tcl commands for iRules (12.x)
  • K15909: List of disabled Tcl commands for iRules (11.x)

The iRules feature of the BIG-IP system uses the industry-standard Tool Command Language (Tcl), version 8.4.6, to create scripts for managing local network traffic. However, there is a subset of Tcl commands that is disabled on the BIG-IP system. Therefore, you should avoid using these commands when writing iRules.

Description

The following list includes Tcl commands that are disabled in BIG-IP 10.x:

  • auto_execok
  • auto_import
  • auto_load
  • auto_mkindex
  • auto_mkindex_old
  • auto_qualify
  • auto_reset
  • bgerror
