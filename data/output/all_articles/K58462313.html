K58462313: Kerberos Single Sign On (SSO) is not accepting domain\username logins

Type
Support Solution
Published
2019-11-21
Updated
2026-09-25
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP APM: 15.0.0, 14.1.0
Source
https://my.f5.com/manage/s/article/K58462313

Description

After upgrading from 13.x to 14.1.0, Kerberos SSO fails when user attempts to log in with NETBIOS domain name.

  • The following error message is seen in /var/log/apm 
    Kerberos: can't get S4U2Self ticket for user <user@domain> - Wrong principal in request (-1765328240)
     
  • SPN format was accepted without errors

Environment

  • Kerberos SSO deployment
  • You are logging in using domain\username

Cause

This is caused by known issue ID821037
 

Recommended Actions

Add variable assign agent in VPE with your full domain name 
session.logon.last.domain = expr {"domain.name"}
