Description

Error "The requested file was not found on the server" is dumped after APM SAML SP receives a right SAML auth response from SAML IdP

Environment

  • BIGIP provisioned with APM
  • APM deployed as SAML SP
  • There is an irule or policy that sends a redirect to the client once BIGIP receives the SAML auth response from SAML IdP.

Cause

BIGIP receives the SAML auth response with url "/saml/sp/profile/post/acs" but this request is not sent up to the access filter due to a policy or irule like this

 

when HTTP_REQUEST {
  if { [HTTP::uri] eq "/saml/sp/profile/post/acs"} {
    HTTP::redirect "/webpage/"

 

Client sends that GET /webpage/ request to BIGIP that responses with a "404 Not Found" because access is still waiting for the SAML auth response.

Recommended Actions

The right way to redirect clients to a web page once SAML succeeds is using SAML 'RelayState'
