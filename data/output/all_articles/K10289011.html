Description

As part of the root password recovery procedure, special settings need to be configured in the Grub menu in order
to boot the device in single user mode.

The system is started with the modified options using the keyboard sequence "CTRL-X" (or the f10 key)
However, the f10 key is not available and the CTRL-X keyboard sequence closes the connection to the BIG-IP.

Environment

  • Grub version 0.97
  • BIG-IP 14.0.x and later
  • Using a Terminal Server to remotely connect to the console
  • The f10 key is not available
  • Not able to have a local console connection bypassing the Terminal Server

Cause

The keyboard sequence CTRL-X is used by the Terminal server to close the connection

Recommended Actions

  1. Configure the terminal Server with a different keyboard sequence to exit (close) the connection, for example CTRL-B
    As an example to configure a different key sequence  for the Avocent® ACS6000 Terminal server, use  
    ts_menu -e ^B
