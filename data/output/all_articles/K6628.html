Known Issue

This is the result of a known issue. The BIG-IP management interface does not honor media setting changes on the management port when the auto-negotiate media setting is enabled. Therefore, you cannot change the media type for the port to a value already arrived at by auto negotiation—the auto-negotiate setting will remain enabled on the port.

For example, if the management port has auto negotiated to 100baseTX full, and you use the bigpipe command to change the media type from auto-negotiate to 100baseTX full, the port will remain set to auto-negotiate.

F5 Product Development tracked this issue as CR67331 and CR69151, and it was fixed in BIG-IP version 9.2.4. For information about upgrading, refer to the LTM, GTM, ASM, or Link Controller release notes.
