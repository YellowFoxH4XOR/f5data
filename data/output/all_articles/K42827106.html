Issue

Error Message

Error Message: 011e0001:4: Limiting unreachable response from 501 to 500 packets/sec for <Traffic Group>

In this error message, note the following:

  • <Traffic Group> is the partition and traffic group against which the message was logged.

For example:

011e0001:4: Limiting unreachable response from 501 to 500 packets/sec for traffic-group /Common/traffic-group-1

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This error message occurs when the number of non-SYN packets without an established connection received by the BIG-IP system exceeds the 500-packets-per-second limit and any of the following conditions are met:

  • A tunnel configured on the BIG-IP becomes unavailable.
  • A Stream Control Transmission Protocol (SCTP) connection becomes unavailable.
  • A route or lasthop becomes unavailable.
  • BIG-IP AFM blocks or rejects a large number of unmatched packets.
  • Maintenance mode is enabled.
  • A configured connection limit is reached.
  • The Action on Service Down setting is enabled for a pool member.

Impact

The BIG-IP system sends a TCP reset (RST) packet to the unmatched packets.

Recommended Actions

If unmatched packets being reset are not affecting services configured on the BIG-IP system, you can set the tm.rejectunmatched database variable to false. This results in the system silently dropping the unmatched packets and suppress the log messages. To set the database variable to false, perform the following procedure:

Impact of procedure: Performing this procedure should not have a negative impact on your system.

  1. Log in to the TMOS Shell (tmsh). 
  2. Set the tm.rejectunmatched database variable to false by typing the following command: 

    modify sys db tm.rejectunmatched value false
