K000138487: BIG-IP stops responding to snmp request.

Type
Support Solution
Published
2024-02-05
Updated
2024-02-05
Status
Final
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000138487

Description


Receiving Timeout: No Response from localhost when trying to poll BIG-IP via snmpwalk or snmpget.


# snmpwalk -v 2c -c public localhost .1.3.6.1.4.1.3375.2.1.1.2.20.13

Timeout: No Response from localhost


Environment

  • BIG-IP
  • Net-SNMP Version 5.8

Cause

  • Using wrong snmp community name
  • Allowed-addresses not configured correctly
  • More than one snmpd process running


Recommended Actions


Check snmpd version

#snmpd --version


Check snmp community names

Check allowed-address

# tmsh list sys snmp

This command will display the current snmp community names and snmp allowed-addresses


Check snmpd processes

On normal system only two snmpd processes exist, they are: 

netstat -pano |grep 161

tcp6    0   0 :::161         :::*          LISTEN   12123/snmpd     off (0.00/0/0)

udp6    0   0 :::161         :::*                12123/snmpd     off (0.00/0/0)


A system with more then two processes may look like this:

$ netstat -pano | grep 161

tcp6    0   0 :::161         :::*          LISTEN   15365/snmpd     off (0.00/0/0)

udp    0   0 0.0.0.0:161       0.0.0.0:*              14371/snmpd     off (0.00/0/0) >>>>>>>>>>>>>> this is the one causing issue

udp6    0   0 :::161         :::*                15365/snmpd     off (0.00/0/0)


$ps aux | grep snmpd

root    14371   1  0.0  0.0 163.0M  8.3M ?    S  Jan16  00:03:12.92 snmpd >>>>>>>>>>>>>> this is the one causing issue

root    15365 15600  0.0  0.0 137.4M  34.1M ?    S  21:15  00:00:00.99 /usr/sbin/snmpd -f -c /config/snmp/snmpd.conf -Lsd -LF 6 /var/log/snmpd.log -p /var/run/snmpd.pid

root    15600 12745  0.0  0.0  2.1M 436.0K ?    S  Sep23  00:00:22.24 runsv snmpd

root    16184 12745  0.0  0.0  2.1M 420.0K ?    S  Sep23  00:00:00.42 runsv nokiasnmpd


Kill extra snmpd process

Kill -9 14371
