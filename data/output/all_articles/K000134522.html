Description

F5 Qkview includes journal data files where BIG-IP processes log events. These journal files are located in /var/log/journal/. There may be instances where these journal data files need to be reviewed off box as iHealth parses these data files as unformatted plain text and journal files requires the journalctl command to properly parse them.   

Environment

F5 qkview journal data files
Access to F5 iHealth "all" Files Menu, then to sub folder /var/log/journal/<random folder name>/system journal files 

Cause

F5 iHealth parses /var/log/journal/<random folder name>/system journal files as unformatted plain text

Recommended Actions

journal files can be downloaded from uploaded Qkviews in F5 iHealth and be reviewed off box. 

To download the journal files,  login to to F5 iHealth, browse the "all" Files Menu, then to sub folder /var/log/journal/, then under the random name folder, example 8cb7b99nnf6e4208b7670fb70d097dee, locate the relevant random name system journal file. You can inspect the timestamp of the journal file and download the relevant file for your purpose.

Inspect the journal file in a secure system with the journalctl command utility. The BIG-IP does include the journalctl command. 

Example: Assume the downloaded journal file -  system-atsign-e89c6fc5779c4djkk1df6d83188a7cc6-0000000000124lwe-0005fb1df6933252.journal - is placed in /var/log/journal/ with the sample folder 8cb7b99nnf6e4208b7670fb70d097dee. 

You can use the journalctl --file <full file path of journal data file> to parse its contents.

Example: 
journalctl --file /var/log/journal/8cb7b99nnf6e4208b7670fb70d097dee/system-atsign-e89c6fc5779c4djkk1df6d83188a7cc6-0000000000124lwe-0005fb1df6933252.journal

     --file=PATH           Show journal file

journalctl --file /var/log/journal/8cb7b99nnf6e4208b7670fb70d097dee/system-atsign-e89c6fc5779c4djkk1df6d83188a7cc6-0000000000124lwe-0005fb1df6933252.journal | head
