Known Issue

BIG-IP Edge Client may display multiple security warnings while restoring an access session.

This issue occurs when all of the following conditions are met:

  • Your local device accesses the network through a captive portal.
  • When establishing an access session you are prompted to accept the BIG-IP APM Secure Sockets Layer (SSL) certificate.
  • Your local device experiences a network connection failure or is placed in hibernation.
  • Your local device restores network connectivity or is woken from hibernation.

Impact

BIG-IP Edge Client displays multiple security warnings when attempting to re-establish the access session.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When BIG-IP Edge Client attempts to re-establish the access session, you observe security warnings similar to the following example:

    Unable to verify SSL Certificate presented by the server

  • After you accept all the security warnings, BIG-IP Edge Client restores the access session.
