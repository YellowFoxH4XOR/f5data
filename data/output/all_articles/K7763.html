Known Issue

This is the result of a known issue. The bigpipe interface <interfacename>.<port> disable command does not disable non-combination small form-factor pluggable (SFP) ports on the following platforms:

  • 1500
  • 3400
  • 6400
  • 6800

Note: Combination SFP ports are ports that contain a combination, such as Gigabit Ethernet port and Fibre Channel port.

When the bigpipe interface <interfacename>.<port> disable command is issued, the switch will still report the port as up and both receiver and transmitter LEDs will be on.

This behavior does not have any adverse affects on traffic or the platform itself. It just prevents an administrator from marking the non-combination SFP ports as down.

F5 Product Development tracked this issue as CR79052 and it was fixed in BIG-IP versions 9.3.1 and 9.4.2. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM, Link Controller, or WebAccelerator release notes.
