Description

BIG-IP APM Network Access "Client Proxy Settings", has the ability to override and control the Web proxy settings (WinINET) on Windows client machines connecting using the BIG-IP Edge Client.   These controls allow the administrator to configure protection, control and filtering of outbound web traffic when the VPN tunnel is connected.  

NOTE: this service is different from Explicit / Transparent forward proxy which is related to: F5 Software Web Gateway (SWG)

Environment

  • Users on Windows 10 Computers
  • BIG-IP Edge Client is installed and configured
  • Administrators wish to control the client-side Web Proxy function.

Cause

None

Recommended Actions

None

Additional Information

BIG-IP APM can be configured using a static entry, OR by the use of a Proxy Auto-config file (PAC file).   A PAC file contains a set of rules coded in javascript that tell a web browser how to route outbound web traffic; either to the destination, or to a proxy server.   PAC files can control both HTTP, HTTPS, and FTP from a browser.  On a Client Windows PC, the proxy or PAC file can be set manually thru a Group policy object setting or it can be automatically detected by the Windows Web Proxy Auto-Detection (WPAD) function.

The BIG-IP Edge Client and associated helper apps can merge and rewrite multiple PAC files (Local PAC files, Edge Client configured PAC Files, etc) into a merged file stored on the local machine during a VPN session.  BIG-IP APM configuration objects can control how or whether various files are merged, or prepended.  This provides the APM administrator flexibility to control and manage the local Proxy on a client machine.   The administrator must be aware of local conditions, and configure the PAC file to address those entries accordingly. 
 

What is a PAC file?

A Proxy Auto-Configuration (PAC) file contains a set of rules coded in JavaScript which allows a web browser to determine whether to send web traffic direct to the Internet or be sent via a proxy server.  PAC files can control how a web browser handles HTTP and HTTPS traffic.

A PAC file can have rules which leverage the following information to route traffic:

  • IP address of the requested website
  • Host of the requested website
  • The user IP address*
  • The date/time

Additionally, a PAC file can route:

  • HTTP, HTTPS, and FTP traffic in a web browser
  • Route traffic either direct or via proxy (by configuring hostname and port)

What is a Proxy Auto-Configuration script:

Here is an example of a basic PAC file script:

function FindProxyForURL(url, host) {
 // If the hostname matches, send direct to the destination.
     if (dnsDomainIs(host, "f5.com") ||
         shExpMatch(host, "(*.example.com|example.ca)"))
         return "DIRECT";
   
 // All other traffic forwards to the upstream web/forward proxy server
     return "PROXY myproxy.domain.com:8080";
 }

In this example, find the HTTP host the user typed; if the host is f5.com or it contains *.example.com or example.ca,  do not proxy these two hosts.   For all other traffic,  send the traffic to "myproxy.domain.com on port 8080"

NOTE:  For more advanced examples refer to:   (External) http://findproxyforurl.com/example-pac-file/
