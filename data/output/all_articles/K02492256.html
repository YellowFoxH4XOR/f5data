Description

You want to list:

  • Client IP addresses that are using a specific SNAT IP address.
  • Ports that are using a specific SNAT IP address.

Environment

  • BIG-IP
  • Using SNAT

Cause

None

Recommended Actions

Log in to the BIG-IP Advanced Shell (bash) for the following recommended actions.

The following command returns client IP addresses and ports that are using a specific SNAT IP address:

tmsh show /sys connection ss-client-addr <SNAT IP address>


For example:

      tmsh show sys connection ss-client-addr 10.1.20.128
      Sys::Connections
      10.1.10.170:50258  10.1.10.128:80  10.1.20.128:50258  10.1.20.161:80  tcp  39  (tmm: 2)  none
      Total records returned: 1

To view multiple SNAT addresses from SNAT pools and SNAT objects by automatically adding them to a for loop, run the following one-liner:
for i in $(tmsh list ltm snat-translation | grep -oE 'address [0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}' | awk '{print $2}'); do tmsh show /sys connection ss-client-addr $i; done 

To view multiple SNAT addresses and manually add them to a for loop, use the following one-liner syntax:
for i in <address> <address> [address]; do tmsh show /sys connection ss-client-addr $i; done 

This example shows a for loop with 3 addresses:

for i in 10.89.197.10 10.89.205.11 10.89.205.12; do tmsh show /sys connection ss-client-addr $i; done 

Additional Information

The following command returns the number of connections that are using the a specific SNAT IP address, but it does not list client IP addresses or ports:

tmsh show /ltm snat-translation <SNAT IP address>
