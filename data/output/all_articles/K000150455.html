Description

You would like to remove the old license which was pushed from BIG IQ to BIG IP, but you don't have administrative access to BIG IQ anymore.

 

Environment

  • BIG IQ
  • BIG IP 
  • Licensing

Cause

None

 Recommended Actions 

 

Important: That procedure will move your license to inoperative mode, if you are unsure with the below steps, please raise a ticket to F5 Support.

 

You have to manually replace the license file, that will allows you to assign new license with the key:

1. mv bigip.license bipip.license.backup - That will move bigip license to backup file, and cause that BIG IP will need new license
2. tmsh load sys config verify
3. tmsh load sys config
4. bigstart restart

In need of rollback the changes you have to repeat the above steps with only one small modification, in first step you have to change the order of the file names:

mv bipip.license.backup bigip.license
