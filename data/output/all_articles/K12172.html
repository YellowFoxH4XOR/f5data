K12172: HTTP '503 Service Unavailable' responses generated by the BIG-IP WebAccelerator system may include an invalid HTTP status code

Known Issue

This is the result of a known issue. In rare instances when the BIG-IP WebAccelerator system generates an HTTP 503 Service Unavailable response, the system may send an invalid HTTP status code of 5 to the client instead of the 503 status code.

Note: For more information about HTTP status codes, refer to RFC2616.

F5 Product Development tracked this issue as ID 225916 (formerly CR140431), ID 324339 (formerly CR140431-1), and ID 328320 (formerly CR140431-2) and it was fixed in BIG-IP WebAccelerator versions 10.2.2 and 11.0.0. For information about upgrading, refer to the BIG-IP WebAccelerator Release Notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.2.0-1755.1-HF1 for BIG-IP version 10.2.0 and in HotFix-BIGIP-10.1.0-3402.0-HF2 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.
