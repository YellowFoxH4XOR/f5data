Description

On a multi-bladed Viprion system, you are deleting old and unused ISO images in /shared/images/ folder but keep on coming back after a while. 
  • Files are successfully deleted using the command rm -rf <image.iso> without any error
 

Environment

  • BIG-IP
  • Viprion with multi-blade
  • ISO Images files
 

Cause

On VIPRION systems, the csyncd process replicates ISO Image files among cluster members.
 

Recommended Actions

Instead of using the rm -rf command, use the command below:
    tmsh delete /sys software <image|hotfix> <image.iso>

For example:
    tmsh delete /sys software image BIGIP-15.1.0.4-0.0.6.iso
    tmsh delete /sys software hotfix Hotfix-BIGIP-14.1.4.3.0.81.8-ENG.iso


Additional Information

To view the list of software images currently in your system and to see which are currently in use on HD volume.
    tmsh list /sys software
