K39377009: ASM Event Correlation Graph is Empty

Type
Support Solution
Published
2022-03-17
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM: 13.X.X, 13.0.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.X, 13.0.1, 13.0.0, 13.1.0
Source
https://my.f5.com/manage/s/article/K39377009

Description

ASM Event Correlation is empty even though the event logs should have triggered such events.

  • event logs are generated and recorded as expected
  • no ASM Event Correlation incidents generated
  • Event Correlation 'Incident Types Volume Graph' is empty

Environment

  • BIG-IP ASM
  • Event logs
  • ASM Event Correlation

Cause

The cause is not determined at the publication of this article. It might be caused by a desync from the correlation daemon.

Recommended Actions

Please run below command to workaround this issue.
Impact of Procedures: Restarting ASM service will cause service outage and lead to HA failover, so we recommend customer doing so in maintenance window.

tmsh restart sys service asm

Additional Information

None
