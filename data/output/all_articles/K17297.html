Known Issue

Under rare conditions, the Traffic Management Microkernel (TMM) process may produce a core file and restart upon failover, with the Assertion 'laddr is not NULL' error message.

Impact

The TMM process produces a core file and restarts.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • In the /var/log/tmm file, you observe error messages that appear similar to the following example:

    notice panic: ../base/listener.c:1157: Assertion "laddr is not NULL" failed.

  • In the /shared/core directory, you observe TMM core files that appear similar to the following example:

    -rw-r--r-- 1 root root 162559296 tmm.0.bld608.15.core.gz
