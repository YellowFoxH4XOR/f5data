Issue

In BIG-IP versions prior to 10.1.0, tmsh used both the set and modify commands in conjunction with the cli admin-partitions and cli preference components. Starting in BIG-IP version 10.1.0, tmsh only uses the modify command in conjunction with these components. This change was implemented to simplify administration. Commands that previously required the set command now require the modify command.

For example:

set cli admin-partitions update-partition db1

The BIG-IP version 10.0.0 command in the previous example now requires the following syntax in BIG-IP versions 10.1.0 and later:

modify cli admin-partitions update-partition db1

If you attempt to use the set command in conjunction with the cli admin-partitions or cli preference components in BIG-IP versions 10.1.0 or later, tmsh reports a syntax error that appears similar to the following example:

[root@bigip-1a:Active] config # create /auth partition db1
[root@bigip-1a:Active] config # set cli admin-partitions update-partition db1
Syntax Error: unexpected argument "set"
[root@bigip-1a:Active] config #

Note: For more information about the cli admin-partitions and cli preference components, refer to the Traffic Management Shell (tmsh) Reference Guide.

F5 Product Development tracked this change as ID 211910 (formerly CR128736).
