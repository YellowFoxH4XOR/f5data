Issue

Error Message

011b0600:3: Error '<reason>' during rrd_update for rrd file '<filename>'

In this error message, note the following:

  • <reason> is reason the Round Robin Database (RRD) database update failed.
  • <filename> is the name of the file containing data that failed to update.

For example:

011b0600:3: Error 'opening '/var/rrd/blade0cpu': No such file or directory' during rrd_update for rrd file '/var/rrd/blade0cpu'

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions are met:

  • An RRD info file is not valid or has become corrupted. 

Impact

Invalid info files prevent the system from presenting certain performance-related statistics accurately when you use the Configuration utility. 

Recommended Actions

To work around this issue, you can remove the invalid information and corresponding data files and restart the statsd process. To do so, perform the following procedure:

Impact of procedure: Some historical data may be missing from the BIG-IP system's performance graphs.

  1. Log in to the affected BIG-IP system's command line.
  2. Run the following command to stop the statsd service:

    tmsh stop /sys service statsd
     
  3. To remove the invalid info files, use the following commands syntax:

    rm -f /shared/rrd.1.2/<file>
    rm -f /shared/rrd.1.2.perm

    For example:
    If the offending <file> name is blade0cpu.info , to remove the info files for named blade0cpu.info and the rrd.1.2.perm file, type the following commands:
    rm -f /shared/rrd.1.2/blade0cpu.info
    rm -f /shared/rrd.1.2.perm/blade0cpu.info
    rm -f /shared/rrd.1.2.perm
    Note: /var/rrd is a symlink to /shared/rrd.1.2.

  4. To restart the statsd process and rebuild the deleted files, type following command:

    tmsh start /sys service statsd
     
  5. Verify that the statsd service is running with the following command:

    tmsh show /sys service statsd
