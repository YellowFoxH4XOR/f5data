Issue

Error Message

013e0002:5: Tcpdump stopping on <int_receive> from <int_send>

In this error message, note the following:

  • <int_receive> is the internal receive interface that the tcpdump utility uses to capture network traffic.
  • <int_send> is the internal send interface that the tcpdump utility uses to capture network traffic.

For example:

013e0002:5: Tcpdump stopping on 127.1.1.1:2 from 127.2.2.2:45678

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The tcpdump utility stops gathering network traffic.

You may notice multiple entries in the log file from the same time period because the tcpdump utility subscribes to each Traffic Management Microkernel (TMM) to gather all network packets.

Impact

Running the tcpdump utility places additional load on the CPU. For more information about running the tcpdump utility, refer to K6546: Recommended methods and limitations for running tcpdump on a BIG-IP system.

Recommended Actions

These log messages are helpful when correlating other log events that occur while the tcpdump utility is running.
