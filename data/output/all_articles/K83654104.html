K83654104: F5 Access client not triggering on-demand VPN for certain FQDNs

Type
Support Solution
Published
2021-08-03
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • F5 Access
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K83654104

Description

F5 Access client on Mobile device IOS is not triggering On-Demand VPN list when attempting to connect to an FQDN that is resolvable externally and internally

Environment

  • MDM
  • F5 Access
  • Apple iOS
  • Mobile Safari
  • Externally Resolvable FQDN

Cause

Per the The Apple Configuration Profile Reference Manual, this is By Design:
"..specified domains should trigger a VPN connection attempt if domain name resolution fails.."

Recommended Actions

 Disable external DNS resolution for the specified FQDN
 
Additional Information

Apple Configuration Profile Reference Manual
