Description

  • Slowness when accessing the management interface on GUI and CLI
     
  • In kern.log there are warning messages on address conflict:
    warning kernel: : [1354596.899652] mgmt: received packet on eth0 with own address as source address
    warning kernel: mgmt: received packet on eth0 with own address as source address

  • With traffic capture on management interface, the conflict can be observed:

    1857    2021-06-17 21:28:08.796149    00:00:5E:00:53:01    00:00:5E:00:53:00            Who has 10.0.0.14? Tell 10.0.0.13
    2479    2021-06-17 21:28:24.407600    00:00:5E:00:53:02    00:00:5E:00:53:00            Who has 10.0.0.10? Tell 10.0.0.34

Environment

  • Big-IP VE environment
  • Two or more devices are sharing the same management interface MAC address due to manually edited MAC addresses

Cause

On a VE environment where MAC address can be set manually, and can cause MAC addresses conflicts


 Recommended Actions

  • Log in to the hypervisor and set the MAC address of the VE's interface with a unique MAC address and confirm that the conflict solved

Additional Information

  • To run traffic capture to see the MAC address conflict, run the following tcpdump command: 

tcpdump -ni eth0 -s0 -w /var/tmp/mgmt1.pcap
