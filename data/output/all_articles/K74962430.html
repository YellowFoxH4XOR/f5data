K74962430: Clientless Mode authentication issue with euro-sign in password

Type
Support Solution
Published
2022-08-11
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IP
  • BIG-IP APM: 15.1.4
Source
https://my.f5.com/manage/s/article/K74962430

Description

Users with euro-sign character '€' fail to authenticate in Clientless Mode but the same password works using browser for example.

Environment

  • BIG-IP APM
  • Clientless Mode

Cause

Euro-sign character '€' is currently not supported in passwords for Clientless Mode.
F5 Product Development has assigned ID 1115405 to this problem

Recommended Actions

Remove the euro-sign from the password.

Please see our article regarding password safety and best practices:
Password Safety & Security Best Practices: Passwords vs Passphrases
