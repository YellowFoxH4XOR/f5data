Description

You can confirm the Live Update configuration from UCS.

Environment

  • BIG-IP ASM
  • UCS
  • ASM Live Update

Cause

None.

Recommended Actions

  1. Generate UCS (K13132)
  2. Expand UCS file
  3. You can find /var/lib/hsqldb/live-update/live-update.yaml file
  4. Check "frequency" in ASM_ATTACK_SIGNATURES section.
For example,

- Installation of Automatically Downloaded Updates : Disabled
  endTime: 23:59
  frequency: NEVER
  startTime: 00:00
  type: ASM_ATTACK_SIGNATURES


- Installation of Automatically Downloaded Updates : Real Time
  endTime: 23:59
  frequency: REAL_TIME
  startTime: 00:00
  type: ASM_ATTACK_SIGNATURES


- Installation of Automatically Downloaded Updates : Scheduled
  endTime: 23:59
  frequency: SCHEDULED
  startTime: 00:00
  type: ASM_ATTACK_SIGNATURES

None.
