Description
BIG-IP GUI is unresponsive, SSH is good and client traffic is not impacted.

Restarting tomcat and httpd with bring GUI up for 15-20 seconds and will go unresponsive again. 

From the QKview, there is no outstanding issue for tomcat, like the java.lang.OutOfMemoryError.

Environment

  • BIG-IP
  • Remote syslog server(s) has been configured

Cause
It caused by the unstable connectivity of the remote syslog server(s). From the log, there are repeating messages like below:

   Sep 22 03:42:06 big-ip notice syslog-ng[25665]: Syslog connection broken; fd='59', server='AF_INET(192.168.1.100:514)', time_reopen='60'
   Sep 22 03:43:06 big-ip notice syslog-ng[25665]: Syslog connection established; fd='30', server='AF_INET(192.168.1.100:514)', local='AF_INET(0.0.0.0:0)'

Recommended Actions

  1. Remove the remote syslog server(s) temporary and restart the syslog-ng
  2. Add the remote syslog server(s) back after the connectivity is stable
