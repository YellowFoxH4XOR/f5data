K08458075: BIND configured to 'forward first' responds with SERVFAIL, if forwarder times out

Type
Support Solution
Published
2020-04-08
Updated
2025-04-02
Applies to
  • BIG-IP
  • BIG-IP GTM: 11.6.2, 11.6.1, 11.5.8, 11.5.7, 11.5.6, 11.5.5, 11.5.4, 11.5.3, 11.6.3
  • BIG-IP DNS: 12.0.X, 14.0.0, 13.1.1, 13.1.0, 13.0.1, 13.0.0, 12.1.3, 12.1.2, 12.1.1, 12.1.0, 12.0.0, 13.0.X
Source
https://my.f5.com/manage/s/article/K08458075

Description
DNS forwarding using BIND doesn't work as expected, queries fail if a configured forwarder times out.

Environment

  • BIG-IP DNS or GTM running one of the following versions:
    • 11.5.3 - 11.5.8
    • 11.6.1 - 11.6.3.4
    • 12.0.0-hf3 - 12.1.3.7
    • 13.0.0 - 13.1.1.3
    • 14.0.0 - 14.0.0.2
  • DNS profile
    • Use BIND Server on BIG-IP enabled
  • BIND configured with:
    • recursion yes
    • forward first
    • At least one forwarder, which times out
      • Any response, including a SERVFAIL, Reject, or ICMP error prevents this behavior.
  • A client attempts to resolve records which the forwarders are not authoritative for, and the forwarders do not allow recursion.

Cause
Due to a bug in BIND v9.9.8 - v9.9.11-P1 and BIND v9.10.3 - v9.10.6, BIND will retry forwarded queries until the original client query times out. This affects BIG-IP versions which use these versions of BIND. 

Recommended Actions

  1. Upgrade to a version of BIG-IP which is not affected.

Additional Information
ISC does not have a publicly-available bug record for this; it is recorded in the changelog distributed with BIND at the time of the fix.
