Description
Attempting to change the admin password fails when using the GUI (Configuration utility) or TMSH with one of the following errors

  • Configuration Utility

01070732:3: PAM error during 'pam_chauthok'=22(Authentication token lock busy)

  • TMSH

01070098:3: Can't create user (error locking file: Read-only file system)

When viewing /var/log/ltm log file for the time of the issue no related errors are logged.

Environment

  • BIG-IP Configuration utility
  • Traffic Management Shell (tmsh)

Cause
 

Recommended Actions
You can schedule the BIG-IP to execute the fsck command to address any file system errors that may be impacting access to the filesystem 

  1. Log in to the command line.
  2. To schedule the BIG-IP to execute fsck on thenext system boot, type the following command:

    touch /forcefsck

    Note. When the BIG-IP is rebooted, the /forcefsck file causes the system to perform a file system check using the fsck command
     

  3. If you want to reboot the system at this time, type the following command:

    reboot

Additional Information

K73827442: Forcing a file system check on the next system reboot (12.x - 13.x)
