Description

High CPU observed after upgrade

  • In the 'top' output - java process consume most of the CPU: 
    PID   USER      PR  NI    VIRT    RES    SHR S  %CPU %MEM     TIME+ COMMAND   P   SWAP
28461 root      38  18 1318352 224840  13436 S  240.5  0.9   1:02.76 java      3      0

Environment

  • Upgraded BIG-IP 

Cause

This is expected behaviour, as described in:
  • K52991500: datasyncd consuming a lot of CPU after upgrade
Once the datasyncd done with copying of the obfuscated scripts, the CPU will be back to a normal use.

Recommended Actions

  • The "epoch time" can be configured in the WebUI under: Security ›› Options : Background Tasks
  • If the datasyncd obfuscator is still behaving unusually after waiting 48 hours or more, open a service request with F5 Support. 

Additional Information

  • K02827102: BIG-IP ASM and BIG-IP FPS systems experience higher CPU usage for several hours per day
