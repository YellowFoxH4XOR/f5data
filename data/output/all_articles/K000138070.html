Description

BIG-IP models equipped with NITROX-III CNN35XX-NFBE do not support 4096 bit RSA keys when using old firmware version.

Environment

BIG-IP iSeries devices with NITROX-III CNN35XX-NFBE:

  • BIG-IP i5820-DF (C125)
  • BIG-IP i7820-DF (C126)
  • BIG-IP i15820-DF (C120)
  • BIG-IP 10350v-FIPS (D112)
  • F5 r5920-DF (C136)
  • F5 r10920-DF (C137)

NITROX-III CNN35XX-NFBE firmware versions older than CNN35XX-NFBE-FW-1.1-05 for example CNN35XX-NFBE-FW-1.0-39 or CNN35XX-NFBE-FW-1.0-52.

Cause

Old firmware version CNN35XX-NFBE-FW-1.0-39 or CNN35XX-NFBE-FW-1.0-52 does not support 4096 bit RSA keys.
Support for 4096 bit RSA keys has been implemented in firmware version CNN35XX-NFBE-FW-1.1-05
Support for 4096 bit RSA keys stored on NITROX-III CNN35XX-NFBE card has been implemented in BIG-IP software version 17.1.0

To be able to use 4096 bit RSA keys stored on NITROX-III CNN35XX-NFBE card you need to use BIG-IP running software version 17.1.0 or later with NITROX-III CNN35XX-NFBE firmware CNN35XX-NFBE-FW-1.1-05 or later.

Recommended Actions

  • Upgrade to the new firmware CNN35XX-NFBE-FW-1.1-05 or later.
  • Upgrade to BIG-IP version 17.1.0 or later.

New firmware for NITROX-III CNN35XX-NFBE is available with BIG-IP software version 17.1.0 or 16.1.4

To upgrade FIPS firmware follow: https://techdocs.f5.com/en-us/bigip-16-1-3/f5-platforms-fips-administration/platform-and-ve-fips-module-and-upgrade-notes.html#fw-upgrades-hw-hsm

Additional Information

Currently BIG-IP does not support RSA 3072 keys with NITROX-III FIPS card.
