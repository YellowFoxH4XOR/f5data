K000092982: iRule command SSL::enable / SSL::Disable is applied the context of the event in which it is called

Type
Support Solution
Published
2023-01-11
Updated
2023-01-11
Source
https://my.f5.com/manage/s/article/K000092982

Description

When using 'SSL::enable' or 'SSL::disable ' command in iRule it is important to pay attention to the context in which it is applied.

 

 

Environment

  • BIG-IP LTM
  • iRules SSL events

 

Cause

iRule command SSL::enable / SSL::Disable is applied the context of the event in which it is called

 

Recommended Actions

For instance., the following iRule would cause the SSL session to be reset upon matching host name.

ltm rule iRule_Hostname {

 

when HTTP_REQUEST {

log local0. "logging on"

 

if {[HTTP::host] equals "example.com"} {

SSL::disable

persist source_addr

pool Pool_example

}

}

}

 

To achieve desirable result, either configure the iRule to specify the SSL::disable command in appropriate event or specify the context along with the command.

 

when HTTP_REQUEST {

log local0. "logging on"

 

if {[HTTP::host] equals "example.com"} {

SSL::disable serverside

persist source_addr

pool Pool_example

}

}
