Known Issue

This is the result of a known issue. The switchboot utility returns an error message when it runs on version 10.x VIPRION systems. For example, when you run the switchboot -l command on a version 10.x VIPRION system, you will get an error message that appears similar to the following:

ERROR: Failed to find active image location

Note: This error message is not related to K9854: Error Message: ERROR: Failed to find active image location, as the message occurs even when there is no prior grub_open command performed.

F5 Product Development tracked this issue as CR121301 and it was fixed in BIG-IP LTM 10.1.0. For information about upgrading, refer to the BIG-IP LTM release notes.

Workaround

On BIG-IP 10.x systems, F5 recommends using the bigpipe software command to display, install and manage software on the BIG-IP system.

For example, to list the installation images on the system, use bigpipe software volume and/or bigpipe software status commands.

To switch to a desired installation location, use the bigpipe software desired HD1.x active enable command.

Note: The bigpipe software desired command applies to all slots on a VIPRION system, and automatically reboots the VIPRION system.

Note: For more information, refer to the bigpipe software help page or the Bigpipe Utility Reference Guide.
