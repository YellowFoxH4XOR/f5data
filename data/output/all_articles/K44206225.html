K44206225: Ansible jobs fail with the error "AbstractDigestAuthHandler does not support the following scheme: 'X-Auth-Token'"

Type
Support Solution
Published
2023-03-22
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K44206225

Description


After upgrade ansible jobs began to fail at a higher rate than usual due to authentication errors, even though there is no remote authentication, with the error

AbstractDigestAuthHandler does not support the following scheme: 'X-Auth-Token'

Environment

  • After upgrade
  • Ansible
  • BIG-IP LTM

Cause

 
This is due to ID 717174
 

Recommended Actions
 

Restart BIG-IP REST daemons with the following commands:
bigstart restart restjavad
bigstart restart restnoded
 

Additional Information


None
