Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator module is provisioned differently on two BIG-IP systems in a redundant pair, the BIG-IP systems may repeatedly log the following error message to the /var/log/ltm file:

warning mcpd[3306]: 01070465:4: DB changed: wam.cache.disk.status, configsync needed

This error message is benign and may safely be ignored.

F5 Networks Product Development is tracking this issue as ID 226387 (formerly CR141383).

This issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.0-1755.1-HF1, which has been issued for BIG-IP version 10.2.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.
