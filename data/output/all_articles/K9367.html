Topic

For client requests to a version 9.4.x BIG-IP WebAccelerator-enabled virtual server, if the BIG-IP WebAccelerator does not receive a response from the origin web server within the Read/Write Timeout value, the BIG-IP WebAccelerator sends the client an HTTP 503 Service Unavailable response that includes the following explanation:

An error occurred while fetching the URI.  Please retry.

Increasing the Read/Write Timeout setting

The default Read/Write Timeout value is 30 seconds with two retries.  In some cases, you may need to increase the timeout slightly to accommodate slow-responding webservers. To increase the Read/Write Timeout setting, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click WebAccelerator.
  3. Click Applications.
  4. From the Main tab, click Destination Hosts.
  5. Click the name of the BIG-IP Internal Pool.
  6. Change the Read/Write Timeout setting to a slightly higher value less than 10,800 seconds.
  7. Click Save.

Important: The Read/Write Timeout value should be set to no more than 3 hours, or 10,800 seconds. In most cases, a timeout value of several minutes should be sufficient. For information about a related known issue, refer to K10605: Configuring the Read/Write Timeout setting to more than 3 hours may result in system instability.

Note: BIG-IP WebAccelerator versions 10.0.0 and later are not affected by this issue, and the internal timeout is not configurable.
