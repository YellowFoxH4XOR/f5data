K000161062: BIG-IQ DoS Summary: High Attack Counts, Severity Mismatches, and Missing Data

Type
Support Solution
Published
2026-05-01
Updated
2026-05-01
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.4.1
Source
https://my.f5.com/manage/s/article/K000161062

Description

When using BIG-IQ to monitor BIG-IP AFM DoS events, users may observe the following issues in the DoS Summary dashboard:

  • The total number of reported attacks appears excessively high.
  • Selecting a specific virtual server causes the attack count to increase further.
  • The severity level of attacks does not match the expected values based on the attack data.
  • The number of unique Attack IDs is lower than the total number of reported attacks for a given time frame.
  • When reviewing attack details, some columns (such as source/destination IP, packet counts, or vector type) are not populated.

These symptoms can cause confusion for security operations teams and may lead to misinterpretation of the actual threat landscape.

Environment

  • Product: BIG-IP AFM, managed by BIG-IQ
  • BIG-IQ version 8.x or later
  • BIG-IP version 14.x or later
  • DoS profiles applied to virtual servers

Cause

Threshold Configuration: If DoS vector detection and mitigation thresholds are set to similar or equal values, AFM may generate numerous events with "Attack ID = 0" before an official attack is declared. These events are included in summary counts but lack full details.

This behavior is described in the article K000160729.

Answer/Recommended Actions

Review Threshold Configuration: Ensure that detection thresholds are set lower than mitigation thresholds for each DoS vector. This helps ensure attacks are properly detected and assigned unique Attack IDs before mitigation occurs.

Use Network Analysis Dashboard: For accurate attack information, use the BIG-IQ DDoS Dashboard → Network Analysis view, which provides more granular and reliable data than the DoS Summary.

Additional Information

  • Events with "Attack ID = 0" and missing columns are expected when mitigation occurs before detection or when data is aggregated.
  • Source IP may show as N/A if AFM mitigates attacks at the hardware level or due to threshold configuration.
  • Some reporting features are legacy and not supported in newer BIG-IP/BIG-IQ versions.
  • If columns remain empty or data appears inconsistent after following the above steps, open a support case for further investigation.
