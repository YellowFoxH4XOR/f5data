K000140360: The tenant does not receive ARP responses

Type
Support Solution
Published
2024-09-13
Updated
2024-09-13
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.10
Source
https://my.f5.com/manage/s/article/K000140360

Description

One of the tenants is not receiving an ARP response from the second tenant, even though you confirmed with a pcap that the ARP response has been sent.

 

Environment

  • F5OS
  • ARP
  • virtual wire

Cause

Virtual wire configured on one interface only.

 

Appliance Tenant1:

!

interfaces interface 2.0

config type ethernetCsmacd

config enabled

ethernet switched-vlan config trunk-vlans [ 2 3 ]

!

 

Appliance Tenant2:

!

interfaces interface 2.0

config type ethernetCsmacd

config enabled

ethernet config virtual-network HA

ethernet switched-vlan config trunk-vlans [ 2 3 ]

!

 

The interface 2.0 on the appliance with tenant2 has been configured as a virtual wire.

!

file config concurrent-operations-limit 5

virtual-networks virtual-network HA

config mode virtual-wire

!

 

Recommended Actions

Either configure both interfaces as virtual wires or remove the virtual wire from the configuration.

This can be changed from GUI: Network Settings >> Virtual Wire.
