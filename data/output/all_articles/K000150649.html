K000150649: Event Logs not shown in GUI

Type
Support Solution
Published
2025-04-01
Updated
2025-04-01
Applies to
  • BIG-IP
  • BIG-IP ASM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000150649

Description

Event logs are not visible in the UI

But, if you apply the filter per support ID, you will see the request.

Additionally, there is an error message in the Security > Event Logs: Application : Requests:

This request is not shown in the list because it was stored only for Traffic Learning

Environment

ASM

Cause

The issue could be related to bug ID746682

It could also be due to too many learning suggestions eating up the logging capacity

Recommended Actions

For the bug, see the workaround on the bug ID article:

Bug ID 746682: ASM unable to display *any* event logs, unless they are searched for by support ID

If the issue is connected with the learning suggestions, you can verify it, accept or delete them.

K000149035: Event logs only visible when searching for support ID

Additional Information

None
