K000147383: When I set up ratio load balancing, I still get requests going to the pool member with '0' Score assigned to it

Type
Support Solution
Published
2024-11-08
Updated
2025-02-20
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Load Balancer
Source
https://my.f5.com/manage/s/article/K000147383

Description

  • When I set up ratio load balancing, I still get requests going to the pool member with a '0' assigned to it
  • The load balancing mode seems to not be working.
  • Even when we put the Score to 10. It still keeps sending traffic to the pool member with the lower Score.
  • It was tried to change the load balancing method to round-robin instead of ratio, but it is still not working

Environment

  • F5®Distributed Cloud DNS Load Balancer

Cause

  • The observed behavior is most probably caused by enabled Response Cache Parameters Choice for the load balancer
     
  • When the Response Cache Parameter Choice is enabled, the DNS request is served from Cache
  • New changes don't take effect until the entry is removed from the Cache.
    Cache time is controlled by Response Cache Parameters or Default Response Cache Parameters value

Answer/Recommended Actions

  • Disable RESPONSE CACHING for the Load-Balanced Record:
     
  • Alternatively, you can clear Cache for the Load-Balancer Record as described in the following article How do I clear the Cache for a specific Load-Balanced Record?
