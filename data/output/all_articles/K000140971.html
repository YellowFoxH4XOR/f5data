K000140971: Monitoring login attempts for Configuration Utility (GUI) on F5OS-A

Type
Support Solution
Published
2024-09-05
Updated
2026-09-04
Applies to
  • F5OS Products
  • F5OS-A: 1.5.3, 1.8.4, 1.8.3, 1.8.0, 1.7.0, 1.5.4, 1.7.X, 1.8.X, 1.5.X, 1.5.2, 1.5.1, 1.5.0
  • F5OS: 2.0.0
Source
https://my.f5.com/manage/s/article/K000140971

Description

You can view login attempts for Configuration Utility (GUI) on BIG-IP F5OS-A in the /var/F5/system/log/audit.log file

 

  • Successful login attempts appear similar to the following example :

 

appliance-1 audit-service[15]: priority="Notice" version=1.0 msgid=0x1f03000000000002 msg="audit" user="admin/0" cmd="external authentication succeeded via rest from 172.18.204.79:0 with http, member of groups: admin session-id:admin1725535885".

appliance-1 audit-service[15]: priority="Notice" version=1.0 msgid=0x1f03000000000002 msg="audit" user="admin/0" cmd="logged in via rest from 172.18.204.79:0 with http using external authentication".

 

  • Unsuccessful login attempts appear similar to the following example:

 

appliance-1 audit-service[15]: priority="Notice" version=1.0 msgid=0x1f03000000000002 msg="audit" user="[withheld]/0" cmd="external authentication failed via rest from 172.18.204.79:0 with http: rc 1 Not Authenticated".

appliance-1 audit-service[15]: priority="Notice" version=1.0 msgid=0x1f03000000000002 msg="audit" user="[withheld]/0" cmd="login failed via rest from 172.18.204.79:0 with http: noauth".

 

Environment

  • F5OS-A
  • login attempts for Configuration Utility (GUI) 

Cause

None

Recommended Actions

Monitoring login attempts can assist in tracking both authorized and unauthorized attempts to access a BIG-IP F5OS-A, giving administrators vital information for formulating a security policy and reacting to threats.
