Topic

You can use Simple Network Management Protocol (SNMP) to query and monitor all BIG-IP platforms for chassis fan speed, chassis temperature, CPU fan speed, CPU temperature, and power supply status.

Note: The VIPRION 2400 (F100) and VIPRION 2200 (D114) chassis do not return chassis temperature value. In these systems, the individual blades report inlet and outlet temperatures, which you can view using the TMOS Shell (tmsh) command, show sys hardware, or the object identifier (OID), F5-BIGIP-SYSTEM-MIB::sysBladeTemp.

The system uses an SNMP script, system_check, to gather the required information. The system then monitors this information and, when it detects that certain parameters exceed the system-defined threshold, it notifies you by either logging a message to the system log file or issuing an SNMP trap (when you configure the system to send traps).

You can use SNMP polling to obtain this information by importing the F5 management information base (MIB) file, F5-BIGIP-SYSTEM-MIB.txt, into your SNMP polling device and configuring the BIG-IP SNMP agent to allow access from the polling device. For more information, refer to the Configuring network monitoring using SNMP chapter of the External Monitoring of BIG-IP Systems: Implementations manual.

Note: For information about how to locate F5 product manuals, refer to K98133564: Tips for searching AskF5 and finding product documentation.

To display the CPU temperature and fan speed sensor information on an iSeries platform, refer to K18802953: The tmsh show /sys hardware command does not provide CPU temperature and fan speed information for iSeries platforms.

For example, the following is the sysChassisFanSpeed (.1.3.6.1.4.1.3375.2.1.3.2.1.2.1.3) OID from F5-BIGIP-SYSTEM-MIB.txt:

snmpwalk -On -c public -v 2c 127.0.0.1 sysChassisFanSpeed

.1.3.6.1.4.1.3375.2.1.3.2.1.2.1.3.1 = Gauge32: 2906
.1.3.6.1.4.1.3375.2.1.3.2.1.2.1.3.2 = Gauge32: 2903
.1.3.6.1.4.1.3375.2.1.3.2.1.2.1.3.3 = Gauge32: 2905
.1.3.6.1.4.1.3375.2.1.3.2.1.2.1.3.4 = Gauge32: 2909

snmpwalk -Ons -c public -v 2c 127.0.0.1 sysChassisFanSpeed.1

sysChassisFanSpeed.1 = Gauge32: 2906

Downloading the F5 MIB file

To download the F5-BIGIP-SYSTEM-MIB.txt file, perform the following procedure:

  1. Log in to the Configuration utility.
  2. On the Welcome page, under Downloads, in SNMP MIBs, click Download F5 MIBs (mibs_f5.tar.gz).

    Note: The F5-BIGIP-SYSTEM-MIB.txt file is located in the download tar archive.

  3. Extract the tar archive and import the F5-BIGIP-SYSTEM-MIB.txt file into your SNMP polling device.

    Note: Refer to your SNMP polling device documentation for information about how to import and configure the device for polling the BIG-IP.
