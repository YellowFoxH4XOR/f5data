Description

  • Items on APM webtops have a default font size of 16 pixels
  • An APM administrator may want to change this

Environment

  • BIG-IP with APM provisioned
  • Users are getting APM Webtop with resources

Cause

The font size of captions for items displayed on the APM webtop is controlled using CSS files. The default setting (16 pixels) can be changed by editing the CSS files using Advanced Customization.

Recommended Actions

  • Procedure for Access Policy created with "Standard" customization type
  1. Navigate to Customization Settings >> Access Profiles >> [Access_Profile_name] >> Common >> apm_full.css
  2. Find the section "#webtop_favorites_inner_container2 span.favorite span.caption" and modify the "font-size" value as required
    Example:
          #webtop_favorites_inner_container2 span.favorite span.caption{
             width: 161px;
             display: table-cell;
             vertical-align: middle;
             font-size: 12px;
             <? if( $_GET['ctype'] == 'IE' && $_GET['cversion'] < 9 ){ ?>zoom: 1;<? } ?>
          }
  3. Click "Save Draft"
  4. Click "Save"
  5. Apply Access Policy
     
  • Procedure for Access Policy created with "Modern" customization type
  1. Navigate to Customization Settings >> Access Profiles >> [Access_Profile_name] >> Common >> user-common.css
  2. Enter the text below and modify the "font-size" value as required
    Example:
          .apmui-webtop-resource--caption {
            display: inline-block;
            font-size: 12px;
            line-height: 1.25;
            max-height: 40px;
            overflow: hidden;
            padding-bottom: 0.8px;
            text-overflow: ellipsis;
          }
  3. Only the modified value needs to be specified to overwrite the default setting
    Example:
          .apmui-webtop-resource--caption {
            font-size: 16px;
          }
  4. Click "Save Draft"
  5. Click "Save"
  6. Apply Access Policy
The changes will come into effect the next time users log into the modified Access Policy.
