K14353714: Message in GUI: ''The system must be rebooted for some changes to take effect''.

Type
Support Solution
Published
2021-01-21
Updated
2023-02-21
Applies to
  • BIG-IP Platforms
  • BIG-IP
  • BIG-IP LTM: 13.1.3
Source
https://my.f5.com/manage/s/article/K14353714

Description

The following message displayed in GUI: "The system must be rebooted for some changes to take effect" while no changes have been done. The message will be cleared after manually reboot.

Environment

  • Datastor core
  • Web-acceleration profile in use

Cause

The reboot is required because of the crash of datastor.

Recommended Actions

  1. Prevent datastor from future crashes by removing the web-acceleration profile from the virtual server or remove the application from the profile.
     

Additional Information

It is intended that datastor also stops TMM when it fails, which is why it is needed to reboot the device to get it online again. The datastor process is the biggest part of the Application Acceleration Manager (AAM) module and is activated when you have a virtual server with a web acceleration profile that has an enabled application. 

AAM will be disabled and no longer available in v16.
