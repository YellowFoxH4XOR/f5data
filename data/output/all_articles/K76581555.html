Known Issue

The internal virtual server inherits the Clustered Multiprocessing (CMP) hash mode from the parent virtual server.

This issue occurs when all of the following conditions are met:

  • You configure a virtual server with a request-adapt or response-adapt profile and a Virtual Local Area Network (VLAN) with a CMP hash mode of src-ip.
  • You configure an internal virtual server without a VLAN or cmp-hash setting.

Impact

The internal virtual server might stop when it attempts to connect to the server. This occurs after the system successfully completes a load-balance, indicated by the LB_SELECTED event, but before the system sends a TCP SYN packet to the server. As a result, the parent virtual server performs the service-down-action configured in the request-adapt or response-adapt profile.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • An internal virtual server might behave in unexpected ways, such as stopping a client connection before connecting to the server.

Workaround

To work around this issue, if possible, do not use the CMP hash mode src-ip.
