Description

On the GUI when you click on Device Management ›› Overview  the page only shows "Receiving configuration data from your device" and nothing ever shows up.

Several management users have the same issue.

The rest of the GUI works fine.

Sync config with tmsh works, as explained on K14856: Performing a ConfigSync using tmsh.

Environment

  • Config Sync
  • GUI (Configuration Utility)

Cause

Unknown at time of publication.

Recommended Actions

On the affected device restart the restjavad and restnoded daemons using the following procedure at the CLI Bash prompt:

Important:  While performing this procedure, the system will not respond to REST API calls.
  1. bigstart status restjavad restnoded    # just to make sure the service is running
  2. bigstart stop restjavad restnoded
  3. bigstart status restjavad restnoded    # to make sure the service stopped
  4. bigstart start restjavad restnoded

Log in the GUI and try to load Device Management ›› Overview page again.
