Known Issue

BIG-IP Virtual Edition (VE) may fail Secure Sockets Layer (SSL) record padding verification.

This issue occurs when the following condition is met:

  • SSL record padding is greater than 127 bytes.

Impact

The BIG-IP system disconnects SSL connections.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When using the ssldump utility to view a packet capture file, you observe an error message similar to the following example:

    Alert message: BAD_RECORD_MAC
    ###Connection reset due to FATAL_ALERT
