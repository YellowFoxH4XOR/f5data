Description

 

APM administrators report strange log messages related to Radius AAA Authentication failures. Radius Authentication failures result in the following log messages display internal loopback IP Address.

Jun 24 10:19:06 BIG-IP-01 err apmd[22448]: 01490108:3: /Common/Access_Policy:Common:XXXXXXXX: RADIUS module: authentication with 'TestUser1' failed: Access-Reject packet from host 127.7.0.8:1812  
 

Environment

Relevant environmental factors specific to the topic

  • APM AAA
  • Radius Authentication
  • Radius server pool

Cause

When the radius AAA server being used is configured as pool option instead of direct option. What we do is we create a internal listener and do a HA IP pick during the LB select from the pool hence the RADIUS server IP here is shown as internal server IP.
Only the listener's IP address (i.e. 127.7.0.X) is known to APMD.

Recommended Actions

This is behaving as designed. If necessary to troubleshoot Authentication failures with Radius servers to test one at a time as Direct.
