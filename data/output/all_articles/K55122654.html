Description

After connection to vpn, the user can get the error similar to:

An error occurred while mounting remote share \\<<<Server IP or Hostname>>>\ to <<<Name of Disk>>>:
The network path was not found.

And subsequently, the user is not assigned with remote drive disk.

Environment

  • APM
  • VPN
  • Edge Client
  • Network-Access Resource
  • Drive Mapping (remote disk mounting)

Cause

Due to wrong format of 'path' setting inside of network-access resource configuration:

(tmos)# list apm resource network-access na_test_ft

apm resource network-access na_test_ft {

[...]
    drive-mapping {
       {
            drive r
            path \\\\10.10.10.10\\ <<<<<<<<<< (!) the format should be not '\\host', but '\\host\path'
        }
    }
    leasepool-name na_test_lp
}

Recommended Actions

Configure the path setting in format '\\host\path'
