Description

How to extract list of virtual servers that were created with an http iapp

Environment

BIG-IP LTM

Cause

Expected behavior

Recommended Actions

You can use the following awk command to output a list of virtual servers to the file /var/tmp/f5_vips.txt:

# awk '/^ltm virtual / {vs=$3; in_vs=1} /^\}/ {in_vs=0} in_vs && /^[[:space:]]*destination / { match($0, /([0-9]+\.[0-9]+\.[0-9]+\.[0-9]+:[0-9]+)/, a); if (a[1] != "") print vs, a[1] }' /config/bigip.conf > /var/tmp/f5_vips.txt
