Description

After an upgrade or after a reboot if tmm is restarting and you find these logs under /var/log/tmm:

Aug 23 23:13:22 LTM notice "client-specific driver info"
Aug 23 23:13:22 LTM notice invoked from within
Aug 23 23:13:22 LTM notice "device driver [client-specific driver info] mlxvf5"
Aug 23 23:13:22 LTM notice (file "/config/tmm_init.tcl" line 1)
Aug 23 23:13:22 LTM notice invoked from within
Aug 23 23:13:22 LTM notice "source "/config/tmm_init.tcl""
Aug 23 23:13:22 LTM notice invoked from within
Aug 23 23:13:22 LTM notice "if {[file exists "tmm_init.tcl"]} {
Aug 23 23:13:22 LTM notice source "tmm_init.tcl"
Aug 23 23:13:22 LTM notice } elseif {[file exists "/config/tmm_init.tcl"]} {
Aug 23 23:13:22 LTM notice source "/config/tmm_init.tcl"
Aug 23 23:13:22 LTM notice }"
Aug 23 23:13:22 LTM notice (file "/usr/lib/tmm/tmm_base.tcl" line 1568)tmm_start: tcl_init_proxy failed (ERR_TCL).

Environment 

  • BIG-IP upgrade or reboot

Cause

Probably /config/tmm_init.tcl was manually created.

Recommended Actions

  1. Run these commands from bash:
    mv /config/tmm_init.tcl /var/tmp/tmm_init.tcl.old

    tmsh restart sys service tmm
     
  2. Only if some services are still down you can add this command:
    bigstart restart
