K000147216: How to raise a feature request

Applies to

  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147216

Description

  • You are trying to do some configuration which is currently not available in F5 Distributed cloud console.

Environment

  • F5® Distributed Cloud Services
  • F5 Distributed Cloud Ideas and Feature Requests (Aha!)

Answer/Recommended Actions

  • You should raise your request with your F5 Account Manager so that they may follow up on it

To raise a feature request on your own:

1. Go to F5 Distributed Cloud Ideas and Feature Requests to log your feature request.

2. Review if your idea is already listed.                                                                                                

                                                                                                               

3. If not, click on Add a new idea.                                                                                                          

4. Select the workspace for your enhancement.

                              

5. Add the details for the new feature.       

                                                                                                                                    

6. Click on Share idea

Cause

Trying to do something which is currently unavailable in F5XC console.
