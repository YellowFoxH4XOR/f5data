Known Issue

The hourly cron script may produce extraneous data to the standard output (stdout) file and send a system-generated email.

This issue occurs when the following condition is met:

  • You have a BIG-IP system licensed and provisioned with only the BIG-IP LTM module.

Impact

You can safely ignore this issue; it should not impact system performance.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Every hour, a message similar to the following example appears in the stdout file:

    Usage: $class->connect([$dsn [,$user [,$passwd [,\%attr]]]]) at /usr/share/mysql/purge_mysql_logs.pl line 37

  • If you configure the BIG-IP system to send email, it generates an email every hour which appears similar to the following example:

    From: root <BIG-IP system's configured email address>
    To: <root@<recipient's email address>>
    Subject: [<email address username>] Cron <root@mssm-f503> run-parts /etc/cron.hourly
    Date: Wed, 21 Dec 2016 09:31:00 -0600
    Sender: <email address username> <BIG-IP system's configured email address>

    /etc/cron.hourly/purge_mysql_logs.pl:

    Usage: $class->connect([$dsn [,$user [,$passwd [,\%attr]]]]) at /etc/cron.hourly/purge_mysql_logs.pl line 27
