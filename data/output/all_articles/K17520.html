Known Issue

BIG-IP ASM configurations may fail to load after an upgrade.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP ASM system is configured with an Event Log custom filter for application requests, based on a source IP address.
  • You upgrade your system from a version listed in the Applies To box (located in the upper-right corner of this article) to different version listed in the Applies To box.

Impact

BIG-IP ASM configurations fail to load after an upgrade.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • After upgrading your BIG-IP ASM system, you receive an error message similar to the following example when attempting to load the configuration:

    Syntax Error:(at line: <line number>) "<custom filter name>" unexpected argument

Workaround

To work around this issue, you can manually edit the /config/bigip.conf configuration file to remove the offending statements. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP ASM system.
  2. Copy the /config/bigip.conf configuration file to /config/bigip.conf.SOL17520 by typing the following command:

    cp /config/bigip.conf /config/bigip.conf.SOL17520
  3. Use a text editor to open the /config/bigip.conf file.
  4. Locate the configuration lines with the following syntax:

    values { \? }
  5. Delete all lines that match this pattern.
  6. Save the changes to /config/bigip.conf.
  7. Load the configuration by typing the following command:

    tmsh load /sys config
  8. After successfully loading the configuration, save the loaded configuration by typing the following command:

    tmsh save /sys config
