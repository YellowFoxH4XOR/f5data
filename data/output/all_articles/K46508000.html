Description

MAC user unable to established VPN connection with BIOS serial number.

Environment

  • MacOS
  • Access Policy
  • Machine Info Inspector
  • BIOS serial number

Cause

This feature is not supported for MacOS and Linux.
The machine info check does pull the serial number for Windows devices but does not for Mac and Linux.
No current supported way for the APM VPN to obtain Mac or Linux serial numbers.

Recommended Actions

Use alternative check for example Machine Cert Auth or use available for MacOS Machine Info Inspector value like MAC address.
