Source

Description

You want to find the description or details of particular OID or object name. Example: sysStatClientTotConns5m (1.3.6.1.4.1.3375.2.1.1.2.1.92).

Environment

  • BIG-IP
  • SNMP
  • OID
  • Object Name
  • MIB file

Cause

None

Recommended Actions

  1. Open the file /usr/share/snmp/mibs/F5-BIGIP-SYSTEM-MIB.txt
  2. Search for the Object Name. The Object Name might be in multiple location in the file, search for the one which contains the Description.

For example if you are searching for this Object Name - sysStatClientTotConns5m

sysStatClientTotConns5m OBJECT-TYPE 
    SYNTAX Gauge
    MAX-ACCESS read-only
    STATUS     deprecated
    DESCRIPTION
        "Deprecated! the average connection data is available in sysStatClientCurConns5m."
    ::= { sysGlobalStat 92 } 

If you only have the OID and do not have the Object Name, you can refer the following article to find the Object Name:

K000132246: Finding the SNMP object name from a known OID
