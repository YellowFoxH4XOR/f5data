Known Issue

This is the result of a known issue. Setting the setDebugZone ZONE_SCRUB option to debug may cause the BIG-IP WebAccelerator to stop processing transactions if the client requests a page that contains a number of IBR-enabled links.

F5 Product Development tracked this issue as CR135764 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP version 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes on systems refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
