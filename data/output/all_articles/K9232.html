K9232: FirePass does not launch Static Java Application Tunnels for access to Citrix Web Interfaces through Portal Access

Topic

Starting in FirePass version 6.0.3, FirePass supports Static Java Application Tunnels for Linux and Mac OS X clients. However, when a user launches a Portal Access Web Application favorite that accesses a Citrix Web Interface (formerly Citrix NFuse) or a custom Citrix portal page, FirePass launches the Static Application Tunnel ActiveX control to intercept traffic between the Citrix client and the Citrix server. The Static Application Tunnel ActiveX control supports Windows clients, but not Linux or Mac OS X clients.

You can work around this behavior by performing the procedure provided in K8192: Using the Citrix Java client with Portal Access for Mac and Linux clients.

Additionally, F5 Networks Product Development is tracking an enhancement request for FirePass to open a Static Java Application Tunnel if it cannot open the ActiveX-based Static Application Tunnel when a user launches a Citrix Application through a Portal Access Web Application favorite. F5 Networks Product Development is tracking this enhancement request as CR102760.

For more information about the current FirePass behavior, refer to K8644: Overview of Citrix access through Portal Access.
