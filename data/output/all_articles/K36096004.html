Description

When using REST API to try creating a new SNAT pool using a similar syntax to the one below:

curl -k -u <user>:<passwd> --location --request POST 'https://<BIG-IP hostname or management IP address>/mgmt/tm/ltm/snatpool' --header 'Content-Type: application/json' --data '{"name": "SNAT_POOL_NAME", "members": ["10.x.x.x", "10.x.x.x"]}'

Note: where 10.x.x.x is the actual IP address 

It returns and "unexpected argument" error:
{"code":400,"message":"\"snatpool\" unexpected argument","errorStack":[],"apiError":26214401}
 

Environment

  • REST API

Cause

User running the REST API command does not permissions due to not having the 'admin' role

Recommended Actions

  • Assign 'admin' role to the user running the REST API command. 
    Alternatively
  • Run the REST API command using the 'admin' user.

None
