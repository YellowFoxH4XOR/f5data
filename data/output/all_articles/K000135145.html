K000135145: SDC components status are showing "Poor"

Type
Support Solution
Published
2023-06-25
Updated
2024-10-01
Applies to
  • Traffix SDC: 5.2.X, 5.2.0, 5.1.0
Source
https://my.f5.com/manage/s/article/K000135145

Description

  • GUI Topology > Site > SDC Components > Health shows status as poor for some components.

Environment

  • Traffix SDC 5.x

Cause

This is usually caused by the component having some errors. Go to the Component health parameters to understand the cause.

 Recommended Actions

  1. Restarting the component can also temporary fix this issue.

Additional Information

None.
