Description

You want to load balance multiple inbound ports for one application

Environment

  • BIG-IP LTM
  • Virtual Server
  • Port List

Cause

None

Recommended Actions

In previous versions, this configuration could only be created using a single virtual server per port, or using a virtual server configured for any port and using an iRule or AFM to filter down accepted connections

In version 14.1 and above, you are able to create a virtual server using a port list.

To build this configuration, you will need the following elements:
  1. A port list configured under the Shared Objects tab of your GUI (When you are creating this port list, you can enter a hyphenated port range as a single entry)
  2. Create a pool with your servers configured for any port
  3. Create a virtual server using your new port list as the destination port
