K000150153: Unable to add BIG-IP to BIG-IQ - 401 Unauthorized with correct credentials

Type
Support Solution
Published
2025-03-03
Updated
2025-03-03
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.0.0, 8.X.X, 8.3.X, 8.3.0, 8.2.X, 8.2.0, 8.1.X, 8.1.0, 8.0.X
Source
https://my.f5.com/manage/s/article/K000150153

Description

When trying to add/discover BIG-IP to BIG-IQ 401 Unauthorized is returned, but BIG-IP credentials are correct

 

On target BIG-IP, you see the following errors in logs: /var/log/httpd/httpd_errors: httpd[15405]:

 

[auth_pam:error] [pid 15405] [client 10.10.10.100:35576] AUTHCACHE PAM: user '\x05\xab"' (fallback: false) - not authenticated: Application needs to call libpam again, referer: http://localhost:8100/cm/global/utility/bigip-device-check

err httpd[15405]: [auth_pam:error] [pid 15405] [client 10.10.10.100:35576] AUTHCACHE Incomplete authentication. auth_state = NULL, referer: http://localhost:8100/cm/global/utility/bigip-device-check

 

or

 

err httpd[22906]: [auth_pam:error] [pid 22906] [client 10.10.10.100:35576] AUTHCACHE PAM: user '\x05\xab"' (fallback: false) - not authenticated: User not known to the underlying authentication module, referer: http://localhost:8100/cm/global/utility/bigip-device-check

 

Environment

  • BIG-IQ
  • BIG-IP
  • Device discovery/add

Cause

Database variable httpd.basic_auth set to disable on target BIG-IP

Recommended Actions

  1. Login to CLI/bash on BIG-IP
  2. Execute command: setdb httpd.basic_auth enable
  3. Execute command: bigstart restart httpd
  4. Add BIG-IP to BIG-IQ
