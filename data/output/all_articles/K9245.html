Topic

There may be occasions when you need to test the validity of the BIG-IP software license. You can verify the license using the tmsh command.

Verifying the license

If the system is properly licensed, the tmsh show /sys license command output displays licensing information for the BIG-IP system, including a list of active modules.

For example:

Sys::License
Licensed Version    x.x.x
Registration key    xxxxx-xxxxx-xxxxx-xxxxx-xxxxxxx
Licensed On         2009/06/19
License Start Date  2009/06/18
License End Date    2011/07/06
Service Check Date  2011/06/06
Platform ID C62
Appliance Serial Number bipxxxxxxx

Active Modules

ADD IPV6 GATEWAY

Licensing errors

You may observe the following licensing errors:

  • Device license expiration
  • Time limited module license expiration

Device license expiration

If the license has expired, the BIG-IP system shows LICENSED EXPIRED on the command prompt and displays the following error when you run the tmsh show /sys license command:

Warning: license has expired

Time limited module license expiration

Subscription and demo licenses for add-on modules are time limited and can expire. You may observe output similar to the following when this happens:

  • On the BIG-IP Configuration utility, when you go to System > License:

    Note: Inactive Module indicates that a module has previously been removed from your license. You may reactivate this module in the next license reactivation activity.

inactive module :   IP Intelligence, 1Yr, 3900/4XXX/i4XXX|AAAAAAA-BBBBBBB|20170711|20211004|SUBSCRIPTION

  • In the /config/bigip.license file:

active module : Advanced Web Application Firewall, C2X00|CCCCCCC-DDDDDDD               <----- "Active" add-on module

# License Tokens for Module Advanced Web Application Firewall, C2X00 key CCCCCCC-DDDDDDD
# 20190423_waf_gc : enabled                                                             <----- Expired date
# 20190423_mod_waf : enabled                                                            <----- Expired date

Important: Avoid unexpected license expirations by making a note of the License End Date.

If the license process has yet to be performed, the license is missing, or the license is not properly installed, you will experience the following symptoms:

  • The BIG-IP system will not function
  • The tmsh show /sys license command will not display any active modules, but will instead display a message similar to the following example:

    Can't load license, may not be operational

If you determine that the license is expired, or not valid, you should attempt to reactivate the license. For more information about licensing the BIG-IP system, refer to K7752: Licensing the BIG-IP system.
