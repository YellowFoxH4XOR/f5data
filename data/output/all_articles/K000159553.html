K000159553: How to Bind CE Load Balancer Traffic to Origin Servers Based In That Same CE?

Source

Description

  • For example, you have a load balancer advertised on two CEs in two separate regions, the United States and Europe. You want to make sure client Load Balancer traffic received by the United States CE is forwarded only to the origin server based in the United States CE, and that traffic received by the Europe CE is forwarded only to the origin server based in the Europe CE. 

Environment

  • F5® Distributed Cloud
  • F5 Load Balancer
  • Customer Edge (CE)
  • Multi-Cloud Network Connect

Answer/Recommended Action

For the example described above, on the load balancer advertised in two CEs in two separate regions, you will need to create a single origin pool (attached to the LB) with two origin servers:

  1. One origin server based in the United States CE
  2. The other based in the Europe CE

The key setting to configure is Endpoint Selection: Local Endpoints Only. See screenshot below for reference. This will make sure that any traffic received by the CE is forwarded only to origin servers local to that CE.
