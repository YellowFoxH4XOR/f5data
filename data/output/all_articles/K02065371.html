K02065371: Error UCS process failed while trying to install image

Description

Errors similar to the following appear in liveinstall.log when attempting to install a new image:

info: Saving active configuration...
info: Thrift: Tue Jul 14 11:09:56 2020 TSocket::open() connect( <Host: localhost Port: 9090>Connection refused
info: Error during config save.
info: Unexpected Error: UCS saving process failed.

Environment

  • LTM only device
  • Report referenced in config from a module that is not provisioned
  • During image install

Cause

bigip.conf file references a report from from a module that isn't provisioned similar to the following:

apm report default-report {
    report-name sessionReports/sessionSummary
    user /Common/admin
}

Recommended Actions

  1. Remove any references to a report that look similar to the above from the config file in your favorite text editor.
  2. Run the following command: 
tmsh save sys config
Then reload the configuration:
tmsh load sys config

 

The next image installation attempt should proceed without issue.
