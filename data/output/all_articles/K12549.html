Known Issue

This is the result of a known issue. In BIG-IP ASM 10.1.0 and 10.2.0, when creating custom filters for the charts feature in the BIG-IP ASM reporting tool, a condition can occur where clicking save on the custom filter causes the Configuration utility to crash. When this condition occurs, the following error message will be displayed in the Configuration utility:

There seems to have been a slight problem with the BIG-IP® Application Security Manager database.
Please try again by pressing the refresh button in your browser.
We apologize for any inconvenience.

This issue has only been known to occur when another custom filter has already been defined within the BIG-IP ASM reporting tools.

F5 Product Development tracked this issue as ID 337965, and it was fixed in BIG-IP 10.2.1. For information about upgrading, refer to the BIG-IP ASM release notes.

In addition, this issue has been fixed in a hotfix. To request the hotfix, contact F5 Technical Support, referencing this article number and the associated ID numbers.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.
