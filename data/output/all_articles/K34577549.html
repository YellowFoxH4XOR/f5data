K34577549: BIG-IQ Script failure

Type
Support Solution
Published
2022-07-14
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K34577549

Description

Deploying BIG-IQ Script result in failure.

Environment

  • BIG-IQ
  • Script Management
  • tmsh command with special characters

Cause

Special characters may result in failure on BIG-IQ or BIG-IP

Recommended Actions

Base64 encode the script to ensure BIG-IQ doesn't have issues with special characters contained in the script.

Example:
  1. Verify command is working and valid on BIG-IP:
    tmsh modify sys snmp users add {user { username user oid-subset .1 access ro security-level auth-privacy auth-protocol sha auth-password PASS privacy-protocol aes privacy-password PASS }}
  2. Base64 encode the command:
    echo 'tmsh modify sys snmp users add {user { username user oid-subset .1 access ro security-level auth-privacy auth-protocol sha auth-password PASS privacy-protocol aes privacy-password PASS }}' | base64 -w0
    Output:
    dG1zaCBtb2RpZnkgc3lzIHNubXAgdXNlcnMgYWRkIHt1c2VyIHsgdXNlcm5hbWUgdXNlciBvaWQtc3Vic2V0IC4xIGFjY2VzcyBybyBzZWN1cml0eS1sZXZlbCBhdXRoLXByaXZhY3kgYXV0aC1wcm90b2NvbCBzaGEgYXV0aC1wYXNzd29yZCBQQVNTIHByaXZhY3ktcHJvdG9jb2wgYWVzIHByaXZhY3ktcGFzc3dvcmQgUEFTUyB9fQo=
  3. Use in BIG-IQ Script:
    echo -n dG1zaCBtb2RpZnkgc3lzIHNubXAgdXNlcnMgYWRkIHt1c2VyIHsgdXNlcm5hbWUgdXNlciBvaWQtc3Vic2V0IC4xIGFjY2VzcyBybyBzZWN1cml0eS1sZXZlbCBhdXRoLXByaXZhY3kgYXV0aC1wcm90b2NvbCBzaGEgYXV0aC1wYXNzd29yZCBQQVNTIHByaXZhY3ktcHJvdG9jb2wgYWVzIHByaXZhY3ktcGFzc3dvcmQgUEFTUyB9fQo= | base64 -d | bash
If the script fails on BIG-IP, review /var/log/audit to examine the command used.

Additional Information

K2873: Characters that should not be used in passwords on F5 products

The # character is a problem when piped into bash on BIG-IP, it's interpreted as a start of a new comment. ie everything after # is being ignored.
