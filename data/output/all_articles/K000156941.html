Description

I'm receiving alerts regarding the CE - "K8s Pods crashing" and "Pod container ves-system/webroot-test123 is crashing at node master-x"

Environment

  • CE (Customer Edge)
  • F5® Distributed Cloud

Cause

The primary cause is blocked network connectivity between CE nodes and the required BrightCloud domains due to firewall rules. When requests to these domains are dropped by the firewall, the Webroot pods cannot download their necessary databases and subsequently crash.

Disk permission or space issues on CE nodes can also result in similar symptoms.

Recommended Actions

Firewall/Proxy Configuration:

  • Update firewall or proxy settings to allow outbound connections to all domains listed in the official F5 documentation:
    • F5 Customer Edge IP Address and Domain Reference for Firewall or Proxy Settings
    • Ensure egress is permitted specifically for all BrightCloud-related domains needed by Webroot.

Note:

The set of domains required for Webroot URL Classification Database access differs between Legacy Customer Edge (CE) sites and Secure Mesh v2 (SMSv2) CE sites.

For Legacy CE sites, you must allow all domains listed under "Webroot URL Classification Database" in the Egress Domain Rules (Legacy) section of the official documentation. This includes both api-* and localdb-* domains, as well as additional third-party endpoints.
For Secure Mesh v2 CE sites, only a reduced set of localdb-* domains is required, as described in Egress Domain Rules. The api-* endpoints are no longer needed for SMSv2.

Network Connectivity Checks:

    • Confirm that CE nodes have network access to all required BrightCloud endpoints (e.g., localdb-* and api-*).
    • Use tools like ping or curl from within the CE environment to verify connectivity.

Disk Health:

    • Verify there is adequate disk space and proper permissions on the CE nodes, as insufficient resources can also cause pod crashes.

Monitoring:

    • Continuously monitor pod health and configure alerts for repeated restarts or failed database downloads.

Additional Information

  • F5 Customer Edge IP Address and Domain Reference for Firewall or Proxy Settings
  • Migrate Legacy CE Sites to New Secure Mesh v2

Ensure you select the correct domain list based on your site type. Using an incorrect list may result in failed database downloads or pod crashes (such as webroot pod restarts).
