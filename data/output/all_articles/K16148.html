Known Issue

The Configuration utility does not display pools with names containing "mam".

This issue occurs when all of the following conditions are met:

  • You create a pool with a name that contains "mam".
  • The text that precedes "mam" is five characters long.

    For example:

    test1mam or test2mamtest

Impact

The pool will be created, but not listed in the Local Traffic > Pools > Pool List screen.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H506067 on the Diagnostics > Identified > Medium screen.
  • Affected pools do not display on the Local Traffic > Pools > Pool List screen, but they are available for selection when creating virtual servers.

Workaround

To work around this issue, you can avoid creating pools with "mam" that are preceded by four or more characters, or use the Traffic Management Shell (tmsh) to list pools with "mam" in the name. To do so, perform the following procedure:

Impact of workaround: Performing the following workaround should not have a negative impact on your system.

Listing available pools using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. List available pools by typing the following command:

    list ltm pool one-line
