K13276: The Network Access tunnel does not use system proxy settings on OS X and Linux

Topic

When connecting to a Network Access tunnel using Apple OS X or Linux, the tunnel does not use the systems proxy settings. This behavior may cause the Network Access tunnel to fail to connect.

Note: Connectivity for Apple OS X has been addressed in BIG-IP 11.0.0 HF1 and BIG-IP 11.1.0.
