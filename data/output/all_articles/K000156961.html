K000156961: You do not need to share BIG-IQ usage reports (json file) when using customer catalog program.

Type
Support Solution
Published
2025-10-09
Updated
2025-10-09
Source
https://my.f5.com/manage/s/article/K000156961

Description

Customers transitioning to the newer Customer Catalog Program (FCP) from FCP do not need to share JSON usage reports from BIG-IQ.

While it is common and correct to create a license pool and add individual license registration keys to it, you do not need to share JSON usage reports in this scenario.

Note that the JSON file format may appear different than expected. For example:

"poolRegkey": "123456-XxxX-4321-A12B-abc123efg" 

Environment

  • BIG-IQ

  • Usgage reporting

Cause

Customers using the "Customer Catalog" program do not need to share usage reporting files (JSON reports) from BIG-IQ.

Answer/Recommended Actions

Customers using the "customer catalog" program do not need to share usage reports / json files.

Additional Information

None.
