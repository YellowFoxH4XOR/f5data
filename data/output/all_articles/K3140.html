Topic

You can configure a FirePass Static Application Tunnel to access Citrix NFuse or NFuse Elite. To access Citrix NFuse Elite through a Static Application Tunnel, create an Application Tunnel Favorite with the following characteristics:
  • A tunnel to the NFuse server that uses port 80, or port 443 if using SSL connections
  • A tunnel to each Citrix application server that uses port 1494

By default, the NFuse server returns an ICA configuration file to the Citrix client that contains the IP address of the Citrix application server rather than the server's fully qualified domain name (FQDN) or hostname. The Citrix client will then attempt to connect to the IP address in the ICA file, rather than the loopback IP address or addresses used by the Static Application Tunnel Favorite. Because there is no direct access to the application server, the client?s connection will fail.

To avoid this issue, you must modify the NFuse.conf file, so that the NFuse server returns an ICA file containing the application server's FQDN or hostname, instead of the application server's IP address. When the Citrix client connection uses the name of the application server, the connection will succeed because the name is mapped to the Static Application Tunnel's loopback address while the Application Tunnel Favorite is running on the system with the Citrix client.

Important: The names used in the Remote Host fields of the Application Tunnel Favorite must match the names returned in the ICA file. Typically, this means using the FQDNs in the configuration of the Application Tunnel Favorite. For example, configuring the Application Tunnel Favorite to use hostnames when the ICA file contains the FQDNs will cause the connection to fail.

For instructions about how to modify the NFuse.conf file, refer to Citrix documentation. The essential information is available in the following Citrix knowledge base article:

http://support.citrix.com/article/CTX104702
