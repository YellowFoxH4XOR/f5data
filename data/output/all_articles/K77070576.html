Description

You want to disable the Connectivity Profile compression setting in BIG-IP APM.

Environment

  • BIG-IP APM has compression enabled in the Connectivity Profile
  • High CPU load
  • Large volume of concurrent users

Cause

None

Recommended Actions

To change the gzip Compression Level to 0- No Compression (Disabled) for the Connectivity Profile, you may follow the steps below:

  1. Navigate to  Access  >>  Connectivity / VPN : Connectivity : Profiles

  2. Select your Connectivity Profile, then click Edit Profile

  3. Under Compression Settings and Network Access then gzip Compression Level

  4. You select 0- No Compression (Disabled) 

  5. Select OK 

  6. Apply the Access policy to complete the changes

Note:
If compression is disabled in the Connectivity Profile, then there is no compression in the direction of BIG-IP APM to the end client. For more information, you may check K52584343 for detail.
