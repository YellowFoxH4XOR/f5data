Known Issue

The BIG-IP system incorrectly logs an error message when it receives an HTTP 408 Request Timeout message.

This issue occurs when all of the following conditions are met:

  • You have configured a BIG-IP virtual server with an HTTP profile.
  • The client does not send an HTTP request within the timeout period expected by the server.

Impact

The BIG-IP system incorrectly logs an error message.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system logs error messages to the /var/log/ltm log file that appear similar to the following example:

    err tmm[1234]: 011f0007:3: http_process_state_prepend - Invalid action EV_INGRESS_DATA during ST_HTTP_PREPEND_HEADERS.
  • The BIG-IP system resets the connection as expected.
