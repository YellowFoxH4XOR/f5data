Topic

The VIPRION chassis platforms do not support serial cable failover between VIPRION chassis.

Description

Serial cable failover is not supported between VIPRION chassis. Users should not configure serial cable failover using any failover cables included with the VIPRION platform.

For redundant VIPRION systems, you must configure network failover.

Recommendation

F5 recommends configuring network failover when redundant VIPRION systems are configured.

For information about configuring network failover for redundant VIPRION systems, refer to the following articles:

  • K13915: Configuring network failover for redundant VIPRION systems (11.x - 12.x)
  • K11939: Configuring network failover for redundant VIPRION systems (10.x)
  • K15930: Overview of vCMP configuration considerations
