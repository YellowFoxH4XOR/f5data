Description

While troubleshooting an issue with iRules using "LB_FAILED" commands, you might notice that this event is being triggered, but logs created with "event info" command inside LB_FAILED event will not display any error code.

Environment

  • BIG-IP

  • LTM

Cause

LB_FAILED event will be triggered not only if pool member can not be chosen, it will also be triggered if server does not respond properly, for example it can happen due to SSL handshake failure.

Answer/Recommended Actions

If you observe that logs created inside "LB_FAILED" event does not contain any error code created with "event info" command, verify if connection with pool member is established properly.
