Known Issue

Note: For information about the external-filer ip address command, refer to the ARX CLI Reference Guide.

This is the result of a known issue. Attempting to remove a secondary or management IP address from an external-filer configuration may result in the primary address being erroneously removed. If the no ip address <IP_address> command does not specify secondary or management, the primary IP address configured for the external-filer will be removed instead of the IP address listed in the no ip address <IP_address> command.

For example, the following external filer is configured with a primary IP address of 1.1.1.1, and a secondary IP address of 1.1.1.2:

Note: Use the show global-config filer command to display the external-filer configuration.

# show global-config filer
;============================ external-filer =============================
  external-filer testfiler
    cifs-port 445
    ip address 1.1.1.1
    ip address 1.1.1.2 secondary
    exit

Attempting to remove the 1.1.1.2 IP address using the no ip address 1.1.1.2 command will actually remove the 1.1.1.1 IP address.

For example:

# show global-config filer
;============================ external-filer =============================

  external-filer testfiler
    cifs-port 445
    ip address 1.1.1.2 secondary
    exit

F5 Product Development tracked this issue as ID 38165, and it was fixed in ARX version 5.2.0. For information about upgrading, refer to the ARX release notes.

Workaround

To remove a secondary or management IP address from an external-filer configuration, you must specify secondary or management as part of the no ip address <IP_address> command.

For example, using the external filer example previously mentioned, you would delete the 1.1.1.2 secondary IP address by typing the following command:

no ip addresss 1.1.1.2 secondary

The external-filer configuration appears similar to the following example:

# show global-config filer
;============================ external-filer =============================

  external-filer testfiler
    cifs-port 445
    ip address 1.1.1.1
    exit
