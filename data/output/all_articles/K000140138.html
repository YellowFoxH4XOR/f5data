Description

You have found that you are receiving traffic from non-existing virtual server <TEST_VS>, which was deleted long time ago, and a new one created with the same IP address <PROD_VS>.

Environment

  • BIG IP
  • Syslog
  • UDP profile

Cause

Old connections remain and should be deleted from connection table:

You are using the same profile for the old and the new VIPs.

Looking to see if they sed the same profile for old and new VIP:

--- /config/bigip.conf 2024-06-04 20:29:58.000000000 +0300 <<<< Before new VIP created.
+++ /config/.diffVersions//config/bigip.conf/bigip.conf 2024-06-04 20:29:40.000000000 +0300
@@ -4969,11 +4969,11 @@ ltm virtual /Common/<TEST_VS> <<<<< Old VIP

Recommended Actions

As it mentioned in the following article: K3605

For the profile changes to take effect, you must clear all UDP connection entries from the connection table. To do so, you can either allow the connection to timeout, or you can perform the following procedures.

 

Removing a specific connection entry:

  1. Log in to the BIG-IP command line.
  2. To remove a specific connection entry, use the following command syntax:

    tmsh delete sys connection cs-client-addr <client IP address> protocol <protocol>

    For example:

    tmsh delete sys connection cs-client-addr 1.2.3.4 protocol udp

Removing all connection entries

  1. Log in to the BIG-IP command line.
  2. To remove all connection entries, type the following command:

    tmsh delete sys connection
