Known Issue

The BIG-IP ASM policy groups page is blank.

This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is configured with at least one policy group.
  • One or more of the policies in a policy group has the Application Security option disabled in the associated HTTP Class of that policy.

Impact

Users cannot view the BIG-IP ASM policy groups page, which means that users cannot manage policy groups.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you access the BIG-IP ASM policy groups section of the Configuration utility, no policy groups are displayed.

Workaround

To work around this issue, you can enable the Application Security option for the associated HTTP Class of the affected policy. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

Note: To view a list of inactive policies, navigate to Application Security > Security Policies > Policy List > Inactive Policies.

Important: Do not use the Active Policy button, which replaces the existing active policy. The proper procedure is to modify the disabled state of the associated HTTP class of that policy.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Server List.
  3. Select the virtual server.
  4. Under Resources, click Manage to right of HTTP Class Profiles.
  5. Move the HTTP Class from the Enabled column to the Available column.
  6. Click Finished.
  7. Navigate to Local Traffic > Profiles > Protocols.
  8. Click HTTP Class.
  9. Select the HTTP Class of the policy.

    Note: The associated policy name will be listed under Active Policy for the HTTP Class.
  10. Under Configuration, set Application Security to Enabled.
  11. Click Update.
  12. Once the HTTP class has been activated for Application Security, click Application Security.
  13. Click Security Policies.
  14. Click Policy Groups.
  15. Select the affected Policy Group.
  16. Select the affected policy from the Members column and move it to the Available column.
  17. Click Save.

After these changes have been implemented to the policy groups, you can disable the initially affected policies without impacting the policy groups display.
