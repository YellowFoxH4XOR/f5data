Known Issue

This is the result of a known issue. When the BIG-IP WebAccelerator is under high load, and closes a connection in the request queue without removing the connection from the processing queue, the BIG-IP WebAccelerator will report the following debug transaction message:

local/hostname debug WA Debug (20697): [ PvTransactionManager.cxx:247 releaseTransaction ] __getRefCount == [0x1] for [0xd53d46c8]

F5 Product Development tracked this issue as CR135673 and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Additionally, this issue has been fixed in Hotfix-BIGIP-10.1.0-3372.0-HF1 for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about the F5 hotfix policy, refer to K4918: Overview of F5 critical issue hotfix policy.
