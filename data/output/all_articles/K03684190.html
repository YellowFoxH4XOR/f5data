Known Issue

The BIG-IP system may cache Online Certificate Status Protocol (OCSP) responses with an incorrect cache duration.

This issue occurs when all of the following conditions are met:

  • You configure an OCSP Stapling profile and associate it with a Client SSL profile.
  • Your BIG-IP virtual server is configured with the Client SSL profile.
  • Your BIG-IP system receives a valid OCSP response from the configured OCSP server.

Impact

The cached OCSP responses expire sooner than expected. As a result, the BIG-IP system sends excessive requests to the OCSP server.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The OCSP server may observe excessive OCSP requests from the BIG-IP system.
