Topic

The BIG-IP APM Client Troubleshooting Utility (CTU) is a Windows client application. Administrators can download the CTU as a single file, f5wininfo.exe, from the BIG-IP system and distribute it to clients for the purpose of collecting diagnostic data and troubleshooting client issues.

Beginning in APM Clients 7.2.1.4, the CTU also includes a OPSWAT Endpoint Inspection report of the client device by default. This includes reports on firewall, antivirus, peer-to-peer software, patch management, hard disk encryption, antispyware, and Windows health agent.

Description

To download the CTU as a single file, perform one of the following procedures:

  • Download the CTU from the Configuration utility
  • Download the CTU from the BIG-IP APM system using a browser
  • Collect the CTU report on the client system

Download the CTU from the Configuration utility

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. In the upper-left corner, select the F5 logo to access the Welcome page.
  3. Under Downloads, select Client Troubleshooting Utility for Windows.
  4. Save the f5wininfo.exe file to a folder on the computer.

Download the CTU from the BIG-IP APM system using a browser

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. On the computer to be inspected, browse to the following HTTPS URL with a preferred web browser by substituting <fqdn or ip> with the fully qualified domain name (FQDN) or IP address of a virtual server on your BIG-IP APM system configured with an access profile:

    https://<fqdn or ip>/public/download/f5wininfo.exe

    For example:

    https://apm.example.com/public/download/f5wininfo.exe

  2. Save the f5wininfo.exe file to a folder on the computer.

Important: F5 may update the CTU between releases or within a release through a cumulative hotfix. You should ensure that you are using the latest version available by downloading it from the Configuration utility.

Collect the CTU report on the client system

Note: This report needs to be collected with elevated privileges. Right click f5wininfo.exe and select run as administrator.

When you open the file, a two-pane display window appears: the selection tree is in the left pane and the associated data in the right pane. This display provides information about the client components and their status as installed on the client machine.

Additional functionality is available from the CTU menu and includes the following options:

  • Diagnostic Report

    You can use these reports to assess the basic network health of the client machine as well as the F5 or Microsoft software components on the client machine. To start the Diagnostic Reports option, select File and select Generate Report. Afterwards, confirm the report was run with administrative access. Extract the f5report.html.gz then open f5report.html. It should state "*******   User has access: READ & WRITE to Registry CLASSES_ROOT\CLSID   *******".

  • Debug Logging

    This option enables detailed logging of all APM client software components for troubleshooting purposes. To start Debug Logging, select Tools and select Enable Logs.

  • Client software removal

    This option enables the user to remove all F5 client software from the computer. To remove components, select Tools from and select Remove Components. A pop-up window appears to confirm the removal.

    If the Edge Client was initially not correctly installed, connections and updates can result in Conflict folders. When removing the Edge Client please refer to K12988: The f5wininfo utility does not uninstall all BIG-IP Edge Client components

  • Network Access Diagnostic

    This option performs a real-time check of the network health of Network Access SSL VPN connection. To start the network access diagnostic, select Tools and select Network Access Diagnostic.
