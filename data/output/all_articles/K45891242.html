Known Issue

TMM may exit and produce a core file when processing a POST initiated access session.

This issue occurs when all of the following conditions are met:

  • An access session is initiated with a POST request.
  • The request header size exceeds 16384 bytes, or the request body size exceeds 64000 bytes.
Note: If both aforementioned size limits are exceeded, the TMM exit is prevented due to a protection.

Impact

The BIG-IP APM system is unable to process traffic while the TMM process is unavailable.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Users are unable to establish access sessions using the BIG-IP APM system.
  • Messages similar to the following example are logged to the /var/log/tmm file:

    notice ** SIGSEGV **
    ...
    notice RIP=0x6df367

  • A TMM core file is generated to the /shared/core directory.
  • The active unit in a high-availability system fails over to standby.
