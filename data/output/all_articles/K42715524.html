Description

Cannot access management IP address frequently, detect 2 MAC address for the management IP address on the MGMT interface.

Environment

  • BIG-IP
  • AOM

Cause

AOM IP address is same with management IP address.

Recommended Actions

Refer to Related Content, remove the AOM IP address or modify the AOM IP address.

None
