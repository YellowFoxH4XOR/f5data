Description

How to modify the HOST and SNI header to match a FQDN pool member's hostname via and iRule using Data-Groups

Environment

BIG-IP LTM

Cause

Looking to change the host header and SNI based on the FQDN pool member selected

Recommended Actions

This method uses a data-group with an iRule to achieve the wanted result

iRule:

when LB_SELECTED {
  # Retrieve the IP address of the selected pool member
  set server_addr [LB::server addr]

  # Log the IP address and port of the selected pool member
  log local0. "Selected pool member: $server_addr"

  # Retrieve the name of the selected server in the load-balancing pool
   set server_name [LB::server name]

  # Log the original Host header and the selected server name for debugging purposes
  log local0. "Original Host: [HTTP::host], Selected Server: $server_name"

  # Retrieve the FQDN based on the IP address from the data group
  set server_fqdn [class lookup $server_addr ip_to_fqdn_dg]

  # Sets the sni_value to the Pool Members FQDN
  set sni_value $server_fqdn

  if { $server_fqdn ne "" } {
       # Log the FQDN of the selected pool member
       log local0. "Selected server FQDN: $server_fqdn"
     } else {
       log local0. "No FQDN mapping found for IP address: $server_addr"
     }
       # Rewrite the Host header to be the name of the selected server
       HTTP::header replace Host $server_fqdn
     
       # Log the new Host header for verification
       log local0. "New Host: [HTTP::header Host]"
}

when SERVERSSL_CLIENTHELLO_SEND {
  # Set the CLIENT HELLO SNI to Pool Member FQDN
  SSL::extensions insert [binary format SSScSa* 0 [expr { [set sni_length [string length $sni_value]] + 5 }] [expr { $sni_length + 3 }] 0 $sni_length $sni_value]
}

---

Data-Group (Example):

ltm data-group internal ip_to_fqdn_dg {
  records {
    10.101.151.2 {
      data two.example.local
    }
    10.101.151.3 {
      data three.example.local
    }
  }
  type string
}
