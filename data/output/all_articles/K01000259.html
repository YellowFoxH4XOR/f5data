Known Issue

A Traffic Management Microkernel (TMM) memory leak may occur when the Dynamic Host Configuration Protocol (DHCP) proxy is set to Forward mode.

This issue occurs when all of the following conditions are met:

  • You have configured your BIG-IP PEM system to use DHCP to discover subscribers.
  • You have configured the DHCPv4 profile to use Forward mode.
  • A DHCP relay agent forwards DHCP client packets to your BIG-IP PEM system and sets itself to the gateway IP address (giaddr) in the DHCP renewal packet.
  • The connection to the DHCP relay agent times out before a connection is created to the DHCP client.

Impact

The BIG-IP system will not process traffic while TMM restarts and if the BIG-IP system is in a high availability (HA) configuration, a failover will occur.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • Your BIG-IP system fails to process traffic for a brief period of time.
  • Your BIG-IP system fails over to another host in the device group.
  • TMM generates a core file in the /var/core directory.
