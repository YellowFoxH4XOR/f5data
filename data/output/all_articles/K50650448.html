Description

When updating an iApp by using the Reconfigure tab (for example, adding a second or third server's IP address in the Exchange iApp) you receive the following error message.
script did not successfully complete: (field not present: "address" while executing "tmsh::get field_value $node address"...)

Environment

  • BIG-IP version 13 or later
  • iApp template version: f5.microsoft_exchange_2010_2013_cas.v1.3.0

Cause

The iApp template is out-of-date, which may not support a newer version of BIG-IP such as version 13 or later.

Old Template 
Versionf5.microsoft_exchange_2010_2013_cas.v1.3.0
Last-ChangedApril, 2014
Tested Versions11.3, 11.4, 11.4.1, 11.5, 11.5.1
 
Newer Template
 
Versionf5.microsoft_exchange_2010_2013_cas.v1.6.2
Last-ChangedJune 2017
iApp RequiresBIG-IP version 11.3 - 13.0 or later


Recommended Actions

It is recommended to update the latest iApp template v1.6.2 and follow the procedure in the following article to update your iApp

K20136220: Updating an iApp to a newer version
 
After updating the iApp template, you may add the new server's IP address in the Reconfigured button successfully.
