Description

You are inquiring about the possibility of modifying the default learning length time for the Behavioral DoS (BDoS) feature within Application Firewall Manager (AFM). By default, the learning phase is set to 120 minutes, and you wish to know if and how this value can be adjusted to fit your specific requirements.

Environment

  • AFM (Application Firewall Manager) with Behavioral DoS (BDoS) feature enabled
  • Dynamic Signatures learning phase configured

Cause

None

Recommended Actions

To adjust the learning phase period for the BDoS Dynamic Signatures feature, follow these steps:

  1. Log in to the TMOS Shell (TMSH) on your AFM device.
  2. Enter the following command to modify the learning phase period:
    tmsh modify sys db l4bdos.baseline.learning.period value <nn>
    Note: Replace <nn> with the number of minutes you want the learning phase period to run.
  3. After adjusting the period, you can select Start Relearning in the Configuration utility to restart the learning phase.For testing or operational purposes, modifying the learning length time allows you to tailor the learning phase to better align with your network traffic patterns and security requirements.

Additional Information

The learning phase is an integral part of the BDoS feature, enabling the system to establish a baseline of normal traffic behavior. Adjusting this period can be beneficial in environments where traffic patterns change frequently or during initial setup when you may require a shorter period to expedite the learning process.
