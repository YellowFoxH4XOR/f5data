Description

"Content-Encoding" header is removed when forwarding HTTP response from server to client.
Server does provide compressed response (for example: Content-Encoding:gzip) however this header is removed by BIG-IP LTM when Rewrite profile is in use.
This may result in client performance impact.

Environment

  • BIG-IP LTM 14.1.x
  • Rewrite profile

Cause

This is expected behaviour.
BIG-IP LTM will remove compression header (Content-Encoding) from HTTP response if Rewrite profile is used.

Recommended Actions

In order to pass compressed content to client you can configure HTTP Compression profile:
  • K15434: Overview of the HTTP Compression profile
