Environment

BIG-IP ASM is provisioned

Cause

The full /var filesystem causes problems with the bd process. F5 is tracking this as Bug ID 712336: bd daemon restart loop.

Recommended Actions

  1. Use the following command, to identify large files in /var/ and its subdirectories: "find /var/ -xdev -type f -exec du {} \; | sort -rn | head -20"
  2. Delete unnecessary files, such as any backup files (found in /var/local/ucs/)
  3. Restart ASM with the command 'bigstart restart asm'
