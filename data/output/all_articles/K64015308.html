Description
IP's could change from one country to another from time to time. Hence why F5 recommends making sure geolocation is up to date.
Now more and more customers are asking how often F5 updates the database.

Environment
All BIG-IP systems using IP geolocation database provided on the F5 Downloads site

Cause
Per K12866, F5 will make updates available for the IP geolocation database on the Tuesday after Digital Element confirms an update is available.
Per confirmation with Digital Element,  "We create new databases each week and send those to F5 every Monday morning". Hence, we will provide IP Geolocation updates every Tuesday. 

Note:  F5 tries to release the new database every Wednesday; however, when there is a build failure internally at F5, a weekly release may be delayed, or can be skipped unexpectedly.  Please check https://downloads.f5.com/ for availability.
