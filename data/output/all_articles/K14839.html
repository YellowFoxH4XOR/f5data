Policy Information

The F5 LineRate product adheres to industry standard software practices in order to provide software and configurations that are secure, by default. F5 is committed to responding quickly to potential vulnerabilities in our products. F5 appreciates the opportunity to work with our customers, independent and corporate researchers, industry representatives, and network/application security professionals, to identify potential vulnerabilities.

This article defines the F5 security vulnerability response policy.

Reporting suspected vulnerabilities

If you are an F5 customer with an active support contract, please open a case with F5 Technical Support.

If you are not an F5 customer, please send details of the suspected vulnerability to security-reporting@f5.com.

An F5 engineer will work with you to gather the necessary details and determine an appropriate course of action.

In cases where the reporter of a vulnerability has provided information to F5 prior to public release, F5 will provide attribution as part of an F5 public statement, at the reporter's request.

Vulnerability Categories

F5 investigates and prioritizes reports based on their potential exploitability. F5 divides security vulnerabilities into the following three categories for resolution:

  • Not vulnerable

    A product declared by F5 as not vulnerable cannot be exploited through the mechanism listed. If the product is running a potentially vulnerable version of the software, a hotfix may have been applied without changing the version number of the affected software, or the affected functionality may not be compiled in the software. Most advisories list only software versions that are potentially vulnerable and do not account for compilation time differences.

  • Local vulnerabilities

    Many security vulnerabilities are local vulnerabilities, which means they can only be exploited to gain root access or privilege escalation when already properly authenticated to an F5 device. F5 provides a fix for these vulnerabilities in the next release of the affected product.

  • Remote vulnerabilities

    Remote vulnerabilities are security vulnerabilities that can be exploited without being authenticated by a unit. Remote vulnerabilities may result in Denial of Service (DoS), remote login, data corruption, or misdirection of network traffic. F5 provides a security hotfix for these vulnerabilities in accordance with the security hotfixes section below.

Security Updates

F5 is committed to evaluating software based on the version of software that F5 LineRate is currently shipping at the time of public disclosure of the issue. F5 evaluates the version of software that F5 LineRate is currently shipping and two minor versions back.

When remote vulnerabilities are discovered, F5 implements, tests, and releases security updates for the latest version of a supported Major Release of software and the two previous versions.

Security updates released by F5 for LineRate 2.x and beyond are cumulative for all updates produced up to the creation of that update. When a security update is released, it will contain all other security-related updates and stability-related updates since the last software release.
