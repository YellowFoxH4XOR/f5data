Description

After upgrading the BIG-IP system from earlier versions to 14.x ISO image,

  • tomcat service keeps restarting by showing "Error message "logger[<PID>]: Re-starting tomcat"
  • GUI will not accessible
  • Device will be "INOPERATIVE" during the time of issue.
     

Environment

  • BIG-IP LTM
  • Software upgrade
  • tomcat daemon
  • Configuration Utility

Cause

You observe in the /config/bigip.conf file that an authentication source is defined but no corresponding definition for that authentication is defined. For example, when you configure remote TACACS+ authentication on the system, the following objects should be created in the /config/bigip.conf file:

auth source {
    type tacacs
}
auth tacacs /Common/system-auth {
    secret $$COMPLICATEDENCRYTPED=
    servers { 1.1.1.1 }
    service tacacsserver
}

This issue can arise when the auth source object is defined but the auth tacacs /Common/system-auth object is not defined in the /config/bigip.conf file.

Recommended Actions

Please follow the below procedure to resolve the issue.

  1. Return to the previous boot location of the previous software code.
    #tmsh reboot volume <OLD_VOLUME>
    Example command
    #tmsh reboot volume HD1.1

  2. Change the authentication type from Remote to Local.
    #tmsh modify auth source type local
    #tmsh save sys config

  3. Copy the configuration from a source boot location to a target boot location and immediately reboot to the specified target partition using the following command syntax:

    #cpcfg --source=SLOT --reboot <destination_location>

    The following example shows the command to copy the configuration from boot location HD1.2 (BIG-IP 11.3.0) to boot location HD1.3 (BIG-IP 11.4.0) and immediately reboot the system to the HD1.3 boot location:

    #cpcfg --source=HD1.2 --reboot HD1.3

  4. Boot back to the new volume.
    #tmsh reboot volume <NEW_VOLUME>

  5. Verify if GUI is accessible after executing the above commands.

  6. Revert back to the previous remote authentication configuration.
