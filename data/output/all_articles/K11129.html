Topic

BIG-IP database monitors are not compatible with IPv6 addresses. As a result, the following database monitor types will fail to connect to an IPv6 database server and mark the member as down:

  • Oracle
  • MSSQL
  • MySQL
  • PostgreSQL

For example, the Oracle database monitor will fail to connect to an Oracle service that is hosted on an IPv6 server. As a result, the BIG-IP system will mark the member as down. The Oracle monitor verifies the availability of an Oracle service by running a userland program that relies on the Java Database Connectivity (JDBC) API. The BIG-IP system uses a version of the Oracle JDBC driver that is incompatible with IPv6. When the Oracle monitor attempts to connect to an Oracle service through IPv6, and debugging is enabled in the monitor configuration, you may observe error messages in the /var/log/DBDaemon.log file that appear similar to the following example:

jdbc:oracle:thin:@2620:0:c10:f501:0:a:a00:14:1521:(Thread-59114): getConnection (Invalid connection string format, a valid format is: "host:port:sid" )

Note: This issue affects the ability of the BIG-IP system to monitor a database service using only the BIG-IP database monitor. You may still load balance traffic to the database service deployed in an IPv6 environment or in a non-default route domain. However, you will have to verify the availability of the database service using a monitor other than the BIG-IP database monitor.
