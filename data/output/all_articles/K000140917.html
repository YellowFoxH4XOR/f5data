Description

There are are cases when a BIG-IP device that is part of a BIG-IP DNS iQuery mesh may send what appears as unexplained ICMP (ping) echo requests originating from the BIG-IP device's self-IP going. This can sometimes trigger a firewall rule match or an intrusion detection system and would appear as an attack.

Environment

  • BIG-IP DNS iQuery Mesh
  • BIG-IP DNS Pool with Dynamic Load Balancing 

Cause

  • After a DNS client (or LDNS) sends a query towards the BIG-IP DNS that hits a gtm pool, path metrics will be collected by big3d agents in the BIG-IP DNS mesh when dynamic load balancing (eg. lowest round trip time) is configured on the BIG-IP DNS. See K6480: Understanding LDNS probing.

Recommended Actions

  • Check if there is any BIG-IP gtm pool that is using any of the dynamic load balancing methods (eg. lowest round trip time, least connections, etc.) . Sample command that can be used would be similar to the following:

    tmsh list gtm pool <DNS RR Type> load-balancing-mode

    Where <DNS RR Type> would be any of the DNS resource record types (eg. a, aaaa, cname, etc.). For example, if we are to check the load-balancing mode for A RR pools, the command would be:

    tmsh list gtm pool a load-balancing-mode

    An example of a pool that uses dynamic load balancing method would be similar to the following:

    gtm pool a testGtmPool {

       load-balancing-mode lowest-round-trip-time

    }

  • Confirm that the probes are due to BIG-IP DNS path metrics collection for the target IP address using the command 'tmsh show gtm path'. An output similar to the following should indicate that path metrics have been collected for IP address 10.10.24.109 after it sent a DNS query:

    root@(bigip1)(cfg-sync Standalone)(Active)(/Common)(tmos)# show gtm path
    ------------------------------------------------------------
    Gtm::Path: 10.10.24.109:datacenter:DC1
    ------------------------------------------------------------
    Statistics              Current Average   Last Probe Time
     Round Trip Time (RTT)     918     918 08/27/24 18:34:41
     Hops                        0       0                 -
     Completion Rate           100     100                 -
