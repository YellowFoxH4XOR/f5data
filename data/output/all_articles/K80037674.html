Description

You are are looking for button on the Configuration Utility to expand all lists under Shared Objects

Environment

  • BIG-IP
  • Shared Object lists

Cause

Expand all button was removed from the Configuration Utility to prevent performance issues when expanding lists containing potentially thousands of items

Recommended Actions

None

Additional Information

in 14.x the Configuration Utility was re-organized to locate IP and port address lists under the Shared Objects section
