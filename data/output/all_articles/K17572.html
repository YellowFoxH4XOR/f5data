Known Issue

The BIG-IP ASM bd process may restart and produce a core file when processing a binary file. This issue occurs when all of the following conditions are met:

  • The BIG-IP ASM system is running BIG-IP ASM 11.5.1 HF5.
  • A security policy has a parameter defined with either of the following:

    • The Parameter Value Type is set to Ignore value.
    • The Parameter Value Type is set to User-input value and the Data Type is set to File Upload.

Impact

The BIG-IP ASM system temporarily fails to process traffic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The BIG-IP ASM system generates a bd core file to the /shared/core directory.
