Description

You are installing the nCipher (formerly Thales) HSM client on BIG-IP and get the following error message when running the nethsm-thales-install.sh script:
 

# nethsm-thales-install.sh --hsm_ip_addr=10.10.10.10 --rfs_interface=Internal
This utility will cause changes to the BIG-IP config. Do you want to continue? (Yes/No) : Yes
ERROR: Thales HSM partition name is required.

Environment

  • BIG-IP
  • nCipher netHSM
  • nethsm-thales-install.sh

Cause

From BIG-IP v14 and above you also need to specify the --hsm_partition_name

Recommended Actions

Specify the hsm partition name for use.  For example you may specify the default hsm partition name "loadshared accelerator" (no password)

# nethsm-thales-install.sh --hsm_ip_addr=10.10.10.10 --rfs_interface=Internal --hsm_partition_name="loadshared accelerator"


Additional Information

See nethsm-thales-install.sh --help

Example output:
