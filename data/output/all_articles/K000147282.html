K000147282: Issue: Sign in with Okta is not working

Type
Support Solution
Published
2024-11-08
Updated
2025-02-20
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147282

Description

  • I was invited to use the F5® Distributed Cloud Console
  • My account was just created
  • When I try to log in with Okta nothing happens
  • The URL has an error: 
    error=access_denied&error_description=User+is+not+assigned+to+the+client+application

Environment

  • Account Management

Cause

  • You either have no valid credentials at Okta or
  • You have not been added to the allowed list of users for this application in Okta 

Resolution/Answer

  • Contact your Okta administrator/support team 

Additional Information
