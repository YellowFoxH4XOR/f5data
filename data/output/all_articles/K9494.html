Topic

FirePass supports the ability to use Client Certificate authentication where the client certificate can be authenticated using a Certificate Revocation List (CRL). The CRL is always issued by the Certificate Authority (CA), which issues the corresponding certificates. In addition, FirePass supports the ability to supply multiple CRLs. In the event a single CRL be unavailable, alternate CRLs can be used to verify the client certificate.

Configuring multiple Certificate Revocation Lists

To configure multiple CRLs, perform the following procedure:

  1. Navigate to the Client CRL On-Line Update section of the Device Management: Security: Certificates page.
  2. To add a URL for the CRLs to be retrieved from, select the Automatically retrieve CRLs from URLs check box
  3. Click Update.
  4. When prompted, insert the URL and define the CRL Retrieval Time and the CRL Retrieval Frequency.
  5. Click Update.

    You will be given the option of creating another URL.

Important: While FirePass permits the usage of multiple CRLs, the URL used for the CRLs (individual or combined CRLs) is limited to an approximate of 8000 characters.
