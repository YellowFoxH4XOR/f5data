Issue

Error Message

Error Message: GTM request rate limiter engaged.

For example:

warning statsd[6916]: 011b0911:4: GTM request rate limiter engaged
warning statsd[6916]: 011b0912:4: GTM request rate limiter disengaged

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The BIG-IP GTM RPS license limit has been exceeded.

The BIG-IP GTM system is licensed to provide a maximum number of GTM WideIP requests processed on a per second (RPS) calculation. These specific limits are determined by the license on the BIG-IP GTM system.

Impact

  • When the BIG-IP GTM RPS license limit has been exceeded, the system drops subsequent requests until the number of requests falls below the RPS threshold.
  • The GTM request rate limiter engaged error message appears in the /var/log/ltm log file when the RPS limit has been exceeded.
  • The GTM request rate limiter disengaged error message appears in the /var/log/ltm log file when RPS returns within the licensed limit.

Recommended Actions

You can view the licensed DNS rate limit (RPS) statistics using the tmsh show ltm profile dns dns command. The Licensed Service Rates section of the command output appears similar to the following example:

tmsh show ltm profile dns dns
Licensed Service Rates             DNS    GTM
  Effective Rate Limit (RPS)        50     25
  Configured Object Count            1      7
  Rate Rejected Requests         19989   1162

The licensed BIG-IP GTM (RPS) rate limit can also be found in the /config/bigip.license file by typing the following command:

cat /config/bigip.license | grep gtm_rate_limit

The output of the command appears similar to the following example:

gtm_rate_limit : 25

F5 recommends that you monitor traffic volumes to allow the license limit to be proactively managed. If the rate limit warnings persist, you can contact your F5 Sales representative about acquiring an update to the license, allowing a higher threshold. Additionally, you can configure the BIG-IP system to send SNMP traps and email messages to a specified address whenever the system logs a message as a result of reaching the RPS limit. For information about these notification and email message options, refer to the Supplemental Information section.
