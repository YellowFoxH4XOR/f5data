Known Issue

This is the result of a known issue. FirePass uses ClamAV version 0.93 as its antivirus (AV) engine. As of April 15, 2010, ClamAV has stopped providing support for ClamAV versions prior to 0.95. As a result, updating to a daily.cvd file later than April 14, 2010 causes the FirePass AV to shut down.

Note: If the AV engine is shut down, files still transfer through FirePass; however, AV scanning is disabled.

Note: For more information about ClamAV's announcement ending support for older versions, refer to the following ClamAV document. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

End of Life Announcement: ClamAV 0.94.x

F5 Product Development tracked this issue as ID 294338 (formerly CR136752) and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass release notes.

This issue has been fixed in point hotfix hotfix-136752-1, which has been issued for FirePass versions 6.1.0, 5.5.2, 5.5.1, and 5.5. You may download this hotfix or later versions of the point hotfix from the F5 Downloads site.

Workaround

To determine whether you are affected by this issue, verify the version of the installed daily.cvd file. To do so, perform the following procedure:

  1. Log in to the FirePass controller.
  2. Click Portal Access.
  3. Click Content Inspection.
  4. Click the AntiVirus tab.
  5. In the Virus Database section, view the date of the daily.cvd file.

    If the date is later than April 14, 2010, you are affected by this issue.

If you are affected by this issue, you can use one of the following three workarounds:

Disabling AntiVirus scanning

Configuring FirePass as an ICAP client

Rolling back the daily.cvd database to a version prior to April 15, 2010

Disabling AntiVirus scanning

  1. Log in to the FirePass controller.
  2. Click Portal Access.
  3. Click Content Inspection.
  4. Click the AntiVirus tab.
  5. Select the Disable Virus Scanning button.
  6. Click Update.

Configuring FirePass as an ICAP client

Note: In this procedure, F5 assumes you already have an ICAP server system in place.

  1. Log in to the FirePass controller.
  2. Click Portal Access.
  3. Click Content Inspection.
  4. Click the AntiVirus tab.
  5. Select the Enable ICAP Client button.
  6. Click Update.
  7. Type the name of your ICAP host server in the ICAP Server Host: text box.
  8. Click Update.

Rolling back the daily.cvd database to a version prior to April 15, 2010

Note: In this procedure, F5 assumes the Enable Standalone Virus Scanner option is already selected. 

Important: You need to locate a ClamAV daily.cvd file that is dated prior to April 15, 2010 to complete this procedure.

  1. Log in to the FirePass controller.
  2. Click Portal Access.
  3. Click Content Inspection.
  4. Click the AntiVirus tab.
  5. In the Virus DataBase Update section, select the Manual update button.
  6. In the Virus DataBase section, click the Browse button on the daily.cvd line.
  7. Browse to your pre April 15, 2010 daily.cvd file.
  8. Highlight your daily.cvd file.
  9. Click Open.
  10. Click Upload.

    After the file uploads, you see the updated date of the daily.cvd file you just uploaded, and the status of the Virus Scanner now shows Standalone Virus Scanner is running.

Note: For more information about using FirePass as an ICAP client, refer to the FirePass Controller Administrator Guide.
