Known Issue

The BIG-IP system may log Tool Command Language (Tcl) error messages after processing an iRules CLIENT_DATA event.

This issue occurs when all of the following conditions are met:

  • The affected iRule is associated with a User Datagram Protocol (UDP) or TCP virtual server.
  • The affected virtual server is configured with a pool resource.
  • The virtual server is configured with an iRule that uses the CLIENT_DATA event.

Note: The UDP or TCP connections of the iRule may continue to work as expected for the CLIENT_DATA event; however, the BIG-IP system logs a Tcl error message.

Impact

Logged Tcl error messages may cause confusion, resulting in the log file filling up quickly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • After handling a CLIENT_DATA event, the BIG-IP system fails to check the Tcl return value of the iRule.
  • In the /var/log/ltm file, you observe error messages that appear similar to the following example:

Workaround

To work around this issue, you can use the CLIENT_ACCEPTED event in your iRule instead of the CLIENT_DATA event.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
