Description

You would like to protect against Server-Side Request Forgery (SSRF) using BIG-IP AWAF/ASM.

Environment

  • BIG-IP AWAF/ASM

Cause

None

Answer/Recommended Actions

BIG-IP Advanced WAF 16.1.0 and later versions include SSRF protection.

For configuration guidance, refer to the Mitigating Server-Side Request Forgery chapter in the BIG-IP Application Security Manager: Implementations manual.

Identify parameters with the data type URI that may be subject to SSRF attacks. You can explicitly define these URI parameters in the security policy or use the Auto-detect Parameter feature to automatically detect URI parameters in the application.

From these parameters, identify the specific hosts to which access should be disallowed. Then, in the security policy under Advanced Protection > SSRF Protection, add these specific hosts, either IP addresses or hostnames, to the SSRF Hosts list.

Additional Information

BIG-IP ASM includes attack signatures that can detect SSRF attempts using regex matching. However, signatures alone cannot fully prevent SSRF, because SSRF abuses the application’s own legitimate functionality.

Attack signatures are designed to detect known malicious patterns, but an SSRF request may contain a seemingly valid URL that causes the application to access an unintended internal or external resource. For example, matching only RFC1918/private IP addresses may result in both false positives and false negatives.

DNS also makes SSRF detection more difficult. An attacker can use a domain name that resolves to a public IP initially, and later repoint it to an internal IP address. This type of behavior cannot be reliably detected by static signature patterns.

Therefore, the dedicated BIG-IP ASM SSRF Protection feature allows users to maintain a positive security model. Administrators can define an allow/deny list of permitted hosts for specific HTTP elements. The feature then parses the URL, resolves the hostname through DNS, and checks the resulting IP address against the configured SSRF host list.
