Description

Deploying BIG-IP using shared VPC on Google Cloud fails.

Environment

  • Shared VPC on Google Cloud Platform
  • BIG-IP
     

Cause

Shared VPCs on Google Cloud are not supported in f5-google-gdm-templates prior to v3.6.0. 

Recommended Actions

F5 Networks added support for shared VPCs in GCP from v3.6.0.  Please follow the release notes page of future releases and use the latest versions for your deployment.
