K000157954: F5OS GUI still displays the previous menu content after an upgrade

Type
Support Solution
Published
2025-11-25
Updated
2025-11-25
Applies to
  • F5OS
  • F5OS-A: 1.8.3
Source
https://my.f5.com/manage/s/article/K000157954

Description

You may notice that F5OS GUI still displays the previous menu content after an upgrade.

Environment

  • F5OS
  • GUI

Cause

Client browser cache is still storing older version GUI content.

Recommended Actions

Clear the client browser cache, then re-access the GUI.

Additional Information

None.
