Known Issue

This is the result of a known issue. If you are replacing an expired SSL certificate on the BIG-IP system, and the new certificate name is the same as the existing certificate, the BIG-IP system may not use the new SSL certificate until the configuration is reloaded or the SSL profile(s) is updated.

F5 Product Development tracked this issue as ID 248109 (formerly CR60320) and it was fixed in BIG-IP 11.0.0. For information about upgrading, refer to the LTM, ASM, PSM, WebAccelerator, WOM, or Edge Gateway release notes.

Workaround

To prompt the SSL profiles to use the new SSL certificate, you can either update each SSL profile that references the SSL certificate or reload the BIG-IP configuration.

Updating the SSL profiles

  1. Log in to the Configuration utility.
  2. In the main navigation panel, select Local Traffic.
  3. In the Virtual Servers sub-menu, select Profiles.
  4. In the upper right portion of the screen, select Client or Server from the SSL drop-down menu.
  5. Select an SSL profile.
  6. Click the Update button, even though you did not make any changes.
  7. Repeat steps 4 through 6 for each SSL profile that uses the renewed certificate.

All SSL virtual servers that use the updated SSL profile will now use the correct certificate.

Reloading the configuration

To reload the configuration, type the following command:

bigpipe load
