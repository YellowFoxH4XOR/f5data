Known Issue

Creating a custom report using the BIG-IP APM system may fail.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM device software has recently been installed or upgraded.
  • You attempt to create a custom report using the BIG-IP APM Configuration utility.

Impact

The Create the Design Custom Report web page does not render correctly.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you access the custom report web page and click Create the Design Custom Report, a pop-up window displays. However, the Available Fields folder spawns indefinitely and the Configuration utility becomes unresponsive.
  • The listed tables do not include the log_param_metadata_ui table when you run the following SQL query from the command line of the affected device:

    mysql -uroot -p`perl -MPassCrypt -nle 'print PassCrypt::decrypt_password($_)' /var/db/mysqlpw` -e 'use apm; show tables;'

Resolution

Status

F5 Product Development has assigned ID 451777 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.6.0
11.5.2		K2200: Most recent versions of F5 software
Hotfix11.5.1 HF5
11.4.1 HF10
11.4.1 HF6
11.4.0 HF8		K9502: BIG-IP hotfix matrix

Note: This issue is fixed in 11.4.1 HF6, 11.4.1 HF7 and 11.4.1 HF8. However, 11.4.1 HF9 introduces a regression where the issue reoccurs.

Workaround

There is no workaround for this issue. F5 recommends that you reinstall the BIG-IP software version. For more information, refer to K3621: Reinstalling BIG-IP LTM, ASM, GTM, PSM, APM, WOM, Link Controller, WebAccelerator, or Edge software.

Impact of workaround: The system will replace the current software image, and you have to configure the system or recover the configuration from backup.
