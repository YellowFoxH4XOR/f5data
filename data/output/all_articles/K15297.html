Known Issue

When using the Configuration utility, you cannot disable (clear) the Include Cluster option after you have enabled (selected) it.

This issue occurs when all of the following conditions are met:

  • The VIPRION system is configured as part of a high availability (HA) group.
  • You have enabled the Include Cluster option in the HA Group configuration.
  • You attempt to disable the Include Cluster option for the affected HA group using the Configuration utility, by navigating to System > High Availability > HA Group List.

Impact

You cannot disable the Include Cluster option on the affected HA Group configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you attempt to disable the Include Cluster option using the Configuration utility, you observe the following symptoms:
    • You cannot disable the Include Cluster option using the Configuration utility on the affected HA group; the Include Cluster option remains selected, even after you have cleared it and clicked Save.
    • In the /var/log/ltm log file, you observe an error message similar to the following example:

      err mcpd[5843]: 01070265:3: The cluster (default) cannot be deleted because it is in use by a HA group cluster (VipGroup1 default).

Workaround

To work around this issue, you can use Traffic Management Shell (tmsh) to remove the cluster from the HA group. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To remove the Include Cluster option, use the following command syntax:

    modify /sys ha-group <HA-Group-Name> clusters delete { all }

    For example:

    modify sys ha-group VipGroup1 clusters delete { all }

  3. Save the configuration by typing the following command:

    save /sys config

  4. Exit the tmsh utility by typing the following command:

    quit
