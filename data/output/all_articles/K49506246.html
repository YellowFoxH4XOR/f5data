Description

You encountered an error message similar to the following example displayed below:

  • Syntax Error:(/config/bigip_base.conf at line: 606) "log-level" invalid value "}", expected one of the following: "critical" "debug" "error" "informational" "notice" "warning"

Environment

  • BIG-IP
  • CSYNCD
     

Cause

This is the result of a known issue. You should not set the LIND, CSYNCD, or CLUSTERD logs to the Emergency or Alert logging levels from the GUI. 
Note: The CLUSTERD log only applies to VIPRION systems.

Recommended Actions

If you encounter the issue while still having a GUI access:

  1. Log in to the Configuration utility.
  2. Go to System > Logs > Configuration > Options > CSYNCD.
  3. Select either Critical, Error, Warning, Notice, Informational or Debug.
  4. Select Update.

If you encounter the issue without having a GUI access - this may happen during reboot when the configuration didn't load successfully and the mcpd is not running.

  1. Log in to the BIG-IP command line.
  2. Edit the /config/bigip_base.conf file using the text editor of your choice.
  3. Locate the stanza for the affected configuration.
    For example, at line: 606 the csyncd has no log-level value:
    sys daemon-log-settings csyncd {
        log-level          <<<<<==========
    }
  4. Include the valid value (Critical, Error, Warning, Notice, Informational or Debug)
    For example, you want to use critical as csyncd log-level value:
    sys daemon-log-settings csyncd {
        log-level critical
    }
  5. Save the changes and exit the text editor.
  6. Reload the configuration by running the following command:
    tmsh load sys config
 

    Additional Information

    Using tmsh, you can only set the csyncd log-level value to either Critical, Error, Warning, Notice, Informational or Debug. If you set it to Emergency or Alert, it will throw an error.

    root@(BigIP-A)(tmos)# modify sys daemon-log-settings csyncd log-level emergency
Syntax Error: "log-level" invalid value "emergency", expected one of the following: "critical" "debug" "error" "informational" "notice" "warning"
