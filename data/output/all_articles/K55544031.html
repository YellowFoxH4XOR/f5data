Issue

Error Message

err tmm[<PID>]: 01010216:3: DNSSEC: Signature failed (<action>) for RRSET (<RRSET_info>) with key <signing_key>, generation <gen_number>.

In this error message, note the following:

  • <PID> is the process ID for the tmm process.
  • <action> is the domain name system security extensions (DNSSEC) failed signing action.
  • <RRSET_info> is the DNS resource record set (RRSET) information.
  • <signing_key> is the signing key used in the DNSSEC transaction.
  • <gen_number> is the signing key generation number.

For example:

err tmm[8484]: 01010216:3: DNSSEC: Signature failed (signature creation) for RRSET (www.example.com, 1) with key /Common/examplezsk, generation 1.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • The BIG-IP system is under memory pressure.
  • The BIG-IP system experiences heavy traffic load.

Impact

DNS fails to resolve due to the incompleted RRSET signing action.

Recommended Actions

You can use Linux utilities, such as top, to see if the BIG-IP system is experiencing memory pressure. If the BIG-IP system is exhausting available system resources, you should use the qkview utility to generate a QKView file and contact F5 Technical Support for troubleshooting assistance. For more information, refer to the following articles:
  • K12878: Generating diagnostic data using the qkview utility
  • K2633: Instructions for submitting a support case to F5
