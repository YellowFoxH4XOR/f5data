Description

After re-scheduling the daily start time for the datasyncd process, you observe high CPU utilization for longer hours than before.

Environment

  • BIG-IP ASM
  • High CPU Utilization

Cause

When changing the daily start time for datasync Background Tasks, a new datasync global-profile is created with the default configuration (and the activation epoch chosen). The profile is active from the activation epoch chosen (and immediately starts generating rows). Therefore, after changing the activation epoch - all profile configuration is reset to default - including the "max rows". Initially, datasyncd would try to create 1001 rows (the default maximum), hence the activity would take longer to complete. However, the CPU usage would return to normal once the correct maximum rows has been calculated.
