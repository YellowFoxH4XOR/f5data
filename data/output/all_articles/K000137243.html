K000137243: Offline Installation of NGINX Agent

Type
Support Solution
Published
2023-10-15
Updated
2025-06-11
Applies to
  • NGINX Products
  • NGINX Agent
Source
https://my.f5.com/manage/s/article/K000137243

Description

  • You installed and configured NGINX Management Suite [NMS]
  • You wish to start managing NGINX instances 
  • But you are required to add these NGINX instances in OFFLINE mode
  • And that you are unable to run NGINX Agent install script "curl -k https://<NMS IP address>/install/nginx-agent | sudo sh"

Environment

  • NGINX
  • NGINX Management Suite
  • NGINX Instances Manager

Cause

  • Nginx Agent install script requires Online access

Recommended Actions

Verify OS version

  • Determine your Operating system and version
    • cat /etc/oc-release

GitHub

  • next navigate to GitHub, https://github.com/nginx/agent/releases
  • download the package relevant to your environment onto your local system
  • copy the package to your Nginx Instance host system using your preferred file transfer tool

Nginx

  • SSH the host system in which Nginx is installed
  • To install NGINX Agent on your system, follow procedures provided here

Association of NMS with Nginx instance

  • Modify /etc/nginx-agent/nginx-agent.conf file to append NMS management IP address
  • Insert the below line
          # specify the server grpc port to connect to
          server:
            # host of the control plane
            host: <NMS IP address>
            grpcPort: 443
          # tls options
          tls:
            # enable tls in the nginx-agent setup for grpcs
            # default to enable to connect with tls connection but without client cert for mtls
            enable: true
            skip_verify: true
  • save and exit
  • restart NGINX Agent
    • sudo systemctl start nginx-agent
