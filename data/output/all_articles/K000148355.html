Description

Modifications to cron job scripts inside the directories mentioned below, seem to only be applied to one slot on a VIPRION system with multiple slots.

  • /etc/cron.hourly
  • /etc/cron.daily
  • /etc/cron.weekly
  • /etc/cron.monthly

Environment

  • cron jobs
  • VIPRION

Cause

The csyncd daemon, which synchronizes certain files and directories across blades, does not by default monitor the aforementioned directories.

Recommended Actions

You may wish to make the same changes on other slots, or copy the scripts from the primary slot to the other ones.

 

For example, if you are following the steps on article Removing the ca-bundle.crt from SSL certificate expiration email alerts, and made changes to /etc/cron.weekly/5checkcert on the primary slot, you may copy it onto the others:

 

scp /etc/cron.weekly/5checkcert root@slotY:/etc/cron.weekly/5checkcert

 

(Replace Y with the slot number. Repeat for each of the other slots).
