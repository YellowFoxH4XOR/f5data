Known Issue

The Configuration utility may not allow the SSL Client Certificate LDAP (ssl-cc-ldap) Authentication Configuration to include the port number of the LDAP server.

This issue occurs when all of the following conditions are met:

  • You attempt to create an ssl-cc-ldap configuration object by navigating in the BIG-IP Configuration utility to Local Traffic > Profiles > Authentication > Configurations.
  • You specify both the IP address and the service port number of an LDAP server in the Hosts box using the following syntax:

    <IP address>:<Port number> 

    For example:

    192.168.1.1:2389

Impact

You may not be able use the Configuration utility to add the LDAP server that you want to the ssl-cc-ldap configuration.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you use the BIG-IP Configuration utility to add an LDAP server with its service port number to an ssl-cc-ldap configuration, you may notice the following error message:

    "Invalid Host Error"

Resolution

Workaround

To work around this issue, you can use the Traffic Management Shell (tmsh) to add the LDAP server that you want to the ssl-cc-ldap configuration. For more information, refer to the Auth chapter of the Traffic Management Shell (tmsh) Reference Guide.

Note: For information about how to locate F5 product guides, refer to K12453464: Finding product documentation on AskF5.
