Known Issue

When you have configured multiple IPsec interfaces, attempting to view the statistics of a specific traffic selector may cause some of the traffic selector statistics to display incorrectly.

This issue occurs when all of the following conditions are met:

  • You have configured multiple IPsec interfaces.
  • You attempt to view IPsec traffic selector statistics for a specific selector using the following command syntax:

    tmsh show net ipsec ipsec-sa traffic-selector <selector-name>

    For example:

    tmsh show net ipsec ipsec-sa traffic-selector selector1

Impact

There is no impact; this issue is purely cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Attempting to view individual traffic selectors may display inconsistent or invalid output.
