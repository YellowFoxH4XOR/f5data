Issue

Starting in FirePass 6.1.0 hotfix HF-610-4 and FirePass 7.0.0 hotfix HF-70-2, F5 has added an option to allow sessions to continue when the browser user-agent changes. By default, FirePass would terminate the user session if the clients browser user-agent string changed.

To set the Allow session to continue when user-agent string changes option, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management > Security.
  3. Click User Access Security.
  4. Select the Allow session to continue when user-agent string changes check box.

Important: Using this option can weaken the security of your FirePass Controller. Only use this option if it is required by your users.

For more information about this behavior, refer to K12445: The session terminates if the browser user-agent string changes.
