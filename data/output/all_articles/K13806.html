Known Issue

The BIG-IP ASM attack signature update may fail after an upgrade to BIG-IP 11.2.0 or 11.2.0 HF1. This issue occurs when all of the following conditions are met:

  • The affected BIG-IP ASM system was upgraded from a version prior to 11.2.0
  • Prior to the upgrade to BIG-IP 11.2.0, the affected BIG-IP ASM system's attack signatures were updated to ASM-SignatureFile_20120519_233948 or later

This issue affects both Automatic and Manual Delivery Mode for the attack signature update. When this issue occurs, you must perform the workaround to successfully update the attack signatures which otherwise may be left in a non-functional state.

You can determine whether the BIG-IP ASM system has had the ASM-SignatureFile_20120519_233948 attack signature file (or later) installed. To do so, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Click Application Security.
  3. Click Options.
  4. Click Attack Signatures.
  5. Click Attack Signatures Update.
  6. Select View update history from previous BIG-IP versions.
  7. For any attack signature update with a creation date of 05/19/2012 or later, you can verify the corresponding signature file name by clicking on the View Readme link.

    The file name will appear similar to the following example:

    Update: v11.1.0/ASM-SignatureFile_20120519_233948:

Impact

The BIG-IP ASM system may fail to enforce attack signatures.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The BIG-IP ASM system fails to enforce attack signatures.
  • The BIG-IP ASM system fails to update its attack signatures and reports an error message in the Configuration utility. The error message appears similar to the following example:

    DBD::mysql::db do failed: Duplicate entry '1-200004156' for key 'PRIMARY'

  • The BIG-IP ASM system fails to update its attack signatures and reports error messages in the /var/log/asm file. The error messages appear similar to the following example:

    01310027:2: ASM subsystem error (asm_config_server.pl,F5::Sigfile::Update::store_error_and_die): DBD::mysql::db do failed: Duplicate entry '1-200004156' for key 'PRIMARY'
    01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::handle_error): Failed update_sigfile on duplicate record for
    01310027:2: ASM subsystem error (asm_config_server.pl,F5::ASMConfig::Handler::log_error_and_rollback): DBD::mysql::db do failed: Duplicate entry '1-200004156' for key 'PRIMARY'

Status

Workaround

You may be able to work around this issue by initiating the attack signature update multiple times on the affected BIG-IP ASM system. Due to the nature of this issue, a portion of the update may complete each time you attempt to apply it, although the error messages above still display.

The update process may complete successfully after multiple attempts (for example, after 10 attempts), and return a message to the Configuration utility. The message will appear similar to the following example:

Attack signatures successfully updated
2 attack signatures had major updates and were placed in staging in relevant security policies
1 attack signatures had minor updates
5 attack signatures were removed
Aug 16 03:19:05 B3900-R66-S15 info perl[12112]: 01310053:6: ASMConfig change: Sigfile Update Result [update]: Signatures updated successfully - 2204 signatures loaded (3 updated)
