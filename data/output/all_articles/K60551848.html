Description

F5 ASM is not logging when # (hash or pound) is part of URL

  • ASM event logs doesn't log the full URL when a # is present in the URL.
  • Though in browser, the complete URL is shown (ex: www.example.com/?a=b#doaction)

Environment

  • BIG-IP
  • ASM provisioned with logging configured to log every request.

Cause

This happens because the client browser doesn't sent the strings after the # in a URL. Though the full URL can be see in the browser, the HTTP GET will only be sent for contents before the #.

For example, consider the URL:
www.example.com/?a=b#doaction
In browser this full URL can be seen.
But in ASM logs, we can only see www.example.com/?a=b

Recommended Actions

The BIG-IP ASM can log only if the request hits the BIG-IP. If the client manages to send the complete URL to BIG-IP, it will be logged. If the # is URL encoded, the client can be tricked to send the full URL and this time full URL will be logged in the BIG-IP as it got the full URL.
For ex: www.example.com/?a=b#doaction can be URL encoded www.example.com/?a=b%23doaction and this time the client will send the full URL.
