Description
The BIG-IP system with ASM-only license does not support HTTP redirect features. 

Environment

  • BIG-IP system with ASM-only license
  • You can not configure "Fallback Host" and "Fallback on Error Codes" in HTTP profile

Cause
This is by design. 

Recommended Actions

None
