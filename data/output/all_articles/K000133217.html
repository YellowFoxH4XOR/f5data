K000133217: Unable to add BIG-IP device to BIG-IQ with error 400

Type
Support Solution
Published
2023-03-27
Updated
2024-09-23
Applies to
  • BIG-IQ
  • BIG-IQ Centralized Management: 8.X.X, 8.0.0, 8.0.X, 8.1.0, 8.1.X, 8.2.0, 8.2.X
Source
https://my.f5.com/manage/s/article/K000133217

Description

After selecting "Add Device(s)" in BIG-IQ in order to add a BIG-IP for device management, providing the BIG-IP details, and then selecting "Add" to establish device trust, you may receive the following message:

  • The system returned an unexpected error (400 bad request)
  • Only one task can be created at a time

Environment

  • BIG-IP
  • BIG-IQ

Cause

A previous device-trust task is still running in the BIG-IQ. 

 Recommended Actions

  1. Execute the following command and find this running task. It will have the status "CANCEL_REQUESTED".

    # restcurl -X GET /cm/global/tasks/device-trust 

    Alternatively, you can look in /var/log/restjavad*.log for the line containing "CANCEL_REQUESTED":

    [WARN][29 Mar 2024 07:36:16 PDT][/cm/global/tasks/device-trust BigIPTrustTaskCollectionWorker] Task trust_192.168.1.35 (https://localhost/mgmt/cm/global/tasks/device-trust/54c688bb-f552-4e64-9c7c-5b3d928ce6fa) in a running (CANCEL_REQUESTED) state. 

  2. From the output of the above command, find the task's ID and then mark its status to "FAILED".  

    # restcurl -X PATCH /cm/global/tasks/device-trust/<id> -d '{"status": "FAILED", "generation": 0}' 

    Sample command: 

    restcurl -X PATCH /cm/global/tasks/device-trust/54c688bb-f552-4e64-9c7c-5b3d928ce6fa -d '{"status": "FAILED","generation": 0}'

  3. Delete this task 
    # restcurl -X DELETE /cm/global/tasks/device-trust/<id>

    Sample command: 

    restcurl -X DELETE /cm/global/tasks/device-trust/54c688bb-f552-4e64-9c7c-5b3d928ce6fa

  4. You may now attempt to add the BIG-IP device again.

Additional Information

None.
