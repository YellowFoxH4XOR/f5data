Known Issue

BIG-IP virtual addresses send gratuitous ARP (GARP) messages after a failover event when Address Resolution Protocol (ARP) is disabled.

This issue occurs when all of the following conditions are met:

  • ARP is disabled for a virtual address.
  • A failover event to another device in the device group occurs.

Impact

BIG-IP virtual addresses that should not respond to ARP requests start receiving traffic after failover.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H435082 on the Diagnostics > Identified > Medium page.
  • Virtual addresses with ARP disabled send GARP messages on failover.

Workaround

To work around this issue, disable the ICMP ECHO option. To disable ICMP ECHO, perform one of the following procedures:

  • Using the Configuration utility to disable ICMP ECHO
  • Using tmsh to disable ICMP ECHO

Impact of workaround: Performing the following procedures should not have a negative impact on your system.

Using the Configuration utility to disable ICMP ECHO

  1. Log in to the Configuration utility as an administrative user.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Address List.
  3. Click the name of the virtual address you want to modify.
  4. Clear the ICMP ECHO box.
  5. Click Update.

Using tmsh to disable ICMP ECHO

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To disable ICMP ECHO for a specific virtual address, use the following command syntax, where <virtual-address> is the name of the virtual address that you want to modify:

    modify /ltm virtual-address <virtual-address> icmp-echo disabled

  3. Save the change by typing the following command:

    save /sys config
