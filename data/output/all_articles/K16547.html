Known Issue

Network virtualization tunnel traffic may be erratic.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system is configured with a network virtualization Generic Routing Encapsulation (GRE) tunnel.
  • The BIG-IP system tm.tcplargereceiveoffload database variable is set with the non-default value of enable.
  • You establish the network virtualization GRE tunnel.

Impact

Traffic processed through the network virtualization tunnel may stall.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When viewing ping statistics across the tunnel, ping requests sporadically time out.
  • Traffic processed by the tunnel is slow or unreliable.

Workaround

To work around this issue, you can set the BIG-IP system database variable to the default setting of disable. To do so, perform the following procedure:

Impact of workaround: F5 does not recommend setting the system database variable to the enabled state, as doing so may cause unpredictable results.

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. Type the following command:

    modify /sys db tm.tcplargereceiveoffload value disable

  3. Save the configuration change by typing the following command:

    save /sys config

  4. To exit the tmsh utility, type the following command:

    quit
