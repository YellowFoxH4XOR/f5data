Known Issue

This is the result of a known issue. If you enable debug for the sod process and the /var/log/sodlog debug log file is 2GB or greater, the sod process restarts continuously. As a result, the BIG-IP system is not operational and is unable to process traffic.

Additionally, if you reboot the BIG-IP system when this issue occurs, the sod process no longer restarts continuously and the BIG-IP system logs a message that appears similar to the following example to the /var/log/ltm file:

sod[PID]: 010c0017:6: cannot open sod log - /var/log/sodlog

Note: This issue temporarily stops occurring after a reboot; however, if you disable and re-enable debug for the sod process, this issue will re-occur.

F5 Product Development tracked this issue as ID 340718 and it was fixed in BIG-IP version 10.2.2. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

In addition, this issue has been fixed in cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing F5 product hotfixes for BIG-IP version 10.x systems.

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

You can work around this issue by disabling debug for the sod process and removing the debug log file. To do so, perform one of the following two procedures:

BIG-IP version 9.x

  1. Log in to the BIG-IP command line.
  2. Disable debug for sod process by typing the following command:

    bigpipe db failover.debug disable

  3. Remove the debug log file by typing the following command:

    rm /var/log/sodlog

BIG-IP version 10.x

  1. Log in to the BIG-IP command line.
  2. Disable debug for sod process by typing the following command:

    tmsh modify sys db failover.debug value disable

  3. Remove the debug log file by typing the following command:

    rm /var/log/sodlog
