Topic

Beginning with BIG-IP 11.0.0, the bigpipe utility is removed from the product in favor of the Traffic Management Shell (tmsh).

tmsh, introduced in BIG-IP 10.0.0, is a hierarchical interface that includes features such as command completion, command history, and context-sensitive Help. You can use tmsh to set up your network, configure local and global traffic management, and display information about performance, load-balancing decisions, and network traffic.

Impact

Starting in BIG-IP 11.0.0, you must use tmsh to configure and manage the BIG-IP system from the command line.

Recommended Actions

If you are planning to upgrade to BIG-IP 11.x and the configuration contains custom scripts, monitors, or syslog configurations that reference the bigpipe command, you must change the custom configuration to reference the appropriate tmsh command.

For example, you can use the /config/startup file to configure the BIG-IP system to run commands or scripts at system startup. If you configured the /config/startup file to call a bigpipe command in BIG-IP 10.x, replace the bigpipe command with the corresponding tmsh command prior to upgrading to BIG-IP 11.x.
