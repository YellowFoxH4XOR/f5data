K32863198: Big IQ reports disk usage has exceeded threshold value of 80.0 percent for BIG-IP Device

Type
Support Solution
Published
2020-11-19
Updated
2023-02-21
Applies to
  • Virtual Editions
  • BIG-IQ Platforms
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K32863198

Description

When a BIG-IP is added as a managed device in BIG-IQ, status of BIG-IP in Devices tab in the Configuration Utility (GUI) of BIG-IQ changes from green to yellow indicating an alert with warning message:

Usage has exceeded threshold value of 80.0 percent

Environment

  • BIG-IP Device discovered by BIG-IQ
  • BIG-IQ Centralized Management

Cause

  • Read-Only /usr partition is more than 80% occupied
  • Other partitions reached more than 80% used space

Recommended Actions

Verify if health of managed BIG-IP device is reporting only /usr partition as above threshold:

Devices > Click on BIG-IP device  > Health

  • Check which partition is affected
    • If its only /usr:
      • ignore alerts 
        or
      • change threshold:
        Alerts & Notification > Settings > "Used disk space is above threshold for a device" from 80 to 90% to clear the alerts
        Note: The increased used disk space threshold will be applied to all partitions instead of specific partition only.
    • Perform further investigation on BIG-IP. Refer to K14403: Maintaining disk space on the BIG-IP system.

Additional Information

Default threshold on BIG-IQ is set to 80%.
Read-Only /usr partition is expected to be above 80%.
