Description

You do not see one (or more) signatures in the list of signatures on a specific application security policy.

But if you go to the list of all signatures:

Security ›› Options : Application Security : Attack Signatures : Attack Signatures List

... you can se the signature there.

Environment

Advanced WAF (ASM)

Cause

You have not enabled the signature on you policy

Recommended Actions

  1. Go to: Security ›› Application Security : Policy Building : Learning and Blocking Settings
  2. Choose the relevant policy
  3. Under "Attack Signatures" there is a "Change" button, press this and enable the sets of signatures you want to this security policy.
