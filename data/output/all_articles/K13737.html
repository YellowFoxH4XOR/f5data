Known Issue

Description

The BIG-IP GTM Configuration utility does not allow users to change the order of the view list hierarchy as expected.

This issue occurs when the following conditions are met:

  • Your BIG-IP GTM configuration contains multiple views.
  • You attempt to reorder the view list hierarchy by selecting After from the View Order menu.

Impact

You may be unable to reorder the view list hierarchy as expected.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • You cannot reorder the view list hierarchy as expected.
  • When you select After from the View Order menu, the second menu is blank and does not contain a list of additional views that you can choose from.

Resolution

Status

F5 Product Development has assigned ID 390086 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Release11.3.0K2200: Most recent versions of F5 software
Hotfix11.2.1 HF11K9502: BIG-IP hotfix matrix

Workaround

To work around this issue, you can remove and recreate the existing views. When you create a new view and select After from the View Order menu, the menu contains the additional views that you can choose from.

Note: You can also move a view to first or last on the list by choosing the First and Last options from the View Order menu.
