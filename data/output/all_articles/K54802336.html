Known Issue

Removing an iRule with higher priority events from a virtual server may result in stoppage of other iRules associated with the same virtual server.

Note: An iRules event without an explicit priority number assigned through the iRules priority command, is assigned with a default number of 500. For more information about iRules priority, refer to priority command iRules page on F5 CloudDocs.

This issue occurs when all of the following conditions are met:

  • The virtual server has multiple iRules enabled.
  • You remove an iRule with higher (lower-numbered) priority events from the virtual server.

Impact

The virtual server and related services may function unexpectedly due to the iRule stoppage.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Some or all of the iRules that are associated with a virtual server may stop properly running after you remove an iRule on the same virtual server.

Workaround

To work around this issue, you can create a dummy iRule with higher priority and associate it with the virtual server before removing the iRule you want to remove. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > iRules > iRule List.
  3. Select Create.
  4. For Name, enter a name for the iRule.
  5. For Definition, enter the dummy iRule.

    Note: The dummy iRule should include the same events, but higher priority, as the iRule that you need to remove from the virtual server.

    For example, the following iRule includes an empty event HTTP_REQUEST with priority 1, which is highest priority you can assign:

    when HTTP_REQUEST priority 1 {

    }

  6. Select Finished.
  7. Ensure that all iRules associated with the virtual server have lower-priority events than the dummy iRule. Modify the assigned priority as necessary.

    Note: The BIG-IP system considers iRules events with lower-priority numbers as higher in priority and evaluates them before events with higher-numbered priority numbers. 

  8. Associate the dummy iRule with the virtual server.
