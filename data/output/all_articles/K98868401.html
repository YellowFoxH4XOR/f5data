Description

Trying to access a service, next error is given in the client side: 
"Refused to execute script from '<URL>' because its MIME type ('') is not executable, and strict MIME type checking is enabled."

Environment

  • LTM policy adding security headers, for example X-Content-Type-Options

Cause

Application not recognizing new headers

Recommended Actions

Match the application side alignments regarding this type of headers. Alternatively, remove or reconfigure the policy that is adding security headers as needed. To identify the LTM policy that is adding the security headers, log in to the tmsh utility and enter the following command in the tmsh utility:

list ltm policy one-line | grep X-Content-Type-Options

The command should return an output similar to the following example:

ltm policy QID11827_mitigation { description "From https://my.f5.com/manage/s/article/K04436209" last-modified 2024-05-05:20:10:55 requires { http } rules { "Strict-Transport-Security header" { actions { 0 { http-header response insert name Strict-Transport-Security value "max-age=16070400; includeSubDomains" } } conditions { 0 { http-header response name Strict-Transport-Security not values { "max-age=16070400; includeSubDomains" } } } ordinal 3 } "X-Content-Type-Options header" { actions { 0 { http-header response insert name X-Content-Type-Options value nosniff } } conditions { 0 { http-header response name X-Content-Type-Options not values { nosniff } } } ordinal 2 } "X-Frame-Options header" { actions { 0 { http-header response insert name X-Frame-Options value DENY } } conditions { 0 { http-header response name X-Frame-Options not values { DENY } } } } "X-XSS-Protection header" { actions { 0 { http-header response insert name X-XSS-Protection value "1; mode=block" } } conditions { 0 { http-header response name X-XSS-Protection not values { "1; mode=block" } } } ordinal 1 } } status published strategy all-match }

You can then proceed to either remove this LTM policy from the affected virtual server or reconfigure the LTM policy as needed. For information about reconfiguring the LTM policy, refer to K04436209: Configuring a BIG-IP virtual server to mitigate the Qualys security scan threat QID 11827.
