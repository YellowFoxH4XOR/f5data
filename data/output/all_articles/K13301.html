Topic

You can use the tcpdump utility to trace packets that are encapsulated in a BIG-IP APM Network Access tunnel.

Description

The tcpdump utility is a command line packet sniffer with many features and options. You can use this utility to help troubleshoot Network Access sessions on a BIG-IP APM system.

The tcpdump utility can capture traffic on a BIG-IP APM Network Access tunnel by supplying the BIG-IP APM connectivity profile name as the value to the interface (-i) argument.

For example:

tcpdump -nni <apm connectivity profile>:nnn host <lease_pool_ip> -s0 -w /var/tmp/tunneltraffic.pcap

Note: Replace <apm connectivity profile> with the configured connectivity profile name used to process the requests.

You can use the host option to specify a client. The IP address should be a lease pool IP.

tcpdump -i <apm connectivity profile> host <lease pool ip>

Note: Replace <lease pool ip> with the IP address assigned to the client from the network access configured lease pool.

If the connectivity profile is in a partition you will need to wrap it with quotes.

For example: 

[root@BIG-IP-01:Active:Standalone] config # tcpdump -nni '/<Partition_1_example>/<APM_connectivity_profile_example>':nnn -s0 -w /var/tmp/tunneltraffic.dmp host <lease_pool_ip>
tcpdump: verbose output suppressed, use -v or -vv for full protocol decode
listening on /Partition1/Connectivity_profile:nnn, link-type EN10MB (Ethernet), capture size 65535 bytes
^C
0 packets captured
0 packets received by filter
0 packets dropped by kernel

For more information about the options available for the tcpdump utility, refer to K411: Overview of packet tracing with the tcpdump utility.
