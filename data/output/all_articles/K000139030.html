Description

File /etc/ntp/keys doesn't survive an upgrade.

You make changes to the /etc/ntp/keys file in order to implement authentication to NTP servers. After upgrading BIG-IP, the file is found to be in a blank/default state, with previous changes lost.

Environment

  • BIG-IP
  • LTM
  • NTP
  • /etc/ntp/keys

Cause

BIG-IP does not manage the configuration of this file, so that when an upgrade is performed, you get a default version of the file and BIG-IP does not copy previously added configuration across in the final stages of an upgrade when the 'Install Configuration' option is selected in the Web GUI, or the cpcfg option is specifified when using tmsh to upgrade from the CLI.

Recommended Actions

Take a manual backup copy of the file before upgrading, or configure UCS to add it as a file that it includes when creating an archive then create a UCS archive (see K4422).
