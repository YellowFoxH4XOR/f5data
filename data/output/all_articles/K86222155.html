Description

With the "Reconnect To Domain" setting enabled in the NA resource, when connecting to the VPN using Edge Client, PowerShell (.ps1) scripts are getting opened in Notepad.exe and are not getting executed.

Environment

  • Network Access resource with the "Reconnect To Domain" (Synchronize with Active Directory policies on connection establishment) setting configured.
  • PowerShell scripts deployed through GPO.
  • BIG-IP Edge Client.

Cause

This feature is currently not supported.

Recommended Actions

None
