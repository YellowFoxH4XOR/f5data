K13023453: SMSGlobal OTP

Type
Support Solution
Published
2025-07-01
Updated
2025-07-01
Applies to
  • BIG-IP
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K13023453

Description

  • Setup One Time Password (OTP) to SMSGlobal

Environment

  • APM
  • Multi-Factor Authentication (MFA)
  • OTP authentication

Cause

none

Recommended Actions

  • Create a AAA HTTP object with the settings below:

    Authentication Type: Form Based
    Form Method: http://api.smsglobal.com/http-api.php?action=sendsms&user=<apiuser>&password=<apipassword>&from=EEF5VPN
    Hidden Form Parameters/Values:
       to %{session.user.otp.destination}
       text %{session.user.otp.message}
    Successful Logon Detection Match Type: By Specific String In Response
    Successful Logon Detection Match Value: Sent queued message ID

    %{session.user.otp.destination} contains the mobile phone number starting with "61..."
    %{session.user.otp.message} contains the OTP token
