Topic

Each time an iControl request is sent to a BIG-IP or 3-DNS, an entry containing information about the request is logged in the /var/log/ITCM.log file on the BIG-IP or 3-DNS system.

In BIG-IP and 3-DNS version 4.5 and later, you can enable the iControl debug mode to produce more verbose logging. To enable debug mode, assign the value DEBUG to the Local.Bigip.CORBA.LogLevel database key. Note that this setting may dramatically increase the size of the ITCM.log file.
