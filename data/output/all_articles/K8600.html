K8600: Error Message: The number of concurrent sessions has exceeded the maximum licensed limit of seats

Issue

Your FirePass license determines the total number of concurrent user sessions supported by your FirePass controller. If a user attempts to log on to the FirePass controller, and the licensed concurrent session limit is already reached, FirePass displays an error message where X is the number of licensed concurrent sessions. This error message appears similar to the following example on the Reports: System Logs page:

The number of concurrent sessions has exceeded the maximum licensed limit of <X> seats.

Note: For more information about concurrent session limits, including how to view the total number of concurrent user sessions included in your FirePass license, refer to K8597: Overview of concurrent session limits.

To ensure that your logging is configured to log this type of event, perform the following procedure:

  1. Log in to the FirePass Administrative Console.
  2. Navigate to Device Management: Maintenance: Logs.
  3. In the Logging Options section, select Error in the drop-down menu next to Maintenance.
  4. Click the Apply Changes button.
