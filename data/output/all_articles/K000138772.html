K000138772: Obtaining license information for NGINX Plus

Type
Support Solution
Published
2024-02-29
Updated
2025-04-02
Applies to
  • NGINX Products
  • NGINX Plus
Source
https://my.f5.com/manage/s/article/K000138772

Description

  • You want to obtain/view NGINX Plus license information.

Environment

  • NGINX Plus
  • License details

Cause

  • None

Recommended Actions

  • MyF5 portal 
    • You can view the license details on MyF5 portal by signing in and navigating to 'Subscriptions' and clicking on 'SUPSCRIPTION ID' 
  • Command Line
    • You can also view the subscription ID and expiration date by running the following command on the NGINX Plus instance:
      openssl x509 -text -noout -in /etc/ssl/nginx/nginx-repo.crt
  • Cloud Platforms
    • For NGINX Plus deployments on Public Cloud Platforms, please refer to your Cloud Provider's documentation.

Additional Information
