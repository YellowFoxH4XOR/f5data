Known Issue

The high-speed logging (HSL) Balanced distribution method does not balance correctly in a two-member pool configuration.

This issue occurs when all of the following conditions are met:

  • You configure a two-member pool as a remote HSL destination.
  • You configure the remote HSL destination distribution method with the Distribution setting's Balanced method.
  • You use a data plane Traffic Management Microkernel (TMM)-specific logging device, such as an iRule that uses the HSL::send command.

Impact

Log message may not distribute correctly, resulting in more load to a single pool member.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Only one member of the two-member pool receives all of the traffic.
