Description

Disk space for /Shared directory is full or has less free space because of zrd.out file

Environment

  • BIG-IP DNS
  • Disk usage
  • /shared directory

Cause

Zone Runner debug is currently enabled or enabled in the past but file is still present

Run below command to check if debug is still enabled or disabled

ls -alh /service/zrd/

You should see output similar to following

[root@bigip1:Standby:In Sync] tmp # ls -alh /service/zrd/

total 20K

drwxr-xr-x. 5 root root 4.0K Mar 29 11:39 .

drwxr-xr-x. 106 root root 4.0K Mar 9 2023 ..

-rw-r--r--. 1 root root 0 Mar 29 11:39 debug <<--------- !!

<..skipped ..>

If it's not enabled you should NOT see debug line in above output.

Recommended Actions

1.Verify if there is any active troubleshooting and is the reason why debug is ON.

2.If it is disabled already, you can either copy file to local machine and can be safely remove from the unit.

To remove you can run below command :

rm /shared/tmp/zrd.out

If debug is still running and need to disable later ( after any active troubleshooting ), run below commands to disable

rm /service/zrd/debug

tmsh restart /sys service zrd

Important: Disabling ZoneRunner debug will restart the Zone Runner process which may impact dns resolutions temporarily, please open a maintenance window if necessary.

Additional Information

Once zrd.out file is removed, a new file will be automatically created either when zrd process restarted or debug is enabled again.
