Topic

You should consider using this procedure under the following condition:

  • You want to enable the Application Security Synchronization feature to save the BIG-IP ASM configuration objects to devices configured as part of a device group.

Description

When the BIG-IP LTM system is configured for synchronization, it does not automatically include the synchronization of BIG-IP ASM objects. You can use the following procedures to configure manual or automatic synchronization of BIG-IP ASM configuration objects, based on your needs.

Note: Manual BIG-IP ASM attack signature updates synchronize across all devices in the device group.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You have already set up the BIG-IP devices with device trust and device group.
  • You have BIG-IP ASM provisioned on all systems in the device group.
  • You have access to the BIG-IP Configuration utility.

Procedures

If you need to create a device group that automatically synchronizes or enable an existing device group to automatically synchronize, you must first perform the Configuring a BIG-IP ASM-enabled device group to automatically sync procedure before performing the Enabling BIG-IP ASM synchronization on a device group procedure.

If you have an existing device group, you can enable BIG-IP ASM synchronization on a device group by performing the Enabling BIG-IP ASM synchronization on a device group procedure.

If you have selected a manual sync device group to enable the BIG-IP ASM synchronization, you should manually synchronize the BIG-IP ASM-enabled device by performing the Manually synchronizing a BIG-IP ASM-enabled device group procedure.

Enabling BIG-IP ASM synchronization on a device group

The following steps configure the BIG-IP system for synchronization of BIG-IP ASM policies.

Impact of procedure : Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Security > Options > Application Security > Synchronization.

    The system displays a list of device groups of which this device is a member.

  3. For Device Group, click the device group containing the members that you want to synchronize.
  4. Click Save.

Manually synchronizing a BIG-IP ASM-enabled device group

The following procedure manually synchronizes the BIG-IP ASM security policies. For more information, refer to the Manually Synchronizing Application Security Configurations chapter of the BIG-IP Application Security Manager: Implementations manual for your software version.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact of procedure: Performing the following procedure synchronizes the BIG-IP ASM configuration objects to the configured device of the device group.

  1. On the BIG-IP ASM-enabled failover device group, create or update an application security policy.
  2. Navigate to Device Management > Overview.
  3. Click the name of the relevant device group.
  4. Set the view to Advanced.
  5. Under Devices, click the device that shows a status of Changes Pending.
  6. Under Sync Options, click Sync Device to Group.
  7. Click Sync.

Verify that the devices are synchronized by logging in to another BIG-IP system in the device group and verify that the security policy you created also resides on that system. Navigate to Security > Application Security > Security Policies and see if the policy is listed.

Configuring a BIG-IP ASM-enabled device group to automatically synchronize

The following steps configure the BIG-IP system for automatic configuration synchronization of BIG-IP ASM policies. For more information refer to the Automatically Synchronizing Application Security Configurations chapter of the BIG-IP Application Security Manager: Implementations manual for your software version.

Note: For information about how to locate F5 product manuals, refer to K12453464: Finding product documentation on AskF5.

Impact of procedure: Performing the following procedure enables automatic synchronization of BIG-IP ASM configuration objects between the configured device of the device group.

  1. Log in to the Configuration utility.
  2. Navigate to Device Management > Device Groups.
  3. Click Create.

    Note: If the device group you want to use already exists, you may omit this step and continue from to step 7.

  4. Type a name for the device group, for Group Type, click Sync-Failover, and type a description for the device group.
  5. For Configuration, click Advanced.
  6. In the Available list, click a host name for each BIG-IP device that you want to include in the device group, including the local device, and move it to the Includes list.

    Note: The Available list shows any devices that are members of the device's local trust domain but not currently members of a Sync-Failover device group. A device can be a member of one Sync-Failover group only.

  7. For Network Failover, select or clear the check box, as needed:
    • Select the check box if you want device group members to handle failover communications by way of network connectivity. This choice is required for active-active configurations.
    • Clear the check box if you want device group members to handle failover communications by way of serial cable (hard-wired) connectivity.

    Note: For active-active configurations, you must select network failover, as opposed to serial-cable (hard-wired) connectivity.

  8. For synchronization settings, refer to the following BIG-IP versions applicable to your environment:

    • BIG-IP 13.x and later

      • For the Sync Type list, click Automatic with Incremental Sync when you want the BIG-IP system to automatically sync the most recent BIG-IP configuration changes from a device to the other members of the device group. In this case, the BIG-IP system synchronizes the configuration data whenever the data changes on any device in the device group. Clicking other options reverts the device group to manual ConfigSync and you need to perform ConfigSync whenever configuration data changes on one of the devices in the device group.

    • BIG-IP 12.x and earlier

      • For the Automatic Sync setting, select the check box for the BIG-IP system to automatically synchronize the BIG-IP configuration data whenever a ConfigSync is required. In this case, the BIG-IP system synchronizes the configuration data whenever the data changes on any device in the device group. If you clear the check box, the device group reverts to manual ConfigSync, and you need to perform a ConfigSync whenever configuration data changes on one of the devices in the device group.

        Note: Beginning in BIG-IP 11.4.0, you can enable automatic synchronization of the system configuration when using the Sync-Failover device group setting.

      • For the Full Sync setting, select the check box when you want all synchronizations to be full synchronizations. In this case, every time a ConfigSync occurs, the BIG-IP system synchronizes all configuration data associated with the device group. This setting has a performance impact and is not recommended for most customers.

        Clear the check box when you want all synchronizations to be incremental (the default setting). In this case, the BIG-IP system synchronizes only the changes that are more recent than those on the target device. When you choose this option, the BIG-IP system compares the configuration data on each target device with the configuration data on the source device and then synchronizes the delta of each target-source pair.

        If you enable incremental synchronization, the BIG-IP system may occasionally perform a full synchronization for internal reasons. This is a rare occurrence and no user intervention is required.

  9. For Maximum Incremental Sync Size (KB), retain the default value of 1024, or type a different value.

    Note: This value specifies the total size of configuration changes that can reside in the incremental synchronization cache. If the total size of the configuration changes in the cache exceeds the specified value, the BIG-IP system performs a full synchronization whenever the next ConfigSync occurs.

  10. Click Finished.
