Source

Description
Unable to see the Web Application Security dashboard and is throwing out an error

Error: 
"INTERNAL_SERVER_ERROR: The query time boundaries for device default are not found. This is likely because the device is not registered for statistics collection. Please check the Agent Manager logs"

Environment

  • BIG-IQ CM
  • BIG-IQ DCD
  • BIG-IP ASM
  • BIG-IQ is managing BIG-IP ASM

Cause

Stats data cannot be saved to elastic search(ES) due to high disk usage caused by huge size event log ASM indices.

Found the following message in BIG-IQ CM appiq manager log:

Recommended Actions

To mitigate this workaround, you can perform any one of the following procedures:

  • To reduce "Max Index Size" and "Retained index Count" to a reasonable amount for "asmindex"
  • To upgrade storage of each DCDs in the cluster then manually increase /var size
  • To add more DCDs to the cluster if the customer doesn't want to reduce asmindex size



To reduce "Max Index Size" and "Retained index Count" to a reasonable amount for "asmindex"

  1. System -> BIG-IQ Data Collection -> BIG-IQ Data Collection Cluster -> Logging Data Collection -> Web Application Security (ASM)-> Press (Configure) button


To upgrade storage of each DCDs in the cluster then manually increase /var size

  1. K58621633: Extending disk space on a BIG-IQ Virtual Edition


To add more DCDs to the cluster if the customer doesn't want to reduce asmindex size

  1. Deploying a Data Collection Device


NOTE: After the changes are made, wait 24 hours and generate new qkviews of CM and DCDs
