Description

During software upgrade the bmcuiupdate failed to complete and the device generates the below error at /var/log/ltm

Failed updated AOM web UI with return code 2

Environment

  • BIG-IP iSeries

Cause

 LCD not detected/not up

Recommended Actions

To workaround the issue, please pick one of next options: 

  • Power cycle the device will force
  • If the power cycle is not an option you can perform a manual bmcui update
  1. Confirm the bmcui version with the below command,
# /usr/bin/ipmiutil cmd 00 20 e8 4f | grep respData | sed s/respData[[]len=40\]:/0:/ | sed s/00.*// | xxd -r -c 40 && echo
  1.  If the bmcui version does not match with the software version run a manual bmcui update
# /etc/lcdui/bmcuiupdate
Should return a prompt within a few tens of seconds

If you don't have above path, please try;
# /etc/rc.d/init.d/bmcuiupdate
# full_box_reboot
  1.  Confirm the bmcui version its matching with the software version
# /usr/bin/ipmiutil cmd 00 20 e8 4f | grep respData | sed s/respData[[]len=40\]:/0:/ | sed s/00.*// | xxd -r -c 40 && echo
