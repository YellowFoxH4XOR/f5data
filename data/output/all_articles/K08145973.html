Description

GTM-DNS Rate Limit not shown in the license after license reactivation and it's prompting a warning message in the GUI:

GTM module is not provisioned.

Environment

  • BIG-IP GTM 
  • GTM-DNS Rate Limit
  • End of life for DNS - Lite on BIG-IP appliance
  • Reactivating License

Cause

F5 has announced the End of Life (K03503468) plan for DNS-Lite for all BIG-IP platforms and will no longer work after a recent license activation. 

Recommended Actions

To resolve the issue, deprovision the GTM by the following steps below:
  1. Check if you have GTM configuration by running command in CLI:
    # ls -l /config/bigip_gtm.conf 
  2. If no GTM configuration is present then perform the next step.
    Note: If GTM configuration is listed, do not deprovision the GTM and contact F5 Technical Support for further assistance. 
  3. Go to GUI and navigate to System > System Provisioning.
  4. For Resource Provision (Licensed Modules), click None (Disable) for the license module you want to deprovision GTM.
  5. Click Update.
  6. After making the necessary provisioning changes, click System.
  7. Click Configuration.
  8. Click Device.
  9. To restart the system, click Reboot.
  10. When prompted, click OK to confirm restart.
