Known Issue

This is the result of a known issue. Defining a navigation parameter for an object may cause the BIG-IP ASM bd process to crash when one of the following three policy conditions occurs:

  • Defining an object, and leaving all fields in their default state
  • Defining a second object, and enabling the Check Flows to this Object flag for this object
  • Defining a navigation parameter on any of the objects created above, within the policy

When a client attempts to access a link encompassed by one of the objects defined, the BIG-IP ASM bd process may crash.
