Environment

  • Failover
  • BIG-IP in Offline state
  • High CPU utilisation

Cause

  • Caused by Bug ID 749011: Datasync may start background tasks during high disk IO utilization

Recommended Actions

  • No workaround available for this Bug ID, recommended action is to upgrade to version 15.1.0 or later.

Additional Information

  • The cause can also be viewed by reviewing CPU utilisation at the time of the failover using the Graphs. At the time failover, it would show significant increase in system IO activity in last CPU core.
  • As per the article K02827102, we know that for several hours per days BIG-IP ASM systems can experience higher CPU usage due to the running datasyncd process for Javascript obfuscation. Hence, using this information, you can refer to the article K12201682 to determine what time the Obfuscation process runs daily and the duration it last.
  •  
  • It was found that during the time when the failover took place and when I/O utilisation was high, the obfuscation process was also running.
