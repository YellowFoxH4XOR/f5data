Known Issue

This is the result of a known issue. Index corruption within the eXtremeDB database can cause MCP to crash.

F5 Product Development tracked this issue as CR74262 and it was fixed in BIG-IP versions 9.1.3 and 9.3. For information about upgrading, refer to the BIG-IP LTM, GTM, ASM and Link Controller release notes.
