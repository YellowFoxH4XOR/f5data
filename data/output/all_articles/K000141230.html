K000141230: HTTP 503 Error when connecting through HTTP Explicit Proxy

Type
Support Solution
Published
2024-10-16
Updated
2024-10-16
Applies to
  • BIG-IP
  • BIG-IP LTM: 15.1.8
Source
https://my.f5.com/manage/s/article/K000141230

Description

When connecting through BigIP explicit HTTP proxy and it returns HTTP 503 status code, check name resolution using the same egressing IP address as Explicit proxy.

  1. First find out which name servers are configured within HTTP Explicit Proxy:

tmsh list ltm profile http <explicit_http_profile> | grep 'dns-resolver'

 dns-resolver /Common/my-resolvers

       2. List 'my-resolvers' net resolvers to find out their IP addresses:

tmsh list net dns-resolver /Common/my-resolvers

net dns-resolver /Common/my-resolvers {
    forward-zones {
        . {
            nameservers {
                10.20.20.53:53 { }
                10.20.30.53:53 { }
            }
        }
    }
    route-domain /Common/0
}

 

     3. To find egressing IP, run TCPdump. The traffic will look like this:

In frame #1 HTTP Proxy makes NS request to the local name server as configured within the proxy.

#1 119.602186 0.000000 4094 10.10.10.34 → 10.20.20.53 85 34145 53 DNS OUT s1/tmm3 : Standard query 0x5277 A www.abc.lan OPT

In frame #2 HTTP Proxy responds back to client with " 503 Service Unavailable " after no response from Name Server in 120 seconds.   

#2 239.602213 120.000027 4094 10.10.10.40 → 10.10.10.82 52 16157 43654 HTTP OUT s1/tmm3 : [TCP ACKed unseen segment] HTTP/1.0 503 Service Unavailable 

 

     4. Then test name resolution using Dig tool with specifying source IP address. In our case would be '10.10.10.34'

dig www.abc.lan @10.20.20.53 -b 10.10.10.34

dig www.abc.lan @10.20.30.53 -b 10.10.10.34

Environment

BigIP 15.1.8 Explicit Proxy

Cause

Collected packet capture clearly shows that there is no name resolution response from the configured DNS servers.

Recommended Actions

Check local firewall logs to see where request is blocked to the name server (10.10.10.34 → 10.20.20.53)

Additional Information
