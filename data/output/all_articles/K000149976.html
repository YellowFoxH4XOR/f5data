Description

What does a value of NONE mean in the DH Groups or Signature Algorithms of a Cipher Rule? 

Environment

  • BIG-IP LTM
  • Cipher rules

Cause

A value of NONE for DH Groups/Signature Algorithms can be applied in a Cipher Rule.

Recommended Actions

if no DH Groups/Signature Algorithms are specified (NONE) then the DEFAULT DH Groups/Signature Algorithms are applied.

For a clientssl profile that has a ciphersuite set, the 'DH Groups'/'Signature Algorithms' will be set to the equivalent of DEFAULT.
In this situation there is no option to prevent a specific signature algorithm from being offered.
