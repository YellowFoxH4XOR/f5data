Known Issue

Applications using static proxy settings may fail through network access.

This issue occurs when all of the following conditions are met:

  • You have configured network access with static proxy settings.
  • You have configured the client application to use static proxy settings.

Impact

End client applications are not accessible.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When establishing network access, static proxy settings are not inserted in the client browser.
  • End client applications are not accessible through network access.
