Description

Upon navigating to Access > Guided Configuration, the following message is displayed:
Not Found
The requested URL was not found on this server

Environment

  • BIG-IP APM
  • Upgrade
  • Guided Configuration
  • iApps LX

Cause

Guided configuration wasn't properly initialized.

Recommended Actions

To reinstall web pages and support files for the Guided Configuration iApp-LX subsystem, perform this procedure.

Performing this procedure has no impact to production traffic and the data-plane configuration held by the TMOS MCP database that controls production traffic and no impact to the Guided Configuration apps (iApp LX blocks) held by the TMOS REST database.

  1. Navigate to Download are of MyF5 https://my.f5.com/manage/s/downloads
  2. Select BIG-IP under product family
  3. Select "Guided Configuration". If issue is impacting a single BIG-IP within an HA pair, then download the guided configuration package version currently used on the working BIG-IP. If this is impacting a standalone BIG-IP then download the latest guided configuration package.
  4. Unpack the archive
  5. In the list of files, you should see a file with a name similar as the following:
         f5-iappslx-access-framework-**.rpm
  6. In BIG-IP Configuration Utility navigate to "iApps ›› Package Management LX"
  7. Uninstall f5-iappslx-access-framework
  8. Import f5-iappslx-access-framework-**.rpm file from step 4. New package will be installed.
  9. Verify the error is gone when going to  Access > Guided Configuration
  10. If that does not help, try to uninstall all the packages under "iApps ›› Package Management LX" and import all the rpms from step 4. individually
