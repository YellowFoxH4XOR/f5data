Known Issue

The BIG-IQ system cannot manage systems running BIG-IP 11.6.1.

This issue occurs when all of the following conditions are met:

  • Your system is running BIG-IP 11.6.1 or BIG-IP 11.6.1 HF1.
  • You disable your BIG-IP system's default administrator account or assign different account credentials to it.
  • You attempt to manage your BIG-IP system using a compatible version of the BIG-IQ system.

Impact

The BIG-IQ system fails to manage the affected BIG-IP system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H615993 on the Diagnostics > Identified > Low page.
  • Your BIG-IQ system is unable to manage the affected BIG-IP system.
  • When you send REST or iControl Simple Object Access Protocol (SOAP) requests from the BIG-IQ command line to the affected BIG-IP system, your BIG-IP system logs failure error messages.

Workaround

To work around this issue, you can re-enable the default administrator account or reassign the default administrator credentials to the account. To do so, perform one of the following procedures:

  • Re-enabling the default administrator account
  • Reassigning default administrator credentials to the administrator account

Impact of workaround: If you previously disabled or reassigned credentials to the default administrator account for a security reason, these procedures may impact your system's security. F5 recommends that you perform a security assessment for your environment before re-enabling the default administrator account.

Re-enabling the default administrator account

  1. Log in to the Configuration utility on the affected BIG-IP system.
  2. Navigate to System > Platform > User Administration > Admin Account.
  3. Deselect the Disable default admin check box.
  4. Optional: Change the password for the administrator account.
  5. Click Update.

Reassigning default administrator credentials to the administrator account

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh

  2. To reassign the default administrator account, type the following command:

    modify /sys db systemauth.primaryadminuser value admin

  3. Optional: Change the password for the administrator account by typing the following command:

    modify /auth user admin prompt-for-password

    The system prompts you to type the new password twice.

  4. Save your changes by typing the following command:

    save /sys config

  5. To exit tmsh, type quit and press Enter.
