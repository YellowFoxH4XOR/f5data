Issue

Old Behavior

In BIG-IP 9.x, the BIG-IP system can successfully monitor FTP service (port 21) residing on a host that has Layer 2 (L2) multicast addressing without enabling the TM.AllowMulticastL2DestinationTraffic db key.

New Behavior

Beginning in BIG-IP 10.0.0, you must enable the TM.AllowMulticastL2DestinationTraffic db key to allow the BIG-IP system to monitor FTP service (port 21) that resides on a host with an L2 multicast address. The TM.AllowMulticastL2DestinationTraffic db key allows the BIG-IP system to flood frames destined for a multicast MAC address across all interfaces in all Virtual Local Area Networks (VLANs). The db key is disabled by default.

You must enable this db key because the BIG-IP system now processes FTP monitor traffic (port 21) using an internal standard virtual server instead of an internal L2 forwarding virtual server.

This change was a result of ID 220508 (formerly CR33990).

Impact

The BIG-IP system marks affected FTP pool members as unavailable.

Recommended Actions

If your BIG-IP system marks FTP pool members down after an upgrade to BIG-IP 10.x or later, you must enable the TM.AllowMulticastL2DestinationTraffic db key on the affected BIG-IP system. To do so, perform the following procedure:

Impact of procedure: Enabling TM.AllowMulticastL2DestinationTraffic allows all frames destined for a multicast MAC address to be flooded across all interfaces in all VLANs.

Using the tmsh utility

  1. Log in to the Traffic Management Shell (tmsh) by typing the following command:

    tmsh
  2. Enable the TM.AllowMulticastL2DestinationTraffic db key by typing the following command:

    modify sys db tm.allowmulticastl2destinationtraffic { value enable }
  3. Save the change by typing the following command:
    • BIG-IP 10.1.0 and later versions:

      save sys config
    • BIG-IP 10.0.x:

      save config

Using the bigpipe command

  1. Log in to the BIG-IP command line.
  2. Enable the TM.AllowMulticastL2DestinationTraffic db key by typing the following command:

    bigpipe db TM.AllowMulticastL2DestinationTraffic enable

  3. Save the change by typing the following command:

    bigpipe save
