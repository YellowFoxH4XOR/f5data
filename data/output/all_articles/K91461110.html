Description
URLs provided via iRules using HTTP::respond command may fail to load when Virtual Server has http2 profile associated with it.

Environment

  • Virtual Server with HTTP2
  • iRule HTTP::respond command

Cause
This issue may be caused due to Bug ID 757446: Invoking the HTTP::respond iRule command when the HTTP2 profile is present can cause stalled or malformed responses..

Recommended Actions

This bug is fixed on version 15.0.x onward, therefore you should consider upgrading to that version or wait until 15.1.x Long-Term Stability Release is available.
 

Additional Information
Note: F5 Support does not design or configure iRules.  If you are in need of any assistance configuring an iRule to best work for your environment, F5 Professional Services can assist.
