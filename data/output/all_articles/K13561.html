Known Issue

The symmetric deployment feature is not functional in BIG-IP WebAccelerator 11.x. 

A symmetric configuration consists of central and remote WebAccelerator systems that have synchronized configurations. With this configuration, users can transparently use the functionality of a WebAccelerator system on another network, across the globe, from both sides of the transaction.

Impact

Symmetric deployments will no longer function.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The symmetric deployment features are missing from the BIG-IP Configuration utility and Traffic Management Shell (tmsh)
  • If you have a symmetric deployment configured, and you upgrade to BIG-IP WebAccelerator 11.x, the feature will no longer function

Resolution

Status

F5 Product Development has assigned ID 346062 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the top right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

There is no workaround to this issue. If you require a symmetric deployment, F5 recommends that you do not upgrade to BIG-IP WebAccelerator 11.x until this issue is resolved.
