Description

BigIP appliance has a disk that’s constantly failing. File System errors that impact services.

  • Sometimes functionality completely stops
  • Reboot required to recover functionality
  • Need to reboot with fsck to be successful
  • You can find similar logs on /var/log/dmesg:

    /var/log/dmesg
    ----------------------
    [   15.129466] EXT3-fs (dm-9): warning: ext3_clear_journal_err: Filesystem error recorded from previous mount: IO failure
    [   15.129468] EXT3-fs (dm-9): warning: ext3_clear_journal_err: Marking fs in need of filesystem check.
    [   15.129579] EXT3-fs (dm-9): mounted filesystem with ordered data mode

Environment

  • File system errors
  • BIG-IP

Cause

Unknown at time of publication.

Recommended Actions

The unit might need hardware replacement. Open a case with F5 support for confirmation.
