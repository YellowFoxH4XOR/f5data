K000090481: Unable to view specific CVE for each NGINX Instance

Type
Support Solution
Published
2021-10-13
Updated
2021-10-13
Source
https://my.f5.com/manage/s/article/K000090481

Description

In Inventory Scan, it will display all Instances which will also include CVES of that instance.


When clicking the CVE number, it will go to a generic NGINX Security Advisories page.


You want to view the specific CVE(s) related to the specific Instance.


 Environment

- NGINX Instance Manager (NIM) 1.0.3

- View CVE for each Instance

 Cause

At the time of publication, the NGINX Instance Manager will only provide the generic NGINX Security Advisories page. You will need to ensure that each Instance complies with the NGINX Security Advisories page.


There is no option to view the specific CVE(s) which is impacting the specific Instance.

 Recommended Actions

Check release notes for future NGINX Instance Manager version on options to view CVE(s) related to the specific Instance.

 Additional Information

None.
