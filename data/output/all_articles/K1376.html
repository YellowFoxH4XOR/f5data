K1376: Reasons why the named utility may fail to start

Topic

The named utility can malfunction if there are typographical errors in the 3-DNS configuration files or if the configuration files are corrupted.

To correct this issue:

  1. Carefully check the wideip.conf file for typographical errors.
  2. If you do not find any errors, type the following command to examine each configuration statement with 3dparse:

    Note: The following command should be typed on one line.

    for i in ../etc/wideip.conf topology.inc ldns region.ISP region.ACL region.GEO cdn.inc request.inc; do echo -e '' \n\n${i}:'';3dparse -if /var/3dns/include/${i}; done

  3. After you correct any errors, reset the cache files by typing the following commands:

    cd /var/3dns/include

    echo 'NO_OP' >request.inc

    echo 'NO_OP' >ldns

  4. Restart named by typing the following command:

    3ndc restart
