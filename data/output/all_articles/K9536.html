Known Issue

This is the result of a known issue. In BIG-IP versions 9.4.5 and 9.4.6, the BIG-IP 1600, 3600, and 6900 platforms have a fixed serial baud rate of 19200, which cannot be changed. For example, if you attempt to change the serial baud rate using the bigpipe hardware baud rate command, the baud rate is not changed, and the system logs an error message to the /var/log/ltm file that appears similar to the following example:

chmand[2185]: 012a0003:3: HAL error setting baud rate: virtual void Hal::MercuryConSvc::setBaud(Hal::BAUD)

F5 Product Development tracked this issue as CR94172 and CR99148, and was fixed in BIG-IP versions 9.4.7 and 10.0.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, PSM, or WebAccelerator release notes.
