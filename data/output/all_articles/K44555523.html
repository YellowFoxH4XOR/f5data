Topic

BIG-IP APM session reports require that you configure the BIG-IP APM access policy log level as Notice or higher.

Description

The BIG-IP APM system populates session reports from information stored in its MySQL database. The information required for BIG-IP APM session reports is only stored to the database when you configure the access policy log levels as Notice, Informational, or Debug.

Note: You should only set the Debug log level on a production system if F5 Technical Support advises you to do so. The Debug log level produces a large amount of data, which may negatively impact performance.

The system does not populate BIG-IP APM session reports if the access policy log levels are configured as Warning, Error, Critical, Alert, or Emergency.

Configuring BIG-IP APM access policy logging levels (BIG-IP 12.x and later)

Beginning in BIG-IP APM 12.0.0, you can use a BIG-IP APM logging profile to configure logging levels for access policy components on a per-policy basis. To that ensure the system populates session reports, the access policy must use a logging profile configured with a log level of Notice or higher. If you configure an access policy to use a logging profile with a lower log level lower, the BIG-IP APM session reports are not be populated. The default logging profile level is Notice.

For information about configuring logging profiles in BIG-IP APM 12.0.0 and later, refer to the following articles:

  • K45423041: Enabling APM Policy debug logging
  • K61903673: Additional per-policy BIG-IP APM logging level configuration options available (13.x)

Configuring access policy logging levels for BIG-IP APM 11.x

For BIG-IP 11.x, you can configure the logging levels of the access policy components with a single, global log-level value which applies to all access policies. BIG-IP APM access reports require you to configure a logging level of Notice, Informational, or Debug. If you configure a logging level of Warning, Error, Critical, Alert, or Emergency, when you attempt to create a BIG-IP APM access report, the system displays a message similar to the following:

Log Level Change Needed
The Access Control log level must be "Notice" or higher to populate these reports (currently set to Warning).

To configure the logging level for BIG-IP APM access policy components on BIG-IP 11.x, perform the following procedure:

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to System > Logs > Configuration > Options.
  3. Under Access Policy Logging, in the Access Policy list, click the logging level you want the system to use.
  4. Click Update.
