Description

Newer versions of horizon (7 & 8) require manual update to monitor settings or connection server or the pool may be marked offline.

Default monitor string of "GET /broker/xml" may result in pool members being marked down.

Node Name:         10.1.1.10
Availability:           Offline (Enabled) /Common/VDI.app/VDI_https: Response Code: 404 (Not Found) @2021/10/26 10:51:07.
Health Monitors:   VDI_https

Environment

Relevant environmental factors specific to the topic

  • VMware Deployment guide
  • VMware iApp deployed
  • BIG-IP APM provisioned
  • Monitor Failures

Cause

It looks like newer versions of VMware connection servers require a different Monitor string than what is outlined in the Deployment Guide.
 

Recommended Actions

Per VMware documentation the load balancer monitor settings should be :
Interval: 30 sec
Timeout 91 sec
Monitor String: GET /favicon.ico HTTP/1.0 or GET /favicon.ico HTTP/1.1

Additional Information

Monitoring health of Horizon Connection Server using Load Balancer, timeout, Load Balancer persistence settings in Horizon 7.x and 8 (56636)
