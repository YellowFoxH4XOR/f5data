Known Issue

A virtual server that uses an iRule which references a pool in another partition indicates an Unknown status.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP system uses two or more additional administrative partitions.
  • An iRule in one partition accesses an object in another partition other than the default Common partition.

In BIG-IP 10.x, if you configure an iRule to load balance to a pool within a different administrative partition than the virtual server, the virtual server indicates an Available/green status in the Configuration utility. In BIG-IP 11.x, the virtual server stays in an Unknown/blue state in the Configuration utility, even though the pool monitor is successful and the pool may continue to pass traffic.

Impact

None. This issue is cosmetic.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H465610 on the Diagnostics > Identified > Low screen.
  • After you upgrade from BIG-IP 10.x to BIG-IP 11.x, the virtual server indicates an Unknown/blue status.
  • The pool being referenced by the iRule indicates an Available/green status.

Workaround

To work around this issue, F5 recommends that you avoid using iRules to access objects in different administrative partitions other than the Common partition.
