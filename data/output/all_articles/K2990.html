K2990: Reasons why Cisco switches may report flapping when connected to a BIG-IP

Topic

You may receive the following error message (with the MAC address of my BIG-IP) from your Cisco switch:

2003 Jul 02 09:18:06 %WARN: 1/Host 0c:cc:01:00:0c:cc is flapping between port 1/1 and port 2/1
2003 Jul 02 09:18:06 %WARN: 1/Host 0c:cc:01:00:0c:cc is flapping between port 1/2 and port 2/1
2003 Jul 02 09:18:06 %WARN: 1/Host 0c:cc:01:00:0c:cc is flapping between port 2/48 and port 2/1

This error is occurs when BIG-IP is using the same MAC address on all VLANs. This is caused because the Cisco 29xx, 4000, and 4500 switches use a single CAM table for the entire switch; therefore, it sees the MAC as changing ports, even though the two ports are on separate VLANs. This results in the flapping error.

This is a design issue in the lower-end Cisco switches. The larger switches do not have this issue, because they allocate memory for a CAM table per VLAN.

For most configurations, you can work around this issue and eliminate this error by setting the vlans unique_mac global variable to enable.

Note: If you are running a layer 2 forwarding configuration, setting the vlans unique_mac variable will not resolve the issue. Instead, you must use separate switches for internal and external VLANS to prevent this error.

To enable the vlans unique_mac global variable from the command line, type the following command:

b global vlans unique_mac enable
