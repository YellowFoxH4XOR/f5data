Security Advisory Description

In some circumstances, a BIG-IP Azure cloud instance may contain a default administrative password which can be used to remotely log in to the BIG-IP system.

The affected administrative account is the Azure instance administrative user created at deployment. The root and admin accounts are not vulnerable.

This issue only affects BIG-IP Virtual Edition (VE) Azure instances and Azure Web Application Firewall solutions on the Azure Marketplace. This issue does not affect BIG-IP VE instances on any other cloud services. All BIG-IP VE Azure instances licensed for any product are affected by this vulnerability, except:

  • Instances deployed using solution templates.
  • Instances deployed using a password rather than public key for the user-defined account during provisioning.

Note: For more information about deploying instances using solution templates, refer to the DevCentral Deploy BIG-IP VE in Microsoft Azure Using an ARM Template article.

Impact

An attacker may be able to remotely access the BIG-IP system using secure shell (SSH).

Mitigation

There are three mitigations available for this issue.

  • Changing the password for the Azure Default user created during instance creation
  • Deleting the Azure Default user created during instance creation
  • Blocking access to the SSH service using an upstream firewall

Changing the password for the Azure Default user created during instance creation

Before manually changing the password, you must determine the user name of the Azure Default user. To do so, perform the following procedure:

Important: You must use the TMOS Shell (tmsh) or the Configuration utility to change the Azure Default user password. Do not attempt to reset the password using the Azure portal.

  1. Log in to the Azure BIG-IP instance as the root user.
  2. To determine the user name of the Azure Default user, type the following command:

    grep "Azure Default User" /etc/passwd

    Output appears similar to the following example:

    azureuser:x:0:500:Azure Default User:/home/azureuser:/bin/bash

    The user name displays in the first field. In this example, the user name is azureuser.

    Note: The actual user name differs based on the individual configuration and the user name chosen at deployment.

  3. To change the password, use the following command syntax:

    tmsh modify auth user <azure-default-user> prompt-for-password

    In this syntax, <azure-default-user> is the user name determined in step 2.

    For example:

    tmsh modify auth user azureuser prompt-for-password

  4. Follow the on-screen prompts to change the password.
  5. Save the configuration by typing the following command:

    tmsh save sys config

Deleting the Azure Default user created during instance creation

  1. Log in to the Azure BIG-IP instance as the root user.
  2. To determine the user name of the Azure Default user, type the following command:

    grep "Azure Default User" /etc/passwd

    Output appears similar to the following example:

    azureuser:x:0:500:Azure Default User:/home/azureuser:/bin/bash

    The user name displays in the first field. In this example, the user name is azureuser.

    Note: The actual user name differs based on the individual configuration and the user name chosen at deployment.

  3. To delete the user, use the following command syntax:

    tmsh delete auth user <azure-default-user>

    In this syntax, <azure-default-user> is the user name determined in step 2.

    For example:

    tmsh delete auth user azureuser

  4. Save the configuration by typing the following command:

    tmsh save sys config
