K000148366: BIG-IP APM Component Installer Package for Windows certificate expired 10/09/24

Type
Support Solution
Published
2024-11-01
Updated
2024-11-07
Applies to
  • BIG-IP
  • APM Clients
  • BIG-IP APM
Source
https://my.f5.com/manage/s/article/K000148366

Description

You have updated APM Edge Client to version 7.2.4.7 but you noticed that code signing certificate for Component Installer Package for Windows is valid only till September 10, 2024. This may cause issues for example with Microsoft Entra ID during rollout.

Environment

  • BIG-IP APM
  • BIG-IP APM Edge Client 7.2.4.7
  • Signing certificate
  • Component Installer Package for Windows

Cause

This is due Bug ID 1644325: Windows code signing certificate update 2024

The certificate for APM Edge Client (v7.2.4.7) expires on 11 Sep. 2024

Recommended Actions

Update the code signing certificate for Windows Edge Client by installing APM Edge Client version 7.2.4.8 or newer

Additional Information

None
