Known Issue

This is the result of a known issue. Some of the HTTP headers inserted by the BIG-IP WebAccelerator for internal operation are not removed before the request leaves the BIG-IP WebAccelerator. Some of the HTTP headers that may be used internally by the BIG-IP WebAccelerator are as follows:

  • WAConnPool
  • WALBServer
  • WASnat
  • WARamCacheHits
  • X-PvMAC
  • WARamCachOrigConditional
  • Surrogate-Capabilities
  • X-Remote-Addr

Note: The BIG-IP WebAccelerator uses the X-Client HTTP header for internal operation. The header is not removed before the request leaves the BIG-IP WebAccelerator. For more information refer to K10919: The BIG-IP WebAccelerator returns compressed content when the request contains an X-Client header.

Non-RFC compliant origin servers may experience issues with unknown HTTP headers.

In a forward proxy configuration, the HTTP headers that are not removed could disclose details about internal network topologies to external entities.
