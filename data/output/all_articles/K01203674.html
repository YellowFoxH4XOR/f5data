Issue

Error Message

0107030c:3: Host persistence requires an HTTP profile to be associated with the virtual server

For example:

err mcpd[5627]: 0107030c:3: Host persistence requires an HTTP profile to be associated with the virtual server

Message Location

You may encounter this message in the following locations:

  • The /var/log/ltm file
  • TMOS Shell (tmsh)
  • Configuration utility

Description

This message occurs when the following condition is met:

  • A BIG-IP administrator attempts to configure a host persistence profile on a virtual server that does not have an HTTP profile configured.

Because host persistence works by allowing clients to persist to pool members based upon the HTTP Host header, the virtual server must have an HTTP profile to parse the HTTP traffic.

Impact

The configuration issued through a tmsh command or the Configuration utility is rejected as invalid.

Recommended Actions

Apply an HTTP profile and a host persistence profile to the affected virtual server

The following procedure enables an HTTP profile and host persistence on a virtual server using the Configuration utility.

Impact of procedure: Adding an HTTP profile to a virtual server causes it to parse HTTP traffic. If the traffic is not compliant with the HTTP RFC, then it may be blocked.

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > Services > HTTP.
  3. To create a new HTTP profile, select Create.
  4. Enter a name for the profile, for Parent Profile, select http.
  5. Under Settings, customize each property as needed.
  6. Select Finished.
  7. Go to Local Traffic > Virtual Servers.
  8. Select the virtual server for which you want to use host persistence.
  9. Under Configuration,
    • In BIG-IP 14.0.0 and earlier, for HTTP profile, select the new HTTP profile.
    • In BIG-IP 14.1.0 and later, for HTTP Profile (Client), select the new HTTP profile and leave HTTP Profile (Server) with the default setting of (Use Client Profile).
  10. Select Update. You will be returned to the virtual server configuration screen.
  11. Select the Resources tab at the top of the page above General Properties.
  12. Configure the host persistence profile for Default or Fallback persistence.
  13. Select Update.
