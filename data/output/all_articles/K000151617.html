Description

Radius Authentication for remote user accounts logging into the F5OS management interface fails when attempting to login to the webUI.

However, the RADIUS server reports the authentication attempt as successful.

Environment

F5OS-A

Remote User authentication using Radius

Cause

It may be discrepancy between the RADIUS server user attribute "F5-F5OS-GID" and the admin role "remote-gid" parameter.

Recommended Actions

  1. Let's get the configuration of the user attribute "F5-F5OS-GID", from the RADIUS server;
  2. Let's connect to the F5OS webUI, and please navigate to Authentication & Access >> Users & Roles
  3. Let's "show" the "Roles"
  4. Let's click the role attached to the user account;
  5. Let's ensure the parameter "Remote GID" does match with he configuration we have at step #1, please update if necessary
