Known Issue

Setting the zxfrd log level to debug can cause Authoritative Transfer (AXFR) or Incremental Zone Transfer (IXFR) failures due to high CPU and disk usage.

This issue occurs when the following condition is met:

  • You set the log.zxfrd.level to debug by typing the following command:

    tmsh modify sys db log.zxfrd.level value debug

Impact

Because the zxfrd process uses a lot of CPU, the IXFRs or AXFRs may fail, and the system may reschedule them, preventing the zxfrd process from processing data packets during a transfer.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • If you enable debug logging on zxfrd (DNSX), the system experiences excessive CPU and disk usage as well as errors during DNS AXFR or IXFR processing.
