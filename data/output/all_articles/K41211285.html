K41211285: About upgrading 3rd Party software components on BIG-IP or BIG-IQ

Type
Support Solution
Published
2020-03-16
Updated
2025-04-01
Applies to
  • BIG-IQ
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K41211285

Description

The BIG-IP and BIG-IQ systems includes 3rd party software that runs on the Linux host OS such as OpenSSL, OpenSSH, and Syslog-ng. F5 does not support upgrading this 3rd party software separately from a BIG-IP or BIG-IQ software upgrade. As a result you should not attempt to upgrade 3rd party software packages individually.
 

Environment

  • BIG-IP
  • BIG-IQ
  • all versions
     

Cause

None
 

Recommended Actions

If you need to upgrade a 3rd party package due to a vulnerability, you must upgrade BIG-IP or BIG-IQ to a fixed release. Refer to the security advisory article for the CVE to determine which release.

If you a have a need for a 3rd party package to be upgraded for another reason, you also must upgrade the BIG-IP or BIG-IQ to your desired version while keeping in mind that it's an entire system upgrade where TMOS (data plane) and all the other 3rd party packages are upgraded as a result. For more information refer to K44525501: Overview of BIG-IP data plane and control plane.

You can check 3rd party software versions for each BIG-IP maintenance version in the following articles; however, the software version listed may have been upgraded in a point or hotfix release due to a vulnerability.
  • K11398383: BIG-IP third-party software matrix (17.x)
  • K48851448: BIG-IP third-party software matrix (16.x)
  • K51874520: BIG-IP third-party software matrix (15.x)
  • K59285635: BIG-IP third-party software matrix (14.x)
  • K65097545: BIG-IP third-party software matrix (12.x -13.x)
  For BIG-IQ:
  • K15861: BIG-IQ third-party software matrix

Additional Information

If you upgrade 3rd party software components individually and experience issues, a clean install of the BIG-IP or BIG-IQ may be required. For more information, refer to:
 K13117:  Performing a clean installation of BIG-IP 11.x - 17.x.
 K33432934: Performing a clean installation of the BIG-IQ hardware system
