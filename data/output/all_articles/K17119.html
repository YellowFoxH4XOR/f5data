Security Advisory Description

Unspecified vulnerability in the MySQL Utilities component in Oracle MySQL 1.5.1 and earlier, when running on Windows, allows local users to affect integrity via unknown vectors related to Installation. (CVE-2015-2576)

Impact

There is no impact; F5 products are not affected by this vulnerability.
