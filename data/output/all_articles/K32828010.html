K32828010: Anti-fraud profile breaks application flow after upgrade

Type
Support Solution
Published
2022-11-02
Updated
2025-02-06
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP FPS
Source
https://my.f5.com/manage/s/article/K32828010

Description

  • Application flow fails after upgrade 15.1.5.1 to 16.1.3.1
  • Anti Fraud profile fictive URL detected as 0day vulnerability requests by AWAF devices

Environment

  • FPS
  • Anti Fraud profile
  • Malware detection

Cause

The device is configured to use a malware detection features of Websafe. Websafe is now EoL K33057152.

Datasafe continues to be supported but does not provide malware detection.

Recommended Actions

Disabled malware detection for the URL in question in the Antifraud profile.

Additional Information

None.
