K000152763: I want to upgrade to 8.4.0 but the /var size is bigger than 75GB

Description

You are planning to upgrade BIG IQ but you have custom size /var on DCDs which is bigger than 75 GB.

Environment

BIG IQ cluster with custom /var size higher then 75GB on DCDs

Cause

During upgrade process BIG IQ is setting new /var size on new partition to default value (75GB) even current size of /var on active boot location is larger. As long as the usage in /var is below 75GB that's not the problem, but when this value is higher, not all statistics will be moved properly, and on new boot location /var will be fully occupied, what also cause read-only state of cluster - BIG IQ is not able to take new statistics.

Recommended Actions

To prepare such upgrade some prerequisites are required, you have to prepare a new boot location with already set custom size /var which will allows you to upgrade smoothly.

1.Check the current /var size on DCD, and note it down

df -h

2. Check the current disk usage - PFree needs to have at least of PSize, if it doesn't please follow K16193 from Related Content section to extend the Virtual Disk size

pvs

config # pvs
  PV         VG        Fmt  Attr PSize    PFree   
  /dev/sda3  vg-db-vda lvm2 a--  <511.79g <412.18g

3. Upload DCD the disk image of BIG IQ version to which you are planning to upgrade

4. Check the current boot locations ID 

tmsh show sys software status 

5. Create the new boot location for upgrade purpose using different ID than listed in 4th step

addvol <install volume> /shared/images//<ISO filename>

addvol HD1.2 /shared/images/BIG-IQ-8.4.0-0.0.139.iso

6.  Resize /var to size collected in 1st step, but calculated from GB to KB (for example 100GB is 104857600)

resizevol /var <size>

resizevol /var 104857600

Note: resizevol tool is changing /var on all boot locations in a system, so be very careful with using that and do not put the lower value then currently used in /var

7. Reboot the DCD

8. Perform the upgrade from BIG IQ CM, but for boot location please choose this one created in 5th step
