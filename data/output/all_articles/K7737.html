Known Issue

This is the result of a known issue. A redundant BIG-IP ASM configuration is unable to perform MySQL replication using the default allowed ports for the self IP address. As a result, the /var/log/asm file will contain error messages similar to the following example:

ASM subsystem error (replication.pl,main::myexit): Problems while trying to enable mysql port on selfip default port list

F5 Product Development tracked this issue as CR79629 and it was fixed in BIG-IP ASM 9.4.2. For information about upgrading, refer to the BIG-IP ASM Release Notes.
