Known Issue

This is the result of a known issue. Some of the Help tabs in the Configuration utility display errant heading information. For example, the SNMP, Access (v1, v2c) online help tab displays the following errant heading at the top of the help file:

System: SNMP: Access
List for SNMP v.1 and
SNMP v.2

Note: This is a display issue; it does not affect system performance.

F5 Product Development tracked this issue as CR116873 and it was fixed in BIG-IP 10.0.1. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, Link Controller, WebAccelerator, or WAN Optimization Release Notes.

In addition, this issue was fixed in hotfix-BIGIP-10.0.0-5460.0-HF1 issued for BIG-IP 10.0.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about installing version 10.x hotfixes on systems with a logical volume management (LVM) disk-formatting scheme, refer to K10025: Managing BIG-IP product hotfixes (10.x). For information about installing version 10.x hotfixes on systems with a partitioned disk-formatting scheme, refer to K9819: Managing F5 product hotfixes for BIG-IP version 10.0.x systems using the partitions disk formatting scheme.
