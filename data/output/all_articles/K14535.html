Topic

You should consider using this procedure under the following condition:
  • You want to configure your BIG-IP APM device so that Network Access clients are able to connect to an FTP server through the tunnel.

Description

For clients to use active FTP in BIG-IP APM Network Access, you must configure a routed configuration where the Network Access object has the SNAT Pool configuration set to None and your back-end FTP servers are configured to route responses back to the clients' lease pool addresses. This is because active FTP requires the FTP server to initiate a connection to the client. If you are unable to configure a routed configuration in your network environment and must use a SNAT pool or AutoMap in your Network Access SNAT Pool configuration, you can create an FTP BIG-IP LTM virtual server to enable your clients to continue using active FTP.

Prerequisites

You must meet the following prerequisite to use this procedure:

  • You already have a working Network Access virtual server that users can connect to reach an FTP server.

Procedures

  • Creating an FTP BIG-IP LTM virtual server

    Immediately disable Address Resolution Protocol (ARP) on the FTP virtual server following the creation of the virtual server. To do so, perform the Disabling ARP on the newly created FTP virtual server procedure.

  • Disabling ARP on the newly created FTP virtual server

Creating an FTP BIG-IP LTM virtual server

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers.
  3. Click Create.
  4. Type a name for the FTP virtual server.
  5. For Type, click Standard.
  6. For Destination Address/Mask, click Host and enter the network IP address of your FTP server.

    Note: For versions earlier than BIG-IP 14.x, enter the network IP address of your FTP server.

  7. For Service Port, click FTP.
  8. For Configuration , click Advanced.
  9. For Protocol, click TCP.
  10. For Protocol Profile (Client), click TCP.
  11. For Protocol Profile (Server), click TCP.
  12. For FTP Profile, click FTP.
  13. For VLAN and Tunnel Traffic, click Enabled on from the menu.
  14. For VLANs and Tunnels, in the Available list, click the VLANs for which the clients will access (the Connectivity profile of your Network Access virtual server), and the VLAN of the destination resources that will initiate FTP sessions and move them to the Selected list.
  15. For Source Address Translation, click a SNAT pool or Auto Map.
  16. Clear the Enabled check boxes for Address Translation and Port Translation.
  17. Click Finished.

Disabling ARP on the newly created FTP virtual server

  1. Log in to the Configuration utility.
  2. Navigate to Local Traffic > Virtual Servers > Virtual Address List.
  3. Click the IP address of the newly created FTP virtual server.
  4. Under Configuration, for ARP, clear the check box to disable ARP for the virtual address.
  5. Click Update.
