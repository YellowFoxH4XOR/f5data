Issue

Users may receive the Couldn't connect to terminal server error message for several reasons. The most common causes of this error message include the following:

  • The target machine may not be accessible from the FirePass Controller
  • The antivirus software or firewall on the client machine may be preventing FirePass components from establishing a connection
  • The mstsc functionality may be corrupt or misconfigured

Note: In the event that you are still unable to resolve this issue, contact F5Technical Support for additional assistance.

The target machine may not be accessible from the FirePass Controller

The FirePass controller needs to have a functional network path to the target machine. You may try taking a network packet dump while trying to connect to the target machine.

Note: For more information, refer to K9704: Capturing and viewing packets for instructions.

If the packet capture shows that the FirePass Controller sends SYN packets, but does not receive any reply packets, there may be no functional network path between the two machines.

The antivirus software or firewall on the client machine may be preventing FirePass components from establishing a connection

Check the antivirus software or firewall on the client machine to ensure that the FirePass components have not been falsely identified as suspect software. Reference your vendor documentation about how to examine your antivirus or client firewall.

The mstsc functionality may be corrupt or misconfigured

If mstsc is corrupt or misconfigured, the Couldn't connect to terminal server error message is usually coupled with the following error message in the terminal server connection window:

Error setting server property

You can resolve this issue by running the following command from an MS-DOS prompt:

regsvr32 mstscax.dll

Important: Before taking actions that may affect your client's drivers, make sure to fully test the solution.
