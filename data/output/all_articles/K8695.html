Known Issue

This is the result of a known issue. As a result of installing cumulative hotfix HF-602-4 on a FirePass controller running software version 6.0.2, when a user employs a Portal Access favorite to access a Microsoft Outlook Web Access (OWA) account, the Reply, Reply-all and Forward functions of email composition may fail to include the quoted text of the message to which the user is responding. Instead, a blank composition window may be presented.

Additionally, the browser may indicate a script error. Using Internet Explorer 6, the script error icon in the status bar may be displayed, along with the Done, but with errors status. Clicking on the script error icon will display an error message that appears similar to the following example:

Line: 214
Char: 522
Error: Object does not support this property or method
Code: 0

Other browsers may produce similar error messages. The OWA email composition window will function normally in all other respects.

Note: This issue occurs when using the most recent version of the Portal Access Web Application engine.

F5 Product Development tracked this issue as CR98994 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass release notes.

Additionally, cumulative hotfix HF-602-5 has been issued for FirePass version 6.0.2. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

To work around this issue, you can install HF-602-5 or uninstall cumulative hotfix HF-602-4. To uninstall cumulative hotfix HF-602-4, perform the following procedure:

  1. In the Administrative Console, click Current Settings from the navigation frame.
  2. In the FirePass Hot-Fixes field of the FirePass Version section, click the HF-602-4 link.
  3. Click the Uninstall hot-fix link.

    A confirmation pop-up window appears.
  4. Click the OK button.

    You should receive a message that appears similar to the following example:

    The Hot-fix was un-installed successfully

Important: Uninstallation of cumulative hotfix HF-602-4 will automatically perform a services restart, which may temporarily interfere with users' FirePass sessions, depending on the FirePass favorites and resources that the users access.
