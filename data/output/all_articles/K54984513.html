Description
The symptom is very similar to K60445773: Taking UCS archive on GUI fails with error "Internal Server Error", but using tmsh to take a UCS archive still fails. You may observe several symptoms like below.

  • Taking a UCS archive on GUI fails after 5 minutes and returns the below error message:

Internal Server Error
The server encountered an internal error or misconfiguration and was unable to complete your request.
Please contact the server administrator at support@f5.com to inform them of the time this error occurred, and the actions you performed just before this error.
More information about this error may be available in the server error log.

  • There are message similar to the following in /var/log/httpd/httpd_errors.

err httpd[<PID>]: [proxy_ajp:error] [pid <PID>] [client <client-ip>:2576] AH00992: ajp_read_header: ajp_ilink_receive failed, referer: https://<bigip-ip>/tmui/Control/jspmap/tmui/system/archive/create.jsp
err httpd[<PID>]: [proxy_ajp:error] [pid <PID>] (70007)The timeout specified has expired: [client <client-ip>:2576] AH00878: read response failed from 127.0.0.1:8009 (localhost), referer: https://<bigip-ip>/tmui/Control/jspmap/tmui/system/archive/create.jsp

  • There are messages similar to the following in /var/log/ltm.

err syscalld[5711]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/bin/tmsh (pid 20251) may be hung or taking a long time. err syscalld[5711]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/bin/tmsh (pid 20251) timed out, so we are no longer monitoring it. err syscalld[5711]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/bin/tmsh (pid 22760) may be hung or taking a long time. err syscalld[5711]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/bin/tmsh (pid 22760) timed out, so we are no longer monitoring it. err syscalld[5711]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/bin/tmsh (pid 26657) may be hung or taking a long time. err syscalld[5711]: 0127000a:3: OPERATION_TIMEOUT -- the operation /usr/bin/tmsh (pid 26657) timed out, so we are no longer monitoring it.

  • Running ps aux command and egrep using the PIDs shown in the logging message above shows several config save processes like below.

Environment

  • Taking a UCS archive on GUI fails after 5 minutes and returns "Internal Server Error"
  • Taking a UCS archive on CLI (tmsh) does not complete forever

Cause
The issue may be due to ID 1062953.

Recommended Actions
In the example above shown in the description field, syscalld is the parent process that created the tmsh process to save the config where the tmsh process hangs. A restart of syscalld using bigstart restart syscalld will kill the hung syscalld and tmsh processes and restore services.

bigstart restart syscalld
