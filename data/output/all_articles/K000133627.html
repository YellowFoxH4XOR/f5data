Description

SNMP service restarting logger message continuously gets generated in the putty session.

logger[29094]: Re-starting snmpd 2023 Apr 20 05:37:38 f5-lab.local logger[29094]: Re-starting snmpd

Broadcast message from systemd-journald@f5-lab.local (Thu 2023-04-20 05:37:40 UTC):

logger[29149]: Re-starting snmpd2023 Apr 20 05:37:40 f5-lab.local logger[29149]: Re-starting snmpd



Verify /Var/log/daemon.log log file and you observe below logs.
 

Apr 20 05:50:14 f5-lab.local err snmpd[21532]: Server Exiting with code 1

Apr 20 05:50:15 f5-lab.local emerg logger[21623]: Re-starting snmpd

Apr 20 05:50:15 f5-lab.local warning sflow_agent[8092]: Warning: Failed to connect to the agentx master agent ([NIL]):

Apr 20 05:50:16 f5-lab.local err snmpd[21598]: Error opening specified endpoint "192.168.1.11"

 

In the bigip_base.conf file, noticed a wrongly configured SNMP configuration with agent-address having unwanted entries.
 

sys snmp {

    agent-address {tcp6:161 udp6:161 192.168.1.11 192.168.1.12} ----> snmp agent-address configuration issue.

    allowed_address {none} {0.0.0.0/0}

    auth-trap none

    }

Environment

BIG-IP 13.X or higher

After software upgrade

SNMP
 

Cause

BIG-IP SNMP configuration needs to be revalidated.


Recommended Actions


Please reconfigure the SNMP agent address by following below steps.
Note: Before doing any change to the configuration take backup of the configuration.


Impact: Stopping and starting SNMPD service will cause temporary disruption to the snmp monitoring service of the BIG-IP device.


# bigstart stop snmpd

# tmsh modify sys snmp agent-addresses replace-all-with { tcp6:161 udp6:161 }

# tmsh save sys config

# bigstart start snmpd
 

After the above steps the configuration would look like below:

 

sys snmp {

agent-addresses { tcp6:161 udp6:161 }

allowed_address {none} {0.0.0.0/0}

auth-trap none

}
