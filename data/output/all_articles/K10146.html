RSA SecurID is a two-factor authentication scheme that uses a combination of a known password and a digitally generated string to grant access to the FirePass controller.

Note: For more information about RSA SecurID authentication, refer to the FirePass Controller Administrator Guide.

To configure RSA SecurID authentication in a FirePass cluster, perform the following two procedures:

  • Configuring the Agent Host records on the RSA server
  • Configuring RSA SecurID authentication in a FirePass cluster configuration

Configuring the Agent Host record on the RSA server

Note: The following RSA configuration steps are for RSA Authentication Manager 6.1. The build version can be found from your RSA Authentication Manager GUI under Help: About Database Administration.

Important: You must create an individual Agent Host and corresponding record file for each FirePass node in the cluster.

To configure the Agent Host records on the RSA server, perform the following procedure:

  1. Create a FirePass controller Agent Host.

    For example:

    Name: “firepass_master.siterequest.com” or “firepass_slave1.siterequest.com”
        Network address: <real/self or NAT translated IP address of the FirePass node>

    Important: Because the FirePass controller is a multi-homed appliance with multiple IP addresses, the Network address setting is very important. If there is a NAT device between the FirePass controller and the RSA authentication server, enter the translated IP address of the FirePass controller. If there is not a NAT device between the FirePass controller and the RSA authentication server, enter the real/self IP address of the FirePass  node. If you have multiple interfaces configured on the FirePass controller, enter the real/self IP address of the interface closest to the RSA authentication server.

    Note: F5 is working to eliminate exclusionary language in our products and documentation. For more information, refer to K34150231: Exclusionary language in F5 products and documentation.

    Agent type: Unix Agent

    Encryption Type: DES

    Secondary Nodes: <none>

    Other settings: For the remaining Agent Host settings, configure the settings appropriate for your environment.

  2. Generate and download the configuration file for the FirePass Agent Host you created.

    Note: This configuration file is typically named sdconf.rec. This file can be named and renamed to match the Agent Host it was generated from. For example, for the firepass_master.siterequest.com Agent Host, the RSA record could be named sdconf_master.rec, or for the firepass_slave1.siterequest.com Agent Host, the RSA record could be named sdconf_slave1.rec.

  3. Activate the FirePass Agent Host for group and/or user profiles that require access to the FirePass controller.
  4. Repeat Steps 1 through 3 for each FirePass node in the cluster.

Configuring RSA SecurID authentication in a FirePass cluster

To configure RSA SecurID authentication in a FirePass cluster, perform the following procedure:

  1. Log on to the Administrative Console of the FirePass primary controller.
  2. Navigate to the Clustering: Stats page.     

    If any synchronization errors are reported, resolve those issues before proceeding to Step 3.    

  3. Navigate to Device Management: Configuration: RSA SecureID.
  4. In the Name field, enter a name to identify your RSA server.     

    Note: This name is for local use and does not need to be DNS resolvable.

    For example:

    rsasrv1

    Important: The Name field must be the same on all FirePass nodes in the cluster. The names are case-sensitive.

  5. In the Configuration File field, enter the full path to the Agent Host configuration file you downloaded in Step 2 of the Configuring the Agent Host record on the RSA Server procedure.

    For example:

    C:\sdconf.rec

    Note: The RSA record file name does not need to be the same name for all FirePass nodes in the cluster.

    For example, for firepass_master.com, you would upload C:\sdconf_master.rec, and for firepass_slave1.com, you would upload C:\sdconf_slave1.rec.

  6. In the Source IP field, enter the IP address you configured for the Network address setting on the RSA authentication server.

    Important: RSA authentication will not work unless the IP address you enter in this field matches the IP address you entered for the Network address setting in Step 1 of the Configuring the Agent Host record on the RSA Server procedure.

  7. Click the Add button.

    Note: Steps 8 through 16 are for the FirePass primary node only. If you are configuring a secondary node, skip to Step 17.

  8. Navigate to the Users: Groups: Master Groups page.
  9. Click the Create new group button.
  10. In the New group name field, enter the name of the new master group.
  11. In the Users in group field, select Local or External.
  12. In the Authentication Method menu, select RSA SecurID.
  13. Click the Create button.     

    This step brings you to the master group configuration page.    

  14. Click the Authentication tab.
  15. Under Configure RSA SecurID Server Settings, select the RSA configuration profile that you created.
  16. Click Update.
  17. For each secondary node in the cluster, repeat Steps 3 through 7.

The FirePass cluster is now configured for RSA SecurID authentication.
