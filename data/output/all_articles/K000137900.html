Description

"No base image installed or compatible volume to install the Hotfix" message when attempting hotfix or Engineering Hotfix upgrade on VE installed from qcow, OVA, or OVF image

Environment

BIG-IP VE

Cause

VE installed from a hypervisor image template doesn't have the base version ISO in the filesystem

Recommended Actions

Retrieve base image from MyF5 Downloads and put it in /shared/images

Additional Information

None
