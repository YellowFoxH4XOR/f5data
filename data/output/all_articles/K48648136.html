Topic

This article discusses requirements for opening a support case for a BIG-IP Next instance or BIG-IP Next Central Manager. For information about requirements for opening a support case for other F5 products, refer to K2633: Instructions for submitting a support case to F5.

F5 Support can help resolve issues more quickly when you provide a full description of the issue and the details of your configuration. Use the following guidelines to gather all of the required information when preparing to open a case.

Description

General Information

Provide the following information when you open a case with F5 Support:

  • A full description of the issue, including the following:
    • The symptoms of the issue
    • The approximate time the issue first occurred
    • The number of times the issue has recurred
    • Any error output provided by the system
    • Steps to reproduce the issue
    • Any changes you made to the system before the issue first occurred
    • Any steps you have taken in an attempt to solve the issue
    • Whether or not the implementation is new
    • If you have uploaded a QKView file to F5 iHealth:
      • Inform Support of the QKView files that you have uploaded to iHealth, and provide the links.
      • Inform Support of the search criteria you used on the AskF5 that did not render an article, if applicable.
  • A description of your issue's impact, using the following definitions:
    • Site Down

      Your network or application is down, or critical business functions have stopped due to the issue.

    • Site at Risk

      Your network or application is severely and negatively impacted by the issue.

    • Performance Severely Degraded

      The performance of your network or application has been severely reduced due to the issue.

    • General Assistance Required

      The subject of the case does not currently impact your network or application.

  • The hours that you are available to work on the issue, and any alternative contacts who can work on the issue if you are not available.
  • Remote access information, if possible. Remote access to your network environment is important because it is the most effective method for collecting information and troubleshooting technical issues. If you cannot provide remote access, F5 Support will work directly with you to resolve the issue over the phone. However, this method can often be more time consuming and may require file transfers, replication, and additional testing.
Product-specific information

Provide the following information when you open the case. For information about how to send information to F5, refer to K000090853: Exchange files with F5 Support using MyF5.

The qkview utility

A QKView diagnostic file contains the configuration files that F5 Support most frequently needs when troubleshooting an issue.

For more information about qkview for a BIG-IP Next instance, refer to K50050103: Generating a QKView diagnostic file for a BIG-IP Next instance using the BIG-IP Next Central Manager.

For more information about qkview for a BIG-IP Next Central Manager, refer to K000136946: Generate a QKView diagnostic file for BIG-IP Next Central Manager.

Packet traces

If the issue involves the network, perform a packet trace while the issue is occurring and provide the packet trace when you open the case.

For more information about performing packet traces with tcpdump on BIG-IP Next instance, refer to K11372938: Overview of the tcpdump utility on BIG-IP Next instances.

For information about performing packet traces on BIG-IP tenants systems, refer to K411: Overview of packet tracing with the tcpdump utility.

If the traffic in question is encrypted, you should decrypt the packet trace using the ssldump utility.

For more information about decrypting encrypted traffic, refer to K10209: Overview of packet tracing with the ssldump utility.
