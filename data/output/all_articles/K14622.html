Known Issue

Secure Sockets Layer (SSL) renegotiation may stall when using the Proxy SSL feature.

This issue occurs when the following conditions are met:

  • The Proxy SSL setting is enabled in the Client and Server SSL profiles.
  • The client initiates an SSL renegotiation.

The Proxy SSL feature provides the BIG-IP system the ability to optimize SSL traffic between the client and the destination server without having the SSL connection terminate on the BIG-IP system. When the Proxy SSL feature is enabled for a virtual server and the client renegotiates an SSL session, the BIG-IP system may fail to proxy the client Finished record. This behavior causes the connection to stall for the duration of the SSL Alert Timeout, which is 10 seconds, by default.

Impact

SSL connections may stall or fail.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H427297 on the Diagnostics > Identified >Medium screen.
  • Client-initiated connections through a virtual server using the SSL Proxy feature may stall or fail.
  • Error messages similar to the following example may be logged to the /var/log/ltm file:

    tmm info tmm[9054]: 01260013:6: SSL Handshake failed for TCP from 10.12.23.121:34690 to 10.12.23.27:443

    tmm debug tmm[9054]: 01260009:7: Connection error: ssl_hs_pxy_scan:5978: malformed ssl record len (80)
