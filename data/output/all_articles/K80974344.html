K80974344: In a BIG-IQ high availability configuration, the primary active device syncs to the secondary standby device

Type
Support Solution
Published
2022-08-26
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K80974344

Description
In a BIG-IQ high availability configuration, the BIG-IQ system replicates configuration changes since the last synchronization from the primary device to the secondary device every 30 seconds by design. Making changes to the standby secondary BIG-IQ are not synched to the active primary BIG-IQ.

Environment

  • BIG-IQ HA pair

Cause
This is by design, see the manual chapter below.
 

Recommended Actions

  1. Only make changes on the active primary BIG-IQ.

Additional Information
