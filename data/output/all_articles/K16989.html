Known Issue

Access policy configurations can trigger misleading log messages.

This issue occurs when all of the following conditions are met:

  • Your BIG-IP APM configuration includes an access policy that queries Active Directory and does not require a password.
  • An event triggers the access profile to execute the Active Directory query.

Impact

Misleading messages are logged to the /var/log/apm file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When the access profile queries Active Directory, log messages similar to the following example are written to the /var/log/apm file:

    err apd[17032]: 01490000:3: modules/Authentication/Ldap/LdapAgent.cpp func: "getLdapUserInput()" line: 718 Msg: 4121b75d: LDAP Agent: getLdapUserInput(): unable to decrypt user password due to NULL ciphertext.

Note: You can safely ignore the log messages.
