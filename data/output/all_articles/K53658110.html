Description

Citrix receiver client fails to change AD password in replacement mode (without Storefront).  There is no prompt/field saying domain password is expired.

"500 internal Server Error" is seen in the packet captures

Environment

  • BIGIP APM
  • Citrix replacement mode (without Storefront)

Cause

"Enable StoreFront Functionality on APM" is disabled under VDI profile -> citrix settings

Recommended Actions

Enable the setting "Enable StoreFront Functionality on APM" under VDI profile -> citrix settings

Additional Information

The packet capture shows 500 Internal Server Error for the below POST request:

POST /Citrix/PNAgent/enum.aspx HTTP/1.1
HTTP/1.1 500 Internal Server Error
