Topic

Historically the ARX did not support Kerberos authentication for Mac OS X clients because the Mac OS X client did not use a Kerberos ticket that could be forwarded. However, changes to both ARX and the Mac OS X clients have introduced support for Kerberos authentication to an ARX CIFS service by Mac OS X clients.

The following changes have introduced support for Kerberos authentication to an ARX CIFS service by Mac OS X clients:

  • Beginning in ARX version 5.2.0, F5 added support for Constrained Delegation, which removed the requirement for a Kerberos ticket that could be forwarded.
  • Beginning in the Mac OS X 10.6.6 client, Kerberos Ticket-Granting Tickets (TGT) that can be forwarded are used.

ARX supports Kerberos authentication for the following Mac OS X clients:

Mac OS X 10.6.1 and earlier clients

No ARX versions support Mac OS X 10.6.1 and earlier clients using Kerberos authentication to an ARX CIFS service.

Mac OS X 10.6.2 to 10.6.5 clients

ARX version 5.2.0 and later support Mac OS X 10.6.2 to 10.6.5 clients using Kerberos authentication to an ARX CIFS service if the CIFS service is joined to the Active Directory Domain using Constrained Delegation. Constrained Delegation requires ARX version 5.2.0 or later.

Mac OS X 10.6.6 and newer clients

Beginning in the Mac OS X 10.6.6 client, Kerberos Ticket-Granting Tickets (TGT) that can be forwarded are used and Constrained Delegation is no longer a requirement. As a result, ARX version 5.1.0 and later will support Mac OS X 10.6.6 and newer clients using Kerberos authentication to an ARX CIFS service. Support for Mac OS X version 10.6 was introduced in ARX version 5.1.0.
