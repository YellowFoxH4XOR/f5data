K4242: The im -Q command does not always report the correct versions for installed packages

Known Issue

This is the result of a known issue. IM upgrade packages include only the files that are new or have been modified since the previous IM package version was installed. Because the entire package is not included, the version of software that the IM database reports does not change. As a result, the im -Q command does not report the correct version number.

F5 Networks Product Development tracked this issue as CR30877.
