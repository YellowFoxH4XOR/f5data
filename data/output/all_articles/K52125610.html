Description

After upgrading your Microsoft .NET server to version 5.0, your website fails and returns ERR_CONNECTION_RESET.

  • The .NET server's logs may show HTTP 0.9 requests from the BIG-IP system's non-floating / "local-only" self-IP address.
  • The virtual server may return ERR_CONNECTION_RESET to the client.
  • The LTM pool is marked DOWN.

Environment

  • BIG-IP LTM pool with an HTTP or HTTPS monitor applied.
  • Your HTTP or HTTPS monitor has not specifically been configured to send an HTTP 1.1 or HTTP 1.2 style request. (The default format sends an HTTP 0.9 request) 

Cause

Microsoft .NET version 5.0 no longer supports HTTP 0.9 requests.

Recommended Actions

Configure a custom BIG-IP LTM health monitor, with an appropriate HTTP 1.0 or HTTP 1.1 style request. For more information, see K2167.
