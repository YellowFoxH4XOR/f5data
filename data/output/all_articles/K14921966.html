Issue

Error Message

notice pgadmind[<PID>]: 0189000b:5: Shutting down postgres.

In this error message, note the following:

  • <PID> is the process ID for the pgadmind process

For example:

notice pgadmind[2325]: 0189000b:5: Shutting down postgres.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when the following condition is met:

  • The pgadmind process initiates shutdown of the PostgreSQL server.

Impact

You are unable to view or edit BIG-IP AFM firewall rules while the PostgreSQL server is down.

Recommended Actions

None
