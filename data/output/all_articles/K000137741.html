Description

After configuring virtual server with HTTP/2 profile, some client connections can receive RST_STREAM message from BIG-IP LTM, after inspecting the HTTP/2 messages from sending client, the following error can be seen:

[ 0.011] recv SETTINGS frame ; ACK (niv=0) [ 0.011] recv GOAWAY frame (last_stream_id=13, error_code=FRAME_SIZE_ERROR(0x06), opaque_data(0)=[]) [ 0.011] recv RST_STREAM frame  (error_code=STREAM_CLOSED(0x05))

Environment

  • BIG-IP LTM
  • Virtual server with HTTP/2 client profile.

Cause

This issue occurs when the client request headers exceeds the value of Maximum Header Count configured within the HTTP (1) profile

Recommended Actions

You can increase the Maximum Header-Count in the HTTP(1) profile. To do so, perform the following procedure:

  • Log in to the Configuration utility as the admin user.
  • Navigate to Local Traffic > Profiles > Services > HTTP.
  • Select the HTTP profile that handles your affected traffic.
  • Change the Maximum Header Count to a higher value, such as 128.
  • Click Update.
