Issue

Error Message

No Such Object available on this agent at this OID

For example:

config # snmpwalk -v 2c -c public localhost sysDot3StatTable
F5-BIGIP-SYSTEM-MIB::sysDot3StatTable = No Such Object available on this agent at this OID

In BIG-IP 11.4.0 and later, the BIG-IP system may also log an error message that appears similar to the following example, when you attempt to access sysDot3StatTable statistics:

err mcpd[7803]: 0107167d:3: Data publisher not found or not implemented when processing request (unknown request), tag (81).

Message Location

You may encounter this message in the following locations:

  • SSH console output
  • The /var/log/ltm file

Description

The BIG-IP 2000s/4000s series platforms, Virtual Clustered Multiprocessing (vCMP) and BIG-IP Virtual Edition (VE) do not support EtherLike interfaces. Therefore, the BIG-IP system may respond with the previously mentioned error message if you make an SNMP request to query sysDot3StatTable interface statistics.

This message occurs when the following condition is met:

  • You attempt to access sysDot3StatTable interface statistics by way of SNMP on affected platforms.

Impact

You can safely ignore this message. The SNMP query will not return any data.

Recommended Actions

F5 recommends that you do not query sysDot3StatTable statistics on affected platforms.
