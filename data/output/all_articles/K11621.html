Known Issue

This is the result of a known issue. If a TACACS+ reply includes a text string in addition to the three digit response code, TACACS+ authentication fails even if the user supplied valid credentials to the BIG-IP system. As described in RFC1492, TACACS servers may include an optional text string such as Signon Successful in addition to the three digit response code.

F5 Product Development tracked this issue as CR121891 and it was fixed in BIG-IP 10.1.0. For information about upgrading, refer to the BIG-IP LTM, ASM, GTM, PSM, Link Controller, WebAccelerator, APM, WOM, or Edge Gateway release notes.

Workaround

You can work around this issue by ensuring that your TACACS+ server does not include text strings in TACACS+ replies. It has been reported that recent versions of the tac_plus software package include a text string in the TACACS+ reply. Since this is not a configurable option for the tac_plus software, you can either upgrade to BIG-IP version 10.1.0 or later, or run an older version of the tac_plus software on the TACACS+ server, such as tac_plus version 4.0.x.
