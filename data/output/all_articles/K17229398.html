Description

After editing UCS file and recompressing the archive under a macOS environment the macOS adds new archives with (._)  before the name of the archive to load. As a result, mcpd is unable to load these files, causing the device to be in an inoperative state and mcpd starts a restarting loop.

/var/ltm/log:

err mcpd[8875]: 01070734:3: Configuration error: MCPProcessor::initializeDB: directory traversal, can't open directory (/ileconfig/fstore/files_d/._Common_d) err (Not a directory).

err mcpd[10253]: 01070734:3: Configuration error: MCPProcessor::initializeDB: directory traversal, can't open directory (/config/filestore/files_d/._Common_d) err (Not a directory).

Environment

  • UCS Archive
  • Decompress on MacOs

Cause
The macOS environment adds new archives with (._)

Recommended Actions

  1.  Edit the configuration directly in the BIG-IP. 
or, 
  1.  Decompress and recompress the UCS archive under a different OS environment.
