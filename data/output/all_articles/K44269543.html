K44269543: ''Unable to verify SSL certificate presented by the server'' error when connecting to VPN using F5 Access app for Android

Type
Support Solution
Published
2021-05-31
Updated
2023-02-21
Applies to
  • F5 Access
Source
https://my.f5.com/manage/s/article/K44269543

Description

Android users are getting "SSL error Unable to verify SSL certificate presented by the server" error when connecting to the VPN using the F5 Access app.

Environment

  • BIG-IP APM with a Network Access resource configured and assigned in the access policy VPE
  • Android mobile
  • F5 Access app

Cause

Some Android devices may not have the intermediate certificate (that is used to establish the trust between the server certificate and the root CA cert) in its Certificate store, and this is what's causing the "Unable to verify SSL certificate" error when connecting using the Android F5 Access app.

Recommended Actions

Download the intermediate certificate from your CA and import it onto the BIG-IP. Then include this intermediate cert in the clientssl profile attached to the VS.
