Description

A Man-in-the-Middle (MITM or MitM) attack is any attack in which the attacker intercepts the communication between the target (user) and the legitimate application the user is accessing by positioning themselves in the network path so that they can eavesdrop on and potentially manipulate the traffic between user and application.

A real-world analogue of this would be an attacker intercepting your mail before it was delivered to you or when it was posted by you, opening and reading or changing the contents, re-sealing it and ultimately delivering it to the originally intended destination.

Environment

A client computer communicating via any network protocol to a remote system (e.g., a web application being delivered to a web browser on a client device)

Cause

  • A network vulnerable to one or more of:
    • IP Spoofing
    • ARP Spoofing
    • DNS Spoofing
  • Or, use of unsecured, untrusted WiFi networks (e.g., public WiFi) without mitigating measures

Recommended Actions

If you are an application owner you should ensure your application uses robust TLS settings and does not allow clear-text communications (e.g., web applications are available via HTTPS and HTTP requests are automatically redirected to HTTPS) to prevent eavesdropping by an attacker.

Most protections, however, are more easily applied by the end users:
  • Avoid untrusted public WiFi or, if you must use public WiFi, use a VPN as an additional layer of protection against eavesdropping
  • Ensure any website you access is via HTTPS and that the certificate presented in the browser is valid and expected
  • Pay attention to any alerts that the resource you are accessing is untrusted or unsecured (e.g., from your browser)
