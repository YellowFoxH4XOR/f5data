Issue

Old Behavior

In versions prior to BIG-IP 12.1.0, the tmsh show /cm device command displays a static list of properties for the device in which the command is run; the output is similar to the tmsh list /cm device command output, and includes minimal real-time statistical or status information relevant to the device. In versions prior to 12.1.0, the tmsh show /cm device output is similar to the following example:

New Behavior

Beginning in BIG-IP 12.1.0, the tmsh show /cm device command is updated to include more useful information, such as statistical and status information relevant to the device in which the command is run. In BIG-IP 12.1.0, the tmsh show /cm device output is similar to the following example:

---------------------------------------------------
CentMgmt::Device: bigip_12.pslab.local
----------------------------------------------------
Hostname                        bigip_12.pslab.local

Device HA State                 active

Impact

None

Recommended Actions

In BIG-IP 12.1.0, some informational fields were removed from tmsh show /cm device command output. You can display the informational fields and other static properties for a device by running the tmsh list /cm device command.
