K4425: Creating a UCS archive that does not contain SSL private keys

Topic

By default, the SSL private keys are included when you create a UCS archive. This ensures that the UCS archive contains a full backup of critical system files and that the private keys can be synchronized during configuration synchronization. You should control the SSL private keys as tightly as possible to prevent compromise of your site.

If you need to store your UCS archives in locations that are not secure, or if you do not want to share your private keys with F5 Networks Technical Support, you can create a UCS archive that does not contain SSL private keys.

To create a UCS archive that does not contain SSL private keys, use the following command syntax:

bigpipe config support save <filename>

Replace <filename> with the name you want to use for the UCS archive file. If you do not specify a path, the file will be stored in the /usr/local/ucs directory.
