Description

You notice that the pool members for a pool is unable to load balance connections evenly


 Environment

  • Round Robin Load Balancing Method
  • Multiple Pool Members
  • No Persistence Profile
  • No One connect profile
  • No iRule configured

 Cause

Instead of using Current Connection to determine if the Pool is load balancing evenly you should calculate the Delta of Total Connection


 Recommended Actions

You can view the number of total connections for each pool member in the GUI which can be helpful in determining the delta value.

To get the difference of the Total connection do the following:


  1. Go to Local Traffic > Pools > Pool Lists
  2. Select the Pool in question
  3. Click on Statistics Tab for the said Pool to view
  4. Check Connections column and note the value for Total Connection for all Pool members
  5. Do step 4 again after 1 hour and subtract the difference to get the delta value and compare
