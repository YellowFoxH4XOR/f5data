Description

An error message generated /shared disk partition is low on space. And the /shared partition is filled with configsync.im files 

For example: Run the command as recommended in K14403 to find the largest files in the /shared partition.

# find /shared -xdev -type f | xargs du | sort -rn | head -20
274252  /shared/tmp/im23111/configsync-2.0-1-Linux-3.10.0862.14.4.7.8664.im
274244  /shared/tmp/im21234/configsync-2.0-1-Linux-3.10.0862.14.4.7.8664.im
274232  /shared/tmp/im21098/configsync-2.0-1-Linux-3.10.0862.14.4.7.8664.im
...

Environment

  • Generating UCS files 
  • /shared partition is full

Cause
When UCS file is generated using script or third-party device, and the script is killed before UCS is completed, temporary orphaned .im files get created in /var/tmp/imxxxx
(where xxxx is the pid of the tmsh process that created it).

Recommended Actions

.im files can be safely removed, however, if the system is still generating these files, further troubleshooting is needed.

Additional Information

None.
