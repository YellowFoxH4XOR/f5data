Description

When deploying a configuration with route-domains involved a BIG-IQ throws the following warning:

 

[INFO][14 Jan 2024 10:08:48 CET][/cm/adc-core/tasks/verify-config/fe36768e-24b0-415f-bd7a-7dd28a494c08/worker AdcVerificationTaskWorker] Verification error: Missing Route domain with id XXX on the device, This Route domain is required by [monitor_ltm]

 

The actual deployment is successful though.

 

Environment

BIG-IQ 8.2.x.

Configuration contains LTM monitors with route-domains.

 

Cause

ID710588.

 

Recommended Actions

None.

 

Additional Information

Bug ID710588 False alarm on route domain verification
