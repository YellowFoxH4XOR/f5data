Description

When you try to run tcpdump via GUI, you may not be able to select any VLANs.

Environment

  • BIG-IP 
  • GUI System >> Support >> Support, click New Support Snapshot then select Generate TCPDump

Cause

Unknown at time of publication.

Recommended Actions

Follow K13030 or use CLI instead of GUI.
