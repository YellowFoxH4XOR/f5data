Issue

Error Message

err mcpd[<PID>]: 01071d79:3 Interface <#> cannot be used in passive/virtual-wire mode

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <#> is the interface number.

For example:

err mcpd[4857]: 01071d79:3 Interface 2.4 cannot be used in passive/virtual-wire mode

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
  • The /var/log/webui.log file

Description

This message occurs when all of the following conditions are met:

  • You attempt to configure an interface for Passive or Virtual Wire forwarding mode.
  • The interface is not eligible for Passive or Virtual Wire mode due to a restriction.

For example, certain BIG-IP hardware platforms have more than 31 logical ports, however, only the logical ports numbered lower than 32 are eligible to be configured in Virtual Wire mode. Attempting to configure an interface with a logical port of 32 to use Virtual Wire forwarding mode results in this error message.

Impact

The interface cannot be used in Passive or Virtual Wire mode.

Recommended Actions

Try configuring Virtual Wire or Passive mode on another port, one that is either not in use or is operating in Layer 3 (L3) mode. Note that changing the mode of a port currently operating in L3 mode to Virtual Wire mode results in changes to the network.

To view the logical ports for the interfaces, use the guishell -c "select name,PHYSPORT from interface order by PHYSPORT" command.  For example, on an i10800 platform, output looks similar to the following:
