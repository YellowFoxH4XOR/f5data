When an ARX system restarts, the system sends a warmStart SNMP trap indicating the reason for the restart. The ARX system logs the trap message in both the traplog and syslog files.

You can search for the warmStart trap messages on the ARX system by typing the following commands:

grep warmStart logs syslog

grep warmStart logs traplog

The warmStart messages in syslog will appear similar to the following example:

: SNMP TRAP: mib2 warmStart: reboot cause unknown: possible power failure

The warmStart messages in traplog will appear similar to the following example:

- mib2 warmStart: reboot cause unknown: possible power failure
