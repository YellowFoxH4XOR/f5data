Description

  • You want to route most, if not all, client traffic through BIG-IP APM Network Access tunnels
  • You want to exclude a subset of addresses from being routed through BIG-IP APM Network Access tunnels
  • BIG-IP APM Network Access tunnels generated via a web browser, Edge Client or F5 Access

Environment

  • BIG-IP APM Network Access

Cause

This is expected behavior.

Recommended Actions

To route all but a select subset of client traffic through BIG-IP APM Network Access tunnels you will need to implement the following BIG-IP APM Network Access settings:

  1. Login to the BIG-IP APM Configuration utility.

  2. Navigate to Access > Connectivity/VPN > Network Access (VPN) > Network Access Lists > [Network Access object] > Network Settings tab
    Notes: If a Network Access object does not already exist then you will need to create one. 
    For versions prior to BIG-IP APM 12.1.0, navigate to Access Policy > Network Access > Network Access List.

  3. Enable Use split tunneling for traffic.

  4. Configure IPV4 LAN Address Space [and "IPV6 LAN Address Space"] with a broad range of addresses that you want routing through BIG-IP APM Network Access tunnels, such as "0.0.0.0/0.0.0.0" for IPv4 [and "::/0" for IPv6].

  5. Configure DNS Address Space with one or more string patterns representing domain names that you want resolved through BIG-IP APM Network Access tunnels,
    Example: host_1.example.com or *.example.com or * (everything)

  6. Configure IPV4 Exclude Address Space [and "IPV6 Exclude Address Space"] with addresses that you want excluded from routing through BIG-IP APM Network Access tunnels.

  7. Configure DNS Exclude Address Space (Windows clients only) with one or more string patterns representing domain names whose corresponding ip addresses you want excluded from routing through BIG-IP APM Network Access tunnels.

Additional Information

BIG-IP APM Network Access excludes address space from routing through BIG-IP APM Network Access tunnels by inserting static routes into the system's route table. When BIG-IP APM Network Access tunnels are terminated the inserted route entries are removed.

The following DOS command is an example of and reveals the route changes made, or not made, when a BIG-IP APM Network Access tunnel is running on a Windows client:
route print

  • DNS Exclude Address Space:

    • Functions only on Windows clients.
    • Cannot function without DNS Relay Proxy Service installed and running.
    • Does not support IPv6 addresses.
    • Does not exclude client system DNS queries from routing through BIG-IP APM Network Access tunnels.

  • Address space excluded by IPV4 Exclude Address Space and DNS Exclude Address Space can overlap as Windows systems will only implement unique route entries.

  • The DNS Relay Proxy Service intercepts, inspects and proxies DNS queries performed by the Windows system.
    The way DNS Exclude Address Space works is as follows:

    • The Windows system performs a DNS query.
    • The DNS Relay Proxy Service compares the DNS name queried against the DNS Exclude Address Space domain name string patterns.
    • If a match is found the corresponding IPv4 addresses, returned as a result of the DNS query, will be entered into the Windows system's route table, excluded from routing through the BIG-IP APM Network Access tunnel.
