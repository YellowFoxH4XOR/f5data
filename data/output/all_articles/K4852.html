Known Issue

This is the result of a known issue. Several registers that BIG-IP uses to calculate interface errors are deprecated. These unused registers may incorrectly report errors, which BIG-IP includes in the error total for the interface. If there are no apparent symptoms associated with the internal interface errors, you can safely ignore the error counts.

F5 Product Development tracked this issue as CR48749 and it was fixed in BIG-IP LTM version 9.1.1. For information about upgrading, refer to the BIG-IP LTM release notes.
