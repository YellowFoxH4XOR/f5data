Issue

Error Message

err bcm56xxd[<PID>]: 012c0004:3: Lost connection with MCP: <code> ... Exiting

In this error message, note the following:

  • <PID> is the process ID for the bcm56xxd process.
  • <code> is an internal message code.

For example:

err bcm56xxd[6935]: 012c0004:3: Lost connection with MCP: 16908291 ... Exiting

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when the following condition is met:

  • The bcm56xxd process loses communication with the mcpd process.

Impact

The bcm56xxd process restarts and causes all switch interfaces on the BIG-IP system to reinitialize.

Recommended Actions

This message indicates an internal error when communicating with the mcpd process. For indications of why the mcpd process has stopped communicating or is restarting, you should review the /var/log/ltm and /var/tmp/mcpd.out files.
