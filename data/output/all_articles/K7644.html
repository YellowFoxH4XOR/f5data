Topic

FirePass has two preconfigured routing tables: main and default. FirePass also has two routing modes: light and advanced. When you click the Routing tab at the top of the Device Management : Configuration : Network Configuration page, FirePass displays routing information in light mode. Information that you configure in light mode will affect the main routing table. If you want to configure the default routing table or other custom-defined routing tables, click the Switch to advanced mode link at the top of the page.

When FirePass makes a routing decision, it consults the main routing table first. Therefore, if FirePass locates a route in the main routing table, it will not consult the default routing table. You can create routes in both the main and default routing tables, but it is important to remember that the main routing table takes precedence over the default routing table.
