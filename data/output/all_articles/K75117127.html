Description
When you try to add or edit an IPv6 address with a route domain ID on the Firewall Rule List page, GUI gives an error "Invalid IP Address", and you cannot explicitly associate a route domain to the IPv6 address. You can still use TMSH to add or edit such IPv6 addresses.

Environment

  • AFM is provisioned
  • Trying to add or edit an IPv6 address with a route domain ID (such as 2001:DB8::1%10) in the following GUI page

    Security ›› Network Firewall : Rule Lists ›› <rule-list name> : <rule name>

Cause
The issue is due to ID 1084901.
The specific GUI page does not accept an IPv6 address with a route domain ID.

Recommended Actions

  1. Upgrade to a BIG-IP software version with the fix if there is any available.
  2. Use TMSH to edit the IPv6 address.
