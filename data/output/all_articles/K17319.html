Known Issue

Changing the system management IP address may cause the BIG-IP ASM bd process to produce a core file.

This issue occurs when all of the following conditions are met:

  • One or more virtual servers are configured to use remote logging.
  • The BIG-IP system is experiencing a high traffic volume.
  • The BIG-IP management IP address is modified.

Impact

The BIG-IP ASM system fails to process traffic while the bd process restarts. A failover may occur if the BIG-IP ASM system is part of a high-availability (HA) group.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H541561 on the Diagnostics > Identified > High screen.
  • In the /var/log/asm file, you observe messages similar to the following example:

    crit ControlPlane.CorrelationEngine[56789]: ControlPlane.CorrelationEngine|CRIT|<DATE>|12345| [read_message() at CorrelationEngine.cpp:1741] flwctl_read() - Failed to receive event from flow control socket. Program terminated.

  • In the /var/log/bd.log file, you observe messages similar to the following example:

    BD_MISC|ERR |<DATE>|12345|LoggingAccount.cpp:3154|remote log write FAILED res = -3 <Failed to send remote message (remote server not responding)> errno <Resource temporarily unavailable> handle=(nil) len: 1080 removing remote logger vs_name_crc 842618851

    BD_MISC|CRIT |<DATE>|12345|signals.c:0076|Received SIGSEGV - Core Dumping

  • In the /var/core directory, you observe a core file that appears similar to the following example:

    bd_bld473_0_core_7328.gz
