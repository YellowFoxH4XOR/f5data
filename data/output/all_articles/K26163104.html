Description

How to find via logs or API calls last date and time of a policy deployment for a BIG-IP AFM device in BIG-IQ.

Environment

  • BIG-IQ CM
  • BIG-IP AFM
  • AFM policy deployment

Cause

None

Recommended Actions

The endpoint /cm/firewall/tasks/deploy-configuration/ returns a list of all deployments of AFM FW rules. If you just want to get the date then you can look for the "endDateTime" field only.

Example:

# restcurl /cm/firewall/tasks/deploy-configuration/f8d67613-f6f2-4e78-838a-8f658743f935 | jq .endDateTime
"2022-02-03T02:47:28.691-0800"
