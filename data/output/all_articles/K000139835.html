Description

When attempting to modify the security NAT source-translation type between Static and Dynamic in the CLI,  the following error is returned: 

01070734:3: Configuration error: FW NAT: Modifying type between Static and Dynamic is not currently supported on a source translation object

This error is also logged in the /var/log/ltm file for further reference.


Environment


  • CLI
  • Security NAT Source-Translation

 

Cause


The modification of the security NAT source-translation type (For example, switching from Static to Dynamic or vice versa) is not supported by design. This is a limitation of the system to prevent configuration inconsistencies or unexpected behaviour.

Example command modifying to Static PAT:

(tmos)# modify security nat source-translation test type static-pat  

 


Recommended Actions


  1. Delete the existing security NAT source-translation configuration.

Example Commands:

(tmos)# delete security nat source-translation test  
(tmos)# create security nat source-translation test type static-pat addresses add { 203.0.x.x/32 } ports add { 80 }  


  2. Create a new configuration with the desired type.

Example Commands to create a Dynamic PAT source translation:

(tmos)# create security nat source-translation test type dynamic-pat addresses add { 203.0.x.x/32 } ports add { 1-65535 }  

 

Additional Information


This limitation ensures that the NAT configuration remains consistent and avoids conflicts that could arise from changing the type dynamically. Always plan and configure NAT policies carefully to minimize the need for such modifications.
