Known Issue

The Traffic Management Microkernel (TMM) may restart after a failover event when BIG-IP systems mirror Layer 7 (L7) packets.

This issue occurs when all of the following conditions are met:

  • You have multiple BIG-IP systems in a high availability (HA) configuration.
  • Your BIG-IP configuration includes one or more standard virtual servers with connection mirroring enabled. By default, connection mirroring is disabled.
  • The active BIG-IP system begins, but does not complete a TCP handshake for one or more new L7 connections.
  • The active BIG-IP system mirrors the initial TCP handshake packets to the next active BIG-IP system.
  • A failover event occurs before the active BIG-IP system completes the TCP handshake for the new L7 connections.

Impact

Traffic processing is interrupted while TMM restarts and a second failover event occurs.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP system fails to process traffic for a brief period.
  • The BIG-IP system fails over to another host in the device group.
  • TMM produces a core file in the /var/core directory.
