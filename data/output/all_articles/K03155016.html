Issue

Error Message

err lacpd[<PID>]: 01160005:3: HalMsgHandler.cpp:125 - HAL send PDU request failed

In this error message, note the following:

  • <PID> is the process ID for the lacpd process.

For example:

err lacpd[8574]: 01160005:3: HalMsgHandler.cpp:125 - HAL send PDU request failed

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when all of the following conditions are met:

  • You configure a trunk on the BIG-IP system with Link Aggregation Control Protocol (LACP) enabled.
  • The lacpd process encounters an unexpected error condition when transmitting protocol data units (PDUs) to the Broadcom switch process, bcm56xxd, or requesting PDUs from the bcm56xxd process using hypertext application language (HAL) messaging.

Impact

Link aggregation functionality for the trunk is degraded or fails altogether.

Recommended Actions

To determine the cause of the issue, gather further log and information following as described in: K04444605: Error Message: 01290003:3: HalmsgTerminalImpl_::sendMessage() Unable to send to any BCM56XXD address and contact F5 Support.

The presence of this message indicates the BIG-IP system experienced internal errors when processing LACP PDUs with the Broadcom switch.  When encountering this message, consider the following:

  • You should review log entries at the time of the incident for any related bcm56xxd errors that may provide more information about the cause.  You can also check the status of the lacpd and bcm56xxd processes to ensure they are running and have not restarted recently.  In some instances, you may be able to work around the issue by restarting those services.  To do so, perform the following procedure:

    Impact of procedure: Performing the following procedure restarts the lacpd and bcm56xxd processes which will impact traffic.  You should perform this procedure during a maintenance window.

    1. Log in to the BIG-IP Advanced shell (bash).
    2. To check the status of the lacpd or bcm56xxd service, use the following syntax:

      tmsh show /sys service <service_name>

      For example, to show the status of the lacpd service, enter the following command:

      tmsh show /sys service lacpd

      If the service is running, output appears similar to the following example:

      lacpd        run (pid 7023) 11 days

    3. To restart the service, use the following syntax:

      tmsh restart /sys service <service_name>

      For example, to restart the lacpd service, enter the following command:

      tmsh restart /sys service lacpd

  • If you still see the errors and traffic is still affected after restarting the lacpd and bcm56xxd processes or restarting the BIG-IP system, you should run the End-User Diagnostics (EUD) utility and provide the diagnostic report to F5 Support.
