Description

No event logs are displayed in GUI: Security > Event Logs > Application > Requests.
Repeating log messages similar to the following indicated that the restjavad service is constantly restarting /var/log/daemon.log:
Re-starting restjavad

Environment

  • BIG-IP ASM
  • Configuration utility
  • Event Logs

Cause

There are two bug IDs that describe this issue:

  • Bug ID 776393
  • Bug ID 894593

Recommended Actions

Increase the memory allocated for the restjavad service (e.g., 2 GB), by following the Workaround outlined each of the bugs linked above.
Important: This procedure will interrupt traffic processing and will cause failover.
Note: Modifying provision.extramb will move memory from TMM process. Make sure that TMM have enough by issuing: tmsh show sys memory and verifying TMMs free memory on the top of the output.
