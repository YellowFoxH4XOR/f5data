Known Issue

This article applies to BIG-IP WebAccelerator version 11.x. For information about other versions, refer to the following article:

  • K10832: Windows Media extensions and mimeTypes are not included in the Audio/Video Media object type list (9.x - 10.x)

This is the result of a known issue. BIG-IP WebAccelerator does not associate the Audio/Video Media object type with all of the file extensions and MIME types used by Windows Media. This behavior may cause rendering issues when the browser attempts to hand off these objects to an external application.

Windows Media uses the following extensions and MIME types:

ExtensionMIME type
.wmaaudio/x-ms-wma
.wmvaudio/x-ms-wmv
.wmaudio/x-ms-wm
.wmxaudio/x-ms-wmx
.waxaudio/x-ms-wax
.wvxaudio/x-ms-wvx
.asfaudio/x-ms-asf
.asxaudio/x-ms-asf

F5 Product Development tracked this issue as ID 223843 and ID 223451 (formerly CR132240 and CR129834) and it was fixed in BIG-IP version 11.2.0. For information about upgrading, refer to the BIG-IP WebAccelerator release notes..

Workaround

You can add the appropriate extensions and MIME types to the Audio/Video Media object type. To do so, perform the following procedure:

  1. Log in to the BIG-IP WebAccelerator Configuration utility. 
  2. Navigate to Configuration > Policies > Object Types.
  3. Select the Audio/Video Media pre-defined object type.
  4. Add the wma, wmv, wm, wmx, wax, and wvx to the Extensions list.
  5. Add audio/x-ms-wma, video/x-ms-wmv, audio/x-ms-wax, and video/x-ms-wvx to the MIME-types list.
  6. Click Save.
