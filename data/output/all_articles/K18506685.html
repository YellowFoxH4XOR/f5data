Description

Does ASM receive Attack Signature Live Updates after our hardware platform has reached EoSS?

Environment

  • Live Updates
  • Hardware support

Cause

None

Recommended Actions

None

Additional Information

A hardware platform can continue to receive Attack Signature Live Updates as long as it's running a BIG-IP software version that is not EoSD.

Live Updates are platform agnostic for the most part - they are developed for the software version rather than the underlying hardware. When the software version reaches EoSD, it no longer receives Live Updates.

For more information about software support, such as Attack Signatures, refer to:

  • K5903: BIG-IP software support policy

For more information about platform support, and what platform EoSS entails, refer to:

  • K4309: F5 platform lifecycle support policy
