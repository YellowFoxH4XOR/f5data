Known Issue

This is the result of a known issue. If the BIG-IP LTM system is configured with a pool named gateway, certain administrative operations such as the configsync and bigpipe load commands fail. The Configuration utility allows users to create a pool named gateway and configure it to specify a route for system. However, if the BIG-IP system is configured as a redundant pair and a configsync operation is initiated, the configsync to the peer system fails. Additionally, running the bigpipe load command on the command line also fails.

F5 Product Development tracked this issue as CR67311 and CR67312 and it was fixed in BIG-IP LTM 9.1.3. For information about upgrading, refer to the BIG-IP LTM Release Notes.

This issue still exists in the 9.3 software branch.
