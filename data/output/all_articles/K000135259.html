Description

  • While troubleshooting connectivity issues for APM, the leasepool statistics return requests and failures for pick, reserve, and release categories, but what do these mean?

Environment

  • Lease pool assigned to network access profile
  • Network Access profile assigned to APM Access Policy

Cause

tmsh show apm resource leasepool <leasepool name>

Recommended Actions

The pick, reserve, and release categories align with DHCP terminology and can be interpreted as DHCP Pick Requests/Failures, DHCP Reserve Request/Failures, and DHCP Release Requests/Failures. Please check with your local DHCP administrator for details about the Total Reserves. 
-----------------------------------------
Apm::Leasepool Statistics: leasepool-full
-----------------------------------------
Current Members 5: total IPs in the lease pool
Current Assigned 1: total IPs in use
Current Free 4: Available IPs in the lease pool
Total Pick Requests 1: IPs requested, clears to 0 once IP is assigned
Total Pick Failures 0: IPs requested, but unable to provide to remote edge client/f5 access
Total Reserve Requests 0: Number of DHCP reserve requests
Total Reserve Failures 0: DHCP reserve failures
Total Release Requests 0: Number of times IP released since last Big-IP restart
Total Release Failures 0: Client didn't reconnect within the access max session timeout
 

Additional Information

DHCP Release Failures could occur via any method where a client doesn't gracefully shutdown and submit a request to release.

A few examples might include:

  1. Forced shutdown of client device. (Power button or CTL-ALT-DEL or similar)
  2. Removal of client device from network. (Network Button, Physical Cable Detach, WiFi Router crash or similar)
  3. Software Crash (F5 Access crash, Edge Client Crash, BSOD or similar)
Most environments configure some type of reconnect duration where network credentials (and by association DHCP lease) are cached. If any of the above conditions occur and the client doesn't reconnect during the max session time, it will get logged as a release failure.
