Known Issue

The Configuration utility may fail to display Secure Sockets Layer (SSL) certificates.

This issue occurs when all of the following conditions are met:

  • You import an SSL certificate with special characters to the system.
  • You then attempt to view the list of SSL certificates by navigating to the Configuration utility SSL Certificate List page.

Additionally, if you attempt to use iControl methods such as Management::KeyCertificate::get_certificate_list and get_certificate_list_v2 to retrieve the list of SSL certificates, the system returns an error.

Impact

You cannot use the Configuration utility or iControl methods to view the list of SSL certificates on the system.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H597422 on the Diagnostics > Identified > Low screen.
  • When you attempt to view the list of SSL certificates on the SSL Certificate List page, the Configuration utility reports an error message similar to the following example:

    An error has occurred while trying to process your request

  • In the /var/log/tomcat/catalina.out file, you observe an error message similar to the following example:

    com.sun.org.apache.xerces.internal.impl.io.MalformedByteSequenceException: Invalid byte 2 of 3-byte UTF-8 sequence.

Workaround

To work around this issue, use the Traffic Management Shell (tmsh) to view the list of SSL certificates. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the tmsh utility by typing the following command:

    tmsh

  2. View the list of SSL certificates by typing the following command:

    list sys file ssl-cert
