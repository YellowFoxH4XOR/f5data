Description

After upgrading to MacOS 14.0 Sonoma, Configurations with Proxy configurations in the Network Access VPN Access may fail.

 

Environment

  • APM VPN Access
  • Network Access with local proxy, proxy or proxy.pac configurations
  • MacOS 14.0 (Sonoma)

 

Cause

Changes in behaviour in CFNetwork API when accessing the proxy is causing issues, F5 now uses different APIs to download the PAC file. Both these issues have been escalated to Apple and customers should keep the tickets opened with Apple until a resolution is identified from Apple team.

 

Recommended Actions

These issues are being tracked by F5 as ID 1350645 (Intel devices) ID 1316609 (M-series devices)
On October 10, 2023 the APMClients version 7.2.4.5 was released on MyF5 Downloads.
It is recommended that you test this releases against your specific configuration before deploying.
