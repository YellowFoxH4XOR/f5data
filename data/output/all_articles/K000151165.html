SCTP vulnerability CVE-2025-41399What is SCTP?

Generated answer for you - Beta

SCTP, or Stream Control Transmission Protocol, is a transport layer protocol used for transmitting data over networks. It supports features such as multihoming, which allows a single SCTP association to span multiple IP addresses, enhancing reliability and fault tolerance. SCTP is designed to transport messages rather than a byte stream, making it suitable for applications that require message-oriented communication. It includes mechanisms for congestion control, flow control, and reliable message delivery, similar to TCP but with additional capabilities.

To check if you have an HTTP Profile with Enforce RFC Compliance enabled, navigate to the Security section of your BIG-IP system. Go to Security > Protocol Security > Security Profiles > HTTP. BIG-IP SIP ALG profile vulnerability CVE-2025-41433How to check if I have SIP message routing framework (MRF) application layer gateway (ALG) profile is configured on a Message Routing virtual serverGenerated answer for you - Beta

To check if you have a SIP message routing framework (MRF) application layer gateway (ALG) profile configured on a Message Routing virtual server, review the configuration settings of the virtual server. Specifically, look for the assigned SIP router profile, which indicates the use of ALG operation mode. Additionally, verify that the SIP session profile is also assigned to the virtual server, as both profiles are necessary for MRF functionality. Check the profiles' stats to ensure they are incrementing with message processing, which confirms that the MRF is actively routing SIP messages.

Additionally, ensure that classification is enabled in the virtual server's settings. If the iRule or policy is present and enabled, URL categorization is active for that virtual server.

TMM vulnerability CVE-2025-41431

What is SSL State mirroring?

K17391: Configuring SSL connection mirroring for Client SSL virtual servers

When you enable connection mirroring on a virtual server that references an SSL profile, the BIG-IP system mirrors SSL-specific data to the appropriate device group member. This preserves SSL connections when failover occurs.

Generated answer for you - Beta

SSL state mirroring is a feature that allows the BIG-IP system to mirror SSL session data, such as session IDs, to peer device group members. This enables SSL session resumption, allowing clients and servers to reuse previously negotiated SSL parameters, which can enhance performance by reducing the need for processor-intensive SSL key exchanges. When SSL state mirroring is enabled in an SSL profile, it ensures that SSL session data is preserved during failover events, maintaining continuity in secure communications.
