K5327: BIG-IP and 3-DNS may not detect the second CPU on platforms with two CPUs due to a defective license

Known Issue

This is the result of a known issue. Between August 17, 2005, and September 15, 2005, the F5 Networks Licensing server produced BIG-IP and 3-DNS product licenses that did not correctly specify the number of installed CPUs. If you licensed your BIG-IP or 3-DNS during this time, your unit will only use one CPU, even if two CPUs are installed.

F5 Networks identified the units that were impacted by this issue and informed the registered owners.

To identify an affected system, you can inspect the /config/bigip.license file. If affected, the license file will display a CPU count of 2, even though only one CPU is active.

The CPU line in an affected license file appears as follows:

CPU : 2

The CPU line in a correctly formatted license file appears as follows:

Number CPU : 2

Workaround:

To work around this issue, you can re-activate your license. For instructions about how to re-activate the license, refer to the BIG-IP or 3-DNS Release Notes for your specific version.

Note: The re-activation process uses Automated Authorization, which requires that the BIG-IP or 3-DNS have Internet access to communicate with the F5 Networks Licensing server.
