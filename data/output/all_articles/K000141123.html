Description

 

Config load fails when a Virtual Server is missing a base profile i.e. tcp-profile on either client or server side.

You may observe it after a reboot, upgrade, config reload or while running "tmsh load sys config verify" command

 

Symptoms

Error similar to this one will show after config load or verification fails:

01070734:3: Configuration error: Less than the required minimum number of profiles found on /Common/my_vs: Exactly 1 of (UDP Profile (clientside), TCP Profile (clientside))

 

Environment

 

  • BIG-IP
  • Virtual Server with TCP/UDP related profile

 

Cause

 

Virtual Server is missing one base protocol profile on either clientside or serverside configuration.

 

Recommended Actions

 

In affected Virtual Server, configure a base profile, TCP or UDP, at both ends, clientside and serverside.
