Known Issue

Note: Feature release 6.0.1 of FirePass software is the first release to support Microsoft Windows Vista clients.

This is the result of a known issue. Protected Workspace does not support Microsoft Windows Vista clients in feature release 6.0.1 of FirePass software.

Protected Workspace is one of the Endpoint Security Inspectors available in a pre-logon sequence. A pre-logon sequence with this Inspector will place users into the Protected Workspace, which provides protection for unintended leakage of sensitive data. However, users connecting to the FirePass controller with the Microsoft Windows Vista operating system will not be able to enter Protected Workspace. Instead, the branch of the pre-login sequence immediately preceding the Switch to PWS action will take effect, such as presenting the user with a Logon Denied Page option.

F5 Networks Product Development tracked this issue as CR69798 and it was fixed in FirePass version 6.0.2. For information about upgrading, refer to the FirePass Release Notes.

Additionally, Cumulative Hotfix HF-601-6 has been issued for FirePass version 6.0.1. You may download this hotfix or later versions of the Cumulative Hotfix from the F5 Networks Downloads site.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Important: In addition to Cumulative Hotfix HF-601-6 or a later version installed on your FirePass controller, your Microsoft Vista client must have Microsoft Update KB935855 and KB933566 installed in order to access Protected Workspace. For more information, refer to http://support.microsoft.com/kb/935855 and http://support.microsoft.com/kb/933566.

Note: Other combinations of Microsoft Updates for Windows Vista may provide the versions of files required to use Protected Workspace.

Workaround

You can work around this issue by providing a branch of your pre-logon sequence that detects Microsoft Windows Vista clients and provides a Microsoft Windows Vista-specific option. For example, you could configure a Logon Denied Page with a message appropriate for Microsoft Windows Vista users.

For instructions about detecting Microsoft Windows Vista clients in a pre-logon sequence, refer to K7177: Detecting Windows Vista clients in a pre-logon sequence.
