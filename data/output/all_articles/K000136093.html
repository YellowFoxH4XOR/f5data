Description

The APM session is stateful, it is different with the stateless web page.

  • A, In the same browser, open multiple tabs for the same APM server will cause unexpected result.
  • B, In the same tab, Go Back is not supported operation.
  • C, In the same tab, Refresh will submit the data again, may cause unexpected result.

Environment

  • BIG-IP APM
  • Virtual server
  • Access Profile (Per-Session Policy)
  • Browser

Cause

None

 Recommended Actions

In the same browser, do not open multiple tabs for the APM portal like https://<IP/FQDN of APM server>/my.policy . If the new tab was opened by APM (like portal access), then it is normal.
In the APM portal tab, do not Go Back to the previous page.
In the APM portal tab, do not refresh the page.

None.
