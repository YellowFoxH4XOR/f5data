K000135008: SNMP not responding for rSeries

Type
Support Solution
Published
2023-06-13
Updated
2023-06-13
Applies to
  • rSeries Platforms
  • rSeries 5600
  • rSeries 5000
Source
https://my.f5.com/manage/s/article/K000135008

 

Description

You are using rSeries appliance running on F5OS 1.5.0 software. SNMP was configured from GUI and does not work. Appliance does not respond to SNMP queries over management port with both v3 and v2c. Tcpdump shows Get Requests going out but no responses.

 

Environment

  • rSeries
  • SNMP v3, v2c
  • Management Port
  • SNMP is working fine for tenants running on this appliance

Cause

SNMP server address is not included in allowed IPs list.

Recommended Actions

Manually add SNMP manager address to list of allowed IPs on the F5OS configuration

system allowed-ips allowed-ip Example
config ipv4 address 192.168.1.1
config ipv4 prefix-length 32
config ipv4 port 161
