Known Issue

The tmsh show ltm profile client-ssl command may display incorrect information.

This issue occurs when all of the following conditions are met:

  • Negotiated SSL ciphers are partially accelerated; the software performs the handshake while the hardware performs the encryption.
  • You run the tmsh show ltm profile client-ssl command to display SSL profile statistics.

Impact

The system displays incorrect SSL profile statistics. However, performance is not affected.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When users run the tmsh show ltm profile client-ssl command, the hardware acceleration statistics output is incorrect.
