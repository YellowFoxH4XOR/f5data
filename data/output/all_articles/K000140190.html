K000140190: Modifying the VLAN Tag in the Tenant

Description

Changing the VLAN TAG in the Tenant.

Environment

F5OS-A

Cause

If we want to modify/change the VLAN TAG, we must first remove it from F5OS-A and Tenant. VLAN TAG cannot be changed directly to Tenant because F5OS will not know which VLAN to forward traffic to. VLAN configuration is inherited from F5OS-A to Tenant.

Recommended Action
 

1. Delete VLAN from Tenant webGUI (VLAN => VLAN List).
2. Detach VLAN from Tenant Deployment and click Save & Close.
3. Go to Network Settings => VLANs and delete VLAN you want to modify.
4. Create a new VLAN with modified TAG/ID, then click Save & Close.
5. Add new/modified VLAN to Tenant Management => Tenant Deployment and click Save & Close.
6. "Modified" VLAN should by visible in Network => VLANs on the Tenant webGUI (please refresh or login again).
