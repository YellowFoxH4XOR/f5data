Known Issue

The BIG-IP system incorrectly reports a 192-bit key length for cipher suites using 3DES (DES-CBC3).

The key size should be reported by the BIG-IP system as 168 bits.

Important: 3DES has been assessed to have a security strength of 112 bits. For more information, refer to NIST Special Publication 800-131A. This link takes you to a resource outside of AskF5, and the third party could remove the document without our knowledge.

This issue occurs when the following condition is met:

  • You use the tmm --clientciphers 3DES command to view the 3DES (DES-CBC3) cipher suites on the BIG-IP system command line.

    Output appears similar the following example:

    ID SUITE BITS PROT METHOD CIPHER MAC KEYX
    0: 49170 ECDHE-RSA-DES-CBC3-SHA 192 TLS1 Native DES SHA ECDHE_RSA
    1: 49170 ECDHE-RSA-DES-CBC3-SHA 192 TLS1.1 Native DES SHA ECDHE_RSA
    2: 49170 ECDHE-RSA-DES-CBC3-SHA 192 TLS1.2 Native DES SHA ECDHE_RSA

    Note: This example output has been truncated for brevity.

Impact

The reported security strength for the cipher suite is incorrect.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When you view cipher suites from the BIG-IP system command line, the cipher suite key size value is incorrectly reported.
  • When you view a large list of cipher suites from the BIG-IP system command line, using the @STRENGTH option, the cipher suite appears higher in the list than it should.
