Topic

You can change the default text editor with the shell variable, EDITOR. To set this variable from the command line, type the following command:

export EDITOR=<editor>

For example:

export EDITOR=pico

If you would like this change to take effect automatically each time you log in, edit the /root/.bash_profile file and place the export EDITOR=pico command at the end of the file.
