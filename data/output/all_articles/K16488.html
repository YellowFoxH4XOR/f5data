Topic

BIG-IP Virtual Edition (VE) instances that use the hourly billing licensing model, within the Amazon Web Services (AWS) environment, do not allow users to change AWS instance types.

Description

Deploying a BIG-IP VE instance by using the hourly billing licensing model within the AWS environment, and then subsequently shutting down this instance and changing its AWS instance type, causes the mcpd process to restart repeatedly after the BIG-IP VE instance restarts.

For example, a user may deploy an F5 BIG-IP Virtual Edition for AWS 25Mbps Hourly (Good) instance within the AWS environment, with an instance type of m3.2xlarge, and then start up the instance and subsequently shut it down to change its instance type to cc2.8xlarge. When the user subsequently starts this BIG-IP VE instance, the mcpd process will repeatedly restart.

This is an expected limitation for BIG-IP VE instances that use the hourly billing licensing model within the AWS environment.

Recommendations

If you require a smaller or larger instance for your deployed BIG-IP VE instance, which uses the hourly billing licensing model within the AWS environment, F5 recommends that you complete the following tasks:

  1. Create a user configuration set (UCS) file on your existing instance and copy it to a secure location.
  2. Deploy a new instance with the desired instance type.
  3. Upload the UCS file to the new instance (to restore the configuration on the new instance).

For more information about completing these recommended tasks, refer to K35355528: Migrating an existing AWS BIG-IP instance to a new instance.
