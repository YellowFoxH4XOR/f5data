Known Issue

The TMOS Shell (tmsh) help page displays an incorrect default value for the request-chunking setting.

This issue occurs when the following condition is met:

  • You run the tmsh help /ltm profile http command.

In the default HTTP profile, 'preserve' is the default value for the request-chunking setting. However, the tmsh help page incorrectly displays the default value as 'selective.'

Impact

None. The incorrect information does not affect the operation of the BIG-IP system.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you refer to the request-chunking section of the tmsh help page, by using the tmsh help /ltm profile http command, you notice incorrect default value information similar to the following example:

    request-chunking
                Specifies how to handle chunked and unchunked requests. The default value is selective.
