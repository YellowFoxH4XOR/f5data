Issue

Description

The BIG-IP DNS (formerly GTM) module has a GSLB HTTPS monitor which is different from the BIG-IP LTM HTTPS monitor. The BIG-IP DNS GSLB HTTPS monitor utilizes OpenSSL (which runs in the Control Plane) rather than the custom SSL/TLS implementation used by BIG-IP LTM via the TMM and Traffic Plane.

Environment

  • BIG-IP DNS or BIG-IP GTM
  • GSLB HTTPS Monitor

Cause

BIG-IP DNS does not utilize TMM-based SSL/TLS and does not support In-TMM monitoring. Consequently it must use SSL/TLS functionality from the Control Plane; this is the OpenSSL package.

Recommended Actions

Each GSLB HTTPS monitor has a Cipherlist field which contains the list of ciphersuites that the BIG-IP will provide in it's TLS ClientHello to the resource it is monitoring, typically a GSLB pool member, server or virtual server. The default cipherlist for the GSLB HTTPS Monitor is "DEFAULT:+SHA:+3DES:+kEDH". This typically results in 73 ciphersuites being offered in the ClientHello.

The list of ciphersuites and their order can be viewed via the command line with:

openssl ciphers DEFAULT:+SHA:+3DES:+kEDH

A list of all ciphers supported by the OpenSSL version on the BIG-IP DNS can be viewed via the command line with:

openssl ciphers ALL
