Cause


This happens when that Signature set is missing.


Recommended Actions


This is related to Bug ID 1113161: After upgrade, Learning and Blocking Settings page is not loading because some policies are still pointing to deleted factory Negsig sets and the Workaround there may resolve the issue.


If it does not a rebuild of the mysql database has shown to resolve the issue.

K05755225: Checking and repairing MySQL databases on the BIG-IP system


Note: After the mysql check command has been run at steps 2 and 3 it just stops as if its waiting on something. If after a couple of minutes it is 'just sitting' it is likely finished and you can hit 'Ctrl + c' to stop it and get a new command prompt.
