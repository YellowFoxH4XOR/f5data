Description

  • Enable QUIC on Nginx Plus load-balancing server

Environment

  • NGINX
  • QUIC

Cause

None

Recommended Actions

Please refer to the configuration below for example:

http {
  upstream http3.com {
    server 10.10.10.10:80;
  }
  server {
    listen 443 quic reuseport; # QUIC
    listen 443 ssl; # TCP

    ssl_certificate certs/example.com.crt;
    ssl_certificate_key certs/example.com.key;
    ssl_protocols TLSv1.3;

      location / {
        add_header Alt-Svc 'h3=":$server_port"; ma=86400';
        add_header X-protocol $server_protocol always;
        proxy_pass http://http3.com;
      }
  }
}
