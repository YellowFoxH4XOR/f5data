K01417400: Plus delimited OAuth scopes are not processed

Type
Support Solution
Published
2021-08-04
Updated
2026-07-14
Status
Legacy Content
Applies to
  • Virtual Editions
  • BIG-IP Platforms
  • VIPRION Platforms
  • BIG-IP
  • BIG-IP APM: 15.1.0
Source
https://my.f5.com/manage/s/article/K01417400

Description
Delivering Scope values via URL multiple scope values can be connected using the '+' sign as a delimiter to form a proper URL.

Environment

  • BIG-IP APM
  • OAuth configuration using multiple scopes

Cause

Delimiters other than spaces are not valid per RFC6749

Recommended Actions

  • Ensure that the URLs are properly constructed using the RFC required space and URL encoded to create a valid URL using '%20'

None
