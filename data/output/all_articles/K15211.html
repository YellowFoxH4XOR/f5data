Known Issue

The Traffic Management Microkernel (TMM) may produce a core file.

This issue occurs when the following conditions are met:

  • The BIG-IP system is running version 11.2.1 HF10 or 11.3.0.
  • A virtual server uses a OneConnect profile.
  • A client request reuses a server-side flow.

Impact

Traffic may be interrupted when the BIG-IP system fails over and the TMM process restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H459469 on the Diagnostics > Identified > High screen.
  • The BIG-IP system sends a SIGSEGV signal to TMM, resulting in a stack trace and core file.
  • TMM may temporarily fail to process traffic.

Resolution

Status

F5 Product Development has assigned ID 411408 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies To box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Workaround

To work around this issue, you can remove the OneConnect profile from the virtual server.
