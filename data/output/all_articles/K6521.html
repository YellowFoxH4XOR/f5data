Known Issue

This is the result of a known issue. Distributed Application Timeout is an absolute timeout from the initial request. The Distributed Application persistence records timeout timer will not be refreshed when that persistence record is used and a persistence-based resolution is provided.

This is different behavior than the wide IP persistence timeout, which is reset when requests are received and a persistence based resolution is provided.

F5 Product Development tracked this issue as CR68155 and it was fixed in BIG-IP GTM 9.2.4 and 9.3.0. For information about upgrading, refer to the BIG-IP GTM Release Notes.
