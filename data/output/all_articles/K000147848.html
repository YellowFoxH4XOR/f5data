K000147848: Can I use mTLS and TLS in a domain that listens on two different ports?

Type
Support Solution
Published
2024-11-08
Updated
2025-02-23
Applies to
  • F5 Distributed Cloud Services
  • F5 Distributed Cloud DNS Load Balancer
  • F5 Distributed Cloud
Source
https://my.f5.com/manage/s/article/K000147848

Description

You have your WebApp example.com listening to 2 different ports on the origin server because you are using client apps in your environment.
You want to configure the following:

  • example.com:30000 with TLS
  • example.com:30001 with mTLS

Is that possible?

Environment

  • F5® Distributed Cloud HTTP Load Balancer
  • Origin Pools

Answer/Recommended Actions

Yes. In order to achieve that, you have to create 2 HTTP Load Balancers instead of one and do the same with the origin pools, one for the port 30000 the other one for the port 30001
