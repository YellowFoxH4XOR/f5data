Description

Important: The behavior described in this article applies to F5OS-C 1.5.0 and earlier. For F5OS-C 1.6.0 and later, refer to the SNMP configuration overview section under the System Settings chapter of the VELOS Systems: Administration and Configuration guide.

There is no place to config SNMP server IP on the GUI. 
There is no information about the fields in the config:
  • snmpCommunityEntry
  • snmpCommunityName
  • snmpCommunitySecurityName
  • vacmSecurityToGroupEntry
  • vacmGroupName

Environment

  • Velos 
  • SNMP Configuration on GUI

Cause

The configurations related to "SNMP-VIEW-BASED-ACM-MIB" may have been removed.

Recommended Actions

  1. Check /var/log/audit.log that may contain: 'audit user: admin/<id_of_user> CLI 'no SNMP-VIEW-BASED-ACM-MIB'
  2. Please take a look at https://clouddocs.f5.com/training/community/rseries-training/html/rseries_monitoring_snmp.html for configuring SNMP on the rSeries appliance. 

    Note : SNMPv3 isn't supported in versions prior to F5OS-C 1.6.0. Starting from F5OS-C 1.6.0, SNMPv3 is supported.
    Note : By default, SNMP traffic is disallowed from coming into the system. You must configure a "system allowed-ips allowed-ip" entry to allow SNMP traffic from a management station.
    Note : You must then configure a community name and configure its access

Additional Information

F5OS is using SNMP-COMMUNITY-MIB and SNMP-VIEW-BASED-ACM-MIB to configure snmp_agent.
http://www.net-snmp.org/docs/mibs/SNMP-COMMUNITY-MIB.txt
http://www.net-snmp.org/docs/mibs/SNMP-VIEW-BASED-ACM-MIB.txt

The above configuration are defined in the MIB's; copied the description as in MIBs;
  • snmpCommunityEntry - Information about a particular community string.
  • snmpCommunityName - The community string for which a row in this table represents a configuration.
  • snmpCommunitySecurityName - A human readable string representing the corresponding value of snmpCommunityName in a Security Model independent format.
  • vacmSecurityToGroupEntry - An entry in this table maps the combination of a securityModel and securityName into a groupName.
  • vacmGroupName - The name of the group to which this entry (e.g., the combination of securityModel and securityName) belongs. This groupName is used as index into the vacmAccessTable to select an access control policy.
However, a value in this table does not imply that an instance with the value exists in table vacmAccesTable.
