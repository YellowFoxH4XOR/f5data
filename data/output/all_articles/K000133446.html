K000133446: Changing of F5OS's tenant management IP from BigIP system doesn't work

Source

Description

For example, you deployed a tenant with tenant_01 named and the management IP is set from F5OS WebUI, TENANT MANAGEMENT >> Tenant Deployments >> tenant_01 >> IP Address: 192.0.2.1


Observation 1:

when attempting to change its management IP from BigIP WebUI, system >> Platform >> IPV4 Config Details, for example changing it to 192.0.2.2, as the result it will be reverted back to 192.0.2.1 after clicking on "Update"


Observation 2:

when attempting to change its management IP from BigIP CLI(TMOS shell) using the following commands: 

# tmsh create /sys management-ip 192.0.2.2/255.255.255.0
# tmsh save sys config

As the result, it does change on the BigIP system level, but it will be reverted back to the initial management IP 192.0.2.1 after giving a reboot.


Observation 3:

You have a BigIP UCS with the management IP 192.0.2.2 is set. If restoring that BigIP UCS on a tenant with an existing management IP 192.0.2.1 is set on the F5OS level, as the result it does change on the BigIP system level but If doing a mcpd reload and rebooting against the BigIP' from its CLI, it will be changed back to the IP that is the same as the tenant's management IP on F5OS level.
 

Environment

F5OS tenant

BigIP system
 

Cause

The tenant is managed as a pod from Kubernetes master node and to get a persistent change at the pod it is required to come from the master
 

Recommended Actions

To work around the issue, you can change the tenant's management IP from F5OS level.

Putting the tenant in a configured state, and then navigating to F5OS WebUI >> TENANT MANAGEMENT >> Tenant Deployments >> tenant_01 >> IP Address, to change the management IP.

Putting back the tenant in deploy state once changed the tenant's management IP to another.
