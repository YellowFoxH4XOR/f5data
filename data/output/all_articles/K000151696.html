Description

SSL Security Scan Doesn't Detect Configured ECDSA Ciphers

Environment

  • LTM
  • SSL Certificate
  • Ciphers

Cause

SSL Certificate Type Determines Available Cipher Suites

RSA Certificate: Only RSA-based cipher suites are used.
ECDSA Certificate: Only ECDSA-based cipher suites are used.

To enable ECDSA cipher suites, an ECDSA certificate must be installed and used in the SSL configuration.

Recommended Actions

Verify the SSL certificate (e.g., RSA or ECDSA) applied to the Virtual Server (VS) being scanned:

openssl x509 -in /config/filestore/files_d/Common_d/certificate_d/:Common:default-ssl_62542_1 -text -noout | grep -i 'Public Key algorithm'

      Public Key Algorithm: rsaEncryption

In the example above, an RSA certificate is in use, so only RSA-based cipher suites will appear in the SSL/TLS handshake and scan results.

ECDSA cipher suites will not appear in the scan results.
