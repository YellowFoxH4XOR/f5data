K61036136: Specifying BIG-IQ session idle timeout for WebUI access

Type

Published
2021-04-10
Updated
2025-02-06
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K61036136

Description

Configuring the Session Idle Timeout for Big-IQ Configuration Utility (WebUI) and information about the Minimum to Maximum accepted time values (in minutes)

Environment

  • BIG-IQ 7.X, 8.X
  • You would like to specify the idle timeout for WebUI access 

Cause

N/A

Recommended Actions

  1. Log in to BIG-IQ System with your user name and password.
  2. In the right corner of the screen, hover at the 'user name' and click 'User Preferences' when it appears.
  3. In the Idle Timeout (minutes) field, type the number of idle minutes you want the BIG-IQ system to wait before logging you out.
    Note: The value must be a minimum of 5 and a maximum of 600. 
  4. Click the 'Save and Close' button.

Additional Information

The "User Preferences" shown in GUI is specific to that user you used to login. To tweak the Idle Timeout setting for multiple user account, each user will need to login to make these changes.
