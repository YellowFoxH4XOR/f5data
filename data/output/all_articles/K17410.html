Known Issue

The Secure Sockets Layer (SSL) handshake with a Client SSL virtual server may fail silently.

This issue occurs when the following condition is met:

  • The affected virtual server's Client SSL profile uses an SSL certificate and key pair that matches one of the following combinations:
     
    • An RSA (Rivest Shamir Adleman) key and DSA-signed (Digital Signature Algorithm) certificate.
    • An RSA key and ECDSA-signed (Elliptic Curve Digital Signature Algorithm) certificate.

Impact

SSL handshakes with the affected client SSL virtual server will silently fail.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Connections to the affected Client SSL virtual server fail.

Workaround

To work around this issue, you should not use SSL certificate and key pairs that match an affected combination. Instead, you can use one of the following certificate and key combinations:

  • An RSA key and an RSA-signed certificate
  • An EC key and an ECDSA-signed certificate
  • An DSA key and a DSA-signed certificate

Impact of workaround: The impact of the suggested workaround depends on the specific environment. F5 recommends testing any such changes during a maintenance window with consideration to the possible impact on your specific environment.
