Description

When updating or creating  Cipher Rules, an error is displayed similar to the following:

Cipher string is invalid.
 

Environment

  • BIG-IP
  • Cipher Rules
  • Cipher Suites
     

Cause
The chosen Cipher Suite is not supported by BIG-IP.
 

Recommended Actions

Check that the cipher suite you added is supported by the BIG-IP version of your system.

  • K86554600: SSL ciphers supported on BIG-IP platforms (15.x)
  • K97098157: SSL ciphers supported on BIG-IP platforms (14.x)
  • K13163: SSL ciphers supported on BIG-IP platforms (11.x - 13.x)

Alternatively, you can view the available cipher suites by running the following command from the command line of your BIG-IP system.

tmm --clientciphers 'DEFAULT' 


Check if OpenSSL supports the cipher suite, and check RFC site if it is supported.

Example to check if AES256-GCM-SHA256 is supported.

 tmm --clientciphers 'DEFAULT' | grep -i AES-GCM | grep -i sha256
