Known Issue

This is the result of a known issue. A CIFS service VIP may remain in Starting state on the ARX 500 platform. This issue may occur when a VIP is created on a redundant system following a failover, similar to the following scenario:

  • Two ARX 500 systems are configured as a redundant pair
  • A managed volume is configured on the active ARX system (Switch #1)
  • Failover to the peer ARX system (Switch #2) occurs
  • A CIFS service VIP on Switch #2 is configured

The CIFS service VIP may remain in Starting state. The output of the show virtual service command will display the state of the VIP.

For example:

Switch   ARX1
------------------------
  Global Server           Virtual IP Address      Service     State
  ------------------------------------------------------------------------
  TEST68                  10.104.252.68           CIFS        Ready
  TEST66                  10.104.252.66           CIFS        Ready
  TEST67                  10.104.252.67           CIFS        Starting

F5 Product Development tracked this issue as ID 36818 and it was fixed in ARX version 5.0.6. For information about upgrading, refer to the ARX release notes.

A hotfix is available for ARX version 4.1.1. Customers affected by this issue should contact F5 Technical Support, referencing this article number and the associated ARX ID number to request the hotfix.

Workaround

Performing a failover will allow the VIP to reach the Ready state.
