Description

In Dashbard, SSL TPS License Limit shown is different from the actual limit. 

Environment

  • BIG-IP Dashboard
  • SSL TPS limit

Cause

It is a known cosmetic issue recorded in ID442489.

Recommended Actions

Actual SSL TPS limit can be derive from the following steps.

1. Find out the licensed SSL TPS limit from bigip.license file.
tmsh show sys license detail | grep -i perf_SSL_total_TPS

perf_SSL_total_TPS :          1450  

2. Identify the number of  TMM in system.
tmsh show /sys tmm-info global

---------------------------
Sys::TMM

---------------------------
Global
  TMM Count               4

3. Calculate total SSL TPS limit in the system.
SSL TPS limit:1450 x 4 = 5800

4. BIG- IP uses HTSplit so it need to be double.
1450 x 4 x 2 = 11600

Additional Information

None.
