Description

Syslog-ng can either use BSD (default) or ISO timestamp format in log files and file-like destinations:

BSD (default) format: Mnn DD hh:mm:ss
For example: May 10 09:39:20

ISO format: YYYY-MM-DDThh:mm:ssTZ
For example: 2019-05-09T09:39:20+08:00

By default, the system logs make use of BSD timestamp. This article describes how to configure syslog-ng to make use of ISO timestamp format when sending the logs remotely to syslog servers.

Environment

  • Remote syslog server configuration

Recommended Actions

  1. Log in to tmsh by typing the following command:
    tmsh

  2. To define the desired syslog filter that references the remote server, type the following command:
    edit /sys syslog all-properties

    The syslog configuration opens in the vi text editor and appears similar to the following example:

    sys syslog {
        auth-priv-from notice
        auth-priv-to emerg
        cron-from warning
        cron-to emerg
        daemon-from notice
        daemon-to emerg
        description none
        include none
        iso-date disabled
        kern-from notice
        kern-to emerg
        mail-from notice
        mail-to emerg
        messages-from notice
        messages-to warning
        remote-servers none
        user-log-from notice
        user-log-to emerg
    }

  3. Within the include statement, insert the following lines.
    options { proto-template(t_isostamp); };
    template t_isostamp { template(\"$ISODATE $HOST $MSGHDR$MSG\\n\"); };

    destination d_remote_loghost {
            tcp(\"10.10.10.1\" port(514) template(t_isostamp));
        };

    For example, the above configuration can be included in this manner:
    include "
    options { proto-template(t_isostamp); };
    template t_isostamp { template(\"$ISODATE $HOST $MSGHDR$MSG\\n\"); };

    destination d_remote_loghost {
            tcp(\"10.10.10.1\" port(514) template(t_isostamp));
        };
    "
    Note: Additionally, you also modify the configuration line iso-date disabled to iso-date enabled if you desire to have local logging to be configured to make use of ISO timestamp

  4. Exit the text editor by hitting Esc to leave Insert mode and then type the following key sequence:
    :wq!

  5. At the following prompt, type y to save the changes to the file:
    Save changes? (y/n/e)
    The tmsh utility prompt returns.
    Note: If the syslog filter contained syntax errors, the tmsh utility returns the following prompt:
    There were errors. Continue editing (y) or discard changes (n) (y/n)

  6. Save the configuration by typing the following command:
    save /sys config
