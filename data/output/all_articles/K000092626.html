K000092626: Virtual server is out of order at member list

Type
Support Solution
Published
2022-12-15
Updated

Status
Legacy Content
Applies to

  • BIG-IP Link Controller: 13.X.X, 13.1.X, 13.1.5, 13.1.4, 13.1.3, 13.1.1, 13.1.0, 13.0.X, 13.0.1, 13.0.0
Source

Description

When you add the virtual server for Wide IP at member list, you may find the virtual server is out of order, these virtual servers are not in alphabetical and numerical order, as you can see from the following photo. Under normal circumstances, these virtual servers should be arranged in alphabetical and numerical order.

Environment

  • Member list
  • Out of order
  • Wide IP

Cause

This is a cosmetic problem and does not affect the normal use of the BIG-IP.

Recommended Actions

None

None
