Known Issue

This is the result of a known issue. When an XML profile is attached to a BIG-IP ASM policy, the BIG-IP ASM bd process may leak memory. When this issue occurs, the bd process will eventually produce a core file and restart due to high memory utilization. The memory leak is caused by a bug in a third-party library utilized by the BIG-IP ASM 9.4.x XML parsing engine. Any XML profile may trigger this issue, regardless of the XML schema or wsdl file used by the profile.

F5 Product Development is tracking this issue as CR136867.

This issue does not affect the BIG-IP ASM 10.x branch.

This issue has been fixed in Hotfix-BIGIP-9.4.8-407.0-HF4, which has been issued for BIG-IP version 9.4.8. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
