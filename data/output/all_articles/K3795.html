Topic

FirePass offers the following three SSL Cipher Security levels:
  • Low-grade security
  • Medium-grade security
  • High-grade security

Each of these security levels includes a different set of ciphers used for negotiating SSL sessions.

Note: The SSL Cipher Security setting is located on the Device Management : Security : User Access Security page in the FirePass Administrative Console.
