Known Issue

This is the result of a known issue. An HTTP cookie that does not have a value may cause the Traffic Management Microkernel (TMM) to crash while attempting to calculate the length of the cookie value.

Note: This issue only occurs when iRules are used to capture and read HTTP cookie information for logging or traffic handling purposes.

For example:

GET /somepath/filename.htm HTTP/1.1
Host: somehost.sitename.com
Connection: Keep-Alive
Cookie: Cookie1=somevalue; SessionID=blahblah; Cookie2=

In the example, Cookie2 is listed without a value, and the semi-colon ( ; ) terminator follows in a second HTTP packet. As a result, TMM may incorrectly attempt to calculate the length of the value contained within Cookie2 starting with the terminator.

F5 Product Development tracked this issue as CR97416 and it was fixed in BIG-IP 9.4.5. For information about upgrading, refer to the BIG-IP LTM release notes.

Additionally, this issue was fixed in Hotfix BIGIP-9.3.1-HF4 issued for BIG-IP 9.3.1. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.
