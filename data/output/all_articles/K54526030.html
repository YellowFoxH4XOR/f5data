Description
Displaying error message when using Configuration Utility to delete A record from ZoneRunner

Error: 01150406:3: Update operation refused

Environment

  • BIG-IP DNS/GTM
  • ZoneRunner/BIND

Cause
It is not allowed to delete A record of a NS before deleting its NS record.

Recommended Actions

Delete NS record before deleting its A record.

For example:

NS record
example.com.    external    example.com.    3600    NS    ns3.example.com.
example.com.    external    example.com.    3600    NS    ns5.example.com.  
example.com.    external    example.com.    3600    NS    ns2.example.com.

A/AAAA record for NS
ns5.example.com.    external    example.com.    3600    AAAA    2001:DB8::1 
ns3.example.com.    external    example.com.    3600    A    192.168.1.21
ns2.example.com.    external    example.com.    3600    A    192.168.1.22

  1. Delete ns5.example.com  NS record first
  2. Delete ns5.example.com  A record
