Description

After restarting a vCMP guest, the configuration failed to load, with the following error appearing when viewing the output of tmsh load sys config, or reviewing /var/log/ltm:

01070734:3: Configuration error: vmw-compat: vlan may only have one interface

Environment

  • vCMP guest
  • Configuration reload

Cause

The vlan.macassignment database key is set to vmw-compat:

sys db vlan.macassignment {
    default-value "unique"
    scf-config "false"
    value "vmw-compat"              <---
    value-range "global unique vmw-compat"
}

The value of vmw-compat should only be used on BIG-IP VE.

  • K14513: MAC address assignment for interfaces, trunks, and VLANs

vmw-compat - Specific to VE systems, only one interface is allowed per VLAN, and the VLAN will use the MAC address of its corresponding interface. No trunks may be attached to these VLANs.

Recommended Actions

Set sys db vlan.macassignment to the default of unique:

tmsh mod sys db vlan.macassignment value unique

Edit the /config/bigip_base.conf and remove the following line:

ltm global-settings general {
    share-single-mac vmw-compat  <--
}

Then reload the configuration:

tmsh load sys config

Additional Information

The following error may also be seen in /var/log/ltm when this issue occurs:

0107071c:3: Trouble allocating mac address for vlan object /Common/vlan123.
