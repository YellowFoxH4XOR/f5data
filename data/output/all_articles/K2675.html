Starting in version 4.2, you can configure BIG-IP to specify the exact ciphers that are permitted for use with SSL proxies. You can configure these settings per proxy, allowing you to make some proxies more permissive than others concerning which ciphers are permitted.

To configure this through the Configuration utility, perform the following steps:

  1. From the navigation pane, click Proxies.
  2. Choose a Proxy Server from the list.
  3. Click the Proxy Advanced Properties tab.
  4. In the Client Cipher List String box, enter the desired parameters.

    For example, to permit only 128-bit (and higher) ciphers, you would type the following:

    RSA+RC4:HIGH:MEDIUM:!LOW:!EXPORT:@STRENGTH

    This cipher string is defined as follows:

    ParameterDefinition
    RSA+RC4Use only ciphers that contain both RSA and RC4 ciphers.
    HIGHCiphers over 128 bits in strength.
    MEDIUM128-bit ciphers
    !LOWDo not use ciphers under 128 bits, except for export ciphers (40 - 64 bits).
    !EXPORTDo not use export ciphers. (40 - 64 bits).
    @STRENGTHOrder the cipher preference by strength.

Note: A complete description of the syntax can be found in the ciphers section of the OpenSSL web site. http://www.openssl.org/docs/apps/ciphers.html
