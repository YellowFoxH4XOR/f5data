Description

The vconsole utility is a telnet based console access utility that is typically used on the vCMP host system to connect to a particular vCMP guest. This procedure explains how to access the vconsole utility using ssh to connect directly to the vCMP guest. 

Environment

  • Viprion with vCMP provisioned 
  • vCMP guest deployed

Cause

  • Using vconsole with SSH

Recommended Actions
 

  1. To View the cluster information on the host system, use the following command:

    show sys cluster

    Your output may appear similar to the following example:

    -----------------------------------------

  | 4   10.10.10.5  available     enabled   true      active   running   Run
  2. To view vCMP guest on the host system, use the following command:

    show vcmp guest

    Your output may appear similar to the following example:
    ------------------------------------------------------------------------------------
    Vcmp::Guest
    Name      Slot ID   Status  Requested   Request  Retries             Uptime  Comment
                                    State  Complete
    ------------------------------------------------------------------------------------
    Guest11a        1  running   deployed      true        0  05/11/21 05:37:01
    Guest22a        3  running   deployed      true        0  05/11/21 05:45:52
     
  3. You can use the following command syntax to connect with the vCMP guest over SSH:

    ssh <user_with_bash_shell_access>@<host_ip_address> vconsole <guest_name> <slot_number> 

    For example, You can use the following command to connect to vCMP Guest11a on slot 1 to a vCMP host 10.10.10.1:

    ssh root@10.10.10.1 vconsole Guest11a 1

    You output may appear similar to the following:
