Issue

Error Message

011f0004:3: Invalid header insert profile, missing the colon separator in - <error> (<configuration>)

In this error message, note the following:

  • <error> is an error message
  • <objects> are the configuration objects associated with the connection flow

For example:

011f0004:3: Invalid header insert profile, missing the colon separator in - <Tcl subst error> (Client side: vip=/Common/example_vip profile=http pool=/Common/example_pool client_ip=10.10.10.10)

Message Location

You may encounter this message in the following location:

  • The /var/log/tmm file

Description

This message occurs when all of the following conditions are met:

  • A virtual server is configured with an HTTP profile.
  • The Request Header Insert option in the profile is configured with invalid text.

The value entered into the field for the Request Header Insert option must contain the header name and value separated by a colon character ( : ).

For example:

Header: Value

When the text does not follow this form, the BIG-IP system generates this message and does not insert the HTTP header.

Impact

The BIG-IP system does not insert the HTTP header configured in the HTTP profile

Recommended Actions

Ensure the Request Header Insert option in the HTTP profile is configured with properly formatted text as shown in the previous example.
