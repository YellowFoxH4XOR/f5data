Known Issue

When the Request Queuing and Priority Group Activation features are enabled for a pool, not all pool members of the priority group may receive connection requests from the pool's connection queue.

This issue occurs when all of the following conditions are met:

  • The Request Queuing feature is enabled for the pool.
  • The affected pool's connection queue is not empty.
  • Priority group activation is configured for the affected pool.
  • Higher priority pool members become unavailable, and there are available pool members with lower priority.

Impact

Pool members with a lower priority may not receive connection requests from the pool's connection queue when the higher priority pool members became unavailable.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The lower-priority pool members do not receive a connection request when the higher-priority pool members are not available.
