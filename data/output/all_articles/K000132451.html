Description

You may find the following error message in /var/log/daemon.log

For example,
LTM1.example.com err rmonsnmpd[pid]: unknown snmp version 193
LTM1.example.com err sflow_agent[pid]: unknown snmp version 193

In this error message, note the following:

•<pid> is the process ID of the daemon (rmonsnmpd/err sflow_agent) process.

Environment

• BIG-IP LTM
• NET-SNMP version 5.8

Cause

The error message will appear upon snmpd start/stop/restart.


Recommended Actions

The error message is cosmetic and can be safely ignored.
