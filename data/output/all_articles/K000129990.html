K000129990: "Check maximum number of parameters" when uploading a file

Type
Support Solution
Published
2022-12-13
Updated
2024-10-09
Applies to
  • BIG-IP
  • BIG-IP ASM: 15.1.5
Source
https://my.f5.com/manage/s/article/K000129990

Description

When uploading large files, violation occurs by "HTTP protocol compliance failed" - "Check maximum number of parameters".

Environment

BIG-IP ASM

File upload

Cause

Default number of parameters is 500 and upload includes more than that.

Recommended Actions

One of following options can be used:

  1. Set a number based on what is seen is the Event log for maximum number of parameters in Security ›› Application Security : Policy Building : Learning and Blocking Settings >> HTTP protocol compliance failed >> Check maximum number of parameters. The number set will depend on application/network needs.
    1. In the Details block it will list the total number of parameter seen in the violation. 
      Example: Number of total parameters <1005> in request (query string and post-data) exceed maximum limitation
    2. The maximum setting is 5000. 
  2. Set an ASM::disable iRule to disable ASM for failing application path
  3. Use a Local Traffic Policy to disable ASM
