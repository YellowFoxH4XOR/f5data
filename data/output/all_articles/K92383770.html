Description

It is possible to add a new VLAN to a running vCMP guest.

Environment

  • vCMP system
  • VLAN

Cause

Shutting down a vCMP guest is not required for a new VLAN to be added to it.

Recommended Actions

You can add a VLAN to a vCMP guest from the vCMP host by entering the following command syntax on the vCMP host command line:

tmsh modify vcmp guest <vCMP guest name> vlans add { <VLAN 1 name> <VLAN 2 name> ... }

For example,

tmsh modify vcmp guest guest1 vlans add { VLAN-A VLAN-B }

When you have added the VLAN(s) to the vCMP guest configuration, the VLAN(s) should show up on the vCMP guest's Network > VLANs > VLAN List page immediately. Alternatively, you can view the VLAN list of the vCMP guest by entering the following command on the vCMP guest command line:

tmsh list net vlan
