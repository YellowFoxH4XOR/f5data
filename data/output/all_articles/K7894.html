K7894: Individual App Tunnel Allow Lists are applied to all App Tunnel Favorites assigned to a user

Known Issue

This is the result of a known issue. If you configure an Allow List for an individual App Tunnel favorite, that Allow List will be applied to all App Tunnel favorites assigned to a user. For example, if you configure the Allow List *:22 for an App Tunnel favorite, FirePass will allow all App Tunnel favorites assigned to the user to access TCP port 22 on any host.

F5 Networks Product Development is tracking this issue as CR84052.

Workaround

You can mitigate this issue by defining specific hosts and ports for each App Tunnel Allow List and by avoiding wildcard characters.

Important: An issue exists where individual App Tunnel Allow Lists are not fully restored from backup. For more information, refer to K10631: Allow lists for Web Application Tunnels are not fully restored from backup. To avoid this issue, you can define resource group Allow Lists on the Application Access : App Tunnels : Resources page under the Web Application Tunnels tab.

For example, change the App Tunnel Allow List *:22 to the following code:


host1.siterequest.com:22

host2.siterequest.com:22

host3.siterequest.com:22

Change the App Tunnel Allow List host1.siterequest.com:1-65535 to the following code:

host1.siterequest.com:25,80,110,443

Important: Defining strict App Tunnel Allow Lists will minimize the impact of this issue, but these Allow Lists will still be shared by all App Tunnels assigned to the user.
