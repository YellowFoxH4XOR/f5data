Known Issue

This is the result of a known issue. When configuring Active Directory authentication for a master group, you can click the Test Saved Settings button to test authentication by entering a user name and password. If the test succeeds, users in that master group can successfully authenticate against the Active Directory server. If the test fails, users in that master group may successfully authenticate against the Active Directory server despite the failed test result.

This issue occurs because the Active Directory test function requires that you configure valid Active Directory credentials in the Domain admin name and Domain admin password fields. Additionally, the account you configured cannot be disabled in Active Directory. For actual user authentication, users can successfully authenticate by supplying a valid Active Directory user name and password, even if the account you specified in Domain admin name field is incorrectly configured or disabled.

Note: The account you configure in the Domain admin name field does not have to be a domain administrator account for the test to succeed, however additional issues can occur if you do not configure an administrator account. For more information, refer to K9860: Reasons to configure the domain administrator account for Active Directory authentication.

F5 Product Development is tracking this issue as CR117317.

Workaround

When configuring Active Directory authentication for a master group, you can ensure that the authentication test will work correctly by performing the following steps:

  • In the master group configuration under the Authentication tab, ensure that valid Active Directory credentials are configured in the Domain admin name and Domain admin password fields.
  • On the Active Directory server, ensure that the account you configured is not disabled.
