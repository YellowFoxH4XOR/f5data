Known Issue

Using the exit command in the Maintenance Operating System (MOS) may end the shell session abruptly.

This issue occurs when all of the following conditions are met:

  • You perform a clean installation of BIG-IP software by using the diskinit and image2disk utilities manually.
  • After the software installation is completed, you run the exit command in MOS.

Impact

The MOS shell session ends abruptly, and the BIG-IP system stops responding.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • The MOS shell session ends abruptly, and the BIG-IP system stops responding.

Workaround

There is no workaround for this issue. However, to avoid this issue, you can run the /bin/start utility instead of using the exit command.
