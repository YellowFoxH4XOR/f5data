Issue

In ARX versions prior to 5.0.0, the NSM binary-core-files feature was disabled by default. In addition, enabling or disabling the feature required you to restart the ARX system.

Beginning in ARX 5.0.0, the NSM binary-core-files feature is enabled by default. When the NSM binary-core-files feature is enabled, the NSM processor will create a detailed binary core file if the NSM processor encounters a failure. In addition, you no longer have to restart the ARX system to enable or disable the NSM binary-core-files feature.

Note: For more information about the NSM binary-core-files feature, refer to the Redundant Pairs chapter in the ARX CLI Reference Guide.

Note: The NSM binary-core-files feature requires the NSM recovery feature to be enabled. For information about a change in behavior for the NSM recovery feature in ARX 5.0.0, refer to K10158: Change in Behavior: NSM recovery.
