Platforms

Customers have reported that the following systems work with the BIG-IP version 9.x PXE network boot server; however, F5 cannot guarantee that all revisions of the specified network interface cards (NICs) will work on all hardware platforms. In some cases, the same revision of a NIC card works on one hardware platform and not on another.

  • Dell 2650 server (NICs: BCM5703, 82543GC, 82544EI)
  • Dell 2550 server (NICs: BCM5703)
  • HP ProLiant DL380 (NICs: BCM5703, 82546EB)
  • Dell D600 Laptop (NICs: BCM5702)
  • Dell GX270 Desktop (NICs: EEPro 100)
  • Dell GX270 Desktop (NICs: 3COM 3c920)
  • Dell GX270 Desktop (NICs: Intel Etherexpress Pro+)

Using a VMware virtual machine

You can also run the BIG-IP version 9.x PXE network boot server as a VMware virtual machine. For information about setting up a new virtual machine, refer to your VMware product documentation. Ensure that you select Other 2.4.x Linux (32-bit) as the guest operating system, and that you bridge the virtual NIC to the BIG-IP management network. Leave all other settings as default when creating the virtual machine. You can mount the BIG-IP ISO file directly on the virtual CD-ROM drive. After powering on the virtual machine, the BIG-IP version 9.x PXE network boot server correctly detects the virtual NIC and loads the appropriate driver for it.

Using a VMware virtual machine can be convenient for the following reasons:

  • It allows the use of a host with a possibly otherwise unsupported network adapter
  • It is not necessary to burn the ISO file to a CD
  • A single host can be used to run the virtual machine and at the same time connect to the console of the BIG-IP system
