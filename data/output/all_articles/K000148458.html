Description

When trying to configure HTTP::redirect inside the LB_QUEUED event you receive an error during save:

01070151:3: Rule [/Common/LB_QUEUED-rule] error: /Common/LB_QUEUED-rule:3: error: [command is not valid in current event context (LB_QUEUED)][HTTP::redirect http://example.com]

 

Environment

  • iRule
  • HTTP::redirect in LB_QUEUED event
  • error "command is not valid in current event context (LB_QUEUED)"

Cause

LB_QUEUED is a server-side event so in order to get a HTTP::redirect to send a response on a client-side we need to change the context.

Recommended Actions

Use the "clientside" command to change the context from server-side to client-side.

The following iRule works fine:

when LB_QUEUED {

clientside { HTTP::redirect "http://example.com" }

}
