K000140127: App shows Health: Critical because of an active alert which is not visible in the API/GUI

Source

Description

In the BIG-IP Next CM, an App shows as Critical, even though traffic is working and no alerts can be found in the GUI/API


This log can be found in the mbiq-alert-feature logs:

2024-03-27 13:14:48.553559+00 \N {ACTIVE} app: health is SEVERE. Name:<<App ID | APP name >> app health is SEVERE, check base alerts for more information


Environment

  • False Critical Alarms

Cause

Bug ID 1592629

Recommended Actions

  1.  Login to pg-cluster-1 pod..

k exec -it pg-cluster-1 -c postgres -- bash


2. To find out the count of app object type alerts.

psql -U postgres -d bigiq_db -c "select count(*) from mbiq_alert.alerts where object_type = 'app' and (additional_information->'hash') is null"


3. To update the status of the app object type alerts.

psql -U postgres -d bigiq_db -c "update mbiq_alert.alerts set status = '{INACTIVE}' where object_type = 'app' and (additional_information->'hash') is null"
