Description

Node inspector is deprecated and you want to use Node.js to debug a node app or LX workspace.

Node.js is built on the JavaScript engine "V8" built for Google Chrome which was open-sourced by Google in 2008.  V8 includes with it an extensive debugging system for use when developing your Node.js applications.  The debugger can be accessed by a TCP based TCP DebuggerProtocol.

Environment

  • BIG-IP
  • LX workspace
  • Chrome DevTools
  • Node.js

Cause

Since version 6.3, Node.js provides a built-in DevTools-based debugger which mostly deprecates Node Inspector. Currently, BIG-IP is using version 6.9.1
 

Recommended Actions

  1. You must add a ACL under System>Platform>Security: Management Port to allow Chrome DevTools Node Inspector or Visual Studio Code to connect to the tcp port 9229.

  2. For Node 6.9.1, you have to use --inspect --debug-brk for inspect & pseudo-breakpoint combo.
    You add this to the Command Options in the LX Plugin properties, followed by reloading the plugin.
