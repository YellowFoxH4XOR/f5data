K000135787: BIG-IP Azure image "best-hourly" is replaced by "best-plus" images

Type
Support Solution
Published
2023-08-30
Updated
2023-11-30
Source
https://my.f5.com/manage/s/article/K000135787

Description

Azure images "f5-bigip-virtual-edition-xxx-best-hourly" shows status deprecated.

 

> az vm image show --urn f5-networks:f5-big-ip-best:f5-bigip-virtual-edition-1G-best-hourly:17.1.001000

(ImageVersionDeprecated) VM Image from publisher: f5-networks with - Offer: f5-big-ip-best, Sku: f5-bigip-virtual-edition-1G-best-hourly, Version: 17.1.001000 is deprecated.

Code: ImageVersionDeprecated

Message: VM Image from publisher: f5-networks with - Offer: f5-big-ip-best, Sku: f5-bigip-virtual-edition-1G-best-hourly, Version: 17.1.001000 is deprecated.

 

Active VM instances won't be impacted. Y cannot scale out the VM instances after the deprecation date.

Environment

azure

Cause

F5 replaced "f5-bigip-virtual-edition-xxxx-best-hourly" images with "f5-big-best-plus-hourly-xxxx", on Aug.05 2023

Recommended Actions

The "f5-bigip-virtual-edition-xxxx-best-hourly" images are no longer available on the Azure Marketplace. Choose one of the "f5-big-best-plus-hourly-xxxx" images instead.
