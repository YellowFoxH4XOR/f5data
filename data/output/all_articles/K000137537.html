Description

BIG-IQ fails to discover LTM module for hardware platforms with error:


"Failed to process module tasks for device test.localhost (10.0.0.1): At least one module has failed"



TCPDUMP collected on BIG-IP during discovery returns 500 error when for GET /mgmt/tm/sys/hardware

(tcpdump -i lo -s0 -w /var/tmp/rest.pcap port 8100 -v)

Cause

Recommended Actions

  • Identify which hardware is causing Discovery issue by using tmsh command:


  • tmsh show sys hardware > /var/tmp/hardware_output.txt

 

Note: Redirect output to file as console output might not show this
