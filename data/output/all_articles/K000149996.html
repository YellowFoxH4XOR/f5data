K000149996: NGINX App protect could trigger signatures "200003534" and "200003036" due to "_uetsid" Cookie containing "ftp" string

Type
Support Solution
Published
2025-02-26
Updated
2025-02-26
Source
https://my.f5.com/manage/s/article/K000149996

Description

Incoming HTTP requests could be blocked due to the "_uetsid" Cookie containing "ftp" string. The signatures could be triggered are:

  • ID200003534 - Windows "ftp" execution attempt (Parameter)
  • ID200003036 - Unix/Linux "ftp" execution attempt (Parameter)

The violation is expected as it matches the attack signature pattern. This is a Microsoft Clarity cookie used to persist the Clarity User ID and preferences, unique to that site is attributed to the same user ID.

External Reference

Microsoft Cookie List

Issue with MS Clarity and F5 WAF Blocking _uetsid Cookie (Containing ftp String)

Environment

  • NGINX App Protect

Cause

The cause of the violation is the value of the cookie that matches the attack signature pattern.

Recommended Actions

To work around this issue disable the signature in the App Protect policy. 

    "signatures": [
                {
                     "signatureId": 200003036
                     "enabled": false
                }, 
    			{
                     "signatureId": 200003534
                     "enabled": false
                }
