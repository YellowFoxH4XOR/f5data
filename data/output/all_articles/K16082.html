Known Issue

The geolocation database may show incorrect country data.

This issue occurs when the following condition is met:

  • You have installed the ip-geolocation-1.0.1- 20140102.* - ip-geolocation-1.0.1-20140807.103.0 version of F5 geolocation data.

Impact

The IP address location information reported by the BIG-IP system is not accurate.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Your BIG-IP system reports inaccurate IP address locations.

Resolution

Status

F5 Product Development has assigned ID 475911 to this issue. F5 has confirmed that this issue exists in the products listed in the Applies to (see versions) box, located in the upper-right corner of this article. For information about releases or hotfixes that resolve this issue, refer to the following table:

Type of FixFixes Introduced InRelated Articles
Release11.6.0*
11.5.1*		K2200: Most recent versions of F5 software
HotfixNoneNone

*The geolocation database was fixed for the noted BIG-IP versions in ip-geolocation-1.0.1-20140902.109.0.zip and later. For information about downloading and installing the latest geolocation database, refer to K11176: Downloading and installing updates to the IP geolocation database.

Workaround

If updating the geolocation database is not possible, you can work around this issue by creating an iRule to rewrite the incorrect country data.
