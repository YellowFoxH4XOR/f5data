Description

Upgrade fails on BIG-IP LTM when upgrading to v16.0.1. CLI is very slow and GUI is unresponsive.

Environment

  • BIG-IP 2000

Cause

Hardware and Software are not compatible.

Recommended Actions

Upgrade according to hardware/software compatibility matrix, as BIGIP 2000 does not support version 16, according to: K9476: The F5 hardware/software compatibility matrix.

Additional Information

The installation of the ISO succeeds, and no error logs are shown.
