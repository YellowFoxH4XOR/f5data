K03227420: EMS is not able to sync configuration to another SDC site

Type
Support Solution
Published
2022-08-23
Updated
2024-10-01
Status
Legacy Content
Applies to
  • Traffix SDC: 5.1.X, 5.1.0
Source
https://my.f5.com/manage/s/article/K03227420

Description

EMS is not able to sync configuration to SDC site or SDC(Components[FEPs/CM]) is not able to sync configuration with SDC(CM)

  • 2022-07-18 11:18:08,204 WARN  [11763] ping to WsRestClientWrapper [baseUri=https://10.53.91.42:61617/cm-distribution/] failed with result FAILED_TO_REGISTER [ping-0_24] [DistributionManager$1.run()] com.traffix.openblox.core.utils.clustering.infrastructure.WsException: javax.ws.rs.ProcessingException: RESTEASY004655: Unable to invoke request: org.apache.http.NoHttpResponseException: 10.53.91.41:61617 failed to respond

Environment

  • SDC running on version CF33/34
  • SDC and EMS is located physically at different location. 
  • SDCs and its components(FEPs)

Cause

Unknown trigger to Jetty bug cause data transmission via TLS record to exceed max length(16k) and this prevents configuration from sync.

Recommended Actions

  1. upgrade to CF35

Additional Information

1) Bugid SDC-2003
