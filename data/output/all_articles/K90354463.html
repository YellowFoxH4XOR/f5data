Description

Failover occurred, the device displays FAILSAFE FAULT, and you can see similar to below log in /var/log/ltm:

  • info bcm56xxd[<pid>]: 012c0015:6: Link: <interface_name> is DOWN
  • warning sod[<pid>]: 01140029:4: HA vlan_fs /<partition>/<vlan_name> fails action is failover.
  • notice sod[<pid>]: 010c005c:5: Failover condition reported by /Common/<device_name> for traffic group /Common/<traffic_group_name>, it will not be able to go active.

Environment

  • BIG-IP
  • Failover
  • VLAN failsafe
     

Cause

This indicates VLAN failsafe is triggered and the condition was not cleared as there is still no traffic in the affected VLANs.
 

Recommended Actions

Check the cause of link down, if there is no physical issue, you may want to perform a packet trace in the affected VLAN to verify if there is traffic:

tcpdump -s0 -nni <VLAN name>


To disable VLAN failsafe, run the following command:

tmsh modify net vlan <vlan_name> { failsafe disabled }


Additional Information

    VLAN failsafe
    With VLAN failsafe, the BIG-IP system monitors network traffic going through a specified VLAN.

    You can check the settings by running the following command:

    list net vlan <vlan_name> all-properties
    net vlan <vlan_name> {
        app-service none
        auto-lasthop default
        cmp-hash default
        customer-tag none
        dag-round-robin disabled
        dag-tunnel outer
        description none
        failsafe enabled   <<----- enabled / disabled
        failsafe-action failover   <<----- action
        failsafe-timeout 90   <<----- in seconds
        fwd-mode l3
        hardware-syncookie disabled
        if-index 208
        interfaces {
            <interface_name> {
                app-service none
                tag-mode none
                untagged
            }
        }
        learning enable-forward
        mtu 1500
        partition Common
        sflow {
            poll-interval 0
            poll-interval-global yes
            sampling-rate 0
            sampling-rate-global yes
        }
        source-checking disabled
        syn-flood-rate-limit 1000
        syncache-threshold 6000
        tag 4093
    }



    Once a VLAN failsafe condition is cleared, a log message similar to the one described in the following article will be triggered:

    • K83454841: Error Message: 01140030:5: HA is now responding

    Additionally, the system will automatically return to the state it was in previously, such as active, standby, or offline.
