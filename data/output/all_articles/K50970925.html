Description

Following a version upgrade, ASM signatures have not been upgraded to the new release signatures.

Environment

  • BigIP ASM version upgrade
  • ASM policies with applied Signatures

Cause

When upgrading ASM, the ASM Signatures are part of the ASM Policy configuration that are rolled forward into the new version.
If ASM Signature Updates are set to manual, there will not be an update performed after the upgrade.

Check in the Attack Signature Update page, depending on your version:

From BIG-IP 12.0.0 and later
Security > Security Updates > Application Security
 

Versions prior to BIG-IP 12.0.0
Security > Options > Application Security > Attack Signatures > Attack Signatures Update

Note: this information is *not* populated directly after an upgrade  
- you will need to look at View update history from previous BIG-IP versions and browse through to the last page to find the last installed version.

Recommended Actions

Manually update the Signatures following an upgrade to ensure ASM Signatures are current.
