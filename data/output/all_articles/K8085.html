Known Issue

This is the result of a known issue. If you configure an SNMPv1 trap host on a FirePass 4100 or 4300 controller, FirePass will incorrectly set the source IP address for SNMPv1 traps to 127.2.0.2. The correct behavior is for FirePass to set the source IP address for SNMPv1 and SNMPv2 traps to the IP address of the first configured interface on the FirePass controller. SNMP settings are configured on the Device Management: Configuration: SNMP page in the FirePass Administrative Console.

Note: This issue only affects SNMPv1 traps. FirePass correctly sets the source IP address for SNMPv2 traps.

F5 Networks Product Development tracked this issue as CR88450 and it was fixed in FirePass version 6.0.3. For information about upgrading, refer to the FirePass Release Notes.
