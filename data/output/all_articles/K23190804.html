K23190804: Unable to Create child policy when Parent has set Auto-Added Signature Accuracy field to a non-default value

Type
Support Solution
Published
2021-11-25
Updated
2023-02-21
Applies to

  • BIG-IP ASM: 16.X.X, 16.0.X, 15.1.X, 15.1.8, 15.1.7, 15.1.6, 15.1.5, 15.1.4, 15.1.3, 15.1.2, 15.1.0, 16.1.3, 16.1.2, 16.1.1, 16.1.0, 16.0.1, 16.0.0, 15.1.1, 16.1.X
Source

Description

For a certain configuration, the creation of child policy fails with an error similar to:

      Could not update the Policy '<policy_fullpath>'. Inherited values may not be changed.

Environment

Parent policy has the following settings:

  • Case Sensitive set to disable.
  • Auto-Added Signature Accuracy set to low.

Cause

This behavior is the result of known issue ID1062105 as ASM should allow the creation of the child security policy.

Recommended Actions

Use REST API command to create the desired child security policy.

For example:

curl -sk -u user:passwd https://localhost/mgmt/tm/asm/policies/ -H "Content-Type: application/json" -X POST -d '{"name":"child_policy", "parentPolicyName":"/Common/parent_policy","template": {"name":"POLICY_TEMPLATE_RAPID_DEPLOYMENT"}}'
Note: update the above command with correct credentials and IP/hostname of the BIG-IP in question as well as correct body variables.
