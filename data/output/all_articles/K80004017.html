Topic

You should consider using this procedure under the following condition:
  • You want to export Learning Suggestions from a specific security policy to an HTML file.

Description

The Traffic Learning feature of the BIG-IP ASM helps you build and refine a security policy especially if you are doing so manually. The BIG-IP ASM does this by presenting you with learning suggestions based on requests and responses the system has analyzed. The system suggests updating the policy due to violations or it suggests adding legitimate entities such as URLs, file types, or parameters that often appear in requests.

Beginning in BIG-IP ASM 14.0.0, you can export individual or multiple learning suggestions to an HTML file. This is particularly useful to provide to technical resources that do not have access to the Traffic Learning page. The export includes all details for each learning suggestion record you selected including sample requests and responses if they are a part of the suggestion. Request logging or response logging must be enabled for the learning suggestion to include samples.

You can also use the iControl REST API to display learning suggestions and easily export the iControl output to another format. For more information refer to K58082590: Displaying BIG-IP ASM learning suggestions using the iControl REST API.

Prerequisites

  • You have administrative access to the Traffic Learning page of the BIG-IP ASM Configuration utility.
  • BIG-IP ASM is provisioned and a security policy is applied to a virtual server.
  • In the Learning and Blocking Settings page, the Learn flag is enabled for violations and learning is enabled for entities such as parameters and URLs.

Procedures

Exporting BIG-IP ASM learning suggestions using the Configuration utility

You can export individual or multiple learning suggestions to an HTML file using the following procedure.

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the Configuration utility.
  2. Go to Security > Application Security > Policy Building > Traffic Learning.
  3. Ensure the name of policy you want to work with is shown near the top of the page.
  4. Select one or more check boxes for the suggestions you want to export in the Suggestions list.
  5. Select Export to export the selected learning suggestions to an HTML file.
  6. Save the file to your workstation.
