Description

  • Configuring SWG SSL bypass

Environment

  • BIG-IP with SWG configured
  • SWG setup with iApp or following deployment guide

Cause

SWG SSL Bypass Set requires a specific sequence of VPE objects in the Per-Request Policy

Recommended Actions

Build a Per-Request Policy as described in SSL Bypass and Intercept with APM in the BIG-IP Access Policy Manager: Secure Web Gateway manual.

Note: when configuring a custom URL Category to be used in the branch rule of the Category Lookup object, the FQDN should be terminated with a forward slash (/). Such as: example.com/.
