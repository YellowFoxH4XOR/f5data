Description

When users submit usernames and/or passwords containing foreign language special characters for RADIUS Authentication, it may fail due to the RADIUS Authentication process on the BIG-IP using the default Character Set value of Windows-1252. This authentication failure occurs because Windows-1252 decodes the username & password into CP-1252 before sending the authentication request to the RADIUS Authentication server. Effectively, this corrupts the username or password containing the foreign language special characters, thereby causing the authentication failure. 

Environment

  • BIG-IP Access Policy Manager (APM)
  • RADIUS Authentication
  • Foreign language usernames & passwords in use.

Cause

This is expected behavior, given the two options for Character Set in the RADIUS AAA object's config, as explained by the Help pertaining to this parameter.

Recommended Actions

This can be avoided by changing the RADIUS AAA object's Character Set parameter to UTF-8, which will prevent any modification of the username & password submitted by the user. So the original user provided username & password are sent to the RADIUS Authentication server unmodified. Thereby allowing for successful RADIUS Authentication. 

To implement this change:

  1. Login to the Configuration utility.
  2. Navigate to Access > Authentication > RADIUS and select the pertinent RADIUS AAA object.
  3. Click the drop-down for Character Set and select UTF-8, instead of Windows-1252.
  4. Then click the Update button to save the change. 

Additional Information

Per the Configuration utility Help tab. The following description of the RADIUS Authentication object's Character Set parameter, and the affects of it's two options:

Character Set: Specifies character encoding for the username and password.

  • Windows-1252 - APM RADIUS Authentication agent decodes the username and password into CP-1252 before sending it to the RADIUS server. This is the default.

  • UTF-8 - RADIUS Authentication sends the username and password unmodified.
