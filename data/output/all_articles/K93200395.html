Description

When you configure "gtm global-settings general { synchronization yes }", it is listed in /config/bigip_gtm.conf.
However, when you configure "gtm global-settings general { synchronization no }", it is not listed in /config/bigip_gtm.conf.

Environment

  • BIG-IP DNS system
  • BIG-IP Link Controller system

Cause

This is by design.

Recommended Actions

None.
