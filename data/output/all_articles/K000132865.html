Description

Tenant on rSeries is unexpectedly failed over due to silent reboot.

Environment

  • F5OS-A
  • rSeries 5000/10000

Cause

  • Bug ID 1231357
  • Bug ID 1232369

Recommended Actions

  1. Upgrade to F5OS-A 1.5.0 to address both IDs 1231357 and 1232369.
  2. To determime if the unit hit this bug, check tenant's /var/log/ files. If nothing indicate the cause of this reboot.
  • var/F5/system/log/platform.log: if any reboot cause indicated before the time of BOOT-MARKER.

appliance-1.chassis.local notice boot_marker: ---===[ BOOT-MARKER ]===---

  • var/log/platform/pel (pel.*) : if similar to the below log (this may not be in show event command output)

| 60564 | AOM | 255 | Na | 0 | CPU internal error event <<<---------------------------[!!]
| 60565 | AOM | 255 | Asserted | 2 | CPU internal error <<<---------------------------[!!]
| 60566 | AOM | 255 | Asserted | 6 | PSU 1 invalid or unsupported command PMBus event
| 60567 | AOM | 255 | Na | 5 | Intel ME PCS sequential read failures: 10
| 60568 | AOM | 255 | Asserted | 5 | CPU temperature sensor fault
| 60569 | AOM | 255 | Asserted | 5 | CPU TCTL-Delta temperature sensor fault

/var/crash/127.0.0.1-<YYYY-MM-DD:HH:MM:SS>/vmcore-dmesg.txt  should have similar to the below log

Please escalate the issue to F5 Support with the following data:

  1. rSeries qkview with Max File Size 1000
  2. The vmcore-dmesg.txt files in /var/crash.
