Description

When attempting to boot into a software volume in Big-IP VE, you may receive an error in the console: 

Error Occurred During File System Check", "Dropping you to a shell; the system will reboot"

Environment

Big-IP VE

Cause

Filesystem corruption can trigger this error. This can also occur if there was a replacement or change/upgrade in hypervisor hardware, the hypervisor itself, or the Big-IP VE software image.

Recommended Actions

On the Big-IP console displaying the error, you will see an option that says:

Give root password for maintenance
(or type Control-D to continue):

Enter the root password or type Control-D to enter the maintenance shell. Within the maintenance shell, force a file system check with the following command:
fsck

After this completes, you will be returned to the Big-IP logon prompt in the console window.
You can then proceed to login and verify the configuration is in place.

Additional Information

K43582200: BIG-IP VE systems no longer automatically perform the file system consistency check
