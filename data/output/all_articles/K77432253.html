K77432253: The value of 'Stats Last Collection Date' is ''Jan 1, 1970'' or ''Dec 31, 1969'' for monitored BIG-IPs

Published
2022-02-22

Description

The last 'Stats Last Collection Date' for a monitored BIG-IP is incorrect when checking the device status through BIG-IQ Centralized Management

  • Stats Last Collection Date shows "Jan 1 1970" or "Dec 31 1969"

  • Device status shows yellow triangle, when hovering cursor on it, there is hint "stats has not started yet"

Restarting the avrd or restjavad daemon cannot fix the issue.  
 

Environment

  • BIG-IQ

  • BIG-IP

  • AVRD

Cause

BIG-IP lost connection with DCD can trigger such issue, it can be verified with telnet, for example,

# tmsh list analytics global-settings

analytics global-settings {
    avrd-interval 30
    ecm-port 443
    enable-bigiq-configuration enabled
    offbox-protocol https
    offbox-tcp-addresses { 192.168.1.1 } <----- get the DCD IP address 
    offbox-tcp-port 443
    source-id <device-ID>_192.168.1.1
    use-offbox enabled
}

telnet test results could be refused or timeout.

# telnet 192.168.1.1 443
Trying 192.168.1.1...
telnet: connect to address 192.168.1.1: Connection refused

Recommended Actions

  • Check the port lockdown setting on BIG-IQ DCD, make sure prot 443 allow.

  • Check whether there is security device blocking the port 443 between BIG-IQ and BIG-IP.

Additional Information

Bug ID 797457: Stats Last Collection date is not correct can trigger the similar symptom.  Please check the connectivity first, if the issue still exist without connectivity and do not match the bug, please contact with F5 support.
