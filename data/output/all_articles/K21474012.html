K21474012: Error message ''Bad SSH2 KexAlgorithm''

Type
Support Solution
Published
2020-09-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 11.6.5
Source
https://my.f5.com/manage/s/article/K21474012

Description
Attempting to edit SSHD properties by specifying the Key exchange algorithm diffie-hellman-group-exchange-sha256 fails with the errors below:

01070920:3: Application error for confpp: STDERR/STDOUT text begins Bad SSH2 KexAlgorithm 'diffie-hellman-group-exchange-sha256'

Environment

  • BIG-IP LTM
  • SSH
  • Software Version prior to 12.0.0

Cause
The SSH Key exchange algorithm diffie-hellman-group-exchange-sha256 is not supported before software version 12.0.0

Recommended Actions
Upgrade to BIG-IP software version 12.0.0 or above, which supports diffie-hellman-group-exchange-sha256

Additional Information
None
