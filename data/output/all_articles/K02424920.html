Issue

Error Message

01020066:3: The requested <object_type> (<object_name>) already exists in partition <partition>.

In this error message, note the following:

  • <object_type> is a BIG-IP configuration object.
  • <object_name> the configuration object name.
  • <partition> is the partition name where the object exists.

For example:

01020066:3: The requested TCP Profile (/Common/tcp_profile) already exists in partition Common.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file

Description

This message occurs when one of the following conditions is met:

  • You attempt to create an object that shares the same name or identifier as an existing object.
  • An internal conflict occurs during delete and create operations when you attempt to reconfigure an iApp.
  • You delete and create an object in a single transaction or perform multiple actions on an object in a single transaction.

Impact

The requested action fails.  This situation can cause validation errors, prevent ConfigSync operations from completing, and cause iApp deployments to fail.

Recommended Actions

  • If the transaction has multiple actions, separate the actions into different transactions. For example, if the transaction deletes HTTP monitor mon_http and then re-creates it, you can create one transaction to delete the monitor and another transaction to re-create it.
  • If an iApp deployment is affected, the configuration may not be complete and you may have to either redeploy the iApp or manually create the configuration.
