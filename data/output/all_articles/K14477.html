Topic

Summary

To identify if an ARX platform is an ARX4000 or ARX4000+, you may use the ARX CLI show chassis command.

Description

The ARX4000 and ARX4000+ platforms are manufactured with different data-plane components and are not guaranteed to function with the other model. It is important to verify which model to order when you request a replacement for an ARX 4000 or ARX 4000+.

To identify the ARX 4000 from the ARX 4000+ platform, you may use the ARX CLI show chassis command. The models numbers listed below identify the difference.

ARX-4000+: ARX4000ALLX
ARX-4000: SR2500ALLXR

For example, the show chassis command output for an ARX 4000 will appear similar to the following example:

Identification:

 Hostname                             UUID
 ------------------------------------ --------------------------------------
 SWITCH                               4ba36c10-30c6-11dd-ba58-b9262f5c441e
 Chassis:
 Chassis Type  Model Number                          HW Ver.  Serial Number
 ------------  ------------------------------------  -------  -------------
 ARX-4000      SR2500ALLXR                                    BZDS80701617

Note: The show chassis command output may also be found in a diagnostics collect in the /acopia/var/log/cli_show.log file.
