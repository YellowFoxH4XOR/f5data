Description

Apache Tomcat is a free and open-source software that provides a "pure Java" HTTP web server environment in which Java code can also run. Thus it is a Java web application server, although not a full JEE application server.

 

Apache Tomcat is not used in F5OS-A, F5OS-C, Big-IQ

 

Environment

  • F5OS-A
  • F5OS-C
  • Big-IQ

Cause

N/A

Recommended Actions

It is confirmed that Apache Tomcat is not used in F5OS-A, F5OS-C, and Big-IQ

 

Additional Information

This information is useful when performing security vulnerability validation for Apache Tomcat
