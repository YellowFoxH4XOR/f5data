Description

  • BIG-IP AFM is sending out logs to remote syslog via tmm interface instead of management interface

Environment

  • AFM logs
  • Log destination configured with HSL pool (Syslog pool)

Cause

The seen behavior is expected, by default HSL dispatches logs through the Traffic Management Microkernel (TMM) process, the BIG-IP system sends the high-speed logs to remote log servers that reside in networks reachable through the TMM interfaces. Starting in BIG-IP 12.0.0, you can configure HSL to use the management port to send logs to servers only reachable through the management network.

Recommended Actions

Starting in BIG-IP 12.0.0, you can configure HSL to use the management port to send logs to servers only reachable through the management network. To do so please perform the steps provided in the following article:

K50040950: Configuring the BIG-IP system to send high-speed logs through the management interface
