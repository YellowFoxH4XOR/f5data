Known Issue

The Traffic Management Microkernel (TMM) may generate a core file and restart when running low on LSN translation addresses and ports.

This issue occurs when all of the following conditions are met:

  • The CGNAT module is licensed on the BIG-IP system.
  • An LSN-pool is configured in Deterministic mode with a backup pool or in NAPT mode.
  • A CGNAT virtual server is associated with the LSN pool.
  • The CGNAT virtual server is handling a high number of clients.

Impact

TMM generates a core file and restarts.

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • BIG-IP iHealth lists Heuristic H432441 on the Diagnostics > Identified > Medium screen.
  • The BIG-IP system generates a TMM core file to the /shared/core directory.
  • The BIG-IP system fails over to another system in the device group.
  • The BIG-IP system temporarily fails to process traffic while TMM restarts.
  • In the /var/log/ltm file, you may observe error messages that appear similar to the following example:

    01010239:3: LSN error: Inbound reservation failed
    01010201:2: Inet port exhaustion on 6.43.168.116 to 107.64.138.97:27965 (proto 17)
