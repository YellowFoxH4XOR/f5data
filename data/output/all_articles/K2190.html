Note: This solution assumes that you know how to trunk your non-BIG-IP device. Direct specific support questions about trunking non-BIG-IP devices to the vendor for that specific device.

To configure a trunk port on BIG-IP from the command line, perform the following steps:

  1. Verify that all the interfaces that you want to combine within a trunk are not already part of a VLAN. If they are, remove the VLAN association by typing the following command:

    Note: If you are connected through SSH to one of the interfaces you want to combine, perform this step through the console, or verify that you are connected through a port that will not be affected by the command.

    b vlan <vlan name> interfaces delete <ifname>

    For example, to create a trunk that contains both the 3.1 and 5.1 interfaces, you would type:

    b vlan external interfaces delete 3.1

b vlan internal interfaces delete 5.1

  2. Using the following command, add the interfaces to a trunk by identifying the controlling link <interface> and defining the other links <interfaces>:

    bigpipe trunk <interfaces> define <interfaces> <interfaces>

    In the following example, 3.1 is the controlling link <interfaces>:

    bigpipe trunk 3.1 define 3.1 5.1

  3. Use the following command to associate only the controlling link <interfaces>to the VLAN for which you want to process traffic.

    b vlan <vlan> interfaces add <interfaces>

    For example:

    b vlan external interfaces add 3.1

    Note: If you want this trunk associated with more than one VLAN, you must use VLAN tagging. For more information on VLAN tagging, refer to the BIG-IP manual.
