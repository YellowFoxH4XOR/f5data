Topic

The BIG-IP compat SSL stack is not compatible with Transport Layer Security (TLS) False Start. When a peer attempts to establish a TLS handshake using False Start with a BIG-IP virtual server using the compat SSL stack, the connection stalls following the first packet containing application data.

TLS False Start is described in the draft-bmoeller-tls-falsestart-00 internet-draft, and is an optional TLS feature used by some web browsers to shorten the message flow during the TLS handshake.

Note: BIG-IP LTM platforms support native and compat SSL stacks. The native stack is the default SSL stack, and supports SSL ciphers that address most SSL connections. The compat stack is a variant of OpenSSL 0.9.7, and supports the ciphers that the native SSL stack supports, in addition to ciphers from the OpenSSL suite.

F5 Product Development is tracking a request for enhancement (RFE) as ID 349742 to allow the compat SSL stack to be compatible with TLS False Start.

Note: The BIG-IP native SSL stack is compatible with the TLS False Start feature. For more information, refer to K12675: The BIG-IP system is compatible with the TLS False Start feature.

Note: For information about using SSL ciphers with the BIG-IP system, refer to K8802: Using SSL ciphers with BIG-IP Client SSL and Server SSL profiles.
