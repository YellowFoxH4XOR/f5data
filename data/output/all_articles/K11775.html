Known Issue

This is the result of a known issue. When defining Terminal Server favorite aliases in an application webtop that contains multiple Terminal Server favorites, the terminal server session will get its configuration from the Terminal Server favorite that is in the same ordinal position in the referenced group.

For example:

group1 :
    TS1  Terminal Server favorite 1
    TS2  Terminal Server favorite 2

group2 :
    Alias TS2 points to group1 TS2
    Alias TS1 points to group1 TS1

When a user in group2 accesses the TS2 alias, the users terminal server session will take the configuration of group1 : TS1.

F5 Product Development is tracking this issue as ID 317789 (formerly CR142722) and as ID 327729 (formerly CR142722-1).

This issue was fixed in cumulative HF-70-1 issued for FirePass version 7.0.0 and in HF-610-4 for FirePass version 6.10.. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this by issue by ensuring your alias favorite is in the same order in the group as the reference favorite. Alternatively, you can avoid using aliases and define the Terminal Server favorite in each group.
