Description

Created a new VIP on LTM but DNS can't see it unless it's single port

Environment

  • LTM 
  • DNS
  • LTM VIP (Virtual Server)
  • Virtual Server discovery

Cause

LTM virtual servers that use a Port List are not able to be discovered by F5 DNS/GTM

Recommended Actions

When using a port list you can workaround the issue by performing the following: 

  1. Change Server Object to use "Enabled (No Delete)" for Virtual Server Discovery
  2. Manually add the DNS Virtual Server and apply a port in the "Port List" 
  3. Assign a desired monitor to virtual server
