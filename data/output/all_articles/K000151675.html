Description

  • What does priority routing entail in this context?

  • What is the function of the Priority Routing option under Load Balancing Control in the Advanced Options of an HTTP Load Balancer route?

Environment

  • F5® Distributed Cloud (XC) HTTP Load Balancer 
  • F5 Regional Edge

Answer/Recommended Actions

The Priority Routing setting controls whether requests for the selected route are handled using a high-priority connection pool to the origin server. This feature is designed to support critical services by giving them preferential routing, ensuring reliability even under high load conditions.

 

It functions similarly to F5 BIG-IP’s OneConnect, enabling the F5 XC proxy to maintain separate connection pools per origin:

  • One for default-priority traffic
  • One for high-priority traffic

Each pool has independent circuit breaker settings, including:

  • Maximum concurrent connections
  • Maximum retries
  • Request thresholds per connection

Cause

Priority routing ensures that critical services (e.g., payment APIs, checkout endpoints) are not impacted by spikes in lower-priority traffic.

If the default connection pool becomes saturated and triggers circuit breakers, the high-priority connection pool remains unaffected, allowing critical requests to bypass congestion and reach the origin successfully.

Additional Information

This can be achieved by:

  • Higher retry thresholds: More retry attempts before failing the request.
  • Increased connection limits: More concurrent connections allowed.
  • Relaxed circuit breaker policies: Fewer restrictions on marking backend servers as unhealthy.
