Description

Cannot create UCS backup due to "errno 5] Input/output error", the logs below can be observed:

/var/log/ltm:

err tmsh[22810]: 01420006:3: Can't create temp directory, /var/tmp/.config.tmp/QQ17U1, errno 5] Input/output error
err tmsh[22806]: 01420006:3: UCS saving process failed.

/var/log/kernel:

crit kernel: : [28426897.293350] EXT3-fs error (device dm-1): ext3_add_entry: bad entry in directory #8144: rec_len is smaller than minimal - offset=0, inode=0, rec_len=0, name_len=0
crit kernel: : [28426905.545490] EXT3-fs error (device dm-1): ext3_add_entry: bad entry in directory #8144: rec_len is smaller than minimal - offset=0, inode=0, rec_len=0, name_len=0
crit kernel: : [28426962.697163] EXT3-fs error (device dm-1): ext3_add_entry: bad entry in directory #8144: rec_len is smaller than minimal - offset=0, inode=0, rec_len=0, name_len=0

Environment

  • Creating a UCS file
  • Input/output error

Cause

This error is caused by a file that has been marked as a directory. This is a non-fatal error and can be fixed by removing the file in question.

Recommended Actions

Locate the file that has been corrupted in the affected system. The file's inode is the number after "bad entry in directory". Using the example error code, the file would be found by doing the following:

  1. Enter bash, run the command:
    find / -inum 8144

  2. Delete the identified file.

  3. Try creating a UCS file.

  4. If it's still failing, apply the procedures in article K73827442 and it should fix the problem.
