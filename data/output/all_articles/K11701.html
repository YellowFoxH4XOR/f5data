Known Issue

This is the result of a known issue. When using RADIUS accounting, stop messages are sent to a different default UDP port than start messages. If you do not specify the port when configuring RADIUS on FirePass, FirePass will default to RADIUS UDP port 1645 for authentication and 1646 for accounting. If your RADIUS server is configured to listen on ports 1645/1646, you will receive authentication requests and accounting start messages; however, you will not receive the accounting stop message when the user logs out, because FirePass sends the accounting stop messages to port 1813.

Note: For more information about the RADIUS ports used in FirePass, refer to K11700: Ports used by FirePass for RADIUS.

F5 Product Development is tracking this issue as ID 327712 (formerly CR141876).

This issue has been fixed in cumulative HF-70-1 issued for FirePass version 7.0.0. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

You can work around this issue by specifying the UDP port for RADIUS accounting. To do so, perform the following procedure:

  1. Log on to the FirePass Administrative Console.
  2. Click Device Management.
  3. Click Maintenance.
  4. Click Accounting.
  5. Type the port number you want to utilize for RADIUS accounting in the Port: text field.

    Note: Typically, the RADIUS accounting port is 1646 or 1813. Check your RADIUS server configuration to determine the correct port to use.

  6. Click the Save Settings button.
