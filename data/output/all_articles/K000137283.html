K000137283: L2 services LACP LLDP does not work

Type
Support Solution
Published
2023-10-18
Updated
2026-08-27

Source
https://my.f5.com/manage/s/article/K000137283

Description

No information about LLDP neighbor is available on the rSeries device, this condition might affect LACP operation as well.

Environment

  • rSeries
  • F5OS Velos

Cause

  • Bug ID 1352421

This is caused by an internal connection break between nic-manager and L2-services containers.

Recommended Actions

  • Suggested to verify internal connections status ( more information under Additional Information) - There should be 2 subscriber connections and 2 sender connections.
  •  In case needed - Workaround will be to reboot the unit

 

Additional Information
