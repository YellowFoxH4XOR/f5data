Description

When working on the OWASP compliance dashboard on the BIG-IP, under the Security > Policies list. You might not have the opportunity to "Ignore" or allow all the mitigation methods (e.g. Disallowed URLs).

It does not matter if you have 0 or more disallowed URLs.

Environment

ASM

Cause

This is as per design, not all mitigation will have an Ignore or Allow option.

Answer/Recommended Actions

Even if the option is not there, you are still able to achieve 100% compliance.
