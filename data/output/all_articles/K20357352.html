K20357352: Overview of BIG-IQ usage data collection

Topic

Starting in 8.0.0, BIG-IQ collects and uploads usage data to F5, to help improve the BIG-IQ product and features.

Description

BIG-IQ usage data collection and reporting occurs once per day, at the same time. The time is picked at random the first time the task runs. If you disable and then re-enable usage data collection, the time of the collection is picked at the time it is re-enabled. The usage data collection stores the last 30 reports in the database. The total amount of storage consumed by the 30 usage data reports is negligible compared to the rest of the data in the database. Additionally, usage data collection and uploading uses a minimum amount of resources and should not have an impact on BIG-IQ system performance.

You can obtain a copy of the usage data reports on the BIG-IQ system by logging in to the BIG-IQ user interface and navigating to the System > USAGE DATA page. When a usage data report is complete, the BIG-IQ user interface reports its status as Finished, together with the date and time it was completed and uploaded to F5. You can also access a link to download the usage data report as a JSON file. If the BIG-IQ user interface reports the status as Failed and no download link is available, the system may have failed to successfully upload the data to F5. There is no impact to the BIG-IQ system and no intervention or recovery action is needed.

BIG-IQ usage data collection is enabled by default. You can disable it by logging in to the BIG-IQ user interface, navigating to the System > USAGE DATA page, and clearing the I agree to F5’s collection and use of Usage Data check box. This action stops the feature from collecting usage data and uploading it to F5. To re-enable it, select I agree to F5’s collection and use of Usage Data. This action automatically resumes collecting and uploading usage data; no other action is needed.

Note: There is no TMOS Shell (tmsh) equivalent for disabling and re-enabling usage data collection. The BIG-IQ user interface is the only available method.

Recommendations

F5 recommends that you keep the BIG-IQ usage data collection enabled to help F5 improve the product.
