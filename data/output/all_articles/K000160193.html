K000160193: TMM failure followed by a loss of pool members - PLLNPLACC101-PRI

Type
Support Solution
Published
2026-04-02
Updated
2026-04-02
Applies to
  • BIG-IP
  • BIG-IP LTM: 17.1.3
Source
https://my.f5.com/manage/s/article/K000160193

Description

The standby BIG-IP LTM device experienced repeated TMM (Traffic Management Microkernel) crashes, resulting in loss of pool members and service disruption.  You can see similar errors 

Feb 17 10:28:41 example.com notice sod[4528]: 01140045:5: HA reports tmm NOT ready.
Feb 17 10:28:41 example.com notice sod[4528]: 010c0050:5: Sod requests links down.
Feb 17 10:28:40 example.com crit tmm1[18864]: 01230111:2: Interface 0.8: HSB DMA lockup on receive failure.
Feb 17 10:28:40 example.com tmm1[18864]: 01010025:2: Device error: hsb hsb interface 3 DMA lockup on receive failure 

As well /var/core directory contains the core files from the TMM 

Environment

  • vCMP guest and host configuration
  • HSB bitfile version 5.9.10 

Cause

Unknown on time of publication

Recommended Actions

  1. Upgrade the BIG-IP LTM system to version 17.5.1.3 or later, ensuring HSB bitfile 5.9.14 is installed.
  2. Monitor the system post-upgrade to confirm stability and absence of TMM crashes.

Additional Information

None
