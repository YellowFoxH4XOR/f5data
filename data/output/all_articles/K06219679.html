K06219679: BIG-IQ: Automatic Update Check and Automatic Phone Home Settings

2020-05-11
Updated

Applies to

Source

Description

  • The option to modify the Automatic Update Check and Automatic Phone Home settings is available within the BIG-IQ CLI
  • If you are seeing failures with the Update Checks, you can disable the feature.
  • The below is an example of a failed daily Update Check on a BIG-IQ Collection Manager (CM).
  • BIG-IQ CLI: 
tmsh show sys software
----------------------------
Sys::Software Update Check
----------------------------
  Check Enabled         true
  Phonehome Enabled     true
  Frequency            daily
  Status             failure
  Errors                  98

Environment

  • BIG-IQ Collection Manager (CM)

Cause

N/A

Recommended Actions
 

These setting are enabled by default, and the frequency is weekly.
To modify the settings for the Phone Home and Update Checks, follow the below steps.
Note: All these settings have to be made through the BIG-IQ CLI:
  1. To modify the schedule of the Phone Home and Update checks:
    • tmsh
    • modify /sys software update frequency [daily | weekly | monthly]
      • ex: modify /sys software update frequency monthly
    • save /sys config 
    • bash
      • this exits you out of the tmsh shell
         
  2. To enable / disable the Automatic Update Check feature:
    • tmsh
    • modify /sys software update auto-check [disabled | enabled]
      • ex: modify /sys software update auto-check disabled
    • save /sys config
    • bash
      • this exits you out of the tmsh shell
         
  3. To enable / disable the Automatic Phone Home feature:
    • tmsh
    • modify /sys software update auto-phonehome [disabled | enabled]
      • ex: modify /sys software update auto-phonehome disabled
    • save /sys config
    • bash
      • this exits you out of the tmsh shell
