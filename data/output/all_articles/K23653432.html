Topic

F5 Remote Access clients feature matrix

Description

F5 has several client software packages that facilitate secure remote connectivity for different device platforms. Because of differences in platforms, the capabilities of each client are also different. The following tables provide an overview of available features to help you plan your deployment.

  • BIG-IP Edge Client component update behavior
  • Desktop features matrix
    • Client features
    • Network access resource settings and features
    • Application tunnel settings and features
  • Mobile features matrix
    • Mobile clients: Per-app VPN settings and features
    • Mobile clients: On-demand VPN settings and features
    • Mobile clients: Full device manual VPN settings and features

Note: F5 VPN refers to the browser Helper Applications available in BIG-IP 13.x and later.
