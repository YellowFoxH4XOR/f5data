Description

  • Blades on a Viprion chassis failing to forward some traffic
  • Error message(s) logged in /var/log/ltm, ex.:

        info bcm56xxd[PID]: 012c0012:6: L2 mitigation: hits 416 -> 417

Environment

  • Viprion with B4450 blades

Cause

L2 forwarding database entry corruption. The L2 module runs in poll mode by default, which is exposed to a 3-second race window in software, during which learning events in the switch hardware for a given L2 FDB entry can be lost. That can lead to corrupted L2 FDB entries and cause traffic hitting the corrupted L2 FDB entries to fail. This most often occurs when the system is under high load.

 Recommended Actions

Modify system DB key switchboard.l2.mitigation to allow forwarding of packets even if FDB entry is corrupted.

 

  1. Log in to tmsh by typing the following command:
    tmsh
  2. List the switchboard.l2.mitigation database key value
    list /sys db switchboard.l2.mitigation 
  3. Enable the system DB key switchboard.l2.mitigation to allow
    modify sys db switchboard.l2.mitigation value enable
  4. Save config changes
    save sys config

Additional Information

The system DB key switchboard.l2.mitigation was introduced as the fix for bug ID655357, but it is set to disable as the default value.
