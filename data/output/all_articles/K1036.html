K1036: Restricting access NameSurfer by IP address

Type
Knowledge
Published
2006-02-17
Updated
2023-02-21
Status
Legacy Content
Applies to
  • Legacy Products
  • 3-DNS: 4.6.4
Source
https://my.f5.com/manage/s/article/K1036

Topic

The 3-DNS Controller proxies all connections to NameSurfer, so that it appears as if connections are coming from the 3-DNS Controller itself, and not the actual user; therefore, restricting by IP address has no effect on accessing NameSurfer.

The 3-DNS Controller does not support restricting IP addresses through NameSurfer.
