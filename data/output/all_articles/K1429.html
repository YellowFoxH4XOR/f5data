Topic

Wrap_pinger is a script that looks for and removes previous instances of health monitors. BIG-IP uses wrap_pinger to check for other running copies and write a process ID file when executing health monitors. You do not need to configure BIG-IP to use wrap_pinger; it is executed automatically when BIG-IP runs health checks.

Note: Refer to the BIG-IP manual for general information about configuring external health monitors (EAVs).

When the wrap_pinger executes its first argument, it immediately creates a /var/run/pinger.$2.$3.pgid PID file. It then passes all arguments to the program it is executing. Argument $2 is the second argument passed to wrap_pinger, and argument $3 is the third argument (which are, as with all external health monitors, the first and second arguments of the program you are executing: the IP and PORT).

If the /var/run/pinger.$2.$3.pgid PID file already exists when wrap_pinger runs, the wrap_pinger deletes that PID file, and replaces it with its own PID.

This behavior of a wrap_pinger is very similar to the shell script, example_pinger. To find out more about the example_pinger and the PID file management used in external health monitors (EAVs), refer to the /usr/local/lib/pingers/example_pinger file.
