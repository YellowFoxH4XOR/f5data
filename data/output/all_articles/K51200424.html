Known Issue

Internet Explorer allows users to specify an invalid IPsec option for IKE Peers.

This issue occurs when the following condition is met:

  • NONE is selected for the Perfect Forward Secrecy setting.

When using Internet Explorer to configure an IKE peer, an invalid value of NONE is presented as an option for the Perfect Forward Secrecy setting.

Impact

Connectivity through an affected IPsec tunnel fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • BIG-IP iHealth lists Heuristic H618181 on the Diagnostics > Identified > High screen.
  • The racoon process fails to start.
  • Connectivity through the IPsec tunnel fails.
  • In the /var/log/racoon.log file, you observe error messages similar to the following example:

    INFO: Reading configuration from "/etc/racoon/racoon.conf"
    ERROR: /etc/racoon/racoon.conf.bigip:59: "}" DH group required.
    ERROR: fatal parse failure (1 errors)
    ERROR: failed to parse configuration file.

Workaround

To work around this issue, you can either use a browser other than Internet Explorer, or avoid selecting NONE for the Perfect Forward Secrecy setting.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
