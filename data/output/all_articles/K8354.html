Known Issue

This is the result of a known issue. When a request is blocked by the policy, the default XML SOAP response page that is reported to the client is not rendered correctly and does not contain a support ID.

F5 Product Development tracked this issue as CR88146 and it was fixed in BIG-IP ASM 9.4.4. For information about upgrading, refer to the BIG-IP ASM Release Notes.

Additionally, this issue was fixed in hotfix BIGIP-9.4.3-14.3-HF3 issued for BIG-IP 9.4.3. You may download this hotfix or a later version of this hotfix from the F5 Downloads site.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about managing F5 product hotfixes, refer to K6845: Managing F5 product hotfixes.
