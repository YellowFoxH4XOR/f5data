Security Advisory Description

Malformed HTTP/2 requests may cause an infinite loop which causes a Denial of Service for Data Plane traffic. TMM takes the configured HA action when the TMM process is aborted. There is no control plane exposure, this is a data plane issue only.(CVE-2021-23009)

Impact

When this vulnerability is exploited, the system may experience a denial-of-service (DoS) attack, which can cause the TMM process to restart.
