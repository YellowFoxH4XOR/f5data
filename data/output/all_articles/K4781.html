K4781: BIG-IP LTM may respond to 3-DNS discovery and automatic configuration with an IP address of zero

Known Issue

This is the result of a known issue. BIG-IP's big3dshim process occasionally responds with a value of 0 rather than an IP address when returning configuration elements. This can cause 3-DNS to crash.

F5 Product Development tracked this issue as CR47748. This issue was fixed in BIG-IP 9.1. To resolve this issue, upgrade to BIG-IP 9.1 or later. For information about upgrading, refer to the BIG-IP LTM Release Notes.
