Description

The different hardware components such as LOP in the VELOS system controller and blade have their individual firmware. You can use either the CLI or the REST API interface to find the firmware version of these hardware components in the system controller. For the blade, you can only use the CLI to find the firmware version of these hardware components.

  • Display the firmware versions of a system controller from the CLI
  • Display the firmware versions of a system controller using a REST API command
  • Display the firmware versions of a blade from the CLI
  • Display the firmware versions of a blade using a REST API command

Display the firmware versions of a system controller from the CLI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of the VELOS chassis as the chassis administrator.
  2. To display the firmware versions, enter the following command syntax:

    show components component <controller-1 | controller-2> properties

    For example, you would enter the following command to display the firmware versions on controller-1:

    show components component controller-1 properties

Display the firmware versions of a system controller using a REST API command

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of the VELOS chassis as the root user.

    Alternatively, you can log in to the system you want that has the curl and jq utilities installed.

  2. To obtain the firmware versions, enter the following REST API command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<ip address>:8888/restconf/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | select(.name == "<controller number>") | .properties.property'

    Note: Replace <username> and <password> with the administrative username and password to access the VELOS chassis, and replace <ip address> with either localhost if you are running the command from the chassis CLI or the floating management IP address of the VELOS chassis if you are running on your external system.

    For example, you would enter the following REST API command if you were running the command from the VELOS chassis CLI using the admin user to query for the firmware on controller-1:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://localhost:8888/restconf/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | select(.name == "controller-1") | .properties.property'

Display the firmware versions of a blade from the CLI

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of the partition as the partition administrator.
  2. To display the firmware versions, enter the following command:

    show components component properties

    The command returns output similar to the following example:

Display the firmware versions of a blade using a REST API command

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the CLI of the VELOS chassis as the root user.

    Alternatively, you can log in to the system you want that has the curl and jq utilities installed.

  2. To obtain the firmware versions, enter the following REST API command syntax:

    curl -X GET -H "Content-Type: application/yang-data+json" -sku <username>:<password> "https://<partition ip address>:8888/restconf/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | select(.name == "<blade number>") | .properties.property'

    Note: Replace <username> and <password> with the administrative username and password to access the VELOS partition, and replace <partition ip address> with the management IP address of the VELOS partition as well as replace <blade number> with the blade(s) assigned to the partition.

    For example, you would enter the following REST API command if you were running the command from the VELOS chassis CLI using the admin user of partition 1 with the partition IP address of 192.168.81.107 attempting to find the firmware on blade-1 (which is assigned to partition 1):

    curl -X GET -H "Content-Type: application/yang-data+json" -sku admin:admin "https://192.168.81.107:8888/restconf/data/openconfig-platform:components" | /usr/bin/jq '.[][][] | select(.name == "blade-1") | .properties.property'
