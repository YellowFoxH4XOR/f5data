Description

You may find the following logs when running lspci -vv . In addition, you may also see the log message when generating a qkview file since BIG-IP will call lspci -vv during the data collection. The log content "0000:0f:00.0" can be different on various different platforms.

linux-kernel-bde 0000:0f:00.0: vpd r/w failed.  This is likely a firmware bug on this device.  Contact the card vendor for a firmware update.

Environment

  • Qkview
  • lspci

Cause

Bug ID 437586

Recommended Actions

You may safely ignore this message and there is no further action required on the appliance. This is an cosmetic issue in the firmware on the device.
