Description

  • An Internet Routing Registry (IRR) is a database of Internet routing objects, such as route, route6, aut-num, and AS-SET objects. This article explains what an AS-SET is and how it is used.

Environment

  • F5 Distributed Cloud
  • Routed DDoS

Answer/Recommended Actions

An AS-SET is a named collection of Autonomous System Numbers (ASNs). It is commonly used to group ASNs for routing policy and prefix-filter generation.

  • It is a Routing Policy Specification Language (RPSL) attribute that starts with "AS-", for example, AS-DEFENSE.
  • It can contain individual ASNs and/or other AS-SETs as members.
  • It is managed by a maintainer object, for example, MAINT-AS55002.
  • It should be maintained in the appropriate Internet Routing Registry (IRR), such as the IRR of record or the relevant Regional Internet Registry (RIR) that assigned or allocated your IPv4/IPv6 address space.

Example

In this example, AS-DEFENSE is an AS-SET that includes the ASN AS55002 and another AS-SET, AS-OPENDNS.

$ whois -h whois.radb.net -- '-L -T as-set AS-DEFENSE'
as-set: AS-DEFENSE (AS-SET)
descr: defense.net
members: AS55002 (Origin AS)
members: AS-OPENDNS (AS-SET)
