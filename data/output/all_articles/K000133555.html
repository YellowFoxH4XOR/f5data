Description

Customer had configured Duo MFA per https://duo.com/docs/f5bigip-web and gets JavaScript pop up with the following error, when they connect using the BIG-IP Edge client

An error has occurred in the script in this page
Line: 2
Char: 32191
Error: Object doesn't support property or method 'addEventListener'
Code: 0
URL : https://api-######.duosecurit.com/fram/static/shared/lib/jquery/jquery.min.js?v#####

 

Environment

  • BIG-IP APM
  • BIG-IP Edge client v7230 or older
  • Duo MFA configured for OIDC

 

Cause

  • Bug ID 1107385: Edge Client fails to render external logon page
  • Bug ID 1047501: [APM][Edge Client] Embedded browser throws JavaScript errors when connecting to logon page or external IdP

 

Recommended Actions

  • Upgrade the BIG-IP Edge Client to at least version 7.2.3.1 or later
