Known Issue

The BIG-IP ASM system may fail to load the configuration when all of the following conditions are met:

  • You saved a custom filter in the ASM Application Request log.
  • The custom filter is not applicable to the ASM Application Charts data.

Impact

The BIG-IP ASM system subsequently fails to load the configuration.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • The BIG-IP ASM system is unable to load the configuration when you attempt to load a configuration using either the tmsh load sys config command or after an upgrade.
  • The ASM Application Charts page fails to load the charts, and reports the following error message when you attempt to use the custom filter that was previously saved in the ASM Application Request page:

    There is no data to display either due to the lack of relevant traffic, or due to the settings of the filter.

    Additionally, the custom filter string displayed on the ASM Application Charts page contains the following:

    Violation: ?

Workaround

There is no workaround for this issue. However you can recover from this issue by manually editing the /config/bigip.conf file and removing the offending custom filter value. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line of the affected BIG-IP ASM system.
  2. Make a backup copy of the /config/bigip.conf file by typing the following command:

    cp -p /config/bigip.conf /var/tmp/bigip.conf.sol16325

  3. Edit the /config/bigip.conf file using a text editor of your choice, for example, vi.
  4. Locate and remove the following configuration snippet in the BIG-IP Analytics predefined-report configuration stanza created by the custom filter:

    values { \? }

  5. Save the changes and exit the text editor.
  6. Proceed to reload the configuration using the following command:

    tmsh load sys config
