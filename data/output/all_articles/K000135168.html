Description

The Auto Threshold for the DOS profile always shows 'Partial Ready' after enabling 'automatic threshold' for dos profile.

You can check this status under Security  >  DoS Protection : Protection Profiles

 

 

 

 

Environment

BIG-IP AWAF 
DOS profile Auto threshold

Cause

Only stress based auto threshold is enabled or only TPS based auto threshold is enabled on DOS profile.

Recommended Actions

This is how auto threshold status is determined on BIG-IP AWAF

1. It's fully ready mode when both stress based and TPS based auto threshold mode is enabled in DOS profile
2. It's partial ready mode when either stress based or TPS based auto threshold mode is enabled in DOS profile
3. It's disabled mode when both stress based and TPS based auto threshold mode is disabled
