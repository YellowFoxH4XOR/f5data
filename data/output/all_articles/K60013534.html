K60013534: The ILX module is not accessible via the GUI, and the workspace with the symlink cannot be run.

Source

Description

ILX error after adding extension module on BIG-IP LTM 15.1.2

"General database error retrieving information. General error: 01070711:3: boost::filesystem::status: Permission denied: "/var/ilx/workspaces/<Workspace_Name>/extensions/<Extension_Name>/node_modules/.bin/<Module>"

Environment

  • An ILX workspace is in the configuration
  • The workspace contains a symlink
  • After installing the relevant npm package with --no-bin-links 
    • (e.g., npm install <package-name> --no-bin-links)

Cause

This issue is related to BugID 764969.

Recommended Actions

  1. Remove the installed package: 
     npm uninstall tedious
  2. Remove the symbolic link as prompted by in the GUI: 
    • cd /var/ilx/workspaces/Common/<Workspace_Name>/extensions/<Extension_Name>/node_modules/.bin/<Module>
ls -la node_modules/.bin/
rm -f node_modules/.bin/detect-libc
rm -f node_modules/.bin/rc
  3. Find other .bin directories in the extension and remove any symbolic links present: 
    • cd /var/ilx/workspaces/Common/<Workspace_Name>/extensions/<Extension_Name>/node_modules/.bin/<Module>
find . -name .bin
  4. Check if the workspace GUI is accessible again
  5. Install the tedious module without symlinks: 
    • npm install tedious --no-bin-links
