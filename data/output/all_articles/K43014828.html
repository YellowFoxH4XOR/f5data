Description

Daemon named seen in a restarting loop after the reboot

Mon DD HH:MM:01 bigip logger [#####]: Re-starting named
Mon DD HH:MM:02 slot1 logger [#####]: Re-starting named
Mon DD HH:MM:13 bigip logger [#####]: Re-starting named
Mon DD HH:MM:14 slotl logger [#####]: Re-starting named
 
The rest of the BIG-IP is working normally, the other daemons seen not affected

Environment

  • DNS doesn't have to be provisioned

Cause

The details of the immediate root cause can be located at /var/log/daemon.log e. g.:

Mon DD HH:MM:SS bigip err named[####]: /config/named.conf:40: change directory to '/config/namedb' failed: file not found
Mon DD HH:MM:SS bigip err named[####]: /config/named.conf:40: parsing failed: file not found
Mon DD HH:MM:SS bigip crit named[####]: loading configuration: file not found
Mon DD HH:MM:SS bigip crit named[####]: exiting (due to fatal error)

Recommended Actions

If DNS is configured, follow the recommendation in K05117215
If DNS is not configured, contact F5 Support for further assistance.
