K19506354: GUI access failing with error 'This site can't be reached'

Type
Support Solution
Published
2022-07-04
Updated
2023-05-22
Applies to
  • BIG-IP Platforms
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K19506354

Description
When accessing the BIG-IP GUI, the access is failing with below error in the browser:
'This site can't be reached'

Similar to below logs will be found under /var/log/httpd/httpd_errors:

[proxy_http:error] [pid 1463] (70007)The timeout specified has expired: [client 10.x.x.x:49470] AH01102: error reading status line from remote server localhost:8100, referer: http://localhost:8100/cm/system/backup-restore/a1713901-18de-4e55-bec7-efa0b58d3de8/worker
[proxy:error] [pid 1463] [client 10.x.x.x:49470] AH00898: Error reading from remote server returned by /mgmt/tm/shared/sys/backup/cd30715b-460a-47cf-bd68-bb99c9f7c864, referer: http://localhost:8100/cm/system/backup-restore/a1713901-18de-4e55-bec7-efa0b58d3de8/worker

Environment

  • GUI access fails in all browsers 
  • Tomcat and httpd services are running
  • No CPU or memory issues found 
     

Cause

Unknown 
 

Recommended Actions

  1.  In order to recover the GUI access, please restart httpd, tomcat, restjavad services using below commands: 
    Impact of workaround: Performing the following procedure should not have a negative impact on your system.
    bigstart restart httpd
    bigstart restart tomcat
    bigstart restart restjavad
     
  2. Wait for 10-15 seconds and access the GUI again in browser. 
     

Additional Information
