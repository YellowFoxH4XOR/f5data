K000160020: DNS Zone is incorrectly signed with DNSSEC keys

Type
Support Solution
Published
2026-02-16
Updated
2026-02-16
Applies to
  • BIG-IP
  • BIG-IP DNS: 17.5.1
  • BIG-IP LTM: 17.5.1
Source
https://my.f5.com/manage/s/article/K000160020

Description

DNS zones transferred from BIG-IP DNS Express with DNSSEC enabled were incorrectly signed, resulting in missing NSEC3 records and incomplete DNSSEC signatures for certain nameserver records. This caused DNSSEC validation failures, as confirmed by `dnssec-verify` reporting missing NSEC3 records and broken NSEC3 chains for nameserver entries used in multiple delegations within the same zone.

 

 

Environment

  • BIG-IP DNS
  • DNSSEC enabled for primary zones
  • Zone transfer feature used to sign and transfer zones
  • Delegated subdomains with nameservers located in the parent zone and used for multiple delegations

 

 

Cause

Bug ID 2186625

 

 

Answer/Recommended Actions

Upgrade to a fixed software version (or request EHF if not available)

 

 

Additional Information

Other zone transfer related issues:

 

Bug ID 2172041: Zone transfer fails for dnsx when the zone file contains TLSA records

Bug ID 2200217: DNSSEC validation failures due to missing DS records in zone transfers
