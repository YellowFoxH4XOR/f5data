Known Issue

The BIG-IP system sends the incorrect packet size to the clone pool member.

This issue occurs when the following condition is met:

  • You configure a clone pool with a virtual server.

Impact

The clone pool members may get traffic that exceeds the link maximum transmission unit (MTU).

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Cloned packets do not acknowledge the egress interface MTU, and clone pool members may get traffic that exceeds the link MTU.

Workaround

To work around this issue, you can disable TCP Segment Offload (TSO) from the TMOS Shell (tmsh) command line. To do so, perform the following procedure:

Impact of workaround: Performing the following procedure should not have a negative impact on your system.

  1. Log in to the command line.
  2. To disable TSO, type the following tmsh command:

    tmsh modify sys db tm.tcpsegmentationoffload value disable
