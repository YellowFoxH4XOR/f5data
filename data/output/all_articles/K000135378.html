Description

Modifying the interface mtu from the tmsh cli results in the following error message logged in /var/log/audit:

[Syntax Error: "mtu" is a read-only property] cmd_data=modify net interface 1.0 mtu

In addition, modifying the vlan mtu does not update the interface mtu

 

Environment

  • BIG-IP
  • Interface MTU
  • VLAN MTU

Cause

Interface mtu is read-only

This is the maximum supported MTU as detected at time of system boot

Recommended Actions

The tmsh show net interface all-properties command shows the maximum supported MTU that the interface can support and does not show the current MTU that TMM is utilizing.

The tmsh show /net vlan command will show what TMM is currently utilizing for the MTU size as configured within the vlan settings. This is the value to configure.

See K13339: Configuring the BIG-IP system to support jumbo Ethernet frames

The utilized MTU size will be shown in the "ifconfig" or "ip address" command output.

Additional Information

Use the following ping command on BIG-IP to test the MTU size

ping <HOST>-s 1600 -M do -c 1

where <HOST> is an IP address or FQDN

and 1600 is the packet size (change as needed)
