Description

A versioning discrepancy may be observed between NGINX Plus R37 software and its official documentation. The software displays the version as "nginx-plus-r37.0.2" (three numeric components), while the documentation or software package may reference to a four-component version (e.g., 37.0.2.1). This can lead to confusion about whether both refer to the same release and the meaning of the additional digit.

Environment

  • Product: NGINX Plus
  • Version: 37.0.0 and later
  • No specific hardware platform involved

Cause

The versioning discrepancy is intentional and by design. NGINX Plus software displays only the first three numeric components, which are relevant to developers and end users. The fourth component, present in documentation and distributed software packages, denotes packaging updates and is reserved for package maintainers. This is not a software bug but a documentation and packaging convention.

Answer/Recommended Actions

  • No technical changes are required.
  • Users should reference the first three numeric components for software versioning.
  • The fourth component in documentation and software packaging can be disregarded for operational and troubleshooting purposes, as it does not affect the software's code or functionality.

Additional Information

  • The second numeric component (.0) represents LTS (Long Term Support).
  • The second numeric component as .1 or higher (e.g., 37.1+) represents CR (Current Release).
  • The third numeric component (e.g., .2 in 37.0.2) represents security-related updates.
  • The fourth numeric component as seen in documentation and software packages (e.g., .1 in 37.0.2.1) represents the "packaging" version, which covers non-code distributable components such as installation scripts, service files, and documentation.
  • NGINX Plus software omits the fourth numeric component because it is only relevant to package creators.
