Description

  • You modified some options in one of BIG-IP's default profiles
  • You see an error message "A modified default profile has been detected" under "Diagnostic" section in QKview
  • You reverted back all non-default modifications to default ones using the configuration utility
  • Default values applied using configuration utility in the previous step are not reflected in bigip.conf (non-default values are still there)

Environment

  • BIG-IP
  • You have modified any of the default profiles

Cause

This is expected behaviour.
Once a default profile is changed, changes will stay in bigip.conf even if everything is changed back to match the default profile values.

 Recommended Actions

The fix is to edit bigip.conf and remove modified entry.
 

Log in into advanced shell (bash) and follow below steps:
 

1) Back-up your current configuration before you start to modify it:
 

cp /config/bigip.conf /config/bigip.conf.old
 

2) Edit your config with text editor like Vim:
 

vi /config/bigip.conf
 

3) Find and delete affected object. 
 

Example:

 

ltm profile http /Common/http {  <---Delete
...profile attributes...     <---Delete
}                 <---Delete

Note: In this example we are looking into http profile, but it can be also other one (like tcp, client-ssl etc.).

4) Save changes, exit editor
 

5) Verify if your config will load without any errors:
 

tmsh load /sys config verify
 

6) If no errors on config verify, proceed with config load:
 

tmsh load /sys config
 

Important: Loading the config is traffic impacting, so perform this while the system is standby and during a maintenance window. You may have to sync the changes across to the peer devices.

Additional Information

None.
