Issue

Error Message

notice mcpd[<PID>]: 01071539: 5: Mcpd is starting.  The BIG-IP version is <version>. 

In this error message, note the following:

  • <PID> is the process ID for the mcpd process.
  • <version> is the BIG-IP version the system is running.

For example:

notice mcpd[6362]: 01071539: 5: Mcpd is starting.  The BIG-IP version is 12.1.2.

Message Location

You may encounter this message in the following location:

  • The /var/log/ltm file
Description

This message occurs when one of the following conditions is met:

  • You reboot the BIG-IP system.
  • You restart the mcpd process.

Impact

None. This message is expected when the mcpd process starts and begins to initialize.

Recommended Actions

None
