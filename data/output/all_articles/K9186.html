Issue

On BIG-IP platforms containing Broadcom switch chips, the following error message may appear in the /var/log/bcm56xxd.log file:

[bcmARL.1]One or more ARL messages were dropped
[bcmARL.0]One or more ARL messages were dropped

This message is benign; it indicates that the Broadcom switch chip dropped a MAC address it learned before the address could be synchronized to TMM. The entries in the ARL table are used to populate the bigpipe vlan fdb show command output, and not utilized by TMM for any traffic passing functionality or load balancing decisions.
