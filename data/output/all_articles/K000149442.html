K000149442: Configure UDP Virtual Server with ClientSSL (DTLS) and VDI Profile

Type
Support Solution
Published
2025-01-29
Updated
2025-01-29
Applies to
  • BIG-IP
  • BIG-IP APM: 17.1.1
Source
https://my.f5.com/manage/s/article/K000149442

Description

You would like to know if there is a way to configure a UDP Virtual Server with the Client SSL profile (DTLS) and VDI profile together.

Environment

  • BIG-IP
  • Client SSL Profile
  • VDI Profile

Cause

None

Recommended Actions

There is no way to configure the client SSL profile with the VDI profile at the same time. As well it's will throw following error during create of the Virtual Server with SSL profile and VDI Profile:

01070734:3 Configuration error: UDP virtual server (/Common/Test_VIP) cannot have a vdi and clientssl profiles at the same time

Additional Information

None
