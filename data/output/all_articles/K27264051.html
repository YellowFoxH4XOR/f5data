K27264051: ''session-limit -1'' is added automatically after upgrade

Type
Support Solution
Published
2021-06-25
Updated
2025-02-06
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K27264051

Description

After upgrading, you may find "session-limit -1" is added for each user in /config/bigip_user.conf

For example;

auth user admin {
    description "Admin User"
    partition-access {
        all-partitions {
            role admin
        }
    }
    session-limit -1    <-----!!!
    shell tmsh
}

Environment

  • BIG-IP
  • Upgrade to 15.1.1 and later versions, 14.1.4 and later versions, 13.1.4 and later versions
  • Check /config/bigip_user.conf

Cause

"session-limit" is implemented by ID719338.

Recommended Actions

Default value is -1, which means disabling the session limit.
 

Additional Information

None.
