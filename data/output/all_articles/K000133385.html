Description

When using BIG-IP as NTP server, you may get below error:

no server suitable for synchronization found

Environment

  • BIG-IP
  • NTP
  • CLI

Cause

If the external NTP server is not accessible, it's expected that the client may get the error message when requesting BIG-IP as NTP server.

 Recommended Actions

Ensure BIG-IP can access external NTP server.

Additional Information

None.
