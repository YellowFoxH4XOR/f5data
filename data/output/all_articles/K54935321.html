K54935321: Bot Protection is not performing DNS Reverse lookup on Google Adsbot

Type
Support Solution
Published
2021-06-08
Updated
2025-02-06
Applies to
  • BIG-IP
  • BIG-IP ASM
Source
https://my.f5.com/manage/s/article/K54935321

Description

Bot Protection is not performing DNS Reverse lookup on Google Adsbot.
 

Environment

  • DNS Servers configured
  • DNS Resolver configured
  • DNS Servers are reachable via TMM
  • Traffic is blocked


Cause

It is by design; Bot Protection does not perform DNS Reverse lookup for Untrusted bots.

Google AdsBot is considered a Crawler and all Crawlers are Untrusted bots.

Bot Protection only performs DNS Reverse lookup for Trusted bots.

Only Search Engines are included in the Trusted bots.


Recommended Actions


At the time of publishing this article, no method exists to modify Google AdsBot into a Trusted bot.
 

Additional Information

It is possible to create a custom Bot Signature and configure Mitigation Exception for desired mitigation action. 

Please refer to the manual "BIG-IP Application Security Manager: Attack and Bot Signatures" for the software version installed.
