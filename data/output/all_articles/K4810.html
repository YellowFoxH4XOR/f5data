Known Issue

This is the result of a known issue. When you install BIG-IP or 3-DNS, the installation process uses a limited Unix environment. This environment does not provide the date command. During the installation of the openssh_nx-3.7.1-BSD_OS package, the installation script attempts to determine the date so that it can be used to date-stamp backup files, which results in the following error message:

date not found

As there are no existing files to back up during installation, this is a harmless message.

F5 Networks Product Development tracked this problem as CR46405 and CR46407 and it was fixed in BIG-IP version 4.5.13 for the 4.5 software branch. For information about upgrading, refer to the BIG-IP or 3-DNS Release Notes.

This issue still exists in the 4.6 software branch.
