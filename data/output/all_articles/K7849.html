Known Issue

This is the result of a known issue. The BIG-IP WebAccelerator module may experience transaction loss and reduced performance when the disk's input and output activity is high.

F5 Product Development tracked this issue as CR78910 and it was fixed in BIG-IP version 9.4.2. For information about upgrading, refer to the BIG-IP WebAccelerator release notes.

Workaround

Reducing the number of new objects written to the BIG-IP WebAccelerator cache using the newObjectCacheRatio setting may help reduce the amount of disk input and output activity. For more information, refer to K9062: Overview of the newObjectCacheRatio setting.
