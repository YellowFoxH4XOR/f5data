Description

In certain scenarios, there can be a necessity for increasing Maximum Cookie Header Length limit to a value greater than 8192 bytes on BIG-IP ASM and Advanced WAF products.

Environment

  • ASM Security Policy

Cause

Some legitimate user requests come in with very large cookie sizes which are currently being blocked, so there can be a business need to increase the value of Maximum Cookie Header Length within the security policy to something greater than 8192 bytes.

Recommended Actions

Starting v14, the maximum value for Maximum Cookie Header Length is increased to 65536 bytes.

In order to make use of the new maximum value for Cookie Header Length, you will have to upgrade to v14 or above release.

Additional Information

For versions prior to v14, the maximum limit is set to 8192 bytes.
