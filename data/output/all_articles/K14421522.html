Description
How to edit the name of an existing VLAN

Environment

  • VLANS
  • Rename

Cause
None
 

Recommended Actions

It is by design the VLAN name cannot rename once it is created, all other parameters and options of the VLAN can be changed.
The name is used as a fixed reference point for the VLAN allowing it to be referenced, thus changing the name would lose the reference to this specific VLAN.
