K25649710: How to confirm health of Elasticsearch of BIG-IQ

Support Solution
Published
2022-04-13
Updated
2023-07-21
Applies to
  • BIG-IQ
Source

Description
Elastic search(ES) is a module that is used by BIG-IQ Central Management System(CM).
ES collects statistic data, event log and indices from the BIG-IP devices and manage those data with BIG-IQ Data Collection Device (DCD) cluster.
In case some problem happens between BIG-IQ CM and DCD or BIG-IP, it is recommend to check the health status of ES with the following methods.

Environment

  • BIG-IQ manages BIG-IP device(s) and collect statistic data to multiple BIG-IQ DCD to form ES cluster.
  • Unable to view specific part of BIG-IQ menu, which is related to the data from BIG-IP device(s) or BIG-IQ DCD

Cause
Health status of elastic search is not operating in normal condition. 

Recommended Actions

  1. To check ES cluster health, run the following command
    # curl -s -u admin:admin --insecure https://localhost:9200/_cluster/health?pretty 
    Check the entry of "status" to see the color:
    • Red indicates an investigation is required
    • Yellow indicates minor problem exist
    • Green indicates normal condition
  2. To check ES indices health, run the following command
    # curl -s -u admin:admin --insecure https://localhost:9200/_cat/indices?v 
    Check the left column to see the color:
    • Red indicates an investigation is required
    • Yellow indicates minor problem exist
    • Green indicates normal condition
  3. The same information can be seen in the following file in a qkview as well.
    # more /var/tmp/bigiqdiags/bigiq_diagnostics.txt
