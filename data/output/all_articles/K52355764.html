Topic

Beginning in BIG-IP 16.0.0, F5 introduces support for Datagram Transport Layer Security (DTLS) 1.2 as defined in RFC6347.

Note: This link takes you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge.

Description

Support for DTLSv1.0 defined in RFC4347 is added in BIG-IP 10.1.0. DTLS 1.0 is originally defined as a delta from TLSv1.1. There is no DTLS 1.1 because the version number is skipped in order to harmonize version numbers with TLS. In DTLSv1.2, the main changes are updates to match TLSv1.2: addition of Authenticated Encryption with Associated Data (AEAD) cipher suites and clarifications of record handling. Beginning in BIG-IP 16.0.0, both the Client SSL and Server SSL profiles support DTLSv1.2.

Configuring DTLSv1.2

In BIG-IP 16.0.0, DTLSv1.2 is disabled by default in the Client SSL and Server SSL profiles. To enable it, perform the following procedure:

  1. Log in to the Configuration utility.
  2. Go to Local Traffic > Profiles > SSL > Client or Server.
  3. Select the SSL profile name.
  4. For Configuration, select Advanced.
  5. Select the Options check box.
  6. By default, Enabled Options is set to No DTLSv1.2. Select No DTLSv1.2 and select Disable.
  7. Select Update.

Note: The No DTLSv1.0 option in the Options List lets you enable/disable DTLSv1.0 only and is also introduced in BIG-IP 16.0.

New ciphers are added in DTLSv1.2. To list the ciphers supported, enter the following commands:

  • clientssl-ciphers dtlsv1_2
  • serverssl-ciphers dtlsv1_2

To list the ciphers supported in DTLSv1.0, enter the following commands:

  • clientssl-ciphers dtlsv1
  • serverssl-ciphers dtlsv1

Recommendations

When troubleshooting DTLSv1.2, you should consider the following factors:

Using the command line or the Configuration utility, you can view DTLS 1.2 statistics associated with the virtual server.

Viewing DTLS 1.2 using the command line

  • Use the following command syntax:

    tmsh show ltm profile client-ssl <clientssl profile name>

    For example:

    tmsh show ltm profile client-ssl clientssl

Viewing DTLS 1.2 using the Configuration utility

  1. Go to Local Traffic > Virtual Server.
  2. Select the name of the virtual server.
  3. Select the Statistics tab.
  4. For Select Profile, select the SSL profile you want to use.

After you view DTLS, review the BIG-IP system logs in the /var/log/ltm and /var/log/tmm files for DTLS information and errors.
