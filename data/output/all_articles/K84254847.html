Description

  • Unable to see ASM reports for BIG-IP v13.x on BIG-IQ under Monitoring > Dashboards > Web Application
  • ASM reports for devices running software version v14.0 or above are displayed without problem

Environment

  • BIG-IQ CM
  • BIG-IP ASM running software version 13.x

Cause

Seen behavior is expected.

Recommended Actions

  • ASM reports for BIG-IPs version 14.0 and above are located on Monitoring > Dashboards > Web Application Security on BIG-IQ GUI
  • ASM reports for BIG-IPs version below 14.0 are located on Monitoring > REPORTS > Security > Web Application Security on BIG-IQ GUI

None
