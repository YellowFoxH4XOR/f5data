Known Issue

This is the result of a known issue. If a user logs on to the FirePass webtop using the following format for the FirePass username, where <DOMAIN> is the Windows domain name and <username> is the Windows username, the user cannot change the Windows password on the Tools: Account Details page.

For example:

<DOMAIN>\<username>

If the user attempts to change the password, FirePass reports the following error message:

Current password is not correct.

F5 Networks Product Development tracked this issue as CR111853 and it was fixed in FirePass version 7.0.0. For information about upgrading, refer to the FirePass Release Notes.

Additionally, this issue was fixed in cumulative hotfix HF-603-1, which has been issued for FirePass version 6.0.3. You may download this hotfix or later versions of the cumulative hotfix from the F5 Networks Downloads site.

To view a list of the latest available hotfixes, refer to K10322: FirePass hotfix matrix.

For instructions about obtaining a hotfix, refer to K167: Downloading software from F5 Networks.

For instructions about installing a hotfix, refer to K3430: Installing FirePass hotfixes.

Workaround

If the Require user logon in form DOMAIN\username check box is not selected in the master group configuration, users can work around this issue by entering <username> instead of <DOMAIN>\<username> as their username on the FirePass logon page.
