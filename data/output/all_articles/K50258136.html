Known Issue

A Traffic Management Microkernel (TMM) processing traffic through an IPsec IKEv2 tunnel may restart and produce a core file on a standby system following a failover.

This issue occurs when all of the following conditions are met:

  • High-availability BIG-IP systems are configured with IPsec tunnels that use the IKEv2 protocol.
  • While processing traffic through the tunnels, the high-availability systems experience multiple failovers. In most cases, this issue occurs on systems that have two to four failovers.

Impact

Following a failover, the high-availability system transitioning to standby may not be available while TMM restarts and generates a core file.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • Following a failover, the high-availability system transitioning to standby generates a TMM core file in the /shared/core directory.
