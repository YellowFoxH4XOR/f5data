Description

When running the command show sys mcp-state the Last Configuration Load Status output can show one of three outputs:

  • high-config-load-succeed
  • base-config-load-succeed
  • full-config-load-succeed

Environment

  • mcp-state

Cause

Information about the different possible's mcp-state.

Recommended Actions

The meaning of the above mentioned statuses is as follows:

  • full-config-load-succeed: Full configuration has loaded after UCS install, loading from SCF, software upgrade or system reboot.
  • high-config-load-succeed: Triggered by  command load sys config  on a system that was already loaded base config or full config.
  • base-config-load-succeed: bigip_base.conf has loaded after (load sys config base).

Additional Information

The MCPD state of 'Last Configuration Load Status' as 'config-load-in-progress' is cosmetic only.

To clear 'config-load-in-progress'  execute below command.

tmsh load sys config

Important : Reloading config may interrupt the traffic you may prefer to run during maintenance window.
