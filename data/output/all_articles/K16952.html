Known Issue

Description

The BIG-IP APM system may not use the correct landing URI.

This issue occurs when all of the following conditions are met:

  • A user's browser is configured to open multiple browser instances (home page tabs) that reference the same BIG-IP APM access profile.
  • You access the BIG-IP APM access policy from multiple tabs with different landing URIs before the session fully establishes.

The BIG-IP APM system incorrectly uses the landing URI from the first tab that started the access session, not the landing URI that continued and finished establishing the access session.

Impact

The BIG-IP APM system fails to redirect traffic to the correct landing URI leading to authentication and web application malfunction. 

Symptoms

As a result of this issue, you may encounter the following symptoms:

  • The user's traffic is not redirected to the expected location after session establishment.
  • A BIG-IP APM system configured as a SAML Service Provider (SP) is unable to establish a session with a SAML Identity Provider (IdP).
