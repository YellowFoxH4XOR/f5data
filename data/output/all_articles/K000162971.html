Description

This article explains the urlfilte.log field schema.

Environment

  • APM

  • urlfilter

Cause

None

Answer/Recommended Actions

urlfilter.log filed schema:
Syslog prefix (standard): <date> <hostname> <severity> tmm[pid]: <errdefs_msgno>

then comma-separated values:

#    Field    Description
1    partition_name    Partition (e.g. Common)
2    context_name    Virtual server / context name
3    profile_access    APM access profile name
4    session_id    APM session ID (hex)
5    source_ip    Client IP address
6    username    Authenticated username (or (anonymous))
7    destination_url    Requested URL
8    url_category    Matched URL category
9    url_filter    URL filter object applied
10    swg_scheme    SWG scheme (often empty)
11    application_id    App ID (0 = unknown)
12    application_name    App name (*application_id = unknown)
13    application_family_id    App family ID
14    application_family_name    App family name (*family_id = unknown)
15    action    Allowed or Blocked
16    ssl_bypass_flag    SSL bypass: 1=bypass, 0=
17    hostname     bigip_hostname

Example:

[root@bigip.local::Active:Standalone] config # less /var/log/urlfilter.log
Mar 10 15:25:05 bigip.local info tmm[21979]: 24641538 Common,/Common/proxy_ingress_vs_any_tcp,/Common/access_explicit,6aedf69e,10.1.20.111,(anonymous),https://example.com/,/Common/Information_Technology,,,0,*application_id,0,*family_id,Allowed,0,bigip.local
