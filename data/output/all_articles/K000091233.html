K000091233: [Nginx Controller] Applying map directive on HTTP snippet return an error

Type
Support Solution
Published
2022-01-21
Updated
2022-01-21
Source
https://my.f5.com/manage/s/article/K000091233

Description

Applying map directive on HTTP snippet returns the following error on Service-Gateways:


example error:

Error:

{"key": "instance:instance01:unspecified::", "type": "failed", "Message": "Failed testing config before applying: nginx: [emerg] invalid number of the map parameters in /etc/nginx/nginx.conf:114\nnginx: configuration file /etc/nginx/nginx.conf test failed\n", "contributions": ["cert:cert-hyahn01::env01:", "cert:cert-hyahn01::prod:", "comp:com01::env01:app01", "comp:test01::prod:app01", "gateway:gw01::prod:", "gateway:ha-gw::env01:"]}

{"key": "instance:instance02:unspecified::", "type": "failed", "Message": "Failed testing config before applying: nginx: [emerg] invalid number of the map parameters in /etc/nginx/nginx.conf:110\nnginx: configuration file /etc/nginx/nginx.conf test failed\n", "contributions": ["cert:cert-hyahn01::env01:", "comp:com01::env01:app01", "gateway:ha-gw::env01:"]}


 Environment

Nginx-Controller version 3.21 or later

 Cause

while applying map directive with wrong sytax cause this issue

Example snippet:

map "$http_upgrade" "$connection_upgrade" {

  default upgrade;

  '' close;

}


The above single quote will be removed when it delivers to Nginx-Plus(Instance) which causes the syntax error.


 Recommended Actions

The single quotes within the curly brace should be covered by double quotes like below:


map "$http_upgrade" "$connection_upgrade" {

  default upgrade;

  "''" close;

}
