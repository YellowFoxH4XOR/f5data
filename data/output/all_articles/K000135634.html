K000135634: How to migrate config with private keys stored on FIPS card from NGFIPS to N3FIPS

Type
Support Solution
Published
2023-12-13
Updated
2025-04-02
Applies to
  • BIG-IP
Source
https://my.f5.com/manage/s/article/K000135634

Description

fipskey_migration tool allows to export private keys stored on internal FIPS card (NGFIPS) and import on another device with N3FIPS card.

Environment

  • BIG-IP with an internal FIPS card

Cause

Config migration between platforms with different type of FIPS cards.

Recommended Actions

On the source device with NGFIPS card:

  1. Create UCS, for example tmsh save sys ucs export1.ucs
  2. Create a folder for the exported keys, for example: mkdir /var/tmp/fips-key-backup/
  3. Note the existing Secure Vault master key (f5mku -K or tmsh modify sys crypto master-key prompt-for-password)
  4. Export the existing FIPS keys: fipskey_migration -export-all /var/tmp/fips-key-backup/. You will be prompted to enter the existing FIPS card Security Officer password and configure a new strong password for the exported keys
  5. Copy UCS and the folder with the exported FIPS keys to the target BIG-IP.

On the destination device with N3FIPS card:

  1. Initialise FIPS card and make sure it does not contain any existing keys
  2. Set the correct Secure Vault master key (f5mku -r KEY or tmsh modify sys crypto master-key prompt-for-password)
  3. Restore UCS - tmsh load sys ucs export1.ucs no-license platform-migrate. The command will fail with "unable to synchronize FIPS key" error message. We will correct it next two steps
  4. Load the exported FIPS keys: ./fipskey_migration -import-all /var/tmp/fips-key-backup/
  5. Load the config again with tmsh load sys config. You may need to correct VLAN definitions to point to existing interfaces and make other modifications due to platform-migrate. Otherwise the config should load fine.
