Known Issue

This is the result of a known issue. Host virtual servers in a datacenter with no BIG-IP GTM systems may not be probed by remote BIG-IP GTM systems. For example, if two BIG-IP GTM systems are configured in datacenter A and no BIG-IP GTM systems are configured in datacenter B, it is possible for each BIG-IP GTM in datacenter A to believe the other BIG-IP GTM system is probing host virtual servers in datacenter B. As a result, the BIG-IP GTM systems will mark host virtual servers as DOWN.

When this occurs, both BIG-IP GTM systems may repeatedly report that the virtual server object will be probed by the other BIG-IP GTM system. The BIG-IP GTM systems will log the following entries to the /var/log/gtm log file:

// From gtm_1 in Datacenter_Agtm_1 gtmd[6699]: Will not probe <host_vs> in DC B because will be done by other GTM// From gtm_2 in Datacenter_Agtm_2 gtmd[1423]: Will not probe <host_vs> in DC B because will be done by other GTM

F5 Product Development tracked this issue as CR72820 and it was fixed in BIG-IP GTM 9.3.0 and 9.4.0. For information about upgrading, refer to the BIG-IP GTM release notes.
