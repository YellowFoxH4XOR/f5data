Known Issue

The BIG-IP system fails to establish adjacencies with Open Shortest Path First (OSPF) version 2 neighbors.

This issue occurs when the following condition is met:

  • You attempt to configure or load OSPFv2 configurations using message digest authentication for a specific interface IP address.

    For example:

    ip ospf 1.1.1.1 message-digest-key 1 md5 mypassword

Note: This issue is triggers only when specifying an optional IP address as part of the command. When you omit the IP address, the configuration loads correctly.

Impact

The OSPF configuration cannot load, which prevents the BIG-IP system from establishing adjacencies with OSPFv2 neighbors.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When viewing the tmsh show /net route command output on the BIG-IP system, you do not observe any dynamic routes.

Workaround

To work around this issue, if you have a single IP address for your interface, you can remove the optional interface IP address argument from the message digest authentication command. To do so, perform the following procedure:

Removing the IP address argument from an existing configuration

Impact of workaround: Performing the following procedure will temporarily disrupt dynamic routing.

  1. Log in to the command line of the affected BIG-IP system.
  2. Create a backup copy of the advanced routing configuration file using the following command syntax:

    cp /config/zebos/<route domain>/ZebOS.conf /config/zebos/<route domain>ZebOS.conf.K21090061

    For example, if OSPF is enabled for route domain 0, type the following command:

    cp /config/zebos/rd0/ZebOS.conf /config/zebos/rd0/ZebOS.conf.K21090061

  3. Using a text editor, modify the ZebOS.conf file and look for a line that appears similar to the following example:

    ip ospf 1.1.1.1 message-digest-key 1 md5 mypassword

    Modify that line and remove the IP address.

    For example:

    ip ospf message-digest-key 1 md5 mypassword

  4. Save your changes and exit the text editor.
  5. To load the configuration file, type the following command:

    tmsh restart /sys service tmrouted

Optionally, you can omit the IP address argument when using the IMI Shell (imish) interactively.

Impact of workaround: Performing the suggested workaround should not have a negative impact on your system.
