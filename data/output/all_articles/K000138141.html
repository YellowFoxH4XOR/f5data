Description

How to use RSA keys size 3072 on BIG-IP.

Environment

  • SSL profile
  • RSA 3072 key

Cause

BIG-IP does not allow creation of RSA keys size of 3072 but you can import existing RSA key generated with other tools like openssl genrsa.

Recommended Actions

To import an existing RSA key of size 3072 using TMSH:

  1. Copy the existing key to BIG-IP (for example to /var/tmp/rsa3072.key)
  2. Run tmsh install sys crypto key rsa3072 from-local-file /var/tmp/rsa3072.key

To import an existing RSA key of size 3072 using Web GUI:

  1. Navigate to System ›› Certificate Management : Traffic Certificate Management : SSL Certificate List
  2. Click Import and specify the key name.

Additional Information

Currently BIG-IP does not allow RSA keys of 3072 with internal FIPS card.
