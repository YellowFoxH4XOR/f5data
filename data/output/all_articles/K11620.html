Issue

After rebooting BIG-IP systems running 10.1.0 and 10.2.x, an error message that appears similar to the following example may be logged to the /var/log/kern.log file:

err kernel: Memory for crash kernel (0x0 to 0x0) notwithin permissible range

This error message is benign; it is the result of a change in the kdump architecture for the CentOS operating system. This error message is documented as a known issue in the CentOS release notes. The following link will take you to a resource outside of AskF5, and it is possible that the document may be removed without our knowledge:

http://wiki.centos.org/Manuals/ReleaseNotes/CentOS5.1/#head-da845ab1cd8fc52963ad03fdbdefc2bde261b0a6

Note: For information about base operating systems, refer to K3645: Base operating system information for the BIG-IP Host system.
