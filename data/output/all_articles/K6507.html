Topic

The default secure shell (SSH) key length is 1024 bits.

You can view this figure by typing the following OpenSSL command:

openssl rsa -noout -text -in /var/ssh/ssh_host_rsa_key | grep -i key

The OpenSSL command will provide the following output:

Private-Key: (1024 bit)
