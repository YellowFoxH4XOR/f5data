Known Issue

This is the result of a known issue. If you attempt to delete a virtual server that references an HTTP class with either the BIG-IP ASM system or BIG-IP WebAccelerator system enabled from a partition other than the common partition, the system generates an error message that appears similar to the following example:

mcpd[26299]: 01070826:3: Current Update Partition Error: The current update partition <partition> does not match the object's partition (Common) (unknown) <virtual_server>

F5 Product Development is tracking this issue as ID 224993 (formerly CR138268).

This issue has been fixed in BIG-IP versions 10.2.2, 11.0.0,  and cumulative hotfix Hotfix-BIGIP-10.2.1-473.0-HF1, which has been issued for BIG-IP version 10.2.1. You may download this hotfix or later versions of the cumulative hotfix from the F5 Downloads site.

For information about installing a hotfix for version 10.x systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

For information about downloading software from F5, refer to K167: Downloading software and firmware from F5.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

Workaround

To work around this issue, perform the following procedure:

  1. Log in to the Configuration utility.
  2. From the Partition drop-down menu, select the partition from which you are attempting to delete the virtual server.
  3. Click Local Traffic.
  4. Click Virtual Servers.
  5. Click the virtual server that you are attempting to delete.
  6. Click the Resources tab.
  7. In the HTTP Class Profiles section, click Manage.
  8. Remove the ASM or WebAccelerator HTTP classes using the Move buttons (>>).
  9. Click Finished.
  10. You can attempt to delete the virtual server object.

    Note: You may have to wait several seconds before attempting to delete the virtual server.
