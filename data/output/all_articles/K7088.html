Topic

Note: Beginning in BIG-IP 9.4.7, F5 does not support the umdinstall utility and removed it from the BIG-IP installation image files. F5 recommends using the mkdisk utility on a BIG-IP system or a Linux-based system to load a BIG-IP installation image onto a USB mass storage device.

In BIG-IP 9.4.0 through 9.4.6, the BIG-IP software includes the umdinstall utility, which can format a USB thumb drive device. When a supported BIG-IP platform is then booted to the USB thumb drive, a complete product installation can occur from that device.

BIG-IP platforms

F5 supports the USB thumb drive installation method on the following BIG-IP platforms:

  • BIG-IP 1500 (C36)
  • BIG-IP 1600 (C102)
  • BIG-IP 3400 (C62)
  • BIG-IP 3410 (C100)
  • BIG-IP 3600 (C103)
  • BIG-IP 3900 (C106)
  • BIG-IP 6400 (D63)
  • BIG-IP 4100 (D46) - unit running ASM only
  • BIG-IP 4500 (D43) - unit running WebAccelerator system only
  • BIG-IP 6800 (D68)
  • BIG-IP 6900 (D104)
  • BIG-IP 8400 (D84)
  • BIG-IP 8800 (D88)
  • BIG-IP 8900 (D106)

Note: The BIOS Rev should be higher than what is noted for the following platforms. For more information, refer to K7119: Displaying BIOS version information for BIG-IP switch appliances.

  • BIG-IP 1500 (C36): BIOS Rev: olTYAN Tomcat i7210 S5112 v0.91 040104 OBJ-0084-00 REV. G
  • BIG-IP 3400 (C62): BIOS Rev: AMIBIOS (C)2001 American Megatrends Inc., Version 07.00.00 TYAN S2707 Motherboard v1.05a 0227041730 OBJ-0075-00 REV. F
  • BIG-IP 6400 (D63): BIOS Rev: TYAN Thunder K8S/K8S-D Pro BIOS vF5-14 OBJ-0092-01 REV. E

USB thumb drives

To use the USB thumb drive installation method, the USB thumb drive should be USB version 2.0 or later, and have a minimum capacity of 1024 MB.

F5 uses the following USB devices successfully for the USB thumb drive installation process:

Note: F5 cannot guarantee that all revisions of the following hardware will function properly. F5 does not endorse or support any hardware or platform that is not provided directly by F5.

  • PNY Technologies Attache 1 GB USB 2.0 Flash Drive
  • Corsair Flash voyager 1 GB USB 2.0 Flash Memory Drive
  • Lexar Jump Drive 1 GB USB 2.0 Flash Drive

F5 confirms that the following system does not work successfully with the USB thumb drive installation process:

  • Kingston Datatraveler II, Model DTI, firmware revision 1.00

Note: F5 does not officially support USB drives that contain encryption hardware.
