Description

Web application is not loading properly after upgrade to v15.1.5
css, js and image files are unable to be downloaded

Environment

  • BIG-IP
  • Upgrade to v15.1.5
  • AAM module provisioned
  • Web page not displayed correctly

Cause

AAM is End of Software Development

Packet capture shows tcp connections are being reset by BIG-IP with F5RST: Internal error ((WAM::HOT) tmi abort failed)

Recommended Actions

  1. Remove "wam application" objects from "ltm profile web-acceleration" objects
  2. Delete all "wam application" objects
  3. Un-provision AAM from the system

Additional Information

Basic caching is still provided by the web acceleration profile as part of the LTM module. See "About Web Acceleration profiles"
Note: "AM Applications" or "wam application" objects are End of Software Development

AAM must be decommissioned prior to upgrading to v16:
K41650093: Configuration failed to load after upgrade to 16.x: Values (/Common/Generic Policy - Enhanced) specified for WAM application
