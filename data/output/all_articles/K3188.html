Topic

BIG-IP includes several built-in mechanisms to prevent SSL proxy resource starvation and Denial of Service (DoS) attacks, including SSL Proxy rate limit queue thresholds.

The SSL Proxy rate limit queue threshold allows to specify global settings to manage high connection rates to an SSL proxy, so that if a proxy is presented with more TCP connections than it is licensed for, BIG-IP can accept the new connections and queue the connections that exceed the licensed TPS.

The sslproxy high queue threshold value specifies the maximum number of pending SSL connections it will store. (The default value is 2000 pending connections.) This limit protects against memory resource starvation.

When the sslproxy high queue threshold value is exceeded, the BIG-IP SSL proxy (all proxies combined) will no longer accept new TCP connections until the queue reaches the sslproxy low queue threshold global setting. (The default value is 1000 pending SSL connections.)

When the sslproxy low queue threshold value is reached, the SSL proxy will begin accepting TCP connections again and the SSL proxy will process the SSL connections in the order that they were received.

For specific additional information, refer to the Mitigating Denial of Service and Other Attacks chapter of the BIG-IP Administration Guide.
