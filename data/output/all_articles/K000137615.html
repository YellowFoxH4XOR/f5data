Description

After upgrading a Viprion with more than 1 blade and one of the slots continuously restarting mcpd along with the following messages:


err mcpd[3084]: 01071991:3: create_a_dir::319 (SDM:Failed to create root dir(/var/sdm/plugin_store/) err(2) (No such file or directory)).

err mcpd[3084]: Configuration error: MCPProcessor::initializeDB: dev/validation/SDMAppProjectMgr.cpp:create_a_dir:320: Failed to create root dir.

err mcpd[3084]: An unexpected failure has occurred, dev/validation/SDMAppProjectMgr.cpp:create_a_dir:320: Failed created root dir. - dev/validation/SDMAppProjectMgr.cpp, line 320, exiting...

info sod[9158]: 010c0012:6 Mcp start publication fails with error 0x1020003.

info clustered[7213]: HA cluster_time_sync clustered enabled.

info clustered[7213]: Blade 1: No info received from slot: waiting for chmand

logger[3234]: Re-staring mcpd 


Environment

VIPRION with multiple blades


Cause

Unknown


Recommended Actions

1) SSH into the slot which is restaring mcpd


2) Run the following command:

mkdir -p /var/sdm

it the issue remains then run the following commnad:

mkdir -p /var/sdm/plugin_store


3) Do a full reboot for all the blades:

clsh shutdown -r now


4) If the issue remains then please be sure you have SSH access open F5 support case for investigation.
