K000137345: F5OS remote syslog with host-logs enabled

Type
Support Solution
Published
2023-10-25
Updated
2023-10-25
Applies to
  • F5OS
  • F5OS-A: 1.3.2
Source
https://my.f5.com/manage/s/article/K000137345

Description

You have configured remote-servers with host-logs enabled.

# show running-config system logging remote-servers
system logging remote-servers remote-server 192.0.2.1
 config remote-port 514
 config proto udp
 selectors selector LOCAL0 WARNING
!
# show running-config system logging host-logs
system logging host-logs
 config remote-forwarding enabled
!

 

Environment

  • Remote syslog
  • host-logs remote-forwarding enabled

Cause

None

Recommended Actions

# cat /etc/rsyslog.d/destinations.conf|grep ";Fwd"
kern.*;daemon.*;user.*;syslog.*;cron.*;authpriv.*;local0.* @[192.0.2.1]:514;FwdFileFormat

After enabling remote servers with host logs enabled, /etc/rsyslog.d/destinations.conf will be updated to send all messages from the kernel, daemon, user, syslog, cron, authpriv, and local0 facilities to the remote server.
