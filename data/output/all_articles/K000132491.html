K000132491: Creating iRule via REST API or tmsh adds an extra newline when viewing the iRule via Configuration Utility

Type
Support Solution
Published
2023-02-10
Updated
2025-02-07
Status
Legacy Content
Applies to
  • BIG-IP
  • BIG-IP LTM: 14.1.5
Source
https://my.f5.com/manage/s/article/K000132491

Description

When creating an iRule through REST API or tmsh, it is observed that an extra newline gets added at the end when viewing the same iRule thereafter via Configuration Utility.  

Environment

  • Creating an iRule via REST API or tmsh

Cause

This is a cosmetic issue with the Web UI and should not cause any negative impact to traffic processing when utilizing the iRule.

Recommended Actions

No immediate action is necessary. In order to get rid of the extra newline, you can simply go to the same iRule via Web UI and click on 'Update' to save the changes (without explicitly removing the extra newline). This action gets rid of the extra newline when viewing the iRule via Configuration Utility.

Additional Information

None.
