Known Issue

The BIG-IP ASM Reports Scheduler tool does not accept all valid generic top-level domains (gTLD).

This issue occurs when the following condition is met:

  • You attempt to add an email address to the BIG-IP ASM Charts Scheduler that contains any of the gTLDs listed below:
    • asia
    • cat
    • coop
    • edu
    • int
    • pro
    • tel
    • travel
    • xxx

The top-level domain (TLD) refers to the last label in a fully-qualified domain name. For example, in the following email addresses, the TLDs are uk and com, respectively:

username@example.co.uk
username@example.com

The BIG-IP ASM Charts Scheduler accepts all two-letter, country-code, top-level domains (ccTLD), and the following gTLDs:

  • com
  • org
  • net
  • gov
  • mil
  • biz
  • info
  • mobi
  • name
  • aero
  • jobs
  • museum

Impact

Certain email addresses cannot receive reporting data from the BIG-IP ASM.

Symptoms

As a result of this issue, you may encounter the following symptom:

  • When you enter an email address into the Charts Scheduler tool and click Add, the system displays an error message that appears similar to the following example:

    The E-Mail address that you have supplied is illegal.

Workaround

To work around this issue, you can modify the email address in the BIG-IP ASM database. To do so, perform the following procedure:

Impact of workaround: None

  1. Back up the BIG-IP ASM configuration by creating a UCS archive. For assistance creating a UCS archive, refer to SOL11318, linked in the Supplemental Information section below.
  2. From the Application Security menu of the Configuration utility, navigate to Reports > Charts > Charts Scheduler.
  3. Click Create.
  4. In the Schedule Title field, type a name for your schedule.
  5. In the Send To (E-Mails) field, type a valid email address that does not contain one of the problematic gTLDs listed in this Solution.

    For example, if your email address is:

    myname@example.edu

    You would type the address with an accepted gTLD, similar to the following example:

    myname@host.com

  6. Click Create.
  7. Log in to the BIG-IP ASM command line interface.
  8. Log in to the MySQL database.
  9. Type the following command:

    # mysql -uroot -p`perl -I/ts/packages -MF5::GenUtils -e 'print get_mysql_password().qq{\n}'`

  10. From the mysql prompt, type the following command syntax, where <OLDEMAIL> is the email address you entered in Step 4, and <NEWEMAIL> is the correct email address:

    mysql> UPDATE DCC.REPORTING_SCHEDULE_EMAILS set email="<NEWEMAIL>" where email="<OLDEMAIL>";

    For example, to make the change with the examples provided in Step 4, you would type the following command:

    mysql> UPDATE DCC.REPORTING_SCHEDULE_EMAILS set email="myname@host.edu" where email="myname@host.com";

  11. Type the following command to exit the MySQL prompt:

    exit
