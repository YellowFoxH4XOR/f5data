Known Issue

This is the result of a known issue. The virtual server creation page does not correctly render in browsers when the BIG-IP system is licensed with a Load Balancing Limited (LBL) license. Depending on the browser, the browser may display garbled content or no content at all. Because of this issue, it is not possible to configure a virtual server using the Configuration utility.

F5 Product Development tracked this issue as ID 243242, ID 247857, and ID 328282 (formerly CR136068), and it was fixed in BIG-IP 10.2.0. For information about upgrading, refer to the BIG-IP LTM release notes.

This issue has been fixed in Hotfix-BIGIP-10.1.0-3402.0-HF2, issued for BIG-IP 10.1.0. You may download this hotfix or later versions of the hotfix from the F5 Downloads site.

To view a list of the latest available hotfixes, refer to K9502: BIG-IP hotfix matrix.

For information about the F5 hotfix policy, refer to K4918: Overview of the F5 critical issue hotfix policy.

For information about installing version 10.x hotfixes on systems, refer to K10025: Managing BIG-IP product hotfixes (10.x).

Workaround

You can work around this issue by configuring a virtual server from the command line by using either the bigpipe utility or the Traffic Management Shell (tmsh).

Note: For more information, refer to the Bigpipe Utility Reference Guide or the Traffic Management Shell (tmsh) Reference Guide.
