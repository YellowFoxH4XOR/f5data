Policy Information

With the availability of the BIG-IP Virtual Edition Lab license that includes BIG-IP Application Acceleration Manager Virtual Edition Lab, BIG-IP Advanced Firewall Manager Virtual Edition Lab, BIG-IP Access Policy Manager Virtual Edition Lab, BIG-IP Application Security Manager Virtual Edition Lab, DNS Virtual Edition Lab, BIG-IP Global Traffic Manager Virtual Edition Lab, and BIG-IP Local Traffic Manager Virtual Edition Lab, F5 is announcing the End of Sale (EoS) of the individual Virtual Edition Lab licenses for each of these modules effective April 1, 2014. Technical Support

F5 maintains generous lifecycle policies that allow customers to enjoy many years of both support and new software releases. Customers whose platforms are designated EoL and who are currently under maintenance contracts will continue to receive technical support until the expiration of the service contract renewal date. Customers are encouraged to upgrade their systems before the Service Contract Renewal date expires.

After the EoSD date, 1-April-2014, F5 will not be able to provide software fixes for any technical issues and F5 will continue to provide technical support for the BIG-IP Application Acceleration Manager Virtual Edition Lab, BIG-IP Advanced Firewall Manager Virtual Edition Lab, BIG-IP Access Policy Manager Virtual Edition Lab, BIG-IP Application Security Manager Virtual Edition Lab, BIG DNS Virtual Edition Lab, BIG-IP Global Traffic Manager Virtual Edition Lab, BIG-IP Local Traffic Manager Virtual Edition Lab on a best-effort basis.
