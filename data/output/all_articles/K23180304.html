Topic

When importing XML-formatted security policies, the BIG-IP ASM system performs XML validation using XML Schema Definition (XSD) files.

Description

You can export BIG-IP ASM security policies as a binary file or as a human readable XML file.  You can then archive or import the exported security policies to another BIG-IP ASM system.

When importing XML-formatted security policies, the BIG-IP ASM system performs XML validation to ensure the XML is well-formed and conforms to the defined schema. The XML file must conform to the schema defined by the BIG-IP ASM system to be successfully imported.  If the security policy does not conform to the XML schema, the import process fails and an error message similar to the following is logged to the /var/log/asm file:

The security policy file does not conform to the schema and cannot be imported.

The following XSD files located on the BIG-IP ASM system define the schema used for validating XML-formatted security policies:

Note: You can load these files into the XML validation tool of your choice.

  • /usr/local/share/perl5/F5/policy_info.xsd  (12.x and later)
  • /usr/lib/perl5/site_perl/F5/policy_info.xsd  (11.x)
  • /var/ts/share/import_export_xml.xsd
  • /var/ts/share/xml/generic_schemas/soap-encoding.xsd
  • /var/ts/share/xml/generic_schemas/soap-envelope-12.xsd
  • /var/ts/share/xml/generic_schemas/soap-envelope.xsd
  • /var/ts/share/xml/generic_schemas/xml.xsd

Recommendations

When you import XML-formatted security policies to the BIG-IP ASM system, consider the following:

  • F5 recommends that you do not import a security policy that was exported from a later software version.
  • If the security policy XML file has been modified, ensure the document conforms to the defined XML schema.
