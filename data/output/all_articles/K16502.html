Known Issue

VMware View desktop initiation may trigger an "HTTP 500 - Internal Server Error" response.

This issue occurs when all of the following conditions are met:

  • Your iOS device is running the VMware View client 2.3.1.
  • You establish an access session.
  • You access the VMware View desktop resource.
  • You close the VMware View desktop.
  • You attempt to relaunch the VMware View desktop.

Impact

Access to the VMware View desktop fails.

Symptoms

As a result of this issue, you may encounter one or more of the following symptoms:

  • When attempting to initiate the access session, the BIG-IP APM responds with an "HTTP 500 - Internal Server Error" response with an OK button to continue.
  • The system logs error messages to the /var/log/apm file that appear similar to the following example:

    err vdi[5774]: 01490000: {16d.C} LookupApmSid error SessionDB:18
    err vdi[5774]: 01490000: {16d.C} SessionState: session data error SessionDB:18
    err vdi[5774]: 01490000: {16d.C} Failed sending headers with error 5 : 'InvalidData'
  • The system logs error messages to the /var/log/ltm file that appear similar to the following example:

    err tmm[8895]: 01230140:3: RST sent from <virtual server ip address:port> to <user session ip address:port>, [0x17c68b4:457] Internal error (VDI requested abort (plugin abort error))
    err tmm1[8895]: 01230140:3: RST sent from <virtual server ip address:port> to <user session ip address:port>, [0x17c68b4:457] Internal error (VDI requested abort (plugin abort error))

Workaround

To work around this issue, you can continue the session initiation by clicking the "HTTP 500 - Internal Server Error" response OK button.

Impact of workaround: Performing this workaround will not have a negative impact on your system.
