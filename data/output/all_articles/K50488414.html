Description

Spikes of Linux load average are reported when monitoring the BIG-IP system via SNMP polling of laLoad.

You suspect a CPU utilization issue.

Environment

  • External monitoring
  • Performance
  • SNMP polling

Cause

Load average on Linux is not intended to reflect CPU load average, but rather overall system load average. A higher load average than normal may be caused by many factors and is not always indicative of high CPU utilization.

A slightly higher load average than normal in a short period of time may mean there are a number of processes wanting to run in a short period. This is generally not cause for concern.

A persistent, significantly higher load average than normal may indicate a more serious problem and requires further investigation.

Recommended Actions

Use other metrics to determine if there are CPU utilization issues, and turn to load average values for an overall view of system resource availability.

Additional Information

laLoad retrieves its values from /proc/loadavg, which is also used by the top and uptime commands. Load average reported by all of these utilities should be identical.
