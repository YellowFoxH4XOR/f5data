K000153001: Extending Expiry Time for Existing Keys in Keyval Zones

Type
Support Solution
Published
2025-08-27
Updated
2025-08-27
Applies to
  • NGINX Products
  • NGINX Plus: R35, R34, R33, R32
Source
https://my.f5.com/manage/s/article/K000153001

Description

  • You have a Keyval zone configured with some keys created with "timeout" parameter set.
  • You want to extend the expiry time for the existing keys.

Environment

  • NGINX Plus
  • Keyval Zones
  • 'timeout' parameter 

Cause

  • None

Recommended Actions

  • Update the "expire" parameter using the following API call:
curl -X 'PATCH' 'http://<NGINX_ADDR/FQDN>:<PORT>/api/9/http/keyvals/<KEYVAL_ZONE_NAME>' -H 'accept: application/json' -H 'Content-Type: application/json' -d '{"<KEY>": {"value": <VALUE>,"expire": <VALUE_IN_MILLISECONDS>}}'

Example:

curl -X 'PATCH' 'http:// localhost:9000/api/9/http/keyvals/apikey' -H 'accept: application/json' -H 'Content-Type: application/json' -d '{"key3": {"value": "value3","expire": 30000}}'

Additional Information

  • None
