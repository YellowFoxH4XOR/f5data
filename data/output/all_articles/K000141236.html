K000141236: 100% utilization of /var/log on BigIQ License Manager

Type
Support Solution
Published
2024-09-29
Updated
2025-02-07
Applies to
  • BIG-IQ
Source
https://my.f5.com/manage/s/article/K000141236

Description

If you are facing 100% /var/log utilization on BIG IQ, which is used only for License Management, the elasticsearch can flood the /var/log/elastisearch/eslognode-*.log, it might be caused by old  configuration stored in BIG IQ configuration files - espescially DCDs which were deleted  not properly in the past.

 

Environment

  • BIG IQ License Manager 

Cause

Inconsistent configuration file

Recommended Actions 

Verify the /var/config/rest/elasticsearch/config/elasticsearch.yml if in hosts section you can see any IP addresses with :9300 port, similar to:

discovery:
  zen:
    ping:
      unicast:
        hosts:
        - 10.0.0.2:9300
        - 10.0.0.3:9300
        - 10.0.0.4:9300

If the DCDs are not expected to see above, follow K02014651 to clean the elasticsearch configuration, and after all you can delete the eslognode-*.log files.

Note: For K02014651, refer to the Related Content section. 

Important: The procedure from K02014651 won't impact your license manager configuration.
